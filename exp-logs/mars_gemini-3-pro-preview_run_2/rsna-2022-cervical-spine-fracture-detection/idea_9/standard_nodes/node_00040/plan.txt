This script implements the end-to-end pipeline for the Cervical Spine Fracture Detection task. It orchestrates data loading, model training, validation, failure analysis, and conditional submission generation based on the specified performance threshold.

The script utilizes the provided library modules for configuration, dataset management, model architecture, and training logic. It ensures reproducibility by setting fixed seeds and optimizes runtime by using GPU acceleration and pre-computed caches. Failure analysis is performed by correlating the validation loss with study-level metadata (slice counts) to identify potential sources of error.
