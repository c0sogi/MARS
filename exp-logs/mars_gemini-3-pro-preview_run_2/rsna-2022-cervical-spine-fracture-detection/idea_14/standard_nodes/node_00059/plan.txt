Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration Override**: We will override the default `Config` to create a "Fast Baseline". We set `EPOCHS` to 5 to ensure execution finishes within the 2-hour limit while still allowing convergence. We keep `SEQ_LEN=96` and `BATCH_SIZE=2` to maintain the integrity of the 2.5D sequence approach on the A100 GPU.
2.  **Training Loop**: We reconstruct the training loop using `train_one_epoch` and `validate` from `library.train_eval`. This gives us fine-grained control to save the best model and track the metric.
3.  **Metric Reporting**: We calculate the validation loss using the provided `WeightedMultilabelLoss` and print it exactly as required (`Final Validation Metric: <value>`).
4.  **Failure Analysis**:
    *   We iterate through the validation set using the trained model.
    *   We compute the weighted loss per study (averaging over the 8 class targets).
    *   We extract metadata (slice count) from the dataset's path map.
    *   We calculate the Pearson correlation between the study-level loss and the slice count to identify if Z-depth complexity correlates with error.
5.  **Submission Generation**:
    *   We check the threshold condition (`val_loss < 0.1241588886`).
    *   If passed, we use `get_test_dataloader` to load test studies.
    *   We run inference (disabling gradients) and format the 8 outputs per study into the required row-based CSV format (`[StudyUID]_[Target]`).
    *   The result is saved to `./submission/submission.csv`.
