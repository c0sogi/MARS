The following script demonstrates the usage of the provided library components for the Cervical Spine Fracture Detection task.

**Implementation Strategy:**
1.  **Configuration Overrides**: We modify the global `Config` class attributes to reduce resource usage (smaller image size, shorter sequence length, smaller backbone, fewer epochs) to ensure the demo runs quickly within the time limit.
2.  **Dataset Verification**: We load a small subset of the training metadata, initialize the `RSNADataset`, and verify that the data loading pipeline (including 2.5D stacking and transforms) produces tensors of the expected shape.
3.  **Model & Loss Verification**: We instantiate the `CervicalSpineModel` and `WeightedMultiLabelLoss`. We perform a forward pass with dummy data to verify the architecture's output shape and calculate the loss to ensure the mathematical operations are valid.
4.  **Training Loop Simulation**: We set up a minimal training environment (optimizer, scaler, data loader) and run `train_one_epoch` and `validate` for a single epoch on a tiny dataset to demonstrate the training workflow.
5.  **Inference & Submission**: We utilize the provided `predict` function in debug mode to generate predictions on the test set and verify the format of the resulting submission file.
