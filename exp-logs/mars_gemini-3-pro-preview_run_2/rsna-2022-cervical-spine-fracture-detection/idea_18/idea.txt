# Proposed Solution: Calibrated 2.5D Multi-Level Network with Hierarchical Embedding Aggregation

## Model
The architecture is a hierarchical sequence network designed to maximize feature resolution and enforce logical consistency between local findings and global diagnosis.

1.  **2.5D Input Representation:**
    The model processes inputs as **2.5D stacks** (slices $z-1, z, z+1$) to provide local volumetric continuity to the 2D backbone. This allows the model to distinguish persistent anatomical structures from transient noise (Cite solution_lesson_node_00014).

2.  **Backbone with Multi-Level Global Pooling:**
    *   **Backbone:** An **EfficientNet-B4** is used as the feature extractor.
    *   **Multi-Level Aggregation:** To resolve the trade-off between semantic context and spatial resolution, features are extracted from both the **penultimate block (P4)** and the **final block (P5)**.
    *   **Robust Pooling:** **Standard Global Average Pooling (GAP)** is applied to the P4 and P5 maps *independently*. The resulting vectors are **concatenated** to form the slice embedding. This ensures the sequence model receives both high-level semantics (P5) and fine-grained texture details (P4) necessary for detecting hairline fractures (Cite solution_lesson_node_00035), avoiding the gradient instability of custom pooling layers (Cite solution_lesson_node_00052).

3.  **Sequence Modeling with Positional Injection:**
    *   **Bi-LSTM:** The sequence of multi-level embeddings is processed by a Bidirectional LSTM to model the anatomical continuity of the spine along the Z-axis (Cite solution_lesson_node_00014).
    *   **Positional Embeddings:** Learnable positional vectors are added to the LSTM outputs. This provides the explicit spatial references required to disentangle visually similar vertebrae (Cite solution_lesson_node_00029).

4.  **Hierarchical Embedding Aggregation (Structural Innovation):**
    *   **Level 1 (Disentangled Subtypes):** The model utilizes **7 Independent Attention Heads**, one for each cervical vertebra (C1-C7). Each head computes unique attention weights to extract a specific feature vector $E_{Cx}$ from the LSTM sequence (Cite solution_lesson_node_00029). These vectors are passed to linear classifiers to predict the C1-C7 probabilities.
    *   **Level 2 (Global Fusion):** Instead of an independent "Overall" attention head (which might attend to irrelevant regions), the **Patient Overall** prediction is derived from a **Fusion Head**. This head takes the **concatenation** of the 7 vertebra-specific embeddings ($[E_{C1}, E_{C2}, \dots, E_{C7}]$) as input.
    *   **Benefit:** This enforces a structural prior: the global diagnosis is a function of the local anatomical features. By aggregating in **embedding space** rather than probability space, the model preserves high-dimensional information (e.g., uncertainty or feature magnitude) for the final decision (Cite solution_lesson_node_00005).

## Data
1.  **Preprocessing & Sampling:**
    *   **High-Density Sampling:** The loader samples a sequence of **96 slices**. This prioritizes Z-axis coverage to ensure small fractures are not skipped, adhering to the finding that sampling density outweighs model complexity (Cite solution_lesson_node_00032).
    *   **2.5D Stacking:** Inputs are constructed by stacking 3 adjacent slices.

2.  **Dataset-Encapsulated Augmentation:**
    *   Geometric transformations (rotation, shift, scale) are sampled *once* per study and applied identically to every slice in the stack within the `Dataset.__getitem__` method. This preserves the physical alignment of the spine required for the sequence model (Cite solution_lesson_node_00008, solution_lesson_node_00010).

## Training
1.  **Calibrated Loss Function:**
    *   The model is trained using **Weighted Multi-Label Logarithmic Loss**.
    *   **Crucial Calibration:** The loss function will use **NO Positive Class Weighting** (i.e., `pos_weight=1.0`). Since the training set is roughly balanced (~46% positive), adding positive weights forces the model to over-predict fractures, destroying probability calibration and degrading the Log Loss metric (Cite solution_lesson_node_00042).
    *   **Metric Normalization:** The loss weights for the different classes (C1-C7 vs Overall) will be explicitly **normalized** to sum to 1.0 to ensure the loss scale is consistent and interpretable (Cite solution_lesson_node_00032).

2.  **Optimization:**
    *   **Gradient Accumulation:** Employed to simulate a stable effective batch size (e.g., 16 studies) despite the memory footprint of the EfficientNet-B4 backbone and dense sampling (Cite solution_lesson_node_00007).
    *   **Stability Strategy:** The model relies solely on the study-level labels. Sparse auxiliary tasks are avoided to prevent instability (Cite solution_lesson_node_00047).

## Evaluation
1.  **Inference:**
    *   Test studies are loaded, preprocessed into 2.5D stacks (96 slices), and passed through the pipeline.
    *   The **Multi-Level GAP** ensures fine details are preserved.
    *   The **Hierarchical Heads** generate C1-C7 probabilities and a logically consistent Patient Overall probability.
    *   The final output probabilities are well-calibrated, maximizing the competition metric.
