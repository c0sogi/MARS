The following script performs an Exploratory Data Analysis on the cervical spine fracture detection dataset.

**Implementation Strategy:**
1.  **Setup & Data Loading**: The script initializes random seeds for reproducibility and loads the training metadata from `./metadata/train_metadata.csv`.
2.  **Target Variable Analysis**: It calculates the prevalence of the overall patient fracture label and each specific vertebrae label (C1-C7). It also analyzes the co-occurrence of fractures (multi-label analysis) and correlations between different fracture sites.
3.  **Input Data Analysis (Image)**: The script analyzes the image data structure. It samples a subset of studies to count the number of slices (Z-dimension) per patient, which is a critical feature for 3D processing. It attempts to import `pydicom` to extract image dimensions (rows, columns) and pixel statistics; if the library is unavailable (due to strict environment constraints), it gracefully falls back to analyzing file sizes as a proxy for image complexity.
4.  **Feature/Signal Relationships**: It investigates relationships between meta-features (e.g., number of slices in a scan, file size) and the presence of a fracture. This is done using Pearson correlation and a lightweight Random Forest classifier to determine if scan protocols (inferred from metadata) carry predictive signal for fractures.
5.  **Reporting**: The results are printed in a clean, formatted text report.
