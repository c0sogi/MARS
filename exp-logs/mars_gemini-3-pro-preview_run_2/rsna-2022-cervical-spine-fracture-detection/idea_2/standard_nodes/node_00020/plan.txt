This aligns with the lesson that configuration definitions must be synchronized with model dependencies (Cite debug_lesson_2). To fix this, I will explicitly define `CLASS_WEIGHTS` (as a list of weights for the 8 target columns) and `POS_WEIGHT` (as a scalar for positive class weighting) in `library/config.py`.
