We will also increase the sequence length to capture more anatomical detail along the Z-axis.

2.  **`library/utils.py`**: Update `WeightedMultiLabelLoss` to accept an optional `pos_weight` argument and apply it using `F.binary_cross_entropy_with_logits`.
3.  **`runfile.py`**: Modify the training loop to use the weighted loss (with `pos_weight`) for optimization but the standard unweighted loss for validation. This ensures the model learns to detect fractures better while the reported metric remains comparable to the baseline (0.3812).
