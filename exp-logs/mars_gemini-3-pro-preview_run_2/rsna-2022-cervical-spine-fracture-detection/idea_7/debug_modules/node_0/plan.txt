The implementation strategy involves the following steps:

1.  **Configuration Override**: Modify the global `Config` class to set reduced hyperparameters (1 epoch, batch size of 2, reduced sequence length and image size) and define a specific working directory for the demo. This ensures the script runs quickly and respects the resource constraints.
2.  **Data Preparation**: Load the pre-generated metadata CSVs and create small subsets (top 4 rows) for training, validation, and testing. Manually instantiate the `CervicalSpineDataset` and `DataLoader` using these subsets to bypass loading the full dataset.
3.  **Model & Loss Verification**: Initialize the `CervicalSpineModel` and `HybridLoss`. Perform a single forward pass with a batch from the training loader to verify tensor shapes (`(Batch, 8)` for study logits, `(Batch, SeqLen)` for slice logits) and ensure the loss is a valid scalar.
4.  **Training Execution**: Call the `fit` function from the provided engine to run the training loop for one epoch. This verifies the integration of the model, optimizer, and loss function, and ensures the model checkpoint is saved.
5.  **Inference & Submission**: Call the `predict` function to generate predictions on the test subset and save the `submission.csv`. Verify the existence of the output file.
6.  **Metric Check**: Validate the `competition_metric` function using dummy numpy arrays to ensure it computes the weighted log loss correctly.
