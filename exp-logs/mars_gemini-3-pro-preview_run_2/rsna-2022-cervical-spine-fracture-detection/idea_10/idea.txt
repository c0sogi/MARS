Based on the progression of experiments and the specific empirical lessons learned, I propose the **Calibrated 2.5D Dual-Attention Network with Anatomical Injection**.

This solution structurally evolves the "Multi-Scale 2.5D Network" (Idea 7/9) by integrating **Explicit Anatomical Injection** to resolve the spatial ambiguity of vertebral levels, and fundamentally alters the training objective to prioritize **Probabilistic Calibration** over raw sensitivity, addressing the metric scaling issues identified in the latest lessons.

# Proposed Solution: Calibrated 2.5D Dual-Attention Network with Anatomical Injection

## Model
The architecture is a hierarchical sequence network that explicitly disentangles **fracture detection** from **anatomical localization** using dense supervision streams.

1.  **2.5D Multi-Scale Backbone:**
    *   **Input:** The model processes **2.5D stacks** (slices $z-1, z, z+1$) to capture local volumetric continuity (Cite solution_lesson_node_00014).
    *   **Feature Extraction:** An **EfficientNet-B4** backbone extracts features. To capture both semantic context and fine fracture lines, feature maps from the **P4 (penultimate)** and **P5 (final)** blocks are extracted and concatenated (Cite solution_lesson_node_00035).

2.  **Spatially-Guided Attention Module:**
    *   Instead of Global Average Pooling, a lightweight convolutional block projects the fused P4/P5 features to a **Spatial Attention Map**.
    *   The slice embedding is computed as the spatially weighted sum of the feature maps. This mechanism is supervised by bounding boxes to force the backbone to "look" at fracture sites before compressing spatial dimensions (Cite solution_lesson_node_00035).

3.  **Anatomically-Injected Sequence Modeling:**
    *   **Bi-LSTM:** The sequence of slice embeddings is processed by a Bidirectional LSTM to model Z-axis continuity (Cite solution_lesson_node_00014).
    *   **Structural Innovation (Anatomical Injection):** A secondary classification head (Multi-Layer Perceptron) is attached to the LSTM output to predict the **Vertebral Level** (C1-C7 or Background) for each slice.
    *   These predicted anatomical probabilities are **concatenated** with the LSTM hidden states. Unlike generic Positional Embeddings (which only encode relative depth), this provides the subsequent attention heads with explicit biological context (e.g., "This slice is definitely C2"), robustly handling patient variability (height/spine length) that confused previous models (Refining Idea 5, Cite solution_lesson_node_00029).

4.  **Class-Specific Attention Aggregation:**
    *   8 Independent Attention Heads (C1-C7, Overall) aggregate the anatomically-enriched LSTM outputs. The C1 Head can now explicitly learn to attend to slices where the Anatomical Injection signal for "C1" is high (Cite solution_lesson_node_00029).

## Data
1.  **Hybrid Dense Target Generation:**
    *   **Fracture Targets:** Slice-level binary vectors are generated from `train_bounding_boxes.csv`.
    *   **Anatomical Targets:** Slice-level multi-class vectors (C1-C7) are generated from the `segmentations/` NIFTI files.
    *   **Spatial Masks:** 2D binary masks are generated for the Spatial Attention Module using bounding box coordinates.

2.  **Preprocessing:**
    *   **2.5D Stacking:** Inputs are stacks of 3 adjacent slices.
    *   **High-Density Sampling:** The sequence length is set to **96 slices**. This prioritizes Z-axis coverage to prevent missing small fractures, adhering to the lesson that sampling density is more critical than model complexity (Cite solution_lesson_node_00032).
    *   **Dataset-Encapsulated Augmentation:** Geometric transformations are applied identically across the entire volume within `__getitem__` to preserve physical alignment (Cite solution_lesson_node_00010).

## Training
1.  **Calibrated Multi-Task Loss:**
    *   The loss function is a weighted sum: $L_{total} = L_{study} + \lambda_1 L_{slice\_fracture} + \lambda_2 L_{spatial} + \lambda_3 L_{anatomy}$.
    *   **Study Loss ($L_{study}$):** Weighted Multi-Label Logarithmic Loss. **Crucially**, this will use **NO Positive Class Weighting** (or very mild weighting). Lesson 00042 demonstrated that aggressive `pos_weight` destroys calibration on balanced datasets, leading to high Log Loss despite high sensitivity. The model will be trained to output calibrated probabilities (Cite solution_lesson_node_00042).
    *   **Auxiliary Losses:**
        *   $L_{slice\_fracture}$: Masked BCE on slice-level fracture predictions (Cite solution_lesson_node_00035).
        *   $L_{spatial}$: Masked Dice Loss on Spatial Attention Maps (Cite solution_lesson_node_00035).
        *   $L_{anatomy}$: Masked Cross-Entropy on the Anatomical Injection head (using the subset of data with segmentation labels).

2.  **Optimization:**
    *   **Gradient Accumulation:** Used to simulate a batch size of 8-16 studies to ensure stable convergence (Cite solution_lesson_node_00007).
    *   **Metric Normalization:** Validation metrics will be explicitly normalized (sum of weights = 1.0) to allow for accurate tracking of model improvement (Cite solution_lesson_node_00032).

## Evaluation
1.  **Inference:**
    *   Test studies are processed through the full pipeline.
    *   The **Anatomical Injection** head generates internal features that guide the attention mechanism, but its outputs are not directly used for submission.
    *   The **Class-Specific Attention Heads** output the final calibrated probabilities for the 8 target columns.
