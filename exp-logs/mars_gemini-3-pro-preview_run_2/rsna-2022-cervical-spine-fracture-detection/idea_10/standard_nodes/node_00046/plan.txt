The issue is that the model attempts to process a very large effective batch size (Batch Size × Sequence Length = 192 high-resolution images) during training. Even though the code chunks the forward pass, PyTorch's autograd engine retains the intermediate activations for all chunks to compute gradients, leading to an Out of Memory error (Cite debug_lesson_10). To resolve this, I will implement gradient checkpointing using `torch.utils.checkpoint` within the chunking loop. This allows the model to discard intermediate activations for each chunk and recompute them during the backward pass. I will manually wrap the backbone execution to ensure compatibility and correctly handle the input gradient requirement, avoiding potential `TypeError` issues with factory functions (Cite debug_lesson_5).
