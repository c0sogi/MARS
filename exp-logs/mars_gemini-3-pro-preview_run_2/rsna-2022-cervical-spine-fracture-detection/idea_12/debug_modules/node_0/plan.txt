The following script demonstrates the end-to-end workflow for the cervical spine fracture detection task using the provided library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to run in a lightweight "Demo Mode" (reduced image size, sequence length, and dataset size) to ensure execution within the time limit.
2.  **Data Loading**: Initializes the DataLoaders and verifies the shape of the generated batches (Sequence of 2.5D slices).
3.  **Model Initialization**: Instantiates the `CalibratedSequenceModel` and performs a dummy forward pass to validate tensor shapes.
4.  **Training Loop**: Runs the `fit` function for a single epoch on a tiny subset of data to demonstrate the training and checkpointing mechanism.
5.  **Inference**: Runs the `inference` function to generate predictions on the test set and creates a submission file.
6.  **Metric Verification**: Manually validates the weighted logarithmic loss function with known inputs.
