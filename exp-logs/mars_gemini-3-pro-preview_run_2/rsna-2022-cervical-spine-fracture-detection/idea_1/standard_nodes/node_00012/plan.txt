The error arises because the `RSNADataset` class definition in `library/dataset.py` does not accept a `split` argument in its `__init__` method, yet both `runfile.py` and `library/inference.py` attempt to pass `split="val"` or `split="test"` during instantiation. This mismatch between the class interface and its usage is a result of code evolution where the dataset logic was updated to infer the mode (train vs. test) from the presence of label columns, but the dependent code was not synchronized (Cite debug_lesson_2). To fix this, I will remove the invalid `split` argument from the `RSNADataset` instantiation in both `runfile.py` and `library/inference.py`.
