The implementation strategy is as follows:

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class and set random seeds for reproducibility.
2.  **Training**: Instantiate the `Trainer` class from the library and execute the `fit()` method. This handles the training loop, validation monitoring, and saving the best model checkpoint. The default configuration (10 epochs) is used as it is appropriate for the dataset size and time constraints.
3.  **Validation Assessment**:
    *   Load the best model weights saved during training.
    *   Iterate through the validation dataset using the `RSNADataset` and `DataLoader`.
    *   Collect predictions and ground truth labels.
    *   Compute the **Final Validation Metric** using the `WeightedLogLoss` class as specified in the task description.
4.  **Failure Analysis**:
    *   Calculate the weighted log loss for each individual study in the validation set.
    *   Merge these loss values with the validation metadata.
    *   Compute and print correlations between the model's error (loss) and key characteristics: the total number of fractures (`fracture_count`) and the overall patient outcome (`patient_overall`). This helps identify if the model struggles more with complex positive cases.
5.  **Submission**: Call the provided `generate_submission` function to run inference on the test set and save the results to `submission.csv`.
