# Proposed Baseline Solution: 2D Slice-Based Multiple Instance Learning (MIL)

## Model
The proposed architecture is a **2D Multiple Instance Learning (MIL) Network** with a Max-Pooling aggregation strategy. Unlike the CNN-RNN approach (Model 1), this design assumes that if a fracture exists in the scan, it will be clearly visible in at least one 2D slice, and thus temporal or spatial sequence modeling is not strictly necessary for a baseline.

1.  **Slice Feature Extractor:** A lightweight, pre-trained 2D CNN (e.g., EfficientNet-B0 or ResNet18) acts as the backbone. It processes individual axial slices independently, treating the 3D volume as a "bag" of 2D images.
2.  **Instance-Level Classifier:** A fully connected layer attached to the backbone outputs 8 probabilities (C1-C7 and patient_overall) for *each* individual slice.
3.  **Global Aggregation (Max Pooling):** To obtain the final prediction for the entire study (the "bag"), the model applies a global max-pooling operation across the slice dimension. For example, the predicted probability for a C1 fracture in the study is the maximum probability of C1 fracture predicted among all processed slices.

## Data
To ensure high throughput and low latency given the large 3D volumes:

1.  **Slice Subsampling:** Instead of processing every slice (which averages ~360 per scan), the loader will uniformly subsample a fixed number of slices (e.g., 64 or 96) from the Z-axis of each scan. This standardizes the input size and significantly reduces computational load.
2.  **Windowing:** DICOM pixel values will be converted to Hounsfield Units and windowed specifically for bone structures (e.g., Window Center: 500, Window Width: 2000). This removes soft tissue noise and highlights fractures.
3.  **Resizing:** Images will be resized from 512x512 to a smaller resolution (e.g., 256x256) to further accelerate the CNN backbone.
4.  **Normalization:** Pixel values will be normalized to the range [0, 1].

## Training
1.  **Loss Function:** The model will be trained using the competition's **Weighted Multi-Label Logarithmic Loss**. Crucially, the loss is calculated between the *aggregated* study-level predictions (after max-pooling) and the study-level ground truth labels. This effectively trains the model in a weakly-supervised manner, encouraging it to identify the most "fracture-like" slice in the volume.
2.  **Optimizer:** Use the AdamW optimizer with a standard learning rate (e.g., 1e-4) and a cosine annealing scheduler.
3.  **Batching:** Training batches will consist of multiple studies, where each study is represented by a tensor of shape `(N_slices, Channels, Height, Width)`.

## Evaluation
1.  **Inference:** For each test study, the pipeline loads the DICOM files, applies the same windowing, resizing, and uniform subsampling used in training.
2.  **Prediction:** The 2D CNN processes the batch of selected slices.
3.  **Aggregation:** The max-pooling operation is applied to the slice predictions to generate the final 8 probabilities for the study. These are formatted into the required submission rows (e.g., `[StudyID]_C1`, `[StudyID]_patient_overall`).
