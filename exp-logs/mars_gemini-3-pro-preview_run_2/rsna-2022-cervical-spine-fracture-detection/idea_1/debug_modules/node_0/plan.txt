The following script demonstrates the usage of the provided library components for the RSNA Cervical Spine Fracture Detection task. It validates the data loading pipeline, model architecture, loss calculation, training loop, and inference generation.

To ensure the demonstration runs quickly and efficiently:
1.  **Configuration Overrides**: Key hyperparameters in `Config` (image size, number of slices, batch size) are modified to reduce computational load.
2.  **Utility & Data Checks**: The script validates DICOM sorting and loading logic, then instantiates the `RSNADataset` to verify tensor shapes.
3.  **Model & Loss Verification**: It performs a forward pass with dummy data to check the MIL architecture and calculates loss to verify the weighted metric.
4.  **Training & Inference**: The `Trainer` and `generate_submission` modules are executed in `debug` mode, running a minimal loop to confirm end-to-end functionality without processing the full dataset.
