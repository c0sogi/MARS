Implementation Strategy:
1.  **Setup & Config**: Initialize the environment and override `Config.EPOCHS` to 5 for a rapid but effective baseline training run on the small training set (161 samples).
2.  **Training**: Instantiate the `Trainer` class and execute the `fit()` method to train the 2.5D Multi-Head Attention Network.
3.  **Validation**: Load the best model checkpoint. Iterate through the validation set to compute the `Final Validation Metric` (Weighted Multi-Label Log Loss) and collect per-sample losses.
4.  **Failure Analysis**: Extract the "Slice Count" feature for each validation study from the disk. Compute and print the Pearson correlation between the model's error magnitude (loss) and the slice count to identify potential biases (e.g., performance degrading on deeper scans).
5.  **Submission**: Compare the calculated validation metric against the threshold (0.38122559812935913). If the model performs sufficiently well, generate the `submission.csv` predictions for the test set.
