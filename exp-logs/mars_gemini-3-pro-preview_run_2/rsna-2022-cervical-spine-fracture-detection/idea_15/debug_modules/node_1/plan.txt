The `ValueError: num_samples should be a positive integer value, but got num_samples=0` occurs because the training dataset is empty. This is caused by a cache collision where the validation dataset overwrites the training dataset's cache file (`paths_cache.parquet`) because both use the same hardcoded filename. When the training loader attempts to reload data from the cache, it reads the validation paths, finds no matching training studies, and filters out all entries.

To fix this, I will modify `library/data.py` to segregate cache files by dataset phase (e.g., `train_paths_cache.parquet`, `val_paths_cache.parquet`). I will update `get_study_file_map` to accept a `phase` argument and use it in the filename, and update `RSNADataset` to pass its phase during initialization.
