The following script demonstrates the usage of the provided library files to train a model and generate a submission for the RSNA Cervical Spine Fracture Detection task.

**Strategy:**
1.  **Configuration Override**: We modify `Config` attributes at runtime to enable `DEBUG` mode, reduce image size, sequence length, and epochs. This ensures the demonstration runs quickly and fits within memory constraints while validating the entire pipeline.
2.  **Component Verification**:
    *   **Data Loading**: We instantiate the data loaders and fetch a single batch to verify tensor shapes (Batch, Sequence, Channels, Height, Width) and target consistency.
    *   **Model Forward Pass**: We manually instantiate the `RSNAModel` and perform a forward pass with the fetched batch to ensure the architecture (EfficientNet backbone + LSTM + Attention) produces logits of the correct shape.
    *   **Loss Calculation**: We verify the custom `weighted_loss` function returns a scalar value.
3.  **Full Pipeline Execution**: We utilize the `RSNAEngine` to run a complete training epoch and generate predictions on the test set.
4.  **Submission Validation**: Finally, we check the generated `submission.csv` to ensure it follows the required format and contains predictions for all test rows.
