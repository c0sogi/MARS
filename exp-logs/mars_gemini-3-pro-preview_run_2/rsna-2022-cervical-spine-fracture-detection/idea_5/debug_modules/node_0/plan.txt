The following script demonstrates the usage of the provided library files to perform the cervical spine fracture detection task. The strategy involves:

1.  **Configuration Override**: Instantiating the `Config` class and modifying specific attributes (enabling debug mode, reducing image size, sequence length, and epochs) to ensure the code runs quickly and fits within memory constraints for the demonstration.
2.  **Data Verification**: Using `get_dataloaders` to load a batch of data and asserting that the input shapes (images) and target shapes (labels) match the expected dimensions for a 2.5D sequence model.
3.  **Model & Loss Verification**: Instantiating `CervicalFractureNet` and `HybridLoss`, performing a forward pass with the batch, and verifying that the output logits and calculated loss are valid.
4.  **Training Loop**: Initializing the `Trainer` with the modified configuration and running `fit()` to demonstrate the training process and checkpoint saving.
5.  **Metric Calculation**: Manually constructing prediction and ground truth DataFrames to verify the `calculate_weighted_log_loss` function.
