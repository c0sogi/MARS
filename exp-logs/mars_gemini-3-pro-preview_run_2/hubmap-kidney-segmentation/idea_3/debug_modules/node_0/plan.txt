The following script demonstrates the usage of the provided library components for the HuBMAP glomerulus detection task. It performs the following steps:

1.  **Configuration Setup**: Overrides the default configuration to run in `DEBUG` mode with reduced epochs and a temporary working directory for speed.
2.  **Utility Verification**: Validates Run-Length Encoding (RLE) logic by encoding and decoding a synthetic mask and asserting data integrity.
3.  **Model Verification**: Instantiates the `AttentionUNetResNet34` model (without pre-trained weights for speed), passes a synthetic tensor, and verifies that the output dimensions match the input resolution.
4.  **Loss Function Verification**: Tests the hybrid `BCEDiceLoss` with dummy predictions and targets to ensure it produces a valid scalar gradient signal.
5.  **Data Pipeline Verification**: Loads the real training data using `get_dataloader` in debug mode (processing only 1 image), verifies the shape of the generated batches (4-channel input: RGB + Anatomical), and checks the normalization statistics.
6.  **Training Loop Demonstration**: Executes a single training step using `train_one_epoch` to verify the backward pass and optimizer step.
7.  **Inference Demonstration**: Simulates the sliding window inference pipeline on a large synthetic image to confirm that the tiling, prediction, and reconstruction logic functions correctly.
