The `torch.OutOfMemoryError` occurred because the configured `BATCH_SIZE` of 16 is too large for the available 16GB VRAM when processing high-resolution $1024 \times 1024$ tiles. As explained in **Debug Lesson 2**, semantic segmentation models require significant memory for storing activation maps, and the batch size must be scaled down to fit the hardware constraints. Cite debug_lesson_2. To resolve this, I will reduce the `BATCH_SIZE` in `library/config.py` from 16 to 4, which will linearly decrease the memory consumption of the tensors and allow the model to train within the available GPU capacity.
