Based on the lessons learned from the previous experiments, I propose the following optimized strategy. This solution structurally evolves the architecture to explicitly handle the extreme sparsity of the target (glomeruli) while retaining the data and training strategies proven to maximize stability and generalization.

### Model: Anatomy-Aware Attention U-Net
I propose replacing the Feature Pyramid Network (FPN) and the previously suggested U-Net++ with an **Anatomy-Aware Attention U-Net** using a **ResNet-34** backbone.

*   **Backbone:** We will use **ResNet-34** as the encoder. As demonstrated in **Cite solution_lesson_node_00008**, heavier backbones like ResNeXt-50 fail to generalize on this small dataset, while **Cite solution_lesson_node_00005** showed ResNet-34 outperforms the lighter ResNet-18.
*   **Structural Innovation 1 (Attention Gates):** Standard U-Nets treat all pixels in the skip connections equally. Given that >98% of the tissue slide is background, this introduces significant noise. We will integrate **Attention Gates** into the decoder's skip connections. These gates use the coarser signal from the decoder to filter the high-resolution features from the encoder, suppressing irrelevant background regions and focusing the model's capacity solely on the sparse target structures.
*   **Structural Innovation 2 (4-Channel Input):** We will modify the first convolutional layer to accept **4 input channels** (RGB + Anatomical Mask). By fusing the binary anatomical segmentation (Cortex vs. Medulla) directly into the input, we provide a hard spatial prior that guides the model to prioritize the renal cortex, where glomeruli are biologically located.

### Data: Context-Fused Representative Sampling
The data pipeline synthesizes the successful sampling strategies from previous lessons with the new anatomical integration.

*   **Preprocessing:** The anatomical structure JSONs will be rasterized into binary masks and concatenated with the source TIFFs to create 4-channel tiles (1024x1024).
*   **Representative Undersampling:** We will employ **Representative Undersampling**, retaining 100% of tiles containing glomeruli and randomly sampling exactly **20% of the background-only tiles**. This ratio was proven in **Cite solution_lesson_node_00006** to outperform strict 1:1 balancing by providing sufficient "negative context" to learn hard negatives without overwhelming the training epoch with empty data.
*   **Augmentation:** We will apply aggressive **Color Augmentation** (Hue, Saturation, Brightness, Contrast) alongside geometric transforms. **Cite solution_lesson_node_00005** showed that color augmentation is critical for generalizing across the staining variations found in the validation set.

### Training: Stabilized Hybrid Optimization with Warmup
The training protocol addresses the instability and premature convergence observed in small-data regimes.

*   **Loss Function:** We will use a **Hybrid BCEDiceLoss** (Sum of Binary Cross Entropy and Dice Loss). As shown in **Cite solution_lesson_node_00005**, this combination stabilizes gradients (via BCE) while optimizing the segmentation metric (via Dice), preventing the vanishing gradients associated with pure Dice loss on sparse targets.
*   **Optimizer:** AdamW optimizer with Cosine Annealing scheduler.
*   **Warmup Strategy:** We will implement a **Training Warmup** by disabling Early Stopping for the first **15 epochs**. **Cite solution_lesson_node_00009** revealed that validation metrics on small datasets are highly volatile; a warmup ensures the model does not terminate prematurely due to transient "lucky" spikes in validation scores before robust features are learned.

### Evaluation: Anatomy-Masked Inference
*   **Inference:** Test images will be processed using the 4-channel sliding window approach with Gaussian kernel smoothing to merge overlapping predictions **Cite solution_lesson_node_00004**.
*   **Post-Processing:** We will apply an **Anatomical Post-Filter**. The predicted probability map will be multiplied by the anatomical cortex mask. This enforces a biological constraint, guaranteeing that no false positives are predicted in the Medulla or non-tissue regions, which effectively removes a class of errors the model might otherwise make.
