To establish a highly efficient baseline that balances speed and accuracy while remaining distinct from the previously suggested architectures, I propose the following approach:

### Model: Feature Pyramid Network (FPN) with ResNet-18
The architecture utilizes a **Feature Pyramid Network (FPN)** equipped with a lightweight **ResNet-18** encoder.
*   **Design:** Unlike the U-Net (Model 1), which relies on symmetric skip connections and concatenation, the FPN employs a top-down pathway with lateral connections. High-level semantic features from the encoder are upsampled and added (element-wise) to high-resolution features from earlier layers.
*   **Efficiency:** The ResNet-18 backbone provides a rapid, low-parameter feature extractor. The FPN decoder is computationally lighter than a standard U-Net decoder because it predicts masks from a coalesced feature map rather than maintaining a heavy, deep decoder path. This structure is particularly effective for detecting objects at varying scales and retaining the fine spatial details necessary for small structures like glomeruli.

### Data
*   **Tiling:** Given the massive resolution of the source TIFF images (e.g., >30,000 pixels wide), the images will be divided into fixed-size tiles of **1024x1024 pixels**.
*   **Balanced Sampling:** The EDA revealed a significant class imbalance (approx. 1.8% foreground). To prevent the model from overfitting to the background, the training dataset will be constructed by retaining **all** tiles containing glomerulus masks and randomly sampling only **20%** of the purely background tiles.
*   **Preprocessing:** Pixel values will be normalized to the range [0, 1] using min-max scaling based on dataset statistics.
*   **Augmentation:** Simple, low-cost augmentations such as random 90-degree rotations and horizontal/vertical flips will be applied during training to improve generalization without increasing preprocessing overhead.

### Training
*   **Loss Function:** A **Soft Dice Loss** will be used as the primary objective. This loss function is differentiable and directly optimizes the evaluation metric (Dice coefficient), making it robust against the heavy foreground-background imbalance inherent in the tissue slides.
*   **Optimizer:** The **AdamW** optimizer will be employed with a standard learning rate (e.g., 1e-4) and weight decay to ensure stable convergence.
*   **Scheduler:** A Cosine Annealing learning rate scheduler will be used to gradually reduce the learning rate, helping the model settle into a robust local minimum.
*   **Compute Strategy:** Mixed-precision training (FP16) will be enabled to maximize throughput on the NVIDIA A100 GPU and reduce memory usage.

### Evaluation
*   **Tiled Inference:** During inference, the large test images will be processed using a sliding window approach with a tile size of 1024x1024 and a **50% overlap**.
*   **Reconstruction:** Predictions from overlapping regions will be averaged (or weighted via a Gaussian kernel) to eliminate edge artifacts caused by tiling.
*   **Thresholding:** The final probability map will be thresholded at 0.5 to generate the binary mask.
*   **Encoding:** The resulting binary mask will be converted to Run-Length Encoding (RLE) as required for the submission format.
