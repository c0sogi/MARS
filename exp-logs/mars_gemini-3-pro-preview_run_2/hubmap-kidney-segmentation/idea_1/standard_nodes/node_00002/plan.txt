The error `IndexError: band index 2 out of range` occurs because the code assumes all input TIFF images have at least 3 channels (RGB) and attempts to read bands `[1, 2, 3]`. However, the dataset contains single-channel (grayscale) images. To fix this, I will modify `library/dataset.py` and `library/inference.py` to check the number of channels (`src.count`) before reading. If the image has fewer than 3 channels, the code will read the first band and replicate it to create a 3-channel input, ensuring compatibility with the ResNet encoder.
