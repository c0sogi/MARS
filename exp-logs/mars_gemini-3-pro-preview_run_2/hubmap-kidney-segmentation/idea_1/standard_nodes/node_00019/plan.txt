Based on the provided lessons and task requirements, I will implement the following optimizations:

1.  **Backbone Replacement (ResNet34)**: I will replace the `FPNResNeXt50` model with `FPNResNet34`. The heavier ResNeXt model degraded performance on this small dataset (Lesson 00008). ResNet34 provides a better balance of capacity and generalization.
2.  **Training Schedule Optimization**: I will increase `NUM_EPOCHS` to 20 in `Config` and ensure the training loop uses this value. This allows the Cosine Annealing scheduler to decay the learning rate more effectively, stabilizing convergence (Lesson 00016).
3.  **Robust Early Stopping & Checkpointing**: I will modify the `Trainer` to include a `warmup_epochs` parameter. During this warmup phase, early stopping counters will not increment, and "best model" checkpoints will not be saved. This prevents the model from locking in weights from transient "lucky" spikes in validation metrics early in training (Lesson 00009, Lesson 00017).

    Feature Pyramid Network (FPN) with ResNeXt-50 (32x4d) Encoder for FTU Detection.
    Cite {solution_lesson_node_00005}

    Architecture:
    - Backbone: ResNeXt-50 32x4d (pretrained on ImageNet)
    - Neck: FPN with lateral connections and top-down pathway
    - Head: Segmentation head that coalesces multi-scale features and upsamples to full resolution
    """

    def __init__(self, num_classes=Config.CLASSES, fpn_channels=128):
        """
        Args:
            num_classes (int): Number of output classes (1 for binary segmentation).
            fpn_channels (int): Number of channels in the FPN layers.
        """

        # Using the modern weights API

        self.bn1 = backbone.bn1

        self.layer3 = backbone.layer3  # C4: 1024 channels, stride 16
        self.layer4 = backbone.layer4  # C5: 2048 channels, stride 32
