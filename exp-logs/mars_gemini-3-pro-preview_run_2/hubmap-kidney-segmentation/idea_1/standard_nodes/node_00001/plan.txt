The following implementation orchestrates the FTU detection pipeline. It begins by setting up the environment and seeding for reproducibility. It then loads the metadata and initializes the datasets, utilizing the provided `HuBMAPDataset` class with caching enabled to speed up data loading. The model (`FPNResNet18`) is initialized and trained using the `Trainer` class for a reduced number of epochs (5) to satisfy the fast baseline requirement while still allowing for convergence.

After training, the script performs a comprehensive validation on the hold-out set. Instead of relying solely on tile-based metrics, it uses the `InferenceRunner` to predict full-resolution masks for the validation images, ensuring the metric reflects the actual task performance. It calculates the Dice coefficient for each validation image and prints the mean as the "Final Validation Metric".

Subsequently, a failure analysis is conducted by correlating the error magnitude (1 - Dice score) with available numerical metadata features (e.g., age, BMI, cortex percentage) to identify potential sources of bias or failure. Finally, the script generates predictions for the test set using the trained model and saves the submission file in the required format.
