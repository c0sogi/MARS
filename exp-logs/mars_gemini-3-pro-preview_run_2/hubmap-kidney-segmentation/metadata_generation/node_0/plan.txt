The following script generates the required metadata for the HuBMAP dataset.

### Implementation Strategy
1.  **Setup and Loading**: The script initializes the output directory (`metadata/`) and reads the provided CSV files (`train.csv`, `HuBMAP-20-dataset_information.csv`) and scans the `input/test/` directory for test images.
2.  **Data Merging**: It merges the training labels from `train.csv` with the rich metadata in `dataset_information.csv` using the image ID as the key. It constructs relative file paths for images, glomerulus segmentation JSONs, and anatomical structure JSONs.
3.  **Train/Validation Split**: Since the dataset contains multiple images per patient, a `GroupShuffleSplit` (80/20 split) is performed based on `patient_number` to ensure no patient's data leaks between training and validation sets.
4.  **Test Metadata**: It compiles the test set metadata by identifying files in the test directory and merging with `dataset_information.csv` where available.
5.  **Saving**: The resulting DataFrames are saved as CSV files in the `metadata/` directory.
6.  **Verification**: The script performs rigorous checks:
    *   Verifies that the file paths in the metadata actually exist in the `input/` directory.
    *   Ensures the train/validation split respects the patient grouping (no patient ID overlap).
    *   Prints summary statistics for all splits.
