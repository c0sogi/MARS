The following script demonstrates the end-to-end usage of the provided HuBMAP kidney segmentation pipeline.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class to enable `DEBUG` mode, reduce the `BATCH_SIZE`, set `EPOCHS` to 1, and change the `WORKING_DIR`. This ensures the script runs quickly on a small subset of data without modifying the source files.
2.  **Component Verification**: We perform unit tests on core components:
    *   **Utils**: Verify Run-Length Encoding (RLE) and Dice Coefficient calculation.
    *   **Model**: Validate the `MultiTaskResNetFPN` architecture by passing a dummy tensor and asserting output shapes.
    *   **Loss**: Verify the `MultiTaskLoss` computation and backward pass.
3.  **Training Pipeline**: We instantiate the `Trainer` class and execute the `fit()` method. This demonstrates data loading, tile generation, and the training loop using the debug subset.
4.  **Inference Pipeline**: We instantiate the `InferenceRunner` class and execute `run()`. This demonstrates sliding window inference, mask reconstruction, and submission file generation.
5.  **Output Verification**: We assert that the model weights and submission file are correctly generated in the specified working directory.
