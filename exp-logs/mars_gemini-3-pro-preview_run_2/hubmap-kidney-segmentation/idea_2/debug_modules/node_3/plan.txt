The issue is that the code assumes all input images are 3-channel (RGB), but the dataset contains single-channel (grayscale) images. When a single-channel image is loaded, it results in a shape of `(H, W, 1)`. After stacking the anatomical mask, the resulting tensor has 2 channels. The downstream normalization code explicitly expects 3 RGB channels (`image[:, :, :3]`) and attempts to subtract a 3-element mean vector, causing a broadcasting error because the last dimension is 2 instead of 3.

To fix this, I will modify the data loading logic in both `process_and_cache_data` and `TestDataset._prepare_tiles` to check the channel count of the loaded image. If the image has 1 channel, I will replicate it to 3 channels to simulate RGB. This ensures the data structure matches the downstream assumption of 3 RGB channels (Cite debug_lesson_1).
