The following implementation demonstrates the usage of the provided library files for the HuBMAP FTU detection task.

### Strategy
1.  **Configuration Override**: We dynamically modify the `Config` class to set up a lightweight run. This includes reducing the number of epochs to 1, increasing the sliding window stride (to generate fewer tiles from the large TIFF images), and redirecting outputs to a temporary working directory.
2.  **Data Subsetting**: We create subset metadata files containing only a single image for training, validation, and testing to ensure the pipeline executes quickly.
3.  **Component Verification**:
    *   **Model**: We instantiate the `AnatomyAwareUNetPlusPlus` model and perform a forward pass with dummy data to verify the input adaptation (4 channels) and output shape.
    *   **Loss**: We verify the `HybridBCEDiceLoss` and `DiceScore` with synthetic logits and targets.
4.  **Pipeline Execution**:
    *   **Training**: We initialize the `Trainer` and run `fit()`. This demonstrates the data loading, caching, and training loop.
    *   **Inference**: We initialize the `InferenceRunner` and run `predict_and_submit()`. This demonstrates the sliding-window inference and RLE submission generation.
5.  **Validation**: Assertions are used throughout to confirm that files are created and shapes are correct.
