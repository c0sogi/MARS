Based on the comprehensive analysis of the "Lessons" and "Previous Ideas," I propose the **Instance-Aware Multi-Task Faster R-CNN**. This solution introduces a structural innovation—**Multi-Instance Learning (MIL)**—to resolve the conflict between global diagnosis and local detection, while rigorously adhering to the stability constraints identified in the failure analyses.

### 1. Model
**Architecture:** Faster R-CNN with **ResNet-101-FPN** and a **Parallel Multi-Instance Learning (MIL) Head**.
*   **Backbone:** We utilize **ResNet-101-FPN**. This provides the optimal balance of depth and trainability, avoiding the "Capacity-Budget Mismatch" and optimization instability observed with the heavier ResNeXt architecture (Cite solution_lesson_node_00022, solution_lesson_node_00024).
*   **Structural Innovation (MIL Head):** Instead of applying Global Average Pooling (Idea 2) or Spatial Attention (Idea 4) to the shared feature maps—which was proven to degrade small object localization by forcing spatial invariance (Cite solution_lesson_node_00026, solution_lesson_node_00027)—we introduce a **Multi-Instance Learning Head**.
    *   *Mechanism:* This head operates *after* the Region Proposal Network (RPN). It takes the pooled feature vectors of the top $K$ (e.g., 64) proposals, passes them through a lightweight Self-Attention mechanism to weight their importance, and aggregates them to predict the study-level label.
    *   *Rationale:* This explicitly models the diagnosis as a function of the *set* of findings (addressing the density bottleneck, Cite solution_lesson_node_00004) without biasing the backbone's spatial maps against small objects.
*   **Detection Head:** We configure the RPN with **High Capacity Settings** (3000 post-NMS proposals, 200 detections). This is necessary to capture dense opacities (Cite solution_lesson_node_00005), but we pair it with an extended training schedule to ensure convergence (Cite solution_lesson_node_00028).

### 2. Data
**Preprocessing:**
*   **Contrast Enhancement:** Apply **CLAHE** (Clip Limit 4.0) to all images. This is critical for enhancing the visibility of subtle, diffuse opacities in monochromatic X-rays (Cite solution_lesson_node_00005).
*   **Resolution:** Fix input resolution at **800x800**. This avoids the optimization instability and batch size constraints associated with 1024x1024, ensuring robust convergence (Cite solution_lesson_node_00017, solution_lesson_node_00022).
*   **Label Engineering:**
    *   **Training:** Assign granular class IDs (Typical, Indeterminate, Atypical) to bounding boxes. This provides rich semantic supervision to the backbone (Cite solution_lesson_node_00020).
    *   **Study Level:** Use study labels to supervise the MIL Head.

### 3. Training
**Strategy:**
*   **Loss Function:** $L_{total} = L_{RPN} + L_{ROI} + 0.5 \times L_{MIL}$. We set the auxiliary weight to **0.5**. This prevents the global classification task from dominating the gradients and hindering the primary localization objective (Cite solution_lesson_node_00013).
*   **Optimization Stability:**
    *   **Gradient Clipping:** Apply gradient clipping (norm 10.0) to prevent the explosion observed when training complex heads (Cite solution_lesson_node_00024).
    *   **Schedule:** Train for **12 Epochs** on the **Full Dataset** (Cite solution_lesson_node_00012). Crucially, decay the learning rate only after **60% of epochs** (Epoch 8). This avoids the premature convergence observed when decaying early on complex data (Cite solution_lesson_node_00014, solution_lesson_node_00017).
*   **Checkpointing:** Save the model based on **Minimum Validation Loss**. This is a more efficient and sufficiently accurate proxy for performance than mAP for this architecture (Cite solution_lesson_node_00006, solution_lesson_node_00007).

### 4. Evaluation
**Inference Pipeline:**
*   **Class Collapsing:** During inference, map all predicted granular bounding box classes (Typical, Indeterminate, Atypical) to the single generic class **"opacity"**. This aligns with the competition metric and prevents penalizing the model for subtype confusion when localization is correct (Cite solution_lesson_node_00020).
*   **Study Prediction Ensemble:** The final study label is determined by a weighted ensemble of the **MIL Head's prediction** and the **maximum confidence score** of the detected boxes.
*   **Consistency:** If the predicted study label is "Negative", explicitly override the detection output to "none 1 0 0 1 1" to eliminate false positives.
