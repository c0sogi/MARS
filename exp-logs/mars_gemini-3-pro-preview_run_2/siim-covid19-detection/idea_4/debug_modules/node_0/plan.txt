This script demonstrates the end-to-end pipeline for the COVID-19 radiograph detection task using the provided library files.

### Strategy Outline
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to enable `DEBUG` mode, reduce the batch size, and limit the number of epochs. This ensures the script runs quickly on a tiny subset of the data (10 samples).
2.  **Reproducibility**: We call `setup_reproducibility` to fix random seeds.
3.  **Data Loading**: We instantiate the training, validation, and test datasets using `get_datasets` and `get_test_dataset`. We verify the data structure (tensors, keys) using assertions.
4.  **Model Initialization**: We load the `MultiTaskFasterRCNN` model using `get_model` and verify a forward pass on a dummy batch to ensure the architecture and loss computation are functioning correctly.
5.  **Training**: We execute a single epoch of training using `train_one_epoch` on the small subset.
6.  **Evaluation**: We run the `evaluate` function on the validation set to check loss calculation and study accuracy logic.
7.  **Inference**: We generate predictions for the test set using `generate_submission` and verify that the output CSV file is created with the correct format.
