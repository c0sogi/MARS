To solve the task of COVID-19 radiograph categorization and opacity detection, I propose a **Multi-Task ResNeXt-FPN with Multi-Scale Attention**. This solution evolves the previous "Multi-Task Faster R-CNN" (Idea 2) by upgrading the feature extraction backbone to handle complex feature cardinality and replacing the simple global pooling head with a structural innovation—a Multi-Scale Attention Module—to better capture diffuse radiographic patterns.

### 1. Model
**Architecture:** Multi-Task Faster R-CNN with **ResNeXt-101-32x8d-FPN**.
*   **Backbone Innovation:** I will replace the ResNet-101 backbone with **ResNeXt-101-32x8d**. The "split-transform-merge" strategy of ResNeXt provides higher cardinality, which is more effective than depth alone for capturing the diverse and subtle textural variations of "Atypical" and "Indeterminate" COVID-19 findings (Cite solution_lesson_node_00012).
*   **Auxiliary Head Innovation (Multi-Scale Attention):** Instead of a simple Global Average Pooling (GAP) layer on the final feature map (which risks losing fine-grained details), I will introduce a **Multi-Scale Attention Head**.
    *   This head will take feature maps from multiple FPN levels (e.g., P3, P4, P5).
    *   A lightweight spatial attention mechanism (1x1 convolution followed by a sigmoid activation) will be applied to each level to highlight relevant regions (opacities) before pooling.
    *   These multi-scale features will be concatenated to predict the 4 study-level classes. This ensures the global diagnosis is informed by both large, obvious consolidations and smaller, subtle infiltrations (Cite solution_lesson_node_00008).
*   **Detection Head Configuration:** The Faster R-CNN head will be configured with high-capacity settings: **3000 post-NMS proposals** and **200 max detections per image**. This directly addresses the bottleneck identified where standard limits suppressed valid objects in dense scenes (Cite solution_lesson_node_00005).

### 2. Data
**Preprocessing:**
*   **Contrast Enhancement:** Apply **CLAHE** (Contrast Limited Adaptive Histogram Equalization) to all input images. This is critical for enhancing the visibility of subtle opacities in monochromatic X-rays (Cite solution_lesson_node_00005).
*   **Label Engineering:**
    *   **Training:** Assign specific class IDs (Typical, Indeterminate, Atypical) to bounding boxes based on the study label. This granular supervision helps the backbone learn richer semantic features (Cite solution_lesson_node_00020).
    *   **Input Resolution:** Resize images to 1024x1024 to balance detail retention with memory constraints.

### 3. Training
**Strategy:**
*   **Loss Function:** $L_{total} = L_{RPN} + L_{ROI} + \lambda L_{Global}$. I will set $\lambda = 0.5$. A lower weight for the auxiliary task prevents the easier global classification objective from dominating the gradients, ensuring the model focuses sufficiently on the harder localization task (Cite solution_lesson_node_00013).
*   **Optimizer & Scheduler:** Use SGD with Momentum. Crucially, the Learning Rate decay will be scheduled to occur **after 50-60% of the total epochs** (e.g., decay at epoch 7 of 12). This prevents premature convergence to suboptimal minima, which was observed when decaying too early on complex data (Cite solution_lesson_node_00014, solution_lesson_node_00017).
*   **Checkpointing:** Save the model checkpoint that achieves the **minimum Validation Loss**, rather than calculating mAP at every epoch. Loss is a smoother, more efficient, and sufficiently correlated proxy for performance in this architecture (Cite solution_lesson_node_00006, solution_lesson_node_00007).

### 4. Evaluation
**Inference Pipeline:**
*   **Study-Level Prediction:** The final study label will be a weighted ensemble of the **Multi-Scale Attention Head's prediction** and the **maximum confidence score** of the detected boxes. This hybrid approach ensures that if the detector finds a high-confidence "Typical" box, the study is labeled "Typical" even if the global head is uncertain.
*   **Image-Level Prediction:**
    *   **Class Collapsing:** While the model predicts granular classes (Typical, Indeterminate, Atypical), these will be mapped to the single generic class **"opacity"** for the submission string. This avoids penalizing the metric for subtype confusion when the localization is correct (Cite solution_lesson_node_00020).
    *   **Consistency Check:** If the predicted study label is "Negative for Pneumonia", explicitly override the detection head and predict "none 1 0 0 1 1" to eliminate false positives.
