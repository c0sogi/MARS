To optimize the solution for the SIIM-FISABIO-RSNA COVID-19 Detection task, I will implement the strategies outlined in **Lesson 12 (Synergy of Data Scale and Auxiliary Supervision)**.

The following changes will be made:

1.  **Adjust Hyperparameters in `library/config.py`**:
    *   **Increase Auxiliary Loss Weight**: Set `LAMBDA_GLOBAL_CLS` to `1.0`. The lesson indicates that increasing the influence of the global classification head acts as a strong regularizer when scaling up to the full dataset, decoupling performance from local object density (Cite solution_lesson_node_00012).
    *   **Refine RPN Proposals**: Decrease `RPN_POST_NMS_TOP_N_TRAIN` from `3000` to `2000`. This forces the network to focus on fewer, high-quality proposals during training, which was found to improve performance in the production-grade regime (Cite solution_lesson_node_00012).
    *   **Increase Workers**: Increase `NUM_WORKERS` to 8 to utilize the available 12 vCPUs more effectively.

2.  **Update Training Configuration in `runfile.py`**:
    *   **Scale to Full Dataset**: Modify `configure_fast_baseline` to remove the sampling limits (`MAX_TRAIN_SAMPLES = None`), ensuring the model trains on the full dataset as recommended for production-grade performance.
    *   **Increase Epochs**: Increase `NUM_EPOCHS` from `3` to `6`. While the previous run converged quickly, the full dataset with stronger regularization may require slightly more training time to reach the target mAP of >0.36. This fits comfortably within the 4-hour limit (estimated ~45-60 mins).
    *   **Update Submission Threshold**: Set the submission threshold to `0.3670952330496907` as requested.
