Here is the implementation of the `runfile.py` script.

This script orchestrates the entire pipeline:
1.  **Setup**: Initializes seeds and configuration.
2.  **Data Loading**: Loads training and validation subsets (limited size for fast baseline) and the full test set.
3.  **Training**: Trains the Class-Aware Faster R-CNN model for a few epochs.
4.  **Validation**:
    *   Calculates the **mAP @ IoU > 0.5** metric on the validation set.
    *   Performs **Failure Analysis** by correlating per-image loss with input features (number of boxes, box area).
5.  **Inference**: Generates predictions for the test set and saves `submission.csv`.
