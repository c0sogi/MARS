Based on the task requirements and the available resources (specifically the installed packages which exclude `ultralytics`), I propose the following baseline approach. This approach synthesizes the "Unified" philosophy of Model 1 with the stability of standard `torchvision` components, creating a distinct and highly efficient solution.

# Baseline Proposal: Class-Aware Faster R-CNN

This approach reframes the multi-task problem (study classification + object detection) into a single **Class-Specific Object Detection** task. Instead of treating all findings as a generic "opacity" and requiring a separate classifier for the study label, we train the detector to recognize the specific *types* of opacities (Typical, Indeterminate, Atypical). This allows a single model to output both image-level bounding boxes and study-level diagnoses in one pass.

### Model
**Architecture:** Faster R-CNN with a ResNet-50-FPN backbone.
*   **Foundation:** We utilize the standard `fasterrcnn_resnet50_fpn` available in `torchvision`. This adheres to the "Unified" concept (Model 1) but replaces the YOLO architecture with a standard Two-Stage detector that is natively supported in the installed environment.
*   **Modification:** The standard box predictor head (usually 2 classes: Background, Object) will be replaced with a 4-class predictor: **Background, Typical, Indeterminate, Atypical**.
*   **Philosophy:** By embedding the study label into the bounding box class, we eliminate the need for a separate study classifier or complex architectural heads. The presence of a "Typical" box implies a "Typical" study.

### Data
**Preprocessing Steps:**
1.  **Label Injection:** Merge `train_study_level.csv` with `train_image_level.csv`.
    *   For every bounding box in the training set, assign it a specific class ID based on its parent study's label:
        *   Study "Typical Appearance" $\rightarrow$ Box Class: `Typical` (ID 1)
        *   Study "Indeterminate Appearance" $\rightarrow$ Box Class: `Indeterminate` (ID 2)
        *   Study "Atypical Appearance" $\rightarrow$ Box Class: `Atypical` (ID 3)
    *   Studies labeled "Negative for Pneumonia" contain no boxes. These are treated as empty samples (background only).
2.  **Formatting:** Convert DICOM images to normalized tensors. Resize images to a standard size (e.g., 1024x1024) to balance speed and small-object detection.
3.  **Split:** Use the provided stratified group split (from `metadata/train.csv` and `val.csv`) to ensure no patient leakage.

### Training
**Procedure:**
*   **Optimizer:** SGD with Momentum (0.9) and Weight Decay (0.0005).
*   **Loss Function:** Standard Faster R-CNN multi-task loss (RPN classification/regression + ROI classification/regression).
*   **Strategy:**
    *   Initialize with ImageNet-pretrained weights.
    *   Train on both positive images (with boxes) and negative images (empty). This allows the model to learn to suppress false positives, effectively learning the "Negative" class implicitly.
    *   Use a moderate learning rate (e.g., 0.005) with a cosine annealing scheduler.

### Evaluation
**Inference Logic:**
1.  **Generate Detections:** Run the image through the model to get a list of bounding boxes, scores, and class labels (Typical, Indeterminate, Atypical). Apply a confidence threshold (e.g., 0.35).
2.  **Study-Level Prediction:**
    *   If **no boxes** remain after thresholding: Predict `negative 1 0 0 1 1`.
    *   If **boxes exist**: Identify the detection with the highest confidence score. Use its class (e.g., "Typical") as the study label. Format: `typical {score} 0 0 1 1`.
3.  **Image-Level Prediction:**
    *   If **no boxes** remain: Predict `none 1 0 0 1 1`.
    *   If **boxes exist**: Take all valid detections. Ignore their specific class (Typical/Indeterminate) and map them all to the generic class `opacity`. Format: `opacity {score} {xmin} {ymin} {xmax} {ymax} ...`.

This pipeline is extremely lightweight (one model, one inference pass) and robust, making it an ideal baseline.
