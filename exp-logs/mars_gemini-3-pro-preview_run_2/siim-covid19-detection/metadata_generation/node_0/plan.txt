I will implement a Python script to generate the required metadata for the COVID-19 radiograph classification task.

### Implementation Strategy

1.  **File Indexing**:
    -   I will traverse the `./input/train` and `./input/test` directories to build a mapping of Image IDs to their relative file paths. This ensures that the metadata contains valid paths for every image.

2.  **Data Loading & Processing**:
    -   I will load the provided `train_study_level.csv` and `train_image_level.csv`.
    -   I will clean the IDs (removing `_study` and `_image` suffixes) to allow merging.
    -   I will merge the study-level labels into the image-level data using `StudyInstanceUID` as the key. This results in a unified dataset containing both image paths, bounding boxes, and study classification labels.

3.  **Stratified Group Split**:
    -   To create a validation set, I will perform a split at the **Study level**, not the Image level. This is crucial to prevent data leakage, as images from the same study (patient) must remain in the same split.
    -   I will derive a single stratification label for each study from the four one-hot encoded columns (`Negative`, `Typical`, `Indeterminate`, `Atypical`).
    -   I will use `train_test_split` with stratification on these unique study labels to create an 80:20 Train/Validation split.

4.  **Metadata Generation**:
    -   I will generate `train.csv` and `val.csv` by filtering the merged dataset based on the split study IDs.
    -   I will generate `test.csv` by scanning the test directory structure (`test/study/series/image.dcm`) and creating a dataframe of image IDs and paths.

5.  **Verification**:
    -   I will calculate and print summary statistics (counts, class distributions).
    -   I will verify the integrity of the file paths by checking a random sample of 1000 paths from each generated file.
    -   I will programmatically assert that there is no overlap of Study IDs between Train and Validation sets and that the split ratio is approximately 20%.
