The following implementation orchestrates the EEG harmful brain activity classification pipeline. It leverages the provided library modules to load data, train a Spectrogram-EfficientNet model, and generate predictions.

**Implementation Strategy:**
1.  **Setup & Reproducibility**: Sets random seeds and configures the computing device (GPU).
2.  **Data Loading & Subsampling**: Loads the metadata. To satisfy the "fast baseline" requirement within the time limit, the training set is subsampled to 10,000 stratified samples. The validation and test sets are kept intact to ensure accurate metrics and submission.
3.  **Transforms**: Applies ImageNet normalization using `albumentations` to align the generated spectrograms (0-1 range) with the pre-trained EfficientNet backbone expectations.
4.  **Model Training**: Instantiates the `SpecEfficientNet` and trains it using the `Trainer` class. Uses `AdamW` optimizer and `OneCycleLR` scheduler for efficient convergence.
5.  **Validation & Metric**: Computes the final Kullback-Leibler Divergence on the hold-out validation set and prints it in the required format.
6.  **Failure Analysis**: Calculates the error (KL divergence) for each validation sample and correlates it with metadata features (e.g., `total_votes`, signal offset) to identify potential weaknesses.
7.  **Inference**: Generates predictions for the test set and saves the correctly formatted `submission.csv`.
