Based on the provided lessons and task description, here is the proposed optimized strategy. This solution introduces a **Dual-Stream Architecture** to fuse the high-resolution temporal details of the raw EEG with the long-term contextual information from the pre-computed spectrograms, addressing the "context gap" in the previous single-stream approach.

# Model
**Architecture:** Dual-Stream EfficientNet-B1 Fusion Network
To capture both the fine-grained morphology of brain activity (e.g., spikes) and the longer-term periodic trends (e.g., evolution of discharges), the model will utilize two parallel encoders:
1.  **High-Resolution Short-Term Encoder:** An **EfficientNet-B1** backbone (Cite solution_lesson_node_00006) that processes the 50-second generated Mel-Spectrograms. This stream focuses on the detailed "Double Banana" montage features validated in previous experiments (Cite solution_lesson_node_00002).
2.  **Contextual Long-Term Encoder:** A second **EfficientNet-B1** backbone that processes the 10-minute pre-computed Kaggle spectrograms. This stream provides the broader temporal context that expert annotators used during labeling, which was missing in the previous EEG-only approach.
3.  **Fusion Head:** The global average pooling outputs from both backbones will be concatenated into a single feature vector. This vector will pass through a Dropout layer (p=0.5) and a fully connected layer to predict the 6 class probabilities.

# Data
**Preprocessing:**
1.  **Stream 1 (EEG):** Load the 50-second raw EEG data. Apply the **Longitudinal Bipolar Montage** (16 channels) to enhance focal differences. Convert these signals into **Log-Mel Spectrograms** using STFT (Cite solution_lesson_node_00002).
2.  **Stream 2 (Kaggle Spectrograms):** Load the corresponding 10-minute spectrogram parquet files. Apply a log transformation to compress the dynamic range and resize the 4 regional sub-plots (LL, RL, LP, RP) to a standardized resolution compatible with the encoder (e.g., 512x512).
3.  **Hybrid Caching:** To manage I/O overhead, Stream 1 features will be generated **on-the-fly** during training (to save disk space) but **cached to disk** for the validation set (to speed up evaluation) (Cite solution_lesson_node_00008).

**Augmentation:**
1.  **MixUp:** Apply MixUp regularization (`alpha=0.4`) to the fused inputs (or independently to streams and targets) during training. This is critical to prevent overfitting on soft-label data (Cite solution_lesson_node_00004) and must be explicitly enabled in the configuration (Cite solution_lesson_node_00003).
2.  **Masking:** Apply **CoarseDropout** to the spectrograms in both streams. Crucially, the mask dimensions will be kept moderate (e.g., max 32x32 pixels) rather than large (64x64) to avoid occluding entire transient events like seizure spikes (Cite solution_lesson_node_00007).

# Training
1.  **Loss Function:** **Kullback-Leibler (KL) Divergence**, as it directly optimizes the competition metric for the soft probability targets.
2.  **Optimizer:** **AdamW** with a Cosine Annealing learning rate scheduler to ensure convergence.
3.  **Regularization:** In addition to MixUp and CoarseDropout, the EfficientNet backbones will utilize **DropPath** (Stochastic Depth) to further regularize the increased capacity of the dual-stream model (Cite solution_lesson_node_00006).

# Evaluation
1.  **Inference:** For each test sample, load both the 50-second EEG and the 10-minute spectrogram. Process them through their respective pipelines (Montage/STFT for EEG, Log/Resize for Spec).
2.  **Prediction:** Pass the pair through the trained Dual-Stream network to obtain the final probability distribution. The submission will be the direct softmax output of this fused model.
