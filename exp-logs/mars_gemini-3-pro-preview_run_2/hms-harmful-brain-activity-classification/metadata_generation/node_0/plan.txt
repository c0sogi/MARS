My implementation strategy is as follows:

1.  **Setup & Loading**: Initialize paths and load the raw `train.csv` and `test.csv` metadata from the `./input` directory.
2.  **Feature Engineering**:
    *   Construct relative file paths for EEG and Spectrogram files (e.g., `train_eegs/{id}.parquet`) for both train and test sets.
    *   Calculate probability distributions for the target labels by normalizing the annotator vote counts in the training data (dividing each class vote by the total votes).
3.  **Data Splitting**:
    *   Use `GroupShuffleSplit` with `patient_id` as the group key to create an 80:20 train-validation split. This ensures that data from the same patient does not appear in both sets, preventing data leakage.
4.  **Saving**: Save the processed `train.csv`, `val.csv`, and `test.csv` to the `./metadata` directory.
5.  **Validation & Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (sample counts, unique patients, label distributions).
    *   Perform a file existence check on a random sample of 1000 paths relative to `./input`. Raise an error if the missing ratio exceeds 50%.
    *   Verify the group split by asserting that the intersection of patient IDs in the training and validation sets is empty.
