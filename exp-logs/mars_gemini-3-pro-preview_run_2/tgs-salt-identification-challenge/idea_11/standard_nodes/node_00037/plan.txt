### Implementation Strategy

1.  **Setup & Imports**: Import necessary libraries (`torch`, `numpy`, `os`, `random`) and the provided modules from the `library` package (`SaltTrainer`, `calculate_iou_batch`, `_calculate_metric_from_iou`).
2.  **Reproducibility**: Define a `set_seed` function to ensure deterministic behavior across runs.
3.  **Fast Training Baseline**:
    *   Initialize the `SaltTrainer` with a reduced number of epochs (20) to satisfy the "fast baseline" requirement while ensuring sufficient convergence on the A100 GPU.
    *   Execute `trainer.train()` to train the model and obtain the optimal binarization threshold.
4.  **Validation & Metric Calculation**:
    *   Load the best model checkpoint saved during training.
    *   Iterate through the validation set (`trainer.val_loader`) in evaluation mode.
    *   Collect predictions, ground truth masks, and depth features.
    *   Crop predictions to the original 101x101 size (removing padding).
    *   Calculate the exact IoU scores per image using the optimal threshold.
    *   Compute the final mAP metric using `_calculate_metric_from_iou` and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Define "error magnitude" as `1.0 - IoU`.
    *   Calculate the Pearson correlation coefficient between the error magnitude and the depth feature.
    *   Print this correlation to identify if depth is associated with poor performance.
6.  **Submission Generation**:
    *   Check if the final validation metric exceeds the threshold of 0.7985.
    *   If successful, trigger `trainer.predict_test(best_threshold)` to generate the `submission.csv` file.
