Based on the accumulated lessons, I propose the following **FiLM-Conditioned ResNet34-WideLinkNet** strategy.

This solution introduces a structural innovation: **Feature-wise Linear Modulation (FiLM)** at the bottleneck. This replaces the simple concatenation used in previous ideas with a dynamic affine transformation, allowing the depth signal to explicitly scale and shift feature distributions. This is combined with **Bernoulli Depth Masking**, a robust training strategy that resolves the conflict between the value of depth conditioning (Cite solution_lesson_node_00001) and its absence in the test set (Cite solution_lesson_node_00020).

### Model: FiLM-Conditioned ResNet34-WideLinkNet

I propose a U-shape architecture that integrates global context via dynamic feature modulation rather than static concatenation.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed (Cite solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** (by summing the original RGB weights) rather than repeating the input data. This improves efficiency and parameter alignment (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Innovation - FiLM):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map $F$ is passed from the encoder (Cite solution_lesson_node_00019).
    *   **FiLM Layer:** Instead of concatenating depth, I employ a **Feature-wise Linear Modulation** block. The scalar depth $z$ is projected through a **Non-Linear MLP** (Linear $\rightarrow$ ReLU $\rightarrow$ Linear) (Cite solution_lesson_node_00029) to generate two vectors of size 512: scale $\gamma(z)$ and shift $\beta(z)$.
    *   **Modulation:** The feature map is transformed as $F' = \gamma(z) \cdot F + \beta(z)$. This allows the depth signal to selectively suppress or emphasize specific feature channels based on geological context, acting as a dynamic style modulator (Cite solution_lesson_node_00001).
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** for efficiency (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` (e.g., 128 for the first block) rather than `out_channels // 4`. This prevents the aggressive information loss observed in standard implementations (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding. This ensures dimensions are multiples of the network's stride (32), preventing spatial aliasing during upsampling (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std). Even with the 1-channel modification, scaling to the pretrained distribution is critical (Cite solution_lesson_node_00025).
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the training depth values (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate organic salt plasticity (Cite solution_lesson_node_00003, solution_lesson_node_00004).
    *   **Rigid:** Apply **ShiftScaleRotate** to ensure geometric invariance (Cite solution_lesson_node_00010).
    *   **Regularization:** Apply these augmentations with a moderate probability ($p=0.2$) (Cite solution_lesson_node_00007).

### Training

*   **Strategy: Bernoulli Depth Masking:** To handle the missing test depths (Cite solution_lesson_node_00020), apply a stochastic mask to the depth input during training. With probability $p=0.5$, replace the true depth value with the **dataset mean (0)**. This forces the FiLM layer to learn a dual behavior: utilizing depth to refine boundaries when available, but reverting to a robust "average" modulation when depth is missing.
*   **Loss Function:** Use the **Sum** of **Lovasz-Hinge Loss** and **Binary Cross Entropy (BCE)**. Lovasz-Hinge optimizes the IoU metric directly (Cite solution_lesson_node_00021), and summing (rather than averaging) maintains the gradient magnitude required for the learning rate schedule (Cite solution_lesson_node_00036).
*   **Optimizer:** **AdamW** with a learning rate of **1e-4** and weight decay of **1e-2**. This conservative rate preserves pretrained features (Cite solution_lesson_node_00022).
*   **Scheduler:** **Cosine Annealing** ($T_{max}=50$).
*   **Horizon:** Train for **50 epochs** to ensure peak convergence (Cite solution_lesson_node_00006).

### Evaluation

*   **Inference:**
    *   **Depth Imputation:** For all test images, inject a **constant depth value of 0** (the training mean). The Bernoulli Depth Masking ensures the model is robust to this state.
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score, rather than using a fixed 0.5 cutoff (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
