### Implementation Strategy

1.  **Configuration Override**: We will modify the static `Config` class attributes at runtime to reduce the dataset size (`MAX_SAMPLES = 50`), number of epochs (`EPOCHS = 1`), and folds. This ensures the demonstration completes quickly while exercising the full pipeline.
2.  **Data Loading Verification**: We will instantiate the data loaders using `get_train_val_loaders` and `get_test_loader` and verify the shape and type of the yielded batches (Images, Masks, Depths).
3.  **Model & Loss Verification**: We will instantiate the `SpecialistTeacher` and `GeneralistStudent` models. We will perform a forward pass with a batch of data to verify output shapes and then calculate losses using `calc_combined_loss` to ensure the loss functions (Lovasz, BCE, MSE) are working correctly.
4.  **Training Loop Demonstration**: We will run a single epoch of training for the Teacher model using `train_model`. This demonstrates the optimization step and metric logging.
5.  **Marginalization & Pseudo-Labeling**: We will use the trained teacher to generate marginalized soft predictions on the test set using `predict_teacher_marginalized`.
6.  **Student Training & Submission**: We will run a single epoch of Student training using the generated pseudo-labels and then execute `generate_submission` to produce the final CSV, verifying the output format.
