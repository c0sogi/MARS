To demonstrate the usage of the provided library files for the salt segmentation task, I will implement a script that performs the following steps:

1.  **Environment Setup**: Configure the environment, set random seeds for reproducibility, and suppress progress bars (monkeypatching `tqdm`) to keep the output clean.
2.  **Verification of Utility Functions**: Validate the Run-Length Encoding (`rle_encode`) logic and Mean Average Precision (`calc_map_score`) calculation with synthetic data.
3.  **Data Loading**: Initialize the data loaders using `get_loaders` in debug mode. This processes a small subset of the data to ensure the script runs quickly. I will verify the shapes and types of the loaded batches.
4.  **Model Initialization**: Instantiate the `ResNet34WideLinkNet` model and perform a forward pass with the sample batch to verify output dimensions.
5.  **Loss Calculation**: Compute the loss using `CombinedLoss` to ensure the loss function and gradient propagation are working correctly.
6.  **Training Loop**: Run `train_one_epoch` for a single epoch on the debug subset to demonstrate the training workflow.
7.  **Evaluation**: Run the `evaluate` function on the validation set to check metric reporting.
8.  **Inference and Post-processing**: Use `predict_proba` to generate predictions, demonstrate how to crop the padded 128x128 predictions back to the original 101x101 size, and encode the result into the RLE format required for submission.
