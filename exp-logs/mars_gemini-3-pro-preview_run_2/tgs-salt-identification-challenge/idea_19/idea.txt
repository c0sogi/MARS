Based on the comprehensive analysis of the accumulated lessons and the specific failure modes of previous attempts, I propose the following **Noisy Student Wide-LinkNet** strategy.

This solution resolves the central paradox: **Depth is critical for performance (Cite solution_lesson_node_00001)** but **missing at test time (Cite solution_lesson_node_00020)**. It synthesizes the robustness of **Bernoulli Depth Masking** (from Idea 16) with the stability of **Soft-Target Distillation** (from Idea 17), and evolves it into a **Noisy Student** paradigm. This ensures the model learns to utilize depth when available (Specialist) while robustly adapting to the test distribution using strong consistency regularization (Generalist).

### Model: ResNet34-WideLinkNet with MLP-Concatenation

I propose a specialized U-shape architecture optimized for information flow and robust conditional execution.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed (Cite solution_lesson_node_00011, solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** by summing the original RGB weights. This preserves pretrained feature detectors without the redundancy of data repetition (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Optimization):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map is passed to the decoder to preserve maximum semantic information (Cite solution_lesson_node_00019).
    *   **Depth Injection:** The scalar depth $z$ is projected through a **Non-Linear MLP** (Linear $\rightarrow$ ReLU $\rightarrow$ Linear) to a 32-channel embedding (Cite solution_lesson_node_00029). This embedding is **concatenated** with the encoder features. Concatenation is chosen over FiLM or Residual Injection because it forces the model to utilize the signal and is robust to initialization (Cite solution_lesson_node_00037, solution_lesson_node_00041).
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** for efficiency (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` rather than `out_channels // 4`. This prevents the aggressive semantic information loss observed in standard implementations (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding. This ensures dimensions are multiples of the network's stride (32), preventing spatial aliasing (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std). Even with the 1-channel modification, scaling to the pretrained distribution is critical (Cite solution_lesson_node_00025).
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the training depth values (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Weak Augmentation (Teacher/Labeled):** Horizontal Flip, ShiftScaleRotate (Cite solution_lesson_node_00010).
    *   **Strong Augmentation (Student/Unlabeled):** Add **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) (Cite solution_lesson_node_00004) and increased intensity.

### Training: Two-Stage Noisy Student Pipeline

I propose a rigorous two-stage process that leverages the unlabeled test data without the risks of naive pseudo-labeling.

*   **Stage 1: Supervised Teacher Training**
    *   Train the model on the labeled training set.
    *   **Bernoulli Depth Masking:** With probability $p=0.5$, replace the normalized depth input $z$ with the **dataset mean (0)**. This trains the Teacher to operate in both "Specialist" (Depth-Aware) and "Generalist" (Depth-Blind) modes (Cite solution_lesson_node_00051).
    *   **Loss:** Sum of **Lovasz-Hinge** (per-image) and **BCE** (Cite solution_lesson_node_00036, solution_lesson_node_00044).
    *   **Horizon:** 50 epochs to ensure full convergence (Cite solution_lesson_node_00045).

*   **Stage 2: Noisy Student Distillation**
    *   **Soft Pseudo-Labeling:** Use the converged Teacher to generate **Soft Probability Maps** for the unlabeled test set.
        *   Input: Test Image + **Constant Depth (0)**.
        *   TTA: Average predictions of original and flipped images (Cite solution_lesson_node_00002).
    *   **Student Training:** Initialize a new model (Student) and train on the combined dataset.
        *   **Labeled Batch:** Input (Image + True Depth). Loss: Lovasz + BCE against GT.
        *   **Unlabeled Batch:** Input (**Strongly Augmented** Image + **Constant Depth 0**). Loss: **BCE** against Teacher's Soft Targets.
    *   **Rationale:** Training the Student on strongly augmented views to match the Teacher's stable predictions enforces smoothness on the test manifold, effectively adapting the model to the target distribution while using the "Generalist" depth mode (Cite solution_lesson_node_00049).

### Evaluation

*   **Inference:**
    *   Use the **Student Model**.
    *   **Depth Handling:** Input a **constant depth value of 0** for all test images.
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
