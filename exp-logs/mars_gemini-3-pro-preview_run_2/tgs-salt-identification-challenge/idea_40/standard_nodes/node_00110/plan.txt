This script implements the **FP32-Stabilized Marginalized-Distillation to Multi-Task Student** strategy. It orchestrates a three-stage pipeline:
1.  **Specialist Teacher Training**: Trains a depth-injected ResNet34 teacher on the labeled dataset (Fold 0) to capture depth-dependent salt features.
2.  **Marginalized Pseudo-Labeling**: Uses the teacher to generate robust soft targets for the unlabeled test set by marginalizing over a range of plausible depths.
3.  **Generalist Student Training**: Distills knowledge into a depth-blind student model using a multi-task objective (Segmentation + Auxiliary Depth Regression) to enforce learning of depth-correlated textures.

The script concludes by validating the student model, performing failure analysis (error vs. depth correlation), and generating a submission if the performance threshold is met.
