This script demonstrates the complete pipeline for the salt segmentation task using the provided library files. It covers:
1.  **Configuration**: dynamically overriding hyperparameters for a fast demonstration.
2.  **Utilities**: verifying RLE encoding/decoding and image padding/unpadding.
3.  **Data Loading**: instantiating dataloaders and verifying tensor shapes.
4.  **Model & Loss**: initializing the `SaltNet` architecture and `BCELovaszLoss`, and performing a forward/backward pass.
5.  **Training**: running a short integration test and executing the full `train_model` pipeline for a single epoch.
