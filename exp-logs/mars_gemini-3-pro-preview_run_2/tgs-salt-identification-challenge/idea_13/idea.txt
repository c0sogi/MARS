Based on the comprehensive analysis of the accumulated lessons, I propose the following **Residual-Injection Wide-LinkNet** strategy.

This solution resolves the central conflict: **Depth information is critical for performance (Cite solution_lesson_node_00001)** but **missing at test time (Cite solution_lesson_node_00020)**. Previous attempts using simple concatenation (Idea 8) worked but lacked explicit structural safety for missing data, while FiLM (Idea 11) failed due to initialization instability (Cite solution_lesson_node_00037).

My proposed structural innovation is a **Zero-Initialized Residual Depth Injection** module. This mechanism guarantees that the model behaves as an identity function with respect to depth at initialization, preventing signal destruction, while allowing it to learn additive, depth-dependent feature refinements during training.

### Model: Residual-Injection ResNet34-WideLinkNet

I propose a specialized U-shape architecture designed for robust conditional feature refinement.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed (Cite solution_lesson_node_00002, solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** by summing the original RGB weights. This preserves pretrained feature detectors without the redundancy of data repetition (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Innovation):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map $F$ is passed from the encoder (Cite solution_lesson_node_00019).
    *   **Residual Injection:**
        1.  **Embedding:** Project the scalar depth $z$ through a **Non-Linear MLP** (Linear $\rightarrow$ ReLU $\rightarrow$ Linear) to a 32-channel embedding $E_z$ (Cite solution_lesson_node_00029).
        2.  **Fusion:** Concatenate $F$ and $E_z$.
        3.  **Transformation:** Pass the concatenated tensor through a lightweight Conv1x1 $\rightarrow$ BatchNorm $\rightarrow$ ReLU block.
        4.  **Zero-Init Projection:** Pass the result through a final Conv1x1 layer initialized with **weights and biases of zero**. This produces a "depth delta" $\Delta F$.
        5.  **Addition:** Compute $F_{out} = F + \Delta F$.
    *   **Benefit:** At initialization, $\Delta F = 0$, so $F_{out} = F$. This ensures the depth path does not disrupt the pretrained visual features (Cite solution_lesson_node_00037), while allowing the model to learn to additively refine features based on geological depth.
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` rather than `out_channels // 4`. This prevents semantic information loss during upsampling (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding. This ensures dimensions are multiples of the network's stride (32), preventing spatial aliasing (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std). Even with the 1-channel modification, scaling to the pretrained distribution is critical (Cite solution_lesson_node_00025).
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the training depth values (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate organic salt plasticity (Cite solution_lesson_node_00003, solution_lesson_node_00004).
    *   **Rigid:** Apply **ShiftScaleRotate** to ensure geometric invariance (Cite solution_lesson_node_00010).
    *   **Regularization:** Apply these augmentations with a moderate probability ($p=0.2$) (Cite solution_lesson_node_00007).

### Training

*   **Strategy: Bernoulli Depth Masking:** To handle missing test depths, apply a stochastic mask to the depth input. With probability $p=0.5$, replace the true depth value with the **dataset mean (0)**. Combined with the Residual Injection architecture, this explicitly trains the model to operate in two modes: "Refinement" (using depth) and "Fallback" (using visual features only, where $\Delta F \approx 0$).
*   **Loss Function:** Use the **Sum** of **Lovasz-Hinge Loss** and **Binary Cross Entropy (BCE)**. Summing maintains the gradient magnitude required for the learning rate schedule (Cite solution_lesson_node_00036), while Lovasz-Hinge optimizes the IoU metric directly (Cite solution_lesson_node_00021).
*   **Optimizer:** **AdamW** with a learning rate of **1e-4** and weight decay of **1e-2**. This conservative rate preserves pretrained features (Cite solution_lesson_node_00022).
*   **Scheduler:** **Cosine Annealing** with $T_{max}=50$.
*   **Horizon:** Train for **50 epochs** to ensure peak convergence (Cite solution_lesson_node_00006).

### Evaluation

*   **Inference:**
    *   **Depth Handling:** For all test images, inject a **constant depth value of 0**. The Residual Injection structure guarantees this results in a near-zero delta, effectively utilizing the "Fallback" mode learned via Bernoulli masking.
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score, rather than using a fixed 0.5 cutoff (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
