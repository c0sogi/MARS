The current `Pipeline` implementation only supports a single-stage supervised training workflow via `train_supervised_student`. This discrepancy between the call site and the method signature causes an `AttributeError`. To resolve this, I will update `runfile.py` to use the available `train_supervised_student` method, ensuring the function call matches the library's interface (Cite debug_lesson_16).
