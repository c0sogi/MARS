The issue stems from how the `logits` tensor is initialized in `test_loss_function`. By creating the tensor with `requires_grad=True` on the CPU and then moving it to the device using `.to(device)`, the resulting `logits` tensor becomes an intermediate node (non-leaf) in the computational graph rather than a leaf node. PyTorch only populates the `.grad` attribute for leaf tensors. To fix this, I will initialize the tensor directly on the target device with `requires_grad=True`, ensuring it remains a leaf tensor and allows gradient tracking as described in debug_lesson_8. Cite debug_lesson_8.
