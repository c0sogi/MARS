This script demonstrates the end-to-end pipeline for the Salt Segmentation task using the provided library. It covers:
1.  **Data Loading**: Initializing datasets and dataloaders for training, validation, and unlabeled data, including handling metadata and caching.
2.  **Stage 1 (Teacher Training)**: Training a "Specialist Teacher" model that uses depth injection.
3.  **Stage 2 (Pseudo-Labeling)**: Generating soft pseudo-labels for the test set using the "Marginalized Depth Scan" technique with the trained teacher.
4.  **Stage 3 (Student Training)**: Training a "Generalist Student" model using multi-task distillation (supervised loss on labeled data + unsupervised loss on pseudo-labeled data).
5.  **Utilities**: Verifying RLE encoding/decoding and image padding logic.

To ensure the script runs quickly within the demonstration limits, hyperparameters like batch size, epochs, and dataset size are significantly reduced.
