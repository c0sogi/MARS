Based on the comprehensive analysis of the accumulated lessons, I propose the following **Marginalized-Distillation Multi-Task Wide-LinkNet** strategy.

This solution resolves the central "Depth Paradox": **Depth information is critical for performance (Cite solution_lesson_node_00001)**, yet **depth metadata is missing for the test set (Cite solution_lesson_node_00020)**.

Previous attempts to bridge this gap failed because:
1.  **Regression** lacks sufficient local signal (Cite solution_lesson_node_00022).
2.  **Standard Distillation** fails because the image-only student faces an information bottleneck regarding the orthogonal depth feature (Cite solution_lesson_node_00032).
3.  **Zero-Masking** creates contradictory training signals (Cite solution_lesson_node_00051).

My proposed structural innovation is **Marginalized Distillation**. Instead of trying to impute a single depth value or forcing a student to mimic a teacher at a specific (unknown) depth, we treat the missing test depth as a latent variable. We train a "Specialist" Teacher to learn the conditional distribution $P(y|x, z)$. We then perform a **Marginalized Depth-Scan** on the unlabeled test set—integrating predictions across the plausible depth range—to generate robust soft targets. Finally, we distill this *marginalized* knowledge into a **Multi-Task Student**, which learns to predict the depth-integrated outcome directly from texture, aided by an auxiliary depth-regularization head.

### Model: Teacher-Student Wide-LinkNet Framework

I propose two distinct model variants sharing a high-performance backbone.

1.  **Specialist Teacher (Depth-Injected):**
    *   **Backbone:** **ResNet34** pretrained on ImageNet (Cite solution_lesson_node_00012).
    *   **Input:** First convolution modified to accept **1-channel input** (summing weights) (Cite solution_lesson_node_00028).
    *   **Bottleneck:** No compression layer; passes full 512 channels (Cite solution_lesson_node_00019).
    *   **Depth Injection:** Projects scalar depth via a **Non-Linear MLP** and **concatenates** it with encoder features (Cite solution_lesson_node_00029, solution_lesson_node_00041).
    *   **Decoder:** **Wide-LinkNet** (internal width = `in_channels // 4`) with **Additive Skip Connections** (Cite solution_lesson_node_00008, solution_lesson_node_00023).

2.  **Generalist Student (Multi-Task):**
    *   **Architecture:** Identical to the Teacher, but **removes the Depth Injection module**.
    *   **Auxiliary Head (Structural Innovation):** Attaches a regression head (GlobalAvgPool $\rightarrow$ MLP $\rightarrow$ Scalar) to the bottleneck. This head is **explicitly connected** to the loss function (Cite solution_lesson_node_00062) to force the encoder to extract depth-correlated texture features, maximizing its capacity to absorb the Teacher's knowledge.

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding to ensure divisibility by 32 (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std) (Cite solution_lesson_node_00025). Apply **Standard Scaling** to depth values (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** ($p=0.2$) with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to capture organic salt morphology (Cite solution_lesson_node_00055, solution_lesson_node_00073).
    *   **Rigid:** Apply **ShiftScaleRotate** ($p=0.2$) for geometric invariance (Cite solution_lesson_node_00054).

### Training: Marginalized Distillation Pipeline

I propose a three-stage pipeline to robustly transfer knowledge to the depth-blind domain.

*   **Stage 1: Train Specialist Teacher (Supervised)**
    *   Train a **5-Fold Ensemble** of the Depth-Injected Teacher on the labeled dataset.
    *   **Depth Jitter:** Add Gaussian noise to the depth input during training. This prevents overfitting to specific discrete depths and smooths the manifold for the subsequent scanning phase.
    *   **Loss:** Sum of **Lovasz-Hinge** (per-image) and **BCE** (Cite solution_lesson_node_00044, solution_lesson_node_00036).
    *   **Horizon:** 50 epochs (Cite solution_lesson_node_00006).

*   **Stage 2: Marginalized Soft Pseudo-Labeling**
    *   **Depth-Scan Inference:** For each unlabeled test image $x$, generate predictions using the Teacher Ensemble across a **spectrum of depths** $Z_{scan}$ (e.g., 5 values linearly spaced from -1.5 to 1.5 std).
    *   **Marginalization:** Average the probability maps across all $z \in Z_{scan}$ and all folds. This computes the expected mask $\mathbb{E}_z[P(y|x, z)]$, effectively integrating out the missing depth variable.
    *   **Output:** High-quality **Soft Probability Maps** that are robust to depth uncertainty.

*   **Stage 3: Student Distillation (Multi-Task)**
    *   Train a single Generalist Student from scratch on the Combined (Train + Test) dataset.
    *   **Labeled Batch:** Input: Image. Target: GT Mask + True Depth. Loss: **Lovasz+BCE** (Mask) + **MSE** (Depth).
    *   **Unlabeled Batch:** Input: Image. Target: Soft Pseudo-Labels. Loss: **BCE** (vs Soft Targets). Note: We use BCE because Lovasz is incompatible with soft targets (Cite solution_lesson_node_00071).
    *   **Optimizer:** AdamW (`lr=1e-4`) with **Cosine Annealing** (Cite solution_lesson_node_00022, solution_lesson_node_00068).

### Evaluation

*   **Inference:**
    *   Use the **Stage 3 Student Model**.
    *   **Input:** Image only (Auxiliary depth head is ignored).
    *   **Test-Time Augmentation (TTA):** Average predictions of original and horizontally flipped images (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
