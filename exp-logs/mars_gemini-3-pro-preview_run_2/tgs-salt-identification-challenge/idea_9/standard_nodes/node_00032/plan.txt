This causes the model to train and validate on a tiny fraction of the dataset, leading to invalid metrics and failure analysis.

To fix this, I will modify `library/dataset.py` to validate the length of the loaded cache arrays against the length of the metadata dataframe. If the dimensions do not match, the code will discard the cached data and proceed to recompute the dataset from source files.
