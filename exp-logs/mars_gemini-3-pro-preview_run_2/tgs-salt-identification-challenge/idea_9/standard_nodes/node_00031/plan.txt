The following strategy outlines the implementation of the `runfile.py` script to orchestrate the Privileged Knowledge Distillation solution:

1.  **Setup & Configuration**: Initialize the environment with a fixed random seed and detect the available computation device (GPU). Define paths for model checkpoints and outputs.
2.  **Data Loading**: Utilize the `get_dataloaders` function to prepare training, validation, and test data iterators. We enable caching to speed up data loading.
3.  **Phase 1: Teacher Training**: Train the "Privileged Teacher" model (ResNet34 + Depth Injection) using the `run_teacher_training` engine function. This phase leverages the depth metadata available in the training set to learn superior features. We limit epochs to 20 to ensure execution within the time limit.
4.  **Phase 2: Student Distillation**: Train the "Depth-Agnostic Student" model using the `run_student_distillation` engine function. The Student learns to mimic the Teacher's logits while relying solely on image data, making it compatible with the test set.
5.  **Validation & Metric**: Evaluate the trained Student model on the full validation set using the official mean Average Precision (mAP) metric. The result is printed strictly in the required format.
6.  **Failure Analysis**: Perform a granular analysis by calculating the error (1 - mAP) for each validation image. Load the validation metadata to compute and print correlations between model error and key features like Depth (`z`) and Salt Coverage, identifying systematic weaknesses.
7.  **Conditional Submission**: Check if the final validation metric exceeds the threshold of **0.7985**. If successful, generate the submission file using the `generate_submission` function, which applies Test-Time Augmentation (TTA) and threshold optimization.
