Implementation Strategy:
1.  **Setup and Configuration**: Import necessary modules and the provided library components. Initialize the `Config` class using `get_config(debug=True)` to enable a lightweight execution mode (fewer epochs, smaller batch size, data subset).
2.  **Utility Verification**: Validate helper functions such as Run-Length Encoding (`rle_encode`/`rle_decode`), image padding (`pad_image`/`unpad_image`), and the competition metric (`do_kaggle_metric`) using synthetic data to ensure correctness.
3.  **Data Pipeline Verification**: Instantiate the DataLoaders using `get_dataloaders`. Fetch a single batch to verify tensor shapes, data types, and value ranges (normalization) for images, masks, and depths.
4.  **Model and Loss Verification**: Instantiate the `SaltNet` model and `BCELovaszLoss`. Perform a forward pass with dummy tensors to verify output shapes. Compute the loss and perform a backward pass to ensure gradients are calculated correctly.
5.  **Training Simulation**: Execute the `train_model` function from `library.train`. This will run a short training loop (1 epoch on a small subset), validating the integration of the model, data, and training logic, and generating a model checkpoint.
6.  **Inference Simulation**: Execute the `predict` function from `library.model`. This will load the checkpoint (or use the model in memory) to generate predictions on the test set and create a submission file.
7.  **Final Checks**: Assert the existence of the output files (checkpoint and submission CSV) to confirm the pipeline completed successfully.
