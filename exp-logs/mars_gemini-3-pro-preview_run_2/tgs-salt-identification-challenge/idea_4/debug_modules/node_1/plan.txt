The issue is that `albumentations.pytorch.ToTensorV2` defaults to `transpose_mask=False`, which preserves the input mask's channel-last format `(H, W, C)`. Since the preprocessing pipeline explicitly expands the mask dimensions to `(128, 128, 1)`, the resulting tensor remains `(128, 128, 1)`, causing a shape mismatch with the PyTorch model and verification tests that expect channel-first format `(1, 128, 128)`. The fix is to explicitly set `transpose_mask=True` in `ToTensorV2` to ensure the mask is permuted to `(C, H, W)`.
