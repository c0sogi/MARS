The following script demonstrates the complete pipeline for the salt segmentation task using the provided library files. It covers data loading, model instantiation, loss calculation, teacher training, inference/pseudo-labeling, student training, and utility verification (RLE encoding/decoding and IoU calculation).

To ensure rapid execution within the time limit, the script:
1.  Enables `DEBUG` mode in the configuration.
2.  Uses `torch.utils.data.Subset` to create tiny datasets (16 samples) for training and validation loops.
3.  Runs only 1 epoch for both teacher and student stages.
4.  Validates the correctness of shapes, loss values, and utility functions using assertions.
