I will create a Python script that generates metadata for the salt segmentation task. The script will perform the following steps:
1.  **Setup and Data Loading**: Load `train.csv` and `depths.csv` from the `./input` directory. It will also scan the `./input/test/images` directory to identify test samples.
2.  **Feature Engineering for Stratification**: Calculate the salt coverage (number of salt pixels) for each training image by parsing the Run-Length Encoded (RLE) masks. This coverage metric will be quantized into bins to serve as a stratification target, ensuring the validation set has a representative distribution of salt amounts (from empty masks to full coverage).
3.  **Data Splitting**: Perform a stratified 80:20 split on the training data using the calculated coverage bins and a fixed random state of 42.
4.  **Metadata Generation**: Construct DataFrames for training, validation, and test sets containing relative file paths (e.g., `train/images/{id}.png`), depth information, and ground truth RLE masks (for train/val). These will be saved as CSV files in the `./metadata` directory.
5.  **Verification**: The script will reload the generated metadata to verify the split ratio, check that the stratification distribution is consistent between train and validation sets, and validate that a random sample of file paths correctly resolves to existing files in the `./input` directory.
