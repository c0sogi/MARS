The `ValueError` occurs because `np.array(data, dtype=object)` attempts to infer a common shape for the elements in the `data` tuple. Since all elements (images, masks, depths, ids) share the same leading dimension (batch size), NumPy tries to broadcast them into a unified multi-dimensional array, which fails due to mismatched trailing dimensions (e.g., `(101, 101, 1)` vs scalar). To fix this, we must explicitly construct an empty object array of the correct length and assign the elements to it, preventing NumPy's dimension discovery logic.
