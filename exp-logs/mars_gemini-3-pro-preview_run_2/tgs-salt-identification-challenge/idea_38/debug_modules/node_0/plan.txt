    *   **Teacher Mode**: Verify it accepts `(image, depth)` and outputs `logits`.
    *   **Student Mode**: Verify it accepts `(image)` and outputs `(logits, predicted_depth)`.

4.  **Loss Function Verification**:
    *   Instantiate `TeacherLoss` and `StudentLoss`.
