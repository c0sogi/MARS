Based on the accumulated lessons and the dataset characteristics, I propose the following **Semi-Supervised Self-Training Strategy** using a **Depth-Conditioned ResNet34-LinkNet**.

### Model: Depth-Conditioned ResNet34-LinkNet (Optimized)
I propose a structural evolution of the architecture that prioritizes efficiency and information flow, specifically removing the bottleneck compression identified as harmful in previous experiments.

*   **Backbone:** Use a **ResNet34** encoder pretrained on ImageNet. This backbone is "right-sized" for the dataset's resolution and scale, avoiding the optimization inertia and overfitting observed with heavier backbones like SE-ResNeXt50 Cite solution_lesson_node_00011, solution_lesson_node_00012.
*   **Decoder:** Utilize the **LinkNet** decoder architecture. Its additive skip connections are computationally efficient and have been proven to outperform the complex, concatenation-heavy U-Net++ for this specific task Cite solution_lesson_node_00008.
*   **Bottleneck Optimization (Structural Change):** Remove the explicit bottleneck compression layer (typically a 1x1 conv reducing channels) between the encoder and decoder. Pass the full, high-dimensional feature map from the encoder directly to the decoder to preserve maximum semantic information Cite solution_lesson_node_00019.
*   **Depth Injection:** Inject the depth metadata at the bottleneck. Project the scalar depth (normalized) into a low-dimensional embedding (e.g., 16 channels) and **concatenate** it with the encoder's feature map. This avoids the parameter explosion of convolutional fusion while maintaining global context Cite solution_lesson_node_00001, solution_lesson_node_00009.

### Data
*   **Preprocessing:**
    *   **Image Formatting:** Convert images to single-channel grayscale and pad to **128x128** using reflection padding.
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the depth values. This is superior to Min-Max scaling for neural network convergence Cite solution_lesson_node_00010.
*   **Augmentation:**
    *   **Affine Transformations:** Incorporate **ShiftScaleRotate**. Geometric invariance is mandatory for seismic data Cite solution_lesson_node_00010.
    *   **Non-Rigid Transformations:** Apply **ElasticTransform** to simulate the organic plasticity of salt bodies Cite solution_lesson_node_00003.
    *   **Tuned Parameters:** Use the optimized parameters for elastic deformation (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to ensure physical significance Cite solution_lesson_node_00004.
    *   **Regularization Strength:** Apply non-rigid augmentations with a moderate probability ($p=0.2$) to act as a regularizer without shifting the training distribution too aggressively Cite solution_lesson_node_00007.

### Training: Semi-Supervised Self-Training Pipeline
I propose a **multi-stage pipeline** to address the limited training data size (3000 images) by leveraging the unlabeled test data (1000 images).

*   **Phase 1: Supervised Training (Cross-Validation)**
    *   Train the model using a **5-Fold Cross-Validation** scheme on the labeled training set.
    *   **Loss Function:** Use **BCE + Dice Loss**. While Lovasz-Hinge is theoretically superior, it converges slower; BCE+Dice is robust and efficient for this pipeline Cite solution_lesson_node_00018.
    *   **Horizon:** Train for **50 epochs** per fold to ensure the model reaches peak performance without premature truncation Cite solution_lesson_node_00006.
*   **Phase 2: Pseudo-Labeling**
    *   Generate predictions for the unlabeled test set using an **ensemble** of the 5 models from Phase 1. Apply **Test-Time Augmentation (TTA)** (horizontal flips) during inference Cite solution_lesson_node_00002.
    *   Create a "Pseudo-Labeled" dataset by combining the original training data with the test images and their predicted masks.
*   **Phase 3: Retraining**
    *   Retrain the 5-Fold Cross-Validation ensemble from scratch using the combined (Labeled + Pseudo-Labeled) dataset. This allows the model to learn from the high-confidence structures identified in the test domain, effectively adapting to the test distribution.

### Evaluation
*   **Inference:**
    *   **Ensemble TTA:** Generate final predictions by averaging the probability maps from the Phase 3 ensemble (5 models), applying horizontal flip TTA for each Cite solution_lesson_node_00002.
*   **Post-Processing:**
    *   **Threshold Optimization:** Instead of a fixed 0.5 threshold, determine the optimal binarization threshold by performing a linear search on the validation set predictions to maximize the mAP score Cite solution_lesson_node_00018.
    *   **Formatting:** Center crop to 101x101 and convert to RLE.
