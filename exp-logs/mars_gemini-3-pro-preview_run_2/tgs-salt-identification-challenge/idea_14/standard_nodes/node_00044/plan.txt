Implementation strategy:

1.  **Setup & Configuration**: Initialize the environment with a fixed random seed and detect the available GPU. Define hyperparameters (epochs, batch size, learning rate) suitable for a fast but effective run.
2.  **Data Loading**: Load metadata for training, validation, and testing. Calculate depth statistics (mean, std) from the training set to normalize all depth inputs consistently.
3.  **Stage 1 - Robust Supervised Training**:
    *   Initialize the `WideLinkNetResNet34` model and `CombinedLoss` (BCE + Lovasz).
    *   Train on the labeled training set using `SaltDataset` with `bernoulli_mask_prob=0.5`. This randomly zeroes out depth information during training, forcing the model to learn features independent of depth (robustness).
    *   Validate periodically and save the best model checkpoint.
4.  **Pseudo-Labeling**:
    *   Use the best Stage 1 model to predict masks for the unlabeled test set.
    *   Crucially, force the depth input to 0 during this inference to mimic the "missing depth" scenario the model was robustly trained for.
    *   Binarize predictions using an optimized threshold and save them as pseudo-masks.
    *   Construct a combined DataFrame of original training data + pseudo-labeled test data.
5.  **Stage 2 - Retraining**:
    *   Initialize a fresh model.
    *   Train on the combined dataset (Train + Pseudo-Test) to adapt the model to the test set's visual domain.
    *   Continue using Bernoulli masking to maintain robustness.
6.  **Evaluation & Failure Analysis**:
    *   Perform inference on the hold-out validation set using the best Stage 2 model.
    *   Optimize the binarization threshold to maximize the mAP metric.
    *   Report the `Final Validation Metric`.
    *   Analyze failures by correlating IoU error with depth and salt coverage to identify systematic weaknesses.
7.  **Submission**:
    *   If the validation metric exceeds the target (0.7985), generate predictions for the test set (forcing depth to 0).
    *   Apply Test-Time Augmentation (TTA) and the optimized threshold.
    *   Save the results to `submission.csv` in RLE format.
