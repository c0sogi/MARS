Based on the comprehensive analysis of the accumulated lessons, I propose the following **Self-Training Depth-Robust Wide-LinkNet** strategy.

This solution synthesizes the conflicting findings regarding depth utilization: while depth injection is critical for performance (Cite solution_lesson_node_00001), the metadata is missing at test time (Cite solution_lesson_node_00020), and previous attempts to bridge this gap via regression (Cite solution_lesson_node_00022) or distillation (Cite solution_lesson_node_00032) have failed.

My proposed structural innovation is a **Two-Stage Self-Training Pipeline** underpinned by a **Bernoulli Scalar Masking** mechanism. This approach explicitly trains the model to handle "missing depth" scenarios, allowing it to safely generate pseudo-labels for the test set and subsequently learn from the test set's visual structure, effectively adapting to the target domain without requiring the missing metadata.

### Model: ResNet34-WideLinkNet with Bottleneck Concatenation

I propose a specialized U-shape architecture optimized for information flow and robust conditioning.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed (Cite solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** by summing the original RGB weights. This preserves pretrained feature detectors without the redundancy of data repetition (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Optimization):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map from the encoder is passed to the decoder to preserve maximum semantic information (Cite solution_lesson_node_00019).
    *   **Depth Injection:** The scalar depth $z$ is projected through a **Non-Linear MLP** (Linear $\rightarrow$ ReLU $\rightarrow$ Linear) to a 32-channel embedding (Cite solution_lesson_node_00029) and **concatenated** with the encoder features. Concatenation is chosen over FiLM or Residual Injection due to its superior robustness and signal propagation (Cite solution_lesson_node_00037, solution_lesson_node_00041).
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** for efficiency (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` rather than `out_channels // 4`. This prevents semantic information loss during upsampling (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding. This ensures dimensions are multiples of the network's stride (32), preventing spatial aliasing (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std). Even with the 1-channel modification, scaling to the pretrained distribution is critical (Cite solution_lesson_node_00025).
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the training depth values (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate organic salt plasticity (Cite solution_lesson_node_00003, solution_lesson_node_00004).
    *   **Rigid:** Apply **ShiftScaleRotate** to ensure geometric invariance (Cite solution_lesson_node_00010).
    *   **Regularization:** Apply these augmentations with a moderate probability ($p=0.2$) (Cite solution_lesson_node_00007).

### Training: Two-Stage Self-Training Pipeline

I propose a multi-stage training process to bridge the metadata gap.

*   **Technique: Bernoulli Scalar Masking.** During training, with probability $p=0.5$, replace the normalized depth input $z$ with the **dataset mean (0)**. This forces the model to learn a dual representation: a "Specialist" mode that uses depth to refine boundaries, and a "Generalist" mode that relies solely on visual texture when depth is missing. This is the key enabler for processing the test set.

*   **Stage 1: Robust Supervised Training**
    *   Train the model on the labeled training set using Bernoulli Scalar Masking.
    *   **Loss:** **Sum** of **Lovasz-Hinge** and **BCE**. Summing maintains gradient magnitude (Cite solution_lesson_node_00036), while Lovasz optimizes IoU (Cite solution_lesson_node_00021).
    *   **Optimizer:** AdamW (`lr=1e-4`) (Cite solution_lesson_node_00022).
    *   **Horizon:** 50 epochs (Cite solution_lesson_node_00006).

*   **Stage 2: Pseudo-Labeling & Retraining**
    *   **Inference:** Use the Stage 1 model to predict masks for the **unlabeled test set**. Crucially, input a **constant depth of 0** for all test images. The Bernoulli Masking in Stage 1 ensures the model handles this gracefully.
    *   **Retraining:** Train a new model from scratch on the combined dataset (Train + Pseudo-Labeled Test).
        *   **Train Data:** Use true depth (with Bernoulli Masking).
        *   **Test Data:** Use fixed depth 0.
    *   This aligns the test data with the "Generalist" mode of the network, allowing the model to learn the specific visual structure of the test set without being confused by the missing metadata (Cite solution_lesson_node_00020).

### Evaluation

*   **Inference:**
    *   Use the **Stage 2 Model**.
    *   **Depth Handling:** Input a **constant depth value of 0** for all test images.
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
