The following strategy outlines the implementation of the `runfile.py` script:

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and define configuration parameters (batch size, learning rate, epochs) optimized for the available hardware (A100 GPU).
2.  **Stage 1 - Robust Supervised Training**:
    *   Load the training and validation datasets using the `SaltDataset` class.
    *   Train the `ResNet34WideLinkNet` model using the `CombinedLoss` (Lovasz-Hinge + BCE).
    *   Save the Stage 1 model and determine the optimal binarization threshold.
3.  **Pseudo-Labeling**:
    *   Load the Stage 1 model and perform inference on the unlabeled test set using Test-Time Augmentation (TTA) and a fixed depth of 0 to enforce "Generalist" behavior.
    *   Generate binary masks based on the optimal threshold and save them to the working directory.
    *   Create a merged metadata CSV (`pseudo_train.csv`) containing absolute paths to both the original training images and the newly generated pseudo-labeled test images.
4.  **Stage 2 - Self-Training**:
    *   Initialize a fresh `ResNet34WideLinkNet` model.
    *   Train the model on the combined dataset (Train + Pseudo-Labeled Test) to refine boundaries and adapt to the test set distribution.
    *   Employ Early Stopping to save the best model based on validation mAP.
5.  **Evaluation & Submission**:
    *   Evaluate the final model on the hold-out validation set and print the `Final Validation Metric`.
    *   Perform failure analysis by calculating the correlation between prediction error (1 - IoU) and depth.
    *   If the validation metric exceeds the threshold (0.7985), generate the final submission file in Run-Length Encoding (RLE) format.
