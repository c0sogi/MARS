Implementation Strategy:
1.  **Configuration Setup**: I will override specific `Config` class attributes (e.g., `DEBUG`, `BATCH_SIZE`, `NUM_WORKERS`) to ensure the script runs quickly on a small subset of data without spawning too many processes.
2.  **Utility Verification**: I will explicitly test the `rle_encode`/`rle_decode` and `pad_image`/`unpad_image` functions with synthetic data to confirm they preserve data integrity.
3.  **Data Loading**: I will utilize `get_dataloaders` with `debug=True` to load a tiny subset of the real data. I will assert the shape of the yielded batches matches the expected dimensions (Batch Size, Channels, Height, Width).
4.  **Model & Loss Initialization**: I will instantiate the `ResNet34WideLinkNet` and `MultiTaskLoss`. I will perform a forward pass with a dummy batch to verify output shapes and loss calculation before starting the training loop.
5.  **Training & Evaluation Loop**: I will run a single training epoch and a validation pass using the `engine` module functions. I will verify that the loss is a finite number and the mAP score is calculated.
6.  **Submission Generation**: I will run the inference pipeline on the test set and verify that a submission CSV is generated with the correct schema.
