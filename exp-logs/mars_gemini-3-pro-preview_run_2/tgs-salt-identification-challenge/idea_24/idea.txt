Based on the comprehensive analysis of the accumulated lessons and the persistent "Depth Paradox" (depth is critical for performance but missing at test time), I propose the following **Multi-Task Wide-LinkNet with Ensemble Soft-Distillation** strategy.

This solution accepts the empirical reality that we cannot reliably impute depth for the test set (Cite solution_lesson_node_00022) nor effectively distill orthogonal depth information into a student (Cite solution_lesson_node_00032). Instead, it maximizes the performance of an **Image-Only Inference** model by using depth as a training-time regularizer (Multi-Task Learning) and leveraging the unlabeled test data via a rigorous **Ensemble Soft-Distillation** pipeline.

### Model: Multi-Task ResNet34-WideLinkNet

I propose a specialized architecture that learns from depth during training but does not require it for inference.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed for this dataset size (Cite solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer to accept **1-channel input** by summing the original RGB weights. This prevents the inefficiency of data repetition (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Optimization):**
    *   **No Compression:** Remove the explicit bottleneck compression layer; pass the full 512-channel feature map to the decoder (Cite solution_lesson_node_00019).
    *   **Auxiliary Depth Head (Innovation):** Attach a lightweight regression head (GlobalAveragePooling $\rightarrow$ MLP $\rightarrow$ Scalar) to the bottleneck. This head predicts the normalized depth $z$ from the image features. While previous experiments showed this is inferior to injection *when depth is available* (Cite solution_lesson_node_00024), it forces the encoder to extract depth-correlated texture features, acting as a critical regularizer for our image-only inference constraint.
*   **Decoder:**
    *   **Wide-LinkNet:** Use **Additive Skip Connections** (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate internal block width as `in_channels // 4` to prevent information bottlenecks (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding to ensure divisibility by 32 (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize images using **Standard ImageNet Statistics** (Cite solution_lesson_node_00025). Standard Scale depth values for the regression target (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate organic salt plasticity (Cite solution_lesson_node_00055).
    *   **Rigid:** Apply conservative **ShiftScaleRotate** ($p=0.2$) (Cite solution_lesson_node_00054).

### Training: Ensemble Soft-Distillation Pipeline

I propose a three-stage pipeline to bridge the performance gap without risking divergence.

*   **Stage 1: Multi-Task Ensemble (Supervised)**
    *   Train a **5-Fold Ensemble** of the Multi-Task model on the labeled training set.
    *   **Loss:** $L = L_{Lovasz+BCE}(Mask, GT) + 0.1 \cdot L_{MSE}(PredDepth, TrueDepth)$.
    *   **Aggregation:** Compute Lovasz loss **per-image** to ensure stability (Cite solution_lesson_node_00044).
    *   **Horizon:** Train for **50 epochs** to ensure full convergence (Cite solution_lesson_node_00045).

*   **Stage 2: Soft Pseudo-Label Generation**
    *   Use the converged 5-Fold Ensemble to predict on the **unlabeled test set**.
    *   **Inference:** Image-only (ignore the auxiliary depth output).
    *   **Soft Averaging:** Average the **probability maps** (Soft Labels) from all 5 models. This reduces label noise and captures uncertainty better than hard thresholding (Cite solution_lesson_node_00049).

*   **Stage 3: Student Distillation (Semi-Supervised)**
    *   Train a single Student model (same architecture) from scratch on the combined dataset (Train + Test).
    *   **Labeled Batch:** Loss = Lovasz + BCE (vs GT) + 0.1 * MSE (vs True Depth).
    *   **Unlabeled Batch:** Apply **Strong Augmentation** (Elastic + Grid Distortion). Loss = **BCE** (vs Soft Pseudo-Labels). Ignore depth loss for these samples.
    *   **Rationale:** The Student learns robust features from the labeled data (regularized by depth) and adapts to the test distribution via the smoothed guidance of the Ensemble.

### Evaluation

*   **Inference:**
    *   Use the **Stage 3 Student Model**.
    *   **Input:** Image only (Auxiliary depth head is ignored).
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
