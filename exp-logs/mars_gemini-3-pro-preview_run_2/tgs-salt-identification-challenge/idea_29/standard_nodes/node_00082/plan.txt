The `AttributeError` occurs because the `StudentLoss` class in `library/losses.py` attempts to access `Config.LOSS_WEIGHT_MSE` and `Config.LOSS_WEIGHT_BCE_DISTILL` during initialization, but these attributes are not defined in `library/config.py`. Even though the current execution is running the Teacher model training (which doesn't use `StudentLoss`), the `Trainer` class initializes `StudentLoss` unconditionally in its constructor, triggering the crash.

To fix this, I will add the missing loss weight parameters to the `Config` class in `library/config.py`. As indicated by the comments in `library/losses.py` (`# L = L_Seg + 0.1 * L_MSE + 0.5 * L_Distill`), I will set `LOSS_WEIGHT_MSE` to 0.1 and `LOSS_WEIGHT_BCE_DISTILL` to 0.5.
