Implementation Strategy:
1.  **Configuration & Setup**: Initialize the environment by setting random seeds for reproducibility and enabling the debug mode in the `Config` class. This reduces the dataset size and number of epochs, ensuring the script executes quickly.
2.  **Utility Verification**: Test the core utility functions (`rle_encode`, `rle_decode`, `pad_image`, `unpad_image`) with synthetic data to ensure valid input/output transformations and shape consistency.
3.  **Dataset & DataLoader**: Instantiate the `SaltDataset` for training and validation. Verify that the data loading pipeline correctly handles image loading, padding, augmentation, and depth normalization. Check the shapes of the tensors produced by the DataLoader.
4.  **Model Initialization**: Instantiate the `ResNet34WideLinkNet` model. Perform a forward pass with dummy data to verify the architecture's connectivity and output shapes (mask logits and depth prediction).
5.  **Loss Function**: Test the `MultiTaskLoss` (combining Lovasz-Hinge, BCE, and MSE) to ensure it computes gradients correctly given model outputs and targets.
6.  **Training Loop**: Execute a single epoch of training using `train_one_epoch` and a validation pass using `validate` from the `engine` module. This demonstrates the integration of the model, data, and loss function.
7.  **Full Pipeline Simulation**: Run the `train_model` function to simulate a complete training cycle (with early stopping and threshold optimization) on the reduced dataset.
8.  **Inference**: Generate predictions using `predict_and_submit` on the test set and verify the generation of the submission file.
