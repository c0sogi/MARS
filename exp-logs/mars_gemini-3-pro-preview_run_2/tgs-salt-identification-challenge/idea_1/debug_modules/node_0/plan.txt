### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` class with overrides to minimize runtime (e.g., `EPOCHS=1`, small `BATCH_SIZE`). Set the random seed for reproducibility.
2.  **Utility Verification**: Validate the Run-Length Encoding (`rle_encode`, `rle_decode`) and IoU metric functions (`metric_iou`) using synthetic data to ensure logic correctness.
3.  **Dataset Inspection**: Instantiate the `SaltDataset` class. Retrieve a single sample to verify data shapes (image, depth, mask) and value ranges (normalization).
4.  **Model Forward Pass**: Instantiate the `DepthLinkNet` model. Perform a forward pass with dummy tensors matching the dataset shapes to verify the architecture and output dimensions.
5.  **Training Simulation**: Use the `Trainer` class to run a single training epoch on a very small subset of data (`debug_limit=32`). This demonstrates the training loop, loss calculation, and checkpoint saving without consuming significant time.
6.  **Inference & Submission**: Execute the `generate_submission` function. Verify that the output CSV is generated, contains the correct columns, and has the expected number of rows corresponding to the test set.
