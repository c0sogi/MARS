Implementation strategy:
1.  **Environment Setup**: Initialize random seeds for reproducibility and create necessary directories (`./submission`).
2.  **Data Preparation**: Load the dataset using `library.dataset.prepare_data` and wrap it in DataLoaders using `library.dataset.get_dataloaders`. This handles caching and normalization.
3.  **Stage 1 - Depth Regression**: Train the `DepthRegressor` (ResNet18) to predict depth from seismic images. This model is trained on the labeled training set. Once trained, use it to impute depth values for the test set, addressing the missing metadata issue.
4.  **Stage 2 - Segmentation Training**: Train the `DepthAwareLinkNet34` (ResNet34 + LinkNet Decoder) using the training images and their ground truth depths. The model injects depth information at the bottleneck.
5.  **Validation & Optimization**:
    *   Generate predictions for the validation set using the trained segmentation model.
    *   Crop predictions and ground truth masks to the original 101x101 size.
    *   Perform a linear sweep over binarization thresholds (0.3 to 0.75) to find the value that maximizes the Mean Average Precision (mAP) metric.
    *   Print the `Final Validation Metric`.
6.  **Failure Analysis**: Calculate the error (1 - mAP) for each validation image and compute the Pearson correlation with depth and salt coverage to identify error sources.
7.  **Submission**: If the best validation mAP exceeds the specified threshold (0.7916...), generate predictions for the test set using the imputed depths and the optimal binarization threshold. Encode the masks using RLE and save to `submission.csv`.
