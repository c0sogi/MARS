This script performs a comprehensive Exploratory Data Analysis (EDA) on the provided apple disease dataset. It treats the problem as a multi-label classification task involving images.

**Implementation Strategy:**
1.  **Setup & Data Loading**: The script initializes by setting random seeds for reproducibility and loading the training metadata from `./metadata/train.csv`.
2.  **Target Variable Analysis**: It parses the space-delimited `labels` column to handle the multi-label nature of the data. It calculates the frequency of individual diseases, analyzes the distribution of label counts per image (e.g., how many images have 1 vs. 2 diseases), and computes class imbalance ratios.
3.  **Image Data Analysis**: To ensure efficiency, the script analyzes a stratified random sample of 2,000 images. It computes statistics for image dimensions (width, height, aspect ratio), checks channel depths (RGB vs. Grayscale), and calculates global pixel mean and standard deviation for normalization purposes.
4.  **Feature Relationships**: It explores correlations between image metadata (file size, dimensions) and the presence of specific diseases. It also computes a co-occurrence matrix to identify which diseases frequently appear together on the same leaf.
5.  **Output**: The results are printed in a structured, text-based report format as requested.
