The `RuntimeError` during `ConvNeXt` initialization is caused by the `global_pool=""` argument in `timm.create_model`. As detailed in **debug_lesson_4**, setting `global_pool` to an empty string triggers `timm` to structurally convert final `Linear` layers (like `pre_logits` in ConvNeXt) into `1x1 Conv2d` layers to support fully convolutional inference. However, the pretrained checkpoint contains 2D weights for a standard `Linear` layer, resulting in a shape mismatch (loading `[1536, 1536]` into `[1536, 1536, 1, 1]`).

To fix this (Cite debug_lesson_4), I will remove the `global_pool=""` argument. The `AppleDiseaseModel` class already correctly uses `self.backbone.forward_features(x)` to extract spatial feature maps, which bypasses the pooling and classification head entirely. Therefore, modifying the head structure via `global_pool` is unnecessary and causes the weight loading failure.
