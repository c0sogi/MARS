    *   Load the best saved weights for both models.
    *   Generate probability predictions on the validation set for both models.
    *   Perform **Soft Voting** by averaging the probabilities.
    *   Calculate the final F1 score using the ensemble predictions.
    *   **Crucial Step**: Print `Final Validation Metric: <value>`.

5.  **Failure Analysis**:
    *   Calculate the mean absolute error (MAE) per sample between the ensemble predictions and ground truth.
    *   Extract metadata features (file size, width, height, aspect ratio) for the validation images.
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify systematic failures.

6.  **Submission**:
    *   Check if the `Final Validation Metric` > `0.9228752356223593`.
    *   If the condition is met:
        *   Load the test metadata.
        *   Generate predictions using the ensemble (averaging probabilities) with Test Time Augmentation (TTA) enabled via `predict`.
        *   Convert probabilities to labels (threshold 0.5) and save to `submission.csv`.
