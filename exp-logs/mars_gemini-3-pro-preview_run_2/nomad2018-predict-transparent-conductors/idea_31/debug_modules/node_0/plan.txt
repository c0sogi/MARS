This script demonstrates the usage of the provided library files for the Crystal Graph Network task. It performs the following steps:
1.  **Configuration**: Modifies the global `Config` to use a temporary working directory and reduced hyperparameters for a quick demonstration.
2.  **Data Preparation**: Creates a small subset of the metadata files to ensure data loading and processing runs quickly.
3.  **Data Loading**: Instantiates the `CrystalGraphDataset` and `DataLoader` to verify data processing pipeline.
4.  **Model Initialization**: Instantiates the `SRACGN` model and verifies the forward pass on a sample batch.
5.  **Training Loop**: Executes a short training run (2 epochs) using the training utilities, including scaler fitting and optimization.
6.  **Checkpointing**: Demonstrates saving and loading model checkpoints.
7.  **Inference**: Generates predictions on the test subset and verifies the output format.
