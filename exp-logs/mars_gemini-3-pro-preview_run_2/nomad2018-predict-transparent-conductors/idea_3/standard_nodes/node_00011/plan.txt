Here is the implementation of the orchestration script `runfile.py`.

**Implementation Strategy:**
1.  **Setup**: Initialize the environment, set random seeds for reproducibility, and configure the device (GPU/CPU).
2.  **Configuration Override**: Modify `Config.NUM_EPOCHS` to a lower value (30) to ensure the baseline training completes quickly within the time constraints while still allowing convergence.
3.  **Training**: Call `library.engine.run_training` to train the Distance-Biased Graph Transformer (DB-GT). This handles data loading, model training, and checkpointing the best model based on validation RMSLE.
4.  **Validation & Failure Analysis**:
    *   Load the validation dataset and the best saved model checkpoint.
    *   Run inference on the validation set to get predictions.
    *   Compute the **Final Validation Metric** (Column-wise RMSLE) and print it in the required format.
    *   Calculate sample-wise errors (mean absolute log error).
    *   Load the validation metadata to retrieve tabular features (e.g., lattice parameters, compositions).
    *   Compute and print Pearson correlations between the error magnitude and these features to identify potential failure modes.
5.  **Submission**: Compare the calculated validation metric against the threshold (0.053007537912991315). If the metric is lower, call `library.engine.generate_submission` to create the `submission.csv` file for the test set.
