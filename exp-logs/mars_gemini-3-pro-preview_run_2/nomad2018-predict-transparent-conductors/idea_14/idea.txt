Based on the lessons learned from previous experiments, I propose the **Crystal Graph Convolutional Network with Inverted Bottleneck FFN (CGCNN-IB)**.

This strategy addresses the identified need for higher model capacity (Lesson 00039) without increasing the graph interaction radius (which introduces noise, Lesson 00007) or using unstable global conditioning mechanisms (Lesson 00022). By interleaving the established Gated Graph Convolutions with node-wise Feed-Forward Networks (FFNs), we deepen the non-linear processing of local chemical environments while preserving the successful inductive biases of the CGCNN backbone.

### Model
The architecture is a Message Passing Graph Neural Network designed as follows:

1.  **Embeddings:**
    *   **Nodes:** Atomic numbers are mapped to learnable embeddings of dimension **128**. This width is retained to prevent the underfitting observed with smaller embeddings (Cite solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static Gaussian Radial Basis Function (RBF) filter with **60 bins** (Cite solution_lesson_node_00005). Crucially, these RBF features are projected into the 128-dimensional space using a learnable **Linear layer** before entering the convolution (Cite solution_lesson_node_00042).

2.  **Interaction Backbone:**
    *   The network consists of **4 Interaction Blocks** (Cite solution_lesson_node_00006).
    *   **Gated Convolution:** Each block begins with a `CGConv` layer, which uses edge features to gate the flow of information between neighbors. This provides the strong physical inductive bias required for crystal systems (Cite solution_lesson_node_00011, solution_lesson_node_00018).
    *   **Inverted Bottleneck FFN (Structural Innovation):** Following the convolution and Batch Normalization, the node features are processed by a node-wise Feed-Forward Network. This MLP projects the features to a higher dimension (e.g., 128 $\to$ 256) and back (256 $\to$ 128) with non-linear activations. This allows the model to learn complex combinations of the aggregated local features *before* mixing them with the residual, effectively increasing the "chemical reasoning" capacity per layer without expanding the graph receptive field.
    *   **Residual Connection:** The input to the block is added to the output of the FFN.
    *   **Activation:** A **Softplus** activation function is applied *after* the residual addition to ensure non-linear state updates (Cite solution_lesson_node_00041).

3.  **Readout:**
    *   **Pooling:** Updated node features are aggregated into a graph vector using **Global Mean Pooling**. This parameter-free method is preferred for intensive properties like formation energy (Cite solution_lesson_node_00033).
    *   **Decoupled Heads:** The pooled vector is fed into two separate, independent MLPs to predict `formation_energy_ev_natom` and `bandgap_energy_ev`, preventing task interference (Cite solution_lesson_node_00039).

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (e.g., using `ase.neighborlist`) to correctly model the infinite crystal lattice (Cite solution_lesson_node_00009).
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å**. This captures the relevant local bonding environment while filtering out noise from distant, weakly interacting atoms (Cite solution_lesson_node_00007).
3.  **Normalization:** Target variables are standardized (zero mean, unit variance) to ensure balanced gradients during training.

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization, which is critical for generalization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the FFN and prediction heads.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on the standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs using the same 5.0 Å cutoff and edge encoding.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
