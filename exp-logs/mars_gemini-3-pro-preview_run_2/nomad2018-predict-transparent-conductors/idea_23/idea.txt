Based on the lessons learned from previous experiments, I propose the **Species-Weighted Receiver-Aware Crystal Graph Network (SW-RA-CGN)**.

This strategy introduces a structural evolution in the graph readout mechanism while consolidating the most effective components identified for the interaction backbone. It addresses the limitation of standard Global Mean Pooling (which treats all atoms as equally important contributors to intensive properties) by introducing **Species-Weighted Pooling**. This allows the model to learn scalar importance weights for each element type (Al, Ga, In, O), enabling it to prioritize the sub-lattices most relevant to the target properties (e.g., metal vs. oxygen sites) without the optimization instability or data hunger of full Attention Pooling.

### Model
The architecture is a Message Passing Graph Neural Network designed as follows:

1.  **Embeddings & Shared Projection:**
    *   **Nodes:** Atoms are embedded into **128-dimensional** vectors based on their atomic number (Cite solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static **60-bin Gaussian RBF** filter (Cite solution_lesson_node_00005). Crucially, these RBF features are projected into the 128-dimensional space using a **Shared Linear Layer** across all interaction blocks (Cite solution_lesson_node_00076). This acts as a structural regularizer, ensuring a consistent geometric interpretation throughout the network.

2.  **Receiver-Aware Interaction Backbone:**
    *   The network consists of **4 Interaction Blocks** (Cite solution_lesson_node_00006).
    *   **Receiver-Aware Message Passing:** Instead of the standard convolution, we use a custom message function that explicitly concatenates the **Source Node ($h_j$), Target Node ($h_i$), and Edge Feature ($e_{ij}$)**: $z_{ij} = [h_i || h_j || e_{ij}]$. This input is processed by a Gated MLP to generate messages, allowing the model to capture specific pairwise chemical interactions (e.g., how Ga affects O vs. how Al affects O) which standard layers miss (Cite solution_lesson_node_00072).
    *   **Learnable Scalar Residuals:** The node update rule is $h_{l+1} = \text{Softplus}(\text{BatchNorm}(\text{Agg}(m_{ij}) + (1 + \epsilon_l) \cdot h_l))$. The scalar $\epsilon_l$ is a learnable parameter initialized to 0. This allows the network to dynamically learn to amplify the identity path (preserving stoichiometric signal) where beneficial, synthesizing the performance of "Amplified Residuals" with the stability of standard connections (Cite solution_lesson_node_00060, solution_lesson_node_00054, solution_lesson_node_00065).

3.  **Species-Weighted Readout (Structural Innovation):**
    *   Instead of standard Global Mean Pooling ($\frac{1}{N}\sum h_i$), we implement **Species-Weighted Pooling**:
        $$ h_{graph} = \frac{1}{N} \sum_{i=1}^{N} \sigma(w_{Z_i}) \cdot h_i $$
    *   Here, $w_{Z_i}$ is a learnable scalar weight associated with the atomic number $Z_i$ of atom $i$, and $\sigma$ is a sigmoid or softplus activation to ensure positivity. This allows the model to weigh the contributions of different chemical species (e.g., upweighting cations for bandgap prediction) while maintaining the robustness of mean pooling (Cite solution_lesson_node_00033).
    *   **Decoupled Heads:** The pooled vector is fed into two separate, independent MLPs to predict `formation_energy_ev_natom` and `bandgap_energy_ev` (Cite solution_lesson_node_00039).

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This ensures the graph captures high-signal local bonds without introducing noise from distant neighbors.
3.  **Normalization:** Target variables are standardized (zero mean, unit variance) to ensure balanced gradients. We exclude explicit global features to avoid optimization interference (Cite solution_lesson_node_00022).

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks and prediction heads.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise for generalization (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs using the same 5.0 Å cutoff and edge encoding.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
