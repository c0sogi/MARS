Based on the comprehensive analysis of previous experiments and the lessons learned, I propose the **k-Nearest Neighbor Receiver-Aware Crystal Graph Network (k-RA-CGN)**.

This strategy introduces a fundamental change to the graph topology construction (switching from Radius-based to k-Nearest Neighbor) while synthesizing the most effective architectural components identified in the lessons (Receiver-Awareness, Shared Geometric Projections, and Learnable Residuals). This approach addresses the issue of "noise injection" from distant neighbors in dense radius graphs while maximizing the model's ability to capture specific pairwise chemical interactions and preserving stoichiometric signal.

### Model
The architecture is a Message Passing Graph Neural Network designed as follows:

1.  **Graph Topology (Structural Innovation):**
    *   Unlike previous iterations that used a fixed radius cutoff (e.g., 5.0 Å), we construct the graph using a **k-Nearest Neighbor (k-NN)** algorithm with **$k=12$**, respecting Periodic Boundary Conditions (PBC).
    *   **Rationale:** Lesson 7 and Lesson 78 highlighted that fixed-radius graphs can include many distant, weakly interacting neighbors, introducing noise that dilutes the local chemical signal. Constraining the graph to the 12 nearest neighbors ensures the model focuses on the primary coordination shell, maintaining a consistent signal-to-noise ratio regardless of lattice density.

2.  **Embeddings & Shared Projection:**
    *   **Nodes:** Atoms are embedded into **128-dimensional** vectors (Cite solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static **60-bin Gaussian RBF** filter (Cite solution_lesson_node_00005).
    *   **Shared Projection:** These RBF features are projected into the 128-dimensional space using a **Shared Linear Layer** across all interaction blocks. This acts as a structural regularizer, enforcing a consistent geometric interpretation throughout the network depth (Cite solution_lesson_node_00076).

3.  **Receiver-Aware Interaction Backbone:**
    *   The network consists of **4 Interaction Blocks** (Cite solution_lesson_node_00006).
    *   **Receiver-Aware Message Passing:** We employ a custom gated convolution where the message generation is conditioned on the concatenation of the **Source Node ($h_j$), Target Node ($h_i$), and Edge Feature ($e_{ij}$)**: $z_{ij} = [h_i || h_j || e_{ij}]$. This allows the model to capture asymmetric pairwise interactions (e.g., the specific effect of neighbor $j$ on central atom $i$) which standard source-only convolutions miss (Cite solution_lesson_node_00072).
    *   **Learnable Scalar Residuals:** The node update rule is $h_{l+1} = \text{Softplus}(\text{BatchNorm}(\text{Agg}(m_{ij}) + (1 + \epsilon_l) \cdot h_l))$. The scalar $\epsilon_l$ is a learnable parameter initialized to 0. This dynamically tunes the preservation of atomic identity (stoichiometry) versus geometric updates, ensuring stability while preventing oversmoothing (Cite solution_lesson_node_00060, solution_lesson_node_00065).

4.  **Readout:**
    *   **Pooling:** We use **Global Mean Pooling** to aggregate node features. This is robust for intensive properties like formation energy (Cite solution_lesson_node_00033).
    *   **Decoupled Heads:** The pooled vector is fed into two separate, independent MLPs to predict `formation_energy_ev_natom` and `bandgap_energy_ev` (Cite solution_lesson_node_00039).

### Data
1.  **Preprocessing:** For each structure, compute the 12 nearest neighbors for every atom using a PBC-aware k-d tree or neighbor list algorithm. This defines the edge connectivity.
2.  **Feature Engineering:** Extract atomic numbers for node initialization and interatomic distances for edge features. We explicitly **exclude** global features (lattice/composition) to avoid optimization interference (Cite solution_lesson_node_00022).
3.  **Normalization:** Target variables are standardized (zero mean, unit variance) to ensure balanced gradients.

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into k-NN graphs ($k=12$) with PBC and shared edge encodings.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
