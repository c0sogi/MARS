Based on the lessons learned from the previous experiments, I propose the **Learnable-Residual Crystal Graph Network (LR-CGCNN) with Dual-Pooling Readout**.

This strategy introduces a structural evolution to the standard residual connection within the GNN blocks. It synthesizes the finding that "Amplified Residuals" ($2x+m$) improve generalization by preserving atomic identity (Lesson 54) with the stability warnings regarding non-unit scaling (Lesson 55). By making the residual weight a learnable parameter initialized to a stable value, the model can dynamically optimize the balance between preserving stoichiometric information and integrating geometric messages. Additionally, the readout architecture is enhanced to capture both average and extremal graph features.

### Model
The architecture is a Message Passing Graph Neural Network with the following design:

1.  **Backbone (CGCNN):** We retain the **Crystal Graph Convolutional Neural Network** layers as the core processing unit. This leverages the **Gated Convolution** mechanism (Cite solution_lesson_node_00011, solution_lesson_node_00018) where edge features modulate the message content, providing the necessary physical inductive bias.
2.  **Structural Innovation: Learnable Residuals ($\epsilon$-Residual):**
    *   Standard ResNets use $h_{l+1} = \sigma(h_l + \text{Message})$.
    *   We modify the update rule to:
        $$ h_{l+1} = \text{Softplus}(\text{BatchNorm}(\text{Message}(h_l, e_{ij}) + (1 + \epsilon) \cdot h_l)) $$
    *   Here, $\epsilon$ is a **learnable scalar parameter** (one per layer), initialized to 0.0. This allows the network to start with stable unit-scaling (Lesson 55) but learn to amplify the identity path ($1+\epsilon > 1$) if preserving atomic identity is beneficial for the task (Lesson 54), effectively automating the "Amplified Residual" insight without forcing instability.
3.  **Embeddings & Projection:**
    *   **Nodes:** Atoms are embedded into **192-dimensional** vectors. This increased width (up from 128) ensures sufficient capacity to model complex interactions without bottlenecking, addressing potential underfitting (Cite solution_lesson_node_00005, solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static **60-bin Gaussian RBF** filter (Cite solution_lesson_node_00005) and projected into the node dimension via a **Linear Layer** before convolution (Cite solution_lesson_node_00042).
4.  **Dual-Pooling Readout:**
    *   Instead of relying solely on Mean Pooling, the final node representations are aggregated using **both Global Mean Pooling and Global Max Pooling**.
    *   These two vectors are concatenated. Mean pooling captures intensive properties (averages), while Max pooling captures salient local features (e.g., specific defects or dominant motifs). This provides a richer graph summary than Mean alone (Cite solution_lesson_node_00033).
5.  **Decoupled Heads:** The concatenated pooling output is fed into two separate, independent MLPs to predict `formation_energy_ev_natom` and `bandgap_energy_ev` (Cite solution_lesson_node_00039).

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This ensures the graph captures high-signal local bonds without introducing noise from distant neighbors.
3.  **Target Normalization:** Target variables are standardized (zero mean, unit variance) to ensure balanced gradients.

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise for generalization (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs using the same 5.0 Å cutoff and edge encoding.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
