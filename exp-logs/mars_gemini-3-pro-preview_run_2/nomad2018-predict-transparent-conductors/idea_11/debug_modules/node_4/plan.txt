The issue is that PyTorch 2.6+ enforces `weights_only=True` by default in `torch.load` for security reasons, which prevents loading checkpoints containing arbitrary Python objects like NumPy arrays (used in `StandardScaler`). To fix the `_pickle.UnpicklingError`, I will explicitly set `weights_only=False` in all `torch.load` calls within `library/data.py`, `library/utils.py`, `library/train.py`, and `runfile.py`, as these files are generated locally and are trusted. This applies **Cite debug_lesson_5**.
