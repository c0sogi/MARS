The `numpy.exceptions.AxisError` occurs because `ase.neighborlist.neighbor_list` returns an empty 1D array for the distance vectors `d` when no neighbors are found within the cutoff radius. Consequently, `np.linalg.norm(d, axis=1)` fails because the array lacks a second dimension. To fix this, we will modify `library/data.py` to request scalar distances (`'D'`) directly from `neighbor_list` instead of distance vectors (`'d'`). This leverages the library's internal calculation which handles empty cases correctly and simplifies the code.
