Based on the lessons learned and the analysis of previous attempts, I propose the **Virtual-Node Augmented Crystal Graph Convolutional Network (VN-CGCNN)**.

This solution structurally evolves the successful Crystal Graph Convolutional Neural Network (CGCNN) by introducing a **Virtual Node** mechanism. This addresses the model's limitation in capturing global properties (like composition and lattice strain) which are highly correlated with the targets, while avoiding the optimization pitfalls of previous global conditioning attempts (FiLM) and maintaining the strong inductive bias of local message passing.

### Model
The architecture consists of two interacting graph levels: the **Atomic Graph** (local) and a **Virtual Node** (global).

1.  **Node Embeddings**: Atoms are embedded into a 64-dimensional vector based on their atomic number (Cite solution_lesson_node_00004).
2.  **Edge Embeddings**: Interatomic distances are expanded using a static Gaussian Radial Basis Function (RBF) filter with 60 bins (Cite solution_lesson_node_00002, solution_lesson_node_00005).
3.  **Virtual Node Initialization**: A single global node is initialized by projecting a vector of **Global Features** (Lattice Vectors, Lattice Angles, and Atomic Composition fractions) via an MLP. Crucially, these features must be **Standardized** (Z-score) before projection to prevent gradient instability (Cite solution_lesson_node_00021).
4.  **Interaction Blocks**: The model uses **4 interaction blocks** (Cite solution_lesson_node_00006). In each block, three distinct updates occur:
    *   **Atom-to-Virtual**: The Virtual Node aggregates features from all atoms (e.g., via Sum Pooling) and updates its state. This allows the model to dynamically build a global representation of the crystal state.
    *   **Virtual-to-Atom**: The updated Virtual Node feature is added (broadcast) to every atom's feature vector. This distributes global context (e.g., "this is an Indium-rich crystal") to local sites without the restrictive multiplicative modulation of FiLM (addressing solution_lesson_node_00022).
    *   **Atom-to-Atom**: Standard **CGCNN Convolutions** are performed, where messages between neighbors are gated by the RBF edge features (Cite solution_lesson_node_00018). We strictly avoid dynamic edge updates (Cite solution_lesson_node_00008).
5.  **Readout**: The final prediction is generated by concatenating the final Virtual Node state with the Mean-Pooled representation of the Atomic Graph, passed through a regression MLP.

### Data
1.  **Graph Construction**: We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to construct the graph.
2.  **Cutoff Radius**: The neighbor cutoff is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This preserves the high signal-to-noise ratio of local chemical bonds, relying on the Virtual Node to handle long-range/global dependencies instead of a larger radius.
3.  **Global Feature Engineering**: For each crystal, we extract the 3 lattice lengths, 3 lattice angles, and the fractional composition of the 4 elements (Al, Ga, In, O). These 10 features are **Standardized** using the training set statistics (Cite solution_lesson_node_00021).
4.  **Target Normalization**: Target variables are standardized to zero mean and unit variance.

### Training
1.  **Optimizer**: **AdamW** is used to decouple weight decay from gradient updates, enhancing generalization (Cite solution_lesson_node_00019).
2.  **Regularization**: We apply **Dropout (0.1)** within the update blocks and a **Weight Decay of 1e-4** to prevent overfitting on this small dataset (Cite solution_lesson_node_00003).
3.  **Batch Size**: A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function**: Mean Squared Error (MSE).

### Evaluation
1.  **Inference**: Test set geometries are processed into PBC-aware graphs and standardized global feature vectors.
2.  **Prediction**: The model predicts standardized targets, which are inverse-transformed using the training set's mean and standard deviation to produce the final `formation_energy_ev_natom` and `bandgap_energy_ev`.
