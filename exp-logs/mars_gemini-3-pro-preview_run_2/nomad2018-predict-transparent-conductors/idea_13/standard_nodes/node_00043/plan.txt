This solution implements the **Pre-Activated Crystal Graph ResNet**, a deep graph neural network designed to capture non-linear atomic interactions for precise property prediction. It orchestrates the entire pipeline from data loading and model training to validation assessment, failure analysis, and conditional submission generation.

The implementation leverages the provided library modules to construct a robust workflow. It uses a **TargetScaler** to normalize regression targets, ensuring stable gradients. The training loop runs for **30 epochs** to provide a fast yet effective baseline, utilizing **AdamW** optimization and **ReduceLROnPlateau** scheduling. The final validation metric is computed as the mean of the column-wise Root Mean Squared Logarithmic Error (RMSLE). Failure analysis is performed by correlating prediction errors with material properties to identify potential weaknesses. Finally, a submission file is generated if the model's performance meets the specified threshold.
