This script demonstrates the usage of the provided library modules (`config`, `utils`, `data`, `model`, `train`) by creating a small-scale demo run. It performs the following steps:

1.  **Configuration Override**: It modifies the `Config` class to use a temporary working directory and reduces hyperparameters (epochs, batch size, model dimensions) to ensure the script executes quickly.
2.  **Data Preparation**: It creates tiny subsets of the training, validation, and test metadata (20, 10, and 10 samples respectively) to speed up the data loading and graph construction process.
3.  **Data Loading**: It utilizes `get_loaders` to process the geometry files referenced in the metadata, construct PyTorch Geometric graphs, and create DataLoaders. It verifies the structure and shapes of the loaded batches.
4.  **Model Instantiation**: It initializes the `RAGLUNet` model and performs a forward pass with a sample batch to verify input/output dimensions.
5.  **Utility Testing**: It tests helper classes like `RBFExpansion` and metric calculation functions.
6.  **Training Loop**: It initializes the `Trainer` class and runs a short training session (2 epochs) on the subset data, verifying that model checkpoints are saved.
7.  **Inference**: It runs predictions on the test subset using the trained model and generates a sample submission file.
