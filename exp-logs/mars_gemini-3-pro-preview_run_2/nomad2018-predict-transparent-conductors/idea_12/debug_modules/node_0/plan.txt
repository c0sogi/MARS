This script demonstrates the end-to-one workflow using the provided library. It performs the following steps:
1.  **Configuration**: Patches the library configuration to use a temporary demo directory and a small subset of data for speed.
2.  **Utilities Verification**: Validates the scaler classes and graph construction function.
3.  **Data Loading**: Processes the metadata, loads geometry files, builds graphs, and creates DataLoaders (using the patched debug size).
4.  **Model Initialization**: Instantiates the `ACSRNet` model and verifies the forward pass.
5.  **Training**: Runs a short training loop (2 epochs) to demonstrate the training process and checkpointing.
6.  **Prediction**: Generates predictions on the test set using the trained model.
