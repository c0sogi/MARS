This script demonstrates the end-to-end usage of the provided machine learning pipeline for crystal property prediction. It first configures a separate demo environment to avoid conflicts with existing runs. Then, it validates individual data processing components like geometry reading, feature extraction, and graph construction. It proceeds to instantiate the custom PyTorch dataset and data loaders, verifying batch collation. The core model architecture, `DualStreamNet`, is initialized and tested with a forward pass. Finally, the script executes a complete training cycle using the `run_training` engine with a small subset of data for speed, followed by generating a submission file to confirm the inference pipeline works correctly.
