Based on the comprehensive analysis of previous experiments and the accumulated lessons, I propose the **Dual-Stream Geometric-Compositional Network with Late Fusion**.

This strategy is a structural evolution designed to leverage the strong correlations between global crystal properties (lattice, composition) and target variables, while strictly isolating this global information from the local message-passing process to avoid the optimization interference observed with FiLM and Virtual Nodes.

### Model
The architecture consists of two parallel processing streams that converge only at the final readout stage:

1.  **Local Geometric Stream (Backbone):**
    *   **Architecture:** We retain the **Crystal Graph Convolutional Neural Network (CGCNN)**. This architecture employs **Gated Convolutions** where edge features modulate the content of messages, providing a necessary physical inductive bias that outperformed Graph Transformers and dynamic edge updates (Cite solution_lesson_node_00011, solution_lesson_node_00018).
    *   **Configuration:** The backbone will consist of **4 interaction layers** with a hidden dimension of **64**. This compact configuration is optimized for the small vocabulary and dataset size to prevent overfitting (Cite solution_lesson_node_00004, solution_lesson_node_00006).
    *   **Aggregation:** We explicitly use **Global Mean Pooling** instead of Attention Pooling. Mean pooling enforces the physical prior that intensive properties (like formation energy per atom) are averages of local environments, which has proven more robust than learnable pooling on this dataset (Cite solution_lesson_node_00033).

2.  **Global Compositional Stream:**
    *   **Input:** A vector containing the **6 Lattice Parameters** (lengths $a, b, c$ and angles $\alpha, \beta, \gamma$) and the **4 Atomic Composition Fractions** (Al, Ga, In, O).
    *   **Processing:** A dedicated **Multi-Layer Perceptron (MLP)** processes these features into a latent global embedding. This stream captures macroscopic strain and stoichiometry directly.

3.  **Late Fusion:**
    *   The output vectors from the Local Stream and the Global Stream are **concatenated**.
    *   This combined vector is passed through a final regression MLP to predict the targets. This approach avoids the "noise injection" effect seen when global features modulate local nodes (Cite solution_lesson_node_00022) or when virtual nodes aggregate over long distances (Cite solution_lesson_node_00025).

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This ensures the graph captures only high-signal local bonds, leaving long-range dependencies to the Global Stream.
3.  **Feature Engineering:**
    *   **Edges:** Interatomic distances are encoded using a static **60-bin** Gaussian Radial Basis Function (RBF) expansion (Cite solution_lesson_node_00002, solution_lesson_node_00005).
    *   **Global Features:** The lattice and composition features must be **Standardized** (Z-score normalization) using training set statistics. This is critical to ensure stable gradient flow in the Global Stream (Cite solution_lesson_node_00021).
4.  **Target Normalization:** Target variables are standardized to zero mean and unit variance.

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** in both streams.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise for generalization (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE).

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs and standardized global feature vectors.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
