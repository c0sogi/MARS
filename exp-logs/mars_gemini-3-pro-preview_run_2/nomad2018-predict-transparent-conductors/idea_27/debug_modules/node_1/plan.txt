The issue is that `ase.io.read` infers the file format from the `.xyz` extension, which corresponds to the standard XYZ format. However, the provided geometry files contain FHI-aims formatted data (indicated by `lattice_vector` and `atom` keywords), causing parsing failures for all files and resulting in an empty dataset. To fix this, I will explicitly pass `format='aims'` to `ase.io.read` in `library/data.py`, forcing the correct parser regardless of the file extension.
