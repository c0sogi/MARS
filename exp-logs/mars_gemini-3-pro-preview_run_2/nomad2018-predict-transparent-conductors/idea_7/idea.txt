Based on the lessons learned from previous experiments, I propose the **Dual-Stream Geometric-Compositional Network (DS-GCN)**.

This solution represents a structural evolution that addresses the limitations of previous global-conditioning attempts (FiLM, Virtual Nodes) by decoupling the processing of local geometric interactions and global crystal properties into separate streams. This allows the model to leverage the strong inductive bias of the CGCNN for local chemistry while simultaneously utilizing the highly correlated global features (lattice parameters, composition) identified in the data analysis, without the optimization interference observed when mixing these signals during message passing.

### Model
The architecture consists of two parallel processing streams that merge at the final readout stage:

1.  **Local Geometric Stream (The Backbone):**
    *   This stream retains the successful **Crystal Graph Convolutional Neural Network (CGCNN)** architecture (Cite solution_lesson_node_00011).
    *   **Nodes:** Atoms are embedded into **64-dimensional** vectors (Cite solution_lesson_node_00004).
    *   **Edges:** Interatomic distances are encoded using a static **Radial Basis Function (RBF)** expansion with **60 bins** (Cite solution_lesson_node_00002, solution_lesson_node_00005). We strictly avoid dynamic edge updates (Cite solution_lesson_node_00008).
    *   **Layers:** The stream consists of **4 Gated Convolution blocks** (Cite solution_lesson_node_00006). These layers use edge features to modulate both the content and strength of messages (Cite solution_lesson_node_00018).
    *   **Pooling:** A global **Mean Pooling** operation aggregates the updated node features into a graph embedding vector.

2.  **Global Compositional Stream:**
    *   This stream is a **Multi-Layer Perceptron (MLP)** designed to capture macroscopic properties.
    *   **Input:** A vector containing the **6 Lattice Parameters** (lengths $a, b, c$ and angles $\alpha, \beta, \gamma$) and the **4 Atomic Composition Fractions** (Al, Ga, In, O).
    *   **Processing:** This vector is processed by a series of dense layers with non-linearities to extract a global context embedding.

3.  **Late Fusion:**
    *   The graph embedding from the Local Stream and the context embedding from the Global Stream are **concatenated**.
    *   This combined vector is passed through a final regression MLP to predict `formation_energy_ev_natom` and `bandgap_energy_ev`. This "Late Fusion" strategy avoids the noise and oversmoothing issues observed when injecting global info into local message passing (Cite solution_lesson_node_00022, solution_lesson_node_00025).

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to construct the atom graph.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007) to preserve the high signal-to-noise ratio of local bonds.
3.  **Global Feature Engineering:** The 10 global features (lattice + composition) are extracted for each crystal. Crucially, these features are **Standardized** (Z-score normalization) based on training set statistics to ensure stable gradient flow in the MLP stream (Cite solution_lesson_node_00021).
4.  **Target Normalization:** Target variables are standardized to zero mean and unit variance.

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** in both the GCN blocks and the MLP stream.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise for generalization (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE).

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs and standardized global feature vectors.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
