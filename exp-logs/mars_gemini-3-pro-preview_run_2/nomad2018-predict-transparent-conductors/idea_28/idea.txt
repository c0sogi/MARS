Based on the lessons learned, I propose the **Stabilized Receiver-Aware Crystal Graph Network (S-RA-CGN)**.

This solution represents a structural evolution that synthesizes the superior pairwise interaction modeling of **Receiver-Awareness** with a rigorously stabilized **Adaptive Residual** mechanism. It directly addresses the "signal collapse" observed in previous iterations (Lesson 90) by correcting the normalization order, while retaining the strong inductive biases of gated convolutions and shared geometric projections that have consistently outperformed other approaches.

### Model

1.  **Embeddings & Shared Projection:**
    *   **Nodes:** Atoms are embedded into **128-dimensional** vectors based on their atomic number (Cite solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static **60-bin Gaussian Radial Basis Function (RBF)** filter (Cite solution_lesson_node_00005).
    *   **Shared Projection:** These high-dimensional RBF features are projected into the 128-dimensional node space using a single **Shared Linear Layer** reused across all interaction blocks. This acts as a structural regularizer, enforcing a consistent geometric interpretation throughout the network depth (Cite solution_lesson_node_00076).

2.  **Receiver-Aware Interaction Backbone:**
    *   The network consists of **4 Interaction Blocks** (Cite solution_lesson_node_00006).
    *   **Receiver-Aware Gated Convolution:** We employ a custom message-passing function where the input is the concatenation of the **Target Node ($h_i$), Source Node ($h_j$), and Edge Feature ($e_{ij}$)**: $z_{ij} = [h_i || h_j || e_{ij}]$. This explicitly models the asymmetric effect of a neighbor on the central atom (Cite solution_lesson_node_00072).
    *   **Non-Linear Gating:** The message is computed as $m_{ij} = \text{Softplus}(\text{Linear}_1(z_{ij})) \odot \text{Sigmoid}(\text{Linear}_2(z_{ij}))$. Using **Softplus** for the content signal is retained as it outperforms linear GLUs for modeling potential energy surfaces (Cite solution_lesson_node_00088).

3.  **Sum-Normalized Adaptive Residual Block (Structural Innovation):**
    *   We implement a specific residual block structure to solve the stability-accuracy trade-off.
    *   The update rule is: $h_{l+1} = \text{Softplus}(\text{BatchNorm}(\text{Agg}(m_{ij}) + (1 + \epsilon_l) \cdot h_l))$.
    *   **Adaptive Identity:** $\epsilon_l$ is a learnable scalar parameter initialized to 0. This allows the network to dynamically learn to amplify the identity path (preserving stoichiometric signal) where beneficial (Cite solution_lesson_node_00060).
    *   **Correct Normalization:** Crucially, **Batch Normalization is applied to the sum** of the convolution output and the residual connection. This ensures that the strong residual signal does not bypass normalization and dominate the structural updates, preventing the "signal collapse" observed in previous attempts (Cite solution_lesson_node_00090).

4.  **Readout:**
    *   **Pooling:** We use **Global Mean Pooling** to aggregate node features. This parameter-free method aligns with the intensive nature of the target properties (Cite solution_lesson_node_00033).
    *   **Decoupled Heads:** The pooled vector is fed into two separate, independent MLPs to predict `formation_energy_ev_natom` and `bandgap_energy_ev` (Cite solution_lesson_node_00039).

### Data

1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). We prioritize a clean Radius Graph over k-NN to preserve local density information (Cite solution_lesson_node_00081).
3.  **Feature Selection:** We explicitly **exclude** auxiliary global features (lattice/composition) to avoid optimization interference (Cite solution_lesson_node_00022).
4.  **Normalization:** Target variables are standardized (zero mean, unit variance).

### Training

1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks and prediction heads to prevent overfitting (Cite solution_lesson_node_00089).
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.
5.  **Scheduler:** A `ReduceLROnPlateau` scheduler is used to anneal the learning rate (Cite solution_lesson_node_00083).

### Evaluation

1.  **Inference:** Test set structures are processed into PBC-aware graphs using the same 5.0 Å cutoff and shared edge encoding.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
