Based on the comprehensive analysis of previous experiments and the specific lessons learned, I propose the **Dual-Stream Late-Fusion CGCNN**.

This strategy addresses the key failure mode of previous global-conditioning attempts (FiLM, Virtual Nodes) where injecting global information directly into the message-passing loop disrupted the learning of local chemical interactions. Instead, this architecture processes local geometric data and global crystal properties in separate streams, fusing them only at the final readout stage. This allows the model to leverage the strong inductive bias of the CGCNN for local bonds while simultaneously utilizing the highly correlated global features (lattice, composition) identified in the data analysis.

### Model
The architecture consists of two parallel branches that merge before the final prediction:

1.  **Local Graph Stream (Backbone):**
    *   **Architecture:** We retain the **Crystal Graph Convolutional Neural Network (CGCNN)** structure. It uses **Gated Convolutions** where messages are modulated by edge features, providing the necessary physical inductive bias that outperformed Graph Transformers and dynamic edge updates (Cite solution_lesson_node_00011, solution_lesson_node_00018).
    *   **Configuration:** The backbone will have **4 interaction layers** with a hidden dimension of **64** to prevent overfitting on this small-vocabulary dataset (Cite solution_lesson_node_00004, solution_lesson_node_00006).
    *   **Aggregation:** We replace simple mean pooling with **Global Attention Pooling**. This allows the network to learn a weighted sum of atomic environments, filtering out noise from less relevant sites, which is crucial given the sensitivity to graph density (Cite solution_lesson_node_00007).

2.  **Global Feature Stream:**
    *   **Input:** A vector containing **Lattice Parameters** (3 lengths, 3 angles) and **Atomic Composition** (fractions of Al, Ga, In, O).
    *   **Architecture:** A dedicated **Multi-Layer Perceptron (MLP)** processes these features into a latent global embedding. This isolates the global signal processing, preventing the optimization issues seen when mixing these scales in FiLM layers (Cite solution_lesson_node_00022).

3.  **Fusion & Readout:**
    *   The output of the Graph Stream (local context) and the Global Stream (global context) are **concatenated**.
    *   This combined vector is passed through specific MLP heads for each target (`formation_energy` and `bandgap`) to generate the final predictions.

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to ensure the graph correctly represents the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This preserves the high signal-to-noise ratio of local bonds, relying on the Global Stream to handle long-range macroscopic properties.
3.  **Feature Engineering:**
    *   **Edges:** Interatomic distances are encoded using a static **60-bin** Gaussian Radial Basis Function (RBF) expansion (Cite solution_lesson_node_00002, solution_lesson_node_00005).
    *   **Global Features:** Lattice parameters and composition fractions are extracted and **Standardized** (Z-score normalization) based on training set statistics. This is mandatory to ensure stable gradient flow in the Global Stream (Cite solution_lesson_node_00021).
4.  **Target Normalization:** Target variables are standardized to zero mean and unit variance.

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** in both streams.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise for generalization (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs and standardized global feature vectors.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
