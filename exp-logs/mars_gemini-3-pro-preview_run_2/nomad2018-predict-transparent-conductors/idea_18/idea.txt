Based on the lessons learned from previous experiments, I propose the **Lattice-Informed Crystal Graph Convolutional Network with Element-wise Learnable Residuals (LI-CGCNN-ELR)**.

This strategy introduces two key structural evolutions. First, it refines the "Learnable Residual" concept by making the scaling factor a **parameter vector** (element-wise) rather than a scalar. This allows the network to selectively preserve specific feature channels (e.g., those encoding stoichiometric identity) while allowing others to evolve with geometric updates, addressing the "oversmoothing" of atomic identity (Lesson 54) without the instability of fixed amplification (Lesson 55). Second, it implements a **Lattice-Specific Late Fusion** readout. Unlike previous attempts that fused all global features (including composition), this stream isolates **Lattice Parameters** (highly correlated with formation energy) to provide macroscopic strain context at the readout stage, while relying on the GNN to handle composition implicitly (Lesson 40), thus avoiding redundancy and optimization interference (Lesson 22).

### Model
The architecture is a dual-input Message Passing Neural Network:

1.  **Local Graph Backbone (CGCNN):**
    *   **Node Embeddings:** Atoms are embedded into **128-dimensional** vectors (Cite solution_lesson_node_00039).
    *   **Edge Encoding:** Interatomic distances are expanded using a static **60-bin Gaussian RBF** filter (Cite solution_lesson_node_00005) and projected into the node dimension via a **Linear Layer** before convolution (Cite solution_lesson_node_00042).
    *   **Interaction Layers:** The backbone consists of **4 Gated Convolution (CGConv)** blocks (Cite solution_lesson_node_00006).
    *   **Element-wise Learnable Residuals:** The update rule is modified to:
        $$ h_{l+1} = \text{Softplus}(\text{BatchNorm}(\text{CGConv}(h_l, e_{ij}) + (1 + \boldsymbol{\epsilon}) \odot h_l)) $$
        Here, $\boldsymbol{\epsilon} \in \mathbb{R}^{128}$ is a learnable parameter vector initialized to 0. This allows the model to learn channel-specific identity preservation rates, optimizing the trade-off between retaining stoichiometric signal and integrating geometric messages (Evolution of solution_lesson_node_00060).

2.  **Lattice Context Stream:**
    *   **Input:** A vector of the **6 Lattice Parameters** (lengths $a, b, c$ and angles $\alpha, \beta, \gamma$).
    *   **Processing:** These features are passed through a small MLP to generate a lattice embedding $h_{lat}$. This provides global strain and volume context that is hard to derive solely from local bond distances.

3.  **Readout:**
    *   **Pooling:** The final node features are aggregated via **Global Mean Pooling** to form $h_{graph}$ (Cite solution_lesson_node_00033).
    *   **Fusion:** $h_{graph}$ and $h_{lat}$ are concatenated.
    *   **Prediction:** The fused vector is passed to **two decoupled MLP heads** to predict `formation_energy_ev_natom` and `bandgap_energy_ev` independently (Cite solution_lesson_node_00039).

### Data
1.  **Graph Construction:** Graphs are constructed using a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009).
2.  **Local Constraints:** A neighbor cutoff radius of **5.0 Å** is strictly enforced to maintain a high signal-to-noise ratio for local interactions (Cite solution_lesson_node_00007).
3.  **Feature Engineering:**
    *   **Lattice Parameters:** Extracted and **Standardized** (Z-score) using training set statistics. This is mandatory for the Lattice Context Stream (Cite solution_lesson_node_00021).
    *   **Targets:** Target variables are standardized to zero mean and unit variance.

### Training
1.  **Optimizer:** **AdamW** is used to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs and standardized lattice vectors.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
