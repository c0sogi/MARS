Based on the comprehensive analysis of previous experiments and the accumulated lessons, I propose the **Scalar-Residual Crystal Graph Network with Dual-Pooling (SR-CGN-DP)**.

This strategy introduces a structural evolution designed to optimally balance the preservation of atomic identity (stoichiometry) with the integration of geometric updates. It synthesizes the success of "Amplified Residuals" (Lesson 00054) with the stability requirements of scalar scaling (Lesson 00065), while enhancing the readout mechanism to capture a broader range of structural features without introducing the optimization noise of explicit global conditioning.

### Model
The architecture is a Message Passing Graph Neural Network with the following design:

1.  **Backbone (CGCNN):** We retain the **Crystal Graph Convolutional Neural Network** layers as the core processing unit. This leverages the **Gated Convolution** mechanism (Cite solution_lesson_node_00011, solution_lesson_node_00018) where edge features modulate the message content, providing the necessary physical inductive bias.

2.  **Structural Innovation: Scalar Learnable Residuals:**
    *   Standard ResNets use $h_{l+1} = \sigma(h_l + \text{Message})$.
    *   Previous experiments showed that amplifying the residual ($2h_l$) improves generalization by preserving stoichiometry (Cite solution_lesson_node_00054) but causes instability (Cite solution_lesson_node_00055). Element-wise learnable scaling also failed due to instability (Cite solution_lesson_node_00065).
    *   **Our Solution:** We implement a **Scalar Learnable Residual** connection. The update rule is:
        $$ h_{l+1} = \text{Softplus}(\text{BatchNorm}(\text{CGConv}(h_l, e_{ij}) + (1 + \epsilon) \cdot h_l)) $$
    *   Here, $\epsilon$ is a **learnable scalar parameter** (one per layer), initialized to 0.0. This allows the network to start with stable unit-scaling but dynamically learn to amplify the identity path if preserving atomic identity is beneficial, effectively automating the "Amplified Residual" insight while maintaining the stability of scalar operations. The activation is explicitly placed *after* the residual addition (Cite solution_lesson_node_00041).

3.  **Embeddings & Projection:**
    *   **Nodes:** Atoms are embedded into **128-dimensional** vectors (Cite solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static **60-bin Gaussian RBF** filter (Cite solution_lesson_node_00005). Crucially, these RBF vectors are projected into the 128-dimensional node space using a learnable **Linear Layer** *before* being used in the convolution (Cite solution_lesson_node_00042).

4.  **Dual-Pooling Readout:**
    *   We replace simple Mean Pooling with a **concatenation of Global Mean Pooling and Global Max Pooling** (Cite solution_lesson_node_00060).
    *   Mean pooling captures intensive properties (averages) robustly (Cite solution_lesson_node_00033), while Max pooling captures salient local features (e.g., extreme bond lengths or defects). This provides a richer graph summary than Mean alone without the complexity of Attention pooling.
    *   **Decoupled Heads:** The concatenated vector (256-dim) is fed into two separate, independent MLPs to predict `formation_energy_ev_natom` and `bandgap_energy_ev` (Cite solution_lesson_node_00039).

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This ensures the graph captures high-signal local bonds without introducing noise from distant neighbors.
3.  **Implicit Global Features:** We explicitly **exclude** separate global feature streams (lattice/composition). We rely on the "Amplified" identity path to carry compositional information (Cite solution_lesson_node_00040) and the graph topology to encode lattice structure (Cite solution_lesson_node_00022), avoiding the optimization interference seen in previous fusion attempts.
4.  **Normalization:** Target variables are standardized (zero mean, unit variance).

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs using the same 5.0 Å cutoff and edge encoding.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
