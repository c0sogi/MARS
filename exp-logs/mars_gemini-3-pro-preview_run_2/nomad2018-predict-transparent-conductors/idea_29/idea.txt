Based on the accumulated lessons, I propose the **Linearly-Projected Receiver-Aware Crystal Graph Network (LP-RA-CGN)**.

This strategy represents a structural evolution that synthesizes the superior pairwise modeling of **Receiver-Awareness** (Lesson 00072) with a rigorous stabilization protocol derived from recent failures. Specifically, it addresses the "signal distortion" caused by non-linear edge encodings (Lesson 00095) and the "signal collapse" caused by improper normalization (Lesson 00090), while retaining the inductive biases that have consistently performed well.

### Model

1.  **Embeddings & Linear Edge Projection:**
    *   **Nodes:** Atoms are embedded into **128-dimensional** vectors based on their atomic number (Cite solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static **60-bin Gaussian Radial Basis Function (RBF)** filter (Cite solution_lesson_node_00005).
    *   **Structural Innovation:** These RBF features are projected into the 128-dimensional node space using a **Shared Linear Layer** (Cite solution_lesson_node_00076) with **No Activation Function** (Cite solution_lesson_node_00095). Previous attempts to apply non-linearities (like SiLU) here distorted the geometric signal; keeping this projection linear preserves the physical distance fidelity required for the message passing.

2.  **Receiver-Aware Interaction Backbone:**
    *   The network consists of **4 Interaction Blocks** (Cite solution_lesson_node_00006).
    *   **Receiver-Aware Message Passing:** We employ a custom gated convolution where the input is the concatenation of the **Target Node ($h_i$), Source Node ($h_j$), and Projected Edge ($e_{ij}$)**: $z_{ij} = [h_i || h_j || e_{ij}]$. This explicitly models asymmetric pairwise interactions (Cite solution_lesson_node_00072).
    *   **Gating Mechanism:** The message is computed as $m_{ij} = \text{Softplus}(\text{Linear}_1(z_{ij})) \odot \text{Sigmoid}(\text{Linear}_2(z_{ij}))$. The **Softplus** activation on the content signal is retained as it outperforms linear GLUs for modeling potential energy surfaces (Cite solution_lesson_node_00088).

3.  **Stabilized Adaptive Residual Block:**
    *   To solve the stability-accuracy trade-off of residual scaling, we implement the update rule:
        $$ h_{l+1} = \text{Softplus}(\text{BatchNorm}(\text{Agg}(m_{ij}) + (1 + \epsilon_l) \cdot h_l)) $$
    *   **Adaptive Identity:** $\epsilon_l$ is a learnable scalar parameter initialized to 0. This allows the network to dynamically learn to amplify the identity path (preserving stoichiometric signal) where beneficial (Cite solution_lesson_node_00060, solution_lesson_node_00065).
    *   **Sum-Normalization:** Crucially, **Batch Normalization is applied to the sum** of the convolution output and the residual connection. This prevents the residual signal from dominating the structural updates, correcting the "signal collapse" observed in previous iterations (Cite solution_lesson_node_00090). The activation is applied *after* normalization (Cite solution_lesson_node_00041).

4.  **Readout:**
    *   **Pooling:** We use **Global Mean Pooling** to aggregate node features. This parameter-free method aligns with the intensive nature of the target properties (Cite solution_lesson_node_00033).
    *   **Decoupled Heads:** The pooled vector is fed into two separate, independent MLPs to predict `formation_energy_ev_natom` and `bandgap_energy_ev` (Cite solution_lesson_node_00039).

### Data

1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). We prioritize a clean Radius Graph over k-NN to preserve local atomic density information (Cite solution_lesson_node_00081).
3.  **Feature Selection:** We explicitly **exclude** auxiliary global features (lattice/composition) to avoid optimization interference (Cite solution_lesson_node_00022).
4.  **Normalization:** Target variables are standardized (zero mean, unit variance).

### Training

1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks and prediction heads to prevent overfitting (Cite solution_lesson_node_00089).
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.
5.  **Scheduler:** A `ReduceLROnPlateau` scheduler is used to anneal the learning rate (Cite solution_lesson_node_00083).

### Evaluation

1.  **Inference:** Test set structures are processed into PBC-aware graphs using the same 5.0 Å cutoff and linear edge encoding.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
