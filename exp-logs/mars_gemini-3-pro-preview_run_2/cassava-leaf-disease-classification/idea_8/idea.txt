Based on the empirical lessons learned and the analysis of previous attempts, I propose the following optimized strategy. This approach structurally evolves the solution by integrating **Progressive Resolution Training** with a **Regularization Decay** schedule within a robust **5-Fold Cross-Validation** framework.

# Model
I propose using the **ConvNeXt Small** architecture, wrapped in **Model EMA (Exponential Moving Average)**.
*   **Architecture**: We will utilize **ConvNeXt Small** (approx. 50M parameters). Previous experiments confirmed that this capacity is superior to the "Tiny" variant when trained correctly **(Cite solution_lesson_node_00027)**.
*   **Weight Averaging**: We will implement **Model EMA**. By maintaining a moving average of the model weights during training, we ensure stability when transitioning between resolution stages and find flatter minima in the loss landscape, which improves generalization on noisy data.
*   **Regularization**: We will implement **Stochastic Depth (Drop Path)** with a rate of 0.4 to prevent co-adaptation in the deeper network **(Cite solution_lesson_node_00011)**.

# Data
*   **Preprocessing**: We will strictly utilize **PIL (Python Imaging Library)** for image loading to ensure native alignment with the augmentation pipeline **(Cite solution_lesson_node_00010)**.
*   **Augmentation Pipeline**:
    1.  **Geometric**: **RandomResizedCrop** is mandatory. It forces the model to learn scale-invariant features and prevents memorization of global image patterns **(Cite solution_lesson_node_00013)**.
    2.  **Photometric**: **RandAugment** will be used for automated, diverse distortions **(Cite solution_lesson_node_00005)**.
    3.  **Mixing**: **MixUp and CutMix** will be applied. Crucially, the application probability will be dynamic (see Training).

# Training
*   **Strategy (Structural Innovation)**: We will implement **5-Fold Stratified Cross-Validation** with **Progressive Resolution and Regularization Decay**.
    *   **Phase 1 (Coarse Learning)**: Train with input resolution **$224 \times 224$** for the first ~60% of epochs. Set MixUp/CutMix probability to **0.5**. This allows the model to learn robust global features while frequently seeing "clean" data to aid convergence **(Cite solution_lesson_node_00023)**.
    *   **Phase 2 (Fine-Tuning)**: Increase input resolution to **$384 \times 384$** for the remaining ~40% of epochs **(Cite solution_lesson_node_00027)**. **Innovation**: Simultaneously **reduce MixUp/CutMix probability to 0.2** (or disable). Since the fine-tuning phase is short, reducing the intensity of strong regularization is necessary to allow the model to rapidly resolve fine-grained details without the "confusion" of heavy interpolation, directly addressing the convergence-regularization trade-off identified in **Lesson 00023**.
*   **Loss Function**: **Soft Target Cross-Entropy Loss** to handle probabilistic labels from mixing and **Label Smoothing** for clean samples **(Cite solution_lesson_node_00006)**.
*   **Optimizer**: **AdamW** with **Cosine Annealing** scheduler **(Cite solution_lesson_node_00005)**.
*   **Batch Size**: 32 (using Gradient Accumulation if memory is constrained at 384px) to leverage implicit gradient noise **(Cite solution_lesson_node_00008)**.

# Evaluation
*   **Ensemble Inference**: The final submission will be generated by averaging the softmax probabilities from the **EMA weights** of all **5 Fold Models**. This ensures maximum robustness against dataset noise and prevents the "stale artifact" issue by ensuring a clean execution scope **(Cite solution_lesson_node_00028)**.
*   **Test Time Augmentation (TTA)**: We will average predictions from the original and a horizontally flipped view for each image **(Cite solution_lesson_node_00013)**.
