The following script demonstrates the usage of the provided library modules to train, validate, and perform inference on the Cassava Leaf Disease dataset.

**Implementation Strategy:**
1.  **Setup**: Initialize the environment using `seed_everything` and configure the `Config` class for a rapid demonstration (using a lightweight model like `resnet18` and small batch sizes).
2.  **Data Loading**: Use `load_dataset_dataframe` in debug mode to load a tiny subset of the data. Instantiate `CassavaDataset` with appropriate transforms from `transforms.py` and create PyTorch DataLoaders.
3.  **Model Initialization**: Use `get_model` to instantiate a ResNet18 model (overriding the default ConvNeXt for speed) and verify the Exponential Moving Average (EMA) wrapper initialization.
4.  **Training Loop**: Execute `train_one_epoch` from `engine.py` using the training data loader, optimizer, and loss function. Verify that the loss is computed and returned correctly.
5.  **Validation Loop**: Execute `validate` from `engine.py` using the validation data loader. Assert that accuracy and loss metrics are generated.
6.  **Inference**: Simulate the test phase by loading the test metadata, creating a test dataset, and running a forward pass to generate predictions. Verify the output shapes match the expected submission format.
