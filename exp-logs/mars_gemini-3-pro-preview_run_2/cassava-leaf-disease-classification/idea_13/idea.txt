Based on the comprehensive analysis of the provided lessons and the trajectory of previous experiments, I propose the following optimized strategy. This approach structurally evolves the solution into a **Dynamic Fidelity Curriculum with Synchronized EMA**, specifically designed to reconcile the conflict between high-capacity feature extraction, regularization intensity, and weight averaging lag.

# Model
I propose using the **ConvNeXt Small** architecture, initialized with pre-trained ImageNet-1k weights.
*   **Architecture Choice**: We will utilize the "Small" variant (approx. 50M parameters). Empirical evidence confirms that this architecture provides superior feature extraction capacity compared to "Tiny" or ResNet baselines, provided it is trained with a strategy that allows for convergence **(Cite solution_lesson_node_00027)**.
*   **Weight Averaging with Phase Synchronization (Structural Innovation)**: We will implement **Model EMA (Exponential Moving Average)**. Crucially, to address the "EMA Lag" issue identified in multi-stage training **(Cite solution_lesson_node_00030)**, we will implement a **Phase Reset Mechanism**. At the exact moment the training transitions from low-resolution to high-resolution (see Training), the EMA shadow weights will be re-initialized to match the current online model weights. This prevents the high-decay EMA from dragging "stale" low-resolution features into the fine-tuning phase, ensuring the inference model immediately benefits from the high-fidelity signal.
*   **Internal Regularization**: We will set the **Stochastic Depth (Drop Path)** rate to 0.4 to prevent co-adaptation of weights in this deeper network **(Cite solution_lesson_node_00011)**.

# Data
*   **Preprocessing**: We will strictly utilize **PIL (Python Imaging Library)** for image loading. This ensures native alignment with the augmentation pipeline and avoids the computational overhead and potential color-space errors associated with OpenCV conversions **(Cite solution_lesson_node_00010)**.
*   **Augmentation Pipeline**:
    1.  **Geometric**: **RandomResizedCrop** is mandatory. It forces the model to learn scale-invariant features and prevents memorization of global image patterns, which is critical for high-capacity models **(Cite solution_lesson_node_00013)**.
    2.  **Photometric**: **RandAugment** will be used for automated, diverse distortions, replacing manual tuning **(Cite solution_lesson_node_00005)**.
    3.  **Mixing**: **MixUp and CutMix** will be applied, but their intensity will be dynamically scheduled to match the training phase.

# Training
We will implement a **5-Fold Stratified Cross-Validation** loop. Unlike previous attempts that failed due to artificial epoch truncation **(Cite solution_lesson_node_00022)**, we will utilize the full 24-hour budget to train each fold to convergence using a **Two-Phase Dynamic Curriculum**:

*   **Phase 1: Coarse Feature Learning (First ~60% of Epochs)**
    *   **Resolution**: Input images are resized to **$224 \times 224$**. This reduces computational load, allowing for rapid iteration of global features.
    *   **Regularization**: **MixUp/CutMix** is applied with a probability of **0.5**. This balances the need for regularization against the need for the model to see "clean" data to aid convergence, correcting the underfitting observed with p=1.0 **(Cite solution_lesson_node_00023)**.
    *   **Loss**: **Soft Target Cross-Entropy** (to handle mixed labels).

*   **Phase 2: Fine-Grained Refinement (Remaining ~40% of Epochs)**
    *   **Resolution**: Input images are increased to **$384 \times 384$**. This allows the model to resolve fine-grained disease artifacts (spots, textures) that are lost at lower resolutions **(Cite solution_lesson_node_00027)**.
    *   **Regularization Annealing**: **MixUp/CutMix is disabled (p=0.0)**. This removal of interpolation noise allows the model to focus purely on refining high-frequency spatial details.
    *   **Loss**: **Cross-Entropy with Label Smoothing (0.1)** **(Cite solution_lesson_node_00006)**.
    *   **Optimization**: We will use **Gradient Accumulation** to maintain an effective **Batch Size of 32** despite the memory increase, preserving beneficial gradient noise **(Cite solution_lesson_node_00008)**.

# Evaluation
*   **Ensemble Inference**: The final submission will be generated by averaging the softmax probabilities from the **EMA weights** of all **5 Fold Models**. We will ensure strict experiment isolation (fresh directories) to avoid ensembling stale artifacts **(Cite solution_lesson_node_00028)**.
*   **Test Time Augmentation (TTA)**: For each fold, we will average predictions from the original image and a horizontally flipped version to leverage orientation invariance **(Cite solution_lesson_node_00013)**.
