Implementation of the `runfile.py` script following the Progressive Resolution Training strategy with Model EMA and 5-Fold CV.

Strategy Outline:
1.  **Configuration**: Import `CFG` and override parameters for a "Fast Baseline" execution (Total 2 epochs per fold: 1 Coarse + 1 Fine) to satisfy time limits while using the full dataset.
2.  **Data Loading**: Load training metadata.
3.  **K-Fold Loop**: Iterate through 5 folds.
    *   **Phase 1 (Coarse)**: Train on 224x224 resolution with MixUp enabled.
    *   **Phase 2 (Fine)**: Continue training on 384x384 resolution with MixUp disabled (fine-tuning).
    *   **Validation**: Evaluate the model on the validation fold using the EMA weights.
    *   **Save**: Save the best model state.
4.  **Global Evaluation**: Aggregate Out-Of-Fold (OOF) predictions to compute the final accuracy.
5.  **Failure Analysis**: Calculate the correlation between prediction error and image file size to identify if image complexity affects performance.
6.  **Submission**: If the validation accuracy exceeds 0.9076, generate predictions for the test set using a TTA ensemble of all 5 models and save `submission.csv`.
