### Implementation Strategy

1.  **Configuration Setup**: We will override specific configurations in the `Config` class to adapt the execution for a quick demonstration. This includes setting a temporary working directory, reducing batch sizes, minimizing epochs to 1, and disabling pretrained weight downloads to ensure the script runs offline and quickly.
2.  **Data Pipeline Verification**: We will load a small subset of the training metadata (50 samples) and verify that `get_dataloaders` correctly returns PyTorch DataLoaders. We will assert the shape of the image tensors and label tensors from a single batch.
3.  **Augmentation Logic Check**: We will instantiate the `Mixup` class and apply it to a dummy batch to verify that it correctly produces mixed images and soft-target labels (checking dimensions and value ranges).
4.  **Model Initialization**: We will initialize the `CassavaModel` (via `create_model`) and `ModelEMA`. We will perform a forward pass with dummy data to verify the output shape matches `(Batch_Size, Num_Classes)`.
5.  **Training Loop Execution**: We will run `train_one_epoch` and `validate` using the subset data. We will check that the loss returned is a valid finite number.
6.  **Inference & Submission**: We will save the model state from the training step as a checkpoint, simulating a trained model. Then, we will execute `run_inference` to generate predictions on the test set and verify that a `submission.csv` file is created with the correct format.
