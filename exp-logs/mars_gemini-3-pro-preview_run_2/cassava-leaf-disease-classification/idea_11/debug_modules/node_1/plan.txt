The issue is caused by the `get_dataloaders` function unconditionally attempting to create a `DataLoader` with `shuffle=True` for the training set, even when provided with an empty "dummy" DataFrame during the inference phase. This triggers a `ValueError` in the `RandomSampler`, which requires a positive number of samples (Cite debug_lesson_1). To fix this, I will modify `library/data.py` to conditionally initialize the `DataLoader` instances only when the corresponding datasets contain data, returning `None` otherwise.
