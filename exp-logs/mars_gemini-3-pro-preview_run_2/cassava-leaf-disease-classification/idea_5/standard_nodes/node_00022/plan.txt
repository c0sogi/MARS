5.  **Metric Calculation**: Concatenate all OOF predictions and calculate the overall accuracy. Print this as `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Calculate the error magnitude for each validation sample. Extract the file size for each image and compute the Pearson correlation between error magnitude and file size to identify if image complexity/quality affects performance.
