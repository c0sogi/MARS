Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Anchored Hybrid-Stem Dense-Feedback Network (AHS-DFN)**.

This strategy synthesizes the structural evolution of the "Dense-Context" architecture. It explicitly resolves the conflict between **Spatial Context Extraction** (Lesson 00125) and **Raw Feature Preservation** (Lesson 00128) via a **Hybrid Input Stem**. Crucially, it re-introduces **Boundary Anchoring** (Lesson 00136) to stabilize the bidirectional aggregator, correcting the performance regression observed in models that utilized strict loss masking. It retains the **Global-Context Recycling** (Lesson 00133) and **Micro-Architectural Robustness** (Lessons 00111, 00116, 00117) established in prior successes.

# Model

### 1. Input Representation (Hybrid & Partner-Aware)
*   **Features:** One-Hot Encoding for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels (Cite solution_lesson_node_00090).

### 2. Hybrid Input Stem (Structural Innovation)
*   **Concept:** To satisfy both **Lesson 00125** (Need Spatial Mixing) and **Lesson 00128** (Need Raw Identity), we construct the backbone input by concatenating two parallel branches:
    *   **Branch A (Identity):** The raw, sparse One-Hot features.
    *   **Branch B (Context):** The One-Hot features processed by a **Spatial Convolution (Kernel 3)** followed by **Layer Normalization** and **SiLU**.
*   **Rationale:** This ensures the backbone receives both the exact nucleotide identities (crucial for base-pairing rules) and the immediate n-gram context (crucial for local motifs), without "smearing" the discrete signal into a purely continuous embedding.

### 3. Main Backbone (Post-Activation Dense Dilated TCN)
*   **Architecture:** A stack of **Single-Layer Dilated Blocks** utilizing **Dense Connections** (concatenating outputs of all prior blocks).
    *   **Rationale:** As established in **Lesson 00145**, Dense connections are superior to Residual connections for 1D dilated networks because they explicitly preserve features from varying receptive fields.
*   **Micro-Architecture (Post-Activation & Decoupled):** We employ **Post-Activation** blocks structured to decouple spatial aggregation from channel mixing (Cite solution_lesson_node_00111):
    *   Structure: `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`.
    *   *Rationale:* **Post-Activation** maximizes initial signal variance (Cite solution_lesson_node_00125). We use **Standard Convolutions** (Cite solution_lesson_node_00116) and **SiLU** (Cite solution_lesson_node_00117) for robustness.
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Growth Rate **64** (Cite solution_lesson_node_00037).
*   **Latent Projection:** The output is projected to **Latent Dim 64** ($Z$) via a **Linear 1x1 Convolution** (Cite solution_lesson_node_00062, solution_lesson_node_00076).

### 4. Global-Context Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Channel Masking:** We strictly zero out the **channels** corresponding to unscored targets (`deg_pH10`, `deg_50C`) (Cite solution_lesson_node_00118).
*   **Global Sequence Context:** We **DO NOT** mask the unscored sequence positions (68-107). We feed the full sequence length back into the model to preserve global folding context (Cite solution_lesson_node_00133).
*   **Spatial Feedback Stem:** We process the masked predictions with a **Standard Convolution (Kernel 3)** $\to$ LayerNorm $\to$ SiLU.
*   **Backbone:** A **Lightweight Dense TCN** (Growth Rate 16) processed in isolation from static features (Late Fusion) (Cite solution_lesson_node_00100, solution_lesson_node_00103).
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 5. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
*   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)** (Cite solution_lesson_node_00117).

# Data

### 1. Preprocessing & Cache Safety
*   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_ahs_dfn_v1.npz`) to ensure input features are generated correctly (Cite solution_lesson_node_00032).
*   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
*   **Boundary Targets:** For training, fill the unscored tail positions (68-107) of the target arrays with `0.0`. This provides the neutral baseline required for Boundary Anchoring (Cite solution_lesson_node_00136).

### 2. Loaders
*   Yield Augmented Input, Partner Index Map, and Targets (Full Length).

# Training

### 1. Optimization Strategy
*   **Batch Size:** Strictly set to **16**. This increases gradient update frequency (~108/epoch), which is critical for convergence on this small dataset (Cite solution_lesson_node_00129).
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Channel-Masked $\hat{Y}_0$ (Full Length) using **Spatial Stem + Feedback Backbone**.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Channel-Masked $R$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 3. Boundary Anchoring Loss
*   **Loss Calculation:** We calculate the MCRMSE loss over the **entire 107-length sequence**.
    *   *Rationale:* As established in **Lesson 00136**, masking the loss in the tail causes the Bidirectional RNN's backward pass to drift. By training the model to predict the neutral baseline (`0.0`) in the tail, we anchor the hidden states and stabilize the global aggregation.
*   **Total Loss:** $L_{total} = \text{MCRMSE}_{0-107}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}_{0-107}(\hat{Y}_1)$.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Channel-Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$ (Full 107 predictions).

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root to avoid the optimistic bias of batch-averaging. Crucially, calculate this metric **only on the 68 valid positions** to get an honest assessment of performance (Cite solution_lesson_node_00131, solution_lesson_node_00020).
