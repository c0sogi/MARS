I will implement the `runfile.py` script to orchestrate the training, evaluation, failure analysis, and submission generation for the SR-DCN model.

**Strategy:**
1.  **Configuration:** I will override the default `Config` parameters to ensure a fast execution, specifically reducing the number of epochs to 15.
2.  **Data Loading:** I will utilize the `RNADataset` class to load training, validation, and test datasets, wrapping them in PyTorch `DataLoader`s.
3.  **Training:** I will initialize the `RNAEngine` and execute the training loop. The engine handles the specific "Cold Start" and "Refinement" passes required by the SR-DCN architecture.
4.  **Validation:** I will retrieve the best validation metric from the training process and print it in the required format.
5.  **Failure Analysis:** I will perform a manual inference pass on the validation set using the best saved model. I will compute the error per sample and correlate it with metadata features (like `signal_to_noise` and base counts) loaded from `metadata/val.csv`.
6.  **Submission:** If the validation metric meets the specified threshold, I will trigger the submission generation using the test loader.
