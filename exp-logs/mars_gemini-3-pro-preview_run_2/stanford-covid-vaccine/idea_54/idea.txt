Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Direct-Access Recurrent Dense Network (DA-RDN)**.

This strategy optimizes the "Dense-Feedback" architecture (Idea 53) by correcting the critical **Feature Isolation Flaw** identified in **Lesson 00128**. While Idea 53 correctly identified the need for spatial mixing, it failed because the "Input Stem" transformed the categorical features into a continuous embedding *before* the DenseNet backbone, effectively hiding the raw nucleotide identities from the deeper layers. The **DA-RDN** removes the isolating stem and enforces **Direct Raw Access**, ensuring that the raw One-Hot features are concatenated to the input of *every* block in the DenseNet. This is combined with a **Post-Activation** micro-architecture to handle sparse inputs robustly, and a **Stabilized Recycling** loop for iterative refinement.

# Model

### 1. Input Representation (Static & Partner-Aware)
*   **Features:** One-Hot Encoding for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) (Cite solution_lesson_node_00052).
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels (Cite solution_lesson_node_00090).

### 2. Main Backbone (Direct-Access Dense Dilated TCN)
*   **Structural Innovation (Direct Raw Access):** We employ a **DenseNet** architecture where the input to the $k$-th block is the concatenation of the outputs of all prior blocks **AND the raw One-Hot input features**.
    *   *Rationale:* As established in **Lesson 00128**, isolating categorical inputs behind a stem "smears" the discrete identity information (e.g., "This is an A") required for precise interaction modeling. By maintaining a direct skip-connection from the raw input to every layer, the model preserves high-fidelity token identity throughout the depth.
*   **Micro-Architecture (Post-Activation & Decoupled):** We employ **Post-Activation** blocks structured to decouple spatial aggregation from channel mixing (Cite solution_lesson_node_00111):
    *   Structure: `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`.
    *   *Rationale:* **Post-Activation** avoids applying Normalization directly to the sparse One-Hot inputs (Cite solution_lesson_node_00120) and maximizes initial signal variance (Cite solution_lesson_node_00125). We use **Standard Convolutions** (Cite solution_lesson_node_00116) and **SiLU** (Cite solution_lesson_node_00117).
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Growth Rate **64** (Cite solution_lesson_node_00037).
*   **Latent Projection:** The output is projected to **Latent Dim 64** ($Z$) via a **Linear 1x1 Convolution** (Cite solution_lesson_node_00062, solution_lesson_node_00076).

### 3. Pure-Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Strict Masking:** We strictly apply a binary mask to zero out unscored targets (`deg_pH10`, `deg_50C`) (Cite solution_lesson_node_00118). We process this signal in isolation (Late Fusion) (Cite solution_lesson_node_00100).
*   **Architecture:** A **Lightweight Dense TCN** (Cite solution_lesson_node_00103).
    *   **Embedding:** First layer is a Linear Projection (Cite solution_lesson_node_00086).
    *   **Blocks:** Uses the same **Post-Activation** structure as the backbone.
    *   **Constraint:** **Low Growth Rate (16)** to prevent the feedback loop from dominating the static signal.
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 4. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
        *   *Note:* This propagates the dynamic feedback through structural connections (Cite solution_lesson_node_00105).
*   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003) feeding directly from the fusion layer (Cite solution_lesson_node_00077).
*   **Constraint:** **Compact Hidden Size (64)** (Cite solution_lesson_node_00117).
*   **Output:** Linear projection to targets.

# Training

### 1. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Masked $\hat{Y}_0$ using the **Pure-Feedback Module**.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Masked $R$ using the **Pure-Feedback Module**.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 2. Loss Function
*   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
*   **Strict Masking:** Calculate loss **only on the three scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) and **only on valid sequence positions** (0-67) (Cite solution_lesson_node_00016, solution_lesson_node_00109).

### 3. Optimizer
*   **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$.

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root to avoid batch-averaging bias (Cite solution_lesson_node_00020).
