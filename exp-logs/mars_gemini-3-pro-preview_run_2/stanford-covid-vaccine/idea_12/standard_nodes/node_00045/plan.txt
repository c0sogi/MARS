The implementation strategy involves the following steps:
1.  **Training**: Execute the training pipeline using the provided `library.train.run_training` function. We adhere to the default configuration (20 epochs) which serves as an efficient baseline for the dataset size.
2.  **Validation**: Reload the best model saved during training and perform a dedicated inference pass on the validation set. We utilize `GlobalMCRMSE` to compute the metric across the entire dataset, avoiding batch-averaging bias.
3.  **Failure Analysis**: During the validation pass, we compute the Mean Columnwise RMSE for each individual sample. We then merge these error values with the validation metadata (specifically `signal_to_noise`) to calculate the Pearson correlation, identifying if noisy samples systematically result in higher errors.
4.  **Submission**: We compare the final validation metric against the specified threshold (0.5421870350837708). If the model performs sufficiently well, we trigger the `library.train.generate_submission` function to create the submission file.
