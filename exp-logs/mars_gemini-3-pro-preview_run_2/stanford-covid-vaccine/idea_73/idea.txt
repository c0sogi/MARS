Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Augmented-Stem Dense-Feedback Recurrent Network (AS-DFRN)**.

This strategy represents the structural culmination of the "Dense-Context" architecture. It synthesizes the successes of **Iterative Refinement** and **Dense Connectivity** while explicitly resolving the conflicts between **Spatial Context** (Cite solution_lesson_node_00125) and **Raw Identity** (Cite solution_lesson_node_00128) via an **Augmented Input Stem**. Furthermore, it corrects the **RNN Drift** issue (Cite solution_lesson_node_00136) by enforcing **Boundary Anchoring**, and ensures robust optimization through **Micro-Architectural Best Practices** (Cite solution_lesson_node_00111, solution_lesson_node_00116, solution_lesson_node_00117).

# Model

### 1. Input Representation (Augmented & Partner-Aware)
*   **Features:** One-Hot Encoding for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
*   **Augmented Input Stem (Structural Innovation):** We construct the input to the backbone by concatenating two parallel branches:
    *   **Branch A (Identity):** The raw, sparse One-Hot features.
    *   **Branch B (Context):** The One-Hot features processed by a **Spatial Convolution (Kernel 3)** followed by **Layer Normalization** and **SiLU**.
    *   **Rationale:** This satisfies **Lesson 00125** (Need Spatial Mixing) by providing n-gram context via Branch B, while simultaneously satisfying **Lesson 00128** (Need Raw Identity) by preserving the discrete token identity via Branch A. Unlike Idea 56 (which reduced backbone capacity to fit this), we maintain full backbone capacity (Cite solution_lesson_node_00149).
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels (Cite solution_lesson_node_00090).

### 2. Main Backbone (Post-Activation Dense Dilated TCN)
*   **Architecture:** A stack of **Single-Layer Dilated Blocks** utilizing **Dense Connections** (concatenating outputs of all prior blocks).
    *   **Rationale:** Dense connections are superior to Residual connections for 1D dilated networks as they explicitly preserve features from varying receptive fields (Cite solution_lesson_node_00145).
*   **Micro-Architecture (Post-Activation & Decoupled):** We employ **Post-Activation** blocks structured to decouple spatial aggregation from channel mixing (Cite solution_lesson_node_00111):
    *   Structure: `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`.
    *   *Rationale:* **Post-Activation** maximizes initial signal variance (Cite solution_lesson_node_00125). We use **Standard Convolutions** (Cite solution_lesson_node_00116) and **SiLU** (Cite solution_lesson_node_00117) for robustness.
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Growth Rate **64**. We strictly maintain this high capacity to prevent underfitting (Cite solution_lesson_node_00149, solution_lesson_node_00037).
*   **Latent Projection:** The output is projected to **Latent Dim 64** ($Z$) via a **Linear 1x1 Convolution** (Cite solution_lesson_node_00062, solution_lesson_node_00076).

### 3. Global-Context Dense-Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Channel Masking:** We strictly zero out the **channels** corresponding to unscored targets (`deg_pH10`, `deg_50C`) to prevent unsupervised noise injection (Cite solution_lesson_node_00118).
*   **Global Sequence Context:** We **DO NOT** mask the unscored sequence positions (68-107). We feed the full sequence length back into the model. This preserves the global physical context required for accurate folding predictions in the scored region (Cite solution_lesson_node_00133).
*   **Architecture:** A **Lightweight Dense TCN** (Growth Rate 16).
    *   *Rationale:* Uses Dense connectivity for superior feature propagation (Cite solution_lesson_node_00047) but remains lightweight to prevent the feedback loop from dominating the static signal (Cite solution_lesson_node_00103).
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 4. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
        *   *Note:* This propagates the dynamic feedback through structural connections (Cite solution_lesson_node_00105).
*   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)**. We strictly limit the RNN capacity to match the feature dimension (Cite solution_lesson_node_00117).
*   **Output:** Linear projection to targets.

# Data

### 1. Preprocessing & Cache Safety
*   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_as_dfrn_v1.npz`) to ensure input features (especially Partner Identity) are generated correctly (Cite solution_lesson_node_00032).
*   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
*   **Boundary Targets:** Fill the unscored tail positions (68-107) of the target arrays with `0.0` to provide a neutral baseline for anchoring (Cite solution_lesson_node_00136).

### 2. Loaders
*   Yield Augmented Input, Partner Index Map, and Targets (Full Length).

# Training

### 1. Optimization Strategy
*   **Batch Size:** Strictly set to **16**. This increases gradient update frequency (~108/epoch), which is critical for convergence on this small dataset (Cite solution_lesson_node_00129).
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Channel-Masked $\hat{Y}_0$ (Full Length) using the **Feedback Module**.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Channel-Masked $R$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 3. Boundary Anchoring Loss
*   **Loss Calculation:** We calculate the MCRMSE loss over the **entire 107-length sequence**.
    *   *Rationale:* As established in **Lesson 00136**, masking the loss in the tail causes the Bidirectional RNN's backward pass to drift, injecting noise into the valid region. By training the model to predict the neutral baseline (`0.0`) in the tail, we anchor the hidden states and stabilize the global aggregation.
*   **Total Loss:** $L_{total} = \text{MCRMSE}_{0-107}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}_{0-107}(\hat{Y}_1)$.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Channel-Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$ (Flattened).

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root to avoid the optimistic bias of batch-averaging. Crucially, calculate this metric **only on the 68 valid positions** to get an honest assessment of performance (Cite solution_lesson_node_00131, solution_lesson_node_00020).
