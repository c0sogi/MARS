### Implementation Strategy

2.  **Data Processing Verification**: Call `library.data_processor.process_data` explicitly to process the training metadata. Verify the integrity of the returned dictionary (keys and array shapes) to ensure features and targets are correctly generated.
3.  **Dataset & DataLoader Verification**: Instantiate `library.dataset.RNADataset` in debug mode (loading a small subset) and wrap it in a `DataLoader` using `library.dataset.get_dataloader`. Fetch a single batch to verify the tensor shapes of inputs, partner indices, and targets.
4.  **Model Component Unit Tests**: Instantiate individual model components (`InputEmbeddingStem`, `PreActDilatedBlock`, `DenseTCN`) from `library.model_components`. 5.  **Full Model Integration**: Instantiate the full `EIPFN` model from `library.model`. Perform a forward pass with the fetched batch, both with and without the feedback loop (`y_prev`), to ensure the model graph is valid and produces predictions of the correct shape.
6.  **Loss Function Verification**: Instantiate `library.loss.MaskedMCRMSELoss` and compute the loss on the model's output. Assert that the loss is a non-negative scalar.
7.  **Metric Verification**: Test the `MCRMSE` class from `library.utils` using synthetic numpy arrays with known values to confirm the metric calculation logic is correct.
8.  **Training Loop Integration**: Execute `library.train.train_model` with `debug=True`, minimal epochs (2), and a small batch size (4). This serves as an end-to-end integration test, validating the interaction between data loading, model forward/backward passes, optimization, and validation scoring.
