Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Anchored Hybrid-Input Recurrent Network (AHI-RN)**.

This strategy synthesizes the structural evolution of the "Dense-Context" architecture. It explicitly resolves the conflict between **Spatial Context Extraction** (Lesson 00125) and **Raw Feature Preservation** (Lesson 00128) via a **Hybrid Input Stem**. Crucially, it corrects the **Boundary Anchoring Flaw** (Lesson 00136) that caused previous bidirectional models to drift, and enforces **Global-Context Recycling** (Lesson 00133) to maintain physical consistency.

# Model

### 1. Input Representation (Hybrid & Partner-Aware)
*   **Features:** One-Hot Encoding for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) (Cite solution_lesson_node_00052).
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels (Cite solution_lesson_node_00090).

### 2. Hybrid Input Stem (Structural Innovation)
*   **Concept:** To satisfy both **Lesson 00125** (Need Spatial Mixing) and **Lesson 00128** (Need Raw Identity), we construct the network input $X_{0}$ by concatenating two parallel branches:
    *   **Branch A (Identity):** The raw, sparse One-Hot features.
    *   **Branch B (Context):** The One-Hot features processed by a **Spatial Convolution (Kernel 3)** followed by **Layer Normalization** and **SiLU**.
*   **Rationale:** This ensures the first layer of the backbone receives both the exact nucleotide identities (crucial for base-pairing rules) and the immediate n-gram context (crucial for local motifs), without "smearing" the discrete signal into a purely continuous embedding.

### 3. Main Backbone (Standard Dense Dilated TCN)
*   **Architecture:** A stack of **Single-Layer Dilated Blocks** utilizing **Dense Connections** (concatenating outputs of all prior blocks) (Cite solution_lesson_node_00047).
*   **Connectivity:** We use standard DenseNet connectivity. The input to Block 1 is $X_{0}$. The input to Block 2 is $[X_{0}, H_{1}]$. This naturally preserves access to the raw features in Branch A throughout the network depth, avoiding the need for explicit "Direct Access" injection (Cite solution_lesson_node_00134).
*   **Micro-Architecture (Post-Activation):** `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`. This decouples spatial/channel mixing (Cite solution_lesson_node_00111) and maximizes initial signal variance (Cite solution_lesson_node_00125).
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Latent Projection:** Output projected to **Latent Dim 64** ($Z$) (Cite solution_lesson_node_00062).

### 4. Global-Context Pure-Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Channel Masking:** Strictly zero out unscored targets (`deg_pH10`, `deg_50C`) (Cite solution_lesson_node_00118).
*   **Full Sequence Context:** We **DO NOT** mask the unscored sequence positions (68-107). We feed the full sequence length back into the model to preserve global folding context (Cite solution_lesson_node_00133).
*   **Architecture:** A **Lightweight Dense TCN** (Growth Rate 16) (Cite solution_lesson_node_00103).
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 5. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)** (Cite solution_lesson_node_00117).

# Data

### 1. Preprocessing & Cache Safety
*   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_ahi_rn_v1.npz`) to ensure input features are generated correctly (Cite solution_lesson_node_00032).
*   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
*   **Target Parsing:** Parse stringified targets to numerical arrays.
*   **Boundary Targets:** For training, fill the unscored tail positions (68-107) of the target arrays with `0.0` (Cite solution_lesson_node_00136).

### 2. Loaders
*   Yield Augmented Input, Partner Index Map, and Targets (Full Length).

# Training

### 1. Optimization Strategy
*   **Batch Size:** Strictly set to **16** to maximize gradient update frequency (Cite solution_lesson_node_00129).
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Boundary Anchoring (Critical Fix)
*   **Loss Calculation:** We calculate the MCRMSE loss over the **entire 107-length sequence**.
    *   *Rationale:* As established in **Lesson 00136**, masking the loss in the tail causes the Bidirectional RNN's backward pass to drift, injecting noise into the valid region. By training the model to predict the neutral baseline (`0.0`) in the tail, we anchor the hidden states and stabilize the global aggregation.

### 3. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Masked $\hat{Y}_0$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Masked $R$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.
*   **Total Loss:** $L_{total} = \text{MCRMSE}_{0-107}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}_{0-107}(\hat{Y}_1)$.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$ (Full 107 predictions).

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root (Cite solution_lesson_node_00020).
