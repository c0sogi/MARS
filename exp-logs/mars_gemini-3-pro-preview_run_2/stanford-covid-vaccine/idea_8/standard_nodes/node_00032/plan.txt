As per **Lesson 00031**, this dynamic gathering is superior to static augmentation. Removing the static features reduces input redundancy and dimensionality (from 18 to 14 channels), forcing the model to rely on the more effective dynamic mechanism.

This aligns with **Lesson 00004**, ensuring the BiGRU hidden size matches half the input dimension (input to GRU is `LATENT_DIM * 2` after gathering, so hidden size `64` results in a bidirectional output of `128`, matching the gather output). This provides a wider bottleneck for structural message passing without excessive over-parameterization.
