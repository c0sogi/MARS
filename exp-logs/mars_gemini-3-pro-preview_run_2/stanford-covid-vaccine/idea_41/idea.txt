Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Raw-Conditioned Recurrent Dense Network (RCR-DN)**.

This strategy evolves the state-of-the-art "Contextualized-Feedback" architecture (Idea 36) by addressing the "Context Blindness" of the recycling loop. While previous iterations successfully smoothed predictions using a Feedback TCN, that module operated in isolation from the sequence identity, limiting its ability to distinguish physical signals (e.g., stable G-C stems) from noise. The **RCR-DN** introduces **Raw-Input Conditioning**, injecting the fundamental chemical context (Sequence, Structure, Partner Identity) directly into the lightweight feedback loop. This enables **Structure-Aware Denoising** while strictly adhering to the "Static Backbone" efficiency (Lesson 00090) and "Late Fusion" (Lesson 00100) constraints.

# Model

1.  **Input Representation (Static & Partner-Aware):**
    *   **Primary Features:** One-Hot Encoding for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base). As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
    *   **Static Tensor:** The main input tensor is static; we do not augment it with recycling channels to avoid re-running the heavy main backbone (Cite solution_lesson_node_00090).

2.  **Main Backbone (Static Dense Dilated TCN):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** (Cite solution_lesson_node_00011) utilizing **Dense Connections** (concatenating outputs of all prior blocks). This preserves the full multi-scale history (Cite solution_lesson_node_00047).
    *   **Micro-Architecture:** Blocks utilize `LayerNorm -> ReLU -> Conv1d -> Dropout(0.1)` with residual connections (Cite solution_lesson_node_00101).
    *   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
    *   **Capacity:** Growth Rate **64** (Cite solution_lesson_node_00037).
    *   **Execution:** Runs **once** per batch to produce dense feature tensor $H_{dense}$.
    *   **Latent Projection:** $H_{dense}$ is projected to **Latent Dim 64** ($Z$) via Linear 1x1 Conv (Cite solution_lesson_node_00062, solution_lesson_node_00076).

3.  **Raw-Conditioned Feedback Module (Structural Innovation):**
    *   **Inputs:**
        1.  Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
        2.  **Raw Context Features:** Concatenation of One-Hot Sequence, Structure, Loop, and **Partner Identity**.
    *   **Masking:** Zero out unscored targets in $\hat{Y}_{k-1}$ (`deg_pH10`, `deg_50C`) to prevent unsupervised noise injection (Cite solution_lesson_node_00016).
    *   **Context Projection:** Project the Raw Context Features to a compact dimension (e.g., 16 channels) using a Linear layer.
    *   **Fusion:** Concatenate $[\hat{Y}_{masked}, \text{ProjectedContext}]$.
        *   *Rationale:* This provides the feedback encoder with the exact chemical environment (e.g., "I am a G paired with C in a Stem") to interpret the stability prediction, without coupling it to the heavy static backbone (avoiding "Early Fusion" failure, Cite solution_lesson_node_00100).
    *   **Architecture:** A **Lightweight Dilated TCN** (3 Residual Blocks, Dilation 1, 2, 4, Dim 32) (Cite solution_lesson_node_00103).
    *   **Output:** Conditioned Feedback Embeddings $E_{fb}$ (32 channels).

4.  **Interaction & Aggregation:**
    *   **Augmented Gather:** For every position $i$ paired with $j$:
        *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
        *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
            *   *Note:* This propagates the feedback structurally (Cite solution_lesson_node_00105).
    *   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
    *   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
    *   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
    *   **Output:** Linear projection to targets.

# Data

1.  **Preprocessing & Cache Safety:**
    *   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_rcr_dn_v1.npz`) to ensure input features are generated correctly (Cite solution_lesson_node_00032).
    *   **Feature Generation:** Generate One-Hot encodings (Seq, Struct, Loop), **Partner Identity**, and Partner Index Map.
    *   **Target Parsing:** Parse stringified targets to numerical arrays.

2.  **Loaders:**
    *   Yield Augmented Input, Partner Index Map, and Targets.

# Training

1.  **Iterative Refinement Loop:**
    *   **Step 1 (Static):** Compute $Z$ from static inputs once.
    *   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
    *   **Pass 1:**
        *   Compute $E_{fb, 0}$ from $\hat{Y}_0$ and Raw Context using **Raw-Conditioned Feedback Module**.
        *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
    *   **Pass 2:**
        *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
        *   Compute $E_{fb, 1}$ from $R$ and Raw Context.
        *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

2.  **Loss Function:**
    *   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
    *   Calculate loss **only on scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) (Cite solution_lesson_node_00016).

3.  **Optimizer:**
    *   **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

# Evaluation

1.  **Inference:**
    *   Compute Backbone features $Z$ once.
    *   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
    *   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
    *   Submit $\hat{Y}_2$.

2.  **Metric:**
    *   Use **Correct Global RMSE** (Cite solution_lesson_node_00020).
