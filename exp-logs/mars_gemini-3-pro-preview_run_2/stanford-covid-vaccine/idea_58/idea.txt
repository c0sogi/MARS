Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Global-Context Spatial-Stem Network (GC-SSN)**.

This strategy represents the convergence of the "Dense-Context" and "Iterative Refinement" architectures. It explicitly resolves the **Input Stem Flaw** (Lesson 00125) and the **Tail Masking Flaw** (Lesson 00133) while adhering to the **Hierarchical Abstraction** principle (Lesson 00134). By combining a **Spatial Input Stem** with a **Global-Context Pure-Feedback Loop**, this solution ensures robust feature extraction and physically consistent refinement without the optimization pathologies of prior attempts.

# Model

### 1. Input Representation (Spatial & Partner-Aware)
*   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
*   **Spatial Input Stem (Structural Innovation):** We process the concatenated One-Hot features with a **Standard Convolution with Kernel Size 3** followed by **Layer Normalization** and **SiLU**.
    *   *Rationale:* As established in **Lesson 00125** and **Lesson 00120**, applying Normalization or 1x1 Convolutions directly to sparse one-hot inputs destroys sequential context. A spatial kernel ($k=3$) ensures immediate mixing of adjacent nucleotides (n-grams), creating a dense, context-rich embedding that serves as a robust foundation for the hierarchical backbone.
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels (Cite solution_lesson_node_00090).

### 2. Main Backbone (Post-Activation Dense Dilated TCN)
*   **Hierarchical Architecture:** We employ a standard **DenseNet** structure where layers consume outputs from prior layers, strictly avoiding the "Direct Access" pattern of injecting raw inputs at every depth (Cite solution_lesson_node_00134).
*   **Micro-Architecture (Post-Activation & Decoupled):** We employ **Post-Activation** blocks structured to decouple spatial aggregation from channel mixing (Cite solution_lesson_node_00111):
    *   Structure: `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`.
    *   *Rationale:* **Post-Activation** maximizes initial signal variance for shallow networks (Cite solution_lesson_node_00125). We use **Standard Convolutions** (Cite solution_lesson_node_00116) and **SiLU** (Cite solution_lesson_node_00117) for robustness.
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Growth Rate **64** (Cite solution_lesson_node_00037).
*   **Latent Projection:** The output is projected to **Latent Dim 64** ($Z$) via a **Linear 1x1 Convolution** (Cite solution_lesson_node_00062, solution_lesson_node_00076).

### 3. Global-Context Pure-Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Channel Masking:** We strictly zero out the **channels** corresponding to unscored targets (`deg_pH10`, `deg_50C`) to prevent unsupervised noise injection (Cite solution_lesson_node_00118).
*   **Global Context Preservation:** Crucially, we **DO NOT** mask the unscored sequence positions (68-107). We feed the full 107-length prediction back into the model. This preserves the global physical context required for accurate folding predictions in the scored region (Cite solution_lesson_node_00133).
*   **Pure Feedback:** We process this signal in isolation from static topology features (Cite solution_lesson_node_00100).
*   **Architecture:** A **Lightweight Dense TCN** (Growth Rate 16) utilizing the same robust Post-Activation structure (Cite solution_lesson_node_00103).
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 4. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
        *   *Note:* This propagates the dynamic feedback through structural connections (Cite solution_lesson_node_00105).
*   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)** (Cite solution_lesson_node_00117).
*   **Output:** Linear projection to targets.

*   **Target Parsing:** Parse stringified targets to numerical arrays.

### 2. Loaders
*   Yield Augmented Input, Partner Index Map, and Targets.

# Training

### 1. Optimization Strategy
*   **Batch Size:** Strictly set to **16**. This increases gradient update frequency (~108/epoch), which is critical for convergence on this small dataset (Cite solution_lesson_node_00129).
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Channel-Masked $\hat{Y}_0$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Channel-Masked $R$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 3. Loss Function
*   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
*   **Evaluation Masking:** Calculate loss **only on scored columns** and **only on valid sequence positions** (0-67) (Cite solution_lesson_node_00016, solution_lesson_node_00109).

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Channel-Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$.

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root to avoid the optimistic bias of batch-averaging (Cite solution_lesson_node_00131, solution_lesson_node_00020).
