The following script demonstrates the usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Configuration Override**: Redirects the cache directory to a demo folder to prevent overwriting existing work.
2.  **Data Loading Verification**: Loads a small subset of the training data and verifies tensor shapes and data types.
3.  **Model Forward Pass Verification**: Instantiates the `ScaleDecoupledDenseNet` and runs a forward pass with the loaded batch to ensure the architecture handles inputs correctly.
4.  **Loss Function Verification**: Manually validates the `MaskedMCRMSELoss` logic using controlled dummy tensors to ensure it correctly masks ignored columns and computes the metric.
5.  **Training Pipeline Execution**: Runs a short training session (2 epochs, 50 samples) using `run_training` to demonstrate the full training loop, including validation and checkpointing.
6.  **Inference and Submission**: Loads the best model saved during the training step, performs inference on a subset of the test data, and generates a sample submission file in the correct format.
