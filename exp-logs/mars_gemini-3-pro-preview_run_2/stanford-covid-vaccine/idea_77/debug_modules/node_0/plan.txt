The following script demonstrates the end-to-end usage of the provided machine learning library for the RNA degradation prediction task.

### Implementation Strategy
1.  **Configuration Setup**: We first import the `Config` class and override specific parameters (e.g., `SUBSET_SIZE`, `EPOCHS`, `BATCH_SIZE`, `WORKING_DIR`) to ensure the demonstration runs quickly and uses a separate workspace.
2.  **Data Loading**: We utilize `load_data` to load small subsets of the training, validation, and test datasets. We verify the structure and shapes of the batches (inputs, partner indices, and targets) using assertions.
3.  **Model Initialization**: We instantiate the `ADFRN` model, move it to the appropriate device (CPU or GPU), and perform a dummy forward pass to verify that the output shapes match the expected dimensions `(Batch, Seq_Len, Num_Targets)`.
4.  **Loss and Metric Verification**: We initialize the `AnchoredMCRMSELoss` and `MCRMSEMetric`. We compute the loss on the dummy batch and verify the metric calculation logic.
5.  **Training Loop Execution**: We manually set up an optimizer and execute `train_one_epoch` and `validate` functions from the library to demonstrate the training workflow and ensure the loss is being calculated and backpropagated correctly.
6.  **Inference and Submission**: We generate predictions using the `generate_submission` function and verify that the output CSV file is created correctly with the required columns and row counts.
