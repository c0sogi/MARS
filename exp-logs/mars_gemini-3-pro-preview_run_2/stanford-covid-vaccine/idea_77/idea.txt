Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Anchored Dense-Feedback Recurrent Network (ADF-RN)**.

This strategy optimizes the architecture of the "Current Best" solution (Idea 36) by integrating the critical stability and robustness improvements identified in subsequent experiments. It explicitly rejects the "Hybrid Stem" and "Direct Access" over-engineering (Cite solution_lesson_node_00149) in favor of a standard **High-Capacity Dense Backbone** that inherently preserves raw features. It corrects the **Feedback Noise** issue via **Strict Channel Masking** (Cite solution_lesson_node_00118) and stabilizes the bidirectional aggregator using **Boundary Anchoring** (Cite solution_lesson_node_00136), while upgrading the micro-architecture with **SiLU** and **Full-Rank Convolutions** (Cite solution_lesson_node_00116, solution_lesson_node_00117).

# Model

### 1. Input Representation (Partner-Aware)
*   **Features:** One-Hot Encoding for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level (Cite solution_lesson_node_00052).
*   **Initial Projection:** The raw features are processed by a **Standard Convolution (Kernel 3)**. This serves as the "Stem," projecting sparse inputs to the dense feature dimension and providing immediate spatial mixing (Cite solution_lesson_node_00125) without the need for parallel branches.
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels (Cite solution_lesson_node_00090).

### 2. Main Backbone (Post-Activation Dense Dilated TCN)
*   **Architecture:** A stack of **Single-Layer Dilated Blocks** utilizing **Dense Connections** (concatenating outputs of all prior blocks).
    *   **Rationale:** Dense connections are superior to Residual connections for 1D dilated networks (Cite solution_lesson_node_00145) and inherently preserve raw feature access throughout the depth (Cite solution_lesson_node_00149).
*   **Micro-Architecture (Post-Activation & Robust):**
    *   Structure: `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`.
    *   *Rationale:* **Post-Activation** is optimal for this depth (Cite solution_lesson_node_00125). **Standard Convolutions** preserve capacity (Cite solution_lesson_node_00116). **SiLU** prevents dead neurons (Cite solution_lesson_node_00117).
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Growth Rate **64**. We strictly maintain high backbone capacity (Cite solution_lesson_node_00037).
*   **Latent Projection:** Output projected to **Latent Dim 64** ($Z$) (Cite solution_lesson_node_00062).

### 3. Global-Context Dense-Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Channel Masking:** Strictly zero out unscored targets (`deg_pH10`, `deg_50C`) (Cite solution_lesson_node_00118).
*   **Global Context:** **DO NOT** mask unscored sequence positions. Feed the full 107-length prediction to preserve global folding context (Cite solution_lesson_node_00133).
*   **Architecture:** A **Lightweight Dense TCN** (Growth Rate 16).
    *   *Rationale:* Uses Dense connectivity for superior signal propagation (Cite solution_lesson_node_00047) but remains lightweight to prevent overfitting (Cite solution_lesson_node_00103).
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 4. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$, gather and concatenate $[Z_i, E_{fb, i}]$ (Self) and $[Z_j, E_{fb, j}]$ (Partner) (Cite solution_lesson_node_00031, solution_lesson_node_00105).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)** (Cite solution_lesson_node_00117).

*   Yield Augmented Input, Partner Index Map, and Targets (Full Length).

# Training

### 1. Optimization Strategy
*   **Batch Size:** Strictly set to **16** to maximize gradient updates (Cite solution_lesson_node_00129).
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Channel-Masked $\hat{Y}_0$.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Channel-Masked $R$.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 3. Anchored Loss Function
*   **Boundary Anchoring:** Calculate MCRMSE loss over the **entire 107-length sequence**.
    *   *Rationale:* Training the model to predict the neutral baseline (`0.0`) in the tail anchors the bidirectional RNN hidden states, preventing drift and noise injection into the valid region (Cite solution_lesson_node_00136).
*   **Total Loss:** $L_{total} = \text{MCRMSE}_{0-107}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}_{0-107}(\hat{Y}_1)$.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Channel-Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$ (Flattened).

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root. Calculate this metric **only on the 68 valid positions** to accurately assess performance (Cite solution_lesson_node_00131, solution_lesson_node_00020).
