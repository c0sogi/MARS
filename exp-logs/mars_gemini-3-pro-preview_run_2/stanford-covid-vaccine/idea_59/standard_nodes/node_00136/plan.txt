This script implements the end-to-end pipeline for the RNA degradation prediction task. It leverages the provided library modules to train a Dual-Stem Recurrent Dense Network (DS-RDN), evaluates it on the validation set, performs failure analysis to identify error sources, and generates a submission file if the performance criteria are met.

**Strategy:**
1.  **Configuration:** We import the configuration and monkey-patch `EPOCHS` to 10 to ensure the training completes quickly within the time limit while still allowing convergence on the small dataset.
2.  **Training:** We execute `library.train.train_model` with the full dataset (`debug=False`) to establish a robust baseline.
3.  **Validation:** We capture the best validation score returned by the training loop and print it in the specific format required (`Final Validation Metric: <value>`).
4.  **Failure Analysis:** We reload the best saved model and perform inference on the validation set. We calculate the MCRMSE for each sample individually. We then load the validation metadata (`val.csv`) and compute Pearson correlations between the sample errors and key features like `signal_to_noise`, `seq_length`, and `mean_reactivity`. This helps diagnose if low signal-to-noise ratio or specific sequence properties drive errors.
5.  **Submission:** If the validation score is below the threshold (0.4714...), we call `library.train.generate_submission` to create the `submission.csv` file.
