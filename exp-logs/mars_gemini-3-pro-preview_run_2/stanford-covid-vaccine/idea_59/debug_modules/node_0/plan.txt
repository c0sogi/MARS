This script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:

1.  **Configuration**: Patches the configuration settings (Epochs, Working Directory) to ensure a fast, isolated execution suitable for a demo.
2.  **Unit Testing**: Verifies the core components:
    *   **Model Architecture**: Instantiates the `DSRDN` model and checks input/output shapes with dummy data.
    *   **Loss Function**: Validates the `MCRMSELoss` logic using synthetic perfect and imperfect predictions.
3.  **Training Pipeline**: Runs the training loop using `library.train.train_model` with the `debug=True` flag to use a subset of data.
4.  **Inference Pipeline**: Generates a submission file using `library.train.generate_submission` with the trained model.
5.  **Output Validation**: Checks the integrity of the generated submission file (dimensions, columns, and value ranges).
