Implementation Strategy:
1.  **Environment Setup**: Import necessary standard libraries and the provided custom library modules (`library.config`, `library.data`, `library.model`, `library.loss`, `library.train`).
2.  **Configuration Override**: Dynamically modify the `Config` class attributes to create a lightweight execution environment. This includes setting a separate working directory, enabling debug mode (small data subset), reducing batch size, and setting epochs to 1.
3.  **Data Pipeline Verification**: Initialize the data loaders using `get_dataloaders`. Fetch a single batch to verify the shapes of inputs (`x`), partner indices (`p_idx`), and targets (`y`) against the expected dimensions defined in `Config`.
4.  **Model Architecture Verification**: Instantiate the `RHIGFN` model. Perform a two-pass forward operation (Pass 1: No feedback, Pass 2: With feedback) to ensure the feedback mechanism and tensor shapes are correct.
5.  **Loss Function Verification**: Calculate the `mcrmse_loss` on the model output and verify the `GlobalMCRMSE` accumulator class functions correctly by updating it with a batch and computing the result.
6.  **Training & Validation Simulation**: Execute `train_one_epoch` and `validate` functions to ensure the training loop and evaluation logic run without errors and produce valid scalar metrics.
7.  **Submission Generation**: Run the `generate_submission` function to produce a CSV file. Verify the file's existence and check that the number of rows matches the expected count (Samples × Sequence Length).
8.  **Assertions**: Embed assertions throughout the script to strictly validate shapes, non-NaN values, and file integrity.
