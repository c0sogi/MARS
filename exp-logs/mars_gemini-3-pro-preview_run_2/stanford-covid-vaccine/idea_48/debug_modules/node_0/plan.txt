### Implementation Strategy

1.  **Environment Setup**: Initialize random seeds using `library.utils.seed_everything` to ensure reproducibility.
2.  **Data Subsetting**: Instead of loading the full dataset, read the first few rows of `train.csv`, `val.csv`, and `test.csv` from the `./metadata` directory. This creates "mini" datasets to ensure the script runs quickly (under 1 minute).
3.  **Data Processing**: Directly utilize `library.data.process_data` to convert these pandas DataFrames into the numpy format required by the model, bypassing the caching mechanism for this ephemeral run.
4.  **Component Verification**:
    *   **Model**: Instantiate the `EIPFN` model from `library.model`. Run a dummy forward pass with random data to verify the output shape matches `(Batch, 5, Seq_Len)`.
    *   **Loss**: Instantiate `MCRMSELoss` from `library.loss_metric`. Compute loss on dummy tensors and assert it matches a manual calculation to verify the metric logic.
5.  **Training Loop**: Configure a PyTorch optimizer and scheduler. Execute the `library.engine.train_model` function for a small number of epochs (2) using the mini-dataloaders.
6.  **Inference & Submission**: Perform inference on the mini-test set. Construct a submission DataFrame in the required format, ensuring all sequence positions are accounted for.
7.  **Cleanup**: The script operates within `./working` and does not modify input files.
