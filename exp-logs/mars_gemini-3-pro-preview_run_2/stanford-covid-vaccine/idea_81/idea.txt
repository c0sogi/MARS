Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Anchored Hybrid-Dense Recurrent Network (AHD-RN)**.

This strategy optimizes the "Dense-Context" architecture (proven effective in Idea 36) by integrating structural solutions to the identified conflicts: **Spatial Context** vs. **Raw Identity** (Lessons 00125, 00128), and **Global Consistency** vs. **Loss Masking** (Lessons 00133, 00136). It strictly enforces the **Small Batch Regime** (Lesson 00129) and upgrades the micro-architecture for robustness (Lessons 00111, 00116, 00117).

# Model

### 1. Input Representation (Hybrid & Partner-Aware)
*   **Features:** One-Hot Encoding for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level (Cite solution_lesson_node_00052).
*   **Hybrid Input Stem:** We construct the input to the backbone by concatenating two parallel branches:
    *   **Branch A (Identity):** The raw, sparse One-Hot features.
    *   **Branch B (Context):** The One-Hot features processed by a **Spatial Convolution (Kernel 3)** followed by **Layer Normalization** and **SiLU**.
    *   **Rationale:** This resolves the conflict between **Lesson 00125** (Need Spatial Mixing) and **Lesson 00128** (Need Raw Identity). Branch B provides immediate n-gram context, while Branch A ensures the deep layers maintain a "line of sight" to discrete nucleotide identities via dense connections.
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels (Cite solution_lesson_node_00090).

### 2. Main Backbone (Post-Activation Dense Dilated TCN)
*   **Architecture:** A stack of **Single-Layer Dilated Blocks** utilizing **Dense Connections** (concatenating outputs of all prior blocks).
    *   **Rationale:** Dense connections are superior to Residual connections for 1D dilated networks as they explicitly preserve features from varying receptive fields (Cite solution_lesson_node_00145).
*   **Micro-Architecture (Post-Activation & Decoupled):** We employ **Post-Activation** blocks structured to decouple spatial aggregation from channel mixing (Cite solution_lesson_node_00111):
    *   Structure: `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`.
    *   *Rationale:* **Post-Activation** maximizes initial signal variance (Cite solution_lesson_node_00125). **Standard Convolutions** preserve capacity (Cite solution_lesson_node_00116). **SiLU** prevents dead neurons (Cite solution_lesson_node_00117).
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Growth Rate **48**. This provides a balanced capacity, higher than the underfitting models (Growth 32) but lighter than the overfitting ones (Growth 64 with complex stems) (Cite solution_lesson_node_00149).
*   **Latent Projection:** Output projected to **Latent Dim 64** ($Z$) via Linear 1x1 Conv (Cite solution_lesson_node_00062).

### 3. Global-Context Pure-Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Channel Masking:** Strictly zero out unscored targets (`deg_pH10`, `deg_50C`) (Cite solution_lesson_node_00118).
*   **Global Sequence Context:** **DO NOT** mask unscored sequence positions. Feed the full 107-length prediction to preserve global folding context (Cite solution_lesson_node_00133).
*   **Architecture:** A **Lightweight Dense TCN** (Growth Rate 16) (Cite solution_lesson_node_00103).
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 4. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$, gather and concatenate $[Z_i, E_{fb, i}]$ (Self) and $[Z_j, E_{fb, j}]$ (Partner) (Cite solution_lesson_node_00031).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)** (Cite solution_lesson_node_00117).

# Data

*   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_ahd_rn_v1.npz`) (Cite solution_lesson_node_00032).
*   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
*   **Boundary Targets:** Fill unscored tail positions (68-107) with `0.0` to provide a neutral baseline for anchoring (Cite solution_lesson_node_00136).

### 2. Loaders
*   Yield Augmented Input, Partner Index Map, and Targets (Full Length).

# Training

### 1. Optimization Strategy
*   **Batch Size:** Strictly set to **16** to maximize gradient updates (Cite solution_lesson_node_00129).
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Channel-Masked $\hat{Y}_0$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Channel-Masked $R$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 3. Anchored Loss Function
*   **Boundary Anchoring:** Calculate MCRMSE loss over the **entire 107-length sequence**.
    *   *Rationale:* Masking the loss in the tail causes the Bidirectional RNN's backward pass to drift. Training on the neutral baseline (`0.0`) anchors the hidden states and stabilizes global aggregation (Cite solution_lesson_node_00136).
*   **Total Loss:** $L_{total} = \text{MCRMSE}_{0-107}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}_{0-107}(\hat{Y}_1)$.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Channel-Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$ (Flattened).

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root. Calculate this metric **only on the 68 valid positions** (Cite solution_lesson_node_00131, solution_lesson_node_00020).
