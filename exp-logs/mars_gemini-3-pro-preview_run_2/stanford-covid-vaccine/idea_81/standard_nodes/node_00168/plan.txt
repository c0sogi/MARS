Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration Override**: To ensure the training completes within the time limit, I will override the `Config.NUM_EPOCHS` to 20. This allows sufficient convergence for the baseline without exceeding the runtime.
2.  **Training Pipeline**: I will utilize the `engine.train_model()` function to handle the training loop, validation, and model checkpointing. This function returns the best validation metric, which I will capture.
3.  **Validation Reporting**: I will print the final validation metric in the strictly required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   I will load the trained model and run inference on the validation set in evaluation mode.
    *   I will calculate the Root Mean Squared Error (RMSE) for each sample individually.
    *   I will load the validation metadata (`val.csv`) to extract features like `signal_to_noise` and calculate `GC_content` from the sequences.
    *   I will compute and print the Pearson correlation between these features and the sample-wise RMSE to identify sources of systematic error.
5.  **Submission Generation**: I will compare the best validation metric against the threshold (`0.47142532743789534`). If the model performs better (lower metric), I will call `engine.generate_submission()` to create the `submission.csv` file.
