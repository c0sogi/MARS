The following script demonstrates the complete pipeline for the RNA Degradation Prediction task using the provided library. It performs the following steps:

1.  **Configuration Override**: Modifies the `Config` class at runtime to set up a fast, low-resource environment (Debug mode, fewer epochs, temporary directories).
2.  **Data Loading & Verification**: Initializes DataLoaders using `get_dataloaders` and verifies the shape and integrity of the batches (inputs, partner indices, and targets).
3.  **Model Initialization & Forward Pass**: Instantiates the `AS_DRN` model, performs a forward pass with a sample batch, and asserts that the output dimensions match the expected shapes `(Batch, Seq_Len, Targets)`.
4.  **Training Loop Execution**: Runs a manual training loop for a few epochs using `train_epoch` and `validate`, ensuring the loss decreases or remains valid (not NaN).
5.  **Submission Generation**: Generates a submission file using `generate_submission` and validates the output CSV format (row counts, column names).
