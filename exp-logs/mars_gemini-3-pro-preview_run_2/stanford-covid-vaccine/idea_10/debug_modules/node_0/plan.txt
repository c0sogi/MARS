The following script demonstrates the usage of the provided library components for the RNA degradation prediction task. It covers data loading, model instantiation, metric verification, a short training loop, and inference.

**Implementation Strategy:**
1.  **Setup & Imports**: Import necessary modules and set random seeds for reproducibility.
2.  **Data Loading**: Use `get_loaders` to load the dataset. We verify the integrity of the data by asserting the shapes of the features (sequence, structure, loop encodings), partner indices, and target values.
3.  **Model Verification**: Instantiate `StagedInteractiveDenseNet`. Perform a forward pass with a single batch to ensure the model architecture accepts the input tensors and produces outputs of the expected shape `(Batch, SeqLen, NumTargets)`.
4.  **Metric Logic Check**: Validate the `GlobalMCRMSE` class. We create synthetic prediction and target tensors with known differences to confirm that the metric computes the Root Mean Squared Error correctly on the specific scored columns.
5.  **Training Demonstration**: Execute a custom, shortened training loop (2 epochs) using `train_fn` and `eval_fn` from `library.engine`. This avoids the long runtime of the full configuration while proving the pipeline works.
6.  **Inference & Submission**: Run `predict_fn` on the test set, verify the output dimensions, and demonstrate how to format the predictions into the required CSV format.
