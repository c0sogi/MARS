4.  **Model & Loss Verification**: We will instantiate the `AHCHIDN` model and the `AnchoredMCRMSELoss`. We will perform a forward pass with dummy tensors to verify the model's output shape and calculate the loss to ensure it produces a valid scalar value.
5.  **Training Loop**: We will initialize the `Trainer` and run the `fit()` method. This will execute a short training cycle, demonstrating the training logic and saving the best model checkpoint.
6.  **Inference & Submission**: Finally, we will load the trained model, perform inference on the test set using the two-pass recycling mechanism, and format the predictions into a standard submission CSV file, verifying the final output format.
