The following is the implementation strategy for the `runfile.py` script:

1.  **Environment Setup**: Initialize the environment by setting random seeds for reproducibility and defining the computation device (GPU/CPU).
2.  **Training**: Execute the training workflow using `library.train.run_training`. We will limit the training to 15 epochs to ensure the script completes quickly while still providing a robust baseline.
3.  **Validation & Metric Calculation**:
    *   Load the best saved model state.
    *   Iterate through the validation dataset using the two-pass recurrent inference strategy (Pass 1: zero initialization, Pass 2: recycled predictions).
    *   Collect predictions and targets.
    *   Compute the **MCRMSE** metric specifically on the scored columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) and masked to the first 68 positions.
    *   Print the result in the exact required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the error magnitude (MCRMSE) for each individual sample in the validation set.
    *   Load the validation metadata (`metadata/val.csv`) to retrieve sample attributes like `signal_to_noise` and `SN_filter`.
    *   Compute and print the Pearson correlation between the error magnitude and these metadata features to identify potential causes of model failure.
5.  **Submission**:
    *   Compare the calculated validation metric against the threshold (`0.5417620723771521`).
    *   If the model performance is sufficient (metric < threshold), invoke `library.train.generate_submission` to create the `submission.csv` file for the test set.
