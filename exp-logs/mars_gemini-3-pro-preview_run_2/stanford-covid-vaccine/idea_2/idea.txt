# Model: Graph-Enhanced Hybrid Network (GEHN)

I propose a multi-stage hybrid architecture that explicitly models the three distinct modalities of RNA stability: local sequence motifs, secondary structure folding (physical proximity), and global sequence context.

1.  **Feature Extraction (Dilated CNN Backbone):**
    *   The model begins with the **Dilated Residual Convolutional Network** established in the baseline. This component utilizes exponentially increasing dilation rates ($d=1, 2, 4, \dots$) to capture local and medium-range sequence motifs without pooling, preserving the required 107-length resolution (Cite Lesson 00002).
2.  **Structural Refinement (Graph Neural Network):**
    *   **Innovation:** I introduce a **Graph Neural Network (GNN)** module inserted after the CNN backbone.
    *   Unlike the CNN (which sees sequence neighbors) or the RNN (which sees temporal neighbors), the GNN explicitly utilizes the provided `structure` data. An adjacency matrix is constructed for each sample where nodes are bases, and edges represent both the phosphodiester backbone ($i \leftrightarrow i+1$) and hydrogen bonds (base pairs $i \leftrightarrow j$ derived from the `(` `)` notation).
    *   The CNN output features are treated as node embeddings and passed through 2-3 layers of Relational Graph Convolution (RGCN) or Graph Attention (GAT). This allows information to flow directly between paired bases, simulating the physical stability constraints of the folded molecule.
3.  **Global Sequence Aggregation (BiGRU Head):**
    *   The structurally refined features are then passed to a **Bidirectional GRU (BiGRU)**. This retains the successful hybrid approach of combining convolutional features with recurrent modeling to capture global sequence dependencies (Cite Lesson 00003).
    *   **Constraint:** The BiGRU will be configured with `hidden_size = input_dim // 2` to ensure the concatenated output dimension matches the input dimension, preventing parameter bloat and overfitting (Cite Lesson 00004).
4.  **Output Projection:**
    *   A final linear layer maps the BiGRU output to the 5 target variables.

# Data

1.  **Preprocessing:**
    *   **Sequence/Structure Encoding:** Continue using One-Hot Encoding for `sequence`, `structure`, and `predicted_loop_type`.
    *   **Graph Construction:** For each sample, parse the dot-bracket `structure` string to generate an Adjacency Matrix (or Edge List).
        *   Add edges for adjacent bases ($i, i+1$).
        *   Add edges for paired bases (e.g., index $i$ and index $j$ if they form a pair `(...)`).
    *   **Target Parsing:** Parse the stringified lists in `train.csv` back to numerical arrays.
2.  **Loaders:**
    *   The data loader must yield the One-Hot features (Batch, 107, Channels), the Adjacency Matrix/Edge Index (Batch, Nodes, Neighbors), and the Targets (Batch, 107, 5).

# Training

1.  **Loss Function:**
    *   Use **MCRMSE** (Mean Columnwise Root Mean Squared Error).
    *   **Crucial Strategy:** Calculate the loss on **all 5 target columns** (`reactivity`, `deg_Mg_pH10`, `deg_pH10`, `deg_Mg_50C`, `deg_50C`), even though only 3 are scored. The unscored targets serve as auxiliary tasks to regularize the shared representation and improve generalization on the scored targets (Cite Lesson 00006).
    *   Apply masking to ensure loss is only calculated on the first 68 positions (`seq_scored`).
2.  **Optimizer:**
    *   Use **AdamW** with a learning rate of 1e-3 and a `ReduceLROnPlateau` scheduler.
3.  **Regularization:**
    *   Apply Dropout within the Residual Blocks and before the final projection.

# Evaluation

1.  **Inference:**
    *   Process the `test.csv` data through the same pipeline (One-Hot + Graph Construction).
    *   Generate predictions for all 107 positions for all 5 targets.
2.  **Submission:**
    *   Flatten the output to the `id_seqpos` format.
    *   Ensure that while the model predicts 5 values, they are mapped correctly to the submission columns.
