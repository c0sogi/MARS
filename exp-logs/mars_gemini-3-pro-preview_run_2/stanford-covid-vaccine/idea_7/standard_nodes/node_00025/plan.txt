The implementation strategy is as follows:

1.  **Setup and Configuration**: Import necessary modules and the provided library components. Programmatically override `Config.EPOCHS` to a small number (15) to ensure the training completes quickly, satisfying the "fast baseline" requirement. We retain the full dataset size as it is small (approx. 2000 samples), and subsampling via the provided `DEBUG` flag would incorrectly truncate the test set, preventing valid submission generation.
2.  **Training**: Execute the `run_training` function from `library.train`. This handles the entire training pipeline, including data loading, model initialization, optimization, and saving the best model checkpoint.
3.  **Validation**: After training, reload the validation data and the best model. Use the `validate` function to compute the global MCRMSE score. Print this score in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**: Implement a custom function to iterate over the validation set, calculating the MCRMSE error for each individual sample. Load the validation metadata (`metadata/val.csv`) and merge it with the per-sample errors. Calculate and print the Pearson correlation between the model error and key metadata features (specifically `signal_to_noise` and `mean_reactivity`) to identify sources of systematic error.
5.  **Submission**: Compare the final validation metric against the provided threshold (0.6477736930052439). If the model performs well enough (score < threshold), create the `./submission` directory and execute `run_inference` to generate the `submission.csv` file.
