We will then extract a single batch to assert that the shapes of the inputs (sequence, structure features), partner indices (for structure-aware processing), and targets match the expected dimensions defined in the configuration.
3.  **Model & Loss Logic Check**: We will instantiate the `HybridNet` model and the `MaskedMCRMSELoss` function. A forward pass will be performed on the extracted batch to ensure the model architecture is valid and produces outputs of the correct shape. We will also compute the loss to verify that the masking logic (handling the difference between predicted sequence length and scored target length) functions correctly without errors.
4.  **Training Loop Execution**: We will invoke `run_training` to simulate a complete training cycle (training, validation, scheduler updates, and checkpoint saving) over a minimal number of epochs.
5.  **Inference & Submission**: We will run `run_inference` to generate predictions using the trained model and save them to a CSV. Finally, we will validate the generated submission file to ensure it adheres to the competition's format requirements (correct columns and row counts).
