The model predicts values for the full sequence length (107), while the ground truth targets are only provided for the scored sequence length (68). The current implementation flattens the arrays before aligning their lengths, causing a mismatch when applying a boolean mask derived from the shorter targets array to the longer predictions array. The fix is to slice the predictions (or targets) to match the minimum sequence length while they are still in 3D shape `(Batch, Seq, Channels)`, before flattening them for metric calculation.
