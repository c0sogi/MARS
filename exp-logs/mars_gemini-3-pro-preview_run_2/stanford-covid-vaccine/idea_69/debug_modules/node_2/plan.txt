This triggers a `ValueError: not enough values to unpack` (Cite debug_lesson_16).

1.  Update `RNADataset.__getitem__` in `library/data.py` to include the sample ID in the return tuple.
2.  Update the training and evaluation loops in `library/engine.py` to unpack and ignore this new ID field, preventing "too many values to unpack" errors.
3.  Update the batch inspection step in `runfile.py` to correctly unpack the 4-element tuple.
