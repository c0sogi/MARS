Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Robust Hybrid-Stem Global-Feedback Network (RHS-GFN)**.

This strategy synthesizes the structural evolution of the "Dense-Context" architecture. It explicitly resolves the trade-off between **Spatial Context Extraction** and **Raw Feature Preservation** (Lessons 00125, 00128) by employing a **Hybrid Input Stem** without sacrificing backbone capacity (Lesson 00149). Furthermore, it optimizes the recycling mechanism by enforcing **Global Context Preservation** (Lesson 00133) in the feedback loop while applying **Strict Loss Masking** (Lesson 00139) to the optimization objective, ensuring physical consistency without multi-task conflicts.

# Model

### 1. Input Representation (Hybrid & Partner-Aware)
*   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels to avoid re-running the heavy main backbone (Cite solution_lesson_node_00090).

### 2. Hybrid Input Stem (Structural Innovation)
*   **Concept:** To satisfy both **Lesson 00125** (Need Spatial Mixing) and **Lesson 00128** (Need Raw Identity), we construct the input to the first backbone block by concatenating two parallel branches:
    *   **Branch A (Identity):** The raw, sparse One-Hot features.
    *   **Branch B (Context):** The One-Hot features processed by a **Spatial Convolution (Kernel 3)** followed by **Layer Normalization** and **SiLU**.
*   **Rationale:** This ensures the backbone receives both the exact nucleotide identities (crucial for base-pairing rules) and the immediate n-gram context (crucial for local motifs). Unlike prior attempts that reduced backbone capacity to fit this stem (Lesson 00149), we maintain full backbone capacity, using this lightweight concatenation only at the initialization stage.

### 3. Main Backbone (Post-Activation Dense Dilated TCN)
*   **Architecture:** A stack of **Single-Layer Dilated Blocks** utilizing **Dense Connections** (concatenating outputs of all prior blocks).
    *   **Rationale:** As established in **Lesson 00145**, Dense connections are superior to Residual connections for 1D dilated networks because they explicitly preserve features from varying receptive fields (scales) in separate channels.
*   **Micro-Architecture (Post-Activation & Decoupled):** We employ **Post-Activation** blocks structured to decouple spatial aggregation from channel mixing (Cite solution_lesson_node_00111):
    *   Structure: `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`.
    *   *Rationale:* **Post-Activation** maximizes initial signal variance (Cite solution_lesson_node_00125). We use **Standard Convolutions** (Cite solution_lesson_node_00116) and **SiLU** (Cite solution_lesson_node_00117) for robustness.
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Growth Rate **64**. We strictly maintain this high capacity to prevent underfitting, prioritizing backbone width over auxiliary complexity (Cite solution_lesson_node_00149, solution_lesson_node_00037).
*   **Latent Projection:** The output is projected to **Latent Dim 64** ($Z$) via a **Linear 1x1 Convolution** (Cite solution_lesson_node_00062, solution_lesson_node_00076).

### 4. Global-Context Pure-Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Channel Masking:** We strictly zero out the **channels** corresponding to unscored targets (`deg_pH10`, `deg_50C`) to prevent unsupervised noise injection (Cite solution_lesson_node_00118).
*   **Global Sequence Context:** Crucially, we **DO NOT** mask the unscored sequence positions (68-107). We feed the full sequence length back into the model. This preserves the global physical context required for accurate folding predictions in the scored region (Cite solution_lesson_node_00133).
*   **Spatial Feedback Stem:** We process the masked predictions with a **Standard Convolution (Kernel 3)** $\to$ LayerNorm $\to$ SiLU to extract local reactivity motifs (Extension of Cite solution_lesson_node_00125).
*   **Backbone:** A **Lightweight Dense TCN** (Growth Rate 16) processed in isolation from static features (Late Fusion) (Cite solution_lesson_node_00100, solution_lesson_node_00103).
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 5. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
        *   *Note:* This propagates the dynamic feedback through structural connections (Cite solution_lesson_node_00105).
*   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)**. We strictly limit the RNN capacity to match the feature dimension (Cite solution_lesson_node_00117).
*   **Output:** Linear projection to targets.

# Training

### 1. Optimization Strategy
*   **Batch Size:** Strictly set to **16**. This increases gradient update frequency (~108/epoch), which is critical for convergence on this small dataset (Cite solution_lesson_node_00129).
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Channel-Masked $\hat{Y}_0$ (Full Length) using **Spatial Stem + Feedback Backbone**.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Channel-Masked $R$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 3. Masked Loss Function
*   **Strict Sequence Masking:** We calculate the MCRMSE loss **only on the valid scored positions (0-67)**. We **do not** train on the zero-padded tail.
    *   *Rationale:* Training on artificial zeros (Anchoring) creates a multi-task conflict (Cite solution_lesson_node_00139). While the tail is used for context in the feedback loop, forcing the model to predict zeros there generates gradients that contradict the physics of the valid region. The Global-Context Feedback Loop provides the necessary stability constraints in Pass 2.
*   **Total Loss:** $L_{total} = \text{MCRMSE}_{0-67}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}_{0-67}(\hat{Y}_1)$.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Channel-Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$ (Flattened).

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root to avoid the optimistic bias of batch-averaging (Cite solution_lesson_node_00131, solution_lesson_node_00020).
