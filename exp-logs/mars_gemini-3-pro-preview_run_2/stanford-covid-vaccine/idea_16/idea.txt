Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Scale-Aligned Dense-Context Hybrid Network**. This strategy optimizes the "Dense-Context" architecture (Idea 8) by fundamentally restructuring the **Latent Interaction Mechanism**. It addresses the information bottleneck present in previous designs by enforcing **Scale-Aligned Feature Fusion**, allowing the model to correlate local and global contexts between paired bases at full resolution before compression.

# Model

The architecture is a **Dense Dilated TCN** that performs structural message passing on the full, multi-scale feature history rather than a compressed summary.

1.  **Input Representation (Dual-Context):**
    *   **Standard Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder to generate meaningful local features.

2.  **Backbone (Dense Dilated TCN):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** (Cite solution_lesson_node_00011) utilizing **Dense Connections**. The input to block $k$ is the concatenation of the outputs of all preceding blocks $0 \dots k-1$.
    *   **Configuration:** We employ exponentially increasing dilation rates ($d=1, 2, \dots, 32$) to ensure global receptive field coverage (Cite solution_lesson_node_00002).
    *   **Capacity & Regularization:** We strictly set the **Growth Rate / Channel Width** to **64** (Cite solution_lesson_node_00037) and apply **Dropout (0.1)** within every block (Cite solution_lesson_node_00038).
    *   **Output:** This produces a high-dimensional tensor $H_{dense}$ (e.g., $6 \times 64 = 384$ channels) containing the full multi-scale history of the sequence (Cite solution_lesson_node_00047).

3.  **Innovation: Scale-Aligned Latent Gather:**
    *   **Critique of Previous Approach:** In Idea 8, $H_{dense}$ was compressed to a small dimension (e.g., 64) *before* gathering the partner's features. This forced the model to summarize the local context without knowing the partner's state, potentially losing scale-specific correlations (e.g., matching local motifs vs. global folds).
    *   **New Mechanism (Late Compression):**
        *   **Full-Scale Gather:** For every position $i$ paired with $j$, we gather the **full uncompressed** feature vector $H_{dense}[j]$ (384 channels).
        *   **Scale-Aligned Concatenation:** We concatenate the local history $H_{dense}[i]$ with the partner history $H_{dense}[j]$ to form a massive interaction tensor (768 channels).
        *   **Interaction & Compression:** We apply a **1x1 Convolution** to project this tensor down to the RNN input dimension (e.g., 128).
    *   **Rationale:** This allows the projection layer to learn **Scale-Specific Interactions**. It can explicitly correlate the "Local Motif" (Layer 1) of base $i$ with the "Local Motif" (Layer 1) of base $j$, and simultaneously correlate their "Global Contexts" (Layer 6). This maximizes the utility of the "Dynamic Feature Gathering" (Cite solution_lesson_node_00031) by providing it with the complete, high-resolution signal generated by the "Dense" backbone.

4.  **Global Aggregation (BiGRU):**
    *   The scale-aligned, structurally fused features are processed by a **Bidirectional GRU** to capture global constraints (Cite solution_lesson_node_00003).
    *   **Constraint:** Hidden size is set to `input_dim // 2` to ensure the output dimension matches the input (Cite solution_lesson_node_00004).

5.  **Output Head:**
    *   Linear projection to the 5 target variables.
