To improve the model's performance, I will implement a **Latent Dense Network** that incorporates a projection bottleneck before the structural gathering step.

**Strategy:**
1.  **Latent Projection (Cite {solution_lesson_node_00062}):** The previous "Scale-Aligned" approach gathered the full, high-dimensional feature history (400+ channels) for paired bases, which likely introduced noise and optimization difficulties. I will modify the architecture to project the dense feature history into a compact latent space (64 channels) *before* performing the gather operation. This forces the model to distill the most relevant contextual information for the interaction.
2.  **Preserve Explicit Input (Cite {solution_lesson_node_00052}):** I will ensure the input features continue to include the explicit one-hot encoding of the partner identity, as removing this has been shown to degrade performance.
3.  **Dense Connectivity (Cite {solution_lesson_node_00047}):** I will retain the Dense Dilated TCN backbone to preserve multi-scale feature history.

-   **Config:** Update working directory to `idea_17`, add `LATENT_DIM = 64`, and update cache filenames to avoid stale data (Cite {solution_lesson_node_00032}).
