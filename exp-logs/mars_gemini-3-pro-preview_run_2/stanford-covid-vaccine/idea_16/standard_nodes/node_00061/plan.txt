The issue is that `numpy.load()` defaults to `allow_pickle=False` in recent versions, which prevents loading `.npz` files containing object arrays (like the string `ids` array in the cached datasets). To fix this, we must explicitly pass `allow_pickle=True` when loading the cached data in `library/data.py`. Cite debug_lesson_6.
