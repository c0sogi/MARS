The following is a self-contained Python script that demonstrates the usage of the provided library files for the RNA degradation prediction task.

**Strategy:**
1.  **Configuration**: We initialize the environment using `library.config`, setting the random seed and overriding hyperparameters (Epochs, Batch Size) to ensure the script runs quickly (Demonstration Mode).
2.  **Data Loading**: We utilize `library.dataset.RNADataset` with `debug=True` to load a small subset of the data, verifying the shapes of inputs, partner indices, and targets.
3.  **Model Verification**: We instantiate each component of the `HIGFDN` model (`HybridInputStem`, `DenseDilatedBackbone`, `FeedbackStem`, `InteractionModule`) individually to verify their input/output tensor shapes, followed by the full model.
4.  **Loss Function**: We test `MaskedMCRMSELoss` with synthetic data where the expected loss is known (1.0) to ensure the masking logic (scoring only specific columns and lengths) works correctly.
5.  **Training**: We execute a short training run using `library.train_utils.run_training` to demonstrate the training loop and model checkpointing.
6.  **Inference**: We generate a submission file using `library.model.generate_submission` and verify the output format and dimensions.
