The `ValueError: Object arrays cannot be loaded when allow_pickle=False` occurs because the cached dataset (`.npz` file) contains the `ids` array, which consists of strings. In NumPy, string arrays are often stored as object arrays, and loading them requires explicit permission (`allow_pickle=True`) for security reasons in recent versions. I will update the `np.load` call in `library/data.py` to enable pickling. I will also apply the same fix to `library/config.py` to ensure consistency across the codebase, as it contains an identical data loading function.
