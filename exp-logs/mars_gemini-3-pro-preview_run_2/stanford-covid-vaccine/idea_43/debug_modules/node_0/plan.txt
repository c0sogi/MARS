The following script demonstrates the usage of the provided library components for the RNA degradation prediction task. It performs the following steps:

1.  **Configuration**: Initializes the `Config` class in debug mode to use a tiny subset of the data for rapid execution. It redirects cache paths to a temporary working directory.
2.  **Data Loading**: Uses `get_loaders` to process the metadata CSVs, generate features (sequence one-hot, structure, loop type, partner identity), and create PyTorch DataLoaders. It verifies the shape of the generated batches.
3.  **Model Initialization**: Instantiates the `TISRNModel` (Topology-Informed Stabilized Recurrent Network) and verifies the output shapes of its two-pass forward mechanism.
4.  **Loss Calculation**: Demonstrates the `MCRMSELoss` function, ensuring it correctly handles the specific scored columns and masking.
5.  **Training & Validation**: Runs a single epoch of training and a validation pass using the provided training functions, ensuring the pipeline runs end-to-end without errors.
6.  **Metric Tracking**: Independently verifies the `MetricTracker` logic using controlled dummy data to ensure the MCRMSE calculation is mathematically correct.
