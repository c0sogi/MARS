The implementation strategy follows the standard machine learning pipeline tailored for the RNA degradation task. 

1.  **Setup & Configuration**: We initialize the `Config` class, overriding the epoch count to 15 to satisfy the "fast baseline" requirement while ensuring sufficient convergence on the small dataset (1728 samples). We set random seeds for reproducibility.
2.  **Data Loading**: We utilize the provided `get_loaders` function to efficiently load training, validation, and test datasets, leveraging the caching mechanism to speed up execution.
3.  **Model Training**: We instantiate the `TISRNModel` (Topology-Informed Stabilized Recurrent Network) and train it using the `train_one_epoch` function. We employ an `AdamW` optimizer and a `ReduceLROnPlateau` scheduler. The training loop saves the model with the best validation MCRMSE.
4.  **Validation**: After training, we load the best model checkpoint and perform a final evaluation on the full hold-out validation set to compute the `Final Validation Metric`.
5.  **Failure Analysis**: We perform a post-hoc analysis by calculating the MCRMSE for each validation sample and correlating these errors with metadata features (Signal-to-Noise, Mean Reactivity) to identify systematic weaknesses.
6.  **Submission Generation**: If the final validation metric meets the specified threshold (< 0.4714...), we generate predictions for the test set. The predictions are flattened and formatted into the required `id_seqpos` structure, ensuring all 5 target columns are present, and saved to `submission.csv`.
