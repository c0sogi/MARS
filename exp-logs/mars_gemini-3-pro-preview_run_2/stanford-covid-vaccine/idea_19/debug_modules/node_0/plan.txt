The following script demonstrates the usage of the provided library modules for the RNA degradation prediction task. It includes:

1.  **Configuration Override**: Modifies the cache version to ensure the script processes a small debug subset rather than loading potentially large pre-existing caches.
2.  **Unit Verification**: Validates the logic of structure parsing, model input/output shapes, and the custom masked loss function.
3.  **Training Pipeline Execution**: Runs a complete training and inference cycle using the `run_training` driver with debug settings (small dataset, 1 epoch).
