The following script demonstrates the end-to-end usage of the provided library components for the RNA degradation prediction task. It initializes the configuration for a quick debug run, loads and verifies the data using the custom `RNADataset` and `DataLoader`, performs a model forward pass to validate tensor shapes, calculates the MCRMSE loss, and executes the training and inference pipelines using the `Engine` class. Finally, it validates the generated submission file format.
