Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` object, overriding the number of epochs to 15 to ensure a fast baseline execution while maintaining sufficient convergence. Ensure the output directory structure exists.
2.  **Data Loading**: Use `get_dataloaders` from `library.data` to load training, validation, and test sets. This leverages the caching mechanism implemented in the library.
3.  **Training**: Instantiate the `Engine` and run the training loop. The engine handles the model initialization, optimizer, scheduler, and the custom `MCRMSELoss`.
4.  **Evaluation**: After training, load the best model checkpoint and compute the `Final Validation Metric` on the full validation set using the `evaluate` method.
5.  **Failure Analysis**:
    *   Perform inference on the validation set to obtain predictions.
    *   Calculate the Mean Squared Error (MSE) for each sample.
    *   Load the validation metadata (specifically `signal_to_noise` and `seq_length`) from `val.csv`.
    *   Compute and print the Pearson correlation between the sample error and these metadata features to identify error sources.
6.  **Submission**: Compare the validation metric against the threshold (0.4714...). If successful, generate predictions for the test set and save the formatted submission file to `./submission/submission.csv`.
