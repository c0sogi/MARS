Strategy:
1.  **Restrict Model Output to Scored Targets**: Modify the model to predict only the 3 scored targets (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) instead of all 5. This prevents the feedback loop from ingesting noise from the 2 unscored (and thus unconstrained) targets, which would otherwise destabilize the iterative refinement process. This aligns with **Lesson `solution_lesson_node_00016`** (Direct Metric Optimization) and **Lesson `solution_lesson_node_00090`** (Iterative Prediction Feedback).
2.  **Normalize Feedback Signal**: Add a `LayerNorm` to the projected feedback embedding in the `LatentFeedbackInteraction` module. This ensures that the scale of the recycled predictions aligns with the latent features from the backbone, improving optimization stability as per **Lesson `solution_lesson_node_00085`**.
3.  **Update Loss and Submission Logic**: Adapt the `mcrmse_loss` function and submission generation script to handle the mismatch between the model's 3-channel output and the dataset's 5-channel structure.

def mcrmse_loss(pred, target, scored_indices=SCORED_INDICES):
    """
    Calculates the Mean Columnwise Root Mean Squared Error (MCRMSE) loss.

    The metric is defined as the average of the RMSE values for each scored column.
    Only the columns specified by scored_indices are used in the calculation.

    Args:
        pred (torch.Tensor): Predicted values of shape (Batch, ..., Channels).
        target (torch.Tensor): Ground truth values of shape (Batch, ..., Channels).
        scored_indices (list, optional): List of indices corresponding to the columns
                                         to be scored. Defaults to SCORED_INDICES from config.
                                         (reactivity, deg_Mg_pH10, deg_Mg_50C).

    Returns:
        torch.Tensor: Scalar tensor containing the MCRMSE loss.

    # Assuming the last dimension is the channel dimension
    pred_scored = pred[..., scored_indices]
    target_scored = target[..., scored_indices]

    # We average over all dimensions except the last (channel) dimension
    mse = torch.mean(
