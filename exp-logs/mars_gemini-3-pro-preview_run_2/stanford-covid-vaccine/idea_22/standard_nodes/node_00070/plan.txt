Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Setup & Initialization**: Initialize the environment using `Config.setup()` and ensure reproducibility with `set_seed()`. Define the computation device (GPU/CPU).
2.  **Data Loading**: Utilize `get_loader` to load training and validation data. We enable `load_cached_data=True` to leverage preprocessed `.npz` files for speed.
3.  **Model Training**: Instantiate the `DecoupledDenseNet`, `MaskedMCRMSELoss`, and `AdamW` optimizer. Execute a training loop for a maximum of `Config.EPOCHS`, employing `train_epoch` and `validate` functions. Implement early stopping and save the best model state based on the validation MCRMSE.
4.  **Final Evaluation**: Load the best model weights. Compute the final MCRMSE on the full validation set using the `validate` function. Print the metric in the required format.
5.  **Failure Analysis**:
    *   Compute the Mean Squared Error (MSE) for each sample in the validation set.
    *   Load the validation metadata (`metadata/val.csv`).
    *   Calculate correlations between the sample-wise error and metadata features (e.g., `signal_to_noise`, `mean_reactivity`, base counts).
    *   Print the top correlations to identify error sources.
6.  **Submission**: Check if the final validation metric is below the threshold (`0.5417620723771521`). If so, generate predictions for the test set using `generate_submission` and move the output file to the `./submission/submission.csv` location as requested.
