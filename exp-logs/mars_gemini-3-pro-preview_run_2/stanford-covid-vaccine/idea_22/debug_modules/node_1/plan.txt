The issue is caused by Python evaluating default function arguments at definition time. When `library.data` is imported, `get_loader` captures the initial value of `Config.BATCH_SIZE` (16) as its default argument. To fix this, the default values for `batch_size` and `num_workers` in `get_loader` should be changed to `None`, and the current values from `Config` should be assigned inside the function body.
