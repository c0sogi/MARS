Based on the comprehensive analysis of the provided lessons, specifically the failure of **Dense Architectures** in low-data regimes (Lesson 00143) and the importance of **Spatial Context** (Lesson 00125) and **Correct Metric Implementation** (Lesson 00131), I propose the **Spatial-Stem Residual-Feedback Network (SS-RFN)**.

This strategy structurally evolves the "Iterative Refinement" approach by reverting to a **Fixed-Width Residual Backbone** (proven superior to DenseNets for this dataset) while integrating the robust micro-architectural optimizations (Decoupled Blocks, SiLU) and strict training protocols (Small Batch, Masked Loss) identified in recent experiments.

# Model

### 1. Input Representation (Spatial & Partner-Aware)
*   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
*   **Spatial Input Stem:** We process the concatenated One-Hot features with a **Standard Convolution with Kernel Size 3** followed by **Layer Normalization** and **SiLU**.
    *   *Rationale:* This ensures immediate mixing of adjacent nucleotides (n-grams) to create a dense, context-rich embedding, preventing the signal destruction caused by applying normalization directly to sparse inputs (Cite solution_lesson_node_00125, solution_lesson_node_00120).
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels (Cite solution_lesson_node_00090).

### 2. Main Backbone (Fixed-Width Residual Dilated TCN)
*   **Architecture:** A stack of **Dilated Residual Blocks**. Crucially, we use **Element-wise Addition** (Residual) rather than Concatenation (Dense) to maintain a fixed channel width throughout the depth.
    *   *Rationale:* As established in **Lesson 00143**, DenseNets expand feature dimensionality linearly, leading to overfitting on small datasets ($N < 2000$). A fixed-width Residual network forces the model to learn more efficient representations.
*   **Micro-Architecture (Decoupled & Robust):** We employ **Pre-Activation** blocks structured to decouple spatial aggregation from channel mixing (Cite solution_lesson_node_00111):
    *   Structure: `LayerNorm -> SiLU -> Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> Dropout(0.1)`.
    *   *Rationale:* We use **Standard Convolutions** (Cite solution_lesson_node_00116) and **SiLU** (Cite solution_lesson_node_00117) for robustness and gradient flow.
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Fixed Width of **128 channels**.

### 3. Residual Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Channel Masking:** We strictly zero out the **channels** corresponding to unscored targets (`deg_pH10`, `deg_50C`) (Cite solution_lesson_node_00118).
*   **Global Sequence Context:** We **DO NOT** mask the unscored sequence positions (68-107). We feed the full sequence length back to preserve global folding context (Cite solution_lesson_node_00133).
*   **Architecture:** A **Lightweight Residual TCN** (Width 32, 3 layers).
    *   *Rationale:* Keeps the feedback loop low-capacity relative to the backbone (Cite solution_lesson_node_00103) and processes it in isolation (Late Fusion) (Cite solution_lesson_node_00100).
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 4. Interaction & Aggregation
*   **Latent Projection:** Project the Backbone output (128) to 64 channels ($Z$).
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
        *   *Note:* This propagates the dynamic feedback through structural connections (Cite solution_lesson_node_00105).
*   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)** (Cite solution_lesson_node_00117).
*   **Output:** Linear projection to targets.

*   Yield Augmented Input, Partner Index Map, and Targets (Full Length).

# Training

### 1. Optimization Strategy
*   **Batch Size:** Strictly set to **16**. This increases gradient update frequency (~108/epoch), which is critical for convergence on this small dataset (Cite solution_lesson_node_00129).
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Channel-Masked $\hat{Y}_0$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Channel-Masked $R$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 3. Masked Loss Function
*   **Strict Sequence Masking:** We calculate the MCRMSE loss **only on the valid scored positions (0-67)**. We **do not** train on the zero-padded tail.
    *   *Rationale:* Training on artificial zeros creates a multi-task conflict. Masking ensures parameter updates are driven solely by valid signal (Cite solution_lesson_node_00139).
*   **Total Loss:** $L_{total} = \text{MCRMSE}_{0-67}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}_{0-67}(\hat{Y}_1)$.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Channel-Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$ (Flattened).

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root to avoid the optimistic bias of batch-averaging (Cite solution_lesson_node_00131, solution_lesson_node_00020).
