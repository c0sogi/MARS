Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Selective-Feedback Dense-Context Network (SF-DCN)**.

This strategy optimizes the state-of-the-art "Latent-Feedback" architecture (Idea 34) by refining the recycling mechanism. It identifies and corrects a critical source of noise: the recycling of unsupervised predictions. By implementing **Selective Recycling** (masking unscored targets) and **Feedback Dropout**, we ensure the iterative refinement loop is driven solely by reliable, supervised signals, while strictly adhering to the "Static Backbone" efficiency and "Partner-Aware" constraints established in prior successes.

# Model

1.  **Input Representation (Static & Partner-Aware):**
    *   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder to generate meaningful local features.
    *   **Static Input:** The input tensor is static; we do not augment it with recycling channels to avoid re-running the backbone (Cite solution_lesson_node_00090).

2.  **Backbone (Static Dense Dilated TCN):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** (Cite solution_lesson_node_00011) utilizing **Dense Connections** (concatenating outputs of all prior blocks). This preserves the full multi-scale history (Cite solution_lesson_node_00047).
    *   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
    *   **Capacity:** Growth Rate **64**, **Dropout 0.1** (Cite solution_lesson_node_00037, solution_lesson_node_00038).
    *   **Execution:** This backbone runs **exactly once** per batch to produce the dense feature tensor $H_{dense}$.

3.  **Selective-Feedback Interaction Module (Innovation):**
    *   **Feature Projection:** We project $H_{dense}$ to a **Latent Dimension of 64** ($Z$) using a **Linear 1x1 Convolution** (Cite solution_lesson_node_00076, solution_lesson_node_00062).
    *   **Selective Recycling:** We take the recycled predictions $\hat{Y}_{k-1}$ (5 channels). Crucially, we apply a **Binary Mask** to zero out the channels corresponding to the unscored targets (`deg_pH10`, `deg_50C`).
        *   *Rationale:* As we adhere to **Lesson 00016** (Masked Loss), the unscored targets receive no gradients and thus contain unsupervised noise. Feeding this "garbage" back into the model destabilizes the refinement loop. Masking ensures feedback is based only on reliable, supervised signals (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
    *   **Feedback Projection:** We process the masked predictions through a **Learnable Linear Projection** to produce a **Feedback Embedding** $E_{k-1}$ (32 channels) (Cite solution_lesson_node_00090).
    *   **Feedback Dropout:** We apply **Dropout (0.1)** to $E_{k-1}$. This prevents the model from over-relying on the feedback hint, forcing it to maintain reliance on the static features $Z$.
    *   **Augmented Gather:** For every position $i$ paired with $j$:
        *   **Self Vector:** Concatenate $[Z_i, E_{k-1, i}]$.
        *   **Partner Vector:** Gather $[Z_j, E_{k-1, j}]$.
    *   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).

4.  **Global Aggregation (BiGRU):**
    *   The fused features are processed by a **Bidirectional GRU** (Cite solution_lesson_node_00003).
    *   **Constraint:** Hidden size is set to `input_dim // 2` (Cite solution_lesson_node_00004).

5.  **Output Head:**
    *   Linear projection to the 5 target variables.

# Data

1.  **Preprocessing & Cache Safety:**
    *   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_sf_dcn_v1.npz`) to ensure input features are generated correctly (Cite solution_lesson_node_00032).
    *   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
    *   **Target Parsing:** Parse stringified targets to numerical arrays.

2.  **Loaders:**
    *   Yield Augmented Input, Partner Index Map, and Targets.

# Training

1.  **Iterative Refinement Loop:**
    *   **Step 1 (Backbone):** Compute $H_{dense}$ from static inputs once.
    *   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
    *   **Pass 1:**
        *   Mask & Project $\hat{Y}_0 \to E_0$.
        *   Run Interaction + RNN using $H_{dense}$ and $E_0$. Output $\hat{Y}_1$.
    *   **Pass 2:**
        *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
        *   Mask & Project $R \to E_1$.
        *   Run Interaction + RNN using $H_{dense}$ and $E_1$. Output $\hat{Y}_2$.

2.  **Loss Function:**
    *   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
    *   Calculate loss **only on scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) (Cite solution_lesson_node_00016).

3.  **Optimizer:**
    *   **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

# Evaluation

1.  **Inference:**
    *   Compute Backbone features once.
    *   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
    *   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
    *   Submit $\hat{Y}_2$.

2.  **Metric:**
    *   Use **Correct Global RMSE** (Cite solution_lesson_node_00020).
