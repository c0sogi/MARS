The implementation strategy involves the following steps:
1.  **Setup**: Initialize the environment by setting random seeds for reproducibility using `library.utils.seed_everything`.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. We will use the full dataset (`debug=False`) as the sample size (~2k) is small enough to train quickly on the provided A100 GPU within the time limit, ensuring we have the best chance to beat the performance threshold.
3.  **Validation & Metric Calculation**:
    *   Load the best model checkpoint saved during training.
    *   Perform inference on the validation set using the `AHCHDN` model.
    *   Calculate the "Final Validation Metric" (MCRMSE) using `library.utils.calculate_global_rmse` on the scored positions and columns.
    *   Print the metric in the required format.
4.  **Failure Analysis**:
    *   Compute the RMSE for each sample in the validation set.
    *   Load validation metadata (`val.csv`) to retrieve features like `signal_to_noise` and `mean_reactivity`.
    *   Calculate and print the Pearson correlation between the model's error (RMSE) and these features to identify systematic weaknesses.
5.  **Submission**:
    *   Compare the calculated validation metric against the threshold (0.47142532743789534).
    *   If the model performs better (lower metric), generate the submission file using `library.train.run_inference`.
