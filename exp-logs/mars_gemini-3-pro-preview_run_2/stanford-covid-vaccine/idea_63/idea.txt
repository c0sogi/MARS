Based on the progression of insights from the provided lessons, specifically the need to resolve the conflict between **Spatial Context** and **Raw Identity** (Lessons 00125, 00128) and the critical importance of **Global Context** in recycling (Lesson 00133) versus **Strict Masking** in optimization (Lesson 00139), I propose the **Hybrid-Stem Global-Feedback Dense Network (HS-GFDN)**.

This strategy synthesizes the robust "Dense-Context" backbone with a novel **Hybrid Input Stem** and a **Global-Context Pure-Feedback Loop**. It strictly enforces the **Small Batch Regime** (Lesson 00129) and **Micro-Architectural Robustness** (Lessons 00111, 00116, 00117).

# Model

### 1. Input Representation (Hybrid & Partner-Aware)
*   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) (Cite solution_lesson_node_00052).
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels to avoid re-running the heavy main backbone (Cite solution_lesson_node_00090).

### 2. Hybrid Input Stem (Structural Innovation)
*   **Concept:** To satisfy both **Lesson 00125** (Need Spatial Mixing) and **Lesson 00128** (Need Raw Identity), we construct the backbone input by concatenating two parallel branches:
    *   **Branch A (Identity):** The raw, sparse One-Hot features.
    *   **Branch B (Context):** The One-Hot features processed by a **Spatial Convolution (Kernel 3)** followed by **Layer Normalization** and **SiLU**.
*   **Rationale:** This ensures the backbone receives both the exact nucleotide identities (crucial for base-pairing rules) and the immediate n-gram context (crucial for local motifs), without "smearing" the discrete signal into a purely continuous embedding (Cite solution_lesson_node_00120).

### 3. Main Backbone (Post-Activation Dense Dilated TCN)
*   **Architecture:** A stack of **Single-Layer Dilated Blocks** utilizing **Dense Connections** (concatenating outputs of all prior blocks) (Cite solution_lesson_node_00047).
*   **Micro-Architecture (Post-Activation & Decoupled):** We employ **Post-Activation** blocks structured to decouple spatial aggregation from channel mixing (Cite solution_lesson_node_00111):
    *   Structure: `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`.
    *   *Rationale:* **Post-Activation** maximizes initial signal variance (Cite solution_lesson_node_00125). We use **Standard Convolutions** (Cite solution_lesson_node_00116) and **SiLU** (Cite solution_lesson_node_00117).
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Growth Rate **64** (Cite solution_lesson_node_00037).
*   **Latent Projection:** The output is projected to **Latent Dim 64** ($Z$) via a **Linear 1x1 Convolution** (Cite solution_lesson_node_00062, solution_lesson_node_00076).

### 4. Global-Context Pure-Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Channel Masking:** We strictly zero out the **channels** corresponding to unscored targets (`deg_pH10`, `deg_50C`) (Cite solution_lesson_node_00118).
*   **Global Sequence Context:** We **DO NOT** mask the unscored sequence positions (68-107). We feed the full sequence length back to preserve global folding context (Cite solution_lesson_node_00133).
*   **Spatial Feedback Stem:** We process the masked predictions with a **Standard Convolution (Kernel 3)** $\to$ LayerNorm $\to$ SiLU to extract local reactivity motifs (Cite solution_lesson_node_00125).
*   **Backbone:** A **Lightweight Dense TCN** (Growth Rate 16) processed in isolation from static features (Late Fusion) (Cite solution_lesson_node_00100, solution_lesson_node_00103).
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 5. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
        *   *Note:* This propagates the dynamic feedback through structural connections (Cite solution_lesson_node_00105).
*   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)** (Cite solution_lesson_node_00117).
*   **Output:** Linear projection to targets.

# Data

### 1. Preprocessing & Cache Safety
*   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_hs_gfdn_v1.npz`) to ensure input features are generated correctly (Cite solution_lesson_node_00032).
*   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
*   **Target Parsing:** Parse stringified targets to numerical arrays.

### 2. Loaders
*   Yield Augmented Input, Partner Index Map, and Targets (Full Length).

# Training

### 1. Optimization Strategy
*   **Batch Size:** Strictly set to **16**. This increases gradient update frequency (~108/epoch), which is critical for convergence on this small dataset (Cite solution_lesson_node_00129).
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Channel-Masked $\hat{Y}_0$ (Full Length) using **Spatial Stem + Feedback Backbone**.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Channel-Masked $R$ (Full Length).
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 3. Masked Loss Function
*   **Strict Sequence Masking:** We calculate the MCRMSE loss **only on the valid scored positions (0-67)**. We **do not** train on the zero-padded tail, avoiding the multi-task conflict of "Anchoring" (Cite solution_lesson_node_00139). The **Global-Context Feedback Loop** provides the necessary stability constraints in Pass 2 to mitigate RNN drift (Cite solution_lesson_node_00136).
*   **Total Loss:** $L_{total} = \text{MCRMSE}_{0-67}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}_{0-67}(\hat{Y}_1)$.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Channel-Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$ (Flattened).

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root to avoid batch-averaging bias (Cite solution_lesson_node_00020).
