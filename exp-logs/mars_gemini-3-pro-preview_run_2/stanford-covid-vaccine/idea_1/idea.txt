To establish a robust and efficient baseline, I propose a **Dilated Residual Convolutional Network (Dilated ResNet)**. 

This approach is distinct from the provided architectures: it eschews the recurrent layers of Model 2 (CNN+RNN) in favor of pure convolutional speed, avoids the complexity of Model 3 (Transformers) and Model 1 (GATs), and processes the sequence holistically rather than using the fragmented sliding-window approach of Models 4 and 5.

### Model
The architecture is a **Fully Convolutional Network** designed to capture both local motifs and long-range dependencies (such as base pairing) through dilated convolutions.

*   **Input Representation**: The model accepts a 3-channel input for each of the 107 sequence positions. These channels correspond to the One-Hot Encoded representations of:
    1.  `sequence` (A, G, U, C)
    2.  `structure` ( (, ), . )
    3.  `predicted_loop_type` (S, M, I, B, H, E, X)
    These are concatenated to form a tensor of shape `(Batch_Size, 107, Total_Features)`.

*   **Backbone (Dilated Residual Blocks)**: The core consists of a stack of residual blocks. Each block contains a 1D Convolutional layer, Batch Normalization, ReLU activation, and Dropout. Crucially, the **dilation rate** of the convolutions increases exponentially (e.g., 1, 2, 4, 8, 16, 32) across the stack. This allows the model to expand its receptive field to cover the entire 107-nucleotide sequence without using pooling operations (which lose spatial resolution) or recurrent connections (which slow down training).

*   **Output Head**: A final point-wise convolution (Kernel Size = 1) maps the high-dimensional features at each position directly to the 5 target variables (`reactivity`, `deg_Mg_pH10`, `deg_pH10`, `deg_Mg_50C`, `deg_50C`).

### Training
*   **Loss Function**: Implement the **MCRMSE** (Mean Columnwise Root Mean Squared Error) loss function. This custom loss will calculate the RMSE for each of the 5 target columns separately and average them. It should be masked to only calculate loss on the first 68 positions (as defined by `seq_scored`) to align with the competition metric, although the model predicts all 107.
*   **Optimizer**: Use **Adam** or **AdamW** with a standard learning rate (e.g., 1e-3) and a scheduler (e.g., ReduceLROnPlateau) to decay the rate when validation loss plateaus.
*   **Strategy**: Train for a fixed number of epochs (e.g., 50) with Early Stopping monitoring the validation MCRMSE. Given the small dataset size and lightweight model, training should complete very quickly on the A100 GPU.
