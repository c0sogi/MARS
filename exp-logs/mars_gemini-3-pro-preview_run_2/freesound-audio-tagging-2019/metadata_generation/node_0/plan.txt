Implementation Strategy:
1.  **Setup and Loading**: Initialize the script by importing necessary libraries (`pandas`, `numpy`, `os`, `skmultilearn`). Define paths for input and metadata directories. Load the curated training, noisy training, and sample submission CSV files.
2.  **Data Cleaning**: Filter out the known corrupted file and the five files with incorrect labels from the curated training dataset to ensure data quality.
3.  **Path Generation**: Construct relative file paths for all datasets. The curated files are in `train_curated/`, noisy files in `train_noisy/`, and test files in `test/`.
4.  **Stratified Split**:
    -   Parse the multi-label strings in the curated dataset into a binary matrix.
    -   Shuffle the curated dataset to ensure randomness (`random_state=42`).
    -   Use `iterative_train_test_split` from `skmultilearn` to split the curated dataset into 80% training and 20% validation sets. This ensures that the multi-label distribution is preserved in both sets.
5.  **Dataset Construction**:
    -   **Training Metadata**: Combine the 80% split of the curated data with the entire noisy dataset. This maximizes the amount of training data while keeping the validation set clean.
    -   **Validation Metadata**: Use the 20% split of the curated data.
    -   **Test Metadata**: Use the sample submission file, adding the generated file paths.
6.  **Saving**: Save the three DataFrames to `./metadata/train.csv`, `./metadata/val.csv`, and `./metadata/test.csv`.
7.  **Verification**:
    -   **File Existence**: Check a random sample of 1000 file paths from each generated metadata file to ensure they resolve to actual files in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
    -   **Split Ratio**: Verify that the curated data was split approximately 80:20.
    -   **Stratification**: Calculate the correlation between the label distributions of the original curated set and the validation set to confirm successful stratification. Raise an `AssertionError` if checks fail.
