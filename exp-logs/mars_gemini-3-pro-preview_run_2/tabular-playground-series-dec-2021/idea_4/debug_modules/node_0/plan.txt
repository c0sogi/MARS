Implementation Strategy:
1.  **Setup and Configuration**: Import necessary modules and the provided library components. Set random seeds for reproducibility. Override `Config` hyperparameters (e.g., reduce `n_estimators` for XGBoost, `epochs` for Neural Network) to ensure the script executes quickly for demonstration purposes.
2.  **Data Loading**: Use `library.data_factory.load_data` and `library.data_factory.prepare_nn_data` to load and preprocess the dataset. These functions handle reading from metadata, feature engineering, and scaling.
3.  **Subsampling**: To adhere to the speed requirement, subsample the loaded data to a small subset (e.g., 5,000 samples) for the training demonstration.
4.  **XGBoost Workflow**: Split the subsampled data into training and validation sets. Train an XGBoost model using `library.xgb_trainer.train_xgb_fold` and generate predictions with `predict_xgb`. Verify the output shapes.
5.  **Neural Network Workflow**: Create PyTorch `DataLoader` instances using `library.data_factory.ForestDataset`. Train a ResNetMLP model using `library.nn_trainer.train_nn_fold` and generate predictions with `predict_nn`. Verify the output shapes.
6.  **Ensemble Optimization**: Use `library.ensemble_optimizer.optimize_blending_weights` to calculate optimal weights for blending the XGBoost and Neural Network predictions. Demonstrate how to compute the weighted average.
7.  **Submission Generation**: Convert the model predictions (indices) back to the original class labels using `Config.ORIGINAL_LABELS` and construct a sample submission DataFrame.
