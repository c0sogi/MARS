Implementation strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided modules (`config`, `data_utils`, `ensemble`). Modify `config` parameters in-place to ensure the script runs within the "fast baseline" time limit (reduce folds, trees, epochs, and set a maximum training sample size).
2.  **Data Loading**: Use `data_utils.preprocess_data(load_cached_data=True)` to load the preprocessed training, validation, and test sets separately.
3.  **Data Preparation**:
    *   **Downsample Training Data**: To meet the time constraints, significantly downsample the training set (e.g., to 100,000 samples) while maintaining class stratification.
    *   **Combine Evaluation Sets**: Concatenate the full validation set and the test set. This allows the `StackingManager` to generate predictions for both in a single pass (since it accepts a single 'test' set argument).
4.  **Model Training (Level-0)**:
    *   Construct the data dictionary expected by `StackingManager.cross_validate_base_models`.
    *   Run cross-validation on the downsampled training data. This trains LightGBM and Neural Network models and generates OOF predictions (for meta-training) and predictions on the combined evaluation set.
5.  **Meta-Learning (Level-1)**:
    *   Train the Logistic Regression meta-learner on the OOF predictions and downsampled training targets.
6.  **Validation & Analysis**:
    *   Split the combined evaluation predictions back into validation and test sets.
    *   Use the meta-learner to predict class labels for the validation set.
    *   Compute and print the **Final Validation Metric** (accuracy) on the full hold-out validation set.
    *   Perform **Failure Analysis** on the validation set by calculating the correlation between input features and prediction errors.
7.  **Submission**:
    *   Compare the validation accuracy against the required threshold (`0.9604513888888889`).
    *   If the threshold is met, generate predictions for the test set using the meta-learner and save the submission file using `StackingManager.generate_submission`.
