The strategy for generating the metadata files is as follows:

1.  **Setup and Directory Creation**: Initialize the script by importing necessary libraries (`os`, `pandas`, `numpy`, `sklearn`) and creating the output directory `./metadata`.
2.  **Training Data Processing**:
    -   Read the ground truth labels from `./input/train_labels.csv`.
    -   Construct the relative file paths for each image using the directory structure convention (`train/{char0}/{char1}/{char2}/{image_id}.png`).
    -   Analyze the labels to determine the splitting strategy. If there are duplicate InChI strings (implying multiple images per molecule), perform a **Group Shuffle Split** to ensure no molecule appears in both training and validation sets (preventing data leakage). If labels are unique, perform a standard **Random Split**.
    -   Split the data into 80% training and 20% validation sets using a fixed random seed (`42`) for reproducibility.
    -   Save the resulting DataFrames to `./metadata/train.csv` and `./metadata/val.csv`.
3.  **Test Data Processing**:
    -   Read the sample submission file `./input/sample_submission.csv` to get the list of test image IDs.
    -   Construct the relative file paths for the test images (`test/{char0}/{char1}/{char2}/{image_id}.png`).
    -   Save the test metadata to `./metadata/test.csv`.
4.  **Validation and Verification**:
    -   Load the generated metadata files.
    -   Print summary statistics (dataset sizes, unique label counts).
    -   **File Existence Check**: Randomly sample 1000 paths from each dataset and verify they exist in the `./input` directory. Raise an error if the missing file ratio exceeds 0.5.
    -   **Split Verification**: Programmatically assert that the train/validation split ratio is approximately 80:20 and that there is no overlap in image IDs (and labels, if group splitting was used).
