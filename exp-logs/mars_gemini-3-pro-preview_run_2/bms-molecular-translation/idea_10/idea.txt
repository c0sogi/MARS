Based on the lessons learned, specifically the failure of the CTC-based baseline due to insufficient encoder output resolution (Lesson ID: `solution_lesson_node_00012`), I propose the following structural evolution.

### **Idea 10: Anisotropic Hybrid ResNet-Transformer**

This solution addresses the "Capacity Constraint Violation" identified in the lessons by structurally decoupling the vertical and horizontal downsampling rates. Unlike standard CNNs that downsample uniformly (e.g., 32x in both dimensions), this model compresses the image vertically to aggregate features into a sequence while preserving high horizontal resolution to satisfy the CTC constraint ($T \ge L$).

#### **1. Model**
The architecture is a multi-task Encoder-Decoder network designed for high-resolution sequence modeling:

*   **Anisotropic Visual Backbone:** A **ResNet-34** is used as the feature extractor, but its pooling and strided convolution layers are modified.
    *   **Vertical Downsampling:** Standard strides are maintained (e.g., total stride of 16 or 32) to collapse the height dimension, capturing the full vertical context of the molecule.
    *   **Horizontal Downsampling:** Strides are removed or reduced (e.g., total stride limited to 4). This ensures that the output feature sequence length $T$ remains sufficiently large to represent every character in the InChI string, directly resolving the architectural mismatch where $T < L$ (Cite `solution_lesson_node_00012`).
*   **Sequence Modeling:** The resulting feature map $(C, 1, W/4)$ is squeezed to a 1D sequence $(W/4, C)$. A **Bi-Directional GRU** or a **Transformer Encoder** layer processes this sequence to model contextual dependencies between distant atoms.
*   **Dual-Head Decoder:**
    *   **CTC Head:** A linear projection maps the encoder output directly to the character vocabulary. This head is used primarily during training to force the encoder to learn a strict monotonic alignment between image columns and characters.
    *   **Attention Decoder:** A standard **Transformer Decoder** attends to the encoder output sequence (Cross-Attention) and generates the InChI string autoregressively. This head handles the complex syntax (parentheses, stereochemistry layers) that CTC alone often struggles to structure correctly.

#### **2. Data**
*   **Preprocessing:**
    *   **Grayscale Conversion:** Images are converted to 1-channel grayscale.
    *   **Fixed-Height Resizing:** Instead of resizing to a fixed square (which distorts aspect ratios and reduces width resolution), images are resized to a **fixed height** (e.g., 192 pixels) while maintaining their original aspect ratio.
    *   **Padding:** The width is padded to the nearest multiple of the backbone's horizontal stride (e.g., 16) to support batching. This ensures that wider images (likely containing longer molecules) naturally result in longer input sequences $T$.
*   **Tokenization:** A unified character-level vocabulary is constructed, containing the CTC "blank" token and the autoregressive special tokens (`<SOS>`, `<EOS>`, `<PAD>`).

#### **3. Training**
*   **Objective:** The model is optimized using a **Joint Loss** function: $\mathcal{L} = \lambda \mathcal{L}_{CTC} + (1-\lambda) \mathcal{L}_{CE}$.
    *   $\mathcal{L}_{CTC}$ ensures the encoder features are robust and aligned.
    *   $\mathcal{L}_{CE}$ (Cross-Entropy) trains the Transformer Decoder using **Teacher Forcing**.
*   **Optimization:** An **AdamW** optimizer is used with a "One Cycle" learning rate schedule. This schedule warms up the learning rate to stabilize the Transformer gradients and then decays it for fine-tuning.

#### **4. Evaluation**
*   **Inference:** Test images are preprocessed (fixed-height resize) and passed through the Encoder.
*   **Decoding:** The final prediction is generated using the **Attention Decoder** with **Beam Search**. The CTC head's output can optionally be used to rescore the beams or simply ignored, as its primary purpose is structural regularization during training. This ensures the output adheres to valid InChI syntax while benefiting from the high-resolution features mandated by the CTC constraint.
