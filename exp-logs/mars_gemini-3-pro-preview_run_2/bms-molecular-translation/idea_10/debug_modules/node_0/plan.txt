The implementation strategy involves creating a single Python script that imports and utilizes the provided library classes to demonstrate the full pipeline: configuration, data loading, model instantiation, training, and inference.

1.  **Configuration**: Initialize `Config` with `debug=True` to ensure the script runs quickly (reduced epochs, batch size, and dataset size).
2.  **Tokenizer**: Instantiate `InChiTokenizer` to verify vocabulary loading/building and encoding/decoding logic.
3.  **Data Loading**: Create a `ChemicalImageDataset` (train mode) and a `DataLoader` using `ChemicalCollate`. Fetch a single batch to verify tensor shapes (images, labels, lengths).
4.  **Model**: Instantiate `HybridResNetTransformer`. Perform a forward pass with the fetched batch to verify the shapes of `ctc_logits` and `decoder_logits` and ensure loss calculation works without errors.
5.  **Training**: Instantiate the `Trainer` class and call `fit()`. Since debug mode subsets the data to ~80 samples and runs for 2 epochs, this will execute rapidly while exercising the full training loop (forward, backward, optimizer step, validation).
6.  **Inference**: Use the trained model and the `BeamSearchDecoder` to predict InChI strings for the sample batch used earlier. Print predictions vs. ground truth to verify the decoding pipeline.
