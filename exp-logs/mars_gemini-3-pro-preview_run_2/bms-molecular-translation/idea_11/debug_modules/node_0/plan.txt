Implementation Strategy:
1.  **Setup & Configuration**: Import necessary libraries and the provided `library` modules. Initialize the `Config` class in debug mode to use lightweight parameters (batch size 4, 1 epoch).
2.  **Data Subsetting**: To ensure the script runs within the time limit, create a small temporary CSV file (`demo_train.csv`) in the `./working` directory containing only the first 10 rows of the provided training metadata.
3.  **Path Overrides**: Monkey-patch `Config.TRAIN_METADATA`, `Config.VAL_METADATA`, and `Config.VOCAB_PATH` to point to the temporary subset and a temporary vocabulary file. This prevents the tokenizer from processing the full 1.5M dataset.
4.  **Tokenizer Initialization**: Instantiate `InChITokenizer`. Force it to rebuild the vocabulary from the subset to ensure it matches the data we are using. Verify basic text-to-sequence functionality.
5.  **Dataset & DataLoader**: Instantiate `InChIDataset` with the subset and `DataLoader` with the custom `collate_fn`. Fetch a single batch to verify tensor shapes (Images: `[B, 1, H, W]`, Labels: `[B, SeqLen]`).
6.  **Model Initialization**: Instantiate the `AnisotropicResNetTransformer` model. Move it to the appropriate device (CPU/GPU).
7.  **Forward Pass Verification**:
    *   Run a forward pass with targets (Training Mode) and verify output logits shape.
    *   Run a forward pass without targets (Inference Mode) and verify output memory shape.
8.  **Training & Validation Loop**: Define a simple optimizer. Run `train_one_epoch` and `validate` using the small dataloader. This effectively tests the entire pipeline logic without the computational cost of a full run.
9.  **Cleanup**: The script relies on the `./working` directory for temporary files, which is permitted.
