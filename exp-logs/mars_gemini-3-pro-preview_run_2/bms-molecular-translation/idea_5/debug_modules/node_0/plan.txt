This script demonstrates how to instantiate and utilize the provided library classes and functions. It performs the following steps:
1.  **Configuration**: Overrides default `Config` settings to run in a fast debug mode (small dataset subset, 1 epoch, no workers).
2.  **Logic Verification**: Tests the utility functions (`parse_inchi_stoichiometry`, `get_atom_vector`) and the `ChemicalDataset` class to ensure data is processed correctly.
3.  **Model Verification**: Instantiates the `StoichiometryEncoder` and checks output shapes with dummy data.
4.  **Training Integration**: Runs the full training loop using `library.train.run_training`.
5.  **Inference Integration**: Runs the retrieval-based inference pipeline using `library.retrieval.run_retrieval_inference` and verifies the output submission file.
