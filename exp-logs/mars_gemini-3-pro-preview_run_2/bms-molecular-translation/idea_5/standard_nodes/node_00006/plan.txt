Based on the provided model architectures and the task requirements, I have implemented the orchestration script `runfile.py`.

**Implementation Strategy:**

1.  **Setup & Reproducibility**: The script initializes with a fixed random seed (`42`) for `random`, `numpy`, and `torch` to ensure reproducible results. It imports the pre-defined classes and functions from the `library` package (`Config`, `StoichiometryEncoder`, `run_training`, `run_retrieval_inference`, etc.).

2.  **Training Phase**: The script calls `library.train.run_training`. To ensure the process completes within the 2-hour limit while still allowing the model to learn the stoichiometry task, I have set the number of epochs to **2**. This is sufficient for the regression head to converge reasonably well on the atom counting task, creating a useful embedding space for retrieval.

3.  **Validation Assessment**:
    *   The script loads the hold-out validation set metadata (`metadata/val.csv`).
    *   It loads the trained model weights.
    *   It constructs a retrieval index using the entire training set (`metadata/train.csv`). This index is cached to disk to speed up the subsequent submission step.
    *   It computes embeddings for the validation set and performs a 1-Nearest Neighbor search against the training index using Cosine Similarity.
    *   It retrieves the ground truth InChI strings of the nearest neighbors as predictions.
    *   It calculates the **Mean Levenshtein Distance** between predictions and ground truth using `nltk.edit_distance` and prints the `Final Validation Metric`.

4.  **Failure Analysis**:
    *   The script calculates the correlation between the Levenshtein distance (error magnitude) and the target InChI string length on the full validation set.
    *   To analyze visual features without incurring a massive I/O penalty (reading 380k images), it samples **2,000** validation images to compute correlations between error and image properties (width, height, aspect ratio).

5.  **Submission Generation**:
    *   Finally, the script calls `library.retrieval.run_retrieval_inference`. This function loads the test set, reuses the cached training index, performs retrieval for the test images, and saves the formatted submission file to `./submission/submission.csv`.
