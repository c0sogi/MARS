Based on the provided model architectures and previous ideas, I propose a highly efficient baseline approach that bypasses the complexity of sequence generation entirely. Instead of generating the InChI string character-by-character, this approach treats the problem as a representation learning and retrieval task.

### **Baseline Approach: Stoichiometry-Supervised Representation Retrieval**

This approach synthesizes **Model 1 (Retrieval)** and **Model 2 (Attribute Prediction)** into a unique baseline. It assumes that visually similar molecules share similar InChI strings (especially the chemical formula and skeletal structure). By training a lightweight network to understand molecular stoichiometry (atom counts), we create a semantic embedding space where we can simply "look up" the label of the most similar training image.

#### **1. Model**
The architecture consists of two distinct stages: a **Supervised Encoder** used for feature extraction and a **Retrieval Module** for inference.

*   **Visual Encoder (Backbone):** A lightweight, pre-trained CNN such as **EfficientNet-B0** or **MobileNetV3** is used to process the input images.
*   **Bottleneck / Embedding Layer:** The convolutional features are aggregated via Global Average Pooling into a 1D vector, followed by a dense linear layer (e.g., 256 or 512 dimensions) with ReLU activation. This vector serves as the "Molecular Embedding."
*   **Proxy Prediction Head:** To force the embedding to learn relevant chemical features, a final linear layer is attached to predict the **counts of specific atoms** (Carbon, Hydrogen, Nitrogen, Oxygen, Sulfur, Fluorine, Chlorine, Bromine, Iodine) present in the molecule. This turns the encoder training into a multi-output regression task.
*   **Retrieval Index:** A non-parametric component (using a library like FAISS or simple matrix operations) that stores the Molecular Embeddings of the entire training set.

#### **2. Data**
*   **Label Processing (Training Only):** The ground truth InChI strings are parsed using regular expressions to extract the **Molecular Formula** layer (e.g., `C13H20OS` from `InChI=1S/C13H20OS/...`). From this formula, the counts of common atoms (C, H, N, O, S, Halogens) are extracted to create a numerical target vector (e.g., `[13, 20, 0, 1, 1, ...]`) for each image.
*   **Image Preprocessing:** Images are resized to a moderate fixed resolution (e.g., $256 \times 256$) and normalized. To maintain efficiency, images are converted to grayscale (1 channel) since color is not semantically significant for these chemical diagrams.

#### **3. Training**
*   **Objective:** The model is trained to minimize the error between the predicted atom counts and the actual atom counts derived from the InChI labels.
*   **Loss Function:** **Smooth L1 Loss (Huber Loss)** or **Mean Squared Error (MSE)** is used for the regression targets. This is more robust to outliers in atom counts than standard Cross-Entropy.
*   **Optimization:** The **Adam** optimizer is used with a standard learning rate.
*   **Strategy:** The network is trained purely as a regressor. This is computationally very cheap compared to sequence-to-sequence training because it avoids timestep-wise backpropagation and expensive attention calculations. The model converges quickly as it only needs to learn to count atoms, not describe connectivity.

#### **4. Evaluation**
*   **Index Construction:** Once the encoder is trained, the "Proxy Prediction Head" is discarded. The model is run in inference mode over the entire **Training Set** to generate and store the 256-d Molecular Embeddings for all training samples.
*   **Prediction:**
    1.  The **Test Set** images are passed through the encoder to generate their embeddings.
    2.  For each test embedding, a **1-Nearest Neighbor (1-NN)** search is performed against the Training Index using Cosine Similarity.
    3.  The predicted InChI string for the test image is simply the **ground truth InChI of its nearest neighbor** in the training set.

**Rationale:** This baseline guarantees valid InChI syntax (since outputs are retrieved from valid training labels) and maximizes the score on the "Formula" layer of the InChI string (since the embeddings are explicitly trained to cluster molecules with identical stoichiometry together). It establishes a strong performance floor with minimal architectural complexity.
