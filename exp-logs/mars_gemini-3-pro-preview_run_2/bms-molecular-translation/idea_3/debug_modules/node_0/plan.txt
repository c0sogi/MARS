1.  **Configuration Override**: We will dynamically modify the `Config` class attributes to enable debug mode, reduce the dataset size to a minimal number of samples (e.g., 20), set the batch size to a small number (e.g., 4), and limit training to 1 epoch. This ensures the script runs very quickly while exercising all code paths.
2.  **Tokenizer Verification**: We will instantiate the `InChITokenizer`, encode a sample InChI string, decode it back, and assert that the reconstructed string matches the original (ignoring special tokens).
3.  **Dataset and DataLoader Verification**: We will initialize the DataLoaders using `get_dataloaders`. We will fetch a single batch to verify the tensor shapes of the images and labels, ensuring the preprocessing pipeline works as expected.
4.  **Model Architecture Verification**: We will instantiate the `CNNTransformer` model. We will perform a forward pass with the fetched batch to check the output logits shape. We will also run the `predict` method to verify the inference (greedy decoding) logic and output shape.
5.  **Training Loop Verification**: We will instantiate the `Trainer` class and run the `fit` method for one epoch. This will verify the loss calculation, backpropagation, validation loop, metric calculation, and checkpoint saving functionality.
6.  **Inference Pipeline Verification**: We will call the `run_inference` function using the checkpoint generated in the previous step. We will verify that a submission file is created and has the correct format.
