The implementation strategy for the **CNN-Transformer Encoder with CTC** baseline is as follows:

1.  **Setup & Configuration**: Initialize the environment with a fixed random seed for reproducibility. Override standard configuration parameters to create a "fast baseline" suitable for the 2-hour runtime limit. This includes setting `EPOCHS=3`, `BATCH_SIZE=128` (optimized for the A100 GPU), and `NUM_WORKERS=8`.
2.  **Data Subsetting**: To ensure training completes quickly, create a subset of the training metadata containing 50,000 samples. This subset is saved to the working directory and the configuration is updated to point to it.
3.  **Training**: Instantiate the `Trainer` class and execute the `fit()` method. This handles the training loop, validation monitoring, and checkpoint saving using the defined CNN-Transformer architecture and CTC loss.
4.  **Validation & Failure Analysis**:
    *   Load the best performing model checkpoint.
    *   Perform inference on the **full** hold-out validation set.
    *   Calculate the exact Levenshtein distance for every sample to compute the `Final Validation Metric`.
    *   Conduct failure analysis by correlating the prediction error (Levenshtein distance) with input properties (image width and target string length) to identify systematic weaknesses.
5.  **Submission**: Execute the inference pipeline on the full test set to generate the `submission.csv` file required for the task.
