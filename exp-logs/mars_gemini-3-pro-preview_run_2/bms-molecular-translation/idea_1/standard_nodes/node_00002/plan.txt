The previous implementation in `runfile.py` overrode the default batch size to 64 for the baseline run. This batch size, combined with the CRNN model architecture (specifically the LSTM processing sequences of length 1024) and large input images (2048px width), exceeded the 40GB memory capacity of the A100 GPU, resulting in a `torch.OutOfMemoryError`. To fix this, I will reduce the batch size in `runfile.py` from 64 to 32, which will reduce the memory required for storing intermediate activations during training.
