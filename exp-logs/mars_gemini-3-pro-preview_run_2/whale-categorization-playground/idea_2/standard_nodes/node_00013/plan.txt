The `KeyError: np.int64(-1)` occurs in `library/trainer.py` because the `id_encoder` (inverse label mapping) lacks an entry for the sentinel value `-1`. In the `WhaleDataset`, the class `new_whale` is assigned the target `-1` since it is excluded from the `label_encoder` used for ArcFace training. However, during inference in `Trainer.predict`, the gallery includes `new_whale` images. When the model retrieves a neighbor with label `-1`, the code attempts to look it up in `id_encoder`, which only contains mappings for known whale IDs ($0 \dots N$).

To fix this, I will manually add the mapping `{-1: "new_whale"}` to `self.id_encoder` in the `Trainer.__init__` method. This ensures that the sentinel value returned by the dataset for `new_whale` can be correctly decoded back to its string identifier during prediction generation.
