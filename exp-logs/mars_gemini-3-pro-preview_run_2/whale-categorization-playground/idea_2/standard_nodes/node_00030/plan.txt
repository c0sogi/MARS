2.  **Dataset (Cite Lesson 18, 19)**: Modify `library/dataset.py` to ensure the `gallery_loader` used for validation and inference contains **only known whales**. Including the "new_whale" class in the gallery treats it as a coherent cluster, which it is not. Removing it forces the model to rely on distance thresholds, which is more robust.
3.  **Validation Logic (Cite Lesson 19)**: Rewrite the `validate` method in `library/trainer.py` to implement **threshold-based rejection**. Instead of simple retrieval, the validation loop will now predict "new_whale" (label -1) if the cosine similarity to the nearest known neighbor is below 0.35. This aligns the validation metric with the actual submission logic.
4.  **Inference (Cite Lesson 18)**: Update `library/inference.py` to filter out "new_whale" from the reference gallery and use a distinct cache file (`gallery_known_images`). This ensures the final submission also relies on the robust thresholding strategy rather than flawed clustering.

    def validate(self, epoch):
        """
        Validates the model by computing MAP@5 using KNN search with Thresholding.
        Gallery: Known Whales Only (Cite Lesson 18, 19)
        Query: Validation Set (includes known and unknown)
        """
        self.logger.info("Validating...")
        start_time = time.time()

        # 1. Extract Gallery Features (Known Whales Only)
        gallery_feats, gallery_labels = self.extract_features(
            self.gallery_loader, "Gallery"
        )

        # 2. Extract Query Features (Validation Set)
        val_feats, val_labels = self.extract_features(self.val_loader, "Query")

        # Move to GPU
        gallery_feats = gallery_feats.to(DEVICE)
        val_feats = val_feats.to(DEVICE)
        gallery_labels = gallery_labels.to(DEVICE)

        # 3. Compute Cosine Similarity Matrix
        sim_matrix = torch.mm(val_feats, gallery_feats.t())

        # 4. Top-K Retrieval
        # We need top 5 candidates from known whales
        topk_scores, topk_indices = torch.topk(sim_matrix, k=5, dim=1)

        # 5. Apply Thresholding Logic (Cite Lesson 19)
        # If max similarity < threshold, predict 'new_whale'
        NEW_WHALE_THRESHOLD = 0.35
        
        pred_labels_np = []
        val_labels_np = val_labels.numpy()

        topk_scores_np = topk_scores.cpu().numpy()

        for i in range(len(val_labels)):
            # Get candidates (indices in gallery)
            indices = topk_indices_np[i]
            scores = topk_scores_np[i]
