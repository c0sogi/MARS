The following script performs a comprehensive Exploratory Data Analysis (EDA) on the whale identification dataset. It analyzes the target distribution, processes image metadata and pixel statistics, and investigates relationships between image properties and the target labels.

### Implementation Strategy
1.  **Setup & Loading**: Initialize the environment, set random seeds, and load the training metadata from `./metadata/train.csv`.
2.  **Target Analysis**: Analyze the `Id` column to report the number of classes, the prevalence of the `new_whale` class, and the distribution of class frequencies (imbalance).
3.  **Image Analysis**:
    *   Iterate through all training images to extract metadata: dimensions (width, height), aspect ratios, file sizes, and channel counts.
    *   Compute global pixel statistics (Mean and Standard Deviation) for normalization. To ensure efficiency and precision, this is done by accumulating channel sums and squared sums across the dataset.
    *   Handle both Grayscale and RGB images, converting Grayscale to RGB for consistent global statistics.
4.  **Relationship Analysis**:
    *   Investigate if image meta-features (e.g., file size, resolution) correlate with the target class.
    *   Specifically, compare the properties of the `new_whale` class versus identified whales (`known`).
5.  **Reporting**: Output the findings in a structured, text-based report with formatted metrics.
