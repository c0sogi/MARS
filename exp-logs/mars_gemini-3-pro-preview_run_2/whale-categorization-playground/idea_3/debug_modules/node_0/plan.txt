This script demonstrates the end-to-end workflow for the Whale Identification task using the provided library. It covers configuration setup, data loading, model instantiation, loss calculation, training, and inference.

**Strategy:**
1.  **Configuration**: We override `Config` parameters to enable "debug" mode, reduce image sizes, and limit epochs/batch sizes. This ensures the script runs quickly (within minutes) while exercising all code paths.
2.  **Verification**: We verify the logic of the evaluation metric (`map_at_5`) and check data shapes manually before starting the training loop.
3.  **Training**: We utilize the `Trainer` class to run a single epoch of training on a small subset of data. This generates a model checkpoint and validates the training pipeline.
4.  **Inference**: We execute the `generate_submission` function to produce predictions using the trained model and the k-reciprocal re-ranking logic, verifying the output format.
