Based on the comprehensive analysis of the previous experiments and the "Lessons Learned," I propose the following optimized strategy. This solution resolves the conflict between model capacity, input resolution, and batch stability by introducing **Gradient Checkpointing** and implements a **Manifold-Aware Split-Inference** pipeline to correct the open-set retrieval flaws.

### Model
**Architecture: EfficientNet-B4 with Gradient Checkpointing**
*   **Backbone:** We will adopt the **EfficientNet-B4** architecture. Previous experiments revealed a "Capacity-Resolution" trade-off where EfficientNet-B3 performed well (Cite solution_lesson_node_00013), but EfficientNet-B4 failed due to batch size constraints (Cite solution_lesson_node_00022). To resolve this, we will enable **Gradient Checkpointing** (activation checkpointing). This technique trades a small amount of compute time for significant memory savings by not storing intermediate activations during the forward pass, allowing us to fit the heavier B4 backbone with high-resolution inputs and a stable batch size on the A100 GPU.
*   **Pooling:** We will retain **Generalized Mean (GeM) Pooling**. This is structurally superior to Global Average Pooling for fine-grained identification as it allows the model to focus on salient features (e.g., scars) while suppressing background water noise (Cite solution_lesson_node_00020).
*   **Head:** We will use the **ArcFace (Additive Angular Margin Loss)** head. This classification-based objective has proven to converge significantly faster and generalize better than pairwise Siamese losses for this high-cardinality dataset (Cite solution_lesson_node_00008).

### Data
**Preprocessing & Curation**
*   **Resolution:** Inputs will be standardized to **384x384**. This high resolution is critical for resolving minute biological markings (Cite solution_lesson_node_00009) and is now feasible with the B4 backbone due to the memory optimizations proposed above.
*   **Training Set:** We will strictly **exclude** the `new_whale` class from the training data. Training on "unknown" samples as a single class causes embedding collapse (Cite solution_lesson_node_00005).
*   **Validation Gallery:** We will construct a **Deterministic, Known-Only Gallery** for validation.
    *   *Deterministic:* A separate data loader will be used to ensure the gallery images are not augmented, preventing noise from obscuring the metric (Cite solution_lesson_node_00024).
    *   *Known-Only:* The gallery will exclude `new_whale` images, aligning the validation metric with the open-set nature of the task (Cite solution_lesson_node_00019).
*   **Caching:** All dataset caches will use parameterized filenames (e.g., `train_enc_b4_384_v2.npy`) to prevent the "Silent Empty Dataset" bug and ensure cache invalidation (Cite solution_lesson_node_00001, solution_lesson_node_00003).

### Training
**Procedure & Strategy**
*   **Batch Size:** We will maintain a batch size of **32**. Previous attempts with EfficientNet-B4 failed because the batch size was reduced to 16, which destabilized the Batch Normalization statistics (Cite solution_lesson_node_00022). Gradient Checkpointing enables us to restore the batch size to 32 even with 384px images.
*   **Loss Function:** ArcFace Loss on known identities.
*   **Checkpointing:** We will save model weights based strictly on the **Validation MAP@5** score, not training loss. Given the stochastic volatility observed in singleton-heavy datasets, the best generalization often occurs at transient peaks (Cite solution_lesson_node_00021).

### Evaluation
**Inference: Manifold-Aware Split-Pipeline**
We introduce a multi-stage inference pipeline that corrects the flaws of previous re-ranking attempts (Cite solution_lesson_node_00018).
1.  **Global Retrieval:** Compute Cosine Similarity between the Test Query and the **Known-Only** Gallery (excluding `new_whale`).
2.  **Manifold Re-ranking:** Apply **k-Reciprocal Encoding Re-ranking** *only* to the top-K retrieved known candidates. By restricting re-ranking to known identities, we leverage the manifold structure (shared neighbors) to disambiguate hard positives without the noise of the incoherent `new_whale` class.
3.  **Open-Set Rejection:** Apply a distance threshold to the top re-ranked candidate.
    *   If the similarity is below the threshold, the primary prediction is `new_whale`.
    *   Otherwise, the primary prediction is the top re-ranked ID.
    *   This hybrid approach uses density estimation for knowns and distance thresholds for unknowns (Cite solution_lesson_node_00018).
