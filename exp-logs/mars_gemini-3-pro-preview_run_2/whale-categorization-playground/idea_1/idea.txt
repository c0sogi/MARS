# Baseline Approach: Siamese ResNet-18 with Contrastive Loss

This approach establishes a lightweight metric learning baseline. Unlike the classification-heavy approaches (Models 1 & 2) or the frozen feature extractor (Model 3), this solution actively learns a distance metric optimized for verifying whether two images belong to the same whale, which is conceptually better suited for the high number of singleton classes than standard classification.

### Model
The architecture is a **Siamese Network** utilizing a shared **ResNet-18** backbone.
*   **Backbone**: We use ResNet-18 initialized with ImageNet weights. This is significantly lighter and faster than EfficientNet-B3 (Model 1) or Swin Transformer (Model 2), adhering to the philosophy of speed.
*   **Embedding Head**: The final classification layer of the ResNet-18 is removed and replaced with a simple projection head: a Global Average Pooling layer followed by a single Fully Connected layer reducing the dimension to **128**.
*   **Normalization**: The output 128-dimensional vectors are L2-normalized to lie on a hypersphere.
*   **Siamese Logic**: During training, the network accepts pairs of images $(Image_A, Image_B)$ and outputs two embedding vectors. The weights are shared between the two passes.

### Data
Preprocessing focuses on generating valid pairs for the metric learning objective, specifically addressing the "singleton" (one image per whale) problem.
*   **Input Processing**: Images are resized to 224x224 pixels and normalized using standard ImageNet mean and standard deviation.
*   **Pair Generation**:
    *   **Positive Pairs (Label 1)**: Two images of the same whale. For classes with only one image (singletons), we generate a positive pair by taking the original image and applying geometric augmentations (random rotation, scaling, and cropping) to create a synthetic second view.
    *   **Negative Pairs (Label 0)**: Two images of different whales, randomly sampled.
    *   **Balancing**: The data loader yields batches containing an approximately 50/50 split of positive and negative pairs to prevent the model from biasing towards "different" (since most random pairs are different).

### Training
The model is trained to minimize the distance between positive pairs and maximize the distance between negative pairs.
*   **Loss Function**: We use **Contrastive Loss**. For a pair with Euclidean distance $D$ and label $Y$ (1 for same, 0 for different):
    $$L = Y \cdot D^2 + (1 - Y) \cdot \max(0, \text{margin} - D)^2$$
    This explicitly forces embeddings of the same whale to contract and different whales to separate by at least a fixed margin (e.g., 1.0).
*   **Optimizer**: AdamW optimizer with a default learning rate (e.g., 1e-3) and a step learning rate scheduler.
*   **Duration**: Training is capped at a low number of epochs (e.g., 10-15) to ensure the runtime remains well within the 24-hour limit.

### Evaluation
Inference treats the problem as a nearest-neighbor retrieval task in the learned metric space.
1.  **Reference Database**: Pass all images in the **Training** set (including singletons) through the trained model to compute and store their 128-d embeddings.
2.  **Test Queries**: Compute the embedding for each image in the **Test** set.
3.  **Similarity Search**: For each test embedding, calculate the Euclidean distance to all embeddings in the Reference Database.
4.  **Prediction Logic**:
    *   Identify the 5 nearest neighbors (Ids).
    *   **Thresholding**: If the distance to the closest neighbor exceeds a calibrated threshold $\tau$ (determined via the Validation set), the primary prediction is set to `new_whale`.
    *   The remaining slots are filled with the Ids of the nearest neighbors in ascending order of distance.
