The issue is that the model checkpoint was trained in debug mode with a subset of classes (30 classes), resulting in an `arc_head` layer of shape `[30, 512]`. However, during inference, the model is initialized with the full dataset's class count (4028 classes), expecting an `arc_head` of shape `[4028, 512]`. This causes a `RuntimeError` when `load_state_dict` attempts to copy the mismatched weights.

To fix this, I will modify `library/engine.py` to inspect the state dictionary before loading. If the shape of `arc_head.weight` in the checkpoint does not match the current model's head, I will remove that key from the dictionary and load the rest of the weights using `strict=False`. This is appropriate because the classification head is not used for inference (Cite debug_lesson_2).
