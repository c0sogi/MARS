Implementation strategy:
1.  **Setup and Initialization**: Import necessary libraries and the provided modules (`config`, `dataset`, `model`, `engine`, `utils`, `inference`, `rerank`). Set random seeds for reproducibility.
2.  **Data Preparation**: Initialize data loaders using `get_dataloaders`. This will handle image caching and preprocessing.
3.  **Model Training**: Instantiate the `WhaleModel` and `WhaleEngine`. Run the `fit()` method to train the model for the configured number of epochs (25). The engine automatically saves the best model based on validation MAP@5.
4.  **Validation & Failure Analysis**:
    *   Load the best saved model weights.
    *   Extract features for the validation set and the training gallery.
    *   Compute similarity matrices (using re-ranking if enabled).
    *   Apply the open-set rejection logic (thresholding) to generate predictions.
    *   Calculate the exact `MAP@5` score and print it in the required format.
    *   Calculate per-sample error (1.0 - Average Precision).
    *   Load validation metadata, read image dimensions/file sizes, and calculate the Pearson correlation between these features and the error magnitude. Print the results.
5.  **Submission Generation**:
    *   Compare the final validation metric against the threshold (0.751589).
    *   If the score is sufficient, call `generate_predictions()` to run the inference pipeline on the test set (using the combined Train+Val gallery) and save `submission.csv`.
