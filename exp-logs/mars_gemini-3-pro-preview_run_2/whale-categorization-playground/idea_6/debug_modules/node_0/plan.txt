This script demonstrates the end-to-end usage of the provided library components for the Whale Species Prediction task. It validates the dataset loading, model architecture, loss function calculation, training loop execution, and inference logic using a small subset of the data to ensure rapid execution.

1.  **Setup**: Initializes random seeds and configures a temporary working directory for the demo.
2.  **Data Preparation**: Creates a mini-subset of the training metadata to simulate a quick training run without processing the entire dataset.
3.  **Component Validation**:
    *   **Dataset**: Verifies that the `WhaleDataset` correctly loads images and labels.
    *   **Model**: Instantiates the `WhaleModel` (EfficientNet-B4 backbone) and checks output shapes.
    *   **Loss**: Validates the `ArcFaceLoss` forward pass.
4.  **Training Simulation**: Runs a single training epoch using `train_fn` to ensure the optimization pipeline works.
5.  **Inference Simulation**: Demonstrates embedding extraction and the open-set prediction logic (handling `new_whale`) using the `predict` function.
