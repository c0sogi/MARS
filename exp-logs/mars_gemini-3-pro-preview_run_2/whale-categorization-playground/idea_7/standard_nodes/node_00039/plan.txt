Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration Override**: To ensure the solution runs quickly as a baseline within the time limit, I will override `Config.STAGES` to run a single training stage at 256x256 resolution for 2 epochs. This significantly reduces computational cost while testing the dual-backbone pipeline.
2.  **Training Orchestration**: I will call `run_training_phase()` from the provided library. This will sequentially train the EfficientNet-B4 and EfficientNet-V2-M models using the overridden configuration.
3.  **Ensemble Validation**:
    *   I will manually load the validation dataset and the trained model checkpoints.
    *   I will compute embeddings for the validation set using both models (with Test-Time Augmentation).
    *   I will average the cosine similarity matrices from both models to form an ensemble prediction.
    *   I will calculate the Mean Average Precision @ 5 (MAP@5) on this ensemble output to determine the "Final Validation Metric".
4.  **Failure Analysis**:
    *   I will calculate the Average Precision (AP) for each validation image.
    *   I will define "Error Magnitude" as `1.0 - AP`.
    *   I will extract metadata (Width, Height, File Size) for the validation images and compute the Pearson correlation between these features and the Error Magnitude to identify systematic failures.
5.  **Conditional Submission**:
    *   If the Final Validation Metric exceeds the specified threshold (0.846985), I will trigger `generate_submission()` to create the submission file for the test set.
