# Proposed Strategy: EfficientNet-B2 with GeM Pooling and Dynamic Spectral Features

This strategy proposes a structural evolution by scaling the backbone to **EfficientNet-B2** and enriching the input representation with **Delta and Delta-Delta** features. This addresses the need for higher capacity while maintaining the robustness of legacy architectures and leverages the full 3-channel capability of pretrained models without weight modification.

### Model
We will upgrade the backbone from EfficientNet-B0 to **EfficientNet-B2**.
- **Backbone**: EfficientNet-B2 offers a deeper and wider architecture than B0, capable of capturing more complex hierarchical features. It remains a "legacy" architecture (unlike ConvNeXt), ensuring the training stability and hyperparameter robustness identified as critical **Cite solution_lesson_node_00013**.
- **Pooling Layer**: We will retain the **Generalized Mean (GeM) Pooling** layer. As proven in previous iterations, GeM is structurally superior to Global Average Pooling for detecting transient, sparse events like whale calls in noisy environments **Cite solution_lesson_node_00017**.
- **Input Configuration**: The model will accept standard **3-channel inputs**. Unlike previous approaches that modified the first layer to accept 1-channel input (averaging weights), we will utilize the original pretrained RGB weights directly by providing a 3-channel spectrogram representation.

### Data
The data pipeline is redesigned to provide dynamic temporal information and respect physical resolution constraints.
- **Spectrogram Generation**:
    1.  **High-Fidelity Settings**: We will generate Mel Spectrograms with `n_fft=1024` and `hop_length=64`. This ensures a dense spectral representation (513 unique bins vs 128 Mel bands) to prevent aliasing **Cite solution_lesson_node_00008**, and high temporal resolution ($\approx 62$ frames per clip) to resolve short call contours **Cite solution_lesson_node_00016**.
    2.  **3-Channel Dynamic Features**: Instead of a single Log-Mel channel, we will construct a 3-channel tensor where:
        -   **Channel 1**: Log-Mel Spectrogram (Static).
        -   **Channel 2**: Delta features (First-order time derivative).
        -   **Channel 3**: Delta-Delta features (Second-order time derivative).
        This explicitly encodes the rate of change of the signal, which is highly discriminative for the "chirp" nature of whale calls, and naturally fits the 3-channel input expectation of the pretrained backbone.
- **Augmentation**: We will apply **SpecAugment** (Time and Frequency Masking). We will explicitly **exclude Mixup**, as linear interpolation was found to degrade performance for these specific transient signals **Cite solution_lesson_node_00018**.

### Training
The training configuration focuses on maximizing stability and handling class imbalance.
- **Sampling**: A **WeightedRandomSampler** will be used to ensure balanced batches (50% whale calls, 50% noise).
- **Batch Size**: We will maximize the batch size to **128** (or the hardware limit). This is essential to stabilize the variance introduced by the weighted sampler and ensure robust Batch Normalization statistics **Cite solution_lesson_node_00004**.
- **Optimizer**: We will use the **AdamW** optimizer with a **Cosine Annealing** learning rate scheduler to ensure convergence to a robust minimum.

### Evaluation
- **Inference**: Test clips will be processed into the same 3-channel format (Mel + Delta + Delta-Delta) using the high-resolution STFT parameters.
- **Prediction**: The EfficientNet-B2 model will output a probability score. The GeM pooling will ensure that even short calls trigger a high detection probability. The results will be formatted into the required submission CSV.
