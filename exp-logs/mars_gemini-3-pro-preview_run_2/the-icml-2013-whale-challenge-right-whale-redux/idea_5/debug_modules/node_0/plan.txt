Implementation strategy:
1.  **Configuration Override**: I will modify the `Config` class attributes at runtime to create an isolated "demo" environment. This involves setting a specific working directory (`./working/demo_run`), enabling `DEBUG` mode with a small sample size (20), reducing `EPOCHS` to 1, and disabling pretrained weights to ensure the script runs quickly without external downloads.
2.  **Data Loading Verification**: I will call `get_dataloaders` to process the raw audio into tensors. I will explicitly verify the shape of the resulting tensors `(Batch, Channels, Mel_Bins, Time)` to ensure the preprocessing pipeline (Mel Spectrogram, Deltas, Normalization) is functioning correctly.
3.  **Model Forward Pass**: I will instantiate the `WhaleEfficientNet` and pass a batch of data through it to confirm the architecture is valid and produces outputs of the correct shape `(Batch, 1)`.
4.  **Training Loop Execution**: I will execute `run_training()` to simulate a full training lifecycle (training, validation, checkpointing). I will verify that a model checkpoint is successfully saved.
5.  **Inference Execution**: I will execute `generate_predictions()` to generate a submission file from the trained model. I will validate the output CSV format and row count.
