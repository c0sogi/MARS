Implementation strategy:

1.  **Configuration & Setup**: Initialize the environment using the provided `Config` class, setting random seeds for reproducibility. Override `Config.EPOCHS` to 5 to ensure the "fast baseline" completes within the time limit while maintaining sufficient convergence for the ensemble.
2.  **Data Preparation**: Load the training and validation metadata and concatenate them to reconstruct the full dataset used for Cross-Validation. Replicate the `StratifiedKFold` logic exactly as implemented in `library.data` to generate the correct validation indices for mapping Out-Of-Fold (OOF) predictions.
3.  **Multi-Resolution Ensemble Training**: Iterate through the three defined base models (EfficientNet-B0 Standard, ResNet34 Standard, EfficientNet-B0 High-Res). For each model, perform 5-Fold Cross-Validation:
    *   Initialize the model and move it to the GPU.
    *   Train for fixed epochs using `train_one_epoch` and `validate`.
    *   Implement early stopping logic (saving the best model based on validation loss).
    *   Generate OOF predictions for the validation fold and accumulate predictions for the test set.
    *   Store OOF predictions in a matrix for the meta-learner.
4.  **Stacking**: Use the `StackingMetaLearner` to fit a Logistic Regression model on the collected OOF predictions from all base models. This learns to optimally weight the standard and high-resolution views.
5.  **Evaluation & Failure Analysis**:
    *   Compute and print the final ROC AUC score on the full validation set.
    *   Perform failure analysis by calculating the absolute error of the stacked model.
    *   Extract audio duration metadata on-the-fly for the validation set and calculate the Pearson correlation between error magnitude and signal duration, as well as error and class label.
6.  **Submission**: If the final validation AUC exceeds the specified threshold (0.99599...), generate the `submission.csv` file using the stacked test predictions.
