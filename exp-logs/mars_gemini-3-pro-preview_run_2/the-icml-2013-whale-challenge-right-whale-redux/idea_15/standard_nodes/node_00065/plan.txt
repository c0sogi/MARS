Implementation Strategy:
1.  **Setup & Configuration**: Import necessary modules and monkey-patch `Config` to reduce epochs (from 20 to 8) and patience (from 5 to 3) to ensure the "fast baseline" completes within the time limit while maintaining sufficient convergence.
2.  **Data Loading**: Use `process_and_cache_data` to load/generate the Training, Hold-out Validation, and Test datasets. The Training set will be further split for Cross-Validation.
3.  **5-Fold Stratified Cross-Validation**:
    *   Initialize storage for Out-Of-Fold (OOF) predictions and bagged (averaged) Test/Hold-out predictions for both base models (EfficientNet and ResNet).
    *   Iterate through 5 folds using `StratifiedKFold`.
    *   For each fold, create `WhaleDataset` and `DataLoader` with `WeightedRandomSampler` to handle class imbalance.
    *   **Train Base Models**: For both EfficientNet and ResNet:
        *   Initialize the model using `get_model`.
        *   Train using `run_training` (monitoring `val_loss`).
        *   Load the best checkpoint.
        *   Generate probabilities for the Fold's Validation set (OOF), the global Hold-out Validation set, and the Test set.
4.  **Ensemble (Stacking)**:
    *   Aggregate OOF predictions to form the training feature matrix for the meta-learner.
    *   Average the predictions across folds for the Hold-out and Test sets (Bagging).
    *   Train a `LogisticRegression` meta-learner on the OOF features.
5.  **Validation & Analysis**:
    *   Evaluate the meta-learner on the Hold-out Validation set.
    *   Print the `Final Validation Metric` (AUC).
    *   Perform Failure Analysis: Calculate the correlation between prediction error and input signal statistics (Mean, Std, Max amplitude) on the Hold-out set.
6.  **Submission**:
    *   Check if the validation AUC exceeds the threshold (0.9959928858461402).
    *   If passed, generate predictions on the Test set using the meta-learner and save to `submission.csv`.
