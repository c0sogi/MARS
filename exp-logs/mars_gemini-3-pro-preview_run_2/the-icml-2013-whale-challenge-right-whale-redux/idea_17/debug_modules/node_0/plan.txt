This script demonstrates the end-to-end pipeline for the Right Whale Call Detection task using the provided library files. It covers data loading, model initialization, training of a heterogeneous ensemble, stacking with a meta-learner, and submission generation.

**Strategy:**
1.  **Configuration Override**: We modify `Config` parameters at runtime to reduce the computational load (1 epoch, small batch size) and redirect outputs to a demo directory. We also limit the ensemble to two lightweight models (`resnet18` and `tf_efficientnet_b0`) to ensure execution completes quickly while still demonstrating the stacking logic.
2.  **Data Loading**: We utilize `get_dataloaders(debug=True)` to load a small subset of the data, ensuring the script runs fast and verifies the pipeline mechanics without processing the full dataset.
3.  **Ensemble Training**: We iterate through the defined models, initializing a `Trainer` for each. We perform a full training cycle (fitting and predicting) for every model.
4.  **Stacking**: We aggregate the out-of-fold (validation) predictions and test predictions. We then use the `fit_stacking_model` function to train a Logistic Regression meta-learner on the validation predictions and generate final calibrated probabilities for the test set.
5.  **Validation & Submission**: We verify the shape and value ranges of the predictions and save the final output to a CSV file, adhering to the required format.
