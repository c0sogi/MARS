Based on the analysis of the previous experiments and the extracted lessons, I propose a **Triple-Architecture Heterogeneous Stacked Ensemble with Aggressive Regularization**.

This strategy represents a structural evolution of the successful Stacking approach (Idea 12). It integrates a third, structurally distinct backbone (**DenseNet-121**) to maximize error decorrelation, which was previously attempted but failed due to implementation flaws (Lesson 00037, Lesson 00061). To ensure this larger ensemble converges robustly, we apply the **Aggressive Frequency Masking** identified in Lesson 00071 and strictly adhere to the "Golden Recipe" of signal processing parameters (Lesson 00062, Lesson 00025) and metric-aligned convergence (Lesson 00066).

# Model
We will construct a **Two-Stage Stacked Generalization Ensemble**.

**Level 0: Heterogeneous Base Learners**
We will employ three "Legacy" CNN architectures with distinct inductive biases: **MBConv** (EfficientNet), **Residual Summation** (ResNet), and **Dense Concatenation** (DenseNet). This maximizes the diversity of errors for the meta-learner to resolve **Cite solution_lesson_node_00053**.

1.  **EfficientNet-B0 (Noisy Student):**
    *   **Initialization:** `ns_jft_in1k`. These weights, learned from JFT-300M, are superior for this domain when properly regularized **Cite solution_lesson_node_00054**.
    *   **Role:** Feature extraction via Inverted Residuals and Squeeze-and-Excitation.
2.  **ResNet-34 (ImageNet):**
    *   **Initialization:** Standard ImageNet.
    *   **Role:** Provides robust deep residual learning. It is less sensitive to hyperparameters than modern architectures **Cite solution_lesson_node_00013**.
3.  **DenseNet-121 (ImageNet):**
    *   **Initialization:** Standard ImageNet.
    *   **Role:** Structural Innovation. DenseNet uses feature concatenation (reuse) rather than summation. This distinct information flow creates a "view" of the data that is structurally decorrelated from ResNet/EfficientNet, enhancing stack performance **Cite solution_lesson_node_00037**.

**Common Structural Components:**
*   **Pooling:** All models will use **Generalized Mean (GeM) Pooling** to maximize detection of transient whale calls **Cite solution_lesson_node_00017**.
*   **Input Adaptation:** First convolutional layers adapted to **1-channel input** via weight averaging **Cite solution_lesson_node_00001**.

**Level 1: Meta-Learner**
*   A **Logistic Regression** model will be trained on the concatenated Out-Of-Fold (OOF) probabilities to learn the optimal weighted combination **Cite solution_lesson_node_00053**.

# Data
The data pipeline strictly enforces the "Golden Recipe" for physical fidelity, augmented with aggressive regularization.

1.  **Spectrogram Generation:**
    *   **FFT:** `n_fft=1024`, `hop_length=64`. Ensures high frequency resolution (>4:1 bin-to-mel ratio) and sufficient temporal resolution **Cite solution_lesson_node_00008**, **Cite solution_lesson_node_00016**.
    *   **Mel Filterbank:** `n_mels=128`, `normalized=False` to preserve environmental spectral tilt **Cite solution_lesson_node_00022**.
    *   **Dynamic Range:** Apply **`top_db=80`** clamping to fix the noise floor **Cite solution_lesson_node_00062**.
2.  **Preprocessing:**
    *   **Native Resolution:** Inputs fed at generated dimensions (~128x63). No resizing to 224x224 **Cite solution_lesson_node_00031**.
    *   **Instance Standardization:** Zero-Mean, Unit-Variance applied per clip **Cite solution_lesson_node_00025**.
3.  **Augmentation:**
    *   **Aggressive SpecAugment:** We will set `freq_mask_param=20` (doubling the standard width). This forces the model to learn robust temporal dependencies for narrow-band signals **Cite solution_lesson_node_00071**. Mixup is excluded **Cite solution_lesson_node_00018**.

# Training
We implement a **5-Fold Stratified Cross-Validation** workflow.

1.  **Sampling:** **WeightedRandomSampler** to balance classes in every batch **Cite solution_lesson_node_00004**.
2.  **Batch Size:** Maximize to **128** for stability **Cite solution_lesson_node_00004**.
3.  **Optimization:**
    *   **Optimizer:** AdamW with **Low Weight Decay (`1e-4`)** to accommodate Noisy Student weights **Cite solution_lesson_node_00039**.
    *   **Scheduler:** Cosine Annealing **Cite solution_lesson_node_00046**.
4.  **Convergence:**
    *   **Metric:** Early Stopping will monitor **Validation AUC** (Target Metric), not Loss. This ensures we capture the peak discrimination capability even if calibration drifts **Cite solution_lesson_node_00066**.
    *   **Patience:** Strict patience (e.g., 5 epochs) to prevent overfitting to fold noise **Cite solution_lesson_node_00072**.

# Evaluation
We utilize a **Bagged-Stacking** protocol **Cite solution_lesson_node_00061**.

1.  **Base Prediction:** For the Test set, generate predictions from all 15 trained models (3 architectures $\times$ 5 folds).
2.  **Bagging:** Average the 5 fold-predictions for each architecture to produce 3 robust probability vectors (`EffNet_Prob`, `ResNet_Prob`, `DenseNet_Prob`).
3.  **Stacking:** Feed these bagged probabilities into the Level 1 Logistic Regression model to generate the final submission.
