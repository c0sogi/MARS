The error occurred because the `WhaleDataset` class in `library/dataset.py` was updated to include time masking augmentation using `Config.TIME_MASK_PARAM`, but this parameter was not defined in the `Config` class in `library/config.py`. This is a classic case of configuration desynchronization where a new code dependency is missing its corresponding configuration definition (Cite debug_lesson_9). To fix this, I will add the missing `TIME_MASK_PARAM` to `library/config.py`, setting it to 20 to align with the existing frequency masking parameter.
