Based on the comprehensive analysis of the previous experiments and the extracted lessons, I propose a **Semi-Supervised Multi-Objective Stacked Ensemble**.

This strategy represents a structural evolution of the high-performing "Multi-Objective" approach (Idea 19). It introduces a **Self-Training Feedback Loop (Pseudo-Labeling)** to bridge the gap between the near-perfect validation performance and the unknown test distribution. This aligns with the success of "Noisy Student" weights (Lesson 00054) by applying the same semi-supervised principle directly to the target dataset, while strictly adhering to the "Golden Recipe" of signal processing (Lesson 00008, 00062) and convergence diversity (Lesson 00082).

# Model
We will construct a **Two-Stage Semi-Supervised Ensemble**.

**Level 0: Base Learners (Iterative Self-Training)**
We will employ the two "Legacy" architectures identified as most robust, trained in two distinct rounds.
1.  **EfficientNet-B0 (Noisy Student):** Initialized with `ns_jft_in1k` weights to leverage massive pre-training **Cite solution_lesson_node_00054**.
2.  **ResNet-34 (ImageNet):** Provides deep residual learning biases to decorrelate errors **Cite solution_lesson_node_00053**.
3.  **Common Components:**
    *   **Pooling:** **Generalized Mean (GeM) Pooling** to maximize detection of transient calls **Cite solution_lesson_node_00017**.
    *   **Input Adaptation:** First layer adapted to **1-channel input** via weight averaging **Cite solution_lesson_node_00001**.
    *   **Multi-Objective Checkpointing:** From every training run, we will save two checkpoints: **Best-AUC** (Discriminator) and **Best-Loss** (Calibrator) **Cite solution_lesson_node_00082**.

**Level 1: Meta-Learner**
*   A **Logistic Regression** model trained on the concatenated Out-Of-Fold (OOF) probabilities.

# Data
The data pipeline strictly enforces the "Golden Recipe" for physical fidelity and introduces a Pseudo-Labeling stream.

1.  **Spectrogram Generation:**
    *   **FFT:** `n_fft=1024`, `hop_length=64`. Ensures high frequency resolution (>4:1 bin-to-mel ratio) and sufficient temporal resolution **Cite solution_lesson_node_00008**, **Cite solution_lesson_node_00016**.
    *   **Mel Filterbank:** `n_mels=128`, `normalized=False` to preserve environmental spectral tilt **Cite solution_lesson_node_00022**.
    *   **Dynamic Range:** Apply **`top_db=80`** clamping to fix the noise floor **Cite solution_lesson_node_00062**.
2.  **Preprocessing:**
    *   **Native Resolution:** Inputs fed at generated dimensions (~128x63). **No resizing** to 224x224 **Cite solution_lesson_node_00031**.
    *   **Instance Standardization:** Zero-Mean, Unit-Variance applied per clip **Cite solution_lesson_node_00025**.
3.  **Augmentation:**
    *   **Aggressive SpecAugment:** `freq_mask_param=20` to force learning of temporal dependencies **Cite solution_lesson_node_00071**. Mixup is excluded **Cite solution_lesson_node_00018**.

# Training
We implement a **Two-Round Stratified Cross-Validation** workflow.

**Round 1: Supervised Training**
1.  Train 5-Fold EfficientNet and ResNet on the original `Train` set.
2.  Use **WeightedRandomSampler** (Batch Size 128) **Cite solution_lesson_node_00004**.
3.  Optimize with **AdamW** (Low Decay `1e-4`) **Cite solution_lesson_node_00039** and **Cosine Annealing** **Cite solution_lesson_node_00046**.
4.  Save **Best-AUC** and **Best-Loss** checkpoints for all folds.

**Round 2: Semi-Supervised Training (Structural Innovation)**
1.  **Pseudo-Labeling:** Generate predictions on the `Test` set using the Round 1 ensemble. Select high-confidence samples (e.g., $p > 0.95$ or $p < 0.05$) and assign them their predicted labels.
2.  **Dataset Expansion:** Create a new training set: `Train` + `Pseudo_Test`.
3.  **Retraining:** Retrain the 5-Fold EfficientNet and ResNet models on this expanded dataset.
    *   **Crucial:** Keep the validation set for each fold as the **original pure Train validation split**. Do not validate on pseudo-labels to prevent leakage.
4.  **Checkpointing:** Save the new **Best-AUC** and **Best-Loss** checkpoints based on the pure validation set performance **Cite solution_lesson_node_00082**.

# Evaluation
We utilize a **Bagged-Stacking** protocol **Cite solution_lesson_node_00061**.

1.  **Base Prediction:** Generate predictions on the Test set using the **Round 2** models (20 total: 5 folds $\times$ 2 architectures $\times$ 2 objectives).
2.  **Bagging:** Average the 5 fold-predictions for each specific type (e.g., `EffNet_AUC`, `ResNet_Loss`) to produce 4 robust probability vectors.
3.  **Stacking:** Feed these 4 vectors into the Logistic Regression meta-learner (trained on Round 2 OOFs) to generate the final submission.
