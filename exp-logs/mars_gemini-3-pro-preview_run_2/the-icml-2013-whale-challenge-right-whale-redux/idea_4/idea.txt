# Proposed Strategy: EfficientNet-B0 with GeM Pooling and Physically-Aligned Spectrograms

This strategy proposes a structural evolution by adopting the **EfficientNet-B0** architecture enhanced with **Generalized Mean (GeM) Pooling**. While previous attempts with EfficientNet and ConvNeXt failed due to signal processing errors and hyperparameter sensitivity, this approach explicitly corrects those flaws by aligning the preprocessing with the physics of the audio data and leveraging the robustness of "legacy" architectures.

### Model
We will transition from the ResNet-18 backbone to **EfficientNet-B0**, which offers a more sophisticated feature extraction mechanism via Squeeze-and-Excitation (SE) blocks while maintaining the training stability of legacy CNNs.
- **Backbone**: EfficientNet-B0 is selected as the core feature extractor. It is classified as a robust "legacy" architecture, making it a safer choice than sensitive modern alternatives like ConvNeXt **Cite solution_lesson_node_00013**. The SE blocks naturally perform channel-wise attention, helping the model isolate relevant frequency bands.
- **Input Adaptation**: The first convolutional layer will be modified to accept 1-channel audio input. Crucially, the weights will be initialized by **averaging the weights of the original pretrained RGB channels** to preserve learned spatial filters **Cite solution_lesson_node_00001**.
- **Pooling Layer (Structural Innovation)**: We will replace the standard Global Average Pooling (GAP) with **Generalized Mean (GeM) Pooling**. Since whale calls are transient events embedded in noise, standard GAP tends to wash out the signal. GeM pooling acts as a learnable compromise between Max and Average pooling, allowing the model to focus on the high-energy "peaks" of the call.

### Data
The preprocessing pipeline is rigorously designed to respect the sampling rate (2000 Hz) and spectral constraints identified in previous failures.
- **Spectrogram Generation**:
    1.  **FFT Window**: We will set `n_fft` to **1024**. This yields 513 unique frequency bins, which significantly exceeds the target of 128 Mel bands (ratio > 4:1), ensuring a dense and alias-free spectral representation **Cite solution_lesson_node_00008**.
    2.  **Temporal Resolution**: We will set the `hop_length` to **64** (approx. 32ms). Given the 2000 Hz sample rate, this generates $\approx 62$ time frames per clip, providing sufficient temporal resolution to resolve short whale calls, correcting the "pixelation" issue seen with larger hop lengths **Cite solution_lesson_node_00016**.
- **Augmentation**: We will employ **SpecAugment** (Time and Frequency Masking) during training. This is prioritized over geometric augmentations as it forces the model to learn robust features from partial signal context **Cite solution_lesson_node_00003**.

### Training
The training configuration prioritizes stability to handle the class imbalance and the batch normalization requirements of EfficientNet.
- **Sampling**: A **WeightedRandomSampler** will be used to oversample the minority class, ensuring balanced batches.
- **Batch Size**: We will maximize the batch size to **128**. This is critical for stabilizing the gradients from the weighted sampler and ensuring robust Batch Normalization statistics **Cite solution_lesson_node_00004**.
- **Optimization**: The model will be trained using **Binary Cross Entropy with Logits Loss** and the **AdamW** optimizer. We will use a Cosine Annealing scheduler to ensure convergence.

### Evaluation
- **Inference**: Test recordings will be processed into Log-Mel Spectrograms using the exact same parameters (`n_fft=1024`, `hop_length=64`, `n_mels=128`).
- **Prediction**: The trained EfficientNet-B0 model will perform a forward pass. The GeM pooling will highlight the call presence, and the final sigmoid output will be recorded as the probability for the submission.
