The implementation of the **Uncertainty-Aware Self-Distilled Heterogeneous Ensemble** strategy follows the pipeline described in the idea. 

**Strategy Outline:**
1.  **Configuration Override**: To ensure the pipeline completes within the 26-minute limit, `Config.n_folds` is reduced to 2 and `Config.epochs` to 1. `Config.debug` is kept `False` to run on the full dataset for meaningful (albeit under-trained) metrics.
2.  **Round 1 (Initial Training)**: Two heterogeneous base learners (EfficientNet-B0-NS and ResNet34) are trained on the original training set. Checkpoints for both "Best AUC" (Discriminator) and "Best Loss" (Calibrator) are saved.
3.  **Pseudo-Labeling**: The Round 1 ensemble generates predictions on the test set. Samples with high confidence and low variance (consensus) are selected and merged with the training data to create an expanded dataset.
4.  **Round 2 (Self-Distillation)**: The models are retrained from scratch on the expanded dataset. The configuration is dynamically updated to point to the new dataset and a new cache file.
5.  **Meta-Learning**: A Logistic Regression meta-learner is trained on the Out-Of-Fold (OOF) predictions from the Round 2 models to learn the optimal stacking weights.
6.  **Validation & Analysis**: The final ensemble performance is evaluated on the hold-out validation set. Failure analysis correlates prediction errors with audio features (Duration, RMS, Peak).
7.  **Submission**: If the validation AUC exceeds the specified threshold, the final submission is generated using the stacked ensemble.
