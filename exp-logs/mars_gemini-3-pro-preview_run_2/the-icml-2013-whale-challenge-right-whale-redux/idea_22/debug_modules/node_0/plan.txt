This script demonstrates the end-to-end pipeline for Right Whale Call Detection using the provided library. It performs the following steps:

1.  **Configuration**: Sets up the environment in "Debug Mode" to process a small subset of data, reducing epochs and folds for rapid execution.
2.  **Data Verification**: Loads training and testing data loaders and verifies tensor shapes.
3.  **Model Verification**: Instantiates the `WhaleModel` and performs a forward pass to check architecture validity.
4.  **Training Simulation**: Runs a shortened training loop for 2 folds using `runner.py`, generating model checkpoints.
5.  **Pseudo-Labeling**: Uses the trained models to generate pseudo-labels for the test set via `ensemble.py`.
6.  **Meta-Learning**: Generates Out-Of-Fold (OOF) features from validation data and trains a Logistic Regression meta-learner.
7.  **Submission**: Generates a final submission file using the stacked ensemble of deep learning models and the meta-learner.
