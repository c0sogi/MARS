Based on the comprehensive analysis of the "Lessons" and "Previous Ideas," I propose the **Uncertainty-Aware Self-Distilled Heterogeneous Ensemble**.

This strategy represents a structural evolution of the **Semi-Supervised** (Idea 20) and **Multi-Objective** (Idea 19) approaches. It introduces a **Consensus-Based Pseudo-Labeling** mechanism that leverages the diversity of the Multi-Objective checkpoints to filter self-training data not just by confidence, but by **ensemble stability**. This directly addresses the risk of confirming model biases during self-training and strictly adheres to the evaluation integrity protocols identified in Lesson 00091.

### Model
We will construct a **Two-Stage Stacked Generalization Ensemble** that evolves through an iterative self-distillation process.

**Level 0: Heterogeneous Base Learners**
We will employ two robust "Legacy" architectures to maximize error decorrelation **Cite solution_lesson_node_00053**.
1.  **EfficientNet-B0 (Noisy Student):** Initialized with `ns_jft_in1k` weights. These leverage massive pre-training and outperform standard ImageNet weights when properly regularized **Cite solution_lesson_node_00054**.
2.  **ResNet-34 (ImageNet):** Provides deep residual learning biases to complement the MBConv-based EfficientNet.
3.  **Common Components:**
    *   **Pooling:** **Generalized Mean (GeM) Pooling** to maximize detection of transient whale calls **Cite solution_lesson_node_00017**.
    *   **Input Adaptation:** First layer adapted to **1-channel input** via weight averaging **Cite solution_lesson_node_00001**.

**Structural Innovation: Multi-Objective Checkpointing**
For every training run, we will save **two distinct checkpoints** per fold:
*   **Discriminator:** The state with **Maximum Validation AUC** (Optimized for Ranking) **Cite solution_lesson_node_00066**.
*   **Calibrator:** The state with **Minimum Validation Loss** (Optimized for Probability Calibration) **Cite solution_lesson_node_00055**.
This yields 4 distinct predictors per fold (EffNet_AUC, EffNet_Loss, ResNet_AUC, ResNet_Loss) from a single trajectory **Cite solution_lesson_node_00082**.

**Level 1: Meta-Learner**
*   A **Logistic Regression** model trained on the concatenated Out-Of-Fold (OOF) probabilities.

### Data
The data pipeline is rigorously standardized to the "Golden Recipe" to preserve physical signal fidelity.

1.  **Spectrogram Generation:**
    *   **FFT Parameters:** `n_fft=1024` (High Freq Res) and `hop_length=64` (High Time Res). This prevents aliasing and resolves short call contours **Cite solution_lesson_node_00008**, **Cite solution_lesson_node_00016**.
    *   **Mel Filterbank:** `n_mels=128`, `normalized=False`. We explicitly disable area normalization to preserve the environmental "Pink" noise spectral tilt **Cite solution_lesson_node_00022**.
    *   **Dynamic Range:** Apply **`top_db=80`** clamping to fix the noise floor **Cite solution_lesson_node_00062**.
2.  **Preprocessing:**
    *   **Native Resolution:** Inputs fed at generated dimensions (~128x63). **No resizing** to 224x224 **Cite solution_lesson_node_00031**.
    *   **Instance Standardization:** Zero-Mean, Unit-Variance applied per clip **Cite solution_lesson_node_00025**.
3.  **Augmentation:**
    *   **Aggressive SpecAugment:** `freq_mask_param=20` (doubling standard width) to force learning of temporal dependencies **Cite solution_lesson_node_00071**. Mixup is excluded **Cite solution_lesson_node_00018**.

### Training
We implement a **Two-Round Stratified Cross-Validation** workflow with Uncertainty Filtering.

**Round 1: Initial Supervised Training**
1.  **Sampling:** **WeightedRandomSampler** to balance classes **Cite solution_lesson_node_00004**.
2.  **Optimization:** **AdamW** (Low Decay `1e-4`) **Cite solution_lesson_node_00039** and **Cosine Annealing** **Cite solution_lesson_node_00046**.
3.  **Execution:** Train 5 folds of EffNet and ResNet. Save **Best-AUC** and **Best-Loss** checkpoints (20 models total).

**Round 2: Consensus-Based Self-Distillation (Structural Innovation)**
1.  **Inference:** Generate predictions for the unlabeled Test set using all 20 Round 1 models.
2.  **Uncertainty Filtering:** For each test sample, calculate the **Mean** and **Standard Deviation** of the predictions.
    *   Select samples where **Confidence is High** (Mean > 0.95 or < 0.05) **AND** **Variance is Low** (Std < 0.05).
    *   This ensures we only propagate pseudo-labels where the ensemble (both Discriminators and Calibrators) agrees, avoiding the confirmation of overconfident errors **Cite solution_lesson_node_00087**.
3.  **Retraining:** Retrain all Base Learners from scratch on the **Expanded Dataset** (Original Train + Filtered Pseudo-Labels).
    *   *Note:* Validation is strictly performed on the **original pure validation splits** to prevent leakage.
4.  **Meta-Learning:** Train the Level 1 Logistic Regression on the **Round 2 OOFs** derived strictly from the **original labeled training data**. This corrects the leakage error identified in Lesson 00091 **Cite solution_lesson_node_00091**.

### Evaluation
We utilize a **Bagged-Stacking** protocol **Cite solution_lesson_node_00061**.

1.  **Base Prediction:** Generate predictions on the Test set using the **Round 2** models (20 total).
2.  **Bagging:** Average the 5 fold-predictions for each specific type (e.g., `EffNet_AUC`) to produce 4 robust probability vectors.
3.  **Stacking:** Feed these 4 bagged vectors into the final Logistic Regression meta-learner to generate the submission.
