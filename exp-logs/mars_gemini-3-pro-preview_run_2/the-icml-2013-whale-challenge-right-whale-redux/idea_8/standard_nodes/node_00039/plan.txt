The `AttributeError` occurs because the `Config` class was refactored to support an ensemble of models (renaming `MODEL_NAME` to `MODEL_A_NAME` and `MODEL_B_NAME`), but the `WhaleEfficientNet` class in `library/models.py` still references the old `Config.MODEL_NAME` in its default constructor arguments. This is a classic case of refactoring breaking downstream dependencies (Cite debug_lesson_6). Additionally, inspection reveals that `runfile.py` and `library/train.py` reference `Config.MODEL_PATH`, which was also removed in favor of specific paths like `MODEL_A_PATH`. I will update these references to point to the correct attributes (`MODEL_A_NAME` and `MODEL_A_PATH`) to resolve the import error and prevent subsequent runtime errors.
