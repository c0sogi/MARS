The issue is that `torch.max(dim=1)` returns a named tuple `(values, indices)` rather than a single tensor, and the `.cpu()` method cannot be called on this tuple directly. To fix this, I will access the `.values` attribute of the returned object to retrieve the tensor of maximum values before moving it to the CPU and converting it to a NumPy array (Cite debug_lesson_5).
