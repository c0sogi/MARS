The implementation strategy follows the requirements to orchestrate the training of a heterogeneous ensemble (EfficientNet-B0 and DenseNet-121) for Right Whale detection.

1.  **Setup & Configuration**: The script initializes the environment using the provided `Config` and `seed_everything` for reproducibility. It ensures the output directory `./submission` exists.
2.  **Data Loading**: It utilizes `get_dataloaders(load_cached_data=True)` to efficiently load the preprocessed spectrogram data, leveraging the caching mechanism implemented in `library/dataset.py`.
3.  **Model Training**:
    *   It sequentially trains **Model A** (`WhaleEfficientNet` initialized with Noisy Student weights) and **Model B** (`WhaleDenseNet`) using the `train_model_instance` function.
    *   Training is performed on the GPU with `BCEWithLogitsLoss` and `AdamW`, using the hyperparameters defined in `Config` (Batch Size 128, 25 Epochs).
4.  **Validation & Ensembling**:
    *   After training, both models generate predictions on the validation set.
    *   **Soft Voting** is applied by averaging the probabilities from both models.
    *   The **Final Validation Metric (ROC-AUC)** is computed on the ensemble predictions and printed in the exact required format.
5.  **Failure Analysis**:
    *   The script iterates through the validation set to extract simple signal features from the spectrograms (Mean, Std, Max intensity).
    *   It calculates the absolute error (`|prediction - label|`) for each sample.
    *   It computes and prints the Pearson correlation between the error magnitude and the extracted features to identify potential failure modes (e.g., correlation with low-energy signals).
6.  **Submission**:
    *   The script checks if the Final Validation Metric exceeds the strict threshold of `0.9959177895986835`.
    *   If the condition is met, it runs inference on the test set using `run_inference` (which handles the ensemble averaging) and saves the results to `./submission/submission.csv`.
