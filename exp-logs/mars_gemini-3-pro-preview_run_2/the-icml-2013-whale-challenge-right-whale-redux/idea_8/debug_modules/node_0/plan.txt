Implementation Strategy:
The implementation will follow a step-by-step demonstration of the provided library components, optimized for execution speed. 
1.  **Configuration**: I will override specific `Config` attributes (e.g., `NUM_EPOCHS`, `BATCH_SIZE`, `PRETRAINED`) immediately after import. This ensures the code runs quickly (1 epoch, small batches) and avoids attempting to download model weights, which might be restricted or slow.
2.  **Data Loading**: I will utilize `get_dataloaders` to trigger the data processing pipeline. Since this function processes the entire dataset, I will rely on its internal caching mechanism. For the demonstration of training and inference, I will manually iterate through the loaders for a fixed number of steps (e.g., 10 steps) rather than processing the full dataset.
3.  **Model Usage**: I will instantiate both `WhaleEfficientNet` and `WhaleDenseNet` to verify they initialize correctly with the modified 1-channel input. I will perform a forward pass with a dummy batch to assert output shapes.
4.  **Execution**: The script will run a partial training loop, a partial validation loop, and a partial inference loop, concluding with the generation of a submission file. Assertions will be placed throughout to verify data shapes, output ranges, and file integrity.
