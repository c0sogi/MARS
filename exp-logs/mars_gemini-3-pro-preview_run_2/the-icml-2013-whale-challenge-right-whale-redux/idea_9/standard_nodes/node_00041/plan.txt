The issue is that `torch.max(dim=1)` returns a named tuple `(values, indices)` rather than a single tensor, causing an `AttributeError` when `.cpu()` is called directly on the tuple. To fix this, I will access the `.values` attribute of the result before converting it to a numpy array, ensuring the code operates on the tensor containing the maximum values (Cite debug_lesson_5).
