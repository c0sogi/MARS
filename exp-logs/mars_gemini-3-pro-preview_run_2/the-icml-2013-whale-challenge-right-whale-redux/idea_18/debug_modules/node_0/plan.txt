This script demonstrates the end-to-end workflow for the Right Whale Detection task using the provided library files. It covers data loading, model initialization, training simulation (creating checkpoints), and the full inference pipeline (OOF generation, meta-learner training, and submission creation).

To ensure rapid execution within the time limit, the script configures the system to run in `DEBUG` mode with a reduced number of folds and epochs. It validates the shapes of data tensors and the existence of output files to ensure correctness.
