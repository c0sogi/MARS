Based on the comprehensive analysis of the previous experiments and the extracted lessons, I propose a **Triple-Architecture Stacked Ensemble with Noisy Student Integration and Loss-Guided Calibration**.

This strategy represents a structural evolution of the successful Stacking approach (Idea 12). It expands the ensemble's architectural diversity by integrating a **DenseNet** backbone (exploiting feature reuse biases) alongside the Residual and MBConv backbones. Crucially, it corrects the implementation flaws of Idea 13 (which removed the critical Weighted Sampler) and Idea 8 (which used suboptimal Soft Voting for DenseNet), while leveraging the superior **Noisy Student** weights identified in Lesson 00054 under the strict regularization constraints of Lesson 00039.

# Model
We will construct a **Two-Stage Stacked Generalization Ensemble**.

**Level 0: Heterogeneous Base Learners**
We will employ three structurally distinct "Legacy" CNN architectures to maximize feature diversity and error decorrelation.
1.  **EfficientNet-B0 (Noisy Student):**
    *   **Initialization:** We utilize weights pre-trained on JFT-300M (`ns_jft_in1k`). This leverages massive external knowledge, superior to standard ImageNet weights **Cite solution_lesson_node_00054**.
    *   **Role:** Captures features using Inverted Residual blocks and Squeeze-and-Excitation.
2.  **ResNet-34 (ImageNet):**
    *   **Role:** Provides deep residual learning biases. Proven to be a robust complementary model for stacking **Cite solution_lesson_node_00053**.
3.  **DenseNet-121 (ImageNet):**
    *   **Role:** Structural Innovation. DenseNet uses dense connectivity (concatenation of feature maps) rather than summation. This distinct information flow creates a "view" of the data that is structurally decorrelated from ResNet/EfficientNet, enhancing the stack's performance where simple averaging failed **Cite solution_lesson_node_00037**, **Cite solution_lesson_node_00053**.

**Common Structural Components:**
*   **Pooling:** All models will replace Global Average Pooling with **Generalized Mean (GeM) Pooling** to maximize the detection of transient whale calls **Cite solution_lesson_node_00017**.
*   **Input Adaptation:** All first convolutional layers will be adapted to **1-channel input**, initialized by averaging the original RGB weights **Cite solution_lesson_node_00001**.

**Level 1: Meta-Learner**
*   A **Logistic Regression** model will be trained on the concatenated Out-Of-Fold (OOF) probability predictions from the three base models. This learns the optimal weighted combination, correcting systematic biases and effectively utilizing the weaker DenseNet predictions **Cite solution_lesson_node_00053**.

# Data
The data pipeline is rigorously standardized to preserve physical signal fidelity, strictly adhering to the "Golden Recipe" of Idea 4.

1.  **Spectrogram Generation:**
    *   **FFT Parameters:** `n_fft=1024` (High Frequency Resolution) and `hop_length=64` (High Temporal Resolution). This ensures the FFT bins exceed Mel bands (>4:1) to prevent aliasing **Cite solution_lesson_node_00008** and resolves short call contours **Cite solution_lesson_node_00016**.
    *   **Mel Filterbank:** `n_mels=128`, `normalized=False`. We explicitly disable area normalization to preserve the environmental "Pink" noise spectral tilt **Cite solution_lesson_node_00022**.
2.  **Preprocessing:**
    *   **Native Resolution:** Inputs will be fed to the models at their **native resolution** (approx. $128 \times 63$). We will **NOT** resize to $224 \times 224$ to avoid interpolation artifacts **Cite solution_lesson_node_00031**.
    *   **Instance Standardization:** We will apply **Zero-Mean, Unit-Variance standardization** to each clip individually. This is critical for convergence **Cite solution_lesson_node_00025**.
3.  **Augmentation:**
    *   **SpecAugment** (Time/Freq masking) will be used **Cite solution_lesson_node_00003**. Mixup is explicitly excluded **Cite solution_lesson_node_00018**.

# Training
We implement a **5-Fold Stratified Cross-Validation** workflow with a focus on probability calibration.

1.  **Sampling (Correction):** We will strictly use a **WeightedRandomSampler** to balance the classes in every batch. This corrects the fatal error in Idea 13 where the sampler was removed **Cite solution_lesson_node_00056**.
2.  **Batch Size:** We will maximize the batch size to **128** to stabilize the gradients from the weighted sampler **Cite solution_lesson_node_00004**.
3.  **Optimization:**
    *   **Optimizer:** AdamW with a **Low Weight Decay of `1e-4`**. This is critical to allow the Noisy Student backbone to adapt without being over-constrained **Cite solution_lesson_node_00039**.
    *   **Scheduler:** Cosine Annealing to ensure effective fine-tuning **Cite solution_lesson_node_00046**.
4.  **Convergence Strategy:**
    *   We will use **Early Stopping monitoring Validation Loss** (not AUC). Minimizing loss ensures the base learners produce well-calibrated probabilities, which is essential for the performance of the Level 1 meta-learner **Cite solution_lesson_node_00055**.

# Evaluation
1.  **Base Prediction:**
    *   Process Test clips using the exact pipeline (1024/64 STFT, Native Res, Instance Norm).
    *   Generate probability predictions from all 15 trained base models (3 architectures $\times$ 5 folds).
2.  **Stacking:**
    *   Feed the predictions into the trained Level 1 Logistic Regression model to generate the final probability. This yields a variance-reduced, calibrated submission that exploits the unique inductive biases of the triple-architecture ensemble.
