Based on the comprehensive analysis of the previous experiments and the extracted lessons, I propose a **Multi-Objective Heterogeneous Stacked Ensemble**.

This strategy represents a structural evolution of the Stacking approach (Idea 12, Idea 18). It operationalizes the insight from **Lesson 00082** that a single training trajectory contains multiple distinct optimal states. By treating the **Convergence Objective** (Loss vs. Rank) as a diversity axis, we can extract double the number of base learners from the same computational footprint, resolving the conflict between Calibration and Discrimination identified in Lessons 00055 and 00066.

# Model
We will construct a **Two-Stage Stacked Generalization Ensemble** derived from **Multi-Objective Checkpointing**.

**Level 0: Multi-Objective Base Learners**
We will train two structurally distinct "Legacy" CNN architectures. From *each* training run, we will extract **two distinct checkpoints**, effectively creating an ensemble of 4 behaviors for the cost of 2 models.

1.  **Backbone A: EfficientNet-B0 (Noisy Student)**
    *   **Initialization:** `ns_jft_in1k`. These weights leverage massive pre-training and outperform standard ImageNet weights when properly regularized **Cite solution_lesson_node_00054**.
    *   **Role:** Feature extraction via Inverted Residuals and Squeeze-and-Excitation.
2.  **Backbone B: ResNet-34 (ImageNet)**
    *   **Initialization:** Standard ImageNet.
    *   **Role:** Provides deep residual learning biases to decorrelate errors from EfficientNet **Cite solution_lesson_node_00053**.
3.  **Common Modifications:**
    *   **Pooling:** **Generalized Mean (GeM) Pooling** to maximize detection of transient whale calls **Cite solution_lesson_node_00017**.
    *   **Input Adaptation:** First layer adapted to **1-channel input** via weight averaging **Cite solution_lesson_node_00001**.
4.  **Checkpointing Strategy (Structural Innovation):**
    *   Instead of saving only one "best" model, we will save:
        *   **Checkpoint 1 (Discriminator):** The state with the **Maximum Validation AUC**. This optimizes for ranking **Cite solution_lesson_node_00066**.
        *   **Checkpoint 2 (Calibrator):** The state with the **Minimum Validation Loss**. This optimizes for probability calibration **Cite solution_lesson_node_00055**.
    *   This yields 4 base predictors: `EffNet_AUC`, `EffNet_Loss`, `ResNet_AUC`, `ResNet_Loss` **Cite solution_lesson_node_00082**.

**Level 1: Meta-Learner**
*   A **Logistic Regression** model will be trained on the concatenated Out-Of-Fold (OOF) probabilities from these 4 predictors. This allows the stack to dynamically weight the sharp decision boundaries of the Discriminators against the reliable probabilities of the Calibrators **Cite solution_lesson_node_00082**.

# Data
The data pipeline strictly enforces the "Golden Recipe" for physical fidelity, augmented with aggressive regularization.

1.  **Spectrogram Generation:**
    *   **FFT Parameters:** `n_fft=1024` (High Freq Res) and `hop_length=64` (High Time Res). This prevents aliasing and resolves short call contours **Cite solution_lesson_node_00008**, **Cite solution_lesson_node_00016**.
    *   **Mel Filterbank:** `n_mels=128`, `normalized=False` to preserve environmental spectral tilt **Cite solution_lesson_node_00022**.
    *   **Dynamic Range:** Apply **`top_db=80`** clamping to fix the noise floor before normalization **Cite solution_lesson_node_00062**.
2.  **Preprocessing:**
    *   **Native Resolution:** Inputs fed at generated dimensions (~128x63). **No resizing** to 224x224 **Cite solution_lesson_node_00031**.
    *   **Instance Standardization:** Zero-Mean, Unit-Variance applied per clip **Cite solution_lesson_node_00025**.
3.  **Augmentation:**
    *   **Aggressive SpecAugment:** We will set `freq_mask_param=20` (doubling standard width). This forces the model to learn robust temporal dependencies for narrow-band signals **Cite solution_lesson_node_00071**. Mixup is excluded **Cite solution_lesson_node_00018**.

# Training
We implement a **5-Fold Stratified Cross-Validation** workflow.

1.  **Sampling:** **WeightedRandomSampler** to balance classes in every batch **Cite solution_lesson_node_00004**.
2.  **Batch Size:** Maximize to **128** for stability **Cite solution_lesson_node_00004**.
3.  **Optimization:**
    *   **Optimizer:** AdamW with **Low Weight Decay (`1e-4`)** to accommodate Noisy Student weights **Cite solution_lesson_node_00039**.
    *   **Scheduler:** Cosine Annealing to ensure effective fine-tuning **Cite solution_lesson_node_00046**.
4.  **Procedure:**
    *   Train each fold for a fixed cycle (e.g., 20 epochs).
    *   During training, track both AUC and Loss.
    *   At the end of the run, save the specific epochs corresponding to Best AUC and Best Loss as separate models **Cite solution_lesson_node_00082**.

# Evaluation
We utilize a **Bagged-Stacking** protocol to ensure robust inference **Cite solution_lesson_node_00061**.

1.  **Base Prediction:** For the Test set, generate predictions from all 20 saved states (5 folds $\times$ 2 architectures $\times$ 2 checkpoints).
2.  **Bagging:** Average the 5 fold-predictions for each specific type (e.g., average all `EffNet_AUC` folds) to produce 4 robust probability vectors.
3.  **Stacking:** Feed these 4 bagged vectors into the Level 1 Logistic Regression model to generate the final submission.
