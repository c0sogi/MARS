Based on the comprehensive analysis of the "Lessons" and "Previous Ideas," I propose the **Self-Distilled Multi-Objective Stacked Ensemble**.

This strategy represents a structural evolution of the **Multi-Objective** approach (Idea 19) and the **Semi-Supervised** approach (Idea 20). It synthesizes the robustness of **Multi-Objective Checkpointing** (resolving the AUC vs. Loss conflict) with the inductive power of **Self-Training**, while strictly adhering to the "Golden Recipe" of signal processing parameters identified as critical in the lessons.

### Model
We will construct a **Two-Stage Stacked Generalization Ensemble** that evolves through two training rounds.

**Level 0: Heterogeneous Base Learners**
We will employ two robust "Legacy" architectures.
1.  **EfficientNet-B0 (Noisy Student):** Initialized with `ns_jft_in1k` weights. These leverage massive pre-training and outperform standard ImageNet weights when properly regularized **Cite solution_lesson_node_00054**.
2.  **ResNet-34 (ImageNet):** Provides deep residual learning biases to decorrelate errors from the EfficientNet backbone **Cite solution_lesson_node_00053**.
3.  **Common Components:**
    *   **Pooling:** **Generalized Mean (GeM) Pooling** to maximize detection of transient whale calls **Cite solution_lesson_node_00017**.
    *   **Input Adaptation:** First layer adapted to **1-channel input** via weight averaging **Cite solution_lesson_node_00001**.

**Structural Innovation: Multi-Objective Checkpointing**
For every training run (in both rounds), we will save **two distinct checkpoints** per fold:
*   **Discriminator:** The model state with **Maximum Validation AUC** **Cite solution_lesson_node_00066**.
*   **Calibrator:** The model state with **Minimum Validation Loss** **Cite solution_lesson_node_00055**.
This yields 4 predictors per fold (EffNet_AUC, EffNet_Loss, ResNet_AUC, ResNet_Loss), capturing diverse optimal states from a single trajectory **Cite solution_lesson_node_00082**.

**Level 1: Meta-Learner**
*   A **Logistic Regression** model trained on the concatenated Out-Of-Fold (OOF) probabilities from the Level 0 models.

### Data
The data pipeline is rigorously standardized to the "Golden Recipe" to preserve physical signal fidelity.

1.  **Spectrogram Generation:**
    *   **FFT Parameters:** `n_fft=1024` (High Freq Res) and `hop_length=64` (High Time Res). This prevents aliasing and resolves short call contours **Cite solution_lesson_node_00008**, **Cite solution_lesson_node_00016**.
    *   **Mel Filterbank:** `n_mels=128`, `normalized=False`. We explicitly disable area normalization to preserve the environmental "Pink" noise spectral tilt **Cite solution_lesson_node_00022**.
    *   **Dynamic Range (Correction):** We will apply **`top_db=80`** clamping to fix the noise floor, preventing the "long tail" of silence from skewing normalization **Cite solution_lesson_node_00062**.
2.  **Preprocessing:**
    *   **Native Resolution:** Inputs fed at generated dimensions (~128x63). **No resizing** to 224x224 **Cite solution_lesson_node_00031**.
    *   **Instance Standardization:** Zero-Mean, Unit-Variance applied per clip **Cite solution_lesson_node_00025**.
3.  **Augmentation:**
    *   **Aggressive SpecAugment:** We will set `freq_mask_param=20` (doubling standard width). This forces the model to learn robust temporal dependencies **Cite solution_lesson_node_00071**. Mixup is excluded **Cite solution_lesson_node_00018**.

### Training
We implement a **Two-Round Stratified Cross-Validation** workflow.

**Round 1: Supervised Training**
1.  **Sampling:** **WeightedRandomSampler** to balance classes in every batch **Cite solution_lesson_node_00004**.
2.  **Optimization:** **AdamW** with **Low Weight Decay (`1e-4`)** (Cite solution_lesson_node_00039) and **Cosine Annealing** (Cite solution_lesson_node_00046).
3.  **Execution:** Train 5 folds of EffNet and ResNet. Save **Best-AUC** and **Best-Loss** checkpoints.
4.  **Meta-Learning:** Train Level 1 Logistic Regression on Round 1 OOFs.

**Round 2: Self-Distillation (Structural Innovation)**
1.  **Pseudo-Labeling:** Use the **Round 1 Meta-Learner** (the full stack) to predict probabilities for the unlabeled Test set. Select high-confidence samples (e.g., $p>0.95$ or $p<0.05$) and add them to the training set **Cite solution_lesson_node_00087**.
2.  **Re-Balancing:** Re-calculate weights for the **WeightedRandomSampler** to account for the class distribution of the new expanded dataset (Train + Pseudo-Test).
3.  **Retraining:** Retrain all Base Learners (EffNet/ResNet) from scratch on the expanded dataset.
    *   *Note:* We use **Aggressive SpecAugment** here to prevent overfitting to the noise in the pseudo-labels.
4.  **Checkpointing:** Again, save **Best-AUC** and **Best-Loss** checkpoints based on the **original pure validation splits** (never validate on pseudo-labels).

### Evaluation
We utilize a **Bagged-Stacking** protocol **Cite solution_lesson_node_00061**.

1.  **Base Prediction:** Generate predictions on the Test set using the **Round 2** models (20 total: 5 folds $\times$ 2 architectures $\times$ 2 objectives).
2.  **Bagging:** Average the 5 fold-predictions for each specific type (e.g., `EffNet_AUC`) to produce 4 robust probability vectors.
3.  **Stacking:** Feed these 4 bagged vectors into a final Logistic Regression meta-learner (trained on Round 2 OOFs) to generate the submission.
