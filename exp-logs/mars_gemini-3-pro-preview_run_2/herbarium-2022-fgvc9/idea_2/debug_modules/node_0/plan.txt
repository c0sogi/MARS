The following script demonstrates the usage of the provided library modules for the plant classification task. It performs the following steps:
1.  **Configuration**: Adjusts `Config` parameters for a fast demonstration (smaller batch size, image size, and debug mode).
2.  **Data Loading**: Uses `get_dataloaders` to load a small subset of the training and validation data. It validates the structure of the batches produced.
3.  **Model Initialization**: Instantiates the `HierarchicalEfficientNet` using taxonomy counts derived from the data loader. It verifies the forward pass logic.
4.  **Training**: Runs a single epoch of training using the `Trainer` class to verify the training loop and checkpoint saving mechanism.
5.  **Inference**: Creates a small subset of the test metadata, updates the configuration to point to this subset, and runs `predict_test_set` to generate a submission file.
