This script follows a strategy to generate metadata for a plant classification task by scanning the directory structure and parsing provided JSON files.

**Implementation Strategy:**
1.  **Training Data Collection**: The script traverses the `./input/train_images` directory. It assumes the file structure `train_images/<subfolder1>/<subfolder2>/<category_id>__<unique_id>.jpg` as indicated by the dataset information. It extracts the label (`category_id`) directly from the filename and stores the relative file path.
2.  **Test Data Collection**: It reads `./input/test_metadata.json` to retrieve test image filenames and IDs. It constructs the relative file path by prepending `test_images/` to the `file_name` found in the JSON, matching the provided file listing.
3.  **Data Splitting**: The training data is split into training (80%) and validation (20%) sets using stratified sampling to maintain class distribution. Classes with fewer than 2 samples are forced into the training set to prevent errors during stratification. A fixed random state (42) is used for reproducibility.
4.  **Metadata Output**: The processed data is saved as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
5.  **Validation**: The script prints summary statistics and performs a file existence check on a random sample of 1000 files from each dataset. It raises an error if more than 50% of the sampled files are missing.
