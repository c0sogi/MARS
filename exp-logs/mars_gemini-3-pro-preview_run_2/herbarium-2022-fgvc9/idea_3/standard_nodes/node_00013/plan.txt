    *   **Class Frequency**: The number of training samples for the ground truth class (to check for long-tail performance issues).
    *   **Image File Size**: A proxy for image complexity/quality.
5.  **Submission**: I will compare the final Macro F1 score against the threshold (`0.6021914648406147`). If the score exceeds this value, I will generate predictions for the test set and save the `submission.csv`.
