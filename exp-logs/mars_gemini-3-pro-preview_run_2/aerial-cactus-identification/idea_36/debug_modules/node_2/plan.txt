The `RuntimeError` occurs because the `fuse_bn_only` function creates a temporary `dummy_conv` layer on the default device (CPU), but attempts to fuse it with a BatchNorm layer (`bn`) that resides on the GPU. PyTorch operations cannot mix tensors from different devices. To fix this, we must explicitly move the `dummy_conv` layer to the same device as the `bn` layer (using `.to(bn.weight.device)`) before calling `fuse_conv_bn`. This ensures all tensors involved in the fusion operation are co-located.
