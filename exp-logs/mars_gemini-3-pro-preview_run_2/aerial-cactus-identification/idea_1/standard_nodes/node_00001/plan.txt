Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the random seeds using `library.utils.set_seed` to ensure reproducibility. Detect the available computation device (CUDA or CPU) using `library.config.Config`.
2.  **Data Preparation**: Load the training, validation, and test datasets using `library.dataset.get_datasets`. Wrap these datasets in PyTorch `DataLoader` instances with appropriate batch sizes and worker counts defined in `Config`.
3.  **Model Initialization**: Instantiate the `ShallowCNN` model from `library.model`.
4.  **Training**: Execute the training pipeline using `library.engine.train_model`. This function handles the training loop, validation at each epoch, and early stopping, reloading the best model weights upon completion.
5.  **Validation**: Perform a final validation pass using `library.engine.validate` to calculate the ROC AUC score on the hold-out validation set. Print this metric strictly in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Iterate through the validation set to generate predictions and calculate the absolute error for each sample.
    *   Extract basic image statistics (brightness, contrast, channel means) for each validation image.
    *   Compute and print the Pearson correlation between the model's error magnitude and these image features to identify potential weaknesses.
7.  **Submission**: Generate predictions for the test set using `library.engine.predict_and_submit` and save the results to the specified submission path.
