This script demonstrates the end-to-end usage of the provided library files for the Cactus Identification task. It performs the following steps:

1.  **Configuration Patching**: It dynamically modifies the `library.config` module at runtime to adapt the settings for a quick demonstration. This includes reducing the number of epochs to 1, using a single random seed, and pointing to a smaller subset of the data to ensure the script completes rapidly.
2.  **Data Preparation**: It creates temporary "mini" metadata files by sampling a small fraction of the original training and test sets. This allows the `dataset.CactusDataset` class to load real images from the `./input` directory without processing the entire dataset.
3.  **Component Verification**:
    *   **Model**: Instantiates the `WideSERes2NeXt` model and performs a forward pass with a dummy input tensor to verify the architecture and output shape.
    *   **Dataset**: Instantiates the `CactusDataset` with the mini-metadata to verify data loading, transformation, and shape consistency.
4.  **Execution**: Invokes `library.engine.run()` to execute the full training and inference pipeline using the patched configuration.
5.  **Result Validation**: Checks for the existence and correctness of the generated submission file.
