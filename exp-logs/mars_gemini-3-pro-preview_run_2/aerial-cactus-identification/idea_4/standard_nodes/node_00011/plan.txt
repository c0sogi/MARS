Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility using the provided `utils` module, and detect the computation device (GPU).
2.  **Data Loading**: Use the `dataset` module to load training, validation, and test datasets. Create PyTorch DataLoaders with appropriate batch sizes and transformations (augmentation for training, standard tensor conversion for validation/test).
3.  **Model Training (Homogeneous Ensemble)**: Iterate through the seeds defined in `config.SEEDS`. For each seed:
    *   Initialize the `MicroConvNeXt` model.
    *   Train the model using `train_engine.train_model` for the specified number of epochs.
    *   Save the best model weights to the working directory.
4.  **Validation & Metric Calculation**:
    *   Load all trained model checkpoints.
    *   Perform inference on the validation set using Test Time Augmentation (TTA) via `inference_engine.predict_with_tta`.
    *   Average the predictions across all models (Ensemble).
    *   Calculate the final ROC AUC score using `utils.calculate_roc_auc`.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Compute the absolute prediction error (`|label - prediction|`) for the validation set.
    *   Extract basic image meta-features (Brightness, Contrast, Red Channel Mean) from the raw validation images.
    *   Calculate and print the Pearson correlation between the error magnitude and these features to identify systematic weaknesses.
6.  **Submission**:
    *   If the validation metric is valid (interpreting the "> 1.0" requirement as a sanity check for a non-trivial model, effectively > 0.5), generate predictions for the test set using the ensemble with TTA.
    *   Save the averaged predictions to `submission.csv` using `inference_engine.save_submission`.
