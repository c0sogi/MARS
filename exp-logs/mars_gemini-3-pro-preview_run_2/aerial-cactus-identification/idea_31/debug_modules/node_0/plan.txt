### Implementation Strategy

    *   Redirecting the working directory to `./working/demo_execution` to isolate outputs.
    *   Reducing `EPOCHS` to 1 and `MAX_TRAIN_SAMPLES` to a small number (e.g., 100) to ensure the script completes quickly.
    *   Setting `NUM_WORKERS` to 0 to avoid multiprocessing overhead on small data.
3.  **Data Pipeline Verification**:
    *   Instantiate the `CactusDataset` with the modified configuration.
    *   Verify that data loading works, shapes are correct (3x32x32 for images), and caching mechanisms function without error.
    *   Validate the transformation pipeline.
4.  **Model Architecture Verification**:
    *   Instantiate the `WideSERes2NeXt` model.
    *   Pass a dummy tensor through the model to verify the forward pass and output dimensions `(Batch_Size, 1)`.
5.  **Training Loop Execution**:
    *   Execute `run_training` for a single seed. This demonstrates the integration of the dataset, model, optimizer, scheduler, and checkpointing logic.
    *   Verify that the model checkpoint file is created.
6.  **Inference & Submission Verification**:
    *   Load the trained model from the checkpoint.
    *   Run the `predict` function on a subset of the test data.
    *   Assert that the output DataFrame has the correct format and probability values are within the valid range `[0, 1]`.
7.  **Metric Utility Verification**:
    *   Explicitly test the `calculate_roc_auc` function with synthetic data to ensure metric calculation correctness.
