Implementation strategy:
1.  **Setup & Imports**: Import necessary modules and the provided library functions (`library.utils`, `library.dataset`, `library.model`, `library.train`). Set the random seed and device.
2.  **Training & Submission**: Utilize the provided `library.train.run_training` function to orchestrate the training of the WideResNet model across 5 folds (seeds). This function automatically handles training loops, early stopping, model saving, and—crucially—generates the test set submission file using Test Time Augmentation (TTA).
3.  **Ensemble Validation**: After training, explicitly load the 5 saved model checkpoints. Run inference on the validation set for each model to obtain probabilities. Average these probabilities to form an ensemble prediction.
4.  **Metric Calculation**: Compute the Area Under the ROC Curve (AUC) using the ensemble validation predictions and the ground truth labels. Print this as `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Iterate through the validation set to compute image meta-features (brightness, contrast, RGB means). Calculate the absolute error of the model's predictions. Compute and print the Pearson correlation between these errors and the image features to identify potential weaknesses.
6.  **Verification**: Confirm the submission file exists. (Note: The constraint "metric > 1.0" is mathematically impossible for AUC; I proceed with the standard submission generation performed by `run_training`).
