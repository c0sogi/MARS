The following script orchestrates the end-to-end pipeline for the Cactus Identification task.

**Implementation Strategy:**
1.  **Setup & Data Loading**: We initialize the environment with a fixed seed and load the dataset using the provided `library.dataset.load_data` function, leveraging caching for speed.
2.  **Ensemble Training**: We iterate through 5 distinct random seeds. For each seed, we invoke `library.trainer.run_training_cycle` to train a `WideAntiAliasedCoordRes2NeXt` model. We limit the epochs to 10 to satisfy the "fast baseline" requirement while ensuring sufficient convergence for the small 32x32 images.
3.  **Ensemble Validation**: We load the best checkpoints from all 5 seeds and perform inference on the hold-out validation set using Test Time Augmentation (TTA). We average the predictions to compute the `Final Validation Metric` (ROC AUC).
4.  **Failure Analysis**: We calculate the absolute error of the ensemble predictions against the ground truth. We then compute meta-features (Brightness, Contrast, Channel Means) for the validation images and calculate the Pearson correlation between these features and the model's error to identify systematic weaknesses.
5.  **Submission**: We generate the final submission file using `library.inference.generate_submission`. Note: The prompt condition "AUC > 1.0" is mathematically impossible; we proceed with submission generation assuming a standard validity threshold (AUC > 0.5) to ensure the required output file is created.
