Implementation Strategy:
1.  **Environment Setup**: Import standard libraries and the provided library modules (`config`, `dataset`, `model`, `train`, `utils`).
2.  **Configuration Override (Monkey-Patching)**: To satisfy the "Optimize for Speed" requirement without modifying the read-only library files, I will programmatically override configuration constants (e.g., `EPOCHS`, `SEEDS`, `DEBUG`, `WORKING_DIR`) in the imported modules. This ensures the training runs for only 1 epoch on a small data subset (100 images) and saves outputs to a temporary demo directory.
3.  **Data Loading Verification**: Call `library.dataset.get_dataloaders` to generate and load the dataset. I will verify the data shapes and batch sizes to ensure the `DEBUG` mode is correctly active (expecting 100 samples).
4.  **Model Verification**: Instantiate `library.model.CactusNet` and perform a dummy forward pass with random data to confirm the architecture produces the correct output shape.
5.  **Training Pipeline Execution**: Execute `library.train.run_training()`. This will run the training loop using the patched configuration (1 epoch, 1 seed), saving the model and generating a submission file.
6.  **Result Validation**: Check for the existence of the generated model checkpoint and submission file. Load the submission file to verify it follows the required format and contains predictions for the expected number of test images.
