3.  **Model Verification**: Instantiate the `WideResNeXt` model. Perform a forward pass with a dummy input tensor to confirm the architecture accepts the input shape and produces the expected output shape `(Batch Size, 1)`.
4.  **Training Loop**: Run `train_model` with a fixed seed. This exercises the loss calculation, backpropagation, and validation logic, saving the trained model to disk.
5.  **Inference & Submission**: Call `generate_submission` to load the saved model, perform inference with Test Time Augmentation (TTA), and generate the CSV file.
6.  **Final Validation**: Check that the submission file exists, has the correct dimensions, and contains valid probability predictions.
