The implementation strategy is as follows:

1.  **Configuration & Setup**: Override the default epoch count in `Config` to a smaller number (4 epochs) to ensure the training completes quickly within the time limit while still learning useful features. Set random seeds for reproducibility.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. This will fine-tune the ResNet50 backbone with the ArcFace head on the training data.
3.  **Validation & Metric Calculation**:
    *   Load the best trained model.
    *   Generate "Gallery" embeddings from the training set using `library.inference.get_gallery_features`.
    *   Generate "Query" embeddings from the validation set by manually creating a `HotelDataset` and running extraction.
    *   Perform retrieval using `library.inference.predict` to get the top 5 predicted hotel IDs for each validation image.
    *   Calculate the Mean Average Precision @ 5 (MAP@5) by comparing predictions against the ground truth in `val_metadata.csv`.
    *   Print the `Final Validation Metric` in the required format.
4.  **Failure Analysis**:
    *   Compute the Average Precision (AP) for each validation sample.
    *   Calculate the "Error Magnitude" as $1 - AP$.
    *   Correlate this error with the class frequency (number of images per hotel in the training set) to check if the model struggles with rare classes (long-tail problem).
    *   Print the correlation coefficient.
5.  **Submission**:
    *   Compare the calculated MAP@5 against the provided threshold.
    *   If the metric exceeds the threshold, execute `library.inference.run_inference` to generate predictions for the test set and save the `submission.csv`.
