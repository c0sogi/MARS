The issue is located in `library/inference.py` within the `extract_embeddings` function. When processing the gallery, the `id_list` accumulates batches of labels as NumPy arrays. The original code checks if the first element is a scalar number (`int`, `float`, etc.), which fails for NumPy arrays. As a result, it executes `np.array(id_list)`, which stacks the batches into a 2D array (shape `[num_batches, batch_size]`) instead of flattening them into a single 1D array. This causes `gallery_labels` to have a length equal to the number of batches (5) rather than the total number of images (60), leading to an `IndexError` during retrieval when accessing indices greater than 4. The fix is to correctly detect NumPy arrays in `id_list` and use `np.concatenate` to flatten the list, ensuring the labels array matches the embeddings dimension.
