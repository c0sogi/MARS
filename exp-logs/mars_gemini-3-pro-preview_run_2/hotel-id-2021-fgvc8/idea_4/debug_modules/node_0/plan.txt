The implementation strategy is as follows:

1.  **Configuration Setup**: Import the `CFG` class and override specific parameters to ensure the script runs quickly and efficiently within the demo environment. This includes enabling debug mode (to limit iterations), reducing the batch size, disabling multiprocessing for data loading, and switching to a lightweight backbone (`resnet18`) with random initialization to avoid network dependency and reduce memory usage.

2.  **Data Preparation**: Use the provided `process_metadata` function to load and encode the dataset. To further optimize speed, slice the resulting DataFrames to create tiny subsets (e.g., 50 samples) for training, validation, and testing. Instantiate the `HotelDataset` and `DataLoader` for each split using the appropriate transforms.

3.  **Model Initialization**: Initialize the `HotelNet` model. Verify that the model architecture correctly produces the expected output shapes (logits for training, embeddings for inference) by running a dummy forward pass.

4.  **Training Simulation**: Execute the `train_loop` function using the subset data. This demonstrates the integration of the training engine, loss calculation (ArcFace/SubCenterArcFace), and validation metrics.

5.  **Inference and Submission**: Run the `inference` function on the test subset. This showcases the test-time augmentation, query expansion, and submission file generation pipeline.

6.  **Validation**: Perform assertions throughout the script to verify:
    *   Dataset output shapes.
    *   Model output shapes.
    *   Existence and format of the generated submission file.
