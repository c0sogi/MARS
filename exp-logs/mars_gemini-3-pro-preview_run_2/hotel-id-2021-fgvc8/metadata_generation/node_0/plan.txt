The implementation strategy is as follows:

1.  **Setup and Loading**: Define paths and constants. Read `train.csv` and `sample_submission.csv` from the `./input` directory.
2.  **Path Construction**: Create a `file_path` column for both datasets.
    *   For training data, the path is constructed as `train_images/{chain}/{image}`.
    *   For test data, the path is constructed as `test_images/{image}`.
3.  **Data Splitting**:
    *   Identify "singleton" hotels (hotels with only 1 image) and separate them. These must go to the training set to ensure every class is represented in training.
    *   Perform a stratified 80/20 split on the remaining data (hotels with $\ge$ 2 images) using `hotel_id` as the stratification target and a fixed random state (42).
    *   Combine the "singleton" samples with the split training samples to form the final training set.
    *   The validation set consists of the validation split from the non-singleton data.
4.  **Saving Metadata**: Save the resulting DataFrames to `train_metadata.csv`, `val_metadata.csv`, and `test_metadata.csv` in the `./metadata` directory.
5.  **Validation**:
    *   Print summary statistics (dataset sizes, unique hotels).
    *   Check file existence: Randomly sample 1000 paths from each metadata file and verify they exist in `./input`. Raise an error if the missing ratio exceeds 0.5.
    *   Verify split integrity: Ensure no image overlap between train and validation, and ensure all hotels in the validation set exist in the training set.
