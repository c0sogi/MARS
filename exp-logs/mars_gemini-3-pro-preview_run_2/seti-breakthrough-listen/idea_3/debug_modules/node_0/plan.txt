The following script demonstrates the usage of the provided library files for the SETI signal detection task. It performs the following steps:
1.  **Configuration**: Overrides default configuration settings to run a fast demonstration (small batch size, limited data subset, no pretrained weights download).
2.  **Data Loading**: Loads metadata, creates a small subset of training, validation, and test data, and initializes `SETIDataset` and `DataLoader` instances.
3.  **Model Initialization**: Instantiates the `SETIModel` (ConvNeXt-Tiny based) on the GPU.
4.  **Training**: Runs a single epoch of training using the `train_one_epoch` engine function, demonstrating mixed-precision training and Mixup augmentation.
5.  **Validation**: Evaluates the model on the validation subset using `valid_one_epoch`.
6.  **Inference**: Generates predictions on the test subset using `inference_fn` with Test Time Augmentation (TTA).
7.  **Verification**: Includes assertions to verify data shapes, output ranges, and pipeline integrity.
