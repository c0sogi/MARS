# Baseline Approach: Shallow Multi-Channel CNN

### Model
The architecture is a lightweight, custom 4-layer Convolutional Neural Network (CNN) designed to process the 6-channel cadence snippets directly. Unlike the "Previous Ideas" which rely on complex backbones (EfficientNet, Swin) or hybrid architectures (RNNs), this model focuses on learning low-level spatial features (like diagonal lines) from scratch with minimal parameter overhead.

*   **Input Layer**: Accepts tensors of shape `(Batch, 6, 273, 256)`, treating the 6 cadence panels (ABACAD) as input channels. This allows the network to learn the contrast between "On-Target" (A) and "Off-Target" (B/C/D) panels immediately at the pixel level.
*   **Convolutional Blocks**: The network consists of 4 sequential blocks. Each block comprises:
    1.  **Conv2D**: 3x3 kernel size, padding='same'. Filter counts increase progressively (e.g., 32, 64, 128, 256).
    2.  **Batch Normalization**: To stabilize training and accelerate convergence.
    3.  **ReLU Activation**: To introduce non-linearity.
    4.  **MaxPooling2D**: 2x2 pooling to reduce spatial dimensions and computational load.
*   **Global Aggregation**: A **Global Average Pooling** layer follows the final convolutional block. This condenses the spatial feature maps into a single vector, making the model robust to the exact position of the signal within the snippet.
*   **Output Head**: A single Fully Connected (Dense) layer maps the feature vector to a scalar output, followed by a Sigmoid activation to produce the probability of a "needle" being present.

### Data
*   **Loading**: Data is loaded directly from the `.npy` files using the paths generated in the metadata.
*   **Preprocessing**:
    *   **Cast**: Convert the default `float16` data to `float32` for numerical stability during training.
    *   **Instance Normalization**: For each individual sample, calculate the mean and standard deviation. Subtract the mean and divide by the standard deviation (plus a small epsilon). This ensures that the model sees data with a consistent scale (Zero Mean, Unit Variance), which is critical for spectrograms where absolute power levels can fluctuate significantly between observations.
*   **Augmentation**: Consistent with the philosophy of a simple baseline, no data augmentation (e.g., flips or rotations) will be applied, as the directional nature of Doppler drifts (diagonal lines) and RFI (vertical lines) contains semantic meaning that random augmentations might corrupt.

### Training
*   **Loss Function**: **Binary Cross-Entropy with Logits** (BCEWithLogitsLoss) will be used to optimize the binary classification task.
*   **Optimizer**: **Adam** optimizer with a default learning rate (e.g., 1e-3) will be employed for its robustness and minimal need for tuning.
*   **Scheduler**: A **ReduceLROnPlateau** scheduler will monitor the validation AUC and reduce the learning rate if improvement stalls, allowing for fine-grained weight updates in later epochs.
*   **Strategy**: The model will be trained for a fixed number of epochs (e.g., 10-15) with Early Stopping enabled (patience of 3 epochs) to prevent overfitting and save runtime. Mixed-precision training (FP16) will be utilized on the A100 GPU to maximize throughput.

### Evaluation
*   **Inference**: The trained model will iterate through the test set using the `test.csv` metadata.
*   **Prediction**: For each test sample, the model will output a probability score. These scores will be mapped to their corresponding `id`s and saved to a submission file in the required CSV format.
*   **Metric**: The validation AUC will be monitored during training to ensure the model is learning effectively before generating the final test submission.
