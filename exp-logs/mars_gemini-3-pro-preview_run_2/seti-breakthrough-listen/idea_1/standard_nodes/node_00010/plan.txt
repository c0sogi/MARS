To improve the model's performance, I will implement a strategy based on the provided lessons learned, specifically targeting the architecture's ability to detect sparse signals and the data pipeline's generalization capability.

1.  **Architecture Upgrade (Cite solution_lesson_node_00007)**: I will replace the ResNet18 backbone with **EfficientNet-B0**. Crucially, I will configure it to use **Global Max Pooling (GMP)** instead of the standard Global Average Pooling. As established in Lesson 00007, GMP is far superior for detecting "needle" signals (sparse, localized anomalies) in a large "haystack" of noise, whereas average pooling tends to wash out the signal.
2.  **Data Augmentation (Cite solution_lesson_node_00009)**: I will introduce random **horizontal flipping** (frequency inversion) into the `SETIDataset`. Lesson 00009 highlights that removing this augmentation causes overfitting because the model fails to learn that Doppler drifts can slope in either direction.
3.  **Hyperparameter Optimization**:
    *   **Learning Rate**: I will lower the learning rate to **1e-4** (from 1e-3) to ensure stable convergence with the EfficientNet architecture (Lesson 00007).
    *   **Training Scale**: I will disable `DEBUG` mode to train on the **full dataset** for **10 epochs**, ensuring the model has enough data and time to generalize.
4.  **Conditional Submission**: I will modify the execution script to only generate a submission file if the validation AUC exceeds the baseline threshold of ~0.806.
