The strategy to implement the `runfile.py` script is as follows:

1.  **Configuration & Setup**: Import the `Config` class from `library.config` and override specific parameters to ensure a fast baseline execution. Specifically, enable `DEBUG` mode, set `DEBUG_SAMPLE_SIZE` to 10,000 samples, and limit `EPOCHS` to 5. Set the random seed using `set_seed`.
2.  **Training**: Instantiate the `Trainer` class from `library.trainer` and call its `fit()` method. This will handle the training loop, validation on a subset (due to debug mode), and saving of the best model checkpoint.
3.  **Full Validation & Failure Analysis**:
    *   Load the best model checkpoint saved by the trainer.
    *   Initialize the `SETIDataset` with the full validation metadata (`Config.VAL_METADATA`) to ensure the final metric is computed on the entire hold-out set.
    *   Run inference in evaluation mode (`torch.no_grad()`) on the available GPU.
    *   Collect predictions and ground truth targets to compute the Area Under the ROC Curve (AUC). Print this as `Final Validation Metric`.
    *   Simultaneously calculate basic image statistics (mean, standard deviation, max value) for each validation sample.
    *   Compute the absolute error between predictions and targets. Calculate and print the correlation between this error and the image statistics to identify potential failure modes.
4.  **Submission**: Call the `generate_submission` function from `library.inference` to predict on the test set and generate the `submission.csv` file.
