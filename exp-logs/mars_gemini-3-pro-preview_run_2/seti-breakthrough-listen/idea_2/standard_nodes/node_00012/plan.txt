Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class. Override `Config.epochs` to a lower value (8 epochs) to ensure the "fast baseline" completes well within the 2-hour limit while still learning effectively from the full dataset. Set random seeds for reproducibility.
2.  **Data Loading**: Utilize `get_datasets(debug=False)` to load the full training, validation, and test sets. Wrap them in PyTorch `DataLoader`s with pinned memory and appropriate batch sizes for the A100 GPU.
3.  **Model Initialization**: Instantiate the `SETIModel` (EfficientNet-V2 Small + GeM pooling) and move it to the GPU. Setup the `AdamW` optimizer and `CosineAnnealingLR` scheduler.
4.  **Training**: Initialize the `SETIEngine` and execute the training loop. The engine handles the training steps, validation monitoring, and saving the best model checkpoint based on AUC.
5.  **Validation & Failure Analysis**:
    *   Load the best model checkpoint.
    *   Perform a dedicated inference pass on the validation set to collect predictions and simultaneously calculate simple statistical features (mean, std, max, min) of the input images.
    *   Compute the final AUC score and print it in the required format.
    *   Calculate the absolute error between predictions and targets. Compute and print the correlation between this error and the image statistics to identify failure modes.
6.  **Submission**: Compare the final validation AUC against the specified threshold (0.8067771599905759). If the model passes, trigger the `engine.predict` method to generate and save `submission.csv` using Test Time Augmentation (TTA).
