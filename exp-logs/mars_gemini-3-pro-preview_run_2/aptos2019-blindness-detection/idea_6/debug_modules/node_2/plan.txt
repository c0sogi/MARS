The issue is a `RuntimeError` caused by a mismatch in the state dictionary keys when loading the Stochastic Weight Averaging (SWA) checkpoint during inference. The SWA model was saved using `AveragedModel`, which wraps the original model and prefixes all parameter keys with `module.` (e.g., `module.backbone...`), whereas the standard `DRModel` initialized for inference expects keys without this prefix (e.g., `backbone...`). To fix this, I will modify `library/inference.py` to sanitize the loaded state dictionary by stripping the `module.` prefix and removing the SWA-specific `n_averaged` buffer before loading the weights into the model.
