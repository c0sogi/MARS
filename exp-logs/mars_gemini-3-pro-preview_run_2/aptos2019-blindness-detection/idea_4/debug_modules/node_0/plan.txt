This implementation demonstrates the end-to-end usage of the provided Diabetic Retinopathy classification library.

### Strategy
1.  **Configuration Override**: We modify the global `Config` class to enable `DEBUG` mode, reduce the number of epochs to 1, reduce folds to 2, and switch the model architecture to a lightweight `resnet18` (input size 224x224). This ensures the script runs quickly (under a few minutes) while exercising all code paths. We also redirect outputs to a dedicated `./working/demo_execution` directory.
2.  **Component Verification**:
    *   **Utils**: We validate the `quadratic_weighted_kappa` metric and `MetricMonitor` with known inputs.
    *   **Dataset**: We instantiate `RetinopathyDataset` using the provided metadata to ensure image loading and transformations work correctly, checking tensor shapes.
    *   **Model**: We instantiate `RetinopathyModel` with the `resnet18` backbone and perform a forward pass with dummy data to verify the regression head output.
3.  **Pipeline Execution**:
    *   **Training**: We call `train_models(debug=True)` to simulate the training loop on a small subset of data. We assert that model checkpoints (`.pth` files) are created.
    *   **Inference**: We call `predict_and_submit(debug=True)` to generate predictions using the trained checkpoints. We assert that the `submission.csv` file is created and follows the correct schema.
