# Proposed Baseline Approach: Deep Regression with MobileNetV3

This approach reformulates the problem from a classification task to a **regression task**. Since the diabetic retinopathy levels (0–4) represent an ordinal scale of severity, treating them as continuous values allows the model to learn the inherent ordering and distance between classes. Furthermore, the evaluation metric (Quadratic Weighted Kappa) penalizes errors quadratically, which aligns mathematically with the Mean Squared Error (MSE) loss function used in regression.

### Model
The architecture is designed for maximum efficiency and low latency:
*   **Backbone:** Use **MobileNetV3-Small**, a lightweight Convolutional Neural Network (CNN) optimized for mobile and edge devices. This model uses depthwise separable convolutions and squeeze-and-excitation modules to maintain representational power with significantly fewer parameters than ResNet or EfficientNet models.
*   **Head:** The standard classification head is replaced with a **single neuron** with a linear activation function. This outputs a continuous scalar value representing the predicted severity score.
*   **Initialization:** The backbone is initialized with weights pre-trained on ImageNet to leverage learned feature extractors, while the regression head is initialized randomly.

### Data
Preprocessing is kept minimal to maximize throughput:
*   **Resizing:** All input images are resized to a standard, compact resolution of **224x224 pixels**. This drastically reduces memory usage and computation time compared to high-resolution processing.
*   **Normalization:** Pixel values are normalized using the standard ImageNet mean and standard deviation to align with the pre-trained backbone.
*   **Augmentation:** To prevent overfitting while maintaining speed, only **Random Horizontal Flips** are applied during training. No computationally expensive augmentations (like rotation or color jitter) are used.

### Training
The training process focuses on optimizing the regression objective:
*   **Loss Function:** **Mean Squared Error (MSE)** is used as the loss function. By minimizing the squared difference between the predicted score and the ground truth label, the model directly optimizes a proxy for the Quadratic Weighted Kappa metric.
*   **Optimizer:** The **Adam** optimizer is employed with a standard learning rate (e.g., 1e-4) for fast convergence.
*   **Label Handling:** The integer labels (0, 1, 2, 3, 4) are cast to floating-point numbers to serve as regression targets.

### Evaluation
Predictions are converted back to the required submission format:
*   **Inference:** The model outputs a continuous floating-point score for each image.
*   **Post-processing:**
    1.  **Clipping:** The scores are clipped to the range [0, 4] to handle any outliers.
    2.  **Rounding:** The continuous values are rounded to the nearest integer to produce the final class labels (0, 1, 2, 3, or 4).
*   **Submission:** The resulting integers are mapped to their corresponding `id_code` for the final submission file.
