This script demonstrates the usage of the provided library modules (`config`, `utils`, `data`, `model`, `engine`) to build a complete training and validation pipeline for Diabetic Retinopathy detection.

### Implementation Strategy

1.  **Configuration & Setup**: We import the `Config` class and override specific parameters (like `BACKBONE`, `BATCH_SIZE`, and `PRETRAINED`) to ensure the demo runs quickly using a lightweight model (ResNet18) and random weights, avoiding large downloads or heavy computation.
2.  **Data Loading & Subsampling**: We use `load_metadata` to fetch the dataset information. To speed up the demo, we slice the DataFrames to use only a small subset (e.g., 32 images) for training, validation, and testing.
3.  **Pipeline Verification**:
    *   **Data**: We initialize `RetinopathyDataset` and `DataLoaders`, verifying that batches are loaded with the correct shapes (Images: `[B, 3, H, W]`, Targets: `[B]`).
    *   **Model**: We instantiate `DRModel`, checking that it constructs the backbone and regression head correctly. A dummy forward pass confirms the output shape.
    *   **Metrics**: We unit-test the `quadratic_weighted_kappa` function with known inputs to ensure it correctly handles regression outputs (floats) by rounding them before scoring.
4.  **Execution Loop**:
    *   **Training**: We run `train_one_epoch` for a single epoch on the subset, asserting that the loss decreases or is at least valid (not NaN).
    *   **Validation**: We run `valid_one_epoch` to generate predictions and calculate the QWK score on the validation subset.
    *   **Inference**: We verify the test loader setup and simulate generating a submission file.
