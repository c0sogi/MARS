3.  **Training & Evaluation**:

    -   Train a separate EfficientNet-B5 regression model for each fold.
    -   Aggregate Out-Of-Fold (OOF) predictions to compute a robust validation QWK score.
    -   Perform failure analysis on the full OOF dataset.
4.  **Ensemble Inference**:
    -   If the OOF metric exceeds the threshold, generate test predictions by averaging the **continuous** regression outputs of all 5 models before rounding. This stabilizes the predictions and improves the QWK score (Cite **solution_lesson_node_00012**).

    predictions = []

    with torch.no_grad():

            if len(batch) == 2:

            else:
