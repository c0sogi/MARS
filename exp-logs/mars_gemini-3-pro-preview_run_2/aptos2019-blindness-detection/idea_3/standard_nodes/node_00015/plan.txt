    *   Extract metadata features for validation images (File Size, Aspect Ratio, Width, Height) on-the-fly.
    *   Compute and print the Spearman correlation between the model's error magnitude and these features to identify systematic weaknesses.

5.  **Submission**:
    *   Check if the Final Validation Metric exceeds the strict threshold of `0.9207435978935975`.
    *   If the condition is met, restore `Config.test_csv_path` and call `predict` to generate the final `submission.csv` for the test set.
