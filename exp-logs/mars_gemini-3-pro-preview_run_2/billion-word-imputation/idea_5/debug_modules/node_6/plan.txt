The analysis identified that the `TimeoutError` is caused by an inefficient inference pipeline. Specifically, the "Hypothesis Expansion" stage performs a round-trip to the CPU to convert tensors to text, manipulate strings, and re-tokenize them for the Infiller model. This process creates a bottleneck that prevents the GPU from being fully utilized, leading to a runtime that exceeds the 1-hour limit.

To fix this, I will implement the following changes:
1.  **Update Config:** Change the `INFILLER_MODEL_NAME` from `roberta-large` to `microsoft/deberta-v3-base`. This aligns the Infiller's tokenizer with the Locator's tokenizer, enabling direct tensor manipulation (splicing) without re-tokenization. This also reduces the computational cost of the Infiller model itself.
2.  **Optimize Inference:** Rewrite the `predict` method in `library/inference.py` to perform hypothesis expansion by splicing the `[MASK]` token ID directly into the input tensors. This removes the costly string decoding/encoding loop and allows the pipeline to run efficiently on the GPU.
