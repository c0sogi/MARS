The implementation strategy involves the following steps:

1.  **Setup and Directory Management**: Define the input directory (`./input`) and the output metadata directory (`./metadata`). Ensure the output directory exists.
2.  **Process Test Data**:
    - Read `test_v2.txt` using pandas. This file has a header (`id,"sentence"`), so it can be read directly as a CSV.
    - Add a `file_path` column pointing to `test_v2.txt`.
    - Save the resulting DataFrame to `./metadata/test.parquet`.
3.  **Process Training Data**:
    - Inspect the first line of `train_v2.txt` to determine if it's a CSV or raw text file.
    - Load the data into memory. Given the 220GB RAM availability, loading 30 million sentences (approx. 5-20GB) is feasible.
    - Create a DataFrame with `id` and `sentence` columns.
    - Add a `file_path` column pointing to `train_v2.txt`.
    - **Splitting**: Perform a random 80:20 split to create training and validation sets using `sklearn.model_selection.train_test_split` with a fixed random state (42). This satisfies the requirement for a reproducible split. Since the task is unsupervised/self-supervised (sentence completion) without discrete class labels, random splitting is the appropriate method.
    - Save the split DataFrames to `./metadata/train.parquet` and `./metadata/val.parquet`.
4.  **Verification**:
    - Reload the generated metadata files.
    - Print summary statistics (count, columns).
    - **File Path Check**: Randomly sample 1000 paths from each dataset and verify they exist in `./input`. Raise an error if the missing ratio exceeds 0.5.
    - **Split Verification**: Calculate the ratio of the validation set size to the total training data size. Assert that it is approximately 0.20 (allowing for minor rounding differences).
