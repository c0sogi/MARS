The `InvalidSubmissionError` is caused by the `DEBUG_SAMPLE_SIZE` configuration in `runfile.py` being inadvertently applied to the test dataset in `library/dataset.py`. This results in a truncated test set (200,000 samples instead of the full 302,644), leading to a submission file with missing predictions.

To fix this, I will modify `_load_and_process_data` in `library/dataset.py` to:
1.  Exclude the test set (`mode="test"`) from the debug sampling logic, ensuring the full test set is always processed.
2.  Update the cache filename generation to exclude the debug suffix for the test set. This ensures that the code loads/saves the full test data to a standard filename (e.g., `test_filtered.parquet`) rather than a debug-specific filename (e.g., `test_filtered_debug_200000.parquet`), preventing the loading of previously truncated data.
