Implementation strategy:
1.  **Configuration Override**: Before importing the core logic, I will modify the `Config` class to enable `DEBUG` mode (using 50,000 samples) and set training epochs to 1. This ensures the script fits within the 2-hour execution window.
2.  **Model Training**: I will call `run_training()` from the pipeline module to train both the Gap Locator and In-Filler models on the reduced dataset.
3.  **Validation & Metric**: I will implement a custom validation routine that:
    *   Loads a subset (5,000 samples) of the validation data.
    *   Synthetically removes one word from each sentence to create a ground-truth test case.
    *   Runs the `Predictor` to infer the missing words.
    *   Computes the Levenshtein distance between the predicted and original sentences.
    *   Prints the `Final Validation Metric`.
4.  **Failure Analysis**: I will compute and print the Pearson correlation between the error (Levenshtein distance) and sentence properties (length, missing word position) to diagnose model weaknesses.
5.  **Submission**: I will check if the validation metric is below the threshold (7.8943). If so, I will trigger the `generate_submission` function to process the actual test set and save `submission.csv`.
