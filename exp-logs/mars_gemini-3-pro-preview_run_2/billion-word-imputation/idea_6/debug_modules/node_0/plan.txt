This script demonstrates the end-to-end usage of the provided machine learning library for the sentence completion task. It overrides the default configuration to use a minimal dataset and reduced training epochs, ensuring the demonstration runs quickly (under 5 minutes) while verifying the logic of data processing, model training, and inference.

Strategy:
1.  **Configuration Override**: Monkey-patch the `Config` class to set small sample sizes (50 samples), reduced epochs (1 epoch), and a temporary working directory. This ensures speed and isolation.
2.  **Environment Setup**: Disable `tqdm` progress bars via environment variables to meet the output requirements.
3.  **Data Processing**: Execute `process_data` to generate synthetic training data from the metadata. Verify the resulting DataFrames are not empty.
4.  **Training Loop**: Instantiate the `Trainer` and run training for both the Locator (DeBERTa) and In-Filler (RoBERTa) models. Verify that model checkpoints are successfully saved.
5.  **Inference Pipeline**: Create a small synthetic test set, run the `BeamPipeline` to predict missing words, and generate a submission file. Verify the submission format and content.
