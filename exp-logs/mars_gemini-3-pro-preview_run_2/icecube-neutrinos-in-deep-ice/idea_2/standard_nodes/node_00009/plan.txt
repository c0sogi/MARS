The execution failed with a `pyarrow.lib.ArrowMemoryError` because the `DataLoader` spawned multiple worker processes (`num_workers=4`), each creating its own instance of the `IceCubeDataset` and loading a separate copy of the massive Parquet batch file into memory. This redundant data loading exceeded the available memory (Cite debug_lesson_3). To fix this, I will set `num_workers=0` in `runfile.py` for all `DataLoader` instances. This forces data loading to occur in the main process, allowing the dataset to efficiently reuse a single cached dataframe, thereby eliminating memory amplification.
