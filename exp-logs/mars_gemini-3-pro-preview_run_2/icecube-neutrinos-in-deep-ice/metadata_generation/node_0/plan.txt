The following script generates metadata for the IceCube neutrino direction prediction task.

**Implementation Strategy:**
1.  **Setup**: Define input/output directories and constants (random state, validation split ratio).
2.  **Training Data Processing**:
    -   Load `train_meta.parquet`.
    -   Generate a `batch_file_path` column by constructing relative paths (e.g., `train/batch_{id}.parquet`) from the `batch_id`.
    -   Perform a random 80:20 split to create training and validation sets using `sklearn.train_test_split` with a fixed random seed (42).
    -   Save the resulting dataframes as `train_metadata.parquet` and `val_metadata.parquet` in the `./metadata` directory.
3.  **Test Data Processing**:
    -   Load `test_meta.parquet`.
    -   Generate the `batch_file_path` column (e.g., `test/batch_{id}.parquet`).
    -   Save as `test_metadata.parquet` in the `./metadata` directory.
4.  **Verification**:
    -   Reload the generated metadata files.
    -   Print summary statistics (sample counts, columns).
    -   Verify the validation split ratio is approximately 0.2.
    -   Check for data leakage (ensure no overlap of `event_id` between train and validation).
    -   Perform a file existence check on a random sample of 1000 paths from each dataset to ensure the generated paths point to existing files in `./input`. Raise an error if >50% are missing.
