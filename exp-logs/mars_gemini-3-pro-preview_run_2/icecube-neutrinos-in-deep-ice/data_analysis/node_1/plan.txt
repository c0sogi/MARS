The issue arises because the `event_id` is stored as the index in the parquet files. When `pd.concat` is called with `ignore_index=True`, the index is discarded, resulting in the loss of `event_id` and the subsequent `KeyError`. The fix involves calling `.reset_index()` immediately after reading each parquet file to convert the `event_id` from the index into a regular column, ensuring it persists after concatenation.
