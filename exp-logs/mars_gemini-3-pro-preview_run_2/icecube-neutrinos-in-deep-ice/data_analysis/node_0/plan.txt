This script performs an Exploratory Data Analysis (EDA) on the IceCube Neutrino Direction dataset. It treats the problem as a regression task involving structured event data derived from variable-length pulse sequences.

The analysis proceeds in three main phases:
1.  **Target Analysis**: Examines the distribution of `azimuth` and `zenith` angles from the metadata.
2.  **Input Data Analysis**: Samples specific batch files to analyze the raw pulse data (charge, time, sensor geometry) and aggregates them into event-level features (e.g., total charge, center of gravity) to treat them as tabular data for statistical reporting.
3.  **Feature Relationships**: Investigates correlations between aggregated physical properties and the target angles, and uses a Random Forest regressor to identify top feature importances.
