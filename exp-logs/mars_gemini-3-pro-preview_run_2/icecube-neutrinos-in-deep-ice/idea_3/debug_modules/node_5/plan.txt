The `ArrowMemoryError` is caused by the `IceCubeDataset` class storing every loaded Parquet batch file in the `self.batch_data` dictionary without any limit. When running with `num_workers=12`, each worker process builds its own unbounded cache. As the training iterates over the dataset, the workers collectively load more batch files into RAM than the system can handle (Cite debug_lesson_3). To fix this, I will implement a cache eviction policy in `IceCubeDataset` (in both `library/data_loader.py` and `library/model.py`) to limit the number of cached batches (e.g., to 3) per worker, ensuring memory usage remains bounded.
