Based on the lessons learned, particularly the critical failure of the previous tabular model due to missing second-order moments, I propose a **Dual-Stream Geometric-Temporal Network**. This approach synthesizes the temporal learning strengths of the 1D CNN (Idea 3) with a robust, corrected implementation of the geometric feature engineering (Idea 4).

# Model
The architecture is a hybrid neural network with two distinct input branches designed to capture complementary aspects of the neutrino event:

1.  **Temporal Stream (1D ResNet):**
    *   **Purpose:** To capture the causal evolution of the light wavefront (e.g., the sequence of sensor triggers indicating the particle's path).
    *   **Architecture:** A deep **1D Residual Network (ResNet)**.
    *   **Input:** A tensor of shape $(Batch, Channels, Length)$, representing a time-sorted sequence of pulses. Channels include `[x, y, z, time, charge, auxiliary]`.
    *   **Function:** This backbone extracts local temporal patterns (like $dE/dx$ profiles) that are difficult to capture with global summary statistics.

2.  **Geometric Stream (Global MLP):**
    *   **Purpose:** To explicitly provide the model with the event's global shape and orientation, directly addressing the failure mode identified in **Cite solution_lesson_node_00011**.
    *   **Architecture:** A **Multi-Layer Perceptron (MLP)** with 3-4 dense layers and ReLU activations.
    *   **Input:** A flat vector of engineered features representing the statistical moments of the pulse cloud.
    *   **Key Features:** This input **must** include the flattened **Covariance Matrix** (6 unique components representing variance and covariance in x, y, z) and the **Center of Gravity**. As learned in **Cite solution_lesson_node_00011**, these second-order moments are mandatory for defining the "principal axis" of the event; without them, the model lacks orientation context.

3.  **Fusion Head:**
    *   The latent vectors from the Global Average Pooling of the ResNet and the output of the MLP are concatenated.
    *   A final regression block maps this fused representation to the unnormalized 3D direction vector $(n_x, n_y, n_z)$.

# Data
1.  **Stream 1 Preprocessing (Sequence):**
    *   **Selection:** Select the top $N=192$ pulses per event based on `charge`. This ensures the strongest signals are retained.
    *   **Sorting:** Sort these pulses strictly by `time`.
    *   **Normalization:** Apply Standard Scaling to coordinates and time; apply Log-transformation to charge.

2.  **Stream 2 Preprocessing (Global Features):**
    *   **Aggregation:** Compute features using **all** pulses in the event (not just the selected 192) to ensure the geometric statistics are statistically robust.
    *   **Feature Calculation:**
        *   **First Moment:** Charge-weighted Center of Gravity $(x_{cog}, y_{cog}, z_{cog})$.
        *   **Second Moment:** Charge-weighted Covariance Matrix of pulse positions. Extract the 3 variances ($\sigma_{xx}, \sigma_{yy}, \sigma_{zz}$) and 3 covariances ($\sigma_{xy}, \sigma_{xz}, \sigma_{yz}$). **Cite solution_lesson_node_00011**.
    *   **Validation:** Implement a strict check during data loading to ensure these covariance columns are not all zeros (which would indicate a bug/silent failure).

# Training
*   **Loss Function:** **Cosine Similarity Loss**.
    *   $L = 1 - \frac{\vec{v}_{pred} \cdot \vec{v}_{true}}{||\vec{v}_{pred}|| \cdot ||\vec{v}_{true}||}$
    *   This objective is orientation-invariant and numerically stable for directional regression.
*   **Optimizer:** **AdamW** with a learning rate of 1e-3.
*   **Scheduler:** **Cosine Annealing Warm Restarts** to periodically reset the learning rate, helping the model escape local minima associated with complex loss landscapes.
*   **Strategy:** Train end-to-end. The MLP branch provides a coarse "initial guess" (the principal axis) which the ResNet branch refines using detailed timing information (direction of travel along that axis).

# Evaluation
1.  **Inference:** Iterate through test batches. For each event, generate the time-sorted pulse tensor (Stream 1) and the global geometric feature vector (Stream 2).
2.  **Prediction:** Forward pass through the Dual-Stream model to obtain the raw vector $\vec{v}$.
3.  **Post-Processing:**
    *   Normalize $\vec{v}$ to a unit vector $\hat{u}$.
    *   Convert $\hat{u}$ to spherical coordinates (`azimuth`, `zenith`).
    *   Write to the submission CSV.
