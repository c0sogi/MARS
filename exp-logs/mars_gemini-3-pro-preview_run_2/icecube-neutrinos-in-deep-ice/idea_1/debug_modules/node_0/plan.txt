This script demonstrates the end-to-end usage of the provided IceCube neutrino direction prediction library. It performs the following steps:

1.  **Verification of Utility Functions**: Validates the coordinate conversion logic (spherical to Cartesian and back) and the angular distance metric.
2.  **Dataset Instantiation**: Loads a small subset of the training metadata (specifically from Batch 1 to ensure file existence) and creates an `IceCubeDataset` instance. It verifies data shapes, types, and feature normalization.
3.  **Model Initialization**: Instantiates the `NeutrinoBiGRU` model and performs a forward pass with a dummy batch to verify input/output dimensions.
4.  **Loss Function Check**: Computes the `CosineDistanceLoss` on the dummy output to ensure the loss calculation is functioning correctly.
5.  **Training Loop Execution**: Runs a short training session (2 epochs) using the `engine` module on the subset of data. This demonstrates the integration of the data loader, model, optimizer, and training logic.
6.  **Inference Demonstration**: Simulates an inference step using the trained model, converting the predicted direction vectors back to azimuth and zenith angles.
