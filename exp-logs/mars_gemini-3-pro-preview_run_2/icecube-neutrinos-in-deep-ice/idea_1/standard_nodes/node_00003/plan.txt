The `ArrowMemoryError` occurred because the memory budget calculation failed to account for the decompression expansion of Parquet files when loaded into RAM (Cite debug_lesson_1). The original `cache_limit=40` resulted in a memory footprint exceeding the available 220GB when multiplied across 4 worker processes. I will reduce the `cache_limit` to 5 in `runfile.py` for training, validation, and testing datasets, which keeps the estimated memory usage around 30GB, safely within the system limits.
