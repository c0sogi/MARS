The `ArrowMemoryError` was caused by excessive memory usage due to the multiplication of cached data across multiple `DataLoader` worker processes (Cite debug_lesson_3). With `cache_limit=5` and 4 workers, the system attempted to hold up to 20 large DataFrames in RAM. Additionally, the cache eviction logic in `IceCubeDataset` loaded the new file *before* removing the old one, causing a temporary memory spike (Cite debug_lesson_1) that triggered the OOM error.

To fix this:
1.  I will modify `library/dataset.py` to evict old files from the cache **before** loading a new one, preventing memory spikes.
2.  I will update `runfile.py` to set `cache_limit=1`. Since the data is sorted by batch, workers only need the current file in memory. This reduces the memory footprint from ~30GB to ~6GB.
