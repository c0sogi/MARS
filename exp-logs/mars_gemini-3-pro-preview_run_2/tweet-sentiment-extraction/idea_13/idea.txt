Based on the analysis of the provided lessons and the identification of the primary bottleneck—**label ambiguity and noise** in the manual annotations—I propose the following optimized strategy. This solution introduces a **Two-Stage Self-Distillation Pipeline** to structurally refine the supervision signal, replacing the standard "Single Stage" training paradigm.

# Model
*   **Backbone Architecture:** Utilize **`microsoft/deberta-v3-large`** as the encoder.
    *   **Retention:** This backbone is retained for its **Disentangled Attention** mechanism (superior for relative positioning `Cite solution_lesson_node_00019`) and **Model Capacity** (proven necessary for semantic nuance `Cite solution_lesson_node_00013`).
*   **Prediction Head:** Employ a **Simple Linear Head** (single projection to Start/End logits) for both the Teacher and Student stages.
    *   **Retention:** We explicitly reject complex heads (CNNs, Pooling) as they introduce optimization difficulties without performance gains `Cite solution_lesson_node_00031`.
*   **Input Representation:** Format the input as `[CLS] <Sentiment> [SEP] <Tweet Text> [SEP]` to condition the text representation on the sentiment token `Cite solution_lesson_node_00009`.

# Data
*   **Alignment-Preserving Tokenization:** Perform tokenization strictly on the **raw, un-normalized text**. Generate and store **offset mappings** that link every token back to its exact character start and end positions.
    *   **Retention:** This prevents the misalignment issues caused by string normalization `Cite solution_lesson_node_00017`.
*   **Stratification:** Implement a **5-Fold Stratified Cross-Validation** scheme, stratifying by `sentiment` to maintain class distribution `Cite solution_lesson_node_00014`.
*   **Dynamic Padding:** Sort training data by length and batch similarly sized samples to maximize throughput `Cite solution_lesson_node_00023`.

# Training
This strategy implements a **Two-Stage Self-Distillation** process to address label noise:

**Stage 1: Teacher Training**
*   **Objective:** Train a robust baseline ensemble to generate "Soft Labels."
*   **Loss Function:** Use **Cross Entropy with Label Smoothing** ($\epsilon=0.1$). This stabilizes the initial training by penalizing overconfidence in noisy boundaries `Cite solution_lesson_node_00012`.
*   **Optimization:** Train 5 independent fold models using **Mixed Precision (AMP)** `Cite solution_lesson_node_00023` and a **Uniform Learning Rate** (e.g., 1e-5) to avoid schedule-induced instability `Cite solution_lesson_node_00020`.

**Intermediate Step: Soft Label Generation**
*   Generate **Out-Of-Fold (OOF) Predictions** for the entire training dataset using the Stage 1 models. For each sample, store the probability distributions (logits) for the start and end positions predicted by the model trained on the *other* folds. These "Soft Labels" capture the ensemble's learned semantic uncertainty, effectively smoothing out annotator noise.

**Stage 2: Student Training**
*   **Objective:** Train a new set of 5 fold models (same architecture) that learn from both the ground truth and the Teacher's knowledge.
*   **Structural Innovation (Distillation Loss):** Minimize a combined loss function:
    $$L = \alpha \cdot L_{CE}(y_{true}, y_{pred}) + (1-\alpha) \cdot L_{KL}(y_{teacher}, y_{pred})$$
    where $L_{CE}$ is Cross Entropy with the noisy manual labels, and $L_{KL}$ is the Kullback-Leibler Divergence against the Teacher's OOF soft labels. This allows the model to learn sharp boundaries where the data is clear, but defer to the smoothed ensemble consensus where the manual labels are ambiguous.
*   **Optimization:** Use the same efficient protocol (AMP, Uniform LR) as Stage 1.

# Evaluation
*   **Ensemble Inference:** For every test sample, generate start and end logit vectors from all **5 Student Models** (Stage 2). **Sum these logits** to create a single, robust probability distribution.
    *   **Retention:** This leverages variance reduction to bridge the OOF-Ensemble gap `Cite solution_lesson_node_00014`.
*   **Decoding:** Select the indices `(start, end)` that maximize the sum of the averaged log-probabilities (subject to `start <= end`).
*   **Reconstruction:** Use the stored **offset mappings** to extract the substring from the raw text `Cite solution_lesson_node_00017`.
*   **Neutral Heuristic:** Deterministically predict the **entire text** if the sentiment is "neutral" `Cite solution_lesson_node_00001`.
