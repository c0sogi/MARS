The implementation strategy is as follows:

1.  **Configuration & Setup**: Import the provided library modules. Override specific configuration parameters (e.g., `NUM_EPOCHS`, `BATCH_SIZE`) to ensure the solution runs quickly as a baseline on the powerful A100 GPU provided.
2.  **Data Loading**: Use `get_loaders` with `load_cached_data=True` to efficiently load the training, validation, and test datasets along with the vocabulary.
3.  **Model Initialization**: Instantiate the `BiGRUPointerNetwork` and the Adam optimizer, moving the model to the appropriate device (GPU).
4.  **Training Loop**: Implement a concise training loop that iterates for a limited number of epochs. Inside the loop, perform training steps and validation evaluation. Implement logic to save the model state whenever the validation Jaccard score improves.
5.  **Final Validation**: Load the best-saved model state. Run a full evaluation on the validation set to compute the global Jaccard score and print it in the strictly required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Perform a granular inference pass on the validation set to calculate per-sample Jaccard scores. Compute the "Error" (1 - Jaccard) and analyze its correlation with input features (text length and sentiment) to identify systematic weaknesses.
7.  **Submission**: Execute the inference pipeline on the test set using the best model and generate the `submission.csv` file.
