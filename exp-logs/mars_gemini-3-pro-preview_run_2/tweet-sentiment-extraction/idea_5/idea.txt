Based on the comprehensive analysis of the previous ideas and the specific failure modes identified in the lessons, I propose the following optimized strategy. This solution evolves the architecture to the largest feasible DeBERTa variant while implementing a rigorous "Alignment-Preserving" data pipeline and regularization scheme to mitigate the overfitting and preprocessing errors observed in prior attempts.

### Model
- **Backbone Architecture:** Adopt **`microsoft/deberta-v3-large`** as the encoder. This choice synthesizes the requirement for **Model Capacity**—proven necessary to capture nuanced sentiment semantics `Cite solution_lesson_node_00013`—with the **Disentangled Attention** mechanism of DeBERTa, which is structurally superior for modeling relative token positions in span extraction tasks.
- **Span Prediction Head:** Utilize the **Pointer Network** formulation `Cite solution_lesson_node_00001`. The model will output two vectors of logits (unnormalized probabilities) corresponding to the sequence length: one for the `start` index and one for the `end` index of the selected text.
- **Input Representation:** Format the input sequence as `[CLS] <Sentiment> [SEP] <Tweet Text> [SEP]`. By treating the sentiment label as a special token within the sequence, the model utilizes its self-attention layers to dynamically condition the text representation on the target sentiment `Cite solution_lesson_node_00009`.

### Data
- **Alignment-Preserving Tokenization:** Perform tokenization strictly on the **raw, un-normalized text**. Do not apply any string cleaning (e.g., whitespace stripping or normalization) prior to tokenization. This ensures that the tokenizer's generated **offset mappings** perfectly align with the original character indices, preventing the misalignment issues that caused performance degradation in previous high-capacity attempts `Cite solution_lesson_node_00017`.
- **Stratification:** Implement a **5-Fold Stratified Cross-Validation** scheme. Split the training data into 5 folds, stratifying by the `sentiment` label to ensure consistent class distribution across all models `Cite solution_lesson_node_00014`.

### Training
- **Loss Function:** Implement **Cross Entropy with Label Smoothing** ($\epsilon=0.1$) for both the start and end targets. This is a critical structural addition to stabilize the "Large" model; it penalizes overconfidence in the noisy/subjective boundaries of the training data, preventing the overfitting dynamics observed when scaling up model size `Cite solution_lesson_node_00012`.
- **Optimization:** Train 5 independent models (one per fold) using the AdamW optimizer. Implement a **linear learning rate decay** schedule with a warmup phase to preserve the pre-trained knowledge of the backbone.
- **Regularization:** Apply dropout within the transformer layers and the prediction head to further improve generalization.

### Evaluation
- **Ensemble Inference:** For every test sample, generate start and end logit vectors from all 5 trained models. **Sum these logits** to create a single, robust probability distribution. This leverages the variance reduction of the ensemble to bridge the gap between validation metrics and test performance `Cite solution_lesson_node_00014`.
- **Decoding & Reconstruction:** Select the indices `(start, end)` that maximize the sum of the averaged log-probabilities (subject to `start <= end`). Use the **offset mappings** derived from the raw-text tokenization to extract the exact substring from the original tweet `Cite solution_lesson_node_00017`.
- **Neutral Heuristic:** Apply a deterministic override: if the sentiment is "neutral", predict the **entire text** of the tweet. This exploits the strong correlation found in the data analysis (Neutral Jaccard $\approx$ 0.98) to eliminate error for a large portion of the dataset.
