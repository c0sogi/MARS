1.  **Setup and Configuration**: Initialize the environment, set random seeds for reproducibility, and override default `Config` parameters (specifically `EPOCHS` and `TRAIN_BATCH_SIZE`) to ensure the training completes efficiently within the 2-hour limit using the A100 GPU.
2.  **Data Loading**: Utilize the provided `get_data` function to load preprocessed and cached training and testing datasets.
3.  **Stratified Cross-Validation**: Implement a 5-fold cross-validation loop. For each fold:
    - Initialize the `TweetModel` (DeBERTa-v3-large).
    - Train the model using a custom loop incorporating `torch.cuda.amp` (Automatic Mixed Precision) for optimized performance.
    - Evaluate on the validation fold and save the model checkpoint with the best Jaccard score.
    - Store Out-Of-Fold (OOF) predictions to compute the global validation metric.
4.  **Validation & Failure Analysis**: Calculate the overall Jaccard score across all folds. Perform failure analysis by correlating the error (1 - Jaccard) with input text length and analyzing performance by sentiment class.
5.  **Ensemble Inference**: If the validation metric exceeds the specified threshold (0.709+), perform inference on the test set. Accumulate logits from all 5 trained models (ensemble), decode the spans, apply the "Neutral Heuristic" (predict full text for neutral sentiment), and generate the final `submission.csv`.
