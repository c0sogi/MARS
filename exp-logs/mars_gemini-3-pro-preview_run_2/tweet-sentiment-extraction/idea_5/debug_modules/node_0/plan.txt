This script demonstrates the end-to-end usage of the provided library components for the Tweet Sentiment Extraction task. It performs the following steps:

1.  **Configuration Override**: Modifies the `Config` class to run in `DEBUG` mode with a small sample size and reduced epochs/folds to ensure the demonstration completes quickly (within minutes).
2.  **Data Loading**: Uses `get_data` to preprocess the raw CSVs into tokenized arrays suitable for the model, bypassing cache to ensure the debug settings are applied.
3.  **Dataset & DataLoader Verification**: Instantiates `TweetDataset`, retrieves a single batch, and asserts that the input tensors (IDs, masks) and target tensors (start/end indices) have the correct shapes and data types.
4.  **Model Initialization & Forward Pass**: Loads the `TweetModel` (DeBERTa-v3-large backbone), moves it to the GPU, and performs a forward pass with the sample batch. It validates that the output logits correspond to the input sequence length.
5.  **Training & Evaluation Loop**: Sets up an optimizer and scheduler, then runs `train_fn` and `eval_fn` for one epoch on a single fold. It asserts that the loss is a valid float and the Jaccard score is within the expected range [0, 1].
6.  **Inference**: Uses `infer_fn` on the test dataset to generate predictions and verifies the output format.
