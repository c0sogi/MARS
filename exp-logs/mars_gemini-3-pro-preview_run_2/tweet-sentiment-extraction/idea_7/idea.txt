Based on the analysis of the previous ideas and the empirical lessons learned, I propose the following optimized strategy. This solution structurally evolves the approach by integrating a **Hybrid Objective Function** and **Internal Ensembling** within the model architecture, while strictly adhering to the efficiency protocols required to train on the full dataset.

### Model
- **Backbone Architecture:** Utilize **`microsoft/deberta-v3-large`** as the encoder. This choice is non-negotiable as it provides the **Disentangled Attention** mechanism necessary for precise relative positioning in span tasks `Cite solution_lesson_node_00019` and the **Model Capacity** required to capture nuanced sentiment semantics `Cite solution_lesson_node_00013`.
- **Structural Innovation (Internal Ensembling):** Replace the standard linear prediction head with a **Multi-Sample Dropout (MSD)** head. The output of the transformer will be fed into multiple parallel dropout masks followed by shared linear layers. This technique acts as an "internal ensemble" during training, significantly improving generalization and convergence speed by forcing the model to rely on diverse feature subsets, effectively mitigating the overfitting risks associated with large models.
- **Input Representation:** Format the input sequence as `[CLS] <Sentiment> [SEP] <Tweet Text> [SEP]`. This allows the model to dynamically condition the text representation on the sentiment token via self-attention `Cite solution_lesson_node_00009`.

### Data
- **Alignment-Preserving Tokenization:** Perform tokenization strictly on the **raw, un-normalized text**. Generate and store **offset mappings** that link every token back to its exact character start and end positions. This is critical to prevent the misalignment issues observed when normalizing text `Cite solution_lesson_node_00017`.
- **Stratification:** Implement a **5-Fold Stratified Cross-Validation** scheme, ensuring the class distribution is preserved across all folds `Cite solution_lesson_node_00014`.

### Training
- **Objective Function (Metric Alignment):** Implement a **Hybrid Loss Function** combining **Cross Entropy with Label Smoothing** and **Soft Jaccard Loss**.
    - **Cross Entropy with Label Smoothing ($\epsilon=0.1$):** Stabilizes training by penalizing overconfidence in the noisy/subjective boundaries of the training data `Cite solution_lesson_node_00012`.
    - **Soft Jaccard Loss:** A differentiable approximation of the Jaccard metric. By adding this component, the optimization landscape is explicitly aligned with the competition metric, encouraging the model to maximize span overlap rather than just matching indices.
- **Efficiency Protocol:** Mandate the use of **Mixed Precision (AMP)** training. This is the critical enabler that allows the computationally heavier "Large" backbone, MSD head, and Hybrid Loss to be trained on the **Full Dataset** within the time limits. We explicitly reject subsampling data to fit the model `Cite solution_lesson_node_00023`.
- **Optimization:** Use the **AdamW** optimizer with a **Uniform Learning Rate** (e.g., 1e-5). Avoid complex layer-wise decay schedules that have proven unstable for this specific fine-tuning task `Cite solution_lesson_node_00020`.

### Evaluation
- **Ensemble Inference:** For every test sample, generate start and end logit vectors from all 5 trained fold models. **Sum these logits** to create a single, robust probability distribution. This leverages variance reduction to bridge the gap between validation and test performance `Cite solution_lesson_node_00014`.
- **Decoding & Reconstruction:** Select the indices `(start, end)` that maximize the sum of the averaged log-probabilities (subject to `start <= end`). Use the **offset mappings** derived from the raw-text tokenization to extract the exact substring from the original tweet `Cite solution_lesson_node_00017`.
- **Neutral Heuristic:** Apply a deterministic override: if the sentiment is "neutral", predict the **entire text** of the tweet.
