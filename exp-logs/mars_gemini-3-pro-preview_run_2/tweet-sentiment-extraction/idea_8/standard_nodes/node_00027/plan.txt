Strategy Outline:
1.  **Setup & Data Loading**: Initialize the environment and seed for reproducibility. Load the metadata CSVs (`train.csv`, `val.csv`) and concatenate them to form a complete dataset for Cross-Validation. Load the test set.
2.  **Preprocessing**: Use the `process_data` function to tokenize the text and generate input arrays (IDs, masks, offsets) for both the full training set and the test set.
3.  **5-Fold Cross-Validation**: Implement a Stratified K-Fold loop. For each fold:
    *   Split the data into training and validation sets.
    *   Create `TweetDataset` and `DataLoader` objects, utilizing `SmartBatchSampler` and `SmartBatchingCollate` to optimize training speed by grouping samples of similar lengths.
    *   Initialize the `TweetModel` (DeBERTa-v3-Large with Weighted Layer Pooling) and the optimizer/scheduler.
    *   Train for the specified epochs, evaluating on the validation set after each epoch. Save the model with the best Jaccard score.
    *   Generate Out-Of-Fold (OOF) predictions for the validation set to enable global failure analysis.
4.  **Validation & Analysis**:
    *   Aggregate OOF predictions and compute the global Jaccard score.
    *   Print the `Final Validation Metric`.
    *   Perform failure analysis by correlating the error magnitude (1 - Jaccard) with input word length and analyzing performance by sentiment class.
5.  **Inference & Submission**:
    *   If the validation metric exceeds the threshold (0.7205), proceed to inference.
    *   Load the best model from each fold.
    *   Perform ensemble inference on the test set: sum the logits from all 5 models.
    *   Decode the aggregated logits into text spans, applying the heuristic to predict the full text for "neutral" tweets.
    *   Save the predictions to `submission.csv` with the required formatting.
