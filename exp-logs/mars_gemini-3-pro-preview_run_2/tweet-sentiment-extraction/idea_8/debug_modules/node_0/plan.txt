The following implementation demonstrates how to utilize the provided library files to train a Tweet Sentiment Extraction model, evaluate it, and generate predictions for a submission file.

**Strategy:**
1.  **Configuration Override**: We modify the static `Config` class attributes to enable `DEBUG` mode (using a tiny subset of data) and reduce epochs/batch sizes. This ensures the script runs quickly (within minutes) while exercising all code paths.
2.  **Data Pipeline**: We utilize `get_loaders` to generate PyTorch DataLoaders. We verify the "Smart Batching" logic by inspecting tensor shapes.
3.  **Model & Training**: We instantiate the `TweetModel` (DeBERTa-v3-large based) and run a single epoch of training using `train_fn`.
4.  **Validation**: We use `eval_fn` to calculate the Jaccard score on the validation set.
5.  **Inference**: Since `eval_fn` requires ground truth labels, we implement a custom inference loop for the test set that mirrors the decoding logic (handling the neutral heuristic and logit processing) to generate the final `selected_text` strings.
6.  **Submission**: We format the predictions into a CSV file matching the competition requirements.
