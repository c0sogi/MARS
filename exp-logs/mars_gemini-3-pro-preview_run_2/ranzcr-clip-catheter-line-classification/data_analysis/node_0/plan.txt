Here is the implementation strategy and the complete Python script for the Exploratory Data Analysis.

### Implementation Strategy

1.  **Setup and Configuration**: Initialize random seeds for reproducibility and define paths. Load the training metadata from `./metadata/train.csv`.
2.  **Target Variable Analysis**:
    *   Identify the 11 target columns (catheter/line labels).
    *   Calculate the prevalence (mean) and count of positive samples for each label to assess class imbalance.
    *   Analyze label co-occurrence (e.g., how many images have multiple catheters).
3.  **Image Data Analysis**:
    *   Since processing 21,700 images is computationally expensive, perform analysis on a stratified sample (e.g., 2,000 images) to ensure execution within the time limit.
    *   Load images using OpenCV to extract dimensions (Width, Height), Aspect Ratios, and Channel counts.
    *   Calculate global pixel mean and standard deviation to inform normalization strategies.
4.  **Feature/Signal Relationships**:
    *   **Target-Target**: Compute a correlation matrix between labels to identify physiological or annotator-driven dependencies (e.g., CVC Normal vs. CVC Abnormal).
    *   **Meta-Feature vs. Target**: Correlate image metadata (width, height, aspect ratio, mean intensity) with target labels to check if specific image properties bias the predictions (e.g., "Incompletely Imaged" labels correlating with image dimensions).
5.  **Output Generation**: Format the findings into clear, capitalized sections with 4-decimal precision as requested.
