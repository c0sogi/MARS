This script demonstrates the usage of the provided library modules for the catheter detection task. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters to run in a lightweight "demo" mode (fewer epochs, disabled pretraining, specific output directories) to ensure speed and isolation.
2.  **Dataset Verification**: Instantiates the `CatheterDataset` with the training metadata, verifies the transformation pipeline, and asserts the correct shape of input images and target labels.
3.  **Model Initialization & Forward Pass**: Initializes the `CatheterModel` (EfficientNetV2-S backbone), moves it to the GPU, and performs a forward pass with a dummy batch to verify output dimensions (logits).
4.  **Training Loop Demonstration**: Sets up the optimizer, scheduler, and loss function, then executes `train_one_epoch` on a small subset of data to verify the training logic.
5.  **Validation Loop Demonstration**: Executes `valid_one_epoch` to ensure loss calculation and metric evaluation (AUC) function correctly.
6.  **Metric Calculation**: Directly tests the `get_score` utility function with synthetic data to verify it handles edge cases (e.g., single-class targets) robustly.
7.  **Inference & Submission**: Saves the trained model state, generates a temporary test metadata subset, and runs the `predict` function to generate a submission file, verifying the output format.
