Implementation strategy:
1.  **Setup & Initialization**: Initialize the environment, set random seeds for reproducibility, and configure the computing device (GPU).
2.  **Data Loading**: Instantiate the `CatheterDataset` and `DataLoader` for both training and validation sets using the paths defined in the `Config` class. The validation loader will be used for both monitoring training progress and final failure analysis.
3.  **Model Configuration**: Initialize the `CatheterModel` (ConvNeXt-Tiny based) and move it to the GPU. Set up the `AdamW` optimizer and `OneCycleLR` scheduler with parameters from the configuration.
4.  **Training Loop**: Execute the training process using the provided `train_model` function. This function handles the training epochs, validation evaluation, and saves the model with the best AUC score.
5.  **Final Evaluation**: Load the best saved model state. Perform a full inference pass on the validation set to calculate the final validation metric and extract predictions for analysis.
6.  **Failure Analysis**: iterate through the validation set metadata to extract original image properties (width, height, intensity). Calculate the correlation between the model's prediction error (MAE) and these input features to identify potential failure modes.
7.  **Submission**: Compare the final validation metric against the specified threshold (0.9398...). If the model performs sufficiently well, generate predictions for the test set using `generate_submission` and save the result to `submission.csv`.
