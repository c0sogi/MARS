To address the `torch.OutOfMemoryError` caused by the high memory footprint of the ConvNeXt-Small model with 640x640 images and a batch size of 32, I will implement the following fixes based on **debug_lesson_1**:

1.  **Reduce Batch Size**: In `library/config.py`, I will decrease the `batch_size` from 32 to 8. This significantly lowers the memory required for intermediate activations.
2.  **Implement Automatic Mixed Precision (AMP)**: In `library/train.py`, I will integrate `torch.cuda.amp`. This involves:
    *   Initializing a `GradScaler` in `run_training`.
    *   Wrapping the forward pass in `train_one_epoch` (and validation) with `torch.cuda.amp.autocast`.
    *   Using the scaler to handle backward passes and optimizer steps.

These changes reduce memory usage by storing activations in half-precision and processing fewer samples concurrently, ensuring the model fits within the 16GB VRAM limit.

    model, optimizer, scheduler, dataloader, device, epoch, scaler, ema_model=None
):
    """
    Trains the model for one epoch.
    """
    model.train()

    dataset_size = 0
    running_loss = 0.0

    criterion = nn.BCEWithLogitsLoss()

    for batch_idx, (images, labels) in enumerate(dataloader):
        images = images.to(device, dtype=torch.float)
        labels = labels.to(device, dtype=torch.float)

        batch_size = images.size(0)

        optimizer.zero_grad()

        # Forward pass with AMP (Cite debug_lesson_1)
        with torch.cuda.amp.autocast(enabled=True):
            logits = model(images)
            loss = criterion(logits, labels)

        # Backward pass with Scaler
        scaler.scale(loss).backward()

        # Gradient clipping (unscale first)
        scaler.unscale_(optimizer)
        torch.nn.utils.clip_grad_norm_(model.parameters(), Config.max_grad_norm)

        scaler.step(optimizer)
        scaler.update()

        if scheduler is not None:
            scheduler.step()

        # Update EMA
        if ema_model is not None:
            ema_model.update(model)

        running_loss += loss.item() * batch_size
        dataset_size += batch_size

    epoch_loss = running_loss / dataset_size
    return epoch_loss
