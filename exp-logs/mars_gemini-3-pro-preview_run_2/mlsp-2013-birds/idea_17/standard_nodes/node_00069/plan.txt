Implementation Strategy:
1.  **Setup & Configuration**: Import necessary modules from the provided library. Override `config.EPOCHS` to 10 to ensure the pipeline completes quickly within the time limit while maintaining sufficient convergence for the small dataset.
2.  **Stage 1 (Teacher Generation)**: Iterate through 5 folds and 3 model architectures (ResNet18, EfficientNet-B0, DenseNet121). Train each model using standard Hard Labels. After training each fold, generate Out-Of-Fold (OOF) predictions on the validation split of that fold using Test-Time Augmentation (TTA). Accumulate these OOF predictions.
3.  **Soft Label Aggregation**: Average the accumulated OOF predictions from all 3 models for each recording ID. These averaged probabilities serve as the "Soft Labels" (Distillation Targets) for the next stage.
4.  **Stage 2 (Student Distillation)**: Re-initialize the heterogeneous ensemble. Train the models again on the 5 folds, but this time use the `DistillationLoss` which combines the ground truth Hard Labels with the generated Soft Labels. This transfers the "dark knowledge" (class ambiguity) to the students.
5.  **Evaluation**: Load the fixed hold-out validation set (`metadata/val.csv`). Perform inference using all 15 trained Stage 2 models (5 folds * 3 architectures) with TTA. Average the predictions. Compute the Macro-Averaged AUC score.
6.  **Failure Analysis**: Calculate the Mean Absolute Error (MAE) for each validation sample. Compute pixel statistics (mean, std) for the validation spectrograms. Calculate and print the Pearson correlation between the error magnitude and these image statistics to identify failure modes.
7.  **Submission**: If the validation AUC exceeds the specified threshold, generate predictions for the test set (`metadata/test.csv`) using the full ensemble. Format the output according to the `Id,Probability` requirement (mapping `rec_id` and `species` to `Id`) and save to `submission.csv`.
