Implementation Strategy:
1.  **Environment Setup**: Initialize the configuration, set random seeds, and prepare the working directory.
2.  **Data Loading & Processing**: Load the training metadata, select a small subset for rapid execution, calculate class weights, and instantiate the `BirdDataset` and `DataLoader` with appropriate transforms.
3.  **Model Instantiation**: Create a `BirdModel` (using ResNet18 with `pretrained=False` to avoid network dependencies) and move it to the appropriate device (CPU/GPU).
4.  **Training & Validation**: Execute a single training epoch and a validation pass using the `BornAgainLoss` function and the `engine` module, verifying that losses are finite and metrics are computed.
5.  **Inference & Utilities**: Generate predictions, demonstrate saving/loading of Out-Of-Fold (OOF) predictions using utility functions, and verify data consistency.
6.  **Distillation Workflow**: Re-initialize the dataset with the generated soft labels (OOF predictions) and run a distillation training step to verify the soft-target loss mechanism.
