This script demonstrates the end-to-end usage of the provided machine learning library for bird species classification. It covers data loading, image preprocessing, dataset creation, model instantiation, loss calculation, training loop execution, and inference.

The strategy involves:
1.  **Configuration**: initializing the environment and setting random seeds for reproducibility.
2.  **Data Preparation**: Loading a small subset of the training metadata and processing the corresponding spectrogram images using the `load_images` utility.
3.  **Dataset & DataLoader**: Creating PyTorch datasets with Albumentations transforms and wrapping them in DataLoaders.
4.  **Model Setup**: Instantiating the `BirdClassifier` with a ResNet18 backbone and verifying the output shape of the custom Multi-Sample Dropout head.
5.  **Loss Function**: Calculating class imbalance weights and initializing the `WeightedDistillationLoss`.
6.  **Training**: Running a single epoch of training using the `Engine` class to demonstrate the Mixup augmentation and backpropagation flow.
7.  **Inference**: Generating predictions on the validation set and verifying the output dimensions.
