The `ValueError` indicates that the `IterativeStratification` class (which inherits from scikit-learn's cross-validation splitters) requires `shuffle=True` when a `random_state` is provided. This is a validation check enforced by scikit-learn to ensure that the random seed actually influences the data splitting. To fix this, I will add `shuffle=True` to the `IterativeStratification` constructor call in `library/data.py`. This resolves the conflict where a seed was set for reproducibility without enabling the shuffling mechanism that uses it (Cite debug_lesson_2).
