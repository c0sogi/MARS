The issue is caused by Python's scoping rules for list comprehensions defined within a class body. While the iterable part of the comprehension (`for c in _class_counts`) can access class-level variables, the expression part (`(_total_samples - c) / c`) runs in a separate scope that cannot see names defined in the class body, leading to a `NameError`. To fix this, I will replace the variable `_total_samples` with its literal value `206` inside the list comprehension in `library/config.py`.
