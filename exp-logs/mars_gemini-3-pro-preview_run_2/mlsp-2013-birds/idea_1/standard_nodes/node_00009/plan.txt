The `BirdModel` class in `library/model.py` is implemented using `XGBClassifier` and explicitly references `Config.XGB_PARAMS`, but `library/config.py` currently defines `RF_PARAMS` containing Random Forest-specific hyperparameters. This configuration-implementation mismatch causes an `AttributeError` (Cite {debug_lesson_3}).
