The `IterativeStratification` class from `scikit-multilearn` does not support the `shuffle` parameter (it defaults to `False`) and consequently raises a `ValueError` if `random_state` is provided (Cite `debug_lesson_2`). To fix this while maintaining the intended randomization, I will manually shuffle the data arrays (`df_dev`, `images_dev`, `labels_dev`) using `sklearn.utils.shuffle` before creating the folds, and remove the `random_state` argument from the `IterativeStratification` constructor. I will also reset the DataFrame index after shuffling to ensure correct indexing during fold assignment.
