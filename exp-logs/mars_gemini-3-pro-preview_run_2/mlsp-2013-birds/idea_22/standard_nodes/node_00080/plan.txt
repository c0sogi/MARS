The issue is a **Semantic Mismatch** between the generic instantiation logic in `BirdModel` and the specific interface of the `DenseNet` class in the `timm` library. The `BirdModel` class unconditionally passes `drop_path_rate` (Stochastic Depth rate) to all backbones, but `densenet121` does not support this argument in its constructor, leading to a `TypeError`.

To fix this, I will modify `library/models.py` to conditionally pass `drop_path_rate` only to models that are not DenseNet variants. This aligns the implementation with the configuration schema and class interfaces (Cite debug_lesson_3).
