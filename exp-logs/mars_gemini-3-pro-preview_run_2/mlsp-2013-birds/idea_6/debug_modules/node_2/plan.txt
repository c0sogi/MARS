The `AssertionError` in `runfile.py` is caused by `val_auc` evaluating to `nan` during the debug run. This occurs because `sklearn.metrics.roc_auc_score` (with `average='macro'`) returns `nan` instead of raising an exception when the input data lacks sufficient class diversity (e.g., constant labels in a small batch), causing the existing `try...except ValueError` fallback mechanism to be bypassed. To fix this, I will modify `calculate_roc_auc` in `library/utils.py` to explicitly check if the computed score is `nan` and raise a `ValueError` if so. This ensures the code triggers the robust column-wise fallback calculation, effectively sanitizing the metric (Cite debug_lesson_3).
