This script implements the Heterogeneous Ensemble with SAM and Cyclic TTA strategy. It trains three distinct backbones (ResNet18, EfficientNet-B0, DenseNet121) on the provided training data, using Sharpness-Aware Minimization (SAM) to stabilize optimization. It then evaluates the ensemble on the hold-out validation set, performs the required failure analysis by correlating prediction errors with input signal intensity, and generates a submission for the test set using Cyclic Test-Time Augmentation if the performance threshold is met.
