This script demonstrates the end-to-end usage of the provided library components for the bird species classification task. It first overrides the default configuration to enable a fast "demo mode" suitable for quick execution and debugging. It then verifies the data loading pipeline by inspecting batch shapes and content from the `BirdDataset` and `DataLoader`. Next, it instantiates a `BirdClassifier` with a ResNet18 backbone, performs a forward pass to validate model architecture, and checks the custom ROC AUC metric calculation. The script proceeds to run a short training session using the `train_fold` function, ensuring the training loop and optimization steps function correctly. Finally, it demonstrates the inference process by loading the trained model, generating predictions on the test set, and formatting the results into a submission file.
