Implementation Strategy:
1.  **Setup & Configuration**: Define hyperparameters (Learning Rate 1e-3, Weight Decay 1e-4, Batch Size 32, Epochs 15) and select the three architectures (`resnet18`, `efficientnet_b0`, `densenet121`). Set random seeds for reproducibility.
2.  **Training Phase**:
    *   Load training and validation metadata from `./metadata/train.csv` and `./metadata/val.csv`.
    *   Iterate through each architecture.
    *   Construct DataLoaders using `library.dataset.get_loader`, ensuring correct image resolutions and caching.
    *   Initialize the `BirdModel` (with Multi-Sample Dropout) and `AdamW` optimizer.
    *   Train using `library.trainer.train_model` which handles Mixup and Early Stopping.
    *   Save the trained models as `model_{arch}_fold_0.pth` in `./working/idea_16/` to mimic the first fold of a K-Fold ensemble.
3.  **Validation & Ensemble Evaluation**:
    *   Implement an evaluation routine that applies Test-Time Augmentation (TTA) (shifts: 0%, 25%, 50%, 75%) to the validation set, mirroring the inference strategy.
    *   Aggregate predictions across all 3 architectures and TTA variations.
    *   Compute the final AUC score using `library.utils.calculate_metrics`.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the Mean Absolute Error (MAE) per validation sample.
    *   Compute simple metadata features (pixel mean, pixel std) for validation images.
    *   Calculate and print the Pearson correlation between model error and these features to identify potential biases (e.g., does the model fail on darker/noisier images?).
5.  **Submission**:
    *   Compare the validation AUC against the threshold (0.9129501920716607).
    *   If successful, invoke `library.inference.run_inference` to generate predictions for the test set using the saved models. The inference function will automatically handle the TTA and ensemble aggregation, skipping missing folds (1-4) gracefully.
