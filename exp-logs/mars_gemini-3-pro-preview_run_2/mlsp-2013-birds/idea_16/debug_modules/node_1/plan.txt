The issue is that the validation AUC (`val_auc`) evaluates to `nan` during the demo run because the validation subset is too small to support the calculation of the macro-averaged ROC AUC. In Python, comparisons involving `nan` (e.g., `nan > -1.0`) always evaluate to `False`, which causes the condition `if val_auc > best_auc:` to fail. Consequently, the model checkpoint is never saved, leading to a `FileNotFoundError` later in the pipeline. To fix this, I will sanitize the `val_auc` variable by checking for `nan` and replacing it with a valid fallback value (0.5) before the comparison, ensuring that the best model logic triggers and the checkpoint is created (Cite debug_lesson_3).
