The implementation strategy involves a simplified execution of the "Born-Again" Ensemble idea to fit within the time constraints while maintaining the core logic.

1.  **Setup & Data Loading**: We initialize the environment with a fixed seed and load the pre-processed training, validation, and test datasets. We override the epoch count to 8 to ensure the pipeline completes quickly.
2.  **Phase 1 (Anchors)**: We train two "Anchor" models (ResNet18 and EfficientNet-B0) on the training set using weighted binary cross-entropy loss to handle class imbalance.
3.  **Phase 2 (Soft Targets)**: We use the trained anchors to generate "soft targets" for the training set via Test-Time Augmentation (TTA). This simulates the distillation process by providing smoothed supervision signals.
4.  **Phase 3 (Born-Again Ensemble)**: We train the full heterogeneous ensemble (ResNet18, EfficientNet-B0, and DenseNet121) on the training set. These models are trained using a Distillation Loss that combines the standard ground truth with the soft targets generated in Phase 2.
5.  **Validation & Analysis**: We perform inference on the validation set using the full ensemble with TTA. We compute the Macro-AUC, print it, and perform failure analysis by correlating prediction errors with label cardinality.
6.  **Submission**: If the validation AUC exceeds the specified threshold, we generate predictions for the test set using the full ensemble and save them in the required format.
