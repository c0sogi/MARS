This script implements the "Heterogeneous Ensemble with Sharpness-Aware Minimization (SAM) and Cyclic Test-Time Augmentation" strategy. It orchestrates the training of three distinct backbones (ResNet18, EfficientNet-B0, DenseNet121) on the provided training split. For each model, it utilizes the SAM optimizer to enhance generalization on the small dataset and applies weighted loss to handle class imbalance. Inference is performed using Cyclic Test-Time Augmentation (TTA) to average predictions across temporal shifts. Finally, the script aggregates predictions from all models, performs failure analysis by correlating errors with image statistics, and generates a submission file if the validation AUC meets the required threshold.
