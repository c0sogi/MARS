The following script performs a comprehensive Exploratory Data Analysis (EDA) on the text normalization training dataset. It loads the data from the pre-generated metadata file, ensures reproducibility with a fixed random seed, and analyzes the target variables (`class` and `after` text) and input text features (`before`). The analysis includes distribution checks, text-specific metrics (lengths, vocabulary, character sets), and relationships between token classes and normalization behavior (e.g., change rates, length correlations). The output is formatted into distinct sections with precise numerical reporting.
