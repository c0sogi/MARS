The implementation strategy follows a strict orchestration pipeline designed to meet the accuracy and runtime requirements. First, we override the default configuration to optimize for a "fast baseline" execution, reducing epochs and folds to ensure the process completes within the 2-hour limit on the provided hardware, while increasing batch size to leverage the A100 GPU. We then initialize the Tier 1 HFBB model, which serves as the foundation for the hybrid system. Next, we trigger the training of the Tier 2 Transformer model, which focuses specifically on "residual" errors—cases where the statistical model fails or is ambiguous. After training, we perform a rigorous validation on the hold-out set, calculating the exact string-match accuracy and conducting a failure analysis to correlate errors with input characteristics like token length and semiotic type. Finally, conditioned on meeting the accuracy threshold, we generate the submission file for the test set.
