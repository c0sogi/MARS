Based on the progression of experiments and the specific lessons learned, I propose the **Confidence-Aware Hybrid Cascade with Curriculum-Enriched Residuals**.

This strategy resolves the conflict between **Lesson 00010** (which mandates exhausting statistical lookups to avoid neural inference errors on simple tokens) and the reality that single-token lookups (Unigrams) are often ambiguous in Russian (e.g., numbers changing case/gender). By introducing a **Confidence Gate**, we allow the system to trust the memory model for "solved" tokens while selectively routing "ambiguous" tokens to the neural network, even if they have been seen before.

# Model

The architecture is a **Two-Tier Cascade** with a confidence-based routing mechanism.

1.  **Tier 1: Confidence-Aware Memory Engine (HFBB)**
    *   **Structure:** A 4-level backoff hierarchy: **Trigram $\rightarrow$ Bigram (Prev) $\rightarrow$ Bigram (Next) $\rightarrow$ Unigram**.
    *   **Innovation (Confidence Gating):** Unlike previous iterations, the **Unigram** layer stores not just the mode normalization but also a **Confidence Score** ($P(\text{Mode}) = \frac{\text{Count}(\text{Mode})}{\text{Total Count}}$).
    *   **Role:** This layer resolves all context-specific matches (Trigrams/Bigrams) and high-confidence context-free matches (e.g., "2012" $\to$ "две тысячи двенадцатый" is stable, whereas "2" is highly ambiguous).

2.  **Tier 2: Curriculum-Enriched Transformer**
    *   **Architecture:** A **Heterogeneous Char-to-Subword Transformer**.
        *   **Input:** Character-level tokenization of the target token + word-level context (`Prev_Word <SEP> Target_Chars <SEP> Next_Word`).
        *   **Output:** BPE subword tokenization of the normalized text.
    *   **Role:** To generate normalizations for **Residuals** (OOV tokens) and **Ambiguous Semiotics** (tokens where Tier 1 has low confidence).

3.  **Routing Logic:**
    *   **Step 1:** Query Trigram $\to$ Bigram(P) $\to$ Bigram(N). If match found, **Return** (Cite {solution_lesson_node_00006}).
    *   **Step 2:** Query Unigram.
        *   If Match **AND** `Confidence > Threshold` (e.g., 0.95): **Return**. (Strictly follows Cite {solution_lesson_node_00010} for simple tokens).
        *   If Match **AND** `Confidence <= Threshold` **AND** `Is_Semiotic`: **Route to Tier 2**. (Addresses the ambiguity gap).
    *   **Step 3:** If No Match (OOV):
        *   If `Is_Semiotic` (contains `\d` or `[a-zA-Z]`): **Route to Tier 2**.
        *   Else: **Identity Fallback**.

# Data

1.  **HFBB Construction:**
    *   Compute frequencies on the full training set. Calculate Confidence Scores for the Unigram layer.

2.  **Transformer Dataset (Curriculum-Enriched Residuals):**
    *   **Phase A: Residual Generation (Jackknifing):** Perform 5-Fold Cross-Validation on the training set. For each fold, train a temporary HFBB model on the other 4.
    *   **Phase B: Error Collection:** Run inference on the hold-out fold. Collect **Residuals**:
        *   Tokens where HFBB prediction was incorrect.
        *   Tokens where HFBB fell back to Identity incorrectly.
        *   *Crucially*, this captures the "Ambiguous" cases where the Unigram mode was wrong for the specific context (Cite {solution_lesson_node_00013}).
    *   **Phase C: Anchor Sampling (Curriculum):** Sample ~20% of the **Correct** semiotic predictions from the Jackknife. These "Anchors" teach the model the fundamental grammar (e.g., "1" $\to$ "one") that purely residual datasets lack (Cite {solution_lesson_node_00014}).
    *   **Phase D: Balancing:** Upsample rare classes (Money, Decimal) in this combined dataset (Cite {solution_lesson_node_00002}).

# Training

1.  **Tier 1 (HFBB):**
    *   Single-pass Maximum Likelihood Estimation.

2.  **Tier 2 (Transformer):**
    *   **Objective:** Minimize Cross-Entropy Loss on the BPE target sequence.
    *   **Optimization:** AdamW with linear warmup and cosine decay.
    *   **Regularization:** Dropout (0.1) and Label Smoothing (0.1) to prevent overfitting to the specific "hard" examples.

# Evaluation

1.  **Inference Pipeline:**
    *   Iterate through the test set.
    *   Apply the **Routing Logic**:
        *   Prioritize Trigram/Bigram matches.
        *   Trust Unigram matches *only* if high confidence.
        *   Delegate low-confidence or OOV semiotic tokens to the Transformer.
    *   Combine outputs into the submission CSV.

This strategy optimally balances the speed and precision of memorization with the context-awareness of neural generation, specifically targeting the "Ambiguity" failure mode that previous strict-priority cascades missed.
