This script demonstrates the end-to-end workflow of the Text Normalization solution. It performs the following steps:

1.  **Configuration Override**: Patches the global `Config` class to use a temporary directory and a small subset of the data for rapid execution.
2.  **Data Preparation**: Creates mini-versions of the training, validation, and test datasets in the working directory.
3.  **HFBB Model**: Trains the Hierarchical Frequency Back-Off model on the mini-dataset and verifies its query logic.
4.  **Tokenization**: Builds Character and BPE tokenizers and verifies encoding/decoding.
5.  **Dataset Construction**: Runs the `DatasetBuilder` to generate curriculum-enriched residuals using Jackknifing.
6.  **Transformer Training**: Trains the Sequence-to-Sequence Transformer for 1 epoch on the residual data.
7.  **Inference**: Runs the `HybridPredictor` (HFBB + Transformer) on the mini-test set and generates a submission file.
