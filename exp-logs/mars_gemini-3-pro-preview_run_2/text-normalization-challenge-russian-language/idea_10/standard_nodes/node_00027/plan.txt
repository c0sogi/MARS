This script orchestrates the hybrid text normalization pipeline. It first configures the environment for a fast baseline run by limiting training samples and epochs. It then initializes the Hierarchical Frequency-Based Backoff (HFBB) system and prepares the class-balanced semiotic dataset for the neural network. The Semiotic Transformer is trained on these hard cases. A full validation pass is performed using the hybrid logic (HFBB for confident/easy tokens, Transformer for ambiguous/semiotic tokens) to compute the final accuracy metric. Failure analysis is conducted to identify error patterns, and if the accuracy threshold is met, the final submission is generated.
