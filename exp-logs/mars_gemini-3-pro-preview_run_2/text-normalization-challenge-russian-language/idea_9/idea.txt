Based on the progression of experiments and the synthesis of all provided lessons, I propose the **Confidence-Gated Curriculum Cascade with Extended Context**.

This strategy addresses the core conflict between **Lesson 00010** (which mandates using statistical lookups for stability) and **Lesson 00013** (which highlights the need to handle distribution mismatches for rare tokens), while solving the "Grammar Gap" identified in **Lesson 00014**.

# Model

The solution utilizes a **Two-Tier Hybrid Cascade** that dynamically routes tokens based on both **Contextual Specificity** and **Statistical Confidence**.

1.  **Tier 1: Confidence-Aware Memory Engine (HFBB)**
    *   **Structure:** The optimized 4-level backoff hierarchy: **Trigram $\rightarrow$ Bigram (Prev) $\rightarrow$ Bigram (Next) $\rightarrow$ Unigram**.
    *   **Innovation (Confidence Gating):** The **Unigram** layer is augmented to store a **Confidence Score** ($P(\text{Mode}) = \frac{\text{Count}(\text{Mode})}{\text{Total Count}}$). This metric quantifies the ambiguity of a context-free token (e.g., "2" is ambiguous/low-confidence due to gender inflection, while "2012" is stable/high-confidence).
    *   **Role:** Resolves all context-dependent matches and high-confidence context-free matches.

2.  **Tier 2: Context-Rich Heterogeneous Transformer**
    *   **Architecture:** A **Character-to-Subword** Encoder-Decoder Transformer.
        *   **Encoder:** Character-level tokenization to preserve precise digit/symbol information.
        *   **Decoder:** Subword (BPE) tokenization (trained on the target text) to ensure valid Russian morphology.
    *   **Innovation (Extended Context):** The input window is expanded to **$\pm 2$ tokens** (`Prev2 Prev1 <SEP> Target <SEP> Next1 Next2`). This captures long-range dependencies (e.g., noun gender agreement) crucial for resolving the ambiguous semiotic tokens that Tier 1 rejects.
    *   **Role:** Generates normalizations for **Residuals** (OOV), **Ambiguous Semiotics** (Low-Confidence Unigrams), and complex rare entities.

# Data

The strategy employs a **Curriculum-Enriched Data Construction** pipeline to train the Transformer, ensuring it learns both the "grammar" of numbers and the "correction" of edge cases.

1.  **HFBB Construction:**
    *   Compute frequencies on the full training set. Calculate Confidence Scores for the Unigram layer.

2.  **Transformer Dataset (The "Hard + Anchor" Mix):**
    *   **Source A: Residuals (The Failures):** Perform K-Fold Cross-Validation on the training set. Collect tokens where the HFBB prediction was **incorrect** (True Negatives). This satisfies **Cite {solution_lesson_node_00013}**.
    *   **Source B: Ambiguity Mining (The Hard Positives):** Collect tokens where HFBB was **correct** but the **Unigram Confidence was Low** (e.g., < 0.9). These are "lucky guesses" by the baseline that the Transformer needs to learn to handle robustly using the Extended Context.
    *   **Source C: Anchors (The Curriculum):** Sample ~20% of **High-Confidence Correct** semiotic tokens. These simple examples (e.g., "1" $\to$ "один") provide the fundamental digit-to-word grammar that purely residual datasets lack, preventing the "forgetting" observed in **Cite {solution_lesson_node_00014}**.
    *   **Preprocessing:** Apply **Class-Balanced Upsampling** to rare classes (Money, Decimal) within this mix to prevent bias towards Dates **Cite {solution_lesson_node_00002}**.

# Training

1.  **Tier 1 (HFBB):**
    *   Single-pass Maximum Likelihood Estimation on the full dataset.

2.  **Tier 2 (Transformer):**
    *   **Objective:** Minimize Cross-Entropy Loss on the target BPE sequence.
    *   **Optimization:** Train from scratch using `AdamW` with a linear warmup and cosine decay scheduler.
    *   **Regularization:** Apply Dropout (0.1) and Label Smoothing (0.1) to prevent overfitting to the specific values in the residual set.

# Evaluation

1.  **Inference Pipeline:**
    *   Iterate through the test set.
    *   **Step 1 (Context Match):** Query Trigram $\rightarrow$ Bigram(P) $\rightarrow$ Bigram(N). If a match is found, **Return** (Highest Precision, **Cite {solution_lesson_node_00006}**).
    *   **Step 2 (Confidence Check):** Query Unigram.
        *   If Match **AND** `Confidence > Threshold` (e.g., 0.95): **Return**. (Preserves stability for simple tokens, **Cite {solution_lesson_node_00010}**).
        *   If Match **AND** `Confidence <= Threshold` **AND** `Is_Semiotic`: **Route to Tier 2**. (Addresses ambiguity).
    *   **Step 3 (Fallback/OOV):**
        *   If `Is_Semiotic` (contains `\d` or `[a-zA-Z]`): **Route to Tier 2**.
        *   Else: **Identity Fallback**.
2.  **Submission:** Format the predictions into the required `id,after` CSV.
