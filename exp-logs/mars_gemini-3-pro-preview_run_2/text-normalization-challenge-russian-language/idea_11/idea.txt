Based on the comprehensive analysis of the task and the specific failure modes identified in the provided lessons, I propose the **Confidence-Gated Hybrid Cascade with Density-Maximized Semiotic Training**.

This strategy addresses the critical "Data Density" failure (**Cite {solution_lesson_node_00026}**) and the "Curriculum Gap" (**Cite {solution_lesson_node_00014}**) by fundamentally restructuring the data pipeline and enforcing a strict, confidence-aware inference hierarchy (**Cite {solution_lesson_node_00010}**).

# Model

The solution utilizes a **Two-Tier Hybrid Cascade** that prioritizes deterministic memory for "solved" patterns and reserves neural generation for the "long tail" of complex semiotic entities.

1.  **Tier 1: Confidence-Aware Memory Engine (HFBB)**
    *   **Architecture:** A 4-level statistical backoff hierarchy: **Trigram $\rightarrow$ Bigram (Prev) $\rightarrow$ Bigram (Next) $\rightarrow$ Unigram**.
    *   **Innovation (Confidence Gating):** The **Unigram** layer is augmented to store a **Confidence Score** ($P(\text{Mode}) = \frac{\text{Count}(\text{Mode})}{\text{Total Count}}$).
    *   **Role:** This tier resolves all context-dependent tokens (**Cite {solution_lesson_node_00006}**) and high-confidence context-free tokens (e.g., "2012" $\to$ "две тысячи двенадцатый"). It acts as a filter to prevent the neural network from hallucinating on simple, stable inputs (**Cite {solution_lesson_node_00010}**).

2.  **Tier 2: Context-Rich Semiotic Transformer**
    *   **Architecture:** A **Character-to-Subword** Encoder-Decoder Transformer (e.g., a custom 6-layer model).
    *   **Input Innovation (Extended Context):** Unlike previous iterations that used a $\pm 1$ word window, this model uses a **$\pm 2$ word window**: `Prev_2 Prev_1 <SEP> Target_Chars <SEP> Next_1 Next_2`. This wider context is structurally necessary to resolve the gender/case ambiguities (e.g., noun agreement for numbers) that cause the Unigram layer to have low confidence.
    *   **Granularity:**
        *   **Encoder:** Character-level tokenization to precisely parse the internal structure of numbers and symbols.
        *   **Decoder:** BPE (Subword) tokenization to ensure the output adheres to valid Russian morphology.

# Data

The core innovation lies in the **Density-Maximized Data Construction**, which rejects the "residual-only" approach that failed in **Cite {solution_lesson_node_00014}** and **Cite {solution_lesson_node_00026}**.

1.  **HFBB Construction:**
    *   Compute frequencies and confidence scores on the full training corpus (7M+ tokens).

2.  **Transformer Dataset (The Semiotic Domain):**
    *   **Domain Filtering:** Extract **ALL** tokens from the training set that contain digits (`\d`) or Latin characters (`[a-zA-Z]`). We do *not* filter out the "easy" examples (Anchors). This ensures the model learns the fundamental grammar of normalization (e.g., "1" $\to$ "one") (**Cite {solution_lesson_node_00014}**).
    *   **Class-Balanced Upsampling:** Calculate the frequency of semiotic classes. Aggressively **upsample** rare, high-cardinality classes (`MONEY`, `DECIMAL`, `TELEPHONE`) to match the frequency of the dominant class (`DATE`). This forces the model to dedicate capacity to the "Infinite Cardinality" problems identified in **Cite {solution_lesson_node_00002}**.
    *   **Density Guarantee:** This process yields a dataset of millions of tokens (high density), ensuring the neural network has sufficient signal to generalize, correcting the "bottleneck" observed in **Cite {solution_lesson_node_00026}**.

# Training

1.  **Tier 1 (HFBB):**
    *   Single-pass Maximum Likelihood Estimation.

2.  **Tier 2 (Transformer):**
    *   **Objective:** Minimize Cross-Entropy Loss on the target BPE sequence.
    *   **Optimization:** Train from scratch using `AdamW` with a linear warmup and cosine decay scheduler.
    *   **Regularization:** Apply Dropout (0.1) and Label Smoothing (0.1) to prevent overfitting to specific numeric values.

# Evaluation

The inference pipeline employs a **Strict-Priority Routing Logic** to ensure stability:

1.  **Step 1 (Context Match):** Query HFBB Trigram $\rightarrow$ Bigram(Prev) $\rightarrow$ Bigram(Next).
    *   If Match Found: **Return Prediction**. (Highest Precision, **Cite {solution_lesson_node_00006}**).
2.  **Step 2 (Confidence Check):** Query HFBB Unigram.
    *   If Match Found **AND** `Confidence > Threshold` (e.g., 0.99): **Return Prediction**. (Preserves stability for simple tokens, **Cite {solution_lesson_node_00010}**).
    *   If Match Found **AND** `Confidence <= Threshold`: **Route to Tier 2**. (The token is seen but ambiguous; Neural Net uses Extended Context to resolve).
3.  **Step 3 (OOV/Fallback):**
    *   If `Is_Semiotic` (contains `\d` or `[a-zA-Z]`): **Route to Tier 2**. (Unseen numbers/money).
    *   Else: **Identity Fallback**. (Unknown proper nouns).
4.  **Submission:** Format predictions into the required `id,after` CSV.
