The following script demonstrates the usage of the provided text normalization library. It performs the following steps:

1.  **Environment Setup**: Creates a lightweight demonstration environment by sampling a small subset of the real data (200 rows) and saving it to the working directory.
2.  **Configuration Override**: Modifies the global `Config` class to point to the small datasets and reduces hyperparameters (epochs, batch size, vocabulary size) for rapid execution.
3.  **Component Verification**:
    *   **Tier 1 (HFBB)**: Initializes and fits the Hierarchical Backoff model, verifying it can correctly retrieve a mapping from the training data.
    *   **Tokenizer**: Trains the Hybrid Tokenizer on the small dataset and verifies encoding/decoding logic and tensor shapes.
    *   **Data Pipeline**: Verifies the `NormalizationDataset` and `DataLoader` correctly produce batches with source, target, and weight tensors.
    *   **Tier 2 (Transformer)**: Initializes the `TransformerTrainer`, runs a single training step to verify the forward/backward pass and loss calculation.
    *   **Inference (Predictor)**: Uses the `HybridPredictor` to generate predictions on the sample test set, verifying the hybrid routing logic (HFBB vs. Neural Network).
