The issue is caused by Python's handling of default argument values, which are evaluated at function definition time (import time). The `ContextAwareTransformer` class uses default values from `Config` in its `__init__` method (e.g., `embed_dim=Config.EMBED_DIM`). When `runfile.py` modifies `Config` at runtime (changing `EMBED_DIM` from 256 to 64), the `Trainer` correctly instantiates the model with the new values because it passes them explicitly. However, `load_model` instantiates the model without arguments, causing it to fall back to the defaults captured at import time (256), resulting in a shape mismatch when loading the checkpoint.

To fix this, I will modify `load_model` in `library/model.py` to explicitly pass the current configuration values from `Config` when instantiating `ContextAwareTransformer`. This ensures the model architecture matches the configuration currently in memory.
