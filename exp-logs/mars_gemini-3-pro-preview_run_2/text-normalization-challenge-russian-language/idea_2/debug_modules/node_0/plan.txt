The implementation strategy is as follows:

1.  **Configuration & Setup**: Override the default `Config` parameters to enable debug mode, reduce model size (layers, dimensions), and set the number of epochs to 1. Redirect all file operations to a temporary working directory (`./working/demo`) to avoid conflicts and ensure clean execution.
2.  **Data Subsetting**: Instead of loading the full multi-gigabyte datasets, read the first 1,000 rows of the provided metadata files (`train.csv`, `val.csv`, `test.csv`) and save them as mini-datasets in the temporary directory. Update `Config` file paths to point to these mini-datasets. This ensures the data processing steps (tokenizer building, dataset loading) execute almost instantly.
3.  **Component Demonstration**:
    *   **Tokenizer**: Initialize and verify the `CharTokenizer` by encoding and decoding a sample string.
    *   **HFBB Model**: Train the hierarchical backoff model on the mini-dataset and verify it can predict simple mappings or backoff correctly.
    *   **Dataset**: Instantiate the `DigitSeq2SeqDataset` and verify it correctly filters for digits and produces tensors of the expected shape.
    *   **Transformer Model**: Instantiate the `ContextAwareTransformer` with the reduced configuration and perform a dummy forward pass to verify tensor shapes.
    *   **Training**: Run the `Trainer` for one epoch on the mini-dataset to produce a trained model checkpoint.
    *   **Inference**: Initialize the `HybridNormalizer` (which loads the trained artifacts) and generate predictions for the mini-test set, verifying the output format.
