Based on the comprehensive failure analysis of previous attempts, I propose the **Curriculum-Enriched Residual Hybrid Cascade**.

This strategy resolves the critical conflict identified between **Lesson 00013** (which demands training on residuals to match the inference distribution) and **Lesson 00014** (which proves that training *only* on residuals destroys the grammatical curriculum required to learn the task).

# Model

The solution utilizes a **Strict-Priority Cascade** that integrates a high-performance memory layer with a specialized neural generalization layer.

1.  **Tier 1: Granular Memory Engine (HFBB)**
    *   **Role:** The primary solver for all "seen" vocabulary and context patterns.
    *   **Structure:** It implements the optimized **4-level backoff hierarchy**: **Trigram $\rightarrow$ Bigram (Prev) $\rightarrow$ Bigram (Next) $\rightarrow$ Unigram**.
    *   **Retention:** Crucially, this tier retains the **Unigram** layer. This ensures that frequent, simple semiotic tokens (e.g., "2" $\rightarrow$ "два") are resolved deterministically by memory, preventing the inference errors caused by routing trivial tasks to neural networks **Cite {solution_lesson_node_00010}**. The intermediate Bigram layers ensure high precision for context-dependent tokens **Cite {solution_lesson_node_00006}**.

2.  **Tier 2: Curriculum-Enriched Transformer (Generative Fallback)**
    *   **Role:** A generative solver reserved for **unseen** semiotic tokens (the "long tail" of Money, Decimals, etc.) that fail the memory lookup.
    *   **Architecture:** A **Heterogeneous Char-to-Subword Transformer**.
        *   **Encoder:** Character-level tokenization to precisely parse digits and symbols in the input.
        *   **Decoder:** Subword (BPE) tokenization to ensure the output adheres to valid Russian morphology.
    *   **Input Context:** `[Prev_Word] <SEP> [Target_Token_Chars] <SEP> [Next_Word]`.

3.  **Routing Logic:**
    *   **Step 1:** Query Tier 1. If a match is found, return it immediately.
    *   **Step 2:** If Tier 1 fails (OOV), check if the token is "semiotic" (contains digits `\d` or Latin `[a-zA-Z]`).
    *   **Step 3:** If semiotic, dispatch to Tier 2 (Transformer).
    *   **Step 4:** Otherwise, fall back to Identity (for rare proper nouns/punctuation).

# Data

The core innovation is the **Curriculum-Enriched Data Construction** strategy, which synthesizes a training dataset that balances "hard" edge cases with "easy" grammatical anchors.

1.  **HFBB Construction:**
    *   Use the full training corpus to populate the Tier 1 hash maps.

2.  **Transformer Dataset Construction:**
    *   **Phase A: Residual Generation (The Target):** Perform K-Fold Jackknifing on the training data. For each fold, train a temporary HFBB model on the other folds and predict the current fold. Collect the **Residuals** (failures). This captures the specific distribution of "hard" cases the model will face at inference **Cite {solution_lesson_node_00013}**.
    *   **Phase B: Anchor Sampling (The Curriculum):** From the set of tokens that HFBB *successfully* predicted, sample a subset (e.g., 20% of the volume of residuals) of **Semiotic Anchors**. These are simple examples (e.g., "1", "2012", "Chapter 5") that contain the fundamental digit-to-word mappings.
    *   **Phase C: Synthesis:** Combine the Residuals and the Anchors into a single training set.
    *   **Rationale:** By re-introducing the Anchors, we provide the model with the "grammar" of numbers (e.g., learning that "2" maps to "two") which was missing in the pure residual approach **Cite {solution_lesson_node_00014}**. The model learns the rules from the Anchors and applies them to solve the Residuals.

3.  **Class Balancing:**
    *   Within the combined dataset, upsample rare classes (Money, Decimal) to match the frequency of the dominant semiotic class (Date) to prevent bias.

# Training

1.  **Tier 1 (HFBB):**
    *   Single-pass Maximum Likelihood Estimation on the full dataset.

2.  **Tier 2 (Transformer):**
    *   **Objective:** Minimize Cross-Entropy Loss on the target BPE sequence.
    *   **Strategy:** Train on the **Curriculum-Enriched** dataset.
    *   **Optimization:** Use `AdamW` with a linear warmup and cosine decay scheduler.
    *   **Regularization:** Apply moderate dropout (0.1) and label smoothing (0.1).

# Evaluation

1.  **Inference Pipeline:**
    *   Iterate through the test set.
    *   **Check Tier 1 (HFBB):** If Trigram/Bigram/Unigram match exists, return it.
    *   **Check Gate:** If no match, check `if has_digit(token) or has_latin(token)`.
    *   **Run Tier 2:** If Gate is True, tokenize input as chars, run Transformer, decode BPE to string.
    *   **Fallback:** Else, return original token.
2.  **Submission:** Format predictions into the required CSV structure.
