This script demonstrates the full pipeline of the Curriculum-Enriched Residual Hybrid Cascade system for text normalization. It begins by configuring the environment for a rapid demonstration, creating a small subset of the provided dataset to ensure quick execution. It then walks through the instantiation and training of the Hierarchical Frequency Back-off (HFBB) model, the preparation of curriculum-enriched data using the DataFactory, and the training of the Character-to-Subword Transformer. Finally, it executes the inference pipeline using the CascadeInference class to generate predictions and a submission file, verifying the outputs at each stage.
