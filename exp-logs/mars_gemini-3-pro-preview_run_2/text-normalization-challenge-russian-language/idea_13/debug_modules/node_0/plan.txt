The following script demonstrates the end-to-end usage of the provided machine learning library for the text normalization task.

**Implementation Strategy:**
1.  **Environment Setup**: We import necessary modules and monkey-patch the data loading function (`load_metadata`) to return small subsets of the data. This ensures the demonstration runs quickly (within minutes) instead of processing millions of records, while still executing the exact same logic paths.
2.  **Configuration**: We initialize the `Config` class with debug settings, a small batch size, and a single training epoch.
3.  **Tier 1 (HFBB) Demonstration**: We initialize and fit the statistical `HFBBStats` model, then verify it can correctly retrieve a high-confidence normalization (e.g., punctuation) from its memory.
4.  **Tokenizer Demonstration**: We initialize and fit the `HybridTokenizer`. We verify that it generates the correct files and that the character-level encoder and BPE decoder work as expected.
5.  **Data Pipeline Demonstration**: We use `DatasetManager` to generate PyTorch DataLoaders. We fetch a single batch to verify tensor shapes and padding logic.
6.  **Tier 2 (Transformer) Demonstration**:
    *   **Model Initialization**: We instantiate the `Seq2SeqTransformer` using vocabulary sizes derived from the tokenizer.
    *   **Forward Pass**: We run a dummy forward pass to confirm the architecture is valid.
    *   **Training Loop**: We use `TransformerTrainer` to run a short training session (1 epoch on the subset), verifying that loss decreases and a checkpoint is saved.
7.  **Inference Demonstration**: We use `HybridPredictor` to generate a submission file. This exercises the hybrid routing logic (choosing between HFBB and the Neural Net) and the beam/greedy search decoding. Finally, we validate the format of the output CSV.
