Based on the progression of experiments and the critical lessons learned—specifically the failure of "residual-only" training (Cite {solution_lesson_node_00013}, {solution_lesson_node_00014}), the necessity of high data density for neural generalization (Cite {solution_lesson_node_00026}), and the catastrophic impact of stale artifacts (Cite {solution_lesson_node_00031})—I propose the **Robust Density-Maximized Hybrid Cascade**.

This strategy is a structural evolution that combines the deterministic precision of the statistical baseline with a "Heavy" neural component that is rigorously engineered to avoid the data starvation and pipeline corruption issues of previous attempts.

# Model

The solution utilizes a **Strict-Priority Two-Tier Cascade** that routes tokens based on context specificity and statistical confidence.

1.  **Tier 1: Confidence-Aware Granular Memory (HFBB)**
    *   **Structure:** This tier implements the optimized **4-level backoff hierarchy**: **Trigram $\rightarrow$ Bigram (Prev) $\rightarrow$ Bigram (Next) $\rightarrow$ Unigram**. This structure preserves the gains from **Cite {solution_lesson_node_00006}**.
    *   **Innovation (Confidence Gating):** The **Unigram** layer stores a **Confidence Score** ($P(\text{Mode})$). This allows the system to distinguish between "stable" context-free tokens (e.g., "2012") and "ambiguous" tokens (e.g., "2").
    *   **Role:** Acts as a high-precision filter, resolving ~98% of queries instantly. It ensures that simple, frequent tokens are never routed to the neural network, preventing inference regressions **Cite {solution_lesson_node_00010}**.

2.  **Tier 2: Anchored Heterogeneous Transformer**
    *   **Architecture:** A Sequence-to-Sequence Transformer designed with **Heterogeneous Granularity**:
        *   **Encoder (Character-Level):** Input is tokenized at the character level to parse the internal structure of infinite-cardinality classes (Money, Decimals) **Cite {solution_lesson_node_00002}**.
        *   **Decoder (Subword-Level):** Output is generated using a BPE tokenizer trained on the target text to ensure valid Russian morphology.
    *   **Structural Innovation (Contextual Anchoring):** Unlike previous iterations, the input sequence explicitly delimits the target token within the context window using special anchor tokens: `[Prev_Context] <SEP> <START> [Target_Chars] <END> <SEP> [Next_Context]`. This attention-guiding mechanism helps the model distinguish the token to be normalized from the context cues required to resolve its gender/case.

# Data

The core innovation is the **Robust Density-Maximized Data Pipeline**, which enforces strict artifact consistency and solves the "Curriculum vs. Mismatch" trade-off.

1.  **Pipeline Safety (Solving Lesson 00031):**
    *   The data processing pipeline will implement **Hash-Based Artifact Validation**. All intermediate artifacts (vocabularies, HFBB tables, processed tensors) will be saved in directories named after the hash of their configuration and source data size. This guarantees that the model never trains on stale "debug" artifacts.

2.  **HFBB Construction:**
    *   Computed on the **Full Training Corpus** (7M+ tokens) to maximize coverage.

3.  **Transformer Dataset (Density-Maximized Semiotics):**
    *   **Domain Filtering (Solving Lesson 00026):** Extract **ALL** tokens from the training set that belong to semiotic classes (containing digits `\d` or Latin `[a-zA-Z]`). We explicitly do **not** use a "residual-only" subset. By using the full semiotic corpus, we ensure the model has sufficient data density to generalize.
    *   **Curriculum Retention (Solving Lesson 00014):** By including "easy" semiotic tokens (Anchors) alongside the hard ones, we ensure the model learns the fundamental grammar of normalization (e.g., "1" $\to$ "один").
    *   **Aggressive Class Balancing:** We apply **Inverse Frequency Upsampling** to rare, high-error classes (`MONEY`, `DECIMAL`, `TELEPHONE`) to match the frequency of the dominant class (`DATE`). This forces the model to prioritize the "long tail" rules that Tier 1 cannot handle.

# Training

1.  **Tier 1 (HFBB):**
    *   Single-pass Maximum Likelihood Estimation on the full dataset.

2.  **Tier 2 (Transformer):**
    *   **Objective:** Minimize Cross-Entropy Loss on the target BPE sequence.
    *   **Strategy:** Train from scratch on the **Density-Maximized Class-Balanced** dataset.
    *   **Optimization:** Use `AdamW` with a linear warmup and cosine decay scheduler.
    *   **Regularization:** Apply **Label Smoothing (0.1)** and **Dropout (0.1)** to prevent overfitting to the specific values in the training set and encourage learning generative rules.

# Evaluation

The inference pipeline employs a **Confidence-Gated Routing Logic** to strictly enforce the "Exhaust Lookup" principle **Cite {solution_lesson_node_00010}**:

1.  **Step 1 (Context Match):** Query HFBB Trigram $\rightarrow$ Bigram(Prev) $\rightarrow$ Bigram(Next).
    *   If a match is found, **Return Prediction** immediately. (Highest Precision, **Cite {solution_lesson_node_00006}**).
2.  **Step 2 (Confidence Check):** Query HFBB Unigram.
    *   If Match Found **AND** `Confidence > Threshold` (e.g., 0.99): **Return Prediction**. (Stable tokens are handled by memory).
    *   If Match Found **AND** `Confidence <= Threshold`: **Route to Tier 2**. (Ambiguous tokens are routed to the Neural Net).
3.  **Step 3 (OOV/Fallback):**
    *   If the token is Semiotic (contains `\d` or `[a-zA-Z]`): **Route to Tier 2**. (Unseen numbers/money).
    *   Else: **Identity Fallback**. (Unknown proper nouns/punctuation).
