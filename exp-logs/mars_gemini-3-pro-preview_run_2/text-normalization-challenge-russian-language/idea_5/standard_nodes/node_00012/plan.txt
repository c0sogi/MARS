Implementation strategy:
1.  **Configuration Override**: Modify the `Config` class attributes at runtime to ensure a fast baseline. Specifically, reduce `EPOCHS` to 3 and `UPSAMPLE_TARGET_COUNT` to 50,000 to limit training time and dataset size while maintaining the "Strict-Priority Hybrid Cascade" strategy.
2.  **Training**: Initialize the `Trainer` and execute the training pipeline. Explicitly pass the reduced epoch count to the `run` method. This handles data processing (with the new limits), tokenizer fitting, and model training.
3.  **Validation Inference**: Load the validation dataset. Initialize the `HybridInference` pipeline (which loads the HFBB memory and the just-trained neural model). Run inference on the validation set.
4.  **Metric Calculation**: Merge predictions with the ground truth validation data. Calculate the exact string match accuracy. Print the required `Final Validation Metric`.
5.  **Failure Analysis**: Compute the correlation between the error signal (binary) and the input token length. Also analyze error rates by class to identify systematic weaknesses.
6.  **Submission**: Check if the validation accuracy exceeds the specified threshold (0.9784022349361615). If so, run inference on the test set and save the `submission.csv`.
