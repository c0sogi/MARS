The implementation strategy involves a structured pipeline leveraging the provided library modules. First, we set up the environment and seed for reproducibility. We then load the data, applying a subsampling limit of 20,000 images to the training set to ensure a fast execution time while keeping the validation and test sets intact for accurate evaluation. The `HybridResNet` model is initialized with class-weighted CrossEntropyLoss to handle the dataset imbalance. The training proceeds in two stages: a linear warmup using L-BFGS to fit the head, followed by fine-tuning the last backbone block with AdamW. After training, we evaluate the model to report the final Macro F1 score. We then perform failure analysis by correlating the model's error magnitude with input metadata features like frame number and location. Finally, conditional on the validation performance meeting the specified threshold, we generate the submission file.
