Based on the dataset analysis and the constraints provided, I propose a **Cached Linear Probing** approach. This solution prioritizes speed and simplicity by treating the deep learning backbone as a fixed feature extractor, reducing the learning problem to a fast, convex optimization task.

### Model
The architecture is a **Linear Probing Network** designed for maximum efficiency:
*   **Backbone**: Use a standard **ResNet50** pre-trained on ImageNet. The weights of this network will be completely **frozen** (non-trainable). This avoids the computational cost of gradient calculation through the deep network.
*   **Pooling**: Apply **Concatenated Global Pooling**. Specifically, compute both the Global Average Pooling (GAP) and Global Max Pooling (GMP) of the final feature map and concatenate them. GAP captures the general scene context (useful for the "Empty" class), while GMP captures the highest activation signals (crucial for detecting small animals that might be washed out by averaging).
*   **Classifier**: A single **Linear Layer** (Dense) that maps the concatenated feature vector (4096 dimensions) directly to the 23 class logits, followed by a Softmax activation. This distinguishes the model from the MLP used in Model 2 (which contains hidden layers) and the Kernel approximation in Model 5.

### Data
*   **Preprocessing**: Resize all images to **224x224** pixels and normalize them using standard ImageNet mean and standard deviation. No geometric augmentations (like flips or crops) will be used to maintain the "baseline" philosophy and deterministic behavior.
*   **Feature Caching**: To maximize training speed, perform a **single forward pass** of the frozen ResNet50 backbone over the entire training dataset. Extract the concatenated pooling vectors and store them in RAM (approx. 2.5 GB for 144k images). This converts the image classification problem into a lightweight tabular data problem.

### Training
*   **Loss Function**: Use **Cross-Entropy Loss** with **Class Weights**. Calculate the weights inversely proportional to the class frequencies in the training set. This is essential to counteract the 73% "Empty" class dominance and optimize for the **Macro F1** metric.
*   **Optimizer**: Use the **L-BFGS** optimizer instead of SGD or Adam. Since the feature extractor is frozen and the classifier is linear, the loss surface is convex. L-BFGS is a second-order optimization algorithm that converges significantly faster and more reliably for such convex problems, often requiring no hyperparameter tuning for learning rates.

### Evaluation
*   **Inference**: For the test set, process each image through the frozen ResNet50 backbone and the pooling layer to generate the feature vector.
*   **Prediction**: Pass the vector through the trained linear layer and select the class index with the highest probability (`argmax`). This ensures a fast inference pipeline suitable for the large test set (153k images).
