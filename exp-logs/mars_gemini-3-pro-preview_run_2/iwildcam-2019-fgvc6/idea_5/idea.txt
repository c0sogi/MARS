Based on the progression of experiments and the specific empirical findings documented in the lessons, I propose a **Native-Resolution EfficientNet-B4 with Balanced Sampling**.

This strategy is a structural synthesis designed to align **Model Capacity** (Backbone), **Input Fidelity** (Resolution), and **Data Distribution** (Sampling). Previous attempts failed because they misaligned these three pillars: Idea 3 lacked capacity (B3), Idea 4 lacked resolution (B4 at 300px), and the Lesson 25 experiment lacked data volume (B4 at 380px on 20% data). This solution synchronizes them while introducing a new data sampling paradigm to address the 73% "Empty" class dominance.

### Model
*   **Backbone Architecture:** Upgrade to **EfficientNet-B4**. This model offers a higher parameter count and deeper feature extraction capabilities than the B3 variant used in the current best solution.
*   **Hybrid Pooling Head:** Retain the **Concatenated Global Pooling** mechanism. The output of the backbone will be processed by both Global Average Pooling (GAP) and Global Max Pooling (GMP), and the results concatenated. This ensures the model retains both the scene context (GAP) and the peak activation signals of small, localized subjects (GMP) **Cite {solution_lesson_node_00010}**.
*   **Classifier:** A single Linear layer mapping the concatenated features to the 23 class logits.

### Data
*   **Resolution Synchronization:** Process all images at **380x380** pixels. This is the specific native resolution for EfficientNet-B4. By strictly aligning the input resolution with the backbone architecture, we leverage the Compound Scaling Law to capture finer details of small subjects that were lost at 300x300, without wasting the B4's capacity on upsampled coarse data **Cite {solution_lesson_node_00024}** **Cite {solution_lesson_node_00022}**.
*   **Balanced Batch Sampling:** Introduce a **Weighted Random Sampler** for the training DataLoader. Instead of relying solely on loss weighting (which handles imbalance via gradients), we will structurally alter the batch composition so that minority classes (e.g., Bobcat, Mountain Lion) appear more frequently. This ensures the model receives consistent gradient updates for rare classes rather than rare, massive spikes, stabilizing the fine-tuning of the larger backbone.
*   **Full Dataset Utilization:** We will train on the **entire training dataset**. We explicitly reject the strategy of subsetting data to save time, as empirical evidence showed that data volume is the primary driver of generalization in this imbalanced domain **Cite {solution_lesson_node_00025}**.
*   **Minimal Augmentation:** Apply only **Random Horizontal Flip**. We will explicitly avoid aggressive photometric augmentations and Label Smoothing, which were proven to degrade performance **Cite {solution_lesson_node_00020}**.

### Training
We will employ the **Two-Stage Optimization Strategy** with specific adaptations for the larger model:

1.  **Stage 1: Aggressive Head Alignment**
    *   **Configuration:** The EfficientNet-B4 backbone is completely frozen. Only the linear classifier is trainable.
    *   **Optimizer:** Use **Adam** with a learning rate of `1e-3` and **zero weight decay**.
    *   **Duration:** Train for 5-6 epochs to ensure the head is fully converged and aligned with the pre-trained features before unfreezing **Cite {solution_lesson_node_00018}**.

2.  **Stage 2: Partial Fine-Tuning with Gradient Accumulation**
    *   **Configuration:** Unfreeze the top blocks of the EfficientNet-B4 backbone (e.g., the final 2 stages) **Cite {solution_lesson_node_00015}**.
    *   **Gradient Accumulation:** Since increasing resolution to 380x380 increases VRAM usage, we will reduce the physical batch size to fit in memory but use Gradient Accumulation to maintain an effective batch size (e.g., 32 or 64). This allows us to train the larger B4 model on the full dataset without OOM errors.
    *   **Optimizer:** Switch to **AdamW** with a reduced learning rate (e.g., `1e-4`) and standard weight decay.
    *   **Scheduler:** Apply a Cosine Annealing scheduler.
    *   **Checkpointing:** Save the best model weights based on the validation Macro F1 score using `copy.deepcopy(model.state_dict())` to prevent implicit overwrites **Cite {solution_lesson_node_00003}**.

### Evaluation
*   **Inference:** Restore the best model from the deep-copied checkpoint.
*   **Prediction:** Resize test images to **380x380** pixels, normalize, and perform a forward pass. Select the class with the highest probability (`argmax`) for the final submission.
