The error `TypeError: '>' not supported between instances of 'Timestamp' and 'numpy.float16'` occurs because the `reduce_mem_usage` function in `library/utils.py` uses an exclusionary check (`if col_type != object ...`) to identify numeric columns. This incorrectly allows `datetime` columns (like `t_dat`) to pass through, leading to a crash when the code attempts to compare timestamps with floating-point limits.

To fix this, I will replace the exclusionary check with an inclusionary check using `pd.api.types.is_numeric_dtype(df[col])`. This explicitly verifies that the column contains numeric data before attempting any numerical optimization, ensuring that non-numeric types like `datetime` are correctly skipped.
