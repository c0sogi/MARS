This implementation strategy outlines a self-contained Python script to demonstrate the functionality of the provided machine learning library for the H&M recommendation task.

### Implementation Strategy

1.  **Setup & Imports**: The script will import necessary standard libraries (`sys`, `os`, `numpy`, `pandas`) and append the current directory to the system path to enable importing from the `library` package. It will set random seeds for reproducibility.
2.  **Metric Verification**: I will perform unit-test style verification of the `mapk` and `calculate_map12` functions using synthetic ground truth and prediction data (e.g., perfect match, no match, reordered match) to ensure the evaluation logic is correct.
3.  **Component Demonstration (`IdEncoder`)**: I will instantiate the `IdEncoder` class, fit it on dummy data, and verify that the transformation (string to int) and inverse transformation (int to string) work as expected, including handling of unknown values.
4.  **Data Loading & Subsampling**: I will use `load_and_filter_data` to load the training and validation datasets. To satisfy the "Optimize for Speed" requirement, I will slice the training data to a smaller subset (e.g., the last 100,000 transactions) and select a small number of validation customers. This ensures the subsequent model fitting runs quickly (seconds instead of minutes).
5.  **Model Training**: I will instantiate the `TimeWeightedCooccurrence` model and call its `fit` method using the subsampled training data. I will explicitly set `load_cached_data=False` to force the model to compute the similarity matrix for the subset rather than loading potentially mismatched cached artifacts.
6.  **Prediction & Evaluation**: I will generate predictions for the selected validation customers using `model.predict`, passing the training subset as their history. I will verify the output format (columns, string format) and calculate the MAP@12 score using `calculate_map12` to demonstrate the full inference and evaluation pipeline.
