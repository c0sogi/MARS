The issue is located in the `apk` function within `library/metrics.py`. The code uses `if not actual:` to check if the ground truth collection is empty. Since the calling function `calculate_map12` passes NumPy arrays (generated by `pandas.Series.unique()`) as the `actual` argument, this boolean check raises a `ValueError` when the array contains more than one element (as the truth value of such an array is ambiguous). The fix is to explicitly check the length of the collection using `len(actual) == 0`, which is valid for both Python lists and NumPy arrays.
