This script demonstrates the end-to-end usage of the provided recommendation system library. It performs the following steps:
1.  **Configuration**: Patches the `Config` class to use a temporary directory and reduces hyperparameters (e.g., number of estimators, retrieval history) for rapid execution.
2.  **Data Loading**: Uses `DataManager` to load and preprocess the raw data.
3.  **Sampling**: drastically downsamples the transaction history and customer list to ensure the demonstration completes quickly (within seconds/minutes).
4.  **Retrieval**: Uses `HybridRetrieval` to generate candidate items for the sampled customers.
5.  **Feature Engineering**: Uses `FeatureEngineer` to create a feature matrix (user, item, and interaction features) for the candidates.
6.  **Ranking**: Uses `Ranker` to train a LightGBM model on the generated features and predict rankings.
7.  **Evaluation**: Uses `Evaluator` to calculate the MAP@12 score for the predictions against the validation set.
