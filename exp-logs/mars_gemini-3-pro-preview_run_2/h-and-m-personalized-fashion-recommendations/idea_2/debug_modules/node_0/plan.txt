The following script demonstrates the end-to-end usage of the provided library components for the H&M recommendation task.

It performs the following steps:
1.  **Data Loading**: Loads the transaction history and splits it into training and validation sets. It subsamples the data to ensure the demonstration runs quickly.
2.  **Retrieval**: Uses `CooccurrenceRecommender` to generate candidate items based on purchase history.
3.  **Feature Engineering**: Uses `RankerDatasetBuilder` to create a dataset enriched with user, item, and visual features (using a pre-trained ResNet).
4.  **Ranking**: Trains an `LGBMRanker` to refine the candidate list.
5.  **Inference & Evaluation**: Generates predictions for test users, creates a submission file, and calculates the MAP@12 metric on the validation set.
