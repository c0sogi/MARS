The following script demonstrates the end-to-end usage of the provided library components for the toxicity classification task.

The strategy is as follows:
1.  **Configuration**: We override the default `Config` to enable `DEBUG` mode. This limits the dataset to 1000 samples and reduces the number of epochs to 1, ensuring the script runs quickly (within minutes) while exercising all code paths.
2.  **Data Loading**: We utilize `get_dataloaders` to process the raw text and metadata into PyTorch DataLoaders. We verify the structure and shapes of the batches produced.
3.  **Model Initialization**: We instantiate the `MultiTaskRoBERTa` model and perform a dummy forward pass to confirm that the output shapes (toxicity logits and identity logits) match the configuration.
4.  **Loss Verification**: We initialize the `HybridContrastiveLoss` and compute the loss on the dummy batch to ensure the ranking loss and auxiliary objectives are functioning correctly.
5.  **Metric Logic**: We explicitly test the `JigsawEvaluator` with synthetic data containing known bias patterns to verify that the competition metric calculation (including BPSN/BNSP AUCs) executes without error.
6.  **Training & Inference**: We run the full training engine (`train_one_epoch`), validation engine (`valid_fn`), and inference engine (`inference_fn`) using the debug data.
7.  **Submission**: Finally, we generate a submission file in the correct format.
