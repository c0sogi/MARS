Based on the lessons learned, specifically the effectiveness of linear probing on high-quality embeddings (Cite solution_lesson_node_00002) and the performance gains from using modern, high-capacity backbones (Cite solution_lesson_node_00006), I propose a **Hybrid Multi-Backbone Embedding Fusion** strategy.

This approach structurally evolves the previous idea by moving from a single feature extractor to a dual-architecture system. By combining a Convolutional Neural Network (CNN) with a Vision Transformer (ViT), we leverage the complementary strengths of local feature processing (CNN) and global context attention (ViT) to create a richer feature manifold for the classifier.

# Model
- **Dual-Backbone Feature Extractor**:
    - **Backbone A (CNN)**: Use **ConvNeXt-Large**, which was identified as a high-performance architecture in previous iterations (Cite solution_lesson_node_00006).
    - **Backbone B (Transformer)**: Introduce a **Vision Transformer (ViT-Large)** (e.g., `vit_large_patch16`) to capture long-range dependencies and global context that CNNs might miss.
    - Both backbones will be initialized with pre-trained ImageNet weights and kept **frozen** to maintain the efficiency of the linear probing paradigm (Cite solution_lesson_node_00002).
- **Fusion Layer**: The outputs from both backbones (Global Average Pooled vectors) will be concatenated into a single, high-dimensional feature vector.
- **Classifier**: A **Logistic Regression** head will be trained on this fused feature vector. This retains the calibrated probability outputs and convex optimization benefits verified in earlier attempts (Cite solution_lesson_node_00002).

# Data
- **Dual-Stream Preprocessing**:
    - Crucially, the input images will be processed twice, using the **specific preprocessing transforms** (resize, crop, normalization) associated with each respective backbone's pre-trained weights. This ensures that the input distribution for each model perfectly matches its pre-training conditions (Cite solution_lesson_node_00005).
- **No Training Augmentation**: We will continue to avoid augmentation during the training of the linear classifier to maintain a deterministic and stable baseline.

# Training
- **Feature Extraction with TTA**:
    - Iterate through the dataset once. For each image, generate two versions: the original and a horizontally flipped counterpart.
    - Pass both versions through Backbone A and Backbone B.
    - **Average** the original and flipped embeddings for Backbone A, and do the same for Backbone B. This applies the successful Feature-Level Test Time Augmentation strategy to both streams (Cite solution_lesson_node_00006).
- **Embedding Fusion**: Concatenate the averaged embedding from Backbone A with the averaged embedding from Backbone B.
- **Optimization**: Train the Logistic Regression classifier on the fused embeddings using the L-BFGS solver with L2 regularization.

# Evaluation
- **Inference Pipeline**:
    - Load test images and apply the dual-stream preprocessing.
    - Compute embeddings using the same "Extract -> Flip-Augment -> Average -> Concatenate" pipeline used during training.
    - Pass the final fused embeddings to the trained Logistic Regression model to predict class probabilities.
