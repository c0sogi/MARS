Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `library.config` to ensure paths, seeds, and hardware settings are consistent.
2.  **Data Preparation**: Load the metadata DataFrames for training, validation, and testing. Generate the class mapping using `library.dataset`.
3.  **Stream Processing (Iterative)**:
    *   **Stream A (ConvNeXt-Large)**:
        *   Initialize the specific transforms (`stream_a`) and DataLoaders.
        *   Load the backbone model and extract features for all splits (Train, Val, Test) using `library.extraction`. Use caching to avoid re-computation.
        *   Free GPU memory.
        *   Fuse the multi-view features (Global + Standard + Local) using `library.processing`.
        *   Train the `LogisticRegressionCV` classifier using `library.modeling`.
        *   Generate probability predictions for validation and test sets.
    *   **Stream B (DINOv2 ViT-Large)**:
        *   Repeat the process with `stream_b` specific transforms and backbone. This ensures the self-supervised features are extracted correctly.
4.  **Ensemble Optimization**:
    *   Use `library.ensemble` to find the optimal weights ($w_A, w_B$) that minimize Log Loss on the validation set.
    *   Compute the combined validation predictions and the **Final Validation Metric**.
5.  **Failure Analysis**:
    *   Calculate the per-sample Log Loss on the validation set.
    *   Analyze metadata correlations: Iterate through validation images to extract dimensions (Width, Height, Aspect Ratio) and compute their Pearson correlation with the error magnitude.
6.  **Submission Generation**:
    *   Check if the Final Validation Metric is strictly lower than the threshold (`0.11640673500383826`).
    *   If successful, compute the weighted test predictions and generate the `submission.csv` file using `library.ensemble`.
