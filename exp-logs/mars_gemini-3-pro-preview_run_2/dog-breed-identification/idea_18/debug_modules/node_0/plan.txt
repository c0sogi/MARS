4.  **Stream A Execution**: Run the full pipeline for the ConvNeXt stream: feature extraction (Global, Standard, Local views), fusion, training, and inference.
5.  **Stream B Execution**: Run the full pipeline for the RegNetY stream.
6.  **Ensemble & Submission**: Optimize ensemble weights using the validation predictions and generate the final submission CSV.
