Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Multi-View Hybrid-Head Strong-Learner Ensemble** strategy.

This approach structurally evolves the current best-performing "Multi-View Early Fusion" strategy (Lesson 00019) by addressing the inherent limitations of **Linear Probing** on complex manifolds (Lesson 00029). Instead of introducing a weaker secondary backbone (Lesson 00011, 00014), we will maximize the utility of the single strongest backbone (`ConvNeXt-Large`) by attaching two architecturally diverse classification heads: a **Linear Head** (to capture linearly separable semantics) and a **Non-Linear Head** (to capture complex feature interactions), strictly adhering to the feature conditioning protocols identified in previous failures.

# Model
- **Backbone Architecture:** We will utilize the **`ConvNeXt-Large`** architecture initialized with **`torchvision` "New Recipe" weights** (`IMAGENET1K_V1`). This retains the high-performance base estimator identified as superior to other variants and libraries (Cite solution_lesson_node_00006, solution_lesson_node_00011).
- **Hybrid Classification Heads:** Instead of a single classifier, we will branch the frozen feature stream into two independent, architecturally distinct heads:
    1.  **Linear Head:** A **`LogisticRegressionCV`** classifier. This provides a robust, well-calibrated baseline for the high-dimensional, linearly separable features typical of Supervised CNNs (Cite solution_lesson_node_00002).
    2.  **Non-Linear Head:** A **`HistGradientBoostingClassifier`** (Histogram-based Gradient Boosting).
        *   *Innovation:* This addresses the "Linear Probe Limit" (Cite solution_lesson_node_00029) by allowing the model to learn non-linear decision boundaries and complex interactions between the "Shape" (Global view) and "Texture" (Local view) features, which a simple linear combination cannot capture.
- **Feature Extraction:** We will replace the final classification layer with an Identity function, strictly retaining the architecture's native **Global Average Pooling and Layer Normalization**. This avoids the performance degradation observed when extracting raw feature maps (Cite solution_lesson_node_00025).

# Data
We will implement the successful **Multi-View Pipeline** that generates three distinct geometric representations for every image (Cite solution_lesson_node_00016).

1.  **Global View (Shape):** Resize to **224x224** (Squish). Preserves object topology.
2.  **Standard View (Context):** Resize to **232x232** and Center Crop to **224x224**. Matches standard pre-training.
3.  **Local View (Texture):** Resize to **288x288** and Center Crop to **224x224** (Zoom). Captures high-frequency details.
4.  **Interpolation:** We will explicitly enforce **Bicubic Interpolation** for all resizing operations to match the ConvNeXt training recipe (Cite solution_lesson_node_00032).

# Training
- **Feature Extraction & TTA:**
    - For every image, generate the three views.
    - Apply **Horizontal Flipping** to all inputs and average the embeddings of the original and flipped versions (Cite solution_lesson_node_00006).
- **Early Fusion (Concatenation):**
    - Concatenate the feature vectors from the Global, Standard, and Local views into a single high-dimensional representation (approx. 4608 dimensions).
    - We will **not** apply L2 normalization, preserving the magnitude signal for the Linear Head (Cite solution_lesson_node_00015).
- **Parallel Optimization:**
    - **Train Linear Head:** Fit `LogisticRegressionCV` on the concatenated features. The internal Cross-Validation will automatically tune the regularization parameter `C` (Cite solution_lesson_node_00021).
    - **Train Non-Linear Head:** Fit `HistGradientBoostingClassifier` on the *same* concatenated features. We will use a validation split to perform early stopping, preventing overfitting on the high-dimensional data.
- **Ensemble Weight Optimization:** Learn optimal scalar weights $(w_{linear}, w_{nonlinear})$ on the validation set to minimize the combined Log Loss. This ensures we leverage the non-linear head only where it provides additive signal (Cite solution_lesson_node_00014).

# Evaluation
- **Inference Pipeline:**
    1.  Load test images and apply the Global, Standard, and Local preprocessing (Bicubic).
    2.  Extract features for all views with Flip TTA.
    3.  Concatenate to match the training structure.
    4.  Generate probabilities $P_{linear}$ using the Logistic Regression head.
    5.  Generate probabilities $P_{nonlinear}$ using the Gradient Boosting head.
    6.  Compute final prediction: $P_{final} = w_{linear} \cdot P_{linear} + w_{nonlinear} \cdot P_{nonlinear}$.
