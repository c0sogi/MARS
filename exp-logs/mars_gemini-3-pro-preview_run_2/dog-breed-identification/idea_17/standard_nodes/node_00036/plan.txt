The implementation strategy follows the **Multi-View Hybrid-Head Strong-Learner Ensemble** design. The script `runfile.py` orchestrates the pipeline by leveraging the provided library modules.

1.  **Setup & Data Loading**: It initializes the environment with a fixed seed and loads the Train, Validation, and Test dataloaders using `data_loader.get_dataloaders`. The `debug` flag is set to `False` to ensure the full dataset is used for maximum performance, as the available A100 GPU can handle the workload within the time limit.
2.  **Feature Extraction**: It calls `feature_engine.extract_features` for all three splits. This function handles the multi-view generation (Global, Standard, Local), TTA (Horizontal Flip), and Early Fusion (concatenation). It utilizes disk caching to prevent redundant computation.
3.  **Model Training**: It instantiates the `HybridEnsemble` class. The `fit` method trains the **Linear Head** (Logistic Regression) and the **Non-Linear Head** (Histogram Gradient Boosting) in parallel on the high-dimensional fused features.
4.  **Ensemble Optimization**: The `optimize_weights` method is called with the validation set to find the optimal scalar weight that minimizes the Log Loss between the two heads.
5.  **Validation & Metrics**: The script prints the final validation Log Loss with full precision.
6.  **Failure Analysis**: It performs a failure analysis on the validation set by calculating the per-sample Log Loss and computing its Pearson correlation with the statistical properties (Mean, Std, Norm) of the input feature vectors to identify error patterns.
7.  **Submission**: If the validation metric is below the strict threshold of `0.11640673500383826`, it generates predictions for the test set and saves them to `submission.csv` using the `hybrid_model.generate_submission` function.
