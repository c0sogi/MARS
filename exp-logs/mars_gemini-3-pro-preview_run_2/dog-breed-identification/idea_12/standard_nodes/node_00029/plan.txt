Implementation strategy:
1.  **Setup**: Initialize the environment, set random seeds for reproducibility, and verify device availability (GPU).
2.  **Feature Extraction**:
    *   Utilize `feature_manager.extract_features` to compute embeddings for both Stream A (ConvNeXt-Large) and Stream B (EVA02-Large).
    *   Process both Training and Validation splits.
    *   This step implicitly handles the Multi-View generation (Global, Standard, Local) and TTA (Horizontal Flip) as defined in the library files.
3.  **Model Training**:
    *   Instantiate `StreamClassifier` (Logistic Regression with CV) for each stream.
    *   Train the classifiers independently on the extracted training embeddings.
4.  **Validation & Optimization**:
    *   Generate probability predictions for the validation set from both streams.
    *   Use `ensemble_optimizer.optimize_ensemble_weights` to find the optimal scalar weights ($w_A, w_B$) that minimize Log Loss on the validation set.
    *   Compute and print the **Final Validation Metric** with full precision.
5.  **Failure Analysis**:
    *   Calculate the Log Loss for each validation sample.
    *   Compute the correlation between error magnitude and class frequency in the training set to identify if data imbalance is a primary error driver.
    *   Print the hardest classes.
6.  **Submission**:
    *   Compare the validation metric against the strict threshold (`0.11640673500383826`).
    *   If the metric is lower (better), proceed to extract features for the Test set.
    *   Generate test predictions, blend them using the optimized weights, and save the result to `submission.csv`.
