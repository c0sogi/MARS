Implementation Strategy:
1.  **Configuration**: I will override the default configuration to ensure the script runs smoothly within the time limit. While the `DEBUG` flag is available, using it naively with the provided `data_loader.py` might cause `KeyError`s if the truncated training set misses classes present in the validation set. Given the powerful A100 GPU, processing the full dataset (approx. 10k images total) is feasible within minutes. Therefore, I will set `DEBUG = False` but force re-computation of embeddings to demonstrate the pipeline.
2.  **Setup**: Initialize the environment with fixed seeds and load the pre-trained ConvNeXt Large backbone model once to be shared across different views.
3.  **Multi-View Processing**: Iterate through the three defined views (`standard`, `global`, `local`). For each view:
    *   Initialize DataLoaders using the provided `data_loader` module.
    *   Extract embeddings for Train, Validation, and Test sets using `feature_extractor`. I will explicitly disable caching (`load_cached_data=False`) to ensure the code demonstrates the extraction process.
    *   Train a Logistic Regression classifier using `ensemble_logic`.
    *   Generate probability predictions for the validation set (for ensembling) and the test set (for submission).
4.  **Ensemble Optimization**: Use the validation predictions from all three views to calculate optimal weights that minimize Log Loss.
5.  **Submission Generation**: Compute the weighted average of the test predictions using the optimized weights. Construct a Pandas DataFrame with the correct schema (`id` column + 120 breed columns) and save it to the submission file.
6.  **Validation**: Include assertions throughout the script to verify tensor shapes, label consistency, and output file formats.
