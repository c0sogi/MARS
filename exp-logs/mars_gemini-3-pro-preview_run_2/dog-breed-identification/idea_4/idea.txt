Based on the provided lessons and the analysis of previous failures, I propose the following **Multi-Scale Homogeneous Ensemble** strategy. This approach focuses on extracting maximum performance from the single strongest architecture identified so far (`ConvNeXt-Large`) by explicitly modeling feature diversity through multi-scale input processing, rather than diluting the signal with inferior architectures.

# Model
- **Homogeneous Backbone**: We will utilize the **`ConvNeXt-Large`** architecture initialized with **`torchvision` "New Recipe" weights** (e.g., `IMAGENET1K_V1`). This adheres to the finding that this specific backbone and weight source significantly outperform alternatives like `timm` ports or EfficientNet (Cite solution_lesson_node_00011, solution_lesson_node_00014).
- **Independent Classifiers**: Instead of a single classifier, we will instantiate **three separate Logistic Regression heads**. Each head will be paired with a specific data processing pipeline (detailed below). This avoids the pitfalls of Early Fusion (concatenation) by allowing each linear model to converge optimally on its specific feature manifold (Cite solution_lesson_node_00009).

# Data
- **Multi-Scale Preprocessing Pipelines**: We will generate three distinct "views" of the dataset to capture complementary visual signals. This creates "variations of the strong model" as recommended to maximize ensemble gains (Cite solution_lesson_node_00014):
    1.  **Standard View (Balance)**: Resize images to **232px** and Center Crop to **224px**. This matches the native pre-training conditions.
    2.  **Global View (Shape/Context)**: Resize images directly to **224px** (no cropping) or Resize to 224px and Center Crop 224px. This ensures the **entire dog silhouette** is visible, aiding in classifying breeds defined by body shape rather than texture.
    3.  **Local View (Texture/Detail)**: Resize images to **288px** and Center Crop to **224px**. This effectively "zooms in" on the center, capturing high-frequency details (fur texture, facial features) critical for distinguishing similar breeds.
- **Feature-Level TTA**: For *each* of the three pipelines, we will apply **Feature-Level Test Time Augmentation**. We will extract embeddings for both the original and horizontally flipped versions of the image and **average them** before training. This reduces variance and improves the robustness of the embeddings (Cite solution_lesson_node_00006).

# Training
- **Parallel Linear Probing**: We will train the three Logistic Regression classifiers independently on the cached embeddings from their respective pipelines (Standard, Global, Local). We will use the L-BFGS solver with L2 regularization for efficiency and calibration (Cite solution_lesson_node_00002).
- **Ensemble Weight Optimization**: To address the risk of one view performing poorly and degrading the average (Cite solution_lesson_node_00012), we will **learn the optimal ensemble weights** on the validation set. We will use a scalar minimization algorithm (e.g., SLSQP or Nelder-Mead) to find the combination of weights $(w_1, w_2, w_3)$ that minimizes the Log Loss of the weighted average prediction.

# Evaluation
- **Weighted Late Fusion**:
    1.  Generate probability predictions for the test set using all three trained pipelines.
    2.  Combine the predictions using the optimized weights derived from the validation phase.
    3.  This **Prediction Ensembling** strategy ensures we leverage the diversity of the multi-scale views while strictly protecting against performance degradation via the weighting mechanism (Cite solution_lesson_node_00014).
