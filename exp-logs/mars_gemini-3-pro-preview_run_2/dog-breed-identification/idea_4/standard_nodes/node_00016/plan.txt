Implementation Strategy:
1.  **Setup & Initialization**: Initialize the environment with a fixed random seed to ensure reproducibility.
2.  **Backbone Loading**: Load the `ConvNeXt-Large` model with `IMAGENET1K_V1` weights once. This model will be reused for all three preprocessing views to maximize efficiency and minimize GPU memory overhead.
3.  **Multi-Scale Feature Extraction**:
    - Iterate through the three defined views: **Standard** (232px resize/224px crop), **Global** (224px squish), and **Local** (288px resize/224px crop).
    - For each view, create specific DataLoaders and extract embeddings for Train, Validation, and Test sets.
    - Utilize **Feature-Level Test Time Augmentation (TTA)** (averaging original and horizontally flipped embeddings) and caching to speed up subsequent runs.
4.  **Independent Classifier Training**: Train a separate Logistic Regression classifier for each of the three views using the extracted embeddings.
5.  **Ensemble Optimization**: Use the validation set predictions to optimize the scalar weights $(w_1, w_2, w_3)$ for the three classifiers, minimizing the Multi-Class Log Loss.
6.  **Validation & Failure Analysis**:
    - Compute the final weighted validation metric.
    - Perform failure analysis by correlating the per-sample Log Loss with image metadata (Width, Height, Aspect Ratio) to identify systematic weaknesses.
7.  **Submission Generation**: If the final validation metric is below the specified threshold (`0.12289895676177`), generate the final test predictions using the optimized ensemble weights and save the `submission.csv` file.
