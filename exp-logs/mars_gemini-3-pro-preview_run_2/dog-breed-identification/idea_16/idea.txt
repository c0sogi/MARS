Based on the analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Statistically Normalized Deep Feature Pyramid with Multi-View Early Fusion** strategy.

This approach structurally evolves the current best-performing "Multi-View Early Fusion" strategy (Lesson 00019) by revisiting the "Deep Feature Pyramid" concept (Lesson 00025). It specifically addresses the root cause of the previous failure—**poor feature conditioning**—by introducing a statistical normalization stage for intermediate features, ensuring they can be effectively integrated with the semantic features in a linear probing regime.

# Model
- **Backbone Architecture:** We will utilize the **`ConvNeXt-Large`** architecture initialized with **`torchvision` "New Recipe" weights** (`IMAGENET1K_V1`). This retains the high-performance base estimator identified as superior to other variants (Cite solution_lesson_node_00011).
- **Deep Feature Pyramid with Conditioning:** We will extract features from two distinct stages of the network to capture both high-level semantics and mid-level textures:
    1.  **Stage 4 (Semantic):** We will extract the final representation using the architecture's **native Global Average Pooling and Layer Normalization**. This preserves the distribution learned during pre-training (Cite solution_lesson_node_00025).
    2.  **Stage 3 (Texture):** We will extract the intermediate feature map and apply Global Average Pooling. **Crucially**, to address the "poor conditioning" failure observed in Lesson 00025, we will apply **Standard Scaling (Z-score normalization)** to these vectors. This aligns the distribution of the raw Stage 3 features (which lack a native LayerNorm) with the normalized Stage 4 features, preventing them from dominating or vanishing in the linear solver.
- **Classifier:** A single **`LogisticRegressionCV`** classifier will be trained on the fused feature space. This ensures automated tuning of the regularization parameter `C`, preventing the performance regression observed when using fixed hyperparameters (Cite solution_lesson_node_00021).

# Data
We will implement the successful **Multi-View Pipeline** that generates three distinct geometric representations for every image (Cite solution_lesson_node_00016).

1.  **Global View (Shape):** Resize to **224x224** (Squish). Preserves object topology.
2.  **Standard View (Context):** Resize to **232x232** and Center Crop to **224x224**. Matches standard pre-training.
3.  **Local View (Texture):** Resize to **288x288** and Center Crop to **224x224** (Zoom). Captures high-frequency details.
4.  **Interpolation Control:** We will explicitly enforce **Bicubic Interpolation** for all resizing operations. This corrects the regression observed in Lesson 00032 where reverting to Bilinear interpolation degraded ConvNeXt performance.

# Training
- **Feature Extraction & TTA:**
    - For every image, generate the three views.
    - Apply **Horizontal Flipping** to all inputs and average the embeddings of the original and flipped versions (Cite solution_lesson_node_00006).
    - Extract Stage 4 and Stage 3 features for all views.
- **Statistical Normalization:**
    - Compute the mean and standard deviation of the **Stage 3** features across the training set.
    - Apply `StandardScaler` to transform the Stage 3 features for both training and test sets. Leave Stage 4 features (which are natively normalized) untouched.
- **Early Fusion (Concatenation):**
    - Concatenate the feature vectors from all views and stages into a single high-dimensional representation: `[Global_S4, Global_S3_Norm, Standard_S4, Standard_S3_Norm, Local_S4, Local_S3_Norm]`.
    - This allows the linear classifier to learn correlations between global shape and properly conditioned local texture (Cite solution_lesson_node_00019).
- **Optimization:** Train `LogisticRegressionCV` on the concatenated embeddings using the L-BFGS solver.

# Evaluation
- **Inference Pipeline:**
    1.  Load test images and apply the Global, Standard, and Local preprocessing (Bicubic).
    2.  Extract Stage 4 (Native) and Stage 3 (Raw) features with Flip TTA.
    3.  Apply the pre-computed **StandardScaler** to the Stage 3 features.
    4.  Concatenate to match the training structure.
    5.  Pass the final vector to the trained `LogisticRegressionCV` model.
