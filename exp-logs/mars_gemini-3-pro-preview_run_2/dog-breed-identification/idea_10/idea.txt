Based on the comprehensive analysis of the "Lessons Learned," I propose the **Dual-Stream Heterogeneous Multi-View Ensemble with Robust Aggregation** strategy.

This approach synthesizes the highly successful "Multi-View Early Fusion" data strategy (Cite solution_lesson_node_00019) with a "Heterogeneous Backbone" architectural strategy. It strictly adheres to the integration protocols that failed in previous attempts by ensuring base estimator quality (Cite solution_lesson_node_00011), avoiding heterogeneous early fusion (Cite solution_lesson_node_00009), and preserving native feature normalization (Cite solution_lesson_node_00025).

# Model
We will construct a prediction system composed of two independent, high-capacity processing streams. This design leverages the complementary strengths of Convolutional Neural Networks (local texture) and Vision Transformers (global context) while maintaining optimal feature conditioning for each.

1.  **Stream A (CNN):** The **`ConvNeXt-Large`** architecture initialized with **`torchvision` "New Recipe" weights** (`IMAGENET1K_V1`). This retains the proven performance of the current best solution (Cite solution_lesson_node_00006).
2.  **Stream B (Transformer):** The **`ViT-Large-16`** (or Huge) architecture initialized with **SWAG weights** (`IMAGENET1K_SWAG_E2E_V1`). The selection of SWAG (Supervised Weakly from AGgregated hashtags) weights addresses the "weak base learner" failure of previous attempts by providing a transformer backbone that is competitive with ConvNeXt (Cite solution_lesson_node_00011).
3.  **Independent Classifiers:** Each stream will terminate in its own independent **`LogisticRegressionCV`** head. We will strictly avoid concatenating embeddings between streams (Early Fusion) to prevent feature space mismatch (Cite solution_lesson_node_00009).

# Data
We will implement a **Robust Multi-View Data Pipeline** for *each* stream. This evolves the previous "Multi-View" strategy by enhancing the "Local" view to be robust against object displacement.

1.  **View Generation:** For every image, we will generate three geometric representations:
    *   **Global View:** Resize to **224x224** (Squish). Preserves the complete object silhouette (Cite solution_lesson_node_00016).
    *   **Standard View:** Resize to **232x232** and Center Crop to **224x224**. Matches native pre-training conditions.
    *   **Robust Local View:** Resize to **288x288**. Instead of a single center crop, generate **Five Crops** (Top-Left, Top-Right, Bottom-Left, Bottom-Right, Center) of size **224x224**.
2.  **Stream-Specific Preprocessing:** Stream A and Stream B will use independent preprocessing transforms (interpolation, mean/std) that perfectly match their respective pre-training recipes (Cite solution_lesson_node_00005).

# Training
The training process combines **Intra-Stream Early Fusion** (for homogeneous data views) and **Inter-Stream Late Fusion** (for heterogeneous architectures).

1.  **Feature Extraction & TTA:**
    *   Apply **Horizontal Flipping** to all inputs (including all 5 crops for the Robust Local view).
    *   Extract embeddings for all views. **Crucially**, we will ensure the extraction process retains the architecture's native **Layer Normalization** and pooling layers (e.g., extracting the CLS token after the final LayerNorm for ViT, and the pooled output after the final LayerNorm for ConvNeXt) to avoid the performance degradation observed with raw feature maps (Cite solution_lesson_node_00025).
    *   For the Robust Local view, **average the embeddings** of the 5 crops (and their flips) to create a single stable feature vector (Cite solution_lesson_node_00006).
2.  **Intra-Stream Early Fusion:**
    *   For Stream A, **concatenate** the embeddings from the Global, Standard, and Robust Local views into a single feature vector. Do **not** apply L2 normalization (Cite solution_lesson_node_00015).
    *   Perform the same concatenation for Stream B.
    *   This allows the linear classifiers to learn correlations between shape (Global) and texture (Local) within a coherent feature space (Cite solution_lesson_node_00019).
3.  **Parallel Optimization:**
    *   Train a `LogisticRegressionCV` on Stream A's concatenated features.
    *   Train a `LogisticRegressionCV` on Stream B's concatenated features.
    *   Using Cross-Validation to tune `C` is critical to prevent underfitting (Cite solution_lesson_node_00021).
4.  **Ensemble Weight Optimization:** Learn optimal scalar weights $(w_A, w_B)$ on the validation set to minimize the combined Log Loss (Cite solution_lesson_node_00012).

# Evaluation
1.  **Weighted Late Fusion:**
    *   Generate probability predictions $P_A$ using the Stream A pipeline.
    *   Generate probability predictions $P_B$ using the Stream B pipeline.
    *   Compute the final prediction: $P_{final} = w_A \cdot P_A + w_B \cdot P_B$.
