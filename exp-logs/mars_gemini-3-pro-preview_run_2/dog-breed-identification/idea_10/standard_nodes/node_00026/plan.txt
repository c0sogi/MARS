Implementation Strategy:
The implementation orchestrates the "Dual-Stream Heterogeneous Multi-View Ensemble" pipeline. It uses the provided `StreamClassifier` to manage the heavy lifting of feature extraction (via `FeatureExtractor`) and logistic regression training.

1.  **Setup & Configuration**: Sets random seeds for reproducibility and ensures the library path is accessible.
2.  **Training Phase**:
    *   Iteratively trains Stream A (ConvNeXt-Large) and Stream B (ViT-Large) using `StreamClassifier.train_stream()`.
    *   This step automatically handles feature extraction (with caching), multi-view concatenation (Global + Standard + Robust), and `LogisticRegressionCV` fitting.
    *   We use the full dataset (`debug_sample_size=None`) because the feature-extraction-based approach is computationally efficient enough to run within the time limit on an A100 GPU, and using the full data is necessary to meet the strict validation metric threshold.
3.  **Ensemble Optimization**:
    *   Calls `StreamClassifier.optimize_ensemble()` to find the optimal scalar weights for combining the two streams, minimizing Log Loss on the validation set.
4.  **Validation & Metrics**:
    *   Prints the final validation metric with full precision as required.
5.  **Failure Analysis**:
    *   Computes the Log Loss contribution of each validation sample.
    *   Loads validation metadata and reads image dimensions (Width, Height, Aspect Ratio) from disk.
    *   Calculates and prints the Pearson correlation between the error magnitude and these image properties to identify systematic weaknesses.
6.  **Submission**:
    *   Checks if the validation metric is below the threshold (0.1164).
    *   If successful, generates the submission file using `StreamClassifier.generate_submission()`.
