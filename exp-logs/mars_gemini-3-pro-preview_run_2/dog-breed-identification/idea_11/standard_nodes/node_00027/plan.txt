The strategy implemented here is **Robust Multi-View Early Fusion with Spatial Aggregation**. This approach addresses the limitation of single-crop methods by introducing a robust "Local" view that aggregates features from five spatial crops (corners + center) and their horizontal flips. This ensures that high-frequency texture details are captured even if the subject is off-center. We combine this with a "Global" view (squished resize) for shape information and a "Standard" view (center crop) for context.

The pipeline proceeds as follows:
1.  **Feature Extraction**: For every image in the train, validation, and test sets, we extract features using a pre-trained **ConvNeXt-Large** backbone.
    *   **Global View**: Resized to 224x224 (squished).
    *   **Standard View**: Center cropped to 224x224.
    *   **Local View**: Five-crop aggregation (Center, TL, TR, BL, BR) resized from a larger 288px image.
    *   All views utilize Test Time Augmentation (Horizontal Flip).
2.  **Early Fusion**: The feature vectors from all three views are concatenated into a single high-dimensional representation (Dimension: $1536 \times 3 = 4608$).
3.  **Classification**: A **LogisticRegressionCV** classifier is trained on the fused features to automatically tune regularization strength.
4.  **Failure Analysis**: We analyze the correlation between validation error and class frequency to detect bias towards common breeds.
5.  **Submission**: Predictions are generated if the validation metric meets the success criteria.
