Based on the analysis of the previous execution and the provided lessons, I will implement the following optimization strategy:

1.  **Simplify the Pipeline (Cite Lesson 00014, 00012)**: Remove "Stream B" (ViT-Large) entirely. The previous run showed it performed significantly worse (Log Loss 0.4668) than Stream A (0.1263) and was effectively discarded by the ensemble. Focusing on the strong ConvNeXt backbone allows for faster iteration and reduced complexity.
2.  **Optimize Feature Extraction (Cite Lesson 00016, 00019)**:
    *   Retain the **Early Fusion** strategy (concatenating views).
    *   Enhance the "Local" view by increasing its resolution (Resize 360, Crop 288) to capture finer texture details, leveraging ConvNeXt's ability to handle varying input sizes.
    *   Fix the `get_model_transforms` function to correctly handle ConvNeXt weights or fallback reliably to the correct Bicubic interpolation and ImageNet normalization, eliminating the "Invalid weight name" errors.
3.  **Refine Classifier Regularization**: Switch from a fixed `C=1.0` to `C=0.35` for the Logistic Regression. Lesson 00019 found that `C ~ 0.36` was optimal for the concatenated feature vector (dimensionality ~4608), preventing overfitting.
4.  **Cache Management (Cite Lesson 00018)**: Update `WORKING_DIR` to `./working/idea_6` to ensure fresh embeddings are generated with the new "Local" view resolution.
