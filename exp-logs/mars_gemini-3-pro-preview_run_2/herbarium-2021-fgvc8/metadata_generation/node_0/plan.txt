The strategy for the implementation is as follows:
1.  **Setup and Imports**: Import necessary libraries (`json`, `pandas`, `os`, `sklearn`) and define constants for paths and random state.
2.  **Process Training Data**:
    -   Load `input/train/metadata.json`.
    -   Extract image information (IDs and file names) and annotation information (image IDs and category IDs) into Pandas DataFrames.
    -   Merge image and annotation data on `image_id`.
    -   Construct the full relative file path for each image by prepending `train/` to the `file_name` provided in the JSON (which already includes `images/...`).
    -   Ensure `image_id` and `category_id` are integers.
3.  **Create Validation Set**:
    -   Identify "rare" classes (classes with fewer than 2 samples) which cannot be stratified.
    -   Split the "common" classes into training (80%) and validation (20%) sets using stratified sampling to maintain class distribution.
    -   Add all samples from "rare" classes to the training set to avoid errors and ensure every class is represented in training.
    -   Shuffle the resulting datasets.
4.  **Process Test Data**:
    -   Load `input/test/metadata.json`.
    -   Extract image information into a DataFrame.
    -   Construct the full relative file path by prepending `test/` to the `file_name`.
    -   Ensure `image_id` is an integer.
5.  **Save Metadata**: Save the processed DataFrames to `metadata/train.csv`, `metadata/val.csv`, and `metadata/test.csv`.
6.  **Validation Checks**:
    -   Reload the saved CSVs.
    -   Print summary statistics (counts, unique classes).
    -   Perform a file existence check on a random sample of 1000 files from each dataset to ensure the constructed paths are correct relative to `./input`. Raise an error if >50% are missing.
    -   Verify that the validation split was performed correctly (e.g., check for data leakage or empty sets).
