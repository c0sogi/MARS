The following script demonstrates the usage of the provided library modules for the Herbarium 2021 plant classification task.

**Implementation Strategy:**
1.  **Configuration Setup**: We first import the `Config` class and override specific parameters (batch size, epochs, debug sample size) to ensure the demonstration runs quickly and uses a minimal amount of memory/compute. We set up a specific working directory for this demo.
2.  **Data Loading & Processing**: We verify the `HerbariumDataset` and `get_dataloaders` functions. We assert that the data loaders produce batches of the correct shape and that the multi-task labels (Species, Family, Order) are correctly formatted.
3.  **Taxonomy & Priors**: We validate the utility functions `load_taxonomy_mapping` and `compute_class_priors` to ensure they correctly process metadata and return data structures matching the expected dimensions (e.g., prior array length equals the number of classes).
4.  **Model Architecture**: We instantiate the `HierarchicalConvNeXt` model, perform a forward pass with a dummy batch, and verify that the output contains logits for all three hierarchical tasks (Species, Family, Order) with correct dimensions. We also test the backbone freezing/unfreezing logic.
5.  **Training Pipeline**: We execute the full `run_training_pipeline` on a tiny subset of data. This acts as an integration test for the training loop, loss calculation, backpropagation, and model checkpointing.
6.  **Inference & Submission**: Finally, we run `run_inference` to generate predictions on a test subset and verify that a valid `submission.csv` file is created.
