The issue is caused by the `DataLoader` converting the tuples returned by the `CutMixCollator` into lists when `pin_memory=True`. The `runfile.py` script contains a strict assertion checking if `targets["species"]` is a `tuple`, which fails when it receives a `list`. Since the training logic in `engine.py` and `loss.py` already supports both tuples and lists, the fix is to relax the assertion in `runfile.py` to accept either type.

    ), "Species target should be a tuple or list (target_a, target_b)"
