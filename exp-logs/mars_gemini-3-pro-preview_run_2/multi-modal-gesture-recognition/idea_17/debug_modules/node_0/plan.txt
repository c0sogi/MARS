Implementation Strategy:
1.  **Environment Setup**: create a dedicated working directory (`./working/demo_task`) with subdirectories for metadata, cache, and checkpoints to isolate the demo execution.
2.  **Data Subsetting**: Read the existing metadata files from `./metadata`, extract a small subset of samples (e.g., 20 training, 10 validation), and save these as new CSV files in the demo metadata directory. This ensures the data loading process is fast.
3.  **Configuration Override**: runtime-modify the `Config` class attributes to point to the new demo directories and reduce model hyperparameters (fewer layers, smaller hidden dimension, fewer epochs) to ensure the script completes quickly.
4.  **Component Verification**:
    *   **Utils**: Assert correctness of Levenshtein distance, decoding, and smoothing functions with known inputs.
    *   **Data**: Load the subset data using `load_data`, create a `GestureDataset`, and verify the shape of the features and labels in a batch.
    *   **Model & Loss**: Instantiate the `SG_CRCN` model (with reduced size) and `TotalLoss`, run a forward pass on a batch, and assert the output shapes and loss validity.
    *   **Training Loop**: Instantiate the `Trainer` and execute a short training run (2 epochs) to verify the end-to-end pipeline and checkpoint generation.
