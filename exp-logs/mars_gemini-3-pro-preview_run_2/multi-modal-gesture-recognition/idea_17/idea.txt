Based on the accumulated lessons, specifically the high performance of the Cascaded Recurrent-Convolutional architecture (Lesson 28, 75) and the specific failure modes associated with Gated Units (Lesson 82, 84) and Loss Configuration (Lesson 87), I propose the **Supervised Gated-Cascaded Recurrent-Convolutional Network (SG-CRCN)**.

This solution structurally evolves the current best approach by replacing the standard Residual TCN blocks with **Gated Activation Units**. While previous attempts at Gated TCNs failed, the analysis confirms these failures were due to implementation errors—specifically the lack of input normalization (Lesson 84) and the omission of explicit boundary supervision (Lesson 82)—rather than the architecture itself. By rigorously correcting these flaws and integrating the proven "Unclamped Smoothing" strategy (Lesson 87), this proposal aims to leverage the superior gating capability of Gated Units to dynamically regulate information flow during gesture transitions.

### Model
**Architecture: Supervised Gated-Cascaded Recurrent-Convolutional Network (SG-CRCN)**
The model consists of three sequentially connected stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Multi-Task Recurrent Encoder**
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain this backbone for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025) and high capacity (Cite solution_lesson_node_00034).
    *   **Input:** Frame-wise feature vector (Upper-Body Skeleton + Velocity + Audio), fused via simple concatenation (Cite solution_lesson_node_00062).
    *   **Heads:** The LSTM output is projected into two distinct streams:
        *   **Class Probabilities ($P_{cls}$):** 21 channels (Softmax).
        *   **Boundary Probability ($P_{bnd}$):** 1 channel (Sigmoid).
    *   **Output:** Concatenated tensor $[P_{cls}, P_{bnd}]$.

2.  **Inter-Stage Masking:**
    *   We explicitly multiply the concatenated output tensor by the binary sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Supervised Gated Refinement (Gated MS-TCN)**
    *   **Structural Innovation:** We replace the standard Dilated Residual Blocks (ReLU) with **Gated Activation Blocks** (WaveNet-style).
        *   **Mechanism:** For input $X$, the block computes $Z = \tanh(W_f * X) \odot \sigma(W_g * X)$.
        *   **Motivation:** The gating mechanism ($\sigma$) allows the network to dynamically "open" gates to update predictions during transitions (high $P_{bnd}$) and "close" them to enforce smoothness during stable gestures. This is more expressive than simple residual addition but requires the explicit boundary signal to function correctly (Cite solution_lesson_node_00082).
    *   **Configuration:** 10 dilated layers ($1, 2, \dots, 512$) with **256 channels**. We maintain high capacity (Cite solution_lesson_node_00078) and explicitly **exclude Instance Normalization** to preserve the magnitude of the sparse probability inputs (Cite solution_lesson_node_00066).
    *   **Input:** The masked tensor $[P_{cls}, P_{bnd}]$ from Stage 1.
    *   **Output:** Refined Class Probabilities ($P'_{cls}$) and Refined Boundary Probability ($P'_{bnd}$).

4.  **Stage 3: Fine Sharpening (Gated MS-TCN)**
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions ($P''_{cls}, P''_{bnd}$).

### Data
**Preprocessing:**
*   **Normalization (Crucial):** We will **center** the skeleton data relative to the HipCenter and explicitly **scale the units from millimeters to meters** (multiply by 0.001). This prevents the large-magnitude inputs from saturating the Tanh/Sigmoid functions in the Gated Units, addressing the numerical instability that caused previous failures (Cite solution_lesson_node_00084).
*   **Feature Selection:** Strictly limit inputs to **12 Upper-Body Joints** and **Audio MFCCs** (Cite solution_lesson_node_00020).
*   **Target Generation:** Generate ground-truth boundary labels ($Y_{bnd}$) where $1$ indicates a frame-to-frame label change.

**Augmentation:**
*   **Physically Consistent Smooth Noise:** We implement the temporally correlated noise pipeline.
    1.  Generate Gaussian noise and apply a **Temporal Low-Pass Filter**.
    2.  Add this smooth noise to the **Raw 3D Joint Positions**.
    3.  **Derive** the Temporal Velocity from the augmented positions.
    *   This ensures velocity features remain physically consistent with position features, avoiding the jitter caused by independent noise injection (Cite solution_lesson_node_00059, solution_lesson_node_00064).

**Evaluation Data:**
*   **Deterministic Split:** Instantiate the validation set with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

### Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification Loss:** Weighted Cross-Entropy with a strict ratio of **0.1 (Background) : 1.0 (Gesture)** (Cite solution_lesson_node_00013).
*   **Boundary Loss (Crucial):** Weighted Binary Cross-Entropy on the boundary heads. This provides the **explicit supervision** required to stabilize the Gated TCN gates, preventing the convergence failure observed when this signal was latent (Cite solution_lesson_node_00082).
*   **Unclamped Probability-Space Smoothing:** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities**. Crucially, we do **not clamp** the loss value (Cite solution_lesson_node_00087) and do not use Log-Softmax (Cite solution_lesson_node_00033).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4` (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize output smoothness (T-MSE weight) over aggressive parameter regularization (Cite solution_lesson_node_00068).

### Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax). This effectively merges fragmented segments (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to prevent the deletion of valid gestures at sequence edges (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse consecutive repeated labels and remove the background class.
