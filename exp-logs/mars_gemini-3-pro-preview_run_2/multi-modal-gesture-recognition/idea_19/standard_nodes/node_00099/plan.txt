The previous implementation generated a "jagged" CSV file by expanding the list of predicted gestures into variable numbers of comma-separated columns, which caused the CSV parser to fail (Cite debug_lesson_10). Additionally, it outputted the sample IDs as strings (e.g., "Sample00300") instead of the integer format (e.g., 300) required by the submission schema (Cite debug_lesson_17). The fix involves serializing the prediction list into a single space-separated string per row, sanitizing the IDs to integers, and using `pandas` to write a structured CSV file with the correct `Id,Sequence` header.
