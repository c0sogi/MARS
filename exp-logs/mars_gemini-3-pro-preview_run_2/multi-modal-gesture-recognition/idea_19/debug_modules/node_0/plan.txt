This script demonstrates the end-to-end usage of the provided library files. It performs the following steps:

1.  **Configuration Setup**: It overrides default `Config` parameters to create a lightweight execution environment suitable for a demo (reduced epochs, smaller model depth, temporary directories).
2.  **Data Subsetting**: It creates a temporary metadata directory and subsets the original CSV files (train, val, test) to only include a few samples. This ensures the data loading process runs quickly by avoiding the processing of the entire dataset.
3.  **Data Loading**: It utilizes `get_data_loaders` to load the subsetted data, verifying the shape and structure of the batches (features, labels, boundaries, masks).
4.  **Model Initialization**: It instantiates the `RSG_CRCN` model, performs a dummy forward pass to validate output shapes and deep supervision stages.
5.  **Training**: It initializes the `Trainer` and runs a short training loop (`fit`) to demonstrate the training and validation process, including loss calculation and metric tracking.
6.  **Utility Verification**: It includes unit tests for helper functions like `compute_levenshtein_distance` and `decode_predictions` to ensure their correctness.
