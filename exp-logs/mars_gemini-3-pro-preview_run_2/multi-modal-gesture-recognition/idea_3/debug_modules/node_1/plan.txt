The issue is caused by the use of `from library.config import *` in `library/data_loader.py`. This import statement copies the values of variables (like `BATCH_SIZE`) from the `config` module into the `data_loader` namespace at import time. When `runfile.py` subsequently modifies `config.BATCH_SIZE`, the `data_loader` module continues to use its local, stale copy (which remains 8), causing the assertion error when `runfile.py` expects a batch size of 2.

To fix this, `library/data_loader.py` should import the `config` module itself (`import library.config as config`) and access variables dynamically via the module reference (e.g., `config.BATCH_SIZE`). This ensures that any runtime updates to the configuration are reflected in the data loader.
