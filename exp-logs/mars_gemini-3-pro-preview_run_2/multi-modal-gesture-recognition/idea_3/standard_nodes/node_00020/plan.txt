3.  **Model Training**: I will instantiate the `HybridGestureNet` and the `Trainer`. I will execute the training loop using `trainer.fit()`, which handles the optimization and saves the best model based on validation loss.

Crucially, I will apply the same post-processing (Median Filtering) used in the inference pipeline to ensure the validation metric accurately reflects the model's test-time performance. I will compute the Levenshtein score and print it as `Final Validation Metric`.
5.  **Failure Analysis**: I will compute the Levenshtein distance for each validation sample and calculate the Pearson correlation between this error magnitude and the sequence length. This identifies if the model struggles with longer or shorter sequences.
6.  **Submission Generation**: I will check if the calculated validation metric is below the threshold of 0.424. If it is, I will call `library.inference.generate_submission` to create the submission file.
