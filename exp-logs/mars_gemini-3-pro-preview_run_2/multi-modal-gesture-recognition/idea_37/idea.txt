Based on the rigorous analysis of the accumulated lessons—specifically the state-of-the-art performance of **Gated Activation Units** (Cite solution_lesson_node_00099), the critical role of **1x1 Output Projections** (Cite solution_lesson_node_00107), the superiority of **Concatenation** for signal fusion (Cite solution_lesson_node_00109), and the importance of **Explicit Feature Engineering** (Cite solution_lesson_node_00113)—I propose the **Densely-Connected Supervised Gated-Cascaded Network (DCSG-CN)**.

This strategy structurally evolves the high-performing RSG-CRCN (Idea 19) by introducing **Dense Probability Connectivity** between the refinement stages. While previous models utilized a strict sequential chain (Stage 1 $\to$ Stage 2 $\to$ Stage 3), this solution concatenates the predictions of *all* preceding stages as input to the final sharpener. This allows the final stage to reconcile the strong semantic priors of the LSTM (Stage 1) with the temporally refined predictions of the TCN (Stage 2), mitigating the "forgetting" of semantic context that can occur in deep cascaded chains, while strictly adhering to the bottleneck and data hygiene constraints identified in previous failures.

# Model
**Architecture: Densely-Connected Supervised Gated-Cascaded Network (DCSG-CN)**
The model consists of a Recurrent Encoder and two Refinement Stages trained end-to-end with Deep Supervision and Dense Connectivity.

1.  **Stage 1: Multi-Task Recurrent Encoder**
    *   **Input:** Frame-wise feature vector containing **Upper-Body Skeleton Positions**, **Explicit Temporal Velocities**, and **Audio MFCCs**. We strictly retain explicit velocity features to provide a strong inductive bias for dynamics (Cite solution_lesson_node_00113).
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain this backbone for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025) and high capacity (Cite solution_lesson_node_00034).
    *   **Heads:** The LSTM output is projected into two distinct streams:
        *   **Class Probabilities ($P_{cls}^{(0)}$):** 21 channels (Softmax).
        *   **Boundary Probability ($P_{bnd}^{(0)}$):** 1 channel (Sigmoid).
    *   **Output:** Concatenated tensor $Out_0 = [P_{cls}^{(0)}, P_{bnd}^{(0)}]$.

2.  **Inter-Stage Masking:**
    *   We explicitly multiply the output tensors by the binary sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Gated Refinement**
    *   **Input:** $Out_0$.
    *   **Backbone:** **Gated MS-TCN** with **1x1 Output Projections**.
        *   **Block:** $Z = \tanh(W_f * X) \odot \sigma(W_g * X)$.
        *   **Projection:** $H = W_{proj} * Z$. We strictly retain this 1x1 projection to facilitate gradient flow and feature alignment (Cite solution_lesson_node_00107).
        *   **Residual:** $Y = X + H$.
    *   **Configuration:** 10 dilated layers with **Monotonically Increasing Dilation** ($1, 2, \dots, 512$) (Cite solution_lesson_node_00101). We maintain **256 channels** (Cite solution_lesson_node_00078) and explicitly **exclude Instance Normalization** (Cite solution_lesson_node_00066).
    *   **Output:** Refined probabilities $Out_1 = [P_{cls}^{(1)}, P_{bnd}^{(1)}]$.

4.  **Stage 3: Densely-Connected Gated Sharpening**
    *   **Dense Input (Structural Innovation):** Instead of receiving only $Out_1$, Stage 3 receives the concatenation of **both** previous outputs: $[Out_0, Out_1]$.
        *   **Motivation:** This provides the final sharpener with direct access to the LSTM's raw semantic predictions (high recall) alongside Stage 2's temporally consistent predictions (high precision). This "skip-connection" in probability space prevents over-smoothing and preserves semantic intent (Cite solution_lesson_node_00109).
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions $Out_2 = [P_{cls}^{(2)}, P_{bnd}^{(2)}]$.

# Data
**Preprocessing:**
*   **Defensive Data Loading:** Implement a robust parser that explicitly validates matrix dimensions and transposes if necessary, failing loudly on errors (Cite solution_lesson_node_00104, solution_lesson_node_00048).
*   **Normalization (Crucial):** Explicitly **center** the skeleton data relative to the HipCenter and **scale the units from millimeters to meters** (multiply by 0.001). This prevents saturation of the Gated Units (Cite solution_lesson_node_00084).
*   **Feature Selection:** Strictly limit inputs to **12 Upper-Body Joints** (Positions + Velocities) and **Audio MFCCs** (Cite solution_lesson_node_00020). We reject Bone Vectors to avoid feature bloat (Cite solution_lesson_node_00106).

**Augmentation:**
*   **Physically Consistent Augmentation:** Implement the temporally correlated noise pipeline.
    1.  Generate Gaussian noise and apply a **Temporal Low-Pass Filter**.
    2.  Add this smooth noise to the **Raw 3D Joint Positions**.
    3.  **Derive** the Temporal Velocity from the augmented positions.
    *   This ensures velocity features remain physically consistent with position features (Cite solution_lesson_node_00059, solution_lesson_node_00064).

**Evaluation Data:**
*   **Deterministic Split:** Instantiate the validation set with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification Loss:** Weighted Cross-Entropy with a strict ratio of **0.1 (Background) : 1.0 (Gesture)** (Cite solution_lesson_node_00013).
*   **Boundary Supervision:** **Binary Cross-Entropy** with **Sharp Targets** (1 at transition frames, 0 otherwise). This explicit supervision is essential for the Gated Units (Cite solution_lesson_node_00082, solution_lesson_node_00103).
*   **Unclamped Probability-Space Smoothing:** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities**. We do **not clamp** the loss (Cite solution_lesson_node_00087) and do not use Log-Softmax (Cite solution_lesson_node_00033).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4` (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize output smoothness (T-MSE weight) over aggressive parameter regularization (Cite solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax). This merges fragmented segments more effectively than probability filtering (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to prevent the deletion of valid gestures at sequence edges (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse consecutive repeated labels and remove the background class.
