This script demonstrates the usage of the provided machine learning library for the gesture recognition task. It performs the following steps:

1.  **Setup & Validation**: Verifies the logic of utility functions like Levenshtein distance and sequence post-processing.
2.  **Model Verification**: Instantiates the `GLT_CRCN` model and `DeepSupervisionLoss`, passes dummy data through them, and asserts that the output shapes and loss values are correct.
3.  **Data Pipeline Preparation**: Creates a small subset of the metadata (first 10 samples) to ensure the demonstration runs quickly. It dynamically patches the `DataLoaderConfig` to point to this subset.
4.  **Training Loop Execution**: Runs the `train_model` function for 1 epoch using the subset data, validating the training pipeline.
5.  **Inference Execution**: Runs `generate_submission` using the trained model on the subset test data, verifying the output format.
