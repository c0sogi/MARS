Based on the rigorous analysis of the accumulated lessons, specifically the state-of-the-art performance of **Gated Activation Units** with **Explicit Boundary Supervision** (Cite solution_lesson_node_00099, solution_lesson_node_00082), the critical role of **1x1 Output Projections** (Cite solution_lesson_node_00107), and the incompatibility of **Instance Normalization** with sparse signals (Cite solution_lesson_node_00066), I propose the **Convolutional-Recurrent Gated-Cascaded Network (CRG-CN)**.

This strategy structurally evolves the high-performing RSG-CRCN (Idea 19) by introducing a **Temporal Convolutional Stem** to the encoder. While previous solutions fed raw coordinate features directly into the LSTM, this innovation adds a learnable feature extraction layer to capture local micro-motion patterns and filter high-frequency noise *before* the recurrent modeling stage. This addresses the "jitter" problem at the source, while strictly adhering to the architectural constraints (No TCN Normalization, Sharp Supervision, Bottleneck interfaces) identified in previous failures.

# Model
**Architecture: Convolutional-Recurrent Gated-Cascaded Network (CRG-CN)**
The model consists of a Hybrid Encoder and two Refinement Stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Hybrid Multi-Task Encoder**
    *   **Input Stem (Structural Innovation):** A stack of **3 Temporal Convolutional Layers** (Kernel Size=3, Stride=1, Padding=1) with **Batch Normalization** and **ReLU** activation.
        *   *Motivation:* The LSTM backbone operates on frame-wise raw coordinates. By prepending a shallow CNN, we extract local temporal primitives (e.g., short-term velocity changes) and suppress sensor noise before the sequence modeling begins. Note: Batch Normalization is permitted here as it operates on dense raw features, unlike the sparse probabilities in the refinement stages (Cite solution_lesson_node_00066).
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units) processes the CNN output. We retain this for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025).
    *   **Heads:** The LSTM output is projected into two distinct streams:
        *   **Class Probabilities ($P_{cls}$):** 21 channels (Softmax).
        *   **Boundary Probability ($P_{bnd}$):** 1 channel (Sigmoid).
    *   **Output:** Concatenated tensor $[P_{cls}, P_{bnd}]$.

2.  **Inter-Stage Masking:**
    *   We explicitly multiply the concatenated output tensor by the binary sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Gated Refinement (Gated MS-TCN)**
    *   **Input:** Concatenated probabilities $[P_{cls}, P_{bnd}]$. We use concatenation as it outperforms explicit modulation (Cite solution_lesson_node_00109) and feature injection (Cite solution_lesson_node_00110).
    *   **Block Architecture:** **Gated Activation Blocks** with **1x1 Output Projections**.
        *   $Z = \tanh(W_f * X) \odot \sigma(W_g * X)$.
        *   $H = W_{proj} * Z$. **Crucial:** We strictly retain this projection to facilitate gradient flow and feature alignment, preventing the degradation observed when it was removed (Cite solution_lesson_node_00107).
        *   $Y = X + H$.
    *   **Configuration:** 10 dilated layers with **Monotonically Increasing Dilation** ($1, 2, \dots, 512$) (Cite solution_lesson_node_00101). We maintain **256 channels** (Cite solution_lesson_node_00078) and explicitly **exclude Instance Normalization** to preserve the magnitude of sparse probability inputs (Cite solution_lesson_node_00066).
    *   **Output:** Refined $[P'_{cls}, P'_{bnd}]$.

4.  **Stage 3: Gated Sharpening**
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions.

# Data
**Preprocessing:**
*   **Defensive Data Loading:** Implement a robust parser that explicitly validates matrix dimensions and transposes if necessary, failing loudly on errors (Cite solution_lesson_node_00104, solution_lesson_node_00048).
*   **Normalization (Crucial):** Explicitly **center** the skeleton data relative to the HipCenter and **scale the units from millimeters to meters** (multiply by 0.001). This prevents saturation of the Gated Units (Cite solution_lesson_node_00084).
*   **Feature Selection:** Strictly limit inputs to **12 Upper-Body Joints** and **Audio MFCCs** (Cite solution_lesson_node_00020).

**Augmentation:**
*   **Physically Consistent Augmentation:** Implement the temporally correlated noise pipeline.
    1.  Generate Gaussian noise and apply a **Temporal Low-Pass Filter**.
    2.  Add this smooth noise to the **Raw 3D Joint Positions**.
    3.  **Derive** the Temporal Velocity from the augmented positions.
    *   This ensures velocity features remain physically consistent with position features (Cite solution_lesson_node_00059, solution_lesson_node_00064). We avoid geometric rotation (Cite solution_lesson_node_00067).

**Evaluation Data:**
*   **Deterministic Split:** Instantiate the validation set with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification Loss:** Weighted Cross-Entropy with a strict ratio of **0.1 (Background) : 1.0 (Gesture)** (Cite solution_lesson_node_00013).
*   **Boundary Supervision:** **Binary Cross-Entropy** with **Sharp Targets** (1 at transition frames, 0 otherwise). This explicit supervision is essential for the Gated Units (Cite solution_lesson_node_00082, solution_lesson_node_00103).
*   **Unclamped Probability-Space Smoothing:** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities**. We do **not clamp** the loss (Cite solution_lesson_node_00087) and do not use Log-Softmax (Cite solution_lesson_node_00033).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4` (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize output smoothness (T-MSE weight) over aggressive parameter regularization (Cite solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax). This merges fragmented segments more effectively than probability filtering (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to prevent the deletion of valid gestures at sequence edges (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse consecutive repeated labels and remove the background class.
