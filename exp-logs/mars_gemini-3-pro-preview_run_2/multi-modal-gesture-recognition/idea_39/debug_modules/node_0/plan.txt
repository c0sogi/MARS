Implementation Strategy:
1.  **Configuration Patching**: Before importing the main logic modules (`trainer`, `inference`, `data_loader`), I will monkey-patch `library.config.get_hyperparams` and `library.config.PATHS`. This ensures that all subsequent imports utilize a "debug" configuration (small dataset subset, 1 epoch, reduced batch size) and write outputs to a dedicated `./working/demo_run` directory. This satisfies the speed and read-only input requirements.
2.  **Utility Verification**: I will demonstrate and verify the Levenshtein distance utility function with a known example to ensure metric calculation correctness.
3.  **Data Loading**: I will initialize the data loaders using the patched configuration. I will explicitly fetch a batch to verify the tensor shapes of the features (RGB+Depth+Audio), targets, and masks.
4.  **Model & Loss**: I will instantiate the `MG_CRGN` model and the `ActionSegmentationLoss`. I will perform a forward pass with the fetched batch and compute the loss, asserting that the output structures and loss scalar are valid.
5.  **Training Loop**: I will instantiate the `Trainer` class and run `fit()`. This will train the model for 1 epoch on the small subset. I will verify that a model checkpoint is saved.
6.  **Inference**: I will run the inference pipeline using `run_inference()`. This will load the just-trained checkpoint and generate a submission file. I will verify the existence and format of the submission CSV.
