The previous implementation generated a "jagged" CSV file by joining gesture predictions with commas, causing the number of columns to vary per row and crashing the grading system's parser (Cite debug_lesson_10). Additionally, the submission format (SessionID string vs. Integer ID) did not match the expected schema (Cite debug_lesson_17). The fix serializes the predictions into a single space-separated string column, adds the required `Id,Sequence` header, and sanitizes the `sample_id` to an integer to ensure a valid rectangular CSV format.
