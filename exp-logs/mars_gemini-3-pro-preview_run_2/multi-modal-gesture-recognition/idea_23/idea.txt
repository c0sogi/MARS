Based on the comprehensive analysis of the accumulated lessons, specifically the success of **Gated Activation Units** (Cite solution_lesson_node_00099), the importance of **Explicit Supervision** (Cite solution_lesson_node_00082), and the nuance that exact frame-level boundaries are often ill-defined (Cite solution_lesson_node_00077), I propose the **Symmetric Gated-Cascaded Recurrent-Convolutional Network (SymG-CRCN)** with **Soft-Boundary Supervision**.

This strategy structurally evolves the RSG-CRCN (Idea 19) by introducing a **Symmetric "Zoom-Out-Zoom-In" Dilation Architecture** to the refinement stages, resolving the trade-off between global context and local fidelity without the parallel branch failure observed in Lesson 101. Additionally, it introduces **Bone Vector** features and **Gaussian Soft-Targets** to robustly handle geometric and temporal ambiguity.

# Model
**Architecture: Symmetric Gated-Cascaded Recurrent-Convolutional Network (SymG-CRCN)**
The model consists of three sequentially connected stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Multi-Task Recurrent Encoder**
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain this backbone for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025).
    *   **Input:** Frame-wise feature vector (Upper-Body Skeleton + Velocity + **Bone Vectors** + Audio).
    *   **Heads:** Two output streams:
        *   **Class Probabilities ($P_{cls}$):** 21 channels (Softmax).
        *   **Boundary Probability ($P_{bnd}$):** 1 channel (Sigmoid).
    *   **Output:** Concatenated tensor $[P_{cls}, P_{bnd}]$.

2.  **Inter-Stage Masking:**
    *   Explicitly multiply the output tensor by the sequence mask to zero out padding (Cite solution_lesson_node_00035).

3.  **Stage 2: Symmetric Gated Refinement**
    *   **Structural Innovation:** We replace the standard "increasing dilation" stack with a **Symmetric Dilation Stack**.
        *   **Mechanism:** The stack follows a "Zoom-Out-Zoom-In" pattern: $d = \{1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 256, 128, \dots, 2, 1\}$.
        *   **Motivation:** Standard TCNs end with high dilation (global context), which can blur local boundaries. By symmetrically reducing dilation back to 1, the network re-integrates local fidelity at the output layers while retaining the global context aggregated in the middle layers. This sequential hierarchy outperforms the parallel multi-scale branches that failed in Lesson 101.
    *   **Block Type:** **Gated Activation Units** ($\tanh \odot \sigma$) to dynamically regulate information flow (Cite solution_lesson_node_00099).
    *   **Configuration:** 256 channels, **no Instance Normalization** (Cite solution_lesson_node_00066).
    *   **Input:** Masked tensor $[P_{cls}, P_{bnd}]$ from Stage 1.
    *   **Output:** Refined $[P'_{cls}, P'_{bnd}]$.

4.  **Stage 3: Symmetric Sharpening**
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions.

# Data
**Preprocessing:**
*   **Geometric Feature Expansion (Bone Vectors):** In addition to Joint Positions and Velocities, we explicitly compute **Bone Vectors** (the 3D vector difference between connected joint pairs, e.g., Elbow-Wrist). This provides the model with explicit orientation and shape information that is translation-invariant, enhancing the LSTM's ability to capture pose semantics.
*   **Normalization:** Explicitly **center** skeleton data relative to the HipCenter and **scale units to meters** (Cite solution_lesson_node_00084).
*   **Feature Selection:** Limit to **12 Upper-Body Joints** (plus derived bones) and **Audio MFCCs** (Cite solution_lesson_node_00020).

**Target Generation (Structural Innovation):**
*   **Soft Boundary Targets:** Instead of binary [0, 1] targets for the boundary head, generate **Gaussian-Smoothed Targets**.
    *   **Mechanism:** Place a Gaussian kernel ($\sigma \approx 1.5$ frames) at every ground-truth transition timestamp.
    *   **Motivation:** This addresses the conflict between Lesson 82 (Need Supervision) and Lesson 77 (Boundaries are Ambiguous). Soft targets provide a stable, differentiable signal that acknowledges the inherent uncertainty of the exact transition frame, preventing the model from overfitting to annotation noise.

**Augmentation:**
*   **Physically Consistent Smooth Noise:** Apply temporally correlated noise to raw positions, then derive velocity and bone vectors (Cite solution_lesson_node_00064).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification Loss:** Weighted Cross-Entropy (0.1 Background : 1.0 Gesture) (Cite solution_lesson_node_00013).
*   **Soft-Boundary Loss:** **Mean Squared Error (MSE)** or **Soft-BCE** between the predicted boundary probability and the **Gaussian Soft Targets**. This provides the necessary supervision for the Gated Units without forcing binary decisions.
*   **Unclamped Probability-Space Smoothing:** T-MSE on Softmax probabilities, unclamped (Cite solution_lesson_node_00087).
*   **Strict Masking:** Apply sequence masks to all losses (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** (`lr=1e-3`, `weight_decay=1e-4`) (Cite solution_lesson_node_00067).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using Stage 3 outputs.
2.  **Label-Space Smoothing:** Apply **Median Filter** to discrete class labels (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse repeats and remove background.
