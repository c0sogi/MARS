Based on the rigorous analysis of the accumulated lessons, specifically the superior performance of **Gated Activation Units** (Cite solution_lesson_node_00099), the critical necessity of **Explicit Boundary Supervision** (Cite solution_lesson_node_00082), the requirement for **1x1 Output Projections** (Cite solution_lesson_node_00107), and the failure of **Global Pooling** mechanisms in continuous segmentation (Cite solution_lesson_node_00108), I propose the **Boundary-Modulated Gated-Cascaded Network (BMG-CN)**.

This strategy structurally evolves the RSG-CRCN architecture by introducing a **Boundary-Modulated Gating Mechanism**. Instead of treating the boundary signal merely as an input feature or an auxiliary output, this architecture injects the supervised boundary probability directly into the gating equation of every refinement block. This creates a "hard-wired" attention mechanism where the network is architecturally biased to "open" its gates and update states rapidly during predicted transitions, while "closing" them to enforce smoothness during stable gesture segments.

# Model
**Architecture: Boundary-Modulated Gated-Cascaded Network (BMG-CN)**
The model consists of three sequentially connected stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Multi-Task Recurrent Encoder**
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain this backbone for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025) and high capacity (Cite solution_lesson_node_00034).
    *   **Input:** Frame-wise feature vector (Upper-Body Skeleton + Velocity + Audio), fused via simple concatenation (Cite solution_lesson_node_00062).
    *   **Heads:** The LSTM output is projected into two distinct streams:
        *   **Class Probabilities ($P_{cls}$):** 21 channels (Softmax).
        *   **Boundary Probability ($P_{bnd}$):** 1 channel (Sigmoid).
    *   **Output:** Concatenated tensor $[P_{cls}, P_{bnd}]$.

2.  **Inter-Stage Masking:**
    *   We explicitly multiply the concatenated output tensor by the binary sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Boundary-Modulated Gated Refinement**
    *   **Structural Innovation (Boundary-Modulated Block):** We modify the standard Gated Block to accept a conditioning signal.
        *   **Inputs:** Feature stream $X$ (from previous layer) and Boundary Signal $B$ (the $P_{bnd}$ output from the *previous stage*).
        *   **Modulated Gate:** $Gate = \sigma(W_g * X + W_{mod} * B)$. Here, $W_{mod}$ is a learnable 1x1 convolution that projects the boundary probability into the gating space. This allows the explicit boundary prediction to directly influence the information flow.
        *   **Filter:** $Filter = \tanh(W_f * X)$.
        *   **Activation:** $Z = Filter \odot Gate$.
        *   **Projection:** $H = W_{proj} * Z$. We strictly retain this 1x1 output projection to facilitate gradient flow and feature alignment (Cite solution_lesson_node_00107).
        *   **Residual:** $Y = X + H$.
    *   **Configuration:** 10 dilated layers with **Monotonically Increasing Dilation** ($1, 2, \dots, 512$) (Cite solution_lesson_node_00101). We maintain **256 channels** (Cite solution_lesson_node_00078) and explicitly **exclude Instance Normalization** (Cite solution_lesson_node_00066).
    *   **Input:** The masked tensor $[P_{cls}, P_{bnd}]$ from Stage 1.
    *   **Output:** Refined Class Probabilities ($P'_{cls}$) and Refined Boundary Probability ($P'_{bnd}$).

4.  **Stage 3: Boundary-Modulated Sharpening**
    *   **Backbone:** Identical to Stage 2, but uses $P'_{bnd}$ (from Stage 2) as the modulating signal.
    *   **Output:** Final predictions.

# Data
**Preprocessing:**
*   **Defensive Data Loading:** Implement a robust parser that explicitly validates matrix dimensions and transposes if necessary, failing loudly on errors (Cite solution_lesson_node_00104, solution_lesson_node_00048).
*   **Normalization (Crucial):** Explicitly **center** the skeleton data relative to the HipCenter and **scale the units from millimeters to meters** (multiply by 0.001). This prevents saturation of the Gated Units (Cite solution_lesson_node_00084).
*   **Feature Selection:** Strictly limit inputs to **12 Upper-Body Joints** and **Audio MFCCs** (Cite solution_lesson_node_00020). We reject Bone Vectors to avoid feature bloat (Cite solution_lesson_node_00106).

**Augmentation:**
*   **Physically Consistent Augmentation:** Implement the temporally correlated noise pipeline.
    1.  Generate Gaussian noise and apply a **Temporal Low-Pass Filter**.
    2.  Add this smooth noise to the **Raw 3D Joint Positions**.
    3.  **Derive** the Temporal Velocity from the augmented positions.
    *   This ensures velocity features remain physically consistent with position features (Cite solution_lesson_node_00059, solution_lesson_node_00064). We avoid aggressive geometric rotation (Cite solution_lesson_node_00067).

**Evaluation Data:**
*   **Deterministic Split:** Instantiate the validation set with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification Loss:** Weighted Cross-Entropy with a strict ratio of **0.1 (Background) : 1.0 (Gesture)** (Cite solution_lesson_node_00013).
*   **Boundary Supervision:** **Binary Cross-Entropy** with **Sharp Targets** (1 at transition frames, 0 otherwise) applied to the boundary head of *every* stage. This explicit supervision is mandatory to ensure the modulating signal $B$ is meaningful (Cite solution_lesson_node_00073, solution_lesson_node_00103).
*   **Unclamped Probability-Space Smoothing:** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities**. We do **not clamp** the loss (Cite solution_lesson_node_00087) and do not use Log-Softmax (Cite solution_lesson_node_00033). We do not condition this loss on the boundary prediction to avoid fragility (Cite solution_lesson_node_00070).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4` (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize output smoothness (T-MSE weight) over aggressive parameter regularization (Cite solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax). This merges fragmented segments more effectively than probability filtering (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to prevent the deletion of valid gestures at sequence edges (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse consecutive repeated labels and remove the background class.
