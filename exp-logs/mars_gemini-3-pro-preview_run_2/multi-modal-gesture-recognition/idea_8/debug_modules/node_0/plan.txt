The following script demonstrates the end-to-end usage of the provided library modules for the gesture recognition task. It performs the following steps:
1.  **Setup & Configuration**: Sets up a temporary working directory and overrides default configuration parameters (e.g., batch size, epochs, model dimensions) to ensure the demo runs quickly.
2.  **Data Preparation**: Creates small subsets of the training, validation, and test metadata to simulate a quick run.
3.  **Data Loading**: Uses `data_loader` to process the raw multi-modal data (Skeleton + Audio) from the subsets into PyTorch DataLoaders.
4.  **Model Initialization**: Instantiates the `DSR_CRCN` model and verifies the output shapes of a forward pass.
5.  **Training**: Runs a short training loop using the `Trainer` class, verifying that the loss decreases and a model checkpoint is saved.
6.  **Inference**: Generates predictions on the test subset using the trained model and saves them to a submission file.
7.  **Metric Verification**: Validates the Levenshtein distance metric calculation logic.
