The following script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition. It performs the following steps:

1.  **Configuration & Setup**: Overrides default hyperparameters (like epoch count) to ensure the demonstration runs quickly.
2.  **Data Loading**: Instantiates the `GestureDataset` with a small subset of data and verifies the structure of the batches produced by the `DataLoader`.
3.  **Model Execution**: Initializes the `GSG_CRCN` model, performs a forward pass with a sample batch, and validates the output shapes of the multi-stage architecture.
4.  **Loss Computation**: Calculates the loss using `DeepSupervisionLoss` and asserts that the loss values are valid scalars.
5.  **Training Loop**: Uses the `Trainer` class to run a single training and validation epoch, simulating a short training session.
6.  **Inference**: Saves a temporary checkpoint and runs the `generate_predictions` function to produce a submission file, verifying the output format.
