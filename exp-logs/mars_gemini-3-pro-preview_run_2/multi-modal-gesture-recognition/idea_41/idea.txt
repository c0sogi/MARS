Based on the comprehensive analysis of the accumulated lessons—specifically the accelerated convergence provided by **Explicit Geometric Features** (Cite solution_lesson_node_00121), the robustness of **Multi-Granularity Temporal Processing** (Cite solution_lesson_node_00120), and the critical need for **Modality-Specific Preprocessing** (Cite solution_lesson_node_00062)—I propose the **Dual-Stem Geometric Multi-Granularity Gated-Cascaded Network (DS-GMG-CN)**.

This strategy structurally evolves the high-potential "Geometric" architecture (Idea 40) by decoupling the Skeleton and Audio processing streams. While Idea 40 successfully accelerated convergence by adding Bone Vectors, it processed Audio and Skeleton features through a single shared convolutional stem. This is suboptimal because skeletal data (low-frequency motion) and audio MFCCs (spectral features) require different feature extraction priors. This solution introduces a **Dual-Stem** design to extract modality-specific primitives before fusion, while strictly adhering to the successful Gated TCN refinement pipeline.

# Model
**Architecture: Dual-Stem Geometric Multi-Granularity Gated-Cascaded Network (DS-GMG-CN)**
The model consists of a Dual-Stem Hybrid Encoder and two Refinement Stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Dual-Stem Hybrid Encoder**
    *   **Input Streams:**
        *   **Stream A (Geometric Skeleton):** Concatenation of **Normalized Positions ($P$)**, **Explicit Velocities ($V$)**, and **Bone Vectors ($B$)**. (Cite solution_lesson_node_00121, solution_lesson_node_00113).
        *   **Stream B (Audio):** **Audio MFCCs**.
    *   **Dual-Stem Processing (Structural Innovation):**
        *   **Skeleton Stem:** The geometric input flows into a **Multi-Granularity Convolutional Block** (Parallel Conv1Ds with kernels $k=3, 7, 11$). This captures motion dynamics at multiple temporal resolutions (jitter vs. gestures) (Cite solution_lesson_node_00120).
        *   **Audio Stem:** The audio input flows into a separate **Single-Scale Convolutional Block** (Conv1D, $k=3$). This isolates spectral feature extraction from kinematic processing.
    *   **Bottleneck Fusion:** The outputs of both stems are concatenated and passed through a **1x1 Convolutional Bottleneck**. This projects the high-dimensional multi-modal features into a compact representation for the LSTM, preventing parameter bloat (Addressing Cite solution_lesson_node_00106).
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units) processes the fused sequence (Cite solution_lesson_node_00025).
    *   **Heads:** Projects to **Class Probabilities ($P_{cls}$)** (21 ch) and **Boundary Probability ($P_{bnd}$)** (1 ch).

2.  **Inter-Stage Masking:**
    *   Explicitly multiply output tensors by the sequence mask to zero out padding (Cite solution_lesson_node_00035).

3.  **Stage 2: Gated Refinement (Gated MS-TCN)**
    *   **Input:** Concatenated probabilities $[P_{cls}, P_{bnd}]$. (Cite solution_lesson_node_00109).
    *   **Block Architecture:** **Gated Activation Blocks** ($\tanh \odot \sigma$) with **1x1 Output Projections**. We strictly retain the projection to facilitate gradient flow (Cite solution_lesson_node_00107).
    *   **Configuration:** 10 dilated layers ($1, 2, \dots, 512$), 256 channels (Cite solution_lesson_node_00078), **No Instance Norm** (Cite solution_lesson_node_00066).
    *   **Output:** Refined $[P'_{cls}, P'_{bnd}]$.

4.  **Stage 3: Gated Sharpening**
    *   **Connectivity:** Strictly Cascaded (Cite solution_lesson_node_00115).
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions.

# Data
**Preprocessing:**
*   **Defensive Data Loading:** Robust parser that validates matrix dimensions and fails loudly on errors (Cite solution_lesson_node_00104).
*   **Normalization:** Explicitly **center** skeleton relative to HipCenter and **scale units to meters** (Cite solution_lesson_node_00084).
*   **Feature Selection:** **12 Upper-Body Joints** (Pos + Vel + Bones) + **Audio** (Cite solution_lesson_node_00020).

**Augmentation:**
*   **Physically Consistent Augmentation:**
    1.  Generate Gaussian noise and apply **Temporal Low-Pass Filter**.
    2.  Add to **Raw Positions**.
    3.  **Derive** Temporal Velocity and Bone Vectors from augmented positions.
    *   This ensures all geometric features remain physically consistent (Cite solution_lesson_node_00059, solution_lesson_node_00064).

**Evaluation:**
*   **Deterministic Split:** Validation set with `is_train=False` (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification:** Weighted Cross-Entropy (0.1 Background : 1.0 Gesture) (Cite solution_lesson_node_00013).
*   **Boundary Supervision:** **Focal Loss** applied to boundary heads. This focuses learning on sparse transition frames, providing a sharper signal than BCE (Cite solution_lesson_node_00118, solution_lesson_node_00082).
*   **Smoothness:** **Unclamped T-MSE** on Softmax probabilities (Cite solution_lesson_node_00087).
*   **Masking:** Strict masking on all losses (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** (`lr=1e-3`, `weight_decay=1e-4`) (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize smoothness weight over parameter regularization (Cite solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Use Class Probability output of **Stage 3**.
2.  **Smoothing:** **Median Filter** on discrete labels (Cite solution_lesson_node_00049).
3.  **Padding:** **Nearest-Neighbor Padding** (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse repeats, remove background.
