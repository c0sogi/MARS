The issue is that `scipy.io.loadmat` returns a Python dictionary, not a structured object, even when `struct_as_record=False` is used. The code incorrectly attempts to access the top-level keys using `_fieldnames` (which does not exist on dicts) or dot notation (e.g., `mat_data.Video`). To fix this, I will modify `library/data_loader.py` to treat `mat_data` as a dictionary, using key lookup (`"Video" in mat_data` and `mat_data["Video"]`) instead of attribute access.
