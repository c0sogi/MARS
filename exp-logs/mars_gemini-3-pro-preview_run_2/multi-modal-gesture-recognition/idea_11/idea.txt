Based on the comprehensive analysis of previous experiments and the specific lessons learned (particularly the potential of Instance Normalization in Lesson 63 and the correction of augmentation errors in Lesson 64), I propose the **Normalized Masked Dual-Stage Cascaded Recurrent-Convolutional Network (NMD-CRCN) with Geometric Augmentation**.

This strategy structurally evolves the successful "Masked Cascaded" architecture (Idea 9) by integrating **Instance Normalization** into the refinement blocks to improve convergence and generalization, and by implementing a **Physically Consistent Geometric Augmentation** pipeline to robustly address the "user-independent" requirement without destroying signal integrity.

# Model
**Architecture: Normalized Masked Dual-Stage Cascaded Recurrent-Convolutional Network (NMD-CRCN)**
The model consists of three sequentially connected stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Generation (Recurrent Encoder)**
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain the RNN backbone to exploit its inductive bias for continuous temporal dynamics, which proved superior to Transformers and Gated Units for this task (Cite solution_lesson_node_00025, solution_lesson_node_00062).
    *   **Input:** Frame-wise feature vector (Upper-Body Skeleton + Velocity + Audio), fused via simple concatenation (Cite solution_lesson_node_00062).
    *   **Output:** Initial frame-wise Softmax probabilities ($P_0$).

2.  **Inter-Stage Masking:**
    *   **Operation:** We explicitly multiply the probability tensor by the binary sequence mask between stages. This ensures that padding frames are strictly zeroed out, preventing "ghost" activations from propagating into the receptive field of the subsequent TCN (Cite solution_lesson_node_00035).

3.  **Stage 2: Coarse Refinement (Normalized Deep TCN)**
    *   **Structural Innovation:** A **Single-Stage Temporal Convolutional Network (SS-TCN)** with **10 dilated residual layers** ($dilation=1, 2, \dots, 512$). Crucially, we introduce **Instance Normalization** layers after every dilated convolution. This stabilizes feature distributions across the temporal dimension, enabling faster convergence and more efficient learning compared to unnormalized counterparts (Cite solution_lesson_node_00063).
    *   **Input:** The masked Softmax probabilities ($P_0$) from Stage 1.
    *   **Output:** Refined probabilities ($P_1$).

4.  **Stage 3: Fine Sharpening (Normalized Deep TCN)**
    *   **Backbone:** Identical to Stage 2 (Instance Normalized Deep TCN). This second pass focuses on sharpening boundaries and correcting residual jitter.
    *   **Input:** The masked Softmax probabilities ($P_1$) from Stage 2.
    *   **Output:** Final probabilities ($P_2$).

# Data
**Preprocessing:**
*   **Feature Selection:** We will strictly limit skeletal inputs to the **12 Upper-Body Joints** (Head, Shoulders, Elbows, Wrists, Hands, Spine, HipCenter) and **Audio MFCCs**, discarding lower-body noise (Cite solution_lesson_node_00020).
*   **Defensive Loading:** Explicitly handle matrix dimension transpositions during data loading to prevent semantic corruption (Cite solution_lesson_node_00048).

**Augmentation (Structural Innovation):**
*   **Physically Consistent Geometric Pipeline:** We fundamentally restructure the augmentation process to address the failures of independent noise injection.
    1.  **Geometric Transformation:** Apply random **3D Rotations** (simulating different camera view angles) and **Uniform Scaling** (simulating different user heights) to the **raw 3D Joint Positions** ($P$).
    2.  **Dynamic Derivation:** Re-calculate the **Temporal Velocity** ($V = \Delta P_{augmented}$) *after* the geometric transformation.
    *   This ensures that the velocity features remain physically consistent with the position features, avoiding the high-frequency jitter caused by independent noise injection (Cite solution_lesson_node_00059, solution_lesson_node_00064).
*   **Normalization:** Apply Root-Relative normalization to the augmented positions (Cite solution_lesson_node_00004).

**Validation:**
*   **Deterministic Split:** The validation dataset will be instantiated with **augmentation disabled** (`is_train=False`) to ensure stable checkpoint selection (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = L_{gen} + L_{ref1} + L_{ref2}$.
*   **Aggressive Class Weighting:** Use Weighted Cross-Entropy with a ratio of **0.1 (Background) : 1.0 (Gesture)** to prevent background collapse (Cite solution_lesson_node_00013).
*   **Probability-Space Smoothing (T-MSE):** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities** (not Log-Softmax) of Stage 2 and 3. This enforces smoothness without the gradient instability associated with log-space losses (Cite solution_lesson_node_00033).
*   **Strict Masking:** Apply sequence masks to all loss calculations to exclude padding (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** Adam with a learning rate of **1e-3** to ensure TCN convergence (Cite solution_lesson_node_00049).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the output of **Stage 3** ($P_2$).
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax), effectively merging fragmented segments (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to preserve start/end gestures (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse repeats and remove background labels.
