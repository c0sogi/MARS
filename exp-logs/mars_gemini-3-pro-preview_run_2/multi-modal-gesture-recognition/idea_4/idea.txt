Based on the comprehensive analysis of previous attempts and the extracted lessons, I propose a **Temporal Transformer** approach. This strategy structurally evolves from the recurrent (Bi-LSTM) and convolutional (MS-TCN) paradigms tried previously, replacing them with a Self-Attention mechanism to better capture global temporal dependencies while strictly adhering to the feature engineering constraints identified as critical for success.

# Model
**Architecture: Temporal Transformer Encoder**
We will replace the recurrent backbone with a **Transformer Encoder** architecture. While the Bi-LSTM (Idea 1) proved effective at capturing local dynamics, it struggles with long-range dependencies and parallelization. The Transformer's self-attention mechanism allows every frame to attend to every other frame in the sequence, enabling the model to resolve ambiguous states (e.g., the middle of a gesture) by directly referencing the start and end phases, effectively reducing the "jitter" observed in RNNs.

*   **Input Embedding:** The frame-wise feature vector is projected to a higher-dimensional latent space via a Linear layer.
*   **Positional Encoding:** Since Transformers are permutation-invariant, we will inject **Sinusoidal Positional Encodings** to preserve the temporal order of the sequence.
*   **Encoder Blocks:** A stack of `N` Transformer Encoder layers. Each layer consists of:
    *   **Multi-Head Self-Attention:** To capture relationships between distant frames.
    *   **Feed-Forward Network:** To process features point-wise.
    *   **Residual Connections & Layer Normalization:** To facilitate stable gradient flow.
*   **Classification Head:** A final Linear layer maps the encoder output to 21 class logits (20 gestures + 1 background) for each frame.

# Data
**Preprocessing:**
*   **Feature Selection (Crucial):** We will strictly limit the skeletal input to the **12 Upper-Body Joints** (Head, Shoulders, Elbows, Wrists, Hands, Spine, HipCenter). We will **discard lower-body joints** to eliminate the noise that caused the failure of the Hybrid model (Cite solution_lesson_node_00020).
*   **Normalization & Dynamics:** Joint coordinates will be normalized relative to the `HipCenter` to ensure user independence, and we will explicitly concatenate the **temporal velocity** (first derivative) of these coordinates to capture motion dynamics (Cite solution_lesson_node_00004).
*   **Audio Fusion:** We will retain the Audio MFCC features, concatenated with the skeletal features, as they provided a robust signal in the baseline.

**Validation Strategy:**
*   **Deterministic Evaluation:** The validation dataset will be instantiated with **augmentation disabled** (`is_train=False`). This is non-negotiable to prevent the metric instability observed in previous runs (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Aggressive Class Weighting:** We will employ Weighted Cross-Entropy Loss with a strict ratio: **0.1 for the Background class and 1.0 for Gesture classes**. This aggressive down-weighting of the majority class is essential to prevent the "background collapse" observed in the MS-TCN experiment (Cite solution_lesson_node_00013).

**Optimization:**
*   **Regularization:** We will apply **Gaussian Noise** to the skeletal input features during training to prevent overfitting and encourage the learning of robust motion patterns (Cite solution_lesson_node_00006).
*   **Monitoring:** We will monitor the **Validation Loss** for convergence to avoid the pitfalls of discrete metric fluctuations (Cite solution_lesson_node_00010), while periodically checking the Levenshtein score to ensure alignment (Cite solution_lesson_node_00008).

# Evaluation
**Inference Pipeline:**
1.  **Prediction:** The model generates frame-wise probability distributions for the test sequence.
2.  **Temporal Smoothing:** We will apply a **Median Filter** to the predicted class indices to remove high-frequency jitter. Crucially, we will use **Nearest-Neighbor Padding** (replicating boundary values) instead of zero-padding to prevent the deletion of valid gestures at the start/end of sequences (Cite solution_lesson_node_00009).
3.  **Decoding:** A greedy decoding strategy (argmax) followed by collapsing consecutive repeats and removing the background class will be used to generate the final submission.
