This strategy structurally evolves the high-performing RSG-CRCN (Idea 19) by integrating **Geometric Feature Expansion** (Bone Vectors) to capture translation-invariant pose structure and **Hierarchical Supervision** (Foreground Presence) to robustly address background dominance. Crucially, it rigorously corrects the implementation flaws of previous attempts by enforcing **Simplified Gated Blocks** and **Defensive Data Ingestion**.

# Model
**Architecture: Geometric Hierarchical Gated-Cascaded Recurrent-Convolutional Network (GHG-CRCN)**
The model consists of three sequentially connected stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Geometric Recurrent Encoder**
    *   **Feature Expansion (Structural Innovation):** In addition to Joint Positions ($P$) and Temporal Velocities ($V$), we explicitly compute **Bone Vectors** ($B$). For every connected pair of joints (e.g., Elbow-Wrist), we calculate the 3D vector difference. This provides a translation-invariant representation of body shape and orientation, enhancing the signal-to-noise ratio (Cite solution_lesson_node_00020).
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain this backbone for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025) and high capacity (Cite solution_lesson_node_00034).
    *   **Input:** Concatenated vector $[P_{norm}, V, B, Audio_{MFCC}]$.
    *   **Heads:** The LSTM output is projected into **three** distinct streams to enforce hierarchical feature learning:
        *   **Class Probabilities ($P_{cls}$):** 21 channels (Softmax).
        *   **Boundary Probability ($P_{bnd}$):** 1 channel (Sigmoid).
        *   **Foreground Probability ($P_{fg}$):** 1 channel (Sigmoid). This explicit "Presence" signal reinforces background suppression and helps the model distinguish "silence" from "gesture" (Cite solution_lesson_node_00013).
    *   **Output:** Concatenated tensor $[P_{cls}, P_{bnd}, P_{fg}]$.

2.  **Inter-Stage Masking:**
    *   We explicitly multiply the concatenated output tensor by the binary sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Hierarchical Gated Refinement (Gated MS-TCN)**
    *   **Block Architecture (Simplified):** We employ **Simplified Gated Activation Blocks**.
        *   Structure: $Z = \tanh(W_f * X) \odot \sigma(W_g * X)$.
        *   Residual: $Y = X + Z$.
        *   **Crucial Correction:** We explicitly **remove the 1x1 output projection layer** in the residual path. This direct identity mapping facilitates better gradient flow and is easier to optimize for limited data, correcting the complexity failure of previous attempts (Cite solution_lesson_node_00103).
    *   **Gating Mechanism:** The gates ($\sigma$) are supervised by the Boundary and Foreground signals (passed in the input), allowing the network to dynamically "open" for transitions and "close" for smoothing.
    *   **Configuration:** 10 dilated layers with **Monotonically Increasing Dilation** ($1, 2, \dots, 512$) to maximize receptive field (Cite solution_lesson_node_00101). We maintain **256 channels** (Cite solution_lesson_node_00078) and explicitly **exclude Instance Normalization** to preserve sparse signal magnitude (Cite solution_lesson_node_00066).
    *   **Input:** The masked tensor $[P_{cls}, P_{bnd}, P_{fg}]$ from Stage 1.
    *   **Output:** Refined $[P'_{cls}, P'_{bnd}, P'_{fg}]$.

4.  **Stage 3: Hierarchical Gated Sharpening**
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions.

# Data
**Preprocessing:**
*   **Defensive Data Loading (Crucial):** Implement a robust parser that explicitly validates matrix dimensions (e.g., checking if `Joints` dimension is 20) and transposes if necessary. **Fail loudly** with an error if data cannot be parsed, rather than substituting zeros (Cite solution_lesson_node_00104, solution_lesson_node_00048).
*   **Normalization:** Explicitly **center** the skeleton data relative to the HipCenter and **scale the units from millimeters to meters** (multiply by 0.001). This prevents saturation of the Gated Units (Cite solution_lesson_node_00084).
*   **Feature Selection:** Strictly limit inputs to **12 Upper-Body Joints** and **Audio MFCCs** (Cite solution_lesson_node_00020).

**Augmentation:**
*   **Physically Consistent Geometric Augmentation:** Implement the temporally correlated noise pipeline.
    1.  Generate Gaussian noise and apply a **Temporal Low-Pass Filter**.
    2.  Add this smooth noise to the **Raw 3D Joint Positions**.
    3.  **Derive** Temporal Velocity and Bone Vectors from the augmented positions.
    *   This ensures all geometric features remain physically consistent (Cite solution_lesson_node_00059, solution_lesson_node_00064).

**Evaluation Data:**
*   **Deterministic Split:** Instantiate the validation set with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{fg}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification Loss:** Weighted Cross-Entropy with a strict ratio of **0.1 (Background) : 1.0 (Gesture)** (Cite solution_lesson_node_00013).
*   **Boundary Supervision:** **Binary Cross-Entropy** with **Sharp Targets** (1 at transition frames, 0 otherwise). We reject Soft Gaussian targets to ensure strong gradient signals (Cite solution_lesson_node_00103).
*   **Foreground Supervision:** **Binary Cross-Entropy** where target is 1 if label $\neq$ Background, else 0.
*   **Unclamped Probability-Space Smoothing:** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities**. We do **not clamp** the loss (Cite solution_lesson_node_00087) and do not use Log-Softmax (Cite solution_lesson_node_00033).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4` (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize output smoothness (T-MSE weight) over aggressive parameter regularization (Cite solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax). This merges fragmented segments more effectively than probability filtering (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to prevent the deletion of valid gestures at sequence edges (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse consecutive repeated labels and remove the background class.
