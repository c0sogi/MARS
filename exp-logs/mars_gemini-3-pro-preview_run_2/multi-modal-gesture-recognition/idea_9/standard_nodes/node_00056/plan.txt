The implementation strategy focuses on enhancing the model's generalization capabilities and input robustness, addressing the overfitting observed in the previous run where validation loss began to rise while the error rate plateaued.

1.  **Input Normalization**: Introduce `nn.LayerNorm` at the input of the `BiLSTMEncoder`. The skeleton data is in millimeters (range ~[-1000, 1000]), which can saturate gradients or slow convergence. Layer normalization ensures the network receives inputs with standardized statistics (Cite **Lesson 00048** regarding handling input dimensions/scales correctly).
2.  **Data Augmentation**: Implement on-the-fly Gaussian noise injection for skeleton features within the `GestureDataset`. This acts as a regularizer to prevent the model from memorizing exact coordinate trajectories. Crucially, this augmentation is applied **only** to the training split to ensure deterministic validation (Cite **Lesson 00006** for noise augmentation and **Lesson 00011** for deterministic validation).
3.  **Regularization**: Increase dropout rates in both the LSTM and TCN layers from 0.3 to 0.5 to further mitigate overfitting.
