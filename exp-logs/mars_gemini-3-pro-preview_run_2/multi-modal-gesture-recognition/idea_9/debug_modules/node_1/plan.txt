The `CUDA error: device-side assert triggered` is caused by an index out-of-bounds access within the Cross Entropy loss kernel on the GPU. The data loader pads variable-length label sequences with `-1` (in `collate_fn`), but `F.cross_entropy` defaults to ignoring only the index `-100`. Consequently, the loss function treats `-1` as a valid class index, causing the kernel to crash when attempting to access class weights or logits at that invalid index. Even though the code subsequently applies a mask to zero out the loss, the crash happens during the initial unmasked computation. The fix is to explicitly pass `ignore_index=-1` to `F.cross_entropy` in `library/loss.py`, ensuring PyTorch skips computation for padded frames.
