The `RuntimeError` is caused by passing an invalid mode string `"edge"` to `scipy.ndimage.median_filter`. The `scipy.ndimage` library does not support `"edge"`; the correct mode for replicating the boundary pixels (nearest-neighbor padding) is `"nearest"`. I will correct the `pad_mode` value in `library/config.py` to `"nearest"`.
