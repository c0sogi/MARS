The `RuntimeError` occurs because the `logits` tensor passed to the loss function is non-contiguous (due to a `.permute()` operation in the `SingleStageTCN` model), and `.view()` strictly requires contiguous memory layout. As detailed in **Cite debug_lesson_9**, operations like `.permute()` or `.transpose()` only modify strides without moving data, leading to this incompatibility. The fix is to replace `.view()` with `.reshape()`, which handles non-contiguous tensors automatically by creating a copy if necessary. I will apply this fix to both `calc_masked_weighted_ce` and `calc_masked_weighted_bce` in `library/losses.py` to ensure robustness.
