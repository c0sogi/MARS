The implementation strategy involves the following steps:

1.  **Environment Setup**: Import necessary standard libraries and the provided modules from the `library` package. Set the random seed for reproducibility.
2.  **Model Training**: Invoke the `run_training` function from `library.train`. To balance the "fast baseline" requirement with the strict performance threshold, the script will use the full dataset (`max_samples=None`) but limit the training to 20 epochs. This ensures the model converges sufficiently on the A100 GPU without exceeding the time limit.
3.  **Validation & Metric Calculation**:
    *   Load the validation ground truth from `metadata/val.csv`.
    *   Use the `Predictor` class to generate predictions on the validation set.
    *   Calculate the Levenshtein distance between predicted and true gesture sequences for each sample.
    *   Compute the final error rate metric ($\frac{\sum \text{Distance}}{\sum \text{Total Gestures}}$) and print it with full precision.
4.  **Failure Analysis**:
    *   Correlate the individual sample errors with sequence length (frames) and sequence complexity (number of gestures) using Pearson correlation.
    *   Print these correlations to reveal systematic failure modes.
5.  **Conditional Submission**:
    *   Check if the validation metric is strictly lower than the threshold `0.06789606035205364`.
    *   If successful, call `run_inference` to generate predictions for the test set and save them to `submission/submission.csv`.
