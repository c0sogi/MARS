The issue stems from using `pd.read_csv` to validate the submission file. The submission format (`SessionID,label1,label2,...`) results in a "jagged" CSV where rows have a variable number of columns depending on the number of detected gestures. Pandas expects a fixed number of columns (rectangular data) and raises a `ParserError` when it encounters rows with different field counts. The fix is to replace the pandas-based reading logic in `runfile.py` with standard Python file I/O to read the file line-by-line, which naturally handles variable line lengths while still allowing validation of the `SessionID` and content format.
