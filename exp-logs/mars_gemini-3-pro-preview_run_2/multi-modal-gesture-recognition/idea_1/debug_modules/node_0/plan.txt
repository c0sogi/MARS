The following script demonstrates the end-to-end pipeline for the gesture recognition task using the provided library files.

**Implementation Strategy:**
1.  **Configuration Setup**: We import the `Config` class and override specific hyperparameters (e.g., `NUM_EPOCHS`, `DEBUG_SUBSET_SIZE`, `BATCH_SIZE`) to ensure the demonstration runs quickly on a small subset of data.
2.  **Utility Verification**: We explicitly test the metric calculation (`compute_levenshtein`) and prediction decoding (`decode_predictions`) functions with synthetic data to guarantee their logic is correct before running the full pipeline.
3.  **Data Loading**: We utilize `get_dataloaders` with the debug flag enabled. We assert the correctness of the batch shapes (features, labels, lengths) produced by the `GestureDataset` and `pad_collate` function.
4.  **Model Initialization & Forward Pass**: We instantiate the `BiLSTMClassifier` and perform a dummy forward pass with a single batch to verify the output tensor dimensions match the expected `(Batch, Time, Num_Classes)`.
5.  **Training Execution**: We run the full training loop using `run_training`. This demonstrates the interaction between the `Trainer`, `Model`, and `DataLoader`, resulting in a saved model checkpoint.
6.  **Inference & Submission**: We execute `run_inference` to generate predictions on the test set using the trained checkpoint. Finally, we validate the format of the generated `submission.csv` file.
