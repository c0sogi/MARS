Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment by setting random seeds and adjusting the `Config` parameters to ensure a fast baseline execution (reducing epochs to 10).
2.  **Data Loading**: Utilize the provided `get_dataloaders` function to load training, validation, and test datasets. This leverages the caching mechanism in `GestureDataset` for efficiency.
3.  **Model Training**: Instantiate the `BiLSTMClassifier` and use the `run_training` function to train the model. This handles the training loop, validation monitoring, and checkpointing of the best model.
4.  **Validation & Failure Analysis**:
    *   Load the best model checkpoint.
    *   Iterate through the validation set to generate predictions and retrieve ground truth sequences.
    *   Compute the Levenshtein distance (error) for each sample.
    *   Calculate the overall validation metric (Total Distance / Total Truth Length) and print it in the required format.
    *   Extract input features (Sequence Length and Motion Magnitude) for each sample.
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify failure modes.
5.  **Inference & Submission**: Execute `run_inference` to generate predictions for the test set and save the results to the submission file.
