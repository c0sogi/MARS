Based on the comprehensive analysis of the accumulated lessons, specifically the superior performance of **Gated Activation Units** (Cite solution_lesson_node_00099), the necessity of **Explicit Boundary Supervision** (Cite solution_lesson_node_00082), the critical role of **1x1 Output Projections** (Cite solution_lesson_node_00107), and the potential information bottleneck in standard cascaded architectures (Cite solution_lesson_node_00078), I propose the **Feature-Injected Supervised Gated-Cascaded Network (FISG-CN)**.

This strategy structurally evolves the high-performing RSG-CRCN (Idea 19) by introducing **Feature Injection Skip Connections**. Instead of feeding only the low-dimensional probability distributions to the refinement stages, we inject the high-dimensional latent representations from the encoder directly into each refinement stage. This resolves the information bottleneck, providing the Gated TCNs with the rich context required to resolve ambiguities, while strictly adhering to the architectural and data hygiene constraints identified in previous failures.

# Model
**Architecture: Feature-Injected Supervised Gated-Cascaded Network (FISG-CN)**
The model consists of an Encoder and two Refinement Stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Multi-Task Recurrent Encoder**
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain this backbone for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025).
    *   **Input:** Frame-wise feature vector (Upper-Body Skeleton + Velocity + Audio), fused via concatenation (Cite solution_lesson_node_00062).
    *   **Outputs:**
        *   **Latent Features ($H_{enc}$):** The raw 256-dimensional output sequence from the LSTM.
        *   **Initial Predictions:** Projected from $H_{enc}$ to Class Probabilities ($P_{cls}^{(0)}$, 21 ch) and Boundary Probability ($P_{bnd}^{(0)}$, 1 ch).

2.  **Inter-Stage Masking:**
    *   We explicitly multiply all tensors ($H_{enc}$, $P_{cls}$, $P_{bnd}$) by the binary sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Feature-Injected Gated Refinement**
    *   **Structural Innovation (Feature Injection):** Instead of inputting only the probabilities from the previous stage, we **concatenate** the Encoder Features ($H_{enc}$) with the probabilities.
        *   **Input:** $[P_{cls}^{(0)}, P_{bnd}^{(0)}, H_{enc}]$.
        *   **Motivation:** This bypasses the information bottleneck of the 22-channel probability map, allowing the TCN to access the full 256-channel context of the encoder to refine predictions (Cite solution_lesson_node_00078, solution_lesson_node_00109).
    *   **Block Architecture:** **Gated Activation Blocks** with **1x1 Output Projections**.
        *   $Z = \tanh(W_f * X) \odot \sigma(W_g * X)$.
        *   $H = W_{proj} * Z$ (Strictly retained to facilitate gradient flow, Cite solution_lesson_node_00107).
        *   $Y = X + H$.
    *   **Configuration:** 10 dilated layers with **Monotonically Increasing Dilation** ($1, 2, \dots, 512$) (Cite solution_lesson_node_00101). We maintain **256 channels** and explicitly **exclude Instance Normalization** (Cite solution_lesson_node_00066).
    *   **Output:** Refined $[P_{cls}^{(1)}, P_{bnd}^{(1)}]$.

4.  **Stage 3: Feature-Injected Gated Sharpening**
    *   **Input:** $[P_{cls}^{(1)}, P_{bnd}^{(1)}, H_{enc}]$. We re-inject the encoder features to ensure the sharpening stage also has access to the full context.
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions.

# Data
**Preprocessing:**
*   **Defensive Data Loading:** Implement a robust parser that explicitly validates matrix dimensions and transposes if necessary, failing loudly on errors (Cite solution_lesson_node_00104, solution_lesson_node_00048).
*   **Normalization (Crucial):** Explicitly **center** the skeleton data relative to the HipCenter and **scale the units from millimeters to meters** (multiply by 0.001). This prevents saturation of the Gated Units (Cite solution_lesson_node_00084).
*   **Feature Selection:** Strictly limit inputs to **12 Upper-Body Joints** and **Audio MFCCs** (Cite solution_lesson_node_00020).

**Augmentation:**
*   **Physically Consistent Augmentation:** Implement the temporally correlated noise pipeline.
    1.  Generate Gaussian noise and apply a **Temporal Low-Pass Filter**.
    2.  Add this smooth noise to the **Raw 3D Joint Positions**.
    3.  **Derive** the Temporal Velocity from the augmented positions.
    *   This ensures velocity features remain physically consistent with position features (Cite solution_lesson_node_00059, solution_lesson_node_00064).

**Evaluation Data:**
*   **Deterministic Split:** Instantiate the validation set with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification Loss:** Weighted Cross-Entropy with a strict ratio of **0.1 (Background) : 1.0 (Gesture)** (Cite solution_lesson_node_00013).
*   **Boundary Supervision:** **Binary Cross-Entropy** with **Sharp Targets** (1 at transition frames, 0 otherwise). This explicit supervision is essential for the Gated Units (Cite solution_lesson_node_00082, solution_lesson_node_00103).
*   **Unclamped Probability-Space Smoothing:** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities**. We do **not clamp** the loss (Cite solution_lesson_node_00087) and do not use Log-Softmax (Cite solution_lesson_node_00033).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4` (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize output smoothness (T-MSE weight) over aggressive parameter regularization (Cite solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax). This merges fragmented segments more effectively than probability filtering (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to prevent the deletion of valid gestures at sequence edges (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse consecutive repeated labels and remove the background class.
