Implementation Strategy:
1.  **Setup & Imports**: Import standard libraries and the provided library modules (`config`, `utils`, `preprocessing`, `dataset`, `model`, `engine`). Set random seeds for reproducibility.
2.  **Helper Functions**:
    *   `generate_submission_dataframe`: A core inference function that iterates over a dataset (validation or test) in `expand_candidates=True` mode. It runs the model in evaluation mode, aggregates logits per `example_id`, selects the best candidate, applies the confidence threshold, and formats the prediction strings for long and short answers.
    *   `failure_analysis`: A function to compute per-example correctness on the validation set, extract text length features from the source file, and calculate the correlation between model error and input length.
3.  **Main Pipeline**:
    *   **Preprocessing**: Initialize the `Tokenizer` and `embedding_matrix`.
    *   **Training**: Initialize `NQDataset` for training (limited to 20,000 samples for speed) and validation (limited for monitoring). Train the `InteractionGridCNN` using the `Trainer` class for 2 epochs.
    *   **Validation**: Load the best model. Run full inference on the validation set. Calculate the official Micro F1 metric using `compute_f1_score` and print it.
    *   **Analysis**: Execute the failure analysis to print feature correlations.
    *   **Submission**: Run inference on the test set and save the `submission.csv` file.
