### Proposed Baseline: Attention-Guided Bag-of-Embeddings (AG-BoE)

This approach introduces a **Query-Attentive** architecture. It synthesizes the efficiency of the Bag-of-Embeddings approach (Idea 1) with the semantic focus of Attention mechanisms (found in BiDAF/Idea 5), but simplifies the interaction to a lightweight vector-to-sequence operation. It distinguishes itself from previous ideas by using learned attention weights not just for pooling, but directly as a heuristic for short answer extraction, avoiding the need for separate trainable span heads or heavy recurrent/convolutional layers.

#### **Model**
*   **Embedding Layer:** The model utilizes pre-trained static word embeddings (e.g., GloVe) to convert tokens into dense vectors. These are frozen to ensure maximum training throughput.
*   **Question Encoder:** The question tokens are aggregated into a single global context vector using **Mean Pooling**. This provides a fixed-size summary of the query's semantic intent.
*   **Attentive Candidate Encoder:**
    *   Instead of simple averaging, the model computes a **Relevance Weight** for each token in the long answer candidate. This is calculated by taking the dot product between the candidate token embedding and the global question vector, followed by a Softmax normalization.
    *   The candidate text is then encoded into a single vector via a **Weighted Sum** of its token embeddings, using these relevance weights. This effectively filters out noise, creating a representation dominated by words semantically related to the question.
*   **Ranking Head:** The global question vector and the attentive candidate vector are concatenated (along with interaction features like element-wise product) and passed through a Multi-Layer Perceptron (MLP) to predict the **Long Answer Score**.
*   **Span Extraction Module:** The model does not use separate neural layers to predict start/end boundaries. Instead, it reuses the **Relevance Weights** computed in the encoder. It assumes that the short answer corresponds to the cluster of words with the highest attention. A sliding window sums these weights, and the window with the maximum cumulative mass is selected as the short answer.
*   **Yes/No Head:** The concatenated representation is passed through a small classifier to predict `YES`, `NO`, or `NONE`.

#### **Data**
*   **Preprocessing:**
    *   **Tokenization:** Input text is split using a fast whitespace tokenizer.
    *   **Padding:** Question and candidate sequences are padded to fixed lengths (e.g., 20 and 300 tokens) to facilitate batched vector operations.
    *   **Vocabulary:** Tokens are mapped to indices in the pre-trained embedding matrix.
*   **Labeling:**
    *   **Ranking Label:** Binary label (`1` if the candidate matches the ground truth, `0` otherwise).
    *   **Attention Mask:** A binary sequence mask the same length as the candidate, where tokens inside the ground truth short answer span are marked as `1` and others as `0`.
    *   **Yes/No:** Categorical labels.

#### **Training**
*   **Strategy:** The model is trained using a **Multi-Task Learning** objective that supervises both the classification outcome and the intermediate attention mechanism.
*   **Sampling:** **Random Negative Sampling** is used. Batches consist of positive pairs and a ratio of negative pairs from the same document.
*   **Loss Function:** A weighted sum of two losses:
    *   **Ranking Loss:** Binary Cross-Entropy for the long answer prediction.
    *   **Attention Loss:** Mean Squared Error (MSE) or Binary Cross-Entropy between the calculated Relevance Weights and the ground truth Attention Mask. This forces the model to "attend" to the correct short answer span during the encoding phase.
*   **Optimizer:** The Adam optimizer is used with a standard learning rate.

#### **Evaluation**
1.  **Inference:** For a test document, the model computes the ranking score and the relevance weight sequence for every question-candidate pair.
2.  **Long Answer Selection:** The candidate with the highest ranking score is selected. If the score is below a **confidence threshold**, the prediction is `BLANK`.
3.  **Short Answer Extraction:** If a long answer is selected, a sliding window (of a fixed average length, e.g., 25 tokens) moves across the Relevance Weight sequence. The window position with the highest sum of weights is extracted as the short answer.
4.  **Yes/No Prediction:** The label is predicted by the Yes/No head based on the aggregated vectors.
