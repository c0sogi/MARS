Implementation strategy:
1.  **Configuration**: Initialize the `Config` class and override parameters to ensure a fast baseline run. Specifically, restrict `DEBUG_SAMPLE_SIZE` to 5000 samples and `NUM_EPOCHS` to 1. Set a reasonable `BATCH_SIZE`.
2.  **Training**: Execute the `train_model` function from the `engine` module. Pass `load_cached_data=False` to ensure the data processing respects the reduced sample size.
3.  **Validation**:
    *   Re-initialize the validation data loader using cached features (generated during the training step).
    *   Load the trained model state from the checkpoint.
    *   Run a validation loop to collect predictions, ground truth labels, and loss values.
    *   Compute and print the **Final Validation Metric** (Micro F1 Score on the binary Long Answer classification task).
4.  **Failure Analysis**:
    *   Calculate the Pearson correlation coefficient between the validation loss and input properties (Question Length and Candidate Length) using NumPy.
    *   Print these correlations to identify error patterns.
5.  **Inference & Submission**:
    *   **Crucial Step**: Reset `Config.DEBUG_SAMPLE_SIZE` to `None` to ensure the full test set is processed.
    *   Execute `run_inference_pipeline` with `load_cached_data=False` to process the complete test dataset and generate the `submission.csv` file.
