Implementation strategy:
The script `runfile.py` orchestrates the entire pipeline. It initializes the `IDFIndex` and `NQDataReader` to prepare data. It loads a subset of training data (50k samples) and validation data (10k samples) to ensure a fast execution time. The `GradientBoostingRanker` (LightGBM) is trained with early stopping. For validation, the script calculates the Micro F1 score for Long Answers by comparing the predicted candidate index against the ground truth. Failure analysis is performed by correlating prediction errors with input features. For the test set, the model predicts scores for all candidates. The script then streams the raw test JSONL file to map the top-ranked candidates to their token indices and applies the `ShortAnswerHeuristic` to extract short answers (including Yes/No checks) by matching token sequences. Finally, it formats and saves the `submission.csv`.
