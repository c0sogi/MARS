### Proposed Baseline: Single-Stream Dilated Residual Network

This approach introduces a **Single-Stream Convolutional** architecture. It distinguishes itself from previous ideas (which were largely Siamese/Dual-Encoders or Matrix-Interaction models) by concatenating the question and candidate into a single sequence. It uses dilated convolutions to efficiently model the interaction between the question and the candidate text over long distances without the heavy computational cost of Transformers or RNNs.

#### **Model**
*   **Single-Stream Input:** Unlike previous approaches that encode the question and candidate independently, this model concatenates them into a single linear sequence: `[Question Tokens] <SEP> [Candidate Tokens]`. This allows the model to learn interactions between the query and the context directly within the encoder's receptive field.
*   **Embedding Layer:** The model uses pre-trained static word embeddings (e.g., GloVe) to convert tokens into dense vectors. These are frozen to ensure maximum training efficiency.
*   **Dilated Convolutional Encoder:** The sequence is processed by a stack of **1D Dilated Convolutional Blocks**.
    *   **Exponential Dilation:** The dilation rate increases exponentially with each layer (e.g., 1, 2, 4, 8). This rapidly expands the receptive field, allowing tokens in the candidate text to integrate information from the question text at the beginning of the sequence, effectively simulating "attention" via convolution.
    *   **Residual Connections:** Each block employs residual connections and Layer Normalization to ensure stable gradient flow and allow for a deeper network.
*   **Ranking Head:** A **Global Max Pooling** operation aggregates the features of the entire sequence into a single vector. This vector is passed to a binary classifier (MLP) to predict the **Long Answer Score**.
*   **Span Prediction Heads:** The output vectors corresponding specifically to the *candidate* portion of the sequence are sliced out and fed into two parallel linear layers to predict the **Start Token** and **End Token** probabilities.
*   **Yes/No Head:** The globally pooled vector is passed to a small classifier to predict `YES`, `NO`, or `NONE`.

#### **Data**
*   **Preprocessing:**
    *   **Tokenization:** Input text is tokenized using a fast whitespace splitter.
    *   **Concatenation:** For every candidate, the question and candidate text are combined into a single list of tokens with a separator.
    *   **Padding:** The concatenated sequences are padded or truncated to a fixed length (e.g., 350 tokens) to facilitate efficient batch processing on the GPU.
    *   **Vocabulary:** Tokens are mapped to indices in the pre-trained embedding matrix.
*   **Labeling:**
    *   **Long Answer:** Binary label (`1` if the candidate matches the ground truth, `0` otherwise).
    *   **Short Answer:** Start and End indices relative to the concatenated sequence. If no short answer exists, indices point to a reserved "null" index (e.g., index 0).
    *   **Yes/No:** One-hot encoded categorical labels.

#### **Training**
*   **Strategy:** The model is trained using a **Multi-Task Learning** objective, simultaneously optimizing the ranking, span extraction, and Yes/No classification heads.
*   **Sampling:** **Random Negative Sampling** is employed to handle class imbalance. Each training batch consists of positive question-candidate pairs and a fixed ratio of randomly selected negative pairs from the same document.
*   **Loss Function:** A weighted sum of three loss components is minimized:
    *   **Binary Cross-Entropy** for the long answer ranking.
    *   **Sparse Categorical Cross-Entropy** for the start and end span indices.
    *   **Categorical Cross-Entropy** for the Yes/No classification.
*   **Optimizer:** The Adam optimizer is used with a standard learning rate schedule.

#### **Evaluation**
1.  **Inference:** For a test document, the model constructs concatenated sequences for the question paired with every available long answer candidate.
2.  **Long Answer Selection:** The candidate with the highest ranking score is identified. If this score is below a calibrated **confidence threshold**, the prediction defaults to `BLANK`.
3.  **Short Answer Extraction:** If a long answer is selected, the span is determined by the indices with the highest logits from the Start and End heads. These indices are adjusted to account for the length of the prepended question.
4.  **Yes/No Prediction:** The final label is assigned based on the class with the highest probability from the Yes/No Head.
