This stale cache causes the `NQDataset` to filter out all metadata entries because the IDs in the cache do not match the metadata, leading to an empty dataset error.

To fix this, I will modify `runfile.py` to explicitly delete any existing `.index.parquet` files in the working directory at the start of execution. This forces the `DataFactory` to rebuild the file index from scratch using the current (presumably correct) logic, ensuring data integrity. This applies **debug_lesson_6** (Invalidate Stale Caches After Patching Data Generation Logic).
