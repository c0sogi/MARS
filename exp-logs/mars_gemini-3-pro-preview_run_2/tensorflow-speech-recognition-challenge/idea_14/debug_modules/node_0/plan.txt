### Implementation Strategy

2.  **Data Loading Verification**: We will utilize `library.data_utils` to load background noise and a subset of training data. We will assert that the returned tensors have the expected dimensions (Batch Size, Time Steps).
3.  **Component Testing**: We will instantiate and test each custom layer (`GPUNoiseInjector`, `DifferentiableSpectrogram`, `SpecAugment`, `AttentionPooling`) individually with dummy data. We will verify input/output shapes and ensure that augmentation layers modify the data when active.
4.  **Model Integration Test**: We will instantiate the full `EfficientNetV2Audio` model and perform a forward pass with a dummy batch of waveforms to confirm it produces logits of the correct shape `(Batch, NumClasses)`.
5.  **Full Pipeline Execution**: We will instantiate the `Trainer` class and run the `fit()` method for one epoch. This verifies the training loop, loss calculation, and backpropagation. Finally, we will run `predict_and_submit()` to ensure the inference pipeline works and generates a valid submission file.
