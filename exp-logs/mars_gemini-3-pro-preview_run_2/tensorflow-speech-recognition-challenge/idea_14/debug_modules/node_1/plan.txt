The issue is a shape mismatch between the training checkpoint and the inference model configuration. During training, the `GPUNoiseInjector` registers a large background noise buffer, which is saved in the checkpoint. During inference, the model is initialized with an empty noise buffer to save resources. When `load_state_dict` attempts to load the large saved buffer into the empty model buffer, it fails due to the size difference. To fix this, I will modify `library/trainer.py` to explicitly remove the `noise_injector.noise_tensor` key from the loaded state dictionary and use `strict=False` to ignore the missing key in the inference model. This resolves the inconsistency between pipeline stages (Cite debug_lesson_3).
