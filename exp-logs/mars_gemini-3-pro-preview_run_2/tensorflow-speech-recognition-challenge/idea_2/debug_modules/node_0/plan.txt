The following implementation demonstrates the usage of the provided library modules for the speech command recognition task.

**Implementation Strategy:**
1.  **Configuration & Setup**: Initialize the environment using `Config` and `set_seed` to ensure reproducibility.
2.  **Utility Verification**: Validate the `get_weighted_sampler` by creating a synthetic imbalanced dataframe and asserting that the calculated weights are inversely proportional to class frequencies.
3.  **Data Processing Pipeline**:
    *   Instantiate the spectrogram transformation pipeline.
    *   Manually process a single audio file from the metadata to verify signal processing logic (loading, resampling, padding, spectrogram generation).
    *   Verify output tensor shapes match the model's expected input.
4.  **DataLoader Integration**: Use `get_dataloaders` in `debug` mode to quickly generate PyTorch DataLoaders with a small subset of data, verifying batch shapes and data types.
5.  **Model Instantiation**: Initialize the `AudioEfficientNet` and perform a forward pass with a batch of data to confirm architecture correctness and output dimensions.
6.  **Training Loop Execution**: Execute `run_training` in `debug` mode for a single epoch. This tests the optimizer, loss calculation, backpropagation, and checkpoint saving mechanisms without consuming excessive time.
7.  **Inference & Submission**: Load the trained model checkpoint, perform inference on the test set (debug subset), and generate a sample submission file to demonstrate the end-to-end workflow.
