### 1. Model: Time-Resolved EfficientNet with Context-Aware Attention
I propose a structural evolution that transforms the standard "Image Classification" backbone into a **Spectro-Temporal Encoder**. While the previous best solution (EfficientNet-B0 + Attention Pooling) treated the spectrogram as a static image, this solution explicitly modifies the network topology to preserve temporal fidelity and model sequential dependencies, addressing the "smearing" issues identified in **Cite solution_lesson_node_00016**.

*   **Backbone (Stride-Modified EfficientNet-B0)**: We will use an EfficientNet-B0 backbone initialized with ImageNet weights.
    *   **Input Adaptation**: The first projection layer will be modified to accept 1-channel input. Crucially, we will initialize the weights by **summing** the original RGB weights to preserve activation magnitudes **(Cite solution_lesson_node_00019)**.
    *   **Structural Innovation (Asymmetric Strides)**: Standard EfficientNet downsamples the input by 32x in both dimensions (Time and Frequency). We will modify the strides of the final two stages (blocks) to be **(2, 1)** (downsample Frequency, preserve Time) instead of the standard (2, 2). This ensures that the final feature map retains high temporal resolution (e.g., ~25-50 time steps) rather than being compressed into a few frames, directly addressing the need for temporal precision in short commands **(Cite solution_lesson_node_00016)**.
*   **Head (Frequency Pooling & 1D Context)**: Instead of flattening the 2D feature map immediately:
    1.  **Frequency-wise Pooling**: We will apply Global Average Pooling *only* across the Frequency dimension. This collapses the spectral features while maintaining the Time dimension, resulting in a sequence of feature vectors.
    2.  **1D Context Layer**: We will process this sequence with a lightweight **1D Convolutional layer** (Kernel size 5). This adds local context awareness (modeling phoneme transitions like "s-t") which the pure Attention mechanism lacks.
    3.  **Attention Pooling**: Finally, we apply the learnable **Attention Pooling** mechanism to this context-enriched sequence to dynamically weight active speech segments and suppress silence **(Cite solution_lesson_node_00011)**.

### 2. Data: High-Fidelity Spectrograms & Balanced Pipeline
The data pipeline is designed to maximize signal fidelity, adhering to the finding that input resolution outweighs model capacity **(Cite solution_lesson_node_00026)**.

*   **Spectro-Temporal Alignment**: We will generate Log-Mel Spectrograms with **128 Mel bins**, a window size of **25ms**, and a hop length of **10ms**.
    *   *Rationale*: We retain the high frequency resolution (128 bins) that ConvNeXt lacked **(Cite solution_lesson_node_00026)** and the high temporal resolution (10ms hop) required to resolve rapid phonemes **(Cite solution_lesson_node_00016)**.
*   **Instance Normalization**: We will apply Instance Normalization to each sample to standardize contrast and volume **(Cite solution_lesson_node_00011)**.
*   **Weighted Random Sampling**: We will strictly employ a `WeightedRandomSampler` to ensure every training batch contains a balanced distribution of the 12 classes, neutralizing the 17:1 imbalance **(Cite solution_lesson_node_00001)**.
*   **Calibrated SpecAugment**: We will apply Time and Frequency masking. The mask parameters will be calibrated to be a conservative fraction (<20%) of the input dimensions to act as a regularizer without destroying the signal **(Cite solution_lesson_node_00005)**.

### 3. Training: Stable & Robust Optimization
*   **Loss Function**: We will use Cross-Entropy Loss with **Label Smoothing (0.1)**. This prevents the model from becoming overconfident and encourages the learning of robust, clustered feature representations **(Cite solution_lesson_node_00013)**.
*   **Optimizer**: We will use **AdamW** with a **Cosine Annealing** learning rate scheduler.
*   **Regularization**: We will **exclude Mixup** to prioritize faster convergence within the 24-hour limit, relying on the calibrated SpecAugment for regularization **(Cite solution_lesson_node_00007)**.

### 4. Evaluation
*   **Inference**: Test audio clips will be processed using the same high-fidelity parameters (128 Mels, 10ms hop) and Instance Normalization.
*   **Prediction**: The model will output class probabilities via Softmax. The label corresponding to the highest probability will be selected. The `unknown` label is predicted naturally if its probability is highest.
