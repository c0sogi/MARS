### 1. Model: Multi-Scale EfficientNet with Hierarchical 2D Attention
I propose a structural evolution that addresses the trade-off between **temporal resolution** and **semantic abstraction**. Previous experiments showed that while deep features are necessary for classification, the standard downsampling (32x) destroys the fine-grained temporal cues required to distinguish short phonemes **(Cite solution_lesson_node_00016)**. However, artificially modifying the backbone strides to preserve resolution degrades performance by breaking the pretrained feature hierarchy **(Cite solution_lesson_node_00030)**.

To resolve this, I propose a **Multi-Scale Feature Aggregation** architecture:
*   **Backbone (EfficientNet-B0)**: We will use the EfficientNet-B0 backbone initialized with ImageNet weights **(Cite solution_lesson_node_00004)**. The input layer will be adapted to 1-channel by **summing** the original RGB weights to preserve activation statistics **(Cite solution_lesson_node_00019)**.
*   **Structural Innovation (Hierarchical Extraction)**: Instead of utilizing only the final feature map (which is spatially compressed by 32x), we will extract feature maps from three distinct stages of the network:
    1.  **Stage 3 Output**: High resolution (Downsample factor 8x), capturing fine phonetic details.
    2.  **Stage 5 Output**: Medium resolution (Downsample factor 16x), capturing syllable/word parts.
    3.  **Stage 9 Output (Final)**: Low resolution (Downsample factor 32x), capturing global semantic context.
*   **Head (Parallel 2D Attention)**: We will apply a separate **2D Attention Pooling** module to each of these three feature maps independently. This ensures that the model can attend to specific frequencies and time steps at the resolution most appropriate for the feature, adhering to the finding that 2D attention is superior to 1D **(Cite solution_lesson_node_00032)**.
*   **Fusion**: The three resulting context vectors will be concatenated to form a rich, multi-resolution representation before passing through the final classification layer.

### 2. Data: High-Fidelity Spectrograms & Balanced Pipeline
The data pipeline will be strictly configured to maximize signal quality, adhering to the lesson that input resolution outweighs model capacity **(Cite solution_lesson_node_00026)**.

*   **Spectro-Temporal Alignment**: We will generate Log-Mel Spectrograms with **128 Mel bins**, a window size of **25ms**, and a hop length of **10ms**. This configuration provides the high temporal resolution needed for speech while maintaining the frequency detail required for the CNN **(Cite solution_lesson_node_00016)**.
*   **Instance Normalization**: We will apply Instance Normalization to each sample to standardize contrast and volume **(Cite solution_lesson_node_00011)**.
*   **Weighted Random Sampling**: We will strictly employ a `WeightedRandomSampler` to ensure every training batch contains a balanced distribution of the 12 classes, neutralizing the 17:1 imbalance **(Cite solution_lesson_node_00001)**.
*   **Calibrated SpecAugment**: We will apply Time and Frequency masking. The mask parameters will be calibrated to be a conservative fraction (<20%) of the input dimensions to act as a regularizer without destroying the signal **(Cite solution_lesson_node_00005)**.

### 3. Training: Optimization for Generalization
*   **Loss Function**: We will use Cross-Entropy Loss with **Label Smoothing (0.1)**. This prevents overconfidence and encourages robust clustering, which was proven superior to standard Cross-Entropy **(Cite solution_lesson_node_00013)**.
*   **Batch Size Strategy**: We will use a smaller batch size (e.g., **64**) rather than maximizing GPU memory (e.g., 512). This ensures a high frequency of gradient updates (~14k updates vs ~2.7k), which is critical for convergence and generalization on this dataset size **(Cite solution_lesson_node_00031)**.
*   **Optimizer**: We will use **AdamW** with a **Cosine Annealing** learning rate scheduler.
*   **Regularization**: We will **exclude Mixup** to prioritize faster convergence, relying on the calibrated SpecAugment and the multi-scale architecture for regularization **(Cite solution_lesson_node_00007)**.

### 4. Evaluation
*   **Inference**: Test audio clips will be processed using the same high-fidelity parameters (128 Mels, 10ms hop) and Instance Normalization.
*   **Prediction**: The model will output class probabilities via Softmax. The label corresponding to the highest probability will be selected. The `unknown` label is predicted naturally if its probability is highest.
