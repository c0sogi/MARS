Based on the provided task description and dataset analysis, here is a proposal for a highly efficient baseline approach.

### Model: Simple Convolutional Baseline (SCB)
The proposed architecture is a lightweight **2D Convolutional Neural Network (CNN)**. This design conceptually simplifies **Model 3** by retaining the convolutional feature extraction front-end but removing the computationally expensive Bi-directional GRU/LSTM recurrent layers. Instead of relying on recurrent units for temporal context, the model relies on the 2D receptive field of the convolutions and a global pooling mechanism to capture the necessary time-frequency patterns.

*   **Input**: Log Mel-spectrograms (1 channel).
*   **Body**: A stack of 4 Convolutional Blocks. Each block comprises:
    *   `Conv2D` layer (kernel size 3x3) to extract spectral features.
    *   `BatchNorm2d` for training stability.
    *   `ReLU` activation.
    *   `MaxPool2d` (2x2) to progressively downsample the time and frequency dimensions.
    *   Filter counts increase progressively (e.g., 16 $\to$ 32 $\to$ 64 $\to$ 128).
*   **Head**: A `GlobalAveragePooling` layer collapses the remaining time-frequency dimensions into a single feature vector. This is followed by a single `Linear` layer mapping to the 12 output classes (`yes`, `no`, `up`, `down`, `left`, `right`, `on`, `off`, `stop`, `go`, `silence`, `unknown`).

### Data
We will preprocess the audio into image-like representations to feed the SCB.

1.  **Audio Loading & Normalization**:
    *   Load audio files at a sample rate of 16 kHz.
    *   Ensure all clips are exactly 1 second (16,000 samples). Clips shorter than 1 second will be padded with zeros; longer clips will be centrally cropped (except for silence, see below).
2.  **Feature Extraction**:
    *   Compute **Mel-spectrograms** (e.g., 64 mel bins, FFT size 1024, hop length 512).
    *   Apply a **Log** transformation to the spectrograms to match human auditory sensitivity (Log-Mel Spectrograms).
3.  **Special Class Handling**:
    *   **Silence**: The training metadata contains a few long background noise files labeled as `silence`. During data loading, if a sample is labeled `silence`, the loader will extract a **random 1-second segment** from the source file. This generates diverse training examples for the `silence` class from the limited number of source files.
    *   **Unknown**: The `unknown` class is significantly overrepresented (approx. 63% of the data). We will use a **Weighted Random Sampler** during training to balance the batches, ensuring the model sees an equal distribution of specific commands, silence, and unknown samples.

### Training
*   **Loss Function**: Standard **Cross-Entropy Loss** for multiclass classification.
*   **Optimizer**: **Adam** optimizer with default parameters.
*   **Procedure**:
    *   Train for a fixed, short duration (e.g., 15 epochs) to ensure quick turnaround.
    *   Use a learning rate scheduler (e.g., `StepLR` or `CosineAnnealing`) to decay the learning rate, helping the model converge to a stable baseline quickly.
    *   Monitor validation accuracy to save the best model checkpoint.

### Evaluation
1.  **Inference**:
    *   Load test files from the `test/audio` directory.
    *   Apply the same preprocessing (padding/cropping, Log-Mel Spectrogram generation) used in training.
    *   Pass the spectrograms through the trained SCB model.
2.  **Prediction**:
    *   Apply `Softmax` to the output logits.
    *   Select the class with the highest probability (`argmax`).
    *   Map the numerical index back to the string label (e.g., 0 $\to$ `yes`, 11 $\to$ `unknown`).
3.  **Submission**:
    *   Generate the `submission.csv` file mapping `fname` to the predicted `label`.
