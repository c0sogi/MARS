Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration Setup**: We will import the global `Config` class and adjust the number of epochs to 15. This balances the need for a "fast baseline" with the requirement to achieve high accuracy on the A100 GPU. The 2-hour time limit is sufficient for this model size and dataset.
2.  **Training Orchestration**: We will instantiate the `Trainer` class from the library. The trainer handles the training loop, validation, checkpointing, and scheduler stepping. We will execute `trainer.fit()` to train the model.
3.  **Validation & Metrics**:
    *   After training, we will load the best model checkpoint.
    *   We will iterate through the validation set to collect predictions and ground truth labels.
    *   We will calculate the **Multiclass Accuracy** and print it in the exact required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   We will calculate the binary error vector (1 for incorrect, 0 for correct).
    *   We will compute the Pearson correlation coefficient between this error vector and the integer-encoded target labels. This quantifies if specific classes (features) are systematically associated with higher error rates.
5.  **Submission Logic**:
    *   We will compare the final validation accuracy against the strict threshold of `0.9866209549293419`.
    *   If the metric exceeds the threshold, we will call `generate_submission()` to create the `submission.csv` file.
    *   If not, we skip submission generation to comply with the logic.
