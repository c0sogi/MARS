The following script demonstrates the usage of the provided library files for the Speech Command Recognition task. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to enable debug mode (using a small subset of data) and reduces the number of epochs to 1. This ensures the demonstration runs quickly.
2.  **Environment Setup**: Patches `tqdm` to suppress progress bars as requested and sets random seeds for reproducibility.
3.  **Dataset Verification**: Instantiates the `SpeechDataset`, loads a sample, and verifies the shape of the generated spectrogram and the validity of the label.
4.  **Model Verification**: Instantiates the `ConvNeXtAudio` model, performs a forward pass with dummy data, and verifies the output shape matches the number of classes.
5.  **Training Pipeline**: Executes the full training and inference pipeline using the `run_training` function from `library.train`. This trains the model on the small debug subset and generates predictions.
6.  **Output Verification**: Validates that the model checkpoint and submission file are correctly generated and contain the expected data.
