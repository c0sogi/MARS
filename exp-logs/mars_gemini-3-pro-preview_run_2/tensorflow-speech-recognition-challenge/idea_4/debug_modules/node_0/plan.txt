Implementation Strategy:
The following script demonstrates the complete pipeline for the Speech Command Recognition task using the provided library files. 
1.  **Configuration**: We override the default `Config` parameters to enable `DEBUG` mode, reduce `EPOCHS` to 1, and disable `PRETRAINED` weights. This ensures the script runs quickly (within minutes) and does not require network access for model weights.
2.  **Component Verification**: We systematically verify each module:
    *   **Utils**: Check reproducibility (`set_seed`) and checkpointing logic.
    *   **Transforms**: Validate that audio waveforms are correctly converted to spectrograms with the expected dimensions.
    *   **Dataset**: Instantiate the dataset in debug mode and verify that `__getitem__` returns tensors of correct shape and type. Check `DataLoader` batching.
    *   **Model**: Pass a sample batch through the `ConvNeXtAudio` model to verify the forward pass and output shape.
    *   **Trainer**: Execute the `fit()` method to run a single epoch of training and the `predict()` method to generate a submission file.
3.  **Execution**: The script is self-contained and asserts the correctness of shapes and file outputs at each step.
