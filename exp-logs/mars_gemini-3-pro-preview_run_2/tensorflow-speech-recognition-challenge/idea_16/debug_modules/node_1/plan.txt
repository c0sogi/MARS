The error `AssertionError: Best model checkpoint was not created` occurs because the `Trainer` initializes `self.best_acc` to `0.0`. In the demo run, the model achieves a validation accuracy of exactly `0.0` in the first (and only) epoch. The condition `if current_acc > self.best_acc` evaluates to `False` (`0.0 > 0.0`), preventing the `best_model.pth` checkpoint from being saved.

To fix this, I will initialize `self.best_acc` to `-1.0`. This ensures that the first epoch's accuracy (even if it is 0.0) is considered an improvement, triggering the checkpoint save. This solution directly applies **debug_lesson_5** ("Initialize Metric Trackers to Guarantee a First Save").
