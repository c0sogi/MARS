The `KeyError: 'class_weight'` arises because the `runfile.py` script attempts to retrieve `class_weight` from the `params` dictionary during the hyperparameter tuning loop, but the configuration grid (`Config.LOGREG_GRID`) only defines the `C` parameter. Consequently, `class_weight` is missing from the generated parameter combinations. A similar error would occur later when building the final model using `best_params`. The fix is to use the dictionary `.get()` method to safely access `class_weight`, defaulting to `None` if the key is not present, which aligns with the default behavior of the `build_linear_branch` function.

```diff
runfile.py
<<<<<<< SEARCH
            model = build_linear_branch(
                C=params["C"],
                class_weight=params["class_weight"],
                random_state=Config.SEED,
            )
=======
            model = build_linear_branch(
                C=params["C"],
                class_weight=params.get("class_weight"),
                random_state=Config.SEED,
            )
>>>>>>> REPLACE
```
