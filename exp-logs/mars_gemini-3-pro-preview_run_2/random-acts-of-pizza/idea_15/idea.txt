Based on the comprehensive failure analysis and the synthesis of lessons learned—specifically the trade-off between semantic resolution and dimensionality (Cite solution_lesson_node_00017), the superiority of linear probes on embeddings (Cite solution_lesson_node_00005), and the failure of unsupervised dimensionality reduction (PCA) to capture predictive signal (Idea 8)—I propose a **Supervised Semantic Projection Ensemble (SSPE)**.

This strategy structurally evolves the solution by upgrading the text backbone to a larger, more powerful model (`all-mpnet-base-v2`) while solving the resulting "Curse of Dimensionality" using **Supervised Partial Least Squares (PLS)** projection. This differs from previous attempts by replacing unsupervised compression (PCA) and complex non-linear heads (SVM) with a mathematically aligned supervised linear projection that maximizes covariance with the target.

# Model
The architecture is a **Bagged Ensemble of Logistic Regression Classifiers** operating on a compact, supervised latent feature space.

1.  **Backbone (Frozen):** `sentence-transformers/all-mpnet-base-v2`.
    *   **Rationale:** We upgrade from `all-MiniLM-L6-v2` (384d) to `all-mpnet-base-v2` (768d) to capture richer semantic nuances and "generic knowledge," addressing the limitations of the smaller model. We keep it frozen to prevent manifold collapse (Cite solution_lesson_node_00014).
2.  **Projection Layer (The Core Innovation):** **Partial Least Squares (PLS)**.
    *   **Rationale:** Instead of feeding raw 768d embeddings (which cause overfitting, Cite solution_lesson_node_00017) or using PCA (which preserves irrelevant noise, Idea 8), we project the embeddings into a low-dimensional space (e.g., 30-50 components) that explicitly maximizes covariance with the "Pizza Success" label. This creates a dense, high-signal representation.
3.  **Classifier:** **BaggingClassifier** wrapping **Logistic Regression**.
    *   **Rationale:** We retain the high-bias linear core (Cite solution_lesson_node_00005) and Bagging for variance reduction (Cite solution_lesson_node_00022).

# Data
1.  **Text Preprocessing:**
    *   Concatenate `request_title` and `request_text_edit_aware` to preserve context (Cite solution_lesson_node_00025).
    *   Encode using `all-mpnet-base-v2`.
    *   **Crucial Step:** Apply **L2 Normalization** *before* projection to place embeddings on the hypersphere (Cite solution_lesson_node_00015).
2.  **Tabular Preprocessing:**
    *   Explicitly include `unix_timestamp_of_request` as it is a top predictor (Cite solution_lesson_node_00033).
    *   Apply **QuantileTransformer (output_distribution='normal')** (RankGauss) to all numerical metadata. This neutralizes outliers and enforces a standard normal distribution (Cite solution_lesson_node_00006, Cite solution_lesson_node_00019).
3.  **Fusion:**
    *   Concatenate the **StandardScaled PLS Components** and the **RankGauss Metadata**.
    *   **Rationale:** Early Fusion allows the linear model to jointly weight the semantic and metadata signals (Cite solution_lesson_node_00020). Scaling the PLS output ensures strict alignment with the metadata (Cite solution_lesson_node_00015).

# Training
1.  **Pipeline Efficiency:**
    *   Pre-compute text embeddings **outside** the cross-validation loop to avoid redundant GPU inference (Cite solution_lesson_node_00031).
2.  **Stratified Cross-Validation with Nested Projection:**
    *   Use 5-Fold Stratified CV.
    *   **Crucial:** Fit the PLS Transformer **inside** the training loop of each fold using only that fold's training data. Transforming the validation set using a PLS model fitted on the whole dataset would constitute severe data leakage.
3.  **Hyperparameter Tuning:**
    *   Perform Grid Search within each fold for:
        *   **PLS Components:** Tune the number of latent components (e.g., `[20, 30, 40, 50]`) to find the optimal compression rate.
        *   **Regularization `C`:** Search the **High-Regularization Regime** (e.g., `1e-4` to `10.0`), capping the maximum to prevent overfitting (Cite solution_lesson_node_00012, Cite solution_lesson_node_00022).
        *   **Class Weights:** Search `['balanced', None]` (Cite solution_lesson_node_00028).

# Evaluation
1.  **Inference:**
    *   Generate L2-normalized MPNet embeddings for the test set.
    *   For each of the 5 trained fold-models:
        *   Project test embeddings using that fold's PLS transformer.
        *   Scale projected features using that fold's StandardScaler.
        *   Transform test metadata using that fold's QuantileTransformer.
        *   Predict probabilities.
2.  **Prediction:**
    *   **Average the probability outputs** from all 5 fold-models (CV-Bagging) to produce the final score (Cite solution_lesson_node_00027).
