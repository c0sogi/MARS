Based on the synthesis of lessons learned—specifically the trade-off between **Semantic Resolution** and **Dimensionality** (Cite solution_lesson_node_00017), the proven superiority of **Early Fusion** on dense features (Cite solution_lesson_node_00020), and the effectiveness of **Asymmetric Dimensionality Reduction** for auxiliary views (Cite solution_lesson_node_00046)—I propose the **Asymmetric Dual-Backbone Consensus (ADBC)** strategy.

This strategy structurally evolves the solution by integrating two distinct semantic resolutions: the compact, proven `MiniLM` (High Resolution) and the powerful but compressed `MPNet` (Low Resolution). Unlike previous attempts that either used `MPNet` raw (causing overfitting) or discarded it, this approach fuses them in a single linear space using unsupervised projection (PCA). This allows the model to leverage the superior "world knowledge" of the larger model as a dense summary signal without triggering the curse of dimensionality or the overfitting risks of supervised projection (Cite solution_lesson_node_00054).

# Model
The architecture is a **Bagged Ensemble of Logistic Regression Classifiers** operating on a fused, multi-resolution semantic feature space.

1.  **Primary Backbone (High-Resolution):** `sentence-transformers/all-MiniLM-L6-v2` (384d).
    *   **Rationale:** We strictly retain this as the "Anchor View". It has the best sample-to-feature ratio (~6:1) and has consistently provided the highest single-model performance (Cite solution_lesson_node_00017).
2.  **Auxiliary Backbone (Low-Resolution):** `sentence-transformers/all-mpnet-base-v2` (768d).
    *   **Transformation:** **Principal Component Analysis (PCA)** reducing to **50 dimensions**.
    *   **Rationale:** This implements **Asymmetric Dimensionality Reduction** (Cite solution_lesson_node_00046). MPNet captures deeper semantic nuances than MiniLM. By compressing it to 50 dimensions using unsupervised PCA (avoiding the overfitting of PLS, Cite solution_lesson_node_00054), we inject this "superior intelligence" as a dense summary signal without triggering the curse of dimensionality (Cite solution_lesson_node_00017).
3.  **Classifier:** **BaggingClassifier** wrapping **Logistic Regression** (Ridge).
    *   **Rationale:** We preserve the high-bias linear core (Cite solution_lesson_node_00005) and use Bagging with standard bootstrapping (`max_samples=1.0`) to reduce variance (Cite solution_lesson_node_00022, Cite solution_lesson_node_00031).

# Data
We construct three distinct feature views and fuse them via **Early Fusion** (Cite solution_lesson_node_00020):

1.  **View 1: Primary Semantics (384 dims)**
    *   **Input:** Concatenation of `request_title` and `request_text_edit_aware` to preserve context (Cite solution_lesson_node_00025).
    *   **Processing:** Encode with `all-MiniLM-L6-v2` (Frozen).
    *   **Normalization:** Apply **L2 Normalization** to project onto the hypersphere (Cite solution_lesson_node_00015).

2.  **View 2: Auxiliary Semantics (50 dims)**
    *   **Input:** Same concatenated text.
    *   **Processing:** Encode with `all-mpnet-base-v2` (Frozen).
    *   **Compression:** Apply **PCA (n_components=50)**.
    *   **Normalization:** Apply **L2 Normalization** *after* PCA.
    *   **Rationale:** Normalizing after projection ensures these auxiliary features have the same unit-norm scale as the primary view, preventing the linear solver from neglecting them (Cite solution_lesson_node_00015).

3.  **View 3: Robust Metadata (~10 dims)**
    *   **Features:** All numerical metadata, **explicitly including** `unix_timestamp_of_request` (Cite solution_lesson_node_00033).
    *   **Scaling:** Apply **QuantileTransformer (output_distribution='normal')** (RankGauss).
    *   **Rationale:** This neutralizes outliers and aligns the metadata distribution with the normalized embeddings (Cite solution_lesson_node_00019).
    *   **Exclusions:** Explicitly exclude user history/subreddit features (Cite solution_lesson_node_00060) and weak heuristics (Cite solution_lesson_node_00038).

# Training
1.  **Pipeline Efficiency & Integrity:**
    *   **Pre-computation:** Compute raw embeddings for both `MiniLM` and `MPNet` **outside** the cross-validation loop to avoid redundant GPU inference (Cite solution_lesson_node_00031).
    *   **Cache Validation:** Implement strict row-count checks to prevent loading stale data (Cite solution_lesson_node_00034).
2.  **Stratified Cross-Validation:**
    *   Use 5-Fold Stratified CV.
    *   **Encapsulation:** The PCA (for View 2) and QuantileTransformer (for View 3) must be fitted **inside** the cross-validation loop (on training folds only) to prevent statistical leakage (Cite solution_lesson_node_00047).
3.  **Hyperparameter Tuning:**
    *   Perform Grid Search within each fold for the Logistic Regression base learner.
    *   **Regularization `C`:** Search the **High-Regularization Regime** (e.g., `1e-4` to `10.0`). **Cap Max C at 10.0** to prevent overfitting (Cite solution_lesson_node_00012, Cite solution_lesson_node_00022).
    *   **Class Weights:** Search `['balanced', None]` (Cite solution_lesson_node_00028).
    *   **Penalty:** Strictly use **L2 (Ridge)** (Cite solution_lesson_node_00044).
4.  **Ensemble Strategy:**
    *   Train a Bagged Ensemble (`n_estimators=20`) on each fold using the best parameters.

# Evaluation
1.  **Inference:**
    *   Generate raw embeddings for the test set using both backbones.
    *   For each of the 5 trained fold-pipelines:
        *   **View 1:** L2 Normalize MiniLM embeddings.
        *   **View 2:** Project MPNet embeddings using that fold's PCA -> L2 Normalize.
        *   **View 3:** Transform metadata using that fold's QuantileTransformer.
        *   **Fusion:** Concatenate and predict.
2.  **Prediction:**
    *   **Average the probability outputs** from all 5 fold-ensembles. This **CV-Bagging** strategy maximizes stability and generalization (Cite solution_lesson_node_00027).
