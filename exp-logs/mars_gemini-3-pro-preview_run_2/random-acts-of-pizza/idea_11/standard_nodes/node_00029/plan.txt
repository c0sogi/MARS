The implementation strategy follows the **Dimensionality-Controlled Hybrid Early Fusion Strategy** outlined in the provided library files.

1.  **Environment & Setup**: The script initializes the environment by setting random seeds for reproducibility and ensuring the library modules are accessible.
2.  **Training Phase**: It invokes `trainer.run_cv_training()` to execute the 5-fold Stratified Cross-Validation. This process trains the Bagged Logistic Regression ensembles on the training set (`metadata/train.csv`), performing hyperparameter tuning (GridSearch) within each fold to prevent leakage. The resulting pipelines are saved as artifacts.
3.  **Validation Phase**:
    *   The script loads the hold-out validation set (`metadata/val.csv`) using the `DataLoader`.
    *   It iterates through the 5 saved fold-models, loading each pipeline and generating probability predictions for the validation set.
    *   Inference is wrapped in `torch.no_grad()` to optimize performance and disable gradient tracking for the SBERT component.
    *   Predictions are averaged (Ensemble of Ensembles) to produce the final validation scores.
    *   The **Final Validation Metric** (ROC AUC) is computed and printed in the required format.
4.  **Failure Analysis**:
    *   The script calculates the absolute error (`|y_true - y_pred|`) for each validation sample.
    *   It computes the Pearson correlation between this error and all numerical metadata features to identify which variables correlate with model failure.
    *   The top 5 correlations are printed.
5.  **Submission**:
    *   The script compares the validation ROC AUC against the threshold `0.713561265524314`.
    *   If the threshold is exceeded, it calls `inference.generate_submission()` to generate predictions for the test set (`metadata/test.csv`) and save them to `submission/submission.csv`.
