The following script demonstrates the complete machine learning pipeline for the Random Acts of Pizza prediction task using the provided library files.

The strategy for this demonstration is as follows:
1.  **Configuration Overrides**: We dynamically modify the `Config` class to enable `DEBUG` mode and reduce model complexity (fewer estimators, smaller hyperparameter grid). This ensures the code executes rapidly (seconds to minutes) while still exercising all logic paths.
2.  **Data Loading**: We utilize `library.data_loader` to load the training, validation, and test datasets, verifying that the data structures match the expected dimensions and types.
3.  **Feature Engineering**: We explicitly instantiate the `HybridFeaturePipeline` from `library.features`. We demonstrate fitting it on the training data and transforming all splits, verifying that the resulting feature matrices are dense numpy arrays of the correct shape.
4.  **Model Training**: We instantiate the `BaggedLREnsemble` from `library.model`. We run the `optimize_and_fit` method to demonstrate the internal cross-validation and bagging logic.
5.  **Evaluation & Prediction**: We generate predictions on the validation set to calculate the ROC AUC score, ensuring the model learned something (even on a small subset). Finally, we generate predictions for the test set and format them for submission.

This approach verifies the correctness of the individual components and their integration without waiting for a full-scale training run.
