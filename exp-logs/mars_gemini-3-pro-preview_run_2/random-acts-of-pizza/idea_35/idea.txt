Based on the comprehensive failure analysis and the synthesis of lessons learned—specifically the need to resolve **Semantic Redundancy** between backbones (Cite solution_lesson_node_00067) while retaining the benefits of **Asymmetric Dimensionality Reduction** (Cite solution_lesson_node_00046) and **Early Fusion** (Cite solution_lesson_node_00020)—I propose the **Orthogonalized Asymmetric Semantic Fusion (OASF)** strategy.

This strategy structurally evolves the "Dual-Backbone" approach (Idea 30) by changing the feature integration logic from simple "Concatenation" to **"Residual Augmentation"**. Instead of fusing the Anchor (MiniLM) and Auxiliary (MPNet) embeddings directly (which introduces collinearity and dilutes the regularization), we explicitly **orthogonalize** the Auxiliary view with respect to the Anchor. We regress the MPNet embeddings on the MiniLM embeddings and extract the **residuals**—representing the *unique* semantic signal possessed by the larger model that is *not* captured by the smaller one. These residuals are then compressed and fused, ensuring the ensemble adds pure information rather than redundant noise.

# Model
The architecture is a **Bagged Ensemble of Logistic Regression Classifiers** operating on a decorrelated, multi-resolution feature space.

1.  **Anchor Backbone (Primary):** `sentence-transformers/all-MiniLM-L6-v2` (384d).
    *   **Rationale:** We strictly retain this as the foundation. It has the optimal sample-to-feature ratio and serves as the stable, low-variance baseline (Cite solution_lesson_node_00017).
2.  **Auxiliary Backbone (Residual):** `sentence-transformers/all-mpnet-base-v2` (768d).
    *   **Transformation:** **Orthogonalization (Ridge Regression)** followed by **PCA**.
    *   **Rationale:** This addresses **Cite solution_lesson_node_00067**. By removing the linear component of MPNet that is explained by MiniLM, we isolate the "Deep Semantic Delta" (e.g., subtle context, world knowledge). Compressing this delta via PCA (to ~50 dims) implements **Asymmetric Dimensionality Reduction** (Cite solution_lesson_node_00046), providing a dense, non-redundant summary signal.
3.  **Classifier:** **BaggingClassifier** wrapping **Logistic Regression** (Ridge).
    *   **Rationale:** We preserve the high-bias linear core (Cite solution_lesson_node_00005) and use Bagging to reduce variance (Cite solution_lesson_node_00022).

# Data
We construct three distinct feature views and fuse them via **Early Fusion** (Cite solution_lesson_node_00020):

1.  **View 1: Anchor Semantics (384 dims)**
    *   **Input:** Concatenation of `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00025).
    *   **Processing:** Encode with `all-MiniLM-L6-v2` (Frozen).
    *   **Normalization:** Apply **L2 Normalization** to project onto the hypersphere (Cite solution_lesson_node_00015).

2.  **View 2: Residual Semantics (50 dims)**
    *   **Input:** Same text, encoded with `all-mpnet-base-v2` (Frozen).
    *   **Orthogonalization:**
        *   Fit a **Ridge Regressor** mapping $X_{MiniLM} \to X_{MPNet}$ (on training data).
        *   Compute Residuals: $R = X_{MPNet} - \text{Predict}(X_{MiniLM})$.
    *   **Compression:** Apply **PCA (n_components=50)** to the residuals $R$.
    *   **Normalization:** Apply **L2 Normalization** to the projected residuals.
    *   **Rationale:** This ensures the auxiliary features are statistically independent of the anchor features, allowing the linear solver to assign weights efficiently without fighting collinearity.

3.  **View 3: Robust Metadata (~10 dims)**
    *   **Features:** All numerical metadata, **explicitly including** `unix_timestamp_of_request` (Cite solution_lesson_node_00033).
    *   **Scaling:** Apply **QuantileTransformer (output_distribution='normal')** (RankGauss).
    *   **Rationale:** Neutralizes outliers and aligns metadata with the normalized embeddings (Cite solution_lesson_node_00019).
    *   **Exclusions:** Explicitly exclude user history (Cite solution_lesson_node_00060) and weak heuristics (Cite solution_lesson_node_00038).

# Training
1.  **Pipeline Efficiency:**
    *   **Pre-computation:** Compute raw embeddings for both backbones **outside** the cross-validation loop (Cite solution_lesson_node_00031).
    *   **Cache Validation:** Implement strict row-count checks (Cite solution_lesson_node_00034).

2.  **Stratified Cross-Validation:**
    *   Use 5-Fold Stratified CV.
    *   **Encapsulation:** The **Ridge Orthogonalizer**, **PCA**, and **QuantileTransformer** must all be fitted **inside** the cross-validation loop (on training folds only) to prevent statistical leakage (Cite solution_lesson_node_00047).

3.  **Context-Aware Hyperparameter Tuning:**
    *   Perform Grid Search within each fold.
    *   **Crucial:** Tune the hyperparameters of the **Full Bagged Ensemble**, not just the base learner (Cite solution_lesson_node_00066).
    *   **Search Space:**
        *   **Regularization (`C`):** High-Regularization Regime (`1e-4` to `10.0`) (Cite solution_lesson_node_00012).
        *   **Class Weights:** `['balanced', None]` (Cite solution_lesson_node_00028).
        *   **Penalty:** Strictly use **L2 (Ridge)** (Cite solution_lesson_node_00044).

4.  **Ensemble Strategy:**
    *   Train a Bagged Ensemble (`n_estimators=20`) on each fold using the best parameters.

# Evaluation
1.  **Inference:**
    *   Generate raw embeddings for the test set using both backbones.
    *   For each of the 5 trained fold-pipelines:
        *   **Step A:** L2 Normalize MiniLM ($X_A$).
        *   **Step B:** Apply fold's Ridge to $X_A$ to predict MPNet ($X_B'$). Compute $R = X_B - X_B'$.
        *   **Step C:** Project $R$ using fold's PCA -> L2 Normalize.
        *   **Step D:** Transform Metadata using fold's RankGauss.
        *   **Fusion:** Concatenate and predict.
2.  **Prediction:**
    *   **Average the probability outputs** from all 5 fold-ensembles. This **CV-Bagging** strategy maximizes stability and generalization (Cite solution_lesson_node_00027).
