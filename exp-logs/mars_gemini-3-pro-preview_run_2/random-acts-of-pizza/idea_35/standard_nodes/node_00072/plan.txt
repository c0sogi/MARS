Implementation Strategy:
1.  **Initialization**: Set random seeds for reproducibility using `library.utils.set_seed`. Initialize the `Engine` and `DataLoader` classes.
2.  **Training & Validation**: Execute `engine.run_cross_validation(load_cached_data=True)`. This leverages the provided `Engine` to perform 5-fold stratified cross-validation using the OASF strategy (MiniLM + Orthogonalized MPNet + Metadata). This step generates Out-Of-Fold (OOF) predictions for the entire labeled dataset (Train + Validation).
3.  **Metric Calculation**:
    *   Load the OOF predictions (`oof_preds.npy`) and assembled targets (`y_train_full_assembled.npy`) from the working directory.
    *   Reconstruct the split boundary between the training set and the hold-out validation set by loading the raw dataframes via `DataLoader`.
    *   Isolate the predictions and targets corresponding specifically to the hold-out validation set (`val.csv`).
    *   Compute the ROC AUC score on this validation subset and print it as "Final Validation Metric".
4.  **Failure Analysis**:
    *   Compute the absolute error (`|y_true - y_pred|`) for the validation subset.
    *   Calculate the Pearson correlation between this error magnitude and the numerical metadata features (including text length).
    *   Print the correlations to identify features associated with high error.
5.  **Submission**:
    *   Compare the calculated validation AUC against the threshold (`0.7190361601447052`).
    *   If the metric exceeds the threshold, trigger `engine.predict_test(load_cached_data=True)` to generate the submission file.
