This script demonstrates the usage of the provided library modules for the Reddit Pizza Request prediction task. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` class to use a small subset of data and reduced hyperparameters for rapid execution.
2.  **Data Loading**: Demonstrates `DataLoader` to load and merge metadata with raw JSON features.
3.  **Feature Generation**: Demonstrates `FeatureGenerator` to create text embeddings (using SentenceTransformers) and extract tabular metadata.
4.  **Model Verification**: Tests the `StratifiedRandomSubspaceEnsemble` class with synthetic data to ensure the bagging and subspace sampling logic functions correctly.
5.  **Training Pipeline**: Executes the `Trainer` to run a minimal cross-validation loop, saving models and scalers.
6.  **Inference Pipeline**: Executes the `InferenceRunner` to generate predictions on the test set using the trained artifacts.

Validation checks (assertions) are included at each stage to verify data shapes, types, and logic correctness.
