Implementation Strategy:
1.  **Setup & Data Loading**: Initialize the environment (seeds, logging) and use the `DataLoader` to load the training, validation, and test datasets. Concatenate training and validation sets into a full training set to maximize data usage for the Cross-Validation (CV) process, while tracking indices to isolate the hold-out validation set later.
2.  **Feature Generation**: Use `FeatureGenerator` to compute L2-normalized text embeddings (using the pre-trained `all-MiniLM-L6-v2` model) and extract tabular metadata features. This leverages the caching mechanism to avoid redundant computation.
3.  **Stratified Cross-Validation Loop**: Implement a 5-Fold Stratified CV loop manually (instead of using the `Trainer` class directly) to ensure granular access to Out-Of-Fold (OOF) predictions.
    *   For each fold, perform an internal Grid Search to tune the `C` (regularization) and `class_weight` parameters of the base Logistic Regression learners.
    *   Train the `StratifiedRandomSubspaceEnsemble` using the best parameters. This ensemble uses bagging and feature subspace sampling (keeping 100% metadata, 50% text features) to handle high dimensionality.
    *   Generate OOF predictions for the validation fold and accumulate predictions for the test set.
4.  **Validation & Failure Analysis**:
    *   Extract the OOF predictions corresponding specifically to the original hold-out validation set (defined by `metadata/val.csv`).
    *   Calculate and print the required `Final Validation Metric` (ROC AUC).
    *   Perform failure analysis by calculating the absolute error of predictions on the validation set and correlating it with input features (e.g., account age, text length) to identify error sources.
5.  **Submission**: Check if the validation AUC exceeds the specified threshold (0.71417...). If successful, average the test predictions across all folds and save the submission file to `./submission/submission.csv`.
