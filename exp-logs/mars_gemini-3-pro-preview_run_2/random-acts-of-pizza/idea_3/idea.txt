Based on the lessons learned from the failure of the Random Forest (overfitting) and the success of the Logistic Regression (robustness), I propose a **Dual-Branch Stacking Ensemble**. This approach structurally evolves the solution by combining the stability of the linear model (Idea 2) with the non-linear interaction capabilities of gradient boosting, while strictly adhering to the constraints identified in the failure analysis regarding high-dimensional embeddings (Lesson 5) and outliers (Lesson 6).

# Model
The architecture is a **Stacking Ensemble** composed of two distinct Level-1 base learners and a single Level-2 meta-learner:

1.  **Base Learner A (High-Dimensional Linear Branch):** A **Logistic Regression** model. This component is retained from "Idea 2" to preserve the high-bias, low-variance baseline that proved effective on this small dataset. It operates on the full, high-dimensional semantic space to capture linear relationships between text sentiment and success.
2.  **Base Learner B (Low-Dimensional Non-Linear Branch):** A **LightGBM Classifier**. This component is introduced to capture complex, non-linear interactions between metadata and text (e.g., "high account age" amplifies "polite text"). Crucially, to avoid the model collapse observed when feeding raw embeddings to trees, this branch will operate on a **compressed feature space** (dimensionality reduction applied to embeddings).
3.  **Meta-Learner:** A **Logistic Regression** classifier. This layer takes the probability outputs from Base Learners A and B and learns the optimal weighted combination, effectively allowing the model to rely on the linear baseline for most cases while leveraging the tree model only where non-linear signals are strong and stable.

# Data
1.  **Feature Extraction (Text):** Continue using the pre-trained **Sentence Transformer** (e.g., `all-MiniLM-L6-v2`) to encode `request_title` and `request_text_edit_aware` into 384-dimensional dense vectors (Cite Idea 2).
2.  **Feature Preprocessing (Tabular):** Apply **RobustScaler** to all numerical metadata features (e.g., `requester_upvotes_minus_downvotes`). This explicitly addresses the heavy-tailed distribution of Reddit karma and decouples prediction error from outlier magnitude (Cite Lesson 6).
3.  **Dimensionality Reduction (Branch B Only):** Apply **Principal Component Analysis (PCA)** to the text embeddings to reduce them from 384 dimensions to a compact dense vector (e.g., 32 components). This specific step enables the LightGBM model to learn effective splits without the "staircase" problem caused by high-dimensional raw embeddings (Cite Lesson 5).
4.  **Input Construction:**
    *   **Input for Learner A:** `[Raw Embeddings (384) + Scaled Metadata]`
    *   **Input for Learner B:** `[PCA Embeddings (32) + Scaled Metadata]`

# Training
1.  **Cross-Validation Strategy:** Use **Stratified K-Fold Cross-Validation** (e.g., 5 folds) to generate "Out-of-Fold" (OOF) predictions for the training set. This is essential to prevent data leakage when training the meta-learner.
2.  **Base Learner Training:**
    *   Train Learner A (Logistic Regression) with L2 regularization on the full feature set.
    *   Train Learner B (LightGBM) on the PCA-reduced feature set. Use strict regularization (e.g., `max_depth=3`, `reg_alpha`) to prevent the overfitting observed in the Random Forest approach (Cite Lesson 1, Lesson 3).
3.  **Meta-Learner Training:** Train the Level-2 Logistic Regression on the OOF predictions from A and B. This allows the ensemble to dynamically weight the linear and non-linear signals.

# Evaluation
1.  **Inference:** For each test sample:
    *   Generate embeddings and scale metadata.
    *   Create two feature views: one full (for Learner A) and one PCA-reduced (for Learner B).
    *   Generate probabilities from both base learners.
    *   Feed these probabilities into the meta-learner to produce the final score.
2.  **Validation:** Compare the Stacking AUC against the single Logistic Regression AUC. Success is defined by an improvement in metric stability and score, confirming that the PCA-GBDT branch adds valuable non-linear signal without re-introducing the noise memorization of the original Random Forest.
