To improve the model's performance, I will implement a targeted feature engineering strategy that introduces temporal and text meta-features while optimizing the dimensionality of the input space for the tree-based model.

**Strategy:**
1.  **Temporal Feature Extraction**: The current model uses the raw Unix timestamp, which is suboptimal for capturing cyclic patterns like "time of day" (e.g., dinner time) or "day of week" (e.g., Friday nights). I will extract `hour` and `day_of_week` from the timestamp and apply cyclic encoding (sine/cosine) to preserve their periodic nature.
2.  **Text Meta-Features**: While the SentenceTransformer captures semantic meaning, explicit signals like the length of the request text and title can be strong proxies for "effort" or "desperation." I will add `text_length` and `title_length` as features.
3.  **Dimensionality Tuning**: I will increase the PCA components for the Tree Branch from 32 to 50. This allows the LightGBM model to access more variance from the rich text embeddings without overwhelming it with high dimensionality, striking a balance between information loss and the "curse of dimensionality" (Cite **solution_lesson_node_00005**).
4.  **Robust Scaling**: All new numerical features will be processed via `RobustScaler` to ensure the model remains stable despite potential outliers in text length or account age (Cite **solution_lesson_node_00006**).

-   **`library/config.py`**: Remove the raw `unix_timestamp_of_request` from `NUMERICAL_COLS` (replaced by derived features), increase `N_PCA_COMPONENTS` to 50, and increase `LGBM_EARLY_STOPPING_ROUNDS` to 100.

    def _get_numerical_features(self, df):
        # 1. Base Numerical Features
        # Extract numerical columns defined in Config
        X_base = df[Config.NUMERICAL_COLS].fillna(0).values

        # 2. Derived Features
        # Text Lengths (Proxy for effort/desperation)
        titles = df["request_title"].fillna("").astype(str)
        texts = df["request_text_edit_aware"].fillna("").astype(str)
        
        len_title = titles.apply(len).values.reshape(-1, 1)
        len_text = texts.apply(len).values.reshape(-1, 1)

        # unix_timestamp_of_request is in seconds. Fill NaNs with 0 (1970) to prevent errors.
        timestamps = pd.to_datetime(df["unix_timestamp_of_request"].fillna(0), unit='s')
        
        # Hour of Day (0-23)
        hour = timestamps.dt.hour
        hour_sin = np.sin(2 * np.pi * hour / 24).values.reshape(-1, 1)
        hour_cos = np.cos(2 * np.pi * hour / 24).values.reshape(-1, 1)

        day = timestamps.dt.dayofweek
        day_sin = np.sin(2 * np.pi * day / 7).values.reshape(-1, 1)
