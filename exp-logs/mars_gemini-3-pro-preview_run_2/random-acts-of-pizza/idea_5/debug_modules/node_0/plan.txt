This script demonstrates the end-to-end execution of the pizza request prediction pipeline using the provided library. It performs the following steps:

1.  **Configuration**: Overrides default hyperparameters (epochs, batch size, cross-validation folds) to ensure the script executes quickly within the demonstration context.
2.  **Data Loading**: Uses `data_handler` to load and verify the training, validation, and test datasets from the raw JSON and metadata files.
3.  **Preprocessing**: Demonstrates the `preprocessor` components by scaling tabular data and preparing text examples for the Siamese network.
4.  **Model Training (Siamese Network)**: Uses `siamese_trainer` to fine-tune a SentenceTransformer model on the training data using triplet loss. This learns a text representation optimized for distinguishing successful requests.
5.  **Feature Extraction**: Uses `feature_extractor` to generate the final feature set. It combines the fine-tuned text embeddings with the scaled tabular features.
6.  **Classification**: Uses `classifier` to train a Logistic Regression model with Grid Search cross-validation, evaluates it on the validation set, and generates a submission file for the test set.
