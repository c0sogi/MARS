Based on the lessons learned, specifically **Lesson 00020** (Early Fusion outperforms Late Fusion on small datasets) and **Lesson 00019** (RankGauss + Bagging improves robustness), I will switch from the current Stacking/Late Fusion architecture to an Early Fusion approach. The previous solution's Late Fusion created an information bottleneck, preventing the model from learning joint weights between the semantic text features and the user metadata.

My strategy is as follows:
1.  **Early Fusion (Cite solution_lesson_node_00020)**: I will modify `runfile.py` to concatenate the 384-dimensional text embeddings and the RankGauss-normalized metadata into a single feature matrix before training.
2.  **Unified Hyperparameter Grid (Cite solution_lesson_node_00012)**: I will update `library/config.py` to define a `COMBINED_GRID` that searches a wide range of regularization strengths (`C` from `0.0001` to `10.0`). This addresses the need for strong regularization when using high-dimensional embeddings on small datasets.
3.  **Optimized Parallelism**: I will adjust the `BAGGING_PARAMS` to use `n_jobs=1` so that `GridSearchCV` can efficiently parallelize the search across the available 12 vCPUs without thread oversubscription.

This approach simplifies the pipeline while increasing the model's capacity to find complex decision boundaries that span both text and metadata modalities.

def get_best_estimator(X, y, param_grid, base_builder_func, random_state):
    """
    Helper function to perform GridSearchCV for a specific view.
    Maps parameters to the inner estimator of the BaggingClassifier.
    """
    # Initialize the base bagged model
    base_model = base_builder_func(random_state=random_state)

    # Map grid parameters to the inner estimator (estimator__param)
    # This is required because BaggingClassifier wraps the LogisticRegression
    sklearn_grid = {}
    for key, values in param_grid.items():
        if key in ["C", "penalty", "solver", "class_weight"]:
            sklearn_grid[f"estimator__{key}"] = values
        else:
            sklearn_grid[key] = values

    # Run Grid Search
    grid_search = GridSearchCV(
        estimator=base_model,
        param_grid=sklearn_grid,
        scoring="roc_auc",
        cv=3,  # Inner CV for hyperparameter tuning
        n_jobs=-1,
        verbose=0,
    )
    grid_search.fit(X, y)
    return grid_search.best_estimator_
