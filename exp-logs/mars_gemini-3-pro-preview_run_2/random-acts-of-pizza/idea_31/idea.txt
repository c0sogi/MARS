Based on the comprehensive failure analysis and the synthesis of lessons learned—specifically the proven superiority of **Early Fusion** (Cite solution_lesson_node_00020), the effectiveness of **Asymmetric Dimensionality Reduction** for auxiliary views (Cite solution_lesson_node_00046), and the importance of **Tuning Inside the Ensemble** (Cite solution_lesson_node_00066)—I propose the **Tri-Backbone Asymmetric Early Fusion (TBAEF)** strategy.

This strategy structurally evolves the solution by expanding the "Dual-Backbone" concept (Idea 30) into a **Tri-Backbone Architecture**. It integrates three distinct semantic resolutions: the compact "Anchor" (`MiniLM`), the deep "Auxiliary" (`MPNet`), and a diverse "Structural" backbone (`DistilRoBERTa`). By compressing the two auxiliary backbones via PCA and fusing them with the anchor in a single linear space, we maximize semantic coverage (leveraging different pre-training objectives) while strictly controlling the feature-to-sample ratio to avoid the curse of dimensionality (Cite solution_lesson_node_00017).

# Model
The architecture is a **Bagged Ensemble of Logistic Regression Classifiers** operating on a fused, multi-resolution semantic feature space.

1.  **Anchor Backbone (High-Res):** `sentence-transformers/all-MiniLM-L6-v2` (384d).
    *   **Rationale:** We strictly retain this as the primary view. It has the best sample-to-feature ratio and serves as the stable, low-variance foundation (Cite solution_lesson_node_00017).
2.  **Auxiliary Backbone 1 (Deep Semantics):** `sentence-transformers/all-mpnet-base-v2` (768d).
    *   **Transformation:** **PCA (50 components)**.
    *   **Rationale:** Captures "Deep Semantics" and world knowledge. Compressed to 50d to provide a dense summary signal without overwhelming the anchor (Cite solution_lesson_node_00046).
3.  **Auxiliary Backbone 2 (Diverse Semantics):** `sentence-transformers/all-distilroberta-v1` (768d).
    *   **Transformation:** **PCA (50 components)**.
    *   **Rationale:** Adds architectural diversity (RoBERTa vs. MPNet/MiniLM). Compressed to 50d. This creates a "Tri-View" consensus where the linear model can leverage agreement between different model families.
4.  **Classifier:** **BaggingClassifier** wrapping **Logistic Regression** (Ridge).
    *   **Rationale:** We preserve the high-bias linear core (Cite solution_lesson_node_00005) and use Bagging to reduce variance (Cite solution_lesson_node_00022).

# Data
We construct four distinct feature views and fuse them via **Early Fusion** (Cite solution_lesson_node_00020):

1.  **View 1: Anchor Semantics (384 dims)**
    *   **Input:** Concatenation of `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00025).
    *   **Processing:** Encode with `all-MiniLM-L6-v2` (Frozen).
    *   **Normalization:** Apply **L2 Normalization** to project onto the hypersphere (Cite solution_lesson_node_00015).

2.  **View 2: Deep Aux Semantics (50 dims)**
    *   **Input:** Same text.
    *   **Processing:** Encode with `all-mpnet-base-v2` (Frozen).
    *   **Compression:** Apply **PCA (n_components=50)**.
    *   **Normalization:** Apply **L2 Normalization** *after* PCA (Cite solution_lesson_node_00015).

3.  **View 3: Diverse Aux Semantics (50 dims)**
    *   **Input:** Same text.
    *   **Processing:** Encode with `all-distilroberta-v1` (Frozen).
    *   **Compression:** Apply **PCA (n_components=50)**.
    *   **Normalization:** Apply **L2 Normalization** *after* PCA.

4.  **View 4: Robust Metadata (~10 dims)**
    *   **Features:** All numerical metadata, **explicitly including** `unix_timestamp_of_request` (Cite solution_lesson_node_00033).
    *   **Scaling:** Apply **QuantileTransformer (output_distribution='normal')** (RankGauss).
    *   **Rationale:** Neutralizes outliers and aligns metadata with the normalized embeddings (Cite solution_lesson_node_00019).

# Training
1.  **Pipeline Efficiency:**
    *   **Pre-computation:** Compute raw embeddings for all three backbones **outside** the cross-validation loop to avoid redundant GPU inference (Cite solution_lesson_node_00031).
2.  **Stratified Cross-Validation:**
    *   Use 5-Fold Stratified CV.
    *   **Encapsulation:** The PCA (for Views 2 & 3) and QuantileTransformer (for View 4) must be fitted **inside** the cross-validation loop (on training folds only) to prevent statistical leakage (Cite solution_lesson_node_00047).
3.  **Hyperparameter Tuning (Context-Aware):**
    *   Perform Grid Search within each fold.
    *   **Crucial:** Tune the hyperparameters (`C`, `class_weight`) of the **Bagged Ensemble** (i.e., evaluate the full ensemble for each candidate), not just the base learner. This ensures the regularization is optimized for the aggregate capacity of the ensemble (Cite solution_lesson_node_00066).
    *   **Search Space:**
        *   `C`: High-Regularization Regime (`1e-4` to `10.0`) (Cite solution_lesson_node_00012).
        *   `class_weight`: `['balanced', None]` (Cite solution_lesson_node_00028).
4.  **Ensemble Strategy:**
    *   Train a Bagged Ensemble (`n_estimators=20`) on each fold using the best parameters.

# Evaluation
1.  **Inference:**
    *   Generate raw embeddings for the test set using all three backbones.
    *   For each of the 5 trained fold-pipelines:
        *   **View 1:** L2 Normalize MiniLM.
        *   **View 2:** Project MPNet using fold's PCA -> L2 Normalize.
        *   **View 3:** Project DistilRoBERTa using fold's PCA -> L2 Normalize.
        *   **View 4:** Transform metadata using fold's RankGauss.
        *   **Fusion:** Concatenate and predict.
2.  **Prediction:**
    *   **Average the probability outputs** from all 5 fold-ensembles. This **CV-Bagging** strategy maximizes stability and generalization (Cite solution_lesson_node_00027).
