This script demonstrates the end-to-end execution of the machine learning pipeline using the provided library files. It performs the following steps:
1.  **Environment Setup**: Initializes the random seed for reproducibility.
2.  **Data Loading**: Loads a small subset of the data (Debug Mode) using `data_loader`.
3.  **Embedding Generation**: Generates embeddings for the debug subset using `embedding_manager`.
4.  **Pipeline Verification**: Manually instantiates the Scikit-Learn pipeline from `pipeline_factory` and tests it with synthetic data to verify dimensions and transformations.
5.  **Training Loop**: Executes the full Cross-Validation training process via `trainer` on the debug dataset.
6.  **Inference**: Generates predictions and a submission file using `inference`.
7.  **Validation**: Checks the integrity of the generated outputs.
