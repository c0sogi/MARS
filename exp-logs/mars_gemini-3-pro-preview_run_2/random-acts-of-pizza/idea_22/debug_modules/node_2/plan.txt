The `pyarrow.lib.ArrowInvalid` error occurs because the `post_was_edited` column contains mixed data types (booleans for unedited posts and float timestamps for edited ones), which violates the strict schema requirements of the Parquet file format. As detailed in **Cite debug_lesson_1**, the solution is to explicitly normalize this column into a single homogeneous type before serialization. I will modify `library/data_loader.py` to convert `post_was_edited` into a binary integer representation (0 for False, 1 for True/Timestamp) in both the `load_labeled_data` and `load_test_data` functions.
