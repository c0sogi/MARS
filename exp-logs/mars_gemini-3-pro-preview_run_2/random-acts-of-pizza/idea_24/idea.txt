Based on the comprehensive failure analysis and the synthesis of lessons learned—specifically the need to resolve **Signal Dilution** in Early Fusion (Cite solution_lesson_node_00026), the requirement for **Asymmetric Dimensionality Reduction** (Cite solution_lesson_node_00046), and the potential of **Aggregate Statistics** for user history (Cite solution_lesson_node_00051)—I propose the **Passthrough-Stacked Hybrid Linear Ensemble (PSHLE)**.

This strategy structurally evolves the solution by adopting a **Passthrough Stacking Architecture**. Instead of concatenating high-dimensional text embeddings directly with low-dimensional metadata (which causes the linear solver to under-weight the metadata, Lesson 26), or stacking purely on predictions (which bottlenecks the metadata signal, Lesson 20), we employ a hybrid approach. We compress the high-dimensional text and sparse history into dense probability scores ("Experts") and fuse them with the **raw** (scaled) metadata in a final meta-learner. This ensures the model applies strong regularization to the noisy semantic views while retaining full access to the high-signal user context.

# Model
The architecture is a **Two-Stage Stacked Ensemble** composed of Modality Experts and a Passthrough Meta-Learner.

1.  **Stage 1: Modality Experts (Base Learners)**
    *   **Text Expert:** A **Bagged Logistic Regression** trained on SBERT embeddings.
        *   **Role:** Compresses the 384-dimensional semantic space into a single "Semantic Success Probability".
        *   **Rationale:** Applies strict regularization to the high-dimensional text view (Cite solution_lesson_node_00012) and reduces it to a scalar, preventing it from overwhelming the metadata in the final stage (Cite solution_lesson_node_00046).
    *   **History Expert:** A **Bayesian Target Encoder**.
        *   **Role:** Computes the "Historical Success Propensity" of the user's subreddits.
        *   **Rationale:** This implements the "Aggregate Statistics" approach suggested in **Cite solution_lesson_node_00051**, replacing the failed SBERT/LDA/PLS approaches. It converts the sparse bag-of-subreddits into a dense scalar (mean target value of associated communities) without introducing noise.

2.  **Stage 2: Passthrough Meta-Learner**
    *   **Architecture:** A **Bagged Logistic Regression**.
    *   **Input:** Concatenation of `[Text_Expert_Probability, History_Expert_Score, RankGauss_Metadata]`.
    *   **Rationale:** By passing the metadata *through* to the second stage (rather than using a metadata base learner), we allow the meta-learner to learn the optimal weighting between the semantic signal and the user's constraints (e.g., "High sentiment score is only valid if account age > 30 days"). This resolves the "Information Bottleneck" of pure stacking (Cite solution_lesson_node_00020).

# Data
1.  **Text Preprocessing:**
    *   Concatenate `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00025).
    *   Encode using `sentence-transformers/all-MiniLM-L6-v2` (Frozen).
    *   **Crucial Step:** Apply **L2 Normalization** (Cite solution_lesson_node_00015).

2.  **History Preprocessing (Bayesian Encoding):**
    *   For each subreddit in `requester_subreddits_at_request`, calculate the smoothed mean target value from the training set: $\mu_s = \frac{C \cdot \mu_{global} + \sum y}{C + n}$.
    *   For each user, aggregate these scores (e.g., mean) to produce a single `history_score`.
    *   **Leakage Prevention:** This must be computed using **Out-of-Fold (OOF)** logic within the training set to prevent target leakage (Cite solution_lesson_node_00047).

3.  **Metadata Preprocessing:**
    *   Explicitly include `unix_timestamp_of_request` (Cite solution_lesson_node_00033).
    *   Apply **QuantileTransformer (RankGauss)** to all numerical features (Cite solution_lesson_node_00019).

# Training
1.  **Strategy:** **Nested Cross-Validation Stacking (CV-Bagging)**.
    *   We use a 5-Fold Stratified CV for the overall process.
    *   **Inside each fold:**
        1.  **Train Text Expert:** Train on the fold's training data. Predict probabilities for the fold's validation set (OOF) and the test set.
        2.  **Train History Expert:** Compute target encodings on the fold's training data. Map to the fold's validation set (OOF) and test set. Handle new subreddits in validation/test by assigning the global training mean.
        3.  **Train Meta-Learner:** Train on the `[Text_OOF, History_OOF, Metadata_Train]` matrix.
        4.  **Predict:** Generate predictions for the test set using the Meta-Learner fed with `[Text_Test_Pred, History_Test_Pred, Metadata_Test]`.

2.  **Hyperparameter Tuning:**
    *   **Text Expert:** Grid search `C` in the **High-Regularization Regime** (`1e-4` to `10.0`) (Cite solution_lesson_node_00022).
    *   **Meta-Learner:** Grid search `C` in a **Lower-Regularization Regime** (e.g., `0.1` to `100.0`), as the inputs are now low-dimensional and high-signal.
    *   **Class Weights:** Search `['balanced', None]` for both (Cite solution_lesson_node_00028).

# Evaluation
1.  **Inference:**
    *   The final prediction for each test sample is the **average of the probabilities** produced by the 5 fold-specific Meta-Learners.
    *   This **CV-Bagging** approach maximizes stability and generalization (Cite solution_lesson_node_00027).
