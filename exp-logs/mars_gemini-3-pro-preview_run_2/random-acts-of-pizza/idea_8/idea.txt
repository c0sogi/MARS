Based on the comprehensive failure analysis and the synthesis of lessons learned—specifically the trade-off between embedding quality and dimensionality (Cite solution_lesson_node_00017), the necessity of outlier-robust scaling (Cite solution_lesson_node_00019), and the superiority of early fusion linear models (Cite solution_lesson_node_00020)—I propose a **Projected Semantic-Interaction Ensemble**.

This strategy structurally evolves the solution by:
1.  **Upgrading the Backbone with Projection:** Moving from "Native Small Embeddings" (MiniLM) to "Projected Large Embeddings" (MPNet + PCA). This allows us to leverage the superior semantic reasoning of a larger model while strictly controlling dimensionality to avoid the "curse of dimensionality" identified in Lesson 17.
2.  **Introducing Metadata Interactions:** Explicitly engineering non-linear interactions (Polynomial Features) for the metadata branch *only*. This addresses the limitation of linear models in capturing conditional user states (e.g., "High Account Age" $\times$ "Low Karma") without exposing the model to the overfitting risks of tree-based interaction learning (Cite solution_lesson_node_00005).

# Model
The architecture is a **Bagged Ensemble of Logistic Regression Classifiers** that operates on a fused, dimensionality-controlled feature space.

1.  **Text Branch (Projected Semantics):**
    *   **Backbone:** `sentence-transformers/all-mpnet-base-v2`. This model (768d) provides richer semantic representations than the previously used `all-MiniLM-L6-v2` (384d).
    *   **Projection Layer:** **Principal Component Analysis (PCA)** reducing the 768 dimensions to **256 components**.
    *   **Rationale:** This explicitly implements the recommendation from **Cite solution_lesson_node_00017**. It captures the "smarter" semantics of the large model but compresses them into a dense vector smaller than the MiniLM baseline, improving the sample-to-feature ratio from ~6:1 to ~9:1 and reducing the risk of overfitting.

2.  **Metadata Branch (Interaction-Aware):**
    *   **Transformation:** **QuantileTransformer (RankGauss)** followed by **PolynomialFeatures (Degree=2, Interaction Only)**.
    *   **Rationale:** Linear models are additive and cannot natively see that "Zero Karma" is only suspicious if "Account Age" is high. Polynomial interactions bridge this gap. We apply this *only* to metadata (low dimensional) to avoid the combinatorial explosion that caused failure in text hashing approaches (Cite solution_lesson_node_00001).

3.  **Classifier:**
    *   **BaggingClassifier** wrapping **Logistic Regression**.
    *   **Rationale:** Retains the high-bias, low-variance properties of the linear model (Cite solution_lesson_node_00005) while using bagging to stabilize predictions against the variance of the projected feature space (Cite solution_lesson_node_00022).

# Data
1.  **Text Preprocessing:**
    *   Encode all text (Train + Test) using the frozen `all-mpnet-base-v2` model.
    *   Fit **PCA (n_components=256)** on the training embeddings and transform both train and test sets.
    *   **Crucial Step:** Apply **L2 Normalization** *after* PCA. This ensures the projected features lie on the hypersphere, strictly aligning their magnitude for the linear solver (Cite solution_lesson_node_00015).

2.  **Tabular Preprocessing:**
    *   Apply **QuantileTransformer (output_distribution='normal')** to numerical metadata. This neutralizes the extreme outliers (Cite solution_lesson_node_00006, Cite solution_lesson_node_00019).
    *   Generate **Polynomial Interaction Features** (e.g., `feature_A * feature_B`).
    *   Apply **StandardScaler** to the resulting interaction features to ensure the products of normal variables (which are heavy-tailed) are re-centered and scaled before fusion.

3.  **Fusion:**
    *   Concatenate `[Projected Text (256d)]` and `[Interaction Metadata (~60-100d)]`. This Early Fusion allows the linear model to jointly weight semantic and behavioral signals (Cite solution_lesson_node_00020).

# Training
1.  **Hyperparameter Tuning:**
    *   Perform **Stratified K-Fold Cross-Validation**.
    *   **Constrained Search:** Search for the regularization parameter `C` in the Logistic Regression, but **cap the upper limit** (e.g., max `C=10.0`). This prevents the selection of under-regularized models that exploit noise in the cross-validation folds, a critical stability fix identified in **Cite solution_lesson_node_00022**.
    *   Tune the Bagging parameters (e.g., `max_samples`, `max_features`) to ensure diversity.

2.  **Class Weighting:**
    *   Use `class_weight='balanced'` to handle the 3:1 imbalance.

# Evaluation
1.  **Inference:**
    *   Generate MPNet embeddings for the test set.
    *   Project using the training set's PCA and L2 normalize.
    *   Transform metadata using the training set's QuantileTransformer, generate interactions, and scale.
    *   Pass the fused vector to the Bagged Ensemble.
2.  **Prediction:**
    *   Average the probability outputs from all bagged estimators to produce the final score. This is expected to yield a higher AUC by combining the superior semantics of MPNet with the interaction-aware robustness of the metadata branch.
