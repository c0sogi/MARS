Based on the comprehensive failure analysis and the synthesis of lessons learned—specifically the conflict between **Semantic Redundancy** (Cite solution_lesson_node_00067) and the **Curse of Dimensionality** (Cite solution_lesson_node_00017), and the proven superiority of **Early Fusion** (Cite solution_lesson_node_00020)—I propose the **Joint-Backbone Principal Component Ensemble (JBPCE)** strategy.

This strategy structurally evolves the "Asymmetric Dual-Backbone" approach (Idea 30) by changing the fusion paradigm. Instead of manually enforcing asymmetry (keeping one backbone full and compressing the other), we apply **Joint Dimensionality Reduction**. We concatenate the normalized embeddings from both the compact "Anchor" (MiniLM) and the deep "Auxiliary" (MPNet) *before* applying PCA. This allows the unsupervised projection to identify the most salient semantic directions across the combined feature space, effectively distilling the shared and complementary signals of both models into a compact dense vector. This resolves the redundancy issue while strictly controlling the feature-to-sample ratio.

# Model
The architecture is a **Bagged Ensemble of Logistic Regression Classifiers** operating on a fused, dimensionality-optimized feature space.

1.  **Dual-Backbone Feature Extraction:**
    *   **Backbone A:** `sentence-transformers/all-MiniLM-L6-v2` (384d). Retained for its high sample-efficiency (Cite solution_lesson_node_00017).
    *   **Backbone B:** `sentence-transformers/all-mpnet-base-v2` (768d). Retained for its deep world knowledge.
    *   **Joint Projection:** **Principal Component Analysis (PCA)** applied to the *concatenation* of A and B.
    *   **Rationale:** Unlike Idea 30 (which compressed only B), or Idea 31 (which added C and caused redundancy), Joint PCA dynamically selects the principal components of the *combined* semantic space. This eliminates the redundant directions shared by both SBERT models (Cite solution_lesson_node_00067) while preserving the unique high-variance signals from each, resulting in a more efficient dense representation.

2.  **Classifier:** **BaggingClassifier** wrapping **Logistic Regression** (Ridge).
    *   **Rationale:** We preserve the high-bias linear core (Cite solution_lesson_node_00005) and use Bagging with standard bootstrapping (`max_samples=1.0`) to reduce variance (Cite solution_lesson_node_00022, Cite solution_lesson_node_00031).

# Data
We construct two primary feature views and fuse them via **Early Fusion** (Cite solution_lesson_node_00020):

1.  **View 1: Joint Semantic Projection (Tunable Dims)**
    *   **Input:** Concatenation of `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00025).
    *   **Processing:**
        1.  Encode with `all-MiniLM-L6-v2` -> Apply **L2 Normalization**.
        2.  Encode with `all-mpnet-base-v2` -> Apply **L2 Normalization**.
        3.  **Concatenate** the two normalized vectors (384 + 768 = 1152 dims).
        4.  Apply **PCA** to reduce to **K dimensions** (e.g., 100-250).
        5.  Apply **L2 Normalization** to the PCA output.
    *   **Rationale:** Normalizing before concatenation ensures both backbones contribute equally to the variance analysis. Normalizing after PCA ensures the final features lie on the hypersphere for the linear solver (Cite solution_lesson_node_00015).

2.  **View 2: Robust Metadata (~10 dims)**
    *   **Features:** All numerical metadata, **explicitly including** `unix_timestamp_of_request` (Cite solution_lesson_node_00033).
    *   **Scaling:** Apply **QuantileTransformer (output_distribution='normal')** (RankGauss).
    *   **Rationale:** This neutralizes outliers and aligns the metadata distribution with the normalized embeddings (Cite solution_lesson_node_00019).

# Training
1.  **Pipeline Efficiency:**
    *   **Pre-computation:** Compute raw embeddings for both backbones **outside** the cross-validation loop to avoid redundant GPU inference (Cite solution_lesson_node_00031).
    *   **Cache Validation:** Implement strict row-count checks (Cite solution_lesson_node_00034).

2.  **Stratified Cross-Validation:**
    *   Use 5-Fold Stratified CV.
    *   **Encapsulation:** The Joint PCA and QuantileTransformer must be fitted **inside** the cross-validation loop (on training folds only) to prevent statistical leakage (Cite solution_lesson_node_00047).

3.  **Context-Aware Hyperparameter Tuning:**
    *   Perform Grid Search within each fold.
    *   **Crucial:** Tune the hyperparameters of the **Full Bagged Ensemble**, not just the base learner (Cite solution_lesson_node_00066).
    *   **Search Space:**
        *   **PCA Components (`n_components`):** Tune this to find the optimal compression rate (e.g., `[100, 150, 200, 250]`). This directly addresses the Curse of Dimensionality (Cite solution_lesson_node_00017).
        *   **Regularization (`C`):** High-Regularization Regime (`1e-4` to `10.0`) (Cite solution_lesson_node_00012).
        *   **Class Weights:** `['balanced', None]` (Cite solution_lesson_node_00028).

4.  **Ensemble Strategy:**
    *   Train a Bagged Ensemble (`n_estimators=20`) on each fold using the best parameters.

# Evaluation
1.  **Inference:**
    *   Generate raw embeddings for the test set using both backbones.
    *   For each of the 5 trained fold-pipelines:
        *   L2 Normalize both -> Concatenate -> Project using fold's PCA -> L2 Normalize.
        *   Transform Metadata using fold's RankGauss.
        *   Concatenate and predict.
2.  **Prediction:**
    *   **Average the probability outputs** from all 5 fold-ensembles. This **CV-Bagging** strategy maximizes stability and generalization (Cite solution_lesson_node_00027).
