The `ValueError` occurs because the `TextEmbedder.get_embeddings` method strictly enforces that the `split_name` must be one of "train", "val", or "test" to map to a predefined cache path in `Config`. The `runfile.py` script attempts to use a custom split name `"train_demo_subset"` to process a small data sample in isolation. This aligns with the principle of segregating cached artifacts when processing data subsets to avoid collisions with the full dataset (Cite debug_lesson_3). To fix this, I will modify the `get_embeddings` method to dynamically generate a cache path for unknown split names instead of raising an error, allowing custom subsets to be processed and cached safely.
