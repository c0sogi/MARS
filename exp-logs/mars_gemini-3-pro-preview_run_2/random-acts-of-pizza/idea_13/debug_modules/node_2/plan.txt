The issue is that the `QuantileTransformer` (RankGauss) fails to produce a distribution with a mean close to 0 when the input data is zero-inflated (contains many identical values, like 0). This causes the assertion `abs(feat_mean) < 0.5` in `runfile.py` to fail. To fix this, I will modify `TabularProcessor` in `library/feature_engineering.py` to apply a `StandardScaler` after the `QuantileTransformer`. This ensures the output features are strictly centered at 0 with unit variance, satisfying the assertion and improving numerical stability for the linear model.
