Implementation strategy:
1.  **Setup & Imports**: Import the provided library modules (`config`, `utils`, `data_loader`, `feature_engineering`, `model_factory`) to leverage the existing codebase. Set random seeds for reproducibility.
2.  **Data Loading**: Use `PizzaDataLoader` to load the training, validation, and test datasets. This handles reading the JSON files and merging them with the metadata splits.
3.  **Feature Engineering**:
    *   Use `TextEmbedder` to generate L2-normalized embeddings for all splits. This uses the `sentence-transformers` model defined in the config.
    *   Use `TabularProcessor` to impute and apply RankGauss transformation to the numeric metadata.
4.  **Hyperparameter Tuning (Grid Search)**:
    *   Implement a nested loop to search over the hyperparameter space defined in `Config.GRID_SEARCH_PARAMS` (`alpha`, `C`, `class_weight`).
    *   For each combination, fuse the text and tabular features using `FeatureFuser` with the specific `alpha` (Modality Balance Factor).
    *   Train the `BaggingClassifier` (wrapping Logistic Regression) on the training set.
    *   Evaluate the model on the **hold-out validation set** (`val_df`) to compute the AUC.
    *   Track the best model and parameters based on the validation AUC.
5.  **Validation Reporting**: Print the "Final Validation Metric" (AUC) on the hold-out set as required.
6.  **Failure Analysis**:
    *   Calculate the absolute prediction error on the validation set using the best model.
    *   Compute and print the correlation between this error and the raw numeric features to identify systematic failure modes.
7.  **Submission**:
    *   Compare the best validation AUC against the threshold (0.7141749705260098).
    *   If the threshold is met, fuse the test set features using the optimal `alpha`, generate predictions, and save the `submission.csv` file.
