The implementation strategy involves orchestrating the Multi-Field Asymmetric Dual-Backbone Ensemble (MF-ADBE) pipeline using the provided library modules.

1.  **Setup**: Initialize the environment with a fixed random seed and a logger for reproducibility and tracking.
2.  **Data Loading**: Utilize `library.embedding_manager.generate_embeddings` to load the pre-computed embeddings for the fixed Train, Validation, and Test splits. This function handles caching and GPU acceleration automatically.
3.  **Pipeline Construction**: Build the model pipeline using `library.pipeline_factory.create_model_pipeline`. This pipeline integrates the multi-view features (Title, Body, Global Context, Metadata) and feeds them into a Bagged Logistic Regression classifier.
4.  **Training & Tuning**: Perform a Grid Search with 3-fold cross-validation on the training set to find the optimal hyperparameters (`C` and `class_weight`) for the ensemble.
5.  **Validation**: Evaluate the best model on the hold-out validation set to compute the ROC AUC. The result is printed in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Analyze the model's performance by calculating the correlation between the prediction error magnitude and the numerical metadata features on the validation set. This identifies which features are associated with higher error rates.
7.  **Submission**: Compare the validation AUC against the threshold (0.7190361601447052). If the model performs sufficiently well, generate predictions for the test set and save them to `submission.csv` in the required format.
