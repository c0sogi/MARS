The following script demonstrates the usage of the provided library components for the pizza request success prediction task. It sequentially verifies the data loading, embedding generation, feature engineering, model training, and full pipeline execution.

To ensure the demonstration runs quickly and robustly within the provided environment:
1.  **Configuration Overrides**: We modify `Config` parameters (e.g., reducing PCA components, cross-validation folds, and grid search space) to support small sample sizes and fast execution.
2.  **Sample Sizes**: We use small subsets of data (10-20 rows) to test logic without waiting for full dataset processing.
3.  **Validation**: Assertions are used to verify shapes, types, and file outputs at each step.
