The implementation strategy is as follows:

1.  **Setup & Configuration**: Import the necessary modules from the provided `library` package. Set a fixed random seed for reproducibility. Define a small `DEMO_SIZE` (e.g., 50 samples) to ensure the script executes quickly within the time constraints.
2.  **Data Loading**: Use `library.data_loader.get_processed_data` to load a subset of both the training and test datasets. This handles metadata merging, text concatenation, and numerical feature extraction.
3.  **Feature Generation (Embeddings)**: Instantiate the `EmbeddingService`. Generate "Primary" (MiniLM) and "Auxiliary" (MPNet) embeddings for the text data of the loaded subsets. Store these embeddings in temporary demo-specific cache files to avoid overwriting full-run artifacts.
4.  **Data Preparation**: Extract the numerical metadata and target labels from the dataframes into NumPy arrays suitable for the training pipeline.
5.  **Model Training**: Execute the `library.model_trainer.run_cross_validation` function. This validates the `ADBEFTransformer` (which handles PCA, Quantile Transformation, and Fusion) and the Logistic Regression + Bagging pipeline on the 5-fold split of the demo data.
6.  **Inference & Submission**: Use the trained pipelines to generate predictions on the test subset via `library.model_trainer.generate_submission`.
7.  **Validation**: Perform assertions to verify that the submission file is created, has the correct dimensions, and contains valid probability scores.
