I will implement a targeted optimization strategy focusing on model capacity and geometric completeness, supported by the provided lessons.

**Strategy:**
1.  **Increase Model Capacity:** I will scale up the Directional Message Passing Neural Network (DMPNN) by increasing the hidden dimension from 128 to 256 and the number of interaction blocks from 6 to 9. This leverages the available A100 GPU to capture more complex dependencies in the molecular graphs.
2.  **Symmetric & Contextual Readout (Cite Lesson 00002):** The previous solution used a single directed edge ($u \to v$) to predict the coupling between atoms $u$ and $v$. However, scalar coupling is a symmetric property dependent on the electronic environment of both atoms. I will modify the architecture to:
    *   Explicitly use edge embeddings for both directions ($h_{uv}$ and $h_{vu}$).
    *   Update node embeddings by aggregating all incoming messages ($h_u' = h_u + \sum h_{ku}$) before the readout.
    *   This ensures the final regression block has a complete, symmetric view of the local geometry and electronic environment.
3.  **Efficiency:** I will increase the batch size to 128 to maintain training speed with the larger model.

The implementation involves modifying `config.py` for hyperparameters, `data.py` to index reverse edges, `model.py` to implement the symmetric readout, and `runfile.py` to update the submission threshold.

class OutputBlock(nn.Module):
    """
    Predicts the scalar coupling constant for specific atom pairs.
    Concatenates the final edge embedding, atom embeddings, and coupling type embedding.
    """

    def __init__(self, hidden_dim, num_coupling_types, output_dim):
        super(OutputBlock, self).__init__()
        self.type_embedding = nn.Embedding(num_coupling_types, hidden_dim)

        # Input: EdgeState + AtomSrc + AtomDst + CouplingType
        input_dim = 4 * hidden_dim

        self.mlp = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.SiLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.SiLU(),
            nn.Linear(hidden_dim, output_dim),
        )

    def forward(self, h_edges, h_nodes, target_edge_index, target_type, edge_index):
        # h_edges: (NumEdges, Hidden) - Final edge representations
        # h_nodes: (NumNodes, Hidden) - Initial atom embeddings
        # target_edge_index: (NumTargets,) - Indices of edges corresponding to coupling pairs
        # target_type: (NumTargets,) - Indices of coupling types
        # edge_index: (2, NumEdges) - Graph connectivity

        # 1. Gather features for the specific target edges
        h_target_edges = h_edges[target_edge_index]  # (NumTargets, Hidden)

        # 2. Identify the atoms connected by these edges
        src_idx = edge_index[0, target_edge_index]
        dst_idx = edge_index[1, target_edge_index]

        h_src = h_nodes[src_idx]
        h_dst = h_nodes[dst_idx]

        # 3. Embed the coupling type
        h_type = self.type_embedding(target_type)

        # 4. Concatenate all information
        out_input = torch.cat([h_target_edges, h_src, h_dst, h_type], dim=-1)

        # 5. Predict
        out = self.mlp(out_input)

        return out
