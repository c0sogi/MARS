This script demonstrates the end-to-end usage of the provided machine learning pipeline for predicting scalar coupling constants. It performs the following steps:

1.  **Configuration Override**: Adjusts the global `Config` class to run in a lightweight "demo" mode (reduced model size, small dataset subset, minimal epochs) to ensure execution within the time limit.
2.  **Dataset Instantiation**: Initializes the `ChampsDataset` using the training metadata. This triggers the graph construction process (`process_dataset`) and caching mechanism.
3.  **Data Loading**: Sets up a PyTorch `DataLoader` with the custom `collate_graphs` function to handle batching of molecular graphs and coupling indices.
4.  **Target Standardization**: Fits a `CouplingStandardizer` to the training subset to handle the varying scales of different coupling types.
5.  **Model Initialization**: Instantiates the `HGANet` model with the modified hyperparameters.
6.  **Training Loop**: Runs a single epoch of training using `train_one_epoch`, verifying that the loss is calculated correctly.
7.  **Evaluation**: Runs the `evaluate` function to compute the validation metric (Log MAE) on the subset.
8.  **Prediction**: Generates predictions using the `predict` function and formats them into a submission DataFrame.
9.  **Verification**: Includes assertions throughout to validate data shapes, tensor types, and output formats.
