This script performs an Exploratory Data Analysis (EDA) on the molecular scalar coupling constant dataset. It treats the problem primarily as a tabular regression task but incorporates geometric meta-features derived from the molecular structures.

**Strategy:**
1.  **Setup & Loading**: Load the training metadata and the structures file. Optimize memory usage by specifying data types.
2.  **Feature Engineering**: Merge the structure data (3D coordinates) with the training set to calculate the Euclidean distance between atom pairs. This is a critical physical feature for coupling constants.
3.  **Target Analysis**: Analyze the distribution, skewness, and kurtosis of the `scalar_coupling_constant`.
4.  **Input Data Analysis**:
    *   **Tabular**: Analyze atom indices and coupling types (cardinality, counts).
    *   **Geometric (Meta)**: Analyze the calculated bond distances.
5.  **Relationships**:
    *   Calculate correlations between the target, distance, and indices.
    *   Train a lightweight Random Forest Regressor to estimate feature importance, using the coupling type, atom indices, and distance as features.
6.  **Reporting**: Output the results in the specified format with high precision.
