Based on the empirical evidence and lessons learned from previous experiments, I propose the **Hybrid Geometric-Attention Network (HGA-Net)**. This architecture synthesizes the proven high-fidelity geometric modeling of the Directional Message Passing backbone with a structural innovation—Global Attention—to address the limitations of local receptive fields in capturing long-range electronic effects.

### Model: Hybrid Geometric-Attention Network (HGA-Net)

The model is composed of three integrated stages designed to balance local geometric precision with global molecular context.

1.  **Local Geometric Encoder (Backbone - Exploitation):**
    *   **Architecture:** We will retain the **Directional Message Passing Neural Network (DMPNN)** as the primary feature extractor. This component operates on **directed edges** ($u \to v$) rather than atoms, which is critical for resolving angular dependencies.
    *   **Geometric Basis:** We will strictly preserve the use of **Radial Basis Functions (RBF)** for expanding inter-atomic distances (Cite `solution_lesson_node_00004`) and **Spherical Basis Functions (SBF)** for encoding triplet bond angles (Cite `solution_lesson_node_00014`). This ensures the model maintains "Geometric Completeness" (Cite `solution_lesson_node_00002`).
    *   **Non-Linear Updates:** The update functions within the message passing blocks will be deep **Multi-Layer Perceptrons (MLPs)** with Swish/SiLU activations. We explicitly avoid reducing these to linear projections to prevent information bottlenecks (Cite `solution_lesson_node_00006`).
    *   **Scaling:** We will configure this backbone with a high hidden dimension (e.g., 192 or 256) and sufficient depth (e.g., 6 layers) to prevent underfitting, as identified in scaling experiments (Cite `solution_lesson_node_00015`).

2.  **Global Interaction Module (Structural Innovation):**
    *   **Aggregation:** After the local message passing layers, the learned edge embeddings will be aggregated (via scatter sum) to form atom-level representations.
    *   **Transformer Encoder:** These atom embeddings will be processed by a **Graph Transformer** (Multi-Head Self-Attention). This layer allows every atom to attend to every other atom in the molecule, enabling the model to capture long-range dependencies (such as conjugation or through-space charge transfer) that extend beyond the fixed spatial cutoff of the DMPNN.

3.  **Deterministic Fusion & Readout:**
    *   **Hybrid Feature Construction:** For a target coupling pair (Atom $u$, Atom $v$), the readout input will be constructed by concatenating:
        1.  The **Global** node embedding of Atom $u$ (from the Transformer).
        2.  The **Global** node embedding of Atom $v$ (from the Transformer).
        3.  The **Local** directed edge embedding $e_{u \to v}$ from the DMPNN backbone. *Retaining this local feature is critical to preserve the precise distance/angle information that might be smoothed by global pooling.*
    *   **Prediction Head:** This vector (combined with the coupling type embedding) will pass through a single **Deterministic MLP** (no Dropout) to predict the scalar coupling constant. We strictly avoid Dropout to maintain precision (Cite `solution_lesson_node_00007`) and use a single final readout to avoid the noise associated with hierarchical summation (Cite `solution_lesson_node_00013`).

### Data

*   **Graph Construction:** We will generate molecular graphs directly from the raw `.xyz` files (Cite `solution_lesson_node_00002`). We will use a spatial cutoff (e.g., 5.0 Å) for the DMPNN connectivity, ensuring that all target coupling pairs are connected by an edge.
*   **Basis Pre-computation:** To maximize training throughput, the RBF expansions for distances and SBF expansions for triplet angles will be pre-computed and cached during the data loading phase (Cite `solution_lesson_node_00014`).
*   **Target Normalization:** The target `scalar_coupling_constant` will be standardized (zero mean, unit variance) individually for each coupling type to handle the varying scales.

### Training

*   **Loss Function:** We will minimize the **Mean Absolute Error (MAE)**.
*   **Optimizer:** We will use **AdamW** with a linear warm-up phase followed by a Cosine Annealing learning rate schedule.
*   **Training Horizon:** We will train for an extended duration (e.g., 50-60 epochs). Previous lessons demonstrated that high-capacity geometric models are slow to converge and require longer schedules to reach the loss floor (Cite `solution_lesson_node_00015`).
*   **Regularization:** We will rely on weight decay and the inductive biases of the geometric architecture. We will strictly avoid Dropout (Cite `solution_lesson_node_00007`).

### Evaluation

*   **Inference:** We will explicitly load the test set geometries from the raw `.xyz` files (via `test_metadata.csv`) to ensure 100% data coverage (Cite `solution_lesson_node_00002`). The graphs will be processed through the trained HGA-Net.
*   **Post-Processing:** The model's normalized predictions will be inversely transformed using the training set's statistics (per coupling type) to produce the final `scalar_coupling_constant` values.
