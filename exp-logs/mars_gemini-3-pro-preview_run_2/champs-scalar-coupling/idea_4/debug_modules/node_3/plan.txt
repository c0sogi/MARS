1.  Modify `MoleculeDataset` in `library/data.py` to accept an optional `model_config` argument, ensuring it uses the provided hyperparameters (like `num_rbf`) instead of defaults.
2.  Update `library/engine.py` to pass the engine's `model_config` when initializing training, validation, and test datasets.
3.  Update `runfile.py` to pass the custom `model_config` during the data pipeline verification step.
