Based on the accumulated lessons and the trajectory of previous experiments, I propose the **Stratified-Variance Hybrid Quantile-GLM**.

This solution represents a structural evolution of the "Current Best" (Idea 6) and the "Spatially-Aware" proposal (Idea 7). It addresses the "bag of slices" limitation by enforcing anatomical consistency while retaining the "variance-based" signal maximization that proved effective. It strictly adheres to the statistical optimizations (Quantile/L1, Gamma/GLM) and dimensionality constraints (PCA) identified in the lessons.

### Model

The architecture consists of a **Spatially-Stratified Feature Extractor** feeding into a **Dual-Branch Linear System**, designed to capture both the biological signature of the disease and the statistical properties of the metric.

1.  **Visual Backbone (EfficientNet-B0):** We utilize **EfficientNet-B0** (pre-trained on ImageNet) for texture extraction.
2.  **Stratified-Variance Sampling (Structural Innovation):**
    *   Instead of selecting slices based purely on global variance (which concentrates sampling in the most damaged region, ignoring healthy context) or purely on position (which may miss focal disease), we implement **Zonal Variance Selection**.
    *   The CT scan is partitioned into three anatomical zones: **Apex (Upper 33%)**, **Mid-Zone**, and **Base (Lower 33%)**.
    *   Within *each* zone, we select the single slice with the highest pixel variance. This ensures the model receives a standardized input vector representing the "worst-case" tissue state for each anatomical region, preserving the basal-predominant signature of IPF.
3.  **Hybrid Feature Fusion:**
    *   **Deep Texture:** Features are extracted from the three selected slices and concatenated (preserving spatial order: `[Top, Mid, Bot]`).
    *   **Explicit Volumetrics:** We calculate the **Total Lung Volume** (via voxel counting) and **Mean Lung Density** from the full scan. This reintroduces absolute physical scale, which CNNs often lose, reinforcing the linear prior that lung capacity is proportional to tissue volume **(Cite solution_lesson_node_00006)**.
4.  **Dimensionality Reduction (PCA):** The concatenated Hybrid Vector (Deep Texture + Volumetrics) is compressed using **Principal Component Analysis (PCA)** to ~40 components. This is mandatory to prevent the curse of dimensionality **(Cite solution_lesson_node_00014)**.
5.  **FVC Predictor (Linear Quantile Regressor):**
    *   A **Linear Quantile Regressor** targeting the **Median (q=0.5)**.
    *   **Inputs:** PCA features ($X$), Time ($t$), and **Interaction Terms** ($X \times t$).
    *   **Rationale:** Optimizing for the Median (L1) aligns with the Laplace metric **(Cite solution_lesson_node_00016)**, while interactions enable patient-specific decline rates **(Cite solution_lesson_node_00008)**.
6.  **Uncertainty Predictor (Gamma GLM):**
    *   A **Gamma Generalized Linear Model** with a **Log Link**.
    *   **Inputs:** PCA features ($X$) and **Time Horizon** ($|t|$).
    *   **Rationale:** This models the strictly positive, skewed distribution of absolute errors better than Gaussian models. We include the Time Horizon to capture temporal heteroscedasticity **(Cite solution_lesson_node_00017)** but exclude interaction terms to adhere to **Parsimony in Uncertainty Modeling (Cite solution_lesson_node_00011)**.

### Data

1.  **Preprocessing:**
    *   **Image:** Resize slices to 224x224 and normalize.
    *   **Volumetrics:** Threshold scan (HU -1000 to -400) to compute Total Volume and Mean Density.
    *   **Tabular:** Standard scale Age/Baseline FVC; One-Hot encode Sex/Smoking.
2.  **Feature Engineering:**
    *   Extract features from the 3 Stratified-Variance slices using EfficientNet-B0.
    *   Concatenate `[Top_Feat, Mid_Feat, Bot_Feat, Volume, Density]`.
    *   Fit **PCA** on the training set to reduce this vector to ~40 dimensions.
    *   **FVC Set:** Create interactions: $X_{PCA} \times \text{Weeks}$.
    *   **Uncertainty Set:** Create horizon: $|\text{Weeks} - \text{Baseline\_Weeks}|$.

### Training

The training utilizes **Decoupled Residual Regression (Cite solution_lesson_node_00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the FVC feature set.
    *   **Objective:** Minimize Mean Absolute Error (L1).
2.  **Stage 2 (Residual Computation):**
    *   Generate median predictions for the training set.
    *   Compute absolute residuals: $r = |y_{true} - y_{pred}| + \epsilon$.
3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Gamma GLM** on the Uncertainty feature set with target $r$.
    *   **Objective:** Minimize Gamma Deviance (Negative Log Likelihood).

### Evaluation

1.  **Inference:**
    *   Extract Stratified-Variance features and Volumetrics for the test patient.
    *   Predict Median FVC using the Quantile Regressor.
    *   Predict expected absolute error ($\Delta$) using the Gamma GLM.
2.  **Analytical Scaling:**
    *   Convert $\Delta$ into the final confidence ($\sigma$) using the formula: $\sigma = \Delta \times \sqrt{2}$. This analytically maps the predicted Mean Absolute Deviation to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.
3.  **Formatting:**
    *   Clip $\sigma$ at 70 ml.
