The implementation strategy is as follows:

1.  **Setup & Loading**: Define input/output directories and load `train.csv`, `test.csv`, and `sample_submission.csv` using pandas.
2.  **Training Data Processing**:
    *   Construct the relative file path for each patient's DICOM directory (`train/<PatientID>`).
    *   Use `GroupShuffleSplit` with `random_state=42` to split the training data into 80% training and 20% validation sets based on unique `Patient` IDs. This ensures no patient appears in both sets (preventing data leakage).
    *   Save `train_metadata.csv` and `val_metadata.csv` to the `./metadata` directory.
3.  **Test Data Processing**:
    *   Parse the `Patient_Week` column in `sample_submission.csv` to extract `Patient` IDs and target `Weeks`.
    *   Merge this with the baseline clinical information from `test.csv` (renaming baseline columns to avoid conflicts).
    *   Construct the relative file path for each test patient (`test/<PatientID>`).
    *   Save `test_metadata.csv` to the `./metadata` directory.
4.  **Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (shapes, unique patients, etc.).
    *   Assert that the intersection of patient IDs between train and validation sets is empty.
    *   Randomly sample 1000 file paths from each dataset and verify they exist in the `./input` directory. Raise an error if the missing ratio exceeds 50%.
