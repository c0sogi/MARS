Based on the accumulated lessons and the specific constraints of the dataset, I propose the **L1-Optimized Quantile-Elastic Pipeline**.

This solution structurally evolves the previous "Deep-Feature Varying-Coefficient Elastic Net" by correcting a fundamental statistical mismatch: while the metric is Laplace-based (requiring L1/Median optimization), previous ideas used L2/Mean optimization (ElasticNet). This solution aligns the model's objective function with the evaluation metric while strictly adhering to the linear constraints required for small-sample generalization.

### Model
The architecture consists of a **Hybrid Feature Extractor** feeding into two distinct **Linear Solvers**, each optimizing a different statistical objective:

1.  **Visual Backbone (EfficientNet-B0):** We replace the ResNet18 with an **EfficientNet-B0** to capture richer texture descriptors (e.g., reticular patterns).
2.  **FVC Predictor (Linear Quantile Regressor):**
    *   Instead of an Elastic Net (which minimizes Mean Squared Error), we employ a **Linear Quantile Regressor** targeting the **50th percentile (Median)**.
    *   **Rationale:** The Laplace Log Likelihood metric is maximized when the location parameter is the Median of the distribution, not the Mean. By minimizing the L1 norm (Least Absolute Deviations), this model aligns perfectly with the metric's geometric assumptions.
    *   **Structure:** It uses the **Varying-Coefficient** design, taking static features ($X$), time ($t$), and their interactions ($X \times t$) as input **(Cite solution_lesson_node_00008)**. This preserves the robust **Linear Prior** required for trend extrapolation **(Cite solution_lesson_node_00006)**.
3.  **Uncertainty Predictor (Elastic Net):**
    *   This model predicts the **Mean Absolute Deviation (MAD)** of the FVC predictor's residuals.
    *   **Rationale:** For a Laplace distribution, the Maximum Likelihood Estimator for the scale parameter ($b$) is the mean of the absolute errors. Therefore, we use a standard **Elastic Net (L2 objective)** to estimate this mean.
    *   **Structure:** This model uses **only static features** (no time interactions), adhering to the principle of **Parsimony in Uncertainty Modeling (Cite solution_lesson_node_00011)** to avoid overfitting to noisy residuals.

### Data
1.  **Intelligent Slice Selection:** Instead of random or uniform sampling, we implement a **Variance-Based Selector**. For each patient, we calculate the pixel variance of lung tissue (HU -1000 to -500) for every slice and select the top 5 slices with the highest variance. This ensures the model focuses on heterogeneous tissue (fibrosis/honeycombing) rather than healthy uniform lung.
2.  **Feature Extraction:**
    *   Pass the 5 selected slices through EfficientNet-B0 (pre-trained on ImageNet).
    *   Apply Global Average Pooling and average the vectors across the 5 slices to create a single `Patient_Embedding`.
    *   Apply **PCA** to reduce the embedding to ~30 dimensions.
3.  **Feature Engineering:**
    *   Combine PCA features with clinical data (Age, Sex, Smoking, Baseline FVC/Percent).
    *   Generate **Interaction Terms**: Multiply every static feature by the `Weeks` variable to create the input for the FVC Predictor **(Cite solution_lesson_node_00008)**.

### Training
The training is a sequential two-stage process utilizing **Decoupled Residual Regression (Cite solution_lesson_node_00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the augmented feature set ($X, t, X \times t$) to predict `FVC`.
    *   Objective: Minimize Mean Absolute Error (L1).
2.  **Stage 2 (Uncertainty Optimization):**
    *   Compute the absolute residuals of the training set: $r = |y_{true} - y_{pred\_median}|$.
    *   Train the **Elastic Net** on the static feature set ($X$) to predict $r$.
    *   Objective: Minimize Mean Squared Error (L2) to accurately estimate the conditional mean of the residuals.

### Evaluation
1.  **Prediction:** For each test query, generate the median FVC prediction using the Quantile Regressor and the expected Mean Absolute Deviation (MAD) using the Elastic Net.
2.  **Analytical Scaling:** Convert the predicted MAD into the submission confidence ($\sigma$) using the formula: $\sigma = \text{MAD} \times \sqrt{2}$. This analytically maps the predicted error to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.
3.  **Formatting:** Clip $\sigma$ at 70 ml and format the submission.
