Based on the "Lessons Learned" and the progression of previous experiments, I propose the **MIP-Enhanced Zonal-Quantile Pipeline**.

This solution structurally evolves the "Orthogonal-View" approach (Idea 11) by introducing **Maximum Intensity Projection (MIP)** as a feature engineering innovation. While previous ideas struggled with slice selection (risking missing focal disease or selecting artifacts), MIP mathematically aggregates the 3D volume into a 2D representation that highlights the densest tissue structures (fibrosis) across the entire lung depth. This solution strictly adheres to the successful "Deep Feature + Regularized Linear Solver" paradigm and the statistical optimizations identified in the lessons.

### Model

The architecture consists of a **MIP-Integrated Feature Extractor** feeding into a **Mathematically Specialized Linear System**.

1.  **Visual Backbone (EfficientNet-B0):**
    *   We utilize **EfficientNet-B0** (pre-trained on ImageNet) as the shared feature extractor for all image inputs.
2.  **MIP-Integrated Spatial Sampling (Structural Innovation):**
    *   **Zonal Axial Input:** We retain the **Zonal Partitioning** strategy. The CT scan is split into Upper, Middle, and Lower zones. We select the slice with the highest variance from each zone to capture local texture heterogeneity **(Cite solution_lesson_node_00008)**.
    *   **Coronal MIP Input:** Instead of selecting a single coronal slice (which may miss disease or be obscured by the heart), we compute the **Coronal Maximum Intensity Projection (MIP)** of the masked lung volume. This collapses the 3D array along the Y-axis, creating a single 2D image where every pixel represents the maximum density encountered at that spatial coordinate. This explicitly visualizes the total "fibrosis load" and the Apical-Basal gradient in a robust, noise-resistant manner.
3.  **Volumetric Priors:**
    *   We compute a **Global Density Histogram** (4 bins) over the segmented lung volume. This provides the linear model with an explicit measure of "Total Damaged Volume," reinforcing the **Inductive Bias** that lung capacity is proportional to healthy tissue quantity **(Cite solution_lesson_node_00013)**.
4.  **Dimensionality Reduction (PCA):**
    *   The concatenated features (3 Axial Vectors + 1 MIP Vector + Histogram) are compressed using **Principal Component Analysis (PCA)** to ~40 dimensions. This is mandatory to prevent the curse of dimensionality **(Cite solution_lesson_node_00014)**.
5.  **FVC Predictor (Linear Quantile Regressor):**
    *   A **Linear Quantile Regressor** targeting the **Median (q=0.5)**.
    *   **Inputs:** PCA features ($X$), Time ($t$), and **Interaction Terms** ($X \times t$).
    *   **Rationale:** Optimizing for the Median (L1) aligns with the Laplace Metric **(Cite solution_lesson_node_00016)**. The interactions allow the model to learn patient-specific decline rates **(Cite solution_lesson_node_00008)**.
6.  **Uncertainty Predictor (Elastic Net):**
    *   An **Elastic Net Regressor** (L1+L2 Regularization).
    *   **Inputs:** PCA features ($X$) and **Time Horizon** ($|t - t_{baseline}|$).
    *   **Rationale:** We use Elastic Net to predict the magnitude of errors. We include the Time Horizon to explicitly model **Temporal Heteroscedasticity** **(Cite solution_lesson_node_00017)**. We use a regularized model to prevent overfitting to noisy residuals **(Cite solution_lesson_node_00023)** and exclude complex interactions to maintain **Parsimony** **(Cite solution_lesson_node_00011)**.

### Data

1.  **Preprocessing:**
    *   **Lung Masking:** Threshold the 3D volume (HU -1000 to -400) to isolate lung tissue.
    *   **Zonal Axial:** Split the masked volume into three Z-axis chunks; select the max-variance slice from each.
    *   **Coronal MIP:** Project the masked volume along the Y-axis using the `max` operation. This highlights fibrosis (high density) while ignoring air (low density).
    *   **Normalization:** Resize all 4 images (3 Axial + 1 MIP) to 224x224 and normalize.
    *   **Tabular:** Standard scale continuous features; One-Hot encode categorical features.
2.  **Feature Engineering:**
    *   Extract EfficientNet features for the 4 images. Concatenate with Density Histogram and Clinical Data.
    *   Fit **PCA** on the training set to reduce this dense vector.
    *   **FVC Set:** Generate interactions: $X_{PCA} \times \text{Weeks}$.
    *   **Uncertainty Set:** Append horizon feature: $|\text{Weeks} - \text{Baseline\_Weeks}|$.

### Training

The training utilizes **Decoupled Residual Regression (Cite solution_lesson_node_00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the FVC feature set.
    *   **Objective:** Minimize Mean Absolute Error (L1).
2.  **Stage 2 (Residual Computation):**
    *   Generate median predictions for the training set.
    *   Compute absolute residuals: $r = |y_{true} - y_{pred}|$.
3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Elastic Net** on the Uncertainty feature set with target $r$.
    *   **Objective:** Minimize Mean Squared Error (L2) + Regularization.

### Evaluation

1.  **Inference:**
    *   Generate Axial and MIP images for the test patient. Extract features.
    *   Predict Median FVC using the Quantile Regressor.
    *   Predict the expected Mean Absolute Deviation (MAD) using the Elastic Net.
2.  **Analytical Scaling:**
    *   Convert the predicted MAD into the final confidence ($\sigma$) using the formula: $\sigma = \text{MAD} \times \sqrt{2}$. This analytically maps the predicted error to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.
3.  **Formatting:**
    *   Clip $\sigma$ at 70 ml.
