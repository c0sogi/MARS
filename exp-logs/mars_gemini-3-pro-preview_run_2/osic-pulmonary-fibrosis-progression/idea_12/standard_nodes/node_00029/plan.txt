The implementation strategy follows the "MIP-Enhanced Zonal-Quantile Pipeline" architecture. 

1.  **Setup & Configuration**: We initialize the environment with a fixed random seed to ensure reproducibility.
2.  **Data Management**: We utilize the `DataManager` class to load the training and validation datasets. We explicitly enable caching (`load_cached_data=True`) to leverage pre-computed features (EfficientNet embeddings + Histograms) stored in the working directory, ensuring the "fast baseline" requirement is met.
3.  **Model Training**: We instantiate the `DecoupledQuantileModel`, which encapsulates the PCA dimensionality reduction, Linear Quantile Regressor (for median FVC), and ElasticNet (for uncertainty/sigma). We fit this pipeline on the training data.
4.  **Validation & Metrics**: We perform inference on the validation set. The `score_function` is used to calculate the modified Laplace Log Likelihood. We print this metric with full precision.
5.  **Failure Analysis**: We load the validation metadata to retrieve interpretable features (Age, Weeks, Percent). We calculate the absolute prediction errors and compute their correlation with these features to identify potential sources of bias or failure.
6.  **Submission**: We compare the validation metric against the specified threshold (-6.805292148096688). If the model performs sufficiently well, we load the test dataset, generate predictions, format them according to the competition requirements (`Patient_Week`, `FVC`, `Confidence`), and save the file to `./submission/submission.csv`.
