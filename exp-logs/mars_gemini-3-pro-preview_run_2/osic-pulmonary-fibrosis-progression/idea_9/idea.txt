Based on the "Lessons Learned" and the progression of previous experiments, I propose the **Density-Aware Global-Local Quantile-GLM**.

This solution structurally evolves the previous "Stratified-Variance" approach by bridging the gap between **local texture analysis** (deep learning on slices) and **global functional assessment** (statistical profiling of the full 3D volume). While previous iterations successfully optimized the regression solvers (Quantile/GLM), they relied on "Mean Density" or "Total Volume" scalars, which oversimplify the complex mixture of healthy, emphysematous, and fibrotic tissue. This proposal introduces **Full-Volume Density Histograms** as a structural innovation to explicitly model tissue composition, strictly adhering to the linear and probabilistic constraints identified in the lessons.

### Model

The architecture is a **Hybrid Global-Local System** that feeds a mathematically specialized Dual-Branch Linear Solver.

1.  **Local Texture Branch (Spatially-Stratified EfficientNet):**
    *   **Backbone:** We utilize **EfficientNet-B0** (pre-trained on ImageNet) to extract texture descriptors.
    *   **Input:** We employ **Stratified-Variance Sampling**. The CT scan is split into three anatomical zones (Apex, Mid, Base). Within each zone, we select the single slice with the highest pixel variance. This captures the "worst-case" texture (e.g., honeycombing) while preserving anatomical context.
    *   **Dimensionality Reduction:** The features from the three slices are concatenated and compressed using **Principal Component Analysis (PCA)** to ~30 dimensions. This is mandatory to prevent the curse of dimensionality when feeding deep features into linear solvers **(Cite solution_lesson_node_00014)**.

2.  **Global Structure Branch (3D Density Profiling):**
    *   **Innovation:** Instead of reducing the entire scan to a single scalar (Volume), we compute a **Density Histogram** over the segmented lung volume. We bin the Hounsfield Units (HU) into clinically relevant ranges (e.g., Emphysema: <-950, Healthy: -950 to -700, Fibrosis/Ground Glass: -700 to -400, Consolidation: >-400).
    *   **Rationale:** This explicitly encodes the *proportion* of damaged tissue across the entire organ, providing a robust physical prior that complements the localized texture features. This enforces the **Inductive Bias** that lung capacity is a function of total healthy tissue volume **(Cite solution_lesson_node_00013)**.

3.  **FVC Predictor (Linear Quantile Regressor):**
    *   A **Linear Quantile Regressor** targeting the **Median (q=0.5)**.
    *   **Inputs:** The concatenated vector $[X_{PCA\_Texture}, X_{Histogram}, X_{Clinical}]$.
    *   **Structure:** We employ a **Varying-Coefficient** design by generating explicit **Interaction Terms**: $X_{all} \times \text{Weeks}$. This allows the model to learn patient-specific rates of decline based on both their texture patterns and tissue composition **(Cite solution_lesson_node_00008)**.
    *   **Objective:** Minimizing L1 loss (Median) aligns perfectly with the Laplace Log Likelihood metric **(Cite solution_lesson_node_00016)**.

4.  **Uncertainty Predictor (Gamma GLM):**
    *   A **Generalized Linear Model (GLM)** with a **Gamma distribution** and **Log Link**.
    *   **Inputs:** The static vector $[X_{PCA\_Texture}, X_{Histogram}, X_{Clinical}]$ plus the **Time Horizon** ($|t - t_{baseline}|$).
    *   **Rationale:** This models the absolute error (strictly positive, skewed) using a statistically appropriate distribution. Including the time horizon captures temporal heteroscedasticity (error growing over time) **(Cite solution_lesson_node_00017)**, while excluding complex interaction terms adheres to **Parsimony in Uncertainty Modeling (Cite solution_lesson_node_00011)**.

### Data

1.  **Preprocessing:**
    *   **Global:** Threshold the full 3D scan (HU -1000 to -400) to segment lungs. Compute Total Volume and the normalized 4-bin Density Histogram.
    *   **Local:** Extract the 3 Stratified-Variance slices, resize to 224x224, and normalize.
    *   **Tabular:** Standard scale continuous features; One-Hot encode categorical features.

2.  **Feature Engineering:**
    *   Extract deep features for the 3 slices, concatenate, and apply **PCA** (fitted on training data).
    *   Fuse PCA features with the Global Histogram and Clinical features.
    *   **FVC Set:** Create interaction features ($X \times \text{Weeks}$) to support the linear prior for trend extrapolation **(Cite solution_lesson_node_00006)**.
    *   **Uncertainty Set:** Append the absolute time delta feature.

### Training

The training utilizes **Decoupled Residual Regression (Cite solution_lesson_node_00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the FVC feature set.
    *   **Objective:** Minimize Mean Absolute Error (L1).

2.  **Stage 2 (Residual Computation):**
    *   Generate median predictions for the training set.
    *   Compute absolute residuals: $r = |y_{true} - y_{pred}| + \epsilon$.

3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Gamma GLM** on the Uncertainty feature set with target $r$.
    *   **Objective:** Minimize Gamma Deviance (Negative Log Likelihood).

### Evaluation

1.  **Inference:**
    *   Process the test patient's CT to extract Local PCA features and Global Density Histograms.
    *   Predict the Median FVC using the Quantile Regressor.
    *   Predict the expected absolute error ($\Delta$) using the Gamma GLM.

2.  **Analytical Scaling:**
    *   Convert the predicted $\Delta$ into the final confidence ($\sigma$) using the formula: $\sigma = \Delta \times \sqrt{2}$. This analytically maps the predicted Mean Absolute Deviation to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.

3.  **Formatting:**
    *   Clip $\sigma$ at 70 ml and format the submission.
