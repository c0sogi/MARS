The implementation strategy is as follows:

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility. Define a temporary working directory (`./working/demo_run`) to store intermediate files and caches, ensuring the demonstration does not interfere with any existing full-scale runs.

2.  **Data Subsetting**: Load the pre-generated metadata files from `./metadata`. Create "mini" versions of the training, validation, and test sets by sampling a small number of unique patients (e.g., 5 for training, 3 for validation). This ensures the pipeline runs quickly (within minutes) while still exercising all code paths.

3.  **Configuration Override**: Monkey-patch the `Config` class to point to the new mini-metadata files and the temporary cache directory. Also, reduce `N_PCA_COMPONENTS` to accommodate the smaller dataset size.

4.  **Component Demonstration**:
    *   **DICOM Processing**: Manually invoke `process_patient` on a single patient to demonstrate image loading, Hounsfield Unit conversion, and resizing. Verify the output shape matches the expected dimensions (6 channels x 224 x 224).
    *   **Feature Extraction**: Instantiate `VisualFeatureExtractor` and pass the processed images to generating a deep feature vector using the EfficientNet-B0 backbone.

5.  **Pipeline Execution (DatasetBuilder)**: Instantiate `DatasetBuilder` and call `generate_datasets()`. This orchestrates the entire data preparation workflow: loading metadata, computing volumetrics, extracting CNN features, applying PCA, processing tabular data, and constructing the final feature matrices (`X_fvc`, `X_unc`) for all splits.

6.  **Model Training**:
    *   **FVC Prediction**: Train a `QuantileMedianRegressor` on the generated training matrix to predict the median FVC.
    *   **Uncertainty Prediction**: Calculate the residuals from the median predictions and train a `ResidualUncertaintyRegressor` to predict the confidence (sigma).

7.  **Evaluation and Submission**: Use the `laplace_log_likelihood` metric to evaluate the model on the validation set. Finally, generate predictions for the test set and format them into a valid submission DataFrame, saving it to disk.
