Based on the accumulated "Lessons Learned" and the analysis of previous experiments, I propose the **Orthogonal MIP-Texture Hybrid Quantile-Elastic Pipeline**.

This solution structurally evolves the previous "Slice-Based" approaches by integrating **Multi-View Computer Vision** to capture the 3D morphology of fibrosis, while strictly adhering to the statistically optimized "Deep Feature + Linear Solver" architecture that has proven most effective for this small-sample dataset.

### Model
The architecture consists of a **Dual-Stream Feature Extractor** feeding into a **Mathematically Specialized Linear System**.

1.  **Visual Backbone (EfficientNet-B0):**
    *   We utilize **EfficientNet-B0** (pre-trained on ImageNet) as the shared feature extractor.
2.  **Dual-Stream Spatial Sampling (Structural Innovation):**
    *   **Stream 1: Local Texture (Axial Slices):** We select the 3 axial slices with the highest pixel variance. This captures the "worst-case" local tissue heterogeneity (e.g., honeycombing) **(Cite solution_lesson_node_00008)**.
    *   **Stream 2: Global Structure (Orthogonal MIPs):** We generate **Maximum Intensity Projections (MIPs)** along three orthogonal axes: Axial (Z), Coronal (Y), and Sagittal (X).
        *   *Rationale:* Standard 2D slices lose 3D context. MIPs mathematically condense the 3D volume into 2D density maps, explicitly visualizing the total "fibrosis load" and anatomical distribution (e.g., Apical-Basal gradient) without the computational cost of 3D CNNs. This provides the model with a structural prior that complements the local texture features.
3.  **Dimensionality Reduction (PCA):**
    *   The features from all 6 images (3 Slices + 3 MIPs) are concatenated and compressed using **Principal Component Analysis (PCA)** to ~50 components. This is mandatory to prevent the curse of dimensionality when feeding deep features into linear solvers **(Cite solution_lesson_node_00014)**.
4.  **FVC Predictor (Linear Quantile Regressor):**
    *   A **Linear Quantile Regressor** targeting the **Median (q=0.5)**.
    *   **Inputs:** PCA features ($X$), Time ($t$), and **Interaction Terms** ($X \times t$).
    *   **Rationale:** Optimizing for the Median (L1) aligns perfectly with the Laplace Metric **(Cite solution_lesson_node_00016)**. The interactions allow the model to learn patient-specific decline rates (Varying-Coefficient) **(Cite solution_lesson_node_00008)**, preserving the linear prior required for trend extrapolation **(Cite solution_lesson_node_00006)**.
5.  **Uncertainty Predictor (Elastic Net):**
    *   An **Elastic Net Regressor** (L1+L2 Regularization).
    *   **Inputs:** PCA features ($X$) and **Time Horizon** ($|t - t_{baseline}|$).
    *   **Rationale:** We use Elastic Net to predict the magnitude of errors, as unregularized GLMs have proven unstable on this dataset **(Cite solution_lesson_node_00023)**. We include the Time Horizon to explicitly model **Temporal Heteroscedasticity** (uncertainty growing over time) **(Cite solution_lesson_node_00017)**, while excluding complex interactions to maintain **Parsimony** **(Cite solution_lesson_node_00011)**.

### Data
1.  **Preprocessing:**
    *   **Volume Loading:** Load DICOMs and stack into a 3D volume. Threshold (HU -1000 to -400) to mask lung tissue.
    *   **MIP Generation:** Compute `np.max` along axes 0, 1, and 2 of the masked volume to create Sagittal, Coronal, and Axial MIPs.
    *   **Slice Selection:** Calculate variance of all axial slices; select top 3.
    *   **Normalization:** Resize all 6 images to 224x224; Standard Scale tabular data.
2.  **Feature Engineering:**
    *   Extract EfficientNet features for the 6 images. Concatenate with explicit volumetrics (Total Volume, Mean Density) **(Cite solution_lesson_node_00013)** and Clinical Data.
    *   Fit **PCA** on the training set to reduce this dense vector.
    *   **FVC Set:** Generate interactions: $X_{PCA} \times \text{Weeks}$.
    *   **Uncertainty Set:** Append horizon feature: $|\text{Weeks} - \text{Baseline\_Weeks}|$.

### Training
The training utilizes **Decoupled Residual Regression (Cite solution_lesson_node_00001)**:
1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the FVC feature set.
    *   **Objective:** Minimize Mean Absolute Error (L1).
2.  **Stage 2 (Residual Computation):**
    *   Generate median predictions for the training set.
    *   Compute absolute residuals: $r = |y_{true} - y_{pred}|$.
3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Elastic Net** on the Uncertainty feature set with target $r$.
    *   **Objective:** Minimize Mean Squared Error (L2) + Regularization.

### Evaluation
1.  **Inference:**
    *   Generate Slices and MIPs for the test patient. Extract features.
    *   Predict Median FVC using the Quantile Regressor.
    *   Predict the expected Mean Absolute Deviation (MAD) using the Elastic Net.
2.  **Analytical Scaling:**
    *   Convert the predicted MAD into the final confidence ($\sigma$) using the formula: $\sigma = \text{MAD} \times \sqrt{2}$. This analytically maps the predicted error to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.
3.  **Formatting:**
    *   Clip $\sigma$ at 70 ml.
