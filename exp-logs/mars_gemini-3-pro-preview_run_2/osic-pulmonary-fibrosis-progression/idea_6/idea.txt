Based on the comprehensive analysis of previous attempts and the "Lessons Learned," I propose the **Dual-Moment GLM-Quantile Pipeline**.

This solution introduces two structural innovations: **Dual-Moment Feature Pooling** to capture intra-patient lung heterogeneity (addressing the loss of detail in simple averaging) and a **Gamma-Log-Link Generalized Linear Model (GLM)** for uncertainty estimation (addressing the statistical mismatch of using Gaussian-assumption models for positive, skewed error distributions). It strictly retains the successful "Deep Feature + Linear Solver" paradigm and the specific optimizations for the Laplace metric identified in the lessons.

### Model

The architecture consists of a frozen deep learning backbone feeding into a statistically specialized dual-branch regression system:

1.  **Visual Backbone (EfficientNet-B0):** We utilize **EfficientNet-B0** (pre-trained on ImageNet) to extract rich texture descriptors from CT slices.
2.  **Dual-Moment Feature Aggregation:**
    *   Instead of simple Global Average Pooling (which dilutes focal fibrosis patterns), we compute both the **Mean** and the **Standard Deviation** of the feature vectors across the selected slices for each patient.
    *   **Rationale:** Fibrosis is often patchy (heterogeneous). The standard deviation of features across slices explicitly encodes this variability, providing the linear model with a signal for "disease patchiness" that average pooling misses.
3.  **Dimensionality Reduction (PCA):** The concatenated Mean+Std vectors are compressed using **Principal Component Analysis (PCA)** to ~40 dimensions. This is mandatory to prevent the curse of dimensionality when feeding deep features into linear solvers **(Cite solution_lesson_node_00014)**.
4.  **FVC Predictor (Linear Quantile Regressor):**
    *   A **Linear Quantile Regressor** targeting the **50th percentile (Median)**.
    *   **Inputs:** PCA features ($X$), Time ($t$), and **Interaction Terms** ($X \times t$).
    *   **Rationale:** This preserves the **Linear Prior** for trend extrapolation **(Cite solution_lesson_node_00006)** and the **Varying-Coefficient** property for patient-specific decline rates **(Cite solution_lesson_node_00008)**, while aligning the objective (L1 minimization) with the Laplace metric **(Cite solution_lesson_node_00016)**.
5.  **Uncertainty Predictor (Gamma GLM):**
    *   A **Generalized Linear Model (GLM)** with a **Gamma distribution** and **Log Link function**.
    *   **Inputs:** PCA features ($X$) and **Time Horizon** ($|t|$).
    *   **Rationale:** The target variable for this model is the absolute residual ($|y - \hat{y}|$), which is strictly positive and typically right-skewed. Standard Elastic Net (Gaussian/MSE) is suboptimal here. A Gamma GLM with a Log Link naturally models this distribution and ensures positive predictions ($\sigma > 0$) without artificial clipping, while explicitly accounting for temporal heteroscedasticity **(Cite solution_lesson_node_00017)**.

### Data

1.  **Variance-Based Slice Selection:** For each patient, calculate the pixel variance of lung tissue in every slice and select the top 5 slices with the highest variance to focus on heterogeneous tissue.
2.  **Feature Extraction & Compression:**
    *   Pass the 5 slices through EfficientNet-B0.
    *   Compute the **Mean** and **Standard Deviation** of the embeddings across the 5 slices. Concatenate them.
    *   Fit **PCA** on the training set to reduce dimensions to ~40, then transform both train and test sets **(Cite solution_lesson_node_00014)**.
3.  **Feature Engineering:**
    *   Combine PCA features with normalized clinical data (Age, Sex, Smoking, Baseline FVC/Percent).
    *   **FVC Set:** Generate interaction terms by multiplying every static feature by `Weeks` **(Cite solution_lesson_node_00008)**.
    *   **Uncertainty Set:** Include the static features and the absolute time delta `abs(Weeks - Baseline_Weeks)` to model error growth over time **(Cite solution_lesson_node_00017)**.

### Training

The training follows a sequential **Decoupled Residual Regression** strategy **(Cite solution_lesson_node_00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the FVC feature set.
    *   **Objective:** Minimize Mean Absolute Error (L1).
2.  **Stage 2 (Residual Computation):**
    *   Generate predictions for the training set.
    *   Compute absolute residuals: $r = |y_{true} - y_{pred}|$. Add a small epsilon ($1e-6$) to ensure strict positivity.
3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Gamma GLM** on the Uncertainty feature set with target $r$.
    *   **Objective:** Minimize Gamma Deviance (Negative Log Likelihood).

### Evaluation

1.  **Inference:**
    *   Generate the median FVC prediction using the Quantile Regressor.
    *   Generate the expected absolute error ($\Delta$) using the Gamma GLM.
2.  **Analytical Scaling:**
    *   Convert the predicted $\Delta$ into the submission confidence ($\sigma$) using the formula: $\sigma = \Delta \times \sqrt{2}$. This analytically maps the predicted Mean Absolute Deviation to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.
3.  **Formatting:** Clip $\sigma$ at 70 ml and format the submission.
