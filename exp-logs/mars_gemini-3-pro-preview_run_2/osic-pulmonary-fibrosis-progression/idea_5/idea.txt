Based on the accumulated lessons and the specific failure modes of previous attempts, I propose the **PCA-Enhanced Quantile-Elastic Pipeline**.

This solution corrects the critical engineering flaw in "Idea 4" (missing dimensionality reduction) while retaining the theoretical superiority of L1-based optimization for the Laplace metric. It strictly adheres to the successful "Deep Feature + Linear Solver" paradigm established in the "Current Best" solution but upgrades the solver objectives to mathematically align with the scoring function.

### Model
The architecture consists of a hybrid feature extraction pipeline feeding into two distinct, mathematically specialized linear solvers.

1.  **Visual Backbone (EfficientNet-B0):** We utilize **EfficientNet-B0** (pre-trained on ImageNet) as the feature extractor. This provides richer texture descriptors (e.g., reticular patterns) compared to the ResNet18 used in the previous successful baseline.
2.  **Dimensionality Reduction (PCA):** Crucially, we apply **Principal Component Analysis (PCA)** to the extracted deep features, compressing them to a low-dimensional dense vector (e.g., 30 components). This directly addresses the "curse of dimensionality" that caused the failure in previous attempts **(Cite Lesson 00014)**.
3.  **FVC Predictor (Linear Quantile Regressor):**
    *   Instead of Elastic Net (which optimizes Mean Squared Error/Mean), we employ a **Linear Quantile Regressor** targeting the **50th percentile (Median)**.
    *   **Rationale:** The Laplace Log Likelihood metric is maximized when the location parameter is the Median of the distribution. By minimizing the L1 norm (Least Absolute Deviations), this model aligns perfectly with the metric.
    *   **Structure:** This model uses a **Varying-Coefficient** design. The input features are the PCA-reduced static descriptors ($X$), the time variable ($t$), and explicit **interaction terms** ($X \times t$). This preserves the robust **Linear Prior** required for trend extrapolation **(Cite Lesson 00006)** while allowing patient-specific rates of decline **(Cite Lesson 00008)**.
4.  **Uncertainty Predictor (Elastic Net):**
    *   This model predicts the **Mean Absolute Deviation (MAD)** of the FVC predictor's residuals.
    *   **Rationale:** For a Laplace distribution, the Maximum Likelihood Estimator for the scale parameter is the mean of the absolute errors. We use **Elastic Net** (L2 optimization) here because it effectively estimates the conditional mean.
    *   **Structure:** This model uses **only static features** (PCA components + clinical data), strictly excluding time-interaction terms. This adheres to the principle of **Parsimony in Uncertainty Modeling** to prevent overfitting to noisy residuals **(Cite Lesson 00011)**.

### Data
1.  **Variance-Based Slice Sampling:** For each patient, calculate the pixel variance of the lung tissue in every slice and select the top 5 slices with the highest variance. This ensures the model focuses on heterogeneous tissue (fibrosis) rather than uniform healthy lung.
2.  **Feature Extraction & Compression:**
    *   Pass the 5 selected slices through EfficientNet-B0.
    *   Apply Global Average Pooling and average the vectors across the 5 slices to create a single `Patient_Embedding`.
    *   **Fit PCA** on the training embeddings to reduce dimensions to ~30, then transform both train and test embeddings **(Cite Lesson 00014)**.
3.  **Feature Engineering:**
    *   Concatenate PCA features with normalized clinical data (Age, Sex, Smoking, Baseline FVC/Percent).
    *   **Interaction Generation:** For the FVC model *only*, create interaction features by multiplying every static feature by the `Weeks` variable **(Cite Lesson 00008)**.

### Training
The training is a sequential process utilizing **Decoupled Residual Regression (Cite Lesson 00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the augmented feature set ($X, t, X \times t$) to predict `FVC`.
    *   **Objective:** Minimize Mean Absolute Error (L1).
2.  **Stage 2 (Residual Computation):**
    *   Generate predictions for the training set using the trained Quantile Regressor.
    *   Compute the absolute residuals: $r = |y_{true} - y_{pred\_median}|$.
3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Elastic Net** on the static feature set ($X$) to predict $r$.
    *   **Objective:** Minimize Mean Squared Error (L2) to estimate the expected magnitude of the error.

### Evaluation
1.  **Inference:** For each test query, generate the median FVC prediction using the Quantile Regressor and the expected Mean Absolute Deviation (MAD) using the Elastic Net.
2.  **Analytical Scaling:** Convert the predicted MAD into the submission confidence ($\sigma$) using the formula: $\sigma = \text{MAD} \times \sqrt{2}$. This analytically maps the predicted error to the optimal scale parameter for the Laplace metric **(Cite Lesson 00009)**.
3.  **Formatting:** Clip $\sigma$ at 70 ml and format the submission.
