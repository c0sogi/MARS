The error `IndexError: boolean index did not match indexed array` is caused by a mismatch between the size of the cached processed data and the runtime metadata. The system is loading stale cached arrays (generated during a previous "Debug" run with a small sample size, e.g., 10) while the current configuration (`DEBUG=False`) loads the full validation metadata (285 samples). This leads to a dimension conflict when `runfile.py` attempts to correlate errors with features.

To fix this, I will modify `library/data_manager.py` to load the metadata *before* checking the cache. I will then implement a validation step that compares the length of the cached arrays (`y_train`, `y_val`) against the loaded metadata dataframes. If the sizes do not match, the cache will be treated as invalid/stale and the data will be recomputed. This applies the solution from **Cite debug_lesson_3** (Invalidate Stale Caches When Toggling Debug Modes).
