Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Multi-Axis Variance-Hybrid Quantile-Elastic Pipeline**.

This solution structurally evolves the "Current Best" approach by addressing its primary limitation: the restriction of feature extraction to the Axial plane. By introducing **Multi-Axis Variance Sampling**, we extend the successful "Content-Aware" selection strategy to the Coronal plane, capturing the 3D extent of fibrosis without falling into the trap of "Geometric Stratification" that caused previous failures. It strictly adheres to the statistically optimized "Deep Feature + Regularized Linear Solver" architecture validated in the lessons.

### Model

The architecture consists of a **Dual-View Content-Aware Feature Extractor** feeding into a **Mathematically Specialized Linear System**.

1.  **Multi-Axis Variance Sampling (Structural Innovation):**
    *   **Concept:** Instead of selecting slices based on fixed anatomical positions (which fails when disease is localized or lungs are displaced), we employ a pure **Content-Based Heuristic** across multiple axes **(Cite solution_lesson_node_00031)**.
    *   **Axial Stream:** We compute the pixel variance for every slice in the standard Z-axis and select the **Top 3** slices with the highest variance. This captures the most heterogeneous (fibrotic) tissue in the transverse plane.
    *   **Coronal Stream:** We reslice the 3D volume to the Coronal plane (Front-to-Back) and select the **Top 3** slices with the highest variance.
    *   **Rationale:** Fibrosis often manifests as a "honeycomb" gradient from the lung base to the apex. Axial slices slice *through* this gradient, while Coronal slices visualize the *extent* of the gradient. Selecting the highest variance slices in the Coronal plane ensures the model sees the "worst-case" vertical distribution of the disease, providing a structural prior that Axial slices alone miss.

2.  **Hybrid Feature Fusion:**
    *   **Deep Texture:** We utilize **EfficientNet-B0** (pre-trained on ImageNet) to extract texture descriptors from the 6 selected slices (3 Axial + 3 Coronal).
    *   **Global Volumetrics:** We compute a **Density Histogram** (4 bins: Emphysema, Healthy, Fibrosis, Consolidation) over the *entire* masked 3D volume. This provides the linear model with an explicit measure of "Total Functional Volume," enforcing the **Inductive Bias** that lung capacity is physically proportional to healthy tissue quantity **(Cite solution_lesson_node_00013)**.

3.  **Dimensionality Reduction (PCA):**
    *   The concatenated features (Deep Texture + Histogram + Clinical) are compressed using **Principal Component Analysis (PCA)** to ~40 dimensions. This is mandatory to prevent the curse of dimensionality when feeding deep features into linear solvers **(Cite solution_lesson_node_00014)**.

4.  **FVC Predictor (Linear Quantile Regressor):**
    *   A **Linear Quantile Regressor** targeting the **Median (q=0.5)**.
    *   **Inputs:** PCA features ($X$), Time ($t$), and **Interaction Terms** ($X \times t$).
    *   **Rationale:** Optimizing for the Median (L1) aligns perfectly with the Laplace Metric **(Cite solution_lesson_node_00016)**. The interactions allow the model to learn patient-specific decline rates (Varying-Coefficient) **(Cite solution_lesson_node_00008)**, preserving the linear prior required for trend extrapolation **(Cite solution_lesson_node_00006)**.

5.  **Uncertainty Predictor (Elastic Net):**
    *   An **Elastic Net Regressor** (L1+L2 Regularization).
    *   **Inputs:** PCA features ($X$) and **Time Horizon** ($|t - t_{baseline}|$).
    *   **Rationale:** We use Elastic Net to predict the magnitude of errors. We include the Time Horizon to explicitly model **Temporal Heteroscedasticity** (uncertainty growing over time) **(Cite solution_lesson_node_00017)**. Crucially, we use a regularized model instead of a GLM to prevent overfitting to noisy residuals **(Cite solution_lesson_node_00023)**, and exclude complex interactions to maintain **Parsimony** **(Cite solution_lesson_node_00011)**.

### Data

1.  **Preprocessing:**
    *   **Volume Construction:** Load DICOM files and stack them into a 3D numpy array.
    *   **Masking:** Apply a threshold (HU -1000 to -400) to isolate lung tissue.
    *   **Sampling:**
        *   Calculate variance for all axial slices; pick Top 3.
        *   Rotate volume 90 degrees (Coronal); calculate variance for all slices; pick Top 3.
    *   **Normalization:** Resize all 6 images to 224x224 (convert to 3-channel RGB); Standard Scale tabular data.

2.  **Feature Engineering:**
    *   Extract EfficientNet-B0 features for the 6 images. Concatenate.
    *   Compute 4-bin Density Histogram on the full masked volume.
    *   Combine Texture, Histogram, and Clinical Data.
    *   Fit **PCA** on the training set to reduce this dense vector.
    *   **FVC Set:** Generate interactions: $X_{PCA} \times \text{Weeks}$.
    *   **Uncertainty Set:** Append horizon feature: $|\text{Weeks} - \text{Baseline\_Weeks}|$.

### Training

The training utilizes **Decoupled Residual Regression (Cite solution_lesson_node_00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the FVC feature set.
    *   **Objective:** Minimize Mean Absolute Error (L1).

2.  **Stage 2 (Residual Computation):**
    *   Generate median predictions for the training set.
    *   Compute absolute residuals: $r = |y_{true} - y_{pred}|$.

3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Elastic Net** on the Uncertainty feature set with target $r$.
    *   **Objective:** Minimize Mean Squared Error (L2) + Regularization.

### Evaluation

1.  **Inference:**
    *   Generate Multi-Axis slices (Axial/Coronal) for the test patient. Extract features.
    *   Predict Median FVC using the Quantile Regressor.
    *   Predict the expected Mean Absolute Deviation (MAD) using the Elastic Net.

2.  **Analytical Scaling:**
    *   Convert the predicted MAD into the final confidence ($\sigma$) using the formula: $\sigma = \text{MAD} \times \sqrt{2}$. This analytically maps the predicted error to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.

3.  **Formatting:**
    *   Clip $\sigma$ at 70 ml.
