Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy
1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility. We will override the default epoch count in `Config` to 50 to ensure the training completes quickly while still allowing convergence.
2.  **Data Loading**: Use the `get_data` function from `library.data` to load the dataset. This function handles caching automatically. We will wrap the returned datasets in PyTorch `DataLoader`s for batch processing.
3.  **Training**: Instantiate the `Engine` class from `library.engine` and execute the `run_training` method. This handles the two-stage training process (FVC trajectory prediction followed by uncertainty estimation) and returns the trained model.
4.  **Validation**: Explicitly calculate the final validation metric using `evaluate_model` with the `laplace` metric option. This ensures we get the exact score required for the threshold check.
5.  **Failure Analysis**: Run inference on the validation set to calculate absolute errors. Construct a DataFrame containing the errors and input features (Weeks, Age, Baseline FVC, Baseline Percent) and compute Pearson correlations to identify error drivers.
6.  **Submission**: Compare the final validation metric against the threshold (-7.004...). If the model performs well enough, generate the submission file using `engine.generate_submission`.
