To fix this, I will normalize the target variable using `StandardScaler` within the `FVCRegressor` class. This ensures the target values are on a scale (mean 0, std 1) where `alpha=0.1` provides effective regularization, preventing numerical instability and physically impossible predictions (Cite debug_lesson_10).
