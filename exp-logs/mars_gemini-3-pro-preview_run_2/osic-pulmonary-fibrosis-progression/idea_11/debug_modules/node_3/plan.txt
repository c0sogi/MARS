The error arises because the `FVCRegressor` is training an unregularized linear model (`QuantileRegressor` with `alpha=0.0`) on an underdetermined system. In the debug configuration, there are only 15 training samples ($N=15$) but approximately 31 features ($P \approx 31$) due to the interaction terms generated between PCA components and the `Weeks` variable. Without regularization, the solver finds a solution that perfectly fits the training points by assigning astronomically large coefficients to the features, leading to numerical explosion and invalid negative predictions (e.g., -1.3e15).

To fix this, I will modify `library/modeling.py` to apply L1 regularization by setting `alpha` to a non-zero value (0.1) in the `QuantileRegressor` constructor. This regularization will constrain the coefficients, preventing them from exploding in rank-deficient scenarios (Cite debug_lesson_7: Adapt Static Hyperparameters to Runtime Data Dimensions).
