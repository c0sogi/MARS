The following script implements the `runfile.py` to orchestrate the solution. It leverages the provided library modules to execute the "Spatially-Aware Hybrid-Feature Quantile-GLM Pipeline".

**Implementation Strategy:**
1.  **Setup & Initialization**: Sets random seeds for reproducibility and initializes the environment.
2.  **Pipeline Execution**: Calls `train_pipeline` with caching enabled. This handles feature extraction (EfficientNet on GPU), preprocessing (PCA + interaction terms), and model training (Quantile Regression & Gamma GLM).
3.  **Validation & Metric**: Performs inference on the validation set, calculates the specific Laplace Log Likelihood metric, and prints it in the required format.
4.  **Failure Analysis**: Loads validation metadata to calculate Pearson correlations between the model's absolute errors and clinical features (Age, Weeks, Percent) to identify error sources.
5.  **Conditional Submission**: Checks the validation metric against the threshold (-6.805...). If the model performs sufficiently well, it runs the `inference_pipeline` to generate `submission.csv`; otherwise, it skips this step.
