This script demonstrates the end-to-end usage of the provided machine learning library for breast cancer detection. It systematically validates the core components:
1.  **Metrics**: Verifies the Probabilistic F1 score calculation.
2.  **Data Loading**: Checks the data pipeline, ensuring images and tabular features are correctly loaded and batched using the `debug` mode for speed.
3.  **Model Architecture**: Instantiates the `HybridEfficientNet` and verifies the forward pass dimensions.
4.  **Training**: Runs a single epoch of training using `run_training` to demonstrate the optimization loop and model saving.
5.  **Inference**: Executes the inference pipeline with `predict_and_submit` to generate a valid submission file.
