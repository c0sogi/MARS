Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and detecting the available computing device (A100 GPU).
2.  **Data Pipeline**: load the pre-processed training, validation, and test dataloaders using the provided `data` library. We utilize the full dataset (approx. 40k images) as the EfficientNetV2-Small backbone is computationally efficient enough to train within the time limit on the provided hardware.
3.  **Model Training**: Invoke the `trainer` module to train the Modality-Regularized Hybrid Network (MR-HN). We train for up to 5 epochs with early stopping to ensure a fast but effective baseline.
4.  **Validation & Metric Calculation**: After training, load the best model checkpoint and perform inference on the full validation set. Compute the Probabilistic F1 (pF1) score and print it in the required format.
5.  **Failure Analysis**: Calculate the absolute prediction error for each validation sample. Compute and print the correlation between this error and key input features (e.g., Age, Machine ID) to identify potential biases or systematic failures.
6.  **Submission Generation**: Compare the validation pF1 against the required threshold (0.0448...). If the model performs sufficiently well, generate the final `submission.csv` by predicting on the test set and aggregating scores by `prediction_id`.
