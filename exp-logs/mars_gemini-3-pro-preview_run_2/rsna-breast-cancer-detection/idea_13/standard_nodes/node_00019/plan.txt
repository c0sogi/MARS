Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and ensure reproducibility with `set_seed()`.
2.  **Data Loading & Subsampling**: Load the training and validation datasets using `BreastCancerDataset`. To satisfy the "fast baseline" requirement, subsample the training data to 5,000 random samples and reduce training epochs to 3. This ensures the pipeline completes within the time limit while still learning from the Tri-Spectral inputs.
3.  **Model Initialization**: Instantiate the `TriSpectralHybridModel` and move it to the GPU.
4.  **Training**: Configure `AdamW` optimizer and `OneCycleLR` scheduler. Execute the training loop using the `fit` function from `library.engine`, which handles mixed-precision training and FP32-guarded loss calculation.
5.  **Validation**: Load the best model checkpoint. Compute the Probabilistic F1 score on the full validation set and print it in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Iterate through the validation set to calculate absolute prediction errors. Compute and print correlations between these errors and metadata features (Age, Implant, Machine ID) to identify systematic weaknesses.
7.  **Submission**: If the validation score exceeds the threshold (0.0448...), perform inference on the test set. Aggregate predictions by `prediction_id` using the maximum probability and save the result to `submission.csv`.
