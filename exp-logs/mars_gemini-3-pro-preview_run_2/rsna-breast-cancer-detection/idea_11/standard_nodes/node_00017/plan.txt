Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy
1.  **Configuration & Setup**: Import necessary modules and the provided library components. Set random seeds for reproducibility. Modify the `Config` to run a "fast baseline" by reducing the number of epochs to 2, ensuring the process completes well within the 2-hour limit on the provided A100 GPU.
2.  **Training Loop**: Manually implement the training loop using `MCSINModel`, `train_one_epoch`, and `evaluate` from `library.model`. This allows capturing the best model state based on the validation pF1 score.
3.  **Validation & Metric**: After training, load the best saved model state. Run evaluation on the full validation set to compute the `pF1` score. Print this score in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**: Extract predictions and targets from the validation step. Load the validation metadata (`val.csv`), merge it with predictions, and calculate the absolute error. Compute and print correlations between the model's error and key features (Age, Density, Machine ID) to identify systematic weaknesses.
5.  **Submission**: Check if the final validation metric exceeds the threshold (0.04488...). If successful, run inference on the test set using `predict_and_submit` and save the `submission.csv`.
