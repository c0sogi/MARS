Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the environment using the provided `Config` class. We will override specific parameters (Epochs, Batch Size) to ensure the script runs quickly as a baseline within the time limit.
2.  **Data Loading**: Use the `get_dataloaders` function to load the Multi-Instance Learning (MIL) bags. This handles the grouping of images by patient/breast.
3.  **Model Initialization**: Instantiate the `BreastCancerMILModel` and move it to the GPU.
4.  **Training Loop**: Implement a standard training loop using `BCEWithLogitsLoss` with a positive weight to handle class imbalance. We will limit the number of epochs to 3 for speed.
5.  **Validation & Metric**: Evaluate the model on the hold-out validation set after each epoch. We will save the best model based on the Probabilistic F1 (pF1) score.
6.  **Failure Analysis**: After training, we will perform inference on the validation set again to collect detailed predictions. We will merge these predictions with the metadata to calculate correlations between the model's error (absolute difference between prediction and target) and clinical features like Age and Implant status.
7.  **Submission**: If the best validation pF1 exceeds the specified threshold, we will run inference on the test set, aggregate predictions by `prediction_id`, and generate the `submission.csv` file.
