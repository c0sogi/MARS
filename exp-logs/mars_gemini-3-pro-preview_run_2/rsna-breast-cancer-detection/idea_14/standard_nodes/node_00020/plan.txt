The implementation strategy follows the "Deeply-Supervised GPU-Enhanced Hybrid Network (DS-GEHN)" design while adhering to the constraints of a fast baseline execution.

1.  **Configuration Override**: To ensure the code completes within the time limit while still utilizing the full dataset (a key strategic requirement), we override `Config.EPOCHS` to 1. This processes all ~40k training images once, which fits comfortably within the 2-hour limit on an A100 GPU (estimated ~15-20 minutes).
2.  **Training Loop**: We implement a custom training loop in `runfile.py` that imports the model and data utilities. This allows us to maintain control over the execution flow and ensures the best model state is captured in memory for immediate validation.
3.  **Validation & Metric**: We perform a full validation pass using the `validate` function from `library.train`. We compute the Probabilistic F1 (pF1) score and print it in the exact required format.
4.  **Failure Analysis**: We extract the validation DataFrame and compute the absolute error (`|y_true - y_pred|`) for each sample. We then calculate the Spearman correlation between this error and key metadata features (Age, Density, Machine ID, etc.) to identify sources of systematic bias.
5.  **Conditional Submission**: We check if the validation pF1 exceeds the threshold (`0.04488...`). If successful, we generate predictions for the test set. We aggregate predictions by `prediction_id` using the maximum probability (as per the strategy for multiple views) and save the result to `submission.csv`.
