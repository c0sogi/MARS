This script demonstrates the end-to-end workflow for the breast cancer detection task using the provided library files. It performs the following steps:

1.  **Configuration**: Overrides default `Config` settings to define a temporary working directory and reduce hyperparameters (epochs, batch size) for rapid execution.
2.  **Data Loading**: Uses `get_dataloaders` to process metadata and create PyTorch DataLoaders. It then subsets these loaders to a very small number of samples (12) to ensure the demonstration completes quickly.
3.  **Model Instantiation**: Initializes the `DSGEHNModel` (Deep Supervision + GPU-Enhanced Input + Hybrid Network) without pretrained weights to avoid download overhead.
4.  **Training Loop**: Runs a single epoch of training using `train_one_epoch` and evaluates using `validate`, asserting that loss and metrics are calculated correctly.
5.  **Metric Verification**: Manually verifies the `probabilistic_f1` function with a known test case to ensure logic correctness.
6.  **Inference**: Generates predictions on the test subset, aggregates them by `prediction_id` (as required by the competition format), and saves a valid submission file.
