# Idea 6: Multi-Task EfficientNetV2 with Balanced Sampling (MT-ENetV2-BS)

Based on the success of the fine-tuned single-instance approach (Idea 3) and the specific failure modes observed in the multi-task (Idea 5) and multi-instance (Idea 4) experiments, I propose a robust **Multi-Task Single-Instance Network**. This strategy leverages the rich auxiliary labels (BIRADS, Density) to improve feature learning while implementing a stabilized training recipe that enables Mixed Precision (AMP) without the numerical instability observed previously.

### Model
**Architecture: Fine-Tuned EfficientNetV2-Small with Auxiliary Heads**
1.  **Visual Backbone:** The model employs an **EfficientNetV2-Small** backbone initialized with ImageNet weights. Crucially, this backbone is **completely unfrozen** and fine-tuned end-to-end. This allows the network to adapt to the specific texture statistics of mammograms (e.g., microcalcifications), addressing the root cause of failure in frozen embedding approaches Cite {solution_lesson_node_00002}. EfficientNetV2 is chosen for its superior training speed and parameter efficiency compared to the V1 and B-series models used in previous ideas.
2.  **Pooling & Fusion:** The spatial feature maps are aggregated using **Generalized Mean Pooling (GeM)**, which is learnable and focuses on high-activation regions (lesions) more effectively than standard average pooling. This visual embedding is concatenated with a normalized tabular vector (Age, Implant, View, Machine ID) processed by a lightweight MLP.
3.  **Multi-Task Output:** The network branches into three heads to utilize all available training signals:
    *   **Primary Head:** Binary classification for `cancer`.
    *   **Auxiliary Head 1:** Regression/Ordinal classification for `BIRADS` scores.
    *   **Auxiliary Head 2:** Multi-class classification for `density` ratings.
    *   *Note:* These auxiliary heads act as regularizers during training, preventing the model from collapsing to a trivial "all-negative" solution given the extreme imbalance.

### Data
1.  **Single-Instance Learning (SIL):** The pipeline strictly follows the Single-Instance Learning paradigm. Patient-level labels (Cancer, BIRADS, Density) are broadcast to every image (view) associated with that patient. This dense supervision strategy is retained as it was proven to outperform the sparse supervision of Multi-Instance Learning (MIL) in this specific domain Cite {solution_lesson_node_00005}.
2.  **Byte-Level Ingestion:** The robust **Byte-Level Image Extractor** (scanning binary streams for JPEG/JPEG2000 headers and decoding via `cv2.imdecode`) is retained to handle the DICOM files without the missing `pydicom` library.
3.  **High-Resolution Input:** Images are resized to **768x768** or **1024x1024**. The use of a more efficient V2 backbone and Mixed Precision training (enabled by the training strategy below) frees up memory to support these higher resolutions, which are critical for detecting small masses.

### Training
1.  **Balanced Sampling Strategy:** To address the `NaN` divergence observed in Idea 5, the training will utilize a **WeightedRandomSampler** (or a custom balanced batch sampler) that ensures every batch contains a fixed ratio of positive cases (e.g., 10-20%).
2.  **Loss Function & Stability:** By physically balancing the batches, we eliminate the need for the large `pos_weight` (e.g., >15.0) in the loss function. The model will use **BCEWithLogitsLoss** with a neutral or low weight (e.g., 1.0 - 2.0). This prevents the gradient explosion that caused the Mixed Precision (AMP) failure in previous attempts Cite {solution_lesson_node_00008}.
3.  **Optimization:** The model will be trained using **AdamW** with **Mixed Precision (AMP)** enabled. The auxiliary losses (BIRADS, Density) will be added to the primary cancer loss with small scalar weights (e.g., 0.1) to guide feature extraction without dominating the gradient descent.

### Evaluation
1.  **Inference:** The model iterates through the test set. Since auxiliary labels are unavailable, only the output from the **Primary Cancer Head** is computed.
2.  **Aggregation:** Predictions are grouped by `prediction_id`. The final submission score is derived by taking the **maximum** probability across all images associated with that ID. This aligns with the empirical finding that robust single-instance predictions aggregated via max-pooling outperform complex learned aggregation mechanisms Cite {solution_lesson_node_00005}.
