This script demonstrates the end-to-end usage of the provided NFL Contact Detection library. It performs the following steps:

1.  **Environment Setup**: Sets random seeds and configures the environment for reproducibility.
2.  **Data Subsetting**: Creates small subsets of the metadata and sample submission files in the `./working` directory. This ensures the demonstration runs quickly (optimizing for speed) while exercising the full data loading and processing pipeline.
3.  **Configuration Overrides**: Dynamically updates the `library.config` paths to point to these subset files, allowing the library functions to operate on the reduced dataset without code modification.
4.  **Data Loading & Feature Engineering**: Uses `library.data_utils` to load tracking data, merge it with the subset metadata, engineer interaction features (e.g., distance, closing speed), and create time-lagged "wide" features.
5.  **Scaling**: Demonstrates fitting a scaler on training data and transforming validation/test sets.
6.  **Dataset & DataLoader**: Instantiates the `ContactDataset` class and wraps it in PyTorch DataLoaders. It verifies the shape and structure of the data yielded by the dataset.
7.  **Model Initialization**: Instantiates the `WITRGN` (Wide-Input Time-Resolved Gated Network) model and performs a dummy forward pass to verify input/output dimensions.
8.  **Training**: Runs a short training loop using `library.train_utils.train_model`, demonstrating epoch execution, validation, and model checkpointing.
9.  **Threshold Optimization**: Calculates the optimal decision threshold based on validation performance.
10. **Inference & Submission**: Generates predictions on the test subset and saves a submission file, verifying the output format.
