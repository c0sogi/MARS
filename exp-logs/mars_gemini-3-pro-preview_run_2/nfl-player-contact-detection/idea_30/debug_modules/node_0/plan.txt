This script demonstrates the end-to-end pipeline for the NFL Contact Detection task using the provided library files.

To ensure rapid execution and verification:
1.  **Data Subsetting**: It creates a temporary "demo" dataset by sampling just 2 plays from the original metadata and filtering the large tracking/helmet CSVs accordingly. This drastically reduces data loading and processing time.
2.  **Configuration Override**: It modifies the global `Config` class to point to these temporary files and reduces training epochs to 1.
3.  **Pipeline Execution**: It runs the `NFLDataLoader` to generate features, wraps them in the `ContactDataset`, initializes the `TDSRVNet` model, and executes a training loop using the `Trainer`.
4.  **Verification**: It includes assertions at key steps (feature shapes, model output dimensions, file generation) to validate the logic.
