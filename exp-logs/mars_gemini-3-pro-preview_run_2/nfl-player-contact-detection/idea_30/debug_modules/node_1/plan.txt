The `ValueError` occurs because `library/data_loader.py` expects player-specific versions (e.g., `rel_dist_p1_-5`) of every feature listed in `Config.KINEMATIC_FEATURES`. However, `rel_dist`, `closing_speed`, `rel_speed`, and `rel_accel` are pairwise interaction metrics generated by `library/feature_engineering.py` as single columns per timestep (e.g., `rel_dist_-5`), not duplicated for each player. The `DataLoader` already explicitly handles these derived features in a separate list (`self.derived_features`). I will remove these pairwise metrics from `Config.KINEMATIC_FEATURES` to resolve the conflicting expectation and align the configuration with the actual column names generated by the pipeline (Cite debug_lesson_15).
