Based on the accumulated lessons, specifically the success of the **Residual-Visual Fusion** strategy (Cite solution_lesson_node_00071) and the identified implementation failures of the **Gated Network** attempts (Cite solution_lesson_node_00076, solution_lesson_node_00077), I propose the **Gated Residual-Visual Corrected Network (GRVC-Net)**.

This solution synthesizes the high-capacity **Gated Backbone** (designed to filter temporal noise in wide windows) with the **Residual Visual Correction** architecture (proven to effectively integrate noisy visual data). Crucially, it explicitly corrects the angular discontinuity and loss hyperparameter errors that caused previous Gated Network attempts to underperform the simpler baselines.

# Model
The architecture is a **Dual-Stream Network** that fuses a sophisticated Kinematic stream with a lightweight Visual stream via residual correction.

1.  **Kinematic Stream (Gated Backbone):**
    *   **Input:** A **flattened wide feature vector** of player tracking data (Window $t-5$ to $t+5$). This preserves the strict temporal alignment proven superior to sequence models (Cite solution_lesson_node_00015).
    *   **Architecture:** A stack of **Gated Residual Blocks**. Each block employs a **Gated Linear Unit (GLU)** mechanism (e.g., $Output = (W_1 x) \odot \sigma(W_2 x) + x$).
    *   **Rationale:** Unlike standard ResNets, the gating mechanism allows the model to dynamically suppress irrelevant features from the edges of the temporal window ($t \pm 5$) while amplifying the signal from the center frame ($t=0$). This recovers the "Center Focus" benefits sought in previous ideas without the rigidity of manual skip connections (Cite solution_lesson_node_00059).
    *   **Output:** A single scalar logit representing the "Kinematic Probability".

2.  **Visual Stream (Shallow Correction):**
    *   **Input:** A **flattened wide feature vector** of helmet bounding box metrics, derived using a **Max-Pooling Selection Strategy** (Cite solution_lesson_node_00074).
    *   **Architecture:** A **Shallow MLP**. This prevents overfitting to the noisy visual proxy while capturing simple geometric rules (e.g., "Zero IoU $\to$ Reduce Probability").
    *   **Output:** A single scalar logit representing the "Visual Correction".

3.  **Residual Fusion:**
    *   **Operation:** $Logit_{final} = Logit_{kinematic} + \lambda \cdot Logit_{visual}$.
    *   **Logits-Only:** The final layer is a linear unit **without activation**, strictly adhering to the requirement for numerically stable loss functions (Cite solution_lesson_node_00048).

# Data
The data pipeline synthesizes the "Entity-First" tracking approach with strict corrections for angular continuity and ground physics.

1.  **Entity-First Feature Generation:** Generate lags and windowed features on the `player_tracking` dataframe **before** merging it with `train_labels`. This prevents O(N²) scaling errors (Cite solution_lesson_node_00045).
2.  **Angular Continuity (Correction):** When calculating relative orientation and direction, explicitly use the **Shortest Arc** method (e.g., `min(|a-b|, 360-|a-b|)`) instead of modulo arithmetic. This corrects the feature discontinuity that degraded previous Gated Network attempts (Cite solution_lesson_node_00076).
3.  **Hybrid Ground Imputation:**
    *   **Kinematics:** Impute Ground Position = Player Position (Distance=0) and Ground Velocity = 0. This preserves the "Relative Motion" signal required to detect impact (Cite solution_lesson_node_00034).
    *   **Visuals:** For Ground interactions, set `Visual_IoU` to 0 but retain the **Player's Helmet Box Top** features to capture the "falling" visual signature (Cite solution_lesson_node_00071).
4.  **Visual Feature Selection (Max-Pooling):** Apply a **Max-Pooling Strategy** per timestamp to select the single "best" view (largest box area) for each player. This creates a dense, consistent visual feature vector, allowing training on the full dataset without sparsity issues (Cite solution_lesson_node_00074).
5.  **Explicit Relative Physics:** Calculate `np.log1p(distance)` (Cite solution_lesson_node_00005) and `clamped_closing_speed` (Cite solution_lesson_node_00007).
6.  **Normalization:** Apply **StandardScaler** to the final fused vector (Cite solution_lesson_node_00037).

# Training
The training strategy is optimized for stability and calibration on the full dataset, correcting previous Focal Loss tuning errors.

1.  **Loss Function:** Use **Focal Loss** implemented via `BCEWithLogitsLoss`. Crucially, set `alpha=0.25` and `gamma=2.0`. This corrects the error of aggressively increasing `alpha` (to 0.75) which previously destabilized training; `alpha` must be low to balance the high `gamma` suppression of negatives (Cite solution_lesson_node_00077).
2.  **Full Dataset:** Train on the **entire training set** (3.4M rows). The efficient tabular architecture allows this within the compute budget, avoiding the performance degradation associated with subsampling (Cite solution_lesson_node_00023, solution_lesson_node_00075).
3.  **Optimizer:** Use **AdamW** with **Early Stopping** monitoring the Validation MCC.

# Evaluation
The evaluation pipeline includes a mandatory calibration step.

1.  **Threshold Optimization:** Post-training, perform a grid search on the **validation set** to find the decision threshold $T$ that maximizes the Matthews Correlation Coefficient (MCC). This aligns the decision boundary with the probability distribution (Cite solution_lesson_node_00002).
2.  **Inference:** Apply the optimized threshold $T$ to the test set predictions to generate the final binary submission.
