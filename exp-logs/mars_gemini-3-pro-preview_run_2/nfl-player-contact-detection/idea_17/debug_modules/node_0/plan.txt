The following implementation demonstrates the end-to-end usage of the provided library components for the NFL Contact Detection task.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes at runtime to enable a "fast mode." This involves setting `USE_ALL_DATA = False` to use a small data subset, reducing `EPOCHS` to 2, and shrinking model dimensions. This ensures the script executes quickly while exercising the full pipeline.
2.  **Feature Engineering**: We instantiate `FeatureEngine` and call `generate_features` with `load_cached_data=False`. This forces the execution of the data loading, alignment, and feature creation logic (including windowing and interaction features) to verify correctness.
3.  **Data Preparation**: We manually extract feature columns, convert them to NumPy arrays, and apply `StandardScaler`. This mirrors the logic inside `trainer.py` but exposes the intermediate steps for verification.
4.  **Model Lifecycle**:
    *   **Initialization**: We instantiate the `MMWIN` model and verify its architecture by passing a dummy tensor.
    *   **Training**: We run `train_model` using the generated `DataLoader`s.
    *   **Optimization**: We utilize `optimize_threshold` to find the best decision boundary on the validation set.
    *   **Inference**: We use `predict` to generate labels for the test set.
5.  **Verification**: Throughout the script, `assert` statements define expected behaviors (e.g., non-empty DataFrames, correct tensor shapes, valid MCC ranges) to ensure the logic is sound.
