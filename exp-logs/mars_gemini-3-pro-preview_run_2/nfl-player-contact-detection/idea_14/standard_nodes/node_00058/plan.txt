Implementation strategy:
1.  **Configuration & Setup**: Initialize the `Config` object with `debug=False` to use the full dataset, but limit `epochs=6` to ensure the "fast baseline" requirement is met within the 2-hour limit (estimated runtime < 30 mins on A100). Initialize `DataProcessor`.
2.  **Training**: Execute `train_model` from `library.train_eval`. This handles the data loading, model initialization, training loop, and threshold optimization, returning the trained model and the optimal decision threshold.
3.  **Validation & Metric**: Reload the validation set and run a dedicated inference pass using `validate`. Compute the Matthews Correlation Coefficient (MCC) on the full validation set and print it in the strictly required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**: Extract the continuous feature matrix from the validation dataset. Calculate the absolute error vector (`|y_true - y_prob|`). Compute the Pearson correlation between the error vector and each input feature. Print the top 10 features most correlated with model error to identify systematic weaknesses.
5.  **Submission**: Compare the final MCC against the required threshold (`0.62458462731896`). If the model passes, load the test set using `get_test_loader`, perform inference (using the optimized threshold), and save the results to `./submission/submission.csv`.
