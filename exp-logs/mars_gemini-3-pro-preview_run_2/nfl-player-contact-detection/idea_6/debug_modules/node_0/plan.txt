The following script demonstrates the end-to-end usage of the provided library files for the NFL Contact Detection task.

The strategy is as follows:
1.  **Configuration Override**: We modify the global `Config` class to use a temporary directory (`./working/demo_execution`) and reduce hyperparameters (1 epoch, small batch size) to ensure the demo runs quickly within the time limit.
2.  **Data Preparation**: We verify the `prepare_data` function by running it in debug mode (using a data subset) and asserting that the resulting feature caches are created and the tensor shapes are correct.
3.  **Model & Loss Verification**: We manually instantiate the `CKResNet` model and `FocalLoss`, pass a single batch of data through them, and verify that the output shapes and loss values are valid.
4.  **Training Pipeline**: We execute `run_training` to simulate a full training cycle, verifying that the model trains without error and saves a checkpoint.
5.  **Inference Pipeline**: We execute `predict` to generate predictions on the test set, ensuring a valid submission file is produced.
