The issue is that the script attempts to run a "Dummy Forward Pass" with a single sample (batch size of 1) to verify the model output shape, but the model is in its default `train` mode. This causes the `BatchNorm1d` layers to fail because they cannot compute a variance from a single value, raising a `ValueError`. To fix this, I will switch the model to evaluation mode using `model.eval()` before the dummy pass, ensuring the BatchNorm layers use their running statistics instead of batch statistics.
