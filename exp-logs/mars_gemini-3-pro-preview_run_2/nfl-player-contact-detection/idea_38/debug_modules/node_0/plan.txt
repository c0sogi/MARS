This script demonstrates the end-to-end usage of the provided machine learning library for the NFL Contact Detection task. It covers data loading, model instantiation, training, and inference.

**Implementation Strategy:**
1.  **Setup**: Initializes the environment, sets random seeds, and cleans the working directory to ensure a fresh execution state.
2.  **Training Workflow**:
    *   Initializes the `DataManager` in "train" mode with a small `debug_size` to ensure the demonstration runs quickly.
    *   Retrieves training and validation dataloaders.
    *   Instantiates the `PIRVNoiseModel` (Pyramidal Invariant Residual-Visual Network).
    *   Verifies the model's forward pass with a dummy batch.
    *   Initializes the `Trainer` and executes a single training epoch to generate model artifacts (`best_model.pth`, `best_threshold.npy`).
3.  **Cache Management**: Explicitly removes cached parquet files generated during the training phase. This is necessary because the provided `DataManager` uses fixed cache filenames, and we must force it to re-process the raw CSVs when switching to "test" mode.
4.  **Inference Workflow**:
    *   Initializes the `DataManager` in "test" mode to process the full test dataset.
    *   Uses the trained `Trainer` to generate predictions on the test set.
    *   Constructs the final submission DataFrame matching the required schema.
5.  **Validation**: Includes assertions throughout to verify data shapes, file existence, and logical consistency.
