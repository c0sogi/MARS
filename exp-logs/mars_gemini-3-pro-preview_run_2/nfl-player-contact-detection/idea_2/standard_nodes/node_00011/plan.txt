Implementation Strategy:
1.  **Initialization**: Set random seeds for reproducibility using `utils.seed_everything`. Initialize the `FeatureEngineer` and `Trainer` classes.
2.  **Data Loading & Subsampling**: Load the training and validation feature sets using the `FeatureEngineer`. To adhere to the "fast baseline" requirement and ensure execution within the time limit, subsample the training data to a maximum of 1,000,000 random samples if the dataset exceeds this size.
3.  **Model Training**: Execute the training process using `Trainer.fit()`. This method manages the training loop, weighted binary cross-entropy loss calculation, and early stopping based on validation MCC.
4.  **Validation & Threshold Optimization**: After training, use the best saved model state to generate probability predictions for the full validation set. Use `utils.optimize_threshold` to determine the decision threshold that maximizes the Matthews Correlation Coefficient (MCC). Print the required `Final Validation Metric`.
5.  **Failure Analysis**: Compute the absolute prediction error on the validation set. Calculate the Pearson correlation between this error and the input features (taken from the middle time-step of the input sequences) to identify features associated with high error rates.
6.  **Submission Generation**: Compare the final validation MCC against the required threshold (0.62458462731896). If the model's performance exceeds this target, load the test dataset, generate predictions using the optimized threshold, and save the results to `./submission/submission.csv`.
