Based on the accumulated lessons, the following strategy proposes a structural evolution from the simple Kinematic MLP to a **Dual-Stream Temporal Convolutional Network (DS-TCN)**. This approach addresses the limitations of flattening temporal data and the distinct physical nature of ground vs. player contacts.

# Proposed Solution: Dual-Stream Temporal Convolutional Network (DS-TCN)

### Model
The architecture upgrades the backbone from a flat MLP to a sequence-aware model that explicitly handles the "Ground" contact failure mode identified in previous iterations.

1.  **Temporal Backbone (1D-CNN):** Instead of flattening the time window into a single vector, the model will accept a tensor of shape $(Batch, Window\_Size, Features)$. A stack of **1D Convolutional Layers** (with residual connections and ReLU activations) will process this sequence. This allows the model to learn temporal filters that detect "impact signatures"—such as sudden spikes in deceleration or rapid changes in closing speed—which are lost or muddied in a flattened MLP representation.
2.  **Dual-Head Architecture:** To address the high error correlation with ground contacts (Cite Lesson 2, 8), the network will split into two distinct decision heads after the temporal encoder:
    *   **Player-Player Head:** Trained to detect collisions between two moving bodies (momentum transfer).
    *   **Player-Ground Head:** Trained to detect impacts with the ground (sudden stops, vertical drops).
3.  **Gated Output:** The final prediction will be a gated combination: $P_{final} = P_{ground} \times I_{ground} + P_{player} \times (1 - I_{ground})$, where $I_{ground}$ is the binary `is_ground` flag. This ensures the model applies the correct physical logic to each interaction type without interference.

### Data
The data pipeline will be refined to support the sequence-based architecture while retaining the successful feature engineering from previous lessons.

1.  **Sequence Generation:** Construct a sliding window (e.g., $t-5$ to $t+5$) for every contact ID. Unlike the previous approach, preserve the temporal dimension to create $(11, N_{features})$ arrays.
2.  **Feature Engineering:**
    *   **Retain:** Use **Logarithmic Distance** (`np.log1p`) to maximize feature resolution near the contact boundary (Cite Lesson 5).
    *   **Retain:** Use **Clamped Closing Speed** (Physics-based vector calculation with denominator clamping) to ensure numerical stability near singularities (Cite Lesson 7).
    *   **Enhancement:** Include raw `acceleration` and `jerk` (change in acceleration) in the sequence features, allowing the 1D-CNN to directly identify the "whiplash" motion characteristic of tackles.

### Training
The training strategy prioritizes handling the extreme class imbalance and ensuring probability calibration.

1.  **Loss Function:** Use **Weighted Binary Cross-Entropy Loss** with a positive class weight proportional to the imbalance (approx. 72). We explicitly reject Focal Loss for this iteration, as previous experiments showed it underperformed when not aggressively weighted for this specific dataset (Cite Lesson 8).
2.  **Procedure:** Train using the AdamW optimizer. Implement Early Stopping based on Validation MCC (not Loss) to prevent overfitting to the majority class.

### Evaluation
The evaluation pipeline incorporates the critical post-processing step learned from the probability shift issue.

1.  **Threshold Optimization:** Do not use a default 0.5 threshold. After training, perform a grid search on the validation set to determine the optimal decision threshold $T$ that maximizes the Matthews Correlation Coefficient (MCC). This compensates for the probability distribution shift caused by the heavy class weighting (Cite Lesson 2).
2.  **Inference:** Apply the optimized threshold $T$ to the test set predictions to generate the final binary submission.
