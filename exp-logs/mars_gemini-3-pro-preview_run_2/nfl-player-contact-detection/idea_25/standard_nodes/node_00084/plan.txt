The implementation strategy for the `runfile.py` script is as follows:

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility and defining the compute device (GPU/CPU) using the provided `Config`.
2.  **Data Loading**: Use `data_processing.get_data(load_cached=True)` to load the preprocessed datasets. To satisfy the "fast baseline" requirement, the training dataset will be subsampled to 200,000 random samples.
3.  **Model Initialization**: Instantiate the `SERVN` model using the dimension metadata returned by the data loader and move it to the configured device.
4.  **Training**: Configure the `Trainer` with the model, data loaders, and an AdamW optimizer. Execute a short training run (limited to 5 epochs) to ensure quick execution while learning sufficient patterns.
5.  **Validation and Threshold Optimization**:
    *   Evaluate the trained model on the full validation set.
    *   Use `optimize_threshold` to find the decision boundary that maximizes the Matthews Correlation Coefficient (MCC).
    *   Print the final metric in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Calculate the absolute prediction errors on the validation set and compute their correlation with the input kinematic features. Print the top 5 features most correlated with error magnitude to identify systematic weaknesses.
7.  **Submission Generation**: Check if the final MCC exceeds the target of `0.6634847318478787`. If successful, generate predictions for the test set using the optimized threshold and save the result to `./submission/submission.csv`.
