Based on the comprehensive analysis of the accumulated lessons, I propose the **Hierarchical Physics-Informed Residual-Visual Network (HPI-RVN)**.

This solution represents a structural evolution from the "Flat Wide-Input" paradigm. It addresses the "Signal Dominance" and "Noise Sensitivity" trade-offs (Cite solution_lesson_node_00075, solution_lesson_node_00081) by introducing a **Hierarchical Input Encoding** strategy. Instead of feeding a monolithic vector where noisy high-order derivatives (acceleration/jerk) can immediately pollute robust positional signals, we segregate features into physical groups processed by independent encoders. This enforces a "Physics-First" inductive bias while retaining the successful **Residual-Visual Fusion** and strict **Numerical Stability** protocols identified in previous iterations.

# Model
The architecture is a **Dual-Stream Network** fusing a Hierarchical Kinematic backbone with a Visual Correction branch.

1.  **Kinematic Stream (Hierarchical Backbone):**
    *   **Input Grouping:** The flattened wide feature vector (Window $t-5$ to $t+5$) is split into three isolated groups before entering the network:
        *   **Group A (Geometry):** High-precision positional features (e.g., `log_distance`, `shortest_arc_orientation_diff`). These are the cleanest signals (Cite solution_lesson_node_00059).
        *   **Group B (Motion):** First-order derivatives (e.g., `relative_speed`, `clamped_closing_speed`, `time_to_collision`).
        *   **Group C (Dynamics):** Second/Third-order derivatives (e.g., `relative_acceleration`, `jerk`). These are inherently noisy and are strictly **clamped** (Cite solution_lesson_node_00081).
    *   **Independent Encoders:** Each group is processed by its own **Dense Feature Encoder** (Linear $\to$ BatchNorm $\to$ ReLU). This prevents the noise in Group C from destabilizing the weights associated with Group A in the early layers.
    *   **Fusion Backbone:** The outputs of the three encoders are concatenated and fed into a **Deep Residual MLP** (Linear $\to$ BatchNorm $\to$ ReLU $\to$ Dropout $\to$ Linear $\to$ Add). This learns the non-linear interactions between geometry and dynamics (e.g., "Close Proximity" + "High Acceleration" = Impact).
    *   **No Embeddings:** We explicitly **exclude** categorical entity embeddings to prevent the model from learning non-invariant priors (Cite solution_lesson_node_00092).
    *   **Output:** A single scalar logit ($L_{kin}$).

2.  **Visual Stream (Shallow Correction):**
    *   **Input:** A **flattened wide feature vector** of helmet bounding box metrics, derived using a **Max-Pooling Selection Strategy** (Cite solution_lesson_node_00074).
    *   **Backbone:** A **Shallow MLP**. This prevents overfitting to the noisy visual proxy while capturing simple geometric rules (Cite solution_lesson_node_00071).
    *   **Output:** A single scalar logit ($L_{vis}$).

3.  **Residual Fusion:**
    *   **Operation:** $Logit_{final} = L_{kin} + \lambda \cdot L_{vis}$.
    *   **Logits-Only:** The final layer outputs raw logits, strictly adhering to the requirement for numerically stable loss functions (Cite solution_lesson_node_00048).

# Data
The data pipeline synthesizes the "Entity-First" tracking approach with strict physical constraints and ground imputation rules.

1.  **Entity-First Feature Generation:** Generate lags and windowed features on the `player_tracking` dataframe **before** merging it with `train_labels`. This prevents O(N²) scaling errors (Cite solution_lesson_node_00045).
2.  **Explicit Numerical Stability:**
    *   **Clamping:** Explicitly clamp derived kinematic features (especially Group C dynamics) to fixed physical ranges (e.g., `[-50, 50]`) during engineering (Cite solution_lesson_node_00081).
    *   **Angular Continuity:** Use the **Shortest Arc** method (e.g., `min(|a-b|, 360-|a-b|)`) for relative angles (Cite solution_lesson_node_00076).
    *   **Resolution Enhancement:** Apply `np.log1p(distance)` (Cite solution_lesson_node_00005) and `clamped_closing_speed` (Cite solution_lesson_node_00007).
3.  **Hybrid Ground Imputation:**
    *   **Kinematics:** Impute Ground Position = Player Position (Distance=0) and Ground Velocity = 0. This preserves the "Relative Motion" signal (Cite solution_lesson_node_00034).
    *   **Visuals:** For Ground interactions, set `Visual_IoU` to 0 but retain the **Player's Helmet Box Top** features to capture the "falling" visual signature (Cite solution_lesson_node_00071).
4.  **Visual Feature Selection (Max-Pooling):** Apply a **Max-Pooling Strategy** per timestamp to select the single "best" view (largest box area) for each player. This creates a dense, consistent visual feature vector (Cite solution_lesson_node_00074).
5.  **Normalization:** Apply **StandardScaler** to all input groups (Cite solution_lesson_node_00037).

# Training
The training strategy is optimized for stability and calibration on the full dataset, strictly adhering to the Alpha-Gamma balance.

1.  **Loss Function:** Use **Focal Loss** implemented via `BCEWithLogitsLoss`. Crucially, set `alpha=0.25` and `gamma=2.0`. This corrects the error of aggressively increasing `alpha`, ensuring the loss properly balances the suppression of easy negatives with the regularization of noisy labels (Cite solution_lesson_node_00077).
2.  **Full Dataset:** Train on the **entire training set** (3.4M rows). The efficient tabular architecture allows this within the compute budget (Cite solution_lesson_node_00023).
3.  **Optimizer:** Use **AdamW** with **Early Stopping** monitoring the Validation MCC.

# Evaluation
The evaluation pipeline includes a mandatory calibration step.

1.  **Threshold Optimization:** Post-training, perform a grid search on the **validation set** to find the decision threshold $T$ that maximizes the Matthews Correlation Coefficient (MCC). This aligns the decision boundary with the probability distribution (Cite solution_lesson_node_00002).
2.  **Inference:** Apply the optimized threshold $T$ to the test set predictions to generate the final binary submission.
