Implementation strategy:
1.  **Environment Setup**: Initialize the environment with the fixed random seed and detect the available computation device (GPU/CPU) using the provided utility functions.
2.  **Data Pipeline**: Invoke `get_dataloaders` with `load_cached_data=True` to efficiently load the preprocessed training, validation, and test datasets along with the feature dimension dictionary.
3.  **Model Initialization**: Instantiate the `EARVN` model using the input dimensions derived from the data loading step and move the model to the computation device.
4.  **Training Loop**: Initialize the `Trainer` with the model, loaders, `AdamW` optimizer, and `FocalLoss`. Execute the training loop for a limited number of epochs (3) to satisfy the "fast baseline" requirement while ensuring sufficient convergence for evaluation.
5.  **Validation & Evaluation**:
    *   Load the best model weights saved during training.
    *   Evaluate the model on the full validation set to obtain logits and targets.
    *   Perform a grid search to find the optimal decision threshold maximizing the Matthews Correlation Coefficient (MCC).
    *   Print the final validation metric in the strictly required format.
6.  **Failure Analysis**:
    *   Calculate the absolute prediction errors on the validation set.
    *   Compute and print the correlation between these errors and the input features (Kinematic, Visual, Gating) to identify sources of systematic error.
7.  **Submission**: Compare the final validation MCC against the specified threshold (0.6634847318478787). If the metric exceeds the threshold, trigger the submission generation process using the `Trainer`.
