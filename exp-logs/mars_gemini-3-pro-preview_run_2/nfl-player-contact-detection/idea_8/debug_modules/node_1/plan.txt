The issue is that the `ids` array contains string data (contact IDs), which NumPy stores as an `object` array. When saving these arrays, NumPy uses Python's pickle protocol. However, for security reasons, `np.load` defaults to `allow_pickle=False`, causing a `ValueError` when attempting to reload the cached ID files. The fix is to explicitly set `allow_pickle=True` when loading the `ids` array in `library/data_processing.py`.
