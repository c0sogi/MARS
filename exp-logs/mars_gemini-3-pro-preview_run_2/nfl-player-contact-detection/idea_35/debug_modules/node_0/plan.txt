The following script demonstrates the end-to-end usage of the provided machine learning pipeline for predicting contact events. The strategy involves:

1.  **Configuration Setup**: Overriding default `Config` paths and parameters to use a temporary working directory and enable fast execution (debug mode, fewer epochs).
2.  **Unit Verification**: Testing specific critical components like `InputClamping` and `impute_ground` logic in isolation to ensure correctness.
3.  **Pipeline Execution**: Running the full training (`train_model`) and inference (`run_inference`) workflows using the `debug` flag, which samples a small subset of the data.
4.  **Output Validation**: Asserting that the model artifacts (weights, scalers) and the final submission file are generated correctly and contain the expected data.
