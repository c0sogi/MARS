The following script performs a comprehensive Exploratory Data Analysis (EDA) on the training dataset.

**Strategy:**
1.  **Setup & Data Loading**: The script initializes by setting random seeds for reproducibility and loading the primary training metadata (`metadata/train.csv`) and auxiliary tabular datasets (`train_player_tracking.csv`, `train_baseline_helmets.csv`).
2.  **Target Analysis**: It analyzes the distribution of the binary `contact` variable in the training labels to assess class imbalance.
3.  **Tabular Data Analysis**:
    *   It computes descriptive statistics (mean, std, outliers) for numerical features in the player tracking and helmet datasets.
    *   It analyzes categorical columns for cardinality and rare labels.
    *   It checks for missing values.
4.  **Image/Video Analysis**:
    *   It samples a subset of video files referenced in the metadata.
    *   Using `cv2`, it extracts video properties (dimensions, frame counts) and computes pixel-level statistics (mean, std) by sampling frames to inform normalization strategies.
5.  **Feature Relationships**:
    *   It constructs a merged dataset linking contact labels with player tracking data (speed, acceleration, position).
    *   It handles the "Ground" contact case by creating a specific flag and imputing missing tracking data.
    *   It calculates correlations between physical metrics and contact events.
    *   It trains a lightweight Random Forest classifier to identify the top 5 most important features for predicting contact.
6.  **Meta-Feature Analysis**: It briefly examines the relationship between the `step` (time within play) and contact frequency.
