The implementation strategy follows a streamlined machine learning pipeline:
1.  **Environment Setup**: Initializes random seeds and detects the compute device (GPU) to ensure reproducibility and performance.
2.  **Data Management**: Uses the provided `DataProcessor` to load cached training and validation data. To adhere to the "fast baseline" requirement and time constraints, the training dataset is subsampled (stratified or random) to a manageable size (e.g., 500k samples) while retaining the full validation set for accurate metric reporting.
3.  **Model Training**: Instantiates the `TRGCN` model and `Trainer`. The model is trained for a limited number of epochs (5) with Early Stopping to prevent overfitting and minimize runtime.
4.  **Validation & Analysis**: After training, the best model weights are loaded. The script calculates the Matthews Correlation Coefficient (MCC) on the validation set and prints it in the required format. It then performs failure analysis by correlating prediction errors with input features (like distance and speed) to identify weakness areas.
5.  **Inference**: Checks if the validation MCC exceeds the specified threshold. If successful, it loads the test data, generates predictions using the `InferenceEngine`, and saves the formatted `submission.csv`.
