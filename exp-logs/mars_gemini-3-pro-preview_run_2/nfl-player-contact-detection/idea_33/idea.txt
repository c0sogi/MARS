Based on the comprehensive analysis of the accumulated lessons, specifically the finding that **Categorical Entity Embeddings** lead to overfitting/memorization (Cite solution_lesson_node_00092) and that **Explicit Numerical Stability** is required for derived physics (Cite solution_lesson_node_00081), I propose the **Invariant-Physical Residual-Visual Network (IP-RVN)**.

This solution represents a structural correction to the recent trend of "Context-Aware" architectures. It rejects the use of categorical identifiers (Team, Position) in favor of a strictly **Invariant** feature space, enforcing the principle that physical laws are universal. It combines this robust kinematic backbone with a **Residual Visual Correction** stream, strictly adhering to the stability and loss parameters identified as critical in the failure analysis.

# Model
The architecture is a **Dual-Stream Network** designed to fuse a high-precision, invariant kinematic signal with a noisy visual proxy.

1.  **Kinematic Stream (Invariant Backbone):**
    *   **Input:** A **flattened wide feature vector** of player tracking data (Window $t-5$ to $t+5$).
    *   **Strict Invariance (Structural Innovation):** We explicitly **exclude** all categorical entity embeddings (`position`, `team`, `player_id`). The model must learn contact solely from relative kinematics (e.g., "Object A approaching Object B"), preventing it from memorizing spurious correlations (e.g., "Player X tackles often") (Cite solution_lesson_node_00092).
    *   **Input Clamping Layer:** A fixed, non-trainable layer immediately following the input that strictly clamps all continuous features to a pre-defined physical range (e.g., `[-50, 50]`). This prevents outliers in derivative features (like closing speed) from destabilizing the gradients (Cite solution_lesson_node_00081).
    *   **Backbone:** A **Deep Residual MLP** (Linear $\to$ BatchNorm $\to$ ReLU $\to$ Dropout $\to$ Linear $\to$ Add). This provides the capacity to learn non-linear physical interactions (e.g., "High Speed" + "Low Angle" = Contact) without the optimization difficulties of Gated or Cross networks (Cite solution_lesson_node_00059, solution_lesson_node_00082).
    *   **Output:** A single scalar logit ($L_{kin}$).

2.  **Visual Stream (Shallow Correction):**
    *   **Input:** A **flattened wide feature vector** of helmet bounding box metrics, derived using a **Max-Pooling Selection Strategy** (Cite solution_lesson_node_00074).
    *   **Backbone:** A **Shallow MLP**. This prevents overfitting to the noisy visual proxy while capturing simple geometric rules (e.g., "Zero IoU $\to$ Reduce Probability") (Cite solution_lesson_node_00071).
    *   **Output:** A single scalar logit ($L_{vis}$).

3.  **Residual Fusion:**
    *   **Operation:** $Logit_{final} = L_{kin} + \lambda \cdot L_{vis}$.
    *   **Logits-Only:** The final layer outputs raw logits, strictly adhering to the requirement for numerically stable loss functions (Cite solution_lesson_node_00048).

# Data
The data pipeline synthesizes the "Entity-First" tracking approach with strict physical constraints and ground imputation rules.

1.  **Entity-First Feature Generation:** Generate lags and windowed features on the `player_tracking` dataframe **before** merging it with `train_labels`. This prevents O(N²) scaling errors (Cite solution_lesson_node_00045).
2.  **Explicit Numerical Stability:**
    *   **Pre-Clamping:** During feature engineering, explicitly clamp derived kinematic features (e.g., `closing_speed`, `acceleration`) to match the model's clamping layer (Cite solution_lesson_node_00081).
    *   **Angular Continuity:** Use the **Shortest Arc** method (e.g., `min(|a-b|, 360-|a-b|)`) for relative angles to avoid manifold discontinuities (Cite solution_lesson_node_00076).
    *   **Resolution Enhancement:** Apply `np.log1p(distance)` (Cite solution_lesson_node_00005) and `clamped_closing_speed` (Cite solution_lesson_node_00007).
3.  **Hybrid Ground Imputation:**
    *   **Kinematics:** Impute Ground Position = Player Position (Distance=0) and Ground Velocity = 0. This preserves the "Relative Motion" signal (Cite solution_lesson_node_00034).
    *   **Visuals:** For Ground interactions, set `Visual_IoU` to 0 but retain the **Player's Helmet Box Top** features to capture the "falling" visual signature (Cite solution_lesson_node_00071).
4.  **Visual Feature Selection (Max-Pooling):** Apply a **Max-Pooling Strategy** per timestamp to select the single "best" view (largest box area) for each player. This creates a dense, consistent visual feature vector, avoiding the sparsity of concatenation (Cite solution_lesson_node_00074).
5.  **Normalization:** Apply **StandardScaler** to the final fused vector (Cite solution_lesson_node_00037).

# Training
The training strategy is optimized for stability and calibration on the full dataset, strictly adhering to the Alpha-Gamma balance.

1.  **Loss Function:** Use **Focal Loss** implemented via `BCEWithLogitsLoss`. Crucially, set `alpha=0.25` and `gamma=2.0`. This corrects the error of aggressively increasing `alpha` (to 0.75), ensuring the loss properly balances the suppression of easy negatives with the regularization of noisy labels (Cite solution_lesson_node_00077).
2.  **Full Dataset:** Train on the **entire training set** (3.4M rows). The efficient tabular architecture allows this within the compute budget, avoiding the performance degradation associated with subsampling (Cite solution_lesson_node_00023).
3.  **Optimizer:** Use **AdamW** with **Early Stopping** monitoring the Validation MCC.

# Evaluation
The evaluation pipeline includes a mandatory calibration step.

1.  **Threshold Optimization:** Post-training, perform a grid search on the **validation set** to find the decision threshold $T$ that maximizes the Matthews Correlation Coefficient (MCC). This aligns the decision boundary with the probability distribution (Cite solution_lesson_node_00002).
2.  **Inference:** Apply the optimized threshold $T$ to the test set predictions to generate the final binary submission.
