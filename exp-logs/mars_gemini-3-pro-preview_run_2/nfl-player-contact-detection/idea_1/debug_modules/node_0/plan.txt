Implementation Strategy:
1.  **Configuration Override**: Monkey-patch the `library.config` module to reduce the number of epochs, batch size, and model complexity. This ensures the demonstration runs quickly within the time limit while still exercising the full pipeline.
2.  **Feature Engineering Verification**: Manually invoke `feature_engineering.generate_features` with `debug=True`. Verify the resulting feature matrix dimensions, target consistency, and absence of NaN values.
3.  **Dataset Class Verification**: Instantiate `NFLContactDataset` using the generated features. Verify that `__getitem__` returns tensors of the correct shape and data type.
4.  **Model Architecture Verification**: Instantiate the `KinematicMLP` model. Perform a forward pass with dummy data to confirm the network architecture and output dimensions (batch_size, 1).
5.  **Full Pipeline Execution**: Run `training.train` and `training.predict` with `debug=True`. This tests the training loop, validation logic, threshold optimization, model saving, and inference.
6.  **Submission Validation**: Check the generated submission file for existence, correct shape, and valid column names/values.
