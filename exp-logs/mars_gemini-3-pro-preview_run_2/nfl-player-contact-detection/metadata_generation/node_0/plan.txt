The strategy for generating the metadata involves the following steps:

1.  **Setup and Loading**: Define the input (`./input`) and output (`./metadata`) directories. Load the `train_labels.csv` and `sample_submission.csv` files using Pandas.
2.  **Training Data Processing**:
    *   Identify unique `game_play` identifiers to use as groups for splitting.
    *   Perform a Group Shuffle Split (80% train, 20% validation) using `RANDOM_STATE = 42` to ensure that all time-steps for a specific play remain in the same split, preventing data leakage.
    *   Assign video file paths (Sideline, Endzone, All29) relative to the `./input` directory based on the `game_play` ID and the `train/` folder structure.
3.  **Test Data Processing**:
    *   Parse the `contact_id` in `sample_submission.csv` to extract `game_play`, `step`, and player IDs, as these columns are not explicitly provided in the submission file.
    *   Assign video file paths based on the `test/` folder structure.
    *   (Optional but recommended) Merge with `test_player_tracking.csv` to acquire `datetime` information for the test set steps, aligning the schema with the training metadata.
4.  **Saving Metadata**: Save the processed DataFrames to `train.csv`, `validation.csv`, and `test.csv` in the `./metadata` directory.
5.  **Validation**:
    *   Reload the generated metadata files.
    *   Verify the 80:20 split ratio and ensure no `game_play` leakage between train and validation sets.
    *   Randomly sample 1000 file paths from the metadata and verify their existence in the `./input` directory.
    *   Print summary statistics for all datasets.
