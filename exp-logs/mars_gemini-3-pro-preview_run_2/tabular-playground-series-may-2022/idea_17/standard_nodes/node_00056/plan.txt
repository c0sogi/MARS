The implementation strategy follows a streamlined pipeline designed to meet the time constraints and functional requirements:

1.  **Setup**: Initialize the environment, random seeds, and compute device using the provided library utilities.
2.  **Fast Training**: Execute the training loop using `library.train.train`. To ensure a quick baseline, the training is restricted to a subset of 100,000 samples and a maximum of 5 epochs. This balances speed with sufficient signal learning.
3.  **Full Validation**: After training, reload the data loaders with the **full** validation set (disabling subsampling) and load the best model checkpoint. Perform inference to calculate the final AUC score.
4.  **Metric & Analysis**: Print the validation metric in the required format. Perform failure analysis by calculating the correlation between the model's prediction error (absolute difference) and the input continuous features on the validation set.
5.  **Conditional Submission**: Compare the final AUC against the specific threshold (0.9970005855169476). If the threshold is exceeded, generate predictions for the full test set and save the formatted submission file to `./submission/submission.csv`.
