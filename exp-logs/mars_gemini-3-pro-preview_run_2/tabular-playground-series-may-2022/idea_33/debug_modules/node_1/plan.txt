The issue is caused by Python's handling of default argument values, which are evaluated once at function definition time. In `library/data.py`, the `get_dataloaders` function defines `debug=config.DEBUG`. Since `config.DEBUG` is `False` when the module is imported, the function defaults to `False` regardless of subsequent changes to `config.DEBUG` in `runfile.py`. Consequently, `generate_submission` loads the full test set (100,000 rows) instead of the debug subset (2,000 rows), triggering the assertion error. To fix this, we change the default value to `None` and resolve `config.DEBUG` at runtime inside the function. This ensures the data loading logic respects the active debug configuration, synchronizing the data stream size with the pipeline's expectations (Cite debug_lesson_4).
