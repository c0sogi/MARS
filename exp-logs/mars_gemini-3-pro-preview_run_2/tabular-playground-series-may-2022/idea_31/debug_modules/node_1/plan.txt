The `KeyError: 'target'` is caused by a column name collision when merging the metadata DataFrame (which contains a `target` column) with the raw training data (which also contains a `target` column). As explained in **debug_lesson_1**, Pandas automatically renames these colliding columns to `target_x` and `target_y`, causing the subsequent lookup for `df["target"]` to fail. Additionally, `library/config.py` contains a top-level call to `train_model()` which inadvertently triggers a full training run (and the associated error) immediately upon import in `runfile.py`.

To fix this, I will:
1.  Remove the `train_model()` execution from the global scope of `library/config.py`.
2.  Update the `extract_features` function in both `library/config.py` and `library/dataset.py` to drop the `target` column from the raw data before merging, ensuring the merged DataFrame retains the correct `target` column from the metadata.
