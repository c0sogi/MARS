The following implementation demonstrates the usage of the provided library files (`config.py`, `utils.py`, `data.py`, `model.py`, `train.py`).

**Strategy:**
1.  **Data Loading**: We utilize `data.process_data` to load and preprocess the raw CSV files. To ensure the demonstration runs quickly, we then manually slice a small subset of the processed data (128 samples) to create lightweight DataLoaders using the `data.ManufacturingDataset` class.
2.  **Model Verification**: We instantiate the `model.HybridNetwork`, move it to the appropriate device, and perform a forward pass with a dummy batch to verify input/output shapes.
3.  **Training Components**: Instead of running the full 40-epoch training loop provided in `train.run_training` (which would take too long), we demonstrate the core building blocks: `train.train_one_epoch`, `train.validate`, and `train.predict` using the subset DataLoaders.
4.  **Verification**: Assertions are placed throughout to ensure data shapes, metric calculations, and prediction ranges are correct.
