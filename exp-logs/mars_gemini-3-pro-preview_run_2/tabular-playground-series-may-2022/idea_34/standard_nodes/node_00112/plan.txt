The implementation strategy follows the orchestration of the provided library components to establish a high-performance baseline within the runtime constraints.

1.  **Configuration Override**: We modify the `Config` class at runtime to reduce `EPOCHS` to 20. This ensures the "fast baseline" requirement is met while still allowing sufficient convergence on the A100 GPU. We explicitly keep `DEBUG = False` to utilize the full 640,000-sample training set, which is necessary to achieve the high AUC threshold (>0.997).
2.  **Pipeline Execution**: The script initializes the `Trainer`, runs the training loop via `fit()`, and saves the best model.
3.  **Validation & Analysis**: We manually reload the validation set and the best model checkpoint to perform inference. This allows us to calculate the exact `Final Validation Metric` and perform the required failure analysis by correlating prediction errors with continuous input features.
4.  **Conditional Submission**: Finally, the script checks the computed AUC against the strict threshold (0.9972336610045187) and generates the submission file using `trainer.predict()` only if the condition is met.
