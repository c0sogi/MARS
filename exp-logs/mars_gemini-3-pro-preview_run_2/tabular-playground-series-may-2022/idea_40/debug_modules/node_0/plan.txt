This script demonstrates the end-to-end usage of the provided machine learning library for the manufacturing control task. It performs the following steps:

1.  **Setup**: Initializes the environment and sets random seeds for reproducibility.
2.  **Data Processing Verification**: Explicitly calls the data processing pipeline to convert raw CSVs into optimized Numpy arrays, verifying shapes and data integrity.
3.  **DataLoader Verification**: Instantiates DataLoaders and checks the dimensions of a single batch to ensure alignment with the model configuration.
4.  **Model Verification**: Instantiates the `HybridNetwork` model and performs a dummy forward pass on the GPU to validate the architecture and output range.
5.  **Training Execution**: Runs the full training loop for a limited number of epochs (2) using a large batch size to demonstrate the training, validation, and inference process quickly on the provided A100 GPU.
6.  **Submission Validation**: Loads the generated submission file to confirm it meets the format and value range requirements.
