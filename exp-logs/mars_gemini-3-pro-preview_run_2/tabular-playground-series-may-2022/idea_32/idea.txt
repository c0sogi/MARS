Based on the comprehensive history of experiments and the derived empirical lessons, I propose the implementation of a **Dual-Stem Post-Norm SwiGLU-ResFunnel Network**.

This strategy represents a structural evolution that pushes the "Late Fusion" principle (Cite solution_lesson_node_00093) further by introducing **Modality-Specific Processing Stems**. Instead of fusing raw embeddings and continuous features immediately, this architecture refines each modality through independent SwiGLU blocks before concatenation. This ensures that the fusion layer receives high-level, non-linearly processed representations from both streams, mitigating the distribution mismatch issues identified in previous fusion attempts (Cite solution_lesson_node_00069, solution_lesson_node_00074), while retaining the proven Post-Norm Transformer (Cite solution_lesson_node_00095) and SwiGLU backbone (Cite solution_lesson_node_00090).

# Model

The architecture is a dual-stream network that processes categorical and continuous features via dedicated non-linear stems before fusing them into a deep residual funnel.

1.  **Stream 1: Categorical Sequence (Post-Norm Transformer)**
    *   **Input**: The `f_27` feature is decomposed into 10 distinct character tokens.
    *   **Embedding**: Tokens are passed through a shared embedding layer (dimension 32).
    *   **Positional Encoding**: **Learnable Absolute Positional Embeddings** are added.
        *   **Initialization**: Explicitly initialize with **Low Variance Random Noise** ($\mathcal{N}(0, 0.02)$) to break symmetry without introducing high-magnitude noise (Cite solution_lesson_node_00081).
        *   **Type**: Use Absolute embeddings, as they are superior to RoPE for fixed-length tabular sequences (Cite solution_lesson_node_00096).
    *   **Encoder**: The sequence is processed by a **Standard Transformer Encoder** (2 layers, 4 heads).
        *   **Configuration**: Use **Post-Normalization** (`norm_first=False`) to maximize capacity for this shallow encoder (Cite solution_lesson_node_00095).
        *   **Activation**: Explicitly set `activation="gelu"` (Cite solution_lesson_node_00068).
        *   **Regularization**: Apply **Low Dropout (0.1)** (Cite solution_lesson_node_00048).
    *   **Output**: The resulting sequence is flattened.

2.  **Stream 2: Continuous Preservation**
    *   **Input**: The 30 numerical features are standardized.
    *   **Preservation**: Features are maintained in their **raw, normalized form** (Cite solution_lesson_node_00038).

3.  **Structural Innovation: Dual Non-Linear Stems**
    *   Instead of concatenating the Flattened Transformer Output and Raw Continuous Features directly, process them independently to map them into a compatible latent space.
    *   **Sequence Stem**: Pass the flattened sequence vector through a **Pre-Norm SwiGLU Block** (Linear $\to$ LayerNorm $\to$ SwiGLU $\to$ Dropout).
    *   **Continuous Stem**: Project the raw continuous features to the same width as the sequence stem via a Linear layer, then pass through an identical **Pre-Norm SwiGLU Block**.
    *   **Rationale**: This creates a "Stage 0" for each modality, allowing the network to perform initial feature extraction and distribution alignment independently. This prevents the high-variance raw continuous features from dominating the gradients at the fusion point (Cite solution_lesson_node_00069).

4.  **Fusion & Backbone: SwiGLU ResFunnel**
    *   **Fusion**: Concatenate the outputs of the Sequence Stem and Continuous Stem.
    *   **Projection**: Pass through a Linear layer to map to the backbone width (512) (Cite solution_lesson_node_00073).
    *   **Topology**: The backbone is organized into 3 stages (512 $\to$ 256 $\to$ 128) (Cite solution_lesson_node_00084).
    *   **Sustained Depth**: Each stage consists of **3 stacked Residual Blocks** (Cite solution_lesson_node_00070).
    *   **Blocks**: Use **Pre-LayerNorm Direct SwiGLU Residual Blocks**.
        *   **Structure**: $x_{out} = x + \text{DropPath}(\text{Dropout}(\text{SwiGLU}(\text{Linear}(\text{LayerNorm}(x)))))$.
        *   **Normalization**: Use **LayerNorm** (Cite solution_lesson_node_00087).
    *   **Regularization**: Linear **Stochastic Depth** schedule (0.0 to 0.2) (Cite solution_lesson_node_00086) + **Dropout (0.35)**.

5.  **Output Head**
    *   **Minimalist Design**: Single `Linear` layer with Sigmoid activation (Cite solution_lesson_node_00060).

# Data

1.  **Decomposition**: The string feature `f_27` is strictly split into 10 integer-encoded columns.
2.  **Normalization**: Continuous features (`f_00` - `f_30`) are Z-score normalized (StandardScaler).
3.  **Splitting**: Use the metadata-defined stratified validation split.
4.  **Volume**: Use the **Full Training Dataset** (640,000 samples) (Cite solution_lesson_node_00058).

# Training

1.  **Optimizer**: Use **AdamW**.
2.  **Strict Decoupled Weight Decay**:
    *   **Group 1 (Decay 1e-2)**: Weights of Linear layers, Embeddings, and Attention projections.
    *   **Group 2 (Decay 0.0)**: Biases, **LayerNorm parameters**, and **Positional Embeddings**. Explicitly filter by name (e.g., `pos_embed`) to prevent the permutation-invariance failure (Cite solution_lesson_node_00098).
3.  **Initialization**:
    *   **SwiGLU Blocks**: Use **Kaiming (He) Uniform** (Cite solution_lesson_node_00090).
    *   **Transformer**: Use **Xavier (Glorot)** (Cite solution_lesson_node_00082).
4.  **Optimization Granularity**:
    *   **Batch Size**: 1024 (Cite solution_lesson_node_00044).
    *   **Scheduler**: Aggressive Step Decay (factor 0.1 every 10 epochs) (Cite solution_lesson_node_00033).
5.  **Duration**: Train for **40 epochs** (Cite solution_lesson_node_00045).
6.  **Metric**: Monitor **Validation AUC** (Cite solution_lesson_node_00003).

# Evaluation

1.  **Inference**: Iterate through the test set using the trained Dual-Stem Post-Norm SwiGLU-ResFunnel.
2.  **Prediction**: Generate predictions using the single output head.
3.  **Submission**: The raw probability outputs are saved directly to the submission file.
