The following script demonstrates the end-to-end usage of the provided machine learning library for the manufacturing control task.

**Strategy:**
1.  **Configuration Override**: We dynamically modify the `ModelConfig` class attributes to set up a "Demo Mode". This includes changing the working directory to avoid overwriting existing experiments, enabling the `DEBUG` flag to use a small subset of data (10,000 samples), and reducing the training duration to 1 epoch.
2.  **Data Pipeline Verification**: We utilize `get_dataloaders` to load the data. We explicitly assert the shapes of the batches (continuous features, categorical features, and targets) to ensure the `ManufacturingDataset` and `DataLoader` are functioning correctly.
3.  **Model Architecture Check**: We instantiate the `IIResFunnelGLU` model and perform a forward pass with a single batch. We verify that the output logits have the expected shape `(Batch_Size, 1)`.
4.  **Training & Evaluation Loop**: We manually execute the training components (`train_one_epoch`, `validate`) rather than calling the black-box `run_pipeline`. This allows us to inspect the loss values and AUC metric immediately.
5.  **Checkpointing**: We demonstrate `save_checkpoint` and `load_checkpoint` to ensure model persistence works.
6.  **Inference**: Finally, we generate predictions on the test set and create a valid submission file, verifying the output format.
