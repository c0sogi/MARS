The following script demonstrates the usage of the provided machine learning library for the manufacturing control task.

### Implementation Strategy
1.  **Environment Setup**: Initialize random seeds for reproducibility and suppress unnecessary warnings.
2.  **Monkey Patching**: Disable `tqdm` progress bars to comply with the output requirements, as the provided library files use them.
3.  **Component Verification (Unit Tests)**:
    *   **Layers**: Instantiate and test `RMSNorm`, `SwiGLU`, and `RoPEAttention` with dummy tensors to verify output shapes and basic functionality.
    *   **Model**: Instantiate the `RoPESwiGLURMSNet` and perform a forward pass with synthetic data to confirm the architecture produces the correct output shape `(batch_size, 1)`.
    *   **Data Processing**: Test the `Tokenizer` on a sample string and verify the `ManufacturingDataset` and `get_dataloaders` function using the debug mode (subset of data).
4.  **Pipeline Execution (Integration Tests)**:
    *   **Training**: Execute `run_training(debug=True)` to train the model for a few epochs on a small subset of the data. This verifies the training loop, loss calculation, and model checkpointing.
    *   **Inference**: Execute `predict(debug=True)` to generate predictions using the trained model.
5.  **Output Validation**: Assert that the expected output files (`best_model.pth`, `submission.csv`) exist and that the submission file follows the correct format and length.
