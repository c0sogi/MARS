5.  **Failure Analysis**:
    *   Calculate the Mean Absolute Error (MAE) for each sample in the validation set.
    *   Load the raw validation metadata to extract text features (e.g., Question Body Length, Answer Length).
    *   Compute and print the Spearman correlation between the model's error magnitude and these input features to identify potential biases or weaknesses.

6.  **Submission Generation**:
    *   Check if the validation metric exceeds the threshold (`0.38439426044249936`).
    *   If the condition is met, generate predictions for the test set using `trainer.predict()`.
