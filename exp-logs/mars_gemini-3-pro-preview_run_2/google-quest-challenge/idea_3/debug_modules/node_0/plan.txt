This script demonstrates the usage of the provided library modules for the StackExchange Question-Answer Labeling task. It performs the following steps:
1.  **Configuration**: Modifies the global `Config` class to run in `DEBUG` mode with a small subset of data (20 samples) and reduced training epochs (1 epoch) for rapid execution.
2.  **Dataset & Dataloader Verification**: Manually initializes the tokenizer and dataloaders to verify that the `QuestDataset` correctly processes text inputs and yields batches with the expected shapes and keys.
3.  **Model Verification**: Instantiates the `CausalAwareSiameseDeberta` model and performs a forward pass with a sample batch to confirm the architecture outputs logits of the correct shape (Batch Size, 30 Targets).
4.  **Metric Verification**: Tests the `compute_spearmanr` function with synthetic data to ensure the scoring logic is correct.
5.  **Trainer Integration**: Runs the full `Trainer` pipeline (`fit` and `predict`) to demonstrate the end-to-end training and inference process, validating the generation of submission-ready predictions.
