Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment by suppressing warnings and setting random seeds using the provided `library` modules to ensure reproducibility.
2.  **Model Training**: Instantiate the `Trainer` class from `library.trainer`. Utilize the pre-implemented training pipeline (`trainer.run()`) which handles the training loop, validation monitoring, early stopping, and automatic loading of the best model weights. We will use the full dataset (as it is small) and a reasonable epoch count (10) to create a fast but effective baseline.
3.  **Validation Assessment**: After training, explicitly call the `validate` function on the validation set using the best model. Print the resulting Mean Spearman Correlation in the strictly required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**: Perform a manual inference pass on the validation set to gather predictions and targets. Calculate the Mean Absolute Error (MAE) for each sample. Compute and print the Spearman correlation between this error and the input sequence lengths (Question and Answer length) to identify if sequence length biases the model's performance.
5.  **Submission Verification**: The `trainer.run()` method automatically generates the submission file. We will verify its existence and ensure the pipeline completes successfully.
