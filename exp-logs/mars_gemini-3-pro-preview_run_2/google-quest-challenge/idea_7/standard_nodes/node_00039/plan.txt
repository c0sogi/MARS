To improve the model's performance, I will implement three targeted optimizations based on the empirical findings and lessons learned:

1.  **Head+Tail Truncation for Long Sequences**: The failure analysis revealed a correlation between prediction error and question length (`Error vs q_len_char: 0.1448`). The current standard truncation likely discards the end of long question bodies, which often contains the core inquiry or summary. I will modify `process_data` to implement a "Head+Tail" truncation strategy (keeping the first 256 and last 256 tokens roughly) instead of simple tail truncation. This ensures the model sees both the context setup and the final question.

2.  **Gradient Accumulation**: To stabilize training and improve generalization, I will increase the effective batch size from 4 to 16 using Gradient Accumulation (`ACCUMULATION_STEPS = 4`). This simulates a larger batch size on the limited GPU memory, reducing gradient noise.

3.  **Cosine Learning Rate Schedule**: Citing **Lesson 00015** regarding convergence latency in Siamese networks, I will replace the linear scheduler with a Cosine schedule. This typically yields better convergence for fine-tuning transformers by maintaining a higher learning rate for longer before decaying.

        # Tokenize without special tokens first
        enc_a = tokenizer(text_list_a, add_special_tokens=False)
        enc_b = tokenizer(text_list_b, add_special_tokens=False) if text_list_b else None
        
        input_ids_out = []
        attention_mask_out = []
        
        cls_id = tokenizer.cls_token_id
        sep_id = tokenizer.sep_token_id
        pad_id = tokenizer.pad_token_id
        
        count = len(text_list_a)
        
        for i in range(count):
            ids_a = enc_a['input_ids'][i]
            ids_b = enc_b['input_ids'][i] if enc_b else []
            
            # Construct: [CLS] A [SEP] B [SEP] or [CLS] A [SEP]
            # Overhead: 3 if B exists, else 2
            overhead = 3 if enc_b else 2
            
            total_tokens = len(ids_a) + len(ids_b) + overhead
            
            if total_tokens > max_len:
                # Truncation Strategy
                if enc_b:
                    # Priority: Keep A (Title), Truncate B (Body)
                    avail_b = max_len - len(ids_a) - overhead
                    if avail_b < 0:
                        # A is too big, truncate A, drop B
                        ids_a = ids_a[:max_len-overhead] # Simple tail cut for Title
                        ids_b = []
                    else:
                        # Head+Tail for B
                        half = avail_b // 2
                        ids_b = ids_b[:half] + ids_b[-half:] if half > 0 else []
                else:
                    # Single sequence: Head+Tail
                    avail_a = max_len - overhead
                    half = avail_a // 2
                    ids_a = ids_a[:half] + ids_a[-half:] if half > 0 else []

                seq = [cls_id] + ids_a + [sep_id]

                mask += [0] * pad_len
