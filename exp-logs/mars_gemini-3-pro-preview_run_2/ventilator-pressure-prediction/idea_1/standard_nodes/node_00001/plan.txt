Implementation strategy:
1.  **Configuration**: Import the `Config` class and modify hyperparameters to create a fast baseline. Specifically, set `EPOCHS` to 5 and enable `DEBUG` mode with a small sample size (e.g., 5000 breaths) to ensure the code runs quickly within the time limit.
2.  **Setup**: Initialize the random seed using `seed_everything` for reproducibility.
3.  **Data Loading**: Call `get_data_loaders` with `load_cached_data=True`. This will attempt to load pre-processed data from the `./working` directory or process the raw data (respecting the debug/sample size settings) if the cache is missing.
4.  **Model Training**: Instantiate the `BiLSTMRegressor` and the `Trainer`. Execute the training loop via `trainer.fit()`.
5.  **Validation & Analysis**:
    *   Load the best model checkpoint saved during training.
    *   Run inference on the validation set to gather predictions, targets, and input features.
    *   Calculate the **Mean Absolute Error (MAE)** specifically for the inspiratory phase (where `u_out == 0`) and print it in the required format.
    *   Perform failure analysis by calculating the absolute error for each time step and computing its correlation with the input features (`time_step`, `u_in`, `R`, `C`, etc.). Print these correlations.
6.  **Submission**: Run `trainer.predict()` to generate predictions on the test set and save the `submission.csv` file.
