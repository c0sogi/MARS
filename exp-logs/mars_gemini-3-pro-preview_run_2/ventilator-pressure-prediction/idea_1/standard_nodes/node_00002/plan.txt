The `InvalidSubmissionError` is caused by the `Config.DEBUG` flag being set to `True` in `runfile.py`. This triggers logic in the data processing pipeline that truncates the test dataset to a smaller sample size (5,000 breaths) for debugging purposes. Consequently, the generated `submission.csv` contains fewer rows than the expected full test set (7,545 breaths), leading to a length mismatch during grading. To fix this, I will set `Config.DEBUG` to `False` in `runfile.py`, ensuring the model generates predictions for the entire test set.
