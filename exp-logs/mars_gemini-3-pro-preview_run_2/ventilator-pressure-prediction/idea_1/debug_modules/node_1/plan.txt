The issue arises because Python evaluates default arguments at function definition time (when the module is imported), not at call time. In `library/utils.py`, `save_checkpoint` sets `filename` to `Config.MODEL_CHECKPOINT` as a default argument. Since `runfile.py` modifies `Config.MODEL_CHECKPOINT` *after* `library/utils.py` has been imported, the default argument retains the original value (pointing to `idea_1/best_model.pth`) instead of the updated value (`demo_cache/best_model.pth`).

To fix this, I will modify `save_checkpoint` and `load_checkpoint` in `library/utils.py` to use `None` as the default value for `filename`. Inside the function body, I will check if `filename` is `None` and then assign it the current value of `Config.MODEL_CHECKPOINT`. This ensures the configuration value is resolved at runtime (late binding), reflecting any changes made to the `Config` class.
