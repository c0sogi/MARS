# Model: Physics-Augmented Dual-Injection BiLSTM (PADI-BiLSTM)

I propose a structural evolution that synthesizes the **Dual-Path Injection** architecture with **Explicit Inductive Bias**, strictly correcting the data pipeline errors that invalidated previous comparisons.

*   **Physics-Augmented Injection Block (Structural Innovation):**
    *   We will construct the "Injection Payload" (the signal fed to every recurrent layer) using two distinct, parallel paths to satisfy both the "Signal Fidelity" (Cite solution_lesson_node_00018) and "Context Abstraction" (Cite solution_lesson_node_00035) requirements.
    *   **Path A (Explicit Fidelity):** An **Identity** mapping of the raw input features *plus* explicitly engineered physics interaction terms (e.g., $R \cdot u_{in}$, $Vol/C$). Lesson 00076 demonstrated that latent architectural learning cannot replace these explicit inductive biases. This path ensures the deep layers have direct access to the terms of the Equation of Motion.
    *   **Path B (Bottlenecked Context):** A **Wide Monolithic Gated Linear Unit (GLU)** (Cite solution_lesson_node_00059) processes all inputs to capture high-order non-linearities. Crucially, this output is projected down to a **Compressed Bottleneck** (e.g., 64-128 units) before fusion. This retains the regularization benefits of bottlenecking (Cite solution_lesson_node_00045) without compressing the fidelity path (Cite solution_lesson_node_00056).
    *   **Fusion:** Path A and Path B are concatenated. We strictly **exclude Dropout** from this payload to ensure it serves as a stable ground truth (Cite solution_lesson_node_00030).
*   **Wide Deep Recurrent Backbone:**
    *   The core will consist of **4 layers of Bidirectional LSTMs** with **512 hidden units**. We explicitly restore the large model width, as Lesson 00064 proved that feature engineering cannot compensate for the loss of representational capacity.
    *   **Deep Injection:** The "Physics-Augmented Payload" is concatenated to the input of **every** LSTM layer (Cite solution_lesson_node_00021).
    *   **Inter-Layer Connectivity:** We use **Layer Normalization** and **Dropout** *between* LSTM layers (Cite solution_lesson_node_00023) but reject complex inter-layer gating to maintain high gradient flow (Cite solution_lesson_node_00048).

# Data: Segregated Physics-Fidelity Pipeline

We will implement a corrected feature engineering pipeline that addresses the "Silent Peril" of scaling binary flags while strictly enforcing the inclusion of physics-based features.

*   **Segregated Robust Scaling (Critical Correction):**
    *   We will explicitly **segregate** the scaling logic.
    *   **Continuous Features** ($u_{in}$, $R$, $C$, Time, Derivatives, Interactions): Apply **RobustScaler** (Median/IQR) to handle the ~14% outliers in control signals (Cite solution_lesson_node_00044).
    *   **Binary Features** ($u_{out}$): Pass through **Raw** (unscaled).
    *   **Rationale:** Lesson 00062 demonstrated that scaling the binary flag $u_{out}$ inverts the validation logic, leading to deceptive metrics. This correction is mandatory for valid learning.
*   **Explicit Physics Interactions:**
    *   We will explicitly calculate and include the interaction terms: `R * u_in` (Resistive Pressure) and `u_in_cumsum / C` (Elastic Pressure). Lesson 00076 proved that removing these in favor of latent learning degrades performance significantly.
*   **Time-Weighted Integration:**
    *   Calculate volume as `u_in_cumsum = cumsum(u_in * dt)` to correct integration error (Cite solution_lesson_node_00032).
*   **Stable Dynamic Features:**
    *   We will implement **Multi-Step Deltas** ($x_t - x_{t-k}$). We reject "Iterated Finite Differences" (acceleration of acceleration) as they amplify noise (Cite solution_lesson_node_00068) and reject "Future Lags" to prevent overfitting (Cite solution_lesson_node_00055).
*   **Signal Fidelity:**
    *   Treat $R$ and $C$ strictly as **continuous numerical features** (Cite solution_lesson_node_00018).

# Training: Stretched-Horizon Convergence Protocol

*   **Loss Function:** We will use a **Weighted L1 Loss**, assigning a weight of **1.0** to the inspiratory phase and **0.1** to the expiratory phase. This focuses capacity on the metric while maintaining the temporal context required for stable hidden states (Cite solution_lesson_node_00021).
*   **Optimizer:** We will use **AdamW** with a **Cosine Annealing** scheduler.
*   **Stretched Horizon:** We will set the training duration to **200 epochs** and explicitly set the scheduler's `T_max=200`.
    *   Deep recurrent models on this task exhibit "long-tail convergence" (Cite solution_lesson_node_00029) and "spectral bias" (Cite solution_lesson_node_00075).
    *   Stretching the scheduler horizon keeps the learning rate higher for longer, preventing premature convergence to shallow local minima (Cite solution_lesson_node_00043).
