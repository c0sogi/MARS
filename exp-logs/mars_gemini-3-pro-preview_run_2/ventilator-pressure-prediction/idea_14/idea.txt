# Model: Deep Front-Loaded Gated-Injection BiLSTM (DFL-GI-BiLSTM)

I propose a structural evolution that maximizes the "Front-Loaded Complexity" principle identified in Lesson 00048. We will deepen the feature extraction capability of the injection path to capture complex instantaneous aerodynamics *before* temporal processing, while retaining the highly effective deep injection backbone.

*   **Deep Front-Loaded Context Extractor (Structural Innovation):**
    *   Previous best solutions used a shallow `Linear -> GLU` projection to generate the "Physics Context" for injection. This limits the model's ability to learn high-order instantaneous non-linearities (e.g., turbulent flow factors) before the signal enters the LSTM.
    *   I propose replacing the shallow projection with a **Deep Gated Residual MLP** acting as a front-end feature extractor.
    *   **Structure:** The raw input sequence will pass through a stack of 2-3 **Gated Residual Blocks** (Linear $\rightarrow$ LayerNorm $\rightarrow$ GLU $\rightarrow$ Dropout $\rightarrow$ Residual Add) operating on each time step independently.
    *   **Rationale:** This adheres to the lesson of "Front-loading complexity" (Cite solution_lesson_node_00048). By processing the instantaneous signal with a deep non-linear network *upfront*, we provide the LSTM with highly refined, abstract physical features (e.g., "Effective Resistance") rather than just raw signals, reducing the burden on the recurrent layers.
*   **Bottlenecked Dual-Path Injection (Strategic Retention):**
    *   The output of the Deep Front-End will be projected down to a low dimension (e.g., 64-128 units) to create a **Bottlenecked Context** (Cite solution_lesson_node_00045).
    *   This context will be concatenated with the **Identity Path** (raw input features) to form the **Injection Payload**. This ensures deep layers have access to both the abstract "Deep Context" and the precise "Raw Signals" (Cite solution_lesson_node_00039).
    *   **Deterministic Constraint:** We will strictly exclude Dropout from the final bottleneck projection to ensure the injected signal serves as a stable ground truth (Cite solution_lesson_node_00030).
*   **Deep Recurrent Backbone:**
    *   The core remains a **4-layer Bidirectional LSTM**.
    *   **Deep Injection:** The "Injection Payload" is concatenated to the input of **every** LSTM layer (Cite solution_lesson_node_00021).
    *   **Inter-Layer Simplicity:** We explicitly reject complex inter-layer gating (Cite solution_lesson_node_00048) and Output Skip-Connections (Cite solution_lesson_node_00036), using only Layer Normalization and Dropout between LSTM layers to maintain high gradient flow.

# Data: Robust Physics-Fidelity Engineering

We will implement the refined feature engineering pipeline that strictly adheres to the calculus of the physical system and robust statistical principles.

*   **Robust Scaling:**
    *   We will apply **RobustScaler** (Median/IQR) to all continuous inputs. This handles the ~14% outliers in the control signal `u_in` significantly better than Standard Scaling, accelerating convergence (Cite solution_lesson_node_00044).
*   **Time-Weighted Integration:**
    *   We will calculate the time delta `dt` and generate the volume feature as `u_in_cumsum = cumsum(u_in * dt)`. This corrects the integration error of early baselines (Cite solution_lesson_node_00032).
*   **Physics Interaction Terms:**
    *   We will calculate `R * u_in` (Resistive Pressure) and `u_in_cumsum / C` (Elastic Pressure) using the time-weighted volume (Cite solution_lesson_node_00004).
*   **Explicit Dynamics:**
    *   We will augment the input with **Lag features** and **Finite Differences** (1st and 2nd derivatives of `u_in`) (Cite solution_lesson_node_00008).
*   **Signal Fidelity:**
    *   Lung Resistance (`R`) and Compliance (`C`) will be treated strictly as **continuous numerical features**. We reject embeddings (Cite solution_lesson_node_00018) and CNN stems (Cite solution_lesson_node_00017) to preserve ordinal magnitude information.

# Training: Stretched-Horizon Convergence Protocol

*   **Loss Function:** We will use a **Weighted L1 Loss**, assigning a weight of **1.0** to the inspiratory phase and **0.1** to the expiratory phase. This focuses capacity on the metric while maintaining the temporal context required for stable hidden states (Cite solution_lesson_node_00021).
*   **Optimizer:** We will use **AdamW** with a **Cosine Annealing** scheduler.
*   **Stretched Horizon:** We will set the training duration to **200 epochs** and explicitly set the scheduler's `T_max=200`.
    *   Deep recurrent models on this task exhibit "long-tail convergence" (Cite solution_lesson_node_00029).
    *   Stretching the scheduler horizon keeps the learning rate higher for longer, preventing premature convergence to shallow local minima and yielding superior final accuracy (Cite solution_lesson_node_00043).
