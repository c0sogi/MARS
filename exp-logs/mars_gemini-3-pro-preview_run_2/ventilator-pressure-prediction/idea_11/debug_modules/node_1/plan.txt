The `StopIteration` error occurs because `get_dataloaders` uses `Config.BATCH_SIZE` (initially 512) as a default argument, which is evaluated at import time (early binding). When `runfile.py` patches `Config.BATCH_SIZE` to 2 at runtime, the function ignores this update and continues using the stale value of 512. With a mini-dataset of only 4 samples, a batch size of 512 combined with `drop_last=True` results in a DataLoader with zero batches, causing iteration to fail immediately.
