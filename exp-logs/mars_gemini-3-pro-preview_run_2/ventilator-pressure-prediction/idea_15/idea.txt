# Model: Deep Front-Loaded Bottlenecked BiLSTM (DFLB-BiLSTM)

I propose a structural evolution that synthesizes the "Front-Loaded Complexity" principle (Cite solution_lesson_node_00048) with the "Bottlenecked Injection" mechanism (Cite solution_lesson_node_00045). This architecture is designed to extract complex instantaneous physical features *before* temporal processing, while ensuring these features do not overwhelm the raw control signals required for numerical integration.

*   **Front-Loaded Context Extractor (Structural Innovation):**
    *   Instead of a shallow linear projection or a simple GLU, the raw input sequence will first pass through a **Deep Gated Residual MLP** (2-3 blocks of `Linear -> LayerNorm -> GLU -> Dropout -> Residual Add`).
    *   **Rationale:** Lesson 00048 demonstrated that "front-loading" complexity is superior to inter-layer complexity. This deep front-end allows the model to learn high-order non-linear mappings of the instantaneous physics (e.g., turbulent resistance factors) *independently* of the temporal state, providing the LSTM with highly refined abstract features.
*   **Bottlenecked Dual-Path Injection:**
    *   **Path A (Signal Fidelity):** An **Identity** mapping of the raw input features (Flow, R, C, Derivatives). This ensures the deep layers retain access to the exact numerical magnitudes required for the Equation of Motion (Cite solution_lesson_node_00039).
    *   **Path B (Compressed Context):** The output of the Deep Front-End will be projected down to a low-dimensional **Bottleneck** (e.g., 128 units). This prevents the high-level context from "drowning out" the raw signals in Path A (Cite solution_lesson_node_00045).
    *   **Payload:** These two paths are concatenated to form the **Injection Payload**.
*   **Deep Recurrent Backbone:**
    *   The core consists of **4 layers of Bidirectional LSTMs**.
    *   **Deep Injection:** The "Injection Payload" is concatenated to the input of **every** LSTM layer (Cite solution_lesson_node_00021).
    *   **Simple Inter-Layer Connectivity:** We explicitly use only Layer Normalization and Dropout between LSTM layers, rejecting complex inter-layer gating to maintain high gradient flow (Cite solution_lesson_node_00048).
    *   **Head:** A final Dense layer projects the LSTM output to pressure. We reject Output Skip-Connections to force static attributes to interact with the temporal state (Cite solution_lesson_node_00036).

# Data: Robust Physics-Fidelity Engineering

We will implement the refined feature engineering pipeline that strictly adheres to the calculus of the physical system and robust statistical principles.

*   **Robust Scaling:**
    *   We will apply **RobustScaler** (Median/IQR) to all continuous inputs. This handles the ~14% outliers in the control signal `u_in` significantly better than Standard Scaling, accelerating convergence (Cite solution_lesson_node_00044).
*   **Time-Weighted Integration:**
    *   We will calculate the time delta `dt` and generate the volume feature as `u_in_cumsum = cumsum(u_in * dt)`. This corrects the integration error of early baselines (Cite solution_lesson_node_00032).
*   **Physics Interaction Terms:**
    *   We will calculate `R * u_in` (Resistive Pressure) and `u_in_cumsum / C` (Elastic Pressure) using the time-weighted volume (Cite solution_lesson_node_00004).
*   **Explicit Dynamics:**
    *   We will augment the input with **Lag features** and **Finite Differences** (1st and 2nd derivatives of `u_in`) (Cite solution_lesson_node_00008).
*   **Signal Fidelity:**
    *   Lung Resistance (`R`) and Compliance (`C`) will be treated strictly as **continuous numerical features**. We reject embeddings (Cite solution_lesson_node_00018) and CNN stems (Cite solution_lesson_node_00017) to preserve ordinal magnitude information.

# Training: Stretched-Horizon Convergence Protocol

*   **Loss Function:** We will use a **Weighted L1 Loss**, assigning a weight of **1.0** to the inspiratory phase and **0.1** to the expiratory phase. This focuses capacity on the metric while maintaining the temporal context required for stable hidden states (Cite solution_lesson_node_00021).
*   **Optimizer:** We will use **AdamW** with a **Cosine Annealing** scheduler.
*   **Stretched Horizon:** We will set the training duration to **200 epochs** and explicitly set the scheduler's `T_max=200`.
    *   Deep recurrent models on this task exhibit "long-tail convergence" (Cite solution_lesson_node_00029).
    *   Stretching the scheduler horizon keeps the learning rate higher for longer, preventing premature convergence to shallow local minima and yielding superior final accuracy (Cite solution_lesson_node_00043).
