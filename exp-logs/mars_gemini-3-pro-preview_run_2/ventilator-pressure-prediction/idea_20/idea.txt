# Model: Corrected Wide-Context Dual-Path BiLSTM (CWCDP-BiLSTM)

I propose a structural synthesis that combines the high-capacity backbone of the "Dual-Path" architecture with the "Monolithic Context" of the latest iterations, while strictly enforcing the model width requirements and correcting the scaling logic.

*   **Wide Monolithic Context Extractor:**
    *   We will employ a **Wide Monolithic Gated Linear Unit (GLU)** (e.g., 256 units) to process *all* input features simultaneously.
    *   **Rationale:** We explicitly reject feature partitioning (Cite solution_lesson_node_00059) to ensure the model can learn cross-term interactions (e.g., $R \times Flow$) immediately. We also reject aggressive bottlenecking (Cite solution_lesson_node_00056) to preserve the richness of this learned context.
*   **Dual-Path Injection Payload:**
    *   **Path A (Signal Fidelity):** An **Identity** mapping of the raw, segregated input features. This ensures deep layers have access to the exact numerical magnitudes required for physics calculations (Cite solution_lesson_node_00018).
    *   **Path B (Physics Context):** The output of the Wide Monolithic GLU.
    *   **Fusion:** These paths are concatenated to form the Injection Payload. We strictly **exclude Dropout** from this payload to ensure it serves as a stable ground truth (Cite solution_lesson_node_00030).
*   **Wide Deep Recurrent Backbone:**
    *   The core will consist of **4 layers of Bidirectional LSTMs** with **512 hidden units**.
    *   **Restored Capacity:** We explicitly restore the large model width (512), rejecting the reduction to 256 attempted in previous iterations. Lesson 00064 proved that feature engineering cannot compensate for the loss of representational capacity in this high-precision task (Cite solution_lesson_node_00064).
    *   **Deep Injection:** The Injection Payload is concatenated to the input of **every** LSTM layer (Cite solution_lesson_node_00021).
    *   **Inter-Layer Connectivity:** We use **Layer Normalization** and **Dropout** *between* LSTM layers (Cite solution_lesson_node_00023) but reject complex inter-layer gating to maintain high gradient flow (Cite solution_lesson_node_00048).

# Data: Segregated Physics-Fidelity Pipeline

We will implement a corrected feature engineering pipeline that addresses the "Silent Peril" of scaling binary flags and optimizes dynamic feature stability.

*   **Segregated Robust Scaling (Critical Correction):**
    *   We will explicitly **segregate** the scaling logic.
    *   **Continuous Features** ($u_{in}$, $R$, $C$, Time, Derivatives): Apply **RobustScaler** (Median/IQR) to handle the ~14% outliers in control signals (Cite solution_lesson_node_00044).
    *   **Binary Features** ($u_{out}$): Pass through **Raw** (unscaled).
    *   **Rationale:** Lesson 00062 demonstrated that scaling the binary flag $u_{out}$ inverts the validation logic, leading to deceptive metrics. This correction is mandatory for valid learning (Cite solution_lesson_node_00062).
*   **Time-Weighted Integration:**
    *   Calculate volume as `u_in_cumsum = cumsum(u_in * dt)` to correct integration error (Cite solution_lesson_node_00032).
*   **Physics Interaction Terms:**
    *   Calculate `R * u_in` (Resistive Pressure) and `u_in_cumsum / C` (Elastic Pressure) using the time-weighted volume (Cite solution_lesson_node_00004).
*   **Stable Dynamic Features (Multi-Step Deltas):**
    *   Instead of standard finite differences (which can be noisy) or iterated differences (which create impulsive outliers), we will implement **Multi-Step Deltas** ($x_t - x_{t-k}$ for $k \in \{1, 2, 3, 4\}$).
    *   **Rationale:** Lesson 00068 demonstrated that iterated differences act as high-pass filters that destabilize training on non-smooth control signals. Multi-step deltas provide robust velocity/trend information without amplifying quantization noise (Cite solution_lesson_node_00068). We explicitly exclude future lags (Cite solution_lesson_node_00055).
*   **Signal Fidelity:**
    *   Treat $R$ and $C$ strictly as **continuous numerical features** (Cite solution_lesson_node_00018).

# Training: Stretched-Horizon Convergence Protocol

*   **Loss Function:** We will use a **Weighted L1 Loss**, assigning a weight of **1.0** to the inspiratory phase and **0.1** to the expiratory phase. This focuses capacity on the metric while maintaining the temporal context required for stable hidden states (Cite solution_lesson_node_00021).
*   **Optimizer:** We will use **AdamW** with a **Cosine Annealing** scheduler.
*   **Stretched Horizon:** We will set the training duration to **200 epochs** and explicitly set the scheduler's `T_max=200`.
    *   Deep recurrent models on this task exhibit "long-tail convergence" (Cite solution_lesson_node_00029).
    *   Stretching the scheduler horizon keeps the learning rate higher for longer, preventing premature convergence to shallow local minima (Cite solution_lesson_node_00043).
