The implementation strategy follows a robust Hybrid Adversarial Stacking pipeline. 

1.  **Setup & Configuration**: We initialize the environment and override the `Config` to set `EPOCHS=1` for a fast baseline execution.
2.  **Data Preparation**: We load the pre-stratified `train`, `val` (hold-out), and `test` datasets from the metadata directory and apply text cleaning.
3.  **Stratified K-Fold Training**: We iterate through 5 folds of the training data.
    *   **Lexical Branch**: We train a TF-IDF + Ridge Regression model. To efficiently gather predictions for both the hold-out validation set and the test set, we combine them into a single evaluation dataframe for this step.
    *   **Semantic Branch**: We train the DeBERTa-v3-Large model with Adversarial Weight Perturbation (AWP). We save the best checkpoint for each fold and generate predictions for OOF, hold-out, and test sets.
4.  **Meta-Learning**: We stack the OOF predictions from both branches and train a Ridge Regression meta-learner to optimally weight the semantic and lexical signals.
5.  **Threshold Optimization**: We use the Nelder-Mead algorithm to find the optimal decision boundaries on the OOF predictions that maximize the QWK score.
6.  **Validation & Analysis**: We evaluate the full ensemble on the hold-out validation set, compute the final QWK metric, and perform failure analysis by correlating error magnitude with essay length.
7.  **Submission**: If the validation metric exceeds the specified threshold, we generate the final submission file for the test set.
