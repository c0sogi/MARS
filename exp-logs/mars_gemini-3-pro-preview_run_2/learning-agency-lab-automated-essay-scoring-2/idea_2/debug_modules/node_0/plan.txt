The following Python script demonstrates the usage of the provided library files to train and evaluate the essay scoring model.

**Strategy:**
1.  **Configuration Overrides**: To ensure the demonstration runs quickly (under 1 minute) and uses minimal resources, we monkey-patch the `Config` class to use a temporary directory, a very short sequence length (`64`), and a tiny batch size.
2.  **Data Subsetting**: We create small subsets (20 training samples, 10 validation, 10 test) from the original metadata to verify the pipeline without processing the full dataset.
3.  **Component Verification**: We sequentially instantiate and verify the correctness of the utility functions, data loaders, model architecture, and training engine using assertions.
4.  **Full Pipeline Execution**: We run a single training epoch and a validation pass, then simulate the post-processing steps (threshold optimization) and submission generation.
