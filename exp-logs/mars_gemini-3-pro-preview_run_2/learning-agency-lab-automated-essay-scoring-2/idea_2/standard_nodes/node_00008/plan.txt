The issue is caused by enabling gradient checkpointing on the Hugging Face model within a custom training loop without explicitly enabling gradients on the input embeddings. As explained in **debug_lesson_1** ("Explicitly Enable Input Gradients When Using Gradient Checkpointing in Custom Loops"), this breaks the autograd graph during the backward pass because the re-entrant computation cannot be linked to the inputs. To fix this, I will modify `library/modeling.py` to call `self.backbone.enable_input_require_grads()` immediately after enabling gradient checkpointing.
