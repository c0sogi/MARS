The previous implementation failed with a `RuntimeError: Trying to backward through the graph a second time` because the default Gradient Checkpointing implementation in Hugging Face uses `use_reentrant=True`. This legacy mode creates a detached autograd session for the re-computed forward pass, which often conflicts with custom training loops and Mixed Precision (AMP), causing the autograd engine to lose track of the graph state. To fix this, I will explicitly set `use_reentrant=False` when enabling gradient checkpointing, which integrates the checkpointed operations directly into the main autograd graph (Cite debug_lesson_2).
