Based on the lessons learned and the available computational resources (NVIDIA A100 GPU), I propose a structural evolution from the sparse linear baseline to a **Deep Learning Transformer-based Regression** strategy.

# Model
The core architecture will shift from a Sparse N-gram Linear Model to a **Pre-trained Transformer Backbone (e.g., DeBERTa-v3-base)**.
- **Backbone:** We will utilize `microsoft/deberta-v3-base`, which is highly effective for natural language understanding tasks due to its disentangled attention mechanism. This moves beyond the "bag-of-words" limitations of the previous TF-IDF approach to capture deep semantic and syntactic dependencies.
- **Head:** A simple linear regression head will be attached to the model's pooling output (e.g., Mean Pooling of the last hidden state).
- **Objective Design:** The model will output a single scalar value per essay. This strictly adheres to the finding that treating the ordinal score as a continuous variable preserves the relative distance between classes better than multi-class classification **(Cite Lesson 1)**.

# Data
- **Tokenization:** We will use the DeBERTa-v3 tokenizer.
- **Sequence Length:** The EDA revealed essays can reach ~1300 words. To respect the finding that retaining a broader range of textual signals (vocabulary) improves performance **(Cite Lesson 3)**, we will increase the maximum sequence length to **1024 tokens**. This utilizes the A100's memory capacity to prevent the truncation of critical information at the end of longer essays, whereas standard 512-token models would discard this data.
- **Preprocessing:** Text will be cleaned minimally, consistent with the previous successful approach, to preserve original student writing patterns.

# Training
- **Loss Function:** We will minimize **Mean Squared Error (MSE)**. This aligns the neural network's optimization landscape with the regression approach that proved successful in the baseline **(Cite Lesson 1)**.
- **Optimization:** We will use the AdamW optimizer with a linear learning rate decay.
- **Compute Utilization:** The training will be executed on the provided NVIDIA A100 GPU, enabling the processing of the larger 1024-token context window and the heavier transformer backbone within the 24-hour limit.

# Evaluation
- **Inference:** The model will generate continuous scalar predictions for the test set.
- **Post-Processing (Threshold Optimization):** We will explicitly reject standard rounding. Instead, we will apply the **Nelder-Mead optimization** technique to learn the optimal decision boundaries (thresholds) on the validation set that maximize the Quadratic Weighted Kappa. This directly addresses the "regression to the mean" weakness identified in previous iterations and maximizes the metric gain **(Cite Lesson 2, Lesson 4)**.
