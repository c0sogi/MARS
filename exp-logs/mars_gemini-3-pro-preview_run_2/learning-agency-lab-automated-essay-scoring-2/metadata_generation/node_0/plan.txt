The strategy is to read the raw CSV files from the input directory, perform a stratified split on the training data to create a validation set, and then save the resulting datasets as new CSV files in the metadata directory. Since the text data is contained directly within the CSVs and not in external files, the metadata files will contain the full text and labels (where available) to facilitate easy loading by downstream models.

1.  **Setup**: Initialize paths and random state. Create the `./metadata` directory.
2.  **Data Loading**: Read `train.csv` and `test.csv` using pandas.
3.  **Splitting**: Use `train_test_split` with stratification on the `score` column to create an 80/20 train/validation split.
4.  **Saving**: Save the training, validation, and test sets to `./metadata/train.csv`, `./metadata/val.csv`, and `./metadata/test.csv` respectively.
5.  **Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (shape, class distribution).
    *   Verify that the stratification was successful by asserting that the class distribution difference between train and validation sets is negligible.
    *   (Note: Since the dataset consists of text within CSVs and not external file paths, the file path resolution check is not applicable, but the script will verify the integrity of the split).
