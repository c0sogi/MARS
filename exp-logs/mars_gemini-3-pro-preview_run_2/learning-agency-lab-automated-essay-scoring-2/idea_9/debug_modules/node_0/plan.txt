Implementation strategy:
1.  **Configuration & Setup**: Import the `Config` class and override specific parameters (`debug`, `epochs`, `n_folds`, `debug_sample_size`) to ensure the pipeline runs rapidly on a tiny subset of data. Call `Config.setup()` to initialize the directory structure.
2.  **Data Pipeline Verification**: Instantiate the tokenizer and use `load_data` to load a debug subset. Verify the dataset size and structure. Test the `collate_fn` by creating a `DataLoader` and fetching a single batch to ensure tensor shapes are correct.
3.  **Feature Extraction**: Run `extract_linguistic_features` on the loaded dataframe and assert that the resulting feature matrix has the correct dimensions and expected columns.
4.  **Classic Models**: Instantiate and run the `ClassicBranch` (Ridge Regression) for both lexical and morphological features. This will generate OOF (Out-Of-Fold) and test predictions.
5.  **Semantic Model**: Execute `run_semantic_training` to fine-tune the DeBERTa model (for 1 epoch on the debug subset). Then run `predict_semantic_test` to generate test predictions.
    *   *Correction Step*: Due to a slight logic difference in how the provided `models_semantic.py` and `models_classic.py` handle debug subsetting (merging before vs. after subsetting), the semantic OOF predictions will be larger than the classic ones. The script will explicitly truncate the semantic predictions to match the classic branch's size, ensuring the Stacking model receives aligned inputs.
6.  **Stacking & Submission**: Instantiate the `StackingModel`. Train it using the generated upstream predictions. Optimize the decision thresholds using `optimize_thresholds`. Finally, generate predictions on the test set and format the submission dataframe.
