The `RuntimeError: unscale_() has already been called` occurs because `scaler.unscale_(optimizer)` is invoked twice within the same optimization step when AWP is enabled: once inside the `if Config.USE_AWP:` block and again unconditionally before gradient clipping. PyTorch's `GradScaler` strictly enforces that `unscale_` is called exactly once per `step()`. To fix this, I will restructure the logic to call `unscale_` in an `else` block only if AWP (which handles its own unscaling) is not used. Additionally, I will disable reentrant checkpointing in the model initialization to prevent potential graph retention issues during gradient accumulation, as advised in the debug lessons (Cite debug_lesson_4).
