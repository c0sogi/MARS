Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `seed_everything` from the provided library to ensure reproducibility.
2.  **Training Orchestration**: Execute `library.train.run_training()`. This function handles the heavy lifting: loading training data, extracting TF-IDF features, performing hyperparameter tuning (Alpha selection) for Ridge Regression, and saving the trained model.
3.  **Validation & Metric Reporting**:
    *   Although `run_training` performs evaluation, the task requires a specific output format (`Final Validation Metric: <value>`).
    *   I will explicitly reload the validation set and the trained model.
    *   I will generate predictions, round them to integers, and compute the Quadratic Weighted Kappa (QWK) using `library.metrics.compute_qwk`.
    *   I will print the metric in the exact required format.
4.  **Failure Analysis**:
    *   Using the validation predictions, I will calculate the absolute error for each sample.
    *   I will derive a simple interpretable feature—**Word Count**—from the raw text.
    *   I will compute and print the Pearson correlation between the **Absolute Error** and **Word Count** to understand if the model struggles with specific essay lengths (e.g., shorter vs. longer essays).
5.  **Submission Generation**: Execute `library.inference.generate_submission()`. This loads the test set, applies the saved TF-IDF vectorizer, predicts scores using the trained Ridge model, formats the output, and saves `submission.csv`.
