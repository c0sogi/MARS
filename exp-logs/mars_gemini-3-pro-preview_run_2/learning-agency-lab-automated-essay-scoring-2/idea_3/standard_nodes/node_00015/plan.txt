The implementation strategy follows the Hybrid Semantic-Lexical Ensemble idea. To ensure the solution serves as a fast baseline, we override the configuration to run for 1 epoch per fold. The script performs a 5-Fold Cross-Validation on the training set (`train.csv`) to train both the Lexical (Ridge) and Semantic (DeBERTa-Large) models. It collects Out-Of-Fold (OOF) predictions to optimize the ensemble weight ($\alpha$) and decision thresholds. These optimized parameters are then evaluated on the hold-out validation set (`val.csv`) to compute the final metric. If the metric exceeds the specified threshold, predictions for the test set (`test.csv`) are generated and saved.
