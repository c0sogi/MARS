2.  **Data Loading**: Instantiate DataLoaders for training, validation, and testing using `create_dataloaders`. We will use the full dataset (`debug=False`) to maximize performance and aim for the target metric.
3.  **Model Training**: Initialize the `DogCatClassifier` (ConvNeXt-Small) and `ModelEMA`. Train the model for the specified number of epochs using `train_one_epoch`. 4.  **Metric Reporting**: Print the final best validation metric with full precision as required.
5.  **Failure Analysis**: Load the best model and generate predictions on the validation set. Calculate the absolute error for each sample. Iterate through the validation dataset to extract image metadata (width, height, aspect ratio) and compute the Pearson correlation between these features and the error magnitude to identify systematic weaknesses.
6.  **Conditional Submission**: Compare the final validation metric against the strict threshold of `0.018199009307556684`. If the model's performance is superior (lower loss), generate test set predictions using Test-Time Augmentation (`predict_tta`) and save the formatted submission file.
