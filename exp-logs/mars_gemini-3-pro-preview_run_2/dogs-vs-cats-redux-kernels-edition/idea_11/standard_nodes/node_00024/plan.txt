The implementation strategy follows the **Semi-Supervised Heterogeneous Stacking** idea. 

1.  **Configuration**: We override the default configuration to create a "fast baseline" that fits within the 2-hour limit. Specifically, we reduce the number of folds to 2 and epochs to 3. This ensures that the complex multi-stage pipeline (Supervised -> Pseudo-Labeling -> Semi-Supervised -> Stacking) executes fully without timeout.
2.  **Stage 1 (Supervised)**: We train two heterogeneous models (`ConvNeXt-Small` and `Swin-Small`) on the labeled training data using Stratified K-Fold. We generate Out-of-Fold (OOF) predictions and average test predictions.
3.  **Pseudo-Labeling**: We average the test predictions from Stage 1 to create soft pseudo-labels for the test set. These are combined with the original training data to form an expanded dataset.
4.  **Stage 2 (Semi-Supervised)**: We retrain the ensembles from scratch on the combined dataset. We maintain the original validation folds to ensure valid OOF predictions for the meta-learner.
5.  **Stacking**: We use a Logistic Regression meta-learner trained on the Stage 2 OOF predictions to combine the models. This meta-learner is then applied to the test set and the hold-out validation set.
6.  **Validation & Analysis**: We calculate the final Log Loss on the hold-out validation set. We perform failure analysis by correlating prediction residuals with image metadata (width, height, aspect ratio).
7.  **Submission**: A submission file is generated only if the final validation metric is below the specified threshold.
