The following script demonstrates the end-to-end usage of the provided library components to solve the Dog vs. Cat classification task.

**Strategy:**
1.  **Configuration**: We override the `CFG` class attributes to enable `debug` mode (using a small data subset) and reduce training epochs/folds for rapid execution.
2.  **Data Loading**: We verify `get_loaders` and `get_test_loader` from `library.data` to ensure they yield batches of the correct shape and type.
3.  **Modeling**: We instantiate a model using `library.modeling.get_model` (using `convnext_small` as defined in config) and verify its output shape.
4.  **Training Loop**: We execute a short training run using `train_one_epoch` and `valid_one_epoch` from `library.training`. We verify that the loss is a scalar and predictions match the batch size.
5.  **Model Soup**: We simulate the "Model Soup" technique by saving two checkpoints from different training states, averaging them using `library.soup_utils.average_weights`, and verifying that the resulting weights are indeed the arithmetic mean of the inputs.
6.  **Inference**: We run `inference_fn` on the test set and generate a submission file in the required format.
