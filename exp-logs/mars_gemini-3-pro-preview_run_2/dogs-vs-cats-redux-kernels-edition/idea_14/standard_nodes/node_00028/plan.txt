Implementation strategy:
1.  **Configuration Override**: Dynamically modify `Config` parameters to satisfy the "Fast Baseline" and 2-hour runtime constraints while preserving the core "Tri-Modal Soup" strategy. We will set `EPOCHS=5` (instead of 20) and `N_FOLDS=5` to ensure a complete stacking pipeline runs within ~1.5 hours on the A100.
2.  **Pipeline Orchestration**: Implement a nested loop over Folds and Models.
    -   **Training**: Train each of the 3 architectures (ConvNeXt, Swin, EfficientNetV2) on the full dataset.
    -   **Soup Generation**: Average checkpoints from epochs 3, 4, and 5 to create the intra-fold Model Soup.
    -   **Inference**: Perform OOF inference (for stacking) and Test inference (with TTA) using the Soup models.
3.  **Meta-Learning**: Aggregate OOF predictions and train a Logistic Regression meta-learner to optimize ensemble weights.
4.  **Failure Analysis**: Compute the correlation between validation errors and image metadata (width, height, aspect ratio) to identify systematic weaknesses.
5.  **Submission**: Generate the final submission file if the validation metric meets the threshold (or as a fallback for grading).
