The implementation strategy involves orchestrating a 5-fold stratified cross-validation for a heterogeneous ensemble of ConvNeXt-Small and Swin-Small models. To ensure the process completes within the 2-hour limit on the available A100 GPU, the number of training epochs is adjusted to 10. The script iterates through each architecture and fold, training the models using the provided `fit` engine which handles data loading, Mixup augmentation, and checkpoint saving. After training, the script performs a global evaluation on the hold-out validation set by aggregating predictions from all 10 models using Test-Time Augmentation (TTA). It calculates and prints the final Log Loss metric and performs failure analysis by correlating prediction errors with image meta-features. Finally, if the validation metric meets the specified threshold, the script invokes the `run_inference` function to generate the submission file.
