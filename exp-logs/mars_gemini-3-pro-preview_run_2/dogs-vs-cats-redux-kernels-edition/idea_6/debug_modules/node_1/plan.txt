The error arises because the installed version of `albumentations` (v2.0+) has replaced the separate `height` and `width` arguments with a single `size` tuple for transforms like `RandomResizedCrop` and `Resize`. This API change causes a Pydantic validation error when the legacy arguments are used. To fix this, I will update the `get_train_transforms` and `get_valid_transforms` functions in `library/dataset.py` to pass the image dimensions as `size=(img_size, img_size)` Cite debug_lesson_1.
