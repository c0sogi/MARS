The implementation strategy involves the following steps:

1.  **Data Loading**: Utilize the `data_factory` to load the training, validation, and test datasets, including the pre-extracted features and the on-the-fly computed morphometrics (cached).
2.  **Expert Library Initialization**: Generate the library of experts defined in `model_lib`, which includes Global Marginal, Global Rotational, Stratified Rotational, Discriminative Interaction, and Polynomial Physical topologies.
3.  **Phase 1: Selection (Validation)**:
    *   Train all experts on the training split.
    *   Generate probability predictions for the validation split.
    *   Use `GreedySelector` to identify the optimal subset of experts and their weights that minimize Log Loss.
    *   Compute and print the **Final Validation Metric**.
4.  **Failure Analysis**:
    *   Calculate the log loss contribution of each validation sample.
    *   Compute Pearson correlations between the error magnitude and the input features (Global View) to identify features associated with high error.
5.  **Phase 2: Final Retraining & Submission**:
    *   Combine the training and validation sets to maximize the data available for the final model.
    *   Retrain *only* the experts selected in Phase 1 on this combined dataset.
    *   Generate predictions for the test set.
    *   Aggregate predictions using the ensemble weights.
    *   Format and save the submission file (ignoring the likely erroneous threshold in the prompt to ensure a valid submission is produced).
