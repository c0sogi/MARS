1.  **Remove Kernel Branch**: The previous failure analysis and validation score (0.0309) indicate that the Kernel Branch is diluting the performance of the highly effective Linear + Generative ensemble. As per **Cite solution_lesson_node_00009**, adding a "noisier" or less confident model to a high-performing ensemble often degrades Log Loss. The linear models (LR + LDA) alone have previously achieved ~0.0101.
2.  **Refine Logistic Regression**:
    *   I will increase `max_iter` from 2000 to 5000 in `get_linear_branch` to ensure full convergence during hyperparameter tuning, as suggested by **Cite solution_lesson_node_00010**.
    *   I will slightly increase the density of the regularization search grid (`Cs`) from 20 to 30 points. def get_linear_branch(cv=3, random_state=42, max_iter=2000, n_jobs=-1):
    """
    Returns the Discriminative Linear Branch: A Logistic Regression model.

    Configuration:
    - LogisticRegressionCV with L2 regularization.
    - Broad search grid for Cs (1e-2 to 1e4).
    - Optimizes neg_log_loss.
    - Uses 'lbfgs' solver for robust convergence.
    """
    # Broad logarithmic grid for Cs to ensure global optimum is found
    Cs = np.logspace(-2, 4, 20)

    clf = LogisticRegressionCV(
        Cs=Cs,
        cv=cv,
        penalty="l2",
        solver="lbfgs",
        scoring="neg_log_loss",

        max_iter=max_iter,
        random_state=random_state,
        n_jobs=n_jobs,
    )
    return clf

def get_kernel_branch(
    cv=3,
    random_state=42,
    max_iter=2000,
    n_jobs=-1,
    pca_variance=0.95,
    nystroem_components=300,
):
    """
    Returns the Discriminative Kernel Branch: A Nystroem Kernel Logistic Regression pipeline.

    Architecture:
    1. PCA (retaining 95% variance) -> Densifies space, removes noise.
    2. Nystroem (RBF kernel approximation) -> Projects to non-linear manifold.
    3. LogisticRegressionCV -> Robust linear solver on non-linear features.
    """
    # 1. PCA to densify feature space and remove noise

    nystroem = Nystroem(

    )

    # 3. Logistic Regression Classifier (Linear solver on non-linear features)
    # Re-using the robust configuration from the linear branch
    Cs = np.logspace(-2, 4, 20)

        solver="lbfgs",

        max_iter=max_iter,
        random_state=random_state,
        n_jobs=n_jobs,
    )
