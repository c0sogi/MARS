Implementation Strategy:
The implementation follows the "Quadratic-Linear Hybrid Ensemble" strategy. The script is divided into two phases: Validation and Submission.

1.  **Validation Phase**: To compute a strictly valid "Final Validation Metric" and perform failure analysis, we manually load the `train.csv` and `val.csv` from the metadata directory. This ensures no data leakage. We train the three-component ensemble (Logistic Regression, LDA, and Polynomial Logistic Regression) on the training split and evaluate it on the validation split. We then compute the Log Loss and perform failure analysis by correlating sample-wise errors with input features.

2.  **Submission Phase**: We compare the calculated validation metric against the provided threshold (`0.010187299388940634`). If the model performs sufficiently well (metric < threshold), we proceed to the submission step. Here, we utilize the `load_full_dataset` function to load the combined training and validation data (maximizing sample size). We retrain the ensemble on this full dataset, generate predictions for the test set, and save the result to `submission.csv`.

The script utilizes the provided library modules (`data_loader`, `model_factory`, `ensemble_trainer`, `inference`) to ensure modularity and adherence to the specified architecture.
