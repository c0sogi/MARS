The following script demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Data Loading**: Uses `library.data.load_data` to load metadata, extract global features, and compute physical morphometric features from images.
2.  **Expert Training**: Uses `library.experts.build_expert_library` to instantiate various LDA-based models (Marginal, Rotational, Physical) and trains them on the respective feature views.
3.  **Ensemble Selection**: Uses `library.ensemble.GreedySelector` to find the optimal combination of experts based on validation log loss.
4.  **Prediction & Submission**: Generates predictions on the test set using the ensemble and formats the output for submission.
