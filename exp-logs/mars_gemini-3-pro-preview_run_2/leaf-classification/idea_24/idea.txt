Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose the **Regularized Quadratic-Linear Generative Ensemble (RQLGE)**.

This strategy structurally evolves the "Diverse-Covariance" approach (Idea 23) by introducing **Decision Boundary Flexibility** via **Regularized Quadratic Discriminant Analysis (QDA)**. It addresses the limitation of the "Super-Expert" LDA (Lesson 63), which enforces a strict homoscedasticity assumption (shared covariance for all 99 classes). By adding Regularized QDA experts to the library, we allow the ensemble to locally adapt the curvature of decision boundaries for classes with distinct variances, while strictly managing the overfitting risk via **Greedy Forward Selection** (Lesson 56).

# Model
The solution utilizes a **Dynamic Ensemble Selection** architecture. We generate a diverse library of probabilistic experts and use Greedy Forward Selection to mathematically construct the optimal weighted ensemble.

### 1. Expert Library Generation
All experts operate in **double precision (`float64`)** (Cite `solution_lesson_node_00073`) and utilize **PowerTransformer** (Yeo-Johnson) preprocessing (Cite `solution_lesson_node_00070`) to strictly satisfy the normality assumptions.

We instantiate a library of experts spanning three levels of complexity:

*   **Group A: The Linear Anchors (LDA)**
    *   **Algorithms:** **Linear Discriminant Analysis** with:
        *   **Ledoit-Wolf Shrinkage:** The analytical baseline (Cite `solution_lesson_node_00063`).
        *   **OAS Shrinkage:** Oracle Approximating Shrinkage for Gaussian-optimized data.
        *   **Fixed Shrinkage:** A grid of fixed values (`[0.001, 0.01, 0.1, 0.5]`) to capture optima that analytical methods miss (Cite `solution_lesson_node_00081`).
    *   **Role:** Provides robust, low-variance density estimation with linear decision boundaries.

*   **Group B: The Quadratic Innovators (Regularized QDA)**
    *   **Algorithm:** **Quadratic Discriminant Analysis (QDA)** with **Regularization** (`reg_param`).
    *   **Grid:** We instantiate experts with `reg_param` values of `[0.1, 0.5, 0.9]`.
    *   **Rationale:** Standard QDA is impossible ($N < P$). However, **Regularized QDA** allows for class-specific covariance estimates by shrinking them towards the Identity matrix. This introduces **quadratic decision boundaries**, enabling the model to separate classes that have different spreads (heteroscedasticity), which LDA cannot capture. The high regularization ensures stability despite the small sample size.
    *   **Role:** Captures non-linearities in the class manifold without the calibration issues of Kernels (Cite `solution_lesson_node_00061`).

*   **Group C: The Orthogonal Morphometric Experts**
    *   **Input:** Explicit **Morphological Features** (Hu Moments + Scalars) extracted from raw images.
    *   **Algorithm:** **LDA** (Ledoit-Wolf).
    *   **Rationale:** Isolates the invariant physical signal (Cite `solution_lesson_node_00050`) in a separate view to prevent it from being drowned out by histogram features (Cite `solution_lesson_node_00052`).

### 2. Selection Mechanism
*   **Greedy Forward Selection:** We employ the selection strategy from Lesson 56. We iteratively add experts from the library to the ensemble *if and only if* they maximize the improvement in Validation Log Loss. This ensures that if the Quadratic experts are too noisy, they are discarded; if they provide valuable curvature, they are included (Cite `solution_lesson_node_00056`).

# Data
1.  **Feature Engineering (Dual-Source):**
    *   **Source A (Global):** Load the provided 192 features (Margin, Shape, Texture).
    *   **Source B (Morphological):** Load raw binary images. Extract **Hu Moments** (7 invariant descriptors) and **Geometric Scalars** (Aspect Ratio, Solidity, Extent, Eccentricity) using `skimage.measure.regionprops`.
    *   **View Construction:** Create `Global` (Source A), `Morphological` (Source B), and `Combined` (Source A + B) feature matrices.
2.  **Preprocessing:**
    *   **Precision:** Cast all data to `float64` to prevent numerical noise in density calculations (Cite `solution_lesson_node_00073`).
    *   **Gaussianization:** Apply `PowerTransformer(method='yeo-johnson')` to all views. This is critical for maximizing the performance of both LDA and QDA (Cite `solution_lesson_node_00070`).
    *   **Leakage Prevention:** Transformers are fit on the training split and applied to the test split.

# Training
The training procedure rigorously separates the Selection phase from the Final Retraining phase to maximize data utilization (Cite `solution_lesson_node_00010`).

1.  **Phase 1: Selection (Train/Val Split)**
    *   Split training data (80/20).
    *   **Train Library:** Train all experts (LDA variants, QDA variants) on their respective views using the 80% split.
    *   **Generate Predictions:** Compute `float64` probability matrices on the 20% hold-out set.
    *   **Run Selection:** Apply Greedy Forward Selection (with replacement) to determine the optimal subset of experts and their integer weights.

2.  **Phase 2: Final Retraining (Full Data)**
    *   Retrain *only* the selected experts on the **Combined Training + Validation Set**.
    *   Use the exact hyperparameters (e.g., specific `reg_param` or `shrinkage`) identified in Phase 1 to prevent configuration drift (Cite `solution_lesson_node_00028`).

# Evaluation
1.  **Inference:**
    *   Extract Morphological features for the Test set.
    *   Process the test set through the retrained pipelines of the selected experts (applying `PowerTransformer` and `float64` casting).
2.  **Aggregation:**
    *   Compute the final submission probabilities using the **Weighted Average** determined in Phase 1.
    *   This strategy combines the robust linear baseline with the capacity for quadratic boundaries and orthogonal physical signals, strictly controlled by validation performance.
