Here is the implementation strategy and the complete Python script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed using the provided `utils.set_seed` to ensure reproducibility. Define paths for input, metadata, and a working directory for caching intermediate files.
2.  **Data Loading & Feature Engineering**:
    *   Instantiate the `DataFactory` class pointing to the pre-generated metadata.
    *   Use `factory.load_datasets()` to load training, validation, and test data. This automatically handles image processing (extracting morphometric features like Hu Moments) and merges them with the provided tabular features (margin, shape, texture).
    *   Verify the data integrity (dimensions, presence of extracted features) using assertions.
3.  **Data Preparation**:
    *   Encode the target variable (`species`) into integers using `LabelEncoder`.
    *   Extract feature groups (margin, shape, texture, morphometrics) using `factory.get_feature_groups()` to facilitate specific pipeline construction.
4.  **Model Training (Expert Library)**:
    *   Retrieve the library of expert pipelines (MS-DIPGE) using `get_expert_library()`. These pipelines utilize different subsets of features and transformations (PCA, LDA, Polynomials).
    *   Iterate through each expert, fitting it on the training data and generating probability predictions for both validation and test sets.
5.  **Ensemble Optimization**:
    *   Instantiate the `GreedySelector` class.
    *   Fit the selector using the validation predictions to find the optimal combination of experts that minimizes Log Loss.
    *   Verify that weights were assigned to at least one expert.
6.  **Final Prediction & Submission**:
    *   Use the fitted selector to compute weighted average predictions on the test set.
    *   Generate a submission file using `create_submission()` in the required format.
    *   Perform a final check to ensure the submission file is created correctly.
