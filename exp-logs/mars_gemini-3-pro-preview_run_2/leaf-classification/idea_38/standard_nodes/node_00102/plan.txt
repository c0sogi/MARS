The implementation strategy is as follows:

1.  **Setup & Data Loading**: Initialize the environment with a fixed random seed for reproducibility. Load the training, validation, and test datasets using the provided `load_datasets` function, utilizing caching to speed up execution.
2.  **Phase 1 - Expert Validation**: Iterate through the expert library defined in `Config`. For each expert (combination of Preprocessing Basis, Model, and Feature View), train on the training set and generate predictions for the validation set. Cache these predictions to avoid redundant computation.
3.  **Ensemble Selection**: Use the `GreedySelector` to identify the optimal combination of experts that minimizes the validation Log Loss. This step determines the weights for the final ensemble.
4.  **Metric Reporting**: Calculate and print the `Final Validation Metric` with full precision as required.
5.  **Failure Analysis**: specific to the requirements, calculate the per-sample log loss on the validation set. Compute the Pearson correlation between this error magnitude and each of the input features. Print the top 5 features most correlated with model error to identify potential weaknesses.
6.  **Submission Generation**: Check if the validation score meets the submission threshold. If successful, combine the training and validation data to create a full training set. Retrain the selected experts on this full dataset, generate predictions for the test set, aggregate them using the ensemble weights, and save the final `submission.csv`.
