The following script demonstrates the usage of the provided Multi-Resolution Gaussianized Dynamic Ensemble (MRGDE) library. It systematically validates each component: configuration, feature extraction, data loading, preprocessing, model training, ensemble selection, and finally, the full pipeline execution.

The script includes assertions to verify data shapes, types, and logic correctness. It is optimized for speed by relying on the relatively small size of the provided dataset, which allows the full pipeline (including image feature extraction and cross-validation) to execute quickly (typically under 2 minutes).
