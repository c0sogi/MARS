The implementation strategy follows the **Dynamic Multi-View Ensemble Selection (DMVES)** architecture outlined in the idea description. The script `runfile.py` serves as the orchestrator, leveraging the provided library modules to execute the pipeline efficiently.

**Strategy Outline:**
1.  **Initialization:** The script initializes the `PhaseManager` from `library.engine`, which handles data loading and model management. Random seeds are set for reproducibility.
2.  **Data Loading:** It loads the pre-processed feature views (Global, Margin, Shape, Texture) for training, validation, and testing using `load_cached_data=True` to utilize existing artifacts in the `./working` directory.
3.  **Phase A (Expert Selection):**
    *   A pool of 9 expert models (Linear and Non-Linear, Generative and Discriminative) is instantiated via `model_factory`.
    *   These models are trained on the training split.
    *   Predictions are generated on the validation split.
    *   The `GreedyEnsembleSelector` fits on these predictions to identify the optimal subset of models and their weights that minimize Log Loss.
    *   The **Final Validation Metric** is printed to stdout as required.
4.  **Failure Analysis:**
    *   The script calculates the per-sample Log Loss on the validation set using the ensemble's predictions.
    *   It computes the Pearson correlation between the error magnitude and each of the 192 input features.
    *   The top 5 features most correlated with model error are printed to identify systematic weaknesses.
5.  **Conditional Submission:**
    *   The script checks if the validation metric is strictly lower than the threshold `0.00870833951594525`.
    *   **If passed:** It proceeds to Phase B. The selected models are retrained on the combined Training + Validation dataset. Crucially, hyperparameters (like `C` for Logistic Regression) are transferred from Phase A to ensure stability. Predictions are generated on the Test set, aggregated using the ensemble weights, and saved to `./submission/submission.csv`.
    *   **If failed:** Submission generation is skipped, and a message is printed.
