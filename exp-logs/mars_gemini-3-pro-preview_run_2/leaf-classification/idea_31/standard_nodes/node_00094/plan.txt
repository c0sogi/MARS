The implementation strategy follows the Stratified-Covariance Projected-Generative Ensemble (SCPGE) design. 

First, the script initializes the environment and ensures reproducibility. It utilizes the `DataProcessor` to load the dataset, which handles feature extraction, floating-point precision casting, and PowerTransformer preprocessing, returning a dictionary of data views (Global, Macro, Combined) for training, validation, and testing.

Phase 1 focuses on Ensemble Selection. The script instantiates the full library of experts (LDA, PC-QDA, Macro-QDA, GNB) defined in `model_library`. Each expert is trained on its specific view of the training split and generates probability predictions for the validation split. The `GreedySelector` is then employed to identify the optimal subset of experts and their weights that minimize the Multi-class Log Loss on the validation set.

Following selection, the script performs Failure Analysis. It calculates the per-sample log loss on the validation set and computes the Pearson correlation between this error and the macro-morphometric features (e.g., solidity, eccentricity) to identify characteristics associated with misclassification.

Phase 2 handles Final Retraining and Submission. The script combines the training and validation data to form a full training set. It retrains only the selected experts on this full dataset using their specific views. Finally, it generates predictions for the test set, aggregates them using the ensemble weights, and produces the submission CSV file.
