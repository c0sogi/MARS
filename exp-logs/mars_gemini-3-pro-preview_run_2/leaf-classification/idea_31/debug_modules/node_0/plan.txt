The following script demonstrates the complete pipeline using the provided library files. It performs the following steps:

1.  **Data Loading & Processing**: Uses `DataProcessor` to load metadata, extract morphometric features from images (calculating Hu moments and geometric properties), and apply Yeo-Johnson power transformation to normalize the feature space.
2.  **Expert Training**: Instantiates the library of probabilistic experts (LDA, PC-QDA, Macro-QDA, GNB) and trains them on their specific data views (Global, Macro, or Combined).
3.  **Ensemble Optimization**: Uses `GreedySelector` to perform forward selection on the validation set, optimizing the Multi-class Log Loss metric.
4.  **Submission Generation**: Generates predictions on the test set using the optimized ensemble and formats the output into a valid submission file.
