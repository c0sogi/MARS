Implementation of the Iterative-Gaussianized Dynamic Generative Ensemble (IGDGE) pipeline.

This script performs the following steps:
1.  **Data Management**: Loads binary leaf images and extracted features, correcting image polarity and extracting morphometric features (Hu Moments, Geometry) to augment the provided feature set.
2.  **Topological Transformation**: Generates a library of feature sets using two Gaussianization topologies:
    *   **Marginal**: Standard Yeo-Johnson Power Transform.
    *   **Iterative**: Power Transform $\rightarrow$ PCA Rotation $\rightarrow$ Power Transform (to unfold non-Gaussian dependencies).
3.  **Expert Library Training**: Trains a diverse set of Linear Discriminant Analysis (LDA) experts with varying shrinkage parameters (OAS, Fixed) on both Global and Combined feature views.
4.  **Ensemble Selection**: Uses Greedy Forward Selection to identify the optimal subset of experts that minimizes Log Loss on the validation set.
5.  **Failure Analysis**: Analyzes validation errors to identify features most correlated with prediction failure.
6.  **Retraining & Submission**: Retrains the selected expert ensemble on the full dataset (Train + Val) and generates the final submission file.
