The following script demonstrates the end-to-end workflow using the provided library. It covers data loading, training a single probabilistic expert, performing greedy forward selection to build an ensemble, retraining the ensemble on the full dataset, and generating a submission file.

Strategy:
1.  **Data Loading**: Initialize `LeafData` and load train, validation, and test splits. Verify data shapes.
2.  **Single Expert Demo**: Instantiate and train a specific `ProbabilisticExpert` (Global Marginal Linear) to demonstrate individual model usage and validate probability outputs.
3.  **Ensemble Selection**: Define a reduced configuration space (subset of experts) to ensure the demonstration runs quickly. Use `GreedySelector` to find the optimal combination of experts based on validation log loss.
4.  **Final Training & Prediction**: Combine training and validation sets to simulate a production retraining step. Train the `WeightedEnsemble` on this combined data and generate predictions for the test set.
5.  **Submission**: Format and save the predictions using the provided utility function.
