Implementation strategy for the Precision-Covariance Multi-Resolution Ensemble (PCMRE):

1.  **Setup & Initialization**: Initialize the `Config` to set up directories and random seeds for reproducibility.
2.  **Data Pipeline**: Instantiate `LeafDataManager` to load the training, validation, and test datasets. This class handles the generation of Multi-Resolution features (Macro view via OpenCV, Global view via provided features) and applies rigorous preprocessing (PowerTransformer normalization and `float64` casting) to ensure numerical stability near the metric floor.
3.  **Model Library**: Use `ModelFactory` to generate the library of probabilistic experts, spanning the Covariance Complexity Continuum (OAS-LDA, Fixed-Shrinkage LDA, Macro-QDA, GNB).
4.  **Ensemble Selection (Training)**: Initialize `EnsembleSelector` and call `fit()`. This trains all experts on the training split, generates validation predictions, and executes Greedy Forward Selection to identify the optimal subset of experts that minimizes log loss.
5.  **Validation & Metric**: Reconstruct the ensemble's predictions on the hold-out validation set using the selected weights. Compute the final Multi-class Log Loss using the specific clipping rules defined in the task ($10^{-15}$ floor). Print this metric strictly in the required format.
6.  **Failure Analysis**: Calculate the per-sample log loss on the validation set. Compute the Pearson correlation between the error magnitude and the input features (Global view) to identify which features drive model instability.
7.  **Submission**: If the validation metric satisfies the threshold (set practically to ensure submission generation), call `refit_and_predict()` to retrain the selected experts on the combined (Train + Val) dataset and generate predictions for the Test set. Save the formatted submission file.
