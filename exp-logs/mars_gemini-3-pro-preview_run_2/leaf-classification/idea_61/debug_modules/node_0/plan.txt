To demonstrate the usage of the provided library files, I have implemented a self-contained Python script.

### Implementation Strategy
1.  **Environment Setup**: The script initializes the random seeds and ensures the working directory exists using the provided `config` and `utils` modules.
2.  **Data Loading**: It loads the pre-generated metadata files (`train.csv`, `val.csv`) to access the dataset features and labels.
3.  **Feature Extraction**: It demonstrates the `load_image_features` function on a small subset of the validation data to verify image processing (Hu moments, geometric scalars). For the training phase of the pipeline, mock morphometric data is generated to satisfy the "Optimize for Speed" requirement while still exercising the pipeline logic.
4.  **Custom Transformers**: It instantiates and fits the `FactorizedDiscriminantProjector` on the global feature set, verifying that the output dimensionality matches the expected expansion from the interaction synthesis logic.
5.  **Expert Library**: It retrieves the expert pipelines using `get_expert_library` and trains a representative subset (one from each of Groups A, B, and C) on the training data.
6.  **Ensemble Selection**: It utilizes the `GreedySelector` to find the optimal weighting of the trained experts based on their validation performance.
7.  **Submission**: It demonstrates how to format and save predictions using the `save_submission` utility.
8.  **Verification**: Assertions are included throughout to verify data shapes, types, and logical consistency (e.g., the ensemble score should not degrade performance compared to the best single model).
