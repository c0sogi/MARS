### Implementation Strategy

1.  **Environment Setup**: We will import necessary libraries and suppress warnings to keep the output clean. We verify the `Config` setup by checking directory existence.
2.  **Component Verification**:
    *   **Preprocessing**: We instantiate `DualStreamPreprocessor` with dummy data to verify that it correctly splits data into "stream_a" (Parametric) and "stream_b" (Non-Parametric) and enforces `float64` precision.
    *   **Data Loading**: We use `DataLoader` to load Phase 1 (Train/Val) data, explicitly disabling caching (`load_cached_data=False`) to trigger the full processing pipeline and verify the shapes of the generated feature matrices.
    *   **Model Factory**: We generate the library of experts (LDA variants and Logistic Regression) and verify that the factory returns a list of correctly formatted dictionaries.
3.  **Ensemble Optimization (Phase 1)**:
    *   We initialize the `GreedyEnsembleSelector`.
    *   We run the `fit` method on the Phase 1 data. This trains all experts, generates validation predictions, and performs greedy forward selection to find the optimal combination of experts (weights) that minimizes log loss.
4.  **Final Inference (Phase 2)**:
    *   We load the Phase 2 data (Full Train + Test) using `DataLoader`.
    *   We iterate through the experts selected in Phase 1.
    *   We retrain each selected expert on the **Full Training Set** (Train + Val) and generate predictions for the **Test Set**.
    *   We aggregate these predictions using the learned ensemble weights.
5.  **Submission Generation**:
    *   We format the final probabilities and save them to a CSV file using `save_submission`.
    *   We perform a final assertion check on the generated file's dimensions to ensure compliance with the submission format.
