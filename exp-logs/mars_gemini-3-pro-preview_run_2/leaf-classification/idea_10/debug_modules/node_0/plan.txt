### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by suppressing unnecessary warnings and setting a fixed random seed for reproducibility.
2.  **Data Processing**: Utilize `library.data_processing.process_data` to load the dataset. We will use a small `debug_size` (e.g., 100 samples) to ensure the script executes quickly within the time limit. We will assert that the returned data structures (dictionaries of views, label arrays) have the correct shapes and keys.
3.  **Model Training & Evaluation**:
    *   Iterate through the defined feature views (`Global`, `Margin`, `Shape`, `Texture`).
    *   For each view, instantiate both a Logistic Regression model and a Linear Discriminant Analysis (LDA) model using `library.model_factory`.
    *   Train each model using `train_and_evaluate` and capture the cross-validation scores.
4.  **Ensemble Strategy**:
    *   Instantiate the `SelectiveEnsemble` class.
    *   Register each trained model as a candidate.
    *   Run `optimize_selection()` to filter models based on the tolerance threshold relative to the global baseline.
    *   Generate predictions on the test set using the ensemble.
5.  **Submission Generation**: Use `generate_submission` to format the predictions into a CSV file.
6.  **Verification**: Perform final assertions to check that the submission file exists, has the correct dimensions, and contains valid probability values.
