My optimization strategy focuses on simplifying the ensemble to prevent probability dilution and refining the hyperparameter search to capture the optimal regularization strength for the high-signal engineered features.

1.  **Remove Kernel Branch**: I will remove the Nystroem-approximated Kernel Logistic Regression branch. Lesson 00009 warns that ensembling weaker or "noisier" models with strong linear baselines dilutes confidence and degrades Log Loss. The Kernel branch had a training loss (0.011) an order of magnitude higher than the Linear branch (0.0008), making it a source of error.
2.  **Optimize Linear Branch**: I will update `build_linear_branch` to use a dense, broad logarithmic grid `np.logspace(-3, 5, 100)` and increase `max_iter` to 5000. Lesson 00047 and Lesson 00037 emphasize that a dense grid covering weaker regularization (higher C) is critical for achieving the target loss of ~0.0087 on this dataset.
3.  **Refine Ensemble Aggregation**: I will update the ensemble to strictly use Soft Voting between the Discriminative (Logistic Regression) and Generative (LDA) models, as supported by Lesson 00006.

def build_kernel_branch(random_state=42, n_jobs=-1, n_components_nystroem=400):
    """
    Constructs the Discriminative Kernel Branch:
    StandardScaler -> PCA -> Nystroem -> LogisticRegressionCV

    Features:
    - PCA (0.95 variance) for dimensionality control and denoising.
    - Nystroem approximation of RBF kernel for non-linearity.
    - Calibrated Logistic Regression solver at the end.
    """
    # Dense, Broad Logarithmic Grid (100 points)
    Cs = np.logspace(-4, 4, 100)

    # PCA retaining 95% variance
    pca = PCA(n_components=0.95, random_state=random_state)

    # Nystroem approximation
    # n_components set to a reasonable default, can be tuned
    nystroem = Nystroem(
        kernel="rbf",
        n_components=n_components_nystroem,
        random_state=random_state,
        n_jobs=n_jobs,
    )

    clf = LogisticRegressionCV(
        Cs=Cs,
        cv=3,
        scoring="neg_log_loss",
        solver="lbfgs",
        penalty="l2",
        multi_class="multinomial",
        max_iter=2000,
        random_state=random_state,
        n_jobs=n_jobs,
    )

    pipeline = Pipeline(
        [
            ("scaler", StandardScaler()),
            ("pca", pca),
            ("nystroem", nystroem),
            ("classifier", clf),
        ]
    )

    return pipeline
