Implementation of the Gaussianized Metric-Optimized Dynamic Ensemble (GMODE) workflow.
1.  **Data Loading**: Loads pre-Gaussianized data using `library.data_loader`.
2.  **Phase 1 (Selection)**: Trains three experts (LDA, NCA+LR, NCA+LDA) on the training split and generates validation predictions. Uses `GreedySelector` to identify the optimal ensemble subset based on validation Log Loss.
3.  **Validation**: Reports the final validation metric and performs failure analysis by correlating prediction error with feature values.
4.  **Phase 2 (Submission)**: If the validation score meets the strict threshold, retrains the selected experts on the combined dataset (using fixed hyperparameters) and generates the final submission.
