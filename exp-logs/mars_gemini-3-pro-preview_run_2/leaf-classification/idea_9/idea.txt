Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose the **Stacked Kernel-Linear Hybrid Ensemble**.

This strategy structurally evolves the previous "Soft Voting" approaches by introducing **Stacking** to solve the "Ensemble Dilution" problem (Cite `solution_lesson_node_00009`) and deploying a **Nystroem Kernel Logistic Regression** to provide a robust, calibrated non-linear component.

# Model
The solution utilizes a **Stacking Ensemble** composed of two levels. This architecture allows the model to learn the optimal combination of base experts, effectively filtering out "noisy" predictions that previously degraded performance in soft-voting schemes.

**Level 0: Base Learners**
1.  **Discriminative Linear Expert:** A **Logistic Regression** model with L2 regularization.
    *   **Role:** Captures the strong linear separability of the feature space (Cite `solution_lesson_node_00001`).
    *   **Configuration:** Uses `LogisticRegressionCV` with a constrained search grid (Cite `solution_lesson_node_00021`) and explicitly optimizes `neg_log_loss` (Cite `solution_lesson_node_00031`).
2.  **Generative Linear Expert:** A **Linear Discriminant Analysis (LDA)** model with Ledoit-Wolf shrinkage.
    *   **Role:** Provides superior sample efficiency and density estimation in the "Small N, High D" regime (Cite `solution_lesson_node_00006`).
3.  **Discriminative Non-Linear Expert (Innovation):** A **Nystroem Kernel Logistic Regression** pipeline.
    *   **Architecture:** `PCA` $\rightarrow$ `Nystroem` $\rightarrow$ `LogisticRegressionCV`.
    *   **Rationale:** Previous non-linear attempts failed due to poor calibration (SVM, Cite `solution_lesson_node_00009`) or overfitting (Polynomials, Cite `solution_lesson_node_00030`). The **Nystroem** method approximates the RBF kernel map explicitly, transforming the data into a non-linear feature space. By applying **Logistic Regression** on top of these features, we retain the robust, log-loss-optimizing properties of the linear solver while capturing non-linear manifold structures.
    *   **Dimensionality Control:** **PCA** (retaining 95% variance) is applied before Nystroem to densify the feature space and remove noise (Cite `idea_4`).

**Level 1: Meta-Learner**
*   A **Logistic Regression** model with non-negative constraints (or a simple Linear Regression with constraints).
*   **Role:** It takes the Out-of-Fold (OOF) probability predictions from the three base learners and learns the optimal mixing weights to minimize Log Loss. This prevents the "dilution" caused by simple averaging if one model is less confident (Cite `solution_lesson_node_00009`).

# Data
1.  **Feature Selection:** Utilize the **192 extracted features** (Margin, Shape, Texture), bypassing raw images (Cite `solution_lesson_node_00001`).
2.  **Preprocessing:**
    *   **Global Scaling:** Apply `StandardScaler` to all features. Explicitly avoid non-linear transformers like `QuantileTransformer` (Cite `solution_lesson_node_00003`).
    *   **Leakage Prevention:** The Scaler, PCA, and Nystroem transformers must be fit **only** on the training folds during the cross-validation process to generate valid OOF predictions (Cite `solution_lesson_node_00021`).

# Training
The training process uses a rigorous **3-Fold Stratified Cross-Validation** scheme (Cite `solution_lesson_node_00010`) to generate the training data for the Meta-Learner.

1.  **Generate OOF Predictions:**
    *   Split the full training data into 3 folds.
    *   For each fold, train the three base learners (Linear, Generative, Kernel) on the other 2 folds.
    *   Predict probabilities for the hold-out fold.
    *   Concatenate these predictions to form the Level 1 training set ($N \times 3 \times 99$ features).

2.  **Train Meta-Learner:**
    *   Train the Level 1 Logistic Regression on the OOF probabilities to minimize Log Loss.

3.  **Retrain Base Learners:**
    *   Refit all three base learner pipelines on the **full** training dataset (Train + Validation) to maximize information for the final inference (Cite `solution_lesson_node_00010`).

# Evaluation
1.  **Base Inference:** Pass the test set features through the three retrained base pipelines to generate three matrices of probabilities.
2.  **Meta Inference:** Pass these three probability matrices into the trained Meta-Learner to produce the final, calibrated submission probabilities.
