The implementation strategy involves the following steps:

1.  **Setup and Data Loading**: Initialize the environment with a fixed random seed. Load the training, validation, and test datasets using the provided `data_loader` module. This ensures we use the pre-extracted features (Margin, Shape, Texture) as required.

2.  **Ensemble Initialization**: Instantiate the `StackingEnsemble` from the `ensemble_engine`. This class encapsulates the three base experts (Linear, Generative, Kernel) and the meta-learner.

3.  **Meta-Training (Level 1)**:
    *   Generate Out-of-Fold (OOF) predictions on the training set (`X_train`) using 3-fold cross-validation. This creates the input data for the meta-learner.
    *   Train the Meta-Learner on these OOF predictions and the training labels.

4.  **Validation (Hold-Out)**:
    *   Train the base models on the **training set only** (`X_train`). This is crucial to prevent data leakage into the validation set.
    *   Generate predictions on the hold-out validation set (`X_val`) using the ensemble (Base Models $\rightarrow$ Meta-Learner).
    *   Compute the **Multi-class Log Loss** on the validation set. This serves as the "Final Validation Metric".

5.  **Failure Analysis**:
    *   Calculate the log loss contribution for each sample in the validation set.
    *   Compute the Pearson correlation between the per-sample loss and each of the 192 input features. This identifies which features are most associated with model errors.

6.  **Submission Generation**:
    *   Compare the validation metric against the specified threshold.
    *   If the model performs well enough, combine the training and validation sets into a full dataset.
    *   **Retrain** the base models on this full dataset to maximize information for the test set.
    *   Generate predictions for the test set (`X_test`) and save the submission file using the `utils` module.
