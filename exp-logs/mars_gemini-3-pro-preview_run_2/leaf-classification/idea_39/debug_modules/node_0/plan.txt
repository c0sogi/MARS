Here is the outline of the implementation strategy followed by the complete Python script:

1.  **Setup and Initialization**: Import necessary libraries and the provided modules (`config`, `features`, `data`, `preprocessing`, `library`, `ensemble`). Define a fixed random seed for reproducibility.
2.  **Feature Extraction Demonstration**: Manually select a sample image from the training set and run `features.extract_morphometrics` to verify it returns a dictionary with the expected keys (Hu moments, geometric scalars) and valid values.
3.  **Data Loading**: Use `data.get_data` to load the training, validation, and test datasets. Validate the returned structure, ensuring the shapes of Global and Macro feature matrices match the number of samples and expected feature counts. Verify the target labels are correctly encoded.
4.  **Preprocessing Pipeline**: Execute `preprocessing.get_transformed_data` to generate the four feature views (`global_a`, `global_b`, `macro_a`, `macro_b`) using the Dual-Stream Pipeline. Verify that the transformed data contains no NaNs and maintains the correct dimensions.
5.  **Expert Model Training**: Iterate through the expert configurations generated by `library.generate_expert_configs`. For each configuration, instantiate an `LDAExpert`, fit it on the corresponding training view, and generate probabilities for the validation set. Store these predictions.
6.  **Ensemble Selection**: Initialize the `ensemble.GreedySelector`. Fit it using the dictionary of validation predictions to select the optimal combination of experts that minimizes log loss. Verify that experts were selected and weights can be retrieved.
7.  **Final Prediction and Submission**: Use the fitted ensemble to predict probabilities on the test set. Construct a submission DataFrame matching the required format (ID column + species columns) and save it to the specified output path. Perform a final check on the submission file's structure.
