Implementation of the **Spectral-Gaussianized Dynamic Generative Ensemble (SGDGE)** strategy.

The solution orchestrates the following pipeline:
1.  **Expert Selection**: Generates a library of LDA experts across three topologies (Marginal, Spectral, Rank) and two views (Global, Combined). Uses Greedy Forward Selection to identify the optimal ensemble on the validation set.
2.  **Validation**: Computes the exact log loss metric and performs failure analysis to identify feature correlations with error.
3.  **Retraining**: Retrains the selected expert configuration on the full dataset (Training + Validation) to maximize data utilization.
4.  **Inference**: Generates predictions on the test set and creates the submission file.
