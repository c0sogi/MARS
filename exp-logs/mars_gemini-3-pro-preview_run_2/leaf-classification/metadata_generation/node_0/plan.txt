The following script generates the required metadata files for the leaf classification task.

### Implementation Strategy
1.  **Setup & Loading**: The script initializes paths and loads the raw `train.csv` and `test.csv` files from the `./input` directory.
2.  **Metadata Enrichment**: It adds a relative `image_path` column to both datasets by mapping the `id` field to the corresponding filename in the `images/` directory (e.g., `id=123` -> `images/123.jpg`).
3.  **Validation Split**: The training data is split into training (80%) and validation (20%) sets using `train_test_split` with stratification on the `species` column to ensure class balance. A fixed random state (42) is used for reproducibility.
4.  **Saving**: The resulting dataframes are saved as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
5.  **Verification**:
    -   **Summary Statistics**: Prints shapes and sample class distributions.
    -   **File Path Check**: Randomly samples 1000 paths from the generated metadata and verifies they exist in the `./input` directory. Raises an error if >50% are missing.
    -   **Stratification Check**: Verifies that the validation set size is approximately 20% of the original training set and that the class distribution is preserved.
