This script demonstrates the end-to-end usage of the provided library components for the Leaf Classification task. It covers:
1.  **Feature Engineering**: Using `MorphologyExtractor` to generate geometric features from raw images.
2.  **Data Management**: Using `LeafDataManager` to load metadata, compute features, and prepare preprocessed training/validation splits.
3.  **Model Creation**: Using `ExpertFactory` to instantiate LDA and Calibrated Logistic Regression models.
4.  **Ensemble Selection**: Using `GreedyEnsembleSelector` to optimize the combination of expert predictions based on validation log loss.

The script includes assertions to verify data shapes, feature integrity, and prediction formats.
