The strategy implements the **Stratified-Discriminative Precision-Generative Ensemble (SDPGE)**. It orchestrates the workflow by first loading the data splits and constructing a library of expert models (Global LDA, Physical Polynomial LDA, and Stratified Interaction LDA). It then employs a **Greedy Forward Selection** algorithm on the validation set to optimize the ensemble composition, minimizing the Multi-class Log Loss. Following selection, it performs a failure analysis by correlating prediction errors with input features. Finally, it retrains the selected experts on the full training dataset, generates predictions for the test set, and saves the submission file.
