The following script demonstrates the usage of the provided library files. It systematically verifies the functionality of the utility functions, image processing, data loading, custom transformers, model factory, and the ensemble optimizer.

To ensure the demonstration runs quickly while still validating the logic, the script:
1.  Validates the custom log loss metric with known inputs.
2.  Tests image processing on a single sample image.
3.  Loads the dataset using the `data_factory`.
4.  Verifies the `StratifiedDiscriminantProjector` by fitting it on the global feature subset.
5.  Builds the expert model library and runs the `GreedySelector` on a subset of these experts (to save compute time) using the training and validation splits.
