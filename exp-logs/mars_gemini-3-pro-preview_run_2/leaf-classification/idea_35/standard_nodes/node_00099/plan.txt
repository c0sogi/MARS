The `ValueError: Object arrays cannot be loaded when allow_pickle=False` is triggered because the target variable `y` contains string labels (plant species names), which NumPy stores as an object array. When loading this cached file, NumPy's default security setting blocks the operation. To resolve this, I will modify the `np.load` call for `y` in `library/data_loader.py` to explicitly enable `allow_pickle=True`, which is required for loading arrays containing non-numeric data like strings.
