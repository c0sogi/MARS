The objective is to optimize the Leaf Classification solution to surpass the strict validation log loss threshold of `3.3768e-06`. The previous solution's `global_lda` expert achieved `3.37682e-06`, missing the target by a negligible margin.

My strategy involves three key modifications based on the provided lessons:
1.  **Optimize LDA Shrinkage (Cite solution_lesson_node_00047)**: The previous solution used `shrinkage='auto'` (Ledoit-Wolf lemma). While highly effective, it optimizes for covariance estimation (MSE), which may not perfectly align with minimizing Log Loss on this specific dataset. I will introduce a `tuned_lda` expert that uses `GridSearchCV` to search a dense grid of shrinkage values (including 'auto') to find the precise parameter that minimizes Log Loss.
2.  **Remove Ineffective Experts (Cite solution_lesson_node_00064)**: The `denoised_lda` experts (using `SelectKBest`) performed significantly worse than the global model because hard feature selection destroys the multivariate covariance signal required by LDA. These will be removed to streamline the pipeline.
3.  **Refine Logistic Regression (Cite solution_lesson_node_00018, solution_lesson_node_00028)**: The `global_lr` expert will be retained as a backup but optimized. I will reduce the hyperparameter search grid (`Cs`) from 100 to 20 to prevent overfitting on this small dataset. Additionally, I will adopt the "Integrated CV" pattern for the final retraining phase, allowing the estimators (`GridSearchCV` and `LogisticRegressionCV`) to manage their own refitting on the full dataset, ensuring consistency and simplicity.

def build_denoised_lda(k_features, random_state=42):
    """
    Constructs a Denoised Generative Expert pipeline.

    Architecture:
        StandardScaler -> SelectKBest (Mutual Info) -> LinearDiscriminantAnalysis (with shrinkage)

    Args:
        k_features (int): Number of top features to select.
        random_state (int): Seed for mutual information calculation.

    Returns:
        sklearn.pipeline.Pipeline: The constructed pipeline.
    """
    # Fix random_state for mutual_info_classif to ensure reproducible feature selection
    score_func = partial(mutual_info_classif, random_state=random_state)

    pipeline = Pipeline(
        [
            ("scaler", StandardScaler()),
            ("selector", SelectKBest(score_func=score_func, k=k_features)),
            ("lda", LinearDiscriminantAnalysis(solver="lsqr", shrinkage="auto")),
        ]
    )
    return pipeline
