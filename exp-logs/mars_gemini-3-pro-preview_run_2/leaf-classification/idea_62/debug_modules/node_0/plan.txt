To implement the solution, we will create a script that orchestrates the entire machine learning pipeline using the provided library modules.

### Strategy Outline
1.  **Environment Setup**: We will start by setting random seeds using `library.utils.set_seed()` to ensure reproducibility and suppressing unnecessary warnings.
2.  **Data Management**: We will use `library.data_manager.load_data()` to load the training, validation, and test sets. This function handles the complex task of reading metadata, extracting morphometric features from images (and caching them), and combining them with the pre-extracted tabular features.
3.  **Expert Definition**: We will retrieve the dictionary of expert models (pipelines) defined in `library.expert_definitions`. These experts utilize various strategies like Power Transforms, PCA, and Linear Discriminant Analysis (LDA) on different feature subsets.
4.  **Training & Inference**: We will iterate through each expert, fitting them on the training data and generating probability predictions for both the validation and test sets.
5.  **Ensemble Optimization**: Using `library.ensemble_optimizer.greedy_forward_selection`, we will optimize the ensemble weights based on the validation Log Loss. This step selects the best combination of experts.
6.  **Submission Generation**: Finally, we will compute the weighted average of the test predictions using the optimized weights, format the result into a DataFrame matching the sample submission, and save it to `submission/submission.csv`.
