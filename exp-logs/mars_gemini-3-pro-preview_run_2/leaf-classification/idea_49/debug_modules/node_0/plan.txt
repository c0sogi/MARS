The following script demonstrates the end-to-end workflow using the provided library files. It covers data loading (including image feature extraction), model pipeline instantiation, training, greedy ensemble selection, and final submission generation.

The strategy is as follows:
1.  **Data Loading**: Use `data_manager` to load training, validation, and test sets. This implicitly demonstrates `image_features` extraction and caching.
2.  **Model Definition**: Instantiate four distinct LDA-based pipelines (Topologies A, B, C, D) using `pipeline_factory`.
3.  **Training & Validation**: Train these pipelines on the training split and generate probability predictions for the validation set.
4.  **Ensemble Optimization**: Use `ensemble_selection.GreedyEnsemble` to find the optimal weighted combination of these models that minimizes log loss on the validation set.
5.  **Final Inference**: Retrain the relevant models on the full dataset (train + val), predict on the test set, apply the ensemble weights, and generate a submission file.
6.  **Verification**: Assertions are placed throughout to verify data shapes, prediction ranges, and metric calculations.
