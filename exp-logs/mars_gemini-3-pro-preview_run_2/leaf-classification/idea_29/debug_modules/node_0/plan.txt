The following script demonstrates the usage of the provided library modules for the leaf classification task. It follows these steps:

1.  **Setup**: Sets random seeds for reproducibility.
2.  **Feature Extraction**: Demonstrates `library.features.extract_morphometrics` on a single image to verify feature generation.
3.  **Data Management**: Uses `library.data.LeafDataManager` to load, process (merge, scale), and split the dataset into training, validation, and test sets. It verifies the shapes and integrity of the generated matrices.
4.  **Hierarchical Ensemble**: Instantiates and trains the `library.models.HierarchicalEnsemble`. It runs the greedy forward selection process (limited to a few iterations for speed) and generates predictions on the test set.
5.  **Standalone Ensemble Selection**: Demonstrates `library.ensemble.GreedyForwardSelector` independently by training two simple baseline models, generating validation predictions, and optimizing their weights.
