The failure is caused by the use of stale cached data (`processed_data.npz`) that was generated during a previous run where `DEBUG_MODE` was enabled. This resulted in a subsampled dataset (50 rows) being loaded, which contains classes with only 1 sample. The `LinearDiscriminantAnalysis` and `QuadraticDiscriminantAnalysis` models require at least 2 samples per class to estimate covariance, leading to the `ValueError`.

To fix this, I will implement a cache invalidation strategy based on **Debug Lesson 8**. I will modify `library/config.py` and `library/data_handler.py` to append a suffix (`_debug` or `_full`) to the cache filenames based on the `DEBUG_MODE` setting. This ensures that the pipeline distinguishes between debug and full datasets, forcing a data reload/reprocessing when the mode changes.
