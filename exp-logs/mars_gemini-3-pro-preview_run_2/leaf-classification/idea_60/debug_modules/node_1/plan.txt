The `ValueError` arises because the `_instantiate_step` function in `library/expert_pipelines.py` aggressively splits the step name `lda_transform` at the underscore, resulting in a `base_name` of `lda`. The subsequent conditional check incorrectly expects `base_name` to be `lda_transform`, causing a mismatch. This is an instance where brittle parsing logic fails when identifiers contain the delimiter used for parsing (Cite debug_lesson_21). The fix involves updating the conditional statement to check for the extracted base name `lda` instead of the full identifier `lda_transform`.
