The implementation strategy follows the Stratified-Discriminative Factorized-Interaction Ensemble (SDFIE) design. It begins by loading the training and validation datasets and aligning the column names to match the configuration expected by the expert library (e.g., mapping `margin_1` to `margin1`). The script then initializes the library of experts, which includes Global Statistical Anchors, Physical Polynomial Experts, and Factorized-Discriminative Interaction Experts.

In Phase 1, the script runs the `run_selection_phase` which trains all experts on the training split, generates validation predictions, and employs Greedy Forward Selection to identify the optimal ensemble subset that minimizes log loss. The final validation metric is computed and printed, followed by a failure analysis that correlates prediction errors with key feature signals to identify potential weaknesses.

In Phase 2, provided the validation metric is within a reasonable range, the script retrains the selected experts on the combined training and validation dataset to maximize data utilization. It then performs inference on the test set, aggregates the predictions using the ensemble weights determined in Phase 1, and generates the final submission file.
