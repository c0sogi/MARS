Implementation Strategy:
1.  **Setup**: Configure random seeds and paths.
2.  **Data Loading**: Load cached data; compute class priors from training labels.
3.  **Model Definition**: Instantiate the SM-FIPE expert library (Global, Stratified, Interaction, Morphometric pipelines).
4.  **Training (Phase 1)**: Train all experts on the training split and generate validation probabilities.
5.  **Selection**: Apply Greedy Forward Selection to optimize the ensemble weights based on validation Log Loss.
6.  **Validation Reporting**: Print the exact final validation metric and perform failure analysis (correlation of error with features).
7.  **Retraining & Submission (Phase 2)**: If the validation score is within the allowable threshold, retrain the selected experts on the combined dataset, generate test predictions, and save the submission file.
