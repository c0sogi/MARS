Based on the analysis of the provided lessons and the constraints of the task, I propose the **Metric-Augmented Dynamic Generative Ensemble (MADGE)**.

This strategy structurally evolves the "Dynamic Ensemble Selection" (Lesson 56) and "Global LDA" (Lesson 63) concepts. It addresses the potential limitation of pure covariance-based modeling (LDA) by introducing **Neighborhood Components Analysis (NCA)**—a supervised metric learning technique—to explicitly optimize the feature space for class separability before density estimation. This adheres to the "Linear Baselines" rule (Lesson 1) while innovating on the feature representation side to combat the "Curse of Dimensionality" (Lesson 8).

# Model
The solution utilizes a **Dynamic Ensemble Selection** architecture that mathematically selects the optimal subset of experts from a generated pool.

### 1. Expert Pool Generation
We construct a pool of experts that maintain the successful linear inductive bias but operate on different representations of the data.

*   **Expert A: Global Generative Anchor (The Baseline)**
    *   **Architecture:** `StandardScaler` $\rightarrow$ **Linear Discriminant Analysis (LDA)**.
    *   **Configuration:** Uses `solver='lsqr'` with `shrinkage='auto'` (Ledoit-Wolf).
    *   **Role:** Captures the holistic signal from all 192 features using robust covariance estimation, serving as the proven "Super-Expert" (Cite `solution_lesson_node_00063`).

*   **Expert B: Metric-Optimized Generative Expert (The Innovation)**
    *   **Architecture:** `StandardScaler` $\rightarrow$ **Neighborhood Components Analysis (NCA)** $\rightarrow$ **LDA** (with shrinkage).
    *   **Rationale:** While LDA assumes Gaussian distributions, it can be sensitive to the "Curse of Dimensionality" in the original feature space. NCA learns a **linear transformation** that maximizes the stochastic nearest-neighbor probability (a proxy for Softmax/Log Loss). By projecting the 192 features into a lower-dimensional discriminative manifold (e.g., $D=99$, matching the class count) *before* applying LDA, we explicitly align the feature space with the classification objective. This differs from the failed "Kernel" approaches (Lesson 61) which *increased* dimensionality; NCA *focuses* the signal.
    *   **Configuration:** NCA `n_components` set to the number of classes (99) or optimized via internal CV.

*   **Expert C: Discriminative Linear Expert (The Backup)**
    *   **Architecture:** `StandardScaler` $\rightarrow$ **Logistic Regression**.
    *   **Configuration:** Uses `LogisticRegressionCV` with a **Dense Logarithmic Grid** (Cite `solution_lesson_node_00047`) and explicitly optimizes `neg_log_loss` (Cite `solution_lesson_node_00031`).
    *   **Role:** Captures purely discriminative boundaries to complement the generative models.

### 2. Selection Mechanism
*   **Greedy Forward Selection:** We employ the selection strategy from Lesson 56. We iteratively add experts to the ensemble *if and only if* they maximize the improvement in Validation Log Loss. This ensures that if the Global LDA is sufficient, the ensemble converges to it; if the NCA projection reveals better separability, it is incorporated (Cite `solution_lesson_node_00056`).

# Data
1.  **Feature Selection:** Utilize the **192 extracted features** (Margin, Shape, Texture) exclusively. We explicitly reject raw images (Cite `solution_lesson_node_00049`) and coarse geometric scalars (Cite `solution_lesson_node_00052`) to maintain the high signal-to-noise ratio of the provided descriptors.
2.  **Preprocessing:**
    *   **Global Scaling:** Apply `StandardScaler` to all pipelines. Explicitly avoid non-linear transformers like `QuantileTransformer` (Cite `solution_lesson_node_00003`).
    *   **Pipeline Specifics:** The NCA transformation is applied only within Expert B's pipeline to prevent leakage.

# Training
The training procedure rigorously separates the Selection phase from the Final Retraining phase to maximize data utilization (Cite `solution_lesson_node_00010`).

1.  **Phase 1: Selection (Train/Val Split)**
    *   Split the training data (80/20).
    *   Train all experts (Global LDA, NCA-LDA, Logistic Regression) on the 80% split.
    *   Generate probability predictions on the 20% hold-out set.
    *   Run **Greedy Forward Selection** (with replacement) on these predictions to determine the optimal ensemble weights (e.g., $0.6 \times \text{Global LDA} + 0.4 \times \text{NCA-LDA}$).

2.  **Phase 2: Final Retraining (Full Data)**
    *   Retrain *only* the selected experts on the **Combined Training + Validation Set**.
    *   For Logistic Regression, use the exact hyperparameters (`C`) found in Phase 1 to prevent configuration drift (Cite `solution_lesson_node_00028`).

# Evaluation
1.  **Inference:**
    *   Process the test set features through the retrained pipelines of the selected experts.
2.  **Aggregation:**
    *   Compute the final submission probabilities using the **Weighted Average** determined in Phase 1.
    *   This strategy combines the robustness of the Global baseline with the discriminative focus of Metric Learning, strictly controlled by validation performance to prevent dilution (Cite `solution_lesson_node_00009`).
