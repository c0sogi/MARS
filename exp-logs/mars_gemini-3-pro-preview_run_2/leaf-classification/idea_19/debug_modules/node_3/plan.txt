The `ValueError` arises because `LogisticRegressionCV` defaults to `StratifiedKFold` with a hardcoded `cv=5`, but the `DEBUG` mode in `runfile.py` subsamples the dataset to 50 rows, creating classes with only 1 sample. Stratified cross-validation requires the number of splits to be less than or equal to the number of samples in the smallest class. To fix this, I will move the `cv` parameter to the `Config` class (Cite `debug_lesson_1`) and override it in `runfile.py` to use `KFold` with 2 splits. Using standard `KFold` instead of `StratifiedKFold` allows the cross-validation to proceed even with singleton classes caused by aggressive subsampling (Cite `debug_lesson_2`).
