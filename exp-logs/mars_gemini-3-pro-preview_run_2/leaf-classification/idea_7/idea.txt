Based on the lessons learned from previous iterations, I propose the **Hierarchical Taxonomy-Regularized Hybrid Ensemble**. This strategy structurally evolves the previous "Quadratic-Linear Hybrid" (Idea 5) by integrating domain-specific biological constraints (Taxonomy) directly into the probabilistic framework.

### Model
The solution utilizes a **Hierarchical Ensemble** composed of two distinct classification tiers: a **Species-Level Tier** (fine-grained) and a **Genus-Level Tier** (coarse-grained).

1.  **Species-Level Tier (Fine-Grained):** This tier generates the primary probability distribution over the 99 species using a **Soft-Voting Ensemble** of three complementary architectures, preserving the successful components from Idea 5:
    *   **Discriminative Linear Branch:** A **Logistic Regression** model with L2 regularization. This serves as the robust linear baseline (Cite `solution_lesson_node_00001`).
    *   **Generative Linear Branch:** A **Linear Discriminant Analysis (LDA)** model with Ledoit-Wolf shrinkage. This provides superior density estimation and sample efficiency (Cite `solution_lesson_node_00006`).
    *   **Discriminative Quadratic Branch:** A pipeline consisting of **PCA** (dimensionality reduction) $\rightarrow$ **PolynomialFeatures (Degree 2)** $\rightarrow$ **Logistic Regression**. This captures explicit feature interactions (e.g., Shape $\times$ Texture) in a compressed manifold, avoiding the calibration issues of SVMs (Cite `solution_lesson_node_00009`, `solution_lesson_node_00028`).

2.  **Genus-Level Tier (Coarse-Grained Supervisor):**
    *   **Architecture:** A dedicated **Logistic Regression** model trained to predict the **Genus** (e.g., *Acer*, *Quercus*) rather than the Species.
    *   **Rationale:** Classification at the Genus level is a structurally easier task (grouping similar classes) with higher effective sample size per class. This model acts as a "Taxonomic Supervisor" to suppress "impossible" errors where the Species model predicts a plant from the wrong biological family (e.g., predicting an *Acer* species when the features clearly indicate *Quercus*).

### Data
1.  **Feature Selection:** The solution will use the **192 extracted features** (Margin, Shape, Texture), ignoring raw images (Cite `solution_lesson_node_00001`).
2.  **Target Engineering (Innovation):**
    *   **Species Labels:** The standard 99-class target.
    *   **Genus Labels:** A new target vector derived by parsing the genus from the species name (e.g., `Acer_Capillipes` $\rightarrow$ `Acer`). This creates a mapping $M: \text{Species} \rightarrow \text{Genus}$.
3.  **Preprocessing:**
    *   **Global Scaling:** All features will be scaled using **StandardScaler**. We explicitly reject non-linear transformations like `QuantileTransformer` (Cite `solution_lesson_node_00003`).
    *   **No Subsampling:** We will use the full feature set for all models (except the PCA-transformed branch), avoiding the performance degradation caused by feature bagging in this highly separable space (Cite `solution_lesson_node_00027`).

### Training
The models will be trained independently on the **combined Training and Validation sets** to maximize sample utilization (Cite `solution_lesson_node_00010`).

1.  **Logistic Regression Models (Species & Genus):**
    *   **Estimator:** We will use `LogisticRegressionCV` directly for the final model to prevent configuration drift (Cite `solution_lesson_node_00028`).
    *   **Hyperparameters:** We will use the `lbfgs` solver with **L2 Regularization** (Cite `solution_lesson_node_00005`).
    *   **Search Space:** We will manually constrain the regularization grid (`Cs`) to the high-signal regime (e.g., $10^{-2}$ to $10^4$) to prevent "Search Space Dilution" and selection bias (Cite `solution_lesson_node_00021`, `solution_lesson_node_00018`).
2.  **LDA:** Trained with Ledoit-Wolf shrinkage.
3.  **Quadratic Pipeline:** The PCA step will retain 95% variance to ensure the polynomial expansion remains computationally feasible relative to $N$.

### Evaluation
1.  **Inference:**
    *   Generate the Species probability vector $P_{species}$ by averaging the outputs of the Linear, Generative, and Quadratic branches (Soft Voting).
    *   Generate the Genus probability vector $P_{genus}$ using the Supervisor model.
2.  **Taxonomic Bayesian Update:**
    *   Refine the final probabilities by conditioning the Species prediction on the Genus prediction:
        $$P_{final}(S_i) \propto P_{species}(S_i) \times P_{genus}(\text{Genus}(S_i))$$
    *   Renormalize $P_{final}$ to sum to 1. This step effectively penalizes high-confidence errors that violate taxonomic constraints, optimizing the Log Loss metric.
