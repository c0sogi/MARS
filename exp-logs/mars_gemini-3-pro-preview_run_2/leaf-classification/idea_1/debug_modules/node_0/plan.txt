To demonstrate the usage of the provided library files for the Leaf Classification task, I will implement a script that orchestrates the data loading, preprocessing, model training, evaluation, and submission generation processes.

### Implementation Strategy

1.  **Configuration & Setup**: I will import the `Config` class and other necessary components. I will set a random seed for reproducibility.
2.  **Data Loading**: I will instantiate `LeafDataLoader` and load the data. To verify the logic, I will assert the dimensions of the returned datasets (Train, Validation, and Test) against the expected shapes derived from the metadata analysis.
3.  **Preprocessing**: I will use `FeatureScaler` to normalize the feature vectors. I will verify that the scaler correctly standardizes the training data (mean $\approx$ 0, std $\approx$ 1).
4.  **Model Training**: I will instantiate `LogisticBaseline`. To ensure the demonstration runs quickly, I will override the default configuration to reduce `max_iter`. I will then train the model on the scaled training data.
5.  **Evaluation**: I will use the `evaluate_model` function to calculate the Multi-class Log Loss on the validation set and assert that the loss is a valid non-negative number.
6.  **Submission**: I will generate a submission file using `generate_submission` and verify that the output CSV has the correct dimensions (rows matching the test set size and columns matching the number of species + ID).
