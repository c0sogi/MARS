The following script demonstrates the usage of the provided machine learning library for the leaf classification task. It walks through the pipeline from data loading and feature extraction to preprocessing, model training, and ensemble selection.

To ensure the demonstration runs quickly within the time limit while verifying correctness:
1.  **Data Loading**: We verify loading on a small subset of the training data.
2.  **Feature Extraction**: We explicitly test extraction on the validation set (smaller than training) to verify shapes and logic.
3.  **Preprocessing**: We generate a specific data view (`global_marginal`) to verify the transformation pipeline.
4.  **Ensemble Optimization**: We instantiate the `GreedyEnsembleSelector` but drastically reduce the number of candidate experts (from ~10 to 2) before running the selection process. This demonstrates the selection logic without waiting for the full search to complete.
5.  **Validation**: Assertions are placed at every step to confirm data shapes, value ranges, and object states.
