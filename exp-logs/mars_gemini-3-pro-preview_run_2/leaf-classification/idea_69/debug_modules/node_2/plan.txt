The error `AttributeError: 'LDAWrapper' object has no attribute 'classes_'` occurs because the wrapper classes (`LDAWrapper` and `QDAWrapper`) encapsulate the scikit-learn estimators but do not expose the `classes_` attribute, which is generated after fitting and contains the class labels. The `GreedyEnsembleSelector` in `library/ensemble.py` relies on this attribute to correctly map predicted probabilities to species names for the submission file.

To fix this, I will add a `classes_` property to both `LDAWrapper` and `QDAWrapper` in `library/models.py`. This property will delegate access to the `classes_` attribute of the underlying fitted model (`self.model`).
