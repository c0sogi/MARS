The issue is caused by the use of the `lsqr` solver in a `LinearDiscriminantAnalysis` step intended for dimensionality reduction (`transform`). In scikit-learn, the `lsqr` solver does not implement the `transform` method; only `svd` and `eigen` solvers do. While `lsqr` is necessary for the final classifiers to support shrinkage (as defined in `Config.LDA_SOLVER`), the intermediate projection step in `build_topology_c` does not use shrinkage and thus should use the standard `svd` solver to enable subspace projection. I will modify `library/pipeline_factory.py` to explicitly use `solver="svd"` for the `lda_proj` component.
