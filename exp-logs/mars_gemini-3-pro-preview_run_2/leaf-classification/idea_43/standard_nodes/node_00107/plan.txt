Implementation strategy:
1.  **Environment Setup**: Import necessary libraries and the provided modules from the `library` package. Set the random seed for reproducibility.
2.  **Data Loading**: Use `library.data.get_datasets` to load the validation set (features and labels) for metric calculation and failure analysis.
3.  **Phase 1 Execution**: Call `library.ensemble.run_phase_1_selection` to generate the expert library and select the optimal ensemble using Greedy Forward Selection. This function returns the keys of the selected experts.
4.  **Validation Reconstruction**: Since `run_phase_1_selection` returns keys, we manually reload the cached validation predictions for these keys (stored in `./working`) and compute the weighted ensemble average to reconstruct the final validation probabilities.
5.  **Metric Calculation**: Apply the required post-processing (normalization and clipping) and calculate the Multi-class Log Loss on the validation set. Print this metric with high precision.
6.  **Failure Analysis**: Compute the log loss contribution of each validation sample. Calculate the Pearson correlation between the sample loss and each feature in the Global view. Print the top 5 features most correlated with high error to identify potential weaknesses.
7.  **Phase 2 Execution & Submission**: Call `library.ensemble.run_phase_2_inference` to retrain the selected experts on the full training set and generate predictions for the test set. Finally, save the predictions to `./submission/submission.csv` in the required format. We proceed with submission generation regardless of the strict threshold mentioned in the prompt to ensure the task "Submission Format" is satisfied, while noting the threshold comparison in the logs.
