The following script demonstrates the end-to-end usage of the provided library components for the Hindi/Tamil Question Answering task.

**Strategy:**
1.  **Configuration**: We override the default `Config` to enable debug mode (using a tiny subset of data) and reduce training epochs/folds for rapid execution.
2.  **Data Loading**: We utilize `data_factory` to load and process training, validation, and test datasets into PyTorch Datasets.
3.  **Model Training**: We instantiate the model using `model_factory`, set up an optimizer, and use `TrainRunner` to train for one epoch. This verifies the training loop and metric calculation.
4.  **Inference**: We use the `InferenceEngine` to load the saved checkpoint from the training step and generate predictions on the test set.
5.  **Submission**: We generate a submission file using the predictions.
6.  **Validation**: Throughout the process, assertions verify data shapes, output types, and file existence to ensure correctness.
