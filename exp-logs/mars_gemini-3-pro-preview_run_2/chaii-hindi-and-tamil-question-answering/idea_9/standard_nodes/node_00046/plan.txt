To optimize the performance of the Question Answering model, I will implement a strategy based on the empirical lessons learned from previous experiments. The previous solution (Idea 9) suffered from performance regression due to the use of Weighted Layer Pooling and Layer-wise Learning Rate Decay (LLRD). I will revert to the simpler, more effective architecture and optimization scheme that achieved the highest historical score.

**Optimization Strategy:**

1.  **Architecture Simplification**: I will remove the `WeightedLayerPooling` mechanism and instead use the `last_hidden_state` of the XLM-RoBERTa model directly for the prediction heads. Empirical evidence suggests that pooling lower layers can dilute the precise boundary signals required for extractive QA (Cite {solution_lesson_node_00043}).
2.  **Differential Learning Rates**: I will replace the complex LLRD schedule with a simple Differential Learning Rate strategy. I will assign a lower learning rate (`1e-5`) to the pre-trained backbone to preserve its features and a higher learning rate (`3e-5`) to the randomly initialized heads to accelerate their convergence (Cite {solution_lesson_node_00045}).
3.  **Strict Weight Decay Exclusion**: I will ensure that bias terms and LayerNorm weights are explicitly excluded from weight decay in the optimizer groups to improve generalization (Cite {solution_lesson_node_00035}).
4.  **Configuration Update**: I will update the working directory to `idea_10` and adjust the hyperparameters in `config.py` to reflect these changes.

class WeightedLayerPooling(nn.Module):
    """
    Computes a learnable weighted average of the last N transformer layers.
    """

    def __init__(self, num_hidden_layers):
        super(WeightedLayerPooling, self).__init__()
        self.num_hidden_layers = num_hidden_layers
        # Initialize weights to be equal (logits for softmax)
        self.weights = nn.Parameter(torch.ones(num_hidden_layers))

    def forward(self, all_hidden_states):
        """
        Args:
            all_hidden_states: Tuple of tensors from the backbone.
                               Usually (embeddings, layer_1, ..., layer_N).
        Returns:
            weighted_output: Tensor of shape (batch, seq_len, hidden_size)
        """
        # Select the last N layers
        # We assume all_hidden_states contains at least num_hidden_layers
        if len(all_hidden_states) < self.num_hidden_layers:
            selected_layers = all_hidden_states
        else:
            selected_layers = all_hidden_states[-self.num_hidden_layers :]

        # Stack layers: (batch, seq_len, hidden_size, num_selected_layers)
        stacked_layers = torch.stack(selected_layers, dim=-1)

        # Compute softmax weights: (num_selected_layers)
        softmax_weights = torch.nn.functional.softmax(self.weights, dim=0)

        # Reshape weights for broadcasting: (1, 1, 1, num_selected_layers)
        softmax_weights = softmax_weights.view(1, 1, 1, -1)

        # Weighted sum: (batch, seq_len, hidden_size)
        weighted_output = (stacked_layers * softmax_weights).sum(dim=-1)

        return weighted_output

def get_optimizer_grouped_parameters(model, learning_rate, weight_decay, llrd_decay):
    """
    Sets up layer-wise learning rate decay and weight decay exclusion.
    """
    no_decay = ["bias", "LayerNorm.weight"]
    optimizer_grouped_parameters = []

    # 1. Heads (Pooler, QA, Answerability)
    # These parameters are initialized from scratch or fine-tuned heavily
    head_params = (
        list(model.pooler.named_parameters())
        + list(model.qa_outputs.named_parameters())
        + list(model.answerability_classifier.named_parameters())
    )

    optimizer_grouped_parameters.append(
        {
            "params": [

            "weight_decay": weight_decay,
            "lr": learning_rate,
