Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Initialization**: Initialize the environment using `Config.setup()` and ensure reproducibility with `set_seed()`.
2.  **Model Training**: Execute the training pipeline using `library.engine.run_training()`. This handles data loading, model fine-tuning (DistilBERT), and saving the best model based on the Jaccard score. We use the full provided dataset (which is already a subsampled version suitable for a fast baseline) by setting `debug=False`.
3.  **Validation & Failure Analysis**:
    *   Load the best saved model and the validation dataset.
    *   Perform inference to generate predictions on the validation set.
    *   Compute the **Word-level Jaccard score** for each sample.
    *   Print the required `Final Validation Metric: <value>`.
    *   Calculate the correlation between the error magnitude ($1 - \text{Jaccard}$) and input features (Context Length, Question Length) to identify failure modes.
4.  **Submission Generation**: Use `library.engine.generate_submission()` to predict answers for the test set and save the formatted `submission.csv`.
