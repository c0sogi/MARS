The strategy involves upgrading the model backbone from `xlm-roberta-base` to `xlm-roberta-large` to leverage its superior capacity for multilingual understanding, building on the finding that high-capacity backbones outperform distilled ones (Cite solution_lesson_node_00028). To accommodate the larger model within the GPU memory constraints while maintaining training stability, the batch size is reduced to 8 with gradient accumulation steps set to 2 (maintaining an effective batch size of 16), the learning rate is slightly lowered to 1.5e-5, and the number of epochs is increased to 6. The submission threshold is updated to the previous best validation score.
