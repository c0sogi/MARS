The implementation strategy follows a robust cross-validation approach using XLM-RoBERTa to address the multilingual Question Answering task.

1.  **Setup & Data Loading**: The script initializes by setting random seeds for reproducibility. It loads the pre-processed features (using cached data if available) and the raw metadata CSVs. The raw metadata is essential for mapping predictions back to the original text and for evaluating against the ground truth.
2.  **K-Fold Training**: A Group K-Fold Cross-Validation loop (K=3) is executed. In each fold, the model is trained for 5 epochs using the AdamW optimizer and a linear scheduler. The best model state for each fold is saved based on validation loss.
3.  **OOF Predictions**: During the training loop, Out-Of-Fold (OOF) predictions are generated for the validation samples of each fold. These are aggregated to form a complete set of predictions for the training dataset.
4.  **Evaluation**: The script isolates the predictions corresponding to the hold-out validation set (`metadata/val.csv`). It computes the Word-level Jaccard score, which is the primary metric.
5.  **Failure Analysis**: A correlation analysis is performed to determine the relationship between the prediction error (1 - Jaccard) and the lengths of the context, question, and answer. This helps identify if the model struggles with longer sequences.
6.  **Ensemble Inference**: If the final validation metric exceeds the strict threshold of `0.2522202380952381`, the script proceeds to generate a submission. It loads all K trained models, performs inference on the test set, averages the logits (ensemble), and post-processes the results to produce the final `submission.csv`.
