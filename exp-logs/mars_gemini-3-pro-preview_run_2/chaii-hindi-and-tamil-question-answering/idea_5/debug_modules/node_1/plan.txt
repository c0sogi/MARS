The issue is caused by using `functools.partial` to monkey-patch `tqdm.__init__`. `partial` objects do not implement the descriptor protocol, meaning they do not automatically bind `self` to the instance when accessed as a method. As a result, the first argument passed to the constructor (the `DataLoader`) is incorrectly interpreted as `self`, leading to an `AttributeError` when the code attempts to access `tqdm` attributes on the `DataLoader`. To fix this, I will replace the `partial` usage with a wrapper function that explicitly accepts `self`, sets the `disable` keyword argument, and calls the original `__init__` method.
