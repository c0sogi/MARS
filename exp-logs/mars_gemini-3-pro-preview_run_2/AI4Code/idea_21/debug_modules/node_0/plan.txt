The following script demonstrates the complete pipeline for the Notebook Cell Ordering task using the provided library files.

**Implementation Strategy:**
1.  **Configuration & Setup**: We monkeypatch the `Config` class to point to a new working directory (`./working/demo_run`) and reduce hyperparameters (e.g., `n_estimators`, `max_features`) to ensure the demo runs quickly (under 5 minutes).
2.  **Data Subsampling**: We load the original metadata and create small subsamples (200 train, 50 val, 50 test) to simulate the workflow without processing the entire 140k dataset.
3.  **Data Loading**: We use `DataManager` to parse the JSON notebooks defined in our subsampled metadata into flat DataFrames.
4.  **Feature Engineering**:
    *   **Vectorization**: We use `DualVectorizer` to create sparse TF-IDF and dense SVD representations of the cell source text.
    *   **Anchors**: We use `AnchorExtractor` to compute features based on the similarity between markdown cells and code cells (anchors) within the same notebook.
5.  **Modeling**:
    *   **Stage 1**: We use `RidgeStacker` on the TF-IDF features to generate a baseline "lexical" rank prediction. We generate OOF predictions for training and standard predictions for validation/test.
    *   **Stage 2**: We combine the Anchor features and Stage 1 predictions into a tabular dataset. We train `LGBMRanker` to predict the final normalized rank.
6.  **Inference & Evaluation**: We predict ranks for the test set, convert them to cell orders, and generate a submission file. We also calculate the Kendall Tau metric on the validation set to verify the pipeline's effectiveness.
