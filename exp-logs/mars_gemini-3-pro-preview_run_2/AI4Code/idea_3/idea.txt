Based on the "Lessons" learned, particularly the effectiveness of the **Anchor-Based Regression** formulation (Cite solution_lesson_node_00001) and the necessity of using the **Full Dataset** (Cite solution_lesson_node_00002), I propose a structural evolution that combines the efficiency of the linear baseline with the semantic power of deep learning.

# Model
I propose a **Hybrid Sparse-Dense Anchor Ranking** system. This architecture ensembles two distinct regression streams to predict the normalized rank of a markdown cell:
1.  **Sparse Lexical Stream (The "Exploitation" Branch):** This preserves the highly effective **Ridge Regression** model from the lessons. It utilizes a **TF-IDF** vectorizer with **Bigrams** and **Logarithmic Term Frequency Scaling** (Cite solution_lesson_node_00004) to capture exact keyword matches and local structural cues (e.g., "import pandas" vs. "submission.csv").
2.  **Dense Semantic Stream (The "Innovation" Branch):** A lightweight **Transformer Regressor** (e.g., `distilroberta-base` or `microsoft/codebert-base`) is introduced to capture high-level semantic intent that n-grams miss (e.g., understanding that a paragraph discussing "hyperparameter tuning" likely appears in the middle of a notebook, regardless of specific keywords). The Transformer outputs a dense embedding for the markdown text, which is projected to a scalar rank $y \in [0, 1]$ via a linear head.

The final prediction is a weighted average of the scalar ranks produced by both streams.

# Data
**Preprocessing for Training:**
1.  **Target Generation:** For every markdown cell in the **Full Training Dataset** (Cite solution_lesson_node_00002), calculate the **Normalized Rank** $y = \frac{\text{rank}}{\text{total\_cells}}$ relative to the ground truth order.
2.  **Text Processing:**
    -   For the **Sparse Stream**, tokenize the text into unigrams and bigrams, building a vocabulary of ~60,000 terms. Do **not** strip accents or perform aggressive normalization (Cite solution_lesson_node_00005).
    -   For the **Dense Stream**, tokenize the raw markdown content using the pre-trained Transformer's tokenizer, truncating to a standard length (e.g., 512 tokens).
3.  **Dataset Construction:** Create a unified training set of (Markdown Text, Normalized Rank) pairs. Code cells are excluded from the input but are used to define the "skeleton" structure for the target ranks.

**Preprocessing for Evaluation:**
1.  Process test markdown cells identically to the training data (Raw Text -> TF-IDF Vector / Token IDs).
2.  Extract the sequence of **Code Cell IDs** for each test notebook to serve as the fixed anchor points.

# Training
1.  **Sparse Stream Training:** Train the Ridge Regression model on the full dataset using a closed-form or iterative solver (e.g., LSQR). This is computationally cheap and provides a strong baseline.
2.  **Dense Stream Training:** Fine-tune the Transformer backbone on the full dataset using **Mean Squared Error (MSE)** loss.
    -   **Optimization:** Use the AdamW optimizer with a linear learning rate decay.
    -   **Efficiency:** Utilize Mixed Precision (FP16) training to fit the 1.5M samples within the 24-hour budget (approx. 1-2 epochs).
3.  **Independence:** The two streams are trained independently to maximize diversity in their error profiles.

# Evaluation
1.  **Hybrid Prediction:** For each markdown cell in a test notebook, generate two rank predictions: $r_{sparse}$ and $r_{dense}$. Compute the final predicted rank $r_{final} = \alpha \cdot r_{sparse} + (1-\alpha) \cdot r_{dense}$ (where $\alpha$ is a hyperparameter, e.g., 0.5).
2.  **Anchor-Based Sorting:**
    -   Assign fixed, equidistant ranks to the notebook's code cells (e.g., $0.0, \dots, 1.0$) to form the structural skeleton (Cite solution_lesson_node_00001).
    -   Combine the code cells (with fixed ranks) and markdown cells (with predicted $r_{final}$) into a single list.
    -   Sort the combined list by rank to produce the final `cell_order`.
