The following script demonstrates the usage of the provided library modules to solve the notebook cell ordering task. It performs the following steps:

1.  **Configuration Override**: Monkey-patches the `config` module to use a temporary working directory and reduced hyperparameters (e.g., fewer SVD components, fewer trees) for rapid execution.
2.  **Data Subsetting**: Creates a small subset of the training, validation, and test metadata (20 notebooks each) to ensure the pipeline runs quickly.
3.  **Component Verification**:
    *   **Metric**: Verifies the Kendall Tau implementation with a known case.
    *   **Data Loading**: Loads the subsetted data using `data_factory`.
    *   **Feature Engineering**: Generates TF-IDF and SVD features using `feature_engine`.
    *   **Modeling**: Trains the Ridge (Stage 1) and LightGBM (Stage 2) models using `training_pipeline`.
    *   **Inference**: Generates predictions and a submission file using `inference_pipeline`.
4.  **Validation**: Asserts that outputs (DataFrames, files) exist and have the correct shapes/formats.
