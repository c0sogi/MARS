The following script demonstrates the usage of the provided library modules to solve the AI4Code notebook ordering task. It performs the following steps:
1.  **Configuration**: Sets random seeds for reproducibility.
2.  **Data Loading**: Demonstrates how to load regression data (Markdown text -> Rank) and inference data (Notebook structure) using `library.data_loader`, verifying the data structures.
3.  **Model Training**: Instantiates and trains the `RankPredictor` (TF-IDF + Ridge Regression) on a small subset of the training data.
4.  **Prediction Logic**: Validates the `predict_notebook_order` function, ensuring it correctly merges code cells (fixed order) and markdown cells (predicted order) into a valid permutation.
5.  **Metric Calculation**: Verifies the Kendall Tau implementation with known edge cases (perfect match vs. reverse order).
6.  **Full Pipeline**: Executes the end-to-end `run_inference` function with limited samples to generate a submission file quickly.
