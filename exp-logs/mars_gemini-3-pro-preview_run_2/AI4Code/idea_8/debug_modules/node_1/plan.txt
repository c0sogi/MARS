The issue is that the `DataLoader` class modifies the cache filenames when running in debug mode (prepending `debug_` to avoid polluting the main cache), but the verification assertions in `runfile.py` check for the original, unmodified filenames defined in `Config`. This causes a `FileNotFoundError` (wrapped in an `AssertionError`) even though the pipeline successfully generated the debug versions of the files.

To fix this, I will update the assertion logic in `runfile.py` to check for the debug-prefixed filenames, consistent with how `DataLoader` operates when `debug=True` is passed.
