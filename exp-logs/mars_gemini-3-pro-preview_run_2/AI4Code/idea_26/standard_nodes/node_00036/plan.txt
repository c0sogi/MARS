Implementation strategy:
1.  **Configuration & Setup**: Import necessary modules and override the `Config` parameters to ensure the pipeline runs quickly within the time limit. Specifically, reduce the number of LightGBM estimators and enable early stopping.
2.  **Training**: Instantiate and run the `TrainPipeline`. This will process the data, extract features (TF-IDF, SVD, Neighborhoods), train the Stage 1 Ridge model, and train the Stage 2 LightGBM model.
3.  **Validation & Metric Calculation**:
    *   Load the validation dataset and sort it by `id` to ensure alignment with the feature extraction pipeline (which processes data group-wise).
    *   Load the trained models and cached features.
    *   Generate predictions for the validation set using the two-stage approach.
    *   Reconstruct the cell order for each notebook based on predicted ranks.
    *   Compute the Kendall Tau correlation using the provided utility function and the ground truth from metadata.
    *   Print the final validation metric in the required format.
4.  **Failure Analysis**:
    *   Calculate the absolute error between predicted ranks and ground truth ranks.
    *   Compute Pearson correlations between the error and various features (e.g., similarity scores, notebook length) to identify error sources.
    *   Print the top correlated features.
5.  **Submission**:
    *   Compare the validation metric against the specified threshold.
    *   If the threshold is met, instantiate the `InferencePipeline` and generate the submission file for the test set.
