The following script demonstrates the usage of the provided library modules for the AI4Code notebook sorting task. It follows a step-by-step approach:

1.  **Metric Verification**: Validates the Kendall Tau implementation with a known toy example.
2.  **Data Loading**: Demonstrates loading a small subset of training data using `debug_n`.
3.  **Vectorization**: Shows how to fit the TF-IDF and SVD models on the loaded text data.
4.  **Stage 1 (Ridge)**: Trains the coarse ranker and generates Out-Of-Fold predictions.
5.  **Feature Extraction**: Generates neighborhood features (lexical and latent similarities) for the Stage 2 model.
6.  **Stage 2 (LightGBM)**: Assembles the final feature set and trains the refinement model.
7.  **Full Pipeline**: Executes the encapsulated `train_pipeline` and `inference_pipeline` functions to simulate a complete run and generate a submission file.
