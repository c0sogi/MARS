Based on the comprehensive analysis of the "Lessons" learned—specifically the necessity of **Decoupling Retrieval Spaces** (Cite solution_lesson_node_00035), the superiority of **Instance-Based** signals over prototypes (Cite solution_lesson_node_00024), the robustness of **Neighborhood Smoothing** (Cite solution_lesson_node_00015), and the critical need for **Explicit Similarity Scores** (Cite solution_lesson_node_00034)—I propose a **Stacked Hybrid Ranking with Decoupled Multi-Resolution Neighborhoods**.

This solution structurally evolves the "Stacked Hybrid" architecture by resolving the conflict between "Lexical Precision" and "Semantic Recall." Instead of conflating these into a single anchor or relying on a single view, this approach explicitly **decouples** the retrieval process into two independent vector spaces. It then feeds the Gradient Booster a structured view of the notebook that includes specific instances, smoothed aggregates, and—crucially—**Cross-View Interaction Features** that allow the model to arbitrate between conflicting signals (e.g., when the Lexical view disagrees with the Latent view).

# Model

The architecture is a **Two-Stage Stacked Regression Pipeline** designed to arbitrate between global structural priors and local multi-resolution alignment cues.

1.  **Stage 1: Sparse Lexical Regressor (The "Signpost" Model)**
    *   **Component:** A **Ridge Regression** model.
    *   **Role:** Explicitly preserved from the lessons to serve as the robust, high-bias baseline. It maps explicit "signpost" keywords (e.g., "Introduction", "Submission") directly to normalized ranks using high-dimensional sparse features (Cite solution_lesson_node_00001, solution_lesson_node_00010).
    *   **Input:** High-dimensional **TF-IDF** vectors (Unigrams + Bigrams).

2.  **Stage 2: Decoupled Multi-Resolution Gradient Booster (The "Refinement" Model)**
    *   **Component:** A **LightGBM Regressor**.
    *   **Role:** Refines the linear prediction by integrating non-linear interactions and **Decoupled Anchoring**. It consumes signals from two independent retrieval resolutions and explicitly models their agreement/disagreement.
    *   **Input Features:**
        *   **Ridge Prediction:** The output from Stage 1 (Cite solution_lesson_node_00011).
        *   **Resolution A: Lexical Neighborhood (Precision View):** Derived from Sparse TF-IDF similarity. Captures exact keyword matches (e.g., `plt.plot` $\leftrightarrow$ "plot").
            *   **Instance Features:** The **Rank** and **Similarity Score** of the **1st and 2nd Nearest Neighbors**. This respects the insight that specific instances provide higher fidelity than clusters (Cite solution_lesson_node_00024) and ensures the model has the confidence gate required to trust the anchor (Cite solution_lesson_node_00034).
            *   **Smoothed Features:** The **Mean Rank** and **Standard Deviation** of the **Top-K** (e.g., K=10) neighbors. This provides robustness against spurious matches (Cite solution_lesson_node_00015).
        *   **Resolution B: Latent Neighborhood (Recall View):** Derived from **Truncated SVD** similarity. Captures conceptual alignment (e.g., `StandardScaler` $\leftrightarrow$ "Preprocessing") efficiently on the full dataset (Cite solution_lesson_node_00013, solution_lesson_node_00035).
            *   **Instance Features:** Rank and Similarity of the 1st and 2nd neighbors in SVD space.
            *   **Smoothed Features:** Mean Rank and Standard Deviation of the Top-K neighbors in SVD space.
        *   **Cross-View Interaction Features (Innovation):** Explicit deltas to guide arbitration:
            *   $|Rank_{Ridge} - Rank_{Lexical\_1}|$ (Divergence from Prior)
            *   $|Rank_{Ridge} - Rank_{Latent\_1}|$
            *   $|Rank_{Lexical\_1} - Rank_{Latent\_1}|$ (View Disagreement)
        *   **Metadata:** Notebook length, markdown ratio, and raw LSA vectors.

# Data

**Preprocessing for Training:**
1.  **Full Dataset:** Utilize the entire training corpus (~140k notebooks). Do not subsample (Cite solution_lesson_node_00002).
2.  **Target Generation:** Calculate the **Normalized Rank** $y \in [0, 1]$ for all markdown cells relative to the fixed code cell skeleton (Cite solution_lesson_node_00001).
3.  **Global Vectorization:**
    *   Fit a **TF-IDF Vectorizer** on the full markdown corpus.
    *   **Configuration:** Vocabulary=60,000, N-gram range=(1, 2), Sublinear TF=True, and **No Accent Stripping** (Cite solution_lesson_node_00004, solution_lesson_node_00005).
4.  **Latent Space Construction (Scalable):**
    *   Fit **Truncated SVD** (e.g., 128 components) on the TF-IDF matrix.
    *   **Project Code Cells:** Transform the notebook's code cells into this same SVD space by projecting their TF-IDF vectors. This creates a shared semantic space without the overhead of Transformers (Cite solution_lesson_node_00013).
5.  **Decoupled Neighbor Extraction:**
    *   **Lexical View:** Compute sparse cosine similarity between each markdown cell and all code cells in its notebook. Retrieve Top-10 neighbors. Extract Instance Features (Rank/Score of Top-2) and Smoothed Features (Mean/Std of Top-10).
    *   **Latent View:** Compute dense cosine similarity in SVD space. Retrieve Top-10 neighbors. Extract Instance Features (Rank/Score of Top-2) and Smoothed Features (Mean/Std of Top-10).

**Preprocessing for Evaluation:**
1.  Apply the fitted TF-IDF and SVD pipelines to the test data.
2.  Extract the fixed sequence of **Code Cell IDs** for each test notebook.
3.  Compute the Decoupled Multi-Resolution Neighborhood Features relative to the test notebook's code skeleton.

# Training

1.  **Stage 1 (Cross-Validation):**
    *   Train the Ridge Regressor using **5-Fold Cross-Validation** on the full dataset.
    *   Generate **Out-Of-Fold (OOF)** predictions for the entire training set to serve as unbiased features for Stage 2 (Cite solution_lesson_node_00011).
    *   Retrain Ridge on the full dataset for final inference.
2.  **Stage 2 (Stacking):**
    *   Construct the Stage 2 dataset combining: OOF Ridge Predictions, Lexical Neighborhood Features, Latent Neighborhood Features, Cross-View Interactions, and Metadata.
    *   Train the **LightGBM Regressor** to predict Normalized Rank, minimizing **Mean Absolute Error (MAE)**.
    *   **Strategy:** Use early stopping with a validation split. The explicit interaction features allow the tree to learn rules like "Trust the Lexical Rank only if Similarity > 0.5; otherwise, fall back to the Latent Smoothed Rank."

# Evaluation

1.  **Pipeline Inference:**
    *   Generate Stage 1 predictions (Ridge).
    *   Generate Stage 2 features (Decoupled Neighborhoods).
    *   Predict Final Rank using the LightGBM model.
2.  **Anchor-Based Sorting:**
    *   Assign fixed, equidistant ranks ($0.0, \dots, 1.0$) to the ordered code cells (Cite solution_lesson_node_00001).
    *   Combine the code cells (fixed ranks) and markdown cells (predicted ranks) into a single list.
    *   Sort the list by rank to produce the final `cell_order`.
