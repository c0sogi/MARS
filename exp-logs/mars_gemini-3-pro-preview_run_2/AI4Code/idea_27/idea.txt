Based on the comprehensive analysis of the "Lessons" learned—specifically the necessity of **Decoupling Retrieval Spaces** (Cite solution_lesson_node_00035), the critical importance of retaining **Intrinsic Node Features** alongside relational ones (Cite solution_lesson_node_00036), the superiority of **Neighborhood Smoothing** (Cite solution_lesson_node_00015), and the efficiency of **Linear Baselines** on the **Full Dataset** (Cite solution_lesson_node_00002)—I propose a **Stacked Hybrid Ranking with Intrinsic-Augmented Decoupled Neighborhoods**.

This solution structurally evolves the "Stacked Hybrid" architecture (Idea 26) by correcting its primary flaw: the removal of the markdown cell's own semantic representation. While Idea 26 correctly decoupled the neighbor retrieval, it forced the model to rely *solely* on neighbors, losing the intrinsic signal of the text itself (e.g., "Introduction" vs. "Appendix"). This proposal explicitly fuses the **Intrinsic Content** (LSA vectors) with **Decoupled Relational Context** (Lexical and Latent Anchors) in the refinement stage.

# Model

The architecture is a **Two-Stage Stacked Regression Pipeline** that arbitrates between global structural priors, intrinsic semantic content, and local alignment cues.

1.  **Stage 1: Sparse Lexical Regressor (The "Signpost" Model)**
    *   **Component:** A **Ridge Regression** model.
    *   **Role:** Explicitly preserved from the lessons to serve as the robust, high-bias baseline. It maps explicit "signpost" keywords (e.g., "Introduction", "Submission") directly to normalized ranks using high-dimensional sparse features (Cite solution_lesson_node_00010).
    *   **Input:** High-dimensional **TF-IDF** vectors (Unigrams + Bigrams).

2.  **Stage 2: Intrinsic-Augmented Gradient Booster (The "Refinement" Model)**
    *   **Component:** A **LightGBM Regressor**.
    *   **Role:** Refines the linear prediction by integrating non-linear interactions between the cell's *own* content and its *neighbors'*.
    *   **Input Features:**
        *   **Ridge Prediction:** The output from Stage 1 (Cite solution_lesson_node_00011).
        *   **Intrinsic Content Features (Correction):** The raw **Latent Semantic Analysis (LSA)** vector (e.g., 128 dimensions) of the markdown cell itself. This ensures the model retains the ability to identify topics independent of neighbors (Cite solution_lesson_node_00036).
        *   **View A: Lexical Neighborhood (Precision):** Derived from **Sparse TF-IDF** similarity. Captures exact keyword matches (e.g., `plt.plot` $\leftrightarrow$ "plot").
            *   **Instance Features:** The **Rank** and **Similarity Score** of the **1st Nearest Neighbor**. Acts as a high-confidence gate for exact matches (Cite solution_lesson_node_00034, solution_lesson_node_00024).
            *   **Smoothed Features:** The **Weighted Mean Rank** and **Std Dev** of the **Top-K** (e.g., K=10) neighbors. Provides robustness against spurious overlaps (Cite solution_lesson_node_00015).
        *   **View B: Latent Neighborhood (Recall):** Derived from **Truncated SVD** similarity. Captures conceptual alignment (e.g., `StandardScaler` $\leftrightarrow$ "Preprocessing") efficiently on the full dataset (Cite solution_lesson_node_00013, solution_lesson_node_00035).
            *   **Instance Features:** Rank and Similarity of the 1st neighbor in SVD space.
            *   **Smoothed Features:** Weighted Mean Rank and Std Dev of the Top-K neighbors in SVD space.
        *   **Metadata:** Notebook length, markdown ratio.

# Data

**Preprocessing for Training:**
1.  **Full Dataset:** Utilize the entire training corpus (~140k notebooks). **Do not subsample** (Cite solution_lesson_node_00002).
2.  **Target Generation:** Calculate the **Normalized Rank** $y \in [0, 1]$ for all markdown cells relative to the fixed code cell skeleton (Cite solution_lesson_node_00001).
3.  **Global Vectorization:**
    *   Fit a **TF-IDF Vectorizer** on the full markdown corpus.
    *   **Configuration:** Vocabulary=60,000, N-gram range=(1, 2), Sublinear TF=True, and **No Accent Stripping** (Cite solution_lesson_node_00004, solution_lesson_node_00005).
4.  **Latent Space Construction:**
    *   Fit **Truncated SVD** (128 components) on the TF-IDF matrix.
    *   **Project Code Cells:** Transform the notebook's code cells into this same SVD space by projecting their TF-IDF vectors (Cite solution_lesson_node_00013).
5.  **Decoupled Neighbor Extraction:**
    *   **Lexical View:** Compute sparse cosine similarity between each markdown cell and all code cells in its notebook. Retrieve Top-10 neighbors. Extract Instance (Top-1) and Smoothed (Top-10) features.
    *   **Latent View:** Compute dense cosine similarity in SVD space. Retrieve Top-10 neighbors. Extract Instance and Smoothed features.

**Preprocessing for Evaluation:**
1.  Apply the fitted TF-IDF and SVD pipelines to the test data.
2.  Extract the fixed sequence of **Code Cell IDs** for each test notebook.
3.  Compute the Intrinsic and Decoupled Neighborhood Features relative to the test notebook's code skeleton.

# Training

1.  **Stage 1 (Cross-Validation):**
    *   Train the Ridge Regressor using **5-Fold Cross-Validation** on the full dataset.
    *   Generate **Out-Of-Fold (OOF)** predictions for the entire training set to serve as unbiased features for Stage 2 (Cite solution_lesson_node_00011).
    *   Retrain Ridge on the full dataset for final inference.
2.  **Stage 2 (Stacking):**
    *   Construct the Stage 2 dataset combining: OOF Ridge Predictions, Intrinsic LSA Vectors, Lexical Neighborhood Features, Latent Neighborhood Features, and Metadata.
    *   Train the **LightGBM Regressor** to predict Normalized Rank, minimizing **Mean Absolute Error (MAE)**.
    *   **Strategy:** Use early stopping with a validation split. The model will learn to use the Intrinsic features to determine the general section (e.g., "This is an import block") and the Neighborhood features to refine the exact position based on code proximity.

# Evaluation

1.  **Pipeline Inference:**
    *   Generate Stage 1 predictions (Ridge).
    *   Generate Stage 2 features (Intrinsic + Decoupled Neighborhoods).
    *   Predict Final Rank using the LightGBM model.
2.  **Anchor-Based Sorting:**
    *   Assign fixed, equidistant ranks ($0.0, \dots, 1.0$) to the ordered code cells (Cite solution_lesson_node_00001).
    *   Combine the code cells (fixed ranks) and markdown cells (predicted ranks) into a single list.
    *   Sort the list by rank to produce the final `cell_order`.
