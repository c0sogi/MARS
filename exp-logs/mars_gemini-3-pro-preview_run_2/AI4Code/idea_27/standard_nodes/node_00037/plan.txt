Based on the lessons learned regarding decoupled retrieval and intrinsic feature preservation, I have implemented the orchestration script `runfile.py`. This script executes a two-stage stacked regression pipeline:

1.  **Stage 1 (Ridge Regression):** Acts as a high-bias "signpost" model using sparse TF-IDF features to predict global rank.
2.  **Stage 2 (LightGBM):** Refines the ranking by integrating the Ridge predictions with **Intrinsic LSA features** (preserving the cell's own semantic content) and **Decoupled Neighborhood features** (Lexical and Latent similarities to code anchors).

The script performs strict hold-out validation, failure analysis, and conditional submission generation.
