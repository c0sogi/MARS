The `FileNotFoundError` is caused by the early binding of the `Config.SUBMISSION_PATH` variable within the `SubmissionGenerator` class. The generator is instantiated before the configuration is updated to point to the validation output file, causing the instance to retain the old path and write the output to the wrong location (Cite debug_lesson_2). To fix this, I will modify `runfile.py` to instantiate `SubmissionGenerator` *after* updating `Config.SUBMISSION_PATH` for the validation step. I will also re-instantiate it in the test section to ensure it correctly picks up the restored submission path for the final output.
