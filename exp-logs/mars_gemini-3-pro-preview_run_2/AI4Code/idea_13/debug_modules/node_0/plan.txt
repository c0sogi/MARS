This script demonstrates the end-to-end execution of the provided machine learning pipeline for ranking notebook cells. It defines a `DemoConfig` to override standard hyperparameters for speed (using a small data subset, fewer epochs, and reduced dimensionality). It then sequentially executes and verifies the Data Loading, Stage 1 (Ridge Regression), Stage 2 (Siamese Metric Learning), and Stage 3 (LightGBM Ranking) components, ensuring that intermediate artifacts and the final submission are correctly generated.
