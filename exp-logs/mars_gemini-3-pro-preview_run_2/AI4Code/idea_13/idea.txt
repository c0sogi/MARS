Based on the "Lessons" learned—specifically the effectiveness of **Anchor-Based Regression** (Cite solution_lesson_node_00001), the necessity of the **Full Dataset** (Cite solution_lesson_node_00002), and the superiority of **Neighborhood Smoothing** (Cite solution_lesson_node_00015)—I propose a **Stacked Hybrid Ranking with Supervised Metric Anchoring**.

This solution structurally evolves the "Previous Ideas" by addressing the primary limitation of the "Latent View" (Idea 12): unsupervised similarity (e.g., SVD/LSA) often fails to align markdown text with code when the vocabulary is disjoint (e.g., "Preprocessing" text vs. `StandardScaler` code). Instead of relying on heavy Transformers (which force data downsampling, Cite solution_lesson_node_00013), I propose introducing a lightweight **Supervised Metric Learning** stage to explicitly learn a projection space where markdown cells are geometrically close to their *adjacent* code cells.

# Model
The architecture is a **Three-Stage Cascaded Pipeline**:

1.  **Stage 1: Sparse Lexical Regressor (The "Signpost" Model)**
    *   **Component:** A **Ridge Regression** model.
    *   **Role:** Preserved from the lessons to act as the high-bias baseline. It maps explicit "signpost" keywords (e.g., "Introduction") directly to normalized ranks using high-dimensional sparse features.
    *   **Input:** **TF-IDF** vectors (Unigrams + Bigrams).

2.  **Stage 2: Supervised Metric Projector (The "Alignment" Model - Innovation)**
    *   **Component:** A lightweight **Siamese Projection Network** (a shallow MLP or Linear Layer).
    *   **Role:** Unlike previous ideas that used unsupervised SVD/LSA for the "Latent View," this model projects the SVD vectors of markdown and code cells into a **Task-Aligned Metric Space**.
    *   **Objective:** It is trained with a **Contrastive Loss** to minimize the Euclidean distance between a markdown cell and its *adjacent* code cells (Positive Pairs) while maximizing the distance to distant code cells (Negative Pairs). This forces the model to learn that "Load Data" is semantically equivalent to `pd.read_csv` for the purpose of ordering.

3.  **Stage 3: Neighborhood Gradient Booster (The "Refinement" Model)**
    *   **Component:** A **LightGBM Regressor**.
    *   **Role:** Refines the rank predictions by aggregating signals from the Ridge model and the Supervised Metric Anchors.
    *   **Input Features:**
        *   **Ridge Prediction:** Output from Stage 1 (Cite solution_lesson_node_00011).
        *   **Supervised Anchor Features:** Aggregated statistics (Mean Rank, Weighted Mean Rank) of the **Top-K** code cells closest to the markdown cell in the **Task-Aligned Metric Space** (Cite solution_lesson_node_00015).
        *   **Lexical Anchor Features:** Top-K statistics from the original Sparse TF-IDF space (to preserve exact matches).
        *   **Anchor Semantics:** Boolean flags indicating if the Top-1 Anchor contains structural keywords (e.g., `import`, `def`, `plot`, `submission`).

# Data
**Preprocessing for Training:**
1.  **Full Dataset:** Utilize the entire training corpus (~140k notebooks) without downsampling (Cite solution_lesson_node_00002).
2.  **Vectorization:**
    *   Fit **TF-IDF** (60k vocab, Bigrams, Log-TF, No Accent Stripping) (Cite solution_lesson_node_00004, solution_lesson_node_00005).
    *   Fit **Truncated SVD** (128 components) on the TF-IDF matrix to generate dense inputs for Stage 2 (Cite solution_lesson_node_00013).
3.  **Metric Learning Pairs:** Construct a dataset of pairs $(M, C)$ where $M$ is a markdown cell and $C$ is a code cell. Label as `1` if they are adjacent in the ground truth order, `0` otherwise.

**Preprocessing for Evaluation:**
1.  Apply TF-IDF and SVD pipelines to test data.
2.  Extract the fixed sequence of **Code Cell IDs** for each test notebook to serve as the anchor skeleton (Cite solution_lesson_node_00001).

# Training
1.  **Stage 1 (Ridge):** Train on the full dataset using 5-Fold Cross-Validation to generate unbiased Out-Of-Fold (OOF) predictions.
2.  **Stage 2 (Metric Learning):** Train the Siamese Projection Network on the pair dataset using **Contrastive Loss** or **Triplet Loss**. Since the input is low-dimensional SVD vectors, this is extremely fast (minutes).
3.  **Stage 3 (LightGBM):**
    *   For every markdown cell, retrieve the **Top-K** (e.g., K=5) nearest code anchors using the learned embeddings from Stage 2.
    *   Compute aggregated rank statistics (Mean, Std).
    *   Train LightGBM to predict Normalized Rank using OOF Ridge scores and Anchor features, minimizing MAE.

# Evaluation
1.  **Inference:**
    *   Generate Ridge predictions.
    *   Project test cells into the Task-Aligned Metric Space.
    *   Retrieve Top-K anchors relative to the test notebook's code skeleton.
    *   Predict Final Rank using LightGBM.
2.  **Sorting:**
    *   Assign fixed ranks ($0.0 \dots 1.0$) to the ordered code cells (Cite solution_lesson_node_00001).
    *   Combine code cells (fixed ranks) and markdown cells (predicted ranks) into a single list.
    *   Sort the list by rank to produce the final `cell_order`.
