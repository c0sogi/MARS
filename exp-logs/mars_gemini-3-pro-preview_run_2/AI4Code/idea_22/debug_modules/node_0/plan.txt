The following script demonstrates the complete workflow for the AI4Code notebook sorting task using the provided library. To ensure the demonstration runs quickly and efficiently within the constraints, the script performs the following steps:

1.  **Configuration Overrides**: It modifies the `Config` class attributes at runtime to use temporary paths and reduced hyperparameters (e.g., smaller vocabulary, fewer SVD components, fewer boosting rounds).
2.  **Data Subsampling**: It creates "mini" metadata files by sampling the original metadata. This restricts the heavy data loading and processing steps to a small subset of notebooks (50 for training, 20 for validation/test).
3.  **Component Execution**: It sequentially instantiates and runs the `NotebookLoader`, `TextPipeline`, `Stage1Ridge`, `FeatureExtractor`, and `Stage2LGBM` classes.
4.  **Logic Verification**: At each step, assertions check the shapes, data types, and integrity of the outputs (e.g., ensuring OOF predictions match the dataframe length, verifying feature dimensions).
5.  **Metric Calculation**: It manually calculates the Kendall Tau score on the validation subset to demonstrate the evaluation metric.
6.  **Pipeline Integration**: Finally, it generates a submission file for the test subset.
