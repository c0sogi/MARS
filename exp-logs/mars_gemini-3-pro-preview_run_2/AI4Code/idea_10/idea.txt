Based on the "Lessons" learned, specifically the superior performance of **Anchor-Based Regression** (Cite solution_lesson_node_00001), the necessity of using the **Full Dataset** (Cite solution_lesson_node_00002), and the critical trade-off where heavy Transformers force data downsampling and degrade performance (Cite solution_lesson_node_00013), I propose a **Stacked Hybrid Ranking with Dual-View Scalable Anchoring**.

This solution structurally evolves the "Stacked Hybrid" approach by introducing **Latent Semantic Analysis (LSI)** as a scalable proxy for semantic embeddings. This resolves the conflict between the need for "Dense/Semantic" matching (to bridge the lexical gap) and the need for "High-Volume" training (to capture rare edge cases).

# Model

The architecture is a **Two-Stage Stacked Regression Pipeline** that arbitrates between explicit lexical signals and implicit latent topics to determine cell ordering.

**Stage 1: Sparse Lexical Regressor (The "Signpost" Model)**
*   **Component:** A **Ridge Regression** model.
*   **Role:** Explicitly preserved from the lessons to serve as the high-bias baseline. It maps "signpost" keywords (e.g., "Introduction", "Submission") directly to normalized ranks using high-dimensional sparse features.
*   **Input:** High-dimensional **TF-IDF** vectors (Unigrams + Bigrams).

**Stage 2: Dual-View Anchor Gradient Booster (The "Refinement" Model)**
*   **Component:** A **LightGBM Regressor**.
*   **Role:** This model refines the linear prediction by learning non-linear interactions and, crucially, utilizing **Dual-View Anchoring** to localize the markdown cell relative to the code skeleton.
*   **Input Features:**
    1.  **Ridge Prediction:** The output from Stage 1 (the primary signal).
    2.  **Lexical Anchor Features (Exploitation):** Derived from **Sparse TF-IDF** similarity (Cite solution_lesson_node_00012). We identify the ordered code cell with the highest cosine similarity to the markdown cell in TF-IDF space. Features include the **Rank** of this neighbor and the **Similarity Score**. This captures exact keyword matches (e.g., `plt.plot` in code $\leftrightarrow$ "plot" in text).
    3.  **Latent Anchor Features (Innovation):** Derived from **Dense SVD/LSA** projection. Instead of using slow Transformers (Cite solution_lesson_node_00013), we project both markdown and code cells into a shared, low-rank Singular Value Decomposition (SVD) space. We identify the "Latent Nearest Neighbor" code cell in this space. Features include the **Rank** of this latent neighbor and the **Dense Similarity Score**. This captures conceptual alignment (e.g., `StandardScaler` in code $\leftrightarrow$ "Preprocessing" in text) efficiently across the full dataset.
    4.  **Metadata:** Notebook length, markdown ratio, and aggregated LSA vectors.

# Data

**Preprocessing for Training:**
1.  **Target Generation:** Calculate the **Normalized Rank** $y \in [0, 1]$ for all markdown cells in the **Full Training Dataset** relative to the fixed code cell skeleton (Cite solution_lesson_node_00001, solution_lesson_node_00002).
2.  **Global Vectorization:**
    *   Fit a **TF-IDF Vectorizer** on the full markdown corpus.
    *   **Configuration:** Vocabulary=60,000, N-gram range=(1, 2), Sublinear TF=True, and **No Accent Stripping** (Cite solution_lesson_node_00004, solution_lesson_node_00005).
3.  **Latent Semantic Space Construction:**
    *   Fit **Truncated SVD** (e.g., 128 components) on the Markdown TF-IDF matrix.
    *   **Project Code Cells:** Transform the notebook's code cells into this same SVD space by projecting their TF-IDF vectors. This aligns code and text in a shared "Topic Space" without expensive neural inference.
4.  **Anchor Extraction:**
    *   **Lexical:** For each markdown cell, compute cosine similarity against all code cells in the notebook using sparse TF-IDF vectors. Extract the Rank and Score of the max-similarity code cell.
    *   **Latent:** For each markdown cell, compute cosine similarity against all code cells in the notebook using dense SVD vectors. Extract the Rank and Score of the max-similarity code cell.

**Preprocessing for Evaluation:**
1.  Apply the fitted TF-IDF and SVD pipelines to the test data.
2.  Extract the fixed sequence of **Code Cell IDs** for each test notebook.
3.  Compute both Lexical and Latent Anchor features relative to the test notebook's code skeleton.

# Training

1.  **Stage 1 (Cross-Validation):**
    *   Train the Ridge Regressor using **5-Fold Cross-Validation** on the full dataset.
    *   Generate **Out-Of-Fold (OOF)** predictions for the entire training set to serve as unbiased features for Stage 2 (Cite solution_lesson_node_00011).
    *   Retrain the Ridge model on the full dataset for final inference.
2.  **Stage 2 (Stacking):**
    *   Construct the Stage 2 dataset combining: OOF Ridge Predictions, Lexical Anchor Features, Latent Anchor Features, and Metadata.
    *   Train the **LightGBM Regressor** to predict Normalized Rank, minimizing **Mean Absolute Error (MAE)**.
    *   **Strategy:** Use early stopping with a validation split. The tree will naturally learn to weight the Lexical Anchor higher when exact keywords are present (high sparse sim) and switch to the Latent Anchor when vocabulary is disjoint (high dense sim but low sparse sim).

# Evaluation

1.  **Pipeline Inference:**
    *   Generate Stage 1 predictions (Ridge).
    *   Generate Stage 2 features (Dual Anchors + Metadata).
    *   Predict Final Rank using the LightGBM model.
2.  **Anchor-Based Sorting:**
    *   Assign fixed, equidistant ranks ($0.0, \dots, 1.0$) to the ordered code cells (Cite solution_lesson_node_00001).
    *   Combine the code cells (fixed ranks) and markdown cells (predicted ranks) into a single list.
    *   Sort the list by rank to produce the final `cell_order`.
