This script demonstrates the end-to-end usage of the provided library for the Notebook Cell Ordering task. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters to use a temporary working directory and reduced model hyperparameters (e.g., fewer trees, smaller vocabulary) for rapid execution.
2.  **Data Subsampling**: Creates small subsets (20 notebooks each) of the training, validation, and test metadata to ensure the demonstration runs quickly.
3.  **Component Validation**:
    *   **Data Loading**: Verifies `NotebookLoader` correctly reads and flattens notebook JSONs into a DataFrame.
    *   **Feature Engineering**: Verifies `AnchorFeatureGenerator` creates the expected lexical, semantic, and symbolic features.
    *   **Modeling**: Tests `Stage1Ridge` (TF-IDF regression) and `Stage2LGBM` (Stacking) individually to ensure they fit and predict correctly.
4.  **Pipeline Integration**: Runs the full `HybridRankingPipeline` on the subsampled data, performing training, validation, and inference, culminating in the generation of a submission file.
