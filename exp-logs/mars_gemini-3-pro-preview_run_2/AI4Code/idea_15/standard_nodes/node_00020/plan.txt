Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and set random seeds for reproducibility.
2.  **Data Management**: Use `DataManager` to load training and validation data. To ensure the solution runs within the time limit (Fast Baseline), I will subsample the training data to 10,000 notebooks while keeping the validation set intact for accurate metric calculation.
3.  **Feature Engineering**: Use `FeatureEngine` to fit TF-IDF/SVD on the subsampled training data and generate multi-view anchor features (Lexical, Latent, Symbolic) for both training and validation sets.
4.  **Stage 1 (Ridge Regression)**: Train the `RidgeStacker` on the sparse TF-IDF features of the subsampled training data using GroupKFold to generate Out-Of-Fold (OOF) predictions. Fit the final Ridge model and generate predictions for the validation set.
5.  **Stage 2 (LightGBM)**: Train the `LGBMRanker` using the dense anchor features + Ridge predictions. Use the validation set for early stopping.
6.  **Validation & Metric**: Predict ranks for the validation set. Reconstruct the full notebook cell order by combining predicted Markdown ranks with fixed Code cell ranks. Compute the Kendall Tau correlation against the ground truth.
7.  **Failure Analysis**: Calculate the absolute error of the predictions on the validation set and compute Pearson correlations with key features (e.g., `lex_std`, `md_ratio`) to identify error sources.
8.  **Submission**: If the validation metric exceeds the threshold (0.7959...), execute the `SubmissionGenerator` to create the final `submission.csv`.
