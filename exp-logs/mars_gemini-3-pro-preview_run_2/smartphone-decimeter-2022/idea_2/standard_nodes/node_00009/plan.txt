This script orchestrates the training, validation, and conditional submission generation for the smartphone location task. It utilizes a Bidirectional LSTM model to predict location residuals based on a sequence of GNSS and IMU features.

Implementation Strategy:
1.  **Configuration**: Overrides default configuration parameters (Epochs, Batch Size) to ensure the training completes quickly within the time limit while maintaining reasonable performance.
2.  **Setup**: Sets random seeds for reproducibility.
3.  **Data Loading**: Initializes the `GNSSWindowDataset` for both training and validation. This leverages the pre-implemented caching and preprocessing logic.
4.  **Training**: Initializes the `BiLSTMRegressor` and trains it using the `train_model` function. The best model is saved based on validation loss.
5.  **Validation & Metric**:
    *   Runs inference on the validation set.
    *   Reconstructs the predicted WGS84 coordinates from the predicted residuals and the WLS baseline.
    *   Computes the Haversine distance between predicted and ground truth coordinates.
    *   Calculates the specific competition metric: Mean of the 50th and 95th percentile errors, averaged across phones.
6.  **Failure Analysis**: Computes and prints the Spearman correlation between the prediction error (distance) and the input features to identify sources of error.
7.  **Conditional Submission**: Checks if the validation metric is below the specified threshold (4.256982128481356). If satisfied, it loads the test dataset and generates the submission file using `generate_submission`.
