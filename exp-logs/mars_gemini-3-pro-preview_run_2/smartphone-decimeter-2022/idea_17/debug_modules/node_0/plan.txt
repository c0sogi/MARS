Implementation Strategy:
1.  **Configuration Override**: To ensure the demonstration runs quickly, I will monkey-patch `library.config` to use a temporary cache directory, reduce the number of epochs to 1, and set a small batch size.
2.  **Data Subsetting**: I will read the existing metadata files, select a very small subset (e.g., one trip for training, validation, and testing), and save these as temporary metadata files in the working directory. This ensures the data processing step is fast while still using real data.
3.  **Component Verification**:
    *   **Utils**: Verify coordinate conversion and distance calculation functions.
    *   **Preprocessing**: Run the data processing pipeline on the subset metadata and verify the shape of the generated feature arrays (Kinematic and Sky context).
    *   **Dataset**: Instantiate the PyTorch dataset and verify the shape of the tensors returned by the `__getitem__` method, ensuring the channel-first format required by 1D-CNNs is correct.
    *   **Model**: Instantiate the `SCRCNN` model and perform a forward pass with dummy data to verify the architecture and output dimensions.
    *   **Training**: Run the training loop using the subset data and verify that the model trains without error and saves the best weights.
    *   **Inference**: Run the inference pipeline to generate a submission file and verify its format.
