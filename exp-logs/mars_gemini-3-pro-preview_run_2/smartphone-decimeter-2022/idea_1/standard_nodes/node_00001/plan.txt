Implementation Strategy:
1.  **Setup**: Initialize random seeds for reproducibility. Import necessary modules and configuration.
2.  **Training & Submission**: Execute the `run_experiment` function from `library.trainer`. This function orchestrates the loading of training data, training the Windowed MLP model (with a limited epoch count for speed), and generating the inference submission file for the test set.
3.  **Validation Inference**:
    *   Load the pre-processed validation data and the raw validation dataframe (to access ground truth and baseline coordinates).
    *   Load the trained model weights.
    *   Perform inference on the validation set to predict residuals.
    *   Reconstruct the predicted Latitude/Longitude by adding predicted residuals to the WLS baseline.
4.  **Metric Calculation**: Implement the specific competition metric (Mean of 50th and 95th percentile errors per trip) using the reconstructed validation predictions and ground truth. Print the result.
5.  **Failure Analysis**: Calculate the Haversine distance error for each validation point. Compute and print the Spearman correlation between this error and key signal features (CN0, Uncertainty, Satellite Count) to identify error sources.
