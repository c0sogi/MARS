Based on the analysis of previous experiments and the accumulated lessons, I propose the **Context-Aware 1D-CNN Smoother**. This solution evolves the successful Windowed MLP approach (Idea 1) into a convolutional architecture that better captures local temporal structure while correcting the architectural flaws that led to the failure of the DST-ResNet (Idea 3).

### Model
**Architecture: Context-Aware 1D-CNN**
The model is designed to perform trajectory smoothing by processing a short time-series window of sensor data. Unlike Idea 3, which stripped absolute positions from the temporal stream, this model processes the **full sequence of absolute states**.

1.  **Input Sequence:** A sliding window of size $N$ (e.g., 11 epochs, representing $\pm 5$ seconds). Each timestep contains a feature vector consisting of **Absolute WLS Coordinates** (Lat, Lon, Alt), **Dynamics** (Deltas), and **Signal Metrics** (Cn0, Uncertainty).
2.  **Convolutional Backbone:** A stack of **1D Convolutional Layers** (e.g., 3 layers with kernel size 3, ReLU, and Batch Normalization). This allows the model to learn local filtering operations (like a learnable moving average) directly on the coordinate sequence, preserving the geometric context that was lost in Idea 3. **Cite solution_lesson_node_00013**.
3.  **Context Injection:** The output of the convolutional block is flattened or pooled. To explicitly enforce the learning of state-dependent environmental biases (e.g., specific multipath zones), the **Absolute WLS Coordinates of the center timestamp** are concatenated to this feature vector. This ensures the model retains the specific spatial context required for bias correction. **Cite solution_lesson_node_00011**.
4.  **Prediction Head:** A Multi-Layer Perceptron (MLP) projects the concatenated vector to a 2D output: the residual correction in local metric units ($\Delta$East, $\Delta$North).

### Data
**Preprocessing:**
1.  **Target Transformation:** Calculate the ground truth residuals in a local metric frame (ENU - East, North, Up). The target is the difference in **meters** between the Ground Truth and the WLS baseline. **Cite solution_lesson_node_00001**.
2.  **Feature Engineering:**
    *   **Absolute State:** Include standardized WLS Latitude, Longitude, and Altitude for every timestep in the window.
    *   **Explicit Dynamics:** Calculate and include the first-order differences (deltas) for Latitude, Longitude, and **Altitude**. Including vertical dynamics provides a critical signal for detecting anomalies in the 2D plane. **Cite solution_lesson_node_00005**, **Cite solution_lesson_node_00006**.
    *   **Signal Quality:** Include standard metrics (Cn0, Uncertainty, Satellite Count).
3.  **Windowing:** Create sliding windows of a short, fixed length (e.g., 11 epochs). A short window is chosen to prevent the overfitting to specific trajectory shapes observed with longer LSTM sequences. **Cite solution_lesson_node_00010**.
4.  **Normalization:** Apply Standard Scaling (Z-score) to all input features.

### Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss is selected for its robustness to the extreme outliers typical of urban GNSS data, aligning with the competition's percentile-based metric.
*   **Optimizer:** **AdamW** with a learning rate scheduler (e.g., `ReduceLROnPlateau`) to handle plateaus and ensure convergence.
*   **Regularization:** Use Batch Normalization within the CNN blocks and Dropout in the final MLP head to improve generalization.

### Evaluation
**Inference Process:**
1.  **Preprocessing:** Apply the same windowing, feature engineering (including Altitude deltas), and normalization to the test data.
2.  **Prediction:** Feed the test windows into the trained CNN to predict the metric residuals ($\Delta$East, $\Delta$North).
3.  **Reconstruction:** Convert the predicted metric residuals back to decimal degrees using local approximation factors (1m $\approx$ 1/111,320 degrees Lat; Lon varies by Lat). Add these degree-based corrections to the baseline WLS position to generate the final submission coordinates.
