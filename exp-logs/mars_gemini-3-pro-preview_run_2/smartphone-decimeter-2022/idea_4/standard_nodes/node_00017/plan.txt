To fix this, I will explicitly add these metadata columns to the `cols_to_keep` list in `library/dataset.py`. Additionally, I will update the cache file names in `library/config.py` to force the preprocessing pipeline to regenerate the data files with the required columns, bypassing the stale cache from the previous run.
