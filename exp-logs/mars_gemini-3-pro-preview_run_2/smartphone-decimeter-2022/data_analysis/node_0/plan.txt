Implementation Strategy:
1.  **Setup & Configuration**: Define constants, random seeds, and helper functions for ECEF to Geodetic conversion.
2.  **Target Analysis**: Load the `train_metadata.csv` to analyze the distribution, skewness, and kurtosis of the ground truth `LatitudeDegrees` and `LongitudeDegrees`.
3.  **Input Data Analysis (Tabular)**:
    *   Sample a subset of trips (e.g., 3 random trips) to keep execution time within limits.
    *   Load `device_gnss.csv` and `device_imu.csv` for these trips.
    *   Perform numerical analysis (mean, std, outliers) on key sensor fields (e.g., `Cn0DbHz`, `RawPseudorangeMeters`, IMU measurements).
    *   Perform categorical analysis on fields like `SignalType` and `ConstellationType`.
    *   Check for missing values.
4.  **Feature/Signal Relationships**:
    *   Aggregate GNSS data by timestamp (epoch) to create features like `SatelliteCount`, `MeanCn0DbHz`, `MeanUncertainty`.
    *   Convert the provided baseline WLS ECEF coordinates to Latitude/Longitude.
    *   Merge aggregated GNSS features with Ground Truth based on timestamps.
    *   Calculate the "Baseline Error" (haversine distance between WLS estimate and Ground Truth).
    *   Compute correlations between aggregated signal features and the Baseline Error.
    *   Train a lightweight Random Forest to estimate feature importance for predicting the Baseline Error (proxy for signal quality importance).
5.  **Output**: Print the results in the specified format.
