### Implementation Strategy

1.  **Configuration Patching**: Before importing the main library modules, we import `library.config` and modify `NUM_EPOCHS` to a lower value (e.g., 5) to ensure the training completes quickly within the time limit.
2.  **Model Training**: We utilize `library.trainer.train_model` to train the `SkyMotionModel`. This handles data loading, scaling, and the training loop with the patched configuration.
3.  **Validation & Metric Calculation**:
    *   We manually load the validation dataset and metadata using `library.data_loader.process_dataset`.
    *   We run inference on the validation set using the trained model to get predicted residuals.
    *   We reconstruct absolute coordinates and calculate the Haversine distance error for each sample.
    *   We compute the competition metric: the mean of the (50th + 95th percentile) error averaged across all phones.
4.  **Failure Analysis**:
    *   We calculate the Pearson correlation between the computed distance errors and the "Sky Context" features (e.g., Signal Strength, Satellite Count, Elevation) to identify factors contributing to high errors.
5.  **Submission**:
    *   If the calculated validation metric is below the specified threshold (4.25698...), we proceed to generate the submission file using `library.inference.generate_submission`.
