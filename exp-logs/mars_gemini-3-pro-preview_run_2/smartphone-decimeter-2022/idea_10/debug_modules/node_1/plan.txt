The issue is that `trip_metadata` in `process_trip` is a pandas DataFrame subset (filtered by `tripId`), so accessing columns like `trip_metadata["gnss_path"]` returns a pandas Series object, not a scalar string. When this Series is passed to `load_gnss_data` and subsequently to `os.path.join`, it raises a `TypeError`.

To fix this, I will modify `library/data_loader.py` to explicitly extract the scalar value from the first row of the Series using `.iloc[0]`. This ensures that `gnss_path` and `trip_id` are strings, which resolves the type error in `os.path.join` and allows the data loading to proceed.
