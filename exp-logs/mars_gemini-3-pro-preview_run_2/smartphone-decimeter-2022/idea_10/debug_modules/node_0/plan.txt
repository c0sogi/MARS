This script demonstrates the end-to-end pipeline for the GNSS positioning task using the provided library modules. It performs the following steps:
1.  **Configuration Override**: Modifies global configuration parameters (batch size, epochs, debug sample size) to ensure the demonstration runs quickly.
2.  **Utility Verification**: Validates the correctness of the haversine distance calculation.
3.  **Data Loading**: Uses `data_loader` to process a small subset of the training and validation data, creating PyTorch DataLoaders.
4.  **Model Initialization**: Instantiates the `SkyMotionModel` and verifies its forward pass with a sample batch.
5.  **Training**: Uses the `Trainer` class to train the model for one epoch on the subset data.
6.  **Inference**: Generates a submission file using the trained model on a subset of the test data.
