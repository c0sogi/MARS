The execution failed with a `TypeError` because the `verbose` argument was passed to the `ReduceLROnPlateau` scheduler constructor. This argument has been deprecated and removed in recent versions of PyTorch (Cite debug_lesson_1). To fix this, I will remove the `verbose=True` argument from the scheduler initialization in both `library/engine.py` and `library/model.py`.
