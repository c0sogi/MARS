The implementation strategy for `runfile.py` involves the following steps:

1.  **Configuration Override**: Before importing the main training logic, we modify the `library.trainer` module's global variables (specifically `NUM_EPOCHS`) to ensure the training completes quickly as a baseline, adhering to the time constraints.
2.  **Training**: We invoke `library.trainer.train_model(load_cached_data=True)`. This function handles data loading, preprocessing (fitting the scaler), and training the `GeometryConditionedCNN` model. It saves the best model weights and the scaler to the working directory.
3.  **Validation**:
    *   We load the validation dataset using `library.data_loader.get_dataset("val")`.
    *   We perform inference on the validation set. Crucially, we reconstruct the subset of the dataframe that corresponds to the valid sequence windows (handling the window offset) to ensure predictions align with ground truth.
    *   We compute the competition metric (mean of 50th and 95th percentile errors) and print it in the required format.
4.  **Failure Analysis**:
    *   During validation inference, we collect input features (CN0, Uncertainty, Satellite Count) alongside the prediction errors.
    *   We calculate and print the Spearman correlation between these features and the error magnitude to identify potential causes of poor performance.
5.  **Submission**:
    *   We check if the calculated validation metric is below the specified threshold (4.256982128481356).
    *   If successful, we call `library.inference.generate_predictions(load_cached_data=True)` to create the final submission file for the test set.
