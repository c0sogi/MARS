This script demonstrates the usage of the provided GNSS localization library. It performs the following steps:
1.  **Configuration Override**: Modifies configuration parameters (enabling debug mode, reducing epochs and batch size) to ensure the script runs quickly for demonstration purposes. It explicitly patches these values in the imported modules to handle `from ... import ...` dependencies.
2.  **Utils Verification**: Validates the correctness of coordinate conversion and distance calculation functions.
3.  **Data Loading**: Loads a small subset of the training data using the `get_dataset` function.
4.  **Preprocessing**: Demonstrates how to fit the `GNSSScaler` and create a `GNSSSequenceDataset`. It verifies the shape of the tensors produced by the dataset.
5.  **Model Initialization**: Instantiates the `GeometryConditionedCNN` model and performs a forward pass with dummy data to verify input/output dimensions.
6.  **Training Loop**: Runs a full training cycle (1 epoch) using `train_model`, ensuring the pipeline from data loading to model saving works correctly.
7.  **Inference**: Generates predictions on the test set using `predict_and_submit` and verifies the generation of the submission file.
