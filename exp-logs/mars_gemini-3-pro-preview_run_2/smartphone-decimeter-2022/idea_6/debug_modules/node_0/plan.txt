The implementation strategy involves creating a single Python script that systematically tests each component of the provided library.

1.  **Setup and Imports**: We will import the necessary classes and functions from the `library` package. We ensure the system path includes the current directory so these imports resolve correctly.
2.  **Coordinate Utility Verification**: We will implement a `test_utils` function to verify the geodetic coordinate conversion functions (`lla_to_ecef`, `ecef_to_lla`, etc.) using round-trip tests and known distance calculations.
3.  **Data Pipeline Verification**: We will implement `test_data_pipeline` to exercise the `load_data` and `get_dataloader` functions. We will modify `Config` parameters at runtime to use a small `DEBUG_SAMPLE_SIZE` (100 samples) and a specific `WINDOW_SIZE` to ensure the data processing completes quickly and produces tensors of the expected shape.
4.  **Model Verification**: We will implement `test_model` to instantiate the `RelativeTrajectoryCNN` and perform a forward pass with dummy data, asserting that the output shape matches the expected `(Batch_Size, 2)`.
5.  **Training Loop Verification**: We will implement `test_training_loop` to run the `run_training` function with a small dataset (200 samples) and a single epoch (`NUM_EPOCHS = 1`). This verifies the integration of the data loader, model, loss function, and optimizer, and ensures artifacts (model weights) are saved.
6.  **Inference Verification**: We will implement `test_inference_and_submission` to run `generate_submission` on a subset of the test data. We will verify that the submission CSV is created, has the correct schema, and contains valid coordinate values.
7.  **Execution**: The `if __name__ == "__main__":` block will execute these test functions sequentially, catching and reporting any errors.
