To establish a robust and highly efficient baseline for the iWildCam species classification task, I propose a **Fixed-Feature Transfer Learning** approach. This method prioritizes training speed and architectural simplicity by leveraging the provided MegaDetector results and a pre-trained CNN without the computational overhead of full network fine-tuning.

### Model
The architecture is a streamlined **Feature Extraction Network**.
*   **Backbone:** Use a lightweight, pre-trained Convolutional Neural Network (CNN), such as **ResNet-18** or **ResNet-50**, initialized with ImageNet weights. Crucially, this backbone will be **frozen** (non-trainable) during the entire process.
*   **Classifier:** Remove the original classification head and replace it with a **single trainable Linear (Dense) layer** followed by a Softmax activation. This layer maps the Global Average Pooled features from the backbone directly to the target species classes (including the "empty" class).
*   **Rationale:** By freezing the backbone, we reduce the trainable parameter count by orders of magnitude, allowing the model to converge rapidly while retaining the robust visual feature extraction capabilities learned from ImageNet.

### Data
Preprocessing relies heavily on the provided MegaDetector output to focus the model on relevant image regions.
*   **Cropping:** For each image, parse the corresponding entry in `iwildcam2020_megadetector_results.json`. Select the bounding box with the **highest confidence score**. Crop the image to this region.
    *   *Handling Empty/Low-Confidence:* If an image has no detections (empty list) or the maximum confidence is below a minimal threshold, use the **entire image** as the crop. This allows the model to learn the visual characteristics of "empty" scenes (Class 0).
*   **Resizing & Normalization:** Resize all crops to a standard, small resolution (e.g., **224x224 pixels**) to minimize I/O and inference time. Apply standard ImageNet normalization (mean and standard deviation subtraction) to pixel values.
*   **No Augmentation:** To maintain maximum speed and simplicity for this baseline, no data augmentation (e.g., flips, rotations) will be applied.

### Training
The training process is designed for efficiency.
*   **Loss Function:** Use **Cross-Entropy Loss** to handle the multi-class classification task.
*   **Optimizer:** Use the **Adam** optimizer with a standard learning rate (e.g., 1e-3). Since only the final linear layer is being updated, the optimization landscape is convex (for the linear layer), ensuring stable and fast convergence.
*   **Procedure:** Train for a small number of epochs (e.g., 3-5) using the training split defined in the metadata. Monitor accuracy on the validation split to check for overfitting, though it is unlikely given the low model complexity relative to the data size.

### Evaluation
*   **Inference:** For every image in the test set, apply the same cropping logic (Max-Confidence Crop or Full Image) and preprocessing used during training.
*   **Prediction:** Pass the processed crop through the frozen backbone and the trained linear head. The predicted class is the index with the highest probability score from the Softmax output.
*   **Submission:** Format the resulting IDs and predicted categories into the required CSV format.
