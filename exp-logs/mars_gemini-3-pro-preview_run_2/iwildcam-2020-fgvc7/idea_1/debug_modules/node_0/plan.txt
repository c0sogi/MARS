This script demonstrates the end-to-end usage of the provided library for the iWildCam 2020 species classification task. It validates the core components: configuration, utility functions for bounding box processing, dataset loading with cropping and transformations, model instantiation with frozen backbones, and the training/inference loops.

The script performs the following steps:
1.  **Setup**: Initializes the environment and sets random seeds for reproducibility.
2.  **Utils Verification**: Tests `load_megadetector_data` to ensure detection metadata is parsed correctly and verifies `get_crop_coordinates` logic for converting relative bounding boxes to absolute pixel coordinates.
3.  **Dataset Verification**: Instantiates `CameraTrapDataset` for training and testing splits using a small sample size. It asserts that the data shapes (images) and types (labels/IDs) are correct.
4.  **Model Verification**: Initializes the `FrozenResNetClassifier`, confirms that the backbone layers are frozen (untrainable) while the head is trainable, and performs a dummy forward pass to check output dimensions.
5.  **Training & Inference**: Runs a complete training cycle (`run_training`) for 1 epoch on a small subset of data, followed by generating a submission file (`generate_predictions`) to verify the pipeline produces the expected output format.
