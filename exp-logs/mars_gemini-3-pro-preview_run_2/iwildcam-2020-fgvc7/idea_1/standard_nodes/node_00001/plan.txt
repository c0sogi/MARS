I will implement the orchestration script `runfile.py` to train a fixed-feature ResNet classifier, evaluate it, analyze its failures, and generate a submission.

### Strategy Outline
1.  **Setup**: Initialize configuration, random seeds, and compute device (GPU).
2.  **Training**: Execute a fast training run using `library.train.run_training`. To ensure the baseline runs quickly within the time limit, I will use a subset of the training data (`sample_size=20000`) and a low number of epochs (3). The model uses a frozen ResNet50 backbone, so convergence should be rapid.
3.  **Validation**: Load the **entire** hold-out validation dataset using `CameraTrapDataset`. Run inference to compute the categorical accuracy and print it as `Final Validation Metric`.
4.  **Failure Analysis**: Compare predictions against ground truth to generate a binary error vector. Extract metadata features (Width, Height, MegaDetector Confidence) from the validation set and calculate their Pearson correlation with the error vector to identify systematic weaknesses.
5.  **Submission**: Load the test dataset and generate predictions using `library.train.generate_predictions`, saving the result to `./submission/submission.csv`.
