The previous implementation encountered a CUDA Out of Memory (OOM) error because the `BATCH_SIZE` of 32 combined with the `EfficientNetV2-S` backbone and large image size (448x448) exceeded the available GPU memory (~16GB). To fix this, I will reduce the `BATCH_SIZE` to 16 in `library/config.py`. Additionally, I will implement Mixed Precision Training (AMP) in `library/train.py` using `torch.cuda.amp.GradScaler` and `autocast` to further reduce memory usage and improve training efficiency on the A100 GPU.
