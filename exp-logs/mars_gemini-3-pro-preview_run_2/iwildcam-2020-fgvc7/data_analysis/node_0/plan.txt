I will create a comprehensive EDA script that analyzes the iWildCam 2020 training data. The script will first load the pre-generated metadata. It will then perform a detailed analysis of the target variable (`category_id`), checking for class imbalance. Following this, it will analyze the image properties both through the metadata (dimensions) and by sampling actual image files to calculate pixel statistics and channel information. Finally, it will explore relationships between the available metadata features (like location and image size) and the target species using correlation metrics and a lightweight Random Forest model to identify potential location biases common in camera trap data.
