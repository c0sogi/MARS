This causes the model's output layer to be too small for the target labels, leading to an index out-of-bounds error during loss calculation (Cite debug_lesson_7).

To fix this, I will:
1.  Update `library/taxonomy.py` to expose a `get_num_species()` method.
2.  Modify `library/model.py` to accept `num_species_classes` as an argument and derive it dynamically from the taxonomy if not provided, removing the reliance on the hardcoded constant.
3.  Update `runfile.py` to pass the correct species count from the taxonomy instance to the model constructor.
