This is a known API change in Albumentations 2.0+. I will update the `RandomResizedCrop` instantiation in `library/dataset.py` to use `size=(image_size, image_size)`. I will not modify `CenterCrop` as it retains the legacy signature requiring explicit `height` and `width` arguments (Cite debug_lesson_1).
