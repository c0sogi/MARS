The following implementation orchestrates the hierarchical classification pipeline. It initializes the data loaders with a subset of data for a fast baseline execution, sets up the `HierarchicalEfficientNet` model, and runs the training loop using the provided `Trainer` class. After training, it evaluates the model on the validation set to calculate the Macro F1 score and performs failure analysis by correlating prediction errors with metadata features. Finally, it generates a submission file if the validation performance meets the specified threshold.
