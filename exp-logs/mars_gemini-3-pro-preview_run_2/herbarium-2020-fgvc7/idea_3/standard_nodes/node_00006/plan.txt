Additionally, the current configuration in `runfile.py` uses `num_workers=4` and `BATCH_SIZE=64`, which the provided Debug Lessons indicate will likely cause shared memory (`SIGBUS`) or system RAM (`OOM`) crashes in this environment.

To fix this:
1.  I will modify `library/dataset.py` to reference the metadata CSV files using their correct paths in the `./metadata` folder.
2.  I will update `runfile.py` to set `num_workers=0` (Cite debug_lesson_1) and reduce `BATCH_SIZE` to 32 (Cite debug_lesson_2) to ensure the training loop runs stably without resource exhaustion.
