The following script demonstrates the end-to-end workflow for the plant species classification task using the provided library modules.

**Implementation Strategy:**
1.  **Configuration**: Initialize the `Config` class with `debug=True`. This drastically reduces the dataset size (to 2000 samples) and training duration (2 epochs), ensuring the script executes quickly for demonstration purposes.
2.  **Data Preparation**: Use `get_dataloaders` to load the training, validation, and test data. We verify the data loading process by checking batch shapes.
3.  **Model Setup**: Instantiate the Swin Transformer model using `get_model`. We verify the model is correctly placed on the GPU and has the correct output dimension matching the number of classes.
4.  **Training**: Configure the AdamW optimizer and Cosine Annealing scheduler. Instantiate the `Trainer` class and execute the `fit` method to train the model. We verify that model artifacts (checkpoints) are created.
5.  **Inference**: Execute the `predict` method to generate predictions on the test set. We verify the output submission file exists and follows the required format.
