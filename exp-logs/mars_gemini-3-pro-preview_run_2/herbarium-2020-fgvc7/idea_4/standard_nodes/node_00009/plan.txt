The `CUDA error: device-side assert triggered` is caused by the `FocalLoss` function receiving target labels that are out of the valid index range `[0, num_classes - 1]`. The dataset uses raw `category_id`s (e.g., taxonomy IDs like 15672) which are not contiguous integers starting from 0. When `FocalLoss` attempts to gather log probabilities using these raw IDs as indices, it triggers an assertion failure on the GPU.

To fix this, I will:
1.  **Create a Label Map**: In `library/dataset.py`, calculate a mapping from raw `category_id` to contiguous indices `[0, num_classes-1]` using the training metadata.
2.  **Update Dataset**: Modify `HerbariumDataset` to accept this map and transform labels in `__getitem__`.
3.  **Update Data Loading**: Modify `get_dataloaders` to generate the map, pass it to the datasets, and return the inverse map (index -> raw ID).
4.  **Update Trainer**: Modify `Trainer` to accept the inverse map and use it in `predict` to convert model predictions (indices) back to raw `category_id`s for the submission file.
5.  **Update Runfile**: Propagate the map from `get_dataloaders` to `Trainer`.
