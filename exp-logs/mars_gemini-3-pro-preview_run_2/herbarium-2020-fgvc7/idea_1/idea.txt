To establish a reliable and efficient baseline for this fine-grained classification task, I propose a solution based on a standard Convolutional Neural Network (CNN) trained with a class-aware sampling strategy. This approach avoids the complexity of metric learning, hybrid ensembles, or heavy transformer architectures, focusing instead on a robust implementation of standard supervised learning.

### Model
The core architecture will be a **ResNet-34**.
*   **Design**: This model serves as a middle ground between the lighter ResNet-18 (used in the hybrid proposal) and the heavier ResNet-50 (used in the metric learning proposal). It provides sufficient depth to capture the subtle visual features required for fine-grained species identification without the computational overhead of larger backbones.
*   **Head**: The network will be terminated with a standard Global Average Pooling layer followed by a single Fully Connected (Linear) layer mapping the 512-dimensional feature vector directly to the 32,093 class logits.
*   **Initialization**: The backbone will be initialized with weights pre-trained on ImageNet to facilitate faster convergence.

### Data
*   **Preprocessing**: All images will be resized to a standard resolution of **224x224** pixels. This resolution balances training speed with the preservation of visual details.
*   **Augmentation**:
    *   **Training**: Apply Random Resized Crop and Random Horizontal Flip to introduce invariance to scale and orientation.
    *   **Evaluation**: Resize the image to 256 pixels along the shorter side and take a Center Crop of 224x224 pixels.
*   **Sampling Strategy**: To address the extreme class imbalance (long tail) and optimize for the **Macro F1 score**, a **Weighted Random Sampler** will be used during training. This sampler will draw images with replacement, where the probability of drawing an image is inversely proportional to the frequency of its class. This ensures that each training batch contains a relatively balanced distribution of rare and frequent species.

### Training
*   **Loss Function**: Standard **Cross-Entropy Loss**. While simple, it is highly effective when combined with the balanced sampling strategy described above.
*   **Optimizer**: **AdamW** optimizer will be used to decouple weight decay from gradient updates, promoting better generalization.
*   **Scheduler**: A **Cosine Annealing** learning rate scheduler will be employed to smoothly decay the learning rate, helping the model settle into a robust minimum.
*   **Compute Efficiency**: Training will utilize **Automatic Mixed Precision (AMP)** on the NVIDIA A100 GPU. This reduces memory usage and increases throughput, allowing for larger batch sizes and faster iteration times.

### Evaluation
*   **Inference**: For the test set, images will be processed using the evaluation preprocessing steps (Resize + Center Crop).
*   **Prediction**: The model will output a probability distribution over the 32,093 classes. The predicted class will be the index corresponding to the maximum logit (Argmax). No region metadata will be used during inference, ensuring the pipeline remains robust even if such metadata is unavailable or unreliable for test samples.
