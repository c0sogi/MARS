The following script demonstrates the usage of the provided library files to train a plant species classification model. It performs the following steps:

1.  **Configuration Override**: Modifies the default `Config` to run in debug mode with a small subset of data and reduced training epochs for speed.
2.  **Data Preparation**: Initializes the logger, sets random seeds, and prepares data loaders using `library.data`. It leverages existing taxonomy mappings if available to save time.
3.  **Model Initialization**: Instantiates the `HerbariumNet` model from `library.model` (using random initialization to avoid downloads).
4.  **Loss Function**: Sets up the `TaxonomicFocalLoss` from `library.loss` and verifies its computation.
5.  **Training Loop**: Executes a single epoch of training using the `fit` function from `library.train` and validates the results.
6.  **Verification**: Includes assertions throughout to ensure tensor shapes, data types, and file outputs are correct.
