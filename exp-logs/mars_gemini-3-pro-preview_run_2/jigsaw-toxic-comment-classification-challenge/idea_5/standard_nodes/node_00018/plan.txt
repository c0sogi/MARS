Implementation strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided modules. Set random seeds for reproducibility. Override `Config.EPOCHS` to 1 and `Config.AWP_START_EPOCH` to 0 to ensure the pipeline completes within the 2-hour limit while maximizing performance per epoch.
2.  **Linear Model (Branch C)**: Execute the `train_linear_pipeline` to get baseline predictions for validation and test sets. This uses the cached TF-IDF features.
3.  **Transformer Training (Branches A & B)**: Implement a reusable `run_transformer` function that:
    *   Initializes the tokenizer and model (DeBERTa-v3-Large or RoBERTa-Large).
    *   Creates DataLoaders.
    *   Sets up the Optimizer, Scheduler, and AWP (Adversarial Weight Perturbation).
    *   Runs the training loop for the configured epochs (1 epoch).
    *   Runs validation and inference.
    *   Returns predictions.
4.  **Ensemble**: Collect predictions from all three branches (Linear, DeBERTa, RoBERTa). Use Nelder-Mead optimization (`find_optimal_weights`) to determine the best blending weights based on the validation set.
5.  **Evaluation**: Calculate the final weighted validation score. Print it in the required format.
6.  **Failure Analysis**: Compute the mean absolute error for each validation sample and calculate its Pearson correlation with the character length of the comment.
7.  **Submission**: If the validation score exceeds the threshold (0.99273...), blend the test predictions using the optimal weights and save the result to `./submission/submission.csv`.
