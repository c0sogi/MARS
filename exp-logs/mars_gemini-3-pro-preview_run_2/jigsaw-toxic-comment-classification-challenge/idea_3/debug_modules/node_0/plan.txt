This script demonstrates the usage of the provided library modules for the Toxicity Prediction task. It validates the data loading pipeline, model initialization, training loops (using a lightweight Transformer for speed), the linear baseline, and the ensemble optimization logic.

The strategy involves:
1.  **Configuration Override**: Enabling `debug` mode and reducing epochs to ensure the script runs quickly (using a subset of data and a tiny model).
2.  **Component Verification**: Systematically instantiating and testing the Data Loader, Transformer Model, Linear Model, and Ensemble modules.
3.  **Integration Test**: Running a complete (but miniaturized) training and inference cycle to verify the pipeline's integrity.
