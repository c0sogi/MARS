# Proposed Baseline Approach

I propose a **Logistic Regression model with Dual TF-IDF Features** (Word and Character N-grams). This approach synthesizes the efficiency of linear models with robust feature extraction to handle the specific challenges of toxic comment classification, such as misspellings and obfuscation, without requiring heavy compute resources.

### Model
The core architecture is a **One-Vs-Rest Logistic Regression** framework.
*   **Feature Representation**: The model will utilize a concatenated sparse feature matrix derived from two distinct TF-IDF (Term Frequency-Inverse Document Frequency) vectorizers:
    1.  **Word N-grams**: Captures semantic meaning and specific toxic phrases (e.g., unigrams and bigrams).
    2.  **Character N-grams**: Captures subword patterns, which is critical for detecting obfuscated toxicity (e.g., "f*ck", "sh!t") and morphological variations (e.g., 2-grams to 6-grams).
*   **Classifier**: Six independent Logistic Regression classifiers will be instantiated, one for each target label (`toxic`, `severe_toxic`, `obscene`, `threat`, `insult`, `identity_hate`). This treats the multi-label problem as six independent binary classification tasks.

### Data
1.  **Preprocessing**: 
    *   Fill any missing values in the `comment_text` column with empty strings.
    *   Lowercase all text to ensure case-insensitivity.
    *   (Optional) Strip basic special characters if they do not contribute to the character n-gram signal, though TF-IDF handles this implicitly.
2.  **Vectorization**:
    *   Fit a **Word TF-IDF Vectorizer** on the training corpus (filtering out extremely rare words via `min_df`) and transform both train and test data.
    *   Fit a **Character TF-IDF Vectorizer** on the training corpus (focusing on a window of characters, e.g., 2 to 6) and transform both train and test data.
    *   Concatenate the resulting sparse matrices horizontally to create the final input dataset.

### Training
1.  **Procedure**: Iterate through each of the six toxicity labels. For each label, train a separate Logistic Regression model using the concatenated TF-IDF features as input and the specific label column as the binary target.
2.  **Loss Function**: Minimize **Binary Cross-Entropy (Log Loss)**, which naturally optimizes the output probabilities required for the ROC AUC metric.
3.  **Optimization**: Use a solver optimized for high-dimensional sparse data (e.g., `liblinear`, `sag`, or `lbfgs`) to ensure rapid convergence.

### Evaluation
1.  **Inference**: Transform the raw text of the test set using the pre-fitted Word and Character TF-IDF vectorizers and concatenate them.
2.  **Prediction**: Pass the transformed test features through each of the six trained Logistic Regression models. Extract the predicted probability of the positive class (class `1`) for each label.
3.  **Submission**: Aggregate the `id` column and the six predicted probability columns into a CSV file matching the submission format.
