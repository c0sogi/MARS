The `torch.OutOfMemoryError` during the TAPT phase indicates that the GPU memory (approx. 16GB available) is insufficient for the `deberta-v3-base` model when training with a batch size of 32 in full FP32 precision. To resolve this, I will implement Mixed Precision training in `library/tapt_trainer.py` using `torch.cuda.amp` (Automatic Mixed Precision), which significantly reduces memory usage by storing activations and gradients in half-precision where possible. Additionally, I will reduce the TAPT batch size in `library/config.py` from 32 to 8 to ensure the process fits comfortably within the hardware limits.
