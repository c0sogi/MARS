The following script demonstrates the usage of the provided machine learning library for the toxicity classification task. It follows a logical pipeline:
1.  **Configuration & Setup**: Modifies the global `Config` to run in a lightweight "debug" mode (fewer samples, 1 epoch, tiny model) to ensure rapid execution.
2.  **Data Processing**: Demonstrates loading raw data and generating TF-IDF features.
3.  **Linear Baseline**: Trains the Logistic Regression wrapper on the TF-IDF features and verifies predictions.
4.  **Task-Adaptive Pretraining (TAPT)**: Runs a short cycle of Masked Language Modeling on a tiny transformer (`prajjwal1/bert-tiny`) to demonstrate the domain adaptation workflow.
5.  **Supervised Fine-Tuning**: Fine-tunes the transformer model using the supervised trainer and generates validation/test predictions.
6.  **Ensemble & Submission**: Simulates an ensemble step by optimizing weights between the Linear and Transformer models, blending their predictions, and generating a submission file.
