Based on the provided model architectures and the requirement for a distinct, efficient baseline, I propose **Idea 4**, which implements the **Model 3** architecture (Superpixel + Classification). This approach diverges from the Deep Learning paradigms (U-Net, Transformer, DeepLab) used in the previous ideas, establishing a classical machine learning baseline that prioritizes low resource usage and interpretability.

### Idea 4: Superpixel-based LightGBM Segmentation

#### Model
The architecture is a two-stage hybrid pipeline that combines unsupervised computer vision with gradient boosting. It avoids the heavy computational cost of convolutional or attention layers by operating on "superpixels" (clusters of similar pixels) rather than individual pixels.

1.  **Unsupervised Segmentation (Superpixels):**
    *   The 2.5D input image is partitioned into perceptually meaningful regions using the **SLIC (Simple Linear Iterative Clustering)** algorithm (or a similar clustering method available in OpenCV, such as K-Means on spatial+color space).
    *   This step reduces the problem dimensionality from ~65,000 pixels (256x256) to approximately 1,000 superpixels per slice, grouping pixels that are likely to belong to the same organ.

2.  **Feature Extractor:**
    *   For each superpixel, we extract a lightweight, deterministic feature vector.
    *   **Intensity Features:** Mean and Variance of pixel intensities within the superpixel. Crucially, to incorporate **2.5D context**, we also calculate the mean intensity of the pixels at the *same spatial coordinates* in the superior ($i-1$) and inferior ($i+1$) slices.
    *   **Spatial Features:** The normalized $(x, y)$ centroid coordinates of the superpixel, providing the classifier with anatomical location priors (e.g., the stomach is usually in the upper-left quadrant).

3.  **Classifier:**
    *   A **LightGBM** (Gradient Boosting Machine) classifier takes the feature vector of a superpixel and predicts its class probabilities (Background, Large Bowel, Small Bowel, Stomach). LightGBM is selected for its extreme training speed and memory efficiency compared to neural networks.

#### Data
Preprocessing transforms the image dataset into a tabular dataset suitable for the gradient boosting classifier.

1.  **2.5D Volume Construction:** Similar to previous ideas, we form 3-channel stacks (Slice $i-1$, Slice $i$, Slice $i+1$) for every slice to ensure volumetric context is available during feature extraction.
2.  **Normalization:** Images are Min-Max normalized to the $[0, 1]$ range to standardize intensity features.
3.  **Tabular Dataset Generation (Training Only):**
    *   We iterate through the training images and generate superpixels.
    *   For each superpixel, we compute the feature vector described above.
    *   **Label Assignment:** The ground truth label for a superpixel is determined by a **majority vote** of the pixel masks contained within it.
    *   **Balancing:** Since "Background" superpixels vastly outnumber organ superpixels, we perform random downsampling of the background class (e.g., keeping only 25% of background samples) to create a balanced tabular dataset.

#### Training
Training focuses on optimizing the decision trees on the structured tabular data.

*   **Algorithm:** LightGBM Classifier.
*   **Loss Function:** **Multi-class Log Loss** (Cross Entropy for tabular data).
*   **Optimization:** We use a simple train/validation split (grouped by Case ID) to monitor the Log Loss. Training stops when the validation loss fails to improve for a set number of rounds (Early Stopping).
*   **Speed:** Unlike CNNs which require epochs of GPU time, LightGBM typically converges in minutes on a CPU, making this an extremely fast baseline to develop.

#### Evaluation
Inference reconstructs the segmentation masks from the classified superpixels.

1.  **Superpixel Generation:** Apply the same segmentation algorithm (SLIC/K-Means) to the test slice.
2.  **Feature Extraction:** Compute the feature vectors for the test superpixels.
3.  **Prediction:** Pass vectors through the trained LightGBM model to get class probabilities.
4.  **Mask Reconstruction:** "Paint" the original image pixels with the predicted class of their corresponding superpixel.
5.  **3D Post-Processing:** To satisfy the Hausdorff distance metric, we stack the predicted 2D masks into a 3D volume. We apply **3D Connected Component Analysis**, retaining only the largest connected volume for each organ class and removing smaller floating artifacts.
6.  **Submission:** The cleaned masks are converted to Run-Length Encoding (RLE).
