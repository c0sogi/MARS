This script demonstrates the end-to-end pipeline for the MRI segmentation task using the provided library modules. It performs the following steps:

1.  **Configuration Overrides**: Modifies hyperparameters in `library.config` (e.g., image size, number of superpixels, boosting rounds) to ensure the demonstration runs quickly.
2.  **Data Processing**: Manually loads a single case from the training metadata and processes it using `library.data_processing` to generate superpixel features and labels. This simulates the dataset creation process without processing the entire dataset.
3.  **Model Training**: Trains the LightGBM model defined in `library.model` using the generated features. It verifies that the model fits and produces a valid validation score.
4.  **Inference**: Runs the inference pipeline on a single test case using `library.model._process_volume_inference`. It checks that the output contains the expected RLE-encoded predictions.
5.  **Post-Processing & Metrics**: Validates the RLE encoding/decoding logic and the 3D post-processing function (`clean_3d_volume`) using synthetic data to ensure correctness.
