Here is the implementation strategy and the complete Python script for the Exploratory Data Analysis.

### Implementation Strategy

1.  **Setup and Data Loading**:
    -   Initialize the environment with fixed random seeds for reproducibility.
    -   Load the training metadata from `./metadata/train_metadata.csv`.
    -   Verify the dataframe structure and clean any potential missing values in the segmentation column (treating NaNs as empty masks).

2.  **Target Variable Analysis (Segmentation Masks)**:
    -   **Proxy Generation**: Since the target is a run-length encoded (RLE) mask, we will derive two proxy targets for analysis:
        -   `has_mask` (Binary): Whether a mask exists for the given class/slice.
        -   `mask_area` (Numerical): The total number of pixels covered by the mask (sum of run lengths).
    -   **Distribution**: Calculate the frequency of masks per organ class (`large_bowel`, `small_bowel`, `stomach`).
    -   **Imbalance**: Report the ratio of empty vs. non-empty slices.

3.  **Input Data Analysis (Image Modality)**:
    -   **Metadata Analysis**: Analyze the distribution of image dimensions (`img_width`, `img_height`) and physical properties (`pixel_spacing`).
    -   **Content Analysis (Sampling)**:
        -   Randomly sample 500 images from the training set to keep runtime low.
        -   Load images using `cv2` (handling potential 16-bit PNGs).
        -   Analyze channel counts (grayscale vs. RGB) and bit depth.
        -   Calculate global pixel mean and standard deviation.

4.  **Feature/Signal Relationships**:
    -   **Structured Relationships**:
        -   Treat metadata fields (`slice`, `day`, `pixel_spacing`, `img_width`) as features.
        -   Calculate correlations between these features and the `mask_area`.
        -   Train a lightweight Random Forest Classifier to predict `has_mask` using metadata features to identify which scan parameters (e.g., slice position) are most predictive of organ presence.
    -   **Meta-Feature Analysis**: Investigate if specific slice indices or days correlate with larger mask areas.

5.  **Reporting**:
    -   Output the results in the requested format with capitalized sections and specific floating-point formatting.
