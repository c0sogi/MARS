### Idea 6: LinkNet with Additive Skip Connections

#### Model
I propose a **LinkNet** architecture, a highly efficient encoder-decoder model that offers a distinct structural alternative to the U-Net (Idea 1) and DeepLab (Idea 3) baselines. While U-Net relies on heavy concatenation operations that double feature channels, LinkNet is designed to minimize parameters and latency.

*   **Encoder (Backbone):** The model uses a lightweight **ResNet-18** backbone pre-trained on ImageNet. This provides a robust feature extractor that utilizes residual blocks to prevent vanishing gradients, while being significantly faster than the EfficientNet or MiT backbones used in other ideas.
*   **Decoder:** The defining characteristic of LinkNet is its **Additive Skip Connections**. Instead of concatenating encoder and decoder feature maps (which increases memory usage and computational cost), LinkNet directly **adds** the encoder's feature maps to the corresponding upsampled decoder maps. This fuses high-level semantic information with low-level spatial details without increasing the channel depth.
*   **Head:** A final convolution layer maps the recovered spatial features to the class probabilities (Large Bowel, Small Bowel, Stomach, Background).
*   **Input:** The model accepts **2.5D inputs** (3 channels: Slice $i-1$, Slice $i$, Slice $i+1$) to incorporate volumetric context into the efficient 2D architecture.

#### Data
The data preparation strategy prioritizes speed and standardizing the input distribution for the ResNet backbone.

1.  **2.5D Stack Generation:** For every slice, construct a 3-channel input comprising the target slice and its immediate superior and inferior neighbors. Use replication padding for the first and last slices of a scan.
2.  **Normalization:** Apply **Min-Max Normalization** to scale pixel intensities to the range $[0, 1]$. This is crucial for MRI data where raw intensity values can vary largely between machines.
3.  **Resizing:** Resize all images to a fixed resolution of **256x256** pixels. This resolution is sufficient for the ResNet-18 encoder to capture organ shapes while keeping training and inference extremely fast.
4.  **Balanced Sampling:** Construct the training set using all slices containing masks and a random subset (e.g., 50%) of background-only slices to maintain a manageable epoch time while addressing class imbalance.

#### Training
The training pipeline focuses on stability and optimizing the competition metric directly.

*   **Loss Function:** A composite **BCE + Dice Loss** is used. Binary Cross Entropy provides smooth gradient descent for pixel classification, while Dice Loss prevents the model from getting stuck in local minima where it simply predicts "background" for everything.
*   **Optimizer:** **Adam** is used for its adaptive learning rate capabilities, ensuring fast convergence without extensive hyperparameter tuning.
*   **Scheduler:** A **Cosine Annealing** scheduler is implemented to aggressively reduce the learning rate towards the end of training, refining the weights for maximum precision.
*   **Augmentation:** To maintain the "lightweight" philosophy, only computationally cheap augmentations are used: Random Horizontal/Vertical Flips and 90-degree Rotations.

#### Evaluation
The evaluation process includes a specific post-processing step to minimize the Hausdorff distance error.

1.  **Inference:** The model generates 2D probability maps for every slice in the test set using the 2.5D input format.
2.  **Thresholding:** A standard threshold (0.5) is applied to binarize the predictions.
3.  **3D Connected Component Analysis:** To optimize the **3D Hausdorff distance**, the predicted 2D masks are stacked into 3D volumes. For each class, a connected component analysis is performed to identify distinct 3D objects. We **retain only the largest connected component** and discard smaller floating artifacts (noise), which disproportionately penalize the Hausdorff metric.
4.  **Submission:** The refined masks are converted to Run-Length Encoding (RLE) for the final submission.
