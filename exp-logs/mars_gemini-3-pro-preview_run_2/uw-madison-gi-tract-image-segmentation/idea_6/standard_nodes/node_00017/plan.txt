The `InvalidSubmissionError` is caused by the submission file rows being ordered numerically by case ID (inherited from the processing pipeline) rather than lexicographically by the `id` string, which is the standard expectation for evaluation systems. This mismatch leads the grader to incorrectly aggregate slices from different cases—often with different spatial dimensions—into the same volume, resulting in shape mismatch errors. To fix this, I will modify `library/inference.py` to explicitly sort the submission DataFrame by `id` and `class` before saving it to CSV. Cite debug_lesson_5.
