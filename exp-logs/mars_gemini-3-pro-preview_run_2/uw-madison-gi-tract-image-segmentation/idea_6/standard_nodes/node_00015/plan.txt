Implementation strategy:
1.  **Configuration**: Import `Config` and override parameters for a fast baseline execution. Set `EPOCHS` to 5 and `BATCH_SIZE` to 128 to utilize the A100 GPU efficiently and complete within the time limit.
2.  **Training**: Call the provided `train()` function from `library.train`. This handles data loading, model training, and checkpointing.
3.  **Validation & Metrics**:
    *   Load the trained model and the validation metadata.
    *   Perform inference on the validation set.
    *   Group 2D predictions into 3D volumes (by case and day) to match the competition metric requirements.
    *   Calculate the Dice coefficient and 3D Hausdorff distance for each volume using the provided utility functions.
    *   Compute the weighted composite metric: $0.4 \times \text{Dice} + 0.6 \times (1 - \text{Hausdorff})$.
    *   Print the final metric in the required format.
4.  **Failure Analysis**:
    *   Calculate the error magnitude (defined as $1 - \text{Dice}$) for each predicted object.
    *   Compute the correlation between this error and the object's size (total mask volume).
    *   Print the correlation coefficient.
5.  **Submission**: Call `run_inference()` from `library.inference` to generate predictions for the test set and save the `submission.csv`.
