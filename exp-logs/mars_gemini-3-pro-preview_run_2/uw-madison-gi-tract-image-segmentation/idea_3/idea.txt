### Idea 3: 2.5D DeepLabV3+ with ASPP

### Model
I propose a **2.5D DeepLabV3+** architecture, directly synthesizing the design principles of **Model 5**. This approach offers a distinct structural philosophy from the U-Net (Idea 1) and Transformer (Idea 2) baselines by relying on dilated convolutions and multi-scale context pooling rather than deep decoder pathways or self-attention.

*   **Backbone (Encoder):** The model employs a **MobileNetV2** backbone pre-trained on ImageNet. Crucially, unlike the U-Net approach, we modify the backbone to use **Dilated (Atrous) Convolutions** in the final blocks. This maintains a higher spatial resolution (Output Stride of 16) throughout the encoder, preventing the loss of fine spatial details associated with aggressive downsampling.
*   **Context Module:** The core component is the **Atrous Spatial Pyramid Pooling (ASPP)** module. This module applies parallel convolutions with different dilation rates (e.g., 6, 12, 18) to the backbone's feature map. This allows the model to capture context at multiple effective fields of view simultaneously—essential for segmenting intestines which vary drastically in shape and scale—without increasing the parameter count.
*   **Decoder:** We utilize a **Lightweight DeepLab Decoder**. Instead of the heavy, multi-stage upsampling of U-Net, this decoder performs a single concatenation step: it fuses the upsampled ASPP features with low-level features (from an earlier stage of the backbone) to refine boundaries, followed by a final upsampling to the input resolution.
*   **Input:** The model processes **2.5D inputs** (3 channels: Slice $i-1$, Slice $i$, Slice $i+1$) to incorporate volumetric information into the 2D segmentation process.

### Data
The data preparation prioritizes consistency and memory efficiency to establish a stable baseline.

1.  **2.5D Volume Construction**: For each target slice, we construct a 3-channel image containing the target slice flanked by its superior and inferior neighbors. Replicate padding is used for the first and last slices of a scan.
2.  **Global Min-Max Normalization**: To handle the variable intensity ranges of MRI scans, we apply min-max normalization to each 3-channel stack, scaling pixel values to the range $[0, 1]$.
3.  **Standardized Resizing**: All input images are resized to a fixed resolution of **256x256**. This resolution balances the receptive field requirements of the ASPP module with computational speed.
4.  **Stratified Sampling**: The training set is constructed to include all positive samples (slices with masks) and a fixed percentage (e.g., 20%) of negative samples (background only) to maintain training efficiency while exposing the model to empty contexts.

### Training
The training strategy is designed for robust convergence using standard, well-understood techniques.

*   **Loss Function**: We employ a composite **BCE + Dice Loss**. Binary Cross Entropy handles the pixel-level classification accuracy, while Dice Loss ensures the model optimizes the intersection-over-union metric directly.
*   **Optimizer**: **AdamW** is selected for its effective handling of weight decay, ensuring the MobileNet weights do not drift excessively during fine-tuning.
*   **Scheduler**: A **Step Decay** learning rate scheduler is used (reducing the learning rate by a factor of 0.1 at fixed epochs). This simple schedule is often more stable for CNNs with ASPP modules than aggressive cosine annealing.
*   **Augmentation**: We apply only rigid geometric augmentations: Random Rotations ($\pm 15^\circ$) and Horizontal/Vertical Flips.

### Evaluation
Evaluation focuses on cleaning up the prediction to maximize the Hausdorff distance score.

1.  **Inference**: The model predicts class probabilities for every slice in the test set using the 2.5D input format.
2.  **Thresholding**: A standard confidence threshold (0.5) is applied to generate binary masks.
3.  **3D Noise Removal**: To improve the 3D Hausdorff metric, we treat the stack of 2D predictions as a 3D volume. We apply a **Minimum Volume Threshold**: for each class, any connected component (3D blob) smaller than a specific voxel count (e.g., 100 voxels) is removed. This eliminates small, scattered false positives that disproportionately penalize the Hausdorff distance.
4.  **Submission**: The cleaned masks are converted to Run-Length Encoding (RLE) for submission.
