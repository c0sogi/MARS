This script demonstrates the end-to-end usage of the provided machine learning library for MRI segmentation. It performs the following steps:
1.  **Setup**: Overrides default configuration parameters (epochs, batch size, directories) to ensure the demonstration runs quickly and stores outputs in a specific demo directory.
2.  **Utility Verification**: Validates the Run-Length Encoding (RLE) logic by encoding a synthetic mask and decoding it back to ensure data integrity.
3.  **Dataset Verification**: Instantiates the `UWMadisonDataset`, loads a sample, and verifies the input tensor shapes (2.5D image stack) and target mask shapes.
4.  **Model Verification**: Instantiates the `DeepLabV3Plus` model, performs a forward pass with dummy data, and asserts the output dimensions match the expected segmentation map size.
5.  **Loss Function Verification**: Calculates the combined BCE + Dice loss on synthetic predictions to ensure the loss function returns a valid scalar.
6.  **Training Pipeline**: Executes a single epoch of training in debug mode (using a data subset) to verify the training loop and checkpoint generation.
7.  **Inference Pipeline**: Runs the inference pipeline on the test set (debug mode), performing 3D post-processing and generating a submission file in the required format.
