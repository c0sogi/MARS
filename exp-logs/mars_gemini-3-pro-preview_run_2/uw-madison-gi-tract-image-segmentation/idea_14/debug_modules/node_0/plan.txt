The following is a complete, self-contained Python script demonstrating the usage of the provided machine learning library for the stomach and intestine segmentation task.

The script performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to run in a lightweight "demo" mode (fewer epochs, small sample size, specific working directory) to ensure quick execution.
2.  **Dataset Verification**: Instantiates the `UWMadisonDataset`, validates the 2.5D image stacking (3 channels), physical space normalization, and mask loading logic using assertions.
3.  **Model Initialization**: Initializes the `HRNetSegmentation` model (without pre-trained weights for speed/offline safety) and validates the forward pass output shapes.
4.  **Loss Function Check**: Computes the `BCETverskyLoss` on a dummy batch to verify gradient flow and loss calculation.
5.  **Training Loop Simulation**: Runs a single training epoch and a validation step using the library's training functions to demonstrate the training pipeline.
6.  **Inference & Post-processing**: Demonstrates the sliding window inference logic and 3D post-processing (Largest Connected Component) on a sample volume.
7.  **Utility Verification**: Verifies the correctness of Run-Length Encoding (RLE) functions by performing a round-trip encode/decode test.
