The `timm` library uses underscores rather than hyphens for its model registry names (e.g., `efficientnet_b0` instead of `efficientnet-b0`), causing a `RuntimeError` during model creation. To fix this, I will correct the model name in `library/config.py`. Additionally, because the Python environment is persistent and the `Config` class may already be loaded in memory with the old value, I will explicitly update `Config.ENCODER_NAME` in `runfile.py` before the model is instantiated. This ensures the correct configuration is used without requiring a runtime restart, applying the principle from Cite debug_lesson_5.

```diff
library/config.py
<<<<<<< SEARCH
    ENCODER_NAME = "efficientnet-b0"
=======
    ENCODER_NAME = "efficientnet_b0"
>>>>>>> REPLACE
```

```diff
runfile.py
<<<<<<< SEARCH
    Config.DEBUG_SAMPLE_SIZE = 20  # Very small number of samples for training loop

    # Setup directories based on new config
=======
    Config.DEBUG_SAMPLE_SIZE = 20  # Very small number of samples for training loop
    Config.ENCODER_NAME = "efficientnet_b0"

    # Setup directories based on new config
>>>>>>> REPLACE
```
