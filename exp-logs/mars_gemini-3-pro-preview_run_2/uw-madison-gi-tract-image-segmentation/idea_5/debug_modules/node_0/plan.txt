### Implementation Strategy

1.  **Environment Setup**: Set random seeds for reproducibility and configure paths using the provided `Config` class.
2.  **Utility Verification**:
    *   **RLE Encoding/Decoding**: Create a synthetic binary mask, encode it to RLE, decode it back, and assert that the reconstruction is identical to the original.
    *   **Metrics**: Create synthetic 3D volumes (ground truth and prediction) to verify `dice_coefficient` and `hausdorff_distance_3d`. Check edge cases like empty masks.
    *   **Post-processing**: Create a 3D mask with two disconnected components (one large, one small) and verify that `keep_largest_connected_component_3d` removes the smaller noise artifact.
3.  **Data Processing Demonstration**:
    *   Load the training metadata to select a valid image file path.
    *   Demonstrate `load_and_preprocess_image` to ensure image normalization and resizing work as expected.
    *   Demonstrate `generate_search_vector` to confirm the dimensionality reduction for the retrieval system.
4.  **Retrieval System Workflow**:
    *   Instantiate the `AtlasSegmenter` class.
    *   Run `fit()` in `debug=True` mode. This limits the processing to a small subset of cases (2 cases) to ensure the demo runs quickly (within seconds/minutes) while still exercising the full pipeline (loading, resizing, vectorizing, caching).
    *   Select a validation image that was *not* in the debug training set (if possible) or just a sample image to simulate inference.
    *   Run `predict_slice()` to retrieve similar masks from the atlas and fuse them.
    *   Validate the output shape and value range of the prediction.
5.  **Execution**: The script runs all steps sequentially, printing status updates and validation confirmations.
