The implementation strategy follows the retrieval-based Multi-Atlas Segmentation approach (Idea 5) outlined in the description.

1.  **Setup & Initialization**: We set random seeds for reproducibility and initialize the `AtlasSegmenter` class. We call `fit()` to load the pre-processed atlas index (vectors, masks, and metadata) from the cache.
2.  **Validation Loop**:
    *   We load the validation metadata and group it by `case` and `day` to process full 3D scans.
    *   For each case, we iterate through its slices sorted by slice index.
    *   We predict the segmentation mask for each slice using the `AtlasSegmenter`, which retrieves similar slices from the training set based on visual similarity and relative depth, then applies majority voting.
    *   The 2D predictions are stacked into a 3D volume. We apply `keep_largest_connected_component_3d` to remove noise.
    *   We compute the Dice coefficient and 3D Hausdorff distance against the ground truth. The final metric is calculated as $0.4 \times \text{Dice} + 0.6 \times (1 - \text{Hausdorff})$.
    *   We collect slice-level performance data (2D Dice) for failure analysis.
3.  **Failure Analysis**: We calculate and print correlations between the model's error (1 - Dice) and features like relative depth and image dimensions to identify systematic weaknesses.
4.  **Inference & Submission**:
    *   We load the test metadata and group by case/day.
    *   We repeat the prediction and 3D post-processing steps for the test set.
    *   The final binary masks are converted to Run-Length Encoding (RLE).
    *   We format the output to match the submission requirements (header, columns) and save it to `submission.csv`.
