Here is a proposal for a highly efficient baseline approach, distinct from the previous idea.

### Model
I propose a **Lightweight SegFormer** architecture, synthesizing the design principles of **Model 2**. This approach shifts from the CNN-based U-Net paradigm to a Transformer-based design that is optimized for efficiency.

*   **Encoder (Backbone):** The model utilizes the **MiT-B0 (Mix Transformer)** encoder. Unlike standard CNNs, this hierarchical transformer creates multi-scale feature maps at resolutions of 1/4, 1/8, 1/16, and 1/32. It employs efficient self-attention mechanisms and overlapping patch embeddings to capture both local details and global context with significantly fewer parameters than ResNet or EfficientNet backbones.
*   **Decoder:** The architecture employs the **"All-MLP" Decoder**. This design completely abandons the computationally expensive transposed convolutions and skip connections found in U-Net. Instead, it processes the multi-level features from the encoder using simple Multilayer Perceptrons (MLPs) to unify their channel dimensions. These features are then upsampled to a common resolution (1/4th of the original image) via bilinear interpolation and concatenated.
*   **Head:** The fused feature map is passed through a final MLP layer to predict the segmentation masks for the three classes (Large Bowel, Small Bowel, Stomach) and the background.
*   **Input:** The model accepts **2.5D inputs** (3 channels: Slice $i-1$, Slice $i$, Slice $i+1$) to provide essential volumetric context to the 2D transformer.

### Data
The data preparation strategy focuses on maximizing the signal-to-noise ratio for the transformer while maintaining low latency.

1.  **2.5D Stack Generation**: For every target slice, a 3-channel image is created using the slice itself and its immediate superior and inferior neighbors. Boundary slices (top/bottom of a scan) use replication padding.
2.  **Intensity Normalization**: MRI scans have arbitrary intensity units. We apply **Instance Min-Max Normalization**, scaling the pixel values of each 3-channel stack to the range $[0, 1]$ based on the minimum and maximum values within that specific stack. This ensures the model is robust to intensity shifts between different cases.
3.  **Resizing**: All inputs are resized to **256x256** pixels. This resolution is sufficient for the MiT-B0 encoder to resolve organ boundaries while keeping memory usage low.
4.  **Balanced Sampling**: To ensure efficient training epochs, we construct the training set using all slices that contain organ masks and a random subsample of background-only slices (e.g., a 1:1 ratio of positive to negative samples).

### Training
The training pipeline is designed to handle the specific convergence properties of transformers and the class imbalance of the dataset.

*   **Loss Function**: We employ a combination of **Focal Loss** and **Dice Loss**. Unlike standard Cross-Entropy, Focal Loss dynamically scales the loss based on prediction confidence, focusing the model's learning on "hard" examples (organ boundaries) rather than the easy background.
*   **Optimizer**: **AdamW** is used to optimize the model, providing decoupled weight decay regularization.
*   **Scheduler**: We utilize a **Polynomial Learning Rate Decay** schedule (linear warmup followed by a polynomial decrease). This is the standard and most effective schedule for transformer-based segmentation models, offering a different convergence profile than Cosine Annealing.
*   **Augmentation**: Fast, non-destructive augmentations are applied: random horizontal flips, vertical flips, and 90-degree rotations.

### Evaluation
The evaluation process includes a specific post-processing step to optimize the Hausdorff distance metric.

1.  **Inference**: The model generates probability maps for each slice in the test set using the 2.5D input format.
2.  **Thresholding**: Probabilities are binarized using a fixed threshold (e.g., 0.5).
3.  **3D Connected Component Analysis**: Since the metric includes 3D Hausdorff distance, isolated 2D predictions can severely hurt the score. We stack the predicted 2D masks into a 3D volume for each case. For each class, we identify all 3D connected components and **retain only the largest component**, discarding smaller clusters of false positives.
4.  **Submission**: The refined 3D volumes are sliced back into 2D masks and converted to Run-Length Encoding (RLE) for the final submission.
