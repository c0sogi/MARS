### Implementation Strategy

1.  **Configuration Setup**: We will override the default `Config` class attributes to adapt the pipeline for a quick demonstration. This includes reducing the number of epochs to 1, setting a small batch size, and redirecting output paths to a temporary `./working/demo` directory.
2.  **Dataset & Transforms**: We will use `prepare_data` to load the training metadata and instantiate the `UWMadisonDataset` class. We will verify the data loading process by asserting the shapes and types of the yielded tensors (image and mask).
3.  **Model & Loss Verification**: We will instantiate the `SegFormer` model and `ComboLoss`. We will perform a forward pass with dummy data to ensure the model architecture is valid and the loss function calculates a scalar value correctly.
4.  **Training Pipeline**: We will initialize the `Trainer` class and execute the `fit` method with `debug=True`. This mode subsamples the dataset, allowing us to verify the entire training loop (forward pass, backward pass, validation, and checkpoint saving) in a short time.
5.  **Inference Pipeline**: To demonstrate inference without processing the entire test set, we will create a small subset of the test metadata (containing just one case). We will then update the configuration to point to this subset and run the `run_inference` function, verifying that a submission file is generated.
6.  **Metrics Calculation**: We will demonstrate the `compute_metrics` function using synthetic 3D volumes to confirm that Dice and Hausdorff metrics are computed correctly.
