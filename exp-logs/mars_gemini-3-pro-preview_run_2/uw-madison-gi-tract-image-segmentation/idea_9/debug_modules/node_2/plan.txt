The error `ValueError: DataFrame index must be unique for orient='index'` occurs because the input DataFrame (`test_df`) contains multiple rows for the same image `id` (one for each class: large_bowel, small_bowel, stomach), which is typical for the competition's data format. When `set_index("id")` is called, the index becomes non-unique, causing `to_dict("index")` to fail. To resolve this, I will deduplicate the DataFrame by `id` before creating the dictionary, as the image dimensions (`img_width`, `img_height`) are identical for all rows corresponding to the same image.
