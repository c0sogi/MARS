The following script demonstrates the end-to-end usage of the provided machine learning pipeline for stomach and intestine segmentation.

### Implementation Strategy
1.  **Configuration Setup**: We first import the `Config` class and modify specific parameters (e.g., `EPOCHS`, `BATCH_SIZE`, `WORKING_DIR`) to ensure the demonstration runs quickly and stores outputs in a dedicated demo directory.
2.  **Metric Verification**: We validate the correctness of the `dice_coef` and `hausdorff_distance_3d` functions using synthetic numpy arrays with known properties (e.g., identical masks should yield perfect scores).
3.  **Dataset Pipeline Verification**: We instantiate the `UWMapDataset` using the metadata loader. We verify that the 2.5D input stacking works correctly (resulting in 3 channels) and that the shapes of images and masks match the configuration.
4.  **Model & Loss Verification**: We initialize the `UnetPlusPlus` model and perform a forward pass with a dummy batch. We verify that the model outputs a list of tensors (due to deep supervision) and that the `BCETverskyLoss` computes a valid scalar loss value.
5.  **Training Integration**: We execute the `train_model` function in debug mode. This runs a short training loop (2 epochs, small subset of data) to verify the training logic and save model weights.
6.  **Inference Integration**: We execute the `inference_fn` function in debug mode. This loads the trained model, performs predictions on a subset of the test set, applies 3D post-processing, and generates a submission file.
7.  **Output Validation**: Finally, we check that the submission file exists and adheres to the required CSV format.
