Implementation Strategy:

1.  **Configuration Override**: We will modify the `Config` class attributes at runtime to adapt the pipeline for a quick demonstration. This includes reducing the number of epochs to 1, lowering the batch size to 2, and redirecting metadata paths to temporary subset files to minimize data processing time.
2.  **Data Preparation**: We will load the existing metadata, select a tiny subset (e.g., 4 training samples, 2 validation samples), and save these as temporary CSVs in the working directory. This ensures the `Dataset` and `Trainer` classes process only a fraction of the data.
3.  **Component Verification**:
    *   **Dataset**: Instantiate `InkDataset` with the subset metadata and verify that `__getitem__` returns tensors of the correct shape `(3, 512, 512)` for inputs and `(1, 512, 512)` for targets.
    *   **Model**: Instantiate `SegFormerMiTB2`, perform a forward pass with dummy data, and verify the output shape matches the input resolution `(Batch, 1, 512, 512)`.
    *   **Loss**: Verify `BCEDiceLoss` returns a valid scalar tensor given model outputs and targets.
4.  **Training Loop Execution**: Initialize the `Trainer`, load the subset data, and run a full training cycle (1 epoch). We will assert that the training completes and produces a model checkpoint.
5.  **Inference Execution**: Initialize the `InferenceEngine`, load the trained checkpoint, and run inference on the test set (limited to 1 fragment). We will verify that a `submission.csv` is generated and follows the correct format.
