Implementation Strategy:
1.  **Environment Setup**: Import necessary libraries and the provided modules (`library.*`).
2.  **Unit Testing**: Implement small, isolated tests for:
    *   **Utils**: Verify `rle_encode` correctness with a known pattern and check metric functions (`fbeta_score`, `dice_coef`) with dummy tensors.
    *   **Data Pipeline**: Verify `InkDataset` loads data correctly, asserting input image shapes `(4, 512, 512)` and mask shapes `(1, 512, 512)`.
    *   **Model Architecture**: Instantiate `HPUnet` and perform a forward pass with dummy data to verify output dimensions.
3.  **Integration Testing**: Execute a modified training and inference loop.
    *   Override `Config` parameters to enable `DEBUG` mode, reduce `EPOCHS` to 1, set `BATCH_SIZE` to 2, and define a custom `WORKING_DIR`.
    *   Run `train_model` to verify the training loop, loss calculation, and checkpoint saving.
    *   Run `run_inference` to verify the prediction pipeline, Test Time Augmentation (TTA), and submission file generation.
4.  **Validation**: Assert the existence and validity of output files (`best_model.pth`, `submission.csv`).
