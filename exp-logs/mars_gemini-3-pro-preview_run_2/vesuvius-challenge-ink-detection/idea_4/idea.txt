Based on the empirical findings and lessons learned, I propose the following optimized strategy. This solution introduces a **Hybrid-Projection (HP) Input Strategy** to resolve the conflict between the robustness of global projections and the information density of stratified depth.

# Hybrid-Projection U-Net (HP-Unet)

### Model
**Architecture:** I propose a **ResNet34 U-Net** with a modified input interface.
*   **Backbone:** We will utilize a **ResNet34** encoder. While Lesson 00014 indicated that ResNet34 failed with pure stratified inputs due to noise sensitivity, we hypothesize this was caused by "Signal Dilution" (Cite Lesson 00015) where the strong ink signal was fragmented across channels. By reinforcing the input with a global signal (see Data section), we can stabilize the deeper encoder and leverage its superior feature extraction capabilities compared to the ResNet18 baseline.
*   **Input Modification:** The first convolutional layer will be adapted to accept a **4-channel input tensor** (instead of the standard 3). This structural change allows the model to simultaneously process the global context and local depth variations.
*   **Decoder:** Standard U-Net decoder with skip connections to the ResNet34 encoder levels.

### Data
**Preprocessing:**
We will construct a **Hybrid-Projection** tensor that synthesizes the "Global MIP" (successful in Lesson 00003/00014) with "Stratified Depth" (successful in Lesson 00010).
*   **Z-Slice Selection:** We focus on the central slab (slices 22-42), which contains the ink signal.
*   **Channel Construction (4 Channels):**
    1.  **Channel 1 (Global Anchor):** A **Maximum Intensity Projection (MIP)** across the entire range (22-42). This explicitly preserves the high-contrast ink signal, addressing the "Signal Dilution" issue (Cite Lesson 00014, 00015) and providing a robust anchor for the model.
    2.  **Channel 2 (Top Slab):** MIP of slices 22-28.
    3.  **Channel 3 (Middle Slab):** MIP of slices 29-35.
    4.  **Channel 4 (Bottom Slab):** MIP of slices 36-42.
    *   *Rationale:* This configuration allows the model to "see" the strong global signal (Ch1) while referencing the stratified channels (Ch2-4) to resolve depth ambiguities (e.g., distinguishing surface ink from internal noise), effectively combining the strengths of 2D and 2.5D approaches.
*   **Normalization:** Normalize pixel values to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** Apply random horizontal/vertical flips and 90-degree rotations.
*   **Intensity Constraints:** Strictly **exclude** brightness, contrast, and gamma augmentations. We must preserve the physical radiodensity values as they are the primary discriminator for ink (Cite Lesson 00006).

### Training
*   **Loss Function:** Composite **BCE + Dice Loss**. The Dice component is crucial for optimizing the F0.5 metric (overlap).
*   **Validation Gating:** The execution script will implement a strict gate: the submission file will *only* be generated if the current model's best validation F0.5 score exceeds the previous best baseline (0.474). This mitigates the risk of submitting inferior models due to run-to-run variance (Cite Lesson 00004).
*   **Optimizer:** Adam optimizer with `ReduceLROnPlateau` scheduler.

### Evaluation
*   **Defensive Inference:** The inference pipeline will explicitly handle the 4-channel input shape. We will construct the 4-channel tensor for each test fragment and ensure the batch dimensions are correct `(Batch, 4, H, W)` before inference (Cite Lesson 00005).
*   **Test Time Augmentation (TTA):** We will average predictions from the original input and its geometric transformations (flips/rotations) to smooth out prediction noise and maximize the F0.5 score.
*   **Thresholding:** The binarization threshold will be optimized based on the validation set performance.
