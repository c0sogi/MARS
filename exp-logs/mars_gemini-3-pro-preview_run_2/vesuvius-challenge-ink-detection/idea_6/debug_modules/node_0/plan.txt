Implementation Strategy:
1.  **Environment Setup**: Initialize the environment using `setup_reproducibility` to ensure deterministic behavior.
2.  **Configuration Override**: Modify the `Config` class attributes at runtime to enable `DEBUG` mode, reduce `EPOCHS` to 1, and lower `BATCH_SIZE`. This ensures the demonstration runs quickly on a subset of data.
3.  **Data Loading Verification**: Use `get_dataloaders` to generate training and validation loaders. Fetch a single batch to verify the shape and data types of the inputs (6-channel volumetric projections) and targets (binary masks).
4.  **Model Initialization**: Instantiate the model using `get_model`. Verify that the first layer has been correctly modified to accept 6 input channels (representing the Z-axis slabs) instead of the standard 3.
5.  **Training & Validation Loop**: Execute `train_one_epoch` and `validate` for a single iteration. This demonstrates the integration of the data loader, model, optimizer, and loss functions (BCE + Dice).
6.  **Metric & Utility Verification**:
    *   Test `fbeta_score` with known tensors to confirm metric calculation.
    *   Test `rle_encoding` with a simple numpy array to verify the run-length encoding logic required for submission.
7.  **Inference Pipeline Simulation**: Demonstrate `predict_fragment` from `library.inference`. To avoid the time cost of processing a full 80MB+ fragment during this demo, I will mock the data loading functions (`load_fragment_mips` and `cv2.imread`) to return small, valid dummy arrays. This allows the actual inference logic (sliding window, TTA, normalization) to execute and be verified without heavy I/O.
