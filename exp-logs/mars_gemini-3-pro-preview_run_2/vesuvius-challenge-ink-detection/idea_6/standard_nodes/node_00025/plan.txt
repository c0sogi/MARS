The implementation strategy involves the following steps:

1.  **Configuration & Setup**: Initialize the environment with a fixed random seed for reproducibility. Modify the global `Config` to ensure the model checkpoint is always saved (by setting the baseline threshold to -1.0) so that validation and failure analysis can be performed regardless of initial performance. Update the `SUBMISSION_PATH` to the required `./submission/` directory and limit `EPOCHS` to 10 to ensure the baseline runs quickly within the time limit.
2.  **Training**: Execute the provided `train_model()` function, which handles the training loop, data loading (using cached MIPs), and model checkpointing.
3.  **Validation & Metrics**: Load the best model checkpoint. Iterate through the hold-out validation set to calculate the `Final Validation Metric` (F0.5 score). Simultaneously, collect per-sample data (prediction error and mean input intensity) for failure analysis.
4.  **Failure Analysis**: Calculate and print the Pearson correlation between the model's error magnitude (1 - F0.5) and the input image intensity using NumPy to identify if signal strength relates to performance drops.
5.  **Submission**: Compare the calculated final validation metric against the strict threshold of `0.5511069832462687`. If the model outperforms this threshold, generate the submission file using `generate_submission()`.
