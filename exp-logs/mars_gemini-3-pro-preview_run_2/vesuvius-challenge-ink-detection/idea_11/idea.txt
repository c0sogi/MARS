Based on the comprehensive empirical history and lessons learned, I propose the **High-Fidelity SegFormer (MiT-B3) with Decoupled Z-Scanning**.

This strategy resolves the central conflict identified in Lessons 00034 and 00035: the need to detect "wandering" ink strokes (which requires depth flexibility) versus the need for high Signal-to-Noise Ratio (SNR) during training (which requires strict depth constraints). By **decoupling** the depth handling—enforcing strict constraints during training but enabling flexible scanning during inference—we can leverage a higher-capacity model without the convergence issues caused by label noise.

# Model
**Architecture:** I propose upgrading the backbone to the **SegFormer MiT-B3** (Mix Transformer B3).
*   **Backbone:** The **MiT-B3** encoder provides a significant increase in parameter count and receptive field compared to the MiT-B2 used in the current best solution. This increased capacity is necessary to resolve fine-grained ink textures that smaller models miss. Unlike the failed MiT-B4 experiments (Cite Lesson 00034, 00035), which were destabilized by noisy data (Wide Context/Z-Jitter), this model will be fed high-SNR data to ensure stable convergence.
*   **Input Interface:** We strictly maintain the **3-channel input interface**. This ensures we can utilize **ImageNet-pretrained weights** without modification, preserving the spatial filters learned on massive datasets and avoiding the failure of random initialization (Cite Lesson 00024) or feature destruction via channel expansion (Cite Lesson 00025).
*   **Decoder:** The standard MLP decoder aggregates multi-scale features to predict the binary mask.

# Data
**Preprocessing (Training):**
*   **Overlapping Stratified Depth Projection:** We retain the highly effective "Overlapping Thick Slab" strategy (Cite Lesson 00029). We define a **Fixed Narrow Context** (slices 20-44) and split it into three overlapping, thick Maximum Intensity Projections (MIPs).
    *   **Channel 1:** MIP of slices **20-32** (12 slices).
    *   **Channel 2:** MIP of slices **26-38** (12 slices).
    *   **Channel 3:** MIP of slices **32-44** (12 slices).
    *   *Rationale:* This configuration optimizes for **Signal Continuity** (Cite Lesson 00026) and **Boundary Preservation** (Cite Lesson 00029). Crucially, we reject the "Wide Context" approach (slices 14-50) which was proven to dilute the signal and degrade performance (Cite Lesson 00034).
*   **Normalization:** Pixel values are normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** Random horizontal/vertical flips and 90-degree rotations.
*   **Exclusion of Z-Jitter:** We explicitly **exclude** Volumetric Z-Jitter during training. Previous experiments showed that shifting the input slab while keeping the 2D label static creates false positive training samples (e.g., input is empty air, label says "ink"), which destroys model precision (Cite Lesson 00035).
*   **Exclusion of Intensity Augmentation:** We explicitly **exclude** brightness/contrast augmentations to preserve the physical radiodensity semantics required for ink detection (Cite Lesson 00006).

# Training
*   **Loss Function:** **BCE + Dice Loss**. We utilize the balanced Dice Loss, as weighted variants (Tversky) failed to improve the F0.5 metric in previous trials (Cite Lesson 00031).
*   **Optimizer:** **AdamW** with `ReduceLROnPlateau` scheduler.
*   **Validation Gating:** The execution script will implement a strict logic gate. The submission file will **only** be generated if the current model's best validation F0.5 score exceeds the previous best baseline (0.5976). This ensures only superior models are submitted (Cite Lesson 00004).

# Evaluation
**Structural Innovation: Decoupled Volumetric Z-Scanning**
To detect ink strokes that wander outside the fixed training window (20-44) without polluting the training data with noise, we introduce a **Multi-Pass Z-Scanning** protocol at inference time.
1.  **Scanning:** For each test fragment, we generate three distinct input tensors corresponding to different depth offsets:
    *   **Scan A (High):** Slabs starting at slice 18 (covering 18-42).
    *   **Scan B (Center):** Slabs starting at slice 20 (covering 20-44).
    *   **Scan C (Low):** Slabs starting at slice 22 (covering 22-46).
2.  **Inference:** The trained MiT-B3 model predicts a probability map for each of the three scans.
3.  **Max-Fusion:** We compute the **Maximum Probability Projection** across the three predictions per pixel.
    *   *Rationale:* Since the model is trained on high-SNR centered data, it will output high confidence only when the ink is properly focused within the slab. By taking the maximum, we effectively "search" for the ink's true depth at inference time, capturing wandering strokes while maintaining the precision of a model trained on clean data.
4.  **Defensive Inference:** Explicitly check input tensor shapes `(Batch, 3, H, W)` before batching to prevent runtime errors (Cite Lesson 00005).
5.  **Test Time Augmentation (TTA):** We will average predictions from geometric flips within each scan pass before the final fusion.
