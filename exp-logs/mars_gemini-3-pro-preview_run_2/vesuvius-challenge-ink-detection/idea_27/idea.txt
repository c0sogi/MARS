Based on the comprehensive empirical history and the synthesis of the "Lessons Learned," I propose the **Translation-Invariant SegFormer (MiT-B2) with Constrained Dynamic Sampling**.

This strategy resolves the project's central conflict: the tension between the need for **High-SNR Training Data** (which requires narrow, focused inputs, Cite Lesson 00034) and the need for **Flexible Inference Depth** (to catch wandering ink, Cite Lesson 00035). Previous attempts failed either by diluting the signal (Wide Context), introducing label noise (Blind Z-Jitter), or running out of compute (Ensembles). This solution uses a **Structural Innovation in the Data Pipeline**—**Constrained Dynamic Sampling**—to train a single, robust model that is mathematically guaranteed to handle the Z-scanning required at inference without the downsides of previous approaches.

# Model
**Architecture:** I propose the **SegFormer MiT-B2** with the standard **MLP Decoder**.
*   **Backbone:** We will utilize the **MiT-B2** encoder (~25M parameters).
    *   *Rationale:* Previous experiments confirmed that scaling up to MiT-B3 or MiT-B4 in this low-data regime (~400 samples) causes the model to overfit to intensity artifacts, degrading the F0.5 score (Cite Lesson 00040). The B2 backbone provides the optimal balance of receptive field and regularization.
*   **Decoder:** We strictly retain the standard **All-MLP Decoder**.
    *   *Rationale:* Experiments demonstrated that U-Net decoders with direct skip connections propagate high-frequency substrate noise (papyrus fibers) to the output, reducing precision (Cite Lesson 00043). The MLP decoder's bottleneck forces the model to learn robust semantic features.
*   **Input Interface:** We maintain the **3-channel input interface** to utilize **ImageNet-pretrained weights** without modification. This avoids the convergence failures associated with random initialization (Cite Lesson 00024) or channel expansion (Cite Lesson 00025).

# Data
**Preprocessing (Training):**
*   **Overlapping Stratified Depth Projection:** We employ the "Overlapping Thick Slab" strategy (Cite Lesson 00029) to generate high-SNR inputs. We define a slab thickness of 12 slices with 50% overlap.
*   **Structural Innovation: Constrained Dynamic Sampling:** Instead of training on a static "Center" view (which causes the model to fail when ink moves to other channels) or "Blind Z-Jitter" (which creates false positives), we implement a **Dynamic Safe-View Generator**.
    *   *Mechanism:* For every training batch, we dynamically sample the Z-window start index from a calculated **Safe Range** (e.g., slices 16 to 24).
    *   *Constraint:* This range is rigorously defined to ensure that the central ink volume (approx. slice 32) *always* remains within the 3-channel input tensor, but its position shifts between Channel 1, 2, and 3.
    *   *Benefit:* This forces the single model to learn **Z-Translation Invariance**—recognizing ink regardless of which channel it occupies—without ever showing it an invalid (empty) input with a positive label (solving the "Label Noise" failure of Lesson 00035).
*   **Normalization:** Pixel values are normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** Random horizontal/vertical flips and 90-degree rotations.
*   **Exclusion of Intensity Augmentation:** We explicitly **exclude** brightness/contrast augmentations to preserve physical radiodensity semantics (Cite Lesson 00006).

# Training
*   **Single-Model Optimization:** We train a **single unified model** rather than an ensemble.
    *   *Rationale:* This consolidates the entire computational budget into one learner, maximizing the number of gradient updates and ensuring full convergence, avoiding the under-fitting observed in split-budget ensembles (Cite Lesson 00051).
*   **Micro-Dataset Protocol:**
    *   **Batch Size:** Strictly set to **8** to maximize gradient steps (Cite Lesson 00044).
    *   **Learning Rate:** Conservative **6e-5** with **AdamW** to prevent divergence (Cite Lesson 00037).
*   **Loss Function:** **BCE + Dice Loss**. We utilize the balanced Dice Loss, as weighted variants (Tversky) failed to improve the F0.5 metric (Cite Lesson 00031).
*   **Validation Gating:** The submission file will **only** be generated if the current model's best validation F0.5 score exceeds the previous best baseline (approx. 0.598) (Cite Lesson 00004).

# Evaluation
**Inference Strategy: Deterministic Z-Scanning**
We leverage the model's learned translation invariance to capture wandering ink strokes at test time.
1.  **Scanning:** For each test fragment, we generate three distinct input tensors corresponding to the boundaries of our training translation (Start Indices: 16, 20, 24).
2.  **Inference:** The unified MiT-B2 model predicts a probability map for each view.
3.  **Max-Fusion:** We compute the **Maximum Probability Projection** across the three predictions per pixel.
    *   *Rationale:* Since the model is explicitly trained to be invariant to the ink's channel position, it will output high confidence in the specific view where the ink is best focused. Max-fusion effectively aggregates these confident detections (Cite Lesson 00042).
4.  **Defensive Inference:** Explicitly check input tensor shapes `(Batch, 3, H, W)` before batching (Cite Lesson 00005).
