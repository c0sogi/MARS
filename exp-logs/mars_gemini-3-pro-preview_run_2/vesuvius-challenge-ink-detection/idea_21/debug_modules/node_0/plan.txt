The following implementation demonstrates the usage of the Vesuvius Ink Detection library components.

### Implementation Strategy

1.  **Configuration & Setup**: We begin by importing the necessary modules and overriding the global `Config` to adapt to a quick demonstration (reducing epochs, batch size, and enabling a temporary working directory).
2.  **Utility Verification**: We validate the `rle_encoding` and `calculate_f05` functions with synthetic data to ensure metric calculation logic is correct.
3.  **Data Pipeline**: We create a temporary metadata subset (referencing the real provided dataset) to allow the `data.py` functions to process a small slice of the data quickly. We then demonstrate `get_specialist_datasets` to generate training tensors.
4.  **Model Instantiation**: We initialize the `SpecialistSegFormer` and perform a dummy forward pass to verify tensor shapes and device placement.
5.  **Training Loop**: We execute `train_specialist` for a single epoch on the subset data. This demonstrates the training lifecycle, loss calculation, and checkpoint saving.
6.  **Inference Pipeline**: We run the full `create_submission` workflow. This loads the trained model, performs inference on a test fragment (using the `inference.py` logic which handles tiling and 3D volume projection), and generates the required run-length encoded submission file.
