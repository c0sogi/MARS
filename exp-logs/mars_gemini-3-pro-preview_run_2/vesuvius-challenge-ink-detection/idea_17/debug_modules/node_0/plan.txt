Implementation Strategy:
1.  **Configuration Override**: We will modify the `library.config.Config` class attributes at runtime to reduce the batch size and number of epochs. This ensures the demonstration runs quickly and fits within the time and memory constraints while using the provided library structure.
2.  **Utility Verification**: We will create synthetic data to verify the correctness of the `rle_encoding`, `dice_coef`, and `fbeta_score` functions from `library.utils`.
3.  **Data Pipeline Demonstration**: We will load the provided metadata, subset it to a very small number of samples (to ensure speed), and instantiate the `InkDataset`. We will verify the output shapes of the tensors produced by the dataset.
4.  **Model Initialization and Forward Pass**: We will instantiate the `VesuviusSegFormer` model using the factory function in `library.model`. We will perform a forward pass with a sample batch to confirm the model architecture matches the input data dimensions.
5.  **Training Loop Execution**: We will run the `fit` function from `library.engine` using the subsetted data. This demonstrates the full training cycle, including loss calculation, backpropagation, and metric evaluation, resulting in a saved model checkpoint.
6.  **Inference and Submission Generation**: We will demonstrate how to load the test metadata, generate predictions using the trained model, apply Run-Length Encoding (RLE), and format the output for submission.
