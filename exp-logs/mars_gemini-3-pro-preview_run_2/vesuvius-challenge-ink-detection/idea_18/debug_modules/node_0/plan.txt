The following script demonstrates the end-to-end usage of the provided Vesuvius Ink Detection library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to reduce dataset size, batch size, and epochs for a rapid demonstration.
2.  **Dataset Verification**: Instantiates the `InkDataset` and `TestInkDataset` to verify data loading, shape consistency, and correct channel construction (3-channel slab projection).
3.  **Model Verification**: Instantiates the `SegFormerB2` model and performs a forward pass with dummy data to ensure the architecture and tensor shapes are correct.
4.  **Training Pipeline**: Executes the `train_model` function, which runs the training loop, performs validation, handles early stopping, and saves the best model checkpoint.
5.  **Inference Pipeline**: Explicitly invokes the `run_inference` function using the trained model to generate the run-length encoded `submission.csv` for the test set.
6.  **Output Validation**: Checks the generated submission file for the correct format and content.
