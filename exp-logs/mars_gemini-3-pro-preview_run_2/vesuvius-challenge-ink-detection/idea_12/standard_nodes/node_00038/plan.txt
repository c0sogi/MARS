The implementation strategy follows the "Stabilized High-Fidelity SegFormer (MiT-B3) with Decoupled Z-Scanning" idea. The script orchestrates the pipeline by first initializing the environment and seeding for reproducibility. It then sets up the `InkDataset` for training and validation and initializes the `SegFormerB3` model with the `BCEDiceLoss` and `AdamW` optimizer. The training loop runs for a fixed number of epochs (defined in Config), saving the model checkpoint only when the validation F0.5 score improves. After training, the script performs a failure analysis on the validation set by calculating the correlation between prediction error magnitude and input image intensity. Finally, if the best validation F0.5 score exceeds the specified threshold (0.597622633), the script triggers the `z_scan_inference` routine to generate the submission file using the decoupled Z-scanning technique.
