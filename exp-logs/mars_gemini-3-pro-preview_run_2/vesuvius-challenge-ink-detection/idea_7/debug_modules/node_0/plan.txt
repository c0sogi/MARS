The implementation strategy involves a step-by-step demonstration of the provided library components. First, we will validate the utility functions (`rle_encoding`, `fbeta_score`) using synthetic data to ensure metric calculation correctness. Next, we will initialize the `InkDataset` with a small subset of the training metadata to verify data loading, transformation, and tensor shapes without processing the entire dataset. We will then instantiate the `OSSNet` model using `build_model`, pass a sample batch through it, and assert that the output dimensions match the input resolution. Following this, we will execute the `run_training` function in debug mode for a single epoch to demonstrate the training loop and checkpointing mechanism. Finally, we will run the `inference` pipeline in debug mode to generate a submission file, verifying the end-to-end workflow and output format.
