The implementation strategy is as follows:

1.  **Setup and Configuration**: Initialize the environment by setting the random seed for reproducibility. We will use the provided `Config` class but explicitly override `Config.EPOCHS` to a slightly lower value (e.g., 10) if necessary to strictly adhere to the "fast baseline" requirement, although the dataset size (412 patches) is small enough that the default 15 epochs will run in minutes on an A100. We will keep the default 15 epochs to maximize performance.

2.  **Training**: Instantiate the `Trainer` class from `library.trainer`. Call the `fit()` method to train the SegFormer model. This handles the training loop, validation at each epoch, and saving the best model checkpoint to the cache directory.

3.  **Validation and Failure Analysis**:
    *   Load the best saved model state.
    *   Iterate through the validation dataset using a `DataLoader`.
    *   Compute the **F0.5 score** on the entire validation set to satisfy the reporting requirement.
    *   Simultaneously, collect data for failure analysis:
        *   **Error Magnitude**: Calculate the Mean Absolute Error (MAE) between predictions and ground truth for each batch.
        *   **Input Feature**: Calculate the mean pixel intensity of the input images for each batch.
    *   Compute and print the **Pearson correlation** between error magnitude and input intensity to identify if brightness/contrast affects performance.
    *   Print the `Final Validation Metric` with full precision.

4.  **Conditional Submission**:
    *   Compare the calculated final validation metric against the strict threshold `0.597622633`.
    *   If the metric exceeds the threshold, invoke `library.inference.run_inference()` to generate predictions on the test set and save `submission.csv`.
    *   If the metric is insufficient, skip submission generation to save resources.
