Implementation Strategy:
1.  **Configuration Override**: Modify the static `Config` parameters at runtime to reduce the computational load. Set `EPOCHS` to 1, `BATCH_SIZE` to 2, and `NUM_WORKERS` to 0. Lower the `VALIDATION_THRESHOLD` to ensure the model checkpoint is saved even with a short training run.
2.  **Data Subsetting**: Read the existing metadata files (`train.csv`, `validation.csv`). Create smaller subset CSVs containing only a few samples (patches) from a single fragment to minimize volume loading times. Save these subsets to the `./working` directory and point `Config` to them.
3.  **Component Verification**:
    *   **Dataset**: Instantiate `InkDataset` with the subset metadata. Verify that the output tensors (image, mask, label) have the expected shapes and value ranges.
    *   **Model**: Instantiate `SegFormerMiTB4`. Perform a forward pass with a dummy tensor or a sample from the dataset to verify output shape.
    *   **Loss**: Instantiate `BCEDiceLoss` and calculate the loss between the model output and a target tensor to ensure it returns a valid scalar.
4.  **Training Loop Execution**: Instantiate the `Trainer` class. Execute the `fit()` method to run one epoch of training and validation. Verify that the `best_model.pth` file is created in the cache directory.
5.  **Inference Execution**: Execute the `run_inference()` function. This will load the saved model and generate predictions for the test set. Verify that `submission.csv` is generated and follows the required format (Id, Predicted) with valid RLE strings.
