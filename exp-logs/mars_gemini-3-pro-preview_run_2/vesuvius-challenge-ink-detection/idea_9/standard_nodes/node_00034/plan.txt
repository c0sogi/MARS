The implementation strategy is as follows:

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility and ensuring the working directory exists. We will use the provided `CFG` class for configuration but rely on the default settings as the dataset size (412 patches) is small enough to run quickly (well under the 2-hour limit) without aggressive subsampling.
2.  **Data Loading**: Utilize the `get_dataloaders` function from `library.data` to load training and validation data. This leverages the pre-generated metadata and handles caching of 3D volume slices.
3.  **Model Initialization**: Instantiate the `WideContextSegFormer` from `library.model`. This model uses a custom adapter to process 5 Z-slices, initialized to identity mapping for stability.
4.  **Training Loop**: Implement a standard training loop using `BCEDiceLoss` and the `AdamW` optimizer. We will train for the configured number of epochs, validating after each epoch using `valid_one_epoch`. The model checkpoint with the highest validation F0.5 score will be saved.
5.  **Validation and Failure Analysis**:
    *   Load the best saved model.
    *   Compute the global F0.5 score on the entire validation set to satisfy the reporting requirement.
    *   Perform failure analysis by calculating the correlation between the mean prediction error (L1 distance) and the mean input intensity of the patches. This identifies if brightness/density affects model performance.
6.  **Submission Logic**: Compare the final validation F0.5 score against the baseline threshold (0.597622633). If the model performs better, execute the `inference` function from `library.inference` to generate the `submission.csv` file using Test Time Augmentation (TTA).
