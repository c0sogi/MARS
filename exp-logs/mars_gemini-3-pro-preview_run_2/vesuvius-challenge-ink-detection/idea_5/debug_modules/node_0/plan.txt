This script demonstrates the end-to-end pipeline for the Vesuvius Ink Detection task using the provided library files. It covers:
1.  **Configuration**: Overriding default settings for a fast demonstration (reduced epochs, debug mode).
2.  **Utilities Verification**: validating RLE encoding and F-beta score calculation.
3.  **Data Pipeline**: initializing data loaders with debug subsampling and verifying batch shapes.
4.  **Model Initialization**: Instantiating the SegFormer model and performing a forward pass check.
5.  **Training Loop**: Executing a short training run to generate model weights.
6.  **Inference**: Generating a submission file using the trained model on test data.
