Based on the empirical lessons learned, I propose the following optimized strategy. This solution introduces a **SegFormer** architecture to address the noise sensitivity observed in deeper CNNs, while retaining the highly effective **Stratified Depth Projection** data representation.

# Stratified SegFormer: Exploiting Global Context with 2.5D Transformers

### Model
**Architecture:** I propose replacing the CNN-based U-Net with a **SegFormer** (Semantic Segmentation Transformer) architecture.
*   **Backbone (Encoder):** We will utilize the **Mix Transformer (MiT-B1)** encoder, initialized with pre-trained ImageNet weights.
    *   *Rationale:* Previous experiments showed that deepening a CNN (ResNet34) led to hypersensitivity to local noise and intensity artifacts (Cite Lesson 00014). Unlike CNNs, which build context slowly through local receptive fields, Transformers utilize self-attention to capture **global context** from the earliest layers. This allows the model to distinguish coherent ink strokes (long-range dependencies) from random volumetric noise, effectively addressing the overfitting issues of the ResNet34 experiment.
*   **Decoder:** A lightweight MLP-based decoder (standard for SegFormer) will be used to aggregate multi-scale features from the encoder and predict the binary mask.
*   **Input:** The model will accept a **3-channel** input tensor, leveraging the pretrained RGB weights of the encoder.

### Data
**Preprocessing:**
*   **Stratified Depth Projection (2.5D):** We will retain the successful "2.5D" representation by splitting the central Z-slice range (22-42) into three contiguous, non-overlapping sub-volumes (e.g., slices 22-28, 29-35, 36-42).
    *   *Projection:* For each sub-volume, we will compute the **Maximum Intensity Projection (MIP)**. This preserves the sparse, high-density ink signal better than statistical averages (Cite Lesson 00015).
    *   *Stacking:* These three MIPs will be stacked to form the 3-channel input image (Cite Lesson 00010).
    *   *Constraint:* We will **strictly avoid** including a global full-volume MIP channel. Previous experiments showed that mixing global and local projections causes the model to take "shortcuts" via the global channel, ignoring the depth-specific cues (Cite Lesson 00018).
*   **Normalization:** Pixel values will be normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** We will apply random horizontal/vertical flips and 90-degree rotations.
*   **Intensity Constraints:** We will explicitly **exclude** brightness, contrast, and gamma augmentations. The model relies on absolute radiodensity to detect ink, and intensity perturbations destroy this physical signal (Cite Lesson 00006).

### Training
*   **Loss Function:** A composite **BCE + Dice Loss** will be used to optimize for both pixel accuracy and the F0.5 overlap metric.
*   **Optimizer:** We will use **AdamW**, which is the standard optimizer for Transformer-based architectures, with a learning rate scheduler (ReduceLROnPlateau).
*   **Validation Gating:** The execution script will implement a conditional logic gate. The submission file will *only* be generated if the current model's best validation F0.5 score exceeds the previous best baseline (0.474). This prevents inferior stochastic runs from overwriting valid results (Cite Lesson 00004).

### Evaluation
*   **Defensive Inference:** The inference pipeline will explicitly check input tensor dimensions to ensure the 3-channel structure is preserved before batching, preventing shape mismatch errors (Cite Lesson 00005).
*   **Test Time Augmentation (TTA):** We will perform inference on the original input and its geometric transformations (flips/rotations). The predictions will be averaged to smooth out noise and maximize the F0.5 score.
