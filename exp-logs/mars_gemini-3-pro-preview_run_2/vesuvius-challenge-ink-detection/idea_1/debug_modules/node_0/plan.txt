Implementation strategy:

1.  **Configuration Override**: We will modify the static `Config` class attributes at runtime to reduce `NUM_EPOCHS` to 1 and adjust `BATCH_SIZE` for a rapid demonstration. We will also redirect the `WORKING_DIR` to a specific demo folder.
2.  **Dataset Verification**: We will instantiate the `InkDataset` using the provided metadata, retrieve a single sample, and assert that the shapes of the image and mask tensors are correct (Channels, Height, Width).
3.  **Model Verification**: We will instantiate the `MIPUNet` architecture, pass the sample tensor through it, and assert that the output logits have the expected dimensions.
4.  **Training Simulation**: We will execute `train_model()`. Since we reduced the epochs, this will run a single pass over the training data (approx. 400 samples) and validation data, saving the best model.
5.  **Inference Execution**: We will call `create_submission()` using the trained model to generate predictions for the test fragments defined in the metadata.
6.  **Output Validation**: Finally, we will inspect the generated `submission.csv` to ensure it follows the required format (columns `Id` and `Predicted`) and contains valid Run-Length Encoding strings.
