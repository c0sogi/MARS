To optimize the model's performance, I will implement a **Stratified Depth Projection** strategy (Cite solution_lesson_node_00010). Instead of compressing the entire relevant Z-volume (slices 22-42) into a single grayscale Maximum Intensity Projection (MIP), I will split this volume into three sub-volumes and generate a MIP for each. These three projections will be stacked to form a 3-channel (RGB-like) input, allowing the ResNet18 encoder to leverage its pre-trained weights more effectively and capture depth-dependent features.

1.  **`library/config.py`**: Update `IN_CHANNELS` to 3 and replace the single `Z_START`/`Z_END` range with `Z_RANGES` defining three sub-volumes `[(22, 28), (28, 35), (35, 42)]`. Update `WORKING_DIR` to `idea_2` to separate artifacts.
2.  **`library/dataset.py`**: Modify `get_fragment_mip` to compute and stack MIPs for the defined Z-ranges, producing an `(H, W, 3)` image. Update `get_transforms` to normalize 3 channels. Update `InkDataset` to correctly handle 3-channel tensor permutation in the manual transform path.

def get_fragment_mip(
    fragment_id,
    volume_path,
    z_ranges=Config.Z_RANGES,
    load_cached_data=True,
):
    """
    Computes or loads the Stratified Maximum Intensity Projection (MIP) for a specific fragment.
    Generates a 3-channel image where each channel corresponds to the MIP of a sub-volume.

    Args:
        fragment_id (str): The ID of the fragment.
        volume_path (str): Relative path to the surface volume directory.
        z_ranges (list of tuples): List of (start, end) tuples for sub-volumes.
        load_cached_data (bool): Whether to attempt loading from cache.

    Returns:
        np.ndarray: The 3-channel MIP image (H, W, 3) with original dtype (uint16).
    """
    cache_filename = f"fragment_{fragment_id}_mip_3ch.npy"
    cache_path = os.path.join(Config.WORKING_DIR, cache_filename)

    # 1. Try to load cached data
    if load_cached_data and os.path.exists(cache_path):
        try:
            mip = np.load(cache_path)
            return mip
        except Exception as e:
            print(
                f"Error loading cache for fragment {fragment_id}: {e}. Recomputing..."
            )

    # 2. Compute from scratch
    full_volume_dir = os.path.join(Config.INPUT_DIR, volume_path)
    channel_mips = []

    for z_start, z_end in z_ranges:
        slices = []
        # Iterate through the specified Z-slice range for this channel
        for z in range(z_start, z_end):
            slice_filename = f"{z:02d}.tif"
            slice_path = os.path.join(full_volume_dir, slice_filename)

            if os.path.exists(slice_path):
                img = cv2.imread(slice_path, cv2.IMREAD_UNCHANGED)
                if img is not None:
                    slices.append(img)

        if not slices:
            raise ValueError(
                f"No valid slices found for fragment {fragment_id} in {full_volume_dir} (range {z_start}-{z_end})"
            )

        # Stack along new axis and take maximum for this sub-volume
        stack = np.stack(slices, axis=0)
        mip_channel = np.max(stack, axis=0)
        channel_mips.append(mip_channel)

    mip_3ch = np.stack(channel_mips, axis=-1)

    # 3. Save to cache
    os.makedirs(Config.WORKING_DIR, exist_ok=True)
    np.save(cache_path, mip_3ch)

    return mip_3ch
