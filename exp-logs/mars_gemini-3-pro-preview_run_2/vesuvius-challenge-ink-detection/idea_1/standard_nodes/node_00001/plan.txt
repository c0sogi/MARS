Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and suppressing warnings. Import necessary modules and the provided library functions.
2.  **Model Training**: Execute the training pipeline using `library.engine.train_model`. This utilizes the `MIPUNet` architecture (ResNet18 encoder) on the Maximum Intensity Projection (MIP) data generated from the 3D volumes. The training process includes early stopping and saves the best model checkpoint.
3.  **Validation & Metric Calculation**:
    *   Load the best-trained model and the validation dataset.
    *   Perform inference on the validation set in batches.
    *   Accumulate predictions and ground truth masks to calculate the global **F0.5 Score** (the competition metric).
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   During validation inference, calculate the error (1 - F0.5) and the mean pixel intensity for each image patch.
    *   Compute the Pearson correlation coefficient between the error magnitude and the input intensity to identify if ink detection performance is dependent on the radiographic density of the fragment.
    *   Print the correlation results.
5.  **Submission Generation**:
    *   Use `library.inference.create_submission` to generate predictions for the test set.
    *   The inference pipeline handles MIP generation, tiling, prediction, stitching, thresholding, and Run-Length Encoding (RLE).
    *   Save the final `submission.csv` to the home directory.
