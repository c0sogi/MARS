This script demonstrates the end-to-end usage of the provided library files for the Cdiscount Product Categorization task. It first creates a small subset of the metadata to ensure the demonstration runs quickly (under 13 minutes). It then verifies the core components: reading BSON images, dataset loading, batch collation, and model instantiation. Finally, it executes a complete training and inference cycle using the `engine` module with the subsetted data.
