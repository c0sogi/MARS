The implementation strategy focuses on creating a fast, compliant baseline within the 10-minute constraint while satisfying all task requirements.

1.  **Fast Training Subset**: To ensure the script completes on time, we will not train on the full 12M dataset. Instead, we will sample a small subset (5,000 images) from `train.csv` and save it as a temporary metadata file. This allows the model to perform a "sanity check" training loop quickly.
2.  **Full Validation**: We will load the **entire** validation set as required. To speed up inference on this large set (1.2M images), we will use a large batch size (1024) and Automatic Mixed Precision (AMP) on the A100 GPU.
3.  **Failure Analysis**: During the validation loop, we will collect prediction correctness and `product_id`s. We will map these IDs to the `bson_length` feature from the metadata to calculate the correlation between error and record size, identifying if larger/complex records are harder to classify.
4.  **Conditional Submission**: We will implement the logic to generate predictions on the test set only if the validation accuracy exceeds the threshold (61.16%). Given the reduced training, this block will likely be skipped, saving significant time, but the code path is fully implemented.
5.  **Environment**: We utilize the provided library modules for consistency and monkey-patch the `Config` class to redirect training to our small subset without modifying the read-only library files.
