# Baseline Approach: ResNet-18 with Late Fusion

### Model
The proposed architecture is a standard **ResNet-18** (Residual Network), chosen for its balance between inference speed and classification performance. Unlike the previously suggested models that aggregate feature embeddings (intermediate representations) from multiple images, this approach treats the problem as a standard single-image classification task. The model consists of the ResNet-18 backbone followed by a Global Average Pooling layer and a single fully connected layer that outputs logits for the 5270 product categories.

### Data
**Training Preprocessing:**
To maximize training efficiency and simplicity, the hierarchical structure of the dataset (where one product contains multiple images) will be **flattened**. Each image will be treated as an independent training sample, inheriting the `category_id` of its parent product. This transforms the problem into a standard image classification task with approximately 12 million samples. Images will be resized to 224x224 pixels and normalized using standard ImageNet mean and standard deviation values. Minimal augmentation (e.g., random horizontal flips) will be applied to maintain high throughput.

**Evaluation Preprocessing:**
For validation and testing, the data loader will yield all images associated with a single `product_id` as a batch, preserving the grouping required for the final prediction.

### Training
The model will be trained using **Cross-Entropy Loss**.
*   **Optimizer:** Stochastic Gradient Descent (SGD) with momentum or AdamW will be used for rapid convergence.
*   **Precision:** Automatic Mixed Precision (AMP) will be utilized to leverage the A100 GPU's tensor cores, significantly reducing memory usage and training time.
*   **Strategy:** Given the massive size of the flattened dataset (~12M images), the model will be trained for a limited number of epochs (e.g., 2-3 epochs) to ensure the runtime remains well within the 24-hour limit while still exposing the model to the vast majority of the data.

### Evaluation
Prediction will be performed using a **Late Fusion (Score Averaging)** strategy:
1.  For a given test product, the model will generate independent probability distributions (via Softmax) for every image associated with that product.
2.  These probability vectors will be averaged element-wise to produce a single "consensus" probability distribution for the product.
3.  The category corresponding to the maximum value in this averaged vector will be selected as the final label.

This approach avoids the complexity of custom architectures for variable-length inputs and leverages the robustness of averaging predictions to handle noisy or ambiguous individual images.
