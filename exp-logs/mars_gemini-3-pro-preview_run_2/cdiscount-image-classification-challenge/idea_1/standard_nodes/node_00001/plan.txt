Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and define device (GPU).
2.  **Data Loading**:
    *   Instantiate `CdiscountDataset` for training, validation, and testing.
    *   **Optimization**: Limit the training dataset size to 500,000 samples to ensure the "fast baseline" executes quickly (within ~2 hours) while still learning. Use the **full** validation and test sets as required.
    *   Use `train_collate_fn` for training (flattens images for efficiency) and `eval_collate_fn` for validation/testing (groups images by product for late fusion).
3.  **Model Initialization**: Load the ResNet-18 model using `get_model`, customized for 5270 classes, and move it to the GPU.
4.  **Training**:
    *   Define `CrossEntropyLoss` and `SGD` optimizer.
    *   Execute `train_model` from the engine. This handles mixed-precision training, logging, and checkpointing.
    *   Train for a limited number of epochs (e.g., 2) to fit the time constraints.
5.  **Validation & Metric**:
    *   Load the best saved checkpoint.
    *   Run `validate` on the full validation set.
    *   Print the `Final Validation Metric` (Accuracy).
6.  **Failure Analysis**:
    *   Perform a custom inference pass on the validation set to collect predictions, true labels, and metadata (number of images, product IDs).
    *   Merge results with metadata (e.g., BSON record length) to analyze correlations between error magnitude (0 or 1) and input features (image count, file size).
7.  **Submission**:
    *   Generate predictions for the test set using `make_predictions`.
    *   Save the results to `submission.csv`.
