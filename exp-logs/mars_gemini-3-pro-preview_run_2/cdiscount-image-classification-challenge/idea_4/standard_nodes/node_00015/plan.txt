To improve the model's performance within the 50-minute time limit, I will implement a "Wide and Fast" training strategy (Cite solution_lesson_node_00007) by switching to a lighter model architecture (`resnet18`) and increasing the training data volume.

Key changes:
1.  **Model Architecture**: Switch from `convnext_tiny` to `resnet18`. ResNet-18 is computationally lighter, allowing for significantly higher data throughput (Cite solution_lesson_node_00008).
2.  **Resolution Matching**: Increase input image size from 180x180 to 224x224. Fine-tuning works best when the input resolution matches the pre-training resolution (Cite solution_lesson_node_00014).
3.  **Data Volume & Epochs**: Increase the training subset from 800,000 to 2,500,000 images and reduce training to 1 epoch. This exposes the model to more unique samples (Cite solution_lesson_node_00007) rather than repeating a smaller subset.
4.  **Batch Size**: Increase batch size from 256 to 512 to fully utilize the A100 GPU with the smaller ResNet-18 model.
