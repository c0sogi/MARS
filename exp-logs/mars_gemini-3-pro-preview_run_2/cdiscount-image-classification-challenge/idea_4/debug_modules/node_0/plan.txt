This script demonstrates the usage of the provided machine learning pipeline components. It performs the following steps:
1.  **Configuration**: Sets up the environment and overrides default parameters (e.g., batch size, subset size) to ensure the demonstration runs quickly (Debug mode).
2.  **Data Loading Verification**: Instantiates the `BSONDataset` and `DataLoader` for training and validation. It asserts that the data shapes (images and labels) are correct.
3.  **Model Initialization**: Loads the ConvNeXt model using the `get_model` function and verifies it is placed on the correct device.
4.  **Training & Validation**: Runs a single epoch of training and validation using the functions provided in `library.engine`. It verifies that the loss and accuracy metrics are computed.
5.  **Inference**: Generates predictions on a subset of the test data using the `predict` function and saves the results in the submission format.
