# Proposed Solution: Heterogeneous Adversarial Hybrid Stacking

### Model
**Architecture (Two-Stream Ensemble):**
We will implement a multi-model system consisting of two distinct transformer backbones to capture diverse semantic patterns.
1.  **Stream A (Primary):** **`microsoft/deberta-v3-large`**. This model excels at fine-grained semantic interaction (Cite **solution_lesson_node_00003**).
2.  **Stream B (Secondary):** **`roberta-large`**. We introduce this backbone to provide **tokenizer diversity** (Byte-Pair Encoding vs. SentencePiece) and architectural variance (MLM vs. RTD), which is critical for robust ensembling.

**Structural Innovation (Hybrid Feature Fusion):**
Both streams will utilize the **Hybrid Architecture**.
*   **Pooling:** We will apply **Attention Pooling** to the last hidden state of each backbone, as it outperforms `[CLS]` fusion (Cite **solution_lesson_node_00014**).
*   **Fusion:** We will explicitly calculate **Normalized Levenshtein Distance**, **Jaccard Similarity**, and **Length Ratio** for every pair. These structural features will be concatenated with the attention-pooled embedding before the final layer. This injects deterministic signals for "exact matches" that pure semantic models may miss (Cite **solution_lesson_node_00015**).
*   **Head:** Both models will use a **5-Class Classification Head** (outputting probabilities for 0.0, 0.25, 0.5, 0.75, 1.0) to model the discrete ordinal target (Cite **solution_lesson_node_00008**).

### Data
**Preprocessing:**
*   **Context Enrichment:** For both streams, we will map CPC context codes (e.g., "A47") to their full textual descriptions to provide explicit domain grounding (Cite **solution_lesson_node_00008**).
*   **Input Format:** `[CLS] Context Description [SEP] Anchor [SEP] Target [SEP]`.
*   **Feature Engineering:** Pre-compute the structural features (Jaccard, Levenshtein, Length) for the entire dataset.

### Training
**Strategy (Adversarial Stabilization):**
We will train both streams using **Stratified 5-Fold Cross-Validation**.
*   **Adversarial Weight Perturbation (AWP):** We will apply AWP to both models to flatten the loss landscape. Crucially, AWP will be activated *after* the first epoch to avoid destabilizing the initial learning phase (Cite **solution_lesson_node_00013**).
*   **Convergence & Stability:** We will train each fold for **5 epochs** to ensure full convergence, addressing the undertraining issues observed previously (Cite **solution_lesson_node_00013**). We will strictly employ **Gradient Accumulation** (Effective Batch Size = 32) and **Gradient Clipping** (Max Norm = 1.0) to prevent the loss stagnation observed in large models (Cite **solution_lesson_node_00016**).
*   **Loss Function:** Cross-Entropy Loss with mild label smoothing (0.1) (Cite **solution_lesson_node_00008**).

### Evaluation
**Inference:**
For every fold in both streams, we will predict the **Expected Value** of the probability distribution ($\sum P(c) \times c$) to generate continuous scores that maximize Pearson correlation (Cite **solution_lesson_node_00008**).

**Ensembling (Stacking):**
The final submission will be generated by averaging the Expected Value predictions from all 10 models (2 Architectures $\times$ 5 Folds). This **Heterogeneous Ensemble** reduces both the variance (via folding) and the inductive bias (via architectural diversity) of the solution.
