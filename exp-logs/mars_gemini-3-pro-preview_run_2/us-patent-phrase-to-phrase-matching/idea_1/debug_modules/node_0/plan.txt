### Implementation Strategy

2.  **Data Loading**: Utilize `data_manager.get_data` to load the training, validation, and test datasets. We will verify that the dataframes contain the expected columns and that the preprocessing logic (concatenating anchor and context) works as intended.
3.  **Feature Extraction**: Instantiate the `SentenceEncoder` and use `extract_embeddings` to generate dense vector representations for the text inputs. We will assert that the output shapes match the expected dimensions of the Sentence Transformer model (384 dimensions for `all-MiniLM-L6-v2`).
4.  **Model Training**: Initialize the `SimilarityRegressor` (Ridge Regression) and train it using the generated embeddings. We will validate that the model produces predictions in the valid range [0, 1] and computes a Pearson correlation score.
5.  **Submission Generation**: Generate predictions for the test set and create a submission file using `generate_submission`. Finally, we will verify the existence and format of the output file.
