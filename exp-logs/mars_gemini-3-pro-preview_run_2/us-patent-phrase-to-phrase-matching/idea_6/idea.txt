# Proposed Solution: Adversarial Hybrid DeBERTa-v3-Large Ensemble

### Model
**Architecture:**
We will utilize the **`microsoft/deberta-v3-large` Cross-Encoder** backbone, which has proven superior to Bi-Encoders (Cite **solution_lesson_node_00003**).

**Structural Innovation (Adversarial Hybrid Fusion):**
We will implement a **Hybrid Architecture** that fuses learned semantic representations with deterministic structural signals, optimized via an adversarial objective.
1.  **Semantic Stream:** We will apply **Attention Pooling** to the backbone's last hidden state, as it outperforms `[CLS]` fusion (Cite **solution_lesson_node_00014**).
2.  **Structural Stream:** We will explicitly calculate a vector of surface-level features for each pair: **Normalized Levenshtein Distance**, **Jaccard Similarity**, and **Length Ratio**. These features provide the "exact match" signals that pure transformers sometimes miss (Cite **solution_lesson_node_00015**).
3.  **Fusion:** The dense semantic embedding will be concatenated with these structural features before entering the classification head.

**Classification Head:**
We will use a **5-Class Classification Head** (outputting probabilities for scores 0.0, 0.25, 0.5, 0.75, 1.0) to model the discrete ordinal target (Cite **solution_lesson_node_00008**).

### Data
**Preprocessing:**
*   **Context Enrichment:** We will map CPC context codes (e.g., "A47") to their full textual descriptions to provide explicit domain grounding (Cite **solution_lesson_node_00008**).
*   **Input Format:** `[CLS] Context Description [SEP] Anchor [SEP] Target [SEP]`.
*   **Feature Engineering:** Pre-compute the Levenshtein, Jaccard, and Length features for all pairs.

### Training
**Strategy (Adversarial Stabilization):**
We will employ **Stratified 5-Fold Cross-Validation**. The core innovation is the successful integration of **Adversarial Weight Perturbation (AWP)**, which previously failed due to undertraining (Cite **solution_lesson_node_00013**).
*   **AWP Integration:** We will inject adversarial perturbations into the model weights to minimize the worst-case loss, flattening the loss landscape for better generalization. AWP will be activated *after* the first epoch (warmup).
*   **Convergence Correction:** To support the computational overhead of AWP and ensure convergence, we will extend training to **5 epochs** per fold.
*   **Stability Protocol:** We will strictly apply **Gradient Accumulation** (Effective Batch Size = 32) and **Gradient Clipping** (Max Norm = 1.0). This prevents the optimization instability and loss stagnation observed in previous large-model experiments (Cite **solution_lesson_node_00016**).

**Loss Function:**
**Cross-Entropy Loss** with mild label smoothing (0.1) will be used to optimize the classification probabilities (Cite **solution_lesson_node_00008**).

### Evaluation
**Inference:**
For each fold, we will predict the **Expected Value** of the probability distribution ($\sum P(c) \times c$) to generate smooth, continuous scores that maximize Pearson correlation (Cite **solution_lesson_node_00008**).

**Ensembling:**
The final submission will be the simple average of the Expected Value predictions from all 5 adversarial hybrid models. This combines the variance reduction of ensembling with the robustness of adversarial training.
