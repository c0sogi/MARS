# Proposed Solution: Multi-Layer Fusion DeBERTa-v3-Large with Adversarial Training

### Model
**Architecture:**
We will retain the **`microsoft/deberta-v3-large` Cross-Encoder** backbone, as it has proven significantly superior to Bi-Encoders for capturing fine-grained semantic interactions (Cite **solution_lesson_node_00003**).

**Structural Innovation (Multi-Layer Fusion):**
To address the model's potential over-reliance on the final abstract layer—which may lose some syntactic nuance required to distinguish between "exact matches" (1.0) and "close synonyms" (0.75)—we will implement a **Multi-Layer Fusion** mechanism. Instead of pooling only the last hidden state, we will extract the hidden states from the **last four layers** of the transformer. These will be concatenated and passed through a weighted projection layer before entering the classification head. This allows the model to leverage a richer hierarchy of linguistic features.

**Classification Head:**
We will preserve the **5-Class Classification Head** (outputting probabilities for scores 0.0, 0.25, 0.5, 0.75, 1.0) rather than a regression head, as this has been proven to better model the discrete ordinal nature of the data (Cite **solution_lesson_node_00008**).

### Data
**Preprocessing (Context Enrichment):**
We will strictly maintain the **Context Enrichment** strategy, mapping the raw CPC codes (e.g., "A47") to their full textual descriptions (e.g., "Furniture; Domestic Articles or Appliances"). The input format will remain: `[CLS] Context Description [SEP] Anchor [SEP] Target [SEP]`. This provides the necessary domain grounding that simple code concatenation lacks (Cite **solution_lesson_node_00008**).

### Training
**Regularization Strategy (Adversarial Weight Perturbation):**
To address the generalization and stability issues observed with standard regularization techniques like Multi-Sample Dropout (Cite **solution_lesson_node_00012**), we will integrate **Adversarial Weight Perturbation (AWP)** into the training loop. AWP explicitly perturbs the model's weights in the direction that maximizes the loss (simulating a "worst-case" scenario) and then minimizes this perturbed loss. This flattens the loss landscape, preventing the model from settling into sharp, unstable minima—a common issue when fine-tuning large models on moderate-sized datasets.

**Loss Function:**
We will continue to use **Cross-Entropy Loss** with mild label smoothing to handle the classification task (Cite **solution_lesson_node_00008**).

### Evaluation
**Inference (Expected Value & Ensembling):**
We will generate predictions using the **Expected Value** method ($\sum P(c) \times c$) to produce smooth, continuous scores that maximize Pearson correlation (Cite **solution_lesson_node_00008**).
To further boost performance and robustness, we will employ a **Stratified K-Fold Ensemble (K=5)**. We will train five independent models on different data splits and average their expected value predictions for the final submission. This ensures that the final score is not dependent on the vagaries of a single random seed or data split.
