# Proposed Solution: Hybrid DeBERTa-v3-Large Ensemble with Adversarial Training

### Model
**Architecture:**
We will utilize the **`microsoft/deberta-v3-large` Cross-Encoder** backbone, as it has been proven to significantly outperform Bi-Encoders (Cite **solution_lesson_node_00003**).

**Structural Innovation (Hybrid Feature Fusion):**
To explicitly address the scoring rubric's reliance on surface-level constraints (e.g., distinguishing "exact matches" from "close synonyms" based on stopwords or abbreviations), we will implement a **Hybrid Architecture**.
*   **Pooling:** We will employ **Attention Pooling** on the last hidden state to derive a semantic embedding, which is superior to [CLS] token fusion (Cite **solution_lesson_node_00014**).
*   **Feature Concatenation:** We will concatenate this dense semantic embedding with a vector of **explicit structural features**: Normalized Levenshtein Distance, Jaccard Similarity, and Normalized Length Difference. This provides the classification head with direct signals for the "exact match" criteria that purely semantic models might treat as noise.
*   **Classification Head:** The combined vector (Embedding + Features) will be fed into a **5-Class Classification Head** (outputting probabilities for scores 0.0, 0.25, 0.5, 0.75, 1.0), which models the discrete ordinal nature of the data better than regression (Cite **solution_lesson_node_00008**).

### Data
**Preprocessing:**
*   **Context Enrichment:** We will map the CPC context codes (e.g., "A47") to their full textual descriptions to provide explicit domain grounding (Cite **solution_lesson_node_00008**).
*   **Input Format:** `[CLS] Context Description [SEP] Anchor [SEP] Target [SEP]`.
*   **Feature Engineering:** We will pre-compute the structural features (Jaccard, Levenshtein, Length Diff) for each pair to be used in the hybrid fusion layer.

### Training
**Strategy (Adversarial Ensemble):**
We will implement a **Stratified 5-Fold Cross-Validation** loop.
*   **Adversarial Weight Perturbation (AWP):** We will integrate **AWP** to flatten the loss landscape and improve generalization. Crucially, to address the failure observed in previous attempts (Cite **solution_lesson_node_00013**), we will **not** limit training to 1 epoch. Instead, we will leverage the full 24-hour compute budget to train each fold for **3-4 epochs**, enabling AWP (activated after the first epoch) to effectively stabilize the model without causing under-fitting.

**Loss Function:**
We will use **Cross-Entropy Loss** with mild label smoothing (0.1) to handle the classification task (Cite **solution_lesson_node_00008**).

### Evaluation
**Inference:**
For each fold, we will predict the **Expected Value** of the probability distribution ($\sum P(c) \times c$) to generate a continuous, correlation-optimized score (Cite **solution_lesson_node_00008**).
**Ensembling:**
The final submission score will be the **simple average** of the Expected Value predictions from all 5 adversarial models. This reduces variance and ensures robustness against data splits.
