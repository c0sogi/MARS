The `RuntimeError` is caused by the use of `-1e9` in the `masked_fill` operation within the `AttentionPooling` layer. When training with Automatic Mixed Precision (AMP), tensors are cast to `float16`, which has a limited range (approx. $\pm 65,504$). The value `-1e9` causes an overflow. I will replace it with `-1e4`, which is safe for `float16` while still functioning as an effective mask Cite debug_lesson_2. Additionally, I will update the gradient checkpointing configuration to set `use_reentrant=False` to avoid potential backward pass errors common with the default legacy implementation Cite debug_lesson_1.
