This script demonstrates the end-to-end usage of the provided library components for the phrase similarity task. It performs the following steps:

1.  **Configuration Setup**: Modifies the global `Config` to run in a lightweight "debug" mode (using a tiny model and minimal data) to ensure rapid execution.
2.  **Data Pipeline Verification**: Initializes the tokenizer and generates DataLoaders (`train`, `val`, `test`) using `get_loaders`. It verifies the structure and shapes of the batches produced.
3.  **Model Initialization**: Instantiates the `HybridDeberta` model (swapped to a tiny BERT variant for speed) and verifies the forward pass logic.
4.  **Training Loop**: Simulates a single training epoch using `train_one_epoch`, including the initialization of the Adversarial Weight Perturbation (AWP) module.
5.  **Validation Loop**: Runs `valid_one_epoch` to compute loss and the Pearson correlation score.
6.  **Inference & Submission**: Simulates the inference process by saving the trained model, running `predict_fold`, and finally executing `generate_submission` to produce the output CSV.
