Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment with a fixed seed for reproducibility. Import necessary modules from the provided library files.
2.  **Stage 1 Training (Base Ensemble)**: Execute the `run_kfold` function from `train_stage1.py`. To ensure the "Fast Baseline" requirement is met within the 2-hour limit, I will set `epochs=2` and `debug=False`. This trains the DeBERTa-v3-Large ensemble on the full dataset but for fewer epochs, generating the necessary Out-Of-Fold (OOF) predictions (`stage1_oof.csv`) and test predictions.
3.  **Stage 2 Training (Meta-Learner)**: Use `prepare_stacking_data` from `meta_learner.py` to load the OOF predictions and structural features. Train a Ridge Regression meta-learner on this data. This model calibrates the neural network predictions using deterministic features (Levenshtein, Jaccard, etc.).
4.  **Validation**:
    *   Reconstruct the ID mapping to identify which rows in the OOF set correspond to the original hold-out validation set (`metadata/val.csv`).
    *   Filter the calibrated OOF predictions to select only these validation samples.
    *   Compute the Pearson correlation coefficient on this subset to produce the **Final Validation Metric**.
5.  **Failure Analysis**:
    *   Calculate the absolute error (residuals) for the validation subset.
    *   Compute and print the Pearson correlation between the error magnitude and key structural features (e.g., Levenshtein distance, Jaccard similarity) to identify error sources.
6.  **Submission**:
    *   Check if the Final Validation Metric exceeds the threshold (0.8654320295612139).
    *   If passed, use the trained meta-learner to predict on the test set (`X_test`) and save the results to `./submission/submission.csv`.
