Here is the implementation strategy and the corresponding Python script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` class with `debug=True`. Crucially, override the `model_name` to a lightweight model (`prajjwal1/bert-tiny`) to ensure the demonstration runs quickly (seconds instead of minutes) and fits easily within memory limits while verifying the entire pipeline logic.
2.  **Data Loading & Processing**: Use `load_processed_data` to get the dataframes. Slice them to a very small subset (e.g., 20 rows) to speed up dataset creation and iteration. Initialize the tokenizer and `InsultDataset`.
3.  **Model Initialization**: Instantiate the `InsultModel` using the tiny model configuration. Verify the forward pass produces logits of the correct shape.
4.  **Optimizer & Scheduler**: Use `get_optimizer_params` to verify the Layer-wise Learning Rate Decay (LLRD) logic and initialize the AdamW optimizer.
5.  **Adversarial Weight Perturbation (AWP)**: Initialize the `AWP` class. We will pass this to the training function to verify integration.
6.  **Training & Validation Loops**: Run `train_fn` for one epoch on the small subset. This validates the training loop, mixed precision scaler, gradient clipping, and AWP injection. Then run `valid_fn` to ensure evaluation logic works.
7.  **Inference**: Run `inference_fn` on the test set subset to verify prediction generation.
8.  **TAPT Data Preparation**: Call `prepare_tapt_data` to verify it correctly aggregates text and writes the corpus file, skipping the actual pre-training time sink.
