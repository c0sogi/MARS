The issue is caused by the deprecation and removal of `AdamW` from the `transformers` library in recent versions (including 4.57.0). The script attempts to import `AdamW` from `transformers`, resulting in an `ImportError`. The fix is to import `AdamW` from PyTorch's native optimization module (`torch.optim`) instead, which provides the standard implementation of the AdamW optimizer compatible with the existing code usage.
