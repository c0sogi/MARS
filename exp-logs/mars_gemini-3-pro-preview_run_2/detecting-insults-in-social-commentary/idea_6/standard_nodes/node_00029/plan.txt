The execution failed with a `CUDA out of memory` error because the configuration was tuned for a 40GB A100 GPU (`train_batch_size=8`), but the actual runtime environment only has a ~16GB GPU (Cite debug_lesson_2). Additionally, enabling gradient checkpointing to save memory is not a viable option here because it conflicts with Adversarial Weight Perturbation (AWP), which modifies weights in-place and causes "backward through graph a second time" errors (Cite debug_lesson_3). Therefore, the correct targeted fix is to reduce the batch sizes in both the configuration and the run script to values compatible with 16GB VRAM (e.g., batch size of 4).
