The implementation strategy involves the following steps:
1.  **Setup**: Define input (`./input`) and output (`./metadata`) directories. Ensure the output directory exists.
2.  **Load Data**: Read `train.csv` and `test.csv` using pandas. Handle potential index columns (e.g., `Unnamed: 0`) by removing them to ensure clean metadata.
3.  **Split Data**: Perform a stratified split on `train.csv` to create a training set (80%) and a validation set (20%). Use `sklearn.model_selection.train_test_split` with `stratify=y` and a fixed random state (`42`) to ensure reproducibility and balanced class distributions.
4.  **Save Metadata**: Save the split training and validation sets, as well as the original test set, to the `./metadata` directory as `train.csv`, `val.csv`, and `test.csv`.
5.  **Validation**:
    *   Reload the generated metadata files.
    *   Print summary statistics (shape, class distribution).
    *   Verify the split ratio is approximately 80:20.
    *   Verify that the class distribution in the validation set matches the training set (stratification check).
    *   (Conditional) If file paths were present, check their validity. Since this is a text dataset, this step is skipped but the logic is acknowledged.
    *   Raise `AssertionError` if any validation check fails.
