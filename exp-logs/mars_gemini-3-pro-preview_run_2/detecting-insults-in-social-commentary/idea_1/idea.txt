# Baseline Approach: Neural Bag-of-Embeddings

## Model
The proposed architecture is a **Neural Bag-of-Embeddings (BoE)** classifier, designed to be the simplest possible neural baseline. 
- **Embedding Layer**: The core component is an `EmbeddingBag` layer. Unlike standard embedding layers that return a tensor of shape `(batch, seq_len, dim)`, this layer efficiently computes the mean of the embeddings for a sequence of tokens in a single operation. This results in a fixed-size dense vector representation for each comment, regardless of its length.
- **Classification Head**: The averaged embedding vector is passed through a lightweight Multi-Layer Perceptron (MLP). This consists of a `Linear` layer, a `ReLU` non-linearity to capture basic interaction effects, and a final `Linear` layer that projects the features to a single scalar logit.
- **Output**: A `Sigmoid` activation function transforms the logit into a probability score in the range [0, 1].
- **Distinction**: This approach differs from Models 3, 4, and 5 by discarding sequence order and complex spatial/temporal operations (Convolution/Recurrence/Attention) in favor of pure averaging. It differs from Models 1 and 2 by using learnable dense representations rather than sparse TF-IDF vectors.

## Data
1. **Text Cleaning**: The `Comment` column will be processed to handle the unicode-escaped format (e.g., converting `\u0027` to `'`) and strip the surrounding double quotes. Text will be lowercased to normalize inputs.
2. **Tokenization**: We will implement a basic tokenizer that splits text on non-alphanumeric characters. A vocabulary will be constructed from the training data, retaining the top $N$ (e.g., 10,000) most frequent tokens. Rare words will be mapped to a generic `<UNK>` token.
3. **Formatting**: The data will be prepared as a flat tensor of token indices alongside an "offsets" tensor (indicating the start index of each sequence). This format is required for the `EmbeddingBag` layer and is more memory-efficient than zero-padding batches.
4. **Metadata**: To strictly adhere to the "simple and lightweight" philosophy, the `Date` column will be omitted, as the preliminary analysis showed the text signal is dominant.

## Training
- **Loss Function**: We will use **Binary Cross-Entropy (BCE) Loss**, which is the standard objective for optimizing probability outputs in binary classification.
- **Optimizer**: The **Adam** optimizer will be employed with default parameters, as it handles the sparse gradients associated with embedding updates effectively.
- **Regularization**: A minimal amount of Weight Decay (L2 regularization) will be applied to the optimizer to prevent the embedding weights from exploding.
- **Procedure**: The model will be trained for a small number of epochs (e.g., 5-10). We will monitor the AUC on the validation set after each epoch and save the model checkpoint with the highest validation score.

## Evaluation
For the test set, the text will be cleaned and tokenized using the vocabulary and pipeline established during training. The model will process the batches in inference mode (gradients disabled) to output probability scores. These scores will be saved directly to the submission file.
