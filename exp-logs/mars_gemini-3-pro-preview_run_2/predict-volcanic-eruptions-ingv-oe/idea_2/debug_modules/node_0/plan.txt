The following script demonstrates the end-to-end usage of the provided seismic eruption prediction library. It employs a strategy of creating a "mini" dataset by subsetting the original metadata to ensure the demonstration runs quickly (under 2 minutes) while verifying all core functionalities.

The script performs the following steps:
1.  **Environment Setup**: Configures paths and creates a small subset of the metadata (20 samples for training, 10 for validation/testing) to optimize execution speed.
2.  **Configuration Override**: Monkey-patches the `Config` class to point to the mini-datasets and reduces training hyperparameters (1 epoch, batch size 4).
3.  **Component Verification**:
    *   **Utils**: Verifies `TargetScaler` logic.
    *   **Feature Engineering**: Validates spectrogram computation and statistical feature extraction on a single file.
    *   **Data Pipeline**: Uses `get_dataloaders` to generate features, cache them, and create PyTorch DataLoaders. Checks batch shapes.
    *   **Model**: Instantiates the `HybridModel` and performs a forward pass check.
    *   **Training**: Runs a custom training loop using `train_one_epoch` and `validate` (bypassing a potential naming bug in the provided `run_training` function) and saves the model.
    *   **Inference**: Executes `generate_predictions` to produce a submission file and verifies the output format.
