Based on the lessons learned and the need for structural innovation, I propose a **Hybrid Spectrogram-CNN and Feature-MLP Architecture**.

This strategy evolves the previous approach by moving beyond simple summary statistics to capture the rich time-frequency information embedded in the seismic signals, while retaining the successful statistical feature engineering as a stabilizing auxiliary branch.

### Model
The architecture consists of two parallel branches that process the data in complementary ways, fused before the final prediction:

1.  **Branch 1: Time-Frequency Encoder (2D CNN)**
    *   **Input**: The raw 10-channel sensor data is transformed into **Log-Mel Spectrograms**. This converts the temporal seismic signals into 2D "images" where the axes represent time and frequency, allowing the model to detect spectral patterns (e.g., harmonic tremors or escalating frequency bands) that scalar statistics miss.
    *   **Backbone**: A lightweight, pre-trained 2D CNN (e.g., ResNet18 or EfficientNet-B0) serves as the feature extractor. The first convolutional layer will be adapted to accept **10 input channels** (one for each sensor) instead of the standard 3 RGB channels.
    *   **Output**: A Global Average Pooling layer flattens the feature maps into a dense embedding vector.

2.  **Branch 2: Statistical Feature Encoder (MLP)**
    *   **Input**: A vector of engineered statistical features (Mean, Std, Skew, Kurtosis, Quantiles, and NaN counts) derived from the raw signals.
    *   **Architecture**: A Multi-Layer Perceptron (Dense $\rightarrow$ Batch Norm $\rightarrow$ ReLU $\rightarrow$ Dropout).
    *   **Purpose**: This branch preserves the "Exploitation" of the previous successful model. It ensures the model retains explicit access to global signal magnitudes and distributions, which might be normalized away in the spectrogram generation process.

3.  **Fusion Head**:
    *   The embeddings from the CNN and MLP branches are concatenated.
    *   A final series of dense layers maps the combined representation to the scalar `time_to_eruption`.

### Data
1.  **Preprocessing**:
    *   **Signal Cleaning**: Fill `NaN` values in the raw sensor data (e.g., with zero or linear interpolation) to ensure valid spectrogram generation.
    *   **Spectrogram Generation**: Use `torchaudio` or `scipy` to compute Mel-Spectrograms for each of the 10 sensors. These will be stacked to form a $(10 \times H \times W)$ tensor for the CNN.
    *   **Feature Extraction**: Compute the statistical summary vector (mean, std, quantiles, etc.) for the MLP branch.
2.  **Scaling**:
    *   **Inputs**: Apply Standard Scaling to the statistical feature vector. Normalize the spectrograms (e.g., to mean 0, std 1) based on global dataset statistics.
    *   **Target**: Apply **Standard Scaling** (subtract mean, divide by std) to the `time_to_eruption` target variable. This is critical to prevent the convergence failure observed previously where the model predicted the mean due to the large magnitude of the target **Cite solution_lesson_node_00001**.

### Training
*   **Loss Function**: Mean Absolute Error (MAE) on the scaled target.
*   **Optimizer**: AdamW with a standard learning rate (e.g., 1e-3) and weight decay.
*   **Patience**: Set the Early Stopping patience to a high value (e.g., **15 to 20 epochs**). Seismic data validation curves are noisy, and a strict patience threshold previously caused premature termination before the model could escape local minima **Cite solution_lesson_node_00003**.
*   **Scheduler**: Use `ReduceLROnPlateau` or a Cosine Annealing scheduler to refine weights as training progresses.

### Evaluation
1.  **Inference**: For each test segment, generate both the spectrogram tensor and the statistical feature vector.
2.  **Prediction**: Pass inputs through the trained hybrid model to get a scaled prediction.
3.  **Inverse Scaling**: Apply the inverse of the target scaler (multiply by training std, add training mean) to convert the model's output back to the original `time_to_eruption` scale (tens of millions).
4.  **Submission**: Format the results into the required CSV structure.
