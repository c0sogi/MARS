The following script demonstrates the end-to-end usage of the provided library components for the seismic eruption prediction task.

### Strategy Outline
1.  **Configuration Override**: We modify the `Config` class at runtime to set a separate working directory (`./working/demo`) and reduce hyperparameters (epochs, batch size, sample size) for rapid execution.
2.  **Feature Extraction**: We invoke `extract_features` on a small subset of the training metadata to verify that sensor statistics are correctly computed and returned as a DataFrame.
3.  **Data Loading**: We utilize `prepare_data` to generate PyTorch DataLoaders. We assert that the data shapes match the expected input dimensions and batch sizes.
4.  **Model Initialization**: We instantiate the `VolcanoMLP` model and perform a dummy forward pass to confirm architectural correctness.
5.  **Training Loop**: We execute `run_training` for a single epoch. This validates the training pipeline, loss calculation, backpropagation, and model checkpointing.
6.  **Inference**: We run `generate_predictions` using the trained model on a subset of test data. We verify the generation of the submission file and its format.
7.  **Validation**: Throughout the script, assertions are used to strictly validate outputs (shapes, file existence, data types).
