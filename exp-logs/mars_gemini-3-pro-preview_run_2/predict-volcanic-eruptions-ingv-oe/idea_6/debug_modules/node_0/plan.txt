Here is the implementation strategy:

1.  **Configuration Setup**: Override the default `Config` parameters to define a temporary working directory (`./working/demo_execution`) and reduce the workload (2 epochs, batch size of 4, debug mode enabled).
2.  **Data Subsetting**: Create smaller versions of the training, validation, and test metadata files (top 10-20 rows) and save them to the working directory. This ensures the feature extraction and training steps run quickly.
3.  **Feature Extraction**: Call `process_and_cache_features` using the subsetted metadata to generate statistical features and save them as Parquet files. Verify the output dimensions.
4.  **Scaler Logic Verification**: Instantiate `TargetScaler`, fit it on the subsetted targets, and verify that `inverse_transform(transform(x))` reconstructs the original value within floating-point tolerance.
5.  **Dataset & DataLoader**: Initialize `VolcanoDataset` with the processed features and scalers. Fetch a single batch via `DataLoader` to assert the shapes of the spectrograms (Batch, 10, 128, Time), statistical vectors, and targets.
6.  **Model Initialization**: Instantiate the `ChannelAdaptiveHybridModel` and perform a forward pass with dummy data (or the fetched batch) to confirm the output shape is `(Batch, 1)`.
7.  **Training Loop**: Initialize the `Trainer` class and execute `trainer.fit()`. Since we reduced the epochs and dataset size, this will finish quickly. Verify that the model weights are saved to disk.
8.  **Inference Demonstration**: Simulate the inference process on the subsetted test data: load the saved model, run predictions, inverse-transform the results, and generate a sample submission file.
