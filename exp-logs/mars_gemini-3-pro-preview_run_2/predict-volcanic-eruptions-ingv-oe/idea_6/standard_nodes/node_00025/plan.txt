The implementation strategy involves the following steps:

1.  **Setup and Configuration**: Initialize the environment by setting random seeds and overriding the `Config` parameters (specifically reducing `EPOCHS` to 15) to ensure the pipeline runs as a fast baseline within the time limits.
2.  **Data Preparation**: Load metadata for training, validation, and testing. Use the provided `process_and_cache_features` function to extract statistical features from the sensor CSVs, leveraging caching to save time.
3.  **Scaling**: Fit a `TargetScaler` on the training targets and a `StandardScaler` on the statistical features to ensure proper data normalization for the hybrid model.
4.  **Dataset and Loader Creation**: Instantiate `VolcanoDataset` and `DataLoader` for the training and validation sets. The training set will use augmentation (SpecAugment), while validation will not.
5.  **Training**: Initialize the `Trainer` class and execute the training loop using `trainer.fit()`. This handles the optimization, learning rate scheduling, and saving of the best model based on validation loss.
6.  **Validation Inference**: Load the best saved model state. Perform inference on the full validation set in evaluation mode (gradients disabled). Apply inverse scaling to the predictions to retrieve the original `time_to_eruption` values.
7.  **Metric Calculation**: Compute the Mean Absolute Error (MAE) between the predictions and actuals. Print the result in the required format: `Final Validation Metric: <value>`.
8.  **Failure Analysis**: Calculate the absolute error for each validation sample. Merge these errors with the input statistical features and compute the Pearson correlation to identify which features are most strongly associated with high prediction errors.
9.  **Submission**: Compare the validation MAE against the specified threshold (1492505.6322055138). If the model performs well enough, process the test set features, run inference, inverse scale the results, and generate the `submission.csv` file.
