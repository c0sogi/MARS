This script demonstrates the end-to-end usage of the provided volcano eruption prediction library. It performs the following steps:

1.  **Environment Setup**: Configures a temporary working directory and overrides `Config` parameters to run a fast, lightweight demonstration (mini-batches, fewer epochs, subset of data).
2.  **Data Preparation**: Creates subsets of the provided metadata (train, val, test) to ensure the feature extraction and training steps complete quickly.
3.  **Dataset Instantiation**: Initializes `VolcanoDataset` for all splits. This triggers the automated feature engineering (statistical extraction) and scaler computation.
4.  **Model Initialization**: Instantiates the `HybridResNet34` model and moves it to the GPU (if available).
5.  **Training Loop**: Executes the `fit` function from the engine to train the model for a few epochs using the training and validation loaders.
6.  **Inference**: Uses the trained model to generate predictions on the test set via `generate_submission`.
7.  **Verification**: Includes assertions to validate data shapes, output file existence, and prediction formats.
