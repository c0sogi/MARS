Based on the lessons learned and the need for structural evolution, I propose the **Multi-Resolution Channel-Stacked Hybrid Network**.

This strategy addresses the trade-off between temporal and frequency resolution identified in **Cite solution_lesson_node_00013** and **Cite solution_lesson_node_00011**. Instead of forcing the model to choose a single spectrogram configuration, this approach generates two complementary time-frequency "views" for each sensor and stacks them along the channel dimension. This allows a deeper CNN backbone to simultaneously learn from high-precision transient textures (e.g., sudden tremors) and high-resolution harmonic patterns (e.g., continuous rumbling), fused with the robust global statistics that have proven essential.

### Model
The architecture is a dual-branch network that fuses a multi-view visual encoder with a statistical encoder:

1.  **Branch 1: Multi-Resolution Spectrogram Encoder**
    *   **Backbone:** **ResNet34**. I propose upgrading from ResNet18 to ResNet34 to provide the additional capacity needed to process the richer, 20-channel input space without overfitting, while retaining the strong texture-extraction bias of the ResNet family **Cite solution_lesson_node_00011**.
    *   **Input Adaptation (Structural Innovation):** The input to the network will be a **20-channel** tensor.
        *   Channels 1-10: High-Temporal-Resolution Spectrograms (Short Window) for the 10 sensors.
        *   Channels 11-20: High-Frequency-Resolution Spectrograms (Long Window) for the 10 sensors.
    *   **Initialization:** The backbone will be initialized with **ImageNet weights**. The first convolutional layer (originally 3 channels) will be adapted by averaging the weights and replicating them 20 times to preserve learned spatial filters **Cite solution_lesson_node_00009**.
    *   **Pooling:** Use **Global Average Pooling (GAP)**. We explicitly reject Attention Pooling mechanisms, as the target variable represents a cumulative global state best captured by averaging feature maps **Cite solution_lesson_node_00015**.

2.  **Branch 2: Statistical Feature Encoder**
    *   **Input:** A vector of engineered statistics (Mean, Std, Skew, Kurtosis, Quantiles, and NaN counts) for all 10 sensors.
    *   **Architecture:** A Multi-Layer Perceptron (MLP) to preserve explicit access to global signal magnitudes and data quality metrics **Cite solution_lesson_node_00006**.

3.  **Fusion Head:**
    *   The embeddings from the GAP layer and the MLP are concatenated.
    *   A series of dense layers maps the combined vector to the scaled prediction.

### Data
1.  **Preprocessing:**
    *   **Imputation:** Fill `NaN` values in the raw sensor data with **zeros**. Do not use linear interpolation to avoid creating artificial spectral artifacts **Cite solution_lesson_node_00012**.
    *   **Multi-View Spectrogram Generation:** For each sensor, generate two Log-Mel Spectrograms with **aligned time dimensions** but different window sizes:
        *   **View A (Temporal Focus):** Window size = 256, Hop length = 256. (Captures sharp transients).
        *   **View B (Spectral Focus):** Window size = 2048, Hop length = 256. (Captures fine frequency bands).
        *   **Note:** Using the same hop length ensures both views have the same width (Time dimension) and can be stacked.
    *   **Scaling:** Use `n_mels=128` for both views and apply **`AmplitudeToDB(top_db=80)`** to normalize dynamic range **Cite solution_lesson_node_00013**.
    *   **Target Scaling:** Apply **StandardScaler** (subtract mean, divide by std) to the `time_to_eruption` target **Cite solution_lesson_node_00001**.

2.  **Augmentation:**
    *   Apply **SpecAugment** (Time and Frequency Masking) to the stacked 20-channel tensor.
    *   **Constraint:** Keep masking parameters **conservative** (e.g., mask <15% of the spectrum) to avoid destroying critical contiguous signal structures **Cite solution_lesson_node_00008**.

### Training
*   **Loss Function:** Mean Absolute Error (MAE) on the scaled target.
*   **Optimizer:** AdamW with weight decay.
*   **Scheduler:** Implement **`ReduceLROnPlateau`**. This is mandatory to achieve high precision in the final epochs, as constant learning rates lead to optimization stagnation **Cite solution_lesson_node_00017**.
*   **Patience:** Set Early Stopping patience to **20 epochs**. This allows the model to navigate the noisy validation landscape and escape local minima without premature termination **Cite solution_lesson_node_00003**.

### Evaluation
1.  **Inference:** For each test segment, generate the zero-filled, multi-resolution spectrogram stack (20 channels) and the statistical feature vector.
2.  **Prediction:** Pass inputs through the trained network to obtain the scaled prediction.
3.  **Inverse Scaling:** Apply the inverse transform (multiply by training std, add training mean) to restore the `time_to_eruption` to its original scale.
4.  **Submission:** Format the results into the required CSV structure.
