### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override specific parameters (`DEBUG`, `EPOCHS`, `BATCH_SIZE`, `WORKING_DIR`) to ensure the script runs quickly on a small subset of data without modifying the original library files.
2.  **Utility Verification**: Demonstrate and verify the `TargetScaler` class (fit, transform, inverse_transform) and the reproducibility utility `seed_everything`.
3.  **Feature Engineering**: Instantiate the `FeatureEngineer` to verify signal processing and spectrogram generation logic. Assert output shapes for a dummy signal.
4.  **Data Loading**: Execute `get_dataloaders` to process the metadata and generate features. This verifies the integration of the feature engineering pipeline with the dataset class. We verify the batch shapes produced by the DataLoader.
5.  **Model Initialization**: Instantiate the `SeismicHybridModel` using the dimensions derived from the data loader. Perform a forward pass with a batch of data to verify the architecture and output dimensions.
6.  **Training Loop**: Run the `run_training` function for a minimal number of epochs (2) to demonstrate the training workflow, including loss calculation, backpropagation, and validation.
7.  **Inference**: Execute `predict_fn` on the test loader to generate predictions and verify the output format.
8.  **Cleanup**: Remove the temporary working directory created for this demonstration.
