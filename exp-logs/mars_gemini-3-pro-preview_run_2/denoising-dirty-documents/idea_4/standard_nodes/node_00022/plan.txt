Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` and set random seeds for reproducibility using the provided `library.utils`.
2.  **Data Preparation**: Instantiate `DenoisingDataset` for both training and validation modes. Wrap them in `DataLoader`s with appropriate batch sizes (64 for training, 1 for validation).
3.  **Model Initialization**: Load the `ResUNetPlusPlus` model, `AdamW` optimizer, `CosineAnnealingLR` scheduler, and the custom `DeepSupervisionLoss`. Move the model to the GPU.
4.  **Training Loop**: Implement the training loop for the specified number of epochs (100). Inside the loop:
    *   Execute one training epoch using `train_one_epoch`.
    *   Evaluate on the validation set using `validate`.
    *   Track the best RMSE and save the model checkpoint (`resunet_plusplus_best.pth`) whenever performance improves.
    *   Implement early stopping based on the patience parameter.
5.  **Final Evaluation**: After training, print the best validation RMSE found.
6.  **Failure Analysis**:
    *   Load the best model checkpoint.
    *   Iterate through the validation set image by image.
    *   Calculate the RMSE for each specific image.
    *   Compute input image statistics (Mean Intensity, Standard Deviation).
    *   Calculate and print the Pearson correlation between the Image RMSE and these statistics to identify error patterns.
7.  **Submission**: Check if the best validation RMSE is below the threshold `0.009138691164531186`. If it is, call `generate_submission` from `library.inference` to create the final `submission.csv`.
