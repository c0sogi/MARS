The issue is that the validation RMSE score saved in the checkpoint is a NumPy scalar (`numpy.float64`), which is not included in the default allowlist for `torch.load` when `weights_only=True` (the default in PyTorch 2.6+). This causes a `_pickle.UnpicklingError` during the submission generation phase when the code attempts to load the checkpoint.

To fix this, I will modify `library/utils.py` to explicitly set `weights_only=False` in the `torch.load` function within `load_checkpoint`. This restores the ability to load checkpoints containing NumPy scalars from trusted sources, as described in **debug_lesson_8**.
