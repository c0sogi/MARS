To address the task of denoising scanned text images, I propose a structural evolution of the previous U-Net approach by transitioning to a **ResUNet (Residual U-Net)** architecture with **Global Residual Learning**, coupled with a robust **Tiled Inference** strategy.

### Model
The core architecture will be a **ResUNet**, which integrates residual learning into the U-Net backbone.
*   **Residual Blocks**: Instead of standard convolutional layers, the encoder and decoder will utilize **Residual Blocks**. Each block consists of two convolutional layers with Batch Normalization (Cite solution_lesson_node_00005) and ReLU activation, featuring a shortcut connection that adds the block's input to its output ($y = F(x) + x$). This facilitates gradient flow through deeper networks, allowing us to increase depth without the risk of vanishing gradients.
*   **Global Residual Learning**: The network will be designed to predict the **noise map** (residuals) rather than the clean image directly. The final output will be computed as $\text{Clean} = \text{Input} - \text{Network}(\text{Input})$. This simplifies the learning task, as the noise distribution in scanned documents is often sparser and more uniform than the complex structural content of the text.
*   **Capacity**: The model will maintain the increased filter capacity (e.g., starting at 64 filters) found effective previously (Cite solution_lesson_node_00010).

### Data
*   **Preprocessing**: Images will be loaded in grayscale and normalized to the [0, 1] range.
*   **Patch Extraction**: Training will be performed on random patches (e.g., $128 \times 128$) extracted from the source images. This ensures the model focuses on local texture and noise patterns while keeping memory usage efficient (Cite solution_lesson_node_00007).
*   **Augmentation**: To exploit the geometric symmetry of noise and text, aggressive geometric augmentations will be applied during training. This includes random horizontal flips, vertical flips, and discrete 90-degree rotations (Cite solution_lesson_node_00010).

### Training
*   **Loss Function**: The model will be trained using **Mean Squared Error (MSE)** loss between the predicted clean image (Input - Predicted Noise) and the ground truth clean image.
*   **Optimizer**: The Adam optimizer will be used for its adaptive learning rate capabilities.
*   **Strategy**: The model will be trained on the augmented patches. Validation RMSE will be monitored to trigger early stopping if performance plateaus.

### Evaluation
To ensure the high performance on patches translates to full-resolution test images, the evaluation pipeline will be structurally enhanced:
*   **Tiled Inference with Overlap**: Instead of resizing test images or processing them in a single pass (which may cause memory issues or boundary artifacts), test images will be processed using a sliding window approach. Overlapping patches (e.g., 50% overlap) will be extracted, denoised, and then merged to reconstruct the full image. Overlapping regions will be averaged (potentially using a Gaussian weight map) to eliminate seams and edge artifacts.
*   **Test Time Augmentation (TTA)**: Leveraging the symmetry observed in training (Cite solution_lesson_node_00010), the inference process will predict multiple versions of the test image (original, horizontally flipped, vertically flipped) and average the resulting denoised outputs. This ensemble-like approach reduces random variance in the predictions.
