Based on the comprehensive analysis of the previous experiments and the specific requirements of the image denoising task, I propose the **Coordinate Residual Dense U-Net (CoRD-ResUNet)**.

This strategy introduces a **Structural Innovation** by integrating **Residual Dense Blocks (RDBs)** into the U-Net backbone. This addresses the "Spatial Depth" limitation identified in Lesson 00041 and the "Feature Reuse" needs implied by Lesson 00007, while strictly adhering to the "Local Inductive Bias" (Lesson 00031) and "Capacity" (Lesson 00021) constraints that caused previous advanced architectures to fail.

### Model: Coordinate Residual Dense U-Net (CoRD-ResUNet)
The architecture is a U-Net that replaces standard Residual Blocks with **Residual Dense Blocks** enhanced with Coordinate Attention.

*   **Structural Innovation: Residual Dense Blocks (RDBs)**
    *   **Mechanism:** Instead of the standard `Conv-BN-Act-Conv-BN-Act` block, each block consists of **3 densely connected convolutional layers**. The input to the $k$-th layer is the concatenation of the outputs from all preceding layers ($0$ to $k-1$) in the block.
    *   **Configuration:**
        *   **Growth Rate:** 32 (each dense layer outputs 32 channels).
        *   **Local Feature Fusion:** A **1x1 Convolution** aggregates the concatenated dense features back to the base channel dimension (64).
        *   **Residual Connection:** The block input is added to the fused output.
    *   **Rationale:** This structure significantly increases the **Spatial Depth** (number of non-linear transformations) and effective receptive field per block without the parameter explosion of simply widening the network. It solves the "Inverted Residual" failure (Cite solution_lesson_node_00041) by ensuring multiple spatial convolutions are applied, and it avoids the "Channel Splitting" failure of Res2Net (Cite solution_lesson_node_00038) by using concatenation (feature accumulation) instead of grouping.
*   **Coordinate Attention (CA):** We insert a **Coordinate Attention** module immediately after the Local Feature Fusion in every RDB.
    *   **Rationale:** This filters the aggregated dense features based on their vertical and horizontal positional statistics, ensuring the model distinguishes between structural text strokes and random noise before the residual addition (Cite solution_lesson_node_00026).
*   **Backbone Components:**
    *   **Base Capacity:** We strictly maintain a base filter count of **64** (Cite solution_lesson_node_00021).
    *   **Inductive Bias:** All spatial layers use **3x3 Convolutions** to preserve the strong local bias required for denoising (Cite solution_lesson_node_00031).
    *   **Bottleneck:** We retain the **Atrous Spatial Pyramid Pooling (ASPP)** module to capture multi-scale global context (Cite solution_lesson_node_00026).
    *   **Upsampling:** We utilize **Transposed Convolutions** to ensure sharp edge reconstruction (Cite solution_lesson_node_00020).
    *   **Activation:** **SiLU (Swish)** is used throughout (Cite solution_lesson_node_00016).
*   **Global Residual Learning:** The network predicts the **noise residual** ($Clean = Input - Prediction$) (Cite solution_lesson_node_00013).

### Data: High-Density Contextual Processing
*   **Preprocessing:** Images are loaded in grayscale and normalized to [0, 1].
*   **Patch Size:** We will strictly use **128x128** patches. This ensures sufficient spatial context for the RDBs and Attention modules to function effectively (Cite solution_lesson_node_00022).
*   **Sampling Density:** We will employ **High-Density Sampling**, extracting **100 random patches per image per epoch**. This provides the rich gradient signal necessary to train the dense connections and attention mechanisms (Cite solution_lesson_node_00014).
*   **Augmentation:** We will apply aggressive geometric augmentations (random horizontal flips, vertical flips, and discrete 90-degree rotations) to exploit the rotational symmetry of the noise (Cite solution_lesson_node_00010).

### Training: Regularized Residual Optimization
*   **Objective:** Minimize **Mean Squared Error (MSE)** on the predicted noise residual.
*   **Optimizer:** We will use **AdamW** with an aggressive **weight decay of 1e-2**. This strong regularization is essential to prevent the increased parameter count of the RDBs from overfitting the small dataset (Cite solution_lesson_node_00015).
*   **Scheduler:** A **Cosine Annealing** learning rate scheduler will be used to gradually reduce the learning rate, ensuring convergence to a sharp minimum (Cite solution_lesson_node_00014).
*   **Duration:** We will train for **100 epochs**. We explicitly acknowledge the "convergence tax" of this sophisticated architecture and allocate sufficient time for the dense features to converge (Cite solution_lesson_node_00019).

### Evaluation: Robust Ensemble Inference
*   **Tiled Inference with Overlap:** Test images will be processed using a sliding window with **50% overlap**. Predictions in overlapping regions will be averaged to eliminate boundary artifacts and ensure every pixel is predicted with centered context (Cite solution_lesson_node_00023).
*   **Test-Time Augmentation (TTA):** We will generate predictions for the original image and its geometric transformations (flips/rotates) and average the results. This ensemble approach reduces variance and improves robustness against random noise patterns (Cite solution_lesson_node_00013).
