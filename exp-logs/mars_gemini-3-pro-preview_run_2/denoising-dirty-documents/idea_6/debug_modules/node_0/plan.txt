The following script demonstrates the end-to-end usage of the provided library for the image denoising task.

### Implementation Strategy
1.  **Configuration Setup**: We override specific configurations in `Config` to create a "demo" environment. This includes setting a separate working directory, reducing the number of epochs to 1, and lowering the sampling rate (patches per image) to ensure the script completes quickly.
2.  **Data Preparation**: To further speed up the demonstration, we create temporary subset metadata files containing only a few samples from the original `train`, `val`, and `test` metadata.
3.  **Component Verification**:
    *   **Dataset**: We instantiate the `DenoisingDataset` and verify that it correctly loads images, applies normalization, and produces tensors of the expected shape (Channels, Height, Width).
    *   **Model**: We instantiate the `AG_CAC_ResUNet` model and perform a forward pass with a dummy tensor to confirm that the architecture is valid and preserves spatial dimensions.
    *   **Metric**: We verify the `calculate_rmse` function with known values.
4.  **Training Loop**: We execute the `train_model` function using the subset data. This demonstrates the integration of the dataset, model, loss calculation, and optimization loop. We verify that a model checkpoint is saved.
5.  **Inference & Submission**: We demonstrate the advanced inference capabilities (`predict_tiled` and `predict_tta`) on the test subset. Finally, we generate a submission file formatted according to the competition requirements and verify its structure.
