The error `TypeError: XGBModel.fit() got an unexpected keyword argument 'early_stopping_rounds'` is caused by an API change in recent XGBoost versions, where `early_stopping_rounds` must be passed to the model constructor rather than the `fit()` method (Cite debug_lesson_1).

To fix this, I will:
1.  Update `library/config.py` to define `EARLY_STOPPING_ROUNDS` before `XGB_PARAMS` and include it directly in the `XGB_PARAMS` dictionary. This ensures the parameter is passed when `XGBRegressor` is initialized.
2.  Update `library/model.py` to remove the `early_stopping_rounds` argument from the `self.model.fit()` call.
