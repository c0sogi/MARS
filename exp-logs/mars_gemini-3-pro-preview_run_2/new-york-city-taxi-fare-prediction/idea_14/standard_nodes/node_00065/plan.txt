2.  **Wisdom Phase (Global Statistics)**: Load the strict training data and fit the `InteractionStatsEngine`. This computes the multi-scale interaction priors (Geohash levels 5, 6, 7) from the full dataset, which are crucial for the model's performance.
3.  **Learner Phase (Training Data)**: Load a subsample (5M rows) of the training data with loose filtering. Apply the `InteractionStatsEngine` to generate features using vectorized K-Fold subtraction. This prevents data leakage while providing robust features.
4.  **Validation Phase**: Load the full validation set with loose filtering. Apply the `InteractionStatsEngine` using direct mapping (since these are "unseen" rows relative to the fold statistics).
5.  **Model Training**: Initialize the `XGBoostTrainer` with default parameters (optimized for A100). Train the model on the processed training data, using the validation set for early stopping.
6.  **Evaluation & Failure Analysis**:

    *   Calculate the absolute error for each prediction.
    *   Compute and print the Pearson correlation between the absolute error and each input feature to identify sources of model failure.
