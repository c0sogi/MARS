I will implement a robust EDA script tailored for the tabular New York City Taxi Fare dataset. The script will load the training data from the parquet file generated in the metadata step. Given the large size of the dataset (~44 million rows), I will perform memory-efficient operations for global statistics and utilize stratified sampling for computationally intensive tasks like training the Random Forest for feature importance.

The implementation strategy is as follows:
1.  **Setup and Loading**: Initialize the environment, set random seeds for reproducibility, and load the `train.parquet` file.
2.  **Preprocessing**: Convert the `pickup_datetime` column to datetime objects to extract meaningful numerical features (hour, day, month, year, weekday) which are crucial for taxi fare prediction.
3.  **Target Analysis**: Analyze `fare_amount` for distribution properties, specifically skewness and kurtosis, to assess normality.
4.  **Input Data Analysis**:
    *   Calculate descriptive statistics (mean, std, min, max) for numerical features (coordinates, passenger count).
    *   Identify missing values.
    *   Detect outliers using the Interquartile Range (IQR) method.
5.  **Feature Relationships**:
    *   Compute a correlation matrix (using a subset for speed) to identify linear relationships and redundancy.
    *   Train a lightweight Random Forest Regressor on a sampled subset to determine the top 5 most important features.
6.  **Reporting**: Output the findings in the specified format, ensuring all floating-point numbers are formatted to 4 decimal places.
