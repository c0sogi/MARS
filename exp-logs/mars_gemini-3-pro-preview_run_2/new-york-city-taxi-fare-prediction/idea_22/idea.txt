Based on the accumulated lessons, I propose a **Hierarchical Distributional Fingerprinting** strategy with **Corrected Dual-Hygiene Encoding**.

This approach structurally synthesizes the **Hierarchical Spatial Context** (Cite {solution_lesson_node_00072}), the **Risk-Awareness of Distributional Moments** (Cite {solution_lesson_node_00071}), and the **Stability of Dual-Hygiene** (Cite {solution_lesson_node_00066}). Crucially, it introduces a novel **Intersection-Filtered Vectorized Subtraction** pipeline to resolve the logical conflict between K-Fold encoding and Dual-Hygiene filtering, ensuring mathematical correctness where previous attempts failed.

# Model
I will utilize the **XGBoost Regressor** as the backbone, leveraging its proven superiority over Deep Learning for low-dimensional spatial tasks (Cite {solution_lesson_node_00030}).

*   **Structural Innovation (Distributional Fingerprinting):** Instead of providing a single "Expected Fare" (Mean) which smooths out critical risk information, I will provide the model with a **Distributional Fingerprint** for every route. This consists of:
    1.  **Mean (Expected Value):** The baseline cost.
    2.  **Standard Deviation (Volatility):** Captures reliability. A high deviation signals the model to look for temporal triggers (e.g., traffic) that cause price surges, allowing it to predict heavy-tail outliers conditionally (Cite {solution_lesson_node_00071}).
    3.  **Count (Confidence):** Allows the tree to weigh the credibility of the prior.
*   **Hierarchical Architecture:** These fingerprints will be generated simultaneously at three spatial resolutions: **Micro** (Geohash L7, ~150m), **Meso** (Geohash L6, ~1km), and **Macro** (Geohash L5, ~5km). This creates a "Pyramid of Priors" that allows the tree to dynamically shift focus from fine-grained memorization to regional smoothing based on data density (Cite {solution_lesson_node_00072}).
*   **Soft Integration:** These features will be supplied as **Input Features**, not Base Margins. This prevents the catastrophic failures seen with hard integration in sparse regions (Cite {solution_lesson_node_00055}, Cite {solution_lesson_node_00070}).

# Data
The data pipeline employs a **Dual-Hygiene Strategy** combined with **Intersection-Filtered Vectorized Subtraction** to maximize signal quality while preventing leakage.

1.  **Input Sanitization (Safety First):**
    *   Strictly clamp all pickup and dropoff coordinates in the **Training, Validation, and Test sets** to the NYC bounding box immediately. This mitigates the risk of linear extrapolation from corrupt GPS data (Cite {solution_lesson_node_00003}, Cite {solution_lesson_node_00070}).

2.  **Dual-Hygiene Definitions (Cite {solution_lesson_node_00066}):**
    *   **Wisdom Set (Background):** Use the **Full 55M Dataset**. Apply **Strict Filtering** (Fare between $2.50 and $200, Fare/Km < $10). This dataset is used *exclusively* to generate clean, robust statistical fingerprints.
    *   **Learner Set (Foreground):** Select a stable **Subsample (5M rows)**. Apply **Loose Filtering** (Fare > $2.50). Retain valid high-fare outliers (e.g., >$500) to ensure the model learns to predict the "Heavy Tail" required for the RMSE metric (Cite {solution_lesson_node_00018}).

3.  **Feature Engineering (Intersection-Filtered Vectorized Subtraction):**
    *   **Global Aggregation:** Compute `Sum_Fare`, `Sum_FareSq`, and `Count` for all Geohash levels (L5, L6, L7) using the **Wisdom Set**.
    *   **Training Encoding:** For the Learner Set, use **K-Fold Target Encoding**.
    *   **Correction Mechanism (The Innovation):** To compute out-of-fold stats efficiently without leakage or logic errors:
        *   Identify rows in the current Learner Fold that *also* meet the **Strict Wisdom Criteria**.
        *   Compute the sums/counts of *only* these rows.
        *   Subtract these "Filtered Fold Stats" from the "Global Wisdom Stats" to get the "Rest-of-World Wisdom Stats".
        *   *Rationale:* This corrects the logic error of simply subtracting the Learner Fold (which contains outliers) from the Wisdom Global (which does not), ensuring the priors remain strictly clean and mathematically valid (Cite {solution_lesson_node_00045}, Cite {solution_lesson_node_00060}).

4.  **Inductive Bias:** Retain explicit geometric features (Haversine, Manhattan, Rotated Coordinates) and raw temporal features (Hour, Year) to allow the model to predict deviations from the priors (Cite {solution_lesson_node_00046}, Cite {solution_lesson_node_00065}).

# Training
1.  **Objective Function:** Use **`reg:squarederror`** (Standard L2 Loss).
    *   **Rationale:** We are training on a stable subsample with robust, clean Distributional Fingerprints. The optimization landscape is stable enough to use L2 loss, which aligns perfectly with the RMSE metric. We avoid robust losses (Huber) as they fail to prioritize the high-fare outliers explicitly retained in the Learner target (Cite {solution_lesson_node_00037}).
2.  **Target:** Train on the **raw `fare_amount`** (Loose Filtered). Do not log-transform (Cite {solution_lesson_node_00025}).

# Evaluation
1.  **Inference:**
    *   **Clamp Test Coordinates** to the NYC bounding box immediately (Cite {solution_lesson_node_00003}).
    *   Map coordinates to Geohashes (L5, L6, L7).
    *   Retrieve the **Global Wisdom Fingerprints** (Mean, Std, Count) directly from the full dataset aggregates (no subtraction needed).
2.  **Prediction:** Generate predictions using the XGBoost model.
3.  **Post-Processing:** Apply a minimum fare floor ($2.50).
