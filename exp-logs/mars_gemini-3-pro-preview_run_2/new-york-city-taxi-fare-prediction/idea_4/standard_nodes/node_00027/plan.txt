The issue is that the model is trained on log-transformed targets to stabilize gradients (as configured by `USE_LOG_TARGET = True`), but the evaluation metric and final submission must be in the original dollar scale. The current implementation calculates the RMSE on the log-transformed values (effectively RMSLE) and writes log-scale predictions to the CSV, resulting in invalid metrics and incorrect submission values. To fix this, I will update `runfile.py` to inverse-transform the predictions and targets using `inverse_log_transform` before calculating the RMSE and generating the submission file.
