Strategy:
1.  **Revert Target Transformation**: Disable the log-transformation of the target variable `fare_amount`. The previous solution's failure analysis and Lesson 00025 indicate that optimizing RMSE on a log-transformed target (which minimizes MSLE) leads to under-prediction on heavy-tailed data. We will train on the raw dollar scale to align the loss function with the evaluation metric.
2.  **Sanitize Training Data**: Apply a strict upper bound filter to the training set (e.g., `fare_amount < 500`). Lesson 00017 highlights that extreme outliers in the training set (max ~$93k) destabilize L2-based optimization (like XGBoost with squared error). We will remove these outliers from the training data to ensure model stability.
3.  **Use Full Dataset**: Switch from debug mode (12M rows) to the full dataset (44M rows) for training. With the target variable sanitized, the model should benefit from the larger dataset without being corrupted by outliers (addressing the issue in Lesson 00017 where full data failed due to lack of sanitization).
4.  **Adjust Evaluation**: Update the reporting and prediction logic to handle raw values instead of log-transformed values.
