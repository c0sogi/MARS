The strategy is to load the raw tabular data from `input/labels.csv` and `input/test.csv`. Since the dataset is a regression task with no inherent groups (like user IDs) specified for grouping, and it is not a classification task, I will perform a standard random 80:20 split to create training and validation sets using a fixed random state. The resulting datasets will be saved as Parquet files in the `metadata` directory to serve as efficient metadata/data loaders for downstream tasks. Finally, the script will reload these files to verify the split ratios, data integrity, and print summary statistics.
