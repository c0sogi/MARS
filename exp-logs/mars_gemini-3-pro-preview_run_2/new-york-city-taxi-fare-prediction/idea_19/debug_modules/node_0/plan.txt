This script demonstrates the usage of the provided library modules for the NYC Taxi Fare Prediction task. It employs a strategy of creating a small, synthetic dataset to simulate the pipeline execution rapidly, ensuring all components (Utils, StatsManager, DataPipeline, FeatureBuilder, ModelTrainer) are exercised and validated within the time constraints.

### Implementation Strategy

1.  **Configuration Override**: We dynamically modify `ProjectConfig` to point to a temporary working directory and use reduced hyperparameters (e.g., fewer XGBoost estimators, smaller data subsets) to ensure immediate execution.
2.  **Synthetic Data Generation**: We generate small Parquet files mimicking the schema of the real dataset (`train`, `val`, `test`) in the `./working` directory. This allows us to test the full data loading and processing logic without reading the massive 55M row dataset.
3.  **Component Validation**:
    *   **Utils**: validate geometric calculations (Haversine, Geohash) with assertions.
    *   **StatsManager**: Verify that hierarchical statistical priors are computed correctly from the synthetic "Wisdom" set.
    *   **FeatureBuilder**: Confirm that geometric features and statistical enrichments are added to a DataFrame.
    *   **DataPipeline**: Ensure the pipeline correctly loads, cleans, and splits data into Train/Val/Test sets.
    *   **ModelTrainer**: Execute a full training cycle (Train -> Save -> Predict) and verify the generation of the submission file.
