Based on the lessons learned, I propose a **Two-Stage Global-Local Gradient Boosting** strategy. This approach resolves the fundamental conflict between the need to utilize the full dataset's information to capture high-fare outliers (Lesson 00018) and the instability of training a model on the full dataset using L2 loss (Lesson 00017).

# Model
I will retain the **XGBoost Regressor** as the backbone, as it has proven structurally superior to Deep Learning for this low-dimensional spatial task **Cite {solution_lesson_node_00030}**.
*   **Structural Innovation:** The model will not rely solely on geometric features (distance) or local batch statistics. Instead, it will be fed **Global-Scale Out-of-Fold (OOF) Target Encodings**. These features act as "priors," explicitly informing the model of the expected price for a route based on the entire 55M-row history, effectively decoupling "knowledge aggregation" (Stage 1) from "gradient learning" (Stage 2).

# Data
The data pipeline is split into two distinct stages to maximize signal retention while ensuring training stability.

**Stage 1: Global Feature Extraction (The "Wisdom of the Crowd")**
1.  **Coordinate Discretization:** Discretize the `pickup` and `dropoff` coordinates of the **entire 55M row dataset** into high-resolution Geohashes or Grid Cells (e.g., precision 6 or 7).
2.  **Out-of-Fold Target Encoding:** Partition the full dataset into $K$ folds (e.g., 5). For each fold, calculate the **Mean Fare** for every unique `(Pickup_Cell, Dropoff_Cell)` route using data from the *other* $K-1$ folds.
    *   **Rationale:** This leverages the massive scale of the full dataset to accurately estimate fares for rare routes and high-fare outliers, which a subsampled dataset would miss. This directly addresses the "heavy tail" prediction problem **Cite {solution_lesson_node_00038}**.
    *   **Safety:** By using OOF calculation, we prevent data leakage, ensuring the feature represents historical knowledge rather than the label itself.

**Stage 2: Training Set Construction**
1.  **Subsampling:** From the enriched 55M dataset, randomly sample a **stable subset** (e.g., 5 million rows) for the actual model training.
    *   **Rationale:** Lesson 00017 proved that training on the full 55M dataset with L2 loss causes gradient instability due to the accumulation of extreme outliers. By training on a subset, we maintain the stability of the "Small Data" solution **Cite {solution_lesson_node_00017}**, but the model is now "smarter" because it sees the Global OOF features derived from the full data.
2.  **Input Clamping:** Strictly clamp all spatial coordinates in the training sample to the NYC bounding box to prevent linear extrapolation risks **Cite {solution_lesson_node_00003}**.
3.  **Target Preservation:** Use the **raw `fare_amount`** as the target. Do **not** truncate outliers (e.g., >$500) and do **not** log-transform.
    *   **Rationale:** Truncation destroys the ability to predict valid high fares **Cite {solution_lesson_node_00018}**, and log-transformation biases the RMSE metric **Cite {solution_lesson_node_00025}**.

# Training
1.  **Objective Function:** Use **`reg:squarederror`** (Standard L2 Loss).
    *   **Rationale:** Since we are training on a subsample (where extreme outliers are statistically less dominant) and providing the model with explicit "expected fare" features, we can safely use the loss function that aligns perfectly with the RMSE metric. We avoid robust losses (Huber) which were shown to underperform on this specific metric **Cite {solution_lesson_node_00037}**.
2.  **Features:** The model will train on:
    *   Global OOF Route Average (from Stage 1).
    *   Haversine/Manhattan Distances.
    *   Rotated Coordinates.
    *   Temporal Embeddings (Hour, Year).

# Evaluation
1.  **Global Lookup:** For the test set, generate the `Route_Avg_Fare` feature using the statistics computed from the **entire 55M row training set** (no folding required for inference).
    *   **Fallback:** If a test route was never seen in the 55M dataset, fall back to a global distance-based estimate.
2.  **Prediction:** Generate predictions using the XGBoost model.
3.  **Post-Processing:** Apply a minimum fare floor ($2.50) and clamp coordinates **Cite {solution_lesson_node_00003}**.
