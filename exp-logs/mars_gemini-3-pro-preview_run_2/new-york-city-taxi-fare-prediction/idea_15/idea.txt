Based on the analysis of the provided lessons and the evolution of previous experiments, I propose a **Factorized Spatiotemporal Dual-Hygiene Gradient Boosting** strategy. This approach structurally synthesizes the "Dual-Hygiene" stability of Idea 15 with a novel **Factorized Target Encoding** scheme to capture time-dependent pricing dynamics (e.g., traffic, surcharges) without incurring the sparsity penalties of high-dimensional interaction grids.

# Model
I will utilize the **XGBoost Regressor** as the backbone, leveraging its proven superiority over Deep Learning for low-dimensional spatial tasks **Cite {solution_lesson_node_00030}**.
*   **Structural Innovation (Factorized Spatiotemporal Integration):** Instead of relying solely on Spatial Interaction priors (Route Average) which average out temporal variances **Cite {solution_lesson_node_00065}**, or attempting sparse Space-Time grids (Route x Hour) which fail due to lack of data **Cite {solution_lesson_node_00062}**, I will decompose the prior into two dense factors:
    1.  **Spatial Base:** The historical average fare for the specific A-to-B route (Multi-Scale Geohash).
    2.  **Temporal Rate Multiplier:** The historical average *Fare-Per-Km* for the neighborhood at that specific hour.
    These will be fed as **Input Features** ("Soft Integration") to the model, allowing it to synthesize a "Time-Adjusted Expected Fare" while retaining the flexibility to handle deviations **Cite {solution_lesson_node_00055}**.

# Data
The data pipeline employs a **Dual-Hygiene Strategy** with **Vectorized Subtraction** to maximize signal quality and temporal resolution.

1.  **Dual-Hygiene Preprocessing:**
    *   **Wisdom Set (Statistics Generation):** Use the **Full 55M Dataset**. Apply **Strict Physics-Consistent Filtering**: Remove outliers (e.g., Fare > $200, Fare/Km > $10) and short trips (< 200m) to prevent "garbage" noise from corrupting the statistical priors **Cite {solution_lesson_node_00017}**.
    *   **Learner Set (Model Training):** Select a stable **Subsample (5M rows)**. Apply **Loose Filtering**: Retain valid high-fare outliers (e.g., long trips > $500) to ensure the model learns to predict the "Heavy Tail" required for the RMSE metric **Cite {solution_lesson_node_00018}**.

2.  **Factorized Feature Engineering:**
    *   **View 1: Multi-Scale Spatial Interaction (The "Where"):** Compute `Mean_Fare` for `(Pickup_Geohash, Dropoff_Geohash)` pairs at Levels 5 (~5km), 6 (~1km), and 7 (~150m). This captures static route pricing **Cite {solution_lesson_node_00066}**.
    *   **View 2: Spatiotemporal Rate (The "When"):**
        *   In the Wisdom Set, calculate `Unit_Rate = Fare_Amount / Haversine_Distance`.
        *   Aggregate `Mean_Unit_Rate` by `(Pickup_Geohash5, Hour, Weekday)`.
        *   **Feature:** `Temporal_Prior = Mean_Unit_Rate * Current_Haversine_Distance`.
        *   **Rationale:** This explicitly captures dynamic pricing (e.g., "Midtown traffic at 5 PM costs $2/km instead of $1/km") without the sparsity of exact route matching.
    *   **Vectorized Subtraction:** Apply these encodings to the Learner Set using **K-Fold Vectorized Subtraction** (Global Stats - Fold Stats) to prevent data leakage while utilizing the full depth of the 55M dataset **Cite {solution_lesson_node_00045}**.

3.  **Inductive Bias Preservation:**
    *   Retain explicit geometric features (Haversine, Manhattan, Rotated Coordinates) and raw temporal features (Hour, Year) to allow the model to predict deviations from the priors **Cite {solution_lesson_node_00065}**.
    *   Strictly clamp all input coordinates to the NYC bounding box **Cite {solution_lesson_node_00003}**.

# Training
1.  **Objective Function:** Use **`reg:squarederror`** (Standard L2 Loss).
    *   **Rationale:** We are training on a stable subsample with robust, clean Factorized Priors. The optimization landscape is stable enough to use L2 loss, which aligns perfectly with the RMSE metric. We avoid robust losses (Huber) as they fail to prioritize the high-fare outliers explicitly retained in the Learner target **Cite {solution_lesson_node_00037}**.
2.  **Target:** Train on the **raw `fare_amount`**. Do not log-transform, as this biases the RMSE **Cite {solution_lesson_node_00025}**.

# Evaluation
1.  **Inference:**
    *   Map the test set coordinates to Geohashes (L5, L6, L7).
    *   Retrieve the **Spatial Base** and **Temporal Rate** priors using the **Strict Global Statistics** derived from the full 55M Wisdom Set (no subtraction needed).
2.  **Prediction:** Generate predictions using the XGBoost model.
3.  **Post-Processing:** Apply a minimum fare floor ($2.50) and ensure coordinate clamping is applied to test inputs **Cite {solution_lesson_node_00003}**.
