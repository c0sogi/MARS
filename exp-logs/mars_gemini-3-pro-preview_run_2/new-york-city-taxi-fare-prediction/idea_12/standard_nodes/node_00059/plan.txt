The implementation strategy follows the Disjoint Background-Foreground Gradient Boosting architecture defined in the provided library files.

1.  **Initialization**: We instantiate the `Config` class. We use `debug=False` to ensure we use the sufficient dataset size (5M Foreground, 38M Background) to achieve the target RMSE, as the A100 GPU can easily handle this volume within the time limit.
2.  **Data Loading**: We use `DataLoader` to load and split the raw data into Background (for priors), Foreground (for training), Validation, and Test sets.
3.  **Feature Engineering**: We use `FeatureEngineer` to generate spatial keys (simulated Geohashes) and physical features. The Background set only receives minimal features needed for aggregation, while Foreground, Validation, and Test sets receive full physical features.
4.  **Knowledge Base Construction**: We use `KnowledgeBase` to compute statistical priors (Mean Fare, Mean Rate) from the Background set at multiple resolutions (Fine, Coarse, Temporal).
5.  **Enrichment**: We enrich the Foreground, Validation, and Test sets by joining these priors. This injects the "Wisdom" from the 38M background rows into the training process without data leakage.
6.  **Training**: We train the `TaxiFareModel` (XGBoost) on the enriched Foreground set, using the enriched Validation set for early stopping.
7.  **Evaluation**: We perform inference on the full validation set to compute the final RMSE. We also conduct a failure analysis by correlating the absolute errors with input features to identify weak points.
8.  **Submission**: If the validation RMSE is below the threshold (3.5069...), we generate predictions for the test set and save the submission file.
