This script demonstrates the end-to-end usage of the provided library files to train a model and generate a submission for the Taxi Fare Prediction task.

**Implementation Strategy:**
1.  **Configuration Overrides**: We dynamically modify the `Config` class attributes to enable `DEBUG` mode (using a small subset of 20,000 rows), reduce training epochs to 2, and point to a temporary working directory. This ensures the script runs quickly (under 5 minutes) while exercising all code paths.
2.  **Data Processing**: We explicitly invoke `DataProcessor.process_data(load_cached_data=False)` to trigger the feature engineering pipeline on the debug subset and verify that the output dataframes match the expected dimensions.
3.  **Dataset & Model Verification**: We instantiate `TaxiDataset` and `SpatialResNet` to inspect the data structures (tensors) and perform a dummy forward pass. This confirms that the data shapes align with the model architecture.
4.  **Training & Submission**: We use the `Trainer` class to run the training loop (`fit`) and generate predictions (`generate_submission`).
5.  **Output Validation**: Finally, we load the generated submission CSV to verify it meets the competition requirements (correct row count, no missing values).
