Based on the accumulated lessons, I propose the **Wide-Expanded Bottleneck Network (WEBN)**.

This solution introduces a structural evolution by decoupling **feature extraction capacity** from **classification complexity**. It synthesizes the conflicting findings of Lesson 49 (which demands a wide backbone for feature quality) and Lesson 41 (which demands a narrow output to prevent dense-layer overfitting) into a single, unified architecture with a "Bell Curve" width profile.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a novel visual backbone design.

1.  **Visual Branch (Wide-Expanded Bottleneck Backbone)**:
    *   **Concept**: Unlike standard VGG-style networks that linearly double filters (e.g., 32$\to$64$\to$128$\to$256), this backbone uses an **Expansion-Compression** strategy. It expands rapidly in the middle layers to create a high-dimensional manifold for separating complex radar textures, then strictly contracts in the final layer to project these features into a compact space.
    *   **Stage 1 (Stem)**: 3x3 Convolution with **64 filters**. Followed by BatchNorm, ReLU, and **Max Pooling** (Cite solution_lesson_node_00021).
    *   **Stage 2 (Expansion)**: 3x3 Convolution with **128 filters**. This width ensures the network has sufficient capacity to learn diverse texture filters (Cite solution_lesson_node_00049).
        *   **Attention**: Apply **Convolutional Block Attention Module (CBAM)** here to refine the expanded feature set (Cite solution_lesson_node_00029).
    *   **Stage 3 (Peak Width)**: 3x3 Convolution with **256 filters**. This maximizes the receptive field's feature richness.
        *   **Attention**: Apply **CBAM** again to focus on signal peaks within this high-dimensional space.
    *   **Stage 4 (Projector/Bottleneck)**: 3x3 Convolution with **48 filters**. This is the structural innovation. Instead of doubling to 512, the network explicitly learns to compress the 256 semantic features down to 48. This **Channel Contraction** (Cite solution_lesson_node_00041) drastically reduces the flattened vector size (from 4096 to 768), preventing the parameter explosion in the dense head that caused previous wider models to fail.
    *   **Output**: **Flatten** the final 4x4x48 feature map. This retains coarse spatial geometry (Cite solution_lesson_node_00021) without the massive dimensionality of a non-contracted network.

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar.

3.  **Fusion Head**:
    *   Concatenate the compact flattened visual vector and the metadata vector.
    *   Process through a classification head with Batch Normalization, ReLU, and **Moderate Dropout (0.2)** (Cite solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1]. This maximizes contrast for each physical signal type (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Explicitly exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).
    *   **Restriction**: Do not use Mixup, as it induces underfitting in this small-data regime (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the WEBN. This is critical to reduce variance and avoid selection bias (Cite solution_lesson_node_00029, solution_lesson_node_00032).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize the Adam optimizer with a conservative learning rate (e.g., **2e-4**) (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights, avoiding reference mutation bugs (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.2). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained WEBN models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance (Cite solution_lesson_node_00036).
