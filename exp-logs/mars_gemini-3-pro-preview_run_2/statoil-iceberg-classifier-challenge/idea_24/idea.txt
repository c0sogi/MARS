Based on the comprehensive analysis of the accumulated lessons, I propose the **Post-Pooling Contracted Wide-Body Network (PPC-WBN)**.

This solution represents a structural synthesis that resolves the primary conflict identified in the development history: the tension between the need for a **Wide Backbone** (to capture complex texture, Cite solution_lesson_node_00077) and the instability caused by **Feature Expansion** (Cite solution_lesson_node_00092) and **Parameter Explosion** (Cite solution_lesson_node_00041). It introduces a novel **"Expand-Then-Contract" Block Topology** and a **Quadrant-Based Readout** to maximize signal retention while strictly controlling model complexity.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone.

1.  **Visual Branch (Post-Pooling Contracted Backbone)**:
    *   **Sustained Width Strategy**: The backbone maintains a sustained width of **128 filters** across all four stages. This avoids the underfitting observed in narrowed architectures (Cite solution_lesson_node_00077) and avoids the destructive "Terminal Bottleneck" of reducing channels in the final layer (Cite solution_lesson_node_00055).
    *   **Block Topology (Structural Innovation)**: Each convolutional block is restructured to explicitly manage the "Shadow Preservation" vs. "Channel Explosion" trade-off:
        1.  **Wide Convolution**: 3x3 Conv with **128 filters** $\to$ BN $\to$ ReLU.
        2.  **Attention (Pre-Pooling)**: Apply **CBAM** strictly before pooling to refine features at high resolution (Cite solution_lesson_node_00061). Crucially, use **Mixed Pooling (Max+Avg)** for attention generation, avoiding the instability of Min-pooling in attention (Cite solution_lesson_node_00095, solution_lesson_node_00079).
        3.  **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth to $128 \times 2 = 256$, preserving the full dynamic range (Cite solution_lesson_node_00070).
        4.  **Immediate Contraction**: Insert a **1x1 Convolution** immediately after pooling to project the 256 channels back down to **128**. This satisfies the requirement to "couple feature-expanding operations with channel contraction" (Cite solution_lesson_node_00092), preventing the noise propagation and instability observed in previous wide models.
    *   **Readout (Quadrant Max Pooling)**:
        *   The final output is $4 \times 4 \times 128$. Flattening this would yield 2048 parameters.
        *   Instead, apply **Adaptive Max Pooling** to a **$2 \times 2$ grid (Quadrants)**.
        *   This reduces the spatial dimension while preserving the strongest signal peak in each quadrant (Cite solution_lesson_node_00021).
        *   **Result**: The flattened vector is $2 \times 2 \times 128 = 512$ dimensions. This is highly efficient, solving the "Parameter Explosion" problem (Cite solution_lesson_node_00041) without sacrificing the backbone's width.

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the Quadrant-Pooled visual vector (512 dim) and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Strict Fold-wise Preprocessing (Crucial)**: Implement **Independent Per-Channel Min-Max Scaling** (Cite solution_lesson_node_00025). Crucially, calculate the scaling statistics **exclusively on the training subset** of the current fold and apply them to the validation subset. This eliminates the data leakage present in previous global scaling approaches (Cite solution_lesson_node_00097).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the PPC-WBN. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format. Use the **average scaling statistics** derived from the training folds to normalize the test data (or ensemble predictions from models scaled with their respective fold stats).
2.  **Ensemble Prediction**: Pass the test data through all 5 trained PPC-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
