Based on the comprehensive analysis of the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **Contrast-Augmented Wide-Body Network (CA-WBN)**.

This solution represents a structural evolution that resolves the "Low Contrast Sensitivity" issue (Lesson 115, 123) and "Texture Ambiguity" (Lesson 127) by explicitly modeling the **Local Contrast** (Peak-to-Shadow Ratio) at the readout stage. It retains the robust **Wide-Body Backbone** (Cite solution_lesson_node_00077) and **Dual-Pooling** (Cite solution_lesson_node_00070) but introduces a **Tri-Path Readout** that adds a dedicated "Contrast Stream". Unlike previous attempts that relied on implicit learning or noisy higher-order statistics (StdDev), this stream leverages the backbone's explicit Max/Min separation to compute a robust, translation-invariant measure of shadow depth, critical for distinguishing icebergs from clutter.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and a novel contrast-aware readout.

1.  **Visual Branch (Wide-Body Delayed-Integration Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across Stages 2, 3, and 4. This avoids underfitting (Cite solution_lesson_node_00077) and prevents destructive terminal bottlenecks (Cite solution_lesson_node_00055).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **256** (from the previous block's Dual-Pooling). The convolution maps $256 \to 128$ filters. This performs feature integration **at the start of the new receptive field**, satisfying **Delayed Integration** (Cite solution_lesson_node_00107).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range of the signal (Cite solution_lesson_node_00070).
    *   **Structural Innovation: Contrast-Augmented Tri-Path Readout**:
        *   The output of Stage 4 is a $4 \times 4 \times 256$ tensor. The first 128 channels represent "Local Peaks" (Max), and the last 128 represent "Local Shadows" (Min).
        *   **Path A (Spatial Context)**: Apply a **3x3 Convolution** (Padding=1, Stride=1) to compress channels from 256 to **64**, then **Flatten**.
            *   *Rationale*: Integrates spatial adjacency (Cite solution_lesson_node_00101) and preserves coarse geometry (Cite solution_lesson_node_00112). ($16 \times 64 = 1024$ dim).
            *   **Normalization**: Apply **Batch Normalization (1D)** (Cite solution_lesson_node_00161).
        *   **Path B (Global Intensity)**: Apply **Global Average Pooling** to the full 256-channel volume.
            *   *Rationale*: Captures translation-invariant signal statistics robust to speckle noise (Cite solution_lesson_node_00123). (256 dim).
            *   **Normalization**: Apply **Batch Normalization (1D)**.
        *   **Path C (Global Contrast)**:
            *   Compute the element-wise difference: $Feature_{Diff} = Feature_{Peak} - Feature_{Shadow}$ (first 128 channels minus last 128 channels).
            *   Apply **Global Average Pooling** to $Feature_{Diff}$.
            *   *Rationale*: Explicitly calculates the average "Shadow Depth" or "Local Contrast" across the receptive field. This provides a direct, robust feature for distinguishing high-contrast targets (ships/icebergs) from flat clutter, orthogonal to mean intensity. It avoids the noise of Global Max Pooling (Cite solution_lesson_node_00115) and the instability of StdDev (Cite solution_lesson_node_00127). (128 dim).
            *   **Normalization**: Apply **Batch Normalization (1D)**.

2.  **Metadata Branch (Deep Normalized Embedding)**:
    *   **Structure**: Linear $\to$ ReLU $\to$ Linear $\to$ **Batch Normalization** $\to$ ReLU.
    *   *Rationale*: Models the non-linear incidence angle relationship (Cite solution_lesson_node_00158) while aligning the embedding distribution with the visual features (Cite solution_lesson_node_00155).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse Path A, Path B, Path C, and Metadata vectors. Total dimension: $1024 + 256 + 128 + 32 \approx 1440$.
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)** (Cite solution_lesson_node_00077).
    *   **Output**: Single neuron with Sigmoid activation (Cite solution_lesson_node_00183).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation** using the **Full Dataset** (Cite solution_lesson_node_00165).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Revert from AdamW to Adam. The aggressive weight decay of AdamW combined with high dropout caused underfitting (Cite solution_lesson_node_00124).
3.  **Optimization Protocol**: Strictly adhere to a **"Low and Slow"** strategy with a learning rate of **2e-4**.
    *   *Rationale*: Critical to stabilize the Batch Normalization layers in the readout and fusion head (Cite solution_lesson_node_00157).
4.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
5.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained CA-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission (Cite solution_lesson_node_00036).
