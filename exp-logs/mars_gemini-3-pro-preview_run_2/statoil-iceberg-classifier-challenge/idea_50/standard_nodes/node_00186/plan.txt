1.  **Configuration & Setup**: Import necessary libraries and the provided modules. Adjust `MAX_EPOCHS` to 50 to ensure the training completes within the time limit while allowing sufficient convergence.
2.  **Data Isolation (Monkey Patching)**: To strictly adhere to the requirement of using the `metadata/val.csv` as a hold-out set, I will monkey-patch the `load_data` function in the library. This patch will filter the training data loaded by the pipeline to include *only* the samples listed in `metadata/train.csv`. This ensures the 5-fold Cross-Validation performed by the library runs exclusively on the training split, leaving the validation split completely unseen.
3.  **Training**: Execute the standard training pipeline using `library.trainer.run_training`.
4.  **Hold-out Validation**: Manually load the unseen validation samples using the IDs from `metadata/val.csv`. Load the 5 trained model checkpoints, perform ensemble inference (averaging predictions), and calculate the final Log Loss metric.
5.  **Failure Analysis**: Compute the absolute prediction errors on the validation set and calculate their correlation with the incidence angle to identify potential systematic biases.
6.  **Submission**: Compare the calculated validation metric against the specified threshold (0.1477...). If the model performs sufficiently well, trigger the submission generation using `library.model.predict_and_submit`.
