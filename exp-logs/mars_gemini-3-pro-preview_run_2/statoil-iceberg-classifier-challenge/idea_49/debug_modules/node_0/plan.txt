Implementation Strategy:
1.  **Configuration & Setup**: Import the `Config` class and modify key parameters (e.g., `DEBUG=True`, `NUM_EPOCHS=2`, `BATCH_SIZE=8`) to ensure the demonstration runs quickly. Initialize the logger using `setup_logger`.
2.  **Data Loading Verification**: Use `get_dataloaders` to fetch training and validation loaders. Iterate through one batch to verify the shape and data types of images, angles, and labels. Ensure images are normalized and tensors are on the correct device.
3.  **Model Architecture Verification**: Instantiate the `DCSWBN` model. Perform a forward pass with a dummy batch (or a real batch from the loader) to verify that the model accepts the inputs correctly and produces an output of shape `(Batch_Size, 1)`.
4.  **Training Pipeline Demonstration**: Execute `train_fold` for a single fold using the debug data loaders. This will test the training loop, loss calculation, backpropagation, and validation logic.
5.  **Inference Demonstration**: Use `get_test_dataloader` to load test data. Load the trained model weights (returned by `train_fold`) and perform inference on a batch of test data to demonstrate prediction generation.
6.  **Assertions**: Throughout the script, use `assert` statements to validate shapes, types, and logical consistency (e.g., loss is a scalar, probabilities are between 0 and 1).
