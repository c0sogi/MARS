This script implements the Robust Dual-Path Wide-Body Network (RDP-WBN) pipeline. It overrides the default epoch count to 50 for a faster baseline execution while maintaining the 5-Fold Cross-Validation strategy. It loads the pre-processed data, trains 5 models, and then evaluates the ensemble performance on the specific hold-out validation set defined in the metadata. Failure analysis is performed by correlating prediction errors with incidence angle and image statistics. Finally, if the validation metric meets the required threshold, it generates a submission file using ensemble predictions on the test set.
