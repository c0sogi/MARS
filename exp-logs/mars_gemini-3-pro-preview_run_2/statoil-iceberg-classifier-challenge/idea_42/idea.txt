Based on the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **Deeply-Normalized Wide-Body Network (DN-WBN)**.

This solution represents a structural evolution that resolves the stability issues identified in the "Normalized Fusion" attempt (Lesson 157) while retaining the critical performance gains from **Input Normalization** (Lesson 155) and **Deep Metadata Embedding** (Lesson 158). It combines the robust **Wide-Body Backbone** (Lesson 77) and **Dual-Pooling** (Lesson 70) with a rigorously stabilized **Normalized Fusion Interface**, ensuring that heterogeneous feature streams (Spatial, Intensity, and Metadata) are statistically aligned before interaction.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and a novel normalized fusion interface.

1.  **Visual Branch (Wide-Body Delayed-Integration Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across all four stages. This avoids underfitting (Cite solution_lesson_node_00077) and prevents destructive terminal bottlenecks (Cite solution_lesson_node_00055).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **256** (from the previous block's Dual-Pooling). The convolution maps $256 \to 128$ filters. This performs feature integration **at the start of the new receptive field**, satisfying **Delayed Integration** (Cite solution_lesson_node_00107).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range of the signal (Cite solution_lesson_node_00070).
    *   **Structural Innovation: Normalized Dual-Path Readout**:
        *   The output of Stage 4 is a $4 \times 4 \times 256$ tensor.
        *   **Path A (Spatial Context)**: Apply a **3x3 Convolution** (Padding=1, Stride=1) to compress channels from 256 to **48**, then **Flatten**.
            *   *Rationale*: Integrates spatial adjacency between "Peak" and "Shadow" channels jointly (Cite solution_lesson_node_00152) and preserves coarse geometry (Cite solution_lesson_node_00112).
            *   **Normalization**: Apply **Batch Normalization (1D)** to the flattened vector. This standardizes the spatial features, preventing magnitude imbalances during fusion (Cite solution_lesson_node_00155).
        *   **Path B (Robust Intensity)**: Apply **Global Average Pooling** to the 256-channel volume.
            *   *Rationale*: Captures translation-invariant signal statistics robust to speckle noise, avoiding the sensitivity of Global Max Pooling (Cite solution_lesson_node_00123, solution_lesson_node_00115).
            *   **Normalization**: Apply **Batch Normalization (1D)** to the pooled vector.

2.  **Metadata Branch (Deep Normalized Embedding)**:
    *   **Structure**: Linear $\to$ ReLU $\to$ Linear $\to$ **Batch Normalization** $\to$ ReLU.
    *   *Rationale*: Unlike previous iterations that used a shallow projection (Lesson 158), this restores the **Multi-Layer Perceptron (MLP)** depth to model non-linear relationships, while the **Batch Normalization** ensures the scalar embedding has the same statistical distribution (zero mean, unit variance) as the visual features (Cite solution_lesson_node_00155).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the Normalized Path A, Normalized Path B, and Normalized Metadata vectors.
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference. Fold-wise scaling introduces covariate shift due to local outliers (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers which are critical signal indicators (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the DN-WBN (Cite solution_lesson_node_00052).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Revert from AdamW to Adam. The aggressive weight decay of AdamW combined with high dropout caused underfitting (Cite solution_lesson_node_00124).
3.  **Optimization Protocol**: Strictly adhere to a **"Low and Slow"** strategy with a learning rate of **2e-4**.
    *   *Rationale*: This is critical to stabilize the Batch Normalization layers in the fusion head. Previous attempts failed because they combined normalization with aggressive learning rates (1e-3), leading to divergent oscillations (Cite solution_lesson_node_00157).
4.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
5.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained DN-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission (Cite solution_lesson_node_00036).
