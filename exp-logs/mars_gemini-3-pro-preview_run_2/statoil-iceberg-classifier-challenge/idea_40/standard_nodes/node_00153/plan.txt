Implementation Strategy:
1.  **Configuration & Setup**: Initialize the environment and set random seeds for reproducibility. Crucially, patch the `NUM_EPOCHS` in `library.config` to 50 before importing the trainer module. This ensures the "fast baseline" requirement is met while allowing sufficient convergence for the QC-WBN architecture.
2.  **Data Loading**: Invoke `process_and_cache_data` to load the full dataset and metadata. This is necessary not just for training, but to replicate the stratified cross-validation splits in the main script, enabling accurate mapping of predictions back to their metadata for failure analysis.
3.  **Training & Validation Loop**: Iterate through 5 folds using `StratifiedKFold`. For each fold, execute `run_fold` to train the model and generate predictions. Collect the Out-Of-Fold (OOF) predictions (for validation) and the test set predictions (for the ensemble submission).
4.  **Metric Calculation**: Aggregate the OOF predictions from all folds and compute the global Log Loss against the true labels. This provides the "Final Validation Metric".
5.  **Failure Analysis**: Using the indices from the stratified split, map the OOF errors back to the validation samples' metadata (Incidence Angle) and derived image statistics (Mean Band Intensity). Calculate and print the correlation between the absolute error magnitude and these features to identify systematic weaknesses.
6.  **Submission**: Check if the Final Validation Metric is strictly lower than the specified threshold (0.15744295919935183). If satisfied, average the test predictions across all 5 folds to create a robust ensemble and save the result to `submission.csv`.
