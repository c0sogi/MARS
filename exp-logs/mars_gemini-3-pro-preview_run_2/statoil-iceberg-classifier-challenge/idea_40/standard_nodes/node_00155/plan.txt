I will optimize the solution by reverting the "Quadrant-Context" readout to the "Robust Dual-Path" readout architecture, which previously achieved the best performance (Cite {solution_lesson_node_00123}). Specifically, I will replace the 2x2 Quadrant Pooling in the intensity path with Global Average Pooling (GAP). This change ensures the model captures translation-invariant signal statistics (robust intensity) while the parallel spatial path retains structural information, avoiding the potential overfitting or noise sensitivity of granular pooling on small feature maps (Cite {solution_lesson_node_00127}). The "Wide-Body" backbone with DualPooling will be preserved as it effectively handles signal preservation (Cite {solution_lesson_node_00070}, {solution_lesson_node_00092}).

    2. Readout:
       - Path A: Shape Stream (Conv + Flatten)
       - Path B: Intensity Stream (Quadrant Pooling + Flatten)
    3. Metadata Branch: MLP for incidence angle.
    4. Fusion Head: Concatenation + Dense Layers.
    """

    def __init__(self):
        super(QCWBN, self).__init__()

        # --- Visual Branch ---
        # Block 1: Input 3 -> 128 -> Pool -> 256
        self.block1 = WideBlock(NUM_CHANNELS, NUM_FILTERS)

        # Block 2: Input 256 -> 128 -> Pool -> 256
        self.block2 = WideBlock(NUM_FILTERS * 2, NUM_FILTERS)

        self.block3 = WideBlock(NUM_FILTERS * 2, NUM_FILTERS)

        # Block 4: Input 256 -> 128 -> Pool -> 256

        self.path_b_pool = nn.AdaptiveAvgPool2d((2, 2))

        self.meta_net = MetadataNet()
