Based on the comprehensive analysis of the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **Channel-Recalibrated Wide-Body Network (CR-WBN)**.

This solution represents a structural evolution of the "Robust Dual-Path Wide-Body Network" (Idea 31). It retains the successful **Wide Backbone** (Lesson 77) and **Dual-Pooling** (Lesson 70) but introduces a **Channel Recalibration Interface** at the readout stage. This addresses the need for "Feature Selectivity" (Lesson 85) specifically at the point of feature integration, allowing the network to dynamically weight the importance of "Peak" vs. "Shadow" feature streams based on global context before splitting them into spatial and intensity pathways.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and a novel recalibrated readout.

1.  **Visual Branch (Wide-Body Delayed-Integration Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across all four stages. This avoids underfitting (Cite solution_lesson_node_00077) and prevents destructive terminal bottlenecks (Cite solution_lesson_node_00055).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **256** (from the previous block's Dual-Pooling). The convolution maps $256 \to 128$ filters. This performs feature integration **at the start of the new receptive field**, satisfying **Delayed Integration** (Cite solution_lesson_node_00107).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range of the signal (Cite solution_lesson_node_00070).
    *   **Structural Innovation: Channel-Recalibrated Dual-Path Readout**:
        *   The output of Stage 4 is a $4 \times 4 \times 256$ tensor.
        *   **Step 1: Global Recalibration (SE-Block)**: Apply a **Squeeze-and-Excitation (SE)** module to the tensor.
            *   *Mechanism*: Global Average Pool $\to$ Dense (Reduction) $\to$ ReLU $\to$ Dense (Expansion) $\to$ Sigmoid $\to$ Channel-wise Multiplication.
            *   *Rationale*: This dynamically reweights the 256 channels (128 Peak + 128 Shadow) based on the global image context. It allows the network to suppress irrelevant feature maps (e.g., empty shadow channels in a flat image) *before* they are processed by the spatial convolution, enhancing feature selectivity (Cite solution_lesson_node_00085).
        *   **Step 2: Dual-Path Split**:
            *   **Path A (Spatial Context)**: Apply a **3x3 Convolution** (Padding=1, Stride=1) to compress the recalibrated channels from 256 to **64**, then **Flatten**.
                *   *Rationale*: Integrates spatial adjacency (Cite solution_lesson_node_00101) and preserves coarse geometry (Cite solution_lesson_node_00112). Increased width to 64 ensures sufficient capacity.
            *   **Path B (Robust Intensity)**: Apply **Global Average Pooling** to the recalibrated 256-channel volume.
                *   *Rationale*: Captures translation-invariant signal statistics robust to speckle noise (Cite solution_lesson_node_00123).
        *   **Fusion**: Concatenate Path A ($16 \times 64 = 1024$) and Path B (256). Total dimension: 1280.

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the visual vector (1280 dim) and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference. Fold-wise scaling introduces covariate shift due to local outliers (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers which are critical signal indicators (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the CR-WBN. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Revert from AdamW to Adam. The aggressive weight decay of AdamW combined with high dropout caused underfitting (Cite solution_lesson_node_00124).
3.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
4.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
5.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained CR-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
