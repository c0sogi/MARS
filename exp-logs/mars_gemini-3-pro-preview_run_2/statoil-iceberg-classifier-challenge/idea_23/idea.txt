Based on the accumulated lessons, specifically the critical need for **Wide Backbones** (Cite solution_lesson_node_00077) and **Shadow Preservation** (Cite solution_lesson_node_00070), balanced against the risks of **Parameter Explosion** (Cite solution_lesson_node_00041) and **Data Leakage** (Cite solution_lesson_node_00097), I propose the **Wide-Body Multi-Granularity Network (WBMG-Net)**.

This solution introduces a structural innovation in the **Readout Interface**. It resolves the conflict between feature capacity and classification complexity by decoupling the "Intensity" and "Spatial" information pathways. This allows the use of a wide, un-bottlenecked backbone (essential for texture modeling) while maintaining a compact dense layer input (essential for generalization), all while strictly enforcing a rigorous, leakage-free data pipeline.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a high-capacity backbone and a novel decoupled head.

1.  **Visual Branch (Wide-Body Dual-Pooling Backbone)**:
    *   **Sustained Width Strategy**: Unlike previous iterations that contracted the final layers (causing underfitting), this backbone maintains high channel capacity throughout to capture complex SAR textures.
        *   **Stage 1**: 64 Filters.
        *   **Stage 2**: 128 Filters.
        *   **Stage 3**: 128 Filters.
        *   **Stage 4**: **128 Filters**. (Cite solution_lesson_node_00077).
    *   **Attention (Pre-Pooling)**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer in every block. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, use standard Mixed Pooling (Max + Avg) for attention generation, explicitly avoiding Min-pooling in the attention logic to prevent instability (Cite solution_lesson_node_00079, solution_lesson_node_00095).
    *   **Pooling (Dual-Stream)**: Employ **Dual-Stream Pooling** (concatenating Max and Min pools) at every stage. This effectively doubles the output depth of each block (e.g., Stage 4 outputs $128 \times 2 = 256$ channels), preserving both the high-intensity peaks and the discriminative signal shadows (Cite solution_lesson_node_00070).
    *   **Activation**: Use **ReLU** exclusively (Cite solution_lesson_node_00071).

2.  **Structural Innovation: Multi-Granularity Readout Head**:
    *   **Problem**: Flattening the wide $4 \times 4 \times 256$ output creates 4,096 dimensions, leading to overfitting (Cite solution_lesson_node_00041). Compressing the whole volume via 1x1 convolution destroys peak signal fidelity (Cite solution_lesson_node_00055).
    *   **Solution**: Decouple the output into two parallel pathways that feed the dense layer:
        *   **Path A (Global Intensity)**: Apply **Global Max Pooling** to the 256-channel volume. This yields a **256-dimensional vector** representing the absolute strongest Peak and Deepest Shadow for each filter, independent of location. This preserves the "What" without parameter explosion.
        *   **Path B (Spatial Layout)**: Apply a **1x1 Convolution** to compress the 256 channels to **48**, then **Flatten** the $4 \times 4$ grid. This yields a **768-dimensional vector** ($16 \times 48$). This preserves the "Where" (coarse geometry) while controlling dimensionality.
    *   **Result**: The fused vector is $256 + 768 = 1024$ dimensions. This matches the optimal input size of the previous best model but is derived from a backbone with **4x the capacity**, satisfying both Lesson 77 (Width) and Lesson 41 (Efficiency).

3.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

4.  **Fusion Head**:
    *   **Concatenation**: Fuse the Path A vector, Path B vector, and Metadata vector (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)** to regularize the wide backbone (Cite solution_lesson_node_00077).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization (Crucial Update)**: Implement **Strict Fold-wise Preprocessing**. Instead of calculating global min/max statistics on the entire dataset (which leaks information), compute scaling statistics **exclusively on the training subset** of the current fold and apply them to the validation subset. Use Independent Per-Channel Min-Max Scaling (Cite solution_lesson_node_00097, solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the WBMG-Net. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.5). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format, scaling them using the **average statistics** derived from the training folds (or ensemble the predictions from models scaled with their respective fold stats).
2.  **Ensemble Prediction**: Pass the test data through all 5 trained WBMG-Net models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission (Cite solution_lesson_node_00036).
