Implementation strategy:
1.  **Environment Setup**: Initialize the random seeds and configure the logger to ensure reproducibility and track progress.
2.  **Data Loading**: Load the training and test datasets using `library.data_loader.load_data` with `load_cached_data=True` to utilize preprocessed artifacts.
3.  **Cross-Validation Loop**:
    *   Iterate through the 5 folds defined in the configuration.
    *   For each fold, execute `library.train.run_fold` to train the `SIWBN` model.
    *   Retrieve the trained model and use it to generate probability predictions on the validation subset of that fold.
    *   Accumulate the validation predictions, true labels, and incidence angles into global arrays for aggregate evaluation.
4.  **Validation & Metrics**:
    *   Calculate the global Log Loss across all validation samples.
    *   Print the "Final Validation Metric" with full precision.
5.  **Failure Analysis**:
    *   Compute the absolute error for each validation sample.
    *   Calculate and print the Pearson correlation between the prediction errors and the incidence angles (`inc_angle`) to identify potential dependencies.
6.  **Submission**:
    *   Check if the Final Validation Metric is strictly lower than the threshold (0.16676861786296204).
    *   If the check passes, generate predictions on the test set using an ensemble (average) of the 5 trained models.
    *   Save the final predictions to `./submission/submission.csv` in the required format.
