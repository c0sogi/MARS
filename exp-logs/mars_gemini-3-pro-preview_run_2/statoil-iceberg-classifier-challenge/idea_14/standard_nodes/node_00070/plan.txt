The implementation strategy involves the following steps:

1.  **Setup & Data Loading**: Initialize the environment with fixed seeds and GPU support. Load the dataset using the provided `load_data` function, which retrieves the pre-defined `train` and `val` splits from the metadata directory.
2.  **Model Training (Cross-Validation)**: Instead of training on the combined dataset, I will perform a Stratified 5-Fold Cross-Validation strictly on the training subset (`X_train`). This preserves the integrity of the provided hold-out validation set (`X_val`). I will use the `DPCNet` model and `engine.train_fold` function, limiting training to 30 epochs for a fast baseline.
3.  **Hold-out Validation**: After training, I will use the ensemble of the 5 models generated during cross-validation to perform inference on the hold-out validation set. The predictions will be averaged to produce a robust estimate.
4.  **Metric & Failure Analysis**: I will calculate the Log Loss on the hold-out set and print it. I will then perform failure analysis by computing the correlation between the prediction error magnitude and key input features (Incidence Angle, Band Means).
5.  **Submission**: If the calculated validation metric is below the specified threshold, I will generate predictions for the test set using the same ensemble and save the results to `submission.csv`.
