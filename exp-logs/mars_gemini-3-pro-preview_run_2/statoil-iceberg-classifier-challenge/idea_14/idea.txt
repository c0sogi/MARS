Based on the accumulated lessons and the specific physical properties of Synthetic Aperture Radar (SAR) imagery, I propose the **Dual-Pooling Contracted Network (DPC-Net)**.

This solution represents a structural evolution of the "Attention-Augmented Shallow Hybrid" architecture. It introduces a **Dual-Stream Pooling Mechanism** to explicitly capture the full dynamic range of radar signals (both high-intensity reflections and low-intensity shadows) while strictly adhering to the parameter constraints identified in previous failures.

# Model

The architecture employs the successful **Split-Branch Topology** (Cite solution_lesson_node_00007) with a novel pooling strategy in the visual backbone.

1.  **Visual Branch (Dual-Pooling Backbone)**:
    *   **Backbone Structure**: A custom 4-stage Convolutional Neural Network designed for 75x75 inputs (Cite solution_lesson_node_00016).
    *   **Structural Innovation: Dual-Stream Pooling**:
        *   **Concept**: Standard Max Pooling captures only the strongest backscatter signals ("Peaks"), which Lesson 21 identified as critical. However, SAR objects (especially icebergs) also cast distinct acoustic shadows (regions of near-zero intensity). Standard pooling discards this "Valley" information.
        *   **Mechanism**: Replace the standard pooling layer with a **Dual-Stream Module** that computes both **Max Pooling** (Peak Extraction) and **Min Pooling** (Shadow Extraction) on the same feature map. The outputs are concatenated along the channel dimension. This effectively doubles the texture information passed to the next layer without increasing the parameter count of the preceding convolution.
    *   **Channel Contraction (Constraint)**: To accommodate the channel-doubling effect of the Dual-Pooling without exploding the parameter count in the dense layers (Cite solution_lesson_node_00041), the convolutional filters are explicitly managed:
        *   **Stages 1-3**: Use sufficient width (e.g., 64-128 filters) to learn features.
        *   **Stage 4 (Terminal)**: Explicitly **contract** the convolution to **32 filters**.
        *   **Result**: The final Dual-Pooling layer (Max+Min) produces $32 + 32 = 64$ channels. Flattening the $4 \times 4 \times 64$ map yields a **1024-dimensional vector**, matching the optimal dense input size identified in previous successful iterations (Cite solution_lesson_node_00055).
    *   **Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer (Pre-Pooling) to refine features at high resolution (Cite solution_lesson_node_00061).

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the scalar `inc_angle` (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   Concatenate the flattened visual vector (1024 dim) and the metadata vector.
    *   Process through a classification head with Batch Normalization, ReLU, and **Moderate Dropout (0.2)** (Cite solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1]. This maximizes contrast for each signal type (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Explicitly exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).
    *   **Exclusion**: Do not use Mixup or interpolation-based techniques (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the DPC-Net. This is critical to reduce variance and avoid selection bias (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize the Adam optimizer with a conservative learning rate (e.g., **2e-4**) (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.2). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained DPC-Net models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance (Cite solution_lesson_node_00036).
