Based on the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **High-Resolution Dual-Stream Network (HRDS-Net)**.

This solution represents a structural evolution that resolves the conflict between **Spatial Resolution** (Lesson 112) and **Statistical Stability** (Lesson 127). It evolves the "Robust Dual-Path" architecture (Idea 31) by shifting the final downsampling operation from the backbone to the readout interface. This allows the terminal feature maps to maintain a higher resolution ($9 \times 9$ vs $4 \times 4$), enabling better discrimination of small objects and more robust global statistics, while strictly adhering to the **Wide Backbone** (Lesson 77) and **Dual-Pooling** (Lesson 70) principles.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and a novel resolution-preserving readout.

1.  **Visual Branch (High-Resolution Wide Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across all four stages. This avoids underfitting (Cite solution_lesson_node_00077) and prevents destructive terminal bottlenecks (Cite solution_lesson_node_00055).
    *   **Stages 1-3 (Standard Reduction)**:
        *   Follow the **Delayed-Integration** topology (Cite solution_lesson_node_00107): Conv(3x3, 128) $\to$ CBAM (Pre-Pool, Max+Avg) $\to$ Dual-Stream Pooling (Max+Min, **Stride 2**).
        *   This reduces resolution from $75 \to 37 \to 18 \to 9$.
    *   **Stage 4 (High-Resolution Terminal Block)**:
        *   **Input**: 256 channels (from Stage 3).
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU. Maps $256 \to 128$ filters.
        *   **Pre-Pooling Attention**: Apply **CBAM** (Max+Avg) strictly before pooling (Cite solution_lesson_node_00061, solution_lesson_node_00095).
        *   **Structural Innovation: Stride-1 Dual-Pooling**: Apply **Max Pooling** and **Min Pooling** with **Stride 1** (Padding 1).
            *   *Rationale*: This preserves the **$9 \times 9$ spatial resolution** while still generating the critical "Peak" and "Shadow" feature streams (Cite solution_lesson_node_00070). This corrects the resolution loss identified in Lesson 112, providing a finer grid for the readout.
    *   **Resolution-Preserving Dual-Path Readout**:
        *   The output of Stage 4 is a $9 \times 9 \times 256$ tensor.
        *   **Path A (Strided Spatial Context)**: Apply a **3x3 Convolution** with **Stride 2** (Padding 0) to compress channels from 256 to **48**.
            *   *Mechanism*: The Stride 2 convolution performs the downsampling *within the readout*, reducing the $9 \times 9$ grid to $4 \times 4$.
            *   *Rationale*: By delaying downsampling to this specific branch, we allow the spatial kernel to integrate context from the higher-resolution map (Cite solution_lesson_node_00101). The resulting flattened vector ($4 \times 4 \times 48 = 768$) remains parameter-efficient (Cite solution_lesson_node_00041).
        *   **Path B (Stable Intensity)**: Apply **Global Average Pooling** to the $9 \times 9 \times 256$ volume.
            *   *Rationale*: Computing statistics on a $9 \times 9$ grid (81 pixels) is significantly more stable and representative than on a $4 \times 4$ grid (16 pixels), reducing the noise sensitivity of the global intensity feature (Cite solution_lesson_node_00127, solution_lesson_node_00123).
        *   **Fusion**: Concatenate Path A (768 dim) and Path B (256 dim). Total dimension: 1024.

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the visual vector (1024 dim) and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference. Fold-wise scaling introduces covariate shift due to local outliers (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers which are critical signal indicators (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the HRDS-Net. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Revert from AdamW (used in failed Lesson 124) to Adam. The aggressive weight decay of AdamW combined with high dropout caused underfitting on this small dataset.
3.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
4.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
5.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained HRDS-Net models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
