Based on the comprehensive analysis of the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **Dilated-Context Wide-Body Network (DC-WBN)**.

This solution represents a structural evolution that resolves the trade-off between **Local Feature Fidelity** and **Global Context Integration** (Lesson 101, 112). It retains the robust **Wide-Body Backbone** (Lesson 77) and **Dual-Pooling** (Lesson 70) but introduces a **Dilated Dual-Path Spatial Readout**. This interface replaces the single convolutional bottleneck of previous bests with a parallel dilated stream, allowing the network to simultaneously capture immediate "Peak-Shadow" boundaries (Local) and broader object-clutter relationships (Context) on the final 4x4 grid, without increasing parameter count or using destructive 1x1 convolutions (Lesson 179).

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and a novel dilated readout.

1.  **Visual Branch (Wide-Body Delayed-Integration Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across all four stages. This avoids underfitting (Cite solution_lesson_node_00077) and prevents destructive terminal bottlenecks (Cite solution_lesson_node_00055).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **256** (from the previous block's Dual-Pooling). The convolution maps $256 \to 128$ filters. This performs feature integration **at the start of the new receptive field**, satisfying **Delayed Integration** (Cite solution_lesson_node_00107).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range of the signal (Cite solution_lesson_node_00070).
    *   **Structural Innovation: Dilated Dual-Path Spatial Readout**:
        *   The output of Stage 4 is a $4 \times 4 \times 256$ tensor.
        *   **Path A (Spatial Features)**: Split into two parallel convolutional streams to capture multi-scale context without downsampling:
            *   **Stream A1 (Local)**: 3x3 Convolution (**Dilation=1**, Padding=1). Compresses $256 \to 32$ channels. Captures immediate adjacency (e.g., shadow edge).
            *   **Stream A2 (Context)**: 3x3 Convolution (**Dilation=2**, Padding=2). Compresses $256 \to 32$ channels. Captures the full receptive field of the 4x4 grid.
            *   **Fusion**: Concatenate A1 and A2 ($32+32=64$ channels), then **Flatten**.
            *   *Rationale*: This adds "Horizontal Feature Diversity" (Cite solution_lesson_node_00135) and integrates spatial context (Cite solution_lesson_node_00101) while avoiding the noise-overfitting risks of 1x1 convolutions (Cite solution_lesson_node_00179).
            *   **Normalization**: Apply **Batch Normalization (1D)** to the flattened vector (1024 dim) (Cite solution_lesson_node_00161).
        *   **Path B (Robust Intensity)**: Apply **Global Average Pooling** to the 256-channel volume.
            *   *Rationale*: Captures translation-invariant signal statistics robust to speckle noise (Cite solution_lesson_node_00123).
            *   **Normalization**: Apply **Batch Normalization (1D)** to the pooled vector (256 dim).

2.  **Metadata Branch (Deep Normalized Embedding)**:
    *   **Structure**: Linear $\to$ ReLU $\to$ Linear $\to$ **Batch Normalization** $\to$ ReLU.
    *   *Rationale*: Models the non-linear incidence angle relationship (Cite solution_lesson_node_00158) while aligning the embedding distribution with the visual features (Cite solution_lesson_node_00155).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the Normalized Spatial vector (1024), Normalized Intensity vector (256), and Normalized Metadata vector.
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference. Fold-wise scaling introduces covariate shift due to local outliers (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation** using the **Full Dataset** (Cite solution_lesson_node_00165).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Revert from AdamW to Adam. The aggressive weight decay of AdamW combined with high dropout caused underfitting (Cite solution_lesson_node_00124).
3.  **Optimization Protocol**: Strictly adhere to a **"Low and Slow"** strategy with a learning rate of **2e-4** and a **Batch Size of 64**.
    *   *Rationale*: Large batch size and low LR are critical to stabilize the Batch Normalization layers in the readout and fusion head (Cite solution_lesson_node_00157, solution_lesson_node_00179).
4.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
5.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained DC-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission (Cite solution_lesson_node_00036).
