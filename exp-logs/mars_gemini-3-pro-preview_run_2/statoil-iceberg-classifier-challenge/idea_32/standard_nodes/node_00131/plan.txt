To fix this, I will update `library/model_architecture.py` to:
1.  Import `DualPathReadout` instead of `TriPathReadout`.
2.  Rename the class `TriPathWideBodyNet` to `DualPathWideBodyNet`.
3.  Update the `readout` layer instantiation to use `DualPathReadout`.
4.  Adjust the `visual_dim` calculation to reflect the removal of the third path (Texture), reducing the dimension from 1280 to 1024 (768 spatial + 256 intensity).
5.  Update the fusion head input dimension accordingly.
