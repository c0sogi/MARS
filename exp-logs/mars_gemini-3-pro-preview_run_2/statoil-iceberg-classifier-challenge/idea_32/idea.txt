Based on the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **Tri-Path Wide-Body Network (TP-WBN)**.

This solution represents a structural evolution that resolves the limitations of the "Robust Dual-Path" architecture (Lesson 123) by explicitly modeling **Signal Texture**—a critical discriminative feature in SAR imagery (distinguishing speckle noise from solid objects)—while maintaining the successful **Wide Backbone** (Lesson 77) and **Dual-Pooling** (Lesson 70) strategies. It also corrects the over-regularization issues identified in Lesson 124.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and a novel **Tri-Path Readout Interface**.

1.  **Visual Branch (Wide-Body Delayed-Integration Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across all four stages. This avoids the underfitting observed in narrower architectures (Cite solution_lesson_node_00077) and prevents the "Terminal Bottleneck" failure (Cite solution_lesson_node_00055).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **256** (from the previous block's Dual-Pooling). The convolution maps $256 \to 128$ filters. This performs feature integration **at the start of the new receptive field**, satisfying the requirement for **Delayed Integration** (Cite solution_lesson_node_00107).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range of the signal (Cite solution_lesson_node_00070).
    *   **Structural Innovation: Tri-Path Readout Interface**:
        *   The output of Stage 4 is a $4 \times 4 \times 256$ tensor. The previous best model used two paths (Spatial + Intensity). This model introduces a third path to capture **Texture Variance**.
        *   **Path A (Spatial Structure)**: Apply a **3x3 Convolution** (Padding=1, Stride=1) to compress channels from 256 to **48**, then **Flatten**.
            *   *Rationale*: Preserves the $4 \times 4$ coarse geometry required to distinguish object shapes from clutter (Cite solution_lesson_node_00112) and integrates spatial context (Cite solution_lesson_node_00101).
        *   **Path B (Robust Intensity)**: Apply **Global Average Pooling** to the 256-channel volume.
            *   *Rationale*: Captures translation-invariant signal strength, robust to speckle noise (Cite solution_lesson_node_00123).
        *   **Path C (Signal Texture)**: Apply **Global Standard Deviation Pooling**.
            *   *Mechanism*: Compute the standard deviation of each feature map across the spatial dimensions.
            *   *Rationale*: SAR imagery is characterized by "speckle" (multiplicative noise). Man-made objects (ships) and natural objects (icebergs) exhibit different texture variances. Explicitly capturing the *dispersion* of the signal (via StdDev) provides a discriminative feature orthogonal to the mean intensity (Path B) and spatial layout (Path A), enhancing separation in low-contrast scenarios.
        *   **Fusion**: Concatenate Path A (768), Path B (256), and Path C (256). Total dimension: 1280.

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the visual vector (1280 dim) and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **Dropout (0.5)**.

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference. Fold-wise scaling introduces covariate shift due to local outliers (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers which are critical signal indicators (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the TP-WBN. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Revert from AdamW (used in the failed Lesson 124) to Adam. The aggressive weight decay of AdamW combined with high dropout caused underfitting on this small dataset. Adam allows weights to grow sufficiently to capture weak signals.
3.  **Regularization**: Use **Dropout (0.5)**.
    *   *Rationale*: This level was successful in the Wide-Body context (Cite solution_lesson_node_00077) and is less aggressive than the 0.6 rate that caused underfitting (Cite solution_lesson_node_00124).
4.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
5.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained TP-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
