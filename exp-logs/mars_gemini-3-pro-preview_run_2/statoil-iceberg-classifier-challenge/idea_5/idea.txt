Based on the accumulated lessons, I propose a **Deep Residual Peak-Preserving Network (DRPPN)**. This solution structurally evolves the previous "Spatially-Aware Hybrid" approach by introducing **residual learning** to enable a deeper architecture, while explicitly correcting the specific architectural flaws (Average Pooling, Aggressive Downsampling, Global Average Pooling) that caused the failure of the ResNet and DenseNet attempts in previous iterations.

# Model

The architecture maintains the successful **split-branch topology** (Cite solution_lesson_node_00007) but completely redesigns the visual feature extractor to combine the benefits of deep networks with the specific signal-processing requirements of SAR data.

1.  **Visual Branch (Custom Residual Peak-Preserving Backbone)**:
    *   **Architecture**: Instead of the shallow 4-layer CNN (Previous Best) or the standard pre-trained ResNet (Failed Idea 3), I will construct a **custom deep network** consisting of 4-5 stages of **Residual Blocks**. This allows the model to learn more complex hierarchical features without suffering from vanishing gradients.
    *   **Input Stem**: The first layer will be a standard 3x3 convolution with **stride 1**. This avoids the aggressive initial downsampling of standard backbones that destroys fine spatial details in 75x75 images (Cite solution_lesson_node_00016).
    *   **Signal Preservation (Innovation)**: Unlike standard ResNets which use strided convolutions or Average Pooling for downsampling, this backbone will strictly utilize **Max Pooling** layers between residual stages. This is critical to preserve the high-intensity "peak" signals characteristic of icebergs/ships against the noise floor, which Average Pooling was found to wash out (Cite solution_lesson_node_00021).
    *   **Spatial Retention**: The final feature map will be **Flattened** rather than processed via Global Average Pooling (GAP). This retains the coarse spatial grid (e.g., 4x4) necessary for the dense layers to learn location-specific features, correcting the flaw in the DenseNet approach (Cite solution_lesson_node_00021).
2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the scalar `inc_angle`, ensuring this low-dimensional feature is not drowned out by the high-dimensional image data (Cite solution_lesson_node_00007).
3.  **Fusion Head**:
    *   The flattened visual vector and the metadata vector are concatenated.
    *   The combined vector passes through a dense classification head with Batch Normalization, ReLU, and Dropout.

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Augmentation**:
    *   **Rotational Invariance**: Implement a generator that applies random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips**. This maximizes the effective training set for top-down imagery (Cite solution_lesson_node_00014).
    *   **Constraint**: Explicitly exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).
    *   **Implementation**: Use **native tensor operations** (e.g., `torch.rot90`) to ensure training speed and stability (Cite solution_lesson_node_00011).
3.  **Preprocessing**:
    *   Scale pixel values to [0, 1] using Min-Max scaling.
    *   Impute missing `inc_angle` values with the training set median.

# Training

1.  **Optimization Strategy**: Adopt a **"Low and Slow"** approach. Initialize the Adam optimizer with a conservative learning rate (e.g., **2e-4**) rather than the standard 1e-3. This prevents the volatility and premature convergence observed in previous aggressive runs (Cite solution_lesson_node_00023).
2.  **Scheduler**: Utilize `ReduceLROnPlateau` to dynamically decay the learning rate when validation loss stagnates. This is essential to allow the model to settle into the complex minima created by the heavy rotational augmentation (Cite solution_lesson_node_00009).
3.  **Regularization**:
    *   **Dropout**: Use a **moderate dropout rate (e.g., 0.2)** in the fusion head. Since the full rotational augmentation acts as a strong regularizer, high dropout (0.5) is unnecessary and may lead to underfitting (Cite solution_lesson_node_00014).
    *   **Weight Decay**: Only apply L2 regularization if the Validation Loss exceeds the Training Loss (Cite solution_lesson_node_00012).
4.  **Early Stopping**:
    *   Monitor validation loss with extended patience (e.g., 25-30 epochs).
    *   **Critical**: Use `copy.deepcopy(model.state_dict())` to save the best model weights, ensuring the restored model is the true optimum (Cite solution_lesson_node_00001).
