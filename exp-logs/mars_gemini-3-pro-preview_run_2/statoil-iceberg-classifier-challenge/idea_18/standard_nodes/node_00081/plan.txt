Implementation strategy:
1.  **Setup & Initialization**: Import provided library modules (`utils`, `model`, `data_loader`, `trainer`). Set random seeds for reproducibility and configure the computing device (GPU).
2.  **Data Loading**: Load and process the dataset using `process_data(load_cached_data=True)`. This handles JSON parsing, band extraction, normalization, and caching.
3.  **Cross-Validation Loop**: Implement a Stratified 5-Fold Cross-Validation loop.
    *   For each fold, initialize the `WB_DSN` model and `ModelTrainer`.
    *   Train the model using `trainer.fit()` with Early Stopping to prevent overfitting and ensure efficiency.
    *   Collect validation predictions, targets, and input features (incidence angle, image statistics) for later analysis.
    *   Store the trained model for ensemble inference.
    *   Track the best validation loss for the fold.
4.  **Validation Reporting**: Calculate and print the mean validation loss across all folds as `Final Validation Metric`.
5.  **Failure Analysis**:
    *   Aggregate validation results from all folds.
    *   Calculate the absolute error (`|y_true - y_pred|`).
    *   Compute and print the correlation between the error magnitude and input features (Incidence Angle, Band 1 Mean, Band 2 Mean) to identify systematic failures.
6.  **Submission Generation**:
    *   Check if the `Final Validation Metric` is below the specified threshold (`0.16676861786296204`).
    *   If successful, generate predictions on the test set using an ensemble (average) of the 5 trained models.
    *   Save the predictions to `./submission/submission.csv` in the required format.
