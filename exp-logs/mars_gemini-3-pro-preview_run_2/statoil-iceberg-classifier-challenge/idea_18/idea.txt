Based on the accumulated lessons and the analysis of the trade-offs between model capacity and generalization, I propose the **Wide-Body Dual-Stream Network (WB-DSN)**.

This solution represents a structural evolution of the "Dual-Pooling Contracted Network" (Idea 14) and the "Wide DPCNet" referenced in Lesson 77. It synthesizes the critical finding that **channel contraction (bottlenecks) causes underfitting** (Cite solution_lesson_node_00077, solution_lesson_node_00055) with the success of **Dual-Stream Pooling** for shadow detection (Cite solution_lesson_node_00070). The innovation lies in unbinding the feature extraction width from the classification interface constraints, relying on heavy regularization rather than architectural compression to manage the bias-variance trade-off.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a **Sustained-Width Visual Backbone**.

1.  **Visual Branch (Wide-Body Backbone)**:
    *   **Sustained Width Strategy**: Unlike previous iterations that contracted the final layer to 32 or 64 filters to save parameters (Idea 14, Idea 11), this backbone maintains a high channel capacity throughout to capture complex texture patterns.
        *   **Stage 1**: 64 Filters.
        *   **Stage 2**: 128 Filters.
        *   **Stage 3**: 128 Filters.
        *   **Stage 4 (Terminal)**: **128 Filters**. (Cite solution_lesson_node_00077, solution_lesson_node_00055).
    *   **Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **Pre-Pooling** (before the pooling layer) in every block. This ensures the model attends to salient features at high resolution before downsampling (Cite solution_lesson_node_00061). Crucially, use standard CBAM (Max/Avg) and do *not* include Min-pooling in the attention generation, as this was found to destabilize training (Cite solution_lesson_node_00079).
    *   **Pooling**: Employ **Dual-Stream Pooling (Max + Min)** at every stage. This concatenates the local maximum (peaks) and local minimum (shadows/voids), effectively doubling the output depth of each block (e.g., Stage 4 outputs $128 \times 2 = 256$ channels). This preserves the full dynamic range of the SAR signal (Cite solution_lesson_node_00070).
    *   **Activation**: Use **ReLU** exclusively, as it provides necessary sparsity and noise filtering superior to LeakyReLU (Cite solution_lesson_node_00071).
    *   **Output Interface**: Flatten the final feature map ($4 \times 4 \times 256$). This results in a 4,096-dimensional vector.

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar, keeping it orthogonal to the visual features until fusion (Cite solution_lesson_node_00007). Do not include explicit global image statistics (Cite solution_lesson_node_00034).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the flattened visual vector and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Regularized Classification**: Process through a dense head with Batch Normalization and ReLU. Crucially, apply **High Dropout (0.5)**. Since the backbone is wide and the flattened vector is large (4,096 dim), this aggressive dropout is essential to prevent the "parameter explosion" overfitting observed in earlier wide models, allowing us to retain the capacity benefits of the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use input-level inversions (Cite solution_lesson_node_00076).
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1] to maximize contrast (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).
    *   **Exclusion**: Do not use Mixup, as it induces underfitting in this small-data regime (Cite solution_lesson_node_00031).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the WB-DSN. This is critical to reduce variance and maximize data utilization compared to fixed splits (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence and oscillation (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained WB-DSN models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
