Based on the accumulated lessons and the analysis of previous structural trade-offs, I propose the **Spatial-Quadrant Wide-Body Network (SQ-WBN)**.

This solution represents a structural evolution of the "Wide-Body Dual-Stream Network" (Idea 18). It resolves the critical conflict between the need for a **Wide Backbone** (Lesson 77) and the risk of **Dense Layer Overfitting** (Lesson 41). Instead of using destructive channel bottlenecks (which cause underfitting, Lesson 55) or massive flattened vectors (which cause overfitting), it introduces a **Quadrant-Based Spatial Readout** to efficiently compress the feature volume while preserving the "Peak" and "Shadow" signals essential for SAR classification.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a novel readout mechanism.

1.  **Visual Branch (Wide-Body Dual-Pooling Backbone)**:
    *   **Sustained Width Strategy**: Maintain high channel capacity throughout the network to capture complex texture patterns, avoiding the underfitting observed in narrowed architectures (Cite solution_lesson_node_00077).
        *   **Stage 1**: 64 Filters.
        *   **Stage 2**: 128 Filters.
        *   **Stage 3**: 128 Filters.
        *   **Stage 4**: **128 Filters**. (No terminal bottleneck, Cite solution_lesson_node_00055).
    *   **Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **Pre-Pooling** (before the pooling layer) in every block. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, use standard CBAM (Max+Avg) for attention generation, avoiding the instability of including Min-pooling in the attention logic (Cite solution_lesson_node_00079).
    *   **Pooling**: Employ **Dual-Stream Pooling (Max + Min)** at every stage. This concatenates the local maximum (peaks) and local minimum (shadows), doubling the output depth of each block (e.g., Stage 4 outputs $128 \times 2 = 256$ channels). This preserves the full dynamic range of the radar signal (Cite solution_lesson_node_00070).
    *   **Activation**: Use **ReLU** exclusively (Cite solution_lesson_node_00071).

2.  **Structural Innovation: Quadrant Max-Pooling Readout**:
    *   **Problem**: The output of Stage 4 is $4 \times 4 \times 256$. Flattening this yields 4,096 features, which causes parameter explosion in the dense head (Cite solution_lesson_node_00041). Reducing channels to 64 destroys discriminative signal (Cite solution_lesson_node_00055). Global Average Pooling destroys spatial location (Cite solution_lesson_node_00021).
    *   **Solution**: Apply **Adaptive Max Pooling** to reduce the $4 \times 4$ spatial grid to a **$2 \times 2$ grid** (Quadrants).
    *   **Mechanism**: This operation selects the strongest signal (Peak or Deepest Shadow) within each of the four image quadrants (Top-Left, Top-Right, Bottom-Left, Bottom-Right).
    *   **Result**: The flattened vector becomes $2 \times 2 \times 256 = 1024$ dimensions. This achieves a 4x parameter reduction compared to full flattening, preventing overfitting, while retaining the coarse spatial localization required to distinguish objects from clutter and preserving the full channel depth.

3.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

4.  **Fusion Head**:
    *   **Concatenation**: Fuse the Quadrant-Pooled visual vector (1024 dim) and the metadata vector (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The dropout acts as a strong regularizer for the wide backbone (Cite solution_lesson_node_00014, solution_lesson_node_00077).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1] to maximize contrast (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the SQ-WBN. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.5). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained SQ-WBN models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
