Based on the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **Multi-Scale Spatial-Context Wide-Body Network (MSSC-WBN)**.

This solution represents a structural evolution that resolves the trade-off between **Spatial Context Integration** (Lesson 101) and **Local Signal Fidelity** (Lesson 21). It retains the robust **Wide-Body Backbone** (Lesson 77) and **Dual-Pooling** (Lesson 70) but introduces a **Multi-Scale Readout Interface**. This interface explicitly separates "Contextual" features (processed via spatial convolution) from "Local Detail" features (processed via pointwise convolution) and "Global Intensity" (processed via robust pooling), allowing the dense head to correlate sharp peak signals with their surrounding shadow context without the blurring effects of a single convolutional bottleneck.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and a novel multi-branch readout.

1.  **Visual Branch (Wide-Body Delayed-Integration Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across Stages 2, 3, and 4. This avoids underfitting (Cite solution_lesson_node_00077) and prevents destructive terminal bottlenecks (Cite solution_lesson_node_00055).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **256** (from the previous block's Dual-Pooling). The convolution maps $256 \to 128$ filters. This performs feature integration **at the start of the new receptive field**, satisfying **Delayed Integration** (Cite solution_lesson_node_00107).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range (Cite solution_lesson_node_00070).
    *   **Structural Innovation: Multi-Scale Spatial-Context Readout**:
        *   The output of Stage 4 is a $4 \times 4 \times 256$ tensor.
        *   **Path A (Context Stream)**: Apply a **3x3 Convolution** (Padding=1, Stride=1) to compress channels from 256 to **32**, then **Flatten**.
            *   *Rationale*: Integrates spatial adjacency between "Peak" and "Shadow" channels (Cite solution_lesson_node_00101), providing the classifier with region-based textural information. ($16 \times 32 = 512$ dim).
        *   **Path B (Detail Stream)**: Apply a **1x1 Convolution** to compress channels from 256 to **16**, then **Flatten**.
            *   *Rationale*: Preserves pixel-wise signal fidelity without spatial blurring. This allows the classifier to detect sharp, high-intensity peaks or deep shadows at specific grid locations, reinforcing "Peak Preservation" (Cite solution_lesson_node_00021) in a parameter-efficient way. ($16 \times 16 = 256$ dim).
        *   **Path C (Global Stream)**: Apply **Global Average Pooling** to the 256-channel volume.
            *   *Rationale*: Captures translation-invariant signal statistics robust to speckle noise (Cite solution_lesson_node_00123). (256 dim).
        *   **Fusion**: Concatenate Path A, Path B, and Path C. Total dimension: $512 + 256 + 256 = 1024$. This matches the optimal input size for the dense head (Cite solution_lesson_node_00041).

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the visual vector (1024 dim) and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference. Fold-wise scaling introduces covariate shift due to local outliers (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the MSSC-WBN (Cite solution_lesson_node_00052).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Revert from AdamW to Adam. The aggressive weight decay of AdamW combined with high dropout caused underfitting (Cite solution_lesson_node_00124).
3.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
4.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
5.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained MSSC-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission (Cite solution_lesson_node_00036).
