This script demonstrates the end-to-end usage of the provided library components for the Iceberg Classification task. It performs the following steps:
1.  **Configuration**: overrides default settings in `Config` to enable `DEBUG` mode, reduce sample size, and limit training epochs for rapid execution.
2.  **Data Loading**: utilizes `make_dataloaders` to process raw JSON data, compute normalization statistics, and create PyTorch DataLoaders. It verifies the structure and shapes of the yielded batches.
3.  **Model Initialization & Verification**: instantiates the `CGWBN` model and performs a dummy forward pass to validate input/output tensor shapes.
4.  **Component Unit Tests**: explicitly tests specific custom layers (`CBAM`, `DualPooling`, `ContextGating`) to ensure they perform the expected tensor transformations.
5.  **Training Loop**: executes a single epoch of training using `train_fold` to demonstrate the optimization process and artifact saving.
6.  **Inference**: runs the `predict` function on the test set and validates the format of the submission predictions.
