Implementation Strategy:
1.  **Environment Setup**: Initialize random seeds for reproducibility and detect the available computation device (GPU/CPU).
2.  **Data Preparation**: Leverage the `library.data_loader` to load and preprocess the dataset (including caching). This handles image stacking, normalization, and incidence angle imputation.
3.  **Stratified Cross-Validation**: Implement a 5-Fold Stratified CV loop manually within the script. This allows precise control over the training process and direct access to validation indices for Out-Of-Fold (OOF) prediction aggregation.
4.  **Model Training**: For each fold, instantiate the `GDPNet` model and train it using the `library.train.Trainer` class. To ensure the solution serves as a "fast baseline," the maximum number of epochs is overridden to 30. This balances convergence speed with performance.
5.  **Validation & Metrics**: After training each fold, perform inference on the validation subset. Aggregate these OOF predictions to calculate the global Log Loss metric.
6.  **Failure Analysis**: Analyze the model's errors by calculating the correlation between the absolute error and input features (specifically incidence angle and mean image intensity) to identify systematic weaknesses.
7.  **Submission**: Compare the final validation metric against the specified threshold (0.1667...). If the model performs sufficiently well, generate predictions on the test set using an ensemble of the 5 trained models, average the probabilities, and save the result to `submission.csv`.
