Based on the comprehensive analysis of the accumulated lessons, I propose the **Wide-Body Delayed-Integration Network (WB-DIN)**.

This solution represents a structural synthesis that resolves the conflict between **Backbone Capacity** (Lesson 77) and **Parameter Efficiency** (Lesson 41) while strictly adhering to the **Dual-Pooling** (Lesson 70) and **Delayed Integration** (Lesson 107) principles. It employs a "Bell Curve" width profile to maximize feature extraction in the middle layers while ensuring a compact interface for the classifier, and utilizes a **Hybrid Readout** to explicitly capture both spatial layout and peak signal intensity.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone.

1.  **Visual Branch (Wide-Body Delayed-Integration Backbone)**:
    *   **Topology**: A 4-stage Convolutional Neural Network designed for 75x75 inputs.
    *   **Delayed-Integration Blocks**:
        *   **Mechanism**: Unlike previous failed iterations that compressed features immediately after pooling (Cite solution_lesson_node_00101), this architecture allows the feature volume to remain expanded (due to Dual-Pooling) and performs integration/compression **at the start of the subsequent block**. This allows the network to learn non-linear relationships between "Peak" and "Shadow" channels within the next receptive field (Cite solution_lesson_node_00107).
        *   **Components**:
            1.  **Convolution**: 3x3 Kernel $\to$ BatchNorm $\to$ ReLU.
            2.  **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer to refine features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure optimization stability (Cite solution_lesson_node_00095).
            3.  **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($N \to 2N$), preserving the full dynamic range (Cite solution_lesson_node_00070).
    *   **Width Profile (Bell Curve)**:
        *   **Stage 1**: Input $\to$ Conv(64) $\to$ DualPool (Output: 128 ch).
        *   **Stage 2**: Input(128) $\to$ Conv(128) $\to$ DualPool (Output: 256 ch). *Wide backbone for texture modeling (Cite solution_lesson_node_00077).*
        *   **Stage 3**: Input(256) $\to$ Conv(128) $\to$ DualPool (Output: 256 ch).
        *   **Stage 4 (Terminal)**: Input(256) $\to$ **Conv(64)** $\to$ DualPool (Output: 128 ch).
            *   *Rationale*: This explicit contraction in the final layer reduces the output volume to prevent parameter explosion in the dense head (Cite solution_lesson_node_00041), but remains wide enough (64 filters) to avoid the signal loss observed in aggressive bottlenecks (Cite solution_lesson_node_00055).
    *   **Hybrid Readout Interface**:
        *   The final output is $4 \times 4 \times 128$.
        *   **Path A (Spatial)**: **Flatten** the tensor to a 2048-dimensional vector. This preserves the coarse spatial geometry ($4 \times 4$) critical for distinguishing objects from clutter (Cite solution_lesson_node_00112).
        *   **Path B (Peak Intensity)**: Apply **Global Max Pooling** to extract a 128-dimensional vector representing the absolute strongest signal and deepest shadow in each filter. This reinforces the "Peak Preservation" principle (Cite solution_lesson_node_00021).
        *   **Fusion**: Concatenate Path A and Path B ($2048 + 128 = 2176$).

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the visual vector (2176 dim) and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone and large input vector (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: While fold-wise scaling prevents leakage, physical sensor data (dB) is susceptible to covariate shift if local outliers distort the mapping. Global scaling provides a stable, physically consistent baseline (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers which are critical signal indicators (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the WB-DIN. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained WB-DIN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
