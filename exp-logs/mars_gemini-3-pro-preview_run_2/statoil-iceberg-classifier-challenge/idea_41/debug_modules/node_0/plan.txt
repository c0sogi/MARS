This script demonstrates the end-to-end usage of the provided machine learning library for the iceberg classification task. It performs the following steps:

1.  **Configuration & Setup**: Imports the `Config` class and modifies hyperparameters (e.g., enabling debug mode, reducing epochs to 2, and setting a small subset size) to ensure the demonstration runs quickly. It also sets the random seed for reproducibility.
2.  **Model Architecture Verification**: Instantiates the `NFWBN` model and performs a forward pass with dummy tensors to verify that the input shapes (image and incidence angle) are handled correctly and the output shape is as expected `(Batch Size, 1)`.
3.  **Data Loading**: Uses `get_loaders` to initialize PyTorch DataLoaders for training, validation, and testing. It verifies that the data loaders yield batches with the correct shapes and types, confirming the data processing pipeline works.
4.  **Training & Validation Loop**: Runs a short training session (2 epochs) using `train_one_epoch` and `validate`. It checks that the loss decreases or remains valid (not NaN) and that the model weights are updated.
5.  **Inference**: Demonstrates how to generate predictions using the trained model on the test set, applying the sigmoid activation to convert logits to probabilities.
