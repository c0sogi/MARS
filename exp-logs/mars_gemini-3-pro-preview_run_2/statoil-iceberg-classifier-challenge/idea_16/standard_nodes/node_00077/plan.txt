My implementation strategy focuses on reverting the ineffective input-level augmentation and replacing it with a structural **Dual-Stream Pooling** mechanism, as recommended by Lessons 70 and 76.

1.  **Revert Input Augmentation**: I will modify `library/data_utils.py` to stop generating inverted images ($1-X$) and revert the `INPUT_CHANNELS` in `library/config.py` to 3. This adheres to Lesson 76, which states that complementary feature extraction (like shadows) should be embedded in the architecture, not the input.
2.  **Implement Dual-Stream Pooling**: I will modify `library/model_utils.py` to introduce a `DualPooling` class. This layer computes both Max Pooling (peaks) and Min Pooling (shadows/voids) and concatenates them, effectively doubling the feature depth at each stage. This addresses Lesson 70 regarding the preservation of signal extremes in SAR imagery.
3.  **Adjust Architecture Dimensions**: I will update the `CSNet` class (effectively converting it to the DPCNet architecture) to handle the channel doubling induced by Dual Pooling. To prevent parameter explosion and overfitting (Lesson 41), I will use a contracted filter progression (`32 -> 64 -> 64 -> 32`), which results in feature map depths of `64 -> 128 -> 128 -> 64` after pooling. This maintains a compact flattened vector size of 1024, striking a balance between capturing rich "shadow" features and maintaining a regularized model capacity.

class CBAM(nn.Module):
    """
    Convolutional Block Attention Module.
    Sequentially applies Channel and Spatial attention.
    """

    def __init__(self, planes, ratio=16, kernel_size=7):
        super(CBAM, self).__init__()
        self.ca = ChannelAttention(planes, ratio)
        self.sa = SpatialAttention(kernel_size)

    def forward(self, x):
        out = x * self.ca(x)
        out = out * self.sa(out)
        return out

class DualPooling(nn.Module):
    """
    Dual-Stream Pooling Module.
    Computes both Max and Min pooling and concatenates them.
    Cite solution_lesson_node_00070: Preserving Signal Extremes.
    """

    def __init__(self, kernel_size=2, stride=2):
        super(DualPooling, self).__init__()
        self.max_pool = nn.MaxPool2d(kernel_size, stride)

    def forward(self, x):
        # Max Pooling (Peaks)
        out_max = self.max_pool(x)
        # Min Pooling (Shadows) - implemented as negative max of negative input
        out_min = -self.max_pool(-x)
        return torch.cat([out_max, out_min], dim=1)
