Based on the accumulated lessons and the analysis of previous structural evolutions, I propose the **Complementary Signal Network (CS-Net)**.

This solution represents a structural evolution of the "Dual-Pooling Contracted Network" (Idea 14). It synthesizes the critical finding that **shadows/signal voids are discriminative** (Cite solution_lesson_node_00070) with the finding that **standard ReLU sparsity is structurally advantageous** (Cite solution_lesson_node_00071). Instead of using a custom pooling layer to capture minima, this solution introduces an **Input-Level Dual-Stream Topology** that explicitly models signal polarity at the data level, allowing the network to use standard high-efficiency operators to learn both peak and shadow features throughout the entire network depth.

# Model

The architecture employs the successful **Split-Branch Topology** (Cite solution_lesson_node_00007) with a redesigned visual interface.

1.  **Visual Branch (Complementary Signal Backbone)**:
    *   **Input-Level Dual-Stream (Structural Innovation)**: The backbone accepts a **6-channel input** instead of 3. These consist of the standard normalized bands (HH, HV, Avg) and their **Complementary Inversions** ($1 - X$).
        *   **Rationale**: This transforms "shadows" (values near 0) in the original image into "peaks" (values near 1) in the complementary channels. This allows the network to detect shadows using standard **ReLU** activations and **Max Pooling**, avoiding the noise-propagation risks of LeakyReLU (Cite solution_lesson_node_00071) or the custom implementation overhead of Dual-Pooling.
    *   **Backbone Structure**: A Custom 4-Stage CNN (Cite solution_lesson_node_00016).
    *   **Width Strategy**: Maintain a **Sustained Width** in the intermediate layers to maximize feature extraction capacity, but strictly **Contract** the final layer to control dense-layer complexity.
        *   **Stage 1**: 64 Filters.
        *   **Stage 2**: 128 Filters.
        *   **Stage 3**: 128 Filters.
        *   **Stage 4 (Terminal)**: **64 Filters**. This contraction ensures the flattened vector is 1024 dimensions ($4 \times 4 \times 64$), matching the optimal capacity identified in previous successes (Cite solution_lesson_node_00041) while avoiding the destructive "Terminal Bottleneck" of narrower designs (Cite solution_lesson_node_00055).
    *   **Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **Pre-Pooling** in every block to refine features at high resolution (Cite solution_lesson_node_00061).
    *   **Pooling**: Employ standard **Max Pooling** exclusively. Since the input contains both signal polarities (peaks and inverted shadows), Max Pooling effectively captures both the strongest backscatter and the deepest shadows (Cite solution_lesson_node_00021).

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the scalar `inc_angle` (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the flattened visual vector and the metadata vector via simple concatenation. This avoids the optimization instability observed with multiplicative gating (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **Moderate Dropout (0.2)** (Cite solution_lesson_node_00014).

# Data

1.  **Input Construction**:
    *   **Base**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
    *   **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for each channel separately on the training set and scale to [0, 1] (Cite solution_lesson_node_00025).
    *   **Complement Generation**: Generate 3 additional channels by calculating $1.0 - \text{Normalized\_Image}$. Stack these to form a 6-channel tensor.
2.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the CS-Net. This is essential to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.2). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 6-channel (Normal + Inverted), per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained CS-Net models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
