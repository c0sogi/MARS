This script demonstrates the usage of the provided library files for the Iceberg vs. Ship classification task. It follows a pipeline approach:
1.  **Configuration**: Overrides default configuration settings (enabling `DEBUG` mode, reducing epochs) to ensure the demonstration runs quickly.
2.  **Data Preparation**: Uses `library.data.get_dataloaders` to load and preprocess the JSON data into PyTorch DataLoaders. It verifies the shape and integrity of the loaded batches.
3.  **Model Initialization**: Instantiates the `QPWBN` (Quadrant-Pooled Wide-Body Network) model defined in `library.model`.
4.  **Forward Pass Verification**: Performs a dummy forward pass to confirm the model architecture accepts the input shapes and produces the correct output format.
5.  **Training & Validation**: Executes a single epoch of training and validation using the functions from `library.train` to demonstrate the optimization loop.
6.  **Inference**: Generates predictions on the test set and formats them into a submission DataFrame.
