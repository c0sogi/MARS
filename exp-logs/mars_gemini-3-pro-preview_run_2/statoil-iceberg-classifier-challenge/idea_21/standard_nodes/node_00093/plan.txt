The strategy focuses on correcting the architectural flaws identified in the previous solution (QPWBN) by aligning with the lessons learned from the successful DPCNet. Specifically, we will implement a **Contracting Dual-Pooling** architecture. This involves modifying the filter sizes to enforce channel contraction before pooling (Cite Lesson 92), effectively preventing parameter explosion while maintaining the benefits of Dual-Stream Pooling (Cite Lesson 70). We will also replace the `QuadrantReadout` with direct flattening to preserve the coarse 4x4 spatial geometry (Cite Lesson 21, Lesson 43), as complex pooling at this stage was detrimental. Finally, we will increase the training patience to support a "Low and Slow" optimization strategy (Cite Lesson 23).

class QuadrantReadout(nn.Module):
    """
    Reduces spatial grid to 2x2 quadrants using Adaptive Max Pooling.
    """

    def __init__(self, output_size=2):
        super(QuadrantReadout, self).__init__()
        self.pool = nn.AdaptiveMaxPool2d((output_size, output_size))

    def forward(self, x):
        # x: (B, C, H, W) -> (B, C, 2, 2)
        x = self.pool(x)
        # Flatten: (B, C*2*2)
        return x.flatten(1)
