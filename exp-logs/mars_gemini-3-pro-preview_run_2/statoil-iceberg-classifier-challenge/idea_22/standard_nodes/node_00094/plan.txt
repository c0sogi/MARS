The implementation strategy follows the standard machine learning pipeline adapted for the specific constraints of the task.

1.  **Initialization**: We setup the environment by initializing the `Config` and seeding all random number generators to ensure reproducibility. We override `Config.NUM_EPOCHS` to 50 to ensure the training completes quickly while still allowing enough convergence to potentially meet the strict validation threshold.
2.  **Data Loading**: We utilize the cached data loading mechanism provided in `library.dataset` to speed up startup time.
3.  **Cross-Validation Loop**: We iterate through the 5 folds defined by the configuration. For each fold:
    *   We generate the specific training and validation dataloaders.
    *   We train the `CADPNet` model using `library.engine.train_fold`.
    *   We generate Out-Of-Fold (OOF) predictions on the validation set to construct a global validation assessment.
    *   We store the trained model and its associated scaling statistics for potential test set inference.
4.  **Validation & Failure Analysis**:
    *   We concatenate the OOF predictions and compute the global Log Loss.
    *   We perform failure analysis by correlating the absolute prediction error with the `inc_angle` metadata and the target class, providing insights into systematic model weaknesses.
5.  **Submission**:
    *   We check if the calculated Log Loss is below the specified threshold (`0.16676861786296204`).
    *   If successful, we perform inference on the test set using an ensemble of the 5 fold models (averaging their probabilities) and save the result to `submission.csv`.
