Based on the accumulated lessons, specifically the critical importance of **Peak Preservation** (Lesson 21), **Shadow Detection** (Lesson 70), **Feature Selectivity** (Lesson 85), and **Channel Contraction** (Lesson 41), I propose the **Coordinate-Aware Dual-Pooling Network (CADP-Net)**.

This solution structurally evolves the current best "DPCNet" by replacing the global-statistics-based CBAM attention with a **Max-Based Coordinate Attention** mechanism. This addresses the limitation that global pooling (used in CBAM) discards the spatial positional information essential for distinguishing compact targets (ships) from diffuse clutter, while strictly adhering to the signal-preserving principles derived from previous failures.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a novel attention mechanism integrated into the visual backbone.

1.  **Visual Branch (Coordinate-Aware Backbone)**:
    *   **Backbone Structure**: A custom 4-stage Convolutional Neural Network designed for 75x75 inputs.
    *   **Channel Strategy**:
        *   **Stages 1-3**: Maintain high capacity (e.g., 64 $\to$ 128 $\to$ 128 filters) to learn complex textures (Cite solution_lesson_node_00077).
        *   **Stage 4 (Terminal)**: Explicitly **contract** the convolution to **32 filters**. This bottleneck is critical to preventing parameter explosion in the dense layers (Cite solution_lesson_node_00041).
    *   **Structural Innovation: Max-Based Coordinate Attention**:
        *   **Concept**: Standard CBAM (used in the previous best model) compresses spatial information into a single global vector ($1 \times 1$) to compute channel weights. This loses positional context. Coordinate Attention decomposes attention into vertical and horizontal directions, preserving spatial dependencies.
        *   **Modification**: Unlike standard Coordinate Attention which uses Average Pooling, this module will strictly utilize **1D Max Pooling** along the X and Y axes.
        *   **Mechanism**:
            1.  Generate two feature maps: $H \times 1$ (via MaxPool X) and $1 \times W$ (via MaxPool Y). This captures the "Peak" signal distribution along each axis (Cite solution_lesson_node_00021).
            2.  Concatenate, process via 1x1 Conv, and split to generate attention maps.
            3.  Apply weights to the input tensor.
        *   **Placement**: Apply strictly **Pre-Pooling** (before the downsampling layer) to refine features at high resolution (Cite solution_lesson_node_00061).
    *   **Pooling**: Employ **Dual-Stream Pooling (Max + Min)**. Concatenate the outputs of Max Pooling (peaks) and Min Pooling (shadows/voids) at every stage. This preserves the full dynamic range of the SAR signal (Cite solution_lesson_node_00070).
    *   **Activation**: Use **ReLU** exclusively (Cite solution_lesson_node_00071).
    *   **Output**: The final flattened vector will be $4 \times 4 \times (32 \times 2) = 1024$ dimensions.

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the scalar `inc_angle` (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the flattened visual vector and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **Moderate Dropout (0.2)** (Cite solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1]. This maximizes contrast for each physical signal type (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the CADP-Net. This is essential to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.2). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained CADP-Net models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
