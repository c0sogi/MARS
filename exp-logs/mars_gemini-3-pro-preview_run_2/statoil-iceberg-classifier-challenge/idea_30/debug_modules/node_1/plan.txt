The issue is a variable naming mismatch in `library/data_loader.py` within the "Process from Scratch" execution path. The code defines incidence angle variables as `train_inc`, `val_inc`, and `test_inc`, but the subsequent debug slicing logic and return statement expect them to be named `inc_train`, `inc_val`, and `inc_test`. This causes an `UnboundLocalError` when the code attempts to access `inc_train` before it has been defined in that scope.

To fix this, I will rename the variables in the "Handle Incidence Angles" section to `inc_train`, `inc_val`, and `inc_test` to ensure consistency with the cache loading path and the rest of the function. This ensures the variables are properly bound when the debug logic tries to slice them (Cite debug_lesson_13).
