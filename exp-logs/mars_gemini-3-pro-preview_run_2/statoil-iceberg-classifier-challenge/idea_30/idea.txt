Based on the comprehensive analysis of the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **Spatially-Contextualized Wide-Body Network (SC-WBN)**.

This solution represents a structural evolution that resolves the critical conflict between **Backbone Capacity** (Lesson 77) and **Parameter Efficiency** (Lesson 41). It maintains a wide, high-capacity backbone to capture complex textures but introduces a novel **Spatial-Context Bottleneck** at the readout stage. This replaces the destructive 1x1 bottlenecks (Lesson 101) and resolution-reducing pooling (Lesson 112) of previous attempts with a mechanism that integrates "Peak" and "Shadow" features using spatial context while efficiently compressing dimensionality.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and readout interface.

1.  **Visual Branch (Wide-Body Delayed-Integration Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across all four stages. This avoids the underfitting observed in narrower architectures (Cite solution_lesson_node_00077) and prevents the "Terminal Bottleneck" failure of reducing channels in the final layer (Cite solution_lesson_node_00055).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **256** (from the previous block's Dual-Pooling). The convolution maps $256 \to 128$ filters. This performs feature integration **at the start of the new receptive field**, satisfying the requirement for **Delayed Integration** (Cite solution_lesson_node_00107).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range of the signal (Cite solution_lesson_node_00070).
    *   **Structural Innovation: Spatial-Context Bottleneck Readout**:
        *   The output of Stage 4 is a $4 \times 4 \times 256$ tensor. Flattening this yields 4,096 parameters (Risk: Overfitting, Cite solution_lesson_node_00041).
        *   **Mechanism**: Apply a **3x3 Convolution** (Padding=1, Stride=1) to compress the channels from 256 to **64**, followed by BatchNorm and ReLU.
        *   **Rationale**:
            1.  **Context Preservation**: Unlike a 1x1 convolution, the 3x3 kernel integrates the spatial adjacency between "Peak" and "Shadow" channels before compression (Cite solution_lesson_node_00101).
            2.  **Resolution Retention**: By using Stride 1, the $4 \times 4$ spatial grid is preserved. This is critical for distinguishing small objects from clutter, correcting the failure of previous 2x2 pooling readouts (Cite solution_lesson_node_00112).
            3.  **Efficiency**: The resulting flattened vector is $4 \times 4 \times 64 = 1024$ dimensions, matching the optimal input size for the dense head (Cite solution_lesson_node_00041).
        *   **Exclusion**: Do not use Global Max Pooling, as it increases sensitivity to noise (Cite solution_lesson_node_00115).

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the visual vector (1024 dim) and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference. Fold-wise scaling introduces covariate shift due to local outliers (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers which are critical signal indicators (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the SC-WBN. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained SC-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
