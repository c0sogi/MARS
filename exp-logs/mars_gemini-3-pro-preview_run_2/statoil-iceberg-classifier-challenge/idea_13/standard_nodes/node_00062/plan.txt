Implementation Strategy:
1.  **Setup & Initialization**: Set random seeds for reproducibility and configure the compute device (GPU). Ensure working directories exist.
2.  **Data Loading**: Retrieve the pre-processed datasets using `process_and_cache_data(load_cached_data=True)`. We distinguish between the training set (from `train.csv`) used for Cross-Validation and the hold-out validation set (from `val.csv`) used for the final metric calculation, ensuring strict data isolation.
3.  **Model Training (5-Fold CV)**: Implement a Stratified 5-Fold Cross-Validation loop on the training data.
    *   For each fold, instantiate the `WBPA_Net` model.
    *   Use the `fit_model` function to train the model with the Adam optimizer, `ReduceLROnPlateau` scheduler, and Early Stopping.
    *   Store the trained model from each fold.
4.  **Ensemble Evaluation**: Perform inference on the hold-out validation set using all 5 trained models. Average the probabilities to obtain the ensemble prediction. Calculate and print the `Final Validation Metric` (Log Loss).
5.  **Failure Analysis**: Compute the absolute errors of the ensemble predictions on the hold-out set. Calculate correlations between these errors and input features (Incidence Angle, HH Channel Mean, HV Channel Mean) to identify error sources.
6.  **Submission Generation**: Compare the final metric against the required threshold. If successful, perform ensemble inference on the test set (`test.csv`) and save the results to `submission.csv`.
