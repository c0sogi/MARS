The implementation strategy is as follows:
1.  **Setup**: Define input and output directories (`./input` and `./metadata`).
2.  **Load Data**: Read the `train.json` and `test.json` files using Pandas. These files contain both metadata and the raw image bands.
3.  **Extract Metadata**: Create lightweight DataFrames containing only the `id`, `inc_angle`, and `is_iceberg` (for training data) columns. Add a `filepath` column pointing to the source JSON file relative to the input directory (e.g., `train.json`). This avoids copying the large `band_1` and `band_2` arrays while allowing future scripts to locate the data.
4.  **Process Features**: Convert the `inc_angle` column to numeric, coercing "na" strings to NaN to ensure proper statistical analysis.
5.  **Create Splits**: Perform a stratified split on the training metadata to create a validation set (80% train, 20% validation) using a fixed random state (42), ensuring the class distribution is preserved.
6.  **Save Metadata**: Write the resulting `train.csv`, `val.csv`, and `test.csv` to the `./metadata` directory.
7.  **Verify**:
    *   Print summary statistics (shapes, class balance, incidence angle stats).
    *   Check the validity of file paths by verifying the existence of the source JSON files for a sample of rows.
    *   Assert that the validation split is non-overlapping and properly stratified.
