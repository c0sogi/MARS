Based on the accumulated lessons, I propose the **Multi-Scale Attention Hybrid Network (MSA-HN)**.

This solution structurally evolves the previous "Attention-Augmented Shallow Hybrid" approach. While the previous model successfully used attention mechanisms to filter noise, it relied on a fixed kernel size (single scale) throughout the backbone. The new architecture introduces **Dual-Path Multi-Scale Blocks** to simultaneously capture compact, high-frequency details (characteristic of ships) and broader, diffuse textures (characteristic of icebergs) within the same layer, before refining them with attention.

# Model

The architecture employs a **Split-Branch Topology** (Cite solution_lesson_node_00007) with a structurally innovative visual backbone.

1.  **Visual Branch (Multi-Scale Backbone)**:
    *   **Core Structure**: A custom 4-stage Convolutional Neural Network.
    *   **Structural Innovation (Dual-Path Blocks)**: Replace standard convolutional layers with **Dual-Path Multi-Scale Blocks**. Each block contains two parallel convolutional streams operating on the same input:
        *   **Local Stream**: 3x3 Convolution (padding=1) to capture fine-grained, local spatial details.
        *   **Context Stream**: 3x3 Convolution with **Dilation=2** (padding=2). This expands the receptive field effectively acting as a 5x5 filter without increasing parameter count, capturing broader contextual features.
        *   **Fusion**: The outputs of both streams are concatenated along the channel dimension.
    *   **Attention Refinement**: Apply a **Convolutional Block Attention Module (CBAM)** to the fused multi-scale feature map. This allows the network to dynamically weight the importance of "local" vs. "context" features and spatially focus on peak signals (Cite solution_lesson_node_00029).
    *   **Pooling**: Strictly employ **Max Pooling** to preserve high-intensity backscatter peaks (Cite solution_lesson_node_00021).
    *   **Output**: **Flatten** the final feature map to retain coarse spatial geometry, avoiding the information loss of Global Average Pooling (Cite solution_lesson_node_00021).

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) (Dense $\rightarrow$ BatchNorm $\rightarrow$ ReLU) to process the scalar `inc_angle` (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   Concatenate the flattened visual vector and the metadata vector.
    *   Process through a classification head with Batch Normalization, ReLU, and **Moderate Dropout (0.2)** (Cite solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1]. This maximizes contrast for each signal type (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).
    *   **Regularization**: Do not use Mixup, as it induces underfitting in this small-data regime (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the MSA-HN. This is critical to reduce variance (Cite solution_lesson_node_00029).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence and oscillation (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights, preventing reference mutation bugs (Cite solution_lesson_node_00001).
4.  **Regularization**: Only apply Weight Decay if Validation Loss > Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained MSA-HN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities. This ensemble approach is the valid metric for performance, avoiding the pitfall of comparing single-model OOF scores against ensemble benchmarks (Cite solution_lesson_node_00036).
