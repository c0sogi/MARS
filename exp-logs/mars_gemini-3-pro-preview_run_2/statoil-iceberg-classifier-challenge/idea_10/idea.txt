Based on the comprehensive analysis of previous experiments and the derived lessons, I propose the **Multi-Level Constrained-Width Network (MLCW-Net)**.

This solution introduces a structural evolution by combining **Multi-Level Feature Fusion** with a **Channel-Contracting Backbone**. This design explicitly addresses the trade-off between the need for high-frequency signal preservation (crucial for identifying small ships/icebergs) and the necessity of preventing parameter explosion in the dense layers (crucial for small-dataset generalization).

### Model
The architecture employs the successful **Split-Branch Topology** (Cite solution_lesson_node_00007) but significantly redesigns the visual feature extractor and its interface with the classification head.

1.  **Visual Branch (Backbone & Fusion)**:
    *   **Backbone Structure**: A custom 4-stage Convolutional Neural Network designed for 75x75 inputs.
    *   **Channel Contraction (Structural Innovation 1)**: Instead of the standard pattern of doubling filters at every stage (e.g., 32$\to$64$\to$128$\to$256), which was found to cause overfitting (Cite solution_lesson_node_00041), this backbone employs a "Bell Curve" or contracting width strategy:
        *   **Stage 1**: 32 Filters
        *   **Stage 2**: 48 Filters
        *   **Stage 3**: 64 Filters
        *   **Stage 4**: **32 Filters**. This explicit reduction in the final convolutional layer acts as a learnable bottleneck, compressing semantic features and significantly reducing the dimensionality of the flattened vector.
    *   **Multi-Level Feature Fusion (Structural Innovation 2)**: To mitigate the risk of "washing out" small, high-intensity peaks during successive pooling (Cite solution_lesson_node_00021), the model extracts features from **two distinct depth levels**:
        *   **Level A (Mid-Level)**: Extract the feature map from **Stage 3** (before the final pooling). Apply **Adaptive Max Pooling** to reduce it to a fixed $4 \times 4$ grid. This preserves sharper, localized intensity peaks.
        *   **Level B (High-Level)**: Extract the final output from **Stage 4** (naturally $4 \times 4$ after pooling). This contains more abstract, semantic features.
    *   **Aggregation**: Flatten and concatenate Level A and Level B vectors. This provides the classifier with both "where" (intensity peaks) and "what" (semantic texture) information.
    *   **Components**: Use **Max Pooling** strictly (Cite solution_lesson_node_00021) and integrate **CBAM (Convolutional Block Attention Modules)** in each stage to filter clutter (Cite solution_lesson_node_00029).

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the scalar `inc_angle`.

3.  **Fusion Head**:
    *   Concatenate the fused visual vector and the metadata vector.
    *   Process through a classification head with Batch Normalization, ReLU, and **Moderate Dropout (0.2)** (Cite solution_lesson_node_00014).

### Data
1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1]. This maximizes contrast for each signal type (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Explicitly exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).
    *   **Restriction**: Do not use Mixup or interpolation-based techniques (Cite solution_lesson_node_00031).

### Training
1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the MLCW-Net. This is critical to reduce variance and avoid selection bias (Cite solution_lesson_node_00029, solution_lesson_node_00032).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize the Adam optimizer with a conservative learning rate (e.g., **2e-4**) (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.2). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

### Evaluation
1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained MLCW-Net models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance (Cite solution_lesson_node_00036).
