# Baseline Approach: Downsampled Dense Neural Network (D2N)

## Model
I propose a **Downsampled Dense Neural Network (D2N)**, a simple Multi-Layer Perceptron (MLP) architecture that treats the image classification task as a generic high-dimensional pattern recognition problem. Unlike the Convolutional Neural Networks (Model 1, 3) that rely on spatial inductive biases, or the Feature Engineering approaches (Model 2, 5) that rely on manual extraction, this model learns non-linear relationships directly from the raw (but compressed) pixel data.

The architecture consists of:
1.  **Input Interface**: Accepts a flattened vector of the downsampled dual-band image concatenated with the scalar incidence angle.
2.  **Dense Blocks**: Two fully connected (Dense) layers. Each layer is followed by **Batch Normalization** to stabilize training and **ReLU** activation.
3.  **Regularization**: A **Dropout** layer is inserted after each dense block to mitigate overfitting, which is crucial given the high feature-to-sample ratio.
4.  **Output Head**: A single Dense neuron with a **Sigmoid** activation to output the probability of the target class.

## Data
To ensure efficiency and reduce the "curse of dimensionality" inherent in using raw pixels with MLPs:
1.  **Spatial Reduction**: Resize all 75x75 images to a lower resolution (e.g., 32x32) using bilinear interpolation. This step serves two purposes: it significantly reduces the input vector size (from 11,250 to ~2,000 features) and acts as a low-pass filter to dampen the high-frequency speckle noise common in SAR imagery.
2.  **Flattening**: Reshape the 32x32x2 image arrays into 1D feature vectors.
3.  **Imputation**: Replace missing `inc_angle` values with the median incidence angle calculated from the training set.
4.  **Normalization**: Apply standard scaling (zero mean, unit variance) to both the pixel values and the incidence angle. This is essential for the convergence of the dense layers.

## Training
1.  **Loss Function**: Use **Binary Cross-Entropy** (Log Loss) as the objective function.
2.  **Optimizer**: Utilize the **Adam** optimizer for its adaptive learning rate capabilities, which generally requires less tuning than SGD.
3.  **Strategy**: Implement **Early Stopping** monitoring the validation loss. This ensures the model halts training before it begins to memorize the noise in the training data, prioritizing generalization.

## Evaluation
1.  **Preprocessing**: Apply the same resizing, flattening, imputation, and normalization steps derived from the training set to the test set images.
2.  **Inference**: Perform a forward pass of the processed test vectors through the trained network to generate the final probability scores (0 to 1).
