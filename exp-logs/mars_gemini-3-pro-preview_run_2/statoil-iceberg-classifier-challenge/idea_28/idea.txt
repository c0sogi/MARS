Based on the accumulated lessons and the synthesis of previous structural trade-offs, I propose the **Delayed-Integration Dual-Pyramid Network (DIDP-Net)**.

This solution represents a structural evolution that resolves the conflict between **Backbone Capacity** (Lesson 77) and **Parameter Efficiency** (Lesson 41) while strictly adhering to the **Dual-Pooling** (Lesson 70) and **Delayed Integration** (Lesson 107) principles. It eliminates the "Immediate Compression" flaws of previous wide architectures by allowing feature streams to remain expanded until the subsequent receptive field, and utilizes a **Quadrant-Based Readout** to efficiently capture spatial context without bottlenecks.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a novel backbone and readout interface.

1.  **Visual Branch (Delayed-Integration Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across all four stages. This avoids the underfitting observed in narrower architectures (Cite solution_lesson_node_00077).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Crucial Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **256** (from the previous block's Dual-Pooling). The convolution maps $256 \to 128$ filters. This performs feature integration and compression **at the start of the new receptive field**, satisfying the requirement for **Delayed Integration** (Cite solution_lesson_node_00107) and avoiding the information loss of immediate post-pooling compression (Cite solution_lesson_node_00101).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range of the signal (Cite solution_lesson_node_00070).
    *   **Quadrant-Based Readout**:
        *   The output of Stage 4 is a $4 \times 4 \times 256$ tensor.
        *   **Mechanism**: Apply **Adaptive Max Pooling** to a **$2 \times 2$ grid (Quadrants)**.
        *   **Rationale**: This reduces the spatial dimension while strictly preserving the strongest signal peak (or deepest shadow) in each quadrant. It retains coarse spatial geometry (Cite solution_lesson_node_00021) without the parameter explosion of full flattening (Cite solution_lesson_node_00041) or the signal loss of a terminal bottleneck (Cite solution_lesson_node_00055).
        *   **Result**: The flattened vector is $2 \times 2 \times 256 = 1024$ dimensions.

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the visual vector (1024 dim) and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Strict Fold-wise Preprocessing**: Implement **Independent Per-Channel Min-Max Scaling**. Crucially, calculate the scaling statistics **exclusively on the training subset** of the current fold and apply them to the validation subset (Cite solution_lesson_node_00097).
3.  **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers which are critical signal indicators (Cite solution_lesson_node_00110).
4.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the DIDP-Net. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format. Use the **average scaling statistics** derived from the training folds to normalize the test data (or ensemble predictions from models scaled with their respective fold stats).
2.  **Ensemble Prediction**: Pass the test data through all 5 trained DIDP-Net models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
