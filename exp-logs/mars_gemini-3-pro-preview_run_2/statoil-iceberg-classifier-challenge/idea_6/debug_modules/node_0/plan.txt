The following script demonstrates the usage of the provided machine learning library for the iceberg classification task.

The strategy involves:
1.  **Data Processing**: Demonstrating how to load and process the raw JSON data into numpy arrays using `process_data`, verifying shapes and statistics.
2.  **Dataset & DataLoader**: Instantiating the `IcebergDataset` and creating DataLoaders to verify data batching and tensor shapes.
3.  **Model Architecture**: Initializing the `A2SHN` (Attention-Augmented Shallow Hybrid Network) model and performing a forward pass with dummy data to verify input/output dimensions.
4.  **Training Loop**: Running a single epoch of training on a small data subset using `train_fold` to verify the optimization step and loss calculation.
5.  **Full Pipeline**: Executing the high-level `run` function with minimal epochs and splits to demonstrate the end-to-end workflow (loading, training, inference, and submission generation).
