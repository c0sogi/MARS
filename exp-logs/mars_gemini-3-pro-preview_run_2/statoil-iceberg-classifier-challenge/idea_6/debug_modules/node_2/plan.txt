The error `ValueError: Object arrays cannot be loaded when allow_pickle=False` occurs because the cached dataset contains the `test_ids` array, which consists of string values (image IDs). NumPy stores strings as generic objects, and recent versions default `allow_pickle` to `False` for security, preventing these arrays from loading. To resolve this, I will update the `np.load` call in `library/utils.py` to explicitly set `allow_pickle=True`. This fix directly addresses the root cause identified in the traceback and aligns with the guidance to handle object array loading issues (Cite debug_lesson_3).
