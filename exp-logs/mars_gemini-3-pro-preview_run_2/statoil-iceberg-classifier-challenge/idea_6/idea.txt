Based on the accumulated lessons, I propose the **Attention-Augmented Shallow Hybrid Ensemble (A2SHE)**. This solution structurally evolves the previous approach by integrating **Attention Mechanisms** into the successful shallow backbone to explicitly address the signal-to-noise challenges of SAR imagery, and by upgrading the training pipeline to a **Cross-Validation Ensemble** to mitigate the high variance inherent in small datasets.

# Model
I propose a **Attention-Augmented Shallow Hybrid Network (A2SHN)**. This architecture retains the successful split-branch topology and lightweight depth but introduces a new attention-based feature refinement mechanism.

1.  **Visual Branch (Attention-Augmented Backbone)**:
    *   **Base Structure**: Utilize the custom **4-layer Convolutional Neural Network** identified as superior to deep ResNets for this specific 75x75 resolution (Cite solution_lesson_node_00024).
    *   **Structural Innovation (CBAM)**: Insert a **Convolutional Block Attention Module (CBAM)** after each convolutional block and before the pooling layer.
        *   **Channel Attention**: Dynamically weights the importance of the input bands (HH vs. HV vs. Avg) and learned feature maps, allowing the model to prioritize the polarization channel with the clearest signal for a given sample.
        *   **Spatial Attention**: Generates a spatial mask to selectively emphasize "peak" intensity regions (icebergs/ships) while suppressing the surrounding sea clutter (speckle noise). This acts as a learnable filter that reinforces the benefits of the Max Pooling strategy (Cite solution_lesson_node_00021).
    *   **Pooling**: Strictly employ **Max Pooling** to preserve high-intensity backscatter signals (Cite solution_lesson_node_00021).
    *   **Output**: Flatten the final feature map to retain coarse spatial geometry for the dense layers, avoiding the information loss of Global Average Pooling (Cite solution_lesson_node_00021).
2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the scalar `inc_angle` (Cite solution_lesson_node_00007).
3.  **Fusion Head**:
    *   Concatenate the flattened visual vector and the metadata vector.
    *   Process through a dense classification head with Batch Normalization, ReLU, and moderate Dropout (Cite solution_lesson_node_00014).

# Data
1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate the min and max values for each channel (HH, HV, Avg) separately on the training set and scale them to [0, 1]. This maximizes the contrast for each physical signal type, outperforming global scaling (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   Implement **Full Rotational Invariance**: Randomly rotate images by 0°, 90°, 180°, or 270° combined with random Horizontal Flips (Cite solution_lesson_node_00014).
    *   **Efficiency**: Use **native tensor operations** (e.g., `torch.rot90`) for speed and stability (Cite solution_lesson_node_00011).
    *   **Constraint**: Exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).

# Training
1.  **Pipeline Strategy (Ensemble)**: Implement **Stratified K-Fold Cross-Validation (K=5)**. Instead of training a single model on one split, train 5 independent instances of the A2SHN on different folds. This is a structural evolution to the training process that directly addresses the dataset's small size by reducing the variance of the final predictions.
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence and oscillation (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates, allowing the model to settle into the complex minima created by the rotational augmentation (Cite solution_lesson_node_00009).
3.  **Regularization**:
    *   **Dropout**: Maintain a moderate rate (e.g., 0.2) as the heavy augmentation provides substantial regularization (Cite solution_lesson_node_00014).
    *   **Weight Decay**: Only apply if validation loss consistently exceeds training loss (Cite solution_lesson_node_00012).
4.  **State Management**: Use `copy.deepcopy(model.state_dict())` within the Early Stopping logic to ensure the exact optimal weights are preserved for each fold (Cite solution_lesson_node_00001).

# Evaluation
1.  **Inference**: Process test images into the same 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This averaging smooths out model-specific errors and provides a more robust probability estimate than any single model could achieve.
