**Strategy:**
1.  **Remove Redundant Features**: Modify `library/dataset.py` to stop calculating the 15 statistical features derived from image bands. 2.  **Update Configuration**: Update `library/config.py` to reflect the reduced number of statistical features (from 16 to 1) and point to a new working directory.
3.  **Restore Conservative Training**: Modify `runfile.py` to remove the "Fast Baseline" overrides (`NUM_EPOCHS=30`, `PATIENCE=8`). This allows the model to train for up to 100 epochs with a patience of 15, as defined in `Config`, enabling stable convergence for the small dataset.
4.  **Update Analysis**: Adjust the failure analysis section in `runfile.py` to track only the remaining metadata feature (`inc_angle`).
