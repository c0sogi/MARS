The implementation strategy involves the following steps:

1.  **Configuration & Setup**: Initialize the environment by setting random seeds and configuring the `Config` class. We will override `NUM_EPOCHS` to a lower value (20) to ensure the "Fast Baseline" requirement is met while still allowing sufficient convergence.
2.  **Data Loading**: Use the provided `process_and_cache_data` function to load the preprocessed data. We will explicitly separate the data into a Training set (derived from `train.csv`) and a Hold-out Validation set (derived from `val.csv`). This ensures we can report a strictly unseen "Final Validation Metric" as requested.
3.  **Cross-Validation Training**: Perform Stratified 5-Fold Cross-Validation on the *Training set only*. For each fold:
    *   Create `IcebergDataset` and `DataLoader` for the fold's train/val splits.
    *   Use the imported `train_fold` function to train the `ShadowAwareWideBodyNet`.
    *   Store the best model weights for ensemble inference.
4.  **Hold-out Validation**:
    *   Load the hold-out validation data (`val.csv` source).
    *   Perform ensemble inference using all 5 trained models.
    *   Calculate and print the Log Loss.
5.  **Failure Analysis**:
    *   Calculate the absolute error between predictions and targets on the hold-out set.
    *   Compute correlations between this error and input features (Incidence Angle, Image Mean, Image Std) to identify systematic weaknesses.
6.  **Submission Generation**:
    *   If the validation metric meets the threshold (< 0.1667...), perform ensemble inference on the Test set.
    *   Save the predictions to `submission.csv` in the required format.
