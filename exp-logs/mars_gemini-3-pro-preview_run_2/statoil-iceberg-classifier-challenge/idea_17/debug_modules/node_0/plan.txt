The following script demonstrates the usage of the provided library components. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to reduce epochs and batch size for a rapid demonstration.
2.  **Data Loading**: Uses `process_and_cache_data` to load and preprocess the dataset, verifying the structure and shapes of the returned data (images, angles, labels).
3.  **Dataset & DataLoader**: Instantiates the `IcebergDataset` and a PyTorch `DataLoader`, fetching a single batch to verify tensor shapes and types.
4.  **Model Initialization**: Instantiates the `ShadowAwareWideBodyNet`, checks for GPU availability, and moves the model to the appropriate device.
5.  **Forward Pass Verification**: Runs a dummy forward pass with the fetched batch to ensure the model architecture (including the custom `SAAM` and `DualPooling` layers) functions correctly and produces outputs of the expected shape.
6.  **Training Loop Demonstration**: Executes a single training epoch using `train_one_epoch` and a validation step using `validate`, asserting that the loss is a valid finite number.
