Based on the accumulated lessons and the consistent finding that **shadows/signal voids are discriminative** (Cite solution_lesson_node_00070) but require specific architectural support to be fully utilized, I propose the **Shadow-Aware Wide-Body Network (SA-WBN)**.

This solution represents a structural evolution of the "Wide DPCNet" (Lesson 77). It goes beyond simply propagating shadow features via pooling; it fundamentally redesigns the **Attention Mechanism** to be explicitly "Shadow-Aware," correcting the blind spot of standard attention modules which only focus on signal presence (Max/Avg) and ignore signal absence (Min).

# Model

The architecture employs the successful **Split-Branch Topology** (Cite solution_lesson_node_00007) with a novel, physically-motivated attention mechanism embedded in a wide backbone.

1.  **Visual Branch (Shadow-Aware Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity throughout the network to prevent underfitting (Cite solution_lesson_node_00077).
        *   **Stage 1**: 64 Filters.
        *   **Stage 2**: 128 Filters.
        *   **Stage 3**: 128 Filters.
        *   **Stage 4**: 128 Filters.
    *   **Structural Innovation: Shadow-Aware Attention Module (SAAM)**:
        *   **Concept**: Standard CBAM (used in previous bests) computes attention using only Average and Max pooling. This biases the network to focus only on high-intensity "peaks" and general texture. It is blind to the "deep shadows" that Lesson 70 proved are critical for iceberg detection.
        *   **Implementation**: Replace CBAM with **SAAM**.
            *   **Channel Attention**: Compute three descriptors: Global Avg Pool, Global Max Pool, and **Global Min Pool**. Feed all three into the shared MLP to generate channel weights. This allows the network to upweight channels that contain strong shadow features.
            *   **Spatial Attention**: Concatenate channel-wise Avg Pool, Max Pool, and **Min Pool** maps. Process with a convolution to generate the spatial mask. This enables the network to spatially attend to signal voids (shadows) as explicitly as it attends to bright reflections.
    *   **Placement**: Apply SAAM strictly **Pre-Pooling** to refine features at high resolution (Cite solution_lesson_node_00061).
    *   **Pooling**: Employ **Dual-Stream Pooling (Max + Min)** (Cite solution_lesson_node_00070). This ensures that the shadow features highlighted by the SAAM are preserved and propagated to the next layer.
    *   **Output**: The final block outputs 128 filters $\times$ 2 (Dual Pooling) = 256 channels at $4 \times 4$ resolution.
    *   **Flattening**: Flatten to a 4096-dimensional vector. Avoid aggressive bottlenecks (Cite solution_lesson_node_00055).

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the scalar `inc_angle` (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse the flattened visual vector and the metadata vector (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to control overfitting given the wide backbone and large flattened vector (Cite solution_lesson_node_00077, solution_lesson_node_00002).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1]. This maximizes contrast for each signal type (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the SA-WBN. This is essential to reduce variance and maximize data utilization (Cite solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained SA-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
