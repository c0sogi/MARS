Based on the comprehensive analysis of previous experiments and the derived lessons, I propose the **Global-Local Peak-Preserving Network (GLPPN)**.

This solution introduces a structural innovation in the **Feature Aggregation Head**. It synthesizes the conflicting requirements of **Backbone Width** (necessary for feature quality, Cite solution_lesson_node_00049) and **Parameter Efficiency** (necessary to prevent dense-layer overfitting, Cite solution_lesson_node_00041) by employing a **Dual-Granularity Interface**. This interface explicitly captures both the spatial geometry ("Where") and the absolute signal intensity ("What") of the target, reinforcing the "Peak-Preserving" philosophy (Cite solution_lesson_node_00021) without the destructive bottlenecks of previous iterations (Cite solution_lesson_node_00055).

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically tuned "Sustained-Width" backbone and a novel fusion head.

1.  **Visual Branch (Sustained-Width Backbone)**:
    *   **Architecture**: A custom 4-stage Convolutional Neural Network.
    *   **Width Strategy**: Unlike previous attempts that either narrowed the network (causing underfitting, Cite solution_lesson_node_00049) or doubled channels aggressively (causing overfitting, Cite solution_lesson_node_00041), this backbone uses a **Sustained-Width** profile:
        *   **Stage 1**: 64 Filters (High initial capacity).
        *   **Stage 2**: 128 Filters.
        *   **Stage 3**: **128 Filters**.
        *   **Stage 4**: **128 Filters**.
    *   **Rationale**: Maintaining 128 filters in the final layers avoids the "Terminal Bottleneck" failure (Cite solution_lesson_node_00055) while keeping the flattened vector size (2048) significantly smaller than the 4096 of a standard doubling network, mitigating the risk of parameter explosion (Cite solution_lesson_node_00041).
    *   **Components**: Strictly employ **Max Pooling** (Cite solution_lesson_node_00021) and **CBAM Attention** (Cite solution_lesson_node_00029) in every block.

2.  **Structural Innovation: Dual-Granularity Aggregation Head**:
    *   Instead of a simple Flatten layer, the output of Stage 4 (a $4 \times 4 \times 128$ tensor) is processed by two parallel pathways:
        *   **Path A (Local-Spatial)**: **Flatten** the tensor to a 2048-dimensional vector. This preserves the coarse spatial grid, allowing the model to learn location-specific features (e.g., "target in top-left").
        *   **Path B (Global-Peak)**: Apply **Global Max Pooling** to produce a 128-dimensional vector. This extracts the single strongest activation for each filter across the entire image, providing a translation-invariant "Peak Signal" signature that is robust to object position.
    *   **Fusion**: Concatenate Path A, Path B, and the Metadata vector. This combination allows the dense layers to correlate *where* the signal is (Path A) with *how strong* the strongest signal is (Path B), stabilizing the decision boundary against sea clutter.

3.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar.

4.  **Classification Head**:
    *   Dense $\rightarrow$ BatchNorm $\rightarrow$ ReLU $\rightarrow$ Dropout (0.2) $\rightarrow$ Output.

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1]. This maximizes contrast for each signal type (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).
    *   **Exclusion**: Do not use Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the GLPPN. This is critical to reduce variance and avoid selection bias (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.2). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained GLPPN models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance (Cite solution_lesson_node_00036).
