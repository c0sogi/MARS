The implementation strategy is as follows:

1.  **Setup and Loading**: Initialize the `input` and `metadata` directories. Load the `train.csv` and `sample_submission.csv` files using pandas.
2.  **Path Generation**: Construct the relative file paths for training and test images. The paths will be in the format `./input/train/<image_id>.dicom` and `./input/test/<image_id>.dicom`.
3.  **Group Stratified Splitting**:
    *   Identify unique `image_id`s from the training set to ensure all annotations for a single image remain in the same split (Group Sampling).
    *   Create a stratification label for each image based on the presence of "No finding" (Class 14) versus any other finding. This ensures the validation set has a representative proportion of empty vs. non-empty images.
    *   Use `train_test_split` with `stratify` on these image-level labels to split the unique image IDs into training (80%) and validation (20%) sets using `RANDOM_STATE = 42`.
4.  **Metadata Creation**: Filter the original training dataframe based on the split image IDs to create `train_meta` and `val_meta`. Create `test_meta` from the sample submission file.
5.  **Saving**: Save the three metadata DataFrames to CSV files in the `./metadata` directory.
6.  **Validation**:
    *   Reload the generated metadata files.
    *   Print summary statistics (row counts, unique images).
    *   Verify the split ratio is approximately 80:20.
    *   Verify there is no data leakage (intersection of image IDs between train and val is empty).
    *   Verify the stratification by comparing the ratio of "No finding" images in train vs. val.
    *   Perform a random check of 1000 file paths from each dataset to ensure they resolve to existing files, raising an error if the missing ratio exceeds 0.5.
