This script demonstrates the end-to-end usage of the provided library for the Thoracic Lung Disease Detection task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We initialize the environment and seed random number generators for reproducibility. We dynamically modify the `Config` class to point to a temporary working directory and use reduced hyperparameters (1 epoch, small batch size) for a fast execution.
2.  **Data Subsetting**: To ensure the script runs quickly (within the time limit) while still exercising the full pipeline, we create small subsets of the provided metadata (train, val, test) containing only a few images.
3.  **Preprocessing**: We call `dicom_converter.convert_and_cache_data` to convert the subset of DICOM images to PNGs. This demonstrates how the library handles data ingestion and caching.
4.  **Dataset & DataLoader**: We instantiate `VinBigDataset` and wrap it in standard PyTorch `DataLoader`s using the provided `collate_fn`. We verify the integrity of the batch generation.
5.  **Model Initialization**: We load the Faster R-CNN model using `get_model`.
6.  **Training**: We use the `Trainer` class to train the model for one epoch on the subset. We verify that the training loop completes and saves a model checkpoint.
7.  **Inference**: We load the saved checkpoint and run inference on the test subset using `trainer.predict`.
8.  **Validation**: We verify that the submission file is generated correctly and adheres to the required format.
