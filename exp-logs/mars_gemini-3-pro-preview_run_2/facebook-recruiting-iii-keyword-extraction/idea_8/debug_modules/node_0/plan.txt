The following script demonstrates the end-to-end usage of the provided library for the Stack Exchange Tag Prediction task. 

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class to set a separate working directory (`./working/demo_run`) and reduce hyperparameters (epochs, dataset size) for a rapid execution suitable for demonstration.
2.  **Data Preparation**: We invoke `prepare_data` in debug mode to process a small subset of the text data into wide (TF-IDF) and deep (Sequence) features.
3.  **Model & Training**: We instantiate the `WideAndDeepModel`, verify its forward pass with a dummy batch, and then use the `Trainer` class to train the model for one epoch.
4.  **Inference**: We utilize the trained model to predict tags for the test set, optimizing the threshold based on validation data, and generate a submission file.
5.  **Validation**: Throughout the script, assertions verify the shapes of tensors, the existence of output files, and the correctness of the submission format.
