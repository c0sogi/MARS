The implementation strategy involves creating a self-contained Python script `runfile.py` that orchestrates the entire machine learning pipeline using the provided library modules.

1.  **Configuration & Setup**: Import necessary modules and the `Config` class. Modify `Config.EPOCHS` to 1 and increase `Config.BATCH_SIZE` to 1024 to ensure the training completes quickly (within the 2-hour limit) while fully utilizing the A100 GPU. Set random seeds for reproducibility.
2.  **Training**: Instantiate the `Trainer` class. Create data loaders for training and validation, explicitly passing the updated batch size. Execute a manual training loop for the specified number of epochs. Inside the loop, train for one epoch, evaluate on the validation set, and save the model checkpoint if the validation loss improves.
3.  **Validation**: Load the best model checkpoint. Re-evaluate on the validation set to obtain predictions. Use `optimize_threshold` to find the best decision boundary and calculate the Mean F1-Score. Print the required `Final Validation Metric`.
4.  **Failure Analysis**: Calculate the per-sample F1 score and derive the error magnitude (`1 - F1`). Load the validation metadata (`metadata/validation.csv`) to extract input features: Title length, Body length, and Number of Tags. Compute and print the Pearson correlation between the error magnitude and these features to identify systematic weaknesses.
5.  **Submission**: Compare the final validation metric against the threshold (`0.0542101508997596`). If the metric is higher, generate predictions for the test set using the optimal threshold, convert the binary predictions back to tag strings using the `Preprocessor`, and save the result to `./submission/submission.csv`.
