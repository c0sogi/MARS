4.  **Training Loop**: We will initialize the `Trainer` class and execute the `fit()` method. This demonstrates the training pipeline, including mixed-precision handling and model checkpointing. We will verify that the model weights are saved to disk upon completion.
5.  **Inference & Submission**: We will run the full inference pipeline using `library.inference.run_inference`.
