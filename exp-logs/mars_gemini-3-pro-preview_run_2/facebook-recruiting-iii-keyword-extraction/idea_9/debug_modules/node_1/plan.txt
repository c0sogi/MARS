The issue is caused by `WideDataset.__getitem__` returning a raw tensor instead of a tuple when targets are not provided (inference mode). Consequently, the `DataLoader` collates samples into a single batch tensor rather than a list containing the batch tensor. When `predict_logits` iterates over this batch tensor (e.g., `[t.to(device) for t in batch]`), it iterates over the batch dimension (size 50), causing `len(batch)` to equal the batch size instead of 1. To fix this, `WideDataset.__getitem__` must return a tuple `(x_tensor,)` to ensure the `DataLoader` yields a list structure compatible with the `predict_logits` logic.
