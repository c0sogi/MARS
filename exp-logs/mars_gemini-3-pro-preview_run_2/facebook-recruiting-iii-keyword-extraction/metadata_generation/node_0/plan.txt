Implementation Strategy:
1.  **Setup & Loading**: Define input/output directories. Load `train.csv` and `test.csv` using pandas. Given the large memory availability (220GB RAM), we load the full datasets.
2.  **Preprocessing for Split**: 
    *   Handle missing values in `Tags`.
    *   Create a proxy label for stratification by extracting the first tag from the space-delimited `Tags` string.
    *   Group rare labels (appearing < 2 times) into an 'other' category to ensure `train_test_split` works correctly with stratification.
3.  **Splitting**: Perform an 80:20 stratified split on the training data using `sklearn.model_selection.train_test_split` with `random_state=42`.
4.  **Metadata Generation**: 
    *   Add a `source_file` column to each dataset (train, val, test) containing the relative path to the original file in `./input` (e.g., `train.csv`).
    *   Save the resulting dataframes as `train.csv`, `validation.csv`, and `test.csv` in the `./metadata` directory.
5.  **Validation**:
    *   Reload the generated metadata files.
    *   Print summary statistics (counts, class distributions).
    *   Programmatically check 1000 random file paths (resolving them against `./input`) to ensure they exist.
    *   Verify the split ratio is approximately 0.2.
    *   Verify there is no ID overlap between train and validation sets.
