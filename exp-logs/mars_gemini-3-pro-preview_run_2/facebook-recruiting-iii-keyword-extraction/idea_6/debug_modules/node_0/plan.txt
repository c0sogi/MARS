### Implementation Strategy

1.  **Data Subsampling**: To ensure the script runs quickly (within minutes), I will load only the first 2,000 rows from the metadata CSVs (`train.csv`, `validation.csv`, `test.csv`) and save them to a temporary working directory (`./working/demo_run`).
2.  **Configuration Override (Monkey Patching)**: Since the provided library files import constants (like file paths and hyperparameters) directly from `library.config`, I will import the relevant modules and update these constants at runtime. I will:
    *   Redirect file paths to the subsampled data.
    *   Reduce `VOCAB_SIZE_WIDE` and `VOCAB_SIZE_DEEP` to 1,000.
    *   Reduce `NUM_TAGS` to 100.
    *   Set `EPOCHS` to 1 and `BATCH_SIZE` to 32.
3.  **Pipeline Execution**:
    *   **Data Processing**: Call `get_dataloaders` to tokenize text and create TF-IDF features. I will verify the integrity of the resulting DataLoaders.
    *   **Model Initialization**: Instantiate `WideAndDeepModel` and verify it accepts the input shapes.
    *   **Training**: Run `train_one_epoch` to demonstrate the training loop and ensure the loss is calculated correctly.
    *   **Evaluation**: Run `evaluate` on the validation set.
    *   **Inference**: Optimize the threshold and generate a submission file using `generate_submission`.
4.  **Validation**: Throughout the script, I will use `assert` statements to verify data shapes, file existence, and logical consistency.
