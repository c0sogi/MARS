# Title
**Wide-and-Deep Network with Focal Loss and Adaptive Thresholding**

# Model
I propose a **Wide-and-Deep** neural architecture that structurally synthesizes the efficiency of count-based models with the semantic power of embeddings. This architecture consists of two parallel pathways:
1.  **The Wide Component:** A single sparse linear layer that takes **TF-IDF vectors** (unigrams and bigrams) as input. This component directly exploits the finding that simple, high-coverage lexical matching is superior for this task **Cite {solution_lesson_node_00007}**. It ensures that specific technical keywords (e.g., "ggplot2", "NullPointerException") map directly to their corresponding tags without being diluted by dense representations.
2.  **The Deep Component:** A dense pathway consisting of a learnable **Embedding Layer** followed by **Global Average Pooling** and a series of fully connected (Dense) layers with ReLU activation. This component captures semantic similarities and latent topic structures that exact keyword matching might miss.
3.  **Fusion & Output:** The outputs (logits) from the Wide and Deep paths are summed and passed through a **Sigmoid** activation function. This ensures the final predictions are bounded probabilities in the range $[0, 1]$, directly resolving the issue of unbounded scores that caused the failure of the Naive Bayes approach **Cite {solution_lesson_node_00006}**.

# Data
1.  **Full Dataset Utilization:** We will utilize the **entire 4.3M sample training set**. We will strictly avoid subsampling, as previous experiments demonstrated that data coverage is more critical than model complexity for high-cardinality tagging **Cite {solution_lesson_node_00007}**.
2.  **Dual Preprocessing:**
    *   **For Wide:** Compute TF-IDF features on the concatenated Title and Body, retaining the top 100,000 unigrams and bigrams.
    *   **For Deep:** Tokenize the text into integer sequences using a vocabulary of the top 50,000 words, padding/truncating to a fixed length (e.g., 200 tokens).
3.  **Targets:** Encode the top 5,000 most frequent tags as Multi-Hot binary vectors.

# Training
1.  **Loss Function:** Implement **Focal Loss**. Standard Binary Cross Entropy struggled with the massive class imbalance (sparsity) in previous neural attempts. Focal Loss will dynamically down-weight the contribution of easy negatives (the vast majority of labels) and focus the gradient updates on hard, misclassified examples **Cite {solution_lesson_node_00007}**.
2.  **Optimization:** Use the **Adam** optimizer. To handle the memory load of the Wide component (sparse) and Deep component (dense) simultaneously on the GPU, we will use mixed-precision training (FP16).

# Evaluation
1.  **Inference:** Generate probability scores for the validation set using the trained model.
2.  **Distribution-Aware Thresholding:** We will not use a hard-coded search range. Instead, we will calculate the **percentiles of the predicted probabilities** on the validation set. The optimal threshold will be searched for dynamically within a range defined by these percentiles (e.g., between the 95th and 99.9th percentile) to ensure the decision boundary adapts to the model's confidence distribution **Cite {solution_lesson_node_00006}**.
