This script demonstrates the end-to-end workflow using the provided library modules. It performs the following steps:
1.  **Setup**: Initializes the environment and sets random seeds.
2.  **Data Loading**: Loads a small subset of the training, validation, and test data using `data_loader`.
3.  **Preprocessing**: Generates Bag-of-Words features for text and One-vs-Rest binary targets for tags using `preprocessor`. It verifies the shapes of the generated matrices.
4.  **Modeling**: Instantiates, trains, and saves the `VectorizedMNB` model. It then loads the model to verify persistence.
5.  **Evaluation**: Predicts tags on the validation set, decodes them back to strings, and calculates a sample F1 score.
6.  **Inference**: Generates predictions for the test set and formats the output for submission.
