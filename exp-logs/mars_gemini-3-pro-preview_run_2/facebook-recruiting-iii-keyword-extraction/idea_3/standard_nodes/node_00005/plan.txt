The issue is caused by a dimension mismatch between the cached feature/target matrices and the loaded dataframe. The caching logic in `library/preprocessor.py` blindly loads existing `.npz` files (e.g., from a previous run with 2,000 samples) without verifying if the number of rows matches the current dataframe (e.g., 50,000 samples). This leads to a `ValueError` when `runfile.py` attempts to calculate correlations between arrays of different lengths.

To fix this, I will update `get_text_features` and `get_target_matrix` in `library/preprocessor.py` to validate that the number of rows in the loaded cached matrix matches the length of the input dataframe. If there is a mismatch, the cache will be ignored, and the features/targets will be recomputed. This ensures consistency regardless of the dataset subset size being used.
