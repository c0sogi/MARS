Implementation Strategy:
1.  **Configuration & Setup**: I will override the default `NUM_EPOCHS` to 5 to ensure the training fits comfortably within the time limit while still allowing the model to converge on the large dataset. I will use the full dataset (`DEBUG=False`) because the Deep Averaging Network (DAN) is computationally efficient.
2.  **Data Loading**: I will utilize `library.data.get_dataloaders` with `load_cached_data=True`. This function handles reading the stratified metadata, preprocessing text (cleaning and tokenization), and creating PyTorch DataLoaders.
3.  **Model Training**: I will instantiate the `DAN` model with the vocabulary and tag sizes derived from the data. I will then train the model using `library.engine.train_model`, which handles the training loop, validation monitoring, and early stopping.
4.  **Threshold Optimization**: Post-training, I will reload the best model checkpoint and perform a dedicated evaluation pass on the validation set to obtain raw probabilities. I will then use `library.utils.optimize_threshold` to determine the decision threshold that maximizes the Mean F1-Score.
5.  **Failure Analysis**: I will calculate the F1 score for each validation sample. I will then compute the Pearson correlation coefficient between the error (1 - F1) and the length of the input text (number of tokens) to analyze if sequence length impacts performance.
6.  **Submission**: I will update the configuration with the optimal threshold and use `library.engine.generate_submission` to predict tags for the test set and save the formatted `submission.csv`.
