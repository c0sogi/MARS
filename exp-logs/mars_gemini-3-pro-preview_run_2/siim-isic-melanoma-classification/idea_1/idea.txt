To establish a highly efficient baseline that prioritizes speed and simplicity while addressing the specific challenges of this dataset (multimodal data, class imbalance), I propose the following solution:

# Model
The architecture is a **Hybrid Linear Probe** built upon a **MobileNetV3-Small** backbone.
*   **Visual Stream:** The MobileNetV3-Small network, pre-trained on ImageNet, is used as a static feature extractor. All convolutional layers are **frozen**, meaning their weights are not updated during training. This ensures maximum training speed and minimal computational overhead compared to the EfficientNet (Model 1) or Swin (Model 2) architectures.
*   **Metadata Integration:** The global average pooled output from the visual stream (576-dimensional vector) is concatenated directly with a processed metadata vector.
*   **Classification Head:** Unlike Model 1 (which uses a multi-layer perceptron) or Model 3 (which uses gradient boosted trees), this architecture employs a **single dense linear layer** followed by a sigmoid activation. This effectively performs logistic regression on the fused feature space, establishing a baseline for linear separability of the pre-trained features.

# Data
*   **Image Preprocessing:** Images are resized to **224x224** pixels to minimize I/O and processing time. Pixel values are normalized using standard ImageNet mean and standard deviation.
*   **Metadata Preprocessing:**
    *   Missing values in `sex`, `age_approx`, and `anatom_site_general_challenge` are imputed using the mode (categorical) or mean (numerical) from the training set.
    *   Categorical variables (`sex`, `anatom_site`) are **one-hot encoded**.
    *   The numerical variable (`age_approx`) is **standardized** (zero mean, unit variance) to match the scale of the visual embeddings.

# Training
*   **Loss Function:** To address the severe class imbalance (approximately 1:55), the model is trained using **Binary Cross Entropy with Logits Loss** weighted by a **positive class weight** (e.g., `pos_weight=50`). This forces the model to pay attention to the rare malignant cases without the complexity of resampling techniques.
*   **Optimizer:** The **Adam** optimizer is used with a standard learning rate (e.g., 1e-3).
*   **Procedure:** Since the backbone is frozen, the model only needs to train the weights of the final linear layer. This allows the training to converge in very few epochs (e.g., 3-5) with extremely low computational cost.

# Evaluation
*   **Inference:** The trained model processes the test set images and metadata using the same preprocessing steps.
*   **Prediction:** The output probabilities from the sigmoid activation are saved directly to the submission file. No test-time augmentation (TTA) or ensembling is performed, strictly adhering to the philosophy of a lightweight baseline.
