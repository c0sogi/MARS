The implementation strategy involves creating a main execution script `runfile.py` that orchestrates the entire machine learning pipeline using the provided library modules.

1.  **Setup & Configuration**: The script initializes the environment by setting random seeds for reproducibility and selecting the appropriate computation device (GPU/CPU) using `Config` and `utils.seed_everything`.
2.  **Data Loading**: It utilizes `dataset.get_dataloaders` to efficiently load training, validation, and test datasets. This leverages the pre-implemented caching mechanism to speed up metadata processing.
3.  **Model Initialization**: The `HybridLinearProbe` model is instantiated. The dimension of the metadata features is dynamically determined from a sample batch to ensure compatibility.
4.  **Training Loop**: A standard training loop is implemented for a fixed number of epochs (defined in `Config`). It uses `BCEWithLogitsLoss` with a positive class weight to handle the class imbalance. The model weights are optimized using Adam. The best model (based on Validation AUC) is saved to disk.
5.  **Validation & Metric Reporting**: After training, the best model is reloaded. The script calculates the AUC on the full validation set and prints it in the specific format required: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: The script performs a failure analysis on the validation set. It computes the absolute error between predictions and ground truth, then calculates and prints the correlation between this error magnitude and key metadata features (Age, Sex, Anatomical Site) to identify potential biases or weak points.
7.  **Submission**: Finally, the model generates probability predictions for the test set. These are formatted into a DataFrame and saved to `submission/submission.csv` as required.
