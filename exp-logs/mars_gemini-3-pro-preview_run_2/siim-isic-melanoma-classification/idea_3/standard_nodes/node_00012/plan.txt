Implementation strategy:
1.  **Setup & Configuration**: Import necessary libraries and the provided modules (`library.config`, `library.data`, `library.model`, `library.engine`). Override `Config` parameters (Epochs, Batch Size) to ensure the script runs efficiently within the time limit while utilizing the A100 GPU.
2.  **Data Loading**: Use `get_loaders(load_cached_data=True)` to efficiently load training, validation, and test data.
3.  **Model Initialization**: Instantiate the `ContextGatedEfficientNet` with the correct metadata dimension derived from the data loader.
4.  **Training Loop**: Implement the training loop using `AdamW` optimizer, `CosineAnnealingLR` with warmup, and `BCEWithLogitsLoss` with positive class weighting. Iterate for the defined epochs, saving the best model based on Validation AUC.
5.  **Validation & Failure Analysis**:
    *   Reload the best model.
    *   Compute and print the `Final Validation Metric` (AUC) on the full validation set.
    *   Perform failure analysis by calculating the absolute error between predictions and targets.
    *   Correlate these errors with patient metadata (`age`, `sex`, `site`) to identify systematic weaknesses.
6.  **Submission**: Check if the Final Validation AUC exceeds the strict threshold (`0.8850620049856426`). If successful, generate predictions for the test set and save `submission.csv`.
