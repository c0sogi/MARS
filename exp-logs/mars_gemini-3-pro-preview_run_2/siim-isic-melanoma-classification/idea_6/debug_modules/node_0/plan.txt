### Implementation Strategy

1.  **Environment Setup**: Set random seeds using the provided `seed_everything` utility to ensure reproducibility. Define paths for temporary outputs in the working directory.
2.  **Utility Verification (`utils.py`)**:
    *   Test `AverageMeter` by updating it with known values and asserting the correct average.
    *   Test `weight_soup` by creating two dummy model checkpoints (state dictionaries), saving them to disk, computing their "soup" (average), and verifying the resulting weights match the expected arithmetic mean.
3.  **Data Loading Verification (`data_loader.py`)**:
    *   Initialize the data loaders using `get_dataloaders`.
    *   Fetch a single batch from the training loader to verify the structure of the batch dictionary (keys: `image`, `meta`, `target`, `diagnosis`) and the tensor shapes.
    *   Create a `TruncatedDataLoader` wrapper class to limit the number of batches yielded during the training/inference simulation, ensuring the script completes quickly.
4.  **Model Verification (`model.py`)**:
    *   Instantiate `HierarchicalEfficientNet` with `pretrained=False` to avoid network requests and speed up initialization.
    *   Perform a forward pass with the batch fetched in the previous step.
    *   Assert that the output shapes for `primary_logits` and `aux_logits` match the expected dimensions based on batch size and class counts.
5.  **Training Loop Verification (`trainer.py`)**:
    *   Manually set up the optimizer and loss functions as defined in `fit_model`.
    *   Run `train_one_epoch` using the `TruncatedDataLoader` (limit to 2 batches) and assert that the returned loss is a valid float.
    *   Run `validate_one_epoch` using the truncated validation loader and assert that it returns a valid loss and AUC score.
6.  **Inference Verification (`inference.py`)**:
    *   Mock the `get_dataloaders` function within `library.inference` to return our truncated test loader. This prevents processing the entire test set.
    *   Save the trained model state to the expected path.
    *   Call `generate_submission` and verify that the output CSV is created and has the correct format and length.
