Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Import the provided library modules. Override `Config.EPOCHS` to 5 to ensure the "fast baseline" requirement is met while allowing sufficient convergence for the deep hybrid model. Initialize the device and random seeds.
2.  **Data Loading**: Use `get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test sets.
3.  **Model Initialization**: Instantiate the `DeepHybridEfficientNet`. Dynamically determine the metadata dimension from a sample batch to ensure architecture compatibility.
4.  **Training Loop**: Implement a standard training loop using `FocalLoss` and `AdamW` with a cosine annealing scheduler. Save the model checkpoint whenever the validation AUC improves.
5.  **Validation & Failure Analysis**:
    *   Load the best saved model.
    *   Run inference on the full validation set to obtain predictions.
    *   Compute and print the `Final Validation Metric` (ROC AUC).
    *   Calculate the absolute error (`|target - prediction|`).
    *   Compute correlations between this error and metadata features (`age_approx`, `sex`, `anatom_site`) to identify failure modes.
6.  **Submission**: Check if the final validation AUC exceeds the specified threshold (`0.8784179875814726`). If successful, generate predictions for the test set and save `submission.csv`.
