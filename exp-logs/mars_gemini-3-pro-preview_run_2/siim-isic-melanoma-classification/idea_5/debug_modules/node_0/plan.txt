This script demonstrates the end-to-end usage of the provided library for the skin lesion classification task. It covers data preparation, model instantiation, training, validation, and checkpoint averaging, ensuring all components function correctly within the provided environment.

1.  **Configuration & Setup**: Initializes the `Config` class in debug mode for speed and sets random seeds for reproducibility.
2.  **Data Processing**: Uses `process_metadata` to load and transform tabular data into features suitable for the neural network. It verifies the consistency of the generated feature arrays.
3.  **Dataset & DataLoader**: Instantiates `SkinLesionDataset` with Albumentations transforms and wraps them in PyTorch DataLoaders.
4.  **Model Initialization**: Creates the `HierarchicalEfficientNet` model. A dummy batch is passed through the model to assert that the output shapes of the primary (malignancy) and auxiliary (diagnosis) heads are correct.
5.  **Training & Evaluation**: Runs a complete training epoch and a validation epoch using the engine functions. It asserts that the loss decreases or remains valid and that the AUC score is computed.
6.  **Checkpoint Management**: Demonstrates the `average_checkpoints` utility by saving temporary model states, averaging them, and reloading the averaged weights, verifying the integrity of the process.
