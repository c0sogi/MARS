Implementation Strategy:
1.  **Configuration Setup**: Override the default `Config` class attributes to enable a "Debug Mode". This involves setting `debug=True`, reducing the number of epochs to 1, setting a small sample size, and switching the model architecture to a lightweight `resnet18` (via `timm`) to ensure the script runs quickly (under 1 minute) on the provided hardware.
2.  **Data Preparation**: Use `load_metadata_splits` to fetch the data. Create PyTorch `DataLoader`s using the `PawpularityDataset` class and appropriate transforms.
3.  **Model Training (Base Learner)**: Instantiate the `PetModel` with the overridden architecture. Use the `fit` function to train the model on the small training subset and generate Out-Of-Fold (OOF) predictions on the validation subset.
4.  **OOF Management**: Save the OOF predictions to a CSV file. Crucially, temporarily point `Config.train_metadata_path` to the validation metadata file. This ensures the `StackingTrainer` (which expects to load ground truth for the OOF predictions) aligns the validation IDs with the generated predictions.
5.  **Stacking (Meta-Learner)**: Initialize the `StackingTrainer`. Load the generated OOF data (which will now match the validation set) to train the Ridge regression meta-learner.
6.  **Inference**: Use the trained base model to predict on the test set. Scale these predictions and pass them to the `StackingTrainer` to generate the final ensemble predictions.
7.  **Submission**: Save the final predictions to `submission.csv` using the provided helper function.
8.  **Validation**: Include assertions throughout to verify data shapes, file existence, and prediction ranges.
