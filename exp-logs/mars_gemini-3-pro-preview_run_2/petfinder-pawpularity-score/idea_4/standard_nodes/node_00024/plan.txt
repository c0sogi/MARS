To optimize the solution, I will implement the following changes based on the provided lessons:

1.  **Simplify Ensemble & Prioritize Convergence (Cite solution_lesson_node_00020)**: I will revert to the **Heterogeneous Ensemble** of **Swin Transformer Large** and **ConvNeXt Large**, removing the BEiT model which underperformed and consumed valuable training time. I will increase the training duration to **3 epochs** per fold to ensure better convergence, as previous logs showed significant gains after epoch 1.
2.  **Re-integrate Metadata Fusion (Cite solution_lesson_node_00007)**: I will modify the dataset and model architecture to feed the 12 binary metadata features (e.g., Focus, Eyes) into the regression head. This was a key component of earlier successful solutions but was missing in the previous iteration.
3.  **Enable Mixed Precision Training (AMP)**: To offset the computational cost of increasing epochs and batch size, I will implement `torch.amp` (Automatic Mixed Precision). This will speed up training and reduce memory usage, allowing for a larger batch size (32).
4.  **Switch to Average Ensembling (Cite solution_lesson_node_00020)**: I will replace the complex Stacking/Ridge Regression meta-learner with a simple average of the model predictions, which has proven more robust for this task given the limited data.

def train_fn(model, data_loader, optimizer, device, criterion, scheduler=None):
    """
    Executes one training epoch.

    Args:
        model: The PyTorch model.
        data_loader: Training DataLoader.
        optimizer: The optimizer.
        device: 'cuda' or 'cpu'.
        criterion: Loss function.
        scheduler: Learning rate scheduler (optional).

    Returns:
        float: Average loss for the epoch.
    """
    model.train()
    running_loss = 0.0
    dataset_size = 0

    for images, targets in data_loader:
        images = images.to(device)
        targets = targets.to(device).view(-1, 1)

        optimizer.zero_grad()

        outputs = model(images)
        loss = criterion(outputs, targets)

        loss.backward()
        optimizer.step()

        batch_size = images.size(0)
        running_loss += loss.item() * batch_size
        dataset_size += batch_size

    # Step the scheduler at the end of the epoch
    if scheduler is not None:
        scheduler.step()

    return running_loss / dataset_size

    """
    Executes one training epoch with optional AMP.
    """
    model.train()
    running_loss = 0.0
    dataset_size = 0
    
    # Initialize GradScaler for AMP
    scaler = torch.amp.GradScaler('cuda', enabled=Config.use_amp)

    for images, meta, targets in data_loader:
        images = images.to(device)
        meta = meta.to(device)
        targets = targets.to(device).view(-1, 1)

        optimizer.zero_grad()

        # Mixed Precision Training
        with torch.amp.autocast('cuda', enabled=Config.use_amp):
            outputs = model(images, meta)
            loss = criterion(outputs, targets)

        scaler.scale(loss).backward()
        scaler.step(optimizer)
        scaler.update()

        batch_size = images.size(0)
        running_loss += loss.item() * batch_size
        dataset_size += batch_size

    # Step the scheduler at the end of the epoch
    if scheduler is not None:
