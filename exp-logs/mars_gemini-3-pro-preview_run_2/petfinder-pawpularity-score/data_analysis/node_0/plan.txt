The following script performs a comprehensive Exploratory Data Analysis (EDA) on the Pet Pawpularity dataset. It handles the multi-modal nature of the data by analyzing both the tabular metadata and the associated image files.

**Implementation Strategy:**
1.  **Setup & Data Loading**: The script initializes by setting random seeds for reproducibility and loading the training metadata from `./metadata/train.csv`.
2.  **Target Variable Analysis**: It analyzes the `Pawpularity` score, calculating distribution statistics, skewness, and kurtosis to understand the regression target.
3.  **Tabular Analysis**: It examines the binary metadata features (Focus, Eyes, etc.), checking for missing values and calculating the frequency of positive labels.
4.  **Image Analysis**: To ensure efficiency within the runtime limit, it samples 1000 images to calculate statistics on dimensions, aspect ratios, and pixel intensity (mean/std).
5.  **Feature Relationships**:
    -   It calculates correlations between the binary metadata features and the target.
    -   It trains a lightweight Random Forest regressor on the metadata to assess feature importance.
    -   It checks for correlations between image meta-features (like size and brightness) and the target score.
6.  **Output**: The results are printed in a structured, readable text format.
