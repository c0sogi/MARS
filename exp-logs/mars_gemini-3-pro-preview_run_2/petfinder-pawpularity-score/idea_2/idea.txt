# Strategy: End-to-End Fine-Tuning with Swin Transformer and Metadata Fusion

### Model
I propose replacing the frozen ResNet-18 with a **Swin Transformer (Tiny)** backbone initialized with ImageNet-1k weights. Unlike the previous Linear Probe approach, we will **fully unfreeze** the backbone. This structural change addresses the "regression to the mean" limitation observed in the baseline (Cite solution_lesson_node_00001), as fine-tuning allows the model to adapt its feature extraction specifically to the nuances of "pet cuteness" rather than relying on generic object classification features.

The architecture will retain the successful metadata integration strategy. The 768-dimensional embedding from the Swin Transformer will be concatenated with the 12 binary metadata features. This combined vector will be passed to a new **Multi-Layer Perceptron (MLP)** head (consisting of a Linear layer, ReLU activation, Dropout, and a final Linear projection) instead of the single linear layer used previously. This MLP allows the model to capture non-linear interactions between the visual content and the metadata tags.

### Data
Preprocessing will involve resizing images to 224x224 pixels and normalizing them using ImageNet statistics. Crucially, I will re-introduce data augmentation techniques such as **RandomHorizontalFlip** and moderate **ColorJitter**. While the previous experiments showed that augmentation degraded performance for a *frozen* linear probe (Cite solution_lesson_node_00005), it is a necessary component for *full fine-tuning* to prevent overfitting as the trainable parameter count increases significantly.

### Training
The model will be trained using **Mean Squared Error (MSE) Loss** to directly optimize the target metric. The targets will be scaled to the range [0, 1] during training to stabilize gradients and scaled back to [1, 100] for evaluation. I will implement a **Cosine Annealing scheduler with a linear warmup** to stabilize the training of the Transformer backbone. Additionally, I will apply **differential learning rates**, using a smaller learning rate for the backbone (to preserve pre-trained knowledge) and a larger learning rate for the MLP head.

### Evaluation
The test set will be processed using the same resizing and normalization steps (without augmentation). The model will output a scalar prediction which will be rescaled to the original [1, 100] range and clipped to ensure valid submission values.
