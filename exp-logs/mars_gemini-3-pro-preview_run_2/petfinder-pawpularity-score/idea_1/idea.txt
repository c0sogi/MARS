To establish a high-speed, reliable baseline for the Pawpularity prediction task, I propose a **Linear Probe on a Frozen ResNet-18**. This approach prioritizes computational efficiency and simplicity, serving as a minimal "deep" baseline to determine how well the problem can be solved using only pre-trained feature representations and a linear combination of metadata.

### Model
The architecture utilizes a **ResNet-18** backbone, chosen for its lightweight parameter count and rapid inference speed compared to EfficientNet or Swin Transformers.
1.  **Backbone**: The ResNet-18 model (pretrained on ImageNet) is instantiated and strictly **frozen**; its weights will not be updated during training. This treats the CNN solely as a feature extractor.
2.  **Feature Extraction**: Input images are passed through the backbone to extract a 512-dimensional feature vector from the global average pooling layer.
3.  **Fusion**: The 12 binary metadata features (Focus, Eyes, Face, etc.) are cast to floating-point values and directly concatenated with the 512 image features, resulting in a 524-dimensional combined vector.
4.  **Prediction Head**: This combined vector is passed into a **single Linear layer** (524 input units $\to$ 1 output unit) with a bias term. Unlike the multi-layer perceptrons (MLPs) used in other architectures, this single layer performs a simple weighted sum of the visual and metadata signals to predict the Pawpularity score.

### Data
1.  **Preprocessing**: Images will be resized to 224x224 pixels and normalized using standard ImageNet mean and standard deviation values. No complex augmentations (e.g., Mixup, Cutmix) will be applied to maintain maximum throughput.
2.  **Metadata**: The binary columns from the CSV will be extracted and converted to a FloatTensor.
3.  **Loading**: Data will be loaded using standard batched loaders. Since the backbone is frozen, the memory footprint will be low, allowing for larger batch sizes (e.g., 64 or 128) to further accelerate the single-epoch runtime.

### Training
1.  **Objective**: The model will be trained to minimize the **Mean Squared Error (MSE)** loss, which directly correlates to the RMSE metric.
2.  **Optimization**: An **AdamW** optimizer will be used to update *only* the parameters of the final linear layer (525 parameters total: 524 weights + 1 bias).
3.  **Procedure**: Because the feature extractor is frozen, the backward pass is computationally negligible. Training will proceed for a fixed, small number of epochs (e.g., 10-15) with a constant learning rate or a simple step decay. This ensures the training phase completes in minutes.

### Evaluation
1.  **Inference**: The test set images will undergo the same resizing and normalization.
2.  **Prediction**: The model will perform a forward pass to generate continuous scalar predictions.
3.  **Post-processing**: Predictions will be clipped to the valid range [1, 100] before saving to the submission file.
