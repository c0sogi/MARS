The following script performs a comprehensive Exploratory Data Analysis (EDA) on the training dataset. It adheres to the constraints by ensuring data integrity (using only the training set), setting random seeds for reproducibility, and employing a sampling strategy for image analysis to ensure the script completes well within the time limit while providing statistically significant results.

The analysis covers:
1.  **Target Variable**: Distribution and balance of tumor vs. non-tumor labels.
2.  **Image Data**: Analysis of dimensions, channel distributions, and global pixel statistics (mean/std) for normalization.
3.  **Meta-Feature Relationships**: Investigation of how simple image properties (brightness, contrast, color channels) correlate with the presence of tumor tissue.
