This script demonstrates the usage of the provided library files (`config.py`, `utils.py`, `data.py`, `models.py`, `engine.py`) to execute a complete machine learning pipeline for digital pathology.

### Implementation Strategy

1.  **Configuration Setup**: We initialize the `Config` class and override specific parameters (e.g., `DEBUG`, `EPOCHS`, `BATCH_SIZE`) to ensure the script runs quickly as a demonstration. We also verify that the necessary directories are created.
2.  **Data Loading**: We utilize `get_loaders` to generate PyTorch DataLoaders. We explicitly disable caching (`load_cached_data=False`) to trigger the raw data processing logic on a small debug subset of the data. We assert that the batch shapes match the expected dimensions.
3.  **Model Initialization**: We instantiate a `convnext_tiny` model using `get_model` (with `pretrained=False` to avoid network dependencies during this check) and verify its output shape with a dummy input.
4.  **Training & Validation**: We run a single epoch of training using `train_one_epoch` and evaluate the model using `validate`. We check that the loss is a valid float and the AUC score is within the [0, 1] range. We also demonstrate the use of `ModelEMA`.
5.  **Inference**: We execute the `predict` function, which performs Test Time Augmentation (TTA), and verify that the number of predictions matches the number of samples in the test set.
6.  **Checkpointing**: We test the `save_checkpoint` and `load_checkpoint` functions to ensure model states can be persisted and restored correctly.
