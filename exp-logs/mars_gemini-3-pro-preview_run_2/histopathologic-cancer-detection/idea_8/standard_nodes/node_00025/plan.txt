To optimize the solution, I will simplify the pipeline to focus on training a single, robust `convnext_tiny` model to convergence, rather than training an under-converged ensemble.

**Strategy:**
1.  **Single Strong Model:** I will remove the `tf_efficientnetv2_s` model and the 5-Fold Cross-Validation ensemble. Instead, I will train a single `convnext_tiny` model on the full training set (`train.csv`) and validate on the fixed validation set (`val.csv`). This allows me to allocate the entire compute budget to optimizing one model's parameters. (Cite solution_lesson_node_00014)
2.  **Increased Training Duration:** I will increase the training epochs from the effective ~3 epochs used previously to **20 epochs**. The previous run showed `convnext_tiny` improving rapidly; extending training will allow it to fully converge. (Cite solution_lesson_node_00007)
3.  **Remove EMA:** Given the relatively short training schedule (compared to ImageNet pre-training) and the lesson that high-decay EMA can hurt performance if the schedule isn't long enough to wash out initialization, I will remove Exponential Moving Average (EMA) to speed up training and avoid initialization bias. (Cite solution_lesson_node_00024)
4.  **Hyperparameter Tuning:** I will set `WEIGHT_DECAY` to `0.05` to properly regularize the ConvNeXt model, as recommended for modern architectures. (Cite solution_lesson_node_00010)

This approach prioritizes model convergence and data efficiency over ensemble diversity, which is the correct trade-off under the given constraints.

def train_one_epoch(model, train_loader, optimizer, device, epoch, ema_model=None):
    """
    Handles one epoch of training.

    Args:
        model: The PyTorch model to train.
        train_loader: DataLoader for training data.
        optimizer: Optimizer.
        device: Computation device.
        epoch: Current epoch number.
        ema_model: Optional ModelEMA instance for weight averaging.

    Returns:
        float: Average loss for the epoch.
    """
    model.train()
    metric_monitor = MetricMonitor()
    criterion = nn.BCEWithLogitsLoss()

    for batch in train_loader:
        images = batch["image"].to(device, non_blocking=True)
        labels = batch["label"].to(device, non_blocking=True)

        # Apply Mixup
        mixed_images, labels_a, labels_b, lam = mixup_data(
            images, labels, Config.MIXUP_ALPHA, device
        )

        # Forward pass
        optimizer.zero_grad()
        outputs = model(mixed_images)

        # Squeeze outputs to match label shape (B,)
        outputs = outputs.squeeze(1)

        loss = mixup_criterion(criterion, outputs, labels_a, labels_b, lam)

        # Backward pass
        loss.backward()
        optimizer.step()

        # Update EMA
        if ema_model:
            ema_model.update(model)

        metric_monitor.update("Loss", loss.item())

    print(f"Epoch {epoch} Training: {metric_monitor}")
    return metric_monitor.metrics["Loss"]["avg"]
