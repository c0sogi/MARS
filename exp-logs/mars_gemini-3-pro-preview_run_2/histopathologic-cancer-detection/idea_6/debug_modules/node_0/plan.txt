### Implementation Strategy

1.  **Configuration Override**: To adhere to the "Optimize for Speed" requirement, the script first overrides `Config` parameters. It sets `EPOCHS` to 1, `BATCH_SIZE` to 8, and redirects output directories (cache, checkpoints) to a temporary folder in `./working`.
2.  **Subset Data Generation**: Instead of loading the full 140k+ dataset, the script reads the provided metadata, samples a tiny subset (e.g., 50 samples), and saves new temporary metadata files in `./working`. It then points `Config` to these new files. This ensures the data loading logic is fully exercised without the runtime overhead.
3.  **Component Verification**:
    *   **Data Loading**: Calls `get_loaders` and asserts that the resulting batches have the correct shapes (images: `[B, 3, 64, 64]`, labels: `[B]`).
    *   **Model**: Instantiates the ConvNeXt model and performs a forward pass with dummy data to verify output dimensionality.
    *   **Utilities**: Verifies `calculate_roc_auc` with known inputs and checks `MetricMonitor` aggregation logic.
    *   **Training Loop**: Runs `train_fold` on the subset data. This implicitly verifies `train_one_epoch`, `validate`, `ModelEMA`, and Mixup augmentation logic.
    *   **Inference**: Runs `inference_fn` (Test Time Augmentation) on the subset test data and asserts prediction shapes.
4.  **Cleanup**: Removes the temporary directories created during execution.
