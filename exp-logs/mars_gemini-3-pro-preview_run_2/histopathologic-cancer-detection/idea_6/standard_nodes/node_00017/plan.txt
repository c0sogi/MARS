Implementation strategy:
1.  **Environment Setup**: Initialize the environment by setting seeds for reproducibility and creating necessary directories using the `Config` class.
2.  **Configuration Override**: Modify `Config` parameters to execute a "fast baseline" within the time limit. This includes reducing the number of epochs to 3 and setting a limit on the number of training samples (5000), while maintaining the 5-fold cross-validation structure.
3.  **Data Loading**: Load the training, validation, and test datasets using `library.data.load_data`. Subsample the training data using stratified sampling to ensure class balance within the reduced dataset.
4.  **Training Loop (5-Fold CV)**:
    *   Use `StratifiedKFold` to split the subsampled training data.
    *   For each fold, initialize the `ConvNeXt-Tiny` model, `AdamW` optimizer, and `CosineAnnealingLR` scheduler.
    *   Train the model using `library.engine.train_fold`, which handles Mixup augmentation, EMA updates, and saving the best model checkpoint.
    *   Reload the best weights for each fold's model after training.
5.  **Global Validation**:
    *   Perform inference on the complete hold-out validation set using the ensemble of 5 models.
    *   Utilize `library.engine.inference_fn` to apply 8-view Test Time Augmentation (TTA).
    *   Average the predictions and calculate the final Area Under the ROC Curve (AUC).
    *   Print the result in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Compute the absolute error between predictions and ground truth on the validation set.
    *   Extract global image features (Brightness, Contrast, Channel Means) for the validation images.
    *   Calculate and print the Pearson correlation between the error magnitude and these features to identify potential biases.
7.  **Submission**:
    *   Check if the validation AUC exceeds the threshold (0.9889066475479729).
    *   If successful, perform inference on the test set using the ensemble and TTA.
    *   Save the averaged predictions to `./submission/submission.csv`.
