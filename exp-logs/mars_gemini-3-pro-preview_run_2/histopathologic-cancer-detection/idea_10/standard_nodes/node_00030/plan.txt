My implementation strategy for the `runfile.py` script is as follows:

1.  **Configuration Override**: I will modify the default `Config` parameters to satisfy the "fast baseline" requirement. Specifically, I will reduce `Config.epochs` to 5 (down from 20) to ensure the training completes quickly while still allowing enough convergence to potentially meet the high AUC threshold. I will keep `Config.debug = False` to utilize the full dataset, as the target AUC (0.9889+) is unlikely to be achieved with a small subsample.
2.  **Data Loading**: I will use the provided `load_data_to_memory` function with `load_cached_data=True` to efficiently load the dataset into RAM, minimizing I/O overhead.
3.  **5-Fold Cross-Validation**: I will implement the main training loop iterating through 5 folds. For each fold, I will:
    *   Initialize the `Trainer` with the appropriate DataLoaders.
    *   Train the model using `trainer.fit()`.
    *   Perform inference on the validation fold using the best saved checkpoint to generate Out-Of-Fold (OOF) predictions.
    *   Store these OOF predictions in a global array aligned with the training labels.
4.  **Validation & Metrics**: I will calculate the Area Under the ROC Curve (AUC) using the aggregated OOF predictions and the ground truth labels. This global metric serves as the "Final Validation Metric".
5.  **Failure Analysis**: I will compute absolute errors for the OOF predictions. Then, I will calculate basic image statistics (Brightness, Contrast, Channel Means) for the validation samples and compute the Pearson correlation between these statistics and the model's error magnitude to identify potential failure modes.
6.  **Submission**: If the calculated Final Validation Metric exceeds the threshold of `0.9889066475479729`, I will trigger the `run_inference()` function from the library to generate the final `submission.csv`.
