The `RuntimeError` indicates that the `checkpoints` directory does not exist when the model attempts to save a checkpoint. This happens because `Config.setup()`, which is responsible for creating the artifact directories (`checkpoints`, `cache`, `submission`), is never called in `runfile.py`. I will fix this by calling `Config.setup()` in the `main` function of `runfile.py`. Additionally, I will proactively prevent a future crash by enabling `allow_pickle=True` when loading cached NumPy arrays in `library/data.py`, as the dataset contains string IDs which require pickling (Cite debug_lesson_2).
