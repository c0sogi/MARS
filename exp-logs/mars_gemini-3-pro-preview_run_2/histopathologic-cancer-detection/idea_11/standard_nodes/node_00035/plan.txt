Implementation strategy:
The implementation orchestrates a fast baseline run of the Memory-Resident Homogeneous Bagged Ensemble strategy. To adhere to the strict 8-minute time limit, the script overrides the default configuration to perform a single-fold, single-epoch training run on a randomly subsampled training set (2,000 images), while ensuring validation is performed on the **entire** hold-out dataset as required.

1.  **Configuration**: At runtime, `Config` attributes are modified: `EPOCHS=1`, `NUM_FOLDS=1`, `NUM_RUNS=1`, and `DEBUG=False` (to ensure full validation set loading).
2.  **Data Loading**: `get_loaders` is called to load the data into RAM. A `torch.utils.data.Subset` is created to limit the training data to 2,000 random samples for speed. The validation loader remains untouched to cover the full 35k+ validation images.
3.  **Training**: A `PathologyModel` (ConvNeXt-Tiny) and `ModelEma` are initialized. The model is trained for one epoch using `train_one_epoch`.
4.  **Validation**: The `validate` function is called with the EMA model on the full validation loader. The final AUC is printed in the specified format.
5.  **Failure Analysis**: A dedicated inference loop generates predictions for the validation set. Vectorized NumPy operations compute image statistics (Brightness, Contrast, RGB Means) for the validation images. Pearson correlations between these features and the absolute prediction error are calculated and printed.
6.  **Submission**: The script checks if the validation AUC strictly exceeds `0.9889066475479729`. If so, it generates predictions using `predict_tta` (8 views) on the test set and saves the submission; otherwise, it skips this step.
