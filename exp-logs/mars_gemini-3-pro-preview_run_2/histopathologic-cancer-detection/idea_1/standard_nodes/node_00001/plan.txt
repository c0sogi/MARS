The implementation strategy is as follows:

1.  **Setup**: Initialize the environment using the provided `Config` and `set_seed` functions to ensure reproducibility and correct device placement (GPU).
2.  **Training**: Execute the training loop using `library.train.run_training`. To meet the "fast baseline" requirement while utilizing the A100 GPU effectively, I will run the training for 2 epochs on the full dataset. This balances speed with the need for the model to see sufficient data.
3.  **Validation & Failure Analysis**:
    *   Load the best model checkpoint saved during training.
    *   Run inference on the validation set in evaluation mode (`model.eval()`) without gradient calculation (`torch.no_grad()`).
    *   Compute and print the `Final Validation Metric` (AUC) as required.
    *   Calculate the absolute error magnitude for each validation sample.
    *   Extract basic image statistics (Brightness, Contrast, RGB Means) from the normalized input tensors.
    *   Compute and print the Pearson correlation between these features and the error magnitude to identify systematic failures.
4.  **Submission**: Generate the final predictions for the test set using `library.predict.generate_submission` and save them to the specified output path.
