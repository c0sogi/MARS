The implementation strategy involves the following steps:

1.  **Setup and Loading**: Initialize paths for input and metadata directories. Define a helper function to parse COCO-style JSON files (`train2019.json`, `val2019.json`, `test2019.json`) into Pandas DataFrames. This function merges image information with annotations (for training/validation data) and category names.
2.  **Validation Set Handling**: Attempt to load the provided `val2019.json`. If this file is missing, empty, or lacks annotation data (ground truth labels), the script will fall back to creating a validation set by splitting the training data. This split uses stratified sampling (80/20 ratio) to maintain class distribution, with special handling for rare classes.
3.  **Path Correction**: Verify that the file paths in the metadata resolve to actual files in the `./input` directory. It is likely that training images need the `train_val2019/` prefix added to their paths. The script checks a sample file and applies the prefix to the entire DataFrame if necessary.
4.  **Metadata Generation**: Save the processed DataFrames as CSV files (`train.csv`, `val.csv`, `test.csv`) in the `./metadata` directory. The CSVs will contain `image_id`, `file_name`, and `category_id` (for train/val).
5.  **Verification**: Reload the generated metadata files and perform a rigorous check. This includes verifying the shape of the data and checking the existence of 1000 randomly sampled file paths for each dataset. If the missing file ratio exceeds 0.5, the script raises an error.
