Implementation strategy:
1.  **Configuration & Setup**: Initialize the environment by setting the random seed and defining constants. I will set the number of training epochs to 3 to ensure a balance between execution speed (fast baseline) and model convergence on the full dataset.
2.  **Training**: Execute the training pipeline using `library.train.train_model` with `debug=False` to utilize the full dataset. This ensures the model learns from the complete distribution of contrails.
3.  **Validation & Metric Calculation**:
    *   Load the trained model and the validation dataloader.
    *   Iterate through the validation set to compute the **Global Dice Coefficient**. This involves accumulating the intersection and union of predicted and ground truth pixels across the entire dataset before computing the ratio, strictly adhering to the metric definition ($2 \cdot |X \cap Y| / (|X| + |Y|)$).
    *   Simultaneously, compute per-sample Dice scores to facilitate failure analysis.
4.  **Failure Analysis**:
    *   Load validation metadata (timestamps, geospatial coordinates).
    *   Merge per-sample error metrics (defined as $1 - \text{Dice}$) with the metadata.
    *   Calculate and print the Pearson correlation between the error magnitude and key features (`hour`, `month`, `row_min`, `col_min`) to identify potential biases or systematic failure modes.
5.  **Submission**:
    *   Compare the computed Global Dice against the threshold ($0.5454606988733747$).
    *   If the model performance exceeds the threshold, execute `library.predict.predict_and_submit` to generate the run-length encoded submission file for the test set.
