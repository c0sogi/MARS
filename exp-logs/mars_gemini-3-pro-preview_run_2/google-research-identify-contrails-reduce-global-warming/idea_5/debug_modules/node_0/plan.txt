The following code demonstrates the usage of the Contrail Identification library components. It verifies the utility functions, dataset loading, model architecture, loss calculation, training loop, and inference pipeline.

The script performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use temporary directories and reduced hyperparameters (1 epoch, small batch size) for a fast demonstration.
2.  **Utility Verification**: Tests the Run-Length Encoding (RLE) logic and Global Dice metric calculation with deterministic inputs.
3.  **Dataset Verification**: Loads a subset of the training data, checks tensor shapes, and verifies data normalization.
4.  **Model Verification**: Instantiates the `ContextEnhancedUNet`, performs a forward pass with dummy data, and asserts output dimensions.
5.  **Loss Verification**: Computes the `HybridBatchDiceLoss` on random tensors to ensure numerical stability.
6.  **Training Loop Execution**: Runs the `train_model` function in debug mode to train on a small subset of data and save a checkpoint.
7.  **Inference Execution**: Runs `predict_and_submit` using the trained checkpoint on a subset of test data to generate a submission file.
