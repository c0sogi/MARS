### Implementation Strategy

2.  **Utility Verification**: Test the `rle_encode` function with a synthetic mask to confirm it produces the expected run-length encoding string. Verify the `dice_coefficient` metric logic.
3.  **Data Loading**: Initialize the data loaders using `get_data_loaders` in debug mode (small sample size). Fetch a single batch from the training loader to verify input shapes (Image: `[B, 6, 256, 256]`, Metadata: `[B, 3]`, Mask: `[B, 1, 256, 256]`) and data types.
4.  **Model Initialization**: Instantiate the `GC_ConvNeXtUNet` model. Perform a dummy forward pass with the fetched batch to verify the output shape matches the ground truth `[B, 1, 256, 256]`.
5.  **Loss Computation**: Instantiate `HybridLoss`. Calculate the loss between the model predictions and the ground truth masks. Verify that the loss is a valid scalar and that backpropagation (gradient calculation) works without errors.
6.  **Optimization Step**: Perform a single optimization step using `AdamW` to demonstrate the training loop mechanics.
7.  **Inference & Submission**: Simulate the inference process on a test batch. Apply sigmoid activation, thresholding, and RLE encoding. Generate a sample submission CSV file to demonstrate the final output format.
