Based on the comprehensive analysis of the accumulated lessons, I propose the **Global-Conditioned Extended-Kernel ConvNeXt U-Net**.

This strategy synthesizes the "Linearity Prior" of the Large-Kernel architecture (Cite `solution_lesson_node_00036`) with a **Metadata-Conditioned Bottleneck** to address geographic bias (Cite `solution_lesson_node_00057`). Furthermore, it re-introduces the **Extended Kernel (11x11) Decoder** from Idea 22 but strictly applies the **Homogeneous Feature Scaling** protocol (Cite `solution_lesson_node_00058`), correcting the specific flaw that caused the previous attempt to fail.

### Model
The architecture is a **U-Net** variant designed to maximize the isotropic receptive field and explicitly condition the feature extraction on global physical parameters.

*   **Backbone (Encoder):** We utilize **ConvNeXt-Tiny** (initialized with ImageNet weights).
    *   **Retention:** We retain the **7x7 Depthwise Convolutions**. As established, this large isotropic receptive field enforces a strong linearity prior, which is superior for contrail segmentation compared to standard 3x3 CNNs (Cite `solution_lesson_node_00036`) or dilated backbones (Cite `solution_lesson_node_00033`).
*   **Context Bridge (Conditioned ASPP):**
    *   We retain the **Atrous Spatial Pyramid Pooling (ASPP)** module to capture multi-scale context (Cite `solution_lesson_node_00021`).
    *   **Structural Innovation (Metadata Injection):** We inject global metadata to address the "Latitude Bias" (Cite `solution_lesson_node_00002`).
        *   We extract `row_min` (latitude), `col_min` (longitude), and `timestamp` (time of day) from the metadata.
        *   These scalars are normalized and passed through a lightweight **Multi-Layer Perceptron (MLP)** to project them into a feature vector.
        *   This vector is spatially broadcast (repeated) to match the resolution of the bottleneck feature map and concatenated with the ASPP output.
        *   **Rationale:** This allows the model to learn location-dependent physics (e.g., temperature thresholds for contrail formation vary by latitude) without breaking the translation invariance of the convolution operations, unlike local coordinate channels (Cite `solution_lesson_node_00057`).
*   **Decoder (Extended-Kernel Refinement):**
    *   We employ a **Sequential U-Net Decoder** (Stride 32 $\to$ 1) (Cite `solution_lesson_node_00046`).
    *   **Innovation:** We utilize **Extended ConvNeXt Blocks** with **11x11 Depthwise Convolutions** in the decoder.
    *   **Rationale:** While 7x7 kernels work well in the encoder, the decoder must reconstruct continuous linear features from low-resolution semantics. Expanding the kernel to 11x11 significantly increases the physical receptive field during upsampling, allowing the model to bridge gaps between disjoint segments more effectively (Cite `solution_lesson_node_00036`).
    *   **Upsampling:** We use **Bilinear Upsampling** followed by convolutions (Cite `solution_lesson_node_00008`).
    *   **Attention:** We retain **SCSE** blocks after concatenation (Cite `solution_lesson_node_00021`).

### Data
*   **Input Engineering (Homogeneous Decoupled Features):** We generate a **6-channel input tensor**.
    *   **Channels 1-3:** "Ash" False Color Composite of the labeled frame ($t=4$).
    *   **Channels 4-6:** **Raw Band Differences** ($t=4$ minus $t=3$) for Bands 11, 14, and 15 (Cite `solution_lesson_node_00045`).
    *   **Preprocessing (Crucial Correction):** We apply **Homogeneous Scaling**.
        *   The Ash Composite is normalized to $[0, 1]$.
        *   The Raw Band Differences are clipped to a fixed physical range (e.g., $\pm 5$ Kelvin) and linearly scaled to $[0, 1]$.
        *   **Rationale:** This corrects the failure of Idea 22, where mixing normalized features with raw physical units caused convergence failure. Ensuring all inputs are in $[0, 1]$ allows the 11x11 kernels to learn effectively from the start (Cite `solution_lesson_node_00058`).
*   **Augmentation:** We employ a strict **Affine Transformation** pipeline (Rotation, Scale, Shift, Flip). We explicitly **exclude** elastic/grid distortions (Cite `solution_lesson_node_00004`).
*   **Dataset:** We train on the **full dataset** (18,673 images) (Cite `solution_lesson_node_00002`).

### Training
*   **Loss Function:** We employ a **Hybrid Loss**: $L_{total} = L_{BCE} + L_{BatchDice}$.
    *   **Batch-Level Dice:** Computed over the **entire flattened batch**. This stabilizes gradients and aligns with the global metric (Cite `solution_lesson_node_00014`, `solution_lesson_node_00018`).
*   **Optimization:** We use **AdamW** with a Cosine Annealing scheduler.
*   **Batch Size:** We utilize a **Batch Size of 32** to ensure statistical stability for the Batch Dice loss (Cite `solution_lesson_node_00043`).
*   **Duration:** We train for **30 epochs** to prevent underfitting (Cite `solution_lesson_node_00007`).

### Evaluation
*   **Inference Strategy:** We implement **Test-Time Augmentation (TTA)** (4 views: original, flips, 180-rot) to maximize precision (Cite `solution_lesson_node_00024`).
*   **Post-Processing:** Standard threshold of **0.5**. No hard gating (Cite `solution_lesson_node_00009`).
