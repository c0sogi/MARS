This script implements the full pipeline for the Contrail Detection task using the Deformable ResNet18 U-Net strategy.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class at runtime to establish a "Fast Baseline". We enable `DEBUG` mode but increase `DEBUG_SAMPLE_SIZE` to 4000 and set `EPOCHS` to 8. This ensures the training completes quickly (well within 2 hours) while providing enough data to potentially meet the performance threshold.
2.  **Training**: We invoke `library.train_engine.run_training`. This handles data loading, model initialization, and the training loop with the Hybrid Loss (BCE + Batch Dice) and AdamW optimizer.
3.  **Validation & Analysis**:
    *   We load the best saved model.
    *   We iterate through the **entire** validation set.
    *   We compute the **Global Dice** metric (aggregating intersection and union across the whole set).
    *   Simultaneously, we collect per-sample statistics (Dice score, Error, Ground Truth Fraction) and link them with metadata (Time of day, etc.) using `record_id`.
4.  **Failure Analysis**: We create a DataFrame from the collected statistics and compute the Pearson correlation between the `Error` (1 - Dice) and various features (Hour, Timestamp, Contrail Fraction) to identify systematic weaknesses.
5.  **Submission**: We compare the computed Global Dice against the strict threshold (`0.5676456935477064`). If the model passes, we execute `library.inference.run_inference` to generate the run-length encoded predictions for the test set.
