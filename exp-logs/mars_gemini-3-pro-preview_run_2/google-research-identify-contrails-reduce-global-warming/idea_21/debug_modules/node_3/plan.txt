The issue is an `IndexError` in `library/model.py` because the code assumes the `convnext_tiny` encoder returns 5 feature maps (indices 0-4), but `timm`'s implementation with `features_only=True` returns only 4 feature maps (indices 0-3) corresponding to the outputs of the four stages (strides 4, 8, 16, 32). The code attempts to access `enc_dims[4]` and `features[4]`, which do not exist.

To fix this, I will shift the indices used in `IsotropicConvNeXtUNet` down by 1 to match the actual output of the encoder:
1.  **Bridge (ASPP):** Use index 3 (Stride 32) instead of 4.
2.  **Decoder 1:** Use skip connection from index 2 (Stride 16) instead of 3.
3.  **Decoder 2:** Use skip connection from index 1 (Stride 8) instead of 2.
4.  **Decoder 3:** Use skip connection from index 0 (Stride 4) instead of 1.

This aligns the U-Net architecture with the 4-level feature pyramid provided by the ConvNeXt backbone.
