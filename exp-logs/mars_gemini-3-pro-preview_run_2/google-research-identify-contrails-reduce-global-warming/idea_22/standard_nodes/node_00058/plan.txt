The following script implements the end-to-end pipeline for the contrail identification task. It leverages the provided library modules to set up the `ExtendedConvNeXtUNet` model, processes the data using the physics-decoupled strategy, and trains the model using a `FocalBatchDiceLoss`.

To ensure the task completes within the "fast baseline" constraints, the script trains on a subset of the training data (5,000 samples) for 5 epochs. It then evaluates the model on the full validation set to compute the global Dice coefficient. Following evaluation, it performs a failure analysis by correlating prediction errors with metadata features. Finally, if the validation performance exceeds the specified threshold, it generates predictions for the test set using Test-Time Augmentation (TTA) and saves the submission file.
