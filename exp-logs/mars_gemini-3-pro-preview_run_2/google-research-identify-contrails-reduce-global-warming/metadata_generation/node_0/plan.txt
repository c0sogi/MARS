The following script generates metadata CSV files for the training, validation, and test datasets by scanning the directory structure and merging with the provided JSON metadata. It includes validation checks to ensure file paths are correct and prints summary statistics.

### Implementation Strategy
1.  **Directory Scanning**: The script scans the `./input/train`, `./input/validation`, and `./input/test` directories to identify all available `record_id`s.
2.  **Path Construction**: For each record, it constructs relative file paths for all 9 satellite bands (`band_08` to `band_16`) and the ground truth masks (`human_pixel_masks`, `human_individual_masks`) where applicable.
3.  **Metadata Merging**: It loads the provided `train_metadata.json` and `validation_metadata.json` files and merges them with the file path information based on `record_id`.
4.  **Output Generation**: The consolidated metadata is saved as CSV files in the `./metadata` directory.
5.  **Validation**: The script performs a sanity check by verifying the existence of 1000 randomly selected files from the generated metadata to ensure the paths are valid. It also prints summary statistics.
