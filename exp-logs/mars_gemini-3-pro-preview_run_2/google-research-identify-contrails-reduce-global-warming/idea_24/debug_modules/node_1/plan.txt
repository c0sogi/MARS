The error `AttributeError: 'FeatureListNet' object has no attribute 'stem'` occurs because `timm.create_model(..., features_only=True)` returns a wrapper class (`FeatureListNet`) that hides the internal layers of the backbone (like `.stem`), making manual modification of the first convolutional layer impossible via direct attribute access. As detailed in **debug_lesson_7**, the robust solution is to pass the `in_chans` argument directly to `timm.create_model`. This instructs the library to automatically handle the reconstruction of the input layer and the initialization of weights (e.g., by recycling pretrained RGB weights for the additional channels), removing the need for the custom `_adapt_input_channels` method.

    def _adapt_input_channels(self, in_channels):
        """
        Modifies the first convolution layer of the backbone to accept `in_channels`.
        Copies weights from the first 3 channels to the new channels to preserve initialization.
        """
        # ConvNeXt stem is usually: Sequential(Conv2d, LayerNorm)
        stem = self.encoder.stem
        old_conv = stem[0]

        if old_conv.in_channels == in_channels:
            return

        new_conv = nn.Conv2d(
            in_channels,
            old_conv.out_channels,
            kernel_size=old_conv.kernel_size,
            stride=old_conv.stride,
            padding=old_conv.padding,
            bias=old_conv.bias is not None,
        )

        # Initialize weights
        with torch.no_grad():
            # Copy RGB weights to first 3 channels
            new_conv.weight[:, :3] = old_conv.weight
            # Copy RGB weights to next 3 channels (temporal diffs)
            # This provides a better starting point than random init
            if in_channels > 3:
                new_conv.weight[:, 3:6] = old_conv.weight

            if old_conv.bias is not None:
                new_conv.bias = old_conv.bias

        stem[0] = new_conv
