The script `runfile.py` orchestrates the entire pipeline. It first overrides the default configuration to limit training epochs to 5 and training samples to 5000 to ensure the process completes quickly within the time limit. It then executes the training loop. After training, it reloads the best model checkpoint and performs a full evaluation on the validation set to calculate the Global Dice coefficient and analyze failure modes by correlating prediction errors with metadata features (time, location, object size). Finally, if the validation metric exceeds the specified threshold, it runs the inference module to generate the submission file.
