The issue is caused by attempting to access `self.encoder.stem` on a `timm` model initialized with `features_only=True`. When `features_only=True` is set, `timm` returns a `FeatureListNet` wrapper that does not directly expose the underlying backbone's attributes like `stem`, causing an `AttributeError` when the code attempts to manually patch the first layer for 6-channel input.

To fix this, I will modify `library/model.py` to pass the `in_chans=Config.IN_CHANNELS` argument directly to `timm.create_model`. This leverages `timm`'s built-in capability to adapt the first convolutional layer for arbitrary input channels (including weight initialization/adaptation), removing the need for manual architecture surgery and resolving the attribute access error.
