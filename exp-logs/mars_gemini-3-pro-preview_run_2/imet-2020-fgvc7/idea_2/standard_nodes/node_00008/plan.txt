    Finds the single global optimal threshold that maximizes the Micro F1 score.
    
    Optimizing thresholds per-class maximizes Macro F1 but often degrades Micro F1 
    by introducing too many false positives for rare classes. A global threshold 
    aligns better with the Micro F1 metric (Cite solution_lesson_node_00006).

    Args:
        val_logits (np.array): Model output logits of shape (N, C).

        num_steps (int): Number of threshold steps to check between 0 and 1.

    Returns:
        np.array: Array of shape (C,) containing the optimal global threshold repeated.
    """
    print("Optimizing global threshold for Micro F1...")

    # Convert logits to probabilities
    val_probs = 1 / (1 + np.exp(-val_logits))

    # Define search space
    thresholds = np.linspace(0.01, 0.99, num_steps)
    
    best_f1 = -1
    best_th = 0.5

    # Grid search for global threshold
    for th in thresholds:

    return np.full(val_targets.shape[1], best_th)
