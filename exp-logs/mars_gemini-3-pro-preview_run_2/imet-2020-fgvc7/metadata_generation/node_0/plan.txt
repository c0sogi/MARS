My implementation strategy is as follows:

1.  **Setup and Discovery**: Define the input (`./input`) and output (`./metadata`) directories. Scan the `./input/train` and `./input/test` directories to map image IDs to their actual filenames (handling potential extensions, though `.png` is expected).
2.  **Data Loading**: Read `train.csv` to get training labels and `sample_submission.csv` to get test IDs.
3.  **Path Resolution**: Create a `file_path` column for all datasets, resolving the relative path from the `./input` directory (e.g., `train/0000...png`). Filter out any entries where the image file does not exist.
4.  **Data Splitting**: Perform an 80:20 train/validation split on the training data.
    -   I will use `sklearn.model_selection.train_test_split` with `random_state=42`.
    -   *Stratification Note*: While the task is multi-label classification, exact iterative stratification on 120,000 samples with ~3,500 classes is computationally expensive and slow. Given the large sample size, a random split with shuffling is statistically sufficient to preserve label distributions. I will verify this representativeness in the validation step.
5.  **Metadata Generation**: Save the processed DataFrames (`train_metadata.csv`, `val_metadata.csv`, `test_metadata.csv`) to the `./metadata` directory.
6.  **Validation & Verification**:
    -   Reload the generated metadata files.
    -   Print summary statistics (shape, columns).
    -   **File Path Check**: Randomly sample 1,000 paths from each file and verify they exist on disk. Raise an error if the missing ratio > 0.5.
    -   **Distribution Check**: Calculate the prevalence of the top 20 labels in both the training and validation sets. Assert that the difference in distribution is within a reasonable tolerance (e.g., 5%) to confirm the split is representative.
