The following script demonstrates the usage of the provided library files to execute a complete, scaled-down version of the artwork attribute labeling pipeline.

**Strategy:**
1.  **Configuration Patching:** We modify the `Config` class attributes at runtime to enable `DEBUG` mode, reduce batch sizes, switch to lightweight models (`resnet18`), and redirect outputs to a temporary `./working/demo_run` directory. This ensures the code runs quickly (within minutes) and does not overwrite production files.
2.  **Component Verification:**
    *   **Dataset:** We instantiate DataLoaders and verify batch shapes and content (images, targets).
    *   **Losses:** We validate that `AsymmetricLoss` and `DistillationLoss` compute scalar values and handle gradients correctly.
    *   **Modeling:** We run a single training epoch for a "Teacher" model to demonstrate the training loop.
    *   **Distillation:** We generate soft labels using the trained teacher and verify the "Student" model can load them for distillation training.
    *   **Inference:** We execute the validation and inference pipeline, including threshold optimization and submission file generation.
3.  **Assertions:** Explicit assertions are placed after each major step to confirm the logic (e.g., checking file existence, tensor shapes, and loss values).
