Optimization Strategy:
1.  **Dual-Transformer Stacking**: Augment the ensemble by adding a second high-capacity transformer, `roberta-large`, alongside `deberta-v3-large`. This increases model diversity (BERT-family vs. DeBERTa-family) and leverages the "strong learner" principle (Cite solution_lesson_node_00009).
2.  **Enhanced Context Window**: Increase `max_length` from 80 to 128. The failure analysis showed a negative correlation between error and text length, suggesting the model performs better with more context. Extending the window ensures longer texts are not prematurely truncated.
3.  **Richer Dense Features**: Increase `svd_n_components` from 100 to 200 to capture more variance in the LSA features used by XGBoost (Cite solution_lesson_node_00004).
4.  **Refined Stacking Logic**: Update the `StackingEnsemble` to support dynamic model selection during the cross-validation loop, allowing multiple distinct neural architectures to be trained and stacked within the same run.
