The `FileNotFoundError` arises because the `create_submission` method in `library/meta_learner.py` defines `output_path` with a default value of `Config.SUBMISSION_PATH`. This default value is evaluated and bound at import time, capturing the original path (Cite debug_lesson_4). Although `runfile.py` updates `Config.SUBMISSION_PATH` at runtime to a new directory, the method call uses the stale default value, saving the submission to the wrong location. I will fix this by explicitly passing the updated `Config.SUBMISSION_PATH` when calling `create_submission` in `runfile.py`, forcing the use of the correct runtime path.
