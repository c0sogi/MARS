# Solution Strategy: Stylometric-Enhanced Hybrid Stacking with Multi-Sample Dropout

## Model
The architecture represents a structural evolution of the "Single-Backbone Multi-View" idea. It enhances the neural backbone's regularization to prevent overfitting on this small dataset and fundamentally expands the feature space of the classical branch to include domain-specific authorship signals.

*   **Level 1: Base Estimators (Tri-View Architecture)**
    *   **Branch A: The Regularized Neural Expert**
        *   **Backbone:** We will utilize **`microsoft/deberta-v3-large`**, identified as the superior learner (Cite solution_lesson_node_00009).
        *   **Structural Innovation (Head):** We will implement a **Weighted Layer Pooling** head (aggregating the last 4 layers) followed by **Multi-Sample Dropout**.
            *   *Mechanism:* Instead of a single dropout layer before the classifier, we will use 5 parallel dropout masks with different random seeds. The output vectors are computed for each mask, passed through the classifier, and then averaged.
            *   *Rationale:* This technique acts as an internal ensemble within the network, smoothing the decision boundary and accelerating convergence, which is critical given the strict early stopping requirements (Cite solution_lesson_node_00010).
    *   **Branch B: The Sparse Statistical Expert (Retained)**
        *   We preserve the highly effective linear models operating on high-dimensional sparse data.
        *   **Models:** **Logistic Regression** and **Multinomial Naive Bayes** trained on sparse TF-IDF features (Cite solution_lesson_node_00004).
    *   **Branch C: The Dense Stylometric Expert (Enhanced)**
        *   We evolve the tree-based component (**XGBoost**) by upgrading its input representation.
        *   **Structural Innovation (Feature Fusion):** Instead of relying solely on latent SVD projections, we will construct an **Augmented Dense Vector**. This vector concatenates:
            1.  **Latent Semantic Features:** Truncated SVD components (100 dim) of the TF-IDF matrix.
            2.  **Explicit Stylometric Features:** A new set of handcrafted features designed to capture authorship style, including:
                *   *Punctuation Density:* Counts of semicolons, colons, exclamation marks, and question marks per sentence (critical for distinguishing EAP/HPL).
                *   *Complexity Metrics:* Average word length, sentence character length, and type-token ratio.
                *   *Stopword Usage:* Frequency of common function words.

*   **Level 2: Meta-Learner**
    *   A **Logistic Regression** model will aggregate the predictions from the Neural branch and the two Classical branches.

## Data
The data pipeline is optimized to maximize signal density while strictly pruning noise.

*   **Text Preprocessing:**
    *   **Hybrid N-Grams:** We will generate **Word N-grams (1-3)** and **Character N-grams (2-5)**. This combination is essential for capturing both semantic content and morphological style (Cite solution_lesson_node_00001).
    *   **Noise Pruning:** We will strictly enforce **`min_df=2`** for all TF-IDF vectorizers to remove singleton terms that induce overfitting (Cite solution_lesson_node_00002).
    *   **Stylometric Extraction:** We will compute the explicit stylometric features (punctuation, length stats) using efficient string operations and standard stopword lists.
    *   **Neural Tokenization:** We will set **`max_length=85`**. Analysis confirms this covers the vast majority of the data distribution (Mean + 3$\sigma$), preventing the batch instability associated with excessive padding (Cite solution_lesson_node_00013).

*   **Dimensionality Reduction:**
    *   We will apply **Truncated SVD** (100 components) to the sparse TF-IDF matrix specifically for the XGBoost input, enabling the tree model to learn from the n-gram data (Cite solution_lesson_node_00004).

## Training
The training strategy is designed to prioritize the generalization of the strongest learner.

*   **Cross-Validation:** We will strictly enforce **Stratified 5-Fold Cross-Validation** for all models. We will *not* sacrifice training data volume (e.g., reducing to 3 folds) to fit more models, as the DeBERTa backbone requires maximum data density to generalize (Cite solution_lesson_node_00015).
*   **Optimization:**
    *   **Aggressive Early Stopping:** For the DeBERTa model, we will set **`patience=1`**. This forces the model to stop immediately upon the first sign of validation loss degradation, preventing the memorization of fold-specific noise (Cite solution_lesson_node_00010).
    *   **Batch Stability:** We will use **Gradient Accumulation** to ensure an effective batch size of at least 16, maintaining stable Batch Normalization statistics despite the memory footprint of the Large model (Cite solution_lesson_node_00013).
    *   **Artifact Caching:** All intermediate features and OOF predictions will be cached using **configuration-hash filenames** to ensure reproducibility (Cite solution_lesson_node_00003).

## Evaluation
*   **Inference:** The test data will be processed through the Neural pipeline (DeBERTa w/ Multi-Sample Dropout) and the Classical pipelines (Sparse TF-IDF and Dense Stylometric+SVD).
*   **Aggregation:** The probability vectors from all base estimators will be concatenated and fed into the trained Meta-Learner.
*   **Safety:** Final predictions will be clipped to the range \\([10^{-15}, 1-10^{-15}]\\) to satisfy the metric stability requirements.
