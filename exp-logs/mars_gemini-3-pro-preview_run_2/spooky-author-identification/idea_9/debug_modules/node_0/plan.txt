Implementation Strategy:
1.  **Environment Setup**: Import libraries and override `Config` parameters to enable debug mode (`debug=True`), reduce dataset size, epochs, and model complexity for rapid execution.
2.  **Data Preparation**: Use `data_factory` to load the small debug dataset and generate classical features (TF-IDF, SVD), asserting correct shapes and existence.
3.  **Classical Modeling**: Execute `classical_engine.run_classical_cv` to train Logistic Regression, Naive Bayes, and XGBoost on the generated features, verifying the output prediction shapes.
4.  **Neural Modeling**: Instantiate the `CustomDeberta` model, tokenizer, and data loaders. Configure the optimizer with layer-wise learning rates.
5.  **Execution & Verification**: Run the training (`train_fn`), evaluation (`eval_fn`), and inference (`inference_fn`) loops for one epoch. Use assertions to validate loss values, probability distributions, and output dimensions.
