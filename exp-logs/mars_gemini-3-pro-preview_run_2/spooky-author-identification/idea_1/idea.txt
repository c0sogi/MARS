# Baseline Solution: Dual-Stream TF-IDF Logistic Regression

### Model
The proposed baseline is a **Sparse Logistic Regression** model designed to exploit the high-dimensional nature of text data without the computational overhead of neural networks. The architecture consists of a single linear classification layer (Softmax Regression) that operates on a unified feature space. This space is constructed by concatenating two distinct sparse representations of the text: one capturing semantic word usage and the other capturing morphological and stylistic character patterns. This approach synthesizes the n-gram feature extraction concepts from the provided architectures but simplifies the pipeline by removing complex weighting schemes (like Naive Bayes ratios) or dimensionality reduction (like SVD), relying instead on the robustness of linear models in high-dimensional spaces.

### Data
Preprocessing will be kept minimal to preserve unique stylistic signals such as capitalization, punctuation, and sentence structure, which are highly predictive of authorship. The feature extraction process involves two parallel TF-IDF (Term Frequency-Inverse Document Frequency) vectorization steps:
1.  **Word N-grams:** We will generate unigrams, bigrams, and trigrams to capture vocabulary and common phrases.
2.  **Character N-grams:** We will generate character n-grams (ranging from length 2 to 5) to capture sub-word structures, suffixes, and punctuation habits.
These two sparse matrices will be horizontally concatenated to create a single, comprehensive feature matrix for every document.

### Training
The model will be trained using **Logistic Regression** with a multinomial (multi-class) objective.
*   **Loss Function:** We will minimize the **Multi-class Logarithmic Loss** (Cross-Entropy), which directly optimizes the evaluation metric.
*   **Optimizer:** We will use a solver optimized for large-scale sparse datasets, such as L-BFGS or SAG (Stochastic Average Gradient).
*   **Regularization:** L2 regularization (Ridge) will be applied to manage the high dimensionality of the concatenated n-gram features and prevent overfitting.

### Evaluation
During evaluation, the test text will be transformed using the fitted TF-IDF vectorizers from the training phase. The trained Logistic Regression model will then predict the probability distribution for the three classes (EAP, HPL, MWS) for each test instance. These raw probabilities will be formatted into the required CSV structure for submission.
