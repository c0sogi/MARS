# Solution Strategy: Single-Backbone Multi-View Stacking

## Model
The core structural innovation is a shift from **Inter-Model Diversity** (training multiple different heavy transformers, which failed due to resource/data constraints) to **Intra-Model Diversity** (extracting multiple distinct representations from a single, state-of-the-art backbone).

*   **Level 1: Base Estimators**
    *   **Branch A: The "Multi-View" Neural Expert**
        *   **Backbone:** We will rely exclusively on **`microsoft/deberta-v3-large`**, identified as the strongest learner (Cite solution_lesson_node_00009).
        *   **Structural Innovation (Custom Head):** Instead of a simple `[CLS]` classifier, we will implement a **Weighted Layer & Dual-Pooling Head**.
            1.  **Layer Selection:** We extract hidden states from the **last 4 layers**. This captures a gradient of information from syntactic structure (lower) to semantic abstraction (higher).
            2.  **Weighted Averaging:** We apply a learnable scalar weight to each of these 4 layers to dynamically fuse them.
            3.  **Dual Pooling:** On this fused representation, we compute both **Mean Pooling** (to capture global stylistic tone) and **Max Pooling** (to capture salient features like specific rare words).
            4.  **Concatenation:** These two vectors are concatenated and fed into the final classification layer. This allows the single model to simultaneously act as a "global style" detector and a "specific feature" detector.
    *   **Branch B: The Classical Statistical Expert**
        *   We retain the highly effective "shallow" stack to capture explicit lexical signals that deep models might smooth over.
        *   **Models:**
            1.  **Logistic Regression** (Sparse TF-IDF)
            2.  **Multinomial Naive Bayes** (Sparse TF-IDF)
            3.  **XGBoost** (Dense SVD-Projected) (Cite solution_lesson_node_00004).

*   **Level 2: Meta-Learner**
    *   A **Logistic Regression** model will aggregate the probability distributions from the Neural branch and the three Classical models.

## Data
The data pipeline is strictly regulated to maximize signal quality and computational stability.

*   **Classical Preprocessing:**
    *   **Feature Engineering:** We will construct a **Hybrid N-Gram** space by concatenating **Word N-grams (1-3)** and **Character N-grams (2-5)** (Cite solution_lesson_node_00001).
    *   **Noise Reduction:** We will enforce **`min_df=2`** to prune singleton noise and improve generalization (Cite solution_lesson_node_00002).
    *   **Dimensionality Reduction:** We will apply **Truncated SVD** (100 components) specifically for the XGBoost input (Cite solution_lesson_node_00009).

*   **Neural Preprocessing:**
    *   **Sequence Length:** We will set **`max_length=85`**. Analysis confirms this covers >99% of the data. Capping it here enables larger batch sizes and prevents the instability caused by processing excessive padding (Cite solution_lesson_node_00013).

## Training
The training strategy is designed to correct the resource allocation error from the previous iteration.

*   **Cross-Validation:** We will strictly enforce **Stratified 5-Fold Cross-Validation** for *all* models, including the large Transformer.
    *   **Correction:** We explicitly reject the 3-fold compromise used previously. By dropping the secondary RoBERTa model, we reclaim the compute time necessary to train the stronger DeBERTa model on 80% of the data (4/5 splits) instead of 66% (2/3 splits), maximizing its generalization capability (Cite solution_lesson_node_00015).
*   **Optimization:**
    *   **Aggressive Early Stopping:** For the DeBERTa model, we will set **`patience=1`**. This forces the model to stop immediately upon the first sign of validation loss degradation, ensuring OOF predictions are not overfitted to specific folds (Cite solution_lesson_node_00010).
    *   **Batch Stability:** We will use **Gradient Accumulation** to ensure an effective batch size of at least 16, maintaining stable Batch Normalization statistics (Cite solution_lesson_node_00013).
    *   **Artifact Caching:** All intermediate features and OOF predictions will be cached using **configuration-hash filenames** to ensure reproducibility and prevent stale data loading (Cite solution_lesson_node_00003).

## Evaluation
*   **Inference:** The test set will be processed through the Neural pipeline (DeBERTa w/ Dual-Pooling) and the Classical pipeline (TF-IDF/SVD).
*   **Aggregation:** The probability vectors from all 4 base estimators (1 Neural, 3 Classical) will be concatenated and fed to the Meta-Learner.
*   **Safety:** Final predictions will be clipped to \\([10^{-15}, 1-10^{-15}]\\) to satisfy the metric requirements.
