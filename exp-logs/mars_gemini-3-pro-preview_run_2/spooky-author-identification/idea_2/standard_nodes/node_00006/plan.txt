To improve the model's performance, I will enhance the **Heterogeneous Stacking Ensemble** by adding a **LightGBM** classifier to the base layer and increasing the resolution of the dense feature representation.

**Strategy:**
1.  **Enhance Feature Representation**: Increase `SVD_N_COMPONENTS` from 300 to 600. This provides the tree-based models (XGBoost, LightGBM) with a richer dense representation of the text, reducing information loss from dimensionality reduction.
2.  **Add LightGBM Base Learner**: Introduce `LGBMClassifier` to the first layer of the stack. LightGBM uses a leaf-wise tree growth strategy (unlike XGBoost's depth-wise), offering a diverse inductive bias that complements XGBoost. This directly applies **Lesson 4 (Heterogeneous Stacking)** (Cite solution_lesson_node_00004).
3.  **Hyperparameter Tuning**: Optimize `XGB_PARAMS` by increasing `n_estimators` to 500 and reducing `learning_rate` to 0.05 for more granular gradient descent. Configure `LGB_PARAMS` similarly.
4.  **Update Pipeline**: Modify `StackingManager` to handle the training, OOF generation, and inference for the new LightGBM model.
5.  **Update Threshold**: Set the submission threshold in `runfile.py` to the previous best score (0.3467) to ensure we only submit if we improve.
