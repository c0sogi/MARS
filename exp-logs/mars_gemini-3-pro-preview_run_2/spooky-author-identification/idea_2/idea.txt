# Solution Strategy: Stacking Ensemble with Hybrid N-Grams and SVD-Projected Non-Linearity

## Model
I propose a structural evolution from a single linear model to a **Two-Layer Stacking Ensemble**. This architecture is designed to combine the strengths of high-dimensional linear discrimination with non-linear tree-based logic and probabilistic modeling.

*   **Layer 1 (Base Estimators):**
    1.  **Logistic Regression:** Retained to exploit the high-dimensional sparse nature of the text features, which proved effective in previous iterations.
    2.  **Multinomial Naive Bayes (MNB):** Introduced to capture the probabilistic distribution of token counts. MNB often provides a diverse error profile compared to discriminative linear models, making it ideal for ensembling.
    3.  **XGBoost Classifier:** Introduced to capture non-linear interactions between features. Since tree-based models struggle with high-dimensional sparse data, this model will operate on a dimensionality-reduced version of the feature space (see Data section).

*   **Layer 2 (Meta-Learner):**
    *   A **Logistic Regression** model will serve as the blender, taking the class probabilities output by the three base estimators as input to generate the final prediction. This allows the system to dynamically weight the most reliable model for different types of samples.

## Data
The data processing pipeline will be upgraded to support the ensemble while strictly adhering to the lessons learned regarding feature quality and integrity.

*   **Feature Extraction:** We will construct a "Hybrid N-Gram" feature space by horizontally concatenating **Word N-grams (range 1-3)** and **Character N-grams (range 2-5)**. This preserves the critical finding that character-level signals are necessary for capturing author style (Cite solution_lesson_node_00001).
*   **Feature Pruning:** All TF-IDF vectorizers will enforce a minimum document frequency of **`min_df=2`**. This removes singleton terms (hapax legomena) to reduce noise and dimensionality, preventing the performance degradation observed when rare terms were included (Cite solution_lesson_node_00002).
*   **Dimensionality Reduction (Branching):**
    *   The Logistic Regression and MNB models will receive the full high-dimensional sparse matrix.
    *   For the **XGBoost** branch, we will apply **Truncated SVD** to project the sparse features into a dense vector space (e.g., 200-500 components). This enables the tree model to efficiently learn non-linear patterns without being overwhelmed by sparsity.

## Training
The training procedure will focus on robust validation and computational efficiency.

*   **Cross-Validation Strategy:** We will use **Stratified K-Fold Cross-Validation** (e.g., 5 folds) to train the base estimators. The Out-Of-Fold (OOF) predictions from these folds will form the training data for the Layer 2 Meta-Learner, preventing data leakage.
*   **Configuration-Aware Caching:** We will implement a caching mechanism that generates filenames based on a **deterministic hash of the configuration parameters** (e.g., `md5(config_dict)`). This ensures that any change to hyperparameters (like `min_df` or SVD components) automatically invalidates old cache files, preventing the "silent failure" caused by stale artifacts (Cite solution_lesson_node_00003).

## Evaluation
*   **Inference:** The test set will be processed through the same feature extraction and SVD pipelines. The base models will predict probabilities for the test samples, which will then be fed into the trained Meta-Learner for the final score.
*   **Post-Processing:** Final probabilities will be clipped to the range \\([10^{-15}, 1-10^{-15}]\\) as specified in the metric requirements to ensure numerical stability for the Log Loss calculation.
