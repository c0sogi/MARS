# Solution Strategy: Dual-Backbone Stylometric Fusion Ensemble

## Model
The proposed architecture introduces a **Stylometric-Fusion Transformer (SFT)** paradigm. This design addresses a fundamental limitation of pure transformer models in authorship attribution: while they excel at semantic and syntactic patterns, they often struggle to explicitly quantify global stylistic statistics (e.g., "frequency of semicolons" or "average sentence length") which are highly discriminative for these specific authors.

*   **Level 1: Base Estimators (Heterogeneous 5-Model System)**
    *   **Branch A: Stylometric-Fusion Transformers (Neural Innovation)**
        *   **Architecture:** We will implement a multi-modal network that processes text and tabular style features simultaneously.
            1.  **Text Path:** The tokenized sequence is fed into a Large Transformer backbone. We extract the hidden states from the last 4 layers and apply **Weighted Layer Pooling** to capture a gradient of syntactic-to-semantic information.
            2.  **Style Path:** We extract a dense vector of explicit stylometric features (punctuation counts, sentence length metrics, function word frequencies) and pass them through a lightweight **MLP (Multi-Layer Perceptron)** with Batch Normalization to project them into a compatible latent space.
            3.  **Fusion:** The pooled text vector and the projected style vector are concatenated.
            4.  **Classification:** The fused vector is passed through a **Multi-Sample Dropout** head to generate predictions.
        *   **Backbones:** To maximize ensemble diversity within the 24-hour budget, we will train two distinct instances of this architecture:
            1.  **`microsoft/deberta-v3-large`:** Selected for its superior disentangled attention mechanism (Cite solution_lesson_node_00009).
            2.  **`roberta-large`:** Selected to provide architectural diversity (Absolute Positional Embeddings vs. Relative) and different tokenization properties.
    *   **Branch B: Classical Statistical Models (Retained)**
        *   We preserve the "shallow" models that capture explicit lexical n-gram signals:
            1.  **Logistic Regression** (Sparse TF-IDF)
            2.  **Multinomial Naive Bayes** (Sparse TF-IDF)
            3.  **XGBoost** (Dense SVD-Projected) (Cite solution_lesson_node_00004).

*   **Level 2: Meta-Learner**
    *   A **Logistic Regression** model will aggregate the probability distributions from the two Neural Fusion models and the three Classical models.

## Data
The data pipeline is optimized to support the multi-modal fusion architecture while strictly adhering to signal quality standards.

*   **Text Preprocessing:**
    *   **Hybrid N-Grams:** For Branch B, we generate **Word N-grams (1-3)** and **Character N-grams (2-5)** (Cite solution_lesson_node_00001).
    *   **Noise Pruning:** We enforce **`min_df=2`** for TF-IDF to remove singleton noise (Cite solution_lesson_node_00002).
    *   **Sequence Length:** For Branch A, we set **`max_length=85`**, covering the vast majority of data without wasteful padding (Cite solution_lesson_node_00013).
*   **Stylometric Feature Engineering:**
    *   We compute a dense vector of authorship markers: punctuation density (semicolons, colons, etc.), type-token ratio, and average word/sentence lengths.
    *   **Normalization:** Crucially, these features will be scaled using **StandardScaler** (zero mean, unit variance) to ensure stable convergence when fused with the normalized transformer embeddings.
*   **Dimensionality Reduction:**
    *   **Truncated SVD** (100 components) is applied to the TF-IDF matrix for the XGBoost input (Cite solution_lesson_node_00009).

## Training
The training strategy is designed to correct previous resource allocation errors and ensure robust generalization.

*   **Cross-Validation:** We will strictly enforce **Stratified 5-Fold Cross-Validation** for *all* models, including both Large Transformers.
    *   **Strategic Correction:** We leverage the full 24-hour runtime to train the two large models sequentially. We explicitly reject reducing the fold count (e.g., to 3 folds), as maximizing the training data volume for the strong learners is prioritized over speed (Cite solution_lesson_node_00015).
*   **Neural Optimization:**
    *   **Aggressive Early Stopping:** We set **`patience=1`** for both transformers to prevent overfitting to specific folds (Cite solution_lesson_node_00010).
    *   **Batch Stability:** We use **Gradient Accumulation** to maintain an effective batch size of $\ge 16$ (Cite solution_lesson_node_00013).
*   **Artifact Caching:** All features and OOF predictions are cached using **configuration-hash filenames** to ensure reproducibility (Cite solution_lesson_node_00003).

## Evaluation
*   **Inference:** Test data is processed through the Neural Fusion pipeline (Text + Scaled Style Features) and the Classical pipeline (TF-IDF/SVD).
*   **Aggregation:** Predictions from all 5 base models are concatenated and fed to the Meta-Learner.
*   **Safety:** Final probabilities are clipped to \\([10^{-15}, 1-10^{-15}]\\).
