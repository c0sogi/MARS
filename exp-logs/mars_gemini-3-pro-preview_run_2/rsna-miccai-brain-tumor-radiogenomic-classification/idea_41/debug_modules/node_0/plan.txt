The following script demonstrates the usage of the provided library files to train a model and generate predictions for the MGMT promoter methylation task.

**Implementation Strategy:**
1.  **Configuration Patching**: Before importing the dependent modules (`data_loader`, `train_eval`), we modify the `library.config` module to set `DEBUG_DATA_LIMIT`, `MAX_EPOCHS`, and file paths. This ensures the demonstration runs quickly on a small subset of data (16 samples) and stores artifacts in a separate demo directory.
2.  **Component Verification**:
    *   **Utils**: We explicitly test `read_dicom_robust` by reading a sample DICOM file from the metadata and asserting the output dimensions match the configuration.
    *   **Data Loading**: We call `get_dataloaders` (which triggers the processing pipeline) and verify the structure and shape of the resulting batches.
    *   **Model**: We instantiate the `AsymmetricGroupedEfficientNet`, perform a forward pass with a dummy tensor, and verify the output shape.
3.  **Training & Inference**: We initialize the `Trainer` and run `fit()` for 1 epoch. We then perform inference using Test-Time Augmentation (TTA) and generate a submission file.
4.  **Final Validation**: We assert that the model checkpoint and submission file were created successfully.
