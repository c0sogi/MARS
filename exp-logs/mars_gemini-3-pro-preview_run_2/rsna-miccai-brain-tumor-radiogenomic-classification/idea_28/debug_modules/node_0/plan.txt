This script demonstrates the end-to-end usage of the provided machine learning pipeline for glioblastoma subtype prediction. It covers data loading, model instantiation, a fast training simulation using a data subset, and inference.

Strategy:
1.  **Configuration Override**: We monkey-patch the `Config` class to use temporary paths and reduced hyperparameters (fewer epochs, smaller batch size) to ensure the demo runs quickly.
2.  **Data Preparation**: We create small subsets of the provided metadata (train/val) and save them to the working directory. This allows the `run_training` function to operate on a tiny dataset.
3.  **Component Verification**:
    *   **Dataset**: We instantiate `MGMTDataset` and verify that it yields tensors of the correct shape `(12, 224, 224)` corresponding to 4 modalities $\times$ 3 slices.
    *   **Model**: We instantiate `AsymmetricEfficientNet` and perform a forward pass with dummy data to verify output shapes.
4.  **Training Simulation**: We execute `run_training()`, which uses the patched configuration to train the model on the subset and save the best checkpoint.
5.  **Inference & Submission**: We load the trained model, run inference on the validation subset, and generate a submission file in the required format.
