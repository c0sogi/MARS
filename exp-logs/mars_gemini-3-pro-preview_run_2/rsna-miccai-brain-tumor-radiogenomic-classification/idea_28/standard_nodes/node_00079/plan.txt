Implementation strategy:

1.  **Setup & Initialization**: Import necessary libraries and the provided modules (`library.config`, `library.model`, `library.data`, `library.train`, `library.utils`). Initialize the device (GPU/CPU) and load the metadata DataFrames for training and validation.
2.  **Model Training**: Instantiate the `AsymmetricEfficientNet` and the optimizer (`AdamW`). Execute the training loop for the number of epochs defined in the config. Inside the loop, perform training and validation steps, tracking the best AUC score and saving the model weights to the specified checkpoint path whenever performance improves.
3.  **Validation & Metric Reporting**: After training, reload the best model checkpoint. Compute the final AUC score on the full validation set and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**: Generate predictions for the validation set using the best model. Calculate the absolute error for each sample. Extract meta-features (specifically the `anchor_index` from the ROI cache and the number of FLAIR slices from the file system) and compute their Pearson correlation with the error magnitude to identify potential systematic biases.
5.  **Submission Generation**: Check if the final validation AUC exceeds the threshold (0.6303636363636363). If it does, load the test set metadata and create a test DataLoader. Perform inference using Test-Time Augmentation (TTA) by averaging predictions from the original image, a horizontally flipped version, and a vertically flipped version. Save the resulting probabilities to `submission.csv`.
