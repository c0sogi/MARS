The implementation strategy involves the following steps:

1.  **Setup & Reproducibility**: Initialize the environment and set random seeds using the provided `utils.seed_everything` function to ensure consistent results.
2.  **Training**: Invoke the `library.train.run_training` function. To adhere to the "fast baseline" requirement, the number of epochs is explicitly limited to 5. This ensures the pipeline completes quickly while still allowing the model to learn from the dataset.
3.  **Validation Assessment**:
    *   Reload the best model weights saved during training.
    *   Perform inference on the hold-out validation set using the `BraTSDataset` and `DataLoader`.
    *   Compute the Area Under the ROC Curve (AUC) using `sklearn.metrics.roc_auc_score` and print it exactly as required (`Final Validation Metric: <value>`).
4.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample (`|Target - Prediction|`).
    *   Extract metadata features for the validation samples, specifically the number of slices available for each MRI modality (FLAIR, T1w, T1wCE, T2w), as a proxy for data quality/quantity.
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify if specific data characteristics (e.g., fewer slices) correlate with higher prediction errors.
5.  **Submission**: Call `library.inference.generate_submission` to generate predictions for the test set and save the `submission.csv` file in the correct format.
