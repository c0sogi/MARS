The implementation strategy follows the "Dual-Scale Asymmetric EfficientNet Ensemble" design. 

1.  **Configuration & Setup**: We import the provided library modules and override specific configuration parameters (`NUM_EPOCHS=5`) to ensure the pipeline runs as a fast baseline within the time limit. Random seeds are set for reproducibility.
2.  **Data Loading**: We utilize `data_loader.get_datasets` to load the training and validation splits for both the "Texture Expert" (Stride 2) and "Context Expert" (Stride 5).
3.  **Training**: We sequentially train both expert models using `trainer.run_training_phase`. This function handles the training loop, validation monitoring, and saves the best model checkpoint based on AUC.
4.  **Validation & Ensemble**: We load the best checkpoints for both models and perform inference on the validation set. The predictions are averaged (ensemble) to compute the `Final Validation Metric` (ROC AUC).
5.  **Failure Analysis**: We calculate the absolute error of the ensemble predictions on the validation set. We then extract the slice count (volume depth) for each validation subject and calculate the correlation between this feature and the error magnitude to identify potential geometric biases.
6.  **Submission**: If the validation metric exceeds the threshold (0.63218...), we proceed to generate predictions for the test set. We use `trainer.predict_with_tta` (Test-Time Augmentation) for robust inference, ensemble the results, and save the final `submission.csv`.
