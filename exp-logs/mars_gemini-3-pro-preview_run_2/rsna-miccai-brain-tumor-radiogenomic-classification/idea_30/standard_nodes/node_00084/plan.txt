This script orchestrates the glioblastoma subtype prediction pipeline. It first ensures reproducible execution by setting random seeds. It then prepares the data by computing the Hybrid-Integral ROI cache and initializing data loaders. The model is trained using the `AsymmetricEfficientNet` architecture with a limited epoch count to serve as a fast baseline.

After training, the script evaluates the model on the hold-out validation set to compute the ROC AUC score. It performs a failure analysis by correlating prediction errors with volume depth (extracted from the ROI cache) and the ground truth labels. Finally, if the validation performance exceeds the specified threshold, it generates predictions for the test set using Test-Time Augmentation (TTA) — averaging predictions from original, horizontally flipped, and vertically flipped inputs — and saves the submission file.
