The issue is that `roc_auc_score` returns `nan` (instead of raising `ValueError`) when the validation set contains only one class and the input arrays are shaped `(N, 1)`, which `scikit-learn` interprets as multi-label classification. This `nan` value causes the model saving condition (`val_auc > best_val_auc`) to fail, resulting in a `FileNotFoundError` when the script attempts to load the non-existent model file. To fix this, I will modify `library/trainer.py` to flatten the target and prediction arrays to 1D (ensuring binary classification behavior) and explicitly check if the targets contain at least two unique classes before calculating AUC, defaulting to 0.5 if not (Cite debug_lesson_1). I will apply this fix to both `train_epoch` and `validate_epoch`.
