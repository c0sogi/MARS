The implementation strategy is as follows:

1.  **Setup and Configuration**: Import necessary modules and the provided library components. Explicitly set random seeds for reproducibility. Adjust `Config.EPOCHS` to 10 to ensure the "fast baseline" requirement is met while still allowing sufficient convergence on this small dataset.
2.  **Data Loading**: Initialize the data loaders using `get_dataloaders` with `load_cached_data=True` to leverage any existing preprocessed ROI caches.
3.  **Model Initialization**: Instantiate the `GroupedEfficientNetV2` model and move it to the appropriate device (GPU).
4.  **Training Loop**: Implement a standard training loop using the imported `train_epoch` and `validate_epoch` functions. Save the model state whenever validation AUC improves.
5.  **Final Validation**: Load the best saved model weights. Perform inference on the full validation set to compute the final AUC score. Print this metric strictly in the required format.
6.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample.
    *   Extract a structural feature (number of FLAIR slices) from the file system for each validation subject to use as a proxy for brain volume/scan complexity.
    *   Compute and print the Pearson correlation between the prediction error and this feature.
7.  **Submission**: Check if the final validation AUC exceeds the threshold (0.63218...). If so, generate the submission file using the imported `generate_submission` function, which applies Test-Time Augmentation (TTA).
