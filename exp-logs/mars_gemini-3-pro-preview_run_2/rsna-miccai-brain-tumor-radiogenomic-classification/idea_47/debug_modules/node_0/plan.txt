The following script demonstrates the usage of the provided machine learning library for the Glioblastoma classification task. It performs the following steps:

1.  **Configuration Setup**: Modifies the global `Config` to use a temporary working directory and small subsets of data for rapid execution.
2.  **Data Preparation**: Creates small subsets of the training, validation, and test metadata to ensure the demonstration completes quickly.
3.  **Component Verification**:
    *   **Image Reading**: Verifies the robust DICOM reader.
    *   **Dataset**: Verifies the `BrainTumorDataset` class, including ROI caching and data shape consistency.
    *   **Model**: Verifies the `AsymmetricEfficientNet` architecture, specifically the modified stem for 12-channel input.
4.  **Training Loop**: Executes a single training epoch and validation step using the subset data, verifying loss calculation and backpropagation.
5.  **Inference**: Runs the full prediction pipeline (including Test-Time Augmentation) on the test subset.
