The following script demonstrates the end-to-end usage of the provided library for the Glioblastoma classification task. It performs the following steps:

1.  **Setup & Configuration**: Initializes the environment and overrides default configuration parameters (e.g., epochs, batch size, file paths) to ensure the demonstration runs quickly using a small subset of the data.
2.  **Data Preparation**: Creates temporary subset CSV files in the working directory to simulate a small training and testing environment without modifying the original metadata.
3.  **Component Verification**:
    *   **Data I/O**: Verifies that DICOM files can be read and resized correctly.
    *   **Dataset**: Instantiates the `BraTSDataset`, checks the shape of the stacked 12-channel tensors, and verifies value normalization.
    *   **Model**: Instantiates the `AsymmetricEfficientNet`, performs a forward pass with dummy data, and validates the output shape.
4.  **Training Pipeline**: Executes a single-epoch training run using the `run_training` engine on the subset data.
5.  **Inference Pipeline**: Generates predictions for the test subset using the `generate_submission` engine and verifies the output format.
