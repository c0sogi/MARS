This script demonstrates the end-to-end usage of the provided machine learning pipeline for Glioblastoma subtype prediction. It verifies the data loading process, model architecture, training loop, and inference mechanism.

To ensure speed and compliance with the requirements:
1.  **Data Loading**: We instantiate the `BraTSDataset` and `DataLoader` to verify input shapes and target formats.
2.  **Model**: We instantiate the `AsymmetricEfficientNet` and perform a forward pass with a dummy batch to verify output dimensions.
3.  **Training**: We execute `run_training` with `debug=True` and `num_epochs=1`. This uses a tiny subset (32 samples) of the data, ensuring the training loop completes in seconds while still generating the necessary checkpoints.
4.  **Inference**: We run `predict_and_submit`, which loads the model trained in the previous step and generates a submission file.
5.  **Validation**: Assertions are placed throughout to confirm shapes, file existence, and data integrity.
