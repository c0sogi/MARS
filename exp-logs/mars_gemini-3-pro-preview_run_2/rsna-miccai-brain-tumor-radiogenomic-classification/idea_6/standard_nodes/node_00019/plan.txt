Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Import necessary modules and load configuration variables (`DEVICE`, `PATHS`, `HYPERPARAMETERS`) from the provided `library` files. Initialize the random seed for reproducibility.
2.  **Data Loading**: Load the pre-generated metadata CSVs for training, validation, and testing. Initialize DataLoaders using the `get_dataloader` function, ensuring `load_cached_data=True` to utilize the ROI caching mechanism.
3.  **Training**: Execute the training loop using `train_model` from `library.engine`. This handles the epoch loop, validation monitoring, early stopping, and saving the best model checkpoint.
4.  **Validation Assessment**:
    *   Load the best saved model checkpoint.
    *   Perform inference on the full validation set in evaluation mode.
    *   Calculate and print the `Final Validation Metric` (AUC) with full precision.
5.  **Failure Analysis**:
    *   Compute the absolute error between predictions and ground truth.
    *   Extract metadata features (Anchor Ratio, Slice Counts) for the validation set.
    *   Calculate and print the Pearson correlation between the error magnitude and these features to identify potential systematic biases.
6.  **Submission**:
    *   Compare the final validation AUC against the threshold (`0.6254545454545455`).
    *   If the threshold is exceeded, generate predictions for the test set using `generate_submission` and save to `submission.csv`.
