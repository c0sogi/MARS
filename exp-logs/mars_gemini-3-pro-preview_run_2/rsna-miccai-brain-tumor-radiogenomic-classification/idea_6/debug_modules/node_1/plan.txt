This `nan` value causes the model checkpointing condition (`val_auc > best_auc`) to fail, preventing the model from being saved. Consequently, the inference step attempts to load a pre-existing, stale checkpoint file with an incompatible architecture, leading to a `RuntimeError`.

1.  Modify `library/engine.py` to explicitly check if the target vector contains at least two unique classes before calculating the AUC, returning a default value (0.5) if not. This addresses the root cause identified in **Cite debug_lesson_1**.
2.  Update `runfile.py` to delete any existing model checkpoint at the start of the demo. This ensures the test validates the creation of a *new* model file and prevents loading stale artifacts.
