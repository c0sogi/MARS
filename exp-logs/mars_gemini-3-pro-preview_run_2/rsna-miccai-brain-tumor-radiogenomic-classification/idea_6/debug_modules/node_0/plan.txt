### Implementation Strategy

1.  **Configuration Override**: To ensure the demonstration runs quickly within the time limit, I will override the `NUM_EPOCHS` and `BATCH_SIZE` settings in the imported `library.config` module. This allows us to run a full training cycle on a small subset of data without modifying the source files.
2.  **Data Loading & Verification**:
    *   Load the pre-generated `train.csv` and `test.csv` metadata files.
    *   Create small subsets (e.g., 4 samples) for training, validation, and testing.
    *   Instantiate the `MGMTDataset` and `DataLoader` via `get_dataloader`.
    *   **Assertion**: Fetch a single batch to verify that the output tensor shapes match the expected dimensions `(Batch, 12, 224, 224)` and that labels are correct.
3.  **Model Instantiation & Forward Pass**:
    *   Initialize the `GroupedEfficientNet` model.
    *   **Assertion**: Pass the sample batch through the model and verify the output logits shape is `(Batch, 1)`.
4.  **Training Loop Execution**:
    *   Run the `engine.train_model` function using the subset data loaders. This demonstrates the full training pipeline, including backpropagation, validation, and checkpoint saving.
    *   **Assertion**: Verify that the `best_model.pth` checkpoint file is created in the working directory.
5.  **Inference & Submission**:
    *   Use `engine.generate_submission` with the test subset.
    *   **Assertion**: Check that the `submission.csv` file is generated and contains the correct columns and row count corresponding to the test subset.
