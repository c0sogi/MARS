The following script demonstrates the usage of the provided library components for the glioblastoma classification task. It validates the functionality of the data loading pipeline, model architecture, and training/inference loops using a small subset of the data to ensure rapid execution.

Strategies used:
1.  **Configuration Override**: Monkey-patches `library.config` to reduce batch size and epochs for the demonstration.
2.  **Data Subsetting**: Creates small DataFrames from the metadata to prevent processing the entire dataset, ensuring the `compute_roi_anchors` function runs quickly.
3.  **Component Verification**: Systematically instantiates and tests the `MGMTDataset`, `AsymmetricEfficientNet`, and utility functions, asserting shapes and types.
4.  **Training/Inference Simulation**: Manually executes `train_one_epoch` and a TTA inference loop using the subsets to verify the pipeline logic without running the full hardcoded `trainer.run_training` function (which would process all data).
