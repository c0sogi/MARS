The following script demonstrates the usage of the provided glioblastoma genetic subtype prediction library. It validates the data loading pipeline, the model architecture, the training loop, and the full inference process.

To ensure the demonstration runs quickly within the time limit, the script dynamically patches the configuration constants (Epochs, Batch Size) imported by the library modules to reduce the workload (1 epoch, small batch size). It then proceeds to verify the shapes of the input tensors, the model outputs, and the generation of a valid submission file.
