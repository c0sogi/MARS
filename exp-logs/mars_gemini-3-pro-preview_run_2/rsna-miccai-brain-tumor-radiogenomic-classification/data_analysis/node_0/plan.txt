Implementation Strategy:
1.  **Environment Setup**: Import necessary libraries (`pandas`, `numpy`, `os`, `cv2`, `sklearn`, etc.) and set random seeds for reproducibility.
2.  **Data Loading**: Load the pre-generated `metadata/train.csv` file. This ensures we only analyze the designated training split, preventing data leakage.
3.  **Target Analysis**: Calculate the distribution of the `MGMT_value` target variable to check for class imbalance.
4.  **Image Data Analysis**:
    *   Since `pydicom` is not listed in the installed packages, we will attempt to read DICOM files using `cv2` (OpenCV).
    *   We will iterate through the training set to collect metadata:
        *   **Volume Depth**: Count the number of slice files per modality folder.
        *   **File Size**: Sum the file sizes to approximate data volume.
        *   **Pixel Stats (if readable)**: If `cv2` successfully reads the DICOMs, we will sample the middle slice of each volume to calculate image dimensions (Height, Width) and pixel intensity statistics (Mean, Std).
    *   If `cv2` fails to read the DICOM format (common without specific codecs), we will gracefully fall back to reporting file system statistics (slice counts and sizes) as proxies for image dimensions/volume.
5.  **Feature Relationships**:
    *   Create a structured dataset of the extracted meta-features (e.g., `FLAIR_slice_count`, `T1w_mean_intensity`).
    *   Calculate correlations between these features and the target.
    *   Train a lightweight Random Forest classifier on these meta-features to determine if simple properties (like brain volume or scan depth) have predictive power.
    *   Identify collinear features (redundancy).
6.  **Reporting**: Output the findings in the requested format with capitalized sections and 4-decimal precision.
