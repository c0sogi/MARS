The implementation strategy is as follows:

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `set_seed` to ensure reproducibility.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. To ensure the "Fast Baseline" requirement is met within the time limit, we will override the default epoch count to **5 epochs**. This provides sufficient convergence for a baseline without exceeding the runtime budget.
3.  **Validation**:
    *   Load the best-performing model checkpoint (`best_model.pth`) saved during training.
    *   Evaluate it on the hold-out validation set using `library.data_loader` and `library.model`.
    *   Compute the **Area Under the ROC Curve (AUC)**.
    *   Print the metric in the strictly required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the absolute error for each validation sample (`|Target - Prediction|`).
    *   Extract a representative metadata feature, **FLAIR Slice Count** (volume depth), for each validation subject.
    *   Calculate the Pearson correlation between the error magnitude and the slice count to identify if tumor volume/scan depth affects performance.
5.  **Submission**:
    *   Compare the validation AUC against the strict threshold `0.6321818181818182`.
    *   If the threshold is exceeded, trigger `library.inference.generate_submission` to produce `submission.csv`.
