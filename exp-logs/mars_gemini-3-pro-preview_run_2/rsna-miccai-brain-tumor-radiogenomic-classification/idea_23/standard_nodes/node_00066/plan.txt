This script implements the end-to-end pipeline for glioblastoma subtype prediction. It orchestrates the training using the provided library, performs a detailed validation assessment including failure analysis, and generates a submission file using Test-Time Augmentation (TTA) if the performance threshold is met.

Key features:
1.  **Orchestration**: Uses `library.train.run_training` for the core training loop.
2.  **Validation**: Reloads the best saved model to compute the final AUC on the hold-out validation set.
3.  **Failure Analysis**: correlates prediction errors with metadata features (slice counts per modality) to identify potential biases or systematic failures.
4.  **Inference**: Implements TTA (Original + Horizontal Flip + Vertical Flip) for robust test set predictions.
