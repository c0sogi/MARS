Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility. Define the working directory based on the provided `Config` class.
2.  **Mini-Dataset Creation**: To satisfy the "Optimize for Speed" requirement, load the provided metadata CSVs (`train.csv`, `val.csv`, `test.csv`), sample the first 4 rows of each, and save them as "mini" datasets in the working directory.
3.  **Configuration Injection**: Monkey-patch the `Config` class attributes (`TRAIN_METADATA_PATH`, etc.) to point to these new mini-datasets. This ensures that when `library` functions are called, they process this small subset instead of the full dataset, drastically reducing runtime while still executing the full logic.
4.  **Component Verification**:
    *   **Utils**: Verify `read_dicom_robust`, `normalize_channel`, and `get_downsampled_max_anchor` by running them on a real file from the mini-dataset.
    *   **Model**: Instantiate `AsymmetricEfficientNet` and perform a forward pass with a dummy tensor to verify architecture and output shape.
5.  **Training Pipeline Integration**: Execute the `run_training` function from `library.train` with `epochs=1` and `batch_size=2`. This acts as an integration test for the dataset loading, ROI caching, and training loop.
6.  **Inference & Submission**: Load the trained model, run inference on the mini-test dataset using `get_test_dataset`, and generate a sample submission file to demonstrate the end-to-end workflow.
