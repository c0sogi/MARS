The following script demonstrates the end-to-end usage of the provided library components for the Glioblastoma genetic subtype prediction task.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes to set up a lightweight demonstration environment. This includes reducing the number of epochs to 1, setting a small batch size, limiting the dataset to 5 samples per split (`DEBUG_SAMPLE_SIZE`), and redirecting outputs to a specific demo directory.
2.  **Silence Output**: We monkey-patch `tqdm` in the `library.data` module to prevent progress bars from cluttering the output, adhering to the requirement for silent execution.
3.  **Data Pipeline Verification**: We manually invoke `get_dataloaders` to process the data and verify the structural integrity (shapes and types) of the generated tensors. This ensures the preprocessing and augmentation logic works as expected.
4.  **Model & Training Execution**: We execute the training loop via `run_training`. Since we pre-cached the data in the previous step, this runs efficiently. We verify that the model training completes and produces a `best_model.pth` file.
5.  **Inference & Submission**: We run `predict_submission` to generate predictions on the test set using the trained model. We verify the existence and format of the output CSV file.
6.  **Assertions**: Throughout the script, assertions are used to strictly validate intermediate and final results.
