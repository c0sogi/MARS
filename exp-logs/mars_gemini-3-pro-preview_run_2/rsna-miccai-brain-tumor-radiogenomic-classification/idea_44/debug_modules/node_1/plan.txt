The issue is that `roc_auc_score` returns `nan` (instead of raising `ValueError`) when the validation set contains only one class (e.g., all 0s) in the small demo dataset. Since `nan > best_val_auc` evaluates to `False`, the model checkpoint is never saved, causing the subsequent `FileNotFoundError`. The fix is to explicitly check if the target vector contains at least two unique classes before calculating the metric in both `train_one_epoch` and `validate`, defaulting to 0.5 if it does not. This addresses the root cause by ensuring a valid numeric score is returned even for single-class batches. Cite debug_lesson_1. Cite debug_lesson_2.
