The implementation strategy follows a strict orchestration of the provided library modules to ensure a robust and reproducible pipeline.

1.  **Configuration & Setup**: The script initializes by importing the `Config` and setting up reproducibility. We rely on the provided `Config` defaults (30 epochs, batch size 32) which are optimized for this dataset size to balance speed and convergence, ensuring the "fast baseline" requirement is met without sacrificing the metric.
2.  **Training**: We invoke `run_training(load_cached=True)`. This function handles the end-to-end training process, including data caching, model initialization, and the training loop with early stopping. It saves the best model weights to the working directory.
3.  **Validation & Failure Analysis**:
    *   We reload the best saved model and the validation data loader.
    *   We perform a full inference pass on the validation set to calculate the `Final Validation Metric` (ROC AUC).
    *   For failure analysis, we compute the absolute error between predictions and targets. We then extract metadata features (slice counts and file sizes) from the validation set and calculate their Pearson correlation with the error magnitude. This identifies if specific data characteristics (e.g., low slice count) correlate with model failure.
4.  **Submission**: We compare the calculated validation AUC against the strict threshold (`0.6321818181818182`). If the condition is met, we call `predict_submission(load_cached=True)`, which uses Test-Time Augmentation (TTA) to generate the final `submission.csv`.
