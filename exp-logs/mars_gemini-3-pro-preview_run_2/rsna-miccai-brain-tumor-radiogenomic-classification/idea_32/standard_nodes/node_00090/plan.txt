The implementation strategy follows the "fast baseline" requirement by orchestrating the pipeline directly within `runfile.py` rather than relying solely on the provided `train.py`, which allows for finer control over the conditional submission logic and failure analysis.

1.  **Setup & Configuration**: The script initializes the environment using the provided `library.utils` to set random seeds and detect the computing device (GPU). It utilizes the `library.data_loader` to fetch the training, validation, and test DataLoaders, ensuring `load_cached_data=True` is used to leverage pre-computed ROI caches.
2.  **Model Training**: The `AsymmetricEfficientNet` from `library.model` is initialized. A standard training loop is implemented using `AdamW` and `BCEWithLogitsLoss`. To ensure a "fast baseline," the number of epochs is set to 10 (sufficient for the small dataset size of ~400 samples without over-consuming time). The best model based on validation AUC is saved to the working directory.
3.  **Validation & Metric**: After training, the best model checkpoint is loaded. The script runs inference on the full validation set to compute the `Final Validation Metric` (AUC). This metric is printed with full precision.
4.  **Failure Analysis**: The script calculates the absolute error (`|target - probability|`) for each validation sample. It then extracts metadata features (specifically the slice counts for FLAIR, T1w, T1wCE, and T2w modalities) for the validation subjects by inspecting the file system. It computes and prints the Pearson correlation between the prediction error and these structural features to identify if scan depth relates to model failure.
5.  **Conditional Submission**: The script checks if the final validation AUC exceeds the threshold `0.6321818181818182`. If successful, it invokes `library.model.predict_and_submit` to generate the submission file using Test-Time Augmentation (TTA).
