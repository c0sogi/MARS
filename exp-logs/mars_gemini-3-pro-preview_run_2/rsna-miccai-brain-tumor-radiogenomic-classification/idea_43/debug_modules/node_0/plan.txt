### Implementation Strategy

2.  **Utility Verification**: Load the training metadata to find a valid image path. Demonstrate and verify `load_dicom_image`, `resize_image`, and `normalize_image` functions by asserting output types, shapes, and value ranges.
3.  **Data Pipeline Verification**: Instantiate the training `DataLoader` using `get_dataloader` with `debug=True`. Fetch a single batch to verify the tensor shapes of inputs (Batch, 12, 224, 224) and targets.
4.  **Model Architecture Verification**: Instantiate the `AsymmetricEfficientNet` model. Perform a forward pass with the fetched batch to confirm the output shape matches expectations (Batch, 1).
5.  **Training Loop Demonstration**: Execute `run_training(debug=True)` to demonstrate the full training pipeline, including loss calculation, backpropagation, and validation.
6.  **Inference and Submission**: Execute `generate_submission(debug=True)` to demonstrate the inference pipeline. Verify that the submission CSV is generated correctly and adheres to the required format.
