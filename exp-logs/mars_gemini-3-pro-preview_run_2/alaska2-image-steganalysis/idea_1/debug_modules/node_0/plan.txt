The following script demonstrates the usage of the provided steganalysis library. It validates the utility functions, dataset loading, model architecture, and the full training/inference pipeline using the `Trainer` class.

To ensure the demonstration runs quickly and reliably:
1.  **Configuration Overrides**: We enable `DEBUG` mode to use a small subset of the data, reduce `EPOCHS` to 1, and disable pretrained weights to avoid network overhead.
2.  **Component Verification**: We explicitly check the shapes of the SRM filters, dataset items, and model outputs using assertions.
3.  **Pipeline Execution**: We run the `Trainer.fit()` and `Trainer.predict()` methods to verify the end-to-end workflow and check for the generation of the submission file.
