The strategy is to implement a fast but effective baseline by orchestrating the provided library modules. We will then perform a rigorous validation on the hold-out set by replicating the inference pipeline (Router classification -> Alignment -> Hybrid Dispatch -> Generator/Rule Execution) and comparing against ground truth.
