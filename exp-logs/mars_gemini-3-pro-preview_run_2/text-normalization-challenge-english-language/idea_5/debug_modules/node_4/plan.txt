The `RuntimeError` is caused by an in-place modification (`+=`) of the `next_alpha` tensor, which is the output of `torch.logsumexp`. In PyTorch, the backward pass for `logsumexp` requires the original output value to compute gradients. Modifying it in-place invalidates the version of the tensor stored for backpropagation. The fix is to replace the in-place addition with an out-of-place addition (`next_alpha = next_alpha + ...`), ensuring the original tensor remains intact for the autograd engine. I will also apply this safe pattern to the final `alpha` update.
