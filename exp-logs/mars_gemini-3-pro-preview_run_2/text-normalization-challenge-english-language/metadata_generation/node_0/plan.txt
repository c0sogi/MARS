I will implement a Python script to generate metadata for the text normalization task. The script will perform the following steps:

1.  **Setup and Data Loading**:
    -   Define input paths (`./input/en_train.csv`, `./input/en_test_2.csv`) and output directory (`./metadata`).
    -   Load the training data using pandas, ensuring all text fields are read as strings (disabling default NA filtering to preserve tokens like "null" or "nan").
    -   Construct the `id` column for the training data by concatenating `sentence_id` and `token_id`.

2.  **Grouped Splitting**:
    -   Identify unique `sentence_id`s from the training data.
    -   Shuffle the unique sentence IDs with a fixed random state (`RANDOM_STATE = 42`).
    -   Split the sentence IDs into an 80% training set and a 20% validation set. This ensures that all tokens from a single sentence remain in the same split (Group Sampling), preserving context.
    -   Filter the original dataframe to create `train_df` and `val_df` based on these sentence ID sets.

3.  **Test Data Processing**:
    -   Load the test data (`en_test_2.csv`).
    -   Construct the `id` column for the test data.
    -   Prepare the test dataframe for saving.

4.  **Saving Metadata**:
    -   Save `train_df`, `val_df`, and the processed test dataframe to `./metadata/train.csv`, `./metadata/val.csv`, and `./metadata/test.csv` respectively.

5.  **Validation and Reporting**:
    -   Reload the generated metadata files to verify integrity.
    -   **Statistics**: Print the shape, number of unique sentences, and class distribution (for train/val) for each dataset.
    -   **Split Verification**: Assert that there is no overlap of `sentence_id` between the training and validation sets to confirm a successful group split.
    -   **File Path Check**: Since the dataset consists of text within CSVs and not external file paths, the file path resolution check is skipped (or implicitly passes with 0 missing files).
