This script demonstrates the end-to-end usage of the provided text normalization library. It begins by configuring the environment for a rapid demonstration (reducing dataset size, epochs, and batch sizes). It then validates the rule-based normalization logic, tests the data processing pipelines, and executes the training and inference workflows for both the Router (classification) and Generator (Seq2Seq) models. Finally, it uses the trained models to generate a submission file, verifying the output format.
