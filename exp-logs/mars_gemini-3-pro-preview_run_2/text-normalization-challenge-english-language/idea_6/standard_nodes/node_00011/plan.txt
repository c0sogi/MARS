Implementation Strategy:
1.  **Setup & Initialization**: Initialize the environment using the provided `Config` class, setting random seeds for reproducibility and detecting the computation device (GPU/CPU).
2.  **Data Loading**: Load the tokenizer (`roberta-base`) and instantiate `NormalizationDataset` for both training and validation splits. The dataset class handles cached data loading and preprocessing.
3.  **Training Optimization**: To ensure the solution runs within the "fast baseline" time limit, I will subset the training dataset to a maximum of 200,000 sentences if it exceeds that size. I will also configure the training pipeline to run for only 1 epoch.
4.  **Model Training**: Execute the training pipeline using the `run_training_pipeline` function from the `trainer` module, which manages the training loop, optimization, and checkpointing.
5.  **Validation & Metric Calculation**:
    *   Perform inference on the full validation set using the trained model.
    *   Reconstruct the normalized strings from the predicted transformation IDs using the `TransformationRegistry`.
    *   Compare predicted strings against the ground truth from the validation metadata to calculate the exact accuracy.
    *   Print the `Final Validation Metric` as required.
6.  **Failure Analysis**:
    *   Analyze the validation results to identify error patterns.
    *   Calculate and print the correlation between error occurrence and token length.
    *   Print error rates broken down by token class.
7.  **Submission Generation**: Check if the validation accuracy exceeds the specified threshold (0.9732...). If so, load the test dataset, generate predictions, and save the submission file to `./submission/submission.csv`.
