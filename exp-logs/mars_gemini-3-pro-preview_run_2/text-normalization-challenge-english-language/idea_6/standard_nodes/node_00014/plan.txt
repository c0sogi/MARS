The issue is that the Hugging Face tokenizer expects a Python `list` of strings when `is_split_into_words=True`, but the data loading process (using Pandas with PyArrow engine) results in the token sequences being stored as NumPy arrays. Passing a NumPy array to the tokenizer triggers a `ValueError`. To fix this, I will explicitly cast the retrieved sequences (`tokens`, `label_ids`, and `sub_ids`) to Python lists inside the `__getitem__` method of `NormalizationDataset`.
