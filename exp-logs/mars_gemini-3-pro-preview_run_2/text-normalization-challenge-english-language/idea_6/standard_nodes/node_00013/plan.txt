The issue is that `NormalizationDataset` fails when loading data from the cache because the `LabelEngineer` instance is not fully initialized. Specifically, `self.label_engineer.name_to_id` remains `None` when the cached data loading path is taken (skipping `process_dataset`), causing an `AttributeError` later in `_apply_sampling`.

To fix this, I will explicitly call `self.label_engineer._load_or_create_label_encoder()` in the `NormalizationDataset.__init__` method. This ensures that the label mapping is always loaded and `name_to_id` is populated, regardless of whether the dataset is loaded from cache or processed from scratch.
