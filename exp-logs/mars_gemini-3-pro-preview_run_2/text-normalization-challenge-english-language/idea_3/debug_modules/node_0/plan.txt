This script demonstrates the end-to-end usage of the provided library modules for the text normalization task. It employs a strategy of monkey-patching the configuration module to redirect file paths to a temporary demo directory and adjusting hyperparameters (like embedding dimensions and neighbor counts) to allow for rapid execution on a small synthetic dataset. The script systematically verifies the logic of normalizers, data loading (including context window generation), feature extraction (TF-IDF + SVD), and the retrieval-based KNN classifier, ensuring all components function correctly before cleaning up the temporary artifacts.
