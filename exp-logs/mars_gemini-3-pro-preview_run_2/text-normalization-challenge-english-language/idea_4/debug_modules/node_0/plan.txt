This script demonstrates the end-to-end usage of the provided text normalization library. It performs the following steps:

1.  **Configuration & Setup**: It creates a temporary directory for outputs and overrides the default `Config` paths to point to this directory. It also creates a small, consistent subset of the test data to ensure that the training and submission generation steps run quickly and that the data alignment logic holds during the demonstration.
2.  **Normalization Rules**: It instantiates the `Normalizer` class and verifies that specific rules (e.g., for money and dates) function correctly.
3.  **Dataset Handling**: It initializes the `TextNormalizationDataset` with a small `debug_size` and verifies the structure of the yielded data samples (input IDs, attention masks, labels).
4.  **Model Initialization**: It loads the `TokenClassifier` and performs a dummy forward pass to confirm the output shape of the logits.
5.  **Training & Submission**: It uses the `Trainer` class to run a short training loop (1 epoch) on the small dataset. It then generates a submission file using the aligned test subset, verifying that the output format matches the requirements.
6.  **Inference Pipeline**: It demonstrates how to load the saved model using `InferencePipeline` and generate predictions programmatically.
