I will create a Python script that generates metadata CSV files for the Kuzushiji character recognition dataset.

The script will perform the following steps:
1.  **Setup and Directory Creation**: Define input and output paths and ensure the `./metadata` directory exists.
2.  **Data Loading**: Read `train.csv` and `sample_submission.csv` from the `./input` directory.
3.  **Path Construction**: Add a `file_path` column to the dataframes. Training images are located in `./input/train_images/` and test images in `./input/test_images/`.
4.  **Group Identification**: Extract a `group_id` from the `image_id` to facilitate group-aware splitting. The `image_id` typically consists of a book identifier followed by a page number (e.g., `bookID_pageID`). Grouping by `bookID` prevents data leakage where pages from the same book appear in both training and validation sets.
5.  **Validation Split**: Use `GroupShuffleSplit` with a fixed random seed (42) to split the training data into 80% training and 20% validation sets, ensuring no book is split across sets.
6.  **Metadata Saving**: Save the resulting dataframes (`train_meta`, `val_meta`, `test_meta`) to the `./metadata` directory.
7.  **Verification**:
    -   **File Existence Check**: Randomly sample 1000 paths from each dataset and verify they resolve to actual files in the `./input` directory.
    -   **Split Verification**: Confirm the 80:20 split ratio and assert that the groups in the validation set do not overlap with the training set.
    -   **Statistics**: Print summary statistics (count, unique groups, etc.) for all datasets.
