This script demonstrates the usage of the provided Kuzushiji recognition library files. It covers:
1.  **Utils**: Verifying label mapping, ground truth parsing, and metric calculation.
2.  **Dataset**: Loading the dataset, creating subsets, and checking data transformations.
3.  **Model & Engine**: Initializing the Cascade R-CNN model, running a short training loop on a small subset, and performing inference.

To ensure compatibility with the provided `library.engine` functions (which access dataset attributes directly), a helper function `create_compatible_subset` is used to propagate necessary attributes (like `int_to_char` and `df`) from the main dataset to the PyTorch `Subset`.
