This solution evolves the architecture from a standard single-stage regressor to a multi-stage refinement pipeline while strictly retaining the data and training optimizations that have proven effective.

### Model
**Architecture: Cascade R-CNN with ResNet-50-FPN**
I propose a structural evolution from Faster R-CNN to **Cascade R-CNN**.
*   **Structural Innovation (Cascade Head):** The primary failure mode identified in early attempts was the inability to separate dense, touching cursive characters, which led to merged predictions **Cite solution_lesson_node_00001**. Standard Faster R-CNN uses a single detection head with a fixed IoU threshold (0.5), which is insufficient for this density. Cascade R-CNN introduces a sequence of three detection heads trained with increasing IoU thresholds (e.g., 0.5, 0.6, 0.7). This multi-stage architecture progressively refines the bounding boxes, effectively disentangling adjacent characters and ensuring high-quality localization for the "center point" metric.
*   **Strategic Retention (Backbone):** We explicitly retain the **ResNet-50** backbone. While deeper networks like ResNet-101 were explored, they proved detrimental to convergence and recall in this specific task due to the geometric (rather than semantic) nature of the features **Cite solution_lesson_node_00026**.
*   **Configuration:** The model will be instantiated using a configuration object to inject parameters (like anchor sizes and input limits) directly into the constructor, preventing the "silent default" errors observed with post-init attribute assignment **Cite solution_lesson_node_00015**, **Cite solution_lesson_node_00023**.

### Data
**Preprocessing & Augmentation**
1.  **Resolution Scaling:** Input images will be resized to `min_size=1024` and `max_size=2048`. This high-resolution input is critical for preserving the spatial fidelity of small characters, as evidenced by the elimination of the negative correlation between image size and performance **Cite solution_lesson_node_00005**.
2.  **Geometric Sanitization:** Ground truth bounding boxes will be explicitly clipped to image boundaries during loading. This prevents regression instability caused by the model attempting to predict coordinates outside the visible frame **Cite solution_lesson_node_00027**.
3.  **Label Encoding:** Class labels will be offset by `+1` (mapping 0-3847 to 1-3848) to strictly reserve index `0` for the background, preventing the silent suppression of the first character class **Cite solution_lesson_node_00022**.
4.  **Photometric Augmentation:** We will apply `ColorJitter` (brightness, contrast, saturation) to the training pipeline. This forces the model to learn shape-invariant features, which is essential for generalizing across different paper types and aging conditions **Cite solution_lesson_node_00020**.

### Training
**Procedure & Optimization**
1.  **Hyperparameters:** We will use a **Batch Size of 4** and a **Learning Rate of 0.005**. This adheres to the Linear Scaling Rule ($0.02 \times 4/16$) required for SGD convergence with small batches, ensuring the model does not underfit due to a conservative learning rate **Cite solution_lesson_node_00012**.
2.  **Schedule:** The training duration will be extended to **15 epochs**, with learning rate decays delayed to epochs 10 and 13. This extended schedule is necessary to allow the model to converge despite the difficulty added by the photometric augmentation **Cite solution_lesson_node_00020**.
3.  **Update Density:** By keeping the batch size small (4), we maximize the number of gradient updates per epoch, which is crucial for learning high-cardinality classification tasks **Cite solution_lesson_node_00007**.

### Evaluation
**Inference Pipeline**
1.  **RPN Uncapping:** The Region Proposal Network will be configured to keep **2,000 post-NMS proposals** (up from the default 1,000). This ensures that on pages with ~600 characters, valid candidates are not discarded before reaching the classifier **Cite solution_lesson_node_00016**.
2.  **Detection Cap:** The maximum detections per image will be set to **1,200**, overriding the library default of 100. This removes the artificial ceiling on Recall for dense pages **Cite solution_lesson_node_00008**.
3.  **Thresholding:** The final confidence threshold will be set to **0.35**. This prioritizes Recall, recovering "borderline" characters that may be partially occluded or ambiguous **Cite solution_lesson_node_00013**.
4.  **Coordinate Restoration:** We will explicitly calculate the scale factors used during the resizing step and apply the inverse transformation to the predicted bounding boxes to ensure the submitted coordinates match the original image resolution **Cite solution_lesson_node_00025**.
