The `torch.OutOfMemoryError` indicates that the GPU memory is insufficient for the `EfficientNetV2-L` model with a batch size of 16 and 480x480 resolution. To resolve this, I will implement Gradient Accumulation and Automatic Mixed Precision (AMP). This approach decouples the physical batch size (which is constrained by VRAM) from the effective batch size (which affects convergence), allowing us to reduce the physical batch size while maintaining the training dynamics (Cite debug_lesson_3, Cite debug_lesson_5).

Here are the specific changes:
1.  **`library/config.py`**: Add `ACCUMULATION_STEPS` and `USE_AMP` configuration parameters.
2.  **`library/train.py`**:
    *   Update `train_one_epoch` to use `torch.cuda.amp.autocast` for mixed precision and implement gradient accumulation logic (scaling loss, accumulating gradients, and stepping optimizer only every N steps).
    *   Update `validate_one_epoch` to use `autocast` to reduce memory usage during validation.
    *   Update `run_fold` to initialize `GradScaler` and pass it along with accumulation steps to the training loop.
3.  **`runfile.py`**: Override `Config.BATCH_SIZE` to 4 (to fit in memory) and set `Config.ACCUMULATION_STEPS` to 4 (to maintain an effective batch size of 16).

def train_one_epoch(epoch, model, loader, optimizer, criterion, device, scaler, accumulation_steps, scheduler=None):
    """
    Trains the model for one epoch using AMP and Gradient Accumulation.
    """
    model.train()
    running_loss = 0.0
    dataset_size = 0

    optimizer.zero_grad()

    for batch_idx, (images, targets) in enumerate(loader):
        images = images.to(device)
        targets = targets.to(device)
        batch_size = images.size(0)

        # Mixed Precision Forward Pass
        with amp.autocast(enabled=Config.USE_AMP):
            # In training mode, model returns a list of logits (MSD)
            outputs = model(images)

            # Calculate loss (Average across MSD heads)
            loss = 0
            for output in outputs:
                loss += criterion(output, targets)
            loss /= len(outputs)
            
            # Normalize loss for gradient accumulation
            loss = loss / accumulation_steps

        # Scaled Backward Pass
        scaler.scale(loss).backward()

        # Step Optimizer
        if (batch_idx + 1) % accumulation_steps == 0:
            # Unscale gradients for clipping
            scaler.unscale_(optimizer)
            torch.nn.utils.clip_grad_norm_(model.parameters(), Config.MAX_GRAD_NORM)
            
            # Step and Update Scaler
            scaler.step(optimizer)
            scaler.update()
            
            # Clear Gradients
            optimizer.zero_grad()

        # Scale loss back for reporting
        running_loss += loss.item() * batch_size * accumulation_steps
        dataset_size += batch_size

    avg_loss = running_loss / dataset_size
    return avg_loss
