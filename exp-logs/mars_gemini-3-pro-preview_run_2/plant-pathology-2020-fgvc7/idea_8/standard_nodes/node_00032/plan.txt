    *   After training, load the best SWA checkpoint for each model and perform inference on the validation fold.

4.  **Global Metric Calculation:** Compute the mean of the per-fold ROC AUC scores to obtain the `Final Validation Metric`.

    *   Calculate the error magnitude for each sample (Mean Absolute Error).
    *   Load image metadata (file size, dimensions) for the validation samples.
    *   Compute and print the Pearson correlation between the error magnitude and these input features.
6.  **Submission:**
    *   Compare the `Final Validation Metric` against the strict threshold (`0.9954104122251848`).
