To establish a robust and efficient baseline for apple disease detection, I propose a solution based on a standard Residual Network (ResNet) architecture. This approach prioritizes simplicity and training stability, leveraging transfer learning to handle the relatively small dataset size effectively.

### Model
The core of the solution will be a **ResNet-18** Convolutional Neural Network.
*   **Architecture**: ResNet-18 is selected for its lightweight nature and proven effectiveness in image classification tasks. It utilizes residual skip connections, which allow for the training of deep networks by mitigating the vanishing gradient problem.
*   **Transfer Learning**: We will use a version of the model pre-trained on the ImageNet dataset. This allows the model to initialize with robust feature extractors (detecting edges, textures, and patterns) rather than learning from scratch.
*   **Classification Head**: The original 1000-class fully connected layer will be replaced with a single linear layer having 4 output neurons, corresponding to the four target classes: `healthy`, `rust`, `scab`, and `multiple_diseases`.

### Data
*   **Preprocessing**: Images will be resized to **224x224** pixels to align with the standard input dimensions of the pre-trained backbone. Pixel values will be normalized using the standard ImageNet mean and standard deviation.
*   **Augmentation**: Given the small dataset size (~1300 training images), we will apply lightweight data augmentation during training to prevent overfitting. This will include **Random Horizontal Flips** and **Random Rotations** (up to 15 degrees). Validation and test images will undergo only resizing and normalization.
*   **Handling Imbalance**: The dataset is imbalanced, with "multiple_diseases" being significantly rarer (~5%) than other classes. To address this, we will compute **Class Weights** inversely proportional to the class frequencies and apply them during the loss calculation.

### Training
*   **Loss Function**: We will use **Cross-Entropy Loss** weighted by the calculated class weights. This ensures the model is penalized more heavily for misclassifying the minority class, preventing it from biasing towards the majority classes.
*   **Optimizer**: The **Adam** optimizer will be employed with an initial learning rate of 1e-4, offering faster convergence compared to standard SGD.
*   **Scheduler**: A **Cosine Annealing** learning rate scheduler will be used to gradually reduce the learning rate over the course of training (e.g., 15 epochs), helping the model settle into a stable local minimum.
*   **Validation**: The model will be evaluated on the validation set at the end of each epoch. The checkpoint achieving the highest Mean Column-wise ROC AUC will be saved as the best model.

### Evaluation
*   **Inference**: The best-saved model will be used to generate predictions on the test dataset.
*   **Post-processing**: The raw output logits from the model will be passed through a **Softmax** activation function to convert them into a probability distribution summing to 1.0 for each image.
*   **Submission**: These probabilities will be mapped to the respective columns (`healthy`, `multiple_diseases`, `rust`, `scab`) and saved in the required CSV format.
