Based on the accumulated lessons and the nature of the dataset, I propose the following optimized strategy.

### Model
I propose replacing the ResNet-50 backbone with an **EfficientNet-B4** architecture.
*   **Structural Innovation:** Unlike ResNet's fixed design, EfficientNet utilizes **Compound Scaling**, which balances network depth, width, and input resolution. This is particularly advantageous for fine-grained disease detection where the visual cues (lesions, spots) can be subtle and texture-dependent. EfficientNet-B4 is specifically optimized for higher resolution inputs (380x380), allowing it to resolve minute features that ResNet-50 (typically 224x224) might blur.
*   **Head:** The pre-trained ImageNet classifier will be replaced with a customized head consisting of Global Average Pooling, a Dropout layer (rate 0.4), and a final Linear layer with 4 outputs.

### Data
*   **Preprocessing:**
    *   **Resolution:** Input images will be resized to **380x380 pixels**. This higher resolution leverages the native capacity of the EfficientNet-B4 backbone to detect small, localized disease indicators.
    *   **Normalization:** Standard ImageNet mean and standard deviation will be applied.
*   **Augmentation:**
    *   **Information Dropping:** We will explicitly preserve the successful **CoarseDropout** strategy. We will apply large occlusion regions (e.g., up to 100x100 pixels for the 380x380 image size) to force distributed feature learning `Cite solution_lesson_node_00006`. We will also strictly enforce minimum hole dimensions (e.g., min 16x16) to prevent trivial occlusions `Cite solution_lesson_node_00005`.
    *   **Photometric Constraints:** We will continue to exclude global photometric distortions (Brightness/Contrast) to avoid altering the color-specific semantics of the diseases `Cite solution_lesson_node_00004`.

### Training
*   **Loss Function:** To handle the class imbalance and metric requirements, we will use **Cross-Entropy Loss** weighted by the inverse class frequencies `Cite solution_lesson_node_00001`.
*   **Regularization:** We will integrate **Label Smoothing (0.1)** into the loss function to prevent overconfidence and improve generalization, which is critical when increasing model capacity `Cite solution_lesson_node_00002`.
*   **Optimizer:** We will use the **AdamW** optimizer, which decouples weight decay from gradient updates, typically yielding better convergence for EfficientNet architectures.
*   **Scheduler:** A **Cosine Annealing** scheduler will be used to smoothly decay the learning rate over 15-20 epochs.

### Evaluation
*   **Inference:** We will employ **Test Time Augmentation (TTA)**, specifically averaging predictions from the original image and a horizontally flipped version, to further boost robustness `Cite solution_lesson_node_00002`.
*   **Metric:** The model will be validated using the Mean Column-wise ROC AUC to align with the competition metric.
