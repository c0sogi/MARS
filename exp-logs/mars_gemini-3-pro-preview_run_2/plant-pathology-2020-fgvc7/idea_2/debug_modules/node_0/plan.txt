The following script demonstrates the end-to-end usage of the provided library for the Apple Disease Detection task.

**Implementation Strategy:**
1.  **Configuration Setup**: We first import the `Config` class and override specific parameters (enabling debug mode, reducing epochs, batch size, and disabling heavy pre-trained weight downloads) to ensure the demonstration runs rapidly within the environment limits.
2.  **Data Loading Verification**: We utilize `get_loaders` to instantiate data loaders and fetch a single batch. We assert the correctness of tensor shapes and data types to verify the data pipeline.
3.  **Model Verification**: We instantiate the `AppleEfficientNet` model and perform a forward pass with the fetched batch, verifying that the output logits have the expected dimensions `(Batch_Size, Num_Classes)`.
4.  **Training Simulation**: We execute `run_training()`. Due to the modified configuration, this runs a single epoch on a small subset of data, testing the loss calculation, backpropagation, and model saving mechanisms.
5.  **Inference Simulation**: We execute `run_inference()`, which loads the model saved in the previous step and generates predictions on the test set. We verify the format and structure of the generated submission file.
6.  **Metric Verification**: We independently test the `calculate_metric` function with synthetic data to ensure the evaluation metric (Mean Column-wise ROC AUC) is computed correctly.
