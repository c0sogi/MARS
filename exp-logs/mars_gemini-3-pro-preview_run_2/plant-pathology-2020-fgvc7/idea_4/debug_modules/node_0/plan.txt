This script demonstrates the usage of the provided library modules for the Apple Disease Detection task. It performs a series of unit tests to verify the functionality of the Dataset, Model, Loss, and Metric components, followed by an integration test that executes a complete training and inference pipeline using a small subset of the data.

The strategy includes:
1.  **Environment Setup**: Setting random seeds for reproducibility.
2.  **Component Verification**:
    *   **Dataset**: Instantiating `AppleDataset` with a small metadata subset to verify image loading, transformation, and label shapes.
    *   **Model**: Initializing `AppleClassifier` (EfficientNet-B5 based) and performing a forward pass with dummy data to verify output dimensions.
    *   **Loss**: Testing `WeightedLabelSmoothCrossEntropy` with dummy logits and targets.
    *   **Metric**: Verifying `calculate_metric` (ROC AUC) with synthetic predictions and ground truth.
3.  **Pipeline Execution**: Running `run_training` with `debug=True` and `epochs=1`. This utilizes the `Config`, `get_dataloaders`, and training loops defined in the library to train on a small subset, save the best model, perform inference, and generate a submission file.
4.  **Output Verification**: Asserting that the submission file is created correctly.
