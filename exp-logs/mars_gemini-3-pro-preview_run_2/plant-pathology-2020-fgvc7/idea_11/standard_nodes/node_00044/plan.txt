This script implements the complete orchestration pipeline for the Apple Disease Detection task. It configures the system for a fast baseline execution by enabling debug mode (subsampling data) and reducing training epochs. It then executes the training of the heterogeneous ensemble (EfficientNetV2-L and ConvNeXt-Base), performs inference on the validation set to compute the Mean Column-wise ROC AUC, conducts a failure analysis by correlating errors with image metadata, and conditionally runs the final inference pipeline if the performance threshold is met.
