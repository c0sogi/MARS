# Model
I propose a **Heterogeneous Ensemble** consisting of two high-capacity backbones: **EfficientNetV2-L** and **ConvNeXt-Base**.
-   **Structural Innovation (GeM Pooling):** I will replace the standard Global Average Pooling (GAP) layer in both backbones with **Generalized Mean (GeM) Pooling**. Standard GAP dilutes the signal of small, localized disease spots (like rust pustules) by averaging them with the healthy leaf background. GeM Pooling introduces a learnable parameter to focus on high-activation regions (the lesions), structurally aligning the network with the fine-grained nature of the pathology `Cite solution_lesson_node_00006`.
-   **Structural Innovation (Multi-Sample Dropout):** To address the overfitting risks on this small dataset, I will implement **Multi-Sample Dropout** in the classification head. Instead of a single dropout path, the features will pass through multiple parallel dropout layers with different masks, accelerating convergence and improving generalization.
-   **Head Design (Multi-Label Decomposition):** Both models will utilize the **Multi-Label Decomposition** strategy, outputting 2 binary logits ("Is Rust" and "Is Scab"). This allows the model to learn shared representations for the "Multiple Diseases" class (which is the intersection of Rust and Scab) rather than treating it as a disjoint minority class `Cite solution_lesson_node_00020`.

-   **Convergence Mandate:** Addressing the failure of previous ensembles `Cite solution_lesson_node_00043`, we will allocate sufficient runtime to train each fold for **20 epochs**, ensuring full convergence before ensembling.
-   **Optimization:**
    -   **Stochastic Weight Averaging (SWA):** We will implement SWA in the final epochs of training. By averaging the weights of the model across multiple points in the optimization trajectory, SWA finds a flatter minimum in the loss landscape, significantly improving stability and calibration `Cite solution_lesson_node_00014`.

# Evaluation
-   **Inference:** We will apply **Test Time Augmentation (TTA)** (horizontal flip) for all 10 base models (5 folds $\times$ 2 architectures) `Cite solution_lesson_node_00002`.
-   **Structural Innovation (Rank-Calibrated Averaging):** To resolve the **calibration drift** that degraded previous cross-validation attempts `Cite solution_lesson_node_00030`, we will implement **Rank Averaging**:
    1.  Convert the raw probability predictions of each model to **percentile ranks** (0-1) on the test set.
    2.  Compute the arithmetic mean of these ranks across all 10 models.
    3.  This ensures that fold-specific calibration biases do not disrupt the global ordering required for the ROC AUC metric.
-   **Reconstruction:** The final aggregated rank scores for "Rust" ($S_r$) and "Scab" ($S_s$) will be mapped to the 4-class format:
    -   `Healthy`: $(1 - S_r)(1 - S_s)$
    -   `Rust`: $S_r(1 - S_s)$
    -   `Scab`: $(1 - S_r)S_s$
    -   `Multiple`: $S_r S_s$
