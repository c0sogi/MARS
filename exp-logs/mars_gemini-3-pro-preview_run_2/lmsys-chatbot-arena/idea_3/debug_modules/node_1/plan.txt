The issue is that the `eps` parameter in `sklearn.metrics.log_loss` has been deprecated and removed in recent versions of scikit-learn (specifically version 1.5+), but the code attempts to use `eps="auto"`. To fix this while maintaining the intended functionality, I will modify `library/utils.py` to manually clip the predicted probabilities using the machine epsilon of the data type before passing them to `log_loss`.
