**Implementation Strategy**

The following script demonstrates the end-to-end usage of the provided 3D object detection library. The implementation is structured as follows:

1.  **Configuration & Setup**: We initialize the environment and set random seeds using `Config.set_seed` to ensure reproducibility.
2.  **Utility Verification**: We validate core geometric functions in `library.utils`, specifically ensuring that quaternion-euler conversions and IoU calculations perform as expected mathematically.
3.  **Dataset Inspection**: We instantiate the `LidarDataset` (in training mode) to verify data loading, preprocessing (rasterization), and target generation. We assert that the output tensor shapes match the configuration (BEV input size and YOLO target grid size).
4.  **Model & Loss Forward Pass**: We instantiate the `BevYolo` model and `YoloLoss`. We run a forward pass with a single batch of data derived from the dataset step to confirm the model architecture is valid and the loss function computes gradients without error.
5.  **Training Loop Demonstration**: We utilize the `train_model` function with `debug=True`. This triggers a training run on a tiny subset of the data for a single epoch, ensuring the training pipeline (optimizer, backpropagation, logging, checkpointing) functions correctly without consuming excessive time.
6.  **Inference & Submission**: Instead of running inference on the entire test set (which would take too long), we manually instantiate the `Predictor` and run a prediction step on a small subset of the test data. We verify that the output can be decoded into the required submission string format.
