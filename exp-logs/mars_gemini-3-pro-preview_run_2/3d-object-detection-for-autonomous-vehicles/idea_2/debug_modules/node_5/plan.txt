The `ValueError` in `library/model.py` occurs because the XGBoost classifier expects contiguous class labels starting from 0 (e.g., `0, 1, 2`), but the training data contains raw class IDs which are discontinuous (e.g., `0, 2, 9`). The `ClusterClassifier` initializes a `LabelEncoder` (`self.le`) but fails to use it to encode the targets in the `fit` method before passing them to the model.

To fix this, I will update `library/model.py` to:
1.  Fit and transform the training labels (`y_clf_train`) using `self.le` before training the classifier.
2.  Transform the validation labels (`y_clf_val`) using the fitted encoder to ensure consistency in evaluation metrics.
3.  Update the regression training logic to use the *encoded* background class ID when filtering out background samples, as `self.bg_class_id` (raw ID 9) will no longer match the encoded labels (Cite debug_lesson_4).
