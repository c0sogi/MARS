The implementation strategy involves a sequential demonstration of the provided library components, moving from low-level utilities to high-level pipeline execution.

1.  **Configuration & Setup**: First, we will override specific settings in `library.config.Config` to ensure the script runs quickly. This includes setting a small `DEBUG_SAMPLE_SIZE`, reducing the number of estimators for XGBoost, and redirecting the working directory to a demo-specific folder.
2.  **Utility Verification**: We will instantiate `CalibrationRegistry` to verify it can load sensor calibration data. We will also test geometric functions like `box_iou_3d` and coordinate transformations using synthetic data to assert correctness.
3.  **Data Processing**: We will demonstrate `PointCloudProcessor` and `FeatureExtractor` using synthetic point cloud data. This ensures the logic for ROI filtering, ground removal, clustering, and feature extraction works as expected without relying on external files initially.
4.  **Dataset Generation**: We will invoke `create_training_dataset` on a tiny subset of the actual training metadata (controlled by the debug config) to verify it produces a valid Pandas DataFrame with the expected features and targets.
5.  **Model Training**: We will use the `Trainer` class to run a full training cycle on the generated subset. We will verify that the model is trained and saved successfully.
6.  **Inference**: Finally, we will use the `InferencePipeline` to generate predictions on a small subset of the test data, verifying that a submission file is created in the correct format.
