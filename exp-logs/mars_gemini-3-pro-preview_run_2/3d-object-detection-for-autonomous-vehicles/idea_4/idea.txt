### Idea 4: Monocular Anchor-Free 3D Detector

I propose a **Monocular Anchor-Free 3D Detector**, a purely image-based approach that establishes a performance baseline using only the camera data. This method is strictly distinct from the LiDAR-centric approaches (Pillars, Clustering, Rasterization) proposed in the previous ideas. It prioritizes speed and architectural simplicity by leveraging standard 2D Convolutional Neural Networks (CNNs) without the need for complex 3D point cloud processing or sparse convolutions.

#### Model
The architecture is a single-stage, anchor-free network derived from **Model 4** in the provided architectures list. It treats 3D detection as a 2D keypoint estimation problem with attribute regression.

1.  **Backbone**: A lightweight, standard 2D CNN (e.g., **ResNet-34** or **DLA-34**) processes the input RGB image to extract semantic features.
2.  **Neck**: Up-sampling layers (using Deconvolution or Bilinear Interpolation) increase the spatial resolution of the feature map (typically to $1/4$ of the input resolution) to ensure precise localization.
3.  **Dense Detection Heads**: Multiple parallel convolutional branches operate on the high-resolution feature map. For every pixel location $(u, v)$, the network predicts:
    *   **Center Heatmap**: A probability score indicating if the pixel corresponds to the projected 2D center of a 3D object.
    *   **Depth**: The absolute depth ($z$) of the object center in the camera coordinate frame.
    *   **Dimensions**: The 3D extent of the object (height, width, length).
    *   **Orientation**: The local observation angle (e.g., encoded as $\sin \alpha, \cos \alpha$).
    *   **2D Offset**: A local correction vector to recover the discretization error caused by the output stride.

#### Data
Data preparation focuses on projecting the 3D ground truth into the 2D image plane to generate training targets.

1.  **Projection**: For each sample, load the 6 camera images and the corresponding 3D ground truth boxes. Use the camera intrinsic and extrinsic matrices to project the 3D center $(x, y, z)$ of each ground truth box onto the 2D image plane $(u, v)$.
2.  **Filtering**: Discard objects that project outside the image boundaries or are located behind the camera plane ($z < 0$).
3.  **Heatmap Generation**: Create a ground truth heatmap where each object center is represented by a 2D Gaussian kernel. The radius of the kernel is determined by the 2D size of the projected bounding box, ensuring the penalty for near-misses is adaptive to object size.
4.  **Attribute Targets**: Assign the ground truth depth, dimensions, and orientation values to the pixel location of the object center.

#### Training
The training procedure optimizes the 2D localization and 3D attribute regression simultaneously.

*   **Loss Function**: A multi-task loss combines:
    *   **Penalty-Reduced Focal Loss**: Applied to the heatmap output to handle the class imbalance between the few object centers and the vast background.
    *   **L1 Loss**: Applied to the regression heads (Depth, Dimensions, Orientation, Offset) but only at the ground truth center locations.
*   **Optimizer**: Use **Adam** with a standard learning rate schedule.
*   **Strategy**: Since the model operates on single images, the batch size can be large, and standard 2D image augmentations (color jitter, random contrast) can be applied to improve robustness.

#### Evaluation
The evaluation pipeline generates 3D predictions by "lifting" the 2D detections back into 3D space.

1.  **Inference**: Run the model on all 6 camera images for a given sample.
2.  **Peak Extraction**: Apply a $3 \times 3$ max-pooling operation on the predicted heatmap to find local maxima (peaks). Select the top $K$ peaks with scores above a confidence threshold.
3.  **3D Reconstruction**: For each detected peak at pixel $(u, v)$:
    *   Retrieve the predicted depth $z_{pred}$, dimensions, and orientation.
    *   **Back-Projection**: Calculate the 3D coordinates in the camera frame using the camera intrinsics $(c_u, c_v, f_x, f_y)$:
        $$x = \frac{(u - c_u) \times z_{pred}}{f_x}, \quad y = \frac{(v - c_v) \times z_{pred}}{f_y}, \quad z = z_{pred}$$
4.  **Coordinate Transformation**: Transform the reconstructed 3D bounding boxes from their respective **Camera Coordinate Frames** to the **Ego-Vehicle Frame**, and finally to the **Global World Frame** using the provided calibration data.
5.  **Submission**: Concatenate predictions from all 6 cameras and format them into the required prediction string.
