Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and prepare the `Config` class.
2.  **Training**: Execute the training loop using `library.train.train_model`. I will limit training to 5 epochs to ensure the process completes quickly (within ~30-45 minutes) while providing a sufficient baseline.
3.  **Validation & Metric Calculation**:
    *   Load the trained model and the validation dataset.
    *   Iterate through the validation set, performing inference to generate 3D bounding box predictions.
    *   Implement the specific 3D IoU calculation (Ground BBox Intersection $\times$ Height Intersection / Union Volume) using OpenCV for rotated rectangle intersection.
    *   Compute the Mean Average Precision (mAP) across IoU thresholds (0.5 to 0.95) as specified in the task.
    *   Print the `Final Validation Metric`.
4.  **Failure Analysis**:
    *   During validation, collect data on True Positive matches (IoU > 0.5).
    *   Calculate error metrics (Euclidean distance error).
    *   Compute and print correlations between error magnitude and object attributes (Depth, Volume) to identify weak points.
5.  **Submission**: Use the provided `library.inference.generate_submission` function to run inference on the test set and generate the `submission.csv` file.
