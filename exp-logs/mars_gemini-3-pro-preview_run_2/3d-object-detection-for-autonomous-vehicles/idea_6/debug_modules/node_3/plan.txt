When `curr_sd_token` is `None` (fallback path), these variables remain undefined, causing an `UnboundLocalError`. To fix this, I will initialize these variables to `None` in the fallback block and explicitly check that they are not `None` before performing coordinate transformations. This ensures the code handles missing pose data gracefully without crashing, addressing the "silent failure" in data processing flow. Cite debug_lesson_1.
