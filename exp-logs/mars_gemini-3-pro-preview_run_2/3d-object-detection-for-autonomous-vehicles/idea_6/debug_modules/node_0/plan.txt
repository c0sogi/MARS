The following script demonstrates the usage of the provided 3D object detection library. It covers the following steps:
1.  **Configuration**: Overrides default configuration parameters (epochs, batch size, debug limits) to ensure the demonstration runs quickly and efficiently.
2.  **Dataset**: Instantiates the `NuScenesDataset`, verifies the structure of the returned samples, and tests the custom collation function.
3.  **Model**: Instantiates the `PillarUNet3D` model, performs a forward pass with a dummy batch, and verifies the output shapes of the heatmap and regression heads.
4.  **Loss**: Computes the `CenterPointLoss` using the model's predictions and the ground truth targets, ensuring the loss is a valid scalar.
5.  **Training**: Executes a minimal training loop (1 epoch on a tiny subset) using `train_model` to verify the training pipeline and checkpoint generation.
6.  **Inference**: Runs the `generate_submission` function using the generated checkpoint to produce a submission CSV, verifying the output format.
7.  **Utilities**: Validates helper functions for coordinate transformations.
