The error is caused by variable name shadowing: the variable `z` is initially assigned the tensor of height predictions for the batch, but inside the loop processing each sample, `z` is repurposed to hold a scalar z-coordinate during string formatting. When the loop proceeds to the next sample, it attempts to index `z` (now a scalar float) as if it were the original tensor, causing an `IndexError`. To fix this, I will rename the height prediction tensor to `z_pred` in both `library/inference.py` and `library/runner.py` to distinguish it from the scalar coordinate variable.
