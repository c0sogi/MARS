The `ValueError: DataFrame index must be unique for orient='index'` occurs because the `ego_pose.json` (and potentially `calibrated_sensor.json`) data contains duplicate entries for the `token` field. When `set_index("token")` is called, these duplicates create a non-unique index, which `to_dict("index")` explicitly forbids. To fix this, I will remove duplicate records based on the `token` column using `drop_duplicates` before creating the lookup dictionaries. This ensures the index is unique, preventing the crash while maintaining the integrity of the lookup table (Cite debug_lesson_3).
