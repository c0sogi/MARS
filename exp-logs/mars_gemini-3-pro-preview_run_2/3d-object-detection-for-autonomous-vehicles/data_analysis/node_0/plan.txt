The strategy involves loading the pre-generated training metadata to perform a comprehensive Exploratory Data Analysis (EDA) on the 3D object detection dataset. The analysis will be divided into three main components: Target Variable Analysis, Input Data Analysis (Images and LiDAR), and Feature Relationships.

1.  **Target Variable Analysis**: We will parse the JSON annotations to extract bounding box properties. We will analyze the distribution of object classes to identify imbalances and calculate descriptive statistics (mean, std, min, max) for bounding box dimensions (width, length, height) and spatial coordinates.
2.  **Input Data Analysis**:
    *   **Images**: We will sample a subset of images to calculate the distribution of dimensions (width, height) and estimate global pixel mean and standard deviation for normalization purposes.
    *   **LiDAR**: We will sample a subset of LiDAR point cloud files (`.bin`) to analyze point density (points per scan) and spatial coverage (min/max coordinates), assuming a standard float32 binary format.
3.  **Feature Relationships**: We will investigate correlations between object attributes, such as the relationship between distance from the ego-vehicle and object size, and analyze the distribution of object counts per scene.

The script will be implemented in a single file, using efficient sampling where necessary to adhere to the time limit, and will output the results in the specified format.
