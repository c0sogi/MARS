Pandas' `.iloc` indexer strictly requires native Python integers and fails with tensors. To fix this, I will modify `library/dataset.py` to explicitly cast the index `idx` to an integer using `int(idx)` before accessing the dataframe, ensuring compatibility regardless of the input type (integer or tensor).
