The implementation strategy involves orchestrating the dual-stream pipeline defined in the library files. 

1.  **Initialization**: Set random seeds for reproducibility and load the global configuration.
2.  **Data Loading**: Retrieve the raw validation dataframe to extract ground truth labels (`y_val`) for final evaluation.
3.  **Model Execution**:
    *   **Stream A (Random Forest)**: Initialize and run the `RandomForestStream`. This handles feature loading (Tabular + TF-IDF), imputation, training, and inference internally.
    *   **Stream B (MLP)**: Initialize and run the `MLPStream`. This handles SBERT embedding generation/loading, metadata preprocessing, training with early stopping, and inference.
4.  **Ensemble**: Compute the weighted average of probabilities from both streams (0.5/0.5 split).
5.  **Evaluation**: Calculate the ROC AUC score on the validation set and print it in the required format.
6.  **Failure Analysis**: Compute the absolute error on the validation set and correlate it with the interpretable tabular features (Metadata + Target Encodings) to identify sources of error.
7.  **Submission**: If the validation AUC exceeds the specified threshold, generate the `submission.csv` file using the test set predictions.
