The following implementation demonstrates how to instantiate and use the provided library modules to solve the "Random Acts of Pizza" task.

**Strategy:**
1.  **Setup & Configuration**: We import the library modules and override specific configuration parameters (e.g., reducing Random Forest estimators and MLP epochs) to ensure the script runs quickly within the demonstration context.
2.  **Data Loading**: We explicitly call `data_loader` to load the metadata CSVs, verifying that the data is correctly loaded and parsed (e.g., list columns).
3.  **Feature Engineering**: We invoke `feature_engineering` to generate metadata and target-encoded features. We force `load_cached_data=False` initially to demonstrate the generation logic and populate the cache.
4.  **Text Processing**: We run `text_processing` pipelines (TF-IDF and SBERT) to generate text embeddings, again populating the cache.
5.  **Model Execution**: We instantiate and run both the `RandomForestStream` and `MLPStream`. These streams are configured to load the pre-computed features from the cache (`load_cached_data=True`) for efficiency.
6.  **Ensembling & Submission**: Finally, we combine the predictions from both models using the weights defined in the config and generate the final submission CSV.
