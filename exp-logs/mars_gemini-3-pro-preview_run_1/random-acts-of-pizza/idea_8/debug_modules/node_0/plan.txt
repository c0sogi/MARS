The following script demonstrates the usage of the provided library files to build a complete pizza request success prediction pipeline.

**Implementation Strategy:**
1.  **Setup & Configuration Override**: We first define a temporary working directory and create small subsets (50 training samples, 20 validation/test samples) of the original metadata. We then monkey-patch the `Config` class attributes to point to these subsets and reduce model hyperparameters (e.g., fewer epochs, smaller batch sizes) to ensure the script runs quickly (under 1 minute).
2.  **Utility Verification**: We demonstrate `load_data` and `get_common_columns` from `library.utils` to ensure data consistency.
3.  **Feature Engineering**: We instantiate `FeaturePipeline` from `library.feature_engineering` to process the raw text and tabular data into features suitable for Random Forest (TF-IDF + Imputed Metadata) and MLP (SBERT Embeddings + Scaled Metadata).
4.  **Model Training**:
    *   We use `train_random_forest` from `library.trainers` to train a baseline model.
    *   We use `train_neural_net` from `library.trainers` to train the custom `GatedFusionMLP` architecture defined in `library.architectures`.
5.  **Ensembling & Submission**: We combine predictions using `predict_ensemble` and save the results using `save_submission`.
6.  **Validation**: Throughout the script, assertions are used to verify data shapes, prediction outputs, and file existence.
