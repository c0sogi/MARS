The strategy is to load the raw JSON datasets from the `./input` directory, convert them into Pandas DataFrames, and then split the training data into a training set and a validation set using an 80:20 ratio with stratified sampling to preserve the class distribution of the target variable `requester_received_pizza`. We will add a `source_file` column to each dataset containing the relative path to the original JSON file to satisfy the file path tracking requirement. Finally, the processed DataFrames will be saved as CSV files in the `./metadata` directory, followed by a rigorous verification step that reloads these files to check for data integrity, correct split ratios, stratification accuracy, and file path validity.
