I will implement the `runfile.py` script to orchestrate the training and evaluation of the hybrid ensemble model (Random Forest + Hierarchical Gated MLP). The script will execute the following steps:

1.  **Initialization**: Set random seeds for reproducibility and import necessary modules from the `library` package.
2.  **Model Training**:
    *   **Stream A (Random Forest)**: Execute `model_rf.train_rf_model()` to train the action-profiled Random Forest.
    *   **Stream B (MLP)**: Execute `model_mlp.train_mlp_model()` to train the Hierarchical Reliability-Gated MLP.
3.  **Ensemble**: Combine the probability predictions from both models using a weighted average (0.5/0.5) on both validation and test sets.
4.  **Evaluation**: Calculate and print the final ROC AUC score on the validation set.
5.  **Failure Analysis**: Compute the absolute prediction errors on the validation set and calculate their correlation with numerical features to identify sources of error.
6.  **Submission**: If the validation AUC exceeds the specified threshold, generate the submission file `submission.csv` with the ensemble predictions for the test set.
