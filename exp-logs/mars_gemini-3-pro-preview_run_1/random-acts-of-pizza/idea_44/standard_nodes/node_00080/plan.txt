The solution orchestrates the hybrid ensemble of an Interaction-Enhanced Random Forest and an Orthogonal Skip-Gated MLP.

**Implementation Strategy:**
1.  **Initialization**: Set up the environment, suppress warnings, and ensure reproducibility via fixed seeds.
2.  **Feature Pipeline**: Instantiate the `FeatureEngineer` to load data and generate features (TF-IDF, SBERT embeddings, Metadata, Interactions). It utilizes caching to speed up execution.
3.  **Data Preparation**: Create PyTorch DataLoaders for the MLP stream using the processed features.
4.  **Stream A (Random Forest)**: Execute the `RFPipeline` to train the tree-based model and generate validation/test probabilities.
5.  **Stream B (MLP)**: Execute the `MLPEngine` to train the neural network with early stopping and generate validation/test probabilities.
6.  **Ensemble**: Combine the predictions from both streams using a weighted average (defined in Config) to produce the final validation scores.
7.  **Validation & Analysis**:
    *   Compute the ROC AUC on the validation set and print it with full precision.
    *   Perform failure analysis by correlating the prediction errors with key numerical metadata features to identify weaknesses.
8.  **Submission**: If the validation AUC exceeds the specified threshold, generate the final submission CSV for the test set.
