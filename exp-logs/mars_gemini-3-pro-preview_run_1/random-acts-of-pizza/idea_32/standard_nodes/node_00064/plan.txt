The implementation strategy involves the following steps:

1.  **Initialization**: Set the random seed for reproducibility using the provided `seed_everything` utility.
2.  **Data Processing**: Initialize the `FeatureEngineer` and execute the `process_data` pipeline. This will load the metadata, generate TF-IDF and SBERT embeddings, compute semantic scores, and prepare the sparse/dense feature matrices for the Random Forest and MLP models. We enable caching to speed up subsequent runs if applicable.
3.  **Model Training**:
    *   Train the **Random Forest** model using `train_rf_model`. This uses the sparse TF-IDF and dense metadata features.
    *   Train the **Dual-Query Gated MLP** using `train_mlp_model`. This utilizes the SBERT embeddings, history sequences, and metadata with the custom `PizzaDataset` and `DataLoader`.
4.  **Validation & Evaluation**:
    *   Generate ensemble predictions on the validation set using `predict_ensemble` (averaging RF and MLP outputs).
    *   Compute the **ROC AUC** score.
    *   Print the metric in the exact required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Compute the absolute error (`|y_true - y_pred|`) for the validation set.
    *   Load the raw validation dataframe to access interpretable features.
    *   Calculate Pearson correlations between the error and numerical features to identify sources of difficulty.
    *   Print the top correlations.
6.  **Submission**:
    *   Check if the validation AUC exceeds the threshold `0.7056961514236341`.
    *   If successful, generate ensemble predictions for the test set.
    *   Load the test dataframe to retrieve `request_id`s.
    *   Save the submission file using `save_submission`.
