Implementation strategy:
1.  **Configuration Override**: Before importing the core logic, I will monkey-patch `library.config` to reduce the number of Random Forest estimators (to 100) and MLP epochs (to 15). This ensures the "Fast Baseline" requirement is met without modifying the provided library files directly.
2.  **Pipeline Orchestration**: I will use the `FeaturePipeline` to load and process data (leveraging caching), then train both the Random Forest (Stream A) and MLP (Stream B) using the `train_rf` and `train_mlp` functions from the library.
3.  **Validation & Metrics**: I will perform inference on the validation set using both models, ensemble their predictions, and compute the ROC AUC score. This score will be printed strictly as `Final Validation Metric: <value>`.
4.  **Failure Analysis**: I will calculate the absolute error of the predictions on the validation set and correlate these errors with the numeric metadata features (loaded from `val.csv`) to identify systematic failure modes.
5.  **Conditional Submission**: I will check if the validation AUC exceeds the specified threshold (0.7135451153926904). If it does, I will generate predictions for the test set, create the submission dataframe, and save it to `submission/submission.csv`.
