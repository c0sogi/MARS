This script demonstrates the end-to-end execution of the hybrid ensemble solution for the Random Acts of Pizza task. It performs the following steps:
1.  **Configuration**: Overrides default hyperparameters (epochs, estimators) to ensure the demonstration runs quickly.
2.  **Feature Engineering**: Runs the complete feature generation pipeline (`run_feature_engineering`), which computes SBERT embeddings, processes user history, and generates tabular metadata features for both the Random Forest and MLP streams.
3.  **Random Forest Stream**: Trains a Random Forest classifier on the generated sparse features and evaluates it on the validation set.
4.  **MLP Stream**: Initializes DataLoaders, trains the custom `PizzaNet` architecture (with dual-query attention and skip-gated fusion), and evaluates it.
5.  **Ensemble & Submission**: Combines predictions from both models using weighted averaging, generates final test predictions, and saves the submission file.
