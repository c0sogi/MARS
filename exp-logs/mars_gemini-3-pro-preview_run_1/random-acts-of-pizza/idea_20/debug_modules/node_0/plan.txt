This script demonstrates the end-to-end usage of the provided library modules for the Random Acts of Pizza prediction task. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration parameters (enabling `DEBUG` mode, reducing epochs, batch sizes, and estimator counts) to ensure the demonstration runs quickly and efficiently.
2.  **Data Loading**: Uses `load_dataset` to load a small subset (50 rows) of the training, validation, and test data, verifying the parsing of list columns.
3.  **Feature Engineering**: Instantiates the `FeatureProcessor` to generate dense (SBERT embeddings, metadata) and sparse (TF-IDF) features. It asserts the correctness of the output data structures and shapes.
4.  **Random Forest Workflow**: Initializes the `RFWrapper`, trains it on the processed features, generates predictions, and verifies the save/load functionality.
5.  **MLP Workflow**: Manually initializes the `PizzaDataset` and `MLPTrainer`, runs a single epoch of training, evaluates the model, and verifies prediction outputs and model persistence.
