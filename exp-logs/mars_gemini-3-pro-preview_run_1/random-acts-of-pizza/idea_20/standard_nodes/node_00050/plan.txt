The implementation strategy involves the following steps:

1.  **Setup and Configuration**: Import necessary modules and the provided library files. Override the default configuration for `EPOCHS` and `RF_ESTIMATORS` to ensure the script runs quickly as a baseline (10 epochs, 100 estimators). Set random seeds for reproducibility.
2.  **Feature Generation**: Initialize the `FeatureProcessor` and execute the `process` pipeline with `load_cached_data=True` to generate features for Random Forest (TF-IDF, dense metadata) and MLP (SBERT embeddings, sequences).
3.  **Random Forest Stream**: Instantiate the `RFWrapper`, train it on the processed training data, and generate probability predictions for the validation and test sets.
4.  **MLP Stream**: Create PyTorch `DataLoader`s for the training, validation, and test sets. Instantiate the `MLPTrainer`, train the model using the GPU if available, and generate predictions for validation and test sets.
5.  **Ensemble**: Combine the predictions from both streams using a simple weighted average (0.5/0.5).
6.  **Evaluation**: Calculate the ROC AUC score on the validation set and print it in the required format.
7.  **Failure Analysis**: Compute the absolute error on the validation set. Load the raw validation metadata to correlate these errors with interpretable features (e.g., account age, upvotes) and print the top correlations.
8.  **Submission**: If the validation AUC exceeds the specified threshold, load the test metadata to retrieve `request_id`s, create a submission DataFrame with the ensemble predictions, and save it to `submission.csv`.
