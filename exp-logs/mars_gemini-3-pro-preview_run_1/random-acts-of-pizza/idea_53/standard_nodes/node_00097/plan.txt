The issue is caused by the `DualQueryAttention` mechanism producing `NaN` values when a user has no subreddit history. In such cases, the attention mask is entirely zeros, causing the masked scores to be all `-inf`. Applying Softmax to a vector of `-inf` results in a division by zero ($0/0$), producing `NaNs` (Cite debug_lesson_6). These `NaNs` propagate through the loss function during training and into the predictions during validation, causing the `roc_auc_score` function to crash.

To fix this, I will modify `library/neural_architecture.py` to sanitize the output of the Softmax function using `torch.nan_to_num`, ensuring that all-masked sequences result in zero attention weights instead of `NaN`.
