Implementation strategy:
1.  **Setup & Imports**: Import necessary classes (`DataLoader`, `SemanticProcessor`, `TabularProcessor`, etc.) from the provided library files. Set the random seed for reproducibility.
2.  **Data Loading**: Use `DataLoader.load_raw_data` with caching enabled to load train, validation, and test sets. Extract target labels.
3.  **Feature Processing**:
    *   Identify safe tabular features using `DataLoader.filter_leakage_columns`.
    *   Generate semantic features (SBERT embeddings for text and subreddit history) using `SemanticProcessor`.
    *   Generate tabular features (TF-IDF and metadata) using `TabularProcessor`.
4.  **Model Execution**:
    *   **Stream A (Random Forest)**: Train and predict using `train_predict_rf`.
    *   **Stream B (MLP)**: Train using `train_mlp` and generate predictions using `predict_mlp`.
5.  **Ensemble**: Combine predictions from both streams using the weights defined in `Config`.
6.  **Validation**: Compute the Area Under the ROC Curve (AUC) on the validation set. Print the metric with full precision.
7.  **Failure Analysis**: Calculate the absolute error between predictions and ground truth. Compute and print the correlation between error magnitude and input features to identify sources of error.
8.  **Submission**: Check if the validation AUC exceeds the specified threshold. If so, save the test predictions to the submission file.
