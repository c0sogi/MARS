2.  **Data Loading**: Use `get_features(load_cached_data=True)` to load the preprocessed training, validation, and test data.
3.  **Model Training (Stream A - RF)**: Initialize the `RFModelWrapper`. Train it on the training data. Manually generate probability predictions for the **validation set** to be used in the ensemble (since the wrapper's `predict` method is hardcoded for test data).
4.  **Model Training (Stream B - MLP)**: Initialize the `MLPModelWrapper`. Train it on the training data. Generate probability predictions for the **validation set** by creating a temporary data dictionary that maps the validation data to the keys expected by the wrapper's `predict` method.
5.  **Ensemble & Evaluation**: Calculate the weighted average of the RF and MLP validation predictions. Compute the ROC AUC score on the validation set. Print the result in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Compute the absolute error between the ensemble predictions and the true validation labels. Calculate the Pearson correlation between this error and the numerical metadata features to identify which features correlate with model failure. Print the top 5 correlated features.
7.  **Submission**: Check if the validation AUC exceeds the specified threshold (0.7036289345758168). If it does, generate predictions for the test set using both models, compute the ensemble average, and save the results to `submission/submission.csv`.
