This script demonstrates the end-to-end execution of the pizza request success prediction pipeline using the provided library modules. It performs the following steps:

1.  **Configuration Override**: Modifies the `Config` class at runtime to reduce hyperparameters (e.g., number of epochs, number of trees) for a fast execution suitable for demonstration.
2.  **Data Loading**: Loads the raw train, validation, and test datasets using `load_data`.
3.  **Feature Engineering**: Uses `FeatureExtractor` to generate TF-IDF, SBERT embeddings, and metadata features. It forces re-computation (bypassing cache) to verify the feature engineering logic.
4.  **Random Forest Training**: Instantiates and trains the `RFModel` on the processed features.
5.  **MLP Training**: Instantiates and trains the `MLPModel` (Stream B) using the generated embeddings and history sequences.
6.  **Inference & Ensembling**: Generates predictions on the test set from both models, computes a weighted average based on `Config.ENSEMBLE_WEIGHTS`, and verifies the output format.
7.  **Submission**: Saves the final predictions to a CSV file.
