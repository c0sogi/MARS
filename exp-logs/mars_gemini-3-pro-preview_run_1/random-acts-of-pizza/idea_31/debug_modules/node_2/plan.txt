The issue stems from the use of implicit boolean evaluation (`if not subs:`) on NumPy arrays, which raises a `ValueError` when the array contains multiple elements. This occurs because loading the dataset from Parquet deserializes the subreddit lists as NumPy arrays, unlike the initial CSV load which produced Python lists. To resolve this, I will replace the implicit check with an explicit length check (`if len(subs) == 0:`), which is robust for both Python lists and NumPy arrays.
