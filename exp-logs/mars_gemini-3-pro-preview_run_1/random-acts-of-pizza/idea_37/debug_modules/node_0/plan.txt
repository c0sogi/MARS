The following script demonstrates the end-to-end execution of the solution using the provided library files.

### Strategy Outline
1.  **Configuration & Setup**: Import the library modules and modify the global configuration dictionaries (`RF_PARAMS`, `MLP_PARAMS`) in-place. This reduces the number of estimators and epochs to ensure the script runs quickly (under 1 hour) while still executing the full logic.
2.  **Cache Management**: Explicitly clear the feature cache directory (`./working/idea_37`) to force the `FeatureGenerator` to compute features from scratch, demonstrating the raw data processing and SBERT embedding generation.
3.  **Random Forest Stream**: Execute `model_rf.run_rf_pipeline()`. This triggers the `DataBuilder`, which computes features, saves them to cache, and then trains/evaluates the Random Forest model. We validate the output structure and AUC score.
4.  **MLP Stream**: Execute `model_mlp.run_mlp_pipeline()`. This reuses the cached features generated in the previous step (simulating a multi-stage workflow) to train the Dual-Attention Centroid Network. We validate the predictions and AUC score.
5.  **Ensemble & Submission**: Combine the predictions from both models using the weights defined in `config.py`. Load the test metadata to retrieve request IDs, construct the final submission DataFrame, and save it to `submission.csv`.
