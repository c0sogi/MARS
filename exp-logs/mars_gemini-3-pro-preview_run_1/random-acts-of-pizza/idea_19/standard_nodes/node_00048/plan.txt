The issue is that the feature engineering pipeline blindly loads cached feature files (e.g., TF-IDF, LSA, Embeddings) if they exist, without verifying that their dimensions match the current dataset size. The error occurred because the cache contained features from a previous small "debug" run (50 samples), but the current execution loaded the full dataset (2302 samples), causing a shape mismatch during feature concatenation. To fix this, I will update the `generate_tfidf`, `generate_lsa`, and `generate_embeddings` methods in `library/features.py` to validate that the number of rows in the cached arrays matches the input dataframes before using them. If a mismatch is detected, the code will ignore the cache and recompute the features. This applies the principle from **Cite debug_lesson_1** ("Invalidate Stale Caches When Changing Data Configuration").
