The implementation strategy involves orchestrating the dual-stream pipeline defined in the library files. 

1.  **Initialization**: Set random seeds for reproducibility using `seed_everything`.
2.  **Data Loading**: Load the raw training, validation, and test DataFrames using `load_data`.
3.  **Feature Engineering**: Instantiate the `FeatureEngineer` and execute `process_features`. This handles metadata extraction, TF-IDF generation, LSA projection, and SBERT embedding generation (with caching enabled to speed up re-runs).
4.  **Model Training**:
    *   **Stream A (Random Forest)**: Train using `train_rf` on the dense feature set (Metadata + TF-IDF + LSA + Alignment).
    *   **Stream B (MLP)**: Train using `train_mlp` on the deep feature set (Embeddings + Metadata) with early stopping.
5.  **Ensemble & Validation**: Compute the weighted average of predictions from both streams on the validation set. Calculate and print the `Final Validation Metric` (ROC AUC).
6.  **Failure Analysis**: specific failure analysis on the validation set by calculating the absolute error of predictions and correlating this error with input numerical features to identify systematic weaknesses.
7.  **Submission**: If the validation AUC exceeds the specified threshold, compute the ensemble predictions for the test set and save the submission file using `save_submission`.
