The error `pyarrow.lib.ArrowInvalid` occurs because the column `giver_username_if_known` contains a mix of strings (usernames) and NaNs. When `final_train.fillna(0)` is executed, the NaNs are replaced with the integer `0`, resulting in a column containing both strings and integers. Parquet requires strict typing and fails to serialize this mixed-type column (Cite debug_lesson_19). To fix this, I will explicitly add `giver_username_if_known` (and other unused object columns like `requester_user_flair` and `requester_username`) to the `drop_cols` list in `get_rf_dataset`. This ensures these columns are removed before the `fillna` operation and Parquet serialization, which is safe as they are not used by the downstream Random Forest model.
