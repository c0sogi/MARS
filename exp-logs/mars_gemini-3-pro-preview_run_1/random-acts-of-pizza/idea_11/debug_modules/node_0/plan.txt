The following script demonstrates the complete workflow for the Pizza Request Prediction task using the provided library files.

### Strategy Outline
1.  **Configuration Override**: We modify the `Config` class at runtime to enable `DEBUG` mode (reducing dataset size) and adjust hyperparameters (fewer epochs, smaller batches) for rapid execution.
2.  **Data Processing**: We manually trigger `load_dataset`, `generate_features`, and `SemanticEngine` to demonstrate how raw data is transformed into tabular and semantic features. We verify the shapes and existence of generated features.
3.  **Stream A (Random Forest)**: We construct the specific feature matrix required for the Random Forest model using `get_rf_features`, instantiate `TopicAugmentedRF`, fit it, and verify prediction outputs.
4.  **Stream B (MLP)**: We utilize `get_dataloaders` to prepare PyTorch-ready batches. We instantiate `AttentionGatedMLP`, perform a forward pass to verify tensor shapes, and run a minimal training loop.
5.  **Full Pipeline Integration**: Finally, we execute `run_pipeline` to simulate the end-to-end process, ensuring it successfully generates a submission file in the correct format.
