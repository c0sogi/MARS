The solution implements the orchestration script `runfile.py` to execute the Hybrid Ensemble pipeline.

**Implementation Strategy:**
1.  **Setup & Configuration**: The script initializes the environment by setting random seeds and creating necessary directories via `Config.setup()`. It explicitly sets `Config.MLP_MAX_EPOCHS` to 30 to ensure the "fast baseline" requirement is met while maintaining sufficient convergence for the small dataset.
2.  **Data Loading**: It utilizes `DataLoader` to fetch the training, validation, and test datasets. The full dataset is used (`debug_size=None`) as it is small enough (~2,300 samples) to process quickly on the available A100 GPU.
3.  **Feature Engineering**: The `FeatureEngine` is invoked with `load_cached_data=True`. This ensures that if computationally expensive features (like SBERT embeddings) were previously generated and cached in the `./working` directory, they are reused to save time.
4.  **Model Training**:
    *   **Stream A (Random Forest)**: Trained using `RandomForestStream`. `force_retrain=True` is used to ensure the model is freshly trained for this run.
    *   **Stream B (MLP)**: Trained using `NeuralNetworkStream`. This handles the Dual-Query Attention mechanism and optimization loop.
5.  **Ensemble & Validation**: The script computes the weighted average of predictions from both streams (0.5/0.5 split). It calculates the ROC AUC on the validation set and prints it in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: It calculates the absolute error magnitude on the validation set and computes the Pearson correlation between this error and all numerical features. The top 5 features most correlated with prediction error are printed to identify systematic weaknesses.
7.  **Submission**: The script checks if the validation AUC exceeds the threshold (0.7056961514236341). If successful, it generates predictions for the test set using both models, ensembles them, and saves the result to `./submission/submission.csv`.
