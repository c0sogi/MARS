The following script demonstrates the usage of the provided library files to build a complete machine learning pipeline for the pizza request prediction task. It overrides the default configuration to run in a "demo" mode with a small subset of data and reduced model complexity, ensuring rapid execution and verification of the logic.

The script performs the following steps:
1.  **Configuration Override**: Adjusts hyperparameters (batch size, epochs, estimators) and enables debug sampling for speed.
2.  **Data Loading**: Uses `DataLoader` to load and parse the metadata CSVs.
3.  **Feature Engineering**: Uses `FeatureEngine` to generate TF-IDF, SBERT embeddings, and metadata features.
4.  **Dataset Verification**: Validates the `PizzaDataset` class used for the PyTorch model.
5.  **Model Training**: Trains both the Random Forest (`RandomForestStream`) and the Neural Network (`NeuralNetworkStream`) on the processed features.
6.  **Pipeline Integration**: Executes the full `Engine` to generate a submission file.
