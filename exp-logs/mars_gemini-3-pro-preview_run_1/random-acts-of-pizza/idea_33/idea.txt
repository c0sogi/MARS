Based on the comprehensive analysis of previous successes (e.g., **Dual-Query Attention**, **Gated Fusion**, **High-Fidelity TF-IDF**) and specific failures (e.g., **Centroid Averaging**, **Batch Normalization Instability**, **Aggregated Target Encoding**), I propose a **Hybrid Ensemble with Predictive-Relevance Trees and Dual-Query Alignment-Injected MLP**.

This solution structurally evolves the "Dual-View Consistency Random Forest" (Idea 31) and the "Dual-Query MLP" (Idea 27/29). The core innovation addresses the **"Semantic Averaging" weakness** in the Random Forest by introducing **Peak-Relevance Scalars** (Max-Pooling equivalent) and **Predictive Top-K Indicators** (Mutual Information Selection), ensuring the tree model receives high-signal, specific history features rather than noisy averages or generic frequencies. Simultaneously, the Neural Network is stabilized by strictly enforcing a **Dropout-Only** regime (removing Batch Normalization) and utilizing **Dual-Query Attention** to respect the structural distinction between Title and Body.

# Model

The solution employs an ensemble of two distinct, highly optimized learners fused via robust averaging.

**1. Stream A: Predictive-Relevance Random Forest**
*   **Goal**: Equip the Random Forest with a robust, multi-view representation of user history that captures "Best Match" relevance and specific high-value community signals, avoiding the information loss of centroid averaging (Cite solution_lesson_node_00032) or the noise of full sparsity (Cite solution_lesson_node_00045).
*   **Architecture**: A Random Forest Classifier with balanced class weights (Cite solution_lesson_node_00004).
*   **Input**:
    *   **High-Fidelity TF-IDF**: Concatenated Title+Body TF-IDF with continuous frequency weights and a large vocabulary (e.g., 5,000) (Cite solution_lesson_node_00031).
    *   **Full-Spectrum Metadata**: **Raw Magnitudes** (e.g., account age) + **Engineered Ratios** (e.g., upvote ratio) + **Text Meta-Features** (e.g., caps ratio) (Cite solution_lesson_node_00021, solution_lesson_node_00013).
    *   **Predictive Top-K Indicators (Structural Innovation)**:
        *   Instead of selecting subreddits by frequency (which biases towards generic communities like "AskReddit"), select the Top-$K$ ($K=50$) subreddits based on **Mutual Information** with the target variable.
        *   Generate binary flags (0/1) for these high-signal communities. This refines the "Specific Indicators" lesson (Cite solution_lesson_node_00055).
    *   **Peak-Relevance Scalars (Structural Innovation)**:
        *   Calculate the **Maximum Cosine Similarity** between the *Request Title* and *any* single subreddit in the user's history. Repeat for *Request Body*.
        *   **Rationale**: Unlike Centroid Similarity (Average), "Peak" Similarity captures whether there is *any* specific precedent for the request in the user's history (e.g., a "Loan" request matching a past "Borrow" post), providing a "Max-Pooling" signal compatible with tree splits.
    *   **Global Alignment Scalars**: Cosine Similarity between Request and History Centroid (Cite solution_lesson_node_00061).
*   **Configuration**: **Low Regularization** (`min_samples_leaf=1`) to preserve fine-grained sparse signals (Cite solution_lesson_node_00057).

**2. Stream B: Dual-Query Alignment-Injected MLP**
*   **Goal**: Model the complex interaction between Request and History using the most effective attention architecture found, stabilized for small-data training.
*   **Architecture**: A neural network with multiple branches and a Gated Fusion mechanism.
    *   **Branch 1 (Title Semantics)**: Processes **Raw SBERT embedding** of Title (No early projection) (Cite solution_lesson_node_00051).
    *   **Branch 2 (Body Semantics)**: Processes **Raw SBERT embedding** of Body.
    *   **Branch 3 (Dual-Query History Attention)**:
        *   **Input**: Sequence of **Raw SBERT embeddings** for user history.
        *   **Head A (Topic Context)**: **Dot-Product Attention** (Query=Title, Key=History) (Cite solution_lesson_node_00059).
        *   **Head B (Narrative Context)**: **Dot-Product Attention** (Query=Body, Key=History).
        *   **Masking**: Apply **Explicit Additive Masking** ($-\infty$ to padding) before Softmax (Cite solution_lesson_node_00053).
    *   **Alignment Injection**: Concatenate scalar similarities ($S_{topic}$, $S_{narrative}$) between Queries and Attended Contexts (Cite solution_lesson_node_00061).
    *   **Branch 4 (Metadata)**: Processes metadata via **Arcsinh Transformation** (Cite solution_lesson_node_00025).
    *   **Gated Fusion**: Metadata generates a **Credibility Gate** modulating the concatenated semantic vector (Cite solution_lesson_node_00028).
    *   **Regularization**: **Dropout Only**. Remove all Batch Normalization layers to prevent the overfitting/instability observed in Lesson 00062.

# Data

1.  **Leakage Prevention**: Strictly apply `get_feature_intersection` to restrict inputs to columns present in both train and test sets (Cite solution_lesson_node_00002).
2.  **Semantic Feature Engineering**:
    *   Compute SBERT embeddings for Title, Body, and all User Subreddits.
    *   **Centroid**: Mean of user subreddit embeddings.
    *   **Peak**: Max dot-product between Title/Body and user subreddit embeddings.
3.  **Predictive Top-K Profiling**:
    *   Calculate Mutual Information between subreddit presence and target in `train`.
    *   Select top 50 subreddits and generate binary flags.
4.  **Preprocessing**:
    *   **Stream A (RF)**: Impute NaNs with median.
    *   **Stream B (MLP)**: Apply **Arcsinh Transformation** followed by **StandardScaler** to numerical metadata (Cite solution_lesson_node_00025).

# Training

1.  **Random Forest**: Trained with 500 estimators, balanced class weights, and `min_samples_leaf=1` (Cite solution_lesson_node_00057).
2.  **MLP**:
    *   **Optimizer**: AdamW with weight decay.
    *   **Regularization**: Dropout (e.g., 0.5 on embeddings, 0.2 on dense).
    *   **Protocol**: **High Patience** (e.g., 15 epochs) and sufficient total epochs (e.g., 50) (Cite solution_lesson_node_00016).
3.  **Independence**: Train both models independently on the full training set.

# Evaluation

1.  **Inference**: Process test data through dual pipelines (Peak-Relevance/Predictive-Top-K/TF-IDF for RF, Sequence-History/SBERT for MLP).
2.  **Ensemble**: Calculate final probability as **Simple Weighted Average** (0.5/0.5) (Cite solution_lesson_node_00020).
