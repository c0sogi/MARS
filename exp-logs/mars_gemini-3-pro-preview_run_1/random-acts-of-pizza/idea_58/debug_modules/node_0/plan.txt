The following script demonstrates the end-to-end execution of the pizza request success prediction pipeline using the provided library files.

**Strategy:**
1.  **Configuration Override:** We modify hyperparameters in `Config` (e.g., reducing epochs, batch size, and feature dimensions) to ensure the script runs almost instantly for demonstration purposes.
2.  **Data Loading:** We load a tiny subset (20 samples) of the training, validation, and test data using `load_dataset`.
3.  **Feature Engineering:** We instantiate the `FeatureGenerator` to fit on the training data and transform all splits into the specific formats required for the Random Forest (flat vectors) and MLP (dictionaries of tensors) models.
4.  **Model Training (Stream A - RF):** We train the `MultiInteractionRF` model and verify its predictions are valid probabilities.
5.  **Model Training (Stream B - MLP):** We train the `DecoupledGatedMLP` using the `MLPTrainer`, verifying the training loop and prediction output.
6.  **Ensemble & Submission:** We average the predictions from both models and generate a submission file using `save_submission`, asserting the file format is correct.
