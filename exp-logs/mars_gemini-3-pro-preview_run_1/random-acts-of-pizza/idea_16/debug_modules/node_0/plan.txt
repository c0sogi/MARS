The following script demonstrates the complete pipeline for the pizza request success prediction task. It leverages the provided library modules to perform feature engineering, model training (Random Forest and Residual-Attention MLP), and ensemble prediction.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the global `config` parameters to run in "Debug Mode". This involves setting a small sample size (`DEBUG_SAMPLE_SIZE=100`) and reducing training epochs/estimators to ensure the script completes quickly (within minutes) while verifying all logic.
2.  **Feature Engineering**: We utilize `feature_factory.create_features()` to generate a rich feature set, including TF-IDF vectors, LSA-projected subreddit history, Sentence-BERT embeddings, and engineered metadata.
3.  **Model Training (Stream A)**: We instantiate and train the `LatentSemanticRF` (Random Forest) on the sparse feature set.
4.  **Model Training (Stream B)**: We instantiate and train the `MLPTrainer` (PyTorch Neural Network) on the dense/sequential feature set.
5.  **Ensemble & Submission**: We generate predictions from both models, compute a weighted average, and generate a submission file matching the required format.
6.  **Validation**: Throughout the process, assertions verify data shapes, target distributions, and prediction validity (range [0, 1]).
