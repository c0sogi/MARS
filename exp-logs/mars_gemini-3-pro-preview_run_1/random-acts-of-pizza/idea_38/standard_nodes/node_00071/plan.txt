The implementation strategy follows the architecture defined in the provided library files, orchestrating the data flow from loading to ensemble prediction.

1.  **Initialization**: Set random seeds for reproducibility using `library.utils.set_seed`.
2.  **Data Loading**: Retrieve stratified Train, Validation, and Test DataFrames using `library.utils.load_json_data`.
3.  **Feature Engineering (Parallel Streams)**:
    *   **Text Embeddings**: Generate SBERT embeddings for Title, Body, and Subreddit History using `library.text_encoders.SBERTEmbedder`.
    *   **TF-IDF**: Vectorize combined text for the Random Forest stream using `library.text_encoders.TFIDFHandler`.
    *   **Sentiment**: Extract VADER sentiment scores using `library.text_encoders.SentimentAnalyzer`.
    *   **Metadata**: Process numerical and text-meta features using `library.feature_engine.MetadataProcessor`. This yields two sets: raw/imputed for RF and scaled/arcsinh for MLP.
    *   **History Flags**: Generate Top-K subreddit binary indicators for RF using `library.feature_engine.HistoryProcessor`.
    *   **Prototypes**: Compute semantic prototype scores (similarity to success/failure centroids) using `library.feature_engine.PrototypeComputer`, utilizing the generated SBERT embeddings.
4.  **Model Training**:
    *   **Stream A (Random Forest)**: Assemble features (TF-IDF, Metadata, Top-K, Prototypes, Sentiment) and train the `RFLearner`.
    *   **Stream B (MLP)**: Assemble tensors (Embeddings, Masks, Scaled Metadata, Prototypes) and train the `MLPLearner` (Dual-Query Network).
5.  **Ensemble & Evaluation**:
    *   Generate probability predictions from both models for Validation and Test sets.
    *   Compute the weighted average (0.5/0.5) to form the final ensemble prediction.
    *   Calculate and print the **Final Validation Metric (AUC)**.
6.  **Failure Analysis**:
    *   Calculate prediction error on the validation set.
    *   Compute and print correlations between error magnitude and numerical features to identify weak points.
7.  **Submission**:
    *   If the validation AUC exceeds the threshold (0.7056...), save the test predictions to `submission.csv`.
