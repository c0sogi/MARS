The following script demonstrates the usage of the provided machine learning library components. It performs the following steps:
1.  **Configuration**: Sets up a temporary working directory and overrides library configurations to ensure the demonstration runs in isolation without overwriting existing production caches.
2.  **Data Loading**: Uses `load_data` to retrieve the dataset and subsets it to 50 samples for rapid execution.
3.  **Feature Engineering**: Instantiates the `FeaturePipeline` to generate both sparse features (for Random Forest) and deep learning features (embeddings/dense vectors for MLP) from the raw text and metadata.
4.  **Random Forest Model**: Trains an `RFPredictor` on the generated sparse features and validates predictions.
5.  **MLP Model**: Trains an `MLPTrainer` (which wraps the `SkipGatedMLP` architecture) on the deep learning features and validates predictions.
6.  **Verification**: Includes assertions throughout to ensure data shapes and prediction probabilities are correct.
