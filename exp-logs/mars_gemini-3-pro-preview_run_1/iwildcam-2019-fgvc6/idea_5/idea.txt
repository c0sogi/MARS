Based on the comprehensive analysis of the previous experiments and the lessons learned, I propose the following optimized strategy. This solution introduces a **Multi-Task Learning Architecture** operating at **High Resolution** to structurally resolve the tension between the dominant "empty" class and the fine-grained animal species.

# Model
I will utilize the **ConvNeXt-Small** architecture, but with a structural modification to the classification head to implement **Multi-Task Learning (MTL)**.
*   **Backbone:** ConvNeXt-Small, initialized with ImageNet-1k weights. This provides a stronger feature extractor than the Tiny variant used previously.
*   **Bifurcated Heads:** Instead of a single linear layer, the backbone features will feed into two parallel classification heads:
    1.  **Species Head (Main):** Outputs 23 logits corresponding to the specific classes (Empty + 22 Species).
    2.  **Detection Head (Auxiliary):** Outputs 1 logit (or 2) for a binary classification task: "Animal Present" vs. "Empty".
*   **Rationale:** This structure explicitly decouples the task of "background rejection" (which dominates the dataset) from "species classification". The Auxiliary Head ensures the backbone learns robust generic animal features without the gradients being diluted by the class imbalance in the main head.

# Data
The data pipeline synthesizes the successful components from previous lessons while increasing the input fidelity.
1.  **Full Dataset:** I will train on the complete 196,157 image training set. **Cite Lesson 00008** established that subsampling discards critical rare examples that cannot be recovered by loss weighting.
2.  **Natural Distribution:** I will **not** use a WeightedRandomSampler. **Cite Lesson 00002** proved that mechanically oversampling location-grouped data leads to background memorization.
3.  **High-Resolution Input:** I will increase the input image size from 224x224 to **384x384**. **Cite Lesson 00016** highlighted the necessity of maintaining spatial resolution for small objects; increasing the input size provides the model with significantly more pixels per animal, which is crucial for distinguishing similar species (e.g., deer vs. elk) in distant shots.
4.  **Augmentation:**
    *   **RandomResizedCrop (RRC):** Strictly applied with a minimum scale of 0.08 to force the model to learn local features. **Cite Lesson 00016**.
    *   **Standard Only:** HorizontalFlip, ColorJitter, and GaussianBlur. **Cite Lesson 00015** showed that mixing regularizers (Mixup/CutMix) retard convergence too much for this task.

# Training
The training strategy focuses on stabilizing the optimization of the long-tail distribution using a composite loss function and temporal averaging.
1.  **Composite Loss Function:** $L_{total} = L_{species} + \lambda \cdot L_{detection}$
    *   **Species Loss:** **Class-Balanced Focal Loss**. The class weights will be calculated using the **Square-Root (Dampened) Inverse Frequency** ($W_c = \sqrt{N_{total}/N_c}$). **Cite Lesson 00020** demonstrated that linear weighting is too aggressive and causes false positives, while dampening achieves the optimal trade-off. These weights will be applied as an **external multiplier** to the loss, not inside the probability computation (**Cite Lesson 00004**).
    *   **Detection Loss:** Standard Binary Cross Entropy (BCE) on the "Empty vs. Animal" target. This provides a stable, high-volume gradient signal to the backbone, preventing the "Empty" class from being suppressed too heavily in the feature learning phase (**Cite Lesson 00014**).
2.  **Optimizer:** AdamW with weight decay (e.g., 0.05).
3.  **Model EMA:** I will maintain an **Exponential Moving Average** of the model weights. **Cite Lesson 00019** showed this is critical for smoothing the volatile gradients produced by weighted loss functions on imbalanced data.

# Evaluation
*   **Inference:** Images will be resized to **384x384** (no cropping) and normalized.
*   **Prediction:** I will use the **Species Head** logits from the **EMA model** for the final prediction. The Detection Head is used solely for training regularization and is discarded at inference time.
