The implementation strategy involves the following steps:

1.  **Configuration & Setup**: Initialize the environment by setting random seeds for reproducibility and configuring the logger. Modify `Config.EPOCHS` to 5 to ensure the training completes well within the 2-hour limit while still providing a robust baseline on the A100 GPU.

2.  **Data Loading**: Utilize `library.data.get_loaders` to retrieve the training, validation, and test data loaders. This leverages the pre-defined `AnimalDataset` and augmentations (RandomResizedCrop, Flip, Jitter) specified in the library.

3.  **Training**: Execute the training pipeline using `library.engine.run_training`. This function handles the initialization of the `ConvNeXt-Small` model, `FocalLoss` (with class balancing), `AdamW` optimizer, and `CosineAnnealingLR` scheduler. It also manages the training loop, validation per epoch, and saving the best model checkpoint (using EMA weights).

4.  **Validation & Metrics**:
    *   Load the best saved model checkpoint.
    *   Perform inference on the full validation set to obtain predictions and ground truth labels.
    *   Calculate and print the `Final Validation Metric` (Macro F1) with full precision.

5.  **Failure Analysis**:
    *   Compute the error status for each validation sample (0 for correct, 1 for incorrect).
    *   Analyze the correlation between the error magnitude and the class rarity (represented by class weights). This helps identify if the model struggles systematically with rare species despite the Focal Loss.

6.  **Submission**:
    *   Check if the validation F1 score exceeds the threshold (0.44583477715072195).
    *   If successful, generate predictions for the test set using `library.engine.predict_and_submit` and save them to `submission.csv`.
