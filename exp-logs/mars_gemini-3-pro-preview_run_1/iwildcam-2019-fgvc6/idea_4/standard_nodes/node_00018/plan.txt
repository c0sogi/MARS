The issue is a `torch.OutOfMemoryError` caused by the `BATCH_SIZE` of 128 being too large for the available GPU memory (approx. 16GB). To fix this, I will reduce the `BATCH_SIZE` to 32 in `library/config.py` and implement Automatic Mixed Precision (AMP) in `library/engine.py` using `torch.cuda.amp`. AMP reduces memory usage by using 16-bit floating point for certain operations while maintaining model accuracy, which helps fit the model and batch into memory.
