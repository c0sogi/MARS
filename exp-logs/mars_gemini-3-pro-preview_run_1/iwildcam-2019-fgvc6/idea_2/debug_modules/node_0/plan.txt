The following implementation demonstrates the usage of the provided library modules (`config`, `utils`, `loss`, `dataset`, `model`, `engine`).

### Implementation Strategy
1.  **Setup & Configuration**: Initialize the random seed for reproducibility. Define paths to the metadata files generated in the previous step.
2.  **Data Loading (Subset)**: Instead of loading the entire dataset (which would take too long for a demo), load the metadata CSVs using pandas and slice the top 50 rows for training and 20 for validation/testing. This ensures the code runs quickly.
3.  **Dataset & DataLoader**: Instantiate the `CameraTrapDataset` class with the subset DataFrames and appropriate transforms. Verify the `__getitem__` method returns tensors of the expected shape. Wrap these datasets in PyTorch `DataLoader`s with a small batch size.
4.  **Model Initialization**: Initialize the `convnext_tiny` model using `get_convnext_model`. We set `pretrained=False` to ensure the script runs immediately without waiting for large weight downloads, as the goal is to verify the pipeline logic.
5.  **Loss Function**: Calculate class weights using the subset data and instantiate the `ClassBalancedFocalLoss`. Verify it computes a valid scalar loss on dummy data.
6.  **Training Loop**: Execute the `train_model` function for a single epoch. This validates the forward pass, backward pass, optimizer step, and validation logic.
7.  **Inference**: Run `predict_and_submit` on the test subset to generate a submission file. Verify the output file exists and has the correct format.
