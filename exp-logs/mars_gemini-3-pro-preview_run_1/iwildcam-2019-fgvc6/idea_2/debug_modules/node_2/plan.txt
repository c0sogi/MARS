The `albumentations` library version 2.0+ introduced a breaking change to `RandomResizedCrop`, replacing the `height` and `width` arguments with a single `size` tuple. I will update `library/dataset.py` to use `size=(IMAGE_SIZE, IMAGE_SIZE)` to resolve the `ValueError`. Additionally, because the Python environment is persistent and caches imported modules, I will modify `runfile.py` to explicitly reload `library.dataset` using `importlib` to ensure the updated code is executed instead of the stale bytecode. Cite debug_lesson_1
