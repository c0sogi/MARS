The following script demonstrates the usage of the provided library modules for the Leaf Classification task. It systematically validates the configuration, data loading, preprocessing, modeling, and utility functions. Finally, it executes the complete training and prediction pipeline.

The strategy involves:
1.  **Configuration Verification**: Ensuring global constants and feature definitions are correct.
2.  **Data Loading**: Loading the raw dataset from metadata CSVs and asserting data shapes.
3.  **Preprocessing**: Instantiating the `IterativeGaussianizer`, fitting it to the training data, and verifying the transformation output.
4.  **Modeling**: Training the `OASDiscriminant` classifier, generating probability predictions, and verifying their properties (shape, normalization).
5.  **Metrics & Utilities**: calculating the multi-class log loss and creating a sample submission file.
6.  **Full Pipeline Execution**: Running the high-level `train_and_predict` orchestrator to generate the final submission.
