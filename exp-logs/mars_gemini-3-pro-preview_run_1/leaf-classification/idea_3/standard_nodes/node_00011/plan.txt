Implementation strategy:
1.  **Setup and Initialization**: Import necessary libraries and the provided modules (`config`, `utils`, `data_loader`, `preprocessing`, `model`). Set random seeds for reproducibility using the value defined in `config.py`.
2.  **Data Loading**: Use `preprocessing.get_preprocessed_data(load_cached_data=True)` to load the training, validation, and test datasets. This function handles the loading of metadata from `./metadata/`, extracting features, and applying the Yeo-Johnson Power Transformation and Standard Scaling as defined in the provided library.
3.  **Model Training**: Instantiate the `StratifiedBaggedLDA` model from `library.model` with the hyperparameters specified in `config.py`. Train the model on the preprocessed training data (`X_train`, `y_train`).
4.  **Validation**:
    *   Generate probability predictions for the validation set (`X_val`).
    *   Calculate the multi-class log loss using `utils.calculate_log_loss`, which handles the specific clipping and rescaling required by the metric definition.
    *   Print the validation score in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the error magnitude for each validation sample, defined as $1.0 - P(\text{true\_class})$.
    *   Compute the Pearson correlation between this error magnitude and each of the 192 transformed input features.
    *   Print the top features most correlated with model error to identify potential weaknesses.
6.  **Submission**:
    *   Compare the validation metric against the strict threshold of `3.3960549710866674e-07`.
    *   If the metric is lower (better) than the threshold, generate predictions for the test set (`X_test`).
    *   Save the submission file using `utils.save_submission` to `./submission/submission.csv`.
