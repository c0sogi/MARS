Based on the comprehensive analysis of the accumulated lessons—specifically the "near-perfect" separation achieved by the **OAS-LDA backbone** [Cite solution_lesson_node_00047], the critical distinction between **Integral** and **Extrema-based** features [Cite solution_lesson_node_00137], the necessity of **Absolute Geometry** [Cite solution_lesson_node_00118], and the engineering failure regarding **Caching** [Cite solution_lesson_node_00116]—I propose the **Moment-Completed High-Precision OAS Discriminant**.

This strategy introduces **Higher-Order Integral Feature Closure** as a structural innovation. We systematically resolve the leaf shape using a complete hierarchy of **Image Moments**:
1.  **Zeroth Moment (Mass):** Absolute Area.
2.  **Second Moments (Inertia):** Absolute Axis Lengths and Eccentricity.
3.  **Third+ Moments (Invariants):** Hu Moments.
Previous attempts failed because they either replaced the critical Absolute features with Invariants [Cite solution_lesson_node_00118] or failed to compute the new features due to stale caching [Cite solution_lesson_node_00116]. By integrating the **Hu Moments** (which capture orthogonal asymmetry and kurtosis signals) *alongside* the proven Absolute and Macro-Geometric descriptors, and processing them through the rigorous **High-Precision Pipeline**, we maximize the discriminative signal available to the linear solver.

# Model
The architecture is a **Custom Linear Discriminant** classifier designed for exact analytical inference using `float64` precision.

1.  **OAS Covariance Backbone (Retention):** We retain the **Oracle Approximating Shrinkage (OAS)** estimator. As established in Lesson 00047, OAS minimizes the Mean Squared Error of the covariance estimate for Gaussianized data.
2.  **SVD-Based Precision Access (Retention):** We explicitly use the library-provided `precision_` attribute (SVD-based pseudo-inverse). Lessons 00062 and 00111 demonstrated that this implementation handles ill-conditioning and spectral truncation more robustly than manual linear solvers or Cholesky decompositions in this high-dimensional regime.
3.  **Linearized Inference (Retention):** We utilize the **Linear Formulation** to pre-compile decision boundaries ($W, b$), algebraically cancelling the unstable quadratic term found in distance-based formulations [Cite solution_lesson_node_00055].

# Data
1.  **Moment-Completed Geometric Fusion (Innovation):**
    *   **Tabular:** Use the 192 pre-extracted features (`margin`, `shape`, `texture`).
    *   **Visual:** Extract a comprehensive suite of **Integral-Based** descriptors from the raw binary images. We explicitly reject unstable extrema features (like MinBox or InscribedCircle) [Cite solution_lesson_node_00137].
        *   **Absolute Moments (Scale/Inertia):** `Area` (0th), `Major_Axis_Length` & `Minor_Axis_Length` (derived from 2nd moments). These preserve the biological size signal [Cite solution_lesson_node_00118].
        *   **Relative Moments (Shape):** `Eccentricity` (derived from 2nd moments).
        *   **Invariant Moments (Structure):** `Hu_Moments` (1-7). These capture higher-order shape properties (skewness, kurtosis) invariant to scale/rotation. We apply a **Log-Modulus Transform** ($sign(x) \cdot \log(|x|)$) to compress their dynamic range.
        *   **Boundary/Hull Integrals:** `Perimeter`, `Convex_Perimeter`, `Solidity` (Area/ConvexArea), `Roundness` ($4\pi A / P^2$).
        *   **Stable Extrema:** `Aspect_Ratio` (AABB), `Extent` (Area/AABB_Area). Although extrema-based, these Axis-Aligned features were proven robust in Lesson 00120 and are retained.
2.  **Configuration-Hashed Caching (Correction):** We implement hashing of the active feature configuration (names + preprocessing params) into the cache filename. This prevents the "Zombie Experiment" failure identified in Lesson 00116, ensuring the model trains on the newly extracted Hu Moments.
3.  **Deterministic Schema:** We enforce **Alphanumeric Column Ordering** on the combined feature set to ensure deterministic memory layout and floating-point associativity [Cite solution_lesson_node_00094].
4.  **Inductive Preprocessing Pipeline:**
    *   **High-Precision Loading:** Data is loaded and processed in **`float64`** [Cite solution_lesson_node_00046].
    *   **Transformation:** Apply **Yeo-Johnson Power Transformation** (`standardize=False`) followed by **Standard Scaling**.
    *   *Crucial:* This transformation is applied to *all* features. The Yeo-Johnson transform is specifically relied upon to stabilize the variance of the geometric features [Cite solution_lesson_node_00028].
    *   **Inductive Fit:** Fitted **only on the Training set** [Cite solution_lesson_node_00041].

# Training
1.  **Parameter Estimation:**
    *   Compute empirical class means $\mu_k$ using the **Arithmetic Mean** [Cite solution_lesson_node_00066].
    *   Compute empirical priors $\pi_k$ [Cite solution_lesson_node_00033].
    *   Compute residuals $R = X - \mu_y$.
    *   Estimate covariance $\Sigma$ using `OAS(assume_centered=True).fit(R)` to ensure geometric consistency [Cite solution_lesson_node_00061].
2.  **Weight Derivation:**
    *   Extract the precision matrix $P = \text{estimator.precision\_}$.
    *   Compute weights $W_k = P \mu_k$.
    *   Compute bias $b_k = -0.5 (W_k \cdot \mu_k) + \log(\pi_k)$.
    *   *Constraint:* All operations must be performed in **`float64`**.

# Evaluation
1.  **Inference:**
    *   Extract the full suite of geometric features from test images and merge with test tabular data.
    *   Preprocess using the fixed `float64` pipeline.
    *   **Linear Scoring:** Compute logits $Z = X_{test} W^T + b$ in **`float64`**.
    *   **Probability:** Apply `scipy.special.softmax` to $Z$ in **`float64`** [Cite solution_lesson_node_00085].
    *   **Precision:** Ensure no intermediate downcasting occurs, avoiding the $10^{-7}$ metric floor [Cite solution_lesson_node_00057].
