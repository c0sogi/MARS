To fix the `ValueError: y contains previously unseen labels` in `library/preprocessing.py`, I will implement a robust subsampling strategy for the debug mode as recommended in **debug_lesson_1**.

The original code naively sliced the first N rows of the dataframe. In a high-cardinality dataset (99 classes), this statistical sampling resulted in the validation set containing classes that were not present in the training subset, causing the `LabelEncoder` to crash.

My fix involves:
1.  **Filtering by Class First**: Selecting the top 15 most frequent classes to ensure sufficient sample density per class.
2.  **Subsampling Training Data**: Slicing the filtered training set to the requested `DEBUG_SAMPLE_SIZE` (50).
3.  **Synchronizing Validation Data**: Filtering the validation set to include *only* the specific species present in the final subsampled training set. This guarantees that `y_val` is a strict subset of `y_train`'s classes, preventing the encoding error.

This approach also satisfies the strict size assertions in `runfile.py` by ensuring we have enough data to fill the 50-sample buffer before slicing.
