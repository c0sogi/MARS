The `ValueError: Input X contains NaN` is caused by a data alignment issue between the preprocessing and feature extraction modules when running in Debug Mode. Specifically, `library/preprocessing.py` filters the training data by class (to ensure density) and then by row count, while `library/feature_extraction.py` independently re-loads the metadata and applies a simple row slice. This results in disjoint sets of Image IDs, causing the subsequent `pd.merge` operation to generate `NaN` values for the geometric features where IDs do not match.

To fix this, I will:
1.  Modify `process_dataset` in `library/feature_extraction.py` to accept an optional `df_meta` argument, allowing it to process the exact set of images filtered by the preprocessing module (Cite `debug_lesson_6`).
2.  Update the caching logic in both files to append a `_debug` suffix to filenames when running in debug mode, preventing cache corruption between full and debug runs (Cite `debug_lesson_14`).
3.  Update `library/preprocessing.py` to pass the filtered metadata dataframes to `process_dataset`.
4.  Enhance the `HighPrecisionPipeline` with `VarianceThreshold(threshold=0)` to drop constant features before standardization, ensuring numerical stability (Cite `debug_lesson_17`).

class HighPrecisionPipeline:
    """
    A wrapper class for the preprocessing pipeline ensuring float64 precision.
    Applies VarianceThreshold, Yeo-Johnson transformation, and Standard Scaling.
    """

    def __init__(self):
        # Drop constant features to avoid numerical instability in scaler/OAS (Cite debug_lesson_17)
        self.selector = VarianceThreshold(threshold=0)
        # Yeo-Johnson handles positive and negative values, unlike Box-Cox.
        # standardize=False because we apply StandardScaler explicitly afterwards.
        self.pt = PowerTransformer(method="yeo-johnson", standardize=False)
        self.scaler = StandardScaler()

    def fit(self, X):
        """
        Fit the pipeline to the data.
        Args:
            X (np.ndarray): Training data.
        """
        X = X.astype(Config.DTYPE)
        
        # 1. Remove constant features
        self.selector.fit(X)
        X_sel = self.selector.transform(X)
        
        # 2. Power Transform
        self.pt.fit(X_sel)
        X_pt = self.pt.transform(X_sel)
        
        # 3. Standard Scale
        self.scaler.fit(X_pt)
        return self
