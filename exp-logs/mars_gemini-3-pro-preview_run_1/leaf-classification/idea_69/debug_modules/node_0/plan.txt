The following script demonstrates the usage of the provided library modules (`utils`, `image_processing`, `data_loader`, and `model`) to solve the leaf classification task.

The script performs the following steps:
1.  **Setup**: Configures the environment and seeds for reproducibility.
2.  **Utility Verification**: Demonstrates hashing and metric calculation logic.
3.  **Feature Extraction**: Loads metadata, identifies an image, and extracts geometric features using `image_processing`.
4.  **Data Loading**: Uses `data_loader` to load a small subset of the data, verifying shapes and preprocessing steps (sanitization, transformation, scaling).
5.  **Model Training & Inference**: Instantiates the `SanitizedOASDiscriminant` model, fits it on the subset, and generates predictions.
6.  **Full Pipeline**: Executes the provided end-to-end `train_and_predict` function and verifies the output submission file.
