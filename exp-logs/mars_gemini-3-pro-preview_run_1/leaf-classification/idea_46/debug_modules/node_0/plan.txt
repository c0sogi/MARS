    *   Validate the structure of the returned data (tuples of features, labels, and IDs).

3.  **Preprocessing Verification**:
    *   Instantiate the `InductivePreprocessor` manually on a small synthetic dataset to verify that it standardizes data (mean $\approx$ 0, std $\approx$ 1).
    *   Run the full `get_preprocessed_data` pipeline on the actual datasets and verify the output shapes and data types (float64).
4.  **Model Logic Verification**:
    *   Instantiate and train the `RatioProjectedOAS` model.

    *   Perform predictions on the validation set and verify that probabilities are valid (range [0, 1], sum to 1).
5.  **Evaluation & Submission Verification**:
    *   Calculate the multi-class log loss using `compute_log_loss` and ensure it returns a valid non-negative number.
    *   Generate a sample submission file using `generate_submission_file`.
