The implementation strategy follows a robust Stratified K-Fold Cross-Validation approach to establish a reliable baseline using the LightGBM model.

1.  **Setup and Loading**: We initialize the environment with a fixed random seed and load the dataset using the provided `data_loader`. This loader combines the training and validation metadata to allow for a full 5-fold cross-validation, ensuring we maximize the use of the small dataset (~1000 samples).
2.  **Model Training (K-Fold)**: We iterate through 5 stratified folds. In each fold, we train the `LeafModel` (LightGBM) on the training subset and validate on the hold-out fold using early stopping to prevent overfitting. We collect Out-Of-Fold (OOF) predictions for the entire training set and accumulate predictions for the test set.
3.  **Validation Metric**: Once training is complete, we calculate the Multi-class Log Loss on the aggregated OOF predictions. We apply the required probability clipping ($10^{-15}$) to match the competition's scoring mechanism and print the result as "Final Validation Metric".
4.  **Failure Analysis**: To understand model weaknesses, we calculate the error magnitude for each sample (defined as $1.0 - P(\text{true\_class})$). We then compute the correlation between this error and every input feature, identifying and printing the top 5 features that are most strongly associated with prediction errors.
5.  **Submission**: Finally, we average the test set predictions across all 5 folds to reduce variance and save the formatted submission file using the provided utility function.
