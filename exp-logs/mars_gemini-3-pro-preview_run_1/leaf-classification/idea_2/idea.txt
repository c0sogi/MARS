Based on the empirical success of Gradient Boosted Decision Trees (GBDT) on extracted features [Cite solution_lesson_node_00001] and the significant performance boost from adding Linear Discriminant Analysis (LDA) [Cite solution_lesson_node_00005], I propose a **Heterogeneous Kernel-Linear-Tree Ensemble**.

This strategy introduces a **Support Vector Machine (SVM)** with an RBF kernel and probability calibration as a third structural pillar. While LightGBM captures non-linear interactions via orthogonal splits and LDA captures global linear separability, the SVM with an RBF kernel models smooth, non-linear decision boundaries in the high-dimensional feature space. This addresses the "small N, high C" challenge by combining three mathematically distinct inductive biases (Generative Linear, Discriminative Kernel, and Recursive Partitioning), maximizing error decorrelation.

### Model
The solution will consist of a voting ensemble of three distinct base classifiers:
1.  **LightGBM (Tree-based):** A gradient boosting model trained on the raw tabular features. This retains the robust baseline established in previous iterations [Cite solution_lesson_node_00001].
2.  **Linear Discriminant Analysis (Linear/Generative):** An LDA model with automatic shrinkage (Ledoit-Wolf) to handle the high dimensionality relative to the sample size. This component is retained for its proven ability to regularize and capture linear signal [Cite solution_lesson_node_00005].
3.  **Calibrated Support Vector Machine (Kernel/Discriminative):** A new component consisting of an SVM with a Radial Basis Function (RBF) kernel. To satisfy the log-loss metric, the SVM output will be calibrated using Platt Scaling (via `CalibratedClassifierCV`). This model introduces a manifold learning capability that complements the step-wise nature of trees and the linearity of LDA.

### Data
The solution will exclusively use the 192 pre-extracted tabular features (`margin`, `shape`, `texture`), adhering to the insight that deep learning on the limited raw image data is prone to overfitting [Cite solution_lesson_node_00001].
- **Preprocessing for LightGBM:** No preprocessing (raw features).
- **Preprocessing for LDA and SVM:**
    - **Power Transformation:** Apply a Yeo-Johnson transformation to the features to stabilize variance and make the distributions more Gaussian, which benefits both LDA and SVM assumptions.
    - **Scaling:** Apply Standard Scaling (zero mean, unit variance) after transformation. This is critical for the RBF kernel in SVM to function correctly, as it relies on Euclidean distances.

### Training
1.  **Stratified K-Fold Cross-Validation:** The dataset will be split into 5 stratified folds to ensure class representation.
2.  **Independent Training:** Each of the three models (LightGBM, LDA, SVM) will be trained independently on the K-1 training folds, generating Out-of-Fold (OOF) probability predictions for the validation fold.
3.  **Ensemble Weight Optimization:** Instead of a simple average, the OOF predictions from all three models will be used to find the optimal scalar weights ($w_{lgbm}, w_{lda}, w_{svm}$) that minimize the multi-class log loss. This will be solved using a constrained optimization algorithm (e.g., SLSQP) to ensure weights sum to 1 and are non-negative.

### Evaluation
For the test set, predictions will be generated by passing the test data through the three trained pipelines (including their respective preprocessing steps). The resulting probability vectors will be combined using the optimized weights derived during the training phase to produce the final submission.
