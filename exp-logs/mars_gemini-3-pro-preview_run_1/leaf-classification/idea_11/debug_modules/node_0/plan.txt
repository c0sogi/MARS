The following script demonstrates the usage of the provided library modules (`config`, `data_loader`, `preprocessing`, and `model`) to build a complete machine learning pipeline for the leaf classification task.

The implementation strategy is as follows:
1.  **Configuration Verification**: Validate that the feature schema and paths are correctly defined in `library.config`.
2.  **Data Loading**: Use `library.data_loader` to load subsets of the data, verifying dimensions and column integrity.
3.  **Preprocessing**: Demonstrate the `GaussianPipeline` from `library.preprocessing` by fitting it on data and checking that the output is standardized.
4.  **Model Training**: Instantiate and fit the `UniformPriorLDA` from `library.model`, verifying that predictions are valid probability distributions and that clipping works as expected.
5.  **Full Pipeline Execution**: Run the end-to-end `train_and_evaluate` function to compute the validation log loss, followed by `generate_submission` to produce the final CSV file.
