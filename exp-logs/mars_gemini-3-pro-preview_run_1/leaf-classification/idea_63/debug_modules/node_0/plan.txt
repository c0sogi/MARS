This script demonstrates the end-to-end workflow using the provided library files. It covers data loading, feature extraction (including geometric features from images), high-precision preprocessing, model training with the custom OAS Discriminant, and submission generation.

**Strategy:**
1.  **Initialization**: Set the random seed for reproducibility.
2.  **Feature Extraction**: Demonstrate the `extract_geometric_features` function on a single sample image to verify image processing logic.
3.  **Data Loading**: Load the full dataset using `get_data`. We use the full dataset (approx. 700 training samples) because the custom `OASDiscriminant` requires samples for every class to calculate class means without NaNs, and the dataset is small enough to process quickly.
4.  **Preprocessing**: Apply the `HighPrecisionTransformer` via `get_preprocessed_data` to sanitize, transform, and scale the features.
5.  **Model Training**: Train the `OASDiscriminant` model, evaluating it on the validation set to check the Multi-class Log Loss.
6.  **Submission**: Generate the final submission file for the test set.
