This script demonstrates the usage of the provided library modules to perform the leaf classification task. It follows the strategy of loading the data using the `data_loader`, initializing and training the `FisherEmbeddedBGP` model, and finally executing the full pipeline to generate a submission.

The script uses the full dataset (which is small, ~700 training samples) to ensure that the Linear Discriminant Analysis (LDA) step has access to all classes, avoiding potential dimensionality errors that might arise from aggressive subsampling.
