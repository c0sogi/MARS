The following script demonstrates the usage of the provided library modules for the Leaf Classification task. It systematically validates each component of the pipeline:

1.  **Image Processing**: Verifies that geometric features (e.g., Area, Solidity) can be extracted from raw images and that the dataset processing handles caching and merging correctly.
2.  **Data Loading**: Demonstrates loading and fusing tabular and geometric features into a unified DataFrame, ensuring correct column ordering.
3.  **Preprocessing**: Validates the `SanitizedTransformer` by creating a synthetic dataset with constant features to ensure the variance thresholding and scaling logic works as expected. It then runs the full preprocessing pipeline on the actual data.
4.  **Model Training**: Instantiates the `OASDiscriminant` classifier, fits it on the processed data, and verifies prediction shapes and probability constraints.
5.  **Metrics**: Uses the custom `compute_log_loss` function to calculate the evaluation metric.
6.  **Full Pipeline**: Executes the end-to-end `train_and_predict` function on a subset of data to generate a submission file.
