Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility using the constant from the `config` module.
2.  **Data Loading**: Utilize the provided `preprocessing.get_preprocessed_data` function to load the training, validation, and test datasets. This leverages the caching mechanism and the `GroupWisePreprocessor` to ensure features are correctly transformed (Yeo-Johnson + Standard Scaling) and split into semantic groups (Margin, Shape, Texture).
3.  **Model Training**: Instantiate the `FactorizedOASLDA` class from the `factorized_lda` library. Fit the model on the preprocessed training data. This calculates the class means and precision matrices for each feature group independently.
4.  **Validation**:
    *   Generate probability predictions for the validation set.
    *   Compute the **Multi-class Log Loss** metric. The probabilities are clipped to $[10^{-15}, 1-10^{-15}]$ to avoid numerical instability, matching the competition metric.
    *   Print the metric in the exact required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the error magnitude for each validation sample, defined as $1.0 - P(\text{True Class})$.
    *   Flatten the validation feature dictionaries into a single matrix.
    *   Compute the Pearson correlation between each feature and the error magnitude to identify which features are most associated with model failure.
    *   Print the top features correlated with high error.
6.  **Submission**:
    *   Check if the validation metric meets the strict threshold (`< 1.2136771218566717e-09`).
    *   If the condition is met, generate predictions for the test set.
    *   Construct the submission DataFrame including the `id` column and all species probability columns.
    *   Save the file to `./submission/submission.csv`.
