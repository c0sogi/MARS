The `ValueError: y contains previously unseen labels` occurs because the "Debug Mode" logic in `library/data_loader.py` naively slices the first `debug_size` rows of both the training and validation datasets. In a dataset with 99 classes, a small training slice (e.g., 20 rows) captures only a random subset of classes. The validation slice, however, contains classes that are not present in this restricted training set. Consequently, the `LabelEncoder` (fitted only on the training subset) fails when it encounters these unknown classes in the validation set.

To fix this, I will modify `library/data_loader.py` to filter the validation dataset so that it only includes classes present in the sliced training set. This ensures label consistency between training and validation during debug runs, effectively applying the principle from **Cite debug_lesson_1** (Filter Classes, Don't Just Slice Rows).
