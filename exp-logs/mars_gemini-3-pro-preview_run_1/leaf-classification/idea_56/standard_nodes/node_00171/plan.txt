Implementation strategy:
1.  **Environment Setup**: Initialize the environment by setting the random seed and validating the existence of input files using the provided library functions.
2.  **Data Loading**: Leverage the `get_preprocessed_data` function from the pipeline library. This handles loading raw images, extracting geometric features, and applying the sanitization/preprocessing pipeline (VarianceThreshold -> PowerTransformer -> StandardScaler). We enable caching to optimize runtime.
3.  **Model Training**: Train the `OASLinearDiscriminant` model using the `train_and_evaluate` function. This model uses a closed-form solution (OAS covariance estimation), ensuring extremely fast training without the need for iterative epochs.
4.  **Validation & Metric**:
    - Perform inference on the validation set.
    - Apply the specific probability clipping ($[10^{-15}, 1-10^{-15}]$) required by the task.
    - Compute the Multi-class Log Loss.
    - Print the metric in the exact required format.
5.  **Failure Analysis**:
    - Calculate the log loss contribution for each validation sample.
    - Compute the Pearson correlation between the error magnitude and each feature.
    - Report the top features associated with high error to identify potential weaknesses.
6.  **Submission**:
    - Compare the final validation metric against the strict threshold ($3.058881515561734 \times 10^{-14}$).
    - If the metric satisfies the condition, generate predictions for the test set and save the `submission.csv` using the provided utility.
