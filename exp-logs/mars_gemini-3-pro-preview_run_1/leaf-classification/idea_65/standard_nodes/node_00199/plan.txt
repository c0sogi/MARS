The implementation strategy follows the "Sanitized Parsimonious Geometric High-Precision OAS Discriminant" architecture described in the task.

1.  **Environment Setup**: We initialize the random seeds using `library.utils.set_seed` to ensure reproducibility.
2.  **Data Pipeline**: We leverage the `library.preprocessing.load_data` function. This function orchestrates the entire data pipeline:
    *   Loads metadata.
    *   Extracts the "Golden 5" geometric features (Area, Eccentricity, Solidity, Extent, Aspect Ratio) and merges them with the 192 tabular features.
    *   Applies **Pipeline Sanitization** via `VarianceThreshold` to remove constant features.
    *   Applies **Yeo-Johnson Transformation** and **Standard Scaling** in `float64` precision to stabilize the feature space.
    *   Returns processed `float64` numpy arrays for training, validation, and testing.
3.  **Model Training**: We instantiate and train the `library.model.OASDiscriminant`. This custom classifier:
    *   Computes empirical class means and priors.
    *   Estimates the covariance matrix of residuals using the **Oracle Approximating Shrinkage (OAS)** estimator.
    *   Derives linear decision boundaries ($W, b$) analytically using the precision matrix, strictly in `float64`.
4.  **Validation**:
    *   We generate probability predictions on the validation set.
    *   We apply the mandatory clipping $max(min(p, 1-10^{-15}), 10^{-15})$ to avoid log loss extremes.
    *   We compute the **Multi-class Log Loss** and print it with full precision.
5.  **Failure Analysis**:
    *   We calculate the error magnitude for each validation sample ($1.0 - P_{true\_class}$).
    *   We compute the Pearson correlation between this error signal and every input feature to identify which features correlate with model uncertainty.
6.  **Submission**:
    *   We compare the validation metric against the strict threshold ($3.058881515561734 \times 10^{-14}$).
    *   If the model passes, we predict on the test set, format the CSV with image IDs and species columns, and save it to `./submission/submission.csv`.
