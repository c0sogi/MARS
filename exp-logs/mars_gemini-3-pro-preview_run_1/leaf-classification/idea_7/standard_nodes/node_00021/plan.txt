The implementation strategy involves the following steps:

1.  **Initialization**: Set random seeds for reproducibility using the provided utility.
2.  **Data Loading**: Load the training, validation, and test datasets using the `data_loader` module. This leverages the cached metadata and raw features.
3.  **Preprocessing (Validation Phase)**: Apply the Yeo-Johnson Power Transformation and Standard Scaling to the data. We first fit the preprocessor on the training set and transform the validation and test sets.
4.  **Model Training (Validation Phase)**: Instantiate and train the `FeatureBaggingLDAEnsemble` on the processed training data.
5.  **Evaluation**:
    - Predict probabilities on the validation set.
    - Compute the Multi-class Log Loss using the competition-specific clipping and rescaling rules.
    - Print the final validation metric with full precision.
6.  **Failure Analysis**:
    - Calculate the log loss contribution for each validation sample.
    - Compute the Pearson correlation coefficient between each feature and the sample-wise error.
    - Report the features most strongly associated with model error.
7.  **Submission Generation**:
    - Check if the validation log loss is below the strict threshold of `1.4705447816556679e-08`.
    - If the threshold is met:
        - Combine training and validation data to maximize the signal.
        - Re-fit the global preprocessor on this combined dataset.
        - Re-train the ensemble on the combined, preprocessed data.
        - Generate predictions for the test set.
        - Save the submission file in the required format.
