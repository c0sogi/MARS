Based on the comprehensive analysis of the accumulated lessons—specifically the "near-perfect" separation achieved by the **OAS-LDA backbone** [Cite solution_lesson_node_00047], the critical importance of **Absolute Geometry** [Cite solution_lesson_node_00118], and the potential for **Hybrid Feature Fusion** to provide orthogonal signal [Cite solution_lesson_node_00113]—I propose the **Spectral-Spatial High-Precision OAS Discriminant**.

This strategy introduces **Spectral-Spatial Feature Fusion** as a structural innovation. We evolve the feature engineering paradigm from simple scalar augmentation to a **Multi-View Shape Representation**. In addition to the tabular histograms (Texture/Margin) and macroscopic scalars (Area/Solidity), we extract **Elliptical Fourier Descriptors (EFDs)** from the leaf contours. EFDs decompose the closed boundary into a sum of harmonic ellipses, capturing the morphological "fingerprint" (lobing, serration frequency) in the frequency domain. This provides a rigorous, orthogonal signal that complements the spatial and histogram features, processed through the proven **High-Precision Pipeline** to break the metric floor.

# Model
The architecture is a **Custom Linear Discriminant** classifier designed for exact analytical inference using `float64` precision.

1.  **OAS Covariance Backbone (Retention):** We retain the **Oracle Approximating Shrinkage (OAS)** estimator. As established in Lesson 00047, OAS minimizes the Mean Squared Error of the covariance estimate for Gaussianized data, handling the increased dimensionality ($P \approx 250$) robustly via analytical shrinkage.
2.  **SVD-Based Precision Access (Retention):** We explicitly use the library-provided `precision_` attribute (SVD-based pseudo-inverse). Lessons 00062 and 00111 demonstrated that this implementation handles ill-conditioning more robustly than manual solvers in high-dimensional regimes.
3.  **Linearized Inference (Retention):** We utilize the **Linear Formulation** to pre-compile decision boundaries ($W, b$), algebraically cancelling the unstable quadratic term found in distance-based formulations [Cite solution_lesson_node_00055].

# Data
1.  **Spectral-Spatial Augmentation (Innovation):**
    *   **Tabular View:** Use the 192 pre-extracted features (`margin`, `shape`, `texture`).
    *   **Spatial View (Macro-Geometry):** Extract **Absolute** and **Relative** scalars from raw binary images: `Area`, `Perimeter`, `Major_Axis`, `Minor_Axis`, `Solidity`, `Extent`, `Aspect_Ratio`, `Equivalent_Diameter`. This preserves the critical "physical size" signal [Cite solution_lesson_node_00118].
    *   **Spectral View (Micro-Morphology):** Extract **Elliptical Fourier Descriptors (EFDs)** from the leaf contours. We compute the first **15 harmonics** (60 coefficients) and normalize them to be invariant to rotation and starting point, but *not* scale (as scale is captured by the Spatial view). This captures the hierarchical shape structure (from global form to local serration) in the frequency domain, providing orthogonal signal to the spatial histograms.
2.  **Configuration-Hashed Caching (Retention):** We implement hashing of the active feature configuration to prevent stale data loading [Cite solution_lesson_node_00116].
3.  **Deterministic Schema:** We enforce **Alphanumeric Column Ordering** on the combined feature set to ensure deterministic memory layout and floating-point associativity [Cite solution_lesson_node_00094].
4.  **Inductive Preprocessing Pipeline:**
    *   **High-Precision Loading:** Data is loaded and processed in **`float64`** [Cite solution_lesson_node_00046].
    *   **Transformation:** Apply **Yeo-Johnson Power Transformation** (`standardize=False`) followed by **Standard Scaling** to *all* features. This stabilizes the variance of the new geometric/spectral descriptors [Cite solution_lesson_node_00028].
    *   **Inductive Fit:** Fitted **only on the Training set** [Cite solution_lesson_node_00041].

# Training
1.  **Parameter Estimation:**
    *   Compute empirical class means $\mu_k$ using the **Arithmetic Mean** [Cite solution_lesson_node_00066].
    *   Compute empirical priors $\pi_k$ [Cite solution_lesson_node_00033].
    *   Compute residuals $R = X - \mu_y$.
    *   Estimate covariance $\Sigma$ using `OAS(assume_centered=True).fit(R)` to ensure geometric consistency [Cite solution_lesson_node_00061].
2.  **Weight Derivation:**
    *   Extract the precision matrix $P = \text{estimator.precision\_}$.
    *   Compute weights $W_k = P \mu_k$.
    *   Compute bias $b_k = -0.5 (W_k \cdot \mu_k) + \log(\pi_k)$.
    *   *Constraint:* All operations must be performed in **`float64`**.

# Evaluation
1.  **Inference:**
    *   Extract the full suite of Spatial and Spectral features from test images and merge with test tabular data.
    *   Preprocess using the fixed `float64` pipeline.
    *   **Linear Scoring:** Compute logits $Z = X_{test} W^T + b$ in **`float64`**.
    *   **Probability:** Apply `scipy.special.softmax` to $Z$ in **`float64`** [Cite solution_lesson_node_00085].
    *   **Precision:** Ensure no intermediate downcasting occurs to avoid the $10^{-7}$ metric floor [Cite solution_lesson_node_00057].
