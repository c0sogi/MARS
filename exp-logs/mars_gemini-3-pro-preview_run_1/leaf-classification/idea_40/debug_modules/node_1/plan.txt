The `ValueError: y contains previously unseen labels` occurs because the `get_preprocessed_data` function naively slices the first `max_samples` rows of the training and validation datasets. In high-cardinality classification tasks (99 classes), a small random slice of the validation set (e.g., 50 rows) is statistically likely to contain classes not present in the corresponding small slice of the training set. This causes the `LabelEncoder`, which is fitted only on the training subset, to fail when transforming the validation subset.

Instead of arbitrary slicing, the code will first identify a small subset of target classes (e.g., the first 10) and filter both the training and validation DataFrames to include only these classes.
