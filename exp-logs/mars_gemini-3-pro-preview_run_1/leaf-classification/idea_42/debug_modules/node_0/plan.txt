The following script demonstrates the usage of the provided library modules for the leaf classification task. It follows a logical flow:
1.  **Setup & Utilities**: Verifies the configuration and utility functions like precision enforcement and caching.
2.  **Feature Extraction**: Demonstrates how to extract morphological features from images using a subset of the data to ensure speed.
3.  **Data Management**: Uses the `FeatureManager` and `DataLoader` to orchestrate the loading, merging, and preprocessing of the full dataset.
4.  **Modeling**: Instantiates the `OASDiscriminant` classifier, trains it on the processed data, and generates predictions.
5.  **Validation**: Includes assertions throughout to verify data types, shapes, and mathematical properties (e.g., probability sums).
