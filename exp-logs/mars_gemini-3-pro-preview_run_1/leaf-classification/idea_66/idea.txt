Based on the comprehensive analysis of the accumulated lessons—specifically the "near-perfect" separation achieved by the **OAS-LDA backbone** [Cite solution_lesson_node_00047], the constraints of **Small Sample Size** ($N \approx 3.6P$) on global covariance estimation [Cite solution_lesson_node_00015], and the potential for **Factorization** to increase statistical power [Cite solution_lesson_node_00156]—I propose the **Sanitized Factorized High-Precision OAS Ensemble**.

This strategy introduces **Bayesian Feature Factorization** as a structural innovation. Instead of estimating a single, massive $197 \times 197$ covariance matrix (which risks overfitting off-diagonal correlations in small-sample regimes), we decompose the problem into four independent "Experts" based on semantic feature groups: **Margin**, **Shape**, **Texture**, and **Geometry**. This increases the effective $N/P$ ratio from ~3.6 to ~11 (for tabular groups) and ~140 (for geometry), significantly stabilizing the covariance estimates. We aggregate these experts by **Summing Linear Logits** (equivalent to multiplying likelihoods under a Naive Bayes assumption), which mathematically "sharps" the probability distribution and pushes predictions closer to 1.0, breaking the metric floor.

# Model
The architecture is a **Bayesian Ensemble of Linear Discriminants** operating in strict **Double Precision**:

1.  **Factorized Backbones:** Four independent **Linear Discriminant Analysis (LDA)** models, each assigned to a specific feature group:
    *   **Expert M:** Trained on `margin_1`...`margin_64`.
    *   **Expert S:** Trained on `shape_1`...`shape_64`.
    *   **Expert T:** Trained on `texture_1`...`texture_64`.
    *   **Expert G:** Trained on the 5 extracted **Golden Geometric Scalars**.
2.  **Group-Wise OAS Covariance:** Each expert estimates its own covariance matrix $\Sigma_g$ using **Oracle Approximating Shrinkage (OAS)**.
    *   *Rationale:* This allows the model to apply distinct shrinkage intensities to different feature types (e.g., heavily shrinking noisy Texture while trusting robust Geometry).
3.  **Bayesian Logit Aggregation:** We combine the experts by summing their **Linear Logits**.
    *   *Formulation:* $Z_{total} = Z_M + Z_S + Z_T + Z_G - 3 \cdot \log(\pi)$.
    *   *Rationale:* Since each LDA expert implicitly calculates $Z_g = \log P(x_g|y) + \log P(y)$, summing them would quadruple-count the prior. We explicitly subtract the excess priors to recover the joint posterior $\log P(y|x)$.

# Data
1.  **Feature Engineering:**
    *   **Tabular:** Split the 192 pre-extracted features into three matrices ($X_M, X_S, X_T$) based on column prefixes.
    *   **Geometric:** Extract the **Golden 5** robust scalar descriptors from raw images using **Polarity Correction** [Cite solution_lesson_node_00145], **Fixed Thresholding** [Cite solution_lesson_node_00195], and **Implicit Filtering** [Cite solution_lesson_node_00197]:
        1.  **Area** (Absolute Scale) [Cite solution_lesson_node_00118].
        2.  **Eccentricity** (Boundary-Fitted Elongation) [Cite solution_lesson_node_00151].
        3.  **Solidity** (Roughness).
        4.  **Extent** (Rectangularity) [Cite solution_lesson_node_00120].
        5.  **Aspect Ratio** (AABB Orientation) [Cite solution_lesson_node_00120].
    *   **Assembly:** Use **Dictionary-Based Assembly** to prevent indexing bugs [Cite solution_lesson_node_00186].
2.  **Sanitized Preprocessing Pipeline:**
    *   **Per-Group Sanitization:** Apply `VarianceThreshold(threshold=0)` to each group independently to remove constant features [Cite solution_lesson_node_00167].
    *   **High-Precision Transformation:** Apply **Yeo-Johnson Power Transformation** (`standardize=False`) followed by **Standard Scaling** in **`float64`** [Cite solution_lesson_node_00046].
    *   **Inductive Fit:** Fitted **only on the Training set** [Cite solution_lesson_node_00041].

# Training
1.  **Parameter Estimation (Per Group):**
    *   For each group $g \in \{M, S, T, G\}$:
        *   Compute empirical class means $\mu_{g,k}$ (Arithmetic Mean [Cite solution_lesson_node_00066]) and priors $\pi_k$ [Cite solution_lesson_node_00033].
        *   Compute residuals $R_g = X_g - \mu_{g,y}$.
        *   Estimate $\Sigma_g$ using `OAS(assume_centered=True).fit(R_g)` [Cite solution_lesson_node_00061].
        *   Extract precision matrix $P_g$ using the robust library implementation [Cite solution_lesson_node_00111].
        *   Derive weights $W_g = P_g \mu_g$ and bias $b_g = -0.5 \text{diag}(\mu_g^T W_g) + \log(\pi)$ [Cite solution_lesson_node_00055].
2.  **No Optimization:** The aggregation is analytical, avoiding overfitting.

# Evaluation
1.  **Inference:**
    *   Extract geometric features from test images and split tabular data into groups.
    *   Preprocess each group using its fixed `float64` pipeline.
    *   **Linear Scoring:** Compute logits $Z_g = X_{test, g} W_g^T + b_g$ in **`float64`**.
    *   **Aggregation:** $Z_{total} = \sum Z_g - 3 \log(\pi)$.
    *   **Probability:** Apply `scipy.special.softmax` to $Z_{total}$ in **`float64`** [Cite solution_lesson_node_00085].
    *   **Post-Processing:** Normalize probabilities before clipping [Cite solution_lesson_node_00184].
