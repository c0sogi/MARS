The following script demonstrates the usage of the provided library modules for the plant species identification task. It follows a step-by-step approach:

1.  **Data Loading**: It explicitly uses `load_dataset` to retrieve raw features and targets, verifying data dimensions.
2.  **Preprocessing**: It demonstrates the `GaussianTransformer` class by fitting it on the training data and validating that the transformed features exhibit zero mean and unit variance. It then uses the high-level `get_preprocessed_data` function to retrieve the fully processed datasets.
3.  **Model Training & Inference**: It instantiates the `OASLinearDiscriminant` class, fits it to the training data, and generates probabilities for the validation set. Assertions ensure the probabilities are valid (sum to 1, range [0, 1]).
4.  **Full Pipeline Execution**: Finally, it calls the `generate_submission` function to execute the end-to-end workflow (retraining on full data and generating the test submission file), followed by a verification of the output file format.
