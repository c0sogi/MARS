Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Setup and Reproducibility**: Initialize the environment by setting random seeds for NumPy and Python's random module to ensure deterministic results.
2.  **Data Loading**: Utilize the provided `library.preprocessing.get_preprocessed_data` function. This leverages the cached, pre-calculated Gaussian-transformed features (Yeo-Johnson + Standard Scaling) to save time and ensure consistency with the `float64` precision requirement.
3.  **Model Training (Validation)**: Instantiate the `OASLinearDiscriminant` from the provided library. Fit the model on the training set (`X_train`, `y_train`) and generate probability predictions for the validation set (`X_val`).
4.  **Evaluation**:
    *   Clip predictions to the range $[10^{-15}, 1 - 10^{-15}]$ to avoid log singularities.
    *   Compute the Multi-class Log Loss on the validation set.
    *   Print the result in the exact required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the individual Cross-Entropy Loss for each sample in the validation set.
    *   Compute the Pearson correlation coefficient between the error (loss) and each of the 192 input features.
    *   Identify and print the features most strongly correlated with high model error to provide insight into weaknesses.
6.  **Submission Generation**:
    *   Compare the validation metric against the strict threshold ($1.4705366241156435 \times 10^{-8}$).
    *   If the metric is better (lower) than the threshold:
        *   Combine training and validation sets to maximize the sample size ($N$) for the OAS covariance estimator.
        *   Retrain the `OASLinearDiscriminant` on this full dataset.
        *   Generate predictions for the test set (`X_test`).
        *   Format the output dataframe with the `id` column and alphanumerically sorted species columns.
        *   Save the file to `./submission/submission.csv`.
