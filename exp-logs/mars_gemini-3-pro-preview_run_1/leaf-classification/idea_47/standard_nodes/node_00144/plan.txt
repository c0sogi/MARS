This solution implements the **Iterative Gaussian-OAS High-Precision Discriminant** pipeline. It orchestrates the loading of pre-extracted features and raw images, applies a strictly `float64` transformation pipeline (Yeo-Johnson $\to$ Whitening PCA $\to$ Yeo-Johnson) to enforce multivariate Gaussianity, and trains a Linear Discriminant classifier with an Oracle Approximating Shrinkage (OAS) covariance estimator.

### Strategy Outline
1.  **Configuration & Setup**: Initialize random seeds and paths using the provided library configuration.
2.  **Data Loading & Transformation**: Utilize `library.transformations.get_transformed_data` to load the dataset. This function automatically handles:
    *   Merging tabular features with geometric descriptors extracted from images.
    *   Applying the three-stage Iterative Gaussianization pipeline.
    *   Caching results to disk for efficiency.
3.  **Model Training**: Instantiate and fit the `OASLinearDiscriminant` on the training set. This model computes the analytical solution for the decision boundaries using high-precision linear algebra.
4.  **Validation**:
    *   Generate probability predictions for the validation set.
    *   Apply rescaling and clipping (min/max at $\epsilon=10^{-15}$) to strictly mimic the evaluation metric's behavior.
    *   Compute and print the **Multi-class Log Loss**.
5.  **Failure Analysis**:
    *   Calculate the per-sample log loss (error magnitude).
    *   Compute the Pearson correlation between the error magnitude and each transformed feature to identify sources of instability.
6.  **Submission**:
    *   Compare the validation metric against the strict threshold ($3.338 \times 10^{-14}$).
    *   If the condition is met, generate predictions for the test set and save the submission file using the provided helper function.
