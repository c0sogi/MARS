### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed for reproducibility and verify the existence of necessary input directories and metadata files.
2.  **Feature Engineering Demonstration**:
    *   Load the training metadata to retrieve a valid image path.
    *   Invoke `feature_engineering.extract_geometric_features` on a single image to demonstrate feature extraction.
    *   Validate that the output dictionary contains the expected keys (Area, Eccentricity, etc.) and valid numerical values.
3.  **Data Loading and Preprocessing Demonstration**:
    *   Call `data_loader.load_dataset` to load the raw feature matrices for train, validation, and test sets.
    *   Validate the shapes of the returned arrays and dataframes.
    *   Call `data_loader.preprocess_data` to apply the Yeo-Johnson transformation and standardization.
    *   Verify that the processed training data has approximately zero mean and unit variance, confirming the scaler's effect.
4.  **Model Training and Inference Demonstration**:
    *   Instantiate the `ParsimoniousOASDiscriminant` class from `library.model`.
    *   Fit the model using the preprocessed training data.
    *   Generate probability predictions on the validation set.
    *   Validate that predictions sum to 1.0 (within floating-point tolerance) and that the output shape matches `(n_samples, n_classes)`.
5.  **Full Pipeline Execution**:
    *   Run the high-level `model.run_training_pipeline` function to execute the end-to-end workflow.
    *   Verify that the submission file is created in the correct location and adheres to the required CSV format (header checks, row counts).
