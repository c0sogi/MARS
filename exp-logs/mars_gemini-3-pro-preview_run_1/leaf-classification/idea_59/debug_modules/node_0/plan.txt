The following script demonstrates the complete workflow using the provided library modules. It performs the following steps:
1.  **Setup**: Sets random seeds for reproducibility.
2.  **Data Loading**: Uses `data_handler` to load a small debug subset of the training, validation, and test data, verifying dimensions and feature merging (tabular + geometric).
3.  **Preprocessing**: Uses `preprocessor` to sanitize, stabilize, and scale the features, asserting that the output is valid and high-precision (`float64`).
4.  **Modeling**: Instantiates and trains the `OASLinearModel`. It validates the learned parameters (weights, biases) and the probability outputs.
5.  **Full Pipeline**: Executes the end-to-end `run_training_and_inference` function to generate a submission file, which is then verified for correctness against the required format.
