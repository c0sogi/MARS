The following script demonstrates the usage of the provided library modules (`config`, `utils`, `data_loader`, `teacher`, `student`) to perform the end-to-end workflow: loading data, training a teacher model (OAS-LDA), generating synthetic data, training a student model (Logistic Regression) with analytic initialization, and generating a submission file.

To ensure the demonstration runs quickly, the number of synthetic samples generated is significantly reduced from the default configuration. Assertions are included to verify the correctness of data shapes, types, and model outputs.
