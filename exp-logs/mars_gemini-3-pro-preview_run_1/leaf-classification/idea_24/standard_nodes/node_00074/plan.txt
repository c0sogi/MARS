The implementation strategy follows the Generative-Discriminative Synthetic Transfer (GDST) workflow. First, we load the high-precision `float64` data using the provided `data_loader`. Next, we fit the `OASTeacher` to the empirical training data to estimate the data manifold and generate a massive synthetic dataset. We then train the `SyntheticStudent` (Logistic Regression) on this synthetic data, utilizing the teacher's analytic solution for weight initialization. After training, we evaluate the model on the validation set, perform a failure analysis by correlating feature values with per-sample log loss, and conditionally generate the submission file if the strict performance threshold is met.
