The issue is a class mismatch caused by training on a truncated dataset (`debug_sample_size=100`) that does not contain all 99 species. The validation set `y_val` retains all classes, causing `log_loss` to fail when it encounters labels unknown to the model (Cite debug_lesson_1). Furthermore, the model's predictions on the test set will have fewer columns than the required 99, which would cause a shape mismatch in `save_submission` (Cite debug_lesson_2).

The fix involves:
1.  Filtering the validation set to strictly include only the classes learned by the model before computing the metric.
2.  Projecting the test set predictions from the reduced class space back to the full 99-class schema by filling missing columns with zeros.
