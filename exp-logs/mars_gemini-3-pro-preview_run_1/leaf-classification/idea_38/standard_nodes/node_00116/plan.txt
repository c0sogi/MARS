The strategy involves implementing the `runfile.py` script to orchestrate the complete machine learning pipeline using the provided library modules.

1.  **Setup & Imports**: We will import the necessary standard libraries (`numpy`, `pandas`, `sklearn`, `scipy`) and the custom modules from the `library` package (`config`, `preprocessing`, `model`). The global random seed will be set to ensure reproducibility.
2.  **Data Loading**: We will use `get_preprocessed_data(load_cached_data=True)` to efficiently load the training, validation, and test datasets. This function handles the merging of metadata with extracted geometric features and applies the `Float64Pipeline` (Yeo-Johnson transform and Standard Scaling).
3.  **Model Training**: We will instantiate the `OASLinearDiscriminant` model and fit it on the training data. This model uses high-precision `float64` linear algebra and Oracle Approximating Shrinkage for robust covariance estimation.
4.  **Validation**: We will generate probability predictions for the validation set and calculate the Multi-class Log Loss. The result will be printed in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: We will compute the per-sample log loss (error magnitude) on the validation set. We will then reconstruct the feature names (combining tabular and geometric features) and calculate the Pearson correlation between each feature and the error magnitude. The top 5 correlations will be printed to identify systematic error sources.
6.  **Submission Logic**: We will compare the final validation metric against the strict threshold of `5.234670549314967e-14`. If and only if the metric is lower than this threshold, we will generate predictions for the test set and save the submission file to `./submission/submission.csv`.
