Implementation strategy:
1.  **Environment Setup**: Import necessary libraries (`numpy`, `pandas`, `sklearn`, `os`, `sys`) and the provided library modules (`config`, `data_processing`, `model`). Set random seeds for reproducibility.
2.  **Data Loading**: Use `library.data_processing.get_processed_data(load_cached_data=True)` to efficiently load the preprocessed training, validation, and test datasets (including the geometric features).
3.  **Label Encoding**: Initialize a `LabelEncoder` and fit it on the combined training and validation target labels to ensure consistent class mapping.
4.  **Model Training**: Instantiate the `HighPrecisionOASDiscriminant` class and fit it on the training data. This model uses a closed-form solution (OAS covariance estimation), so training is fast and deterministic.
5.  **Validation & Metric**:
    *   Generate probability predictions for the validation set.
    *   Compute the Multi-class Log Loss using `sklearn.metrics.log_loss`.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate the error magnitude (negative log-likelihood of the true class) for each validation sample.
    *   Compute the Pearson correlation between each feature and the error magnitude vector.
    *   Print the top 5 features most correlated with prediction errors to identify potential weaknesses.
7.  **Submission**:
    *   Check if the validation metric is strictly lower than the specified threshold (`3.058881515561734e-14`).
    *   **If and only if** the condition is met:
        *   Generate predictions for the test set.
        *   Construct a pandas DataFrame with `id` and sorted species columns.
        *   Save the dataframe to `./submission/submission.csv`.
    *   If the condition is not met, skip submission generation to strictly adhere to the requirements.
