Based on the comprehensive analysis of the accumulated lessons—specifically the "near-perfect" separation achieved by the **OAS-LDA backbone** [Cite solution_lesson_node_00047], the critical role of **Double Precision** [Cite solution_lesson_node_00057], and the explicit warning against using inverted precision matrices in favor of direct solvers [Cite solution_lesson_node_00095]—I propose the **Exact Cholesky-OAS Linear Discriminant**.

This strategy introduces a **Direct Linear Solver Architecture** as a structural innovation. Previous "High-Precision" attempts failed to break the metric floor because they relied on the `precision_` attribute of the OAS estimator, which internally computes an explicit inverse matrix using SVD-based pseudo-inversion. This operation squares the condition number (amplifying noise) and truncates the spectrum (discarding subtle signal). By switching to a **Cholesky-Factorized Solver**, we maintain the covariance in its decomposed form ($L L^T$) and solve for the decision boundaries directly. This guarantees numerical stability and strictly preserves all discriminative signal without truncation, maximizing the resolution of the probability estimates.

# Model
The architecture is a **Custom Linear Discriminant** classifier designed for exact analytical inference using `float64` precision.

1.  **OAS Covariance Backbone (Retention):** We retain the **Oracle Approximating Shrinkage (OAS)** estimator. As established in Lesson 00047, OAS minimizes the Mean Squared Error of the covariance estimate for Gaussianized data. Crucially, the shrinkage ensures the covariance matrix is Positive Definite (PD), satisfying the mathematical prerequisite for Cholesky decomposition.
2.  **Direct Cholesky Solver (Innovation):** Instead of computing weights via $W = \Sigma^{-1}_{SVD} \mu$ (using the explicit precision matrix), we solve the linear system $\Sigma W = \mu$ directly.
    *   **Factorization:** Compute the Cholesky decomposition $\Sigma = L L^T$ using `scipy.linalg.cho_factor`.
    *   **Substitution:** Solve for weights $W$ using `scipy.linalg.cho_solve`.
    *   *Rationale:* This avoids the numerical instability associated with explicit inversion [Cite solution_lesson_node_00095] and eliminates the information loss associated with SVD truncation.
3.  **Linearized Inference (Retention):** We utilize the **Linear Formulation** to pre-compile decision boundaries ($W, b$), algebraically cancelling the unstable quadratic term found in distance-based formulations [Cite solution_lesson_node_00055].
    *   $b_k = -0.5 (W_k \cdot \mu_k) + \log(\pi_k)$.

# Data
1.  **Input:** The solution will exclusively use the 192 pre-extracted tabular features (`margin`, `shape`, `texture`).
2.  **Deterministic Ordering:** We hardcode the list of 192 feature names in strict alphanumeric order to prevent implicit column permutation and floating-point associativity noise [Cite solution_lesson_node_00029, solution_lesson_node_00094].
3.  **Inductive Preprocessing Pipeline:**
    *   **High-Precision Loading:** Data is loaded and processed in **`float64`** to preserve signal during transformation [Cite solution_lesson_node_00046].
    *   **Transformation:** Apply **Yeo-Johnson Power Transformation** (`standardize=False`) followed by **Standard Scaling**.
    *   **Inductive Fit:** These transformers are fitted **only on the Training set** [Cite solution_lesson_node_00041].
    *   **No Quantization:** Data remains in `float64` throughout the entire pipeline to avoid the $10^{-7}$ metric floor imposed by `float32` [Cite solution_lesson_node_00057].

# Training
1.  **Parameter Estimation:**
    *   Compute empirical class means $\mu_k$ using the **Arithmetic Mean** (optimal for Gaussian data) [Cite solution_lesson_node_00066].
    *   Compute empirical priors $\pi_k$ based on training class frequencies [Cite solution_lesson_node_00033].
    *   Compute residuals $R = X - \mu_y$.
    *   Estimate the covariance matrix $\Sigma$ using `OAS(assume_centered=True).fit(R)`. We explicitly extract the `covariance_` attribute, avoiding the `precision_` attribute.
    *   *Constraint:* Ensure `assume_centered=True` to enforce geometric consistency between the means and the covariance [Cite solution_lesson_node_00061].
2.  **Exact Weight Derivation:**
    *   Compute the Cholesky factorization: $c, lower = \text{scipy.linalg.cho_factor}(\Sigma)$.
    *   Solve for the weight matrix: $W = \text{scipy.linalg.cho_solve}((c, lower), \mu^T)^T$.
    *   Compute the bias vector $b$ using the dot product of $W$ and $\mu$.
    *   *Precision:* All operations must be performed in **`float64`**.

# Evaluation
1.  **Inference:**
    *   Preprocess the test data using the fixed `float64` pipeline.
    *   **Linear Scoring:** Compute the logits $Z = X_{test} W^T + b$ in **`float64`**.
    *   **Probability:** Apply `scipy.special.softmax` to $Z$ in **`float64`**. We leverage library-level numerical optimizations [Cite solution_lesson_node_00085] and avoid redundant re-normalization.
2.  **Robustness:** This strategy combines the statistical robustness of OAS (for covariance estimation) with the numerical precision of Cholesky solvers (for weight derivation). By avoiding explicit inversion and SVD truncation, we resolve the decision boundaries with the maximum possible fidelity allowed by double-precision arithmetic.
