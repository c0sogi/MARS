The strategy for the `runfile.py` implementation is as follows:

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and import necessary modules from the provided library files (`config`, `data_loader`, `preprocessor`, `model`, `evaluation`).
2.  **Data Pipeline**:
    *   Load the training, validation, and test datasets using `load_datasets(load_cached_data=True)` to leverage any existing cache for speed.
    *   Apply the preprocessing pipeline (Yeo-Johnson Power Transform + Standard Scaling) using `preprocess_data`.
3.  **Model Training**:
    *   Instantiate the `FisherGaussianEnsemble` model.
    *   Fit the model on the training data. This triggers the LDA dimensionality reduction followed by the Gaussian Process Classifier optimization.
4.  **Validation & Metrics**:
    *   Generate probability predictions for the validation set.
    *   Calculate the Multi-class Log Loss using the provided `calculate_log_loss` function.
    *   Print the final metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Compute the per-sample log loss for the validation set.
    *   Calculate the Pearson correlation coefficient between each feature and the error magnitude.
    *   Identify and print the top 5 features positively and negatively correlated with model error to provide insights into failure modes.
6.  **Submission**:
    *   Compare the validation metric against the strict threshold (`1.4705447816556679e-08`).
    *   If the metric is lower than the threshold, generate predictions for the test set and save the `submission.csv` file using `create_submission_file`.
