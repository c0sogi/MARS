This script demonstrates the usage of the provided library components for the leaf classification task. It covers:
1.  **Configuration & Utilities**: Setting random seeds and verifying configuration constants.
2.  **Feature Extraction**: Using `ImageFeatureExtractor` to generate geometric and tabular features from a subset of data.
3.  **Preprocessing**: Applying the `HighPrecisionTransformer` (Yeo-Johnson + Standard Scaling) and verifying data statistics.
4.  **Data Management**: Using `DataManager` to orchestrate the loading and processing of train, validation, and test sets.
5.  **Model Training & Inference**: Training the `OASLinearDiscriminant` model and generating predictions.
6.  **Metric Calculation**: Computing the custom multi-class log loss.

The script runs on a small subset of the data (`max_samples=50`) to ensure quick execution while validating the logic of all components.
