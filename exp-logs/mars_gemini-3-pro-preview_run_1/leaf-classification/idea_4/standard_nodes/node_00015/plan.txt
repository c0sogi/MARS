The `InvalidSubmissionError` indicates that the submission file is missing columns for some species classes. This occurs because the script is loading stale preprocessed data from a previous "debug" run (where only a subset of classes was used) instead of processing the full dataset. As noted in the error analysis, the cached data in `./working/idea_4/` contains the `species_encoder` with only the debug classes.

To fix this, we need to force the `load_data` function to ignore the existing cache and re-process the full dataset from the raw CSVs. This aligns with the principle of clearing stale state when the underlying data requirements change (Cite debug_lesson_1). I will modify `runfile.py` to set `load_cached_data=False`.
