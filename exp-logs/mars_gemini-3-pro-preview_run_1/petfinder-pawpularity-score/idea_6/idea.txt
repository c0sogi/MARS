# Proposed Strategy: Tri-Paradigm Stacking with Heterogeneous Interaction Experts

## Model
To address the limitations of purely distance-based estimators (Ridge, SVR) in handling the interaction between high-dimensional visual embeddings and binary metadata, I propose extending the **Tri-Paradigm Stacking Ensemble** (Cite `solution_lesson_node_00022`) with a **Partitioning Expert**.

1.  **Feature Extractors (Backbones):**
    *   **Semantic:** **CLIP ViT-L/14**. Captures subjective "vibes" and text-aligned concepts (Cite `solution_lesson_node_00021`).
    *   **Geometric:** **DINOv2 ViT-Large**. Captures object layout and structure via self-supervision (Cite `solution_lesson_node_00022`).
    *   **Textural:** **ConvNeXt Large**. Captures local high-frequency details (Cite `solution_lesson_node_00015`).

2.  **Level-0 Heterogeneous Experts:**
    Instead of relying only on Linear and Kernel methods, I will introduce a Tree-based estimator to explicitly model conditional logic (e.g., "If *Blur* is present, downweight texture features"). For *each* of the three backbones, I will train three distinct estimators:
    *   **Linear Expert:** **Ridge Regression**. Efficiently maps the global trend (Cite `solution_lesson_node_00001`).
    *   **Kernel Expert:** **Support Vector Regression (SVR)** with RBF kernel. Captures non-linear manifolds based on embedding distance (Cite `solution_lesson_node_00023`).
    *   **Partitioning Expert (New):** **ExtraTrees Regressor** (Extremely Randomized Trees). Unlike Ridge/SVR, trees can natively handle the binary nature of metadata and learn hierarchical splits. To make this computationally feasible and robust, it will be trained on **PCA-reduced embeddings** (e.g., top 64 components) concatenated with the raw metadata.

3.  **Level-1 Meta-Learner:**
    *   A **Ridge Regression** meta-learner will aggregate the 9 predictions (3 Backbones $\times$ 3 Experts) using "Late Fusion" (Cite `solution_lesson_node_00019`).

## Data
1.  **Preprocessing:** Images will be resized and normalized specific to each backbone's requirements.
2.  **Feature-Space Augmentation:** Embeddings will be computed for both original and horizontally flipped images and averaged to enforce invariance (Cite `solution_lesson_node_00009`).
3.  **Feature Transformation:**
    *   For **Ridge/SVR**: Apply **StandardScaler** to the concatenated vector of [Embeddings, Metadata] to ensure proper regularization weighting (Cite `solution_lesson_node_00007`).
    *   For **ExtraTrees**: Apply **PCA** (Principal Component Analysis) to the image embeddings to reduce dimensionality while preserving variance, then concatenate with the raw binary metadata.

## Training
1.  **Cross-Validation:** Employ **5-Fold Cross-Validation** to generate unbiased Out-of-Fold (OOF) predictions for all Level-0 experts.
2.  **Hyperparameter Optimization:**
    *   **Ridge:** Use `RidgeCV` with an expanded alpha search range (up to 50,000) to avoid boundary clipping (Cite `solution_lesson_node_00010`).
    *   **SVR:** Grid search for `C` and `epsilon` on a subset of data if necessary to manage runtime.
    *   **ExtraTrees:** Standard configuration with a sufficient number of trees (e.g., 500) to stabilize variance.
3.  **Meta-Learning:** Train the Level-1 Ridge Regressor on the matrix of OOF predictions.

## Evaluation
1.  **Inference:** Process test images through the three backbones (with flip-averaging) to generate embeddings.
2.  **Prediction:**
    *   Apply scaling/PCA transforms.
    *   Generate predictions from all 9 Level-0 experts (averaged across folds).
    *   Feed these base predictions into the Level-1 Meta-Learner to output the final `Pawpularity` score.
