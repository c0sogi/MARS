Implementation Strategy:
1.  **Configuration Setup**: We will first override the global `Config` settings to enable `DEBUG` mode (using a tiny subset of data), reduce the number of cross-validation folds to 2, and simplify hyperparameter search spaces. This ensures the entire pipeline runs within minutes.
2.  **Dataset Verification**: We will instantiate the `PawpularityDataset` and `get_transforms` to verify that images and metadata can be loaded and preprocessed correctly, asserting output tensor shapes.
3.  **Feature Extraction**: We will execute `extract_and_save_features` for the CLIP backbone. This demonstrates the deep learning inference step and caching mechanism.
4.  **Feature Processing**: We will run `get_expert_data` to demonstrate how raw embeddings are normalized and concatenated with metadata for the 'linear' expert group.
5.  **Level-0 Expert Training**: We will train two lightweight experts (Ridge and SVR) using the extracted CLIP features. This tests the `Level0Trainer` class and the caching of OOF/Test predictions.
6.  **Meta-Learner Execution**: We will instantiate the `MetaLearner`, restricting its scope to the previously trained experts (CLIP+Ridge, CLIP+SVR) to avoid running the full heavy ensemble. We will then execute the meta-learner to generate the final submission file.
7.  **Validation**: Throughout the script, assertions will verify data shapes, file existence, and logical consistency of the outputs.
