The `BayesianRidge` model in scikit-learn (version 1.7.2) no longer accepts the `n_iter` parameter, which has been renamed to `max_iter`. This causes a `TypeError` when the `Level1MetaLearner` attempts to initialize the model using the configuration dictionary. I will update `META_MODEL_PARAMS` in `library/config.py` to use `max_iter` instead of `n_iter`, ensuring compatibility with the installed library version.
