The implementation strategy follows the Multi-Paradigm Stacking Ensemble architecture defined in the provided library files. The script will orchestrate the pipeline by initializing the `StackingManager`, which handles feature extraction (using Swin, ConvNeXt, and CLIP), Level-0 expert training (Ridge Regression), and Level-1 meta-learning.

1.  **Setup**: We import necessary modules and suppress warnings to maintain a clean output. The random seed is fixed using `seed_everything` for reproducibility.
2.  **Training**: We instantiate `StackingManager` with `subset_size=None` to use the full dataset (as the dataset size is small enough for the A100 GPU to handle quickly) and `load_cached_data=True` to utilize any pre-computed features. We then execute `train_level_0` and `train_level_1`.
3.  **Validation & Analysis**: We manually reconstruct the final ensemble predictions on the validation set to calculate the exact RMSE. We then calculate the absolute prediction errors and compute their correlation with the binary metadata features to identify sources of error (Failure Analysis).
4.  **Submission**: We compare the calculated RMSE against the specified threshold (17.514754696543086). If the model performs sufficiently well, we generate the submission file using `manager.predict()`.
