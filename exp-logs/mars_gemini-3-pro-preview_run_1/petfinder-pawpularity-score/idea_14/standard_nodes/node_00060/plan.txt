Implementation strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided `library` modules. Override `Config` parameters to ensure the pipeline runs within the 23-minute limit (reduce folds to 3, limit tree estimators, subsample training/validation data to 1500/500 samples).
2.  **Data Loading**: Load metadata using `load_metadata` with `merge_train_val=False` to maintain a distinct hold-out validation set. Subsample the dataframes for speed.
3.  **Feature Extraction**: Iterate through the three backbones (SigLIP, DINOv2, ConvNeXt V2). Use `PetDataset` and `process_and_cache_features` to extract embeddings for Train, Validation, and Test sets. Use `return_flipped=True` for feature-space augmentation.
4.  **Level 0 Modeling**: Instantiate `Level0Trainer`. Combine Validation and Test features into a single "test" dictionary to pass to `run_cv`. This allows us to get predictions for both sets using the models trained on the Train set.
5.  **Level 1 Modeling**: Train the `BayesianRidge` meta-learner on the Out-Of-Fold (OOF) predictions from Level 0. Generate final predictions for the Validation and Test sets.
6.  **Validation & Analysis**: Calculate the RMSE on the hold-out Validation set. Print the metric in the required format. Calculate the correlation between absolute errors and metadata features to identify failure modes.
7.  **Submission**: Check if the Validation RMSE is below the threshold (16.9554...). If so, save the Test predictions to `submission.csv`.
