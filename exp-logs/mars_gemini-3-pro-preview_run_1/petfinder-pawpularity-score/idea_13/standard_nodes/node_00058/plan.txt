Implementation strategy:
1.  **Setup & Imports**: Import necessary libraries and the provided modules (`Config`, `utils`, `feature_extraction`, `level0_experts`, `level1_meta`). Set the random seed for reproducibility.
2.  **Pipeline Execution**:
    *   Execute `run_feature_extraction` to generate embeddings from images using the three backbones (SigLIP, DINOv2, ConvNeXt).
    *   Execute `train_level0_experts` to train the base regressors (Ridge, SVR, ExtraTrees, LightGBM) via stratified cross-validation.
    *   Execute `train_meta_learner` to train the Interaction-Aware Meta-Learner and generate the initial `submission.csv`.
3.  **Validation & Metric Calculation**:
    *   Load the hold-out validation metadata from `./metadata/val.csv`.
    *   Load the Level-1 OOF data (`level1_X_oof.npy`, `level1_y_oof.npy`) and the merged IDs from the cache.
    *   Re-run the 5-Fold Cross-Validation on the Meta-Learner (using the same seed and parameters) to reproduce the OOF predictions.
    *   Filter these predictions to isolate the subset corresponding to the hold-out validation IDs.
    *   Calculate the RMSE on this specific validation subset.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Using the validation subset predictions and targets, calculate the absolute errors.
    *   Extract the metadata features from the design matrix for this subset.
    *   Compute and print the Pearson correlation between the error magnitude and each metadata feature to identify performance bottlenecks.
5.  **Submission Logic**:
    *   Compare the calculated validation RMSE against the threshold (16.95541414729265).
    *   If the RMSE is not lower than the threshold, delete the generated `submission.csv`.
