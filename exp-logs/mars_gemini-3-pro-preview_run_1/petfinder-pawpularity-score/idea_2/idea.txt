# Proposed Strategy: End-to-End Fine-Tuning of Swin Transformer with Metadata Fusion

## Model
To address the limitations of the previous linear probing approaches, I propose a transition to an **End-to-End Fine-Tuning** architecture using a **Swin Transformer** backbone.

*   **Backbone:** I will utilize **Swin Transformer Tiny** (swin_tiny_patch4_window7_224) pre-trained on ImageNet. This represents a structural shift from Convolutional Neural Networks (MobileNet) to Hierarchical Vision Transformers. Swin Transformers are better suited to capture global compositional details and long-range dependencies, which are critical for assessing the aesthetic quality and "engagement" of a photo, unlike the texture-biased features of CNNs.
*   **Multimodal Fusion:** The backbone will output a 768-dimensional feature vector. I will concatenate this vector with the 12 binary metadata features.
*   **Prediction Head:** I will replace the simple Ridge Regressor with a **Multi-Layer Perceptron (MLP)** (Projection -> BatchNorm -> Activation -> Dropout -> Prediction).
    *   *Rationale:* This addresses the finding that a linear combination of features is insufficient to capture the complexity of the task (Cite `solution_lesson_node_00001`). The MLP introduces non-linearity to model the interaction between visual aesthetics and metadata tags.

## Data
*   **Preprocessing:** Images will be resized to 224x224 and normalized using ImageNet statistics.
*   **Augmentation:** To mitigate the risk of overfitting associated with high-dimensional features on small datasets (Cite `solution_lesson_node_00004`), I will implement a robust data augmentation pipeline. This will include Random Horizontal Flips, Random Resized Crops, and Color Jittering. This artificially increases the effective size of the training set, allowing the model to leverage the higher capacity of the Swin backbone without memorizing the training data.

## Training
*   **Strategy:** Unlike the previous "frozen" approach, I will perform **full fine-tuning** of the model weights. This allows the visual features to adapt specifically to the "Pawpularity" task rather than relying on generic object classification signals.
*   **Optimization:** I will use the **AdamW** optimizer with a **Cosine Annealing** learning rate scheduler.
*   **Loss Function:** I will use **BCEWithLogitsLoss** (scaling the target 1-100 range to 0-1) or **MSELoss**. Scaling targets to 0-1 and using a Sigmoid activation often stabilizes training for bounded regression tasks like this.
*   **Regularization:** In addition to data augmentation, I will apply **Weight Decay** and **Dropout** within the MLP head to further enforce the heuristic of constraining model capacity relative to the dataset size (Cite `solution_lesson_node_00004`).

## Evaluation
*   **Inference:** The test images will be processed through the fine-tuned pipeline.
*   **Post-Processing:** If a Sigmoid output is used, the predictions will be rescaled from [0, 1] back to the original [1, 100] range.
*   **Validation:** I will continue to use the stratified validation set to monitor RMSE and ensure the model generalizes better than the linear probing baselines.
