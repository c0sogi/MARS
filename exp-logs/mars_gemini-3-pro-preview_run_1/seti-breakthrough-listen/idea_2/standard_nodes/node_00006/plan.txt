The implementation strategy follows the "Fast Baseline" approach while ensuring high performance by utilizing the full dataset (as permitted by the A100 GPU speed and the library constraints). We will use the provided `get_dataloaders` with `debug=False` to ensure the full test set is processed for a valid submission. After training, we reload the best checkpoint to perform a detailed failure analysis—correlating prediction errors with input signal statistics (mean, std, max, contrast)—and generate the final submission if the validation AUC exceeds the specified threshold.
