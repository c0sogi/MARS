The following implementation strategy demonstrates the usage of the provided library files to train, validate, and generate predictions for the Technosignature detection task.

### Implementation Strategy
1.  **Setup & Imports**: Import the necessary classes and functions from the `library` package (`config`, `dataset`, `model`, `engine`, `utils`). Set the random seed for reproducibility.
2.  **Data Loading**: Initialize the DataLoaders using `get_dataloaders`. We will enable the `debug=True` mode with a small `debug_size` (e.g., 50 samples) and a small `batch_size` (e.g., 8). This ensures the script runs quickly within the time limit while still exercising the full pipeline.
3.  **Model Initialization**: Instantiate the custom multi-channel ResNet18 model using `get_multichannel_resnet`. We set `pretrained=False` to ensure the script runs without requiring an internet connection to download weights.
4.  **Training Simulation**: Define a loss function (`BCEWithLogitsLoss`) and an optimizer (`Adam`). Run a single training epoch using `train_one_epoch` to verify the training loop logic and loss calculation.
5.  **Validation**: Run the `validate` function on the validation loader to compute the loss and ROC AUC score on the debug subset.
6.  **Inference & Submission**: Use `generate_submission` to predict targets for the test set (debug subset) and save the results to a CSV file.
7.  **Verification**: Throughout the script, use `assert` statements to verify tensor shapes, data types, and the existence/format of the output submission file.
