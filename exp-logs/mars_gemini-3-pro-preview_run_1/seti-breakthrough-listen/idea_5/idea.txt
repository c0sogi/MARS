Based on the lessons learned from previous experiments, I propose the **Time-Distributed Multi-Scale ResNet50-GN**, a structural evolution of the successful Late-Fusion architecture. This solution addresses the capacity bottleneck of the ResNet34 model while solving the batch size instability that caused the ResNet50 failure, and introduces a multi-scale fusion strategy to better detect fine-grained drifting signals.

# Model
We propose a **Time-Distributed Multi-Scale ResNet50-GN** architecture.

1.  **Backbone with Group Normalization:** We will use a **ResNet50** backbone to increase model capacity, as previous results showed that deeper models (ResNet34) significantly outperformed shallower ones (ResNet18) (Cite solution_lesson_node_00017). Crucially, we will **replace all Batch Normalization (BN) layers with Group Normalization (GN)**. This structural change allows us to train the larger ResNet50 model with a small batch size (e.g., 8-12) without suffering from the statistical instability and convergence failure observed when using BN with small batches (Cite solution_lesson_node_00020).
2.  **Time-Distributed Feature Extraction:** We will wrap this backbone in a `TimeDistributed` layer to process each of the 6 cadence panels independently. This avoids the early aggregation of the "ON-OFF" pattern that caused channel-stacking 2D CNNs to fail (Cite solution_lesson_node_00006) and avoids the temporal smoothing issues of 3D CNNs (Cite solution_lesson_node_00010).
3.  **Multi-Scale Late Fusion:** Instead of fusing features only at the final layer (which has low spatial resolution), we will extract feature maps from three stages of the backbone (e.g., Stride 8, 16, and 32). For each scale, we will concatenate the feature maps from all 6 time steps along the channel dimension. This preserves the spatial coordinates necessary for the subsequent 2D convolution layers to detect the Doppler drift of the signal across the sequence (Cite solution_lesson_node_00018).
4.  **Feature Pyramid Aggregation:** These multi-scale fused volumes will be processed by a Feature Pyramid Network (FPN) style head: the deepest (lowest resolution) features will be upsampled and added to the shallower (higher resolution) features. This ensures the model can utilize both high-level semantic context (ON-OFF logic) and fine-grained spatial details (diagonal line trajectory) to detect faint signals. The head will include **Dropout** to prevent overfitting (Cite solution_lesson_node_00017).

# Data
1.  **Input Formatting:** The input will be reshaped to `(Batch, 6, 1, 273, 256)` to be compatible with the Time-Distributed 2D backbone.
2.  **Normalization:** We will apply instance-wise normalization (zero mean, unit variance) to each sample.
3.  **Augmentation:** We will apply **Random Frequency Shifting** (vertical translation) and spatial flips identically across all 6 frames to simulate signal drift. We will **strictly exclude Mixup augmentation**, as it has been proven to degrade performance by diluting faint signals in this low-SNR regime (Cite solution_lesson_node_00015).
4.  **Drift Preservation:** By avoiding any preprocessing that collapses the time dimension (like averaging or subtraction), we ensure that the non-stationary, drifting nature of the technosignatures is preserved for the model (Cite solution_lesson_node_00001).

# Training
1.  **Loss Function:** We will use **Binary Cross-Entropy with Logits Loss**.
2.  **Optimizer:** We will use the **AdamW optimizer** with a **OneCycleLR** scheduler to ensure stable convergence.
3.  **Batch Size Strategy:** Thanks to the switch to Group Normalization, we will use a **batch size of 8 to 12** (depending on GPU memory). This fits the heavier ResNet50 backbone into memory while maintaining stable gradient estimates, directly addressing the failure mode of the previous ResNet50 attempt (Cite solution_lesson_node_00020).
4.  **Duration:** We will train for at least **15 epochs**, utilizing Early Stopping based on Validation ROC AUC.

# Evaluation
For the test set, samples will be reshaped to `(1, 6, 1, 273, 256)` and normalized. The model will output a probability score based on the multi-scale spatiotemporal features. This approach leverages the high capacity of ResNet50 and the stability of GroupNorm to perform a robust "spot-the-difference" check across the cadence, preserving both the "ON-OFF" logic and the spatial drift trajectory.
