# Baseline Approach: Spatial Difference CNN

## Model
We propose a **Spatial Difference CNN**, a lightweight, custom convolutional neural network designed to operate on a pre-processed single-channel representation of the cadence. Unlike **Model 1**, which uses a deep MobileNet backbone on raw 6-channel data to learn channel dependencies, this model relies on a shallow, custom architecture (e.g., 3 to 4 convolutional blocks). Each block will consist of a 2D convolution (3x3 kernels), Batch Normalization, ReLU activation, and Max Pooling. The network concludes with Global Average Pooling and a single dense layer with a sigmoid activation. This design drastically reduces the parameter count and computational overhead by offloading the "ON-OFF" comparison logic to the preprocessing stage.

## Data
The core of this approach lies in reducing the 6-channel cadence snippet into a single-channel **Difference Map** before it reaches the model.
1.  **Aggregation:** For each sample, compute the pixel-wise mean of the 'ON' target panels (indices 0, 2, 4) and the 'OFF' target panels (indices 1, 3, 5).
2.  **Subtraction:** Subtract the 'OFF' mean from the 'ON' mean. This operation explicitly isolates energy that appears only during observations of the target star (technosignatures) while canceling out Radio Frequency Interference (RFI) present in both phases.
3.  **Normalization:** Standardize the resulting single-channel image (273x256) to have zero mean and unit variance to ensure stable convergence.
This preprocessing step distinguishes the approach from **Model 4** (which flattens data for PCA/SVM) by preserving the 2D spatial structure necessary to detect diagonal Doppler drifts.

## Training
The model will be trained using **Binary Cross-Entropy with Logits Loss**. We will use the **Adam optimizer** with a default learning rate (e.g., 0.001). Due to the simplified input (1 channel vs. 6) and the shallow architecture, we expect rapid convergence. We will implement **Early Stopping** based on the validation ROC AUC score to prevent overfitting. Consistent with the baseline philosophy, we will not employ heavy augmentations (like Mixup) or test-time augmentation.

## Evaluation
For the test set, we will apply the same "Difference Map" generation and normalization steps. The trained CNN will perform a forward pass on these single-channel images to output the predicted probability of a technosignature "needle." These probabilities will be saved to the submission file alongside their corresponding IDs.
