The implementation strategy is as follows:

1.  **Configuration**: Initialize the environment by setting the random seed for reproducibility. Modify the global `Config` to enable "Debug Mode" with a subset of 5,000 samples and limit training to 2 epochs. This ensures the script serves as a fast baseline that completes well within the 2-hour limit.
2.  **Training**: Invoke the `train_model` function from the `library` package. This handles the model initialization (Spatiotemporal ResNet-18), training loop, and saving of the best checkpoint based on validation AUC.
3.  **Validation & Failure Analysis**:
    *   Load the validation data (consistent with the debug subset) and the trained model checkpoint.
    *   Perform inference to calculate the final ROC AUC score and print it in the required format (`Final Validation Metric: <value>`).
    *   Conduct failure analysis by extracting meta-features (mean, std, max, contrast) from the validation samples and calculating their Pearson correlation with the model's absolute prediction error. This identifies which signal properties correlate with poor performance.
4.  **Submission**: Compare the final validation metric against the specified threshold (0.5095077440787745). If the model passes the threshold, call the `predict` function to generate predictions for the entire test set and save the `submission.csv` file.
