# Idea 4: Late-Fusion Time-Distributed CNN

## Model
We propose a **Late-Fusion Time-Distributed CNN** to address the limitations of early aggregation found in previous attempts. Previous experiments showed that collapsing the temporal dimension via averaging destroys drifting signals (Cite solution_lesson_node_00001) and that stacking raw frames as channels in a standard 2D CNN causes the first convolutional layer to wash out faint signals against the noise (Cite solution_lesson_node_00006). Furthermore, 3D CNNs failed because they smoothed over the discrete "ON-OFF" state changes (Cite solution_lesson_node_00010).

To solve this, we will decouple **feature extraction** from **temporal comparison**:
1.  **Time-Distributed Backbone:** We will use a lightweight 2D CNN (e.g., ResNet-18 without the final fully connected layer) wrapped in a `TimeDistributed` layer. This backbone processes each of the 6 cadence panels ($t=0$ to $5$) **independently** but using **shared weights**. This allows the model to learn to detect "needle-like" features (diagonal lines) in each frame individually, utilizing the non-linear activations (ReLU) to suppress noise *before* any temporal mixing occurs.
2.  **Feature Concatenation:** The output feature maps from the 6 passes are concatenated along the channel dimension. If the backbone outputs $C$ channels per frame, the concatenated tensor will have $6 \times C$ channels, preserving the spatial layout of features for each time step.
3.  **Cadence Analysis Head:** The concatenated features are fed into a shallow 2D convolutional head (the "Fusion" module). This module is responsible for learning the logical "ABACAD" pattern (e.g., feature present in channels $0..C$ but absent in $C..2C$) and tracking the spatial drift of the signal across the stacked maps.

## Data
The data pipeline will be structured to support the time-distributed architecture while strictly avoiding signal-degrading augmentations:
1.  **Input Formatting:** The raw data `(6, 273, 256)` will be reshaped to `(Batch, 6, 1, 273, 256)` to represent a sequence of 6 single-channel images.
2.  **Normalization:** We will apply instance-wise normalization (zero mean, unit variance) to each sample to standardize the noise floor.
3.  **Augmentation:** We will apply **Random Frequency Shifting** (vertical translation) and spatial flips identically across all 6 frames to simulate signal drift and location variance. Crucially, we will **strictly exclude Mixup augmentation**. As observed in previous experiments, blending faint signals with noise dilutes the signal below the detection threshold in low-SNR regimes (Cite solution_lesson_node_00015).

## Training
The model will be trained using **Binary Cross-Entropy with Logits Loss**. We will use the **AdamW optimizer** with a **OneCycleLR** scheduler to ensure stable convergence. By using a pre-trained backbone (e.g., ImageNet weights) for the shared encoder, we can leverage robust feature extractors, while the custom Fusion Head will be initialized randomly to learn the specific cadence logic. We will monitor the validation ROC AUC for **Early Stopping**.

## Evaluation
For inference, the test set snippets will be reshaped to `(1, 6, 1, 273, 256)` and normalized. The model will process the sequence, extracting features for each frame and then fusing them to output a probability score. This approach ensures that the "ON-OFF" comparison happens in a high-SNR feature space rather than the noisy pixel space.
