I will implement the `runfile.py` script to orchestrate the taxi fare prediction pipeline. The strategy involves:

1.  **Setup**: Initialize the environment and random seeds for reproducibility.
2.  **Data Processing**: Use the `TaxiDataProcessor` to load and prepare the datasets. To ensure the baseline runs quickly within the time constraints, I will limit the training data to 1,000,000 samples. The validation and test sets will be processed in full to ensure accurate evaluation.
3.  **Model Training**: Instantiate the `FarePredictor` (LightGBM) and train it using the processed training and validation data. Early stopping is enabled via the configuration to prevent overfitting and reduce runtime.
4.  **Evaluation**:
    *   Compute predictions on the full validation set.
    *   Calculate the Root Mean Squared Error (RMSE).
    *   Print the metric in the strictly required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Calculate the absolute error for each validation prediction and compute Pearson correlations between this error and the input features to identify sources of inaccuracy.
6.  **Submission**: Generate predictions for the test set and save the `submission.csv` file in the specified format.
