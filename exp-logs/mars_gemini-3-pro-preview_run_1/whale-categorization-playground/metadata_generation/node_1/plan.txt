The `ValueError` in `train_test_split` arises because the validation set size (calculated as 20% of the data) is smaller than the number of unique classes included in the split. This makes it impossible to satisfy the stratification requirement (at least one sample per class in the validation set). This happens because many classes have very few samples (2-4). To fix this, I will increase the minimum sample threshold for the stratified split from 2 to 5. Classes with fewer than 5 samples will be allocated entirely to the training set. This ensures that for the remaining classes, the validation set size is sufficient to include at least one sample from each class (since 5 samples * 0.2 = 1).
