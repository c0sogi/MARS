The `AssertionError` arises because Python evaluates default arguments at function definition time. The `save_checkpoint` function binds `dir_path` to the initial value of `Config.CHECKPOINT_DIR` (from `library/config.py`) when `library/utils.py` is imported. When `runfile.py` subsequently updates `Config.CHECKPOINT_DIR` to the demo directory, `save_checkpoint` continues to use the stale, original path. This causes the checkpoint to be saved in the wrong location, leading to a file not found error during verification, which relates to the issue of ensuring artifacts are written to the correct, clean directory (Cite debug_lesson_2). To fix this, I will modify `save_checkpoint` to use `None` as the default value for `dir_path` and resolve `Config.CHECKPOINT_DIR` dynamically within the function body.
