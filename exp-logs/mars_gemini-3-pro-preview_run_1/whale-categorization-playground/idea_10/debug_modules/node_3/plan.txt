The loading logic in `runfile.py` blindly copies this key into the new state dictionary, causing `load_state_dict` to fail due to the unexpected key. To fix this, I will modify the state dictionary processing loop in `runfile.py` to explicitly filter out the `n_averaged` key before loading weights into the inference model.
