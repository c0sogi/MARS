This script demonstrates the end-to-end usage of the provided Whale Species Prediction library. It performs the following steps:

1.  **Configuration**: Monkey-patches the `Config` class to run in a fast "Debug" mode (small subset of data, few epochs, reduced batch size) and sets up the working directories.
2.  **Dataset Verification**: Instantiates the `WhaleDataset`, verifies data loading, image shapes, and class mapping consistency.
3.  **Model & Loss Verification**: Instantiates the `WhaleDenseNet` and `WhaleLoss`, performs a dummy forward pass, and verifies output shapes and loss calculation.
4.  **Training Loop**: Uses the `Trainer` class to run a short training cycle (2 epochs) with SWA (Stochastic Weight Averaging), validating the creation of checkpoints.
5.  **Inference & Submission**: Loads the trained model, runs inference on a sample of the test set using Test-Time Augmentation (TTA), and generates a submission file in the required format (MAP@5).
