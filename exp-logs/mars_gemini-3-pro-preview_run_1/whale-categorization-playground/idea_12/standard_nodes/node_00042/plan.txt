The `AttributeError: 'numpy.ndarray' object has no attribute 'index'` occurs because the `calculate_map5` function expects `predictions` to be a list of lists (so it can use the Python `.index()` method), but it receives a list of 1D NumPy arrays. This happens because `all_preds.extend(top_indices.cpu().numpy())` appends NumPy arrays directly to the list. To fix this, we must explicitly convert the NumPy arrays to Python lists using `.tolist()` before extending `all_preds` and `all_targets` in both `library/trainer.py` and `runfile.py`. This ensures the data types are consistent with what `calculate_map5` expects.
