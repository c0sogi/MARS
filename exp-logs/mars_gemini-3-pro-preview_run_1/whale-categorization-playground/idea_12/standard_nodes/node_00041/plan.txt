Implementation strategy:
1.  **Configuration & Setup**: Import the `Config` class and override `MAX_EPOCHS` to 8 and `EARLY_STOPPING_PATIENCE` to 3. This ensures the 4-model ensemble training completes within the 2-hour limit while still allowing for convergence on the dataset.
2.  **Data Loading**: Use `get_dataloaders(load_cached_data=True)` to efficiently load the training and validation data.
3.  **Ensemble Training**: Iterate through the defined `Config.ENSEMBLE_MODELS` (2x DenseNet121, 2x ResNet50-IBN-a). For each model, set the specific seed, initialize the `WhaleModel` and `Trainer`, and run `train_until_convergence()`. Free GPU memory after each model to prevent OOM errors.
4.  **Ensemble Validation**: Load all 4 trained models using `load_ensemble`. Perform inference on the validation set using the ensemble strategy (averaging logits from original and horizontally flipped views). Calculate the `MAP@5` score using `calculate_map5`.
5.  **Failure Analysis**: Compute the error magnitude (`1.0 - score`) for each validation sample. Load the corresponding images to extract metadata (Width, Height, Aspect Ratio, Intensity) and calculate the Pearson correlation coefficient between the error and these features using `numpy`.
6.  **Submission**: Compare the final validation metric against the threshold (`0.6636...`). If the metric is higher, clear memory and call `predict_ensemble()` to generate the `submission.csv` file.
