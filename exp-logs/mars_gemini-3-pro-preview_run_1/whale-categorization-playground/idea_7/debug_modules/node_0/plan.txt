### Implementation Strategy

1.  **Configuration Patching**: We will dynamically modify the `Config` class attributes to adapt the pipeline for a quick demonstration. This includes enabling debug mode (to subsample data), reducing the number of epochs for both training stages to 1, setting a small batch size, and defining a specific working directory for demo artifacts.
2.  **Utility Verification**: We will demonstrate the `WhaleLabelEncoder` by manually fitting it to a small list of IDs and verifying that encoding and decoding operations are consistent.
3.  **Dataset Verification**: We will instantiate the `WhaleDataset` (in debug mode) and iterate through a single batch to verify data loading, image transformation shapes, and label types.
4.  **Model Verification**: We will instantiate the `WhaleDenseNet` model, perform a forward pass with dummy data to check output shapes, and verify the ArcFace logic.
5.  **Training Loop Execution**: We will execute the `train_model` function for a single seed. Thanks to the patched configuration, this will run a very short training cycle (Stage 1 and Stage 2) on the subsampled dataset, ensuring the training pipeline functions correctly without timing out.
6.  **Inference Verification**: Finally, we will load the checkpoint generated by the training step and perform a manual inference pass using `get_logits_inference` to confirm that the model produces valid prediction logits.
