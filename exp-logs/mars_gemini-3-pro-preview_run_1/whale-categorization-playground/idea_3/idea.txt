Based on the lessons learned from the previous experiments, I propose a structural evolution from a standard classification approach to a **Metric Learning** paradigm using a **DenseNet** backbone. This strategy addresses the fine-grained nature of the task and the limitations of previous architectures.

# Model
I propose replacing the ResNet/EfficientNet architectures with a **DenseNet121** backbone equipped with an **ArcFace (Additive Angular Margin)** head.
*   **Backbone**: **DenseNet121**. Unlike ResNet, which sums features, DenseNet concatenates features from all preceding layers. This "collective knowledge" preservation is critical for fine-grained recognition, as it maintains high-frequency details (scars, notches) throughout the network that are often lost in standard summation or aggressive downsampling.
*   **Pooling**: Retain **Global Average Pooling (GAP)**. Previous experiments demonstrated that specialized pooling (like GeM) leads to overfitting on artifacts in few-shot scenarios. GAP provides a robust, "soft" feature aggregation that generalizes better for ranking. **Cite solution_lesson_node_00010**.
*   **Head**: Replace the linear classification head with an **ArcFace** layer. Standard Cross-Entropy (used in previous ideas) only encourages separability. ArcFace enforces a geodesic distance margin on the hypersphere, compressing intra-class variance and maximizing inter-class distance. This is essential for distinguishing between the 4,000+ subtlely different whale IDs.

# Data
*   **Resolution**: Standardize input size to **320x320**. Previous lessons showed that 224x224 destroys critical details (**Cite solution_lesson_node_00005**), while 448x448 induces overfitting (**Cite solution_lesson_node_00007**). 320x320 offers the optimal trade-off between detail preservation and regularization (**Cite solution_lesson_node_00008**).
*   **Splitting**: Maintain the **Singleton-Inclusive Split**. All singleton classes (1 sample) must be in the training set to avoid zero-shot validation errors. **Cite solution_lesson_node_00002**.
*   **Augmentation**:
    *   **Geometric**: Apply affine transformations (rotation, shear, scaling) and horizontal flips to learn pose invariance.
    *   **Photometric**: Apply brightness and contrast adjustments.
    *   **Exclusion**: Explicitly **exclude** saturation and hue jitter, as chromatic noise has been proven to degrade performance in this texture-dependent domain. **Cite solution_lesson_node_00004**.

# Training
*   **Loss Function**: **ArcFace Loss**. This replaces Cross-Entropy (or Label Smoothing). It calculates the angle between the feature vector and the class center, adds a margin $m$, and re-projects to the probability space. This forces the model to learn highly discriminative embeddings.
*   **Optimizer**: **AdamW** for effective weight decay.
*   **Scheduler**: **Cosine Annealing** to ensure smooth convergence from a warm-up phase. **Cite solution_lesson_node_00003**.
*   **Strategy**: Train end-to-end. Treat `new_whale` as a standard class ID (class 0) within the ArcFace formulation, allowing the margin penalty to separate known individuals from the generic "new" category.

# Evaluation
*   **Protocol**: Implement **Test-Time Augmentation (TTA)** using Horizontal Flips for both the **validation loop** and **final inference**.
*   **Consistency**: Ensure the validation metric calculation mirrors the inference pipeline (averaging predictions of original + flipped images) to prevent underestimating model performance and discarding valid checkpoints. **Cite solution_lesson_node_00011**.
*   **Prediction**: Extract the cosine similarities (logits) from the ArcFace head and select the top 5 classes.
