The previous implementation failed during the evaluation phase because `torch.load` now defaults to `weights_only=True` in recent PyTorch versions, restricting the loading of non-PyTorch types for security. The checkpoint file contained a NumPy scalar (likely the `best_score` metric calculated via `np.mean`), which triggered a `_pickle.UnpicklingError` when the loader encountered `numpy._core.multiarray.scalar`. To fix this, I will explicitly set `weights_only=False` in the `torch.load` call, allowing the trusted local checkpoint to be deserialized correctly. Cite debug_lesson_1.
