### Strategy Outline
1.  **Configuration Setup**: We override the default `Config` parameters to enable `DEBUG` mode, reduce batch sizes, and set a temporary working directory. This ensures the script runs quickly (within seconds) and does not interfere with existing files.
2.  **Metric Verification**: We validate the `calculate_map5` function with a deterministic test case to ensure scoring logic is correct.
3.  **Data Pipeline**: We initialize the DataLoaders using `get_dataloaders`. We verify that the data is loaded correctly and that the shapes of the images and labels match the configuration.
4.  **Model Instantiation**: We initialize the `WhaleDenseNet` model. We perform a forward pass with and without labels to verify both training (margin loss) and inference (cosine similarity) paths.
5.  **Training Loop**: We execute a single training step (`train_one_epoch`) and a validation step (`validate`) using the provided trainer functions. We assert that loss values are valid.
6.  **Inference & Submission**: We save the model state to a checkpoint, then invoke `predict_ensemble` to generate predictions on the test set. Finally, we verify the structure and content of the generated `submission.csv`.
