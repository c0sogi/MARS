Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose the following optimized strategy. This solution implements a **Heterogeneous Ensemble with Iterative Self-Training**.

This strategy introduces a **Multi-Stage Pipeline** (Structural Innovation) to directly address the primary bottleneck identified in the lessons: **Data Scarcity** (76% singleton classes). By leveraging the unlabeled test data through high-confidence pseudo-labeling, we artificially expand the support for rare classes, allowing the proven architectures to form more robust decision boundaries than is possible with the training set alone.

# Model
I propose a **Heterogeneous Ensemble** consisting of **DenseNet121** and **ResNet50-IBN-a** models.

*   **Backbone 1: DenseNet121**
    *   *Rationale:* Retained for its superior performance in this few-shot, fine-grained regime due to efficient feature reuse **Cite solution_lesson_node_00016**.
*   **Backbone 2: ResNet50-IBN-a**
    *   *Rationale:* Retained for its **Instance-Batch Normalization (IBN)** blocks, which provide critical invariance to style/domain shifts (lighting, water color) that confuse standard CNNs **Cite solution_lesson_node_00043**.
*   **Common Components:**
    *   **Pooling:** **Global Average Pooling (GAP)**. We explicitly reject specialized pooling (GeM) **Cite solution_lesson_node_00010**.
    *   **Neck:** **Projection Head**. Structure: `Linear (Features -> 512)` $\to$ `Batch Normalization`. This is mandatory for adapting features to the metric loss **Cite solution_lesson_node_00015**. We explicitly **exclude Dropout** to prevent underfitting **Cite solution_lesson_node_00030**.
    *   **Head:** **ArcFace (Additive Angular Margin)**. Retained as the superior objective for high-cardinality classification **Cite solution_lesson_node_00012**.

# Data
*   **Splitting Strategy:** Strictly maintain the **Singleton-Inclusive Split**. All classes with only 1 sample must be in the training set **Cite solution_lesson_node_00002**.
*   **Resolution:** Fixed **320x320**.
    *   *Rationale:* This is the empirical sweet spot. We reject 224x224 (loss of detail) **Cite solution_lesson_node_00005**, 448x448 (overfitting) **Cite solution_lesson_node_00007**, and Progressive Resizing **Cite solution_lesson_node_00023**.
*   **Augmentation:**
    *   **Geometric:** **Conservative** Affine transformations (Rotation $\pm 20^\circ$, Scale 0.9-1.1) and Horizontal Flips. Aggressive distortions are avoided **Cite solution_lesson_node_00014**.
    *   **Photometric:** Brightness and Contrast only. Explicitly **exclude** Saturation and Hue jitter **Cite solution_lesson_node_00004**.

# Training
I propose a **Two-Stage Self-Training Pipeline**:

*   **Stage 1 (Teacher Training):**
    *   Train the heterogeneous ensemble (e.g., 2x DenseNet, 2x ResNet-IBN) on the original labeled training set.
    *   **Optimization:** Use **AdamW** with a **Conservative Learning Rate** (e.g., `3e-4`) to ensure stability **Cite solution_lesson_node_00038**.
    *   **Regularization:** Apply **Label Smoothing (0.1)**. This is critical for preventing overfitting on singleton classes **Cite solution_lesson_node_00024**.
    *   **Stopping:** Use **Early Stopping** with a relaxed patience to allow embedding convergence **Cite solution_lesson_node_00044**.

*   **Stage 2 (Pseudo-Labeling & Refinement):**
    *   **Generation:** Use the converged Stage 1 ensemble to predict labels for the **unlabeled test set**.
        *   Apply **Test-Time Augmentation (TTA)** during generation to maximize label quality **Cite solution_lesson_node_00011**.
    *   **Filtering:** Select test samples where the model's confidence exceeds a high threshold (e.g., 0.9) AND the predicted class is **NOT** `new_whale`.
        *   *Rationale:* This selectively mines new examples for known IDs, effectively turning "one-shot" classes into "two-shot" or "multi-shot" classes.
    *   **Retraining:** Train a new ensemble (or fine-tune the existing one) on the combined dataset (**Original Train + Pseudo-Labeled Test**). The additional data density allows the model to learn more generalizable intra-class features.

# Evaluation
*   **Protocol:** Implement **Test-Time Augmentation (TTA)** using Horizontal Flips for **both** the validation loop and final inference.
    *   *Rationale:* Consistency between validation and inference is crucial for accurate checkpoint selection **Cite solution_lesson_node_00011**.
*   **Inference:**
    1.  Load the **Best Checkpoints** from the Stage 2 ensemble.
    2.  Generate logits for all test images using Original + Flipped views.
    3.  Average the logits across all models and views.
    4.  Select the top 5 `Id`s.
