Based on the lessons learned from the previous experiments, I propose the following optimized strategy. This solution implements a **Validation-Optimized Homogeneous Ensemble** of **DenseNet121** models.

The core innovation here is not just "using an ensemble" (which failed in Idea 8 due to overfitting), but the structural integration of **Test-Time Augmentation (TTA)** into the **Model Selection Protocol** for every individual member of the ensemble. We explicitly reject the "train for fixed epochs" approach that ruined previous ensemble attempts and replace it with a strict **Best-Checkpoint Retention** strategy derived from the successful single-model experiments.

# Model
I propose an **Ensemble of 3 to 5 Independent DenseNet121 Models**, each featuring a **Projected ArcFace Head**.

*   **Backbone:** **DenseNet121**.
    *   *Rationale:* This architecture has been empirically proven to outperform both deeper variants (DenseNet169) and modern isotropic designs (ConvNeXt) in this specific few-shot, fine-grained regime. Its dense connectivity maximizes feature reuse, which is critical when training data is sparse **Cite solution_lesson_node_00016, solution_lesson_node_00020**.
*   **Pooling:** **Global Average Pooling (GAP)**.
    *   *Rationale:* We retain GAP and explicitly reject specialized pooling (GeM), which was shown to overfit to background artifacts **Cite solution_lesson_node_00010**.
*   **Neck (Critical Component):** **Projection Head**.
    *   *Structure:* `Batch Normalization` $\to$ `Dropout (0.5)` $\to$ `Linear (Features $\to$ 512)` $\to$ `Batch Normalization`.
    *   *Rationale:* This learnable bottleneck is essential for adapting the semantic features of the backbone to the geometric constraints of the ArcFace loss. Omitting it leads to severe underfitting **Cite solution_lesson_node_00015**.
*   **Head:** **ArcFace (Additive Angular Margin)**.
    *   *Rationale:* Superior to Cross-Entropy for high-cardinality classification by enforcing intra-class compactness **Cite solution_lesson_node_00012**.

# Data
*   **Splitting Strategy:** Strictly maintain the **Singleton-Inclusive Split**.
    *   *Rationale:* All classes with only 1 sample must be in the training set to prevent zero-shot validation errors. The validation set will consist solely of a stratified subset of multi-instance classes **Cite solution_lesson_node_00002**.
*   **Resolution:** Fixed **320x320**.
    *   *Rationale:* This is the empirical "sweet spot." It avoids the information loss of 224x224 **Cite solution_lesson_node_00005** and the overfitting risks of 448x448 **Cite solution_lesson_node_00007**. We explicitly reject progressive resizing **Cite solution_lesson_node_00023**.
*   **Augmentation:**
    *   **Geometric:** **Conservative** Affine transformations (Rotation $\pm 20^\circ$, Scale 0.9-1.1) and Horizontal Flips. We avoid aggressive distortions that degrade metric learning **Cite solution_lesson_node_00014**.
    *   **Photometric:** Brightness/Contrast only. Explicitly **exclude** Saturation/Hue jitter **Cite solution_lesson_node_00004**.

# Training
*   **Ensemble Protocol (Structural Innovation):** Train **3 to 5 independent models**, each initialized with a different random seed.
    *   *Correction from previous failures:* Unlike Idea 8, which failed by aggregating overfit models trained for a fixed duration **Cite solution_lesson_node_00027**, we will independently monitor each model and restore the **best checkpoint** based on validation performance before ensembling.
*   **Loss Function:** **ArcFace Loss**.
*   **Regularization:** **Enable Label Smoothing (0.1)**.
    *   *Rationale:* This is critical for singleton-heavy datasets. It prevents the model from overfitting to the artifacts of the single training example, a failure observed when smoothing was removed **Cite solution_lesson_node_00024**.
*   **Optimizer:** **AdamW** with **Cosine Annealing** scheduler.

# Evaluation
*   **Validation Consistency:** The validation loop for *each* ensemble member must use **Test-Time Augmentation (Horizontal Flip)** to calculate the metric.
    *   *Rationale:* Evaluating without TTA underestimates performance and leads to suboptimal checkpoint selection **Cite solution_lesson_node_00011**.
*   **Inference Strategy:**
    1.  Load the **Best Checkpoint** for each of the $N$ models (determined by the TTA-Validation metric).
    2.  For each test image, generate embeddings/logits from all $N$ models using both **Original** and **Horizontally Flipped** views ($2N$ predictions per image).
    3.  Average the logits across all views and models.
    4.  Select the top 5 `Id`s.
