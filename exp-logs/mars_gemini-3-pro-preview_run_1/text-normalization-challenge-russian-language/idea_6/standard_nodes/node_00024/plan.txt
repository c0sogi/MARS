To resolve the `torch.OutOfMemoryError` caused by the GPU's VRAM limit being exceeded during the backward pass, I will implement **Gradient Accumulation**. This technique allows training with a larger effective batch size (e.g., 128) by splitting it into smaller physical mini-batches (e.g., 32) that fit in memory, accumulating gradients over multiple steps before updating the model weights. This directly addresses the issue identified in **debug_lesson_5** (Cite debug_lesson_5) and aligns the physical batch size with hardware limits (Cite debug_lesson_4).

I will make the following changes:
1.  **`library/config.py`**: Add a `gradient_accumulation_steps` parameter to the `Config` class.
2.  **`library/neural_trainer.py`**: Update `_train_epoch` to scale the loss, accumulate gradients, and perform optimizer steps only after the specified number of accumulation steps.
3.  **`runfile.py`**: Reduce the physical `batch_size` to 32 and set `gradient_accumulation_steps` to 4 to maintain the effective batch size of 128.

    def _train_epoch(self, loader: DataLoader) -> float:
        """
        Runs one epoch of training with Gradient Accumulation.
        """
        self.model.train()
        total_loss = 0.0
        num_batches = 0

        self.optimizer.zero_grad()

        for batch_idx, batch in enumerate(loader):
            # Move batch to device
            src_left = batch["src_left"].to(DEVICE)
            src_target = batch["src_target"].to(DEVICE)
            src_right = batch["src_right"].to(DEVICE)
            tgt = batch["tgt"].to(DEVICE)  # Contains [SOS, ..., EOS]

            # Prepare Inputs and Targets for Teacher Forcing
            # Input to decoder: [SOS, t1, t2, ...] (exclude last EOS)
            tgt_input = tgt[:, :-1]
            # Target for loss: [t1, t2, ..., EOS] (exclude first SOS)
            tgt_output = tgt[:, 1:]

            # Forward Pass
            logits = self.model(src_left, src_target, src_right, tgt_input)

            # Reshape for Loss
            # logits: [Batch, Seq_Len, Vocab] -> [Batch*Seq_Len, Vocab]
            # tgt_output: [Batch, Seq_Len] -> [Batch*Seq_Len]
            loss = self.criterion(

            )

            loss.backward()

            total_loss += loss.item() * self.config.gradient_accumulation_steps
            num_batches += 1
