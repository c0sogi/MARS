This script demonstrates the end-to-end pipeline for the text normalization task using the provided library files. It performs the following steps:

1.  **Setup**: Configures the environment, sets random seeds, and creates a temporary working directory.
2.  **Data Preparation**: Creates "mini" versions of the training, validation, and test datasets from the provided metadata to ensure the demonstration runs quickly.
3.  **Tokenization**: Initializes and trains the `HybridTokenizer` (BPE + Char) on the mini dataset.
4.  **Symbolic Modeling**: Builds the `HierarchicalNgram` model (Trigram/Bigram/Unigram stats) for non-neural fallback.
5.  **Neural Data Processing**: Prepares context windows and sequences for the neural model using `DataManager`.
6.  **Model Initialization**: Instantiates the `DualGranularityTransformer` model.
7.  **Training**: Runs a short training loop (1 epoch) using `ModelTrainer` to update model weights and save checkpoints.
8.  **Inference**: Uses the `HybridRouter` to generate predictions on the mini test set, combining symbolic lookups and neural predictions.
9.  **Validation**: Verifies that artifacts (tokenizers, stats, checkpoints, submission) are created and formatted correctly.
