Implementation strategy:
1.  **Configuration**: Initialize the `Config` class with optimized hyperparameters to ensure the pipeline runs quickly (acting as a fast baseline) while utilizing the A100 GPU efficiently. I will reduce the `plain_subset_ratio` to 5% and `epochs` to 3, and increase `batch_size` to 1024.
2.  **Symbolic Training**: Execute `train_symbolic` to build the hierarchical N-gram memory (Trigram/Bigram/Unigram) from the training data.
3.  **Neural Training**: Execute `train_neural` to train the Character-Level Transformer. This handles the data processing (with the reduced subset ratio) and training loop automatically.
4.  **Validation**:
    *   Load the validation metadata (`val.csv`).
    *   Use `HybridPredictor` to generate predictions for the validation set.
    *   Merge predictions with ground truth to calculate the exact match accuracy.
    *   Print the "Final Validation Metric" in the required format.
5.  **Failure Analysis**:
    *   Compute error flags (1 for incorrect, 0 for correct).
    *   Calculate and print correlations between the error and input features (token length, presence of digits) to identify weaknesses.
6.  **Submission**:
    *   Check if the validation accuracy exceeds the specified threshold (0.9798075665557208).
    *   If successful, generate the submission file using `HybridPredictor` and move it to the required `./submission/submission.csv` path.
