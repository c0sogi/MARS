Based on the comprehensive analysis of the provided lessons and previous attempts, I propose a **Context-Anchored Hybrid Neuro-Symbolic System**. This solution synthesizes the efficiency of the hierarchical lookup (Lesson 00001) with a robustly trained neural generalization component (Lesson 00010), explicitly correcting the "context starvation" (Lesson 00012) and "input noise" (Lesson 00013) issues identified in prior experiments.

# Model
The architecture is a **Hybrid Cascade** composed of two distinct solvers and a deterministic router:

1.  **Symbolic Memory (The "Head" Solver):** A **Hierarchical N-gram Lookup** (Trigram $\to$ Bigram $\to$ Unigram). This component is retained to handle the 90%+ of tokens (`PLAIN`, `PUNCT`) that are deterministic and frequent. It provides $O(1)$ inference and 100% precision for memorized patterns (Cite solution_lesson_node_00001).
2.  **Neural Generalization (The "Tail" Solver):** A **Character-Level Encoder-Decoder Transformer**. This model is responsible for generating normalized text for combinatorial semiotic classes (e.g., numbers, dates, measures).
    *   **Architecture:** A standard Transformer (e.g., 4-6 layers) operating on a character-level vocabulary.
    *   **Input Scope:** Unlike the "Full Sentence" approach which failed due to noise (Cite solution_lesson_node_00013), and the "Window-1" approach which lacked inflectional cues, this model uses a **Fixed Context Window of $\pm$ 2 words**. This strikes the optimal balance between signal density and grammatical context.
3.  **Router:** A logic layer that directs traffic based on token content and memory availability. It prioritizes specific memories (Trigrams) but routes unknown combinatorial tokens (containing digits) to the neural model (Cite solution_lesson_node_00010).

# Data
1.  **Sequence Reconstruction:** Reconstruct full sentences from the tabular data using `sentence_id` and `token_id` to enable context extraction.
2.  **Context-Anchored Neural Dataset:** Construct a training set for the neural model that specifically addresses the "Context Starvation" failure (Cite solution_lesson_node_00012). The dataset will consist of:
    *   **Targeted Semiotics:** 100% of tokens from generative classes (`CARDINAL`, `DATE`, `MONEY`, `MEASURE`, `TELEPHONE`, `DECIMAL`, `ORDINAL`) and any `PLAIN` token containing digits.
    *   **Contextual Anchors:** A **massive subset (e.g., 30-50%) of standard `PLAIN` text**. Unlike previous iterations that used only 1-5%, this high volume is critical for the model to learn robust embeddings for the context words (the "background data"). This ensures that when the model encounters a number, it correctly interprets the grammatical case imposed by the surrounding context.
3.  **Feature Engineering:** Format the neural input as a concatenated string of characters: `[Prev_Word_2] [Prev_Word_1] <sep> [Target_Token] <sep> [Next_Word_1] [Next_Word_2]`.

# Training
1.  **Artifact Versioning:** Implement strict **configuration hashing** for all saved artifacts (dictionaries, model checkpoints). This ensures that changes to the data selection logic or architecture force a fresh training run, preventing the silent caching failures observed previously (Cite solution_lesson_node_00002).
2.  **Symbolic Training:** Perform a single-pass Maximum Likelihood Estimation on the *entire* dataset to build the N-gram frequency maps.
3.  **Neural Training:** Train the Character-Level Transformer from scratch on the **Context-Anchored Neural Dataset**.
    *   **Objective:** Cross-Entropy Loss with Label Smoothing (to handle valid variations).
    *   **Optimization:** Use the A100 GPU to train for sufficient epochs (e.g., 5-10) with a cosine learning rate schedule, ensuring the model converges on the complex inflection rules which were previously under-fitted.

# Evaluation
The inference pipeline processes the test set using the following **Priority Cascade**:
1.  **Step 1 (Specific Memory):** Query the **Trigram** lookup `(prev, target, next)`. If a match is found, return it immediately. This captures specific memorized phrases (e.g., "Chapter 1") with high precision.
2.  **Step 2 (Neural Generalization):** If no Trigram match is found, check if the token contains **digits** (Regex `\d`). If yes, construct the $\pm$ 2 window context and pass it to the **Neural Model**. This handles unseen numbers and dates.
3.  **Step 3 (General Memory):** If the token has no digits, back off to **Bigram** and then **Unigram** lookups.
4.  **Step 4 (Fallback):** If all lookups fail, return the original text (Identity).
