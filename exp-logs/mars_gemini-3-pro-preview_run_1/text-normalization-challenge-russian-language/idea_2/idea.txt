# Hybrid Cascade: N-gram Memory with Neural Numeral Generalization

### Model
I propose a **Hybrid Cascade Architecture** that integrates the efficiency of the previous statistical approach with a specialized neural network for complex semiotic classes.
1.  **Symbolic Memory (The "Head" Solver):** Retain the **Hierarchical N-gram Lookup** (Trigram $\to$ Bigram $\to$ Unigram) as the primary engine. This component effectively solves the "Head" of the distribution (standard words, punctuation) which constitutes >90% of the data, as proven by the high baseline performance (Cite solution_lesson_node_00001).
2.  **Neural Generalization (The "Tail" Solver):** Introduce a **Character-Level Seq2Seq Transformer**. This model is designed to handle "Generative" classes (e.g., numbers, dates, money) where the mapping is rule-based and combinatorial rather than fixed. Unlike the previous attempt, this model will be explicitly trained only on the subset of data requiring normalization logic.
3.  **Heuristic Router:** A deterministic routing layer based on input features (specifically, the presence of digits). This router directs traffic: standard text is processed by the N-gram Memory (fast, high precision), while complex tokens containing digits are sent to the Neural Model (robust generalization).

### Data
1.  **Global Construction:** Reconstruct full sentences from the `sentence_id` and `token_id` columns to preserve context.
2.  **Subset Filtering:**
    *   **Memory Set:** Use the entire training corpus to populate the N-gram frequency tables.
    *   **Neural Set:** Filter the training data to include only tokens belonging to semiotic classes that require normalization logic (e.g., `CARDINAL`, `DATE`, `MONEY`, `MEASURE`, `DECIMAL`, `TELEPHONE`).
3.  **Neural Preprocessing:** Tokenize the input at the character level (or byte level). Include a context window (previous word, next word) in the neural input to resolve ambiguities (e.g., distinguishing "2" in "Chapter 2" vs. "2 apples").

### Training
1.  **Artifact Versioning:** To prevent the silent failure observed previously, all saved artifacts (model weights, lookup tables) will be saved with a unique version identifier or hash in the filename, ensuring the pipeline does not load stale data from previous runs (Cite solution_lesson_node_00002).
2.  **Memory Construction:** Perform a single-pass Maximum Likelihood Estimation to build the N-gram hash maps.
3.  **Neural Training:** Train the Character-Level Transformer on the **Neural Set** using Cross-Entropy Loss. The model will learn to map the raw character sequence of a number/symbol (with context) to its normalized Russian text representation.

### Evaluation
The inference pipeline will process the test set token-by-token using the **Hybrid Cascade**:
1.  **Route:** Check if the raw token contains a digit (Regex `\d`).
2.  **Path A (Text):** If no digits are present, query the N-gram Hierarchy (Trigram $\to$ Bigram $\to$ Unigram $\to$ Identity).
3.  **Path B (Numeric):** If digits are present:
    *   First, check the **Trigram** layer. If the specific sequence (Context + Number) was seen in training (e.g., "Level 1"), use the memorized result.
    *   If not found, pass the token (with context) to the **Neural Model** to generate the normalized text.
    *   This ensures that common numeric phrases are retrieved instantly, while novel numbers are generated correctly.
