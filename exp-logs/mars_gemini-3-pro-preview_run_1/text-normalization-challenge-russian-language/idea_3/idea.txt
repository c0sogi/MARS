# Hybrid Neuro-Symbolic Transformer with Context-Aware Routing

### Model
I propose a **Hybrid Neuro-Symbolic Architecture** that explicitly divides the problem space into "Head" (frequent, deterministic) and "Tail" (rare, combinatorial) components, utilizing the best solver for each.

1.  **Symbolic Layer (The "Head" Solver):** This component retains the **Hierarchical N-gram Lookup** (Trigram $\to$ Bigram $\to$ Unigram) identified as highly effective for standard text (Cite solution_lesson_node_00001). It acts as a fast, high-precision memory for the 90%+ of tokens that are `PLAIN` or `PUNCT`, as well as frequent numeric phrases (e.g., "Page 1").
2.  **Neural Layer (The "Tail" Solver):** For complex semiotic tokens (numbers, dates, measures) that require generalization rather than memorization, I introduce a **Character-Level Encoder-Decoder Transformer**. Unlike previous generic RNN proposals, this model uses a Transformer backbone (e.g., a miniature T5-style architecture) to attend to the internal structure of the token (digits, symbols) and its surrounding context simultaneously.
    *   **Input:** A character sequence representing the `[Previous Word] <sep> [Target Token] <sep> [Next Word]`.
    *   **Output:** The normalized character sequence.
3.  **Inference Router:** A logic layer that arbitrates between the two solvers:
    *   **Step 1 (Specific Memory):** Check the **Trigram** lookup. If the exact sequence `(prev, target, next)` was seen frequently in training, return the memorized result immediately.
    *   **Step 2 (Generalization):** If the Trigram is missing, check if the token contains **digits** or special symbols. If yes, route it to the **Neural Layer**. This ensures that unseen numbers (e.g., "1,234.56") are handled by the model trained to read numbers, rather than falling back to a generic Unigram which would likely fail.
    *   **Step 3 (General Memory):** If the token has no digits and was not in the Trigram, back off to **Bigram** and then **Unigram** lookups (handling rare words or lower-cased variants).

### Data
1.  **Sequence Reconstruction:** Reconstruct full sentences from the tabular data using `sentence_id` and `token_id` to enable context extraction.
2.  **Neural Dataset Construction:** Create a specialized training subset for the Neural Layer. Filter the training data to include:
    *   All tokens belonging to semiotic classes (`CARDINAL`, `DATE`, `MONEY`, `MEASURE`, etc.).
    *   Any `PLAIN` token containing digits.
    *   A small random sample of `PLAIN` text to prevent the model from hallucinating on simple inputs.
3.  **Contextual Formatting:** Preprocess the neural inputs to include the immediate left and right neighbors. For example, if the sentence is "Chapter 5 starts", the input for "5" becomes `Chapter <sep> 5 <sep> starts`. This allows the Transformer to infer grammatical case (inflection) from the context.

### Training
1.  **Artifact Versioning:** To strictly prevent the silent caching failures observed previously, all saved model artifacts (dictionaries, checkpoints) will be named using a **configuration hash** (e.g., `ngram_stats_{hash}.npy`, `transformer_{hash}.pt`). This ensures that any change to the architecture or data selection forces a fresh training run (Cite solution_lesson_node_00002).
2.  **Symbolic Training:** Perform a single-pass Maximum Likelihood Estimation on the full dataset to build the N-gram frequency maps.
3.  **Neural Training:** Train the Character-Level Transformer on the **Neural Dataset** using Cross-Entropy Loss. Use a tokenizer that treats every character/byte as a token (vocab size ~256-1000) to handle arbitrary numeric formats without out-of-vocabulary issues.

### Evaluation
The inference pipeline processes the test set as follows:
1.  Reconstruct test sentences.
2.  For each token, query the **Trigram** table. If a match is found, use it.
3.  If no Trigram match, check the token content. If it contains digits `[0-9]`, batch it for the **Neural Transformer**.
4.  If it contains no digits, query the **Bigram** and **Unigram** tables.
5.  If all lookups fail (unseen non-numeric word), return the original text (Identity).
6.  Merge the Neural predictions back into the sequence and format for submission.
