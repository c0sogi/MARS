The issue is that the `HybridRouter` prioritizes the neural model for any token containing digits, causing it to skip the symbolic model's unigram and bigram lookups. This means that even if a simple digit token like "2" has been memorized as "two" in the unigram statistics, the router ignores this and sends it to the neural model (which produced garbage in the demo). The fix is to reorder the inference logic to check the symbolic backoff (Bigram and Unigram) *before* falling back to the neural model for complex tokens.
