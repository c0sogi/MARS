The following strategy outlines the implementation of the demonstration script:

1.  **Configuration Setup**: We will extend the provided `Config` class to create a `DemoConfig`. This configuration will point to a temporary working directory and use significantly reduced hyperparameters (e.g., smaller embedding dimensions, fewer layers, single epoch) to ensure the script runs quickly on the available hardware.

2.  **Data Subsampling**: To demonstrate the pipeline without processing the entire 7-million-row dataset, we will load the first few thousand rows from the provided metadata files (`train.csv`, `val.csv`, `test.csv`) and save them as "mini" datasets in the working directory. This allows the tokenizer and model training to execute in seconds rather than hours.

3.  **Component Execution & Verification**:
    *   **Tokenizer**: We will instantiate the `CharTokenizer`, fit it on the mini-dataset, and verify it correctly encodes/decodes text.
    *   **Symbolic Model**: We will train the `NgramLookup` on the mini-training data and assert that it correctly memorizes simple mappings (e.g., "word" -> "word").
    *   **Neural Training**: We will initialize the `Trainer` with the `DemoConfig` and run a single epoch of training. We will verify that the model artifacts (checkpoints) are created.
    *   **Hybrid Inference**: We will use the `HybridPredictor` to generate predictions for the mini-test set. We will verify that the output submission file follows the correct format and contains entries for the test IDs.

4.  **Cleanup**: All temporary artifacts will be stored in `./working/demo_run` to avoid clutter and ensure read-only compliance for input directories.
