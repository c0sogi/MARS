Based on the lessons learned, particularly the failure of local-window models to capture sufficient grammatical context for inflection (Cite solution_lesson_node_00012) and the proven efficiency of the hybrid approach (Cite solution_lesson_node_00010), I propose the following **Target-Aware Global-Context Hybrid** solution.

# Model
The architecture is a **Hybrid Neuro-Symbolic System** composed of two specialized solvers managed by a deterministic router:

1.  **Symbolic Solver (The "Head"):** Retain the **Hierarchical N-gram Lookup** (Trigram $\to$ Bigram $\to$ Unigram) as the primary engine. This component provides near-instant, perfect recall for the 90%+ of tokens (`PLAIN`, `PUNCT`) that are deterministic (Cite solution_lesson_node_00001).
2.  **Neural Solver (The "Tail"):** Replace the previous window-based network with a **Target-Aware Global-Context Transformer**.
    *   **Structural Innovation:** Instead of feeding a limited window (e.g., previous/next word) which failed to capture long-range dependencies required for correct inflection (Cite solution_lesson_node_00012), this model takes the **entire sentence** as input.
    *   **Target Marking:** To direct the model to the specific token requiring normalization, the target token is wrapped in special control tags within the sentence string (e.g., `... cost <tgt> $5 </tgt> to fix ...`). This allows the self-attention mechanism to utilize the full sentence context (e.g., the gender of a noun appearing early in the sentence) to generate the correctly inflected normalized text.
3.  **Router:** A logic layer that directs traffic. Tokens found in the N-gram lookup are solved symbolically. Tokens that are missing from the lookup *and* contain digits (indicating combinatorial complexity) are routed to the Neural Solver (Cite solution_lesson_node_00010).

# Data
1.  **Sequence Reconstruction:** Reconstruct full sentences from the tabular data using `sentence_id` to enable global context extraction.
2.  **Neural Dataset Composition:** Create a specialized training set for the Transformer that explicitly addresses the "context starvation" issue (Cite solution_lesson_node_00012):
    *   **Core Data:** Include 100% of tokens from semiotic classes (`DATE`, `MONEY`, `MEASURE`, etc.) and any token containing digits.
    *   **Contextual Anchor Data:** Include a **substantial subset (e.g., 30%) of `PLAIN` and `PUNCT` tokens**. Unlike previous iterations that used a minimal sample, this larger volume is necessary for the model to learn robust embeddings of the Russian language structure, which is a prerequisite for resolving the grammatical case of the "hard" tokens.
3.  **Input Formatting:** Preprocess neural inputs by converting the full sentence to a character sequence and inserting `<tgt>` and `</tgt>` markers around the token of interest.

# Training
1.  **Artifact Versioning:** All saved artifacts (dictionaries, model weights) will be saved with filenames containing a **configuration hash**. This strictly prevents the pipeline from silently loading stale data from previous experiments (Cite solution_lesson_node_00002).
2.  **Procedure:**
    *   **Symbolic:** Perform a single-pass Maximum Likelihood Estimation on the full dataset to build the N-gram maps.
    *   **Neural:** Train the Character-Level Transformer from scratch on the composite Neural Dataset. Use Cross-Entropy Loss with Label Smoothing to handle ambiguity. Given the larger dataset size (due to increased PLAIN text), utilize the A100 GPU with mixed-precision training to maximize throughput.

# Evaluation
1.  Reconstruct the test set sentences.
2.  Iterate through each token:
    *   **Step 1:** Query the Trigram/Bigram/Unigram hierarchy. If found, use the result.
    *   **Step 2:** If not found and the token contains digits, format the **entire sentence** with target markers and pass it to the Neural Solver.
    *   **Step 3:** Otherwise, fallback to the identity (return original text).
3.  Combine predictions and format for submission.
