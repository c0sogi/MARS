The strategy involves the following steps:
1.  **Parse Metadata**: Load `train_metadata.json` (dictionary with `images` and `annotations`) and `test_metadata.json` (list of image records). Merge training images with their annotations to associate `image_id` with `category_id`.
2.  **Path Resolution**: Implement a dynamic path resolution strategy. Since the metadata `file_name` might differ slightly from the physical directory structure (e.g., containing prefixes like `h22-train/`), the script will check a sample file against the `./input` directory to determine the correct relative path format (e.g., prepending `train_images/` or stripping prefixes).
3.  **Stratified Split**: Perform an 80-20 train-validation split. To handle the large number of classes (some with only 1 sample), separate "singleton" classes (count < 2) and force them into the training set to ensure no class is lost. Apply stratified splitting on the remaining data using `sklearn`.
4.  **Save Metadata**: Save the processed dataframes to `metadata/train.csv`, `metadata/val.csv`, and `metadata/test.csv` with columns `image_id`, `file_path`, and `category_id` (for train/val).
5.  **Validation**: Immediately load the generated CSVs to verify file existence (checking a random sample of 1000 paths) and confirm that the validation set does not contain classes unseen in the training set.
