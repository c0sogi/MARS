Based on the provided task and constraints, here is a proposal for a highly efficient baseline approach.

### **Linear Probing with Weighted Loss**

#### **Model**
The proposed model utilizes a **ResNet-18** architecture, chosen for its balance of speed and widely accepted performance as a standard baseline.
*   **Frozen Backbone:** The convolutional backbone of the ResNet-18 is initialized with pre-trained ImageNet weights and **frozen** (all gradients disabled). This ensures the feature extraction layers remain static, significantly reducing the computational cost of backward passes and memory usage.
*   **Classification Head:** The existing fully connected layer is replaced with a new, trainable linear layer that projects the 512-dimensional feature vector directly to the 15,501 species classes.
*   **Distinction:** Unlike Model 1 (which implies full network training) or Model 4 (which uses Gradient Boosted Trees), this approach uses a simple linear classifier (Logistic Regression) on top of deep features, trained via standard backpropagation.

#### **Data**
To maximize throughput and establish a consistent baseline:
*   **Preprocessing:** All images (training and test) are resized to a fixed resolution of **224x224** pixels.
*   **Normalization:** Pixel values are normalized using the standard ImageNet mean and standard deviation to match the pre-trained backbone's expected input distribution.
*   **Augmentation:** No data augmentation (e.g., flips, rotations) is applied. This minimizes CPU overhead during data loading and ensures the baseline reflects the raw power of the pre-trained features.

#### **Training**
*   **Loss Function:** To directly address the **Macro F1** metric and the class imbalance (17:1 ratio), the model is trained using **Weighted Cross-Entropy Loss**. Class weights are pre-calculated as the inverse of the class frequency in the training set. This penalizes errors on rare classes more heavily, encouraging the model to learn the minority classes required for a high Macro F1 score.
*   **Optimizer:** An Adam optimizer is used to update **only** the weights of the final linear classification layer.
*   **Procedure:** Because the backbone is frozen, the model converges very quickly. Training will proceed for a small number of epochs (e.g., 3-5) until the loss on the validation set stabilizes.

#### **Evaluation**
*   **Inference:** Test images are processed through the frozen backbone and the trained linear head.
*   **Prediction:** The class corresponding to the highest logit value (argmax) is selected as the predicted `category_id`.
*   **Validation:** The Macro F1 score is monitored on the validation set to ensure the weighted loss effectively balances performance across all 15,501 species.
