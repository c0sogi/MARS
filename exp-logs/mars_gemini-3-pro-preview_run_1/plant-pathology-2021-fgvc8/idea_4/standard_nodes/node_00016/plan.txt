    *   Track the best F1-score and save the model checkpoint whenever the score improves.

4.  **Validation & Metrics**:
    *   After training, reload the best model checkpoint to ensure evaluation on the optimal weights.
    *   Run inference on the full validation set in evaluation mode (`torch.no_grad()`).
    *   Calculate the exact Mean F1-Score using the provided utility and print it in the required format: `Final Validation Metric: <value>`.

5.  **Failure Analysis**:
    *   Calculate the error magnitude for each validation sample (defined as the mean absolute error between predicted probabilities and binary targets).
    *   Extract image metadata (Width, Height, Aspect Ratio) for all validation images. This involves reading the image dimensions efficiently.
    *   Compute and print the Pearson correlation coefficients between the error magnitude and these input features to identify systematic failures.

6.  **Submission**:
    *   Compare the final validation metric against the strict threshold (`0.9187550291577454`).
    *   If the threshold is met, load the test dataset, run inference, format the predictions (space-delimited labels), and save the `submission.csv` to the specified directory.
