Instead of returning a single score, the dataset will convert the score into a binary vector where the first $S-1$ elements are 1s and the rest are 0s (e.g., a score of 3 becomes `[1, 1, 0, 0, 0]`). This ensures the target shape aligns with the model's output logits, satisfying the contract required by the loss function (Cite debug_lesson_4).
