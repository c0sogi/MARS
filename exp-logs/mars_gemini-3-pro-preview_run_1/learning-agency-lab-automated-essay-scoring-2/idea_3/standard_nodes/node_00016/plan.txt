I will optimize the solution by transitioning from an Ordinal Classification approach using `deberta-v3-small` to a Regression approach using `deberta-v3-base`.

**Strategy:**
1.  **Model Upgrade**: Switch the backbone to `microsoft/deberta-v3-base`. Empirical findings indicate that the `base` model provides a higher performance ceiling needed to surpass the 0.8203 QWK threshold, which the `small` model struggled to reach (Cite {solution_lesson_node_00009}).
2.  **Loss Function Alignment**: Replace the Ordinal Regression (5 binary classifiers) with Standard Regression using Mean Squared Error (MSE). MSE aligns mathematically with the Quadratic Weighted Kappa metric, penalizing larger errors more aggressively than the linear penalty of ordinal classification (Cite {solution_lesson_node_00012}).
3.  **Hyperparameters**: Set `epochs` to 3 to prevent overfitting, as observed in previous experiments where validation loss degraded after epoch 3 (Cite {solution_lesson_node_00010}).

class OrdinalHead(nn.Module):
    """
    Custom Head for Ordinal Regression.
    Consists of MeanPooling followed by a Linear layer.
    """

    def __init__(self, hidden_size, num_labels):
        super(OrdinalHead, self).__init__()
        self.pooler = MeanPooling()
        self.fc = nn.Linear(hidden_size, num_labels)

    def forward(self, last_hidden_state, attention_mask):
        feature = self.pooler(last_hidden_state, attention_mask)
        logits = self.fc(feature)
        return logits
