This script demonstrates the end-to-end usage of the provided library for the Essay Scoring task. It performs the following steps:
1.  **Configuration Setup**: Overrides default configuration parameters to run in "debug" mode (using a small subset of data and fewer epochs) for rapid execution.
2.  **Data Preparation**: Instantiates the `EssayDataset` for training and validation, verifying the data loading and ordinal label encoding logic.
3.  **Model Initialization**: Loads the `OrdinalModel` (DeBERTa-v3-small backbone with a custom ordinal head) and verifies the output shape of a forward pass.
4.  **Training Loop**: Sets up the optimizer with Layer-wise Learning Rate Decay (LLRD) and runs the training loop for one epoch to demonstrate the training and validation process.
5.  **Inference**: Generates predictions on the test set and creates a submission file.
6.  **Metric Verification**: Validates the Quadratic Weighted Kappa (QWK) metric function with known inputs.
