Based on the progression of empirical findings and the specific lessons learned, I propose the following optimized strategy. This solution introduces a **Multi-Stage Domain Adaptation Pipeline** combined with a **Cross-Validation Ensemble**.

This approach addresses the data scarcity issue by leveraging unlabeled test data and maximizes the stability and performance of the large backbone identified as the state-of-the-art in **Cite {solution_lesson_node_00020}**.

# Model
**Architecture**:
- **Backbone**: We will utilize **DeBERTa-v3-Large**.
    - **Rationale**: Previous experiments confirmed that model capacity is the primary driver of performance, with the Large variant significantly outperforming Base and Small versions **Cite {solution_lesson_node_00020}**. We retain this backbone to ensure sufficient representational power for capturing complex argumentation flows.
- **Pooling Mechanism**: We will employ **Attention Pooling** (Weighted Layer Pooling).
    - **Rationale**: As established in **Cite {solution_lesson_node_00020}**, this mechanism is superior to standard Mean Pooling because it allows the model to dynamically weight the importance of different sentences, focusing on critical rhetorical structures while downweighting filler text.
- **Head**: A simple Linear Regression layer outputting a scalar score.

# Data
**Preprocessing**:
- **Corpus Construction (Innovation)**: We will create a combined text corpus consisting of the `full_text` from both `train.csv` and `test.csv`.
    - **Rationale**: The training set contains only ~12.5k samples. By including the test set (unlabeled), we significantly increase the volume of text available for the model to learn the specific linguistic nuances, vocabulary, and syntax of student essays before supervised fine-tuning.
- **Tokenization**: Use the DeBERTa-v3-Large tokenizer.
- **Sequence Length**: Maintain the maximum sequence length of **1024 tokens**.
    - **Rationale**: This length is necessary to capture the full narrative arc and "argumentation flow" without aggressive truncation, which was a limitation of the baseline models **Cite {solution_lesson_node_00001}**.

# Training
**Procedure**:
This solution implements a **Two-Stage Training Pipeline**:

**Stage 1: Domain-Adaptive Pre-training (DAPT)**
- **Objective**: Train the DeBERTa-v3-Large backbone on the combined corpus (Train + Test) using the **Masked Language Modeling (MLM)** objective.
- **Rationale**: This unsupervised stage allows the model to adapt its internal representations to the specific domain of student writing (e.g., common misspellings, sentence structures) without requiring labels. This effectively boosts the "lexical signal" baseline **Cite {solution_lesson_node_00001}** before the model attempts the scoring task.

**Stage 2: Cross-Validated Supervised Fine-Tuning**
- **Strategy**: Fine-tune the adapted backbone using **5-Fold Cross-Validation (CV)**.
    - **Rationale**: Previous attempts failed when data was subsampled to fit time constraints **Cite {solution_lesson_node_00019}**. CV ensures that **100% of the training data** is utilized across the folds, maximizing the signal available to the ensemble while providing robust out-of-fold (OOF) predictions for validation.
- **Loss Function**: **Mean Squared Error (MSE)**.
    - **Rationale**: We strictly adhere to MSE as it mathematically aligns with the Quadratic Weighted Kappa metric, avoiding the sub-optimal penalty structure of Ordinal Classification **Cite {solution_lesson_node_00012}**.
- **Optimization**: Use **Layer-wise Learning Rate Decay (LLRD)**.
    - **Rationale**: As proven in **Cite {solution_lesson_node_00020}**, LLRD is critical for stabilizing the training of Large models, preventing catastrophic forgetting of the pre-trained (and now domain-adapted) features.

# Evaluation
**Inference Strategy**:
- **Ensembling**: For each essay in the test set, generate predictions using all 5 models from the Cross-Validation folds and compute the **mean** of these predictions.
    - **Rationale**: Ensembling reduces the variance associated with stochastic training noise **Cite {solution_lesson_node_00010}** and generally improves generalization over any single model.
- **Post-Processing**: Clip the averaged predictions to the range [1, 6] and round to the nearest integer.
    - **Rationale**: This heuristic remains the most effective method for converting the continuous regression output into the required discrete scoring format **Cite {solution_lesson_node_00001}**.
