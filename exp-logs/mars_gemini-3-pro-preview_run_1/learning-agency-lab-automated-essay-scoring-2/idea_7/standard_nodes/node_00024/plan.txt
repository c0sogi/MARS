The implementation strategy follows a strict optimization for the 2-hour time limit while adhering to the two-stage stacking architecture. 

1.  **Configuration Overrides**: I will override the default `Config` to reduce `epochs` to 1 and `num_folds` to 3. I will also disable the MLM pre-training (`mlm_epochs=0`) as it is computationally expensive and the supervised signal is sufficient for a baseline.
2.  **Data Subsampling**: To ensure the pipeline finishes quickly, I will subsample the training data to 5,000 samples. This provides enough diversity for the model to learn while drastically reducing training time.
3.  **Silent Execution**: I will monkey-patch `tqdm` to suppress progress bars and set logging levels to `ERROR` to meet the requirement of only printing necessary information.
4.  **Pipeline Execution**:
    *   **Level 1 (DeBERTa)**: Train on the subsampled data using `trainer.run_training`.
    *   **Level 2 (Stacking)**: Train a LightGBM regressor on the Out-of-Fold (OOF) predictions and meta-features.
    *   **Validation**: Load the hold-out validation set (`metadata/val.csv`), run inference using the ensemble of Level 1 models and the Level 2 stacker, and compute the QWK metric.
    *   **Failure Analysis**: Calculate correlations between prediction errors and meta-features on the validation set.
    *   **Submission**: If the validation metric meets the threshold, generate predictions for the test set and save `submission.csv`.
