Implementation Strategy:
1.  **Configuration**: I will override the default `Config` to set `EPOCHS = 1` and skip pre-training (`MLM_EPOCHS = 0`) to ensure the pipeline completes within the 2-hour limit while still training the powerful DeBERTa-v3-Large backbone.
2.  **Training**: I will execute `run_training()` from the library. This performs 5-fold cross-validation on the training data (`metadata/train.csv`), saves model checkpoints, and generates Out-of-Fold (OOF) predictions required for the stacking stage.
3.  **Validation**: I will load the hold-out validation set (`metadata/val.csv`). I will run inference using the 5 saved checkpoints, averaging their predictions to form a robust ensemble estimate. I will then compute the Quadratic Weighted Kappa (QWK) on this set.
4.  **Failure Analysis**: I will calculate the absolute residuals (errors) of the model on the validation set and compute their Pearson correlation with text features (e.g., character count, word count) to identify bias.
5.  **Submission**: I will check if the validation QWK exceeds the specified threshold (0.8274925140324321). If satisfied, I will call `run_stacking()`, which trains the Level 2 meta-learner (Ridge Regression) on the OOF predictions and generates the final submission for the test set.
