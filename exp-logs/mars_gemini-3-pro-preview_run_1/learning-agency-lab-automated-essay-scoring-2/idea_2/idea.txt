# Solution Proposal: Contextual Transformer Regressor (DeBERTa)

## Model
To address the limitations of the previous Deep Averaging Network (DAN), specifically its inability to capture "structural context (syntax, coherence, argumentation flow)" Cite {solution_lesson_node_00001}, I propose replacing the static embedding backbone with a **Pre-trained Contextual Transformer**, specifically **DeBERTa-v3-small**.

1.  **Backbone**: The model will utilize the DeBERTa-v3-small architecture. Unlike the DAN, which treats the essay as a "bag-of-words," this backbone uses self-attention mechanisms to process the sequence of tokens, effectively capturing the syntactic relationships, word order, and long-range dependencies required to distinguish high-quality essays from poor ones.
2.  **Pooling Mechanism**: We will retain the concept of aggregating information but upgrade it to **Contextual Mean Pooling**. Instead of averaging static word vectors, we will compute the average of the *contextualized* token embeddings output by the final transformer layer. This preserves the "lexical signal" strength identified in the previous lesson Cite {solution_lesson_node_00001} while integrating the structural nuance learned by the Transformer.
3.  **Regression Head**: The pooled representation will be fed into a simple linear regressor (a single dense layer) to output a continuous scalar score.

## Data
1.  **Tokenization**: We will replace the whitespace tokenizer with the specific **SentencePiece/Subword tokenizer** associated with DeBERTa-v3. This allows the model to handle rare words and morphological variations more effectively than the fixed vocabulary approach used previously.
2.  **Sequence Length Management**: The EDA showed a mean word count of ~368 and a max of ~1312. To minimize information loss while fitting within GPU memory, we will set a maximum sequence length of **1024 tokens**. This covers the vast majority of essays fully, addressing the need to see the "argumentation flow" Cite {solution_lesson_node_00001} without aggressive truncation.

## Training
1.  **Objective**: We will retain the **Mean Squared Error (MSE)** loss function. While the previous model suffered from regression to the mean, this was attributed to the model's inability to perceive structural features rather than the loss function itself. With the stronger backbone, MSE remains an effective proxy for the Quadratic Weighted Kappa metric.
2.  **Optimization**: We will use the **AdamW** optimizer with a linear learning rate scheduler (warmup followed by decay).
3.  **Regularization**: To prevent overfitting on this relatively small dataset (12k samples), we will apply standard dropout within the regression head and potentially use weight decay.

## Evaluation
1.  **Inference**: The model will predict a continuous floating-point score for each essay in the test set.
2.  **Post-Processing**: We will strictly exploit the successful post-processing strategy from the previous solution: clipping the predictions to the [1, 6] range and rounding them to the nearest integer Cite {solution_lesson_node_00001}. This ensures the output format matches the competition requirements while bridging the gap between the regression objective and the ordinal classification target.
