Implementation strategy:
1.  **Configuration**: Initialize the `Config` class and modify it for a "fast baseline" execution. This involves reducing the number of epochs to 1 and creating a smaller subset (4,000 samples) of the training data to ensure the script completes quickly (well within the 2-hour limit).
2.  **Data Preparation**: Load the training metadata, sample the subset, and save it to a temporary file. Update the configuration paths to point to this subset. Use `get_dataloaders` to prepare training, validation, and test loaders, leveraging caching where appropriate.
3.  **Model Initialization**: Instantiate the `EssayScorerModel` (DeBERTa-v3-Large with Attention Pooling) and move it to the GPU.
4.  **Optimization**: Configure the optimizer with Layer-wise Learning Rate Decay (LLRD) and a cosine schedule with warmup using the provided utility functions.
5.  **Training**: Execute the training loop using `train_fn`. The loop handles gradient accumulation and saves the best model based on validation QWK.
6.  **Validation & Analysis**: Load the best saved model. Compute the final QWK on the full validation set. Perform failure analysis by calculating the correlation between the model's absolute error and the essay length (character count).
7.  **Submission**: Check if the final validation QWK exceeds the specified threshold (0.8203336917523225). If it does, generate predictions for the test set, apply post-processing (clipping and rounding), and save the `submission.csv`.
