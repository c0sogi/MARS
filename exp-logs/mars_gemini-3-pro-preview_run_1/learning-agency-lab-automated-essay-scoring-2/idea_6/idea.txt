Based on the empirical evidence and lessons learned from the previous experiments, I propose the following optimized strategy. This solution implements a **Domain-Adaptive Adversarial Pipeline**, combining unsupervised knowledge transfer with robust supervised fine-tuning to maximize the potential of the large-scale backbone.

# Model
**Architecture**:
- **Backbone**: We will persist with the **DeBERTa-v3-Large** architecture.
    - **Rationale**: Previous experiments conclusively demonstrated that model capacity is the dominant factor in performance, with the "Large" variant significantly outperforming "Base" and "Small" versions **Cite {solution_lesson_node_00020}**. We must retain this high-capacity backbone to capture the complex "argumentation flow" that smaller models miss **Cite {solution_lesson_node_00001}**.
- **Pooling Mechanism**: We will use **Attention Pooling** (Weighted Layer Pooling).
    - **Rationale**: As validated in **Cite {solution_lesson_node_00020}**, this mechanism outperforms standard mean pooling by allowing the model to dynamically weigh the importance of specific sentences, filtering out noise and focusing on rhetorical structure.
- **Head**: A simple Linear Regression layer outputting a scalar score.

# Data
**Preprocessing**:
- **Corpus Construction (Stage 1)**: We will construct a combined unlabeled corpus containing the `full_text` from both `train.csv` and `test.csv`.
- **Tokenization**: Use the **DeBERTa-v3-Large** tokenizer (SentencePiece).
- **Sequence Length**: Maintain the maximum sequence length of **1024 tokens**.
    - **Rationale**: This length is critical for covering the full narrative arc of the essays without aggressive truncation, ensuring the model perceives the holistic context **Cite {solution_lesson_node_00001}**.

# Training
**Procedure**:
This solution introduces a **Two-Stage Training Pipeline** augmented with **Adversarial Weight Perturbation (AWP)**:

**Stage 1: Domain-Adaptive Pre-training (DAPT)**
- **Objective**: Train the DeBERTa-v3-Large backbone on the combined corpus (Train + Test) using the **Masked Language Modeling (MLM)** objective.
- **Rationale**: This unsupervised stage adapts the generic pre-trained weights to the specific linguistic nuances, spelling errors, and syntax of student essays. This enhances the "lexical signal" **Cite {solution_lesson_node_00001}** and provides a better initialization for the scoring task.

**Stage 2: Adversarial Supervised Fine-Tuning**
- **Strategy**: Fine-tune the adapted backbone using **5-Fold Cross-Validation**.
    - **Rationale**: We must utilize **100% of the training data** to avoid the performance degradation observed when subsampling **Cite {solution_lesson_node_00019}**. Cross-validation also mitigates the stochastic noise identified in **Cite {solution_lesson_node_00010}**.
- **Loss Function**: **Mean Squared Error (MSE)**.
    - **Rationale**: We adhere to MSE as it mathematically aligns with the Quadratic Weighted Kappa metric, avoiding the sub-optimal linear penalties of Ordinal Classification **Cite {solution_lesson_node_00012}**.
- **Optimization Strategy (Innovation)**:
    - **Layer-wise Learning Rate Decay (LLRD)**: Apply decaying learning rates from the head to the backbone to preserve pre-trained features **Cite {solution_lesson_node_00020}**.
    - **Adversarial Weight Perturbation (AWP)**: During fine-tuning, we will inject adversarial perturbations into the model's weights that maximize the loss, and then update the model to minimize this "worst-case" loss. This flattens the loss landscape and improves generalization on unseen test data, addressing the "regression to the mean" issue by forcing the model to learn more robust decision boundaries.

# Evaluation
**Inference Strategy**:
- **Ensembling**: Generate predictions for each test essay using all 5 models from the Cross-Validation folds and compute the **mean**.
    - **Rationale**: Averaging across folds reduces variance and improves stability **Cite {solution_lesson_node_00010}**.
- **Post-Processing**: Clip the averaged predictions to the range [1, 6] and round to the nearest integer.
    - **Rationale**: This heuristic remains the most effective method for bridging the continuous regression output with the discrete scoring format **Cite {solution_lesson_node_00001}**.
