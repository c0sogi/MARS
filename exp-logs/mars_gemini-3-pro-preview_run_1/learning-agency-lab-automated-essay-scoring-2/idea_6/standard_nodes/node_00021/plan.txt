3.  **Supervised Fine-Tuning (Stage 2)**: Implement a 5-Fold Cross-Validation loop on the training set (`metadata/train.csv`). For each fold:
    *   Initialize the `EssayModel` with the weights from the MLM stage.
    *   Train for 1 epoch using the `train_fn` (which includes AWP) and `valid_fn`.
    *   Save the best model checkpoint.
4.  **Final Validation**: Load the hold-out validation set (`metadata/val.csv`). Generate predictions using an ensemble (average) of the 5 trained fold models. Calculate and print the Quadratic Weighted Kappa score.
5.  **Failure Analysis**: Calculate the correlation between the absolute prediction error and the essay length (character count) on the validation set to identify potential biases.
6.  **Submission**: If the validation score exceeds the specified threshold, generate predictions for the test set (`metadata/test.csv`) using the ensemble and save the result to `submission.csv`.
