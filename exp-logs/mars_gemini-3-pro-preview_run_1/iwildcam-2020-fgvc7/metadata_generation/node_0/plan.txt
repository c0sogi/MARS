The strategy to implement the metadata generation script is as follows:

1.  **Setup and Imports**: Import necessary libraries (`os`, `json`, `pandas`, `numpy`, `sklearn.model_selection`). Define constants for input and output directories (`./input`, `./metadata`) and the random state (42).
2.  **Data Loading Functions**:
    *   Create a function to load the training annotations from `iwildcam2020_train_annotations.json`. This file follows the COCO format. We will extract image information (IDs and filenames) and annotations (categories).
    *   Map image IDs to their filenames and category IDs. If an image has no annotation, assign it category `0` (empty), as per the task description. If multiple annotations exist, we will take the first one (a common simplification for metadata generation when specific hierarchy rules aren't provided).
    *   Create a function to load test information from `iwildcam2020_test_information.json` to get test image IDs and filenames.
3.  **DataFrame Construction**:
    *   Construct a pandas DataFrame for the training data with columns `image_id`, `file_path`, and `category_id`. Ensure file paths are relative to `./input` (e.g., `train/<filename>`).
    *   Construct a pandas DataFrame for the test data with columns `image_id` and `file_path`.
4.  **Stratified Splitting**:
    *   Check the distribution of the `category_id` column in the training data.
    *   Identify "rare" classes (those with fewer than 2 samples) which cannot be stratified in an 80:20 split.
    *   Separate these rare samples to be forced into the training set.
    *   Perform a stratified 80:20 split on the remaining "common" data using `train_test_split` with `random_state=42`.
    *   Combine the split common data with the rare data to form the final `train` and `validation` sets.
5.  **Saving Metadata**:
    *   Create the `./metadata` directory.
    *   Save `train.csv`, `val.csv`, and `test.csv` to this directory.
6.  **Verification**:
    *   **Stats**: Print the shape and class distribution summary of the generated datasets.
    *   **File Existence**: Randomly sample 1000 paths from the generated metadata and verify they exist in `./input`. If the missing ratio exceeds 0.5, raise a `FileNotFoundError`.
    *   **Split Validation**: Verify the validation set size is approximately 20% of the original split-able data and assert that the split was performed (checking that the validation set is not empty).
