# Baseline Approach: Detector-Guided Single-Stream CNN

### Model
I propose a **Detector-Guided Single-Stream CNN** that synthesizes the end-to-end simplicity of **Model 1** with the object-centric philosophy of **Model 4**. Instead of processing the entire high-resolution scene (which wastes computation on background) or employing complex attention mechanisms over multiple crops, this architecture focuses on a single, deterministic "Region of Interest" (RoI).

The architecture consists of a lightweight, pre-trained backbone (e.g., ResNet-18 or EfficientNet-B0) followed by a global average pooling layer and a simple linear classification head. The key design choice is the input mechanism: the network is fed a single image patch that represents the most likely location of an animal, derived directly from the provided MegaDetector metadata. This allows the model to utilize standard, efficient 224x224 input dimensions while maintaining high resolution on the animal itself.

### Data
Preprocessing will focus on constructing the optimal input patch for each sample using the MegaDetector JSON:

1.  **RoI Extraction**: For every image, check the MegaDetector results.
    *   **Animal Present**: If detections exist, identify the bounding box with the highest confidence score. Crop the image to this box (adding a small context margin).
    *   **Empty/No Detection**: If no detections exist (or confidence is below a low threshold), use the entire original image.
2.  **Resizing**: Resize the extracted patch (or full image) to a standard resolution (e.g., 224x224 pixels). This ensures consistent input sizes for batching without the heavy computational cost of processing large megapixel images.
3.  **Normalization**: Apply standard normalization using ImageNet mean and standard deviation values.
4.  **Augmentation**: Apply minimal augmentations—specifically Random Horizontal Flips—to the training stream to encourage basic invariance without slowing down the data loader.

### Training
The training procedure prioritizes stability and convergence speed:

*   **Loss Function**: Use **Weighted Cross-Entropy Loss**. Calculate class weights inversely proportional to the class frequencies in the training set. This is a lightweight method to handle the significant imbalance between the "Empty" class and rare species without the complexity of Focal Loss.
*   **Optimizer**: Use the **Adam** optimizer with a default learning rate (e.g., 1e-4) and a standard weight decay.
*   **Scheduler**: Implement a simple **Step Learning Rate Scheduler**, decaying the learning rate by a factor of 0.1 after a fixed number of epochs (e.g., halfway through the allotted time).
*   **Strategy**: Fine-tune the entire network (backbone and head) end-to-end. This allows the feature extractors to adapt to the specific characteristics of camera trap imagery (e.g., infrared lighting, motion blur) better than a frozen backbone would.

### Evaluation
Evaluation on the test set will mirror the training preprocessing to ensuring consistency:

1.  **Input Generation**: For each test image ID, look up the corresponding MegaDetector result. Extract the highest-confidence crop or the full image if no detection is found.
2.  **Inference**: Pass the resized input tensor through the trained model to obtain logits.
3.  **Prediction**: Apply a Softmax function to the logits and select the class index with the maximum probability as the final prediction. No test-time augmentation (TTA) or ensemble voting will be used.
