The following script demonstrates the end-to-end usage of the provided machine learning pipeline components. It covers data loading with context-aware cropping, model initialization, training loop execution, and inference generation.

To ensure the demonstration runs quickly and reliably within the constraints:
1.  **Data Subsetting**: It creates small subsets (16 samples) of the training and test metadata to verify pipelines without processing the full dataset.
2.  **Speed Optimization**: The model is initialized with `pretrained=False` to skip downloading weights, and training is limited to 1 epoch with a small batch size.
3.  **Configuration Overrides**: It temporarily modifies `config` paths to point to the generated subsets for the inference step.
4.  **Verification**: Assertions are placed at key steps to validate data shapes, model output dimensions, loss calculation, and file generation.
