The error `CUDA error: device-side assert triggered` occurs because the model is configured with `NUM_CLASSES = 185` (expecting target indices in `[0, 184]`), but the dataset provides raw category IDs which are sparse and extend up to 250. This causes an index out-of-bounds error in the loss function.

To fix this, I will implement a label mapping strategy (Cite debug_lesson_2). I will modify `library/dataset.py` to create a mapping from raw `category_id` to contiguous indices `[0, N-1]` based on the training metadata, and apply this mapping in `CameraTrapDataset`. I will also modify `library/engine.py` to map the model's predicted indices back to the original category IDs when generating the submission.
