The following implementation orchestrates the sentence infilling task using a Gated Convolutional Sequence Labeler. The script is designed to run efficiently within the time constraints by limiting the dataset size for the baseline training while ensuring full functionality, including validation with Levenshtein distance, failure analysis, and submission generation.

**Implementation Strategy:**
1.  **Configuration Override**: Adjusts `Config` parameters (sample size, epochs) to ensure the "fast baseline" completes within the 2-hour limit on the provided hardware.
2.  **Data Pipeline**: Initializes the vocabulary and loads training, validation, and test dataloaders using the provided library functions. It leverages caching to speed up data loading.
3.  **Model Setup**: Instantiates the `GatedInfillingModel`, moves it to the GPU, and sets up the AdamW optimizer and OneCycleLR scheduler.
4.  **Training Loop**: Trains the model for a fixed number of epochs, saving the best checkpoint based on validation loss.
5.  **Validation & Analysis**:
    *   Loads the best model.
    *   Iterates through the validation set to generate predictions.
    *   Reconstructs both the ground truth and predicted sentences.
    *   Computes the **Levenshtein distance** (edit distance) as the primary validation metric.
    *   Performs failure analysis by calculating the correlation between sentence length and error magnitude.
6.  **Submission**: Generates the final `submission.csv` for the test set using the trained model.
