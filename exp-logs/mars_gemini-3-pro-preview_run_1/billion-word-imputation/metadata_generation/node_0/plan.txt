The strategy is to create a robust Python script that reads the input text datasets, handles potential format differences (CSV vs. raw text), and generates the required metadata splits.

1.  **Data Loading & Format Detection**: The script will inspect `train_v2.txt`. Based on the first line, it will determine if the file is a CSV (with headers) or a raw text file (one sentence per line). It will load the data into a Pandas DataFrame accordingly. `test_v2.txt` is known to be CSV.
2.  **Splitting**: We will use `sklearn.model_selection.train_test_split` to create a training and validation set with an 80:20 ratio, using a fixed random state (42) for reproducibility.
3.  **Metadata Generation**: The script will save the split datasets (`train.csv`, `val.csv`) and the test dataset (`test.csv`) to the `./metadata` directory.
4.  **Validation**: After saving, the script will reload the files to calculate statistics, verify the split ratio, and ensure the data integrity. A placeholder check for file paths is included but will likely be skipped as this dataset contains embedded text rather than external file references.
