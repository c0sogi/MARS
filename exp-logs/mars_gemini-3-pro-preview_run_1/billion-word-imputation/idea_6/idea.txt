Based on the progression of insights from the "Dense Gap Classification" to the "Interleaved Transformer," and specifically addressing the failure of shared representations in "Global Constraints" (Cite `solution_lesson_node_00016`), I propose the **Bifurcated Interleaved Transformer**.

### Model
The architecture is a **Split-Stream Transformer** designed to physically separate the processing of structural anomalies (detection) from semantic infilling (identification), resolving the "Representation Conflict" identified in Lesson 00016.

1.  **Input Topology**: We retain the **Interleaved Gap-Token** strategy (Cite `solution_lesson_node_00015`). The input sequence is constructed by inserting a learnable `[GAP]` token between every pair of words (e.g., `[w1, GAP, w2, GAP, w3]`). This allows the model to explicitly attend to transitions.
2.  **Shared Context Encoder**: The bottom $K$ layers (e.g., 6 layers) of the Transformer are shared. These layers process the low-level syntax and local context common to both tasks.
3.  **Bifurcated Processing Streams**: At layer $K$, the architecture splits into two parallel, independent stacks of Transformer layers (e.g., 2-4 layers each):
    *   **Localization Stream**: Focuses exclusively on syntactic integrity and structural breaks. It terminates in a **Binary Localization Head** (Sigmoid) that predicts $P(Missing | Gap_i)$ for each gap independently. This adheres to the finding that local objectives outperform global constraints (Cite `solution_lesson_node_00016`).
    *   **Identification Stream**: Focuses exclusively on semantic context and vocabulary selection. It terminates in a **Multi-class Identification Head** (Softmax) that predicts $P(Word | Gap_i)$.
4.  **Rationale**: Previous iterations (Idea 4, 5) forced a single hidden state to encode both "something is missing" (syntax) and "word X is missing" (semantics). Lesson 00016 proved this creates conflict. Bifurcation allows the Localization stream to learn "gap-ness" features without being washed out by the high-dimensional semantic gradients of the Identification stream.

### Data
-   **Vocabulary**: Construct a vocabulary of the top $K$ (e.g., 50,000) frequent words from `train_v2.txt`.
-   **Dynamic Interleaved Generation**:
    1.  Sample a sentence and remove one word at index $k$.
    2.  Construct the input sequence with interleaved `[GAP]` tokens.
    3.  **Localization Target**: A binary vector where the `[GAP]` token at the missing position is 1, and all others are 0.
    4.  **Identification Target**: The ID of the removed word.
-   **Preprocessing**: Perform this transformation on-the-fly during training to ensure the model sees a diverse range of gap contexts.

### Training
-   **Decoupled Multi-Task Loss**: The loss function is $L = \lambda_{loc} L_{BCE} + \lambda_{id} L_{CE}$.
    *   $L_{BCE}$: **Weighted Binary Cross-Entropy** on the Localization Stream output. We apply class weighting (Cite `solution_lesson_node_00003`) to handle the sparsity of valid gaps (1 vs $N$).
    *   $L_{CE}$: **Masked Cross-Entropy** on the Identification Stream output. Crucially, this is calculated **only** for the `[GAP]` token corresponding to the true missing word (Cite `solution_lesson_node_00015`). This ensures the semantic branch is not confused by negative examples.
-   **Optimization**: Use AdamW with a One-Cycle learning rate scheduler. The split architecture increases parameter count slightly but maintains the $O(1)$ parallel nature of the Transformer, fitting within the compute budget.

### Evaluation
-   **Single-Pass Inference**:
    1.  Preprocess the test sentence with `[GAP]` tokens.
    2.  Forward pass to obtain the Localization vector $P_{loc}$ (from Stream A) and Identification matrix $P_{id}$ (from Stream B).
    3.  **Score Fusion**: Compute the final score $S_{i,w} = P_{loc}[i] \times P_{id}[w | i]$ (Cite `solution_lesson_node_00015`).
    4.  Select the tuple $(i, w)$ with the maximum score.
    5.  Reconstruct the sentence.
