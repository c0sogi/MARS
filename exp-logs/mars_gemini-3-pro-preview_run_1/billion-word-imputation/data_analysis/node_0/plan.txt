This script performs a robust Exploratory Data Analysis (EDA) on the text training dataset. It handles the large dataset size by using a statistically significant sample for computationally intensive text operations while ensuring reproducibility. The analysis treats the task as a self-supervised classification problem where the "target" is the vocabulary distribution (predicting missing words). It covers data integrity, target variable analysis (vocabulary distribution), input data analysis (sequence lengths, vocabulary stats), and meta-feature relationships.
