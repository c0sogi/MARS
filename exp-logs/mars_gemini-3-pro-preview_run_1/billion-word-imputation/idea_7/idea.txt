Based on the empirical evidence from the provided lessons, I propose the **Syntax-Aware Interleaved Transformer with Consistency Decoding**.

This strategy builds directly upon the successful **Interleaved Gap-Token** architecture (Cite solution_lesson_node_00015) and the **Shared Encoder** principle (Cite solution_lesson_node_00017), while addressing the "Syntax/Semantics Entanglement" problem via a new auxiliary supervision signal rather than architectural bifurcation.

# Model
The architecture is a **Multi-Head Transformer Encoder** designed to jointly model structural location, syntactic category, and semantic identity.

1.  **Backbone**: A deep **Transformer Encoder** (e.g., 12 layers) that processes the sequence via **Hard Parameter Sharing** (Cite solution_lesson_node_00017). This ensures that the rich contextual features learned for identifying the missing word are also available for detecting the gap, avoiding the performance degradation seen in split-stream architectures.
2.  **Input Topology**: We retain the **Interleaved Gap-Token** strategy (Cite solution_lesson_node_00015). The input sequence is constructed by inserting a special learnable `[GAP]` token between every pair of words (e.g., `[w1, GAP, w2, GAP, w3]`). This explicitly reifies the potential insertion site, allowing the model to attend to the "empty space" transition.
3.  **Decoupled Output Heads**: Attached to the `[GAP]` token representations are three specialized heads:
    *   **Localization Head**: A binary classifier (Sigmoid) predicting $P(Missing | Gap_i)$. This maintains the effective **Local Objective** (Cite solution_lesson_node_00016) for structure detection.
    *   **Syntax Head (New)**: A multi-class classifier predicting the **Part-of-Speech (POS)** tag of the missing word (e.g., Noun, Verb, Adjective). This auxiliary head forces the shared encoder to explicitly learn grammatical structure, bridging the gap between raw gap detection and specific word identification.
    *   **Identification Head**: A multi-class classifier predicting the specific word ID from the vocabulary.
4.  **Consistency Decoding Mechanism**: A novel inference logic that fuses the outputs of all three heads. Instead of relying solely on $P(Loc) \times P(Word)$, we weigh the word probability by its syntactic fit: $Score = P(Loc) \times P(Word) \times P(Syntax=Tag(Word))$.

# Data
1.  **Preprocessing (POS Tagging)**: Use the installed `spacy` or `nltk` library to generate ground-truth Part-of-Speech tags for the training sentences.
2.  **Vocabulary & Syntax Map**:
    *   Construct the word vocabulary (Top $K$ frequent words).
    *   Construct a static **Word-to-POS Mapping** (e.g., `{"run": "VERB", "apple": "NOUN"}`). For words with multiple tags, assign the most frequent tag observed in the training set.
3.  **Dynamic Sample Generation**:
    *   Sample a sentence and remove one word at index $k$.
    *   **Inputs**: Interleave `[GAP]` tokens between words.
    *   **Targets**:
        *   Localization: 1 at index $k$, 0 elsewhere.
        *   Syntax: The POS tag ID of the removed word.
        *   Identification: The Word ID of the removed word.

# Training
1.  **Multi-Task Objective**: The loss function is $L = \lambda_{loc}L_{BCE} + \lambda_{id}L_{CE} + \lambda_{syn}L_{CE}$.
    *   $L_{BCE}$: Weighted Binary Cross-Entropy on the Localization head (handling class imbalance via weighting, Cite solution_lesson_node_00003).
    *   $L_{CE}$ (Identification): Cross-Entropy on the Identification head, **masked** to calculate loss *only* at the true gap position (Cite solution_lesson_node_00015).
    *   $L_{CE}$ (Syntax): Cross-Entropy on the Syntax head, also **masked** to apply only at the true gap position.
2.  **Optimization**: Use AdamW with a One-Cycle learning rate scheduler to maximize convergence speed within the 24-hour limit.

# Evaluation
1.  **Inference Pipeline**:
    *   Preprocess the test sentence to inject `[GAP]` tokens.
    *   Forward pass to obtain:
        *   Localization vector $L$ (Size $N$).
        *   Syntax matrix $S$ (Size $N \times |Tags|$).
        *   Identification matrix $I$ (Size $N \times |Vocab|$).
2.  **Score Fusion**:
    *   For every candidate word $w$ in the vocabulary, retrieve its static tag $t_w$.
    *   Compute the insertion score for word $w$ at gap $i$:
        $$Score_{i,w} = L[i] \times I[i, w] \times S[i, t_w]$$
    *   This effectively down-weights semantically plausible words that do not fit the predicted grammatical slot (e.g., penalizing a Noun prediction if the Syntax head strongly predicts a Verb).
3.  **Selection**: Select the tuple $(i, w)$ with the maximum score and reconstruct the sentence.
