The validation logic in `runfile.py` requires these raw indices to reconstruct ground-truth sentences for Levenshtein distance calculation, causing a `KeyError`.

I will modify `library/data.py` to include `"target_gap_idx"` and `"target_word_id"` in the dictionary returned by `collate_fn` for the training/validation branch. This ensures the validation loop can access the necessary ground truth data without altering the stored dataset cache (Cite debug_lesson_3).
