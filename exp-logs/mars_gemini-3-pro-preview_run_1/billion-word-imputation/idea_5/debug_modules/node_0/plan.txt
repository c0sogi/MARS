The following script demonstrates the end-to-end pipeline using the provided library files.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to create a "Demo Mode". This involves enabling debug flags, reducing dataset sizes (to 2000 samples), shrinking model dimensions (embedding size 64, 2 layers), and redirecting outputs to a specific `./working/demo_execution` directory. This ensures the script runs quickly (within minutes) and doesn't interfere with full-scale training artifacts.
2.  **Environment Setup**: We initialize the random seeds for reproducibility and set up the logging environment.
3.  **Vocabulary Construction**: We instantiate the `Vocabulary` class and build it from scratch using the small debug dataset. We verify that special tokens (PAD, UNK, GAP) are correctly indexed.
4.  **Data Pipeline**: We generate PyTorch DataLoaders for training, validation, and testing using `get_dataloaders`. We explicitly verify the integrity of a single batch (checking tensor shapes and data types) to ensure the `InterleavedDataset` and `collate_fn` are functioning correctly.
5.  **Model Initialization**: We instantiate the `GlobalLocalTransformer` and perform a dummy forward pass with a batch of data. We assert that the output shapes for localization logits, identification logits, and hidden states match expected dimensions.
6.  **Training & Evaluation Loop**: We set up the `MultiObjectiveGapLoss`, optimizer, and the `Engine`. We run a single epoch of training and one evaluation pass. We verify that the loss decreases or is computed (finite values) and that the Levenshtein distance metric is generated.
7.  **Inference**: We run the prediction pipeline on the test set and verify that the submission CSV is generated with the correct format and number of rows.
