Here is the implementation strategy:

1.  **Environment Setup**: We will start by configuring the environment, setting random seeds for reproducibility, and defining a working directory for this demonstration to avoid conflicts with existing files.
2.  **Configuration Override**: We will modify the `Config` class attributes at runtime. This allows us to point the system to small, synthetic datasets (created in the next step) and reduce hyperparameters (like epochs and batch size) to ensure the script executes almost instantly.
3.  **Data Generation**: We will create small CSV files mimicking the structure of the training, validation, and test metadata. This ensures the data loading logic works without processing the massive full dataset.
4.  **Component Verification**:
    *   **Vocabulary**: We will instantiate the `Vocabulary` class, build it from our synthetic data, and verify tokenization/detokenization logic.
    *   **Dataset & DataLoader**: We will use the `get_dataloaders` factory function and iterate through a single batch to verify tensor shapes and data types (specifically the interleaved structure of the input).
    *   **Model**: We will instantiate the `InterleavedTransformer`, perform a forward pass with the dummy batch, and assert that the output logits have the expected dimensions.
    *   **Training Loop**: We will run the `fit_model` function for a single epoch on the tiny dataset to demonstrate the training pipeline.
    *   **Inference**: We will run `generate_submission` and verify that the output CSV is generated correctly with the expected format.
