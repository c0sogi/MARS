To address the `torch.OutOfMemoryError`, I will significantly reduce the `Config.BATCH_SIZE` in `runfile.py` from 512 to 64. The original batch size caused an explosion in memory usage due to the large output tensor size (Batch × Sequence × Vocab) required for the vocabulary projection layer (Cite debug_lesson_1). Additionally, I will modify `library/dataset.py` to prevent the debug sampling logic from truncating the test set. This ensures that the full test dataset is always processed for submission, even when running in debug mode, preventing invalid submission file lengths (Cite debug_lesson_2).
