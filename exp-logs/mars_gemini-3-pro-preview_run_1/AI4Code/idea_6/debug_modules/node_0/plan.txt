This script demonstrates the end-to-end workflow of the provided machine learning pipeline for ordering notebook cells. It performs the following steps:

1.  **Configuration**: Overrides the default `Config` settings to run in "Debug Mode" with a tiny dataset size (10 samples), 1 training epoch, and a dedicated working directory (`./working/demo_run`) to ensure speed and isolation.
2.  **Data Preprocessing**: Initializes the `DataPreprocessor` to load raw JSON notebooks, extract code/markdown text, generate embeddings using a Sentence Transformer, and cache the features to Parquet files. It verifies the existence of these output files.
3.  **Dataset Verification**: Instantiates the `NotebookEmbeddingDataset`, loads a sample batch, and asserts that the data shapes and types (embeddings, masks, labels) are correct.
4.  **Model Verification**: Instantiates the `DualContextAnchorNetwork`, performs a forward pass with the sample batch, and verifies that the output logits have the expected dimensions `(Batch, N_md, N_code + 1)`.
5.  **Training**: Executes `train_model()`, which trains the network for one epoch on the debug subset and saves the best model checkpoint. It verifies the creation of the model file.
6.  **Inference**: Executes `predict_and_sort()`, which loads the trained model, predicts cell orders for the test set, and generates a submission CSV. It verifies the submission file's format and content.
