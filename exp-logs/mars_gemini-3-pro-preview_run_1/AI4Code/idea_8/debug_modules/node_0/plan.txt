The following script demonstrates the end-to-end pipeline for the AI4Code task using the provided library files. It performs the following steps:

1.  **Setup**: Configures the environment, sets random seeds, and creates a temporary working directory for the demo.
2.  **Data Subset Creation**: Samples a small subset (10 notebooks) from the provided metadata to create a lightweight dataset for demonstration purposes.
3.  **Configuration Override**: Monkey-patches the `Config` class to point to these new subset files, ensuring the library classes use them instead of the full dataset.
4.  **Preprocessing**: Uses `FeatureExtractor` to generate embeddings for the code and markdown cells of the subset notebooks.
5.  **Dataset & DataLoader**: Verifies the `CachedDataset` and `collate_fn` by loading a batch and checking tensor shapes and masking logic.
6.  **Model Initialization**: Instantiates the `DCAN` model and performs a forward pass to verify architecture compatibility.
7.  **Training Loop**: Uses the `Engine` class to train the model for a few epochs on the subset, demonstrating the training and validation flow.
8.  **Inference**: Generates predictions on a test subset and saves a submission file.
9.  **Metric Validation**: independently verifies the `compute_kendall_tau` function with known inputs.
