The following script demonstrates the end-to-end usage of the provided library for the AI4Code cell ordering task.

**Implementation Strategy:**
1.  **Environment Setup**: We silence `tqdm` progress bars by patching the library before importing the custom modules, ensuring the output remains clean as requested.
2.  **Configuration Override**: We modify the `Config` class to use a temporary working directory (`./working/demo_run`) and reduce training hyperparameters (1 epoch, minimal patience) to ensure the script executes quickly. We explicitely update dependent path variables in `Config` since they are defined at the class level.
3.  **Preprocessing**: We execute `preprocess_data` with `debug=True`. This processes only the first 100 notebooks from the metadata, generating feature parquet files in the working directory. We verify the existence of these files.
4.  **Dataset & Model Verification**: We instantiate the `CachedNotebookDataset` and `DataLoader`. We fetch a single batch to verify the data shapes and pass it through the `DualContextAnchorNetwork` to confirm the model architecture produces the correct output dimensions (`[Batch, Max_MD, Max_Code + 1]`).
5.  **Training Simulation**: We run `train_model` for one epoch using the debug datasets. This demonstrates the training loop, loss calculation, and model checkpointing.
6.  **Inference**: We run `predict_and_rank` with `debug=True` to generate predictions for the test set. Finally, we validate the format of the generated `submission.csv`.
