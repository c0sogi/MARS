The issue is that PyArrow cannot serialize 2D NumPy arrays stored in a Pandas DataFrame column (`code_embeddings` and `markdown_embeddings`) when saving to Parquet. To fix this, I will modify `library/preprocess.py` to convert these 2D arrays into Python lists of lists before dataframe creation (Cite debug_lesson_3). Correspondingly, I will update `library/dataset.py` to handle the loaded data, which will now be Python lists instead of NumPy arrays, by explicitly converting them back to NumPy arrays before passing them to `torch.from_numpy`.
