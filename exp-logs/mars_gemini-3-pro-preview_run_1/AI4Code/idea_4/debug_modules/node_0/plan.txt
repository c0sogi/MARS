The following script demonstrates the end-to-end pipeline for the AI4Code task using the provided library files.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the global `Config` class to run in `DEBUG` mode with a small sample size (50 notebooks) and reduced training epochs (1 epoch). This ensures the script executes quickly within the time limit. We also redirect output paths to a specific `./working/demo_run` directory.
2.  **Feature Extraction**: We instantiate `FeatureExtractor` to process the raw JSON notebooks and metadata into Parquet files containing CodeBERT embeddings. This step handles tokenization and model inference.
3.  **Data Loading Verification**: We explicitly create a `DataLoader` using `get_dataloader` and inspect a single batch to verify that the data shapes (embeddings, masks, labels) are correct and compatible with the model.
4.  **Model & Training**: We instantiate the `Trainer` class, which encapsulates the model initialization, training loop, validation, and checkpointing. We call `trainer.fit()` to execute the training process and generate predictions on the test set.
5.  **Output Verification**: We assert that the model checkpoint (`best_model.pth`) and the submission file (`submission.csv`) are generated correctly.
6.  **Metric Logic Check**: We perform a standalone unit test on the `compute_kendall_tau` utility function to verify the metric calculation logic.
