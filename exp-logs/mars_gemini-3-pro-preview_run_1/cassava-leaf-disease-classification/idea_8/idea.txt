Based on the comprehensive analysis of the provided lessons and previous experiments, I propose the following **Heterogeneous Cross-Validation Ensemble (HCVE)** strategy. This solution structurally evolves the approach from a single-split training pipeline to a robust, multi-architecture ensemble trained via stratified cross-validation. It leverages the "Compute-Optimal" insight **Cite solution_lesson_node_00024** by utilizing efficient "Small/Tiny" backbones to afford the computational cost of a 10-model ensemble within the 24-hour limit.

# Model
- **Architecture (Heterogeneous Ensemble):** Construct an ensemble using two distinct architectures to maximize feature diversity:
    1.  **ConvNeXt V2-Small:** A CNN-based model initialized with FCMAE weights, optimized for capturing local, high-frequency textural anomalies (disease spots).
    2.  **Swin Transformer V2-Tiny:** A hierarchical Vision Transformer, selected to capture long-range global dependencies and semantic context that CNNs might miss.
    - **Rationale:** Using "Small/Tiny" variants avoids the overfitting and undertraining issues observed with "Base" models **Cite solution_lesson_node_00024**, while their efficiency permits training multiple folds.
- **Pooling:** Replace Global Average Pooling with **Generalized Mean Pooling (GeM)** in both architectures. This learnable pooling layer adaptively focuses on salient high-frequency details (lesions) rather than washing them out **Cite solution_lesson_node_00028**.
- **Head:** Equip all models with a **Multi-Sample Dropout** classification head to accelerate convergence and improve generalization by averaging logits from multiple parallel dropout masks **Cite solution_lesson_node_00012**.

# Data
- **Splitting Strategy:** Implement **5-Fold Stratified Cross-Validation**. Instead of a single train/val split, the entire dataset will be used to train 5 versions of each architecture (10 models total). This ensures the model learns from every available sample and provides a statistically robust prediction.
- **Preprocessing (Progressive Resizing):**
    - **Phase 1:** Resize images to **384x384** for the initial training phase.
    - **Phase 2:** Resize images to **512x512** for fine-tuning and SWA. This leverages the accuracy gains from high-resolution training **Cite solution_lesson_node_00018**.
- **Augmentation:**
    - **Mixing:** Apply **MixUp** and **CutMix** to synthesize novel samples and handle class imbalance **Cite solution_lesson_node_00011**.
    - **Contextual Cropping:** Constrain `RandomResizedCrop` to a scale of `(0.3, 1.0)` to prevent training on ambiguous macro-crops **Cite solution_lesson_node_00015**.
    - **Determinism:** Explicitly seed the `worker_init_fn` in DataLoaders for reproducibility **Cite solution_lesson_node_00007**.

# Training
- **Optimizer Strategy:** Use **AdamW** with **Layer-wise Learning Rate Decay (LLRD)**. Apply a decay factor (e.g., 0.8) to progressively lower the learning rate for layers closer to the input. This preserves robust pre-trained features while allowing the GeM pooling and heads to adapt aggressively **Cite solution_lesson_node_00028**.
- **Loss Function:** Use **Soft Target Cross Entropy** to handle the continuous targets from MixUp/CutMix. Do not use explicit Label Smoothing, as MixUp provides sufficient smoothing **Cite solution_lesson_node_00027**.
- **Regularization:** Set **Stochastic Depth (Drop Path)** rate to `0.0`. Given the strong augmentation and moderate model size, standard drop path rates lead to over-regularization **Cite solution_lesson_node_00019**.
- **Batch Size:** Use **Gradient Accumulation** to ensure effective batch size $\ge 32$ **Cite solution_lesson_node_00016**.
- **Schedule (Per Fold):**
    1.  **Warmup:** 1 epoch at 384x384 with backbone frozen **Cite solution_lesson_node_00001**.
    2.  **Base Training:** ~8 epochs at 384x384 with LLRD.
    3.  **High-Res Fine-Tuning:** ~4 epochs at 512x512.
    4.  **Stochastic Weight Averaging (SWA):** ~4 epochs at 512x512 using a cyclical learning rate. Average the snapshots to create the final weights for each fold **Cite solution_lesson_node_00026**.

# Evaluation
- **Inference:**
    1.  **Test Time Augmentation (TTA):** For each test image, generate predictions for the original, horizontally flipped, and vertically flipped versions **Cite solution_lesson_node_00011**.
    2.  **Ensemble Aggregation:** Compute the arithmetic mean of the probabilities from all 10 models (2 Architectures $\times$ 5 Folds). This minimizes variance and exploits the complementary inductive biases of the CNN and Transformer.
