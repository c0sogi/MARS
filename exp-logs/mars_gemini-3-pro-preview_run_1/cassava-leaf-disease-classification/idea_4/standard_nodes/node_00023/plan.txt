Implementation strategy:

1.  **Setup and Configuration**: Initialize the `Config`, set random seeds for reproducibility, and setup the logger and computing device (GPU).
2.  **Model Initialization**: Instantiate the `CassavaClassifier` with a pre-trained `ConvNeXt-Base` backbone. Initialize `ModelEMA` to maintain a stable moving average of weights.
3.  **Training Strategy**:
    *   **Phase 1 (Warmup)**: Freeze the backbone and train only the classifier head for 1 epoch to stabilize initial weights.
    *   **Phase 2 (Coarse)**: Train the full model at `384x384` resolution for 8 epochs using Layer-wise Learning Rate Decay (LLRD) and Cosine Annealing.
    *   **Phase 3 (Fine-Tuning)**: Fine-tune the model at `512x512` resolution for 3 epochs with a lower learning rate to capture fine-grained details.
    *   *Note*: Epoch counts are adjusted to ensure the pipeline completes within the 2-hour limit while maintaining high performance.
4.  **Validation and Failure Analysis**:
    *   Evaluate the model on the hold-out validation set.
    *   Calculate the "Error Magnitude" (1 - probability of true class) for each validation sample.
    *   Compute and print the correlation between error magnitude and image file size to identify potential biases.
    *   Print the `Final Validation Metric` as required.
5.  **Submission**:
    *   Check if the validation accuracy exceeds the threshold `0.9025367158754805`.
    *   If passed, perform inference on the test set using **Test Time Augmentation (TTA)** (Original + Horizontal Flip + Vertical Flip).
    *   Save the predictions to `./submission/submission.csv`.
