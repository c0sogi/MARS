To optimize performance for the iNaturalist species classification task, I will implement the following changes based on the provided lessons:

1.  **Architecture Upgrade**: Replace `MobileNetV3-Large` with **`EfficientNet-B0`**. This model provides a superior accuracy-to-efficiency ratio for fine-grained classification (Cite solution_lesson_node_00006).
2.  **Training Optimization**: Implement **Automatic Mixed Precision (AMP)** using `torch.cuda.amp`. This allows doubling the batch size to **256** and training for **10 epochs** within the time limit (Cite solution_lesson_node_00006).
3.  **Loss Function**: Adopt **Label Smoothing (0.1)** with Cross Entropy Loss to improve generalization on the 1,010-class dataset (Cite solution_lesson_node_00006).
4.  **Augmentation Refinement**: Revert the aggressive color jitter (specifically removing hue rotation) that degraded performance in previous iterations, while maintaining `RandomResizedCrop` (Cite solution_lesson_node_00003).

    """
    Constructs a MobileNetV3-Large model customized for the iNaturalist dataset.

    Args:

        num_classes (int): The number of output classes (species).
        device (str): The device to put the model on ('cuda' or 'cpu').

    model = model.to(device)

    return model

def train_one_epoch(train_loader, model, criterion, optimizer, device, epoch, scaler):
    """
    Trains the model for one epoch using AMP.
    """
    model.train()
    losses = AverageMeter()
    top1 = AverageMeter()

    for i, (images, targets) in enumerate(train_loader):
        images = images.to(device)
        targets = targets.to(device)

        # Forward pass with AMP (Cite solution_lesson_node_00006)
        with torch.cuda.amp.autocast():
            outputs = model(images)
            loss = criterion(outputs, targets)

        # Measure accuracy and record loss
        acc1 = accuracy(outputs, targets, topk=(1,))[0]
        losses.update(loss.item(), images.size(0))
        top1.update(acc1.item(), images.size(0))

        # Backward pass and optimize
        optimizer.zero_grad()
        scaler.scale(loss).backward()
        scaler.step(optimizer)
        scaler.update()

    print(f"Epoch [{epoch}] Training Loss: {losses.avg}, Training Acc: {top1.avg}")
    return losses.avg, top1.avg
