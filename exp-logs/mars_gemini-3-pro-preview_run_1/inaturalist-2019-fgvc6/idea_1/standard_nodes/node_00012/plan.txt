2.  **Training Efficiency (Cite Lesson 6)**: Implement **Automatic Mixed Precision (AMP)**. This is critical to offset the increased computational cost of EfficientNet-B1, allowing us to train a heavier model within the 2.5-hour limit.
3.  **Loss Function (Cite Lesson 6)**: Integrate **Label Smoothing (0.1)** into the CrossEntropyLoss. This helps prevent overfitting in fine-grained classification tasks with many classes (1,010 species).
4.  **Data Preprocessing (Cite Lesson 3 & 7)**:
    *   **Validation**: Replace the direct resize with `Resize(256) -> CenterCrop(240)` to preserve aspect ratios, which is crucial for species identification.
    *   **Training**: Revert the aggressive color augmentation (specifically removing hue rotation and reducing intensity) that was shown to degrade performance, while keeping `RandomResizedCrop`.
5.  **System Optimization**: Increase `NUM_WORKERS` to 12 to fully utilize the available vCPUs and prevent data loading bottlenecks.

def train_one_epoch(train_loader, model, criterion, optimizer, device, epoch, scaler):

    Trains the model for one epoch using Automatic Mixed Precision (AMP).
    Cite solution_lesson_node_00006: Optimizing via Mixed Precision.

        # Forward pass with AMP

        scaler.step(optimizer)
