Based on the lessons learned, I propose the **"Weighted Layer-Pooling Stacking with DeBERTa-v3-Large"** strategy.

This solution structurally evolves the previous ideas by addressing the specific failure mode of "Large" models (undertraining) and the need for deeper syntactic signal capture, while strictly adhering to the efficiency protocols established in the lessons.

### Model
I propose a **Two-Stage Stacking Ensemble** that fuses a high-capacity semantic expert with a lightweight stylometric expert.

1.  **Level 1: Heterogeneous Base Experts**
    *   **Expert A (Deep Syntactic-Semantic):** I will utilize **`microsoft/deberta-v3-large`**. As established, backbone quality is the primary driver of performance **Cite {solution_lesson_node_00018}**, and DeBERTa's disentangled attention is superior for capturing the "syntactic rhythm" of authors **Cite {solution_lesson_node_00014}**.
        *   **Structural Innovation (Weighted Layer Pooling):** Instead of using the standard `[CLS]` token for classification, I will implement a **Weighted Layer Pooling** head. This mechanism learns a scalar weight for each of the last 4 hidden layers of the transformer. By computing a weighted average of these layers *before* pooling, the model can dynamically access lower-level syntactic features (often preserved in intermediate layers) alongside high-level semantic features (top layer). This directly addresses the signal loss observed in short texts by leveraging the full depth of the transformer's linguistic understanding.
    *   **Expert B (Surface Stylometric):** I will retain the **Logistic Regression model trained on Hybrid TF-IDF features (Word N-grams 1-3 + Character N-grams 3-5)**. This model acts as a critical "stylometric residual," capturing morphological fingerprints (e.g., suffix usage, punctuation patterns) that deep transformers tend to smooth over **Cite {solution_lesson_node_00005}**.

2.  **Level 2: Conditional Meta-Learner**
    *   **Algorithm:** An **XGBoost Classifier** will combine the predictions.
    *   **Input Features:** The meta-learner will ingest the class probabilities from both experts, concatenated with **explicit meta-features** (Sentence Character Length, Word Count, and Punctuation Density). This enables the ensemble to dynamically down-weight the Transformer on very short texts where it lacks context **Cite {solution_lesson_node_00008}**.
    *   **Constraint:** I will strictly **exclude** derived statistical features (Entropy, Standard Deviation) and POS-tag models to avoid the noise and dimensionality bloat that degraded performance in previous iterations **Cite {solution_lesson_node_00021}**.

### Data
*   **Dynamic Sequence Length:** For Expert A, I will set the maximum sequence length to the **99th percentile of the training data distribution** (approximately 256 tokens) rather than a fixed 512. This prevents "Context Bloat" and allows for larger batch sizes and stable convergence **Cite {solution_lesson_node_00021}**.
*   **Sparse Preservation:** For Expert B, TF-IDF matrices will be generated and maintained strictly in **Sparse Matrix format (CSR)**. This prevents the massive memory overhead and runtime latency caused by densifying high-dimensional n-gram features **Cite {solution_lesson_node_00001}**.

### Training
I will employ a **5-Fold Out-of-Fold (OOF) Stacking Strategy** to maximize data efficiency **Cite {solution_lesson_node_00019}**.

1.  **Expert A Optimization (DeBERTa-v3-Large):**
    *   **Convergence Assurance:** To address the "undertraining" issue observed with Large models **Cite {solution_lesson_node_00027}**, I will implement **Layer-Wise Learning Rate Decay (LLRD)**. By assigning lower learning rates to the bottom layers (which contain robust pre-trained syntactic features) and higher rates to the top layers, the model stabilizes faster.
    *   **Gradient Accumulation:** To accommodate the "Large" model on the A100 GPU, I will use gradient accumulation to simulate a larger effective batch size (e.g., 32), ensuring stable gradients.
    *   **Dynamic Early Stopping:** Instead of a fixed epoch limit, I will train with Early Stopping based on validation loss, allowing the model to converge fully.
2.  **Expert B Optimization:**
    *   Trained on the CPU using a solver optimized for sparse inputs (e.g., `saga` or `lbfgs`).
3.  **Meta-Learner Training:**
    *   The XGBoost model will be trained on the full set of OOF predictions (14k samples) generated by the 5 folds of Experts A and B. This avoids the data starvation issues associated with Hold-Out Blending **Cite {solution_lesson_node_00015}**.

### Evaluation
1.  **Bagged Inference:** The 5 trained models for Expert A and the 5 trained models for Expert B will each generate predictions for the test set. These predictions will be averaged (bagged) to produce stable probability vectors for each expert.
2.  **Meta-Prediction:** Meta-features will be calculated for the test set. The bagged expert probabilities and meta-features will be fed into the trained XGBoost meta-learner to generate the final submission.
