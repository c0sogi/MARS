To establish a robust and highly efficient baseline for the Spooky Author Identification task, I propose a **Logistic Regression model utilizing Hybrid TF-IDF Features**.

### Model
The architecture consists of a single linear classification layer—**Logistic Regression**—operating on a high-dimensional, sparse feature space. This design synthesizes the feature extraction strategy found in the SVM architecture (Model 1) with a probabilistic classifier that directly optimizes the target metric. By using Logistic Regression instead of an SVM, we eliminate the need for complex post-training probability calibration (like Platt scaling), as the model naturally minimizes the log-loss function. The input features will be a concatenation of:
1.  **Word N-grams:** To capture semantic content and common phrases.
2.  **Character N-grams:** To capture morphological style, punctuation usage, and sub-word patterns distinct to each author.

### Data
Preprocessing will be kept minimal to preserve stylistic signals; punctuation and casing will likely be retained as they can be indicative of specific authors (e.g., Poe's use of dashes). The text data will be transformed using two separate TF-IDF (Term Frequency-Inverse Document Frequency) vectorizers:
*   One vectorizer for **word n-grams** (ranging from unigrams to trigrams).
*   One vectorizer for **character n-grams** (ranging from 3-grams to 5-grams).
These two sparse matrices will be stacked horizontally to create a unified feature set for every sentence.

### Training
The model will be trained to minimize **Multi-class Logarithmic Loss** (Cross-Entropy) with L2 regularization (Ridge) to handle multicollinearity in the high-dimensional feature space. An efficient solver such as L-BFGS or SAG (Stochastic Average Gradient) will be employed for rapid convergence. A simple k-fold cross-validation strategy will be used on the training set to determine the optimal regularization strength ($C$) that yields the lowest validation log-loss.

### Evaluation
For evaluation, the text from the test set will be transformed using the vectorizers fitted on the training data. The trained Logistic Regression model will then predict the probability distribution over the three classes (EAP, HPL, MWS) for each test instance. These probabilities will be directly written to the submission file, ensuring they conform to the required format.
