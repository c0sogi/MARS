The following script demonstrates the complete pipeline for the Author Identification task using the provided library components. It optimizes execution speed by running in debug mode with a reduced sample size, fewer folds, and a smaller Transformer backbone (`prajjwal1/bert-tiny`) to verify logic without the overhead of the full DeBERTa-Large model.

The script performs the following steps:
1.  **Configuration Override**: Adjusts global settings (folds, epochs, model size) for a fast demonstration.
2.  **Component Verification**: Validates the log loss metric and feature extraction logic.
3.  **Pipeline Execution**:
    *   Runs **Expert B** (TF-IDF + Logistic Regression).
    *   Runs **Expert A** (Transformer Fine-tuning).
    *   Runs the **Meta-Learner** (XGBoost Stacking).
4.  **Output Validation**: checks the integrity of the generated predictions and the final submission file.
