Implementation strategy:
1.  **Configuration Override**: Import the `Config` class and override `EPOCHS` to 2 to ensure the training completes quickly within the time limit while maintaining sufficient performance.
2.  **Expert Execution**:
    - Execute `run_expert_a` to train the DeBERTa model (5-fold CV) and generate OOF and Test predictions. This function also saves model checkpoints which are crucial for validation inference.
    - Execute `run_expert_b` to train the Linear model and generate OOF and Test predictions.
3.  **Validation Assessment**:
    - Load the hold-out validation dataset (`metadata/validation.csv`).
    - **Expert A Inference**: Load the 5 saved DeBERTa checkpoints, perform inference on the validation set, and average the probabilities (bagging).
    - **Expert B Inference**: Since the linear models aren't saved, replicate the fast TF-IDF + Logistic Regression training loop on the training folds and predict on the validation set, averaging the results.
    - **Meta-Learner Inference**: Extract meta-features for the validation set. Train an XGBoost model on the stacked OOF predictions (from `train.csv`) and predict on the stacked validation features.
    - Compute and print the **Final Validation Metric** (Log Loss).
4.  **Failure Analysis**:
    - Calculate the log loss contribution for each validation sample.
    - Compute correlations between this error magnitude and meta-features (Character Length, Word Count, Punctuation Density) to identify error patterns.
5.  **Submission**:
    - If the validation metric meets the required threshold, execute `run_meta_learner` to generate the final `submission.csv` using the test predictions generated in step 2.
