Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and verify directory structures using the provided `Config` class.
2.  **Data Loading & Splitting**:
    *   Load the full training set (`metadata/train.csv`) and the hold-out validation set (`metadata/validation.csv`).
    *   Split the full training set into a **Base Training Set (80%)** for training the Level 1 experts and a **Blending Set (20%)** for training the Level 2 meta-learner. This ensures the meta-learner is trained on out-of-sample predictions to avoid overfitting.
3.  **Level 1 Expert Training**:
    *   **Expert A (Transformer)**: Train a DeBERTa-v3-base model on the Base Training Set. Use a small subset of the Base Training Set for internal early stopping.
    *   **Expert B (Lexical)**: Train a Logistic Regression model on Word/Char TF-IDF features derived from the Base Training Set.
    *   **Expert C (Syntactic)**: Train a Logistic Regression model on POS-Tag TF-IDF features (using Spacy for extraction) from the Base Training Set.
4.  **Level 2 Meta-Learner Training**:
    *   Generate probability predictions from all three trained experts on the **Blending Set**.
    *   Assemble a feature matrix containing these probabilities, uncertainty statistics (entropy, std dev), and explicit meta-features (text length, punctuation).
    *   Train an XGBoost classifier on this assembled data to map expert signals to ground truth labels.
5.  **Validation & Evaluation**:
    *   Run the full ensemble (Experts + Meta-Learner) on the **Hold-Out Validation Set**.
    *   Compute and print the **Final Validation Metric** (Multi-class Log Loss).
6.  **Failure Analysis**:
    *   Calculate the log loss contribution of each validation sample.
    *   Compute correlations between the error magnitude and input features (e.g., sentence length, punctuation density) to identify weaknesses.
7.  **Submission**:
    *   If the validation metric meets the threshold (< 0.264), generate predictions for the **Test Set** using the full ensemble and save the submission file in the required format.
