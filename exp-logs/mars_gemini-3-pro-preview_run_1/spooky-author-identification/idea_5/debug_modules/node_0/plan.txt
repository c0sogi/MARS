The following script demonstrates the end-to-end pipeline for the Author Identification task using the provided library modules. It performs the following steps:

1.  **Environment Setup**: Configures random seeds and suppresses unnecessary logs for a clean execution.
2.  **Data Loading**: Demonstrates how to create stratified folds using `data_loader.py` and verifies the structure of the `AuthorDataset` class for PyTorch compatibility.
3.  **Linear Expert**: Runs the TF-IDF + Logistic Regression pipeline (`linear_expert.py`) in debug mode (subset of data, fewer folds) to generate Out-of-Fold (OOF) and Test predictions.
4.  **Transformer Expert**: Runs the DeBERTa-based pipeline (`transformer_expert.py`) in debug mode (1 epoch, subset of data) to generate deep learning-based predictions.
5.  **Meta-Learner**: Aggregates the predictions from the Linear and Transformer experts along with meta-features using `meta_learner.py` to produce the final submission.
6.  **Validation**: Includes assertions at each step to ensure data shapes, file outputs, and prediction formats are correct.
