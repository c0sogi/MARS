# Idea 3: Meta-Feature Aware Stacking Ensemble

### Model
I propose a **Two-Stage Stacking Architecture** that evolves the previous weighted ensemble into a dynamic, conditional combination strategy. This design explicitly addresses the identified weakness where model performance degrades on short sentences by allowing the ensemble to adjust its reliance on each expert based on input characteristics.

1.  **Level 1: Heterogeneous Base Experts**
    *   **Contextual Expert (Deep):** I will upgrade the backbone to **`microsoft/deberta-v3-base`**. DeBERTa's disentangled attention mechanism provides superior syntactic understanding compared to RoBERTa, offering a stronger semantic signal.
    *   **Stylometric Expert (Surface):** I will retain the **Logistic Regression model trained on Hybrid TF-IDF features (Word N-grams 1-3 + Character N-grams 3-5)**. As established, this model captures morphological "fingerprints" (like suffix usage and punctuation patterns) that deep learning models often smooth over Cite {solution_lesson_node_00001}.

2.  **Level 2: Meta-Learner (The Structural Innovation)**
    *   Instead of a static linear average, I will employ a **Gradient Boosting Classifier (XGBoost)** as a meta-learner.
    *   **Input Features:** This meta-learner will ingest the class probability distributions from both Level 1 experts *concatenated with* **explicit meta-features** (e.g., sentence character length, word count, and punctuation density).
    *   **Mechanism:** This structure allows the model to learn non-linear combination rules (e.g., "If the sentence is very short, trust the Stylometric Expert's character n-grams more than the Transformer's context"). This directly targets the failure mode correlated with sentence length identified in previous iterations Cite {solution_lesson_node_00005}.

### Data
Data processing will occur in parallel streams to serve the distinct needs of the hierarchy:
*   **For the Contextual Expert:** Raw text will be tokenized using the DeBERTa-v3 tokenizer (SentencePiece).
*   **For the Stylometric Expert:** Text will be vectorized into sparse TF-IDF matrices (Word + Char). Crucially, these will remain in **Sparse Matrix format** to maintain computational efficiency Cite {solution_lesson_node_00001}.
*   **For the Meta-Learner:** I will extract a dense vector of meta-features for every sample, specifically: character count, word count, and counts of specific punctuation marks (commas, semicolons, colons) which are known high-signal stylistic markers for these authors.

### Training
The training pipeline implements a **Cross-Validation Stacking Strategy** to prevent data leakage:
1.  **Base Model Training (Level 1):** Both the DeBERTa transformer and the Logistic Regression model will be trained using **5-Fold Cross-Validation**.
    *   For each fold, we generate **Out-of-Fold (OOF) predictions** for the validation holdout.
    *   This results in a full set of unbiased probability predictions for the entire training set.
2.  **Meta-Learner Training (Level 2):** The XGBoost classifier will be trained on the OOF predictions from Level 1 combined with the meta-features. It will optimize the **Multi-class Logarithmic Loss**.
3.  **Final Re-training:** After the meta-learner is trained, the Level 1 base models will be re-trained on the full training dataset to maximize their utility for the test set.

### Evaluation
For the test set, the procedure mirrors the training pipeline:
1.  Generate probability predictions using the re-trained Level 1 DeBERTa and Logistic Regression models.
2.  Extract meta-features (length, punctuation) for the test samples.
3.  Feed the concatenated vector (Level 1 Probabilities + Meta-features) into the trained XGBoost Meta-Learner.
4.  The output of the XGBoost model (probabilities) will be clipped and formatted for submission.
