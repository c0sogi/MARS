The issue arises because `TransformerDataset` is initialized with a Pandas Series that has a non-contiguous index (due to `train_test_split`). When the PyTorch `DataLoader` attempts to access an item using a positional index (e.g., `180`), the Pandas Series interprets this as a label lookup. If that label does not exist in the Series index (e.g., it was assigned to the validation set), a `KeyError` is raised. The fix is to convert the `texts` and `labels` inputs to standard Python lists in the `__init__` method, ensuring that indexing is always positional (0 to N-1) and compatible with the `DataLoader`.
