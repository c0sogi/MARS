The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup and Loading**: Initialize the environment with fixed random seeds. Load the `./metadata/train.csv` file. Parse the JSON-encoded `annotations` and stringified `image_paths` to create a workable DataFrame.
2.  **Target Variable Analysis**:
    *   Treat the 3D bounding box annotations as the target.
    *   **Classification**: Analyze the frequency and balance of the `class_name` attribute.
    *   **Regression**: Flatten the bounding box parameters (`center_x`, `center_y`, `center_z`, `width`, `length`, `height`, `yaw`) into a tabular format. Calculate distribution statistics (Skewness, Kurtosis) for these continuous variables.
3.  **Input Data Analysis (Image)**:
    *   Since the dataset contains thousands of images, perform analysis on a random sample (e.g., 500 images) to ensure execution within the time limit.
    *   Analyze image dimensions (Width, Height, Aspect Ratio).
    *   Analyze channel counts.
    *   Calculate global pixel mean and standard deviation.
4.  **Input Data Analysis (Tabular/Metadata)**:
    *   Analyze the metadata DataFrame itself for missing values.
    *   Analyze the distribution of object counts per sample.
5.  **Feature/Signal Relationships**:
    *   **Structured**: Calculate correlations between bounding box dimensions (e.g., Width vs. Length).
    *   **Unstructured/Meta**: Analyze the relationship between object class and object volume (Width * Length * Height). Analyze the spatial distribution of objects (Center X vs. Center Y) relative to the ego vehicle.
6.  **Output**: Format all findings into distinct, capitalized sections with 4-decimal precision, printing to stdout.
