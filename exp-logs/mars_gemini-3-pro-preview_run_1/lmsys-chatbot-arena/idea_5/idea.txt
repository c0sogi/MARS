# Solution Proposal

### Model
**Architecture:** Siamese DeBERTa-v3-Base with Weighted Layer Pooling
To resolve the capacity limitations of the "Small" backbone (Cite **solution_lesson_node_00015**) and the data-scaling failures of previous "Base" attempts (Cite **solution_lesson_node_00019**), I propose a robust **Siamese DeBERTa-v3-Base** architecture optimized for the full dataset.
1.  **Backbone:** The model utilizes `microsoft/deberta-v3-base` as a shared encoder. This provides significantly higher parameter capacity than the `small` variant to capture subtle semantic nuances.
2.  **Weighted Layer Pooling:** Instead of standard Mean Pooling (which outperformed [CLS] pooling, Cite **solution_lesson_node_00016**), I will implement **Weighted Layer Pooling**. This mechanism extracts the hidden states from the **last 4 layers** of the transformer and computes a learnable weighted average. This allows the model to dynamically leverage lower-level syntactic/structural features (preserved in earlier layers) alongside high-level semantics, addressing the need for "quality" signals beyond pure meaning (Cite **solution_lesson_node_00002**).
3.  **Interaction Mechanism:** The pooled embeddings ($u$ and $v$) are combined using explicit geometric interaction terms: $|u - v|$ and $u \cdot v$ (Cite **solution_lesson_node_00013**).
4.  **Strictly Relative Feature Injection:** A vector of scalar features is concatenated with the interaction embeddings. Crucially, this vector will contain **only relative values** (Differences and Ratios of lengths/newlines) and **exclude absolute values**, enforcing a hard inductive bias that prevents the model from learning distracting heuristics (Cite **solution_lesson_node_00020**).

### Data
1.  **Dataset Strategy:** The model will be trained on the **full training dataset** (~41k samples). I will strictly avoid subsampling, as previous experiments proved that model scale cannot compensate for data loss (Cite **solution_lesson_node_00019**).
2.  **Feature Engineering:** 
    *   Compute global statistics: Character count, Word count, Newline count (Cite **solution_lesson_node_00006**, **solution_lesson_node_00008**).
    *   **Transformation:** Convert all statistics into pairwise **Differences** ($A-B$) and **Ratios** ($A/B$). Discard the raw absolute counts to reduce noise (Cite **solution_lesson_node_00020**).
    *   **Exclusion:** Do not calculate local token counts (e.g., code blocks) as the attention mechanism handles these internally (Cite **solution_lesson_node_00018**).
3.  **Preprocessing:** Tokenize inputs with `deberta-v3-base` tokenizer, max length 512.

### Training
1.  **Resource Optimization:** To enable training the `Base` model on the full dataset without exceeding the A100 GPU memory (a bottleneck in **solution_lesson_node_00019**), I will employ **Gradient Accumulation** (accumulating gradients over multiple mini-batches before stepping) and **Mixed Precision (FP16)** training. This allows for an effective batch size (e.g., 16 or 32) while keeping the physical batch size small.
2.  **Optimization Strategy:** Use **AdamW** with a **differential learning rate**:
    *   Backbone: 1e-5 (conservative updates).
    *   Head/Pooling Weights: 1e-3 (rapid adaptation).
3.  **Convergence Monitoring:** Train for 2-3 epochs, explicitly monitoring the **Training vs. Validation Loss delta**. Training will continue until the Training Loss drops to or slightly below the Validation Loss to ensure full convergence (Cite **solution_lesson_node_00015**).
4.  **Regularization:** Apply Weight Decay (0.01) and Early Stopping based on Validation Log Loss to prevent the catastrophic overfitting often seen in small-to-medium transformers (Cite **solution_lesson_node_00021**).

### Evaluation
1.  **Inference:** Process test set pairs through the fine-tuned Siamese Base backbone.
2.  **Fusion:** Apply the learned layer weights to pool embeddings, compute interaction terms, and concatenate with the pre-computed test-set **relative** scalar features.
3.  **Prediction:** Generate probabilities via the MLP head.
