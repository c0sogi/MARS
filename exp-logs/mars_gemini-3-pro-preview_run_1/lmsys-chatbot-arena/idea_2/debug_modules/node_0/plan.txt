This script demonstrates the end-to-end pipeline for the chatbot preference prediction task using the provided library files. It overrides the default configuration to run in "debug mode," ensuring rapid execution by using a small subset of the data (100 training samples, 50 validation/test samples) and training for only 1 epoch.

The script performs the following steps:
1.  **Configuration**: Sets up paths and enables debug mode for speed.
2.  **Feature Engineering**: Generates scalar features (length differences, etc.) and asserts correct shapes.
3.  **Dataset Construction**: Builds PyTorch datasets and validates item structure.
4.  **Model Initialization**: Instantiates the Siamese DeBERTa model and verifies a forward pass.
5.  **Training**: Runs the training loop using the `engine` module and checks for model checkpoint creation.
6.  **Inference**: Generates predictions on the test set and verifies the submission file format.
