The issue is that `Config.epochs` is accessed as a default argument in the `train_model` function signature in `library/model.py`. In Python, default arguments are evaluated at module import time. However, in the original `library/config.py`, `epochs` is only defined as an instance attribute (inside `__init__`), not as a class attribute. Consequently, accessing `Config.epochs` on the class itself raises an `AttributeError`. To fix this, `epochs` (along with `train_batch_size`, `valid_batch_size`, and `debug`, which are used similarly) must be defined as class attributes in the `Config` class body. This applies the concept from Cite debug_lesson_1.
