# Solution Proposal

### Model
**Architecture:** Siamese Transformer with Hybrid Feature Fusion
To address the inability of frozen embeddings to capture response quality (Cite **solution_lesson_node_00002**), I propose replacing the static feature extractor with a **fine-tunable Siamese Transformer backbone** (e.g., `deberta-v3-small`).
1.  **Siamese Encoders:** The model processes two inputs independently using shared weights:
    *   Input A: `[CLS] Prompt [SEP] Response A [SEP]` $\rightarrow$ Embedding $u$
    *   Input B: `[CLS] Prompt [SEP] Response B [SEP]` $\rightarrow$ Embedding $v$
2.  **Semantic Interaction Layer:** To explicitly capture the semantic differences between the responses, we construct a combined embedding vector using operations that highlight contrast: $E_{sem} = [u, v, |u - v|, u * v]$.
3.  **Hybrid Fusion:** We concatenate $E_{sem}$ with a vector of **Explicit Scalar Features** ($S$). This vector $S$ retains the successful orthogonal structural signals identified in previous experiments, specifically:
    *   **Granular Differences:** Word count differences and newline count differences (Cite **solution_lesson_node_00008**).
    *   **Non-Linear Ratios:** Length ratios (e.g., $Len(A)/Len(B)$) to provide scale-invariant signals that the network struggles to approximate from raw inputs (Cite **solution_lesson_node_00010**).
4.  **Classifier Head:** The final fused vector $[E_{sem}, S]$ is passed to an MLP to predict the 3 target classes (A, B, Tie).

### Data
1.  **Text Preprocessing:** Tokenize the `Prompt + Response` pairs using the backbone's tokenizer. Apply dynamic truncation to ensure the `Prompt` context is preserved while fitting within the sequence length limit (e.g., 512 tokens).
2.  **Feature Engineering:** Pre-compute the auxiliary scalar features ($S$) for the entire dataset. Ensure these include both character-level and word-level statistics (Cite **solution_lesson_node_00008**) and ratio-based interaction features (Cite **solution_lesson_node_00010**).
3.  **Dataset Usage:** Utilize the full training dataset for the fine-tuning process to maximize signal, rather than a subset (Cite **solution_lesson_node_00006**).

### Training
1.  **Procedure:** End-to-end fine-tuning of the Transformer backbone and the MLP head.
2.  **Loss Function:** Categorical Cross-Entropy Loss.
3.  **Optimization:** Use the AdamW optimizer with a **differential learning rate** strategy: a lower learning rate (e.g., 2e-5) for the transformer backbone to preserve pre-trained knowledge, and a higher learning rate (e.g., 1e-3) for the randomly initialized MLP head.
4.  **Regularization:** Implement Early Stopping based on validation Log Loss to prevent overfitting.

### Evaluation
1.  **Inference:** Pass the test set `Prompt + Response` pairs through the fine-tuned Siamese network to generate embeddings $u$ and $v$.
2.  **Fusion:** Compute the interaction terms and concatenate with the pre-computed test set scalar features.
3.  **Prediction:** Feed the fused vector into the MLP head and apply Softmax to generate the final probability distribution.
