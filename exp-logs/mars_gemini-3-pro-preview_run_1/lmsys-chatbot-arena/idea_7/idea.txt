# Solution Proposal: Siamese DeBERTa-v3-Base with Gated Semantic-Structural Fusion

### Model
**Architecture:** Siamese DeBERTa-v3-Base with Weighted Layer Pooling and Gated Feature Fusion.
This architecture evolves the previous Siamese designs by introducing a **Gated Fusion Head** that dynamically arbitrates between semantic signals (from the transformer) and structural signals (from engineered features), addressing the feature interference observed in previous iterations.

1.  **Backbone:** Utilize `microsoft/deberta-v3-base` as the shared encoder. This provides the necessary capacity for semantic nuance (Cite **solution_lesson_node_00023**) while avoiding the resource prohibitive nature of larger models.
2.  **Weighted Layer Pooling:** Extract hidden states from the **last 4 layers** of the encoder and compute a learnable weighted average. This aggregates both high-level semantic abstractions and lower-level syntactic information (Cite **solution_lesson_node_00023**), superior to standard Mean or [CLS] pooling (Cite **solution_lesson_node_00016**).
3.  **Dual-Stream Interaction:**
    *   **Semantic Stream:** Compute explicit geometric interaction terms from the pooled embeddings $u$ and $v$: $|u - v|$ and $u \cdot v$. These primitives provide a stronger inductive bias for comparison than learnable attention mechanisms in this regime (Cite **solution_lesson_node_00025**).
    *   **Structural Stream:** A vector of **Explicit Relative Scalar Features** (Differences and Ratios).
4.  **Gated Fusion Mechanism (Structural Innovation):** Instead of simple concatenation, process the Semantic Stream and Structural Stream through independent dense projections to map them to a shared latent space. Then, apply a **Gating Unit** (Sigmoid activation) that learns a scalar coefficient $\alpha$ for each sample. The final representation is a weighted combination (e.g., $\alpha \cdot H_{sem} + (1-\alpha) \cdot H_{struct}$) or a gated concatenation.
    *   *Rationale:* This allows the model to dynamically shift focus. For example, if the structural disparity is high (e.g., one response is empty or significantly shorter), the gate can prioritize the "hard" structural signal (Cite **solution_lesson_node_00010**). Conversely, if structures are identical, it can prioritize the semantic nuance, preventing the "distraction" from auxiliary features observed previously (Cite **solution_lesson_node_00020**).

### Data
1.  **Dataset Strategy:** Train on the **full training dataset** (~41k samples). Do not subsample, as data volume is the primary driver of performance (Cite **solution_lesson_node_00019**).
2.  **Feature Engineering:**
    *   **Strict Relative Constraint:** Compute global statistics (Character count, Word count, Newline count) but convert them strictly into **Pairwise Differences** ($A-B$) and **Ratios** ($A/B$).
    *   **Exclusion:** Explicitly exclude absolute values to prevent the model from learning non-generalizable heuristics (Cite **solution_lesson_node_00020**) and exclude local token counts (e.g., bold tags) which are better handled by the attention mechanism (Cite **solution_lesson_node_00018**).
    *   **Orthogonality:** Retain newline counts as they provide orthogonal formatting signals (Cite **solution_lesson_node_00006**).
3.  **Preprocessing:** Tokenize inputs using the `deberta-v3-base` tokenizer with a max length of 512 tokens.

### Training
1.  **Optimization:**
    *   **Gradient Accumulation:** Accumulate gradients to achieve an **Effective Batch Size of 32**. This stabilizes the noisy gradients inherent in Siamese networks (Cite **solution_lesson_node_00026**).
    *   **Differential Learning Rates:** Use `1e-5` for the Backbone and `1e-4` for the Head/Pooling layers. This conservative 10x ratio prevents the random head from destabilizing the pre-trained weights (Cite **solution_lesson_node_00026**).
2.  **Convergence Strategy:**
    *   **Overshooting & Restoration:** Set the training schedule to 3-4 epochs (longer than the expected 2-epoch peak). Use a **Model Checkpoint** callback to save the state with the lowest Validation Log Loss and restore it for inference. This is more robust to stochastic fluctuations than hard-stopping (Cite **solution_lesson_node_00027**).
    *   **Loss Monitoring:** Continue training until the **Training Loss drops to or below the Validation Loss** to ensure the model is not underfitting (Cite **solution_lesson_node_00015**).
3.  **Regularization:** Apply Early Stopping (patience=2) to prevent the rapid overfitting characteristic of this dataset (Cite **solution_lesson_node_00021**).

### Evaluation
1.  **Inference:** Pass test set pairs through the Siamese backbone.
2.  **Gated Prediction:** Compute the semantic and structural streams, pass them through the learned Gated Fusion Head, and generate the final probability distribution via the MLP.
