The implementation strategy follows a streamlined pipeline:
1.  **Setup**: Initialize the environment and set random seeds for reproducibility.
2.  **Data Loading**: Use the provided `DataHandler` to load and preprocess the data, leveraging caching to minimize runtime.
3.  **Training**: Train a Logistic Regression model. To adhere to the "fast baseline" requirement, we will limit the training set to 100,000 samples. This ensures the code runs quickly while still providing a meaningful baseline.
4.  **Validation**: Evaluate the model on the full validation set, compute the ROC AUC, and print it in the strictly required format.
5.  **Failure Analysis**: Compute the correlation between the absolute prediction errors and the input features on the validation set. This identifies which features are most associated with model errors.
6.  **Submission**: Generate predictions for the test set and save the result to the submission file.
