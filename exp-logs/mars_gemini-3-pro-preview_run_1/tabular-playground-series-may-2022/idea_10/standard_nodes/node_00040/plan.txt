The implementation strategy is as follows:

1.  **Configuration**: Initialize the environment using the provided `Config` class. We override `Config.EPOCHS` to 20 to ensure the training completes efficiently within the time limit while leveraging the A100 GPU's throughput.
2.  **Data Loading**: Utilize `get_dataloaders` to load the dataset. This includes the semi-supervised training set (labeled training data + unlabeled test data), the validation set, and the test set.
3.  **Model Instantiation**: Dynamically detect the number of numerical features from a data batch and instantiate the `SSDeGUT` (Semi-Supervised Denoising Granular Unified Transformer) model.
4.  **Training**: Execute the training loop using the `Trainer` class. The trainer handles the combined classification and reconstruction loss, optimization, and saving the best model based on validation AUC.
5.  **Validation & Analysis**: Reload the best model weights and perform inference on the validation set. Calculate the final ROC AUC score with full precision. Perform failure analysis by calculating the correlation between the model's error magnitude ($|y_{true} - y_{pred}|$) and the input features to identify systematic weaknesses.
6.  **Submission**: Compare the final validation AUC against the required threshold (0.9977872734278943). If the threshold is exceeded, generate the submission file using `Trainer.predict`.
