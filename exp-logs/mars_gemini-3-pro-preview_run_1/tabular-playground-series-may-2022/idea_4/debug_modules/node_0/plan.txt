The following script demonstrates the usage of the provided library files (`config.py`, `data_utils.py`, `model.py`, `train_utils.py`) to solve the manufacturing control task.

### Strategy Outline
1.  **Configuration Override**: We first import the `Config` class and override specific parameters (e.g., `DEBUG_SAMPLE_SIZE`, `EPOCHS`, `BATCH_SIZE`, `WORKING_DIR`) to ensure the demonstration runs quickly and uses a separate workspace.
2.  **Component Verification**: We systematically instantiate and verify the core components:
    *   **Tokenizer**: We verify `CharTokenizer` correctly maps characters to indices and handles padding.
    *   **Dataset**: We verify `ManufacturingDataset` returns tensors of the expected shape and type.
    *   **Data Loading**: We call `get_dataloaders` to process the raw data (using the debug subset) and verify the resulting DataLoaders yield correct batch sizes.
3.  **Model Verification**: We instantiate the `HybridTransformer` model (after data loading ensures the vocabulary size is set) and perform a dummy forward pass to confirm the architecture produces the correct output shape.
4.  **Training & Inference**: We execute the `run_training` loop for a single epoch on the small subset, followed by the `predict` function to generate a submission file. We assert that the model checkpoint and submission file are correctly created.
