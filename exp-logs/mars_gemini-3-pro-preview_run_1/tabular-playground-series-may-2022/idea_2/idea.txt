# Deep Neural Network with Entity Embeddings and Sequence Aggregates

## Model
To address the limitations of linear baselines and exploit the complex interactions within the data, I propose a **Deep Neural Network (DNN) architecture with Entity Embeddings**.

*   **Embedding Layer for Sequences:** Instead of using One-Hot Encoding which treats character positions as orthogonal and independent, the `f_27` string sequence will be split into individual characters, and each position will be mapped to a dense vector using a learnable **Entity Embedding** layer. This allows the model to learn distributed representations of characters and their semantic relationships across positions.
*   **Dense Backbone:** The learned embeddings will be flattened and concatenated with the continuous numerical features. This combined input will be fed into a Multi-Layer Perceptron (MLP) consisting of several fully connected layers with non-linear activation functions (e.g., ReLU or Swish), Batch Normalization, and Dropout. This architecture is specifically designed to capture the high-order **non-linear interactions** that the linear baseline failed to model (Cite solution_lesson_node_00001).

## Data
*   **Sequence Tokenization:** The `f_27` column will be tokenized into fixed-length integer sequences (mapping characters to indices) to serve as input for the embedding layer.
*   **Global Summary Statistics:** We will explicitly engineer and append the **count of unique characters** in the `f_27` sequence to the numerical input vector. This step strictly adheres to the finding that global sequence properties provide critical signals that the model cannot easily infer from isolated positions (Cite solution_lesson_node_00003).
*   **Normalization:** All continuous numerical features (`f_00`–`f_30`) and the engineered count features will be standardized (e.g., Z-score normalization) to ensure stable convergence during gradient-based training.

## Training
*   **Loss Function:** The model will be trained to minimize **Binary Cross-Entropy** loss.
*   **Optimizer:** We will use the **AdamW** optimizer, which decouples weight decay from gradient updates, providing better regularization for the embedding layers.
*   **Scheduling:** A learning rate scheduler (such as OneCycleLR or Cosine Annealing) will be employed to manage the learning trajectory, allowing for a rapid initial learning phase followed by fine-tuning.
*   **Regularization:** Early stopping based on Validation AUC will be used to prevent overfitting.

## Evaluation
*   **Inference:** The preprocessed test data (tokenized sequences and normalized numericals) will be passed through the trained network.
*   **Output:** The final sigmoid activation output will provide the probability of the machine being in state `1`, which will be used directly for the submission.
