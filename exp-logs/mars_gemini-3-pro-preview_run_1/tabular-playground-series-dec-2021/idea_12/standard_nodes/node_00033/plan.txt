The `torch.OutOfMemoryError` was caused by an overly aggressive `KNN_BATCH_SIZE` (10,000) in `library/config.py`. When computing the pairwise distance matrix between a batch of query samples (10,000) and the reference set (500,000), the GPU attempted to allocate approximately 18.6 GiB of memory, exceeding the available 15.77 GiB capacity. To resolve this, I will reduce the `KNN_BATCH_SIZE` to 2048, which will reduce the memory requirement for the distance matrix to approximately 3.8 GiB, ensuring it fits comfortably within the GPU's VRAM.
