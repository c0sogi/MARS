My optimization strategy focuses on maximizing the utility of the full dataset and reducing variance through homogeneous ensembling, while removing computationally expensive and redundant components.

1.  **Remove k-NN Features**: I will remove the k-NN feature injection pipeline. Lesson `solution_lesson_node_00034` demonstrated that these features are redundant for gradient boosting on this dataset and incur significant computational cost.
2.  **Full Dataset Training**: I will revert to training on the full 2.8M sample training set. Lesson `solution_lesson_node_00002` showed that subsampling limits performance on GPU-accelerated workflows.
3.  **Seed Averaging Ensemble**: Instead of a single model, I will train 3 XGBoost models with different random seeds on the full training data and average their predictions (Seed Averaging). This leverages the "Homogeneous Ensembling" concept from Lesson `solution_lesson_node_00012` to reduce variance and improve the validation score, which is critical to beating the high threshold.
4.  **Hyperparameter Tuning**: I will increase `max_depth` from 10 to 11 (Cite `solution_lesson_node_00013`) to allow the model to capture finer patterns in the larger dataset.
5.  **Enhanced Failure Analysis**: I will implement the continuous "Error Magnitude" metric (Cite `solution_lesson_node_00022`) for failure analysis to provide higher-resolution diagnostics.

def inject_knn_features(
    ref_df: pd.DataFrame,
    query_df: pd.DataFrame,
    knn_cols: list,
    exclude_self: bool = False,
) -> pd.DataFrame:
    """
    Generates Manifold-Aware k-NN features for query_df using ref_df as the reference set.

    Args:
        ref_df: The reference dataset (e.g., training fold).
        query_df: The dataset to generate features for (e.g., val fold or test set).
        knn_cols: List of base feature names to use for distance calculation.
        exclude_self: Whether to exclude the nearest neighbor (self). True for Train-on-Train.

    Returns:
        pd.DataFrame: query_df with appended k-NN feature columns.
    """
    # Identify scaled columns used for distance calculation (created in preprocess_data)
    scaled_cols = [f"{c}_scaled" for c in knn_cols]

    # Validation
    if not all(c in ref_df.columns for c in scaled_cols):
        raise ValueError(f"Reference DataFrame missing scaled columns: {scaled_cols}")
    if not all(c in query_df.columns for c in scaled_cols):
        raise ValueError(f"Query DataFrame missing scaled columns: {scaled_cols}")

    # Prepare data for GPU
    X_ref = ref_df[scaled_cols].values
    X_query = query_df[scaled_cols].values
    y_ref = ref_df[Config.TARGET_COL].values

    # Initialize and fit KNN
    device = Config.XGB_PARAMS.get("device", "cuda")
    knn = KNNFeatureExtractor(k=Config.KNN_K, device=device)
    knn.fit(X_ref, y_ref)

    # Transform
    # Use Config.KNN_BATCH_SIZE or a safe default if not set
    batch_size = getattr(Config, "KNN_BATCH_SIZE", 2048)
    knn_feats = knn.transform(X_query, batch_size=batch_size, exclude_self=exclude_self)

    # Clear GPU memory immediately
    knn.clear_memory()
    del knn

    # Align index with query dataframe and concatenate
    knn_feats.index = query_df.index
    return pd.concat([query_df, knn_feats], axis=1)
