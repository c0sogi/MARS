Implementation Strategy:
1.  **Environment Setup**: Initialize the environment with a fixed random seed for reproducibility and set up a logger.
2.  **Data Loading & Preprocessing**: Load the preprocessed training, validation, and test datasets using the `preprocess_data` function. To adhere to the "fast baseline" requirement and the 2-hour time limit, I will subsample the training data to 500,000 samples. This size provides a good balance between training speed and model performance (density for k-NN).
3.  **Target Encoding**: Encode the categorical target variable `Cover_Type` using `LabelEncoder`.
4.  **Feature Engineering (Manifold Injection)**:
    *   Inject k-NN features into the **Training Set** using itself as the reference (excluding self-matches to prevent leakage).
    *   Inject k-NN features into the **Validation Set** using the Training Set as the reference.
    *   This adds local density and class prior probabilities as features.
5.  **Model Training**: Initialize the `XGBoostTrainer` and train the model on the subsampled training data, using the validation set for early stopping.
6.  **Validation & Metrics**: Generate predictions for the validation set. Calculate the exact accuracy and print it in the required format: `Final Validation Metric: <value>`.
7.  **Failure Analysis**: Calculate the correlation between the binary error vector (correct/incorrect) and all input features on the validation set. Print the top features associated with model errors.
8.  **Submission**: If the validation accuracy exceeds the threshold (`0.9628180555555556`), inject k-NN features into the **Test Set** (using Training Set as reference), generate predictions, inverse-transform the labels, and save the submission file to `./submission/submission.csv`.
