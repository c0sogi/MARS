Implementation Strategy:
1.  **Setup and Patching**: To ensure the demonstration runs quickly and stays within memory limits, we will monkey-patch the `DataProcessor.load_raw_data` method. Instead of loading the full 3.6 million row dataset, the patched method will load a small subset (e.g., 2000 rows) from the metadata CSVs. This allows the subsequent feature engineering and caching logic to execute normally but almost instantly.
2.  **XGBoost Demonstration**:
    *   We will invoke the `DataProcessor` to generate the XGBoost-specific dataset (with One-Hot Encoding preserved). Because of the patch, this creates a small cached dataset.
    *   We will then run the `run_xgb_cv` function with `n_splits=2` to perform a quick 2-fold cross-validation.
    *   We will validate the shape of the predictions and the consistency of the returned data.
3.  **ResNet Demonstration**:
    *   We will invoke the `DataProcessor` again to generate the Neural Network-specific dataset (using dense indices and QuantileTransformer).
    *   We will run `run_resnet_cv` with reduced epochs (`epochs=1`) and `n_splits=2`.
    *   We will validate the output shapes and ensure the model training loop completes successfully.
4.  **Dataset Class Verification**:
    *   We will manually instantiate the `ForestDataset` (aliased from `TabularDataset`) using the processed data to verify that it correctly yields tensors for categorical and continuous features.
