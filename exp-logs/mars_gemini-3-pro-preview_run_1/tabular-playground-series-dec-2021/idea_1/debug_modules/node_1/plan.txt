The `ImportError` is caused by a module name collision where the standard or environment-installed `utils` package is being loaded instead of the local `library/utils.py`. This happens because `sys.path.append("./library")` places the local directory at the end of the search path. To fix this, I will replace `sys.path.append` with `sys.path.insert(0, ...)` in `runfile.py`, `library/data_manager.py`, and `library/model_wrapper.py`. This prioritizes the local `./library` directory, ensuring the correct modules are imported.

from utils import set_seed, save_submission
=======
# Add library path to allow imports from the provided modules
sys.path.insert(0, "./library")
