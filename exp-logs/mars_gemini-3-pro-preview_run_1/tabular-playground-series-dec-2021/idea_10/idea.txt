Based on the comprehensive analysis of the previous attempts and the accumulated lessons, I propose a **Target-Encoded Homogeneous Ensemble with Geometric Priors**. This strategy addresses the identified weakness of the model in handling specific categorical sub-populations (evidenced by the correlation of errors with `Wilderness_Area` in **Lesson 00022**) by introducing a **Statistical Feature Engineering Paradigm**. This moves beyond the purely physical features used previously to include explicit Bayesian priors derived from the target distribution.

# Model
The core architecture will remain the **Homogeneous Ensemble of XGBoost Classifiers**, as this has proven superior to heterogeneous mixtures (**Cite solution_lesson_node_00006**) and stacking (**Cite solution_lesson_node_00018**).
*   **Backbone:** We will utilize the **XGBoost** classifier with **GPU acceleration** (`tree_method='hist'`, `device='cuda'`). This setup maximizes efficiency and performance (**Cite solution_lesson_node_00002**).
*   **Configuration:** We will maintain the high-capacity configuration (`max_depth=10`, `eta=0.05`) that successfully balances complexity and convergence, avoiding the diminishing returns of aggressive fine-tuning (**Cite solution_lesson_node_00004**).
*   **Ensemble Structure:** The model will be a **Stratified 5-Fold Bagged Ensemble**. This ensures robust variance reduction without diluting the strong signal of the best algorithm (**Cite solution_lesson_node_00012**).

# Data
We will implement a **Tri-View Feature Engineering Pipeline** that combines physical, structural, and statistical representations of the data.
1.  **Data Volume:** We will load the **Full Training Dataset** (2.8M+ samples). We will strictly avoid subsampling, as data quantity is the primary driver of performance (**Cite solution_lesson_node_00009**).
2.  **View 1: Physics-Informed Geometric Features (Exploitation):** We will retain the critical geometric transformations: Euclidean Distance to Hydrology ($\sqrt{H^2 + V^2}$), Relative Elevation ($Elevation - Vertical\_Dist$), and Cyclic Aspect encoding. These features resolve spatial dependencies that trees struggle to approximate (**Cite solution_lesson_node_00007**).
3.  **View 2: Dual-Representation Categoricals (Exploitation):**
    *   **Retention:** We will **keep** the original One-Hot Encoded (OHE) binary columns to allow granular splits (**Cite solution_lesson_node_00019**).
    *   **Augmentation:** We will also generate **Dense Integer Indices** for `Soil_Type` and `Wilderness_Area`, ensuring we **explicitly sort the column names numerically** before indexing to preserve ordinal semantics (**Cite solution_lesson_node_00014**).
4.  **View 3: Statistical Priors via Target Encoding (Innovation):**
    *   We will introduce **Multi-Class Target Encoding** for the high-cardinality `Soil_Type` and `Wilderness_Area` indices.
    *   For each categorical value, we will compute the empirical probability of each target class (e.g., $P(Class=1 | SoilType=X)$, $P(Class=2 | SoilType=X)$, ...).
    *   **Rationale:** Previous error analysis (**Cite solution_lesson_node_00022**) showed the model makes high-confidence errors in specific categorical contexts. Explicitly providing the global class probabilities as input features acts as a "Bayesian Prior," allowing the tree to calibrate its predictions against the baseline behavior of that soil type rather than relearning it from scratch via deep splits.

# Training
The training procedure will be upgraded to a **Leakage-Free Cross-Validation Pipeline**.
*   **Protocol:** We will execute a Stratified 5-Fold Cross-Validation loop.
*   **Dynamic Encoding:** Inside the loop, the **Target Encoding** must be fitted *only* on the training folds and then applied to the validation fold. For the test set, we will average the target encodings derived from all 5 training folds. This prevents the data leakage that would occur if we encoded the entire dataset globally.
*   **Optimization:** We will train the XGBoost models to minimize `multi:softmax` loss but explicitly use **Log Loss (`mlogloss`)** for **Early Stopping** (patience=50). This ensures the ensemble optimizes probability calibration—critical for the soft-voting stage—rather than just discrete error rate (**Cite solution_lesson_node_00020**).
*   **Efficiency:** All operations will leverage the NVIDIA A100 GPU (`device='cuda'`) to handle the increased feature dimensionality within the time limit.

# Evaluation
*   **Inference:** We will generate class probability vectors for the test set using all 5 trained models.
*   **Aggregation:** We will compute the **Unweighted Average (Soft Voting)** of the probability vectors. This method effectively averages out the variance of the individual models (**Cite solution_lesson_node_00012**).
*   **Prediction:** The final class label will be selected by applying `argmax` to the averaged probability vector.
