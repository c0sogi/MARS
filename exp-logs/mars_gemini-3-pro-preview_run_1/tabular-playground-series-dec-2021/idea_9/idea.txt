Based on the comprehensive analysis of the previous attempts and the accumulated lessons, I propose a **Confident Self-Training Homogeneous Ensemble with Dual-Representation Features**. This strategy evolves the solution from a purely supervised approach to a semi-supervised pipeline. It leverages the now-optimized supervised baseline—which has successfully maximized data volume and feature representation—to exploit the unlabeled test data structure, addressing the "Competence Threshold" requirement for effective pseudo-labeling.

# Model
The core architecture will be a **Homogeneous Ensemble of XGBoost Classifiers** implemented in a two-stage **Self-Training (Teacher-Student)** pipeline.
*   **Backbone:** We will utilize the **XGBoost** classifier with **GPU acceleration** (`tree_method='hist'`, `device='cuda'`). This model has consistently proven to be the most efficient and performant backbone. **Cite solution_lesson_node_00002**.
*   **Configuration:** We will strictly adhere to the high-capacity configuration (`max_depth=10`, `eta=0.05`) that balances complexity with convergence speed. We will avoid aggressive fine-tuning which yields diminishing returns. **Cite solution_lesson_node_00004**.
*   **Ensemble Structure:** Both the Teacher (Stage 1) and Student (Stage 2) models will be **Stratified 5-Fold Bagged Ensembles**. This homogeneous approach effectively reduces variance without diluting the strong signal of the best algorithm, unlike heterogeneous mixtures. **Cite solution_lesson_node_00006, solution_lesson_node_00012**.

# Data
We will employ a **Dual-Representation Feature Engineering** strategy that maximizes the information available to the tree splits, combined with a **Data Augmentation** step.
1.  **Data Volume:** We will load the **Full Training Dataset** (2.8M+ samples). We will strictly avoid subsampling, as data quantity is the primary driver of performance. **Cite solution_lesson_node_00009**.
2.  **Physics-Informed Features (Exploitation):** We will generate the geometric features identified as critical: Euclidean Distance to Hydrology ($\sqrt{H^2 + V^2}$), Relative Elevation ($Elevation - Vertical\_Dist$), and Cyclic Aspect encoding. **Cite solution_lesson_node_00007**.
3.  **Dual-Representation for Categoricals (Exploitation):**
    *   **Retention:** We will **retain** the original One-Hot Encoded (OHE) binary columns (e.g., `Soil_Type1`...`Soil_Type40`) to allow efficient isolation of specific categories. **Cite solution_lesson_node_00019**.
    *   **Augmentation:** We will *also* generate **Dense Integer Indices** for `Soil_Type` and `Wilderness_Area`. Crucially, we will **explicitly sort the column names numerically** before indexing to preserve ordinal semantics. **Cite solution_lesson_node_00014**.
4.  **Pseudo-Label Augmentation (Innovation):** The training set for Stage 2 will be augmented with high-confidence predictions from the test set (generated in Stage 1).

# Training
The training will proceed in a **Two-Stage Pipeline** to ensure the pseudo-labels are generated by a fully competent model.

1.  **Stage 1: Teacher Training:**
    *   Perform **Stratified 5-Fold Cross-Validation** on the original training set.
    *   **Optimization:** Train 5 XGBoost models minimizing `multi:softmax` but using **Log Loss (`mlogloss`)** for Early Stopping (patience=50). This ensures the ensemble optimizes probability calibration, which is critical for identifying high-confidence samples. **Cite solution_lesson_node_00020**.
    *   **Inference:** Generate probability predictions for the **Test Set** using this Teacher Ensemble.

2.  **Stage 2: Student Training:**
    *   **Filtering:** Identify test samples where the Teacher Ensemble's maximum class probability exceeds a strict threshold (e.g., **0.99**). This high threshold ensures we only augment with "safe" labels, respecting the competence threshold principle. **Cite solution_lesson_node_00010**.
    *   **Augmentation:** Append these pseudo-labeled samples to the training folds.
    *   **Retraining:** Train a fresh **Stratified 5-Fold Ensemble** of XGBoost models on the augmented data.
    *   **Validation Constraint:** We will validate the Student models using the **original** validation folds (excluding pseudo-labels) to ensure the Out-Of-Fold (OOF) metric remains a reliable proxy for true performance and prevents leakage.

# Evaluation
*   **Inference:** Pass the full test set through the 5 trained **Student** models from Stage 2.
*   **Aggregation:** Compute the **Unweighted Average (Soft Voting)** of the class probability vectors. This method effectively averages out the variance of the individual models. **Cite solution_lesson_node_00012**.
*   **Prediction:** Select the class with the highest probability from the averaged vector for the final submission.
