Based on the analysis of the provided lessons and the performance of previous ideas, I propose a **Two-Stage Homogeneous Stacked Generalization** strategy. This approach evolves the solution from a simple averaged ensemble (Bagging) to a learned combination (Stacking) that can correct systematic errors, while strictly adhering to the data volume and feature engineering principles that have proven successful.

# Model
The architecture will be a **Two-Stage Homogeneous Stacking Ensemble** utilizing **XGBoost** for both the base and meta-learner levels.
*   **Level 0 (Base Learners):** We will train a **Stratified 5-Fold Ensemble** of XGBoost classifiers. This retains the high-capacity backbone (`max_depth=10`, `eta=0.05`) that was identified as the strongest individual performer. **Cite solution_lesson_node_00002**.
*   **Level 1 (Meta Learners):** Instead of the naive soft-voting (averaging) used previously, which treats all models and samples equally, we will train a second layer of XGBoost models. This meta-layer will take the class probabilities output by Level 0 and, crucially, the key physical features, to learn a contextual correction function (e.g., "Trust Model A less when Elevation > 3000m").
*   **Homogeneity:** Unlike previous failed stacking attempts that introduced weaker models like Neural Networks or LightGBM which diluted performance (**Cite solution_lesson_node_00006, solution_lesson_node_00009**), this architecture uses the superior XGBoost algorithm at both levels to maintain high signal quality.

# Data
*   **Data Volume:** We will utilize the **Full Training Dataset** (2.8M+ samples) for both levels. We explicitly reject subsampling, as previous experiments proved that data quantity is the primary driver of performance and must not be sacrificed for architectural complexity. **Cite solution_lesson_node_00009**.
*   **Feature Engineering (Exploitation):**
    1.  **Geometric Transformations:** We will generate the physics-informed features: Euclidean Distance to Hydrology, Relative Elevation, and Cyclic Aspect. **Cite solution_lesson_node_00007**.
    2.  **Reverse One-Hot Encoding:** We will condense the binary `Soil_Type` and `Wilderness_Area` columns into dense integer indices. Crucially, we will **explicitly sort the column names numerically** before indexing to preserve ordinal semantics, which allows the trees to efficiently group categories. **Cite solution_lesson_node_00014**.
*   **Stacking Features:**
    *   The input to the Level 1 models will be the **concatenation** of the Level 0 Out-Of-Fold (OOF) class probabilities and the **Geometric Features**. We include the features to allow the meta-learner to condition its weighting on the physical context (Passthrough Features).

# Training
*   **Level 0 Training:**
    *   Perform Stratified 5-Fold Cross-Validation on the full dataset.
    *   Train 5 XGBoost models using **GPU acceleration** (`tree_method='hist'`, `device='cuda'`) and **Early Stopping** (patience=50) to manage convergence automatically. **Cite solution_lesson_node_00003**.
    *   Generate OOF predictions for the training set and probability predictions for the test set.
*   **Level 1 Training:**
    *   Perform a secondary Stratified 5-Fold Cross-Validation on the OOF predictions generated by Level 0.
    *   Train 5 new XGBoost models on this meta-dataset.
    *   Use a moderate learning rate (`eta=0.05`) to avoid the pitfalls of aggressive fine-tuning. **Cite solution_lesson_node_00004**.
*   **Cache Management:** We will ensure all training runs on fresh data loading to prevent the "stale cache" failure mode observed previously. **Cite solution_lesson_node_00015**.

# Evaluation
*   **Inference:**
    1.  Pass the Test Set through the 5 Level 0 models to generate 5 sets of probability vectors.
    2.  Average these vectors to create the `Level0_Test_Input`.
    3.  Pass `Level0_Test_Input` (concatenated with test set geometric features) through the 5 Level 1 models.
*   **Aggregation:** Compute the unweighted average of the probabilities from the 5 Level 1 models.
*   **Prediction:** Select the class with the highest probability from the final averaged vector. This method captures the "Ensemble Lift" that OOF metrics often underestimate. **Cite solution_lesson_node_00016**.
