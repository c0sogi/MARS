Implementation strategy:
1.  **Environment Setup**: Initialize the environment, set random seeds for reproducibility, and suppress unnecessary warnings.
2.  **Data Loading**: Use `library.data_loader` to load the dataset. This handles reading the metadata CSVs, concatenating the training and validation sets into a single dataframe for Cross-Validation, and reducing memory usage.
3.  **Feature Engineering**: Apply the `library.feature_engineering` pipeline. This transforms the raw data by adding geometric features, performing PCA on continuous variables to capture rotational variance, and calculating contextual group statistics.
4.  **Model Training**: Instantiate the `library.model_trainer.EnsembleTrainer`. Execute `run_stratified_cv` to train a 5-fold XGBoost ensemble. This method automatically handles the stratified splitting, training, and Out-Of-Fold (OOF) prediction generation.
5.  **Validation & Failure Analysis**:
    *   Report the overall OOF accuracy as the "Final Validation Metric".
    *   Perform failure analysis by calculating the correlation between the model's error magnitude (1 - probability of true class) and the input features. This helps identify which features contribute most to misclassifications.
6.  **Submission Generation**: Compare the validation metric against the specified threshold (`0.9619111111111112`). If the model performs sufficiently well, use `library.inference.InferenceEngine` to generate predictions for the test set and save the `submission.csv` file.
