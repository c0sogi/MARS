This script demonstrates the end-to-end usage of the provided library modules to solve the classification task. It strategically manages imports to override configuration for a fast demonstration run. The process involves:
1.  **Configuration Override**: adjusting `MAX_ROUNDS` and `EARLY_STOPPING_ROUNDS` before importing the trainer module to ensure the demonstration runs quickly (simulating a "debug" mode).
2.  **Data Loading**: Utilizing `data_processor.py` to load and engineer features, then immediately subsampling the data to a minimal set (2,000 samples) to minimize runtime.
3.  **Ensemble Training**: Using `ensemble_trainer.py` to train a 2-fold XGBoost ensemble on the subsampled data.
4.  **Inference**: applying the trained models to generate predictions via `inference_utils.py`.
5.  **Submission**: exporting the results to the specified format.
6.  **Validation**: performing assertions to verify data shapes, model outputs, and file generation.
