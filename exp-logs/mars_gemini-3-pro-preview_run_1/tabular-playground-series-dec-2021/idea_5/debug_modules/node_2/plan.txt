The issue is that XGBoost's `XGBClassifier` (specifically with multi-class objectives) requires target labels to be zero-indexed contiguous integers (0, 1, ..., N-1), but the provided dataset contains 1-based and potentially non-contiguous labels (e.g., 1, 2, 3, 6, 7). This mismatch causes the `ValueError` during the `fit` method. To fix this, I will use `sklearn.preprocessing.LabelEncoder` in `runfile.py` to encode the target variable `y_subset` before passing it to the training function, and then use `inverse_transform` to decode the model's predictions back to the original class labels. I will also ensure the encoded targets are converted back to a Pandas Series to remain compatible with the `train_ensemble` function's use of `.iloc`.
