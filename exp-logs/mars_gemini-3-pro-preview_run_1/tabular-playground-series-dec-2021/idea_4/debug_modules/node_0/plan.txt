This script demonstrates the usage of the provided library modules (`config`, `data_utils`, `model_utils`, `pipeline`) to solve the image classification task on the synthetic dataset.

To ensure the demonstration runs quickly and successfully within the constraints:
1.  It creates a **subsampled dataset** (Train, Val, Test) and caches it, tricking the pipeline into using this small subset instead of the full millions of records.
2.  It generates a corresponding **temporary sample submission file** to match the subsampled test set IDs, preventing shape mismatch errors in the submission generation function.
3.  It **overrides configuration parameters** (reducing estimators, folds, and switching to CPU for low-overhead processing of small data) to complete the run in seconds.
4.  It performs **unit tests** on individual components (feature engineering, model training, augmentation) before running the full pipeline.
