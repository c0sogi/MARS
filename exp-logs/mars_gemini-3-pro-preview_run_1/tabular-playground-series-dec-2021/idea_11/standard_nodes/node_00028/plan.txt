Implementation Strategy:
The solution implements a robust Homogeneous Ensemble pipeline using XGBoost and Supervised Linear Projection (LDA). 
1.  **Data Loading & Processing**: We leverage the provided `process_data` to load cached training and test sets. Crucially, we manually load and process the hold-out validation set (`val.csv`) using `engineer_static_features` to ensure it has the exact same feature space (Physics-informed features + Robust Densification) as the training data.
2.  **Ensemble Architecture**: We employ a Stratified 5-Fold Cross-Validation on the 80% training data (`train.csv`). For each fold:
    *   **Dynamic Feature Learning**: We fit a `SupervisedProjector` (LDA) *only* on the fold's training split to prevent leakage. We then project the fold-train, fold-val, hold-out-val, and test sets into this discriminative subspace and append these as new features.
    *   **Model Training**: We train an XGBoost classifier (GPU-accelerated) on the augmented feature set, using the fold's validation split for early stopping.
    *   **Inference**: We generate probability predictions for both the hold-out validation set and the test set.
3.  **Aggregation & Evaluation**: We average the probability vectors from all 5 models (Soft Voting). We calculate the final accuracy on the hold-out set.
4.  **Failure Analysis**: We compute the correlation between the error vector (misclassifications) and input features to identify weak points.
5.  **Submission**: If the validation accuracy exceeds the specified threshold, we decode the test predictions and generate the submission file.
