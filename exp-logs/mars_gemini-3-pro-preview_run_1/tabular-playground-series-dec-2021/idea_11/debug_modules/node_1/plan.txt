The issue is caused by Python's default argument evaluation behavior: the `output_dir` default value in `save_submission` is bound to `Config.SUBMISSION_DIR` at import time, before `runfile.py` monkey-patches `Config` with the demo paths. As a result, the function saves the submission to the original default location (`./submission`) instead of the updated demo location (`./working/demo_submission`), causing the subsequent file existence check to fail. The fix is to explicitly pass the updated `Config.SUBMISSION_DIR` when calling `save_submission` in `runfile.py`.
