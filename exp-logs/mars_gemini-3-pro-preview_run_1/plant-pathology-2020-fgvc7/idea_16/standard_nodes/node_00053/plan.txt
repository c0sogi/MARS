Here is the implementation of `runfile.py` following the "Decoupled Calibration with Full-Data Seed Ensembling" strategy.

The strategy involves:
1.  **Calibration**: Running a fast 5-Fold Cross-Validation (limited to 6 epochs for speed) to statistically determine the optimal stopping epoch ($E_{opt}$).
2.  **Production**: Training an ensemble of 5 models on the full dataset (Train + Validation) for exactly $E_{opt}$ epochs.
3.  **Validation**: Evaluating the ensemble on the hold-out validation set (defined in metadata) to compute the final metric and perform failure analysis.
4.  **Submission**: Generating predictions on the test set if the validation metric exceeds the threshold.
