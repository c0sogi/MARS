Implementation Strategy:
I will implement the `runfile.py` script to orchestrate the "Full-Data Seed Ensembling with Proxy Calibration" strategy. The workflow consists of three main phases:

1.  **Proxy Calibration (Phase 1)**: I will perform a Stratified 5-Fold Cross-Validation on the training metadata (`train_metadata.csv`). This phase serves two purposes:
    *   **Optimal Epoch Discovery**: I will track the validation AUC across all folds and epochs to identify the global optimal epoch ($E_{opt}$) where the model performance peaks.
    *   **TTA Decision**: I will evaluate the trained fold models with and without Test-Time Augmentation (Horizontal and Vertical Flips) to empirically decide if TTA should be applied during the final inference.

2.  **Production Training (Phase 2)**: Using the $E_{opt}$ derived from Phase 1, I will train an ensemble of 5 ResNet34 models on the **entire** training dataset (100% of `train_metadata.csv`). Each model will be initialized with a different random seed (`Config.ENSEMBLE_SEEDS`) to maximize diversity. This leverages the full dataset for the final models while retaining the regularization benefits of the ensemble.

3.  **Validation & Submission**:
    *   I will evaluate the full ensemble on the hold-out validation set (`val_metadata.csv`) to compute the "Final Validation Metric" required by the task.
    *   I will perform the required failure analysis by calculating the correlation between the prediction error magnitude and image meta-features (intensity, dimensions) on the validation set.
    *   Finally, if the validation metric exceeds the specified threshold, I will generate predictions for the test set (`test_metadata.csv`) using the ensemble and save the submission file.
