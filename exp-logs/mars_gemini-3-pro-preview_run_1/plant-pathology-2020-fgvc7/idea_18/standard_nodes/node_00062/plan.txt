The implementation strategy follows the "Stratified Bagging Ensemble with Out-of-Bag (OOB) Early Stopping" idea.

1.  **Initialization**: We set up the environment, seeds, and directories using the provided `Config` and `utils`.
2.  **Training (Bagging)**: We implement a loop to train 5 independent `AppleResNet34` models.
    *   For each iteration, we use `get_bag_loaders` to retrieve a bootstrapped training set and its corresponding Out-of-Bag (OOB) validation set.
    *   We use `CrossEntropyLoss` weighted by class frequency (calculated via `get_class_weights`) to handle imbalance.
    *   We employ the `Adam` optimizer and `CosineAnnealingWarmRestarts` scheduler.
    *   We perform an initial loss check on the first bag to verify model initialization.
    *   We train for 15 epochs, saving the model checkpoint that achieves the highest OOB AUC for that specific bag.
3.  **Validation Assessment**:
    *   We load the fixed hold-out validation set (`val_metadata.csv`) to compute the final metric required by the task.
    *   We load all 5 trained models and perform ensemble inference (averaging probabilities) on this set.
    *   We calculate and print the `Final Validation Metric` (Mean column-wise ROC AUC).
4.  **Failure Analysis**:
    *   We calculate the error magnitude (1 - probability of the true class) for each validation sample.
    *   We extract image meta-features (width, height, mean intensity) and compute their Pearson correlation with the error magnitude to identify systematic weaknesses.
5.  **Submission**:
    *   If the final validation metric exceeds the threshold `0.9901680711448418`, we generate predictions for the test set using the ensemble and save them to `submission.csv`.
