The `AttributeError: type object 'Config' has no attribute 'n_runs'` occurs because the `Config` class in `library/config.py` lacks the `n_runs` and `seeds` attributes, which are now required by the updated `inference.py` and `trainer.py` modules for the seed averaging ensemble strategy. This is a synchronization issue where the configuration schema was not updated to match the new execution logic (Cite debug_lesson_3). To fix this, I will add the missing `n_runs` (set to 5) and `seeds` (a list of 5 integers) attributes to the `Config` class in `library/config.py`.
