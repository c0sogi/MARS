The implementation plan follows the Progressive Resizing strategy with a ResNet34 backbone. It involves a 5-fold stratified cross-validation on the training metadata. For each fold, the model is trained in two phases: first at 256x256 resolution to learn structural features, and then fine-tuned at 512x512 resolution for fine-grained details. The final evaluation is performed on the hold-out validation set using an ensemble of the 5 fold models with Test-Time Augmentation (TTA). Failure analysis is conducted by correlating prediction errors with image meta-features. Finally, if the validation metric exceeds the threshold, predictions are generated for the test set and saved.
