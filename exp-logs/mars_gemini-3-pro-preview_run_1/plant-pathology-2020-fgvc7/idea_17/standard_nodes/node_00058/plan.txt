The implementation strategy involves orchestrating the High-Density Stratified K-Fold (K=10) training pipeline as defined in the provided library files. I will re-implement the control flow in `runfile.py` to ensure granular access to Out-Of-Fold (OOF) predictions for the required failure analysis and specific metric reporting.

1.  **Setup & Data Loading**: Initialize the environment with the fixed seed and device. Load the training and validation metadata, combining them into a single dataframe to perform the 10-fold stratified split. Load class weights using the provided utility.
2.  **Training Loop**: Iterate through 10 folds. For each fold:
    *   Split data into train/val.
    *   Initialize the `AppleResNet34` model (pretrained).
    *   Train for 15 epochs using Adam optimizer and Cosine Annealing scheduler.
    *   Perform validation at each epoch and save the model checkpoint with the best AUC.
    *   After training, reload the best model and generate OOF predictions for both Single View and TTA View (Horizontal+Vertical flips).
3.  **Validation Assessment**: Aggregate OOF predictions. Calculate the macro-averaged ROC AUC for both Single and TTA views. Select the better strategy and print the `Final Validation Metric` with full precision.
4.  **Failure Analysis**: Calculate the error magnitude (1 - probability of true class) for each sample in the OOF set. Compute image meta-features (Width, Height, Mean Intensity) for all images. Calculate and print the Pearson correlation between error magnitude and these features to identify systematic weaknesses.
5.  **Submission**: Check if the final metric exceeds the threshold (0.990168...). If so, generate predictions on the test set using the ensemble of 10 trained models (applying TTA if it proved beneficial during validation) and save the submission file.
