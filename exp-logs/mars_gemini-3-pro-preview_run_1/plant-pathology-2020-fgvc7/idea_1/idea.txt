To establish a robust and efficient baseline for apple disease detection, I propose a solution based on the **ResNet-18** architecture. This approach prioritizes simplicity and training speed while addressing the class imbalance identified in the data analysis.

# Model
The core of the solution is a **ResNet-18** Convolutional Neural Network.
- **Architecture**: Unlike the EfficientNetV2 (Model 1) which uses complex inverted residual blocks, ResNet-18 uses standard residual blocks with skip connections. This structure allows for efficient gradient flow and easy optimization.
- **Initialization**: The backbone will be initialized with weights pre-trained on ImageNet. This transfer learning approach allows the model to leverage generic feature extractors (edges, textures) immediately, which is crucial given the small dataset size (~1300 training images).
- **Head**: The pre-trained classification head will be replaced with a simple Global Average Pooling layer followed by a single fully connected (Dense) layer with 4 output neurons, corresponding to the target classes (`healthy`, `multiple_diseases`, `rust`, `scab`).

# Data
- **Resizing**: The original high-resolution images (~2048x1365) will be resized to **256x256** pixels. This drastically reduces the input dimensionality, enabling faster training and inference while retaining sufficient detail to identify disease spots.
- **Normalization**: Images will be normalized using the standard ImageNet mean (`[0.485, 0.456, 0.406]`) and standard deviation (`[0.229, 0.224, 0.225]`) to match the pre-trained backbone's expectations.
- **Augmentation**: To provide basic regularization without computational overhead, only **Random Horizontal Flips** and **Random Vertical Flips** will be applied during training.
- **Class Imbalance**: To address the scarcity of the `multiple_diseases` class (only ~5% of data), **Class Weights** will be computed inversely proportional to the frequency of each class in the training set.

# Training
- **Loss Function**: **Weighted Cross-Entropy Loss** will be used. The pre-calculated class weights will be passed to the loss function, penalizing the model more heavily for misclassifying the minority class (`multiple_diseases`), thereby encouraging it to learn features for underrepresented samples.
- **Optimizer**: The **Adam** optimizer will be employed for its adaptive learning rate capabilities, facilitating faster convergence compared to standard SGD. A conservative learning rate (e.g., 1e-4) will be used to fine-tune the pre-trained weights.
- **Strategy**: The model will be trained for a limited number of epochs (e.g., 10-15). Performance will be monitored on the validation set using the ROC AUC metric, and the best-performing model checkpoint will be saved.

# Evaluation
- **Inference**: Test images will undergo the same resizing (256x256) and normalization as the training data. No test-time augmentation (TTA) will be used to maintain high throughput.
- **Output**: The model's raw output logits will be passed through a **Softmax** function to generate a probability distribution across the 4 classes. These probabilities will be mapped to the corresponding `image_id` and formatted according to the submission requirements.
