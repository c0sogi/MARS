The implementation strategy follows a streamlined pipeline to establish a fast and robust baseline for apple disease detection using the ResNet-18 architecture.

1.  **Setup & Configuration**: Initialize the environment by setting a fixed random seed for reproducibility and detecting the available hardware (GPU). Define paths for input data, metadata, and output directories.
2.  **Model Training**: Utilize the pre-implemented `train_model` function from the `library` package. We will train the ResNet-18 model for 10 epochs. This duration is chosen to balance speed and performance, ensuring the model converges sufficiently on the small dataset (~1300 images) without exceeding the time constraints of a "fast baseline".
3.  **Validation & Metric Calculation**:
    *   Load the best-performing model checkpoint.
    *   Perform inference on the hold-out validation set to obtain probability predictions.
    *   Calculate the **Mean Column-wise ROC AUC** score using `sklearn.metrics.roc_auc_score` with the `macro` average and `ovr` (One-vs-Rest) strategy, as required by the task.
    *   Print the metric in the specified format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the error magnitude for each validation sample, defined as $1.0 - P(\text{true\_class})$.
    *   Extract basic meta-features from the validation images (width, height, mean pixel intensity).
    *   Calculate and print the Pearson correlation between the error magnitude and these meta-features to identify potential biases or systematic failures (e.g., does the model fail more on darker images?).
5.  **Submission Generation**: Use the `predict_and_submit` function to generate predictions for the test set and save the formatted `submission.csv` file.
