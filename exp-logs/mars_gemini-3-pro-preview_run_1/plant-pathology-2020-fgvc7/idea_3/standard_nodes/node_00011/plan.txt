Implementation strategy:
1.  **Configuration**: Initialize the `Config` object, overriding `epochs` to 10 to create a fast baseline that fits within the time limit while ensuring reasonable convergence.
2.  **Training & OOF Collection**: Iterate through 5 folds using Stratified K-Fold. For each fold:
    *   Train the model using `library.trainer.run_fold`.
    *   Reload the best saved model state.
    *   Perform inference on the validation set to collect Out-Of-Fold (OOF) predictions and targets.
3.  **Global Validation**: Aggregate the OOF predictions from all folds to calculate the "Mean column-wise ROC AUC" on the entire training dataset.
4.  **Failure Analysis**: Calculate the Mean Squared Error (MSE) for each validation sample. Extract image metadata (width, height, mean intensity) and compute the Pearson correlation coefficient between the error magnitude and these features to identify potential biases.
5.  **Submission Logic**: Compare the global validation metric against the strict threshold (0.9871488489626378).
    *   If the metric is higher, perform inference on the test set using an ensemble of the 5 trained models.
    *   Apply Test-Time Augmentation (TTA) by averaging predictions from original and horizontally flipped images.
    *   Save the formatted predictions to `submission.csv`.
