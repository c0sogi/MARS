The `AttributeError: type object 'Config' has no attribute 'MIN_LR'` occurs because the execution script `runfile.py` references `Config.MIN_LR` to configure the learning rate scheduler, but this attribute is missing from the `Config` class definition in `library/config.py`. This discrepancy between the execution logic and the configuration schema is a classic example of the issue described in **Cite debug_lesson_3**. To fix this, I will add the `MIN_LR` attribute to the `Config` class in `library/config.py` with a default value of `1e-6`.
