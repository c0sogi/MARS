### Implementation Strategy

1.  **Configuration & Setup**: Initialize the environment by setting the random seed and enabling `DEBUG` mode in the `Config` class. This reduces the dataset size (to 64 samples), the number of epochs (to 2), and the number of ensemble splits, ensuring the demonstration runs quickly.
2.  **Data Loading Verification**: Instantiate the training and validation data loaders using `get_data_loaders`. Fetch a single batch to verify the tensor shapes (Batch Size, Channels, Height, Width) and target dimensions (Batch Size, Num Classes).
3.  **Model Instantiation & Forward Pass**: Initialize the `AppleResNet34` model. Perform a forward pass with the fetched batch to ensure the architecture produces logits of the correct shape. Verify the weight initialization logic using the model's built-in check.
4.  **Loss Function Verification**: Calculate class weights from the metadata and instantiate the `WeightedSoftCrossEntropy` loss. Compute the loss on the batch to verify it produces a valid scalar value.
5.  **Optimizer (SAM) Verification**: Initialize the SAM optimizer wrapping an Adam optimizer. Perform a manual optimization step with a closure to verify the parameter update mechanism works without errors.
6.  **Pipeline Integration**: Execute the `train_single_fold` function for the first seed defined in the configuration. This tests the complete training loop, including backpropagation, logging, and checkpointing.
7.  **Inference & Submission**: Run `generate_submission` to generate predictions using the trained model. Verify that the output CSV file is created and contains the expected number of rows and columns.
