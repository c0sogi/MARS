The implementation strategy is as follows:
1.  **Setup**: Define input (`./input`) and output (`./metadata`) directories. Ensure the output directory exists.
2.  **Load Training Metadata**: Read `input/train.csv` to get segment IDs and targets.
3.  **Construct Paths**: Add a `file_path` column to the dataframe pointing to the corresponding CSV file in `train/` relative to the input directory (e.g., `train/12345.csv`).
4.  **Stratified Split**: Since this is a regression task (`time_to_eruption`), create a temporary binning column using quantiles on the target variable. Use this binning column to perform a stratified 80/20 split using `sklearn.model_selection.train_test_split` with `random_state=42`. This ensures the validation set has a representative distribution of eruption times.
5.  **Process Test Data**: List all CSV files in `input/test/`. Extract segment IDs from filenames and create a dataframe with `segment_id` and `file_path` (e.g., `test/67890.csv`). Initialize `time_to_eruption` as 0 or NaN for consistency.
6.  **Save Metadata**: Save the resulting DataFrames to `metadata/train.csv`, `metadata/val.csv`, and `metadata/test.csv`.
7.  **Verification**:
    -   **Load**: Reload the generated metadata files.
    -   **Stats**: Print shapes and target statistics (mean, std) for train/val to show distribution alignment.
    -   **Path Check**: Randomly sample 1000 paths from each dataset and verify they exist in `./input`. Raise an error if >50% are missing.
    -   **Split Check**: Verify the validation set size is approximately 20% of the total training data and that the split logic executed correctly.
