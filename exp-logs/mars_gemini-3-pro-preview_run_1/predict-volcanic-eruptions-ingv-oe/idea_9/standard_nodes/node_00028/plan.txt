Implementation of the `runfile.py` script.

This script orchestrates the **Parsimonious Beamformed Stacking Strategy**. It overrides the configuration to ensure a fast baseline execution (limiting epochs and sample size), trains the heterogeneous ensemble (LightGBM + EfficientNet), evaluates performance on the hold-out validation set, performs failure analysis by correlating errors with features, and generates a submission if the metric threshold is met.
