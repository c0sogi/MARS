2.  **Optimize LightGBM Capacity**: I will increase the `num_leaves` from 31 to 127. Lesson `solution_lesson_node_00030` indicates that reducing model capacity degraded the tabular branch's performance, which is the dominant signal carrier.
3.  **Stabilize CNN Training**: I will introduce gradient clipping in the training loop. The previous run exhibited a catastrophic gradient explosion (MAE ~4.6e60) in one fold. Clipping gradients will prevent this instability.
4.  **Full Data Training**: I will disable the `DEBUG` mode and remove the overrides that reduced epochs and estimators in `runfile.py`. Training on the full dataset with sufficient epochs (15) is critical for the deep learning branch to generalize effectively.

def compute_beamformed_sensor(df_segment: pd.DataFrame) -> pd.Series:
    """
    Computes a virtual beamformed sensor by averaging normalized signals.
    Implements Delay-and-Sum Beamforming assuming simultaneous arrival.
    """
    # Select physical sensors
    sensor_data = df_segment[Config.SENSOR_COLS].copy()

    # Fill NaNs with 0 (equilibrium) before normalization
    sensor_data = sensor_data.fillna(0)

    # Normalize each sensor: (x - mean) / (std + epsilon)
    # This ensures each sensor contributes equally to the sum
    means = sensor_data.mean()
    stds = sensor_data.std()
    normalized = (sensor_data - means) / (stds + 1e-6)

    # Compute mean across sensors (Beamforming)
    virtual_sensor = normalized.mean(axis=1)
    return virtual_sensor
