Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose the **Robust Audio-Seismic & Contrast-Normalized Stacking Strategy**. This approach structurally evolves the solution by synthesizing the high-capacity feature engineering of the "Current Best" solution with the superior vision preprocessing of the "Parsimonious" attempt, while strictly enforcing the robustness constraints identified in the failure analysis.

# Model
The solution utilizes a **Heterogeneous Stacking Ensemble** that integrates a high-capacity Tabular Learner with a Contrast-Normalized Vision model. This design specifically addresses the "weak vision" bottleneck of Idea 5 and the "tabular underfitting" failure of Idea 9.

1.  **Branch A: Robust Audio-Seismic Regressor (LightGBM)**
    *   **Architecture:** A Gradient Boosting Machine (LightGBM) optimized for a high-dimensional feature space.
    *   **Structural Innovation (Robust Feature Selection):** Unlike Idea 9 (which reduced capacity via beamforming) or Idea 5 (which included noisy high-order features), this branch employs a **"Full-Resolution, Noise-Robust"** paradigm. It retains granular, per-sensor features (Cite solution_lesson_node_00029) but strictly filters them through a "Robustness Gate" (excluding min/max and high-order spectral coefficients) to maximize signal-to-noise ratio without sacrificing model capacity.

2.  **Branch B: Contrast-Normalized Vision Model (EfficientNet)**
    *   **Architecture:** An **EfficientNet-B0** CNN modified to accept 10-channel inputs.
    *   **Structural Innovation (Instance Standardization):** We incorporate the **Per-Sample Standardization** layer from Idea 9. This normalizes each spectrogram individually ($X_{norm} = \frac{X - \mu}{\sigma}$), allowing the CNN to learn morphological seismic textures independent of the global signal amplitude, which varies by sensor distance (Cite solution_lesson_node_00030).

3.  **Meta-Learner:**
    *   A **Ridge Regression** model (Unconstrained) trained on the Out-of-Fold (OOF) predictions. This preserves the ability to correct systematic biases using the Vision model's orthogonal predictions, unlike constrained blending (Cite solution_lesson_node_00027).

# Data
The data pipeline implements strict safeguards against stale data (Cite solution_lesson_node_00002) and enforces the specific feature engineering lessons learned.

1.  **Branch A Preprocessing (Tabular):**
    *   **Input:** All 10 Physical Sensors (No Beamforming/PCA replacement).
    *   **Robust Cepstral Features (MFCCs):** Extract Mel-frequency cepstral coefficients, but strictly limit them to **Coefficients 1-13** to capture the spectral envelope (timbre) while rejecting the noise-prone high-frequency coefficients (14-40) (Cite solution_lesson_node_00025).
    *   **Robust Aggregation:** For all spectral features (MFCCs, FFT), compute *only* **Robust Statistics** (Mean, Std, Q05, Q95). Explicitly **exclude** Min and Max statistics, which were identified as noise artifacts in Idea 5 (Cite solution_lesson_node_00021).
    *   **Energy & Structure:** Include **Absolute Quantiles** (`quantile(abs(x))`) to capture polarity-independent energy (Cite solution_lesson_node_00014) and **Raw Zero-Crossing Rate** (without centering) to utilize the signal offset as an amplitude gate (Cite solution_lesson_node_00007).
    *   **Spatial Interaction:** Compute the **Correlation Matrix** between all sensor pairs to capture spatial coherence (Cite solution_lesson_node_00017).
    *   **Exclusion:** Explicitly avoid raw gradients/derivatives to prevent high-frequency noise overfitting (Cite solution_lesson_node_00020).

2.  **Branch B Preprocessing (Vision):**
    *   **Input:** Log-Mel Spectrograms stacked into a `(10, Freq, Time)` tensor.
    *   **Preprocessing:** Apply **Instance Standardization** (per-image mean subtraction and variance scaling) before feeding into the CNN (Cite solution_lesson_node_00030).
    *   **Target Scaling:** Apply **Log-Scaling** (`np.log1p`) to the `time_to_eruption` target to prevent convergence failure (Cite solution_lesson_node_00009).

# Training
1.  **Strategy:** 5-Fold Cross-Validation for both branches to generate aligned OOF predictions.
2.  **Tabular Branch:** Train LightGBM with early stopping based on validation MAE.
3.  **Vision Branch:** Train using **AdamW** with **Cosine Annealing**. Crucially, maintain the extended training duration (e.g., 20+ epochs) to ensure convergence (Cite solution_lesson_node_00017).
4.  **Meta-Learner:** Train Ridge Regression on the OOF predictions against the ground truth.

# Evaluation
1.  **Inference:**
    *   Generate the "Robust Audio-Seismic" feature matrix and "Contrast-Normalized" Spectrograms for the test set.
    *   Predict with LightGBM (Branch A).
    *   Predict with EfficientNet (Branch B) and apply **Inverse Target Transformation** (`np.expm1`).
2.  **Submission:** Input both prediction vectors into the trained Ridge Meta-Learner to produce the final `time_to_eruption` estimate.
