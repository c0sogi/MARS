The following script demonstrates the complete pipeline for the volcano eruption prediction task using the provided library files.

### Implementation Strategy
1.  **Configuration Override**: To ensure the script runs quickly within the demonstration limits, we override the `Config` class attributes. We enable `DEBUG` mode, reduce the number of cross-validation folds to 2, minimize the number of estimators for LightGBM, and set the CNN epochs to 1.
2.  **Pipeline Execution**:
    *   **Branch A (LightGBM)**: We execute `run_lgbm_cv` to extract tabular features (MFCCs, robust stats) and train a Gradient Boosting model.
    *   **Branch B (CNN)**: We execute `run_cnn_cv` to generate Log-Mel Spectrograms and train an EfficientNet-B0 model.
    *   **Meta-Learner**: We pass the Out-of-Fold (OOF) predictions and Test predictions from both branches to `train_ridge_stacker` to generate the final ensemble prediction.
3.  **Validation**: At each step, we assert that the output DataFrames are non-empty and contain the expected columns (`segment_id`, `pred`, `time_to_eruption`).
