Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose a **Parsimonious Source-Aware Stacking Strategy**. This approach structurally evolves the solution by correcting the "Feature Explosion" and "Constrained Blending" failures of previous iterations, while integrating a novel "Beamforming" concept to robustly model the seismic source.

# Model
The solution utilizes a **Heterogeneous Stacking Ensemble** designed to maximize the performance of the dominant tabular modality while leveraging the orthogonal diversity of the vision modality (Cite solution_lesson_node_00015).

1.  **Branch A: Source-Aware Tabular Regressor (LightGBM)**
    *   **Architecture:** A Gradient Boosting Machine (LightGBM) optimized for a dense but rigorously pruned feature space.
    *   **Structural Innovation (Beamformed Virtual Sensor):** Instead of using PCA (which introduced noise in Idea 6), we will implement **Sensor Beamforming**. We will generate a "Virtual Source" channel by averaging the normalized waveforms of all 10 sensors. This constructive interference amplifies the common-mode volcanic tremor while attenuating incoherent sensor noise. Features extracted from this virtual channel will explicitly model the global event magnitude.
    *   **Feature Selection:** We will enforce **Parsimony** by strictly limiting feature families to those proven effective, avoiding the "Curse of Dimensionality" (Cite solution_lesson_node_00025).

2.  **Branch B: Instance-Normalized Vision Model (EfficientNet)**
    *   **Architecture:** An **EfficientNet-B0** CNN modified to accept 10-channel inputs.
    *   **Role:** Captures complex time-frequency textures (e.g., harmonic gliding) that statistical aggregates miss.

3.  **Meta-Learner:**
    *   A **Ridge Regression** model (Unconstrained) trained on the Out-of-Fold (OOF) predictions. This replaces the failed "Weighted Blender" to allow the ensemble to correct systematic biases via non-convex weighting, effectively utilizing the weaker Vision model (Cite solution_lesson_node_00027).

# Data
The data pipeline implements strict safeguards against stale data and overfitting, utilizing a **Hashed Caching** mechanism (Cite solution_lesson_node_00002).

1.  **Branch A Preprocessing (Tabular):**
    *   **Input:** 10 Physical Sensors + 1 Beamformed Virtual Sensor.
    *   **Global & Absolute Statistics:** Compute Mean, Std, Skew, Kurtosis, and Quantiles (e.g., 99th) over the entire segment (Cite solution_lesson_node_00004). Crucially, include **Absolute Quantiles** (`quantile(abs(x))`) to measure signal energy independent of polarity (Cite solution_lesson_node_00014).
    *   **Parsimonious Cepstral Features (MFCCs):** Extract MFCCs but restrict them to **Coefficients 1-13** (Low-Order) to capture the spectral envelope (timbre) without the high-frequency noise of higher orders (Cite solution_lesson_node_00025). Aggregate these using *only* **Robust Statistics** (Mean, Std, Q05, Q95) and explicitly exclude Min/Max to avoid outlier artifacts (Cite solution_lesson_node_00021).
    *   **Structural Features:** Calculate **Raw Zero-Crossing Rate** (without centering) to utilize the signal offset as an amplitude gate (Cite solution_lesson_node_00007).
    *   **Spatial Features:** Compute the **Correlation Matrix** between all physical sensors (Cite solution_lesson_node_00017).
    *   **Exclusion:** Explicitly **exclude** derivatives/gradients to prevent high-frequency noise overfitting (Cite solution_lesson_node_00020).
    *   **Implementation:** Use explicit function calls rather than dynamic configuration loops (Cite solution_lesson_node_00005).

2.  **Branch B Preprocessing (Vision):**
    *   **Input:** Log-Mel Spectrograms stacked into a `(10, Freq, Time)` tensor.
    *   **Instance Standardization (Innovation):** Apply **Per-Sample Standardization** (`(x - mean) / std`) to each spectrogram image individually. This local contrast normalization is superior to global normalization for this specific dataset (Cite solution_lesson_node_00027).
    *   **Target Scaling:** Apply **Log-Scaling** (`np.log1p`) to the `time_to_eruption` target to prevent convergence failure (Cite solution_lesson_node_00009).

# Training
1.  **Strategy:** 5-Fold Cross-Validation for both branches to generate aligned OOF predictions.
2.  **Tabular Branch:** Train LightGBM with early stopping based on validation MAE.
3.  **Vision Branch:** Train using **AdamW** with **Cosine Annealing**. Crucially, extend the training duration to **30+ epochs** to ensure the CNN converges on the complex spectrogram patterns (Cite solution_lesson_node_00017).
4.  **Meta-Learner:** Train Ridge Regression on the OOF predictions against the ground truth.

# Evaluation
1.  **Inference:**
    *   Generate Tabular Features (Physical + Beamformed) and Instance-Normalized Spectrograms for test data.
    *   Predict with LightGBM (Branch A).
    *   Predict with EfficientNet (Branch B) and apply **Inverse Target Transformation** (`np.expm1`).
2.  **Submission:** Input both prediction vectors into the trained Ridge Meta-Learner to produce the final `time_to_eruption` estimate.
