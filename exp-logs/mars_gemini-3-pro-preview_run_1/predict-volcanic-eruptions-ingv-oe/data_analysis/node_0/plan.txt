The strategy involves a hybrid analysis approach tailored to the multi-channel sensor data provided in CSV format. Since the data consists of time-series readings from sensors, we will treat the raw signal data as "Tabular" for the purpose of statistical distribution analysis (mean, std, outliers, missing values) and as "Signal" for feature extraction.

1.  **Setup & Metadata**: Load the training metadata from `./metadata/train.csv` to identify training segments and targets.
2.  **Target Analysis**: Analyze the `time_to_eruption` column for distribution, skewness, and kurtosis to understand the regression target.
3.  **Data Sampling**: To perform efficient EDA within the time limit, we will sample a subset of the training files (e.g., 200 segments).
    *   **Detailed Sample**: Load full sensor data for a smaller subset (e.g., 50 files) to perform granular "Input Data Analysis" (global mean, std, missing values, outlier detection using IQR).
    *   **Feature Sample**: For the larger subset (200 files), compute aggregated features (mean, std, min, max, quantiles) per sensor to create a structured dataset for relationship analysis.
4.  **Input Data Analysis**: Report global statistics for the sensors, including missing value percentages and outlier counts based on the detailed sample.
5.  **Feature/Signal Relationships**:
    *   **Correlation**: Calculate Pearson correlations between the extracted sensor features and the target.
    *   **Importance**: Train a lightweight Random Forest Regressor on the extracted features to identify the most predictive sensors/statistics.
    *   **Redundancy**: Identify highly collinear feature pairs.
6.  **Formatting**: Output the results in the specified capitalized sections with formatted floats.
