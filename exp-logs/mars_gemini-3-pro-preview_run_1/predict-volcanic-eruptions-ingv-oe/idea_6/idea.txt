Based on the extensive failure analysis and success signals from the previous experiments, I propose a **Latent-Source Cepstral Stacking** strategy. This approach structurally evolves the solution by introducing a "Latent Source" feature extraction paradigm (via PCA) to explicitly model the coherent seismic signal amidst sensor noise, while rigorously refining the "Audio-Seismic" features and ensemble architecture based on the established lessons.

# Model
The solution utilizes a **Heterogeneous Stacking Ensemble** that integrates a high-capacity Tabular Learner with a Spectral Vision model to capture orthogonal signal patterns (Cite Lesson ID: solution_lesson_node_00015).

1.  **Branch A: Latent-Source Tabular Regressor (LightGBM)**
    *   **Architecture:** A Gradient Boosting Machine (LightGBM) optimized for a dense, high-dimensional feature space.
    *   **Structural Innovation (Latent Source Modeling):** Instead of treating the 10 sensors purely as independent channels, we will apply **Principal Component Analysis (PCA)** to the raw sensor array (shape `60001 x 10`) for each segment. We will extract the **First Principal Component (PC1)**, which represents the "Common Mode" signal—the coherent volcanic tremor—while filtering out uncorrelated noise. Features will be extracted from this "Virtual Source Sensor" in addition to the physical sensors.

2.  **Branch B: Spectral Vision Model (EfficientNet)**
    *   **Architecture:** An **EfficientNet-B0** CNN modified to accept 10-channel inputs.
    *   **Role:** Captures complex time-frequency textures (e.g., gliding tremors) that global statistics miss. Although "weaker" in standalone metrics, it provides crucial diversity to the ensemble (Cite Lesson ID: solution_lesson_node_00015).

3.  **Meta-Learner:**
    *   A **Ridge Regression** model trained on the Out-of-Fold (OOF) predictions from both branches to optimally weigh their contributions (Cite Lesson ID: solution_lesson_node_00012).

# Data
The data pipeline implements strict safeguards against stale data and overfitting, utilizing a **Hashed Caching** mechanism (Cite Lesson ID: solution_lesson_node_00002).

1.  **Branch A Preprocessing (Tabular):**
    *   **Paradigm:** Treat the seismic data as a 10-channel audio signal.
    *   **Latent Source Features:** Compute all statistical features on the **PC1 array** (the "Virtual Source") to capture the global event magnitude and structure.
    *   **Cepstral Features (MFCCs):** Extract Mel-frequency cepstral coefficients (MFCCs) to capture the "timbre" of the tremors (Cite Lesson ID: solution_lesson_node_00019). **Crucially**, aggregate these using only **Robust Statistics** (Mean, Std, Q05, Q95) and explicitly **exclude** Min/Max to avoid noise artifacts (Cite Lesson ID: solution_lesson_node_00021).
    *   **Energy-Domain Features:** Compute **Absolute Quantiles** (e.g., `quantile(abs(x))`) to properly measure the intensity of the zero-mean oscillatory signals (Cite Lesson ID: solution_lesson_node_00014).
    *   **Structural Features:** Calculate **Raw Zero-Crossing Rate** (without centering) to utilize the signal offset as an amplitude gate (Cite Lesson ID: solution_lesson_node_00007).
    *   **Spatial Features:** Compute the **Correlation Matrix** between all sensor pairs to quantify spatial coherence (Cite Lesson ID: solution_lesson_node_00017).
    *   **Exclusion:** Explicitly avoid high-order derivatives (gradients) to prevent high-frequency noise overfitting (Cite Lesson ID: solution_lesson_node_00020).

2.  **Branch B Preprocessing (Vision):**
    *   **Input:** Log-Mel Spectrograms stacked into a `(10, Freq, Time)` tensor.
    *   **Target Scaling:** Apply **Log-Scaling** (`np.log1p`) to the `time_to_eruption` target. This is mandatory to prevent convergence failure in the Neural Network (Cite Lesson ID: solution_lesson_node_00009).

# Training
1.  **Strategy:** 5-Fold Cross-Validation for both branches to generate aligned OOF predictions.
2.  **Tabular Branch:** Train LightGBM with **Recursive Feature Elimination (RFE)** or built-in feature importance pruning within the folds to manage the expanded dimensionality (~1000 features) and prevent overfitting.
3.  **Vision Branch:** Train using **AdamW** with **Cosine Annealing**. Crucially, extend the training duration (e.g., 20+ epochs) to ensure the CNN converges on the complex spectrogram patterns (Cite Lesson ID: solution_lesson_node_00017).
4.  **Meta-Learner:** Train Ridge Regression on the OOF predictions against the ground truth.

# Evaluation
1.  **Inference:**
    *   Generate Tabular Features (including PCA and Robust MFCCs) and Spectrograms for test data.
    *   Predict with LightGBM (Branch A).
    *   Predict with EfficientNet (Branch B) and apply **Inverse Target Transformation** (`np.expm1`) to restore the scale.
2.  **Submission:** Input both prediction vectors into the trained Ridge Meta-Learner to produce the final `time_to_eruption` estimate.
