The strategy implements a **Latent-Source Cepstral Stacking** pipeline. It orchestrates feature engineering (extracting PCA-based latent source features and robust MFCCs), trains a heterogeneous ensemble (LightGBM on tabular data, EfficientNet on spectrograms), and combines them using a Ridge Meta-Learner. The script includes strict validation checks, failure analysis via error-feature correlation, and conditional submission generation based on a performance threshold.
