Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose the **Magnitude-Modulated Hybrid Ensemble**. This strategy structurally evolves the solution by implementing a **Feature-wise Linear Modulation (FiLM)** mechanism within the Vision branch. This specifically addresses the "Feature Scale Mismatch" (Lesson 00044) and "Magnitude Insensitivity" (Lesson 00037) failures of previous attempts, while strictly adhering to the "Single-Resolution" constraint (Lesson 00045) to avoid dimensionality issues.

# Model
The solution utilizes a **Heterogeneous Stacking Ensemble** designed to synergize expert statistical modeling with a magnitude-aware deep learning architecture.

1.  **Branch A: Energy-Partitioned Tabular Regressor (LightGBM)**
    *   **Architecture:** A Gradient Boosting Machine (LightGBM) optimized for a feature space that explicitly separates signal magnitude from spectral shape.
    *   **Feature Policy (Multi-View Robustness):**
        *   **Time/Energy Domain:** Retain **Full Statistics** (Min, Max, Skew, Kurtosis) and **Absolute Quantiles** (`quantile(abs(x))`). This preserves the absolute magnitude of extreme seismic events, which are critical predictors (Cite solution_lesson_node_00032, solution_lesson_node_00014).
        *   **Spectral Domain:** Use **Robust Statistics Only** (Mean, Std, Q05, Q95) for MFCCs and FFTs to filter out transient noise artifacts (Cite solution_lesson_node_00021).
    *   **Structural Innovation (Sub-band Energy):** Explicitly engineer **Log-Subband Energies** (log-sum-squared magnitude in distinct frequency bands) and **Crest Factor** to provide the model with granular, intensity-aware spectral descriptors, correcting the magnitude-blindness of normalized spectral features (Cite solution_lesson_node_00037).

2.  **Branch B: Magnitude-Modulated Vision Model (EfficientNet + FiLM)**
    *   **Architecture:** An **EfficientNet-B0** CNN modified to accept a **Single-Resolution** 10-channel spectrogram input (Cite solution_lesson_node_00045).
    *   **Structural Innovation (FiLM Modulation):** To guarantee the network utilizes absolute signal intensity without the stability issues of Idea 13/14, we implement a **Feature-wise Linear Modulation (FiLM)** block.
        *   **Mechanism:** A vector of global energy scalars (Log-Energy, Max, Crest Factor) is passed through a **Batch Normalization** layer (Cite solution_lesson_node_00044) and then a small MLP to generate scale ($\gamma$) and shift ($\beta$) parameters.
        *   **Modulation:** These parameters affine-transform the CNN's final embedding vector ($E_{mod} = \gamma \cdot E_{cnn} + \beta$) before the regression head. This allows the absolute magnitude to dynamically "gate" or scale the texture features learned by the CNN, restoring energy information lost during internal processing.

3.  **Meta-Learner:**
    *   A **Ridge Regression** model (Unconstrained) trained on Out-of-Fold (OOF) predictions. This allows the ensemble to optimally weigh the orthogonal contributions of the Tabular and Vision branches (Cite solution_lesson_node_00027).

# Data
The data pipeline implements strict safeguards against stale data using **Configuration Hashing** (Cite solution_lesson_node_00002).

1.  **Branch A Preprocessing (Tabular):**
    *   **Features:** Sub-band Energies, Crest Factor, Robust MFCCs (Coefficients 1-13 only, Cite solution_lesson_node_00025), Absolute Quantiles, Raw Zero-Crossing Rate (Cite solution_lesson_node_00007), and Spatial Correlation (Cite solution_lesson_node_00017).
    *   **Exclusion:** Explicitly exclude raw gradients to prevent noise overfitting (Cite solution_lesson_node_00020) and avoid beamforming aggregation (Cite solution_lesson_node_00029).

2.  **Branch B Preprocessing (Vision):**
    *   **Spectrograms:** Generate **Single-Resolution** Log-Mel Spectrograms ($N_{FFT}=1024$).
    *   **Normalization:** Apply **Global Log-Max Scaling**: $X_{norm} = \frac{\log(X + 1)}{\log(M_{global} + 1)}$, where $M_{global}$ is a fixed constant derived from the training set. This bounds the input while preserving relative energy differences between segments (Cite solution_lesson_node_00032).
    *   **Scalar Vector:** Extract global energy statistics per segment for the FiLM generator.
    *   **Target Scaling:** Apply **Log-Scaling** (`np.log1p`) to the `time_to_eruption` target (Cite solution_lesson_node_00009).

# Training
1.  **Strategy:** 5-Fold Cross-Validation for both branches to generate aligned OOF predictions.
2.  **Tabular Branch:** Train LightGBM with early stopping based on validation MAE.
3.  **Vision Branch:** Train using **AdamW** with **Cosine Annealing**. Extend training to **30+ epochs** to ensure convergence on the complex texture patterns (Cite solution_lesson_node_00017).
4.  **Meta-Learner:** Train Ridge Regression on the OOF predictions against the ground truth.

# Evaluation
1.  **Inference:**
    *   Generate Energy-Partitioned Tabular Features and Global-Scaled Spectrograms + Normalized Scalars for the test set.
    *   Predict with LightGBM (Branch A).
    *   Predict with Magnitude-Modulated EfficientNet (Branch B) and apply **Inverse Target Transformation** (`np.expm1`).
2.  **Submission:** Input both prediction vectors into the trained Ridge Meta-Learner to produce the final `time_to_eruption` estimate.
