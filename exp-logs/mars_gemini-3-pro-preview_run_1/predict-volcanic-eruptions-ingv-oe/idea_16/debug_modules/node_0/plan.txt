Implementation Strategy:
1.  **Setup Environment**: Import necessary libraries and the provided modules. Set random seeds for reproducibility.
2.  **Create Mini-Datasets**: To satisfy the speed constraint, read the original metadata files (`train.csv`, `val.csv`, `test.csv`), sample a small number of rows (e.g., 20 training samples, 10 validation samples), and save them as "mini" metadata files in the `./working` directory.
3.  **Patch Configuration**: Dynamically modify the `Config` class attributes to:
    *   Point to the new mini-metadata files.
    *   Redirect output directories (`WORKING_DIR`, `SUBMISSION_DIR`) to a demo folder to avoid conflicts.
    *   Reduce computational parameters: `N_FOLDS=2`, `EPOCHS=1`, `LGBM_PARAMS['n_estimators']=10`.
    *   Update derived paths (e.g., feature cache paths, spectrogram directory) to align with the new working directory.
4.  **Execute Tabular Branch**: Instantiate `TabularTrainer` and run the cross-validation loop (`run_cv`). Verify that OOF predictions and test predictions are generated.
5.  **Execute Vision Branch**: Instantiate `VisionTrainer` and run `run_cv`. This will trigger the `SpectrogramProcessor` to generate spectrograms for the mini-dataset and then train the `VolcanoEfficientNet` for 1 epoch. Verify outputs.
6.  **Execute Meta-Learner**: Instantiate `StackingEnsemble`, train the meta-model using the OOF predictions from both branches, and generate the final submission.
7.  **Validation**: Throughout the process, use `assert` statements to verify that files are created, shapes are correct, and the pipeline completes successfully.
