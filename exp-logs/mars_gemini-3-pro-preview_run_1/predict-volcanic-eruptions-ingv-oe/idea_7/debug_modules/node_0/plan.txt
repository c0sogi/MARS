### Implementation Strategy

1.  **Configuration Overrides**: To ensure the script runs quickly (within the time limit) and demonstrates functionality without full training, we will monkey-patch the configuration constants in the imported library modules. We will reduce `CNN_EPOCHS` to 1, `LGB_ROUNDS` to 10, and `NUM_FOLDS` to 2.
2.  **Data Subsetting**: We will load the provided metadata files and create small subsets (e.g., 50 samples for training/validation) to speed up feature extraction and model training demonstrations.
3.  **Feature Extraction**: We will demonstrate the usage of `TabularFeatureExtractor` to generate statistical features from the sensor data and `VisionTransformer` to generate spectrograms. We will verify the output shapes using assertions.
4.  **Data Loading**: We will instantiate the `VolcanoDataset` and `DataLoader` to verify that the vision data is correctly formatted for PyTorch models (checking tensor shapes).
5.  **Model Architecture**: We will instantiate the `VolcanoEfficientNet` and perform a forward pass with a dummy batch to confirm the architecture handles the 10-channel input correctly.
6.  **Training Pipeline**: We will execute the `run_cross_validation` function using the subsetted data. This covers the LightGBM training, CNN training (for 1 epoch), and the Meta-Learner training.
7.  **Validation**: Throughout the script, assertions will be used to validate data integrity, shape consistency, and model output formats.
