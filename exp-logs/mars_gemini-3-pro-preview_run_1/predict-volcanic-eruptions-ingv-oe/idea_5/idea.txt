Based on the lessons learned from the previous experiments, I propose a **Hybrid Spectrogram-Tabular Stacking Strategy**. This approach structurally evolves the solution by replacing the failed 1D-Deep Learning branch with a 2D-Vision approach (Spectrograms), strictly implementing target scaling to fix convergence issues, and upgrading the ensemble mechanism to handle performance disparities.

# Model
The solution employs a **Heterogeneous Stacking Ensemble** consisting of two distinct modeling branches and a meta-learner:

1.  **Branch A: Expert Feature Regressor (LightGBM)**
    *   **Purpose:** Exploits the proven efficiency of Gradient Boosting on structured statistical data (Cite Lesson ID: solution_lesson_node_00001).
    *   **Features:** A dense vector comprising:
        *   **Global Distributional Statistics:** Mean, Std, Skew, Kurtosis, and Quantiles (e.g., 99th percentile) computed over the entire segment to preserve sparse event magnitudes (Cite Lesson ID: solution_lesson_node_00004).
        *   **Spectral Features:** FFT statistics (Mean, Std, Dominant Frequency) to capture harmonic tremors (Cite Lesson ID: solution_lesson_node_00006).
        *   **Structural Features:** Total Variation and **Raw Zero-Crossing Rate** (calculated on raw data to utilize amplitude gating) (Cite Lesson ID: solution_lesson_node_00007).
        *   **Wavelet Features:** Energy and Entropy of Discrete Wavelet Transform (DWT) coefficients to capture non-stationary time-frequency characteristics.

2.  **Branch B: Time-Frequency Vision Model (2D-CNN)**
    *   **Structural Innovation:** Replaces the 1D-ResNet (which failed to learn from raw waveforms) with an **EfficientNet-B0** (or similar 2D-CNN) modified to accept 10 input channels.
    *   **Input:** **Log-Mel Spectrograms** of the sensor data. This transforms the temporal signal into an image representation, allowing the model to leverage powerful vision biases to detect evolving frequency patterns (e.g., pre-eruptive rumbles) that global statistics might obscure.

3.  **Meta-Learner:**
    *   A **Ridge Regression** model trained on the Out-of-Fold (OOF) predictions from Branch A and Branch B. This replaces simple averaging to optimally weigh the contributions of each model, mitigating the risk of one branch degrading the ensemble (Cite Lesson ID: solution_lesson_node_00012).

# Data
The data pipeline is designed to be robust against stale data and convergence failures:

1.  **Robust Caching:**
    *   Implement **Configuration Hashing** for both the tabular feature extraction and spectrogram generation. The cache filenames will include a hash of the configuration parameters to ensure that any logic change forces a re-computation (Cite Lesson ID: solution_lesson_node_00002).

2.  **Branch A Preprocessing (Tabular):**
    *   **Explicit Extraction:** Feature calculation will use explicit, hardcoded function calls rather than dynamic configuration loops to prevent silent failures (Cite Lesson ID: solution_lesson_node_00005).
    *   **Imputation:** Missing sensor values are filled with the segment mean.

3.  **Branch B Preprocessing (Spectrograms):**
    *   **Transformation:** Convert the 10 normalized sensor arrays into Log-Mel Spectrograms and stack them into a `(10, Freq_Bins, Time_Steps)` tensor.
    *   **Target Scaling (Crucial):** Apply **Log-Scaling** (`np.log1p`) to the `time_to_eruption` target variable for this branch. This reduces the target magnitude from $\sim10^7$ to a small range, preventing the gradient explosion and convergence failure observed in the previous neural network attempt (Cite Lesson ID: solution_lesson_node_00009).

# Training
Both branches will be trained using a **5-Fold Cross-Validation** scheme to generate consistent OOF predictions for stacking.

1.  **Branch A (LightGBM):**
    *   Objective: Mean Absolute Error (MAE).
    *   Strategy: Early stopping based on validation MAE.

2.  **Branch B (2D-CNN):**
    *   Objective: MAE calculated on the **scaled target**.
    *   Optimizer: **AdamW** with **Cosine Annealing** learning rate scheduler for stable convergence.
    *   Regularization: Weight decay and mild SpecAugment (time/frequency masking) to prevent overfitting.

3.  **Stacking:**
    *   The Ridge Regressor is trained on the OOF predictions (after inverse-transforming Branch B's outputs) against the ground truth `time_to_eruption`.

# Evaluation
1.  **Inference:** Process test data to generate the Expert Feature Matrix and Spectrogram Tensor (using hashed caches).
2.  **Prediction:**
    *   **Branch A:** Predict directly.
    *   **Branch B:** Predict and apply **Inverse Transformation** (`np.expm1`) to return to the original time scale.
3.  **Submission:** Feed the predictions from both branches into the trained Meta-Learner to produce the final estimate.
