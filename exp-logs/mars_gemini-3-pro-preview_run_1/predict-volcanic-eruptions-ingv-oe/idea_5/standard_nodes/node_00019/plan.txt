To improve the solution, I will focus on enhancing the **Tabular Branch (LightGBM)**, which has proven to be significantly more effective than the Vision branch. Based on **Lesson 17**, explicit feature engineering outperforms deep learning on raw representations in low-data regimes. I will incorporate **Mel-Frequency Cepstral Coefficients (MFCCs)** into the tabular feature set. MFCCs capture the spectral envelope ("timbre") of the seismic signals, effectively encoding the frequency information that the Vision model attempts to learn, but in a format that Gradient Boosting Trees can leverage more efficiently.

Additionally, I will optimize the LightGBM hyperparameters by slightly reducing the learning rate and increasing the number of estimators to allow the model to better utilize the expanded feature space.
