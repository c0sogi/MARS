The following is a comprehensive implementation strategy and the corresponding Python script to demonstrate the volcano eruption prediction pipeline.

### Implementation Strategy

1.  **Configuration Override**: To ensure the script executes quickly (within the 1-hour limit) and serves as a proper demonstration, we will monkey-patch the `Config` class. We will enable `DEBUG` mode (reducing data to 20 samples per split), reduce the number of Cross-Validation folds to 2, and drastically reduce model hyperparameters (e.g., `n_estimators=20` for LightGBM, `epochs=1` for the CNN).
2.  **Data Loading Verification**: We will instantiate the `DataManager` and request training data in debug mode. We will assert that the returned data structures (Pandas DataFrame for tabular, NumPy array for spectrograms) have the expected shapes and types.
3.  **Model Architecture Check**: We will manually instantiate the `VolcanoEfficientNet` and pass a dummy tensor with the correct dimensions (derived from the loaded data) to verify the forward pass and output shape `(Batch, 1)`.
4.  **Dataset Logic Check**: We will verify the `VolcanoSpectrogramDataset` by retrieving a single sample and confirming the tensor shapes and the application of log-scaling to the target variable.
5.  **Full Pipeline Execution**: We will sequentially run the provided training functions:
    *   `run_tabular_training`: Generates Out-of-Fold (OOF) and Test predictions using LightGBM.
    *   `run_vision_training`: Generates OOF and Test predictions using the 2D-CNN.
    *   `train_meta_learner`: Blends the predictions using Ridge Regression and generates the final submission.
6.  **Final Validation**: We will check for the existence of the submission file, verify its CSV structure, and ensure predictions are non-negative.
