This script demonstrates the end-to-end pipeline for the Volcanic Eruption Prediction task using the provided library files. It overrides the global configuration to run a fast, minimal version of the training and inference processes (using small data subsets and reduced epochs). It validates the logic of the Tabular Branch (Feature Engineering + LightGBM), the Vision Branch (Spectrogram Generation + EfficientNet), and the Meta-Learner Stacking.
