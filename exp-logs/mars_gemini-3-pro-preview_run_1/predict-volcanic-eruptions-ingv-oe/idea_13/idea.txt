Based on the analysis of the previous experiments and the distilled lessons, I propose the **Magnitude-Injected Hybrid Ensemble**. This strategy structurally evolves the solution by implementing the **Sub-band Energy** features recommended in Lesson 00037 (which were proposed but replaced by ineffective Shape Features in the previous iteration) and by introducing a **Scalar-Conditioned CNN Architecture** to guarantee that the Vision model utilizes absolute signal intensity.

# Model
The solution utilizes a **Heterogeneous Stacking Ensemble** designed to explicitly capture the absolute energy evolution of the seismic signals, addressing the "Magnitude-Dependent Residuals" identified in Lesson 00037.

1.  **Branch A: Energy-Partitioned Tabular Regressor (LightGBM)**
    *   **Architecture:** A Gradient Boosting Machine (LightGBM) optimized for a feature space that prioritizes absolute magnitude over spectral shape.
    *   **Structural Innovation (Log-Subband Energies):** To address the failure of normalized spectral features (Centroid, Bandwidth) which discard intensity information (Cite solution_lesson_node_00037), we will explicitly engineer **Log-Subband Energies**. We divide the frequency spectrum into distinct bands (e.g., 0-2Hz, 2-5Hz, 5-10Hz) and calculate the log-sum-squared magnitude for each. This provides the model with granular, magnitude-aware spectral descriptors.
    *   **Feature Policy:** We retain the **Multi-View Robustness Policy**:
        *   **Time/Energy Domain:** Retain full statistics (Min, Max, Kurtosis) and **Absolute Quantiles** to preserve extreme event magnitudes (Cite solution_lesson_node_00032, solution_lesson_node_00014).
        *   **Spectral Domain:** Use **Robust Statistics Only** (Mean, Std, Q05, Q95) for MFCCs and FFTs to avoid transient noise artifacts (Cite solution_lesson_node_00021).

2.  **Branch B: Magnitude-Injected Vision Model (EfficientNet)**
    *   **Architecture:** An **EfficientNet-B0** CNN modified to accept a **Multi-Modal Input**.
    *   **Structural Innovation (Scalar Conditioning):** Standard CNNs with Batch Normalization can become invariant to global input scaling, losing critical intensity information even if the input is globally scaled. We will modify the architecture to accept a secondary input vector of **Global Energy Scalars** (Log-Total-Energy, Global Max, Crest Factor). This vector will be concatenated with the image embedding (after the convolutional backbone) before the final dense regression layers. This "Short-Circuit" ensures the network has direct access to the absolute signal magnitude (Cite solution_lesson_node_00032).
    *   **Input:** **Global Log-Max Scaled** Log-Mel Spectrograms (Cite solution_lesson_node_00032).

3.  **Meta-Learner:**
    *   A **Ridge Regression** model (Unconstrained) trained on Out-of-Fold (OOF) predictions to optimally weigh the contributions of both branches (Cite solution_lesson_node_00027).

# Data
The data pipeline implements strict safeguards against stale data (Cite solution_lesson_node_00002) and enforces specific feature engineering constraints.

1.  **Branch A Preprocessing (Tabular):**
    *   **Sub-band Energy:** Calculate `log(sum(fft_magnitude[band]**2))` for ~10 linearly spaced frequency bands.
    *   **Impulsiveness:** Calculate **Crest Factor** (`max(abs(x)) / rms(x)`) to quantify signal shock (Cite solution_lesson_node_00037).
    *   **Robust MFCCs:** Extract MFCCs restricted to **Coefficients 1-13** (Low-Order) to capture timbre, aggregated using only robust statistics (Cite solution_lesson_node_00025).
    *   **Spatial:** Correlation Matrix between all sensors (Cite solution_lesson_node_00017).
    *   **Exclusion:** Explicitly exclude normalized spectral shape features (Centroid, Rolloff) and raw gradients (Cite solution_lesson_node_00037, solution_lesson_node_00020).

2.  **Branch B Preprocessing (Vision):**
    *   **Spectrograms:** Generate Log-Mel Spectrograms for all 10 sensors. Normalize via $X_{norm} = \frac{\log(X + 1)}{\log(M_{global} + 1)}$, where $M_{global}$ is the maximum value observed in the training set (Cite solution_lesson_node_00032).
    *   **Scalars:** Extract a vector of global energy statistics per segment for the injection layer.
    *   **Target Scaling:** Apply **Log-Scaling** (`np.log1p`) to the `time_to_eruption` target (Cite solution_lesson_node_00009).

# Training
1.  **Strategy:** 5-Fold Cross-Validation for both branches to generate aligned OOF predictions.
2.  **Tabular Branch:** Train LightGBM with early stopping based on validation MAE.
3.  **Vision Branch:** Train using **AdamW** with **Cosine Annealing**. Extend training to **30+ epochs** to ensure convergence (Cite solution_lesson_node_00017).
4.  **Meta-Learner:** Train Ridge Regression on the OOF predictions against the ground truth.

# Evaluation
1.  **Inference:**
    *   Generate the Energy-Partitioned Feature Matrix and the Global-Scaled Spectrograms + Scalar Vectors for the test set.
    *   Predict with LightGBM (Branch A).
    *   Predict with Magnitude-Injected EfficientNet (Branch B) and apply **Inverse Target Transformation** (`np.expm1`).
2.  **Submission:** Input both prediction vectors into the trained Ridge Meta-Learner to produce the final `time_to_eruption` estimate.
