The following script demonstrates the complete pipeline for the Volcano Eruption Prediction task using the provided library files.

### Strategy Outline
1.  **Environment Setup**: We create a temporary directory `./working/demo_run` to store all outputs. We generate "mini" metadata files (subsetting the original metadata to ~10 rows) to ensure the entire pipeline runs in seconds rather than hours.
2.  **Configuration Override**: We modify the `Config` class at runtime. We point it to our mini metadata and temporary directories, and drastically reduce training hyperparameters (1 epoch, 2 folds, small batch size) to optimize for speed.
3.  **Component Verification**:
    *   **Feature Engineering**: We run `generate_features` and assert that tabular features and spectrograms are correctly generated for the subset.
    *   **Vision Branch**: We instantiate the `VolcanoDataset` and `DataLoader`, fetch a batch, and verify the shapes of the spectrograms and scalar inputs. We then run a forward and backward pass on the `ScalarConditionedEfficientNet` to confirm gradient flow.
    *   **Tabular Branch**: We train the `LightGBMTrainer` on the subset and verify it produces predictions of the correct shape.
4.  **Integration Test**: We execute `run_training()`, which orchestrates the full K-Fold Cross-Validation, ensemble logic, and submission generation. We verify the final submission file is created.
