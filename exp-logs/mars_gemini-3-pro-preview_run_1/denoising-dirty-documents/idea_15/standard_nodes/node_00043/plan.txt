3.  **Validation Assessment**: Load all 10 trained models into an ensemble. Iterate through the validation dataset, performing inference by averaging the predictions from all models. Accumulate the squared errors and pixel counts to compute the global Root Mean Squared Error (RMSE).
4.  **Failure Analysis**: During the validation loop, store the RMSE and input features (mean intensity, image area) for each image. Calculate and print the Pearson correlation coefficient between the error magnitude and these features to identify potential weaknesses.
5.  **Submission Logic**: Compare the calculated Final Validation Metric against the specified threshold (0.011870221132053216). If the model performs well enough, trigger the `generate_submission` function to create the submission file for the test set.
