Based on the comprehensive analysis of the provided lessons and the specific constraints of the text denoising task, I propose the following optimized strategy. This solution resolves the critical conflict identified between **Lesson 27** (Need for Small Patches to ensure Diversity) and **Lesson 34** (Need for Large Patches to ensure Context) by implementing a **Heterogeneous Multi-Scale Ensemble**.

# Model
**Architecture: Heterogeneous Dual-Stream Ensemble**
Instead of searching for a single "compromise" architecture, we will deploy an ensemble of two distinct model variants, each optimized for a specific aspect of the denoising task.

1.  **Stream A: Context Specialists (4-Level U-Net)**
    *   **Backbone:** A standard **4-Level U-Net** (Encoder: 32 $\to$ 64 $\to$ 128 $\to$ 256 $\to$ 512).
    *   **Rationale:** This deeper architecture provides the large receptive field necessary to model global text structure and line continuity. It is specifically designed to work with large input patches where the bottleneck resolution ($20 \times 20$) remains sufficient (Cite {solution_lesson_node_00026}).
    *   **Upsampling:** Bilinear Upsampling followed by Convolution (Cite {solution_lesson_node_00009}).

2.  **Stream B: Texture Specialists (3-Level Shallow U-Net)**
    *   **Backbone:** A lightweight **3-Level U-Net** (Encoder: 32 $\to$ 64 $\to$ 128 $\to$ 256).
    *   **Rationale:** This shallower architecture acts as a structural regularizer and is optimized for smaller input patches. As proven in previous experiments, it outperforms deeper models when restricted to limited spatial contexts by preventing overfitting (Cite {solution_lesson_node_00018}).
    *   **Upsampling:** Bilinear Upsampling followed by Convolution.

# Data
**Preprocessing & Augmentation: Multi-Scale Strategy**
We will implement a differentiated data pipeline for each stream to maximize the strengths of the respective architectures.

1.  **Stream A Data (Context):**
    *   **Patch Size:** **$320 \times 320$ pixels**.
    *   **Rationale:** Maximizes the physical input window to provide the dense context required for the 4-Level network to distinguish signal from noise (Cite {solution_lesson_node_00034}). While this reduces crop diversity (Cite {solution_lesson_node_00027}), it is necessary for the deep network to function correctly (Cite {solution_lesson_node_00026}).

2.  **Stream B Data (Diversity):**
    *   **Patch Size:** **$160 \times 160$ pixels**.
    *   **Rationale:** Ensures massive **combinatorial crop diversity**. Since the patch area is small relative to the image size ($<20\%$), the number of unique random crops is exponentially higher. This forces the model to learn robust, translation-invariant local texture statistics, addressing the overfitting concerns of larger patches (Cite {solution_lesson_node_00027}).

3.  **Common Augmentation:**
    *   **Geometric:** Random horizontal flips, vertical flips, and 90-degree rotations (Cite {solution_lesson_node_00003}).
    *   **Deterministic Loading:** Use a `worker_init_fn` to seed data loaders for full reproducibility (Cite {solution_lesson_node_00015}).
    *   **No Resizing:** All crops are extracted at native resolution (Cite {solution_lesson_node_00001}).

# Training
**Procedure: Converged Independent Training**
We will train a total of **6 independent models** (3 instances of Stream A, 3 instances of Stream B) to create a robust ensemble.

*   **Optimization Velocity:** **Adam** optimizer with a **high learning rate (1e-3)** and **small batch size (16)**. This maximizes gradient update frequency, critical for small datasets (Cite {solution_lesson_node_00010}).
*   **Full Convergence:** Each model will be trained for **1000 epochs**. We explicitly prioritize training fewer models to full convergence over many undertrained models (Cite {solution_lesson_node_00012}, Cite {solution_lesson_node_00016}).
*   **Scheduler:** **Cosine Annealing** with `T_max=1000` (decoupled from early stopping). This ensures the learning rate decays fully to zero, allowing the models to settle into sharp minima (Cite {solution_lesson_node_00007}).
*   **Loss Function:** Standard **Mean Squared Error (MSE)** on the direct signal prediction. We avoid Deep Supervision (Cite {solution_lesson_node_00017}) and Residual Prediction (Cite {solution_lesson_node_00023}) as they were proven detrimental for this specific task.

# Evaluation
**Inference Pipeline**
*   **D4 Group Test-Time Augmentation (TTA):** For every test image, we will generate predictions for **8 geometric views** (Original, Rot90, Rot180, Rot270, and their horizontal flips). These will be inversely transformed and averaged. This significantly reduces variance (Cite {solution_lesson_node_00028}).
*   **Heterogeneous Aggregation:** The TTA-averaged outputs from all 6 fully converged models (3 Context + 3 Texture) will be averaged together.
    *   **Benefit:** This ensemble combines the **global coherence** of the Context models with the **fine-grained texture fidelity** of the Texture models, effectively cancelling out the specific errors (overfitting vs. lack of context) inherent to each individual approach.
