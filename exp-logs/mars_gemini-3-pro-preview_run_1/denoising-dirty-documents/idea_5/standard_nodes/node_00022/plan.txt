The implementation strategy is as follows:

1.  **Setup & Imports**: Import necessary modules and the provided library functions (`library.config`, `library.train`, `library.inference`, etc.). Set the global random seed for reproducibility.
2.  **Fast Baseline Training**: Execute the K-Fold training pipeline using `library.train.run_training`. To satisfy the "fast baseline" and time limit requirements, the number of epochs is reduced to 50 (from the default 1000). This ensures the script completes quickly while still training the ensemble of 5 models.
3.  **Validation & Metrics**:
    *   Load the hold-out validation dataset (`metadata/val.csv`) using `library.dataset._load_and_cache_data`.
    *   Initialize the ensemble of trained models.
    *   Perform inference on the validation set using Test-Time Augmentation (TTA) via `library.inference.predict_tta`.
    *   Compute the global Root Mean Squared Error (RMSE) between the reconstructed clean images and the ground truth.
    *   Print the `Final Validation Metric` in the required format.
4.  **Failure Analysis**:
    *   Calculate per-image RMSE.
    *   Compute image statistics (mean intensity, standard deviation) for each validation image.
    *   Calculate and print the Pearson correlation between the prediction error (RMSE) and these image features to identify error patterns.
5.  **Submission**:
    *   Compare the calculated `Final Validation Metric` against the threshold (`0.012221260240721992`).
    *   If the metric is lower (better), call `library.inference.generate_submission` to produce the `submission.csv` file for the test set.
