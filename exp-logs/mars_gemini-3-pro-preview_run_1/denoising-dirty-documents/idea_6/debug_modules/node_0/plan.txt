This script demonstrates the end-to-end workflow using the provided library. It performs the following steps:
1.  **Data Loading & Verification**: Loads the dataset using `get_data` and verifies data integrity (shapes, types, value ranges).
2.  **Model & Component Verification**: Instantiates the `ShallowUNet` model and `DenoisingDataset` to verify forward passes, output shapes, and data transformation logic.
3.  **Training Demonstration**: Runs a single fold of training (`run_fold`) on a small subset of data for a limited number of epochs to verify the training loop and model saving mechanism.
4.  **Inference Demonstration**: Generates a submission file (`generate_submission`) using the trained model on a subset of test data, verifying the output format and TTA (Test-Time Augmentation) logic.
