Implementation strategy:
1.  **Configuration & Setup**: I will define a `main` function that orchestrates the pipeline. To satisfy the "fast baseline" requirement while ensuring convergence on the small dataset, I will override the default 1000 epochs to 200 epochs. This ensures the training completes well within the time limit on the A100 GPU. I will use the provided `Config` class for all other settings, including the 10-seed ensemble.
2.  **Training**: I will iterate through the seeds defined in `Config.SEEDS`. For each seed, I will call `train_one_seed` with the reduced epoch count. This will save the trained models to the working directory.
3.  **Validation & Failure Analysis**:
    *   I will load the validation dataset and all trained models.
    *   I will perform inference on the validation set using the full ensemble and Test-Time Augmentation (TTA), mirroring the robust inference pipeline.
    *   Crucially, I will unpad the predictions to the original image dimensions to calculate the Root Mean Squared Error (RMSE) accurately against the ground truth.
    *   I will compute the correlation between the per-image RMSE and input image statistics (mean and standard deviation) to perform the required failure analysis.
4.  **Submission**: I will compare the final global validation RMSE against the specified threshold (`0.011870221132053216`). If the model performs well enough, I will trigger the `predict_and_submit` function to generate the final submission file.
