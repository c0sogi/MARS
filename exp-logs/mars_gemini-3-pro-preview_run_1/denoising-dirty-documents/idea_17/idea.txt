Based on the comprehensive analysis of the provided lessons, specifically the identified "Context-Diversity-Resolution Trilemma" (Cite {solution_lesson_node_00026}, Cite {solution_lesson_node_00027}, Cite {solution_lesson_node_00034}), I propose the **Dual-Stream Capacity-Resolution Ensemble**.

This strategy synthesizes the robust performance of the **Deep Context U-Net** (Idea 7) with a structurally novel **Resolution-Preserved Diversity U-Net**. It explicitly resolves the failure of previous heterogeneous ensembles (Idea 11, Idea 15) by ensuring that the "Diversity Stream" maintains the high parameter capacity of a deep network (Cite {solution_lesson_node_00024}) while operating on small patches to maximize data diversity (Cite {solution_lesson_node_00027}), all without suffering from resolution collapse (Cite {solution_lesson_node_00026}).

# Model
**Architecture: Heterogeneous Dual-Stream Ensemble**
We will deploy an ensemble of two distinct U-Net architectures. Both streams will utilize **Deep 4-Level Backbones** to ensure sufficient learning capacity (Cite {solution_lesson_node_00024}), but they will be architecturally specialized for their specific input resolutions.

1.  **Stream A: Context Specialist (Standard 4-Level U-Net)**
    *   **Backbone:** A standard **4-Level U-Net** (Encoder: 32 $\to$ 64 $\to$ 128 $\to$ 256 $\to$ 512 filters).
    *   **Downsampling:** Standard strided convolutions (Factor 16 reduction).
    *   **Role:** Captures global text structures and line continuity. Requires large input patches to maintain a viable bottleneck resolution ($20 \times 20$) (Cite {solution_lesson_node_00026}).
    *   **Upsampling:** Bilinear Upsampling followed by Convolution (Cite {solution_lesson_node_00009}).

2.  **Stream B: Diversity Specialist (Resolution-Preserved 4-Level U-Net)**
    *   **Backbone:** A modified **4-Level U-Net** with identical channel depth (Encoder: 32 $\to$ 64 $\to$ 128 $\to$ 256 $\to$ 512).
    *   **Structural Innovation:** In the **4th Encoder Block**, we change the convolution **Stride to 1** and **Dilation to 2**.
        *   **Rationale:** This restricts the total downsampling factor to **8x** (equivalent to a 3-Level network) while preserving the 4-Level depth. This allows the model to accept small input patches ($160 \times 160$) while maintaining a safe **$20 \times 20$ bottleneck resolution** (Cite {solution_lesson_node_00026}).
    *   **Decoder Adjustment:** The corresponding 4th Decoder Block will use convolutions without upsampling to match the encoder's resolution preservation.
    *   **Role:** Exploits massive combinatorial crop diversity (from small patches) to learn robust local texture statistics, without the capacity penalty of a shallow network.

3.  **Common Components:**
    *   **Activation:** The final output layer for both streams will use a **Sigmoid Activation** to structurally enforce the $[0, 1]$ pixel intensity bounds (Cite {solution_lesson_node_00040}).

# Data
**Preprocessing: Dense Signal with Differential Patching**
We will implement a dual-pipeline that serves resolution-matched data to each stream while maintaining the robust "Dense" representation.

1.  **Dense Representation:** We will use the **original image intensities** (Text=0, Background=1). We explicitly reject "Signal Inversion" as it was proven to degrade performance by creating sparse activation maps (Cite {solution_lesson_node_00041}).
2.  **Reflection Padding:** We will strictly use **Reflection Padding** for all boundary handling (augmentations and internal padding) to maintain statistical continuity at the edges (Cite {solution_lesson_node_00039}).
3.  **Differential Patch Extraction:**
    *   **For Stream A (Context):** Extract random crops of **$320 \times 320$ pixels**. This maximizes the physical input window for global structure (Cite {solution_lesson_node_00034}).
    *   **For Stream B (Diversity):** Extract random crops of **$160 \times 160$ pixels**. This maximizes combinatorial crop diversity, effectively multiplying the dataset size to prevent overfitting (Cite {solution_lesson_node_00027}).
4.  **Augmentation:** Random horizontal flips, vertical flips, and 90-degree rotations (Cite {solution_lesson_node_00003}), using a `worker_init_fn` to ensure deterministic reproducibility (Cite {solution_lesson_node_00015}).

# Training
**Strategy: Converged Heterogeneous Bagging**
We will train a robust ensemble of **10 independent models** (5 instances of Stream A, 5 instances of Stream B) using different random seeds.

*   **Full Convergence:** Each model will be trained for **1000 epochs**. We prioritize training to full convergence to minimize bias and resolve high-frequency details (Cite {solution_lesson_node_00016}, Cite {solution_lesson_node_00012}).
*   **Optimization Velocity:** We will use the **Adam** optimizer with a **high learning rate (1e-3)** and **small batch size (16)** to maximize the frequency of gradient updates (Cite {solution_lesson_node_00010}).
*   **Scheduler:** **Cosine Annealing** with `T_max=1000`. This decouples the scheduler from stopping criteria, ensuring the learning rate decays fully to zero (Cite {solution_lesson_node_00007}).
*   **Loss Function:** Mean Squared Error (MSE) on the dense original signal.

# Evaluation
**Inference Pipeline**
*   **Padding:** Test images will be reflection-padded to be multiples of 16 (satisfying constraints of both streams).
*   **D4 Group Test-Time Augmentation (TTA):** For every test image, we will generate predictions for **8 geometric views** (Original, Rot90, Rot180, Rot270, and their horizontal flips). These will be inversely transformed and averaged. This significantly reduces variance compared to single-view inference (Cite {solution_lesson_node_00028}).
*   **Ensemble Aggregation:** The TTA-averaged outputs from all **10 fully converged models** (5 Context + 5 Diversity) will be averaged together. This combines the global coherence of the Context Stream with the robust, diversity-trained texture fidelity of the Resolution-Preserved Diversity Stream.
