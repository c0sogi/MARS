The implementation strategy is as follows:
1.  **Data Discovery**: Scan the `./input/train`, `./input/train_cleaned`, and `./input/test` directories to identify all image files.
2.  **Pairing**: Match noisy images in `train` with their clean counterparts in `train_cleaned` using the file ID (filename without extension). Only pairs that exist in both directories will be included in the training data.
3.  **Splitting**: Create a DataFrame of the paired training data. Split this into training (80%) and validation (20%) sets using `sklearn.model_selection.train_test_split` with `random_state=42`. Since this is an image denoising task (regression) with no explicit categories or grouping identifiers provided in the filenames, a simple random shuffle split is appropriate.
4.  **Metadata Generation**: Create a separate DataFrame for the test set containing only the noisy image paths. Save the train, validation, and test DataFrames as CSV files in the `./metadata` directory. All paths will be relative to `./input`.
5.  **Verification**: Reload the generated CSVs to perform the required checks:
    *   Print summary statistics (counts).
    *   Verify that at least 50% of a random sample of 1000 file paths resolve to existing files (raising an error if not).
    *   Assert that the validation split ratio is approximately 20% and that there is no data leakage (overlap of IDs) between train and validation sets.
