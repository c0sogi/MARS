Implementation strategy:
1.  **Setup**: Initialize the environment with a fixed random seed and detect the computation device (GPU).
2.  **Training**: Execute the training pipeline using `run_training`. I will set `epochs=150` to create a fast baseline that fits well within the time limit while allowing the cosine annealing scheduler to complete a full cycle. This trains an ensemble of 5 models.
3.  **Validation**:
    *   Load the validation dataset and the trained model ensemble.
    *   Perform inference using Test-Time Augmentation (TTA) to ensure the validation metric matches the potential test performance.
    *   Calculate the **Global RMSE** across all pixels in the validation set, as per the metric definition.
    *   Collect per-image metadata (intensity stats, dimensions) and per-image RMSE for failure analysis.
4.  **Failure Analysis**: Calculate and print the Pearson correlation between the model's error (RMSE) and input image features (mean intensity, standard deviation, size) to identify systematic weaknesses.
5.  **Submission**: Compare the calculated Global RMSE against the specified threshold (`0.012221260240721992`). If and only if the metric is lower than the threshold, invoke `generate_submission` to create the final prediction file.
