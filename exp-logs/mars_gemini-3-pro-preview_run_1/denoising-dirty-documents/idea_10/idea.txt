Based on the comprehensive analysis of the provided lessons and the identification of the "Context-Diversity Trade-off" (Cite {solution_lesson_node_00027}, Cite {solution_lesson_node_00034}) as the primary bottleneck, I propose the following optimized strategy. This solution implements a **Heterogeneous Dual-Stream Ensemble** enhanced by a **Signal-Aligned Data Pipeline**.

# Model
**Architecture: Heterogeneous Dual-Stream Ensemble**
Instead of relying on a single "compromise" architecture, we will deploy a composite system consisting of two distinct U-Net variants, each specialized for a specific aspect of the denoising task.

1.  **Stream A: Context Specialist (4-Level U-Net)**
    *   **Structure:** A standard **4-Level U-Net** (Encoder: 32 $\to$ 64 $\to$ 128 $\to$ 256 $\to$ 512).
    *   **Role:** This deep network is designed to capture global text structures (lines, paragraphs) and continuity. It is architected to accept large input patches where the bottleneck resolution ($20 \times 20$) remains sufficient to preserve spatial fidelity (Cite {solution_lesson_node_00026}).
    *   **Upsampling:** Bilinear Upsampling followed by Convolution (Cite {solution_lesson_node_00009}).

2.  **Stream B: Texture Specialist (3-Level U-Net)**
    *   **Structure:** A lightweight **3-Level U-Net** (Encoder: 32 $\to$ 64 $\to$ 128 $\to$ 256).
    *   **Role:** This shallower network acts as a structural regularizer optimized for high-frequency texture reconstruction. It is architected to accept smaller input patches, preventing overfitting by leveraging massive crop diversity (Cite {solution_lesson_node_00018}).

# Data
**Preprocessing & Augmentation: Signal Alignment and Multi-Scale Strategy**
We will implement a fundamentally new data paradigm to address the "Padding Artifacts" and "Context-Diversity" conflicts.

1.  **Signal Alignment (Structural Innovation):**
    *   **Inverted Intensity Processing:** We will invert the pixel intensities of all images during loading: $I_{input} = 1.0 - I_{raw}$.
    *   **Rationale:** In the provided dataset, text is black (0) and background is white (1). Standard zero-padding in CNNs introduces "black border" artifacts (value 0) which the model interprets as signal (text). By inverting the images, the background becomes 0 (sparse) and text becomes 1 (signal). This ensures that zero-padding seamlessly extends the background, eliminating border artifacts and aligning the sparse text signal with the ReLU activation mechanics of the network.

2.  **Dual-Scale Patching:**
    *   **Stream A (Context):** Trained on **$320 \times 320$ pixel crops**. This maximizes the physical input window to provide the dense context required for the deep network (Cite {solution_lesson_node_00034}).
    *   **Stream B (Texture):** Trained on **$160 \times 160$ pixel crops**. This ensures massive combinatorial crop diversity, forcing the model to learn robust, translation-invariant local texture statistics (Cite {solution_lesson_node_00027}).

3.  **Augmentation:**
    *   **Geometric:** Random horizontal flips, vertical flips, and 90-degree rotations (Cite {solution_lesson_node_00003}).
    *   **Deterministic Loading:** Use a `worker_init_fn` to seed data loaders for full reproducibility (Cite {solution_lesson_node_00015}).

# Training
**Procedure: Massive Converged Bagging**
We will leverage the high efficiency of the proposed architectures to train a large-scale ensemble within the 24-hour budget.

*   **Ensemble Scale:** We will train **10 independent instances** of the Context Specialist (Stream A) and **10 independent instances** of the Texture Specialist (Stream B), for a total of **20 models**.
*   **Full Convergence:** Each model will be trained for **1000 epochs**. We explicitly prioritize training fully converged models over using early stopping, as this minimizes bias (Cite {solution_lesson_node_00012}, Cite {solution_lesson_node_00016}).
*   **Optimization Velocity:** **Adam** optimizer with a **high learning rate (1e-3)** and **small batch size (16)** to maximize gradient update frequency (Cite {solution_lesson_node_00010}).
*   **Scheduler:** **Cosine Annealing** with `T_max=1000` (decoupled from stopping criteria). This ensures the learning rate decays fully to zero, allowing the models to settle into sharp minima (Cite {solution_lesson_node_00007}).
*   **Loss Function:** Mean Squared Error (MSE) on the inverted signal.

# Evaluation
**Inference Pipeline**
*   **Inverted Inference:** Test images will be inverted ($1.0 - I$) before processing to match the training distribution and padding logic.
*   **D4 Group Test-Time Augmentation (TTA):** For every test image, we will generate predictions for **8 geometric views** (Original, Rot90, Rot180, Rot270, and their horizontal flips). These will be inversely transformed and averaged (Cite {solution_lesson_node_00028}).
*   **Heterogeneous Aggregation:** The TTA-averaged outputs from all **20 fully converged models** (10 Context + 10 Texture) will be averaged together. This combines the global coherence of the Context models with the fine-grained fidelity of the Texture models.
*   **Re-Inversion:** The final averaged prediction will be inverted back ($1.0 - I_{pred}$) to the original intensity space for submission.
