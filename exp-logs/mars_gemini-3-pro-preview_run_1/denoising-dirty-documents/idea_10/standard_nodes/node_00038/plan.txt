Implementation Strategy:
1.  **Configuration Override**: To adhere to the "fast baseline" requirement while ensuring sufficient convergence to meet the validation threshold, we will override the default `EPOCHS` and `ENSEMBLE_SIZE` in `library.config`. We will set `EPOCHS` to 30 (sufficient for convergence on this small dataset) and `ENSEMBLE_SIZE` to 2 (providing ensemble benefits without excessive runtime).
2.  **Training**: We will execute `library.train.train_model(debug=False)`. We use `debug=False` to utilize our custom overrides rather than the hardcoded debug settings (which are too short).
3.  **Validation**:
    *   We will load the trained ensemble using `library.inference.load_ensemble`.
    *   We will iterate through the validation set provided by `library.dataset.get_dataloaders`.
    *   For each image, we will compute the RMSE between the prediction (using Test-Time Augmentation via `predict_with_tta`) and the ground truth.
    *   We will aggregate these errors to compute the global Final Validation Metric.
4.  **Failure Analysis**:
    *   We will calculate the correlation between the per-image RMSE and image statistics (Mean and Std Dev of intensity).
    *   This helps identify if the model struggles with specific image characteristics (e.g., darker or more complex images).
5.  **Submission**:
    *   We will compare the Final Validation Metric against the provided threshold.
    *   If the metric is lower (better), we will trigger `library.inference.generate_submission` to create the submission file.
