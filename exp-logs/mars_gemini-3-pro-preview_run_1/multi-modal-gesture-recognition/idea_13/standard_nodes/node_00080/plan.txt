Implementation Strategy:
1.  **Data Preprocessing**: Implement **Root-Relative Normalization** in `library/data_loader.py`. By subtracting the "HipCenter" coordinates from all other joints frame-by-frame, we enforce translation invariance, allowing the model to focus on the pose configuration rather than the subject's absolute position (Cite {solution_lesson_node_00079}).
2.  **Model Architecture**: Modify the `IICGRN` model in `library/model.py` to use `pack_padded_sequence` and `pad_packed_sequence` for the GRU layers. This ensures the recurrent network explicitly ignores padded time-steps during training, preventing the hidden state from being corrupted by padding noise (Cite {solution_lesson_node_00079}).
3.  **Training Loop**: Update `library/engine.py` to pass the sequence lengths to the model's forward pass, which is required for the packing operation.
4.  **Hyperparameters**: Increase the number of training epochs to 60 in `runfile.py` to ensure the model has sufficient time to converge, as indicated by previous successful runs (Cite {solution_lesson_node_00040}).
