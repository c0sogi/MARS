This script demonstrates the end-to-end usage of the provided machine learning library for the multimodal gesture recognition task. It performs the following steps:

1.  **Setup & Configuration**: Sets random seeds for reproducibility and creates temporary subsets of the metadata to ensure the demonstration runs quickly.
2.  **Data Loading Verification**: Instantiates the `GestureDataset` and `DataLoader`, verifying that data samples (Skeleton, Audio, Labels) are loaded correctly and that batch collation (padding/masking) functions as expected.
3.  **Model Architecture Verification**: Instantiates the `IDGFN` model, performs a forward pass with a sample batch, and asserts that the output logits have the correct dimensions.
4.  **Training Loop Demonstration**: Configures the `Trainer` for a minimal run (2 epochs, small batch size) and executes the training process on the subset data, verifying that a model checkpoint is saved.
5.  **Inference & Submission**: Runs the prediction pipeline using the trained checkpoint on a test subset, verifying that the output submission file is generated in the correct format.
6.  **Metric Logic Check**: Validates the Levenshtein distance metric calculation with a known example.
