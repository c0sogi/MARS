The issue stems from corrupted or incompatible cached data (`.npz` files) where the `skeleton` tensor has 2 dimensions (flattened) instead of the expected 3 dimensions (Time, Joints, Channels). The `DataLoader` crashes when trying to unpack the shape into 3 variables. To fix this, I will modify `library/data_loader.py` to validate the dimensions of the loaded cache and reject it if it doesn't match the expected 3D structure (Cite debug_lesson_1). Additionally, I will update `runfile.py` to delete the existing statistics file at startup to ensure global stats are recomputed using the corrected data format, preventing downstream contamination (Cite debug_lesson_14).
