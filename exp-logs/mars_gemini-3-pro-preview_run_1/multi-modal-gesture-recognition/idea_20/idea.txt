Based on the comprehensive analysis of the accumulated lessons, I propose the **Decoupled-Anchor Gated-Injection Network (DAGI-Net)**. This solution introduces a structural innovation—**Modality-Specific Anchoring**—to the fusion and injection mechanism. By extracting global context descriptors from each modality *before* fusion, this architecture enables the gating mechanism to distinguish between "globally silent" and "globally active" modalities more effectively than the previous post-fusion approach, while rigorously adhering to the successful optimization and backbone strategies identified in the lessons.

# Model

The architecture is a **Multi-Stream Hybrid Network** that evolves the "Global-Conditioned" backbone by decoupling the global context extraction.

1.  **Decoupled Input Stems (Strategic Retention):**
    We process modalities independently to prevent gradient dominance and allow specific feature extraction (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates (Flattened) via `Linear Projection -> Temporal Conv1d(k=7) -> ReLU -> Dropout`. The kernel size of 7 ensures a robust local receptive field (Cite solution_lesson_node_00040), and the ordering ensures correct feature extraction (Cite solution_lesson_node_00010). We strictly avoid graph convolutions (Cite solution_lesson_node_00039) and explicit velocity inputs (Cite solution_lesson_node_00053).
    *   **Audio Stream:** Processes **MFCCs** via an identical stem. We strictly use compact MFCCs rather than high-dimensional Mel Spectrograms to prevent noise overfitting (Cite solution_lesson_node_00096).

2.  **Modality-Specific Anchoring & Conditioned Gating (Structural Innovation):**
    *   **Decoupled Anchors:** Instead of computing Global Average Pooling (GAP) on the fused sequence (which mixes modality statistics), we compute GAP on the output of *each* stem independently:
        *   $G_{skel} = \text{GAP}(Stem_{skel})$
        *   $G_{audio} = \text{GAP}(Stem_{audio})$
        *   $G_{decoupled} = \text{Concat}(G_{skel}, G_{audio})$
    *   **Fusion:** The stem outputs are concatenated to form $X_{fused}$ and normalized via **Layer Normalization** (Cite solution_lesson_node_00011).
    *   **Decoupled-Conditioned Gating:** We apply a gating mechanism conditioned on the fused local features AND the decoupled global anchors:
        *   $Gate_t = \sigma(W_x X_{fused, t} + W_g G_{decoupled} + b)$
        *   $Y_t = X_{fused, t} \odot Gate_t$
    *   **Rationale:** This allows the gate to explicitly suppress a specific modality channel if its corresponding global anchor indicates low information (e.g., "Audio is globally silent, so gate down audio features"), preventing the "averaging out" of context that occurs in post-fusion pooling (Cite solution_lesson_node_00102).

3.  **Dual-Injected Recurrent Backbone (Strategic Retention):**
    We employ a 2-layer **Bidirectional GRU** (Hidden Dim=256) with the successful **Dual-Injection** topology.
    *   **Layer 1:** Processes the Gated Fusion sequence $Y$. Output is $H_1$.
    *   **Layer 2:** Processes a composite input formed by the previous hidden state, the cleaned local input, and the Decoupled Anchors.
        *   $Input_2 = H_1 + \text{Proj}_{local}(Y) + \text{Proj}_{global}(G_{decoupled})$.
    *   **Rationale:** Injecting the decoupled anchors ensures that deep layers maintain access to the distinct global properties of each modality, stabilizing long-term tracking (Cite solution_lesson_node_00070, solution_lesson_node_00086).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) for all frames. Never use raw absolute coordinates (Cite solution_lesson_node_00079).
    *   **Audio Feature Extraction:** Extract MFCCs using a **Physics-Based Alignment**. Set the Hop Length to match the video frame rate ($16000/20 = 800$) and set the **FFT Window Size** significantly larger (e.g., `n_fft=2048`) to ensure temporal overlap (Cite solution_lesson_node_00080, solution_lesson_node_00054).
    *   **Robust Ingestion:** Implement strict shape-based validation (e.g., `if shape == (20, 3)`) to handle `.mat` file variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Independent Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00016).

2.  **Augmentation (Strategic Retention):**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** to the entire multi-modal sequence (scaling length by $\alpha \sim U(0.8, 1.2)$). This targets global manifold variations (Cite solution_lesson_node_00102, solution_lesson_node_00090).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).
    *   **Avoid:** 3D Rotation (Cite solution_lesson_node_00103) and Max Pooling (Cite solution_lesson_node_00098).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index (Cite solution_lesson_node_00076).
    *   **Background Class Weight (0.5):** **Crucially**, set the background class weight to **0.5** to prevent model collapse (Cite solution_lesson_node_00095).
    *   **Label Smoothing (0.1):** To handle boundary ambiguity (Cite solution_lesson_node_00011).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** to maximize gradient updates per epoch (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU forward pass (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the DAGI-Net.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
