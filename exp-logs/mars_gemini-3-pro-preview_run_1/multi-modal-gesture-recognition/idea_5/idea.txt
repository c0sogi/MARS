Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose the **Adaptive Graph-Gated Residual Network (AG-GRN)**. This solution introduces a structural innovation in the feature engineering paradigm—**Adaptive Spatial Graph Convolution**—to explicitly model the topological relationships of the skeleton data, while retaining the successful temporal backbone and optimization strategies from the previous best approach.

# Model

The architecture is a **Hybrid Graph-Recurrent Network** that evolves the previous Multi-Stream approach by replacing the flat linear projection of skeleton data with a structure-aware graph processing block.

1.  **Adaptive Graph Skeleton Stem (Structural Innovation):**
    Instead of flattening the skeleton joints into a single vector (which discards connectivity information), we process the input as a **Spatio-Temporal Graph** $X \in \mathbb{R}^{T \times V \times C}$ (where $V=20$ joints, $C=3$ coordinates).
    *   **Adaptive Graph Layer:** We introduce a graph convolution operation defined as $Y = \text{ReLU}((A_{phys} + A_{learn}) X W)$.
        *   $A_{phys}$: A fixed binary adjacency matrix representing the physical connections of the human body (e.g., Elbow connected to Wrist). This provides a strong inductive bias.
        *   $A_{learn}$: A learnable matrix of the same shape, initialized to zero. This allows the model to learn non-physical dependencies (e.g., coordination between left and right hands) that are critical for gesture recognition.
        *   $W$: A shared weight matrix applied to the features of each joint.
    *   **Temporal Projection:** The graph output is flattened and passed through a `Conv1d(k=5) -> ReLU -> Dropout` block to extract local temporal dynamics (Cite solution_lesson_node_00010, solution_lesson_node_00007).

2.  **Audio Stem:**
    *   Processes MFCC features using an independent `Linear -> Conv1d -> ReLU -> Dropout` block to extract auditory cues without interference (Cite solution_lesson_node_00021).

3.  **Gated Fusion & Backbone:**
    *   **Fusion:** The outputs from the Graph Skeleton Stem and Audio Stem are concatenated and normalized via **Layer Normalization** (Cite solution_lesson_node_00011).
    *   **Context Gating:** We retain the **Context Gating** mechanism ($Y = X \odot \sigma(W X + b)$) immediately after fusion. This dynamically re-weights the multimodal features frame-by-frame, suppressing noisy modalities (Cite solution_lesson_node_00036).
    *   **Residual Recurrent Backbone:** The sequence is processed by a **Residual Bidirectional GRU** (2 layers, Hidden Dim=256). The residual connections prevent gradient degradation, and the reduced hidden dimension acts as a structural regularizer (Cite solution_lesson_node_00036, solution_lesson_node_00023).

# Data

1.  **Preprocessing:**
    *   **Skeleton:** Compute relative coordinates (`Joint - HipCenter`) (Cite solution_lesson_node_00005). Reshape the flat data into $(20, 3)$ per frame to support the graph layer.
    *   **Audio:** Extract MFCCs aligned to the video frame rate.
    *   **Normalization:** Apply **Z-score Normalization** (Zero Mean, Unit Variance) to both modalities using global training statistics. Do *not* use physical unit scaling (Cite solution_lesson_node_00016).

2.  **Augmentation:**
    *   **Random Channel Masking:** Randomly zero out ~10% of feature channels for the entire sequence duration with 50% probability (Cite solution_lesson_node_00013).
    *   **Additive Gaussian Noise:** Inject noise into the skeleton coordinates during training (Cite solution_lesson_node_00007).

# Training

1.  **Loss Function:**
    *   **Frame-wise Cross Entropy Loss**.
    *   **Label Smoothing (0.1)** to handle boundary ambiguity (Cite solution_lesson_node_00011).
    *   **Background Class Weight (0.5)** to balance recall with precision (Cite solution_lesson_node_00011).

2.  **Optimization Strategy:**
    *   **Optimizer:** AdamW with a **ReduceLROnPlateau** scheduler to ensure convergence (Cite solution_lesson_node_00031).
    *   **Metric-Aware Checkpointing:** Save the checkpoint that minimizes the **Levenshtein Error Rate** on the validation set, rather than Validation Loss (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the AG-GRN model.
    *   Apply a **Median Filter** (window size 5) to smooth the frame-wise probability maps (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the final list of gesture IDs, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
