### Implementation Strategy

1.  **Setup & Imports**: Import necessary classes and functions from the provided library files (`library.*`). Ensure the environment is configured correctly by setting the random seed.
2.  **Training**: Initialize the `Trainer` class. Execute the training loop using `trainer.fit()` with a reduced number of epochs (20) to satisfy the "fast baseline" requirement while ensuring sufficient convergence on this small dataset.
3.  **Validation & Metric Calculation**:
    *   Load the best model checkpoint saved during training.
    *   Iterate over the validation dataset using a `DataLoader`.
    *   Perform inference to generate frame-wise predictions.
    *   Apply post-processing (median filtering and decoding) to convert frame predictions into gesture sequences, matching the inference pipeline.
    *   Compute the Levenshtein distance between predicted sequences and ground truth labels.
    *   Calculate the final error rate: (Total Levenshtein Distance) / (Total Ground Truth Gestures).
    *   Print the metric in the required format.
4.  **Failure Analysis**:
    *   Aggregate error statistics per sample.
    *   Compute and print Pearson correlations between the error metric and input features (sequence length in frames and number of gestures) to identify systematic weaknesses.
5.  **Submission**:
    *   Check if the calculated validation metric is below the threshold of `0.1981`.
    *   If the condition is met, instantiate the `InferenceManager` to generate predictions for the test set and save the `submission.csv`.
