Based on the comprehensive analysis of the accumulated lessons, I propose the **Multi-Scale Context-Gated Input-Injected Network (MSC-IIN)**. This solution introduces a structural innovation—**Multi-Scale Temporal Stems**—to the feature extraction phase. By replacing the fixed-kernel stems of the previous best model with parallel multi-resolution branches, this architecture empowers the **Global-Conditioned Gating** mechanism to dynamically select the optimal temporal receptive field (e.g., short kernels for rapid jitters vs. long kernels for smooth motions) based on the sequence context. This is integrated into the robust "Input-Injected" backbone and optimization framework established in the lessons.

# Model

The architecture is a **Multi-Stream Hybrid Network** that evolves the "Global-Conditioned" approach by enriching the local feature representation with multi-scale temporal dynamics.

1.  **Decoupled Multi-Scale Stems (Structural Innovation):**
    We process modalities independently to prevent gradient dominance (Cite solution_lesson_node_00021), but we upgrade the feature extractors to capture diverse temporal resolutions.
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates via three parallel 1D Convolutional branches with kernel sizes $k=\{3, 7, 11\}$. The outputs are concatenated, followed by `ReLU -> Dropout`.
        *   $k=3$: Captures rapid, transient movements.
        *   $k=7$: Captures standard gesture dynamics (Cite solution_lesson_node_00040).
        *   $k=11$: Captures sustained, smooth motions.
    *   **Audio Stream:** Processes **MFCCs** via an identical multi-branch stem ($k=\{3, 7, 11\}$). We strictly use compact MFCCs (Cite solution_lesson_node_00096).

2.  **Global-Conditioned Gating & Scale Selection:**
    *   **Fusion:** The multi-scale outputs from both stems are concatenated to form the raw fused sequence $X$.
    *   **Raw Global Context:** We compute the **Global Average Pooling (GAP)** of $X$ (masking padding) to obtain $C_{raw}$. We strictly avoid Max Pooling (Cite solution_lesson_node_00098).
    *   **Conditioned Gating:** We apply the gating mechanism: $Y_t = X_t \odot \sigma(W_x X_t + W_c C_{raw} + b)$.
    *   **Rationale:** In this topology, the gate acts as a **Soft Scale Selection** mechanism. Conditioned on the global context (e.g., "this is a fast-paced sequence"), the network can suppress the $k=11$ channels and emphasize the $k=3$ channels frame-by-frame (Cite solution_lesson_node_00114, solution_lesson_node_00102).

3.  **Refined Context & Dual-Injected Backbone (Strategic Retention):**
    We employ the successful **Dual-Injection** topology with **Refined Context**.
    *   **Refined Anchor:** We compute the GAP of the *gated* sequence $Y$ to obtain $G_{refined}$. This ensures the injected context is free of noise suppressed by the gate (Cite solution_lesson_node_00106).
    *   **Layer 1:** Processes $Y$. Output is $H_1$.
    *   **Layer 2:** Processes a composite input: $Input_2 = H_1 + \text{Proj}_{local}(Y) + \text{Proj}_{global}(G_{refined})$.
    *   **Rationale:** This ensures deep layers have direct access to the multi-scale boundary information ($Y$) and stable semantic context ($G_{refined}$) (Cite solution_lesson_node_00086, solution_lesson_node_00070).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) (Cite solution_lesson_node_00079).
    *   **Audio Processing:** Mix stereo channels in the **time domain** (waveform averaging) *before* feature extraction (Cite solution_lesson_node_00114). Extract MFCCs using a **Physics-Based Hop Length** ($Hop = SampleRate / VideoFPS$) to ensure alignment (Cite solution_lesson_node_00054).
    *   **Robust Ingestion:** Implement strict shape-based validation to handle `.mat` variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Global Z-score Normalization** to both modalities using global training statistics. Do not use Instance-Level Normalization (Cite solution_lesson_node_00107, solution_lesson_node_00108).

2.  **Augmentation:**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** to the entire multi-modal sequence (scaling length by $\alpha \sim U(0.8, 1.2)$). This targets global manifold variations (Cite solution_lesson_node_00102).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).
    *   **Avoid:** 3D Rotation (Cite solution_lesson_node_00103) and Explicit Velocity (Cite solution_lesson_node_00053).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index (Cite solution_lesson_node_00076).
    *   **Background Class Weight (0.5):** Set weight to **0.5** to prevent model collapse (Cite solution_lesson_node_00095).
    *   **Label Smoothing (0.1):** (Cite solution_lesson_node_00011).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save checkpoint minimizing **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the MSC-IIN.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
