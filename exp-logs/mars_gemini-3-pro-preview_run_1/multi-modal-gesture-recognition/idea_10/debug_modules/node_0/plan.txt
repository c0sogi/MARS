This script demonstrates the end-to-end usage of the provided gesture recognition library. It performs the following steps:
1.  **Setup**: Configures paths and seeds for reproducibility. It creates a temporary working directory (`./working/demo_run`) to store subset metadata and cache files, ensuring the main experiment data remains untouched.
2.  **Data Preparation**: Creates small subsets (top 6 samples) of the provided metadata files to allow for rapid execution and testing.
3.  **Utility Verification**: Validates core utility functions like `levenshtein_distance`, `rle_decode`, and `median_filter` with assertions to ensure correctness.
4.  **Data Loading**: Manually instantiates `GestureDataset` and `DataLoader` using the subset metadata. It verifies the shape and integrity of the loaded batches (Skeleton, Audio, Labels, Masks).
5.  **Model Initialization**: Instantiates the `DGR_RN` model and performs a forward pass with dummy data to verify input/output tensor shapes.
6.  **Training & Validation Loop**: Runs a short training session (2 epochs) using the manual data loaders and the provided `train_one_epoch` and `validate` functions. It checks that the loss decreases or remains valid and that the model state can be saved.
