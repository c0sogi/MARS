Based on the comprehensive analysis of the accumulated lessons, I propose the **Semantic-Anchored Magnitude-Preserving Network (SAMP-Net)**. This solution introduces a structural innovation—**Semantic Anchor Supervision**—combined with a **Magnitude-Preserving Fusion Topology**.

This architecture explicitly corrects the "Normalization Interference" (Lesson 00111, 00127) and "Truncation Alignment" (Lesson 00132) flaws that caused previous high-capacity models to fail. By removing normalization layers around the gating mechanism and adding an auxiliary task that forces the global anchor to encode the *set* of present gestures, we ensure that the context injected into the backbone is both numerically high-fidelity and semantically rich.

# Model

The architecture is a **Multi-Stream Hybrid Network** designed to maximize signal integrity and semantic consistency.

1.  **Wide Independent Stems (Strategic Retention):**
    We process modalities independently to prevent gradient dominance (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates via a **Wide** `Linear -> Conv1d(k=7, channels=256) -> ReLU -> Dropout` block. We prioritize a single wide branch to maintain representational richness (Cite solution_lesson_node_00117).
    *   **Audio Stream:** Processes **MFCCs** via an identical wide stem. We strictly use compact MFCCs rather than high-dimensional Mel Spectrograms (Cite solution_lesson_node_00096).

2.  **Magnitude-Preserving Gated Fusion (Structural Optimization):**
    *   **Fusion:** The outputs from both stems are concatenated to form the raw fused sequence $X_{raw}$.
    *   **No Pre-Gate Normalization:** We strictly **remove Layer Normalization** before the gating block to preserve amplitude cues (Cite solution_lesson_node_00111).
    *   **Masked Global Context:** We compute the **Global Average Pooling (GAP)** of $X_{raw}$ using **Explicit Masking** to exclude padded time-steps ($G_{raw} = \sum(X \cdot mask) / \sum(mask)$). This corrects the "naive pooling" bug (Cite solution_lesson_node_00123).
    *   **Conditioned Gating:** The gate is computed as $Gate_t = \sigma(W_x X_{raw,t} + W_g G_{raw} + b)$. The gated output is $Y_t = X_{raw,t} \odot Gate_t$.
    *   **No Post-Gate Normalization:** We strictly **remove Layer Normalization** after gating to ensure suppressed frames remain numerically close to zero ("silence") (Cite solution_lesson_node_00127).

3.  **Semantic Auxiliary Head (Structural Innovation):**
    *   **Refined Anchor:** We compute the **Masked GAP** of the *gated* sequence $Y$ to obtain $G_{refined}$ (Cite solution_lesson_node_00106).
    *   **Auxiliary Task:** $G_{refined}$ is passed to a small MLP (`Linear -> ReLU -> Linear -> Sigmoid`) to predict the **multi-hot set of gestures** present in the sequence. This auxiliary supervision forces the global anchor to encode robust, position-invariant semantic information (e.g., "This video contains gesture A and B"), improving its utility when injected into the backbone (Cite solution_lesson_node_00093).

4.  **Input-Injected Backbone (Strategic Retention):**
    We employ a **2-layer Bidirectional GRU** (Hidden Dim=256) (Cite solution_lesson_node_00124).
    *   **Layer 1:** Processes $Y_t$. Output is $H_1$.
    *   **Layer 2 (Dual Injection):** Processes a composite input: $Input_2 = H_1 + \text{Proj}(Y) + \text{Proj}(G_{refined})$. This provides deep layers with direct access to high-frequency boundaries and the semantically supervised global context (Cite solution_lesson_node_00070, solution_lesson_node_00086).

5.  **Non-Linear Output Head:**
    *   A non-linear MLP projects the backbone output to frame-wise class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Anchor Modality Alignment:** Treat the **Video/Skeleton** stream as the anchor. Always **pad or interpolate** the Audio stream to match the Video duration. **Never truncate** the Video or rescale timestamps, as this destroys valid data and breaks alignment (Cite solution_lesson_node_00132).
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) (Cite solution_lesson_node_00079).
    *   **Audio Processing:** Mix stereo channels in the **time domain** (Cite solution_lesson_node_00114). Extract MFCCs using a **Physics-Based Hop Length** ($Hop = SampleRate / VideoFPS = 800$) and a **Window Size of 2048** (~2.5x Hop). This ensures sufficient temporal overlap without excessive smoothing (Cite solution_lesson_node_00080, solution_lesson_node_00128).
    *   **Robust Ingestion:** Implement strict shape-based validation to handle `.mat` variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Global Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00107).

2.  **Augmentation:**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** to the entire multi-modal sequence (scaling length by $\alpha \sim U(0.8, 1.2)$) (Cite solution_lesson_node_00102).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).

# Training

1.  **Loss Function:**
    *   **Multi-Task Loss:** $L = L_{Frame} + 0.2 \times L_{Set}$.
    *   **$L_{Frame}$:** Frame-wise Cross Entropy with **Supervised Padding** (do not mask padding). Set **Background Class Weight to 0.5** to prevent collapse (Cite solution_lesson_node_00076, solution_lesson_node_00095). Apply **Label Smoothing (0.1)** (Cite solution_lesson_node_00011).
    *   **$L_{Set}$:** Binary Cross Entropy on the multi-hot gesture set targets derived from the label list.

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the SAMP-Net.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
