2.  **Data Subsetting**:

    *   Create "mini" versions of these CSVs (e.g., 5 samples each) and save them to the demo directory.
    *   Update `Config` to point to these mini CSVs. This forces the data loader to process only a tiny fraction of the dataset, drastically reducing runtime.

3.  **Component Verification**:

    *   **Training Step**: Initialize the optimizer and loss functions. Run `train_epoch` for a single epoch and assert that the returned loss metrics are valid (finite numbers).

    *   **Inference**: Run `generate_submission` and verify that the output CSV file is created and follows the expected format.

4.  **Execution**:
    *   Run the entire pipeline within the `if __name__ == "__main__":` block.
    *   Use `set_seed` to ensure reproducibility.
    *   Suppress non-critical warnings for cleaner output.
