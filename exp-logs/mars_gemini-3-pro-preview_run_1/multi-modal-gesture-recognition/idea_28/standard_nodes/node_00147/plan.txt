Implementation Strategy:
1.  **Revert to GCINet Architecture (Cite Lesson 114, 145):** The previous solution (BAMPNet) added a boundary detection head which, while accelerating convergence, resulted in a higher final error rate (0.087) compared to the simpler GCINet (0.057). I will remove the boundary head and its associated auxiliary loss to focus the model capacity entirely on the sequence classification task.
2.  **Optimize Audio Alignment (Cite Lesson 141):** The current data loader uses linear interpolation to force MFCC features to match the video frame count. Lesson 141 warns that this "warping" destroys temporal locality. I will replace `F.interpolate` with explicit truncation or padding of the feature sequence to preserve frame-to-frame synchronization.
3.  **Extended Training Schedule:** Since the boundary head (which accelerated convergence) is removed, I will increase `NUM_EPOCHS` from 10 to 50 to allow the model sufficient time to converge, mirroring the successful GCINet run.
4.  **Cleanup:** Remove boundary-related logic from `config.py`, `data_loader.py`, `train.py`, and `runfile.py`.

def train_epoch(model, loader, optimizer, criterion_class, criterion_boundary, device):
    """
    Executes one training epoch.
    """
    model.train()
    total_loss = 0.0
    total_class_loss = 0.0
    total_bound_loss = 0.0
    num_batches = 0

    for batch in loader:
        # Move data to device
        skeleton = batch["skeleton"].to(device)
        audio = batch["audio"].to(device)
        labels = batch["labels"].to(device)
        boundaries = batch["boundaries"].to(device)
        mask = batch["mask"].to(device)
        lengths = batch[
            "lengths"
        ]  # Keep on CPU for pack_padded_sequence if needed, or move inside model

        optimizer.zero_grad()

        # Forward pass
        outputs = model(skeleton, audio, lengths, mask)
        logits = outputs["logits"]  # (B, T, NumClasses+1)
        pred_bound = outputs["boundary"]  # (B, T, 1)

        # Flatten for loss computation
        # Mask out padded regions for loss calculation to be precise,
        # though CrossEntropy handles ignore_index, masking is safer for custom logic.
        # Here we rely on the flattened view and the fact that we can ignore padding in CE if needed,
        # but since we have "supervised padding" (class 0), we include it.

        # Flatten: (B*T, C)
        logits_flat = logits.view(-1, logits.shape[-1])
        labels_flat = labels.view(-1)

        bound_flat = pred_bound.view(-1)
        boundaries_flat = boundaries.view(-1)

        # Compute Losses
        loss_cls = criterion_class(logits_flat, labels_flat)
        loss_bnd = criterion_boundary(bound_flat, boundaries_flat)

        # Combined Loss
        loss = (
            loss_cls * Config.LOSS_WEIGHT_CLASS + loss_bnd * Config.LOSS_WEIGHT_BOUNDARY
        )

        # Backward
        loss.backward()

        # Gradient Clipping
        torch.nn.utils.clip_grad_norm_(model.parameters(), Config.GRADIENT_CLIP_VAL)

        total_class_loss += loss_cls.item()
        total_bound_loss += loss_bnd.item()
