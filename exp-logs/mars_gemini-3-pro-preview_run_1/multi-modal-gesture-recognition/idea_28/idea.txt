Based on the comprehensive analysis of the accumulated lessons, I propose the **Boundary-Aware Magnitude-Preserving Network (BAMP-Net)**. This solution introduces two structural innovations: **Gated Convolutional Stems** (replacing static non-linearities with learnable feature selection) and **Auxiliary Boundary Supervision** (explicitly modeling temporal transitions). These are integrated into the robust **Magnitude-Preserving Input-Injected** architecture established in the previous best solution, strictly adhering to the optimization and preprocessing strategies that yielded the lowest error rates.

# Model

The architecture is a **Multi-Stream Hybrid Network** designed to maximize feature selectivity and temporal precision.

1.  **Gated Convolutional Stems (Structural Innovation):**
    We process modalities independently to prevent gradient dominance (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates via a **Wide Gated Block**: `Linear -> GatedConv1d(k=7, channels=256) -> Dropout`.
        *   **Gated Conv Unit:** Replaces the standard `Conv -> ReLU` with a **Gated Linear Unit (GLU)** topology. It computes two parallel convolutions, $A$ and $B$. The output is $A \odot \sigma(B)$. This allows the network to learn a dynamic feature selection mask early in the pipeline, prioritizing informative kinematic cues while suppressing noise, improving upon the static receptivity of previous stems (Cite solution_lesson_node_00117).
    *   **Audio Stream:** Processes **MFCCs** via an identical Gated Stem. We strictly use compact MFCCs (Cite solution_lesson_node_00096).

2.  **Magnitude-Preserving Gated Fusion (Strategic Retention):**
    *   **Fusion:** The outputs from both stems are concatenated to form $X_{raw}$.
    *   **No Pre-Gate Normalization:** We strictly **remove Layer Normalization** before gating to preserve amplitude cues (Cite solution_lesson_node_00111).
    *   **Masked Global Context:** We compute the **Global Average Pooling (GAP)** of $X_{raw}$ using **Explicit Masking** to exclude padded time-steps (Cite solution_lesson_node_00123).
    *   **Conditioned Gating:** The gate is computed as $Gate_t = \sigma(W_x X_{raw,t} + W_g G_{raw} + b)$. The gated output is $Y_t = X_{raw,t} \odot Gate_t$.
    *   **No Post-Gate Normalization:** We strictly **remove Layer Normalization** after gating to ensure suppressed frames remain numerically close to zero (Cite solution_lesson_node_00127).

3.  **Refined-Context Input-Injected Backbone (Strategic Retention):**
    We employ a **2-layer Bidirectional GRU** (Hidden Dim=256) (Cite solution_lesson_node_00124).
    *   **Refined Anchor:** We compute the **Masked GAP** of the *gated* sequence $Y$ to obtain $G_{refined}$ (Cite solution_lesson_node_00106).
    *   **Layer 1:** Processes $Y_t$. Output is $H_1$.
    *   **Layer 2 (Dual Injection):** Processes a composite input: $Input_2 = \text{Dropout}(H_1 + \text{Proj}(Y) + \text{Proj}(G_{refined}))$.
    *   **Vertical Dropout:** We apply dropout **after the summation** to enforce robust feature learning and prevent co-adaptation (Cite solution_lesson_node_00135, solution_lesson_node_00138).

4.  **Multi-Task Output Heads (Structural Innovation):**
    *   **Classification Head:** A non-linear MLP projects the backbone output to class probabilities.
    *   **Boundary Head:** A parallel MLP projects the backbone output to a binary probability $P(Boundary_t)$, indicating whether a gesture transition occurs at time $t$. This provides dense, frame-wise supervision that sharpens segmentation boundaries, complementing the class-based loss (Cite solution_lesson_node_00083).

# Data

1.  **Preprocessing:**
    *   **Anchor Modality Alignment:** Treat Video as the anchor. **Pad or interpolate** Audio to match Video duration. **Never truncate** or rescale timestamps (Cite solution_lesson_node_00132).
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) (Cite solution_lesson_node_00079).
    *   **Audio Processing:** Mix stereo channels in the **time domain** (Cite solution_lesson_node_00114). Extract MFCCs using a **Physics-Based Hop Length** ($Hop = SampleRate / VideoFPS = 800$) and a **Window Size of 2048** (~2.5x Hop) (Cite solution_lesson_node_00080, solution_lesson_node_00128).
    *   **Robust Ingestion:** Implement strict shape-based validation (Cite solution_lesson_node_00077).
    *   **Normalization:** Apply **Global Z-score Normalization** to both modalities (Cite solution_lesson_node_00107).

2.  **Augmentation:**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** ($\alpha \sim U(0.8, 1.2)$) to target global manifold variations (Cite solution_lesson_node_00102).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).
    *   **Avoid:** 3D Rotation (Cite solution_lesson_node_00103).

# Training

1.  **Loss Function:**
    *   **Multi-Task Loss:** $L = L_{Class} + 0.5 \times L_{Boundary}$.
    *   **$L_{Class}$:** Frame-wise Cross Entropy with **Supervised Padding** (padding = Background Class). Set **Background Class Weight to 0.5** (Cite solution_lesson_node_00076, solution_lesson_node_00095). Apply **Label Smoothing (0.1)** (Cite solution_lesson_node_00011).
    *   **$L_{Boundary}$:** Binary Cross Entropy. Targets are generated dynamically: $y_t = 1$ if $label_t \neq label_{t-1}$, else $0$. Padding is treated as Background (Class 0), so transitions to/from padding are valid boundaries.

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the BAMP-Net.
    *   Use the **Classification Head** output for prediction.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
