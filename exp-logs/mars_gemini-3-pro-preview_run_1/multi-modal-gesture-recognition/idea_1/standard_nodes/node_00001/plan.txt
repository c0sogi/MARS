4.  **Validation & Metric Calculation**: After training, load the best model checkpoint. Run a manual inference pass over the validation set to calculate the Levenshtein distance for each sample. Compute and print the `Final Validation Metric` as required.
5.  **Failure Analysis**: Analyze the validation results by computing correlations between the prediction error (Levenshtein distance) and input characteristics (Sequence Length and Number of Gestures). Print these correlations to identify error patterns.
