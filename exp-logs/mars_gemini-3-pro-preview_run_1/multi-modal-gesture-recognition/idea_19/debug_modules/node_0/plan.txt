Implementation Strategy:
1.  **Configuration Setup**: We will override the default hyperparameters in `library.config` to ensure the demonstration runs quickly. This includes reducing the number of epochs, batch size, and model hidden dimensions, and redirecting paths to a temporary working directory.
2.  **Data Preparation**: To avoid the overhead of processing the entire dataset, we will create subsets of the provided metadata files (train, val, test) containing only a few samples. We will update the configuration to point to these subset files.
3.  **Component Verification**:
    *   **Utils**: Verify the correctness of `levenshtein_distance` and `decode_predictions` with known inputs.
    *   **Dataset & DataLoader**: Instantiate `GestureDataset` with the subset metadata, verify the initialization of statistics, and check the `collate_fn` by loading a single batch.
    *   **Model**: Instantiate `GCINet`, perform a forward pass with the loaded batch, and assert the output shape is correct.
4.  **Training Loop**: Initialize the `Trainer` with the subset data loaders and execute `trainer.fit()` to demonstrate the training process, validation, and checkpointing.
5.  **Inference & Submission**: Run a prediction loop on the test subset using the trained model and generate a sample submission file in the required format.
