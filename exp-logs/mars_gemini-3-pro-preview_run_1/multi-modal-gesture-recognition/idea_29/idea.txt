Based on the comprehensive analysis of the accumulated lessons, I propose the **Boundary-Supervised Magnitude-Preserving Input-Injected Network (BS-MPII)**.

This solution introduces a structural evolution by integrating **Auxiliary Boundary Supervision** (to accelerate convergence and sharpen transitions) into the **Magnitude-Preserving Input-Injected** architecture (which maximizes signal integrity). It explicitly synthesizes the robust "Wide Single-Scale" feature extraction (correcting the underfitting of GLU stems in Lesson 00148) with the "Vertical Dropout" and "No-Norm Gating" strategies that defined the stability of the previous best models.

# Model

The architecture is a **Multi-Stream Hybrid Network** designed to preserve signal amplitude while explicitly optimizing for temporal segmentation precision.

1.  **Wide Independent Stems (Strategic Retention):**
    We process modalities independently to prevent gradient dominance (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates via a **Wide** `Linear -> Conv1d(k=7, channels=256) -> ReLU -> Dropout` block. We explicitly choose a single wide branch (Cite solution_lesson_node_00117) and avoid complex Gated Linear Units to ensure rapid convergence (Cite solution_lesson_node_00148).
    *   **Audio Stream:** Processes **MFCCs** via an identical wide stem. We strictly use compact MFCCs rather than high-dimensional Mel Spectrograms (Cite solution_lesson_node_00096).

2.  **Magnitude-Preserving Gated Fusion (Strategic Retention):**
    *   **Fusion:** The outputs from both stems are concatenated to form the raw fused sequence $X_{raw}$.
    *   **No Pre-Gate Normalization:** We strictly **remove Layer Normalization** before the gating block to preserve amplitude cues (Cite solution_lesson_node_00111).
    *   **Masked Global Context:** We compute the **Global Average Pooling (GAP)** of $X_{raw}$ using **Explicit Masking** to exclude padded time-steps ($G_{raw}$). This corrects the "naive pooling" bug (Cite solution_lesson_node_00123).
    *   **Conditioned Gating:** The gate is computed as $Gate_t = \sigma(W_x X_{raw,t} + W_g G_{raw} + b)$. The gated output is $Y_t = X_{raw,t} \odot Gate_t$.
    *   **No Post-Gate Normalization:** We strictly **remove Layer Normalization** after gating. This ensures that suppressed frames remain numerically close to zero, allowing the backbone to treat them as "silence" (Cite solution_lesson_node_00127).

3.  **Regularized Input-Injected Backbone (Strategic Retention):**
    We employ a **2-layer Bidirectional GRU** (Hidden Dim=256) (Cite solution_lesson_node_00124).
    *   **Refined Anchor:** We compute the **Masked GAP** of the *gated* sequence $Y$ to obtain $G_{refined}$ (Cite solution_lesson_node_00106).
    *   **Layer 1:** Processes $Y_t$. Output is $H_1$.
    *   **Layer 2 (Dual Injection):** Processes a composite input: $Input_2 = \text{Dropout}(H_1 + \text{Proj}(Y) + \text{Proj}(G_{refined}))$.
    *   **Vertical Dropout:** We apply dropout **after the summation** to enforce robust feature learning and prevent co-adaptation (Cite solution_lesson_node_00135, solution_lesson_node_00138).

4.  **Multi-Task Output Heads (Structural Innovation):**
    *   **Classification Head:** A non-linear MLP projects the backbone output to class probabilities.
    *   **Boundary Head:** A parallel MLP projects the backbone output to a binary probability $P(Boundary_t)$, indicating whether a gesture transition occurs at time $t$. This provides dense, frame-wise supervision that sharpens segmentation boundaries, complementing the class-based loss (Cite solution_lesson_node_00145).

# Data

1.  **Preprocessing:**
    *   **Anchor Modality Alignment:** Treat Video as the anchor. **Pad or interpolate** Audio to match Video duration. **Never truncate** or rescale timestamps (Cite solution_lesson_node_00132).
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) (Cite solution_lesson_node_00079).
    *   **Audio Processing:** Mix stereo channels in the **time domain** (Cite solution_lesson_node_00114). Extract MFCCs using a **Physics-Based Hop Length** ($Hop = SampleRate / VideoFPS = 800$) and a **Window Size of 2048** (~2.5x Hop) (Cite solution_lesson_node_00080, solution_lesson_node_00128).
    *   **Robust Ingestion:** Implement strict shape-based validation (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Global Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00107).

2.  **Augmentation:**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** ($\alpha \sim U(0.8, 1.2)$) to target global manifold variations (Cite solution_lesson_node_00102).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).
    *   **Avoid:** 3D Rotation (Cite solution_lesson_node_00103) and Explicit Velocity (Cite solution_lesson_node_00053).

# Training

1.  **Loss Function:**
    *   **Multi-Task Loss:** $L = L_{Class} + 0.5 \times L_{Boundary}$.
    *   **$L_{Class}$:** Frame-wise Cross Entropy with **Supervised Padding** (padding = Background Class). Set **Background Class Weight to 0.5** to prevent collapse (Cite solution_lesson_node_00076, solution_lesson_node_00095). Apply **Label Smoothing (0.1)** (Cite solution_lesson_node_00011).
    *   **$L_{Boundary}$:** Binary Cross Entropy. Targets are generated dynamically: $y_t = 1$ if $label_t \neq label_{t-1}$, else $0$.

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the BS-MPII.
    *   Use the **Classification Head** output for prediction.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
