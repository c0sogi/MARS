The following script demonstrates the usage of the provided library files for the multimodal gesture recognition task. It performs a series of integration tests:
1.  **Utility Verification**: validates the logic of prediction decoding and metric computation.
2.  **Data Loading**: instantiates the `GestureDataset` with a small debug subset, verifies data shapes, and tests the batch collation process.
3.  **Model Forward Pass**: initializes the `PCA_IIN` model and performs a forward pass with dummy data to verify tensor dimensions.
4.  **Full Training Loop**: executes a short training run (2 epochs on 10 samples) using the `train_model` function to ensure the entire pipeline works end-to-end.
