This script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition. It performs the following steps:

1.  **Data Loading & Processing**: Loads the training metadata and processes a small subset of samples to extract skeleton and audio features using `process_sample`. It verifies the data structures and shapes.
2.  **Statistics Computation**: Computes global normalization statistics (mean/std) on the subset using `compute_global_stats`.
3.  **Dataset & DataLoader**: Instantiates the `GestureDataset` and a `DataLoader` with the custom `collate_fn`. It verifies batch construction, padding, and tensor shapes.
4.  **Model Initialization & Inference**: Initializes the `GCAResNet` model, performs a forward pass with a batch of data, and verifies the output logit shapes.
5.  **Loss Calculation**: Demonstrates how to compute the CTC loss given the model outputs and targets, ensuring correct dimension permutation.
6.  **Metrics Evaluation**: Decodes the model predictions using `decode_predictions` (which applies median filtering) and computes the Levenshtein distance against ground truth using `evaluate_batch`.
7.  **Optimization Step**: Simulates a single training optimization step to verify backward pass and parameter updates.

The script runs on a small subset (4 samples) to ensure rapid execution and uses assertions to strictly validate logic correctness.
