Based on the comprehensive analysis of the accumulated lessons, I propose the **Deep Wide-Spectrum Anchored Input-Injected Network (DW-AIIN)**. This solution introduces a structural evolution by combining **Raw Magnitude Gating** (to preserve signal amplitude) with a **Deep Input-Injected Backbone** (3 layers instead of 2) and **Wide Single-Scale Stems**. This addresses the specific weaknesses identified in previous multi-scale and normalized-gating experiments while scaling up the successful "Input Injection" topology.

# Model

The architecture is a **Multi-Stream Hybrid Network** that prioritizes feature width and signal integrity over complex branching.

1.  **Wide Single-Scale Stems (Structural Optimization):**
    We process modalities independently to prevent gradient dominance (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates via a **Wide** `Linear -> Conv1d(k=9, channels=256) -> ReLU -> Dropout` block. We explicitly choose a single wide branch over thin multi-scale branches to avoid information bottlenecks (Cite solution_lesson_node_00117). The kernel size of 9 ensures a broad local receptive field (Cite solution_lesson_node_00040).
    *   **Audio Stream:** Processes **MFCCs** via an identical wide stem. We strictly use compact MFCCs rather than Mel Spectrograms (Cite solution_lesson_node_00096).

2.  **Raw Magnitude Gating (Structural Innovation):**
    *   **Fusion:** The outputs from both stems are concatenated to form $X_{raw}$.
    *   **No Pre-Gate Normalization:** We strictly **remove Layer Normalization** before the gating block. Normalization standardizes the background noise to the same scale as active gestures, washing out the amplitude cues required for effective filtering (Cite solution_lesson_node_00111).
    *   **Conditioned Gating:** We compute the Global Average Pooling (GAP) of $X_{raw}$ to obtain $G_{raw}$. The gate is computed as $Gate = \sigma(W_x X_{raw} + W_g G_{raw} + b)$. The gated output is $Y = X_{raw} \odot Gate$. This allows the model to suppress noise based on the raw signal magnitude and global context (Cite solution_lesson_node_00102).

3.  **Refined Context & Deep Dual-Injected Backbone (Structural Innovation):**
    We extend the backbone to a **3-layer Bidirectional GRU** (Hidden=256) to increase temporal depth.
    *   **Refined Anchor:** We compute the GAP of the *gated* sequence $Y$ to obtain $G_{refined}$. This ensures the injected context is clean (Cite solution_lesson_node_00106).
    *   **Layer 1:** Processes $Y$. Output is $H_1$.
    *   **Layer 2:** Processes $Input_2 = H_1 + \text{Proj}(Y) + \text{Proj}(G_{refined})$.
    *   **Layer 3:** Processes $Input_3 = H_2 + \text{Proj}(Y) + \text{Proj}(G_{refined})$.
    *   **Rationale:** Injecting the clean local signal ($Y$) and global anchor ($G_{refined}$) into *every* deep layer prevents signal dilution and gradient degradation, allowing the deeper network to refine segmentation boundaries without losing track of the input (Cite solution_lesson_node_00070, solution_lesson_node_00086).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) (Cite solution_lesson_node_00079).
    *   **Audio Processing:** Mix stereo channels in the **time domain** before feature extraction (Cite solution_lesson_node_00114). Extract MFCCs using a **Physics-Based Hop Length** ($Hop = SampleRate / VideoFPS$) and a large window size ($4 \times Hop$) (Cite solution_lesson_node_00054, solution_lesson_node_00080).
    *   **Robust Ingestion:** Implement strict shape-based validation to handle `.mat` variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Global Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00107).

2.  **Augmentation:**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** to the entire multi-modal sequence (scaling length by $\alpha \sim U(0.8, 1.2)$) to target global manifold variations (Cite solution_lesson_node_00102).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).
    *   **Avoid:** 3D Rotation (Cite solution_lesson_node_00103) and Explicit Velocity (Cite solution_lesson_node_00053).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index (Cite solution_lesson_node_00076).
    *   **Background Class Weight (0.5):** Set weight to **0.5** to prevent model collapse (Cite solution_lesson_node_00095).
    *   **Label Smoothing (0.1):** (Cite solution_lesson_node_00011).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save checkpoint minimizing **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the DW-AIIN.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
