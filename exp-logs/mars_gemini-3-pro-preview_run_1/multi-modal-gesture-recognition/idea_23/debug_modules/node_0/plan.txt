The following script demonstrates the end-to-end usage of the provided library components for the gesture recognition task.

**Implementation Strategy:**
1.  **Setup & Configuration**: Initialize the environment by setting random seeds and creating a temporary working directory (`./working/demo_execution`) to avoid conflicts with existing runs. We modify the `Config` class attributes at runtime to point to this directory and reduce hyperparameters (e.g., 2 epochs) for a fast execution.
2.  **Data Subsetting**: To ensure the demonstration runs quickly, we read the existing metadata files (`train.csv`, `val.csv`, `test.csv`), select a small subset of samples (top 10), and save them as new CSVs in the demo directory. We then point `Config` to these subset files.
3.  **Utility Verification**: We explicitly test the `levenshtein_distance` and `decode_predictions_to_gestures` functions with known inputs to verify their logic.
4.  **Model Verification**: We instantiate the `DW_AIIN` model and perform a dummy forward pass with random tensors to confirm that the architecture handles inputs and produces outputs of the correct shape.
5.  **Training Pipeline**: We execute `library.train.run_training()`. This function initializes the data loaders (calculating stats on the subset), trains the model for the specified few epochs, and saves the best checkpoint.
6.  **Inference Pipeline**: We execute `library.predict.run_prediction()`. This loads the saved checkpoint, runs inference on the subset test data, and generates a `submission.csv`.
7.  **Output Validation**: Finally, we assert that the submission file exists and contains the expected number of lines.
