### Implementation Strategy

1.  **Configuration Setup**: We will override the default `Config` parameters to create a "Demo Mode". This involves redirecting output directories (cache, checkpoints, submission) to a temporary `./working/demo_execution` folder and reducing training intensity (2 epochs, batch size 2, small subset of data).
2.  **Utility Verification**: We will validate the helper functions in `library/utils.py`, specifically ensuring the Levenshtein distance calculation and the prediction decoding logic (smoothing and run-length encoding) work as expected on synthetic data.
3.  **Data Loading Verification**: We will instantiate the `MultimodalDataset` using the provided library. We will assert that it correctly loads data, computes statistics, and that the `collate_fn` correctly pads sequences and generates masks.
4.  **Model Architecture Verification**: We will instantiate the `MCWINet` model from `library/model.py`, pass a batch of synthetic data through it, and verify that the output logits have the correct shape `(Batch, Time, NumClasses)`.
5.  **Training Pipeline Execution**: We will use the `Trainer` class from `library/trainer.py` to run a complete but short training loop (`fit`) and inference step (`predict`). We will verify that the loss decreases (or runs without error) and that a valid submission file is generated.
6.  **Cleanup**: We will remove the temporary directories created during the demo.
