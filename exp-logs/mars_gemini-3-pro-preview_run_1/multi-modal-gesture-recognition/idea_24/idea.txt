Based on the comprehensive analysis of the accumulated lessons, I propose the **Masked-Context Wide-Injected Network (MCWI-Net)**. This solution introduces a structural evolution by synthesizing the **Wide Single-Scale Stems** (to maximize feature capacity) with **Raw Magnitude Gating** (to preserve signal amplitude) and **Precise Masked Pooling** (to handle variable lengths correctly). It explicitly corrects the architectural flaws—specifically naive pooling and pre-gate normalization—that caused the failure of previous high-capacity models (e.g., Idea 23), while retaining the successful "Input Injection" topology.

# Model

The architecture is a **Multi-Stream Hybrid Network** designed to maximize signal integrity and context stability.

1.  **Wide Single-Scale Stems (Structural Optimization):**
    We process modalities independently to prevent gradient dominance (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates via a **Wide** `Linear -> Conv1d(k=7, channels=256) -> ReLU -> Dropout` block. We prioritize a single wide branch over thin multi-scale branches to avoid information bottlenecks and maintain representational richness (Cite solution_lesson_node_00117).
    *   **Audio Stream:** Processes **MFCCs** via an identical wide stem. We strictly use compact MFCCs rather than high-dimensional Mel Spectrograms (Cite solution_lesson_node_00096).

2.  **Raw Magnitude Gating (Structural Innovation):**
    *   **Fusion:** The outputs from both stems are concatenated to form the raw fused sequence $X_{raw}$.
    *   **No Pre-Gate Normalization:** We strictly **remove Layer Normalization** before the gating block. Normalization standardizes background noise to the same scale as active signals; removing it preserves the amplitude cues required for effective filtering (Cite solution_lesson_node_00111).
    *   **Masked Global Context:** We compute the **Global Average Pooling (GAP)** of $X_{raw}$ using **Explicit Masking** to exclude padded time-steps ($G_{raw} = \sum(X \cdot mask) / \sum(mask)$). This corrects the "naive pooling" bug from previous iterations (Cite solution_lesson_node_00123).
    *   **Conditioned Gating:** The gate is computed as $Gate_t = \sigma(W_x X_{raw,t} + W_g G_{raw} + b)$. The gated output is $Y_t = X_{raw,t} \odot Gate_t$.
    *   **Post-Gate Normalization:** Layer Normalization is applied *after* gating ($Y_{norm} = \text{LayerNorm}(Y)$) to stabilize the backbone input.

3.  **Refined-Context Input-Injected Backbone (Strategic Retention):**
    We employ a **2-layer Bidirectional GRU** (Hidden Dim=256) (Cite solution_lesson_node_00124).
    *   **Layer 1:** Processes $Y_{norm}$. Output is $H_1$.
    *   **Refined Anchor:** We compute the **Masked GAP** of the *gated* sequence $Y_{norm}$ to obtain $G_{refined}$. This ensures the injected context is free of suppressed noise (Cite solution_lesson_node_00106).
    *   **Layer 2 (Dual Injection):** Processes a composite input: $Input_2 = H_1 + \text{Proj}(Y_{norm}) + \text{Proj}(G_{refined})$. This provides deep layers with direct access to high-frequency boundaries and stable semantic context (Cite solution_lesson_node_00070, solution_lesson_node_00086).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) to ensure translation invariance (Cite solution_lesson_node_00079).
    *   **Audio Processing:** Mix stereo channels in the **time domain** before feature extraction (Cite solution_lesson_node_00114). Extract MFCCs using a **Physics-Based Hop Length** ($Hop = SampleRate / VideoFPS$) and a **Large Window Size** ($4 \times Hop$) to ensure temporal overlap and spectral continuity (Cite solution_lesson_node_00054, solution_lesson_node_00080).
    *   **Robust Ingestion:** Implement strict shape-based validation to handle `.mat` variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Global Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00107).

2.  **Augmentation:**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** to the entire multi-modal sequence (scaling length by $\alpha \sim U(0.8, 1.2)$) to target global manifold variations (Cite solution_lesson_node_00102).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).
    *   **Avoid:** 3D Rotation (Cite solution_lesson_node_00103) and Explicit Velocity (Cite solution_lesson_node_00053).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index to anchor null-state predictions (Cite solution_lesson_node_00076).
    *   **Background Class Weight (0.5):** **Crucially**, set the background class weight to **0.5** to prevent model collapse (Cite solution_lesson_node_00095).
    *   **Label Smoothing (0.1):** To handle boundary ambiguity (Cite solution_lesson_node_00011).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** to maximize gradient updates per epoch (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU forward pass to ensure correct backward context (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the MCWI-Net.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
