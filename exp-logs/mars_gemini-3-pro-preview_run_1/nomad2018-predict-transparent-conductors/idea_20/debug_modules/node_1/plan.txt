The error occurs because the `get_dataloaders` function uses `Config.BATCH_SIZE` as a default argument, which binds the initial value (128) at module import time. When `setup_demo_environment` updates `Config.BATCH_SIZE` to 4 at runtime, the function's default argument remains stale (128). Consequently, the dataloader produces batches of size 50 (the full mini-dataset), causing a shape mismatch against the expected batch size of 4 in the assertion.
