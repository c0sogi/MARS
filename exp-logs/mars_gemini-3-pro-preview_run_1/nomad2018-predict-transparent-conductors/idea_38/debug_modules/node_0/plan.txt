The implementation strategy involves creating a self-contained Python script that imports the provided library modules and demonstrates their functionality in a logical sequence.

1.  **Setup and Patching**: The script will first set up a temporary directory structure (`./working/demo_execution`) to store outputs, ensuring isolation. It will "monkey patch" configuration variables in the library modules (specifically `WORKING_DIR` and `DEBUG_SAMPLE_SIZE`) to ensure the demonstration runs quickly on a small subset of data (50 samples) and writes to the demo directory.
2.  **Component Verification**: It will then systematically instantiate and verify the core components:
    *   **Utils**: Verify logging, metrics (RMSLE), and the `AverageMeter` class.
    *   **Geometry**: Load a sample atom file, compute PBC distances, and center positions, asserting correct shapes.
    *   **Feature Engineering**: verifying the extraction of atomic and global features using dummy metadata and the loaded geometry.
    *   **Data Loading**: Initialize the data loaders with the patched debug size, fetching a batch to verify tensor shapes match the configuration dimensions.
    *   **Architecture**: Instantiate the `SSAWDSModel` and perform a forward pass with the fetched batch to confirm the model accepts the data format and produces the correct output shape.
3.  **End-to-End Training**: Finally, it will invoke the `run_training` function from `training.py` to execute a complete training loop for 1 epoch. This serves as an integration test. The script will verify that a submission file is generated as expected.
