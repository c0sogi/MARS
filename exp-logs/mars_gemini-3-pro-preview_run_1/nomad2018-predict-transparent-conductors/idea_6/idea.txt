Based on the lessons learned, I propose the **Physically-Augmented Dual-Stream Deep Sets (PA-DSDS)** strategy. This approach evolves the successful AP-DeepSets architecture (Idea 4) by transitioning from simple one-hot/geometric inputs to a **physically-informed feature paradigm**. It addresses the limitations of sparse geometric proxies (Lesson 21) by incorporating statistical summaries of the local topology, and it enhances the chemical representation using domain-specific atomic constants, while strictly adhering to the architectural principles (Wide MLPs, Dual Pooling, Late Fusion) that have proven effective.

### Model
The architecture consists of two parallel streams that process local and global information independently before fusing:

1.  **Atomic Stream (Physically-Informed):**
    *   **Input Features:** For each atom, construct a rich feature vector containing:
        *   **Chemical Identity:** One-hot encoding (Al, Ga, In, O).
        *   **Physical Constants:** Explicit values for **Atomic Mass**, **Covalent Radius**, and **Pauling Electronegativity**. This provides the model with continuous chemical manifolds rather than just orthogonal categories, aiding generalization across the limited element set.
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ (Cite Lesson 10).
        *   **Statistical Local Fingerprint:** Instead of a single nearest-neighbor distance (which is noisy) or a raw vector of neighbors (which overfits, Cite Lesson 21), calculate three scalar summary statistics of the $K=12$ nearest neighbors:
            *   **Minimum Distance ($d_{min}$):** Proxy for bond length limits (Cite Lesson 15).
            *   **Mean Distance ($\mu_{d_{12}}$):** Proxy for local packing density.
            *   **Distance Standard Deviation ($\sigma_{d_{12}}$):** Proxy for local structural distortion/regularity.
    *   **Encoder:** A **Wide MLP** (512 hidden units) projects this composite vector into a high-dimensional latent space (Cite Lesson 6, Lesson 17).
    *   **Output Layer:** A **Linear** projection (no activation) to the embedding dimension (Cite Lesson 18).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) to capture both average properties and salient structural anomalies (Cite Lesson 5, Lesson 7).

2.  **Global Stream (Thermodynamic Context):**
    *   **Input:** Macroscopic features: Lattice vector lengths, lattice angles, unit cell volume, atomic density, and **explicit stoichiometry** (composition percentages) (Cite Lesson 13).
    *   **Encoder:** A **High-Capacity MLP** (3 layers, 256 units) to model the complex non-linear influence of boundary conditions on energy (Cite Lesson 9).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (Cite Lesson 19).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Physical Constants Dictionary:** Define a lookup table for Al, Ga, In, O containing Mass, Radius, and Electronegativity.
2.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   Center atomic coordinates by subtracting the unit cell centroid.
    *   Compute the pairwise distance matrix (applying periodic boundary conditions).
    *   For each atom, identify the 12 nearest neighbors and compute the **Min**, **Mean**, and **Std Dev** of their distances.
    *   Construct the atom-wise feature vectors by combining One-Hot, Physical Constants, Centered Coords, and the Statistical Fingerprint.
3.  **Tabular Preprocessing:**
    *   Extract lattice parameters and stoichiometry.
    *   Calculate derived features: Cell Volume and Atomic Density.
    *   Apply **Standard Scaling** (z-score) to all continuous features (global and local) to ensure balanced gradients.
4.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables.

### Training
*   **Loss Function:** Mean Squared Error (MSE) on log-transformed targets.
*   **Optimizer:** AdamW with weight decay (e.g., 1e-4) to regularize the wide layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation RMSLE.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~15-20 epochs) to allow the larger capacity model to converge fully (Cite Lesson 17).

### Evaluation
1.  **Inference:** Preprocess the test set using the same pipeline (physical constants lookup, k-NN statistics, scaling).
2.  **Prediction:** Pass data through the trained model.
3.  **Inverse Transform:** Apply `exp(x) - 1` to predictions.
4.  **Submission:** Format as `id,formation_energy_ev_natom,bandgap_energy_ev`.

PHYSICAL_CONSTANTS = {

    "Ga": [69.72, 1.22, 1.81],
    "In": [114.82, 1.42, 1.78],
    "O": [16.00, 0.66, 3.44],
}

# 2. Data Preprocessing Functions

def parse_xyz(file_path):
    """Parses an XYZ file to extract atom types and coordinates."""
    with open(file_path, "r") as f:
        lines = f.readlines()

    # Skip header (comment lines) - usually first 2 lines in standard XYZ,
    # but this dataset has a specific format.
    # We look for lines starting with 'atom'
    atoms = []
    coords = []
    lattice_vectors = []

    for line in lines:
        parts = line.strip().split()
        if not parts:
            continue
        if parts[0] == "atom":
            coords.append([float(parts[1]), float(parts[2]), float(parts[3])])
            atoms.append(parts[4])
        elif parts[0] == "lattice_vector":
            lattice_vectors.append(
                [float(parts[1]), float(parts[2]), float(parts[3])]
            )

    return np.array(atoms), np.array(coords), np.array(lattice_vectors)


def get_pbc_distances(coords, lattice_vectors):
    """
    Computes pairwise distances under periodic boundary conditions.
    Uses the minimum image convention.
    """
    # Simple minimum image convention for orthogonal-ish boxes
    # For general triclinic, we check 27 images.
    n_atoms = len(coords)
    if n_atoms <= 1:
        return np.zeros((1, 1))

    # Create images
    images = []
    for i in [-1, 0, 1]:
        for j in [-1, 0, 1]:
            for k in [-1, 0, 1]:
                images.append(
                    i * lattice_vectors[0]
                    + j * lattice_vectors[1]
                    + k * lattice_vectors[2]
                )
    images = np.array(images)  # (27, 3)

    # Compute distances
    # This can be memory intensive for large N, but N is small here (~80).
    # d_ij = min(|r_i - r_j + T|)
    # Expand dims: (N, 1, 1, 3) - (1, N, 1, 3) + (1, 1, 27, 3)
    diff = (
        coords[:, None, None, :]
        - coords[None, :, None, :]
        + images[None, None, :, :]
    )
    dists_sq = np.sum(diff**2, axis=-1)  # (N, N, 27)
    min_dists_sq = np.min(dists_sq, axis=-1)  # (N, N)
    return np.sqrt(min_dists_sq)


def compute_local_fingerprint(coords, lattice_vectors, k=12):
    """
    Computes statistical summary of local neighborhood for each atom.
    Returns: [d_min, d_mean, d_std] for k nearest neighbors.
    """
    dist_matrix = get_pbc_distances(coords, lattice_vectors)
    n_atoms = len(coords)
    fingerprints = []

    # Fill diagonal with infinity to ignore self-distance
    np.fill_diagonal(dist_matrix, np.inf)

    for i in range(n_atoms):
        # Sort distances
        sorted_dists = np.sort(dist_matrix[i])
        # Take k nearest (or all if less than k)
        k_nearest = sorted_dists[: min(k, n_atoms - 1)]

        if len(k_nearest) == 0:
            fingerprints.append([0.0, 0.0, 0.0])
        else:
            d_min = k_nearest[0]
            d_mean = np.mean(k_nearest)
            d_std = np.std(k_nearest)
            fingerprints.append([d_min, d_mean, d_std])

    return np.array(fingerprints)


def calculate_cell_volume(lv):
    """Calculates volume of the unit cell defined by lattice vectors."""
    return np.abs(np.dot(lv[0], np.cross(lv[1], lv[2])))


def process_dataset(df, root_dir):
    """
    Process the dataframe to generate features.
    """
    atomic_features_list = []
    global_features_list = []
    targets_list = []
    ids = []

    print(f"Processing {len(df)} samples...")

    for idx, row in df.iterrows():
        # 1. Parse Geometry
        file_path = os.path.join(root_dir, row["file_path"])
        atoms, coords, lattice_vectors = parse_xyz(file_path)

        # 2. Centered Coordinates (Lesson 10)
        centroid = np.mean(coords, axis=0)
        centered_coords = coords - centroid

        # 3. Local Fingerprint (Lesson 15, 21)
        # d_min, d_mean, d_std
        local_stats = compute_local_fingerprint(
            coords, lattice_vectors, k=CONFIG["k_neighbors"]
        )

        # 4. Construct Atomic Features
        # [OneHot(4), Mass, Radius, Negativity, x, y, z, d_min, d_mean, d_std]
        n_atoms = len(atoms)
        sample_atomic_feats = []
        for i in range(n_atoms):
            atom_type = atoms[i]
            # One-hot
            one_hot = [0] * 4
            one_hot[ATOM_MAP[atom_type]] = 1
            # Physical constants
            phys = PHYSICAL_CONSTANTS[atom_type]
            # Coords
            xyz = centered_coords[i].tolist()
            # Stats
            stats = local_stats[i].tolist()

            feat_vec = one_hot + phys + xyz + stats
            sample_atomic_feats.append(feat_vec)

        atomic_features_list.append(np.array(sample_atomic_feats, dtype=np.float32))

        # 5. Construct Global Features
        # [lv1, lv2, lv3 (lengths), alpha, beta, gamma, volume, density, stoichiometry(4)]
        # Lattice lengths
        lv_lengths = [
            row["lattice_vector_1_ang"],
            row["lattice_vector_2_ang"],
            row["lattice_vector_3_ang"],
        ]
        # Angles
        angles = [
            row["lattice_angle_alpha_degree"],
            row["lattice_angle_beta_degree"],
            row["lattice_angle_gamma_degree"],
        ]
        # Volume
        vol = calculate_cell_volume(lattice_vectors)
        # Density
        density = n_atoms / vol
        # Stoichiometry (explicit, Lesson 13)
        # percent_atom_al, percent_atom_ga, percent_atom_in. Oxygen is implicit remainder?
        # The csv has percent columns for Al, Ga, In.

        # Let's use the 3 provided + calculated O percent.
        pct_al = row["percent_atom_al"]
        pct_ga = row["percent_atom_ga"]
        pct_in = row["percent_atom_in"]
        # Assuming sum is 1.0 for cations? Or total?
        # Usually these sum to 1.0 or similar. Let's just use the 3 columns provided.
        # Actually, let's add total atoms too.
        total_atoms = row["number_of_total_atoms"]

        global_vec = (
            lv_lengths + angles + [vol, density, total_atoms, pct_al, pct_ga, pct_in]
        )
        global_features_list.append(np.array(global_vec, dtype=np.float32))

        # 6. Targets
        if "formation_energy_ev_natom" in row:
            targets_list.append(

            )
        else:
            targets_list.append([0.0, 0.0])  # Dummy for test

        ids.append(row["id"])

    return atomic_features_list, np.array(global_features_list), np.array(targets_list), ids

# 3. Model Definition

class PADSDS(nn.Module):
    def __init__(self, atomic_input_dim, global_input_dim, hidden_dim, latent_dim):
        super(PADSDS, self).__init__()

        # Atomic Stream Encoder (Wide MLP, Lesson 6, 17)
        self.atomic_encoder = nn.Sequential(
            nn.Linear(atomic_input_dim, hidden_dim),
            nn.BatchNorm1d(hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.BatchNorm1d(hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.BatchNorm1d(hidden_dim),
            nn.ReLU(),
            # Linear projection before pooling (Lesson 18)
            nn.Linear(hidden_dim, latent_dim),
        )

        # Global Stream Encoder (High Capacity, Lesson 9)
        self.global_encoder = nn.Sequential(
            nn.Linear(global_input_dim, 256),
            nn.BatchNorm1d(256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.BatchNorm1d(256),
            nn.ReLU(),
            nn.Linear(256, latent_dim),
            nn.BatchNorm1d(latent_dim),
            nn.ReLU(),
        )

        # Fusion Head (Late Fusion, Lesson 19)
        # Input is Latent (Mean) + Latent (Max) + Latent (Global)
        fusion_input_dim = latent_dim * 2 + latent_dim
        self.regressor = nn.Sequential(
            nn.Linear(fusion_input_dim, 512),
            nn.ReLU(),
            nn.Dropout(0.1),
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, 2),  # Two targets
        )

    def forward(self, atomic_feats, batch_indices, global_feats):
        """
        atomic_feats: (Total_Atoms, Atomic_Input_Dim)
        batch_indices: (Total_Atoms,) indicating which sample each atom belongs to
        global_feats: (Batch_Size, Global_Input_Dim)
        """
        # 1. Atomic Stream
        atom_embeddings = self.atomic_encoder(atomic_feats)

        # 2. Aggregation (Dual Pooling: Mean + Max) (Lesson 5)
        # We need to pool atom_embeddings based on batch_indices
        batch_size = global_feats.size(0)
        
        # Initialize outputs
        pooled_mean = torch.zeros(batch_size, atom_embeddings.size(1), device=atom_embeddings.device)
        pooled_max = torch.full((batch_size, atom_embeddings.size(1)), -1e9, device=atom_embeddings.device)

        # Scatter operations (manual implementation for compatibility)
        # Mean
        pooled_mean.index_add_(0, batch_indices, atom_embeddings)
        # Count atoms per batch
        counts = torch.bincount(batch_indices, minlength=batch_size).unsqueeze(1).float()
        pooled_mean = pooled_mean / (counts + 1e-6)

        # Max (Scatter Max is tricky without torch_scatter, use loop or padded tensor if slow)
        # For efficiency in this script without extra deps, we'll use a loop-based approach for max
        # or a masked fill approach if memory allows. Given N~80 and Batch~32, loop is acceptable.
        # Actually, let's use a scatter_reduce if available (PyTorch 1.11+) or fallback.
        # Environment is PyTorch 2.x, so scatter_reduce is available.
        # Note: 'amax' reduction available in newer torch
        try:
            pooled_max = torch.zeros_like(pooled_mean).scatter_reduce_(
                0, batch_indices.unsqueeze(1).expand(-1, atom_embeddings.size(1)), 
                atom_embeddings, reduce="amax", include_self=False
            )
            # Handle cases where init value persists (no atoms?) - unlikely here
            # Replace -inf with 0
            pooled_max[pooled_max == -1e9] = 0.0
        except AttributeError:
             # Fallback for older torch or if scatter_reduce acts up
             for i in range(batch_size):
                 mask = (batch_indices == i)
                 if mask.any():
                     pooled_max[i] = torch.max(atom_embeddings[mask], dim=0)[0]
                 else:
                     pooled_max[i] = 0.0

        # 3. Global Stream
        global_embeddings = self.global_encoder(global_feats)

        # 4. Fusion
        # Concatenate: [Mean_Pool, Max_Pool, Global]
        combined = torch.cat([pooled_mean, pooled_max, global_embeddings], dim=1)

        # 5. Prediction
        output = self.regressor(combined)
        return output

# 4. Dataset & Collate
# -----------------------------------------------------------------------------
class CrystalDataset(Dataset):
    def __init__(self, atomic_feats, global_feats, targets):
        self.atomic_feats = atomic_feats
        self.global_feats = global_feats
        self.targets = targets

    def __len__(self):
        return len(self.global_feats)

    def __getitem__(self, idx):
        return (
            torch.tensor(self.atomic_feats[idx], dtype=torch.float32),
            torch.tensor(self.global_feats[idx], dtype=torch.float32),
            torch.tensor(self.targets[idx], dtype=torch.float32),
        )


def collate_fn(batch):
    atomic_list, global_list, target_list = zip(*batch)

    # Create batch indices for atoms
    batch_indices = []
    for i, atoms in enumerate(atomic_list):
        batch_indices.append(torch.full((atoms.shape[0],), i, dtype=torch.long))

    atomic_batch = torch.cat(atomic_list, dim=0)
    batch_indices = torch.cat(batch_indices, dim=0)
    global_batch = torch.stack(global_list, dim=0)
    target_batch = torch.stack(target_list, dim=0)

    return atomic_batch, batch_indices, global_batch, target_batch

def main():
    # Paths
    INPUT_DIR = "./input"
    TRAIN_CSV = os.path.join(INPUT_DIR, "train.csv")
    TEST_CSV = os.path.join(INPUT_DIR, "test.csv")
    SUBMISSION_PATH = "submission.csv"

    # Load Dataframes
    train_df = pd.read_csv(TRAIN_CSV)
    test_df = pd.read_csv(TEST_CSV)

    # Add file paths
    train_df["file_path"] = train_df["id"].apply(lambda x: f"train/{x}/geometry.xyz")
    test_df["file_path"] = test_df["id"].apply(lambda x: f"test/{x}/geometry.xyz")

    # --- Preprocessing ---
    print("Preprocessing Training Data...")
    train_atomic, train_global, train_targets, _ = process_dataset(train_df, INPUT_DIR)
    
    print("Preprocessing Test Data...")
    test_atomic, test_global, test_targets, test_ids = process_dataset(test_df, INPUT_DIR)

    # Feature Scaling
    # Atomic features: flatten list to fit scaler, then reshape? No, just fit on stacked.
    all_atomic = np.vstack(train_atomic)
    scaler_atomic = StandardScaler()
    scaler_atomic.fit(all_atomic)

    # Apply scaling
    train_atomic = [scaler_atomic.transform(x) for x in train_atomic]
    test_atomic = [scaler_atomic.transform(x) for x in test_atomic]

    # Global features
    scaler_global = StandardScaler()
    train_global = scaler_global.fit_transform(train_global)
    test_global = scaler_global.transform(test_global)

    # Log Transform Targets
    train_targets_log = np.log1p(train_targets)

    # Train/Val Split
    X_atomic_train, X_atomic_val, X_global_train, X_global_val, y_train, y_val = (
        train_test_split(
            train_atomic,
            train_global,
            train_targets_log,
            test_size=0.2,
            random_state=CONFIG["seed"],
        )
    )

    # Datasets & Loaders
    train_dataset = CrystalDataset(X_atomic_train, X_global_train, y_train)
    val_dataset = CrystalDataset(X_atomic_val, X_global_val, y_val)
    test_dataset = CrystalDataset(test_atomic, test_global, test_targets)

    train_loader = DataLoader(
        train_dataset,
        batch_size=CONFIG["batch_size"],
        shuffle=True,
        collate_fn=collate_fn,
    )
    val_loader = DataLoader(
        val_dataset,
        batch_size=CONFIG["batch_size"],
        shuffle=False,
        collate_fn=collate_fn,
    )
    test_loader = DataLoader(
        test_dataset,
        batch_size=CONFIG["batch_size"],
        shuffle=False,
        collate_fn=collate_fn,
    )

    # --- Model Initialization ---
    atomic_dim = X_atomic_train[0].shape[1]
    global_dim = X_global_train.shape[1]

    model = PADSDS(
        atomic_input_dim=atomic_dim,
        global_input_dim=global_dim,
        hidden_dim=CONFIG["hidden_dim_atomic"],
        latent_dim=CONFIG["latent_dim"],
    ).to(CONFIG["device"])

    optimizer = optim.AdamW(
        model.parameters(), lr=CONFIG["lr"], weight_decay=CONFIG["weight_decay"]
    )
    scheduler = optim.lr_scheduler.ReduceLROnPlateau(
        optimizer, mode="min", factor=0.5, patience=5, verbose=True
    )
    criterion = nn.MSELoss()

    # --- Training Loop ---
    best_val_loss = float("inf")
    patience_counter = 0

    print("Starting Training...")
    for epoch in range(CONFIG["epochs"]):
        model.train()
        train_loss = 0.0
        for atomic, batch_idx, glob, target in train_loader:
            atomic, batch_idx, glob, target = (
                atomic.to(CONFIG["device"]),
                batch_idx.to(CONFIG["device"]),
                glob.to(CONFIG["device"]),
                target.to(CONFIG["device"]),
            )

            optimizer.zero_grad()
            preds = model(atomic, batch_idx, glob)
            loss = criterion(preds, target)
            loss.backward()
            optimizer.step()
            train_loss += loss.item() * glob.size(0)

        train_loss /= len(train_dataset)

        # Validation
        model.eval()
        val_loss = 0.0
        with torch.no_grad():
            for atomic, batch_idx, glob, target in val_loader:
                atomic, batch_idx, glob, target = (
                    atomic.to(CONFIG["device"]),
                    batch_idx.to(CONFIG["device"]),
                    glob.to(CONFIG["device"]),
                    target.to(CONFIG["device"]),
                )
                preds = model(atomic, batch_idx, glob)
                loss = criterion(preds, target)
                val_loss += loss.item() * glob.size(0)

        val_loss /= len(val_dataset)
        val_rmsle = np.sqrt(val_loss) # Approximation since we optimized MSE on log

        print(
            f"Epoch {epoch+1}/{CONFIG['epochs']} - Train Loss: {train_loss:.4f} - Val Loss: {val_loss:.4f} - Val RMSLE: {val_rmsle:.4f}"
        )

        scheduler.step(val_loss)

        if val_loss < best_val_loss:
            best_val_loss = val_loss
            patience_counter = 0
            torch.save(model.state_dict(), "best_model.pt")
        else:
            patience_counter += 1
            if patience_counter >= CONFIG["patience"]:
                print("Early stopping triggered.")
                break

    # --- Inference ---
    print("Generating Predictions...")
    model.load_state_dict(torch.load("best_model.pt"))
    model.eval()
    
    all_preds = []
    with torch.no_grad():
        for atomic, batch_idx, glob, _ in test_loader:
            atomic, batch_idx, glob = (
                atomic.to(CONFIG["device"]),
                batch_idx.to(CONFIG["device"]),
                glob.to(CONFIG["device"]),
            )
            preds_log = model(atomic, batch_idx, glob)
            preds = torch.expm1(preds_log) # Inverse transform
            all_preds.append(preds.cpu().numpy())

    all_preds = np.concatenate(all_preds, axis=0)

    # Save Submission
    submission_df = pd.DataFrame(
        all_preds, columns=["formation_energy_ev_natom", "bandgap_energy_ev"]
    )
    submission_df.insert(0, "id", test_ids)
    submission_df.to_csv(SUBMISSION_PATH, index=False)
    print(f"Submission saved to {SUBMISSION_PATH}")


if __name__ == "__main__":
    main()
