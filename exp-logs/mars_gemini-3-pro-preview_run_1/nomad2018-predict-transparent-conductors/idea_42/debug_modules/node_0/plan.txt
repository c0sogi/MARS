The following script demonstrates the usage of the provided machine learning library for crystal property prediction. It performs the following steps:

1.  **Configuration Override**: Patches the `library.config` module at runtime to use a temporary working directory and reduced hyperparameters (fewer epochs, small dataset subset) for a fast demonstration.
2.  **Data Processing**: Manually calls `process_data` to generate features from the raw crystal structures and verifies the output shapes.
3.  **Dataset & DataLoader**: Instantiates the `CrystalDataset` and a PyTorch `DataLoader` with the custom sparse collate function, verifying batch integrity.
4.  **Model Initialization**: Instantiates the `REMSWDSModel` and performs a forward pass with a dummy batch to verify tensor dimensions.
5.  **Full Training Pipeline**: Executes `train_model()` to train the model on the subset and save the checkpoint.
6.  **Inference**: Executes `generate_predictions()` to produce a submission file using the trained model.
