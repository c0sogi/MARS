Based on the lessons learned from the previous experiments, I propose the **Context-Aware Deep Sets with Topological Fingerprinting (CADS-TF)** strategy. This approach structurally evolves the baseline Deep Sets architecture by introducing a "Local Topology Fingerprint" to resolve the lack of interaction modeling (addressing Lesson 8 and 15) and implementing "Early Context Injection" to condition atomic processing on global constraints (addressing Lesson 2 and 9), while retaining the capacity and stability improvements from Lessons 17 and 18.

### Model
The architecture consists of two interconnected processing streams that merge via a sophisticated aggregation mechanism:

1.  **Global Context Stream:**
    *   **Input:** Macroscopic features including lattice vector lengths, lattice angles, unit cell volume, atomic density, and **explicit stoichiometry** (composition percentages). Explicit stoichiometry is retained to satisfy **Lesson 13**.
    *   **Encoder:** A high-capacity MLP (e.g., 3 layers, 128 units) processes these features to generate a `global_context_vector`. This vector represents the thermodynamic boundary conditions (strain, pressure, chemical potential) of the crystal.

2.  **Atomic Stream (Context-Modulated):**
    *   **Input Features:** For each atom, construct a feature vector consisting of:
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ to retain node-level spatial variance (**Cite Lesson 10**).
        *   **Local Topology Fingerprint:** A vector containing the **sorted Euclidean distances to the $K$ nearest neighbors** (e.g., $K=16$). This evolves the single "nearest neighbor" scalar from **Lesson 15** into a richer, permutation-invariant descriptor of the local packing structure without introducing the computational cost or overfitting risks of dense graph convolution layers (**Cite Lesson 8**).
    *   **Early Context Injection:** The `global_context_vector` from the Global Stream is **concatenated** to the input vector of *every* atom. This structural change allows the Atomic Encoder to learn context-dependent potential energy surfaces (e.g., how an Al-O bond behaves differently under high lattice strain) (**Cite Lesson 2**).
    *   **Encoder:** A **Wide MLP** (projecting to 512 dimensions) processes these augmented atomic vectors. The network depth is kept moderate, but the width is maximized to prevent information bottlenecks (**Cite Lesson 6, Lesson 17**). The final layer of this encoder uses a **Linear** activation to preserve the full vector space for pooling (**Cite Lesson 18**).

3.  **Attention-Based Aggregation:**
    *   Instead of simple Mean Pooling, employ **Attention-Weighted Mean Pooling**. A learnable query vector computes a scalar attention score for each atom, normalized via Softmax. This allows the model to dynamically weight atoms based on their chemical importance (e.g., prioritizing surface or defect-like sites) before averaging.
    *   This is concatenated with **Global Max Pooling** to retain the signal of salient features (**Cite Lesson 5**). Sum pooling is explicitly excluded to maintain robustness for intensive targets (**Cite Lesson 7**).

4.  **Prediction Head:**
    *   The aggregated atomic embedding is passed through a final regressor MLP to predict `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files. Center atomic coordinates by subtracting the unit cell centroid.
    *   Compute the pairwise distance matrix for all atoms in the unit cell (applying periodic boundary conditions is ideal, but using the provided Cartesian coordinates is sufficient given the success of Lesson 15).
    *   For each atom, extract the distances to the nearest $K$ neighbors, sort them in ascending order, and append them to the atomic feature vector.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters and calculate derived features: Unit Cell Volume and Atomic Density.
    *   Standardize all continuous features (z-score normalization).
3.  **Target Transformation:**
    *   Apply `log(1+y)` transformation to both target variables to align the training objective with the RMSLE metric.

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW optimizer with weight decay to regularize the wide latent projections.
*   **Scheduler:** `ReduceLROnPlateau` to adapt the learning rate based on validation performance.
*   **Strategy:** Train for a fixed epoch count (e.g., 150-200) with early stopping.

### Evaluation
1.  **Inference:** Process the test set using the same pipeline (centering, K-NN fingerprint generation, scaling). Pass the data through the trained model.
2.  **Inverse Transformation:** Apply `exp(x) - 1` to the model predictions to recover the original energy scale.
3.  **Submission:** Format the output into the required CSV format.
