The `ValueError: zero-size array to reduction operation minimum which has no identity` is caused by attempting to calculate the minimum neighbor distance on an empty distance matrix, which occurs when a crystal structure file contains no atoms. Additionally, calculating centroids (mean) on empty coordinate arrays in the feature extractor will raise runtime warnings or errors.

I will fix this by:
1.  Modifying `library/geometry.py` to explicitly check for empty distance matrices in `compute_local_potential` and return empty arrays instead of performing reduction operations.
2.  Modifying `library/features.py` to check if coordinate arrays are empty before calculating centroids in `process_data`.
3.  Modifying `library/features.py` to handle the case where the concatenated atomic features array is empty in `DataScaler.fit`.
