Implementation of the orchestration script `runfile.py`.

This script orchestrates the full pipeline:
1.  **Training**: Trains the Hybrid-Coordinate Potential Deep Sets (HCP-DS) model using the provided trainer library. It sets the epoch count to 100 to ensure fast execution while allowing convergence.
2.  **Validation**: Loads the hold-out validation set, computes predictions, and calculates the **Column-wise Root Mean Squared Logarithmic Error (RMSLE)**. Since the model is trained on `log1p` targets, the RMSLE is calculated directly as the RMSE of the model outputs vs. transformed targets.
3.  **Failure Analysis**: Calculates the correlation between the model's prediction error (MAE in log space) and the global input features (lattice parameters, stoichiometry, density) to identify sources of error.
4.  **Submission**: Checks if the validation metric is below the specified threshold (0.05479004207787702). If successful, it generates the `submission.csv` file for the test set.
