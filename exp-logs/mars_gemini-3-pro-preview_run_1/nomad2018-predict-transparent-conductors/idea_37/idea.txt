Based on the comprehensive analysis of the previous experiments and the extracted lessons, I propose the **Dual-Shell Geometric Wide Deep Sets (DSG-WDS)** strategy.

This strategy represents a structural evolution of the successful "Augmented Point-Cloud Deep Sets" (Idea 4). It refines the local feature engineering by resolving the local environment into two distinct "shells": the **Bonding Shell** (nearest neighbor) and the **Coordination Shell** (neighbors 2-5). This addresses the limitation of using a single distance scalar (which cannot distinguish between different packing geometries like tetrahedral vs. octahedral) without incurring the penalties of high-dimensional fingerprints (Lesson 21) or smoothed density fields (Lesson 77). Crucially, the architecture rigorously enforces the **Wide MLP**, **Batch Normalization**, **Dropout**, and **System Cardinality** safeguards identified as essential for stability and generalization in Lessons 17, 24, 35, and 36.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Dual-Shell Point Processor):**
    *   **Input Features:** For each atom, construct a dense, compact feature vector (9 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains critical node-level spatial variance (**Cite Lesson 10**).
        *   **Bonding Shell Distance ($d_{bond}$):** The scalar distance to the single closest neighbor (PBC-corrected). This captures the immediate bond constraint and steric repulsion (**Cite Lesson 15**).
        *   **Coordination Shell Distance ($d_{coord}$):** The arithmetic mean of the distances to the $2^{nd}$ through $5^{th}$ nearest neighbors (PBC-corrected). This provides a robust scalar proxy for the local coordination geometry and packing efficiency, distinguishing between structures with similar bond lengths but different packing densities, while adhering to parsimony (**Cite Lesson 21**).
    *   **Encoder:** A **Wide MLP** (e.g., 3 layers of 512 hidden units) to project these features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation. This is essential to handle the heterogeneous scales of the inputs and prevent overfitting in the wide layers.
    *   **Output:** A **Linear** projection (no activation) to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) to capture both average properties and salient structural features (**Cite Lesson 5**). Sum pooling is excluded (**Cite Lesson 7**).

2.  **Global Stream (Thermodynamic Context):**
    *   **Input:** Macroscopic features: Lattice vector lengths, lattice angles, unit cell volume, atomic density, **explicit stoichiometry** (**Cite Lesson 13**), and the **Total Number of Atoms** (**Cite Lesson 35**).
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout to model non-linear boundary condition effects (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Neighbor Search:** Compute the pairwise distance matrix using lattice vectors to respect Periodic Boundary Conditions.
    *   **Feature Extraction:** For each atom, sort the neighbor distances.
        *   $d_{bond} = d_1$ (1st nearest neighbor).
        *   $d_{coord} = \text{mean}(d_2, d_3, d_4, d_5)$.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, and **Total Atoms**.
    *   Calculate Unit Cell Volume and Atomic Density.
    *   **Scaling:** Apply Standard Scaling (z-score) to all continuous features (atomic coords, shell distances, global features) to ensure balanced gradients.
3.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$) to regularize the wide layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence over a longer schedule (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-Shell calculation, Scaling).
2.  **Prediction:** Pass the processed data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs to recover the original energy scale.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
