The `TypeError: ReduceLROnPlateau.__init__() got an unexpected keyword argument 'verbose'` is caused by the `verbose` argument being passed to the scheduler, which has been deprecated and removed in newer PyTorch versions. I will remove this argument from the scheduler initialization in both `library/architecture.py` and `runfile.py`. Additionally, I will add a check for empty atomic positions in `library/dataset.py` to prevent the `RuntimeWarning: invalid value encountered in scalar divide` that occurs when calculating the centroid of an empty set of atoms.
