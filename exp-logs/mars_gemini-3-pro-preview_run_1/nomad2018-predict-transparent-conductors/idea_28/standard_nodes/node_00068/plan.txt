Implementation Strategy:
1.  **Setup**: Initialize the environment, set random seeds for reproducibility, and determine the computation device (GPU/CPU).
2.  **Model Training**: Execute the training pipeline using the provided `run_training` function. This will process the data, train the `HCCRDSModel` (Wide MLP with chemical features), and save the best checkpoint based on validation loss.
3.  **Validation**:
    *   Load the validation dataset using the cached data loader.
    *   Perform inference on the validation set to obtain predictions (log-transformed).
    *   Calculate the **Column-wise Root Mean Squared Logarithmic Error (RMSLE)**. Since the model predicts log-transformed values, this is equivalent to the RMSE of the model outputs vs. transformed targets.
    *   Print the final validation metric with full precision.
4.  **Failure Analysis**:
    *   Calculate the prediction error for each validation sample.
    *   Correlate these errors with the global input features (lattice parameters, volume, density, composition) to identify which properties are most strongly associated with model failure.
    *   Print the top correlations.
5.  **Submission**:
    *   Compare the final validation metric against the threshold (0.05479).
    *   If the model performance is sufficient, generate the submission file using the `generate_submission` function, which handles inference on the test set and the inverse transformation of the targets.
