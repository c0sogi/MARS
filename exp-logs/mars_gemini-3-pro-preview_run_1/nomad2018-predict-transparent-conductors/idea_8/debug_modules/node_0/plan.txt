The following Python script demonstrates how to instantiate and utilize the classes and functions from the provided library files (`config.py`, `utils.py`, `data_loader.py`, `model.py`, `trainer.py`).

The script performs the following steps:
1.  **Setup**: Imports necessary modules and sets random seeds for reproducibility.
2.  **Data Subsetting**: Creates a small subset of the training, validation, and test metadata (20, 10, and 10 samples respectively) to ensure the demonstration runs quickly.
3.  **Configuration Override**: Overrides default parameters in `Config` (such as paths, batch size, and number of epochs) to use the demo data and limit runtime.
4.  **Data Loading**: Uses `get_dataloaders` to process the raw data subset and create PyTorch DataLoaders. It verifies the structure and shapes of the loaded batches.
5.  **Model Verification**: Instantiates the `SIRDS_SP` model and performs a forward pass with a batch of data to verify output shapes.
6.  **Training**: Instantiates the `Trainer` and runs the training loop (`fit`) for 2 epochs.
7.  **Prediction**: Runs the prediction pipeline (`predict`) on the test set and verifies the generated submission file format.
