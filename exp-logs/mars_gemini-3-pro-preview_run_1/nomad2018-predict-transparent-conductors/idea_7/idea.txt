Based on the comprehensive analysis of previous experiments, I propose the **Symmetry-Informed Residual Deep Sets (SI-RDS)** strategy. This approach evolves the successful AP-DeepSets architecture (Idea 4) by upgrading the atomic encoder to a Residual network, enriching the aggregation mechanism with statistical variance, and explicitly modeling crystallographic symmetry, while strictly adhering to the regularization and feature engineering principles identified in the lessons.

### Model
The architecture consists of three converging streams that process local, global, and symmetry information:

1.  **Atomic Stream (Residual Point Processor):**
    *   **Input:** A compact feature vector for each atom: **One-hot encoding** of the element (Al, Ga, In, O), **Centered Cartesian coordinates** (Cite Lesson 10), and the **PBC-corrected Nearest Neighbor Distance** (Cite Lesson 15). Note that physical constants are excluded to avoid redundancy (Cite Lesson 23).
    *   **Backbone:** A **Wide Residual MLP** consisting of stacked Residual Blocks (Linear $\to$ BN $\to$ ReLU $\to$ Dropout $\to$ Linear $\to$ BN $\to$ Add Input $\to$ ReLU). This structural innovation allows the model to learn deeper, more complex non-linear transformations of the local geometry without suffering from gradient degradation, unlike the standard MLPs used in previous ideas.
    *   **Regularization:** **Dropout** is included within the blocks to prevent overfitting to specific geometric configurations (Cite Lesson 24).
    *   **Aggregation (Tri-Pooling):** The atomic embeddings are aggregated into a global vector using **Mean**, **Max**, and **Standard Deviation** pooling. While Mean and Max capture average properties and salient features (Cite Lesson 5), the novel addition of **Std Dev pooling** explicitly encodes the *variance* or heterogeneity of local atomic environments (e.g., distortion), which is critical for energy prediction.

2.  **Global Stream (Thermodynamic Context):**
    *   **Input:** Macroscopic features: Lattice vector lengths, lattice angles, unit cell volume, atomic density, and **explicit stoichiometry** (Cite Lesson 13).
    *   **Backbone:** A high-capacity MLP to process these boundary conditions (Cite Lesson 9).

3.  **Symmetry Stream (New):**
    *   **Input:** The Spacegroup ID (integer).
    *   **Backbone:** A learnable **Embedding Layer** that maps the discrete spacegroup label to a continuous vector space. This injects high-level crystallographic constraints that are difficult for the model to infer solely from raw coordinates, providing a strong prior for the energy potential surface.

4.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the Tri-Pooled atomic vector, the Global embedding, and the Symmetry embedding (Cite Lesson 19).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   Center atomic coordinates by subtracting the unit cell centroid.
    *   Compute the **PBC-aware pairwise distance matrix** using the lattice vectors to strictly respect periodic boundary conditions. Extract the minimum distance for each atom as the "Nearest Neighbor" feature.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters and stoichiometry.
    *   Calculate derived features: Unit Cell Volume and Atomic Density.
    *   Extract Spacegroup ID.
    *   Apply **Standard Scaling** to all continuous features (atomic and global) to ensure stable gradients.
3.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for a fixed number of epochs (e.g., 150) with early stopping.

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (centering, PBC-neighbor calc, scaling).
2.  **Prediction:** Pass the processed data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs to recover the original energy scale.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
