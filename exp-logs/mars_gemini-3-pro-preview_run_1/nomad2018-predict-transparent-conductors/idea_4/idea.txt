Based on the comprehensive analysis of previous experiments, I propose the **Augmented Point-Cloud Deep Sets (AP-DeepSets)** strategy. This approach evolves the successful Lattice-Conditioned Deep Sets baseline by enriching the atomic feature representation with invariant local structural scalars and employing robust aggregation and global conditioning techniques identified in the lessons.

### Model
The architecture consists of two parallel processing streams that merge for the final regression:

1.  **Atomic Stream (Feature-Augmented Point Cloud):**
    *   **Input:** For each atom in the unit cell, construct a feature vector containing:
        *   **Atomic Identity:** One-hot encoding of the element type (Al, Ga, In, O).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains the critical node-level spatial information **(Cite Lesson 10)**.
        *   **Local Density Proxy:** The scalar Euclidean distance to the *nearest neighbor* atom. This adds a rotationally and translationally invariant structural feature that captures local atomic crowding without the computational cost or overfitting risks of dense pairwise interaction graphs **(Cite Lesson 8)**.
    *   **Encoder:** Pass this composite vector through a **Wide Multi-Layer Perceptron (MLP)** that projects the input immediately to a high-dimensional latent space (e.g., 256 units). This ensures the low-dimensional atomic features are sufficiently disentangled before pooling **(Cite Lesson 6)**.
    *   **Aggregation:** Apply **Dual Pooling** by concatenating the **Global Mean** and **Global Max** of the encoded atomic vectors. This captures both the average distribution of properties and the presence of specific structural features **(Cite Lesson 5)**, while explicitly avoiding Sum pooling to maintain robustness for intensive targets **(Cite Lesson 7)**.

2.  **Global Stream (Explicit Context):**
    *   **Input:** A vector of macroscopic properties: lattice vector lengths, lattice angles, total number of atoms, and **explicit composition percentages** (stoichiometry). Retaining explicit stoichiometry is crucial for composition-dependent properties like bandgap **(Cite Lesson 13)**.
    *   **Encoder:** A **High-Capacity MLP** (e.g., 3 layers, 128+ units) to process these features. This ensures the model has sufficient capacity to resolve energy variations driven by boundary conditions, treating global features as primary drivers rather than simple conditioning tags **(Cite Lesson 9)**.

3.  **Fusion and Prediction:**
    *   Concatenate the aggregated atomic embedding and the encoded global embedding.
    *   Pass the combined vector through a final regressor MLP to predict `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Processing:**
    *   Parse `geometry.xyz` files to extract atomic positions and types.
    *   Calculate the geometric centroid of the unit cell and subtract it from all atomic coordinates to center them.
    *   Compute the **Nearest Neighbor Distance** for each atom. This is done by calculating the pairwise distance matrix (applying periodic boundary conditions using the lattice vectors if possible, or using the provided Cartesian coordinates as a sufficient approximation for local density in these unit cells) and taking the minimum non-zero distance for each row.
2.  **Tabular Processing:**
    *   Extract lattice vectors, angles, and composition percentages from the CSV files.
    *   Calculate derived global features: **Unit Cell Volume** and **Atomic Density** (Total Atoms / Volume) to provide the global branch with explicit density signals.
    *   Apply standard scaling (z-score normalization) to all continuous features.
3.  **Target Transformation:**
    *   Apply a `log(1+y)` transformation to both `formation_energy_ev_natom` and `bandgap_energy_ev`. This aligns the training loss (MSE) with the competition metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW optimizer with weight decay to regularize the wide projection layers.
*   **Scheduler:** `ReduceLROnPlateau` to dynamically adjust the learning rate when validation performance plateaus.
*   **Strategy:** Train for a fixed number of epochs (e.g., 150) with early stopping monitoring the validation loss.

### Evaluation
1.  **Inference:** Process the test set using the same pipeline (geometry centering, neighbor distance calculation, tabular scaling). Pass the data through the trained model.
2.  **Inverse Transformation:** Apply the exponential function `exp(x) - 1` to the model predictions to convert them back to the original energy scale.
3.  **Submission:** Generate the submission file in the specified format (`id,formation_energy_ev_natom,bandgap_energy_ev`).
