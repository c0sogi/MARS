Based on the analysis of the previous experiments and the extracted lessons, I propose the **Multi-Scale Context Wide Deep Sets (MSC-WDS)** strategy.

This strategy represents a structural evolution of the successful **Soft-Chemical Context Wide Deep Sets** (Idea 39). It refines the feature engineering by resolving the local chemical environment into **multiple radial scales** (Short-Range vs. Medium-Range). This allows the model to distinguish between immediate bonding chemistry (e.g., first coordination shell) and the broader crystal field, providing a richer, continuous description of the local environment. Crucially, it incorporates the **Sparse Batching** technique (Lesson 89) to correct the normalization errors that caused Idea 40 to fail, and strictly enforces the **Wide MLP**, **Batch Normalization**, and **Dropout** safeguards (Lessons 17, 24, 36).

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Multi-Scale Point Processor):**
    *   **Input Features:** For each atom, construct a dense feature vector (16 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains critical node-level spatial variance (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance:** The scalar distance to the single closest neighbor (PBC-corrected), providing a sharp proxy for steric constraints (**Cite Lesson 15, Lesson 77**).
        *   **Short-Range Chemical Context ($C_{short}$):** A 4-dimensional vector representing the **Inverse-Distance Weighted Composition** of the **$K=6$** nearest neighbors. This captures the immediate coordination geometry (e.g., tetrahedral vs. octahedral bonding partners).
        *   **Medium-Range Chemical Context ($C_{med}$):** A 4-dimensional vector representing the **Inverse-Distance Weighted Composition** of the **$K=24$** nearest neighbors. This captures the broader local stoichiometry and crystal field environment.
        *   *Note:* Both context vectors are normalized to sum to 1.0, ensuring they encode *identity* rather than density, which is handled by the NN distance (**Cite Lesson 86**).
    *   **Encoder:** A **Wide MLP** (e.g., 3 layers of 512 hidden units) to project these features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation. This is critical to handle the heterogeneous scales of the inputs and prevent overfitting.
    *   **Output:** A **Linear** projection (no activation) to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) to capture both average properties and salient features (**Cite Lesson 5**). Sum pooling is excluded (**Cite Lesson 7**).

2.  **Global Stream (Thermodynamic Context):**
    *   **Input:** Macroscopic features: Lattice vector lengths, lattice angles, unit cell volume, atomic density, **explicit stoichiometry** (**Cite Lesson 13**), and the **Total Number of Atoms** (**Cite Lesson 35**).
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout to model non-linear boundary condition effects (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Neighbor Search:** Compute the pairwise distance matrix using lattice vectors to respect Periodic Boundary Conditions.
    *   **Feature Extraction:**
        *   Extract the minimum non-zero distance (NN Dist).
        *   Identify the $K=6$ and $K=24$ nearest neighbors.
        *   Compute the **Weighted Context Vectors** for both scales: Sum the one-hot vectors of neighbors weighted by $1/d$, then normalize.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, and **Total Atoms**.
    *   Calculate Unit Cell Volume and Atomic Density.
    *   **Scaling:** Apply Standard Scaling (z-score) to all continuous features (atomic coords, NN dist, context vectors, global features).
3.  **Batching Strategy:**
    *   Use **Sparse (Flattened) Batching**: Concatenate all atoms from a batch of crystals into a single large tensor `[Total_Batch_Atoms, Features]` and use an index vector to track crystal assignment. **Do not use padding**, as this corrupts Batch Normalization statistics (**Cite Lesson 89**).
4.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$) to regularize the wide layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence over a longer schedule (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-MultiScale-Context calculation, Scaling).
2.  **Prediction:** Pass the processed data through the trained model using sparse batching.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs to recover the original energy scale.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
