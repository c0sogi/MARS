This script implements the **Density-Calibrated Chemically-Contextualized Wide Deep Sets (DC3-WDS)** strategy. It orchestrates the entire machine learning workflow, including data loading, model training, validation assessment, failure analysis, and conditional submission generation.

The script utilizes the provided library modules (`config`, `data_loader`, `model`, `trainer`, `inference`) to ensure modularity and adherence to the specified architecture. It overrides the default epoch count to 100 to ensure a fast baseline execution while maintaining sufficient convergence.
