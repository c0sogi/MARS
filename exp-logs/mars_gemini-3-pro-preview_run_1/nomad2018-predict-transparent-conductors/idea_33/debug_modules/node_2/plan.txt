The issue is that `Config.BEST_MODEL_PATH` is a static class attribute initialized at import time using the original `Config.WORKING_DIR`. When `runfile.py` updates `Config.WORKING_DIR` to a new demo directory, `Config.BEST_MODEL_PATH` retains the old path pointing to a non-existent directory, causing `torch.save` to fail.
