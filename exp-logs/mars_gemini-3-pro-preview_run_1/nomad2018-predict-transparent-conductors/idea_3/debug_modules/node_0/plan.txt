This script demonstrates the end-to-end usage of the provided library modules for the material property prediction task. It covers configuration setup, feature extraction, dataset loading, model instantiation, training, and inference.

The script performs the following steps:
1.  **Configuration**: Overrides default hyperparameters (epochs, batch size) to ensure quick execution for demonstration purposes.
2.  **Feature Engineering**: Demonstrates how `process_dataset` extracts atomic and lattice features from raw metadata and XYZ files, verifying the shapes of the generated features.
3.  **Data Loading**: Initializes `MaterialsDataset` and a `DataLoader` with the custom `collate_fn`, verifying the structure of the batched tensors.
4.  **Model Initialization**: Instantiates the `RBFDualStreamDeepSets` model and performs a forward pass with a sample batch to verify input/output dimensions.
5.  **Training**: Runs a shortened training loop using `train_model` to demonstrate the optimization process and model checkpointing.
6.  **Inference**: Generates predictions on the test set using `generate_submission` and verifies the output file format.
