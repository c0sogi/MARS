Based on the lessons learned from the previous experiments, I propose the **RBF-Augmented Dual-Stream Deep Sets** strategy. This approach evolves the successful Lattice-Conditioned Deep Sets (LCDS) baseline by enhancing the atomic feature representation with rotationally invariant spatial encodings and improving the aggregation mechanism, while strictly adhering to the architectural constraints identified in the lessons.

### Model
The architecture consists of two parallel streams that converge for the final regression:

1.  **Atomic Stream (Enhanced Deep Sets):**
    *   **Input Features:** For every atom $i$ in the unit cell, construct a feature vector containing:
        *   **Atomic Type:** One-hot encoding (Al, Ga, In, O).
        *   **Centered Coordinates:** Cartesian coordinates $(x, y, z)$ shifted so the centroid is at the origin. This explicitly retains the spatial node-level features found to be critical **(Cite Lesson 10)**.
        *   **Radial Embedding:** The Euclidean distance $r_i$ of the atom from the centroid, expanded using a bank of **Gaussian Radial Basis Functions (RBFs)**. This adds a rotationally invariant spatial signal and handles non-linearities in spatial positioning better than raw scalar distances, avoiding the optimization difficulties of dense pairwise maps **(Cite Lesson 8)**.
    *   **Encoder:** Pass this composite vector through a **Wide MLP** (e.g., projecting immediately to 256 or 512 dimensions). This ensures the low-dimensional input is mapped to a sufficiently rich latent space before pooling **(Cite Lesson 6)**.
    *   **Aggregation:** Apply **Dual Pooling** by concatenating the **Global Mean** and **Global Max** of the atomic vectors. This captures both the intensity and presence of chemical/structural features **(Cite Lesson 5)**. **Sum pooling is explicitly excluded** to maintain robustness for intensive targets **(Cite Lesson 7)**.

2.  **Lattice Stream (Global Context):**
    *   **Input:** Macroscopic features: lattice vector lengths, lattice angles, and total atom count.
    *   **Encoder:** A **High-Capacity MLP** (e.g., 3-4 layers, 128+ units wide). This branch is treated as a primary feature extractor rather than a simple conditioning vector, ensuring the model can resolve energy variations driven by boundary conditions **(Cite Lesson 9)**.

3.  **Fusion:**
    *   Concatenate the outputs of the Atomic Stream (aggregated) and the Lattice Stream.
    *   Pass the combined vector through a final Regressor MLP to predict `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Processing:**
    *   Parse `geometry.xyz` files. Calculate the geometric centroid of the atoms.
    *   Compute centered coordinates: $pos_i = pos_i - centroid$.
    *   Compute radial distances: $r_i = ||pos_i||_2$.
    *   Generate RBF features: Create a fixed set of Gaussian centers $\mu_k$ (e.g., 0 to 10 Å) and compute $\exp(-\gamma (r_i - \mu_k)^2)$.
2.  **Tabular Processing:**
    *   Standardize lattice vectors and angles (z-score normalization).
    *   One-hot encode atomic types.
3.  **Target Transformation:**
    *   Apply a `log(1+y)` transformation to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay to prevent overfitting on the high-dimensional projections.
*   **Scheduler:** Use a `ReduceLROnPlateau` scheduler to adapt the learning rate.
*   **Strategy:** Train for a fixed epoch count (e.g., 150) with early stopping based on validation RMSLE.

### Evaluation
1.  **Inference:** Run the trained model on the preprocessed test set.
2.  **Inverse Transformation:** Apply `exp(x) - 1` to the model predictions to return them to the original energy scale.
3.  **Submission:** Format the output into the required `id,formation_energy_ev_natom,bandgap_energy_ev` CSV format.
