Based on the lessons learned from the previous experiments, I propose the **Chemically-Weighted Wide Deep Sets (CW-DS)** strategy.

This strategy structurally evolves the "Augmented Point-Cloud Deep Sets" (Idea 4) by resolving the "Interaction Blindness" of the atomic encoder. It introduces **Inverse-Distance Weighted Chemical Counts (IDW-CC)** to capture the local chemical environment (e.g., distinguishing an atom surrounded by Oxygen vs. Indium) without the sparsity issues of placeholder values (Lesson 58) or the discontinuities of categorical ranking (Lesson 64). Furthermore, it rigorously enforces the architectural safeguards—**Wide MLPs**, **Batch Normalization**, **Dropout**, and **Explicit System Cardinality**—that have been identified as critical for stability and generalization in Lessons 17, 24, 35, and 36.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Chemically-Aware Point Processor):**
    *   **Input Features:** For each atom, construct a dense, compact feature vector (12 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains critical node-level spatial variance (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance:** The scalar distance to the single closest neighbor (PBC-corrected), providing a high-signal steric constraint (**Cite Lesson 15**).
        *   **Local Chemical Density (IDW-CC):** A 4-dimensional vector $[v_{Al}, v_{Ga}, v_{In}, v_{O}]$. Each component represents the aggregate proximity of that specific element type within the local neighborhood. It is calculated as the sum of inverse distances ($1/d_{ij}$) to the $K=12$ nearest neighbors of that type. If a species is absent in the neighborhood, the value is naturally 0. This provides a continuous, dense signal of the local chemical potential (**Cite Lesson 21, Lesson 58**).
    *   **Encoder:** A **Wide MLP** (e.g., 512 hidden units) to project features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation. This is essential to handle the heterogeneous scales of the inputs (one-hot vs. coords vs. inverse distances) and prevent overfitting in the wide layers.
    *   **Output:** A **Linear** projection (no activation) to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) to capture both average properties and salient features (**Cite Lesson 5**). Sum pooling is explicitly excluded to maintain intensivity (**Cite Lesson 7**).

2.  **Global Stream (Thermodynamic Context):**
    *   **Input:** Macroscopic features: Lattice vector lengths, lattice angles, unit cell volume, atomic density, **explicit stoichiometry** (**Cite Lesson 13**), and the **Total Number of Atoms** (**Cite Lesson 35**).
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout to model non-linear boundary condition effects (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Neighbor Search:** Compute the pairwise distance matrix using lattice vectors to respect Periodic Boundary Conditions. Identify the 12 nearest neighbors for each atom.
    *   **Feature Extraction:**
        *   Extract the minimum distance (NN Dist).
        *   Compute the **IDW-CC vector**: For each atom, sum the inverse distances ($1/d$) of its 12 nearest neighbors, grouping the sums by the neighbor's element type.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, and **Total Atoms**.
    *   Calculate Unit Cell Volume and Atomic Density.
    *   **Scaling:** Apply Standard Scaling (z-score) to all continuous features (atomic coords, NN dist, IDW-CC vector, global features).
3.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$) to regularize the wide layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence over a longer schedule (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-IDW-CC calculation, Scaling).
2.  **Prediction:** Pass the processed data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs to recover the original energy scale.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
