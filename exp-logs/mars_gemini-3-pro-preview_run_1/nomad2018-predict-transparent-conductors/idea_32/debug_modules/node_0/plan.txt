This script demonstrates the usage of the provided library modules (`config`, `utils`, `data`, `model`, `train`) to parse atomic geometry data, create datasets, train a Chemically-Weighted Deep Sets model, and generate a submission.

It performs the following steps:
1.  **Configuration**: Overrides default `Config` paths and hyperparameters to use a temporary working directory and run a fast, small-scale demo (2 epochs, small batch size).
2.  **Utils Demo**: Parses a sample `.xyz` file, computes periodic boundary condition distances, and calculates chemical environment features.
3.  **Data Demo**: Initializes the `MaterialDataset` with a small subset of data, verifies feature shapes, and demonstrates batch collation.
4.  **Model Demo**: Instantiates the model and performs a forward pass with the collated batch.
5.  **Training Demo**: Runs the full training pipeline (`train_model`) on the subset, generating scalers and a model checkpoint.
6.  **Submission Demo**: Generates a submission file (`demo_submission.csv`) using the trained model on a subset of the test data.
