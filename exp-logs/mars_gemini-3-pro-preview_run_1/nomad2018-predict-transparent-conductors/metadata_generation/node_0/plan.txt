The implementation strategy is as follows:
1.  **Setup Directories**: Define the input directory (`./input`) and create the metadata directory (`./metadata`) if it doesn't exist.
2.  **Load Data**: Read the `train.csv` and `test.csv` files from the input directory using pandas.
3.  **Generate File Paths**: Add a `file_path` column to both dataframes. The paths will be constructed as `train/{id}/geometry.xyz` and `test/{id}/geometry.xyz` respectively, corresponding to the directory structure provided in the dataset description.
4.  **Split Data**: Split the training dataframe into training and validation sets using `train_test_split` from scikit-learn. A fixed `test_size=0.2` and `random_state=42` will be used to ensure reproducibility and meet the 80:20 split requirement. Random shuffling is enabled.
5.  **Save Metadata**: Save the resulting training, validation, and test dataframes as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
6.  **Validation**:
    *   Load the saved metadata files.
    *   Print summary statistics (number of samples).
    *   Verify that there is no overlap of IDs between training and validation sets.
    *   Verify that the validation split ratio is approximately 20%.
    *   Perform a file existence check on a random sample of 1000 paths (or all if fewer) from each dataset to ensure the `file_path` column points to existing files in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
