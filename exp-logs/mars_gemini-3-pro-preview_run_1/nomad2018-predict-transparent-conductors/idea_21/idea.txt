Based on the comprehensive analysis of previous experiments and the extracted lessons, I propose the **Chemically-Resolved Raw-Distance Deep Sets (CRRD-DS)** strategy.

This strategy represents a structural evolution of the successful "Augmented Point-Cloud Deep Sets" (Idea 4). It addresses the limitation that a single "nearest neighbor distance" ignores chemical identity (e.g., treating an Al-O bond the same as an In-In bond). By resolving this geometric feature into **Chemically-Specific Raw Distances**, we inject explicit bond-constraint information. Crucially, this strategy corrects the implementation flaws of previous attempts by using **Raw Distances** instead of Gaussian kernels (Cite Lesson 47) and strictly enforcing **Batch Normalization** and **System Cardinality** (Cite Lesson 36, Lesson 35).

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Chemically-Aware Point Processor):**
    *   **Input Features:** For each atom, construct a compact feature vector (11 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains critical node-level spatial variance (**Cite Lesson 10**).
        *   **Chemically-Resolved Nearest Neighbors:** A 4-dimensional vector $[d_{Al}, d_{Ga}, d_{In}, d_{O}]$. Each component represents the **raw Euclidean distance** (PBC-corrected) to the nearest atom of that specific element type. If an element type is absent in the crystal, a large constant (e.g., 20.0 Å) is used to represent "infinite" distance. This allows the model to learn specific potential energy curves for different bond pairs without the gradient-squashing issues of kernel transformations (**Cite Lesson 47**) or the sparsity issues of graph convolutions.
    *   **Encoder:** A **Wide MLP** (e.g., 512 hidden units) to project features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (**Cite Lesson 24**) are applied after every ReLU activation. This is essential to handle the heterogeneous scales of the inputs (one-hot vs. coords vs. raw distances) and prevent overfitting in the wide layers.
    *   **Output:** A **Linear** projection (no activation) to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) to capture both average properties and salient features (**Cite Lesson 5**). Sum pooling is excluded (**Cite Lesson 7**).

2.  **Global Stream (Thermodynamic Context):**
    *   **Input:** Macroscopic features: Lattice vector lengths, lattice angles, unit cell volume, atomic density, **explicit stoichiometry** (**Cite Lesson 13**), and the **Total Number of Atoms** (**Cite Lesson 35**).
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout to model non-linear boundary condition effects (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Calculations:** Compute the pairwise distance matrix using lattice vectors to respect Periodic Boundary Conditions.
    *   **Feature Extraction:** For each atom $i$, calculate the minimum distance to any atom of type $T \in \{Al, Ga, In, O\}$. If type $T$ is not present in the unit cell, assign a large placeholder value (20.0).
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, and **Total Atoms**.
    *   Calculate Unit Cell Volume and Atomic Density.
    *   **Scaling:** Apply Standard Scaling (z-score) to all continuous features (atomic coords, chemical distances, global features) to ensure balanced gradients.
3.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$) to regularize the wide layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence over a longer schedule (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-Chemical-Distance calculation, Scaling).
2.  **Prediction:** Pass the processed data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
