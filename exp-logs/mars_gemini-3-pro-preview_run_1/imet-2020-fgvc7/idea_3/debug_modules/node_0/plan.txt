This script demonstrates the usage of the provided library modules for the Artwork Attribute Labeling task. It performs the following steps:

1.  **Configuration**: Sets up the environment and overrides default configuration parameters (e.g., image size, batch size, model architecture) to ensure the demonstration runs quickly on the available hardware.
2.  **Dataset Verification**: Loads a small subset of the training and validation metadata, initializes the `ArtworkDataset` with Albumentations transforms, and verifies data loading, shape consistency, and target formatting.
3.  **Model Verification**: Instantiates the `ArtworkModel` (using a lightweight backbone for speed), performs a forward pass to check output shapes, and verifies the Exponential Moving Average (EMA) utility.
4.  **Training Loop**: Simulates a single training epoch and a validation pass using the `train_one_epoch` and `validate` functions, checking for valid loss computation and gradient updates.
5.  **Metrics**: Validates the F1 score calculation and the threshold search logic using synthetic data to ensure correctness.
