### Implementation Strategy

1.  **Environment Setup**: Initialize the random seeds using the provided `set_seed` utility to ensure reproducibility.
2.  **Configuration Overrides**:
    *   Create a temporary directory `./working/demo_execution` to store demonstration artifacts (metadata subsets, cache files, model checkpoints).
    *   Modify `PathConfig` to point to this new directory and use subset metadata files to drastically reduce runtime.
    *   Modify `TrainConfig` to run for only 1 epoch with a single seed, ensuring the training loop completes quickly.
3.  **Data Preparation**:
    *   Read the original metadata files from `./metadata`.
    *   Create small subsets (e.g., 50 samples) for training, validation, and testing.
    *   Save these subsets to the temporary directory.
4.  **Component Verification (Unit Tests)**:
    *   **Layers**: Instantiate `CoordinateAttention`, `SpecFPN`, and `AttentionPooling` with dummy tensors to verify input/output shapes and logic.
    *   **Model**: Instantiate the full `SpecFPN_CRNN` model, pass a dummy batch, and verify the output shape and value range (probabilities).
5.  **Pipeline Execution**:
    *   **Data Loading**: Use `get_dataloaders` to process the audio files from the subset metadata and generate PyTorch DataLoaders.
    *   **Training**: Execute `fit_model` to train the model on the subset. This demonstrates the training loop, loss calculation (Mixup/BCE), and checkpointing.
    *   **Inference**: Use `generate_submission` to predict on the test subset and generate a submission CSV.
6.  **Final Validation**: Check that the submission file exists and follows the required format.
