The error `AttributeError: 'SelectiveKernelBasic' object has no attribute 'bn2'` occurs because the `CABasicBlock` wrapper assumes the underlying block strictly follows the standard ResNet `BasicBlock` interface (with `bn2` and `act2` attributes). However, the `skresnet18` backbone uses `SelectiveKernelBasic` blocks from `timm`, which encapsulate normalization within the Selective Kernel unit (omitting `bn2`) and may use a shared `act` attribute instead of separate `act1`/`act2`. To fix this, I will update the `forward` method in `library/model.py` to access these attributes conditionally using `hasattr`, falling back to `act` if specific activation attributes are missing. This aligns with the lesson to "Audit the Complete Component Interface When Structural Assumptions Fail" (Cite debug_lesson_11).
