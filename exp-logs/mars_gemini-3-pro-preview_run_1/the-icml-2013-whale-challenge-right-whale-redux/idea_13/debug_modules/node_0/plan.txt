The implementation strategy involves creating a self-contained script that leverages the provided library modules to perform an end-to-end machine learning workflow for Right Whale Detection. 

1.  **Configuration & Setup**: The script initializes the environment by setting random seeds for reproducibility and detecting the available computation device (GPU/CPU). It overrides specific configurations in `library.config.Config`—such as batch size, number of workers, and epochs—to ensure the demonstration runs quickly and efficiently within the time constraints. It also sets up a dedicated working directory (`./working/demo_execution`) to avoid conflicts.

2.  **Data Loading**: The script utilizes `library.data.get_dataloaders` to load the dataset. To optimize for speed, it uses the `debug_size` parameter to load only a small subset (100 samples) of the training, validation, and test data. This validates the data preprocessing pipeline (spectrogram generation, normalization) without the overhead of processing the full dataset. Assertions verify that the data tensors have the correct dimensions (Batch, Channel, Frequency, Time).

3.  **Model Initialization**: It instantiates the `HierarchicalCRNN` model from `library.model` and moves it to the configured device. A dummy forward pass with a batch from the data loader is performed to verify that the model architecture is valid and produces outputs of the expected shape.

4.  **Training**: The script sets up an `AdamW` optimizer and a `ReduceLROnPlateau` scheduler. It then calls `library.engine.train_model` to execute a short training run (2 epochs). This demonstrates the training loop, loss calculation (BCEWithLogitsLoss), backpropagation, and validation metric tracking (AUC).

5.  **Inference & Submission**: After training, the script loads the best model checkpoint saved during the training phase. It runs inference on the test subset, converts the logits to probabilities using the sigmoid function, and generates a submission CSV file. Final assertions confirm the file's existence, correct row count, and valid probability range [0, 1].
