Based on the comprehensive history of experiments and the specific lessons learned, I propose the **Spectrally-Adaptive Hierarchical CA-ResNet-18 CRNN**.

This solution introduces a **Structural Innovation** in the feature aggregation stage: **Adaptive Spectral Pooling with Bottleneck Fusion**. It synthesizes the "Frequency Localization" benefits of Multi-Band Pooling (Lesson 00060) with the "Dimensionality Control" of the Hierarchical approach (Lesson 00057), while strictly adhering to the robust "Time-Preserving" backbone configuration established in previous successes.

### Model

The architecture is a **Convolutional Recurrent Neural Network (CRNN)** designed to preserve spectro-temporal detail while dynamically managing feature dimensionality.

1.  **Backbone: Time-Preserving ResNet-18 with Coordinate Attention**
    *   **Base Architecture**: We retain the **ResNet-18** backbone equipped with **Coordinate Attention (CA)** blocks. This combination is proven to be the most robust feature extractor for this task (Cite solution_lesson_node_00031, solution_lesson_node_00047).
    *   **Time-Preservation**: We strictly maintain **Asymmetric Strides `(2, 1)`** (Frequency, Time) in Layers 3 and 4. Crucially, we **retain standard strides** (downsampling in both dimensions) in Layer 2. This preserves the receptive field hierarchy essential for feature learning (Cite solution_lesson_node_00059).
    *   **Initialization**: Initialize with **ImageNet pre-trained weights**, averaging the first layer to accept 1-channel input (Cite solution_lesson_node_00020).

2.  **Structural Innovation: Adaptive Spectral Pooling & Bottleneck Fusion**
    *   **Motivation**: Previous ideas either pooled globally (losing frequency location) or split manually into bands (creating excessive dimensionality). We propose a generalized, adaptive approach.
    *   **Mechanism**:
        *   **Hierarchical Extraction**: Extract feature maps from **Layer 2**, **Layer 3**, and **Layer 4**.
        *   **Adaptive Spectral Pooling**: Instead of Global Pooling, apply **Adaptive Average Pooling** along the frequency dimension to a fixed number of bins $K$, which decreases as the network deepens (reflecting the inherent spatial compression).
            *   **Layer 2**: Pool to **4 Frequency Bins** (Preserves coarse localization of textures).
            *   **Layer 3**: Pool to **2 Frequency Bins** (Separates high/low frequency semantics).
            *   **Layer 4**: Pool to **1 Frequency Bin** (Standard global abstraction).
        *   **Flatten & Concatenate**: Flatten the frequency bins into the channel dimension and concatenate the sequences. This creates a rich representation where early layers contribute spatially resolved features and deep layers contribute semantic abstractions.
        *   **Bottleneck Fusion**: Pass the concatenated sequence through a **1x1 Convolution** (Bottleneck) to reduce dimensionality (e.g., to 512 channels) followed by a **Squeeze-and-Excitation (SE)** block. This allows the network to learn which spectral bands and hierarchy levels are most important, correcting the overfitting observed in the raw Multi-Band approach (Cite solution_lesson_node_00060).

3.  **Head: Bi-GRU with Attention Pooling**
    *   The fused sequence is fed into a **Bi-Directional GRU** to model the temporal contour (Cite solution_lesson_node_00001).
    *   The sequence is aggregated via **Attention Pooling** to focus on the call segment (Cite Idea 3).

### Data

1.  **Preprocessing**:
    *   **Input Window**: Generate Log-Mel Spectrograms covering the **full 2.0-second duration** of the clip. Do not truncate (Cite solution_lesson_node_00023).
    *   **Channel Format**: Use a **1-channel** input representation (Cite solution_lesson_node_00042).
    *   **Spectrogram Parameters**: Use **128 Mel bins** to ensure sufficient resolution for the adaptive pooling in early layers.

2.  **Augmentation**:
    *   **Mixup**: Apply Mixup ($\alpha=0.4$) to training batches to regularize the model and accelerate convergence (Cite solution_lesson_node_00020).
    *   **SpecAugment**: Apply Frequency and Time Masking.
    *   **Constraint**: Strictly limit the **Time Mask width to a maximum of 200ms** (approx. 20 frames) to avoid occluding the short whale call (Cite solution_lesson_node_00011).

### Training

1.  **Loss Function**: Use **Binary Cross-Entropy with Logits Loss**.
    *   **Class Weighting**: Apply a **Positive Class Weight** (e.g., 9.0) to explicitly handle the 1:9 class imbalance. This is superior to Focal Loss for this specific imbalance ratio (Cite solution_lesson_node_00058).
    *   **Target Handling**: Compute loss against the **mixed soft targets** generated by Mixup.

2.  **Optimizer**: Use **Adam** with a standard learning rate.

3.  **Scheduler**: Implement **ReduceLROnPlateau** to decay the learning rate when Validation AUC stagnates (Cite solution_lesson_node_00006).

4.  **Metric Validity**: Monitor **Validation AUC** on unmixed data. Do not rely on training metrics computed against hard labels during Mixup (Cite solution_lesson_node_00022).

### Evaluation

1.  **Inference**: Process test clips into 2.0s Log-Mel Spectrograms (128 bins).
2.  **Prediction**: Pass inputs through the Spectrally-Adaptive Hierarchical model.
3.  **Output**: Apply a Sigmoid activation to the final output of the Attention Pooling layer to generate the probability `p`.
