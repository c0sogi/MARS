Based on the lessons learned, I propose an optimized solution that evolves the previous **CRNN** approach into a **ResNet-BiGRU-Attention** architecture. This strategy integrates a deeper spectral feature extractor with a more sophisticated temporal aggregation mechanism, while strictly adhering to the data augmentation constraints identified in the failure analysis.

### Model
The architecture is a **Convolutional Recurrent Neural Network (CRNN)** with three distinct stages:

1.  **Deep Spectral Feature Extraction (Innovation)**:
    Instead of the shallow 2-layer CNN used previously, employ a **ResNet-18** backbone as the feature extractor. The ResNet-18 will process the Log-Mel Spectrogram as a single-channel image. This deeper architecture allows the model to capture complex, hierarchical time-frequency patterns (such as specific harmonic stacks and curvature of the up-sweep) that shallow networks miss. We will discard the global pooling and classification layers of the ResNet, retaining the spatial feature map $(C \times T' \times F')$.

2.  **Temporal Context Modeling (Retain)**:
    To leverage the temporal evolution of the signal, we collapse the frequency dimension of the ResNet output (via average pooling) to create a sequence of feature vectors $(T' \times C)$. This sequence is passed to a **Bi-directional GRU** (Cite Lesson 00001, 00003). This preserves the model's ability to analyze the "shape" of the call over time, which was proven robust against noise.

3.  **Attention-Based Aggregation (Innovation)**:
    Replace the Global Max Pooling layer with an **Attention Pooling** mechanism. Instead of simply taking the maximum activation (which can be triggered by a loud noise artifact), the attention layer learns a weight for every time step in the GRU output. This allows the model to compute a weighted sum of the sequence, dynamically focusing on the specific time segment where the whale call occurs and suppressing the contribution of time steps containing only background noise.

### Data
1.  **Preprocessing**:
    Convert all raw audio clips into **Log-Mel Spectrograms** (Cite Lesson 00001). Use parameters consistent with previous successes (e.g., 64 Mel bins, 25ms window).

2.  **Augmentation**:
    Apply **SpecAugment** during training to improve generalization (Cite Lesson 00006). Crucially, enforce the constraint discovered in the calibration lesson: set the **maximum Time Mask width to 200ms** (approx. 20 frames). This ensures that the augmentation does not fully occlude the short transient whale calls, preventing the introduction of label noise (Cite Lesson 00011).

### Training
-   **Loss Function**: Use **Binary Cross-Entropy with Logits Loss**. Apply a fixed **positive class weight** (e.g., 9.0) to counterbalance the dataset's 1:9 imbalance (Cite Lesson 00001).
-   **Optimization**: Use the **Adam** optimizer. Implement a **ReduceLROnPlateau** scheduler to decay the learning rate when the validation AUC plateaus, ensuring convergence to a finer optima (Cite Lesson 00006).
-   **Regularization**: Apply weight decay and dropout within the GRU and Attention layers to prevent overfitting given the increased capacity of the ResNet backbone.

### Evaluation
-   **Inference**: Transform test clips into Log-Mel Spectrograms using the training parameters.
-   **Prediction**: Pass the spectrograms through the ResNet-BiGRU-Attention model. The output of the Attention Pooling layer is fed to a final fully connected layer with a Sigmoid activation to produce the probability score.
