This script demonstrates the end-to-end workflow for the Right Whale Detection task using the provided library modules. It performs the following steps:

1.  **Configuration**: Modifies the global `Config` to reduce the number of epochs for a rapid demonstration while maintaining the batch size. It ensures reproducibility by setting the random seed.
2.  **Data Loading**: Uses the `get_dataloaders` function from `library.dataset`. This leverages the pre-cached numpy arrays in `./working/idea_2` (as indicated in the environment description) to avoid time-consuming audio processing. It verifies the integrity of the loaded batches.
3.  **Model Verification**: Instantiates the `ResNetBiGRUAttention` model and performs a dummy forward pass with a random tensor to confirm the architecture produces the correct output shape `(Batch_Size, 1)`.
4.  **Training**: Initializes the `Trainer` and executes the `fit` method. The training loop runs for the reduced number of epochs, validating against the validation set and saving the best model based on ROC AUC.
5.  **Inference**: Uses the trained model to generate predictions on the test set via the `predict` method.
6.  **Submission Check**: Validates the generated `submission.csv` file, ensuring it contains the correct columns and the expected number of rows corresponding to the test set.
