### Baseline Approach: Bi-directional Recurrent Spectral Network

#### Model
The proposed solution is a **Bi-directional Recurrent Neural Network (RNN)** designed to capture the temporal evolution of frequency patterns. Unlike the 2D CNN (Model 1) which treats the spectrogram as an image, or the 1D CNN (Model 3) which processes raw waveforms, this architecture treats the input as a sequence of spectral frames. This is particularly effective for detecting right whale calls, which are characterized by specific temporal "up-sweep" frequency contours.

*   **Input**: The model accepts a Log-Mel Spectrogram, represented as a sequence of vectors $T \times F$, where $T$ is the number of time steps and $F$ is the number of Mel frequency bins.
*   **Backbone**: The core layer is a **Bi-directional Gated Recurrent Unit (GRU)**. The bi-directional nature allows the model to aggregate context from both the beginning and end of the clip, effectively capturing the shape of the call regardless of its position in the audio. GRUs are chosen over LSTMs for their simplicity and computational efficiency.
*   **Aggregation**: The outputs of the GRU at every time step are aggregated using **Global Max Pooling** across the time dimension. This creates a fixed-size embedding and provides temporal invariance, allowing the model to detect the "strongest" evidence of a whale call anywhere in the 2-second clip.
*   **Classification Head**: The pooled embedding is passed to a single dense linear layer followed by a sigmoid activation function to produce the final probability score.

#### Data
*   **Preprocessing**:
    1.  **Spectrogram Generation**: Convert the raw audio waveforms (sampled at 2 kHz) into Mel-spectrograms. Use a short window size (e.g., 25ms) and hop length (e.g., 10ms) to maintain high temporal resolution, with approximately 64 Mel bands to capture the low-frequency details relevant to whale calls.
    2.  **Log Scaling**: Apply a logarithmic transformation to the Mel-spectrogram magnitudes to match human auditory perception and compress the dynamic range.
    3.  **Normalization**: Standardize the spectrograms (Z-score normalization) using the mean and standard deviation computed from the training set to ensure stable convergence.
    4.  **Fixed Sizing**: Pad or truncate all spectrograms to a fixed number of time steps to allow for efficient batch processing.

#### Training
*   **Loss Function**: Use **Binary Cross-Entropy with Logits Loss**. To address the class imbalance (approx. 10% positive samples), apply a fixed **positive class weight** (e.g., `pos_weight=9.0`) within the loss function to penalize false negatives more heavily.
*   **Optimizer**: Use the **Adam** optimizer with default parameters for its robustness and minimal need for tuning.
*   **Procedure**: Train for a fixed number of epochs with Early Stopping based on validation AUC. No heavy data augmentation (like MixUp or SpecAugment) is used to maintain simplicity and speed.

#### Evaluation
*   **Inference**: For the test set, process audio files into Log-Mel Spectrograms using the same parameters as training.
*   **Prediction**: Pass the batches through the trained network to obtain probability scores.
*   **Submission**: Map the resulting probabilities to their corresponding clip filenames and save to the submission CSV format.
