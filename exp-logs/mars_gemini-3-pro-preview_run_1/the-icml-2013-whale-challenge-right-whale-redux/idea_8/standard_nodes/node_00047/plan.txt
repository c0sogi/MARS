The `ValueError: Object arrays cannot be loaded when allow_pickle=False` occurs because the cached ID arrays (`train_ids.npy`, etc.) contain string data (clip filenames), which NumPy stores as object arrays. Loading object arrays requires explicitly enabling pickle support, which is disabled by default in recent NumPy versions for security. I will update the `np.load` call for the `ids` variable in `library/dataset.py` to set `allow_pickle=True`, resolving the loading issue for the string identifiers.
