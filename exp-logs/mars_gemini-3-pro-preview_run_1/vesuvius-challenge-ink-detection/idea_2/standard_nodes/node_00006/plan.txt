The implementation strategy involves orchestrating the training, validation, and inference pipeline using the provided library modules. 

1.  **Setup**: Initialize the environment using `Config.setup()` and define the computation device (GPU/CPU).
2.  **Data Loading**: Instantiate `InkDataset` for both training and validation. Use `DataLoader` to handle batching, ensuring the validation loader is not shuffled to maintain alignment with metadata for failure analysis.
3.  **Model Initialization**: Load the `InkUNet` model, `BCEWithLogitsLoss` (with positive class weighting), and the `Adam` optimizer.
4.  **Training Loop**: Execute a limited number of epochs (10) to satisfy the "fast baseline" requirement. Inside the loop, use `train_one_epoch` for optimization and `validate` to monitor performance and save the best model checkpoint based on the F0.5 score.
5.  **Failure Analysis & Final Validation**: Load the best model checkpoint. Iterate through the validation set to:
    *   Compute the final F0.5 score using the optimal threshold found during training.
    *   Calculate the Mean Absolute Error (MAE) for each sample.
    *   Correlate the MAE with input metadata (mean intensity, x, y coordinates) to identify error patterns.
6.  **Submission**: Check if the final validation metric exceeds the threshold of 0.41758. If successful, generate the submission file using `generate_submission`.
