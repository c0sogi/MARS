Implementation strategy:
1.  **Configuration Overrides**: Modify the `Config` class attributes at runtime to optimize for speed. Set `EPOCHS` to 1, `BATCH_SIZE` to 2, and `NUM_WORKERS` to 0. Redirect `CHECKPOINT_DIR` to a temporary folder in `./working`.
2.  **Data Optimization**: Create a subset of the test metadata (2 rows) and save it to `./working`. Point `Config.TEST_METADATA_PATH` to this subset to ensure the inference step in the pipeline runs almost instantly.
3.  **Component Verification (Unit Tests)**:
    *   **Utils**: Verify `rle_encode` produces correct run-length strings and `calculate_fbeta` computes the correct score for known inputs.
    *   **Dataset**: Instantiate `InkDataset` with a small limit. Verify that items loaded have the correct shapes for volumes `(Z, H, W)` and labels `(1, H, W)`.
    *   **Model**: Instantiate `InkUNet`. Pass a dummy tensor with reduced spatial dimensions (to save compute) through the model and assert the output shape is correct.
4.  **Pipeline Integration**: Execute `run_training(limit=4, epochs=1)`. This function orchestrates the entire workflow: data loading, model initialization, training loop, validation, and submission generation.
5.  **Output Verification**: Check that `submission.csv` is created and contains the expected columns and rows corresponding to the test fragments.
