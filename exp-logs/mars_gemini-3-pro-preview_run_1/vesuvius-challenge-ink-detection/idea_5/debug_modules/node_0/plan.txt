Implementation Strategy:
1.  **Environment Setup**: Initialize the working environment by importing necessary libraries and the provided custom modules (`library.*`). Set random seeds for reproducibility.
2.  **Utility Verification**: Test `library.utils` functions by creating synthetic data. Verify `rle_encode` against a known binary mask pattern and `fbeta_score` against manually calculated precision/recall scenarios.
3.  **Model Architecture Check**: Instantiate `SFRPNet` from `library.model`. Pass a dummy tensor with the correct 3D volume dimensions through the network to verify the forward pass mechanics and output shape `(Batch, 1, H, W)`.
4.  **Dataset Loading**: Use `library.dataset` to create DataLoaders with a small subset of data (`limit` parameter). Fetch a single batch to verify tensor shapes and key existence (`volume`, `label`).
5.  **Training Pipeline**: Execute a minimal training run using `library.train.run_training` with reduced epochs (1) and a small dataset limit. This validates the training loop, loss calculation, checkpoint saving, and threshold optimization logic.
6.  **Inference Pipeline**: Execute the inference routine using `library.predict.run_inference` to generate predictions using the checkpoint created in the previous step. Verify the generation of the `submission.csv` file and its format.
