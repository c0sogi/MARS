The following script demonstrates the usage of the provided library modules for the Vesuvius Challenge Ink Detection task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We override the default `Config` parameters to use a temporary working directory (`./working/demo_execution`) and reduce hyperparameters (epochs=1, batch_size=2) to ensure the script runs quickly within the time limit.
2.  **Utility Verification**: We validate the metric calculation functions (`rle_encode`, `calculate_fbeta`) with known inputs to ensure correctness.
3.  **Model Architecture**: We instantiate the `FRUNet` model, pass a dummy tensor with the expected shape `(Batch, 65, 512, 512)`, and assert the output shape is correct.
4.  **Dataset Pipeline**: We initialize the `InkDataset` with a small sample limit, retrieve a batch, and verify the tensor shapes and types for volumes, labels, and masks.
5.  **Training Loop**: We execute the `train_model` function restricted to a very small subset of data (4 samples) to demonstrate the training process, loss calculation, and checkpoint saving without consuming excessive time.
6.  **Inference & Submission**: We run `predict_and_encode` using the trained checkpoint on the test set, verifying that a valid `submission.csv` is generated with the correct format.
