The following script demonstrates the usage of the provided library modules for the Vesuvius Challenge ink detection task.

The implementation strategy is as follows:
1.  **Utilities Verification**: Validate the metric calculation (`calculate_fbeta`) and run-length encoding (`rle_encode`) using synthetic data to ensure correctness.
2.  **Model Architecture Check**: Instantiate the `ParallelDilatedCNN` model and perform a forward pass with dummy tensors to verify input/output shapes and memory compatibility.
3.  **Data Subset Preparation**: To ensure the demonstration runs quickly (under 1 hour) and uses minimal resources, we create "mini" versions of the metadata CSV files containing only 2 samples each. We then monkey-patch the file paths in `library.dataset` to point to these mini files.
4.  **Dataset & DataLoader Demo**: Instantiate the `InkDataset` and `DataLoaders` using the mini metadata to verify data loading, shape consistency, and pipeline integration.
5.  **Training Loop Demo**: Execute a single epoch of the training routine (`run_training`) using the mini dataset. This verifies the loss calculation, backpropagation, and checkpoint saving mechanisms.
6.  **Inference Pipeline Demo**: Run the inference routine (`predict_and_submit`) using the trained checkpoint and mini test set. This verifies threshold calibration, patch stitching, and submission file generation.
