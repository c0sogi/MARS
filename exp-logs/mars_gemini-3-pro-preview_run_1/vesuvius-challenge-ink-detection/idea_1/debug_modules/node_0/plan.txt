The following script demonstrates the usage of the provided library files for the Vesuvius Challenge Ink Detection task.

**Implementation Strategy:**
1.  **Setup**: Initialize the environment and set random seeds using `library.utils`.
2.  **Utility Verification**: Validate the `fbeta_score` and `rle_encoding` functions with known inputs to ensure metric correctness.
3.  **Data Pipeline**: Initialize `get_dataloaders` with a strictly limited sample size (`limit_samples=16`) to ensure the preprocessing and loading steps execute quickly. Verify the tensor shapes of the batches.
4.  **Model Architecture**: Instantiate `DepthProjectionCNN`, move it to the configured device, and perform a dummy forward pass to verify input/output dimensions.
5.  **Training Integration**: Execute the high-level `run_training` function with minimal epochs (`epochs=1`) to test the full training loop, validation, and automatic submission generation.
6.  **Inference Module**: Explicitly demonstrate the `library.inference` functions (`predict_fragment`, `generate_submission_file`) using the trained model to verify the standalone inference logic.
7.  **Output Verification**: Confirm that the `submission.csv` file was generated successfully.
