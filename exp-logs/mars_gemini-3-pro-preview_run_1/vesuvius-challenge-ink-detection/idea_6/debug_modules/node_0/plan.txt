The following script demonstrates the complete pipeline for the Vesuvius Challenge ink detection task using the provided library files.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class to use a temporary working directory and reduce hyperparameters (1 epoch, batch size 2) for rapid execution.
2.  **Data Subsetting**: We create "mini" versions of the training, validation, and test metadata files containing only a few samples. This ensures the training and inference loops complete in seconds while still exercising the full data loading and processing logic.
3.  **Component Verification**:
    *   **Utils**: We validate the Run-Length Encoding (`rle_encode`) and F-Beta score (`calculate_fbeta`) functions against known inputs to ensure metric correctness.
    *   **Model**: We instantiate the `FFDCNet` and perform a forward pass with dummy data to verify tensor shapes and architecture integrity.
4.  **Pipeline Execution**:
    *   **Training**: We run `train_model`, which processes the mini-dataset, computes loss, updates weights, and saves the best model checkpoint.
    *   **Inference**: We run `generate_submission`, which loads the trained model, predicts on the mini-test set, reconstructs the fragments, and generates the required `submission.csv`.
5.  **Assertions**: Throughout the script, assertions enforce that files are created, shapes are correct, and logic holds true.
