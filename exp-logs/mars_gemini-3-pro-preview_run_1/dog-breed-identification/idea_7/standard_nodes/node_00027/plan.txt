3.  **Ensemble Training Loop**: Iterate through the two model architectures (ConvNeXt-Base and Swin-Base). For each architecture, perform 5-fold cross-validation.

    *   **Phase 2 (Regularized Fine-Tuning)**: Unfreeze backbone, apply Mixup/CutMix, use discriminative learning rates.

    *   **Phase 4 (SWA)**: Apply Stochastic Weight Averaging to find a robust optimum.
    *   Store the trained models in memory (and save to disk).
4.  **Validation & Ensemble**: Perform inference on the hold-out validation set using all 10 trained models (2 architectures $\times$ 5 folds). Apply Test Time Augmentation (TTA). Average the predictions to form the ensemble prediction. Calculate and print the Multi Class Log Loss.
5.  **Failure Analysis**: Compute the per-sample loss on the validation set. Correlate this loss with image metadata (width, height, aspect ratio) derived from the loaded images to identify error patterns.
6.  **Submission**: If the validation metric meets the specified threshold (< 0.1297), generate predictions for the test set using the full ensemble and save the `submission.csv`.
