Based on the lessons learned from the ResNet-18 experiments, I propose a strategy that evolves the architecture to a modern **ConvNeXt** backbone while adopting a disciplined training regime that balances feature specialization with geometric integrity.

### Model
I propose replacing the ResNet-18 architecture with **ConvNeXt-Tiny**.
- **Architecture:** ConvNeXt modernizes the standard Convolutional Neural Network by incorporating design choices from Vision Transformers (e.g., larger 7x7 kernels, Layer Normalization, and inverted bottlenecks) while retaining the inductive biases of CNNs. This provides a more powerful feature extractor for fine-grained details (like fur texture and snout shape) compared to the older ResNet-18.
- **Head:** The pre-trained classification head will be replaced with a single linear layer mapping the backbone's output to the 120 dog breed classes.

### Data
Data processing will focus on preserving the geometric integrity of the subjects, adhering strictly to the findings regarding fine-grained classification.
- **Preprocessing:** All images (train and test) will be **Resized to 256x256** and then **Center Cropped to 224x224**. This ensures that the aspect ratios of the dogs' features (ears, snouts) remain undistorted, which is critical for breed differentiation.
- **Augmentation:** We will use **only Random Horizontal Flips** for the training set. We will explicitly **exclude** aggressive spatial transformations like `RandomResizedCrop` or rotation, as these have been proven to degrade performance by destroying the precise geometric signals required for this task `Cite solution_lesson_node_00002`.

### Training
The training process will use a **Progressive Fine-Tuning** strategy with **Discriminative Learning Rates** to address the overfitting observed in previous attempts without causing the underfitting seen with heavy regularization.
- **Optimizer & Loss:** We will use **AdamW** to optimize **Cross-Entropy Loss**. We will **avoid Label Smoothing**, as it penalizes the high-confidence predictions required to minimize the Log Loss metric `Cite solution_lesson_node_00004`.
- **Phase 1 (Head Adaptation):** Freeze the entire ConvNeXt backbone and train only the new linear head. This aligns the random weights of the classifier with the pre-trained features `Cite solution_lesson_node_00001`.
- **Phase 2 (Fine-Tuning with Discriminative LR):** Unfreeze the **last stage (Stage 4)** of the backbone along with the head. Crucially, we will apply **Discriminative Learning Rates**: a lower learning rate (e.g., 1e-5) for the backbone layers and a higher learning rate (e.g., 1e-3) for the head. This allows the model to specialize high-level features for dog breeds without "forgetting" the robust generic features learned from ImageNet, thereby mitigating the overfitting seen in the ResNet-18 baseline.
- **Regularization:** We will utilize **Stochastic Depth (DropPath)** (inherent to ConvNeXt) and mild Weight Decay. This provides necessary regularization without the destructive impact of high Dropout rates or pixel-level noise.

### Evaluation
- **Inference:** Predictions will be generated on the test set using the same Resize (256) and Center Crop (224) pipeline.
- **Output:** Raw logits will be passed through a Softmax function to produce the final probability distribution for the submission file.
