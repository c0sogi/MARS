The implementation strategy orchestrates the Dog Breed Classification pipeline by leveraging the provided library modules while maintaining granular control over the training and evaluation process to meet specific task requirements.

1.  **Setup & Initialization**: We initialize the `Trainer` class, which encapsulates the ConvNeXt-Tiny model and device management. We set the random seed for reproducibility.
2.  **Data Loading**: We load the training, validation, and test DataLoaders using `get_dataloaders(load_cached_data=True)` to utilize pre-processed Parquet files for efficiency.
3.  **Two-Phase Training**: We manually implement the training loops to replicate the `fit` logic but with explicit control.
    *   **Phase 1 (Head Adaptation)**: We freeze the backbone and train the classifier head for 3 epochs using `setup_phase(..., "phase1")`.
    *   **Phase 2 (Fine-Tuning)**: We unfreeze the last stage of the backbone and fine-tune with discriminative learning rates for up to 20 epochs. We implement early stopping based on the validation Log Loss and save the best model.
4.  **Final Validation**: We reload the best model weights and compute the final validation metric on the hold-out set, printing it in the required format.
5.  **Failure Analysis**: We perform inference on the validation set to calculate per-sample Cross-Entropy loss (error magnitude). We then extract geometric features (width, height, area, aspect ratio) from the validation images and calculate their correlation with the error magnitude using NumPy to identify systematic weaknesses.
6.  **Conditional Submission**: We compare the final validation metric against the threshold (`0.7155465919038524`). Only if the model performs better (lower loss) do we generate the submission file for the test set.
