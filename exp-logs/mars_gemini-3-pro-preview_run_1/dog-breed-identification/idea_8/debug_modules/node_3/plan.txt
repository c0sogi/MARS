When loading this checkpoint into a standard, unwrapped model architecture (as done in the stacking phase), `load_state_dict` fails because the standard model does not contain this buffer.

To fix this, I will modify `library/stacking.py` to sanitize the state dictionary before loading it. Specifically, I will explicitly filter out the `"n_averaged"` key while iterating through the dictionary to strip prefixes.
