The `RuntimeError` is caused by a key mismatch between the saved model checkpoints and the model architecture instantiated during stacking. The checkpoints were saved using `torch.optim.swa_utils.AveragedModel`, which wraps the base model and prefixes all parameter keys with `module.`. When `Stacker._load_model` creates a standard (unwrapped) model instance, it expects keys without this prefix. To fix this, I will modify `library/stacking.py` to iterate through the loaded state dictionary and strip the `module.` prefix from any keys before loading them into the model.
