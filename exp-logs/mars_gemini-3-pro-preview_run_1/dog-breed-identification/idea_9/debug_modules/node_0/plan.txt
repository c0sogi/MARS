Here is the implementation strategy followed by the complete Python script.

### Implementation Strategy

1.  **Configuration Setup**: Initialize the `Config` class with parameters optimized for speed (e.g., `debug=True`, `epochs=2`, `image_size=64`, `pretrained=False`). This ensures the demonstration runs quickly and uses minimal resources.
2.  **Data Loading & Verification**: Use `load_data` to load a subset of the dataset (limited by the debug flag). Verify the integrity of the returned data dictionary, including shapes of images, IDs, and labels.
3.  **Dataset & DataLoader**: Instantiate `DogDataset` and a PyTorch `DataLoader`. Fetch a single batch to validate the data pipeline, ensuring images are tensors of the correct shape and labels are present.
4.  **Model Initialization**: Create the model using `create_model`. Perform a forward pass with a dummy input to confirm the architecture is valid and produces logits of the expected shape (Batch Size, Num Classes).
5.  **Loss Function Verification**: Instantiate `DistillationLoss`. Test it with two scenarios:
    *   **Hard Labels only**: Standard training scenario.
    *   **Soft Targets (Distillation)**: simulating a student-teacher training step to ensure the KL Divergence component works correctly.
6.  **Training & Evaluation Loop**: Run `train_one_epoch` and `evaluate` on the small data subset. This verifies the integration of the engine, model, and loss function.
7.  **Prediction**: Use the `predict` function on the test set data to ensure the inference pipeline (including Test Time Augmentation logic) functions correctly.
8.  **Cleanup**: The script writes to `./working/demo_execution` to keep the environment organized.
