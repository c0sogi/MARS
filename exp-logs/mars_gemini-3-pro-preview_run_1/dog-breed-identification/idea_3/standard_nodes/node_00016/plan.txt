Implementation Strategy:
1.  **Upgrade Model Architecture**: Switch from `convnext_base.fb_in1k` to `convnext_large.fb_in22k_ft_in1k`. This applies **Lesson 14** (Scaling up the backbone) and leverages superior ImageNet-22k pretraining for better fine-grained feature extraction.
2.  **Adjust Batch Size**: Reduce `BATCH_SIZE` from 32 to 16 to ensure the larger model fits comfortably in GPU memory and to potentially improve generalization via gradient noise.
3.  **Enable Automatic Mixed Precision (AMP)**: Modify `library/engine.py` to use `torch.cuda.amp` (GradScaler and autocast). This optimizes execution speed and memory usage on the A100 GPU, counteracting the computational cost of the larger model.
