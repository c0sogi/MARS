# Idea: Optimized ConvNeXt-Small with Cosine Annealing

Building on the success of the ConvNeXt-Tiny architecture, I propose scaling up the backbone capacity while refining the training dynamics to overcome the optimization plateaus observed in previous experiments.

### Model
I propose upgrading the backbone from ConvNeXt-Tiny to **ConvNeXt-Small**.
- **Architecture:** We will utilize the **ConvNeXt-Small** architecture pre-trained on ImageNet. This model offers a higher parameter count and deeper feature extraction capabilities than the "Tiny" variant, allowing it to capture more complex, fine-grained patterns necessary for distinguishing between 120 dog breeds `Cite solution_lesson_node_00005`.
- **Head:** The classification head will consist of a single linear layer. Crucially, we will include a **Dropout** layer before the final classifier to enforce regularization and prevent the overfitting observed when model capacity increases `Cite solution_lesson_node_00006`.

### Data
We will strictly adhere to a deterministic geometric processing pipeline to preserve breed-specific traits.
- **Preprocessing:** All images will be **Resized to 256x256** and **Center Cropped to 224x224**. We will explicitly avoid aggressive spatial augmentations (like `RandomResizedCrop`), as maintaining the correct aspect ratio is vital for fine-grained classification `Cite solution_lesson_node_00002`.
- **Augmentation:** Training data will only undergo **Random Horizontal Flips**.

### Training
The training strategy will be a **Two-Phase Pipeline** enhanced with a learning rate scheduler to address convergence issues.
- **Loss Function:** We will use standard **Cross-Entropy Loss**, strictly avoiding Label Smoothing to ensure the model can predict high-confidence probabilities required for minimizing Log Loss `Cite solution_lesson_node_00004`.
- **Global Tracking:** We will maintain a single global variable to track the best validation metric across both phases, ensuring we never discard a superior model checkpoint when transitioning between phases `Cite solution_lesson_node_00008`.

**Phase 1: Shortened Head Adaptation**
- **Procedure:** Freeze the backbone and train only the classification head.
- **Duration:** We will limit this phase to a short duration (e.g., 3-4 epochs). This prevents the head from overfitting to the static features ("optimization inertia") and ensures a smoother transition to fine-tuning `Cite solution_lesson_node_00009`.

**Phase 2: Fine-Tuning with Cosine Annealing**
- **Procedure:** Unfreeze the backbone and fine-tune the entire model.
- **Discriminative Learning Rates:** We will apply a very low learning rate to the backbone (e.g., `1e-6`) and a higher rate to the head (e.g., `1e-4`) to adapt the model without destroying pre-trained weights `Cite solution_lesson_node_00006`.
- **Scheduler:** To address the early stopping plateaus observed in previous attempts, we will introduce a **Cosine Annealing Learning Rate Scheduler**. This will dynamically adjust the learning rate, helping the model settle into a deeper local minimum rather than stalling with a constant low learning rate `Cite solution_lesson_node_00010`.

### Evaluation
- **Inference:** Test images will be processed using the same Resize (256) and Center Crop (224) pipeline.
- **Output:** Logits will be converted to probabilities via Softmax.
