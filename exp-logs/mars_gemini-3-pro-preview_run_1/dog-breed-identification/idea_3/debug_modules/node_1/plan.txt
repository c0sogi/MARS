The error `ValueError: y_true and y_prob contain different number of classes` occurs because `sklearn.metrics.log_loss` attempts to infer the class labels solely from the unique values in `y_true`. In the demo execution, the validation subset is small and contains only 14 distinct breeds, whereas the model outputs probabilities for all 120 breeds. This causes a shape mismatch between the inferred classes and the probability matrix. To fix this, I will explicitly pass the `labels` argument (a list of all class indices from 0 to 119) to `utils.calculate_log_loss` in `runfile.py`. This forces the metric to recognize the full label space independent of the specific samples in the batch. Cite debug_lesson_1.
