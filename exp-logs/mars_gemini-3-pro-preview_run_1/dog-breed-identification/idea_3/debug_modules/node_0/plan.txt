To demonstrate the usage of the provided library files while adhering to the constraints (optimizing for speed, verifying logic, and ensuring reproducibility), the following script implements a complete pipeline. It overrides configuration defaults to use small data subsets and minimal training epochs, ensuring the code executes quickly while still exercising all key components.

### Implementation Strategy

1.  **Setup & Imports**: Import the provided library modules (`config`, `utils`, `dataset`, `model`, `engine`) and standard PyTorch/Pandas libraries.
2.  **Reproducibility**: Initialize the random seed using `utils.set_seed`.
3.  **Data Loading**: Load the metadata using `dataset.load_data` and immediately slice the DataFrames to create tiny subsets (32 training, 16 validation, 16 test samples). This ensures the `DataLoader` and `DogDataset` operations are instant.
4.  **Model Initialization**: Build the model using `model.build_model`. We explicitly set `pretrained=False` to avoid any network overhead or errors related to downloading weights in the environment, as we only need to verify the architecture and flow.
5.  **Training Simulation**: Execute `engine.run_training` with `phase1_epochs=1` and `phase2_epochs=1`. This exercises the training loop, validation step, optimizer, scheduler, and checkpoint saving logic without waiting for convergence.
6.  **Inference**: Run `engine.generate_submission` on the test subset to verify the prediction pipeline and output formatting.
7.  **Validation**: Perform assertions on tensor shapes, file existence, and submission column structure to guarantee correctness.
