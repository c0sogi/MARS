The implementation strategy is as follows:
1.  **Setup**: Import necessary libraries (`pandas`, `numpy`, `os`, `sklearn`) and define constants for input/output directories and the random state.
2.  **Data Loading**: Read `train.csv` and `test.csv` from the `./input` directory.
3.  **Path Construction**: Create a new column `file_path` for both datasets. Based on the provided dataset structure, training images are in `jpeg/train/` and test images in `jpeg/test/`. The paths will be relative to `./input`.
4.  **Data Cleaning**: Handle missing `patient_id` values in the training set by filling them with the `image_name` to ensure these samples are treated as distinct groups during splitting.
5.  **Splitting**: 
    *   First, shuffle the training dataframe with `random_state=42` to satisfy the randomization requirement.
    *   Use `StratifiedGroupKFold` with `n_splits=5` (which creates an 80:20 split) to split the training data into training and validation sets. This ensures that patients (groups) do not leak between sets while attempting to maintain class balance.
6.  **Saving**: Save the resulting `train.csv`, `val.csv`, and `test.csv` metadata files to the `./metadata` directory.
7.  **Verification**: 
    *   Reload the saved metadata files.
    *   Print summary statistics (shape, class distribution, unique patients).
    *   Perform a file existence check on 1000 random samples per dataset. If >50% of paths are invalid, raise a `FileNotFoundError`.
    *   Verify the group split by asserting that the intersection of patient IDs in train and validation sets is empty.
