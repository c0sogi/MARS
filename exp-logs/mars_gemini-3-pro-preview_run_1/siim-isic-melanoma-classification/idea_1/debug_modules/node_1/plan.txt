The issue is that the `mobilenet_v3_large` model from `timm` (with `num_classes=0`) includes the final projection layer, resulting in an output dimension of 1280, not 960 as originally configured. The `runfile.py` script hardcoded the expectation of 960 features, causing an assertion error when the actual output (1289 features = 1280 image + 9 tabular) did not match the expected (969 features).

To fix this, I will update `FEATURE_DIM` in `library/config.py` to 1280 and modify `runfile.py` to import and use this constant dynamically instead of the hardcoded value.
