Implementation Strategy:
1.  **Data Loading & Integrity**: The script will load the `train.parquet` file from the `./metadata` directory. This ensures we are using the pre-split training set and avoiding data leakage.
2.  **Target Analysis**:
    - The `annotations` column (JSON string) will be parsed to determine the nature of the answer for each sample.
    - We will define four mutually exclusive classes for the target distribution: `NoAnswer`, `Long` (Long answer only), `Short` (Short answer implies Long answer exists), and `YesNo` (Yes/No answer implies Short and Long exist).
    - We will calculate class balance and the independent probabilities of having a long, short, or yes/no answer.
3.  **Input Data Analysis (Text Modality)**:
    - Due to the massive size of the JSONL file (15GB), we cannot process the entire text content within the time limit.
    - We will perform a robust analysis on a random sample of 5,000 examples using the `byte_offset` from the metadata for efficient random access.
    - For these samples, we will compute:
        - Document length (words/characters).
        - Question length (words/characters).
        - Number of long answer candidates.
        - Vocabulary statistics (unique tokens, singleton/OOV rate) based on the questions in the sample.
4.  **Feature Relationships**:
    - We will treat the extracted text statistics (lengths, counts) as structured meta-features.
    - We will calculate Pearson correlations between these meta-features and the binary target `has_long_answer`.
    - We will train a lightweight Random Forest classifier to predict `has_long_answer` using these meta-features to assess their importance (e.g., does document length predict answerability?).
5.  **Output**: The results will be printed to stdout, formatted with f-strings to 4 decimal places, organized into capitalized sections.
