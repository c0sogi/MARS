The issue is that the `json` library cannot serialize NumPy data types (like `int64` or `float64`) which are used by Scikit-Learn's vectorizers for vocabulary indices and calculated statistics. To fix the `TypeError`, we must explicitly cast these NumPy values to native Python types (`int` and `float`) before serialization. This ensures the data is compatible with `json.dump`.
