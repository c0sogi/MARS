The following script generates the required metadata files `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.

### Implementation Strategy
1.  **Setup and Loading**:
    -   Define paths for input (`./input`) and output (`./metadata`).
    -   Load `train/metadata.json` and `test/metadata.json` using the `json` library. Given the large memory available (220 GB), loading the full JSONs into memory is feasible.

2.  **Processing Training Data**:
    -   Extract image information (ID, file name) and annotations (category ID) from the training metadata.
    -   Merge images and annotations on `image_id` to create a unified dataset.
    -   Construct the relative file path for each image by prepending `train/` to the `file_name` provided in the JSON (which starts with `images/...`).
    -   Ensure `image_id` and `category_id` are integers.

3.  **Splitting Training and Validation**:
    -   Identify "singleton" classes (categories with only 1 sample). These cannot be stratified and must be placed in the training set to ensure the model has seen them.
    -   Perform a stratified 80/20 split on the remaining multi-sample data using `sklearn.model_selection.train_test_split` with `random_state=42`.
    -   Combine the singleton samples with the stratified training split to form the final training set.
    -   The validation set consists of the stratified validation split.

4.  **Processing Test Data**:
    -   Extract image information from the test metadata.
    -   Construct relative file paths by prepending `test/` to the `file_name`.
    -   Ensure `image_id` is an integer to match the submission format.

5.  **Saving Metadata**:
    -   Save the resulting DataFrames to `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.

6.  **Validation and Verification**:
    -   Print summary statistics (count, class distribution summary).
    -   **File Existence Check**: Randomly sample 1000 paths from each generated CSV and verify they exist in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
    -   **Split Verification**: Verify that the validation set is approximately 20% of the stratifiable data and that the class distribution in the validation set roughly mirrors the training set for shared classes.
