The strategy involves a systematic analysis of the training data defined in `./metadata/train.csv`. Given the large size of the dataset (~1.4 million images), processing every image for pixel-level statistics is computationally infeasible within the time limit. Therefore, the strategy relies on robust stratified subsampling for image-specific analysis while performing exact analysis on the tabular metadata (target labels).

1.  **Setup & Data Loading**: Initialize the environment with fixed random seeds. Load the `./metadata/train.csv` file.
2.  **Target Variable Analysis**: Analyze the `category_id` column to determine the number of classes, distribution of samples per class, and the severity of class imbalance (which is expected to be high in herbarium datasets).
3.  **Image Data Analysis (Subsampled)**:
    *   Randomly sample 5,000 images from the training set to ensure the script completes quickly.
    *   Load these images to extract physical properties: dimensions (width, height), aspect ratios, and channel counts.
    *   Calculate global pixel mean and standard deviation (per channel) to inform normalization strategies.
4.  **Feature/Signal Relationships**:
    *   Investigate if there are correlations between image metadata (e.g., image size, aspect ratio) and the target class frequency (e.g., "Do rare species have lower resolution images?").
5.  **Reporting**: Output the findings in the specified format, ensuring all floating-point numbers are formatted to 4 decimal places.
