The implementation strategy follows a two-stage decoupled training pipeline designed to handle the long-tail class distribution of the Herbarium 2021 dataset efficiently within the time constraints.

1.  **Stage 1 (Representation Learning)**: We train the entire **EfficientNet-B0** model using **Square-Root Sampling**. This sampling strategy reduces the extreme imbalance (2000:1) to a milder ratio (~45:1), allowing the model to learn robust features from the frequent classes without completely ignoring the tail. We use a **OneCycleLR** scheduler to converge quickly in a single epoch.
2.  **Stage 2 (Classifier Re-balancing)**: We **freeze the backbone** and fine-tune only the classifier head using **Class-Balanced Sampling** (uniform probability per class). This stage adjusts the decision boundaries to maximize the Macro F1 score, ensuring rare classes are treated equally to frequent ones.
3.  **Validation & Analysis**: We evaluate the final model on the hold-out validation set to compute the Macro F1 score. We then perform a failure analysis by correlating prediction errors with class frequency to understand the impact of data imbalance.
4.  **Submission**: If the validation F1 score exceeds the specified threshold, we generate predictions for the test set using the provided inference utility.

The script utilizes the provided library modules for data loading, modeling, and training to ensure consistency and efficiency.
