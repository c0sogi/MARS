The issue is that the `Trainer.fit` method saves the `classes` metadata (a NumPy array) directly into the checkpoint dictionary. When `torch.load` is called subsequently (either in `fit` or `inference.py`), it fails because modern PyTorch defaults to `weights_only=True`, which blocks the deserialization of complex objects like NumPy arrays for security reasons (Cite debug_lesson_3).

To fix this, I will modify `library/trainer.py` to convert the `classes` array to a standard Python list using `.tolist()` before saving it to the checkpoint. This ensures the metadata consists only of safe primitives, making it compatible with `weights_only=True`.
