# Optimized Solution: Decoupled Training with EfficientNet and Square-Root Sampling

### Model
I propose replacing the ResNet-18 backbone with **EfficientNet-B0**. EfficientNet-B0 offers a superior trade-off between parameter efficiency and accuracy, making it better suited for fine-grained classification tasks than the legacy ResNet architecture.
*   **Backbone**: EfficientNet-B0 pre-trained on ImageNet. This modern architecture uses compound scaling to extract richer features with fewer parameters.
*   **Head**: A single linear layer projecting the 1280-dimensional features to the 64,500 classes.

### Data
To address the conflict between feature learning (requiring head data) and metric optimization (requiring tail performance), I propose a dual-strategy data approach:
1.  **Stage 1 Data (Square-Root Sampling)**: For the initial training phase, I will construct a subset where the number of samples per class is proportional to the square root of its original frequency ($\sqrt{N_c}$). This approach dampens the extreme imbalance (2000:1) to a manageable ratio (~45:1) while strictly avoiding the aggressive truncation of frequent classes that was found to degrade feature learning **Cite solution_lesson_node_00003**.
2.  **Stage 2 Data (Class-Balanced Sampling)**: For the second phase, I will use a Weighted Random Sampler that samples every class with equal probability ($1/C$), ensuring the model sees rare and frequent classes equally.

### Training
I will implement a **Two-Stage Decoupled Training Pipeline**, a structural innovation designed to separate representation learning from classifier balancing:
*   **Stage 1: Representation Learning**: Train the **entire model (backbone + head)** using the **Square-Root Sampled** dataset. This phase focuses on learning robust, generalizable visual features by leveraging the higher volume of data available in the "head" and "body" classes, ensuring the feature extractor does not collapse due to data starvation.
*   **Stage 2: Classifier Re-balancing**: **Freeze the backbone parameters** and fine-tune **only the final classification head** using the **Class-Balanced Sampler**. This phase explicitly optimizes the decision boundaries for the Macro F1 metric, correcting the bias against tail classes without corrupting the high-quality features learned in Stage 1. This directly mitigates the tail collapse observed in previous attempts **Cite solution_lesson_node_00001**.
*   **Optimizer**: AdamW with a One-Cycle Learning Rate scheduler for Stage 1; a constant low learning rate for Stage 2.
*   **Loss**: Cross-Entropy Loss.

### Evaluation
*   **Inference**: Resize test images to 224x224, normalize, and perform a single forward pass.
*   **Prediction**: Select the class with the highest logit. No test-time augmentation (TTA) will be used to conserve runtime.
