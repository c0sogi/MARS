Implementation Strategy:
The following script demonstrates the usage of the provided machine learning library for the Cactus Identification task. The strategy involves:
1.  **Configuration**: Importing the `Config` class and overriding settings (enabling `DEBUG` mode, reducing `EPOCHS` and `BATCH_SIZE`) to ensure the demonstration runs quickly (under 1 minute) while exercising all code paths.
2.  **Data Loading**: Utilizing `get_train_val_loaders` and `get_test_loader` from `library.data` to load the dataset. We verify the integrity of the data (shapes of images, metadata, and labels) using assertions.
3.  **Model Verification**: Instantiating all three provided model architectures (`CactusRepVGG`, `CactusResNet`, `CactusNeXt`) and performing a dummy forward pass on the CPU/GPU to confirm they accept the `(image, metadata)` input format and produce the correct output shape.
4.  **Training & Validation**: Executing a single epoch of training using `library.engine.train_one_epoch` and a validation pass using `library.engine.validate`. This ensures the training loop, loss calculation, and metric computation (ROC AUC) are functioning.
5.  **Advanced Features**:
    *   **SWA (Stochastic Weight Averaging)**: Instantiating `SWAHandler`, forcing a step update, and running the batch normalization update routine.
    *   **TTA (Test Time Augmentation)**: Running inference on the test set using the 4-view TTA function provided in `library.engine`.
    *   **RepVGG Deployment**: Demonstrating the `switch_to_deploy` method, verifying that the multi-branch training architecture is successfully collapsed into a single inference-optimized branch.
