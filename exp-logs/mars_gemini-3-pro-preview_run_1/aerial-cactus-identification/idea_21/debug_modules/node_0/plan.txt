This script demonstrates the complete workflow using the provided library files. It covers:
1.  **Setup**: initializing directories and random seeds.
2.  **Data Loading**: loading cached data or processing from scratch, and creating DataLoaders for training, validation, and testing.
3.  **Model Usage**: instantiating the `MultiScaleRepVGG` architecture and verifying its multi-head output.
4.  **Training**: running a single epoch of training with Mixup augmentation.
5.  **Evaluation**: calculating the ROC AUC metric on the validation set.
6.  **SWA**: applying Stochastic Weight Averaging and updating BatchNorm statistics.
7.  **Optimization**: reparameterizing the model (fusing branches) for faster inference.
8.  **Inference**: generating a submission file in the correct format.
