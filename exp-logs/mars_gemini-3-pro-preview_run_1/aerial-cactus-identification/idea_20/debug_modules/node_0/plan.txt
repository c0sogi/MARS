### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed for reproducibility and define paths for input data and temporary working directories.
2.  **Data Loading**: Use `library.dataset.load_and_cache_images` to load a small subset of the training and test data (using `max_samples`) to ensure the script runs quickly.
3.  **Dataset & DataLoader**: Instantiate `CactusDataset` for both training and validation sets. Verify the output shapes of the data loaders to ensure dimensions are correct (Batch x Channels x Height x Width).
4.  **Model Initialization**: Create an instance of `RepVGGClassifier` with a reduced `width_multiplier` to create a lightweight version of the model suitable for a quick demonstration.
5.  **Training Loop & SWA**:
    *   Run a short training loop (2 epochs) using `library.engine.train_one_epoch`.
    *   Integrate `library.engine.SWAHandler` to demonstrate Stochastic Weight Averaging updates.
    *   Validate the model after each epoch using `library.engine.evaluate`.
6.  **Model Deployment**: Convert the trained model to inference mode using `library.model.model_to_deploy`. This fuses the multi-branch blocks into single convolutional layers.
7.  **Inference Verification**: Run a forward pass with the deployed model on the test set to verify it produces predictions without errors and check the output shape.
8.  **Cleanup**: Remove temporary cache files created during the run.
