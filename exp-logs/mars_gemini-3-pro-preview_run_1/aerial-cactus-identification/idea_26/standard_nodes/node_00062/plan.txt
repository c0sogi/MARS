Implementation Strategy:
The solution implements a robust **5-Fold Stratified Cross-Validation** pipeline using the **Quality-Supervised RepVGG** architecture. 
1.  **Data Management**: We load the training data from `train_metadata.csv` and split it into 5 stratified folds. We use the `CactusDataset` class which caches preprocessed tensors to RAM for high-speed training.
2.  **Training Loop**: For each fold, we train a `QualityRepVGG` model (RepVGG-A0 backbone) for 25 epochs. We use **AdamW** with **Cosine Annealing** and **Mixup** augmentation. **Stochastic Weight Averaging (SWA)** is applied in the final epochs to improve generalization. The loss function combines binary classification loss and auxiliary file-size regression loss.
3.  **Validation & Calibration**: We evaluate the ensemble of 5 models on the official hold-out validation set (`val_metadata.csv`). We apply **Quality-Calibrated Inference**, where model predictions are weighted by their ability to correctly estimate the image's file size (a proxy for image quality/compression artifacts).
4.  **Failure Analysis**: We analyze the validation errors by calculating their correlation with input features (File Size, Intensity, Contrast) to understand systematic weaknesses.
5.  **Submission**: Finally, we generate predictions for the test set using the calibrated ensemble and **Test Time Augmentation (TTA)**, saving the results to `submission.csv`.
