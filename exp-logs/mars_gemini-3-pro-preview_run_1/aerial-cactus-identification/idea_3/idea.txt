# Model
I propose a **Shallow Steerable Equivariant ResNet**.

*   **Structural Innovation (Geometric Equivariance):** Instead of standard Convolutional Neural Networks (CNNs) which are only translation-equivariant, I will implement a **Steerable CNN** that is equivariant to the discrete rotation and reflection group $D_4$ (rotations of 0, 90, 180, 270 degrees and flips). By using steerable convolutions (via the available `cuequivariance` libraries), the network's feature maps will mathematically guarantee that a rotated input produces a correspondingly rotated feature response. This provides a much stronger inductive bias for aerial imagery than standard data augmentation alone **(Cite solution_lesson_node_00002)**.
*   **Backbone Design:** The architecture will mirror the successful depth of the previous best model but use equivariant layers. It will consist of an equivariant stem followed by 3 stages of **Equivariant Residual Blocks**.
*   **Conservative Downsampling:** Crucially, I will retain the **Conservative Downsampling** strategy (initial stride 1, no early pooling) to preserve the 32x32 spatial resolution throughout the early stages, ensuring fine-grained texture details are not lost **(Cite solution_lesson_node_00001)**.
*   **Invariant Head:** The final classification head will utilize **Group Pooling** (aggregating features across all rotations/reflections) followed by Global Average Pooling to produce a strictly rotation-invariant feature vector before the final linear classifier.

# Data
*   **Preprocessing:** Images will be normalized using the dataset's channel-wise mean and standard deviation.
*   **Augmentation:**
    *   **Geometric:** Standard RandomHorizontalFlip and RandomVerticalFlip will be applied to the training set. While the model is equivariant, these augmentations still help by presenting the network with varied pixel interpolation artifacts **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** I will apply **Mild Mixup Regularization** (Beta distribution $\alpha=0.2$). This specific intensity was found to be optimal for closing the generalization gap without drowning out the signal, unlike the aggressive $\alpha=1.0$ which degraded performance **(Cite solution_lesson_node_00004, solution_lesson_node_00006)**.

# Training
*   **Loss Function:** **Binary Cross-Entropy with Logits** will be used to handle the soft targets generated by Mixup.
*   **Optimizer:** The **AdamW** optimizer will be used for stable convergence and weight decay handling.
*   **Scheduler:** A **Cosine Annealing** scheduler will be employed.
*   **Duration:** The training will run for **30 epochs**. This duration is explicitly chosen to accommodate the slower convergence dynamics of Mixup and to ensure the Cosine Annealing schedule has a sufficiently gradual decay tail, avoiding the performance regression seen with shorter 15-epoch schedules **(Cite solution_lesson_node_00003)**.

# Evaluation
*   **Inference Strategy:** Despite the architectural equivariance, I will retain **4-view Test Time Augmentation (TTA)** (averaging predictions of original, horizontal flip, vertical flip, and 180-degree rotation). This acts as a robust ensemble method to marginalize out any remaining discretization noise or interpolation variances **(Cite solution_lesson_node_00002)**.
