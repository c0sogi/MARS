The `KeyError: 'exp_avg'` occurs because the custom `SAM` optimizer implementation modifies the shared parameter state dictionary (`self.state`) before the base optimizer (`AdamW`) performs its first step. Specifically, `SAM.first_step` saves the original weights into `self.state[p]["old_p"]`. When `AdamW.step()` is subsequently called, it checks `len(state[p])` to decide whether to initialize its momentum buffers (like `exp_avg`). Since `SAM` has already added an entry, `AdamW` assumes initialization is complete and attempts to access the non-existent `exp_avg`, causing the crash.

To fix this, I will modify `SAM` to store the backup weights (`old_p`) in a separate instance attribute (`self.backup`) instead of the shared `self.state`. This ensures that `self.state` remains empty for the base optimizer's first step, allowing it to trigger its initialization logic correctly. This resolution directly applies the knowledge from Cite debug_lesson_4.
