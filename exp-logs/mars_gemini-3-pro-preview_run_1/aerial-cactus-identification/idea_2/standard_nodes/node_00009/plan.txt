The `AttributeError: type object 'Config' has no attribute 'RESNET_BLOCKS'` occurs because the `CactusResNet` class definition in `library/model.py` attempts to access `Config.RESNET_BLOCKS` as a default argument for `num_blocks`. However, `library/config.py` defines this configuration variable as `BLOCK_CONFIG`, not `RESNET_BLOCKS`. Furthermore, accessing configuration attributes directly in the function signature causes the value to be evaluated at import time, which can lead to errors if the configuration class is not fully initialized or if there are circular dependencies.

To fix this, I will modify the `__init__` method of `CactusResNet` in `library/model.py`. I will change the default value of `num_blocks` to `None` and assign it the correct value `Config.BLOCK_CONFIG` inside the method body. This approach resolves the naming mismatch and decouples the method signature from the configuration class, preventing import-time errors (Cite debug_lesson_1).
