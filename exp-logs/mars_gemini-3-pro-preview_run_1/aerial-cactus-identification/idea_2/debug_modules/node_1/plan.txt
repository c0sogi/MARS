The issue lies in the weight initialization loop within the `CactusDenseNet` class in `library/model.py`. The code iterates through all modules and attempts to initialize the bias of every `nn.Linear` layer to 0 (`nn.init.constant_(m.bias, 0)`). However, the `SEBlock` used in the model defines `nn.Linear` layers with `bias=False`, causing `m.bias` to be `None`. Attempting to modify `None` raises the `AttributeError`. The fix is to explicitly check if `m.bias` is not `None` before attempting initialization.
