The following script demonstrates the end-to-end usage of the provided library for the Cactus Identification task.

**Implementation Strategy:**
1.  **Configuration Setup**: We dynamically override the default `Config` parameters to define a temporary working directory for this demonstration and reduce the training duration (2 epochs) to ensure quick execution.
2.  **Data Loading Verification**: We initialize the data loaders using `get_dataloaders` and verify the shape and type of the batches yielded by the training loader.
3.  **Model Architecture Check**: We instantiate the `RepVGGCactus` model and perform a forward pass with a sample batch to confirm output dimensions. We also explicitly validate the structural re-parameterization logic (fusing multi-branch blocks into a single convolution) by comparing outputs before and after conversion.
4.  **Training Loop Execution**: We initialize the `Trainer` class and run the `fit` method for the reduced number of epochs. We assert that the model checkpoint is successfully saved.
5.  **Inference and Submission**: We utilize the trained model to generate predictions on the test set using Test Time Augmentation (TTA), create a submission file, and verify its format against the requirements.
6.  **Cleanup**: We ensure the script is self-contained and leaves the environment clean (though the temporary directory structure is kept for inspection if needed).
