To demonstrate the utilization of the provided library files for the Cactus Classification task, I have implemented a comprehensive script that performs the following steps:

1.  **Setup & Configuration**: Initializes the environment, sets random seeds for reproducibility, and overrides the epoch count to 1 to ensure the demo runs quickly.
2.  **Data Pipeline Verification**: Loads the training data using `dataset.get_data`, creates a `CactusDataset`, and verifies the integrity of data loading and the `Mixup` augmentation class using assertions.
3.  **Model Architecture Check**: Instantiates all three provided model architectures (`CactusResNet`, `CactusRepVGG`, `CactusNeXt`) using the factory function `models.create_model` and performs a dummy forward pass on the GPU to verify input/output shapes.
4.  **Training Loop Demonstration**: Runs a complete training epoch for the `CactusResNet` model on the first fold of the data using `engine.train_one_epoch`. It then evaluates the model using `engine.validate` to report Loss and ROC AUC.
5.  **Inference & TTA**: Generates predictions on the test set using Test-Time Augmentation (TTA) via `engine.predict_tta`.
6.  **Stacking Ensemble**: Demonstrates the `stacking.py` module by creating synthetic "Out-Of-Fold" predictions (simulating a multi-model ensemble) and training the Logistic Regression `MetaLearner`. It then uses this meta-learner to generate final calibrated probabilities.
7.  **Submission**: Formats the final predictions into a DataFrame and saves the submission file to the specified location.
