This script demonstrates the end-to-end workflow for the Cactus Classification task using the provided library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to run in a fast "Debug Mode" (fewer epochs, smaller dataset, fewer folds, single model architecture) to ensure the script completes quickly within the time limit.
2.  **Data Loading**: Uses `library.dataset` to load training, validation, and test data loaders, verifying batch shapes.
3.  **Model Training**: Executes `library.training.run_fold` to train a `CactusResNet` model for 2 folds using the debug dataset. This demonstrates the training loop, Mixup augmentation, SWA (Stochastic Weight Averaging), and checkpoint saving.
4.  **Stacking & Inference**: Uses `library.stacking.GeometricStacking` to generate meta-features from the trained models (using Test-Time Augmentation), train a Logistic Regression meta-learner, and generate a final submission file.
5.  **Validation**: Includes assertions to verify that data shapes are correct, checkpoints are created, and the submission file follows the required format.
