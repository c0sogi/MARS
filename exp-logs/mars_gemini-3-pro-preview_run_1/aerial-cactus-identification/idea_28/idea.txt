Based on the comprehensive analysis of the accumulated lessons, specifically the breakthrough in **Lesson 00062** (using auxiliary quality errors as trust scores) and the validation of **Heterogeneous Stacking** in **Lesson 00033**, I propose a solution that evolves the "Trust Score" from a fixed heuristic into a learnable feature within a stacking framework.

# Model
I propose a **Heterogeneous Trust-Aware Stacking Ensemble**.

### 1. Diverse Base Learners
The ensemble will consist of two distinct backbone architectures to ensure diversity in feature representation and error profiles.
*   **CactusRepVGG:** A re-parameterizable architecture using multi-branch blocks (3x3 + 1x1 + Identity) during training for stability, fused into single-path 3x3 convolutions for inference **(Cite solution_lesson_node_00017)**.
*   **CactusResNet:** A standard residual network backbone providing a stable, diverse alternative to the VGG-style stream.

**Universal Structural Constraints:**
Both architectures will strictly adhere to the following design principles:
*   **Conservative Downsampling:** Stems will use a single 3x3 convolution with stride 1 and **no pooling** to strictly preserve the 32x32 spatial resolution **(Cite solution_lesson_node_00001)**.
*   **Small Kernel Constraint:** All convolutions will strictly use **3x3 kernels** to avoid the signal blurring observed with larger kernels on small images **(Cite solution_lesson_node_00016)**.
*   **Implicit Quality Supervision:** Both architectures will feature an **Auxiliary Regression Head** attached to the final feature layer, trained to predict the **Log-Transformed File Size**. This forces the backbones to implicitly learn compression artifacts without the redundancy of explicit metadata injection at the input level **(Cite solution_lesson_node_00054, solution_lesson_node_00062)**.

### 2. Structural Innovation: Trust-Aware Meta-Learner
Instead of using a fixed heuristic to weight models (as in Lesson 00062) or a simple probability stack (as in Lesson 00033), I will implement a **Feature-Augmented Meta-Learner**.
*   The Meta-Learner (Logistic Regression) will be trained on a dense feature matrix containing:
    1.  **Class Probabilities:** The `has_cactus` predictions from the base models.
    2.  **Trust Scores:** The **Absolute Error** between each model's predicted file size and the actual file size.
*   **Rationale:** This allows the meta-learner to mathematically learn the optimal weighting function, down-weighting specific models on specific samples where their "quality understanding" (auxiliary error) indicates confusion, rather than relying on a hard-coded exponential decay **(Cite solution_lesson_node_00062)**.

# Data
*   **Preprocessing & Caching:** The entire dataset (train and test) will be decoded and **cached in RAM** as floating-point tensors to eliminate I/O latency **(Cite solution_lesson_node_00020)**.
*   **Target Engineering:**
    *   **Training:** File sizes will be extracted, log-transformed, and normalized (0-1) to serve as targets for the Auxiliary Regression Heads.
    *   **Meta-Training:** Out-Of-Fold (OOF) auxiliary errors will be computed to construct the Trust Score features.
*   **Augmentation:**
    *   **Geometric:** **RandomHorizontalFlip** and **RandomVerticalFlip** to exploit rotational invariance **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** **Mild Mixup** ($\alpha=0.2$) applied to both class labels and regression targets to close the generalization gap **(Cite solution_lesson_node_00004)**.

# Training
*   **Strategy:** **5-Fold Stratified Cross-Validation** will be performed for each architecture. This generates the unbiased OOF predictions and OOF Trust Scores required to train the Meta-Learner **(Cite solution_lesson_node_00033)**.
*   **Optimizer:** **AdamW** with a **Cosine Annealing** scheduler for **30 epochs** per fold to ensure convergence with Mixup **(Cite solution_lesson_node_00003)**.
*   **Stochastic Weight Averaging (SWA):** Activated during the final 10 epochs (with cyclic learning rates) to locate flat minima in the loss landscape, improving robustness without the cost of SAM **(Cite solution_lesson_node_00029)**.
*   **Loss Function:** Weighted Multi-Task Loss: $L_{total} = L_{BCE}(\text{Class}) + \lambda L_{MSE}(\text{Quality})$.

# Evaluation
*   **Structural Fusion:** Before inference, RepVGG models will be re-parameterized into single layers **(Cite solution_lesson_node_00017)**.
*   **Inference Strategy:**
    1.  **TTA:** Each of the 10 trained models (2 archs $\times$ 5 folds) generates predictions using **4-view Test Time Augmentation** **(Cite solution_lesson_node_00002)**.
    2.  **Feature Extraction:** For each test image, we extract the aggregated Class Probability and calculate the Trust Score (Auxiliary Error) for each architecture.
    3.  **Meta-Prediction:** These features are fed into the trained Logistic Regression Meta-Learner to produce the final calibrated probability.
