The following script demonstrates the end-to-end usage of the provided library components for the cactus classification task.

**Implementation Strategy:**
1.  **Configuration Setup**: We override specific `Config` parameters (enabling `DEBUG` mode, reducing `EPOCHS` to 2, and setting a specific working directory) to ensure the script runs quickly and does not overwrite existing work.
2.  **Data Pipeline Verification**: We initialize the data loaders using `get_dataloaders` and verify the structure and dimensions of the batches (images, labels, auxiliary quality targets). We also validate the `mixup_data` augmentation function.
3.  **Model Architecture Verification**: We instantiate both `CactusRepVGG` and `CactusResNet`. We specifically test the `RepVGG` re-parameterization logic (`switch_to_deploy`) by asserting that the model output remains consistent (within a small tolerance) before and after fusing the blocks.
4.  **Training Loop Execution**: We run the `fit` function from the engine module. This exercises the training step, validation step, SWA (Stochastic Weight Averaging) handler, and checkpoint saving mechanisms.
5.  **Output Validation**: Finally, we check that the expected model checkpoints (`best_model.pth`, `swa_model.pth`) were generated successfully.
