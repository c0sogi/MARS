Based on the accumulated lessons and the trajectory of previous ideas, I propose a solution that structurally evolves the **Heterogeneous Stacking** approach by integrating **Multi-Task Learning (MTL)**. This strategy directly targets the "Data Quality" bottleneck by forcing the network to explicitly learn features related to image compression, rather than just passively gating based on metadata.

# Model
I propose a **Heterogeneous Multi-Task Stacking Ensemble**.

### 1. Diverse Base Architectures
The ensemble will consist of three distinct backbones to maximize feature diversity. All will utilize **Conservative Downsampling** (stride-1, pooling-free stems) to strictly preserve the 32x32 spatial resolution **(Cite solution_lesson_node_00001)**.
1.  **CactusRepVGG-MTL:** A re-parameterizable backbone (3x3 + 1x1 + Identity) **(Cite solution_lesson_node_00017)**.
2.  **CactusResNet-MTL:** A standard residual network backbone using 3x3 convolutions.
3.  **CactusNeXt-MTL (3x3):** A modernized backbone (Depthwise Conv, LayerNorm, GELU) strictly enforcing **3x3 kernels** to prevent signal blurring **(Cite solution_lesson_node_00016)**.

### 2. Structural Innovation: Multi-Task Quality Supervision
To address the strong correlation between error rates and image file size **(Cite solution_lesson_node_00029)**, I will introduce a **Multi-Task Learning** framework.
*   **Primary Head:** A standard classification head predicting `has_cactus`.
*   **Auxiliary Quality Head:** A regression head attached to the final feature layer, trained to predict the **Log-Transformed File Size** of the input image.
*   **Rationale:** By forcing the shared backbone to predict the file size, the convolutional filters are compelled to encode features related to compression artifacts (e.g., blocking, ringing, blur). This ensures that the visual representation contains explicit "quality awareness," which the primary head can then use to adjust its confidence.

### 3. Feature-wise Linear Modulation (FiLM)
Complementing the implicit multi-task learning, I will retain the explicit **FiLM** layers from previous ideas. The normalized file size metadata will modulate the feature maps ($Feature_{out} = \gamma \cdot Feature_{in} + \beta$) throughout the network **(Cite solution_lesson_node_00035)**. This dual approach (Implicit MTL + Explicit FiLM) provides the strongest possible inductive bias for handling variable-quality data.

# Data
*   **Preprocessing & Caching:** The entire dataset will be decoded and **cached in RAM** as floating-point tensors to eliminate I/O latency **(Cite solution_lesson_node_00020)**.
*   **Feature Engineering:** Image file sizes will be extracted.
    *   For **FiLM Inputs:** Z-score normalized.
    *   For **Auxiliary Targets:** Log-transformed and normalized to a 0-1 range.
*   **Augmentation:**
    *   **Geometric:** **RandomHorizontalFlip** and **RandomVerticalFlip** to exploit rotational invariance **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** **Mild Mixup** ($\alpha=0.2$) applied to both images and targets (interpolating both the class label and the file size target) to close the generalization gap **(Cite solution_lesson_node_00004, solution_lesson_node_00006)**.

# Training
*   **Strategy:** **5-Fold Stratified Cross-Validation** will be performed for each of the 3 architectures (15 models total) to generate unbiased Out-Of-Fold (OOF) predictions **(Cite solution_lesson_node_00033)**.
*   **Loss Function:** A weighted Multi-Task Loss: $L_{total} = L_{BCE}(class) + \lambda L_{MSE}(quality)$.
*   **Optimizer:** **AdamW** for effective weight decay.
*   **Scheduler:** **Cosine Annealing** for **30 epochs** to ensure convergence with Mixup **(Cite solution_lesson_node_00003)**.
*   **Stochastic Weight Averaging (SWA):** Activated in the final epochs to locate flat minima and improve robustness **(Cite solution_lesson_node_00029)**.

# Evaluation
*   **Structural Fusion:** Before inference, the RepVGG models will undergo **Structural Re-parameterization**, fusing the convolutional branches into single layers while retaining the FiLM and classification heads **(Cite solution_lesson_node_00017)**. The Auxiliary Quality Head can be discarded during inference to save compute.
*   **Inference Strategy:**
    1.  **TTA:** Each model will generate predictions using **4-view Test Time Augmentation** (original, horizontal flip, vertical flip, 180-degree rotation) **(Cite solution_lesson_node_00002)**.
    2.  **Stacking:** The aggregated OOF predictions from all base learners, along with the file size metadata, will be fed into a **Logistic Regression Meta-Learner** to produce the final probability **(Cite solution_lesson_node_00033)**.
