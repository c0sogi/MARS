The following script demonstrates the end-to-end pipeline using the provided library files. It covers data loading, model instantiation, training (with Mixup and Multi-Task Learning), validation, SWA (Stochastic Weight Averaging), inference with TTA (Test Time Augmentation), and model stacking.

To ensure the demonstration runs quickly within the constraints, the script overrides the default configuration to use a small debug subset of the data and runs for a minimal number of epochs. It includes assertions at key steps to verify the correctness of shapes and outputs.
