Based on the accumulated lessons and the trajectory of previous experiments, I propose a solution that synthesizes the robustness of **Heterogeneous Stacking**, the efficiency of **Structural Re-parameterization**, and the critical insight regarding **Data Quality** into a unified **Heterogeneous Multi-Task Quality-Aware Ensemble**.

# Model
I propose a **Heterogeneous Multi-Task Stacking Ensemble** composed of three diverse backbone architectures.

### 1. Diverse Base Architectures
To maximize feature diversity and marginalize architectural biases, the ensemble will consist of three distinct backbones. Crucially, all three will strictly adhere to two constraints derived from previous failures:
*   **Conservative Downsampling:** All stems will use a 3x3 convolution with stride 1 and no pooling to strictly preserve the 32x32 spatial resolution, preventing the signal destruction observed with standard aggressive downsampling **(Cite solution_lesson_node_00001)**.
*   **Small Kernel Constraint:** All convolutions will strictly use **3x3 kernels**. This modifies modern architectures (like ConvNeXt) to avoid the performance degradation caused by large kernels (7x7) on small thumbnail images **(Cite solution_lesson_node_00016)**.

The three architectures are:
1.  **CactusRepVGG-MTL:** A re-parameterizable backbone using multi-branch blocks (3x3 + 1x1 + Identity) for training stability, fused into single layers for inference **(Cite solution_lesson_node_00017)**.
2.  **CactusResNet-MTL:** A standard residual network backbone using 3x3 convolutions.
3.  **CactusNeXt-MTL (3x3):** A modernized backbone using Depthwise Convolutions, Layer Normalization, and GELU, adapted to the 3x3 kernel constraint.

### 2. Structural Innovation: Dual Quality Awareness
To directly address the **Data Quality Bottleneck** (the strong correlation between error rates and image file size identified in failure analysis), every backbone will incorporate two complementary mechanisms:
*   **Implicit Supervision (Multi-Task Learning):** Each model will have an **Auxiliary Regression Head** trained to predict the **Log-Transformed File Size** of the input image. This forces the shared convolutional filters to explicitly encode features related to compression quality (e.g., artifacts, blur), ensuring the visual representation is "quality-aware" **(Cite solution_lesson_node_00029)**.
*   **Explicit Modulation (FiLM):** Every block in the networks will be equipped with **Feature-wise Linear Modulation (FiLM)** layers. A shared MLP will project the normalized file size metadata into scale and shift parameters to modulate feature maps ($Feature_{out} = \gamma \cdot Feature_{in} + \beta$). This allows the network to dynamically adapt its processing—suppressing noise in low-quality images—based on the explicit metadata signal **(Cite solution_lesson_node_00035)**.

# Data
*   **Preprocessing & Caching:** To eliminate I/O bottlenecks and maximize training throughput, the entire dataset (train and test) will be decoded and **cached in RAM** as floating-point tensors **(Cite solution_lesson_node_00020)**.
*   **Feature Engineering:** Image file sizes will be extracted.
    *   For **FiLM Inputs:** Z-score normalized.
    *   For **MTL Targets:** Log-transformed and normalized to a 0-1 range.
*   **Augmentation:**
    *   **Geometric:** **RandomHorizontalFlip** and **RandomVerticalFlip** will be applied to exploit the rotational invariance of aerial photography **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** **Mild Mixup** ($\alpha=0.2$) will be applied to both images and targets (interpolating class labels and file size targets) to close the generalization gap without drowning out the signal **(Cite solution_lesson_node_00004, solution_lesson_node_00006)**.

# Training
*   **Strategy:** **5-Fold Stratified Cross-Validation** will be performed for each of the 3 architectures (15 models total). This generates unbiased Out-Of-Fold (OOF) predictions required to train the Meta-Learner **(Cite solution_lesson_node_00033)**.
*   **Optimizer:** **AdamW** will be used for effective weight decay.
*   **Scheduler:** A **Cosine Annealing** scheduler will be employed for **30 epochs** per fold. This duration is explicitly chosen to ensure convergence with Mixup **(Cite solution_lesson_node_00003)**.
*   **Stochastic Weight Averaging (SWA):** To efficiently locate flat minima in the loss landscape and improve robustness without the 2x computational cost of SAM, SWA will be activated during the final epochs of training **(Cite solution_lesson_node_00029)**.
*   **Loss Function:** A weighted Multi-Task Loss: $L_{total} = L_{BCE}(class) + \lambda L_{MSE}(quality)$.

# Evaluation
*   **Structural Fusion:** Before inference, the RepVGG models will undergo **Structural Re-parameterization**, fusing the convolutional branches into single layers while retaining the FiLM modulation **(Cite solution_lesson_node_00017)**. The Auxiliary Quality Head will be discarded for inference.
*   **Inference Strategy:**
    1.  **TTA:** Each of the 15 trained models will generate predictions using **4-view Test Time Augmentation** (original, horizontal flip, vertical flip, 180-degree rotation) **(Cite solution_lesson_node_00002)**.
    2.  **Stacking:** The aggregated OOF predictions from all base learners, concatenated with the file size metadata, will be fed into a **Logistic Regression Meta-Learner** to produce the final probability. This hierarchical approach leverages the ensemble's diversity to correct for remaining errors **(Cite solution_lesson_node_00033)**.
