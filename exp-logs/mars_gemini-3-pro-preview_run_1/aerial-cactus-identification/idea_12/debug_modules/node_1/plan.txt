The issue lies in the `switch_to_deploy` method of the `MetadataGatedRepVGG` class in `library/model.py`. The method iterates over `self.modules()`, which includes the instance itself (`self`) as the first element. Since `MetadataGatedRepVGG` defines `switch_to_deploy`, the check `hasattr(module, "switch_to_deploy")` passes for `self`, causing the method to call itself recursively and resulting in a `RecursionError`.

To fix this, we must explicitly exclude `self` from the loop before attempting to call `switch_to_deploy` on the module. This ensures the method only triggers the deployment switch on the submodule components (like `RepVGGBlock`) and not the container class itself.
