The `numpy.random.randint` function raises a `TypeError` when `dtype=np.float32` is passed because it is designed to generate integers and only accepts integer data types. To fix the issue in `runfile.py`, I will modify the generation of `mock_labels` and `mock_fsizes` to generate standard integers first and then cast them to the required floating-point type using `.astype(np.float32)`.

=======
