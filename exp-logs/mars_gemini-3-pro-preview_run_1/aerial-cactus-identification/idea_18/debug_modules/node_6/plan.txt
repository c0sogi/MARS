The `RecursionError` occurs because `CactusModel.switch_to_deploy` iterates over `self.modules()`, which yields the `CactusModel` instance itself (`self`) as the first item. Since `self` has the `switch_to_deploy` method, the code calls `self.switch_to_deploy()` recursively, leading to an infinite loop. I will fix this by adding a check `if m is not self` inside the loop to ensure the method is only called on descendant modules, effectively breaking the recursion cycle (Cite debug_lesson_12).
