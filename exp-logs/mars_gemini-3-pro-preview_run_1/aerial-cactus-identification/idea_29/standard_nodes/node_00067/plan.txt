Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `utils`. We will override the default `EPOCHS` to 15 and `SWA_START_EPOCH` to 10 to ensure the "fast baseline" requirement is met while maintaining convergence on the small 32x32 images.
2.  **Data Loading**: Use `get_dataloaders` to load training and validation sets into RAM (using the caching mechanism). We also prepare the test loader.
3.  **Expert Training (Stage 1)**:
    *   Iterate through the two architectures: `CactusRepVGG` and `CactusResNet`.
    *   For each expert, run a training loop using **AdamW** and **Cosine Annealing**.
    *   Implement **Stochastic Weight Averaging (SWA)** in the final epochs to improve generalization.
    *   Save the best performing model (based on validation AUC) and the SWA model.
    *   Generate and store OOF-like predictions (class probabilities and auxiliary file size estimates) on the validation set to be used for training the router.
4.  **Router Training (Stage 2)**:
    *   Construct the training data for the **Trust Router**: Inputs are the "Trust Scores" (absolute error of the auxiliary file size prediction) from both experts; Targets are the ground truth labels.
    *   Train the MLP Router to learn optimal mixing weights based on how "trustworthy" (low error) each expert is for a given image.
5.  **Validation & Failure Analysis**:
    *   Evaluate the full ensemble (Experts + Router) on the validation set.
    *   Print the **Final Validation Metric (ROC AUC)**.
    *   Perform failure analysis by calculating the correlation between the model's prediction error and the image file sizes, identifying if compression artifacts affect performance.
6.  **Inference & Submission**:
    *   Load the best expert models.
    *   Structurally re-parameterize the `CactusRepVGG` expert (fuse branches) for efficient inference.
    *   Perform **4-view Test Time Augmentation (TTA)** (Original, HFlip, VFlip, HVFlip) on the test set.
    *   Calculate Trust Scores for the test set using the TTA-averaged auxiliary predictions.
    *   Gate the experts using the trained Router and generate the final submission file.
