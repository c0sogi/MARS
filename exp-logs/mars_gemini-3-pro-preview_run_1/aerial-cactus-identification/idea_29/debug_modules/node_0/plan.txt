This script demonstrates the complete pipeline for the "Heterogeneous Trust-Gated Mixture of Experts" solution using the provided library files. It covers data loading, expert model initialization and training, trust score calculation, gating network (router) training, and final ensemble inference.

The strategy involves:
1.  **Configuration**: Overriding default `Config` settings to enable `DEBUG` mode and reduce epochs for rapid execution.
2.  **Data Preparation**: utilizing `get_dataloaders` to load cached tensors into RAM.
3.  **Expert Training**: Training two distinct backbones (`CactusRepVGG` and `CactusResNet`) on the primary classification task and the auxiliary file-size regression task.
4.  **Trust Signal Generation**: Calculating the "Trust Score" (absolute error between predicted and actual file size) on the validation set.
5.  **Router Training**: Training a small MLP (`TrustRouter`) to assign weights to experts based on their trust scores.
6.  **Inference**: Applying the ensemble to the test set, where file sizes are known metadata, allowing dynamic weighting of predictions.
