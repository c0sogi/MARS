The following implementation demonstrates the end-to-end workflow for the Semantic Similarity task using the provided library modules.

### Implementation Strategy

1.  **Configuration & Setup**: We define a `DemoConfig` class inheriting from the provided `Config`. We override specific settings (enabling debug mode, reducing epochs to 1, shortening sequence length) to ensure the script executes rapidly (under 5 minutes) while still exercising all code paths. We also set up logging and random seeds for reproducibility.
2.  **Data Preparation**: We load the metadata CSVs (`train.csv`, `val.csv`, `test.csv`). To strictly control runtime, we sample a tiny subset (50 rows) of the training and validation data.
3.  **CPC Context Mapping**: We utilize `get_cpc_texts` to parse the context descriptions, validating that the mapping is generated correctly.
4.  **Dataset & DataLoader**: We initialize the tokenizer and create instances of `PearsonDataset`. We verify the integrity of the dataset by checking the shape and types of the tensors produced by `__getitem__`.
5.  **Model Initialization**: We instantiate the `CustomModel` (DeBERTa-v3-Large based). We perform a dummy forward pass with a single batch to verify the model architecture and output dimensions before starting the training loop.
6.  **Training & Evaluation**: We configure the optimizer using `get_optimizer_params` (applying Layer-wise Learning Rate Decay) and a scheduler. We run `train_fn` for one epoch and `valid_fn` to compute the validation loss and Pearson correlation coefficient.
7.  **Inference**: We process the test set, run inference to generate similarity scores, and format the results into a submission DataFrame.
8.  **Assertions**: Throughout the script, assertions enforce expected behaviors (e.g., loss is a finite float, predictions match dataset size, Pearson score is within valid range).
