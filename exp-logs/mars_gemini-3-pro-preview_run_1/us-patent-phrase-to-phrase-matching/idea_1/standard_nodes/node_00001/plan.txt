The implementation strategy follows the standard machine learning pipeline using the provided library modules.

1.  **Setup & Configuration**: Initialize the `Config` and set random seeds using `library.utils.set_seed` to ensure reproducibility.
2.  **Data Loading**: Instantiate `PhraseDataset` for training, validation, and testing. These are wrapped in PyTorch `DataLoader`s. The `PhraseDataset` class handles tokenization and caching, ensuring efficiency.
3.  **Model Initialization**: Create an instance of `SiameseBiEncoder` (which uses a pre-trained Transformer backbone) and move it to the available device (GPU/CPU).
4.  **Training**: Configure the `AdamW` optimizer and a linear warmup scheduler. Use the `library.engine.fit` function to execute the training loop, which includes forward passes, backpropagation, and early stopping based on validation performance.
5.  **Validation**: After training, evaluate the best model on the validation set using `library.engine.evaluate` to report the `Final Validation Metric` (Pearson correlation).
6.  **Failure Analysis**: Generate predictions on the validation set and compare them with ground truth labels. Calculate correlations between the absolute error and input features (e.g., phrase lengths, ground truth score) to identify systematic weaknesses.
7.  **Submission**: Use the trained model to generate predictions for the test set via `library.engine.generate_submission` and save the results to the specified submission path.
