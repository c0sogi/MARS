### 1. Model: DeBERTa-v3-Large with Weighted Layer Pooling
**Cite Lesson ID: solution_lesson_node_00002, solution_lesson_node_00010, solution_lesson_node_00019**

We will utilize the **`microsoft/deberta-v3-large`** backbone within a **Cross-Encoder** architecture (**Cite Lesson 00002**). To address the need for high capacity (**Cite Lesson 00010**) and stability (**Cite Lesson 00019**), we will implement a custom architectural head that goes beyond the standard classification layer.

*   **Structural Innovation (Weighted Layer Pooling):** Instead of relying solely on the `[CLS]` embedding from the final transformer layer, we will implement **Weighted Layer Pooling (WLP)**. We will extract the `[CLS]` embeddings from the last $N$ (e.g., 4) hidden layers of the backbone. These embeddings will be aggregated using a learnable weighted average. This allows the model to dynamically leverage both the high-level semantic abstractions of the top layers and the more granular linguistic features of the intermediate layers, providing a richer representation for the similarity task.
*   **Head Design:** The pooled representation will be passed to a **Multi-Sample Dropout (MSD)** module (**Cite Lesson 00019**). This module instantiates multiple dropout masks in parallel, projects the outputs, and averages them before the final regression neuron. This acts as an internal ensemble, smoothing the loss landscape and improving generalization.

### 2. Data: Hierarchical Context & Native Pair Encoding
**Cite Lesson ID: solution_lesson_node_00001, solution_lesson_node_00010, solution_lesson_node_00022**

*   **Semantic Expansion:** We will parse the `input/description.md` file to map CPC codes to their **full hierarchical natural language descriptions**. For example, a code like "H04" will be expanded to "ELECTRICITY; ELECTRIC COMMUNICATION TECHNIQUE". This injects explicit semantic definitions into the model (**Cite Lesson 00001**).
*   **Structural Innovation (Input Construction):** We will strictly adhere to **Native Pair Encoding** to resolve the tokenizer confusion identified in **Lesson 00022**. We will construct the input as two distinct segments passed separately to the tokenizer:
    *   **Segment A (Text):** `Context Hierarchy + ". " + Anchor Phrase`
    *   **Segment B (Text Pair):** `Target Phrase`
    *   By passing these as `text` and `text_pair` arguments, the tokenizer will correctly assign `token_type_ids`, allowing the model's self-attention to explicitly distinguish between the "contextualized anchor" and the "target" candidate.
*   **Splitting:** We will employ **Stratified Group K-Fold Cross-Validation** (5 folds). We will group by the `anchor` phrase to strictly prevent leakage (ensuring no anchor appears in both train and val) and stratify by the discrete `score` to maintain class balance (**Cite Lesson 00010**).

### 3. Training: Stabilized Regression with Model EMA
**Cite Lesson ID: solution_lesson_node_00007, solution_lesson_node_00011, solution_lesson_node_00018, solution_lesson_node_00019**

*   **Objective:** We will optimize **Mean Squared Error (MSE) Loss**. As established in **Lesson 00018**, MSE aligns geometrically with the Pearson correlation metric, whereas BCE induces non-linear distortions that degrade performance.
*   **Structural Innovation (Training Dynamics):** To further address the instability and "fold collapse" noted in **Lesson 00011** and **Lesson 00019**, we will implement **Model Exponential Moving Average (EMA)**. We will maintain a shadow copy of the model's parameters that updates as a moving average of the training weights (e.g., decay=0.999) after each step. We will use these smoothed EMA weights for validation and final inference. This technique filters out high-frequency noise in the optimization trajectory, leading to more robust minima and better generalization than the final "raw" weights.
*   **Optimization:** We will use the AdamW optimizer with **Layer-wise Learning Rate Decay (LLRD)** (**Cite Lesson 00019**), assigning lower learning rates to the bottom layers to preserve pre-trained features.
*   **Schedule:** We will use a **short training horizon (3-4 epochs)** with a linear warmup, as extending training beyond this yields diminishing returns (**Cite Lesson 00011**). We will use **Mixed Precision (FP16)** and **Gradient Accumulation** to manage memory (**Cite Lesson 00010**).

### 4. Evaluation: Robust Ensemble Inference
**Cite Lesson ID: solution_lesson_node_00010**

*   **Inference:** We will generate predictions for the test set using the **EMA weights** of the 5 models trained during the Stratified Group K-Fold Cross-Validation.
*   **Ensembling:** The final submission score for each pair will be the **arithmetic mean** of the predictions from the 5 folds. This ensemble approach mitigates the variance of individual models and leverages the full diversity of the training data (**Cite Lesson 00010**).
