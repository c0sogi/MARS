The implementation strategy follows the optimized "Idea 4" while adhering to the "Fast Baseline" constraints.

1.  **Configuration & Setup**: We initialize the environment using the provided `Config` and `utils` to ensure reproducibility (fixed seeds) and proper device allocation (GPU).
2.  **Data Preparation**: We load the CPC descriptions and merge them with the training and validation data. We employ `StratifiedGroupKFold` on the training set to respect the grouping by anchors, preventing leakage.
3.  **Model Training (Fast Baseline)**: To satisfy the time limit, we train only the first fold (Fold 0) of the `microsoft/deberta-v3-large` model. We override the default epoch count to 2 epochs. The training utilizes **Layer-wise Learning Rate Decay (LLRD)** for stability and **Adversarial Weight Perturbation (AWP)** in the second epoch to improve robustness.
4.  **Validation & Analysis**: After training, we evaluate the best model checkpoint on the official hold-out validation set (`./metadata/val.csv`). We compute and print the Pearson correlation. We then perform failure analysis by correlating the error magnitude with input features (lengths, target score).
5.  **Submission**: If the validation metric exceeds the threshold (0.8673), we generate predictions for the test set and save the submission file.
