Based on the provided lessons and the analysis of the previous ideas, here is the optimized strategy.

### 1. Model: DeBERTa-v3-Large with Layer-wise Learning Rate Decay
**Cite Lesson ID: solution_lesson_node_00002, solution_lesson_node_00005, solution_lesson_node_00010**

We will utilize the **`microsoft/deberta-v3-large`** backbone within a **Cross-Encoder** architecture.
*   **Architecture:** The model will be instantiated using **`AutoModelForSequenceClassification`** with a single output neuron (`num_labels=1`). This retains the successful Cross-Encoder approach (**Cite Lesson 00002**) and the standardized classification head (**Cite Lesson 00005**) which have proven superior to Bi-Encoders and custom heads.
*   **Structural Innovation (Optimization Dynamics):** To address the training instability and "fold collapse" observed in **Lesson 00011**, we will implement **Layer-wise Learning Rate Decay (LLRD)**. Instead of a single learning rate, we will assign multiplicatively decaying learning rates to the transformer layers (e.g., $lr_{layer} = lr_{base} \times \text{decay}^{depth}$). This allows the pre-trained lower layers (which capture general syntax) to remain stable while the top layers (which adapt to the specific semantic task) learn more aggressively. This structural change to the optimizer is critical for stabilizing large models like DeBERTa-Large on moderate-sized datasets.

### 2. Data: Semantic Context Expansion & Group Stratification
**Cite Lesson ID: solution_lesson_node_00001, solution_lesson_node_00010**

*   **Semantic Context Expansion (Evolution of Lesson 00001):** We will fundamentally upgrade the context injection strategy. Instead of injecting the raw CPC code (e.g., "H04"), which relies on the model to memorize latent domain meanings, we will parse the provided `input/description.md` file to map every code to its full natural language description (e.g., "H04" $\rightarrow$ "ELECTRIC COMMUNICATION TECHNIQUE").
    *   **Input Format:** `[CLS] Context Description [SEP] Anchor [SEP] Target [SEP]`
    *   This ensures the Cross-Encoder conditions the similarity assessment on explicit semantic definitions, resolving the ambiguity of polysemous terms more effectively than symbolic codes.
*   **Stratified Group K-Fold:** We will employ **Stratified Group K-Fold Cross-Validation** (5 folds), grouping by the `anchor` phrase. This prevents "anchor leakage" (where the model memorizes an anchor's behavior rather than learning the relationship) and ensures the validation metrics are realistic (**Cite Lesson 00010**).

### 3. Training: Adversarial Robustness & Bounded Regression
**Cite Lesson ID: solution_lesson_node_00007, solution_lesson_node_00011**

*   **Structural Innovation (Regularization):** We will wrap the training loop with **Adversarial Weight Perturbation (AWP)**. AWP injects worst-case noise into the model weights during the forward pass and optimizes the loss against this perturbation. This explicitly flattens the loss landscape, preventing the model from converging into the sharp, unstable minima that caused the fold collapse in **Lesson 00011**.
*   **Loss Function:** We will use **BCEWithLogitsLoss** instead of MSE. Since the target scores are bounded in the $[0, 1]$ interval, treating the problem as a probability estimation (soft regression) often yields better gradients at the boundaries (0 and 1) compared to MSE, which assumes a Gaussian distribution.
*   **Schedule:** We will adhere to a **short training horizon (3-4 epochs)**. As proven in **Lesson 00011**, extending training beyond this point for large models yields diminishing returns and increases instability risk. AWP will be activated after the first epoch (warmup).

### 4. Evaluation: Robust Ensemble Inference
**Cite Lesson ID: solution_lesson_node_00010**

*   **Inference:** We will generate predictions for the test set using all 5 models trained during the Cross-Validation phase.
*   **Ensembling:** The final similarity score will be the **arithmetic mean** of the predictions from all folds. This ensemble approach mitigates the variance of individual models and leverages the full diversity of the training data (**Cite Lesson 00010**).
