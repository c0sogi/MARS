The issue is a `torch.OutOfMemoryError` because the batch size of 32 requires more memory than the available GPU capacity (~16GB). To fix this, I will reduce the batch size to 8 and increase `gradient_accumulation_steps` to 4 to maintain an effective batch size of 32. I will also enable gradient checkpointing in the model to significantly reduce memory consumption during the forward pass.
