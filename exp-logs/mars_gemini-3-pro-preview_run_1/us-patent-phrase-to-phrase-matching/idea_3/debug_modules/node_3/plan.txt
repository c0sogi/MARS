The issue stems from passing `classifier_dropout` as a keyword argument to `AutoModelForSequenceClassification.from_pretrained` while also providing a `config` object. When `config` is present, the `transformers` library passes any extra keyword arguments directly to the underlying model's `__init__` method. The `BertForSequenceClassification` model (used by `bert-tiny` in the demo) does not accept `classifier_dropout` in its constructor, raising a `TypeError`. The fix is to set `classifier_dropout` directly on the `self.config` object before creating the model and remove the argument from the `from_pretrained` call.
