The issue is that `StratifiedGroupKFold` in scikit-learn performs a check on the target variable `y`. Since the `score` column contains floating-point numbers (e.g., 0.0, 0.25), scikit-learn identifies the target type as 'continuous', which is not supported for stratification (which requires 'binary' or 'multiclass'). To fix this, we will cast the `score` column to strings specifically within the `split` method. This forces scikit-learn to treat the targets as discrete labels, satisfying the requirement for stratified splitting without altering the actual data used for training.
