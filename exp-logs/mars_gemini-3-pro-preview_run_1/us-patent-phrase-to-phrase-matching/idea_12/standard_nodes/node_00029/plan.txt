Implementation strategy:
1.  **Configuration & Setup**: Initialize the `Config` object with `epochs=2` to balance performance with the "fast baseline" time constraint (approx. 1 hour). Set random seeds for reproducibility.
2.  **Tokenizer**: Load the `deberta-v3-large` tokenizer and resize it to include "Atomic Context" tokens (CPC codes) using the provided `get_tokenizer_and_resize` function.
3.  **Training Loop (Stratified Group K-Fold)**: Iterate through 5 folds. For each fold:
    *   Create train and validation DataLoaders.
    *   Initialize the `CustomDeberta` model and move it to the GPU.
    *   Configure the optimizer with **Layer-wise Learning Rate Decay (LLRD)** to stabilize training.
    *   Train for 2 epochs using Mixed Precision (FP16).
    *   Save the best model checkpoint based on validation Pearson correlation.
    *   Clean up memory (delete model/optimizer) to prevent OOM.
4.  **Hold-out Validation**: Load the unseen `metadata/val.csv` dataset. Perform ensemble inference using all 5 trained models (averaging predictions). Compute and print the final Pearson correlation metric.
5.  **Failure Analysis**: Calculate the absolute error of predictions on the validation set. Compute correlations between this error and input features (e.g., text length, score magnitude) to identify weak points.
6.  **Submission**: If the final validation metric exceeds the threshold (0.8673), generate predictions for the test set (`metadata/test.csv`) using the ensemble, format the output, and save it to `./submission/submission.csv`.
