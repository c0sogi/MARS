### 1. Model: DeBERTa-v3-Large with Atomic Context Embeddings
**Cite Lesson ID: solution_lesson_node_00002, solution_lesson_node_00005, solution_lesson_node_00010, solution_lesson_node_00028**

We will utilize the **`microsoft/deberta-v3-large`** backbone within a **Cross-Encoder** architecture (**Cite Lesson 00002**). This model provides the high capacity required for fine-grained semantic scoring (**Cite Lesson 00010**).

*   **Structural Innovation (Atomic Context Embeddings):** We will fundamentally alter how the model perceives the CPC context. **Lesson 00028** demonstrated that expanding codes into text descriptions degrades performance because it dilutes the signal with semantic noise. Conversely, treating codes as plain text (e.g., "H04") risks sub-optimal tokenization.
    *   We will explicitly add all unique CPC codes (e.g., "A47", "H04") to the tokenizer's vocabulary as **new special tokens**. We will then resize the model's embedding layer to accommodate them.
    *   This forces the model to learn a dedicated, dense vector representation for each domain context, maximizing the "Latent Representation" efficiency identified in **Lesson 00028** while avoiding the noise of natural language definitions.
*   **Head Design:** We will use the **Standard Classification Head** (`AutoModelForSequenceClassification`). As established in **Lesson 00024**, complex heads like Multi-Sample Dropout slow down convergence. Given the need for a short, stable training run, the pre-optimized standard head is superior (**Cite Lesson 00005**).

### 2. Data: Context-Prefixed Native Pair Encoding
**Cite Lesson ID: solution_lesson_node_00001, solution_lesson_node_00022**

*   **Input Construction:** We will strictly adhere to **Native Pair Encoding** to ensure the model receives the correct segment signals (**Cite Lesson 00022**). We will construct the input as two distinct segments passed to the tokenizer's `text` and `text_pair` arguments.
    *   **Segment A (Query):** We will prepend the **Atomic Context Token** to the Anchor phrase.
        *   Format: `[Context_Token] + " " + Anchor Phrase`
    *   **Segment B (Candidate):** `Target Phrase`
    *   This structure `[CLS] [Context_Token] Anchor [SEP] Target [SEP]` allows the self-attention mechanism to condition the Anchor's representation on the specific domain embedding *before* comparing it to the Target, without the tokenizer treating the context as a sequence of fragmented subwords.
*   **Splitting:** We will employ **Stratified Group K-Fold Cross-Validation** (5 folds). We will group by the `anchor` phrase to strictly prevent "anchor leakage" and stratify by the discrete `score` to maintain class balance (**Cite Lesson 00010**).

### 3. Training: Stabilized Regression with Layer-wise Decay
**Cite Lesson ID: solution_lesson_node_00007, solution_lesson_node_00011, solution_lesson_node_00018, solution_lesson_node_00019**

*   **Loss Function:** We will use **Mean Squared Error (MSE) Loss**. We explicitly reject Binary Cross Entropy (BCE) because MSE aligns geometrically with the Pearson correlation metric (linear dependence), whereas BCE induces non-linear distortions (**Cite Lesson 00018**).
*   **Structural Innovation (Optimization):** To ensure stability without the convergence penalty of complex heads, we will rely on **Layer-wise Learning Rate Decay (LLRD)**. We will assign a high learning rate to the classification head and new context embeddings, while multiplicatively decaying the rate (e.g., 0.9x) for each subsequent lower layer. This preserves the robust pre-trained features of the backbone while allowing the new context tokens to be learned aggressively (**Cite Lesson 00019**).
*   **Schedule:** We will set the training duration to **4 epochs**. This strikes the optimal balance between the under-training observed at 2-3 epochs and the diminishing returns/instability of longer schedules (**Cite Lesson 00007, 00011**).
*   **Hardware Optimization:** We will use **Mixed Precision (FP16)** and **Gradient Accumulation** to fit the large model into memory (**Cite Lesson 00010**).

### 4. Evaluation: Robust Ensemble Inference
**Cite Lesson ID: solution_lesson_node_00010**

*   **Inference:** We will generate predictions for the test set using all 5 models trained during the Stratified Group K-Fold Cross-Validation.
*   **Ensembling:** The final submission score for each pair will be the **arithmetic mean** of the predictions from the 5 folds. This ensemble approach mitigates the variance of individual models and leverages the full diversity of the training data to maximize the Pearson correlation (**Cite Lesson 00010**).
