### 1. Model: DeBERTa-v3-Large with Multi-Sample Dropout (MSD)
**Cite Lesson ID: solution_lesson_node_00002, solution_lesson_node_00010, solution_lesson_node_00019**

We will employ the **`microsoft/deberta-v3-large`** backbone within a **Cross-Encoder** architecture. This model's disentangled attention mechanism provides the high capacity required for fine-grained semantic scoring (**Cite Lesson 00010**), significantly outperforming Bi-Encoders (**Cite Lesson 00002**).

*   **Structural Innovation (Head Design):** We will replace the standard classification head with a **Multi-Sample Dropout (MSD)** module. Instead of a single dropout pass, this module instantiates multiple dropout masks (e.g., 5) in parallel during the forward pass. The embeddings are passed through each mask, projected to the scalar output, and averaged *before* loss calculation. This acts as an internal ensemble, smoothing the loss landscape and improving generalization. This structural change is critical for stabilizing the training of large models, as identified in **Lesson 00019**.

### 2. Data: Tri-Segment Semantic Input via Native Pair Encoding
**Cite Lesson ID: solution_lesson_node_00001, solution_lesson_node_00022**

*   **Semantic Expansion:** We will parse `input/description.md` to map the cryptic CPC codes (e.g., "H04") to their **full hierarchical natural language descriptions** (e.g., "ELECTRICITY; ELECTRIC COMMUNICATION TECHNIQUE"). This injects explicit domain definitions (**Cite Lesson 00001**).
*   **Structural Innovation (Input Construction):** We will implement a **Tri-Segment Input** strategy while strictly adhering to **Native Pair Encoding** to ensure correct tokenization (**Cite Lesson 00022**).
    *   We will construct the first text segment by concatenating the Context Description and the Anchor Phrase, separated by the tokenizer's special separator token.
    *   **Segment A:** `Context_Description + tokenizer.sep_token + Anchor_Phrase`
    *   **Segment B:** `Target_Phrase`
    *   We will pass these as `text` and `text_pair` arguments to the tokenizer. This results in a sequence structure effectively like `[CLS] Context [SEP] Anchor [SEP] Target [SEP]`. This allows the model's self-attention to explicitly distinguish three information blocks (Domain, Query, Candidate) while maintaining the correct segment IDs for the Cross-Encoder.
*   **Splitting:** We will use **Stratified Group K-Fold Cross-Validation** (5 folds). We will group by the `anchor` phrase to strictly prevent "anchor leakage" and stratify by the discrete `score` (**Cite Lesson 00010**).

### 3. Training: Stabilized Regression with Layer-wise Decay
**Cite Lesson ID: solution_lesson_node_00007, solution_lesson_node_00011, solution_lesson_node_00018, solution_lesson_node_00019, solution_lesson_node_00024**

*   **Loss Function:** We will use **Mean Squared Error (MSE) Loss**. We explicitly reject Binary Cross Entropy (BCE) because MSE aligns geometrically with the Pearson correlation metric (linear dependence), whereas BCE induces non-linear distortions that can degrade performance (**Cite Lesson 00018**).
*   **Structural Innovation (Optimization):** To address the instability and "fold collapse" observed in **Lesson 00011**, we will implement **Layer-wise Learning Rate Decay (LLRD)**. We will assign a high learning rate to the MSD head and multiplicatively decay the rate (e.g., 0.9x) for each subsequent lower layer of the Transformer. This ensures that the pre-trained linguistic features in the lower layers remain stable while the top layers adapt to the task (**Cite Lesson 00019**).
*   **Schedule:** We will set the training duration to **4 epochs**. This strikes the optimal balance between the under-training observed at 2 epochs (**Cite Lesson 00024**) and the instability/diminishing returns observed at 5 epochs (**Cite Lesson 00011**).
*   **Hardware Optimization:** We will use **Mixed Precision (FP16)** and **Gradient Accumulation** to fit the large model and sufficient batch sizes into the A100 GPU memory (**Cite Lesson 00010**).

### 4. Evaluation: Robust Ensemble Inference
**Cite Lesson ID: solution_lesson_node_00010**

*   **Inference:** We will generate predictions for the test set using all 5 models trained during the Stratified Group K-Fold Cross-Validation.
*   **Ensembling:** The final submission score for each pair will be the **arithmetic mean** of the predictions from the 5 folds. This ensemble approach mitigates the variance of individual models and leverages the full diversity of the training data to maximize the Pearson correlation (**Cite Lesson 00010**).
