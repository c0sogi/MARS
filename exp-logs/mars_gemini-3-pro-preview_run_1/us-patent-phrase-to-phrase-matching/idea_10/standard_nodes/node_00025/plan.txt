### Implementation Strategy

1.  **Configuration & Setup**: We initialize the `Config` class and override specific parameters (`epochs=2`, `n_folds=4`, `train_batch_size=16`) to ensure the pipeline executes within the 2-hour "fast baseline" limit while utilizing the A100 GPU efficiently.
2.  **Data Loading**: We use the provided `get_data_splits` to load the training data and generate stratified group folds. We also manually load and process the hold-out validation set (`metadata/val.csv`) by mapping CPC codes to their text descriptions using `get_cpc_texts`.
3.  **Model Training**: We iterate through 4 folds. For each fold, we:
    *   Initialize the `CustomModel` (DeBERTa-v3-large with Multi-Sample Dropout).
    *   Configure the optimizer with Layer-wise Learning Rate Decay (LLRD) using `get_optimizer_params`.
    *   Train for 2 epochs using `train_fn`, saving the model checkpoint with the best validation Pearson correlation.
4.  **Final Validation**: After training, we load the best models from all folds and perform ensemble inference on the hold-out validation set. We calculate the final Pearson correlation metric.
5.  **Failure Analysis**: We compute the absolute error of the predictions on the validation set and calculate correlations between the error magnitude and input features (e.g., text lengths) to identify systematic weaknesses.
6.  **Submission**: If the final validation metric exceeds the threshold (0.8673), we process the test set (`metadata/test.csv`), generate predictions using the model ensemble, and save the result to `submission.csv`.
