### Implementation Strategy

3.  **Data Processing**: Use `get_processed_data` to generate feature sets (sliding windows) for training, validation, and testing. Force `load_cached_data=False` to ensure the "debug" subset is processed fresh.
4.  **Data Loading**: Instantiate `QADataset` and PyTorch `DataLoader`s for the processed features. Verify the integrity of the batches (shapes and data types).
5.  **Model Setup**: Load the pre-trained XLM-Roberta model using `get_model`. Configure the optimizer (`AdamW`) and learning rate scheduler.
6.  **Training Demonstration**: Run `train_fn` for a single epoch on the small subset. Assert that the loss is a valid number.
7.  **Evaluation Demonstration**: Load the raw validation data (required for text extraction). Run `eval_fn` to compute the Jaccard score. Assert the score is within the valid range [0, 1].
8.  **Inference Demonstration**: Load the raw test data. Run `predict_fn` to generate answers. Verify the output format (dictionary mapping IDs to strings).
9.  **Submission Generation**: Use `save_submission` to write the results to a CSV file. Verify the file is created and follows the correct schema.
