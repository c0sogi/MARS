The implementation strategy involves the following steps:

1.  **Setup and Loading**: Define the input (`./input`) and output (`./metadata`) directories. Load the raw `train.csv` and `test.csv` files using pandas.
2.  **Grouped Splitting**: To create a validation set, use `GroupShuffleSplit` from scikit-learn. The `context` column will serve as the group identifier. This ensures that all questions derived from the same paragraph (context) are placed in the same split (either training or validation), preventing data leakage where the model could "memorize" the context from the training set to answer questions in the validation set. We will target an 80:20 split with a fixed random state of 42.
3.  **Metadata Generation**: Save the resulting training, validation, and test dataframes as CSV files in the `./metadata` directory. These files will contain the actual text data, serving as the metadata/index for downstream tasks.
4.  **Validation**:
    *   **Load**: Immediately reload the generated files from `./metadata`.
    *   **Statistics**: Print the shape and language distribution (Hindi/Tamil) for each dataset.
    *   **Path Check**: Implement a check that scans columns for file path patterns. Since this dataset contains raw text and not file paths, this check will report that no paths were found, fulfilling the requirement logic safely.
    *   **Split Verification**: Programmatically assert that the intersection of `context` values between the training and validation sets is empty (verifying the group split). Also, check that the split ratio is approximately correct.
