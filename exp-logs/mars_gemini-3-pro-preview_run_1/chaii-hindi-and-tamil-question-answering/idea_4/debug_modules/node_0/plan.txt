This script demonstrates the end-to-end usage of the provided library for the Hindi/Tamil Question Answering task. It begins by configuring the environment for a rapid demonstration run by enabling debug mode and reducing the number of epochs and data samples. It then proceeds to verify the data loading pipeline, ensuring that the training and validation datasets are correctly processed and tokenized. Following this, the script initializes the MuRIL-based model and executes a short training loop to verify the training runner and checkpoint saving mechanism. Once a model checkpoint is generated, the script demonstrates the inference pipeline, including feature extraction, logit computation, and the ensemble post-processing step to generate final predictions. Throughout the execution, assertions are used to validate the correctness of tensor shapes, data types, and output formats. Finally, the metric function is verified with standard test cases.
