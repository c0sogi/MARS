The `RuntimeError` is caused by a dimension mismatch in the model's forward pass because `token_type_ids` are being generated as scalars instead of sequences (lists) when the tokenizer does not provide them (e.g., XLM-Roberta). The current implementation `tokenized_inputs.get("token_type_ids", [0] * len(input_ids))[i]` constructs a default list of zeros for the sequence length but then immediately indexes it with `[i]`, resulting in a single integer `0` instead of the full list of zeros for the i-th window.

To fix this, I will update `prepare_train_features` and `prepare_test_features` in `library/data_loader.py` to correctly assign `token_type_ids`. If the key is missing from `tokenized_inputs`, I will explicitly generate a list of zeros of length `len(input_ids)` for the current window, ensuring the resulting tensor has the correct shape `(batch_size, seq_len)`.
