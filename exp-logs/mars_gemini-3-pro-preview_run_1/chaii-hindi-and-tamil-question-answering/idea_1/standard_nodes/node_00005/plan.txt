Implementation Strategy:
1.  **Exhaustive Sliding Window (Dataset):** I will modify `QADataset` in `library/dataset.py` to implement an exhaustive sliding window strategy for validation and test sets (Cite solution_lesson_node_00004). Instead of selecting a single window based on heuristic overlap, the dataset will pre-process documents into multiple overlapping chunks (windows). This ensures the model has access to the complete text of long documents, eliminating the retrieval bottleneck.
2.  **Aggregation Logic (Trainer & Inference):** I will update `Trainer.evaluate` in `library/trainer.py` and `generate_predictions` in `library/inference.py` to handle the multi-window output. The logic will collect all predictions for a given document ID and select the final answer using the "longest predicted string" heuristic, which has been shown to improve recall in this task.
3.  **Consistency:** I will ensure the `QADataset` passes the full original context string in the batch metadata so that the `find_best_substring` post-processing function can accurately map the generated answer back to the original text.
