This script demonstrates the end-to-end usage of the provided library for the Question Answering task. It covers configuration setup, data loading, model instantiation, a quick training run on a subset of data, inference, and metric calculation.

The strategy is as follows:
1.  **Configuration**: Initialize the `Config` class in debug mode and override specific parameters (epochs, batch size) to ensure the script runs very quickly (within a few minutes).
2.  **Data Preparation**: Load the datasets using `get_data`. We verify the data integrity and create a small subset of the training data to speed up the training demonstration.
3.  **Model Verification**: Instantiate the `XLMRobertaForQA` model and perform a dummy forward pass to verify the architecture and output shapes.
4.  **Training**: Run the `train_model` function using the small data subset. This verifies the training loop, loss calculation, and model saving mechanisms.
5.  **Inference**: Execute `generate_submission` to run the trained model on the test set and generate the submission file.
6.  **Metric Check**: Validate the provided `jaccard` utility function with known inputs.
