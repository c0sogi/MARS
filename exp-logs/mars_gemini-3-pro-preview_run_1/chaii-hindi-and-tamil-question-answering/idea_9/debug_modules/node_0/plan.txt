This script demonstrates the end-to-end usage of the provided library files for the Question Answering task. It covers configuration setup, data processing with sliding windows, model instantiation, training with adversarial regularization (FGM), and inference. To ensure the demonstration runs quickly within the time limit, it uses the `debug` mode (processing only a small subset of data) and overrides the model architecture to the smaller `xlm-roberta-base` variant. It includes assertions to verify the correctness of data shapes, model outputs, and metric calculations.
