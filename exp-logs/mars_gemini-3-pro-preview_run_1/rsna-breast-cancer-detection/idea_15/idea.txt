Based on the progression of empirical findings—specifically the need to mitigate the "Age Shortcut" (Cite solution_lesson_node_00012, solution_lesson_node_00014), the superiority of Single-Task Learning (Cite solution_lesson_node_00021), and the requirement for robust feature alignment to enable effective symmetry analysis—I propose the **FPN-Enhanced Deformable Siamese Network**.

This architecture represents a structural evolution of the "Deformable Siamese" concept (Idea 14). By integrating a **Feature Pyramid Network (FPN)** *within* the Siamese branches, we enrich the fine-grained texture maps (critical for microcalcifications) with global semantic context (critical for alignment) before the difference operation. This ensures that the difference map captures true anatomical asymmetry rather than misalignment noise, while mathematically neutralizing demographic bias.

### Model
**Architecture: FPN-Enhanced Deformable Siamese EfficientNet-B2**

*   **Siamese Backbone:** Utilize **EfficientNet-B2** in a Siamese configuration (shared weights). This processes both the **Target Image** and the **Contralateral Image** (opposing breast, same view) identically.
*   **Input Strategy (Early Fusion):**
    *   Retain **Spatial Channel Expansion** (Cite solution_lesson_node_00002).
    *   Input tensors are $3 \times 768 \times 768$, comprising the **Image**, a spatially broadcasted **Age** map, and a spatially broadcasted **Implant** map.
    *   **Demographic Cancellation:** Since Age/Implant maps are spatially constant for a patient, they are preserved during warping and cancelled during subtraction, preventing the "Age Shortcut."
*   **Shared Feature Pyramid Network (Structural Innovation):**
    *   Instead of processing backbone levels (P3, P4, P5) independently, pass them through a shared **BiFPN** or **FPN** neck.
    *   *Rationale:* This propagates strong semantic information (e.g., breast boundaries, pectoral muscle location) from P5 down to the high-resolution P3 layers. This global context is crucial for the subsequent alignment step to correctly register tissues, which simple independent-level alignment often fails to do.
*   **Deformable Alignment & Difference Module:**
    *   For each FPN-enhanced level, concatenate Target and Contralateral features to predict dense offsets.
    *   Apply **Deformable Resampling** to the Contralateral features using these offsets.
    *   Compute the **Aligned Difference**: $D = F_{target} - F'_{contra}$. This suppresses symmetric tissue (density) and demographic embeddings, isolating the asymmetric lesion signal.
*   **Fusion Head:**
    *   Concatenate **Global Average Pooled** vectors of the Target features ($F_{target}$) and the Difference features ($D$) from all FPN levels.
    *   Pass through a single dense layer for binary classification.

### Data
**Preprocessing & Augmentation**

*   **Paired Data Loading:**
    *   Load (Target, Contralateral) pairs. If a physical contralateral is missing, substitute a zero-tensor.
    *   **Fail Loudly:** The data loader must **raise an exception** immediately if a file is missing or corrupt. Do not use silent fallbacks (e.g., black images) for I/O errors, as this causes model collapse (Cite solution_lesson_node_00016).
*   **Normalization:**
    *   Apply **Standard Scaling** (Zero Mean, Unit Variance) to the Age metadata before broadcasting. This ensures the scalar signal has unit variance and does not dominate gradients (Cite solution_lesson_node_00005).
*   **Augmentation:**
    *   **Synchronized Geometric Augmentation:** Apply identical random spatial transformations (Flip, Rotate, Shift) to both images to maintain global correspondence (Cite solution_lesson_node_00007).
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts. Preserving absolute pixel intensity (density) is critical for this modality (Cite solution_lesson_node_00008).

### Training
**Procedure**

*   **Objective:** **Single-Task Learning (STL)**.
    *   Train exclusively on the binary cancer target. Do not use auxiliary heads for Breast Density or other attributes.
    *   *Rationale:* Auxiliary tasks on global features are "easier" to learn and have been proven to exacerbate age bias, leading to negative transfer (Cite solution_lesson_node_00021).
*   **Loss Function:** `BCEWithLogitsLoss` with `pos_weight` set to **47.0**.
    *   Aggressive positive weighting is required to maintain Probabilistic Recall in this 1:47 imbalance regime (Cite solution_lesson_node_00003).
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   Clipping gradients neutralizes the high `pos_weight`, preventing the necessary large updates for the minority class (Cite solution_lesson_node_00009).
*   **Optimizer:** AdamW (LR 1e-4) with Cosine Annealing.

### Evaluation
**Inference Pipeline**

*   **Pair Construction:** Iterate through `test.csv`. For each prediction row, identify and load the matching contralateral view.
*   **Prediction:** Pass the pair through the FPN-Enhanced Siamese network.
*   **Aggregation:** Group predictions by `prediction_id` (breast level). Compute the **Max** probability across all available views (CC and MLO) for that breast to generate the final submission.
