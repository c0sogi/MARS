The following script demonstrates the end-to-end usage of the provided breast cancer detection library.

**Implementation Strategy:**
1.  **Configuration Setup**: We first override the default `Config` parameters to create a "Debug Mode". This includes reducing the number of epochs to 1, batch size to 2, and disabling multiprocessing workers. We also redirect output paths to a temporary working directory to avoid clutter.
2.  **Data Subsetting**: To ensure the script runs quickly (under 1 hour) and uses valid data, we scan the provided metadata files. We filter for rows where the actual image files exist on disk (based on the provided input directory structure) and create tiny subsets (e.g., 16 samples) for training, validation, and testing. These subsets are saved to a temporary location.
3.  **Component Verification**:
    *   **Metric**: We validate the `pf1_score` function with a manual calculation.
    *   **Dataset/Loader**: We instantiate the DataLoaders using the subsetted metadata and verify the output tensor shapes (Batch, Channels, Height, Width) and types. We confirm the input channels include the image, age map, and implant map.
    *   **Model**: We instantiate the `SiameseFPNEfficientNet`, perform a forward pass with a dummy batch, and verify the output shape and gradient propagation.
4.  **Training & Inference Execution**:
    *   We execute the `run_training()` function to train the model on the tiny subset for one epoch.
    *   We execute `predict_submission()` to generate predictions on the test subset.
5.  **Final Validation**: We assert that the model checkpoint and submission file were successfully created and that the submission file follows the required format.
