Based on the progression of empirical findings—specifically the success of the Siamese architecture in reducing demographic bias (Lesson 00021) and the limitations of global pooling in preserving fine-grained details—I propose a **Spatial Symmetry-Difference Siamese Network**.

This approach evolves the previous "Global Difference" strategy (Idea 5) into a **"Spatial Difference"** strategy. By comparing the target and contralateral breasts at the *feature map* level (before global pooling), the model can explicitly localize asymmetric anomalies (tumors) while suppressing symmetric background tissue patterns, which are strongly correlated with Age and Density.

### Model
**Architecture: Spatial Symmetry-Difference Siamese EfficientNet-B2**

*   **Backbone:** **EfficientNet-B2** in a Siamese configuration (shared weights).
*   **Input Strategy (Early Fusion):**
    *   The network accepts a **pair** of inputs: the **Target Image** (the breast to be classified) and the **Contralateral Image** (the opposing breast, same view).
    *   Each input utilizes **Spatial Channel Expansion** (*Cite Lesson 00002*): The tensor is $3 \times 768 \times 768$, comprising the Image, Spatially Broadcasted Age, and Spatially Broadcasted Implant status.
*   **Spatial Fusion Mechanism (The Innovation):**
    *   Instead of pooling features immediately, extract the final convolutional feature maps from the backbone for both inputs: $M_{target}, M_{contra} \in \mathbb{R}^{C \times H' \times W'}$.
    *   Compute the **Spatial Difference Map**: $M_{diff} = M_{target} - M_{contra}$. This operation mathematically cancels out symmetric global features (like dense tissue patterns common to both breasts) at every spatial location, leaving high activation only where local anomalies exist.
    *   **Concatenation:** Stack the maps along the channel dimension: $M_{fused} = \text{Concat}(M_{target}, M_{diff})$. This preserves the texture of the target breast (necessary for characterization) while explicitly providing the asymmetry signal.
*   **Classification Head:**
    *   Pass $M_{fused}$ through a lightweight **Depthwise Separable Convolution** block to mix the target and difference features.
    *   Apply **Global Average Pooling** followed by a single dense layer to predict the cancer probability.

### Data
**Preprocessing & Augmentation**

*   **Paired Data Loading:**
    *   Construct pairs based on `patient_id` and `view` (e.g., match Left CC with Right CC).
    *   **Handling Missing Counterparts:** If a contralateral image is unavailable, substitute a **zero-tensor (black image)**. The network will interpret $M_{diff} \approx M_{target}$, effectively falling back to standard single-image classification for these cases.
    *   **Fail Loudly:** The data loader must **raise an exception** if a file exists in metadata but cannot be read. Do not use silent fallbacks. (*Cite Lesson 00016*)
*   **Normalization:**
    *   Apply **Standard Scaling** (Zero Mean, Unit Variance) to the Age metadata before broadcasting. (*Cite Lesson 00005*)
*   **Augmentation:**
    *   **Synchronized Geometric Augmentation:** Apply identical random spatial transformations (Flip, Rotate, Shift) to both the target and contralateral images to maintain pixel-wise correspondence for the difference operation.
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts, as these destroy the density signal. (*Cite Lesson 00008*)

### Training
**Procedure**

*   **Objective:** **Single-Task Learning**. Train exclusively on the binary cancer target.
    *   Do not use auxiliary heads for Density. (*Cite Lesson 00021*: Auxiliary tasks on global features distract the model and increase age bias).
*   **Loss Function:** `BCEWithLogitsLoss` with `pos_weight` set to **47.0**.
    *   (*Cite Lesson 00003*: Aggressive positive weighting is required to maintain Probabilistic Recall in this 1:47 imbalance regime).
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   (*Cite Lesson 00009*: Clipping gradients neutralizes the high `pos_weight`, preventing the model from prioritizing the minority class).
*   **Optimizer:** AdamW (LR 1e-4) with Cosine Annealing.

### Evaluation
**Inference Pipeline**

*   **Pair Construction:** Iterate through `test.csv`. For each row, identify and load the matching contralateral image.
*   **Prediction:** Pass the pair through the Spatial Symmetry-Difference model.
*   **Aggregation:** Group predictions by `prediction_id` (breast level). Compute the **Max** probability across all views (CC and MLO) for that breast to generate the final submission.
