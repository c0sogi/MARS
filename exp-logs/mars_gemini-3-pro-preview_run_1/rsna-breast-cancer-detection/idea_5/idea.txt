Based on the progression of empirical findings—specifically the persistent issue of the model relying on demographic "shortcuts" (Age) despite auxiliary tasks (Lesson 00012, 00021) and the instability of destructive regularization like Modality Dropout (Lesson 00019)—I propose a **Symmetry-Aware Siamese Architecture**.

This approach structurally forces the model to focus on **asymmetry** (a primary indicator of malignancy) rather than global tissue texture or age, which are generally symmetric across breasts.

### Model
**Architecture: Symmetry-Aware Siamese EfficientNet-B2**

*   **Core Concept:** Instead of processing a single image in isolation, the model will process a **pair** of images: the target view (e.g., Left MLO) and its **contralateral counterpart** (e.g., Right MLO) from the same patient.
*   **Backbone:** Use **EfficientNet-B2** with shared weights (Siamese configuration). This ensures both images are processed by the exact same feature extractor.
*   **Input Strategy (Early Fusion):** Both the target and contralateral images will utilize the **Spatial Channel Expansion** technique.
    *   Input Tensor: $3 \times H \times W$ (Image + Spatially Broadcasted Age + Spatially Broadcasted Implant).
    *   *Cite Lesson 00002:* This retains the proven capability of early layers to learn context-aware features.
    *   *Cite Lesson 00005:* The Age channel must be **Standard Scaled** (Zero Mean, Unit Variance) to prevent it from dominating the visual signal.
*   **Feature Fusion:**
    *   The backbone outputs global feature vectors for the target ($f_{target}$) and contralateral ($f_{contra}$) images.
    *   Construct a combined feature vector: $F = \text{Concat}(f_{target}, |f_{target} - f_{contra}|)$.
    *   *Rationale:* The difference term $|f_{target} - f_{contra}|$ mathematically cancels out features common to both breasts (e.g., global density patterns, age-related tissue structure) while highlighting asymmetric anomalies (tumors). This structurally mitigates the "Age Shortcut" problem identified in *Lesson 00021*.
*   **Classification Head:** A single dense layer processes $F$ to predict the probability of cancer in the *target* breast.

### Data
**Preprocessing & Augmentation**

*   **Paired Data Loading:**
    *   The dataset class must be modified to identify and load the matching contralateral image for every training sample.
    *   **Handling Missing Pairs:** If a contralateral image is missing (e.g., patient only has Left views), substitute a black placeholder image. The network will learn that "difference against black" implies "rely on absolute features," ensuring robustness.
    *   **Fail Loudly:** Raise an explicit exception if a file path exists in metadata but the file is unreadable. *Cite Lesson 00016.*
*   **Resolution:** Resize all images to **768x768** to capture microcalcifications.
*   **Augmentation:**
    *   **Synchronized Geometric Augmentation:** Apply the *same* random geometric transformation (Flip, Rotate, Shift) to both the target and contralateral image to maintain spatial correspondence.
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts. *Cite Lesson 00008:* Preserving absolute density values is critical for this modality.

### Training
**Procedure**

*   **Objective:** **Single-Task Learning**.
    *   Train exclusively on the binary cancer target. Do not use auxiliary density heads.
    *   *Cite Lesson 00021:* Auxiliary tasks on "easier" global features (like density) lead to negative transfer and increased age bias. The Siamese difference operation handles the density signal implicitly.
*   **Loss Function:** `BCEWithLogitsLoss` with `pos_weight` set to **47.0**.
    *   *Cite Lesson 00003:* Aggressive positive weighting is non-negotiable for maintaining Probabilistic Recall in this 1:47 imbalance regime.
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   *Cite Lesson 00009:* Clipping gradients neutralizes the effect of the high `pos_weight`, causing the model to collapse to the majority class.
*   **Optimizer:** AdamW with learning rate 1e-4 and Cosine Annealing.

### Evaluation
**Inference Pipeline**

*   **Pair Construction:** For every row in `test.csv`, identify the contralateral file path using the patient ID and view columns.
*   **Prediction:** Pass the pair through the Siamese network.
*   **Aggregation:** Group predictions by `prediction_id` (breast level). Compute the **Max** probability across all views (CC and MLO) for that breast to generate the final submission score.
