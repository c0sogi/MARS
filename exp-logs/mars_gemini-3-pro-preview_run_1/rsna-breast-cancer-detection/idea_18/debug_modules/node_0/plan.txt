This script demonstrates the end-to-end pipeline for the Breast Cancer Detection task using the provided library files. It validates the core components including the probabilistic metric, image loading, data augmentation, the Siamese dataset structure, the custom model architecture, and the training/inference engine.

To ensure rapid execution within the demonstration limits, the script monkey-patches the `Config` class to enable `DEBUG` mode (using a small subset of data) and reduces the training duration to 1 epoch.
