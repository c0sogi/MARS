The following script demonstrates the end-to-end usage of the provided library for the breast cancer detection task.

### Strategy
1.  **Configuration**: We override the `Config` class to enable `DEBUG` mode, reduce `EPOCHS` to 1, and set a small `BATCH_SIZE` and sample size. This ensures the code runs to completion quickly (within minutes) while exercising all logic paths.
2.  **Verification**:
    *   **Utils**: We validate the `probabilistic_f1` metric with a synthetic test case.
    *   **Dataset**: We instantiate the `SiameseBreastCancerDataset` to verify it can load metadata, handle missing files (via sampling), and produce tensors of the correct shape `(3, 768, 768)`.
    *   **Model**: We perform a forward pass with dummy data on the `PyramidSiameseEfficientNet` to confirm the architecture produces the expected output shape `(Batch, 1)`.
3.  **Pipeline Execution**:
    *   **Training**: We call `train()` to execute the training loop, ensuring the loss decreases and the model artifact is saved.
    *   **Inference**: We call `predict()` to generate predictions on the test set and verify the `submission.csv` format.
