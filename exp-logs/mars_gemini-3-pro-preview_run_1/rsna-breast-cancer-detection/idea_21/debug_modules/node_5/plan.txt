The issue is that the `Config` class defaults to `NUM_WORKERS = 12`, causing the script to spawn 12 worker processes even in debug mode. These processes consume significant system RAM and file descriptors, leading to resource exhaustion that prevents the CUDA driver from initializing, which manifests as a `CUDA error: out of memory` (Cite debug_lesson_32). The fix is to override `NUM_WORKERS` to 0 within `Config.setup` when `debug=True`, ensuring data loading occurs in the main process.
