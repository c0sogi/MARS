Based on the progression of empirical findings—specifically the persistent "Age Shortcut" bias observed in single-stream models (Cite solution_lesson_node_00012, solution_lesson_node_00014) and the superiority of Single-Task Learning over Multi-Task Learning (Cite solution_lesson_node_00021)—I propose a **Spatial Symmetry-Difference Siamese Network**.

This architecture structurally enforces the model to learn **asymmetry** (the primary biomarker for malignancy) rather than relying on global demographic priors (Age) or tissue texture (Density), which are symmetric across breasts.

### Model
**Architecture: Spatial Symmetry-Difference Siamese EfficientNet-B2**

*   **Siamese Backbone:** Utilize **EfficientNet-B2** in a Siamese configuration (shared weights). This ensures that both the target and contralateral images are processed by the exact same feature extractor, making their feature maps directly comparable.
*   **Input Strategy (Early Fusion):**
    *   The network accepts a **pair** of inputs: the **Target Image** (candidate for cancer) and the **Contralateral Image** (opposing breast, same view).
    *   Each input utilizes **Spatial Channel Expansion** (Cite solution_lesson_node_00002): The input tensor is $3 \times 768 \times 768$, comprising the **Image**, a spatially broadcasted **Age** map, and a spatially broadcasted **Implant** map.
    *   *Crucial Detail:* Since the Age and Implant maps are identical for both the left and right breasts of the same patient, they will mathematically cancel out in the difference operation described below, strictly preventing the "Age Shortcut" in the asymmetry stream.
*   **Spatial Fusion Mechanism (The Innovation):**
    *   Extract the final convolutional feature maps from the backbone for both inputs: $M_{target}$ and $M_{contra}$.
    *   Compute the **Spatial Difference Map**: $M_{diff} = M_{target} - M_{contra}$. This operation suppresses symmetric background tissue (dense tissue, age-related patterns) while highlighting asymmetric anomalies (tumors).
    *   **Concatenation:** Stack the maps: $M_{fused} = \text{Concat}(M_{target}, M_{diff})$. This preserves the local texture context of the target breast (via $M_{target}$) while explicitly providing the asymmetry signal (via $M_{diff}$).
*   **Classification Head:** A depthwise separable convolution block followed by Global Average Pooling and a single dense layer to predict the binary cancer probability.

### Data
**Preprocessing & Augmentation**

*   **Paired Data Loading:**
    *   Construct training pairs by matching `patient_id` and `view` (e.g., Left CC paired with Right CC).
    *   **Fail Loudly:** The data loader must **raise an exception** immediately if a file is missing or corrupt. Do not use silent fallbacks (e.g., returning black images), as this caused model collapse in previous iterations (Cite solution_lesson_node_00016).
    *   **Handling Missing Counterparts:** Only for cases where a patient physically lacks a contralateral image, substitute a zero-tensor.
*   **Normalization:**
    *   Apply **Standard Scaling** (Zero Mean, Unit Variance) to the Age metadata before spatial broadcasting. This prevents the scalar value from being overpowered by image features or dominating gradients (Cite solution_lesson_node_00005).
*   **Augmentation:**
    *   **Synchronized Geometric Augmentation:** Apply identical random spatial transformations (Flip, Rotate, Shift) to *both* the target and contralateral images simultaneously. This preserves the pixel-wise correspondence required for the difference operation (Cite solution_lesson_node_00007).
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts. In mammography, absolute pixel intensity represents physical tissue density; altering it destroys the diagnostic signal (Cite solution_lesson_node_00008).

### Training
**Procedure**

*   **Objective:** **Single-Task Learning (STL)**.
    *   Train exclusively on the binary cancer target. Do not use auxiliary heads for Breast Density.
    *   *Rationale:* Auxiliary tasks on global features (like density) are easier to learn than lesion detection and exacerbate the age bias, leading to negative transfer (Cite solution_lesson_node_00021).
*   **Loss Function:** `BCEWithLogitsLoss` with `pos_weight` set to **47.0** (approximating the inverse class frequency).
    *   Aggressive positive weighting is required to maintain Probabilistic Recall in this highly imbalanced regime (Cite solution_lesson_node_00003).
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   Clipping gradients neutralizes the effect of the high `pos_weight`, preventing the optimizer from making the large updates necessary to correct errors on the minority class (Cite solution_lesson_node_00009).
*   **Optimizer:** AdamW (LR 1e-4) with a Cosine Annealing scheduler.

### Evaluation
**Inference Pipeline**

*   **Pair Construction:** Iterate through `test.csv`. For each prediction row, identify the file path for the contralateral view (same patient, same view, opposite laterality).
*   **Prediction:** Pass the pair through the Siamese network.
*   **Aggregation:** Group predictions by `prediction_id` (which represents a specific breast). Compute the **Max** probability across all available views (CC and MLO) for that breast to generate the final submission score.
