To address the `CUDA error: out of memory` occurring during model initialization, I will modify `runfile.py` to implement an aggressive resource cleanup strategy. This issue arises because the script runs in a persistent environment where variables from previous executions (like models and optimizers) remain in the global scope ("zombie" objects), preventing the GPU memory from being freed (Cite debug_lesson_7).

My fix involves:
1.  Importing `gc` and `torch.optim` to support the cleanup logic.
2.  Defining a `cleanup_gpu` function that:
    *   Clears `sys.last_traceback` to release stack frames.
    *   Iterates through the global namespace to identify and delete persistent instances of `torch.Tensor`, `torch.nn.Module`, and `torch.optim.Optimizer` (Cite debug_lesson_15).
    *   Forces garbage collection and clears the CUDA cache.
3.  Calling `cleanup_gpu()` at the very beginning of `run_demo` to ensure the GPU is reset before allocating the new model.

def cleanup_gpu():
    """
    Aggressively clears GPU memory by removing 'zombie' objects from the global scope
    and forcing garbage collection.
    """
    print("Cleaning up GPU resources...")
    
    # 1. Clear sys.last_traceback to free stack frames
    if hasattr(sys, 'last_traceback'):
        del sys.last_traceback
        
    # 2. Iterate through globals to find and delete PyTorch objects
    # We use list(globals().keys()) to avoid 'dictionary changed size during iteration'
    for name in list(globals().keys()):
        if name in globals():
            obj = globals()[name]
            # Check for Tensors, Modules, and Optimizers
            if isinstance(obj, (torch.Tensor, torch.nn.Module, torch.optim.Optimizer)):
                print(f"Deleting global object: {name}")
                del globals()[name]
            
    # 3. Force Garbage Collection
    gc.collect()
    
    # 4. Clear CUDA Cache
    if torch.cuda.is_available():
        torch.cuda.empty_cache()
        print(f"GPU Memory Allocated: {torch.cuda.memory_allocated() / 1024**2:.2f} MB")
        print(f"GPU Memory Reserved: {torch.cuda.memory_reserved() / 1024**2:.2f} MB")
        
    print("GPU cleanup complete.")


def run_demo():
    # Perform cleanup BEFORE doing anything else
    cleanup_gpu()

    print("Starting Library Usage Demo...")
