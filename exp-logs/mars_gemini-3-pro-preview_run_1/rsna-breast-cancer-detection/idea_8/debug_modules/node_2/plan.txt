The `AssertionError` occurs because the data augmentation (specifically `TF.rotate`) is applied to the entire 3-channel tensor (Image + Age + Implant). When the tensor is rotated, the empty corners are filled with zeros. Since the Age and Implant channels contain non-zero constant values (e.g., normalized age), the zero-filled corners introduce variance, causing the "spatially constant" check (`torch.std(age_map) < 1e-6`) to fail.

To fix this, I will decouple the image processing from the metadata channel construction. I will modify `_process_single_image` to return the image tensor and scalar metadata values separately. Then, in `__getitem__`, I will apply augmentation **only** to the image tensor and reconstruct the full 3-channel tensor by appending the constant metadata planes *after* the geometric transformations. This ensures the metadata channels remain perfectly uniform without rotation artifacts.
