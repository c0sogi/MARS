Based on the progression of empirical findings—specifically the need to mitigate the "Age Shortcut" via symmetry analysis (Cite solution_lesson_node_00012, solution_lesson_node_00014) and the limitations of rigid subtraction in the presence of anatomical misalignment—I propose the **Deformable Symmetry-Aware Siamese Network**.

This architecture evolves the previous "Pyramid Symmetry-Difference" concept by integrating a **Deformable Feature Alignment** module. Unlike rigid subtraction (which generates noise at tissue boundaries due to natural breast asymmetry) or global flow (which can over-warp), deformable alignment locally registers the contralateral features to the target features *before* subtraction. This ensures that the difference operation precisely isolates asymmetric lesions (tumors) while maintaining the mathematical cancellation of the demographic bias.

### Model
**Architecture: Deformable Symmetry-Aware Siamese EfficientNet-B2**

*   **Siamese Backbone:** Utilize **EfficientNet-B2** in a Siamese configuration (shared weights). This ensures identical feature extraction for both the **Target Image** and **Contralateral Image** (opposing breast, same view).
*   **Input Strategy (Early Fusion):**
    *   Retain the **Spatial Channel Expansion** technique (Cite solution_lesson_node_00002).
    *   Input tensors are $3 \times 768 \times 768$, comprising the **Image**, a spatially broadcasted **Age** map, and a spatially broadcasted **Implant** map.
    *   **Demographic Cancellation:** Since the Age/Implant maps are spatially constant for a given patient, they remain invariant under the resampling operation described below. Consequently, the difference operation strictly cancels out these signals, preventing the "Age Shortcut."
*   **Deformable Alignment & Difference Module (Structural Innovation):**
    *   Extract feature maps from pyramid levels **P3, P4, and P5**.
    *   For each level, concatenate the Target features ($F_{target}$) and Contralateral features ($F_{contra}$). Pass this stack through a lightweight convolution to predict **dense offsets** ($\Delta p$).
    *   Apply **Deformable Convolution / Resampling** to $F_{contra}$ using $\Delta p$ to generate **Aligned Contralateral Features** ($F'_{contra}$). This locally warps the healthy tissue of the contralateral breast to match the anatomy of the target breast.
    *   Compute the **Aligned Difference**: $D = F_{target} - F'_{contra}$. This suppresses aligned symmetric tissue (density) while highlighting anomalies that cannot be matched (tumors).
*   **Fusion Head:**
    *   Global Average Pool both $F_{target}$ (context) and $D$ (asymmetry signal) at all levels.
    *   Concatenate and pass through a dense layer for binary classification.

### Data
**Preprocessing & Augmentation**

*   **Paired Data Loading:**
    *   Load (Target, Contralateral) pairs. If a physical contralateral is missing, substitute a zero-tensor.
    *   **Fail Loudly:** The data loader must **raise an exception** immediately if a file is missing or corrupt. Do not use silent fallbacks (e.g., black images) for I/O errors, as this causes model collapse (Cite solution_lesson_node_00016).
*   **Normalization:**
    *   Apply **Standard Scaling** (Zero Mean, Unit Variance) to the Age metadata before broadcasting. This ensures the scalar signal has unit variance and does not dominate gradients (Cite solution_lesson_node_00005).
*   **Augmentation:**
    *   **Synchronized Geometric Augmentation:** Apply identical random spatial transformations (Flip, Rotate, Shift) to both images to maintain global correspondence (Cite solution_lesson_node_00007).
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts. Preserving absolute pixel intensity (density) is critical for this modality (Cite solution_lesson_node_00008).

### Training
**Procedure**

*   **Objective:** **Single-Task Learning (STL)**.
    *   Train exclusively on the binary cancer target. Do not use auxiliary heads for Breast Density.
    *   *Rationale:* Auxiliary tasks on global features are "easier" to learn and exacerbate age bias, leading to negative transfer (Cite solution_lesson_node_00021).
*   **Loss Function:** `BCEWithLogitsLoss` with `pos_weight` set to **47.0**.
    *   Aggressive positive weighting is required to maintain Probabilistic Recall in this 1:47 imbalance regime (Cite solution_lesson_node_00003).
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   Clipping gradients neutralizes the high `pos_weight`, preventing the necessary large updates for the minority class (Cite solution_lesson_node_00009).
*   **Optimizer:** AdamW (LR 1e-4) with Cosine Annealing.

### Evaluation
**Inference Pipeline**

*   **Pair Construction:** Iterate through `test.csv`. For each prediction row, identify and load the matching contralateral view.
*   **Prediction:** Pass the pair through the Deformable Siamese network.
*   **Aggregation:** Group predictions by `prediction_id` (breast level). Compute the **Max** probability across all available views (CC and MLO) for that breast to generate the final submission.
