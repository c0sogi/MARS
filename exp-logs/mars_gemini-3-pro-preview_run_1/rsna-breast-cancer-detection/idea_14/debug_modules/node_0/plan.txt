This script demonstrates the end-to-end pipeline for the breast cancer detection task using the provided library files. It overrides the default configuration to run in "Debug Mode" with a very small subset of data (10 samples) and a lightweight model setup (no pretrained weights, 1 epoch). It verifies the data loading process, model forward pass, training step, validation metric calculation, and submission generation, asserting the correctness of shapes and outputs at each stage.
