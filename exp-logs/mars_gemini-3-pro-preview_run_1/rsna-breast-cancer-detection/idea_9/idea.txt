Based on the comprehensive analysis of previous iterations and the specific empirical lessons learned, I propose the **Spatial Symmetry-Difference Siamese Network**.

This strategy addresses the persistent "Age Shortcut" bias observed in single-stream models (where the model relies on patient age rather than visual tumor patterns) by structurally forcing the network to learn **asymmetry**. Since breast tissue density and age-related patterns are generally symmetric across breasts, while cancerous lesions are asymmetric, a Siamese difference architecture effectively cancels out the confounding demographic signals.

### Model
**Architecture: Spatial Symmetry-Difference Siamese EfficientNet-B2**

*   **Backbone:** Use **EfficientNet-B2** in a Siamese configuration. Two identical branches (sharing all weights) process the **Target Image** (the candidate for cancer) and the **Contralateral Image** (the opposing breast, same view).
*   **Input Strategy (Early Fusion):**
    *   Retain the **Spatial Channel Expansion** technique (Cite solution_lesson_node_00002).
    *   Both the target and contralateral inputs are $3 \times 768 \times 768$ tensors, consisting of the **Image**, a spatially broadcasted **Age** map, and a spatially broadcasted **Implant** map.
    *   *Crucial Mechanism:* Since the Age and Implant maps are identical for the same patient, they will be mathematically neutralized in the difference operation described below, strictly preventing the "Age Shortcut" (Cite solution_lesson_node_00012, solution_lesson_node_00014).
*   **Spatial Fusion Module (Structural Innovation):**
    *   Instead of global pooling, extract the final convolutional feature maps ($768 \to \sim24 \times 24$) from both branches: $M_{target}$ and $M_{contra}$.
    *   Compute the **Spatial Difference Map**: $M_{diff} = M_{target} - M_{contra}$. This suppresses symmetric background tissue (density) while highlighting local asymmetric anomalies (tumors).
    *   **Concatenation:** Stack the maps along the channel dimension: $M_{fused} = \text{Concat}(M_{target}, M_{diff})$. This preserves the local texture context of the target breast while explicitly injecting the asymmetry signal.
*   **Head:** A Depthwise Separable Convolution block processes $M_{fused}$, followed by Global Average Pooling and a single dense layer for the binary prediction.

### Data
**Preprocessing & Augmentation**

*   **Paired Data Loading:**
    *   The dataset class must identify and load the matching contralateral image (e.g., Left CC paired with Right CC) for every training sample.
    *   **Handling Missing Counterparts:** If a patient physically lacks a contralateral image, substitute a zero-tensor.
    *   **Fail Loudly:** The loader must **raise an exception** if a file path exists in metadata but the file is unreadable. Do not use silent fallbacks (e.g., returning black images) for corrupt files, as this causes model collapse (Cite solution_lesson_node_00016).
*   **Normalization:**
    *   Apply **Standard Scaling** (Zero Mean, Unit Variance) to the Age metadata before broadcasting. This prevents the scalar value from being overpowered by image features or dominating gradients (Cite solution_lesson_node_00005).
*   **Augmentation:**
    *   **Synchronized Geometric Augmentation:** Apply identical random spatial transformations (Flip, Rotate, Shift) to *both* the target and contralateral images simultaneously to maintain pixel-wise correspondence for the difference operation (Cite solution_lesson_node_00007).
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts. In mammography, absolute pixel intensity represents physical tissue density; altering it destroys the diagnostic signal (Cite solution_lesson_node_00008).

### Training
**Procedure**

*   **Objective:** **Single-Task Learning (STL)**.
    *   Train exclusively on the binary cancer target. Do not use auxiliary heads for Breast Density.
    *   *Rationale:* Auxiliary tasks on global features (like density) are easier to learn than lesion detection and exacerbate the age bias, leading to negative transfer (Cite solution_lesson_node_00021).
*   **Loss Function:** `BCEWithLogitsLoss` with `pos_weight` set to **47.0** (approximating the inverse class frequency).
    *   Aggressive positive weighting is required to maintain Probabilistic Recall in this highly imbalanced regime (Cite solution_lesson_node_00003).
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   Clipping gradients neutralizes the effect of the high `pos_weight`, preventing the optimizer from making the large updates necessary to correct errors on the minority class (Cite solution_lesson_node_00009).
*   **Optimizer:** AdamW (LR 1e-4) with a Cosine Annealing scheduler.

### Evaluation
**Inference Pipeline**

*   **Pair Construction:** Iterate through `test.csv`. For each prediction row, identify the file path for the contralateral view.
*   **Prediction:** Pass the pair through the Siamese network.
*   **Aggregation:** Group predictions by `prediction_id` (which represents a specific breast). Compute the **Max** probability across all available views (CC and MLO) for that breast to generate the final submission score.
