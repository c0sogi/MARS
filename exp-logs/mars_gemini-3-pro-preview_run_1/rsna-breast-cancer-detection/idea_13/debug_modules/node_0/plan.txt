    *   **Training**: We will execute the `run_training` function using the synthetic data. This tests the data loaders, training loop, loss calculation, and checkpoint saving.

5.  **Assertions**: Throughout the script, we will use assertions to confirm that files are created, shapes are correct, and the metric behaves as expected.
