This script demonstrates the usage of the provided library modules for the breast cancer detection task. It performs the following steps:

1.  **Configuration**: Overrides the default configuration to enable `DEBUG` mode and reduce the number of epochs for a quick demonstration.
2.  **Utility Verification**: Validates the `probabilistic_f1` metric calculation with test cases.
3.  **Data Pipeline Demonstration**:
    *   Monkey-patches the image loading method to generate synthetic data. This ensures the demonstration runs robustly without relying on specific DICOM compatibility in the environment's OpenCV build.
    *   Initializes the `SiameseMammographyDataset` and `DataLoader`.
    *   Verifies the structure and shapes of the data batches (Target Image, Contralateral Image, Metadata Maps).
4.  **Model Demonstration**:
    *   Instantiates the `PyramidSiameseEfficientNet`.
    *   Performs a forward pass with a dummy batch to verify tensor shapes and gradient propagation.
5.  **Training Loop Demonstration**:
    *   Runs a complete training and validation cycle for one epoch using the `train_one_epoch` and `validate` functions.
    *   Checks if the model artifacts are saved correctly.
