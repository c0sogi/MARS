The following script demonstrates the end-to-end workflow for the breast cancer detection task using the provided library files.

**Strategy:**
1.  **Configuration**: We override the default `Config` parameters to enable `DEBUG` mode, reduce `EPOCHS` to 1, and lower the `BATCH_SIZE`. This ensures the script executes quickly (within minutes) while still exercising all code paths.
2.  **Metric Validation**: We verify the `probabilistic_f1` function with synthetic data to ensure the custom metric logic is correct.
3.  **Data Pipeline**: We initialize the dataloaders and inspect a single batch to confirm that image tensors (including Age and Implant channels) and targets are shaped correctly.
4.  **Model Logic**: We instantiate the `MultiTaskEfficientNet` and perform a forward pass with dummy data to verify output shapes for both the cancer and density heads.
5.  **Training & Inference**: We execute the full `train_model` and `run_inference` functions provided in the library. This validates the integration of the training loop, validation step, model checkpointing, and submission file generation.
