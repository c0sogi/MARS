The issue is a CUDA Out of Memory error caused by a configuration designed for an A100 (40GB) GPU running on a smaller (~16GB) GPU. The combination of `(768, 768)` image resolution and `BATCH_SIZE = 16` exceeds the available memory.

To fix this, I will:
1.  **Modify `library/config.py`**: Reduce `IMG_SIZE` to `(512, 512)` and `BATCH_SIZE` to `8` to fit within the 16GB limit.
2.  **Modify `library/train.py`**: Implement Automatic Mixed Precision (AMP) using `torch.cuda.amp` to further reduce memory usage and improve performance. I will initialize `GradScaler` inside `train_epoch` to avoid changing the function signature and breaking `runfile.py`.
