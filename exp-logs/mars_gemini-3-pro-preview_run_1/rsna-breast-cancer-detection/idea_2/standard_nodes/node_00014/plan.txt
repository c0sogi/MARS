To optimize the solution, I will implement a **Late Fusion** architecture, directly addressing the structural bias identified in Lesson `solution_lesson_node_00012`. The previous Early Fusion approach (broadcasting scalar metadata as image channels) caused the model to over-rely on the "clean" age signal (correlation 0.85) at the expense of visual features. By processing the image and metadata (Age, Implant) in separate streams and fusing them at the feature level, we force the backbone to learn visual representations before they are influenced by demographic priors.

Key changes:
1.  **Architecture (Cite solution_lesson_node_00012):** Modify `MultiTaskEfficientNet` to accept a tuple of inputs `(image, metadata)`. The image passes through the EfficientNet backbone, and the metadata passes through a small MLP. The resulting feature vectors are concatenated before the classification heads.
2.  **Data Pipeline:** Update `MammogramDataset` to return `(image, metadata)` tuples. The image is now a standard 3-channel RGB tensor (grayscale repeated) to leverage pretrained weights effectively, while metadata is a distinct vector.
3.  **Hyperparameters:** Increase `EPOCHS` to 5 in `runfile.py` to allow the new architecture sufficient convergence time (previous run took ~17 mins for 3 epochs, so 5 is well within limits).

class MultiTaskEfficientNet(nn.Module):
    def __init__(self, backbone_name=Config.BACKBONE, pretrained=True):
        super(MultiTaskEfficientNet, self).__init__()

        # Initialize backbone as feature extractor
        # in_chans=3 (RGB)
        self.backbone = timm.create_model(
            backbone_name,
            pretrained=pretrained,
            num_classes=0,
            in_chans=Config.IN_CHANNELS,
        )

        # Metadata processing
        self.meta_mlp = nn.Sequential(
            nn.Linear(Config.META_DIM, 32),
            nn.ReLU(),
            nn.Dropout(0.2)
        )

        # Combined features
        n_features = self.backbone.num_features + 32

        # Primary Head: Cancer Detection (Binary)
        self.cancer_head = nn.Linear(n_features, 1)

        # Auxiliary Head: Density Classification (4 classes)
        self.density_head = nn.Linear(n_features, Config.NUM_AUX_CLASSES)

    def forward(self, inputs):
        x, meta = inputs
        
        # Extract image features
        img_features = self.backbone(x)
        
        # Extract metadata features
        meta_features = self.meta_mlp(meta)
        
        # Late Fusion
        combined = torch.cat([img_features, meta_features], dim=1)

        # Multi-task outputs
        cancer_logits = self.cancer_head(combined)
        density_logits = self.density_head(combined)

        return cancer_logits, density_logits
