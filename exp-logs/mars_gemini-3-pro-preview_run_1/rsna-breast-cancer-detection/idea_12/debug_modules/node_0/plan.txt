The following script demonstrates the end-to-end usage of the provided library components for the breast cancer detection task. It performs the following steps:

1.  **Configuration Override**: Adjusts `Config` parameters (Batch Size, Epochs, Debug Mode) to ensure the demonstration runs quickly (under a few minutes) while using the provided hardware.
2.  **Metric Verification**: Validates the `probabilistic_f1` function with a manual calculation to ensure correctness.
3.  **Data Pipeline**: Initializes the DataLoaders using `get_dataloaders` in debug mode. It fetches a single batch to verify tensor shapes, data types, and the custom channel stacking logic (Image + Age + Implant).
4.  **Model Initialization & Forward Pass**: Instantiates the `FlowAlignedSiameseNet`, moves it to the GPU, and performs a forward pass with the sample batch to verify output dimensions.
5.  **Training Loop**: Executes the `fit` function from the engine to simulate a full training run (1 epoch) with validation and checkpointing.
6.  **Inference**: Runs the `inference` function on the test set and verifies that the submission file is generated correctly with the required schema.
