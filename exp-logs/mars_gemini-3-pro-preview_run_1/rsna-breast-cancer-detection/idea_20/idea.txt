Based on the comprehensive analysis of the empirical lessons—specifically the persistent "Age Shortcut" bias (Cite solution_lesson_node_00012, solution_lesson_node_00014), the superiority of Single-Task Learning (Cite solution_lesson_node_00021), and the risks of complex auxiliary tasks or aggressive augmentation (Cite solution_lesson_node_00008, solution_lesson_node_00019)—I propose the **Channel-Attentive Symmetry-Difference Siamese Network**.

This strategy structurally evolves the previous "Symmetry-Difference" ideas. Instead of attempting to spatially *fix* anatomical misalignment via complex warping (which risks hallucinating features), this architecture accepts that misalignment exists and uses a **Channel Attention** mechanism to dynamically suppress feature maps that are sensitive to noise, while amplifying those that capture robust asymmetric lesions.

### Model
**Architecture: Channel-Attentive Symmetry-Difference Siamese EfficientNet-B2**

*   **Siamese Backbone:** Utilize **EfficientNet-B2** in a Siamese configuration (shared weights). This ensures that both the **Target Image** (candidate for cancer) and the **Contralateral Image** (opposing breast, same view) are processed by the exact same feature extractor.
*   **Input Strategy (Early Fusion):**
    *   Retain the **Spatial Channel Expansion** technique (Cite solution_lesson_node_00002).
    *   The input tensor for both branches is $3 \times 768 \times 768$, comprising the **Image**, a spatially broadcasted **Age** map, and a spatially broadcasted **Implant** map.
    *   **Demographic Cancellation:** Since the Age and Implant maps are identical for the left and right breasts of the same patient, they will be mathematically zeroed out in the difference operations described below. This strictly prevents the "Age Shortcut" (Cite solution_lesson_node_00014).
*   **Attentive Difference Module (Structural Innovation):**
    *   Extract feature maps from **three distinct stages** of the backbone (P3, P4, P5) to capture both microcalcifications and masses.
    *   Compute the **Signed Feature Difference**: $D_i = F_{target, i} - F_{contra, i}$.
    *   **Noise Suppression via Channel Attention:** Apply a **Squeeze-and-Excitation (SE) Block** to each difference map $D_i$.
        *   *Rationale:* Simple subtraction creates noise at tissue boundaries due to natural anatomical misalignment. The SE Block learns to re-weight the channels of the difference map, suppressing channels that respond to misalignment noise and amplifying channels that respond to genuine asymmetric lesions (tumors). This is a robust, lightweight alternative to risky spatial warping.
*   **Fusion & Classification Head:**
    *   Concatenate the Target features ($F_{target, i}$) and the Attended Difference features ($SE(D_i)$) at all three stages.
    *   Apply Global Average Pooling and pass the combined vector through a single dense layer to predict the cancer probability.

### Data
**Preprocessing & Augmentation**

*   **Paired Data Loading:**
    *   Construct training pairs by matching `patient_id` and `view` (e.g., Left CC paired with Right CC).
    *   **Fail Loudly:** The data loader must **raise an exception** immediately if a file is missing or corrupt. Do not use silent fallbacks (e.g., returning black images), as this caused model collapse in previous iterations (Cite solution_lesson_node_00016).
    *   **Missing Counterparts:** Only for cases where a patient physically lacks a contralateral image, substitute a zero-tensor.
*   **Normalization:**
    *   Apply **Standard Scaling** (Zero Mean, Unit Variance) to the Age metadata before spatial broadcasting. This prevents the scalar value from being overpowered by image features or dominating gradients (Cite solution_lesson_node_00005).
*   **Augmentation:**
    *   **Synchronized Geometric Augmentation:** Apply identical random spatial transformations (Flip, Rotate, Shift) to *both* the target and contralateral images simultaneously. This preserves the pixel-wise correspondence required for the difference operation (Cite solution_lesson_node_00007).
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts. In mammography, absolute pixel intensity represents physical tissue density; altering it destroys the diagnostic signal (Cite solution_lesson_node_00008).

### Training
**Procedure**

*   **Objective:** **Single-Task Learning (STL)**.
    *   Train exclusively on the binary cancer target. Do not use auxiliary heads for Breast Density.
    *   *Rationale:* Auxiliary tasks on global features (like density) are "easier" to learn than lesion detection and have been proven to exacerbate age bias, leading to negative transfer (Cite solution_lesson_node_00021).
*   **Loss Function:** `BCEWithLogitsLoss` with `pos_weight` set to **47.0** (approximating the inverse class frequency).
    *   Aggressive positive weighting is required to maintain Probabilistic Recall in this highly imbalanced regime (Cite solution_lesson_node_00003).
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   Clipping gradients neutralizes the effect of the high `pos_weight`, preventing the optimizer from making the large updates necessary to correct errors on the minority class (Cite solution_lesson_node_00009).
*   **Optimizer:** AdamW (LR 1e-4) with a Cosine Annealing scheduler.

### Evaluation
**Inference Pipeline**

*   **Pair Construction:** Iterate through `test.csv`. For each prediction row, identify the file path for the contralateral view (same patient, same view, opposite laterality).
*   **Prediction:** Pass the pair through the Channel-Attentive Siamese network.
*   **Aggregation:** Group predictions by `prediction_id` (which represents a specific breast). Compute the **Max** probability across all available views (CC and MLO) for that breast to generate the final submission score.
