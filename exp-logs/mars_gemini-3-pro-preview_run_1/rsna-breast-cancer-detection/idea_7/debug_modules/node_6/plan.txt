The `CUDA error: out of memory` is caused by TensorFlow eagerly allocating GPU memory when imported at the top level of `library/utils.py`, which prevents PyTorch from allocating memory for the model. To fix this, I will move the TensorFlow import inside the `load_image` function (lazy import) and explicitly configure it to use CPU only, ensuring it does not initialize the GPU context (Cite `debug_lesson_13`). Additionally, I will update `runfile.py` to explicitly unload `tensorflow` and the library modules from `sys.modules` before reloading, ensuring that the persistent environment does not retain the previous GPU-locking TensorFlow instance.
