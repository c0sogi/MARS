The `torch.AcceleratorError: CUDA error: out of memory` occurring at model instantiation indicates that the GPU memory is saturated, likely by "zombie" tensors or models from previous executions persisting in the Python interpreter's global scope. Standard `gc.collect()` calls are insufficient to free these resources if they are referenced by global variables.

To fix this, I will modify `runfile.py` to:
1.  **Implement Aggressive Global Cleanup:** Iterate through the `globals()` dictionary at the start of the script and explicitly delete any `torch.nn.Module`, `torch.Tensor`, or `torch.optim.Optimizer` objects. This removes the root references preventing the garbage collector from freeing GPU memory (Cite debug_lesson_7).
2.  **Optimize Memory Usage During Verification:** Explicitly delete data tensors (`images`, `batch`, etc.) after the data pipeline verification step and before model loading to minimize peak memory usage (Cite debug_lesson_6).
3.  **Decouple Verification Steps:** Modify the model architecture verification to use generated dummy data instead of reusing data from the previous step, allowing for complete cleanup of the data loader outputs before the model is placed on the GPU.
