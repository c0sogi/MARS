Implementation Strategy:
1.  **Configure Environment**: Dynamically update the `Config` class to use a temporary working directory and enable debug mode. This ensures the demonstration runs quickly on a small data subset without overwriting existing production files.
2.  **Verify Utilities**: Test the `probabilistic_f1` metric with synthetic data and verify the `get_cached_data` function to ensure data persistence logic works correctly.
3.  **Verify Data Pipeline**: Initialize dataloaders using `get_dataloaders` with debug enabled. Fetch a single batch to validate tensor shapes (Batch Size, Channels, Height, Width) and data integrity.
4.  **Verify Model Architecture**: Instantiate the `SpatialSiameseEfficientNet`, perform a forward pass with the fetched batch, and assert that the output dimensions match the expected shape `(Batch, 1)`.
5.  **Verify Training Loop**: Execute `run_training` in debug mode. This runs a short training session (2 epochs) to validate the integration of the dataset, model, loss, and optimizer, ensuring a model checkpoint is successfully saved.
