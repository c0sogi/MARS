The following script demonstrates the usage of the provided breast cancer detection library.

**Implementation Strategy:**
1.  **Unit Testing**: Verifies the `probabilistic_f1` metric with known inputs to ensure correctness.
2.  **Configuration Patching**: Modifies the `Config` class at runtime to use smaller image sizes (256x256), a smaller batch size, and fewer epochs. This ensures the demonstration runs quickly on the available hardware.
3.  **Data Subsetting**: Creates small subsets of the training, validation, and test metadata (50 samples each) in the working directory. This allows the training loop to complete a full epoch in seconds rather than hours, validating the entire pipeline flow without waiting for the full dataset.
4.  **Component Verification**:
    *   **Data Loading**: Instantiates dataloaders and verifies the structure and shape of the batches (Target Image, Contralateral Image, Metadata Channels).
    *   **Model Inference**: Instantiates the `SiameseEfficientNet`, performs a forward pass with a dummy batch, and verifies output dimensions.
    *   **Training Loop**: Executes a single epoch of training using the `run_training` function to verify loss calculation, backpropagation, and checkpoint saving.
    *   **Submission**: Generates a submission file using the trained model to verify the inference pipeline.
