Implementation strategy:
1.  **Setup**: Initialize environment, set seeds, and detect device (GPU).
2.  **Data Loading**: Use `get_dataloaders` to load the balanced training set (Teacher set) and validation set. Load background noise files for augmentation.
3.  **Teacher Training**: Train a `DilatedEfficientNet` model on the labeled training data. Use Mixup and Noise Injection. Train for a limited number of epochs (12) to ensure the pipeline fits within the time limit.
4.  **Pseudo-Labeling**: Use the trained Teacher model to predict labels for the unlabeled test set. Filter predictions using a high confidence threshold (0.95) to create a high-quality pseudo-labeled dataset.
5.  **Student Training**: Combine the original labeled data with the pseudo-labeled test data. Train a fresh `DilatedEfficientNet` (Student) on this larger, noisier dataset. This step enables domain adaptation to the test set's unseen speakers.
6.  **Evaluation**: Validate the Student model on the hold-out validation set. Calculate the Multiclass Accuracy.
7.  **Failure Analysis**: Analyze the validation results. Calculate the correlation between error magnitude (misclassification) and input features like audio duration and RMS amplitude to identify systematic weaknesses.
8.  **Submission**: If the validation accuracy exceeds the specified threshold (0.98729...), generate the submission file using the Student model.
