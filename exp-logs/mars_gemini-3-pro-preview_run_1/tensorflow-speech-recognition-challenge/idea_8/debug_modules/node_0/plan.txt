The following script demonstrates the usage of the provided library components for the speech command recognition task. It performs the following steps:

1.  **Configuration & Utilities Verification**: Verifies the `LabelMapper` logic to ensure fine-grained labels are correctly mapped to the 12 submission classes (e.g., 'bed' -> 'unknown', 'yes' -> 'yes').
2.  **Dataset Verification**: Manually loads a small subset of the metadata to instantiate `SpeechCommandsDataset` and verifies that it produces spectrograms of the correct shape `(1, 128, 101)` and integer labels.
3.  **Model Verification**: Instantiates the `ContextAwareEfficientNet` and performs a forward pass with dummy data to confirm output dimensions match the class count (31).
4.  **Training Loop Integration**: Demonstrates the `Trainer` class. To ensure quick execution, it monkey-patches the data loading function to return very small dataloaders (batch size 4, 10 samples) and overrides the training configuration to run for only 1 epoch. It then executes a training step and a validation step, asserting that loss and accuracy are calculated correctly.
