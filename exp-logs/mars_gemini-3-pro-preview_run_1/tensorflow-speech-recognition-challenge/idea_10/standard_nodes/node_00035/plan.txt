        *   **Duration**: Read from audio file headers (handling synthetic silence).
        *   **Label Index**: The integer representation of the class.
    *   Calculate and print the Pearson correlation between the error signal and these features to identify systematic issues.

5.  **Submission**:
    *   Compare the final validation metric against the strict threshold (`0.9872909698996656`).
