This script demonstrates the end-to-end usage of the provided library components for the Speech Command Recognition task. It covers:

1.  **Configuration**: Adjusting hyperparameters for a fast demonstration run.
2.  **Label Management**: Initializing the `LabelManager` to handle fine-grained class mappings.
3.  **Data Loading**: Loading the training and validation datasets, and subsetting them significantly to ensure the training loop completes quickly.
4.  **Model Initialization**: Instantiating the `DilatedEfficientNet` with the correct number of classes.
5.  **Training**: Running a single-epoch training loop using the `Trainer` class.
6.  **Inference & Mapping**: Demonstrating how to convert model predictions (indices) back to fine-grained labels and then to the final 12 submission categories.
