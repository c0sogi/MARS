Implementation strategy:
1.  **Configuration & Setup**: Import the provided library modules. Override `Config.EPOCHS` to 15 to ensure the "fast baseline" requirement is met while allowing sufficient convergence for the high accuracy threshold. Set random seeds for reproducibility.
2.  **Data Loading**: Use `get_dataloaders(load_cached_data=True)` to efficiently load the training, validation, and test sets along with the label encoder.
3.  **Model Initialization**: Instantiate the `EnergyGatedEfficientNet` using the number of fine-grained classes derived from the label encoder.
4.  **Training**: Initialize the `Trainer` and execute the training loop via `fit()`. This will automatically save the best model based on validation accuracy.
5.  **Validation & Metrics**: 
    *   Reload the best saved model.
    *   Perform inference on the full validation set.
    *   Calculate the exact "Mapped Accuracy" (Competition Metric) by mapping fine-grained predictions to the 12 target classes.
    *   Print the metric in the required format.
6.  **Failure Analysis**:
    *   Compute binary error flags (1 for incorrect, 0 for correct) based on the mapped predictions.
    *   Extract simple signal features (Mean Energy, Mean Spectral Intensity) from the validation tensors.
    *   Calculate and print the Pearson correlation between these features and the error magnitude to identify systematic failures (e.g., does the model fail more on quiet clips?).
7.  **Submission**: Compare the final validation metric against the strict threshold (`0.9872909698996656`). If the condition is met, generate the `submission.csv` using the trainer's prediction method.
