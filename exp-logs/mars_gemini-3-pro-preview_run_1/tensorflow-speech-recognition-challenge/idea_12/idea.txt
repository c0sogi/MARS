# Model
**Architecture: Energy-Gated Dilated EfficientNet-B2**

I propose a structural evolution that augments the CNN backbone with an explicit **Energy Side-Channel** to resolve the ambiguity between "Silence", "Background Noise", and "Active Speech".

*   **Backbone (Dilated EfficientNet-B2):** We will retain the **EfficientNet-B2** backbone due to its strong inductive bias for this dataset size (Cite solution_lesson_node_00024).
    *   **Input Adaptation:** The first layer will be initialized by **averaging the pretrained ImageNet RGB weights** to accept 1-channel Log-Mel Spectrograms (Cite solution_lesson_node_00016).
    *   **Resolution Preservation:** We will strictly apply **Dilated Convolutions** (stride=1, dilation=2) in the final stage (Stage 5). This preserves a temporal resolution of ~6-7 frames, preventing the feature map collapse that hinders attention mechanisms (Cite solution_lesson_node_00009, Cite solution_lesson_node_00025).

*   **Structural Innovation (Energy-Gated Attentive Pooling):**
    *   **Problem:** Standard Attentive Pooling infers relevance solely from spectral features. However, Lesson 39 proved that **absolute signal energy** is the primary discriminator for the "Silence" class, and purely spectral models can struggle to distinguish low-volume speech from high-volume noise.
    *   **Solution:** We will implement a parallel **Energy Gating Module**.
        1.  **Extraction:** Compute the **Frame-wise RMS Energy** vector ($T \times 1$) from the input spectrogram (before the backbone).
        2.  **Projection:** Pass this vector through a lightweight 1D convolution to align it with the backbone's feature dimension.
        3.  **Gating:** Inject this energy signal into the attention mechanism. The attention score for time step $t$ will be calculated as:
            $$ \text{Score}_t = \tanh(W_{feat} \cdot f_t + W_{energy} \cdot e_t) $$
            $$ \alpha_t = \text{Softmax}(\text{Score}_t) $$
    *   **Benefit:** This creates a "soft bias" where high-energy frames (speech) naturally attract attention, while the spectral weights ($W_{feat}$) can veto this bias if the high-energy signal is detected as noise.

*   **Output Head:** The model will output probabilities for **31+ Fine-Grained Classes** (all unique command words) rather than the compressed 12-class target set (Cite solution_lesson_node_00028).

# Data
**Preprocessing:**
*   **High-Fidelity Spectrograms:** Generate Log-Mel Spectrograms with **128 Mel bands**, **N_FFT of 1024** (64ms), and a **Hop Length of 160** (10ms). This configuration balances spectral density with the temporal precision required for short phonemes (Cite solution_lesson_node_00005, Cite solution_lesson_node_00008).
*   **Waveform Noise Injection:** We will inject background noise into the raw waveform *before* spectrogram generation (SNR 10-30dB, Prob 0.5). This forces the model to learn invariant spectral features (Cite solution_lesson_node_00029).
*   **Dynamic Silence Synthesis:** We will synthesize the 'silence' class by randomly cropping 1-second segments from background noise files (Cite solution_lesson_node_00001).
*   **No Instance Normalization:** We will **strictly avoid** per-sample Instance Normalization to preserve the absolute energy differences between silence and speech (Cite solution_lesson_node_00039).
*   **Variance-Aware Balancing:** We will employ the asymmetric balancing strategy. Target commands (e.g., "up", "down") will be upsampled to ~2,000, while the diverse auxiliary classes (e.g., "bed", "bird") will be kept at their natural counts (~9,000 total) to ensure the "Unknown" super-class retains high variance (Cite solution_lesson_node_00026).

# Training
**Strategy:**
*   **Regularization:** We will apply **SpecAugment** (Time/Freq masking) (Cite solution_lesson_node_00003) and **Mixup** with **$\alpha = 1.0$**. This high-intensity regularization is critical for preventing memorization in high-capacity models (Cite solution_lesson_node_00006, Cite solution_lesson_node_00016).
*   **Optimizer:** We will use **AdamW** with a **Cosine Annealing** learning rate scheduler to ensure convergence despite the noise from Mixup (Cite solution_lesson_node_00003).
*   **Duration:** We will train for **50 epochs** to allow the model to learn the fine-grained distinctions and converge under strong regularization (Cite solution_lesson_node_00002).
*   **Validation:** We will perform model selection based on **Fine-Grained Validation Accuracy** (31 classes) to ensure the decision boundaries are precise before mapping to the final targets (Cite solution_lesson_node_00031).

# Evaluation
**Inference:**
*   Test clips will be processed into Log-Mel Spectrograms using the fixed parameters (128 Mels, 1024 FFT, 160 Hop).
*   The model will predict probabilities for the 31+ fine-grained classes.
*   **Post-Hoc Mapping:** We will map the fine-grained predictions to the final submission format (Cite solution_lesson_node_00028):
    *   Target Labels (`yes`, `no`, `up`...) $\rightarrow$ Target Labels.
    *   `silence` $\rightarrow$ `silence`.
    *   Auxiliary Labels (`bed`, `bird`, `cat`...) $\rightarrow$ `unknown`.
