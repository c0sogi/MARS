Implementation strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided modules. Set the random seed for reproducibility. Override `Config.EPOCHS` to 8 to ensure the training completes within the ~36-minute time limit while allowing sufficient convergence for the baseline.
2.  **Training**: Execute the `train_model()` function from the engine. This handles the training loop with SAM optimizer, Mixup, and validation monitoring, saving the best model checkpoint.
3.  **Validation & Metric Calculation**:
    *   Load the best saved model.
    *   Perform inference on the full validation set.
    *   Map the fine-grained model predictions (31 classes) and ground truth labels to the 12 competition target labels (`yes`, `no`, `unknown`, etc.) using the logic provided in `library/utils.py`.
    *   Compute the final Multiclass Accuracy.
    *   Print the metric in the required format.
4.  **Failure Analysis**:
    *   Analyze the validation results to identify error patterns.
    *   Compute the correlation between the error (binary) and the target class index to see if specific classes are more prone to errors.
    *   Print the correlation.
5.  **Submission**:
    *   Check if the validation accuracy exceeds the strict threshold (0.98729...).
    *   If passed, run inference on the test set, map predictions to the target format, and save `submission.csv`.
