The `KeyError: 'swa_lr'` occurs because the `Trainer` class in `library/engine.py` attempts to access `TRAINING_PARAMS["swa_lr"]`, but this key is missing from the configuration dictionary in `library/config.py`. This is a case of configuration drift where the code expects a parameter that hasn't been defined in the central config (Cite debug_lesson_1).

To fix this, I will update `library/config.py` to include `swa_lr` (and `swa_start_epoch` for completeness, as it is also referenced by the Trainer) in the `TRAINING_PARAMS` dictionary. This ensures the configuration schema matches the implementation requirements.
