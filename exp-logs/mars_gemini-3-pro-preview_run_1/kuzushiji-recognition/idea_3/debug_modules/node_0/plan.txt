This script demonstrates the end-to-end usage of the provided Kuzushiji Character Recognition library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to use a small subset of data and reduced training parameters (1 epoch, small batch size) to ensure the demonstration runs quickly.
2.  **Data Preparation**: Creates temporary mini-datasets from the original metadata to feed into the training loop.
3.  **Component Validation**:
    *   Instantiates the `KuzushijiDataset` and verifies the integrity of the generated heatmaps and regression targets.
    *   Instantiates the `SwinCenterNet` model and performs a forward pass to verify output shapes.
    *   Calculates the `CenterNetLoss` to ensure the loss function and target alignment are correct.
    *   Validates the `kuzushiji_f1_score` metric with a manual test case.
4.  **Training & Inference**: Runs the `Trainer` to fine-tune the model on the mini-dataset and generate predictions on the test set.
