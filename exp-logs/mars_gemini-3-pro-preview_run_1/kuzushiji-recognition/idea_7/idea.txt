Based on the analysis of the previous experiments and the specific lessons learned, I propose the following optimized strategy. This solution structurally evolves the approach by selecting a backbone that balances the receptive field benefits of Transformers with the convergence speed of CNNs, specifically tailored for the time-constrained, high-cardinality nature of this task.

# Optimized Strategy: ConvNeXt-Tiny CenterNet with Deformable Heads

## Model
I propose replacing the ResNet backbone with a **ConvNeXt-Tiny** architecture, integrated with a **Feature Pyramid Network (FPN)** and **Deformable Convolution (DCNv2)** heads.

*   **Backbone (ConvNeXt-Tiny):**
    *   **Structural Innovation:** This backbone serves as a strategic middle ground between the **ResNet50** (which converged well but lacks global context) and the **Swin-B** (which failed to converge due to excessive size/complexity). ConvNeXt adopts "Transformer" design principles—specifically **7x7 large kernels**—which significantly expand the receptive field. This allows the model to "see" the ink strokes of a character even when the geometric center lies on empty whitespace, directly addressing the key failure mode of center-based detectors **Cite solution_lesson_node_00002**.
    *   **Efficiency:** Unlike the "Base" variants or Swin Transformers that failed to converge in the limited time **Cite solution_lesson_node_00016**, the "Tiny" variant (~28M parameters) has a computational footprint comparable to ResNet50. This ensures the model can undergo sufficient training iterations to condense probability mass for the 3,800+ classes within the 24-hour limit.
*   **Neck (FPN):** A Feature Pyramid Network will be used to fuse multi-scale features. This ensures robust detection across the extreme scale variations of Kuzushiji characters (from tiny annotations to large headers).
*   **Heads (Deformable CenterNet):** The prediction heads (Heatmap, Regression, Classification) will utilize **Deformable Convolutions (DCNv2)**. These layers learn dynamic offsets to the sampling grid, allowing the model to adaptively aggregate features from the irregular, curved strokes of the characters rather than a fixed rectangular context **Cite solution_lesson_node_00002**.

## Data
*   **Preprocessing:**
    *   **Resolution:** Images will be resized to `1024x1024` with padding to preserve the aspect ratio.
    *   **Normalization:** Crucially, pixel values will be **normalized using the standard ImageNet mean and standard deviation**. This corrects the fatal error in previous iterations where omitting normalization led to a complete model failure (0.0 F1) despite low training loss **Cite solution_lesson_node_00012**.
*   **Augmentation:**
    *   **Geometric Only:** The pipeline will strictly utilize **Geometric Augmentations** (Random Scaling, Random Shifting, and Random Rotation).
    *   **Exclusion:** I will explicitly **exclude** all photometric augmentations (Gaussian noise, blur, color jitter). As determined in previous experiments, these distortions destroy the high-frequency edge information (strokes) that constitutes the primary signal for character recognition **Cite solution_lesson_node_00006**.

## Training
*   **Loss Functions:**
    *   **Heatmap:** Penalty-Reduced Focal Loss to handle the foreground-background imbalance.
    *   **Classification:** Cross-Entropy Loss (calculated only at positive ground truth center locations) to handle the 3,800+ classes **Cite solution_lesson_node_00004**.
    *   **Regression:** L1 Loss for offsets and bounding box sizes.
*   **Optimizer:** **AdamW** with a **Cosine Annealing** scheduler.
*   **Duration:** Training will be set to **30-40 epochs**. By using the lighter "Tiny" backbone, we can achieve this higher epoch count (compared to the heavy models) which is critical for high-cardinality convergence **Cite solution_lesson_node_00016**.

## Evaluation
*   **Inference:** Forward pass test images through the ConvNeXt-Tiny CenterNet model.
*   **Decoding:** Apply 3x3 Max Pooling to the heatmap to extract local peaks. Select the top 1,200 peaks with confidence > 0.1.
*   **Submission:** Map the predicted center coordinates from the model space back to the original image dimensions. This anchor-free approach ensures direct alignment with the evaluation metric **Cite solution_lesson_node_00002**.
