The issue is that the `CenterNetLoss` function masks invalid regression predictions (padding) by multiplying them with a binary mask (`pred_reg_wh * mask_expanded`). If the model outputs `NaN` values in these padded regions (which can happen with randomly initialized `DeformableConv` layers), the operation `0.0 * NaN` results in `NaN`, causing the entire loss to become invalid. To fix this, I will implement boolean indexing to explicitly select only the valid predictions and targets before calculating the loss. This ensures that `NaN` values in the ignored padding regions are completely excluded from the computation, as recommended in **debug_lesson_14**.
