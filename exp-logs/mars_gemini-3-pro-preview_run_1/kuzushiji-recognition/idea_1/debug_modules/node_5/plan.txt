The issue is caused by the empty `anns_list` when processing the test set metadata (which has no valid ground truth annotations). `np.array(anns_list)` creates a numpy array of shape `(0,)`. When this 1D empty array is passed to `pd.DataFrame` with a list of 6 column names, pandas raises a `ValueError` because the data shape `(0, 1)` (implied by 1D array) does not match the expected 6 columns. To fix this, we must explicitly reshape the empty `anns_np` array to `(0, 6)` before creating the DataFrame or saving it to cache.
