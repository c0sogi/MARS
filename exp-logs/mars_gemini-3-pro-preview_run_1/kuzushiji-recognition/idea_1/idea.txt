To establish a robust and efficient baseline for the Kuzushiji character recognition task, I propose a **Decoupled Keypoint Network (DKN)**. This approach synthesizes the anchor-free philosophy of Model 1 (CenterNet) with a decoupled classification strategy to efficiently handle the high cardinality of the dataset (3,800+ classes).

### Model
The architecture is designed to be lightweight and fast, avoiding the complexity of anchor-based detectors or multi-stage cascades.
*   **Backbone**: Use **ResNet-18** as the feature extractor. It provides an optimal balance between inference speed and feature representation capability for this specific task.
*   **Neck**: Employ a simple upsampling module (using three deconvolutional layers) to restore the feature map spatial resolution to 1/4th of the input size. This ensures high-precision localization for small characters.
*   **Heads**: The network branches into three distinct heads:
    1.  **Objectness Head (1 channel)**: Predicts a class-agnostic heatmap indicating the probability of a character's center being present at each spatial location. This differs from standard CenterNet (which uses C channels) to save memory and compute.
    2.  **Classification Head (N channels)**: A dense classification map that predicts the specific Kuzushiji character class. During inference, this is only queried at the locations identified by the Objectness Head.
    3.  **Regression Head (4 channels)**: Predicts the local offset (2 channels) to recover discretization errors and the bounding box dimensions (2 channels). While the task only requires a center point, predicting dimensions helps the model learn scale-invariant features and allows for dynamic Gaussian radius calculation during training.

### Data
*   **Preprocessing**: Resize all images to a fixed square resolution (e.g., `1024x1024`) using padding to preserve the original aspect ratio. Normalize pixel values using standard ImageNet means and standard deviations.
*   **Target Generation**:
    *   **Heatmap**: For each ground truth character, compute the center point on the 1/4 scale feature map. Splat a Gaussian kernel onto the Objectness Head target at this center location. The radius of the Gaussian should be adaptive, based on the width and height of the ground truth bounding box (larger boxes = larger Gaussian spread).
    *   **Classification**: Assign the ground truth class label to the specific pixel coordinate of the character center in the Classification Head target.
    *   **Regression**: Calculate the offset (difference between exact float center and integer grid center) and log-scale dimensions for the Regression Head target.

### Training
*   **Loss Functions**:
    *   **Objectness**: Use **Penalty-Reduced Focal Loss**. This handles the extreme class imbalance between the few "center" pixels and the vast majority of "background" pixels.
    *   **Classification**: Use **Cross-Entropy Loss**, but only calculate gradients for pixels corresponding to ground truth character centers. This prevents the model from wasting capacity trying to classify background regions.
    *   **Regression**: Use **L1 Loss** or **Smooth L1 Loss** for both offset and dimension predictions, applied only at positive object locations.
*   **Optimization**: Use the **AdamW** optimizer with a standard learning rate schedule (linear warmup followed by cosine decay). Train for a fixed number of epochs (e.g., 30-50) to ensure convergence.

### Evaluation
*   **Inference**: Perform a forward pass on the test image.
*   **Peak Extraction**: Apply a 3x3 Max Pooling operation on the predicted Objectness Heatmap to identify local maxima.
*   **Thresholding**: Select the top $K$ peaks (e.g., $K=1200$) that exceed a confidence threshold (e.g., 0.1).
*   **Decoding**: For each selected peak at location $(x, y)$:
    1.  Retrieve the class label using `argmax` from the Classification Head at $(x, y)$.
    2.  Retrieve the offsets $(\delta x, \delta y)$ from the Regression Head.
    3.  Compute the refined center: $X = (x + \delta x) \times 4$, $Y = (y + \delta y) \times 4$.
*   **Rescaling**: Map the coordinates from the resized model input space back to the original image dimensions.
*   **Submission**: Format the results as `image_id, {label X Y} ...` for the final submission file.
