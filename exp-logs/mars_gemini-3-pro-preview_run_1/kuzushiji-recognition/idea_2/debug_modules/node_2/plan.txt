The issue is that the model is currently selecting the first feature map (`features[0]`) from the `timm` backbone, which corresponds to a stride of 2 (resulting in a 512x512 output for a 1024x1024 input). However, the dataset targets and the CenterNet architecture are designed for a stride of 4 (256x256 output). I will fix this in `library/model.py` by changing the index to `features[1]` in both the `__init__` method (to correctly determine input channels) and the `forward` method.
