The `_pickle.UnpicklingError` occurs because the `load_checkpoint` function uses `torch.load`, which defaults to `weights_only=True` in recent PyTorch versions (like 2.8.0). This setting restricts the unpickler to safe types and rejects the NumPy scalar (`numpy.float64`) used to store the validation score in the checkpoint. To resolve this, I will update the `load_checkpoint` wrapper in `library/utils.py` to explicitly pass `weights_only=False` to the underlying `torch.load` call. This ensures the wrapper correctly configures the internal component to handle the data types present in the project's checkpoints. Cite debug_lesson_1
