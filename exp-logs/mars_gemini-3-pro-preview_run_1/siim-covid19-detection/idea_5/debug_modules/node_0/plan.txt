This script demonstrates the end-to-end usage of the provided machine learning pipeline for radiographic finding classification and segmentation. It performs the following steps:

1.  **Utility Verification**: Validates helper functions like IoU calculation and bounding box extraction from masks.
2.  **Data Loading**: Initializes the data pipeline in debug mode (processing a small subset of images) to verify the shape and integrity of batches (images, masks, labels).
3.  **Model Initialization**: Instantiates the `ResNet18AttentionUNet` model (without pre-trained weights for speed) and verifies the output shapes of the classification and segmentation heads.
4.  **Training Loop**: Executes a single training epoch using `train_one_epoch`, verifying that the loss is computed correctly.
5.  **Evaluation**: Runs the `evaluate` function on the validation set to check metric calculation (mAP).
6.  **Inference**: Generates predictions on the test set using the `inference` function and verifies that the submission file is created with the correct format.
