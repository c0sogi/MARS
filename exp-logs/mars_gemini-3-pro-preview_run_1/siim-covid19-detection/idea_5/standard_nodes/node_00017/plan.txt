The existing cache validation only checks for file existence and sample count, failing to detect the shape mismatch. This causes `CrossEntropyLoss` to misinterpret the input as probabilities but receive integer types, leading to the `RuntimeError`.

To fix this, I will modify `library/dataset.py` to explicitly validate that the cached `labels` array is 1-dimensional. This implements the principle of validating cache integrity against runtime configuration (Cite debug_lesson_3). If the loaded labels are not 1D, the cache will be considered invalid, triggering a reprocessing of the data to generate the correct scalar labels.
