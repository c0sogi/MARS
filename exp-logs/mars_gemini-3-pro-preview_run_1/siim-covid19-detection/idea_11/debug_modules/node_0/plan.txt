This script demonstrates the functionality of the provided library files for the COVID-19 detection task. It systematically verifies the utility functions, dataset loading and processing, model architecture, and training/evaluation loops.

The strategy is as follows:
1.  **Utils Verification**: Validates helper functions like IoU calculation, bounding box extraction from masks, and mAP calculation using synthetic data to ensure mathematical correctness.
2.  **Dataset Demonstration**: Instantiates the `SIIMDataset` using the `get_dataset` factory with the `debug=True` flag. This loads a small subset of the real data, processes the DICOMs, and generates masks. We verify the shapes and data types of the yielded tensors.
3.  **Model Demonstration**: Instantiates the `ResNet18UNet` model. We perform a forward pass with a dummy tensor matching the dataset's output dimensions to verify the shapes of the segmentation mask and classification logits.
4.  **Engine/Training Loop**: Sets up a minimal training environment (Optimizer, Scaler, DataLoader) and executes one epoch of training using `train_one_epoch` and one evaluation cycle using `evaluate`. This demonstrates how the components integrate to learn and predict, verifying that loss values are returned and mAP is calculated.
