To address the task of classifying chest radiographs and detecting opacities with a highly efficient and distinct baseline, I propose the **Multi-Task Semantic Segmentation Network (U-Net)**.

### Model
The architecture is designed as a unified Encoder-Decoder network (U-Net) that simultaneously performs image classification and pixel-wise segmentation. This approach treats the "object detection" task as a segmentation problem, which is computationally efficient and well-suited for the amorphous shapes of lung opacities.

*   **Backbone (Encoder):** A lightweight, pre-trained Convolutional Neural Network (e.g., ResNet-18 or EfficientNet-B0) serves as the shared encoder. It extracts hierarchical features from the input radiograph, reducing spatial dimensions while increasing channel depth.
*   **Study-Level Head (Classification):** A Global Average Pooling layer is applied to the final feature map of the encoder (the bottleneck). This vector is fed into a simple fully connected layer with 4 outputs (corresponding to 'Negative', 'Typical', 'Indeterminate', 'Atypical') to predict the study-level labels.
*   **Image-Level Head (Segmentation):** The encoder features are fed into a decoder path with skip connections (standard U-Net design). The decoder upsamples the features back to the original input resolution and outputs a single-channel probability map representing the presence of "opacity" at each pixel.

### Data
*   **Input Processing:** All DICOM images will be resized to a fixed, moderate resolution (e.g., 512x512) to minimize computational overhead while retaining sufficient detail. Pixel intensities will be normalized to a standard range (0-1) or standardized using ImageNet statistics.
*   **Target Generation:**
    *   **Study Targets:** One-hot encoded vectors based on the study-level labels.
    *   **Image Targets:** Binary masks will be generated from the training bounding boxes. For every image, regions defined by the ground-truth bounding boxes will be filled with 1s (foreground), and the rest will be 0s (background). Images with "Negative for Pneumonia" will have completely black masks.

### Training
*   **Loss Function:** A composite loss function will be used: $L_{total} = L_{cls} + \lambda L_{seg}$.
    *   $L_{cls}$: Cross-Entropy loss for the study-level classification head.
    *   $L_{seg}$: Dice Loss or Binary Cross-Entropy (BCE) for the segmentation mask, ensuring the model focuses on the shape and location of opacities.
*   **Optimizer:** Adam or AdamW optimizer with a standard learning rate schedule (e.g., Cosine Annealing) to ensure stable convergence.
*   **Strategy:** The model is trained end-to-end. The shared encoder learns features relevant for both identifying the disease type and localizing the specific opacities.

### Evaluation
*   **Inference:** For each test image, the model outputs a 4-element classification vector and a pixel-wise probability mask.
*   **Study-Level Prediction:** The classification vector is processed (e.g., via Softmax or Sigmoid) to generate the required study label string.
*   **Image-Level Prediction:**
    1.  **Thresholding:** The probability mask is thresholded (e.g., > 0.5) to create a binary mask.
    2.  **Contour Extraction:** Connected components (contours) are identified in the binary mask.
    3.  **Box Generation:** A bounding rectangle is calculated for each contour.
    4.  **Consistency Check:** If the study-level prediction is strongly "Negative for Pneumonia", the image-level prediction is forced to "none 1 0 0 1 1". Otherwise, the generated boxes are formatted as "opacity [confidence] [xmin] [ymin] [xmax] [ymax]". The confidence for each box can be derived from the mean pixel probability within the contour.
