Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override specific parameters (`DEBUG`, `EPOCHS`, `BATCH_SIZE`, `NUM_WORKERS`) to ensure the script runs quickly on a small subset of data without multiprocessing overhead.
2.  **Data Loading Verification**: Initialize the training and validation data loaders using `get_train_val_loaders`. Fetch a single batch to verify the shape and data types of images, labels, and masks.
3.  **Model Initialization & Forward Pass**: Instantiate the `MultiTaskModel`. Perform a forward pass with the dummy batch to verify that the classification and segmentation logits have the expected dimensions.
4.  **Loss Function Test**: Initialize `MultiTaskLoss`. Compute the loss on the model outputs and verify that the returned dictionary contains scalar loss values.
5.  **Training Loop Execution**: Initialize an optimizer and run `train_one_epoch` for a single epoch. This demonstrates the integration of the model, data loader, MixUp augmentation, and loss calculation.
6.  **Evaluation Execution**: Run the `evaluate` function on the validation loader to demonstrate metric calculation (mAP) and validation loss reporting.
7.  **Inference & Submission**: Initialize the test loader, run `inference_and_submit`, and verify that the submission CSV is generated with the correct format and content.
