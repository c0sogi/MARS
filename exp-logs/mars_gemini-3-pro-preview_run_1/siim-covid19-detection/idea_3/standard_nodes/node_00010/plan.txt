The `RuntimeError` occurs because the `nn.AdaptiveAvgPool2d(1)` layer outputs a 4D tensor of shape `(Batch_Size, Channels, 1, 1)`, while the subsequent `nn.Linear` layer expects a 2D tensor of shape `(Batch_Size, Channels)` (or at least a tensor where the last dimension matches `in_features`). PyTorch's `nn.Linear` applies to the last dimension of the input, treating the preceding dimensions as batch dimensions. Consequently, it attempts to multiply a vector of size 1 (the last dimension) with weights expecting size 384, causing the shape mismatch. The fix is to flatten the pooled features using `torch.flatten` before passing them to the classification head.
