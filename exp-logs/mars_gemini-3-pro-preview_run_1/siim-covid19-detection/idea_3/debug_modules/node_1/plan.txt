The issue arises from Python's early binding of default arguments. The `get_dataloaders` function in `library/dataset.py` defines `batch_size=Config.BATCH_SIZE` as a default parameter, which is evaluated and bound to the value `16` at import time. When `runfile.py` modifies `Config.BATCH_SIZE` to `4` at runtime, the function call `get_dataloaders()` still uses the stale default value of `16` because the argument was not explicitly provided. To fix this, we must explicitly pass `batch_size=Config.BATCH_SIZE` in the function calls within `runfile.py`, ensuring the updated runtime value is used.
