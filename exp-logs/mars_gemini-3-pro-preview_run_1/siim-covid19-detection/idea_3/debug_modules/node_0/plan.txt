The following script demonstrates the end-to-end usage of the provided library modules for the Chest X-Ray classification and detection task.

### Implementation Strategy
1.  **Configuration Override**: We dynamically patch the `Config` class to use a temporary working directory and enable `DEBUG` mode. This ensures the script runs on a small subset of data (32 images) and creates new cache files, avoiding the overhead of loading the full dataset.
2.  **Data Pipeline Verification**: We initialize the `ChestXrayDataset` via `get_dataloaders` and `get_test_dataloader`. We assert that the output tensors have the correct shapes (Batch, Channels, Height, Width) and types.
3.  **Model Initialization**: We instantiate the `EfficientNetUnet` model and perform a dummy forward pass to verify that the classification logits and segmentation maps match the expected dimensions.
4.  **Training Loop**: We execute `train_one_epoch` using the `HybridLoss` function. This demonstrates the integration of the optimizer, model, and loss calculation.
5.  **Evaluation**: We run the `evaluate` function to compute the validation loss and mAP (mean Average Precision) score.
6.  **Inference & Submission**: We simulate the inference process on the test set, generating prediction strings using `format_prediction_string` and saving a sample submission file.
