The `AttributeError: type object 'Config' has no attribute 'DEVICE'` occurs because the `Config.DEVICE` attribute is dynamically initialized within the `Config.setup()` class method, but this method is never called in `runfile.py`. As a result, when the script attempts to access `Config.DEVICE` for logging or training, the attribute does not exist. To fix this, `Config.setup()` must be invoked at the beginning of the `main()` execution flow to ensure the configuration environment (including the device and directories) is properly initialized before use.
