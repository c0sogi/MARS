Implementation Strategy:
1.  **Configuration & Setup**: Import necessary modules and the provided library components. Override specific `Config` parameters (e.g., `EPOCHS`, `BATCH_SIZE`, `WORKING_DIR`) to ensure the script runs quickly and uses a temporary workspace.
2.  **Data Subsetting**: Create a "mini" version of the training, validation, and test metadata (CSV files) containing only a few rows. This drastically reduces the time required for DICOM image processing and loading.
3.  **Data Loading Verification**: Initialize the DataLoaders using the mini-datasets. Assert that the batch shapes for images, labels, and masks are correct.
4.  **Model Initialization**: Instantiate the `StochasticDepthResNet34UNet` model. Perform a forward pass with a dummy batch to verify that the classification and segmentation output shapes are correct.
5.  **Training Loop Execution**: Run the `train_one_epoch` function for a single epoch. Verify that the returned loss is valid (not NaN).
6.  **Validation Execution**: Run the `validate` function. Ensure it computes a loss and an mAP score without error.
7.  **Inference & Submission**: Run the `inference` function on the mini test set. Verify that the `submission.csv` file is generated, follows the correct format, and contains the expected number of predictions.
