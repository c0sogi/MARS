I will implement a robust Exploratory Data Analysis (EDA) script that focuses on the provided training metadata and DICOM images.

**Strategy:**
1.  **Setup & Loading**: Initialize the environment with fixed random seeds. Load the pre-generated `./metadata/train.csv`.
2.  **Target Variable Analysis**: Analyze the distribution of the four study-level classification labels (`Negative`, `Typical`, `Indeterminate`, `Atypical`). I will check for class imbalance and multi-label occurrences. I will also analyze the image-level target: the bounding boxes (count per image and spatial distribution).
3.  **Image Data Analysis**:
    *   Since the dataset consists of DICOM files, I will attempt to use `pydicom` to read a representative sample (N=300) of the training images.
    *   I will extract metadata tags (Rows, Columns, Photometric Interpretation) to analyze image dimensions and aspect ratios.
    *   I will compute pixel-level statistics (mean and standard deviation) on this sample to inform normalization strategies.
    *   *Contingency*: If `pydicom` is not available in the environment, I will gracefully skip the pixel-level analysis and report based on available metadata only.
4.  **Feature Relationships**:
    *   I will investigate the relationship between metadata features (e.g., Image Area, Number of Bounding Boxes) and the target classes.
    *   I will calculate correlations between the binary target labels.
5.  **Reporting**: The script will output a structured text report with capitalized sections, using formatted strings for precision.
