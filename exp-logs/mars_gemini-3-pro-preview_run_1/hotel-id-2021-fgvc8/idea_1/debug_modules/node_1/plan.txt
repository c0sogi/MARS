The execution failure is due to a breaking API change in `albumentations` version 2.0+. The error `pydantic_core._pydantic_core.ValidationError: 1 validation error for InitSchema size Field required` occurs because the `RandomResizedCrop` and `CenterCrop` transforms now require a single `size` argument (a tuple of `(height, width)`) instead of separate `height` and `width` arguments.

To fix this, I will update `library/dataset.py` to use the `size` parameter for both `A.RandomResizedCrop` and `A.CenterCrop` in the `get_transforms` function.
