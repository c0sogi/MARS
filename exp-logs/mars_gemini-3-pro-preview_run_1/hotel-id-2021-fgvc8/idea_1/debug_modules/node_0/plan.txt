This script demonstrates the usage of the provided Hotel Identification library. It covers the following steps:
1.  **Configuration Setup**: Overrides default configuration parameters (e.g., epochs, batch size, debug mode) to ensure the demonstration runs quickly within the time limit.
2.  **Utility Verification**: Validates the `HotelIdLabelEncoder` for correct encoding/decoding of targets and tests the `calculate_map5` metric function with a manual example to ensure accuracy.
3.  **Dataset Pipeline**: Instantiates the `HotelDataset` and `get_transforms` to verify that images are correctly loaded, augmented, and converted to tensors with the expected shapes.
4.  **Model Architecture**: Initializes the `HotelResNet` model and performs a dummy forward pass to confirm the output dimensions match the configuration.
5.  **Training & Inference Loop**: Uses the `Trainer` class to run a complete (but short) training epoch on a subset of data, followed by a prediction run on the test set, generating a valid submission file.
