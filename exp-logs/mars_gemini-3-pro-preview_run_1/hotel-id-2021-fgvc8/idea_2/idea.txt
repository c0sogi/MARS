Based on the provided model architectures and the requirement for a solution distinct from the standard classification baseline (Idea 1), here is a proposal for a **Lightweight Metric Learning Baseline**.

### Model
This approach synthesizes the efficiency of mobile-optimized architectures with the discriminative power of metric learning.
*   **Backbone**: Utilize **MobileNetV3-Large** pre-trained on ImageNet. This backbone is explicitly designed for minimal latency and parameter count, making it significantly faster and lighter than the ResNet-18 used in Idea 1 or the EfficientNet-B0 in Model 1.
*   **Neck**: Append a fully connected "embedding layer" (Linear + BatchNorm + PReLU) to the backbone's output to project the features into a compact 512-dimensional vector.
*   **Head**: Attach an **ArcFace (Additive Angular Margin)** head. Unlike the standard linear layer in Idea 1, this head maintains a set of learnable "class centers" (weights) and computes the cosine similarity between the image embedding and these centers, adding an angular margin penalty to the target class to enforce tighter intra-class clustering.

### Data
*   **Preprocessing**: Resize all images to **256x256** and perform a center crop to **224x224**. This standardizes the input size for the MobileNet backbone.
*   **Normalization**: Apply standard ImageNet normalization (mean and standard deviation) to pixel values.
*   **Augmentation**: Use only **Horizontal Flipping** during training. This is computationally free and prevents the model from overfitting to object orientation without introducing the processing overhead of complex augmentations.

### Training
*   **Objective**: Minimize the **ArcFace Loss**. This loss function is specifically effective for datasets with high cardinality (7,700+ hotels) and low inter-class variance, as it optimizes the angular distribution of features on a hypersphere rather than just probability magnitudes.
*   **Optimizer**: Use **AdamW** with a standard learning rate (e.g., 1e-3) and weight decay to prevent overfitting.
*   **Strategy**: Train for a fixed number of epochs (e.g., 10-15) using a **Cosine Annealing** learning rate scheduler. This ensures the model converges smoothly to a stable solution within the time limit.

### Evaluation
*   **Inference**: For each test image, perform a forward pass through the backbone and embedding layer to extract the normalized 512-dimensional feature vector.
*   **Retrieval**: Calculate the **Cosine Similarity** between the test image's embedding and the learned class centers (the weights of the ArcFace head).
*   **Prediction**: Rank the class centers by their similarity score and output the top 5 Hotel IDs corresponding to the highest scores.
