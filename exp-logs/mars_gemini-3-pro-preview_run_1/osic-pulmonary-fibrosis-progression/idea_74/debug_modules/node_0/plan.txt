The following script demonstrates the end-to-end usage of the provided library components for the Pulmonary Fibrosis Progression task.

### Implementation Strategy
1.  **Configuration Override**: We modify the `Config` class to run in `DEBUG` mode with a very small batch size and sample size. This ensures the script executes quickly (seconds instead of hours) while still exercising all code paths.
2.  **Data Loading Verification**: We utilize `get_dataloaders(debug=True)` to load a subset of the data. We explicitly verify the dictionary keys and tensor shapes of the batch to ensure the `OSICDataset` and `process_dicom` pipeline is functioning correctly.
3.  **Model & Loss Verification**: We instantiate `PCCGNet` and `LaplaceLogLikelihoodLoss`. We perform a forward pass with real data from the loader and compute the loss, asserting that the output shapes are correct and the loss is a valid scalar.
4.  **Training & Evaluation Loop**: We execute `train_one_epoch` and `evaluate` for a single epoch on the reduced dataset. This verifies the optimization step and metric calculation logic in `engine.py`.
5.  **Inference & Submission**: We run the `predict` function on the test set and generate a sample submission file, demonstrating how to map model outputs back to the required CSV format.
