The following script demonstrates the end-to-end usage of the provided library files for the lung function decline prediction task.

**Implementation Strategy:**
1.  **Setup and Configuration**: We initialize the environment and modify the `Config` class to point to a smaller subset of the data. This ensures the demonstration runs quickly (seconds instead of hours) while exercising the full pipeline.
2.  **Data Preparation**: We create temporary subset CSV files in the `./working` directory by sampling the provided metadata. This verifies that the `OSICDataset` and `get_dataloaders` functions can handle the data format correctly.
3.  **Component Verification**:
    *   **Data Loading**: We fetch a batch from the training loader and assert the shapes of the image tensors (Axial/Coronal), tabular features, and target variables.
    *   **Model Architecture**: We instantiate the `DALANet` model, perform a forward pass with the fetched batch, and verify that the outputs (`FVC` and `Confidence`) have the correct dimensions and constraints (e.g., positive confidence).
    *   **Loss Function**: We compute the `LaplaceLogLikelihoodLoss` on the batch to ensure the mathematical operations are stable.
4.  **Training Loop**: We execute a minimal training run (2 epochs on the subset) using `train_one_epoch` and `valid_one_epoch` to demonstrate the optimization process and metric tracking.
5.  **Inference and Submission**: We run the trained model on the test set, generate predictions, and format them into the required submission structure, verifying the final output format.
