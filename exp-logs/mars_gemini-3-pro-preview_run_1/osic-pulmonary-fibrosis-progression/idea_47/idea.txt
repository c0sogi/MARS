Based on the comprehensive analysis of the accumulated lessons, specifically the convergence of findings regarding **Dimensionality Balancing** (Cite solution_lesson_node_00080), **Shared Representation Learning** (Cite solution_lesson_node_00082), and **Holistic Contextualization** (Cite solution_lesson_node_00078), I propose the **Shared-Latent Holistic Dual-Axis Network (SLH-DAN)**.

This solution represents a structural synthesis that resolves the "Split-Path" and "Prior Dilution" conflicts identified in previous iterations. It combines the stability of **Low-Capacity Backbones** with a **Shared Latent Topology** that ensures the clinical prior is both deeply integrated into the visual fusion *and* preserved for the final prediction without gradient fragmentation or signal drowning.

### 1. Model: Shared-Latent Holistic Dual-Axis Network (SLH-DAN)

**Architecture Design**
1.  **Independent Low-Capacity Visual Backbones:**
    *   We utilize two separate **EfficientNet-B0** backbones (initialized with ImageNet weights) to process the orthogonal views. This strictly respects the low-capacity requirement for the small dataset to prevent "confidence overfitting" (Cite solution_lesson_node_00079).
    *   **Branch A (Axial):** Processes the Axial Tri-Slab input.
    *   **Branch B (Coronal):** Processes the Coronal Tri-Slab input.
    *   **High-Fidelity Extraction:** We apply **Global Average Pooling (GAP)** to the output feature maps. **Crucially**, we maintain the **native backbone dimensionality** (1280-dim) and do **not** project these down. This adheres to the lesson that compressing visual features destroys critical texture signals (Cite solution_lesson_node_00039). Explicit modality embeddings are omitted as independent backbones render them redundant (Cite solution_lesson_node_00056).

2.  **Shared-Latent Tabular Encoder (Structural Innovation):**
    *   To resolve the conflict between "Dual-Path" inefficiency (Cite solution_lesson_node_00082) and "Raw Scalar" dilution (Cite solution_lesson_node_00080), we employ a **Shared Latent Topology**.
    *   **Shared Encoder:** The raw metadata (Age, Sex, Smoking, **Percent** - Cite solution_lesson_node_00017) is processed by a **Deep MLP** (`Linear -> GeLU -> Linear -> GeLU`) to produce a robust **Shared Latent Vector ($T_{lat}$)** of dimension **128**.
    *   *Rationale:* This 128-dim vector serves as the single source of truth for the clinical prior, receiving gradients from both the fusion task and the direct prediction task. It provides non-linear alignment (Cite solution_lesson_node_00070) without parameter explosion.

3.  **Bifurcated Flow with Alignment:**
    *   **Flow A (Fusion Alignment):** $T_{lat}$ (128-dim) is projected via a linear layer to **1280-dim** ($T_{align}$) to match the visual backbone. This satisfies the dimensionality requirement for attention (Cite solution_lesson_node_00039) without inflating raw scalars (Cite solution_lesson_node_00043).
    *   **Flow B (Prior Preservation):** $T_{lat}$ (128-dim) is passed directly to the skip connection. This ensures the prior has sufficient bandwidth to influence the head (unlike raw scalars) but remains distinct from the high-dim visual noise (Cite solution_lesson_node_00080).

4.  **Pre-Norm Symmetric Attention (Contextualization Phase):**
    *   **Tokenization:** We stack the vectors into a sequence: $[V_{ax}, V_{cor}, T_{align}]$.
    *   **Fusion:** A single **Multi-Head Self-Attention** layer processes this sequence. We employ **Pre-Normalization** for stability (Cite solution_lesson_node_00008) and retain the Feed-Forward Network (FFN) with dropout to provide non-linear capacity (Cite solution_lesson_node_00070).
    *   **Holistic Readout:** We apply **Global Average Pooling** across **ALL** updated tokens ($V'_{ax}, V'_{cor}, T'_{align}$) to derive the fused context vector $H_{fused}$. This preserves the contextualized clinical signal (Cite solution_lesson_node_00078) and avoids flattening (Cite solution_lesson_node_00047).

5.  **Balanced Prior-Anchored Head:**
    *   We concatenate the **Holistic Fused Vector** ($H_{fused}$, 1280-dim) with the **Shared Latent Vector** ($T_{lat}$, 128-dim).
    *   **Constraint:** The head predicts $\alpha$ (Slope), $\sigma_{base}$, and $\sigma_{growth}$. We strictly exclude `Week` or `Time` from the input (Cite solution_lesson_node_00062).
    *   **Activation:** We apply **Softplus** activation to the $\sigma$ outputs (Cite solution_lesson_node_00021).

### 2. Data: Fixed Overlapping Orthogonal Tri-Slabs

**Preprocessing**
1.  **Dual-View Generation:** For each patient, generate two inputs to capture 3D spatial heterogeneity (Cite solution_lesson_node_00010).
    *   **Axial Tri-Slab (RGB):** Split the CT volume along the Z-axis (Depth) into three slabs with **fixed boundaries** (0-33%, 33-66%, 66-100%) and **15% overlap**. Compute MIPs and map to RGB (Cite solution_lesson_node_00006). We strictly avoid stochastic jitter (Cite solution_lesson_node_00035).
    *   **Coronal Tri-Slab (RGB):** Split along the Y-axis (Anterior-Posterior) into three overlapping slabs, compute MIPs, and map to RGB.
2.  **Resolution:** Resize all images to **224x224**. This matches the **native resolution of EfficientNet-B0**, strictly avoiding the overfitting caused by resolution mismatch (Cite solution_lesson_node_00009).

**Augmentation**
1.  **Spatial Only:** Apply random horizontal flips, shifts, and slight rotations (Cite solution_lesson_node_00007).
2.  **No Intensity Changes:** Strictly **disable** brightness/contrast augmentations to preserve the physical Hounsfield Unit density signal (Cite solution_lesson_node_00005).

### 3. Training: Robust Metric Optimization

**Procedure**
*   **Loss Function:** Modified Laplace Log Likelihood. We explicitly **retain the error clipping** (thresholding absolute error at 1000 ml) to filter outliers (Cite solution_lesson_node_00013). No auxiliary losses (Cite solution_lesson_node_00016).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.
*   **Strategy:** Use a strict patience (e.g., 6-8 epochs) for **Early Stopping**. We avoid Stochastic Weight Averaging (SWA) as it degrades performance on this small dataset (Cite solution_lesson_node_00030).

### 4. Evaluation: Parametric Inference

For every `Patient_Week` in the test set:
1.  Generate the Fixed Overlapping Axial and Coronal Tri-Slab images (224x224).
2.  Pass inputs and baseline metadata through the **SLH-DAN** model to obtain static parameters $\alpha, \sigma_{base}, \sigma_{growth}$.
3.  Calculate predictions using the anchored trajectory logic (Cite solution_lesson_node_00045):
    *   $$ \text{FVC} = \text{Baseline\_FVC} + \alpha \times (\text{Week} - \text{Baseline\_Week}) $$
    *   $$ \text{Confidence} = \sigma_{base} + \sigma_{growth} \times |\text{Week} - \text{Baseline\_Week}| $$
4.  Clip the Confidence at 70 ml as required by the metric.
