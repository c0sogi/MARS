The `RuntimeError` is caused by `pydicom` failing to decompress JPEG Lossless encoded DICOM files due to missing system dependencies (`gdcm`, `pylibjpeg`) in the restricted environment. To address this, I will modify `library/data.py` to wrap the pixel array extraction in a `try-except RuntimeError` block. This allows the `load_scan` function to gracefully return `None` upon decompression failure, which triggers the existing fallback mechanism in `process_patient` to generate and cache placeholder images, preventing the pipeline from crashing or entering retry loops (Cite debug_lesson_2, debug_lesson_8).
