Based on the comprehensive analysis of the accumulated lessons, specifically the convergence of findings regarding **Dimensionality Balancing** (Cite solution_lesson_node_00080), **Shared Representation Learning** (Cite solution_lesson_node_00082), **Normalization Preconditions** (Cite solution_lesson_node_00095), and the nuance of **Holistic Readout** (Cite solution_lesson_node_00078), I propose the **Split-Context Shared-Latent Network (SCSL-Net)**.

This solution represents a structural evolution that resolves the "Bandwidth Competition" between modalities. While previous "Holistic" approaches pooled all tokens together (implicitly weighting the visual signal at 66% in a 3-token sequence), and "Visual-Exclusive" approaches discarded the contextualized tabular token (losing non-linear interactions), this architecture separates the **Visual Context**, **Tabular Context**, and **Tabular Prior** into distinct streams. It compresses the high-dimensional contextual streams to strictly enforce a balanced contribution (e.g., 50% Prior, 50% Context) at the final decision layer, maximizing the utility of the dominant clinical signal while preserving the visual residual.

### 1. Model: Split-Context Shared-Latent Network (SCSL-Net)

**Architecture Design**
1.  **Independent Low-Capacity Visual Backbones:**
    *   We utilize two separate **EfficientNet-B0** backbones (initialized with ImageNet weights) to process the **Axial** and **Coronal** views. This respects the low-capacity requirement for the small dataset (Cite solution_lesson_node_00079).
    *   **High-Fidelity Extraction:** We apply **Global Average Pooling (GAP)** to the output feature maps. We maintain the **native backbone dimensionality** (1280-dim) and do **not** project these down, preserving critical texture signals (Cite solution_lesson_node_00039). Explicit modality embeddings are omitted (Cite solution_lesson_node_00056).

2.  **Shared-Latent Tabular Encoder:**
    *   We employ a **Shared Latent Topology** to process the raw metadata (Age, Sex, Smoking, **Percent** - Cite solution_lesson_node_00017).
    *   **Shared Encoder:** A **Deep MLP** (`Linear -> GeLU -> Linear -> GeLU`) projects the scalars to a robust **Shared Latent Vector ($T_{lat}$)** of dimension **128**. This serves as the single source of truth for the clinical prior, preventing gradient splitting (Cite solution_lesson_node_00082) and providing non-linear alignment (Cite solution_lesson_node_00070).

3.  **Normalized Bifurcated Flow:**
    *   **Flow A (Fusion Alignment):** $T_{lat}$ (128-dim) is projected via a linear layer to **1280-dim** ($T_{align}$). **Crucially**, we apply **Layer Normalization** immediately after this projection to prevent initialization shock in the attention block (Cite solution_lesson_node_00095).
    *   **Flow B (Prior Preservation):** $T_{lat}$ (128-dim) is reserved for the final assembly.

4.  **Pre-Norm Symmetric Attention (Contextualization Phase):**
    *   **Tokenization:** Sequence $[V_{ax}, V_{cor}, \text{LayerNorm}(T_{align})]$.
    *   **Fusion:** A single **Multi-Head Self-Attention** layer (with Pre-Norm and FFN) processes this sequence (Cite solution_lesson_node_00008).
    *   **Output:** Updated tokens $V'_{ax}, V'_{cor}$ (Contextualized Visual) and $T'_{align}$ (Contextualized Tabular).

5.  **Split-Stream Compressed Readout (Structural Innovation):**
    *   Instead of pooling everything into one vector, we process the streams separately to control their bandwidth:
    *   **Visual Stream:** $H_{vis} = \text{Mean}(V'_{ax}, V'_{cor})$ (1280-dim). Projected down to **64-dim**.
    *   **Tabular Context Stream:** $H_{ctx} = T'_{align}$ (1280-dim). Projected down to **64-dim**.
    *   **Prior Stream:** The raw Shared Latent Vector $T_{lat}$ (**128-dim**).
    *   **Assembly:** We concatenate $[H_{vis\_64}, H_{ctx\_64}, T_{lat\_128}]$.
    *   *Rationale:* The final 256-dim vector is composed of 50% **Raw Prior** ($T_{lat}$) and 50% **Learned Context** (split evenly between visual and tabular). This strictly enforces Dimensionality Balancing (Cite solution_lesson_node_00080) and ensures the visual noise cannot statistically drown out the clinical ground truth, while still retaining the non-linear tabular context discarded by visual-exclusive approaches (Cite solution_lesson_node_00078).

6.  **Parametric Head:**
    *   The head predicts $\alpha$ (Slope), $\sigma_{base}$, and $\sigma_{growth}$. We strictly exclude `Week` or `Time` from the input (Cite solution_lesson_node_00062).
    *   **Activation:** We apply **Softplus** activation to the $\sigma$ outputs (Cite solution_lesson_node_00021).

### 2. Data: Fixed Overlapping Orthogonal Tri-Slabs

**Preprocessing**
1.  **Dual-View Generation:** For each patient, generate two inputs to capture 3D spatial heterogeneity (Cite solution_lesson_node_00010).
    *   **Axial Tri-Slab (RGB):** Split the CT volume along the Z-axis (Depth) into three slabs with **fixed boundaries** (0-33%, 33-66%, 66-100%) and **15% overlap**. Compute MIPs and map to RGB (Cite solution_lesson_node_00006). We strictly avoid stochastic jitter (Cite solution_lesson_node_00035).
    *   **Coronal Tri-Slab (RGB):** Split along the Y-axis (Anterior-Posterior) into three overlapping slabs, compute MIPs, and map to RGB.
2.  **Resolution:** Resize all images to **224x224**. This matches the **native resolution of EfficientNet-B0**, strictly avoiding the overfitting caused by resolution mismatch (Cite solution_lesson_node_00009).

**Augmentation**
1.  **Spatial Only:** Apply random horizontal flips, shifts, and slight rotations (Cite solution_lesson_node_00007).
2.  **No Intensity Changes:** Strictly **disable** brightness/contrast augmentations (Cite solution_lesson_node_00005).

### 3. Training: Robust Metric Optimization

**Procedure**
*   **Loss Function:** Modified Laplace Log Likelihood. We explicitly **retain the error clipping** (thresholding absolute error at 1000 ml) to filter outliers (Cite solution_lesson_node_00013). No auxiliary losses (Cite solution_lesson_node_00016).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.
*   **Strategy:** Use a strict patience (e.g., 6-8 epochs) for **Early Stopping**. We avoid Stochastic Weight Averaging (SWA) as it degrades performance on this small dataset (Cite solution_lesson_node_00030).

### 4. Evaluation: Parametric Inference

For every `Patient_Week` in the test set:
1.  Generate the Fixed Overlapping Axial and Coronal Tri-Slab images (224x224).
2.  Pass inputs and baseline metadata through the **SCSL-Net** model to obtain static parameters $\alpha, \sigma_{base}, \sigma_{growth}$.
3.  Calculate predictions using the anchored trajectory logic (Cite solution_lesson_node_00045):
    *   $$ \text{FVC} = \text{Baseline\_FVC} + \alpha \times (\text{Week} - \text{Baseline\_Week}) $$
    *   $$ \text{Confidence} = \sigma_{base} + \sigma_{growth} \times |\text{Week} - \text{Baseline\_Week}| $$
4.  Clip the Confidence at 70 ml as required by the metric.
