The `RuntimeError: Unknown model (efficientnet-b0)` occurs because the `timm` library's model registry uses underscores for EfficientNet identifiers (e.g., `efficientnet_b0`), whereas the configuration file specifies `efficientnet-b0` with a hyphen. This registry key mismatch causes the factory method to fail (Cite debug_lesson_8). I will update the `BACKBONE` configuration in `library/config.py` to use the correct identifier.
