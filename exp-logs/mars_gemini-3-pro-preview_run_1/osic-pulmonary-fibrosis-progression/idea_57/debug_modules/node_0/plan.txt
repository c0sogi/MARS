The implementation strategy is as follows:

1.  **Setup and Configuration**: Initialize the environment by setting reproducible seeds and overriding specific `Config` parameters (like `BATCH_SIZE`, `EPOCHS`, and `CACHE_DIR`) to ensure the demo runs quickly and uses a temporary directory for caching processed images.
2.  **Data Preparation**: Load the provided metadata CSVs (`train.csv` and `test.csv`). Create small subsets of these DataFrames (e.g., 2 patients for training, 1 for testing) to minimize runtime during the computationally expensive DICOM processing.
3.  **Dataset & DataLoader Demonstration**: Instantiate the `OSICDataset` class using the training subset. Verify the integrity of the data produced by `__getitem__` (checking shapes of image tensors and tabular data). Create a PyTorch `DataLoader`.
4.  **Model Initialization**: Instantiate the `SCSLNet` model. Perform a dummy forward pass with a single batch to confirm the output shape corresponds to the expected parametric outputs (`alpha`, `sigma_base`, `sigma_growth`).
5.  **Training Loop**: Initialize the `LaplaceLoss` criterion and an optimizer. Execute `train_one_epoch` to demonstrate the training pipeline and verify that the loss is computed and backpropagated without errors.
6.  **Evaluation**: Run the `evaluate` function on the training subset (acting as a validation set for this demo) to calculate the competition metric.
7.  **Inference & Submission**: Instantiate the `OSICDataset` in test mode. Iterate through the test data, perform inference, and calculate the final `FVC` and `Confidence` using the model's parametric outputs and the time delta. Construct a sample submission DataFrame.
8.  **Metric Validation**: Manually verify the `laplace_log_likelihood_metric` function with known inputs to ensure it adheres to the mathematical definition provided in the task.
