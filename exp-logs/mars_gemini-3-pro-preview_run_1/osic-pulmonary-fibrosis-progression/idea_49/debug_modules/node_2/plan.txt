The `RuntimeError: Input type (torch.cuda.DoubleTensor) and weight type (torch.cuda.FloatTensor) should be the same` occurs because the image data is being processed and stored as 64-bit floating point (`float64`), which PyTorch converts to `DoubleTensor`, while the model weights are `FloatTensor` (`float32`). This happens because standard Python float operations (like the normalization division) promote arrays to `float64`, and the validation/test transforms (unlike training) do not include an operation that implicitly casts back to `float32`.

To fix this, I will modify `library/data.py` to explicitly cast image data to `float32` at three critical points:
1.  When loading cached arrays from disk (Cite debug_lesson_10).
2.  When returning the generated tri-slab image.
3.  After normalizing the CT volume.
