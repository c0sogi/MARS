Based on the comprehensive analysis of the accumulated lessons and the evolution of previous strategies, I propose the **Progressive-Aligned Visual-Exclusive Network (PAVE-Net)**.

This solution represents a structural synthesis designed to resolve the "Signal Dilution" and "Alignment" conflicts identified in previous iterations. It combines **Independent High-Fidelity Backbones** (Cite solution_lesson_node_00014, solution_lesson_node_00039) with a **Progressive Tabular Alignment** module (resolving the conflict between Cite solution_lesson_node_00043 and solution_lesson_node_00070) and a **Visual-Exclusive Readout** (refining Cite solution_lesson_node_00038). This architecture strictly enforces the separation of the "Clinical Prior" and the "Visual Residual" to maximize predictive accuracy on the small dataset.

### 1. Model: Progressive-Aligned Visual-Exclusive Network (PAVE-Net)

**Architecture Design**
1.  **Independent High-Fidelity Visual Backbones:**
    *   The model utilizes two separate **EfficientNet-B0** backbones (initialized with ImageNet weights) to process the orthogonal views.
    *   **Branch A (Axial):** Processes the Axial Tri-Slab input.
    *   **Branch B (Coronal):** Processes the Coronal Tri-Slab input.
    *   **High-Fidelity Extraction:** We apply **Global Average Pooling (GAP)** to the output feature maps to obtain robust global descriptors $V_{ax}$ and $V_{cor}$. **Crucially**, we maintain the **native backbone dimensionality** (1280-dim) and do **not** project these down. This strictly adheres to the lesson that compressing visual features destroys critical texture signals in small datasets (Cite solution_lesson_node_00039). Independent backbones allow view-specific texture learning without explicit modality embeddings (Cite solution_lesson_node_00056).

2.  **Progressive Tabular Alignment (Structural Innovation):**
    *   To resolve the tension between "avoiding inflation" (Cite solution_lesson_node_00043) and "needing non-linearity" (Cite solution_lesson_node_00070), we employ a **Progressive Expansion MLP**.
    *   Instead of a single massive projection or granular tokens, the raw metadata (Age, Sex, Smoking, **Percent** - Cite solution_lesson_node_00017) is projected to 1280-dim via a narrow-to-wide bottleneck structure: $7 \to 64 \to 256 \to 1280$.
    *   **Components:** Each stage includes `Linear -> LayerNorm -> GeLU`.
    *   *Rationale:* This creates a deep, semantically rich representation of the clinical prior that is aligned with the visual manifold, without the parameter explosion of granular tokenization.

3.  **Pre-Norm Symmetric Attention (Contextualization Phase):**
    *   **Tokenization:** We stack the vectors into a sequence: $[V_{ax}, V_{cor}, V_{tab}]$.
    *   **Fusion:** A single **Multi-Head Self-Attention** layer processes this sequence. We employ **Pre-Normalization** (LayerNorm before Attention) for stability (Cite solution_lesson_node_00008). We retain the Feed-Forward Network (FFN) with high dropout (0.5) to provide necessary non-linear capacity (Cite solution_lesson_node_00070).
    *   **Mechanism:** This allows the visual tokens to be "contextualized" by the tabular token (e.g., resolving spatial ambiguity using disease severity) via Symmetric Self-Attention (Cite solution_lesson_node_00028).

4.  **Visual-Exclusive Pooled Readout (Isolation Phase):**
    *   **Structural Innovation:** We extract *only* the updated visual tokens $V'_{ax}$ and $V'_{cor}$ from the attention output. We **discard** the contextualized tabular token from the pooling operation.
    *   **Aggregation:** We apply **Average Pooling** to the two visual tokens to derive a single **Contextualized Visual Residual** vector.
    *   *Rationale:* This strictly isolates the "Visual Delta"—the new information provided by the scan—without diluting it with the projected tabular embedding (Refining Cite solution_lesson_node_00038) or risking the noise of Max Pooling (Cite solution_lesson_node_00065).

5.  **Prior-Anchored Parametric Head (Correction Phase):**
    *   We concatenate the Contextualized Visual Residual with the **Raw Tabular Features** (original scalars) via a skip connection. This guarantees the regression head has direct, uncorrupted access to the strong scalar priors (Baseline FVC, Percent) (Cite solution_lesson_node_00018).
    *   **Constraint:** The head predicts $\alpha$ (Slope), $\sigma_{base}$, and $\sigma_{growth}$. **Crucially**, we do **not** include `Week` or `Time` as inputs. The parameters are derived solely from static baseline characteristics (Cite solution_lesson_node_00062).
    *   **Activation:** We apply **Softplus** activation to the $\sigma$ outputs (Cite solution_lesson_node_00021).

### 2. Data: Fixed Overlapping Orthogonal Tri-Slabs

**Preprocessing**
1.  **Dual-View Generation:** For each patient, generate two inputs to capture 3D spatial heterogeneity (Cite solution_lesson_node_00010).
    *   **Axial Tri-Slab (RGB):** Split the CT volume along the Z-axis (Depth) into three slabs with **fixed boundaries** (0-33%, 33-66%, 66-100%) and **15% overlap**. Compute MIPs and map to RGB (Cite solution_lesson_node_00006). We strictly avoid stochastic jitter to preserve semantic spatial consistency (Cite solution_lesson_node_00035).
    *   **Coronal Tri-Slab (RGB):** Split along the Y-axis (Anterior-Posterior) into three overlapping slabs, compute MIPs, and map to RGB.
2.  **Resolution:** Resize all images to **224x224**. This matches the **native resolution of EfficientNet-B0**, strictly avoiding the overfitting caused by resolution mismatch (Cite solution_lesson_node_00009).

**Augmentation**
1.  **Spatial Only:** Apply random horizontal flips, shifts, and slight rotations (Cite solution_lesson_node_00007).
2.  **No Intensity Changes:** Strictly **disable** brightness/contrast augmentations to preserve the physical Hounsfield Unit density signal (Cite solution_lesson_node_00005).

### 3. Training: Robust Metric Optimization

**Procedure**
*   **Loss Function:** Modified Laplace Log Likelihood. We explicitly **retain the error clipping** (thresholding absolute error at 1000 ml) to filter outliers (Cite solution_lesson_node_00013). No auxiliary losses (Cite solution_lesson_node_00016).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.
*   **Strategy:** Use a strict patience (e.g., 6-8 epochs) for **Early Stopping**. We avoid Stochastic Weight Averaging (SWA) as it degrades performance on this small dataset (Cite solution_lesson_node_00030).

### 4. Evaluation: Parametric Inference

For every `Patient_Week` in the test set:
1.  Generate the Fixed Overlapping Axial and Coronal Tri-Slab images.
2.  Pass inputs and baseline metadata through the **PAVE-Net** to obtain static parameters $\alpha, \sigma_{base}, \sigma_{growth}$.
3.  Calculate predictions using the anchored trajectory logic (Cite solution_lesson_node_00045):
    *   $$ \text{FVC} = \text{Baseline\_FVC} + \alpha \times (\text{Week} - \text{Baseline\_Week}) $$
    *   $$ \text{Confidence} = \sigma_{base} + \sigma_{growth} \times |\text{Week} - \text{Baseline\_Week}| $$
4.  Clip the Confidence at 70 ml as required by the metric.
