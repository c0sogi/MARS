Based on the dataset characteristics and the constraints provided, I propose the following highly efficient baseline approach.

### **Model: MIP-Based Linear Decay Network**

**Architecture Design**
This approach simplifies the complex 3D volumetric problem into a 2D regression task by utilizing **Maximum Intensity Projection (MIP)**. The core philosophy is that lung function decline in fibrosis patients is largely determined by the extent of scarring (high-density tissue). A MIP projects the 3D volume onto a 2D plane by taking the maximum density value at each pixel location across the depth axis, effectively summarizing the "worst-case" scarring in a single image.

1.  **Image Branch:** The input is a single 2D MIP image constructed from the patient's CT scan. This is fed into a lightweight, pre-trained CNN (e.g., ResNet-18) to extract a dense feature vector representing the severity of fibrosis.
2.  **Tabular Branch:** A simple Multi-Layer Perceptron (MLP) processes the baseline clinical metadata (Age, Sex, SmokingStatus) and the `Baseline_Percent` (normalized).
3.  **Fusion & Prediction Head:** The image and tabular features are concatenated. Instead of predicting the absolute `FVC` for every week (which varies temporally), the network predicts two patient-specific scalar values:
    *   **$\alpha$ (Decline Rate/Slope):** The rate at which the patient's lung function is decaying per week.
    *   **$\sigma$ (Uncertainty):** A baseline confidence level for the patient.

**Inference Logic**
The model does not output the FVC directly. Instead, it predicts the *trajectory*. The final prediction for any given week $t$ is calculated deterministically using the patient's known `Baseline_FVC` (measured at week 0):
$$ \text{FVC}_{pred}(t) = \text{Baseline\_FVC} + \alpha \times t $$
This ensures that the prediction is perfectly anchored to the ground truth at week 0, a critical anchor point for this dataset.

### **Data: Preprocessing and Preparation**

**Training Data Preparation**
1.  **Image Processing (MIP Generation):** For each patient, load the middle 50% of the CT slices (to avoid noise from the stomach or shoulders). Compute the Maximum Intensity Projection along the axial direction.
2.  **Normalization:** Resize the resulting 2D image to $224 \times 224$. Apply windowing to focus on lung tissue (e.g., clip Hounsfield Units between -1000 and 400), then normalize pixel values to the $[0, 1]$ range.
3.  **Tabular Data:** One-hot encode `Sex` and `SmokingStatus`. Normalize `Age` and `Percent`.

**Evaluation Data Preparation**
*   Process the test set CT scans identically to generate one MIP image per test patient.

### **Training: Procedure and Strategy**

**Loss Function**
Train the model end-to-end using the competition's **Modified Laplace Log Likelihood** as the loss function.
*   For a training sample (Patient $P$, Week $t$, True FVC $y_{true}$):
    1.  The model predicts $\alpha$ and $\sigma$.
    2.  Compute $\hat{y} = \text{Baseline\_FVC}_P + \alpha \times t$.
    3.  Compute the metric loss using $\hat{y}$, $y_{true}$, and $\sigma$.

**Training Strategy**
*   **Data Sampling:** Treat every recorded visit in `train.csv` as a training sample. The input (Baseline CT + Baseline Metadata) remains constant for a patient, but the target `FVC` and the input time delta ($t$) change for each visit.
*   **Optimization:** Use the Adam optimizer with a standard learning rate (e.g., 1e-4). Since the visual backbone is pre-trained, use a lower learning rate for the CNN layers and a higher one for the regression head.
*   **Efficiency:** Because the 3D volume is reduced to a single 2D image during preprocessing, the training loop is extremely fast (comparable to standard image classification) and requires minimal GPU memory compared to 3D CNNs or MIL approaches.

### **Evaluation: Prediction Generation**

1.  **Inference:** For each patient in the test set, pass their MIP image and baseline metadata through the model to obtain their predicted Slope ($\alpha$) and Confidence ($\sigma$).
2.  **Extrapolation:** For every requested `Patient_Week` in the submission file:
    *   Extract the relative week number ($t$).
    *   Calculate `FVC` = $\text{Baseline\_FVC} + \alpha \times t$.
    *   Use the predicted $\sigma$ as the `Confidence` value.
3.  **Formatting:** Save these values into the submission CSV format.
