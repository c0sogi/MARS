Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the `Config` class to set up directories and random seeds for reproducibility. Define the computation device (GPU/CPU).
2.  **Data Preparation**: Instantiate `LungDataset` for training, validation, and testing. Wrap them in `DataLoader`s with appropriate batch sizes and worker counts to maximize throughput on the provided hardware.
3.  **Model Training**: Invoke the `train_model` function from the engine. This handles the training loop, validation per epoch, optimizer stepping, learning rate scheduling, and early stopping, saving the best model to disk.
4.  **Validation Assessment**: Load the best saved model state. Run a dedicated evaluation pass on the validation set to compute the `Final Validation Metric` (Modified Laplace Log Likelihood).
5.  **Failure Analysis**: Perform a detailed inference pass on the validation set to extract predictions, ground truth, and input features. Calculate the absolute prediction error and compute Pearson correlations between the error and input features (Age, Sex, Smoking Status, Percent) to identify sources of model bias.
6.  **Submission Generation**: Compare the final validation metric against the threshold (-6.510164260864258). If the model performs sufficiently well, run the `predict` function on the test set to generate `submission.csv` formatted according to competition requirements.
