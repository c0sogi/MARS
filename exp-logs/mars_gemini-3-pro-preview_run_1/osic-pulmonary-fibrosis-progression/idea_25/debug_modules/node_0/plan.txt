This script demonstrates the end-to-end pipeline for the Pulmonary Fibrosis Progression task using the provided library.

**Implementation Strategy:**
1.  **Configuration**: We enable `debug_mode` in the `Config` class. This reduces the number of epochs to 2 and limits the dataset size to 32 samples, ensuring the script runs very quickly for demonstration purposes.
2.  **Data Loading**: We instantiate `LungDataset` for training, validation, and testing. We verify the data loading process by inspecting a single batch to ensure tensor shapes and types are correct.
3.  **Model Verification**: We instantiate the `IASDANet` model and perform a dummy forward pass with a batch of data. We assert that the output shapes (FVC prediction and Confidence) are correct before proceeding to training.
4.  **Training**: We execute the `train_model` function from the engine, which handles the training loop, validation, and checkpoint saving.
5.  **Inference**: We run the `predict` function to generate predictions on the test set using the trained model.
6.  **Result Validation**: Finally, we load the generated submission file, verify its structure (columns, row count), and ensure that confidence values adhere to the clipping constraints.
