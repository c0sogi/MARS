### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override specific parameters (e.g., `EPOCHS`, `BATCH_SIZE`, `DEBUG` flags) to ensure the script runs quickly on a small subset of data.
2.  **Component Verification**:
    *   **Dataset**: Instantiate `PulmonaryDataset` using the training metadata. Fetch a single sample to verify the shape and data types of the returned tensors (Image, Tabular features, Targets).
    *   **Model**: Instantiate `TriSlabModel`. Perform a forward pass with the sample data to confirm the output shape corresponds to the expected parameters `[alpha, sigma_base, sigma_growth]`.
    *   **Loss**: Instantiate `LaplaceLogLikelihoodLoss` and compute the loss on the model's output to ensure the mathematical operations are valid and return a finite scalar.
3.  **Pipeline Execution**:
    *   **Training**: Execute `run_training(debug=True)`. This utilizes the provided training loop to train the model for a few epochs on the debug subset and saves the `best_model.pth`.
    *   **Inference**: Execute `generate_submission()`. This uses the trained model to generate predictions for the test set.
4.  **Output Validation**: Load the generated `submission.csv` and assert that it contains the required columns (`Patient_Week`, `FVC`, `Confidence`) and rows, ensuring the full end-to-end workflow is correct.
