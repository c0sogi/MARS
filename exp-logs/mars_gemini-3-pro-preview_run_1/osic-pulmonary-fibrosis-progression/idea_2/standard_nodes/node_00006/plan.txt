The strategy for implementing the `runfile.py` script is as follows:

1.  **Configuration & Setup**: Import the necessary modules and the `Config` class. Modify `Config.EPOCHS` to a lower value (10) to satisfy the "fast baseline" requirement while ensuring sufficient training on the relatively small dataset.
2.  **Training**: Execute the provided `run_training()` function from `library.train`. This handles the training loop, validation monitoring, and saves the best model to `./working/best_model.pth`.
3.  **Validation & Metrics**:
    *   Reload the best saved model and set it to evaluation mode.
    *   Load the hold-out validation set (`./metadata/val.csv`) using `PulmonaryDataset` and `DataLoader`.
    *   Perform inference on the full validation set to gather predictions, targets, and metadata.
    *   Calculate the competition metric using `calculate_metric_numpy` and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the absolute prediction error for each validation sample.
    *   Retrieve the corresponding metadata (Age, Percent, Sex, SmokingStatus) from the dataset.
    *   Encode categorical variables numerically.
    *   Compute and print the Pearson correlation between the absolute error and these features to identify sources of poor performance.
5.  **Submission**:
    *   Compare the final validation metric against the threshold `-7.496936493589167`.
    *   If the metric is strictly greater than the threshold, call `generate_submission()` from `library.inference` to produce `./submission/submission.csv`.
