The implementation strategy involves a step-by-step verification of the machine learning pipeline provided in the library files. First, we will validate the data loading process by retrieving a batch from the data loaders and asserting the correctness of input shapes and types, specifically for the image modalities (Axial, Coronal) and tabular features. Next, we will instantiate the `TSCPNet` model, perform a forward pass with the retrieved batch, and verify that the output parameters (alpha, sigma_base, sigma_growth) have the expected dimensions. We will then compute the custom loss and metric functions to ensure they return valid scalar values. Finally, we will execute a short training run (1-2 epochs on a debug subset) and a prediction pass to verify that the training loop completes successfully, model artifacts are saved, and a valid submission file is generated.
