This script demonstrates the end-to-end usage of the provided library components to solve the lung function decline prediction task.

**Implementation Strategy:**
1.  **Configuration Patching**: Since the provided `Config` class uses static attributes for hyperparameters, we explicitly overwrite `Config.EPOCHS`, `Config.BATCH_SIZE`, and directory paths at runtime. This ensures the demo runs rapidly (2 epochs, batch size 4) and writes outputs to a dedicated `./working/demo_run` directory, keeping the environment clean.
2.  **Data Pipeline Verification**: We call `get_dataloaders(debug=True)` and inspect a single batch. We verify that the dictionary keys (`image_axial`, `image_coronal`, `tabular`, etc.) and tensor shapes match the expected architecture input requirements.
3.  **Model & Loss Logic Check**: We instantiate the `BBSLNet` model and `LaplaceLoss`. We perform a forward pass with the fetched batch to ensure the model produces the correct output format (slope `alpha` and uncertainties `sigma`). We then calculate the loss to confirm the mathematical operations are valid (finite, non-NaN).
4.  **Training & Inference Execution**: We execute `train_model(debug=True)` to simulate the training process and generate a `best_model.pth`. Finally, we run `generate_submission` to produce the submission CSV, verifying the file's existence and format.
