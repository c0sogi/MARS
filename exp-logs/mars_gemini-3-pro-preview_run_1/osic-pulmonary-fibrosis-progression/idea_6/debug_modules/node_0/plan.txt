This script demonstrates the end-to-end usage of the provided library components for the Pulmonary Fibrosis progression task. It performs the following steps:

1.  **Configuration**: Overrides default settings (epochs, batch size, directories) to ensure the demo runs quickly and does not interfere with production files. It also disables pre-trained weight downloading to ensure offline execution.
2.  **Data Preparation**: Uses `DataUtils` to load a small subset of the training data, process the DICOM images into 3D Tri-Slab tensors, and normalize tabular features. It asserts the correctness of the generated data structures.
3.  **Dataset & DataLoader**: Instantiates the `LungDataset` and verifies that it yields batches with the correct shapes for the dual-view (Axial/Coronal) architecture.
4.  **Model Initialization**: Instantiates the `TQSAN` model and performs a forward pass with a dummy batch to verify the output shape `[Batch, 3]` (Alpha, Sigma_Base, Sigma_Growth).
5.  **Loss Calculation**: Computes the modified Laplace Log Likelihood loss to ensure the mathematical operations are valid.
6.  **Training Loop**: Runs a short training cycle (2 epochs) using the `Trainer` class to demonstrate the optimization process and model checkpointing.
7.  **Inference**: Loads the trained model and performs prediction on a subset of the test metadata, decoding the trajectory parameters into FVC predictions and confidence intervals.
