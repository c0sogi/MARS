Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `seed_everything` for reproducibility. Define the device (GPU/CPU) based on availability.
2.  **Training Phase**: Execute the training pipeline by calling `run_training` from the provided `library.train` module. We will limit the training to **12 epochs** to ensure the script completes within the "fast baseline" time constraints while allowing sufficient convergence for the small dataset.
3.  **Model Loading**: Re-instantiate the `HiFiDACR` model structure. Determine the dynamic input dimension for the tabular data by inspecting a batch from the data loader. Load the best model weights saved during the training phase.
4.  **Validation & Metric Calculation**:
    *   Run inference on the full validation set using the loaded model in `eval` mode.
    *   Compute the **Modified Laplace Log Likelihood** metric using the provided loss class (negating the loss to get the metric).
    *   Print the `Final Validation Metric` with full precision.
5.  **Failure Analysis**:
    *   Compare predictions against ground truth targets for the validation set.
    *   Calculate absolute errors.
    *   Load the original validation metadata and calculate Pearson correlations between the error magnitude and key features (`Age`, `Percent`, `Weeks`).
    *   Print these correlations to identify systematic failures.
6.  **Submission Generation**:
    *   Check if the validation metric exceeds the threshold (`-6.510164260864258`).
    *   If successful, run inference on the test set (`test_loader`).
    *   Collect predictions (`FVC`, `Confidence`) and map them to `Patient_Week` identifiers.
    *   Save the results to `submission.csv` in the required format.
