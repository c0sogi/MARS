Based on the comprehensive analysis of the accumulated lessons, I propose the **Tri-Stream Balanced-Context Network (TSBC-Net)**.

This solution represents a structural synthesis designed to resolve the tension between **Feature Fidelity** (preserving rich visual signals) and **Prior Dominance** (ensuring the clinical metadata drives the trajectory). It corrects the "Signal Mixing" inherent in Holistic Pooling (Cite solution_lesson_node_00047) and the "Linear Bottleneck" of previous decoupled architectures (Cite solution_lesson_node_00114). By explicitly separating the **Visual Context**, **Tabular Context**, and **Clinical Prior** into distinct streams and fusing them via a non-linear, balanced head, this architecture maximizes predictive accuracy on the small dataset.

### 1. Model: Tri-Stream Balanced-Context Network (TSBC-Net)

**Architecture Design**
1.  **Independent Low-Capacity Visual Backbones:**
    *   We utilize two separate **EfficientNet-B0** backbones (initialized with ImageNet weights) to process the **Axial** and **Coronal** views. This strictly respects the low-capacity requirement for the small dataset (Cite solution_lesson_node_00079).
    *   **High-Fidelity Extraction:** We apply **Global Average Pooling (GAP)** to the output feature maps. **Crucially**, we maintain the **native backbone dimensionality** (1280-dim) and do **not** project these down. This adheres to the lesson that compressing visual features prior to fusion destroys critical texture signals (Cite solution_lesson_node_00039). Explicit modality embeddings are omitted (Cite solution_lesson_node_00056).

2.  **Shared-Latent Tabular Encoder:**
    *   We employ a **Shared Latent Topology** to process the raw metadata (Age, Sex, Smoking, **Percent** - Cite solution_lesson_node_00017).
    *   **Shared Encoder:** A **Deep MLP** (`Linear -> GeLU -> Linear -> GeLU`) projects the scalars to a robust **Shared Latent Vector ($T_{lat}$)** of dimension **128**. This serves as the single source of truth for the clinical prior, preventing gradient splitting (Cite solution_lesson_node_00082) and providing non-linear alignment (Cite solution_lesson_node_00070).

3.  **Normalized Bifurcated Flow:**
    *   **Flow A (Fusion Alignment):** $T_{lat}$ (128-dim) is projected via a linear layer to **1280-dim** ($T_{align}$) to match the visual backbone. **Crucially**, we apply **Layer Normalization** immediately after this projection to prevent initialization shock in the attention block (Cite solution_lesson_node_00095).
    *   **Flow B (Prior Preservation):** $T_{lat}$ (128-dim) is reserved for the final assembly (Stream 3).

4.  **Pre-Norm Symmetric Attention (Contextualization Phase):**
    *   **Tokenization:** We stack the vectors into a sequence: $[V_{ax}, V_{cor}, \text{LayerNorm}(T_{align})]$.
    *   **Fusion:** A single **Multi-Head Self-Attention** layer processes this sequence. We employ **Pre-Normalization** for stability (Cite solution_lesson_node_00008) and retain the Feed-Forward Network (FFN) with dropout to provide non-linear capacity (Cite solution_lesson_node_00070).
    *   **Output:** Updated tokens $V'_{ax}, V'_{cor}$ (Contextualized Visual) and $T'_{align}$ (Contextualized Tabular).

5.  **Tri-Stream Balanced Readout (Structural Innovation):**
    *   We process the output tokens in three distinct streams to strictly control their bandwidth and prevent signal dilution:
    *   **Stream 1 (Visual Context):** $H_{vis} = \text{Mean}(V'_{ax}, V'_{cor})$ (1280-dim). Projected down to **64-dim** via a bottleneck (`Linear -> GeLU`).
    *   **Stream 2 (Tabular Context):** $H_{ctx} = T'_{align}$ (1280-dim). Projected down to **64-dim** via a bottleneck (`Linear -> GeLU`).
        *   *Note:* Retaining this stream respects the lesson to never discard contextualized scalar tokens (Cite solution_lesson_node_00078).
    *   **Stream 3 (Clinical Prior):** The raw Shared Latent Vector $T_{lat}$ (**128-dim**).
    *   **Assembly:** We concatenate $[H_{vis\_64}, H_{ctx\_64}, T_{lat\_128}]$.
    *   *Rationale:* The final 256-dim vector is composed of 50% **Raw Prior** ($T_{lat}$) and 50% **Learned Context** (split evenly between visual and tabular). This strictly enforces Dimensionality Balancing (Cite solution_lesson_node_00080), ensuring the visual noise cannot statistically drown out the clinical ground truth.

6.  **Non-Linear Parametric Head:**
    *   **Crucially**, we pass the assembled 256-dim vector through a **Non-Linear MLP Head** (`Linear -> GeLU -> Linear`) before the final projection.
    *   *Rationale:* A linear readout forces the Prior and Context to contribute additively. A non-linear head allows the model to learn **gating interactions**, where the strong clinical prior can suppress or amplify specific features in the visual context (Cite solution_lesson_node_00114).
    *   **Constraint:** The head predicts $\alpha$ (Slope), $\sigma_{base}$, and $\sigma_{growth}$. We strictly exclude `Week` or `Time` from the input (Cite solution_lesson_node_00062).
    *   **Activation:** We apply **Softplus** activation to the $\sigma$ outputs (Cite solution_lesson_node_00021).

### 2. Data: Fixed Overlapping Orthogonal Tri-Slabs

**Preprocessing**
1.  **Dual-View Generation:** For each patient, generate two inputs to capture 3D spatial heterogeneity (Cite solution_lesson_node_00010).
    *   **Axial Tri-Slab (RGB):** Split the CT volume along the Z-axis (Depth) into three slabs with **fixed boundaries** (0-33%, 33-66%, 66-100%) and **15% overlap**. Compute MIPs and map to RGB (Cite solution_lesson_node_00006). We strictly avoid stochastic jitter to preserve semantic spatial consistency (Cite solution_lesson_node_00035).
    *   **Coronal Tri-Slab (RGB):** Split along the Y-axis (Anterior-Posterior) into three overlapping slabs, compute MIPs, and map to RGB.
2.  **Resolution:** Resize all images to **224x224**. This matches the **native resolution of EfficientNet-B0**, strictly avoiding the overfitting caused by resolution mismatch (Cite solution_lesson_node_00009).

**Augmentation**
1.  **Spatial Only:** Apply random horizontal flips, shifts, and slight rotations (Cite solution_lesson_node_00007).
2.  **No Intensity Changes:** Strictly **disable** brightness/contrast augmentations to preserve the physical Hounsfield Unit density signal (Cite solution_lesson_node_00005).

### 3. Training: Robust Metric Optimization

**Procedure**
*   **Loss Function:** Modified Laplace Log Likelihood. We explicitly **retain the error clipping** (thresholding absolute error at 1000 ml) within the loss calculation to filter outliers (Cite solution_lesson_node_00013). No auxiliary losses (Cite solution_lesson_node_00016).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.
*   **Strategy:** Use a strict patience (e.g., 6-8 epochs) for **Early Stopping**. We avoid Stochastic Weight Averaging (SWA) as it degrades performance on this small dataset (Cite solution_lesson_node_00030).

### 4. Evaluation: Parametric Inference

For every `Patient_Week` in the test set:
1.  Generate the Fixed Overlapping Axial and Coronal Tri-Slab images (224x224).
2.  Pass inputs and baseline metadata through the **TSBC-Net** model to obtain static parameters $\alpha, \sigma_{base}, \sigma_{growth}$.
3.  Calculate predictions using the anchored trajectory logic (Cite solution_lesson_node_00045):
    *   $$ \text{FVC} = \text{Baseline\_FVC} + \alpha \times (\text{Week} - \text{Baseline\_Week}) $$
    *   $$ \text{Confidence} = \sigma_{base} + \sigma_{growth} \times |\text{Week} - \text{Baseline\_Week}| $$
4.  Clip the Confidence at 70 ml as required by the metric.
