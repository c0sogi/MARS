Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class. Set random seeds for reproducibility using `seed_everything`. Define the computation device (GPU/CPU).
2.  **Data Loading**: Instantiate `LungDataset` for training, validation, and testing. Use `DataLoader` to batch the data, enabling caching (`load_cached_data=True`) to speed up image loading.
3.  **Model Initialization**: Load the `TabularGatedDualViewNetwork` and move it to the GPU.
4.  **Training**: Execute the training loop using the `fit` function from the `engine` module. To ensure a "fast baseline" as requested, we will limit the number of epochs to 30 (with early stopping), which is sufficient for this dataset size and time constraint.
5.  **Validation & Analysis**:
    *   Load the best model checkpoint.
    *   Perform inference on the full validation set to calculate the `Final Validation Metric`.
    *   **Failure Analysis**: Compute the absolute error for each validation sample. Calculate and print the correlation between this error and key clinical features (Age, Percent, Baseline FVC, Time Delta) to identify systematic weaknesses.
6.  **Submission**:
    *   Check if the validation metric exceeds the threshold (-6.510164260864258).
    *   If passed, run inference on the test set.
    *   Align predictions with the `Patient_Week` identifiers from the metadata.
    *   Clip confidence values at 70ml (as per metric definition) and save the formatted `submission.csv`.
