The following script demonstrates the end-to-end usage of the provided SCVR-Net library. It modifies the configuration to run in a lightweight "Debug" mode, ensuring the execution completes quickly while verifying the integrity of the data loading, model architecture, loss calculation, training loop, and inference pipeline.

### Implementation Strategy
1.  **Configuration Override**: We first modify the `Config` class to enable `DEBUG` mode, reduce the batch size, set epochs to 1, and disable multiprocessing workers to ensure stability and speed in the demonstration environment.
2.  **Data Pipeline Verification**: We instantiate the `LungDataset` and `DataLoader`, fetching a single batch to assert that image tensors (Axial/Coronal) and tabular features have the correct shapes and data types.
3.  **Model Architecture Check**: We initialize the `SCVRNet` model and perform a forward pass using the batch of data fetched previously. We verify that the output contains the three expected parameters: $\alpha$, $\sigma_{base}$, and $\sigma_{growth}$.
4.  **Metric & Loss Validation**: We manually compute the modified Laplace Log Likelihood metric on dummy data to verify the logic against the `LaplaceLogLikelihoodLoss` class and `compute_metric_score` function, ensuring clipping rules are applied correctly.
5.  **Training Loop Execution**: We run `train_one_epoch` on the CPU (or GPU if available) using the small debug dataset to confirm the optimization step works without errors. We then save these weights.
6.  **Inference Demonstration**: We use the saved weights to run the `run_inference` function, generating a submission file. We then validate the format of the generated CSV file.
