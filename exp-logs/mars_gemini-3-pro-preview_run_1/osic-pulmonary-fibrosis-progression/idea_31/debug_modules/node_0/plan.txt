The following script demonstrates the usage of the provided library files to train and evaluate the `AVRDAN` model for the pulmonary fibrosis progression task.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to enable a "fast mode" (reduced epochs, small batch size, and a tiny subset of data) suitable for demonstration within the time limit.
2.  **Utility Verification**: We validate the custom Laplace Log Likelihood metric function against a manual calculation to ensure correctness.
3.  **Data Pipeline Verification**: We instantiate the `OSICDataset` and `DataLoader`, retrieving a single batch to assert that input shapes (images and tabular features) and target types are correct.
4.  **Model Architecture Verification**: We instantiate the `AVRDAN` model, perform a forward pass with the retrieved batch, and verify that the output shapes (FVC prediction and Confidence) match the batch size and that confidence values are positive.
5.  **Training Loop Execution**: We execute the full training pipeline using `library.train.run_training()`. This tests the integration of data loading, model forward/backward passes, and checkpoint saving.
6.  **Inference Execution**: We run the prediction pipeline using `library.predict.generate_submission_file()`, ensuring the trained model can generate a submission file in the required format.
