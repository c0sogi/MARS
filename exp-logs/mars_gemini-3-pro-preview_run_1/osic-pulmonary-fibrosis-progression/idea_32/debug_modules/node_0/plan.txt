This script demonstrates the end-to-end usage of the provided lung function decline prediction library. It performs the following steps:
1.  **Configuration**: Overrides default `Config` settings to use the writable `./working` directory and reduces epochs/batch sizes for rapid execution.
2.  **Data Subset Creation**: Generates small training and validation subsets from the provided metadata to speed up data loading.
3.  **Metric Verification**: Validates the custom Laplace Log Likelihood metric against a manual calculation.
4.  **Pipeline Validation**:
    *   **Data Loading**: Instantiates the `OSICDataset` and `DataLoader` to verify input shapes (Dual-view CT images + Tabular features).
    *   **Model Inference**: Runs a forward pass on `MPVERNet` to ensure correct output dimensions (`FVC` and `Confidence`).
    *   **Loss Calculation**: Computes the loss to verify differentiability.
5.  **Training Loop**: Executes a minimal training run using the `Trainer` class to demonstrate optimization and checkpointing.
