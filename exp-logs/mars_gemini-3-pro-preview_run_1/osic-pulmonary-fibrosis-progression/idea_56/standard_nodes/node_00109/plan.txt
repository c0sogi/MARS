2.  **Validation & Metric Calculation**: After training, we reload the best model state and perform a dedicated inference pass on the validation set. We explicitly calculate the modified Laplace Log Likelihood metric using the provided `score` function to ensure accuracy.
3.  **Failure Analysis**: We compute the absolute prediction errors on the validation set and calculate Pearson correlations between these errors and key metadata features (e.g., Age, Weeks, Percent). This helps identify if specific patient subgroups are driving model error.
4.  **Conditional Submission**: We check if the final validation metric exceeds the threshold of -6.510164260864258.
5.  **Optimized Test Inference**: If the threshold is met, we generate the submission. To optimize inference time, we identify unique patients from the test set and run the computationally expensive CNN forward pass only once per patient to predict the trajectory parameters ($\alpha, \sigma_{base}, \sigma_{growth}$).
