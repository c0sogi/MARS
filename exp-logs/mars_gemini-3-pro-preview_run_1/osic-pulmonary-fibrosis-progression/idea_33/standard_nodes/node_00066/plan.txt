    *   Load the best saved model.
    *   Perform a full inference pass on the validation set to collect predictions (`FVC`, `Confidence`), targets, and input features (`Age`, `Percent`, `Baseline_FVC`).
    *   Calculate the **Final Validation Metric** using `laplace_log_likelihood_metric`.
    *   Compute the absolute error magnitude (`|True - Pred|`) for each sample.
    *   Calculate and print Pearson correlations between the error magnitude and input features to identify failure modes.

5.  **Submission Generation**:
    *   Check if the validation metric exceeds the threshold `-6.510164260864258`.
    *   If passed, load the test dataset (`metadata/test.csv`).
    *   Run inference in evaluation mode (`no_grad`) to generate predictions for all `Patient_Week` rows.
    *   Clip confidence values at 70 ml as per the metric definition.
    *   Format the output DataFrame and save it to `./submission/submission.csv`.
