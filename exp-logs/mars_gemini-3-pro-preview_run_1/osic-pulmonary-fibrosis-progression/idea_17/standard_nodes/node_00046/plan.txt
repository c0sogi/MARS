Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Initialization**: Set random seeds for reproducibility using the provided `seed_everything` utility. Define the computation device (GPU/CPU).
2.  **Data Loading**: Initialize `LungDataset` for training and validation sets using the metadata CSVs. Create PyTorch `DataLoader` instances with appropriate batch sizes and workers.
3.  **Model Setup**: Instantiate the `DualAxisNet` model, move it to the GPU, and define the `AdamW` optimizer and `CosineAnnealingLR` scheduler as specified in the configuration.
4.  **Training**: Initialize the `Engine` class and execute the training loop via `engine.fit()`. This handles the forward pass, backpropagation, metric calculation, and early stopping.
5.  **Validation & Metrics**: After training, load the best saved checkpoint. Calculate the final validation metric on the full validation set and print it in the required format.
6.  **Failure Analysis**: Perform a specific inference pass on the validation set to collect predictions and metadata. Calculate the absolute error for each sample and compute Pearson correlations between the error and input features (Age, Percent, Weeks, etc.) to identify systematic weaknesses.
7.  **Submission**: Compare the final validation metric against the threshold (-6.510164260864258). If the model performs better (higher score), generate predictions for the test set using `engine.predict()` and save the submission file.
