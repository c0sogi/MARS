This script demonstrates the end-to-end usage of the provided library components for the Lung Function Decline prediction task. It validates the data processing pipeline (DICOM loading, tri-slab generation), the dataset and dataloader construction, the custom model architecture (Dual-Axis Transformer with GeM pooling), the custom metric (Laplace Log Likelihood), and the training/inference loops.

To ensure rapid execution and robustness within the provided environment:
1.  **Configuration Overrides**: We modify `Config` parameters (image size, batch size, epochs, pretrained weights) to minimize resource usage and runtime.
2.  **Data Verification**: We explicitly check the shapes and value ranges of processed images and tensors.
3.  **Model Verification**: We validate the forward pass shapes and ensure the output constraints (positive sigma values) are met.
4.  **Metric Verification**: We test the loss function with known inputs to confirm correctness.
5.  **Training & Inference**: We run a single epoch of training and a mock inference step to verify the pipeline's integrity without performing a full convergence run.
