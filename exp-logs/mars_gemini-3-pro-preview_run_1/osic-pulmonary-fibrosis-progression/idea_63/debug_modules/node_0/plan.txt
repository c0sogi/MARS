### Implementation Strategy

1.  **Configuration Override**: We will import the `Config` class and modify its attributes at runtime to enable "Debug Mode". This involves setting `debug=True` (reducing dataset size), reducing `epochs` to 1, and setting a small `batch_size`. We will also redirect output paths to a temporary `demo_working` directory to avoid conflicts.
2.  **Data Pipeline Verification**: We will instantiate the data loaders using `get_dataloaders()`. We will fetch a single batch from the training loader and use assertions to verify the shapes of the inputs (Axial images, Coronal images, Tabular data) and targets.
3.  **Model & Loss Verification**: We will instantiate the `BBSLNet` model and the `LaplaceLogLikelihoodLoss`. We will perform a forward pass on the fetched batch, ensuring the output shape is `(Batch_Size, 2)` (FVC and Confidence). We will then compute the loss and assert it is a valid finite number.
4.  **Engine Execution**: We will run one iteration of `train_fn` and `eval_fn` to ensure the training loop logic holds together (gradient calculation, optimizer step).
5.  **Inference Simulation**: We will run `inference_fn` using the submission loader. Finally, we will verify that the submission CSV is generated correctly and contains the required columns.
