Based on the comprehensive analysis of the accumulated lessons, specifically the convergence of findings regarding **Dimensionality Balancing** (Cite solution_lesson_node_00080), **Shared Representation Learning** (Cite solution_lesson_node_00082), **Normalization Preconditions** (Cite solution_lesson_node_00095), **Holistic Contextualization** (Cite solution_lesson_node_00078), and **Non-Linear Readout Capacity** (Cite solution_lesson_node_00114), I propose the **Balanced-Bottleneck Shared-Latent Network (BBSL-Net)**.

This solution represents a structural synthesis that resolves the critical conflicts identified in previous iterations. It eliminates the "Gradient Splitting" of dual-path encoders, the "Prior Dilution" caused by imbalanced skip connections, and the "Initialization Shock" that destabilized residual fusion. Uniquely, it introduces a **Balanced Bottleneck** coupled with a **Non-Linear Head** to strictly enforce parity between the visual context and the clinical prior at the decision stage.

### 1. Model: Balanced-Bottleneck Shared-Latent Network (BBSL-Net)

**Architecture Design**
1.  **Independent Low-Capacity Visual Backbones:**
    *   We utilize two separate **EfficientNet-B0** backbones (initialized with ImageNet weights) to process the orthogonal views (**Axial** and **Coronal**). This strictly respects the low-capacity requirement for the small dataset to prevent "confidence overfitting" (Cite solution_lesson_node_00079).
    *   **High-Fidelity Extraction:** We apply **Global Average Pooling (GAP)** to the output feature maps. **Crucially**, we maintain the **native backbone dimensionality** (1280-dim) and do **not** project these down. This adheres to the lesson that compressing visual features prior to fusion destroys critical texture signals (Cite solution_lesson_node_00039). Explicit modality embeddings are omitted as independent backbones render them redundant (Cite solution_lesson_node_00056).

2.  **Shared-Latent Tabular Encoder:**
    *   To resolve the conflict between "Dual-Path" inefficiency (Cite solution_lesson_node_00082) and "Raw Scalar" dilution (Cite solution_lesson_node_00080), we employ a **Shared Latent Topology**.
    *   **Shared Encoder:** The raw metadata (Age, Sex, Smoking, **Percent** - Cite solution_lesson_node_00017) is processed by a **Deep MLP** (`Linear -> GeLU -> Linear -> GeLU`) to produce a robust **Shared Latent Vector ($T_{lat}$)** of dimension **128**.
    *   *Rationale:* This 128-dim vector serves as the single source of truth for the clinical prior, receiving gradients from both the fusion task and the direct prediction task. It provides non-linear alignment (Cite solution_lesson_node_00070).

3.  **Normalized Bifurcated Flow:**
    *   **Flow A (Fusion Alignment):** $T_{lat}$ (128-dim) is projected via a linear layer to **1280-dim** ($T_{align}$) to match the visual backbone. **Crucially**, we apply **Layer Normalization** immediately after this projection. This prevents the scale disparity between the initialized projection and the pre-trained visual features from destabilizing the residual attention block (Cite solution_lesson_node_00095).
    *   **Flow B (Prior Preservation):** $T_{lat}$ (128-dim) is reserved for the final assembly.

4.  **Pre-Norm Symmetric Attention (Contextualization Phase):**
    *   **Tokenization:** We stack the vectors into a sequence: $[V_{ax}, V_{cor}, \text{LayerNorm}(T_{align})]$.
    *   **Fusion:** A single **Multi-Head Self-Attention** layer processes this sequence. We employ **Pre-Normalization** for stability (Cite solution_lesson_node_00008) and retain the Feed-Forward Network (FFN) with dropout to provide non-linear capacity (Cite solution_lesson_node_00070).
    *   **Holistic Readout:** We apply **Global Average Pooling** across **ALL** updated tokens ($V'_{ax}, V'_{cor}, T'_{align}$) to derive the fused context vector $H_{fused}$ (1280-dim). This preserves the contextualized clinical signal (Cite solution_lesson_node_00078) and avoids flattening (Cite solution_lesson_node_00047).

5.  **Balanced-Bottleneck Head (Structural Innovation):**
    *   **Compression:** We project the high-dimensional fused vector $H_{fused}$ (1280-dim) down to **128-dim** ($H_{compressed}$) using a linear bottleneck layer (`Linear -> GeLU -> Dropout`).
    *   **Balanced Concatenation:** We concatenate $H_{compressed}$ (128-dim) with the Shared Latent Vector $T_{lat}$ (128-dim).
    *   *Rationale:* This ensures that the Visual Context and the Clinical Prior occupy equal "bandwidth" (50/50) in the final feature vector. This strictly enforces Dimensionality Balancing (Cite solution_lesson_node_00080), preventing the high-variance visual features from drowning out the dominant clinical predictor.
    *   **Non-Linear Readout:** The concatenated vector is passed through a **Non-Linear MLP** (`Linear -> GeLU -> Linear`) before the final projection. This allows the model to learn gating interactions between the prior and the visual context (Cite solution_lesson_node_00114).
    *   **Constraint:** The head predicts $\alpha$ (Slope), $\sigma_{base}$, and $\sigma_{growth}$. We strictly exclude `Week` or `Time` from the input (Cite solution_lesson_node_00062).
    *   **Activation:** We apply **Softplus** activation to the $\sigma$ outputs (Cite solution_lesson_node_00021).

### 2. Data: Fixed Overlapping Orthogonal Tri-Slabs

**Preprocessing**
1.  **Dual-View Generation:** For each patient, generate two inputs to capture 3D spatial heterogeneity (Cite solution_lesson_node_00010).
    *   **Axial Tri-Slab (RGB):** Split the CT volume along the Z-axis (Depth) into three slabs with **fixed boundaries** (0-33%, 33-66%, 66-100%) and **15% overlap**. Compute MIPs and map to RGB (Cite solution_lesson_node_00006). We strictly avoid stochastic jitter to preserve semantic spatial consistency (Cite solution_lesson_node_00035).
    *   **Coronal Tri-Slab (RGB):** Split along the Y-axis (Anterior-Posterior) into three overlapping slabs, compute MIPs, and map to RGB.
2.  **Resolution:** Resize all images to **224x224**. This matches the **native resolution of EfficientNet-B0**, strictly avoiding the overfitting caused by resolution mismatch (Cite solution_lesson_node_00009).

**Augmentation**
1.  **Spatial Only:** Apply random horizontal flips, shifts, and slight rotations (Cite solution_lesson_node_00007).
2.  **No Intensity Changes:** Strictly **disable** brightness/contrast augmentations to preserve the physical Hounsfield Unit density signal (Cite solution_lesson_node_00005).

### 3. Training: Robust Metric Optimization

**Procedure**
*   **Loss Function:** Modified Laplace Log Likelihood. We explicitly **retain the error clipping** (thresholding absolute error at 1000 ml) within the loss calculation to filter outliers (Cite solution_lesson_node_00013). No auxiliary losses (Cite solution_lesson_node_00016).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.
*   **Strategy:** Use a strict patience (e.g., 6-8 epochs) for **Early Stopping**. We avoid Stochastic Weight Averaging (SWA) as it degrades performance on this small dataset (Cite solution_lesson_node_00030).

### 4. Evaluation: Parametric Inference

For every `Patient_Week` in the test set:
1.  Generate the Fixed Overlapping Axial and Coronal Tri-Slab images (224x224).
2.  Pass inputs and baseline metadata through the **BBSL-Net** model to obtain static parameters $\alpha, \sigma_{base}, \sigma_{growth}$.
3.  Calculate predictions using the anchored trajectory logic (Cite solution_lesson_node_00045):
    *   $$ \text{FVC} = \text{Baseline\_FVC} + \alpha \times (\text{Week} - \text{Baseline\_Week}) $$
    *   $$ \text{Confidence} = \sigma_{base} + \sigma_{growth} \times |\text{Week} - \text{Baseline\_Week}| $$
4.  Clip the Confidence at 70 ml as required by the metric.
