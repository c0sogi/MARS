This script implements the full training and validation pipeline for the Lung Function Decline prediction task. It uses the provided `VERNet` architecture and `FVCDataset`. The pipeline includes:
1.  **Configuration**: Sets seeds and device (GPU).
2.  **Training**: Runs the training loop for 15 epochs with early stopping using the `library.engine.run_training` function.
3.  **Validation**: Loads the best saved model and performs a full inference pass on the validation set to calculate the `Laplace Log Likelihood` metric with full precision.
4.  **Failure Analysis**: Computes correlations between the absolute prediction error and key features (Age, Percent, Week, True FVC) to identify systematic weaknesses.
5.  **Submission**: Generates the `submission.csv` file for the test set if the validation metric exceeds the specified threshold.
