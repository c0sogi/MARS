Implementation strategy:
1.  **Environment Setup**: Patch `tqdm` to suppress progress bars as strictly required. Set random seeds for reproducibility.
2.  **Configuration**: Override `Config.EPOCHS` to 20. This ensures the training completes quickly (satisfying the "fast baseline" requirement) while providing enough iterations for the model to converge and meet the performance threshold.
3.  **Training**: Execute `library.train.run_training`. This handles the full training loop, Stochastic Weight Averaging (SWA), and saves the best model to `./working/best_model.pth`. It also generates an initial submission as a side effect.
4.  **Validation & Metric Calculation**: Load the saved `best_model.pth` and the validation dataset. Perform inference to calculate the exact Modified Laplace Log Likelihood on the hold-out set. Print this metric with full precision.
5.  **Failure Analysis**: Construct a DataFrame of validation predictions and errors. Calculate and print the correlation between the absolute prediction error and key metadata features (`Age`, `Percent`, `Weeks`) to identify systematic failure modes.
6.  **Submission Logic**: Compare the calculated validation metric against the threshold (`-6.510164260864258`).
    *   If the metric is **higher** than the threshold, explicitly call `library.predict.generate_predictions` to finalize the submission.
    *   If the metric is **lower**, delete the submission file generated by `run_training` to strictly adhere to the "If and only if" requirement.
