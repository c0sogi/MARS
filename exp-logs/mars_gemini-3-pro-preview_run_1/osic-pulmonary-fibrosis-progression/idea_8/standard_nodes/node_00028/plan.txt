The previous implementation of `runfile.py` attempted to suppress progress bars by replacing the `tqdm.tqdm` class with a simple function (`noop_tqdm`). This caused a `TypeError` because downstream libraries (specifically `huggingface_hub`, imported via `albumentations`) attempt to inherit from `tqdm.tqdm`. Since functions cannot be base classes, the inheritance failed. The fix involves replacing `tqdm.tqdm` with a subclass (`SilentTqdm`) that inherits from the original `tqdm` class but forces the `disable=True` argument in its constructor. This preserves the class hierarchy required by dependencies while achieving the goal of silencing output.
