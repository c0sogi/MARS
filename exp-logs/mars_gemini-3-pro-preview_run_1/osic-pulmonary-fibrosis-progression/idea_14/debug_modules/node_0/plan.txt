This script demonstrates the end-to-end usage of the provided library files for the Pulmonary Fibrosis Progression task. It covers data loading, processing, model instantiation, a short training loop, inference, and metric calculation.

The strategy is as follows:
1.  **Setup**: Initialize the environment and random seeds.
2.  **Data Processing**: Demonstrate how `LungDataProcessor` converts raw DICOMs into tensor-ready images using a small subset of the training data.
3.  **Dataset & Transforms**: Instantiate `LungDataset` to verify data augmentation and feature extraction logic.
4.  **Model Verification**: Initialize `HighFidelityDualNet`, perform a forward pass with dummy data, and assert output shapes.
5.  **Training Simulation**: Create temporary subset CSVs and run `run_training` for a minimal number of epochs to demonstrate the training loop without consuming excessive time.
6.  **Inference**: Use the trained model to generate predictions on a subset of the test metadata.
7.  **Metric Check**: Validate the `laplace_log_likelihood_metric` function against a manual calculation.
