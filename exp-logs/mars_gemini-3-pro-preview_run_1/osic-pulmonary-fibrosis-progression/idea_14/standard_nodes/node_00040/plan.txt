The implementation strategy follows the requirements to create a fast, reproducible, and robust orchestration script.

1.  **Setup & Configuration**: The script initializes by setting random seeds for reproducibility and suppressing unnecessary warnings. It defines paths for metadata and model checkpoints.
2.  **Training**: It utilizes the `run_training` function from `library.train`. To ensure a fast baseline execution within the time limit, the epoch count is set to 15, which is sufficient for the small dataset size (~1100 samples) to converge or trigger early stopping. The batch size is set to 16 to fit comfortably within GPU memory while maintaining training stability.
3.  **Validation**: After training, the script explicitly reloads the best model weights saved during the training phase. It runs a dedicated inference pass on the validation set to compute the `Final Validation Metric` with full precision using the provided `laplace_log_likelihood_metric`.
4.  **Failure Analysis**: The script calculates the absolute error for each validation sample and computes correlations with input features (Weeks, Percent, Age, Sex, SmokingStatus). This identifies which patient characteristics are associated with higher prediction errors.
5.  **Submission**: It checks the computed validation metric against the threshold (-6.510164260864258). If the model performs better (i.e., metric is higher), it loads the test metadata and calls the `predict` function from `library.model` to generate and save `submission.csv`.
