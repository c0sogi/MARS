The following script demonstrates the end-to-end usage of the provided library modules for the Lung Function Decline Prediction task.

**Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class to use a temporary working directory and reduce hyperparameters (epochs, batch size) for rapid execution.
2.  **Data Subsetting**: We load the metadata and filter it to include only a very small number of patients (2 for training, 1 for validation, 1 for testing). This ensures the computationally expensive DICOM processing and caching step completes quickly.
3.  **Component Verification**:
    *   **Data Loading**: We verify that `get_dataloaders` correctly processes the subset and returns loaders with the expected batch structure (images and tabular features).
    *   **Model Architecture**: We instantiate `DynamicDepthGeMNet`, perform a forward pass with a dummy batch, and assert the output shapes for FVC and Confidence predictions.
    *   **Loss Function**: We verify the `CustomLaplaceLoss` computes a valid scalar loss.
    *   **Training Loop**: We execute `train_one_epoch` and `valid_one_epoch` to ensure the optimization step and metric calculation function correctly without errors.
    *   **Inference**: We run the prediction generation logic on the test subset and verify the output submission file format.
4.  **Cleanup**: Temporary files created in `./working` are cleaned up (optional, but good practice, though we might leave them for inspection).
