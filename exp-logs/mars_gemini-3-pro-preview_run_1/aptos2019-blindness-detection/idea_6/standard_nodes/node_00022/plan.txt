I will implement the orchestration script `runfile.py` to train the EfficientNetV2-Small model with ordinal regression, validate it, perform failure analysis, and conditionally generate a submission.

The strategy is as follows:
1.  **Setup**: Initialize the environment using `seed_everything` and prepare directories.
2.  **Training**: Use `library.model.run_training` to train the model. This handles the training loop, validation per epoch, scheduler, and saves the best checkpoint.
3.  **Validation & Metric**: Load the best model checkpoint and perform a dedicated inference pass on the validation set to obtain the final QWK score and detailed predictions.
4.  **Failure Analysis**: Compute image metadata (width, height, intensity, file size) for the validation set. Calculate the absolute error between ground truth and predictions. Compute and print the Pearson correlation between these errors and the image metadata to identify systematic weaknesses.
5.  **Submission**: Check if the final QWK exceeds the strict threshold of `0.922975135423079`. If it does, generate the submission file using `library.model.generate_submission`.
