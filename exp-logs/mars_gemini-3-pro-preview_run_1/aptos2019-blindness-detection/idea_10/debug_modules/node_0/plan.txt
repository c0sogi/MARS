This script demonstrates the usage of the provided diabetic retinopathy detection library. It validates the metric calculation, dataset loading, model architecture, and the full training pipeline.

**Strategy:**
1.  **Configuration Override**: We modify the global `Config` class to enable `debug` mode, reduce image size to 256px, and set `batch_size` to 4. This ensures the demonstration runs quickly and uses minimal resources.
2.  **Component Validation**:
    *   **Utils**: We verify `quadratic_weighted_kappa` with known ground truth and prediction vectors.
    *   **Dataset**: We initialize the `RetinaDataset` (forcing a cache rebuild) and verify that the `DataLoader` yields batches with the correct shapes and data types. We also verify the `mixup_data` function.
    *   **Model**: We instantiate `MultiScaleConvNeXt` (with `pretrained=False` to avoid network dependency issues during the demo) and perform a forward pass to confirm the output shape corresponds to `[batch_size, num_ordinal_heads]`.
    *   **Training Logic**: We verify the `get_ordinal_targets` function to ensure integer labels are correctly converted to ordinal binary vectors.
3.  **Integration Test**: We execute `run_training` for a single epoch. This runs the full pipeline—loading data, training, validation, saving the model, running inference, and generating the `submission.csv` file.
