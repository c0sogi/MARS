Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by setting random seeds and configuring the device (GPU/CPU) using the provided `Config` and `utils` modules. I will also suppress `tqdm` output to comply with the "no progress bars" requirement by monkey-patching it before other imports.
2.  **Configuration**: I will override the default `Config.EPOCHS` to 10 to ensure the baseline runs quickly while still learning effectively from the small dataset.
3.  **Data Loading**: Use `get_dataloaders` from `library.data` to load the training, validation, and test sets.
4.  **Model Training**: Instantiate the `OrdinalMobileNetV3` model and `Trainer`. Execute the training loop using `trainer.fit()`.
5.  **Validation Assessment**:
    *   Load the best saved model checkpoint.
    *   Perform inference on the full validation set.
    *   Calculate the Quadratic Weighted Kappa (QWK) using `compute_qwk`.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Compute the absolute error between predictions and ground truth for the validation set.
    *   Extract basic metadata features (Width, Height, Mean Intensity, File Size) for the validation images.
    *   Calculate and print the Pearson correlation between these features and the model's error magnitude to identify potential biases (e.g., does the model fail more on darker or larger images?).
7.  **Submission Generation**:
    *   Generate predictions for the test set using `trainer.predict()`.
    *   Save the results to `./submission/submission.csv`.
