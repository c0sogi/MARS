Consequently, the dataset returns raw images in HWC (Height, Width, Channels) format as NumPy arrays, while the verification logic expects PyTorch tensors in CHW (Channels, Height, Width) format. To fix this, I will import `get_transforms` from `library.dataset` and pass the appropriate transformation pipeline to the dataset constructor in `runfile.py`. This ensures `ToTensorV2` is applied, converting the images to the expected shape.
