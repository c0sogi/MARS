### Implementation Strategy

1.  **Configuration Setup**: Override default `Config` parameters to enable a "Debug Mode" for rapid execution. This includes reducing the number of epochs to 1, setting a small batch size, and defining a specific working directory for the demo.
2.  **Data Pipeline Verification**:
    *   Test the `parse_structure` function to ensure RNA secondary structure strings are correctly converted into distance matrices.
    *   Execute `process_data` to load a subset of training and test data.
    *   Initialize `RNADataset` and `DataLoader` to verify batch shapes and data types.
3.  **Model Architecture Verification**:
    *   Instantiate the `Net` model.
    *   Perform a forward pass with a sample batch to confirm the output tensor shape matches `(Batch, Sequence_Length, 3)`.
    *   Check the `SinusoidalPositionalEmbedding` to ensure it generates embeddings of the correct dimension.
4.  **Loss Function Verification**:
    *   Test `MaskedMSELoss` and `calculate_mcrmse` with synthetic tensors where the expected outcome is known (e.g., zero loss for identical inputs, specific loss for known differences).
    *   Verify that the masking logic correctly ignores unscored positions.
5.  **Training Loop Demonstration**:
    *   Instantiate the `Trainer` class with the model, optimizers, and debug data loaders.
    *   Run a single epoch of training to ensure the backpropagation and validation logic executes without errors.
    *   Verify that a model checkpoint is saved.
6.  **Inference and Submission**:
    *   Load the saved checkpoint using the `Predictor` class.
    *   Run inference on the test set.
    *   Generate a submission file using `generate_submission_file` and verify the output CSV format and dimensions.
