# Baseline Approach: 1D Convolutional Neural Network (1D-CNN)

## Model
The proposed baseline is a **1D Convolutional Neural Network (1D-CNN)**. Unlike the graph-based, recurrent, or attention-based models listed previously, this architecture treats the RNA molecule as a fixed-length one-dimensional grid. It relies on learnable filters to detect local structural motifs and sequence patterns (k-mers) that correlate with stability and degradation.

*   **Inputs**: The model accepts the RNA sequence, secondary structure (dot-bracket), and predicted loop type as parallel input channels.
*   **Encoder**: The core architecture consists of a stack of 3 to 4 1D convolutional layers. Each layer uses a small kernel size (e.g., 3 or 5) to capture local context, followed by Batch Normalization and ReLU activation. To preserve the spatial resolution of the sequence (length 107), "same" padding is applied at each layer, and pooling operations are avoided.
*   **Output Head**: The final convolutional layer projects the extracted feature maps directly to 5 output channels (corresponding to the 5 target degradation values) for every position in the sequence. This results in a purely feed-forward, non-recurrent architecture that is highly parallelizable and computationally efficient.

## Data
1.  **Tokenization**: Create integer mappings for the three categorical input features:
    *   `sequence` (A, G, C, U)
    *   `structure` ((, ), .)
    *   `predicted_loop_type` (S, M, I, B, H, E, X)
2.  **Vectorization**: Convert the raw text strings for all samples into integer arrays of fixed length 107.
3.  **Embedding**: Replace integer tokens with small, learnable embedding vectors (e.g., dimension 8-16) and concatenate them along the channel dimension to form the input tensor.
4.  **Target Alignment**: Extract the 5 target arrays (`reactivity`, `deg_Mg_pH10`, etc.) for the training set. Although the model outputs predictions for the full 107 length, the loss will only be calculated on the first 68 positions (defined by `seq_scored`) where ground truth is available.

## Training
*   **Loss Function**: Use **Mean Squared Error (MSE)** or Smooth L1 Loss computed only on the first 68 masked positions of the sequence. Minimizing MSE directly optimizes the competition metric (MCRMSE).
*   **Optimizer**: Use the **Adam** optimizer with a standard learning rate (e.g., 1e-3).
*   **Procedure**: Train the model in mini-batches. Since the model is lightweight, it can be trained for a higher number of epochs (e.g., 50-100) with Early Stopping triggered if the validation loss plateaus.
*   **Regularization**: Apply a moderate amount of Dropout between convolutional layers to prevent overfitting to the specific sequences in the training set.

## Evaluation
1.  **Inference**: Pass the tokenized `test.json` sequences through the trained network. The model will output a tensor of shape `(N_samples, 107, 5)`.
2.  **Formatting**: Although only the first 68 positions are scored, the submission format requires rows for all sequence positions. Flatten the predictions to match the `id_seqpos` format.
3.  **Post-processing**: Ensure no negative predictions are submitted if the physical degradation rates are strictly non-negative (clipping to 0), though the prompt implies raw regression values are expected. Save the result to `submission.csv`.
