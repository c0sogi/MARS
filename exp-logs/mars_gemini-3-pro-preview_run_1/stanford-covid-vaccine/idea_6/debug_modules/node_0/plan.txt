This script demonstrates the usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use a small debug subset and temporary directories for speed and isolation.
2.  **Metric Verification**: Validates the `mcrmse_metric` function with a known numerical example.
3.  **Data Loading**: Uses `get_dataloaders` to load processed training and testing batches, verifying tensor shapes and types.
4.  **Model Instantiation & Forward Pass**: Initializes the `HybridResNetBiGRU` model and performs a forward pass with a batch of data, asserting output dimensions.
5.  **Loss Calculation**: Computes the `MaskedHuberLoss` ensuring it handles the masking of unscored positions correctly.
6.  **Training Loop Simulation**: Runs a single epoch of training and validation using the provided functions to ensure the pipeline is functional.
7.  **Inference & Submission**: Generates a submission file for the test set and verifies the output format.
