Based on the analysis of the previous experiments and the derived lessons, I propose a **Hybrid ResNet-BiGRU** strategy. This approach is a structural evolution that combines the local feature extraction efficiency of CNNs with the global context modeling of the Bi-GRU, while introducing a robust loss function to handle noisy data without the pitfalls of sample weighting.

# Model
**Architecture: 1D-ResNet + Bidirectional GRU Hybrid**
We will construct a sequential two-stage encoder.
*   **Input Embeddings**: We will retain the successful multi-channel embedding strategy. The `sequence`, `structure`, and `predicted_loop_type` inputs will be embedded and concatenated. We will **not** use graph-based edge construction, adhering to the lesson that sequence-native architectures outperform graph models on this data **Cite solution_lesson_node_00009**.
*   **Stage 1: Local Motif Encoder (1D-ResNet)**: The embeddings will first pass through a stack of **Residual 1D Convolutional Blocks**.
    *   **Rationale**: While the Bi-GRU (Current Best) is excellent at global context, it is computationally inefficient at learning simple local chemical motifs (k-mers). CNNs have a strong **inductive bias for locality** **Cite solution_lesson_node_00010**, allowing the model to efficiently extract high-level local features (e.g., "GC-rich region", "hairpin start") before they are processed for global context.
*   **Stage 2: Global Context Aggregator (Bi-GRU)**: The output of the ResNet will be fed into a **Bidirectional GRU**.
    *   **Rationale**: RNA stability is determined by global folding. The Bi-GRU ensures the model maintains a **Global Receptive Field**, allowing information to propagate across the entire 107-nucleotide sequence to capture long-range base-pairing effects **Cite solution_lesson_node_00004**. This hybrid design leverages the strengths of both architectures: CNN for local syntax, RNN for global semantics.
*   **Output Head**: A Shared MLP will project the hidden states to the 5 target values.

# Data
*   **Full-Context Processing**: We will process the complete 107-nucleotide sequence for every sample. We will **not crop** the inputs to the scored length (68), ensuring the model has access to downstream structural motifs that causally influence the upstream scored regions **Cite solution_lesson_node_00002**.
*   **Preprocessing**: Inputs will be integer-encoded for embedding lookup.

# Training
*   **Masked Robust Loss (Huber/Smooth L1)**: We will implement a **Masked Huber Loss**.
    *   **Masking**: Gradients will only be calculated for the first 68 positions where ground truth exists **Cite solution_lesson_node_00002**.
    *   **Robustness**: Previous failure analysis showed that models struggle with noisy data **Cite solution_lesson_node_00002**, but explicitly weighting samples by signal-to-noise ratio degraded performance because the evaluation metric is unweighted **Cite solution_lesson_node_00011**. Huber Loss provides a middle ground: it is less sensitive to outliers (noise) than MSE, effectively "dampening" the impact of noisy labels without explicitly changing the training distribution or sample weights.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler to stabilize the training of the hybrid weights.

# Evaluation
*   **Inference**: The test sequences (length 107) will be passed through the Hybrid ResNet-BiGRU model.
*   **Formatting**: The model will output predictions for all 107 positions. These will be flattened to match the `id_seqpos` format. Predictions for unscored positions (69-107) will be included to satisfy the submission format requirements.
