This script implements the end-to-end pipeline for the Structure-Biased Attention-Augmented Wide-Stream BiGRU model.

### Implementation Strategy
1.  **Setup & Configuration**: Initialize the environment using `Config` and `set_seed` to ensure reproducibility.
2.  **Training**: Execute the training loop using `train_model` from the provided `engine.py`. We utilize the full training set (1,728 samples) and the default 20 epochs, as this dataset size is small enough to complete training rapidly (well within the 2-hour limit) without subsampling.
3.  **Validation & Failure Analysis**:
    *   Load the best saved model state.
    *   Perform inference on the hold-out validation set in `eval` mode with `torch.no_grad()`.
    *   Compute the **MCRMSE** metric strictly on the scored columns and positions.
    *   Calculate per-sample RMSE and merge with validation metadata (loaded from `val.parquet`).
    *   Compute and print Pearson correlations between model error and key features (`signal_to_noise`, `SN_filter`, nucleotide counts) to identify failure modes.
4.  **Submission**: Compare the final validation metric against the specified threshold (`0.6199890971183777`). If the model performs better (lower metric), generate the `submission.csv` using `generate_submission`; otherwise, skip submission.
