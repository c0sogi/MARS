Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Multi-Task Distance-Aware Residual BiGRU** strategy. This approach is a structural evolution that enhances the state-of-the-art "Distance-Aware BiGRU" (Idea 8) by integrating a **Masked Nucleotide Reconstruction (MNR)** auxiliary task. This directly addresses the "Small Data" limitation identified in Lesson 00010 by leveraging the entire sequence for supervision, while retaining the successful architectural components from Lessons 00016 and 00017.

# Model
**Architecture: Multi-Task Distance-Aware Residual BiGRU**
We will construct a dual-head recurrent network that simultaneously predicts degradation rates and reconstructs masked RNA sequences to enforce strong structural learning.

*   **Input Embeddings**:
    *   **Masked Sequence**: We will use a learnable embedding layer for the nucleotide sequence. Crucially, during training, a percentage of tokens will be replaced with a special `[MASK]` token.
    *   **Predicted Loop Type**: Standard embedding for the loop type categorical feature.
    *   **Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$, if it is paired with nucleotide $j$, we calculate the signed distance $d = j - i$. If unpaired, $d=0$. This scalar is projected into a high-dimensional vector using **Sinusoidal Positional Encodings**. This feature proved superior to categorical structure tokens **Cite solution_lesson_node_00016** and avoids the pitfalls of Graph Neural Networks **Cite solution_lesson_node_00009**.
*   **Backbone: Deep Pre-LayerNorm Residual BiGRU**:
    *   The encoder will consist of 5-6 layers of **Bidirectional GRUs**.
    *   **Pre-LayerNorm Design**: We will apply Layer Normalization *before* the GRU layer in the residual block (`x + GRU(Norm(x))`). This facilitates the training of deeper recurrent networks compared to the standard Post-LayerNorm approach **Cite solution_lesson_node_00017**.
    *   We will **not** use Convolutional layers, adhering to the lesson that CNNs smooth features too aggressively for this task **Cite solution_lesson_node_00013**.
*   **Dual Output Heads**:
    1.  **Degradation Head (Regression)**: A MLP projecting the hidden states to the 5 target degradation values.
    2.  **Reconstruction Head (Classification)**: A MLP projecting the hidden states to 4 logits (A, G, C, U) to predict the identity of the masked input bases.

# Data
*   **Full-Context Processing**: We will process the complete 107-nucleotide sequence. We will **not crop** inputs to the scored length (68), ensuring the model utilizes downstream structural context **Cite solution_lesson_node_00002**.
*   **Dynamic Masking**: During training data loading, we will randomly mask 15% of the `sequence` tokens. This forces the model to learn the "grammar" of RNA folding (e.g., inferring a 'G' because it pairs with a 'C' in the structure) to minimize the reconstruction loss.
*   **Feature Generation**: We will pre-calculate the "Pairing Distance" ($j-i$) map for all samples from the `structure` string.

# Training
*   **Objective Function: Joint Masked Loss**:
    *   $L = L_{Regression} + \lambda \cdot L_{Reconstruction}$
    *   **Regression Loss**: We will use **Masked Mean Squared Error (MSE)** calculated *only* on the first 68 positions (scored region). We will strictly avoid "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **Reconstruction Loss**: We will use **Cross Entropy Loss** calculated *only* on the masked positions (which can be anywhere in the 107-length sequence). This allows the model to gain supervision signal from the unscored regions (69-107), effectively increasing the dataset utility.
    *   **No Sample Weighting**: We will **not** weight samples by signal-to-noise ratio, treating all samples equally to avoid distribution mismatch **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW with Cosine Annealing scheduler.

# Evaluation
*   **Inference**: The test sequences will be passed through the model **without masking**. We will extract the output from the **Degradation Head** only.
*   **Formatting**: The model will output predictions for all 107 positions. These will be flattened to match the `id_seqpos` format.
