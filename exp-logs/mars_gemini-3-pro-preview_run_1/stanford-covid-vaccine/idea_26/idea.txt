Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Position-Aware Wide-Stream BiGRU with Structural Dropout**. This strategy represents a structural evolution of the "Scalar-Aggregated Wide-Stream Residual BiGRU" (Idea 19). It retains the robust backbone and aggregation mechanisms while introducing **Absolute Positional Embeddings** to explicitly model fixed-length end-effects and **Structural Edge Dropout** to regularize against noise in the provided secondary structure predictions.

# Model
**Architecture: Position-Aware Wide-Stream Residual BiGRU with Structural Dropout**
We will construct a deep recurrent network optimized for fixed-length RNA sequences with noisy structural inputs.

*   **Input Embeddings**: We will concatenate four distinct feature channels per nucleotide:
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024**.
    4.  **Absolute Positional Embedding (Structural Innovation)**: We will add a learnable embedding vector corresponding to the absolute index of the nucleotide (0 to 106).
        *   **Rationale**: RNA degradation often exhibits strong "end effects" (e.g., fraying at the 5' and 3' termini) that are strictly dependent on absolute position. While RNNs can implicitly learn to count, explicit positional embeddings allow the model to bias predictions for specific regions (like the first 5 bases) efficiently, reinforcing the **Global Receptive Field** **Cite solution_lesson_node_00004**.

*   **Structural Edge Dropout (Regularization Innovation)**:
    *   During training, we will apply a specialized dropout mask to the **Pairing Distance** feature.
    *   With probability $p$ (e.g., 0.15), we will forcibly set the distance of a paired base to $0$ (treating it as unpaired).
    *   **Rationale**: The provided `structure` data is a *prediction* (from ViennaRNA), not ground truth, and contains errors. By randomly dropping structural edges, we act as a regularizer that prevents the model from over-relying on potentially incorrect base-pairs, forcing it to learn robust features from the sequence and loop context. This avoids the destructive impact of masking the *sequence* itself **Cite solution_lesson_node_00020**.

*   **Recurrent Stem**:
    *   A single **BiGRU layer** projects the concatenated embeddings to the model's residual stream width $W$ (e.g., 384). This ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: We use **Pre-LayerNorm** **Cite solution_lesson_node_00017** and **maintain the full residual stream width** $W$ throughout (BiGRU hidden size $W/2$), avoiding bottleneck projections **Cite solution_lesson_node_00041**.

*   **Output Head**:
    *   **Scalar Mixture Aggregation**: We compute a learnable weighted sum of outputs from the Stem and all Blocks **Cite solution_lesson_node_00049**. We use **Iterative Accumulation** for memory efficiency **Cite solution_lesson_node_00063**.
    *   **Shared Projection**: A simple Linear layer maps the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00048**, **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** mask any input sequence tokens **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW with Weight Decay (e.g., 0.01) to prevent overfitting **Cite solution_lesson_node_00060**.
*   **Scheduler**: **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20) **Cite solution_lesson_node_00056**.
*   **Checkpointing**: Save the model with the **lowest Validation MCRMSE**, rejecting SWA/tail-averaging **Cite solution_lesson_node_00060**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model (Structural Dropout is disabled during inference). Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
