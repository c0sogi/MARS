### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` object with `debug=True` to ensure minimal resource usage. Set random seeds using `seed_everything` for reproducibility.
2.  **Feature Engineering Demonstration**: Manually define a short RNA sequence and structure string. Invoke `compute_adjacency`, `compute_rwpe`, and `compute_signed_distance` from `library.features` to demonstrate how raw text data is converted into geometric and topological features. Validate the output shapes (e.g., adjacency matrix symmetry, RWPE feature dimensions).
3.  **Dataset & DataLoader Demonstration**: Load a small sample (first 5 rows) from the provided `./metadata/train.parquet`. Use `process_dataframe` to convert this pandas DataFrame into the dictionary format required by `RNADataset`. Instantiate the dataset and a PyTorch DataLoader, then fetch a single batch to verify tensor shapes for sequences, loop types, RWPE, distances, and targets.
4.  **Model Instantiation & Forward Pass**: Initialize the `TopologicalWideResBiLSTM` model. Pass the batch retrieved in the previous step through the model to demonstrate inference. Assert that the output logits have the expected shape `(Batch_Size, Seq_Len, 3)`.
5.  **Metric Verification**: Create dummy ground truth and prediction arrays to verify the `mcrmse` function logic.
6.  **Full Pipeline Execution**: Call the `run_training` function from `library.train` with `debug=True` and `epochs=1`. This demonstrates the end-to-end workflow including training, validation, and submission generation, utilizing the pre-existing logic in the library.
