To resolve the `RuntimeError: CUDA error: CUBLAS_STATUS_ALLOC_FAILED`, which indicates GPU resource exhaustion or fragmentation in the persistent session (Cite debug_lesson_3), I will implement the following changes:

1.  **Reduce Memory Pressure**: In `runfile.py` and `library/config.py`, I will decrease the batch size from 32 to 16. This reduces the memory footprint of intermediate activations during the forward/backward passes.
2.  **Eliminate Multiprocessing Overhead**: In `library/dataset.py`, I will set `num_workers` to 0 in the `DataLoader`. This prevents the spawning of additional processes that consume system resources and can conflict with the main process's CUDA context in constrained environments.
3.  **Clear GPU Cache**: In `runfile.py`, I will explicitly call `torch.cuda.empty_cache()` before the training loop starts to release any "zombie" memory held by previous executions in the persistent environment.
