The implementation strategy involves creating a standalone script `runfile.py` that orchestrates the training, validation, failure analysis, and submission process using the provided library modules.

1.  **Configuration & Setup**: I will instantiate the `Config` class, overriding the default epochs to 15 to ensure a fast but effective baseline within the time limit. Random seeds will be set for reproducibility.
2.  **Data Loading**: The `get_dataloaders` function will be used to load training, validation, and test datasets, leveraging the caching mechanism for speed.
3.  **Training Loop**: A standard training loop will be implemented using `train_fn` for training and a custom evaluation function that captures IDs, predictions, and targets for the validation set. This allows for both metric calculation and subsequent failure analysis. The best model based on validation MCRMSE will be saved.
4.  **Validation & Failure Analysis**:
    *   After training, the best model will be reloaded.
    *   The **Final Validation Metric** (MCRMSE) will be computed and printed with full precision.
    *   **Failure Analysis** will be performed by calculating the per-sample RMSE on the validation set. I will load the validation metadata (`val.parquet`) to extract input features (Signal-to-Noise, Nucleotide counts). Spearman correlations between the error magnitude and these features will be calculated and printed to identify sources of systematic error.
5.  **Conditional Submission**:
    *   The script will check if the validation metric is below the threshold `0.6176461577`.
    *   If the condition is met, `inference_fn` will be called on the test set.
    *   The predictions will be formatted according to the submission requirements (expanding 3 predicted columns to 5, filling others with 0, and flattening to row-per-position format) and saved to `submission.csv`.
