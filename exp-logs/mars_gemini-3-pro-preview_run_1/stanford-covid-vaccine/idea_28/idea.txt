Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **SwiGLU-Augmented Wide-Stream BiGRU with Continuous Noise Injection**. This strategy represents a structural evolution that addresses the "Capacity vs. Regularization" paradox identified in Lessons 00022 and 00070. It integrates a high-capacity non-linear activation block (SwiGLU) directly into the recurrent backbone to maximize expressivity without depth scaling, and employs **Continuous Gaussian Noise Injection** to robustly regularize the model without the causal corruption issues of structural dropout.

# Model
**Architecture: SwiGLU-Augmented Wide-Stream Residual BiGRU**
We will construct a high-capacity recurrent network that enhances the processing power of each layer while maintaining the successful "Wide-Stream" information flow.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide. We will maintain **High-Dimensional Embeddings (128)** to prevent information bottlenecks **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. Lesson 00022 proved that width is the primary driver of performance. The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: SwiGLU-Augmented Residual Blocks (Structural Innovation)**:
    *   The encoder will consist of **6 Blocks** (adhering to the "Shallow and Wide" principle **Cite solution_lesson_node_00065**).
    *   **Structure**: Each block improves upon the standard design by integrating a **SwiGLU** (Swish-Gated Linear Unit) non-linearity *after* the BiGRU but *before* the residual addition.
        1.  **Pre-Norm**: $h_{in} = \text{LayerNorm}(x)$ **Cite solution_lesson_node_00017**.
        2.  **Wide BiGRU**: $h_{rnn} = \text{BiGRU}(h_{in})$. The BiGRU has hidden size 256 per direction, outputting dimension $W=512$. We strictly avoid bottleneck projections **Cite solution_lesson_node_00041**.
        3.  **SwiGLU Block**:
            *   Project $h_{rnn}$ to $2W$ (1024) via Linear layer.
            *   Split into two chunks $a, b$ of size $W$.
            *   Compute $h_{act} = a \odot \text{Swish}(b)$.
            *   **Rationale**: SwiGLU adds significant learnable capacity and non-linearity to the recurrent transition without increasing depth or decoupling the mixing (as warned against in **Cite solution_lesson_node_00047**). It acts as an "Inverted Bottleneck" for feature processing.
        4.  **Residual**: $x = x + h_{act}$.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating for noisy data **Cite solution_lesson_node_00061** and dense concatenation **Cite solution_lesson_node_00055**. We use iterative accumulation for memory efficiency **Cite solution_lesson_node_00063**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053** and keep the head simple **Cite solution_lesson_node_00048**.

# Data
*   **Continuous Embedding Noise Injection (Regularization Innovation)**:
    *   To regularize the high-capacity (Width 512) backbone without the destructive effects of Structural Dropout **Cite solution_lesson_node_00067** or Causal Augmentation **Cite solution_lesson_node_00069**, we will inject **Gaussian Noise** into the continuous embedding space.
    *   During training, after looking up and concatenating the embeddings (Sequence + Loop + Distance), we add noise $\epsilon \sim \mathcal{N}(0, \sigma)$ (e.g., $\sigma=0.1$).
    *   **Rationale**: This smooths the feature manifold and prevents the model from overfitting to high-frequency artifacts in the input representation, acting as a robust regularizer compatible with the causal nature of the data.

*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** mask any input sequence tokens **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly reject high weight decay (1e-2) which was proven destructive for RNNs in **Cite solution_lesson_node_00070**. We rely on Dropout and Noise Injection for regularization instead.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.
*   **Checkpointing**:
    *   Save the model with the **lowest Validation MCRMSE**, rejecting SWA/tail-averaging **Cite solution_lesson_node_00060**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model (Noise Injection disabled). Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
