Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Deeply-Supervised Wide-Stream Residual BiLSTM** strategy. This approach represents a structural evolution that resolves the optimization and generalization bottlenecks of high-capacity recurrent networks (Lessons 00108, 00150) by enforcing semantic feature alignment at every depth via **Deep Supervision**, while strictly adhering to the stability protocols (Gradient Clipping, Pre-LayerNorm) that define the state-of-the-art.

# Model
**Architecture: Deeply-Supervised Wide-Stream Residual BiLSTM**
We will construct a deep recurrent network optimized for hierarchical feature extraction, where every layer is explicitly trained to be predictive of the target, creating a robust "Depth Ensemble".

*   **Proportional Input Embeddings**: We will maintain the **Heterogeneous Feature Embedding** strategy to balance information content **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.
    *   **Fusion**: These are concatenated (Total Dim 256) without independent normalization **Cite solution_lesson_node_00102**.

*   **High-Fidelity Recurrent Stem**:
    *   The fused input is projected via a single **BiLSTM layer** to the model's residual stream width $W$.
    *   **Backbone Choice**: We utilize **BiLSTM** (Bidirectional LSTM). LSTMs possess superior memory capabilities for hierarchical RNA folding compared to GRUs **Cite solution_lesson_node_00150**, provided they are stabilized (see Training).
    *   **Capacity Control**: We will set the stream width $W$ to **384**. We adhere to this width because scaling to 512 has consistently led to overfitting **Cite solution_lesson_node_00081** and optimization instability **Cite solution_lesson_node_00108**.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem **Cite solution_lesson_node_00109**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We **maintain the full residual stream width** $W=384$ throughout, explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiLSTM but before the residual addition **Cite solution_lesson_node_00076**.

*   **Shared Readout & Deep Supervision (Structural Innovation)**:
    *   We employ a **Shared Linear Projection Head** that maps a 384-dim vector to the 3 target channels.
    *   **Deep Supervision**: During training, we apply this Shared Head to the output of the **Stem** and **every Residual Block** ($x_0, \dots, x_6$). We compute the MSE loss for each of these intermediate predictions.
    *   **Rationale**: This forces every layer in the network to learn semantically meaningful features that are linearly separable with respect to the target. It mitigates the vanishing gradient problem in LSTMs and regularizes the deep backbone by constraining the hidden state trajectory, addressing the optimization difficulties observed in **Cite solution_lesson_node_00108**.

*   **Aggregation: Scalar Mixture**:
    *   For the final prediction, we compute a learnable weighted sum of the outputs from the Stem and all 6 Blocks ($h_{final} = \sum w_l x_l$). This **Global Static Aggregation** acts as an ensemble of the deeply-supervised layers **Cite solution_lesson_node_00049**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**. The aggregated vector is passed to the Shared Head for the primary prediction.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Total Loss**: $L = \text{MSE}(y_{main}, y_{gt}) + \lambda \sum_{l=0}^{6} \text{MSE}(y_{layer\_l}, y_{gt})$. We set $\lambda=0.5$.
    *   **Loss Type**: Strictly use **MSE (L2)** **Cite solution_lesson_node_00012**.
    *   **Masking**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is the critical stabilizer that allows the deep BiLSTM to converge **Cite solution_lesson_node_00097**.
    *   **Batch Size**: Strictly use **32** **Cite solution_lesson_node_00131**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20) **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Use the prediction derived from the **Scalar Mixture** (Main Output). Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
