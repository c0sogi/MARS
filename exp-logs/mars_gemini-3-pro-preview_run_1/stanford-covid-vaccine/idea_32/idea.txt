Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **LayerScale-Stabilized Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that resolves the "Capacity vs. Optimization" paradox identified in Lessons 00022, 00065, and 00081. By integrating **LayerScale**—a learnable gating mechanism—into the recurrent backbone, we can successfully deploy the high-capacity **Wide-Stream (Width 512)** architecture that was previously unstable, without resorting to destructive regularization techniques like high weight decay or structural dropout.

# Model
**Architecture: LayerScale-Stabilized Wide-Stream Residual BiGRU**
We will construct a high-capacity deep recurrent network optimized for stable gradient propagation and effective utilization of width.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide, maintaining **High-Dimensional Embeddings (e.g., 128)** to prevent information bottlenecks **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or RBFs **Cite solution_lesson_node_00042**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. Lesson 00022 proved that width is the primary driver of performance, and LayerScale will mitigate the overfitting risks identified in Lesson 00081. The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: LayerScale-Stabilized Residual Blocks (Structural Innovation)**:
    *   The encoder will consist of **6-8 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=512$ throughout (BiGRU hidden size 256 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **LayerScale Integration**: We will introduce a learnable diagonal scaling matrix $\Lambda_l$ (initialized to a small value $\epsilon$, e.g., 1e-4) to the residual branch of each block.
        *   $h_{rnn} = \text{BiGRU}(\text{LayerNorm}(x_l))$
        *   $x_{l+1} = x_l + \text{diag}(\Lambda_l) \cdot h_{rnn}$
        *   **Rationale**: LayerScale allows the model to behave like a shallow ensemble at initialization (since the residual branch is scaled down), facilitating the optimization of the deep, wide backbone. As training progresses, the model can adaptively "open" the gates to utilize the full non-linear capacity of the 512-width BiGRU, solving the optimization friction that hindered previous wide models **Cite solution_lesson_node_00065**, **Cite solution_lesson_node_00081**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all Blocks. This **Global Static Aggregation** is superior to dynamic gating for noisy data **Cite solution_lesson_node_00061**, dense concatenation **Cite solution_lesson_node_00055**, and channel-wise weighting **Cite solution_lesson_node_00073**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053** and keep the head simple **Cite solution_lesson_node_00048**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** mask any input sequence tokens or perform auxiliary Masked Language Modeling **Cite solution_lesson_node_00020**.
    *   **No Augmentation**: Avoid Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We rely on LayerScale and Inter-Layer Dropout for regularization and explicitly avoid the high weight decay that suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Regularization**: Use **Inter-Layer Dropout** (e.g., 0.1) which outperforms Zoneout **Cite solution_lesson_node_00076**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.
*   **Checkpointing**:
    *   Save the model with the **lowest Validation MCRMSE**, rejecting SWA/tail-averaging to avoid overfitting artifacts **Cite solution_lesson_node_00060**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
