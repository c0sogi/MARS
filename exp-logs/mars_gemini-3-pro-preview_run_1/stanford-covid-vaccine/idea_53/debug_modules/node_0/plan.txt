This implementation strategy outlines a self-contained Python script to demonstrate and verify the provided RNA degradation prediction library.

### Strategy Outline
1.  **Configuration Override**: Modify the `Config` class attributes at runtime to create a "Demo" environment. This involves setting a custom working directory (`./working/demo_run`) to avoid overwriting existing caches, and reducing model hyperparameters (batch size, hidden dimensions, layers) and training duration (1 epoch) to ensure the script executes quickly.
2.  **Utility Verification**: Explicitly test the `mcrmse` metric function with manually calculated ground truth and prediction arrays to confirm correctness.
3.  **Data Processing Verification**: Validate the `parse_structure_to_distance` function by passing a known RNA structure string and asserting the calculated distance array matches expected values.
4.  **Pipeline Component Checks**:
    *   Initialize the `RNADataset` and `DataLoader` using the training metadata. Verify the shapes of the yielded tensors (`sequence`, `target`, `pairing_distance`) against the configuration.
    *   Instantiate the `RNAModel` and perform a forward pass with a real batch of data to verify tensor flow and output dimensions.
    *   Compute the loss using `loss_fn` to ensure the masking logic (scoring only the first 68 bases) functions correctly and returns a valid scalar.
5.  **Integration Test**: Execute the `run_training` function with `debug=True`. This runs a shortened training loop (limiting the number of batches) and automatically triggers the submission generation process using the test set.
6.  **Submission Validation**: Load the generated `submission.csv`, verify its dimensions (rows = test samples * sequence length), check for required columns, and ensure there are no missing values.
