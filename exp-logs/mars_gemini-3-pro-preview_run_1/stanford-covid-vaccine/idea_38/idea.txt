Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Cardinality-Scaled Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that resolves the "Capacity vs. Overfitting" paradox identified in Lessons 00022 and 00081. By adopting a **Split-Transform-Merge** topology (inspired by ResNeXt), we can deploy a high-capacity **Wide-Stream (Width 512)** backbone to maximize information flow, while strictly controlling parameter complexity to prevent overfitting on this small dataset.

# Model
**Architecture: Cardinality-Scaled Wide-Stream Residual BiGRU**
We will construct a deep recurrent network that scales "Cardinality" (number of parallel recurrent paths) rather than just depth or dense width, optimizing the parameter-efficiency of the wide backbone.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide. We will strictly maintain **High-Dimensional Embeddings (128)** to prevent the information bottleneck identified in **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U) **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or RBFs **Cite solution_lesson_node_00042**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W=512$.
    *   **Rationale**: The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: Cardinality-Scaled Residual Blocks (Structural Innovation)**:
    *   The encoder will consist of **6 Blocks**.
    *   **Split-Transform-Merge Topology**: Instead of a single dense BiGRU (which overfits at Width 512 **Cite solution_lesson_node_00081**), each block will implement a grouped transformation:
        1.  **Pre-Norm**: $x_{norm} = \text{LayerNorm}(x)$ **Cite solution_lesson_node_00017**.
        2.  **Split**: Divide $x_{norm}$ (channel-wise) into $C=4$ groups of width 128.
        3.  **Transform (Parallel Recurrence)**: Process each group independently with a dedicated BiGRU (Hidden Size 64 per direction, Output 128). This reduces the recurrent parameter count by a factor of $C$ while maintaining the total state capacity of 512.
        4.  **Merge**: Concatenate the group outputs and pass them through a **Mixing Linear Projection** ($512 \to 512$) to enable cross-group information exchange.
        5.  **Dropout**: Apply **Inter-Layer Dropout (p=0.2)** **Cite solution_lesson_node_00076**.
        6.  **Residual**: $x = x + h_{mixed}$.
    *   **Rationale**: This architecture allows us to satisfy Lesson 00022 (Width drives performance) by maintaining a 512-dimensional residual stream, while avoiding the parameter explosion that caused overfitting in previous wide models. It respects the "Stacked RNN" inductive bias **Cite solution_lesson_node_00047** but structures the weight matrices for efficiency.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**, dense concatenation **Cite solution_lesson_node_00055**, or channel-wise weighting **Cite solution_lesson_node_00073**. We strictly exclude raw inputs **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**. We rely on the grouped architecture and dropout for regularization.
    *   **Gradient Clipping**: Clip gradients to norm 1.0 to ensure stability **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
