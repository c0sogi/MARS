Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Configuration & Setup**: Import the provided `Config` and override specific parameters (`EPOCHS`) to ensure the training completes quickly as a baseline. Set random seeds for reproducibility.
2.  **Data Loading**: Use the `get_dataloaders` function from the library to load training, validation, and test sets. This leverages the caching mechanism implemented in `library/data.py`.
3.  **Model Initialization**: Instantiate the `RNAModel` (Cardinality-Scaled Wide-Stream Residual BiGRU) and move it to the configured device (GPU).
4.  **Training**: Initialize the `Trainer` and execute the `fit()` method. This handles the training loop, loss calculation, and model checkpointing.
5.  **Validation**: After training, perform a dedicated validation run on the full validation set to compute the final MCRMSE metric. Print this metric in the exact required format.
6.  **Failure Analysis**:
    *   Load the validation metadata to retrieve sample-level attributes (e.g., `signal_to_noise`).
    *   Run inference on the validation set to compute sample-wise RMSE errors.
    *   Calculate and print Pearson correlations between the error magnitude and input features (Signal/Noise, Nucleotide Composition) to identify sources of systematic error.
7.  **Submission**: Compare the final validation metric against the specified threshold (`0.6199890971183777`). If the model performs well enough, generate the `submission.csv` file using the `generate_submission` method of the trainer.
