The `AssertionError: Loss should be a scalar` occurs because the `HomoscedasticLoss` class in `library/model.py` initializes its learnable parameters `s1` and `s2` as 1-dimensional tensors (`torch.zeros(1)`). When these are used in the loss calculation, PyTorch's broadcasting rules cause the resulting loss to also be a 1-dimensional tensor (shape `[1]`), whereas the training loop and validation checks expect a 0-dimensional scalar (shape `[]`). I will fix this by initializing these parameters as scalars using `torch.tensor(0.0)`.
