implementation strategy
The implementation demonstrates the end-to-end usage of the provided RNA degradation prediction library. 

1.  **Setup & Data Mocking**: It creates a temporary directory and generates "mini" versions of the training, validation, and test datasets by sampling the first few rows of the original metadata files. This ensures the code runs quickly (optimizing for speed) while using real data structures.
2.  **Configuration Patching**: Since the library modules import configuration constants at the top level, the script explicitly patches these constants within the `library.config`, `library.data`, and `library.train` namespaces. This redirects the pipeline to use the mini datasets and reduced hyperparameters (2 epochs, batch size 4).
3.  **Component Validation**:
    *   **Data Loading**: Verifies `library.data.get_dataset` correctly loads the mini datasets and produces items with the expected keys and tensor shapes.
    *   **Model**: Instantiates `library.model.RNANet`, performs a forward pass with dummy data, and asserts output shapes match `[Batch, Seq_Len, 3]`.
    *   **Loss**: Validates `library.model.HomoscedasticLoss` computes a scalar loss from model outputs.
4.  **Pipeline Execution**: Calls `library.train.run_training()` to execute the full training loop, validation, and inference process using the patched configuration.
5.  **Submission Verification**: Checks the generated submission file for correct dimensions (rows matching test samples × sequence length) and required columns.
