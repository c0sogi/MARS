### Implementation Strategy

1.  **Configuration Override**: Since the library files import `Config` directly, we will modify the attributes of `library.config.Config` at runtime. We will reduce model size (hidden dimensions, layers) and training parameters (epochs, batch size) to ensure the demonstration runs in seconds rather than hours.
2.  **Utility Verification**: We will test the `mcrmse` metric function with known inputs and verify the `format_submission` function generates a CSV with the correct structure.
3.  **Dataset Loading**: We will instantiate the `RNADataset` for training and testing. We will verify that data loading works, cache files are created in the working directory, and the output tensors have the expected shapes and data types.
4.  **Model Forward Pass**: We will instantiate the `TokenAdaptiveWideResBiGRU` model with the reduced configuration. We will perform a forward pass using a batch of real data from the dataset to verify tensor shapes and connectivity.
5.  **Training & Inference Loop**: We will manually construct `DataLoader` instances with a small subset of data. We will run one epoch of training using `train_fn`, one evaluation pass using `eval_fn`, and an inference pass using `inference_fn`. This demonstrates the `engine.py` components without running the full-scale training process.
6.  **Cleanup**: We will ensure all outputs are directed to a specific demo directory within `./working` to keep the environment clean.
