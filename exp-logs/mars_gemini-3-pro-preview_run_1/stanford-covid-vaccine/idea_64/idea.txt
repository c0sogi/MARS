Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Structure-Injected Wide-Stream Residual BiLSTM** strategy. This approach represents a structural evolution that unlocks the high-performance potential of the **Width 512** regime (Lesson 00022) by resolving the "Memory vs. Context" bottleneck. By explicitly re-injecting structural features at every depth, we relieve the recurrent state from the burden of maintaining static topological information, allowing the high-capacity backbone to focus on modeling complex degradation kinetics without the overfitting observed in previous attempts (Lesson 00081).

# Model
**Architecture: Structure-Injected Wide-Stream Residual BiLSTM**
We will construct a deep, high-capacity recurrent network where static structural context is available as a direct input to every processing block, while sequence information evolves hierarchically.

*   **Proportional Input Embeddings**: We will implement the **Heterogeneous Feature Embedding** strategy to balance information content **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.
    *   **Structural Context Vector**: We define $E_{struct} = \text{Concat}(E_{loop}, E_{dist})$ (Dim 128). This vector represents the static topology of the RNA.

*   **High-Fidelity Recurrent Stem**:
    *   The full input (Sequence + Structure, Total Dim 256) is projected via a single **BiLSTM layer** to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. We switch to **BiLSTM** for superior long-term dependency modeling **Cite solution_lesson_node_00150**, **Cite solution_lesson_node_00108**.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem **Cite solution_lesson_node_00109**.

*   **Backbone: Structure-Injected Residual Blocks (Structural Innovation)**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We **maintain the full residual stream width** $W=512$ throughout **Cite solution_lesson_node_00041**.
    *   **Structural Injection**: Inside each block, we concatenate the static **Structural Context Vector** ($E_{struct}$) to the normalized residual stream *before* feeding it into the BiLSTM.
        *   $h_{in} = \text{Concat}(\text{LayerNorm}(x_l), E_{struct})$
        *   $h_{rnn} = \text{BiLSTM}(h_{in})$ (Input Dim $512+128$, Hidden $256 \times 2$)
        *   $x_{l+1} = x_l + \text{Dropout}(h_{rnn})$
    *   **Rationale**: Unlike re-injecting the sequence (which causes overfitting, **Cite solution_lesson_node_00154**), re-injecting the static structure provides a stable "scaffold" at every depth. This prevents the "vanishing structure" problem in deep RNNs and allows the LSTM cell state to be dedicated entirely to integrating the dynamic sequence-structure interactions, stabilizing the training of the 512-width backbone.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks **Cite solution_lesson_node_00049**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)** **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is critical for stabilizing the 512-width BiLSTM **Cite solution_lesson_node_00097**.
    *   **Batch Size**: Strictly use **32** **Cite solution_lesson_node_00131**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20) **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
