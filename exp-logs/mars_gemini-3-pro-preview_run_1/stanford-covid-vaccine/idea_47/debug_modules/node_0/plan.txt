Implementation Strategy:
1.  **Configuration Setup**: Import the global `Config` class and modify its attributes (e.g., `WORKING_DIR`, `NUM_EPOCHS`, `BATCH_SIZE`) to create a lightweight execution environment suitable for a demonstration. This ensures we don't overwrite production files and the code runs quickly.
2.  **Metric Verification**: Create a standalone test for the `mcrmse` function using manually defined tensors with known values to verify the correctness of the scoring metric.
3.  **Model Verification**: Instantiate the `RNAModel` and perform a forward pass with dummy random data. Assert that the output shape matches the expected dimensions `(Batch, Seq_Len, N_Outputs)`.
4.  **Data Loading**: Use the provided `get_dataloaders` function to load the actual dataset. Since the dataset is relatively small (~2k samples), we can use the full set for a single epoch to demonstrate the pipeline without significant delay.
5.  **Training & Evaluation Loop**: execute a custom training loop mirroring `run_training` but simplified. Train for one epoch using `train_one_epoch`, then evaluate using `validate`.
6.  **Inference**: Run `generate_submission` to create a prediction file.
7.  **Output Verification**: Load the generated submission CSV and verify its dimensions and column names against the requirements.
