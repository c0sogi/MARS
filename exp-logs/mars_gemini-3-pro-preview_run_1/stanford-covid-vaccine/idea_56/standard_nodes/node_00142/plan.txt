Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class and set random seeds via `set_seed` to ensure reproducibility. Detect the available hardware (GPU/CPU).
2.  **Data Loading**: Use `get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test datasets.
3.  **Model Training**: Initialize the `RNAModel` and `Trainer`. Execute the training loop (`trainer.fit()`), which runs for a fixed number of epochs (20) and saves the best model checkpoint based on validation MCRMSE.
4.  **Validation & Metric Calculation**:
    *   Load the best saved model checkpoint.
    *   Run inference on the full validation set in `eval` mode without gradient computation.
    *   Compute the **Final Validation Metric** (MCRMSE) using the provided `compute_mcrmse` function on the scored positions (first 68 bases).
    *   Print the metric in the required format.
5.  **Failure Analysis**:
    *   Calculate the Root Mean Squared Error (RMSE) for each individual sample in the validation set.
    *   Load the validation metadata (including `signal_to_noise` and sequence content).
    *   Compute and print the Pearson correlation between the sample-wise error and key features (Signal-to-Noise, SN_filter, Nucleotide Counts) to identify sources of systematic error.
6.  **Submission Generation**:
    *   Compare the final validation metric against the threshold `0.6176461577`.
    *   If the model performance is sufficient (metric < threshold), call `trainer.generate_submission()` to create the `submission.csv` file. Otherwise, skip generation.
