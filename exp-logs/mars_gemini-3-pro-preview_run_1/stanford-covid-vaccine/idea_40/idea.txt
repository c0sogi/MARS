Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose an **Input-Normed Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that aims to finally unlock the high-capacity **Width 512** regime—which has theoretically high potential (Lesson 00022) but has consistently failed due to overfitting or optimization issues in previous attempts (Lessons 00065, 00070, 00081, 00098, 00099)—by synthesizing a precise combination of **Proportional Embeddings**, **Input Normalization**, and **Correct Regularization**.

# Model
**Architecture: Input-Normed Wide-Stream Residual BiGRU**
We will construct a high-capacity deep recurrent network optimized for stable training and maximum signal fidelity.

*   **Input Embeddings**: We will implement the **Proportional Feature Embedding** strategy to balance information content with parameter efficiency **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings** **Cite solution_lesson_node_00057**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024**.

*   **Independent Feature Normalization (Structural Innovation)**:
    *   Before concatenating the three embedding channels, we will apply **Independent Layer Normalization** to each embedding vector.
    *   $E_{fused} = [\text{LN}(E_{seq}); \text{LN}(E_{loop}); \text{LN}(E_{dist})]$.
    *   **Rationale**: The different feature modalities (categorical sequence vs. geometric distance) have distinct variances and distributions. Concatenating them directly creates a jagged feature landscape that can destabilize the initial projection of the wide backbone. Normalizing them independently ensures that the BiGRU Stem receives a well-conditioned input, facilitating the optimization of the 512-width latent space.

*   **Recurrent Stem**:
    *   The fused output is projected via a single **BiGRU layer** to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. We explicitly target this high capacity **Cite solution_lesson_node_00022**, relying on the strict regularization suite (below) to prevent the overfitting observed in **Cite solution_lesson_node_00081**. The Stem ensures temporal contextualization **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks** (adhering to the "Shallow and Wide" principle **Cite solution_lesson_node_00065**).
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=512$ throughout, explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiGRU but before the residual addition. This is strictly superior to Zoneout **Cite solution_lesson_node_00076** and is critical for stabilizing the 512-width backbone.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks **Cite solution_lesson_node_00049**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Data

    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.

    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)** **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0** to ensure stability **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20) **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)** **Cite solution_lesson_node_00032**.
