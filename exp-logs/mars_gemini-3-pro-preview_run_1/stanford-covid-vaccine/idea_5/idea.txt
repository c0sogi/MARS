Based on the lessons learned from the previous experiments, I propose a **Hybrid Bi-GRU-Transformer** strategy. This approach synthesizes the superior sequential modeling of the Bi-GRU with the direct global interaction capabilities of the Transformer, while introducing a noise-aware training objective to address data quality issues.

# Model
**Architecture: Hybrid Recurrent-Attention Network**
The model is a two-stage encoder that balances inductive bias with global expressivity.
*   **Input Embeddings**: We will continue to use learnable embeddings for `sequence`, `structure`, and `predicted_loop_type`, concatenated into a single feature vector per position.
*   **Stage 1: Bidirectional GRU Encoder**: The core backbone will remain a multi-layer **Bidirectional GRU**.
    *   **Rationale**: The lessons established that Recurrent Networks significantly outperform CNNs and pure Transformers in this small-data regime due to their strong **inductive bias for sequentiality** **Cite solution_lesson_node_00010** and ability to maintain a **Global Receptive Field** **Cite solution_lesson_node_00004**. This stage converts raw tokens into rich, context-aware hidden states.
*   **Stage 2: Transformer Encoder Layer**: We will append a shallow (1-2 layer) **Transformer Encoder** block *on top* of the Bi-GRU output.
    *   **Rationale**: While the Bi-GRU captures global context, its path length is linear $O(N)$. The Transformer layer introduces a **Self-Attention Mechanism** that allows every nucleotide to attend directly to every other nucleotide with $O(1)$ path length. This explicitly models the non-local pairwise interactions (base-pairing) that define RNA stability, refining the recurrent features without forcing the model to learn topology from scratch (which caused the pure Transformer to fail **Cite solution_lesson_node_00010**). This adheres to the **sequence-native** principle **Cite solution_lesson_node_00009** while enhancing the global connectivity.
*   **Output Head**: A shared MLP projects the refined features to the 5 target values.

# Data
*   **Full-Context Processing**: We will process the entire 107-nucleotide sequence. We will **not crop** the inputs to the scored length (68), ensuring the model has access to downstream structural motifs (e.g., stem-loops) that stabilize the upstream scored region **Cite solution_lesson_node_00002**.
*   **Feature Engineering**: Inputs will be integer-encoded for embedding lookup. No graph topology will be constructed, avoiding the noise of predicted edges **Cite solution_lesson_node_00009**.

# Training
*   **Signal-Weighted Masked Loss**: We will implement a modified **Masked Mean Squared Error (MSE)**.
    *   **Masking**: As before, gradients will only be calculated for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Sample Weighting**: We will introduce a sample weighting term based on the `signal_to_noise` metadata column. Samples with higher signal-to-noise ratios will be assigned higher weights in the loss function. This directly addresses the failure analysis finding that models struggle to learn from noisy data **Cite solution_lesson_node_00002**, ensuring the model prioritizes high-quality ground truth signals during optimization.
*   **Optimizer**: AdamW with a learning rate scheduler (Cosine Annealing) to handle the hybrid architecture.

# Evaluation
*   **Inference**: The test sequences (length 107) will be passed through the hybrid model.
*   **Formatting**: The model will output predictions for all 107 positions. These will be flattened to match the `id_seqpos` format. Predictions for unscored positions (69-107) will be included to satisfy the submission format requirements.
