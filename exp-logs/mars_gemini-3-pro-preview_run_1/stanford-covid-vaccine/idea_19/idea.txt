Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Scalar-Aggregated Wide-Stream Residual BiGRU** strategy. This approach is a structural evolution that synthesizes the "Wide Stream" and "Recurrent Stem" concepts (which were partially explored but misconfigured in previous attempts) with the proven "Sinusoidal Geometric Encoding," while stripping away the detrimental components (RBFs, Bottlenecks, and Complex Heads) identified in the failure analysis.

# Model
**Architecture: Scalar-Aggregated Wide-Stream Residual BiGRU**
We will construct a deep recurrent network designed to maximize information flow by maintaining a wide residual stream and aggregating multi-scale features.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide:
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers which dilute data in small regimes **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer this over RBFs **Cite solution_lesson_node_00042**. Unpaired bases (distance 0) are encoded validly without zero-masking **Cite solution_lesson_node_00046**.

*   **Recurrent Stem (Structural Correction)**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W = 2 \times H$ (where $H$ is the hidden dimension, e.g., 192, so $W=384$).
    *   **Rationale**: We strictly reject linear projection stems. The Recurrent Stem ensures that the input to the first residual block is already temporally contextualized, aligning the semantic level of the skip connection with the processed path **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **5-6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. Crucially, we will **maintain the full residual stream width** $W$.
        *   Input $x$ has dimension $W$.
        *   The BiGRU layer has hidden size $H = W/2$. Its output (Forward + Backward) has dimension $2 \times (W/2) = W$.
        *   Residual connection: $x = x + \text{BiGRU}(\text{LayerNorm}(x))$.
        *   **Rationale**: We explicitly avoid the bottleneck projection (projecting $2H \to H$) used in failed experiments. This allows gradients to flow through the full bidirectional capacity of the network **Cite solution_lesson_node_00041**.

*   **Scalar Mixture Aggregation (Refined Component)**:
    *   Instead of using only the final layer, we will compute a learnable **Scalar Mixture** (weighted sum) of the outputs from *all* layers (Stem + Blocks 1..N).
    *   **Rationale**: This re-introduces the aggregation concept from Idea 17 but pairs it with the correct Sinusoidal encodings (fixing the RBF failure). It allows the final classifier to leverage both low-level physicochemical features (from the stem) and high-level folding features (from deep blocks) simultaneously.

*   **Output Head**:
    *   A simple Linear projection mapping the aggregated state to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We avoid complex MLPs to prevent overfitting **Cite solution_lesson_node_00048**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: We will process the complete 107-nucleotide sequence. We will **not crop** inputs, ensuring the model utilizes downstream structural information **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. We will only train on the three scored columns to prevent high-variance unscored noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: We will **not** mask any input tokens or perform auxiliary Masked Language Modeling, as it corrupts the precision regression signal **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE) **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally. We will **not** weight samples by their signal-to-noise ratio, avoiding the distribution mismatch that degrades performance on unweighted metrics **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler.

# Evaluation
*   **Metric Correction**: During validation, we will calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: The test sequences (length 107) will be passed through the model. The predictions for the 3 scored columns will be extracted, and the unscored columns will be filled with 0.0 to meet the submission format requirements.
