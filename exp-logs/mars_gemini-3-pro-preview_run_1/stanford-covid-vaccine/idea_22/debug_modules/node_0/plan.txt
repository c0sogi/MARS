The following script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It begins by creating a lightweight "demo" configuration and a small subset of the data to ensure rapid execution. It then systematically verifies the core components: the structure parsing logic, the dataset processing, the model architecture (forward pass and shapes), the custom loss function, and the evaluation metric. Finally, it executes the full training and inference pipelines using the library's high-level functions, asserting that the model checkpoints and submission files are correctly generated.
