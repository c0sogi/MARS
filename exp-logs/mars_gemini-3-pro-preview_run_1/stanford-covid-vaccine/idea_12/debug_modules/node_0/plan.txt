This script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:

1.  **Configuration Override**: Modifies the default `Config` parameters to create a lightweight "demo" mode (smaller model, fewer epochs, CPU execution) suitable for rapid verification.
2.  **Data Preparation**: Uses `get_dataloaders` to process the raw metadata into PyTorch DataLoaders. It verifies the integrity and shapes of the loaded data.
3.  **Model Initialization**: Instantiates the `InteractionAwareModel` and validates the forward pass with a sample batch.
4.  **Training**: Runs a training loop using the provided `train_one_epoch` function.
5.  **Validation**: Evaluates the model using the `validate` function and the MCRMSE metric.
6.  **Inference & Submission**: Generates predictions on the test set and formats them into a submission CSV using `format_submission`.
