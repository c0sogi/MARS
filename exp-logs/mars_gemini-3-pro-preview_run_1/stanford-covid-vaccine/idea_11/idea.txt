Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Structure-Augmented Hybrid Recurrent-Attention Network**. This strategy synthesizes the state-of-the-art "Distance-Aware Residual BiGRU" (Idea 8) with a refined "Paired-Base Identity" feature (salvaged from Idea 10) and a post-processing Attention mechanism (refining Idea 5), while strictly adhering to the training protocols established in the lessons.

# Model
**Architecture: Structure-Augmented Hybrid Recurrent-Attention Network**
We will construct a hierarchical encoder that combines explicit structural features, strong sequential inductive bias, and global attention refinement.

*   **Input Embeddings**: We will concatenate four distinct feature channels per nucleotide:
    1.  **Sequence & Loop**: Learnable embeddings for the nucleotide sequence and predicted loop type.
    2.  **Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**.
    3.  **Paired-Base Identity (Innovation)**: We will introduce a "Teleportation" feature. For a base $i$ paired with $j$, we will look up the embedding of the nucleotide at index $j$ and concatenate it directly to the input vector of $i$. If unpaired, a special "Unpaired" token embedding is used. This provides the model with immediate access to the "Watson-Crick" context of the base pair without relying on the RNN to propagate this information over long distances, addressing the failure of Idea 10 (which failed due to capacity/MLM issues, not this feature).
*   **Stage 1: Deep Pre-LayerNorm Residual BiGRU**:
    *   The core backbone will be a stack of **5-6 Bidirectional GRU layers** with **Pre-LayerNorm** residual connections (`x + GRU(Norm(x))`).
    *   We will maintain a **High Hidden Dimension (e.g., 384)**. Lesson 00022 proved that reducing capacity (to 256) causes significant performance regression in these architectures **Cite solution_lesson_node_00022**. This stage provides the necessary **Sequential Inductive Bias** **Cite solution_lesson_node_00010**.
*   **Stage 2: Transformer Encoder Refinement**:
    *   We will append a **2-layer Transformer Encoder** (with Multi-Head Self-Attention) *after* the BiGRU stack.
    *   **Rationale**: While the BiGRU builds rich local and sequential features, the Transformer allows for a final global "polish" where every nucleotide can attend to every other nucleotide with $O(1)$ path length. This ensures the **Global Receptive Field** is maximized **Cite solution_lesson_node_00004**, refining the structural dependencies established by the RNN.
*   **Output Head**: A shared MLP projects the final hidden states to the 3 scored target values.

# Data
*   **Full-Context Processing**: We will process the complete 107-nucleotide sequence for every sample. We will **not crop** inputs to the scored length (68), ensuring the model utilizes downstream structural information **Cite solution_lesson_node_00002**.
*   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. We will only train on the three scored columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to prevent high-variance unscored noise from diluting the gradients **Cite solution_lesson_node_00019**.
*   **No Masking**: We will **not** mask any input tokens. Lesson 00020 demonstrated that joint Masked Language Modeling corrupts the input signal for precision regression tasks **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE) **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally. We will **not** weight samples by their signal-to-noise ratio, avoiding the distribution mismatch that degrades performance on unweighted metrics **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler.

# Evaluation
*   **Inference**: The test sequences (length 107) will be passed through the model to generate predictions.
*   **Formatting**: The model will output predictions for the 3 scored columns. We will construct the submission file by filling the unscored columns (`deg_pH10`, `deg_50C`) with 0.0 and flattening the result to the `id_seqpos` format.
