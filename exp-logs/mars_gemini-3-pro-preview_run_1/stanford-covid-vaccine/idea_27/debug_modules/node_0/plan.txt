### Implementation Strategy

1.  **Configuration Override**: Since the library files are fixed, we will modify the `Config` class attributes at runtime to adapt the pipeline for a quick demonstration (reducing epochs, batch size, and directing outputs to a specific demo directory).
2.  **Component Verification**:
    *   **Dataset**: We will load a small subset of the training data using `load_data`, verify the `RNADataset` structure, and check tensor shapes (Sequence, Loop Type, Distance, Targets).
    *   **Model**: We will instantiate the `WideResBiGRU` model, perform a forward pass with a dummy batch, and assert that the output dimensions match `(Batch, Seq_Len, Num_Targets)`.
    *   **Metric**: We will validate the `mcrmse_loss` function by comparing its output against a manually calculated value for a simple tensor.
3.  **Pipeline Execution**:
    *   **Training**: We will execute `train_model` with a small `subset_size` to verify the training loop, gradient updates, and checkpoint saving mechanics without consuming significant time.
    *   **Inference**: We will run `predict` on a subset of the test data to ensure the submission generation logic functions correctly and produces the expected CSV format.
4.  **Validation**: Throughout the script, assertions will be used to enforce expected behaviors and shapes.
