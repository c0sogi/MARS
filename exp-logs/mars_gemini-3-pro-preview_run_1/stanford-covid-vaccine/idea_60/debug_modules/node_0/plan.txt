The following script demonstrates the usage of the provided RNA degradation prediction library. It covers data loading, model instantiation, forward pass verification, loss and metric calculation, and a full training loop execution using the debug mode.

The implementation strategy is as follows:
1.  **Configuration**: Set random seeds and define a temporary working directory for the demonstration to ensure isolation and reproducibility.
2.  **Data Processing**: Use `library.dataset.get_dataset` to load and process a subset of the training data. Assertions verify that the data shapes match the expected sequence length (107) and scored length (68).
3.  **Model Verification**: Instantiate the `RNAModel` and perform a forward pass with a dummy batch. Verify that the output shape corresponds to `(Batch, Seq_Len, 3)`.
4.  **Loss & Metric Validation**: Manually compute the Masked MSE and MCRMSE on dummy tensors and assert that the library functions (`MaskedMSELoss` and `calculate_mcrmse`) return the identical values.
5.  **Training Pipeline**: Execute `library.train.run_training` in debug mode. This runs a shortened training loop (few epochs, small subset) to verify the integration of the dataset, model, optimizer, and training logic without consuming excessive time.
6.  **Cleanup**: Clean up the temporary directories created during the run.
