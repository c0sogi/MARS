The issue is that the `Config` class in `library/config.py` lacks the `DROPOUT` attribute, but the `ResidualBiGRUBlock` class in `library/layers.py` attempts to access `Config.DROPOUT` to set a default argument value. This causes an `AttributeError` at import time. This is a synchronization failure between the configuration and the model components (Cite debug_lesson_2). To fix this, I will add the `DROPOUT` parameter to the `Config` class, setting it to `0.1` to match the regularization strength implied by the existing (but seemingly unused) `ZONEOUT_PROB`.
