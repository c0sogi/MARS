This setting blocks the unpickling of complex objects like NumPy arrays, which are present in the cached dataset files (`train_data.pt`). As advised in the error analysis and **Cite debug_lesson_4**, the fix is to explicitly set `weights_only=False` when loading these trusted local artifacts to allow the deserialization of the full dataset dictionary.
