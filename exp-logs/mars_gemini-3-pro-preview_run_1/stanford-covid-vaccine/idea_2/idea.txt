Based on the insights from the previous experiments, I propose a **Graph Neural Network (GNN)** strategy. This approach represents a structural evolution from the grid-based (CNN) and sequential (RNN) paradigms by explicitly modeling the RNA molecule as a topological structure, leveraging the provided secondary structure data to create direct information pathways between distant nucleotides.

# Model
**Architecture: Relational Graph Neural Network (R-GNN)**
Instead of treating the RNA as a 1D sequence, we will represent each sample as a graph where nodes are nucleotides and edges represent physical interactions.
*   **Graph Topology**:
    *   **Nodes**: 107 nodes per sample, representing the bases.
    *   **Edges**: We will construct a heterogeneous graph with two distinct edge types:
        1.  **Backbone Edges**: Connecting node $i$ to $i+1$ (and $i+1$ to $i$) to capture the sequential covalent linkage.
        2.  **Base-Pair Edges**: Connecting node $i$ to node $j$ if they are paired in the provided `structure` string (i.e., opening parenthesis at $i$ matches closing at $j$). This explicitly "folds" the sequence in the model's representation.
*   **Node Embeddings**: Each node will be initialized with a concatenation of learnable embeddings for:
    *   `sequence` identity (A, G, C, U).
    *   `predicted_loop_type` (S, M, I, B, H, E, X).
    *   `structure` character ((, ), .).
    *   **Positional Sinusoidal Encoding**: To retain the notion of absolute position within the 107-length sequence.
*   **Encoder**: A stack of **Relational Graph Convolution (RGCN)** or **Graph Attention (GAT)** layers. These layers will aggregate messages from neighbors. Crucially, the Base-Pair edges allow the model to propagate information between distant parts of the sequence in a single hop, satisfying the requirement for global receptive fields **Cite solution_lesson_node_00004** more efficiently than a recurrent network.
*   **Decoder**: A shared Multi-Layer Perceptron (MLP) applied to each node's final hidden state to predict the 5 target degradation values.

# Data
*   **Graph Construction**: For both training and testing, we will parse the `structure` string to generate the adjacency matrix (edge indices) for the Base-Pair connections. The Backbone connections will be generated procedurally based on the sequence length.
*   **Full-Context Retention**: We will construct graphs containing all 107 nodes for every sample. Even though scoring is limited to the first 68 positions, the downstream nodes (69-106) will be included in the graph message passing to provide necessary structural context (e.g., the closing side of a stem loop started in the first 68 bases) **Cite solution_lesson_node_00002**.
*   **Feature Engineering**: Convert categorical text inputs (`sequence`, `structure`, `predicted_loop_type`) into integer indices for embedding lookup.

# Training
*   **Loss Function**: We will use **Masked Mean Squared Error (MSE)**. The model will output predictions for all 107 nodes, but the loss will be calculated by applying a boolean mask that zeros out the contribution of indices $>67$ (and any other unscored positions defined by `seq_scored`). This strictly adheres to the successful strategy of using full inputs with masked supervision **Cite solution_lesson_node_00002**.
*   **Optimizer**: AdamW optimizer with a learning rate scheduler (e.g., Cosine Annealing) to stabilize the training of the graph weights.
*   **Regularization**: Dropout applied to the node embeddings and attention weights (if using GAT) to prevent overfitting to specific structural motifs.

# Evaluation
*   **Inference**: The test set (240 samples) will be processed into graph objects identical to the training set.
*   **Prediction**: The model will perform a forward pass on the full 107-node graphs.
*   **Formatting**: We will extract the predictions for all nodes and flatten them to match the `id_seqpos` submission format. Post-processing will ensure non-negative values if necessary, though the raw regression output is primarily desired.
