Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **RBF-Encoded Deep Residual BiGRU with Layer Aggregation** strategy. This approach represents a structural evolution of the "Distance-Aware Residual BiGRU" (Idea 8) by refining the geometric encoding mechanism and enhancing the gradient flow/feature utilization via a novel output aggregation head.

# Model
**Architecture: RBF-Encoded Wide-Stream Residual BiGRU with Layer Aggregation**
We will construct a deep recurrent network that utilizes learnable geometric features and multi-scale representation aggregation.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide:
    1.  **Atomic Sequence**: Learnable embeddings for the nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers which dilute data in small regimes **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Gaussian RBF Distance Encoding (Innovation)**: We will replace the fixed Sinusoidal encoding with a **Learnable Gaussian Radial Basis Function (RBF)** bank.
        *   **Mechanism**: For every nucleotide $i$ paired with $j$, we calculate the **signed** distance $d = j-i$. We project this scalar through a bank of $N$ Gaussian kernels with learnable centers $\mu_k$ and widths $\sigma_k$: $f_k(d) = \exp(-\frac{(d - \mu_k)^2}{\sigma_k^2})$.
        *   **Rationale**: While Sinusoidal encodings (Lesson 00016) are effective, they impose a periodic inductive bias. RBFs provide a **localized** inductive bias, allowing the model to learn specific distance "buckets" (e.g., "immediate neighbor", "short hairpin", "long-range stem") with greater flexibility. Preserving the sign ensures directionality is maintained **Cite solution_lesson_node_00024**.
*   **Backbone: Deep Wide-Stream Pre-LayerNorm Residual BiGRU**:
    *   The encoder will consist of **5-6 layers** of Bidirectional GRUs.
    *   **Wide Residual Stream**: We will project the initial input embedding to dimension $2 \times H$ and maintain this width throughout the network. The residual connection will be $x + \text{BiGRU}(\text{Norm}(x))$, where both $x$ and the BiGRU output are $2 \times H$. We strictly avoid projecting the BiGRU output back down to $H$ (bottleneck), as this restricts capacity **Cite solution_lesson_node_00041**.
    *   **Pre-LayerNorm**: We will use the **Pre-LayerNorm** configuration to facilitate training **Cite solution_lesson_node_00017**.
    *   **Capacity**: We will maintain a **High Hidden Dimension (e.g., 384)** **Cite solution_lesson_node_00022**.
*   **Output Head: Scalar Mixture Layer Aggregation (Innovation)**:
    *   Instead of utilizing only the final layer's hidden state, we will implement a **Scalar Mixture** mechanism.
    *   We will learn a set of scalar weights $\{w_0, w_1, ..., w_L\}$ (softmax-normalized) to compute a weighted average of the hidden states from *all* layers: $h_{final} = \sum_{l=0}^{L} w_l \cdot h_l$.
    *   **Rationale**: This creates a "Gradient Superhighway" from the loss to every layer, mitigating vanishing gradients. It allows the final classifier to simultaneously leverage low-level physicochemical features (from early layers) and high-level global folding features (from late layers), respecting the sequential inductive bias **Cite solution_lesson_node_00010** without the noise of Input Injection **Cite solution_lesson_node_00035**.
    *   The aggregated state is projected to **3 output channels** (scored targets).

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: We will process the complete 107-nucleotide sequence. We will **not crop** inputs, ensuring the model utilizes downstream structural information **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. We will only train on the three scored columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to prevent high-variance unscored noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: We will **not** mask any input tokens or perform auxiliary Masked Language Modeling, as it corrupts the precision regression signal **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE) **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally. We will **not** weight samples by their signal-to-noise ratio, avoiding the distribution mismatch that degrades performance on unweighted metrics **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler.

# Evaluation
*   **Metric Correction**: During the validation phase, we will calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact identified in previous experiments **Cite solution_lesson_node_00032**.
*   **Inference**: The test sequences (length 107) will be passed through the model.
*   **Formatting**: We will construct the final submission file by placing the predictions into their respective columns and filling the unscored columns (`deg_pH10`, `deg_50C`) with 0.0. The results will be flattened to the `id_seqpos` format.
