Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Distance-Aware Residual BiGRU** strategy. This approach is a structural evolution that enhances the "Current Best" BiGRU by injecting explicit structural topology features (addressing the GNN's goal without its drawbacks) and deepening the architecture using residual connections (addressing the capacity limitations of shallow RNNs).

# Model
**Architecture: Distance-Aware Residual BiGRU**
We will construct a deep recurrent network that explicitly encodes the RNA's secondary structure as a sequence-native feature, bridging the gap between the "Graph" and "Sequence" paradigms.

*   **Input Embeddings**:
    *   **Sequence & Loop**: We will retain the learnable embeddings for `sequence` and `predicted_loop_type`.
    *   **Structural Relative Positional Encoding**: Instead of simple tokens for the `structure` (e.g., `(`, `)`, `.`) or a graph adjacency matrix (which failed **Cite solution_lesson_node_00009**), we will calculate the **relative distance** to the paired base for each nucleotide.
        *   If nucleotide $i$ is paired with $j$, the feature is $j - i$.
        *   If unpaired, the feature is $0$ (or a special token).
        *   This scalar value will be projected into a dense vector using **Sinusoidal Positional Encodings**. This explicitly informs the RNN of long-range dependencies (e.g., "this base pairs with one 50 steps ahead") without requiring it to "count" tokens or rely on message passing, directly satisfying the need for a **Global Receptive Field** **Cite solution_lesson_node_00004**.
*   **Backbone: Deep Residual BiGRU**:
    *   We will employ a stack of **5-6 Bidirectional GRU layers**.
    *   **Residual Connections**: To enable this increased depth without vanishing gradients, we will add residual connections (Input + Output) between the GRU layers. This increases the model's capacity to learn complex folding functions compared to the baseline's shallow network, while maintaining the **Sequential Inductive Bias** that is critical for this small dataset **Cite solution_lesson_node_00010**.
    *   We will **not** prepend any Convolutional layers, avoiding the feature smoothing issues identified in Lesson 00013 **Cite solution_lesson_node_00013**.
*   **Output Head**: A shared Multi-Layer Perceptron (MLP) will project the final hidden states to the 5 target degradation values.

# Data
*   **Preprocessing**:
    *   **Full-Context Retention**: We will process the complete 107-nucleotide sequence for every sample. We will **not crop** the inputs to the scored length (68), ensuring the model utilizes downstream structural information (e.g., 3' stem halves) that causally affects the 5' scored region **Cite solution_lesson_node_00002**.
    *   **Feature Generation**: We will parse the dot-bracket `structure` string during preprocessing to generate the "Pairing Distance" array for each sample.
*   **Format**: Inputs will be converted to integer indices (for sequence/loop) and float values (for distance encodings).

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE), preventing the under-prediction of outliers **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated only for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will **not** weight samples by their signal-to-noise ratio. We will treat all samples equally to avoid creating a distribution mismatch between training and the unweighted evaluation metric **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler to stabilize the deep residual network.

# Evaluation
*   **Inference**: The test sequences (length 107) will be processed to extract the pairing distance features and passed through the model.
*   **Formatting**: The model will output a tensor of shape `(N, 107, 5)`. These predictions will be flattened to match the `id_seqpos` format. Values for unscored positions (69-107) will be included in the submission file to meet format requirements.
