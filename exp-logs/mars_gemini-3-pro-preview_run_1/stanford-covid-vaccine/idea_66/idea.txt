Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose an **Expanded-Capacity Projected Wide-Stream BiLSTM** strategy. This approach represents a structural evolution that resolves the "Capacity vs. Stability" paradox (Lessons 00022, 00081) by decoupling the recurrent memory capacity from the residual stream width. By employing an **Inverted Bottleneck** topology—expanding dimensions within the LSTM cell and projecting back to a stable stream width—we can leverage high-dimensional feature processing without the optimization instability of a fully wide backbone.

# Model
**Architecture: Expanded-Capacity Projected Wide-Stream BiLSTM**
We will construct a deep recurrent network that utilizes an "Inverted Bottleneck" block design to maximize memory capacity while maintaining a stable gradient highway.

*   **Proportional Input Embeddings**: We will maintain the **Heterogeneous Feature Embedding** strategy **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.
    *   **Fusion**: These are concatenated (Total Dim 256) without independent normalization **Cite solution_lesson_node_00102**.

*   **Recurrent Stem**:
    *   The fused input is projected via a single **BiLSTM layer** to the model's residual stream width $W$.
    *   **Stream Width**: We will set the residual stream width $W$ to **384**. We adhere to this width because it has proven stable and generalizable **Cite solution_lesson_node_00081**.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem **Cite solution_lesson_node_00109**.

*   **Backbone: Expanded-Capacity Projected Blocks (Structural Innovation)**:
    *   The encoder will consist of **6 Blocks**.
    *   **Inverted Bottleneck Topology**: Instead of matching the LSTM hidden size to the stream width (which limits capacity), we **expand** the internal capacity and then **project** back.
        1.  **Pre-Norm**: $x_{norm} = \text{LayerNorm}(x_l)$ (Width 384) **Cite solution_lesson_node_00017**.
        2.  **Expanded BiLSTM**: We use a BiLSTM with hidden dimension **384 per direction** (Total Internal Width 768). This doubles the memory capacity compared to the baseline (192/dir), satisfying the need for high capacity **Cite solution_lesson_node_00022**.
        3.  **Compression Projection**: The BiLSTM output (768) is mapped back to the stream width (384) via a **Linear Projection**. This forces the model to compress the high-dimensional recurrent features into the stable residual manifold, acting as a bottleneck regularizer.
        4.  **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the projection **Cite solution_lesson_node_00076**.
        5.  **Residual**: $x_{l+1} = x_l + \text{Dropout}(\text{Proj}(\text{BiLSTM}(x_{norm})))$.
    *   **Orthogonal Initialization**: We explicitly initialize the recurrent weights with **Orthogonal Initialization** (gain 1.0) to ensure stability in this expanded parameter space **Cite solution_lesson_node_00108**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks **Cite solution_lesson_node_00049**. We strictly **exclude** raw inputs **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)** **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is critical for stabilizing the expanded BiLSTM **Cite solution_lesson_node_00097**.
    *   **Batch Size**: Strictly use **32** **Cite solution_lesson_node_00131**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20) **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
