Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and detecting the compute device. We will use the provided `Config` class but ensure the validation data loader is not shuffled to facilitate failure analysis alignment.
2.  **Training**: We will load the training and validation datasets using the provided `get_dataloader` function. We will then instantiate the `RNAModel` and train it using the `train_and_evaluate` engine function. This function handles the training loop, cosine annealing scheduling, and saving the best checkpoint based on MCRMSE.
3.  **Validation & Metric Calculation**: After training, we will reload the best saved model state. We will perform a dedicated inference pass on the validation set (with `shuffle=False`) to compute the final `MCRMSE` score. This score will be printed in the strict format required: `Final Validation Metric: <value>`.
4.  **Failure Analysis**: We will compute the MCRMSE loss for each individual sample in the validation set. We will then load the validation metadata (from `val.parquet`) to extract features like Signal-to-Noise Ratio (SNR), SN filter status, and nucleotide counts. We will calculate and print the Pearson correlation between the model's error and these features to identify systematic weaknesses.
5.  **Submission**: If the validation metric meets the threshold (< 0.619989), we will generate predictions for the test set. We will map the model's 3 output channels to the required 5 submission columns (filling the unscored `deg_pH10` and `deg_50C` with 0.0). The results will be formatted into the `id_seqpos` row-wise format and saved to `./submission/submission.csv`.
