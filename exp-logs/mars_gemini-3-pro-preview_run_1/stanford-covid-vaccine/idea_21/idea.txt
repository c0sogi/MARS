Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Dense-Aggregated Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution of the "Scalar-Aggregated" model (Idea 19) by replacing the constrained scalar mixing with a **Dense Feature Aggregation** mechanism, while simultaneously correcting the critical scheduler and metric flaws identified in Lessons 00051 and 00032.

# Model
**Architecture: Dense-Aggregated Wide-Stream Residual BiGRU**
We will construct a deep recurrent network designed to maximize feature accessibility and gradient flow by maintaining a wide residual stream and providing the output head with direct access to every channel at every depth.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide:
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers which dilute data in small regimes **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer this over RBFs **Cite solution_lesson_node_00042**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W = 2 \times H$ (e.g., 384). This ensures the input to the first residual block is temporally contextualized, aligning the semantic level of the skip connection with the processed path **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W$ throughout. The BiGRU layer within the block will have hidden size $W/2$ (output $W$), avoiding any bottleneck projection that restricts capacity **Cite solution_lesson_node_00041**.

*   **Dense Feature Aggregation (Structural Innovation)**:
    *   Instead of computing a weighted sum of layer outputs (Scalar Mixture), we will **Concatenate** the outputs of the Stem and all 6 Residual Blocks along the feature dimension.
    *   Resulting Dimension: $L \times W$ (e.g., $7 \times 384 = 2688$).
    *   **Rationale**: Scalar mixing forces the model to assign a single importance weight to an entire layer. Dense Aggregation (Concatenation) allows the final classifier to perform "Random Access" feature selection, picking specific channels from Layer 1 (e.g., local motifs) and Layer 6 (e.g., global folds) simultaneously. This maximizes the utility of the deep hierarchy without the complexity of attention mechanisms **Cite solution_lesson_node_00049**.

*   **Output Head**:
    *   A single **Wide Linear Projection** mapping the concatenated vector directly to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
    *   We strictly use a linear readout to prevent overfitting, adhering to the "Wider, Simpler" principle **Cite solution_lesson_node_00048**. We enforce **Shared Aggregation** (one head for all targets) to leverage inter-target correlations **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: We will process the complete 107-nucleotide sequence. We will **not crop** inputs, ensuring the model utilizes downstream structural information **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. We will only train on the three scored columns to prevent high-variance unscored noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: We will **not** mask any input tokens or perform auxiliary Masked Language Modeling, as it corrupts the precision regression signal **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE) **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally. We will **not** weight samples by their signal-to-noise ratio, avoiding the distribution mismatch that degrades performance on unweighted metrics **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer.
*   **Scheduler (Correction)**: We will use **ReduceLROnPlateau** (monitoring Validation MCRMSE) instead of `CosineAnnealingLR`. This decouples the learning rate decay from the number of epochs, preventing the "stretched schedule" artifact that hindered convergence in previous experiments **Cite solution_lesson_node_00051**.

# Evaluation
*   **Metric Correction**: During the validation phase, we will calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact identified in previous experiments **Cite solution_lesson_node_00032**.
*   **Inference**: The test sequences (length 107) will be passed through the model. The predictions for the 3 scored columns will be extracted, and the unscored columns (`deg_pH10`, `deg_50C`) will be filled with 0.0 to meet the submission format requirements.
