Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Noise-Stabilized High-Capacity Wide-Stream BiGRU** strategy. This approach represents a structural evolution that finally unlocks the high-performance potential of the **Width 512** regime (identified as critical in **Cite solution_lesson_node_00022**) by resolving the specific optimization and regularization flaws (High Weight Decay, Logic Errors, Zoneout) that caused previous high-capacity attempts to fail. It synthesizes the "Current Best" features (Proportional Embeddings, No Stem Dropout) with **Continuous Embedding Noise** to robustly regularize the expanded parameter space.

# Model
**Architecture: Noise-Stabilized High-Capacity Wide-Stream BiGRU**
We will construct a deep recurrent network optimized for maximum information density, utilizing continuous noise injection to prevent overfitting in a high-capacity backbone.

*   **Proportional Input Embeddings**: We will maintain the **Heterogeneous Feature Embedding** strategy to balance information content **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**. We explicitly ensure correct implementation to avoid the padding logic errors observed in previous 512-width attempts **Cite solution_lesson_node_00081**.

*   **Continuous Noise Injection (Structural Innovation)**:
    *   After concatenating the embeddings (Total Dim 256) and *before* the Recurrent Stem, we will inject **Gaussian Noise** ($\epsilon \sim \mathcal{N}(0, \sigma=0.1)$) into the feature vector during training.
    *   **Rationale**: This smooths the input manifold and acts as an infinite data augmentation strategy. It regularizes the high-capacity backbone without the destructive feature conflicts of Structural Dropout **Cite solution_lesson_node_00067** or the label inconsistency of Causal Augmentation **Cite solution_lesson_node_00069**.

*   **High-Fidelity Recurrent Stem**:
    *   The noisy input is projected via a single **BiGRU layer** to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. We explicitly target this high capacity to maximize performance **Cite solution_lesson_node_00022**.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem to preserve the fidelity of the initial projection **Cite solution_lesson_node_00109**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=512$ throughout, explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiGRU but before the residual addition. This is strictly superior to Zoneout **Cite solution_lesson_node_00076** and is critical for stabilizing the 512-width backbone.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061** or dense concatenation **Cite solution_lesson_node_00055**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.

    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals and caused previous 512-width models to underfit **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is the critical missing component that caused previous high-capacity models to diverge **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model (Noise Injection disabled). Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
