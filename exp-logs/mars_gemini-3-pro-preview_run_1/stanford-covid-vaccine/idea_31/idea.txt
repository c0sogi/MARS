Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Gated-Fusion Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that enhances the "Current Best" architecture by introducing a non-linear, locally-aware feature fusion stage. This addresses the limitation of linear input projection while strictly adhering to the successful backbone and training protocols established in the lessons.

# Model
**Architecture: Gated-Fusion Wide-Stream Residual BiGRU**
We will construct a deep recurrent network that prioritizes the non-linear interaction of sequence and structural features before temporal propagation.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide. We will maintain **High-Dimensional Embeddings (e.g., 128)** to prevent information bottlenecks **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or RBFs **Cite solution_lesson_node_00042**.

*   **Gated Fusion Stem (Structural Innovation)**:
    *   Instead of simply concatenating embeddings and projecting them linearly (which limits the model's ability to capture complex physicochemical interactions early), we will process the inputs through a **Gated Feature Fusion Block**.
    *   **Mechanism**: $x_{fused} = \text{GLU}(\text{Conv1D}_{k=3}(\text{LayerNorm}([E_{seq}, E_{loop}, E_{dist}])))$.
    *   **Rationale**: 
        1.  **Local Context**: The 1D Convolution (kernel size 3) captures immediate neighbor interactions (local $k$-mers) without the vocabulary dilution of explicit K-mer tokenization **Cite solution_lesson_node_00028**.
        2.  **Non-Linearity**: The Gated Linear Unit (GLU) allows the model to selectively filter information (e.g., suppressing loop features in stem regions) *before* it enters the recurrent backbone. This maximizes the expressivity of the input features.

*   **Recurrent Contextualization**:
    *   The fused output is passed through a single **BiGRU layer** that projects the stream to the model's residual width $W=384$. This ensures the input to the residual stack is temporally contextualized **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=384$ throughout (BiGRU hidden size 192 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Capacity Control**: We strictly adhere to Width 384, as Width 512 was proven to overfit this dataset **Cite solution_lesson_node_00081**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Recurrent Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061** and dense concatenation **Cite solution_lesson_node_00055**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** mask any input sequence tokens **Cite solution_lesson_node_00020**.
    *   **No Augmentation**: Avoid Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Regularization**: Use **Inter-Layer Dropout** (e.g., 0.1) which outperforms Zoneout **Cite solution_lesson_node_00076**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
