Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Multi-Task Enhanced Distance-Aware BiGRU** strategy. This approach synthesizes the state-of-the-art architecture from Idea 8 with a corrected Multi-Task learning objective (refining Idea 9) and introduces a novel "Paired-Base Identity" feature to fully exploit the RNA structural information.

# Model
**Architecture: Multi-Task Enhanced Distance-Aware Residual BiGRU**
We will construct a dual-head recurrent network that integrates explicit geometric and semantic structural features to predict degradation and reconstruct masked sequences.

*   **Input Embeddings**:
    *   **Masked Sequence**: Learnable embeddings for the nucleotide sequence (A, G, C, U, [MASK]).
    *   **Predicted Loop Type**: Learnable embeddings for the loop type (S, M, I, B, H, E, X).
    *   **Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**.
    *   **Paired-Base Identity (Innovation)**: We will introduce a new feature channel that explicitly provides the identity of the paired nucleotide. For a base $i$ paired with $j$, we will look up the embedding of the base at index $j$ (from the sequence input) and concatenate it to the input vector of $i$. If $j$ is masked, the `[MASK]` embedding is used. This provides the model with immediate "teleportation" of semantic information across the structure, complementing the geometric distance encoding and reinforcing the **Global Receptive Field** **Cite solution_lesson_node_00004**.
*   **Backbone: Deep Pre-LayerNorm Residual BiGRU**:
    *   The encoder will consist of 5-6 layers of **Bidirectional GRUs** with **Pre-LayerNorm** residual connections (`x + GRU(Norm(x))`). This architecture provides the strong **Sequential Inductive Bias** required for small datasets **Cite solution_lesson_node_00010** while enabling deep network training **Cite solution_lesson_node_00017**.
    *   We will **not** use Convolutional layers, avoiding feature smoothing **Cite solution_lesson_node_00013**.
*   **Dual Output Heads**:
    1.  **Scored Regression Head**: A MLP projecting the hidden states to **3 output channels** corresponding strictly to the scored targets (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
    2.  **Reconstruction Head**: A MLP projecting the hidden states to 4 logits to predict the identity of masked bases.

# Data
*   **Full-Context Processing**: We will process the complete 107-nucleotide sequence for every sample to capture downstream structural dependencies **Cite solution_lesson_node_00002**.
*   **Dynamic Masking**: During training, we will randomly mask 15% of the sequence tokens. This forces the model to learn RNA folding grammar (e.g., Watson-Crick pairing) to minimize reconstruction loss, acting as a powerful regularizer for this small dataset.
*   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. These unscored, high-variance targets introduce noise that degrades performance on the scored metrics **Cite solution_lesson_node_00019**.

# Training
*   **Objective Function: Joint Aligned Loss**:
    *   $L = MSE_{Regression} + \lambda \cdot CE_{Reconstruction}$
    *   **Regression Loss**: We will use **Masked Mean Squared Error (MSE)** calculated **only** on the 3 scored columns and **only** for the first 68 positions **Cite solution_lesson_node_00002**. We strictly avoid "Robust" losses (Huber) to ensure alignment with the RMSE metric **Cite solution_lesson_node_00012**.
    *   **Reconstruction Loss**: Cross Entropy Loss calculated only on the masked positions.
*   **No Sample Weighting**: We will treat all samples equally, avoiding the distribution mismatch caused by signal-to-noise weighting **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW with a Cosine Annealing scheduler.

# Evaluation
*   **Inference**: The test sequences will be passed through the model without masking.
*   **Formatting**: The model will output predictions for the 3 scored columns. We will construct the final submission file by placing these predictions into their respective columns and filling the unscored columns (`deg_pH10`, `deg_50C`) with 0.0. This ensures the submission format is valid while preventing the model from optimizing or predicting noisy, unscored variables.
