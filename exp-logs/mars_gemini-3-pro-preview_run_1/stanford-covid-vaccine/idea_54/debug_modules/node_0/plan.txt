The following script demonstrates the usage of the provided RNA degradation prediction library. It performs the following steps:

1.  **Setup and Verification**: Configures the environment for a fast demonstration run by overriding default configuration paths and parameters. It explicitly verifies the logic of the structure distance calculation function.
2.  **Model Component Testing**: Instantiates the `RNAModel` and its sub-components (like the `SinusoidalPositionalEmbedding`) with dummy data to verify input/output shapes and forward pass mechanics.
3.  **Pipeline Execution**: Utilizes the `run_training` function in `debug` mode. This mode automatically slices the dataset to a small subset (100 samples) and runs for a limited number of epochs, ensuring the demonstration completes quickly while exercising the full data loading, training, validation, and inference workflow.
4.  **Output Validation**: Checks the generated submission file to ensure it meets the competition's format requirements (correct columns and row counts for the test subset).
