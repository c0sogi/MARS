I will implement the `runfile.py` script to execute the "Stabilized High-Capacity Wide-Stream BiLSTM" strategy. This script will handle the full pipeline: setting up the environment, loading data, training the model, performing validation and failure analysis, and generating the submission if the performance criteria are met.

The implementation will:
1.  **Setup**: Initialize the environment and random seeds using `library.utils`.
2.  **Data Loading**: Use `library.data.get_dataloaders` to load cached training, validation, and test datasets.
3.  **Model**: Instantiate the `StabilizedWideBiLSTM` from `library.model`.
4.  **Training**: Execute the training loop using `library.engine.train_model`, which manages the optimizer, scheduler, and model checkpointing.
5.  **Validation**: Load the best saved model and perform inference on the full validation set to compute the `Final Validation Metric` (MCRMSE).
6.  **Failure Analysis**: Calculate per-sample RMSE and correlate it with metadata features (Signal/Noise, GC content, etc.) to identify error sources.
7.  **Submission**: conditionally generate the submission file using `library.engine.generate_submission` based on the validation score threshold.
