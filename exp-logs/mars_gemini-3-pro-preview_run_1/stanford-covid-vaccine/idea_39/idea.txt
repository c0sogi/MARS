Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Heterogeneous-Embedding Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that resolves the "Capacity vs. Overfitting" paradox by synthesizing the high-capacity "Wide-Stream" backbone with a novel **Proportional Feature Embedding** input stage and correct regularization protocols.

# Model
**Architecture: Heterogeneous-Embedding Wide-Stream Residual BiGRU**
We will construct a high-capacity deep recurrent network optimized for maximum information density and stable gradient propagation.

*   **Input Embeddings (Structural Innovation)**: We will implement a **Proportional Feature Embedding** strategy. Instead of using uniform dimensions for all inputs (which causes noise/bloat) or reducing all dimensions (which causes bottlenecks), we will allocate capacity based on feature entropy **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for the primary nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the 7-class structural context. This adheres to the 50-70% ratio rule **Cite solution_lesson_node_00099**.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) for the geometric encoding. We use **Fixed Sinusoidal Encodings** to provide a deterministic inductive bias **Cite solution_lesson_node_00057**, preserving the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024**.

*   **Recurrent Stem**:
    *   The concatenated embeddings (Total Dim 256) are projected via a single **BiGRU layer** to the model's residual stream width $W$.
    *   **Simple Projection**: We strictly avoid complex non-linear stems (like GLU/Conv) to preserve signal fidelity **Cite solution_lesson_node_00082**.
    *   **Temporal Contextualization**: This ensures the input to the residual stack is temporally processed **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks** (adhering to the "Shallow and Wide" principle **Cite solution_lesson_node_00065**).
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. Lesson 00022 proved that width is the primary driver of performance. We enable this high capacity by using specific regularization (below) to prevent the overfitting observed in previous attempts **Cite solution_lesson_node_00081**.
    *   **Dense Connectivity**: Each block uses a standard dense BiGRU (Hidden 256 per direction), explicitly rejecting grouped recurrence **Cite solution_lesson_node_00098** and bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Pre-LayerNorm**: We apply LayerNorm before the BiGRU **Cite solution_lesson_node_00017**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiGRU but before the residual addition. This is strictly superior to Zoneout for this task **Cite solution_lesson_node_00076**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks.
    *   **Global Static Aggregation**: This is superior to dynamic gating **Cite solution_lesson_node_00061**, dense concatenation **Cite solution_lesson_node_00055**, or channel-wise weighting **Cite solution_lesson_node_00073**.
    *   **Input Exclusion**: We strictly **exclude** the raw input embeddings from this mixture to prevent noise injection **Cite solution_lesson_node_00092**.
    *   **Implementation**: Use iterative accumulation for memory efficiency **Cite solution_lesson_node_00063**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053** and keep the head simple **Cite solution_lesson_node_00048**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** mask any input sequence tokens **Cite solution_lesson_node_00020**.
    *   **No Augmentation**: Avoid Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**. We rely on Inter-Layer Dropout for regularization.
    *   **Gradient Clipping**: Clip gradients to norm **1.0** to ensure stability for the deep recurrent backbone **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.
*   **Checkpointing**:
    *   Save the model with the **lowest Validation MCRMSE**, rejecting SWA/tail-averaging to avoid overfitting artifacts **Cite solution_lesson_node_00060**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
