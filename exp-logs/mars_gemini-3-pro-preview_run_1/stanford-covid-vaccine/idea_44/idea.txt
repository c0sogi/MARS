Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Dual-Stream Recurrent Fusion Wide-Stream BiGRU** strategy. This approach represents a structural evolution that enhances the signal fidelity of the "Current Best" architecture (Idea 44) by disentangling the initial processing of sequence identity and structural topology. This addresses the "Signal Fidelity" requirement (Lesson 00109) and the "Proportional Feature" principle (Lesson 00099) while strictly adhering to the robust backbone and training protocols established in the lessons.

# Model
**Architecture: Dual-Stream Recurrent Fusion Wide-Stream BiGRU**
We will construct a deep recurrent network that processes sequence and structure in parallel streams before fusing them into a high-capacity residual backbone.

*   **Proportional Input Embeddings**: We will maintain the **Heterogeneous Feature Embedding** strategy **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.

*   **Dual-Stream Recurrent Stem (Structural Innovation)**:
    *   Instead of concatenating all features immediately (which forces a single RNN to disentangle distinct modalities), we will employ **Two Parallel BiGRU Stems**:
        1.  **Sequence Stem**: Processes the **Atomic Sequence Embeddings** (128 dim) and projects them to a hidden state of size **192**. This allows the model to learn pure sequence motifs (k-mers) without structural interference.
        2.  **Structure Stem**: Processes the concatenated **Loop + Distance Embeddings** (128 dim) and projects them to a hidden state of size **192**. This extracts topological features.
    *   **Fusion**: The outputs of the two stems are **Concatenated** to form the initial residual stream of width **384** ($192 + 192$).
    *   **Rationale**: This respects the "Simplicity in Input Stems" lesson **Cite solution_lesson_node_00082** by using pure RNNs, but enhances "Signal Fidelity" **Cite solution_lesson_node_00109** by isolating the primary sequence signal during the critical initial transformation.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The fused stream enters a stack of **6 Residual Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We **maintain the full residual stream width** $W=384$ throughout, explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiGRU but before the residual addition. This is strictly superior to Zoneout **Cite solution_lesson_node_00076**.
    *   **No Stem Dropout**: We explicitly **remove dropout** from the output of the Dual Stems to preserve the fidelity of the fused representation **Cite solution_lesson_node_00109**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the **Fused Stem** and all **6 Blocks**. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061** or dense concatenation **Cite solution_lesson_node_00055**. We strictly **exclude** raw input embeddings from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is critical for stabilizing the deep recurrent backbone **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
