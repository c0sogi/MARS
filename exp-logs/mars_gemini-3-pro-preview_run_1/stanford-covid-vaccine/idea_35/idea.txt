Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose an **Input-Inclusive Wide-Stream Residual BiGRU with Inter-Layer Dropout**. This strategy represents a structural evolution that synthesizes the high-capacity "Wide-Stream" backbone (proven essential in Lesson 00022) with the specific regularization techniques required to stabilize it (Inter-Layer Dropout, Lesson 00076), while introducing an **Input-Inclusive Aggregation** mechanism to preserve high-fidelity atomic signals.

# Model
**Architecture: Input-Inclusive Wide-Stream Residual BiGRU**
We will construct a high-capacity deep recurrent network optimized for maximum information flow and signal preservation.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide. We will strictly maintain **High-Dimensional Embeddings (128)** to prevent the information bottleneck identified in **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. Lesson 00022 proved that width is the primary driver of performance. The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks with Inter-Layer Dropout**:
    *   The encoder will consist of **6 Blocks** (adhering to the "Shallow and Wide" principle **Cite solution_lesson_node_00065**).
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=512$ throughout (BiGRU hidden size 256 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout (Regularization Innovation)**: We will apply **Dropout (p=0.2)** to the output of the BiGRU *before* the residual addition ($x = x + \text{Dropout}(\text{BiGRU}(\text{LN}(x)))$). This is strictly superior to Zoneout or Recurrent Dropout for biological sequences **Cite solution_lesson_node_00076** and enables the training of the 512-width backbone without the overfitting observed in **Cite solution_lesson_node_00081**.

*   **Input-Inclusive Scalar Mixture (Structural Innovation)**:
    *   We will evolve the "Scalar Mixture" aggregation **Cite solution_lesson_node_00049**.
    *   In addition to the outputs of the Stem and all 6 Blocks, we will include the **Linear Projection of the Raw Input Embeddings** in the mixture pool.
    *   $h_{agg} = w_{in} \cdot \text{Proj}(E_{input}) + w_{stem} \cdot h_{stem} + \sum w_l \cdot h_l$.
    *   **Rationale**: This creates a "Safe Shortcut" for the high-fidelity atomic features (exact base identity and distance) to reach the classifier directly, bypassing the potential noise amplification of the deep RNN layers **Cite solution_lesson_node_00035**, while avoiding the optimization issues of hard architectural shortcuts **Cite solution_lesson_node_00086**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** mask any input sequence tokens **Cite solution_lesson_node_00020**.
    *   **No Augmentation**: Avoid Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**. We rely on Inter-Layer Dropout for regularization.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.
*   **Checkpointing**:
    *   Save the model with the **lowest Validation MCRMSE**, rejecting SWA/tail-averaging to avoid overfitting artifacts **Cite solution_lesson_node_00060**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
