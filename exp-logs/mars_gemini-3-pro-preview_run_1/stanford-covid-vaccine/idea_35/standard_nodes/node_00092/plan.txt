Implementation strategy:
1.  **Configuration Override**: Adjust `Config.EPOCHS` to 15 to ensure the training completes quickly within the baseline constraints while maintaining sufficient convergence.
2.  **Training Orchestration**: Call `library.train.train_model()` to execute the training pipeline. This utilizes the provided `RNAModel` (Wide-Stream Residual BiGRU) and `RNADataset`.
3.  **Validation & Metric Calculation**:
    *   Load the best saved model (`best_model.pth`).
    *   Run inference on the full validation set using the GPU.
    *   Compute the global MCRMSE metric using `library.utils.mcrmse_loss`.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the error (MCRMSE) for each individual sample in the validation set.
    *   Load the validation metadata to retrieve sample-level features (`signal_to_noise`, `SN_filter`) and derive `GC_content` from the sequence.
    *   Calculate Pearson correlations between the error and these features to identify systematic weaknesses.
    *   Print the correlations.
5.  **Submission Generation**:
    *   Compare the final validation metric against the threshold (0.6199890971183777).
    *   If the model performs well enough, call `library.train.generate_submission()` to create `submission.csv`.
