Implementation Strategy:
1.  **Setup**: Import necessary modules and the provided library components.
2.  **Configuration**: Modify the global `Config` class to set up a lightweight training run (single epoch, smaller model, small batch size) and redirect output to a demo directory to ensure speed and isolation.
3.  **Data Preparation**: Use `get_loaders` to load the data, forcing a reprocessing step (`load_cached_data=False`) to demonstrate the pipeline logic, and verify the integrity of the loaded batches using assertions.
4.  **Model Initialization**: Instantiate the `RNA_ResBiLSTM` model from `library.model` with the modified configuration and verify the forward pass output shape.
5.  **Training**: Execute a short training loop using `run_training` from `library.engine`, ensuring the pipeline runs without errors.
6.  **Evaluation**: Perform a manual inference step on the test set, verify the `mcrmse_metric` function with dummy data, and generate a submission file formatted correctly.
7.  **Cleanup**: Ensure all paths and directories are handled correctly using the `working` directory.
