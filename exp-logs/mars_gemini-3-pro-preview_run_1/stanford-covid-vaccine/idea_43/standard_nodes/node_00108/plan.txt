Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and detecting the computation device (GPU/CPU). Suppress unnecessary warnings to keep the output clean.
2.  **Data Loading**: Utilize the provided `get_loaders` function from `library.data` to efficiently load training, validation, and test DataLoaders with caching enabled.
3.  **Model Initialization**: Instantiate the `RNA_ResBiLSTM` model from `library.model` and move it to the configured device.
4.  **Training Setup**: Configure the `AdamW` optimizer and `CosineAnnealingLR` scheduler as specified in the configuration. Use `MSELoss` as the criterion.
5.  **Execution**: Run the training loop using `library.engine.run_training` for the specified number of epochs (20). This function handles the training loop, validation monitoring, and saving the best model state.
6.  **Validation & Metric**:
    *   Compute the final MCRMSE on the full validation set using `library.engine.eval_fn` (which uses `mcrmse_metric`).
    *   Print the result in the strictly required format: `Final Validation Metric: <value>`.
7.  **Failure Analysis**:
    *   Load the validation metadata (Parquet file) to access auxiliary features like `signal_to_noise`.
    *   Compute the per-sample RMSE (Root Mean Squared Error) between the model's predictions and the ground truth.
    *   Calculate and print the Pearson correlation between the sample errors and available metadata features (`signal_to_noise`, `SN_filter`, sequence attributes) to identify sources of systematic error.
8.  **Submission Generation**:
    *   Compare the final validation metric against the threshold (`0.6199890971183777`).
    *   If the model performs well enough, generate predictions for the test set.
    *   Format the predictions into the required CSV structure, filling unpredicted columns (`deg_pH10`, `deg_50C`) with zeros.
    *   Save the file to `./submission/submission.csv`.
