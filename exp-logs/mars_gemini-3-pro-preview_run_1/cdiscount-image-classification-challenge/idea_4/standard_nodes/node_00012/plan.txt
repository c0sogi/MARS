The `torch.OutOfMemoryError` was caused by an excessively large effective batch size being processed by the ResNet-50 backbone. The model processes 4 images per product sample, so a configured `BATCH_SIZE` of 512 resulted in 2,048 high-resolution images being passed through the network simultaneously, exceeding the GPU's memory capacity. To fix this, I will reduce the `BATCH_SIZE` to 128, which results in a safer effective batch size of 512 images ($128 \times 4$). This aligns with the guidance to divide the target batch size by the number of views per sample Cite debug_lesson_1.
