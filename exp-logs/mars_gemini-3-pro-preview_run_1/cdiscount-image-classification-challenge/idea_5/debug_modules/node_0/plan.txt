The following implementation demonstrates the end-to-end usage of the provided library files for the product categorization task.

**Implementation Strategy:**
1.  **Hierarchy Mapping**: We first instantiate the `HierarchyMapper` to validate that it correctly reads the category names and generates the mapping statistics (Level 1, 2, and 3 classes) required for the model.
2.  **Data Loading**: We utilize `get_dataloaders` in debug mode (`subset_size=32`) to quickly load a small batch of data. We verify the shape of the output tensors, ensuring the custom collation logic (padding to 4 images per product) works as expected.
3.  **Model Instantiation**: We initialize the `DeepSupervisedResNet50` model using the class counts derived from the mapper. We perform a forward pass with the loaded batch to confirm the output shapes of the three deep supervision heads.
4.  **Training Loop**: We execute the `run_training` function (a wrapper around the `Trainer` class) with `debug=True` and `epochs=1`. This performs a full integration test: initializing data loaders, setting up the optimizer/scheduler, running a training epoch, validating, and saving the best model checkpoint.
5.  **Inference**: Finally, we load the saved checkpoint, run inference on the test set, map the predicted indices back to the original `category_id`s using the mapper, and generate a sample submission file.
