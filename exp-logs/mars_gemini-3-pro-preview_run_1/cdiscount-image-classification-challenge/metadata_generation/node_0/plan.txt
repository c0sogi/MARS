An outline of the implementation strategy follows:

1.  **Define Constants and Paths**: Set up paths for input data (`train.bson`, `test.bson`) and output metadata (`./metadata`). Define the schema for the metadata files.
2.  **Implement BSON Scanner**: Create a robust and efficient function to scan BSON files.
    *   Iterate through the file by reading the 4-byte document size header.
    *   Use a "peek" strategy: Read a small initial chunk (e.g., 1KB) of each document to attempt to extract `_id` and `category_id` without reading the potentially large image data.
    *   Implement a lightweight BSON parser that traverses the elements (Type-Name-Value) to reliably find the fields.
    *   If the fields are not found in the initial chunk (e.g., if metadata is placed after images), fallback to reading the full document for that record.
    *   Store `_id`, `category_id`, `offset`, and `length` for each record.
3.  **Process Datasets**:
    *   Scan `train.bson` to generate the training metadata.
    *   Scan `test.bson` to generate the test metadata (no labels).
4.  **Create Validation Split**:
    *   Convert the training metadata to a Pandas DataFrame.
    *   Handle rare categories (classes with only 1 sample) by forcing them into the training set to prevent errors during stratification.
    *   Perform an 80/20 stratified split on the remaining data using `sklearn.model_selection.train_test_split` with `random_state=42`.
    *   Combine the split data back into final Train and Validation sets.
5.  **Save Metadata**: Write the DataFrames to CSV files in the `./metadata` directory (`train_metadata.csv`, `val_metadata.csv`, `test_metadata.csv`).
6.  **Validate Submission**:
    *   Reload the generated metadata files.
    *   Print summary statistics (counts, class distributions).
    *   Perform the required file path checks (verifying `train.bson` and `test.bson` exist).
    *   Additionally, verify a random sample of offsets by seeking to the location and checking if a valid BSON size header exists.
    *   Assert that the validation split ratio and stratification logic were applied correctly.
