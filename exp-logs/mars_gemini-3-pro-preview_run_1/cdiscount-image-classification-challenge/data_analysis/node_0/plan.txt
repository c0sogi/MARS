This script performs an Exploratory Data Analysis (EDA) on the Cdiscount image classification dataset. It begins by analyzing the target variable (`category_id`) distribution using the provided metadata and category hierarchy. It then performs a modality-specific analysis on the image data by sampling 5,000 records from the training set. A custom BSON parser is implemented using the `struct` module to efficiently seek and extract image data from the large binary file without external BSON libraries. The script calculates image dimensions, channel distributions, and pixel statistics (mean/std). Finally, it explores relationships between meta-features (such as the number of images per product and file sizes) and the product categories.
