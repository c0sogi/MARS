Implementation strategy:

2.  **Training**: Initialize the `Trainer` class. Execute the `fit` method with a strict `debug_limit` (200,000 samples) and `num_epochs=1`. This ensures the training phase completes quickly (approx. 15-20 mins) while providing a sufficient baseline model.
3.  **Full Validation & Analysis**: Implement a custom `run_analysis` function.
    *   Load the **entire** validation dataset (1.2M samples) to compute the official `Final Validation Metric`.
    *   Perform inference in evaluation mode (`no_grad`, `amp.autocast`) for speed.
    *   Compare predictions with targets to calculate accuracy.
    *   **Failure Analysis**: Calculate the Point-Biserial correlation between the error signal (0 for correct, 1 for incorrect) and the number of images per product. This identifies if the model struggles with products having fewer or more images.
4.  **Submission**: Call the provided `generate_submission` function, which loads the best checkpoint, runs inference on the test set, and saves the `submission.csv`.
