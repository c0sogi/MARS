This script demonstrates the end-to-end usage of the provided machine learning pipeline for cervical spine fracture detection. It systematically validates the data loading, model architecture, training loops, and inference logic for all three stages of the pipeline.

The execution flow is as follows:
1.  **Configuration Setup**: Overrides default hyperparameters (epochs, batch sizes) to ensure the demonstration runs quickly within the time limit.
2.  **Stage 1 (Segmentation)**: Validates the `SegmentationDataset` by loading a sample, checks the `UNetLocalizer` architecture, and runs a short training cycle.
3.  **Stage 2 (Encoder)**: Validates the `EncoderTrainDataset` (2.5D slice windows), checks the `MaskedCNNEncoder`, and executes a training epoch.
4.  **Stage 3 (Aggregator)**: Validates the `SequenceDataset` (handling missing features with dummy data), checks the `AnatomicalBiGRU`, and runs the sequence aggregation training.
5.  **Inference Pipeline**: Simulates the inference process for a single study by generating features from raw DICOMs using the models and then predicting fracture probabilities.
