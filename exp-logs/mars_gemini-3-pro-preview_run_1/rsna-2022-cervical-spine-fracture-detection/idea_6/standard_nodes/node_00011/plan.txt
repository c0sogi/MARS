The issue is that the script crashes because the execution environment passes extra command-line arguments (e.g., `workspace_dir`, `log_dir`) that are not defined in the script's `argparse` configuration. `parser.parse_args()` strictly enforces that only defined arguments are present. To fix this, I will switch to `parser.parse_known_args()`, which parses the expected arguments (like `--mode`) and safely ignores any undefined arguments passed by the environment.
