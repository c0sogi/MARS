The `RuntimeError: Unknown model (efficientnet-b0)` occurs because the `timm` library expects the model identifier `efficientnet_b0` (with an underscore), but the configuration uses `efficientnet-b0` (with a hyphen). This mismatch causes the model factory to fail (Cite debug_lesson_4). Additionally, because the script runs in a persistent interpreter session where modules are cached, modifying the configuration file on disk might not update the `Config` class already loaded in memory. To ensure the fix takes effect immediately without requiring a kernel restart, I will explicitly update `Config.STAGE1_BACKBONE` within the execution script (Cite debug_lesson_13).
