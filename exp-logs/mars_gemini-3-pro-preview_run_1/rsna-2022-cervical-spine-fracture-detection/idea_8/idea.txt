Based on the comprehensive analysis of the previous ideas and the critical lessons learned, I propose the **Hierarchical Anatomical-Recurrent Network (HARN)**. This solution structurally evolves the "Anatomically-Grouped" concept (Idea 6) by integrating **Soft Anatomical Attention** (to handle segmentation uncertainty) and a **Hierarchical Aggregation Head** (to explicitly model the logical relationship between vertebrae and patient-level outcomes).

# Model

The architecture is a three-stage cascade designed to enforce anatomical consistency, preserve high-frequency details, and model the logical hierarchy of the competition metric.

1.  **Stage 1: Multi-Class Anatomical Localizer (2D U-Net)**
    *   **Architecture:** A lightweight 2D U-Net trained on the segmentation subset.
    *   **Task:** Multi-class segmentation (Background, C1, C2, ..., C7).
    *   **Outputs:** For every slice, it provides:
        1.  **ROI Coordinates:** The center of the vertebral mass for cropping.
        2.  **Binary Bone Mask:** A merged mask of all vertebrae to guide the encoder.
        3.  **Soft Anatomical Map:** A probability vector ($P_{C1}, ..., P_{C7}$) indicating the likelihood of each vertebra being present in the slice. This preserves uncertainty at vertebral boundaries.

2.  **Stage 2: Mask-Conditioned Detail Encoder (2.5D CNN)**
    *   **Input:** To capture fine-grained fractures, we extract **high-resolution crops** (e.g., 256x256) from the *original* 512x512 images centered on the Stage 1 coordinates. We do not downsample the source image **Cite solution_lesson_node_00002**.
    *   **Composition:** A 4-channel tensor: 3 consecutive CT slices (RGB) + the **Binary Bone Mask** (Alpha) from Stage 1.
    *   **Backbone:** A robust 2D CNN (e.g., EfficientNet-V2) that outputs a dense **Visual Feature Vector** for each slice.

3.  **Stage 3: Hierarchical Anatomical Aggregator (Bi-GRU)**
    *   **Input:** A sequence representing the patient scan. At each step $t$, the input is the concatenation of the **Visual Feature Vector** and the **Soft Anatomical Map**.
    *   **Sequence Modeling:** A **Bidirectional GRU** processes the sequence. We select a GRU over a Transformer due to the small dataset size (~160 studies) and the need for strong inductive bias **Cite solution_lesson_node_00009**.
    *   **Soft Anatomical Attention Pooling:** Instead of a single global pool, the model generates 7 distinct **Vertebra Context Vectors** ($V_{C1}, ..., V_{C7}$).
        *   $V_{Ck}$ is computed by computing a weighted average of the GRU hidden states, where the weights are derived from the **Soft Anatomical Map** for class $k$ (from Stage 1) combined with a learned attention score. This ensures $V_{C1}$ aggregates features specifically from slices probabilistically identified as C1.
    *   **Hierarchical Prediction Heads:**
        *   **Vertebrae Heads:** 7 independent classifiers predict probabilities for C1-C7 using their respective vectors $V_{Ck}$.
        *   **Patient Head:** Instead of attending to the raw sequence again, this head takes the **concatenation** of all 7 context vectors ($[V_{C1}, ..., V_{C7}]$) as input. This explicitly models the logical dependency ("Patient is fractured if C1 OR C2... is fractured") while allowing the network to learn correlations between levels **Cite solution_lesson_node_00008**.

# Data

1.  **Preprocessing:**
    *   **Windowing:** Apply "bone window" (Center: 400, Width: 1800) to all DICOMs.
    *   **Inference Generation:** Run the Stage 1 U-Net on the entire dataset (train/test) to generate ROI coordinates, Masks, and Soft Anatomical Maps.
    *   **Cropping:** Extract fixed-size crops centered on the spine from the **full-resolution** source images **Cite solution_lesson_node_00002**.

2.  **Labeling:**
    *   **Stage 2:** Use `train_bounding_boxes.csv` to create binary slice-level targets (Fracture vs. Background).
    *   **Stage 3:** Use `train.csv` for patient-level multi-label targets.

# Training

The training is divided into three phases to decouple feature learning from metric optimization.

1.  **Phase 1 (Localizer):** Train the Multi-Class U-Net using Dice Loss + Cross Entropy to accurately segment C1-C7.

2.  **Phase 2 (Encoder):** Train the Stage 2 CNN on the slice-level bounding box targets.
    *   **Loss:** Use **Unweighted Binary Cross Entropy (BCE)**. We explicitly **do not** apply the competition's heavy `patient_overall` weights here. This forces the encoder to be conservative and precise, learning to detect fractures based on visual evidence rather than class bias **Cite solution_lesson_node_00005**.

3.  **Phase 3 (Aggregator):** Freeze the Stage 2 Encoder. Pre-compute feature sequences for all training patients. Train the Stage 3 Bi-GRU on these sequences.
    *   **Loss:** Use the **Weighted Multi-label Logarithmic Loss**. Since the RNN aggregates evidence across the volume and uses Hierarchical Pooling to route signals, it can safely optimize the weighted metric without the risk of amplifying single-slice noise inherent to Max Pooling **Cite solution_lesson_node_00008**.

# Evaluation

1.  **Inference Pipeline:**
    *   **Step 1:** Pass the test scan through Stage 1 to obtain ROI coordinates, Binary Masks, and Soft Anatomical Maps.
    *   **Step 2:** Extract high-resolution crops and pass them through Stage 2 to get Visual Feature Vectors.
    *   **Step 3:** Construct the sequence (Visual Features + Anatomical Maps) and feed it to the Stage 3 Bi-GRU.
    *   **Step 4:** The Bi-GRU generates 7 Vertebra Context Vectors via Soft Attention.
    *   **Step 5:** The Vertebrae Heads predict C1-C7 probabilities; the Patient Head predicts `patient_overall` from the concatenated context vectors.
