Implementation strategy:
1.  **Environment Setup**: Initialize the environment by setting the random seed and updating the system path to include the current directory for module imports.
2.  **Training Pipeline**: Sequentially execute the three stages of the pipeline using the provided `engine` module:
    *   **Stage 1 (Segmentation)**: Train the U-Net to localize vertebrae.
    *   **Stage 2 (Encoder)**: Train the 2.5D CNN to extract slice-level features.
    *   **Feature Extraction**: Process the entire dataset (Train, Val, Test) to generate feature vectors, caching them for the final stage.
    *   **Stage 3 (Aggregator)**: Train the Transformer to aggregate features and predict patient-level fractures.
3.  **Validation & Analysis**:
    *   Manually load the trained Stage 3 model and the validation dataset.
    *   Run inference on the validation set, ensuring data preprocessing (padding, anatomical ID masking) matches the training conditions (specifically setting anatomical IDs to zero as the training data loader defaults to this).
    *   Compute and print the **Final Validation Metric** using the weighted logarithmic loss.
    *   Perform **Failure Analysis** by calculating the correlation between the model's error magnitude (per-sample loss) and metadata features (number of slices, fracture count).
4.  **Conditional Submission**:
    *   Check if the validation metric is below the specified threshold (`0.9254394427010018`).
    *   If the condition is met, prepare a consistent inference cache for the test set (mapping features from the engine's output to the format expected by the inference pipeline, forcing anatomical IDs to zero to avoid out-of-distribution errors).
    *   Execute the `InferencePipeline` to generate the final `submission.csv`.
