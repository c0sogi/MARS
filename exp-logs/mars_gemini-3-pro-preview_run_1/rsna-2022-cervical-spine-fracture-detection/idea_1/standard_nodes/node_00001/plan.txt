The implementation strategy involves leveraging the pre-built library modules to execute a standard machine learning workflow: Training, Validation, Failure Analysis, and Inference.

1.  **Training**: We will invoke `library.train.run_training()`. This function automatically prepares a balanced dataset of fractured and healthy slices (approx. 1,200 total images based on the bounding box count), initializes the ResNet-18 model, and trains it for 10 epochs. This dataset size is small enough to ensure the "fast baseline" requirement is met (finishing in minutes on an A100).
2.  **Validation & Metric**: After training, we load the `best_model.pth` checkpoint. We run inference on the full validation set (aggregated by patient using max-pooling) to calculate the **Weighted Multi-label Logarithmic Loss**. This value is printed with high precision as required.
3.  **Failure Analysis**: We analyze the validation results by calculating the loss contribution of each patient. We then calculate the Pearson correlation between this error magnitude and the number of slices in the scan (a proxy for scan complexity/size) to identify if scan size affects performance.
4.  **Submission**: Finally, we call `library.inference.run_inference()` to generate predictions for the test set and save the `submission.csv` file.
