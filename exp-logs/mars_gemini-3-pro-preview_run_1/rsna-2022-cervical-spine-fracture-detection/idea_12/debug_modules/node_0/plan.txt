The following implementation demonstrates the full pipeline for the RSNA Cervical Spine Fracture Detection task using the provided library.

### Strategy Outline
1.  **Configuration Override**: We modify the global `Config` to point to a temporary working directory and reduce hyperparameters (epochs, batch sizes) for a rapid demonstration.
2.  **Data Subsetting**: We create "mini" versions of the metadata files (train, val, test) containing only a few samples. This ensures the training and inference loops complete quickly while still exercising the actual data loading logic. We specifically ensure the training subset includes studies with segmentation files for Stage 1.
3.  **Model Verification**: We instantiate each model (UNet, Encoder, Aggregator) and perform a dummy forward pass with random tensors to verify architecture and shape correctness.
4.  **Training Pipeline**: We initialize the `Trainer` and run all three stages sequentially:
    *   **Stage 1**: Train the UNet Localizer on the subset of segmented data.
    *   **Stage 2**: Train the Dual-Stream Encoder on slice-level data.
    *   **Feature Extraction**: Extract features for the subset using the trained Stage 1 & 2 models.
    *   **Stage 3**: Train the Sequence Aggregator on the extracted features.
5.  **Inference Pipeline**: We initialize the `InferencePipeline` and generate predictions for the mini test set.
6.  **Metric Validation**: We verify the weighted log loss calculation function.
