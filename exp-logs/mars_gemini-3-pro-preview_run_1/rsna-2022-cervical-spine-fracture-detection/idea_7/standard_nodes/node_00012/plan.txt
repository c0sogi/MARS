Implementation strategy:

1.  **Configuration & Setup**: Initialize the environment and override default configuration parameters (epochs, batch sizes) to ensure the pipeline runs efficiently within the 2-hour limit while utilizing the A100 GPU.
2.  **Pipeline Execution**:
    *   **Stage 1 (Segmentation)**: Train the U-Net model for global context and ROI localization.
    *   **Stage 2 (Encoder)**: Train the 2.5D CNN for local fracture detection on slice crops.
    *   **Feature Generation**: Run inference using Stage 1 and Stage 2 models on the training and validation sets to create feature sequences (embeddings + probabilities) required for Stage 3.
    *   **Stage 3 (Aggregator)**: Train the Bi-GRU model on the generated sequences to produce patient-level and vertebrae-level predictions.
3.  **Validation & Analysis**:
    *   Evaluate the trained Stage 3 model on the validation set.
    *   Compute the required weighted logarithmic loss metric.
    *   Perform failure analysis by correlating prediction error with metadata features (sequence length and fracture count).
4.  **Submission Logic**:
    *   Compare the validation metric against the specified threshold (0.9254394427010018).
    *   If the model performs well enough, generate features for the test set and run the full inference pipeline to create `submission.csv`.
