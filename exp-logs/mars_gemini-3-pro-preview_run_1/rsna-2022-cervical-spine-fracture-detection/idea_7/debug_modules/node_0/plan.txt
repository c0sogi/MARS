This script demonstrates the end-to-end pipeline for the RSNA Cervical Spine Fracture Detection task using the provided library files.

**Implementation Strategy:**
1.  **Configuration**: We modify the `Config` class to enable `DEBUG` mode, reduce the number of epochs to 1, and set small batch sizes. This ensures the entire pipeline runs quickly (within minutes) while exercising all code paths.
2.  **Model Verification**: We instantiate the models for all three stages (`SegmentationUNet`, `FractureEncoder`, `DualStreamRNN`) and perform a forward pass with dummy tensors to verify input/output shapes and architecture validity.
3.  **Training Pipeline**: We sequentially execute the training functions for Stage 1 (Segmentation), Stage 2 (Slice Classification), and Stage 3 (Sequence Aggregation). We assert that the respective checkpoints are created after each stage.
4.  **Feature Generation**: We invoke the feature generator to create the intermediate representations required for Stage 3, verifying that `.npy` files are produced.
5.  **Inference**: We run the inference pipeline on a small subset of the test data and verify that a valid `submission.csv` file is generated.
