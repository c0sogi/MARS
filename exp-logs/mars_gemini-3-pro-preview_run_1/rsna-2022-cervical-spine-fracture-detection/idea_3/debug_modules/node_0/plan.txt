The following script demonstrates the usage of the provided library components for the Cervical Spine Fracture Detection task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We start by importing the necessary modules and patching the `Config` class to ensure the demonstration runs quickly (reducing epochs, batch sizes, and enabling debug mode). We then initialize the environment.
2.  **Utility Verification**: We demonstrate the image processing pipeline (`process_dicom`, `apply_bone_window`) and the custom loss function (`calculate_weighted_loss`) using real data paths and dummy predictions.
3.  **Model Instantiation & Forward Pass**: We instantiate the three core models (`SpineLocalizer`, `SliceEncoder`, `SequenceAggregator`) and perform a forward pass with dummy tensors to verify input/output shapes.
4.  **Dataset Loading**: We demonstrate how to initialize the datasets (`SegmentationDataset`, `SliceClassificationDataset`, `FeatureSequenceDataset`). To save time, we filter the metadata to a single study or generate synthetic feature data where appropriate.
5.  **Training Simulation**: Instead of running full training epochs, we execute a single training step (forward + backward) for each model stage to verify the optimization pipeline.
6.  **Inference Pipeline**: We simulate the inference process on a single test study using the `predict_study` function logic, ensuring the end-to-end flow works.
