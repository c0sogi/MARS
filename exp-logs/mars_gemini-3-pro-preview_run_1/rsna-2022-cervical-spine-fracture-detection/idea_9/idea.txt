Based on the accumulated lessons and the evolution of previous ideas, I propose the **Dual-Stream Hierarchical Recurrent Network (DS-HRN)**. This solution integrates the high-resolution requirements for fracture detection, the global context needed for alignment injuries, and a robust, anatomically aware sequence aggregation strategy.

# Model

The architecture is a three-stage cascade designed to reconcile fine-grained detail with global spinal alignment, aggregated via a structured recurrent network.

1.  **Stage 1: Multi-Class Anatomical Localizer (2D U-Net)**
    *   **Purpose:** To provide spatial guidance and anatomical context.
    *   **Architecture:** A lightweight 2D U-Net trained on the segmentation subset.
    *   **Outputs per Slice:**
        1.  **ROI Coordinates:** Center-of-mass of the spinal column.
        2.  **Binary Bone Mask:** To guide the local encoder.
        3.  **Soft Anatomical Map:** A probability vector ($P_{C1}, ..., P_{C7}$) indicating the presence of specific vertebrae, preserving uncertainty at boundaries.

2.  **Stage 2: Dual-Branch Feature Encoder**
    *   **Innovation:** A dual-stream CNN that processes visual information at two scales, addressing the recommendation to use dual branches when global context is required **Cite solution_lesson_node_00002**.
    *   **Branch A (Local Stream):** Accepts **High-Resolution Crops** (e.g., 256x256) extracted from the *original* 512x512 images centered on the spine. It includes the Binary Bone Mask as a 4th channel. This branch focuses on high-frequency fracture details (hairline cracks) **Cite solution_lesson_node_00002**.
    *   **Branch B (Global Stream):** Accepts downsampled full-field-of-view slices (e.g., 256x256). This branch captures gross anatomical context, such as spinal alignment and dislocations, which might be normalized out in centered crops.
    *   **Fusion:** The outputs of both branches are concatenated to form a comprehensive **Slice Feature Vector**.

3.  **Stage 3: Hierarchical Anatomical Aggregator (Bi-GRU)**
    *   **Sequence Modeling:** A **Bidirectional GRU** processes the sequence of Slice Feature Vectors (concatenated with the Soft Anatomical Map) for the entire patient. We select a GRU over a Transformer due to the dataset size and the need for stability **Cite solution_lesson_node_00009**.
    *   **Soft Anatomical Pooling:** Instead of a single global pool, the model generates 7 distinct **Vertebra Context Vectors** ($V_{C1}, ..., V_{C7}$).
        *   $V_{Ck}$ is computed by aggregating the GRU hidden states weighted by the **Soft Anatomical Map** for class $k$ (from Stage 1) and a learned attention score. This ensures features for "C1" are derived from slices probabilistically identified as C1.
    *   **Hierarchical Heads:**
        *   **Vertebrae Heads:** 7 classifiers predict C1-C7 probabilities using $V_{C1}...V_{C7}$.
        *   **Patient Head:** A separate classifier predicts `patient_overall` using the **concatenation** of all context vectors ($[V_{C1}, ..., V_{C7}]$). This explicitly models the logical dependency of the metric **Cite solution_lesson_node_00008**.

# Data

1.  **Preprocessing:**
    *   **Windowing:** Apply "bone window" (Center: 400, Width: 1800) to all DICOMs.
    *   **Stage 1 Inference:** Run the U-Net on all data to generate ROI coordinates, Masks, and Anatomical Maps.
    *   **Dual-Resolution Extraction:**
        *   For the **Local Stream**, extract crops from the **original full-resolution** images **Cite solution_lesson_node_00002**.
        *   For the **Global Stream**, resize the full slice.

2.  **Labeling:**
    *   **Stage 2:** Use `train_bounding_boxes.csv` to generate binary slice-level targets (Fracture vs. Background) for the subset of data where they exist.
    *   **Stage 3:** Use `train.csv` for patient-level multi-label targets.

# Training

The training strategy is decoupled to prevent metric-induced noise amplification.

1.  **Phase 1 (Localizer):** Train the U-Net on the segmentation subset using Dice Loss + Cross Entropy.

2.  **Phase 2 (Encoder):** Train the Stage 2 Dual-Branch CNN on the slice-level bounding box targets.
    *   **Loss:** Use **Unweighted Binary Cross Entropy (BCE)**. We explicitly **do not** apply the competition's heavy `patient_overall` weights here. This forces the encoder to be conservative and precise, learning to detect fractures based on visual evidence rather than class bias **Cite solution_lesson_node_00005**.

3.  **Phase 3 (Aggregator):** Freeze the Stage 2 Encoder. Pre-compute feature sequences for all training patients. Train the Stage 3 Bi-GRU on these sequences.
    *   **Loss:** Use the **Weighted Multi-label Logarithmic Loss**. Since the RNN aggregates evidence across the volume and uses Anatomical Pooling to route signals, it can safely optimize the weighted metric without the risk of amplifying single-slice noise inherent to Max Pooling **Cite solution_lesson_node_00008**.

# Evaluation

1.  **Inference Pipeline:**
    *   **Step 1:** Pass the test scan through Stage 1 to obtain ROI coordinates, Masks, and Anatomical Maps.
    *   **Step 2:** Generate High-Res Crops (Local) and Downsampled Slices (Global).
    *   **Step 3:** Pass inputs through the Stage 2 Encoder to generate a sequence of fused features.
    *   **Step 4:** Pass the sequence to the Stage 3 Bi-GRU.
    *   **Step 5:** The Bi-GRU generates Vertebra Context Vectors via Soft Pooling.
    *   **Step 6:** The Hierarchical Heads output the final probabilities for C1-C7 and `patient_overall`.
