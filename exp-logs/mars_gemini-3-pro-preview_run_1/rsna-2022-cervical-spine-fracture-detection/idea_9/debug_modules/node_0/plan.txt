Implementation Strategy:
1.  **Configuration Setup**: I will subclass or modify the `Config` class at runtime to point to a temporary working directory (`./working/demo_run`) and reduce hyperparameters (epochs, batch sizes) to ensure the script runs quickly (1 epoch, batch size 2).
2.  **Data Subsetting**: I will load the provided metadata files, select a very small subset of samples (e.g., 2-4 studies, ensuring some have segmentations), and save these as "mini" metadata files. I will point the `Config` paths to these mini files. This ensures the data processing pipelines run on real data but finish almost instantly.
3.  **Model Verification**: I will instantiate the models for all three stages (`AnatomicalLocalizer`, `DualBranchEncoder`, `HierarchicalAggregator`) and perform a dummy forward pass with random tensors to assert that the input/output shapes are correct.
4.  **Pipeline Execution**: I will run the training loops (`Stage1Trainer`, `Stage2Trainer`, `Stage3Trainer`) using the mini datasets. This verifies the integration of data loading, processing, and model training.
5.  **Submission Generation**: I will run the `SubmissionGenerator` to verify the inference pipeline and output format.
6.  **Validation**: I will include assertions throughout to check for the existence of output files (checkpoints, cache, submission) and the validity of shapes/values.
