Implementation strategy:
1.  **Setup & Data Loading**: Initialize the environment using `Config.setup()`. Load the training, validation, and test metadata from the CSV files generated in the `./metadata` directory. Concatenate them into a single DataFrame for processing steps that apply to the entire dataset (mask generation and feature extraction).
2.  **Stage 1 (Segmentation)**: Execute `train_segmenter` to train the U-Net model on the training set. Then, run `generate_dataset_masks` on the combined dataset to create and cache segmentation masks for all scans.
3.  **Stage 2 (Slice Encoder)**: Execute `train_encoder` to train the 2.5D CNN on cropped slices using the generated masks. Follow this by running `extract_patient_features` on the combined dataset to convert image sequences into feature sequences.
4.  **Stage 3 (Sequence Aggregator)**: Execute `train_aggregator` to train the RNN model on the extracted feature sequences of the training set.
5.  **Validation & Metrics**: Load the trained aggregator model and run inference on the validation set in evaluation mode (using `torch.no_grad()` and GPU). Compute the `weighted_log_loss` using the provided utility function and print it as "Final Validation Metric".
6.  **Failure Analysis**: Calculate the average loss per patient in the validation set. Compute correlations between this error magnitude and metadata features (sequence length, presence of bounding boxes) to identify error sources.
7.  **Submission**: Compare the final validation metric against the threshold (0.9440845186799401). If the metric is lower (better), execute `predict_pipeline` to generate predictions for the test set and save the submission file.
