Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override settings to enable `DEBUG` mode, reduce batch sizes, set worker counts to 0 (for simple sequential execution), and limit epochs to 1. This ensures the pipeline runs rapidly for demonstration purposes.
2.  **Data Loading Verification**: Load the pre-generated metadata files. Instantiate the `SegmentationDataset` and `SliceClassificationDataset` to verify that data can be loaded, transformed, and returned in the correct shapes.
3.  **Model Architecture Verification**: Instantiate the three core models (`AnatomicalSegmentor`, `FractureEncoder`, `HCHRNAggregator`) with `pretrained=False` (to avoid network overhead during the shape check). Pass dummy tensors through them to validate input/output dimensions match the expected architecture.
4.  **Loss Function Verification**: Test the custom loss functions (`DiceBCELoss`, `CompetitionWeightedLoss`) with dummy predictions and targets to ensure numerical stability and correct shape handling.
5.  **Full Pipeline Execution**:
    *   Initialize the `FractureDetectionTrainer`.
    *   Run `train_segmentor` (Stage 1) on a small subset.
    *   Run `train_encoder` (Stage 2) on a small subset.
    *   Run `train_aggregator` (Stage 3). This step implicitly tests the feature extraction logic, which uses the trained Stage 1 and Stage 2 models to generate inputs for Stage 3.
6.  **Inference Pipeline**: Initialize and run the `InferencePipeline` on the test metadata to generate a `submission.csv`, verifying the end-to-end flow.
