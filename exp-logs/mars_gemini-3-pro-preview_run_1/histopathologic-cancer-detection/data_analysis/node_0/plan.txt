I will implement a robust EDA script for the Histopathologic Cancer Detection dataset.

**Strategy:**
1.  **Setup & Integrity**: I will set fixed random seeds and strictly use the provided `./metadata/train.csv` to ensure no data leakage from validation or test sets.
2.  **Target Analysis**: I will load the training metadata and compute the class balance (Tumor vs. No Tumor) to identify any imbalance that might require handling (e.g., weighted loss).
3.  **Image Analysis (Sampling)**:
    *   Since reading 140,000+ TIFF files can be I/O heavy, I will perform stratified sampling of 10,000 images. This provides statistically significant results while ensuring the script completes well within the 1-hour limit.
    *   I will use `cv2` to load images and extract:
        *   Dimensions (Height, Width).
        *   Channel counts.
        *   Pixel statistics (Mean and Std Dev per channel) to calculate global normalization constants.
4.  **Meta-Feature Extraction**:
    *   I will compute "Brightness" (mean pixel intensity) and "Contrast" (standard deviation of pixel intensity) for each image in the sample.
5.  **Relationship Analysis**:
    *   I will compare the distributions of Brightness and Contrast between positive and negative classes.
    *   I will calculate the Point-Biserial correlation between these meta-features and the binary target to see if simple image statistics are predictive.
6.  **Reporting**: The results will be printed in the specified format with clear headers and 4-decimal precision.
