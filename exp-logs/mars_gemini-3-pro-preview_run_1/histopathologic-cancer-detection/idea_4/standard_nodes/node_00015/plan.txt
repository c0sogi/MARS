Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Orchestration**: The script orchestrates the entire pipeline: data loading, model initialization, training, validation, failure analysis, and submission.
2.  **Training Loop**: Instead of using `library.train.run_training` (which doesn't return the metric needed for the conditional check), I import `train_one_epoch` and `validate` from `library.train` and reconstruct the training loop. This allows capturing the `best_auc` precisely for the threshold check.
3.  **Data Loading**: Uses `TumorDataset` and `DataLoader` from the library. I utilize the full dataset to ensure the high AUC threshold (0.9849) can be met, leveraging the A100 GPU for speed.
4.  **Failure Analysis**: After training, the best model is loaded. I iterate through the validation set to compute predictions and extraction image meta-features (brightness and contrast) from the tensors. I then calculate the correlation between the model's prediction error (`|pred - label|`) and these features.
5.  **Submission**: If the best validation AUC exceeds the strict threshold of `0.9849192531860572`, the `library.inference.run_inference` function is triggered to generate the submission file using Test Time Augmentation.
