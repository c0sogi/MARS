This script demonstrates the end-to-end usage of the provided machine learning library for digital pathology classification. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to use a temporary directory, reduce epochs, and limit batch sizes for a rapid execution demonstration.
2.  **Utility Verification**: Validates reproducibility (seeding) and metric calculation (AUC).
3.  **Data Pipeline Verification**: Instantiates the `PathologyDataset` and `DataLoader`, verifying image tensor shapes and label formats using a debug subset.
4.  **Model Architecture Verification**: Instantiates the modified DenseNet and ResNet models, checking that the custom stem (3x3 conv) is correctly applied and that the output dimensions are correct.
5.  **Training Loop Demonstration**: Runs the full training pipeline (`run_training`) on a tiny subset of data. This validates the `Trainer` class, loss calculation, backpropagation, and model saving.
6.  **Inference & Submission Demonstration**: Runs the inference pipeline (`run_inference`), which loads the trained models, performs Test Time Augmentation (TTA), and generates a submission CSV.
