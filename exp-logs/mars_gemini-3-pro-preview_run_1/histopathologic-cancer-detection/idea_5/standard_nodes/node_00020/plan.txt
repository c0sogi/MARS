The execution failed with a `torch.OutOfMemoryError` because the architectural modification to the model's stem (removing the initial downsampling to preserve resolution) significantly increased the memory required for storing activations (Cite debug_lesson_3). While the configuration was intended for a 40GB A100, the runtime environment reported only ~16GB of available GPU memory, causing the large batch size of 256 to exceed capacity.

To fix this, I will:
1.  **Reduce the Batch Size**: In `library/config.py`, I will lower `BATCH_SIZE` from 256 to 64. This is the primary fix to fit the larger activation maps within the available GPU memory.
2.  **Enable Automatic Mixed Precision (AMP)**: In `library/train.py`, I will implement `torch.cuda.amp.GradScaler` and `autocast`. This reduces the memory footprint of the model and activations, providing additional headroom and efficiency (Cite debug_lesson_3).
