Implementation strategy:
1.  **Configuration Override**: To ensure the code completes within the "fast baseline" time limit (2 hours) while maintaining high performance, I will override `Config.EPOCHS` to 5. This allows the model to converge sufficiently on the A100 GPU without running for the full 20 epochs originally planned.
2.  **Data Loading & Splitting**: I will load both the training and validation metadata files, concatenate them into a single dataset, and perform Stratified 5-Fold Cross-Validation. This aligns with the "Idea" to use the full dataset for training to maximize model capacity.
3.  **Model Training**: I will train a heterogeneous ensemble consisting of `densenet121` and `densenet169` on each of the 5 folds (10 models total). I will use the provided `EnsembleDenseNet` class (which includes GeM pooling and modified stems), `AdamW` optimizer, and `CosineAnnealingLR` scheduler. The best model from each fold (based on validation AUC) will be saved.
4.  **Validation Assessment**: I will generate Out-Of-Fold (OOF) predictions for the entire dataset. The final validation metric will be the AUC score calculated on these aggregated OOF predictions.
5.  **Failure Analysis**: I will compute the absolute error of the predictions on a subset of the data. I will then calculate the brightness and contrast of these images and compute the Pearson correlation between these features and the error magnitude to identify potential failure modes.
6.  **Submission Generation**: If the final validation AUC exceeds the threshold of 0.9849, I will load the test dataset and perform inference using Test Time Augmentation (TTA) with all 10 trained models. The predictions will be averaged and saved to `submission.csv`.
