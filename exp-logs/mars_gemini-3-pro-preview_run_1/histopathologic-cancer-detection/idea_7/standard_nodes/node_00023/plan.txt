The `CUDA out of memory` error is caused by an activation memory explosion due to the removal of downsampling in the DenseNet121 stem (stride 1 instead of 4) combined with a large batch size of 256. As noted in the error analysis, this increases the spatial dimensions of early feature maps by 16x. To fix this, I will reduce the `BATCH_SIZE` to 64 and implement Automatic Mixed Precision (AMP) training. This aligns with **Cite debug_lesson_3**, which recommends reducing batch size and using AMP when model strides are reduced.

Here are the edits:

1.  **`library/config.py`**: Reduce `BATCH_SIZE` from 256 to 64.
2.  **`library/engine.py`**: Update `train_one_epoch` and `fit` to use `torch.cuda.amp.GradScaler` and `autocast` for mixed precision training.

def train_one_epoch(model, train_loader, criterion, optimizer, scaler, device, epoch, logger):
    """
    Trains the model for one epoch using AMP.

    Args:
        model (nn.Module): The neural network model.
        train_loader (DataLoader): DataLoader for training data.
        criterion (nn.Module): Loss function.
        optimizer (Optimizer): Optimizer.
        scaler (GradScaler): Scaler for AMP.
        device (torch.device): Device to run training on.
        epoch (int): Current epoch number.
        logger (logging.Logger): Logger instance.

    Returns:
        float: Average loss for the epoch.
    """
    model.train()
    metric_monitor = MetricMonitor()

    # Label smoothing factor
    smoothing = Config.LABEL_SMOOTHING

    for batch_idx, data in enumerate(train_loader):
        images = data["image"].to(device, dtype=torch.float)
        targets = data["target"].to(device, dtype=torch.float)

        # Apply Label Smoothing manually for BCE
        # y_smooth = y * (1 - alpha) + 0.5 * alpha
        smoothed_targets = targets * (1 - smoothing) + 0.5 * smoothing

        optimizer.zero_grad()

        # Forward pass with AMP
        with torch.cuda.amp.autocast():
            # Model outputs logits of shape (Batch, 1)
            outputs = model(images).view(-1)
            loss = criterion(outputs, smoothed_targets)

        # Backward pass with AMP
        scaler.scale(loss).backward()
        scaler.step(optimizer)
        scaler.update()

        metric_monitor.update(loss.item(), images.size(0))

    return metric_monitor.avg
