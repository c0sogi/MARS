Implementation strategy for `runfile.py`:

1.  **Configuration & Setup**: Initialize the environment by setting random seeds and detecting the compute device (GPU). Override the global `Config` to enable "Fast Baseline" mode: reduce `EPOCHS` to 2 and set `DEBUG_SAMPLE_SIZE` to 2000. This ensures the script executes quickly as required.

2.  **Training Loop**: Iterate through the 5 folds defined in the configuration. For each fold, generate data loaders (which will be subsampled due to the debug config) and train the `DenseNet121GeM` model using the `engine.fit` function. This produces 5 trained model checkpoints.

3.  **Validation Assessment**: Reset `Config.DEBUG_SAMPLE_SIZE` to `None` to ensure evaluation is performed on the full dataset. Load the hold-out validation metadata (`val.csv`) and the fold definitions. Map each validation image to its assigned fold and perform Out-Of-Fold (OOF) inference: for each image, use the model trained on the fold where that image was in the validation set. This provides an unbiased performance metric. Calculate and print the `Final Validation Metric` (ROC AUC).

4.  **Failure Analysis**: During the validation inference loop, compute aggregate brightness and contrast statistics for the validation images. Calculate the Spearman correlation between these image statistics and the model's absolute prediction error. Print the correlations to identify if image quality issues (brightness/contrast) are associated with model failure.

5.  **Submission**: Compare the calculated validation AUC against the strict threshold (0.9849...). If the model performance exceeds the threshold, execute the `inference.run_inference` function to generate predictions for the entire test set and save the `submission.csv`.
