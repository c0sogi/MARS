Here is the implementation strategy for the `runfile.py` script:

1.  **Initialization**: Set random seeds for reproducibility and load the configuration from `library.config`.
2.  **Data Loading**: Use `library.data_loader.load_data` with `load_cached_data=True` to retrieve the training, validation, and test dataframes.
3.  **Model Execution**:
    *   Execute the Structural Branch (NBSVM) using `library.nbsvm_model.run_nbsvm`. This returns validation and test probabilities.
    *   Execute the Semantic Branch (Transformer) using `library.transformer_model.run_transformer`. This also returns validation and test probabilities.
4.  **Ensemble Optimization**:
    *   Perform a grid search for the blending weight $w$ (ranging from 0.0 to 1.0) that maximizes the AUC on the validation set.
    *   Formula: $P_{ensemble} = w \cdot P_{transformer} + (1-w) \cdot P_{nbsvm}$.
5.  **Validation & Reporting**:
    *   Calculate the final AUC using the optimal weight.
    *   Print the required metric string: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Compute the absolute error between predictions and ground truth labels on the validation set.
    *   Generate meta-features (character count, caps ratio) for the validation data.
    *   Calculate and print the correlation between these features and the model error to identify systematic weaknesses.
7.  **Submission**:
    *   Check if the final validation AUC exceeds the threshold `0.8992692939244664`.
    *   If passed, calculate the final test predictions using the optimized weight.
    *   Format the submission dataframe according to the sample file and save it to `./submission/submission.csv`.
