This omission causes an `AttributeError` at runtime.

To fix this, I will add the `SVD_COMPONENTS` variable to the `Config` class with a value of 128 (a standard default for this type of task and consistent with the file artifacts seen in the working directory). This enables the code in `nbsvm_model.py` to correctly namespace the cache artifacts by configuration (Cite debug_lesson_2), preventing collisions when hyperparameters change.
