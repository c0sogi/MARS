Based on the lessons learned from previous experiments, I propose the following optimized strategy. This solution introduces a **Gated Multi-Modal Fusion Architecture with Weighted Layer Pooling**. This design addresses the limitations of simple concatenation (Idea 4) and single-layer representations (Idea 3) by allowing the model to dynamically weigh the importance of structural features and leverage hierarchical semantic signals.

# Model
I propose a **Hybrid DeBERTa-v3 with Weighted Layer Pooling and Gated Structural Injection**.

1.  **Semantic Backbone (Hierarchical Representation)**:
    *   We will use **`microsoft/deberta-v3-base`** (Cite solution_lesson_node_00015).
    *   **Structural Innovation (Pooling)**: Instead of relying solely on the final layer's `[CLS]` token (which can miss lower-level morphological signals) or Mean Pooling (which dilutes trigger words, Cite solution_lesson_node_00008), we will implement **Weighted Layer Pooling**. We will extract the `[CLS]` embeddings from the **last four hidden layers** of the Transformer. These four embeddings will be combined using a learnable set of scalar weights (softmax-normalized). This allows the model to automatically select the optimal level of abstraction—balancing deep semantic context (top layer) with surface-level syntactic features (lower layers) where insults often reside.

2.  **Structural Branch (Normalized Statistical Features)**:
    *   We retain the **Multi-Granularity Feature** approach, extracting **Word N-grams (1-2)** and **Character N-grams (3-5)** (Cite solution_lesson_node_00012).
    *   These sparse features are projected to a 256-dimensional dense vector via **TruncatedSVD** and explicitly normalized using **Layer Normalization** (Cite solution_lesson_node_00016) to ensure compatibility with the Transformer embeddings.

3.  **Fusion Mechanism (Gated Injection)**:
    *   Instead of simple concatenation, we introduce a **Gated Linear Unit (GLU)** for fusion.
    *   The Normalized SVD vector ($V_{svd}$) is projected to the same dimension as the Transformer embedding ($V_{trans}$).
    *   A "Gate" vector $g$ is computed: $g = \sigma(W \cdot [V_{trans}; V_{svd}] + b)$, where $\sigma$ is the sigmoid function.
    *   The final fused representation is $V_{final} = V_{trans} + (g \odot V_{svd})$.
    *   This mechanism allows the network to dynamically "gate" the statistical features—utilizing them heavily when the text is obfuscated (and semantic confidence is low) or suppressing them when they represent noise, effectively solving the "Feature Space Dilution" risk (Cite solution_lesson_node_00004).

# Data
1.  **Text Preprocessing**: We will feed **raw, uncleaned text** to the DeBERTa tokenizer. We explicitly avoid manual unicode cleaning or unescaping, relying on the tokenizer's pre-trained robustness (Cite solution_lesson_node_00009).
2.  **Structural Feature Engineering**:
    *   Fit the TF-IDF vectorizers (Word 1-2, Char 3-5) and TruncatedSVD on the **training data only** to prevent data leakage.
    *   Transform both training and test data to generate the static SVD vectors.

# Training
The training procedure prioritizes robustness against the small dataset size and noisy labels.

1.  **Adversarial Weight Perturbation (AWP)**: We will integrate AWP into the training loop. By perturbing weights to maximize loss before the optimization step, we force the model to find a flat, stable minimum that generalizes better to unseen insults (Cite solution_lesson_node_00016).
2.  **Differential Learning Rates**: We will apply strict differential optimization (Cite solution_lesson_node_00015):
    *   **Backbone Layers**: $2 \times 10^{-5}$ (to preserve linguistic knowledge).
    *   **Pooling & Fusion Layers**: $1 \times 10^{-3}$ (to rapidly learn the new gating logic).
3.  **Loss Function**: Binary Cross-Entropy Loss.
4.  **Scheduler**: Linear decay with 5% warmup.

# Evaluation
1.  **Stratified Cross-Validation**: We will perform **Stratified 5-Fold Cross-Validation** (Cite solution_lesson_node_00016).
2.  **Inference**:
    *   For each fold, process the test text to generate Token IDs and SVD vectors.
    *   Pass inputs through the trained model (DeBERTa -> Weighted Pooling -> Gated Fusion -> Classifier).
    *   Average the probability scores across all 5 folds. This ensemble approach mitigates the variance inherent in training on small datasets (~3k samples).
