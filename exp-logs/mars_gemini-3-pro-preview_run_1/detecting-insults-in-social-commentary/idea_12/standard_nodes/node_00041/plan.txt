The following is the implementation of the `runfile.py` script for the Heterogeneous Mutual-Distillation Pipeline.

**Strategy Outline:**
1.  **Setup & Preprocessing**: Initialize configuration, set seeds, and load metadata. Compute/load SVD structural features and initialize DeBERTa and RoBERTa tokenizers.
2.  **Stage 1 (Teacher Training)**: Train "Teacher" ensembles (5-fold) for both DeBERTa (Stream A) and RoBERTa (Stream B) on the labeled training data. Aggregate their logits on the unlabeled test set.
3.  **Stage 2 (Soft Label Generation)**: Convert the aggregated test logits from both teachers into soft probability targets using temperature scaling ($T=2.0$). Construct augmented datasets for distillation: Student A learns from Teacher B's soft targets, and Student B learns from Teacher A's soft targets.
4.  **Stage 3 (Student Distillation)**: Train "Student" ensembles (5-fold) from scratch on the combined dataset (Labeled Train + Soft-Labeled Test). This cross-model distillation forces each model to learn from the complementary inductive biases of the other architecture.
5.  **Evaluation**: Aggregate predictions from both Student ensembles. Compute the final AUC on the hold-out validation set and perform failure analysis (correlation of errors with text features).
6.  **Submission**: If the validation AUC exceeds the threshold (0.96038...), generate the submission file using the aggregated student predictions.
