Based on the comprehensive analysis of previous experiments and the specific lessons learned, I propose the following optimized strategy. This solution introduces a **Heterogeneous Mutual-Distillation Pipeline**. This structural evolution addresses the limitations of Independent Stacking (Idea 11) and the failures of Self-Training (Idea 7) by implementing a **Cross-Architecture Knowledge Exchange** mechanism. This allows two diverse models to correct each other's blind spots on the unlabeled test data using soft targets, mitigating the confirmation bias observed in single-model pseudo-labeling.

# Model
I propose a **Dual-Stream Hybrid Architecture** consisting of two distinct, robust backbones that learn from each other.

1.  **Stream A: Hybrid DeBERTa-v3-Large**
    *   **Backbone**: `microsoft/deberta-v3-large`. Selected for its superior NLU performance and SentencePiece tokenization (Cite solution_lesson_node_00015).
    *   **Structural Fusion**: We retain the **Normalized SVD Fusion** architecture. The `[CLS]` token embedding is concatenated with a 256-dimensional **Layer-Normalized** vector derived from SVD-compressed Word (1-2) and Character (3-5) N-grams (Cite solution_lesson_node_00011, solution_lesson_node_00012, solution_lesson_node_00016).
    *   **Head**: The fused vector is passed through **Variable-Rate Multi-Sample Dropout (VR-MSD)** layers (Cite solution_lesson_node_00021) to a linear classifier.

2.  **Stream B: Hybrid RoBERTa-Large**
    *   **Backbone**: `roberta-large`. Selected to provide **architectural diversity**; its Byte-Level BPE tokenizer processes text differently than DeBERTa, offering orthogonal error patterns essential for effective ensembling (Cite solution_lesson_node_00022).
    *   **Structural Fusion**: Identical to Stream A (SVD-Fusion + LayerNorm) to ensure it benefits from robust morphological features against obfuscation (Cite solution_lesson_node_00002).

# Data
1.  **Text Preprocessing**: Feed **raw, uncleaned text** to both tokenizers. We explicitly avoid manual cleaning to preserve the "insult signals" found in noise (Cite solution_lesson_node_00009).
2.  **Structural Feature Engineering**:
    *   Fit TF-IDF vectorizers (Word 1-2, Char 3-5) and TruncatedSVD on the **Training Data only**.
    *   Transform Validation and Test data using these fitted operators to strictly prevent data leakage (Cite solution_lesson_node_00016).
3.  **Augmented Training Set**: For the distillation phase, the training set is augmented with the **Unlabeled Test Data**, which will be assigned Soft Targets.

# Training
The training procedure implements a **Cross-Architecture Mutual Distillation** strategy. This replaces the failed "Self-Training" (Idea 7) with a robust "Co-Teaching" approach.

**Stage 1: Independent Teacher Training**
*   Train **Stratified 5-Fold Ensembles** for both Stream A (DeBERTa) and Stream B (RoBERTa) on the labeled training data.
*   **Optimization**: Use **Adversarial Weight Perturbation (AWP)** (Cite solution_lesson_node_00016) and **Differential Learning Rates** ($1e^{-5}$ backbone, $1e^{-3}$ head) (Cite solution_lesson_node_00015).

**Stage 2: Cross-Model Soft-Label Generation**
*   **Teacher A (DeBERTa)** predicts logits for the Test Set. Apply **Temperature Scaling** ($T=2.0$) to generate softened probability distributions (Cite solution_lesson_node_00030).
*   **Teacher B (RoBERTa)** predicts logits for the Test Set, also Temperature-Scaled.

**Stage 3: Mutual Student Distillation**
*   **Train Student A (DeBERTa)** from scratch.
    *   **Loss**: On Labeled Data, use Ground Truth BCE. On Unlabeled Test Data, use BCE against **Teacher B's Soft Labels**.
    *   *Rationale*: DeBERTa learns from RoBERTa's perspective, forcing it to generalize beyond its own inductive biases and reducing confirmation bias.
*   **Train Student B (RoBERTa)** from scratch.
    *   **Loss**: On Labeled Data, use Ground Truth BCE. On Unlabeled Test Data, use BCE against **Teacher A's Soft Labels**.
*   **Regularization**: Continue to use AWP and VR-MSD on Students.

# Evaluation
1.  **Ensemble Inference**:
    *   Process the Test Set through the 5 folds of **Student A** and the 5 folds of **Student B**.
    *   Obtain 10 probability vectors.
2.  **Final Aggregation**:
    *   Average the predictions of Student A and Student B. This combines the benefits of architectural diversity with the robustness gained from mutual knowledge distillation.
