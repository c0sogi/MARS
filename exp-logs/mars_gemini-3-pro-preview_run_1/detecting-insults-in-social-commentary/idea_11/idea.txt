Based on the analysis of the previous experiments and the specific lessons learned, I propose the following optimized strategy. This solution introduces a **Heterogeneous Hybrid Stacking Architecture**. This structural evolution moves beyond the single-backbone paradigm (which hit a performance ceiling) and the failed semi-supervised attempts (MLM, Pseudo-Labeling) to explicitly target the "Tokenization Gap" and variance errors inherent in small-data insult detection.

# Model
I propose a **Heterogeneous Stacking Ensemble** composed of two distinct **Hybrid Transformer architectures**, unified by a linear meta-learner.

1.  **Hybrid Backbone A: DeBERTa-v3-Large**
    *   **Rationale**: We upgrade the backbone from "Base" to "Large" to leverage superior Natural Language Understanding capabilities (Cite solution_lesson_node_00015). DeBERTa-v3 uses a **SentencePiece** tokenizer, which is highly effective but can struggle with certain character-level obfuscations.
    *   **Structural Fusion**: We retain the successful **Normalized SVD Fusion** architecture. The `[CLS]` token embedding is concatenated with a **Layer-Normalized** dense vector derived from SVD-compressed N-grams (Cite solution_lesson_node_00011, solution_lesson_node_00016).
    *   **Head**: The fused vector is passed through **Variable-Rate Multi-Sample Dropout (VR-MSD)** layers (Cite solution_lesson_node_00021) before the final classifier.

2.  **Hybrid Backbone B: RoBERTa-Large**
    *   **Rationale**: While RoBERTa underperformed as a standalone model (Cite solution_lesson_node_00015), we re-introduce it here specifically for **Diversity**. RoBERTa uses **Byte-Level BPE** tokenization, which processes text differently than DeBERTa's SentencePiece. This diversity is critical for handling the "unique phrasing" and obfuscation noted in the task description, providing orthogonal error patterns that enhance ensembling (Cite solution_lesson_node_00022).
    *   **Structural Fusion**: Identical to Backbone A (SVD-Fusion + VR-MSD) to ensure it benefits from the robust morphological features (Cite solution_lesson_node_00012).

3.  **Meta-Learner**:
    *   A **Ridge Regression** (L2-regularized Linear Model) trained on the Out-Of-Fold (OOF) predictions from both backbones. This effectively learns the optimal weighted combination of the two tokenization paradigms.

# Data
1.  **Text Preprocessing**: We will feed **raw, uncleaned text** to both tokenizers. We explicitly avoid manual cleaning to preserve the "insult signals" found in noise (Cite solution_lesson_node_00009).
2.  **Structural Feature Engineering**:
    *   We generate a **Multi-Granularity Feature Matrix** using **Word N-grams (1-2)** and **Character N-grams (3-5)** (Cite solution_lesson_node_00012).
    *   We apply **TruncatedSVD** (256 components) to compress this matrix.
    *   **Strict Isolation**: To prevent data leakage, the TF-IDF and SVD transformers are fit **only on the training split** of each fold, and then applied to the validation/test splits (Cite solution_lesson_node_00016).

# Training
The training procedure prioritizes stability and robustness, strictly avoiding the pitfalls of semi-supervised learning on small data (Cite solution_lesson_node_00026, solution_lesson_node_00030).

1.  **Stratified 5-Fold Cross-Validation**: Both backbones will be trained on the same stratified folds to generate aligned OOF predictions.
2.  **Optimization Strategy**:
    *   **Adversarial Weight Perturbation (AWP)**: We apply AWP to both models to smooth the loss landscape and prevent overfitting to noisy labels (Cite solution_lesson_node_00016).
    *   **Differential Learning Rates**: We apply strict differential rates ($1 \times 10^{-5}$ for backbones, $1 \times 10^{-3}$ for fusion heads) to ensure proper convergence of the hybrid layers (Cite solution_lesson_node_00015).
3.  **Regularization**:
    *   **Variable-Rate Multi-Sample Dropout**: We apply increasing dropout rates (e.g., 0.1 to 0.5) in the classification heads to force the models to learn robust features (Cite solution_lesson_node_00021).

# Evaluation
1.  **OOF Generation**: For each of the 5 folds, generate probability predictions for the validation set from both Hybrid DeBERTa-Large and Hybrid RoBERTa-Large.
2.  **Stacking**: Train the Ridge Regression meta-learner on the concatenated OOF predictions against the ground truth labels.
3.  **Inference**:
    *   Process the Test Set through all 5 folds of both backbones (10 total inference passes).
    *   Average the predictions across folds for each backbone.
    *   Feed the averaged DeBERTa and RoBERTa predictions into the trained Meta-Learner to produce the final submission score.
