implementation strategy
The implementation follows a Heterogeneous Hybrid Stacking strategy. We begin by loading the metadata for training, validation (holdout), and test sets. To ensure robust structural features without data leakage, we combine the holdout and test texts and pass them to the SVD feature extractor, which fits only on the training fold data. We then execute a Stratified 5-Fold Cross-Validation loop. Inside each fold, we train two distinct hybrid models: one based on DeBERTa-v3-Large and another on RoBERTa-Large. Both models fuse their transformer embeddings with the SVD-derived dense vectors. We collect Out-Of-Fold (OOF) predictions for the training set and accumulate averaged predictions for the holdout and test sets.

After the CV loop, we employ a Ridge Regression meta-learner. This stacker is trained on the concatenated OOF predictions from both backbones to learn the optimal weighting. We then apply this meta-learner to the averaged holdout and test predictions. The final model is evaluated on the holdout set using the AUC metric. We perform a failure analysis by correlating errors with input features like character count and capitalization ratio. Finally, if the validation AUC exceeds the required threshold, we generate the submission file.
