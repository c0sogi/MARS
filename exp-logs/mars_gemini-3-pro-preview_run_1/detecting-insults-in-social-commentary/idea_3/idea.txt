To address the task of Insult Detection, I propose a **Hybrid DeBERTa-v3 Architecture with Structural Feature Fusion**. This strategy evolves the previous "Ensemble" approach (Idea 2) into a single, unified neural network. Instead of averaging predictions from a strong Transformer and a weak Linear model (which failed to fully utilize the structural features), this approach injects the robust morphological features directly into the Transformer's decision layer, allowing the model to learn non-linear interactions between deep semantic context and surface-level obfuscation patterns.

# Model
The architecture is a **Dual-Input Neural Network** composed of a Semantic Branch and a Structural Branch that fuse before the final classification.

1.  **Semantic Backbone (DeBERTa-v3)**:
    *   We replace the RoBERTa backbone with **DeBERTa-v3-base**. DeBERTa (Decoding-enhanced BERT with disentangled attention) generally outperforms RoBERTa on NLU tasks. This branch processes the input text to generate a deep contextual embedding.
    *   **Pooling Strategy**: We explicitly utilize the **`[CLS]` token embedding** for the classification signal. We reject Mean Pooling, as averaging embeddings dilutes the signal of specific "trigger" words in binary classification tasks (Cite solution_lesson_node_00008).

2.  **Structural Branch (Compressed Character N-grams)**:
    *   We retain the **Character N-gram** feature extraction (range 3-5) to preserve robustness against obfuscated profanity and typos (Cite solution_lesson_node_00002).
    *   Instead of training a separate Logistic Regression model, we transform these sparse TF-IDF features using **TruncatedSVD** (Singular Value Decomposition) to reduce them to a dense vector (e.g., 128 dimensions). This avoids the "Feature Space Dilution" associated with raw high-dimensional inputs (Cite solution_lesson_node_00004).

3.  **Feature Fusion Head**:
    *   The 768-dimensional `[CLS]` embedding from DeBERTa and the 128-dimensional structural vector are **concatenated** into a single tensor.
    *   This fused vector is passed through a custom classification head (Dropout -> Linear -> ReLU -> Linear -> Sigmoid). This allows the model to leverage the Transformer's semantic power (`solution_lesson_node_00007`) while explicitly conditioning on the robust morphological features that tokenizers might miss.

# Data
The data processing pipeline is designed to be minimal and robust:

1.  **Text Preprocessing**: We feed the **raw, uncleaned text** into the DeBERTa tokenizer. We explicitly avoid manual unescaping or unicode cleaning, relying on the pre-trained tokenizer's ability to handle noise and natural language artifacts (Cite solution_lesson_node_00009).
2.  **Feature Engineering**:
    *   **Input A**: Tokenized text (Input IDs, Attention Mask) for DeBERTa.
    *   **Input B**: Character N-grams (3-5) extracted via TF-IDF and compressed via SVD. We strictly avoid expanding to trigrams or character unigrams to prevent overfitting (Cite solution_lesson_node_00004).

# Training
The training procedure focuses on optimizing the fused architecture end-to-end:

1.  **Optimizer**: Use **AdamW** with a layer-wise learning rate decay (lower rates for the DeBERTa backbone, higher rates for the Fusion Head) to preserve pre-trained knowledge.
2.  **Loss Function**: Binary Cross-Entropy Loss.
3.  **Regularization**: Apply high dropout (e.g., 0.2) in the Fusion Head to prevent the model from over-relying on the SVD features, forcing it to integrate both semantic and structural signals.
4.  **SVD Pre-computation**: The TF-IDF and SVD transformation are fit on the training data once and applied to validation/test data to create static auxiliary inputs.

# Evaluation
1.  Process the test set text to generate Token IDs and SVD-compressed Character N-gram vectors.
2.  Pass these dual inputs through the trained Hybrid DeBERTa model.
3.  The model outputs a single probability score per sample, which is directly used for the submission. This eliminates the need for post-hoc ensemble weight tuning.
