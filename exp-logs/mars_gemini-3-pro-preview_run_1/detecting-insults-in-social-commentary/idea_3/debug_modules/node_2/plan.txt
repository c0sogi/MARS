The issue stems from Python's behavior where default arguments are evaluated at function definition time. Although `runfile.py` later patches `Config.SVD_COMPONENTS` to 8, the `StructuralFeatureExtractor` continues to use the stale default value of 128 when instantiated without arguments. This causes the generated features to have 128 dimensions instead of the expected 8, triggering the assertion error.
