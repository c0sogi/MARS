This script implements the end-to-end Self-Training Hybrid pipeline. It begins by loading the data and structural features, then executes a two-stage training process. In Stage 1 (Teacher), a 5-fold ensemble is trained on the labeled data to generate pseudo-labels for the test set. In Stage 2 (Student), the models are retrained on the combined labeled and pseudo-labeled data. The script calculates the final validation AUC using Out-Of-Fold predictions, performs failure analysis by correlating errors with input features, and generates a submission file if the performance threshold is met.
