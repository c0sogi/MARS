The following script demonstrates the usage of the provided library components for the Insult Detection task. It covers data loading, model instantiation, adversarial weight perturbation (AWP) verification, training loop execution, validation, inference, and pseudo-label generation.

The script is optimized for speed by using debug modes (truncating datasets), small batch sizes, and a single training epoch. It includes assertions to verify the correctness of shapes, data types, and logic flow. It also suppresses progress bars to comply with the silent execution requirement.
