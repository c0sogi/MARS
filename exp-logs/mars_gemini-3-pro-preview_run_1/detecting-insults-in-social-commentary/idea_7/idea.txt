Based on the lessons learned from the previous experiments, I propose the following optimized strategy. This solution introduces a **Self-Training Hybrid Architecture** (a multi-stage pipeline). This approach addresses the data scarcity issue—which motivated the failed MLM attempt (Idea 6)—by leveraging the test set through supervised pseudo-labeling rather than generic unsupervised pre-training.

# Model
I propose a **Robust Hybrid DeBERTa-v3 with Variable-Rate Multi-Sample Dropout**, deployed within a self-training loop.

1.  **Semantic Backbone**: We will utilize **`microsoft/deberta-v3-base`** (Cite solution_lesson_node_00015). We will extract the **`[CLS]` token embedding** for classification, as it outperforms Mean Pooling for trigger-word detection (Cite solution_lesson_node_00008).
2.  **Structural Branch**: We will retain the **Multi-Granularity Feature** approach, extracting both **Word N-grams (1-2)** and **Character N-grams (3-5)** (Cite solution_lesson_node_00012).
    *   These sparse features will be compressed to a 256-dimensional dense vector via **TruncatedSVD**.
    *   **Crucial Step**: We will apply **Layer Normalization** to this SVD vector before fusion to ensure scale compatibility with the Transformer embeddings (Cite solution_lesson_node_00016).
3.  **Fusion & Classification Head**:
    *   The `[CLS]` embedding and Normalized SVD vector are concatenated.
    *   We reject complex gating mechanisms (Cite solution_lesson_node_00019) and instead use **Variable-Rate Multi-Sample Dropout (VR-MSD)**. The fused vector is passed through multiple dropout layers with increasing rates (e.g., 0.1 to 0.5) to enforce generalization (Cite solution_lesson_node_00021).

# Data
The data pipeline prioritizes signal integrity and strict separation to prevent leakage.

1.  **Text Preprocessing**: We will feed **raw, uncleaned text** to the DeBERTa tokenizer, relying on its pre-trained robustness to handle noise (Cite solution_lesson_node_00009).
2.  **Structural Feature Engineering**:
    *   Fit the TF-IDF vectorizers and TruncatedSVD on the **Training Data only**.
    *   Transform the Validation and Test data using these fitted operators. This prevents the "Feature Space Dilution" and leakage observed in earlier iterations (Cite solution_lesson_node_00004, solution_lesson_node_00016).

# Training
The training procedure implements a **Two-Stage Self-Training Pipeline** to safely leverage the unlabeled test data.

**Stage 1: Teacher Training**
1.  Train a **Stratified 5-Fold Ensemble** on the labeled training data.
2.  **Optimization**:
    *   **Adversarial Weight Perturbation (AWP)**: Apply AWP to smooth the loss landscape and improve robustness against noisy labels (Cite solution_lesson_node_00016).
    *   **Differential Learning Rates**: Apply $2 \times 10^{-5}$ to the backbone and $1 \times 10^{-3}$ to the fusion head (Cite solution_lesson_node_00015).

**Stage 2: Pseudo-Labeling & Student Retraining**
1.  **Inference**: Use the Stage 1 ensemble to predict probabilities for the entire **Test Set**.
2.  **Filtering**: Select high-confidence test samples (e.g., predictions $>0.9$ or $<0.1$) to create a "Pseudo-Labeled" dataset. This avoids the pitfalls of generic MLM on small corpora (Cite solution_lesson_node_00026) by using task-specific signals.
3.  **Retraining**: Combine the original training data with the pseudo-labeled data. Retrain the **Stratified 5-Fold Ensemble** from scratch on this augmented dataset using the same robust hyperparameters (AWP, VR-MSD).

# Evaluation
1.  **Ensemble Inference**:
    *   For each of the 5 folds from the **Stage 2 (Student)** model, process the test set to generate Token IDs and SVD vectors.
    *   Pass inputs through the models to obtain probability scores.
    *   Average the scores across all 5 folds. This prioritizes the variance reduction of ensembling (Cite solution_lesson_node_00022) while benefiting from the augmented training distribution.
