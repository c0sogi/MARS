The implementation strategy follows the provided library structure to create a fast and effective baseline for insult detection.

1.  **Setup & Loading**: We initialize the environment with a fixed seed and load the datasets (train, validation, test) using `library.data_loader`. We utilize the full dataset size (~3,000 samples) as it is small enough for rapid training with Logistic Regression.
2.  **Feature Engineering**: We use `library.feature_engineering.extract_features` to transform raw text into a high-dimensional sparse matrix containing both word and character TF-IDF n-grams. This dual-granularity approach captures both semantic meaning and morphological obfuscations common in insults.
3.  **Modeling**: We instantiate and train the `InsultClassifier` (Logistic Regression) from `library.model`. We use class weighting to handle the imbalance.
4.  **Validation**: We evaluate the model on the validation set, printing the required `Final Validation Metric` (AUC).
5.  **Failure Analysis**: We analyze the errors by calculating the absolute difference between predictions and true labels. We then compute correlations between this error magnitude and (a) the length of the comments, and (b) the presence of the most heavily weighted features, to identify potential weaknesses.
6.  **Submission**: Finally, we generate probability predictions for the test set and save them using `library.utils.save_submission`.
