This script demonstrates the end-to-end workflow for the Glioblastoma subtype prediction task using the provided library files.

**Strategy:**
1.  **Configuration Override**: We dynamically modify the `library.config` parameters to point to a temporary working directory and reduce the dataset size (mini-batches), epochs, and worker threads. This ensures the demo runs quickly (within seconds/minutes) rather than hours.
2.  **Data Preparation**: We create "mini" versions of the training and validation metadata files containing only a few subjects. This allows us to verify the data loading and processing pipeline without processing the entire 400GB+ dataset.
3.  **Component Verification**:
    *   **Data Loader**: We manually invoke `process_dataset` to verify that DICOM images are correctly read, resized, and assembled into the 2.5D montage format. We assert output shapes.
    *   **Model**: We instantiate the `MontageEfficientNet`, pass a dummy tensor with the expected dimensions, and verify the output shape.
    *   **Training Loop**: We execute `train.run_training` using the mini-datasets. This acts as an integration test, verifying that the data loader, model, loss function, optimizer, and checkpointing logic work together correctly.
4.  **Checkpoint Validation**: Finally, we verify that the training loop successfully saved a model checkpoint and that it can be loaded back.
