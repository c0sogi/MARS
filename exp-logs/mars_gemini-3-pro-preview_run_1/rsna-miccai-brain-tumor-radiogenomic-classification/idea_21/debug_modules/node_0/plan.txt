This script demonstrates the end-to-end usage of the provided library components for the glioblastoma genetic subtype prediction task. It performs the following steps:

1.  **Setup**: Initializes the environment and random seeds.
2.  **Data Preparation**: Creates small subsets of the training, validation, and test metadata to ensure the demonstration runs quickly.
3.  **Data Loading**: Uses `process_dataset` to load MRI volumes for the subsets and wraps them in `SFWIVDataset` and `DataLoader`.
4.  **Model Initialization**: Instantiates the `SFWIVModel` (EfficientNet-B0 with 9-channel input) and verifies its architecture.
5.  **Training Loop**: Runs a single epoch of training and validation using the library's `train_one_epoch` and `validate` functions.
6.  **Inference**: Generates predictions on the test subset and formats the output as a submission file.
