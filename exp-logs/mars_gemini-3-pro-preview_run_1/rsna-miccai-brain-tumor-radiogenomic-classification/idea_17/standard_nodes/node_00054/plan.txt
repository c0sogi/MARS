Here is the implementation strategy for the `runfile.py` script:

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and detecting the available computation device (GPU/CPU).
2.  **Training**: Execute the training pipeline using the provided `run_training` function from `library.train`. This handles data loading, model initialization, the training loop with early stopping, and saving the best model checkpoint.
3.  **Validation & Aggregation**:
    *   Load the best saved model.
    *   Run inference on the hold-out validation set.
    *   Since the dataset generates 3 anatomical slabs per patient, aggregate these predictions by calculating the mean probability per subject.
    *   Compute and print the **Final Validation Metric** (ROC AUC) on these aggregated patient-level scores.
4.  **Failure Analysis**:
    *   Calculate the absolute error between the aggregated predictions and the ground truth.
    *   Extract a simple metadata feature (FLAIR file count) for each validation subject as a proxy for scan depth/quality.
    *   Compute and print the correlation between the prediction error and this feature to identify potential failure modes.
5.  **Submission**:
    *   Compare the validation AUC against the specified threshold (`0.6705454545454544`).
    *   If the threshold is met, run inference on the test set, aggregate predictions per subject, and save the results to `./submission/submission.csv`.
