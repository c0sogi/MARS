The issue is caused by inconsistent spatial dimensions among the image channels being stacked. DICOM images from different modalities (or even within the same modality) can have varying resolutions (e.g., 512x512 vs 256x256), and the fallback for missing files is a fixed 224x224 zero array. Since `np.stack` requires all input arrays to have identical shapes, this mismatch triggers a `ValueError`. The fix is to explicitly resize every loaded image to the target `Config.IMG_SIZE` immediately after normalization and before stacking, ensuring all channels are uniform.
