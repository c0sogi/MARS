The implementation strategy involves the following steps:

1.  **Configuration Override**: Modify the global `Config` class attributes to adapt the pipeline for a quick demonstration. This includes setting a temporary working directory, reducing the image size to 128x128, disabling multiprocessing (num_workers=0) to avoid overhead, and setting `EPOCHS=1` with a small `BATCH_SIZE`.
2.  **Setup**: Initialize the environment and random seeds using `seed_everything` to ensure reproducibility.
3.  **Data Loading & Verification**: Instantiate the `BraTSDataset` for training and validation with a `debug_limit` to load only a small subset of data. Create PyTorch `DataLoader` instances. Verify the shape of the produced tensors to ensure the 2.5D Siamese structure (Batch, Views, Channels, Height, Width) is correct.
4.  **Model Initialization & Verification**: Instantiate the `SiameseEfficientNet` model. Perform a forward pass with a dummy batch derived from the dataloader to verify the architecture and output dimensions (Batch, 1).
5.  **Training Execution**: Execute the `run_training` function from the engine module. This will train the model for one epoch on the subset and save the weights. Verify that the model file is created.
6.  **Inference Execution**: Instantiate the test dataset (subset) and run `predict_and_submit`. Verify that the submission CSV is generated and follows the correct format.
7.  **Assertions**: Throughout the script, assertions are used to validate data shapes, file existence, and logical flow.
