Implementation Strategy:
1.  **Setup & Data Loading**: Initialize the environment with fixed seeds for reproducibility. Load the pre-processed metadata dataframes (Train, Validation, Test) using the `generate_roi_cache` function from the provided library. The "Train" metadata will be used for 5-Fold Cross-Validation, while the "Validation" metadata serves as the fixed hold-out set for final metric reporting.
2.  **5-Fold Cross-Validation**: Implement a loop using `StratifiedKFold`. For each fold:
    *   Split the training metadata into fold-specific train and validation sets.
    *   Instantiate `BraTSDataset` and `DataLoader` for both.
    *   Initialize the `Trainer` (which creates a fresh `VRAWIVModel`).
    *   Train the model using `trainer.fit()`.
    *   Rename and save the best model checkpoint for the fold to avoid overwriting.
3.  **Ensemble Validation**: Load the fixed hold-out validation set. Iterate through the 5 saved fold models, generate predictions for the hold-out set, and average them (ensemble). Compute the ROC AUC score and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**: Calculate the absolute error between the ensemble predictions and the ground truth on the hold-out set. Compute and print the correlation of this error with the target label (to detect class bias) and the Subject ID (to detect temporal/site bias).
5.  **Submission**: Check if the final validation metric exceeds the threshold (0.6705...). If so, generate predictions for the Test set using the ensemble of 5 models, format the output according to the sample submission, and save it to `./submission/submission.csv`.
