# Spatially-Decomposed Consensus (SDC) Network

This solution introduces a **Structural Innovation** by decomposing the volumetric classification problem into a **Spatially-Stratified Ensemble**. Instead of struggling to cram volumetric context into a single 2D network (which violates spatial congruence, Cite solution_lesson_node_00106) or using 3D architectures (which fail due to data scarcity, Cite solution_lesson_node_00008), we train distinct "Expert" models specialized for specific anatomical planes. This is coupled with **Independent Content-Based Anchoring** to solve the alignment and "Middle Slice" failures.

### Model
*   **Architecture:** We utilize an ensemble of **three independent EfficientNet-B0** models.
    *   **Expert A (Lower):** Specialized for the anatomical plane at **-10%** relative to the Brain Center of Mass (CoM).
    *   **Expert B (Center):** Specialized for the **Brain CoM** plane.
    *   **Expert C (Upper):** Specialized for the anatomical plane at **+10%** relative to the Brain CoM.
*   **Input Structure:** Each expert receives a standard **3-channel** 2D input $(224 \times 224 \times 3)$ comprising **[FLAIR, T1wCE, T2w]** at its designated depth.
    *   *Rationale:* This adheres to **Early Fusion** for modalities (Cite solution_lesson_node_00031) while strictly respecting **Spatial Congruence** (Cite solution_lesson_node_00106). By training separate models, we avoid the "Subject Identity Overfitting" caused by mixing correlated views in a single training loop (Cite solution_lesson_node_00058) and the "Signal Dilution" of Siamese pooling (Cite solution_lesson_node_00018).

### Data
The pipeline employs **Independent Content-Based Anchoring** and **Strict Integrity Verification**.

1.  **Independent Anatomical Anchoring:**
    *   For **each modality independently**, we load the volume and threshold pixels $>0$ to identify the brain tissue. We calculate the **Z-axis Center of Mass (CoM)** and the **Brain Depth** (max - min index).
    *   We extract slices at relative offsets: $CoM - 0.1 \times Depth$, $CoM$, and $CoM + 0.1 \times Depth$.
    *   *Benefit:* This anchors sampling to the biological center, solving the "Middle Slice Fallacy" (Cite solution_lesson_node_00002). Calculating indices independently for each modality handles varying Fields-of-View without the misalignment errors of cross-modality projection (Cite solution_lesson_node_00036).
2.  **High-Fidelity Preprocessing:**
    *   **Precision:** Use **float32** to preserve the 12-16 bit dynamic range (Cite solution_lesson_node_00016).
    *   **Normalization:** Apply **Independent Channel Min-Max Scaling** to $[0, 1]$ *before* stacking. This prevents high-intensity modalities from suppressing low-intensity ones (Cite solution_lesson_node_00023). We avoid ImageNet mean/std normalization (Cite solution_lesson_node_00017).
3.  **Integrity Check:** We implement a strict assertion that the dataset length matches the expected subject count (~523) and that CoM metadata is successfully computed. We explicitly **remove legacy fallback logic** to prevent silent pipeline failures (Cite solution_lesson_node_00092, solution_lesson_node_00071).

### Training
*   **Procedure:** Train the three Expert models independently.
*   **Loss Function:** Binary Cross-Entropy (BCE) with Logits.
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Aggressive Weight Decay:** Set to **$1e-2$** to prevent overfitting on the small dataset (Cite solution_lesson_node_00010).
    *   **Dropout:** Enforce a rate of **0.3** (Cite solution_lesson_node_00044).
*   **Spatially-Coupled Augmentation:**
    *   Apply **Elastic Transformations**, **Grid Distortions**, **Rotations**, and **Flips**.
    *   **Strictly Exclude:** Random Translations (Shift) and Scaling. Since we are using CoM Anchoring, the tumor is spatially localized relative to the frame. Translation augmentation destroys this strong spatial prior and degrades performance (Cite solution_lesson_node_00065, solution_lesson_node_00102).
*   **Strategy:** **5-Fold Cross-Validation** grouped by Subject ID. This ensures the training set size (~418 subjects) remains above the critical mass required for generalization (Cite solution_lesson_node_00051).

### Evaluation
*   **Inference:** For each test subject, calculate the Independent CoM per modality and deterministically generate the three inputs (Lower, Center, Upper).
*   **Prediction:** Pass each input to its corresponding Expert model (A, B, C).
*   **Consensus:** Average the probabilities from the three experts (and across their 5 folds). This leverages volumetric coverage to detect off-center tumors without the complexity or memory cost of 3D architectures (Cite solution_lesson_node_00008).
