Implementation Strategy:
The solution implements the Spatially-Decomposed Consensus (SDC) pipeline. It proceeds in four main stages:
1.  **Training (5-Fold CV)**: We iterate through three spatial experts (Lower, Center, Upper). For each expert, we load the training data defined in `train_metadata.csv` and perform 5-Fold Stratified Cross-Validation. This results in 15 trained `EfficientNet-B0` models (3 experts × 5 folds), which are saved to the working directory. We leverage the provided `library` modules for data loading, augmentation, and training orchestration.
2.  **Validation (Ensemble Inference)**: We load the hold-out validation set (`val_metadata.csv`). We generate predictions for every subject using all 15 models. The final prediction is the unweighted average of these probabilities. We compute the Area Under the ROC Curve (AUC) and print it as the `Final Validation Metric`.
3.  **Failure Analysis**: We analyze the model's performance on the validation set by calculating the absolute error for each subject. We then verify if the error correlates with specific input characteristics, specifically the mean pixel intensity of the center-slice images, to detect potential sensitivity to image brightness or acquisition differences.
4.  **Submission**: If the validation AUC exceeds the specified threshold (0.6705), we proceed to the test phase. We load the test data (`test_metadata.csv`), generate ensemble predictions using the same 15 models, and generate the `submission.csv` file in the required format.
