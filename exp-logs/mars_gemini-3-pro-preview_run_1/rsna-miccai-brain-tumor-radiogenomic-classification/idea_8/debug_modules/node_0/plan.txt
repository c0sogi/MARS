This script demonstrates the end-to-end usage of the provided library components for the Glioblastoma genetic subtype prediction task. It first overrides the default configuration to ensure rapid execution (using a subset of data and fewer epochs). It then systematically validates the utility functions, dataset loading, and model architecture through unit tests and assertions. Finally, it executes the full training and inference pipeline using the `run_training` function and verifies the generation of a valid submission file.
