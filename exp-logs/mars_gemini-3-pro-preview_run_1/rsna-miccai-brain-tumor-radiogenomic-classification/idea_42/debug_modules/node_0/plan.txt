This script demonstrates the end-to-end usage of the provided library modules for the glioblastoma genetic subtype prediction task. To ensure the demonstration executes quickly (within the time limit) while verifying all logic, the script performs the following steps:

1.  **Configuration Override**: It creates a "mini" dataset by sampling a small subset (10 subjects) of the provided metadata and saving it to the working directory. It then updates the `config` paths to point to these mini-datasets, ensuring the heavy DICOM processing step finishes rapidly.
2.  **Preprocessing Verification**: It calls the preprocessing pipeline to load DICOMs, crop ROIs, and normalize images, asserting that the output data shapes are correct.
3.  **Dataset & DataLoader Verification**: It instantiates the custom PyTorch Dataset and DataLoader, fetching a batch to verify tensor shapes and data types.
4.  **Model Architecture Check**: It initializes the `MGMTNet` (EfficientNet-B0 backbone) and performs a forward pass with dummy data to confirm the output dimensions.
5.  **Training Pipeline**: It executes a 2-fold cross-validation training loop for 1 epoch using the mini-dataset. This verifies the training logic, loss calculation, backpropagation, and model checkpointing.
6.  **Inference & Submission**: It runs the inference pipeline using the trained models to generate a submission file, verifying the output format.
