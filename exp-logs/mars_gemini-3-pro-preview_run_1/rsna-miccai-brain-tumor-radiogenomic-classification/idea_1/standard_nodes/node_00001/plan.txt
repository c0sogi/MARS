Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class and set random seeds for reproducibility.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. We will slightly reduce the number of epochs to 10 to ensure the "fast baseline" requirement is met while still allowing convergence on this small dataset.
3.  **Validation & Metric Calculation**:
    *   Load the best saved model checkpoint.
    *   Run inference on the validation set using the `MGMTDataset` and `DataLoader`.
    *   Compute the Area Under the ROC Curve (AUC) and print it in the specific format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample (`|predicted_prob - actual_label|`).
    *   Extract metadata features (file counts and average file sizes) for the validation subjects by inspecting the file system.
    *   Compute and print the Pearson correlation between these metadata features and the model's prediction error to identify potential sources of bias or failure (e.g., does the model fail more on scans with fewer slices?).
5.  **Submission**: Use `library.predict.generate_submission` to generate predictions for the test set and save the `submission.csv` file.
