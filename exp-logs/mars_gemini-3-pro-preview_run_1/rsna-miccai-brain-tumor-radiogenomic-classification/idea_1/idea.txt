To establish a robust and highly efficient baseline for predicting MGMT promoter methylation, I propose a **2.5D Multi-Modal Stacking Network**. This approach leverages the power of transfer learning from 2D natural image recognition while incorporating the multi-contrast nature of MRI data, without the computational overhead of full 3D volumetric processing or complex sequence modeling.

### Model
The core architecture is a standard **2D Convolutional Neural Network (CNN)**, specifically utilizing a lightweight backbone such as **EfficientNet-B0** or **ResNet-18**.
*   **Input Representation:** Instead of treating the MRI as a 3D volume or a sequence of slices, the model treats the data as a single "RGB-like" composite image. The network accepts a 3-channel input tensor of shape $(H, W, 3)$.
    *   **Channel 1:** The central slice of the **FLAIR** modality (captures edema/fluid).
    *   **Channel 2:** The central slice of the **T1wCE** modality (captures active tumor/contrast enhancement).
    *   **Channel 3:** The central slice of the **T2w** modality (captures structural abnormalities).
*   **Backbone & Head:** The 3-channel input is processed by the pretrained CNN backbone to extract spatial features. A Global Average Pooling layer condenses the feature maps into a single vector, which is passed to a simple fully connected output layer with a sigmoid activation to predict the probability of MGMT methylation.

### Data
The data preprocessing pipeline focuses on rapid dimensionality reduction by selecting the most informative 2D plane:
1.  **Slice Selection:** For each subject and each of the three chosen modalities (FLAIR, T1wCE, T2w), identify the file list, sort by instance number, and select the **middle slice** (median index). This relies on the heuristic that the brain and tumor bulk are generally centered in the scan volume.
2.  **Image Loading & Normalization:** Load the pixel data for the three selected slices. Apply Min-Max normalization to scale pixel intensities to the range $[0, 1]$ for each slice independently.
3.  **Resizing & Stacking:** Resize each slice to a standard resolution (e.g., $224 \times 224$ or $256 \times 256$). Stack the three slices along the channel dimension to form the final $(224, 224, 3)$ composite image.
4.  **Handling Missing Data:** If a modality is missing for a subject (rare, but possible), replace that channel with a zero-filled array to maintain the input structure.

### Training
The training procedure prioritizes stability and speed:
*   **Loss Function:** Use **Binary Cross-Entropy with Logits Loss** to optimize the classification objective.
*   **Optimizer:** Employ **AdamW** with a default learning rate (e.g., $1e-4$) and a small weight decay to prevent overfitting.
*   **Augmentation:** Apply light, computationally inexpensive 2D augmentations on the composite image, such as random horizontal flips and small rotations ($\pm 15^\circ$). This encourages the model to learn rotation-invariant features without distorting the anatomical structure too heavily.
*   **Strategy:** Train for a fixed number of epochs (e.g., 10-20) with Early Stopping based on validation AUC. Use a standard batch size (e.g., 32 or 64) that fits comfortably in GPU memory.

### Evaluation
For the test set, the process is a direct feed-forward pass:
1.  **Preprocessing:** Generate the 2.5D composite image for each test subject using the same "middle slice" logic and normalization parameters as the training set.
2.  **Inference:** Pass the composite image through the trained model to obtain the raw logit.
3.  **Prediction:** Apply the sigmoid function to the logit to produce the final probability score for the `MGMT_value`.
4.  **Submission:** Map these probabilities to the corresponding `BraTS21ID` and format the CSV for submission.
