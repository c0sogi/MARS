The following code demonstrates the complete pipeline for the Glioblastoma genetic subtype prediction task using the provided library files. It performs the following steps:

1.  **Data Subsetting**: Creates temporary "mini" metadata files from the original dataset to ensure the demonstration runs quickly (using only a few samples).
2.  **Configuration Override**: Modifies the global `Config` to point to these mini datasets and adjusts hyperparameters (epochs, batch size) for speed.
3.  **Component Verification**:
    *   **Utils**: Verifies seed setting and slice loading logic.
    *   **Dataset**: Instantiates the `MGMTDataset`, verifies data loading, shape consistency, and transformation pipelines.
    *   **Model**: Instantiates the `MGMTClassifier`, performs a dummy forward pass, and verifies output dimensions.
4.  **Training Loop**: Executes `run_training` on the subset, verifying that the training process completes and saves a model checkpoint.
5.  **Inference**: Executes `generate_submission` using the trained model, verifying the output format and content of the submission file.
