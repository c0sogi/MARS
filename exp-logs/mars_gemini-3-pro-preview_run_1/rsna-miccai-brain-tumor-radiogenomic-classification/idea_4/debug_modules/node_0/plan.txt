The following script demonstrates the end-to-end usage of the provided library files for the Glioblastoma MGMT Promoter Methylation Prediction task.

**Implementation Strategy:**
1.  **Configuration Overrides**: We patch the `Config` class to run in "Debug" mode with minimal resources (1 epoch, small batch size, small image resolution, disabled pretrained weights) to ensure the script completes quickly (within minutes) and requires no internet access.
2.  **Utility & Data Verification**: We explicitly test the `read_dicom` function and the `get_dataloaders` pipeline, asserting that the data shapes for both training (2D slices) and testing (Volumetric/2.5D stacks) are correct.
3.  **Model Verification**: We instantiate the `MGMTNet` model and perform a forward pass with real data from the loader to confirm the architecture produces the expected logit shapes.
4.  **Engine Execution**: We execute the full `engine.run()` loop, which handles training, validation, and inference.
5.  **Result Validation**: Finally, we verify that the submission file is created and adheres to the required format.
