# Anatomically-Centric Weight-Inflated Volumetric (AC-WIV) Network

This solution introduces a **Structural Innovation** in both **Data Sampling** and **Network Initialization**. It moves beyond the "File-Index Heuristics" (which fail on off-center scans, Cite solution_lesson_node_00002) to **"Anatomical Centroid Alignment"**, and refines the "Thick Slab" architecture with **Gaussian Weight Inflation** to preserve the strong "Middle Slice" prior while enabling volumetric learning.

### Model
*   **Backbone:** We utilize **EfficientNet-B0**. This architecture is retained for its parameter efficiency and proven stability on this dataset (Cite solution_lesson_node_00002).
*   **Input Structure:** The network accepts a **9-channel** input tensor $(224 \times 224 \times 9)$, employing **Early Fusion** (Cite solution_lesson_node_00031) to capture cross-modality and cross-depth correlations immediately.
    *   **Channels 0-2:** [FLAIR, T1wCE, T2w] at **Anatomical Depth $z-\delta$**.
    *   **Channels 3-5:** [FLAIR, T1wCE, T2w] at **Anatomical Depth $z$** (Centroid).
    *   **Channels 6-8:** [FLAIR, T1wCE, T2w] at **Anatomical Depth $z+\delta$**.
*   **Innovation: Gaussian Weight Inflation:**
    *   To utilize 9 channels without destroying ImageNet priors (Cite solution_lesson_node_00009) or using unstable learnable adapters (Cite solution_lesson_node_00025), we mathematically adapt the backbone's first convolutional layer weights $W_{rgb}$.
    *   Instead of uniform distribution, we initialize with a **Center-Biased (Gaussian) Prior**.
        *   **Center Slices (Channels 3-5):** Receive **50%** of the original weight energy ($0.5 \times W_{rgb}$). This ensures the model behaves similarly to the strong "Middle Slice" baseline (Cite solution_lesson_node_00002) at epoch 0.
        *   **Peripheral Slices (Channels 0-2, 6-8):** Receive **25%** of the weight energy ($0.25 \times W_{rgb}$). This allows the model to gradually integrate volumetric context during training without starting from a high-entropy state.

### Data
The pipeline employs **Per-Modality Centroid Alignment** and **Strided Volumetric Packing**.

1.  **Anatomical Centroid Alignment:**
    *   Instead of the "Median File Index" (which fails on neck/skull artifacts, Cite solution_lesson_node_00002), we compute the **Z-axis Center of Mass** of the brain tissue.
    *   For **each modality independently**, we threshold pixels $>0$ to define the Brain ROI and calculate its geometric centroid index $C$. This handles varying Fields-of-View without misalignment (Cite solution_lesson_node_00036).
2.  **Strided Volumetric Packing:**
    *   We define a stride $\delta = 5$ slices.
    *   We extract slices at $C-\delta$, $C$, and $C+\delta$ for each modality.
    *   **Crucially**, we stack these into a single 9-channel tensor per subject. We **do not** split them into independent samples, avoiding the "Subject Identity Overfitting" observed when correlated views are treated as i.i.d. (Cite solution_lesson_node_00058).
3.  **High-Fidelity Preprocessing:**
    *   **Precision:** All operations use **float32** to preserve the MRI dynamic range (Cite solution_lesson_node_00016).
    *   **Normalization:** We apply **Independent Channel Min-Max Scaling** to $[0, 1]$ *before* stacking. This prevents high-intensity modalities from suppressing low-intensity ones (Cite solution_lesson_node_00023). We avoid ImageNet mean/std normalization (Cite solution_lesson_node_00017).

### Training
*   **Loss Function:** Binary Cross-Entropy (BCE) with Logits.
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Aggressive Weight Decay:** Set to **$1e-2$** to prevent overfitting given the increased input dimensionality (Cite solution_lesson_node_00010).
    *   **Dropout:** Enforce a rate of **0.3** in the classifier (Cite solution_lesson_node_00044).
*   **Corrective Augmentation:**
    *   We apply **Elastic Transformations**, **Grid Distortions**, and **Rotations**.
    *   **Strictly Exclude:** Random Translations (Shift) and Scaling. Since we are using Anatomical Centroid alignment, the tumor location is spatially anchored; translation augmentation destroys this strong spatial prior (Cite solution_lesson_node_00065).
*   **Strategy:** **5-Fold Cross-Validation** grouped by **Subject ID** (Cite solution_lesson_node_00028).

### Evaluation
*   **Inference:** For each test subject, calculate the Per-Modality Centroid $C$ and deterministically generate the 9-channel input ($C-\delta, C, C+\delta$).
*   **Prediction:** Pass the tensor through the AC-WIV network.
*   **Submission:** Average the probabilities from the 5 fold models. This leverages the robustness of the volumetric context without the need for stochastic test-time ensembles (Cite solution_lesson_node_00015).
