### Implementation Strategy

1.  **Configuration Override**: We will modify the global `library.config` parameters to adapt the workflow for a quick demonstration. This includes reducing the number of epochs to 1, setting the number of cross-validation folds to 2, disabling pretrained weight downloads (to ensure offline compatibility and speed), and pointing the data paths to a smaller subset of the metadata.
2.  **Mini-Dataset Creation**: We will generate temporary "mini" metadata CSV files by sampling the first few rows of the provided full metadata files. This ensures the data loading and preprocessing steps (DICOM reading, resizing) complete in seconds rather than minutes.
3.  **Component Verification**:
    *   **Data Loader**: We will instantiate the training loader and verify the batch dimensions match the expected shape `(Batch, Channels, Height, Width)`.
    *   **Model**: We will instantiate the `ACWIVNet` model and perform a forward pass with a dummy batch to confirm the output shape is `(Batch, 1)`.
4.  **Full Pipeline Execution**:
    *   **Training**: We will execute the `train_all_folds()` function to simulate the training process. This will generate model checkpoints in the working directory.
    *   **Inference**: We will execute the `predict()` function, which loads the generated checkpoints and creates a submission file for the test set.
5.  **Validation**: Throughout the script, assertions will be used to validate shapes, file existence, and logical consistency.
