This script performs an Exploratory Data Analysis (EDA) on the BraTS21 dataset. Since the primary data modality is 3D MRI scans (DICOM files) but the installed packages list does not explicitly include `pydicom` (the standard library for reading DICOMs), the analysis adopts a robust strategy:

1.  **Target Analysis**: Analyzes the distribution of the `MGMT_value` labels.
2.  **Metadata Extraction (Image Proxy)**: Instead of relying solely on pixel data (which might be inaccessible without specific libraries), it iterates through the file system to extract "meta-features" for every subject:
    *   **Slice Counts**: The number of images per modality (FLAIR, T1w, T1wCE, T2w), representing the depth of the 3D volume.
    *   **File Sizes**: The average file size per modality, serving as a proxy for image resolution or compression complexity.
3.  **Pixel Analysis (Conditional)**: It attempts to read a sample of images using `cv2` or `pydicom` (if available via fallback) to report dimensions and pixel statistics. If reading fails, it gracefully reports the limitation.
4.  **Feature Relationships**: It compiles the extracted meta-features into a structured dataframe to analyze correlations with the target and trains a lightweight Random Forest to assess if scan metadata (e.g., "does the patient have more slices?") carries predictive signal.
