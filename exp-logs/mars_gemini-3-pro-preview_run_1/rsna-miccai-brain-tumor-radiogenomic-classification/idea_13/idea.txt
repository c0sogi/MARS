# Wide-Field Stratified Instance Learning (WSIL) Network

This solution introduces a **Data-Centric Structural Innovation**. It evolves the "Independent Instance" concept (Idea 12) by integrating **Wide-Field Striding** and **Label Smoothing** to address the "Middle Slice Fallacy" (Cite solution_lesson_node_00002) without incurring the "Label Noise" penalty of stochastic sampling (Cite solution_lesson_node_00015) or the "Signal Dilution" of Siamese architectures (Cite solution_lesson_node_00018).

### Model
*   **Architecture:** We utilize a standard **EfficientNet-B0** backbone initialized with ImageNet weights. This architecture is selected for its proven stability and parameter efficiency (Cite solution_lesson_node_00002).
*   **Input:** A standard 3-channel 2D composite image $(224 \times 224 \times 3)$.
    *   Channel 1: **FLAIR** slice.
    *   Channel 2: **T1wCE** slice.
    *   Channel 3: **T2w** slice.
*   **Design Rationale:** We strictly adhere to **Early Fusion** (stacking modalities) rather than Multi-Stream architectures, as the latter triples the parameter count and causes overfitting (Cite solution_lesson_node_00031). We retain the backbone's default hyperparameters (e.g., dropout) to avoid performance regression (Cite solution_lesson_node_00012).

### Data
The innovation lies in the **Wide-Field Independent Sampling Pipeline**, which triples the effective dataset size while ensuring robust anatomical coverage.

1.  **Independent Heuristic Alignment:**
    *   For each subject and **for each modality independently**, we sort the file list and identify the **Median Index** ($M$).
    *   We do *not* project depth from one modality to another. This **Independent Heuristic** ensures that we select the geometric center of the Field-of-View for each scan, implicitly handling alignment errors caused by varying acquisition protocols (Cite solution_lesson_node_00036).
2.  **Wide-Field Deterministic Expansion:**
    *   Instead of a narrow local neighborhood (which fails to capture off-center tumors), we define a **Wide Stride** $\delta$ (e.g., 10 slices).
    *   We construct 3 distinct composite images per subject:
        *   **Instance A (Lower):** $[FLAIR_{M-\delta}, T1wCE_{M-\delta}, T2w_{M-\delta}]$
        *   **Instance B (Center):** $[FLAIR_{M}, T1wCE_{M}, T2w_{M}]$
        *   **Instance C (Upper):** $[FLAIR_{M+\delta}, T1wCE_{M+\delta}, T2w_{M+\delta}]$
    *   **Crucially**, we treat these as **independent training samples**, assigning the patient's global label to each. This effectively triples the training data, providing the regularization needed for the high-capacity backbone (Cite solution_lesson_node_00010).
3.  **High-Fidelity Preprocessing:**
    *   **Precision:** All operations use **float32** to preserve the MRI dynamic range (Cite solution_lesson_node_00016).
    *   **Normalization:** We apply **Independent Channel Min-Max Scaling** to $[0, 1]$ *before* stacking. This prevents high-intensity modalities (like T2w) from suppressing low-intensity ones (Cite solution_lesson_node_00023). We avoid ImageNet mean/std normalization (Cite solution_lesson_node_00017).

### Training
*   **Loss Function:** **Binary Cross-Entropy with Label Smoothing (0.1)**.
    *   *Innovation:* Since we are expanding the data using a Wide Stride, there is a risk that one of the peripheral instances (e.g., $M-\delta$) does not contain the tumor. Label Smoothing explicitly prevents the model from becoming over-confident on these potentially noisy labels, mitigating the risk identified in stochastic sampling (Cite solution_lesson_node_00015).
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Aggressive Weight Decay:** Set to **$1e-2$**. Strong regularization is critical for generalization on small medical datasets (Cite solution_lesson_node_00010).
    *   **Augmentation:** Apply **Elastic Transformations** and **Grid Distortions**. Non-rigid augmentations are essential for modeling anatomical variance (Cite solution_lesson_node_00010).
*   **Validation Strategy:** **GroupKFold** grouped by **Subject ID**. This ensures that all 3 instances from a single patient reside in the same fold, preventing data leakage (Cite solution_lesson_node_00028).

### Evaluation
*   **Inference:** For each test subject, we deterministically generate the same 3 instances ($M-\delta, M, M+\delta$) using the independent median heuristic.
*   **Consensus Aggregation:** We pass each instance through the model to obtain 3 probability scores. The final prediction is the **mean** of these scores. This acts as a deterministic ensemble, robustifying the prediction against positioning offsets without the signal dilution of Siamese feature pooling (Cite solution_lesson_node_00018).
