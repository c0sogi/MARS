The issue is that the data loader blindly loads existing cache files (`.npy`) without verifying if their content matches the current configuration. The previous run generated data with 9 channels (3 slices × 3 modalities), but the current configuration expects 3 channels (1 slice × 3 modalities). This mismatch causes a `RuntimeError` in the model's first convolutional layer.

To fix this, I will modify `library/data.py` to verify the shape of the loaded cached images against `Config.IN_CHANNELS`. If the shapes do not match, the cache will be considered invalid, and the data will be reprocessed from scratch. This applies `debug_lesson_1` (Verify Cache Consistency) and `debug_lesson_5` (Bind Cache Identity to Hyperparameters).
