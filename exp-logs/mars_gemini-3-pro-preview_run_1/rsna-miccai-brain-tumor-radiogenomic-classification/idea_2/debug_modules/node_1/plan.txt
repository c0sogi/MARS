The `torch.OutOfMemoryError` occurred because the effective batch size (8 subjects × 32 slices = 256 images) required more memory for intermediate activations than the GPU could provide. To fix this, I will reduce the `BATCH_SIZE` in `library/config.py` from 8 to 2, reducing the effective batch size to 64 images. This reduction increases the likelihood of batches containing only a single class, but the existing metric calculation logic in `library/engine.py` already handles this case safely, preventing the issue described in **Cite debug_lesson_1**.
