Implementation Strategy:

1.  **Configuration Override**: We will monkey-patch the `Config` class from `library.config` immediately after import. This allows us to reduce the computational load (e.g., fewer trees, smaller window sizes) and redirect output directories to a demo-specific folder without modifying the read-only library files.
2.  **Training Pipeline Execution**: We will invoke `run_training_pipeline` with a small `debug_sample` (e.g., 5000 rows). This exercises the data loading, merging, feature engineering (gating, basis projection), scout training (hard negative mining), and expert ensemble training logic.
3.  **Artifact Verification**: We will assert that the expected model files (LGBM, XGBoost) and the optimal threshold file are created in the working directory.
4.  **Inference Pipeline Execution**: We will invoke `run_inference` with a small `debug_sample`. This verifies that the trained models can be loaded and applied to the test set to generate predictions.
5.  **Submission Verification**: We will load the generated `submission.csv` to ensure it follows the required format (correct columns, binary predictions) and that the merge logic correctly handled gated-out rows (filling them with 0).
