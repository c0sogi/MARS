The issue is that `LGBMClassifier` and `XGBClassifier` are being used to train on continuous "soft" labels (generated by label smoothing), which causes a `ValueError` because these classifiers expect discrete class labels. To fix this, I will replace them with `LGBMRegressor` and `XGBRegressor` respectively, configured with binary objectives. This allows the models to minimize log-loss on soft targets without strict class validation. I will also update the prediction methods (`predict_proba` in `TriEnsemble` and the direct calls in `pipeline.py`) to use `.predict()` instead of `.predict_proba()` for these regressors, as they output probabilities directly when using binary objectives.
