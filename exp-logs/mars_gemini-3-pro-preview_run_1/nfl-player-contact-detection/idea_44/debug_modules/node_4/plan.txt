The `ValueError` in `LGBMWrapper` occurs because the `early_stopping_rounds` parameter is passed directly to the `LGBMClassifier` constructor via `**self.params`. This unconditionally enables early stopping logic, which strictly requires a validation dataset (`eval_set`). During the "Scout" training phase, no validation set is provided, causing LightGBM to raise an error. Additionally, the code references an undefined attribute `self.fit_params`.

To fix this, I will modify `LGBMWrapper` to extract (`pop`) `early_stopping_rounds` from the parameters dictionary in `__init__`, preventing it from being passed to the constructor. Then, in `fit`, I will use this stored value to conditionally register the `lgb.early_stopping` callback only when validation data is present. This approach ensures callbacks are only registered when their dependencies are met (Cite debug_lesson_32).
