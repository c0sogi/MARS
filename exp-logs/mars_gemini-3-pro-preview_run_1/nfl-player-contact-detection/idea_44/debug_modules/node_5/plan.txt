The issue is that `XGBClassifier` is being initialized with `early_stopping_rounds` even when no validation dataset is provided (e.g., during the "Scout" training phase). XGBoost raises a `ValueError` if early stopping is configured but `eval_set` is missing. To fix this, I will modify the `XGBWrapper` class in `library/models.py` to extract `early_stopping_rounds` from the parameters during initialization and only inject it back into the `XGBClassifier` constructor if validation data is explicitly passed to the `fit` method. This ensures early stopping is conditionally enabled only when feasible. Cite debug_lesson_32 and Cite debug_lesson_40.
