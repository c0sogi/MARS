To resolve this, I will modify `library/model_factory.py` to inject `early_stopping_rounds` into the `XGBClassifier` constructor using the value from `Config`. I will then remove the parameter from the `fit_params` dictionary in the `fit` method, ensuring only valid arguments like `eval_set` are passed during training. Cite debug_lesson_7.
