The error `ValueError: Unknown label type: continuous` occurs because the "Expert" training phase uses soft labels (continuous probabilities) generated by temporal smoothing, but the model ensemble is currently configured with Classifiers (`LGBMClassifier`, `XGBClassifier`, etc.) which strictly require discrete integer targets (0 or 1).

To fix this, I will modify `library/model_factory.py` to replace the Classifiers with their Regressor counterparts (`LGBMRegressor`, `XGBRegressor`, `HistGradientBoostingRegressor`). I will also adjust the training objectives to be suitable for regression on probabilities (e.g., `binary:logistic` for XGBoost, `regression`/MSE for LightGBM) and update the prediction logic to use `predict()` instead of `predict_proba()`, ensuring outputs are clipped to the [0, 1] range. This aligns with **Cite debug_lesson_30**, which states that soft labels require regressors with appropriate objectives.
