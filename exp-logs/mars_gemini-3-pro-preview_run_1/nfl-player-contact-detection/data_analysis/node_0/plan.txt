This script performs a comprehensive Exploratory Data Analysis (EDA) on the training dataset provided in the `./metadata` and `./input` directories. It adheres to the constraints of using only training data, handling multimodal inputs (tabular tracking data and video footage), and ensuring reproducibility.

The analysis covers:
1.  **Target Variable**: Distribution of the `contact` class.
2.  **Video Data**: Analysis of video dimensions, frame rates, and pixel statistics using a sampled subset of the footage.
3.  **Tabular/Tracking Data**: Merging of player tracking data with contact labels to engineer features (e.g., player distance, speed). It analyzes the statistics of these features.
4.  **Feature Importance**: Training a lightweight Random Forest classifier on the engineered tracking features to identify the most predictive signals for contact events.
