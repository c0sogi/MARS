The `NameError` in `library/config.py` occurs because `STREAM_B_FEATURES` is referenced within the `CNN_PARAMS` dictionary definition before it has been defined in the `Config` class body. In Python, class attributes are evaluated sequentially, so referenced attributes must be defined earlier in the file. To fix this, I will define `STREAM_B_FEATURES` immediately after `TRACKING_COLS` and before it is used in `CNN_PARAMS`, ensuring linear definition order (Cite debug_lesson_1).
