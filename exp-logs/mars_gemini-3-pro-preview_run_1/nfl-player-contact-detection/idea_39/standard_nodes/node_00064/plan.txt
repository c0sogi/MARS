I will implement the `runfile.py` script to orchestrate the SFGA-E pipeline. The strategy involves:

3.  **Step-by-Step Training**: Manually executing the `Trainer` phases (Scouts -> Mining -> Experts) to maintain control over the workflow and access intermediate models.
4.  **Validation & Failure Analysis**: Performing inference on the full validation set to compute the required Matthews Correlation Coefficient (MCC). I will then calculate the correlation between prediction errors and input features to identify failure modes.
5.  **Conditional Submission**: Checking if the validation MCC exceeds the threshold (0.6865). If successful, I will generate features for the test set, run the ensemble inference, apply the optimized threshold, and save the submission file.
