The issue is that the validation set was being filtered ("gated") to remove "easy" negatives, which drastically skewed the class distribution and invalidated the Matthews Correlation Coefficient (MCC) calculation. Validation metrics must be computed on the full, unaltered hold-out set (Cite debug_lesson_3). Additionally, simply changing the logic is insufficient if the pipeline loads the old, gated data from the cache; the cache filename must be updated to force regeneration (Cite debug_lesson_5).

The fix involves updating `library/features.py` to:
1.  Change the cache filename for validation data from `val_features_gated.parquet` to `val_features_full.parquet`.
2.  Restrict the gating logic so it only applies when processing the training set (`Config.TRAIN_METADATA_PATH`), ensuring validation and test sets retain the full distribution.
