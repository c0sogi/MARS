This script demonstrates the full end-to-end pipeline for the NFL Contact Detection task using the provided library. To ensure rapid execution and verification within the time limit, it performs the following steps:

1.  **Environment Setup**: Configures logging and seeds for reproducibility.
2.  **Data Subsetting**: Creates "mini" versions of the metadata and tracking files in the working directory containing only a few plays. This drastically reduces processing time for feature engineering.
3.  **Configuration Override**: Dynamically updates paths in `library.config` to point to these mini datasets and reduces model hyperparameters (e.g., `n_estimators`) for quick training.
4.  **Feature Engineering**: Generates features for train, validation, and test splits using `library.features` and `library.data_loader`.
5.  **Model Training**: Runs the `library.train` pipeline, including Scout model training, hard negative mining, Expert ensemble training, and threshold optimization.
6.  **Inference**: Generates predictions on the test set and creates a submission file using `library.inference`.
7.  **Verification**: Asserts that outputs (features, models, submission) are created correctly and contain the expected data structures.
