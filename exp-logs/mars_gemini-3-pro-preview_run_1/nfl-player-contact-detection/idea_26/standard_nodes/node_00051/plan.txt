The implementation strategy for the `runfile.py` script is as follows:

1.  **Initialization**: Import necessary standard libraries and the provided custom library modules (`config`, `utils`, `training_pipeline`, `inference_pipeline`, `physics_engine`, `model_factory`).
2.  **Configuration Override**: Monkey-patch `library.config.SUBMISSION_DIR` to point to `./submission` as required by the task, and ensure the directory exists. Set the random seed for reproducibility.
3.  **Training Execution**: Instantiate the `TrainingPipeline`. Execute the `run()` method with `debug_sample=200000` and `load_cached_data=True`. This ensures the solution runs quickly (Fast Baseline) by limiting the dataset size while performing the full VASM-E workflow (Scout Mining -> Expert Training).
4.  **Validation & Failure Analysis**:
    *   Since the pipeline manages memory aggressively, manually reload the validation data (using `FeatureManager`) and the trained model (using `TriEnsemble`).
    *   Generate predictions on the validation set.
    *   Compute and print the `Final Validation Metric` (MCC) using the optimized threshold found during training.
    *   Perform failure analysis by calculating the absolute prediction error and computing the correlation between this error and each input feature. Print the features ranked by their correlation with the error.
5.  **Submission**: Check if the Final MCC exceeds the threshold of `0.6865`. If successful, instantiate the `InferencePipeline` and execute `run()` to generate predictions for the full test set and save the submission file to `./submission/submission.csv`.
