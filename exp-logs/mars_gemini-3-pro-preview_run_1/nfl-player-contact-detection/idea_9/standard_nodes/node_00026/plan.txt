This script implements the Geometrically-Gated Full-Context Mining Ensemble (GGFC-ME) pipeline.

**Strategy Outline:**
1.  **Configuration:** Sets random seeds for reproducibility and overrides the default number of estimators to 500 to ensure the "Fast Baseline" constraint is met within the runtime limits.
2.  **Training Pipeline:** Utilizes the `MiningTrainer` class to execute the multi-stage training curriculum:
    *   **Geometric Gating:** Filters the training data to remove physically impossible contacts (handled by `DataFactory`).
    *   **Scout Training:** Trains a LightGBM model on a balanced subset.
    *   **Hard Negative Mining:** Uses the Scout model to identify difficult non-contact examples from the full gated dataset.
    *   **Expert Training:** Trains a heterogeneous ensemble (LightGBM + XGBoost) on a high-fidelity dataset composed of positives and mined hard negatives.
    *   **Threshold Optimization:** Finds the optimal decision threshold on the validation set.
3.  **Validation & Analysis:**
    *   Reloads the full hold-out validation set.
    *   Computes and prints the `Final Validation Metric` (Matthews Correlation Coefficient).
    *   Performs failure analysis by calculating the correlation between model error magnitude and input features to identify weak points.
4.  **Submission:** Checks if the validation MCC exceeds the specified target (0.6746...). If successful, invokes the `InferenceManager` to generate predictions for the test set and save `submission.csv`.
