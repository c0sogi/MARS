The following implementation demonstrates the Kinematically-Projected Mining Ensemble (KP-ME) pipeline. It performs the following steps:

1.  **Configuration Override**: Adjusts the `Config` class to use a temporary working directory and reduced hyperparameters (e.g., fewer estimators) for rapid execution.
2.  **Mini-Dataset Creation**: Samples a small subset of the provided metadata and tracking data to create a lightweight demonstration dataset.
3.  **Feature Engineering**: Uses `FeatureEngineer` to generate kinematic features, applying temporal windowing and reachability gating.
4.  **Scout Training**: Uses `MiningStrategy` to train balanced "Scout" models (LightGBM and XGBoost).
5.  **Hard Negative Mining**: Uses the Scouts to identify "hard negatives" (non-contact events that look like contact) from the full training set.
6.  **Expert Training**: Trains "Expert" models on a dataset enriched with these hard negatives to improve decision boundary precision.
7.  **Inference**: Generates predictions on a test set using the Expert models.
