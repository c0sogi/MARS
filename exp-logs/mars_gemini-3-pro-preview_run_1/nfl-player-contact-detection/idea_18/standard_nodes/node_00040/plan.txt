Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy
1.  **Configuration & Setup**: Import necessary modules and the provided library classes. Patch the `Config` class at runtime to reduce the number of training epochs (`SCOUT_EPOCHS` to 100, `EXPERT_EPOCHS` to 300) to ensure the solution runs within the "Fast Baseline" time constraints.
2.  **Data Loading**: Initialize the `DataManager` and load the training, validation, and test feature sets using the cached data loading methods to save time.
3.  **Pipeline Execution**:
    *   **Phase 1 (Scouts)**: Instantiate the `Trainer` and execute `train_scouts` to build the initial diversity models.
    *   **Phase 2 (Mining)**: Execute `mine_hard_negatives` to identify difficult examples from the training set.
    *   **Phase 3 (Experts)**: Execute `train_expert_ensemble` using the mined hard negatives to train the final high-capacity ensemble.
4.  **Validation & Metrics**:
    *   Perform inference on the validation set using the trained ensemble.
    *   Iterate through thresholds to find the one that maximizes the Matthews Correlation Coefficient (MCC).
    *   Print the required metric string: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the absolute error between predictions and ground truth.
    *   Compute the correlation between this error and each input feature to identify weak points.
    *   Print the top feature correlations.
6.  **Submission**:
    *   Check if the best validation MCC exceeds the threshold of `0.6865`.
    *   If successful, generate predictions for the test set and save `submission.csv` using `Trainer.generate_submission`.
