Implementation Strategy:
1.  **Setup Environment**: Import necessary libraries and the provided modules (`library.*`).
2.  **Create Mini-Datasets**: To ensure the script runs within the time limit and demonstrates the logic quickly, we will create smaller versions of the metadata and tracking files (approx. 2-3 plays) in the `./working` directory.
3.  **Patch Configuration**: Since the library modules import constants from `config.py` at the top level, we will dynamically patch these constants in the imported modules (`data_loader`, `model_factory`, `utils`, etc.) to point to our mini-datasets and use a temporary working directory.
4.  **Optimize Hyperparameters**: Patch the model parameters in `model_factory` to use very few estimators (e.g., 2) and shallow trees, ensuring the training phase finishes in seconds.
5.  **Execute Training**: Run the `TrainingPipeline.run_pipeline()` method. This will trigger feature engineering, scout training, hard negative mining, expert training, and threshold optimization on the mini-dataset.
6.  **Execute Inference**: Run the `InferencePipeline.run_inference()` method to generate predictions on the mini-test set.
7.  **Verification**: Assert that the submission file is created and has the expected number of rows.
