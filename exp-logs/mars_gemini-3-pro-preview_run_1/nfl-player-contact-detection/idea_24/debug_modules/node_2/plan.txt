The `ValueError: Duplicate column names found` during Parquet serialization is caused by the `step` column appearing in both the metadata columns list (`meta_cols`) and the feature configuration list (`Config.FEATURES`). When these lists are concatenated to form `final_cols`, `step` is duplicated. Although Pandas allows selecting duplicate columns (creating a DataFrame with two `step` columns), the Parquet format strictly forbids this ambiguity. To resolve this, I will deduplicate the `final_cols` list using `dict.fromkeys()` (which preserves order) before filtering for existing columns and selecting them from the DataFrame. This ensures the output schema is valid for serialization. Cite debug_lesson_15
