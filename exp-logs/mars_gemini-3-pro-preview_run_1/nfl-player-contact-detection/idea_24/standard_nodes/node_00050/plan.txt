The implementation strategy is as follows:

1.  **Configuration Setup**: Import the `Config` class and modify `NUM_BOOST_ROUND` to 500 to ensure the training completes quickly within the time limit, while maintaining sufficient capacity for the model to learn. We also silence verbose outputs.
2.  **Workflow Execution**: Instantiate the `WorkflowManager` and run the training phase. We use `debug=False` to utilize the full dataset for maximum performance, relying on the efficient `MiningStrategy` (which subsets the data for the Expert model) to keep training times low. We enable `load_cached_data=True` to leverage any existing features.
3.  **Validation & Analysis**:
    *   Manually load the validation dataset and the trained models/thresholds to perform a detailed evaluation.
    *   Compute the Matthews Correlation Coefficient (MCC) on the full validation set and print it in the required format: `Final Validation Metric: <value>`.
    *   Perform failure analysis by calculating the absolute prediction error (residuals) and computing the Pearson correlation between these residuals and each input feature. This identifies which features correlate most with model failure.
4.  **Conditional Submission**: Check if the validation MCC exceeds the threshold of 0.6865. If successful, trigger the `WorkflowManager`'s inference phase to generate predictions on the test set and save `submission.csv`.
