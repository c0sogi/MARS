The `ValueError: pandas dtypes must be int, float or bool` is caused by the creation of an empty DataFrame (`anchors = pd.DataFrame(columns=df.columns)`) when `n_anchors` is zero. This empty DataFrame defaults to `object` dtype for all columns. When it is concatenated with the populated `positives` and `hard_negatives` DataFrames, pandas upcasts the resulting columns (including the target `contact`) to `object` to accommodate the mixed types, which LightGBM rejects.

To fix this, I will modify `library/data_pipeline.py` to use a list-based concatenation approach. Instead of creating an empty placeholder, I will initialize a list with the mandatory DataFrames and conditionally append `anchors` only if it contains data. This ensures that `pd.concat` receives only DataFrames with valid numeric schemas (Cite debug_lesson_34). I will also update the logging logic to reflect this change.
