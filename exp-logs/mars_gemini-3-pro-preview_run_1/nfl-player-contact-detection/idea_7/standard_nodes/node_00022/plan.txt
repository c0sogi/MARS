Implementation strategy:
1.  **Environment & Configuration**: Initialize the logger and set random seeds for reproducibility. Detect available GPU resources and dynamically update the XGBoost configuration in `library.config` to utilize the GPU for training and inference, ensuring compliance with the optimization requirements.
2.  **Data Loading**: Instantiate the `DataLoader`. Load a subset (500,000 rows) of the training data to ensure the pipeline completes within the 2-hour limit ("Fast Baseline"). Load the *entire* validation set as strictly required for metric calculation.
3.  **Cascade Training Pipeline**:
    *   **Scout**: Train the lightweight Scout model on a small balanced subset of the limited training data.
    *   **Mining**: Use the Scout model to mine "Hard Negatives" from the full 500k training rows.
    *   **Experts**: Train the Expert Ensemble (LightGBM + XGBoost) using the mined training data (Positives + Hard Negatives) and the full validation set.
4.  **Validation & Analysis**:
    *   Re-run inference on the full validation set using the trained Expert Ensemble.
    *   Calculate and print the **Matthews Correlation Coefficient (MCC)** in the exact specified format.
    *   Perform **Failure Analysis** by calculating the absolute error magnitude for each validation sample and computing its correlation with input features to identify sources of error.
5.  **Submission**: Compare the calculated validation MCC against the threshold (`0.6746827603428585`). If the metric exceeds the threshold, load the test set, generate predictions, and save the `submission.csv` file.
