The issue is caused by an API incompatibility between the `XGBClassifierWrapper` implementation and the installed version of XGBoost (`3.0.5`). In newer versions of XGBoost (specifically 1.6+ and the 2.x/3.x series), the `early_stopping_rounds` parameter has been removed from the `fit()` method and must instead be passed to the model constructor (`__init__`). The current code attempts to pass it to `fit()`, raising a `TypeError`.

To fix this, I will modify the `XGBClassifierWrapper.fit` method in `library/models.py`. I will move the `early_stopping_rounds` parameter from the `fit()` call to the `XGBClassifier` initialization, conditionally adding it to the parameters only when a validation set is present. This aligns with the principle of adapting library-specific configurations as highlighted in **Cite debug_lesson_3**.
