This script demonstrates the end-to-end workflow for predicting player contact using the provided library. It covers data loading, feature engineering, model training (Scout and Expert stages), hard negative mining, and inference. To ensure rapid execution within the demonstration environment, the script uses a small subset of the data (`nrows=2000`) and reduces the number of boosting rounds for the LightGBM and XGBoost models. It explicitly verifies the output shapes and logic at each step using assertions.
