Implementation Strategy:
1.  **Environment Setup**: Import necessary modules and set the random seed for reproducibility.
2.  **Configuration Override**: Monkey-patch the `Config` class to define a custom working directory (`./working/demo_run`) and reduce model hyperparameters (e.g., `n_estimators=10`) to ensure the demo completes quickly.
3.  **Data Loading Verification**: Instantiate `DataManager` and load a small sample (5000 rows) of the training data. Verify that the returned DataFrame contains expected columns and that the Sentinel Value strategy for ground interactions is applied correctly.
4.  **Feature Engineering Verification**: Instantiate `FeatureEngine` pointing to the demo directory. Process the training sample and verify that feature columns (e.g., projections, lags) are generated and that the gating mechanism functions (returns a DataFrame).
5.  **Full Pipeline Execution**: Instantiate `Trainer` and execute the `run()` method with the small sample size. This tests the end-to-end flow: Scout training, Hard Negative mining, Expert training, Threshold tuning, and Inference.
6.  **Artifact Verification**: Assert that all expected model files (Scouts, Experts), the threshold file, and the submission CSV are created in the demo directory.
7.  **Inference Pipeline Verification**: Instantiate `InferencePipeline`, run `generate_submission`, and verify that it successfully produces a valid submission file.
