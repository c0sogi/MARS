This script demonstrates the end-to-end execution of the NFL Contact Detection pipeline using the provided library classes.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the global `Config` class to point to a temporary working directory and reduce model hyperparameters (e.g., `n_estimators=10`) for rapid execution.
2.  **Data Subsampling**: To ensure the demo runs quickly within the time limit, we create "mini" versions of the metadata and tracking datasets. We sample a small subset of plays from the provided metadata and filter the tracking data to match these plays.
3.  **Pipeline Execution**: We instantiate the `Trainer` class, which orchestrates the feature extraction, scout training, hard negative mining, expert ensemble training, threshold optimization, and submission generation.
4.  **Verification**: After execution, we validate that the submission file exists, contains the correct number of rows corresponding to our mini test set, and follows the required format.
