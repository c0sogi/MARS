The previous implementation failed because it attempted to access the standard Python `logging` module through an internal, undocumented submodule of pandas (`pd.io.common.logging`). This path does not exist in the installed version of pandas, leading to an `AttributeError`. Relying on internal library structures is unstable and an anti-pattern (Cite debug_lesson_23). The fix involves importing the standard `logging` module directly and using `logging.getLogger(__name__)` in both `library/feature_extractor.py` and `library/trainer.py`.
