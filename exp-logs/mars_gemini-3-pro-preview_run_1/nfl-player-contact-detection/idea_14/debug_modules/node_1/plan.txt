The `FileNotFoundError` occurs because the `EnsemblePredictor` class (specifically the underlying `BaseModel.load` method) automatically prepends `MODEL_OUTPUT_DIR` to the model path argument. The calling code in `runfile.py` and `library/inference.py` incorrectly constructs a full path before passing it, resulting in a duplicated directory structure (e.g., `./working/.../models/./working/.../models/file.joblib`). The fix is to pass only the filenames (e.g., `"expert_lgbm.joblib"`) to `EnsemblePredictor`, allowing the internal logic to resolve the correct absolute path.
