Implementation strategy:
1.  **Setup & Configuration**: Initialize logging and random seeds. Detect GPU availability and dynamically update `Config` parameters for LightGBM and XGBoost to utilize GPU acceleration. Reduce the number of estimators in `Config` to ensure the pipeline completes within the 2-hour limit while maintaining a baseline performance.
2.  **Data Loading & Feature Generation (Tier 1)**: Use `DataLoader` to load training and validation metadata/tracking. Use `FeatureGenerator` to create "Tier 1" (Kinematic + Physics) features for the full datasets. This is required for the "Scout" mining phase.
3.  **Mining (Scout)**: Instantiate `ScoutMiner` and execute it on the Tier 1 training data. This identifies "Hard Negatives" and returns the indices of the subset to be used for expert training.
4.  **Expert Training**: Instantiate `ExpertTrainer` and train the heterogeneous ensemble (LightGBM + XGBoost) on the mined subset. This class handles Tier 2 feature generation (adding Context) for the mined data and validation set internally.
5.  **Validation & Failure Analysis**:
    *   Reload the validation dataset and generate Tier 2 features (since the trainer cleans up to save memory).
    *   Load the trained models and optimized threshold.
    *   Perform inference on the validation set.
    *   Compute and print the `Final Validation Metric` (MCC).
    *   Calculate correlations between the absolute prediction error and key features to identify failure modes.
6.  **Submission**: Check if the validation MCC exceeds the specified threshold (0.67468...). If successful, run the `InferencePipeline` to generate the submission file for the test set.
