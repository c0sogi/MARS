The following script demonstrates the end-to-end execution of the Variable-Resolution Contextual Mining Ensemble (VRC-ME) pipeline using the provided library files.

To ensure rapid execution and logic verification:
1.  **Configuration Overrides**: We modify `Config` parameters to enable debug mode, reduce sample sizes to 200 rows, and limit model estimators to 2. This ensures the pipeline runs in seconds rather than hours.
2.  **Data Loading**: We verify the `DataLoader` correctly handles debug sampling and merging of tracking data.
3.  **Feature Engineering**: We generate Tier 1 (Scout) features and verify the existence of kinematic columns.
4.  **Mining**: We execute the `ScoutMiner` to simulate hard-negative mining on the small subset.
5.  **Training**: We run the `ExpertTrainer` to train the heterogeneous ensemble (LightGBM + XGBoost) on the mined data.
6.  **Inference**: We execute the `InferencePipeline` to generate predictions and a submission file.
7.  **Validation**: Assertions are placed throughout to confirm data shapes, file creation, and logical consistency.
