The following script demonstrates the usage of the provided library components. It follows a logical flow:
1.  **Configuration Setup**: Overrides default configuration to ensure the script runs quickly (1 epoch, small subset of data).
2.  **Utility Verification**: Tests the normalization, composite generation, and RLE encoding functions.
3.  **Dataset Verification**: Instantiates the dataset, loads a sample, and verifies tensor shapes and types.
4.  **Model & Loss Verification**: Instantiates the `TemporalAshNet` and `WeightedLoss`, runs a dummy forward pass, and verifies output shapes and loss calculation.
5.  **Training Loop Demonstration**: Executes the full training pipeline in debug mode.
6.  **Inference Demonstration**: Creates a subset of the test metadata to run a quick inference pass and verifies the submission output.
