Based on the lessons learned, I propose the **Dilated ResNet-Ash U-Net**. This strategy structurally evolves the previous "ResNet-Ash" approach by integrating the resolution-preserving properties of the custom baseline with the efficiency of pretrained backbones, while strictly enforcing the data processing protocols that yielded the highest scores.

# Model
**Architecture: Dilated ResNet34-UNet (Output Stride 16)**
I propose a structural modification to the standard ResNet34-UNet backbone to address the "thin feature" signal loss identified in previous iterations.
*   **Backbone Modification:** Instead of using the standard ResNet34 encoder which downsamples the image by 32x (resulting in an 8x8 bottleneck for 256x256 inputs), we will modify the final encoder stage (`layer4`). We will set the stride to 1 (instead of 2) and apply **dilated convolutions (dilation=2)**. This restricts the maximum downsampling factor to **16x**, preserving the spatial resolution of thin contrails while retaining the deep semantic features of the full ResNet depth. Cite solution_lesson_node_00015
*   **Initialization:** The backbone will be initialized with **ImageNet pretrained weights** to ensure rapid convergence and robust feature extraction, improving upon the slow training of custom architectures. Cite solution_lesson_node_00014
*   **Decoder:** The U-Net decoder will be adapted to match the 16x bottleneck resolution, using symmetric skip connections from the encoder layers.

# Data
**Preprocessing: Wide-Spectrum Ash Composite**
We will strictly adhere to the "Ash" false-color composite but correct the normalization strategy that caused regression in previous attempts.
*   **Input Representation:** 3-Channel Ash Composite (Red: Band 15-14, Green: Band 14-11, Blue: Band 14). Cite solution_lesson_node_00001
*   **Normalization:** We will use the **wider, statistically derived normalization bounds** observed in the successful custom baseline (e.g., Red Channel: -6.7 to 2.6) rather than the tighter heuristic bounds (e.g., -4 to 2) used in the failed ResNet attempt. This ensures that subtle spectral signals in the tails of the distribution are not clipped. Cite solution_lesson_node_00016
*   **Augmentation:** We will employ **only discrete geometric transformations** (Horizontal Flip, Vertical Flip, Random 90-degree Rotation) and explicitly exclude interpolation-based transforms (scaling, shifting) to preserve the integrity of the single-pixel-wide contrail features. Cite solution_lesson_node_00012

# Training
**Strategy: Balanced Imbalance-Aware Optimization**
The training loop is designed to stabilize gradients for the sparse target class.
*   **Loss Function:** A composite loss of **Focal Loss + Dice Loss**.
    *   **Focal Loss Configuration:** We will set **$\alpha=0.5$** (balanced) to prevent down-weighting the minority class, as identified in the most successful experiment. Cite solution_lesson_node_00010
    *   **Weighting:** We will maintain a significant weight on the pixel-wise loss (e.g., 0.75 Focal / 0.25 Dice or 0.5/0.5) to prioritize gradient stability over aggressive shape regularization in the early stages. Cite solution_lesson_node_00006
*   **Optimizer:** AdamW with a `ReduceLROnPlateau` scheduler to fine-tune the model once the loss stabilizes.

# Evaluation
**Inference Process**
1.  **Generation:** Generate the Ash composite for the test set using the **Wide Normalization** constants.
2.  **Prediction:** Pass inputs through the Dilated ResNet34-UNet.
3.  **Post-Processing:** Apply a sigmoid activation and a fixed threshold (0.5) to generate binary masks.
4.  **Formatting:** Encode the masks using Run-Length Encoding (RLE) for submission.
