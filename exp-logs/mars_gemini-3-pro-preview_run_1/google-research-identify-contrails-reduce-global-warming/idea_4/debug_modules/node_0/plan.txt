Implementation Strategy:
1.  **Utility Verification**: Demonstrate `rle_encode` and `dice_coefficient` with synthetic data to verify correctness of metric calculations and submission formatting.
2.  **Configuration & Setup**: Initialize the configuration in debug mode and set random seeds for reproducibility.
3.  **Data Loading**: Instantiate the `ContrailDataset` and `DataLoader` (via `get_dataloader`). Fetch a single batch to verify input image shapes `(B, 3, H, W)` and mask shapes `(B, 1, H, W)`. Verify that data normalization results in values within the expected `[0, 1]` range.
4.  **Model Initialization & Forward Pass**: Instantiate the `HRNetSegmenter`. Perform a forward pass using the batch loaded in the previous step to confirm the model outputs logits of the correct shape `(B, 1, H, W)`.
5.  **Loss Calculation**: Instantiate `ContrailLoss` (Composite Focal + Dice). Calculate the loss using the model outputs and ground truth masks to ensure the loss function is differentiable and returns a scalar.
6.  **Full Training Loop Execution**: Execute the `train_model` function in debug mode. To ensure this completes rapidly, we will override the `Config` class attributes to run only 1 epoch with a very small subset of data. This demonstrates the integration of all components.
