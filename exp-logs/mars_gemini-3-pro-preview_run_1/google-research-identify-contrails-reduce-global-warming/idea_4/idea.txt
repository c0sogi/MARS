Based on the lessons learned from previous iterations, I propose the **HRNet-Ash Semantic Segmenter**. This strategy introduces a structural paradigm shift from the Encoder-Decoder (U-Net) architecture to a **High-Resolution Network (HRNet)** architecture. This change directly addresses the critical issue of signal loss during downsampling while maintaining the successful data and training protocols established in earlier experiments.

# Model
**Architecture: HRNet-W18 (High-Resolution Network)**
I propose replacing the U-Net architecture with **HRNet-W18-V2**.
*   **Structural Innovation:** Unlike U-Net or ResNet, which serially downsample the image to a low-resolution bottleneck (losing spatial precision) and then attempt to recover it, HRNet maintains a **high-resolution representation** throughout the entire forward pass. It connects high-to-low resolution subnetworks in parallel and repeatedly fuses information across scales. This structural design is specifically chosen to address the "thin feature" signal loss observed with standard 32x downsampling backbones. Cite solution_lesson_node_00015
*   **Initialization:** The backbone will be initialized with **ImageNet pretrained weights** to ensure rapid convergence and robust feature extraction. Cite solution_lesson_node_00014
*   **Head:** A simple 1x1 convolution segmentation head will be applied to the high-resolution output (1/4 scale), followed by bilinear upsampling to the original input size.

# Data
**Preprocessing: Wide-Spectrum Ash Composite**
We will retain the physics-informed input representation but strictly enforce the normalization strategy that yielded the best results.
*   **Input Representation:** 3-Channel Ash False-Color Composite.
    *   Red: Band 15 $-$ Band 14 (Optical Depth)
    *   Green: Band 14 $-$ Band 11 (Particle Phase)
    *   Blue: Band 14 (Temperature)
    Cite solution_lesson_node_00001
*   **Normalization:** We will apply the **Wide Normalization Bounds** (e.g., Red channel: -6.7 to 2.6) identified in the successful custom baseline. We will explicitly reject the tighter "standard" bounds used in the failed ResNet experiment to prevent clipping the subtle signal tails. Cite solution_lesson_node_00016
*   **Augmentation:** We will use **only discrete geometric transformations** (Horizontal Flip, Vertical Flip, Random 90-degree Rotation). We will strictly exclude interpolation-heavy operations (scaling, shearing, shifting) to preserve the integrity of single-pixel contrail lines. Cite solution_lesson_node_00012

# Training
**Strategy: Metric-Coupled Refinement**
The training loop is designed to handle extreme imbalance and ensure the model is fully converged.
*   **Loss Function:** A composite of **Balanced Focal Loss + Dice Loss**.
    *   **Configuration:** We will set the Focal Loss alpha parameter to **$\alpha=0.5$** to ensure the minority class is not down-weighted, correcting the imbalance issue found in earlier attempts. Cite solution_lesson_node_00010
*   **Scheduler:** We will use `ReduceLROnPlateau` monitoring the **Validation Dice Score**, not the Validation Loss. This ensures that learning rate decay is triggered only when the segmentation quality actually stagnates, allowing for a proper refinement phase that was missing in the Dilated ResNet experiment. Cite solution_lesson_node_00018
*   **Duration:** The model will be trained for **30+ epochs** to allow sufficient time for the scheduler to decay the learning rate and fine-tune the weights.

# Evaluation
**Inference Process**
1.  **Input Generation:** Generate the 3-channel Ash composite for the test set using the **Wide Normalization** constants.
2.  **Prediction:** Pass inputs through the HRNet-W18 model.
3.  **Upsampling:** Bilinearly upsample the output logits from 1/4 resolution to full resolution (256x256).
4.  **Thresholding:** Apply a sigmoid activation and a fixed threshold (0.5) to generate binary masks.
5.  **Formatting:** Encode the masks using Run-Length Encoding (RLE) for submission.
