Implementation Strategy:
1.  **Setup and Configuration**: Initialize random seeds for reproducibility. Define paths and load the training metadata from `./metadata/train.csv`.
2.  **Sampling**: Due to the large dataset size and file I/O overhead, select a random sample of records (e.g., 500 for masks, 100 for full spectral bands) to perform the analysis efficiently within the time limit.
3.  **Target Variable Analysis**:
    *   Load the binary masks (`human_pixel_masks.npy`) for the sampled records.
    *   Calculate the global distribution of contrail pixels vs. background pixels (Class Balance).
    *   Determine the frequency of "empty" masks (images with no contrails).
4.  **Image Data Analysis**:
    *   Load the spectral bands (`band_08.npy` through `band_16.npy`) for the sub-sample.
    *   Verify image dimensions (Height, Width, Temporal depth).
    *   Calculate global Mean and Standard Deviation for each spectral band to inform normalization strategies.
5.  **Meta-Feature Relationships**:
    *   Extract metadata features like Timestamp (convert to Hour of Day).
    *   Calculate the "Contrail Coverage" (fraction of pixels that are contrails) for each record.
    *   Compute correlations between metadata (Time, Location proxies) and Contrail Coverage to check for temporal or spatial patterns.
6.  **Reporting**: Output the findings in the requested format with clear sections and formatted numbers.
