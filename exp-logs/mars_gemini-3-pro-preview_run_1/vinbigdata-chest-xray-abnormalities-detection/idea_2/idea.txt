To address the task of thoracic disease detection and localization, I propose a solution that structurally evolves the baseline CenterNet approach into a **Multi-Task EfficientDet-based CenterNet**. This strategy integrates a stronger, multi-scale backbone with a dedicated global classification head and, crucially, implements a robust, centralized data ingestion pipeline to resolve the specific failures identified in the provided lessons.

### Model: Multi-Task CenterNet with EfficientNet & BiFPN
I will replace the simple ResNet-18 + Deconvolution architecture with a more sophisticated **EfficientNet-B0 backbone coupled with a Bi-directional Feature Pyramid Network (BiFPN)**.

*   **Backbone (EfficientNet-B0):** This model offers a better trade-off between parameter efficiency and feature extraction capability compared to ResNet. It will be initialized using pre-trained weights (via `timm`).
*   **Neck (BiFPN):** Unlike the simple upsampling in the previous idea, BiFPN allows for weighted, bi-directional feature fusion. This is critical for chest X-rays where findings vary drastically in scale (e.g., tiny calcifications vs. massive pleural effusions). The BiFPN will output a high-resolution feature map (stride 4) by aggregating features from levels P3-P7.
*   **Heads:**
    1.  **Detection Heads:** Standard CenterNet heads (Heatmap, Object Size, Center Offset) operating on the fused feature map.
    2.  **Global Classification Head:** A new structural addition. A Global Average Pooling layer followed by a dense layer will be attached to the deepest feature map (P7) to predict a binary "Finding vs. No Finding" probability. This explicitly models the high prevalence of normal images (46%) and acts as a gate for predictions.

### Data: Robust Custom Parsing & Centralized Metadata
To address the critical failures caused by missing libraries and coordinate mismatches, I will implement a **standalone, pure-Python DICOM parser** encapsulated in a shared utility module.

*   **Custom Binary Parser:** Since `pydicom` is unavailable and standard libraries failed, I will implement a parser that reads the DICOM binary stream directly. It will scan for specific tags—specifically Rows `(0028,0010)`, Columns `(0028,0011)`, and Pixel Data `(7FE0,0010)`—to extract metadata and raw pixel bytes. If the pixel data is encapsulated (e.g., JPEG), the parser will extract the byte stream and decode it using `cv2.imdecode`.
*   **Fail-Loud Validation:** The data loader will include an immediate assertion that the loaded image array is not empty and has a non-zero mean. If parsing fails, it will raise a critical exception rather than returning a zero-tensor, preventing the "silent failure" scenario where the model trains on black images. **Cite {solution_lesson_node_00001}**.
*   **Centralized Metadata Utility:** I will create a single function, `load_image_and_metadata(path)`, used by *both* the training dataset and the inference script. This ensures that the "original dimensions" used to normalize targets during training are identical to those used to rescale predictions during evaluation, preventing the coordinate space mismatch that previously resulted in 0.0 mAP. **Cite {solution_lesson_node_00003}**.

### Training
*   **Loss Function:** A multi-task loss combining:
    *   **Focal Loss** for the heatmap (handling class imbalance).
    *   **L1 Loss** for box size and offset regression.
    *   **Binary Cross-Entropy** for the new Global Classification head.
*   **Strategy:** The model will be trained with the AdamW optimizer. I will use a "warm-up" period for the learning rate, followed by a Cosine Annealing schedule to stabilize convergence on the new architecture.

### Evaluation
1.  **Loading:** Use the centralized `load_image_and_metadata` to retrieve the test image and its original $(W_{orig}, H_{orig})$.
2.  **Inference:**
    *   Pass the resized image through the model.
    *   Check the **Global Classification Head**. If the probability of "No Finding" exceeds a high threshold (e.g., 0.8), immediately predict the "No finding" string (`14 1 0 0 1 1`).
    *   Otherwise, decode the heatmap peaks into bounding boxes.
3.  **Rescaling:** Map the predicted boxes from the model's input scale $(W_{input}, H_{input})$ back to $(W_{orig}, H_{orig})$ using the dimensions retrieved in step 1. This ensures the submitted boxes align with the ground truth. **Cite {solution_lesson_node_00003}**.
