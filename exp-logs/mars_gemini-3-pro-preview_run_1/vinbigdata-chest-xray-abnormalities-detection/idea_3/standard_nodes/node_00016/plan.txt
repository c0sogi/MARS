This solution implements a complete training and evaluation pipeline for the **Spatially-Aware EfficientNet-B3 CenterNet**.

### Strategy Outline
1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and detect the computation device (A100 GPU).
2.  **Data Subsampling**: To satisfy the "fast baseline" requirement within the 2-hour limit, the script generates a stratified subset of the training data (2,500 images) and saves it as a temporary metadata file. This ensures the model sees a representative distribution of classes without processing the entire dataset.
3.  **Model Initialization**: Instantiate the `SpatiallyAwareCenterNet` which integrates CoordinateConv and BiFPN with an EfficientNet-B3 backbone.
4.  **Training Loop**: Execute a training run for 5 epochs using the subsampled data. The `train_model` function handles the optimizer (AdamW), scheduler (Cosine Annealing), and validation monitoring.
5.  **Validation & Metrics**: Load the best-performing model checkpoint and evaluate it on the **full** validation set to compute the PASCAL VOC mAP. The result is printed in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Perform a granular analysis on the validation set by computing the loss for individual images and correlating it with metadata features (e.g., number of ground truth boxes, bounding box area, aspect ratio). This identifies systematic weaknesses (e.g., if the model struggles with small objects or crowded images).
7.  **Submission**: If the validation mAP exceeds the threshold (0.1783551866), generate predictions for the test set using the `predict_and_submit` engine function, which handles global gating ("No finding" logic) and coordinate rescaling.
