The issue is caused by a security feature in PyTorch 2.6+ where `torch.load` defaults to `weights_only=True`. The model checkpoint contains a NumPy scalar (the validation mAP score) which is not in the default allowlist, causing a `_pickle.UnpicklingError`.

To fix this:
1.  In `runfile.py`, I will modify the `torch.load` call to explicitly set `weights_only=False`. This permits loading the checkpoint containing the NumPy scalar.
2.  In `library/utils.py`, I will update `save_checkpoint` to cast the score to a standard Python `float` before saving. This ensures future checkpoints do not contain NumPy types, making them compatible with strict security settings. I will also update `load_checkpoint` to use `weights_only=False` for robustness.
