This script demonstrates the end-to-end pipeline for the thoracic disease detection task using the provided library files. It performs the following steps:
1.  **Environment Setup**: Monkey-patches `tqdm` to silence progress bars and sets random seeds for reproducibility.
2.  **Data Preparation**: Creates a tiny subset of the training, validation, and test metadata to ensure the demonstration runs quickly (within minutes) while exercising all logic.
3.  **Configuration**: Overrides default `Config` parameters (paths, epochs, batch size) to adapt to the tiny dataset.
4.  **Data Loading**: Instantiates the `ThoracicDataset` and `DataLoader` via `get_dataloaders` and verifies the structure and shapes of the generated batches.
5.  **Model Initialization**: Instantiates the `SpatiallyAwareCenterNet` model and verifies the output shapes of its heads (heatmap, size, offset, global classification).
6.  **Training Loop**: Executes a full training cycle for 1 epoch using `train_model`, verifying that the loss is calculated and the model weights are updated.
7.  **Evaluation**: Runs the evaluation loop on the validation subset to compute the mAP score.
8.  **Inference**: Generates predictions on the test subset using `predict_and_submit` and verifies the format of the output submission file.
