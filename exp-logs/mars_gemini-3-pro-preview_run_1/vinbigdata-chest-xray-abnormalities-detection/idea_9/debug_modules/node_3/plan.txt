When this float is used to index the NumPy heatmap array `hm` in the line `draw_gaussian(hm[cls_id], ...)`, it triggers an `IndexError` because NumPy arrays require integer indices. To fix this, I will explicitly cast `cls_id` to an integer immediately after unpacking it in the loop, ensuring it is a valid index type (Cite debug_lesson_7).
