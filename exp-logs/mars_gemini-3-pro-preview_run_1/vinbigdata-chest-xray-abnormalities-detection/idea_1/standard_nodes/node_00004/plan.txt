Implementation Strategy:
1.  **Robust Data Ingestion (Cite solution_lesson_node_00001):** Implement a custom, manual DICOM parser in a new file `library/data_utils.py`. This bypasses the missing `pydicom` dependency and the failure of `opencv`/`rasterio` to read the specific DICOM format, ensuring the model trains on actual pixel data instead of black images.
2.  **Centralized Data Access (Cite solution_lesson_node_00003):** Update `library/dataset.py` to use this new parser for loading training images. Crucially, update `library/trainer.py` and `runfile.py` to use the same parser to retrieve original image dimensions. This fixes the coordinate space mismatch that caused the 0.0 mAP by ensuring bounding boxes are rescaled correctly during evaluation.
3.  **Hyperparameter Tuning:** Increase `NUM_EPOCHS` from 5 to 10 in `runfile.py` to allow the model sufficient time to converge on the real image features, balancing the 4-hour runtime limit.

import numpy as np
import os

def read_dicom(path):
    """
    Manually reads a DICOM file to extract pixel data and dimensions.
    This is a robust fallback for environments where pydicom is missing.
    Assumes uncompressed pixel data located at the end of the file.
    """
    try:
        with open(path, 'rb') as f:
            data = f.read()
            
        # Helper to find tag value (Simple Heuristic)
        # Rows: (0028, 0010) -> b'\x28\x00\x10\x00'
        # Cols: (0028, 0011) -> b'\x28\x00\x11\x00'
        
        def get_short_value(tag_bytes, data):
            idx = data.find(tag_bytes)
            if idx == -1: return None
            # Skip Tag (4)
            # Heuristic: Try to find the value in the next 12 bytes
            # Explicit VR might have 2 bytes VR + 2 bytes len, or 2 bytes VR + 2 reserved + 4 len
            # Implicit VR has 4 bytes len
            # We just look for the value which is likely 2 bytes at offset 8 or similar.
            # A safer way for Rows/Cols (US) is to look for the value at offset 8 (Implicit) or 8 (Explicit US)
            # If explicit US: Tag(4) + 'US'(2) + Len(2) + Val(2) -> Offset 8
            # If implicit: Tag(4) + Len(4) + Val(2) -> Offset 8
            # So offset 8 is a good bet for US.
            try:
                return int.from_bytes(data[idx+8:idx+10], 'little')
            except:
                return None

        rows = get_short_value(b'\x28\x00\x10\x00', data)
        cols = get_short_value(b'\x28\x00\x11\x00', data)
        
        if rows is None or cols is None:
            return None, (None, None)
            
        # Pixel Data Tag (7FE0, 0010)
        # We assume data is at the end of the file for uncompressed DICOM
        expected_pixels = rows * cols
        expected_bytes = expected_pixels * 2 # Assuming 16-bit
        
        if len(data) >= expected_bytes:
            # Take from end
            pixel_bytes = data[-expected_bytes:]
            img = np.frombuffer(pixel_bytes, dtype=np.uint16).reshape((rows, cols))
            
            # Check Photometric Interpretation for MONOCHROME1 (0 is white)
            # Tag (0028, 0004)
            mono_idx = data.find(b'\x28\x00\x04\x00')
            if mono_idx != -1:
                # Search nearby for "MONOCHROME1"
                chunk = data[mono_idx:mono_idx+50]
                if b'MONOCHROME1' in chunk:
                    img = np.max(img) - img
            
            return img, (rows, cols)
            
        return None, (rows, cols)
        
    except Exception:
        return None, (None, None)
