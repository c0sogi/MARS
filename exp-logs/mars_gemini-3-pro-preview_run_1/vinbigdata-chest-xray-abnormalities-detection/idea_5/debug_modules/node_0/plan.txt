The following script demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Setup**: Configures the environment, sets random seeds, and creates a temporary "mini-dataset" by subsetting the provided metadata files. This ensures the demonstration runs quickly.
2.  **Data Loading Verification**: Tests the `DicomParser` and `VinBigDataset` to ensure images and annotations are loaded and transformed correctly.
3.  **Model & Loss Verification**: Instantiates the `SpatiallyAwareCenterNet` and passes a batch of data through it. It then calculates the loss using `CenterNetLoss` to verify the backward pass connectivity.
4.  **Training Loop**: Runs a single epoch of training on the mini-dataset using the `train_one_epoch` function.
5.  **Inference**: Runs the inference pipeline on the mini-test set, including decoding predictions and formatting the submission string.
