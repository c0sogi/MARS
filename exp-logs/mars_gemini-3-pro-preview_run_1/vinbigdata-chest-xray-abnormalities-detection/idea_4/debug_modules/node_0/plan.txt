### Implementation Strategy

1.  **Configuration Override**: To ensure the demonstration runs quickly and uses the provided resources efficiently, I will modify the static attributes of the `Config` class at runtime. This includes reducing the number of epochs to 1, setting a small batch size, and redirecting data paths to temporary subset files created in the `./working` directory.
2.  **Data Subsetting**: I will load the original metadata files (`train_meta.csv`, `val_meta.csv`, `test_meta.csv`), sample a small fraction of rows (e.g., 20 samples), and save these as temporary CSVs. This allows the heavy `train.py` and `inference.py` logic to run on a tiny dataset, verifying the pipeline without waiting for full training.
3.  **Component Verification**: I will systematically verify each component:
    *   **Utils**: Verify DICOM image reading and dimension extraction.
    *   **Dataset**: Instantiate the `ThoraxDataset`, retrieve a sample, and assert the shapes of the generated CenterNet targets (heatmap, width/height, regression, indices).
    *   **Model**: Instantiate `AnatomicalCenterNet`, perform a forward pass with the sample batch, and verify output shapes.
    *   **Loss**: Calculate the loss using `CenterNetLoss` and assert it produces a valid scalar.
4.  **Integration Testing**:
    *   **Training**: Call `run_training()` to execute a full training epoch on the subset. I will verify that model checkpoints are successfully saved.
    *   **Inference**: Call `predict_and_format()` to generate predictions on the test subset and verify the output submission file format.
5.  **Reproducibility**: `seed_everything` will be called at the start to ensure consistent results.
