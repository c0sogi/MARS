### Implementation Strategy

1.  **Configuration Setup**: Import the `CFG` class from `library.config` and override specific parameters to enable "Debug Mode". This includes setting `debug = True` (to use small data subsets), reducing `epochs` to 1, and selecting a single model architecture to minimize runtime while ensuring all components are exercised.
2.  **Data Pipeline Verification**:
    *   Execute `prepare_data` to generate cross-validation folds and assert that the resulting DataFrame contains the necessary 'fold' column.
    *   Initialize `get_loaders` for a specific fold and fetch a single batch.
    *   Validate the tensor shapes of the images and labels to ensure the data augmentation and loading logic works correctly.
3.  **Model Architecture Verification**:
    *   Instantiate the model using `get_model`.
    *   Perform a dummy forward pass with the batch fetched previously to verify the input-output dimensions (specifically ensuring the output is a logit of shape `[batch_size, 1]`).
4.  **Training Loop Execution**:
    *   Run `train_fold` for a single fold. This function encapsulates the optimizer setup, mixed-precision training, validation, and checkpoint saving.
    *   Since `debug=True` and `epochs=1`, this will run very quickly on a small subset of data.
    *   Assert that the training completes and returns a valid validation score.
5.  **Inference and Submission**:
    *   Load the test data using `get_test_loader`.
    *   Perform inference using the trained model via the `inference` function.
    *   Verify that the number of predictions matches the number of test samples.
    *   Construct a submission DataFrame and verify its format against the requirements.
