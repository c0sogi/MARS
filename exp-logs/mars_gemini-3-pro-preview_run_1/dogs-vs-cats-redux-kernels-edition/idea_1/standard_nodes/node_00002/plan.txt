4.  **Training Engine (`library/engine.py`)**: Integrate `CosineAnnealingLR` scheduler to smoothly decay the learning rate, helping the model settle into a better optimum.
5.  **Execution (`runfile.py`)**: Add the required conditional logic to only generate a submission if the validation metric improves upon the baseline.
