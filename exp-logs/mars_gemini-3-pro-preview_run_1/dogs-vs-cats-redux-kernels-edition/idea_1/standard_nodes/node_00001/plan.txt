Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` object, overriding defaults to ensure a fast runtime (e.g., reducing epochs to 2). Set random seeds for reproducibility.
2.  **Model Training**: Use `train_model` from `library.engine` to fine-tune the EfficientNetV2-B0 model on the training set. This function handles the training loop, mixed-precision optimization, and saving the best model based on validation loss.
3.  **Validation & Metric Calculation**:
    *   Re-instantiate the validation DataLoader.
    *   Perform inference on the full validation set using the trained model in evaluation mode.
    *   Calculate the **Log Loss** metric using `sklearn.metrics.log_loss` and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the absolute error for each validation sample (`|label - prediction|`).
    *   Extract metadata features (image width, height, file size) by iterating through the validation files.
    *   Calculate and print the Pearson correlation between the error magnitude and these features to identify potential sources of systematic error.
5.  **Submission Generation**: Invoke `predict_and_submit` from `library.engine` to generate predictions for the test set and save the `submission.csv` file.
