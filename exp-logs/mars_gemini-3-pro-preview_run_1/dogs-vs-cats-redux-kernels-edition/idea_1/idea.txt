To establish a robust and highly efficient baseline for the Dog vs. Cat classification task, I propose a solution based on **Transfer Learning with a Lightweight CNN**. This approach prioritizes rapid experimentation and low computational cost while leveraging the architectural efficiency concepts found in the provided model descriptions.

### Model
The architecture will be a **Scaled-Down Fused-MBConv CNN** (specifically the **EfficientNetV2-B0** variant). 
*   **Conceptual Foundation**: This model draws directly from the design of Model 1 (EfficientNetV2-S) but utilizes the smallest compound scaling configuration ("B0") to minimize parameter count and maximize inference speed. It retains the core **Fused-MBConv** building blocks, which replace standard depthwise separable convolutions in early layers with standard convolutions followed by expansion, optimizing memory access patterns on the A100 GPU.
*   **Head Design**: The complex classification heads often used in larger models will be replaced with a single **Global Average Pooling** layer followed by a **Linear layer** with one output unit.
*   **Initialization**: The backbone will be initialized with weights pre-trained on ImageNet, allowing the model to leverage learned texture and shape features (like fur patterns and ear shapes) immediately, rather than learning from scratch.

### Data
*   **Preprocessing**: All images will be resized to a fixed, compact resolution of **224x224** pixels. Pixel values will be normalized using the standard ImageNet mean and standard deviation to align with the pre-trained weights.
*   **Augmentation**: To maintain simplicity and speed, data augmentation will be strictly limited to **Random Horizontal Flips** during training. This introduces basic invariance to orientation without the computational overhead of complex geometric transformations.
*   **Validation Split**: The pre-generated validation split (from `metadata/val.csv`) will be used to monitor performance.

### Training
*   **Loss Function**: The model will be trained using **Binary Cross-Entropy with Logits Loss**, directly optimizing the competition metric (Log Loss).
*   **Optimizer**: The **AdamW** optimizer will be used for its ability to handle weight decay effectively, with a default learning rate (e.g., 1e-3).
*   **Strategy**: 
    *   **Mixed Precision**: Automatic Mixed Precision (AMP) will be enabled to reduce memory usage and speed up training on the A100.
    *   **Standard Fine-tuning**: Unlike Model 1's progressive learning, this baseline will use a fixed image size and regularization strength throughout training. The entire model will be fine-tuned (rather than just the head) to allow the feature extractors to adapt to the specific domain of dogs and cats.
    *   **Early Stopping**: Training will run for a small fixed number of epochs (e.g., 3-5), stopping early if validation loss plateaus, ensuring the runtime remains minimal.

### Evaluation
*   **Inference**: Test images will be resized to 224x224 and normalized using the same statistics as the training set.
*   **Prediction**: The model will output raw logits, which will be passed through a **Sigmoid activation function** to generate probabilities in the [0, 1] range.
*   **Submission**: These probabilities will be mapped to the corresponding image IDs and saved to the submission CSV file.
