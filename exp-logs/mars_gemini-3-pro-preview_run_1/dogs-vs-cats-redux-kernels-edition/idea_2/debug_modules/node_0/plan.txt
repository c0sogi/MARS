The following script demonstrates the usage of the provided library files for the Dog vs. Cat classification task.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes at runtime to adapt the pipeline for a quick demonstration (e.g., disabling pretrained weights to save download time, reducing image size for speed, and setting a temporary working directory).
2.  **Component Verification**:
    *   **Dataset**: We instantiate the `DogCatDataset` with a small sample of the metadata and verify that it yields tensors of the correct shape and data type.
    *   **Model**: We instantiate the `DogCatClassifier`, perform a forward pass with dummy data, and assert that the output logits have the expected dimensions.
3.  **Pipeline Execution**: We execute the `run_training_pipeline` function in `debug` mode with minimal epochs (1) and folds (2). This validates the end-to-end training loop, including data loading, mixed-precision training, validation, checkpoint saving, and ensemble inference.
4.  **Output Validation**: Finally, we inspect the generated `submission.csv` to ensure it follows the required format (ID column and probability column) and that predictions are within the valid probability range [0, 1].
