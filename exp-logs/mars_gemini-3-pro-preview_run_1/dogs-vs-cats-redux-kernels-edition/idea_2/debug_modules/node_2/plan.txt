The `FileNotFoundError` occurs because the `save_checkpoint` function in `library/utils.py` uses a default argument for `folder` (`Config.model_dir`) that is evaluated at import time. When `runfile.py` updates `Config.model_dir` at runtime, the `save_checkpoint` function continues to use the old path (bound at import) when called without an explicit `folder` argument. Consequently, the model is saved to the old directory (`./working/idea_2/models`), but the training pipeline attempts to load it from the new directory (`./working/demo_execution/models`).

To fix this, I will modify `library/trainer.py` to explicitly pass `folder=Config.model_dir` when calling `save_checkpoint`. This ensures the function uses the current runtime value of the configuration path.
