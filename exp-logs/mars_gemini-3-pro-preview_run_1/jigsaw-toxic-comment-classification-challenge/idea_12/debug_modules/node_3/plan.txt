The execution failure is caused by the use of `-1e9` as a masking constant, which overflows the range of `float16` (Half Precision) used during mixed-precision training (Cite debug_lesson_8). The `float16` format has a minimum value of approximately -65,504, so -1,000,000,000 causes a runtime error when cast to half precision. To fix this, I will replace all instances of `-1e9` in `library/model.py` with `-1e4` (-10,000), which is small enough to ensure the softmax output is effectively zero while remaining safely within the `float16` dynamic range.
