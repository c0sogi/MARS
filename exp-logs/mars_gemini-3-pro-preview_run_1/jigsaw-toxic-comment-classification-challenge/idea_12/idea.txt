# Solution: Domain-Adapted DeBERTa-v3 with Consistency-Regularized Self-Distillation

## Model
I propose a robust architecture designed to maximize signal extraction and generalization, specifically tailored to the "noisy" nature of toxicity classification.

1.  **Backbone (Strategic Retention):** We will utilize **DeBERTa-v3-base**. This model outperforms RNNs (Cite solution_lesson_node_00007) and offers superior context understanding via disentangled attention. We explicitly select the "Base" variant to ensure we can execute the computationally intensive multi-stage pipeline on the **full dataset** within the 24-hour limit, prioritizing data coverage over parameter count (Cite solution_lesson_node_00014).
2.  **Weighted Layer Aggregation (Strategic Retention):** We will implement a **learnable weighted sum of the last 4 encoder layers**. Lesson 00009 highlighted that lower layers contain critical lexical information (slang, profanity) that must be adapted. Aggregating these layers provides the classification head with direct access to these raw signals alongside high-level semantics (Cite solution_lesson_node_00009).
3.  **Hybrid Pooling Head (Strategic Retention):** We will apply the proven hybrid pooling strategy to the aggregated representation:
    *   **Global Max Pooling:** To extract the strongest local toxic signal (e.g., a specific slur) regardless of context (Cite solution_lesson_node_00001).
    *   **Linear Attention Pooling:** To compute a context-aware weighted average, prioritizing relevant tokens while filtering noise (Cite solution_lesson_node_00002). We will use simple **Linear Attention** ($w^T h_t$) for efficient convergence (Cite solution_lesson_node_00003).
    *   These two vectors will be concatenated.
4.  **Multi-Sample Dropout (Strategic Retention):** The concatenated vector will pass through 5 parallel dropout masks to smooth the loss landscape (Cite solution_lesson_node_00016).

## Data
1.  **Tokenization (Strategic Retention):** We will use the **DeBERTa-v3 Tokenizer** (SentencePiece). This preserves punctuation and special characters (e.g., "!!", "f**k") as distinct tokens, which are critical features for detecting emotional intensity and obfuscated toxicity (Cite solution_lesson_node_00004).
2.  **Unsupervised Corpus:** We will concatenate `train.csv` and `test.csv` to create a domain-specific corpus for pre-training.
3.  **Pseudo-Labeled Dataset:** For the final training stage, we will combine the original training data with the test data, assigning **soft labels** (probability vectors) to the test samples based on predictions from the "Teacher" ensemble.

## Training
I propose a **Three-Stage Training Pipeline** with a structural innovation in the final stage to ensure robustness.

**Stage 1: Domain-Adaptive Pre-training (DAPT)**
*   **Objective:** Fine-tune the DeBERTa-v3 backbone on the combined (train + test) corpus using **Masked Language Modeling (MLM)** for 3 epochs.
*   **Rationale:** This adapts the tokenizer embeddings and lower layers to the specific toxic vocabulary of the dataset before supervised learning begins, addressing the lexical gap identified in Lesson 00009 without the risks of Layer-wise Learning Rate Decay.

**Stage 2: Teacher Training (Robust Supervised CV)**
*   **Strategy:** Fine-tune the DAPT backbone using **5-Fold Cross-Validation** on the labeled training set.
*   **Optimization:** Use **AdamW** with a **Uniform Learning Rate** (rejecting Layer-wise Decay to allow lower layers to adapt, Cite solution_lesson_node_00009).
*   **Robustness:** Implement **Adversarial Weight Perturbation (AWP)** starting from epoch 2. This perturbs weights to maximize loss during training, forcing the model to find flatter, more robust minima (Cite solution_lesson_node_00018).
*   **Scheduling:** Use **OneCycleLR** with a duration of 5 epochs per fold to avoid the performance degradation of compressed schedules (Cite solution_lesson_node_00006).

**Stage 3: Student Training (Consistency-Regularized Self-Distillation)**
*   **Structural Innovation:** We will train a Student model on the **combined dataset** (Train + Soft-Labeled Test). Unlike standard self-training, we will incorporate **R-Drop (Consistency Regularization)**.
*   **Mechanism:** For each input batch, we perform **two forward passes** with the same model weights but different dropout masks.
*   **Loss Function:** $L_{total} = L_{BCE}(\text{SoftTargets}) + \alpha \cdot L_{KL}(P_1 || P_2)$.
*   **Rationale:** The KL-divergence term forces the model to be invariant to dropout noise, smoothing the decision boundary and preventing the student from overfitting to the noise inherent in the teacher's pseudo-labels. This acts as a powerful regularizer synergistic with AWP.
*   **Configuration:** Train for 5 epochs on the combined dataset using AWP and Uniform LR.

## Evaluation
1.  **Inference:** Generate predictions for the test set using the **Stage 3 (Student)** model.
2.  **Submission:** Format the probabilities into the required CSV structure. By training on the test set with soft labels and consistency regularization, the Student model effectively learns the manifold of the test data, providing superior transductive predictions compared to a purely inductive model.
