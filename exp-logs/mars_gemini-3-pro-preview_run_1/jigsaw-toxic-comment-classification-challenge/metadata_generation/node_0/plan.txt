The following script generates metadata for the training, validation, and test sets without copying the raw text data. It performs a stratified 80:20 split on the training data using a label-combination strategy to ensure balanced multi-label distribution. The metadata files contain IDs, labels (for train/val), and a relative reference to the source file in the input directory. Finally, the script verifies the generated metadata by loading the datasets, checking file path validity, and asserting that the split ratios and distributions are correct.
