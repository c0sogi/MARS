This script demonstrates the end-to-end usage of the provided library components for the toxic comment classification task. It covers configuration setup, data loading for different stages (DAPT, Teacher, Student, Inference), model initialization, and the execution of training and validation loops.

To ensure the demonstration runs quickly and efficiently within the constraints, the `Config` is initialized in debug mode with a very small sample size (50 samples) and minimal epochs. This allows verification of the pipeline logic without waiting for full model convergence.
