The previous execution failed with a `torch.OutOfMemoryError` during the DAPT stage because the `train_batch_size` of 32 (resulting in ~4GB for logits alone) plus model overhead exceeded the 16GB VRAM of the A100 GPU. The error analysis correctly identified the need to decouple the physical batch size from the effective batch size using Gradient Accumulation and to use Automatic Mixed Precision (AMP). Additionally, the debugging lessons highlighted that hardcoded masking values like `-1e9` can cause overflows in FP16 (AMP), requiring a change to `-1e4`.

Here is the plan to fix the issue:

1.  **`library/config.py`**: Reduce `train_batch_size` to 8 (micro-batch size) and set `accumulation_steps` to 4 to maintain an effective batch size of 32. Reduce `valid_batch_size` to 16 to ensure safety.
2.  **`library/model.py`**: Update `LinearAttentionPooling` and `CustomModel` to use `-1e4` instead of `-1e9` for masking, preventing FP16 overflow (Cite {debug_lesson_1}).
3.  **`library/engine.py`**: Implement Gradient Accumulation and AMP (`torch.cuda.amp`) in `train_mlm` and `train_fn`. For `train_fn`, adapt the AWP logic to accumulate adversarial gradients per micro-batch (Cite {debug_lesson_5}).

    """
    Trains the classification model (Teacher or Student) with optional AWP.
    """
    model.train()
    losses = AverageMeter()
    start = time.time()
    scaler = torch.cuda.amp.GradScaler()

    # Initialize AWP if configured
    awp = None
    if config.use_awp and epoch >= config.awp_start_epoch:
        awp = AWP(model, optimizer, adv_lr=config.awp_lr, adv_eps=config.awp_eps)

    criterion = nn.BCEWithLogitsLoss()

    print(f"\n[Train] Epoch {epoch + 1} Training...")

    for step, batch in enumerate(dataloader):
        input_ids = batch["input_ids"].to(device)
        attention_mask = batch["attention_mask"].to(device)
        labels = batch["labels"].to(device)

        batch_size = input_ids.size(0)

        with torch.cuda.amp.autocast():
            y_preds = model(input_ids, attention_mask)
            loss = criterion(y_preds, labels)
        
        losses.update(loss.item(), batch_size)

        # If AWP is active, we need to handle gradients carefully
        if awp is not None:
            # 1. Compute standard gradients to guide perturbation
            scaler.scale(loss).backward()
            scaler.unscale_(optimizer) # Unscale for AWP to see real grad magnitudes
            
            # 2. Perturb weights
            awp.attack_step()
            
            # 3. Clear standard gradients (we will accumulate adversarial ones)
            optimizer.zero_grad()
            
            # 4. Compute adversarial loss
            with torch.cuda.amp.autocast():
                y_preds_adv = model(input_ids, attention_mask)
                loss_adv = criterion(y_preds_adv, labels)
                loss_final = loss_adv / config.accumulation_steps
            
            # 5. Accumulate adversarial gradients
            scaler.scale(loss_final).backward()
            
            # 6. Restore weights
            awp.restore()
        else:
            # Standard Path: Just accumulate standard gradients
            loss_final = loss / config.accumulation_steps
            scaler.scale(loss_final).backward()

        if (step + 1) % config.accumulation_steps == 0:
            scaler.unscale_(optimizer)
            torch.nn.utils.clip_grad_norm_(model.parameters(), config.max_grad_norm)
