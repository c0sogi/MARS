The `KeyError: 'layer_weights'` occurs because the `AWP` instance attempts to access perturbation bounds in `_attack_step` that have not yet been computed or stored. The `_save` method is responsible for backing up the original weights and calculating these bounds (`self.backup_eps`), but it is never called in the training loop. To fix this, I will add a call to `awp._save()` inside `train_fn` in `library/engine.py` immediately before `awp._attack_step()` is executed.
