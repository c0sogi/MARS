To address the `torch.OutOfMemoryError`, I will implement Automatic Mixed Precision (AMP) in `library/trainer.py`, which significantly reduces memory usage by performing operations in half-precision where safe. I will also reduce the `train_batch_size` in `library/config.py` from 32 to 16 to ensure the model fits within the available VRAM. Crucially, I will update the masking constants in `library/model.py` from `-1e9` to `-1e4`. As noted in **debug_lesson_1**, using `-1e9` in FP16 contexts causes numerical overflow (`value cannot be converted to type at::Half without overflow`), so adjusting this constant is required when enabling AMP.
