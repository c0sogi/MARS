# Context-Aware Transformer with Hybrid Signal Aggregation

## Model
I propose a fundamental structural evolution by replacing the Recurrent Neural Network (RNN) backbone with a **Pre-trained Transformer Encoder** (specifically **RoBERTa-base**), while retaining the highly effective custom aggregation strategy developed in previous iterations.

1.  **Backbone (Structural Innovation):** The static embeddings and BiGRU layers will be replaced by the **RoBERTa-base** architecture. Unlike the GRU, which processes text sequentially, the Transformer utilizes multi-head self-attention to capture deep, bidirectional, and contextual relationships between words, offering a significantly richer representation of the input text.
2.  **Hybrid Aggregation Head (Strategic Retention):** We will **not** use the standard `[CLS]` token for classification, as it can act as an information bottleneck. Instead, we will apply the successful pooling strategy derived from the lessons to the sequence of hidden states output by the Transformer:
    *   **Global Max Pooling:** We will extract the maximum value across the sequence dimension for each feature. This preserves the strongest activation (e.g., a specific slur), ensuring the model remains sensitive to local toxic signals regardless of context (Cite solution_lesson_node_00001).
    *   **Linear Attention Pooling:** We will compute a weighted sum of the hidden states using a learned **Linear Attention** mechanism ($w^T h_t$). This allows the model to dynamically prioritize relevant tokens for the global context representation without the complexity and slow convergence of non-linear attention (Cite solution_lesson_node_00002, solution_lesson_node_00003).
    *   **Concatenation:** These two vectors (Max Pool and Attention Pool) will be concatenated to form the final representation passed to the dense classification layers.

## Data
1.  **Subword Tokenization:** We will utilize the pre-trained **RoBERTa Tokenizer** (Byte-Level BPE). This tokenizer inherently addresses the need to treat punctuation as features (Cite solution_lesson_node_00004) by encoding punctuation marks as distinct tokens rather than stripping them. It also handles out-of-vocabulary words by breaking them into subwords, preserving semantic meaning for rare or obfuscated toxic terms.
2.  **Formatting:** Input sequences will be tokenized and padded/truncated to a fixed length (e.g., 256 tokens) to fit the Transformer's input requirements, generating `input_ids` and `attention_mask` tensors.

## Training
1.  **Optimization:** We will use the **AdamW** optimizer, which is standard for fine-tuning Transformers, with a weight decay to prevent overfitting.
2.  **Loss Function:** Binary Cross-Entropy (BCE) with Logits will be used for the multi-label classification task.
3.  **Scheduling:** We will implement a learning rate schedule with a **linear warmup** followed by a decay. Crucially, we will ensure the training duration (epochs) is sufficient to allow for gradual convergence, avoiding the performance degradation observed when compressing the decay schedule too aggressively (Cite solution_lesson_node_00006).
4.  **Regularization:** Dropout will be applied within the Transformer and before the final dense layer.

## Evaluation
The evaluation process remains consistent with previous iterations. The test set will be processed using the RoBERTa tokenizer with the same configuration as the training set. The model will predict six probabilities for each comment, which will be saved to a CSV file matching the submission format.
