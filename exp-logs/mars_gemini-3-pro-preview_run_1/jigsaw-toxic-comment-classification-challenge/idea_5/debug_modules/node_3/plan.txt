The `RuntimeError: Trying to backward through the graph a second time` is caused by a conflict between **Gradient Checkpointing** and the **Weighted Layer Pooling** mechanism which aggregates multiple hidden layers. Gradient checkpointing optimizes memory by discarding intermediate activations and recomputing them during the backward pass, but this interferes with the computation graph when the model explicitly retains and combines multiple intermediate outputs (`hidden_states`) for the pooling layer. As noted in the error analysis, this is a known incompatibility (Cite debug_lesson_5). To fix this, I will disable gradient checkpointing in `library/model.py`. Given the A100 GPU and small batch size, the model will fit in memory without this optimization.
