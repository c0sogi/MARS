Implementation strategy:
1.  **Setup and Configuration**: Import necessary modules and the provided library functions. Set random seeds for reproducibility.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. We will adhere to the "Idea" by using the full dataset (no subsampling) and the default configuration (6 epochs), which fits comfortably within the 2-hour execution limit on an A100 GPU.
3.  **Validation**:
    *   Reload the validation dataset and the best saved model.
    *   Perform inference on the validation set to obtain predictions.
    *   Calculate and print the `Final Validation Metric` (Average ROC AUC) as required.
4.  **Failure Analysis**:
    *   Compute the Mean Absolute Error (MAE) for each sample in the validation set.
    *   Calculate the point-biserial correlation between the error magnitude and the presence of each target label to identify which catheter types are associated with higher model error.
    *   Print these correlations.
5.  **Submission**:
    *   Compare the final validation metric against the specified threshold (`0.9122773173141027`).
    *   If the metric exceeds the threshold, generate the submission file using `library.predict.inference_fn` targeting the `./submission` directory.
