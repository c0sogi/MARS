The `AssertionError: Model file not found` occurs because the training loop failed to save the model checkpoint. This happened because the validation metric (`val_auc`) was `nan` (as seen in the logs: `Valid AUC: nan`), causing the improvement check `if val_auc > best_auc` to evaluate to False. The `nan` value arises because `roc_auc_score` with `average='macro'` can return `nan` (instead of raising a `ValueError`) when the validation subset lacks class diversity (e.g., all zeros in a small debug sample), and the original code only caught `ValueError`.

To fix this, I will modify `get_score` in `library/utils.py` to explicitly check if the calculated score is `nan` or `None`. If so, it will trigger the fallback mechanism (column-wise calculation or default value), ensuring a valid float is always returned. This ensures the training loop can compare metrics and save the model, preventing the missing artifact error (Cite debug_lesson_1).
