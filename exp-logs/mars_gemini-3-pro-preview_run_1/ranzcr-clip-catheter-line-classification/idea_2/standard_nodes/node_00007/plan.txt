4.  **Metric Reporting**: Print the `Final Validation Metric` in the exact required format.
5.  **Failure Analysis**: Compute the Mean Absolute Error (MAE) for each validation sample. We will then extract basic image features (Width, Height, Aspect Ratio, Mean Intensity) by reading the validation images and calculate the Pearson correlation between these features and the error magnitude to identify potential biases.
6.  **Submission**: Compare the final validation metric against the threshold (0.9122773173141027). If the metric is higher, we call `library.inference.predict(debug=False)` to generate the submission file for the full test set.
