### Implementation Strategy

Specifically, I will reduce the `IMAGE_SIZE` to 256x256, set `BATCH_SIZE` to 4, and limit `NUM_EPOCHS` to 1. I will also disable pretrained weight downloading to ensure the script runs offline if necessary.
2.  **Utility Verification**: I will verify the `rle_decode` function by creating a simple Run-Length Encoded string and asserting the decoded mask matches the expected binary array.
3.  **Data Pipeline Verification**:
    *   Instantiate the `CatheterDataset` with a small `sample_size` (e.g., 16 samples) to test data loading, augmentation, and formatting without processing the entire dataset.
    *   Verify the `DataLoader` yields batches with the correct shapes for images (`B, 3, H, W`), masks (`B, 1, H, W`), and targets (`B, NumClasses`).
4.  **Model Architecture Verification**:
    *   Initialize the `MultiTaskEfficientNet` (with `pretrained=False` for speed).
    *   Perform a forward pass with a dummy batch to verify that the classification logits and segmentation logits are produced with the correct dimensions.
5.  **Loss Function Verification**:
    *   Initialize `MultiTaskLoss`.
    *   Compute the loss on the model outputs and verify that the returned dictionary contains the total loss and individual components (`cls_loss`, `seg_loss`), and that the total loss is a valid scalar with gradient history.
6.  **Training Loop Verification**:
    *   Run `train_one_epoch` using the small dataset subset. This confirms that the optimization step, gradient scaling (AMP), and backpropagation are functioning correctly.
    *   Run `valid_one_epoch` to check evaluation logic and metric calculation.
7.  **Inference Verification**:
    *   Execute `inference_fn` to demonstrate Test Time Augmentation (TTA) and prediction aggregation, asserting output shapes match the number of samples and classes.
