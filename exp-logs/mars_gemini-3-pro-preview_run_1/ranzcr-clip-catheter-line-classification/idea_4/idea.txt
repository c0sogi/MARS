# Solution: Multi-Task EfficientNetV2-S with Auxiliary Segmentation Supervision

### Model
We will implement a **Multi-Task Learning (MTL) architecture** that simultaneously performs classification and segmentation.
- **Backbone (Encoder):** We will retain the **EfficientNetV2-S** architecture. This model has proven to offer the optimal balance of capacity and training stability compared to larger variants like B4, while outperforming lightweight options like MobileNet on server-grade hardware **Cite solution_lesson_node_00002, solution_lesson_node_00007**.
- **Classification Head:** The encoder's final feature map will be processed by a **Generalized Mean (GeM) Pooling** layer. We will explicitly avoid manual FP32 casting within this layer to maintain optimal Mixed Precision performance **Cite solution_lesson_node_00012, solution_lesson_node_00016**. The pooled features will pass through a linear layer to predict the 11 target class probabilities.
- **Segmentation Head (Auxiliary):** We will attach a lightweight decoder (e.g., a Feature Pyramid Network or simplified U-Net block) to the encoder's intermediate stages. This head will predict pixel-wise binary masks of the catheters. This structural addition forces the encoder to retain fine-grained spatial information about thin structures—which is often lost in pure classification models—thereby improving the feature representation for the primary classification task **Cite solution_lesson_node_00015**.

### Data
The preprocessing pipeline will be enhanced to handle both images and segmentation masks.
- **Resolution:** Input images will be resized to **768x768**. Previous experiments confirmed that this high resolution is critical for resolving thin catheter lines, outweighing the cost of reduced batch sizes **Cite solution_lesson_node_00015**.
- **Mask Generation:** We will utilize the `train_annotations.csv` file to generate ground-truth binary masks for the ~60% of training samples that have segmentation data. For samples without annotations, we will generate empty placeholder masks and an internal flag to ignore them during loss calculation.
- **Augmentation:** We will apply consistent geometric augmentations (e.g., horizontal flips, slight rotations) to both the image and its corresponding mask. **CoarseDropout** will be applied to the images to encourage robust feature extraction **Cite solution_lesson_node_00012**.

### Training
The training strategy focuses on leveraging the auxiliary task while maintaining the stability established in previous lessons.
- **Loss Function:** We will minimize a composite loss: $L_{total} = L_{cls} + \lambda L_{seg}$.
    - $L_{cls}$: **BCEWithLogitsLoss** with `pos_weight` set to the inverse class frequency to handle the extreme class imbalance **Cite solution_lesson_node_00001**.
    - $L_{seg}$: Binary Cross Entropy or Dice Loss applied to the segmentation output. Crucially, this loss term will be multiplied by the validity flag (0 for unannotated images, 1 for annotated images) so that the model is only penalized on samples with ground truth.
- **Optimizer & Schedule:** We will use the **AdamW** optimizer with a **constant learning rate** (e.g., 1e-4). We will avoid aggressive decay schedules to prevent underfitting in the short training regime **Cite solution_lesson_node_00006**.
- **Efficiency:** We will train on the **full dataset** **Cite solution_lesson_node_00007** using **Automatic Mixed Precision (AMP)** to maximize throughput. We will also employ **Model Exponential Moving Average (EMA)** with a decay rate of **0.9995** (calibrated for short training runs) to improve generalization and stability **Cite solution_lesson_node_00013, solution_lesson_node_00014**.

### Evaluation
- **Inference:** Test images will be resized to **768x768** and passed through the trained network. We will only utilize the output of the classification head for the submission; the segmentation head is discarded at inference time.
- **TTA:** We will apply Test Time Augmentation by averaging the predictions of the original image and a horizontally flipped version to reduce variance **Cite solution_lesson_node_00012**.
