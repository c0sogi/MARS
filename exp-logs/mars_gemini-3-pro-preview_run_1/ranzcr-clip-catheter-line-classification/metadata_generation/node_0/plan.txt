The following Python script generates metadata files for the training, validation, and test datasets. It reads the raw CSV files from the `./input` directory, constructs relative file paths for the images, and splits the training data into training and validation sets using a Group Shuffle Split based on `PatientID` to prevent data leakage. The resulting metadata is saved to the `./metadata` directory. Finally, the script performs rigorous validation checks, including verifying file existence and ensuring no patient overlap between the training and validation splits.
