# Baseline Approach: Region-Aware ResNet-18

### Model
I propose a **Region-Aware ResNet-18**, which synthesizes the CNN backbone concept from Model 1 and the metadata integration strategy from Model 2 into a lightweight, end-to-end architecture.
*   **Backbone**: Use a **ResNet-18** pre-trained on ImageNet. This is significantly lighter and faster than the EfficientNet-B3 (Model 1) or Swin Transformer (Model 2), making it ideal for a baseline.
*   **Region Embedding**: To leverage the strong correlation between geography and species (observed in the EDA), I will introduce a learnable **Region Embedding** layer. This layer maps the categorical `region_id` (0-3) to a low-dimensional vector (e.g., dimension 16).
*   **Fusion & Classification**: The 512-dimensional feature vector from the ResNet Global Average Pooling layer will be concatenated with the 16-dimensional region embedding. This combined vector (528 dimensions) will be fed into a single fully connected linear layer to predict the 32,093 class logits.
*   **Activation**: Standard Softmax activation will be used for the final output.

### Data
*   **Preprocessing**: Images will be resized to **224x224** pixels to minimize computational overhead while retaining sufficient detail for classification. Pixel values will be normalized using standard ImageNet mean and standard deviation.
*   **Augmentation**: To maintain simplicity and speed, only **Random Horizontal Flip** will be applied during training. No heavy augmentations (like Mixup or CutMix) will be used.
*   **Input Handling**: The data loader will yield batches containing the image tensor, the integer `region_id`, and the target `category_id`.

### Training
*   **Loss Function**: Standard **Cross-Entropy Loss**. While the data is imbalanced, this serves as the most robust and simple starting point for a baseline.
*   **Optimizer**: **Adam** optimizer with a default learning rate (e.g., 1e-3) and weight decay.
*   **Procedure**: 
    1.  **Freeze-Then-Unfreeze**: For the first epoch, the ResNet backbone will be frozen, training only the randomly initialized embedding layer and classification head. This prevents the large gradients from the uninitialized head from destroying the pre-trained backbone weights.
    2.  **Fine-tuning**: For subsequent epochs (e.g., 5-10 epochs total), the entire network will be unfrozen and fine-tuned with a reduced learning rate.
*   **Hardware Utilization**: Given the A100 GPU and 224x224 input size, a large batch size (e.g., 256 or 512) will be used to maximize throughput and reduce training time.
