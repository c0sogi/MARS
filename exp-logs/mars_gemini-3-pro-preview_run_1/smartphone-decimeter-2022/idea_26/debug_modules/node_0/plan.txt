Implementation Strategy:
1.  **Setup and Configuration**: Import necessary libraries and the provided modules. Create a specific working directory for the demo (`./working/demo_run`). Monkey-patch the `library.config.Config` class to point to this directory and use "mini" metadata files to limit the data scope.
2.  **Mini Metadata Generation**: Read the original metadata files, sample a small subset (one drive for training/validation, one for testing), and save these as mini metadata files in the demo directory. This ensures the subsequent steps run quickly on real data.
3.  **Utility Verification**: Test the `WGS84` coordinate conversion functions with known values to ensure geometric logic is correct.
4.  **Preprocessing**: Instantiate `GNSSPreprocessor` (which will now use the patched Config). Run `generate_dataset` for train and test splits. Verify the output DataFrames are not empty.
5.  **Dataset Loading**: Create `GnssSequenceDataset` instances for training and validation using the processed data. Verify the shape of the tensors produced by `__getitem__`.
6.  **Model Initialization**: Instantiate the `PhaseAwareAttentionResUNet` model. Perform a dummy forward pass with random data to verify input/output shapes and deep supervision heads.
7.  **Loss Calculation**: Instantiate `DecimatedMAELoss`. Calculate loss on the dummy output to verify the weighting and masking logic.
8.  **Training Loop**: Initialize the `Trainer`. Run a minimal training session (1 epoch, small batch size) to demonstrate the training pipeline and ensure the model weights are saved.
9.  **Inference**: Use the trained model to generate a submission file for the mini test set using `generate_submission`. Verify the output file exists.
