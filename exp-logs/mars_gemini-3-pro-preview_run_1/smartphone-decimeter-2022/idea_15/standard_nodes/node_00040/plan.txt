The execution failure is caused by the validation data loader attempting to batch together sequences of different lengths. In the `GnssSequenceDataset`, validation samples correspond to full driving sessions which vary in duration, unlike training samples which are windowed to a fixed size. When `batch_size` is greater than 1 (default is 16), the default collate function fails to stack these variable-length tensors, raising a `RuntimeError`. To fix this, I will set the batch size for the validation and test data loaders to 1 in `runfile.py`, ensuring each batch contains only a single sequence and avoiding the need for stacking.
