Implementation Strategy:
1.  **Configuration**: Override `CFG.EPOCHS` to 5 to ensure the script completes within the time limit. Update `CFG.WORKING_DIR` to `./working` to utilize potential existing cache files.
2.  **Data Loading**: Use `get_train_val_datasets` with `load_cached_data=True` to load and scale training and validation data. Create PyTorch DataLoaders.
3.  **Model**: Initialize the `ResUNet1D` model defined in the library.
4.  **Training**: Execute `train_model` to train the network using the training set and monitor performance on the validation set.
5.  **Validation & Metric**:
    *   Run inference on the validation set.
    *   Map the predicted East/North offsets back to the original dataframe rows using indices.
    *   Convert offsets + WLS baseline to predicted Latitude/Longitude.
    *   Calculate the Haversine distance error for each point.
    *   Compute the competition metric: Mean of (Mean of (50th percentile error, 95th percentile error) per phone).
    *   Print the metric in the required format.
6.  **Failure Analysis**: Calculate Pearson correlations between the distance error and the input features to identify error drivers.
7.  **Submission**:
    *   Compare the validation metric against the threshold (3.80224).
    *   If the metric is lower, load the test dataset, run inference, reconstruct coordinates, and save the `submission.csv` file.
