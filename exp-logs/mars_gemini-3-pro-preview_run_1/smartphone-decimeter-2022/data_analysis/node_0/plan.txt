This script performs an Exploratory Data Analysis (EDA) on the training dataset for the Smartphone Decimeter Challenge. It focuses on the tabular nature of the sensor data (GNSS and IMU) and the ground truth targets.

**Strategy:**
1.  **Setup**: Initialize reproducible seeds and define paths.
2.  **Target Analysis**: Load the ground truth data using `metadata/train_metadata.csv`. Analyze the distribution, skewness, and kurtosis of `LatitudeDegrees` and `LongitudeDegrees`.
3.  **Input Analysis**: Due to the large volume of raw sensor logs, randomly sample 3 specific drives from the training set to represent the input data distribution.
    *   **GNSS**: Analyze numerical features like signal strength (`Cn0DbHz`) and pseudorange. Analyze categorical features like `ConstellationType`.
    *   **IMU**: Analyze accelerometer and gyroscope readings.
4.  **Relationship Analysis**: Construct a synchronized dataset from the sampled drives. Aggregate GNSS measurements (e.g., mean signal strength per epoch) and align them with Ground Truth timestamps to calculate correlations and feature importance using a Random Forest regressor.
5.  **Output**: Format the results into a clear, text-based report.
