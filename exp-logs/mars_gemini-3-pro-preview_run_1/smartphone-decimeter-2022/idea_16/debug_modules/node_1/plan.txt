The following changes address the `RuntimeError` caused by a channel dimension mismatch in the ASPP module and the "Empty Dataset" issue caused by timestamp mismatches during data loading.

1.  **`library/model.py`**: The `ASPP` class incorrectly calculated `num_branches` by including dilation rate `1` in the count, even though the loop explicitly skips it (since a 1x1 convolution branch is added separately). This caused the projection layer to expect more channels than were actually concatenated. I corrected the calculation to exclude skipped dilations, ensuring the input channels match the actual runtime concatenation (Cite `debug_lesson_15`).

2.  **`library/data_loader.py`**: The training data loading failed because the Ground Truth timestamps (millisecond precision) were not aligned with the processed GNSS timestamps (rounded to 1Hz). I added a rounding step to the Ground Truth timestamps before merging to ensure the join keys overlap, preventing the empty DataFrame issue (Cite `debug_lesson_4`).
