Based on the comprehensive analysis of previous experiments and lessons learned, I propose the **Phase-Aware Stratified 1D Attention ResUNet with ASPP**.

This strategy synthesizes the most effective feature engineering paradigm (**Stratified Aggregation** from Cite solution_lesson_node_00063) with advanced architectural components (**Attention Gates** and **ASPP**) that were previously hindered by specific implementation flaws (e.g., raw scalar angles, incorrect deep supervision targets). By correcting these issues, we create a model capable of dynamically filtering multipath noise while capturing multi-scale trajectory drifts.

### Model
**Architecture: 1D Residual U-Net with Attention Gates and ASPP**
The model is a sequence-to-sequence Encoder-Decoder network designed to map a time-series of sensor features to coordinate corrections.
*   **Residual Encoder:** The contracting path consists of stacked **1D Residual Blocks** followed by Max Pooling layers. This allows the network to learn deep, hierarchical representations of signal error dynamics without gradient degradation (Cite solution_lesson_node_00018).
*   **ASPP Bottleneck:** The deepest layer utilizes **Atrous Spatial Pyramid Pooling (ASPP)**. This module applies parallel 1D convolutions with varying dilation rates to the feature map. This allows the model to simultaneously capture instantaneous signal spikes (multipath) and long-term trajectory drifts (atmospheric bias) (Cite solution_lesson_node_00012), preserving the local inductive bias of CNNs (Cite solution_lesson_node_00031).
*   **Attention-Gated Decoder:** Upsampling layers are connected to the encoder via **Attention Gates** (Cite solution_lesson_node_00015).
    *   *Mechanism:* Instead of simple concatenation, the gate uses the upsampled decoder feature (global context) to compute a weighting map for the encoder features (local details). This suppresses irrelevant noise (e.g., jitter from the "High-Risk" stratum) while passing through relevant signal transients.
*   **Decimated Auxiliary Heads:** Intermediate decoder layers are equipped with auxiliary output heads. These are trained using **Decimated Deep Supervision** (Cite solution_lesson_node_00060) to ensure the encoder learns valid instantaneous states, stabilizing the training of the Attention Gates.

### Data
**Preprocessing Pipeline**
1.  **Temporal Quantization:** Raw GNSS logs and ground truth are aligned by **rounding timestamps to the nearest second (1Hz)**. This prevents data loss from clock jitter (Cite solution_lesson_node_00016).
2.  **Phase-Aware Stratified Aggregation:** For each timestamp, partition visible satellites into three strata (Cite solution_lesson_node_00063):
    *   **Stratum 1 (Global):** All visible satellites.
    *   **Stratum 2 (High-Precision):** Satellites with `SignalType` in {L5, E5a, B2a} **OR** `AccumulatedDeltaRangeState` indicating **Valid Carrier Phase**. Valid phase is a strong physical proxy for line-of-sight signals.
    *   **Stratum 3 (High-Risk):** Satellites with Elevation < 30 degrees.
    *   For each stratum, compute **Mean, Standard Deviation, Minimum, and Maximum** for `Cn0DbHz` and `SvElevationDegrees` (Cite solution_lesson_node_00020).
3.  **Corrected Geometric Context:** Calculate the **Signal-Weighted Azimuth Centroid**. Crucially, decompose this angle into **Sine and Cosine components** before feeding it to the network to avoid numerical discontinuities (Cite solution_lesson_node_00064).
4.  **Translation Invariance:** Strictly exclude absolute `Latitude` and `Longitude` (Cite solution_lesson_node_00003).
5.  **Target Transformation:** Convert regression targets from Degrees to **Meters (East-North)** relative to the WLS baseline (Cite solution_lesson_node_00018).

### Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. The total loss is a weighted sum of the final output loss and auxiliary head losses. MAE is used for robustness to outliers (Cite solution_lesson_node_00001).
*   **Deep Supervision Targets:** For auxiliary heads, the ground truth target is **decimated (subsampled)** to match the temporal resolution of the layer, rather than average-pooled (Cite solution_lesson_node_00060).
*   **Optimizer:** AdamW with **Gradient Clipping** and a **Cosine Annealing** learning rate schedule to ensure stability given the increased architectural complexity (Cite solution_lesson_node_00042).

### Evaluation
1.  **Inference:** Feed the preprocessed stratified feature sequence for a full test drive into the model. The model outputs the sequence of Cartesian residuals $(\Delta North, \Delta East)$ from the final high-resolution head.
2.  **Reconstruction:** Convert Cartesian offsets to angular offsets $(\Delta Lat, \Delta Lon)$ using local WGS84 approximations.
3.  **Correction:** Add the predicted offsets to the baseline WLS coordinates provided in the test set to generate the final submission.
