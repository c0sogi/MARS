Based on the lessons learned, particularly the importance of **Residual Learning** (Cite solution_lesson_node_00001), **Translation Invariance** (Cite solution_lesson_node_00003), and the superiority of **Signal Quality features over Kinematics** (Cite solution_lesson_node_00010), I propose a **Deep-Set TCN** strategy.

This approach replaces the manual feature aggregation (e.g., calculating "Mean Cn0") with a learnable aggregation layer. By processing the raw set of visible satellites directly, the model can learn to weigh high-quality signals against low-quality ones (e.g., ignoring a low-elevation satellite with high uncertainty) more effectively than heuristic averages.

### Model
The architecture is a hierarchical neural network consisting of two stages:
1.  **Satellite-Level Encoder (Deep Set):**
    *   **Input:** For each time step $t$, the input is a set of vectors $\{s_{t,1}, s_{t,2}, ..., s_{t,n}\}$, where each vector represents a single visible satellite's features.
    *   **Processing:** A shared Multi-Layer Perceptron (MLP) processes each satellite independently to produce a latent embedding.
    *   **Aggregation:** A symmetric, permutation-invariant pooling operation (Max-Pooling) aggregates these individual embeddings into a single **Epoch Embedding** vector. This vector encapsulates the overall geometric and signal quality context of that timestamp (e.g., "Good geometry but weak signals").
    *   **Context Fusion:** Global metadata features (e.g., `SatCount`, `WlsAlt`) are concatenated to this Epoch Embedding (Cite solution_lesson_node_00006).
2.  **Sequence-Level Backbone (TCN):**
    *   The sequence of Epoch Embeddings (representing a time window) is fed into a **Temporal Convolutional Network (TCN)**. This backbone models the temporal correlation of errors (e.g., slowly drifting atmospheric delays).
    *   **Capacity:** The TCN will use a constrained width (e.g., 64 channels) to prevent overfitting to specific drive trajectories (Cite solution_lesson_node_00002).
3.  **Output Head:** A final fully connected layer predicts the 2D residual vector $(\Delta Lat, \Delta Lon)$.

### Data
**Preprocessing Pipeline:**
1.  **Satellite Feature Extraction:** From `device_gnss.csv`, extract features for every satellite at every timestamp: `Cn0DbHz`, `SvElevationDegrees`, `SvAzimuthDegrees` (transformed to $\sin/\cos$), `RawPseudorangeUncertaintyMeters`, and `ConstellationType` (one-hot encoded).
2.  **Global Feature Extraction:** Extract `WlsAlt` (Altitude) and calculate `SatCount` per timestamp.
3.  **Tensor Construction:** Group data by `UnixTimeMillis`. Pad the number of satellites to a fixed maximum $N_{max}$ (e.g., 32) to create tensors of shape `(Window_Size, N_max, Features)`. Create a corresponding mask for padding.
4.  **Target Generation:** Compute the residuals: $Target = GroundTruth_{Lat/Lon} - WLS_{Lat/Lon}$.
5.  **Exclusion:** Explicitly exclude absolute `Latitude` and `Longitude` from the input features to enforce translation invariance (Cite solution_lesson_node_00003).

### Training
*   **Loss Function:** **Mean Absolute Error (MAE)** is used to minimize the impact of heavy-tailed outliers common in GNSS data (Cite solution_lesson_node_00001).
*   **Optimizer:** AdamW with a standard learning rate (e.g., 1e-3) and weight decay for regularization.
*   **Validation:** A `GroupShuffleSplit` based on `drive_id` is used to ensure the model is evaluated on unseen drives, preventing data leakage.

### Evaluation
1.  **Inference:** For each timestamp in the test set, construct the satellite feature tensor and feed it to the trained Deep-Set TCN to predict the residuals $(\Delta Lat, \Delta Lon)$.
2.  **Reconstruction:** Add the predicted residuals to the baseline WLS coordinates provided in the test data: $Final_{Lat/Lon} = WLS_{Lat/Lon} + Predicted_{Residuals}$.
3.  **Formatting:** Save the results in the required submission format.
