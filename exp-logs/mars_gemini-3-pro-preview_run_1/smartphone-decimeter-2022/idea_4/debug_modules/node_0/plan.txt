This script demonstrates the end-to-step usage of the provided library components for the smartphone location tracking task. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory and reduced hyperparameters (1 epoch, small batch size) for rapid execution.
2.  **Data Preparation**: Creates subsets of the provided metadata files (train, validation, test) containing only a single drive each. This ensures the data processing and training steps run quickly on a small representative sample.
3.  **Utility Verification**: Validates the coordinate conversion functions (`ecef_to_geodetic`, `geodetic_to_enu`, `enu_to_geodetic`) using round-trip assertions.
4.  **Data Processing**: Demonstrates `process_dataset` to load raw GNSS data, aggregate it, and merge it with ground truth, verifying the resulting DataFrame structure.
5.  **Dataset & DataLoader**: Instantiates `GNSSSequenceDataset` and a PyTorch `DataLoader` to verify sequence generation, normalization, and batch padding logic.
6.  **Model Initialization**: Instantiates the `UNet1D` model and performs a forward pass with a sample batch to verify tensor shapes.
7.  **Training**: Runs the `train_model` function on the mini-dataset to demonstrate the training loop and weight saving mechanism.
8.  **Inference**: Runs `generate_submission` using the trained model and mini-test dataset to produce a submission file.
