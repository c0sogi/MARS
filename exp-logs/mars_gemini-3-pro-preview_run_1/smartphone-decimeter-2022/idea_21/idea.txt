Based on the accumulated lessons, I propose the **Multi-Frequency 1D ResUNet with Decimated Deep Supervision**.

This strategy introduces two key evolutions:
1.  **Multi-Frequency Input Structure:** It moves beyond global aggregation by structurally separating satellite signals based on their frequency band (e.g., L1 vs. L5). This allows the model to explicitly leverage the superior multipath resistance of L5 signals, which were previously diluted by averaging with L1 signals.
2.  **Decimated Deep Supervision:** It corrects the flaw in previous multi-scale training attempts (Cite solution_lesson_node_00060) by aligning auxiliary loss targets via subsampling (decimation) rather than average pooling, ensuring the model learns precise instantaneous corrections at all depths.

### Model
**Architecture: 1D Residual U-Net with ASPP**
The backbone is a sequence-to-sequence Encoder-Decoder network designed to map a time-series of signal features to coordinate corrections.
*   **Multi-Channel Input:** The input tensor dimension is expanded to accommodate independent feature sets for different signal bands (Standard vs. High-Precision).
*   **Residual Encoder:** A stack of **1D Residual Blocks** followed by Max Pooling layers. This extracts hierarchical features while preventing gradient degradation (Cite solution_lesson_node_00018).
*   **ASPP Bottleneck:** An **Atrous Spatial Pyramid Pooling** module processes the compressed features with multiple dilation rates. This captures both local signal spikes and global trajectory drifts (Cite solution_lesson_node_00012) while maintaining the local inductive bias of CNNs (Cite solution_lesson_node_00031).
*   **Residual Decoder:** Upsampling layers concatenated with **Skip Connections** from the encoder to preserve high-frequency temporal details.
*   **Decimated Auxiliary Heads (Structural Innovation):** Intermediate decoder layers are equipped with auxiliary output heads. Unlike standard Deep Supervision which compares these low-resolution outputs to *averaged* ground truth, these heads are trained against **decimated (subsampled)** ground truth targets. This forces the encoder to learn valid instantaneous states rather than smoothed approximations (Cite solution_lesson_node_00060).

### Data
**Preprocessing Pipeline**
1.  **Temporal Quantization:** Raw GNSS logs and ground truth are aligned by **rounding timestamps to the nearest second (1Hz)** to prevent data loss from clock jitter (Cite solution_lesson_node_00016).
2.  **Frequency-Split Aggregation (Innovation):** Instead of aggregating all satellites together, partition the visible satellites into two groups based on `SignalType`:
    *   **Group A (Standard):** GPS L1, GAL E1, GLO G1, BDS B1, etc.
    *   **Group B (High-Precision):** GPS L5, GAL E5a, BDS B2a, QZS J5.
    *   For *each* group, compute robust statistics: **Mean, Standard Deviation, Minimum, and Maximum** for `Cn0DbHz` and `SvElevationDegrees` (Cite solution_lesson_node_00020).
    *   If a group is empty for a timestamp, fill with zero/mask values.
3.  **Global Context:** Concatenate these group-specific features with global metadata (`SatCount`, `RawPseudorangeUncertaintyMeters`) and the Signal-Weighted Azimuth Centroid (Cite solution_lesson_node_00033).
4.  **Translation Invariance:** Strictly exclude absolute `Latitude` and `Longitude` (Cite solution_lesson_node_00003).
5.  **Target Transformation:** Convert regression targets from Degrees to **Meters (East-North)** relative to the WLS baseline (Cite solution_lesson_node_00018).

### Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. The total loss is a weighted sum: $L_{total} = L_{final} + \lambda \sum L_{aux}$.
    *   $L_{aux}$ is computed as: $MAE(Output_{downsampled}, Target_{decimated})$.
*   **Optimizer:** AdamW with **Cosine Annealing** and **Gradient Clipping** to ensure stability (Cite solution_lesson_node_00042).
*   **Validation:** `GroupShuffleSplit` based on `drive_id` to ensure evaluation on unseen trips.

### Evaluation
1.  **Inference:** The preprocessed multi-frequency feature sequence for a full test drive is fed into the model. The model outputs the sequence of Cartesian residuals $(\Delta North, \Delta East)$ from the final high-resolution head.
2.  **Reconstruction:** Convert Cartesian offsets to angular offsets $(\Delta Lat, \Delta Lon)$ using local WGS84 approximations.
3.  **Correction:** Add offsets to the baseline WLS coordinates provided in the test set.
