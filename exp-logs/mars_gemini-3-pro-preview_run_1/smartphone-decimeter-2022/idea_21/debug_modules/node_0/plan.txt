This script demonstrates the end-to-step usage of the provided machine learning pipeline for GNSS positioning. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use temporary directories and reduced hyperparameters (1 epoch, debug mode) for rapid execution.
2.  **Data Preparation**: Creates "mini" metadata files by sampling a small subset of the original metadata to ensure the data processing and training steps finish quickly.
3.  **Data Processing**: Demonstrates the `process_dataset` function, verifying that it correctly extracts features from raw GNSS logs and merges them with ground truth.
4.  **Dataset & DataLoader**: Instantiates the `GnssDataset` and `DataLoader`, verifying batch shapes and data types.
5.  **Model & Loss**: Initializes the `ResUNet1D` model and `DecimatedMAELoss`, performs a forward pass with a dummy batch, and verifies the output structure and loss calculation.
6.  **Training Loop**: Uses the `Trainer` class to run a full training cycle (fitting and validation) on the mini dataset.
7.  **Inference**: Runs the prediction pipeline using the trained model to generate a submission file.
