Based on the lessons learned, I propose a solution that evolves the architecture from RoBERTa to **DeBERTa-v3** while retaining the highly effective data filtering and robust loss formulation strategies.

### Model
**Backbone Architecture:**
We will replace the `roberta-base` backbone with **`microsoft/deberta-v3-base`**.
*   **Rationale:** Previous experiments showed that simply scaling to `roberta-large` caused overfitting and performance degradation on this dataset Cite {solution_lesson_node_00009}. DeBERTa-v3 (Decoding-enhanced BERT with disentangled attention) introduces structural improvements—specifically **disentangled attention** (separating content and position vectors) and an **enhanced mask decoder**—which provide superior representations for span extraction tasks without the parameter bloat of "Large" models.

**Head Design:**
We will implement a **CNN-Enhanced Weighted Pooling Head**.
*   **Weighted Layer Pooling:** We will continue to aggregate the hidden states from the last four layers of the transformer to capture both syntactic and semantic features Cite {solution_lesson_node_00007}.
*   **Convolutional Context:** Instead of feeding the pooled output directly into a linear classifier, we will pass it through a **1D Convolutional Layer** (kernel size=3, padding=1). This structural addition allows the model to explicitly capture local n-gram context around potential start/end boundaries, complementing the "Gaussian" nature of the targets.

### Data
**Preprocessing & Alignment:**
*   **Robust Normalization:** We will apply strict whitespace normalization (collapsing multiple spaces) to both the tweet text and the selected text before processing. This is critical to prevent the alignment failures observed in earlier iterations Cite {solution_lesson_node_00005}.
*   **Tokenization:** We will use the DeBERTa-v3 tokenizer (SentencePiece-based) and generate offset mappings to link tokens back to original character indices.

**Strategic Filtering:**
*   **Neutral Exclusion:** We will strictly **exclude all 'neutral' tweets from the training set** Cite {solution_lesson_node_00002}. The model will be trained exclusively on 'positive' and 'negative' samples to focus its capacity on the non-trivial extraction logic.

**Target Generation:**
*   **Soft Targets:** We will generate **Gaussian-smoothed targets** for the start and end indices. Instead of a one-hot vector, the target will be a probability distribution centered on the ground-truth token with a variance ($\sigma$) of 1.0. This accounts for the annotation noise inherent in the dataset Cite {solution_lesson_node_00006}.

### Training
**Loss Function:**
We will use **Kullback-Leibler (KL) Divergence Loss** (or Soft Cross Entropy) to minimize the difference between the predicted log-probabilities and the Gaussian-smoothed target distributions. This aligns with the finding that penalizing "near-misses" too harshly degrades generalization Cite {solution_lesson_node_00007}.

**Optimization:**
*   **Optimizer:** AdamW with a linear learning rate scheduler and warmup.
*   **Precision:** Mixed Precision (FP16) to maximize training speed on the A100 GPU.

### Evaluation
**Inference Strategy:**
We will employ the **Hybrid Inference Pipeline** Cite {solution_lesson_node_00002}:
1.  **Neutral Tweets:** If `sentiment == "neutral"`, predict the full `text`.
2.  **Positive/Negative Tweets:** Pass the text through the DeBERTa model.
    *   **Joint Decoding:** Calculate the score for every possible span `(start, end)` as `Logit_start[start] + Logit_end[end]`. Select the span that maximizes this sum, subject to the constraint `start <= end` Cite {solution_lesson_node_00007}.
    *   **Reconstruction:** Use the stored offset mappings to extract the final string from the original text, ensuring correct punctuation and spacing.
