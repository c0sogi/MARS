The implementation strategy is as follows:

1.  **Setup & Initialization**: Import necessary libraries and the provided helper modules (`library.*`). Initialize the `TweetConfig` and set random seeds for reproducibility.
2.  **Data Loading**: Use `get_loaders(load_cached_data=True)` to efficiently load the preprocessed training, validation, and test DataLoaders. This leverages the cached numpy arrays to save time.
3.  **Model Setup**: Instantiate the `TweetModel` (DeBERTa-v3-base with the custom CNN head) and move it to the GPU. Initialize the `AdamW` optimizer and a linear learning rate scheduler with warmup.
4.  **Training Loop**: Execute the training for the number of epochs specified in the config (5 epochs). Inside the loop:
    *   Run `train_fn` to update model weights.
    *   Run `eval_fn` to calculate validation Loss and Jaccard score.
    *   Track the best Jaccard score and save the model state whenever performance improves.
5.  **Final Evaluation**: Print the final best validation metric in the required format.
6.  **Failure Analysis**:
    *   Load the best saved model state.
    *   Run inference on the validation set to get predictions.
    *   Load the validation metadata (filtering out 'neutral' rows to match the DataLoader's behavior).
    *   Compute the Jaccard score for each validation sample.
    *   Calculate and print the correlation between the error magnitude (`1 - Jaccard`) and the input text length.
7.  **Submission**: Check if the best validation metric exceeds the threshold (0.6990869212051385). If so, run inference on the test set and generate the `submission.csv` file using the provided `generate_submission` utility.
