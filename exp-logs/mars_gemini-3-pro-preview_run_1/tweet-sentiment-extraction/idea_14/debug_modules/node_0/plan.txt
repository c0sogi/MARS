This script demonstrates the end-to-end usage of the provided library files for the sentiment extraction task. It performs the following steps:

1.  **Setup & Configuration**: Overrides the default `Config` to use a temporary directory and creates small subsets of the training, validation, and test metadata to ensure the demo runs quickly (optimizing for speed).
2.  **Data Loading**: Initializes the tokenizer and uses `get_loaders` to generate PyTorch DataLoaders for the training and validation subsets. It verifies the batch structure and shapes.
3.  **Model Initialization**: Instantiates the `TweetModel` (DeBERTa-v3-large backbone with a custom head), moves it to the GPU, and performs a dummy forward pass to verify output shapes.
4.  **Loss Calculation**: Instantiates the `SoftTargetKLLoss` (task loss) and `RDropLoss` (consistency loss) and verifies they produce valid scalar outputs.
5.  **Training Loop**: Configures the optimizer with layer-wise learning rate decay and runs `train_fn` for one epoch on the subset.
6.  **Evaluation**: Runs `eval_fn` on the validation subset to compute the Loss and Jaccard score.
7.  **Inference**: Generates a test set DataLoader, runs the model in inference mode, applies the span selection logic to extract the sentiment-supporting text, and formats the output as a pandas DataFrame.
