Based on the comprehensive analysis of the "Lessons" and the trajectory of previous experiments, I propose the following optimized strategy. This solution synthesizes the high-performance **DeBERTa-v3-Large** backbone with a **Shared Gated Convolutional Head**, integrated into a robust **5-Fold Cross-Validation** pipeline. This approach isolates the structural benefits of gated feature selection from the computational overhead of consistency regularization, while strictly adhering to the proven data alignment and optimization protocols.

# Model

**Architecture:** **DeBERTa-v3-Large with Shared Gated Convolutional Head**
We will utilize **`microsoft/deberta-v3-large`** as the backbone. This model has demonstrated superior sample efficiency and feature extraction capabilities compared to Base variants when stabilized with appropriate optimization techniques Cite {solution_lesson_node_00036}, Cite {solution_lesson_node_00011}.

**Structural Innovation (Head Design):**
To refine the localization of span boundaries, we will implement a **Shared Gated Convolutional Head**.
1.  **Weighted Layer Pooling:** We will aggregate hidden states from the last four layers of the transformer to capture a rich blend of semantic and syntactic features Cite {solution_lesson_node_00007}.
2.  **Shared Gated Mechanism:** Instead of a standard Convolution or Decoupled Streams, the pooled embeddings will pass through a **Gated Linear Unit (GLU)** mechanism adapted for 1D sequences. We will apply two parallel **1D Convolutional Layers** (kernel size 3) to the shared input $X$:
    *   **Content Stream:** $C = \text{Conv1d}_a(X)$
    *   **Gate Stream:** $G = \text{Sigmoid}(\text{Conv1d}_b(X))$
    *   **Output:** $H = C \odot G$ (Element-wise product).
    *   *Rationale:* This mechanism retains the locality benefits of CNNs Cite {solution_lesson_node_00011} but allows the model to dynamically suppress irrelevant n-grams (noise) based on the learned gate. We explicitly keep this head **Shared** for both start and end predictions to leverage the strong correlation between boundaries, avoiding the performance degradation seen in decoupled architectures Cite {solution_lesson_node_00041}.
3.  **Regularization:** We will apply standard **Dropout** to the gated output to enable extended training without overfitting Cite {solution_lesson_node_00037}. We explicitly avoid Multi-Sample Dropout Cite {solution_lesson_node_00012}.
4.  **Projection:** A single Linear layer projects the refined features to 2 output logits (Start and End).

# Data

**Preprocessing & Alignment:**
*   **"Normalize-First" Pipeline:** We will strictly enforce a synchronized normalization protocol. We will normalize whitespace (collapsing multiple spaces) on the raw text *before* tokenization and use this **same normalized string** for the final substring extraction. This prevents the critical index misalignment observed in previous attempts Cite {solution_lesson_node_00018}.
*   **Input Formatting (Early Fusion):** We will format the input as `[CLS] Sentiment [SEP] Text [SEP]`. This allows the Transformer's self-attention to condition the text representation on the sentiment deep within the network, which is superior to Late Fusion Cite {solution_lesson_node_00033} or architectural branching Cite {solution_lesson_node_00029}.
*   **Strategic Filtering:** We will continue to **exclude 'neutral' tweets** from the training set entirely, as they follow a trivial identity mapping Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Containment Mapping:** We will generate token-level targets using **containment logic** (`token_start <= char_idx < token_end`) to handle subword splits accurately Cite {solution_lesson_node_00030}.
*   **Soft Targets:** We will generate **Gaussian-smoothed targets** ($\sigma=1.0$) for the start and end indices to handle annotation noise Cite {solution_lesson_node_00006}.

# Training

**Optimization Strategy:**
*   **Layer-wise Learning Rate Decay (LLRD):** We will apply LLRD with a decay factor of 0.9 and a **high base learning rate** (e.g., 5e-5). This ensures the task head converges rapidly while the lower backbone layers are fine-tuned conservatively, preventing the underfitting observed with flat learning rates on Large models Cite {solution_lesson_node_00036}, Cite {solution_lesson_node_00014}.
*   **Loss Function:** We will use **Kullback-Leibler (KL) Divergence Loss** to align with the soft targets Cite {solution_lesson_node_00007}. We will explicitly **average** the losses from the start and end heads (rather than summing) to preserve gradient scaling Cite {solution_lesson_node_00020}.
*   **Efficiency:** We will utilize **Automatic Mixed Precision (AMP)** to accelerate training and reduce memory footprint Cite {solution_lesson_node_00051}.
*   **Exclusions:** We will explicitly avoid R-Drop due to its prohibitive computational cost Cite {solution_lesson_node_00048} and AWP due to optimization instability Cite {solution_lesson_node_00015}.

# Evaluation

**Inference Pipeline:**
*   **5-Fold Cross-Validation Ensemble:** We will train the model on 5 distinct folds of the data and average the logits during inference. This is critical to reduce variance and maximize performance on this noisy dataset Cite {solution_lesson_node_00051}, Cite {solution_lesson_node_00042}.
*   **Neutral Samples:** Deterministically predict the full `text` Cite {solution_lesson_node_00002}.
*   **Positive/Negative Samples:**
    1.  Pass the **normalized** text through the ensemble.
    2.  **Joint Logit Decoding:** Select the span $(i, j)$ that maximizes the **sum of averaged logits**: $Logit_{start}(i) + Logit_{end}(j)$ subject to $i \le j$ Cite {solution_lesson_node_00021}.
    3.  **Reconstruction:** Extract the predicted substring from the **normalized** input text using the tokenizer offsets Cite {solution_lesson_node_00018}.
