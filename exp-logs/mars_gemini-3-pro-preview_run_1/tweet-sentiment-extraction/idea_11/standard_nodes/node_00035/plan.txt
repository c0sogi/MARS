Implementation strategy:
1.  **Setup & Configuration**: Import necessary libraries and the provided modules. Override `Config` parameters (Epochs=2, Folds=3) to ensure the script completes within the 2-hour limit while maintaining a robust baseline.
2.  **Data Loading**: Load the training and hold-out validation metadata.
3.  **Training Loop**: Implement a Stratified K-Fold loop (3 folds). For each fold:
    *   Filter out 'neutral' tweets from the training data as per the strategy.
    *   Train the `SentimentModel` using the `train_fn`.
    *   Save the model weights (`model_fold_{i}.bin`).
4.  **Validation**: Implement a custom ensemble validation function that:
    *   Loads the hold-out validation set.
    *   Runs inference using the 3 trained models.
    *   Applies the logic: if sentiment is 'neutral', predict full text; otherwise, use the ensemble logits to decode the span.
    *   Computes and prints the `Final Validation Metric` (Jaccard).
5.  **Failure Analysis**: Analyze the validation results to calculate the correlation between prediction error and text length, and inspect performance by sentiment.
6.  **Submission**: If the validation score exceeds the specified threshold, invoke the `run_inference` function to generate predictions on the test set and save `submission.csv`.
