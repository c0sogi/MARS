Based on the comprehensive analysis of previous experiments and lessons learned, I propose the following optimized strategy.

# Model
**Architecture:** **DeBERTa-v3-base with Dual-Head Multi-Task Learning**
We will utilize `microsoft/deberta-v3-base` as the backbone, leveraging its disentangled attention mechanism which is superior for span extraction tasks Cite {solution_lesson_node_00011}. We will implement a structural innovation by attaching two distinct heads to the encoder:
1.  **Primary Span Head (CNN-Enhanced):** We will retain the successful architecture from Idea 3. Hidden states from the last four layers will be aggregated via **Weighted Layer Pooling** Cite {solution_lesson_node_00007}, passed through a **1D Convolutional Layer** (kernel size 3) to capture local boundary context Cite {solution_lesson_node_00011}, and finally projected to Start/End logits.
2.  **Auxiliary Dense Head:** To address the sparsity of the start/end signals, we will add a secondary Linear head that performs binary classification on *every* token embedding, predicting whether the token belongs to the selected span. This provides dense supervision, forcing the encoder to learn robust representations for the entire sentiment-bearing phrase, not just the boundaries.

# Data
**Preprocessing:**
*   **Normalization:** We will apply strict whitespace normalization to both tweets and targets to ensure robust alignment Cite {solution_lesson_node_00005}.
*   **Filtering:** We will strictly **exclude 'neutral' tweets** from the training set, using them only for validation/testing, as they follow a trivial identity mapping Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Primary:** We will generate **Gaussian-smoothed targets** ($\sigma=1.0$) for the start and end indices to handle annotation noise Cite {solution_lesson_node_00006}.
*   **Auxiliary:** We will generate binary masks (0/1) for the dense head, corresponding to the ground truth span.

# Training
**Loss Function:**
The total loss will be a weighted sum: $L_{total} = L_{KL\_Div}(Span) + \lambda \cdot L_{BCE}(Aux)$.
*   We use **KL Divergence** for the span head to align with the Gaussian soft targets Cite {solution_lesson_node_00007}.

**Optimization Strategy:**
*   **Layer-wise Learning Rate Decay (LLRD) with Extended Schedule:** We will re-introduce LLRD to preserve pre-trained knowledge, but to correct the underfitting observed in previous attempts Cite {solution_lesson_node_00014}, we will **increase the training duration** (e.g., from 5 to 8-10 epochs). This ensures that the lower layers, which receive smaller updates due to decay, have sufficient steps to adapt to the tweet domain.
*   **Adversarial Weight Perturbation (AWP):** We will implement AWP to improve generalization against noisy labels. To avoid the instability seen in Idea 4 Cite {solution_lesson_node_00015}, we will apply AWP **only after the first epoch**, allowing the model to stabilize before introducing adversarial perturbations.

# Evaluation
**Inference Pipeline:**
1.  **Neutral Samples:** Deterministically predict the full text Cite {solution_lesson_node_00002}.
2.  **Positive/Negative Samples:** Pass through the DeBERTa model.
    *   **Joint Decoding:** Use the Primary Span Head's logits to select the span $(i, j)$ that maximizes $P_{start}(i) + P_{end}(j)$ subject to $i \le j$ Cite {solution_lesson_node_00007}.
    *   The Auxiliary Head is used solely for representation learning during training and is discarded during inference.
    *   **Reconstruction:** Use offset mappings to extract the final substring from the original raw text.
