Based on the comprehensive analysis of the provided lessons and the failure modes of previous iterations, I propose the following optimized strategy. This solution introduces a **Sentiment-Conditioned Convolutional Head** to enforce explicit dependency on the sentiment label at the decision boundary, while strictly adhering to the robust data alignment and inference protocols established in successful experiments.

# Model

**Architecture:** **DeBERTa-v3 with Sentiment-Conditioned Convolution**
We will utilize **`microsoft/deberta-v3-base`** as the backbone, leveraging its disentangled attention mechanism which is superior for span extraction tasks Cite {solution_lesson_node_00011}. We will implement a structural innovation in the classification head to reinforce the conditioning signal:

1.  **Weighted Layer Pooling:** We will aggregate hidden states from the last four layers of the transformer to capture a robust mix of syntactic and semantic features Cite {solution_lesson_node_00007}.
2.  **Late Fusion Conditioning (Structural Innovation):** Standard architectures rely on the Transformer's self-attention to mix the sentiment and text features. To prevent this signal from being diluted during pooling, we will explicitly extract the embedding of the **sentiment token** (e.g., the token at index 1) from the final encoder layer. We will replicate this sentiment vector and **concatenate** it with the pooled representation of *every* token in the sequence.
    *   *Rationale:* This ensures that the subsequent convolutional layer receives the explicit "instruction" (Positive vs. Negative) alongside the local context at every position, addressing the need for explicit conditioning Cite {solution_lesson_node_00028} without the data fragmentation caused by decoupled heads Cite {solution_lesson_node_00029}.
3.  **Conditioned Convolution:** The concatenated features (Text + Sentiment) will be passed through a **1D Convolutional Layer** (kernel size 3). This retains the proven benefit of capturing local n-gram context Cite {solution_lesson_node_00011} but now operates on a representation that is explicitly "sentiment-aware".
4.  **Projection:** A final Linear layer projects the convolutional output to Start and End logits.

# Data

**Preprocessing & Alignment:**
*   **"Normalize-First" Pipeline:** We will strictly enforce a synchronized normalization protocol. We will normalize whitespace (collapsing multiple spaces) on the raw text *before* tokenization. Crucially, we will use this **same normalized string** for the final substring extraction during inference. This prevents the critical index misalignment observed when tokenizer offsets are applied to mismatched raw text Cite {solution_lesson_node_00018}.
*   **Target Mapping (Containment):** We will generate token-level targets using **containment logic** (`token_start <= char_idx < token_end`). We will explicitly avoid boundary thresholding heuristics, which fail on subword splits Cite {solution_lesson_node_00030}.
*   **Strategic Filtering:** We will continue to **exclude 'neutral' tweets** from the training set entirely. These samples follow a trivial identity mapping, and training on them wastes model capacity Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Soft Targets:** We will generate **Gaussian-smoothed targets** ($\sigma=1.0$) for the start and end indices. This prevents the model from overfitting to the noisy and subjective boundaries inherent in the dataset Cite {solution_lesson_node_00006}.

# Training

**Loss Function:**
*   We will use **Kullback-Leibler (KL) Divergence Loss** to align with the Gaussian soft targets Cite {solution_lesson_node_00007}.
*   **Loss Averaging:** We will explicitly **average** the losses from the start and end heads (i.e., $L = 0.5 \times L_{start} + 0.5 \times L_{end}$) rather than summing them. This preserves the gradient scale and ensures compatibility with standard pre-trained learning rates Cite {solution_lesson_node_00020}.

**Optimization Strategy:**
*   **Optimizer:** We will use AdamW with a linear learning rate scheduler.
*   **Stability First:** We will strictly **avoid** stacking complex optimization tricks like Adversarial Weight Perturbation (AWP) or Layer-wise Learning Rate Decay (LLRD). Previous lessons demonstrated that combining these with structural changes leads to instability and catastrophic failure Cite {solution_lesson_node_00015}. We will rely on the structural innovation of Late Fusion Conditioning rather than optimization hacks.

# Evaluation

**Inference Pipeline:**
1.  **Neutral Samples:** Deterministically predict the full `text` Cite {solution_lesson_node_00002}.
2.  **Positive/Negative Samples:** Pass the **normalized** text through the DeBERTa model.
    *   **Joint Logit Decoding:** Calculate the score for span $(i, j)$ as the **sum of logits**: $Logit_{start}(i) + Logit_{end}(j)$. We will select the span that maximizes this sum subject to $i \le j$ Cite {solution_lesson_node_00021}.
    *   **Reconstruction:** Extract the predicted substring from the **normalized** input text using the tokenizer offsets, ensuring bit-perfect alignment Cite {solution_lesson_node_00018}.
