The solution implements the end-to-end pipeline for sentiment extraction using a DeBERTa-v3 model with a custom sentiment-conditioned head.

**Strategy Outline:**
1.  **Setup & Data Loading:** We initialize the environment and load cached dataloaders. The training set excludes neutral tweets (as per strategy), while validation and test sets retain them.
2.  **Model Training:** We train the `SentimentConditionedDeberta` model for 5 epochs using AdamW and a linear scheduler. We save the model checkpoint with the lowest validation loss.
3.  **Validation & Metric Calculation:** We perform inference on the validation set. We apply the "Normalize-First" protocol to ensure text alignment.
    *   **Neutral Tweets:** We deterministically predict the full normalized text.
    *   **Pos/Neg Tweets:** We use the trained model. We employ **Joint Logit Decoding** (maximizing `start + end` logits) to select the best span.
    *   We compute the Jaccard score and print it in the required format.
4.  **Failure Analysis:** We analyze the validation results by calculating the correlation between the error (1 - Jaccard) and input features like text length and sentiment, identifying systematic weaknesses.
5.  **Submission:** If the validation score exceeds the threshold (0.7043), we generate predictions for the test set using the same robust inference pipeline and save the submission file.
