The implementation strategy involves the following steps:
1.  **Setup**: Define input (`./input`) and output (`./metadata`) directories. Ensure the output directory exists.
2.  **Data Loading**: Read `train.csv` and `test.csv` using pandas.
3.  **Preprocessing**: Remove rows in the training set that contain missing values (NaN) in the `text` or `selected_text` columns to ensure data integrity.
4.  **Splitting**: Perform a stratified split on the training data to create a validation set. Use an 80:20 ratio (`test_size=0.2`), fix the random state to 42, and stratify based on the `sentiment` column to preserve class distribution.
5.  **Saving**: Save the split training set, validation set, and the original test set as new CSV files in the `./metadata` directory (`train_metadata.csv`, `validation_metadata.csv`, `test_metadata.csv`).
6.  **Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (row counts, sentiment distributions).
    *   Programmatically assert that the split ratio is approximately 80:20.
    *   Programmatically assert that the sentiment distribution in the validation set matches the training set (stratification check).
    *   Since the dataset consists of text within CSV files and does not reference external media files, the file path existence check is noted as not applicable.
