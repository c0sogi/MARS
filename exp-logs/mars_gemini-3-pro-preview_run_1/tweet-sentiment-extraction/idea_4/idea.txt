Based on the lessons learned from previous iterations, I propose a solution that integrates **Adversarial Training** and **Dense Supervision** into the **DeBERTa-v3** architecture. This strategy aims to maximize robustness against annotation noise while correcting the optimization issues observed with Layer-wise Learning Rate Decay.

### Model
**Backbone:**
We will utilize **`microsoft/deberta-v3-base`** as the feature extractor. Its disentangled attention mechanism has proven superior for span extraction tasks compared to RoBERTa variants Cite {solution_lesson_node_00011}.

**Heads (Structural Innovation):**
We will implement a **Multi-Task Architecture** with two distinct heads branching from the same encoder:
1.  **Primary Span Head:** This path uses **Weighted Layer Pooling** (aggregating the last 4 layers) Cite {solution_lesson_node_00007} followed by a **1D Convolutional Layer** Cite {solution_lesson_node_00011} to predict the `start` and `end` token indices.
2.  **Auxiliary Dense Head:** We will add a token-level classification head (Linear layer) that predicts a binary mask (0 or 1) for *every* token, indicating whether it is part of the selected text.
    *   **Rationale:** Start/End targets are "sparse" (only two positive signals per sequence). Adding a dense auxiliary task forces the model to learn a robust representation of the entire sentiment-bearing phrase, stabilizing convergence on noisy data.

### Data
**Preprocessing:**
*   **Normalization:** Apply strict whitespace normalization to input text and targets to ensure alignment. Cite {solution_lesson_node_00005}.
*   **Filtering:** Exclude all 'neutral' tweets from the training set and use them only for validation/testing. Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Primary:** Generate **Gaussian-smoothed targets** ($\sigma=1.0$) for start and end indices to handle annotation uncertainty. Cite {solution_lesson_node_00006}.
*   **Auxiliary:** Generate binary token masks where `1` represents tokens inside the ground-truth span and `0` otherwise.

### Training
**Optimization Strategy (Correction):**
We will employ **Layer-wise Learning Rate Decay (LLRD)** but with a **Corrected Base Learning Rate**.
*   Previous attempts with LLRD failed due to underfitting Cite {solution_lesson_node_00014}. To fix this, we will **increase the base learning rate** (e.g., to 5e-5) while maintaining the decay factor (0.9). This ensures that the lower layers of the backbone receive sufficient updates to adapt to the tweet domain, while the top layers are fine-tuned more conservatively.

**Robustness Technique (Innovation):**
We will implement **Adversarial Weight Perturbation (AWP)**.
*   During the training loop, after the initial forward/backward pass, we will inject small adversarial perturbations into the model's embeddings and compute the loss again. The model minimizes this "worst-case" loss. This technique is specifically designed to improve generalization on datasets with noisy or inconsistent labels, addressing the core difficulty of this task.

**Loss Function:**
The total loss will be a weighted sum: $L_{total} = L_{KL\_div}(Start, End) + \lambda \cdot L_{BCE}(Aux\_Mask)$.

### Evaluation
**Inference Strategy:**
*   **Neutral Samples:** Predict the full text. Cite {solution_lesson_node_00002}.
*   **Positive/Negative Samples:** Use the trained model.
    *   **Decoding:** Perform **Joint Span Decoding** on the Primary Head's logits. Select the span $(i, j)$ that maximizes $P_{start}(i) + P_{end}(j)$ subject to $i \le j$. Cite {solution_lesson_node_00007}.
    *   The Auxiliary Head is used solely for representation learning during training and is discarded during inference.
