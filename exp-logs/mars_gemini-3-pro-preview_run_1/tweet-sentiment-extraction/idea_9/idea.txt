Based on the comprehensive analysis of the provided lessons and the failure modes of previous iterations, I propose the following optimized strategy. This solution introduces a **Sentiment-Decoupled Head Architecture** to maximize the specificity of boundary detection, while strictly adhering to the robust data alignment and inference protocols established in successful experiments.

# Model

**Architecture:** **DeBERTa-v3 with Sentiment-Decoupled Heads**
We will utilize **`microsoft/deberta-v3-base`** as the backbone, leveraging its disentangled attention mechanism which is superior for span extraction tasks Cite {solution_lesson_node_00011}. We will implement a structural innovation in the classification head to explicitly handle the conditional nature of the task:

1.  **Weighted Layer Pooling:** We will aggregate hidden states from the last four layers of the transformer to capture a robust mix of syntactic and semantic features Cite {solution_lesson_node_00007}.
2.  **Shared Context Layer:** The pooled embeddings will pass through a shared **1D Convolutional Layer** (kernel size 3). This retains the proven benefit of capturing local n-gram context and sharpening decision boundaries Cite {solution_lesson_node_00011}.
3.  **Sentiment-Decoupled Projection (Structural Innovation):** Instead of a single Linear layer predicting start/end logits for all inputs, we will implement **two distinct Linear heads**: one specialized for `positive` tweets and one for `negative` tweets.
    *   During the forward pass, we will use the sample's sentiment label to route the embedding to the corresponding head.
    *   **Rationale:** The linguistic patterns and vocabulary distributions for "positive" spans differ from "negative" ones. Decoupling the final projection allows each head to learn specialized decision boundaries without interference from the opposing sentiment, effectively extending the logic of handling "neutral" tweets separately Cite {solution_lesson_node_00002} to the active classes.
4.  **Regularization:** We will use standard Dropout. We will explicitly **avoid** Multi-Sample Dropout, as it has been shown to degrade precision in this specific task Cite {solution_lesson_node_00012}.

# Data

**Preprocessing & Alignment:**
*   **"Normalize-First" Pipeline:** We will strictly enforce a synchronized normalization protocol. We will normalize whitespace (collapsing multiple spaces) on the raw text *before* tokenization. Crucially, we will use this **same normalized string** for the final substring extraction during inference. This prevents the critical index misalignment observed when tokenizer offsets are applied to mismatched raw text Cite {solution_lesson_node_00018}.
*   **Input Formatting:** We will retain the **Question-Answering format** (`[CLS] Sentiment [SEP] Text [SEP]`). Even with decoupled heads, explicitly encoding the sentiment in the input sequence is necessary for the Transformer backbone to attend to the relevant sentiment-bearing tokens Cite {solution_lesson_node_00028}.
*   **Strategic Filtering:** We will continue to **exclude 'neutral' tweets** from the training set entirely. These samples follow a trivial identity mapping, and training on them wastes model capacity Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Soft Targets:** We will generate **Gaussian-smoothed targets** ($\sigma=1.0$) for the start and end indices. This prevents the model from overfitting to the noisy and subjective boundaries inherent in the dataset Cite {solution_lesson_node_00006}.

# Training

**Loss Function:**
*   We will use **Kullback-Leibler (KL) Divergence Loss** to align with the Gaussian soft targets Cite {solution_lesson_node_00007}.
*   **Loss Averaging:** We will explicitly **average** the losses from the start and end heads (i.e., $L = 0.5 \times L_{start} + 0.5 \times L_{end}$) rather than summing them. This preserves the gradient scale and ensures compatibility with standard pre-trained learning rates Cite {solution_lesson_node_00020}.

**Optimization Strategy:**
*   **Optimizer:** We will use AdamW with a linear learning rate scheduler.
*   **Stability First:** We will strictly **avoid** stacking complex optimization tricks like Adversarial Weight Perturbation (AWP) or Layer-wise Learning Rate Decay (LLRD). Previous lessons demonstrated that combining these with structural changes leads to instability and catastrophic failure Cite {solution_lesson_node_00015}. We will rely on the structural innovation of Decoupled Heads rather than optimization hacks.

# Evaluation

**Inference Pipeline:**
1.  **Neutral Samples:** Deterministically predict the full `text` Cite {solution_lesson_node_00002}.
2.  **Positive/Negative Samples:** Pass the **normalized** text through the DeBERTa model.
    *   **Routing:** Route the embeddings to the specific `Positive` or `Negative` linear head based on the tweet's sentiment.
    *   **Joint Logit Decoding:** Calculate the score for span $(i, j)$ as the **sum of logits**: $Logit_{start}(i) + Logit_{end}(j)$. We will select the span that maximizes this sum subject to $i \le j$ Cite {solution_lesson_node_00021}.
    *   **Reconstruction:** Extract the predicted substring from the **normalized** input text using the tokenizer offsets, ensuring bit-perfect alignment Cite {solution_lesson_node_00018}.
