The implementation strategy for the VH-FASE pipeline is as follows:

1.  **Setup & Imports**: Import the required modules from the provided `library` package (`config`, `data_loader`, `feature_engineering`, `model`, `utils`) and standard libraries. Set the random seed for reproducibility.
2.  **Data Processing**:
    *   Load training and validation metadata using `data_loader`.
    *   Generate the hierarchical features (Level 0 distance, Level 1 neighbors, Level 2 message passing, and Field Projections) using `feature_engineering.generate_hierarchical_features`. This function handles vectorization and caching.
3.  **Fast Baseline Configuration**:
    *   To meet the "fast baseline" requirement, perform stratified subsampling on the training data (e.g., reducing to 500,000 samples) to ensure the training completes within the 2-hour limit while maintaining type distribution.
    *   Modify the in-memory XGBoost configuration (`config.TYPE_SPECIFIC_PARAMS`) to limit `n_estimators` (e.g., to 2500) and enforce GPU acceleration (`device='cuda'`).
4.  **Training**: Initialize the `StratifiedEnsemble` and train it on the subsampled training data and the full validation data.
5.  **Validation & Metrics**:
    *   Generate predictions for the full validation set.
    *   Calculate the Log Mean Absolute Error using `utils.calculate_log_mae`.
    *   Print the `Final Validation Metric` in the required format.
6.  **Failure Analysis**:
    *   Calculate absolute errors for the validation set.
    *   Compute and print the top correlations between features and the absolute error to identify sources of model failure.
7.  **Submission**:
    *   Check if the validation metric is lower (better) than the threshold `-0.7386035268505905`.
    *   If successful, load test metadata, generate features for the test set, predict using the ensemble, and save the submission file using `utils.format_submission`.
