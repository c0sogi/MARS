The error `TypeError: Not supported type for data.<class 'xgboost.core.DMatrix'>` occurs because the `StratifiedEnsemble.predict` method wraps the input data in a `xgb.DMatrix` before passing it to `model.predict()`. However, the models are loaded as `xgb.XGBRegressor` objects (Scikit-Learn API), which expect standard array-like inputs (such as Pandas DataFrames or NumPy arrays) and do not support receiving a pre-constructed `DMatrix`. To fix this, I will remove the manual `DMatrix` creation in the inference loop and pass the Pandas DataFrame `X_test` directly to the `predict` method.
