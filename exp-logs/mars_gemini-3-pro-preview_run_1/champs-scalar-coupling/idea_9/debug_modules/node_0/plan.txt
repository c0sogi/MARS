Strategy:
1.  **Setup Environment**: Define paths for a temporary working directory (`./working/demo_run`) to store subsetted data and outputs.
2.  **Data Subsetting**: Load the first few rows of the provided metadata (`train.csv`, `val.csv`, `test.csv`) and the corresponding structures from `input/structures.csv`. Filter the structures to include only the molecules present in the metadata subsets. Save these subsets to the temporary directory. This ensures the demonstration runs quickly on a small dataset (~140 molecules total).
3.  **Configuration Patching**: Import `library.config` and modify `DATA_PATHS` to point to the new subsetted files. Also, drastically reduce `XGB_PARAMS` (e.g., `n_estimators=10`, `max_depth=3`) to minimize training time. Update `WORKING_DIR` in the config to point to the demo directory.
4.  **Library Import**: Import `library.features` and `library.model` *after* patching the configuration. This ensures that the `GraphEngine` class (which uses `DATA_PATHS` in default arguments) and the `StratifiedEnsemble` class use the updated paths and parameters.
5.  **Execution**:
    *   Initialize the random seed using `library.utils.set_seed`.
    *   Generate features using `library.features.generate_features` with `load_cached_data=False` to force the pipeline to run on the new subset.
    *   Train the model ensemble using `library.model.StratifiedEnsemble.fit`.
    *   Generate predictions using `library.model.StratifiedEnsemble.predict`.
6.  **Validation**: Perform assertions to verify that features were generated (check columns), models were trained (check file output), and predictions match the expected shape.
