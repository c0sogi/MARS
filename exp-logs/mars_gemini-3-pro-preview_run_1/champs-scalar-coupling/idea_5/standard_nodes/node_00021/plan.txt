The implementation strategy follows the **Multi-Hop Topological Stratified Ensemble** idea.

1.  **Data Loading & Feature Engineering**: We utilize the `TabularMessagePasser` to generate the 1-hop and 2-hop topological features. To adhere to the strict 2-hour time limit while maintaining model quality, we will train on a representative subset of the training data (500,000 rows, approx. 15%), but we will evaluate on the **full** validation set to ensure the metric is strictly comparable to the target threshold.
2.  **Model Training**: We use the `StratifiedModelManager` to train 8 separate XGBoost models (one per coupling type). The models utilize the GPU (`device='cuda'`) and histogram-based tree construction for speed.
3.  **Evaluation**: We compute the Log Mean Absolute Error (Log MAE) across all types on the hold-out validation set.
4.  **Failure Analysis**: We generate predictions on the validation set, calculate the absolute residuals, and compute the Pearson correlation between these residuals and the input features to identify sources of error.
5.  **Submission**: If the calculated validation metric is below the specified threshold (`-0.7386...`), we proceed to process the test set and generate the `submission.csv` file.
