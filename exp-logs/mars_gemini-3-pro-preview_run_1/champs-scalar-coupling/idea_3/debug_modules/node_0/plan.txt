This script demonstrates the end-to-end execution of the Graph-Augmented Stratified Ensemble (GASE) solution. It performs the following steps:

1.  **Configuration Patching**: Overrides the default `GASEConfig` to use a temporary working directory and reduced hyperparameters (fewer epochs, smaller estimators) for a fast demonstration.
2.  **Data Subsampling**: Creates a small subset of the training, validation, and test metadata (based on a few molecules) to ensure the pipeline runs quickly.
3.  **Data Processing**: Uses `library.data_utils` to compute geometric features.
4.  **Graph Construction**: Uses `library.graph_utils` to build molecular graphs for the Message Passing Neural Network (MPNN).
5.  **MPNN Training**: Uses `library.mpnn_trainer` to train the graph neural network on the subset.
6.  **Embedding Extraction**: Generates learned interaction embeddings using the trained MPNN.
7.  **Feature Assembly**: Combines geometric features and embeddings using `library.feature_eng`.
8.  **Ensemble Training & Prediction**: Uses `library.xgb_model` to train stratified XGBoost models and generate a submission file.
9.  **Verification**: Includes assertions at each step to validate data shapes and file generation.
