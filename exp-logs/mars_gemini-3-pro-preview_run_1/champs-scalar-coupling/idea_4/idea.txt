Based on the accumulated lessons and previous attempts, I propose the **Path-Contextualized Stratified Ensemble (PCSE)**.

### 1. Model
The architecture remains a **Stratified Ensemble** of Gradient Boosted Decision Trees (XGBoost), as established in **Idea 2**. We will train **eight separate regressors**, one for each scalar coupling type (e.g., `1JHC`, `2JHH`, `3JHC`).

**Structural Innovation:**
The core innovation lies in the **Input Representation**. Previous models relied on "Through-Space" features (Euclidean distance) and "Node-Centric" features (Bag of Neighbors). This solution introduces **"Path-Centric" features**.
*   Scalar coupling is physically mediated by the electron distribution along the chemical bonds connecting the two atoms.
*   We will explicitly model the **Bond Path** (the sequence of atoms connecting Atom 0 and Atom 1).
*   This transforms the problem from predicting interaction based on *proximity* (distance) to predicting interaction based on *connectivity* (topology and path geometry).

### 2. Data
The data pipeline will be upgraded to extract specific geometric invariants related to the bond path (Angles and Torsions) which are critical for 2-bond and 3-bond couplings but were absent in previous iterations.

**Preprocessing & Feature Engineering:**
1.  **Graph Construction:**
    *   Load `structures.csv` and compute the **Adjacency Matrix** based on a bond-length threshold (e.g., < 1.6 Angstroms for C-H/C-C bonds).
    *   Use **Sparse Matrix Multiplication** (Cite **Lesson 00009**) to identify neighbors efficiently.

2.  **Path Extraction (The Innovation):**
    *   For each coupling pair, identify the shortest path through the molecular graph.
    *   **1J (Direct):** Path is the bond itself. Feature: Bond Length.
    *   **2J (Geminal):** Identify the central atom $C$ in $A-C-B$. Calculate the **Bond Angle** $\angle ACB$. (Cite **Lesson 00011**).
    *   **3J (Vicinal):** Identify the path $A-B-C-D$. Calculate the **Dihedral Angle** (Torsion) between the plane $ABC$ and $BCD$. This is the physical driver of 3-bond coupling (Karplus equation) and has been missing from previous models.

3.  **Contextual Features:**
    *   **Node Context:** Generate "Bag of Neighbors" vectors (counts of H, C, N, O neighbors) for every atom in the path (Cite **Lesson 00006**).
    *   **Through-Space:** Retain Inverse Distance powers ($1/d, 1/d^2, 1/d^3$) to model field effects (Cite **Lesson 00001**).

4.  **Sanitization:**
    *   Since the models are stratified by type, features like `type` or `atom_0` (e.g., always 'H' for `1JHC`) become constant. These will be dropped to reduce noise.

### 3. Training
The training regime is designed to maximize the model's ability to learn complex physical interactions from the full dataset.

*   **Dataset:** Train on the **Full Training Set** (100% of data). Do not subsample. (Cite **Lesson 00008**).
*   **Hyperparameters:**
    *   **Depth:** Set `max_depth` to **10-12**. The physical interaction (especially 3J coupling) involves high-order interactions between the path geometry and the electronic environments of 4+ atoms. High depth is required to capture this. (Cite **Lesson 00017**).
    *   **Regularization:** Set `colsample_bytree` to **0.4 - 0.5**. Since we are removing constant features (like atom types) in the stratified models, we must lower column sampling to force the trees to use diverse geometric features and prevent overfitting to the dominant path features. (Cite **Lesson 00007**).
    *   **Patience:** Use a low `learning_rate` (e.g., **0.02**) and a very high `n_estimators` ceiling (e.g., **30,000**) with Early Stopping. This ensures that difficult strata (like `1JHC`) have sufficient capacity to converge. (Cite **Lesson 00013**).

### 4. Evaluation
1.  **Path Generation:** Process `test.csv` to extract the same Path-Centric features (Angles, Dihedrals) using the test structures.
2.  **Stratified Inference:** Split the test set by coupling type. Feed the corresponding subset into the specific trained XGBoost model.
3.  **Submission:** Concatenate the predictions and save to `submission.csv`.
