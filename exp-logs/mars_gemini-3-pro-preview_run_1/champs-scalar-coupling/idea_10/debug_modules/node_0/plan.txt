Here is the implementation strategy:

1.  **Environment Setup**: Initialize a dedicated working directory (`./working/demo_execution`) to isolate generated files and caches.
2.  **Data Subsetting**: To ensure the script executes quickly (within the time limit), load a small fraction of the provided metadata (train, val, test) and the corresponding molecular structures. Save these subsets to the demo directory.
3.  **Configuration Override**: Monkey-patch the `library.config` module to point to the subsetted data files and the new working directory. Drastically reduce model hyperparameters (epochs, batch size, tree estimators) to demonstrate functionality without long training times.
4.  **Pipeline Execution**:
    *   **Symbolic Feature Engineering**: Generate geometric and graph-based features using `feature_engineering`.
    *   **GNN Pipeline**: Train the Graph Neural Network using `engine_gnn` on the subset and extract learned interaction embeddings.
    *   **Data Merging**: Combine symbolic features with GNN embeddings.
    *   **Ensemble Training**: Train the Stratified XGBoost Ensemble using `engine_xgb` on the combined features.
    *   **Prediction**: Generate predictions for the test subset.
5.  **Verification**: Assert that the output submission file exists and has the correct dimensions relative to the test subset.
