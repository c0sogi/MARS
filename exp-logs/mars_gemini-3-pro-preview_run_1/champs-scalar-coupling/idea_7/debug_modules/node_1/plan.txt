The issue is caused by an unguarded call to `main()` at the global scope in `library/features.py`. When `runfile.py` imports `library.features`, this `main()` function is immediately executed, triggering the full production pipeline with default hyperparameters (40,000 estimators) instead of the intended lightweight demo configuration. This consumes all available runtime and causes a timeout. The fix is to wrap the execution of `main()` in an `if __name__ == "__main__":` block, ensuring it only runs when the file is executed directly.

```diff
library/features.py
<<<<<<< SEARCH
# Execute Pipeline
main()
=======
# Execute Pipeline
if __name__ == "__main__":
    main()
>>>>>>> REPLACE
```
