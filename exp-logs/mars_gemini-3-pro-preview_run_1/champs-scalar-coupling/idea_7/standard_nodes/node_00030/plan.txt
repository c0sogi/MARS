My implementation strategy focuses on three key optimizations derived from the provided lessons:

1.  **Late Aggregation of Angular Features (Cite Lesson 00028):** I will replace the "mean bond vector" approach with a "Late Aggregation" strategy. Instead of averaging neighbor vectors *before* calculating angles (which destroys anisotropy), I will modify the `DataProcessor` to merge coupling pairs with the full edge list. This allows calculating the cosine similarity between the coupling axis and *each* neighbor bond individually, followed by aggregation (mean, min, max, std). This explicitly captures the geometric environment's directionality.
2.  **Vectorized Edge Processing (Cite Lesson 00021):** To support the above, I will update `GraphFeatureEngine` to expose and cache the full `edges` dataframe (containing bond vectors) alongside the node features. The `DataProcessor` will consume this edge list to perform the vectorized merge and calculation described above, ensuring the pipeline remains efficient enough for the full dataset.
3.  **Increased Model Capacity (Cite Lesson 00008):** I will remove the "fast baseline" patch in `runfile.py` and update `library/config.py` to use 12,000 estimators (up from 2,500) and a learning rate of 0.02. This leverages the 4-hour runtime to allow the model to fully converge on the complex geometric features.

    def __init__(self, node_features, edges):
        self.node_features = node_features
        self.edges = edges

    def _compute_angular_features(self, df, atom_idx_col, prefix):
        """
        Calculates aggregate angular features (Late Aggregation).
        Computes cosine similarity between the coupling axis and ALL neighbor bonds.
        Cite solution_lesson_node_00028
        """
        # Calculate Coupling Vector C
        if atom_idx_col == "atom_index_0":
            # Vector from 0 to 1
            cx = df["x_1"] - df["x_0"]
            cy = df["y_1"] - df["y_0"]
            cz = df["z_1"] - df["z_0"]
        else:
            # Vector from 1 to 0
            cx = df["x_0"] - df["x_1"]
            cy = df["y_0"] - df["y_1"]
            cz = df["z_0"] - df["z_1"]

        c_norm = np.sqrt(cx**2 + cy**2 + cz**2)

        # Ensure ID for merge
        if "id" not in df.columns:
            df["temp_id"] = np.arange(len(df))
            merge_id = "temp_id"
        else:
            merge_id = "id"

        # Prepare small DF for merge
        df_merge = df[[merge_id, "molecule_name", atom_idx_col]].copy()
        df_merge["cx"] = cx
        df_merge["cy"] = cy
        df_merge["cz"] = cz
        df_merge["c_norm"] = c_norm

        # Merge with edges to get all neighbors
        # Edges columns: molecule_name, atom_index_0 (center), dx, dy, dz (to neighbor)
        merged = pd.merge(
            df_merge,
            self.edges[["molecule_name", "atom_index_0", "dx", "dy", "dz"]],
            left_on=["molecule_name", atom_idx_col],
            right_on=["molecule_name", "atom_index_0"],
            how="left",
            suffixes=("", "_edge")
        )

        # Calculate Cosine
        # neighbor vector N = (dx, dy, dz)
        dot = merged["cx"] * merged["dx"] + merged["cy"] * merged["dy"] + merged["cz"] * merged["dz"]
        n_norm = np.sqrt(merged["dx"]**2 + merged["dy"]**2 + merged["dz"]**2)
        
        merged["cosine"] = dot / (merged["c_norm"] * n_norm + 1e-9)

        # Aggregate
        grp = merged.groupby(merge_id)["cosine"]
        agg = grp.agg(["mean", "min", "max", "std"]).add_prefix(f"{prefix}_cos_")

        # Merge back
        df = pd.merge(df, agg, left_on=merge_id, right_index=True, how="left")

        # Fill NaNs
        fill_cols = [f"{prefix}_cos_{stat}" for stat in ["mean", "min", "max", "std"]]
        df[fill_cols] = df[fill_cols].fillna(0)

        if "temp_id" in df.columns:
            df = df.drop(columns=["temp_id"])

        return df
