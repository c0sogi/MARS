My implementation strategy focuses on improving the geometric feature engineering by adopting a "Late Aggregation" approach for angular features, as suggested by Lesson 28 (Cite solution_lesson_node_00028) and Lesson 22 (Cite solution_lesson_node_00022). Instead of pre-aggregating neighbor vectors and then calculating the cosine with the coupling axis (which loses anisotropy information), I will calculate the cosine similarity for *each* neighbor bond individually and then aggregate the statistics (min, max, mean, std).

1.  **Modify `GraphFeatureEngine`**: Update it to calculate unit vectors for all bonds and return the full `edges` dataframe alongside the node features. This allows downstream access to individual neighbor vectors.
2.  **Modify `DataProcessor`**: Update it to accept the `edges` dataframe. Implement a vectorized "Late Aggregation" routine that merges the coupling pairs with the `edges` dataframe to compute the cosine of the angle between the coupling axis and every neighbor bond, followed by aggregation by coupling ID.

class DataProcessor:
    def __init__(self, node_features, edges):
        self.node_features = node_features
        self.edges = edges

    def _add_angular_features(self, df, atom_idx_col, coupling_vec_cols, suffix):
        """
        Calculates angular features using Late Aggregation (Cite solution_lesson_node_00028).
        Merges edges to get all neighbors, computes individual cosines, then aggregates.
        """
        # Prepare coupling vector components (normalized)
        cx, cy, cz = coupling_vec_cols
        dist = df["dist"] + 1e-9
        
        # Create a temp dataframe with just the necessary info for the join
        # We need the coupling vector for each 'id'
        df_vec = df[["id", "molecule_name", atom_idx_col]].copy()
        df_vec["cx"] = df[cx] / dist
        df_vec["cy"] = df[cy] / dist
        df_vec["cz"] = df[cz] / dist

        # Merge with edges to get neighbors
        # Edges has: molecule_name, atom_index_0 (source), ux, uy, uz
        edges_subset = self.edges[["molecule_name", "atom_index_0", "ux", "uy", "uz"]]
        
        merged = pd.merge(
            df_vec,
            edges_subset,
            left_on=["molecule_name", atom_idx_col],
            right_on=["molecule_name", "atom_index_0"],
            how="left"
        )
        
        # Calculate Cosine for each neighbor
        # cos = c . u (both are unit vectors)
        merged["cos"] = (
            merged["cx"] * merged["ux"] +
            merged["cy"] * merged["uy"] +
            merged["cz"] * merged["uz"]
        )
        
        # Fill NaN cosines (no neighbors) with 0
        merged["cos"] = merged["cos"].fillna(0)
        
        # Aggregate by coupling ID
        agg_funcs = ["mean", "min", "max", "std"]
        stats = merged.groupby("id")["cos"].agg(agg_funcs)
        stats.columns = [f"cos_{suffix}_{fn}" for fn in stats.columns]
        
        # Merge stats back to main df
        df = pd.merge(df, stats, on="id", how="left")
        
        # Fill NaNs from merge (std can be NaN if 1 neighbor)
        df = df.fillna(0)
        
        return df
