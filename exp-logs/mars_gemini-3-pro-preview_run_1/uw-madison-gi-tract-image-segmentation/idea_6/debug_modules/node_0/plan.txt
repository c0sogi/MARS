The following implementation strategy outlines the steps to verify the provided machine learning pipeline for 3D stomach and intestine segmentation.

1.  **Configuration Override**: We will modify the `Config` class attributes at runtime to enable `DEBUG` mode (reducing the dataset to just 2 cases) and set `EPOCHS` to 1. This ensures the entire pipeline runs quickly within the time limit.
2.  **Unit Testing Utilities**: We will validate the correctness of helper functions. Specifically, we will verify that `rle_encode` and `rle_decode` are consistent inverses of each other, and that `keep_largest_component_3d` correctly removes disconnected noise from a 3D volume.
3.  **Data Loading Verification**: We will initialize the data loaders using `create_dataloaders`. We will fetch a single batch to assert that the input tensor shapes (Batch, Channel, Depth, Height, Width) and data types match the model's expected input.
4.  **Model and Loss Verification**: We will instantiate the `ResNet3DUNet` and `BCEDiceLoss`. We will perform a forward pass with the fetched batch to confirm the output shape is correct and that the loss calculation yields a valid scalar.
5.  **Full Training Loop Integration**: We will instantiate the `Trainer` class and execute `fit()`. This tests the training step, validation loop, sliding window inference, and checkpoint saving mechanisms.
6.  **Inference and Submission**: We will execute `predict_and_submit()` to generate predictions on the test set (subset) and verify that the output `submission.csv` is created with the correct format and content.
