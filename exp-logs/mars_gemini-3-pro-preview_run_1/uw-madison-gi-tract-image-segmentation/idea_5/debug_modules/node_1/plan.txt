The issue is that the `albumentations.pytorch.ToTensorV2` transform converts images to "Channel-First" (CHW) format but leaves masks in "Height-Width-Channel" (HWC) format by default, causing a dimension mismatch in the DataLoader output (Cite debug_lesson_2). The fix is to explicitly instantiate `ToTensorV2` with `transpose_mask=True` in the `get_transforms` function within `library/dataset.py`. This ensures that multi-channel masks are correctly transposed to the (C, H, W) format expected by the model and loss function.
