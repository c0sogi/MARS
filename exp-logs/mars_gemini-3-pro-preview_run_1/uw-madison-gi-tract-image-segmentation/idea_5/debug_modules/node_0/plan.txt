Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and modify settings for a rapid demonstration. This includes enabling debug mode (which subsets the data), reducing the number of epochs to 1, setting a smaller batch size, and reducing image resolution to speed up processing.
2.  **Data Loading & Verification**: Use `prepare_loaders` to initialize data loaders. Fetch a single batch to verify the input shapes (checking for the 4-channel input: RGB + Depth) and target shapes (3 classes). Assert that data normalization and type casting are correct.
3.  **Model & Loss Verification**: Instantiate the `UnetPlusPlus` model and `WeightedDeepSupervisionLoss`. Perform a forward pass with the dummy batch to verify that the model outputs a list of tensors (due to deep supervision) and that the loss function computes a valid scalar gradient.
4.  **Training Simulation**: Execute the `run_training` function. This utilizes the `Trainer` class to run a full training cycle (1 epoch) and saves the best model checkpoint.
5.  **Inference & Submission**: Execute `predict_and_submit` to generate predictions on the test set using the trained checkpoint. Verify that the submission file is created and adheres to the required format (columns and RLE encoding).
6.  **Metric Utility Check**: Manually test the metric functions (`get_dice_coef`, `get_3d_hausdorff`) with synthetic binary volumes to ensure they behave as expected.
