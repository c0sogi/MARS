This script demonstrates the end-to-end pipeline for the stomach and intestine segmentation task using the provided library files. It verifies the functionality of utility functions, the data loading pipeline, the model architecture, the training loop, and the evaluation/submission generation process.

The strategy is as follows:
1.  **Utility Verification**: validates core helper functions like RLE encoding/decoding and normalization to ensure data transformations are correct.
2.  **Dataset & Model Verification**: Manually instantiates the dataset and model to verify input/output shapes and tensor types before starting the training loop.
3.  **Training Demonstration**: Runs the training loop for a single epoch on a small subset of data (Debug Mode) to verify the training stability and checkpoint generation.
4.  **Evaluation & Submission**: Runs the inference pipeline on validation and test subsets to verify metric calculation and submission file generation.
