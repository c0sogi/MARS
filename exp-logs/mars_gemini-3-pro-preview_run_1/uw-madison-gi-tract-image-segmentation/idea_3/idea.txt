Based on the lessons learned and the analysis of the previous approach, I propose the following optimized strategy. This solution transitions from a purely 2D slice-by-slice approach to a **2.5D Volumetric approach** to better capture spatial continuity, upgrades the backbone for better feature extraction, and implements rigorous post-processing to stabilize the Hausdorff metric.

# Model
I propose a **2.5D U-Net architecture** utilizing an **EfficientNet-B1 backbone**.
*   **2.5D Input Context:** Instead of treating each MRI slice as an independent 2D image, the model will accept a 3-channel input consisting of the current slice $z$, the previous slice $z-1$, and the next slice $z+1$. This allows the network to leverage inter-slice spatial context, helping to disambiguate organ boundaries that are unclear in a single cross-section. Standard ImageNet pre-trained weights can still be effectively utilized since the input remains a 3-channel tensor.
*   **Backbone Upgrade:** We will replace the ResNet-18 backbone with **EfficientNet-B1**. This offers a stronger feature extractor with a slightly larger receptive field and better parameter efficiency, addressing the low Dice scores observed in the baseline while remaining well within the 24-hour compute budget.
*   **Decoder:** A standard U-Net decoder with skip connections will be used to aggregate features from the EfficientNet encoder levels, terminating in a segmentation head with 3 output channels (one per class).

# Data
*   **Preprocessing (2.5D Stacking):**
    *   We will generate 3-channel images for every slice ID by stacking adjacent slices. For the first and last slices of a scan, we will replicate the available slice to maintain the 3-channel depth.
*   **Robust Normalization:**
    *   To address the failure on dark/low-contrast images identified in the previous analysis, we will replace simple Min-Max scaling with **Percentile Normalization**. We will calculate the 1st and 99th percentiles of pixel intensities per image (or per case volume) and clip values to this range before scaling to [0, 1]. This prevents extreme outliers from compressing the dynamic range of the organ tissues.
*   **Resolution:**
    *   We will increase the input resolution from 256x256 to **320x320**. This aligns closer to the median resolution of the dataset (266x266 and 360x310), reducing the loss of fine-grained boundary details caused by downsampling.
*   **Augmentation:**
    *   We will apply spatial augmentations (RandomRotate90, Flip, ShiftScaleRotate) and Elastic Transforms to simulate anatomical variations.

# Training
*   **Loss Function:** We will use a combined **BCE + Dice Loss**. The Binary Cross Entropy provides smooth gradients for pixel-level classification, while the Dice Loss directly optimizes the overlap metric.
*   **Optimizer:** We will use the **AdamW** optimizer with a Cosine Annealing learning rate scheduler to ensure efficient convergence.
*   **Strategy:** Training will proceed on the 2.5D inputs using the case-aware split defined in the metadata.

# Evaluation
*   **3D Reconstruction Pipeline:**
    *   We will strictly adhere to the "reconstruct-then-score" methodology. The model will predict 2D masks for all slices in a validation case, which will then be stacked into a full 3D volume before calculating metrics. This ensures the validation score accurately reflects the 3D Hausdorff distance, which is non-additive and cannot be averaged across slices. **Cite solution_lesson_node_00006**.
*   **Post-Processing (Noise Removal):**
    *   To address the volatility of the Hausdorff metric caused by stray pixel predictions, we will apply **3D Connected Component Analysis (CCA)** (or 2D CCA per slice if 3D is computationally prohibitive) during inference. For each class, we will retain only the largest connected volume (or area) and zero out smaller disconnected clusters. This effectively removes "shot noise" outliers that would otherwise drastically penalize the Hausdorff score. **Cite solution_lesson_node_00007**.
