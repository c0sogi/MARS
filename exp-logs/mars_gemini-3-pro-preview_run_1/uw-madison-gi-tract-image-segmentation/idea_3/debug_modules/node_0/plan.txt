The following script demonstrates the end-to-end usage of the provided machine learning pipeline for MRI segmentation. It performs the following steps:

1.  **Configuration**: Overrides default `Config` settings to enable a high-speed "Debug Mode" (fewer epochs, smaller dataset, specific working directories) suitable for demonstration within the time limit.
2.  **Utility Verification**: Validates core utility functions, including Run-Length Encoding (RLE) round-trip consistency and metric calculations (Dice and Hausdorff), using synthetic data to ensure correctness.
3.  **Data Pipeline Verification**: Initializes the data loaders in debug mode and inspects a single batch to verify tensor shapes, data types, and value ranges (e.g., image normalization and binary masks).
4.  **Model Architecture Verification**: Instantiates the 2.5D U-Net model, performs a forward pass with a sample batch, and asserts that the output dimensions match the input resolution and class count.
5.  **Training & Inference Loop**: executing the `Trainer` class to run a complete training epoch, validation step, and submission generation. It finally asserts that the model checkpoints and submission files are correctly generated.
