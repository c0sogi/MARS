If the rows are shuffled or interleaved (due to the `DataLoader` or dictionary iteration order), the grader attempts to stack slices from different cases (which have different shapes), causing the `InvalidSubmissionError: all input arrays must have the same shape`. To fix this, we will load the `sample_submission.csv` file and use it as a template, populating its `predicted` column with our model's predictions via a lookup map. This ensures the final submission exactly matches the structure and order expected by the evaluation system (Cite debug_lesson_4).
