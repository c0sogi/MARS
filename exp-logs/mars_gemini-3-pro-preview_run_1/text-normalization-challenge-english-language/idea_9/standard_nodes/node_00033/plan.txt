The implementation strategy is as follows:

1.  **Configuration & Setup**: Import the `Config` class and override specific parameters to ensure a fast baseline execution. Specifically, set `DEBUG = True` to use a subset of data (50k samples) and reduce `NUM_EPOCHS` to 5. This satisfies the requirement to limit training samples and runtime.
2.  **Knowledge Base Construction**: Explicitly build the Knowledge Base (KB) using the full training dataset. This is crucial because the KB handles the majority of normalization cases (93%+), and building it from the full set maximizes validation accuracy even if the neural models are trained on a subset.
3.  **Model Training**: Execute `train_models(debug=True)`. This trains both the Multi-Granularity Bi-LSTM Tagger and the Transformer Seq2Seq fallback model using the debug configuration.
4.  **Full Validation**:
    *   Load the complete validation dataset from `./metadata/val.csv`.
    *   Load the trained Tagger and Seq2Seq models.
    *   Implement a validation loop that replicates the inference pipeline: Predict Class $\rightarrow$ KB Lookup $\rightarrow$ Seq2Seq Fallback.
    *   Compare predicted strings against the ground truth `after` column to compute the exact accuracy.
    *   Print the result in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Identify incorrect predictions from the validation pass.
    *   Calculate correlations between the error (binary) and input features like token length and class ID to identify systematic weaknesses.
6.  **Submission**:
    *   Check if the validation accuracy exceeds the threshold (0.9949142925818993).
    *   If successful, instantiate the `NormalizationPipeline` with `debug=False` to process the full test set and generate `./submission/submission.csv`.
