The issue is caused by a mismatch between the reduced dataset size used in debug mode (5,000 samples) and the default BPE vocabulary size (30,000). SentencePiece raises a `RuntimeError` because the small input corpus does not contain enough unique subword units to support the requested vocabulary size. To resolve this, I will update `runfile.py` to lower `Config.BPE_VOCAB_SIZE` (e.g., to 2,000) when setting up the demo environment. This applies the principle of synchronizing hyperparameters with data sources when subsetting for debugging (Cite debug_lesson_10).
