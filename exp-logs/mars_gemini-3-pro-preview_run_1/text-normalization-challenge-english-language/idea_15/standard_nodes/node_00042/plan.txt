Here is the implementation of `runfile.py`.

The strategy involves:
1.  **Configuration Override**: Adjusting `Config` parameters to enable a fast baseline run (using `DEBUG` mode with 300k samples, 1 epoch, and large batch sizes) while utilizing the powerful NVIDIA A100 GPU.
2.  **Data Preparation**: Building vocabularies and the Knowledge Base (KB) using cached data where possible. Crucially, the KB is built from the full training set (via `FeatureEngineer`), providing a strong deterministic backbone even if the neural models are trained on a subset.
3.  **Training**: Training the `GatedBiLSTMTagger` and `Seq2SeqFallback` models using `ModelTrainer`.
4.  **Full Validation**: Performing a rigorous evaluation on the **entire** validation set (not the debug subset) to compute the official "Final Validation Metric". This involves a hybrid inference pipeline: Tagger Classification -> KB Lookup -> Seq2Seq Fallback.
5.  **Failure Analysis**: Analyzing error patterns on the validation set, specifically calculating the correlation between token length and prediction error.
6.  **Submission**: Generating the submission file for the test set using the `Predictor` class, strictly conditional on the validation metric exceeding the specified threshold.
