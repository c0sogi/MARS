Based on the comprehensive analysis of the accumulated lessons and the evolution of previous ideas, I propose the **Gated Multi-Granularity Bi-LSTM Tagger with Recurrent Neural Fallback**.

This solution represents a structural evolution of the "Prior-Informed" strategies. It addresses the "Input Fidelity" bottleneck **Cite {solution_lesson_node_00009}** using a rich feature set, but introduces a **Gated Feature Fusion** mechanism to intelligently balance these features, preventing the model from over-relying on priors. Crucially, it strictly enforces the architectural choices (Bi-LSTM Tagger, LSTM Fallback) that have proven superior to Transformers/CRFs for this specific domain **Cite {solution_lesson_node_00012}** **Cite {solution_lesson_node_00037}**.

# Model

The architecture follows the decoupled "Classify-Retrieve-Generate" paradigm **Cite {solution_lesson_node_00005}**, splitting the task into semantic classification and conditional normalization.

1.  **Stage 1: Gated Multi-Granularity Tagger (Classification)**
    *   **Input Representation (Penta-Hybrid):** To maximize fidelity and capture both memorized and morphological signals:
        1.  **Word Embeddings:** Large vocabulary (100k+) to capture high-level semantics.
        2.  **Subword (BPE) Embeddings:** To capture semantic stems for rare words (e.g., "bio", "graphy") **Cite {solution_lesson_node_00009}**.
        3.  **Character-Level CNN:** A 1D-CNN extracting local morphological features (e.g., suffixes, capitalization).
        4.  **Explicit Morphological Features:** Dense vector of Regex flags (e.g., `is_digit`, `is_date_format`).
        5.  **Global Prior Features:** Empirical class probability vector from the training set.
    *   **Structural Innovation (Gated Fusion):** Instead of simple concatenation, we introduce a **Gated Feature Fusion Layer**. A learnable gating network (Dense + Sigmoid) dynamically assigns weights to the "Memorization Features" (Word Emb, Priors) and "Generalization Features" (BPE, Char-CNN, Regex) based on the input. This allows the model to explicitly trust Priors for known tokens while suppressing them in favor of morphological signals for Out-Of-Vocabulary (OOV) tokens, resolving the conflict between memory and generalization.
    *   **Backbone:** The fused representation is fed into a **Bi-directional LSTM (Bi-LSTM)**. This recurrent architecture is retained as it converges significantly faster and captures local dependencies more effectively than Transformers for this specific tagging task **Cite {solution_lesson_node_00012}**.
    *   **Head:** A standard **Softmax Classification Head**. We explicitly reject the Conditional Random Field (CRF), as lessons prove it hinders convergence for this locally-determinable task **Cite {solution_lesson_node_00028}**.

2.  **Stage 2: Hybrid Normalization Strategy**
    *   **Primary (Deterministic Memory):** A **Knowledge Base (KB)** maps `(raw_token, predicted_class)` pairs to their normalized text. This handles the vast majority of cases (93%+) with 100% precision.
    *   **Secondary (Neural Fallback):** For OOV tokens, we employ a **Character-Level LSTM Seq2Seq Model**.
        *   **Strategic Retention:** We explicitly use an **LSTM** (not a Transformer) for the fallback. As identified in **Cite {solution_lesson_node_00037}**, LSTMs outperform Transformers on character-level transduction tasks with rigid formatting rules (like dates/numbers) due to their inherent sequential inductive bias.
        *   **Conditioning:** The model is conditioned on the **Class Embedding** predicted by the Tagger.

# Data

1.  **Knowledge Base & Prior Construction:**
    *   Use the **entire training dataset** to build the KB and compute Global Prior vectors. Maximizing coverage is the single most effective way to reduce error **Cite {solution_lesson_node_00007}**.
2.  **Tagger Data:**
    *   Train a BPE tokenizer on the corpus.
    *   Pre-calculate Regex flags and Global Prior vectors for all tokens.
3.  **Fallback Data:**
    *   Filter the training data to include only token pairs where `before != after`. This focuses the generative model on non-trivial transformations **Cite {solution_lesson_node_00027}**.

# Training

1.  **Tagger Training:**
    *   **Loss Function:** Cross-Entropy Loss with **Square-Root Smoothed Class Weights** ($\sqrt{N/N_c}$). This penalizes errors on rare classes without the gradient instability caused by raw inverse frequency weights **Cite {solution_lesson_node_00013}**.
    *   **Optimizer:** **Adam** optimizer paired with a **ReduceLROnPlateau** scheduler. This dynamic schedule is critical for allowing the LSTM to escape local minima **Cite {solution_lesson_node_00011}**.
    *   **Regularization:** Apply **Feature Dropout** specifically to the Global Prior vector (randomly zeroing it out with $p=0.2$) to force the Gated Fusion layer to learn robust fallback weights.
2.  **Fallback Training:**
    *   Train the LSTM Seq2Seq using standard Cross-Entropy Loss with Teacher Forcing on the filtered "changed" dataset.

# Evaluation

1.  **Inference Pipeline:**
    *   **Step 1 (Feature Extraction):** Generate Word, BPE, Char-CNN, Regex, and Global Prior features for the test sentence. (Test tokens use zero vectors for Priors if unseen).
    *   **Step 2 (Tagging):** Pass features through the **Gated Multi-Granularity Bi-LSTM** to predict the class.
    *   **Step 3 (Retrieval):** Query the **Knowledge Base** using `(token, predicted_class)`. If a match is found, return the stored value.
    *   **Step 4 (Generation):** If the pair is missing from the KB (OOV) and the class is not `PLAIN`, pass the token and its class to the **LSTM Seq2Seq Fallback Model** to generate the normalized text **Cite {solution_lesson_node_00027}**.
