The issue is that the `verbose` parameter has been removed from the `ReduceLROnPlateau` scheduler in PyTorch versions 2.2 and newer, causing a `TypeError` during initialization. To fix this, I will remove the `verbose=True` argument from the `ReduceLROnPlateau` instantiation in both the `TaggerEngine` and `Seq2SeqEngine` classes within `library/engine.py`. This aligns with the guidance in Cite debug_lesson_2 regarding updating deprecated arguments.
