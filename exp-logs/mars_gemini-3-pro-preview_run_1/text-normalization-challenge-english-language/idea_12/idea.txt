Based on the accumulated lessons, I propose the **Morphologically-Enhanced Bi-LSTM Tagger with Recurrent Neural Fallback**.

This strategy synthesizes the robust architectural choices of the "Current Best" solution (Idea 5) with the advanced feature engineering concepts attempted in Idea 11, while explicitly discarding the components that led to recent failures (Transformers for short-string generation and CRFs for local classification).

### Model
The solution follows the decoupled "Classify-Retrieve-Generate" paradigm **Cite {solution_lesson_node_00005}**, optimized for input fidelity and generative stability.

1.  **Stage 1: Morphologically-Enhanced Tagger (Classification)**
    *   **Structural Innovation (Input):** To address the "Input Fidelity" bottleneck **Cite {solution_lesson_node_00009}** and the "Needle-in-a-haystack" nature of the task, we will employ a **Tri-Hybrid Input Representation**:
        1.  **Word Embeddings:** A trainable embedding layer with a maximized vocabulary size (100k+) to capture high-level semantics.
        2.  **Character-Level CNN:** A 1D-CNN processing character sequences to extract learned morphological features.
        3.  **Explicit Morphological Features:** A dense vector of binary flags derived from **Regex Matching** (e.g., `is_digit`, `is_date_format`, `has_currency_symbol`, `is_capitalized`). This integrates the "Wide" feature approach from Idea 11, forcing the model to attend to specific lexical cues that define rare classes, but pairs it with the robust Bi-LSTM backbone instead of the fragile Transformer setup.
    *   **Backbone:** The concatenated representation is fed into a **Bi-directional LSTM (Bi-LSTM)**. We explicitly retain this recurrent architecture as it converges significantly faster and captures local dependencies more effectively than Transformers for this specific tagging task **Cite {solution_lesson_node_00012}**.
    *   **Head:** A standard **Softmax Classification Head**. We explicitly reject the Conditional Random Field (CRF) layer, as lessons prove it hinders convergence for this locally-determinable task **Cite {solution_lesson_node_00028}**.

2.  **Stage 2: Hybrid Normalization Strategy**
    *   **Primary (Deterministic Memory):** A **Knowledge Base (KB)** maps `(raw_token, predicted_class)` pairs to their normalized text. This handles the vast majority of cases with 100% precision.
    *   **Secondary (Neural Fallback):** For Out-of-Vocabulary (OOV) tokens, we employ a **Character-Level LSTM Seq2Seq Model with Attention**.
        *   **Strategic Retention:** We revert to the **LSTM-based** fallback used in Idea 5, explicitly rejecting the Transformer fallback from Idea 11. As identified in **Cite {solution_lesson_node_00037}**, LSTMs outperform Transformers on character-level transduction tasks with rigid formatting rules and constrained training budgets due to their inherent sequential inductive bias.
        *   **Conditioning:** The model is conditioned on the **Class Embedding** predicted by the Tagger.

### Data
1.  **Knowledge Base Construction:** We will construct the KB using the **entire training dataset** to maximize coverage, as performance is bounded by memory capacity **Cite {solution_lesson_node_00007}**.
2.  **Tagger Data:** The Tagger is trained on the full dataset. We will pre-calculate the Explicit Regex Feature vectors for all tokens in the corpus.
3.  **Fallback Data:** We will create a specialized dataset by filtering the training data to include only token pairs where `before != after`. This focuses the generative model on non-trivial transformations **Cite {solution_lesson_node_00027}**.

### Training
1.  **Tagger Training:**
    *   **Loss Function:** Cross-Entropy Loss with **Square-Root Smoothed Class Weights** ($\sqrt{N/N_c}$). This penalizes errors on rare classes (like `MONEY`) without the gradient instability caused by raw inverse frequency weights **Cite {solution_lesson_node_00013}**.
    *   **Optimizer:** We will use the **Adam** optimizer paired with a **ReduceLROnPlateau** scheduler. This dynamic schedule is critical for allowing the LSTM to escape local minima and converge to a better generalization point than static rates **Cite {solution_lesson_node_00011}**.
2.  **Fallback Training:** The LSTM Seq2Seq will be trained using standard Cross-Entropy Loss with Teacher Forcing on the filtered "changed" dataset.

### Evaluation
1.  **Inference Pipeline:**
    *   **Step 1 (Tagging):** Generate Word, Char-CNN, and Regex features for the test sentence and pass them through the **Morphologically-Enhanced Bi-LSTM** to obtain the predicted class.
    *   **Step 2 (Retrieval):** Query the **Knowledge Base** using `(token, predicted_class)`. If a match is found, return the stored value.
    *   **Step 3 (Generation):** If the pair is missing from the KB (OOV) and the class is not `PLAIN`, pass the token and its class to the **LSTM Seq2Seq Fallback Model** to generate the normalized text. This ensures robust handling of unseen entities while leveraging the superior sequential modeling of LSTMs **Cite {solution_lesson_node_00037}**.
