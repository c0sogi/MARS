Based on the accumulated lessons and the task requirements, I propose the **Multi-Granularity Hybrid System with Neural Fallback**. This strategy introduces a structural innovation in input representation (combining character and word features) and fallback generation, while strictly retaining the successful architectural choices (Bi-LSTM, Decoupling) from previous iterations.

# Model
The solution employs a multi-stage pipeline that decouples semantic classification from text normalization, ensuring high accuracy and robustness.

1.  **Stage 1: Multi-Granularity Tagger (Classification)**
    *   **Structural Innovation (Input):** To address the "Input Fidelity" issue **Cite {solution_lesson_node_00009}** and better handle Out-of-Vocabulary (OOV) tokens, we will augment the standard word embeddings with **Character-Level Embeddings**. A 1D-Convolutional Neural Network (CNN) will process the character sequence of each token to extract morphological features (e.g., digit patterns, suffixes). This character vector will be concatenated with the word embedding. This allows the model to classify unseen tokens (like new dates or serial numbers) based on their internal structure rather than just their identity.
    *   **Backbone:** We retain the **Bi-LSTM** architecture for the tagging task, as it has proven to converge significantly faster and more reliably than raw Transformers on this specific dataset **Cite {solution_lesson_node_00012}**. The Bi-LSTM processes the concatenated Word+Char representations to predict the semantic class (e.g., `DATE`, `CARDINAL`) of each token.

2.  **Stage 2: Cascade Decoder (Normalization)**
    *   The normalization process follows a hierarchy:
        *   **Tier 1 (Memory):** Query a deterministic **Knowledge Base (KB)**. This exploits the finding that performance is bounded by memory coverage **Cite {solution_lesson_node_00007}**.
        *   **Tier 2 (Neural Fallback):** For tokens not found in the KB (OOV), we replace brittle regex heuristics with a **Character-Level Seq2Seq Model** (Encoder-Decoder with Attention). This lightweight model is trained to translate raw text into normalized text, conditioned on the class predicted by the Tagger. This maintains the benefits of decoupling ambiguity resolution from generation **Cite {solution_lesson_node_00005}**.

# Data
1.  **Knowledge Base Construction:** Iterate through the **entire training dataset** to build the `(raw_token, predicted_class) -> normalized_text` map, ensuring maximum coverage **Cite {solution_lesson_node_00007}**.
2.  **Tagger Data:** Prepare the full dataset for sequence labeling. Create a vocabulary for words (maximized size to reduce `<UNK>` **Cite {solution_lesson_node_00009}**) and a vocabulary for characters.
3.  **Seq2Seq Data:** Filter the training data to extract only the tokens where `before != after`. This creates a focused dataset of "non-trivial" normalizations to train the Neural Fallback model efficiently.

# Training
1.  **Tagger Training:**
    *   **Loss Function:** Use Cross-Entropy Loss with **Square-Root Smoothed Class Weights** ($\sqrt{N/N_c}$). This balances the need to penalize rare class errors without destabilizing the gradients, correcting the regression observed with raw inverse frequency weights **Cite {solution_lesson_node_00013}**.
    *   **Optimization:** Use the **Adam** optimizer with a **ReduceLROnPlateau** scheduler. This dynamic learning rate schedule is critical for allowing the LSTM to escape local minima early in training **Cite {solution_lesson_node_00011}**.
2.  **Seq2Seq Training:** Train the fallback model on the filtered "changed" dataset using standard teacher forcing.

# Evaluation
1.  **Inference:**
    *   Pass the test sentence through the **Multi-Granularity Tagger** to obtain the predicted class for each token.
    *   For each token, check the **Knowledge Base** using the pair `(token, class)`.
    *   **Hit:** If found, return the stored value.
    *   **Miss:** If not found and the class is not `PLAIN`, pass the token and its predicted class to the **Seq2Seq Fallback Model** to generate the normalized string.
