The following script demonstrates the end-to-end workflow using the provided library. It performs the following steps:
1.  **Configuration**: Overrides default configuration parameters to run in `DEBUG` mode with a small dataset subset and reduced model sizes for rapid execution.
2.  **Vocabulary & Data**: Builds vocabularies, initializes the `DataManager`, creates the Knowledge Base, and computes class weights.
3.  **Tagger Training**: Prepares grouped data (sentences), initializes the `BiLSTMTagger`, and trains it for one epoch.
4.  **Seq2Seq Training**: Prepares filtered data (changed tokens), initializes the `TransformerSeq2Seq` model, and trains it for one epoch.
5.  **Inference**: Instantiates the `InferencePipeline` (which loads the saved models) and generates predictions on the test set, producing a submission file.
6.  **Validation**: Asserts that key artifacts (checkpoints, submission file) are created successfully.
