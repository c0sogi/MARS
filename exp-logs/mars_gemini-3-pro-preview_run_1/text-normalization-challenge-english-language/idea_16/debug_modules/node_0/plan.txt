This script demonstrates the end-to-end usage of the provided text normalization library. It begins by configuring a lightweight demonstration environment by overriding the default `Config` parameters (reducing epochs, batch sizes, and redirecting paths to a temporary directory). It then creates a small subset of the training data to ensure the pipeline runs quickly. The script proceeds to build necessary artifacts (vocabularies, knowledge base), trains both the Tagger and Seq2Seq models for a single epoch, and finally executes the inference pipeline to generate a submission file. Assertions are included at each step to verify the correct generation of files and model checkpoints.
