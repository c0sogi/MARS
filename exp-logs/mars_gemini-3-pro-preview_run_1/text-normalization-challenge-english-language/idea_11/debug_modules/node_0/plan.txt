This script demonstrates the end-to-end workflow of the text normalization solution using the provided library. It performs the following steps:

1.  **Environment Setup**: Monkey-patches `tqdm` to suppress progress bars as requested and sets random seeds for reproducibility.
2.  **Data Subsetting**: Creates small subsets of the training, validation, and test metadata in the `./working` directory. This ensures the demonstration runs quickly (within minutes) compared to processing the full multi-million row dataset.
3.  **Configuration Override**: Modifies the global `Config` class to point to these new subset files and reduces hyperparameters (epochs, batch size, vocabulary size) for speed.
4.  **Vocabulary & Feature Initialization**: Builds vocabularies, global priors, and the knowledge base from the subset data.
5.  **Data Loading**: Verifies the data loading pipeline by fetching a batch from the `TaggerDataset` and `Seq2SeqDataset`.
6.  **Model Training**: Runs a short training cycle (1 epoch) for both the Tagger (Bi-LSTM) and the Seq2Seq (Transformer) models using the `engine` module.
7.  **Inference**: Executes the inference pipeline on the test subset, utilizing the trained models and the knowledge base to generate predictions.
8.  **Validation**: Asserts that artifacts (models, submission files) are created correctly and that the output format matches requirements.
