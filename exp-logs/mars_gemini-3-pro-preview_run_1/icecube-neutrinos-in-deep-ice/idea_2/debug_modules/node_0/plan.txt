This script demonstrates the end-to-end pipeline for predicting neutrino directions using the provided library. It performs the following steps:
1.  **Data Loading**: Loads a subset of training and validation data using `data_loader.py`, ensuring feature engineering is performed on the fly.
2.  **Model Configuration**: Initializes the `DirectionalLGBM` model and overrides hyperparameters to ensure rapid execution for demonstration purposes.
3.  **Training**: Trains the model on the training subset and validates it on the validation subset.
4.  **Evaluation**: Predicts directions on the validation set, converts the output vectors to spherical coordinates, and calculates the mean angular error.
5.  **Inference & Submission**: Loads a subset of test data, generates predictions, and creates a submission file in the required format.

Throughout the process, assertions are used to verify data integrity, shapes, and value ranges.
