The issue is that PyTorch's `DataLoader` raises a `ValueError` if `persistent_workers=True` is used when `num_workers=0`. The `runfile.py` sets `Config.NUM_WORKERS = 0` for the demo to avoid multiprocessing overhead, but the `DataLoader` initialization in `library/data.py` has `persistent_workers=True` hardcoded.

To fix this, I will modify `library/data.py` to conditionally set `persistent_workers` to `True` only if `Config.NUM_WORKERS > 0`. This ensures compatibility when running in the main process (debug/demo mode) while maintaining performance optimizations for full training runs.
