Implementation Strategy:
1.  **Environment Setup**: Import necessary libraries and the provided modules. Set random seeds for reproducibility.
2.  **Data Subsetting**: Create a lightweight version of the metadata (train, val, test) containing only a few batches/events to ensure the demo runs quickly. Save these to a temporary working directory.
3.  **Configuration Override**: Modify the global `Config` class attributes to point to the subsetted metadata, reduce model complexity (hidden dimensions, layers), and limit training epochs to 1.
4.  **Utility Verification**: Validate the geometric conversion functions (`spherical_to_cartesian`, `cartesian_to_spherical`) and the metric function (`angular_dist_score`) using known inputs to ensure mathematical correctness.
5.  **Pipeline Integration**:
    *   **Data Loading**: Instantiate `IceCubeDataset` with the subsetted metadata. Verify `__getitem__` returns tensors of correct shapes. Test the `collate_fn` with a DataLoader.
    *   **Model Initialization**: Instantiate `DynGTNet` with the reduced configuration. Perform a forward pass with a dummy batch to verify tensor shape compatibility.
    *   **Training**: Initialize the `Trainer`. Run a single training epoch and a validation step. Assert that the loss is a valid float and model parameters have gradients.
    *   **Inference**: Run the inference engine to generate a submission file. Verify the output CSV format and content.
