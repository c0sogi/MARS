The issue is that `event_id` is stored as the index in the batch parquet files. When the script merges the batch data with the sensor geometry using `df_batch.merge(...)`, the index (`event_id`) is discarded because it is not part of the merge key. This causes the subsequent `groupby("event_id")` to fail with a `KeyError`. The fix is to explicitly reset the index of `df_batch` immediately after loading it, converting `event_id` into a regular column so it is preserved during the merge operation.
