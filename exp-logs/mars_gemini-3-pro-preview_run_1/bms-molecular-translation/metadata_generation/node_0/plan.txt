The implementation strategy involves the following steps:

1.  **Setup & Configuration**: Define the paths for input data (`./input`) and output metadata (`./metadata`). Set the random state to 42 and validation split ratio to 0.2 (20%).
2.  **Data Loading**: Read the `train_labels.csv` and `sample_submission.csv` files into pandas DataFrames.
3.  **Feature Engineering (File Paths)**: Construct the relative file path for each image. Based on the dataset description, the file structure uses the first three characters of the `image_id` as nested folder names (e.g., `train/0/0/0/000011a64c74.png`). This logic is applied to both train and test sets.
4.  **Data Splitting**: Split the training data into a training set (80%) and a validation set (20%) using `train_test_split`. A random split is used because the target labels (InChI strings) are unique sequences, making standard classification-based stratification impossible.
5.  **Metadata Export**: Save the prepared DataFrames (`train_metadata.csv`, `val_metadata.csv`, `test_metadata.csv`) to the `./metadata` directory.
6.  **Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (dataset shapes).
    *   Programmatically verify the split ratio matches the 80:20 requirement.
    *   Randomly sample 1000 file paths from each dataset and check if the files exist in the `./input` directory. Raise an error if the missing file ratio exceeds 50%.
