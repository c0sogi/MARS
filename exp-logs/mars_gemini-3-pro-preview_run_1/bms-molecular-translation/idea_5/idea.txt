Based on the empirical findings from the previous experiments, specifically the success of attribute conditioning and the identified failure mode regarding loss imbalance, I propose the **Attribute-Augmented Attention Network**. This strategy evolves Idea 4 by integrating the attribute guidance into a stronger attention-based architecture (from Idea 2) and explicitly fixing the optimization dynamics.

### Model
The architecture is a dual-branch Encoder-Decoder system designed to ground the sequence generation in both fine-grained spatial details and high-level chemical constraints.
*   **Encoder**: We upgrade the backbone from MobileNetV3 to **EfficientNet-B0**. This provides a richer feature hierarchy necessary for distinguishing complex atomic structures, addressing the potential underfitting of the lighter backbone. The encoder outputs both a spatial feature map (for attention) and a global feature vector (via Global Average Pooling).
*   **Attribute Branch**: A Multi-Layer Perceptron (MLP) projects the global feature vector to a set of regression targets: the normalized counts of specific atoms (C, H, O, N, S, Halogens) and the total InChI string length.
*   **Decoder**: A **Bahdanau Attention-based LSTM**.
    *   **Initialization**: The initial hidden and cell states of the LSTM are learned projections of the concatenated global visual features and the *predicted* attribute vector. This retains the strong initialization strategy from the previous lesson. Cite {solution_lesson_node_00008}.
    *   **Persistent Conditioning**: Unlike previous iterations where attributes were used only for initialization, the predicted attribute vector is **concatenation-injected** into the LSTM input at *every* time step, alongside the character embedding and the attention context vector. This forces the model to remain "aware" of the remaining atom budget throughout the generation of long InChI strings.

### Data
*   **Image Preprocessing**: Images are resized to $256 \times 256$ pixels and normalized using ImageNet statistics. Standard augmentations (random rotation, crop) are applied during training.
*   **Target Engineering (Normalization)**: To directly address the **Loss Imbalance** identified in the lesson, the regression targets (atom counts and length) are **Z-score normalized** (standardized) using the mean and standard deviation calculated from the training set. This scales the regression targets to a range (roughly -3 to 3) comparable to the gradients of the Cross-Entropy loss, preventing the auxiliary task from overwhelming the sequence learning. Cite {solution_lesson_node_00008}.
*   **Text Preprocessing**: Standard character-level tokenization with `<SOS>`, `<EOS>`, and `<PAD>` tokens.

### Training
*   **Loss Function**: A balanced Multi-Task Loss: $L_{total} = L_{CrossEntropy} + L_{MSE}$. Due to the target normalization step described above, we can set the weighting factor $\lambda \approx 1.0$ without the regression loss dominating the optimization trajectory.
*   **Optimizer**: **AdamW** with a "ReduceLROnPlateau" scheduler to fine-tune the learning rate as validation loss stagnates.
*   **Strategy**: Joint end-to-end training with **Teacher Forcing** for the sequence decoder. The attribute branch provides gradients to the encoder from epoch 0, helping to shape the visual representations to be chemically semantic before the decoder fully converges.

### Evaluation
*   **Inference Process**: The image is passed through the encoder to obtain spatial features and the predicted attribute vector. The decoder is initialized using these predictions.
*   **Generation**: We employ **Greedy Decoding**, generating the sequence character-by-character. At each step, the model attends to the spatial features and uses the persistent attribute vector to guide the prediction of the next character until `<EOS>` is reached.
