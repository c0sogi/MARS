Implementation strategy:
1.  **Configuration**: Initialize the `Config` class. Override `DEBUG` to `True` and set `DEBUG_SAMPLE_SIZE` to a reasonable number (e.g., 10,000) and `EPOCHS` to 2 to ensure the training phase completes quickly (fast baseline).
2.  **Training**: Execute `run_training(config)`. This uses the `DEBUG` setting to train on a subset of data.
3.  **Full Validation**:
    *   Switch `config.DEBUG` to `False` to ensure validation runs on the **entire** hold-out set as required.
    *   Reload the validation dataset using `prepare_datasets`.
    *   Load the trained model weights.
    *   Run inference in evaluation mode (`torch.no_grad()`) on the full validation set using the GPU.
    *   Collect predictions and ground truth texts.
4.  **Metric Calculation**: Compute the mean Levenshtein distance using the collected predictions. Print it in the specified format with full precision.
5.  **Failure Analysis**:
    *   Calculate the Levenshtein distance for each sample.
    *   Compute the correlation between the error (distance) and the length of the ground truth InChI string.
    *   Print the correlation.
6.  **Submission**:
    *   Compare the calculated validation metric against the threshold (81.60407868615773).
    *   If the metric is lower (better), run `generate_predictions(config)` to create the submission file.
