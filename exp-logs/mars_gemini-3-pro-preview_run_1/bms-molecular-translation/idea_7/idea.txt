Based on the lessons learned, specifically the importance of attribute conditioning and the need to manage loss imbalances, I propose the **Attribute-Modulated Visual Transformer (AM-ViT)**. This strategy structurally evolves the previous Transformer-based idea by replacing the "summary token" or simple concatenation methods with **Adaptive Layer Normalization (AdaLN)**. This mechanism, popular in generative modeling, allows the predicted chemical constraints to globally modulate the activations of the decoder, enforcing composition consistency at every layer of the generation process.

### Model
The architecture is a hybrid CNN-Transformer designed to inject global chemical constraints directly into the computation of the sequence decoder.
*   **Encoder**: We retain **EfficientNet-B0** as the backbone for its efficiency. It processes the input image to produce a spatial feature map (preserving structural grid information) and a global feature vector (via Global Average Pooling).
*   **Attribute Branch**: A Multi-Layer Perceptron (MLP) projects the global feature vector to a set of regression targets: the counts of specific atoms (C, H, O, N, S, Halogens) and the total InChI string length. Crucially, these targets are **Z-score normalized** to align the regression loss scale with the classification loss. Cite {solution_lesson_node_00008}.
*   **Conditioning Mechanism (Innovation)**: Instead of a static start token or memory concatenation, we implement **Adaptive Layer Normalization (AdaLN)** in the Transformer Decoder. The predicted attribute vector $z_{attr}$ is projected via linear layers to predict the scale ($\gamma$) and shift ($\beta$) parameters for the Layer Normalization operations within each decoder block. This effectively "styles" the sequence generation based on the predicted molecular formula, biasing the entire network towards the correct atom inventory.
*   **Decoder**: A **Transformer Decoder** (e.g., 4 layers). It uses Masked Self-Attention for the sequence and Cross-Attention over the encoder's spatial feature map. The AdaLN mechanism ensures that the global context (formula/length) modulates how these features are processed at every depth.

### Data
*   **Image Preprocessing**: Images are resized to **$256 \times 256$ pixels** and normalized using standard ImageNet mean and deviation.
*   **Attribute Engineering**: We parse the ground truth InChI strings to extract the counts of common atoms and the total sequence length. These values are **Z-score normalized** using statistics calculated from the training set (subtract mean, divide by std). This ensures the auxiliary task provides stable, balanced gradients. Cite {solution_lesson_node_00008}.
*   **Text Preprocessing**: InChI strings are tokenized at the character level. We use a fixed maximum sequence length (derived from EDA, e.g., 400) with padding.

### Training
*   **Loss Function**: A balanced Multi-Task Loss: $L_{total} = L_{CrossEntropy} + \lambda \cdot L_{MSE}$. Because the attribute targets are normalized, we set $\lambda \approx 1.0$, preventing the regression task from overwhelming the sequence learning while ensuring strong guidance. Cite {solution_lesson_node_00008}.
*   **Optimizer**: **AdamW** is used to handle the Transformer's weight decay requirements, coupled with a learning rate scheduler (Linear Warmup followed by Cosine Decay) to stabilize the early training phase of the attention mechanisms.
*   **Strategy**: The model is trained end-to-end. The attribute branch provides immediate supervision to the encoder, while the AdaLN mechanism forces the decoder to respect these predictions during the autoregressive learning process (Teacher Forcing).

### Evaluation
*   **Inference Process**: The test image is passed through the encoder to obtain spatial features and the predicted attribute vector. The attribute vector is used to generate the layer normalization parameters ($\gamma, \beta$) for the decoder.
*   **Decoding**: The Transformer decoder operates autoregressively using **Greedy Decoding**. It predicts characters one by one, conditioned on the spatial features and the globally modulated context, until the `<EOS>` token is generated.
