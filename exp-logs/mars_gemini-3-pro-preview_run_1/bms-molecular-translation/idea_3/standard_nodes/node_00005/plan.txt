Implementation Strategy:
1.  **Setup & Config Override**: Initialize the `Config` class and override `BATCH_SIZE` to 256 (to leverage A100 memory) and `EPOCHS` to 1 (for a fast baseline). Set random seeds.
2.  **Data Loading**: Load the generated metadata CSVs. To ensure the script runs within the 2-hour limit, subsample the training data to 30,000 samples and the validation data to 5,000 samples. Initialize the `Tokenizer` (loading from cache if available) and create `InChiDataset` and `DataLoader` instances for training, validation, and testing.
3.  **Model Initialization**: Instantiate the `VisualTransformer` model (ResNet18 Encoder + Transformer Decoder) and move it to the GPU. Setup `CrossEntropyLoss` and `AdamW` optimizer with a `OneCycleLR` scheduler.
4.  **Training**: Execute the training loop for 1 epoch using `train_one_epoch`. Save the model weights.
5.  **Validation**: Run inference on the validation subset using `greedy_decode`. Calculate the Levenshtein distance metric using `compute_levenshtein`. Print the final metric in the required format.
6.  **Failure Analysis**: Calculate the correlation between the Levenshtein distance (error) and the length of the ground truth InChI strings to identify if sequence length impacts performance. Print this correlation and a few worst-case examples.
7.  **Submission**: Run inference on the **entire** test set (loaded from `test_metadata.csv`). Use a slightly reduced `max_len` (275) during greedy decoding to optimize inference speed while covering the vast majority of chemical structures. Save the predictions to `submission.csv`.
