Implementation Strategy:
1.  **Setup & Configuration**: Import the provided library modules. Patch the `Config` class at runtime to reduce hyperparameters (epochs, batch size, embedding dimensions) and enable debug mode (small dataset subset) to ensure the script completes quickly.
2.  **Component Verification**:
    *   **Utils**: Verify `parse_inchi_attributes` correctly parses a sample InChI string into atom counts and length. Verify `compute_levenshtein` returns the correct edit distance.
    *   **Tokenizer**: Verify the round-trip conversion (text -> sequence -> text) preserves the original string.
3.  **Data Pipeline**: Initialize data loaders using `get_dataloaders` with a small `debug_size`. Verify the shape and types of the yielded batches (images, sequences, attributes).
4.  **Model Logic**: Instantiate the `AttributeConditionedModel`. Perform a forward pass with teacher forcing to verify the shapes of logits and attribute predictions. Perform an inference pass (`predict`) to verify the shape of generated sequences.
5.  **Training & Evaluation**: Execute `train_one_epoch` and `validate` on the debug dataset. This confirms the loss calculation, backpropagation, and metric tracking logic functions correctly without errors.
6.  **Inference Pipeline**: Run `generate_submission` using the model and test loader to produce a `submission.csv` file, verifying the end-to-end inference flow.
