This script performs a comprehensive Exploratory Data Analysis (EDA) on the training metadata and a representative sample of the raw data files (EEG and Spectrograms).

**Strategy:**
1.  **Setup & Configuration**: Initialize paths, constants, and random seeds for reproducibility.
2.  **Target Analysis**: Analyze the distribution of the probability targets (`*_prob`) and the derived "hard" labels (argmax) to understand class imbalance.
3.  **Tabular Metadata Analysis**: Examine the metadata columns (`eeg_label_offset_seconds`, `patient_id`, etc.) for distributions, missing values, and cardinality.
4.  **Signal (EEG) Analysis**: Randomly sample 100 EEG files to analyze signal dimensions, sampling rates (inferred from shape), missing values (NaNs), and amplitude statistics.
5.  **Image (Spectrogram) Analysis**: Randomly sample 100 Spectrogram files to analyze dimensions, channel/frequency structures, and pixel value distributions.
6.  **Feature Relationships**:
    *   Analyze correlations between the different target class probabilities.
    *   Investigate the relationship between metadata (e.g., offset seconds) and target classes.
    *   Train a lightweight Random Forest on the metadata features to assess their predictive power for the `expert_consensus`.
7.  **Output**: Print the findings in the specified format without unnecessary logs.
