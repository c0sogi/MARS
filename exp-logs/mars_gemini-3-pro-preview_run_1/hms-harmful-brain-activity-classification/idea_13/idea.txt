Based on the comprehensive analysis of the provided lessons and the structural evolution of previous iterations, I propose the **Auxiliary-Supervised Coordinate-Guided Fusion Network**.

This strategy structurally evolves the "Current Best" (Idea 10/11) by addressing the **Modality Imbalance** problem. While the Coordinate-Injected Spectrogram (Lesson 00011) is a strong predictor, the Raw EEG stream (Lesson 00002) is a weaker but complementary predictor. In standard fusion, the model often ignores the weaker stream, degenerating into a unimodal model. This new architecture introduces **Deep Auxiliary Supervision** and **Modality Dropout** to force the network to learn robust features from *both* streams independently before fusing them, maximizing the synergy between the high-resolution phase data (EEG) and the global spectral context (Spectrogram).

### 1. Model
The architecture is a multimodal network with three exit heads, designed to enforce feature quality across both streams.

*   **Stream A: Raw EEG Encoder (Waveform Stream)**
    *   **Backbone:** Retain the **Multi-Scale 1D Convolutional (Inception)** architecture.
    *   **Input:** 50-second raw EEG (20 channels), downsampled to 100 Hz **Cite {solution_lesson_node_00002}**. Process all channels jointly **Cite {solution_lesson_node_00005}**.
    *   **Output:** A sequence of temporal features $E_{seq}$ and a global feature vector $E_{vec}$ (via Global Average Pooling).
    *   **Auxiliary Head:** $E_{vec}$ is passed to a dedicated Dense classification layer to produce predictions $P_{eeg}$.

*   **Stream B: Coordinate-Aware Spectrogram Encoder (Context Stream)**
    *   **Backbone:** Use **EfficientNet-B0** (lightweight to fit budget).
    *   **Input:** 10-minute Spectrogram constructed as a **5-channel tensor** (4 regions + 1 Coordinate Map) **Cite {solution_lesson_node_00011}**.
    *   **Output:** A feature map flattened into a sequence of tokens $S_{tok}$. **Crucially, do not pool the frequency dimension** to preserve spectral semantics **Cite {solution_lesson_node_00009}**. A global vector $S_{vec}$ is also computed.
    *   **Auxiliary Head:** $S_{vec}$ is passed to a dedicated Dense classification layer to produce predictions $P_{spec}$.

*   **Fusion: Asymmetric Cross-Attention with Skip Connections**
    *   **Mechanism:** Implement **Unidirectional Cross-Attention** where the EEG sequence $E_{seq}$ acts as **Queries**, and the Spectrogram tokens $S_{tok}$ act as **Keys/Values**. This allows the randomly initialized EEG stream to extract stable features from the pretrained Spectrogram backbone without destabilizing it **Cite {solution_lesson_node_00012}**.
    *   **Lightweight Design:** Use a single attention layer rather than a deep Transformer stack to ensure convergence within the compute budget **Cite {solution_lesson_node_00013}**.
    *   **Integration:** The attention output is pooled and concatenated with the original global vectors: $F_{final} = \text{Concat}( \text{Pool}(\text{Attn}), E_{vec}, S_{vec} )$.
    *   **Main Head:** $F_{final}$ is passed to the final Dense layer to produce $P_{joint}$.

### 2. Data
*   **Raw EEG:** Extract the central 50-second window. Downsample to **100 Hz** **Cite {solution_lesson_node_00002}**. Apply channel-wise instance normalization.
*   **Spectrograms:** Load the full 10-minute spectrogram. Resize to a standard resolution (e.g., $512 \times 512$).
*   **Coordinate Injection:** Generate the 5th input channel as a linear gradient map encoding the relative temporal distance from the center of the labeled event (normalized $[-1, 1]$) **Cite {solution_lesson_node_00011}**.
*   **Augmentation:** Apply **SpecAugment** to the spectrogram and **Channel Dropout** to the EEG.

### 3. Training
*   **Strategy:** Train on the **Full Dataset** (no subsampling) for a limited number of epochs (e.g., 1-2) to maximize data diversity **Cite {solution_lesson_node_00010}**.
*   **Loss Function:** Use a weighted **Multi-Task KL Divergence Loss**:
    $$L_{total} = \text{KL}(P_{joint}, Y) + \lambda [\text{KL}(P_{eeg}, Y) + \text{KL}(P_{spec}, Y)]$$
    where $\lambda=0.5$. This forces the individual encoders to become strong discriminators on their own.
*   **Regularization:** Implement **Modality Dropout**. During training, randomly zero out the features of Stream A or Stream B (e.g., 20% probability) before the fusion layer. This prevents the joint head from over-relying on the stronger Spectrogram stream and ensures it learns to utilize the EEG stream effectively.
*   **Optimizer:** **AdamW** with **OneCycle Learning Rate** scheduler for super-convergence.

### 4. Evaluation
*   **Inference:** For each test sample, generate the 50s EEG and 5-channel Spectrogram.
*   **Prediction:** Pass inputs through the network. The final prediction is taken solely from the **Joint Head** ($P_{joint}$), which now benefits from the robust, independently verified features of both streams.
*   **Post-Processing:** Ensure probabilities sum to 1.0.
