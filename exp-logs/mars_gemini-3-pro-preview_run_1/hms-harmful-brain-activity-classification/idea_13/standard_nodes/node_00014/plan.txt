The implementation strategy is as follows:

1.  **Environment Setup**: Suppress `tqdm` progress bars via monkey-patching to meet the "no progress bars" requirement. Import necessary standard libraries and the provided modules from the `library` package. Set random seeds for reproducibility.
2.  **Data Loading**: Manually instantiate `MultiModalDataset` and `DataLoader`.
    *   For **Training**, load the full `train.csv` metadata but run for only 1 epoch to ensure the execution completes well within the 2-hour limit while maximizing learning.
    *   For **Validation**, load the complete `val.csv` to ensure the metric is computed on the entire hold-out set as required.
3.  **Model Training**: Initialize the `AuxiliaryFusionNet`, `AdamW` optimizer, and `OneCycleLR` scheduler. Execute a custom training loop for 1 epoch using `train_one_epoch` from the library.
4.  **Validation & Metric**: Run inference on the validation set using the `validate` function. Print the final KL Divergence metric with full precision.
5.  **Failure Analysis**:
    *   Compute the KL Divergence for each individual sample in the validation set.
    *   Merge these error values with the validation metadata.
    *   Calculate and print the Pearson correlation between the error magnitude and numerical metadata features (`eeg_label_offset_seconds`, `spectrogram_label_offset_seconds`) to identify error sources.
6.  **Submission Generation**:
    *   Check if the validation metric is strictly lower than the threshold `0.6822116374969482`.
    *   If successful, load the test data, generate predictions using the `inference` function, and save the formatted `submission.csv` to the specified directory.
