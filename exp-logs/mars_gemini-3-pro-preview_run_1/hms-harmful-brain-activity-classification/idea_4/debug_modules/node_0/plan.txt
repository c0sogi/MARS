The following script demonstrates the end-to-end usage of the provided library for the EEG classification task. It begins by configuring the environment for a rapid demonstration run (patching the `Config` class to use a small subset of data and fewer epochs). It then verifies the data loading pipeline by inspecting batch shapes and types. Next, it instantiates the `DualStreamNetwork` model, performs a forward pass, and calculates the KL Divergence loss to ensure architectural correctness. Finally, it executes the training loop for a single epoch and runs inference on the test set, validating the generation of the submission file and the integrity of the predictions.
