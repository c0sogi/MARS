The implementation strategy follows the "Fast Baseline" requirement by configuring the training process for speed (limited epochs, larger batch size for the A100 GPU, and a subset of training data) while strictly adhering to the provided library architecture.

1.  **Setup & Configuration**: Initialize the environment with a fixed seed and override default `Config` parameters. Specifically, set `EPOCHS` to 3 and `BATCH_SIZE` to 64 to utilize the A100 GPU efficiently. Limit the training set to 20,000 samples to ensure execution completes well within the 2-hour limit.
2.  **Data Loading**: Use `get_dataloaders` with `load_cached_data=True` to leverage pre-processed data.
3.  **Training**: Instantiate the `SymmetryAwareNet` and `Trainer`. Execute the training loop, saving the best model based on validation KL divergence.
4.  **Validation & Metric Calculation**:
    *   Load the best saved model checkpoint.
    *   Run inference on the full validation set using `trainer.predict`.
    *   Extract ground truth labels directly from the validation metadata (guaranteed alignment due to `shuffle=False`).
    *   Compute and print the `Final Validation Metric` with full precision.
5.  **Failure Analysis**:
    *   Calculate the KL divergence for each validation sample.
    *   Compute Pearson correlations between the error (KL) and metadata features (`eeg_label_offset_seconds`, `spectrogram_label_offset_seconds`).
    *   Print the correlations to identify error sources.
6.  **Submission**:
    *   Compare the validation metric against the threshold (`0.7327804565429688`).
    *   If the metric is lower (better), run inference on the test set, format the predictions according to the sample submission, and save to `submission.csv`.
