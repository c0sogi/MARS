### Implementation Strategy

1.  **Configuration & Setup**: Initialize the environment using `library.config.Config`. Set random seeds for reproducibility. Define the device (GPU).
2.  **Data Preparation**: Load the pre-generated metadata for training (`train.csv`), validation (`val.csv`), and testing (`test.csv`).
3.  **Cyclic-Subset Training Loop**:
    *   Implement the cyclic training strategy defined in the idea: split unique patients into $N$ disjoint folds.
    *   For each epoch, select one fold of patients to form the training subset. This ensures the model sees the full diversity of data over time while keeping individual epochs short and stable.
    *   Initialize the `CyclicFusionNet` model, `AdamW` optimizer, and `OneCycleLR` scheduler.
    *   Train for `NUM_FOLDS * NUM_CYCLES` epochs.
    *   After each epoch, validate on the hold-out validation set and save the checkpoint if the score improves.
4.  **Final Validation & Metric**:
    *   Load the best saved model checkpoint.
    *   Perform inference on the full validation set.
    *   Compute the global KL Divergence metric.
    *   Print the metric in the strictly required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Compute the KL divergence error for each individual validation sample.
    *   Calculate Pearson correlations between this error and metadata features (e.g., signal offsets) to identify weak points.
    *   Print the top correlations.
6.  **Conditional Submission**:
    *   Check if the validation metric is below the threshold `0.6822116374969482`.
    *   If successful, generate predictions for the test set using the best model.
    *   Format and save the predictions to `submission.csv`.
