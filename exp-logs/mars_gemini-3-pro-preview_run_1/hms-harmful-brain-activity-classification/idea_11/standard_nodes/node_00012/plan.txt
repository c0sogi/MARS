    *   Calculate the **Kullback-Leibler (KL) Divergence** score.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
    *   Compute the KL divergence per sample to quantify error magnitude.
    *   Calculate and print the Pearson correlation between this error magnitude and metadata features (`eeg_label_offset_seconds`, `spectrogram_label_offset_seconds`) to identify systematic failure modes.

5.  **Submission Generation**:
    *   Check if the final validation metric is strictly lower than `0.6822116374969482`.
    *   If the condition is met, load the test metadata, run inference on the test set, format the probabilities (ensuring they sum to 1.0), and save the result to `./submission/submission.csv`.
