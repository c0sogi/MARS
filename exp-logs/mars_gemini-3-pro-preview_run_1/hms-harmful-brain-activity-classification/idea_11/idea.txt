Based on the progression of empirical findings—specifically the high performance of the Coordinate-Injected approach (Lesson 00011) and the established superiority of dual-stream architectures (Lesson 00003)—I propose the **Bidirectional Coordinate-Guided Fusion Network**.

This strategy structurally evolves the previous best approach by correcting the "Attention Asymmetry." Previous iterations treated the EEG as the primary signal and the Spectrogram merely as context (EEG querying Spectrogram). However, Lesson 00011 revealed that the Spectrogram, when augmented with coordinate information, is an exceptionally strong predictor. This new architecture treats both modalities as "first-class citizens," employing a bidirectional attention mechanism that allows the Coordinate-Aware Spectrogram to actively query the high-resolution EEG phase information, and vice-versa.

### 1. Model
The architecture consists of two parallel encoders connected by a symmetric fusion bridge:

*   **Stream A: Raw EEG Encoder (Waveform Stream)**
    *   **Backbone:** Retain the **Multi-Scale 1D Convolutional (Inception)** architecture.
    *   **Function:** It processes the 50-second raw EEG window using parallel convolutional branches with varying kernel sizes.
    *   **Rationale:** This component is preserved to explicitly extract phase and frequency-specific features directly from the time-series, which has been proven superior to spectrograms for short-window analysis **Cite {solution_lesson_node_00002}**.
    *   **Input:** Process all 20 channels (19 EEG + 1 EKG) jointly to capture full spatial dependencies, avoiding the performance degradation caused by manual channel splitting **Cite {solution_lesson_node_00005}**.

*   **Stream B: Coordinate-Aware Spectrogram Encoder (Context Stream)**
    *   **Backbone:** Utilize an **EfficientNet-B1** (a feasible upgrade from B0) to process the 10-minute spectrogram.
    *   **Input Construction:** Construct a **5-channel input tensor**. The first 4 channels correspond to the standard recording regions (LL, RL, LP, RP). The **5th channel is a Coordinate Map**—a linear gradient encoding the relative temporal distance from the center of the labeled event.
    *   **Rationale:** This injection of coordinate metadata breaks the CNN's translation invariance, allowing it to distinguish the "Event of Interest" from the "Background Context" effectively **Cite {solution_lesson_node_00011}**.
    *   **Tokenization:** The output feature map is flattened into a sequence of tokens. Crucially, the frequency dimension is **not pooled**, preserving the spectral semantic identity **Cite {solution_lesson_node_00009}**.

*   **Fusion: Bidirectional Cross-Attention Bridge**
    *   **Mechanism:** Instead of a single attention layer, implement two parallel Cross-Attention heads:
        1.  **Waveform-Guided Context ($Q=EEG, K=Spec, V=Spec$):** The EEG features query the Spectrogram to contextualize the local waveform within the 10-minute history.
        2.  **Context-Guided Waveform ($Q=Spec, K=EEG, V=EEG$):** The Coordinate-Aware Spectrogram features query the EEG to verify spectral patterns against high-resolution phase details.
    *   **Benefit:** This ensures that the strong predictive power of the Coordinate-Injected Spectrogram **Cite {solution_lesson_node_00011}** is not bottlenecked by the EEG representation, while still leveraging the fine-grained temporal resolution of the 1D CNN.
    *   **Classification:** The outputs of both attention heads are Global Average Pooled, concatenated, and passed to a final Dense layer with Softmax activation.

### 2. Data
*   **Raw EEG:** Extract the central 50-second window. Downsample to **100 Hz** to maintain the Nyquist frequency while reducing sequence length **Cite {solution_lesson_node_00002}**. Apply channel-wise instance normalization.
*   **Spectrograms:** Load the full 10-minute spectrogram. Resize to a standard resolution (e.g., $512 \times 512$).
*   **Coordinate Map:** Generate the 5th channel by creating a matrix where each column's value corresponds to its normalized temporal distance from the `spectrogram_label_offset_seconds` **Cite {solution_lesson_node_00011}**.
*   **Augmentation:** Apply **SpecAugment** (masking) to the spectrogram channels (excluding the coordinate channel) and **Channel Dropout** to the EEG. Avoid adding redundant cropped inputs **Cite {solution_lesson_node_00004}**.

### 3. Training
*   **Loss Function:** Use **Kullback-Leibler (KL) Divergence** to align with the soft probability targets provided by the expert annotators **Cite {solution_lesson_node_00002}**.
*   **Optimizer:** Use **AdamW** combined with a **OneCycle Learning Rate** scheduler to facilitate super-convergence **Cite {solution_lesson_node_00003}**.
*   **Strategy:** Train on the **Full Dataset** for a limited number of epochs (e.g., 1-2). Do not subsample the data, as data diversity is critical for generalization, especially for this higher-capacity bidirectional model **Cite {solution_lesson_node_00010}**.

### 4. Evaluation
*   **Inference:** For each test sample, generate the 50-second EEG and the 5-channel Spectrogram (using a centered offset if metadata is missing).
*   **Prediction:** Pass the inputs through the bidirectional model.
*   **Post-Processing:** Apply Softmax to the output logits to obtain the 6 class probabilities, ensuring they sum to 1.0.
