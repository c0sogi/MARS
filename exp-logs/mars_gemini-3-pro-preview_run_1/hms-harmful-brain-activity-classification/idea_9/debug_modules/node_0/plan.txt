The implementation strategy involves creating a self-contained Python script that overrides the default configuration to run a fast, minimal version of the training and inference pipeline.

1.  **Configuration Override**: We will modify the `Config` class attributes at runtime to point to a temporary working directory (`./working/demo_execution`), reduce the batch size to 4, set epochs to 1, and disable multiprocessing workers to ensure stability and speed for the demo.
2.  **Dataset Initialization**: We will instantiate `EEGDataset` for training, validation, and testing with a strict `sample_size` limit (e.g., 20 samples) to minimize data loading time. We will verify the shapes of the yielded tensors (EEG, Spectrogram, and Targets) using assertions.
3.  **Model Verification**: We will instantiate the `TimeRelativeTransformer`, move it to the configured device (GPU/CPU), and perform a dummy forward pass to verify that the output shape is `(Batch, 6)` and that the probabilities sum to 1.
4.  **Training Loop**: We will set up the optimizer and scheduler, then execute the `train_loop` function for a single epoch. We will assert that a model checkpoint (`best_model.pth`) is successfully saved.
5.  **Inference**: We will load the saved checkpoint and run `generate_submission` on the subsampled test set. We will verify the integrity of the output CSV (columns, row count, probability sums).
