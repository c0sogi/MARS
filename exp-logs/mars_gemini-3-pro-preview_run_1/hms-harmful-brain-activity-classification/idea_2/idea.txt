### **Baseline Approach: Multi-Scale 1D Convolutional Network**

This approach focuses on processing the **raw EEG signals** directly in the time domain, bypassing the need for spectrogram generation. It leverages a Deep 1D Convolutional Neural Network (CNN) inspired by the Inception architecture (Model 3) to automatically learn frequency-specific features corresponding to the target brain activities (e.g., rhythmic delta activity) through parallel convolutional filters.

#### **1. Model**
The architecture is designed to capture patterns across different temporal scales (frequencies) simultaneously:
*   **Input:** The model accepts raw EEG time-series data with shape $(Batch, Channels, Time)$.
*   **Multi-Scale Blocks:** The core of the network consists of a stack of "Inception-style" 1D convolutional blocks. Within each block, the input is processed in parallel by multiple 1D convolutional layers with varying kernel sizes (e.g., small kernels for high-frequency Gamma activity, large kernels for low-frequency Delta activity).
*   **Feature Aggregation:** The outputs of these parallel branches are concatenated along the channel dimension. Residual connections and Max Pooling layers are interspersed between blocks to facilitate gradient flow and reduce the temporal dimension.
*   **Classification Head:** A Global Average Pooling layer collapses the remaining temporal sequence into a single feature vector per sample. This is fed into a final Fully Connected layer with a **Softmax** activation to predict the 6 class probabilities.

#### **2. Data**
Preprocessing is minimal to maintain speed, focusing on the `train_eegs` directory:
*   **Extraction:** Use the `eeg_label_offset_seconds` from the metadata to extract the specific **50-second window** of interest from the raw EEG parquet files.
*   **Downsampling:** Resample the signals from 200 Hz to **100 Hz**. This reduces the input sequence length by half (from 10,000 to 5,000 time steps), significantly speeding up training while preserving the Nyquist frequency (50 Hz) sufficient to capture all relevant brain activity types.
*   **Cleaning & Normalization:** Replace `NaN` values (common in disconnected electrodes) with 0. Apply channel-wise normalization (subtract mean, divide by standard deviation) to standardize the amplitude of the electrical potentials across different patients.

#### **3. Training**
The training process is optimized for the specific metric and data characteristics:
*   **Loss Function:** **Kullback-Leibler (KL) Divergence**. This aligns perfectly with the competition metric and the soft probability targets provided in the metadata.
*   **Optimizer:** **AdamW** is used for its efficiency in handling sparse gradients and weight decay properties.
*   **Scheduler:** Implement a **OneCycle Learning Rate** policy. This schedule rapidly increases the learning rate to a maximum value and then decays it, allowing for super-convergence and reducing the total number of epochs required.
*   **Regularization:** Apply **Dropout** before the final classification layer to prevent overfitting to the specific patient IDs in the training set.

#### **4. Evaluation**
*   **Preprocessing:** Load the `test_eegs` files. Since test files are exactly 50 seconds long, no window extraction is needed. Apply the same downsampling (to 100 Hz) and normalization statistics derived from the training step.
*   **Inference:** Pass the processed tensors through the trained network to generate logits.
*   **Submission:** Apply Softmax to the output logits to obtain probabilities. Ensure the column order matches the submission format (`seizure_vote`, `lpd_vote`, etc.) and that rows sum to 1.0 before saving.
