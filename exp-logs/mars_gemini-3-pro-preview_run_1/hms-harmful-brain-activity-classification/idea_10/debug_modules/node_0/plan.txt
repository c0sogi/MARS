This script demonstrates the end-to-end usage of the provided library components for the EEG seizure detection task. It performs the following steps:

1.  **Configuration**: Defines a `DemoConfig` class inheriting from the base `Config` to override settings for a rapid demonstration (reduced epochs, small dataset subset, disabled caching).
2.  **Data Loading**: Uses `get_dataloaders` to initialize PyTorch DataLoaders for training, validation, and testing. It verifies the integrity of a single batch (shapes of EEG waveforms, spectrograms, and targets).
3.  **Model Initialization**: Instantiates the `DualStreamModel` (EEG + Spectrogram fusion) and performs a forward pass with the sample batch to verify output shapes and numerical stability.
4.  **Training Loop**: Sets up the optimizer (AdamW) and scheduler (OneCycleLR), then executes the full training pipeline using the `fit` engine. This demonstrates the training and validation logic.
5.  **Inference**: Loads the best saved model from the training phase and generates predictions on the test set, creating a submission DataFrame.
