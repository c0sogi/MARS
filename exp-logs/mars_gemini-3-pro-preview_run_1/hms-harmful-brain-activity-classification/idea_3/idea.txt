# Proposed Strategy: Context-Aware Dual-Stream Hybrid Network

This strategy proposes a structural evolution by fusing the high-resolution temporal modeling of raw EEG (from the previous successful experiment) with the long-range contextual information provided by spectrograms. This addresses the limitation of the previous approach, which only viewed a narrow 50-second window, by integrating the broader 10-minute context available in the spectrogram data.

### 1. Model
The architecture is a **Dual-Stream Network** that processes raw EEG and spectrograms in parallel branches before fusing them for the final classification.

*   **Stream A (Local Temporal Stream):** This branch processes the 50-second raw EEG signals. It retains the **Multi-Scale 1D Convolutional (Inception)** architecture. This component is explicitly preserved to leverage its proven ability to learn frequency-specific filters (e.g., for rhythmic delta activity) and capture phase information directly from time-series data Cite {solution_lesson_node_00002}.
*   **Stream B (Global Context Stream):** This branch processes the 10-minute pre-computed spectrograms. It utilizes a lightweight 2D CNN backbone (e.g., EfficientNet-B0) to extract visual time-frequency patterns (such as the "flames" of seizures or periodic discharges) over a much longer time horizon than the EEG stream allows.
*   **Fusion Head:** The feature vectors from Global Average Pooling layers of both streams are concatenated. This combined vector is passed through a Dropout layer and a final Dense layer with Softmax activation to predict the 6 class probabilities.

### 2. Data
The data pipeline is designed to prepare distinct inputs for the two streams:

*   **Raw EEG Preprocessing:**
    *   Extract the central 50-second window centered on the annotated event.
    *   Downsample the signal from 200 Hz to **100 Hz** to reduce computational load while maintaining the Nyquist frequency necessary for brain activity classification.
    *   Apply channel-wise instance normalization (subtract mean, divide by std).
*   **Spectrogram Preprocessing:**
    *   Load the full 10-minute spectrograms (or a large central crop, e.g., 5-10 minutes) to provide the "Global Context" missing from the 50s EEG.
    *   Apply a Log transformation to compress the dynamic range.
    *   Resize the image to a standard resolution (e.g., $512 \times 512$) to fit the 2D CNN input requirements.
*   **Augmentation:** Apply independent augmentations: **TimeMasking/ChannelShuffle** for EEG and **SpecAugment** (time/frequency masking) for spectrograms.

### 3. Training
*   **Loss Function:** **Kullback-Leibler (KL) Divergence** is used to align with the competition metric and effectively learn from the soft probability targets.
*   **Optimizer & Schedule:** Use **AdamW** combined with a **OneCycle Learning Rate** scheduler. This schedule allows for rapid convergence by super-converging the weights, a behavior observed to be effective in the previous 1D CNN experiments.
*   **Strategy:** Train the model end-to-end. To manage the "moderately heavier" computational load, use mixed-precision training (FP16).

### 4. Evaluation
*   **Inference:** For each test sample, load the 50-second EEG file and the corresponding 10-minute spectrogram file. Process them through their respective preprocessing pipelines.
*   **Prediction:** Pass the inputs through the dual-stream model to obtain the probability distribution.
*   **Post-Processing:** Ensure the output probabilities sum to 1.0. No complex ensemble is required; the single hybrid model is expected to generalize better than the individual previous ideas.
