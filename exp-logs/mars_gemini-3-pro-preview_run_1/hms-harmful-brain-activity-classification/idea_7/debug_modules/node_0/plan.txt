The following script demonstrates the end-to-end usage of the provided library components for classifying harmful brain activity.

### Implementation Strategy

1.  **Configuration Setup**: We first modify the global `Config` class to run in `DEBUG` mode. We drastically reduce the dataset size (e.g., 20 training samples), batch size, and number of epochs to ensure the script executes in under a minute while still exercising all code paths.
2.  **Data Loading & Verification**: We utilize `get_dataloaders` to prepare the data. We explicitly fetch a single batch to verify the tensor shapes of the Spectrograms (image-like), EEG signals (time-series), guidance scalars, and target probabilities against the expected dimensions.
3.  **Model Initialization & Forward Pass**: We instantiate the `OffsetGuidedDualStreamModel`. We perform a forward pass with the verified batch to ensure the model architecture processes inputs correctly and outputs logits of the correct shape `(Batch_Size, Num_Classes)`.
4.  **Training & Validation Step**: We manually initialize the optimizer and scheduler, then run `train_one_epoch` and `validate` functions. We assert that these functions return valid scalar loss values, confirming the training loop logic.
5.  **Inference Pipeline**: We execute the `run_inference` function, which handles the test set prediction and submission file generation. We verify that the output CSV is created, has the correct dimensions, and contains probabilities summing to approximately 1.0.
