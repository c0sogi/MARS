The following implementation demonstrates the usage of the provided library files (`config.py`, `utils.py`, `data.py`, `models.py`, `train.py`, `infer.py`) to perform the EEG classification task.

The script performs the following steps:
1.  **Configuration Override**: Adjusts the `Config` class settings to use a temporary working directory and reduces parameters (epochs, batch size) for a fast execution.
2.  **Data Loading**: Uses `get_loaders` to load a debug subset of the data and verifies the structure and dimensions of the multi-view inputs (Micro, Meso, Macro).
3.  **Model Verification**: Instantiates the `TriViewNet` model, performs a forward pass with a dummy batch, and validates the output shape and logic.
4.  **Metric Calculation**: Manually tests the `kl_divergence_score` function.
5.  **Training Loop**: Executes the `train` function for one epoch to demonstrate the training pipeline, including loss calculation, backpropagation, and checkpoint saving.
6.  **Inference**: Runs the `inference` function using the trained checkpoint to generate predictions on the test set and verifies the submission file format.
