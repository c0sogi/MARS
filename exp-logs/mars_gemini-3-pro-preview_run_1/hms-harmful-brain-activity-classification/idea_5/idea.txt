Based on the lessons learned from the Multi-Scale 1D CNN and the Dual-Stream Attention networks, I propose a **Tri-View Hierarchical Fusion Network**.

This strategy structurally evolves the previous "Dual-Stream" approach by addressing a critical resolution mismatch: the raw EEG stream views a 50-second window, while the spectrogram stream views a 10-minute window. While the previous solution bridged this with attention, the massive downsampling required for the 10-minute spectrogram likely obscures high-frequency visual patterns (like rapid spikes) specific to the seizure event. This new architecture introduces a third "Meso-Scale" stream to explicitly model the high-resolution time-frequency features of the event itself, creating a hierarchical bridge between the waveform and the global context.

### 1. Model
The architecture consists of three specialized encoders organized into a hierarchical fusion pipeline:

*   **Stream A: Micro-View Encoder (Raw EEG):**
    *   This stream processes the **50-second raw EEG** signal.
    *   It utilizes the **Multi-Scale 1D Convolutional (Inception)** architecture. This component is retained to extract fine-grained phase information and learn frequency-specific filters directly from the waveform, which has been proven effective for this task Cite {solution_lesson_node_00002}.
*   **Stream B: Meso-View Encoder (Local Spectrogram):**
    *   **Innovation:** This new stream processes a **50-second crop** of the spectrogram, temporally aligned with the raw EEG.
    *   It uses a standard 2D CNN (e.g., EfficientNet-B0). Unlike the global stream, this input preserves high-resolution time-frequency details of the specific event (e.g., the visual "flames" of a seizure) that are often lost when compressing 10 minutes of data. This provides the explicit spectral inductive bias recommended in the lessons Cite {solution_lesson_node_00003} but at a temporal resolution matching the EEG.
*   **Stream C: Macro-View Encoder (Global Spectrogram):**
    *   This stream processes the full **10-minute spectrogram** using a 2D CNN (e.g., EfficientNet-B0, potentially sharing weights with Stream B). It captures the long-range evolution of brain states (e.g., pre-seizure slowing) necessary for context.
*   **Hierarchical Attentive Fusion:**
    *   **Stage 1 (Local Integration):** The feature vectors from Stream A (EEG) and Stream B (Local Spec) are concatenated. Since they represent the exact same time window, this creates a robust "Event Representation" combining waveform dynamics with high-fidelity spectral patterns.
    *   **Stage 2 (Contextual Attention):** This Event Representation serves as the **Query** in a **Cross-Attention** block. The features from Stream C (Global Spec) serve as the **Keys and Values**. This allows the model to dynamically "look up" relevant historical context to resolve ambiguities in the local event, leveraging the dual-stream fusion principles Cite {solution_lesson_node_00003}.

### 2. Data
The data pipeline is updated to generate three distinct inputs for each sample:

*   **Raw EEG (Micro):** Extract the central 50-second window. Downsample to **100 Hz** to reduce dimensionality while maintaining the Nyquist frequency Cite {solution_lesson_node_00002}. Apply channel-wise instance normalization.
*   **Local Spectrogram (Meso):** Using the `spectrogram_label_offset_seconds` metadata, calculate the start and end indices corresponding to the 50-second EEG window within the full spectrogram. Crop this region and resize it to a square resolution (e.g., $224 \times 224$).
*   **Global Spectrogram (Macro):** Load the full 10-minute spectrogram. Apply Log transformation (dB scale) and resize to a standard resolution (e.g., $512 \times 512$).
*   **Augmentation:** Apply **SpecAugment** (masking) to both spectrogram inputs and **Channel Dropout** to the raw EEG.

### 3. Training
*   **Loss Function:** Use **Kullback-Leibler (KL) Divergence** to optimize against the soft probability targets, as this metric has consistently outperformed Cross-Entropy for this specific label distribution Cite {solution_lesson_node_00002}.
*   **Optimizer:** Use **AdamW** combined with a **OneCycle Learning Rate** scheduler. This schedule facilitates super-convergence, which is critical for training this heavier multi-stream architecture efficiently within the time limits Cite {solution_lesson_node_00002}.
*   **Strategy:** Train end-to-end using mixed-precision (FP16) to manage the memory footprint of the three encoders.

### 4. Evaluation
*   **Preprocessing:** For each test `eeg_id`, generate the three required views: the 50s raw EEG, the 50s spectrogram crop, and the 10m global spectrogram.
*   **Inference:** Pass the triplet of inputs through the network.
*   **Post-Processing:** The model outputs logits which are passed through a Softmax layer. Ensure the resulting probabilities sum to 1.0 before submission.
