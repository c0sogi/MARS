### Implementation Strategy

1.  **Environment Setup**: Initialize the environment using `library.config.set_seed` and `library.config.setup_directories` to ensure reproducibility and file system readiness.
2.  **Utility Verification**: Demonstrate and validate `library.utils.compute_kl_divergence` and `library.utils.normalize_probabilities` using synthetic numpy arrays to ensure metric calculation and probability normalization logic is correct.
3.  **Data Loading & Processing**:
    *   Load the training metadata manually and sample a small subset (e.g., 64 samples) to create a "Mini" dataset. This ensures the demonstration runs quickly without processing the entire 80k+ dataset.
    *   Directly instantiate `library.data_loader.SpectrogramDataset` with this subset.
    *   Wrap it in a `DataLoader` and iterate once to verify input tensor shapes `(Batch, Channels, Time, Freq)` and target shapes.
4.  **Model Initialization & Forward Pass**:
    *   Instantiate `library.model.SpectrogramCRNN`.
    *   Perform a forward pass with the batch fetched from the mini-loader.
    *   Validate that the output shape matches `(Batch, Num_Classes)` and that values are valid probabilities (sum to 1).
5.  **Training Loop Demonstration**:
    *   Initialize `library.trainer.Trainer` using the mini-loader for both training and validation.
    *   Execute `trainer.fit(epochs=1)` to demonstrate the training pipeline, loss calculation, and checkpoint saving mechanics without consuming excessive time.
    *   Verify that the model checkpoint (`best_model.pth`) is successfully saved to the cache directory.
6.  **Inference & Submission**:
    *   Execute `library.inference.predict_and_submit`. This function loads the checkpoint created in the previous step, performs inference on the test set, and generates `submission.csv`.
    *   Validate the generated submission file for correct dimensions, column names, and row sums.
