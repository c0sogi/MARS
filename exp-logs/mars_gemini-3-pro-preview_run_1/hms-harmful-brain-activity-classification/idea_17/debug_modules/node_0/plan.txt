The following script demonstrates the usage of the provided library files to train and evaluate a harmful brain activity classification model.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class at runtime to set up a lightweight demonstration environment. This includes disabling pretrained weight downloads (to ensure offline execution), reducing the number of epochs to 2, setting a small batch size, and defining a temporary working directory.
2.  **Data Loading**: We utilize `get_dataloaders` with `debug=True` to load a small subset of the data. We then iterate through a single batch to verify the data shapes and integrity of the EEG and Spectrogram tensors.
3.  **Model Initialization**: We instantiate the `HarmfulBrainActivityModel`. We perform a forward pass with the sample batch to verify the architecture's connectivity and output dimensions.
4.  **Training Loop**: We set up the `AdamW` optimizer and `OneCycleLR` scheduler, then invoke the `fit` function from `library.engine` to execute the training process.
5.  **Verification**: After training, we verify that the model checkpoint was saved correctly. We then load this checkpoint and perform inference on a validation batch to demonstrate how to generate predictions and calculate the KL divergence metric manually.
