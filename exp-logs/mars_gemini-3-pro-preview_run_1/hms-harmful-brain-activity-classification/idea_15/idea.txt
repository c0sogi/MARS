Based on the comprehensive analysis of the provided lessons, particularly the failure of "Full Dataset" training strategies (Lesson 00014) and the failure of "Sequential Partitioning" (Lesson 00015), combined with the architectural success of "Coordinate Injection" (Lesson 00011), I propose the **Deeply-Supervised Coordinate-Fusion Network**.

This strategy structurally evolves the previous "Current Best" (Idea 10) by integrating the **Auxiliary Supervision** concept from Idea 13. However, it explicitly corrects the fatal training flaw of Idea 13 (which used a single epoch on the full dataset) by adopting the robust **Global Random Subsampling** strategy (from Idea 10/Lesson 00014). This ensures that the benefits of multi-task learning are realized through sufficient iterative convergence.

### 1. Model
The architecture is a **Dual-Stream Network** with three distinct classification heads (Tri-Head), designed to enforce strong feature learning in both modalities before fusion.

*   **Stream A: Raw EEG Encoder (Waveform Stream)**
    *   **Backbone:** Retain the **Multi-Scale 1D Convolutional (Inception)** architecture.
    *   **Function:** Processes the 50-second raw EEG window (20 channels) using parallel convolutional branches with varying kernel sizes.
    *   **Rationale:** This component is preserved to explicitly extract phase and frequency-specific features directly from the time-series, which has been proven superior to spectrograms for short-window analysis **Cite {solution_lesson_node_00002}**.
    *   **Constraint:** Process all 20 channels (19 EEG + 1 EKG) jointly to capture full spatial dependencies **Cite {solution_lesson_node_00005}**.
    *   **Auxiliary Head:** The global pooling output of this stream is passed to a dedicated Dense layer to produce prediction $P_{eeg}$.

*   **Stream B: Coordinate-Aware Spectrogram Encoder (Context Stream)**
    *   **Backbone:** Use a lightweight **EfficientNet-B0**.
    *   **Input Construction:** Construct a **5-channel input tensor**. Channels 1-4 are the standard recording regions. Channel 5 is a **Coordinate Map**—a linear gradient encoding the relative temporal distance from the center of the labeled event.
    *   **Rationale:** This injection breaks translation invariance, allowing the CNN to effectively locate the event within the 10-minute context **Cite {solution_lesson_node_00011}**.
    *   **Tokenization:** The output feature map is flattened into tokens. **Crucially, do not pool the frequency dimension**, preserving spectral semantics **Cite {solution_lesson_node_00009}**.
    *   **Auxiliary Head:** The global pooling output of this stream is passed to a dedicated Dense layer to produce prediction $P_{spec}$.

*   **Fusion: Asymmetric Cross-Attention**
    *   **Mechanism:** Implement a **Single-Layer Cross-Attention** block **Cite {solution_lesson_node_00013}**.
    *   **Directionality:** Configure strictly as **EEG queries Spectrogram** ($Q=EEG, K=Spec, V=Spec$). This allows the randomly initialized EEG stream to extract stable features from the pretrained Spectrogram backbone without destabilizing it **Cite {solution_lesson_node_00012}**.
    *   **Joint Head:** The attention output is concatenated with the global vectors from both streams and passed to a final Dense layer to produce $P_{joint}$.

### 2. Data
*   **Raw EEG:** Extract the central 50-second window. Downsample to **100 Hz** to maintain the Nyquist frequency while reducing sequence length **Cite {solution_lesson_node_00002}**. Apply channel-wise instance normalization.
*   **Spectrograms:** Load the full 10-minute spectrogram. Resize to a standard resolution (e.g., $512 \times 512$).
*   **Coordinate Map:** Generate the 5th channel by creating a matrix where each column's value corresponds to its normalized temporal distance (e.g., $[-1, 1]$) from the `spectrogram_label_offset_seconds` **Cite {solution_lesson_node_00011}**.
*   **Augmentation:** Apply **SpecAugment** (masking) to the spectrogram channels (excluding the coordinate channel) and **Channel Dropout** to the EEG. Avoid adding redundant cropped inputs **Cite {solution_lesson_node_00004}**.

### 3. Training
*   **Strategy: Global Random Subsampling (Correction from Idea 13/14)**
    *   **Protocol:** Instead of training on the full dataset for 1 epoch (which causes underfitting **Cite {solution_lesson_node_00014}**) or sequential partitions (which causes divergence **Cite {solution_lesson_node_00015}**), randomly sample a fixed subset of the data (e.g., 25% or ~20,000 samples) at the start of the run.
    *   **Iterations:** Train on this **same subset** for multiple epochs (e.g., 4-5). This allows the optimizer to stabilize Batch Normalization statistics and converge to a sharp local minimum, which is empirically superior to a single pass over more data in this time-constrained regime **Cite {solution_lesson_node_00014}**.
*   **Loss Function:** Use a weighted **Multi-Task KL Divergence Loss**:
    $$L_{total} = \text{KL}(P_{joint}, Y) + 0.5 \cdot \text{KL}(P_{eeg}, Y) + 0.5 \cdot \text{KL}(P_{spec}, Y)$$
    This forces the EEG stream to become a strong discriminator independently, preventing the model from over-relying on the stronger Spectrogram stream.
*   **Optimizer:** **AdamW** with a **OneCycle Learning Rate** scheduler to facilitate super-convergence **Cite {solution_lesson_node_00003}**.

### 4. Evaluation
*   **Inference:** For each test sample, generate the 50-second EEG and the 5-channel Spectrogram.
*   **Alignment:** If `spectrogram_label_offset_seconds` is missing in the test metadata, assume the test EEG is centered within the spectrogram (offset = 0) to generate the coordinate map.
*   **Prediction:** Pass the inputs through the network. The final prediction is taken solely from the **Joint Head** ($P_{joint}$), which benefits from the robust, deeply supervised features.
*   **Post-Processing:** Apply Softmax and ensure probabilities sum to 1.0.
