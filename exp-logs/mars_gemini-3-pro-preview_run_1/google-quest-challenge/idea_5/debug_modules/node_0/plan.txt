This script demonstrates the end-to-end usage of the provided library components for the Google QUEST Q&A Labeling task. It performs the following steps:
1.  **Configuration**: Overrides default `Config` settings to enable debug mode and reduce runtime (smaller batch sizes, fewer epochs) for demonstration purposes.
2.  **Data Loading**: Uses `load_data` to fetch the training and test sets, verifying the data structures.
3.  **Dataset & Collation**: Instantiates `QuestDataset` and `Collate` to process raw text into tokenized, padded tensors. It verifies the shapes of the resulting batches.
4.  **Model Initialization**: Loads the `QuestModel` (DeBERTa-v3-small based), moves it to the available device, and performs a forward pass to verify output dimensions.
5.  **Training & Evaluation**: Runs a minimal training loop (1 epoch on a tiny subset) using `train_fn` and `valid_fn`, ensuring the loss calculation and backpropagation pipeline works.
6.  **Inference**: Generates predictions on the test set using `inference_fn` and verifies the output format.
7.  **Metric Calculation**: Tests the `compute_spearmanr_score` function with synthetic data to ensure metric validity.
