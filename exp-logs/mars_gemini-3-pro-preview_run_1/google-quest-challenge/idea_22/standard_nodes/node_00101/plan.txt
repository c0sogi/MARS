Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize random seeds for reproducibility and define constants such as the working directory, model name, and the validation threshold.
2.  **Model Training**: Instantiate the `Trainer` class from the provided `library.trainer` module. Configure it with the "Phantom Scheduling" strategy (7 total epochs, stopping at 3) and "Head Warmup" (handled internally by the Trainer). Execute the training loop using `trainer.train()`.
3.  **Validation Inference**: Load the best model checkpoint saved during training. Re-initialize the validation dataset using `StackExchangeDataset` and `DataLoader` to run inference on the full validation split.
4.  **Metric Calculation**: Compute the Mean Column-wise Spearman's Correlation on the validation predictions and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Calculate the Mean Absolute Error (MAE) for each validation sample. Load the validation metadata to extract text length features (Question Body and Answer lengths). Compute and print the Spearman correlation between the model's error and these features to identify systematic biases.
6.  **Submission Handling**: Check if the `Final Validation Metric` exceeds the threshold (`0.4118214482019393`). The `Trainer` automatically generates a submission file; if the metric is below the threshold, strictly enforce the requirement by deleting the generated submission file.
