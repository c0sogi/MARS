This script demonstrates the usage of the provided library modules for the StackExchange task. It performs three main verification steps:
1.  **Dataset & DataLoader Verification**: Validates that the `StackExchangeDataset` correctly loads data, tokenizes text, and that `collate_fn` properly batches and pads the tensors.
2.  **Model Architecture Verification**: Instantiates the `PartitionedPoolingDualEncoder`, performs a forward pass with a dummy batch, and asserts that the output dimensions match the expected target shape (Batch Size, 30).
3.  **Training Loop Verification**: Uses the `Trainer` class to run a minimal training cycle (1 epoch on a debug subset), ensuring that the training pipeline executes without errors and generates the required submission files.
