The following script demonstrates the usage of the provided library files for the StackExchange Question-Answer labeling task. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters to optimize for a quick demonstration (reduced batch size, single epoch, disabled accumulation).
2.  **Data Loading**: Uses `get_dataloaders` with `debug=True` to load a small subset of the data for rapid execution. It verifies the integrity of the batch structure produced by the custom `Collate` function.
3.  **Model Initialization**: Instantiates the `HybridDualEncoder` model, ensuring it loads the correct asymmetric backbones and moves to the appropriate device.
4.  **Training Simulation**: Runs the `train_fn` for one epoch on the debug subset to verify the training loop and loss calculation.
5.  **Evaluation Simulation**: Runs the `eval_fn` on the validation subset to verify prediction generation and Spearman's correlation calculation.
6.  **Metric Verification**: Explicitly tests the `compute_spearmanr` utility with synthetic data to ensure metric correctness.
