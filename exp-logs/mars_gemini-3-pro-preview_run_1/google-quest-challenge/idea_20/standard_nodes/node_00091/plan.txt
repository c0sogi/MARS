The `AttributeError` occurs because the `SiameseDualEncoderModel` (defined in `library/model.py`) stores the transformer model in a single attribute `self.backbone`, whereas the training engine (`library/engine.py`) attempts to access non-existent attributes like `embeddings`, `shared_layers`, `q_branch`, and `a_branch`. This mismatch between the model's interface and the engine's expectations causes the crash. To resolve this, I will update both `set_backbone_freezing` and `train_one_epoch` in `library/engine.py` to correctly reference `model.backbone` when defining the list of modules to freeze/unfreeze. This ensures the component integration respects the actual class definition (Cite debug_lesson_7).
