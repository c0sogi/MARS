Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the following optimized strategy.

# Model
I propose a **DistilRoBERTa Dual-Encoder with Consistency-Regularized Optimization (R-Drop)**.

This strategy introduces a **Structural Innovation** in the training paradigm. While previous architectural attempts (e.g., larger backbones, complex heads, auxiliary tasks) failed due to the constraints of the small dataset (~4,400 samples), this approach directly addresses the **Generalization vs. Overfitting** trade-off by enforcing output consistency across stochastic forward passes, effectively doubling the training signal without increasing model parameters.

*   **Backbone Architecture:** Utilize **`distilroberta-base`**.
    *   *Rationale:* This backbone (82M params) is the empirically verified "Right-Sized" model for this dataset (**Cite solution_lesson_node_00023**). It avoids the "Starved Batch" instability of larger models (**Cite solution_lesson_node_00022**) and the capacity limitations of smaller ones (**Cite solution_lesson_node_00045**).
*   **Dual-Branch Structure:** Maintain the Siamese design, processing the "Question" and "Answer" streams independently. This preserves the full 512-token context for both inputs, avoiding the truncation issues of Single-Encoders (**Cite solution_lesson_node_00032**) and the context leakage of Cross-Encoders (**Cite solution_lesson_node_00030**).
*   **Optimized Input Structure:**
    *   **Question Branch:** Use the tokenizer to pair the Title and Body: `[CLS] Title [SEP] Body [SEP]`. This leverages the model's native sentence-pair handling to preserve semantic boundaries, outperforming string concatenation (**Cite solution_lesson_node_00070**).
    *   **Answer Branch:** Use `[CLS] Answer [SEP]`. Avoid prepending the Title here; previous experiments showed that redundant context forces truncation of the unique Answer text, degrading performance (**Cite solution_lesson_node_00063**).
*   **Masked Hybrid Pooling:** Apply **Masked Global Average and Max Pooling** to the final hidden state of both branches (**Cite solution_lesson_node_00003**).
*   **Interaction-Aware Fusion:**
    *   Compute explicit interactions (Element-wise Product and Absolute Difference) *only* on the **Average Pooled** vectors (**Cite solution_lesson_node_00007**).
    *   Concatenate: $[u_{avg}, u_{max}, v_{avg}, v_{max}, u_{avg} \odot v_{avg}, |u_{avg} - v_{avg}|]$.
    *   Apply **Layer Normalization** to the fused vector (**Cite solution_lesson_node_00009**).
*   **Monolithic Minimalist Head:**
    *   Pass the normalized vector through a simple MLP: `Linear` $\to$ `ReLU` $\to$ `Dropout` ($p=0.1$) $\to$ `Linear` (predicting 30 targets).
    *   *Rationale:* This retains the necessary non-linearity (**Cite solution_lesson_node_00027**) while avoiding the optimization instability of complex Gated/LayerNormed heads (**Cite solution_lesson_node_00054**, **Cite solution_lesson_node_00046**).
    *   **Initialization:** Initialize the head's weights using a Normal distribution ($\mu=0, \sigma=0.02$) to match the backbone's scale (**Cite solution_lesson_node_00051**).

# Data
*   **Preprocessing:**
    *   **Stream A:** `tokenizer(question_title, question_body)`
    *   **Stream B:** `tokenizer(answer)`
*   **Tokenization:** Use the `distilroberta-base` tokenizer with dynamic padding to the longest sequence in the batch (**Cite solution_lesson_node_00018**).
*   **Feature Selection:** Rely solely on text. Do not inject metadata, as it induces shortcut learning (**Cite solution_lesson_node_00049**, **Cite solution_lesson_node_00039**).

# Training
*   **Consistency Regularization (R-Drop):**
    *   **Mechanism:** For each mini-batch, perform **two** forward passes with the same data but different random Dropout masks.
    *   **Loss Function:** Minimize $L_{total} = L_{BCE}(y, \hat{y}_1) + L_{BCE}(y, \hat{y}_2) + \alpha \cdot L_{KL}(\hat{y}_1 || \hat{y}_2)$.
    *   *Benefit:* This forces the model to learn a smooth manifold where predictions are robust to dropout noise, acting as a powerful regularizer for small datasets without the convergence latency of Multi-Sample Dropout (**Cite solution_lesson_node_00042**).
*   **Batch Size:** Use **16**. This fits in memory and provides the necessary gradient noise for robust generalization (**Cite solution_lesson_node_00012**).
*   **Differential Learning Rates:** Apply a high learning rate (`1e-3`) to the Head and a low learning rate (`2e-5`) to the Backbone (**Cite solution_lesson_node_00015**).
*   **Parameter Grouping:** Explicitly exclude `bias` and `LayerNorm` parameters from weight decay (**Cite solution_lesson_node_00018**).
*   **Schedule:**
    *   **Epoch 1 (Head Warmup):** Freeze the backbone. Train only the head (**Cite solution_lesson_node_00050**).
    *   **Epochs 2-8 (Fine-tuning):** Unfreeze the backbone. Use a continuous linear decay schedule. Do not reset the optimizer (**Cite solution_lesson_node_00019**).
    *   *Note:* Extend training to 8 epochs to accommodate the regularization effect of R-Drop, ensuring full convergence.

# Evaluation
*   **Inference:** Pass the test set through the model (standard single forward pass).
*   **Prediction:** Apply Sigmoid activation to the 30 output logits.
*   **Validation:** Monitor Mean Column-wise Spearman's Correlation. Accept the model if it exceeds the previous best (`~0.408`) plus a small noise margin (**Cite solution_lesson_node_00010**).
