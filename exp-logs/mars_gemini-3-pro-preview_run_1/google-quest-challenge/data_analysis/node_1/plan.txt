The issue in `runfile.py` is that the logic for identifying target columns relies solely on checking if column names start with "question_" or "answer_". This incorrectly captures non-numeric metadata columns present in the dataset (such as `question_user_name` or `answer_user_name`), which contain string values. When the script attempts to calculate the mean of these string columns, it raises a `TypeError`. The fix is to update the column selection logic to explicitly check that the column data type is numeric before including it in the `target_cols` list.
