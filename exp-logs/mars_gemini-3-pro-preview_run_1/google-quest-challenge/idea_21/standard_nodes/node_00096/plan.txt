Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` object to manage hyperparameters and paths. Set random seeds for reproducibility using `seed_everything`.
2.  **Training Phase**: Execute the training pipeline using the provided `run_training` function. This handles the "Phantom Scheduling", differential learning rates, and saves the best model checkpoint based on validation performance.
3.  **Validation & Metric Calculation**:
    *   Load the best model checkpoint saved during training.
    *   Perform inference on the validation set using a custom `inference` function (optimized with `torch.no_grad()`).
    *   Compute the Mean Column-wise Spearman's Correlation.
    *   Print the result strictly in the format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the Mean Absolute Error (MAE) for each validation sample.
    *   Extract meta-features (text lengths of question title, body, and answer) from the validation dataframe.
    *   Compute and print the Spearman correlation between the MAE and these meta-features to identify if sentence length correlates with model error.
5.  **Submission Generation**:
    *   Check if the validation metric exceeds the threshold (`0.4118214482019393`).
    *   If passed, load the test set and perform inference.
    *   Construct the submission DataFrame with the correct `qa_id` and column headers.
    *   Save the file to `./submission/submission.csv`.
