Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Shared-Bottom RoBERTa Dual-Encoder with Multi-Level Interaction Fusion**.

This strategy synthesizes the high capacity of `roberta-base` (**Cite solution_lesson_node_00077**) with the specialization benefits of Independent Encoders (**Cite solution_lesson_node_00076**), while introducing a **Structural Innovation**—**Multi-Level Interaction Fusion**—to guarantee geometric feature alignment (**Cite solution_lesson_node_00080**, **Cite solution_lesson_node_00085**).

# Model
*   **Backbone Architecture:** Utilize **`roberta-base`**.
    *   *Rationale:* This model (125M params) provides the necessary capacity to model complex hierarchical dependencies in the Question text, outperforming distilled variants (**Cite solution_lesson_node_00077**).
*   **Shared-Bottom Split-Top Structure:**
    *   **Layers 0-9 (Shared):** The first 10 layers are shared between the Question and Answer branches. This anchors the representations in a unified metric space, preventing the "Alignment Drift" that degrades geometric features in fully independent models (**Cite solution_lesson_node_00080**) and reducing the parameter count to mitigate overfitting (**Cite solution_lesson_node_00077**).
    *   **Layers 10-11 (Independent):** The top 2 layers are split into independent branches. This allows the model to learn specialized high-level semantic features for the disjoint target sets (Question Quality vs. Answer Relevance) without gradient interference (**Cite solution_lesson_node_00076**).
*   **Multi-Level Interaction Fusion (Structural Innovation):**
    *   Extract **Masked Average Pooled** vectors from both the **Shared Output (Layer 9)** ($u_{shared}, v_{shared}$) and the **Split Output (Layer 11)** ($u_{split}, v_{split}$).
    *   **Level 1 Interactions (Guaranteed Alignment):** Compute $I_{shared} = [u_{shared} \odot v_{shared}, |u_{shared} - v_{shared}|]$. Since these vectors come from the shared encoder, they are perfectly aligned in the metric space, maximizing the validity of geometric operations (**Cite solution_lesson_node_00080**).
    *   **Level 2 Interactions (Specialized):** Compute $I_{split} = [u_{split} \odot v_{split}, |u_{split} - v_{split}|]$. These capture high-level specialized relationships.
    *   **Intrinsic Features:** Extract **Masked Max Pooled** vectors from the Split Output ($u_{max}, v_{max}$) to capture salient intrinsic signals (**Cite solution_lesson_node_00003**).
    *   **Fusion:** Concatenate all components: $F = [u_{split}, v_{split}, u_{max}, v_{max}, I_{shared}, I_{split}]$.
    *   Apply **Layer Normalization** to $F$ (**Cite solution_lesson_node_00009**).
*   **Residual Interaction Head:**
    *   Utilize the **Residual Projection Block** (**Cite solution_lesson_node_00076**).
    *   Architecture: $Output = \text{Linear}(\text{Concat}(F, \text{Dropout}(\text{ReLU}(\text{Linear}(F)))))$.
    *   This preserves the raw multi-level signals via skip connection while enabling non-linear feature mixing (**Cite solution_lesson_node_00027**).
    *   **Monolithic Output:** Predict all 30 targets simultaneously (**Cite solution_lesson_node_00016**).

# Data
*   **Preprocessing:**
    *   **Question Stream:** Use `tokenizer(question_title, question_body)`. This leverages the tokenizer's native separator insertion (`[CLS] Title [SEP] Body [SEP]`) to preserve semantic structure (**Cite solution_lesson_node_00070**).
    *   **Answer Stream:** Use `tokenizer(answer)`. Do not inject the Title here to avoid redundancy and truncation (**Cite solution_lesson_node_00063**).
    *   **Metadata:** Exclude categorical metadata to prevent shortcut learning (**Cite solution_lesson_node_00039**, **Cite solution_lesson_node_00049**).
*   **Tokenization:** Use the `roberta-base` tokenizer.
*   **Dynamic Padding:** Pad sequences to the longest length in the batch to optimize throughput (**Cite solution_lesson_node_00018**).

# Training
*   **Phantom Scheduling (Strategic Retention):**
    *   **Configuration:** Initialize the Learning Rate Scheduler with a total duration of **7 epochs**.
    *   **Execution:** Explicitly terminate training after **3 epochs**.
    *   *Rationale:* `roberta-base` peaks at Epoch 3 on this dataset (**Cite solution_lesson_node_00077**). "Phantom Scheduling" ensures the decay profile remains optimal for fine-tuning, avoiding the underfitting caused by compressing the schedule (**Cite solution_lesson_node_00078**).
*   **Gradient Accumulation:** Set physical batch size to **8** and accumulate gradients (steps=2) to achieve an **effective batch size of 16** (**Cite solution_lesson_node_00022**).
*   **Differential Learning Rates:** Apply a high learning rate (`1e-3`) to the Head and a low learning rate (`2e-5`) to the Backbone (**Cite solution_lesson_node_00015**).
*   **Head Warmup:** Freeze the backbone (Shared + Split layers) for the first epoch. Train only the head (**Cite solution_lesson_node_00050**).
*   **Continuous Schedule:** Do not reset the optimizer after warmup (**Cite solution_lesson_node_00019**).
*   **Loss Function:** Binary Cross Entropy (BCE) with Logits Loss.

# Evaluation
*   **Inference:** Pass the test set through the model, extracting features from both Layer 9 and Layer 11 for fusion.
*   **Prediction:** Apply Sigmoid activation to the 30 output logits.
*   **Validation:** Monitor Mean Column-wise Spearman's Correlation, expecting peak performance at Epoch 3.
