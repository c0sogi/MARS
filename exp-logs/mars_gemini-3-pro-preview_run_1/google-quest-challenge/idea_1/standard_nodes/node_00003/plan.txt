To improve the performance of the Dual-Branch Deep Averaging Network (DAN) (Cite solution_lesson_node_00001), I will implement the following targeted optimizations:

1.  **Enhanced Pooling Mechanism**: I will replace the simple Global Average Pooling with a concatenation of **Masked Average Pooling** and **Masked Max Pooling**. While average pooling captures the general semantic "gist" of the text, max pooling extracts the most salient features (e.g., specific keywords). Combining them provides a richer representation for the MLP to learn from, directly addressing the information bottleneck in the original DAN.
2.  **Training Dynamics**: I will introduce a `ReduceLROnPlateau` learning rate scheduler. This allows the model to dynamically reduce the learning rate when validation performance plateaus, facilitating convergence to a better local minimum.
3.  **Hyperparameter Tuning**: To accommodate the richer feature set (4x embedding dim instead of 2x) and the scheduler, I will increase the `HIDDEN_DIM` to 512 and the `EPOCHS` to 30.
4.  **Conditional Execution**: I will modify the run script to strictly adhere to the requirement of generating a submission only if the validation score exceeds the previous benchmark of ~0.2787.

    def _pool(self, seq, emb):
        """
        Performs masked average and max pooling.
        """
        # Create mask (Batch, Len, 1) where True indicates valid token
        mask = (seq != 0).unsqueeze(2)
        
        # Masked Average Pooling
        # Sum valid embeddings
        emb_sum = torch.sum(emb * mask, dim=1)
        # Count valid tokens (clamp to avoid division by zero)
        seq_lens = torch.sum(mask, dim=1).clamp(min=1e-9)
