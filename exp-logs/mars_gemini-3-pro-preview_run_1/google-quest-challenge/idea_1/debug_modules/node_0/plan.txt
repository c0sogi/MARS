The implementation strategy involves creating a single Python script that imports the provided library modules to demonstrate the end-to-end workflow of the machine learning task.

1.  **Configuration**: We will first override the default `Config` parameters to enable `DEBUG` mode and reduce the dataset size (`DEBUG_SIZE=100`), epochs, and batch size. This ensures the demonstration runs quickly within the time limit.
2.  **Data Loading**: We will explicitly call `get_dataloaders` to verify that data processing and tokenization work correctly. We will assert that the returned batch shapes match the expected dimensions defined in the configuration.
3.  **Model Verification**: We will instantiate the `DualBranchDAN` model and perform a forward pass with dummy data derived from the data loader. We will verify that the output shape is correct and that predictions are within the valid probability range `[0, 1]`.
4.  **Metric Verification**: We will demonstrate the `compute_spearman_metric` function using synthetic ground truth and prediction tensors to confirm it calculates correlations correctly (e.g., perfect correlation yields 1.0).
5.  **Training & Prediction**: We will instantiate the `Trainer` class and execute the `fit()` method to train the model for a few epochs. We will then call `predict()` to generate the submission file.
6.  **Validation**: Finally, we will verify that the submission file is created, has the correct dimensions matching the test set (or debug subset), and contains the required columns.
