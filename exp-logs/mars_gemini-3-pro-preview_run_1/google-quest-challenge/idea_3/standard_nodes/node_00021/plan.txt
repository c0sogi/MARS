The execution failure was caused by a CUDA Out Of Memory (OOM) error during the second epoch when the backbone was unfrozen. To resolve this, I will implement three memory-saving strategies:
1.  **Enable Mixed Precision (AMP)**: In `library/engine.py`, I will introduce `torch.amp.GradScaler` and `torch.amp.autocast`. This reduces the memory required for storing activations and weights by using lower precision (float16) where appropriate.
2.  **Reduce Batch Size**: In `runfile.py`, I will lower the `BATCH_SIZE` from 8 to 4 to directly reduce the memory footprint of the input tensors and intermediate states.
3.  **Enable Gradient Checkpointing**: In `runfile.py`, I will enable gradient checkpointing on the backbone. This trades a small amount of computation for significant memory savings by not storing all intermediate activations during the forward pass.
