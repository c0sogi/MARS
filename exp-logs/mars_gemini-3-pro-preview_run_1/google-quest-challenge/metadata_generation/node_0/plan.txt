The implementation strategy involves the following steps:

1.  **Setup and Data Loading**: Create the `metadata` directory. Load the raw `train.csv`, `test.csv`, and `sample_submission.csv` from the `input` directory using Pandas.
2.  **Target and Group Identification**: Identify the 30 target columns using the sample submission file. Check if the `question_body` column exists in the training data to use as a grouping key for splitting (to prevent data leakage where answers to the same question appear in both train and validation sets). If not, fall back to `qa_id` or simple random splitting.
3.  **Data Splitting**: Perform an 80:20 split using `GroupShuffleSplit` (if grouping is possible) or `train_test_split`. Use a fixed random state (`42`) to ensure reproducibility.
4.  **Metadata Generation**: Add a `filepath` column to the dataframes pointing to the source CSV files relative to the `input` directory (e.g., `train.csv`). Save the split dataframes (train, validation) and the test dataframe to the `metadata` directory.
5.  **Validation and Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (shape, target distribution mean).
    *   Verify the split ratio and ensuring no group leakage (if grouping was used).
    *   Perform a file existence check on a sample of the `filepath` column entries to ensure they resolve correctly within the `input` directory.
