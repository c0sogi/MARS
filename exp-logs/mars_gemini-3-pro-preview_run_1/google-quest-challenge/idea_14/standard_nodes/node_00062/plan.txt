7.  **Validation & Metric**: Load the best saved model. Perform a full evaluation on the validation set to compute the Mean Column-wise Spearman's Correlation. Print the result in the required format: `Final Validation Metric: <value>`.
8.  **Failure Analysis**: Compute the Mean Absolute Error (MAE) for each validation sample. Calculate correlations between this error and input text lengths (Title, Body, Answer) to identify if sequence length impacts performance.
9.  **Submission**: Compare the validation metric against the threshold (`0.40802662717842303`). If the model performs better, generate predictions for the test set and save `submission.csv` to the specified directory.
