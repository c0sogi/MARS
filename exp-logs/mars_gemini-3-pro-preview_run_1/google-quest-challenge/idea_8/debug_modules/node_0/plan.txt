This script demonstrates the end-to-end usage of the provided library modules for the StackExchange Question-Answering task. It performs the following steps:

1.  **Configuration Setup**: Imports the global configuration and overrides settings for a rapid "debug" run (small sample size, single epoch).
2.  **Data Pipeline Verification**: Initializes the tokenizer and data loaders. It fetches a single batch to verify the correctness of data shapes, padding, and tensor types.
3.  **Model Initialization & Forward Pass**: Instantiates the `DebertaDualEncoder` model using metadata dimensions derived from the data pipeline. It performs a forward pass with the sample batch to ensure the model architecture and tensor dimensions (specifically the 30 target outputs) are correct.
4.  **Metric Verification**: Tests the `compute_spearman_metric` function with synthetic data to confirm it correctly calculates the mean column-wise Spearman correlation.
5.  **Training & Inference Loop**: Runs a minimal training loop (one epoch on the debug subset), followed by evaluation and inference steps, asserting that loss values are valid and prediction shapes match the test set.
