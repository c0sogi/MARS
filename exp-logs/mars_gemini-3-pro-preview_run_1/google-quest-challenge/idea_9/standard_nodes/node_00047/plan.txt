Based on the analysis of the previous solution and the provided lessons, the primary optimization strategy is to address the **Dimensionality Bottleneck** in the feature fusion head (Cite solution_lesson_node_00046).

The previous solution utilized a `GatedFusionHead` which maintained the high dimensionality of the fused vector ($6 \times 768 = 4608$) throughout its internal layers. This resulted in a massive parameter explosion (e.g., $4608 \times 4608$ weight matrices), leading to overfitting and optimization difficulties on the small dataset (~4,400 samples).

I will replace the `GatedFusionHead` with a `BottleneckHead` (a standard MLP with a bottleneck). This head will project the high-dimensional fused features down to the model's hidden size (768) via a linear layer, followed by a non-linearity (ReLU) and dropout, before the final classification projection (Cite solution_lesson_node_00027). This significantly reduces the parameter count, forcing the model to learn compact representations of the interactions and improving generalization.

class GatedFusionHead(nn.Module):
    """
    Gated Residual Network Head.
    Implements the logic: Output = x + Dropout(Gate * Feature) -> Linear -> Logits
    """

    def __init__(self, input_dim, dropout_p=0.1, num_labels=30):
        super(GatedFusionHead, self).__init__()

        # Gate branch: determines how much of the feature to let through
        self.gate_proj = nn.Linear(input_dim, input_dim)

        # Feature branch: non-linear transformation of the input
        self.feature_proj = nn.Linear(input_dim, input_dim)

        self.dropout = nn.Dropout(dropout_p)

        # Final projection to target labels
        self.classifier = nn.Linear(input_dim, num_labels)

        self._init_weights()

    def _init_weights(self):
        nn.init.xavier_uniform_(self.gate_proj.weight)
        nn.init.zeros_(self.gate_proj.bias)
        nn.init.xavier_uniform_(self.feature_proj.weight)
        nn.init.zeros_(self.feature_proj.bias)
        nn.init.xavier_uniform_(self.classifier.weight)
        nn.init.zeros_(self.classifier.bias)

    def forward(self, x):
        # x: [Batch, Input_Dim]

        # Gate: sigma(Wg * x + bg)
        gate = torch.sigmoid(self.gate_proj(x))

        # Feature: GELU(Wf * x + bf)
        feature = F.gelu(self.feature_proj(x))

        # Residual Connection: x + Dropout(Gate * Feature)
        residual = self.dropout(gate * feature)
        out = x + residual

        # Final prediction
        logits = self.classifier(out)
        return logits

class BottleneckHead(nn.Module):
    """
    Bottleneck MLP Head.
    Projects high-dimensional fused features down to hidden size before classification.
    """

    def __init__(self, input_dim, hidden_dim, num_labels, dropout_p=0.1):
        super(BottleneckHead, self).__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.dropout = nn.Dropout(dropout_p)
        self.fc2 = nn.Linear(hidden_dim, num_labels)
        self._init_weights()

        nn.init.xavier_uniform_(self.fc1.weight)
        nn.init.zeros_(self.fc1.bias)

        nn.init.zeros_(self.fc2.bias)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
