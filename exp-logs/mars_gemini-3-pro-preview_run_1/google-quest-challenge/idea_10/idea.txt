Based on the accumulated lessons and the analysis of previous experiments, I propose the following optimized strategy.

# Model
I propose a **Text-Augmented DistilRoBERTa Dual-Encoder with Wide-Bottleneck Fusion**. This architecture synthesizes the robust efficiency of the `distilroberta` backbone with a refined metadata integration strategy and a capacity-preserving projection head, directly addressing the bottlenecks identified in previous iterations.

*   **Backbone Architecture:** Utilize **`distilroberta-base`**.
    *   *Rationale:* This backbone (82M params) has consistently outperformed both `deberta-v3-small` (44M params) and `deberta-v3-base` (184M params) in this specific low-data regime. It avoids the capacity limitations of the small model (**Cite solution_lesson_node_00045**) and the "Starved Batch" instability required to run the base model (**Cite solution_lesson_node_00022**).
*   **Textual Metadata Injection:** Prepend categorical metadata directly to the Question text sequence.
    *   Format: `"Category: [category]. Host: [host]. [question_title]..."`
    *   *Rationale:* This leverages the pre-trained model's linguistic understanding to interpret domain indicators (e.g., "StackOverflow" implies code context) without the overfitting risks of dedicated embedding layers (**Cite solution_lesson_node_00039**). By placing this at the start of the sequence, we ensure this high-level signal is never truncated.
*   **Dual-Branch Structure:** Process the "Augmented Question" and "Answer" streams independently to preserve their distinct semantic properties and maximize the effective context window (**Cite solution_lesson_node_00030**, **Cite solution_lesson_node_00032**).
*   **Masked Hybrid Pooling:** Apply **Masked Global Average and Max Pooling** to the final hidden state of both branches (**Cite solution_lesson_node_00003**).
*   **Interaction-Aware Fusion:**
    1.  Compute explicit interactions (Element-wise Product and Absolute Difference) *only* on the **Average Pooled** vectors (**Cite solution_lesson_node_00007**).
    2.  Concatenate components: $[u_{avg}, u_{max}, v_{avg}, v_{max}, u_{avg} \odot v_{avg}, |u_{avg} - v_{avg}|]$.
    3.  Apply **Layer Normalization** to the fused vector (**Cite solution_lesson_node_00009**).
*   **Wide-Bottleneck Projection Head (Structural Innovation):**
    *   Replace the standard MLP with a **Wide-Projecting MLP**.
    *   **Layer 1:** Linearly project the high-dimensional fused vector (~4608 dims) to an intermediate dimension of **1024**.
    *   **Layer 2:** GELU Activation.
    *   **Layer 3:** Dropout ($p=0.1$) (**Cite solution_lesson_node_00042**).
    *   **Layer 4:** Final Linear Projection to 30 targets.
    *   *Rationale:* Previous attempts failed because the head was either too complex (Gated Head, **Cite solution_lesson_node_00046**) or too constricted (512-dim bottleneck, **Cite solution_lesson_node_00048**). A "Wide Bottleneck" (1024 dims) provides sufficient capacity to disentangle the added metadata signals from the text features without exploding the parameter count.
    *   **Monolithic Output:** Predict all 30 targets simultaneously to leverage inter-label correlations (**Cite solution_lesson_node_00016**).

# Data
*   **Preprocessing:**
    *   **Question Input:** Construct the string: `f"Category: {category}. Host: {host}. {question_title} {question_body}"`.
    *   **Answer Input:** Use `answer`.
*   **Tokenization:** Use the `distilroberta-base` tokenizer.
*   **Dynamic Padding:** Pad sequences to the longest length in the batch to optimize throughput (**Cite solution_lesson_node_00018**).

# Training
*   **Differential Learning Rates:** Apply a high learning rate (`1e-3`) to the Wide-Bottleneck Head and a low learning rate (`2e-5`) to the backbone. This ensures the scratch-initialized head converges without destroying the pre-trained features (**Cite solution_lesson_node_00015**).
*   **Parameter Grouping:** Explicitly exclude `bias` and `LayerNorm` parameters from weight decay in the AdamW optimizer (**Cite solution_lesson_node_00018**).
*   **Batch Size:** Use a batch size of **16**. This fits comfortably in memory with `distilroberta` and provides the necessary gradient noise for robust generalization (**Cite solution_lesson_node_00012**).
*   **Schedule:** Train for **5 epochs** using a **continuous** linear decay schedule with warmup. Do not reset the optimizer after the initial warmup epoch (**Cite solution_lesson_node_00019**, **Cite solution_lesson_node_00011**).
*   **Loss Function:** Binary Cross Entropy (BCE) with Logits Loss.

# Evaluation
*   **Inference:** Pass the test data (with Metadata prefixes) through the model.
*   **Prediction:** Apply Sigmoid activation to the 30 output logits.
*   **Validation:** Monitor Mean Column-wise Spearman's Correlation. Accept the model if it exceeds the previous best (`~0.408`) plus a small noise margin (**Cite solution_lesson_node_00010**).
