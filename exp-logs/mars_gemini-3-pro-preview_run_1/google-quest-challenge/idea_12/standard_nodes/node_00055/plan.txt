Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Initialization**: Set random seeds for reproducibility and configure the device (GPU/CPU). Create the working directory.
2.  **Data Loading**: Initialize the tokenizer (`distilroberta-base`) and load the training, validation, and test dataloaders using the provided `get_dataloaders` function. This utilizes the caching mechanism for speed.
3.  **Model Setup**: Instantiate the `DistilRobertaDualEncoder`. Move it to the GPU.
4.  **Two-Stage Training**:
    *   **Stage 1 (Warmup)**: Freeze the backbone parameters. Initialize the optimizer with only the head parameters (using `Config.LR_HEAD`). Train for 1 epoch to align the randomly initialized head with the pre-trained embeddings.
    *   **Stage 2 (Fine-tuning)**: Unfreeze the backbone. Re-initialize the optimizer to include all parameters, applying differential learning rates (`LR_BACKBONE` for the transformer, `LR_HEAD` for the head). Set up a linear learning rate scheduler. Train for the remaining epochs (Configured as 4 more epochs).
    *   **Validation**: After each training epoch, evaluate on the validation set using Spearman's correlation. Use `EarlyStopping` to save the best model.
5.  **Final Evaluation**: Load the best model checkpoint. Compute the final validation metric on the full validation set.
6.  **Failure Analysis**: Calculate the Mean Absolute Error (MAE) for each validation sample. Compute and print the correlation between this error and the lengths of the question/answer text to identify if input length impacts performance.
7.  **Submission**: Check if the final validation metric exceeds the threshold (`0.40802662717842303`). If so, generate predictions for the test set, format them into a DataFrame, and save `submission.csv`.
