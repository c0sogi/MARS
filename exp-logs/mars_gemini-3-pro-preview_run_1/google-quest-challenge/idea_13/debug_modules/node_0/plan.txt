### Implementation Strategy

1.  **Configuration Setup**: We will import the `Config` class and override specific parameters (e.g., `EPOCHS`, `TRAIN_BATCH_SIZE`, `WORKING_DIR`) to ensure the demonstration runs quickly and uses a separate directory for outputs.
2.  **Utility Verification**: We will demonstrate `seed_everything` for reproducibility and validate `compute_spearmanr` using synthetic numpy arrays with known correlation properties.
3.  **Dataset & DataLoader**: We will utilize `get_dataloaders` with `debug=True`. This forces the loading of a tiny subset of the data (100 rows), ensuring the pipeline runs almost instantly. We will inspect a single batch to verify tensor shapes and key existence.
4.  **Model Initialization & Inference**: We will instantiate the `TripleBranchDistilRoBERTa` model. We will perform a forward pass with the batch retrieved from the DataLoader to verify that the output logits have the correct shape `(Batch_Size, 30)`.
5.  **Engine Components**: Instead of running the full `run_training` function (which would run for too long), we will manually construct a minimal training loop using `train_fn`, `eval_fn`, and `get_optimizer_params`. This demonstrates how to assemble the provided building blocks into a working pipeline.
6.  **Assertions**: Throughout the script, `assert` statements will be used to strictly validate shapes, types, and logic.
