The implementation strategy focuses on a comprehensive Exploratory Data Analysis (EDA) of the training dataset located in `./metadata/train.csv`. The script is designed to handle the hybrid nature of the dataset, which contains both unstructured text (comments) and structured metadata (identity attributes and toxicity scores).

1.  **Setup and Loading**: The script initializes the environment with fixed random seeds for reproducibility and loads the training data.
2.  **Target Variable Analysis**: It analyzes the `target` column both as a continuous variable (checking distribution properties like skewness) and as a binary classification target (threshold $\ge 0.5$), reporting class imbalance ratios.
3.  **Text Data Analysis**: It computes statistics on comment lengths (character and word counts) and estimates vocabulary size. This informs decisions on sequence truncation and tokenizer vocabulary limits.
4.  **Tabular/Identity Analysis**: It treats the identity columns (e.g., `male`, `female`, `black`) as tabular features. It checks for missing values, calculates correlations with the toxicity target to identify potential bias, and trains a lightweight Random Forest model to determine which identity features are most strongly associated with toxicity labels in the training data.
5.  **Meta-Feature Relationships**: It investigates the relationship between text length and toxicity to see if longer or shorter comments are disproportionately toxic.
