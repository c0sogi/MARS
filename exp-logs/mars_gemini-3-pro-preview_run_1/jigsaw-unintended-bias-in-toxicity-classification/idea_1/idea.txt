# Baseline Solution: Ridge Regression with Soft Targets and Bias-Corrective Resampling

### Model
The proposed model is a **Ridge Regression (Linear Least Squares with L2 Regularization)** classifier. Unlike the provided architectures that treat the task as a binary classification problem (using Logistic Regression, SVMs, or Softmax), this approach treats toxicity detection as a **regression problem**.

*   **Architecture**: The model consists of a single linear layer ($y = w^T x + b$). It takes high-dimensional sparse vectors as input and outputs a continuous score directly.
*   **Key Distinction**: By using a regression framework, the model can learn from the **fractional** toxicity labels provided in the dataset (e.g., a score of 0.6) rather than forcing them into binary buckets (0 or 1). This preserves the nuance of "ambiguous" comments—which often contain identity mentions—preventing the model from becoming over-confident on difficult examples.

### Data
1.  **Text Vectorization**:
    *   Apply **TF-IDF (Term Frequency-Inverse Document Frequency)** vectorization to the `comment_text`.
    *   Generate both **word n-grams** (e.g., unigrams and bigrams) and **character n-grams** (e.g., 3-5 chars). This captures both semantic meaning and morphological patterns (e.g., obfuscated slurs) without heavy deep learning embeddings.
2.  **Bias-Corrective Resampling (Preprocessing)**:
    *   To minimize unintended bias, perform **Stratified Oversampling** on the training data before vectorization.
    *   Identify the "hard" subgroups that contribute to the BPSN (Background Positive, Subgroup Negative) and BNSP (Background Negative, Subgroup Positive) metrics. Specifically, duplicate training rows that are **Non-Toxic + Identity Mention** and **Toxic + Identity Mention**.
    *   This physical alteration of the dataset distribution forces the linear model to pay more attention to the context surrounding identity terms, effectively counteracting the imbalance that leads to bias, without requiring complex loss weighting schemes.

### Training
*   **Objective Function**: Minimize **Mean Squared Error (MSE)** between the predicted score and the **raw fractional target** (`target`).
    *   *Note*: Standard baselines often threshold the target at 0.5 and minimize Log-Loss. Using MSE on soft targets is computationally faster and empirically provides better ranking (AUC) for this specific dataset because it penalizes the model less for being "unsure" about ambiguous identity-based comments.
*   **Optimization**: Use an iterative solver (e.g., **LSQR** or **SAG**) to solve the Ridge Regression optimization problem. This is extremely memory-efficient and fast for sparse TF-IDF matrices compared to exact matrix inversion.

### Evaluation
*   **Inference**: Transform the test set text using the fitted TF-IDF vectorizer and pass it through the trained linear model.
*   **Post-Processing**: The raw regression output is clipped to the range [0, 1] to ensure valid probability-like predictions for the submission format. No thresholding is applied, as the metric is ROC-AUC (rank-based).
