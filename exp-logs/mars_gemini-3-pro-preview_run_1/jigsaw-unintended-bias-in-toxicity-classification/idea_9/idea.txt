# Proposed Solution: Domain-Adaptive DeBERTa-v3-Large with Multi-Task Ranking and Adversarial Robustness

### Model
**Architecture:**
We utilize **DeBERTa-v3-Large** as the backbone. This model is chosen for its superior disentangled attention mechanism, which is critical for distinguishing between the *content* of an identity term and its *context*.
**Structural Innovation (Triangulated Multi-Task Heads):**
We employ a **Multi-Task Learning (MTL)** architecture where the shared encoder feeds into three distinct classification heads. This explicitly prevents the model from collapsing identity concepts into a single "toxicity" proxy. **Cite solution_lesson_node_00004**.
1.  **Primary Toxicity Head:** Predicts the main `target`.
2.  **Auxiliary Identity Head:** Predicts the presence of identity attributes (e.g., `male`, `muslim`).
3.  **Auxiliary Identity Attack Head:** Predicts the `identity_attack` subtype. This provides a triangulation signal, teaching the model that *Identity* + *Attack* = Toxic, but *Identity* alone $\neq$ Toxic.
**Pooling:** We replace the standard `[CLS]` token pooling with **Mean Pooling** of the last hidden state to generate a more robust sentence representation for the noisy comment text.

### Data
**Preprocessing:**
1.  **Corpus Generation:** We create a massive unlabeled text corpus by concatenating the `comment_text` from both the **Train** and **Test** datasets. This allows the model to learn from the test set distribution (transductive learning) without using labels.
2.  **Stratified Weighted Sampling:** For the supervised phase, we use a **Weighted Random Sampler** that significantly oversamples the "Bias Trap" subgroups (Non-Toxic + Identity Mention, Toxic + Identity Mention). This ensures that every mini-batch contains a dense mixture of these rare examples, which is a strict prerequisite for the pairwise ranking loss to function. **Cite solution_lesson_node_00007**.
3.  **Bias-Centric Sample Weights:** We generate a sample weight vector where examples belonging to the "Bias Trap" subgroups are assigned a significantly higher weight (e.g., 5.0) compared to standard examples (1.0). **Cite solution_lesson_node_00002**.

### Training
**Pipeline Stage 1: Domain-Adaptive Pretraining (DAPT):**
Before supervised training, we perform **Masked Language Modeling (MLM)** on the combined Train + Test corpus for 1 epoch. This adapts the DeBERTa backbone's internal representations to the specific dialect, slang, and obfuscations found in online comments, reducing the domain shift between the pre-trained weights (Wikipedia/Books) and the competition data.

**Pipeline Stage 2: Robust Supervised Fine-Tuning:**
We fine-tune the adapted model using a **Hybrid Loss Function** and **Adversarial Weight Perturbation (AWP)**.
1.  **Loss Function:** $L_{total} = L_{BCE\_Weighted} + \lambda_{rank} L_{Rank} + \lambda_{aux} L_{Aux}$.
    *   **Weighted Pointwise Loss ($L_{BCE\_Weighted}$):** Weighted Binary Cross-Entropy on soft toxicity targets using the **Bias-Centric Sample Weights**. This forces the model to prioritize minimizing error on the specific subgroups that degrade the metric. **Cite solution_lesson_node_00002**.
    *   **Pairwise Margin Ranking Loss ($L_{Rank}$):** We mine hard pairs within each batch (e.g., Toxic Background vs. Non-Toxic Identity) and penalize the model if it ranks the neutral identity example higher than the toxic background example. This directly optimizes the rank-based competition metric. **Cite solution_lesson_node_00007**.
    *   **Auxiliary Loss ($L_{Aux}$):** Standard BCE on the auxiliary heads to enforce semantic disentanglement. **Cite solution_lesson_node_00004**.
2.  **Adversarial Weight Perturbation (AWP):** We integrate AWP into the training loop. This technique injects worst-case perturbations into the model weights during the forward pass and minimizes the loss with respect to these perturbations. This forces the model to find a "flat minimum" in the loss landscape, significantly improving robustness against overfitting to specific identity tokens.

### Evaluation
**Inference:**
The test data is processed through the fine-tuned DeBERTa-v3-Large backbone. We extract predictions **only from the Primary Toxicity Head** for the final submission. The auxiliary heads and ranking logic are training-time constraints used solely to shape the encoder's representation.
