Implementation strategy:
1.  **Setup & Config**: Initialize the environment, setting random seeds and the logger. Override `Config` parameters to ensure a "fast baseline" execution (1 epoch, batch size 16, immediate AWP start) suitable for the available compute and time constraints.
2.  **Data Loading**: Load the pre-processed training data using `load_and_process_data`. To strictly adhere to the runtime limit, subsample the training data to 80,000 samples while preserving the `WeightedRandomSampler` logic for bias mitigation. Load the full validation set.
3.  **Model & Training**: Initialize the `DebertaV3MultiTask` model, AdamW optimizer, and Cosine scheduler. Initialize `AWP` (Adversarial Weight Perturbation). Execute the training loop for 1 epoch using `train_one_epoch`.
4.  **Validation**: Evaluate the model on the full validation set using `validate`. Print the required "Final Validation Metric".
5.  **Failure Analysis**: Perform a separate inference pass on the validation set to calculate absolute prediction errors. Compute and print the correlation of these errors with identity attributes and text length to identify systematic biases.
6.  **Submission**: Check if the validation score exceeds the specified threshold (0.9268315106992828). If successful, load the test set and generate the `submission.csv` using the `inference` function.
