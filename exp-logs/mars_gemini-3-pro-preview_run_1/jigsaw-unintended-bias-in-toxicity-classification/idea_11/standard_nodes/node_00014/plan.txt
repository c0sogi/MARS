Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds, and override `Config` parameters to ensure the pipeline runs within the 6-minute limit (e.g., reducing epochs to 1, batch sizes, and subsampling datasets).
2.  **Data Loading & Subsampling**: Load the training, validation, and test datasets. Crucially, subsample them (e.g., 1000 training samples) to allow the heavy DeBERTa-Large model to complete training cycles quickly.
3.  **Stage 1: DAPT (Simplified)**: Run the Domain-Adaptive Pretraining on the subsampled text data to adapt the tokenizer/encoder, saving the model to a temporary path.
4.  **Stage 2: Scout Training & Mining**: Train a lightweight "Scout" model (or the DAPT model) on the subsampled training data. Use this model to predict on a subset of the test data, identify "Bias Traps" (Hard Negatives), and augment the training set with these difficult examples.
5.  **Stage 3: Final Robust Training**: Train the final model on the augmented dataset using Adversarial Weight Perturbation (AWP) and the custom bias-aware loss function.
6.  **Validation**: Create a custom deterministic DataLoader (without weighted sampling) to evaluate the model on the validation set. Compute the competition metric and perform failure analysis (correlation of errors with identity attributes).
7.  **Submission**: If the validation score exceeds the specified threshold, perform inference on the *full* test set (using a large batch size for speed) and generate the submission file.
