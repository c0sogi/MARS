This script demonstrates the end-to-end usage of the provided library files for the Toxicity Classification task. It covers data loading, sample weight calculation for bias mitigation, metric computation, model initialization, training with a debug subset, and submission generation.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to enable `DEBUG` mode (reducing dataset size) and set `EPOCHS` to 1 for a fast execution.
2.  **Data Loading Verification**: We utilize `get_data_loaders` to load the data and verify the structure and shapes of the batches (input IDs, masks, targets, weights).
3.  **Bias Logic Verification**: We create a synthetic dataframe to verify that `calculate_sample_weights` correctly assigns higher weights to "trap" examples (e.g., non-toxic comments mentioning an identity).
4.  **Metric Verification**: We test `compute_final_metric` with a perfect prediction scenario to ensure it returns a perfect score (1.0).
5.  **Training Loop**: We instantiate the `ToxicityClassifier` and `Trainer`, then run `trainer.fit()` on the debug data. We replicate the sampling logic used in the data loader to ensure the validation dataframe aligns with the validation loader.
6.  **Inference**: We generate predictions using `trainer.generate_submission` and verify the output file format.
