The implementation strategy follows a three-stage pipeline designed to maximize performance through ensemble learning and semi-supervised distillation, utilizing Stochastic Weight Averaging (SWA) at each training phase.

1.  **Stage 1: Teacher Ensemble Training:** We train three independent `BirdResNet` (ResNet-34) models on the labeled training set. Each model is trained for 40 epochs, with SWA activated for the final 25% of epochs to find a flatter, more robust minimum.
2.  **Stage 2: Pseudo-Label Generation:** The three SWA teacher models generate predictions for the unlabeled test set (Fold 1). These predictions are averaged to reduce variance and then sanitized (NaNs removed, values clipped) to serve as soft targets (pseudo-labels).
3.  **Stage 3: Student Distillation:** A single student model is trained on a combined dataset consisting of the original labeled training data and the pseudo-labeled test data. This student model is trained for 50 epochs, with SWA activated for the final 30% of epochs. This step allows the student to learn from the high-confidence patterns identified by the teacher ensemble.
4.  **Validation & Analysis:** The final student model is evaluated on the hold-out validation set. We report the ROC AUC metric and perform a failure analysis by correlating the prediction error with the number of species present (label cardinality).
5.  **Submission:** If the validation metric exceeds the specified threshold, predictions are generated for the test set, formatted, and saved to `submission.csv`.
