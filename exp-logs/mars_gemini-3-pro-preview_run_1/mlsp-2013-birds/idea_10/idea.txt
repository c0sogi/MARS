Based on the comprehensive analysis of previous experiments and the "Lessons Learned," I propose the **High-Fidelity Resolution-Aligned Distillation with Dual-Stage SWA**.

This strategy introduces two structural innovations:
1.  **Resolution-Aligned Distillation:** It shifts the feature engineering paradigm from "feature densification" (512px width) to **"high-fidelity preservation" (640px width)**. This aligns the student model's capacity with the optimal resolution identified in Lesson 00036, preventing the degradation caused by forcing a student to learn from a teacher that sees features the student cannot.
2.  **Dual-Stage Stochastic Weight Averaging (SWA):** It extends the SWA protocol to the **Teacher Ensemble** phase. By stabilizing the teachers before generating pseudo-labels, we produce higher-quality, lower-variance targets for the student, amplifying the benefits of the semi-supervised pipeline.

### Model
*   **Backbone:** Maintain the **ResNet-34** architecture initialized with ImageNet weights. This remains the optimal backbone for this dataset size, balancing capacity and regularizability (Cite solution_lesson_node_00006, solution_lesson_node_00015).
*   **Input Adaptation:** Use **Channel Replication** (copying the single-channel spectrogram to R, G, and B inputs) to preserve natural image statistics (Cite solution_lesson_node_00022).
*   **Classification Head:** Use a standard **Linear Layer** projecting to the 19 species classes, strictly avoiding complex aggregation heads (Cite solution_lesson_node_00007).

### Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Vertical Dimension:** Fix height at **256 pixels** to strictly preserve native frequency resolution (Cite solution_lesson_node_00013).
    *   **Horizontal Dimension:** Resize images to a fixed width of **640 pixels**. This resolution was empirically identified as the superior "sweet spot" (outperforming 512px) in Lesson 00036, capturing fine-grained temporal morphology without becoming too sparse (as seen with 1280px in Lesson 00015).
*   **Pipeline Integrity:** Implement **Purely Dynamic In-Memory Loading**. Do not cache pre-processed tensors to disk. This ensures that dynamic, per-epoch augmentations are applied correctly, preventing the performance regression observed when static caching was used (Cite solution_lesson_node_00018, solution_lesson_node_00032).
*   **Augmentation:** Apply **Conservative Mixup** (alpha=0.2) and **SpecAugment** dynamically during training (Cite solution_lesson_node_00030).

### Training
I will implement a **Three-Stage Pipeline** that incorporates SWA at both model training stages:

1.  **Stage 1: High-Fidelity Teacher Ensemble with SWA**
    *   Train **3 independent ResNet-34 models** on the labeled training set (Fold 0) at **256x640** resolution.
    *   **SWA Protocol:** Train for an extended schedule (e.g., 40 epochs). Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs. This creates "Super-Teachers" with flatter minima and better generalization than standard early-stopped models (Cite solution_lesson_node_00028).
    *   Use **BCEWithLogitsLoss** (Cite solution_lesson_node_00008) and a stable learning rate of **3e-4** (Cite solution_lesson_node_00025).

2.  **Stage 2: Sanitized Pseudo-Label Generation**
    *   Generate predictions for the unlabeled Test Set (Fold 1) using the 3 SWA Teachers.
    *   Average the probabilities to create robust soft targets.
    *   **Sanitize:** Explicitly assert that the merged targets contain no `NaN` values before proceeding (Cite solution_lesson_node_00027).

3.  **Stage 3: Resolution-Aligned Student with SWA**
    *   Train a single **ResNet-34 Student** on the **Combined Dataset** (Labeled Train + Sanitized Pseudo-Labeled Test).
    *   **Input Resolution:** **256x640**. This matches the teacher's resolution, ensuring the student can see the same fine-grained features that informed the pseudo-labels (Cite solution_lesson_node_00036).
    *   **SWA Protocol:** Train for an extended duration (e.g., 50 epochs) and activate SWA for the final 30% of epochs (Cite solution_lesson_node_00029).

### Evaluation
*   **Inference:** Preprocess test images to the high-fidelity resolution (**256 x 640**), normalize, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities.
