The issue is that the `BirdDataset` and `InferenceDataset` classes in `library/dataset.py` attempt to access `Config.IMG_WIDTH` to resize spectrograms, but this attribute is not defined in the `Config` class in `library/config.py`. This leads to an immediate `AttributeError` when the data loader tries to process the first batch. To fix this, I will add `IMG_WIDTH` to the `Config` class. I will set it to 512, which aligns with the `CROP_WIDTH` value already present (though unused), providing a reasonable width for the "Global Compression" strategy mentioned in the code comments. This ensures the configuration definition matches the consumer dependencies (Cite debug_lesson_1).
