# Optimized Strategy: High-Fidelity ResNet-50 Ensemble with Sliding Window Inference

## Model
I propose upgrading the architecture to a **ResNet-50** Convolutional Neural Network, pretrained on ImageNet. This deeper backbone (compared to the previous ResNet-34) offers a higher capacity to model complex spectral features.
*   **Backbone:** ResNet-50, replacing the initial convolution to accept 1-channel input (or replicating the grayscale spectrogram to 3 channels).
*   **Classification Head:** A standard **Linear Layer** projecting the pooled features to the 19 species classes. I will explicitly avoid complex aggregation mechanisms (like Concat Pooling) which have been shown to degrade performance in this low-data regime (Cite Lesson 00007).
*   **Input Strategy:** The model will accept **high-resolution temporal crops** rather than globally resized images, preserving the fine-grained morphological signatures of bird calls identified as critical for classification (Cite Lesson 00006).

## Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing:**
    *   **High-Fidelity Cropping (Structural Innovation):** Instead of resizing the full ~1246-pixel wide spectrogram into a small square (e.g., 224x224)—which squashes short calls and destroys signal fidelity—I will train on **random temporal crops** of width 512 pixels (approx. 4 seconds) and height 224 pixels. This maintains the original time-frequency resolution.
    *   **Normalization:** Standard ImageNet mean/std normalization.
*   **Augmentation:**
    *   **Conservative Mixup:** Apply Mixup augmentation with a low beta parameter (**alpha = 0.2**). This ensures that synthetic samples remain predominantly one class (e.g., 90/10 blends) rather than ambiguous 50/50 mixtures, preserving the distinct features necessary for learning from few examples (Cite Lesson 00007).
    *   **SpecAugment:** Apply random time and frequency masking to encourage robustness.

## Training
*   **Strategy:** Implement a **Stratified 5-Fold Cross-Validation** loop. Given the extremely small dataset size (208 training samples), training a single model is prone to high variance. An ensemble of 5 models trained on different data splits will significantly improve generalization and stability.
*   **Loss Function:** Use **BCEWithLogitsLoss**. I will avoid Focal Loss, as previous experiments demonstrated that it degrades the global AUC score by suppressing the "easy" examples that constitute the majority of the stable training signal in small datasets (Cite Lesson 00008).
*   **State Preservation:** Implement Early Stopping based on validation AUC. Crucially, I will use `copy.deepcopy(model.state_dict())` to save the best model weights, ensuring the checkpoint is an immutable snapshot that does not degrade as training continues (Cite Lesson 00001).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.

## Evaluation
*   **Inference (Sliding Window):** For each test recording, generate predictions using a **Sliding Window** approach. Extract overlapping 512-pixel wide crops with a stride of 256 pixels to cover the entire 10-second duration.
*   **Aggregation:**
    1.  **Window Aggregation:** Average the logits (pre-sigmoid) across all sliding windows for a single recording. This ensures that a bird call appearing at any point in the clip contributes to the final detection.
    2.  **Ensemble Aggregation:** Average the final probabilities across the **5 Cross-Validation models**.
*   **Submission:** Format the averaged probabilities into the required `Id,Probability` CSV structure.
