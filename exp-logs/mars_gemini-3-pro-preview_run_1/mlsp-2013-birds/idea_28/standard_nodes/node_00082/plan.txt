This implementation orchestrates the **Augmentation-Stratified ResNet-34 Ensemble Distillation** pipeline. It proceeds in four main stages:

1.  **Teacher Ensemble Training**: Trains three independent ResNet-34 models, each with a distinct augmentation policy ("Texture", "Feature", "Balanced") to induce error decorrelation. Training uses Stochastic Weight Averaging (SWA) and runs for a reduced epoch count (30) to ensure execution within the time limit while maintaining convergence on the small dataset.
2.  **Pseudo-Label Generation**: Generates calibrated pseudo-labels for the test set using the ensemble. It applies Test-Time Augmentation (TTA) and Temperature Scaling ($T=1.5$) to soften the targets and preserve inter-class relationships.
3.  **Student Training**: Trains a single ResNet-34 Student model on the combined dataset (Labeled Train + Pseudo-Labeled Test) using the "Balanced" policy and SWA.
4.  **Evaluation & Submission**: Validates the student model, performs failure analysis by correlating error with label cardinality, and generates the submission file if the validation AUC exceeds the specified threshold.
