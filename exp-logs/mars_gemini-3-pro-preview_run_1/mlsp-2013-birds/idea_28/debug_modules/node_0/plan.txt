The following code demonstrates the complete pipeline for the bird species classification task using the provided library.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class parameters to enable `DEBUG` mode and reduce training epochs/batch sizes. This ensures the script runs quickly (within a few minutes) on a small subset of the data while exercising all code paths.
2.  **Data Loading**: We load the pre-generated metadata and initialize DataLoaders using `get_dataloaders`. This handles image loading, augmentation policies, and dataset splitting.
3.  **Teacher Training**: We train a "Teacher" model using the `run_training_cycle` function with the "Texture" augmentation policy. We verify that the model checkpoint is saved correctly.
4.  **Pseudo-Labeling**: Using the trained Teacher model, we generate pseudo-labels for the test set via `generate_pseudo_labels`. This simulates the semi-supervised learning aspect of the task.
5.  **Student Training**: We train a "Student" model using the combined original training data and the pseudo-labeled test data. This uses the "Balanced" policy.
6.  **Inference**: Finally, we generate predictions using the Student model and save them to a submission CSV file, verifying the output format.
