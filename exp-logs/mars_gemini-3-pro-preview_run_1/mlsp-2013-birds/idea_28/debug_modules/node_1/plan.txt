The issue arises because Python evaluates default arguments at function definition time (import time), binding `get_dataloaders` to the original `Config.BATCH_SIZE` (32). When `runfile.py` subsequently overrides `Config.BATCH_SIZE` to 8 for the demo execution, `get_dataloaders` continues to use the stale default value of 32, causing an assertion failure when the returned batch size is checked. To fix this, we must explicitly pass the updated `Config.BATCH_SIZE` when calling `get_dataloaders`, ensuring the runtime configuration is respected (Cite debug_lesson_14).

    )
=======
    teacher_loaders = get_dataloaders(
        train_df, val_df, test_df, teacher_policy="Texture",
        batch_size=Config.BATCH_SIZE,
    )
