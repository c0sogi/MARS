Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Sharpness-Aware High-Fidelity SWA-Distillation**.

This strategy introduces a fundamental innovation in the optimization paradigm: **Sharpness-Aware Minimization (SAM)**. While previous attempts focused on architectural regularization (Dropout, Stochastic Depth) which proved destructive in this micro-data regime (Lesson 00063), SAM regularizes the *optimization trajectory* itself. By simultaneously minimizing loss value and loss curvature, SAM forces the model to converge to "flat minima" which are robust to domain shifts. This is synergized with **Stochastic Weight Averaging (SWA)** and the proven **High-Fidelity Distillation** pipeline to maximize generalization.

# Model
*   **Backbone:** Utilize the **Vanilla ResNet-34** architecture initialized with ImageNet weights.
    *   *Strategic Retention:* This backbone is retained as the optimal choice. It provides sufficient capacity without the overfitting risks of larger models **Cite solution_lesson_node_00006** and avoids the suppression of co-occurring classes observed with SE-ResNet architectures in multi-label tasks **Cite solution_lesson_node_00056**.
    *   *Homogeneity:* Both Teachers and Student will use this architecture to ensure inductive bias alignment **Cite solution_lesson_node_00068**.
*   **Optimization (Structural Innovation):** Replace the standard optimizer (e.g., AdamW) with **SAM (Sharpness-Aware Minimization)** wrapping AdamW.
    *   *Rationale:* In small datasets (N=208), standard optimizers often converge to "sharp" minima—narrow valleys in the loss landscape where training error is low but test error is high. SAM explicitly solves a min-max problem to find a neighborhood of parameters with uniformly low loss (a "flat" minimum), significantly improving generalization without requiring destructive structural noise like Dropout.
*   **Classification Head:** Use a standard **Linear Layer** projecting to the 19 species classes **Cite solution_lesson_node_00007**.

# Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Resolution:** Resize images to **256 pixels (Height) x 640 pixels (Width)**. This preserves native frequency resolution **Cite solution_lesson_node_00013** and captures the fine-grained temporal morphology required for high performance **Cite solution_lesson_node_00041**.
    *   **Normalization:** Explicitly apply **ImageNet Mean and Standard Deviation normalization** to maintain the transfer learning contract **Cite solution_lesson_node_00045**.
    *   **Input Adaptation:** Use **Channel Replication** (grayscale to RGB) **Cite solution_lesson_node_00022**.
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Implement purely dynamic in-memory loading without disk caching **Cite solution_lesson_node_00018**.
    *   **Deterministic Seeding:** Explicitly pass a fixed seed to the NumPy `default_rng()` generator within augmentation classes to prevent hidden variance **Cite solution_lesson_node_00043**.
*   **Augmentation:**
    *   **Unstructured Cutout:** Apply random rectangular masks **Cite solution_lesson_node_00038**.
    *   **Horizontal Flip:** Enable random time inversion **Cite solution_lesson_node_00039**.
    *   **Conservative Mixup:** Apply Input-level Mixup with **alpha = 0.2** **Cite solution_lesson_node_00030**. (Strictly avoid Manifold Mixup **Cite solution_lesson_node_00070**).

# Training
I will implement a **Single-Stage Ensemble Distillation Pipeline** enhanced with SAM and SWA. I will explicitly avoid iterative distillation to prevent error amplification **Cite solution_lesson_node_00065**.

1.  **Stage 1: Sharpness-Aware Teacher Ensemble**
    *   Train **3 independent ResNet-34 models** on the labeled training set (Fold 0).
    *   **Optimizer:** **SAM** (neighborhood size `rho=0.05`).
    *   **Schedule:** Train for **50 epochs** to ensure full convergence with Mixup **Cite solution_lesson_node_00044**.
    *   **SWA Protocol:** Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs. The combination of SAM (finding flat regions) and SWA (averaging within flat regions) creates a "Flat-Minima Synergy" for maximum robustness **Cite solution_lesson_node_00028**.
    *   **Safety:** Explicitly disable Early Stopping during the SWA phase **Cite solution_lesson_node_00050**.
    *   **Loss:** BCEWithLogitsLoss **Cite solution_lesson_node_00008**.

2.  **Stage 2: Robust Pseudo-Label Generation**
    *   Generate predictions for the Test Set (Fold 1) using the 3 Teachers.
    *   **TTA:** Apply **Test-Time Augmentation** (Horizontal Flips) during inference and average the results.
    *   **Ensemble Averaging:** Average the predictions across the 3 teachers.
    *   **Sanitize:** Assert no `NaN` values **Cite solution_lesson_node_00027**.

3.  **Stage 3: Sharpness-Aware Student Training**
    *   Train a single **ResNet-34 Student** on the **Combined Dataset** (Labeled Train + Pseudo-Labeled Test).
    *   **Optimizer:** **SAM**.
    *   **Schedule:** 50 epochs with SWA active in the final 30% **Cite solution_lesson_node_00029**.

# Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, apply **ImageNet Normalization**, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities. This leverages the finding that a single model trained on maximal data outperforms cross-validation ensembles **Cite solution_lesson_node_00012**.
