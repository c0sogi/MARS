The `AssertionError: Validation AUC out of range: nan` occurs because the `roc_auc_score` function (with `average='macro'`) returns `nan` when the validation subset contains "degenerate" classes (i.e., species with no positive samples in the current batch or split). This is a known issue when working with small or imbalanced validation sets, as the metric for those specific classes is mathematically undefined. To fix this, I will modify `calculate_roc_auc` in `library/utils.py` to explicitly iterate over each class. I will check if a class contains both positive and negative samples using `np.unique` before calculating its AUC, and then compute the mean of only the valid class scores. This ensures the global metric remains valid even if some classes are missing from the validation data (Cite debug_lesson_5).
