Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Diversity-Augmented ResNet34-d Ensemble Distillation with SWA**.

This strategy introduces a structural innovation in the **Backbone Architecture** (ResNet34-d) to better preserve spectral fidelity and a novel **Ensemble Diversity Strategy** (Augmentation Heterogeneity) to improve pseudo-label quality. It strictly retains the successful high-fidelity resolution and SWA-Distillation pipeline while avoiding the architectural pitfalls (SE-Attention, Heterogeneous Backbones) and optimization errors (Normalization, Seeding) identified in previous lessons.

# Model
*   **Backbone (Structural Innovation):** Utilize the **ResNet34-d** architecture (via `timm`) initialized with ImageNet weights.
    *   *Rationale:* Standard ResNet-34 uses an aggressive initial stem (7x7 convolution with stride 2, followed by Max Pooling) which rapidly downsamples the input, discarding fine-grained spatial information. **ResNet34-d** replaces this stem with three consecutive 3x3 convolutions. In the context of spectrograms, this modification preserves the high-frequency transient details of bird calls (syllables/trills) that are otherwise lost in the first layer, aligning with the "High-Fidelity" imperative **Cite solution_lesson_node_00041** without introducing the risky channel attention mechanisms that failed in SE-ResNet **Cite solution_lesson_node_00056**.
*   **Classification Head:** Use a standard **Linear Layer** projecting to the 19 species classes, strictly avoiding complex aggregation heads **Cite solution_lesson_node_00007**.
*   **Input Adaptation:** Use **Channel Replication** (copying the single-channel spectrogram to R, G, and B inputs) to preserve natural image statistics **Cite solution_lesson_node_00022**.

# Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Resolution:** Resize images to **256 pixels (Height) x 640 pixels (Width)**. This resolution strictly preserves the native frequency resolution **Cite solution_lesson_node_00013** and captures the fine-grained temporal morphology required for high performance **Cite solution_lesson_node_00041**. Crucially, all models (Teachers and Student) will operate at this fixed resolution to prevent knowledge dilution **Cite solution_lesson_node_00036** and geometric distortion **Cite solution_lesson_node_00072**.
    *   **Normalization:** Explicitly apply **ImageNet Mean and Standard Deviation normalization**. This is mandatory to uphold the transfer learning contract **Cite solution_lesson_node_00045**.
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Implement purely dynamic in-memory loading without disk caching to prevent stale data issues **Cite solution_lesson_node_00018**.
    *   **Deterministic Seeding:** Explicitly pass a fixed seed to the NumPy `default_rng()` generator within augmentation classes to prevent hidden variance **Cite solution_lesson_node_00043**.
*   **Augmentation:**
    *   **Unstructured Cutout:** Apply random rectangular masks **Cite solution_lesson_node_00038**.
    *   **Horizontal Flip:** Enable random time inversion **Cite solution_lesson_node_00039**.
    *   **Mixup:** Applied with varying intensities (see Training).

# Training
I will implement a **Single-Stage Ensemble Distillation Pipeline** with extended schedules. I will explicitly avoid iterative distillation to prevent error amplification **Cite solution_lesson_node_00065**.

1.  **Stage 1: Diversity-Augmented Teacher Ensemble (Structural Innovation)**
    *   Train **3 independent ResNet34-d models** on the labeled training set (Fold 0).
    *   **Augmentation Heterogeneity:** Instead of relying solely on random initialization for diversity, vary the **Mixup Intensity** for each teacher to induce different decision boundary smoothings:
        *   **Teacher 1:** Mixup $\alpha = 0.1$ (Conservative).
        *   **Teacher 2:** Mixup $\alpha = 0.2$ (Balanced).
        *   **Teacher 3:** Mixup $\alpha = 0.3$ (Stronger Regularization).
    *   **Schedule:** Train for **50 epochs** to ensure convergence **Cite solution_lesson_node_00044**.
    *   **SWA Protocol:** Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs **Cite solution_lesson_node_00028**.
    *   **Safety:** Explicitly disable Early Stopping during the SWA phase **Cite solution_lesson_node_00050**.
    *   **Loss:** BCEWithLogitsLoss **Cite solution_lesson_node_00008**.

2.  **Stage 2: Robust Pseudo-Label Generation**
    *   Generate predictions for the Test Set (Fold 1) using the 3 Teachers.
    *   **TTA:** Apply **Test-Time Augmentation** (Horizontal Flips) during inference and average the results.
    *   **Ensemble Averaging:** Average the predictions across the 3 teachers. This combines models trained with different regularization strengths, creating a robust consensus.
    *   **Sanitize:** Assert no `NaN` values **Cite solution_lesson_node_00027**.

3.  **Stage 3: Student Training**
    *   Train a single **ResNet34-d Student** on the **Combined Dataset** (Labeled Train + Pseudo-Labeled Test).
    *   **Augmentation:** Use the balanced Mixup $\alpha = 0.2$ **Cite solution_lesson_node_00030**.
    *   **Schedule:** 50 epochs with SWA active in the final 30% **Cite solution_lesson_node_00029**.

# Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, apply **ImageNet Normalization**, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities. This leverages the finding that a single model trained on maximal data outperforms cross-validation ensembles **Cite solution_lesson_node_00012**.
