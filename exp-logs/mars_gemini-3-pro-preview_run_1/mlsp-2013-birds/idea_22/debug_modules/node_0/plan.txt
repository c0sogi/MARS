The following script demonstrates the complete workflow using the provided library modules. It performs the following steps:

1.  **Configuration Override**: Modifies global settings in `config.py` to run on a small subset of data with reduced epochs for rapid execution.
2.  **Data Loading**: Initializes data loaders and verifies the `DynamicBatchCollate` logic and tensor shapes.
3.  **Model Initialization**: Instantiates the ResNet-34 model adapted for 19 classes.
4.  **Training**: executes a training loop using the `Trainer` class, including Mixup augmentation and Stochastic Weight Averaging (SWA), and verifies checkpoint creation.
5.  **Inference & TTA**: Runs standard inference and Multi-Scale Test-Time Augmentation (TTA) on the test set.
6.  **Submission & Pseudo-Labeling**: Generates a submission CSV and a pseudo-label Parquet file, validating their format and existence.
