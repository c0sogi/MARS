The issue is caused by a mismatch between the number of predictions generated (which respects `config.DEBUG_MAX_SAMPLES`) and the number of recording IDs loaded from the metadata (which loads the full dataset). In `generate_submission`, the code iterates over the full list of `rec_ids` (64 items) but attempts to index into `probs` (32 items), causing an `IndexError` when the index exceeds the prediction array size. A similar issue exists in `save_pseudo_labels`, where a length mismatch would trigger a `ValueError`.

To fix this, I will modify both `generate_submission` and `save_pseudo_labels` in `library/inference.py` to explicitly apply the `config.DEBUG_MAX_SAMPLES` limit to the loaded metadata dataframe. This ensures the metadata subset aligns exactly with the data subset processed by the `BirdDataset` and `DataLoader`, resolving the inconsistency (Cite debug_lesson_4).
