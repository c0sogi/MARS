Based on the comprehensive analysis of previous experiments and the "Lessons Learned," I propose the **Multi-Generational Noisy Student Distillation with SWA and Head Dropout**.

This strategy represents a structural evolution of the successful Idea 11 (High-Fidelity Distillation). It introduces a **Multi-Generational Self-Training Pipeline** (Iterative Distillation) to progressively refine pseudo-labels. Crucially, it incorporates **Head Dropout** as a specific noise injection mechanism to prevent the student from overfitting to the teacher's bias during the second generation, while strictly adhering to the architectural constraints (Vanilla ResNet-34) identified in Lesson 00056.

### Model
*   **Backbone:** Utilize the **ResNet-34** architecture initialized with ImageNet weights. This backbone is retained as the optimal choice, balancing capacity and generalization for this micro-dataset **Cite solution_lesson_node_00006**. I will strictly avoid Squeeze-and-Excitation (SE) blocks, as they have been proven to suppress co-occurring classes in this multi-label task **Cite solution_lesson_node_00056**.
*   **Classification Head (Structural Innovation):** Modify the standard linear head to include a **Dropout Layer (p=0.5)** before the final projection (`Dropout -> Linear`).
    *   *Rationale:* In a multi-generational pipeline, the Student must be "noisier" than the Teacher to learn a more robust manifold (The "Noisy Student" principle). While previous attempts relied solely on data augmentation for noise, adding architectural dropout provides necessary regularization to prevent "Student 2" from simply memorizing the biases of "Student 1".
*   **Input Adaptation:** Use **Channel Replication** (grayscale to RGB) to preserve natural image statistics **Cite solution_lesson_node_00022**.

### Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Resolution:** Resize images to **256 pixels (Height) x 640 pixels (Width)**. This resolution preserves native frequency resolution **Cite solution_lesson_node_00013** and captures the fine-grained temporal morphology required for high performance **Cite solution_lesson_node_00041**. All models in the pipeline will operate at this resolution to prevent knowledge dilution **Cite solution_lesson_node_00036**.
    *   **Normalization:** Explicitly apply **ImageNet Mean and Standard Deviation normalization** to maintain the transfer learning contract **Cite solution_lesson_node_00045**.
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Implement purely dynamic in-memory loading without disk caching **Cite solution_lesson_node_00018**.
    *   **Deterministic Seeding:** Explicitly pass a fixed seed to the NumPy `default_rng()` generator within augmentation classes to prevent hidden variance **Cite solution_lesson_node_00043**.
*   **Augmentation (The "Noise"):**
    *   **Unstructured Cutout:** Random rectangular masks **Cite solution_lesson_node_00038**.
    *   **Horizontal Flip:** Random time inversion **Cite solution_lesson_node_00039**.
    *   **Conservative Mixup:** Alpha = 0.2 **Cite solution_lesson_node_00030**.

### Training
I will implement a **Three-Stage Multi-Generational Pipeline**. This is justified because the Student in Idea 11 (AUC 0.959) demonstrably outperformed its Teacher (AUC 0.93), satisfying the condition for iterative improvement **Cite solution_lesson_node_00054**.

1.  **Stage 1: Teacher Ensemble Training**
    *   Train **3 independent ResNet-34 models** (No Dropout in Head) on the labeled training set (Fold 0).
    *   **Schedule:** 50 epochs total. Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs **Cite solution_lesson_node_00028**.
    *   **Safety:** Disable Early Stopping during SWA **Cite solution_lesson_node_00050**.

2.  **Stage 2: Generation 1 Distillation (Ensemble $\to$ Student 1)**
    *   Generate predictions for the Test Set (Fold 1) using the Teacher Ensemble. Average the predictions.
    *   **Sanitize:** Assert no `NaN` values **Cite solution_lesson_node_00027**.
    *   Train **Student 1** (ResNet-34 **with Dropout**, Mixup, Cutout) on the Combined Dataset (Labeled + Pseudo-Labeled).
    *   **Schedule:** 50 epochs with SWA.

3.  **Stage 3: Generation 2 Distillation (Student 1 $\to$ Student 2)**
    *   Generate refined pseudo-labels for the Test Set using **Student 1** with **Test-Time Augmentation (TTA)** (Horizontal Flips).
    *   Train **Student 2** (ResNet-34 **with Dropout**, Mixup, Cutout) on the Combined Dataset using the refined targets. This generation allows the model to leverage the superior generalization of Student 1 to further denoise the test set labels.

### Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, apply **ImageNet Normalization**, and perform a single forward pass using the final **Student 2** model.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities.
