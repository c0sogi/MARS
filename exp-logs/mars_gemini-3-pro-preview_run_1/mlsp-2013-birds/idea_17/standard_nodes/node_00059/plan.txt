The training metadata inadvertently contains an extra column (`species_19`) due to upstream generation issues, while the generated pseudo-labels only contain the expected 19 columns (`species_0` to `species_18`). This mismatch causes the column selection to fail. To fix this, we must explicitly define the label columns using `Config.NUM_CLASSES` to ensure consistency.
