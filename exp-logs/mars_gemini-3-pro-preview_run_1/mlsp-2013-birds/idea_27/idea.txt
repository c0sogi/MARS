Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Calibrated High-Fidelity Homogeneous SWA-Distillation**.

This strategy introduces a structural innovation in the **Pseudo-Labeling Mechanism**: combining **Test-Time Augmentation (TTA)** with **Temperature Scaling** during the teacher inference phase. While previous attempts focused on model architecture or training regularization, this approach directly improves the *quality and calibration* of the distillation signal. By smoothing the teacher's probability distribution and averaging out variance via TTA, we provide the student with a richer, more robust "dark knowledge" signal, preventing overfitting to noisy high-confidence predictions. This is integrated into the proven ResNet-34 SWA pipeline, strictly adhering to the stability constraints identified in the lessons.

# Model
*   **Backbone:** Utilize the **Vanilla ResNet-34** architecture initialized with ImageNet weights.
    *   *Strategic Retention:* This backbone is retained as the optimal choice. It provides sufficient capacity for the dataset without the overfitting risks of larger models **Cite solution_lesson_node_00006** and avoids the suppression of co-occurring classes observed with SE-ResNet architectures in multi-label tasks **Cite solution_lesson_node_00056**.
    *   *Homogeneity:* Both Teachers and Student will use this identical architecture to ensure inductive bias alignment **Cite solution_lesson_node_00068**.
*   **Classification Head:** Use a standard **Linear Layer** projecting to the 19 species classes, strictly avoiding complex aggregation heads **Cite solution_lesson_node_00007** or structural noise like Dropout **Cite solution_lesson_node_00063**.
*   **Input Adaptation:** Use **Channel Replication** (copying the single-channel spectrogram to R, G, and B inputs) to preserve natural image statistics **Cite solution_lesson_node_00022**.

# Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Resolution:** Resize images to **256 pixels (Height) x 640 pixels (Width)**. This resolution strictly preserves the native frequency resolution **Cite solution_lesson_node_00013** and captures the fine-grained temporal morphology required for high performance **Cite solution_lesson_node_00041**. Crucially, all models will operate at this fixed resolution to prevent knowledge dilution **Cite solution_lesson_node_00036**.
    *   **Normalization:** Explicitly apply **ImageNet Mean and Standard Deviation normalization**. This is mandatory to uphold the transfer learning contract, correcting the failure of previous TTA attempts **Cite solution_lesson_node_00045**.
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Implement purely dynamic in-memory loading without disk caching to prevent stale data issues **Cite solution_lesson_node_00018**.
    *   **Deterministic Seeding:** Explicitly pass a fixed seed to the NumPy `default_rng()` generator within augmentation classes to prevent hidden variance **Cite solution_lesson_node_00043**.
*   **Augmentation:**
    *   **Unstructured Cutout:** Apply random rectangular masks instead of structured SpecAugment **Cite solution_lesson_node_00038**.
    *   **Horizontal Flip:** Enable random time inversion **Cite solution_lesson_node_00039**.
    *   **Conservative Mixup:** Apply **Input-Level Mixup** with **alpha = 0.2** **Cite solution_lesson_node_00030**.

# Training
I will implement a **Single-Stage Homogeneous Ensemble Distillation Pipeline** with extended schedules. I will explicitly avoid iterative distillation **Cite solution_lesson_node_00065**.

**Stage 1: Teacher Ensemble Training**
*   Train **3 independent ResNet-34 models** on the labeled training set (Fold 0).
*   **Schedule:** Train for **50 epochs** to ensure full convergence with Mixup **Cite solution_lesson_node_00044**.
*   **SWA Protocol:** Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs **Cite solution_lesson_node_00028**.
*   **Safety:** Explicitly disable Early Stopping during the SWA phase **Cite solution_lesson_node_00050**.
*   **Loss:** BCEWithLogitsLoss **Cite solution_lesson_node_00008**.

**Stage 2: Calibrated Pseudo-Label Generation (Structural Innovation)**
*   Generate predictions for the Test Set (Fold 1) using the 3 Teachers.
*   **Test-Time Augmentation (TTA):** For each image, generate predictions for both the original and **Horizontally Flipped** versions. Average these to reduce variance.
*   **Temperature Scaling:** Before applying the Sigmoid activation, divide the logits by a temperature factor **$T=1.5$**.
    *   *Rationale:* This softens the probability distribution, preventing the student from overfitting to overconfident teacher predictions and exposing more information about the inter-class relationships ("dark knowledge").
*   **Ensemble Averaging:** Average the calibrated, TTA-smoothed probabilities across the 3 teachers.
*   **Sanitize:** Assert no `NaN` values **Cite solution_lesson_node_00027**.

**Stage 3: Student Training**
*   Train a single **ResNet-34 Student** on the **Combined Dataset** (Labeled Train + Pseudo-Labeled Test).
*   **Targets:** Use hard ground truth for labeled data and the **Calibrated Soft Targets** for the test data.
*   **Schedule:** 50 epochs with SWA active in the final 30% **Cite solution_lesson_node_00029**.

# Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, apply **ImageNet Normalization**, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities. This leverages the finding that a single model trained on maximal data outperforms cross-validation ensembles **Cite solution_lesson_node_00012**.
