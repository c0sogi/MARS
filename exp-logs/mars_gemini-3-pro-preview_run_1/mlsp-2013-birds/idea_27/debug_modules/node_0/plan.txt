The following script demonstrates the usage of the provided library files. It performs the following steps:
1.  **Setup**: Sets random seeds for reproducibility and configures a logger.
2.  **Data Loading**: Initializes `BirdDataset` for training and validation. It subsets these datasets to a small number of samples (16) to ensure the demonstration runs quickly.
3.  **Model Initialization**: Instantiates the `BirdResNet` (ResNet34) model and verifies its output shape.
4.  **Training**: Sets up an optimizer and loss function, then initializes the `Trainer`. It runs a short training loop (2 epochs) with Stochastic Weight Averaging (SWA) enabled from epoch 1.
5.  **Inference (Teacher)**: Uses the trained model checkpoint to generate calibrated pseudo-labels for the test set.
6.  **Inference (Student)**: Uses the trained model checkpoint to generate the final submission file.
7.  **Validation**: Asserts that all output files (checkpoints, pseudo-labels, submission) are created correctly and contain the expected data dimensions.
