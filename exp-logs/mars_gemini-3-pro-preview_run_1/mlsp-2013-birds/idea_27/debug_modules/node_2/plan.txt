The issue is caused by the default strict security setting (`weights_only=True`) in `torch.load` on recent PyTorch versions, which rejects NumPy scalars (like the `auc` metric saved in the checkpoint) as "unsupported globals." To fix this, I will update `library/utils.py` to explicitly set `weights_only=False` when loading checkpoints, as we trust the source of these files (Cite {debug_lesson_8}). Additionally, I will modify `library/training.py` to cast the AUC metrics to native Python floats before saving, ensuring that future checkpoints do not contain unsupported NumPy types (Cite {debug_lesson_8}).
