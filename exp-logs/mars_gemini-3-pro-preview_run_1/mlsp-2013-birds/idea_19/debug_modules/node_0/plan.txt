The following implementation demonstrates the end-to-end usage of the provided library components. It covers data loading, model initialization, training loop execution (with SWA), checkpoint saving, and inference/submission generation.

To ensure speed and reliability within the demo environment:
1.  **Configuration Override**: We modify `Config` attributes at runtime to disable pretrained weight downloads (saving time/bandwidth), reduce epochs to 2, and set a small batch size.
2.  **Validation**: Assertions are used at each step to verify tensor shapes, data types, and file outputs.
3.  **Workflow**:
    *   **Data**: Verifies the `BirdDataset` and `DataLoader` correctly load images and labels.
    *   **Model**: Verifies the ResNet-34 architecture output dimensions.
    *   **Training**: Runs a minimal training session (`run_training`) to verify the loop, SWA integration, and checkpointing.
    *   **Inference**: Loads the saved checkpoint, runs predictions, and generates valid submission and pseudo-label files.
