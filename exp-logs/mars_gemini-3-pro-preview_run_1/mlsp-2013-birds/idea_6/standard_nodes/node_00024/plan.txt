2.  **Data Integrity**: I will remove the disk-based caching system (`.npy` files) and load data directly into memory. 3.  **Training Strategy**: I will simplify the training pipeline from a Teacher-Student distillation loop to a robust **Single-Stage Supervised** approach. The complexity of distillation is unnecessary given that a properly configured single ResNet34 has been shown to achieve >0.92 AUC.
4.  **Hyperparameters**: I will increase `MIXUP_ALPHA` from 0.2 to **0.4**. Lesson 00007 indicates this is the optimal sweet spot for regularization in this data regime, balancing signal fidelity with diversity. **(Cite solution_lesson_node_00007)**

    @staticmethod
    def compute_deltas(spec):
        """
        Computes the first and second temporal derivatives (deltas) of the spectrogram
        to create a 3-channel input.

        Args:
            spec (np.ndarray): Single channel spectrogram (H, W).

        Returns:
            np.ndarray: 3-channel image (H, W, 3) -> [Intensity, Delta, Delta-Delta].
        """
        # Ensure input is float
        spec = spec.astype(np.float32)

        # Channel 1: Intensity (Original)
        c1 = spec

        # Channel 2: Delta (First derivative along time axis / width)
        # axis 1 is width (time)
        c2 = np.gradient(spec, axis=1)

        # Channel 3: Delta-Delta (Second derivative)
        c3 = np.gradient(c2, axis=1)

        # Stack channels
        img_3c = np.stack([c1, c2, c3], axis=-1)

        return img_3c
