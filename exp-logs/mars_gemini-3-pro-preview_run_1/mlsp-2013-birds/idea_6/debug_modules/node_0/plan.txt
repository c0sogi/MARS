The following script demonstrates the usage of the provided library files for the bird species classification task. It performs the following steps:

1.  **Configuration Setup**: Modifies the default `Config` to run in a lightweight "Debug" mode (using a small subset of data) and redirects output to a demo directory.
2.  **Data Loading**: Uses `get_data_loaders` to process raw spectrograms, compute spectral deltas, and create PyTorch DataLoaders. It verifies the input shapes (Batch, 3, H, W).
3.  **Model Initialization**: Instantiates the `BirdResNet` model and performs a dummy forward pass to verify output dimensions.
4.  **Training Loop**: Runs a single epoch of training using `train_one_epoch` to demonstrate the optimization process and Mixup augmentation logic.
5.  **Validation**: Evaluates the model on the validation set using `validate` and checks the returned metrics (Loss, AUC).
6.  **Inference**: Generates predictions on the test set using `inference` and formats the results into the required submission DataFrame structure.
