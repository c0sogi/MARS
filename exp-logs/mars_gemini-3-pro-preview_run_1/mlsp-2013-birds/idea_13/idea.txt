Based on the comprehensive analysis of previous experiments and the specific "Lessons Learned," I propose the **Corrected Attentive High-Fidelity SWA-Distillation**.

This strategy is a structural evolution of the failed Idea 12. It retains the architectural innovation of **Squeeze-and-Excitation (SE) Attention** to address the "cocktail party" problem of overlapping calls but rigorously corrects the implementation failures—specifically the lack of input normalization (Cite solution_lesson_node_00045), under-training (Cite solution_lesson_node_00044), and non-deterministic augmentation (Cite solution_lesson_node_00043)—that caused the previous attempt to regress.

# Model
*   **Backbone (Structural Innovation):** Utilize the **SE-ResNet-34** (Squeeze-and-Excitation ResNet) architecture initialized with ImageNet weights.
    *   *Rationale:* While standard ResNet-34 is effective (Cite solution_lesson_node_00006), it treats all feature channels equally. The **SE blocks** explicitly model inter-dependencies between channels, adaptively recalibrating feature responses. This is critical for multi-label audio classification, allowing the model to suppress noise channels and focus on frequency bands containing specific bird calls.
*   **Head:** Employ a standard **Linear Layer** projecting to the 19 species classes, strictly avoiding complex aggregation heads to minimize overfitting (Cite solution_lesson_node_00007).

# Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Vertical Dimension:** Fix height at **256 pixels** to strictly preserve the native frequency resolution of the source spectrograms (Cite solution_lesson_node_00013).
    *   **Horizontal Dimension:** Fix width at **640 pixels**. This high-fidelity resolution captures fine-grained temporal morphology (Cite solution_lesson_node_00041). Crucially, both Teachers and Student must operate at this resolution to prevent knowledge dilution (Cite solution_lesson_node_00036).
    *   **Input Adaptation:** Use **Channel Replication** (grayscale to RGB) (Cite solution_lesson_node_00022).
    *   **Normalization (Critical Correction):** Explicitly apply **ImageNet Mean and Standard Deviation normalization**. Failing to do this in the previous attempt caused a massive distribution shift that negated the benefit of pretrained weights (Cite solution_lesson_node_00045).
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Use purely dynamic in-memory loading without disk caching (Cite solution_lesson_node_00018).
    *   **Deterministic Seeding:** Explicitly pass a fixed seed to the NumPy `default_rng()` generator within augmentation classes to prevent hidden variance (Cite solution_lesson_node_00043).
*   **Augmentation:**
    *   **Unstructured Cutout:** Apply random rectangular masks instead of structured SpecAugment to preserve partial features of short signals (Cite solution_lesson_node_00038).
    *   **Horizontal Flip:** Enable random time inversion to regularize the high-dimensional 640px input space (Cite solution_lesson_node_00039).
    *   **Conservative Mixup:** Apply Mixup with **alpha = 0.2** (Cite solution_lesson_node_00030).

# Training
I will implement a **Three-Stage Pipeline** with extended schedules to ensure convergence (Cite solution_lesson_node_00029):

1.  **Stage 1: Attentive Teacher Ensemble with SWA**
    *   Train **3 independent SE-ResNet-34 models** on the labeled training set (Fold 0).
    *   **Schedule (Correction):** Train for **50 epochs**. The previous attempt's 15-epoch schedule was insufficient for the model to learn effective representations with Mixup, creating "poisoned" teachers (Cite solution_lesson_node_00044).
    *   **SWA Protocol:** Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs to create robust teachers with flat loss minima (Cite solution_lesson_node_00028).
    *   **Loss:** Use **BCEWithLogitsLoss** (Cite solution_lesson_node_00008).

2.  **Stage 2: TTA-Enhanced Pseudo-Labeling**
    *   Generate predictions for the unlabeled Test Set (Fold 1) using the 3 SWA Teachers.
    *   **TTA Strategy:** Apply **Test-Time Augmentation** (Horizontal Flips) during inference. Average the standard and flipped predictions for each teacher, then average across the ensemble. This reduces the variance of the soft targets.
    *   **Sanitization:** Explicitly assert that merged targets contain no `NaN` values (Cite solution_lesson_node_00027).

3.  **Stage 3: Attentive Student with SWA**
    *   Train a single **SE-ResNet-34 Student** on the **Combined Dataset** (Labeled Train + Sanitized Pseudo-Labeled Test).
    *   **Input Resolution:** **256x640** (Matching Teachers).
    *   **Schedule:** Train for **50 epochs**, activating SWA for the final 30% of epochs (Cite solution_lesson_node_00029).

# Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, apply **ImageNet Normalization**, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities. This leverages the finding that a single model trained on maximal data outperforms cross-validation ensembles (Cite solution_lesson_node_00012).
