Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Anti-Aliased High-Fidelity ResNet-34d Distillation with SWA**.

This strategy introduces a structural innovation in the backbone architecture: **Anti-Aliased ResNet-34d**. This architecture explicitly addresses two critical signal processing challenges identified in the lessons: (1) the loss of transient details due to aggressive downsampling (addressed by the "Deep Stem") and (2) the lack of shift invariance in standard CNNs (addressed by "BlurPool"). This is integrated into the proven Single-Stage Ensemble Distillation pipeline, strictly adhering to the stability constraints (Homogeneity, Input Mixup, SWA) established in previous successful attempts.

# Model
*   **Backbone (Structural Innovation):** Utilize the **Anti-Aliased ResNet-34d** architecture (available via `timm` with `resnet34d` and `antialiased=True`).
    *   **Deep Stem (ResNet-D):** Standard ResNet-34 uses a 7x7 stride-2 convolution followed by Max Pooling, which aggressively downsamples the input by 4x immediately. This destroys fine-grained transient features (e.g., short chirps) critical for high-fidelity audio classification **Cite solution_lesson_node_00041**. The "Deep Stem" replaces this with three consecutive 3x3 convolutions, preserving the spectrotemporal morphology of the signal in the early layers.
    *   **Anti-Aliasing (BlurPool):** Standard strided convolutions and max pooling are not shift-invariant; a small shift in the input time series can drastically change the feature map. **BlurPool** inserts a low-pass filter before downsampling, enforcing shift invariance. This allows the model to be robust to small temporal jitters in bird calls without requiring the destructive geometric augmentations that failed in previous attempts **Cite solution_lesson_node_00072**.
    *   **Safety:** This architecture strictly avoids Global Channel Attention (SE blocks), preventing the suppression of co-occurring classes observed in multi-label tasks **Cite solution_lesson_node_00056**.
*   **Classification Head:** Use a standard **Linear Layer** projecting to the 19 species classes, strictly avoiding complex aggregation heads to minimize overfitting **Cite solution_lesson_node_00007**.
*   **Input Adaptation:** Use **Channel Replication** (copying the single-channel spectrogram to R, G, and B inputs) to preserve natural image statistics **Cite solution_lesson_node_00022**.

# Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Resolution:** Resize images to **256 pixels (Height) x 640 pixels (Width)**. This resolution strictly preserves the native frequency resolution **Cite solution_lesson_node_00013** and captures the fine-grained temporal morphology required for high performance **Cite solution_lesson_node_00041**. Crucially, all models (Teachers and Student) will operate at this fixed resolution to prevent knowledge dilution **Cite solution_lesson_node_00036**.
    *   **Normalization:** Explicitly apply **ImageNet Mean and Standard Deviation normalization**. This is mandatory to uphold the transfer learning contract **Cite solution_lesson_node_00045**.
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Implement purely dynamic in-memory loading without disk caching to prevent stale data issues **Cite solution_lesson_node_00018**.
    *   **Deterministic Seeding:** Explicitly pass a fixed seed to the NumPy `default_rng()` generator within augmentation classes to prevent hidden variance **Cite solution_lesson_node_00043**.
*   **Augmentation:**
    *   **Unstructured Cutout:** Apply random rectangular masks instead of structured SpecAugment **Cite solution_lesson_node_00038**.
    *   **Horizontal Flip:** Enable random time inversion **Cite solution_lesson_node_00039**.
    *   **Conservative Mixup:** Apply **Input-Level Mixup** with **alpha = 0.2** **Cite solution_lesson_node_00030**. Strictly avoid Manifold Mixup **Cite solution_lesson_node_00070**.

# Training
I will implement a **Single-Stage Homogeneous Ensemble Distillation Pipeline** with extended schedules. I will explicitly avoid iterative distillation to prevent error amplification **Cite solution_lesson_node_00065** and heterogeneous ensembles to prevent capacity misalignment **Cite solution_lesson_node_00068**.

1.  **Stage 1: Anti-Aliased Teacher Ensemble**
    *   Train **3 independent Anti-Aliased ResNet-34d models** on the labeled training set (Fold 0).
    *   **Schedule:** Train for **50 epochs** to ensure full convergence with Mixup **Cite solution_lesson_node_00044**.
    *   **SWA Protocol:** Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs **Cite solution_lesson_node_00028**.
    *   **Safety:** Explicitly disable Early Stopping during the SWA phase to prevent returning uninitialized models **Cite solution_lesson_node_00050**.
    *   **Loss:** BCEWithLogitsLoss **Cite solution_lesson_node_00008**.

2.  **Stage 2: Robust Pseudo-Label Generation**
    *   Generate predictions for the Test Set (Fold 1) using the 3 Teachers.
    *   **TTA:** Apply **Test-Time Augmentation** (Horizontal Flips) during inference and average the results.
    *   **Ensemble Averaging:** Average the predictions across the 3 teachers to create low-variance soft targets.
    *   **Sanitize:** Assert no `NaN` values **Cite solution_lesson_node_00027**.

3.  **Stage 3: Student Training**
    *   Train a single **Anti-Aliased ResNet-34d Student** on the **Combined Dataset** (Labeled Train + Pseudo-Labeled Test).
    *   **Schedule:** 50 epochs with SWA active in the final 30% **Cite solution_lesson_node_00029**.

# Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, apply **ImageNet Normalization**, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities. This leverages the finding that a single model trained on maximal data outperforms cross-validation ensembles **Cite solution_lesson_node_00012**.
