### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed for reproducibility and define working directories.
2.  **Data Loading Verification**:
    *   Use `create_dataloaders` to instantiate data loaders for training and testing.
    *   Fetch a single batch to verify the shape of images (Batch, Channels, Height, Width) and labels (Batch, NumClasses).
    *   Verify that the custom `BirdDataset` correctly handles image loading and transformation.
3.  **Model Instantiation Verification**:
    *   Initialize the `seresnet34` model using `get_seresnet_model`.
    *   Perform a forward pass with the dummy batch from the previous step to confirm the output shape matches `(Batch, NumClasses)`.
4.  **Pipeline Execution (Distillation Workflow)**:
    *   **Teacher Training**: Execute `train_teachers` with reduced hyperparameters (`num_teachers=1`, `epochs=1`) to demonstrate the training loop without consuming excessive time. Verify the checkpoint creation.
    *   **Pseudo-Label Generation**: Use the trained teacher to generate pseudo-labels for the test set via `generate_pseudo_labels`. Validate the structure and value range of the resulting DataFrame.
    *   **Student Training**: Execute `train_student` using the generated pseudo-labels, again with `epochs=1`. This verifies the semi-supervised learning capability (merging labeled train data with pseudo-labeled test data).
    *   **Submission Generation**: Use the trained student model to generate a submission file via `generate_submission`. Verify the output CSV format against the requirements.
