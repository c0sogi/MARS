The issue is caused by a breaking change in PyTorch 2.6+ where `torch.load` defaults to `weights_only=True`, restricting the types of objects that can be unpickled for security. The checkpoint file contains a NumPy scalar (the AUC score), which is not in the default allowlist, triggering a `_pickle.UnpicklingError`. To resolve this, I will explicitly set `weights_only=False` in the `torch.load` call within `library/utils.py`, as the checkpoints are generated locally and trusted. Cite {debug_lesson_10}
