2.  **Homogeneous Ensemble**: I will use a homogeneous ensemble of 3 ResNet34 models for the teachers. This matches the configuration of the best-performing solution so far (Idea 11).
3.  **Deterministic Mixup**: To address the variance and reproducibility issues noted in **Lesson 00043**, I will replace the `np.random.beta` call in the Mixup implementation with `torch.distributions.beta.Beta`. This ensures that the mixing coefficients are generated using the PyTorch random state, which is properly seeded by `seed_everything`, preventing hidden non-determinism.
