The following script demonstrates the usage of the provided library files for the bird species classification task. It outlines a complete workflow including configuration customization, data loading, model initialization, training, validation, SWA (Stochastic Weight Averaging), and pipeline execution.

To ensure the demonstration runs quickly and verifies correctness:
1.  **Configuration Override**: Key hyperparameters (image size, batch size, epochs) in `Config` are monkey-patched to reduce computational load.
2.  **Data Subsetting**: Only a small subset of the metadata is used.
3.  **Component Verification**: Each step (Dataset, Model, Engine, SWA) includes assertions to verify shapes, types, and logic.
4.  **Pipeline Execution**: The high-level pipeline functions are executed on the subset to demonstrate the full end-to-end process (Teacher training -> Pseudo-labeling -> Student SWA training -> Submission).
