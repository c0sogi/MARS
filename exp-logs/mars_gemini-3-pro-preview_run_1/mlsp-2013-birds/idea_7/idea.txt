Based on the comprehensive analysis of the "Lessons Learned" and the failures of previous semi-supervised attempts, I propose the **Ensemble-Distilled ResNet-34 with Densified Spectral Inputs**.

This strategy introduces a structural innovation—**Ensemble Knowledge Distillation**—to generate robust pseudo-labels for the unlabeled test data, addressing the critical data scarcity (Lesson 00012) while strictly adhering to the stability and signal fidelity constraints identified in previous experiments (Lessons 00010, 00013, 00015, 00018, 00022, 00025).

### Model
*   **Backbone:** Utilize the **ResNet-34** architecture initialized with ImageNet weights. This backbone provides the optimal balance of capacity and generalization for this dataset, outperforming both simpler MLPs (Cite solution_lesson_node_00006) and more complex architectures like EfficientNet (Cite solution_lesson_node_00015).
*   **Input Adaptation:** Explicitly use **Channel Replication** (copying the grayscale spectrogram to R, G, and B channels). This preserves the natural image statistics expected by the pretrained weights, avoiding the degradation caused by engineered "Delta" features (Cite solution_lesson_node_00022).
*   **Classification Head:** Employ a standard **Linear Layer** projecting to the 19 species classes. I will strictly avoid complex aggregation mechanisms like ConcatPooling, which have been shown to induce overfitting in this low-data regime (Cite solution_lesson_node_00007).

### Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (Densified Global Resize):**
    *   **Vertical Dimension:** Resize images to a fixed height of **256 pixels**. This preserves the native frequency resolution of the source files, preventing the loss of spectral details caused by downsampling to 224px (Cite solution_lesson_node_00013).
    *   **Horizontal Dimension:** Resize images to a fixed width of **512 pixels**. This "Global Resize" strategy ensures the model sees the entire 10-second context (Cite solution_lesson_node_00010) while acting as **feature densification**, making sparse signals easier to learn than in high-fidelity 1280px inputs (Cite solution_lesson_node_00015).
*   **Data Pipeline Integrity:** Implement **Dynamic In-Memory Loading** without persistent disk caching. This strictly prevents the "stale cache" data starvation issue that caused previous semi-supervised attempts to fail (Cite solution_lesson_node_00018).
*   **Augmentation:**
    *   **Conservative Mixup:** Apply Mixup with **alpha = 0.2** to ensure synthetic samples remain predominantly one class (Cite solution_lesson_node_00007).
    *   **SpecAugment:** Apply random time and frequency masking.

### Training
*   **Strategy (Structural Innovation):** Implement a **Three-Stage Ensemble Distillation Pipeline**.
    *   **Stage 1 (Teacher Ensemble):** Train **3 independent ResNet-34 models** on the full labeled training set (Fold 0) using different random seeds. This ensemble approach reduces the variance of the predictions compared to a single teacher, creating higher-quality targets for the student.
    *   **Stage 2 (Pseudo-Labeling):** Generate **soft pseudo-labels** for the unlabeled Test Set (Fold 1) by averaging the probability outputs of the 3 Teachers.
    *   **Stage 3 (Student Training):** Train a single, fresh ResNet-34 model (the Student) on the **Combined Dataset** (Labeled Train + Pseudo-Labeled Test).
*   **Optimization:**
    *   **Learning Rate:** Use a stable learning rate of **3e-4**. I will explicitly avoid aggressive rates (e.g., 1e-3) which caused optimization collapse in previous attempts (Cite solution_lesson_node_00025).
    *   **Loss Function:** Use **BCEWithLogitsLoss** for all stages. I will avoid Focal Loss as it degrades global AUC on small datasets (Cite solution_lesson_node_00008).
    *   **State Preservation:** Use `copy.deepcopy(model.state_dict())` to save the best model weights during Early Stopping, ensuring the checkpoint is immutable (Cite solution_lesson_node_00001).

### Evaluation
*   **Inference:** Preprocess test images to **256 x 512** (Height x Width), normalize, and perform a single forward pass using the **Stage 3 (Student)** model.
*   **Output:** Apply Sigmoid activation to the logits to generate the final probabilities.
