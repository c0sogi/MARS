Implementation Strategy:
1.  **Setup & Initialization**: Set random seeds for reproducibility and define the computation device (GPU/CPU). Suppress warnings to keep output clean.
2.  **Data Loading**: Load the pre-generated metadata for training, validation, and test sets using the provided library functions.
3.  **Stage 1 - Teacher Ensemble Training**: Train three independent `BirdResNet34` models on the labeled training set (Fold 0). Each model uses a different random seed to ensure diversity. Save the best state of each teacher model.
4.  **Stage 2 - Distillation**: Use the ensemble of trained teachers to generate soft pseudo-labels for the unlabeled test set (Fold 1). The predictions are averaged to create robust targets.
5.  **Stage 3 - Student Training**: Construct a combined dataset consisting of the original training data (with hard labels) and the pseudo-labeled test data (with soft labels). Train a final Student `BirdResNet34` model on this augmented dataset.
6.  **Validation**: Evaluate the trained Student model on the hold-out validation set to compute the final AUC score.
7.  **Failure Analysis**: specific failure analysis by calculating the correlation between the model's prediction error magnitude and the signal energy (mean pixel intensity) of the validation images.
8.  **Submission**: If the final validation AUC exceeds the specified threshold (0.9255...), generate predictions for the test set using the Student model and save the submission file in the required format.
