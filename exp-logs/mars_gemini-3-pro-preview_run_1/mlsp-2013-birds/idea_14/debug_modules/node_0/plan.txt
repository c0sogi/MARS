This script demonstrates the end-to-end usage of the provided library for the Bird Species Classification task. It covers data loading, model instantiation, training with SWA (Stochastic Weight Averaging), pseudo-label generation (distillation), and submission formatting.

To ensure rapid execution, the script dynamically overrides `Config` parameters to run in `DEBUG` mode with a tiny subset of data and minimal epochs. It verifies the logic at each step using assertions.
