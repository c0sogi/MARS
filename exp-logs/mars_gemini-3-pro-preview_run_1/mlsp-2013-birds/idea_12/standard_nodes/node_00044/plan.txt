The implementation strategy follows the "Attentive High-Fidelity SWA-Distillation" pipeline described in the idea.

1.  **Configuration & Setup**: Initialize the `Config` object, overriding epoch counts to ensure the script runs within the "fast baseline" time constraints (15 epochs for teachers, 20 for student). Set random seeds for reproducibility.
2.  **Stage 1: Teacher Ensemble Training**: Train 3 independent SE-ResNet-34 models on the labeled training set. Use Stochastic Weight Averaging (SWA) for the latter part of training. After training, update Batch Normalization statistics and save the models.
3.  **Stage 2: Pseudo-Labeling**: Use the ensemble of SWA Teachers to predict labels for the test set. Apply Test-Time Augmentation (TTA) with horizontal flips. Sanitize the predictions and save them as a Parquet file for the student.
4.  **Stage 3: Student Training**: Train a single SE-ResNet-34 Student model on the combined dataset (labeled train + pseudo-labeled test). Apply SWA and update BN statistics.
5.  **Validation & Failure Analysis**: Evaluate the final Student SWA model on the hold-out validation set. Calculate the ROC AUC score. Perform failure analysis by computing the correlation between sample-wise loss and image signal intensity (mean pixel value) to identify potential biases.
6.  **Submission**: If the validation ROC AUC exceeds the specified threshold (0.959408...), generate predictions for the test set using the Student model with TTA and save the submission file.
