This script implements the **Manifold-Regularized High-Fidelity SWA-Distillation** pipeline. It proceeds in three stages:
1.  **Teacher Ensemble:** Trains 3 independent ResNet-34 models on the labeled training set using Manifold Mixup and Stochastic Weight Averaging (SWA).
2.  **Pseudo-Labeling:** Generates robust soft-labels for the test set by averaging predictions from the teacher ensemble with Test-Time Augmentation (TTA).
3.  **Student Distillation:** Trains a final Student model on the combined dataset (Labeled Train + Pseudo-Labeled Test) using the same regularization techniques, followed by validation and submission generation.
