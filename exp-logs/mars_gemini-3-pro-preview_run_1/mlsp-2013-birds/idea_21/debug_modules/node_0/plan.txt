### Implementation Strategy

1.  **Initialization**: Set random seeds for reproducibility using `library.utils.set_seed`. Initialize the `Config` class in debug mode to ensure the script runs quickly with reduced dataset sizes and epochs.
2.  **Data Loading**: Use `library.dataset.get_dataloaders` to load the training, validation, and test data. Verify the integrity of the data loaders by checking batch shapes (images, targets, IDs) and ensuring the image dimensions match the configuration.
3.  **Model Instantiation**: Create an instance of `ManifoldMixupResNet` from `library.model`. Verify the model architecture by performing a standard forward pass and a mixup forward pass, ensuring the output shapes and return types are correct.
4.  **Training & Validation**:
    *   Execute `library.engine.train_one_epoch` to simulate a training epoch, checking that the loss is returned correctly.
    *   Test the Manifold Mixup functionality within the training loop.
    *   Run `library.engine.validate` to evaluate the model, asserting that valid loss and ROC AUC scores are computed.
5.  **SWA & Inference**:
    *   Demonstrate Stochastic Weight Averaging (SWA) utility by running `library.engine.update_bn` to update Batch Normalization statistics.
    *   Generate predictions using `library.engine.generate_predictions` with Test-Time Augmentation (TTA), verifying the output format and probability values.
6.  **Utilities**: Test helper functions in `library.utils`, specifically `compute_roc_auc` for metric calculation and `save_checkpoint`/`load_checkpoint` to verify model persistence logic.
