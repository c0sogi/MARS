### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` with `debug=False` to ensure the model trains on the full dataset (which is small enough for rapid training) to meet the high performance threshold. Set global random seeds for reproducibility.
2.  **Stage 1 (Teacher Ensemble)**: Train 3 independent `BirdResNet` (ResNet-34) models on the labeled training set. Each teacher utilizes Stochastic Weight Averaging (SWA) for robustness. After training, generate predictions on the test set for each teacher.
3.  **Stage 2 (Pseudo-Labeling)**: Aggregate the predictions from the 3 teachers by averaging them to create soft pseudo-labels. Sanitize these labels to ensure no NaNs are present before passing them to the student.
4.  **Stage 3 (Student Distillation)**: Train a single `BirdResNet` Student model on the combined dataset (Labeled Train + Pseudo-Labeled Test). The student also uses SWA and is trained at the high-fidelity resolution (256x640) to match the teachers' capacity.
5.  **Evaluation**: Evaluate the final Student model on the hold-out validation set. Print the `Final Validation Metric` (AUC) as required.
6.  **Failure Analysis**: Perform inference on the validation set to calculate the Mean Absolute Error (MAE) per sample. Compute and print the Pearson correlation between the error magnitude and the image mean intensity to analyze if signal brightness relates to model failure.
7.  **Submission**: Check if the validation AUC exceeds the strict threshold of `0.9433543480067271`. If successful, generate the `submission.csv` using the Student model on the test set.
