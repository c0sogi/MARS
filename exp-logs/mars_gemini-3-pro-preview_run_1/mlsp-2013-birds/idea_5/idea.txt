Based on the lessons learned from previous iterations, I propose a **Semi-Supervised ResNet-34 with Densified Spectrograms**. This strategy addresses the primary bottleneck identified in Lesson 00012 (extreme data scarcity) by implementing a multi-stage self-training pipeline to leverage the unlabeled test data, while strictly adhering to the signal fidelity constraints identified in Lessons 00010, 00013, and 00015.

# Model
*   **Backbone:** Utilize a **ResNet-34** architecture initialized with ImageNet weights. This backbone provides a balance of capacity and regularizability that outperformed both shallower MLPs (Cite Lesson 00006) and deeper/complex architectures like EfficientNet with GeM pooling (Cite Lesson 00015) in this specific domain.
*   **Pooling & Head:** Employ standard **Global Average Pooling** followed by a simple **Linear Classification Head** projecting to the 19 species classes. I will explicitly avoid complex aggregation heads (like ConcatPooling), which were shown to degrade performance by increasing overfitting risks in this low-data regime (Cite Lesson 00007).

# Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (Densified Global Resize):**
    *   **Vertical Dimension:** Resize images to a fixed height of **256 pixels**. This strictly preserves the native frequency bin resolution of the source spectrograms, avoiding the interpolation artifacts caused by resizing to standard 224px dimensions (Cite Lesson 00013).
    *   **Horizontal Dimension:** Resize images to a fixed width of **512 pixels**. This "Global Resize" strategy ensures the model sees the entire 10-second context (Cite Lesson 00010). Furthermore, this specific resolution acts as **feature densification**, compressing the sparse bird call signals into a denser representation that is easier for the model to learn compared to high-fidelity 1280px inputs (Cite Lesson 00015).
    *   **Channel Adaptation:** Replicate the single-channel spectrogram to 3 channels to match the backbone's input expectation.
*   **Augmentation:**
    *   **Conservative Mixup:** Apply Mixup with **alpha = 0.2**. This ensures synthetic samples remain predominantly one class, preserving the distinct features necessary for learning from few examples (Cite Lesson 00007).
    *   **SpecAugment:** Apply random time and frequency masking to encourage robustness.

# Training
*   **Strategy (Structural Innovation):** Implement a **Two-Stage Self-Training (Semi-Supervised)** pipeline to address the micro-data limitation (Cite Lesson 00012).
    *   **Stage 1 (Teacher):** Train a ResNet-34 model on the labeled training set (Fold 0) using **BCEWithLogitsLoss** (Cite Lesson 00008). Use **AdamW** with Cosine Annealing. Implement Early Stopping based on validation AUC, ensuring to use `copy.deepcopy(model.state_dict())` to preserve the immutable best state (Cite Lesson 00001).
    *   **Stage 2 (Student):** Use the best Stage 1 model to generate **soft pseudo-labels** (probability outputs) for the unlabeled Test Set (Fold 1).
    *   **Stage 3 (Retraining):** Train a fresh ResNet-34 model (Student) on the **combined dataset** (Labeled Train + Pseudo-Labeled Test). For the labeled data, use ground truth labels; for the test data, use the Teacher's soft predictions as targets. This effectively expands the training volume, allowing the model to learn the manifold of the test distribution.
*   **Loss Function:** Standard **BCEWithLogitsLoss** for both stages. I will avoid Focal Loss as it was shown to degrade global AUC by suppressing the stable training signal from "easy" examples (Cite Lesson 00008).

# Evaluation
*   **Inference:** Resize test spectrograms to **256 x 512** (Height x Width), normalize, and perform a single forward pass using the Stage 3 (Student) model.
*   **Output:** Apply a Sigmoid activation to the logits to generate probabilities for the submission.
