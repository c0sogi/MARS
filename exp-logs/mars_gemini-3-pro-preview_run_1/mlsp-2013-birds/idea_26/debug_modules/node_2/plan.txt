The issue is caused by the `BirdDataset` class using implicit pattern matching (`startswith("species_")`) to identify label columns. The metadata generation script inadvertently created 20 label columns (including an artifact `species_19`) because the `species_list.txt` contained 20 lines, whereas the task and model configuration expect only 19 classes. This results in a shape mismatch during training (`torch.Size([2, 20])` vs expected 19). To fix this, I will modify `BirdDataset.__init__` in `library/data.py` to explicitly construct the list of label columns (`species_0` to `species_18`) based on the `num_classes` defined in the trusted `Config` object, as recommended in **debug_lesson_1**.
