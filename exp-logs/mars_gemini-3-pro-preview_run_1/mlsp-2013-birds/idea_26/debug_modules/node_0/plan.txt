The following script demonstrates the usage of the provided library files to execute the bird species classification pipeline. It performs the following steps:

1.  **Initialization**: Sets up the environment and configuration in `DEBUG` mode to ensure fast execution with a small subset of data.
2.  **Data Verification**: Loads the datasets and verifies that the data shapes (images and labels) are correct.
3.  **Model Verification**: Instantiates the ResNet-34d model and performs a forward pass to confirm the output dimensions.
4.  **Component Verification**: Tests the `Mixup` augmentation and `SWAEngine` logic.
5.  **Full Pipeline Execution**: Runs the complete Knowledge Distillation pipeline (Training Teachers -> Generating Pseudo-Labels -> Training Student -> Inference) using the `run_pipeline` function.
6.  **Output Validation**: Asserts that the final submission file and model checkpoints are generated correctly.
