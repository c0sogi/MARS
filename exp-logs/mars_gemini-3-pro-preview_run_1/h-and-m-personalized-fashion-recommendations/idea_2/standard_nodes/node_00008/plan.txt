Implementation Strategy:
The solution implements a Two-Stage Recommender System. 
1.  **Data Loading**: Utilizes the provided `DataLoader` to load transactions and metadata, processing them into a temporal format with a 'week' index (0 = most recent).
2.  **Training (Week 1)**: 
    *   **Candidate Generation**: Generates candidates for a subset of customers (50k) active in Week 1 using history from Week > 1. Strategies include Repurchase, Popularity, and ItemCF.
    *   **Feature Engineering**: Enriches candidates with user stats, item recency, and category recency features using `FeatureFactory`.
    *   **Ranking**: Trains a LightGBM Ranker (`lambdarank`) to re-order candidates based on purchase probability.
3.  **Validation (Week 0)**:
    *   Applies the pipeline to all customers active in Week 0 (Validation set).
    *   Computes the **MAP@12** metric by comparing top-12 ranked predictions against actual Week 0 purchases.
    *   Performs failure analysis by correlating prediction errors with input features.
4.  **Submission (Test)**:
    *   If the validation metric exceeds the threshold, generates candidates for all test customers using full history (Week >= 0).
    *   Predicts scores, selects top-12 items, and generates the submission file in the required format.
