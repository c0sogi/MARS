This implementation demonstrates a complete recommendation pipeline using the provided library files. It follows a standard time-split strategy:
1.  **Data Loading**: Loads transactions and metadata, computing the `week` column for temporal splitting.
2.  **Training Set Construction (Week 1)**: Generates candidates and features for a subset of customers active in Week 1, using history from Week > 1.
3.  **Validation Set Construction (Week 0)**: Generates candidates and features for a subset of customers active in Week 0 (the most recent week), using history from Week > 0.
4.  **Model Training**: Trains a LightGBM Ranker to rank candidates by relevance (purchased or not).
5.  **Evaluation**: Calculates MAP@12 on the validation set to verify model performance.
6.  **Inference (Test)**: Generates predictions for a sample of the test set using all available history.

The code uses aggressive sampling (subsetting customers) and reduced model iterations to ensure it executes quickly within the demonstration environment.
