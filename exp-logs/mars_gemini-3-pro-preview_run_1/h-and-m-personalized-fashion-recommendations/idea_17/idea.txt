Based on the comprehensive analysis of the "Lessons Learned" and the specific failure modes of previous experiments—particularly the tension between "Long-Tail Structure" (Lesson 00012) and "Concept Drift" (Lesson 00007), and the failure of "Hard Filters" (Lesson 00039)—I propose the **Trend-Modulated Vectorized Cascade (TMVC)**.

This solution introduces a structural innovation by **decoupling Item Similarity from Item Velocity**. Instead of forcing a single time window to capture both stable relationships and current trends, or applying hard filters that destroy recall, we explicitly modulate the Collaborative Filtering signal with a continuous "Soft Trend" mask. This allows the model to leverage deep historical data to learn robust item-to-item structures while mathematically suppressing candidates that are no longer active in the current market, all within a strictly prioritized vectorized cascade.

### Model
The architecture is a **Three-Stage Stratified Retrieval System** implemented via vectorized sparse linear algebra. It generates a single unified score vector $R_u$ for each user, utilizing disjoint numerical ranges to enforce a strict priority hierarchy: **Habit > Trend-Modulated CF > Global Trend**.

1.  **Stratum 1: Habitual Repurchase (The "Priors" Layer)**
    *   **Logic:** Users are overwhelmingly likely to rebuy items purchased recently. **Cite {solution_lesson_node_00002}**.
    *   **Mechanism:** Retrieve the user's full history vector $U_{hist}$. Apply strict temporal decay ($w = 1 / \text{days\_elapsed}$).
    *   **Stratification:** Scores are shifted to the range $[2000, \infty)$. This ensures explicit history *always* outranks inferred similarity, strictly adhering to the "Cascade > Ensemble" principle. **Cite {solution_lesson_node_00016}**.

2.  **Stratum 2: Trend-Modulated Collaborative Filtering (The "Discovery" Layer)**
    *   **Structural Innovation (Decoupled Modulation):**
        *   **Structure Learning ($S_{decay}$):** We construct the Similarity Matrix using a **16-week** window with **Continuous Time-Decay**. This deep window captures the "Long Tail" of item correlations (e.g., specific pants that go with a specific top) that are lost in shorter windows. **Cite {solution_lesson_node_00012}**.
        *   **Velocity Modulation ($V_{trend}$):** We compute a "Soft Trend" vector based on the sales volume of items in the **Last 1 Week**. $V_i = \log(1 + \text{count}_i)$.
        *   **Fusion Logic:** The raw CF score ($U \times S$) represents "theoretical relevance." We element-wise multiply this by the velocity vector: $R_{cf} = (U_{intent} \times S_{decay}) \odot V_{trend}$.
        *   **Why:** This effectively "projects" the latent desires learned from the 16-week graph onto the currently active market. Unlike the "Hard Filter" in Idea 15 which zeroed out valid candidates (**Cite {solution_lesson_node_00039}**), this "Soft Mask" simply down-weights obsolete items while preserving strong signals for niche items that are still selling (even if slowly).
    *   **User Query ($U_{intent}$):** Constructed using **Full History** with **Aggressive Decay** ($1/t$). This resolves the failure of Idea 14 where hard truncation of user history destroyed the query signal. **Cite {solution_lesson_node_00037}**.
    *   **Normalization:** $S_{decay}$ is built using **Row-wise (User) Normalization** (**Cite {solution_lesson_node_00004}**) and **IDF Weighting** (**Cite {solution_lesson_node_00011}**).
    *   **Stratification:** Scores are normalized and scaled to the range $[100, 1000]$.

3.  **Stratum 3: Global Trend (The "Fallback" Layer)**
    *   **Logic:** Time-decayed sales velocity for cold-start users.
    *   **Stratification:** Scores are scaled to $[0, 10]$.

**Final Aggregation:**
$$ R_{total} = R_{rep} + R_{cf} + R_{trend} $$

### Data
1.  **Temporal Windowing:**
    *   **Structure Window:** Last 16 weeks (for $S_{decay}$).
    *   **Velocity Window:** Last 1 week (for $V_{trend}$).
    *   **Query Window:** Full History (for $U_{intent}$).
2.  **Validation Strategy:**
    *   **Time-Based Split:** Train on interactions up to Week $T-1$, Validate on Week $T$. This ensures the model has access to the user history required for Strata 1 and 2, rectifying the failure of User-Group splitting. **Cite {solution_lesson_node_00026}**.
3.  **Precision:**
    *   Use **float32** for all matrix accumulators. This prevents the numerical overflow issues observed when using `float16` with stratified offsets. **Cite {solution_lesson_node_00010}**.
4.  **Exclusion:**
    *   Explicitly exclude Visual Embeddings (**Cite {solution_lesson_node_00020}**) and Metadata Hybridization (**Cite {solution_lesson_node_00027}**) to maintain behavioral signal purity.

### Training
Since this is a memory-based heuristic model, "training" is the efficient construction of the sparse matrices:
1.  **Interaction Matrix:** Construct sparse $X_{decay}$ from the 16-week window using continuous decay weights ($1/\sqrt{t}$).
2.  **Normalization:** Apply IDF to columns and L2 normalization to rows (Users).
3.  **Similarity:** Compute $S_{decay} = X_{decay}^T X_{decay}$ via sparse matrix multiplication. Prune to top-100 neighbors.
4.  **Velocity Vector:** Compute $V_{trend}$ from the last week's transaction counts.

### Evaluation
1.  **Vectorized Inference:**
    *   Construct sparse $U_{intent}$ for test users.
    *   Compute $R_{raw} = U_{intent} \times S_{decay}$ (**Cite {solution_lesson_node_00012}**).
    *   Apply Modulation: $R_{mod} = R_{raw} \odot V_{trend}$.
2.  **Retrieval Strategy:**
    *   Employ the **Mask-and-Partition** technique: Densify the score vector, mask history items (unless Repurchase score overrides), and use `np.argpartition` to select top 12 items in linear time. **Cite {solution_lesson_node_00013}**.
