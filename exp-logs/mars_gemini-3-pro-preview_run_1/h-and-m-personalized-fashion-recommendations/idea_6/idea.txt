Based on the comprehensive analysis of the "Lessons Learned" and the failure modes of previous experiments (specifically the limitations of Visual Similarity and Learning-to-Rank), I propose the **Stratified Directional-Cohort Cascade (SDCC)**.

This solution introduces two structural innovations: **Directional Collaborative Filtering** (evolving the behavioral graph from undirected to directed to explicitly model "next-item" transitions) and **Demographic Trend Stratification** (replacing the generic global fallback with age-segmented popularity). It integrates these into the proven vectorized stratified framework.

### Model
The architecture is a **Four-Stage Stratified Retrieval System** that generates a unified score vector $R_u$ for each user. It strictly enforces the "Cascade" logic (Cite {solution_lesson_node_00016}) by mapping signal sources to disjoint score ranges, ensuring high-precision priors always outrank lower-precision fallbacks.

1.  **Stratum 1: Habitual Repurchase (The "Priors" Layer)**
    *   **Logic:** Users are most likely to rebuy what they recently bought.
    *   **Mechanism:** Retrieve user history from the training window. Score items using strict temporal decay ($1 / \text{days\_elapsed}$).
    *   **Stratification:** Scores are shifted to the range $[1000, \infty)$. This preserves the strong baseline performance (Cite {solution_lesson_node_00002}).

2.  **Stratum 2: Directional Behavioral CF (The "Discovery" Layer)**
    *   **Innovation:** We refine the Item-Item Collaborative Filtering by constructing a **Hybrid Directional Matrix** $S_{hybrid}$.
    *   **Matrix Construction:** $S_{hybrid} = S_{sym} + \lambda \cdot S_{fwd}$.
        *   **$S_{sym}$ (Symmetric):** The standard co-occurrence matrix ($X^T X$) capturing items bought in the same basket or time window. Constructed using **Row-wise (User) Normalization** (Cite {solution_lesson_node_00004}) and **IDF Weighting** (Cite {solution_lesson_node_00011}).
        *   **$S_{fwd}$ (Forward Transition):** A directed sparse matrix where $S_{ij}$ represents the frequency of users buying item $j$ *after* item $i$. This explicitly models the "Next-Item" prediction task, addressing the limitation of purely symmetric CF which treats baskets as unordered bags.
    *   **Inference:** Vectorized multiplication $R_{cf} = U_{decayed} \times S_{hybrid}$. The user vector $U_{decayed}$ weights seed items by recency (Cite {solution_lesson_node_00005}).
    *   **Stratification:** Scores are normalized and scaled to $[100, 900]$. This allows behavioral signals to rank high but never override explicit history.

3.  **Stratum 3: Cohort-Based Trend (The "Segmented" Layer)**
    *   **Innovation:** Instead of falling back immediately to Global Trends (which ignores user context), we implement **Demographic Popularity**.
    *   **Mechanism:** Users are mapped to **Age Bins** (e.g., 18-25, 26-35, etc.) based on `customers.csv`. For each bin, we calculate a separate time-decayed popularity vector.
    *   **Logic:** This provides a personalized fallback for "Cold Start" users (who have no history in the window) by recommending trends specific to their peer group, avoiding the noise of irrelevant global bestsellers.
    *   **Stratification:** Scores are scaled to $[10, 90]$.

4.  **Stratum 4: Global Trend (The "Universal" Layer)**
    *   **Logic:** The final fallback for users with missing metadata and no history.
    *   **Stratification:** Scores are scaled to $[0, 9]$.

### Data
1.  **Temporal Windowing:**
    *   Restrict training data to the **last 5 weeks**. This adheres to the "Recency over Volume" principle (Cite {solution_lesson_node_00007}) to minimize concept drift.
2.  **Precision:**
    *   Use **float32** for all matrix accumulators. This prevents the numerical overflow issues observed when using `float16` with stratified offsets (Cite {solution_lesson_node_00010}).
3.  **Preprocessing:**
    *   **Age Binning:** Discretize `age` from `customers.csv` into 10-year intervals.
    *   **Transition Pairs:** Process transactions to generate pairs $(i, j)$ where $t_{purchase}(j) > t_{purchase}(i)$ for the same user to build $S_{fwd}$.

### Training
Since this is a memory-based heuristic model, "training" is the efficient construction of the sparse matrices:
1.  **Symmetric Matrix:** Compute $S_{sym} = X_{norm}^T X_{norm}$ with IDF weighting.
2.  **Forward Matrix:** Construct $S_{fwd}$ by counting directed transitions. Normalize columns to unit probability.
3.  **Cohort Aggregation:** Group transactions by User Age Bin and compute decayed popularity counts for each group.

### Evaluation
1.  **Vectorized Inference:**
    *   Generate predictions using **Vectorized Sparse Matrix Multiplication** ($R = U \times S$). This captures the "long tail" of similarity signals (Cite {solution_lesson_node_00012}).
2.  **Retrieval Strategy:**
    *   Employ the **Mask-and-Partition** technique (Cite {solution_lesson_node_00013}):
        1.  Compute the dense stratified score vector $R_u$.
        2.  Use `np.argpartition` to select the top 12 indices in linear time.
        3.  Sort the top 12 items.
    *   This avoids the overhead of sorting the entire vocabulary.
