Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Reproducibility**: Import necessary libraries and the provided modules (`library.config`, `library.smdc_model`, `library.metrics`). Set a fixed random seed for reproducibility.
2.  **Validation Phase**:
    *   Initialize the `SMDCRecommender`.
    *   Call `fit(validate=True)` to load data and build matrices using the validation split (Train: T-5w to T-1w, Test: T).
    *   Generate predictions for the validation set users.
    *   Compute the MAP@12 score using the provided `library.metrics` module.
    *   Print the metric in the strictly required format: `Final Validation Metric: <value>`.
3.  **Failure Analysis**:
    *   Calculate the Average Precision (AP) for each user individually.
    *   Merge these scores with customer metadata (Age) and behavioral features (History Length derived from the training transactions).
    *   Compute and print Pearson correlations between the AP scores and these features to identify error patterns (e.g., does the model fail on older users or cold-start users?).
4.  **Submission Phase**:
    *   Check if the validation MAP@12 exceeds the threshold (0.0265060791).
    *   If passed, re-initialize the `SMDCRecommender` and call `fit(validate=False)` to retrain on the full dataset (Train: T-5w to T).
    *   Generate the final submission file at `./submission/submission.csv` using `generate_submission()`.
