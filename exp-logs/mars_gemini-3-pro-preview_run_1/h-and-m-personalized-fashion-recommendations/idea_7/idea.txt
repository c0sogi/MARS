Based on the comprehensive analysis of previous experiments and the "Lessons Learned," I propose the **Stratified Metadata-Densified Cascade (SMDC)**.

This solution represents a structural evolution of the "Stratified Cascade" architecture. It addresses the limitations of previous iterations by replacing the noisy "Visual Similarity" layer with a high-precision **Metadata Densification** layer and replacing the generic "Global Trend" fallback with **Cohort-Based Trends**. Crucially, it rectifies the validation methodology to ensure history-based signals are correctly evaluated.

### Model
The architecture is a **Four-Stage Stratified Retrieval System** that generates a unified score vector $R_u$ for each user. It strictly enforces the "Cascade" logic (Cite {solution_lesson_node_00016}) by mapping signal sources to disjoint numerical ranges. This ensures that high-confidence priors (like Repurchase) always outrank discovery signals (like CF), which in turn outrank generic fallbacks.

1.  **Stratum 1: Habitual Repurchase (The "Priors" Layer)**
    *   **Logic:** Users are most likely to rebuy what they recently bought.
    *   **Mechanism:** Retrieve user history from the training window. Score items using strict temporal decay ($1 / \text{days\_elapsed}$).
    *   **Stratification:** Scores are shifted to the range $[1000, \infty)$. This preserves the strong baseline performance (Cite {solution_lesson_node_00002}).

2.  **Stratum 2: Densified Collaborative Filtering (The "Discovery" Layer)**
    *   **Innovation:** We construct a **Hybrid Similarity Matrix** $S_{hybrid}$ that fuses behavioral co-occurrence with explicit metadata relationships.
    *   **Matrix Construction:** $S_{hybrid} = S_{behavior} + \lambda \cdot S_{variant}$.
        *   **$S_{behavior}$:** The standard Item-Item co-occurrence matrix ($X^T X$). It is constructed using **Row-wise (User) Normalization** to mitigate power-user bias (Cite {solution_lesson_node_00004}) and **IDF Weighting** to penalize globally popular items (Cite {solution_lesson_node_00011}).
        *   **$S_{variant}$:** A sparse binary adjacency matrix where $S_{ij}=1$ if item $i$ and item $j$ share the same `product_code` (i.e., they are different colorways of the same product). This "densifies" the graph, allowing the model to recommend high-precision substitutes (e.g., White T-Shirt for Black T-Shirt) without the noise introduced by visual embeddings (Cite {solution_lesson_node_00020}).
    *   **Inference:** Vectorized multiplication $R_{cf} = U_{decayed} \times S_{hybrid}$. The user vector $U_{decayed}$ weights seed items by their recency (Cite {solution_lesson_node_00005}).
    *   **Stratification:** Scores are normalized and scaled to the range $[100, 900]$.

3.  **Stratum 3: Cohort-Based Trend (The "Segmented" Layer)**
    *   **Innovation:** Instead of falling back immediately to Global Trends, we implement **Demographic Popularity**.
    *   **Mechanism:** Users are mapped to **Age Bins** (e.g., 18-25, 26-35) based on `customers.csv`. For each bin, we calculate a separate time-decayed popularity vector.
    *   **Logic:** This provides a personalized fallback for "Cold Start" users by recommending trends specific to their peer group.
    *   **Stratification:** Scores are scaled to $[10, 90]$.

4.  **Stratum 4: Global Trend (The "Universal" Layer)**
    *   **Logic:** The final fallback for users with missing metadata and no history.
    *   **Stratification:** Scores are scaled to $[0, 9]$.

### Data
1.  **Temporal Windowing:**
    *   Restrict training data to the **last 5 weeks** of transactions. This adheres to the "Recency over Volume" principle (Cite {solution_lesson_node_00007}) to minimize concept drift.
2.  **Validation Strategy:**
    *   **Time-Based Split:** We will train on Weeks $T-5$ to $T-1$ and validate on Week $T$. This rectifies the critical failure of the "User Group Split" (Cite {solution_lesson_node_00026}), ensuring the model has access to the user history required for Strata 1 and 2.
3.  **Precision:**
    *   Use **float32** for all matrix accumulators and score calculations. This prevents the numerical overflow issues observed when using `float16` with stratified offsets (Cite {solution_lesson_node_00010}).
4.  **Preprocessing:**
    *   **Variant Matrix:** Group `articles.csv` by `product_code` to build $S_{variant}$.
    *   **Age Binning:** Discretize `age` into 10-year intervals.

### Training
Since this is a memory-based heuristic model, "training" is the efficient construction of the sparse matrices:
1.  **Behavioral Matrix:** Compute $S_{behavior} = X_{norm}^T X_{norm}$ with IDF weighting.
2.  **Variant Matrix:** Construct $S_{variant}$ from metadata.
3.  **Hybrid Fusion:** Compute $S_{hybrid} = S_{behavior} + 0.1 \cdot S_{variant}$. The scalar $\lambda=0.1$ ensures that actual co-occurrence (stronger signal) dominates, but product identity provides coverage where co-occurrence is missing.
4.  **Cohort Aggregation:** Group transactions by User Age Bin and compute decayed popularity counts.

### Evaluation
1.  **Vectorized Inference:**
    *   Generate predictions using **Vectorized Sparse Matrix Multiplication** ($R = U \times S$). This captures the "long tail" of similarity signals (Cite {solution_lesson_node_00012}).
2.  **Retrieval Strategy:**
    *   Employ the **Mask-and-Partition** technique (Cite {solution_lesson_node_00013}):
        1.  Compute the dense stratified score vector $R_u$.
        2.  Use `np.argpartition` to select the top 12 indices in linear time.
        3.  Sort the top 12 items to produce the final ranked list.
