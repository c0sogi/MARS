To demonstrate the functionality of the provided library files while adhering to the time and resource constraints, I will implement a script that first generates a small, synthetic dataset within the `./working` directory. I will then monkey-patch the `Config` class to point to this synthetic data directory. This allows the complex pipelines (Data Loading, Matrix Construction, Trend Calculation, and Inference) to execute quickly and verify the logic without processing the full 30GB+ dataset.

The script will proceed through the following steps:
1.  **Setup**: Configure paths and generate mock `transactions`, `articles`, `customers`, and `sample_submission` files.
2.  **Data Management**: Demonstrate `DataManager` to load and split data, verifying the `Indexer` logic.
3.  **Similarity Engine**: Use `SimilarityEngine` to build User-Item (`U`) and Hybrid Similarity (`S_hybrid`) matrices, checking dimensions and sparsity.
4.  **Trend Engine**: Use `TrendEngine` to calculate Global and Cohort-based trends.
5.  **Full Model Pipeline**: Instantiate `SMDCRecommender`, fit the model (which orchestrates the engines), and generate a submission.
6.  **Metrics**: Validate the `calculate_map12` function with known ground truth examples.
