The implementation strategy follows the requirements to orchestrate the Stratified Vectorized Hybrid-Graph Cascade solution.

1.  **Initialization**: We set random seeds for reproducibility and initialize the `StratifiedRecommender` from the provided library.
2.  **Data Loading**: We use the `load_resources` method with `load_cached_data=True` to efficiently load the training, validation, and test datasets along with the pre-computed similarity matrices and user history vectors.
3.  **Validation**:
    *   We identify unique customers in the validation set.
    *   We generate predictions for these customers using the `predict` method.
    *   We calculate the MAP@12 score using the provided `evaluation` module and print it in the required format.
4.  **Failure Analysis**:
    *   We compute the Average Precision (AP) for each user in the validation set.
    *   We define "Error Magnitude" as $1.0 - \text{AP}$.
    *   We load customer metadata (Age) and calculate user history length from the training data.
    *   We compute and print the Pearson correlation between the Error Magnitude and these features to identify systematic weaknesses (e.g., cold-start users vs. established users).
5.  **Submission**:
    *   We check if the validation MAP@12 exceeds the specified threshold (0.0265060791).
    *   If successful, we trigger the `run_submission` method to generate predictions for the test set and save the `submission.csv`.
