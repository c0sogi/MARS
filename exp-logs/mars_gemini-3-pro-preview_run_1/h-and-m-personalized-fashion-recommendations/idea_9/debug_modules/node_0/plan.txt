This script demonstrates the end-to-end workflow of the Decay-Weighted Stratified Cascade (DWSC) recommendation system. It overrides the global configuration to run in `DEBUG` mode, ensuring rapid execution by processing a small subset of the data. The script performs the following steps:
1.  **Configuration**: Sets `DEBUG` flags and reduces hyperparameters (neighbor count, batch size) for speed.
2.  **Data Preparation**: Uses `DataManager` to load and split the data into training and validation sets, ensuring correct integer mapping for users and items.
3.  **Model Training**: Instantiates `DWSCRecommender` to build the interaction matrix, compute item-item similarities, and calculate global trends.
4.  **Inference**: Generates predictions for the validation set.
5.  **Evaluation**: Calculates the MAP@12 score using the provided ground truth.
6.  **Submission Workflow**: Demonstrates how to retrain on the full dataset and generate the final submission file.
