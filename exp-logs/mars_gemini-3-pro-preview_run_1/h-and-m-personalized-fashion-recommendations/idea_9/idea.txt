Based on the comprehensive analysis of the "Lessons Learned" and the unexecuted potential of "Idea 8," I propose the **Decay-Weighted Stratified Cascade (DWSC)**.

This solution introduces a structural innovation in the **Collaborative Filtering (CF) Matrix Construction** phase. It resolves the conflict between "Recency" (Lesson 00007) and "Long-Tail Volume" (Lesson 00012) by embedding temporal decay directly into the training interaction matrix. This creates a "Rolling Similarity" graph that mathematically down-weights obsolete correlations without discarding the data entirely. I couple this with a **Stratified Vectorized Inference** engine to strictly enforce the successful "Cascade" logic (Lesson 00016) within a high-speed linear algebra framework.

# Model
The architecture is a **Three-Stage Stratified Retrieval System** that generates a single unified score vector $R_u$ for each user. The innovation lies in the **Stratification Logic**, which maps disjoint signal sources to specific numerical ranges. This effectively vectorizes the "Cascade" concept, ensuring high-precision priors (Habit) always outrank discovery signals (CF), which in turn outrank fallbacks (Trend).

1.  **Stratum 1: Habitual Repurchase (The "Priors" Layer)**
    *   **Logic:** Users are overwhelmingly likely to rebuy recent items. Cite {solution_lesson_node_00002}.
    *   **Mechanism:** Retrieve the user's history vector $U_{hist}$. Apply strict temporal decay ($1 / \text{days\_elapsed}$).
    *   **Stratification:** Scores are shifted to the range $[2000, \infty)$. This ensures explicit history *always* outranks inferred similarity, preventing the "Ensemble Noise" failure observed in Lesson 00016.

2.  **Stratum 2: Decay-Weighted Collaborative Filtering (The "Discovery" Layer)**
    *   **Structural Innovation:** Instead of a binary interaction matrix ($X \in \{0, 1\}$), we construct a **Time-Decayed Interaction Matrix** $X_{decay}$.
        *   $X_{ui} = w(t_{ui}) \cdot \text{IDF}_i$, where $w(t_{ui}) = \frac{1}{\sqrt{\text{days\_elapsed} + 1}}$.
        *   **Why:** Standard CF treats a co-occurrence from 5 weeks ago the same as one from yesterday. By weighting the *training* matrix, the resulting similarity $S = X_{decay}^T X_{decay}$ prioritizes *concurrent* market behavior, addressing the "Concept Drift" issue (Cite {solution_lesson_node_00007}) while allowing us to use a longer data window to capture the "Long Tail" (Cite {solution_lesson_node_00012}).
    *   **Normalization:** We apply **Row-wise (User) Normalization** to $X_{decay}$ to mitigate power-user bias. Cite {solution_lesson_node_00004}.
    *   **Weighting:** We apply **IDF Weighting** to penalize globally popular items that act as noisy hubs. Cite {solution_lesson_node_00011}.
    *   **Inference:** $R_{cf} = U_{query} \times S$. The query vector $U_{query}$ is also weighted by recency. Cite {solution_lesson_node_00005}.
    *   **Stratification:** Scores are normalized and scaled to the range $[100, 1000]$.

3.  **Stratum 3: Global Trend (The "Fallback" Layer)**
    *   **Logic:** Time-decayed sales velocity for cold-start users.
    *   **Stratification:** Scores are scaled to $[0, 10]$.

**Final Aggregation:**
$$ R_{total} = R_{rep} + R_{cf} + R_{trend} $$
Because the ranges are disjoint, sorting $R_{total}$ is mathematically equivalent to the heuristic cascade: Sort(Repurchase) $\rightarrow$ Sort(CF) $\rightarrow$ Sort(Trend).

# Data
1.  **Temporal Windowing:**
    *   We will extend the training window to **10 weeks** but apply the **Decay-Weighting** described above. This allows the model to leverage a larger volume of data for stability (Long Tail) while mathematically suppressing the noise from obsolete trends (Recency), resolving the conflict identified in Lesson {solution_lesson_node_00007}.
2.  **Precision:**
    *   Use **float32** for all matrix accumulators and score calculations. This prevents the numerical overflow issues observed when using `float16` with stratified offsets. Cite {solution_lesson_node_00010}.
3.  **Preprocessing:**
    *   Convert transaction dates to "days elapsed" relative to the prediction start date.
    *   Compute IDF weights for all items based on the 10-week window.

# Training
Since this is a memory-based heuristic model, "training" is the efficient construction of the sparse matrices:
1.  **Interaction Matrix:** Construct sparse $X_{decay}$ where values are decay weights $\times$ IDF.
2.  **Normalization:** Apply L2 normalization to the rows (Users) of $X_{decay}$.
3.  **Similarity:** Compute $S = X_{decay}^T X_{decay}$ via sparse matrix multiplication.
4.  **Pruning:** Retain only the top-100 neighbors per item to optimize inference speed and memory.

# Evaluation
1.  **Validation Strategy:**
    *   **Time-Based Split:** Train on Weeks $T-10$ to $T-1$, Validate on Week $T$. This ensures the model has access to the user history required for Strata 1 and 2, rectifying the failure of User-Group splitting. Cite {solution_lesson_node_00026}.
2.  **Vectorized Inference:**
    *   Generate predictions using **Vectorized Sparse Matrix Multiplication** ($R = U \times S$). This captures the "long tail" of similarity signals better than iterative lookups. Cite {solution_lesson_node_00012}.
3.  **Retrieval:**
    *   Employ the **Mask-and-Partition** technique: Densify the score vector, mask history items (unless Repurchase score overrides), and use `np.argpartition` to select top 12 items in linear time. Cite {solution_lesson_node_00013}.
