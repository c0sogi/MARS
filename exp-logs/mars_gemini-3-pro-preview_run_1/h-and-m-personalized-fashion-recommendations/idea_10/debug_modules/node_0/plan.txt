This script demonstrates the usage of the Time-Embedded Similarity Stratified Cascade (TESSC) model. It first creates a lightweight subset of the data (using the most recent transactions to ensure the time-based validation logic functions correctly) and overrides the global configuration to use this subset. It then executes the full pipeline: fitting the model, evaluating it using the built-in time-split validation to compute MAP@12, and finally generating a submission file for the test set. Assertions are included to verify the integrity of the process and the output format.
