Based on the comprehensive analysis of the "Lessons Learned," particularly the critical failure of **Idea 14** (due to hard temporal truncation of user history, Cite {solution_lesson_node_00037}) and the limitations of **Idea 12** (which applied a single decay rate to both graph learning and user inference), I propose the **Asymmetric-Decay Inventory-Projected Cascade (ADIPC)**.

This solution introduces a structural innovation by **decoupling the temporal dynamics** of "Structure Learning" (Item-Item Relationships) from "Intent Inference" (User Query). It employs an **Asymmetric Decay Architecture**: a *gentle* decay for building the similarity graph (to maximize signal density) and an *aggressive* decay for constructing the user query (to maximize intent relevance). This is integrated into a strictly prioritized, vectorized cascade that projects predictions onto the currently active inventory.

### Model
The architecture is a **Three-Stage Stratified Retrieval System** implemented via vectorized sparse linear algebra. It generates a single unified score vector $R_u$ for each user, where signal sources are mapped to disjoint numerical ranges to enforce a strict priority hierarchy: **Habit > Projected CF > Global Trend**.

1.  **Stratum 1: Habitual Repurchase (The "Priors" Layer)**
    *   **Logic:** Users are overwhelmingly likely to rebuy items purchased recently. Cite {solution_lesson_node_00002}.
    *   **Mechanism:** Retrieve the user's full history vector $U_{hist}$. Apply strict temporal decay ($1 / \text{days\_elapsed}$).
    *   **Stratification:** Scores are shifted to the range $[2000, \infty)$. This ensures explicit history *always* outranks inferred similarity, strictly adhering to the "Cascade > Ensemble" principle. Cite {solution_lesson_node_00016}.

2.  **Stratum 2: Asymmetric-Decay Collaborative Filtering (The "Discovery" Layer)**
    *   **Structural Innovation (Asymmetric Decay):**
        *   **Structure Learning ($S_{gentle}$):** We construct the Interaction Matrix $X_{train}$ using a **Gentle Decay** (e.g., $w = (1 + \text{days})^{-0.3}$) over a **10-week window**. This preserves the "Long Tail" of item-to-item correlations (Cite {solution_lesson_node_00012}) while mitigating the noise of ancient history (Cite {solution_lesson_node_00007}).
        *   **Intent Inference ($U_{aggressive}$):** We construct the User Query Vector using the **Full User History** (fixing the failure of Lesson 00037) but apply an **Aggressive Decay** (e.g., $w = (1 + \text{days})^{-1.0}$). This ensures the "seed" signal is dominated by immediate context (Cite {solution_lesson_node_00005}) while still providing a non-zero signal for sparse users with older history.
    *   **Inventory Projection ($M_{active}$):** We explicitly mask the output scores by the set of items transacted in the **Last 1 Week**. This forces the model to project latent desires (learned from the 10-week graph) onto currently feasible actions, filtering out obsolete trends.
    *   **Matrix Construction:** $X_{train}$ is subjected to **Row-wise (User) Normalization** (Cite {solution_lesson_node_00004}) and **IDF Weighting** (Cite {solution_lesson_node_00011}) before computing similarity $S_{gentle} = X_{train}^T X_{train}$.
    *   **Inference:** $R_{cf} = (U_{aggressive} \times S_{gentle}) \odot M_{active}$.
    *   **Stratification:** Scores are normalized and scaled to the range $[100, 1000]$.

3.  **Stratum 3: Global Trend (The "Fallback" Layer)**
    *   **Logic:** Sales velocity from the **Last 1 Week** for cold-start users.
    *   **Stratification:** Scores are scaled to $[0, 10]$.

**Final Aggregation:**
$$ R_{total} = R_{rep} + R_{cf} + R_{trend} $$

### Data
1.  **Temporal Windowing:**
    *   **Graph Window:** Last 10 weeks of training data (for $S_{gentle}$).
    *   **Query Window:** Full available history (for $U_{aggressive}$), resolving Lesson 00037.
    *   **Inventory Window:** Last 1 week (for $M_{active}$).
2.  **Validation Strategy:**
    *   **Time-Based Split:** Train on Weeks $T-10$ to $T-1$, Validate on Week $T$. This ensures the model has access to the user history required for Strata 1 and 2, strictly adhering to Lesson 00026.
3.  **Precision:**
    *   Use **float32** for all matrix accumulators. This prevents the numerical overflow issues observed when using `float16` with stratified offsets. Cite {solution_lesson_node_00010}.
4.  **Exclusion:**
    *   Explicitly exclude Visual Embeddings (Cite {solution_lesson_node_00020}) and Metadata Hybridization (Cite {solution_lesson_node_00027}) to maintain behavioral signal purity.

### Training
Since this is a memory-based heuristic model, "training" is the efficient construction of the sparse matrices:
1.  **Interaction Matrix:** Construct sparse $X_{train}$ using the gentle decay weights.
2.  **Normalization:** Apply IDF to columns and L2 normalization to rows (Users).
3.  **Similarity:** Compute $S_{gentle} = X_{train}^T X_{train}$ via sparse matrix multiplication.
4.  **Pruning:** Retain only the top-100 neighbors per item to optimize inference speed.
5.  **Inventory Mask:** Identify unique `article_id`s in the last week to create the binary mask $M_{active}$.

### Evaluation
1.  **Vectorized Inference:**
    *   Construct the sparse query matrix $U_{aggressive}$ for all test users using full history and steep decay.
    *   Compute $R_{raw} = U_{aggressive} \times S_{gentle}$ via sparse matrix multiplication (Cite {solution_lesson_node_00012}).
    *   Apply the mask: $R_{projected} = R_{raw} \odot M_{active}$.
2.  **Retrieval Strategy:**
    *   Employ the **Mask-and-Partition** technique: Densify the score vector, mask history items (unless Repurchase score overrides), and use `np.argpartition` to select top 12 items in linear time. Cite {solution_lesson_node_00013}.
