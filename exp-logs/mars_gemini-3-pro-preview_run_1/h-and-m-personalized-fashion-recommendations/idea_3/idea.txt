Based on the provided lessons and dataset characteristics, I propose a **Hybrid Multi-View Similarity Ensemble**. This solution evolves the architecture from a rigid, deterministic cascade (Previous Idea 1) to a unified linear algebra framework that aggregates signals from three distinct "views" of user preference: **Habit (Repurchase)**, **Behavioral Co-occurrence**, and **Visual Similarity**.

This approach addresses the limitations of the "Learning-to-Rank" attempt (Lesson 00009) by replacing the complex, unstable feature-based ranker with a robust, numerically stable weighted score aggregation. It also introduces a structural innovation by incorporating image data to solve the "Cold Start" problem for items that are visually similar to a user's taste but have not yet been frequently bought together.

# Model
The core architecture is a **Weighted Sparse Matrix Ensemble**. Instead of selecting candidates sequentially (Repurchase $\rightarrow$ CF $\rightarrow$ Trend), we compute a unified relevance score vector $R_u$ for each user $u$ by linearly combining three sparse score vectors.

1.  **View 1: Temporal Repurchase Vector ($V_{rep}$):**
    A sparse vector representing the user's explicit history. Indices correspond to purchased `article_id`s, and values are time-decay weights ($1 / \text{days\_elapsed}$), capturing the strong "Habit" signal. Cite {solution_lesson_node_00002}.

2.  **View 2: Behavioral Similarity ($V_{cf}$):**
    Derived from the optimized Item-Item Collaborative Filtering matrix ($S_{behavior}$). This matrix captures latent purchasing patterns (e.g., "people who buy this top also buy these pants").
    *   **Construction:** We use **Row-wise (User) Normalization** on the interaction matrix to mitigate power-user bias Cite {solution_lesson_node_00004} and apply **IDF Weighting** to down-weight universally popular items Cite {solution_lesson_node_00011}.

3.  **View 3: Visual Similarity ($V_{vis}$) [Structural Innovation]:**
    A new signal derived from the `images/` directory. We construct a Visual Similarity Matrix ($S_{visual}$) where $S_{i,j}$ represents the cosine similarity between the CNN embeddings of article $i$ and article $j$.
    *   **Purpose:** This captures "look-alike" recommendations orthogonal to purchase history, allowing the model to recommend new or niche items that visually match the user's style but lack sufficient co-occurrence data.

**Aggregation Logic:**
The final score vector is computed as:
$$ R_u = \alpha \cdot V_{rep} + \beta \cdot (U_{hist} \times S_{behavior}) + \gamma \cdot (U_{hist} \times S_{visual}) + \delta \cdot V_{trend} $$
where $U_{hist}$ is the user's history vector weighted by recency Cite {solution_lesson_node_00005}, and $\alpha, \beta, \gamma, \delta$ are scalar weights tuned on the validation set.

# Data
1.  **Temporal Windowing:**
    We restrict the training data to the last **5 weeks** of transactions. This adheres to the "Recency over Volume" principle, avoiding noise from obsolete fashion trends Cite {solution_lesson_node_00007}.

2.  **Visual Feature Extraction:**
    *   Load the pre-trained ResNet or EfficientNet model (available via `torchvision` or `timm`).
    *   Process images for all active `article_id`s (resize to 224x224, normalize).
    *   Extract the penultimate layer embedding vectors.
    *   Compute the top-20 nearest neighbors for each item using cosine similarity to build the sparse $S_{visual}$ matrix.

3.  **Numerical Precision:**
    All score aggregations and matrix multiplications will be performed using **float32**. We explicitly avoid `float16` for accumulators to prevent the overflow/infinity issues observed in previous experiments Cite {solution_lesson_node_00010}.

# Training
Since this is a memory-based heuristic ensemble, "training" consists of two steps:
1.  **Matrix Construction:** Efficiently building the sparse matrices $S_{behavior}$ and $S_{visual}$ using the definitions above.
2.  **Weight Calibration:** Instead of training a Gradient Boosted Ranker (which failed due to noise/overfitting), we will perform a simple **Grid Search** or **Logistic Regression** on the Validation Set (Week $T$) to find the optimal scalar coefficients ($\alpha, \beta, \gamma, \delta$). This allows the model to learn the global relative importance of "Habit" vs. "Visuals" vs. "Co-occurrence" without overfitting to specific item features.

# Evaluation
1.  **Vectorized Inference:**
    We generate predictions using **Vectorized Sparse Matrix Multiplication**. This allows us to aggregate scores from *all* neighbors (long-tail) rather than pruning strictly to the top-N neighbors during the lookup phase Cite {solution_lesson_node_00012}.

2.  **Retrieval Strategy:**
    We employ the **Mask-and-Partition** technique for efficiency Cite {solution_lesson_node_00013}:
    *   Compute the dense score vector $R_u$.
    *   **Mask** items already present in the user's history (setting score to $-\infty$) to promote discovery (unless Repurchase score $\alpha$ is high enough to override).
    *   Use `np.argpartition` to select the top 12 indices in linear time.
    *   Sort the final 12 items by score.

3.  **Cold Start Fallback:**
    For users with no history in the 5-week window, we default to the Global Trend vector ($V_{trend}$), constructed using time-decayed sales counts.
