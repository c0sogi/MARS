The issue stems from the fact that `recommender.mapper.map_users` returns a pandas Series. When this Series is sliced (e.g., `batch_indices = all_indices[start:end]`), the resulting slice retains the original index labels (e.g., 2000 to 3999). Inside the loop, `batch_indices[i]` is called with `i` starting from 0 (via `enumerate`). Since pandas Series uses label-based lookup for integer keys, accessing `batch_indices[0]` when the index starts at 2000 raises a `KeyError`. The fix is to convert the mapped indices to a NumPy array using `.values` immediately, ensuring that subsequent slicing produces NumPy arrays which support standard 0-based positional indexing.
