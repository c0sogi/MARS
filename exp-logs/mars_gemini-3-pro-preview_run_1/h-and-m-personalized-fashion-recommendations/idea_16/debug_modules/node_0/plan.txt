The following script demonstrates the usage of the provided TWIG-SR library components.

### Implementation Strategy
1.  **Environment Setup**: Fix random seeds and suppress warnings for reproducibility and clean output.
2.  **Data Subsampling**: To ensure the demonstration runs quickly (within the time limit) and respects the "optimize for speed" requirement, we create a small, consistent subset of the provided metadata. We sample a specific set of users and their transactions to maintain graph connectivity.
3.  **Configuration Override**: We dynamically modify the `library.settings` module at runtime to point to our generated subset files and a temporary working directory. This allows the complex pipeline to run on the small dataset without modifying the original library code.
4.  **Component Verification**:
    *   **Metrics**: Verify the MAP@12 calculation logic with a known manual example.
    *   **Data Manager**: Instantiate `TransactionLoader` to process raw CSVs into training tensors and ID mappings, asserting correct shapes and data types.
    *   **Graph Model**: Instantiate `InteractionGraph` to build the User-Item interaction matrix ($X$) and Item-Item similarity matrix ($S$), verifying sparsity and dimensions.
    *   **Predictor**: Instantiate `StratifiedRecommender` to run the full inference pipeline (Habit + CF + Trend), first in validation mode (calculating MAP) and then in submission mode (generating output).
