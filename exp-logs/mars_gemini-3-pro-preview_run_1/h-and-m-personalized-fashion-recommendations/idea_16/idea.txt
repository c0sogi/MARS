Based on the analysis of the "Lessons Learned" and the failure modes of previous experiments, I propose the **Time-Weighted Interaction Graph with Stratified Retrieval (TWIG-SR)**.

This solution introduces a structural innovation by **decoupling "Signal Freshness" from "Data Volume"** within the Collaborative Filtering topology. It resolves the conflict between **Lesson 00007** (where long history introduced concept drift) and **Lesson 00012** (where vectorized inference benefited from long-tail data) by embedding continuous temporal decay directly into the interaction graph's edge weights. Unlike previous attempts that failed due to hard temporal cutoffs (Cite {solution_lesson_node_00037}, {solution_lesson_node_00039}) or improper validation (Cite {solution_lesson_node_00026}), this approach allows the model to leverage a deep historical window for structural density while mathematically suppressing obsolete noise, strictly enforced via a vectorized cascade.

### Model
The architecture is a **Three-Stage Stratified Retrieval System** implemented via vectorized sparse linear algebra. It generates a single unified score vector $R_u$ for each user, utilizing disjoint numerical ranges to enforce a strict priority hierarchy: **Habit > Time-Weighted CF > Global Trend**.

1.  **Stratum 1: Habitual Repurchase (The "Priors" Layer)**
    *   **Logic:** Users are overwhelmingly likely to rebuy items purchased recently. Cite {solution_lesson_node_00002}.
    *   **Mechanism:** Retrieve the user's history vector $U_{hist}$. Apply strict temporal decay ($w = 1 / \text{days\_elapsed}$).
    *   **Stratification:** Scores are shifted to the range $[2000, \infty)$. This ensures explicit history *always* outranks inferred similarity, strictly adhering to the "Cascade > Ensemble" principle. Cite {solution_lesson_node_00016}.

2.  **Stratum 2: Time-Weighted Collaborative Filtering (The "Discovery" Layer)**
    *   **Structural Innovation (Continuous-Decay Matrix):** Instead of a binary interaction matrix over a short window, we construct a **Time-Weighted Interaction Matrix** $X_{decay}$ over an **Extended Window (10 weeks)**.
        *   **Edge Weighting:** $X_{ui} = \frac{1}{1 + \log(t_{ui} + 1)} \cdot \text{IDF}_i$.
        *   **Why:** This allows the graph to retain "Long Tail" connectivity (Cite {solution_lesson_node_00012}) from 2 months ago but scales the magnitude down so it cannot override concurrent trends. This solves the "Concept Drift" issue (Cite {solution_lesson_node_00007}) without using the destructive "Hard Filters" that caused previous failures (Cite {solution_lesson_node_00039}).
    *   **Normalization:** We apply **Row-wise (User) Normalization** to $X_{decay}$ to mitigate power-user bias. Cite {solution_lesson_node_00004}.
    *   **Weighting:** We apply **IDF Weighting** to penalize globally popular hubs. Cite {solution_lesson_node_00011}.
    *   **Inference:** $R_{cf} = U_{query} \times S$, where $S = X_{decay}^T X_{decay}$. The query vector $U_{query}$ is also weighted by recency to prioritize immediate intent. Cite {solution_lesson_node_00005}.
    *   **Stratification:** Scores are normalized and scaled to the range $[100, 1000]$.

3.  **Stratum 3: Global Trend (The "Fallback" Layer)**
    *   **Logic:** Time-decayed sales velocity for cold-start users.
    *   **Stratification:** Scores are scaled to $[0, 10]$.

**Final Aggregation:**
$$ R_{total} = R_{rep} + R_{cf} + R_{trend} $$
Sorting $R_{total}$ is mathematically equivalent to the heuristic cascade: Sort(Repurchase) $\rightarrow$ Sort(CF) $\rightarrow$ Sort(Trend).

### Data
1.  **Temporal Windowing:**
    *   **Training Window:** We extend the training data to the **Last 10 Weeks**. The continuous decay mechanism makes this safe, unlike in Lesson 00007.
    *   **Validation Split:** We employ a **Time-Based Split** (Train on $T-10$ to $T-1$, Validate on $T$). This ensures the model has access to the user history required for Strata 1 and 2, rectifying the failure of User-Group splitting. Cite {solution_lesson_node_00026}.
2.  **Precision:**
    *   Use **float32** for all matrix accumulators and score calculations. This prevents the numerical overflow issues observed when using `float16` with stratified offsets. Cite {solution_lesson_node_00010}.
3.  **Exclusion:**
    *   Explicitly exclude Visual Embeddings (Cite {solution_lesson_node_00020}) and Metadata Hybridization (Cite {solution_lesson_node_00027}) to maintain behavioral signal purity.

### Training
Since this is a memory-based heuristic model, "training" is the efficient construction of the sparse matrices:
1.  **Interaction Matrix:** Construct sparse $X_{decay}$ using the log-decay formula.
2.  **Normalization:** Apply IDF to columns and L2 normalization to rows (Users).
3.  **Similarity:** Compute $S = X_{decay}^T X_{decay}$ via sparse matrix multiplication.
4.  **Pruning:** Retain only the top-100 neighbors per item to optimize inference speed.

### Evaluation
1.  **Vectorized Inference:**
    *   Generate predictions using **Vectorized Sparse Matrix Multiplication** ($R = U \times S$). This captures the "long tail" of similarity signals better than iterative lookups. Cite {solution_lesson_node_00012}.
2.  **Retrieval Strategy:**
    *   Employ the **Mask-and-Partition** technique: Densify the score vector, mask history items (unless Repurchase score overrides), and use `np.argpartition` to select top 12 items in linear time. Cite {solution_lesson_node_00013}.
