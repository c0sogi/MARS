Here is the implementation of the orchestration script `runfile.py`.

The strategy follows the **Time-Weighted Interaction Graph with Stratified Retrieval (TWIG-SR)** methodology:
1.  **Validation & Analysis**: The script first loads the validation split using `TransactionLoader`. It constructs the `InteractionGraph` and manually executes the stratified inference loop (Global Trend + Time-Weighted CF + Habitual Repurchase) to compute the MAP@12 score. This manual execution allows capturing per-user AP scores for failure analysis.
2.  **Failure Analysis**: It calculates the correlation between the model's error magnitude ($1 - \text{AP}$) and the user's history length, identifying if the model struggles with cold-start or heavy-history users.
3.  **Submission**: If the validation score exceeds the threshold ($0.0265060791$), it instantiates the `StratifiedRecommender` class to retrain on the full dataset and generate the submission file, leveraging the optimized pipeline provided in the library.
