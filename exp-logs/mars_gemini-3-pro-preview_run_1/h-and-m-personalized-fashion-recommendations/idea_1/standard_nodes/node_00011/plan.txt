To optimize the recommendation model, I will implement **IDF (Inverse Document Frequency) Weighting** within the Item-Item Collaborative Filtering component. By down-weighting items that are purchased by a vast number of users (e.g., basics), the similarity matrix will capture more meaningful, specific co-occurrence patterns rather than generic popularity associations. This aligns with standard Information Retrieval practices to improve signal-to-noise ratio in similarity calculations.

Additionally, I will increase the `CF_NEIGHBORS` hyperparameter from 20 to 60. With the improved signal from IDF weighting, expanding the neighbor pool will allow the model to retrieve a richer set of relevant candidates for the collaborative filtering stage, potentially improving coverage for users with sparse history (Cite `solution_lesson_node_00003`).

        # Calculate Inverse Document Frequency to down-weight universally popular items
        # IDF = log(Total Users / (Users who bought item + 1))
        print("Calculating IDF weights...")
        user_counts = df.groupby("article_id")["customer_id"].nunique()
        n_total_users = df["customer_id"].nunique()
        
        idf_vals = np.log(n_total_users / (user_counts + 1.0))
