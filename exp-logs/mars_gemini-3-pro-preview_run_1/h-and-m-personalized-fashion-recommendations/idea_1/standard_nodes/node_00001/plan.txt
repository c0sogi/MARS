Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Setup & Imports**: Import necessary classes and functions from the provided `library` modules (`config`, `utils`, `data_loader`, `model`, `metrics`) to avoid code duplication. Set random seeds for reproducibility.
2.  **Validation Loop**:
    *   Load the transaction data using `load_filtered_transactions` with caching enabled.
    *   Manually split the data into a training set (historical data) and a validation set (last 7 days) based on the `days_elapsed` column.
    *   Instantiate and fit the `TrendRepurchaseCascade` model on the training split.
    *   Generate predictions for the validation customers.
    *   Format these predictions and calculate the MAP@12 score using `calculate_map12`.
    *   Print the result strictly as `Final Validation Metric: <value>`.
3.  **Failure Analysis**:
    *   Calculate the Average Precision (AP) for each individual customer in the validation set to quantify performance at a granular level.
    *   Define "Error Magnitude" as $1.0 - \text{AP}$.
    *   Load customer metadata (`customers.csv`) and merge it with the error scores.
    *   Compute derived features like "history length" (number of training transactions per user).
    *   Calculate and print the correlation between the Error Magnitude and features (Age, Club Status, History Length) to identify systematic failures.
4.  **Submission Generation**:
    *   Call the provided `run_submission()` function from `library.model`. This function handles retraining on the full dataset, predicting for the test set defined in `sample_submission.csv`, and saving the result to `submission/submission.csv`.
