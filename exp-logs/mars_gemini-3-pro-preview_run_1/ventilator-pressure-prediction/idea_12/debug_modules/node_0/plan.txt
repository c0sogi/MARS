The following script demonstrates the end-to-end usage of the provided library files for the ventilator pressure prediction task.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to enable `DEBUG` mode. This restricts the dataset to a small subset (200 breaths) and reduces the number of epochs to 1, ensuring the script executes quickly (within minutes) while still exercising all code paths.
2.  **Data Pipeline Verification**: We call `get_data_loaders` to trigger the feature engineering and data loading pipeline. We assert that the resulting DataLoaders yield batches with the correct shapes (Batch Size, Sequence Length, Features) and data types.
3.  **Metric Verification**: We perform a unit test on the `compute_mae` function using manually constructed numpy arrays to ensure the masking logic (ignoring the expiratory phase where `u_out=1`) functions correctly.
4.  **Model & Training Demonstration**: We instantiate the `VentilatorModel`, move it to the appropriate device, and run a single epoch of training and validation. We assert that the loss is a valid finite number.
5.  **Inference & Submission**: We execute the inference function on the test set and verify that the generated `submission.csv` adheres to the required format (correct columns and row count corresponding to the debug subset).
