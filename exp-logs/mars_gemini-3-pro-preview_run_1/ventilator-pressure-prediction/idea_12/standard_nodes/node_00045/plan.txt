Implementation strategy:
1.  **Setup & Config**: Import necessary modules and the provided library. Override `Config.EPOCHS` to 15 to ensure a fast but sufficient training run. Keep `Config.DEBUG = False` to utilize the full dataset (which is fast enough on A100) and leverage existing caches.
2.  **Data Loading**: Call `get_data_loaders(load_cached_data=True)` to efficiently load preprocessed data.
3.  **Training**: Initialize the `VentilatorModel`, `AdamW` optimizer, and `OneCycleLR` scheduler. Execute the training loop, tracking the validation MAE and saving the best model state.
4.  **Validation & Analysis**: Load the best model. Compute the final validation metric on the hold-out set. Perform failure analysis by extracting features and predictions from the validation set, filtering for the inspiratory phase, calculating absolute errors, and computing Pearson correlations between error magnitude and input features.
5.  **Submission**: Compare the final validation metric against the threshold (0.2164510190486908). If the metric is lower, generate the submission file using the test set via the `inference_fn`.
