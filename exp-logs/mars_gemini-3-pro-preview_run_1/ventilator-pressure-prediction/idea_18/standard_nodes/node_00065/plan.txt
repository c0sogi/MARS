Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the provided `Config` class. To strictly adhere to the "fast baseline" and "limit maximum number of training samples" requirements, I will override `EPOCHS` to 15 and limit the training dataset to 30,000 breaths (approx. 60% of the data) using `torch.utils.data.Subset`. This ensures the code completes well within the 2-hour limit on the provided hardware.
2.  **Data Pipeline**: Use the `prepare_data` function from `library.dataset` to load and cache the training and validation datasets. Create standard PyTorch `DataLoader`s, enabling pinned memory for GPU acceleration.
3.  **Model Training**: Instantiate the `VentilatorModel` and `Trainer`. Run the training process via `trainer.fit()`, which handles the training loop, gradient clipping, and learning rate scheduling.
4.  **Validation**: After training, execute `trainer.validate()` to compute the Mean Absolute Error (MAE) on the inspiratory phase of the full hold-out validation set. The result is printed in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Perform a post-hoc analysis on the validation set. Extract model predictions and ground truth, filter for the inspiratory phase (masking `u_out == 1`), and compute the absolute error per time step. Calculate and print the Pearson correlation between the error magnitude and input features to identify systematic weaknesses.
6.  **Submission Logic**: Compare the calculated validation metric against the threshold `0.2164510190486908`. If and only if the metric is lower (better), invoke `generate_predictions` from `library.inference` to produce the `submission.csv` file.
