### Implementation Strategy

2.  **Data Loading & Verification**: We will utilize `get_dataloaders` to prepare the data. We will fetch a single batch from the training loader to verify the tensor shapes (Batch Size, Sequence Length, Features) and data types.
3.  **Model Initialization & Forward Pass**: We will instantiate the `VentilatorModel` and perform a dummy forward pass with the batch retrieved earlier. We will assert that the output shape matches expectations `(Batch, Seq_Len, 1)`.
4.  **Metric Logic Verification**: We will manually test the `compute_metric` function with synthetic tensors to confirm that the Mean Absolute Error is calculated strictly for the inspiratory phase (`u_out == 0`) and ignores the expiratory phase.
5.  **Training Loop Execution**: We will initialize the `Engine` and run the `fit` method. This demonstrates the training pipeline, including loss calculation, backpropagation, and validation.
6.  **Inference & Submission**: We will run `generate_submission` to create the output CSV. We will verify the file's existence and format (headers and row counts) against the test set IDs.
