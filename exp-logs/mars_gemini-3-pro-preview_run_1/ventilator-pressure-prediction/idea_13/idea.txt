# Proposed Strategy: High-Capacity Unnormalized Physics-Injected Composite CNN-LSTM-FFN

This strategy is a rigorous synthesis of the most successful architectural components identified in the lessons. It combines the **Pointwise Feed-Forward Networks** (Lesson 40) that drove the best performance (MAE 0.2165) with the **High-Capacity** requirements (Lesson 42) and the strict **No-Normalization** constraint for regression (Lesson 44). It explicitly rejects the "Add & Norm" Transformer topology in favor of a pure "Add" residual stream to preserve signal magnitude.

### Model
The architecture is a **High-Capacity Unnormalized Physics-Injected Composite CNN-LSTM-FFN**. It is designed to maximize expressivity via channel mixing while maintaining the gradient highway required for precise continuous regression.

*   **Stem (Multi-Scale CNN):** The input sequence is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. The outputs are concatenated to capture both fine-grained signal noise and smoothed trend derivatives (Cite solution_lesson_node_00015).
*   **Backbone (Unnormalized Composite Blocks):** The core consists of a stack of **4 High-Capacity Composite Blocks**. We strictly maintain a hidden dimension of **512** (Cite solution_lesson_node_00042). Each block contains two distinct sub-modules executed sequentially:
    1.  **Context-Injected Temporal Mixer (Bi-LSTM):**
        *   **Input:** The input to the LSTM is the concatenation of the previous block's output and the **Static Physics Features** (scaled `R`, `C`, `u_in * R`, `Vol / C`). This ensures physical constraints are re-injected at every depth (Cite solution_lesson_node_00035).
        *   **Processing:** A Bidirectional LSTM (512 units) processes the sequence.
        *   **Residual:** A simple additive residual connection ($y = x + \text{Dropout}(\text{LSTM}(x))$) is used. We explicitly **exclude Layer Normalization** to preserve the absolute pressure magnitude (Cite solution_lesson_node_00044).
    2.  **Pointwise Channel Mixer (FFN):**
        *   **Processing:** The output of the temporal mixer is passed through a **Pointwise Feed-Forward Network** (`Linear -> GELU -> Linear`). This decouples channel mixing from temporal mixing, significantly enhancing the model's ability to learn non-linear physical interactions (Cite solution_lesson_node_00040).
        *   **Residual:** A second simple additive residual connection ($z = y + \text{Dropout}(\text{FFN}(y))$) is applied. Again, **no normalization** is used (Cite solution_lesson_node_00044).
*   **Deep Supervision:** We attach an **Auxiliary Regression Head** (Linear projection) to the output of the **2nd Block**. This creates a short-circuit for gradients, accelerating convergence and enforcing feature quality at intermediate depths (Cite solution_lesson_node_00039).
*   **Final Head:** A linear layer projects the output of the 4th Block to the final `pressure` prediction.

### Data
The data pipeline is strictly engineered for **Physics Fidelity** and **Reproducibility**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$. This corrects the mathematical error of using raw sums (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms derived from the Equation of Motion (`u_in * R`, `volume / C`) as input features. We avoid "Hard" additive residuals to prevent unit-mismatch biases (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` to capture system inertia (Cite solution_lesson_node_00022).
    *   **Continuous Attributes:** Treat `R` and `C` as continuous scaled inputs to preserve their ordinal magnitude (Cite solution_lesson_node_00022).
*   **Robust Caching:** Generate cache filenames using a **hash of the configuration and feature list** to prevent stale data artifacts (Cite solution_lesson_node_00002).
*   **Preprocessing:** Reshape to `(N_breaths, 80, N_features)` and normalize using `RobustScaler`.

### Training
*   **Composite Loss Function:** We utilize a weighted **Masked L1 Loss**.
    *   $L_{total} = L_{mask}(y_{final}, y_{true}) + 0.3 \cdot L_{mask}(y_{aux}, y_{true})$.
    *   Both losses are masked by `(1 - u_out)` to focus strictly on the inspiratory phase (Cite solution_lesson_node_00001).
*   **Optimization:** Use **AdamW** with a **OneCycleLR** scheduler.
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which is critical for the convergence of deep residual architectures (Cite solution_lesson_node_00028).
*   **Update Budget:** Maintain a batch size of **512**. We explicitly avoid increasing the batch size further to ensure a sufficient number of gradient updates are performed (Cite solution_lesson_node_00019).
*   **Dropout Placement:** Dropout is applied strictly to the residual branch *before* addition to preserve the identity path (Cite solution_lesson_node_00024).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** Predictions are generated using only the **Final Head** (Block 4 output). The auxiliary head is discarded during inference. The output is flattened and mapped to the `id` column for submission.
