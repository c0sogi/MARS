# Proposed Strategy: Wide-Projected Physics-Composite Network

This strategy resolves the conflict between **Model Capacity** (Lesson 42, 55) and **Optimization Stability** (Lesson 64, 73). It employs a **"Bottleneck-to-Wide"** topology: the model initializes features in a compressed space to filter noise, projects them once to a high-dimensional space, and then processes them through a **Strict-Identity Backbone**. This ensures the high capacity required for physical modeling without the instability of parameterized residual shortcuts.

### Model
The architecture is a **Wide-Projected Physics-Composite Network**. It separates the feature extraction dimension ($D_{stem}=512$) from the latent modeling dimension ($D_{model}=1024$) to maximize both stability and expressivity.

*   **Stem (Bottleneck Initialization):** The input sequence is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. The output is projected to a **Bottleneck Dimension of 512**. This compressed initialization stabilizes early training by filtering high-frequency noise from the raw sensors (Cite solution_lesson_node_00073).
*   **Wide Projection Adapter:** A simple learnable **Linear Layer** projects the 512-dim stem output to the **Model Dimension of 1024**. This one-time projection allows us to transition to a high-capacity state space without embedding learnable projections inside the recurrent residual stream (Cite solution_lesson_node_00027).
*   **Backbone (Wide-State Identity Blocks):** The core consists of a stack of **4 Composite Blocks** operating at $D_{model}=1024$.
    1.  **Curated Physics Injection:** At *every* block, the input $x$ (1024) is concatenated with a **Curated Context Vector**. This vector contains **Static Attributes** ($R, C$) and **Derived Physics Interactions** ($R \cdot u_{in}$, $Volume / C$). We explicitly inject these derived terms to relieve the network of learning arithmetic multiplication, while excluding raw noise sources (Cite solution_lesson_node_00076, Cite solution_lesson_node_00066).
    2.  **Wide-State Temporal Mixing (Bi-LSTM):** A Bidirectional LSTM processes the concatenated input. We set the hidden dimension to **512 per direction**, resulting in a natural output dimension of **1024**. This matches the block input exactly, ensuring no information bottleneck (Cite solution_lesson_node_00055).
    3.  **Strict Identity Residual 1:** The residual connection is applied as $y = x + \text{Dropout}(\text{LSTM}(\dots))$. Since Input and Output are both 1024, we use a **Strict Identity Mapping** (no weights) on the skip connection. This creates a pristine gradient highway (Cite solution_lesson_node_00064).
    4.  **Pointwise Channel Mixing (FFN):** The output $y$ is passed through a **Pointwise Feed-Forward Network** (`Linear -> GELU -> Linear`) with an expansion factor of **2x** (2048 units). We avoid 4x expansion to maintain stability without normalization (Cite solution_lesson_node_00052).
    5.  **Strict Identity Residual 2:** A second identity residual is applied: $z = y + \text{Dropout}(\text{FFN}(y))$. We strictly **exclude Layer Normalization** to preserve the absolute pressure magnitude (Cite solution_lesson_node_00044).
*   **Deep Supervision:** An **Auxiliary Regression Head** is attached to the output of **Block 2** to accelerate convergence (Cite solution_lesson_node_00039).
*   **Head:** A linear layer projects the output of Block 4 to the final `pressure`.

### Data
The data pipeline is strictly engineered for **Physics Fidelity** and **Control Segregation**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$ (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms (`u_in * R`, `volume / C`) as input features. We avoid "Hard" additive residuals to prevent unit-mismatch biases (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` to capture system inertia (Cite solution_lesson_node_00022).
*   **Control Segregation:** Explicitly segregate the `u_out` control flag. It must **not** be scaled or normalized, preserving its binary (0/1) nature for exact loss masking (Cite solution_lesson_node_00058). All other continuous features are scaled using `RobustScaler`.
*   **Robust Caching:** Generate cache filenames using a hash of the configuration to prevent stale data artifacts.

### Training
*   **Loss Function:** Weighted **Masked L1 Loss** ($L_{total} = L_{final} + 0.3 \cdot L_{aux}$). The mask is calculated as `1 - u_out` using the unscaled binary flag (Cite solution_lesson_node_00001).
*   **Optimizer:** **AdamW** with a **OneCycleLR** scheduler.
*   **Strict Gradient Clipping:** We enforce a gradient clipping threshold of **1.0**. This is a mandatory prerequisite for the convergence of the Wide-State LSTM backbone (Cite solution_lesson_node_00059).
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which is critical for solving the cumulative (elastic) dynamics of the system (Cite solution_lesson_node_00028, Cite solution_lesson_node_00057).
*   **Update Budget:** Maintain a batch size of **512** to ensure a sufficient number of gradient updates (Cite solution_lesson_node_00019).
*   **Dropout Placement:** Dropout is applied strictly to the residual branch *before* addition (Cite solution_lesson_node_00024).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** Predictions are generated using only the **Final Head** (Block 4 output). The auxiliary head is discarded during inference. The output is flattened and mapped to the `id` column for submission.
