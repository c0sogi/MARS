# Proposed Strategy: Physics-Injected Residual Multi-Scale CNN-LSTM

This strategy synthesizes the "Physics-Fidelity" data requirements (Cite solution_lesson_node_00031), the "Multi-Scale" feature extraction (Cite solution_lesson_node_00015), and the "Simple Residual" structural stability (Cite solution_lesson_node_00033).

**Structural Innovation: Deep Context Injection**
To address the fading of physical context in deep networks (a root cause of errors in "stiff" lungs), I propose **Deep Context Injection**. Instead of feeding static lung attributes (`R`, `C`) and physics interactions only at the input stem, we will concatenate these critical features to the input of **every** LSTM layer in the deep backbone. This ensures that the physical constraints (Equation of Motion) remain accessible to the network at all depths, reinforcing the inductive bias without the optimization penalties of multiplicative gating.

### Model
The architecture is a **Physics-Injected Residual Multi-Scale CNN-LSTM**.

*   **Stem (Multi-Scale CNN):** The input sequence is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. The outputs are concatenated to capture both fine-grained signal noise and smoothed trend derivatives (Cite solution_lesson_node_00015).
*   **Backbone (Deep Context-Injected Bi-LSTM):** The core consists of a stack of **4 Bidirectional LSTM layers**.
    *   **Context Injection:** At each layer $l$, the input is formed by concatenating the output of the previous layer $h_{l-1}$ with the static physics features $F_{phys}$ (scaled `R`, `C`, `u_in * R`, `Vol / C`). This preserves the physical regime context throughout the network depth.
    *   **Manual Residuals:** We employ **Simple Additive Residual Connections** ($y = x + \text{LSTM}(x)$) rather than multiplicative gating or SE-blocks, as regression tasks require unattenuated gradient highways (Cite solution_lesson_node_00033).
    *   **Projection Shortcuts:** Since the Context Injection changes the input dimension at each layer, we apply a learnable **Linear Projection** to the residual path to match dimensions before addition (Cite solution_lesson_node_00027).
    *   **Dropout:** Dropout is strictly applied to the residual branch *before* the addition to preserve the identity path (Cite solution_lesson_node_00024).
*   **Head:** A simple Linear layer projects the final hidden states to the scalar `pressure`.

### Data
The data pipeline is strictly engineered for **Physics Fidelity** and **Reproducibility**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$. This corrects the "raw sum" error that degrades performance (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms derived from the Equation of Motion (`u_in * R`, `volume / C`) as **input features**. We explicitly avoid "Hard" additive residuals to prevent unit-mismatch biases (Cite solution_lesson_node_00011).
    *   **Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` to capture system inertia (Cite solution_lesson_node_00022).
    *   **Continuous Attributes:** Treat `R` and `C` as **continuous scaled inputs** to preserve their ordinal magnitude, rather than using embeddings (Cite solution_lesson_node_00022).
*   **Robust Caching:** Generate cache filenames using a **hash of the configuration and feature list** to prevent stale data artifacts (Cite solution_lesson_node_00002).
*   **Preprocessing:** Reshape to `(N_breaths, 80, N_features)` and normalize using `RobustScaler`.

### Training
*   **Loss Function:** Use **Masked L1 Loss**. The error is calculated element-wise and multiplied by `(1 - u_out)` before averaging to focus optimization strictly on the inspiratory phase (Cite solution_lesson_node_00001).
*   **Optimization:** Use **AdamW** with a **OneCycleLR** scheduler.
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which was proven necessary to maximize the performance of deep residual architectures (Cite solution_lesson_node_00028).
*   **Update Budget:** Maintain a batch size of **512**. We explicitly avoid increasing the batch size further to ensure a sufficient number of gradient updates are performed (Cite solution_lesson_node_00019).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** The model predicts pressure sequences which are flattened and mapped to the `id` column. The result is a CSV file containing `id` and `pressure` pairs.
