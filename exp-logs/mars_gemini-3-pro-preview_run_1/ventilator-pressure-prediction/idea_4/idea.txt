# Proposed Strategy: Physics-Residual Multi-Scale CNN-LSTM

### Model
I propose a **Physics-Residual Multi-Scale CNN-LSTM** architecture. This design leverages the "Inductive Bias Efficiency" of LSTMs (Cite solution_lesson_node_00008) while introducing a structural innovation to enforce physical constraints directly.

*   **Multi-Scale Stem (Inception-1D):** Instead of a single convolutional layer, the input sequence passes through a **Multi-Scale 1D Convolutional Block** (Inception-style). This block applies parallel convolutions with different kernel sizes (e.g., 3, 5, and 7) to the input. The outputs are concatenated, allowing the model to simultaneously capture fine-grained signal noise and broader trend derivatives, enhancing the local feature extraction identified as critical in the previous hybrid model (Cite solution_lesson_node_00005).
*   **Sequential Backbone (Residual Bi-LSTM):** The multi-scale features are fed into a stack of **Bidirectional LSTM layers** with residual connections. We explicitly retain this recurrent backbone over Transformers to ensure efficient convergence and strong sequential inductive bias given the limited compute budget (Cite solution_lesson_node_00008).
*   **Physics-Residual Connection:** We introduce a structural skip connection. The model will calculate a **Theoretical Pressure** sequence based on the Equation of Motion approximation ($P \approx \frac{V}{C} + \dot{V}R$) using the input features. This theoretical baseline is added directly to the output of the LSTM's projection head. Consequently, the neural network is tasked only with predicting the *residual error* ($\Delta P$) between the ideal physical model and the real-world sensor data, rather than learning the full pressure magnitude from scratch.

### Data
The data pipeline will be upgraded to support the physics-residual architecture and ensure reproducibility.

*   **Equation-Driven Feature Engineering:** We will explicitly engineer terms corresponding to the Equation of Motion:
    *   **Cumulative Volume:** Integral of `u_in` over time.
    *   **Flow Interaction:** `u_in * R` (representing resistive pressure).
    *   **Volume Interaction:** `cumulative_volume / C` (representing elastic pressure).
    *   **Theoretical Pressure:** The sum of the Flow and Volume interactions. This serves as both a feature for the LSTM and the baseline for the residual connection (Cite solution_lesson_node_00005).
*   **Robust Caching:** To prevent the "Stale Artifacts" failure, all cached data filenames will be generated using a **hash of the configuration parameters and feature list**. This ensures that any change to the feature engineering logic automatically triggers a re-computation of the dataset (Cite solution_lesson_node_00002).
*   **Preprocessing:** Data will be reshaped into sequences of shape `(N_breaths, 80, N_features)` and normalized using `RobustScaler`.

### Training
*   **Loss Function:** We will strictly adhere to the **Masked L1 Loss** (Mean Absolute Error). The loss will be calculated element-wise and multiplied by `(1 - u_out)` before averaging. This ensures the optimizer focuses exclusively on the inspiratory phase, ignoring the irrelevant expiratory phase which dilutes the gradient signal (Cite solution_lesson_node_00001).
*   **Optimization:** Use the **AdamW** optimizer combined with a **OneCycleLR** scheduler to ensure fast convergence and regularization.
*   **Regularization:** Apply dropout within the LSTM layers and spatial dropout after the Convolutional block to prevent overfitting.

### Evaluation
*   **Inference:** The test set will be processed through the exact same hashed caching and equation-driven feature engineering pipeline.
*   **Prediction:** The model will predict the pressure residuals, which will be added to the pre-calculated theoretical pressure to form the final prediction. These will be flattened and mapped to the `id` column for submission.
