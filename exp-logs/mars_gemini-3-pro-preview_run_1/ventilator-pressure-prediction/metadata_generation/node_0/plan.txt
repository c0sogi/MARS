The implementation strategy involves the following steps:

1.  **Setup and Initialization**: Define the input directory (`./input`) and the output directory (`./metadata`). Ensure the output directory exists, creating it if necessary. Set the random seed to 42 for reproducibility.
2.  **Data Loading**: Read the raw `train.csv` and `test.csv` files from the input directory using pandas.
3.  **Group Splitting**: Identify unique `breath_id`s from the training data. Since the data represents time series grouped by breaths, perform a group shuffle split to ensure that all time steps for a single breath remain in the same split. Shuffle the unique `breath_id`s and split them into an 80% training set and a 20% validation set.
4.  **Metadata Generation**:
    *   Filter the original training dataframe based on the split `breath_id`s to create `train_meta` and `val_meta` dataframes. These will contain the features and ground-truth labels (`pressure`).
    *   Prepare the `test_meta` dataframe from the raw test data.
    *   Save these dataframes as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
5.  **Verification**:
    *   Reload the generated metadata files to verify integrity.
    *   **Group Split Check**: Assert that there is no overlap of `breath_id`s between the training and validation sets.
    *   **Ratio Check**: Verify that the split ratio is approximately 80:20 based on the number of breaths.
    *   **Statistics**: Print summary statistics (shape, unique breaths, target distribution) for all sets.
    *   **File Path Check**: Explicitly check for file path columns. Since this is a purely tabular dataset with no external file references (like images), log that no file path validation is required.
