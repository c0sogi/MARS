2.  **Data Reordering:** I will modify the preprocessing pipeline in `data.py` to force these context features to be the first columns in the input tensor. This allows the model to efficiently slice and broadcast them as the context vector.
3.  **Remove Layer Normalization (Cite Lesson 00044):** I will remove `LayerNorm` from the residual blocks in `model.py`. Empirical evidence suggests that normalization in the residual stream degrades performance for regression tasks where absolute signal magnitude is significant.
4.  **Training Duration (Cite Lesson 00028):** I will increase the training duration from 6 to 25 epochs to allow the deep LSTM backbone sufficient time to converge, as the previous short run showed signs of underfitting.

        self.lstm = nn.LSTM(
            input_size=input_dim + static_dim,
            hidden_size=lstm_hidden,
            batch_first=True,
            bidirectional=True,
        )

        self.res_proj = nn.Linear(input_dim, wide_dim)
        self.dropout = nn.Dropout(dropout)

        self.ffn = nn.Sequential(
            nn.Linear(wide_dim, wide_dim * 2),
            nn.GELU(),
            nn.Linear(wide_dim * 2, wide_dim),
            nn.Dropout(dropout),
        )
        self.norm = nn.LayerNorm(wide_dim)

    def forward(self, x, static_context):
        # x: (B, L, input_dim)
        # static_context: (B, L, static_dim)

        lstm_in = torch.cat([x, static_context], dim=-1)

        out = lstm_out + self.dropout(res)

        # FFN
        ffn_out = self.ffn(out)
        out = out + ffn_out

        return self.norm(out)
