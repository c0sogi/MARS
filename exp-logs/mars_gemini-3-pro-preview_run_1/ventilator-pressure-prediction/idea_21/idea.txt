# Proposed Strategy: Graduated-Capacity Curated-Composite Network

This strategy synthesizes the structural insights regarding **Initialization** (Lesson 73), **State Capacity** (Lesson 55), and **Gradient Flow** (Lesson 64). It introduces a **Graduated-Capacity Backbone** that starts with a compressed bottleneck to filter noise and naturally expands into a wide-state identity stream, resolving the conflict between "Wide Initialization" instability and "Bottleneck" capacity constraints.

### Model
The architecture is a **Graduated-Capacity Curated-Composite Network**. It features a funnel-like expansion trajectory that maximizes feature extraction efficiency while maintaining a pristine gradient highway in deep layers.

*   **Stem (Bottleneck Initialization):** The input sequence (dynamic controls + physics terms) is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. Crucially, the output is projected to a compressed **Bottleneck Dimension of 512**. This avoids the instability and noise dilution observed when projecting raw inputs immediately to high dimensions (Cite solution_lesson_node_00073).
*   **Block 1 (The Expansion Block):** This block handles the transition from the bottleneck to the wide state.
    *   **Curated Context Injection:** Concatenate input ($D=512$) with **Static Physics Features** ($F_{static}$: scaled `R`, `C`). We strictly exclude dynamic inputs to prevent noise propagation (Cite solution_lesson_node_00066).
    *   **Expanding Bi-LSTM:** A Bidirectional LSTM processes the sequence with a hidden dimension of **512 per direction**. The output naturally concatenates to **1024**, expanding the state space.
    *   **Projected Residual:** Since Input (512) $\neq$ Output (1024), we use a learnable linear projection on the residual path (Cite solution_lesson_node_00027).
    *   **Pointwise FFN:** A Feed-Forward Network processes the 1024-dim output (Expansion 2x $\to$ 2048 $\to$ 1024).
*   **Blocks 2-4 (Wide-State Identity Blocks):** These blocks maintain the high capacity established by Block 1.
    *   **Curated Context Injection:** Concatenate input ($D=1024$) with $F_{static}$.
    *   **Wide-State Bi-LSTM:** A Bidirectional LSTM (Hidden=512 per direction) processes the sequence. The output remains **1024**.
    *   **Strict Identity Residual 1:** Since Input (1024) matches Output (1024), we use a **Strict Identity Mapping** (no weights) on the skip connection. This creates an unhindered gradient highway for the deep layers (Cite solution_lesson_node_00064).
    *   **Pointwise FFN:** FFN processes the 1024-dim output.
    *   **Strict Identity Residual 2:** Additive identity residual around the FFN. **No Layer Normalization** is used to preserve regression magnitude (Cite solution_lesson_node_00044).
*   **Deep Supervision:** An **Auxiliary Regression Head** is attached to the output of **Block 2**. This accelerates convergence (Cite solution_lesson_node_00039).
*   **Head:** A linear layer projects the output of Block 4 to the final `pressure`.

### Data
The data pipeline is strictly engineered for **Physics Fidelity** and **Control Segregation**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as $\sum (u_{in} \cdot \Delta t)$ (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms (`u_in * R`, `volume / C`) as input features to the Stem (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4) and Differences of `u_in` (Cite solution_lesson_node_00022).
*   **Control Segregation:** `u_out` is kept as a raw binary integer (0/1) and is **not** scaled, ensuring exact loss masking (Cite solution_lesson_node_00058). All other continuous features are scaled using `RobustScaler`.
*   **Robust Caching:** Cache filenames are hashed based on configuration to prevent stale data.

### Training
*   **Loss Function:** Weighted **Masked L1 Loss** ($L_{total} = L_{final} + 0.3 \cdot L_{aux}$). Mask calculated as `1 - u_out` (Cite solution_lesson_node_00001).
*   **Optimizer:** **AdamW** with **OneCycleLR**.
*   **Strict Gradient Clipping:** Threshold set to **1.0**. This is mandatory for the convergence of the wide-state LSTM backbone (Cite solution_lesson_node_00059).
*   **Extended Horizon:** Train for **35 epochs** to allow full annealing of the learning rate and solution of cumulative dynamics (Cite solution_lesson_node_00028).
*   **Update Budget:** Batch size of **512** to ensure sufficient gradient updates (Cite solution_lesson_node_00019).
*   **Dropout:** Applied to residual branches *before* addition (Cite solution_lesson_node_00024).

### Evaluation
*   **Inference:** Test data is processed through the identical pipeline.
*   **Prediction:** Predictions are generated using the **Final Head** (Block 4). The auxiliary head is ignored. Outputs are flattened and mapped to `id`.
