# Proposed Strategy: Strict-Identity Physics-Injected Composite Network

This strategy introduces a structural innovation: the **Strict-Identity Composite Block**. It resolves the conflict between "Deep Context Injection" (which changes input dimensions) and "Residual Stability" (which requires identity mappings). By architecturally aligning the LSTM's natural output width to the block's input width, we enable **Strict Identity Residuals** even while injecting physics context, creating a pristine gradient highway (Cite solution_lesson_node_00064) while preserving physical fidelity (Cite solution_lesson_node_00035).

### Model
The architecture is a **Strict-Identity Physics-Injected Composite Network**. It prioritizes unhindered gradient flow by eliminating all linear projections in the residual path.

*   **Stem (Multi-Scale CNN):** The input sequence is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. The concatenated output is projected to a fixed Model Dimension of **$D_{model} = 512$** (Cite solution_lesson_node_00015).
*   **Backbone (Strict-Identity Composite Blocks):** The core consists of a stack of **4 Composite Blocks**. Each block is engineered to maintain $D_{model}$ on the residual stream while processing expanded context:
    1.  **Curated Context Injection:** The input to the recurrent layer is formed by concatenating the block input $x$ ($D=512$) with **only** the static physics features ($F_{static}$: scaled `R`, `C`, `u_in * R`, `Vol / C`). We explicitly exclude dynamic raw inputs (like lags) from this injection to prevent signal noise (Cite solution_lesson_node_00066).
    2.  **Aligned Wide-State Bi-LSTM:** A Bidirectional LSTM processes the concatenated input $[x, F_{static}]$. Crucially, we set the hidden dimension to **256 per direction**, resulting in a natural output dimension of **512**. This matches the block input $x$ exactly, avoiding the bottleneck of compression (Cite solution_lesson_node_00055).
    3.  **Strict Identity Residual 1:** The residual connection is applied as $y = x + \text{Dropout}(\text{LSTM}([x, F_{static}]))$. Because the dimensions of $x$ and the LSTM output match perfectly, we use a **strict identity mapping** (no linear projection weights) on the skip connection. This prevents the instability observed in Idea 18 (Cite solution_lesson_node_00064).
    4.  **Pointwise Channel Mixing (FFN):** The output $y$ is passed through a **Pointwise Feed-Forward Network** (`Linear -> GELU -> Linear`) with an expansion factor of **2x** (1024 units). We avoid 4x expansion to maintain stability without normalization (Cite solution_lesson_node_00052).
    5.  **Strict Identity Residual 2:** A second identity residual is applied: $z = y + \text{Dropout}(\text{FFN}(y))$. We strictly **exclude Layer Normalization** to preserve the absolute pressure magnitude for regression (Cite solution_lesson_node_00044).
*   **Deep Supervision:** An **Auxiliary Regression Head** is attached to the output of the **2nd Block**. This accelerates convergence by providing a short-circuit for gradients to the early layers (Cite solution_lesson_node_00039).
*   **Head:** A linear layer projects the output of the 4th Block to the final `pressure` prediction.

### Data
The data pipeline is strictly engineered for **Physics Fidelity** and **Control Segregation**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$ (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms (`u_in * R`, `volume / C`) as input features. We avoid "Hard" additive residuals to prevent unit-mismatch biases (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` to capture system inertia (Cite solution_lesson_node_00022).
    *   **Continuous Attributes:** Treat `R` and `C` as continuous scaled inputs to preserve their ordinal magnitude (Cite solution_lesson_node_00022).
*   **Control Segregation:** Explicitly segregate the `u_out` control flag. It must **not** be scaled or normalized, preserving its binary (0/1) nature for exact loss masking (Cite solution_lesson_node_00058). All other continuous features are scaled using `RobustScaler`.
*   **Robust Caching:** Generate cache filenames using a hash of the configuration to prevent stale data artifacts.

### Training
*   **Loss Function:** Weighted **Masked L1 Loss** ($L_{total} = L_{final} + 0.3 \cdot L_{aux}$). The mask is calculated as `1 - u_out` using the unscaled binary flag (Cite solution_lesson_node_00001).
*   **Optimizer:** **AdamW** with a **OneCycleLR** scheduler.
*   **Strict Gradient Clipping:** We enforce a gradient clipping threshold of **1.0**. This is a mandatory prerequisite for the convergence of the LSTM backbone (Cite solution_lesson_node_00059).
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which is critical for solving the cumulative (elastic) dynamics of the system (Cite solution_lesson_node_00028, Cite solution_lesson_node_00057).
*   **Update Budget:** Maintain a batch size of **512** to ensure a sufficient number of gradient updates (Cite solution_lesson_node_00019).
*   **Dropout Placement:** Dropout is applied strictly to the residual branch *before* addition (Cite solution_lesson_node_00024).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** Predictions are generated using only the **Final Head** (Block 4 output). The auxiliary head is discarded during inference. The output is flattened and mapped to the `id` column for submission.
