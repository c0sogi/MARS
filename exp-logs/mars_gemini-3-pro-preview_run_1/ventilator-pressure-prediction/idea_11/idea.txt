# Proposed Strategy: Deeply Supervised Physics-Injected Hybrid CNN-LSTM-FFN

This strategy represents the culmination of the architectural evolution observed in the lessons. It synthesizes the **Multi-Scale Feature Extraction** (Lesson 15), **Deep Context Injection** (Lesson 35), and **Deep Supervision** (Lesson 39) with the critical new insight of decoupling temporal and channel mixing via **Pointwise Feed-Forward Networks** (Lesson 40).

### Model
The architecture is a **Deeply Supervised Physics-Injected Hybrid CNN-LSTM-FFN**. It adopts a "Block" design philosophy similar to Transformers but retains the inductive bias of Recurrent Neural Networks for time-series efficiency.

*   **Multi-Scale Stem (Inception-1D):** The input sequence is processed by a parallel set of 1D Convolutions with kernel sizes of `[3, 5, 7]`. The outputs are concatenated to capture both fine-grained signal noise and smoothed trend derivatives (Cite solution_lesson_node_00015).
*   **Backbone (Context-Injected LSTM-FFN Blocks):** The core consists of a stack of **4 Composite Blocks**. Each block contains two distinct sub-layers:
    1.  **Context-Injected Recurrent Sub-layer:**
        *   **Input:** The input to the LSTM is the concatenation of the previous block's output and the **Static Physics Features** (scaled `R`, `C`, `u_in * R`, `Vol / C`). This ensures physical constraints are re-injected at every depth (Cite solution_lesson_node_00035).
        *   **Processing:** A Bidirectional LSTM processes the sequence.
        *   **Residual:** We use a simple additive residual connection ($y = x + \text{LSTM}(x)$) with a learnable linear projection if dimensions differ (Cite solution_lesson_node_00027). We strictly avoid multiplicative gating here (Cite solution_lesson_node_00033).
        *   **Dropout:** Applied strictly to the residual branch before addition (Cite solution_lesson_node_00024).
    2.  **Pointwise Feed-Forward Sub-layer (The Innovation):**
        *   **Processing:** The output of the recurrent sub-layer is passed through a Pointwise Feed-Forward Network (FFN) consisting of `Linear -> GELU -> Linear`. This component focuses exclusively on "channel mixing" (modeling non-linear relationships between features at a single time step), decoupling it from the "temporal mixing" of the LSTM (Cite solution_lesson_node_00040).
        *   **Residual:** A second additive residual connection is applied around the FFN ($z = y + \text{FFN}(y)$).
*   **Deep Supervision:** We attach an **Auxiliary Regression Head** (Linear projection) to the output of the **2nd Block**. This provides a gradient short-circuit to earlier layers, accelerating convergence and enforcing feature quality at intermediate depths (Cite solution_lesson_node_00039).
*   **Final Head:** A linear layer projects the output of the 4th Block to the final `pressure` prediction.

### Data
The data pipeline is strictly engineered for **Physics Fidelity** and **Reproducibility**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$. This corrects the mathematical error identified in Lesson 31 (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms derived from the Equation of Motion (`u_in * R`, `volume / C`) as input features. We avoid "Hard" additive residuals to prevent unit-mismatch biases (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` to capture system inertia (Cite solution_lesson_node_00022).
    *   **Continuous Attributes:** Treat `R` and `C` as continuous scaled inputs to preserve ordinal magnitude (Cite solution_lesson_node_00022).
*   **Robust Caching:** Generate cache filenames using a **hash of the configuration and feature list** to prevent stale data artifacts (Cite solution_lesson_node_00002).
*   **Preprocessing:** Reshape to `(N_breaths, 80, N_features)` and normalize using `RobustScaler`.

### Training
*   **Composite Loss Function:** We utilize a weighted **Masked L1 Loss**.
    *   $L_{total} = L_{mask}(y_{final}, y_{true}) + 0.3 \cdot L_{mask}(y_{aux}, y_{true})$.
    *   Both losses are masked by `(1 - u_out)` to focus strictly on the inspiratory phase (Cite solution_lesson_node_00001).
*   **Optimization:** Use **AdamW** with a **OneCycleLR** scheduler.
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which is critical for the convergence of deep residual architectures (Cite solution_lesson_node_00028).
*   **Update Budget:** Maintain a batch size of **512**. We explicitly avoid increasing the batch size further to ensure a sufficient number of gradient updates are performed (Cite solution_lesson_node_00019).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** Predictions are generated using only the **Final Head** (Block 4 output). The auxiliary head is discarded during inference. The output is flattened and mapped to the `id` column for submission.
