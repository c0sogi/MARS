This script demonstrates the end-to-end usage of the provided ventilator pressure prediction library. It performs the following steps:
1.  **Configuration**: Overrides the default configuration to run in `debug` mode with a minimal number of epochs and batch size for rapid execution. It sets up a dedicated working directory for this demonstration.
2.  **Feature Engineering**: Uses `FeatureEngineer` to process raw metadata into engineered features (physics-informed features, lags, diffs) and verifies the output structure.
3.  **Dataset Creation**: Instantiates `VentilatorDataset` to create PyTorch-ready tensors and verifies data shapes (sequence length, feature dimensions).
4.  **Model & Loss Verification**: Instantiates the `WideProjectedNet` and `MaskedAuxL1Loss`, performs a dummy forward pass, and verifies output shapes and loss calculation logic.
5.  **Training Loop**: Uses the `Trainer` class to run a single epoch of training on the debug subset and verifies that model checkpoints are saved.
6.  **Inference**: Loads the saved model, runs inference on the test set using `predict_test`, and generates a submission file.
