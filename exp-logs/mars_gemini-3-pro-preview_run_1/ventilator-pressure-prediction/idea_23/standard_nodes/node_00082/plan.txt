4.  **Failure Analysis**: Collect predictions and targets from the validation set. Calculate the absolute error for each time step. Re-run the feature engineering on a dummy sample to retrieve feature column names, then calculate and print the Pearson correlation between the error magnitude and each feature.
5.  **Submission**: Check if the calculated validation metric is below the threshold (0.2164510190486908). If successful, generate predictions for the test set, format them according to the sample submission, and save to `./submission/submission.csv`.
