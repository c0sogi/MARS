The following implementation orchestrates the full machine learning pipeline for the ventilator pressure prediction task.

### Strategy
1.  **Configuration & Setup**: The script begins by setting the random seed for reproducibility and initializing the configuration. To satisfy the "Fast Baseline" requirement, I override the default `EPOCHS` to 20 and increase the `BATCH_SIZE` to 1024. This ensures the model trains quickly on the A100 GPU while processing the full dataset.
2.  **Data Loading**: I utilize the `prepare_data` function with `load_cached_data=True`. This leverages the pre-processed numpy arrays (if available) to minimize data loading overhead.
3.  **Training**: The `BidirectionalLSTM` model and `Trainer` are instantiated. The training loop is executed via `trainer.fit()`, which handles optimization, masked loss calculation, and learning rate scheduling.
4.  **Validation & Metric**: After training, I perform a separate inference pass on the validation set. I manually compute the **Masked Mean Absolute Error** (MAE) for the inspiratory phase (`u_out == 0`) to strictly adhere to the competition metric. This value is printed with full precision.
5.  **Failure Analysis**: During the validation pass, I collect predictions, targets, and input features. I calculate the absolute error for every inspiratory time step and compute the Pearson correlation between the error magnitude and the input features (`R`, `C`, `u_in`, `time_step`). This identifies which conditions lead to higher model error.
6.  **Submission**: Finally, the `trainer.predict()` method is called to generate predictions for the test set and save the `submission.csv` file in the required format.
