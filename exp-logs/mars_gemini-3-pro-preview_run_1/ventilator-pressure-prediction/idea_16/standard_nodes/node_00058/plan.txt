My strategy is to revert the model architecture to the high-performing "Deeply Supervised Physics-Injected CNN-LSTM" configuration (Idea 10) while incorporating the beneficial "Pointwise Feed-Forward Network" (FFN) enhancement (Idea 11/Lesson 00040), but with corrected implementation details derived from the failure analysis of Idea 14 and Idea 16.

Specifically, I will:
1.  **Restore Model Capacity and Remove Bottlenecks**: Replace the `CompositeBlock` (which bottlenecked the Bi-LSTM to match input dimensions, Cite Lesson 00055) with a `ContextInjectedResBlock`. This block will allow the Bi-LSTM to expand the state dimension (`2 * hidden`), using a linear projection on the residual path to match dimensions (Cite Lesson 00027).
2.  **Stabilize the FFN**: Reduce the FFN expansion factor from 4 to 2 and remove `weight_norm`. High expansion without normalization caused instability (Cite Lesson 00052), while LayerNorm in the residual path degraded regression performance (Cite Lesson 00044). I will use simple additive residuals with Dropout on the branch (Cite Lesson 00024).
3.  **Optimize Training Schedule**: Increase `EPOCHS` to 30 (Cite Lesson 00028) and remove the data subsampling in `runfile.py` to train on the full dataset. The previous failure was partly due to underfitting from insufficient training on resistive dynamics (Cite Lesson 00057).
4.  **Deep Context Injection**: Ensure static physics features are concatenated to the input of *every* LSTM layer (Cite Lesson 00035, 00039).

class CompositeBlock(nn.Module):
    """
    Wide-State Weight-Normalized Physics-Injected Composite Block.
    Maintains high-magnitude gradient highway and high-capacity channel mixing.
    """

    def __init__(self, input_dim, hidden_dim, physics_dim, expansion_factor, dropout):
        super().__init__()

        # 1. Wide-State Temporal Mixing (Bi-LSTM)
        # Input includes Deep Context Injection (Previous State + Physics Features)
        self.lstm = nn.LSTM(
            input_size=input_dim + physics_dim,
            hidden_size=hidden_dim,
            batch_first=True,
            bidirectional=True,
        )

        # Bi-LSTM output dimension is 2 * hidden_dim
        lstm_out_dim = 2 * hidden_dim

        # 2. Projected Residual 1
        # Projects the identity path to match LSTM output dimension if necessary
        if input_dim != lstm_out_dim:
            self.res1_proj = nn.Linear(input_dim, lstm_out_dim)
        else:
            self.res1_proj = nn.Identity()

        # 3. High-Capacity Channel Mixing (Weight-Norm FFN)
        ffn_inner_dim = lstm_out_dim * expansion_factor
        self.ffn = nn.Sequential(
            weight_norm(nn.Linear(lstm_out_dim, ffn_inner_dim)),
            nn.GELU(),
            weight_norm(nn.Linear(ffn_inner_dim, lstm_out_dim)),
        )

        # 4. Residual 2
        self.dropout = nn.Dropout(dropout)

        lstm_input = torch.cat([x, physics_feats], dim=-1)

        # Channel Mixing
        ffn_out = self.ffn(res1)

class ContextInjectedResBlock(nn.Module):
    """
    Physics-Injected Residual Block with Pointwise FFN.
    Combines Deep Context Injection (Cite Lesson 00039) with decoupled
    temporal/channel mixing (Cite Lesson 00040).
    """

    def __init__(self, input_dim, hidden_dim, physics_dim, expansion_factor, dropout):
        super().__init__()

        # 1. Temporal Mixing: Bi-LSTM
        # Cite Lesson 00055: Do not bottleneck Bi-LSTM; allow 2*hidden output
        self.lstm = nn.LSTM(
            input_size=input_dim + physics_dim,
            hidden_size=hidden_dim,
            batch_first=True,
            bidirectional=True,
        )

        lstm_out_dim = 2 * hidden_dim

        # 2. Residual Connection 1 (LSTM)
        # Cite Lesson 00027: Projection Shortcuts for dimension mismatch
        if input_dim != lstm_out_dim:
            self.res1_proj = nn.Linear(input_dim, lstm_out_dim)
        else:
            self.res1_proj = nn.Identity()

        self.dropout1 = nn.Dropout(dropout)

        # 3. Channel Mixing: Pointwise FFN
        # Cite Lesson 00052: Modest expansion (2x) without normalization
        ffn_inner_dim = int(lstm_out_dim * expansion_factor)
        self.ffn = nn.Sequential(
            nn.Linear(lstm_out_dim, ffn_inner_dim),
            nn.GELU(),
            nn.Linear(ffn_inner_dim, lstm_out_dim),
        )

        self.dropout2 = nn.Dropout(dropout)

    def forward(self, x, physics_feats):
        # Deep Context Injection: Concatenate input with physics features
        # Cite Lesson 00035
        lstm_input = torch.cat([x, physics_feats], dim=-1)

        lstm_out, _ = self.lstm(lstm_input)

        # Residual 1: Additive with Dropout on branch (Cite Lesson 00024, 00044)
        x_res = self.res1_proj(x) + self.dropout1(lstm_out)

        # FFN
        ffn_out = self.ffn(x_res)

        # Residual 2
        out = x_res + self.dropout2(ffn_out)

        return out
