The issue is caused by the way `library/dataset.py` imports configuration variables. It uses `from library.config import DEBUG, DEBUG_SAMPLE_SIZE`, which binds the values of these variables (False and 1000) at the time of import. When `runfile.py` later modifies `config.DEBUG` and `config.DEBUG_SAMPLE_SIZE` to enable debug mode, `library/dataset.py` continues to use the stale, originally imported values, causing it to load the full dataset instead of the small sample required for the demo. This behavior is a variation of the early binding issue described in **Cite debug_lesson_1**.

To fix this, I will modify `library/dataset.py` to import the `library.config` module itself (`import library.config as config`) and access the variables via the module namespace (e.g., `config.DEBUG`). This ensures that the code looks up the current values of these variables at runtime, reflecting the changes made by `runfile.py`.
