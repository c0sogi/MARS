This script demonstrates the end-to-end usage of the provided Ventilator Pressure Prediction library. It performs the following steps:

1.  **Configuration Setup**: Overrides the default `Config` to enable `DEBUG` mode (using a small data subset) and reduces training epochs for rapid execution.
2.  **Data Preparation**: Uses `prepare_datasets` to engineer features and generate training tensors from the metadata.
3.  **Component Verification**:
    *   **Model**: Instantiates the `TransLSTM` model and verifies input/output shapes with a dummy batch.
    *   **Loss**: Validates the `MaskedL1Loss` logic to ensure it correctly ignores the expiratory phase.
4.  **Training & Inference**: Uses the `Trainer` class to train the model on the debug dataset and generate predictions for the test set.
5.  **Output Verification**: Asserts that the model checkpoint and submission files are correctly generated.
