# Proposed Strategy: Physics-Enhanced Hybrid CNN-LSTM with Robust Pipeline

This strategy evolves the baseline by introducing a hybrid architecture that combines local feature extraction with long-term temporal modeling, and by implementing a rigorous, physics-informed feature engineering pipeline designed to prevent the configuration drift observed in previous attempts.

### Model
The architecture moves from a pure RNN approach to a **Hybrid CNN-Bidirectional LSTM** with residual connections.
*   **Feature Extraction (CNN):** The input sequence first passes through a 1D Convolutional layer. This component is designed to capture local patterns and immediate derivatives in the control signals (like the sharp opening of the valve) more effectively than an LSTM alone.
*   **Temporal Dynamics (Residual Bi-LSTM):** The convolved features are fed into a stack of Bidirectional LSTM layers. To address the difficulty in modeling "stiff" lungs and prevent signal degradation in deeper networks, we introduce **residual connections** (skip connections) between the LSTM layers (adding the layer input to its output).
*   **Head:** A final fully connected layer projects the hidden states to the scalar `pressure` prediction.

### Data
To address the "Stale Artifacts" failure where new features were ignored, the data pipeline is fundamentally restructured to link cache validity to the feature configuration.
*   **Physics-Informed Feature Engineering:** We will explicitly engineer features that represent the physical state of the lung, which the model previously had to infer:
    *   **Cumulative Volume:** The cumulative sum of `u_in` (scaled by time delta), representing the total air volume in the lung.
    *   **Dynamics:** First and second-order differences of `u_in` and `u_in` lag features to capture valve acceleration.
    *   **Interaction Terms:** Explicit interactions between control inputs and lung attributes (e.g., `u_in * R`).
*   **Categorical Embeddings:** `R` and `C` will be treated as categorical variables (one-hot encoded) rather than continuous scalars, allowing the model to learn distinct behaviors for each lung setting rather than assuming a linear relationship.
*   **Robust Caching:** The caching mechanism will generate filenames based on a hash of the active feature list and configuration parameters. This ensures that any change to the feature engineering logic automatically invalidates old data, preventing the silent failures observed previously (Cite solution_lesson_node_00002).
*   **Preprocessing:** Data will be reshaped into sequences of shape `(N_breaths, 80, N_features)` and normalized using a `RobustScaler`.

### Training
*   **Loss Function:** We retain the **Masked L1 Loss** (Mean Absolute Error). The loss will be calculated for the entire sequence but multiplied element-wise by `(1 - u_out)` before averaging. This ensures the optimizer focuses exclusively on the inspiratory phase, preventing the model from wasting capacity on the irrelevant expiratory phase (Cite solution_lesson_node_00001).
*   **Optimization:** We will use the AdamW optimizer with a `OneCycleLR` scheduler to ensure fast convergence and regularization.
*   **Regularization:** Dropout will be applied within the LSTM layers to prevent overfitting on the training breath sequences.

### Evaluation
*   **Inference:** The test data will be processed through the same hashed caching and feature engineering pipeline to ensure consistency.
*   **Prediction:** The model will predict pressure sequences for the test set batches. These will be flattened and mapped to the submission format `id`, ensuring the order aligns perfectly with the provided `test.csv`.
