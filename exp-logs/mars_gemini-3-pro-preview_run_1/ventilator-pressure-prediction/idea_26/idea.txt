# Proposed Strategy: Wide-Projected Deeply-Supervised Physics-Identity Network

This strategy synthesizes the critical insights regarding **State Capacity** (Cite solution_lesson_node_00055), **Initialization Stability** (Cite solution_lesson_node_00073), and **Physics Fidelity** (Cite solution_lesson_node_00090). It resolves the conflict between the need for a "Wide-State" representation and the instability of "Bottleneck-to-Wide" expansions by implementing a **Projected Backbone Topology**. This ensures the recurrent layers operate at full capacity (1024 dim) with strict identity residuals, while the stem remains compressed to filter noise.

### Model
The architecture is a **Wide-Projected Deeply-Supervised Physics-Identity Network**. It separates the feature extraction dimension ($D_{stem}=512$) from the latent modeling dimension ($D_{model}=1024$) via a dedicated adapter, enabling a uniform, high-capacity backbone.

*   **Stem (Mixed Multi-Scale Initialization):** The input sequence—explicitly including `u_out` (Cite solution_lesson_node_00086)—is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. The concatenated output is immediately processed by a **Linear Projection** to mix features into a unified **Bottleneck Dimension of 512** (Cite solution_lesson_node_00084). This compressed initialization filters high-frequency noise (Cite solution_lesson_node_00073).
*   **Wide Projection Adapter:** A simple learnable **Linear Layer** projects the 512-dim stem output to the **Model Dimension of 1024**. This one-time projection transitions the signal to the high-capacity space *before* entering the recurrent backbone, avoiding the instability of expanding dimensions within the LSTM blocks (Cite solution_lesson_node_00027, Cite solution_lesson_node_00085).
*   **Backbone (Uniform Wide-State Identity Blocks):** The core consists of a stack of **4 Composite Blocks** operating uniformly at $D_{model}=1024$.
    1.  **Explicit Context Injection:** The input to the recurrent layer is formed by concatenating the block input $x$ ($1024$) with a **Curated Context Vector**. This vector contains **only** raw Static Attributes ($R, C$) and **Derived Physics Interactions** ($R \cdot u_{in}$, $Volume / C$). We explicitly inject these terms to relieve the network of learning arithmetic (Cite solution_lesson_node_00076), while strictly excluding dynamic noise like lags (Cite solution_lesson_node_00066). We use explicit concatenation, not learned projections (Cite solution_lesson_node_00090).
    2.  **Wide-State Bi-LSTM:** A Bidirectional LSTM processes the concatenated input. We set the hidden dimension to **512 per direction**, resulting in a natural output dimension of **1024**. This matches the block input exactly, preventing the information bottleneck observed when compressing Bi-LSTMs (Cite solution_lesson_node_00055).
    3.  **Strict Identity Residual 1:** The residual connection is applied as $y = x + \text{Dropout}(\text{LSTM}(\dots))$. Since dimensions match perfectly (1024 -> 1024), we use a **Strict Identity Mapping** (no linear weights) on the skip connection. This creates a pristine gradient highway (Cite solution_lesson_node_00064).
    4.  **Pointwise Channel Mixing (FFN):** The output $y$ is passed through a **Pointwise Feed-Forward Network** (`Linear -> GELU -> Linear`) with an expansion factor of **2x** (2048 units). We avoid 4x expansion to maintain stability without normalization (Cite solution_lesson_node_00052).
    5.  **Strict Identity Residual 2:** A second identity residual is applied: $z = y + \text{Dropout}(\text{FFN}(y))$. We strictly **exclude Layer Normalization** to preserve the absolute pressure magnitude required for regression (Cite solution_lesson_node_00044).
*   **Deep Supervision:** An **Auxiliary Regression Head** is attached to the output of the **2nd Block**. This provides a gradient short-circuit to accelerate convergence (Cite solution_lesson_node_00039).
*   **Head:** A linear layer projects the output of the 4th Block to the final `pressure`.

### Data
The data pipeline is strictly engineered for **Physics Fidelity**, **Completeness**, and **Segregation**.

*   **Feature Completeness:** We explicitly **include `u_out`** in the input feature set. Even though the metric ignores the expiratory phase, the Bi-LSTM requires this state to model the sequence coherence and backward pass dynamics (Cite solution_lesson_node_00086).
*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$ (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms (`u_in * R`, `volume / C`) as input features to the Stem (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` (Cite solution_lesson_node_00022).
*   **Control Segregation:** We maintain two copies of `u_out`. One is included in the model input. The other is kept as a **raw binary integer (0/1)** for the loss mask to ensure exact zeroing of the expiratory phase (Cite solution_lesson_node_00058).
*   **Preprocessing:** All continuous features are scaled using `RobustScaler`. Data is reshaped to `(N_breaths, 80, N_features)`.

### Training
*   **Loss Function:** Weighted **Masked L1 Loss** ($L_{total} = L_{final} + 0.3 \cdot L_{aux}$). The mask is calculated as `1 - u_out_raw` (Cite solution_lesson_node_00001).
*   **Optimizer:** **AdamW** with a **OneCycleLR** scheduler.
*   **Strict Gradient Clipping:** We enforce a gradient clipping threshold of **1.0**. This is a mandatory prerequisite for the convergence of the Wide-State LSTM backbone (Cite solution_lesson_node_00059).
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which is critical for solving the cumulative (elastic) dynamics of the system (Cite solution_lesson_node_00028).
*   **Update Budget:** Maintain a batch size of **512** (Cite solution_lesson_node_00019).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** Predictions are generated using only the **Final Head** (Block 4 output). The auxiliary head is discarded during inference. The output is flattened and mapped to the `id` column for submission.
