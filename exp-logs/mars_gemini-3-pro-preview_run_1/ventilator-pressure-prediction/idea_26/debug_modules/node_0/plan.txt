The following script demonstrates the end-to-end workflow for the Ventilator Pressure Prediction task using the provided library.

**Implementation Strategy:**
1.  **Configuration Setup**: We initialize the `Config` and override specific parameters (enabling `DEBUG` mode, reducing `EPOCHS` and `BATCH_SIZE`) to ensure the demonstration runs quickly (under 1 minute) while still executing the full pipeline.
2.  **Data Loading & Verification**: We utilize `prepare_data` to load the datasets. We explicitly fetch a batch from the training loader to assert the correctness of tensor shapes (Batch Size, Sequence Length, Feature Dimension) and data types.
3.  **Model Initialization & Forward Pass**: We instantiate the `WideProjectedNet` using feature metadata. We perform a dummy forward pass to verify that the model architecture accepts the input tensors and produces outputs of the expected shape.
4.  **Loss Function Verification**: We isolate the `MaskedHybridLoss` and `compute_metric` functions. We feed them synthetic data with known errors in specific phases (inspiratory vs. expiratory) to verify that the masking logic correctly ignores the expiratory phase as required by the competition metric.
5.  **Training Loop**: We instantiate the `Trainer` and run the `fit()` method for a single epoch. We verify that the model weights are saved to the working directory.
6.  **Inference & Submission**: We generate predictions using the trained model on the test set and verify that the submission file is generated with the correct format and number of rows.
