Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Calibrated Full-Fit ResNet-18 Ensemble with Deterministic Cosine-SWA**.

This solution represents a structural evolution of the training pipeline. It resolves the critical conflict between **Data Scarcity** (Lesson 00020) and **Optimization Stability** (Lessons 00055, 00107). Previous "Full-Fit" attempts failed because they either used reactive schedulers that malfunctioned without validation data (Trajectory Replay) or fixed schedulers that didn't match the model's convergence needs. This proposal introduces a **Deterministic Schedule Mapping Protocol** that translates the adaptive convergence trajectory found during cross-validation into a smooth, data-agnostic Cosine schedule for the final production training on 100% of the dataset.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001). We avoid complex gating mechanisms (Cite solution_lesson_node_00082).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline:
    *   **Discrete:** `RandomRotate90` to ensure closure over cardinal axes (Cite solution_lesson_node_00028).
    *   **Continuous:** `ShiftScaleRotate` ($\pm 20^{\circ}$) to smooth the decision boundary (Cite solution_lesson_node_00031).
    *   **Flips:** Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Schedule-Mapped Protocol** to ensure optimal convergence on the full dataset.

**Phase 1: Calibration (Adaptive Trajectory Discovery)**
*   **Objective:** Determine the natural convergence epoch ($E_{conv}$) where the model stabilizes.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimizer:** **AdamW** with a low base learning rate of **2e-4** and `weight_decay=0.01` (Cite solution_lesson_node_00077).
*   **Scheduler:** `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**. This allows the model to find the optimal stopping point organically without premature freezing (Cite solution_lesson_node_00070, solution_lesson_node_00065).
*   **Selection:** Identify $E_{conv}$ as the epoch that minimizes the **TTA-Validation Loss** (average of Original + Flips) (Cite solution_lesson_node_00025, solution_lesson_node_00040).

**Phase 2: Production (Deterministic Cosine-SWA Full-Fit)**
*   **Objective:** Train 5 independent models on **100% of the training data** (Train + Validation combined).
*   **Schedule Mapping (Structural Innovation):** Instead of using the plateau scheduler (which fails without a validation set) or replaying specific milestones (which are noisy), we map the trajectory to a **Cosine Annealing Schedule**.
    *   Configure `CosineAnnealingLR` with $T_{max} = E_{conv}$, starting at `2e-4` and decaying to the target SWA learning rate (e.g., `1e-5`).
    *   **Rationale:** This forces the model to follow the exact convergence duration discovered in Phase 1 but uses a smooth, deterministic curve that guarantees the model lands in the correct state for SWA (Cite solution_lesson_node_00107).
*   **SWA Phase:** Immediately continue training for 12 additional epochs using **Stochastic Weight Averaging (SWA)** with a constant learning rate of `1e-5`. This ensures a smooth transition without the "shock" of hard resets (Cite solution_lesson_node_00090, solution_lesson_node_00049).
*   **Loss:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) (Cite solution_lesson_node_00065).

# Evaluation
*   **Exhaustive Closed-Group TTA:** For every test image, we will generate predictions using the **Klein Four-Group**: Original, Horizontal Flip, Vertical Flip, and Rotate180. This ensures the prediction is mathematically invariant to cardinal symmetries (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SWA models**.
