Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Continuous SAM-SWA ResNet-18 with Adaptive GeM Pooling**.

This solution represents a structural synthesis of three powerful components that have individually shown promise or theoretical merit but failed due to specific implementation flaws identified in the lessons: **Adaptive GeM Pooling** (failed due to low patience), **Sharpness-Aware Minimization (SAM)** (failed due to state/checkpoint mismatches), and **Stochastic Weight Averaging (SWA)** (failed due to scheduler incompatibility). By integrating them into a rigorous **Continuous Full-Fit Pipeline**, this strategy addresses the "Data Scarcity vs. Generalization" trade-off without the pitfalls of previous iterations.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Adaptive GeM Pooling (Structural Innovation):** We will replace the standard Global Average Pooling (GAP) with **Generalized Mean (GeM) Pooling**, defined as $f = (\frac{1}{N} \sum x^p)^{1/p}$.
    *   **Initialization:** We will explicitly initialize the learnable parameter $p=1$. This starts the model in the "Average Pooling" regime, which is robust to speckle noise (Cite solution_lesson_node_00019).
    *   **Adaptation:** By allowing $p$ to be learnable, the model can adaptively shift towards Max Pooling behavior ($p > 1$) to capture high-intensity targets (icebergs) only if the signal-to-noise ratio permits. This resolves the conflict between signal detection and noise suppression (Cite solution_lesson_node_00016). We correct the previous failure of this component by pairing it with a high-patience scheduler (Cite solution_lesson_node_00070).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the pooled feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline including **RandomRotate90** (Discrete) and **ShiftScaleRotate** (Continuous $\pm 20^{\circ}$) (Cite solution_lesson_node_00028, solution_lesson_node_00031). We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Continuous Protocol** using the **SAM Optimizer**.

**Phase 1: Calibration (Global Epoch Selection)**
*   **Objective:** Determine the optimal convergence epoch ($E_{conv}$) and the **Final Learning Rate** ($LR_{final}$).
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimizer:** **SAM (Sharpness-Aware Minimization)** wrapping **AdamW** (`lr=2e-4`, `weight_decay=0.01`). SAM performs dual forward/backward passes to minimize loss sharpness (Cite solution_lesson_node_00089).
*   **Scheduler:** `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**.
    *   **Rationale:** The gentle decay ensures the learning rate remains high enough (e.g., stopping at `2.5e-5` rather than `1e-6`) to support the subsequent SWA phase (Cite solution_lesson_node_00090). The high patience prevents premature decay due to noise (Cite solution_lesson_node_00070).
*   **Selection:** Identify $E_{conv}$ as the epoch that minimizes the **TTA-Validation Loss** (Cite solution_lesson_node_00025).

**Phase 2: Production (Continuous SAM-SWA)**
*   **Objective:** Train 5 independent models on **100% of the training data**.
*   **Continuous Trajectory:** Train from scratch using SAM for exactly $E_{conv}$ epochs.
*   **Seamless Transition (Structural Innovation):** Immediately transition to **Stochastic Weight Averaging (SWA)** for an additional 12 epochs.
    *   **Crucial Fix:** We will **not** reload checkpoints (avoiding optimizer state mismatch, Cite solution_lesson_node_00089). We will set the SWA learning rate to be **equal to** the $LR_{final}$ determined in Phase 1. This prevents the "shock" of resetting the learning rate, ensuring the model stays in the flat minimum found by SAM (Cite solution_lesson_node_00090).
*   **Loss Function:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) (Cite solution_lesson_node_00065).

# Evaluation
*   **Exhaustive Closed-Group TTA:** For every test image, we will generate predictions using the **Klein Four-Group**: Original, Horizontal Flip, Vertical Flip, and Rotate180. This ensures the prediction is mathematically invariant to cardinal symmetries (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SAM-SWA models**.
