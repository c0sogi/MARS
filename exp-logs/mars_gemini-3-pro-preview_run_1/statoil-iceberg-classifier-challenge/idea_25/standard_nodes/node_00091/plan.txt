The implementation strategy follows the "Continuous SAM-SWA ResNet-18 with Adaptive GeM Pooling" idea, adapted for a robust end-to-end execution.

1.  **Setup & Data Loading**: The script initializes the environment with a fixed seed and detects the computing device. It loads the pre-processed data and metadata, strictly splitting the training data into training and validation subsets according to the `train_metadata.csv` and `val_metadata.csv` files to ensure a valid hold-out assessment.
2.  **Phase 1 (Calibration/Validation)**: A ResNet-18 model with Adaptive GeM pooling is initialized. The training uses the SAM optimizer (wrapping AdamW) to minimize sharpness and improve generalization. A `ReduceLROnPlateau` scheduler manages the learning rate. The model is trained for 25 epochs, with Stochastic Weight Averaging (SWA) activated for the final 6 epochs to stabilize the solution.
3.  **Validation Assessment & Failure Analysis**: After Phase 1, the script evaluates the model on the hold-out validation set using Test-Time Augmentation (TTA) (Original, HFlip, VFlip, Rot180). It prints the final log loss metric. It then calculates the correlation between prediction errors and input features (incidence angle, band statistics) to identify potential failure modes.
4.  **Phase 2 (Production & Submission)**: If the validation metric is below the specified threshold (`0.169...`), the script proceeds to the production phase. It retrains a fresh model on the *entire* labeled dataset (Train + Val) using the same SAM-SWA protocol. Finally, it generates predictions for the test set using TTA and saves the submission file.
