Based on the comprehensive analysis of previous attempts and the derived lessons, I propose a **Stratified ResNet-34 Ensemble with Calibrated Regularization**. This solution structurally evolves the approach by moving from a single point-estimate model (Idea 2) to a robust probabilistic ensemble, while explicitly reverting the backbone choice from the failed EfficientNet (Idea 3) back to a Dense Convolutional architecture, scaled up to ResNet-34.

# Model
The architecture is designed to prioritize robust feature extraction from noisy radar data while integrating metadata context.

*   **Backbone Architecture:** We will employ a **ResNet-34** pretrained on ImageNet. This represents a structural upgrade in capacity over the ResNet-18 (Idea 2) while strictly adhering to the finding that **standard dense convolutions** are superior to depthwise separable convolutions (like EfficientNet) for small, noisy radar datasets (Cite solution_lesson_node_00008).
*   **Input Representation:** The network will accept a **3-channel composite image** formed by stacking Band 1 (HH), Band 2 (HV), and their arithmetic mean. This explicitly encodes inter-band correlation.
*   **Late Fusion Strategy:** We will retain the **Late Fusion** mechanism. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional feature vector extracted by the ResNet-34's Global Average Pooling layer. This allows the dense head to calibrate visual features based on the viewing geometry (Cite solution_lesson_node_00001).
*   **Classification Head:** The fused vector will pass through a block consisting of Batch Normalization, Dropout (rate 0.5), and a final Dense layer.

# Data
*   **Upsampling:** To leverage the pretrained ResNet-34 filters effectively, the native 75x75 images will be **upsampled to 224x224** using bicubic interpolation (Cite solution_lesson_node_00004).
*   **Preprocessing:** Pixel values (dB) will be Min-Max scaled to the [0, 1] range. Missing `inc_angle` values will be imputed with the training set mean.
*   **Augmentation:** We will apply **aggressive geometric augmentation**, including Random Horizontal/Vertical Flips, Rotations, and Translations. We explicitly prioritize these input-space transformations over pure output-space regularization to force the model to learn spatial invariances, correcting the under-augmentation observed in Idea 3 (Cite solution_lesson_node_00006).

# Training
*   **Pipeline Structure:** We will implement **Stratified 5-Fold Cross-Validation**. Five independent ResNet-34 models will be trained on distinct data splits. This ensemble structure directly addresses the high variance inherent in the small dataset.
*   **Objective Function:** We will use **BCEWithLogitsLoss** combined with **Label Smoothing** ($\epsilon=0.05$). This prevents the model from becoming overconfident on the training data, improving probability calibration for the Log Loss metric (Cite solution_lesson_node_00005).
*   **Optimizer:** We will use **AdamW** with a significant `weight_decay` of **0.01**. This corrects the previous implementation where decoupled weight decay was too weak to provide effective regularization (Cite solution_lesson_node_00007).
*   **Scheduling:** We will employ a **ReduceLROnPlateau** scheduler with an aggressive decay factor (e.g., **0.1**) and a low base learning rate (e.g., `1e-4`). This ensures the model settles into sharp local minima, avoiding the optimization instability observed with gentle decay schedules (Cite solution_lesson_node_00011).
*   **Checkpointing:** For each fold, we will save the model weights using `copy.deepcopy()` at the epoch with the lowest validation loss to ensure the restored state is immutable and correct (Cite solution_lesson_node_00002).

# Evaluation
*   **Test Time Augmentation (TTA):** During inference, we will generate predictions for the original test image and its horizontally/vertically flipped versions. These probabilities will be averaged to smooth out noise (Cite solution_lesson_node_00005).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from all **5 models** in the Stratified K-Fold ensemble.
