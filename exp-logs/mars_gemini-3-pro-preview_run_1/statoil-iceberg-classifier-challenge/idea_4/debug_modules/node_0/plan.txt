This script demonstrates the end-to-end workflow for the Iceberg Classification task using the provided library. It performs the following steps:

1.  **Configuration**: Overrides default `Config` settings to run a fast demonstration (reduced epochs and folds, specific working directory).
2.  **Data Processing**: Loads raw JSON data, processes it into numpy arrays (stacking bands, normalizing angles), and validates the shapes and integrity of the data.
3.  **Model Verification**: Instantiates the `IcebergResNet34` model and performs a dummy forward pass to ensure the architecture and tensor shapes are correct.
4.  **Training**: Executes the training pipeline for 2 folds (1 epoch each) to demonstrate the training loop and model checkpointing.
5.  **Inference**: Uses the trained models to generate predictions on the test set using Test Time Augmentation (TTA), creates a submission file, and validates its format.
