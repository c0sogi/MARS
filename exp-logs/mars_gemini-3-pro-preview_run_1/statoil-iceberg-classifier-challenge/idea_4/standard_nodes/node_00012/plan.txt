The implementation strategy follows a robust Stratified K-Fold Cross-Validation approach using a ResNet-34 backbone.

1.  **Setup & Configuration**: We initialize the environment with a fixed random seed and detect the available device (GPU). We override the `Config.NUM_EPOCHS` to 20 to ensure the training completes quickly while still allowing convergence for this small dataset.
2.  **Training & OOF Generation**: We iterate through 5 stratified folds. For each fold, we train the model using `run_fold`, which handles the training loop, validation monitoring, and checkpointing of the best model. Immediately after training, we load the best checkpoint and perform inference on the fold's validation set to collect Out-Of-Fold (OOF) predictions, targets, and metadata (incidence angles).
3.  **Global Validation**: We aggregate the OOF predictions from all folds and calculate the global Log Loss metric. This provides a reliable estimate of the model's generalization performance.
4.  **Failure Analysis**: We calculate the absolute error for each sample and compute the Pearson correlation coefficient between the error magnitude and the incidence angle. This helps identify if the model struggles with specific viewing geometries.
5.  **Submission**: If the final validation metric is below the specified threshold, we generate the submission file by running the ensemble of 5 models on the test set with Test Time Augmentation (TTA).
