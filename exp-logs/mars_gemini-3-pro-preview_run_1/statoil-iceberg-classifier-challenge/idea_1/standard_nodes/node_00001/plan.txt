### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` object, overriding the default `NUM_EPOCHS` to 25 to ensure a fast baseline execution as requested. Set random seeds using the provided `set_seeds` function to guarantee reproducibility.
2.  **Data Loading**: Use `get_dataloaders(load_cached_data=True)` to load the pre-processed training, validation, and test datasets. This leverages the caching mechanism implemented in the library for speed.
3.  **Training**: Call `train_model` to train the `CompositeCNN`. This function manages the training loop, optimizer, and early stopping, returning the model with the best validation weights.
4.  **Validation & Metric**: Switch the model to evaluation mode and iterate through the validation loader. Compute the Log Loss (Binary Cross-Entropy) on the entire validation set and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: While iterating through the validation set, collect predictions, targets, and input features (incidence angle, image pixel mean, image pixel std). Calculate the absolute error magnitude for each sample. Compute and print the correlation between the error magnitude and these features to identify potential sources of systematic error.
6.  **Submission**: Invoke `generate_submission` with the best model and the test loader to generate predictions and save the `submission.csv` file.
