Implementation Strategy:
1.  **Setup & Imports**: Configure the system path to ensure the provided `library` modules can be imported. Set random seeds for reproducibility.
2.  **Data Loading Verification**:
    *   Initialize the `Config` object.
    *   Call `get_dataloaders` with `load_cached_data=False` to trigger the raw data processing and cache generation pipeline.
    *   Retrieve a single batch from the training loader.
    *   Assert that the shapes of images, angles, and labels match the expected dimensions (Batch Size, Channels, Height, Width).
    *   Verify that image data is normalized (float32) and angles are present.
3.  **Model Verification**:
    *   Instantiate the `CompositeCNN` model.
    *   Perform a forward pass using the batch retrieved in the previous step.
    *   Assert that the output shape is `(Batch Size, 1)` and that values fall within the probability range `[0, 1]`.
4.  **Training Pipeline Verification**:
    *   Execute `run_training` with a minimal configuration: 1 epoch, a small batch size (e.g., 4), and a limit on samples (e.g., 20) to ensure immediate completion.
    *   Verify that the model checkpoint (`best_model.pth`) and submission file (`submission.csv`) are generated.
    *   Validate the structure of the generated submission file.
5.  **Inference Pipeline Verification**:
    *   Execute the `predict` function with a small subset of samples.
    *   Verify that a new submission file is generated and contains the expected number of rows corresponding to the `max_samples` limit.
