The strategy involves parsing the provided JSON files (`train.json` and `test.json`) to extract tabular metadata (ID, incidence angle, and labels) while excluding the high-dimensional image band data to adhere to the requirement of not copying raw data. A `sample_index` will be created to map each metadata entry back to its specific position in the original JSON file, enabling efficient random access. The training data will be split into training and validation sets using an 80:20 ratio with stratified sampling on the `is_iceberg` target variable to ensure distribution consistency. Finally, the script will validate the generated metadata by checking file path existence, confirming the split ratio, and verifying the stratification.
