This script demonstrates the end-to-end workflow for the Iceberg Classification task using the provided library components.

**Strategy Outline:**
1.  **Setup**: Initialize the environment, set random seeds for reproducibility, and configure the computing device (CPU/GPU).
2.  **Data Preparation**: Load the dataset using `load_data_splits`. To ensure the demonstration runs quickly, we create small subsets (64 training samples, 32 validation/test samples) and wrap them in the `IcebergDataset` class with appropriate transformations.
3.  **Model Training**: Initialize the `IcebergResNet` model. Execute a short training loop (2 epochs) using `train_one_epoch` and `evaluate` to verify the optimization process and loss calculation.
4.  **SWA (Stochastic Weight Averaging)**: Demonstrate how to wrap the model in an SWA container and update its Batch Normalization statistics using `update_swa_bn`.
5.  **Inference & Submission**: Generate predictions on the test subset using Test-Time Augmentation (TTA) via `generate_submission` and verify the output CSV format.
6.  **Pseudo-Labeling**: Simulate an ensemble scenario by saving model checkpoints. Calculate prediction statistics (mean/std) using `generate_ensemble_stats`, filter for high-confidence samples using `filter_pseudo_labels`, and extract the corresponding data for self-training using `extract_pseudo_dataset`.
