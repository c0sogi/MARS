This solution represents a structural evolution that revisits the **Semi-Supervised Learning (SSL)** approach attempted in Ideas 14 and 16. It directly addresses the "Data Scarcity" bottleneck (Lesson 00020) by leveraging unlabeled test data. Crucially, it succeeds where previous attempts failed by strictly enforcing the **Robust Optimization Protocols** identified in Lessons 00065, 00070, and 00077 to ensure the "Teacher" ensemble is stable and accurate, preventing the "noisy pseudo-label" failure mode described in Lesson 00053.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline including **RandomRotate90** (Discrete) and **ShiftScaleRotate** (Continuous $\pm 20^{\circ}$) (Cite solution_lesson_node_00028, solution_lesson_node_00031). We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Stage Semi-Supervised Protocol** that prioritizes teacher stability.

**Stage 1: Teacher Ensemble (Robust SWA)**
*   **Calibration (Global Epoch Selection):** Run **Stratified 5-Fold Cross-Validation** to determine the optimal convergence epoch ($E_{conv}$).
    *   **Optimizer:** **AdamW** with a low learning rate of **2e-4** and `weight_decay=0.01` (Cite solution_lesson_node_00077, solution_lesson_node_00007).
    *   **Scheduler:** `ReduceLROnPlateau` with **Factor=0.5** (Gentle Decay) and **Patience=10** (High Patience). This explicitly corrects the premature convergence issues caused by aggressive scheduling in previous SSL attempts (Cite solution_lesson_node_00065, solution_lesson_node_00070).
    *   **Loss:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) to prevent overfitting (Cite solution_lesson_node_00065).
    *   **Selection:** Identify $E_{conv}$ based on the minimum **TTA-Validation Loss** (Cite solution_lesson_node_00025).
*   **Production:** Train **5 independent models** on **100% of the labeled data** for $E_{conv}$ epochs, followed by 12 epochs of **Stochastic Weight Averaging (SWA)** (Cite solution_lesson_node_00049, solution_lesson_node_00055).

**Stage 2: Student Ensemble (Self-Training)**
*   **Pseudo-Labeling:** Generate predictions on the **Test Set** using the Stage 1 Teacher Ensemble with **4-View Closed-Group TTA** (Cite solution_lesson_node_00074).
*   **Variance Filtering:** Select samples that meet strict criteria: **High Confidence** ($p>0.95$ or $p<0.05$) AND **Low Variance** (StdDev across ensemble members $< 0.02$). This ensures the students only learn from stable, agreed-upon predictions (Cite solution_lesson_node_00053).
*   **Retraining:** Train **5 new independent SWA models** on the **Combined Dataset** (Labeled + Pseudo-Labeled).
    *   **Gradient Volume Scaling:** We will scale the number of training epochs proportionally to the increase in dataset size to ensure the total number of gradient steps remains consistent with the calibrated optimal volume (Cite solution_lesson_node_00038).

# Evaluation
*   **Exhaustive Closed-Group TTA:** For every test image, we will generate predictions using the **Klein Four-Group**: Original, Horizontal Flip, Vertical Flip, and Rotate180 (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Stage 2 (Student) models**.
