Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **SWA-ResNet Ensemble with Adaptive GeM Pooling and TTA-Aware Calibration**.

This solution structurally evolves the successful **SWA Ensemble** (Idea 13) by introducing **Adaptive Generalized Mean (GeM) Pooling**. This architectural innovation directly addresses the conflict between **Lesson 00016** (Max Pooling captures bright targets) and **Lesson 00019** (Max Pooling amplifies speckle noise) by allowing the network to learn the optimal spatial aggregation strategy. It wraps this new architecture in the robust, fully-calibrated training pipeline established in Idea 13.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Adaptive GeM Pooling (Structural Innovation):** We will replace the standard Global Average Pooling (GAP) layer with a **Generalized Mean (GeM) Pooling** layer, defined as $f = (\frac{1}{N} \sum x^p)^{1/p}$.
    *   **Rationale:** We will initialize the learnable parameter $p=1$ (equivalent to Average Pooling). This initializes the model in the safe, noise-robust regime identified as superior in **Lesson 00019**. However, unlike fixed GAP, the network can learn to increase $p$ during training to emphasize high-intensity features (approaching Max Pooling behavior) only if they are discriminative enough to overcome the speckle noise. This resolves the trade-off between signal detection and noise suppression (Cite solution_lesson_node_00016).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the pooled feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline including **RandomRotate90** and **Continuous Rotation** ($\pm 20^{\circ}$) (Cite solution_lesson_node_00028, solution_lesson_node_00031). We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Protocol** that combines TTA-Aware Calibration with SWA.

**Phase 1: Calibration (Global Epoch Selection)**
*   **Objective:** Determine the optimal convergence epoch ($E_{conv}$) for the GeM-equipped architecture.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimization:** Use **AdamW** (`weight_decay=0.01`) with a **Gentle Scheduler** (`ReduceLROnPlateau`, factor 0.5) and **Label Smoothing** (0.05). This ensures prolonged, stable convergence without the premature freezing caused by aggressive decay (Cite solution_lesson_node_00065, solution_lesson_node_00009).
*   **Stopping Criterion:** Identify $E_{conv}$ as the epoch that minimizes the **TTA-Validation Loss** (average across folds using lightweight TTA). This ensures the training duration is optimized for the final inference strategy, not just single-crop performance (Cite solution_lesson_node_00025). We will enforce a minimum burn-in period to avoid premature SWA initialization (Cite solution_lesson_node_00063).

**Phase 2: Production (Full-Fit SWA)**
*   **Objective:** Train 5 independent models on **100% of the training data** (Train + Validation combined).
*   **Standard Stage:** Train for $E_{conv}$ epochs using the hyperparameters and scheduler dynamics derived from Phase 1.
*   **SWA Stage:** Continue training for an additional 12 epochs using **Stochastic Weight Averaging (SWA)** with a constant learning rate. This allows the model to settle into the flat center of the loss basin, maximizing generalization (Cite solution_lesson_node_00049, solution_lesson_node_00055).

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views (Cite solution_lesson_node_00031).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SWA models**.
