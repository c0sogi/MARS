Based on the comprehensive analysis of previous attempts and the derived lessons, I propose the **Stratified Dual-Stream ResNet-18 Ensemble with Adaptive Normalization**.

This solution structurally evolves the approach by combining the superior feature extraction architecture of Idea 5 (Dual-Stream Pooling) with the robust data preprocessing paradigm of Idea 2 (Adaptive Normalization), while wrapping the entire solution in a Stratified K-Fold pipeline to ensure statistical reliability.

# Model
The model architecture is designed to maximize signal detection in noisy SAR imagery while maintaining the stability of dense convolutions.

*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We explicitly select this shallow, dense-convolutional backbone over deeper variants (ResNet-34) or depthwise-separable architectures (EfficientNet) to avoid optimization instability and hyperparameter sensitivity on this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Dual-Stream Pooling (Structural Innovation):** We will replace the standard Global Average Pooling (GAP) layer with a **Dual-Stream Pooling** mechanism. This layer computes both the **Global Average** (to smooth noise) and the **Global Maximum** (to capture peak intensity "bright spots" typical of hard targets like ships/icebergs) of the feature maps. These two vectors will be concatenated to form a robust feature representation (Cite solution_lesson_node_00016).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the Dual-Stream feature vector. This allows the classifier to condition its decision boundary on the viewing geometry (Cite solution_lesson_node_00001).
*   **Classification Head:** The fused vector will pass through a Batch Normalization layer, a **Dropout layer (rate 0.5)** to prevent overfitting during fine-tuning (Cite solution_lesson_node_00011), and a final Dense layer.

# Data
*   **Adaptive Per-Sample Normalization:** We will strictly implement **Per-Sample Min-Max Scaling**. We explicitly reject the "Fixed Global Normalization" attempted in Idea 5, as failure analysis showed it degraded performance on low-contrast images. Each image will be independently scaled to [0, 1] based on its own minimum and maximum values to maximize local contrast (Cite solution_lesson_node_00018).
*   **Input Construction:** We will construct a **3-channel composite image** using Band 1 (HH), Band 2 (HV), and their arithmetic mean.
*   **Upsampling:** The native 75x75 images will be **upsampled to 224x224** using bicubic interpolation to leverage the pretrained filters of the ResNet backbone (Cite solution_lesson_node_00004).
*   **Augmentation:** We will employ **Input-Space Augmentation** (Random Horizontal Flips, Random Vertical Flips, and Random Rotations). We prioritize these geometric transformations to teach spatial invariance, which is more effective than pure output regularization on small datasets (Cite solution_lesson_node_00006).

# Training
*   **Pipeline Strategy:** We will implement **Stratified 5-Fold Cross-Validation**. This ensures that our performance metrics are robust to random data splits, addressing the "deceptive stability" of single-split validation (Cite solution_lesson_node_00018).
*   **Optimizer:** We will use **AdamW** with a `weight_decay` of **0.01**. This corrects the under-regularization observed when using default Adam settings or low decay values (Cite solution_lesson_node_00007).
*   **Scheduling:** We will employ a **ReduceLROnPlateau** scheduler with an **aggressive decay factor of 0.1** and a conservative base learning rate (e.g., `1e-4`). This ensures the model settles into sharp local minima without the oscillation caused by gentle decay schedules (Cite solution_lesson_node_00009, solution_lesson_node_00011).
*   **Objective Function:** We will use **BCEWithLogitsLoss** combined with **Label Smoothing ($\epsilon=0.05$)**. This prevents overconfidence and improves probability calibration for the Log Loss metric (Cite solution_lesson_node_00005).
*   **Checkpointing:** For each fold, we will save the model weights using `copy.deepcopy()` at the epoch with the lowest validation loss to ensure the restored state is immutable and correct (Cite solution_lesson_node_00002).

# Evaluation
*   **Test Time Augmentation (TTA):** During inference, we will generate predictions for the original test image and its horizontally/vertically flipped versions. These probabilities will be averaged to smooth out noise and improve calibration (Cite solution_lesson_node_00005).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from all **5 independent models** trained in the cross-validation loop.
