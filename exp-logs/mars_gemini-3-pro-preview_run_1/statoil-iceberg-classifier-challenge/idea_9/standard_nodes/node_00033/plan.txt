The implementation strategy follows a strict two-stage Knowledge Distillation pipeline designed to maximize data efficiency while retaining the robustness of an ensemble.

1.  **Data Preparation**: We first load the complete labeled dataset and split it into a "Training" set and a "Validation" set based on the provided metadata CSVs. This ensures we have a pristine hold-out set for the final metric calculation, strictly adhering to the task requirements.
2.  **Stage 1 (Teacher Ensemble)**: We perform Stratified 5-Fold Cross-Validation on the "Training" split. In each fold, we train a ResNet-18 model and generate predictions for the validation fold. These Out-Of-Fold (OOF) predictions are aggregated to form a set of "soft targets" for the entire training split. These soft targets capture the ensemble's knowledge (dark knowledge).
3.  **Stage 2 (Student Distillation)**: We initialize a fresh ResNet-18 "Student" model and train it on the full "Training" split. The loss function is a linear combination of the standard Binary Cross Entropy (against hard ground truth labels) and the KL Divergence (against the Teacher's soft targets). This allows the student to learn from the full dataset while being regularized by the teacher's probability distribution.
4.  **Evaluation & Submission**: We evaluate the Student model on the hold-out "Validation" set using Test Time Augmentation (TTA). We compute the final log loss and perform failure analysis by correlating errors with input features. If the performance meets the threshold, we generate the final submission using TTA on the test set.
