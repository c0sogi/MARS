The following script demonstrates the end-to-end pipeline for the iceberg classification task using the provided library. It covers data processing, model instantiation, the two-phase training strategy (Calibration & Production), and inference.

To ensure the demonstration runs quickly within the time limit, the script overrides several hyperparameters in the `Config` class (e.g., reducing epochs, folds, and ensemble size). It includes assertions at key steps to validate the logic and correctness of the data shapes and outputs.
