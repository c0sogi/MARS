The issue is caused by a mismatch between the keys in the saved checkpoint and the model architecture used for inference. The training process uses `torch.optim.swa_utils.AveragedModel`, which wraps the base model and prefixes all parameter keys with `module.` (e.g., `module.features...`). However, the inference script initializes the base `AngleGatedResNet` directly, which expects keys without this prefix. To fix this, I will modify `library/engine.py` to save the `state_dict` of the underlying unwrapped model (`swa_model.module`) instead of the wrapper itself.
