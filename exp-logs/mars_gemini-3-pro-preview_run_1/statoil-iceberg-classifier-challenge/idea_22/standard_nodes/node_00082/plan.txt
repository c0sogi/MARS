Here is the implementation plan and the `runfile.py` script.

### Implementation Plan

1.  **Configuration Setup**: Import the `Config` class and override specific hyperparameters (Epochs, Patience, Folds) to ensure the script runs within the "Fast Baseline" time constraints while still providing meaningful results.
2.  **Phase 1 (Calibration)**: Execute `Engine.find_optimal_epoch()` to determine the optimal number of training epochs using Cross-Validation.
3.  **Verification & Analysis**:
    *   Train a single `AngleGatedResNet` model using the fixed training split (from metadata) for the determined optimal epochs + SWA epochs.
    *   Evaluate this model on the fixed validation split to compute the **Final Validation Metric** (Log Loss).
    *   Perform **Failure Analysis** by calculating the correlation between the prediction error and input features (Incidence Angle, Band Statistics) on the validation set.
4.  **Phase 2 (Production) & Submission**:
    *   Check if the validation metric is below the specified threshold (`0.16918645240183008`).
    *   If successful, execute `Engine.train_full_fit_swa()` to train the ensemble on the full dataset (Train + Val).
    *   Generate the `submission.csv` using `inference.generate_submission()`.
