Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Isovariant SWA-ResNet Ensemble with Deterministic Cosine Calibration**.

This solution introduces **Gradient-Isovariant Calibration** as the primary structural innovation. It resolves the "Translation Gap" identified in **Lesson 00038** and **Lesson 00106**—where optimal parameters derived from Cross-Validation (on 80% of the data) fail to map correctly to Production Training (on 100% of the data) because the total volume of gradient updates increases if epoch count remains fixed. By mathematically scaling the production training duration to match the calibrated gradient step volume, and coupling this with a **Deterministic Cosine-SWA** schedule (Lesson 00107), this strategy ensures the final models are perfectly aligned with the optimal convergence trajectory discovered during calibration.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation**. We explicitly reject Bilinear interpolation to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline that combines discrete and continuous transformations:
    *   **Discrete:** `RandomRotate90` to ensure closure over cardinal axes (Cite solution_lesson_node_00028).
    *   **Continuous:** `ShiftScaleRotate` ($\pm 20^{\circ}$) to smooth the decision boundary (Cite solution_lesson_node_00031).
    *   **Flips:** Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Gradient-Isovariant Protocol**.

**Phase 1: Calibration (Step Volume Discovery)**
*   **Objective:** Determine the optimal **Total Gradient Steps** required for convergence.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimizer:** **AdamW** with a low base learning rate of **2e-4** and `weight_decay=0.01` (Cite solution_lesson_node_00077).
*   **Scheduler:** `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**. This allows the model to find the optimal stopping point organically without premature freezing (Cite solution_lesson_node_00070, solution_lesson_node_00065).
*   **Selection:** Identify the epoch $E_{opt}$ that minimizes the **TTA-Validation Loss** (average of Original + Flips) (Cite solution_lesson_node_00025, solution_lesson_node_00040).

**Phase 2: Production (Isovariant Full-Fit)**
*   **Objective:** Train 5 independent models on **100% of the training data**.
*   **Isovariant Scaling (Structural Innovation):** Calculate the production epoch count $E_{prod} = \lceil E_{opt} \times 0.8 \rceil$. Since the full dataset is $1.25\times$ larger than the CV folds, scaling the epochs by $0.8$ ensures the **Total Gradient Updates** remains invariant ($1.25 \times 0.8 = 1.0$). This prevents the over-training that occurs when simply replaying $E_{opt}$ on the full set (Cite solution_lesson_node_00038, solution_lesson_node_00106).
*   **Deterministic Schedule:** Use `CosineAnnealingLR` with $T_{max} = E_{prod}$, decaying from `2e-4` to `1e-5`. This guarantees a smooth, deterministic trajectory to the SWA entry point, avoiding the noise of replaying reactive milestones (Cite solution_lesson_node_00107).
*   **SWA Phase:** Immediately continue training for 12 additional epochs using **Stochastic Weight Averaging (SWA)** with a constant learning rate of `1e-5`. This ensures a smooth transition without the "shock" of hard resets (Cite solution_lesson_node_00090, solution_lesson_node_00049).
*   **Loss:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$).

# Evaluation
*   **Exhaustive Closed-Group TTA:** For every test image, we will generate predictions using the **Klein Four-Group**: Original, Horizontal Flip, Vertical Flip, and Rotate180 (composed flips). This ensures the prediction is mathematically invariant to cardinal symmetries (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SWA models**.
