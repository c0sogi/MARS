The issue is caused by a filename collision in `library/utils.py` within the `save_checkpoint` function. When the function is called with `filename="best_model.pth"` (as done in `runfile.py`), the source `filepath` becomes identical to the hardcoded destination `best_path` used for saving the best model. `shutil.copyfile` raises a `SameFileError` when the source and destination are the same. The fix is to add a conditional check to verify that `filepath` and `best_path` are different before attempting the copy operation. This ensures the function handles cases where the checkpoint name matches the "best model" name gracefully, preventing the crash.
