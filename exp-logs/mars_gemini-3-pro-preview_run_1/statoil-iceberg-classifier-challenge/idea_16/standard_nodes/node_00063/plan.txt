The optimization strategy focuses on reverting the detrimental semi-supervised learning components (Lesson 53) and implementing a robust **Stochastic Weight Averaging (SWA) Ensemble** calibrated via **Global Epoch Selection** (Lesson 49).

**Key Changes:**
1.  **Remove Semi-Supervised Learning:** The Teacher-Student pipeline and pseudo-labeling logic are removed, as Lesson 53 indicates they degrade performance on this dataset due to unstable teachers and noisy labels.
2.  **Implement 5-Fold Cross-Validation Calibration:** The `run_calibration` function is rewritten to use `StratifiedKFold`. It calculates the average validation loss curve across 5 folds to identify the globally optimal epoch count (`best_epoch`), ensuring the training duration is robust to data splits (Lesson 40).
3.  **Refine SWA Configuration:** The SWA duration is increased to 12 epochs (Lesson 55) to allow for better weight averaging. The ensemble is then trained on the full training set for the calibrated duration plus the SWA phase.
4.  **Adaptive Scheduling:** The Learning Rate schedule for the final training is derived from the median decay epochs observed during the calibration phase, ensuring the production models follow the optimal optimization trajectory (Lesson 55).

def run_calibration():
    """
    Runs 5-Fold Cross-Validation to determine the global optimal epoch count.
    Cite solution_lesson_node_00040: Global Epoch Selection vs Local Early Stopping.
    Cite solution_lesson_node_00049: Calibrate Duration via K-Fold CV.

            val_ds, batch_size=Config.BATCH_SIZE, shuffle=False, 
            num_workers=Config.NUM_WORKERS, pin_memory=True
        )
        
        # Model & Optimizer
        model = IcebergResNet(pretrained=True)
        optimizer = optim.AdamW(model.parameters(), lr=Config.LR, weight_decay=Config.WEIGHT_DECAY)
        scheduler = optim.lr_scheduler.ReduceLROnPlateau(
            optimizer, mode="min", factor=Config.SCHEDULER_FACTOR, patience=Config.PATIENCE
        )
        
        trainer = IcebergTrainer(model)
        current_lr = Config.LR

        for epoch in range(1, max_epochs + 1):
            trainer.train_one_epoch(train_loader, optimizer)
            _, val_logloss, _ = trainer.evaluate(val_loader)
            
            # Record Loss (0-indexed)
            all_val_losses[fold, epoch-1] = val_logloss
            
            # Check LR Decay
            new_lr = optimizer.param_groups[0]["lr"]
            if new_lr < current_lr:
                all_lr_changes.append(epoch)
                current_lr = new_lr

            if epoch > 20 and val_logloss > 0.5:

    # Mask out inf values (in case of early break, though we run fixed epochs mostly)
    # Here we assume we ran enough epochs.
    avg_val_losses = np.mean(all_val_losses, axis=0)
    
    # Find Global Optimal Epoch (argmin)
    best_epoch_idx = np.argmin(avg_val_losses)
    best_epoch = best_epoch_idx + 1

        print(f"Derived LR Milestones: {milestones}")
    else:
        milestones = []
        print("No LR decay detected during calibration.")
