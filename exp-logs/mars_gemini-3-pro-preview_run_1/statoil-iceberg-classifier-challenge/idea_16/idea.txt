Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Semi-Supervised SWA-ResNet Ensemble with Gradient-Consistent Replay**.

This solution structurally evolves the successful **SWA Ensemble** (Idea 13) by integrating a **Semi-Supervised Learning (SSL)** loop. This directly addresses the "Data Scarcity" bottleneck (Lesson 00020) by leveraging the test set to expand the effective training data. Crucially, it mitigates the "Unstable Teacher" failure mode of previous SSL attempts (Lesson 00053) by using the highly robust, calibrated SWA models from Idea 13 as the teacher ensemble, and ensures optimization stability using a **Gradient-Consistent Replay** strategy derived from Lesson 00038 and 00055.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024, solution_lesson_node_00011).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline:
    *   **RandomRotate90** (Discrete rotations) (Cite solution_lesson_node_00028).
    *   **Rotate** with a limit of $\pm 20^{\circ}$ (Continuous rotation) (Cite solution_lesson_node_00031).
    *   Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Stage Semi-Supervised Protocol** that ensures stability and maximizes data utilization.

**Stage 1: Teacher Ensemble (Calibrated SWA)**
*   **Calibration:** Run **Stratified 5-Fold Cross-Validation** with a **ReduceLROnPlateau** scheduler and **AdamW** (`lr=1e-4`, `weight_decay=0.01`). Determine the global optimal convergence epoch ($E_{conv}$) where the average validation loss is minimized (Cite solution_lesson_node_00040, solution_lesson_node_00055). Record the epoch indices where the scheduler triggered learning rate reductions.
*   **Production:** Train **5 independent models** on **100% of the labeled data**.
    *   **Phase A (Replay):** Train for $E_{conv}$ epochs using a **MultiStepLR** scheduler configured with the recorded reduction milestones. This replicates the optimal optimization trajectory (Cite solution_lesson_node_00038).
    *   **Phase B (SWA):** Continue training for 10 additional epochs using **Stochastic Weight Averaging (SWA)** with a constant low learning rate to find a flat, robust minimum (Cite solution_lesson_node_00049).

**Stage 2: Student Ensemble (Self-Training)**
*   **Pseudo-Labeling:** Generate predictions on the **Test Set** using the Stage 1 Teacher Ensemble with **Exhaustive TTA**.
*   **Variance Filtering:** Select test samples that meet **two criteria**:
    1.  **High Confidence:** Mean probability $> 0.95$ or $< 0.05$.
    2.  **Low Variance:** The standard deviation of predictions across the 5 ensemble members is below a strict threshold (e.g., $0.02$). This ensures we only learn from samples where the teachers consistently agree, mitigating the risk of confirmation bias (Cite solution_lesson_node_00053).
*   **Retraining:** Train **5 new independent SWA models** on the **Combined Dataset** (Labeled + Pseudo-Labeled).
    *   **Gradient Consistency:** We will maintain the same epoch count ($E_{conv} + 10$). Since the dataset size $N$ has increased, the total number of gradient steps will naturally increase, allowing the model to absorb the new information without underfitting (Cite solution_lesson_node_00038).

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views (Cite solution_lesson_node_00031).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Stage 2 (Student) models**.
