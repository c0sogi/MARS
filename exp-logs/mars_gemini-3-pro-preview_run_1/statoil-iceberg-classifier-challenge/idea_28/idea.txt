Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Trajectory-Replayed ResNet-18 Ensemble with Low-Energy Cyclic SWA**.

This solution structurally evolves the successful **SWA Ensemble** (Idea 13) by resolving the "Scheduler Incompatibility" identified in Lesson 00090 and the "Trajectory Mismatch" identified in Lesson 00055. It replaces the reactive scheduler in the production phase with a deterministic **Trajectory Replay** mechanism derived from calibration, and implements a **Low-Energy Cyclic SWA** schedule to explore the loss basin without the destabilizing shocks that caused previous advanced optimizers to fail.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector. We avoid complex gating mechanisms which have proven difficult to optimize (Cite solution_lesson_node_00001, solution_lesson_node_00082).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2. This prioritizes denoising over feature separation (Cite solution_lesson_node_00103, solution_lesson_node_00037).
    4.  Stack them to form the input.
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation**. We explicitly reject Bilinear interpolation to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline:
    *   **Discrete:** `RandomRotate90` to ensure closure over cardinal axes (Cite solution_lesson_node_00028).
    *   **Continuous:** `ShiftScaleRotate` ($\pm 20^{\circ}$) to smooth the decision boundary (Cite solution_lesson_node_00031).
    *   **Flips:** Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Protocol** that utilizes Trajectory Replay to enable safe full-data training.

**Phase 1: Calibration (Trajectory Discovery)**
*   **Objective:** Determine the optimal convergence epoch ($E_{conv}$), the final learning rate ($LR_{final}$), and the specific epoch milestones where learning rate decay occurs.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimizer:** **AdamW** with a low base learning rate of **2e-4** and `weight_decay=0.01` (Cite solution_lesson_node_00077).
*   **Scheduler:** `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**. This allows the model to find the optimal stopping point organically without premature freezing (Cite solution_lesson_node_00070, solution_lesson_node_00065).
*   **Selection:** Identify $E_{conv}$ as the epoch that minimizes the **TTA-Validation Loss** (Cite solution_lesson_node_00025). Record the average epoch indices where the scheduler triggered reductions.

**Phase 2: Production (Trajectory Replay with Low-Energy Cyclic SWA)**
*   **Objective:** Train 5 independent models on **100% of the training data** (Train + Validation combined).
*   **Trajectory Replay (Structural Innovation):** Instead of using the plateau scheduler (which fails without a validation set), we configure a **MultiStepLR** scheduler using the reduction milestones discovered in Phase 1. This forces the model to follow the exact, proven optimization path of the calibration phase (Cite solution_lesson_node_00055).
*   **Low-Energy Cyclic SWA (Structural Innovation):** After reaching epoch $E_{conv}$, we transition to SWA. Crucially, instead of resetting the learning rate to a high value (which causes shock, Cite solution_lesson_node_00090), we initiate a **Cyclic Schedule** that oscillates between $LR_{final}$ and $LR_{final}/2$ for 3 short cycles (e.g., 4 epochs each). This allows the model to explore the local basin geometry without being ejected from the minimum (Cite solution_lesson_node_00049).
*   **Loss:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$).

# Evaluation
*   **Exhaustive Closed-Group TTA:** For every test image, we will generate predictions using the **Klein Four-Group**: Original, Horizontal Flip, Vertical Flip, and Rotate180. This ensures the prediction is mathematically invariant to cardinal symmetries (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SWA models**.
