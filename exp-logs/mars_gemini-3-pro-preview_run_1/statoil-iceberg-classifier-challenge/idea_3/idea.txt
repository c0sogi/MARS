# Proposed Solution: Stratified K-Fold Ensemble with EfficientNet and Corrected Regularization

## Model
To address the small dataset size and the need for robust feature extraction, we will evolve the architecture from a standard ResNet to a **Stratified K-Fold Ensemble of EfficientNet-B0 models**.

*   **Backbone Architecture**: We will replace the ResNet-18 backbone with **EfficientNet-B0** pretrained on ImageNet. EfficientNet utilizes inverted residual blocks and Squeeze-and-Excitation optimization, which generally provides superior parameter efficiency and generalization on smaller datasets compared to older ResNet architectures.
*   **Input Construction**: The input will remain a **3-channel composite** (Band 1, Band 2, and their Mean) to explicitly capture inter-band correlation.
*   **Late Fusion**: We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the feature vector extracted by the EfficientNet's Global Average Pooling layer, allowing the dense head to condition predictions on the viewing geometry (Cite solution_lesson_node_00001).
*   **Classification Head**: The fused vector will pass through a Batch Normalization layer, a Dropout layer, and a final Dense layer.

## Data
*   **Preprocessing**: Missing `inc_angle` values will be imputed with the training mean. The 75x75 images will be **upsampled to 224x224** using bicubic interpolation to match the native resolution of the pretrained EfficientNet backbone (Cite solution_lesson_node_00004). Pixel values (dB) will be Min-Max scaled to [0, 1].
*   **Augmentation**: We will apply **aggressive geometric augmentation** (Random Horizontal/Vertical Flips, Random Rotations, and Translations). We will explicitly prioritize these input-space transformations over pure output-space regularization to force the model to learn spatial invariances (Cite solution_lesson_node_00006).

## Training
*   **Pipeline Strategy**: We will implement **Stratified 5-Fold Cross-Validation**. Instead of relying on a single train/validation split, we will train five separate models on distinct subsets of the data. This structural change directly mitigates the high variance associated with the small dataset size.
*   **Loss Function**: We will use **BCEWithLogitsLoss** with **Label Smoothing** (e.g., $\epsilon=0.05$). This ensures the model does not become overconfident, improving the calibration of the predicted probabilities for the Log Loss metric (Cite solution_lesson_node_00005).
*   **Optimizer**: We will use the **AdamW** optimizer. Crucially, we will set the `weight_decay` to a significant value (e.g., `0.01` or `0.05`) rather than the default low values used for standard Adam. This corrects the previous oversight where decoupled weight decay was too weak to provide effective regularization (Cite solution_lesson_node_00007).
*   **Checkpointing**: For each fold, we will save the model weights corresponding to the lowest validation loss using `copy.deepcopy()` to ensure the saved state is immutable and correct (Cite solution_lesson_node_00002).

## Evaluation
*   **Test Time Augmentation (TTA)**: For every test image, we will generate predictions for the original image and its horizontally and vertically flipped versions, averaging the probabilities to smooth out noise (Cite solution_lesson_node_00005).
*   **Ensemble Prediction**: The final prediction for each ID will be the arithmetic mean of the TTA-averaged probabilities produced by the **5 independent models** from the cross-validation folds. This ensemble approach is expected to significantly reduce generalization error.
