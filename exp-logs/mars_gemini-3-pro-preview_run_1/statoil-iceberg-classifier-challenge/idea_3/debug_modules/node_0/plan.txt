This script demonstrates the end-to-end usage of the provided library modules for the Ship vs Iceberg classification task. It performs the following steps:
1.  **Configuration Patching**: Modifies hyperparameters (Epochs, Folds, Batch Size) at runtime to ensure the demonstration runs quickly.
2.  **Data Loading**: Uses `library.dataset.load_data` to load and preprocess the training data, verifying data integrity and normalization.
3.  **Dataset & DataLoader**: Instantiates the `IcebergDataset` and verifies the output shapes of the tensors produced.
4.  **Model Initialization**: Instantiates the `IcebergEfficientNet` model and performs a forward pass with dummy data to verify architecture and output dimensions.
5.  **Training Simulation**: Runs a single training epoch and validation step on a small subset of the real data using `library.train` functions, ensuring the optimization loop functions correctly.
6.  **Inference Simulation**: Demonstrates Test Time Augmentation (TTA) prediction using `library.predict` functions.
7.  **Submission Generation**: Simulates the final submission file generation process.
