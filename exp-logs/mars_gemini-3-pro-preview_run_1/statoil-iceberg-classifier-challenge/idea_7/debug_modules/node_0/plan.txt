The following script demonstrates the complete pipeline for the Iceberg Detection task using the provided library.

### Implementation Strategy
1.  **Configuration**: We override the default `Config` parameters to define a custom working directory and significantly reduce the training duration (1 epoch, 2 bags) for demonstration purposes.
2.  **Data Loading & Verification**: We use `load_data` to process the raw JSON files into numpy arrays and assert that the shapes and values are correct.
3.  **Model Sanity Check**: We instantiate the `IcebergResNet18` model and perform a forward pass with dummy data to verify the architecture and output dimensions on the available device (CPU/GPU).
4.  **Training**: We execute `train_bagging_ensemble` to train the model using the reduced configuration. This generates model checkpoints in the working directory.
5.  **Inference**: We run `generate_submission` to load the saved checkpoints, perform inference with Test Time Augmentation (TTA) on the test set, and create the submission CSV.
6.  **Result Validation**: We inspect the generated submission file to ensure it adheres to the required format and value ranges.
