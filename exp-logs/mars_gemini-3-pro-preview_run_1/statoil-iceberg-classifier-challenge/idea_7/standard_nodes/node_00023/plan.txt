The `ValueError: Per-column arrays must each be 1-dimensional` is caused by a shape mismatch between `y_val` (shape `(N,)`) and `avg_preds` (shape `(N, 1)`). When calculating `errors = np.abs(y_val - avg_preds)`, NumPy broadcasts these arrays into an `(N, N)` matrix instead of performing element-wise subtraction. Consequently, the resulting `errors` array is 2-dimensional, which pandas rejects when constructing the DataFrame. The fix is to flatten `avg_preds` to a 1D array immediately after averaging the ensemble predictions.
