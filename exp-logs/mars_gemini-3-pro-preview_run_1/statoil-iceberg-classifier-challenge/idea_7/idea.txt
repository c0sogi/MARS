Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Bagging-Enhanced ResNet-18 Ensemble with Global Calibration**.

This solution introduces a structural shift in the training pipeline: moving from **Partition-based Ensembling (Stratified K-Fold)** to **Resampling-based Ensembling (Bagging)**. This directly addresses the critical conflict identified in **Lesson 00020**, where the reduction in training set size inherent to K-Fold validation degraded the performance of individual deep learning models on this data-scarce task.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants (ResNet-34) or depthwise-separable architectures (EfficientNet) for small, noisy radar datasets (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will revert to standard **Global Average Pooling (GAP)**. We explicitly reject the Dual-Stream (Max+Avg) pooling attempted previously, as analysis confirmed that Max Pooling amplifies speckle noise in SAR imagery, degrading performance in high-noise regimes (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector. This allows the classifier to condition predictions on the viewing geometry (Cite solution_lesson_node_00001).
*   **Classification Head:** The fused vector will pass through a block consisting of Batch Normalization, **High Dropout (0.5)**, and a final Dense layer. The high dropout is preserved to prevent overfitting during fine-tuning (Cite solution_lesson_node_00011).

# Data
*   **Global Normalization (Critical Correction):** We will implement **Global Min-Max Scaling**. We explicitly reject the "Per-Sample Normalization" used in Idea 6. Radar backscatter (dB) contains absolute physical meaning; scaling globally preserves the relative intensity differences between "bright" icebergs and "dark" ships/ocean, which per-sample scaling destroys (Cite solution_lesson_node_00021).
*   **Input Construction:** We will construct a **3-channel composite image** using Band 1 (HH), Band 2 (HV), and their arithmetic mean.
*   **Upsampling:** The native 75x75 images will be **upsampled to 224x224** using bicubic interpolation to match the receptive field of the pretrained backbone (Cite solution_lesson_node_00004).
*   **Augmentation:** We will employ **Input-Space Augmentation** (Random Horizontal Flips, Random Vertical Flips, and Random Rotations). We prioritize these geometric transformations to teach spatial invariance (Cite solution_lesson_node_00006) and explicitly **remove Label Smoothing** to avoid the underfitting observed when stacking multiple regularizers (Cite solution_lesson_node_00013).

# Training
*   **Pipeline Strategy (Structural Innovation):** We will implement a **Bagging (Bootstrap Aggregating) Ensemble**. Instead of splitting the small dataset into folds (which reduces the training data seen by each model by 20%), we will train **5 independent models**. Each model will be trained on a dataset of size $N$ (equal to the original training set size) created by **sampling with replacement** from the original data.
    *   **Rationale:** This ensures every model learns from a "full-size" dataset, overcoming the data scarcity bottleneck that caused K-Fold approaches to fail (Cite solution_lesson_node_00020), while still introducing the diversity required for a robust ensemble.
    *   **Validation:** We will use the Out-of-Bag (OOB) samples for each model to monitor convergence and trigger early stopping.
*   **Optimizer:** We will use **AdamW** with a `weight_decay` of **0.01**. This ensures effective decoupled regularization (Cite solution_lesson_node_00007).
*   **Scheduling:** We will employ a **ReduceLROnPlateau** scheduler with an **aggressive decay factor of 0.1** and a conservative base learning rate (`1e-4`). This forces the model to settle into sharp local minima rather than oscillating (Cite solution_lesson_node_00009, solution_lesson_node_00011).
*   **Loss Function:** We will use standard **BCEWithLogitsLoss** (without Label Smoothing) to allow the model to fully fit the signal provided by the augmented data.

# Evaluation
*   **Test Time Augmentation (TTA):** During inference, we will generate predictions for the original test image and its horizontally/vertically flipped versions, averaging the probabilities (Cite solution_lesson_node_00005).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Bagged Models**.
