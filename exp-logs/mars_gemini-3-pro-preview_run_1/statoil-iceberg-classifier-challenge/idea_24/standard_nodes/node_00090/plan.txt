Implementation Strategy:
The solution orchestrates the "Calibrated SAM-SWA ResNet Ensemble" strategy through a multi-phase process implemented in `runfile.py`.

1.  **Setup and Initialization**: We import necessary libraries and the provided helper modules (`library.*`). We verify the device (GPU) and set global random seeds to ensure reproducibility.
2.  **Phase 1: Calibration**: We call `workflow.run_phase_1_calibration(n_splits=5)`. This executes a Stratified 5-Fold Cross-Validation using the SAM optimizer. The goal is not just to evaluate performance, but to determine the `optimal_epochs` ($E_{conv}$) — the epoch where the model consistently achieves the lowest TTA-Validation loss across folds.
3.  **Phase 1.5: Validation Assessment**: Since the production phase trains on the *entire* dataset (including validation samples), we perform a dedicated validation run to compute the required metrics.
    *   We load the specific `train` and `val` indices from the metadata CSVs.
    *   We train a single SAM-SWA model on the `train` split for exactly $E_{conv}$ epochs (SAM) followed by 12 epochs of SWA.
    *   We evaluate this model on the hold-out `val` split using Test-Time Augmentation (TTA).
    *   We compute the **Final Validation Metric** (Log Loss) and print it with full precision.
    *   **Failure Analysis**: We calculate the absolute prediction error for each validation sample and compute its correlation with the `inc_angle` feature to diagnose systematic dependencies.
4.  **Phase 2: Production Training**: If the validation metric is below the specified threshold (0.1691...), we proceed to the production phase. We call `workflow.run_phase_2_production`, which trains an ensemble of 5 models on the **full dataset** (Train + Val) using the calibrated $E_{conv}$ and SWA trajectory.
5.  **Submission Generation**: Finally, `workflow.generate_submission` is called to generate the `submission.csv` by averaging the TTA predictions from the 5 production models.
