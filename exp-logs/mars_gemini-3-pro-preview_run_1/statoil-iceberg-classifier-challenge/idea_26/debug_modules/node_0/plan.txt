The following script demonstrates the usage of the provided library to solve the Ship vs Iceberg classification task.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes at runtime to redirect outputs to a demo directory and drastically reduce training time (1 epoch, 2 folds) for demonstration purposes.
2.  **Data Subsetting (Optimization)**: To ensure the script runs almost instantly while validating the entire pipeline, we intercept the data loading process. We load the real data once, slice it to a tiny subset (50 samples), and save this subset to the cache. The library functions, configured to prefer cached data, will then use this small dataset.
3.  **Component Verification**: We explicitly verify the correctness of the data loader (shapes, types) and the model architecture (forward pass dimensions) using assertions.
4.  **Pipeline Execution**:
    *   **Phase 1 (Calibration)**: We run the calibration phase to determine the optimal epoch count (`e_conv`).
    *   **Phase 2 (Production)**: We run the production phase using the determined `e_conv` to train an ensemble and generate a submission.
5.  **Output Validation**: We verify that the submission file is generated correctly and adheres to the required format.
