The implementation strategy involves the following steps:

1.  **Environment and Configuration**: We import the necessary modules and the provided library components. We dynamically adjust the `Config` parameters (specifically reducing `P1_MAX_EPOCHS`, `P1_PATIENCE`, and `N_FOLDS`) to ensure the calibration and training phases complete rapidly, satisfying the "fast baseline" requirement.
2.  **Calibration Phase**: We execute `run_calibration_phase` to empirically determine the optimal convergence epoch (`e_conv`) using a stratified cross-validation approach on the training data.
3.  **Validation Run**: To calculate the required "Final Validation Metric" on the hold-out set, we perform a dedicated training run. We train a `IcebergResNet18` model on the training split (defined by metadata) using the `IcebergTrainer` and the determined `e_conv`, following the exact Cosine-SWA schedule intended for production. We then evaluate this model on the validation split using Exhaustive Closed-Group Test-Time Augmentation (TTA).
4.  **Failure Analysis**: Using the predictions from the validation run, we calculate the per-sample log loss and compute its Pearson correlation with the incidence angle (`inc_angle`). This helps identify if the model struggles with specific viewing geometries.
5.  **Submission Logic**: We compare the calculated validation metric against the strict threshold provided (0.16918645240183008). If and only if the metric is lower (better), we trigger `run_production_phase`, which trains the full 5-model ensemble on the entire dataset and generates the `submission.csv` file.
