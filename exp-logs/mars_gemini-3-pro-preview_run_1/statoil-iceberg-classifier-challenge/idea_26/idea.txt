Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Calibrated Cosine-SWA ResNet-18 Ensemble**.

This solution represents a structural evolution of the training pipeline. It resolves the critical conflict between **Adaptive Calibration** (Lesson 00055) and **Optimizer Stability** (Lesson 00090). Previous solutions either used adaptive schedulers (`ReduceLROnPlateau`) that caused "learning rate shocks" when transitioning to SWA, or fixed schedulers (`CosineAnnealing`) that biased the calibration. This proposal introduces a **Schedule Mapping Protocol** that uses adaptive calibration to define the parameters of a smooth, deterministic cosine trajectory for the final production training.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline including:
    *   **RandomRotate90** (Discrete) for cardinal invariance (Cite solution_lesson_node_00028).
    *   **ShiftScaleRotate** (Continuous $\pm 20^{\circ}$) to smooth the decision boundary (Cite solution_lesson_node_00031).
    *   Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Schedule Mapping Protocol** to ensure optimal convergence and smooth SWA transition.

**Phase 1: Adaptive Calibration (Global Epoch Selection)**
*   **Objective:** Determine the natural convergence epoch ($E_{conv}$) without imposing a fixed timeline.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimization:** **AdamW** (`lr=2e-4`, `weight_decay=0.01`) (Cite solution_lesson_node_00077).
*   **Scheduler:** `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**. This allows the model to find the optimal stopping point organically (Cite solution_lesson_node_00055, solution_lesson_node_00070).
*   **Selection:** Identify $E_{conv}$ as the epoch that minimizes the **TTA-Validation Loss** (average of Original + Flips) (Cite solution_lesson_node_00025).

**Phase 2: Production (Cosine-SWA Full-Fit)**
*   **Objective:** Train 5 independent models on **100% of the training data** (Train + Validation combined).
*   **Schedule Mapping (Structural Innovation):** Instead of reusing the plateau scheduler (which requires validation data), we map the trajectory to a **Cosine Annealing Schedule**.
    *   Configure `CosineAnnealingLR` with $T_{max} = E_{conv}$ and $\eta_{min} = \text{SWA\_LR}$ (e.g., `1e-5`).
    *   **Rationale:** This forces the model to converge exactly at the calibrated epoch $E_{conv}$, but ensures the learning rate lands smoothly at the target SWA learning rate, preventing the "shock" caused by hard resets (Cite solution_lesson_node_00090).
*   **SWA Phase:** Immediately continue training for 12 additional epochs using **Stochastic Weight Averaging (SWA)** with a constant learning rate of `1e-5`.
*   **Loss Function:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) (Cite solution_lesson_node_00065).

# Evaluation
*   **Exhaustive Closed-Group TTA:** For every test image, we will generate predictions using the **Klein Four-Group**: Original, Horizontal Flip, Vertical Flip, and Rotate180. This ensures the prediction is mathematically invariant to cardinal symmetries (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit Cosine-SWA models**.
