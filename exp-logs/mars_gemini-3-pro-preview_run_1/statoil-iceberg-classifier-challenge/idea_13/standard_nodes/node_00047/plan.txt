This provides a more robust estimate of the optimal stopping point for the full-data training.
3.  **Label Smoothing (Cite Lesson 00005):** To improve Log Loss (which penalizes overconfident wrong predictions), I will enable `label_smoothing=0.05` in the `BCEWithLogitsLoss`. This prevents the model from chasing probability targets of 0 and 1, improving generalization.

    # Use config epochs
    max_epochs = config.MAX_EPOCHS_PHASE_1

    val_loss_history = np.zeros((config.NUM_FOLDS, max_epochs))

        )
        val_loader = DataLoader(
            val_sub,

            # Store loss (epoch is 1-based, index is 0-based)
