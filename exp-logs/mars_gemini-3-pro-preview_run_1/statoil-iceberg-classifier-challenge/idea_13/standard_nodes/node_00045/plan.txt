Implementation strategy:
1.  **Setup**: Initialize the environment, seed random number generators, and detect the computation device (GPU).
2.  **Data Loading**: Load the training and validation datasets using the provided `data_loader` module. This utilizes the metadata files and caching mechanism.
3.  **Phase 1 (Calibration)**: Perform a Stratified 5-Fold Cross-Validation on the training dataset (`train_metadata.csv`). For each fold, train a ResNet-18 model to identify the epoch where validation loss is minimized. Calculate the average optimal epoch ($E_{conv}$) to determine the convergence point for the production models.
4.  **Phase 2 (Production Training)**: Train an ensemble of 5 independent models on the full training dataset (`train_metadata.csv`). Each model follows a specific schedule:
    *   Train for $E_{conv}$ epochs using a Cosine Annealing scheduler to reach convergence.
    *   Continue training for a fixed number of SWA epochs (`SWA_EPOCHS`) with a constant learning rate, updating an `AveragedModel` (Stochastic Weight Averaging) at each step.
    *   Update Batch Normalization statistics for the SWA model at the end of training.
5.  **Evaluation**: Evaluate the ensemble of 5 SWA models on the hold-out validation set (`val_metadata.csv`). Use Test Time Augmentation (TTA) for each model and average the probabilities across the ensemble. Compute and print the final Log Loss metric.
6.  **Failure Analysis**: Calculate the absolute error between predictions and targets on the validation set. Compute the correlation between these errors and the incidence angle to identify potential biases.
7.  **Submission**: If the validation metric meets the specified threshold, generate predictions for the test set using the ensemble (with TTA) and save the results to `submission.csv`.
