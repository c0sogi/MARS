To optimize the solution, I will focus on removing the Consistency Regularization and reverting to a robust supervised training pipeline with Test-Time Augmentation (TTA), as suggested by **Lesson 00066**. The previous attempt's use of consistency loss likely interfered with the optimization on this small dataset.

Here is the strategy:
1.  **Configuration**: Lower the learning rate to `2e-4` and weight decay to `1e-4` to stabilize fine-tuning (Cite **Lesson 00067**, **Lesson 00009**). Remove consistency loss weights.
2.  **Optimization**: Replace `ConsistencyLoss` with a standard `IcebergLoss` (BCEWithLogits + Label Smoothing). This simplifies the objective function and prevents the conflict between consistency and discrimination (Cite **Lesson 00066**).
3.  **Data Loading**: Modify `IcebergDataset` to return a single augmented image during training instead of dual views, as we are dropping the consistency constraint.
4.  **Training Engine**: Update the training loop to handle single inputs and the new loss function.
5.  **Execution**: In `runfile.py`, relax the "fast baseline" constraints. I will increase the calibration epochs to 50 and the ensemble size to 5 to maximize performance within the 4-hour limit (Cite **Lesson 00038** regarding sufficient gradient steps).

class ConsistencyLoss(nn.Module):
    """
    Custom loss function implementing BCE with Label Smoothing and Geometric Consistency Regularization.

    Formula:
        L = BCEWithLogits(f(x), y_smooth) + lambda * ||sigma(f(x)) - sigma(f(x'))||^2

    Where:
        f(x) is the output for the first view.
        f(x') is the output for the second view.
        sigma is the sigmoid function.
        lambda is the consistency weight.
    """

    def __init__(self):
        super(ConsistencyLoss, self).__init__()
        self.smoothing = Config.LABEL_SMOOTHING
        self.consistency_weight = Config.CONSISTENCY_LOSS_WEIGHT

    def forward(self, logits1, logits2, targets):
        """
        Args:
            logits1 (torch.Tensor): Logits from the first augmented view (Batch, 1).
            logits2 (torch.Tensor): Logits from the second augmented view (Batch, 1).
            targets (torch.Tensor): Ground truth labels (Batch,).
        """
        # Ensure targets are the correct shape (Batch, 1)
        targets = targets.view(-1, 1)

        # 1. Label Smoothing
        # y_smooth = y * (1 - epsilon) + 0.5 * epsilon
        with torch.no_grad():
            targets_smooth = targets * (1.0 - self.smoothing) + 0.5 * self.smoothing

        # 2. BCE Loss on the first view
        # We use binary_cross_entropy_with_logits for numerical stability
        bce_loss = F.binary_cross_entropy_with_logits(logits1, targets_smooth)

        # 3. Consistency Loss (MSE between probabilities)
        probs1 = torch.sigmoid(logits1)
        probs2 = torch.sigmoid(logits2)
        consistency_loss = F.mse_loss(probs1, probs2)

        # 4. Total Loss
        total_loss = bce_loss + self.consistency_weight * consistency_loss

        return total_loss

        with torch.no_grad():

def train_one_epoch(model, loader, optimizer, loss_fn, device, epoch):
    """
    Trains the model for one epoch using Geometric Consistency Regularization.

    Args:
        model (nn.Module): The model to train.
        loader (DataLoader): Training dataloader returning ((img1, img2), angle, label).
        optimizer (Optimizer): The optimizer.
        loss_fn (nn.Module): The ConsistencyLoss function.
        device (str): Device to run on.
        epoch (int): Current epoch number.

    Returns:
        float: Average loss for the epoch.
    """
    model.train()
    losses = AverageMeter()

    for batch_idx, (images, angles, labels) in enumerate(loader):
        # Unpack dual views
        img1, img2 = images

        # Move to device
        img1 = img1.to(device, non_blocking=True)
        img2 = img2.to(device, non_blocking=True)
        angles = angles.to(device, non_blocking=True)
        labels = labels.to(device, non_blocking=True)

        optimizer.zero_grad()

        logits2 = model(img2, angles)

        loss = loss_fn(logits1, logits2, labels)

        # Backward pass
        loss.backward()
        optimizer.step()

        # Update metrics
        losses.update(loss.item(), img1.size(0))

    print(f"Epoch {epoch} Train Loss: {losses.avg}")
    return losses.avg
