Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Sharpness-Aware SWA-ResNet Ensemble**.

This solution introduces **Sharpness-Aware Minimization (SAM)** as a structural evolution of the training pipeline. While the previous best solution (Idea 13) successfully utilized Stochastic Weight Averaging (SWA) to find flat minima *post-hoc* (averaging along a trajectory), SAM explicitly optimizes for loss landscape flatness *during* every gradient step. By combining SAM's active flatness-seeking with SWA's trajectory averaging, and wrapping it in the robust Full-Fit protocol established in previous lessons, this strategy directly targets the generalization gap inherent in small, noisy datasets.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001, solution_lesson_node_00082).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline that combines **Discrete** and **Continuous** transformations to ensure full invariance:
    *   **RandomRotate90** (Discrete) for cardinal invariance (Cite solution_lesson_node_00028, solution_lesson_node_00077).
    *   **Rotate** with a limit of $\pm 20^{\circ}$ (Continuous) to smooth the decision boundary (Cite solution_lesson_node_00031).
    *   Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Protocol** incorporating SAM and SWA.

**Phase 1: Calibration (Global Epoch Selection)**
*   **Objective:** Determine the optimal convergence epoch ($E_{conv}$) where the model stabilizes.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimizer (Structural Innovation):** **SAM (Sharpness-Aware Minimization)** wrapping **AdamW** (`lr=2e-4`, `weight_decay=0.01`). SAM will perform dual forward/backward passes to minimize both the loss value and the loss sharpness (neighborhood radius $\rho=0.05$).
*   **Scheduler:** Use `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**. This ensures the model converges deeply without premature freezing (Cite solution_lesson_node_00065, solution_lesson_node_00070).
*   **Selection:** Identify $E_{conv}$ as the epoch that minimizes the **TTA-Validation Loss** (average of Original + Flips) to align training with inference (Cite solution_lesson_node_00025, solution_lesson_node_00040).

**Phase 2: Production (Full-Fit SAM-SWA)**
*   **Objective:** Train 5 independent models on **100% of the training data** (Train + Validation combined).
*   **Standard Stage:** Train for exactly $E_{conv}$ epochs using the SAM optimizer and the hyperparameter dynamics derived from Phase 1.
*   **SWA Stage:** Continue training for an additional 12 epochs using **Stochastic Weight Averaging (SWA)** with a constant learning rate. This combines the active flatness seeking of SAM with the trajectory averaging of SWA for maximum robustness (Cite solution_lesson_node_00049).
*   **Loss Function:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) (Cite solution_lesson_node_00065).

# Evaluation
*   **Exhaustive Closed-Group TTA:** For every test image, we will generate predictions using the **Klein Four-Group**: Original, Horizontal Flip, Vertical Flip, and Rotate180 (composed flips). This ensures the ensemble average is mathematically invariant to the cardinal symmetries (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SAM-SWA models**.
