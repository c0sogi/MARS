Based on the analysis of the previous attempts and the derived lessons, I propose the **Semi-Supervised ResNet-18 SWA Ensemble with Iterative Confidence Filtering**.

This solution introduces a **Semi-Supervised Learning** loop as the primary structural innovation. It directly addresses the "Data Scarcity" bottleneck identified in **Lesson 00020** (where splitting data for validation hurt performance) by leveraging the unlabeled test data to expand the effective training set. It integrates this with the robust **Stochastic Weight Averaging (SWA)** training pipeline (Lesson 00049) to ensure the models trained on this expanded dataset generalize effectively.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Corrected Composite Fusion:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics (Cite solution_lesson_node_00021, solution_lesson_node_00042).
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2 (Cite solution_lesson_node_00037).
    4.  Stack them to form the input.
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ the robust geometric augmentation pipeline:
    *   **RandomRotate90** (Discrete rotations) (Cite solution_lesson_node_00028).
    *   **Rotate** with a limit of $\pm 20^{\circ}$ (Continuous rotation) (Cite solution_lesson_node_00031).
    *   Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Cycle Training Protocol** to safely leverage unlabeled data.

**Cycle 1: Teacher Ensemble (SWA)**
*   **Calibration:** Run **Stratified 5-Fold Cross-Validation** to determine the optimal SWA start epoch ($E_{start}$) and duration ($E_{dur}$) by minimizing the global average validation loss (Cite solution_lesson_node_00040).
*   **Production:** Train **5 independent models** on **100% of the labeled data** (Train + Validation combined). Each model trains for $E_{start}$ epochs using a standard scheduler, followed by $E_{dur}$ epochs of **Stochastic Weight Averaging (SWA)** to find a robust minimum (Cite solution_lesson_node_00049).
*   **Optimization:** **AdamW** (`weight_decay=0.01`) with a **Batch Size of 32** (Cite solution_lesson_node_00038, solution_lesson_node_00007).
*   **Loss:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) (Cite solution_lesson_node_00005).

**Cycle 2: Student Ensemble (Semi-Supervised)**
*   **Pseudo-Labeling:** Generate predictions on the **Test Set** using the Cycle 1 Ensemble (with TTA). Select high-confidence samples (e.g., probability $> 0.95$ or $< 0.05$) and assign them hard pseudo-labels.
*   **Refinement:** Train **5 new independent SWA models** on the **Combined Dataset** (Original Labeled + Pseudo-Labeled Test Data). We will re-use the $E_{start}$ and $E_{dur}$ parameters from Cycle 1, scaled proportionally if the dataset size increases significantly, or re-calibrate if computational time permits. This allows the models to learn from the expanded data distribution, mitigating the data scarcity issue (Cite solution_lesson_node_00020).

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views (Cite solution_lesson_node_00031).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Cycle 2 (Student) models**.
