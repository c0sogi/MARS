The implementation strategy follows the "Full-Fit ResNet-18 Seed Ensemble with Corrected Composite Fusion" idea.

1.  **Phase 1: Calibration (Cross-Validation)**: We execute a Stratified 5-Fold Cross-Validation using the `run_calibration` function. This phase serves two critical purposes:
    *   **Hyperparameter Tuning**: It identifies the optimal number of training epochs ($E_{opt}$) by tracking the average validation log loss across folds. This prevents overfitting in the full-fit phase.
    *   **Performance Estimation**: It calculates a robust "Final Validation Metric" by averaging the best validation scores from the CV folds. This satisfies the requirement to report a metric on the validation set (conceptually covering the entire dataset).
    *   **Failure Analysis**: We retrain one fold (Fold 0) for exactly $E_{opt}$ epochs to generate a representative set of validation predictions. We then calculate the correlation between the prediction error and the incidence angle to identify systematic failures.

2.  **Phase 2: Production (Full-Fit Ensemble)**: If the CV score meets the specified threshold, we proceed to `run_production`.
    *   We train **5 independent models** on **100% of the available training data** (Train + Validation combined).
    *   Each model is initialized with a different random seed (`Config.ENSEMBLE_SEEDS`) to induce diversity.
    *   Training lasts for exactly $E_{opt}$ epochs using a Cosine Annealing scheduler, ensuring convergence without the need for a validation set (which is now part of the training data).

3.  **Inference and Submission**:
    *   We generate predictions for the test set using **Test Time Augmentation (TTA)**. For each image, we average predictions from the original view, horizontal flip, and vertical flip.
    *   The final submission is the arithmetic mean of the TTA predictions from all 5 Full-Fit models.
