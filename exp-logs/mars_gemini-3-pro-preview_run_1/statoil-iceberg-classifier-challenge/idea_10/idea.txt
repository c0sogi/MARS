Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Full-Fit ResNet-18 Seed Ensemble with Corrected Composite Fusion**.

This solution introduces a **Full-Fit Seed Ensemble** strategy to resolve the critical trade-off between data scarcity and ensemble diversity. It structurally evolves the data preprocessing pipeline to correct the feature fusion logic identified in Lesson 00037 and strictly adheres to the architectural and interpolation choices proven to work on this specific dataset.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants (ResNet-34) or depthwise-separable architectures (EfficientNet) for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Corrected Composite Fusion (Structural Innovation):** We will fundamentally change the input construction pipeline. Instead of averaging the raw bands and then normalizing (which suppresses signal in the lower-magnitude HV band), we will:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using global training statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using global training statistics (Cite solution_lesson_node_00021).
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the 3-channel input. This ensures equal contribution of structural information from both polarizations (Cite solution_lesson_node_00037).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation**. We explicitly reject Bilinear interpolation, which was shown to degrade performance by smoothing out high-frequency texture details (Cite solution_lesson_node_00004, solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline including:
    *   **RandomRotate90** (Discrete rotations) (Cite solution_lesson_node_00028).
    *   **ShiftScaleRotate** with a limit of $\pm 20^{\circ}$ (Continuous rotation). This combination is critical for rotational invariance (Cite solution_lesson_node_00031).
    *   Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
*   **Strategy: Full-Fit Seed Ensemble (Structural Innovation):**
    *   **Phase 1 (Calibration):** We will run a **Stratified 5-Fold Cross-Validation** routine to determine the optimal number of training epochs ($E_{opt}$) and validate the hyperparameter configuration. We will use **TTA-Aware Monitoring** (checking validation loss with flips) to select $E_{opt}$ (Cite solution_lesson_node_00025).
    *   **Phase 2 (Production):** We will train **5 independent models** on **100% of the training data** (Train + Validation combined) for exactly $E_{opt}$ epochs. Each model will be initialized with a different random seed. This approach maximizes the data available to each model (resolving the underfitting caused by K-Fold splitting) while still providing the variance reduction of an ensemble (Cite solution_lesson_node_00020, solution_lesson_node_00023).
*   **Optimizer:** **AdamW** with `weight_decay=0.01` to ensure effective decoupled regularization (Cite solution_lesson_node_00007).
*   **Scheduler:** We will use a **Cosine Annealing LR** scheduler for the Full-Fit phase, scheduled to decay from `1e-4` to `0` over exactly $E_{opt}$ epochs. This avoids the dependency on a validation metric (which doesn't exist in Phase 2) while ensuring convergence (Cite solution_lesson_node_00009).
*   **Loss Function:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) to improve probability calibration (Cite solution_lesson_node_00005).

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views. We explicitly use all three views rather than a subset (Cite solution_lesson_node_00031).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit models**.
