To improve the model's performance and address the regression observed in the previous solution, I will implement a strategy based on "Global Epoch Selection" combined with an SWA Ensemble, while also correcting data normalization practices for SAR imagery.

**Strategy Outline:**

1.  **Correct Data Normalization (Cite 00042):** I will remove the ImageNet normalization (`mean=[0.485...], std=[0.229...]`) from the preprocessing pipeline. SAR data relies on absolute backscatter intensity, and centering the distribution at 0 destroys the semantic meaning of "background" vs "target". I will rely solely on the Global Min-Max scaling already implemented in the dataset class.
2.  **Optimize Hyperparameters (Cite 00009, 00005):** I will reduce the learning rate from `1e-3` to `1e-4` to ensure stable fine-tuning of the pre-trained ResNet18 backbone and introduce `Label Smoothing` (0.05) to prevent overconfidence and improve log loss.
3.  **Global Epoch Selection via 5-Fold CV (Cite 00049, 00040):** Instead of a single validation split, I will run a 5-Fold Cross-Validation in Phase 1. I will track the validation loss curve for each fold and select the global optimal epoch count that minimizes the *average* validation loss. This provides a robust stopping criterion for the final training on the full dataset.
4.  **SWA Ensemble in Production (Cite 00049):** In Phase 3, if the CV metric meets the threshold, I will train an ensemble of 5 independent models on the full dataset. Each model will be trained for the calibrated epoch count followed by a Stochastic Weight Averaging (SWA) phase. The final predictions will be the average of this ensemble, reducing variance and improving generalization.
