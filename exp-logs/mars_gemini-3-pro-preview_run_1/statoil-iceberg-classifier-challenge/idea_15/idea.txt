Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **OOF-Calibrated SWA-ResNet Ensemble with Trajectory Replay**.

This solution structurally evolves the successful **SWA Ensemble** approach (Idea 13) by integrating the **Trajectory Replay** and **Post-Hoc Calibration** concepts from Idea 12, but correcting their implementation flaws using the robust **Global Epoch Selection** method. It addresses the remaining risk of probability miscalibration in Log Loss optimization without sacrificing the data efficiency of full-set training.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ the robust geometric augmentation pipeline:
    *   **RandomRotate90** (Discrete rotations) (Cite solution_lesson_node_00028).
    *   **Rotate** with a limit of $\pm 20^{\circ}$ (Continuous rotation) (Cite solution_lesson_node_00031).
    *   Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Three-Phase Protocol** that combines robust epoch selection with explicit probability calibration.

**Phase 1: Calibration & Trajectory Extraction (5-Fold CV)**
*   **Objective:** Determine optimal hyperparameters and generate Out-Of-Fold (OOF) predictions.
*   **Optimization:** Use **AdamW** (`weight_decay=0.01`) with a **Batch Size of 32** (Cite solution_lesson_node_00038).
*   **Schedule:** Use **ReduceLROnPlateau** (factor 0.1) to naturally find the convergence point.
*   **SWA:** Upon convergence (triggered by the scheduler), enter a **Stochastic Weight Averaging (SWA)** phase for a fixed duration (e.g., 12 epochs) (Cite solution_lesson_node_00049).
*   **Outputs:**
    1.  **Global Convergence Epoch ($E_{conv}$):** The epoch minimizing the *average* validation loss curve (Cite solution_lesson_node_00040).
    2.  **Trajectory Milestones:** The average epoch indices where the scheduler triggered LR reductions.
    3.  **OOF Logits:** The aggregated validation predictions from the SWA models.

**Phase 2: Meta-Calibration**
*   **Objective:** Learn a calibration map to minimize Log Loss.
*   **Method:** Train a **Logistic Regression** (Platt Scaling) model on the Phase 1 OOF Logits to predict the true labels. This corrects any residual miscalibration from the SWA ensemble (Cite solution_lesson_node_00005).

**Phase 3: Production (Full-Fit SWA with Trajectory Replay)**
*   **Objective:** Train 5 independent models on **100% of the training data**.
*   **Trajectory Replay:** Instead of using a reactive scheduler (which fails without a validation set), use a **MultiStepLR** scheduler configured with the **Trajectory Milestones** from Phase 1. Train for exactly $E_{conv}$ epochs.
*   **SWA Phase:** Continue training for the SWA duration used in Phase 1.
*   **Result:** 5 fully-trained SWA models that followed the optimal optimization path.

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views (Cite solution_lesson_node_00031).
*   **Ensemble & Calibration:**
    1.  Average the TTA logits for each model.
    2.  Average the logits across the 5 Full-Fit models.
    3.  Apply the **Phase 2 Calibrator** (Logistic Regression) to the final ensemble logits to generate the submission probabilities.
