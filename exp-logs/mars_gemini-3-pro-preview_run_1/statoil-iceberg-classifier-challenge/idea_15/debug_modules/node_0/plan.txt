The following script demonstrates the end-to-end pipeline for the Iceberg classification task using the provided library files. It covers configuration setup, data loading, model initialization, training, SWA (Stochastic Weight Averaging), calibration using Platt Scaling, and inference with Test Time Augmentation (TTA).

The script is optimized for speed by enabling `DEBUG` mode (using a subset of data) and running for a minimal number of epochs. It includes assertions to verify the correctness of shapes and logic at each step.
