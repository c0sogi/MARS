Based on the comprehensive analysis of previous attempts and the derived lessons, I propose the **Calibrated Full-Data ResNet-18 Ensemble with Global Epoch Selection**.

This solution structurally evolves the approach by resolving the conflict between "Ensembling" and "Data Scarcity" (Lesson 00020, 00023). It replaces the Bagging approach of Idea 7 and the flawed Full-Fit attempt of Idea 10 with a rigorous **Two-Phase Training Protocol**. This protocol uses Cross-Validation solely for calibration (Global Epoch Selection) and then trains a Seed Ensemble on 100% of the data, strictly preserving the gradient step volume and optimization dynamics that proved successful in Idea 7.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Corrected Composite Fusion:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ the successful geometric augmentation pipeline from Idea 7:
    *   **RandomRotate90** (Discrete rotations) (Cite solution_lesson_node_00028).
    *   **Rotate** with a limit of $\pm 20^{\circ}$ (Continuous rotation). This combination is critical for rotational invariance (Cite solution_lesson_node_00031).
    *   Horizontal and Vertical Flips.
    *   We will **not** use Mixup or Label Smoothing, relying on the augmentation and TTA for calibration (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Protocol** to maximize data usage while ensuring convergence stability.

**Phase 1: Calibration (Global Epoch Selection)**
*   **Objective:** Determine the optimal number of training epochs ($E^*$) and learning rate schedule milestones.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimization:** Use **AdamW** (`weight_decay=0.01`) with a **Batch Size of 32** and a **ReduceLROnPlateau** scheduler. We strictly enforce the Batch Size of 32 to maintain the high gradient step volume that was critical to Idea 7's success (Cite solution_lesson_node_00038).
*   **Selection Criterion:** Calculate the average validation loss across all folds for each epoch. Select $E^*$ as the epoch that minimizes this global average curve (Cite solution_lesson_node_00040). Record the average epochs where the LR scheduler triggered reductions.

**Phase 2: Production (Full-Fit Seed Ensemble)**
*   **Objective:** Train the final models on the maximum available data.
*   **Method:** Train **5 independent models** on **100% of the training data** (Train + Validation combined) for exactly $E^*$ epochs. Each model uses a different random seed.
*   **Optimization:** Use the same settings as Phase 1 (AdamW, Batch Size 32).
*   **Schedule:** Use a **MultiStepLR** scheduler with milestones set to the average reduction epochs identified in Phase 1. This replicates the reactive optimization trajectory of the calibration phase without needing a validation set (Cite solution_lesson_node_00038).

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views. We explicitly use all three views to marginalize out variance (Cite solution_lesson_node_00031, solution_lesson_node_00025).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit models**. This provides the variance reduction of an ensemble while ensuring every model is trained on the full dataset (Cite solution_lesson_node_00020).
