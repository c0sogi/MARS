The strategy involves a two-phase training protocol to implement the **Gradient-Isovariant ResNet-18 SWA Ensemble**.

1.  **Phase 1: Calibration & Validation**: We first train a single `IcebergResNet18` model on the training split (80%) and validate on the hold-out set (20%). This serves three purposes:
    *   **Metric Reporting**: It provides the required validation metric on held-out data.
    *   **Failure Analysis**: It allows us to correlate prediction errors with incidence angles on unseen data.
    *   **Volume Discovery**: It identifies the optimal number of *total gradient steps* ($S_{opt}$) required for convergence, determined by the epoch with the lowest validation loss.

2.  **Phase 2: Production (Full-Fit)**: If the validation metric meets the threshold, we proceed to the production phase. We calculate the number of epochs required to replicate $S_{opt}$ on the *full* dataset (100% of labeled data). We then train an ensemble of 5 independent models using this isovariant epoch count, followed by Stochastic Weight Averaging (SWA) to improve generalization.

3.  **Inference**: Finally, we load the 5 SWA models and generate predictions on the test set using Exhaustive Closed-Group Test-Time Augmentation (TTA). The predictions are averaged and saved to `submission.csv`.
