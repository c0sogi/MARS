This script demonstrates the end-to-end pipeline for the Iceberg Classification task using the provided library modules. It covers data loading, model instantiation, a fast-forwarded training process (calibration and production phases) using a debug subset of data, and finally generates a submission file.

The strategy involves:
1.  **Setup**: configuring paths and seeds for reproducibility.
2.  **Data Verification**: Instantiating dataloaders to verify input shapes and data processing logic.
3.  **Model Verification**: Instantiating the ResNet18-based model and performing a forward pass to check output dimensions.
4.  **Training Pipeline**: Executing the `Trainer` class methods in debug mode. This runs a shortened 5-fold calibration to determine optimal steps, followed by a production run to train a single SWA (Stochastic Weight Averaging) model.
5.  **Inference**: Loading the trained SWA model, performing Test-Time Augmentation (TTA) on the test set, and generating a valid submission CSV.
