My implementation strategy focuses on reverting the detrimental semi-supervised learning components and reinforcing the robust supervised baseline that previously yielded the best results.

1.  **Remove Semi-Supervised Pipeline (Cite solution_lesson_node_00053)**: The previous execution showed that the Teacher-Student approach degraded performance (0.1948) compared to the supervised baseline (0.1692). I will modify `runfile.py` to remove the pseudo-labeling and student training stages, focusing solely on optimizing the "Teacher" ensemble.

2.  **Simplify Model Architecture (Cite solution_lesson_node_00019)**: I will replace the learnable Generalized Mean (GeM) pooling in `library/model.py` with standard Global Average Pooling (GAP). On small, noisy datasets like this SAR collection, learnable pooling parameters can introduce instability or overfitting. GAP acts as a robust low-pass filter for speckle noise.

3.  **Refine Calibration and SWA (Cite solution_lesson_node_00055, solution_lesson_node_00065)**:
    -   In `runfile.py`, I will increase `MAX_EPOCHS_CV` from 30 to 50 to ensure the cross-validation phase finds the true convergence "basin" without being cut off prematurely.
    -   I will increase `SWA_EPOCHS` from 10 to 12 to allow sufficient trajectory averaging.
    -   The final training loop will use the calibrated `avg_best_epoch` as the pre-SWA duration, ensuring SWA starts only after the model has stabilized.

class GeM(nn.Module):
    """
    Generalized Mean Pooling (GeM) layer.
    Computes the generalized mean of the input tensor.

    Formula: f(X) = (1/|X| * sum(x^p))^(1/p)

    Args:
        p (float): Initial value for the power parameter. Default: 1.0 (Average Pooling).
        eps (float): Small constant to avoid numerical instability.
    """

    def __init__(self, p=1.0, eps=1e-6):
        super(GeM, self).__init__()
        self.p = nn.Parameter(torch.ones(1) * p)
        self.eps = eps

    def forward(self, x):
        return self.gem(x, p=self.p, eps=self.eps)

    def gem(self, x, p=3, eps=1e-6):
        # x shape: (N, C, H, W)
        # We perform pooling over the spatial dimensions (H, W)
        # clamp(min=eps) ensures non-negative base for power operation
        return F.avg_pool2d(x.clamp(min=eps).pow(p), (x.size(-2), x.size(-1))).pow(
            1.0 / p
        )

    def __repr__(self):
        return (
            self.__class__.__name__
            + "("
            + "p="
            + "{:.4f}".format(self.p.data.tolist()[0])
            + ", "
            + "eps="
            + str(self.eps)
            + ")"
        )
