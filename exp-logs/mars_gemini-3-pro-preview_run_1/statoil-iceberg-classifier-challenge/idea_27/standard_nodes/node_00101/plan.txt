Implementation Strategy:
The solution implements a robust "Hybrid-Input SWA-ResNet Ensemble" pipeline. 
1.  **Data Management**: We load the raw dataset and filter it into training and validation subsets based on the provided metadata CSVs to strictly prevent leakage. Normalization statistics are computed solely on the training subset.
2.  **Phase 1 (Calibration)**: We perform a 5-Fold Stratified Cross-Validation on the training subset. We use `ReduceLROnPlateau` to dynamically adjust the learning rate and identify the optimal convergence epoch ($E_{conv}$) and stable final learning rate ($LR_{final}$) that minimize TTA-Validation Loss.
3.  **Phase 2 (Production)**: We train an ensemble of 5 ResNet-18 models (3 using Mean-channel input, 2 using Difference-channel input) on the full training subset. We map the trajectory discovered in Phase 1 to a deterministic `CosineAnnealingLR` schedule ($T_{max}=E_{conv}$), followed by a 5-epoch Stochastic Weight Averaging (SWA) phase to enhance generalization.
4.  **Evaluation & Submission**: We evaluate the ensemble on the hold-out validation set using Klein Four-Group Test-Time Augmentation (TTA). If the log loss is below the specified threshold, we generate predictions for the test set and create the submission file. Failure analysis is performed by correlating prediction errors with incidence angles.
