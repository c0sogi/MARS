Implementation Strategy:
1.  **Setup & Imports**: Import necessary libraries (`torch`, `numpy`, `pandas`, `scipy`) and the provided library modules (`utils`, `dataset`, `model`, `trainer`). Set the random seed for reproducibility.
2.  **Configuration**: Define parameters for training (15 epochs, patience 5) to ensure the baseline runs quickly within the time limit.
3.  **Data Loading**: Use `get_dataloaders` to load train, validation, and test sets. Enable caching to speed up data processing.
4.  **Model & Training**: Initialize the `DepthAwareUNet` and `SaltTrainer`. Execute the training loop with early stopping.
5.  **Validation & Failure Analysis**:
    *   Load the best saved model.
    *   Iterate through the validation set to calculate the competition-specific metric (Mean Average Precision at IoU thresholds 0.5-0.95).
    *   Simultaneously extract input features (depth from channel 1, image intensity stats from channel 0) and compute the prediction error (1 - precision) for each sample.
    *   Calculate and print the global "Final Validation Metric".
    *   Calculate Pearson correlations between the error and input features to identify failure modes.
6.  **Submission**: Generate predictions for the test set using the trained model. The `generate_submission` method handles cropping (back to 101x101) and RLE encoding. Save the result to `./submission/submission.csv`.
