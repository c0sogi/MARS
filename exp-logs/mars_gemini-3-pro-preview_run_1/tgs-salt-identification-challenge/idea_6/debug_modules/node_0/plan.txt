### Implementation Strategy

1.  **Environment Setup**: Import necessary standard libraries and the provided custom library modules (`library.utils`, `library.dataset`, `library.model`, `library.losses`, `library.trainer`). Set random seeds for reproducibility.
2.  **Utility Verification**:
    *   Test `rle_encode` and `rle_decode` by creating a synthetic mask, encoding it, decoding it, and asserting the result matches the original.
    *   Test `pad_image_128` and `unpad_image_101` to ensure image dimensions are correctly transformed for the network architecture.
    *   Test `do_kaggle_metric` with synthetic predictions to verify the mean Average Precision calculation logic.
3.  **Dataset & DataLoader Verification**:
    *   Initialize the `SaltDataset` (which handles caching automatically) and `DataLoader`.
    *   Fetch a single batch to verify tensor shapes (Image: `[B, 2, 128, 128]`, Mask: `[B, 1, 128, 128]`) and data types.
4.  **Model Architecture Verification**:
    *   Instantiate the `ResUNetPPM` model.
    *   Perform a forward pass with dummy data in training mode to verify it returns logits and deep supervision outputs.
    *   Perform a forward pass in evaluation mode to verify it returns only logits.
5.  **Loss Function Verification**:
    *   Test `BCEDiceLoss` and `LovaszBCELoss` with dummy logits and targets to ensure they return a scalar loss value.
6.  **Training Loop Integration**:
    *   Instantiate the `Trainer` class with `debug=True` and `epochs=1`. This configuration limits the run to a few batches for speed while exercising the full training pipeline (forward pass, backward pass, optimizer step, validation, checkpointing).
    *   Execute `trainer.fit()` to simulate a training run.
    *   Execute `trainer.generate_submission()` to verify the inference and submission file generation pipeline.
7.  **Output Verification**: Check for the existence of generated checkpoints and the submission file.
