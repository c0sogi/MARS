The implementation strategy involves the following steps:

1.  **Setup and Loading**: Initialize the environment and load the raw CSV files (`train.csv`, `depths.csv`, `sample_submission.csv`) from the `./input` directory.
2.  **Data Merging**: Merge the depth information from `depths.csv` into both the training and test dataframes based on the image `id`.
3.  **Feature Engineering for Stratification**: Calculate the salt coverage area for each training image by decoding the Run-Length Encoding (RLE) masks provided in `train.csv`. Convert this area into a coverage percentage and bin it into discrete classes (e.g., 10 bins) to define stratification groups.
4.  **Stratified Splitting**: Use `sklearn.model_selection.train_test_split` with `stratify` set to the calculated coverage classes to split the training data into an 80% training set and a 20% validation set, using a fixed random state of 42.
5.  **Path Generation**: Construct relative file paths for images and masks.
    *   For training and validation sets (derived from the original train data), paths point to `train/images/{id}.png` and `train/masks/{id}.png`.
    *   For the test set, paths point to `test/images/{id}.png`.
6.  **Saving Metadata**: Save the processed dataframes as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
7.  **Validation and Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (shape, class distribution).
    *   Perform a file existence check on a random sample of 1000 paths to ensure the generated relative paths are correct.
    *   Programmatically verify that the validation split respects the stratification logic by comparing the distribution of coverage classes between the training and validation sets.
