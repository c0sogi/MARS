The following script demonstrates the usage of the provided library files for the Salt Segmentation task. It validates the core utility functions (RLE encoding/decoding, IoU/mAP metrics), verifies the model and loss components through a forward/backward pass, and executes a complete (but minimized) training and inference pipeline using the provided entry points.

The script overrides the global `Config` to ensure execution completes quickly (using a subset of data and minimal epochs) and directs all artifacts to the `./working` directory.
