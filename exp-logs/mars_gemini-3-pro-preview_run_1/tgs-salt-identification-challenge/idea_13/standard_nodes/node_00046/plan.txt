Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Training**: We will instantiate the provided `Trainer` class and execute the `fit()` method. This handles the 150-epoch training schedule with Curriculum Learning (BCE+Dice $\to$ Lovasz) and saves checkpoints for Snapshot Ensembling (Cycle 2 and Cycle 3).
2.  **Ensemble Inference**: We will implement a robust inference function that:
    *   Loads the checkpoints for Cycle 2 and Cycle 3 (falling back to the global best model if specific cycle checkpoints are missing).
    *   Applies **Test-Time Augmentation (TTA)** by averaging predictions from the original image and its horizontal flip.
    *   Averages the predictions across the loaded checkpoints (Snapshot Ensemble).
    *   Performs center-cropping to revert the $128 \times 128$ padded predictions back to the original $101 \times 101$ resolution.
3.  **Validation**: We will run the ensemble inference on the hold-out validation set to compute the `Final Validation Metric` (mAP).
4.  **Failure Analysis**: We will calculate the mAP for each validation image individually. We will then merge these scores with the metadata (depth, salt coverage) to compute and print Pearson correlations, identifying which factors contribute to model errors.
5.  **Submission**: If the validation mAP exceeds the threshold of 0.833, we will generate predictions for the test set using the same ensemble strategy, apply Run-Length Encoding (RLE), and save the `submission.csv`.
