The `AssertionError: Mask values must be binary (0 or 1)` occurs because the cached mask data loaded in `SaltDataset` likely contains pixel values of 0 and 255 (standard 8-bit image format), whereas the code expects them to be strictly 0 and 1. While the `_load_data` method includes logic to binarize masks when processing from scratch, the `__getitem__` method directly converts the loaded (potentially cached) values to float tensors without normalization or thresholding. To fix this, we must explicitly enforce the binary contract in `__getitem__` by thresholding the mask tensor, ensuring it always contains 0.0 or 1.0 regardless of the source data's scale.
