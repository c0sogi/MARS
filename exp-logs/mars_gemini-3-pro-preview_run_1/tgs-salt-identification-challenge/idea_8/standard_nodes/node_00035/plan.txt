This increases the effective training set size, which is critical for performance in data-constrained regimes.
2.  **Architecture Simplification (Cite {solution_lesson_node_00033}):** I will replace the `ResUNetASPP` with a `DeepResUNet`. The Atrous Spatial Pyramid Pooling (ASPP) module will be removed and replaced with a standard Residual Block bottleneck. ASPP's large receptive field is likely introducing noise on the small 101x101 input images.
3.  **Optimization Stability (Cite {solution_lesson_node_00033}, Cite {solution_lesson_node_00018}):** I will remove the hard switch to the Lovasz-Hinge loss function, which caused catastrophic forgetting in the previous run. Instead, I will use the consistent `Phase1Loss` (BCE + Sample-Wise Dice) throughout the entire 150-epoch training duration. Additionally, I will increase the batch size to 64 to improve gradient stability (Cite {solution_lesson_node_00023}).

        self.input_conv = nn.Sequential(

            nn.BatchNorm2d(filters),
            nn.ReLU(inplace=True),

        self.enc2 = ResidualBlock(filters, filters * 2, stride=2)

        self.enc3 = ResidualBlock(filters * 2, filters * 4, stride=2)

        # Level 4: 16x16, 512 filters (Downsampled via Stride 2)
        self.enc4 = ResidualBlock(filters * 4, filters * 8, stride=2)
