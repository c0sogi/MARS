The following script demonstrates the usage of the provided library components for the Salt Segmentation task.

### Implementation Strategy
1.  **Configuration Setup**: We override the default `Config` parameters to run in a lightweight "Debug" mode. This involves reducing the dataset size, batch size, and number of epochs to ensure the script executes quickly (within seconds/minutes).
2.  **Utility Verification**: We validate the correctness of the Run-Length Encoding (RLE) and IoU/mAP metric calculation functions using synthetic data with known ground truths.
3.  **Data Pipeline**: We initialize the `SaltDataset` via `get_dataloaders` and verify that the data shapes (images, masks, depths) and preprocessing (padding, depth fusion) are correct.
4.  **Model Architecture**: We instantiate the `ResUNetASPP` model and verify its behavior in both training (deep supervision with auxiliary heads) and evaluation (single output) modes.
5.  **Loss Functions**: We test both `Phase1Loss` (BCE+Dice) and `Phase2Loss` (BCE+Lovasz) to ensure they compute gradients correctly.
6.  **Training & Inference Loop**: We run a minimal training loop (1 epoch) and an evaluation step using the `engine` module, followed by generating a sample submission file to verify the end-to-end pipeline.
