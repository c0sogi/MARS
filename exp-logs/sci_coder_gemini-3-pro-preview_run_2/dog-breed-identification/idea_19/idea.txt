Based on the "Lessons Learned" and the trajectory of previous experiments, I propose the **Dual-Stream Multi-Resolution Strong-Learner Ensemble** strategy.

This approach represents a structural evolution of the "Multi-View Early Fusion" baseline (Lesson 00019) by addressing the "Performance Disparity" failure observed in previous ensembles (Lesson 00014, 00029). Instead of pairing a strong CNN with a weak Transformer, we will pair the current best backbone (`ConvNeXt`) with a **Massive-Scale CNN** (`RegNetY-128GF`) initialized with **SWAG weights**. This ensures both streams are "Strong Learners" with high linear separability (Lesson 00036), while introducing critical diversity across **Architecture** (ConvNeXt vs. RegNet), **Pre-training Data** (ImageNet-1k vs. SWAG), and **Input Resolution** (224px vs. 384px).

# Model
We will construct a prediction system composed of two independent, high-capacity processing streams. Both will utilize **Linear Probing** on frozen features, strictly adhering to the "Late Fusion" protocol for heterogeneous architectures (Cite solution_lesson_node_00009).

1.  **Stream A (Baseline):** **`ConvNeXt-Large`** initialized with **`torchvision` "New Recipe" weights** (`IMAGENET1K_V1`).
    *   *Role:* Retains the high-performance, texture-biased features of the current best solution (Cite solution_lesson_node_00006).
    *   *Native Resolution:* **224x224**.
2.  **Stream B (High-Res Diversity):** **`RegNetY-128GF`** initialized with **`torchvision` SWAG weights** (`IMAGENET1K_SWAG_E2E_V1`).
    *   *Innovation:* This massive CNN (128 GigaFlops) pre-trained on billions of weakly supervised images (SWAG) provides a feature space that is statistically distinct from standard ImageNet-1k supervision but maintains the high linear separability of CNNs. This directly addresses the failure of SSL/MIM models (Cite solution_lesson_node_00032) and weak supervised baselines (Cite solution_lesson_node_00014).
    *   *Native Resolution:* **384x384** (typical for SWAG models), adding multi-scale diversity.
3.  **Classifiers:** Two independent **`LogisticRegressionCV`** heads.
    *   We use Cross-Validation to auto-tune `C` for each stream, preventing the underfitting observed in previous ensembles (Cite solution_lesson_node_00021).
    *   We strictly avoid Tree-based heads, relying on the proven efficiency of Linear Probes for high-dimensional CNN embeddings (Cite solution_lesson_node_00036).

# Data
We will implement a **Stream-Specific Multi-View Pipeline** for *each* backbone. This leverages the "Multi-View Early Fusion" strategy (Cite solution_lesson_node_00019) to maximize the signal-to-noise ratio for each architecture independently.

1.  **View Generation:** For every image, generate three geometric representations (Cite solution_lesson_node_00016):
    *   **Global View:** Resize to Input Size (Squish). Captures topology.
    *   **Standard View:** Resize and Center Crop. Matches pre-training.
    *   **Local View:** Resize to `1.28x` Input Size and Center Crop (Zoom). Captures texture.
        *   *Constraint:* Use a deterministic Center Crop. Do **not** use spatial averaging (TenCrop), which dilutes signal with background noise (Cite solution_lesson_node_00028).
2.  **Stream-Specific Preprocessing:**
    *   **Stream A (ConvNeXt):** Input Size **224**. Interpolation **Bicubic** (Cite solution_lesson_node_00032).
    *   **Stream B (RegNet):** Input Size **384**. Interpolation **Bicubic**. Use the specific Mean/Std associated with SWAG weights (Cite solution_lesson_node_00005).

# Training
The training process combines **Intra-Stream Early Fusion** (concatenation) and **Inter-Stream Late Fusion** (ensemble).

1.  **Feature Extraction & TTA:**
    *   Apply **Horizontal Flipping** to all views and average the embeddings of the original and flipped versions (Cite solution_lesson_node_00006).
    *   **Crucially**, extract features using the architecture's native Global Average Pooling and LayerNorm/BatchNorm. Do **not** extract raw feature maps or intermediate layers (Cite solution_lesson_node_00025, solution_lesson_node_00035).
2.  **Intra-Stream Early Fusion:**
    *   For Stream A, **concatenate** embeddings from Global (224), Standard (224), and Local (224) views.
    *   For Stream B, **concatenate** embeddings from Global (384), Standard (384), and Local (384) views.
    *   Do **not** apply L2 normalization; preserve feature magnitude (Cite solution_lesson_node_00015).
3.  **Parallel Optimization:**
    *   Train `LogisticRegressionCV` on Stream A's concatenated features.
    *   Train `LogisticRegressionCV` on Stream B's concatenated features.
4.  **Ensemble Weight Optimization:** Learn optimal scalar weights $(w_A, w_B)$ on the validation set to minimize Log Loss. This ensures the ensemble only benefits from the RegNet stream if it provides additive signal (Cite solution_lesson_node_00012).

# Evaluation
1.  **Inference:**
    *   Load test images.
    *   Process through Pipeline A (224px, ConvNeXt) to get Probability Vector $P_A$.
    *   Process through Pipeline B (384px, RegNet) to get Probability Vector $P_B$.
2.  **Fusion:**
    *   Compute final prediction: $P_{final} = w_A \cdot P_A + w_B \cdot P_B$.
3.  **Cache Safety:**
    *   Store embeddings in directories explicitly named `convnext_large_v1` and `regnet_y_128gf_swag` to prevent cache collisions (Cite solution_lesson_node_00018).
