The execution failure was caused by **stale default argument binding** in `library/utils.py`. The function `save_submission` used `Config.SUBMISSION_PATH` as a default argument value, which is evaluated only once at import time. Consequently, when `runfile.py` updated `Config.SUBMISSION_PATH` at runtime to point to the demo directory, `save_submission` continued to use the original path, saving the file to the wrong location. This led the verification step to read a stale file with incorrect dimensions, triggering the `AssertionError`.

To fix this, I will modify `seed_everything` and `save_submission` in `library/utils.py` to set their default arguments to `None` and resolve the configuration values dynamically inside the function body.
