This script demonstrates the end-to-end workflow using the provided library modules. It performs the following steps:
1.  **Setup**: Sets random seeds for reproducibility.
2.  **Feature Extraction**: Uses `feature_engine.extract_embeddings` to extract features from the CNN and ViT backbones for a small subset (debug mode) of the training, validation, and test data. This validates the data loading and model inference pipelines.
3.  **Model Training**: Uses `logistic_model.train_classifier` to train a Logistic Regression model on the extracted training features and evaluates it on the validation set.
4.  **Inference**: Uses the trained model to predict breed probabilities for the test set.
5.  **Submission**: Generates a submission CSV file in the required format and verifies its structure.
