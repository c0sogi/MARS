The implementation strategy involves orchestrating a high-performance machine learning pipeline using the provided library modules. We will first initialize the environment and ensure reproducibility. The core of the solution is the feature extraction phase, where we employ a dual-backbone architecture (ConvNeXt Large and ViT Large) with Test Time Augmentation (TTA) to generate robust, fused embeddings for the training, validation, and test sets. These embeddings are cached to maximize efficiency. We then train a Logistic Regression classifier on these high-dimensional features. Following training, we conduct a rigorous validation assessment to compute the Multi-Class Log Loss and perform failure analysis by correlating prediction errors with image properties (dimensions) and embedding signal strength. Finally, conditional on the validation performance meeting the strict threshold, we generate the submission file for the test set.
