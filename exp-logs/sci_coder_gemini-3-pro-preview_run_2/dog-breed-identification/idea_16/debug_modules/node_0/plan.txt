This script demonstrates the end-to-end usage of the provided library components to solve the dog breed classification task. It performs the following steps:

1.  **Data Preparation**: Loads the metadata and creates small subsets (50 training, 20 validation, 20 test samples) to ensure the demonstration runs quickly within the time limit.
2.  **Feature Extraction**: Iterates through the three defined views (Global, Standard, Local). For each view, it initializes the `DogDataset` and `DataLoader`, then uses `model_utils.run_inference` to extract Stage 3 (texture) and Stage 4 (semantic) features from the ConvNeXt backbone.
3.  **Feature Fusion**: Utilizes `feature_processing.process_features` to normalize the intermediate features and concatenate them into a single high-dimensional feature vector for each image.
4.  **Model Training**: Trains a Logistic Regression classifier on the fused features.
5.  **Validation & Submission**: Evaluates the model on the validation subset and generates a submission file for the test subset in the required format.

Throughout the script, assertions are used to verify the shapes of tensors and arrays, ensuring the logic of the library classes is functioning as expected.
