Based on the comprehensive analysis of the "Lessons Learned" and the failures of previous ensemble attempts, I propose the **Dual-Stream Heterogeneous Strong-Learner Ensemble** strategy.

This approach structurally evolves the solution by integrating a second **State-of-the-Art (SOTA) Hybrid Architecture** (`MaxViT`) to complement the strong CNN baseline (`ConvNeXt`). It specifically addresses the "Weak Base Learner" failure (Cite solution_lesson_node_00014) by selecting a secondary model that matches the primary model's predictive power, while adhering to the "Multi-View Early Fusion" protocol (Cite solution_lesson_node_00019) that yielded the best results.

# Model
We will construct a prediction system composed of two independent, high-capacity processing streams. This design leverages the complementary strengths of a pure CNN and a CNN-Transformer Hybrid without mixing their feature spaces.

1.  **Stream A (Pure CNN):** The **`ConvNeXt-Large`** architecture initialized with **`torchvision` "New Recipe" weights** (`IMAGENET1K_V1`). This retains the proven, high-performance base estimator from the current best solution (Cite solution_lesson_node_00006).
2.  **Stream B (Hybrid CNN-Transformer):** The **`MaxViT-Large`** architecture (e.g., `maxvit_large_tf_224.in1k` from `timm`).
    *   *Innovation:* Unlike previous attempts with pure Transformers (ViT/Swin) which proved to be weak linear probes (Cite solution_lesson_node_00029), MaxViT utilizes **Multi-Axis Self-Attention** combined with **MBConv (Convolutional)** blocks. This hybrid design provides the global context of transformers while retaining the strong inductive bias and linear separability of CNNs, making it a "Strong Learner" comparable to ConvNeXt (Cite solution_lesson_node_00014).
3.  **Independent Classifiers:** Each stream will terminate in its own independent **`LogisticRegressionCV`** head.
    *   We will **not** concatenate embeddings between streams (Heterogeneous Early Fusion) to prevent distribution mismatch (Cite solution_lesson_node_00009).
    *   We will use **Cross-Validation** to automatically tune the regularization parameter `C` for each stream, preventing the underfitting observed in previous ensembles (Cite solution_lesson_node_00021).

# Data
We will implement a **Stream-Specific Multi-View Pipeline** for *each* backbone. This leverages the "Multi-View Early Fusion" strategy (Cite solution_lesson_node_00019) to maximize the signal-to-noise ratio for each architecture independently.

1.  **View Generation:** For every image, generate three geometric representations (Cite solution_lesson_node_00016):
    *   **Global View:** Resize to 224x224 (Squish). Preserves object topology.
    *   **Standard View:** Resize to 232 and Center Crop to 224. Matches standard pre-training.
    *   **Local View:** Resize to 288 and **Center Crop** to 224 (Zoom).
        *   *Constraint:* We will use a deterministic Center Crop, rejecting the "TenCrop" spatial averaging which degrades performance by introducing background noise (Cite solution_lesson_node_00028).
2.  **Stream-Specific Preprocessing:**
    *   **Stream A:** Use `torchvision` transforms (Bilinear interpolation, standard Mean/Std).
    *   **Stream B:** Use `timm` MaxViT-specific transforms (often Bicubic interpolation, specific Mean/Std) to ensure perfect alignment with the pre-training recipe (Cite solution_lesson_node_00005).

# Training
The training process combines **Intra-Stream Early Fusion** (for homogeneous data views) and **Inter-Stream Late Fusion** (for heterogeneous architectures).

1.  **Feature Extraction & TTA:**
    *   Apply **Horizontal Flipping** to all views and average the embeddings of the original and flipped versions (Cite solution_lesson_node_00006).
    *   **Crucially**, ensure feature extraction retains the architecture's native **Layer Normalization** (extracting the pooled output *after* the final Norm layer) to avoid the performance degradation observed with raw feature maps (Cite solution_lesson_node_00025).
2.  **Intra-Stream Early Fusion:**
    *   For Stream A, **concatenate** the embeddings from the Global, Standard, and Local views into a single feature vector. Do **not** apply L2 normalization (Cite solution_lesson_node_00015).
    *   Perform the same concatenation for Stream B.
    *   This allows the linear classifiers to learn correlations between shape and texture within a coherent feature space (Cite solution_lesson_node_00019).
3.  **Parallel Optimization:**
    *   Train `LogisticRegressionCV` on Stream A's concatenated features.
    *   Train `LogisticRegressionCV` on Stream B's concatenated features.
4.  **Ensemble Weight Optimization:** Learn optimal scalar weights $(w_A, w_B)$ on the validation set to minimize the combined Log Loss. If MaxViT underperforms, the optimizer will naturally suppress it, reverting to the strong ConvNeXt baseline (Cite solution_lesson_node_00012).

# Evaluation
1.  **Weighted Late Fusion:**
    *   Generate probability predictions $P_A$ using the full Stream A pipeline.
    *   Generate probability predictions $P_B$ using the full Stream B pipeline.
    *   Compute the final prediction: $P_{final} = w_A \cdot P_A + w_B \cdot P_B$.
2.  **Cache Safety:** Store embeddings in directories explicitly named with the model architecture (e.g., `convnext_large_sup`, `maxvit_large_sup`) to prevent cache collisions (Cite solution_lesson_node_00018).
