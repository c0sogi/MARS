The following script generates the required metadata files for the dog breed classification task. It performs the following steps:

1.  **Setup**: Defines input and output directories and sets the random seed.
2.  **Data Loading**: Reads the `labels.csv` for training data and `sample_submission.csv` to identify test set IDs.
3.  **Path Construction**: Adds a `file_path` column to the dataframes, pointing to the images in `train/` and `test/` directories relative to `./input`.
4.  **Splitting**: Performs a stratified 80:20 split on the training data using the `breed` label to create a validation set.
5.  **Saving**: Saves the resulting dataframes to `metadata/train.csv`, `metadata/val.csv`, and `metadata/test.csv`.
6.  **Validation**:
    - Prints summary statistics.
    - Checks the existence of 1000 random file paths from each dataset to ensure the `missing file ratio` is not > 0.5.
    - Verifies that the validation split ratio is correct and that the class distribution is preserved (stratification check).
