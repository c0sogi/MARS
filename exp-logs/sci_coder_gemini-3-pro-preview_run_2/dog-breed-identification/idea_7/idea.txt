Based on the analysis of the provided lessons and the task requirements, I propose the **Multi-Scale Deep Feature Pyramid with Robust Local Aggregation** strategy. This approach structurally evolves the successful "Multi-View" and "Single Strong Backbone" concepts by introducing **Multi-Layer Feature Extraction** and **Robust Crop Aggregation**, addressing the fine-grained nature of dog breed classification while strictly adhering to the integration protocols that yielded the best results.

# Model
- **Backbone Architecture**: We will utilize the **`ConvNeXt-Large`** architecture initialized with **`torchvision` "New Recipe" weights** (`IMAGENET1K_V1`). This retains the high-performance base estimator identified in previous iterations (Cite solution_lesson_node_00006, solution_lesson_node_00011).
- **Deep Feature Pyramid**: Instead of extracting features solely from the final Global Average Pooling (GAP) layer (Stage 4), we will extract and concatenate GAP features from **both Stage 4 (Semantic)** and **Stage 3 (Texture/Pattern)**.
    - *Rationale*: Dog breeds are often distinguished by high-frequency details (fur texture, spots) captured in intermediate layers, which may be lost in the final semantic abstraction. This "Hypercolumn" style representation enriches the feature space without adding architectural heterogeneity.
- **Classifier**: A single **`LogisticRegressionCV`** (Logistic Regression with built-in Cross-Validation) will be trained on the combined feature vector. This ensures optimal regularization tuning, addressing the regression observed when using fixed hyperparameters (Cite solution_lesson_node_00021).

# Data
We will implement a **Multi-Scale, Multi-View Pipeline** that generates three distinct geometric representations for every image. Crucially, we will enhance the "Local" view to be robust against object displacement.

1.  **Global View (Shape)**: Resize image to **224x224** (Squish). This preserves the entire object silhouette (Cite solution_lesson_node_00016).
2.  **Standard View (Context)**: Resize to **232x232** and Center Crop to **224x224**. Matches pre-training defaults.
3.  **Robust Local View (Texture)**: Resize to **288x288**. Instead of a single center crop, apply **Five-Crop Aggregation** (Top-Left, Top-Right, Bottom-Left, Bottom-Right, Center) of size **224x224**.
    - *Aggregation*: The embeddings from these 5 crops will be **averaged** to form a single "Robust Local" feature vector. This ensures we capture texture details even if the dog is not perfectly centered, reducing variance (Cite solution_lesson_node_00006).

# Training
- **Feature Extraction & TTA**: For every image, we will generate the three views. We will apply **Horizontal Flipping** to all inputs (including all 5 crops for the Local view). Features from the original and flipped versions will be averaged (Cite solution_lesson_node_00006).
- **Early Fusion**: We will concatenate the feature vectors from all views and layers into a single high-dimensional representation for each image.
    - Structure: `[Global_Stage4, Global_Stage3, Standard_Stage4, Standard_Stage3, Local_Stage4, Local_Stage3]`.
    - We will **not** apply L2 normalization to these vectors, preserving magnitude signal (Cite solution_lesson_node_00015). This Early Fusion allows the classifier to learn correlations between global shape and local texture (Cite solution_lesson_node_00019).
- **Optimization**: The `LogisticRegressionCV` model will be trained on the concatenated embeddings (approx. 9000 dimensions). The L-BFGS solver will be used for efficiency (Cite solution_lesson_node_00002).

# Evaluation
- **Inference**:
    1.  Load test images and generate the Global, Standard, and Robust Local views.
    2.  Extract Stage 3 and Stage 4 features for all views (applying Flip TTA and Crop Averaging).
    3.  Concatenate features to match the training structure.
    4.  Pass the final vector to the trained `LogisticRegressionCV` model to predict probabilities.
