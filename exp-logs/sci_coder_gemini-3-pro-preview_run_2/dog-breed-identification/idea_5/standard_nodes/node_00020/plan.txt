The implementation strategy involves executing the "Heterogeneous Multi-View Stacking" pipeline defined in the library files.

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and verify access to the library modules.
2.  **Feature Extraction**:
    *   Utilize `library.feature_engine.extract_features` to generate embeddings for the Training and Validation sets.
    *   Perform this for both **Stream A** (ConvNeXt-Large) and **Stream B** (ViT-Large-16).
    *   Enable `load_cached_data=True` to utilize any existing processed features, speeding up execution.
3.  **Model Training**:
    *   Train independent Logistic Regression classifiers for both streams using `library.classifier.train_logreg`.
    *   This step is computationally efficient as it operates on pre-computed low-dimensional embeddings.
4.  **Ensemble Optimization**:
    *   Calculate the optimal weighting between Stream A and Stream B using `library.classifier.optimize_ensemble_weights` on the validation predictions.
5.  **Validation & Metric Reporting**:
    *   Compute the final weighted ensemble log loss on the validation set.
    *   Print the metric in the strictly required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Compute the log loss for each individual validation sample.
    *   Correlate these error values with image metadata (width, height, aspect ratio) to identify systematic weaknesses (e.g., does the model fail on small or irregular images?).
7.  **Submission Generation**:
    *   Check if the validation metric meets the threshold (< 0.1164).
    *   If successful, trigger `library.classifier.generate_submission` to predict on the Test set and save the `submission.csv`.
