Implementation Strategy
The implementation will follow a step-by-step demonstration of the provided library components, culminating in a full pipeline execution.

1.  **Environment Setup**: Import standard libraries and the provided `library` modules (`config`, `dataset`, `backbones`, `feature_engine`, `classifier`, `ensemble`). Set random seeds for reproducibility.
2.  **Dataset & DataLoader Demo**: Instantiate `MultiViewDataset` in debug mode. Fetch a single sample to verify the dictionary structure of the views ('standard', 'global', 'local') and their tensor shapes. Initialize a `DataLoader` to confirm batch processing works.
3.  **Backbone Demo**: Load the feature extractor (ConvNeXt) defined in the configuration. Pass a dummy input tensor through the model to verify it runs without errors and outputs embeddings with the correct dimensionality (1536).
4.  **Feature Engine Demo**: Manually invoke `extract_features` on the training set (debug subset). Verify that the resulting embeddings correspond to the concatenation of the three views (Total Dimension = 1536 * 3) and that labels are correctly aligned.
5.  **Classifier Demo**: Train a Logistic Regression model using the features extracted in the previous step. Verify that the `train_logreg` function returns a trained model and validation probabilities with the correct shape.
6.  **Full Pipeline Demo**: Run the `classifier.run_classifier_pipeline` function with `debug=True`. This demonstrates the end-to-end workflow: extracting features for the second stream (ViT), training both stream classifiers, optimizing the ensemble weights, and generating the final `submission.csv`.
7.  **Validation**: Throughout the script, `assert` statements will be used to enforce expected shapes and logic. Finally, verify the existence and dimensions of the generated submission file.
