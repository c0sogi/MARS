This mismatch causes a `ValueError`.

To fix this, I will explicitly pass the `labels` parameter to `log_loss` using `clf.classes_`. This informs the metric of the full set of classes the model outputs probabilities for, resolving the ambiguity. I will apply this fix to `train_logreg` where the error occurred, and also update `optimize_ensemble_weights` and its call site in `run_classifier_pipeline` to prevent the same error from occurring during the ensemble optimization step.
