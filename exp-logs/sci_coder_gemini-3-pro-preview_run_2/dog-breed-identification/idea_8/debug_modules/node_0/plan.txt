Implementation Strategy:
1.  **Configuration & Setup**: Initialize random seeds for reproducibility. Modify `library.config` at runtime to enable `DEBUG` mode and reduce sample sizes/CV folds, ensuring the script executes quickly (within minutes) while still exercising the code paths.
2.  **Component Verification**:
    *   **Transforms**: Instantiate global, standard, and local transforms. Apply them to a synthetic image and assert that the output tensor shapes match the expected dimensions (including the 5-crop dimension for the local view).
    *   **Dataset**: Instantiate the `DogDataset` in debug mode using the provided real metadata. Verify that it loads images correctly and returns the expected `(image, label)` or `(image, id)` tuples.
    *   **Model**: Instantiate the `ConvNeXtMultiLayerExtractor`. Pass a dummy tensor through it to verify that it correctly extracts and pools features from Stage 3 and Stage 4, returning the correct dictionary structure and tensor shapes.
    *   **Embedding Pipeline**: Run `get_dataset_embeddings` for the training set in debug mode. This validates the integration of the dataset, model, and caching logic with real data.
3.  **Integration Test (Classifier)**:
    *   Create a temporary "dummy" metadata CSV with a small subset of breeds (3 classes).
    *   Override `config.TRAIN_METADATA_PATH` to point to this dummy file.
    *   Generate synthetic embeddings and labels matching these 3 classes.
    *   Run `train_and_predict` with these synthetic inputs. This verifies the `LogisticRegressionCV` training, validation logic, and the formatting of the final submission CSV.
4.  **Cleanup**: Ensure temporary files created during the run are cleaned up, leaving the environment tidy.
