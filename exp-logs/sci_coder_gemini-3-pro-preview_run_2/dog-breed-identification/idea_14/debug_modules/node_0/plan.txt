This script demonstrates the end-to-end pipeline for the dog breed classification task using the provided library files. It overrides specific configuration parameters to speed up the execution (reducing Cross-Validation folds and regularization search space) while maintaining the integrity of the full dataset processing.

The workflow includes:
1.  **Setup**: Initializing seeds and overriding `config` for speed.
2.  **Data Preparation**: Loading metadata and creating `MultiViewDataset` instances for Train, Val, and Test splits.
3.  **Feature Extraction**: Using `timm` backbones (ConvNeXt and ViT) to extract Global, Standard, and Local view embeddings for both streams.
4.  **Feature Fusion**: Concatenating embeddings from different views.
5.  **Modeling**: Training Logistic Regression heads on the fused features and evaluating them.
6.  **Ensemble**: Optimizing weights between the two streams to minimize Log Loss.
7.  **Submission**: Generating the final CSV submission file.
