Based on the analysis of the "Lessons Learned" and the trajectory of "Previous Ideas," I propose the **Multi-Scale Deep Feature Pyramid with Robust Local Aggregation** strategy.

This approach structurally evolves the current best-performing "Multi-View Early Fusion" strategy (Lesson 00019) by addressing two specific limitations:
1.  **Semantic Information Loss:** The current solution relies solely on the final Global Average Pooling (Stage 4) layer, which abstracts away high-frequency texture details (fur patterns, spotting) critical for fine-grained breed classification.
2.  **Localization Variance:** The "Local" view in the current pipeline relies on a single center crop, which risks missing distinctive features (ears, tails) if the subject is not perfectly centered.

### Model
-   **Backbone Architecture:** We will utilize the **`ConvNeXt-Large`** architecture initialized with **`torchvision` "New Recipe" weights** (`IMAGENET1K_V1`). This preserves the high-quality base estimator identified as superior to other variants (Cite solution_lesson_node_00011).
-   **Deep Feature Pyramid:** We will modify the feature extraction mechanism to retrieve Global Average Pooled (GAP) embeddings from **two distinct layers**:
    1.  **Stage 4 (Final):** Captures high-level semantic shape and object identity (1536 dimensions).
    2.  **Stage 3 (Intermediate):** Captures mid-level texture and pattern information (768 dimensions), which is often lost in the final downsampling but is crucial for distinguishing breeds with similar shapes but different coats.
-   **Classifier:** A single **`LogisticRegressionCV`** classifier will be trained on the combined feature space. This ensures automated tuning of the regularization parameter `C`, preventing the performance regression observed when using fixed hyperparameters (Cite solution_lesson_node_00021).

### Data
We will implement a **Robust Multi-View Pipeline** that generates three geometric representations for every image, ensuring the input distribution matches the pre-training recipe (Cite solution_lesson_node_00005).

1.  **Global View (Shape):** Resize the image to **224x224** (Squish). This preserves the complete object silhouette (Cite solution_lesson_node_00016).
2.  **Standard View (Context):** Resize to **232x232** and Center Crop to **224x224**. Matches native pre-training conditions.
3.  **Robust Local View (Texture):** Resize to **288x288**. Instead of a single center crop, we will generate **Five Crops** (Top-Left, Top-Right, Bottom-Left, Bottom-Right, Center) of size **224x224**.
    -   *Aggregation:* The embeddings from these 5 crops will be **averaged** to form a single "Robust Local" representation. This mitigates the risk of the "Zoom" view missing the subject (Cite solution_lesson_node_00006).

### Training
-   **Feature Extraction & TTA:** For every image, we will generate the three views. We will apply **Horizontal Flipping** to all inputs (including all 5 crops for the Local view). Features from the original and flipped versions will be averaged to reduce variance (Cite solution_lesson_node_00006).
-   **Early Fusion (Concatenation):** We will concatenate the feature vectors from all views and both layers into a single high-dimensional representation for each image.
    -   Structure: `[Global_S4, Global_S3, Standard_S4, Standard_S3, Local_S4, Local_S3]`.
    -   We will **not** apply L2 normalization to these vectors, preserving the magnitude signal which correlates with feature saliency (Cite solution_lesson_node_00015).
    -   This Early Fusion allows the linear classifier to learn correlations between global shape (Stage 4) and local texture (Stage 3) across different scales (Cite solution_lesson_node_00019).
-   **Optimization:** The `LogisticRegressionCV` model will be trained on the concatenated embeddings. The L-BFGS solver will be used for efficiency (Cite solution_lesson_node_00002).

### Evaluation
-   **Inference Pipeline:**
    1.  Load test images and apply the Global, Standard, and Robust Local (5-crop) preprocessing.
    2.  Extract Stage 3 and Stage 4 features for all views (applying Flip TTA).
    3.  Concatenate features to match the training structure.
    4.  Pass the final vector to the trained `LogisticRegressionCV` model.
-   **Cache Safety:** All intermediate embeddings will be saved in a directory explicitly named with the model version and configuration (e.g., `convnext_large_pyramid_v1`) to avoid cache collision failures (Cite solution_lesson_node_00018).
