Based on the task requirements and the provided dataset analysis, I propose the following baseline approach. This solution prioritizes speed and simplicity by utilizing a robust, standard architecture with an efficient offline training strategy, distinct from the provided examples.

# Baseline Solution

### Model
**ResNet-50 with Logistic Regression**
*   **Architecture**: Use a **ResNet-50** model pre-trained on ImageNet as a fixed feature extractor. This architecture is distinct from the EfficientNet (inverted residuals) and Swin Transformer (attention) models listed previously, utilizing standard residual connections which remain a gold standard for stability and performance.
*   **Classification Head**: Replace the neural network classification head with a standalone **Logistic Regression** model. Unlike the Support Vector Machine (Model 4) which optimizes for margin (Hinge Loss), Logistic Regression directly optimizes the evaluation metric (Log Loss) and outputs well-calibrated probabilities naturally.

### Data
*   **Preprocessing**:
    *   Resize all images to **224x224** pixels.
    *   Apply standard ImageNet normalization (Mean: `[0.485, 0.456, 0.406]`, Std: `[0.229, 0.224, 0.225]`).
    *   No augmentation is applied to the training data to maximize processing speed and establish a deterministic baseline.
*   **Feature Extraction**:
    *   Pass the entire training and test datasets through the frozen ResNet-50 backbone once.
    *   Extract the output of the Global Average Pooling layer (a 2048-dimensional vector for each image) and save these embeddings to memory/disk. This decouples the heavy CNN computation from the classifier training.

### Training
*   **Procedure**: Train the Logistic Regression classifier on the pre-computed training embeddings.
*   **Optimization**: Use a solver like **L-BFGS** (Limited-memory Broyden–Fletcher–Goldfarb–Shanno), which converges significantly faster than standard Stochastic Gradient Descent (SGD) for convex problems like this.
*   **Regularization**: Apply L2 regularization (Ridge) to handle potential multicollinearity in the high-dimensional feature space and prevent overfitting.

### Evaluation
*   **Inference**:
    *   Load the pre-computed embeddings for the test set (or compute them on the fly if memory is constrained).
    *   Pass the embeddings through the trained Logistic Regression model.
*   **Output**: Generate probability distributions for the 120 breeds using the Softmax function and format the output according to the submission requirements.
