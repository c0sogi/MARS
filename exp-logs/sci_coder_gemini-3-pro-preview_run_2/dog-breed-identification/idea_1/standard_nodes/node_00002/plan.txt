The issue is caused by the use of stale cached feature embeddings (`.npy` files) in `runfile.py`, which likely contain a subset of the data from a previous debug run. This results in a mismatch between the number of test predictions and the expected number of test samples, causing the `InvalidSubmissionError`. The fix is to disable loading from the cache by setting `load_cached_data=False` during feature extraction, forcing the script to process the full dataset and generate the correct number of predictions.
