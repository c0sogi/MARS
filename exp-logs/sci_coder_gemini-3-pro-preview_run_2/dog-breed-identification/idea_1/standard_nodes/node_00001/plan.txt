The following implementation orchestrates the dog breed classification pipeline. It leverages the provided library modules to perform the following steps:
1.  **Setup**: Sets random seeds for reproducibility.
2.  **Data Loading**: Initializes DataLoaders for training, validation, and testing using the full dataset (as the offline feature extraction approach is highly efficient).
3.  **Feature Extraction**: Uses the pre-trained ResNet50 (via `FeatureExtractor`) to convert images into 2048-dimensional embeddings. This process runs on the GPU and caches results to disk to optimize runtime.
4.  **Modeling**: Trains a Logistic Regression classifier (via `LogRegClassifier`) on the extracted embeddings. This solver-based approach is significantly faster than training a neural network end-to-end while providing a strong baseline.
5.  **Validation & Analysis**: Evaluates the model using Log Loss. It performs failure analysis by calculating the correlation between the per-sample prediction error and the magnitude (L2 norm) of the feature embeddings, identifying if specific signal characteristics relate to model failure.
6.  **Submission**: Generates predictions for the test set and saves them in the required CSV format.
