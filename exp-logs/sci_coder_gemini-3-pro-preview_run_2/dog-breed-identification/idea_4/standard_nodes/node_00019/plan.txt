My strategy is to implement **Early Fusion (Feature Concatenation)** of the three multi-view representations ("standard", "global", "local") combined with a **Regularized Logistic Regression (LogisticRegressionCV)**.

1.  **Cache Invalidation (Cite Lesson 00018)**: I will update the `WORKING_DIR` to `./working/idea_5` to ensure we do not load stale embeddings from previous experiments (which used different loader settings).
2.  **Data Consistency**: I will modify `library/data_loader.py` to set `shuffle=False` for the training `DataLoader`. This is critical for Early Fusion because we need the row order of extracted embeddings to be identical across different views (Standard, Global, Local) so we can concatenate them (e.g., Row 1 in "Standard" must be the same image as Row 1 in "Global"). Since the metadata `train.csv` is already shuffled, this preserves randomness while ensuring alignment.
3.  **Early Fusion (Cite Lesson 00009/00016)**: Instead of training separate classifiers and averaging predictions (Late Fusion), I will concatenate the 1536-dimensional feature vectors from all three views into a single 4608-dimensional vector. While Lesson 00009 warned against this for *heterogeneous* backbones, for *homogeneous* backbones (same ConvNeXt model, different crops), this allows the linear classifier to learn correlations between views (e.g., "squished view shows shape X AND zoomed view shows texture Y").
4.  **Robust Linear Probing (Cite Lesson 00002)**: I will replace the fixed `C=1.0` Logistic Regression with `LogisticRegressionCV`. This will automatically tune the regularization strength `C` using Cross-Validation on the training set, adapting to the increased dimensionality of the concatenated features.
