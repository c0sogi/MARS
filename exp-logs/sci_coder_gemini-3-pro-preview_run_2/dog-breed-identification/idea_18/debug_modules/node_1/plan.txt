The issue stems from the creation of the "demo" training dataset, which selects only 1 sample per breed. However, the pipeline uses `LogisticRegressionCV` with `cv=2` (configured in `runfile.py`), which defaults to Stratified K-Fold cross-validation. Stratified splitting requires at least $K$ samples per class (where $K$ is the number of folds) to ensure that every class is represented in both the training and validation splits of each fold. Since $1 < 2$, the splitter fails.

To fix this, I will modify `runfile.py` to sample 2 images per breed for the demo training set. This ensures the synthetic data cardinality satisfies the cross-validation constraints (Cite debug_lesson_8).
