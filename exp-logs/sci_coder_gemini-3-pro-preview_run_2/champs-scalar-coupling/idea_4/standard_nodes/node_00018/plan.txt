    *   Set `batch_size=128` to maximize GPU utilization on the A100.

2.  **Data Loading**:

    *   Create `DataLoader` instances with `collate_graphs` to handle the variable-sized molecular graphs.

3.  **Model Initialization**:

    *   Move the model to the detected device (CUDA).

4.  **Training Loop**:

5.  **Final Evaluation**:
    *   Load the best model checkpoint.
    *   Run a final validation pass to compute the `Final Validation Metric` (LogMAE).
    *   Print the metric in the strictly required format.

6.  **Failure Analysis**:
    *   Run inference on the validation set to collect predictions, targets, and input features (specifically coupling distances).
    *   Calculate the absolute error for each prediction.
    *   Compute and print the Pearson correlation between the **Error Magnitude** and the **Inter-atomic Distance**.

7.  **Submission**:
    *   Check if the `Final Validation Metric` is lower (better) than the threshold `-1.407172441`.
    *   If successful, load the test dataset, generate predictions using the `predict` function, and save `submission.csv`.
