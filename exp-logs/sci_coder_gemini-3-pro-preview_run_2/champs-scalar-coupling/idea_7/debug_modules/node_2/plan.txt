The `RuntimeError` arises because the outputs of the `RBFExpansion` and `SBFExpansion` modules are PyTorch tensors with `requires_grad=True` (attached to the computation graph), which cannot be directly converted to NumPy arrays. To resolve this, I will add `.detach()` before the `.numpy()` call in `library/data.py` for both the RBF and SBF feature extraction steps. This effectively removes the tensors from the computation graph, allowing for safe conversion during data preprocessing.
