This script demonstrates the usage of the provided machine learning library for the molecular coupling prediction task. It covers feature engineering, data preprocessing, model instantiation, and the full training pipeline.

The script performs the following steps:
1.  **Configuration**: Sets up the environment for a fast, debug-mode execution (small sample size, 1 epoch).
2.  **Feature Verification**: Validates the Radial Basis Function (RBF) and Spherical Basis Function (SBF) expansion layers.
3.  **Data Processing**: Demonstrates how to load and process molecular data into graph structures using `MolecularGraphDataset`, including verifying the graph connectivity and feature shapes.
4.  **Model Inference**: Instantiates the `HGANet` model and performs a forward pass on a batch of molecular graphs to verify input/output dimensions.
5.  **Full Pipeline Execution**: Runs the `run_training` function to simulate a complete training and inference cycle, generating a submission file.
