# Optimized Strategy: Directional Message Passing with Angular Features

### Model
I propose a **Directional Message Passing Neural Network (DMPNN)**. This architecture evolves beyond the atom-centric SchNet approach by performing message passing on directed edges (bonds) rather than atoms, enabling the explicit modeling of bond angles.

*   **Directional Embeddings:** Instead of maintaining only atom embeddings, the model will maintain embeddings for directed edges (e.g., message from atom $j$ to atom $i$). This allows the network to distinguish the geometric context of an atom from different directions.
*   **Angular Basis Integration:** To address the limitation that scalar distance features are angle-blind (Cite `solution_lesson_node_00002`), the interaction block will aggregate messages from preceding edges ($k \to j$) to the current edge ($j \to i$). This aggregation will be modulated by **Angular Basis Functions** (e.g., Fourier-Bessel or Circular Harmonics) representing the angle $\angle kji$, alongside the standard Radial Basis Functions (RBF) for distances (Cite `solution_lesson_node_00004`).
*   **Non-Linear Update Blocks:** The update function for the edge embeddings will employ a deep Multi-Layer Perceptron (MLP) with non-linear activation functions (e.g., Swish or Shifted Softplus). This ensures the model retains the capacity to disentangle mixed geometric signals, strictly avoiding the performance degradation associated with linear update projections (Cite `solution_lesson_node_00006`).
*   **Deterministic Readout:** The final regression head will concatenate the learned representations of the interacting atom pair with their specific coupling type embedding. This MLP will be fully deterministic, avoiding the use of Dropout, which has been shown to degrade precision in this deterministic physical task (Cite `solution_lesson_node_00007`).

### Data
*   **Graph Construction:** For each molecule, generate a neighbor list with a generous cutoff (e.g., 5.0 Å) to capture relevant chemical environments.
*   **Triplet Pre-computation:** Unlike standard GNNs, generate an index mapping for all triplets $(k, j, i)$ where $k$ is a neighbor of $j$ and $j$ is a neighbor of $i$. This is required to compute the angular features for the directional message passing.
*   **Basis Pre-calculation:** Pre-compute the RBF expansions for all edge distances and the angular basis expansions for all triplets to speed up training.
*   **Target Normalization:** Normalize the `scalar_coupling_constant` values (e.g., standardization) per coupling type to handle the varying scales of the target variable.

### Training
*   **Loss Function:** Minimize the Mean Absolute Error (MAE), which serves as a robust proxy for the competition's LogMAE metric.
*   **Optimizer:** Use AdamW with a warm-up phase followed by a cosine annealing learning rate schedule to ensure stable convergence in the complex geometric loss landscape.
*   **Regularization:** Rely on the geometric equivariance constraints and weight decay for regularization. Do not use Dropout.

### Evaluation
*   **Inference:** Process the test set molecules to generate the corresponding graph and triplet structures.
*   **Re-scaling:** Pass the data through the model to predict normalized values, then apply the inverse of the training standardization to produce the final `scalar_coupling_constant` predictions.
*   **Submission:** Map these predictions to the `id` column provided in `test.csv` and save to `submission.csv`.
