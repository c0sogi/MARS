The following implementation demonstrates the usage of the provided library files to set up a complete, albeit mini-scale, training pipeline for the molecular coupling prediction task.

### Strategy Outline
1.  **Configuration Override**: We dynamically modify the `Config` class to enable `DEBUG` mode and set a separate `WORKING_DIR`. This ensures the script runs quickly (processing only ~20 molecules) and does not interfere with existing artifacts.
2.  **Data Preprocessing Verification**: We instantiate `TargetScaler` to compute mean/std statistics from the metadata and verify that the transformation and inverse transformation logic is mathematically consistent.
3.  **Dataset & Graph Construction**: We initialize the `CouplingDataset` in debug mode. This triggers the `process_and_cache_dataset` function, which reads XYZ files, builds neighbor graphs, and computes geometric features (RBF/SBF). We verify the integrity of the generated data structures.
4.  **Batching Logic**: We use `collate_graphs` within a PyTorch `DataLoader` to combine multiple molecular graphs into a disjoint union batch and verify that tensor shapes are correct.
5.  **Model Execution**: We instantiate the `HGANet` model, move it to the appropriate device (CPU/GPU), and perform a forward pass with a sample batch.
6.  **Optimization Loop**: We simulate a single training step (Forward -> Loss -> Backward -> Optimizer Step) to ensure the gradient flow works correctly. We manually scale the targets for the loss calculation using the scaler statistics.
7.  **Metric Calculation**: We demonstrate the `LogMAE` metric calculation on dummy data to verify the scoring logic.
