This script demonstrates the end-to-end usage of the provided machine learning library for molecular property prediction. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters to run in a lightweight "Debug" mode (fewer samples, smaller model, fewer epochs) to ensure quick execution within the time limit.
2.  **Feature Engineering Verification**: Instantiates and tests the `RadialBasisFunctions` and `SphericalBasisFunctions` classes to verify they produce tensors of the correct shape.
3.  **Data Loading**: Uses `get_molecular_data` to load a small subset of the training data, verifying the graph construction and attribute generation.
4.  **Target Statistics**: Computes and verifies target statistics (mean/std) used for normalization.
5.  **Model Initialization**: Instantiates the `HGANet` model with the reduced hyperparameters.
6.  **Training Loop**: Runs a single epoch of training using `train_one_epoch` to verify the forward and backward passes.
7.  **Evaluation**: Runs the `evaluate` function on the training subset to verify metric calculation.
8.  **Inference & Denormalization**: Demonstrates how to generate predictions and denormalize them back to the original scale.
