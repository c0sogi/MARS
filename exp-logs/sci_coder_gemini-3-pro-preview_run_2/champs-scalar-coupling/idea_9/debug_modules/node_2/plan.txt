The `RuntimeError` is caused by a "double multiplication" of the feature dimensions in the `HGANet` initialization. The `DMPNNLayer` logic expects the raw number of spherical basis functions (`num_sbf`) because it internally calculates the total input dimension as `num_rbf * num_sbf`. However, the `HGANet` class currently passes the already-flattened dimension (`Config.NUM_RBF * Config.NUM_SBF`) to the encoder. This causes the layer to expect an input size of `num_rbf * (num_rbf * num_sbf)` (e.g., 300) instead of the actual feature size (e.g., 30). The fix is to pass the raw `Config.NUM_SBF` to the encoder.
