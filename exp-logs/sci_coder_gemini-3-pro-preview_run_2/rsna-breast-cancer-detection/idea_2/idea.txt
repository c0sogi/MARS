### Idea 2: Two-Stage Deep Embedding & Gradient Boosting

This approach adopts the **Model 5** architecture described in the task information. It fundamentally differs from the previous end-to-end deep learning approach by decoupling feature extraction from classification. This strategy leverages the power of pre-trained convolutional networks for visual representation while utilizing the efficiency and tabular handling capabilities of Gradient Boosting Machines (GBMs) for the final decision.

#### Model
The architecture consists of two distinct stages:
1.  **Feature Extractor (Backbone):** A **ResNet18** model (via `timm` or `torchvision`) initialized with ImageNet weights serves as the visual backbone.
    *   **Configuration:** The network is completely **frozen** (no gradient updates). The final classification layer is removed, and the output of the Global Average Pooling layer is extracted. This results in a compact 512-dimensional vector representing the high-level visual content of each mammogram.
    *   **Rationale:** ResNet18 is chosen for its extreme speed and low memory footprint, allowing for rapid processing of the large dataset within the time limit.
2.  **Classifier:** A **LightGBM** (Light Gradient Boosting Machine) model.
    *   **Input:** A concatenated vector consisting of the 512-dimensional image embedding and the raw tabular metadata (Age, Site ID, Laterality, View, Implant, Machine ID).
    *   **Rationale:** LightGBM is highly efficient, natively handles missing values (common in the metadata), and excels at learning complex interactions between dense numerical embeddings and categorical clinical features.

#### Data
**Image Loading & Preprocessing:**
*   **Robust Loading:** To address the lack of `pydicom` and the presence of JPEG 2000 compression, the solution will utilize the same **byte-level signature detection** strategy as the previous idea. It will scan binary file streams for JPEG/JPEG2000 headers and decode the payload directly using `cv2.imdecode`.
*   **Resizing:** Images will be resized to **224x224** pixels. This is the native resolution for standard ResNet models, ensuring optimal feature extraction without the computational cost of processing larger 512x512 inputs.
*   **Normalization:** Pixel values will be normalized using standard ImageNet mean and standard deviation.

**Feature Caching:**
*   Instead of loading images during the training loop, the pipeline will perform a **single pass** over the training and validation datasets.
*   For each image, the system will compute the embedding and save it alongside the corresponding metadata into a structured file (e.g., a Pandas DataFrame saved as Parquet). This creates a purely tabular dataset for the classifier, drastically reducing training time.

#### Training
**Procedure:**
1.  **Feature Generation:** Iterate through the training and validation metadata. Load images, pass them through the frozen ResNet18, and store the resulting vectors.
2.  **Classifier Training:** Train the LightGBM model on the generated tabular dataset.
    *   **Objective:** Binary Logloss.
    *   **Imbalance Handling:** Set the `is_unbalance=True` (or adjust `scale_pos_weight`) parameter in LightGBM. This automatically reweights the loss function to account for the ~2% prevalence of cancer, ensuring the model doesn't bias heavily toward the negative class.
    *   **Hyperparameters:** Use the provided validation set to tune `num_boost_round`, `learning_rate`, and `num_leaves`. Early stopping will be enabled to prevent overfitting.

#### Evaluation
**Inference Pipeline:**
1.  Load the `test.csv` metadata.
2.  Iterate through the test set row by row.
3.  **Step 1:** Load and resize the image, then pass it through the frozen ResNet18 to obtain the embedding.
4.  **Step 2:** Concatenate the embedding with the test metadata.
5.  **Step 3:** Pass the combined vector to the trained LightGBM model to predict the cancer probability.
6.  **Aggregation:** Group the predictions by `prediction_id` and calculate the **maximum** probability across all views (images) for that breast. This ensures that if any single view suggests cancer, the prediction reflects that risk.
