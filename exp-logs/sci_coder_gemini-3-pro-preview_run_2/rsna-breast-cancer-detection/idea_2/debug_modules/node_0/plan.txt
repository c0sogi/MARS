The strategy involves creating a self-contained pipeline that utilizes the provided library modules to perform breast cancer detection. 

1.  **Environment Setup**: We will first initialize the system using `setup_system` to ensure reproducibility and directory structure.
2.  **Data Sampling**: To optimize for speed, we will load the metadata CSVs and create small, stratified subsets (e.g., 100 images) rather than processing the entire dataset. This ensures the demonstration completes quickly while still providing valid inputs to the model.
3.  **Feature Extraction**: We will initialize the vision backbone (`get_image_encoder`) and use `generate_embeddings` to extract 512-dimensional feature vectors from the DICOM images in our subsets.
4.  **Model Training**: We will instantiate the `CancerClassifier` (LightGBM wrapper) and train it using the generated embeddings and metadata.
5.  **Inference**: We will run the trained model on the test subset using `predict_and_submit` to generate a valid submission file.
6.  **Verification**: Throughout the script, we will use assertions to verify data shapes, file existence, and value ranges. We will also explicitly test the `probabilistic_f1` metric function.
