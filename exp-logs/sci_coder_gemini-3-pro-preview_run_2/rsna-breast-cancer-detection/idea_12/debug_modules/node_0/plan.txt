### Implementation Strategy

1.  **Configuration Setup**: We will import the `library.config` module and override specific settings (e.g., `DEBUG=True`, `EPOCHS=1`, `BATCH_SIZE=4`) to ensure the demonstration runs quickly and uses a small subset of the data.
2.  **Data Loading**: We will utilize `library.data.get_dataloaders` to generate training, validation, and test dataloaders. We will verify the integrity of the data batches (shapes, types) using assertions.
3.  **Model Initialization**: We will instantiate the `MRHNModel` from `library.model` using the metadata derived from the data loading step. We will perform a dummy forward pass to verify the model architecture and output dimensions.
4.  **Metric Verification**: We will explicitly test the `pf1_score` function from `library.utils` with synthetic data to ensure the custom metric logic is correct.
5.  **Training Loop**: We will execute `library.trainer.run_training` for a single epoch. This demonstrates the integration of the model, optimizer, loss function, and mixed-precision scaler.
6.  **Inference and Submission**: We will run `library.model.predict_and_submit` to generate predictions on the test set and create a submission file. We will validate the format of the resulting CSV.
