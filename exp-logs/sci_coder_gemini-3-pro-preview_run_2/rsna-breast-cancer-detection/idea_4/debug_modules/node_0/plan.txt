This script demonstrates the end-to-end usage of the provided Multi-Instance Learning (MIL) library for breast cancer detection. It first validates the custom probabilistic metric, then sets up the environment and data loaders in a debug configuration (using a small subset of data and lower image resolution for speed). It verifies the data batch structure and model architecture by performing a forward and backward pass. Finally, it executes a complete training epoch using the provided training pipeline and generates a submission file from the test set, verifying the output format against the requirements.
