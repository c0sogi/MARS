### Implementation Strategy

1.  **Configuration Override**: Modify the `Config` class attributes to enable a "Demo Mode". This involves setting `DEBUG=True`, reducing `IMAGE_SIZE` to `(256, 256)` for speed, setting `NUM_EPOCHS=1`, and defining a dedicated `WORKING_DIR` to avoid conflicts.
2.  **Safety Patching**: Monkey-patch the `MultiTaskEfficientNet` class initialization to force `pretrained=False`. This ensures the script does not attempt to download model weights from the internet, which guarantees execution in offline environments.
3.  **Component Validation**:
    *   **Dataset**: Initialize dataloaders using `get_dataloaders` with debug sampling. Fetch a single batch to verify tensor shapes (Images, Metadata, Targets).
    *   **Model**: Perform a forward pass with the fetched batch to verify that the model outputs the expected keys (`cancer`, `birads`, `density`) and dimensions.
    *   **Loss**: Compute the loss using `StableFocalLoss` on dummy data to verify numerical stability.
4.  **Integration Testing**:
    *   **Training**: Instantiate the `Trainer` class and execute the `train()` method. This runs a full training loop (forward, backward, optimizer step) on the debug subset.
    *   **Inference**: Execute `generate_submission()` to generate predictions on the test set and save the result to a CSV file.
5.  **Final Verification**: Check for the existence and validity of the generated `submission.csv` file.
