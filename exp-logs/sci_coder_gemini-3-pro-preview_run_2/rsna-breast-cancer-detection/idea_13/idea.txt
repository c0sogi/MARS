Based on the comprehensive analysis of previous experiments and the extracted lessons, I propose the **Tri-Spectral Hybrid Network (TS-HN)**.

This strategy synthesizes the robust architectural foundation of the "Current Best" solution (Idea 3) with the input engineering innovations attempted in Idea 11, while strictly adhering to the stability and training protocols that prevented the failure of Ideas 6, 8, and 10.

# Model
**Architecture: Tri-Spectral EfficientNetV2-Small with Tabular Fusion**
1.  **Input Engineering (Structural Innovation):** To address the weak visual signal inherent in raw mammograms without relying on unstable auxiliary tasks, the model transforms the single-channel DICOM input into a **3-Channel Tri-Spectral Tensor**. This mimics the radiologist's "windowing" workflow to explicitly highlight different pathologies:
    *   **Channel 1 (Linear):** Standard Min-Max normalized grayscale (General Structure).
    *   **Channel 2 (Texture):** Processed with **CLAHE** (Contrast Limited Adaptive Histogram Equalization) to maximize local contrast, specifically targeting **microcalcifications**.
    *   **Channel 3 (Density):** Processed with **Gamma Correction** ($\gamma=2.0$) to suppress background noise and highlight dense tissue masses.
2.  **Visual Backbone:** An **EfficientNetV2-Small** initialized with ImageNet weights. It is **completely unfrozen and fine-tuned** end-to-end to adapt to these specific texture representations **Cite {solution_lesson_node_00002}**.
3.  **Hybrid Fusion:** The visual features are aggregated via **Generalized Mean Pooling (GeM)** and concatenated with a processed metadata vector (Age, Implant, View, etc.) from a parallel MLP. We explicitly **retain the tabular branch**, as removing it (Idea 11) proved that visual features alone cannot replace the strong clinical prior provided by patient age **Cite {solution_lesson_node_00017}**.
4.  **Single-Task Head:** The fused embedding outputs to a single sigmoid neuron for cancer probability. We explicitly **reject Multi-Task Learning**, as dense auxiliary gradients (BIRADS/Density) have been shown to dilute the sparse signal of the primary minority class **Cite {solution_lesson_node_00016}**.

# Data
1.  **Single-Instance Learning (SIL):** The pipeline strictly follows the SIL paradigm. Patient-level labels are broadcast to every individual image. This **dense supervision** is retained as it outperforms the sparse supervision of Multi-Instance Learning in this domain **Cite {solution_lesson_node_00005}**.
2.  **Full Dataset Utilization:** The model is trained on the **entire training set**. We avoid subsampling to fit higher resolutions (e.g., 1024px), prioritizing the number of positive samples over spatial dimensions **Cite {solution_lesson_node_00014}**.
3.  **Resolution:** Images are resized to **640x640**. This serves as an optimal balance, allowing for full-dataset training within the 24-hour limit while utilizing the Tri-Spectral input to compensate for not using higher resolutions.
4.  **Ingestion:** The robust **Byte-Level Image Extractor** (using `cv2.imdecode` on binary streams) is retained to handle DICOM files without `pydicom`.

# Training
1.  **Objective: FP32-Guarded Weighted Loss:**
    *   The model uses **BCEWithLogitsLoss** with a high `pos_weight` (e.g., 20.0) to aggressively target the ~1:50 class imbalance.
    *   **Stability Mechanism:** The loss calculation is explicitly wrapped in a **Float32 context** (`with torch.amp.autocast(enabled=False):`). This allows the use of high scalar weights without causing the `NaN` divergence observed when such weights interact with the limited dynamic range of Mixed Precision (AMP) **Cite {solution_lesson_node_00008}**, **Cite {solution_lesson_node_00013}**.
2.  **Sampling: Natural Distribution:**
    *   The training uses a **Standard Random Sampler**. We explicitly reject `WeightedRandomSampler` to ensure the model learns the true prior probability of cancer (~2%), preserving the **probability calibration** required for the Probabilistic F1 metric **Cite {solution_lesson_node_00010}**.
3.  **Optimization:** **AdamW** optimizer with a **OneCycleLR** scheduler is used to facilitate rapid convergence.

# Evaluation
1.  **Inference:** The model iterates through the test set. For each image, the Tri-Spectral input is generated on-the-fly, fused with metadata, and a probability is predicted.
2.  **Aggregation:** Predictions are grouped by `prediction_id`. The final submission score is the **maximum** probability across all images (views) associated with that ID, ensuring high sensitivity to any suspicious view **Cite {solution_lesson_node_00005}**.
