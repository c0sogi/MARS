This script demonstrates the end-to-end usage of the provided library for the Breast Cancer Detection task. It performs the following steps:

1.  **Configuration & Setup**: Overrides default configuration parameters (epochs, batch size, directories) to ensure the demo runs quickly and stores outputs in a separate demo directory.
2.  **Logic Verification**: Validates critical components like the probabilistic F1 score calculation and the tri-spectral image generation pipeline using assertions.
3.  **Data Loading**: Instantiates the `BreastCancerDataset` and creates small subsets (using `torch.utils.data.Subset`) of the training and validation data to simulate a rapid training cycle.
4.  **Model Initialization**: Loads the `TriSpectralHybridModel`, moves it to the appropriate device (GPU/CPU), and verifies the forward pass output shape.
5.  **Training Loop**: Executes the training process using `engine.fit` for a single epoch on the subset data.
6.  **Inference & Submission**: Runs inference on a subset of the test data and generates a valid `submission.csv` file.
