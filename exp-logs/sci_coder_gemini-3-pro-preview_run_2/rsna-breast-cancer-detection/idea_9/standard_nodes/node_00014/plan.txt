The following strategy outlines the implementation of the `runfile.py` script, designed to serve as a fast baseline for the Stabilized High-Resolution Multi-Task Network (SHR-MTN).

1.  **Setup & Configuration**: The script will initialize the environment with fixed seeds and detect the computing device. It will override `Config.NUM_EPOCHS` to 2 to ensure the training completes quickly within the time limit.
2.  **Data Loading**: It will load the full datasets using `get_dataloaders(debug=False)`. To satisfy the "Fast Baseline" requirement while ensuring valid metrics, it will create a `Subset` of the training dataset (first 5,000 samples) for the training loop, while preserving the full validation dataset for accurate evaluation.
3.  **Model Initialization**: The `SHR_MTN` model will be instantiated along with an AdamW optimizer, Gradient Scaler for mixed precision, and the defined loss criteria (BCE with positive weights for cancer, MSE for BIRADS, CrossEntropy for Density).
4.  **Training Loop**: The model will train for 2 epochs on the subsetted data. After each epoch, it will evaluate on the full validation set. The model with the highest Probabilistic F1 (pF1) score will be saved.
5.  **Validation & Analysis**: After training, the best model will be re-loaded to generate predictions on the full validation set. The script will compute and print the `Final Validation Metric`. It will then perform failure analysis by calculating the correlation (using NumPy) between prediction errors and metadata features (e.g., Age, Density).
6.  **Submission**: If the final validation metric exceeds the threshold (0.044888656586408615), the script will generate predictions for the test set and save them to `submission.csv`.
