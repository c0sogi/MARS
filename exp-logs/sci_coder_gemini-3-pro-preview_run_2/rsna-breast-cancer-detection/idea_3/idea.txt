# Optimized Strategy: End-to-End Fine-Tuned Hybrid EfficientNet with GeM Pooling

### Model
The proposed architecture is a **Hybrid Vision-Tabular Network** trained end-to-end. This design directly addresses the failure of frozen embeddings by allowing the feature extractor to adapt to the specific textures of mammography (e.g., microcalcifications and masses) which differ significantly from natural images.

*   **Visual Backbone:** An **EfficientNet-B2** initialized with ImageNet weights. Crucially, this backbone will be **completely unfrozen** and fine-tuned. This ensures the network learns domain-specific features rather than relying on generic edge detectors, correcting the root cause of the previous failure Cite {solution_lesson_node_00002}.
*   **Pooling Layer:** Instead of standard Global Average Pooling (GAP), the model will utilize **Generalized Mean Pooling (GeM)**. GeM is a learnable pooling layer that can focus on salient high-activation regions (potential lesions) while suppressing the background, which is critical for medical anomaly detection where the target signal is small relative to the image size.
*   **Metadata Branch:** A Multi-Layer Perceptron (MLP) processes the clinical metadata (Age, View, Implant, etc.). Categorical variables are one-hot encoded, and continuous variables are normalized.
*   **Fusion Head:** The visual embedding (from GeM) and the tabular embedding (from the MLP) are concatenated. The combined vector passes through a final fully connected layer with a Sigmoid activation to output the cancer probability.

### Data
*   **Ingestion (Retained):** The solution will retain the **Byte-Level Image Extractor** developed in previous iterations. This component scans binary streams for JPEG/JPEG2000 signatures and decodes them using `cv2.imdecode`, successfully bypassing the missing `pydicom` library constraint.
*   **Resolution Upgrade:** To capture subtle pathologies like microcalcifications, the input resolution will be increased to **640x640** (or higher if memory permits), significantly larger than the 224x224 resolution that contributed to the previous model's inability to find discriminative signals Cite {solution_lesson_node_00002}.
*   **Augmentation:** Since the backbone is being fine-tuned, strong data augmentation is required to prevent overfitting. The pipeline will use `albumentations` for random rotations, horizontal flips (correcting for laterality), brightness/contrast shifts, and coarse dropout.

### Training
*   **Procedure:** The model will be trained **end-to-end** using the training set defined in the metadata.
*   **Loss Function:** **BCEWithLogitsLoss** with a `pos_weight` parameter (e.g., 20-50) will be used to explicitly counter the severe class imbalance (~2% positive cases).
*   **Optimizer & Scheduler:** The **AdamW** optimizer will be paired with a **OneCycleLR** scheduler. This combination allows for a rapid warm-up to a higher learning rate (facilitating the escape from local minima in the pre-trained weights) followed by a disciplined decay for convergence.
*   **Regularization:** Drop-Path (Stochastic Depth) will be applied within the EfficientNet backbone, and standard Dropout will be applied in the fusion head.

### Evaluation
*   **Inference:** The model will iterate through the test metadata, loading images via the byte-level extractor and resizing them to the training resolution.
*   **Aggregation:** Predictions will be grouped by `prediction_id`. The final submission score for each ID will be the **maximum** probability across all associated images (views). This ensures that if any single view of a breast indicates malignancy, the patient is flagged accordingly.
