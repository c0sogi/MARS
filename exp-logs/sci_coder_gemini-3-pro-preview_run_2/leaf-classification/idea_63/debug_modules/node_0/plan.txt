The following strategy outlines the implementation of the leaf classification task using the provided library files:

1.  **Setup**: Initialize the environment by setting random seeds for reproducibility and suppressing unnecessary warnings.
2.  **Data Loading**: Utilize `data_manager.load_data` to load the training, validation, and test datasets. This function handles reading the pre-generated metadata and extracting morphometric features from images using `image_processing.py`.
3.  **Expert Generation**: Use `expert_library.generate_candidate_experts` to create a diverse library of machine learning pipelines (Experts). These pipelines utilize different feature subsets (Margin, Shape, Texture) and strategies (Global, Stratified, Interactions) defined in `pipeline_factory.py`.
4.  **Training & Inference**: Iterate through the generated experts, training each on the training data. Generate probability predictions for both the validation set (used for ensemble weighting) and the test set (used for the final submission).
5.  **Ensemble Optimization**: Instantiate `ensemble_selection.GreedySelector` to perform greedy forward selection. This process identifies the optimal combination of experts that minimizes the multi-class log loss on the validation set.
6.  **Submission**: Calculate the final weighted average predictions for the test set using the optimized ensemble. Save these predictions in the required CSV format using `utils.save_submission`.
7.  **Verification**: Include assertions throughout the script to verify data shapes, prediction validity (range [0, 1]), and the correct generation of the output file.
