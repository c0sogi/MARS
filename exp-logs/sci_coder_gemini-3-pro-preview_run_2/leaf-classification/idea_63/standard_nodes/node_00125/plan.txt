SR-FIPE Strategy Implementation:
1.  **Setup & Data**: Initialize environment and seed. Load the dataset using `data_manager`, ensuring all feature matrices are converted to `float64` numpy arrays for precision and compatibility with `ColumnTransformer` indices.
2.  **Expert Library**: Generate the full suite of SR-FIPE experts (Global, Stratified Rotational, Factorized Interaction, Morphometric) using `expert_library`.
3.  **Phase 1 (Selection)**: Train all experts on the training split and generate predictions for the validation split. Use `GreedySelector` to identify the optimal ensemble subset that minimizes Log Loss on the validation set.
4.  **Failure Analysis**: Compute the correlation between the ensemble's error magnitude and input features on the validation set to diagnose systematic weaknesses.
5.  **Phase 2 (Retraining)**: Combine training and validation data. Retrain **only** the selected experts on this full dataset to maximize signal utilization.
6.  **Inference & Submission**: Generate predictions on the test set using the retrained experts. Aggregate these predictions using the ensemble weights determined in Phase 1. Save the submission if the validation metric meets the threshold.
