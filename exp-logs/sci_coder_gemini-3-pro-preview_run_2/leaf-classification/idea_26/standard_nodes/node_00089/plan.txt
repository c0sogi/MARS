The implementation strategy orchestrates the PMAGL pipeline in two main phases. First, it leverages the `library.data_loader` and `library.preprocessing` modules to load the dataset, generate the novel Probabilistic Morphometric features via Monte-Carlo augmentation, and apply Yeo-Johnson PowerTransformer to all feature views (Global, Morph, and Combined). In Phase 1, it instantiates a library of LDA and Regularized QDA experts using `library.model_factory` and trains them on the training split. It then employs the `library.ensemble_selection.select_best_ensemble` function to perform Greedy Forward Selection based on validation Log Loss, determining the optimal subset of experts and their weights. Following this, it performs a failure analysis by correlating validation error magnitudes with input features. In Phase 2, the script retrains the selected experts on the combined training and validation data to maximize signal utilization, generates weighted predictions for the test set, and formats the final `submission.csv` file.
