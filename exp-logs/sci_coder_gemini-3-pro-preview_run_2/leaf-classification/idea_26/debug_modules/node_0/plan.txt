The following script demonstrates the end-to-end pipeline using the provided library files. It loads the dataset, preprocesses features, trains a library of expert models (LDA and QDA variants on different feature views), performs ensemble selection to combine predictions, and generates a valid submission file.

### Implementation Strategy
1.  **Setup**: Initialize the environment and random seeds using `library.utils` and `library.config`.
2.  **Data Loading**: Use `library.data_loader` to load training, validation, and test sets. This step handles reading metadata and extracting raw features.
3.  **Preprocessing**: Use `library.preprocessing` to apply Yeo-Johnson power transformation to standardize features and make them more Gaussian-like, which benefits the LDA/QDA models.
4.  **Model Training**: Use `library.model_factory` to instantiate a diverse set of expert models. We iterate through these experts, training them on the specific views (Global, Morphological, or Combined) they are designed for.
5.  **Evaluation**: Generate probability predictions for the validation set and calculate the Log Loss for each model.
6.  **Ensemble Selection**: Use `library.ensemble_selection` to perform greedy forward selection, finding the optimal weighted combination of models that minimizes validation loss.
7.  **Submission Generation**: Apply the learned ensemble weights to the test set predictions, format the output according to the sample submission, and save the result.
8.  **Verification**: Include assertions throughout to verify data shapes, column consistency, and prediction validity.
