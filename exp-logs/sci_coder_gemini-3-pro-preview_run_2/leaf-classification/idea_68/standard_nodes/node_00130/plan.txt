Implementation strategy:

1.  **Setup and Data Loading**: Initialize the environment with a fixed seed. Use the `data_handler` module to load the training, validation, and test datasets, leveraging the `load_cached_data=True` option to use pre-processed Parquet files. The data loader provides dictionary-based access to different feature views (Global, Margin, Shape, Texture, Morphometrics).

2.  **Expert Library Construction**: Define a set of expert configurations based on the FR-SRPE architecture. This involves iterating through four expert groups (Global Marginal, Global Rotational, Stratified Rotational, Physical Polynomial) and applying a range of LDA shrinkage parameters to each.

3.  **Training and Validation (Phase 1)**: Iterate through all defined configurations. For each expert, instantiate the appropriate pipeline using `pipeline_definitions`, fit it on the training split, and generate probability predictions for the validation split. Store these validation predictions in a library.

4.  **Ensemble Selection**: Use the `GreedySelector` from `ensemble_strategy` to perform Forward Selection on the validation predictions. This identifies the optimal subset of experts and their weights that minimize the validation log loss.

5.  **Validation Assessment & Failure Analysis**:
    *   Compute and print the **Final Validation Metric** using the aggregated ensemble predictions.
    *   Perform failure analysis by calculating the per-sample log loss on the validation set.
    *   Compute the Pearson correlation between these error magnitudes and the Morphometric features (e.g., Aspect Ratio, Solidity) to identify physical characteristics associated with model error.

6.  **Final Retraining and Submission (Phase 2)**:
    *   Retrain *only* the selected experts on the combined Training + Validation dataset to maximize signal.
    *   Generate predictions for the Test set using these retrained models.
    *   Aggregate the test predictions using the weights determined in the selection phase.
    *   Save the final submission file using `utils.save_submission`.
