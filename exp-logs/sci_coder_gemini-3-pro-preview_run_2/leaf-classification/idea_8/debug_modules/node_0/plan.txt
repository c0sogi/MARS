This script demonstrates the end-to-end workflow using the provided library modules. It covers data loading, preprocessing (both standard scaling and PCA), model training (Logistic Regression, LDA, and Gaussian Process Classifier), logic verification through assertions, and the generation of a submission file.

The strategy involves:
1.  **Data Loading**: Utilizing `load_datasets` to fetch train, validation, and test splits.
2.  **Preprocessing**: Creating two versions of the data: one scaled (for linear models) and one PCA-reduced (for the probabilistic non-linear model).
3.  **Model Training**: Training the three defined models on the full training set (since N ~ 700, this is computationally feasible within the time limit).
4.  **Validation**: Verifying that predicted probabilities sum to 1 and that feature dimensions are correct.
5.  **Submission**: Averaging predictions from the three models and saving the result using `save_submission`.
