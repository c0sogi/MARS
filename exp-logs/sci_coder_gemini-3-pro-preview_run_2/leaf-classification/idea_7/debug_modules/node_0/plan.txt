This script demonstrates the usage of the provided leaf classification library. It covers data loading, utility verification, model definition with optimized hyperparameters for speed, and the execution of the hierarchical taxonomy ensemble.

The strategy involves:
1.  **Data Loading**: Using `load_and_process_data` to fetch pre-processed features and targets.
2.  **Utility Verification**: Testing the genus extraction and mapping logic to ensure biological constraints are correctly formatted.
3.  **Model Optimization**: Instantiating the `TaxonomyEnsemble` and then replacing its internal models with "lightweight" versions (fewer iterations, smaller cross-validation folds) to ensure the demo runs quickly.
4.  **Execution & Validation**: Training the ensemble on a subset of data, generating predictions, and asserting that the output probabilities are valid (shape, sum to 1).
