This script implements the **Cross-Domain Interaction Precision-Generative Ensemble (CD-IPGE)**. It orchestrates the following steps:
1.  **Data Loading**: Loads preprocessed feature views (Global, Semantic, Morphometric, Interactions) using the `DataManager`.
2.  **Expert Definition**: Instantiates a library of experts including Global Statistical Anchors (LDA variants), Physical Polynomial Experts (Morphometrics), and Cross-Domain Interaction Experts (Margin-Texture, etc.).
3.  **Phase 1 (Selection)**: Trains all experts on the training split, evaluates them on the validation split, and uses **Greedy Forward Selection** (`HillClimbingOptimizer`) to identify the optimal ensemble composition.
4.  **Analysis**: Computes the final validation log loss and performs failure analysis by correlating prediction errors with input features.
5.  **Phase 2 (Submission)**: Retrains the selected experts on the combined (Train + Val) dataset and generates predictions for the test set, saving the result to `submission.csv`.
