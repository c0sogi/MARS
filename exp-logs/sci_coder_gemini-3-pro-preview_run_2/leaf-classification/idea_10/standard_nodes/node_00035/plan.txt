This is the implementation of the `runfile.py` script. It orchestrates the "Selective Multi-View Hybrid Ensemble" strategy, performing a rigorous validation phase on the hold-out set followed by a full training phase for submission generation.

**Strategy Outline:**
1.  **Validation Phase:**
    -   Manually loads `train.csv` and `val.csv` from metadata.
    -   Extracts Global, Margin, Shape, and Texture views.
    -   Applies `StandardScaler` (fit on Train, transform Train & Val).
    -   Trains the ensemble candidates (LogisticRegressionCV and LDA) on the Training set.
    -   Optimizes the ensemble selection based on internal CV scores.
    -   Evaluates the ensemble on the Validation set to compute the "Final Validation Metric".
    -   Performs Failure Analysis by correlating prediction error with input features.
2.  **Submission Phase:**
    -   Checks if the validation metric meets the strict threshold.
    -   Uses `process_data` to load the combined (Train + Val) dataset and Test set.
    -   Retrains the selected ensemble strategy on the full data to maximize performance.
    -   Generates predictions and saves the submission file.
