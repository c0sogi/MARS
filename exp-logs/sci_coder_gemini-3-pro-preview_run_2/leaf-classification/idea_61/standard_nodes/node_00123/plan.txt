The implementation strategy follows the **Factorized-Discriminative Manifold Ensemble (FDME)** design.

1.  **Data Ingestion**: We load the metadata CSVs (`train`, `val`, `test`) and the global feature vectors. We utilize the `feature_extraction` module to compute or load cached **Morphometric features** (Hu moments, geometric scalars) for all splits. Target labels are encoded using `LabelEncoder`.
2.  **Phase 1: Expert Selection**:
    *   We instantiate the expert library (Global Anchors, Physical Polynomials, Factorized Interactions) using `get_expert_library`.
    *   Each expert is trained on the **Training set** and generates probabilities for the **Validation set**.
    *   The `GreedySelector` is applied to the validation predictions to determine the optimal ensemble composition (weights) that minimizes Log Loss.
3.  **Validation & Analysis**:
    *   The optimized **Final Validation Metric** is reported.
    *   **Failure Analysis** is performed by calculating the per-sample log loss on the validation set and correlating these errors with key feature groups (Margin, Shape, Texture means, and Morphometrics) to identify weak points.
4.  **Phase 2: Final Inference**:
    *   The Training and Validation sets are **combined** to maximize data density.
    *   Only the **selected experts** are retrained on this full dataset using the hyperparameters validated in Phase 1.
    *   Predictions are generated for the **Test set**, aggregated using the ensemble weights, and saved to `submission.csv`.
