Here is the implementation strategy and the complete Python script for the Exploratory Data Analysis.

### Implementation Strategy

1.  **Setup and Loading**:
    -   Initialize the environment with fixed random seeds for reproducibility.
    -   Load the training metadata from `./metadata/train.csv`.
    -   Identify the full path to images using the `./input` directory.

2.  **Target Variable Analysis**:
    -   Analyze the `species` column.
    -   Calculate the number of unique classes and the distribution of samples per class.
    -   Assess class balance (min, max, mean samples per class).

3.  **Tabular Data Analysis**:
    -   The dataset contains three distinct groups of pre-extracted features: `margin`, `shape`, and `texture`, each with 64 dimensions.
    -   Instead of printing statistics for all 192 columns individually, I will aggregate statistics by feature group (e.g., Global Mean/Std for Texture features) and report the range of values.
    -   Check for missing values and calculate outlier counts using the IQR method.

4.  **Image Data Analysis**:
    -   Iterate through all training images (since N=712, this is computationally feasible).
    -   Load images using OpenCV to extract dimensions (Height, Width, Channels).
    -   Calculate global pixel statistics (Mean, Std) and aspect ratios.

5.  **Feature Relationships**:
    -   **Structured**:
        -   Compute a correlation matrix for the numerical features.
        -   Identify highly collinear pairs (Correlation > 0.90).
        -   Train a Random Forest Classifier to identify the top 5 most important features for species classification.
    -   **Unstructured (Meta-features)**:
        -   Analyze if image geometry (Aspect Ratio, Area) varies significantly across different species using a one-way ANOVA test.

6.  **Output**:
    -   Print findings in clear, capitalized sections with floats formatted to 4 decimal places.
