The following script demonstrates the usage of the provided library files to perform the Leaf Classification task. It first cleans the cache to ensure a fresh execution of the feature extraction and preprocessing logic. Then, it utilizes the `Preprocessor` to load and transform the data. A `GreedyEnsembleSelector` is instantiated and trained with a reduced ensemble size for speed. Finally, the full `run_smpge_pipeline` is executed to generate the submission file, and the output is validated.
