### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by importing necessary libraries and setting the random seed using `library.utils.set_seed` to ensure reproducibility.
2.  **Data Loading**: Use `library.data_loader.load_dataset` to retrieve the pre-processed training, validation, and test datasets. This function handles feature extraction (global and morphometric) and label encoding.
3.  **Pipeline Instantiation & Training**:
    *   Iterate through the five expert topologies (A, B, C, D, E) defined in `library.expert_pipelines`.
    *   Assign appropriate feature sets: Topologies A-D use global features (Margin, Shape, Texture), while Topology E uses extracted morphometric features (Hu moments, geometric scalars).
    *   Instantiate each pipeline using `build_pipeline` with a fixed shrinkage parameter (where applicable) to ensure fast convergence.
    *   Train each pipeline on the training set and generate probability predictions for the validation set.
    *   Verify prediction shapes and value ranges (0-1) using assertions.
4.  **Metric Verification**: explicitely test the `clipped_log_loss` function with a synthetic edge case (probabilities of 0 and 1) to confirm the clipping logic prevents numerical instability.
5.  **Ensemble Optimization**:
    *   Initialize the `GreedyEnsembleSelector` from `library.ensemble_selection`.
    *   Fit the selector using the dictionary of validation predictions collected from the individual experts.
    *   Validate that the ensemble selector returns weights and an improved (or equal) score compared to the single best model.
6.  **Final Prediction**: Use the fitted ensemble to generate predictions on the test set, demonstrating the end-to-end inference flow.
