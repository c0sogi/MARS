This script demonstrates the end-to-end pipeline using the provided library files. It covers data loading, feature extraction, gaussian basis preprocessing, model training (LDA and Logistic Regression), greedy ensemble selection, and submission generation.

Key steps performed:
1.  **Setup**: Sets random seeds for reproducibility.
2.  **Data Loading**: Uses `DataLoader` to load training and validation splits, including both pre-computed global features and on-the-fly extracted macro features from images.
3.  **Preprocessing**: Uses `GaussianBasisFactory` to transform features into multiple latent spaces (Parametric, Quantile) to enhance model diversity.
4.  **Modeling**: Trains a diverse set of experts (LDA, Regularized Logistic Regression) on different combinations of feature views and basis transformations.
5.  **Ensemble**: Uses `GreedyEnsembleSelector` to find the optimal weighted combination of experts that minimizes log loss on the validation set.
6.  **Submission**: Generates a submission file in the correct format.
