The implementation strategy for the **Multi-Basis Gaussianized Hybrid Ensemble (MB-GHE)** is as follows:

1.  **Initialization**: Set random seeds for reproducibility and import necessary modules from the provided library.
2.  **Data Loading**: Use the `DataLoader` to load training, validation, and test datasets. This includes the provided global features and the extraction of deterministic macro features (Hu moments, shape scalars) which are cached for efficiency.
3.  **Preprocessing (Phase 1)**: Instantiate the `GaussianBasisFactory` to fit transformations (Parametric, Coarse-Quantile, Fine-Quantile) on the training set and transform all splits. This prepares the "Basis" dimension of the expert library.
4.  **Expert Library Training**: Iterate through the full Cartesian product of Bases, Views (Global, Macro), and Estimators (LDA variants, LogReg). Train each expert on the training split and generate predictions for the validation split.
5.  **Ensemble Selection**: Apply `GreedyEnsembleSelector` to the validation predictions. This algorithm iteratively selects experts that maximize the validation Log Loss improvement, determining the optimal composition and weighting of the ensemble.
6.  **Validation & Analysis**:
    *   Compute and print the **Final Validation Metric** (Log Loss) with high precision.
    *   Perform **Failure Analysis** by calculating the per-sample log loss on the validation set and correlating it with the raw input features. This identifies which physical characteristics (e.g., specific texture or shape properties) are most associated with model error.
7.  **Retraining (Phase 2)**:
    *   Combine the training and validation datasets to maximize the data available for the final model.
    *   Re-fit the `GaussianBasisFactory` on this combined dataset to ensure transformations utilize the full data distribution.
    *   Retrain *only* the experts selected in Phase 1 on the combined, transformed data.
8.  **Submission**: Generate predictions for the test set using the retrained ensemble and the weights determined in Phase 1. Save the results to `submission.csv` in the required format.
