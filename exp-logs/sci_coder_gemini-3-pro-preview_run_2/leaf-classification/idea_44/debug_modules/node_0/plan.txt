Implementation Strategy:
1.  **Setup & Initialization**: Configure the environment by setting random seeds to ensure reproducibility.
2.  **Data Loading**: Use the `data_loader` library to load the training, validation, and test datasets.
3.  **Label Encoding**: Fit a `LabelEncoder` on the training target labels to convert species names into integer indices, ensuring consistency across all models and evaluation metrics.
4.  **Feature Engineering**:
    *   **Global View**: Extract the pre-computed margin, shape, and texture features directly from the dataframes.
    *   **Morph-Poly View**: Use the `feature_engineering` library to process raw images (extracting Hu moments and geometric scalars) and apply polynomial expansion. This demonstrates the integration of image processing with tabular data.
5.  **Expert Modeling**: Instantiate the expert pipelines defined in `expert_library`. Iterate through each expert configuration, select the appropriate feature view, train the model on the training set, and generate probabilities for validation and test sets.
6.  **Ensemble Optimization**: Utilize the `GreedyEnsembleSelector` to find the optimal weighted combination of expert predictions that minimizes log loss on the validation set.
7.  **Submission Generation**: Apply the optimized ensemble weights to the test set predictions, format the output dataframe with the correct species columns, and save it to a CSV file.
8.  **Validation**: Perform assertions on the generated submission file to verify dimensions, probability ranges, and row sums.
