Implementation strategy:
1.  **Setup & Data Loading**: Initialize the environment and seed. Use the provided `load_and_process_data` function to load the dataset, which handles feature extraction (Global and Macro views) and preprocessing (PowerTransformer).
2.  **Expert Initialization**: Instantiate the four hierarchical experts defined in the strategy:
    *   **Analytical Anchor**: LDA with automatic shrinkage (OAS/Ledoit-Wolf) on Global features.
    *   **Bagged Generative Expert**: A Bagging ensemble of LDA models to reduce covariance estimation variance.
    *   **Macro-QDA**: Regularized QDA on the low-dimensional physical Macro features (Hu moments, geometry).
    *   **Taxonomic Prior**: An LDA model trained on Genus labels that distributes probability mass to constituent species, acting as a phylogenetic constraint.
3.  **Phase 1 (Selection)**: Train all experts on the training split and generate probabilities for the validation split.
4.  **Ensemble Optimization**: Use the `GreedySelector` to determine the optimal combination (and integer weights) of experts that minimizes validation Log Loss.
5.  **Failure Analysis**: Compute the correlation between the ensemble's validation error and input features to identify systematic weaknesses.
6.  **Phase 2 (Retraining)**: Combine training and validation sets. Retrain the selected experts on the full dataset using the hyperparameters validated in Phase 1.
7.  **Inference & Submission**: Generate predictions for the test set using the retrained ensemble. Apply the weighted aggregation derived from the selection phase. Check the validation metric against the threshold and save the submission file.
