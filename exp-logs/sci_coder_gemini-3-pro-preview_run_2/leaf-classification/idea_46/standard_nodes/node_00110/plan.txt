My implementation strategy for the **Compressed-Interaction Precision-Generative Ensemble (CIPGE)** is as follows:

1.  **Data Ingestion**: I will use the provided `library.data_loader` to load the training, validation, and test datasets. This loader automatically handles the retrieval of the 192 global features and triggers the extraction of the polarity-corrected morphometric features (Hu Moments, Geometric Scalars) via `library.image_processing`, caching the results to disk for efficiency.
2.  **Expert Library Construction (Phase 1)**: I will iterate through the four defined Views (A, B, C, D) specified in the configuration. For each view, I will instantiate the corresponding preprocessing pipeline (using `library.pipelines`) and the set of Linear Discriminant Analysis (LDA) experts with varying shrinkage parameters (using `library.models`).
3.  **Training & Validation**: Each expert will be trained on the training split and used to generate probability predictions on the validation split. These predictions will be stored in a registry.
4.  **Ensemble Selection**: I will employ the `library.ensemble.GreedySelector` to perform Greedy Forward Selection on the validation predictions. This will identify the optimal subset of experts and their weights that minimize the Multi-class Log Loss.
5.  **Failure Analysis**: I will compute the per-sample log loss on the validation set using the selected ensemble. I will then calculate the Pearson correlation between these loss values and the global input features to identify which characteristics are most associated with model error, printing the top 5 correlations.
6.  **Retraining (Phase 2)**: I will combine the training and validation datasets into a full training set. I will then retrain *only* the experts selected in the previous step on this full dataset to maximize signal utilization.
7.  **Submission Generation**: Finally, I will generate predictions for the test set using the retrained experts, aggregate them using the ensemble weights, and save the formatted submission file to `submission.csv`.
