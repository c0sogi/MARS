This script demonstrates the end-to-end usage of the provided library modules to solve the Leaf Classification task. It covers data loading, feature engineering via pipelines, model training with LDA experts, ensemble selection using greedy forward selection, and submission generation.

**Implementation Strategy:**
1.  **Setup**: Initialize random seeds for reproducibility.
2.  **Data Loading**: Use `data_loader` to load training, validation, and test datasets, including both global features and morphometric features extracted from images.
3.  **Pipeline & Model Execution**: Iterate through the four defined views (A, B, C, D). For each view:
    *   Construct the specific preprocessing pipeline using `pipelines.ViewFactory`.
    *   Transform the data (handling PCA/Polynomial expansions).
    *   Generate a library of LDA experts with varying shrinkage parameters using `models.get_view_experts`.
    *   Train experts and generate probabilities for validation and test sets.
4.  **Ensemble Selection**: Use `ensemble.GreedySelector` to find the optimal weighted combination of experts that minimizes log loss on the validation set.
5.  **Submission**: Generate the final predictions on the test set and save the submission file using `utils.save_submission`.
