Implementation strategy:
1.  **Setup & Data Loading**: Initialize the environment with a fixed seed. Use the provided `DataFactory` to load the training, validation, and test datasets. This class handles the extraction of morphometric features (Hu moments, geometry) from images and merges them with the provided tabular features.
2.  **Expert Library Initialization**: Instantiate the library of expert models using `pipeline_definitions.get_expert_library`. This creates a diverse set of pipelines including Global Linear LDA, Rotational LDA, and Interaction-based LDA models (Global and Stratified), all operating with `float64` precision.
3.  **Phase 1 - Selection (Train/Val)**:
    *   Train all expert pipelines on the training split (`df_train`).
    *   Generate probability predictions for the validation split (`df_val`).
    *   Use `ensemble_strategy.GreedySelector` to perform forward selection, identifying the optimal subset of experts and their weights that minimize the Multi-class Log Loss on the validation set.
    *   **Metric & Analysis**: Print the final validation metric. Perform failure analysis by calculating the correlation between sample-wise log loss and feature values (e.g., morphometrics, texture) to identify error sources.
4.  **Phase 2 - Retraining & Inference**:
    *   Combine the training and validation data into a full training set.
    *   Retrain *only* the experts selected in Phase 1 on this full dataset.
    *   Generate predictions for the test set (`df_test`) using the retrained experts.
    *   Aggregate these predictions using the ensemble weights determined in Phase 1.
5.  **Submission**: Format the final predictions into a CSV file using `utils.create_submission`, ensuring the output matches the required format.
