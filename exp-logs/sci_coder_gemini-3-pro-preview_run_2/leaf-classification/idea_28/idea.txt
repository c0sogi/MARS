Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose the **Multi-Resolution Precision-Generative Ensemble (MR-PGE)**.

This strategy structurally evolves the "Generative Library" (Idea 23) and "Morphological Augmentation" (Idea 22) concepts. It resolves the tension between Lesson 63 (Global Concatenation is best for provided features) and Lesson 50/22 (Morphological features add value) by formalizing the data into a **Multi-Resolution Hierarchy**. By treating the "Macro" (Geometric) and "Micro" (Texture/Margin) resolutions as distinct views with dedicated experts, we allow the **Greedy Selector** to mathematically determine the optimal balance between high-level shape constraints and fine-grained texture details, without the signal dilution caused by blind concatenation.

# Model
The solution utilizes a **Dynamic Ensemble Selection** architecture composed of a library of probabilistic experts. Each expert is tailored to a specific **Resolution** of the data and utilizes **Double-Precision Generative Models** to ensure stability.

### 1. The Multi-Resolution Expert Library
All experts operate in `float64` (Cite `solution_lesson_node_00073`) and use `PowerTransformer` (Cite `solution_lesson_node_00070`).

*   **Resolution A: Macro-View Experts (The Physical Signal)**
    *   **Input:** Explicit **Morphological Descriptors** (Hu Moments + Geometric Scalars).
    *   **Dimensionality:** Low ($D \approx 12$).
    *   **Algorithms:**
        *   **LDA** with Shrinkage Library (Ledoit-Wolf, OAS, Fixed Grid).
        *   **Regularized QDA:** Unlike the high-dimensional views, this low-dimensional view allows for **Quadratic Discriminant Analysis** with regularization. This captures **heteroscedasticity** (class-specific shape variance) which LDA misses, providing a high-capacity expert for the physical geometry (Cite `solution_lesson_node_00050`).
    *   **Role:** Captures invariant global shape constraints.

*   **Resolution B: Micro-View Experts (The Statistical Signal)**
    *   **Input:** The 192 Provided Features (Margin, Shape, Texture).
    *   **Dimensionality:** High ($D = 192$).
    *   **Algorithms:** **LDA** with Shrinkage Library (Ledoit-Wolf, OAS, Fixed Grid `[0.001, 0.01, 0.1]`).
    *   **Role:** Preserves the state-of-the-art baseline performance (Cite `solution_lesson_node_00063`, `solution_lesson_node_00090`). QDA is excluded here due to the "Small N, High D" constraint.

*   **Resolution C: Synergistic Experts (The Combined Signal)**
    *   **Input:** Concatenation of Macro + Micro views.
    *   **Algorithms:** **LDA** with Shrinkage Library.
    *   **Role:** Captures cross-covariance between global shape and local texture.

### 2. Selection Mechanism
*   **Greedy Forward Selection:** We employ the selection strategy from Lesson 56. We iteratively add experts from the library to the ensemble *if and only if* they maximize the improvement in Validation Log Loss. This ensures that if the Macro view is redundant (as hinted in Lesson 90), it is discarded; if it adds orthogonal signal (as in Lesson 22), it is included (Cite `solution_lesson_node_00056`).

# Data
1.  **Feature Engineering (Multi-Resolution):**
    *   **Macro-Resolution:** Load raw binary images. Extract **Hu Moments** (7 invariant descriptors) and **Geometric Scalars** (Aspect Ratio, Solidity, Extent, Eccentricity) using `skimage.measure.regionprops`.
    *   **Micro-Resolution:** Load the provided 192 feature vectors.
    *   **Synergistic:** Concatenate Macro and Micro feature matrices.
2.  **Preprocessing (The Rigor):**
    *   **Precision:** Cast **all** feature matrices to `float64`. This is mandatory for minimizing Log Loss near the theoretical floor (Cite `solution_lesson_node_00073`).
    *   **Gaussianization:** Apply `PowerTransformer(method='yeo-johnson')` to all views. This forces the skewed geometric scalars and non-normal histograms to conform to the Gaussian assumption of the generative models (Cite `solution_lesson_node_00070`).
    *   **Leakage Prevention:** Transformers are fit on the training split and applied to the test split.

# Training
The training procedure rigorously separates the Selection phase from the Final Retraining phase to maximize data utilization (Cite `solution_lesson_node_00010`).

1.  **Phase 1: Selection (Train/Val Split)**
    *   Split training data (80/20).
    *   **Train Library:** Train all experts (LDA variants on all views; Regularized QDA on Macro view) using the 80% split.
        *   *Note:* The Shrinkage Grid for LDA should be `[0.0001, 0.001, 0.01, 0.1, 0.5]` to capture the optimal fixed point (Cite `solution_lesson_node_00081`).
    *   **Generate Predictions:** Compute `float64` probability matrices on the 20% hold-out set.
    *   **Run Selection:** Apply Greedy Forward Selection (with replacement) to determine the optimal subset of experts and their integer weights.

2.  **Phase 2: Final Retraining (Full Data)**
    *   Retrain *only* the selected experts on the **Combined Training + Validation Set**.
    *   Use the exact hyperparameters (e.g., specific shrinkage or regularization values) identified in Phase 1 to prevent configuration drift (Cite `solution_lesson_node_00028`).

# Evaluation
1.  **Inference:**
    *   Extract Macro-Resolution features for the Test set.
    *   Process the test set through the retrained pipelines of the selected experts (applying `PowerTransformer` and `float64` casting).
2.  **Aggregation:**
    *   Compute the final submission probabilities using the **Weighted Average** determined in Phase 1.
    *   This strategy combines the robustness of the Global LDA baseline with the specialized capacity of the Macro-QDA expert, strictly managed by validation performance.
