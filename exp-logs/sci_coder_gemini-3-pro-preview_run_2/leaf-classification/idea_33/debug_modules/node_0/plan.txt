Here is the implementation strategy and the complete Python script.

### Strategy Outline
1.  **Environment Setup**: Initialize random seeds and suppress unnecessary warnings to ensure a clean, reproducible run.
2.  **Data Loading**: Use `data_loader.get_data_splits` to load training and validation data. This demonstrates the integration of metadata loading and macro feature extraction. We will assert the data shapes to verify correctness.
3.  **Feature Extraction Verification**: Manually invoke `feature_extraction.process_single_image` on a sample image to verify the image processing logic (Hu moments and geometric properties) works as expected.
4.  **Model Training (Expert Library)**:
    *   Retrieve the list of expert configurations using `model_library.build_expert_library()`.
    *   Iterate through each expert (Parametric, Non-Parametric, Morphometric), fitting their respective pipelines on the training data.
    *   Generate probability predictions on the validation set for each expert.
5.  **Ensemble Selection**:
    *   Instantiate the `ensemble_selection.GreedySelector`.
    *   Fit the selector using the validation predictions to determine the optimal combination of experts that minimizes Log Loss.
    *   Validate that experts were actually selected.
6.  **Inference & Submission**:
    *   Load the test dataset using `data_loader.get_test_data`.
    *   Generate predictions for the test set using the trained experts.
    *   Aggregated these predictions using the fitted selector.
    *   Format the output into the required CSV format and save it to `submission.csv`.
