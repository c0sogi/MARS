The following script demonstrates the complete workflow using the provided library modules. It performs the following steps:
1.  **Setup & Configuration**: Sets random seeds for reproducibility.
2.  **Data Loading**: Uses `data_loader.py` to load and preprocess the training and testing data from the metadata CSVs. It verifies the data shapes and class counts.
3.  **Model Instantiation**: Demonstrates how to build the individual model branches (Linear, Generative, Kernel) using `model_factory.py` and inspects their pipeline steps.
4.  **Ensemble Training**: Uses `engine.train_ensemble` to train all three branches on the loaded data. It verifies that the returned dictionary contains the expected trained models.
5.  **Inference**: Uses `engine.predict_ensemble` to generate soft-voting predictions on the test set. It verifies the probability properties (range [0, 1]).
6.  **Submission Generation**: Uses `utils.create_submission_file` to format the predictions into a CSV file and validates the output format.
