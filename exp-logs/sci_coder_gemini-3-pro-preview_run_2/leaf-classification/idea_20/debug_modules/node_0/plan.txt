The following implementation demonstrates the complete workflow using the provided library files. It loads the Leaf Classification dataset, trains three distinct expert models (Generative, Metric-Discriminative, and Metric-Generative), optimizes their hyperparameters, selects the best ensemble using Greedy Forward Selection, and generates a submission file.

The script is optimized for speed by using the full dataset (which is small, ~900 samples total) rather than a subset, ensuring all 99 classes are present for stable training of Linear Discriminant Analysis and Neighborhood Components Analysis. It includes rigorous assertions to verify data shapes, pipeline structures, and output formats.
