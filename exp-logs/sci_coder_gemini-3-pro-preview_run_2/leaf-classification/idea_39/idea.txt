Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose the **Dual-Stream Precision-Generative Library (DSPGL)**.

This strategy structurally evolves the "Generative Library" (Idea 23) and "Precision-Gaussianized" (Idea 30) concepts. It directly addresses the "Metric Floor Paradox" (Lesson 90) and the specific failure mode of Non-Parametric Gaussianization (Lesson 76). By establishing two parallel, high-precision preprocessing streams—one **Parametric** (proven baseline) and one **Regularized Non-Parametric** (innovation)—and managing them via **Greedy Selection**, we create a stereoscopic density estimation framework that is mathematically robust, statistically diverse, and strictly protected against overfitting.

# Model
The solution utilizes a **Dynamic Ensemble Selection** architecture. We generate a library of probabilistic experts that vary in **Gaussianization Basis**, **Covariance Estimation**, and **Feature Resolution**.

### 1. The Dual-Stream Architecture
All experts operate in **double precision (`float64`)** to strictly minimize numerical noise at the metric floor (Cite `solution_lesson_node_00073`).

*   **Stream A: Parametric Gaussian Anchors (The Baseline)**
    *   **Preprocessing:** **PowerTransformer** (Yeo-Johnson).
    *   **Rationale:** Stabilizes variance using a smooth, global power law. This satisfies the normality assumption of LDA while preserving global linear structure, serving as the proven state-of-the-art baseline (Cite `solution_lesson_node_00070`).

*   **Stream B: Constrained Non-Parametric Experts (The Innovation)**
    *   **Preprocessing:** **QuantileTransformer** with `output_distribution='normal'` and **`n_quantiles=50`**.
    *   **Rationale:** Lesson 76 failed because `n_quantiles` was set to ~700 (matching $N$), causing the transformer to memorize the training distribution (overfitting) and destroy linear separability. By strictly constraining `n_quantiles` to a small value (e.g., 50, approx 7% of $N$), we create a **Regularized Rank-Based Normalizer**. This handles multi-modal or highly skewed features that Yeo-Johnson cannot fix, providing a mathematically distinct "Gaussian View" without overfitting the empirical distribution function (Cite `solution_lesson_node_00076`).

### 2. The Expert Library
For each Stream, we instantiate a set of **Linear Discriminant Analysis (LDA)** experts applied to specific Feature Views:

*   **Global Experts:**
    *   **Input:** The 192 provided features (Margin, Shape, Texture).
    *   **Estimators:**
        *   **OAS-LDA:** Uses **Oracle Approximating Shrinkage**. Proven to be asymptotically optimal for this dataset (Cite `solution_lesson_node_00090`).
        *   **Fixed-Shrinkage LDA:** A grid of fixed shrinkage values (`[0.001, 0.01, 0.1]`). Captures empirical optima that analytical methods might miss (Cite `solution_lesson_node_00081`).

*   **Macro-Resolution Experts:**
    *   **Input:** Explicit **Morphological Descriptors** (Hu Moments + Geometric Scalars).
    *   **Estimators:** **LDA** with Ledoit-Wolf shrinkage.
    *   **Rationale:** Captures invariant physical shape constraints orthogonal to the texture histograms. We use LDA (Shared Covariance) because the sample size ($N_{class} \approx 8$) is too small to support Class-Specific Covariance (QDA) even in this low-dimensional space (Cite `solution_lesson_node_00094`, `solution_lesson_node_00050`).

### 3. Selection Mechanism
*   **Greedy Forward Selection:** We employ the selection strategy from Lesson 56. We iteratively add experts to the ensemble *if and only if* they maximize the improvement in Validation Log Loss. This ensures that if the Parametric OAS-LDA is sufficient, the ensemble converges to it; if the Constrained Non-Parametric stream adds orthogonal signal, it is incorporated (Cite `solution_lesson_node_00056`).

# Data
1.  **Feature Engineering:**
    *   **Global View:** Load the provided 192 feature vectors.
    *   **Macro View:** Load raw binary images. Extract **Deterministic** Morphometrics: **Hu Moments** (7 invariant descriptors) and **Geometric Scalars** (Aspect Ratio, Solidity, Extent, Eccentricity). We explicitly reject Monte-Carlo augmentation (Cite `solution_lesson_node_00089`) and ImageNet features (Cite `solution_lesson_node_00049`).
2.  **Preprocessing (The Rigor):**
    *   **Precision:** Cast **all** feature matrices to `float64`. This is mandatory for minimizing Log Loss near the theoretical floor (Cite `solution_lesson_node_00073`).
    *   **Stream Generation:** Apply `PowerTransformer` (Stream A) and `QuantileTransformer(n_quantiles=50)` (Stream B) to generate transformed versions of both Global and Macro views.
    *   **Leakage Prevention:** Transformers are fit on the training split and applied to the test split.

# Training
The training procedure rigorously separates the Selection phase from the Final Retraining phase to maximize data utilization (Cite `solution_lesson_node_00010`).

1.  **Phase 1: Selection (Train/Val Split)**
    *   Split training data (80/20).
    *   **Train Library:** Train all experts (Stream A/B $\times$ Global/Macro $\times$ OAS/Fixed) on the 80% split.
    *   **Generate Predictions:** Compute `float64` probability matrices on the 20% hold-out set.
    *   **Run Selection:** Apply Greedy Forward Selection (with replacement) to determine the optimal subset of experts and their integer weights.

2.  **Phase 2: Final Retraining (Full Data)**
    *   Retrain *only* the selected experts on the **Combined Training + Validation Set**.
    *   Use the exact hyperparameters (e.g., shrinkage values) identified in Phase 1 to prevent configuration drift (Cite `solution_lesson_node_00028`).

# Evaluation
1.  **Inference:**
    *   Extract Macro features for the Test set.
    *   Process the test set through the retrained pipelines of the selected experts (applying the specific Gaussianization stream and `float64` casting).
2.  **Aggregation:**
    *   Compute the final submission probabilities using the **Weighted Average** determined in Phase 1.
