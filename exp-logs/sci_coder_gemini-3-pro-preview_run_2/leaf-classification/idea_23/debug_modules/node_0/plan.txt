This script demonstrates the end-to-end usage of the provided machine learning library for the leaf classification task. It covers data loading, feature extraction verification, data preprocessing, expert model definition, ensemble selection using a greedy strategy, and final submission generation.

The strategy involves:
1.  **Data Management**: Using `DataManager` to load pre-extracted features and compute morphometric features from images.
2.  **Preprocessing**: Applying `PowerTransformer` (Yeo-Johnson) to normalize feature distributions, handling both 'Global' (provided features) and 'Combined' (provided + morphometrics) views.
3.  **Expert Library**: Instantiating a diverse set of LDA and Naive Bayes models using `expert_factory`.
4.  **Ensemble Optimization**: Using `GreedySelector` to select the optimal combination of experts based on validation log loss. We limit iterations to 20 for this demonstration to ensure speed.
5.  **Refitting and Prediction**: Retraining the selected ensemble on the full dataset (Train + Validation) and generating predictions for the test set.
