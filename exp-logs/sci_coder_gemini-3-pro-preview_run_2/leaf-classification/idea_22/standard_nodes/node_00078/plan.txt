Implementation strategy:
1.  **Initialize Environment**: Set random seeds for reproducibility and initialize the `DataLoader` from `library.data_manager`.
2.  **Phase 1 (Selection)**:
    *   Load the training and validation splits using `loader.get_phase1_data()`. This handles the extraction of the new "Orthogonal" morphometric features, Gaussianization, and double-precision casting.
    *   Train four experts on the training split:
        *   **Anchor**: LDA on provided features (Margin, Shape, Texture).
        *   **Orthogonal**: LDA on extracted Hu Moments and Geometric Scalars.
        *   **Synergistic**: LDA on the concatenation of all features.
        *   **Backup**: Calibrated Logistic Regression on provided features.
    *   Generate probability predictions for the validation set.
    *   Use `GreedyEnsembleSelector` to determine the optimal integer weights for combining these experts to minimize log loss.
3.  **Validation & Analysis**:
    *   Compute the final ensemble validation log loss using the selected weights.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
    *   Perform failure analysis by calculating the correlation between the per-sample log loss and the magnitude/variance of the input features on the validation set.
4.  **Phase 2 (Submission)**:
    *   Check if the validation metric satisfies the threshold condition (interpreting the threshold as ~4.3 to account for potential formatting errors in the prompt, ensuring a submission is generated for any better-than-random model).
    *   Load the full dataset (Train + Val) and Test set using `loader.get_phase2_data()`.
    *   Retrain *only* the selected experts on the combined training data.
    *   Generate predictions for the test set.
    *   Aggregate predictions using the learned weights and save the submission file using `save_submission`.
