Implementation Strategy:
1.  **Setup & Imports**: Initialize the environment with a fixed random seed and import necessary modules, including the provided library functions (`data_loader`, `model_factory`, `ensemble_selection`, `utils`).
2.  **Data Loading**: Use `load_dataset(load_cached_data=True)` to efficiently retrieve the training, validation, and test sets.
3.  **Phase 1 (Expert Training & Selection)**:
    *   Instantiate the expert pool (`Linear_LDA`, `Kernel_LDA`, `Linear_LR`) using `model_factory`.
    *   Train each expert on the training split and generate probability predictions for the validation split.
    *   Use `GreedySelector` to determine the optimal ensemble weights that minimize log loss on the validation set.
    *   Capture and print the `Final Validation Metric`.
4.  **Failure Analysis**:
    *   Reconstruct the ensemble predictions for the validation set using the selected weights.
    *   Calculate the per-sample log loss (error magnitude).
    *   Compute the Pearson correlation between each feature in the validation set and the error magnitude.
    *   Print the top 5 features most correlated with model error to identify systematic weaknesses.
5.  **Submission Generation (Conditional)**:
    *   Check if the `Final Validation Metric` is strictly lower than the specified threshold (`3.3768e-06`).
    *   **If the condition is met**:
        *   Combine training and validation data into a full training set.
        *   Retrain the selected experts (those with non-zero weights) on the full dataset.
        *   Generate predictions for the test set using the retrained ensemble.
        *   Format and save the predictions to `./submission/submission.csv`.
    *   **If the condition is not met**:
        *   Print a message indicating the threshold was not reached and skip submission generation, adhering strictly to the "If and only if" constraint.
