This script demonstrates the usage of the provided library files to execute the Stratified-Manifold Full-Rank Interaction Ensemble (SM-FRIE) pipeline. It performs the following steps:

1.  **Configuration Patching**: Redirects working directories and output paths to a temporary demo folder to ensure isolation and prevent overwriting existing results.
2.  **Feature Extraction Verification**: Validates the `image_features` module by creating a synthetic binary leaf image and asserting that morphometric features (like aspect ratio and solidity) are extracted correctly.
3.  **Data Loading**: Uses `LeafDataManager` (via `ExperimentRunner`) to load the dataset, processing images and merging them with tabular features. It verifies the integrity and dimensions of the generated feature views (Global, Margin, Shape, Texture, Morphometrics).
4.  **Pipeline Execution**: Runs the `ExperimentRunner` to perform:
    *   **Phase 1 (Selection)**: Trains the library of probabilistic experts (LDA/QDA variants) on a subset of the training data and selects the optimal ensemble using Greedy Forward Selection based on validation log loss.
    *   **Phase 2 (Inference)**: Retrains the selected ensemble on the full combined dataset and generates predictions for the test set.
5.  **Submission Verification**: Checks the generated submission file for correct formatting and value ranges.
