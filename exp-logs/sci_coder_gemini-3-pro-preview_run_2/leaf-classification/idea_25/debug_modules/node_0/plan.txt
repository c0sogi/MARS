This script demonstrates the end-to-end usage of the provided Leaf Classification library. It optimizes for execution speed by enabling `DEBUG_MODE` via monkey-patching, which processes only a small subset of the data. The workflow includes loading data with the `DataManager` (which triggers the `ImageProcessor` for feature extraction), training a suite of expert models from `model_zoo`, optimizing an ensemble using `GreedySelector`, and generating a submission file. Assertions are included to verify data integrity and prediction validity.
