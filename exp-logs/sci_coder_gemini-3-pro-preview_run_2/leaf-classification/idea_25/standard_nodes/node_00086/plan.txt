The implementation strategy follows the "Monte-Carlo Augmented Generative Library Ensemble" design.

1.  **Data Loading & Preparation**: We initialize the `DataManager` and load the training, validation, and test sets. This handles the Monte-Carlo feature extraction (via caching) and constructs the three feature views: 'Global', 'Morph', and 'Combined'.
2.  **Expert Library Training (Phase 1)**: We instantiate the expert library (LDA, QDA, GNB variants) using `model_zoo`. We train all experts on the training split and generate probability predictions for the validation split.
3.  **Ensemble Selection**: We use the `GreedySelector` to perform Forward Selection on the validation predictions, optimizing for Log Loss. This yields a set of optimal weights for the experts.
4.  **Validation & Failure Analysis**: We compute the final ensemble Log Loss on the validation set. We then perform failure analysis by calculating the per-sample log loss and correlating it with the input features to identify error drivers.
5.  **Final Retraining & Submission (Phase 2)**: Based on the selected experts, we retrain them on the combined (Train + Validation) dataset to maximize data utilization. We generate predictions for the test set, apply the learned ensemble weights, and format the output into `submission.csv`.
