### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed using `library.utils.set_seed` to ensure reproducibility.
2.  **Data Loading**: Use `library.data_loader.load_data` to load the training, validation, and test datasets. This function automatically handles the extraction of morphometric features from images and merges them with the provided tabular features.
3.  **Expert Library Initialization**: Calculate class priors from the training labels. Then, instantiate the library of probabilistic experts using `library.expert_library.get_expert_library`, passing the feature slices definition obtained from the data loader.
4.  **Model Training (Fit)**: Iterate through each expert pipeline in the library. Fit each pipeline on the training data (`X_train`, `y_train`) and generate probability predictions for the validation set (`X_val`).
5.  **Ensemble Selection**: Use `library.ensemble_selection.greedy_forward_selection` to determine the optimal combination of experts that minimizes log loss on the validation set. This results in a dictionary of weights for the selected experts.
6.  **Inference (Predict)**: Using the fitted pipelines of the selected experts, generate predictions for the test set (`X_test`). Compute the final weighted ensemble prediction using `library.ensemble_selection.compute_ensemble_prediction`.
7.  **Submission**: Format the final predictions using the test IDs and class names, and save the submission file using `library.utils.save_submission`.
8.  **Verification**: Throughout the script, assertions are used to verify data shapes, prediction probabilities, and file outputs to ensure correctness.
