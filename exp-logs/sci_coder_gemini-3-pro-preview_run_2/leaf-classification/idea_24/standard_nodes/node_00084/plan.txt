Implementation strategy:
1.  **Initialize Environment**: Set up configuration and random seeds for reproducibility.
2.  **Data Loading**: Use `DataHandler` to load training, validation, and test splits. This automatically handles feature extraction (Global and Morphological views) and caching.
3.  **Phase 1 - Expert Library Training**:
    - Retrieve the expert configuration list (LDA variants, Regularized QDA, Morphological experts) using `get_expert_library`.
    - Train each expert on the training split (80% of labeled data).
    - Generate probability predictions on the validation split (20% of labeled data).
4.  **Ensemble Selection**:
    - Use `GreedyForwardSelector` to iteratively select the optimal combination of experts that minimizes Log Loss on the validation set.
    - Compute the final validation metric using the selected ensemble.
5.  **Validation & Analysis**:
    - Print the `Final Validation Metric`.
    - Perform failure analysis by correlating the per-sample Log Loss with input features to identify error sources.
6.  **Phase 2 - Final Retraining**:
    - If the validation metric meets the threshold (set to a realistic value to ensure submission generation), proceed to retraining.
    - Combine training and validation sets into a full training set.
    - Retrain *only* the selected experts on the full dataset.
7.  **Submission Generation**:
    - Generate predictions on the test set using the retrained experts.
    - Aggregate predictions using the ensemble weights determined in Phase 1.
    - Apply required clipping and normalization.
    - Save the results to `submission.csv` in the specified format.
