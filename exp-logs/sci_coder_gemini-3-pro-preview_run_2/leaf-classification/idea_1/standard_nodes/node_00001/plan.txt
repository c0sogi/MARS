The implementation strategy involves the following steps:

1.  **Setup and Initialization**: Import necessary standard libraries and the provided custom library modules (`Config`, `LeafDataLoader`, `FeatureScaler`, `LogisticBaseline`, `evaluation`). Set random seeds for reproducibility.
2.  **Data Loading**: Use `LeafDataLoader` to load the training, validation, and testing datasets. Enable caching to speed up execution if data was previously processed.
3.  **Feature Scaling**: Apply `FeatureScaler` to normalize the features (Z-score standardization), which is crucial for the convergence and performance of the Logistic Regression model.
4.  **Model Training**: Instantiate the `LogisticBaseline` model (Regularized Multinomial Logistic Regression). Train it on the full scaled training set. Given the small dataset size (~700 samples), training is extremely fast and does not require subsampling.
5.  **Validation**:
    *   Use the trained model to predict probabilities on the validation set.
    *   Calculate the Multi-class Log Loss using `evaluation.compute_log_loss`.
    *   Print the `Final Validation Metric` with full precision.
6.  **Failure Analysis**:
    *   Compute the per-sample log loss on the validation set to quantify "error magnitude".
    *   Calculate the Pearson correlation coefficient between this error magnitude and each of the 192 input features.
    *   Identify and print the features most strongly correlated with high prediction error.
7.  **Submission Generation**:
    *   Generate probability predictions for the test set.
    *   Format the predictions into the required CSV format using the `generate_submission` helper function from `library.model`.
    *   Save the file to `./submission/submission.csv`.
