To establish a reliable, high-speed baseline that is distinct from the complex tree-based, deep learning, and kernel-based architectures previously listed, I propose a linear probabilistic approach.

# Model
The proposed baseline is a **Regularized Multinomial Logistic Regression** (also known as Softmax Regression). Unlike the non-linear approaches (GBDT, SVC with RBF kernel, Neural Networks) or instance-based methods (k-NN) listed in the Model Architectures, this model assumes a linear relationship between the input features and the log-odds of the classes. It consists of a single linear layer that maps the 192 extracted feature dimensions directly to the 99 class logits, followed by a Softmax activation function to normalize these logits into a valid probability distribution. This architecture is computationally inexpensive, interpretable, and directly optimizes the target metric (log loss).

# Data
To prioritize speed and simplicity, this approach will exclusively use the **192 extracted features** (margin, shape, and texture) provided in the CSV files, discarding the raw image data.
1.  **Loading:** The training and test feature vectors will be loaded from the CSV files.
2.  **Imputation:** Although the EDA showed no missing values, a simple mean imputer will be instantiated as a safeguard for the test set.
3.  **Scaling:** A Standard Scaler (Z-score normalization) will be applied to all features. This is a critical step for linear models to ensure that features with different magnitudes (e.g., texture vs. shape histograms) contribute equally to the gradient updates and to speed up convergence.

# Training
The model will be trained using a convex optimization algorithm (such as L-BFGS or Newton-CG) to minimize the **Multi-class Log Loss** (Cross-Entropy).
-   **Regularization:** To prevent overfitting—a significant risk given the high dimensionality (192 features) relative to the small sample size (~700 training samples)—**L2 Regularization** (Ridge penalty) will be applied. The regularization strength (C or alpha) will be fixed at a default value or selected via a quick cross-validation on the training set.
-   **Efficiency:** As a convex problem, training is guaranteed to converge to a global optimum rapidly without the need for complex hyperparameter tuning or GPU acceleration.

# Evaluation
For the test set, the preprocessed (scaled) features will be passed through the trained linear model. The output will be a probability matrix of shape (N_test, 99), where each row sums to 1. These probabilities will be formatted directly into the submission CSV file. The simplicity of the model ensures that inference time is negligible.
