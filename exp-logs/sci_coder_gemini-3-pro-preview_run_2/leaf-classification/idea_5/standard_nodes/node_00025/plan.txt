To optimize performance, I will revert the solution to the high-performing "Hybrid Ensemble" architecture (Logistic Regression + LDA) described in the lessons, removing the "Quadratic Component" (PCA -> Polynomial -> LR). The previous run showed that the Quadratic component, despite having low training loss, degraded the validation log loss to `0.0152` compared to the known baseline of `~0.0102` (Cite solution_lesson_node_00009). This confirms that adding complex, potentially overfitting models dilutes the calibrated probabilities of the simpler, robust linear models.

Additionally, I will increase the `max_iter` of the `LogisticRegressionCV` from 2000 to 5000 to ensure full convergence during hyperparameter tuning (Cite solution_lesson_node_00010).

def build_quadratic_pipeline(random_state=42, n_jobs=-1, pca_variance=0.95):
    """
    Constructs the Discriminative Quadratic Component:
    StandardScaler -> PCA -> PolynomialFeatures -> LogisticRegressionCV

    This pipeline captures non-linear interactions while managing dimensionality via PCA.

    Args:
        random_state (int): Seed for reproducibility.
        n_jobs (int): Number of CPU cores to use.
        pca_variance (float): Variance ratio to retain in PCA (0.0 < v <= 1.0).

    Returns:
        sklearn.pipeline.Pipeline: The constructed quadratic pipeline.
    """
    set_seed(random_state)

    # Constrain the search space
    Cs = np.logspace(-2, 4, 20)

    pipeline = Pipeline(
        [
            ("scaler", StandardScaler()),
            ("pca", PCA(n_components=pca_variance, random_state=random_state)),
            ("poly", PolynomialFeatures(degree=2, include_bias=False)),
            (
                "clf",
                LogisticRegressionCV(
                    Cs=Cs,
                    cv=3,
                    penalty="l2",
                    solver="lbfgs",
                    multi_class="multinomial",
                    max_iter=2000,
                    scoring="neg_log_loss",
                    random_state=random_state,
                    n_jobs=n_jobs,
                ),
            ),
        ]
    )
    return pipeline

def predict_ensemble(models, X_test):
    """
    Generates predictions using the Soft-Voting Ensemble strategy.
    Aggregates predictions from Linear, Generative, and Quadratic models.

    Args:

    set_seed(42)

    required_keys = ["linear", "generative", "quadratic"]

    # Combines the strengths of all three approaches
    print("Averaging probabilities...")
