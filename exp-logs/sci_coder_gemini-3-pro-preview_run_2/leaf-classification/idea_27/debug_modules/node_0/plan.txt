The following script demonstrates the usage of the provided library components for the leaf classification task. It validates the functionality of the preprocessing, model generation, and ensemble selection modules individually before executing the full pipeline to generate a submission.

To ensure the demonstration runs cleanly and efficiently:
1.  **Configuration Override**: The script monkey-patches the `Config` class to redirect outputs to a dedicated `./working/demo_run` directory, ensuring isolation.
2.  **Component Validation**:
    *   **Preprocessing**: Verifies that `RobustPreprocessor` correctly handles data transformation and sanitization.
    *   **Expert Library**: Confirms that the `ExpertLibrary` factory produces the expected dictionary of LDA and QDA models.
    *   **Ensemble Selection**: Tests the `GreedyEnsembleSelector` with synthetic data to ensure it correctly identifies and weights the best-performing models.
3.  **Pipeline Execution**: Runs the complete `Pipeline` end-to-end. This involves feature extraction (Zernike moments), Tier 1 & 2 model training, ensemble weight optimization, and final inference.
4.  **Result Verification**: Checks the generated submission file for correct dimensions and format.
