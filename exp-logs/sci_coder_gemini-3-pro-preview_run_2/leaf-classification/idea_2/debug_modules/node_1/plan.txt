The error `ValueError: n_splits=5 cannot be greater than the number of members in each class` occurs because the `GridSearchCV` used within the SVM component has a hardcoded cross-validation split (`cv=5`) in `library/model_factory.py`. The dataset contains classes with as few as 5 samples total (and likely fewer in the training split), making a 5-fold split impossible for stratified cross-validation.

To fix this, I will:
1.  **Modify `library/config.py`**:
    *   Add a new configuration parameter `SVM_GRID_CV` defaulting to 3 (a safer baseline for small datasets).
    *   Reduce the default `cv` in `SVM_CALIBRATION_PARAMS` and `LR_PARAMS` from 5 to 3 to prevent similar errors in other components or the calibration step.
2.  **Modify `library/model_factory.py`**:
    *   Replace the hardcoded `cv=5` in `GridSearchCV` with `Config.SVM_GRID_CV`.
3.  **Modify `runfile.py`**:
    *   Update `optimize_config_for_demo` to set `Config.SVM_GRID_CV = 2`, ensuring the demo run (which uses `cv=2` for other components) remains consistent and error-free.
