The implementation orchestrates the Component-Wise Polynomial Precision-Generative Ensemble (CW-PPGE) workflow. It begins by initializing the environment and loading the dataset using `LeafData`, which handles feature extraction and caching. The workflow proceeds in two phases: first, a Greedy Forward Selection is performed on the training and validation splits to identify the optimal subset of experts from the `EXPERT_LIBRARY_CONFIG` (LDA models with various preprocessing topologies). The best validation log loss is reported. Second, a Failure Analysis is conducted by re-evaluating the selected ensemble on the validation set and correlating the per-sample log loss with morphometric features to identify error patterns. Finally, the selected experts are retrained on the combined training and validation data, and predictions are generated for the test set and saved to a CSV file.
