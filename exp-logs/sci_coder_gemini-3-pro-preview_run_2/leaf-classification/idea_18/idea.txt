Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose the **Adaptive Denoised Generative Ensemble (ADGE)**.

This strategy structurally evolves the "Greedy Forward Selection" (Lesson 56) and "Global LDA" (Lesson 63) concepts. It addresses the hypothesis that while the Global LDA is a "Super-Expert," it may still be inhibited by noise or redundancy within the 192 handcrafted features (hinted at in Lesson 52). Instead of forcing a choice between "All Features" (Global) or "Semantic Subsets" (Multi-View, which failed in Lesson 63), this solution generates a pool of experts trained on **mathematically denoised subspaces** and allows the ensemble selector to empirically determine the optimal signal-to-noise ratio.

# Model
The solution utilizes a **Dynamic Ensemble Selection** architecture composed of three distinct tiers of experts, all governed by a Greedy Forward Selector.

1.  **Tier 1: Global Generative Anchor (The Baseline)**
    *   **Architecture:** `StandardScaler` $\rightarrow$ **Linear Discriminant Analysis (LDA)**.
    *   **Configuration:** Uses **Ledoit-Wolf shrinkage**.
    *   **Role:** Captures the holistic signal from all 192 features, serving as the proven high-performance baseline (Cite `solution_lesson_node_00063`).

2.  **Tier 2: Denoised Generative Experts (The Innovation)**
    *   **Architecture:** `StandardScaler` $\rightarrow$ **SelectKBest (Mutual Information)** $\rightarrow$ **LDA** (with shrinkage).
    *   **Rationale:** Previous experiments showed that adding redundant features degraded performance (Cite `solution_lesson_node_00052`) and that random feature subsampling (Bagging) destroyed linear separability (Cite `solution_lesson_node_00027`). This tier introduces **Informed Feature Selection**. We instantiate multiple LDA experts trained on the top $K$ features (e.g., $K=144, 96, 48$) ranked by Mutual Information. This allows the model to test if a reduced, higher-density feature space yields better covariance estimation than the full 192-dimensional space.

3.  **Tier 3: Discriminative Backup**
    *   **Architecture:** `StandardScaler` $\rightarrow$ **Logistic Regression**.
    *   **Configuration:** Uses `LogisticRegressionCV` with a **Dense Logarithmic Grid** (Cite `solution_lesson_node_00047`) and explicitly optimizes `neg_log_loss` (Cite `solution_lesson_node_00031`).
    *   **Role:** Provides a purely discriminative decision boundary to complement the generative models if specific class boundaries are non-Gaussian.

4.  **Selection Mechanism:**
    *   **Greedy Forward Selection:** Instead of averaging all experts (which causes dilution, Cite `solution_lesson_node_00009`), we iteratively add experts to the ensemble *only if* they improve the Validation Log Loss (Cite `solution_lesson_node_00056`). This ensures that if the Global Anchor is optimal, the ensemble converges to it; if a Denoised Expert is superior, it is prioritized.

# Data
1.  **Feature Selection:** Utilize the **192 extracted features** (Margin, Shape, Texture) exclusively. We explicitly reject raw images and deep learning (Cite `solution_lesson_node_00049`) and coarse geometric scalars (Cite `solution_lesson_node_00052`) to maintain the high quality of the provided descriptors.
2.  **Preprocessing:**
    *   **Global Scaling:** Apply `StandardScaler` to all pipelines. Explicitly avoid non-linear transformers like `QuantileTransformer` (Cite `solution_lesson_node_00003`).
    *   **Filter Selection:** The `SelectKBest` step is applied internally within the Denoised Experts' pipelines to prevent leakage.

# Training
The training procedure rigorously separates the Selection phase from the Final Retraining phase to maximize data utilization (Cite `solution_lesson_node_00010`).

1.  **Phase 1: Selection (Train/Val Split)**
    *   Split the training data (80/20).
    *   **Train Expert Pool:**
        *   1x Global LDA (192 feats).
        *   3x Denoised LDAs (Top 75%, 50%, 25% features via Mutual Info).
        *   1x Global Logistic Regression.
    *   **Generate Predictions:** Compute probabilities on the 20% hold-out set.
    *   **Run Selection:** Apply Greedy Forward Selection to determine the optimal subset of experts and their integer weights (e.g., $2 \times \text{Denoised}_{75\%} + 1 \times \text{Global LDA}$).

2.  **Phase 2: Final Retraining (Full Data)**
    *   Retrain *only* the selected experts on the **Combined Training + Validation Set**.
    *   For Logistic Regression, use the exact hyperparameters (`C`) found in Phase 1 to prevent configuration drift (Cite `solution_lesson_node_00028`).

# Evaluation
1.  **Inference:**
    *   Process the test set features through the retrained pipelines of the selected experts.
2.  **Aggregation:**
    *   Compute the final submission probabilities using the **Weighted Average** determined in Phase 1.
    *   This strategy combines the robustness of the Global baseline with the potential precision of Denoised subspaces, strictly controlled by validation performance to prevent overfitting or dilution.
