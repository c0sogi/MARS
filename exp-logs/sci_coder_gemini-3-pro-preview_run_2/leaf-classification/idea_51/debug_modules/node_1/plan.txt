The error `TypeError: got an unexpected keyword argument 'eps'` confirms that the `eps` parameter has been removed from `sklearn.metrics.log_loss` in the installed version of scikit-learn (v1.5+), as noted in `debug_lesson_12`. Since the `calculate_log_loss` function already performs explicit probability clipping using `np.clip` in the lines immediately preceding the library call, passing `eps` to `log_loss` is redundant and now causes a crash. The fix involves removing the `eps` argument from the `log_loss` function call while retaining the manual clipping logic to satisfy the competition's metric definition.
