The following script demonstrates the end-to-end pipeline for the Contrail Identification task using the provided library files. It covers:
1.  **Configuration Override**: Adjusting hyperparameters for a fast demonstration run.
2.  **Utility Verification**: Unit testing the RLE encoding and Dice metric functions.
3.  **Data Loading**: Instantiating the dataset and verifying batch shapes.
4.  **Model Initialization**: Creating the U-Net model and verifying the forward pass.
5.  **Training**: Running a short training loop with the hybrid loss function.
6.  **Inference**: Generating predictions on a subset of the test set and creating a submission file.
