This script demonstrates the usage of the provided Contrail Detection library. It performs the following steps:
1.  **Configuration Override**: Adjusts paths and parameters in the `Config` class to run a lightweight demonstration (using temporary directories and small dataset subsets).
2.  **Component Verification**:
    *   **RLE Encoding**: Validates the run-length encoding logic with a known binary mask.
    *   **Dataset**: Verifies that the `ContrailDataset` loads images and masks with correct shapes and data types.
    *   **Model & Loss**: Instantiates the `SoftGatedResnetUNet` and `SoftGatedLoss`, performs a forward pass with dummy data, and verifies the output structure and loss calculation.
3.  **Training Pipeline**: Runs a minimal training loop (1 epoch, few samples) using `train_model` to verify the training process and generate a `best_model.pth`.
4.  **Inference Pipeline**:
    *   Subsets the test metadata to ensure the inference demo runs almost instantly.
    *   Runs `predict` to generate a submission file.
    *   Validates the format and content of the generated submission.
