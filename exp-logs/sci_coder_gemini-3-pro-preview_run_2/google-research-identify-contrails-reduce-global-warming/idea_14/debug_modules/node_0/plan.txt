The following script demonstrates the usage of the provided library files to build a complete training and validation pipeline for the contrail segmentation task.

Strategy:
1.  **Configuration Override**: We modify the `Config` class parameters at runtime to enable `DEBUG` mode and reduce the dataset size (`DEBUG_SAMPLE_SIZE = 10`), batch size, and epochs. This ensures the script runs quickly for demonstration purposes.
2.  **Data Loading Verification**: We instantiate the `ContrailDataset` and a `DataLoader`. We fetch a single batch to verify that the input images have the correct 6-channel shape (Ash composite + Temporal difference) and that masks are properly formatted.
3.  **Model Initialization & Forward Pass**: We initialize the `ConvNeXtHyperUNet` model, move it to the appropriate device (GPU/CPU), and perform a forward pass with dummy data to verify the output tensor shape `(Batch, 1, H, W)`.
4.  **Loss Calculation**: We instantiate the `HybridLoss` (BCE + Dice) and compute the loss on the model's output to ensure the loss function is differentiable and returns a valid scalar.
5.  **Training Loop Execution**: We run a single epoch of training (`train_one_epoch`) and validation (`valid_one_epoch`) using the `engine.py` functions. This validates the integration of the optimizer, scaler, and training logic.
6.  **Metric & Post-processing Check**: We manually test the `rle_encode` function and `dice_coef_metric` to ensure prediction formatting and evaluation metrics are correct.
