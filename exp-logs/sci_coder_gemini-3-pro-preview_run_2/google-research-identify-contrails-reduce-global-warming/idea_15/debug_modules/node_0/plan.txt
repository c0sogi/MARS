This script demonstrates the end-to-end pipeline for identifying contrails in satellite imagery using the provided library files. It performs the following steps:

1.  **Configuration**: Patches the global configuration (`CFG`) to run in a lightweight debug mode (fewer epochs, smaller dataset subset) suitable for a quick demonstration.
2.  **Unit Verification**: Validates the correctness of core components:
    *   **Utils**: Verifies Run-Length Encoding (RLE) and Dice Coefficient calculation.
    *   **Dataset**: Checks data loading, shape consistency, and augmentation pipeline.
    *   **Model**: Validates the ConvNeXt U-Net architecture by performing a forward pass with dummy data.
    *   **Loss**: Ensures the Hybrid Loss (BCE + Dice) computes valid gradients and scalar values.
3.  **Training Loop**: Executes a single-epoch training run using `train_model` on the debug subset to generate model weights.
4.  **Inference**: Runs `predict_and_submit` to generate predictions on the test set using the trained model, producing a submission file.
