### Implementation Strategy

We will limit the training epochs to 5 and subsample the training dataset to 10,000 records (approx. 50% of the data). This ensures the model converges sufficiently to meet the metric threshold without exceeding the time budget.
2.  **Training**: We will execute the `train_model` function with `debug=True`. This triggers the dataset subsampling logic defined in the configuration step, training the `ConvNeXtUNet` model with the `HybridLoss`.
3.  **Validation & Metric Calculation**: We will manually implement a validation loop to evaluate the trained model on the **full** hold-out validation set. We will compute the Global Dice coefficient and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**: Concurrently with validation, we will calculate the error magnitude (defined as `1.0 - Dice`) for each validation sample. We will then merge these errors with the metadata (specifically `hour`, `row_min`, and `col_min`) and calculate the Pearson correlation coefficient to identify systematic failure modes.
5.  **Submission**: We will check if the calculated Global Dice exceeds the threshold of `0.5910660985501295`. If it does, we will trigger the `predict_and_submit` function to generate the submission file for the test set.
