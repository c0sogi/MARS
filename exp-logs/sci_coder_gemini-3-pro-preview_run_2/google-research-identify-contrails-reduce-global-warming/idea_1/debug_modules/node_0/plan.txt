The following script demonstrates the usage of the provided library files for the contrail segmentation task. It follows a pipeline approach: validating the dataset loading, verifying model architecture, testing utility functions (Dice score and RLE), running a short training cycle, and finally generating a submission file.

To ensure the demonstration runs quickly within the constraints, the script overrides specific `Config` parameters (reducing dataset size to 20 samples, batch size to 4, and epochs to 1). It includes assertions at each step to verify the correctness of shapes, data types, and logic.
