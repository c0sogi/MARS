The `AttributeError: 'FeatureListNet' object has no attribute 'stem'` occurs because `timm.create_model` with `features_only=True` wraps the backbone in a `FeatureListNet`, which hides internal attributes like `stem`, preventing manual modification of the input layer. To fix this, I will modify `library/model.py` to pass the `in_chans` argument directly to `timm.create_model`, which automatically handles the input channel adaptation and weight initialization. Cite debug_lesson_7. I will also remove the now redundant `_adapt_input_channels` method and its invocation.

    def _adapt_input_channels(self, in_channels):
        """
        Modifies the first convolution layer of the backbone to accept `in_channels`.
        Copies weights from the first 3 channels to the new channels to preserve initialization.
        """
        # ConvNeXt stem is usually: Sequential(Conv2d, LayerNorm)
        stem = self.encoder.stem
        old_conv = stem[0]

        if old_conv.in_channels == in_channels:
            return

        new_conv = nn.Conv2d(
            in_channels,
            old_conv.out_channels,
            kernel_size=old_conv.kernel_size,
            stride=old_conv.stride,
            padding=old_conv.padding,
            bias=old_conv.bias is not None,
        )

        # Initialize weights
        with torch.no_grad():
            # Copy RGB weights to first 3 channels
            new_conv.weight[:, :3] = old_conv.weight
            # Copy RGB weights to next 3 channels (temporal diffs)
            # This provides a better starting point than random init
            if in_channels > 3:
                new_conv.weight[:, 3:6] = old_conv.weight

            if old_conv.bias is not None:
                new_conv.bias = old_conv.bias

        stem[0] = new_conv
