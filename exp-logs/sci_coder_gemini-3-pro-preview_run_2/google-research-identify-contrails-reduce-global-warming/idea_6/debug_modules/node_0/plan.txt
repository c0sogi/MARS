The following script demonstrates the end-to-end usage of the provided library components for the contrail identification task. 

It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` class to run in a lightweight "demo" mode (1 epoch, small batch size, debug subset) to ensure execution finishes quickly.
2.  **Utility Verification**: Validates the Run-Length Encoding (RLE) logic with a synthetic test case.
3.  **Dataset & Pipeline Verification**: Instantiates the `ContrailDataset`, applies transforms, and verifies input tensor shapes and data types.
4.  **Model & Loss Verification**: Instantiates the `StripPoolingResNet18UNet`, performs a forward pass with dummy data, and calculates loss using `HybridLoss` to ensure the computation graph is valid.
5.  **Training Integration**: Executes the full training loop using `run_training(debug=True)`.
6.  **Inference Integration**: Executes the inference pipeline using `generate_submission(debug=True)` and verifies the output submission file format.
