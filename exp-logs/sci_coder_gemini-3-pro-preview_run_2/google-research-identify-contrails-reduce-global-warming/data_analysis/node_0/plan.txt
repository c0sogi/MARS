This script performs an Exploratory Data Analysis (EDA) on the contrail identification dataset. It analyzes the target masks to understand class imbalance, examines the satellite imagery properties (dimensions, channel statistics), and investigates relationships between metadata (timestamps, geolocation) and contrail prevalence.

**Strategy:**
1.  **Setup & Sampling**: Load the generated `train_metadata.csv`. To ensure the analysis runs within the time limit while remaining statistically significant, we perform detailed image/mask analysis on a random sample of 500 records.
2.  **Target Analysis**: Load `human_pixel_masks.npy` for the sample. Calculate the global Dice coefficient baseline (class balance), the distribution of contrail coverage per image, and check for empty masks.
3.  **Image Analysis**: Load the spectral bands (`band_{08-16}.npy`). Verify image dimensions ($H \times W$) and temporal depth ($T$). Calculate global mean and standard deviation for each spectral band to inform normalization strategies.
4.  **Meta-Feature Analysis**: Extract temporal features (Hour, Month) from the `timestamp`. Compute correlations between these metadata features, geospatial coordinates, and the calculated "contrail coverage" to identify potential biases or signals (e.g., are contrails more common at certain times or locations?).
5.  **Reporting**: Output the results in a structured, text-based format.
