The following Python script demonstrates the usage of the provided library files to train a model and generate a submission. It performs the following steps:

1.  **Configuration**: Overrides default settings in `Config` to create a fast "demo" run (1 epoch, small batch size, debug mode with subset of data).
2.  **Verification**:
    *   **Utilities**: Validates the Run-Length Encoding (RLE) logic with a known matrix.
    *   **Dataset**: Loads a sample from the training set and asserts correct tensor shapes.
    *   **Model**: Performs a forward pass with dummy data to verify architecture and output dimensions.
    *   **Loss**: Computes the hybrid loss to ensure numerical stability.
3.  **Training**: Runs a complete training loop for 1 epoch using the `train_model` engine, saving the best model checkpoint.
4.  **Inference**: Uses the `run_inference` function to generate predictions on the test set using the saved checkpoint and verifies the output submission file format.
