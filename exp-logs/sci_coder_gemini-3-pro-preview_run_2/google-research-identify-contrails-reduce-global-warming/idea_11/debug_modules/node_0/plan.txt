The following is an implementation strategy and the complete Python script to verify the provided library components.

### Implementation Strategy

1.  **Configuration Setup**: Override the default `Config` parameters to create a lightweight execution environment. This includes setting `DEBUG=True` with a small sample size (12 samples), reducing `EPOCHS` to 1, and setting `BATCH_SIZE` to 4. This ensures the script runs quickly while still exercising all code paths.
2.  **Data Loading Verification**: Instantiate the `ContrailDataset` for training and validation splits. Verify that the data loader yields tensors of the correct shape `(Batch, Channels, Height, Width)` and that pixel values are correctly normalized to the `[0, 1]` range.
3.  **Model Initialization & Forward Pass**: Initialize the `ConvNeXtUNet` model and move it to the appropriate device. Perform a forward pass with a dummy batch to confirm the output shape matches `(Batch, 1, Height, Width)` and that no NaNs are produced.
4.  **Loss Function Check**: Compute the `HybridLoss` on the dummy output and target to ensure the loss calculation is valid and returns a non-negative scalar.
5.  **Training Loop Execution**: Execute the `train_model` function for a single epoch using the small dataset subset. This verifies the integration of the optimizer, scheduler, and training logic.
6.  **Inference & Submission Generation**: Run the `predict_and_submit` function on the test set (debug subset) to generate a submission CSV. Validate the CSV format and the logic of the Run-Length Encoding (RLE) utility using a synthetic mask.
