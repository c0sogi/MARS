The implementation strategy involves the following steps:

1.  **Configuration & Setup**: Initialize the environment by setting random seeds for reproducibility. Override default configuration parameters (specifically reducing `EPOCHS` to 5) to ensure the script executes within the "fast baseline" time constraints while still learning effectively on the A100 GPU.

2.  **Data Loading**: Instantiate the `ContrailDataset` for training, validation, and testing. Create PyTorch `DataLoader` objects. The training loader will use shuffling, while validation and test loaders will be sequential to facilitate metric tracking and submission generation.

3.  **Model Initialization**: Initialize the `ConvNeXtUNet` architecture, the `HybridLoss` function (combining BCE and Dice loss), and the optimizer (AdamW) with a Cosine Annealing scheduler. Move the model to the GPU.

4.  **Training Loop**: Execute the training process using the provided `engine.train_model` function. This handles the epoch loop, gradient updates, and model checkpointing based on validation performance.

5.  **Validation & Failure Analysis**:
    *   Load the best saved model state.
    *   Calculate the **Final Validation Metric** (Global Dice) on the full validation set.
    *   Perform failure analysis by iterating through the validation set (without shuffling) to compute per-sample Dice scores.
    *   Correlate these scores with metadata features (time of day, spatial coordinates) to identify error patterns.

6.  **Submission**: Compare the final validation metric against the required threshold (0.5676456935477064). If the model performs sufficiently well, generate the submission file using Test-Time Augmentation (TTA) and Run-Length Encoding (RLE) via `engine.predict_and_submit`.
