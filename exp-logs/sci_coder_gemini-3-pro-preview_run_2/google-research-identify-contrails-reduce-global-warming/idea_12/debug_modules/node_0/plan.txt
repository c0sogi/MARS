This script demonstrates the complete pipeline for the contrail identification task using the provided library files. It performs the following steps:

1.  **Configuration Override**: Modifies the `Config` class at runtime to use a small subset of data and fewer epochs, ensuring the demo completes quickly.
2.  **Data Verification**: Instantiates the `ContrailDataset` and `DataLoader`, verifying input shapes (6 channels) and normalization (values between 0 and 1).
3.  **Model Verification**: Initializes the `ConvNeXtUNet`, performs a forward pass with a batch of data, and asserts that output dimensions match the ground truth.
4.  **Loss & Optimization Verification**: Computes the `HybridLoss` and executes a single training step to confirm that gradients are propagated and model weights are updated.
5.  **Validation Verification**: Runs the validation function to ensure the Dice metric is calculated correctly.
6.  **Full Pipeline Execution**: Runs the `train_loop` (training the model on the subset) and `make_predictions` (generating a submission file), verifying the final output format.
