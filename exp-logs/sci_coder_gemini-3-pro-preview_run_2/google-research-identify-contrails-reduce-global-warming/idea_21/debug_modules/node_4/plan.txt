The `ConvNeXtBlock` implementation permutes the feature map to a channels-last format `(N, H, W, C)` before applying normalization, but the `LayerNorm` module is initialized with its default `data_format="channels_first"`. This causes the normalization layer to incorrectly attempt to broadcast channel-wise weights against the spatial height dimension, resulting in a shape mismatch (256 vs 16). To resolve this, I will update the `LayerNorm` initialization in `ConvNeXtBlock` to explicitly set `data_format="channels_last"`, matching the tensor layout at that point in the forward pass.
