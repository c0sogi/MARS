The issue is located in `library/dataset.py` within the `__getitem__` method. The `self.transform` pipeline uses `ToTensorV2`, which converts the input NumPy arrays (image and mask) into PyTorch tensors (Cite debug_lesson_1). However, the code subsequently attempts to wrap the `mask` variable—which is already a tensor—in `torch.from_numpy()` before permuting its dimensions to match the Channel-First format (Cite debug_lesson_6). This redundant conversion triggers a `TypeError`. The fix is to remove `torch.from_numpy()` and directly call `.permute()` on the existing tensor.
