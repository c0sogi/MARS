The following script demonstrates the end-to-end pipeline for the Contrail Identification task using the provided library files.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` object in debug mode. This reduces the dataset size (500 samples) and epochs (2) to ensure the script completes quickly. We also disable pretrained weights to avoid potential network dependencies during execution.
2.  **Component Verification**:
    *   **Utils**: Verify the Run-Length Encoding (RLE) logic with a known binary mask.
    *   **Dataset**: Instantiate the `DataLoader` and fetch a single batch to verify input tensor shapes (Batch x 6 Channels x H x W) and mask shapes.
    *   **Model**: Initialize the `MacroContextUNet`. Perform a forward pass in both training mode (checking deep supervision outputs) and evaluation mode (checking single output).
    *   **Loss**: Verify the `DeepSupervisionLoss` computes a valid scalar gradient.
    *   **Metrics**: specific unit test for `GlobalDiceMetric` using manual tensors to confirm calculation accuracy.
3.  **Training Loop**: Initialize the `Trainer` and execute `fit()`. This runs the training and validation loops, saving the best model checkpoint.
4.  **Inference**: Run the `predict_and_submit` function to generate predictions on the test set using the trained model.
5.  **Output Validation**: Assert that the model checkpoint and submission CSV are created correctly.
