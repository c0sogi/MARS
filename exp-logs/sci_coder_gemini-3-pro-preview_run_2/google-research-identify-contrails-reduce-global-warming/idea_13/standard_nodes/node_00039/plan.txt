Implementation strategy:
1.  **Configuration**: Initialize the `Config` class with `debug=False` to use the full dataset, but limit `epochs` to 8 to ensures the training completes well within the 2-hour limit while providing sufficient convergence to meet the metric threshold. Set a batch size of 32 for stability.
2.  **Training**: Instantiate the `Trainer` class and execute the `fit()` method. This handles the training loop, validation at each epoch, and saving the best model checkpoint based on the Dice score.
3.  **Validation & Metrics**:
    *   Reload the best model weights.
    *   Iterate through the validation dataloader in inference mode (no gradients) to compute the **Global Dice** score across the entire validation set.
    *   Print the result strictly as `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   During the validation pass, calculate the Dice score for each individual sample.
    *   Load the validation metadata and merge it with the per-sample error rates (defined as $1 - Dice$).
    *   Calculate and print the Pearson correlation between the error rate and input features (Timestamp, Hour, Latitude/Row, Longitude/Col) to identify systematic failure modes.
5.  **Submission**:
    *   Compare the final validation metric against the required threshold (`0.5910660985501295`).
    *   If the threshold is met, invoke the `predict_and_submit` function from `library.inference` to generate predictions on the test set and save `submission.csv`.
