### Implementation Strategy

1.  **Training**: We utilize the provided `train_model` function from `library.train` to train the `DilatedResNetUNet`. To adhere to the "fast baseline" requirement while ensuring sufficient performance to beat the threshold, we limit the training set to 12,000 samples and run for 8 epochs. This balances runtime (well under 2 hours on an A100) with convergence.
2.  **Validation & Failure Analysis**:
    *   We reload the best saved model and iterate through the full validation dataset.
    *   We compute the **Global Dice** metric as required.
    *   For failure analysis, we calculate the sample-level Dice loss ($1 - Dice$) for each image. We then merge these errors with the validation metadata (timestamp, geospatial coordinates) and compute Pearson correlations to identify if errors are temporally or spatially biased.
3.  **Inference with TTA**:
    *   If the validation score exceeds the threshold ($0.5676456935477064$), we proceed to inference on the test set.
    *   We implement **Test-Time Augmentation (TTA)**: averaging predictions from the original image, horizontal flip, vertical flip, and 180-degree rotation. This improves robustness for the thin linear features.
    *   Predictions are thresholded at 0.5, Run-Length Encoded (RLE), and saved to `submission.csv`.
