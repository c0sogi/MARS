The implementation strategy involves the following steps:

1.  **Configuration Override**: Adjust `Config.EPOCHS` to 10 to ensure the training completes within the 2-hour limit while utilizing the full dataset as specified in the strategy.
2.  **Training**: Execute the `train_model` function from `library.train`. This handles the training loop, validation at each epoch, and saves the best model based on the Dice coefficient.
3.  **Validation & Failure Analysis**:
    *   Load the best saved model state.
    *   Iterate through the validation dataset to collect predictions, ground truth masks, and record IDs.
    *   Compute the **Final Validation Metric** (Global Dice) on the full validation set.
    *   Calculate per-sample error (defined as `1 - per_image_dice`).
    *   Merge per-sample errors with metadata (timestamp, spatial coordinates) using `record_id`.
    *   Compute and print Pearson correlations between the error magnitude and metadata features (`hour`, `row_min`, `col_min`) to identify systematic failure modes.
4.  **Submission**:
    *   Compare the Final Validation Metric against the required threshold (`0.5454606988733747`).
    *   If the threshold is met, call the `inference` function from `library.train` to generate predictions for the test set and save the `submission.csv` file.
