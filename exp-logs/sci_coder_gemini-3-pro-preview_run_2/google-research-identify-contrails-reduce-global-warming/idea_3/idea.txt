Based on the accumulated lessons, I propose the **Multi-Task Attention U-Net with Classification Gating**.

This strategy introduces a structural innovation by converting the single-task segmentation network into a **Multi-Task Learning (MTL) framework**. It addresses the critical bottleneck identified in **Lesson 2** (the need to reject False Positives in a sparse dataset) by explicitly training the model to classify image-level presence alongside pixel-level location. Additionally, it integrates lightweight attention mechanisms to refine the feature selection process without the computational cost of deeper backbones.

### Model
The architecture is a **Multi-Task U-Net** built upon a **ResNet18** encoder.

*   **Backbone (Encoder):** We retain the **ResNet18** encoder. As shown in **Lesson 5**, deeper backbones like ResNet34 do not improve performance for simple geometric features and only increase training time. ResNet18 provides sufficient capacity for the background distribution.
*   **Input Head:** The model accepts the **6-channel input tensor** (Ash Composite + Temporal Difference) established as optimal in **Lesson 1** and **Lesson 6**.
*   **Structural Innovation 1: Classification Head:** A classification branch is attached to the encoder's bottleneck (the final 512-channel feature map). This head consists of Global Average Pooling followed by a Fully Connected layer and a Sigmoid activation. It predicts a binary scalar: *Does this image contain a contrail?* This forces the encoder to learn global discriminative features, helping to suppress false positives on images with only cirrus clouds.
*   **Structural Innovation 2: SCSE Attention Decoder:** The decoder utilizes **Bilinear Upsampling** followed by Convolution (Cite **Lesson 8**). Uniquely, we insert **SCSE (Spatial and Channel Squeeze & Excitation)** modules after every concatenation step in the decoder. SCSE blocks re-weight the feature maps spatially and channel-wise, allowing the model to suppress noise from the skip connections and focus on the sparse contrail activations. This improves feature fidelity without the artifacts of Transposed Convolutions.

### Data
*   **Input Engineering:** We generate the **6-channel input**: Channels 1-3 are the Ash Composite of the labeled frame ($t=4$), and Channels 4-6 are the difference between the labeled frame and the previous frame ($t=4 - t=3$). We explicitly reject symmetric future differencing ($t+1$) as it adds redundancy without gain (Cite **Lesson 6**).
*   **Dataset:** We utilize the **full training dataset** (18,673 images) to ensure the model learns the full diversity of background noise (Cite **Lesson 2**).
*   **Augmentation:** We employ a strict **Affine Transformation** pipeline (Horizontal/Vertical Flip, Shift, Scale, Rotate). We explicitly **exclude** elastic, grid, or optical distortions, as these warp the linear morphology of contrails into curve-like shapes that resemble natural clouds, creating adversarial noise (Cite **Lesson 4**).

### Training
*   **Loss Function:** We minimize a joint Multi-Task Loss: $L_{total} = L_{seg} + \lambda L_{cls}$.
    *   $L_{seg}$: Combination of **Dice Loss** and **BCE** for the segmentation mask.
    *   $L_{cls}$: **Binary Cross Entropy** for the image-level classification head.
    *   This joint optimization ensures the encoder features are robust for both detection and segmentation.
*   **Optimization:** We use the **AdamW** optimizer with a Cosine Annealing scheduler.
*   **Training Horizon:** We train for a minimum of **20 epochs**. As noted in **Lesson 7**, reducing the training duration prevents the model from converging on the fine details required for sparse segmentation.

### Evaluation
*   **Gated Inference:**
    1.  The model predicts both a pixel-wise **Probability Mask** and an image-level **Classification Score**.
    2.  We apply a **Classification Gate**: If the Classification Score is below a strict threshold (e.g., 0.5), the entire mask is set to zero (empty prediction).
    3.  If the score is above the threshold, we apply the standard pixel-level threshold (0.5) to the Probability Mask.
*   **Rationale:** This gating mechanism directly leverages the Multi-Task architecture to filter out "hard negative" images (e.g., complex cirrus formations) that often confuse the segmentation head, thereby improving the Global Dice score by reducing the denominator $|X|$ (predicted pixels) in false positive cases.
