The `AttributeError` occurs because `Config.IN_CHANNELS` is referenced in the default arguments of the `ContextEnhancedUNet.__init__` method in `library/model.py`, but this attribute is missing from the `Config` class in `library/config.py`. In Python, default arguments are evaluated at import time, causing the script to crash immediately upon importing the model module (Cite debug_lesson_9).

To fix this, I will:
1.  Update `library/config.py` to explicitly define `IN_CHANNELS = 6` (sum of the two streams defined in the config).
2.  Update `library/model.py` to set the default value of `in_chans` to `None` and resolve it to `Config.IN_CHANNELS` inside the `__init__` method. This defers the attribute access until runtime, preventing import-time errors and following the best practice described in the debug lesson (Cite debug_lesson_9).
