Based on the comprehensive analysis of the accumulated lessons, I propose the **Input-Injected Large-Kernel ConvNeXt U-Net**.

This strategy introduces a structural innovation called **Multi-Scale Input Injection**. It addresses the persistent risk of "signal washout" in deep networks—where the faint, sparse thermal signature of a contrail is lost during the heavy encoding process—by re-introducing the raw physical data directly into the decoder's reconstruction path. This synthesizes the "Linearity Prior" of ConvNeXt (Cite `solution_lesson_node_00036`) with the "Physics-Informed" philosophy (Cite `solution_lesson_node_00001`), ensuring that the fine-grained reconstruction is constantly grounded in the local spectral and temporal evidence.

### Model
The architecture is a **U-Net** variant that maximizes receptive field size while maintaining direct access to raw signal at all scales.

*   **Backbone (Encoder):** We utilize **ConvNeXt-Tiny** (initialized with ImageNet weights).
    *   **Retention:** We retain the **7x7 Depthwise Convolutions**. As established, this large isotropic receptive field enforces a strong linearity prior, which is superior for contrail segmentation compared to standard 3x3 CNNs (Cite `solution_lesson_node_00036`) or dilated backbones (Cite `solution_lesson_node_00033`).
*   **Context Bridge:** We retain the **Atrous Spatial Pyramid Pooling (ASPP)** module at the bottleneck to capture global multi-scale context (Cite `solution_lesson_node_00021`).
*   **Decoder (Sequential Refinement):**
    *   We employ a standard sequential upsampling path (Stride 32 $\to$ 16 $\to$ 8 $\to$ 4 $\to$ 2 $\to$ 1). We explicitly reject "Pyramid Fusion" (Cite `solution_lesson_node_00046`) and interpolation shortcuts (Cite `solution_lesson_node_00039`), ensuring learned upsampling reaches the pixel level.
    *   **Blocks:** We use **ConvNeXt Blocks (7x7)** in the decoder to preserve the linearity of features during reconstruction (Cite `solution_lesson_node_00036`).
    *   **Upsampling:** We use **Bilinear Upsampling** followed by convolutions (Cite `solution_lesson_node_00008`).
*   **Structural Innovation: Multi-Scale Input Injection:**
    *   We create a localized image pyramid from the 6-channel input tensor using Average Pooling to match the resolution of each decoder stage (Stride 16, 8, 4, 2, 1).
    *   At each decoder stage, before the convolutional block, we **concatenate** the corresponding downsampled input tensor with the incoming feature map (from the skip connection and upsampling).
    *   **Rationale:** This provides the decoder with a "residual connection to the physics." Even if the encoder abstracts the features into high-level semantics, the decoder can verify its reconstruction against the raw local thermal gradients (Ash + Diff) at the exact scale it is processing. This is distinct from Deep Supervision (which constrains output) as it provides *information* without forcing *representation*.
*   **Attention:** We retain **SCSE (Spatial and Channel Squeeze & Excitation)** blocks after the injection and concatenation steps to adaptively weigh the fused features (Cite `solution_lesson_node_00021`).

### Data
*   **Input Engineering (Decoupled Features):** We generate a **6-channel input tensor** that stacks spectral and temporal data (Early Fusion) (Cite `solution_lesson_node_00047`).
    *   **Channels 1-3:** "Ash" False Color Composite of the labeled frame ($t=4$). This encodes static physical properties.
    *   **Channels 4-6:** **Raw Band Differences** ($t=4$ minus $t=3$) for Bands 11, 14, and 15. We explicitly use raw values to preserve the dynamic range of the cooling signal, avoiding the information loss caused by differencing processed composites (Cite `solution_lesson_node_00045`).
*   **Augmentation:** We employ a strict **Affine Transformation** pipeline (Rotation, Scale, Shift, Flip). We explicitly **exclude** elastic, grid, or optical distortions, as these warp the linear morphology of contrails into curve-like shapes that resemble natural clouds (Cite `solution_lesson_node_00004`).
*   **Dataset:** We train on the **full dataset** (18,673 images) to ensure the model learns to suppress the "long tail" of background clutter (Cite `solution_lesson_node_00002`).

### Training
*   **Loss Function:** We employ a **Hybrid Loss**: $L_{total} = L_{BCE} + L_{BatchDice}$.
    *   **Binary Cross Entropy (BCE):** Included to provide smooth, convex gradients for pixel-level classification.
    *   **Batch-Level Dice:** We compute the Dice score over the **entire flattened batch** (treating the batch as a single volume). This stabilizes gradients and aligns with the global metric, avoiding the instability of sample-level averaging (Cite `solution_lesson_node_00014`) and the degradation caused by pure Dice loss (Cite `solution_lesson_node_00018`).
*   **Optimization:** We use **AdamW** with a Cosine Annealing scheduler.
*   **Batch Size:** We utilize a **Batch Size of 32**. This is critical to ensure the statistical stability of the Batch Dice loss (Cite `solution_lesson_node_00043`).
*   **Duration:** We train for **30 epochs**. We explicitly avoid shortening the training horizon to prevent underfitting on fine-grained details (Cite `solution_lesson_node_00007`).

### Evaluation
*   **Inference Strategy:** We implement **Test-Time Augmentation (TTA)**.
    *   For each test image, we generate predictions for the original, horizontally flipped, vertically flipped, and 180-degree rotated versions.
    *   The four probability maps are averaged before thresholding. This ensemble-like approach smooths out prediction noise and boosts the Global Dice score (Cite `solution_lesson_node_00024`).
*   **Post-Processing:** We apply a standard pixel-level threshold of **0.5**. We explicitly reject "Hard Gating" mechanisms (Cite `solution_lesson_node_00009`).
