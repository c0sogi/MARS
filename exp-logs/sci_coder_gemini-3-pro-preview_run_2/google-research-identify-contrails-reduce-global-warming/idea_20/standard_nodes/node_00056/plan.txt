The implementation strategy is as follows:

1.  **Setup**: Initialize the environment and random seeds using the provided `library.utils` to ensure reproducibility.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. We set `epochs=5` to ensure the "fast baseline" requirement is met and the process completes well within the 2-hour limit on the available hardware. The library function handles model saving.
3.  **Validation & Failure Analysis**:
    *   Load the best saved model and the validation dataset.
    *   Run a dedicated inference pass on the validation set to calculate the **Global Dice** metric (required for the submission condition) and **per-sample Dice scores** (required for failure analysis).
    *   Print the `Final Validation Metric` in the specified format.
    *   Correlate the per-sample error (defined as `1 - Dice`) with metadata features (`timestamp`, `row_min`, `col_min`) to identify systematic failure modes.
4.  **Submission**:
    *   Check if the `Final Validation Metric` exceeds the threshold `0.5910660985501295`.
    *   If the condition is met, call `library.inference.make_submission` to generate predictions for the test set and save the `submission.csv` file.
