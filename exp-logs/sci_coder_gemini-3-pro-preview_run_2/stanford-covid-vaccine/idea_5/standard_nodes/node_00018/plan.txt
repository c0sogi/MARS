This script orchestrates the RNA degradation prediction pipeline. It first overrides configuration parameters to ensure a fast execution suitable for a baseline. It then executes the training process using the provided library functions. After training, it evaluates the model on the validation set to compute the specific MCRMSE metric required. It performs a failure analysis by correlating prediction errors with input features like signal-to-noise ratio and sequence composition. Finally, if the validation performance meets the specified threshold, it generates a submission file for the test set.
