3.  **Model Initialization & Forward Pass**: Instantiate the `RCRDN` model from `library.model`. Create a dummy batch from the loaded data and perform a forward pass. Verify that the model returns a list of predictions (due to the recycling mechanism) and that the shapes align with the sequence length and target dimensions.
4.  **Loss Function Verification**: Initialize `MCRMSELoss` from `library.loss` and compute the loss using the model's output and the ground truth. Assert that the loss is a valid non-negative scalar.
5.  **Full Pipeline Execution**: Execute the `run_training` function from `library.train`. This will run a short training loop (2 epochs) and generate a submission file using the best saved model.
6.  **Submission Validation**: After the pipeline completes, load the generated `submission.csv` to verify it follows the correct format (columns and row count) corresponding to the test set size.
