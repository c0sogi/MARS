Here is the implementation strategy for the `runfile.py` script:

1.  **Environment Setup**: Import necessary standard libraries (`os`, `sys`, `pandas`, `numpy`, `torch`) and the provided project modules (`library.config`, `library.utils`, `library.data`, `library.model`, `library.train`). Ensure the random seed is fixed and the computation device (GPU/CPU) is correctly selected.
2.  **Configuration**: Override the default epoch count in `Config` to 15 to ensure the baseline runs quickly while still learning effectively.
3.  **Data Loading**: Initialize data loaders using `get_loaders(load_cached_data=True)` to leverage preprocessed data for speed.
4.  **Model Initialization**: Instantiate the `GCDARN` model, move it to the device, and set up the `AdamW` optimizer and `MCRMSELoss` criterion.
5.  **Training Loop**: Iterate through the epochs. In each epoch, perform a training pass using `train_epoch`, evaluate on the validation set using `validate`, and update the learning rate scheduler. Save the model state whenever the validation score improves.
6.  **Final Evaluation**: Load the best saved model checkpoint. Compute the final validation metric on the entire validation set and print it in the specific format required (`Final Validation Metric: <value>`).
7.  **Failure Analysis**: Generate predictions for the validation set to calculate per-sample errors. Merge these errors with the validation metadata (loaded from `val.csv`) to calculate and print the correlation between model error and the `signal_to_noise` ratio.
8.  **Conditional Submission**: Compare the final validation metric against the threshold (0.47142532743789534). If the model performs well enough, generate predictions for the test set using `predict` and save them to `submission.csv` using `format_submission`.
