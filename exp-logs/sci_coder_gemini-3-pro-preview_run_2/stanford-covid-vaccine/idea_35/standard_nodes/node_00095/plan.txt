6.  **Failure Analysis**: Compute sample-wise RMSE on the validation set. Load the validation metadata CSV, merge it with the error metrics, and calculate Pearson correlations between the error and features like Signal-to-Noise ratio, Mean Reactivity, and base counts. Print these correlations to identify error sources.
7.  **Submission**: Check if the final validation metric is strictly less than the provided threshold (0.5403054356575012). If satisfied, generate predictions on the test set using `generate_submission` and save to the submission path.
