The following script demonstrates the usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Configuration Setup**: Overrides default `Config` paths and parameters to use a temporary directory and run a lightweight demonstration (small batch size, few epochs).
2.  **Data Loading**: Uses `get_loaders` to load and process the metadata. It verifies the integrity of the data batches (shapes, types).
3.  **Model Initialization & Inference**: Instantiates the `ML_GFN` model, performs a forward pass, and verifies output shapes.
4.  **Loss Function Verification**: Validates the `MaskedMCRMSELoss` by checking that it correctly ignores unscored columns and computes zero loss for perfect predictions.
5.  **Training Loop Simulation**: Runs a minimal training loop (1 epoch, limited batches) using `train_one_epoch` to demonstrate the optimization process.
6.  **Validation & Metric Check**: Uses the `validate` function and `MCRMSE_Metric` to evaluate the model.
7.  **Submission Generation**: Simulates the submission creation process.
