Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Cascaded Latent-Refined Dense Network**. This strategy structurally evolves the "Staged" concept by explicitly optimizing for **Base-Pair Stacking Thermodynamics** via a dilation-reset mechanism, while strictly adhering to the capacity and regularization constraints identified in recent failures.

# Model

The architecture is a **Two-Stage Dense Hybrid** designed to learn local sequence motifs first, then explicitly model the interactions between paired bases (stacking) using learned features.

1.  **Input Representation (Parsimonious One-Hot):**
    *   We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   We strictly **exclude** static "Partner Base Identity" or "Partner Triplets" from the input. As established in **Lesson 00031** and **Lesson 00023**, dynamic gathering of learned features is superior to static injection, and high-dimensional sparse inputs degrade optimization.

2.  **Stage 1 Backbone (Local Motif Extraction):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** (Cite solution_lesson_node_00011) with **Dense Connections** (concatenating outputs of all prior blocks).
    *   **Configuration:** We employ exponentially increasing dilation rates ($d=1, 2, \dots, 32$) to capture global sequence context (Cite solution_lesson_node_00002).
    *   **Capacity:** We strictly set the **Growth Rate / Channel Width** to at least **64**. This addresses the bottleneck failure observed in **Lesson 00037**, ensuring the model has sufficient vocabulary to encode diverse chemical motifs.
    *   **Regularization:** We apply **Dropout (0.1)** within every block. This is mandatory to prevent the overfitting observed in **Lesson 00038** when using dense connectivity.

3.  **Inter-Stage Latent Refinement (The Stacking Interaction):**
    *   **Compression:** The output of Stage 1 is compressed via a 1x1 convolution to a compact dimension (e.g., 64).
    *   **Dynamic Gather:** For every position $i$, we gather the compressed feature vector of its paired partner $j$ (using the structure map) and concatenate it to the feature vector of $i$. This creates a **"Pair-State" Representation** (Cite solution_lesson_node_00031).

4.  **Stage 2 Backbone (Stacking-Aware Processing):**
    *   **Input:** The fused $[Feature_i, Feature_{partner}]$ vector.
    *   **Structural Innovation (Dilation Reset):** We process this fused representation with a second stack of Dense Dilated Blocks. Crucially, we **reset the dilation schedule** starting from $d=1, 2, 4 \dots$.
    *   **Rationale:** The physical stability of RNA is largely determined by **stacking interactions** (the energy between base pair $i-j$ and base pair $(i+1)-(j-1)$). By resetting dilation to 1, the first layers of Stage 2 explicitly convolve over adjacent **pairs**, allowing the model to learn these stacking energies from the "Pair-State" features constructed in the previous step. This solves the physics targeted by "Partner Triplets" (Idea 6) using robust learned features instead of sparse inputs.

5.  **Global Aggregation (BiGRU):**
    *   The Stage 2 output is processed by a **Bidirectional GRU** to capture global constraints (Cite solution_lesson_node_00003).
    *   **Constraint:** Hidden size is set to `input_dim // 2` (Cite solution_lesson_node_00004).

6.  **Output Head:**
    *   Linear projection to the 5 target variables.

# Training

1.  **Loss Function (Masked Optimization):**
    *   Use **MCRMSE** (Mean Columnwise Root Mean Squared Error).
    *   **Strategy:** Calculate loss **only on the three scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
    *   **Rationale:** We strictly adhere to **Lesson 00016**, masking out auxiliary targets to prevent negative transfer and align the objective with the competition metric.

2.  **Optimizer:**
    *   Use **AdamW** with a learning rate of 1e-3 and a `ReduceLROnPlateau` scheduler.
    *   Use **Standard Convolutions** throughout (Cite solution_lesson_node_00018).
