The following script demonstrates the usage of the provided library files for the RNA degradation prediction task.

### Strategy
1.  **Configuration Override**: The script first modifies the `Config` class to use a temporary working directory and reduces hyperparameters (epochs, batch size, dataset size) to ensure the demonstration runs in under a minute.
2.  **Data Logic Verification**: It validates the helper functions `get_structure_pairs` and `get_one_hot_encoding` using assertions to ensure input features are generated correctly.
3.  **Pipeline Execution**:
    *   **Data Loading**: Initializes data loaders in debug mode and checks batch tensor shapes.
    *   **Model Inference**: Instantiates `CascadedDenseNet` and performs a forward pass to verify output dimensions.
    *   **Loss Calculation**: Tests `MCRMSELoss` with synthetic data to confirm it correctly masks unscored columns.
    *   **Training**: Runs a full training cycle for 1 epoch using `train_model`.
    *   **Submission**: Generates a submission file using `generate_submission` and validates the output CSV format.
