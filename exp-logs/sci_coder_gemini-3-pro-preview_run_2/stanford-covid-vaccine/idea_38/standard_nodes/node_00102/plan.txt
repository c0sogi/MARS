Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Environment & Configuration**: Initialize the environment by setting random seeds and detecting the computation device (GPU/CPU). We utilize the provided `Config` class but ensure the `EPOCHS` are set to a reasonable number (25) to fit within the "fast baseline" requirement while ensuring convergence.
2.  **Training Orchestration**: We call the provided `run_training()` function from `library.train`. This handles the data loading (with caching), model initialization, the iterative refinement training loop (Pass 1 & Pass 2), validation monitoring, and saving the best model checkpoint.
3.  **Validation & Metric Calculation**:
    *   After training, we load the best saved model state.
    *   We run a dedicated inference pass on the validation set to retrieve raw predictions. Crucially, we strictly follow the inference logic: compute backbone features $\to$ Pass 1 (zero feedback) $\to$ Pass 2 (feedback from Pass 1).
    *   We compute the **MCRMSE** metric on the scored columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) using the full validation set and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   We calculate the sample-wise Mean Squared Error (MSE) on the validation predictions.
    *   We load the validation metadata (`val.csv`) to retrieve the `signal_to_noise` ratio.
    *   We compute and print the Pearson correlation between the model's error and `signal_to_noise` to identify if noisy samples correlate with higher errors.
5.  **Submission Generation**:
    *   We check if the validation metric is below the threshold `0.47142532743789534`.
    *   If passed, we load the test data (using `process_data` with caching) and run inference (Backbone $\to$ Pass 1 $\to$ Pass 2).
    *   We format the output into the required CSV format. This involves flattening the `(N, 107, 5)` prediction tensor into a long-format DataFrame where each row corresponds to `id_{seqpos}`.
    *   The result is saved to `submission.csv`.
