Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Dense-Feedback Dense-Context Network (DF-DCN)**.

This strategy evolves the state-of-the-art "Contextualized-Feedback" architecture (Idea 36) by structurally upgrading the recycling mechanism. It synthesizes the success of **Dense Connectivity** (Lesson 00047) with the power of **Iterative Refinement** (Lesson 00090, 00097). By replacing the simple residual feedback encoder with a **Dense Dilated Feedback Backbone**, we allow the model to construct a richer, multi-scale representation of the "stability landscape" from previous predictions, while strictly adhering to the "Static Backbone" efficiency and "Micro-Architecture" robustness constraints.

# Model

1.  **Input Representation (Static & Partner-Aware):**
    *   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
    *   **Static Input:** The main input tensor is static; we do not augment it with recycling channels to avoid re-running the heavy main backbone (Cite solution_lesson_node_00090).

2.  **Main Backbone (Static Dense Dilated TCN):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** (Cite solution_lesson_node_00011) utilizing **Dense Connections** (concatenating outputs of all prior blocks). This preserves the full multi-scale history (Cite solution_lesson_node_00047).
    *   **Micro-Architecture:** Each block uses `LayerNorm -> ReLU -> Conv1d -> Dropout(0.1)` with a residual connection (Cite solution_lesson_node_00101).
    *   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
    *   **Capacity:** Growth Rate **64** (Cite solution_lesson_node_00037).
    *   **Execution:** Runs **once** per batch to produce dense feature tensor $H_{dense}$.
    *   **Projection:** $H_{dense}$ is projected to **Latent Dim 64** ($Z$) via Linear 1x1 Conv (Cite solution_lesson_node_00062, solution_lesson_node_00076).

3.  **Dense Feedback Backbone (Structural Innovation):**
    *   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
    *   **Masking:** Zero out unscored targets (`deg_pH10`, `deg_50C`) to prevent unsupervised noise injection (Cite solution_lesson_node_00016).
    *   **Architecture:** A dedicated **Dense Dilated TCN** for the feedback stream.
        *   *Rationale:* Idea 36 used a simple residual stack. **Lesson 00047** proved that Dense connectivity significantly outperforms Residual connectivity for this data. We apply this insight to the feedback encoder to generate high-quality, multi-scale "Error Embeddings".
    *   **Configuration:** 4-6 layers, Dilation $1, 2, 4, \dots$, Growth Rate **32** (lighter than main backbone).
    *   **Output:** Feedback Embeddings $E_{fb}$ (projected to 32 channels).

4.  **Interaction & Fusion:**
    *   **Augmented Gather:** For every position $i$ paired with $j$:
        *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
        *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
    *   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
    *   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066, solution_lesson_node_00073).

5.  **Global Aggregation (BiGRU):**
    *   The fused features are processed by a **Bidirectional GRU** (Cite solution_lesson_node_00003).
    *   **Constraint:** Hidden size is set to `input_dim // 2` (Cite solution_lesson_node_00004).
    *   **Output:** Linear projection to targets.

# Data

1.  **Preprocessing & Cache Safety:**
    *   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_df_dcn_v1.npz`) to ensure input features are generated correctly (Cite solution_lesson_node_00032).
    *   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
    *   **Target Parsing:** Parse stringified targets to numerical arrays.

2.  **Loaders:**
    *   Yield Augmented Input, Partner Index Map, and Targets.

# Training

1.  **Iterative Refinement Loop:**
    *   **Step 1 (Static):** Compute $Z$ from static inputs once.
    *   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
    *   **Pass 1:**
        *   Compute $E_{fb, 0}$ from $\hat{Y}_0$ using **Dense Feedback Backbone**.
        *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
    *   **Pass 2:**
        *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
        *   Compute $E_{fb, 1}$ from $R$ using **Dense Feedback Backbone**.
        *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

2.  **Loss Function:**
    *   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
    *   Calculate loss **only on scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) (Cite solution_lesson_node_00016).

3.  **Optimizer:**
    *   **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

# Evaluation

1.  **Inference:**
    *   Compute Backbone features $Z$ once.
    *   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
    *   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
    *   Submit $\hat{Y}_2$.

2.  **Metric:**
    *   Use **Correct Global RMSE** (Cite solution_lesson_node_00020).
