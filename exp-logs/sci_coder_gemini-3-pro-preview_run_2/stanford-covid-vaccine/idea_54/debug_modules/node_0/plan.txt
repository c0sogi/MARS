The following script demonstrates the end-to-end pipeline using the provided library files. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to run in a lightweight "debug" mode (fewer epochs, smaller dataset) for rapid execution.
2.  **Data Loading & Verification**: Uses `get_loader` to load training data and asserts that the input tensors (sequence features, partner indices) and target tensors match the expected shapes.
3.  **Model Initialization & Forward Pass**: Instantiates the `DARDN` model, performs a forward pass with a real batch, and verifies that the output shapes (for both the auxiliary and final refinement passes) are correct.
4.  **Loss Calculation**: Computes the MCRMSE loss on the dummy batch to ensure the custom loss function operates correctly on the specific scored columns.
5.  **Training**: Executes the full training loop via `train_model`, which handles backpropagation, validation, and checkpointing.
6.  **Inference & Submission**: Loads the best saved model, performs inference on the test set, and formats the predictions into the required CSV structure, verifying the final output dimensions.
