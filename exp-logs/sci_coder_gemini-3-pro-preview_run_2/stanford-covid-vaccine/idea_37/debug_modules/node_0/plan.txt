### Implementation Strategy

1.  **Environment Setup**: Import necessary standard libraries and the provided `library` modules (`config`, `utils`, `data`, `model`). Set the random seed using `utils.set_seed` for reproducibility.
2.  **Data Preparation**:
    *   To optimize for speed, create a "mini" training dataset by extracting the first 16 rows from `metadata/train.csv` and saving it to the `./working` directory.
    *   Use `data.preprocess_data` to process this mini dataset, ensuring the feature extraction logic works correctly without processing the entire dataset.
    *   Verify the shapes of the returned features and targets using assertions.
3.  **Data Loading**: Wrap the processed data in `data.RNADataset` and create a PyTorch `DataLoader`.
4.  **Model Initialization & Execution**:
    *   Instantiate the `model.SCR_DN` (Structure-Conditional Recurrent Dense Network).
    *   Perform a forward pass with a batch of data.
    *   Verify that the model output is a list (due to the recycling mechanism) and that the final prediction tensor has the correct shape `(Batch, SeqLen, Targets)`.
5.  **Training Simulation**:
    *   Define a Loss function (`MSELoss`) and an Optimizer (`Adam`).
    *   Execute a backward pass and an optimizer step to confirm gradients propagate correctly.
6.  **Metric Validation**:
    *   Calculate the MCRMSE score using `utils.mcrmse` on the batch predictions.
    *   Perform a manual check with dummy tensors to verify the metric calculation logic against a known value.
7.  **Submission Generation**:
    *   Generate dummy test IDs and use the model's predictions to create a submission file via `utils.format_submission`.
    *   Validate the generated CSV's dimensions and column structure against the competition requirements.
