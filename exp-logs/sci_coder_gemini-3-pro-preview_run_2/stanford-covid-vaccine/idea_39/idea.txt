Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Graph-Smoothed Recurrent Dense Network (GS-RDN)**.

This strategy evolves the state-of-the-art "Contextualized-Feedback" architecture (Idea 36) by structurally upgrading the recycling mechanism. While Idea 36 successfully smoothed predictions using a sequence-based TCN, it treated the feedback signal as structurally agnostic. The **GS-RDN** introduces a **Graph-Smoothed Feedback Module** that explicitly diffuses stability estimates across base pairs *within the recycling loop*. This ensures that the "hint" passed to the next iteration is not only locally smooth but also physically consistent (e.g., enforcing that paired bases share stability profiles) before it interacts with the static features.

# Model

1.  **Input Representation (Static & Partner-Aware):**
    *   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
    *   **Static Input:** The main input tensor is static; we do not augment it with recycling channels to avoid re-running the heavy main backbone (Cite solution_lesson_node_00090).

2.  **Main Backbone (Static Dense Dilated TCN):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** (Cite solution_lesson_node_00011) utilizing **Dense Connections** (concatenating outputs of all prior blocks). This preserves the full multi-scale history (Cite solution_lesson_node_00047).
    *   **Micro-Architecture:** Blocks utilize `LayerNorm -> ReLU -> Conv1d -> Dropout(0.1)` with residual connections (Cite solution_lesson_node_00101).
    *   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
    *   **Capacity:** Growth Rate **64** (Cite solution_lesson_node_00037).
    *   **Execution:** Runs **once** per batch to produce dense feature tensor $H_{dense}$.
    *   **Projection:** $H_{dense}$ is projected to **Latent Dim 64** ($Z$) via Linear 1x1 Conv (Cite solution_lesson_node_00062, solution_lesson_node_00076).

3.  **Graph-Smoothed Feedback Module (Structural Innovation):**
    *   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
    *   **Masking:** Zero out unscored targets (`deg_pH10`, `deg_50C`) to prevent unsupervised noise injection (Cite solution_lesson_node_00016).
    *   **Projection:** Linear Projection to 32 channels (Cite solution_lesson_node_00086).
    *   **Sequence Smoothing:** Process with a lightweight **Dilated TCN** (2 residual blocks) to aggregate local context (Cite solution_lesson_node_00097). Output: $H_{seq}$.
    *   **Structural Smoothing (New):** Perform a **Latent Gather** on $H_{seq}$ using the partner index map. For position $i$, retrieve $H_{seq}$ of partner $j$.
    *   **Null-Masking:** Apply **Zero-Mask** to gathered features for unpaired bases (Cite solution_lesson_node_00071).
    *   **Fusion:** Sum the local sequence feedback $H_{seq}$ and the gathered partner feedback.
        *   *Rationale:* This creates a **Graph-Smoothed Embedding** $E_{fb}$ where the stability estimate of a base is informed by both its sequence neighbors and its structural partner *independent of the static features*. This adheres to **Lesson 00100** (Late Fusion) while adding physical constraints to the feedback.

4.  **Main Interaction & Aggregation:**
    *   **Augmented Gather:** For every position $i$ paired with $j$:
        *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
        *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
    *   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
    *   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
    *   **Output:** Linear projection to targets.

# Data

1.  **Preprocessing & Cache Safety:**
    *   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_gs_rdn_v1.npz`) to ensure input features are generated correctly (Cite solution_lesson_node_00032).
    *   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
    *   **Target Parsing:** Parse stringified targets to numerical arrays.

2.  **Loaders:**
    *   Yield Augmented Input, Partner Index Map, and Targets.

# Training

1.  **Iterative Refinement Loop:**
    *   **Step 1 (Static):** Compute $Z$ from static inputs once.
    *   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
    *   **Pass 1:**
        *   Compute $E_{fb, 0}$ from $\hat{Y}_0$ using **Graph-Smoothed Feedback Module**.
        *   Run Main Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
    *   **Pass 2:**
        *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
        *   Compute $E_{fb, 1}$ from $R$ using **Graph-Smoothed Feedback Module**.
        *   Run Main Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

2.  **Loss Function:**
    *   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
    *   Calculate loss **only on scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) (Cite solution_lesson_node_00016).

3.  **Optimizer:**
    *   **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

# Evaluation

1.  **Inference:**
    *   Compute Backbone features $Z$ once.
    *   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
    *   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
    *   Submit $\hat{Y}_2$.

2.  **Metric:**
    *   Use **Correct Global RMSE** (Cite solution_lesson_node_00020).
