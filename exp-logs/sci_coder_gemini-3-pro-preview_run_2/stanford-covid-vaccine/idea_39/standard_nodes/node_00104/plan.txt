Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the `Config` class and set random seeds using `library.utils.set_seed` to ensure reproducibility.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. We will use 15 epochs and a batch size of 32 to ensure a fast but effective baseline run within the time limits.
3.  **Validation & Metric**:
    *   Load the best saved model (`best_model.pth`).
    *   Iterate through the validation dataloader to generate predictions using the two-pass inference strategy (Pass 1: Zero Feedback, Pass 2: Graph-Smoothed Feedback).
    *   Extract the scored columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
    *   Compute the MCRMSE metric on the full validation set.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the Root Mean Squared Error (RMSE) for each sample in the validation set.
    *   Load the validation metadata (`val.csv`) to access sample features.
    *   Compute and print the Pearson correlation between the sample-wise error magnitude and input features (`signal_to_noise`, `mean_reactivity`, `SN_filter`).
5.  **Submission**:
    *   Compare the final validation metric against the threshold `0.47142532743789534`.
    *   If the model performs better (lower metric), generate the submission file using `library.train.generate_submission`.
