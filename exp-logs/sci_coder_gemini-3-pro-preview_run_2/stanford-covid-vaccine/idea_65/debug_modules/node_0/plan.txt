### Implementation Strategy

1.  **Dynamic Module Patching**: The provided `library/config.py` file contains a global function call `run_pipeline()` at the end of the file. Importing this module directly would trigger a full 20-epoch training run, violating the "Optimize for Speed" requirement. To bypass this, the script manually reads the source code of `library/config.py`, removes the line calling `run_pipeline()`, and dynamically creates the module in `sys.modules`. This allows subsequent imports (like `library.data` and `library.engine`) to function correctly without triggering the unwanted execution.
2.  **Data Loading & Validation**: The script uses `library.data.get_dataloaders` to load the dataset. It asserts the correctness of the data shapes (batch size, sequence length, feature dimensions) to verify the data processing pipeline.
3.  **Model Instantiation**: It instantiates the `SSRFN` model from `library.model` and performs a dummy forward pass to verify input/output tensor compatibility and shapes.
4.  **Optimized Training Loop**: The script calls `library.engine.fit` with `epochs=1` and a custom working directory. This demonstrates the training capability while keeping execution time minimal.
5.  **Inference & Submission**: It runs `library.engine.inference` to generate predictions on the test set and validates that the output submission file is created with the correct format and dimensions.
6.  **Reproducibility**: `library.utils.seed_everything` is used to ensure consistent results.
