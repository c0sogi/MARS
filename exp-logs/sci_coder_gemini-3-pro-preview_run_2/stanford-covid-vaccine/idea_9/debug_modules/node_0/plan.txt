### Implementation Strategy

1.  **Environment Setup**: Import necessary libraries and the provided modules (`library.config`, `library.data`, `library.model`, `library.loss`, `library.utils`, `library.train`). Set random seeds for reproducibility.
2.  **Data Generation**: Create a temporary directory in `./working` and generate small, synthetic CSV files (train, val, test) mimicking the schema of the real dataset. This ensures the demonstration runs quickly and independently of the large provided datasets.
3.  **Component Verification**:
    *   **Data Processing**: Use `library.data.process_dataframe` on the synthetic data and assert that the resulting numpy arrays (inputs, partner indices, targets) have the correct shapes and data types.
    *   **Model Architecture**: Instantiate `DenseContextNet`, pass the processed synthetic inputs through it, and verify the output shape corresponds to `(Batch, Sequence_Length, Num_Targets)`.
    *   **Loss Function**: Instantiate `MaskedMCRMSELoss`. Create specific prediction and target tensors where the error is known (e.g., error only on scored columns vs unscored columns) to verify that the loss correctly masks out the unscored columns.
    *   **Metric Tracker**: Feed batches of data into `MetricTracker` and verify it correctly accumulates errors and computes the MCRMSE.
4.  **Integration Test**: Configure the global `Config` class to point to the synthetic datasets and cache files. Execute `library.train.train_model` in debug mode to verify the end-to-end training loop (loading, training, validation, saving) functions without errors.
