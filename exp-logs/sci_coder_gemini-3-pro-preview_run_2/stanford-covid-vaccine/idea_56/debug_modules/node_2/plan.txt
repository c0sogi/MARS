The issue is that the `get_dataloader` function defines its default arguments (like `debug=Config.DEBUG`) at the time the module is imported. Since `Config.DEBUG` is initially `False`, the function permanently captures this value as the default. When `runfile.py` later updates `Config.DEBUG` to `True` at runtime, the `get_dataloader` function continues to use the stale `False` value, causing it to load the full dataset instead of the debug subset.
