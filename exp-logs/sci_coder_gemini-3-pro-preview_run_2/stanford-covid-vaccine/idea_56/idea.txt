Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Hybrid-Stem Direct-Access Recurrent Network (HS-DARN)**.

This strategy synthesizes the robust "Direct-Access" architecture (Idea 54) with a novel **Hybrid Input Stem** to resolve the conflict between "Spatial Context Extraction" (Lesson 00125) and "Raw Feature Preservation" (Lesson 00128). It further optimizes the training dynamics by strictly enforcing the **Small Batch Regime** (Lesson 00129) and correcting the evaluation metric (Lesson 00131).

# Model

### 1. Input Representation (Hybrid & Partner-Aware)
*   **Features:** One-Hot Encoding for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) (Cite solution_lesson_node_00052).
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels (Cite solution_lesson_node_00090).

### 2. Hybrid Input Stem (Structural Innovation)
*   **Concept:** We split the input processing into two parallel branches before entering the backbone:
    *   **Branch A (Identity):** Passes the raw One-Hot features directly.
    *   **Branch B (Context):** Processes the One-Hot features with a **Spatial Convolution (Kernel 3)** followed by LayerNorm and SiLU (Cite solution_lesson_node_00125).
*   **Fusion:** The backbone input is the concatenation of `[Branch A, Branch B]`.
*   **Rationale:** This resolves the trade-off between Idea 53 (which lost token identity via the stem, Lesson 00128) and Idea 54 (which lacked immediate n-gram context). Branch B provides rich local texture, while Branch A guarantees the deep layers can access exact nucleotide identities.

### 3. Main Backbone (Direct-Access Dense Dilated TCN)
*   **Architecture:** A stack of **Single-Layer Dilated Blocks** utilizing **Dense Connections**.
*   **Direct Raw Access:** The input to the $k$-th block is the concatenation of the outputs of all prior blocks **AND the raw One-Hot input features (Branch A)**. This ensures deep layers maintain a "line of sight" to the discrete categorical data (Cite solution_lesson_node_00128).
*   **Micro-Architecture (Post-Activation):** `Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> LayerNorm -> SiLU -> Dropout(0.1)`. This decouples spatial/channel mixing (Cite solution_lesson_node_00111) and uses robust ops (Cite solution_lesson_node_00116, solution_lesson_node_00117).
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Latent Projection:** Output projected to **Latent Dim 64** ($Z$) (Cite solution_lesson_node_00062).

### 4. Direct-Access Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (masked to zero out unscored targets, Cite solution_lesson_node_00118).
*   **Architecture:** A **Lightweight Dense TCN** (Growth Rate 16) (Cite solution_lesson_node_00103).
*   **Topology Access:** We concatenate **Raw Topology Features** (Structure/Loop One-Hots) to the input of **every block** in the feedback encoder. This enables structure-conditional denoising throughout the feedback depth.
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 5. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
        *   *Note:* This propagates dynamic feedback through structural connections (Cite solution_lesson_node_00105).
*   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
*   **Constraint:** **Compact Hidden Size (64)** (Cite solution_lesson_node_00117).

### 2. Loaders
*   Yield Augmented Input, Partner Index Map, and Targets.

# Training

### 1. Optimization Strategy (Correction)
*   **Batch Size:** Strictly set to **16**.
    *   *Rationale:* As established in **Lesson 00129**, large batch sizes (e.g., 64) on this small dataset reduce the number of gradient updates too drastically (~27/epoch vs ~108/epoch), leading to underfitting. A small batch size is critical for convergence.
*   **Optimizer:** **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

### 2. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Masked $\hat{Y}_0$.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Masked $R$.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 3. Loss Function
*   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
*   **Strict Masking:** Calculate loss **only on scored columns** and **only on valid sequence positions** (0-67) (Cite solution_lesson_node_00016, solution_lesson_node_00109).

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$.

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root to avoid the optimistic bias of batch-averaging (Cite solution_lesson_node_00131, solution_lesson_node_00020).
