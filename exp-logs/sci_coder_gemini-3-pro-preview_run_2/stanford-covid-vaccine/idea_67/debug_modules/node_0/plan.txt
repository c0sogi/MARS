This script demonstrates the usage of the provided RNA degradation prediction library. It performs the following steps:

1.  **Component Verification**: It first instantiates the `AHS_DFN` model and the `MCRMSE` metric independently to verify their input/output shapes and calculation logic using synthetic data.
2.  **Pipeline Execution**: It executes the full training and prediction pipeline using the `train_and_predict` function. To ensure speed, it runs in `debug` mode (using a subset of 100 samples) and for only 2 epochs.
3.  **Output Validation**: Finally, it verifies that the submission file is generated correctly and contains the expected number of rows for the debug subset.
