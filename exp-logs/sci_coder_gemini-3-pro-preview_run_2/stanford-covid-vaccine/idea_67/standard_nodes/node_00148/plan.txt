Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by importing necessary libraries and setting random seeds for reproducibility using `library.utils.seed_everything`.
2.  **Data Loading**: Utilize `library.data.get_dataloaders` to load pre-processed training, validation, and test datasets. We will use the full dataset but limit the training epochs to ensure the "fast baseline" requirement is met.
3.  **Model Initialization**: Instantiate the `AHS_DFN` model from `library.model` and move it to the configured device (GPU).
4.  **Training**: Initialize the `Trainer` from `library.train`. Execute the training loop for a reduced number of epochs (15) to balance performance with the time limit. The trainer handles the optimization, loss calculation (Anchored MCRMSE), and model checkpointing.
5.  **Validation & Metric Calculation**:
    *   Load the best model state saved during training.
    *   Perform inference on the full validation set in evaluation mode (`no_grad`).
    *   Calculate the final MCRMSE score using `library.utils.metric_mcrmse` and print it in the required format.
6.  **Failure Analysis**:
    *   Compute the RMSE for each sample in the validation set individually.
    *   Load the validation metadata (`val.csv`) to access auxiliary features like `signal_to_noise` and sequence properties (e.g., A/G/C/U counts).
    *   Calculate and print the Pearson correlation between the model's error and these features to identify potential weaknesses (e.g., does low signal-to-noise ratio correlate with high error?).
7.  **Submission**:
    *   Check if the validation score meets the threshold (< 0.47142532743789534).
    *   If successful, generate predictions for the test set using the best model.
    *   Format the predictions using `library.train.generate_submission` and save to `./submission/submission.csv`.
