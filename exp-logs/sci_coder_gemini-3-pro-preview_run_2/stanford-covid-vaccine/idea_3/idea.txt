Based on the lessons learned from previous iterations, I propose the **Embedding-Enhanced Channel-Attentive Hybrid Network**. This strategy evolves the successful Dilated CNN-RNN architecture by fundamentally upgrading the input representation and the feature extraction mechanism, while strictly adhering to the insights regarding global modeling and multi-task learning.

# Model

1.  **Input Representation (Learnable Embeddings):**
    *   Instead of the static One-Hot encoding used in previous ideas, I will implement **Learnable Embedding Layers** for the three categorical inputs: `sequence` (4 tokens), `structure` (3 tokens), and `predicted_loop_type` (7 tokens).
    *   These embeddings will map each discrete token to a dense vector space, allowing the model to learn semantic relationships between structural elements (e.g., the similarity between different loop types) that One-Hot encoding cannot capture. These embeddings are concatenated to form the input tensor.

2.  **Backbone (Channel-Attentive Dilated ResNet):**
    *   The core feature extractor remains a **Dilated Residual Network** to capture long-range dependencies without pooling, preserving the 107-nucleotide resolution (Cite solution_lesson_node_00002).
    *   **Innovation:** I will integrate **Squeeze-and-Excitation (SE) Modules** within each residual block. The SE block explicitly models inter-dependencies between channels, allowing the network to adaptively recalibrate feature responses (e.g., emphasizing specific motif detectors while suppressing noise) based on the global content of the receptive field.
    *   The backbone will continue to use exponentially increasing dilation rates ($d=1, 2, 4, \dots$) to expand the receptive field.

3.  **Global Context Aggregation (BiGRU):**
    *   Following the backbone, I will retain the **Bidirectional GRU (BiGRU)** layer. This component is proven to be superior to pure CNNs for aggregating global sequence state (Cite solution_lesson_node_00003).
    *   **Constraint:** The BiGRU will be configured with `hidden_size = input_dim // 2`. This ensures the concatenated output dimension matches the input dimension, preventing parameter bloat and overfitting (Cite solution_lesson_node_00004).

4.  **Output Head:**
    *   A final linear projection maps the aggregated features to the 5 target variables.

# Data

1.  **Preprocessing:**
    *   **Tokenization:** Convert the character-based `sequence`, `structure`, and `predicted_loop_type` columns into integer indices to feed into the Embedding layers.
    *   **Target Parsing:** Parse the stringified target lists in `train.csv` back into numerical arrays.
2.  **Loaders:**
    *   Construct data loaders that yield batches of integer-encoded sequences (Batch, 107, 3) and target vectors (Batch, 107, 5).

# Training

1.  **Loss Function (Multi-Task Learning):**
    *   I will use the **MCRMSE** loss function calculated on **all 5 target columns** (`reactivity`, `deg_Mg_pH10`, `deg_pH10`, `deg_Mg_50C`, `deg_50C`).
    *   Even though only 3 targets are scored, the inclusion of the correlated auxiliary targets (`deg_pH10`, `deg_50C`) provides essential regularization and improves the generalization of the shared representation (Cite solution_lesson_node_00006).
    *   The loss will be masked to consider only the first 68 positions (`seq_scored`).

2.  **Optimization:**
    *   Use the **AdamW** optimizer with a standard learning rate (e.g., 1e-3) and a `ReduceLROnPlateau` scheduler to adaptively lower the learning rate when validation loss stagnates.

# Evaluation

1.  **Inference:**
    *   Process the `test.csv` file using the same tokenization pipeline.
    *   Generate predictions for all 107 positions and all 5 targets.
2.  **Submission:**
    *   Flatten the predictions to the `id_seqpos` format required for submission, ensuring the correct mapping of the 5 predicted channels to the submission columns.
