Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Dense-Refined Recurrent Hybrid Network (DR-RHN)**.

This strategy optimizes the state-of-the-art "Contextualized-Feedback" architecture (Idea 36) by structurally upgrading the feedback encoder. It synthesizes the architectural superiority of **Dense Connectivity** (Lesson 00047) with the strict **Lightweight Constraint** (Lesson 00103) required for stability refinement. By replacing the simple residual feedback blocks with a **Lightweight Dense TCN**, we maximize feature reuse and signal propagation within the recycling loop without bloating the parameter count, while strictly adhering to the "Static Backbone" and "Late Fusion" principles.

# Model

1.  **Input Representation (Static & Partner-Aware):**
    *   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder to generate meaningful local features.
    *   **Static Tensor:** The input tensor is static; we do not augment it with recycling channels to avoid re-running the heavy main backbone (Cite solution_lesson_node_00090).

2.  **Main Backbone (Static Dense Dilated TCN):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** (Cite solution_lesson_node_00011) utilizing **Dense Connections** (concatenating outputs of all prior blocks). This preserves the full multi-scale history (Cite solution_lesson_node_00047).
    *   **Micro-Architecture:** `LayerNorm -> ReLU -> Conv1d -> Dropout(0.1)` with residual connections (Cite solution_lesson_node_00101).
    *   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
    *   **Capacity:** Growth Rate **64** (Cite solution_lesson_node_00037).
    *   **Execution:** Runs **once** per batch to produce dense feature tensor $H_{dense}$.
    *   **Latent Projection:** $H_{dense}$ is projected to **Latent Dim 64** ($Z$) via Linear 1x1 Conv (Cite solution_lesson_node_00062, solution_lesson_node_00076).

3.  **Lightweight Dense Feedback Module (Structural Innovation):**
    *   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
    *   **Masking:** Zero out unscored targets (`deg_pH10`, `deg_50C`) to prevent unsupervised noise injection (Cite solution_lesson_node_00016).
    *   **Projection:** Linear Projection to 16 channels (Cite solution_lesson_node_00086).
    *   **Architecture:** A **Lightweight Dense TCN**.
        *   *Rationale:* Idea 36 used Residual blocks. Idea 38 used a Heavy DenseNet (Growth 32) and failed (Lesson 00103). We propose a **Low-Growth DenseNet** (Growth Rate **12**, 4 layers). This leverages the superior feature propagation of Dense connectivity (Lesson 00047) to extract richer "error gradients" from the feedback signal, while remaining strictly lightweight to prevent the feedback loop from dominating the static signal.
    *   **Output:** Feedback Embeddings $E_{fb}$ (projected to 32 channels).

4.  **Interaction & Aggregation:**
    *   **Augmented Gather:** For every position $i$ paired with $j$:
        *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
        *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
            *   *Note:* This propagates the dynamic feedback through structural connections (Cite solution_lesson_node_00105).
    *   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
    *   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
        *   *Note:* This adheres to **Late Fusion** (Cite solution_lesson_node_00100) by keeping static $Z$ and dynamic $E$ separate until this step.
    *   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003).
    *   **Output:** Linear projection to targets.

# Data

1.  **Preprocessing & Cache Safety:**
    *   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_dr_rhn_v1.npz`) to ensure input features are generated correctly (Cite solution_lesson_node_00032).
    *   **Feature Generation:** Generate One-Hot encodings (Seq, Struct, Loop), Partner Identity, and Partner Index Map.
    *   **Target Parsing:** Parse stringified targets to numerical arrays.

2.  **Loaders:**
    *   Yield Augmented Input, Partner Index Map, and Targets.

# Training

1.  **Iterative Refinement Loop:**
    *   **Step 1 (Static):** Compute $Z$ from static inputs once.
    *   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
    *   **Pass 1:**
        *   Compute $E_{fb, 0}$ from $\hat{Y}_0$ using **Lightweight Dense Feedback Module**.
        *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
    *   **Pass 2:**
        *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
        *   Compute $E_{fb, 1}$ from $R$ using **Lightweight Dense Feedback Module**.
        *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

2.  **Loss Function:**
    *   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
    *   Calculate loss **only on scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) (Cite solution_lesson_node_00016).

3.  **Optimizer:**
    *   **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

# Evaluation

1.  **Inference:**
    *   Compute Backbone features $Z$ once.
    *   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
    *   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
    *   Submit $\hat{Y}_2$.

2.  **Metric:**
    *   Use **Correct Global RMSE** (Cite solution_lesson_node_00020).
