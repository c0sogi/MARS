The following script demonstrates the usage of the provided library files to train the `AHCHDN` model and generate a submission.

**Implementation Strategy:**
1.  **Configuration Override:** We modify the `Config` class attributes at runtime to point to a temporary working directory (`./working/demo_run`) and reduce hyperparameters (epochs, batch size) for a fast execution.
2.  **Component Verification:** We instantiate the model (`AHCHDN`) and loss function (`AnchoredMCRMSELoss`) and run dummy tensors through them to assert that the shapes and calculations are correct before starting the pipeline.
3.  **Training Pipeline:** We utilize `library.train.run_training` with `debug=True`. This flag forces the training loop to use a small subset of the data, ensuring the process completes quickly while still exercising the data loading, forward pass, backward pass, and validation logic.
4.  **Inference Pipeline:** We execute `library.train.run_inference`, which loads the trained model and generates predictions for the public test set (240 samples), saving the result to a CSV file.
5.  **Output Validation:** Finally, we verify that the submission file exists and conforms to the expected dimensions and column structure.
