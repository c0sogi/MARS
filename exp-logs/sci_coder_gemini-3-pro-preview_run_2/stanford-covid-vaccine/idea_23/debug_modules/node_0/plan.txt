This script demonstrates the usage of the RNA degradation prediction library. It performs the following steps:
1.  **Configuration Override**: Modifies the `Config` class at runtime to use a small data subset, temporary directories, and minimal epochs for rapid execution.
2.  **Data Pipeline Verification**: Loads a debug subset of the data using `get_dataloaders`, inspecting shapes and types of inputs, partner indices, and targets.
3.  **Model Verification**: Instantiates the `RNAModel`, performs a forward pass on a batch, and validates the output structure.
4.  **Loss & Metric Verification**: Computes the `MaskedMCRMSELoss` and `GlobalMCRMSE` metric on the model outputs to ensure mathematical correctness.
5.  **Training Loop Verification**: Executes a single epoch of training and validation using the `train_fn` and `eval_fn` from the engine, verifying that the optimization step functions correctly.
