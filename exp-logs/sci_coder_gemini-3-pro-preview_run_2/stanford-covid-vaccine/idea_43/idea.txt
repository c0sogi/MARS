Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Topology-Informed Stabilized Recurrent Network (TI-SRN)**.

This strategy evolves the state-of-the-art "Contextualized-Feedback" architecture (Idea 36) by implementing two critical structural optimizations. First, it addresses the "Context Blindness" of the recycling loop by injecting **Raw Topological Features** directly into the feedback encoder, enabling structure-conditional denoising without violating the "Late Fusion" constraint. Second, it enforces **Micro-Architectural Robustness** (Lesson 00111) across both the static backbone and the feedback loop, ensuring that spatial aggregation and channel mixing are strictly decoupled to maximize expressivity within a lightweight budget.

# Model

1.  **Input Representation (Static & Partner-Aware):**
    *   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder to generate meaningful local features.
    *   **Static Tensor:** The main input tensor is static; we do not augment it with recycling channels to avoid re-running the heavy main backbone (Cite solution_lesson_node_00090).

2.  **Main Backbone (Static Dense Dilated TCN):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** utilizing **Dense Connections** (concatenating outputs of all prior blocks) (Cite solution_lesson_node_00047).
    *   **Micro-Architecture (Innovation):** We strictly enforce the **Decoupled Block Structure** identified in **Lesson 00111**: `Dilated Conv (k=3) -> Norm -> ReLU -> Pointwise Conv (k=1) -> Norm -> ReLU`. This ensures spatial aggregation is separated from channel mixing.
    *   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
    *   **Capacity:** Growth Rate **64**, **Dropout 0.1** (Cite solution_lesson_node_00037, solution_lesson_node_00038).
    *   **Latent Projection:** The output $H_{dense}$ is projected to **Latent Dim 64** ($Z$) via a **Linear 1x1 Convolution** (Cite solution_lesson_node_00062, solution_lesson_node_00076).

3.  **Topology-Informed Feedback Module (Structural Innovation):**
    *   **Inputs:**
        1.  Recycled predictions $\hat{Y}_{k-1}$ (5 channels), masked to zero out unscored targets (Cite solution_lesson_node_00016).
        2.  **Raw Topology Features:** One-Hot `structure` and `predicted_loop_type` (10 channels).
    *   **Fusion:** Concatenate $[\hat{Y}_{masked}, \text{Topology}]$.
        *   *Rationale:* This provides the feedback encoder with minimal structural context (e.g., "I am in a Stem") to interpret stability predictions, distinguishing physical signals from noise. Unlike Idea 37 (which failed due to Early Fusion of heavy backbone features), this fuses only lightweight raw features, preserving the independence of the feedback loop (Cite solution_lesson_node_00100).
    *   **Encoder:** A **Lightweight Dilated TCN** (Cite solution_lesson_node_00103) utilizing the same **Decoupled Block Structure** (Dilated $\to$ Pointwise) to maximize parameter efficiency.
    *   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

4.  **Interaction & Aggregation:**
    *   **Augmented Gather:** For every position $i$ paired with $j$:
        *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
        *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
            *   *Note:* This propagates the dynamic feedback through structural connections (Cite solution_lesson_node_00105).
    *   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
    *   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
    *   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003) feeding directly from the fusion layer (Cite solution_lesson_node_00077).
    *   **Output:** Linear projection to targets.

# Data

1.  **Preprocessing & Cache Safety:**
    *   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_ti_srn_v1.npz`) to ensure input features (especially Partner Identity) are generated correctly (Cite solution_lesson_node_00032).
    *   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
    *   **Target Parsing:** Parse stringified targets to numerical arrays.

2.  **Loaders:**
    *   Yield Augmented Input, Partner Index Map, and Targets.

# Training

1.  **Iterative Refinement Loop:**
    *   **Step 1 (Static):** Compute $Z$ from static inputs once.
    *   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
    *   **Pass 1:**
        *   Compute $E_{fb, 0}$ from $\hat{Y}_0$ and Raw Topology.
        *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
    *   **Pass 2:**
        *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
        *   Compute $E_{fb, 1}$ from $R$ and Raw Topology.
        *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

2.  **Loss Function:**
    *   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
    *   Calculate loss **only on scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) (Cite solution_lesson_node_00016).

3.  **Optimizer:**
    *   **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

# Evaluation

1.  **Inference:**
    *   Compute Backbone features $Z$ once.
    *   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
    *   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
    *   Submit $\hat{Y}_2$.

2.  **Metric:**
    *   Use **Correct Global RMSE** (accumulate SSE and counts, compute root at end) (Cite solution_lesson_node_00020).
