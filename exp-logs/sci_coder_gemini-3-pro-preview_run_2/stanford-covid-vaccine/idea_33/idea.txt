Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Projected Feedback Recurrent Dense Network (PFR-DN)**.

This strategy synthesizes the robust, state-of-the-art "Dense-Context" backbone (proven in Idea 8) with a **Corrected Recycling Mechanism**. It specifically addresses the failure of previous recycling attempts caused by "Scale Mismatch" (Lesson 00085) and "Saturation" (Lesson 00086) by replacing raw or squashed feedback with a **Learnable Linear Projection**. This allows the model to iteratively refine its stability estimates using a high-dimensional, non-saturating embedding of its own predictions, while retaining the stabilization techniques (Lesson 00078) and architectural optimizations established in prior successes.

# Model

1.  **Input Representation (Projected Recurrent & Partner-Aware):**
    *   **Static Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base). As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
    *   **Dynamic Feedback Projection (Innovation):** Instead of concatenating raw scalar predictions (which causes scale mismatch, Cite solution_lesson_node_00085) or Tanh-squashed predictions (which causes saturation, Cite solution_lesson_node_00086), we process the 5 recycling channels through a **Learnable Linear Projection Layer** (mapping 5 $\to$ 32 channels).
        *   *Rationale:* This projects the regression outputs into a high-dimensional embedding space, allowing the network to learn the optimal representation of magnitude and uncertainty without the information loss associated with clipping or saturation.

2.  **Backbone (Dense Dilated TCN):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** (Cite solution_lesson_node_00011) utilizing **Dense Connections** (concatenating outputs of all prior blocks). This preserves the full multi-scale history (Cite solution_lesson_node_00047).
    *   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) for global receptive field coverage (Cite solution_lesson_node_00002).
    *   **Capacity & Regularization:** We strictly set the **Growth Rate** to **64** (Cite solution_lesson_node_00037) and apply **Dropout (0.1)** within every block to prevent overfitting (Cite solution_lesson_node_00038).
    *   **Convolution Type:** Standard Convolutions (Cite solution_lesson_node_00018).

3.  **Latent Structural Interaction (Optimized):**
    *   **Linear Projection:** We project the high-dimensional dense history to a **Latent Dimension of 64** using a **Linear 1x1 Convolution**. This avoids non-linear distortion (Cite solution_lesson_node_00076) and compresses noise (Cite solution_lesson_node_00062) while acting on the unified history (Cite solution_lesson_node_00070).
    *   **Symmetric Gather:** For every position $i$, we gather the 64-dimensional latent vector of its paired partner $j$ (Cite solution_lesson_node_00031).
    *   **Null-Masking:** We explicitly apply a **Zero-Mask** to the gathered features for unpaired bases (Cite solution_lesson_node_00071).
    *   **Fusion:** We concatenate the local latent vector (64 dim) with the gathered partner vector (64 dim). We use simple **Concatenation** (Cite solution_lesson_node_00066) to maintain symmetry (Cite solution_lesson_node_00073).

4.  **Global Aggregation (BiGRU):**
    *   The fused features (128 dim) are processed by a **Bidirectional GRU** (Cite solution_lesson_node_00003).
    *   **Constraint:** Hidden size is set to `input_dim // 2` (64) (Cite solution_lesson_node_00004).
    *   **Placement:** Direct feed to RNN (Cite solution_lesson_node_00077).

5.  **Output Head:**
    *   Linear projection to the 5 target variables.

2.  **Loaders:**
    *   Yield the Augmented Input Tensor, Partner Index Map, and Target Tensor. Recycling inputs are initialized to zero in the training loop and updated dynamically.

# Training

1.  **Stabilized Recurrent Loop:**
    *   For each batch, perform a **Two-Stage Forward Pass**:
        1.  **Pass 1 (Cold Start):** Feed inputs with zeroed recycling channels. Output $\hat{Y}_1$.
        2.  **Gradient Detachment:** Create a detached copy: $R = \hat{Y}_1.detach()$. This prevents the "noisy feedback loop" (Cite solution_lesson_node_00078).
        3.  **Pass 2 (Refinement):** Feed inputs with $R$ as the recycling channels (processed by the Linear Projection layer). Output $\hat{Y}_2$.

2.  **Loss Function (Masked & Multi-Stage):**
    *   **Primary Loss:** MCRMSE on $\hat{Y}_2$, calculated **only on the three scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) (Cite solution_lesson_node_00016).
    *   **Auxiliary Loss:** MCRMSE on $\hat{Y}_1$.
    *   **Total Loss:** $L_{total} = L(\hat{Y}_2) + 0.5 \times L(\hat{Y}_1)$.

3.  **Optimizer:**
    *   Use **AdamW** with a learning rate of 1e-3 and a `ReduceLROnPlateau` scheduler.

# Evaluation

1.  **Inference Strategy:**
    *   Initialize recycling channels to zero.
    *   Run **Pass 1** to generate initial predictions.
    *   Run **Pass 2** using Pass 1 outputs as input.
    *   Use **Pass 2** outputs as the final submission predictions.
