The following script demonstrates the usage of the provided library modules for the RNA degradation prediction task.

### Implementation Strategy

1.  **Configuration Setup**: We first override specific paths in `library.config.Config` to ensure all outputs (cache, models, submissions) are directed to the `./working` directory and do not interfere with existing files. We also set the random seed for reproducibility.
2.  **Component Verification (Unit Tests)**:
    *   **Layers**: We instantiate `RobustBlock` and `DenseDilatedTCN` from `library.layers` and verify that they handle input tensors correctly and produce outputs with expected shapes.
    *   **Model**: We instantiate the `REIDFN` model from `library.model`. We create dummy input tensors (features and pair indices) to simulate a batch and verify the forward pass works for both the initial pass (no feedback) and the second pass (with feedback).
    *   **Loss**: We verify `MaskedMCRMSELoss` from `library.loss` by calculating the loss between identical tensors (expecting 0.0) and known differing tensors to ensure the masking and column selection logic functions as intended.
3.  **Data Pipeline Verification**:
    *   We utilize `library.data.process_data` with a `debug_size` to quickly load a small subset of the training data.
    *   We inspect the returned data dictionaries and instantiate `RNADataset` to verify that data loading and tensor conversion are correct.
4.  **Full Training Loop Integration**:
    *   We execute `library.train.run_training` with `debug_size=32` and `epochs=1`. This runs the complete end-to-end pipeline: data loading, model initialization, training for one epoch, validation, and submission generation.
5.  **Output Verification**: Finally, we confirm that the submission file was generated successfully.
