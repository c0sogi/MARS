Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Robust Embedded-Input Dense-Feedback Network (REID-FN)**.

This strategy synthesizes the state-of-the-art "Pure-Feedback" architecture (Idea 47) with critical micro-architectural corrections identified in **Lesson 00120** (Input Embedding), **Lesson 00111** (Decoupled Blocks), and **Lesson 00116** (Full-Rank Convolutions). It establishes a robust, pre-activation pipeline that preserves sparse input signals while maximizing the expressivity of the static backbone and the stability of the recycling loop.

# Model

### 1. Input Representation (Embedded & Partner-Aware)
*   **Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
*   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base) at the input level. As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
*   **Input Embedding Stem (Structural Innovation):** We process the concatenated One-Hot features with a **Standard Convolution (Kernel 1)** *before* entering the backbone.
    *   *Rationale:* This projects the sparse, orthogonal categorical vectors into a dense, learnable embedding space. This is strictly required before applying **Layer Normalization** in a Pre-Activation architecture to avoid "smearing" the discrete signal (Cite solution_lesson_node_00120).
*   **Static Tensor:** The input remains static; we do not augment it with recycling channels to avoid re-running the heavy main backbone (Cite solution_lesson_node_00090).

### 2. Main Backbone (Static Dense Dilated TCN)
*   **Architecture:** A stack of **Single-Layer Dilated Blocks** utilizing **Dense Connections** (concatenating outputs of all prior blocks) (Cite solution_lesson_node_00047).
*   **Micro-Architecture (Robust, Decoupled, & Pre-Activation):** We employ **Pre-Activation** blocks utilizing **Standard Full-Rank Convolutions** and **SiLU Activations**, structured to decouple spatial aggregation from channel mixing:
    *   Structure: `LayerNorm -> SiLU -> Standard Dilated Conv (k=3) -> LayerNorm -> SiLU -> Standard Pointwise Conv (k=1) -> Dropout(0.1)`.
    *   *Rationale:* 
        *   **Pre-Activation** improves gradient flow (Cite solution_lesson_node_00120).
        *   **Standard Convolutions** (vs. Separable) preserve motif interaction capacity (Cite solution_lesson_node_00116).
        *   **Decoupled Structure** (Dilated $\to$ Pointwise) ensures robust feature mixing (Cite solution_lesson_node_00111).
        *   **SiLU** prevents dead neurons in low-data regimes (Cite solution_lesson_node_00117).
*   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$) (Cite solution_lesson_node_00002).
*   **Capacity:** Growth Rate **64** (Cite solution_lesson_node_00037).
*   **Latent Projection:** The output is projected to **Latent Dim 64** ($Z$) via a **Linear 1x1 Convolution** (Cite solution_lesson_node_00062, solution_lesson_node_00076).

### 3. Pure-Feedback Module
*   **Input:** Recycled predictions $\hat{Y}_{k-1}$ (5 channels).
*   **Strict Masking:** We strictly apply a binary mask to zero out unscored targets (`deg_pH10`, `deg_50C`). We **do not** concatenate raw topology features, ensuring the loop is driven solely by the supervised signal (Cite solution_lesson_node_00118, solution_lesson_node_00100).
*   **Architecture:** A **Lightweight Dense TCN** (Cite solution_lesson_node_00103).
    *   **Embedding:** First layer is a Linear Projection (Cite solution_lesson_node_00086).
    *   **Blocks:** Uses the same **Robust, Decoupled, Pre-Activation** structure as the backbone to ensure optimization stability.
    *   **Constraint:** **Low Growth Rate (16)** to keep capacity low relative to the backbone.
*   **Output:** Feedback Embeddings $E_{fb}$ (32 channels).

### 4. Interaction & Aggregation
*   **Augmented Gather:** For every position $i$ paired with $j$:
    *   **Self Vector:** Concatenate $[Z_i, E_{fb, i}]$.
    *   **Partner Vector:** Gather $[Z_j, E_{fb, j}]$ (Cite solution_lesson_node_00031).
        *   *Note:* This propagates the dynamic feedback through structural connections (Cite solution_lesson_node_00105).
*   **Null-Masking:** Apply **Zero-Mask** to gathered vectors for unpaired bases (Cite solution_lesson_node_00071).
*   **Fusion:** Concatenate Self and Partner vectors (Cite solution_lesson_node_00066).
*   **Global Aggregation:** Process with a **Bidirectional GRU** (Cite solution_lesson_node_00003) feeding directly from the fusion layer (Cite solution_lesson_node_00077).
*   **Constraint:** **Compact Hidden Size (64)**. We strictly limit the RNN capacity to match the feature dimension (Cite solution_lesson_node_00117).
*   **Output:** Linear projection to targets.

# Training

### 1. Iterative Refinement Loop
*   **Step 1 (Static):** Compute $Z$ from static inputs once.
*   **Step 2 (Recycling):** Initialize $\hat{Y}_0 = 0$.
*   **Pass 1:**
    *   Compute $E_{fb, 0}$ from Masked $\hat{Y}_0$ using the **Pure-Feedback Module**.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 0}$. Output $\hat{Y}_1$.
*   **Pass 2:**
    *   Detach Gradients: $R = \hat{Y}_1.detach()$ (Cite solution_lesson_node_00078).
    *   Compute $E_{fb, 1}$ from Masked $R$ using the **Pure-Feedback Module**.
    *   Run Interaction + RNN using $Z$ and $E_{fb, 1}$. Output $\hat{Y}_2$.

### 2. Loss Function
*   $L_{total} = \text{MCRMSE}(\hat{Y}_2) + 0.5 \times \text{MCRMSE}(\hat{Y}_1)$.
*   **Strict Masking:** Calculate loss **only on the three scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) and **only on valid sequence positions** (0-67) (Cite solution_lesson_node_00016, solution_lesson_node_00109).

### 3. Optimizer
*   **AdamW** (lr=1e-3) with `ReduceLROnPlateau`.

# Evaluation

### 1. Inference
*   Compute Backbone features $Z$ once.
*   Run Pass 1 (Zero Feedback) $\to \hat{Y}_1$.
*   Run Pass 2 (Feedback = Masked $\hat{Y}_1$) $\to \hat{Y}_2$.
*   Submit $\hat{Y}_2$.

### 2. Metric
*   Use **Correct Global RMSE**. Accumulate SSE and counts across the entire validation set before computing the square root to avoid batch-averaging bias (Cite solution_lesson_node_00020).
