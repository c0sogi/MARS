The following script demonstrates the end-to-end usage of the provided library files. It performs the following steps:
1.  **Configuration**: overrides the working directory to isolate the demo execution and sets random seeds.
2.  **Component Verification**: validates the functionality of utility functions, the model architecture (`SRDN`), and the loss function (`MCRMSELoss`) using synthetic data.
3.  **Pipeline Execution**: runs the full training and inference pipeline using `train_model` with a restricted sample size and epoch count to ensure rapid execution.
4.  **Output Verification**: asserts that the submission file is generated correctly and adheres to the expected format.
