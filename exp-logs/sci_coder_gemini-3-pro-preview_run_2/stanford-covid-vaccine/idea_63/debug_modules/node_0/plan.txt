The following is a complete, self-contained Python script that demonstrates the usage of the provided library modules. It outlines a strategy to verify data loading, model instantiation, training logic, and submission generation using a reduced subset of data for speed.

### Implementation Strategy
1.  **Setup & Reproducibility**: Initialize random seeds and configure device (CPU/GPU).
2.  **Data Loading**: Use `library.data.get_dataloaders` to load the full datasets.
3.  **Subset Creation**: Create smaller DataLoaders (using `torch.utils.data.Subset`) to ensure the demonstration runs quickly (processing only a few batches instead of the full dataset).
4.  **Model Initialization**: Instantiate the `HS_GFDN` model from `library.model` and verify its structure.
5.  **Forward Pass & Loss Verification**: Run a single batch through the model and compute the `MaskedMCRMSE` loss to ensure shapes and calculations are correct.
6.  **Training Loop Simulation**: Execute `library.train.train_one_epoch` and `library.train.validate` using the mini-dataloaders to verify the optimization loop and metric calculation.
7.  **Inference & Submission**: Run `library.train.inference` on the mini-test set and generate a sample submission file using `library.train.generate_submission`.
8.  **Validation**: Assert conditions throughout to guarantee correctness (e.g., output shapes, loss types, file existence).
