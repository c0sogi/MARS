The issue is that the PyTorch `Conv1d` layers in the model expect input tensors in the **Channel-First** format `(Batch, Channels, Length)`, whereas the dataset is currently providing them in the **Channel-Last** format `(Batch, Length, Channels)`. This causes a `RuntimeError` during the forward pass because the sequence length is interpreted as the channel dimension. To fix this, I will modify the `RNA_Dataset` class in `library/data.py` to explicitly permute the `inputs` and `targets` tensors to `(N, C, L)` during initialization. This ensures compatibility with the convolutional backbone and the loss function. Cite debug_lesson_17.
