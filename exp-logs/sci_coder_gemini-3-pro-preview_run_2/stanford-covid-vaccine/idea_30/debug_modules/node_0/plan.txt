The following script demonstrates the usage of the provided library files to train and evaluate the RNA degradation prediction model. It performs the following steps:

1.  **Configuration Setup**: Overrides the default `Config` to use a temporary directory and a small subset of data (Debug mode) for rapid execution.
2.  **Data Loading**: Uses `get_loader` to prepare training and validation dataloaders, verifying the shape and integrity of the batches.
3.  **Model Initialization**: Instantiates the `SR_DCN` model and performs a forward pass to verify output dimensions.
4.  **Loss Calculation**: Validates the `masked_mcrmse` loss function with synthetic data to ensure metric correctness.
5.  **Training Loop**: Executes a single training epoch and a validation step using the functions provided in `library.train`.
6.  **Inference**: Generates predictions for a test batch and formats them into a submission file.
7.  **Cleanup**: Removes the temporary working directory.
