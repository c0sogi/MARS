Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Stacking-Aware Gated Hybrid Network**. This strategy evolves the successful "Partner-Aware" baseline by integrating a physics-inspired feature expansion (Stacking Interactions) and upgrading the convolutional backbone to a Gated architecture to better control information flow.

# Model

1.  **Input Representation (Stacking-Aware Encoding):**
    *   **Standard Features:** Retain **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Innovation (Partner Triplet Features):** Building on the success of "Partner Base Identity" (Cite solution_lesson_node_00015), I will explicitly model **Base Stacking Interactions**, which are the primary driver of RNA helix stability. For every base $i$ paired with $j$, we will concatenate the One-Hot encodings of the **triplet** $(j-1, j, j+1)$ to the input vector of $i$.
        *   This provides the model with the immediate structural context of the distal partner, allowing it to infer stacking energies (e.g., G-C stacked on A-U) without needing to resolve these dependencies through deep layers.
        *   If unpaired, these features are zeroed.

2.  **Backbone (Gated Dilated TCN):**
    *   **Structural Innovation:** Replace the standard ReLU-based convolutional blocks with **Gated Residual Blocks** (inspired by WaveNet).
    *   **Mechanism:** Each dilated layer will produce two outputs using separate convolutions: a "filter" output (activated by Tanh) and a "gate" output (activated by Sigmoid). The block output is the element-wise product: $z = \tanh(W_{f} * x) \odot \sigma(W_{g} * x)$.
    *   **Rationale:** This gating mechanism allows the network to dynamically select relevant features from the exponentially growing receptive field, suppressing noise and emphasizing signal more effectively than static ReLU activations, which is crucial given the noisy nature of the data.
    *   **Configuration:** Maintain **Single-Layer Blocks** (Cite solution_lesson_node_00011) with exponentially increasing dilation rates ($d=1, 2, \dots, 32$) to ensure global coverage (Cite solution_lesson_node_00002).

3.  **Global Aggregation (BiGRU):**
    *   Retain the **Bidirectional GRU** to capture global sequence state (Cite solution_lesson_node_00003).
    *   **Constraint:** Strictly set `hidden_size = input_dim // 2` to ensure the concatenated output dimension matches the input, preventing parameter bloat (Cite solution_lesson_node_00004).

4.  **Output Head:**
    *   A final linear projection maps the BiGRU output to the 5 target variables.

# Data

1.  **Preprocessing:**
    *   **Target Parsing:** Parse stringified targets in `train.csv` to numerical arrays.
    *   **Feature Generation:**
        *   Generate One-Hot encodings for `sequence`, `structure`, and `predicted_loop_type`.
        *   **Partner Triplet Generation:** Parse `structure` to find pairs $(i, j)$. For each $i$, retrieve the one-hot vectors for indices $j-1$, $j$, and $j+1$ (handling boundary conditions with padding). Concatenate these to position $i$.
    *   **Concatenation:** Combine all features into a single tensor.

2.  **Loaders:**
    *   Yield the stacking-augmented input tensors and the 5-column target vectors.

# Training

1.  **Loss Function (Masked Optimization):**
    *   Use **MCRMSE** (Mean Columnwise Root Mean Squared Error).
    *   **Strategy:** Calculate loss **only on the three scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
    *   **Rationale:** As established in **Lesson 00016**, masking out the auxiliary targets (`deg_pH10`, `deg_50C`) prevents negative transfer and aligns the optimization strictly with the competition metric.

2.  **Optimizer:**
    *   Use **AdamW** with a learning rate of 1e-3 and a `ReduceLROnPlateau` scheduler.
