Based on the comprehensive analysis of the provided lessons and previous attempts, I propose the **Partner-Aware Multi-Scale Hybrid Network**. This strategy introduces a novel feature engineering paradigm to explicitly model RNA folding constraints without the complexity of graph networks, combined with an architectural evolution that fuses local and global features.

# Model

The architecture is a **1D Convolutional-Recurrent Hybrid** designed to maximize information flow and feature resolution.

1.  **Input Representation (Partner-Aware Encoding):**
    *   **Standard Features:** We retain the successful One-Hot Encoding for `sequence` (4 channels), `structure` (3 channels), and `predicted_loop_type` (7 channels) as learnable embeddings proved inferior for these small vocabularies (Cite solution_lesson_node_00010).
    *   **Innovation (Partner Features):** To address the failure of explicit Graph Neural Networks (Cite solution_lesson_node_00007) while still capturing the critical physical interactions of base pairing, I introduce a **Partner Base Identity** channel. For every position $i$ in the sequence, if the `structure` indicates a base pair with position $j$, we concatenate the One-Hot encoding of the base at $j$ to the input vector of $i$. If unpaired, this is a zero vector. This effectively "teleports" the distal partner's identity into the local feature space, allowing the convolution to process the base-pair interaction immediately without needing deep layers to resolve the dependency.

2.  **Backbone (Multi-Scale Dilated TCN):**
    *   The core encoder consists of a stack of **Single-Layer Dilated Residual Blocks**. We use single-layer blocks (convolution $\to$ activation $\to$ dropout) rather than double-layer bottlenecks to minimize parameter complexity and improve optimization (Cite solution_lesson_node_00011).
    *   We employ exponentially increasing dilation rates ($d=1, 2, 4, \dots, 32$) to ensure global receptive field coverage without pooling (Cite solution_lesson_node_00002).
    *   **Innovation (Multi-Scale Fusion):** Instead of feeding only the output of the final residual block to the RNN, we implement **Skip Connections** that concatenate the feature maps from the early (local context, low dilation) and late (global context, high dilation) blocks. This fused tensor is passed through a 1x1 convolution (bottleneck) to compress the channels before the next stage.

3.  **Global Aggregation (BiGRU):**
    *   The fused multi-scale features are processed by a **Bidirectional GRU (BiGRU)**. This component is retained to capture the global sequence state and dependencies that pure CNNs struggle with (Cite solution_lesson_node_00003).
    *   **Constraint:** The hidden size of the BiGRU will be strictly set to half of the input dimension (`input_dim // 2`) to ensure the output dimension matches the input, preventing overfitting (Cite solution_lesson_node_00004).

4.  **Output Head:**
    *   A final linear projection maps the BiGRU output to the 5 target variables.

# Data

1.  **Preprocessing:**
    *   **Target Parsing:** Convert the stringified lists in `train.csv` (reactivity, deg_*) back into numerical arrays.
    *   **Partner Feature Generation:**
        *   Parse the dot-bracket `structure` string for each sample to identify pairs $(i, j)$.
        *   Create a new feature array of shape $(L, 4)$ where row $i$ contains the One-Hot encoding of the sequence base at index $j$.
    *   **Encoding:** Generate standard One-Hot encodings for sequence, structure, and loop type.
    *   **Concatenation:** Combine all encodings into a single tensor of shape $(107, C_{total})$.

2.  **Loaders:**
    *   Create data loaders that yield the augmented input tensors and the 5-column target vectors.

# Training

1.  **Loss Function:**
    *   Use **MCRMSE** (Mean Columnwise Root Mean Squared Error).
    *   **Strategy:** Calculate the loss on **all 5 target columns** (`reactivity`, `deg_Mg_pH10`, `deg_pH10`, `deg_Mg_50C`, `deg_50C`). Even though `deg_pH10` and `deg_50C` are not scored, they provide critical regularization signals for the shared representation (Cite solution_lesson_node_00006).
    *   Apply masking to calculate loss only on the first 68 positions (`seq_scored`).

2.  **Optimizer:**
    *   Use **AdamW** with a learning rate of 1e-3.
    *   Implement a `ReduceLROnPlateau` scheduler to decay the learning rate when the validation MCRMSE plateaus.
