Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the **Recurrent Self-Correcting Dense Network**.

This strategy synthesizes the robust, state-of-the-art performance of the "Dense-Context" architecture (Idea 8) with a structural innovation inspired by protein folding models: **Input Recycling**. By feeding the model's own predictions back as inputs in an iterative refinement loop, we enable the network to condition its stability estimates on a "global consensus" (e.g., "My partner is predicted to be stable in Pass 1, so I should be stable in Pass 2"), explicitly enforcing physical consistency without adding learnable parameters.

### Model

1.  **Input Representation (Recurrent & Partner-Aware):**
    *   **Static Features:** We utilize **One-Hot Encoding** for `sequence`, `structure`, and `predicted_loop_type` (Cite solution_lesson_node_00010).
    *   **Explicit Partner Identity:** We **retain** the explicit injection of the **Partner Base Identity** (one-hot vector of the paired base). As established in **Lesson 00052**, this provides the necessary chemical context for the encoder.
    *   **Dynamic Recycled Features (Innovation):** We add 5 input channels corresponding to the model's predictions for the 5 target variables (`reactivity`, `deg_*`). In the first pass, these are initialized to zero. In the second pass, they contain the predictions from the first pass.

2.  **Backbone (Dense Dilated TCN):**
    *   **Architecture:** A stack of **Single-Layer Dilated Residual Blocks** (Cite solution_lesson_node_00011) utilizing **Dense Connections** (concatenating outputs of all prior blocks). This preserves the full multi-scale history (Cite solution_lesson_node_00047).
    *   **Configuration:** Exponentially increasing dilation rates ($d=1, 2, 4, 8, 16, 32$).
    *   **Capacity & Regularization:** We strictly set the **Growth Rate** to **64** (Cite solution_lesson_node_00037) and apply **Dropout (0.1)** within every block (Cite solution_lesson_node_00038).
    *   **Convolution Type:** Standard Convolutions (Cite solution_lesson_node_00018).

3.  **Latent Structural Interaction:**
    *   **Compression:** A **Linear 1x1 Convolution** compresses the dense history to **32 channels** (Cite solution_lesson_node_00076, solution_lesson_node_00062).
    *   **Gather:** For every position $i$, we gather the compressed features of its paired partner $j$ (Cite solution_lesson_node_00031). Crucially, because of recycling, these gathered features now implicitly encode the *partner's predicted stability* from the previous pass.
    *   **Null-Masking:** We apply a **Zero-Mask** to gathered features for unpaired bases (Cite solution_lesson_node_00071).
    *   **Fusion:** We concatenate the local and partner features (Cite solution_lesson_node_00066, solution_lesson_node_00073).

4.  **Global Aggregation (BiGRU):**
    *   The fused features are processed by a **Bidirectional GRU** (Cite solution_lesson_node_00003).
    *   **Constraint:** Hidden size is set to `input_dim // 2` (64) (Cite solution_lesson_node_00004).

5.  **Output Head:**
    *   Linear projection to the 5 target variables.

### Data

1.  **Preprocessing & Cache Safety:**
    *   **Explicit Cache Invalidation:** Use a new cache key (e.g., `train_data_recurrent_v1.npz`) to ensure the input features (specifically Partner Identity) are generated correctly (Cite solution_lesson_node_00032).
    *   **Feature Generation:** Generate One-Hot encodings, Partner Identity, and Partner Index Map.
    *   **Target Parsing:** Parse stringified targets in `train.csv` to numerical arrays.

2.  **Loaders:**
    *   Yield the Augmented Input Tensor, Partner Index Map, and Target Tensor.

### Training

1.  **Recurrent Training Loop:**
    *   For each batch, perform **Two Forward Passes**.
    *   **Pass 1:** Feed $X$ with zero-initialized recycling channels. Output $\hat{Y}_1$.
    *   **Pass 2:** Feed $X$ with $\hat{Y}_1$ (detached or with gradients) as recycling channels. Output $\hat{Y}_2$.
    *   **Loss Calculation:** Compute loss on $\hat{Y}_2$. This forces the model to learn how to refine its own estimates.

2.  **Loss Function (Masked Optimization):**
    *   Use **MCRMSE** calculated **only on the three scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
    *   **Rationale:** We strictly adhere to **Lesson 00016**, masking out auxiliary targets to prevent negative transfer.

3.  **Optimizer:**
    *   Use **AdamW** with a learning rate of 1e-3 and a `ReduceLROnPlateau` scheduler.

### Evaluation

1.  **Recurrent Inference:**
    *   Initialize recycling channels to zero.
    *   Run Pass 1 to generate initial predictions.
    *   Run Pass 2 using Pass 1 output as input.
    *   Use Pass 2 output as the final prediction.

2.  **Metric Calculation:**
    *   Implement the **Correct Global RMSE** calculation (Cite solution_lesson_node_00020).

3.  **Submission:**
    *   Flatten outputs to the `id_seqpos` format.
