The following script performs a comprehensive Exploratory Data Analysis (EDA) on the training dataset. It identifies the data modality as Image-based classification.

**Strategy:**
1.  **Setup**: Fix random seeds for reproducibility and load the `./metadata/train.csv` file.
2.  **Target Analysis**: Analyze the `category_id` column to report class counts, distribution statistics, and imbalance ratios.
3.  **Image Analysis**: Since the dataset is large (~186k images), we perform stratified sampling (approx. 3000 images) to efficiently estimate global statistics.
    *   We iterate through the sampled images to extract dimensions (Width, Height), Aspect Ratios, and Channel counts.
    *   We compute global pixel mean and standard deviation using a running accumulator to avoid loading all images into memory.
4.  **Relationship Analysis**:
    *   We extract "Super Categories" (e.g., Birds, Reptiles) from the file paths to analyze high-level distributions.
    *   We investigate if image metadata (like aspect ratio or size) has any statistical relationship with the target categories using ANOVA.
5.  **Output**: The results are printed in the requested format with clear section headers.
