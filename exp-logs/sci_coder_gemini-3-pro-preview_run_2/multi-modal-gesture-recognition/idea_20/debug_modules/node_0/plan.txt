The following script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration parameters (e.g., batch size, epochs, cache directories) to ensure the demo runs quickly and uses the `./working` directory.
2.  **Data Loading**: Instantiates the `GestureDataset` with a small limit to verify data loading and preprocessing logic. It checks the shapes of the generated tensors.
3.  **Model Initialization**: Initializes the `DSG_CRCN` model and verifies the forward pass using a batch of data.
4.  **Loss Computation**: Calculates the multi-stage loss using `DSG_Loss` to ensure the training objective is functioning correctly.
5.  **Training Loop**: Runs a single epoch of training using the `Trainer` class to demonstrate the optimization process and checkpoint saving.
6.  **Inference & Submission**: Uses the `Predictor` class to load the trained model, perform inference on a subset of data, and generate a submission file in the expected format.
