Implementation Strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided modules. Override `Config` parameters to ensure the demonstration runs quickly (e.g., reduced epochs, specific working directory) and uses a small subset of data.
2.  **Utility Verification**: Validate the `levenshtein_distance` function with a known example and test the `post_process_predictions` logic with dummy data to ensure correctness.
3.  **Dataset & DataLoader**: Manually instantiate `GestureDataset` with a `limit_size` to load only a few samples. Create PyTorch DataLoaders and verify the shape of the batches (features, labels, masks) produced by the `collate_fn`.
4.  **Model Initialization & Forward Pass**: Instantiate the `MultiStageTCN` model. Pass a batch of data through it and verify that the output structure and dimensions match expectations (List of `(Batch, Classes, Time)`).
5.  **Loss Computation**: Initialize `ActionSegmentationLoss` and compute the loss for the forward pass output. Assert that the loss is a valid scalar.
6.  **Training Loop**: Initialize the `Trainer`. Replace its internal DataLoaders with the lightweight ones created in step 3. Execute `trainer.fit()` for a few epochs to demonstrate the training pipeline and checkpoint saving.
7.  **Inference**: Run `trainer.predict()` to generate predictions on the test set (also limited) and verify that the submission file is generated correctly.
