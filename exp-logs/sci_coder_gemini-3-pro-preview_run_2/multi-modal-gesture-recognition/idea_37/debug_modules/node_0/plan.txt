The following script demonstrates the usage of the provided library files for the Italian Gesture Recognition task. It performs the following steps:
1.  **Setup**: Configures a temporary working directory and overrides hyperparameters for a fast demonstration.
2.  **Data Preparation**: Creates a small subset of the metadata (training, validation, and test) to ensure quick execution.
3.  **Data Loading**: Verifies the `GestureDataset` and `DataLoader` functionality, checking batch shapes and data integrity.
4.  **Model Initialization**: Instantiates the `DCSGCN` model and verifies the forward pass output structure and dimensions.
5.  **Loss Computation**: Tests the `DCSGCNLoss` (composite loss including classification, boundary, and smoothing terms) to ensure it produces valid scalar values.
6.  **Training Loop**: Runs a single epoch of training and validation using the provided training utilities.
7.  **Inference**: Simulates the inference pipeline, generating predictions on the test subset and verifying the submission file format.
