This script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition. It performs the following steps:

1.  **Configuration Patching**: Modifies the global configuration in memory to use a temporary working directory and reduce model complexity/training duration for a quick demonstration.
2.  **Utility Verification**: Validates the correctness of the Levenshtein distance metric calculation and the prediction decoding logic (smoothing and background removal).
3.  **Data Preparation**: Creates a small subset of the metadata (training, validation, and test) to enable rapid data loading and processing.
4.  **Data Loading**: Uses `process_dataset` to extract features from the raw multi-modal data (Skeleton + Audio) for the subset and wraps them in PyTorch DataLoaders.
5.  **Model Verification**: Instantiates the `CRCN` (Cascaded Recurrent-Convolutional Network) model and performs a forward pass with a dummy batch to verify tensor shapes and deep supervision outputs.
6.  **Training & Inference**: Initializes the `Trainer`, runs a single epoch of training, validates the model, and generates predictions on the test subset.
