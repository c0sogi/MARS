Based on the comprehensive analysis of the accumulated lessons, specifically the success of the **Latent Transition** architecture (Lesson 75) and the trade-off between **Receptive Field** (Lesson 34) and **Over-Smoothing** (Lesson 31), I propose the **Dual-Scale Latent-Cascaded Recurrent-Convolutional Network (DSL-CRCN)**.

This strategy structurally evolves the "Cascaded" paradigm by replacing the standard Single-Stream TCN refinement stages with **Dual-Scale TCN Blocks**. This addresses the inherent conflict between correcting "jitter" (which requires global context/high dilation) and preserving sharp boundaries (which requires local context/low dilation), while strictly adhering to the data hygiene and loss configuration lessons that prevented previous failures.

### Model
**Architecture: Dual-Scale Latent-Cascaded Recurrent-Convolutional Network (DSL-CRCN)**
The model consists of three sequentially connected stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Latent-Transition Recurrent Encoder**
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain this backbone for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025) and high capacity (Cite solution_lesson_node_00034).
    *   **Input:** Frame-wise feature vector (Upper-Body Skeleton + Velocity + Audio), fused via concatenation (Cite solution_lesson_node_00062).
    *   **Heads:** The LSTM output is projected into two streams:
        *   **Class Probabilities ($P_{cls}$):** 21 channels (Softmax).
        *   **Latent Transition Signal ($P_{trans}$):** 1 channel (Sigmoid). This auxiliary head is **unsupervised** (no explicit boundary loss). It allows the network to learn an optimal internal representation to signal "change" vs. "stability" to the downstream stages, avoiding the noise introduced by forcing hard boundary predictions (Cite solution_lesson_node_00077, solution_lesson_node_00075).
    *   **Output:** Concatenated tensor $[P_{cls}, P_{trans}]$.

2.  **Inter-Stage Masking:**
    *   We explicitly multiply the concatenated output tensor by the binary sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Dual-Scale Refinement (Parallel TCN)**
    *   **Structural Innovation:** We replace the standard Dilated Residual Blocks with **Dual-Scale Blocks**.
        *   **Mechanism:** Each block splits the input into two parallel branches:
            *   **Local Branch:** Standard convolution or low dilation ($d=1$) to preserve high-frequency boundary details.
            *   **Global Branch:** High dilation ($d=2^k$) to capture long-range dependencies and smooth over jitter.
        *   **Fusion:** The outputs of both branches are concatenated and projected back to the channel dimension. This allows the model to simultaneously attend to local transitions and global consistency, resolving the "over-smoothing vs. jitter" trade-off (Cite solution_lesson_node_00031).
    *   **Configuration:** 10 layers deep. We maintain a high channel width (**256 channels**) to ensure sufficient capacity for error correction (Cite solution_lesson_node_00078). We **exclude Instance Normalization** to preserve the magnitude of the sparse probability inputs (Cite solution_lesson_node_00066).
    *   **Input:** The masked tensor $[P_{cls}, P_{trans}]$ from Stage 1.
    *   **Output:** Refined $[P'_{cls}, P'_{trans}]$.

4.  **Stage 3: Dual-Scale Sharpening**
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final Class Probabilities ($P''_{cls}$).

### Data
**Preprocessing:**
*   **Normalization (Crucial):** Explicitly **center** the skeleton data relative to the HipCenter and **scale the units from millimeters to meters** (multiply by 0.001). This prevents numerical instability and saturation (Cite solution_lesson_node_00084).
*   **Feature Selection:** Strictly limit inputs to **12 Upper-Body Joints** and **Audio MFCCs** (Cite solution_lesson_node_00020).
*   **Defensive Loading:** Explicitly handle matrix dimension transpositions (Cite solution_lesson_node_00048).

**Augmentation:**
*   **Physically Consistent Smooth Noise:** Implement the temporally correlated noise pipeline.
    1.  Generate Gaussian noise and apply a **Temporal Low-Pass Filter**.
    2.  Add this smooth noise to the **Raw 3D Joint Positions**.
    3.  **Derive** the Temporal Velocity from the augmented positions.
    *   This ensures velocity features remain physically consistent with position features, avoiding the jitter caused by independent noise injection (Cite solution_lesson_node_00059, solution_lesson_node_00064). We avoid geometric rotation to preserve semantic directionality (Cite solution_lesson_node_00067).

**Evaluation Data:**
*   **Deterministic Split:** Instantiate the validation set with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

### Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = L_{stage1} + L_{stage2} + L_{stage3}$.
*   **Classification Loss:** Weighted Cross-Entropy with a strict ratio of **0.1 (Background) : 1.0 (Gesture)** (Cite solution_lesson_node_00013).
*   **Unclamped Probability-Space Smoothing:** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities** of the classification heads.
    *   We do **not** clamp the loss (Cite solution_lesson_node_00087).
    *   We do **not** condition it on the boundary head (Cite solution_lesson_node_00070).
    *   We use Softmax, not Log-Softmax (Cite solution_lesson_node_00033).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4` (Cite solution_lesson_node_00067).
*   **Regularization:** Prioritize output smoothness (T-MSE) over aggressive parameter regularization (Cite solution_lesson_node_00068).

### Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax). This merges fragmented segments more effectively than probability filtering (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to prevent the deletion of valid gestures at sequence edges (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse consecutive repeated labels and remove the background class.
