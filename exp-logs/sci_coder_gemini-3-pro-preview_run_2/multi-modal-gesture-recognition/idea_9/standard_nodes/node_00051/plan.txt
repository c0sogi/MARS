The previous implementation failed with a `TypeError` because `os.path.join` encountered `NaN` (float) values in the metadata DataFrame's path columns, which occurs when pandas loads CSVs with missing entries. Additionally, the path construction logic was located outside the error handling blocks, causing the entire data loading process to crash on these invalid inputs instead of gracefully handling them.

To fix this, I will:
1.  **Sanitize the DataFrame** in `GestureDataset.__init__` by explicitly filling missing values in path columns with empty strings and converting them to string type, ensuring `os.path.join` always receives valid string arguments (Cite debug_lesson_9).
2.  **Refactor `extract_features`** to move path construction inside the `try...except` blocks and initialize the `video` variable safely. This ensures that any remaining data issues are caught by the existing error handlers rather than crashing the program (Cite debug_lesson_1).
