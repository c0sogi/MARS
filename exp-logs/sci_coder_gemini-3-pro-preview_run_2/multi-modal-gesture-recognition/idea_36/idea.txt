Based on the rigorous empirical analysis of previous experiments—specifically the superior performance of **Gated Activation Units** (Cite solution_lesson_node_00099), the necessity of **Explicit Boundary Supervision** (Cite solution_lesson_node_00082), the critical role of **1x1 Output Projections** (Cite solution_lesson_node_00107), and the benefits of **Information Bottlenecks** (Cite solution_lesson_node_00110)—I propose the **Dense-Cascaded Hybrid-Gated Network (DCHG-Net)**.

This strategy introduces two structural evolutions:
1.  **Hybrid Input Encoding:** It combines **Explicit Velocity** features with a **Temporal Convolutional Stem**. This corrects the failure of Idea 35 (which removed velocity) by retaining the explicit dynamic features while using the stem to learn local noise-suppression filters before the LSTM.
2.  **Dense Probability Cascading:** Instead of a strictly sequential chain (Stage 1 $\to$ Stage 2 $\to$ Stage 3), we introduce **Dense Connections in Probability Space**. Stage 3 receives the concatenated probability outputs of *both* Stage 1 (Encoder) and Stage 2 (Refinement). This allows the final sharpener to reconcile the strong semantic priors of the LSTM with the temporally refined predictions of the first TCN, resolving the "forgetting" issue inherent in long chains.

# Model
**Architecture: Dense-Cascaded Hybrid-Gated Network (DCHG-Net)**
The model consists of a Hybrid Encoder and two Refinement Stages trained end-to-end with Deep Supervision and Dense Connectivity.

1.  **Stage 1: Hybrid Recurrent Encoder**
    *   **Input:** Frame-wise feature vector containing **Upper-Body Skeleton Positions**, **Explicit Temporal Velocities**, and **Audio MFCCs**. We strictly retain explicit velocity to capture dynamics (Cite solution_lesson_node_00113).
    *   **Temporal Convolutional Stem (Structural Innovation):** The input flows through a shallow 1D Convolutional block (Kernel=3, Batch Normalization, ReLU).
        *   *Motivation:* This learns to filter high-frequency sensor noise and extract local motion primitives *before* the sequence modeling, improving the signal-to-noise ratio for the LSTM. Batch Norm is permitted here as inputs are dense raw features (Cite solution_lesson_node_00066).
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). (Cite solution_lesson_node_00025).
    *   **Heads:** Projects to **Class Probabilities ($P_{cls}^{(1)}$)** (21 ch, Softmax) and **Boundary Probability ($P_{bnd}^{(1)}$)** (1 ch, Sigmoid).

2.  **Inter-Stage Masking:**
    *   Explicitly multiply output tensors by the sequence mask to zero out padding (Cite solution_lesson_node_00035).

3.  **Stage 2: Gated Refinement**
    *   **Input:** $[P_{cls}^{(1)}, P_{bnd}^{(1)}]$.
    *   **Backbone:** **Gated MS-TCN** with **1x1 Output Projections**.
        *   $Z = \tanh(W_f * X) \odot \sigma(W_g * X)$.
        *   $H = W_{proj} * Z$ (Strictly retained, Cite solution_lesson_node_00107).
        *   $Y = X + H$.
    *   **Configuration:** 10 dilated layers ($1, 2, \dots, 512$), 256 channels, **No Instance Norm** (Cite solution_lesson_node_00066).
    *   **Output:** $[P_{cls}^{(2)}, P_{bnd}^{(2)}]$.

4.  **Stage 3: Dense Gated Sharpening**
    *   **Dense Input (Structural Innovation):** Concatenate outputs from **both** previous stages: $[P_{cls}^{(1)}, P_{bnd}^{(1)}, P_{cls}^{(2)}, P_{bnd}^{(2)}]$.
        *   *Motivation:* This allows Stage 3 to see the original "raw" predictions (rich in semantics) and the "refined" predictions (rich in temporal structure) simultaneously, enabling more informed sharpening than a purely sequential chain.
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions.

# Data
**Preprocessing:**
*   **Defensive Data Loading:** Robust parser that validates matrix dimensions and fails loudly on errors (Cite solution_lesson_node_00104).
*   **Normalization:** Center skeleton relative to HipCenter and **scale units to meters** (Cite solution_lesson_node_00084).
*   **Feature Selection:** **12 Upper-Body Joints** + **Audio** (Cite solution_lesson_node_00020).

**Augmentation:**
*   **Physically Consistent Augmentation:**
    1.  Generate Gaussian noise and apply **Temporal Low-Pass Filter**.
    2.  Add to **Raw Positions**.
    3.  **Derive** Temporal Velocity from augmented positions. (Cite solution_lesson_node_00059, solution_lesson_node_00064).

**Evaluation:**
*   **Deterministic Split:** Validation set with `is_train=False` (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification:** Weighted Cross-Entropy (0.1 Background : 1.0 Gesture) (Cite solution_lesson_node_00013).
*   **Boundary Supervision (Focal Loss):** Instead of standard BCE, use **Focal Loss** for the boundary heads.
    *   *Motivation:* Boundaries are extremely sparse (class imbalance ~1:50). Focal loss focuses gradients on these hard, sparse examples, providing a sharper signal to the Gated Units than standard BCE (Cite solution_lesson_node_00082).
*   **Smoothness:** **Unclamped T-MSE** on Softmax probabilities (Cite solution_lesson_node_00087).
*   **Masking:** Strict masking on all losses (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** (`lr=1e-3`, `weight_decay=1e-4`) (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize smoothness weight over parameter regularization (Cite solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Use Class Probability output of **Stage 3**.
2.  **Smoothing:** **Median Filter** on discrete labels (Cite solution_lesson_node_00049).
3.  **Padding:** **Nearest-Neighbor Padding** (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse repeats, remove background.
