The following script demonstrates the usage of the provided machine learning library for the gesture recognition task. It performs the following steps:

1.  **Setup**: Creates a temporary working directory and generates "mini" metadata files containing a small subset of the original data to ensure the demonstration runs quickly.
2.  **Configuration Patching**: Overrides the default configuration (paths, epochs, batch size) to point to the mini datasets and limit runtime.
3.  **Utility Verification**: Tests the Levenshtein distance calculation logic.
4.  **Data Loading**: Instantiates the `GestureDataset` and verifies that data is loaded, cached, and collated correctly into batches.
5.  **Model & Loss**: Initializes the `CASGCN` model, performs a forward pass with a batch of data, calculates the multi-stage loss, and verifies the output shapes and loss values.
6.  **Training Loop**: Runs a full training cycle for 1 epoch using the `train.run_training` function.
7.  **Inference**: Runs the inference pipeline using the trained model on the mini test set and generates a submission file.
8.  **Output Verification**: Validates the format and content of the generated submission file.
