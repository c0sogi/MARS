This script orchestrates the training, validation, failure analysis, and submission process for the IDC-RCN model. It first overrides specific configuration parameters to ensure the training completes within the time limit while maintaining sufficient capacity to learn. It then initializes the `Trainer` class, performs the training loop, and reloads the best checkpoint for evaluation. A detailed failure analysis is conducted on the validation set to correlate error rates with sequence properties (length and gesture count). Finally, if the validation performance meets the specified threshold, the script generates the submission file for the test set.
