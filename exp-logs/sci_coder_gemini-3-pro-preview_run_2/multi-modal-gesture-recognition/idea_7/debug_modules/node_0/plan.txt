The following script demonstrates the end-to-end usage of the provided library modules for the gesture recognition task. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory and reduced hyperparameters (fewer epochs, smaller model size, smaller batch size) to ensure the demonstration runs quickly.
2.  **Data Preparation**: Creates a small subset of the training, validation, and test metadata to simulate a quick run without processing the entire dataset.
3.  **Data Loading Verification**: Uses `get_dataloaders` to load the subset data and asserts that the batch shapes (features, masks, labels) are correct.
4.  **Model & Loss Verification**: Instantiates the `IDCRCN` model and `MultiStageLoss`, performs a forward pass with a dummy batch, and verifies that the loss calculation produces valid scalar values.
5.  **Training Loop Execution**: Initializes the `Trainer` and runs the `fit` method for one epoch to demonstrate the training process and early stopping logic.
6.  **Inference & Submission**: Runs the `predict` method to generate predictions on the test subset and verifies that the submission file is created with the correct format.
