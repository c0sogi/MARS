Based on the comprehensive analysis of previous experiments and the extracted lessons, I propose the **Boundary-Aware Masked Dual-Stage Cascaded Recurrent-Convolutional Network (BA-MD-CRCN)** with **Physically Consistent Smooth Augmentation**.

This strategy structurally evolves the current best "Masked Cascaded" architecture (Idea 9) by introducing an **explicit boundary detection mechanism** and an **adaptive smoothing objective**. This directly addresses the tension between "jitter reduction" (Lesson 6, 29) and "over-smoothing" (Lesson 31) by allowing the model to learn exactly where to break temporal continuity, rather than applying a global smoothing penalty. Additionally, it corrects the augmentation flaws identified in Lessons 59 and 64 by implementing a physically valid noise injection pipeline.

# Model
**Architecture: Boundary-Aware Masked Dual-Stage Cascaded Recurrent-Convolutional Network (BA-MD-CRCN)**
The model consists of three sequentially connected stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Multi-Task Generation (Recurrent Encoder)**
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain this backbone for its superior inductive bias for continuous dynamics (Cite solution_lesson_node_00025) and high capacity (Cite solution_lesson_node_00034).
    *   **Input:** Frame-wise feature vector (Upper-Body Skeleton + Velocity + Audio).
    *   **Heads:** The LSTM output is projected into two distinct streams:
        *   **Classification Head:** Outputs frame-wise Class Probabilities ($P_{cls}$) via Softmax (21 channels).
        *   **Boundary Head:** Outputs frame-wise **Boundary Probabilities** ($P_{bnd}$) via Sigmoid (1 channel). This explicitly predicts the probability of a transition event occurring at the current frame.
    *   **Output:** Concatenated tensor $[P_{cls}, P_{bnd}]$.

2.  **Inter-Stage Masking:**
    *   We explicitly multiply the output tensor by the sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Boundary-Aware Refinement (Deep TCN)**
    *   **Input:** The masked concatenated probabilities ($[P_{cls}, P_{bnd}]$) from Stage 1. By feeding the boundary probability into the TCN, the refinement network gains explicit cues on where to switch classes, reducing the reliance on implicit learning.
    *   **Backbone:** A **Single-Stage Temporal Convolutional Network (SS-TCN)** with **10 dilated residual layers** ($dilation=1, 2, \dots, 512$) to maximize receptive field (Cite solution_lesson_node_00034).
    *   **Output:** Refined Class Probabilities ($P'_{cls}$) and Refined Boundary Probabilities ($P'_{bnd}$).

4.  **Stage 3: Fine Sharpening (Deep TCN)**
    *   **Input:** Output from Stage 2.
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions ($P''_{cls}, P''_{bnd}$).

# Data
**Preprocessing:**
*   **Feature Selection:** Strictly limit skeletal inputs to the **12 Upper-Body Joints** and **Audio MFCCs** (Cite solution_lesson_node_00020).
*   **Defensive Loading:** Explicitly handle matrix dimension transpositions (Cite solution_lesson_node_00048).
*   **Target Generation:** Generate ground-truth boundary labels ($Y_{bnd}$) by marking frames where the gesture label changes (i.e., $y_t \neq y_{t-1}$) as 1, and others as 0.

**Augmentation (Structural Innovation):**
*   **Physically Consistent Smooth Noise:** To address the failures of independent noise injection (Cite solution_lesson_node_00064), we implement a **temporally correlated noise** pipeline:
    1.  Generate white Gaussian noise for the sequence.
    2.  Apply a **Low-Pass Filter** (smoothing) to the noise tensor to create smooth random trends.
    3.  Add this smooth noise to the **Raw 3D Joint Positions**.
    4.  **Derive** the Temporal Velocity from the augmented positions.
    *   This ensures that the velocity features remain physically consistent with the position features, preserving signal integrity (Cite solution_lesson_node_00059).

**Validation:**
*   **Deterministic Split:** Instantiate validation with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Task Deep Supervision:** Minimize $L_{total} = L_{stage1} + L_{stage2} + L_{stage3}$.
*   **Classification Loss ($L_{cls}$):** Weighted Cross-Entropy (Ratio 0.1 Background : 1.0 Gesture) (Cite solution_lesson_node_00013).
*   **Boundary Loss ($L_{bnd}$):** Weighted Binary Cross-Entropy to handle the extreme sparsity of boundary frames (e.g., weight positive samples by 10x).
*   **Adaptive Probability-Space Smoothing ($L_{smooth}$):**
    *   We modify the T-MSE loss to be **boundary-adaptive**.
    *   $L_{smooth} = \frac{1}{N} \sum_{t} (1 - Y_{bnd}^{(t)}) \cdot ||P_{cls}^{(t)} - P_{cls}^{(t-1)}||^2$
    *   **Mechanism:** This term enforces smoothness *only* when the ground truth indicates there is **no boundary**. At transition frames ($Y_{bnd}=1$), the penalty is removed, allowing the model to make sharp, confident switches without incurring a smoothing cost. This resolves the over-smoothing trade-off (Cite solution_lesson_node_00031).
    *   Computed on **Softmax probabilities** (Cite solution_lesson_node_00033).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4`. We prioritize AdamW over Adam to ensure proper decoupled regularization (Cite solution_lesson_node_00067, solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax) to merge fragmented segments (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse repeats and remove background labels.
