The `RuntimeError` occurs because the custom loss module `DeepSupervisionLoss` contains internal state (specifically, the class weights buffer in `MaskedWeightedCrossEntropy`) which resides on the CPU by default. When the model and data are on the GPU, calculating the loss causes a device mismatch. To resolve this, the loss module must be explicitly moved to the computation device using `.to(device)`, treating it like a model as described in **debug_lesson_4**. I will apply this fix to the instantiation of `criterion` in `runfile.py`, `library/train_eval.py`, and `library/model.py`.
