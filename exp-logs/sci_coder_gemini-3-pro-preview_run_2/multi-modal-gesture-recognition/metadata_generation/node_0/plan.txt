Implementation strategy:
1.  **Setup and Imports**: Import necessary libraries (`os`, `glob`, `pandas`, `numpy`, `scipy.io`, `shutil`, `sklearn`). Define the input and metadata directories.
2.  **Gesture Mapping**: Define a dictionary mapping the 20 Italian gesture names to their integer labels (1-20) as specified in the task description.
3.  **MAT File Parsing**: Implement a function `parse_mat_file` to read the `_data.mat` files using `scipy.io.loadmat`. This function will extract the `Labels` (converting names to IDs) and `NumFrames`. It will handle potential variations in the MAT file structure (e.g., empty labels, single label, multiple labels).
4.  **Data Scanning**: Implement a function `get_samples` that iterates through the specified subdirectories (`training1`, `training2`, `training3`, `test`). It will identify samples based on the `_data.mat` files, construct relative paths for all modalities (RGB, Depth, Audio, User, Data), and parse the labels for training data.
5.  **Dataset Construction**:
    *   Scan `training1`, `training2`, and `training3` to build the full training dataset.
    *   Scan `test` to build the test dataset.
6.  **Validation Split**: Split the full training dataset into a training set (80%) and a validation set (20%) using `train_test_split` with a fixed random seed (`42`).
7.  **Metadata Export**: Save the resulting DataFrames to `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
8.  **Verification**: Implement a `verify_metadata` function to print statistics (sample counts, unique gestures) and check for missing files by randomly sampling paths from the generated metadata. This ensures the metadata is accurate and points to existing files.
