Based on the comprehensive analysis of the accumulated lessons, specifically the superior performance of **Gated Activation Units** with **Explicit Supervision** (Cite solution_lesson_node_00099) and the identified trade-off between global context and local boundary precision (Cite solution_lesson_node_00018, solution_lesson_node_00031), I propose the **Dual-Scale Supervised Gated-Cascaded Recurrent-Convolutional Network (DSG-CRCN)**.

This strategy structurally evolves the current best architecture (RSG-CRCN) by replacing the single-stream Gated TCN blocks with **Dual-Scale Gated Blocks**. This innovation addresses the tension between smoothing high-frequency jitter (requiring large receptive fields) and preserving sharp transitions (requiring local fidelity) by processing features at two temporal scales simultaneously within the refinement stages.

# Model
**Architecture: Dual-Scale Supervised Gated-Cascaded Recurrent-Convolutional Network (DSG-CRCN)**
The model consists of three sequentially connected stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Multi-Task Recurrent Encoder**
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units). We retain this backbone for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025) and high capacity (Cite solution_lesson_node_00034).
    *   **Input:** Frame-wise feature vector (Upper-Body Skeleton + Velocity + Audio), fused via simple concatenation (Cite solution_lesson_node_00062).
    *   **Heads:** The LSTM output is projected into two distinct streams:
        *   **Class Probabilities ($P_{cls}$):** 21 channels (Softmax).
        *   **Boundary Probability ($P_{bnd}$):** 1 channel (Sigmoid).
    *   **Output:** Concatenated tensor $[P_{cls}, P_{bnd}]$.

2.  **Inter-Stage Masking:**
    *   We explicitly multiply the concatenated output tensor by the binary sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Dual-Scale Gated Refinement**
    *   **Structural Innovation:** We replace the single-stream Gated Blocks with **Dual-Scale Gated Blocks**.
        *   **Parallel Branches:** Each block processes the input through two parallel paths:
            1.  **Global Branch:** Dilated Convolution ($d=2^i$) followed by a Gated Activation Unit ($\tanh \odot \sigma$). This captures long-range context to suppress jitter.
            2.  **Local Branch:** Fixed Low-Dilation Convolution ($d=1$) followed by a Gated Activation Unit. This preserves high-frequency boundary details often lost in deep dilated networks.
        *   **Fusion:** The outputs of both branches are concatenated and projected back to the original channel width via a $1 \times 1$ convolution.
    *   **Configuration:** 10 layers deep. We use **128 channels per branch** (concatenating to 256) to maintain the high capacity identified as critical (Cite solution_lesson_node_00078). We explicitly **exclude Instance Normalization** to preserve the magnitude of sparse probability inputs (Cite solution_lesson_node_00066).
    *   **Input:** The masked tensor $[P_{cls}, P_{bnd}]$ from Stage 1.
    *   **Output:** Refined Class Probabilities ($P'_{cls}$) and Refined Boundary Probability ($P'_{bnd}$).

4.  **Stage 3: Dual-Scale Sharpening**
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions ($P''_{cls}, P''_{bnd}$).

# Data
**Preprocessing:**
*   **Normalization (Crucial):** Explicitly **center** the skeleton data relative to the HipCenter and **scale the units from millimeters to meters** (multiply by 0.001). This prevents saturation of the Gated Units (Cite solution_lesson_node_00084).
*   **Feature Selection:** Strictly limit inputs to **12 Upper-Body Joints** and **Audio MFCCs** (Cite solution_lesson_node_00020).
*   **Target Generation:** Generate ground-truth boundary labels ($Y_{bnd}$) where $1$ indicates a frame-to-frame label change.

**Augmentation:**
*   **Physically Consistent Smooth Noise:** Implement the temporally correlated noise pipeline.
    1.  Generate Gaussian noise and apply a **Temporal Low-Pass Filter**.
    2.  Add this smooth noise to the **Raw 3D Joint Positions**.
    3.  **Derive** the Temporal Velocity from the augmented positions.
    *   This ensures velocity features remain physically consistent, avoiding jitter caused by independent noise injection (Cite solution_lesson_node_00064). We avoid aggressive geometric rotation (Cite solution_lesson_node_00067).

**Evaluation Data:**
*   **Deterministic Split:** Instantiate the validation set with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification Loss:** Weighted Cross-Entropy with a strict ratio of **0.1 (Background) : 1.0 (Gesture)** (Cite solution_lesson_node_00013).
*   **Boundary Loss (Crucial):** Weighted Binary Cross-Entropy on the boundary heads. This provides the **explicit supervision** required to drive the Gated Units effectively (Cite solution_lesson_node_00082).
*   **Unclamped Probability-Space Smoothing:** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities** of the classification heads. We do **not clamp** the loss (Cite solution_lesson_node_00087) and use Softmax rather than Log-Softmax (Cite solution_lesson_node_00033). We do not condition this loss on the boundary prediction to avoid fragility (Cite solution_lesson_node_00070).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4` (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize output smoothness (T-MSE weight) over aggressive parameter regularization (Cite solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax). This merges fragmented segments more effectively than probability filtering (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to prevent the deletion of valid gestures at sequence edges (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse consecutive repeated labels and remove the background class.
