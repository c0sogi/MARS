Based on the rigorous empirical analysis of the accumulated lessons—specifically the state-of-the-art performance of the **Multi-Granularity Hybrid** architecture (Cite solution_lesson_node_00120), the critical role of **Explicit Feature Engineering** (Cite solution_lesson_node_00113), and the potential of **Geometric Features** (Cite solution_lesson_node_00020) when supported by a robust architecture (Cite solution_lesson_node_00107)—I propose the **Geometric Multi-Granularity Convolutional-Recurrent Gated Network (GMG-CRGN)**.

This strategy structurally evolves the current best solution (Idea 39) by re-integrating **Bone Vectors** into the feature set. While Lesson 106 warned against "feature bloat," that failure was confounded by the removal of the critical 1x1 output projection (Cite solution_lesson_node_00107) and the use of redundant hierarchical losses. By restoring the robust Gated TCN block with projections and leveraging the **Multi-Granularity Stem** to efficiently process high-dimensional inputs, this solution captures the full kinematic state (Position + Shape + Dynamics) without architectural fragility.

# Model
**Architecture: Geometric Multi-Granularity Convolutional-Recurrent Gated Network (GMG-CRGN)**
The model consists of a Geometric Hybrid Encoder and two Refinement Stages trained end-to-end with Deep Supervision.

1.  **Stage 1: Geometric Multi-Granularity Encoder**
    *   **Feature Expansion (Structural Innovation):** The input vector is expanded to include **Upper-Body Skeleton Positions ($P$)**, **Explicit Temporal Velocities ($V$)**, **Bone Vectors ($B$)**, and **Audio MFCCs**.
        *   *Bone Vectors:* Calculated as the 3D vector difference between connected joint pairs (e.g., Elbow-Wrist). This provides a translation-invariant representation of pose structure (Cite solution_lesson_node_00020).
        *   *Explicit Dynamics:* Velocity is strictly retained to provide inductive bias for motion (Cite solution_lesson_node_00113).
    *   **Multi-Granularity Stem:** The concatenated input flows into **three parallel 1D Convolutional branches** with varying kernel sizes ($k=3, 7, 11$).
        *   *Motivation:* This mechanism extracts motion primitives at multiple temporal resolutions (micro-jitter vs. contextual trends) *before* the recurrent modeling, effectively managing the increased dimensionality of the geometric features (Cite solution_lesson_node_00120). Each branch uses Batch Normalization and ReLU.
    *   **Backbone:** A **Bi-Directional LSTM** (2 layers, 256 hidden units) processes the stem's concatenated output. We retain this for its superior inductive bias for continuous temporal dynamics (Cite solution_lesson_node_00025).
    *   **Heads:** The LSTM output is projected into two distinct streams:
        *   **Class Probabilities ($P_{cls}$):** 21 channels (Softmax).
        *   **Boundary Probability ($P_{bnd}$):** 1 channel (Sigmoid).
    *   **Output:** Concatenated tensor $[P_{cls}, P_{bnd}]$.

2.  **Inter-Stage Masking:**
    *   We explicitly multiply the concatenated output tensor by the binary sequence mask to zero out padding, preventing noise propagation (Cite solution_lesson_node_00035).

3.  **Stage 2: Gated Refinement (Gated MS-TCN)**
    *   **Input:** Concatenated probabilities $[P_{cls}, P_{bnd}]$. We use concatenation as it outperforms explicit modulation (Cite solution_lesson_node_00109).
    *   **Block Architecture:** **Gated Activation Blocks** with **1x1 Output Projections**.
        *   $Z = \tanh(W_f * X) \odot \sigma(W_g * X)$.
        *   $H = W_{proj} * Z$. **Crucial:** We strictly retain this 1x1 projection to facilitate gradient flow and feature alignment, preventing the degradation observed in previous attempts (Cite solution_lesson_node_00107).
        *   $Y = X + H$.
    *   **Configuration:** 10 dilated layers with **Monotonically Increasing Dilation** ($1, 2, \dots, 512$) (Cite solution_lesson_node_00101). We maintain **256 channels** (Cite solution_lesson_node_00078) and explicitly **exclude Instance Normalization** (Cite solution_lesson_node_00066).
    *   **Output:** Refined $[P'_{cls}, P'_{bnd}]$.

4.  **Stage 3: Gated Sharpening**
    *   **Connectivity:** Strictly Cascaded. Stage 3 receives only the output of Stage 2, avoiding the noise re-introduction caused by dense connections (Cite solution_lesson_node_00115).
    *   **Backbone:** Identical to Stage 2.
    *   **Output:** Final predictions.

# Data
**Preprocessing:**
*   **Defensive Data Loading:** Implement a robust parser that explicitly validates matrix dimensions and transposes if necessary, failing loudly on errors (Cite solution_lesson_node_00104, solution_lesson_node_00048).
*   **Normalization (Crucial):** Explicitly **center** the skeleton data relative to the HipCenter and **scale the units from millimeters to meters** (multiply by 0.001). This prevents saturation of the Gated Units (Cite solution_lesson_node_00084).
*   **Feature Selection:** Strictly limit inputs to **12 Upper-Body Joints** (Pos + Vel + Bones) and **Audio MFCCs**, discarding lower-body noise (Cite solution_lesson_node_00020).

**Augmentation:**
*   **Physically Consistent Augmentation:** Implement the temporally correlated noise pipeline.
    1.  Generate Gaussian noise and apply a **Temporal Low-Pass Filter**.
    2.  Add this smooth noise to the **Raw 3D Joint Positions**.
    3.  **Derive** both **Temporal Velocity** and **Bone Vectors** from the augmented positions.
    *   This ensures all geometric features remain physically consistent with the perturbed positions, avoiding the jitter caused by independent noise injection (Cite solution_lesson_node_00059, solution_lesson_node_00064).

**Evaluation Data:**
*   **Deterministic Split:** Instantiate the validation set with **augmentation disabled** (`is_train=False`) (Cite solution_lesson_node_00011).

# Training
**Loss Function:**
*   **Multi-Stage Deep Supervision:** Minimize $L_{total} = \sum_{s=1}^{3} (L_{cls}^{(s)} + L_{bnd}^{(s)} + L_{smooth}^{(s)})$.
*   **Classification Loss:** Weighted Cross-Entropy with a strict ratio of **0.1 (Background) : 1.0 (Gesture)** (Cite solution_lesson_node_00013).
*   **Boundary Supervision:** **Focal Loss** applied to the boundary heads.
    *   *Motivation:* Transition frames are extremely sparse. Focal Loss focuses the training signal on these hard examples, providing a sharper supervisory signal to the Gated Units than standard BCE (Cite solution_lesson_node_00118, solution_lesson_node_00082).
*   **Unclamped Probability-Space Smoothing:** Apply **Truncated Mean Squared Error (T-MSE)** to the **Softmax probabilities**. We do **not clamp** the loss (Cite solution_lesson_node_00087).
*   **Strict Masking:** Apply sequence masks to all loss terms (Cite solution_lesson_node_00035).

**Optimization:**
*   **Optimizer:** **AdamW** with learning rate `1e-3` and weight decay `1e-4` (Cite solution_lesson_node_00067).
*   **Strategy:** Prioritize output smoothness (T-MSE weight) over aggressive parameter regularization (Cite solution_lesson_node_00068).

# Evaluation
**Inference Pipeline:**
1.  **Forward Pass:** Generate predictions using the Class Probability output of **Stage 3**.
2.  **Label-Space Smoothing:** Apply a **Median Filter** to the discrete class labels (post-argmax). This merges fragmented segments more effectively than probability filtering (Cite solution_lesson_node_00049).
3.  **Boundary Protection:** Use **Nearest-Neighbor Padding** during filtering to prevent the deletion of valid gestures at sequence edges (Cite solution_lesson_node_00009).
4.  **Decoding:** Collapse consecutive repeated labels and remove the background class.
