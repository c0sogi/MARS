The following script orchestrates the training, validation, analysis, and submission pipeline for the gesture recognition task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We override the default epoch count to 20 to create a fast baseline that fits within the time constraints while allowing sufficient convergence. We ensure reproducibility by setting the random seed.
2.  **Data Loading**: We utilize the `get_dataloaders` function with `load_cached_data=True` to efficiently load the pre-processed training and validation data.
3.  **Training Loop**: We implement a custom training loop that iterates for the defined epochs. Inside the loop, we perform forward passes, backward passes (optimization), and validation steps using the provided `train_one_epoch` and `validate` functions. We track the validation score (Levenshtein error rate) and save the model checkpoint whenever a new best score is achieved.
4.  **Final Evaluation**: After training, we reload the best model checkpoint and compute the `Final Validation Metric` on the full validation set, printing it in the required format.
5.  **Failure Analysis**: We perform a failure analysis by iterating through the validation set in evaluation mode. We compute the Levenshtein distance for each sample and calculate the Pearson correlation between the error magnitude and input features (sequence length and number of gestures) to identify systematic weaknesses.
6.  **Conditional Submission**: We compare the final validation metric against the specified threshold (0.09294436906377204). If the model's performance meets the criteria, we invoke the `generate_predictions` function to create the submission file; otherwise, we skip this step.
