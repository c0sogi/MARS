The following script demonstrates the end-to-end usage of the provided machine learning library for the gesture recognition task. It performs the following steps:

1.  **Configuration & Setup**: Modifies the global `Config` to use a temporary working directory and reduces hyperparameters (epochs, batch size) for a fast demonstration.
2.  **Data Preparation**: Creates small subsets of the provided metadata (train, val, test) to ensure the data loading and processing steps complete quickly.
3.  **Data Loading**: Uses `get_dataloaders` to process the raw multimodal data (Skeleton, Audio) from the subsets into PyTorch DataLoaders. It verifies the shape of the generated batches.
4.  **Model Initialization**: Instantiates the `SBMD_CRCN` model and performs a forward pass to verify output dimensions.
5.  **Loss Computation**: Calculates the multi-objective loss using `CombinedLoss` and asserts the validity of the loss value.
6.  **Training & Validation**: Runs a single epoch of training and validation using the `train_one_epoch` and `validate` functions, checking that model parameters are updated.
7.  **Inference**: Generates predictions on the test subset using `generate_predictions` and verifies the format of the output submission file.
