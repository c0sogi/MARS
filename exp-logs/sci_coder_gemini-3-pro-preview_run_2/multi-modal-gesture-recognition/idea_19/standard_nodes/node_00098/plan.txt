The implementation strategy involves the following steps:

1.  **Configuration & Setup**: Import the provided `Config` class and override specific parameters (e.g., `NUM_EPOCHS`) to ensure the training runs quickly as a baseline. Set the random seed and detect the computation device (GPU/CPU).
2.  **Data Loading**: Use the `get_data_loaders` function from the `library.data_loader` module to load the training, validation, and test datasets. Enable caching to expedite data loading.
3.  **Model Initialization**: Instantiate the `RSG_CRCN` model from `library.model` and move it to the configured device.
4.  **Training**: Initialize the `Trainer` from `library.trainer` and execute the `fit()` method. This handles the training loop, validation, early stopping, and model checkpointing.
5.  **Validation & Metric Reporting**: Retrieve the best validation metric (Levenshtein Error Rate) from the trainer and print it in the required format.
6.  **Failure Analysis**: Load the best saved model and perform inference on the validation set. Calculate the Levenshtein distance for each sample and compute correlations between this error and input characteristics (sequence length, number of gestures). Print these correlations.
7.  **Submission Generation**: Check if the final validation metric meets the specified threshold. If successful, run inference on the test set, apply the median filter and decoding logic, and generate the `submission.csv` file in the required format.
