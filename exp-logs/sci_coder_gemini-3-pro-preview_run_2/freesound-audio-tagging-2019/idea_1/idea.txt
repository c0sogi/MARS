To establish a robust and highly efficient baseline for the audio tagging task, I propose a solution centered on a lightweight 2D Convolutional Neural Network (CNN). This approach prioritizes computational speed and architectural simplicity while effectively handling the multi-label classification requirements.

### Model
The core architecture is a streamlined **2D CNN** inspired by the efficiency of MobileNet designs (referenced in Model 1).
*   **Input**: The model accepts single-channel Log-Mel Spectrograms as input, treating audio data as 2D images where one axis represents time and the other frequency.
*   **Backbone**: The network is constructed using a stack of **Inverted Residual Blocks**. These blocks utilize **Depthwise Separable Convolutions** to significantly reduce the number of parameters and floating-point operations compared to standard convolutions. Each block consists of a point-wise expansion, a depth-wise convolution for spatial feature extraction, and a point-wise projection back to a lower channel dimension.
*   **Aggregation & Head**: A Global Average Pooling (GAP) layer is applied after the final convolutional block to collapse the time and frequency dimensions into a single feature vector. This allows the model to handle input spectrograms of variable lengths natively. The resulting vector is passed through a single fully connected linear layer with 80 output units, followed by a Sigmoid activation function to produce independent probabilities for each class.

### Data
Preprocessing focuses on converting raw audio into a consistent spectral representation suitable for the 2D CNN.
*   **Audio Loading**: Audio files are decoded and resampled to a fixed sample rate (e.g., 32 kHz) to standardize the input bandwidth and reduce data size compared to the original 44.1 kHz.
*   **Spectrogram Generation**: Short-Time Fourier Transform (STFT) is applied to the waveforms, followed by mapping to the Mel scale (e.g., 128 Mel bands) to approximate human hearing sensitivity. The magnitude spectrograms are then converted to a logarithmic scale (Log-Mel Spectrograms).
*   **Formatting**:
    *   **Training**: To enable efficient batching, training clips are randomly cropped or padded with zeros to a fixed duration (e.g., 10 seconds).
    *   **Normalization**: Input spectrograms are normalized instance-wise (zero mean, unit variance) or using global dataset statistics to stabilize training.

### Training
The training procedure is designed for stability and convergence speed.
*   **Loss Function**: **Binary Cross-Entropy (BCE) with Logits Loss** is used, which is the standard objective for multi-label classification tasks where classes are not mutually exclusive.
*   **Optimizer**: The **Adam** optimizer is employed for its adaptive learning rate capabilities, requiring minimal tuning.
*   **Dataset Usage**: The model is trained on the combined dataset (Curated + Noisy) to maximize the diversity of training examples. The Curated Validation set is used to monitor performance and trigger early stopping if the validation loss plateaus.
*   **Strategy**: A simplified learning rate schedule (e.g., reducing the learning rate by a factor of 10 upon validation plateau) is used to fine-tune the weights as training progresses. No heavy augmentations (like Mixup or SpecAugment) are applied to maintain the "baseline" philosophy.

### Evaluation
Inference is performed to generate clip-level predictions for the test set.
*   **Processing**: Test audio files undergo the same resampling, spectrogram generation, and normalization steps as the training data.
*   **Variable Length Inference**: Thanks to the Global Average Pooling layer, the model is applied directly to the full-length spectrogram of each test clip without the need for cropping or sliding windows. This ensures the entire audio context is considered for the prediction.
*   **Output**: The raw logits from the model are passed through a Sigmoid function to obtain probability scores (0 to 1) for all 80 categories, which are then formatted into the required submission structure.
