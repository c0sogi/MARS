To implement the audio tagging baseline, I will create a script that orchestrates the entire machine learning pipeline using the provided library modules.

### Implementation Strategy

1.  **Configuration & Setup**: I will start by importing the necessary modules and setting the random seed for reproducibility. To ensure the baseline runs quickly within the time limit, I will override `Config.MAX_EPOCHS` to 5. I will also detect the available hardware (GPU) for accelerated processing.
2.  **Data Loading**: I will utilize `library.dataset.get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test datasets. This leverages the pre-processed parquet files if they exist.
3.  **Model Initialization**: I will instantiate the `AudioMobileNet` model defined in `library.model` and move it to the configured device (GPU).
4.  **Training & Submission**: I will call `library.engine.run`. This function encapsulates the training loop, validation monitoring, learning rate scheduling, and early stopping. Crucially, it automatically loads the best model checkpoint at the end of training and generates the submission file (`submission.csv`) for the test set.
5.  **Validation Assessment**: After the `run` function completes (ensuring the model is in its best state), I will explicitly call `library.engine.validate` on the validation loader to compute the final LWLRAP score. I will print this in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: I will implement a `failure_analysis` function that iterates through the validation set in inference mode. It will calculate the per-sample Binary Cross-Entropy (BCE) loss to quantify error magnitude. Simultaneously, it will retrieve the audio duration for each file using `soundfile`. Finally, it will compute and print the Pearson correlation between the error magnitude and the audio duration to identify if clip length influences model performance.
