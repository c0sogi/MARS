The issue is a "silent failure" in the data loading process. The `DataFactory.build_file_index` method reads the input JSONL file in binary mode (`"rb"`) but attempts to parse the lines using `json.loads` without explicitly decoding them to strings. In this environment, this likely raises exceptions (e.g., `JSONDecodeError` or `TypeError`) which are caught and ignored by the `try...except` block inside the loop. Consequently, the function returns an empty `offsets` dictionary. This empty index is then used to filter the metadata, resulting in an empty dataset, which causes the `DataLoader` to crash with `ValueError: num_samples=0`.

To fix this, I will:
1.  **Explicitly decode** binary lines to UTF-8 strings before parsing in `library/data_factory.py`, `library/inference_pipeline.py`, and `runfile.py`.
2.  **Fail fast** by asserting that the built index is not empty in `DataFactory.build_file_index`, raising a `RuntimeError` if no data was loaded (Cite debug_lesson_4).
3.  Add a check in `NQDataset` to ensure the dataset is not empty after filtering.
