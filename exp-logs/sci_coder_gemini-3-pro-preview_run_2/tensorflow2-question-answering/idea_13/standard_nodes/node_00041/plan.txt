The `CUDA error: device-side assert triggered` is caused by an index out-of-bounds error in the target labels for the span end prediction. The Natural Questions dataset uses exclusive end indices, but the `WindowProcessor` was using these directly as classification targets. If an answer span ends at the window boundary (e.g., index 128 for a window size of 128), the label becomes 128, which is invalid for a 0-indexed classification task (valid indices 0-127). I will fix this by converting the end index to be inclusive (subtracting 1) in `library/window_processor.py`. I will also update the inference logic in `library/solver.py` and the evaluation logic in `runfile.py` to convert the inclusive predictions back to exclusive indices for the final output. Finally, I will force the data cache to regenerate in `runfile.py` to ensure the corrected labels are used (Cite debug_lesson_2).
