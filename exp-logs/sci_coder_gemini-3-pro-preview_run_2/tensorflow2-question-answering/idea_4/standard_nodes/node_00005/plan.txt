Implementation Strategy:
1.  **Setup & Data Loading**: Initialize the environment and load the vocabulary and embedding matrix using the provided library functions. Create `NQDataset` instances for training (subsampled for speed), validation, and testing. Use `DataLoader` for efficient batching.
2.  **Model & Training**: Instantiate the `SiameseBiLSTM` model. Train for a limited number of epochs using `train_one_epoch` and monitor performance with `evaluate`. Save the best model state.
3.  **Inference & Aggregation**: Implement an inference loop that processes batches and aggregates predictions by `example_id`. Since the dataset provides candidate-level samples, we must group them to find the best candidate for each question.
4.  **Validation & Failure Analysis**: On the validation set, compare predictions against ground truth (loaded from raw data via the dataset map) to compute the Micro F1 score. Calculate correlations between F1 scores and metadata features (question length, candidate length) to identify error sources.
5.  **Submission Generation**: Run inference on the test set. Apply the confidence threshold to decide between outputting an answer or leaving it blank. Format the outputs (Long Answer indices, Short Answer indices/Yes/No) into the required CSV format.
