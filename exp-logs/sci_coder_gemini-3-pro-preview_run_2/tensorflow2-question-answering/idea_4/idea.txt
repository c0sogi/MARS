### Proposed Baseline: Siamese Recurrent Dual-Encoder with Trainable Span Heads

This approach establishes a baseline using Recurrent Neural Networks (RNNs), specifically Bi-LSTMs, which capture global sequential dependencies in text that Bag-of-Embeddings (Idea 1) and Convolutional (Idea 3) models might miss. It distinguishes itself from previous ideas by replacing heuristic short-answer extraction with fully trainable prediction heads, allowing the model to learn span boundaries directly from data.

#### Model
The architecture is a **Multi-Task Siamese Network** designed to handle long answer ranking, short answer extraction, and yes/no classification within a single efficient pass.

*   **Embedding Layer:** Input text is converted into dense vectors using pre-trained static embeddings (e.g., GloVe). These embeddings are frozen during training to minimize computational overhead.
*   **Shared Encoder:** A shared **Bi-Directional LSTM (Long Short-Term Memory)** processes the Question and the Long Answer Candidate independently. This generates a sequence of hidden states for the candidate ($H_c$) and the question ($H_q$).
*   **Long Answer Module (Ranking):**
    *   **Pooling:** The sequence of hidden states for both inputs is aggregated into single fixed-size vectors ($v_q$ and $v_c$) using **Global Max Pooling**. This captures the most salient features of the sequences.
    *   **Scoring:** The relevance score is calculated using the **Cosine Similarity** between $v_q$ and $v_c$. This score represents the probability that the candidate contains the answer.
*   **Short Answer Module (Span Prediction):**
    *   **Context Conditioning:** The pooled question vector $v_q$ is repeated and concatenated with every time-step of the candidate's unpooled sequence $H_c$. This conditions the candidate representation on the question context.
    *   **Span Heads:** The combined sequence is fed into two parallel linear layers: one to predict the **Start Token** probability and one for the **End Token** probability.
*   **Yes/No Module:**
    *   The pooled vectors $v_q$ and $v_c$ are concatenated and passed through a small Multi-Layer Perceptron (MLP) to predict a 3-class probability distribution: `YES`, `NO`, or `NONE`.

#### Data
*   **Preprocessing:**
    *   **Tokenization:** Text is split on whitespace. Punctuation is retained as separate tokens.
    *   **Padding:** Question sequences are padded to a short fixed length (e.g., 20 tokens), and candidates to a moderate length (e.g., 300 tokens) to accommodate LSTM processing.
    *   **Vocabulary:** Tokens are mapped to indices based on the pre-trained embedding vocabulary.
*   **Labeling:**
    *   **Long Answer:** Binary label (1 if the candidate matches the ground truth, 0 otherwise).
    *   **Short Answer:** Start and End indices relative to the candidate text. If no short answer exists, indices are set to 0 (a reserved "no answer" token).
    *   **Yes/No:** One-hot encoded labels for the three classes.

#### Training
*   **Strategy:** The model is trained using a **Multi-Task Learning** objective. All three heads (Ranking, Span, Yes/No) are optimized simultaneously.
*   **Sampling:** To handle class imbalance, **Random Negative Sampling** is applied. Each training batch consists of positive question-candidate pairs and a fixed ratio of negative pairs sampled from the same document.
*   **Loss Function:** A weighted sum of three losses is minimized:
    1.  **Ranking Loss:** Binary Cross-Entropy for the long answer score.
    2.  **Span Loss:** Sparse Categorical Cross-Entropy for the start and end token indices.
    3.  **Class Loss:** Categorical Cross-Entropy for the Yes/No classification.
*   **Optimizer:** The Adam optimizer is used with a standard learning rate.

#### Evaluation
1.  **Inference:** For a test example, the model processes the question paired with every long answer candidate.
2.  **Long Answer Selection:** Candidates are ranked by their cosine similarity scores. The candidate with the highest score is selected. If this score is below a tuned **confidence threshold**, the prediction defaults to `BLANK`.
3.  **Short Answer Extraction:** For the selected candidate, the indices with the highest logits from the Start and End heads are chosen. If the model predicts the reserved "no answer" index or if the confidence is low, the short answer is left blank.
4.  **Yes/No Prediction:** The class with the highest probability from the Yes/No head is assigned. If `NONE` is dominant, no Yes/No label is output.
