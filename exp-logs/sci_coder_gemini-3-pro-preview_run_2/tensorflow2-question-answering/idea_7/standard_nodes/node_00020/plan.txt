Implementation strategy:
1.  **Configuration Patching**: Modify `Config` parameters at runtime to ensure the training completes quickly (reduce epochs, enable debug mode with a subset of data).
2.  **Vocabulary Initialization**: Check for the existence of the vocabulary cache. If missing, read a sample of the training data, fit the `Tokenizer`, and save the vocabulary to ensure the `Trainer` and `Evaluator` can initialize correctly.
3.  **Model Training**: Instantiate the `Trainer` class and run the `fit()` method to train the model.
4.  **Validation & Metric Calculation**:
    *   Load the validation dataset.
    *   Run inference to select the best candidate per `example_id`.
    *   Compare predictions against ground truth labels derived from the dataset.
    *   Calculate the Micro F1 score for both long and short answers combined.
5.  **Failure Analysis**:
    *   During validation, track metadata (question length, candidate length) and error status (correct/incorrect).
    *   Calculate the Pearson correlation between these features and the error magnitude (1 - accuracy).
6.  **Submission Generation**: Instantiate the `Evaluator` class and generate the submission file using the trained model.
