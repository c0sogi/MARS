### Proposed Baseline: Global-Context Pointwise Network

This approach establishes a highly efficient neural baseline that avoids the computational complexity of recurrent layers (RNNs), convolutions (CNNs), or dense alignment matrices. Instead, it relies on a "pointwise" architecture that processes each word in the candidate text independently, conditioned on a global summary of the question. This design is significantly faster than the Siamese or Matrix-based approaches while still supporting fully trainable span prediction.

#### **Model**
*   **Embedding Layer:** The model utilizes pre-trained static word embeddings (e.g., GloVe) to convert tokens into dense vectors. These embeddings are frozen to minimize memory usage and training time.
*   **Question Encoder:** The variable-length question sequence is aggregated into a single fixed-size context vector using a learnable **Attention-Weighted Average**. This compresses the query into a global semantic summary.
*   **Context Broadcasting:** The global question vector is replicated (broadcast) and concatenated with the embedding of *every* token in the long answer candidate. This step explicitly conditions each word of the candidate text on the question's intent.
*   **Pointwise Encoder:** A shared **Feed-Forward Neural Network (MLP)** processes each candidate token (paired with the question context) independently. Unlike RNNs or CNNs, this layer does not look at neighboring words; it simply assesses the relevance of each individual token to the question, generating a sequence of token-level feature vectors.
*   **Ranking Head:** A **Global Max Pooling** operation aggregates the sequence of token vectors into a single document representation. This representation is passed to a binary classifier to predict the **Long Answer Score**.
*   **Span Prediction Heads:** The sequence of token-level feature vectors (preserving the original length) is fed into two parallel linear layers to predict the **Start Token** and **End Token** probabilities for the short answer.
*   **Yes/No Head:** The pooled document representation is passed to a classifier to predict the probabilities for `YES`, `NO`, or `NONE`.

#### **Data**
*   **Preprocessing:**
    *   **Tokenization:** Input text is tokenized using a fast whitespace splitter.
    *   **Padding:** Question sequences are padded to a short fixed length (e.g., 20 tokens), and long answer candidates are padded/truncated to a moderate fixed length (e.g., 300 tokens) to allow for efficient batch processing.
*   **Labeling:**
    *   **Long Answer:** Binary labels (`1` if the candidate matches the ground truth, `0` otherwise).
    *   **Short Answer:** Start and End indices relative to the candidate text. If no short answer exists, indices point to a reserved "null" position.
    *   **Yes/No:** One-hot encoded categorical labels.

#### **Training**
*   **Strategy:** The model is trained using a **Multi-Task Learning** objective, optimizing all heads simultaneously.
*   **Sampling:** To address class imbalance, **Random Negative Sampling** is employed. Each training batch consists of positive question-candidate pairs and a fixed ratio of randomly selected negative pairs from the same document.
*   **Loss Function:** A weighted sum of three loss components is minimized:
    *   **Binary Cross-Entropy** for the long answer ranking.
    *   **Sparse Categorical Cross-Entropy** for the start and end span indices.
    *   **Categorical Cross-Entropy** for the Yes/No classification.
*   **Optimization:** The Adam optimizer is used with a standard learning rate schedule.

#### **Evaluation**
1.  **Inference:** For a test document, the model processes the question paired with every available long answer candidate.
2.  **Long Answer Selection:** The candidate with the highest ranking score is identified. If this score is below a calibrated **confidence threshold**, the prediction defaults to `BLANK`.
3.  **Short Answer Extraction:** If a long answer is selected, the span is determined by the indices with the highest logits from the Start and End heads.
4.  **Yes/No Prediction:** The final label is assigned based on the class with the highest probability from the Yes/No Head.
