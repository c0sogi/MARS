This script demonstrates the end-to-step usage of the provided Natural Questions library. To ensure the code runs quickly and verifies logic effectively, it employs the following strategy:

1.  **Data Mocking**: It creates small subsets (50 examples) of the training and test data in a temporary working directory. This avoids processing the massive original files.
2.  **Metadata Generation**: It generates corresponding metadata CSVs for these subsets so the `DataLoader` can filter and load them correctly.
3.  **Configuration Override**: It dynamically modifies the `Config` class to point to these mock files and reduces hyperparameters (embedding dimension, batch size, epochs) for speed.
4.  **Component Execution**: It sequentially instantiates and runs the Tokenizer, Embedding Generator, Data Loader, Model, Training Engine, and Predictor, asserting the validity of outputs at each step.
