Implementation Strategy:
1.  **Configuration & Setup**: Initialize the environment, set random seeds for reproducibility, and define run-specific hyperparameters (e.g., reduced epochs and sample sizes for a fast baseline).
2.  **Data Preparation**:
    *   Initialize the `Tokenizer` and build/load the vocabulary.
    *   Create the `embedding_matrix` using the tokenizer.
    *   Generate DataLoaders for training and validation. To ensure the process is fast, we will force the data loader to process a limited subset of the raw data (`sample_size=20000` for train, `5000` for val) by bypassing the cache.
3.  **Model Initialization**: Create the `SentenceFactorizedModel` with the prepared vocabulary and embedding matrix.
4.  **Training**: Use the `TrainEngine` to train the model. We will run for a small number of epochs (e.g., 3) to satisfy the time constraint.
5.  **Validation & Metric Calculation**:
    *   Implement a custom validation loop that performs inference on the validation set.
    *   Load the raw validation data to extract ground truth annotations (Long Answer spans, Short Answer spans, Yes/No labels).
    *   Compare model predictions against ground truth to calculate True Positives, False Positives, and False Negatives.
    *   Compute the global Micro F1 score and print it in the required format.
6.  **Failure Analysis**:
    *   Track F1 scores per example alongside metadata (document length, question length).
    *   Compute Pearson correlations to identify features associated with poor performance.
7.  **Inference & Submission**:
    *   Use the provided `Predictor` class to generate predictions for the test set.
    *   The `Predictor` handles the mapping from model outputs to the required CSV format.
