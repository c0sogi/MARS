This script demonstrates the usage of the provided Natural Questions library components. It performs the following steps:
1.  **Configuration**: Redirects output paths to a temporary directory and reduces training iterations for speed.
2.  **Text Processing**: Verifies tokenization and stemming logic.
3.  **Corpus Statistics**: Builds an IDF index from a small subset of the corpus.
4.  **Feature Extraction**: Generates numerical features (BM25, TF-IDF, etc.) for sample inputs.
5.  **Data Loading**: Loads small subsets of training and validation data using the pipeline.
6.  **Model Training**: Trains a LightGBM ranker on the loaded data.
7.  **Inference**: Generates predictions and verifies score ranges.
8.  **Answer Selection**: Tests heuristics for extracting short answers and Yes/No labels.
