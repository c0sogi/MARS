### **Proposed Baseline: 2D Interaction-Grid Convolutional Network**

This approach treats the relationship between the question and the answer candidate as an "image recognition" problem. Instead of encoding the texts into separate vectors (Siamese approach) or using complex attention mechanisms, this model constructs a simple 2D map of word similarities and uses standard 2D Convolutions to detect matching patterns (like phrases or keyword clusters). This design is computationally lightweight, leveraging the speed of matrix multiplications and optimized CNN kernels.

#### **Model**
*   **Embedding Layer:** The model utilizes pre-trained static word embeddings (e.g., GloVe) to convert tokens into dense vectors. These embeddings are frozen to minimize training costs.
*   **Interaction Grid:** For a given pair of Question and Long Answer Candidate, the model computes the dot product between every question word vector and every candidate word vector. This results in a **2D Interaction Grid** (an "image" of size $N \times M$, where $N$ is the fixed question length and $M$ is the fixed candidate length). Visual patterns in this grid correspond to text matches (e.g., a diagonal line of high values indicates a matching phrase).
*   **2D Encoder:** A **2D Convolutional Neural Network (CNN)** processes the Interaction Grid. It uses 2D kernels to detect local matching patterns (like n-gram overlaps) and Max Pooling layers to aggregate these features into a global representation of the match quality.
*   **Ranking Head:** The output of the CNN is flattened and passed through a dense layer (MLP) to output a probability score indicating if the candidate is the correct long answer.
*   **Span Prediction Head:** To predict the short answer, the model collapses the 2D Interaction Grid along the question axis (summing the similarity scores) to produce a 1D "relevance profile" over the candidate text. This profile is fed into a lightweight 1D Convolutional layer to predict **Start** and **End** token probabilities.
*   **Yes/No Head:** The flattened CNN output is passed through a classifier to predict `YES`, `NO`, or `NONE`.

#### **Data**
*   **Preprocessing:**
    *   **Tokenization:** Input text is tokenized using a fast whitespace splitter.
    *   **Fixed-Size Grids:** Question sequences are padded/truncated to a fixed length (e.g., 20 tokens) and candidates to a fixed length (e.g., 300 tokens). This ensures the Interaction Grid always has consistent dimensions ($20 \times 300$) for the 2D CNN.
*   **Labeling:**
    *   **Long Answer:** Binary label (`1` if the candidate matches the annotation, `0` otherwise).
    *   **Short Answer:** Start and End indices relative to the candidate text.
    *   **Yes/No:** Categorical labels.

#### **Training**
*   **Strategy:** The model is trained using a **Multi-Task Learning** objective, optimizing for ranking, span extraction, and Yes/No classification simultaneously.
*   **Sampling:** To handle the high ratio of negative candidates, **Random Negative Sampling** is employed. Each training batch consists of positive pairs and a fixed ratio of randomly selected negative pairs from the same document.
*   **Loss Function:** A weighted sum of **Binary Cross-Entropy** (for ranking), **Sparse Categorical Cross-Entropy** (for span indices), and **Categorical Cross-Entropy** (for Yes/No).
*   **Optimizer:** The Adam optimizer is used with a standard learning rate schedule.

#### **Evaluation**
1.  **Inference:** For a test document, the model generates Interaction Grids for the question paired with every long answer candidate and performs a forward pass.
2.  **Long Answer Selection:** The candidate with the highest ranking score is selected. If the score is below a calibrated **confidence threshold**, the prediction defaults to `BLANK`.
3.  **Short Answer Extraction:** If a long answer is selected, the span is determined by the indices with the highest probabilities from the Span Prediction Head.
4.  **Yes/No Prediction:** The label is assigned based on the highest probability class from the Yes/No Head.
