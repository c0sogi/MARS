Implementation strategy:
1.  **Setup**: Initialize the configuration, setting a small `DEBUG_SAMPLE_SIZE` (2000) and `NUM_EPOCHS` (1) to ensure the script runs quickly as a baseline. Set random seeds.
2.  **Data Processing**: Use `DataProcessor` to build the vocabulary and create the embedding matrix from the training data.
3.  **Training**:
    *   Create `NQDataset` and `DataLoader` for training and validation splits.
    *   Initialize the `FeedForwardDecomposableAttention` model.
    *   Use the `Trainer` class to train the model.
4.  **Validation & Evaluation**:
    *   Implement a custom validation loop using the validation `DataLoader` (batch size 1 to process one example at a time).
    *   For each example, perform inference to predict Long and Short answers.
    *   Retrieve ground truth labels directly from the dataset's internal cache (`id_to_data`) to ensure accuracy.
    *   Compute the Micro F1 score based on exact string matching (or token index matching as per format).
    *   Collect error statistics (correct/incorrect) and input features (document length, question length) for failure analysis.
5.  **Failure Analysis**: Calculate and print the Pearson correlation between the error status and input features to identify performance bottlenecks.
6.  **Submission**:
    *   Use `InferenceManager` to generate predictions for the official test set.
    *   Save the results to `submission.csv`.
