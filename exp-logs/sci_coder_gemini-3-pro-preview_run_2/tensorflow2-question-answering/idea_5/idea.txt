### Proposed Baseline: Feed-Forward Decomposable Attention Network

This approach introduces a **Feed-Forward Decomposable Attention** architecture. It conceptually simplifies the attention mechanisms found in complex QA models (like BiDAF, listed in Model Architectures) by removing heavy recurrent layers (LSTMs) and replacing them with fast feed-forward operations. This design focuses on "interaction-first" processing, distinguishing it from the "representation-first" Siamese architectures of previous ideas.

#### Model
The model is designed to align and compare the question and candidate text at the word level using a lightweight attention mechanism, followed by aggregation for classification.

*   **Embedding Layer:** Input text is converted into dense vectors using pre-trained static embeddings (e.g., GloVe). These are frozen to ensure low resource usage.
*   **Attention-Based Alignment:** Instead of encoding the question and candidate into single vectors immediately, the model computes a **Similarity Matrix** between every word in the question and every word in the candidate.
    *   For each word in the candidate, the model calculates a **Soft-Aligned Question Vector**. This is a weighted sum of all question word embeddings, where the weights are derived from the similarity matrix. This step effectively "aligns" relevant parts of the question to the corresponding parts of the candidate.
*   **Comparison Layer:** A **Feed-Forward Neural Network (MLP)** independently processes each candidate word paired with its Soft-Aligned Question Vector. This layer outputs a sequence of "comparison vectors" that encode how well each specific word in the candidate matches the aligned concepts in the question.
*   **Aggregation & Ranking:** The sequence of comparison vectors is summed (aggregated) to produce a single fixed-size vector summarizing the global match quality. This vector is passed to a final output layer to predict the **Long Answer Score**.
*   **Span Prediction Heads:** The sequence of comparison vectors (before aggregation) retains spatial information. This sequence is fed into two parallel linear layers to predict the **Start Token** and **End Token** probabilities for the short answer.
*   **Yes/No Head:** The aggregated vector is also passed to a classifier to predict `YES`, `NO`, or `NONE`.

#### Data
*   **Preprocessing:**
    *   **Tokenization:** Text is split on whitespace.
    *   **Padding:** Question and candidate sequences are padded to fixed lengths (e.g., 20 and 300 tokens respectively) to allow for efficient batched matrix operations.
    *   **Vocabulary:** Tokens are mapped to indices in the pre-trained embedding matrix.
*   **Labeling:**
    *   **Long Answer:** Binary label (`1` if the candidate contains the answer, `0` otherwise).
    *   **Short Answer:** Indices of the start and end tokens relative to the candidate text.
    *   **Yes/No:** Categorical labels for the three classes.

#### Training
*   **Strategy:** The model is trained end-to-end using a **Multi-Task Learning** objective.
*   **Sampling:** To manage class imbalance, **Random Negative Sampling** is used. Each training batch includes the positive candidate paired with a subset of negative candidates from the same document.
*   **Loss Function:** A combined loss function is minimized:
    *   **Binary Cross-Entropy** for the long answer ranking score.
    *   **Sparse Categorical Cross-Entropy** for the start and end token positions.
    *   **Categorical Cross-Entropy** for the Yes/No classification.
*   **Optimization:** The Adam optimizer is used with a standard learning rate.

#### Evaluation
1.  **Inference:** The model processes the question paired with every long answer candidate in a test document.
2.  **Long Answer Selection:** Candidates are ranked based on the output of the ranking head. The candidate with the highest score is selected. If the score is below a **confidence threshold**, the prediction is `BLANK`.
3.  **Short Answer Extraction:** If a long answer is selected, the span is extracted using the indices with the highest probabilities from the Start/End heads.
4.  **Yes/No Prediction:** The Yes/No label is determined by the class with the highest probability from the Yes/No head.
