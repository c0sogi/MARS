Implementation strategy:
1.  **Configuration Override**: Dynamically modify `Config` parameters at runtime to ensure the script completes within the time limit. Specifically, reduce `DATASET_FRACTION` to 0.05 (5% of data) and `NUM_EPOCHS` to 2.
2.  **Data Loading**: Use `get_dataloaders` to load training, validation, and test data. This handles vocabulary building and tokenization.
3.  **Model Setup**: Initialize the `SingleStreamNetwork` and the `Engine`.
4.  **Training**: Run the training loop for the specified epochs. Use the `train_one_epoch` method from the engine.
5.  **Validation & Metric**:
    *   Implement a custom validation inference loop (similar to `engine.predict` but strictly in memory) to generate prediction strings for the validation set.
    *   Load ground truth annotations from the validation metadata/parquet.
    *   Compute the Micro F1 score by comparing predictions against ground truths.
    *   Print `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate the F1 score per instance.
    *   Extract metadata features (Question Length, Document Length) for the validation set.
    *   Compute Pearson correlation between Error (1 - F1) and these features.
7.  **Test Inference**: Call `engine.predict` to generate the final `submission.csv` for the test set.
