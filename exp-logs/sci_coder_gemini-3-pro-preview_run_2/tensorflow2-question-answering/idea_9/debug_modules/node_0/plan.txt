The following script demonstrates the usage of the provided Single-Stream Dilated Residual Network library. It performs the following steps:
1.  **Configuration**: Overrides default `Config` parameters to use a small subset of data and fewer epochs for rapid execution.
2.  **Data Loading**: Uses `get_dataloaders` to generate training, validation, and test data loaders, and `preprocess_data` to retrieve the test dataframe required for inference mapping.
3.  **Model Initialization**: Instantiates the `SingleStreamNetwork` and verifies the output shapes of a forward pass.
4.  **Training & Validation**: Runs a training loop using the `Engine` class, performing backpropagation and loss calculation, followed by a validation step.
5.  **Inference**: Generates predictions on the test set and creates a submission file in the correct format.
6.  **Verification**: Includes assertions throughout to ensure data integrity, tensor shapes, and file generation.
