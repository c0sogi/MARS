Implementation Strategy:
1.  **Setup**: Define input (`./input`) and output (`./metadata`) directories. Ensure the output directory exists.
2.  **Data Processing Function**: Create a function to process the JSONL files in chunks using `pandas.read_json`. This avoids loading the entire 15GB+ dataset into memory at once.
    -   For each chunk, drop the heavy `document_text` column immediately to free memory.
    -   Extract `example_id` and `annotations` (for training data).
    -   Parse the `annotations` to derive ground truth labels: `long_answer_index`, `short_answer_exists`, and `yes_no_answer`.
    -   Construct a `stratify_label` based on the combination of these labels to ensure a representative validation split.
    -   Accumulate the lightweight metadata into a list of DataFrames.
3.  **Train/Validation Split**:
    -   Load the full training metadata.
    -   Use `sklearn.model_selection.train_test_split` with the constructed `stratify_label` to create an 80:20 train/validation split. Use `random_state=42`.
    -   Save the resulting metadata to `train_metadata.csv` and `validation_metadata.csv`.
4.  **Test Data Processing**:
    -   Process the test file similarly (chunked reading), extracting `example_id`.
    -   Save to `test_metadata.csv`.
5.  **Verification**:
    -   Reload the generated metadata files.
    -   Print summary statistics (counts, label distributions).
    -   Perform the required file path existence check on a random sample of 1000 entries per file.
    -   Verify that the validation split respects the stratification logic using assertions.
