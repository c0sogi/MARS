The following script demonstrates the usage of the provided machine learning library for the Pulmonary Fibrosis Progression task.

### Implementation Strategy
1.  **Setup & Configuration**: We initialize the environment by setting random seeds using `library.utils.seed_everything` and inspecting the default configuration from `library.config`.
2.  **Metric Verification**: We validate the `laplace_log_likelihood_metric` function with known inputs to ensure the scoring logic is correct.
3.  **Image Processing**: We demonstrate how to load and process a single patient's CT scan using `library.image_processing.process_patient_scan`. We verify the output shape corresponds to `(Slices, Height, Width, Channels)`.
4.  **Feature Extraction**: To demonstrate feature extraction without running the heavy CNN on the entire dataset, we select a small subset (top 3 patients) from the training metadata. We use `library.feature_extraction.CNNFeatureExtractor` to generate visual embeddings for this subset.
5.  **Data Management**: We manually invoke `library.config.process_tabular_data` on our subset to show how raw clinical data is transformed (e.g., relative weeks, one-hot encoding). We then combine these with our generated image embeddings using `library.data_manager.create_interaction_features`.
6.  **Modeling (Stage 1 & 2)**:
    *   We instantiate and train the `FVCPredictor` (Quantile Regression) on the subset data.
    *   We calculate residuals and train the `UncertaintyPredictor` (ElasticNet) to predict confidence.
    *   We assert that the models produce predictions of the correct shape and type.
7.  **Inference**: We demonstrate how to generate the final `FVC` and `Confidence` predictions using the trained models, applying the necessary clipping and scaling logic found in `library.workflow`.
