5.  **Failure Analysis**:

    *   Calculate the absolute error magnitude (`|True FVC - Predicted FVC|`).
    *   Compute the Pearson correlation coefficient between this error magnitude and each feature in the input matrix (`X_fvc`).
    *   Print the top 5 features most positively correlated with higher errors to identify sources of difficulty.
