The following script demonstrates the usage of the provided library files to build an end-to-end lung function decline prediction pipeline.

**Implementation Strategy:**
1.  **Configuration Override**: We first modify the `Config` class to enable `DEBUG` mode (processing only 5 patients) and redirect outputs to a specific `./working/demo_execution` directory. This ensures the script runs quickly and doesn't overwrite existing work.
2.  **Component Verification**:
    *   **Utils**: We validate the `laplace_log_likelihood` metric against a manually calculated value.
    *   **Image Processing**: We manually load one patient's scan using `ImageProcessor` to verify the extraction of morphological (8 dimensions) and texture features (3840 dimensions).
    *   **Feature Engineering**: We use `FeatureProcessor` to generate training, validation, and test datasets from the raw metadata and images. We assert that the resulting feature matrices have the correct dimensions.
    *   **Modeling**: We instantiate and fit the `QuantileLinearModel` (for FVC) and `ResidualElasticModel` (for Uncertainty) on the processed data, verifying prediction outputs.
3.  **Pipeline Integration**: Finally, we use the `Trainer` class to orchestrate the entire flow—loading data, training, evaluating, and generating a submission file—asserting that the final submission file is created correctly.
