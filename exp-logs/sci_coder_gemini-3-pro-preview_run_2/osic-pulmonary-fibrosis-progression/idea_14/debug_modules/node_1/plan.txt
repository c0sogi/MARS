The issue is that the `PCA` algorithm is initialized with a static number of components (30) defined in the configuration, but during the debug run, the sample size is reduced to 5. Scikit-learn's PCA implementation raises a `ValueError` because the number of components cannot exceed the number of samples (specifically $\min(n\_samples, n\_features)$).

To fix this, I will modify the `fit` method in `library/feature_engineering.py` to dynamically check the number of available samples at runtime. If the sample size is smaller than the configured `n_components`, I will clamp `n_components` to the sample size before fitting the model. This applies the principle from **debug_lesson_7** ("Adapt Static Hyperparameters to Runtime Data Dimensions").
