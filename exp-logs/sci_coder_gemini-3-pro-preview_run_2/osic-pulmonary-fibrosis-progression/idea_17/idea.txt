Based on the accumulated "Lessons Learned" and the analysis of previous experiments, I propose the **Dual-Moment Axial-Quantile Pipeline**.

This solution synthesizes the successful components of previous iterations (Deep Features, Linear Solvers, Variance Sampling) while introducing **Dual-Moment Feature Aggregation** as a structural innovation. It explicitly addresses the loss of intra-patient heterogeneity caused by simple average pooling, without incurring the risks of multi-view reconstruction or geometric stratification that led to prior failures.

### Model

The architecture consists of a **Heterogeneity-Aware Feature Extractor** feeding into a **Mathematically Specialized Linear System**.

1.  **Visual Backbone (EfficientNet-B0):**
    *   We utilize **EfficientNet-B0** (pre-trained on ImageNet) as the frozen feature extractor.
    *   **Axial-Only Sampling:** We restrict analysis to the native Axial plane to avoid interpolation artifacts and the curse of dimensionality associated with multi-view reconstruction **(Cite solution_lesson_node_00032)**.
    *   **Variance-Based Selection:** For each patient, we select the **Top 5 Axial Slices** with the highest pixel variance. This ensures the model focuses on the most heterogeneous (fibrotic) tissue **(Cite solution_lesson_node_00031)**.

2.  **Dual-Moment Feature Aggregation (Structural Innovation):**
    *   Instead of Global Average Pooling (which reduces the 5 slices to a single mean vector, discarding information about tissue patchiness), we compute both the **Mean** and the **Standard Deviation** of the feature vectors across the 5 slices.
    *   **Rationale:** Pulmonary fibrosis is often patchy. Two patients might have the same "average" fibrosis score, but one might have uniform diffuse damage while the other has focal honeycombing. The **Standard Deviation** of the deep features explicitly encodes this **intra-patient heterogeneity**, providing the linear model with a signal for "disease variance" that simple averaging misses.

3.  **Dimensionality Reduction (PCA):**
    *   The concatenated vector (Mean Embedding + Std Embedding) is compressed using **Principal Component Analysis (PCA)** to **30 components**. This is mandatory to prevent the curse of dimensionality when feeding deep features into linear solvers **(Cite solution_lesson_node_00014)**.

4.  **FVC Predictor (Linear Quantile Regressor):**
    *   A **Linear Quantile Regressor** targeting the **Median (q=0.5)**.
    *   **Inputs:** PCA features ($X$), Time ($t$), and **Interaction Terms** ($X \times t$).
    *   **Rationale:** Optimizing for the Median (L1) aligns perfectly with the Laplace Metric **(Cite solution_lesson_node_00016)**. The interactions allow the model to learn patient-specific decline rates (Varying-Coefficient) **(Cite solution_lesson_node_00008)**, preserving the linear prior required for trend extrapolation **(Cite solution_lesson_node_00006)**.

5.  **Uncertainty Predictor (Elastic Net):**
    *   An **Elastic Net Regressor** (L1+L2 Regularization).
    *   **Inputs:** PCA features ($X$) and **Time Horizon** ($|t - t_{baseline}|$).
    *   **Rationale:** We use Elastic Net to predict the magnitude of errors. We include the Time Horizon to explicitly model **Temporal Heteroscedasticity** (uncertainty growing over time) **(Cite solution_lesson_node_00017)**. We use a regularized model to prevent overfitting to noisy residuals **(Cite solution_lesson_node_00023)** and exclude complex interactions to maintain **Parsimony** **(Cite solution_lesson_node_00011)**.

### Data

1.  **Preprocessing:**
    *   **Variance Calculation:** Load DICOMs, compute pixel variance for every slice, and select the Top 5.
    *   **Feature Extraction:** Pass the 5 slices through EfficientNet-B0.
    *   **Dual-Moment Pooling:** Compute the Mean and Standard Deviation of the 5 feature vectors. Concatenate them.
    *   **Normalization:** Standard Scale clinical features; One-Hot encode categorical features.

2.  **Feature Engineering:**
    *   Combine Dual-Moment Image Embeddings with Clinical Data.
    *   Fit **PCA** on the training set to reduce the vector to ~30 dimensions **(Cite solution_lesson_node_00014)**.
    *   **FVC Set:** Generate interaction features: $X_{PCA} \times \text{Weeks}$ **(Cite solution_lesson_node_00008)**.
    *   **Uncertainty Set:** Append the horizon feature: $|\text{Weeks} - \text{Baseline\_Weeks}|$ **(Cite solution_lesson_node_00017)**.

### Training

The training utilizes **Decoupled Residual Regression (Cite solution_lesson_node_00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the FVC feature set.
    *   **Objective:** Minimize Mean Absolute Error (L1).

2.  **Stage 2 (Residual Computation):**
    *   Generate median predictions for the training set.
    *   Compute absolute residuals: $r = |y_{true} - y_{pred}|$.

3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Elastic Net** on the Uncertainty feature set with target $r$.
    *   **Objective:** Minimize Mean Squared Error (L2) + Regularization.

### Evaluation

1.  **Inference:**
    *   Extract Dual-Moment features for the test patient.
    *   Predict Median FVC using the Quantile Regressor.
    *   Predict the expected Mean Absolute Deviation (MAD) using the Elastic Net.

2.  **Analytical Scaling:**
    *   Convert the predicted MAD into the final confidence ($\sigma$) using the formula: $\sigma = \text{MAD} \times \sqrt{2}$. This analytically maps the predicted error to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.

3.  **Formatting:**
    *   Clip $\sigma$ at 70 ml.
