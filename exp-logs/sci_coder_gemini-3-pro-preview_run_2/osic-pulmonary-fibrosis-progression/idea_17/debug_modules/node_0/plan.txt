### Implementation Strategy

1.  **Environment Setup**: Import necessary libraries and the provided modules (`Config`, `utils`, `DataManager`, `DualModel`, `generate_submission`). Set random seeds for reproducibility.
2.  **Configuration Patching**: To ensure the script executes within the tight time limit, I will create "mini" versions of the metadata files (subsetting the first few rows of the original metadata). I will then patch the `Config` class attributes to point to these mini files and reduce computationally expensive parameters like `N_SLICES` and `PCA_COMPONENTS`.
3.  **Data Preparation**: Instantiate the `DataManager`. Run `prepare_data` to extract features from the mini-dataset. This involves reading DICOMs, extracting features via EfficientNet, and applying PCA/Scaling.
4.  **Verification (Data)**: Assert that the generated data matrices have the expected dimensions corresponding to the mini-dataset size.
5.  **Model Training**: Instantiate the `DualModel` (Quantile Regression + ElasticNet). Train it on the processed training data and evaluate it on the validation data.
6.  **Verification (Model)**: Assert that predictions are finite and valid. Check that the custom metric calculation works as expected.
7.  **Submission Generation**: Generate predictions for the test set and create the submission file.
8.  **Final Output Check**: Verify the existence and format of the generated `submission.csv`.
