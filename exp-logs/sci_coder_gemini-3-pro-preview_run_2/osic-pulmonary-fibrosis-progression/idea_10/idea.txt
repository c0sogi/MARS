Based on the accumulated lessons, I propose the **Spatially-Partitioned Hybrid-Feature Quantile-Elastic Pipeline**.

This solution structurally evolves the previous "Stratified-Variance" and "Density-Aware" ideas by integrating them into a **Zonal-Specific Feature Engineering** paradigm. It addresses the limitation of global averaging by explicitly modeling the **Apical-Basal Gradient**—a critical pathological signature of Idiopathic Pulmonary Fibrosis (IPF)—while strictly adhering to the robust "Deep Feature + Regularized Linear Solver" architecture validated in the lessons.

### Model

The architecture consists of a **Zonal Feature Extractor** feeding into a **Dual-Branch Linear System**, optimized for the Laplace metric.

1.  **Zonal Visual Backbone (EfficientNet-B0):**
    *   **Anatomical Partitioning:** The CT scan is divided into three anatomical zones along the Z-axis: **Upper (Apex)**, **Middle**, and **Lower (Base)**.
    *   **Stratified-Variance Sampling:** Within *each* zone, we select the single slice with the highest pixel variance. This captures the most heterogeneous tissue (likely fibrosis) specific to that anatomical region.
    *   **Feature Extraction:** We use **EfficientNet-B0** (pre-trained on ImageNet) to extract texture vectors from the three selected slices. These are concatenated (preserving spatial order) rather than averaged, allowing the model to distinguish "Basal Fibrosis" from "Apical Emphysema".

2.  **Zonal Density Profiling (Structural Innovation):**
    *   Instead of a global lung volume or global histogram, we compute a **Density Histogram (4 bins)** specifically for *each* of the three zones.
    *   **Rationale:** IPF typically manifests as high-density fibrosis in the lung base, while other conditions might show low-density emphysema in the apex. Zonal histograms provide the linear model with explicit structural priors (e.g., "Basal High-Density Count") that complement the deep texture features **(Cite solution_lesson_node_00013)**.

3.  **Dimensionality Reduction (PCA):**
    *   The concatenated vector (Zonal Texture + Zonal Histograms + Clinical Data) is compressed using **Principal Component Analysis (PCA)** to ~40 components. This is mandatory to prevent the curse of dimensionality when feeding deep features into linear solvers **(Cite solution_lesson_node_00014)**.

4.  **FVC Predictor (Linear Quantile Regressor):**
    *   A **Linear Quantile Regressor** targeting the **Median (q=0.5)**.
    *   **Inputs:** PCA features ($X$), Time ($t$), and **Interaction Terms** ($X \times t$).
    *   **Rationale:** Optimizing for the Median (L1) aligns perfectly with the Laplace metric **(Cite solution_lesson_node_00016)**. The interactions allow the model to learn patient-specific decline rates (e.g., "Patients with Basal Fibrosis decline faster") **(Cite solution_lesson_node_00008)**, preserving the linear prior required for trend extrapolation **(Cite solution_lesson_node_00006)**.

5.  **Uncertainty Predictor (Elastic Net):**
    *   An **Elastic Net Regressor** (L1+L2 Regularization).
    *   **Inputs:** PCA features ($X$) and **Time Horizon** ($|t - t_{baseline}|$).
    *   **Rationale:** We revert to Elastic Net (from the failed GLM idea) to ensure strong regularization, preventing overfitting to noisy residuals **(Cite solution_lesson_node_00023)**. We include the Time Horizon to explicitly model temporal heteroscedasticity (uncertainty growing over time) **(Cite solution_lesson_node_00017)**, while excluding complex interactions to maintain parsimony **(Cite solution_lesson_node_00011)**.

### Data

1.  **Preprocessing:**
    *   **Zonal Splitting:** Divide the sorted CT slices into three equal chunks.
    *   **Image:** From each chunk, select the max-variance slice, resize to 224x224, and normalize.
    *   **Volumetrics:** For each chunk, compute a 4-bin histogram of Hounsfield Units (e.g., <-950, -950:-700, -700:-400, >-400). Normalize counts by the total volume of that zone.
    *   **Tabular:** Standard scale Age/Baseline FVC; One-Hot encode Sex/Smoking.

2.  **Feature Engineering:**
    *   Extract EfficientNet features for the 3 slices. Concatenate with the 3 zonal histograms and clinical data.
    *   Fit **PCA** on the training set to reduce this dense vector to ~40 dimensions.
    *   **FVC Set:** Generate interaction features: $X_{PCA} \times \text{Weeks}$.
    *   **Uncertainty Set:** Append the horizon feature: $|\text{Weeks} - \text{Baseline\_Weeks}|$.

### Training

The training utilizes **Decoupled Residual Regression (Cite solution_lesson_node_00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the FVC feature set.
    *   **Objective:** Minimize Mean Absolute Error (L1).

2.  **Stage 2 (Residual Computation):**
    *   Generate median predictions for the training set.
    *   Compute absolute residuals: $r = |y_{true} - y_{pred}|$.

3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Elastic Net** on the Uncertainty feature set with target $r$.
    *   **Objective:** Minimize Mean Squared Error (L2) + Regularization. This estimates the conditional mean of the absolute error.

### Evaluation

1.  **Inference:**
    *   Extract Zonal Texture and Zonal Density features for the test patient.
    *   Predict Median FVC using the Quantile Regressor.
    *   Predict the expected Mean Absolute Deviation (MAD) using the Elastic Net.

2.  **Analytical Scaling:**
    *   Convert the predicted MAD into the final confidence ($\sigma$) using the formula: $\sigma = \text{MAD} \times \sqrt{2}$. This analytically maps the predicted error to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.

3.  **Formatting:**
    *   Clip $\sigma$ at 70 ml.
