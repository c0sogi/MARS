To address the task of predicting lung function decline, I propose a **Deep-Feature Varying-Coefficient Elastic Net**. This strategy evolves the previous "Radiomics" approach by integrating deep learning for feature extraction while strictly adhering to the robustness of linear modeling for the temporal dynamics.

### Model
The architecture is a **Varying-Coefficient Linear Model** driven by deep image features. It is designed to capture the patient-specific rate of lung function decline without overfitting to noise.

1.  **Feature Extractor (Backbone):** Instead of simple global statistics (Idea 1), we utilize a pre-trained 2D CNN (e.g., ResNet18 or EfficientNet-B0) to extract rich texture descriptors from the CT scans. This captures complex patterns like honeycombing or ground-glass opacity that correlate with fibrosis progression.
2.  **Dimensionality Reduction:** The high-dimensional CNN features are compressed using Principal Component Analysis (PCA) to a compact vector (e.g., 20-30 components). This prevents the "curse of dimensionality" when training the subsequent linear regressor on a small dataset.
3.  **Varying-Coefficient Predictor:**
    *   The core prediction logic enforces a **Linear Prior** on the time variable: $FVC(t) = \text{Intercept}(X) + \text{Slope}(X) \times \text{Weeks}$.
    *   This is implemented using a **Dual Elastic Net** where the input feature space is augmented with **Interaction Terms**. Specifically, we create features $X_{int} = X_{static} \times \text{Weeks}$.
    *   By feeding $[X_{static}, \text{Weeks}, X_{int}]$ into an Elastic Net, the model learns a patient-specific baseline (Intercept) and a patient-specific rate of decline (Slope). This directly addresses the finding that linear priors outperform tree-based models for trend extrapolation **(Cite Lesson 00006)**.
4.  **Decoupled Uncertainty Estimator:**
    *   A secondary Elastic Net model is employed to predict the confidence $\sigma$.
    *   This model is trained on the **absolute residuals** ($|FVC_{true} - FVC_{pred}|$) of the primary FVC predictor. This explicitly models the heteroscedasticity of the data **(Cite Lesson 00001)**.

### Data
1.  **Slice Selection:** For each patient, select 3 representative axial slices from the CT scan (e.g., at 20%, 50%, and 80% of the scan depth) to approximate the 3D volume without heavy computation.
2.  **Deep Feature Extraction:** Pass the selected slices through the pre-trained CNN backbone. Average the output feature vectors across the 3 slices to obtain a single robust "Fibrosis Embedding" per patient.
3.  **Preprocessing:**
    *   Apply PCA to the Fibrosis Embeddings.
    *   Normalize continuous clinical features (Age, Baseline FVC, Baseline Percent).
    *   One-hot encode categorical features (Sex, SmokingStatus).
    *   **Feature Interaction:** Generate the interaction features by multiplying the normalized static feature vector by the `Weeks` variable for each sample.

### Training
The training process is sequential:
1.  **Stage 1 (FVC Prediction):** Train the Primary Elastic Net on the augmented dataset ($X_{static} + \text{Weeks} + X_{int}$) to predict `FVC`. Use Cross-Validation to tune the regularization strength ($\alpha$) and L1 ratio.
2.  **Stage 2 (Residual Computation):** Generate predictions for the training set using the optimized Stage 1 model and compute the absolute errors: $\Delta = |y_{true} - y_{pred}|$.
3.  **Stage 3 (Uncertainty Prediction):** Train the Secondary Elastic Net on the static features ($X_{static}$) to predict $\Delta$. This model learns to map patient characteristics (e.g., high fibrosis score) to expected prediction error.

### Evaluation
For each `Patient_Week` in the test set:
1.  Extract deep features from the test patient's baseline CT and apply the learned PCA transformation.
2.  Construct the feature vector including the specific target `Weeks` and the interaction terms.
3.  Predict `FVC` using the Stage 1 model.
4.  Predict `Confidence` ($\sigma$) using the Stage 3 model.
5.  Clip $\sigma$ to a minimum of 70 ml and format the submission.
