Based on the accumulated "Lessons Learned" and the analysis of previous experiments, I propose the **Bagged Variance-Weighted Quantile-Elastic Pipeline**.

This solution introduces two structural innovations: **Variance-Weighted Feature Pooling** (to maximize signal-to-noise ratio in the embedding space) and **Bootstrap Aggregation (Bagging) of Linear Solvers** (to stabilize predictions in this small-sample regime). It strictly adheres to the "Deep Feature + Regularized Linear Solver" architecture that has proven most effective, while integrating the specific statistical optimizations (Quantile/Median, ElasticNet, Analytical Scaling) identified in the lessons.

### Model

The architecture consists of a **Signal-Weighted Feature Extractor** feeding into an **Ensemble of Mathematically Specialized Linear Solvers**.

1.  **Visual Backbone (EfficientNet-B0):**
    *   We utilize **EfficientNet-B0** (pre-trained on ImageNet) as the frozen feature extractor.
    *   **Axial-Only Sampling:** We restrict analysis to the native Axial plane to avoid interpolation artifacts and the curse of dimensionality associated with multi-view reconstruction **(Cite solution_lesson_node_00032)**.
    *   **Variance-Based Selection:** For each patient, we select the **Top 5 Axial Slices** with the highest pixel variance. This ensures the model focuses on the most heterogeneous (fibrotic) tissue **(Cite solution_lesson_node_00031)**.

2.  **Variance-Weighted Pooling (Structural Innovation):**
    *   Instead of simple Global Average Pooling (which treats all selected slices equally) or Max Pooling (which ignores context), we compute a **Weighted Average** of the feature vectors from the 5 slices.
    *   **Weights:** The weight $w_i$ for slice $i$ is proportional to its pixel variance: $w_i = \frac{\text{Var}_i}{\sum \text{Var}}$.
    *   **Rationale:** This acts as a "Soft Attention" mechanism explicitly driven by the domain heuristic that "Variance = Signal" **(Cite solution_lesson_node_00031)**. It ensures the patient embedding is dominated by the most damaged tissue while still retaining context from other slices.

3.  **Dimensionality Reduction (PCA):**
    *   The weighted embedding is compressed using **Principal Component Analysis (PCA)** to **30 components**. This is mandatory to prevent the curse of dimensionality when feeding deep features into linear solvers **(Cite solution_lesson_node_00014)**.

4.  **FVC Predictor (Bagged Linear Quantile Ensemble):**
    *   Instead of a single solver, we employ an **Ensemble of 50 Linear Quantile Regressors**.
    *   **Target:** Median (q=0.5), which minimizes L1 loss and aligns with the Laplace metric **(Cite solution_lesson_node_00016)**.
    *   **Inputs:** PCA features ($X$), Time ($t$), and **Interaction Terms** ($X \times t$). The interactions preserve the **Varying-Coefficient** property for patient-specific decline rates **(Cite solution_lesson_node_00008)**.
    *   **Bagging:** Each model is trained on a bootstrap sample of the training data. This stabilizes the coefficients and reduces variance, addressing the instability of linear models on small datasets ($N \approx 120$ patients).

5.  **Uncertainty Predictor (Bagged Elastic Net Ensemble):**
    *   An **Ensemble of 50 Elastic Net Regressors**.
    *   **Target:** Absolute Residuals ($|y - \hat{y}|$) of the FVC predictor.
    *   **Inputs:** PCA features ($X$) and **Time Horizon** ($|t - t_{baseline}|$). We include the horizon to model **Temporal Heteroscedasticity** **(Cite solution_lesson_node_00017)** but exclude complex interactions to maintain **Parsimony** **(Cite solution_lesson_node_00011)**.
    *   **Rationale:** We use Elastic Net (Regularized) instead of GLMs to prevent overfitting to noisy residuals **(Cite solution_lesson_node_00023)**.

### Data

1.  **Preprocessing:**
    *   **Variance Calculation:** Load DICOMs, compute pixel variance for every slice, and select the Top 5.
    *   **Feature Extraction:** Pass the 5 slices through EfficientNet-B0.
    *   **Weighted Pooling:** Compute the variance-weighted average of the 5 feature vectors.
    *   **Normalization:** Standard Scale clinical features; One-Hot encode categorical features.

2.  **Feature Engineering:**
    *   Combine Weighted Image Embeddings with Clinical Data.
    *   Fit **PCA** on the training set to reduce the vector to ~30 dimensions **(Cite solution_lesson_node_00014)**.
    *   **FVC Set:** Generate interaction features: $X_{PCA} \times \text{Weeks}$ **(Cite solution_lesson_node_00008)**.
    *   **Uncertainty Set:** Append the horizon feature: $|\text{Weeks} - \text{Baseline\_Weeks}|$ **(Cite solution_lesson_node_00017)**.

### Training

The training utilizes **Decoupled Residual Regression (Cite solution_lesson_node_00001)** wrapped in a **Bagging Loop**:

1.  **Stage 1 (FVC Ensemble):**
    *   Initialize 50 Linear Quantile Regressors.
    *   For each, sample the training data with replacement and fit the model (Target: FVC, Objective: L1).
    *   Store all models.

2.  **Stage 2 (Residual Computation):**
    *   Generate predictions for the training set using the FVC Ensemble (averaging the outputs).
    *   Compute absolute residuals: $r = |y_{true} - y_{pred\_avg}|$.

3.  **Stage 3 (Uncertainty Ensemble):**
    *   Initialize 50 Elastic Net Regressors.
    *   For each, sample the training data (features + residuals $r$) with replacement and fit the model (Target: $r$, Objective: MSE + Regularization).

### Evaluation

1.  **Inference:**
    *   Extract Variance-Weighted features for the test patient.
    *   **FVC:** Pass features through the 50 Quantile Regressors and average the predictions.
    *   **Uncertainty:** Pass features through the 50 Elastic Nets, average the predictions to get the expected Mean Absolute Deviation (MAD).

2.  **Analytical Scaling:**
    *   Convert the predicted MAD into the final confidence ($\sigma$) using the formula: $\sigma = \text{MAD} \times \sqrt{2}$. This analytically maps the predicted error to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.

3.  **Formatting:**
    *   Clip $\sigma$ at 70 ml.
