Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Environment Setup**: Initialize random seeds for reproducibility using the constant defined in `library.config`. Suppress unnecessary warnings.
2.  **Data Loading**: Instantiate the `FeatureEngineer` class from `library.data_handler`. Call `load_datasets(load_cached_data=True)` to efficiently retrieve training, validation, and test sets, leveraging the caching mechanism implemented in the library to save time.
3.  **Model Training**: Use the `train_model` function from `library.model_architecture`. This function initializes the `DualModel` (Radiomics-Enhanced Dual Elastic Net), trains both the FVC regressor and the Uncertainty regressor, and performs an initial evaluation.
4.  **Validation Assessment**:
    *   Perform inference on the validation set using the trained model.
    *   Calculate the final score using `laplace_log_likelihood` from `library.metrics`.
    *   Print the metric strictly in the format `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the absolute prediction errors on the validation set.
    *   Retrieve feature names from the preprocessor pipeline.
    *   Compute the Pearson correlation between each feature and the error magnitude to identify which patient characteristics (e.g., specific age groups, smoking status, or radiomics features) are associated with higher model uncertainty/error.
    *   Print the top correlations.
6.  **Submission Generation**: Call `generate_submission` to predict on the test set and save the results to `./submission/submission.csv` in the required format.
