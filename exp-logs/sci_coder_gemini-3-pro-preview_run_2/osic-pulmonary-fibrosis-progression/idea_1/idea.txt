To establish a highly efficient baseline that remains distinct from the previously suggested neural networks, tree ensembles, and Gaussian processes, I propose a **Radiomics-Enhanced Dual Elastic Net**.

### Model
The architecture consists of two parallel **Linear Regression models with Elastic Net regularization** (combining L1 and L2 penalties). This approach avoids the computational overhead of deep learning and the complexity of ensemble trees, relying instead on classical statistical modeling.
1.  **FVC Regressor:** The first linear model predicts the `FVC` value directly. It assumes a linear relationship between the decay of lung function, the time elapsed (`Weeks`), and the patient's baseline characteristics.
2.  **Uncertainty Regressor:** The second linear model predicts the **Confidence** ($\sigma$). It is trained to estimate the magnitude of the error (absolute residual) expected for a given patient, effectively modeling heteroscedasticity (varying uncertainty) across the population.

### Data
Data preparation focuses on extracting lightweight, global descriptors ("radiomics") from the images to avoid processing heavy 3D volumes during training.
1.  **Image Preprocessing:** For each patient's baseline CT scan, apply a Hounsfield Unit (HU) threshold (e.g., between -1000 and -400) to segment the lung tissue from air and bone. From the segmented voxels, calculate three global statistics: **Total Lung Volume** (voxel count), **Mean Lung Density** (average HU), and **Density Variance** (standard deviation of HU). These scalars summarize the extent of lung damage without requiring spatial convolutions.
2.  **Tabular Preprocessing:** Normalize continuous features (`Age`, `Baseline FVC`, `Baseline Percent`, `Weeks`) to a standard scale. One-hot encode categorical features (`Sex`, `SmokingStatus`).
3.  **Feature Fusion:** Concatenate the extracted image statistics with the processed tabular features to form a single flat input vector for each sample.

### Training
The training procedure is split into two sequential stages:
1.  **Stage 1 (FVC Prediction):** Train the first Elastic Net model on the training set to minimize the **Mean Absolute Error (MAE)** between the predicted and true FVC. MAE is chosen over MSE to be more robust to outliers and aligned with the Laplace metric's reliance on absolute error ($\Delta$).
2.  **Stage 2 (Uncertainty Estimation):** Compute the absolute residuals ($|FVC_{true} - FVC_{pred}|$) for all training samples using the trained Stage 1 model. Then, train the second Elastic Net model using the same input features, but with these absolute residuals as the target. This allows the model to learn which patient characteristics (e.g., lower baseline volume, specific smoking status) correlate with higher prediction errors.

### Evaluation
For every `Patient_Week` in the test set:
1.  Extract the global image statistics from the test patient's baseline CT and prepare the tabular features (using the specific target `Weeks` for that prediction).
2.  Feed the feature vector into the **FVC Regressor** to obtain the predicted lung capacity.
3.  Feed the same vector into the **Uncertainty Regressor** to predict the expected error ($\sigma$).
4.  Clip the predicted $\sigma$ at a minimum of 70 ml (as required by the metric) to generate the final submission.
