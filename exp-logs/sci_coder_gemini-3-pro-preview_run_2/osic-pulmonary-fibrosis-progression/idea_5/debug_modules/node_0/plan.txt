The implementation strategy involves the following steps:

1.  **Setup and Configuration**: Import the necessary classes from the provided library files. Override the `Config` class parameters to enable `DEBUG` mode, reduce the sample size to 10, and lower PCA components to 5. This ensures the script executes quickly within the provided environment.
2.  **Image Processing Demo**: Demonstrate the image pipeline by loading a single patient's DICOM scans, selecting the high-variance slices, and preprocessing them into a tensor. Assertions will verify the correct shapes.
3.  **Feature Extraction Demo**: Instantiate the `VisualEncoder` and pass the preprocessed image tensor to it to verify the generation of deep learning embeddings.
4.  **Data Pipeline Execution**: Instantiate the `DataProcessor` and run the full `process_data` pipeline. This will load metadata, generate embeddings, perform PCA, and create tabular/interaction features. We verify the output dictionary keys and array shapes.
5.  **Modeling**:
    *   Train the `FVCPredictor` (Quantile Regression) on the interaction features (`X_inter`) and target FVC.
    *   Calculate training residuals and train the `UncertaintyPredictor` (Elastic Net) on the static features (`X_static`) and absolute residuals.
6.  **Evaluation and Submission**: Use the trained models to predict on the validation set and calculate the custom metric. Finally, generate predictions for the test set and format them into a submission CSV file using `format_submission`.
