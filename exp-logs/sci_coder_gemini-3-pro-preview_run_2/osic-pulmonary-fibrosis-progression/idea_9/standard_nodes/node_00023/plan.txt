Implementation strategy:
1.  **Environment Setup**: Initialize random seeds for reproducibility using `Config.SEED`. Ensure the output directories exist.
2.  **Data Preparation**: Utilize the `DataPreparation` class to load and preprocess the data. This class manages the `FeaturePipeline` which extracts texture features (via EfficientNet) and global density histograms from the CT scans. It handles caching to ensure efficiency within the runtime limits.
3.  **Model Training**: Instantiate and train the `QuantileGLMSystem`. This involves two steps:
    *   Fitting a Linear Quantile Regressor (q=0.5) to predict the median FVC.
    *   Fitting a Gamma GLM (Log Link) to the absolute residuals of the first model to predict the uncertainty (expected error).
4.  **Validation**: Evaluate the trained system on the hold-out validation set. Compute the "Modified Laplace Log Likelihood" metric.
5.  **Failure Analysis**: Compute the correlation between the model's absolute errors on the validation set and the input features. This identifies which features are most associated with poor predictions.
6.  **Submission**: Check if the validation metric exceeds the specified threshold (-6.805292148096688). If successful, process the test set, generate predictions, apply the analytical scaling ($\sigma = \Delta\sqrt{2}$), clip the confidence values, and save the `submission.csv`.
