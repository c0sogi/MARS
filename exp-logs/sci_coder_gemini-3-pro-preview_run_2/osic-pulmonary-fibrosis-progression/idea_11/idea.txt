Based on the accumulated lessons and the trajectory of previous experiments, I propose the **Orthogonal-View Density-Aware Quantile-Elastic Pipeline**.

This solution structurally evolves the "Spatially-Partitioned" approach (Idea 10) by replacing the manual "Zonal" partitioning with a **Multi-View Computer Vision** approach. It addresses the critical need to capture the **Apical-Basal Gradient** (a hallmark of IPF) by introducing **Coronal Plane Analysis** while retaining the robust "Deep Feature + Linear Solver" architecture. It strictly adheres to the statistical optimizations (Quantile/Median, ElasticNet/Regularization) and dimensionality constraints (PCA) identified in the lessons.

### Model

The architecture consists of a **Dual-View Feature Extractor** feeding into a **Mathematically Specialized Linear System**.

1.  **Orthogonal Visual Backbone (Structural Innovation):**
    *   **Backbone:** We utilize **EfficientNet-B0** (pre-trained on ImageNet) as the feature extractor.
    *   **Axial Branch (Texture Detail):** We select the 3 axial slices with the highest pixel variance. This captures the "worst-case" local texture (e.g., honeycombing) regardless of its location **(Cite solution_lesson_node_00008)**.
    *   **Coronal Branch (Spatial Context):** We generate a **Coronal View** (vertical cross-section) of the lung by slicing the 3D volume along the Y-axis and selecting the central slice.
    *   **Rationale:** Standard axial slices lose the Z-axis context. A coronal image explicitly visualizes the **Apical-Basal Gradient** (distribution of fibrosis from top to bottom) in a single 2D plane. This provides the model with a structural "map" of the disease that axial slices alone cannot provide.

2.  **Global Density Profiling:**
    *   We compute a **Global Density Histogram** (4 bins: Emphysema, Healthy, Fibrosis, Consolidation) over the entire segmented lung volume.
    *   **Rationale:** This reintroduces the absolute physical scale (Total Volume of Damaged Tissue) that CNNs often lose, enforcing the **Inductive Bias** that lung capacity is physically proportional to healthy tissue volume **(Cite solution_lesson_node_00013)**.

3.  **Dimensionality Reduction (PCA):**
    *   The concatenated vector (Axial Features + Coronal Features + Density Histogram) is compressed using **Principal Component Analysis (PCA)** to ~40 components. This is mandatory to prevent the curse of dimensionality when feeding deep features into linear solvers **(Cite solution_lesson_node_00014)**.

4.  **FVC Predictor (Linear Quantile Regressor):**
    *   A **Linear Quantile Regressor** targeting the **Median (q=0.5)**.
    *   **Inputs:** PCA features ($X$), Time ($t$), and **Interaction Terms** ($X \times t$).
    *   **Rationale:** Optimizing for the Median (L1) aligns with the Laplace Metric **(Cite solution_lesson_node_00016)**. The interactions allow the model to learn patient-specific decline rates based on their orthogonal texture patterns **(Cite solution_lesson_node_00008)**.

5.  **Uncertainty Predictor (Elastic Net):**
    *   An **Elastic Net Regressor** (L1+L2 Regularization).
    *   **Inputs:** PCA features ($X$) and **Time Horizon** ($|t - t_{baseline}|$).
    *   **Rationale:** We use Elastic Net to predict the magnitude of errors. We include the Time Horizon to explicitly model **Temporal Heteroscedasticity** (uncertainty growing over time) **(Cite solution_lesson_node_00017)**. We use a regularized model instead of a GLM to prevent overfitting to noisy residuals **(Cite solution_lesson_node_00023)**, and exclude complex interactions to maintain **Parsimony** **(Cite solution_lesson_node_00011)**.

### Data

1.  **Preprocessing:**
    *   **Volume Loading:** Load the DICOM files and stack them into a 3D volume.
    *   **Axial Sampling:** Calculate variance for all axial slices; select top 3.
    *   **Coronal Sampling:** Reslice the 3D array (`numpy.rot90` or indexing) to the Coronal plane; select the middle slice (containing the trachea/main carina).
    *   **Density:** Threshold the full 3D volume (HU -1000 to -400) to segment lungs; compute the 4-bin normalized histogram.
    *   **Normalization:** Resize images to 224x224; Standard Scale tabular data.

2.  **Feature Engineering:**
    *   Extract EfficientNet-B0 features for the 3 Axial and 1 Coronal slice. Concatenate.
    *   Combine with Density Histogram and Clinical Data.
    *   Fit **PCA** on the training set to reduce this dense vector to ~40 dimensions.
    *   **FVC Set:** Generate interactions: $X_{PCA} \times \text{Weeks}$.
    *   **Uncertainty Set:** Append horizon feature: $|\text{Weeks} - \text{Baseline\_Weeks}|$.

### Training

The training utilizes **Decoupled Residual Regression (Cite solution_lesson_node_00001)**:

1.  **Stage 1 (FVC Optimization):**
    *   Train the **Linear Quantile Regressor (q=0.5)** on the FVC feature set.
    *   **Objective:** Minimize Mean Absolute Error (L1).

2.  **Stage 2 (Residual Computation):**
    *   Generate median predictions for the training set.
    *   Compute absolute residuals: $r = |y_{true} - y_{pred}|$.

3.  **Stage 3 (Uncertainty Optimization):**
    *   Train the **Elastic Net** on the Uncertainty feature set with target $r$.
    *   **Objective:** Minimize Mean Squared Error (L2) + Regularization.

### Evaluation

1.  **Inference:**
    *   Extract Axial, Coronal, and Density features for the test patient.
    *   Predict Median FVC using the Quantile Regressor.
    *   Predict the expected Mean Absolute Deviation (MAD) using the Elastic Net.

2.  **Analytical Scaling:**
    *   Convert the predicted MAD into the final confidence ($\sigma$) using the formula: $\sigma = \text{MAD} \times \sqrt{2}$. This analytically maps the predicted error to the optimal scale parameter for the Laplace metric **(Cite solution_lesson_node_00009)**.

3.  **Formatting:**
    *   Clip $\sigma$ at 70 ml.
