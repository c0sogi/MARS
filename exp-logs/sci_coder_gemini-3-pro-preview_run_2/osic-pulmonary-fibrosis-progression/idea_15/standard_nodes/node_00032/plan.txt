This script orchestrates the Multi-Axis Variance-Hybrid Quantile-Elastic Pipeline. It initializes the `LungFunctionPredictor`, prepares the data (utilizing cached features where available), trains the quantile and elastic net models, and evaluates performance on the validation set. It then performs a failure analysis by correlating prediction errors with clinical features. Finally, if the validation score exceeds the specified threshold, it generates and saves the submission file.
