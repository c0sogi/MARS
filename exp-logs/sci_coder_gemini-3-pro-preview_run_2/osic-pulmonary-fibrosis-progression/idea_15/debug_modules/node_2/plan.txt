The `ValueError: Input X contains NaN` during PCA execution is caused by numerical overflow in the `StandardScaler` when operating on `float32` data. Features with extremely low variance can produce values that exceed the range of single-precision floating point numbers (resulting in Infinity) during the scaling process, which `PCA` subsequently detects and rejects. To fix this, I will instantiate the raw feature matrix `X_raw` using `float64` (double precision) in `library/model_pipeline.py`. This ensures that the scaling calculations remain within valid numerical bounds, preventing the generation of non-finite values. This change adapts the pipeline to handle the numerical properties of the data robustly. Cite {debug_lesson_7}
