The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup & Data Loading**: Initialize the environment with fixed random seeds for reproducibility. Load the training metadata from `./metadata/train_metadata.csv`, which contains the clinical tabular data and paths to the image directories.
2.  **Target Variable Analysis**: Analyze the `FVC` column (the regression target). Calculate its mean, standard deviation, skewness, and kurtosis to assess its distribution and normality.
3.  **Tabular Data Analysis**:
    *   **Numerical Features** (`Weeks`, `Age`, `Percent`): Compute descriptive statistics (mean, std, min, max) and detect outliers using the IQR method.
    *   **Categorical Features** (`Sex`, `SmokingStatus`): Report cardinality and frequency of categories.
    *   **Missing Values**: Check for any null values in the dataset.
4.  **Image Data Analysis (Metadata-based)**:
    *   Since `pydicom` is not in the allowed package list, we cannot reliably read the pixel content or headers of the DICOM files.
    *   Instead, we will perform a **volumetric analysis** by iterating through the patient directories provided in `dcm_path`. We will count the number of DICOM files per patient to generate a `ScanDepth` feature (representing the number of slices in the CT scan).
    *   We will analyze the distribution of `ScanDepth`.
5.  **Feature Relationships**:
    *   **Correlation**: Merge the `ScanDepth` feature with the tabular data. Encode categorical variables (`Sex`, `SmokingStatus`) and calculate the Pearson correlation matrix to identify linear relationships with `FVC`.
    *   **Feature Importance**: Train a lightweight Random Forest Regressor to predict `FVC` using all available features (Clinical + ScanDepth). Report the top 5 most important features to understand drivers of lung capacity.
6.  **Formatting**: The output will be printed in a clean, structured text report with capitalized sections and formatted numbers.
