### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment, suppress warnings, and set random seeds for reproducibility. Define a temporary working directory for the demo to store subsets of metadata and cache files.
2.  **Data Subsetting**: To ensure the demonstration runs quickly (within 7 minutes) while respecting the dimensionality requirements of PCA (n_components=30), we will load the full metadata and create "mini" datasets. We will select 40 unique patients for training, 10 for validation, and 5 for testing. We ensure all rows associated with these patients are included so that baseline augmentation logic works correctly.
3.  **Feature Extraction (CNN & Radiomics)**: We will utilize `generate_embeddings` to process the images for our subset of patients. This demonstrates the integration of the `image_utils` (DICOM loading, preprocessing) and `cnn_model` (EfficientNet feature extraction) modules. We explicitly disable caching (`load_cached_data=False`) to force the execution of the image processing pipeline.
4.  **Data Processing**: We will instantiate the `DataProcessor` and invoke `process_data`. This step merges the extracted image features with the tabular clinical data, handles baseline augmentation, applies PCA, scales numerical features, and one-hot encodes categorical variables.
5.  **Model Training**:
    *   **FVC Prediction**: We will train the `QuantileModel` (Quantile Regression, q=0.5) on the processed training features (`X_fvc`) to predict the median FVC.
    *   **Uncertainty Prediction**: We will calculate the absolute residuals from the training predictions and train the `ResidualModel` (ElasticNet) on the uncertainty features (`X_unc`) to predict the confidence ($\sigma$).
6.  **Validation & Evaluation**: We will generate predictions for the validation set and compute the modified Laplace Log Likelihood metric using `laplace_log_likelihood` to verify the model's performance calculation.
7.  **Inference**: Finally, we will generate predictions for the test set and organize them into the required submission format, asserting that the output dimensions and values are valid.
