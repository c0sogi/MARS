This script demonstrates the end-to-end usage of the provided HuBMAP FTU detection library. It covers data preparation, utility verification, model initialization, training, and inference.

**Strategy:**
1.  **Configuration Overrides**: We modify `Config` attributes at runtime to point `INPUT_DIR` to a temporary directory in `./working`. This allows us to generate small, synthetic TIFF images and metadata, ensuring the demonstration runs quickly and does not attempt to process the massive real datasets (2GB+ files). We also reduce epochs and batch sizes.
2.  **Synthetic Data Generation**: We create a small 1024x1024 RGB TIFF and a corresponding binary mask. We generate a valid RLE encoding for the mask and create a metadata DataFrame mimicking the structure of `train_metadata.csv`.
3.  **Component Verification**:
    *   **Utils**: We verify `rle_encode`, `rle_decode`, and `dice_coef` with assertions.
    *   **Dataset**: We instantiate `HuBMAPDataset` with the synthetic metadata and verify data loading and augmentation shapes.
    *   **Model**: We instantiate `FPNResNet18` and verify the output shape of a forward pass.
    *   **Training**: We run the `Trainer` for a single epoch on the synthetic data to verify the training loop, loss calculation, and checkpoint saving.
    *   **Inference**: We use `InferenceRunner` to load the trained checkpoint and predict on the synthetic image, verifying that an RLE string is produced.
