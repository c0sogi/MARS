Implementation strategy:
1.  **Configuration Override**: Modify `library.config.DEBUG_SAMPLE_SIZE` and `library.config.N_ESTIMATORS` to ensure the training completes within the time limit (Fast Baseline).
2.  **Data Preparation**: Use `IceCubeFeatureGenerator` to load and process the training and validation datasets. This utilizes the pre-defined feature engineering pipeline.
3.  **Model Training**: Initialize and train the `GradientBoostingVectorRegressor`. This fits three LightGBM models (one for each vector component) to the training data.
4.  **Validation & Metric Calculation**:
    *   Generate predictions on the validation set.
    *   Implement the **Mean Angular Error** metric calculation: Convert spherical coordinates to Cartesian vectors, compute the dot product, clamp values, and calculate the arccosine.
    *   Print the final metric in the required format.
5.  **Failure Analysis**:
    *   Calculate the angular error for each event in the validation set.
    *   Compute Pearson correlations between the error magnitude and input features (e.g., `n_pulses`, `total_charge`, `spread`).
    *   Identify and print the features most strongly correlated with high error.
6.  **Submission Generation**: Invoke the `library.inference.generate_submission` function to process the test set in batches and generate the final `submission.csv`.
