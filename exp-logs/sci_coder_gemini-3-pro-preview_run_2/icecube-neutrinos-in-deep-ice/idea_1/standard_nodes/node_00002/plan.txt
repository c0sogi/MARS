The previous implementation caused an `ArrowMemoryError` because the `cache_limit` of 500 batches per worker resulted in excessive memory consumption. With 4 workers, the total potential memory usage (approx. 340 GB) exceeded the available system RAM (220 GB). To fix this, I will reduce the `cache_limit` to 40 batches in `runfile.py`. This ensures that the total memory usage across all workers stays within safe limits (approx. 27 GB).
