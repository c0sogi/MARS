The implementation strategy follows a streamlined pipeline to ensure execution within the time limits while meeting all analytical requirements.

1.  **Configuration & Setup**: We initialize the environment by setting random seeds for reproducibility and defining constraints for a "fast baseline" run. We limit the training set to 500,000 samples and the validation set to 50,000 samples, with a reduced training duration of 5 epochs. This ensures the script completes well within the 2-hour target.
2.  **Training**: We utilize the `train_model` function from `library.trainer`. This handles the training loop, checkpointing, and early stopping. We pass the sample limits and epoch count explicitly.
3.  **Validation & Failure Analysis**:
    *   We load the best model checkpoint and a dedicated validation `DataLoader`.
    *   We iterate through the validation set to generate predictions.
    *   We calculate the **Mean Angular Error** (MAE) for the entire set and print it in the required format: `Final Validation Metric: <value>`.
    *   Simultaneously, we extract input features (total charge, number of pulses, auxiliary pulse ratio) from the input tensors.
    *   We compute and print the Pearson correlation between these features and the angular error to identify failure modes (e.g., does the model perform worse on low-energy events?).
4.  **Inference**: Finally, we invoke `predict_and_submit` from `library.inference` to generate predictions for the full test set and save the `submission.csv`.
