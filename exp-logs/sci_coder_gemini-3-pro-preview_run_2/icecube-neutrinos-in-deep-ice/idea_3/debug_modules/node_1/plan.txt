The `ArrayMemoryError` is caused by the `IceCubeDataset` class aggressively preloading all batch files and immediately expanding them with dense geometry columns (`sensor_x`, `sensor_y`, `sensor_z`) for every pulse. When the dataset is shuffled, this forces a large number of batches into memory simultaneously, exceeding the available RAM.

To fix this, I will modify `IceCubeDataset` in both `library/data_loader.py` and `library/model.py` to:
1.  **Optimize Data Loading**: In `__init__`, restrict `pd.read_parquet` to load only the essential columns (`sensor_id`, `time`, `charge`, `auxiliary`) and remove the immediate geometry mapping.
2.  **Implement Lazy Geometry Lookup**: In `__getitem__`, perform the coordinate lookup (`x`, `y`, `z`) dynamically for only the specific pulses of the requested event using `map`. This significantly reduces the memory footprint by avoiding the storage of redundant coordinate data for millions of pulses in RAM.
