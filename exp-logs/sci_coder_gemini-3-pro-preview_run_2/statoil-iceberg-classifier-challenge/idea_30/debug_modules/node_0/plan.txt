Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override specific parameters (`DEBUG`, `NUM_EPOCHS`, `BATCH_SIZE`) to ensure the demonstration runs quickly (using a small data subset and a single training epoch) without modifying the library files.
2.  **Data Loading**: Use `load_data` to retrieve the training, validation, and test sets. Since `DEBUG` is enabled, this will automatically slice the datasets to a small number of samples.
3.  **Validation**: Assert the shapes of the loaded data arrays and the output of the `IcebergDataset` class to verify data integrity and processing logic.
4.  **Model Initialization**: Instantiate the `SC_WBN` model and perform a dummy forward pass with random tensors to verify the architecture and output dimensions.
5.  **Training Loop**: Execute `run_fold` for a single fold. This demonstrates the integration of the dataset, dataloader, model, optimizer, and training loop provided in the library.
6.  **Prediction**: Load the model checkpoint saved during the training step and generate predictions on the test set using the `predict` function.
7.  **Submission Generation**: Create a sample submission DataFrame and save it to the working directory, verifying the end-to-end pipeline.
