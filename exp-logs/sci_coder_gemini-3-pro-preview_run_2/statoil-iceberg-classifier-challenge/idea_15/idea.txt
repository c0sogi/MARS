Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose the **Gated Dual-Pooling Network (GDP-Net)**.

This solution represents a structural evolution of the "Dual-Pooling Contracted Network" (Idea 14). It retains the highly successful **Dual-Stream Pooling** mechanism (Lesson 70) to capture the full dynamic range of radar signals but introduces a **Multiplicative Gating Mechanism** to explicitly model the physical dependence of radar backscatter on the incidence angle, replacing the naive concatenation fusion used in previous iterations.

# Model

The architecture employs a **Modulated Split-Branch Topology** that allows the metadata to dynamically recalibrate the visual features before classification.

1.  **Visual Branch (Backbone)**:
    *   **Structure**: Retain the **Custom 4-Stage CNN** designed for 75x75 inputs (Cite solution_lesson_node_00016).
    *   **Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **Pre-Pooling** (before the pooling layer) in every block to refine spatial features at high resolution (Cite solution_lesson_node_00061).
    *   **Pooling**: Employ **Dual-Stream Pooling (Max + Min)**. Concatenate the outputs of Max Pooling (peaks) and Min Pooling (shadows) to preserve the full signal texture (Cite solution_lesson_node_00070).
    *   **Activation**: Use **ReLU** exclusively, avoiding the noise propagation issues of LeakyReLU in SAR data (Cite solution_lesson_node_00071).
    *   **Channel Contraction**: In the final convolutional stage, explicitly **contract** the filter count to **32**. After Dual-Pooling (which doubles channels), this results in a **64-channel** feature map. This constraint is critical to prevent parameter explosion in the dense head (Cite solution_lesson_node_00041).

2.  **Metadata Branch (Gating Generator)**:
    *   Process the `inc_angle` scalar through a dedicated Multi-Layer Perceptron (MLP).
    *   **Structural Innovation**: The MLP outputs a **Gating Vector** of size 64 (matching the visual channel depth) with a **Sigmoid** activation. This vector represents the "relevance" of each visual feature channel given the specific viewing geometry.

3.  **Gated Fusion Head**:
    *   **Feature Modulation**: Perform an **Element-wise Multiplication** between the final visual feature map ($64 \times 4 \times 4$) and the Gating Vector (broadcast spatially). This allows the incidence angle to suppress or amplify specific texture detectors (e.g., suppressing shadow features at steep angles where shadows are minimal), a physically motivated interaction that simple concatenation cannot easily model.
    *   **Aggregation**: Flatten the modulated feature map.
    *   **Residual Connection**: Concatenate the flattened vector with the original metadata embedding (to ensure the raw angle value is still available to the classifier).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **Moderate Dropout (0.2)** (Cite solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1] to maximize contrast (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the GDP-Net. This is essential to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.2). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained GDP-Net models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the only valid metric for performance comparison (Cite solution_lesson_node_00036).
