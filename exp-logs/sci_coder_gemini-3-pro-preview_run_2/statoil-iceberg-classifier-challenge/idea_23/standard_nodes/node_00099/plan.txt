My strategy is to replace the current `WBMGNet` with a **Contracting Dual-Pooling Network (CDPNet)**. This architecture directly addresses the failure modes of the previous solution by strictly adhering to the "Channel Contraction" principle (Cite Lesson 00092) to manage the feature expansion caused by Dual-Stream Pooling (Cite Lesson 00070). Specifically, the new model will maintain a wide intermediate representation (256 channels) to capture complex features (Cite Lesson 00077) but will explicitly contract the channel depth in the final convolutional block before flattening (Cite Lesson 00041) to prevent parameter explosion in the dense layers. I will also simplify the readout head by removing the multi-granularity branches in favor of a robust Flatten+Concatenation approach (Cite Lesson 00021, 00073). Finally, I will adopt a "Low and Slow" training schedule (Cite Lesson 00023) by increasing the epoch count and patience to allow the model to converge stably with the 2e-4 learning rate.

        self.conv2 = nn.Conv2d(128, 128, kernel_size=3, padding=1)

        self.cbam2 = CBAM(128)
        self.pool2 = DualPooling()
        # Output: 128 filters * 2 = 256 channels. Size: 37 -> 18

        self.bn3 = nn.BatchNorm2d(128)
        self.cbam3 = CBAM(128)
        self.pool3 = DualPooling()

        # Structural Innovation: Multi-Granularity Readout Head
        # ==========================================

class CDPNet(nn.Module):
    """
    Contracting Dual-Pooling Network (CDPNet).

    Implements:
    - Dual-Stream Pooling (Max+Min) for signal/shadow preservation (Cite Lesson 00070).
    - Channel Contraction to manage feature expansion (Cite Lesson 00092).
    - Wide intermediate layers for capacity (Cite Lesson 00077).
    - CBAM Attention before pooling (Cite Lesson 00029, 00061).
    - Simple Flattening + Concatenation for readout (Cite Lesson 00021, 00073).
    """

    def __init__(self):
        super(CDPNet, self).__init__()

        # Block 1: 3 -> 64 -> DualPool(128)
        self.conv1 = nn.Conv2d(Config.IN_CHANNELS, 64, kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(64)
        self.cbam1 = CBAM(64)
        self.pool1 = DualPooling()

        # Block 2: 128 -> 128 -> DualPool(256) (Widening)
        self.conv2 = nn.Conv2d(128, 128, kernel_size=3, padding=1)
        self.bn2 = nn.BatchNorm2d(128)
        self.cbam2 = CBAM(128)
        self.pool2 = DualPooling()

        # Block 3: 256 -> 128 -> DualPool(256) (Maintains width)
        self.conv3 = nn.Conv2d(256, 128, kernel_size=3, padding=1)
        self.bn3 = nn.BatchNorm2d(128)
        self.cbam3 = CBAM(128)
        self.pool3 = DualPooling()

        # Block 4: 256 -> 64 -> DualPool(128) (Contraction)
        # Explicitly reducing filters before final pooling to control dense layer size (Cite Lesson 00041)
        self.conv4 = nn.Conv2d(256, 64, kernel_size=3, padding=1)
        self.bn4 = nn.BatchNorm2d(64)
        self.cbam4 = CBAM(64)
        self.pool4 = DualPooling()

        # Final Volume: 128 * 4 * 4 = 2048
        self.flat_size = 128 * 4 * 4

        # Metadata
        self.meta_fc = nn.Sequential(
            nn.Linear(1, 16),
            nn.ReLU(),
            nn.Linear(16, 32),
            nn.ReLU()
        )

        # Dense
        self.fc1 = nn.Linear(self.flat_size + 32, 512)
        self.bn_fc1 = nn.BatchNorm1d(512)
        self.dropout = nn.Dropout(Config.DROPOUT_RATE)  # 0.5 (Cite Lesson 00077)
        self.fc2 = nn.Linear(512, 1)

    def forward(self, x, inc_angle):
        # Block 1
        x = F.relu(self.bn1(self.conv1(x)))
        x = self.cbam1(x)
        x = self.pool1(x)

        # Block 2
        x = F.relu(self.bn2(self.conv2(x)))
        x = self.cbam2(x)
        x = self.pool2(x)

        # Block 3
        x = F.relu(self.bn3(self.conv3(x)))
        x = self.cbam3(x)
        x = self.pool3(x)

        # Block 4
        x = F.relu(self.bn4(self.conv4(x)))
        x = self.cbam4(x)
        x = self.pool4(x)

        # Flatten (Cite Lesson 00021)
        x = x.view(x.size(0), -1)

        # Metadata
        if inc_angle.dim() == 1:
            inc_angle = inc_angle.unsqueeze(1)
        meta = self.meta_fc(inc_angle)

        # Concat (Cite Lesson 00073)
        x = torch.cat([x, meta], dim=1)

        # Dense
        x = F.relu(self.bn_fc1(self.fc1(x)))
        x = self.dropout(x)
        x = self.fc2(x)

        return x
