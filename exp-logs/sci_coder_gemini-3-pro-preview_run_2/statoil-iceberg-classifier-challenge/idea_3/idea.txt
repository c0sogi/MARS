Based on the accumulated lessons and the limitations of the previous custom architectures, I propose a **Residual Hybrid Transfer Network (RHTN)**. This solution structurally evolves the approach from a shallow, custom-trained CNN to a deep, pre-trained Residual Network backbone. This shift leverages the power of transfer learning to extract richer, hierarchical features from the radar imagery while retaining the successful hybrid topology and rigorous training protocols identified in previous iterations.

# Model
The architecture adopts a **split-branch topology** (Cite solution_lesson_node_00007) to process the heterogeneous data modalities (images and scalar metadata) separately before fusion.

1.  **Visual Branch (Backbone)**:
    *   **Architecture**: Replace the custom convolutional stack with a **ResNet-18** backbone (using the `timm` library). This introduces residual connections, allowing for a much deeper network that avoids vanishing gradients and captures more complex texture patterns inherent in radar backscatter.
    *   **Transfer Learning**: Initialize the backbone with **ImageNet weights**. While radar data differs from RGB photography, the low-level filters (edge and blob detectors) learned from ImageNet provide a superior initialization compared to random weights for this small dataset.
    *   **Adaptation**:
        *   Modify the first convolutional layer to accept **3 input channels** (matching the constructed data format).
        *   Remove the original fully connected classification layer.
        *   Apply **Global Average Pooling (GAP)** to the final feature map. This generates a spatial-invariant feature vector (e.g., 512 dimensions), making the model robust to the location of the iceberg within the 75x75 grid, unlike the flattening approach used previously.
2.  **Metadata Branch**:
    *   Process the scalar `inc_angle` through a dedicated Multi-Layer Perceptron (MLP) consisting of a Dense layer followed by Batch Normalization and ReLU activation.
3.  **Fusion Head**:
    *   Concatenate the 512-dimensional vector from the Visual Branch with the output of the Metadata Branch.
    *   Pass the combined vector through a classification head: `Dense -> BatchNorm -> ReLU -> Dropout -> Dense (Output) -> Sigmoid`.

# Data
1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2` to leverage the pre-trained backbone's expectation of 3-channel input.
2.  **Resolution**: Maintain the raw **75x75** resolution (Cite solution_lesson_node_00004). The ResNet backbone's downsampling factor (32x) will result in a ~3x3 feature map, which is sufficient for Global Average Pooling.
3.  **Augmentation**:
    *   Implement **Native Tensor Operations** for augmentation to ensure efficiency and type safety (Cite solution_lesson_node_00011).
    *   Apply **Full Rotational Invariance**: Randomly rotate images by 0°, 90°, 180°, or 270° combined with random Horizontal Flips. This maximizes the effective training set size for top-down imagery (Cite solution_lesson_node_00014).
    *   Do not include a separate Vertical Flip transformation, as it is mathematically redundant given the rotation and horizontal flip operations (Cite solution_lesson_node_00015).
4.  **Preprocessing**:
    *   Scale pixel values (dB) to the [0, 1] range using Min-Max scaling.
    *   Impute missing `inc_angle` values with the training set median.

# Training
1.  **Loss Function**: Binary Cross-Entropy (Log Loss).
2.  **Optimizer**: Adam optimizer.
3.  **Learning Rate Scheduler**: Implement `ReduceLROnPlateau` to dynamically decay the learning rate when validation loss stagnates. This allows the model to settle into deeper minima that a static learning rate would miss (Cite solution_lesson_node_00009).
4.  **Regularization**:
    *   Use a **moderate Dropout rate (e.g., 0.2 - 0.3)** in the fusion head. Since the heavy rotational augmentation acts as a strong regularizer, the dropout rate is reduced from previous highs (0.5) to prevent underfitting (Cite solution_lesson_node_00014).
    *   Monitor the gap between Training and Validation loss; only introduce Weight Decay if the model shows clear signs of overfitting (Validation Loss > Training Loss) (Cite solution_lesson_node_00012).
5.  **Early Stopping**: Monitor validation loss with a patience mechanism. Crucially, use **`copy.deepcopy(model.state_dict())`** to save the best model weights, ensuring the restored model is the true optimum and not a reference to the final state (Cite solution_lesson_node_00001).

# Evaluation
1.  **Inference**: Process the test images into the same 3-channel, scaled format.
2.  **Prediction**: Pass the test data through the trained RHTN to generate probability scores. The use of Global Average Pooling ensures that the predictions are robust even if the test objects are not perfectly centered.
