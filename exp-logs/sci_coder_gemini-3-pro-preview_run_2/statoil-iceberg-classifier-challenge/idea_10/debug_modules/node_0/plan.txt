Strategy:
1.  **Configuration Setup**: Import the `Config` class and override specific paths and hyperparameters to create a fast, isolated demonstration environment. This includes setting a temporary working directory, enabling debug mode (to use a data subset), reducing the number of epochs to 1, and reducing the number of folds to 2. Crucially, derived paths like `PROCESSED_DATA_PATH` must be manually updated since they are evaluated at class definition time.
2.  **Data Loading Verification**: Call `process_and_cache_data` to generate the processed dataset. Verify the shapes of the returned arrays (Training images, labels, angles, etc.) to ensure the data pipeline is functioning correctly.
3.  **Model Architecture Verification**: Instantiate the `MLCWNet` model. Create dummy input tensors matching the expected dimensions and perform a forward pass. Assert that the output shape is correct (batch size, 1) and that no errors occur.
4.  **Training Loop Execution**: Execute `train_model` from the `train_eval` module. This will run the training loop using the modified configuration (subset of data, 1 epoch). This verifies the integration of the data loader, model, loss function, and optimizer.
5.  **Inference and Submission**: Call `generate_submission` to produce predictions on the test set using the trained models.
6.  **Result Validation**: Check for the existence of the submission file and verify its content format (headers, row count) to ensure the pipeline is complete.
