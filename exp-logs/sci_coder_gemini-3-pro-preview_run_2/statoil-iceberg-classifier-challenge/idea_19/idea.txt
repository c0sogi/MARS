Based on the accumulated lessons from previous experiments, I propose the **Decoupled Wide-Body Dual-Pooling Network (DWB-DPN)**.

This solution represents a structural evolution of the "Wide-Body Dual-Stream Network" (Idea 18). It synthesizes the critical need for a **Wide Backbone** (Lesson 77) and **Shadow Preservation** (Lesson 70) with a novel **Decoupled Readout Interface**. This interface solves the "Parameter Explosion" problem of wide networks (Lesson 41) without resorting to destructive channel bottlenecks (Lesson 55), effectively unbinding the feature extraction capacity from the classification head's complexity.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a redesigned visual backbone and readout mechanism.

1.  **Visual Branch (Wide-Body Dual-Pooling Backbone)**:
    *   **Sustained Width Strategy**: Maintain high channel capacity throughout the network to capture complex SAR textures, avoiding the underfitting caused by narrowing the network (Cite solution_lesson_node_00077).
        *   **Stage 1**: 64 Filters.
        *   **Stage 2**: 128 Filters.
        *   **Stage 3**: 128 Filters.
        *   **Stage 4**: **128 Filters**.
    *   **Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **Pre-Pooling** (before the pooling layer) in every block. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, use standard CBAM (Max+Avg) for attention generation, avoiding the instability of including Min-pooling in the attention logic (Cite solution_lesson_node_00079).
    *   **Pooling**: Employ **Dual-Stream Pooling (Max + Min)** at every stage. This concatenates the local maximum (peaks) and local minimum (shadows), doubling the output depth of each block (e.g., Stage 4 outputs $128 \times 2 = 256$ channels). This preserves the full dynamic range of the radar signal (Cite solution_lesson_node_00070).
    *   **Activation**: Use **ReLU** exclusively to leverage sparsity for noise filtering (Cite solution_lesson_node_00071).

2.  **Structural Innovation: Decoupled Dual-Path Readout**:
    *   Instead of flattening the massive $4 \times 4 \times 256$ feature map directly (which creates 4,096 parameters and risks overfitting, Cite solution_lesson_node_00041), or applying a 1x1 conv bottleneck to the whole volume (which destroys peak intensity info, Cite solution_lesson_node_00055), split the output into two parallel pathways:
        *   **Path A (Spatial Grid)**: Apply a **1x1 Convolution** to reduce channels from 256 to **64**, then **Flatten**. This preserves the coarse $4 \times 4$ spatial geometry necessary for location-specific features (Cite solution_lesson_node_00021) while compressing the semantic dimension. Output size: $4 \times 4 \times 64 = 1024$.
        *   **Path B (Peak Intensity)**: Apply **Global Max Pooling** to the original 256-channel volume. Since the volume contains both Max and Inverted-Min channels, this operation extracts the **Global Peak** and **Global Deepest Shadow** for every filter, preserving the absolute signal extremes that the 1x1 conv might suppress. Output size: 256.
    *   **Result**: The fused vector is $1024 + 256 = 1280$ dimensions. This is significantly more parameter-efficient than the 4096 of the previous Wide-Body model, allowing for better generalization without sacrificing backbone width.

3.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

4.  **Fusion Head**:
    *   **Concatenation**: Fuse the Path A vector, Path B vector, and Metadata vector (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **Moderate-High Dropout (0.4)**. The reduced input size allows us to slightly lower dropout from 0.5 (Idea 18) while still regularizing the wide backbone (Cite solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1] to maximize contrast (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the DWB-DPN. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.4). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained DWB-DPN models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
