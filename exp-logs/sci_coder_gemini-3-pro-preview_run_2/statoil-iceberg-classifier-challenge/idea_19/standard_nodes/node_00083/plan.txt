Implementation strategy:

1.  **Configuration**: Modify `Config.EPOCHS` to 20 to ensure a fast baseline execution while maintaining sufficient convergence for the small dataset.
2.  **Data Loading**: Use `get_processed_data` to load the preprocessed training data. Load the metadata files (`train.csv` and `val.csv`) to determine the index split point, allowing isolation of the specific "hold-out" validation set (the `val.csv` portion) from the combined training data.
3.  **Training (5-Fold CV)**: Iterate through 5 folds using `run_fold` from the library. This trains the DWB-DPN model 5 times on different splits. We collect Out-Of-Fold (OOF) predictions for the entire dataset. This is necessary because the `val.csv` samples are scattered across the stratified folds, so we need the full CV process to get unbiased predictions for them.
4.  **Validation Assessment**: Extract the OOF predictions corresponding specifically to the `val.csv` indices. Calculate the Log Loss on this subset. This serves as the "Final Validation Metric".
5.  **Failure Analysis**: Calculate the log loss contribution for each sample in the validation subset. Compute correlations between this error and available features (Incidence Angle, Band 1 Mean, Band 2 Mean) to identify error sources.
6.  **Submission Logic**: Compare the validation metric against the threshold (0.16676861786296204). If the metric is lower (better), load the test data, generate predictions using the ensemble of 5 saved models, average them, and save to `submission.csv`.
