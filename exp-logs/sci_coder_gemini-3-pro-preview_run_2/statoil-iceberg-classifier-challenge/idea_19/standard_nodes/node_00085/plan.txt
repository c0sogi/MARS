My optimization strategy involves simplifying the architecture to remove conflicting components and adjusting hyperparameters for better convergence on the small dataset.

1.  **Remove CBAM and Decoupled Readout**: I will remove the Convolutional Block Attention Module (CBAM) and the Decoupled Readout head. The spatial attention in CBAM (based on max/avg pooling) likely suppresses "shadow" regions (signal voids), which are crucial features captured by the Dual-Pooling (Min-Pooling) mechanism. This interference degrades performance (Cite Lesson 00079). The Decoupled Readout adds unnecessary complexity; a standard flattened vector preserves spatial structure better than global pooling (Cite Lesson 00021).
2.  **Optimize Width & Contraction**: I will modify the `WideBodyBackbone` to contract channels in the final stage (256 $\to$ 64 filters, resulting in 128 channels after DualPooling). This creates a bottleneck that reduces the flattened vector size to 2048, preventing overfitting in the dense layer while maintaining width in earlier feature extraction layers (Cite Lesson 00041, Lesson 00077).
3.  **Enhance Regularization**: I will increase the Dropout rate from 0.4 to 0.5 to provide stronger regularization for the wide backbone (Cite Lesson 00077).
4.  **Refine Training Dynamics**: I will increase the learning rate scheduler patience from 3 to 5 and restore the full 50-epoch training duration (removing the 20-epoch cap) to allow the model to converge properly without premature stagnation (Cite Lesson 00023).

class CBAMBlock(nn.Module):
    """
    Convolutional Block Attention Module (CBAM).
    Applies Channel Attention followed by Spatial Attention.
    """

    def __init__(self, channels, reduction=16):
        super(CBAMBlock, self).__init__()

        # Channel Attention: Shared MLP
        self.mlp = nn.Sequential(
            nn.Flatten(),
            nn.Linear(channels, channels // reduction),
            nn.ReLU(),
            nn.Linear(channels // reduction, channels),
        )

        # Spatial Attention: 7x7 Conv on concatenated Max+Avg maps
        self.conv7x7 = nn.Conv2d(2, 1, kernel_size=7, padding=3, bias=False)

    def forward(self, x):
        # --- Channel Attention ---
        b, c, h, w = x.size()
        # Compute Max and Avg pools for channel attention
        max_pool = F.max_pool2d(x, (h, w), stride=(h, w))
        avg_pool = F.avg_pool2d(x, (h, w), stride=(h, w))

        # Shared MLP processing
        channel_att = torch.sigmoid(self.mlp(max_pool) + self.mlp(avg_pool))
        channel_att = channel_att.view(b, c, 1, 1)

        # Apply channel attention
        x_out = x * channel_att

        # --- Spatial Attention ---
        # Compute Max and Avg pools along the channel dimension
        max_spatial, _ = torch.max(x_out, dim=1, keepdim=True)
        avg_spatial = torch.mean(x_out, dim=1, keepdim=True)

        # Concatenate and convolve
        spatial_input = torch.cat([max_spatial, avg_spatial], dim=1)
        spatial_att = torch.sigmoid(self.conv7x7(spatial_input))

        # Apply spatial attention
        return x_out * spatial_att
