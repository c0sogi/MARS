Based on the accumulated lessons and the synthesis of previous structural evolutions, I propose the **Quadrant-Pooled Wide-Body Network (QP-WBN)**.

This solution represents a structural evolution that explicitly resolves the "Capacity vs. Complexity" conflict identified in Lessons 41, 55, and 77. It combines the feature-richness of a **Wide Backbone** (necessary to prevent underfitting) with a novel **Quadrant-Based Readout** (necessary to prevent overfitting) while strictly adhering to the signal-preserving principles of **Dual-Pooling** and **Attention**.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and readout interface.

1.  **Visual Branch (Wide-Body Dual-Pooling Backbone)**:
    *   **Sustained Width Strategy**: The backbone maintains a high channel capacity throughout to capture complex SAR textures, avoiding the underfitting observed in narrowed/bottlenecked architectures (Cite solution_lesson_node_00077).
        *   **Stage 1**: 64 Filters.
        *   **Stage 2**: 128 Filters.
        *   **Stage 3**: 128 Filters.
        *   **Stage 4**: **128 Filters** (Avoiding the terminal bottleneck, Cite solution_lesson_node_00055).
    *   **Attention (Pre-Pooling)**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer in every block. This allows the model to refine features at high resolution (Cite solution_lesson_node_00061). Crucially, the attention logic uses standard Max/Avg pooling to determine salience, avoiding the instability of using Min-pooling for attention generation (Cite solution_lesson_node_00079).
    *   **Pooling (Dual-Stream)**: Employ **Dual-Stream Pooling** (concatenating Max and Min pools) at every stage. This effectively doubles the output depth of each block (e.g., Stage 4 outputs $128 \times 2 = 256$ channels), preserving both the high-intensity peaks and the discriminative signal shadows/voids (Cite solution_lesson_node_00070).
    *   **Activation**: Use **ReLU** exclusively to leverage sparsity for noise filtering (Cite solution_lesson_node_00071).

2.  **Structural Innovation: Quadrant-Based Readout**:
    *   **Problem**: Flattening the final $4 \times 4 \times 256$ feature map creates 4,096 dimensions, leading to parameter explosion and overfitting in the dense head (Cite solution_lesson_node_00041). Reducing channels via 1x1 convolution destroys discriminative signal (Cite solution_lesson_node_00055).
    *   **Solution**: Apply **Adaptive Max Pooling** to reduce the $4 \times 4$ spatial grid to a **$2 \times 2$ grid (Quadrants)**.
    *   **Mechanism**: This operation extracts the strongest signal (Peak or Deepest Shadow) within each of the four image quadrants (Top-Left, Top-Right, Bottom-Left, Bottom-Right).
    *   **Result**: The flattened vector becomes $2 \times 2 \times 256 = 1024$ dimensions. This achieves a 4x parameter reduction compared to full flattening, preventing overfitting, while retaining the coarse spatial localization required to distinguish objects from clutter (Cite solution_lesson_node_00021).

3.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the `inc_angle` scalar (Cite solution_lesson_node_00007).

4.  **Fusion Head**:
    *   **Concatenation**: Fuse the Quadrant-Pooled visual vector (1024 dim) and the metadata vector via simple concatenation (Cite solution_lesson_node_00073).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)**. The high dropout is essential to regularize the wide backbone (Cite solution_lesson_node_00077, solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1]. This maximizes contrast for each physical signal type (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the QP-WBN. This is critical to reduce variance and maximize data utilization (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained QP-WBN models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance comparison (Cite solution_lesson_node_00036).
