The previous implementation suffered from data leakage because it combined the training and validation splits into a single dataset for Cross-Validation, meaning the models were trained on data later used for the final hold-out evaluation. This resulted in an invalid and overly optimistic validation metric. To fix this, I will modify `library/train.py` to strictly use only the training split for the K-Fold CV loop, reserving the validation split for the final evaluation (Cite debug_lesson_7). Additionally, I will update `runfile.py` to increase the number of epochs to 30 for better convergence and remove the conditional threshold check, ensuring a submission file is always generated.
