Based on the accumulated lessons and the analysis of previous structural failures, I propose the **Wide-Body Projected Attention Network (WBPA-Net)**.

This solution represents a structural evolution that synthesizes the conflicting requirements of **feature extraction capacity** (which demands a wide backbone, Cite solution_lesson_node_00049) and **classification efficiency** (which demands a compact interface to prevent overfitting, Cite solution_lesson_node_00041). It resolves the "Terminal Bottleneck" issue (Cite solution_lesson_node_00055) by decoupling the spatial processing width from the classification input dimension via a novel projection interface.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a redesigned visual backbone.

1.  **Visual Branch (Wide-Body Backbone with Projection)**:
    *   **Sustained Width Strategy**: Unlike previous iterations that either narrowed the network (causing underfitting) or doubled channels aggressively (causing overfitting), this backbone maintains a **Sustained Width of 128 filters** in the deeper layers.
        *   **Stage 1**: Conv(64, 3x3) $\to$ BN $\to$ ReLU $\to$ **CBAM (Pre-Pool)** $\to$ **Max Pool**.
        *   **Stage 2**: Conv(128, 3x3) $\to$ BN $\to$ ReLU $\to$ CBAM (Pre-Pool) $\to$ Max Pool.
        *   **Stage 3**: Conv(128, 3x3) $\to$ BN $\to$ ReLU $\to$ CBAM (Pre-Pool) $\to$ Max Pool.
        *   **Stage 4**: Conv(128, 3x3) $\to$ BN $\to$ ReLU $\to$ CBAM (Pre-Pool) $\to$ Max Pool.
    *   **Key Components**:
        *   **Pre-Pooling Attention**: The Convolutional Block Attention Module (CBAM) is strictly applied **before** the pooling layer to guide feature selection on the high-resolution map (Cite solution_lesson_node_00061).
        *   **Max Pooling**: Utilized strictly to preserve high-intensity backscatter peaks (Cite solution_lesson_node_00021).
    *   **Structural Innovation: 1x1 Projection Bottleneck**:
        *   After Stage 4, the feature map is $4 \times 4 \times 128$. Instead of flattening this directly (which creates 2048 features) or using a 3x3 conv to reduce channels (which degrades spatial features, Cite solution_lesson_node_00055), I insert a **1x1 Convolutional Layer** to project the 128 channels down to **64**.
        *   **Rationale**: This decouples the spatial filtering capacity (kept high at 128) from the dense layer input size (compressed to 1024 flattened features). This satisfies the need for a "Channel Contraction" (Cite solution_lesson_node_00041) without imposing a destructive bottleneck on the spatial convolutions.
    *   **Output**: Flatten the projected $4 \times 4 \times 64$ map to a 1024-dimensional vector.

2.  **Metadata Branch**:
    *   A dedicated Multi-Layer Perceptron (MLP) to process the scalar `inc_angle` (Cite solution_lesson_node_00007).

3.  **Fusion Head**:
    *   Concatenate the flattened visual vector and the metadata vector.
    *   Process through a classification head with Batch Normalization, ReLU, and **Moderate Dropout (0.2)** (Cite solution_lesson_node_00014).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Normalization**: Apply **Independent Per-Channel Min-Max Scaling**. Calculate min/max statistics for HH, HV, and Avg channels separately on the training set and scale each to [0, 1]. This maximizes contrast for each signal type (Cite solution_lesson_node_00025).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Explicitly exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).
    *   **Exclusion**: Do not use Mixup or interpolation-based techniques (Cite solution_lesson_node_00031).

# Training

1.  **Pipeline Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the WBPA-Net. This is critical to reduce variance and avoid selection bias (Cite solution_lesson_node_00029, solution_lesson_node_00052).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize the Adam optimizer with a conservative learning rate (e.g., **2e-4**) (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
3.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
4.  **Regularization**: Apply Dropout (0.2). Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

# Evaluation

1.  **Inference**: Process test images into the 3-channel, per-channel scaled format.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained WBPA-Net models from the cross-validation folds.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble approach is the valid metric for performance (Cite solution_lesson_node_00036).
