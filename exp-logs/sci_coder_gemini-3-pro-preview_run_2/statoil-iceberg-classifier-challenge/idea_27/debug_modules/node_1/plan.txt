The error arises because the `verbose` parameter was removed from the `ReduceLROnPlateau` constructor in recent PyTorch versions (v2.2+), causing a `TypeError` when the code attempts to initialize the scheduler with this argument. To resolve this, I will remove the `verbose=False` argument from the `ReduceLROnPlateau` instantiation in both `library/train_eval.py` (where the crash occurred) and `library/model.py` (where the same deprecated pattern exists).
