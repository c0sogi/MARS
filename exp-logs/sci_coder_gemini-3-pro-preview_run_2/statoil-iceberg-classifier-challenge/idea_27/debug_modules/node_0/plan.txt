This script demonstrates the usage of the provided machine learning library for the Iceberg vs. Ship classification task.

The strategy is as follows:
1.  **Setup**: Initialize the environment and seed random number generators for reproducibility.
2.  **Data Loading Verification**: Explicitly call `load_data` with a custom cache directory to verify the raw data processing logic and check the integrity of the returned data structures (shapes, types, channel construction).
3.  **Model Component Verification**: Instantiate the `SWDINet` model and its sub-components (`DualPooling`, `CBAMBlock`). Run a dummy forward pass to verify tensor shape transformations and ensure the architecture is valid.
4.  **Training Pipeline Execution**: Run the full `run_training` pipeline with minimal hyperparameters (`epochs=1`, `batch_size=32`) to demonstrate the complete workflow from data loading to cross-validation and submission generation.
5.  **Submission Verification**: Check that the submission file is generated correctly and adheres to the expected format.
