Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Setup and Imports**: Import necessary PyTorch modules, standard libraries, and the pre-defined components from the provided `library` package (`config`, `utils`, `dataset`, `model`).
2.  **Data Loading**: Initialize the data loaders using `get_dataloaders`. We will use the full dataset (`debug=False`) because the dataset is small (approx. 1600 images) and fits easily into memory/compute constraints, ensuring the best possible score within the "fast baseline" context.
3.  **Model Initialization**: Instantiate the `SAHCN` model, `BCEWithLogitsLoss` criterion, and `Adam` optimizer with the hyperparameters defined in `library.config`.
4.  **Training Loop**: Execute `train_model`. This function handles the training iterations, validation monitoring, and early stopping, returning the model state with the best validation loss.
5.  **Validation and Metric Calculation**:
    *   Run a dedicated inference pass on the validation set to collect predictions, targets, and metadata (incidence angles).
    *   Compute the **Log Loss** using `sklearn.metrics.log_loss` and print it in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate the absolute prediction error for each validation sample.
    *   Compute correlations between this error and available features: `inc_angle` and image signal statistics (mean value of channels).
    *   Print these correlations to identify systematic errors.
7.  **Submission**: Check if the validation metric meets the threshold (< 0.4997743261785452). If successful, call `predict_and_submit` to generate the `submission.csv` file.
