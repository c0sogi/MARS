# Proposed Solution: Spatially-Aware Hybrid Convolutional Network (SA-HCN)

## Model
I propose a **Spatially-Aware Hybrid Convolutional Network (SA-HCN)**. This architecture represents a structural shift from the previous Multi-Layer Perceptron (MLP) approach. While the previous D2N model treated the image as a flattened statistical vector, this solution utilizes a Convolutional Neural Network (CNN) backbone to explicitly learn spatial hierarchies and local feature patterns (such as the shape and texture of the object) which are critical for distinguishing icebergs from ships.

The architecture consists of two parallel branches:
1.  **Image Branch**: A convolutional backbone accepting the full-resolution 75x75 images. It consists of a series of convolutional blocks (Conv2D $\rightarrow$ Batch Normalization $\rightarrow$ ReLU $\rightarrow$ MaxPooling). This preserves the spatial fidelity that was found to be crucial in previous iterations (Cite solution_lesson_node_00004).
2.  **Metadata Branch**: A fully connected branch processing the scalar `inc_angle`.
3.  **Fusion Head**: The outputs of the image branch (flattened) and the metadata branch are concatenated. This combined vector passes through a dense classification head.
4.  **Regularization**: To control the "velocity" of overfitting in this small-data regime, the dense layers in the fusion head will employ aggressive **Dropout** (e.g., rate of 0.5) (Cite solution_lesson_node_00002).

## Data
1.  **Channel Construction**: Instead of using only the two provided bands, I will construct a 3-channel image to leverage standard CNN inductive biases. The channels will be: `Band_1`, `Band_2`, and the arithmetic mean of the two (`(Band_1 + Band_2) / 2`).
2.  **Resolution Preservation**: Unlike the previous approach which downsampled images, I will utilize the raw **75x75** resolution. This decision directly addresses the finding that higher resolutions contain necessary discriminative signals (Cite solution_lesson_node_00004).
3.  **Preprocessing**:
    *   **Scaling**: Apply Min-Max scaling to normalize pixel values (typically -100 to +100 dB) to the [0, 1] range.
    *   **Imputation**: Missing `inc_angle` values will be replaced with the median of the training set.

## Training
1.  **Loss Function**: Binary Cross-Entropy (Log Loss).
2.  **Optimizer**: Adam optimizer with a conservatively low learning rate (e.g., 0.0002) to ensure stable convergence and flatten the validation loss curvature (Cite solution_lesson_node_00002).
3.  **Early Stopping Strategy**: I will implement a training loop that monitors validation loss. Crucially, when saving the best model, I will explicitly perform a **deep copy** of the model's state dictionary (`copy.deepcopy(model.state_dict())`) rather than storing a reference. This ensures the restored model is actually the best-performing checkpoint and not the final overfitted state (Cite solution_lesson_node_00001).

## Evaluation
1.  **Inference**: The test set images will be processed into 3-channel 75x75 arrays and scaled using the parameters derived from the training set.
2.  **Prediction**: The trained SA-HCN will predict probabilities for the test samples. The final submission will be generated from these probabilities.
