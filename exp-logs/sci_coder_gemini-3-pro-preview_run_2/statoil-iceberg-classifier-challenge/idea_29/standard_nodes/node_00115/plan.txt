Implementation Strategy:
1.  **Environment Setup**: Initialize the environment by setting random seeds for reproducibility and selecting the appropriate computation device (GPU/CPU).
2.  **Data Preparation**:
    *   Use `data_loader.process_data(load_cached_data=True)` to load the pre-processed dataset.
    *   Extract the training (`X_train`) and validation (`X_val`) sets corresponding to the metadata splits to ensure a strict hold-out validation set.
    *   Construct PyTorch `DataLoader` instances for training, validation, and testing using `data_loader.IcebergDataset`.
3.  **Model Training**:
    *   Execute a single training run using `train.run_fold` on the training split, validating against the hold-out set. This leverages the `WBDIN` architecture defined in `model.py`.
4.  **Evaluation & Failure Analysis**:
    *   Load the best saved model state.
    *   Perform inference on the validation set to obtain probabilities.
    *   Compute the final Log Loss metric.
    *   Conduct failure analysis by correlating prediction errors with `inc_angle` and image signal statistics (mean intensity of bands).
5.  **Submission**:
    *   Check if the validation metric satisfies the threshold (< 0.16676861786296204).
    *   If satisfied, perform inference on the test set, format the predictions, and save the `submission.csv` file.
