### Implementation Strategy

1.  **Configuration & Setup**:
    *   Import the provided library modules (`config`, `utils`, `model`, `data_loader`, `trainer`).
    *   Override `Config` parameters to ensure the demonstration runs quickly (reduce epochs to 1, batch size to 16, and use a dedicated working directory).
    *   Initialize the environment using `Config.setup()` and `seed_everything()` to guarantee reproducibility.

2.  **Data Pipeline Verification**:
    *   Execute `process_data()` to parse the raw JSON files into numpy arrays and cache them.
    *   Initialize `get_data_loaders()` for a specific fold (Fold 0).
    *   Iterate through one batch from the training loader to verify tensor shapes (Images: `[B, 3, 75, 75]`, Angles: `[B]`, Labels: `[B]`) and data types.

3.  **Model Architecture Verification**:
    *   Instantiate the `CSPHN` (Contracted Spatial Pyramid Hybrid Network) model.
    *   Move the model to the configured device (GPU/CPU).
    *   Perform a forward pass using the batch of data retrieved in the previous step.
    *   Assert that the output shape is `[Batch_Size, 1]` and that values are within the valid probability range `[0, 1]`.

4.  **Training Loop Demonstration**:
    *   Manually execute the `train_one_epoch` and `validate` functions for a single epoch to demonstrate the training logic without relying on the full `run_fold` wrapper initially.
    *   Verify that the loss returned is a valid finite number.

5.  **Full Workflow Integration**:
    *   Execute `run_fold(0)` to demonstrate the complete training orchestration, including checkpoint saving and early stopping (though with 1 epoch, it will just save the best).
    *   Verify that the model checkpoint file is successfully created in the working directory.

6.  **Inference Demonstration**:
    *   Load the saved checkpoint.
    *   Run inference on a sample from the test loader to show how to generate predictions.
