The error `TypeError: Object of type float32 is not JSON serializable` arises because the `json` module cannot serialize NumPy data types (specifically `np.float32` returned by `.min()` and `.max()` in the data loader). Although the existing code converted the tuples in `scaling_stats` to lists, it did not convert the contained values to native Python types. I will fix this in `library/train_eval.py` by iterating through the `scaling_stats` and explicitly casting each element to a Python `float` before serialization.
