4.  **Training Loop Demonstration**:

        *   Train the model using `engine.train_fold`.
        *   Store the trained model and the fold-specific scaling statistics.

5.  **Inference & Submission**:
    *   For each trained fold model, generate a test dataloader using the corresponding scaling stats.
    *   Generate predictions using `engine.predict`.
    *   Average the predictions across folds (Ensembling).
    *   Create a submission DataFrame and save it to a CSV file.
    *   Verify the output file exists and has the correct format.
