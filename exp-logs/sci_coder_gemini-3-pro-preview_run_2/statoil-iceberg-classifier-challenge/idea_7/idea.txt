Based on the accumulated lessons and the specific challenges of the dataset (small size, high noise, specific physical properties of Radar), I propose the **Statistically-Enriched Attention Hybrid Network (SEA-HN)**.

This solution represents a structural evolution from a purely "spatial" deep learning approach to a **dual-paradigm architecture**. It explicitly combines the successful shallow Convolutional Neural Network (for spatial pattern recognition) with a new, rigorous Feature Engineering branch (for intensity distribution analysis). This addresses the finding that while CNNs are powerful, they struggle to learn simple global statistics (like signal-to-noise ratios) from small datasets as effectively as explicit calculation.

# Model

The architecture employs a **Multi-Stream Topology** that processes spatial and statistical modalities in parallel before fusion.

1.  **Visual Branch (Spatial Stream)**:
    *   **Backbone**: Retain the **Custom 4-Layer Shallow CNN** identified as superior to deep ResNets for this 75x75 resolution (Cite solution_lesson_node_00016, solution_lesson_node_00024).
    *   **Attention**: Integrate **Convolutional Block Attention Modules (CBAM)** after each convolutional block. This allows the network to dynamically weight informative channels and spatially focus on "peak" signals while suppressing sea clutter (Cite solution_lesson_node_00029).
    *   **Pooling**: Strictly employ **Max Pooling** to preserve the high-intensity backscatter characteristic of icebergs (Cite solution_lesson_node_00021).
    *   **Output**: **Flatten** the final feature map (e.g., to a 4x4xFilters vector) rather than using Global Average Pooling. This preserves coarse spatial geometry necessary for the dense layers to resolve location-specific features (Cite solution_lesson_node_00021).

2.  **Statistical Branch (Global Feature Stream) - *Structural Innovation***:
    *   **Concept**: Instead of feeding only the `inc_angle` metadata, this branch will process a comprehensive **Global Statistical Vector**.
    *   **Input Features**: For each band (HH, HV) and the composite Average band, calculate and feed: **Mean, Standard Deviation, Minimum, Maximum, and Median**. These 15 explicit features (plus `inc_angle`) provide a robust, noise-invariant representation of the image's intensity distribution, directly leveraging the strong correlations found in EDA which the CNN might miss due to data scarcity.
    *   **Architecture**: A dedicated Multi-Layer Perceptron (MLP) (Dense $\rightarrow$ BatchNorm $\rightarrow$ ReLU) processes this vector to extract high-level statistical descriptors.

3.  **Fusion Head**:
    *   Concatenate the flattened spatial vector from the Visual Branch with the latent statistical vector.
    *   Process through a classification head with Batch Normalization, ReLU, and **Moderate Dropout (0.2)** (Cite solution_lesson_node_00014).

# Data

1.  **Input Construction**:
    *   **Images**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
    *   **Stats**: Pre-calculate the statistical feature vector (Mean, Std, Min, Max, Median per channel) for every sample.
2.  **Normalization**:
    *   **Images**: Apply **Independent Per-Channel Min-Max Scaling**. Scale each channel (HH, HV, Avg) to [0, 1] using its own training set statistics to maximize contrast (Cite solution_lesson_node_00025).
    *   **Stats**: Standardize the statistical vector (Zero Mean, Unit Variance) to ensure stable training dynamics in the MLP branch.
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips to avoid mathematical redundancy (Cite solution_lesson_node_00015).
    *   **Implementation**: Use **native tensor operations** for efficiency (Cite solution_lesson_node_00011).
    *   **Note**: Do not apply geometric augmentation to the Statistical Branch inputs, as global stats are rotation-invariant.

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent models on different data splits. This is critical to reduce variance and avoid selection bias inherent in small-sample validation (Cite solution_lesson_node_00029, solution_lesson_node_00032).
2.  **Optimization**:
    *   **"Low and Slow"**: Initialize Adam with a conservative learning rate (e.g., **2e-4**) to prevent premature convergence (Cite solution_lesson_node_00023).
    *   **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates, allowing the model to settle into sharp minima (Cite solution_lesson_node_00009).
3.  **Regularization**:
    *   **Avoid Mixup**: Do not use interpolation-based regularization like Mixup, as it induces underfitting in this small-data regime (Cite solution_lesson_node_00031).
    *   **Dropout**: Maintain a moderate rate (0.2) as rotational augmentation already provides strong regularization (Cite solution_lesson_node_00014).
4.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).

# Evaluation

1.  **Inference**:
    *   Process test images into the 3-channel format and generate the corresponding statistical feature vectors.
    *   Apply the same scaling parameters derived from the training set.
2.  **Ensemble Prediction**:
    *   Pass the test data through all 5 trained SEA-HN models from the cross-validation folds.
    *   Compute the **mean** of the predicted probabilities to generate the final submission. This ensemble averaging is the most effective method to smooth out the high variance of individual models on this noisy dataset (Cite solution_lesson_node_00029).
