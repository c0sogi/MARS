# Proposed Solution: Residual-Integrated Wide-Body Network (RI-WBN)

Based on the accumulated lessons, I propose the **Residual-Integrated Wide-Body Network (RI-WBN)**. This solution structurally evolves the successful "Wide-Body Delayed-Integration" architecture (Idea 31) by incorporating **Residual Learning** into the feature integration process.

This addresses a potential bottleneck in the previous best model: the reliance on a single convolutional layer to mix the heterogeneous "Peak" (Max) and "Shadow" (Min) feature streams. By replacing this with a **Residual Integration Module**, we facilitate better gradient flow and allow the network to learn a robust mapping from the dual-stream input to the integrated feature space, preserving signal fidelity while maintaining the successful wide topology.

## Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a novel Residual-Integrated Backbone.

### 1. Visual Branch (Residual-Integrated Wide Backbone)
*   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** across Stages 2, 3, and 4. This avoids underfitting (Cite solution_lesson_node_00077) and prevents destructive terminal bottlenecks (Cite solution_lesson_node_00055).
*   **Residual-Integrated Block Topology**:
    *   **Input**: The block receives a **256-channel** input (concatenated Max+Min from the previous block's Dual-Pooling).
    *   **Structural Innovation: Residual Integration Module**:
        *   Instead of a simple convolution, process the input via two parallel branches to map $256 \to 128$ channels:
            *   **Main Branch**: 3x3 Convolution (Padding=1) $\to$ BatchNorm $\to$ ReLU.
            *   **Shortcut Branch**: 1x1 Convolution (Projection) $\to$ BatchNorm.
        *   **Fusion**: Element-wise Addition of the two branches $\to$ ReLU.
        *   *Rationale*: This satisfies **Delayed Integration** (Cite solution_lesson_node_00107) while the residual connection ensures that raw Peak/Shadow signals can flow through the network even if the non-linear integration is imperfect, improving optimization on small data.
    *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
    *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range of the signal (Cite solution_lesson_node_00070).

### 2. Robust Dual-Path Readout
*   The output of Stage 4 is a $4 \times 4 \times 256$ tensor.
*   **Path A (Spatial Context)**: Apply a **3x3 Convolution** (Padding=1, Stride=1) to compress channels from 256 to **48**, then **Flatten**.
    *   *Rationale*: Preserves the $4 \times 4$ coarse geometry required to distinguish object shapes from clutter (Cite solution_lesson_node_00112) and integrates spatial context (Cite solution_lesson_node_00101).
*   **Path B (Robust Intensity)**: Apply **Global Average Pooling** to the 256-channel volume.
    *   *Rationale*: Captures translation-invariant signal statistics robust to speckle noise, avoiding the sensitivity of Global Max Pooling (Cite solution_lesson_node_00115, solution_lesson_node_00123).
*   **Fusion**: Concatenate Path A (768 dim) and Path B (256 dim). Total dimension: 1024. This remains within the safe parameter range (Cite solution_lesson_node_00041).

### 3. Metadata Branch & Fusion Head
*   Process `inc_angle` via a dedicated MLP (Cite solution_lesson_node_00007).
*   Fuse via **Concatenation** (Cite solution_lesson_node_00073).
*   Classify using a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)** (Cite solution_lesson_node_00077).

## Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference. Fold-wise scaling introduces covariate shift due to local outliers (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

## Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation**. Train 5 independent instances of the RI-WBN (Cite solution_lesson_node_00052).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Avoid AdamW. The aggressive weight decay combined with high dropout caused underfitting in previous iterations (Cite solution_lesson_node_00124).
3.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
4.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).
5.  **Regularization**: Rely on High Dropout (0.5) and Rotational Augmentation. Only introduce Weight Decay if Validation Loss consistently exceeds Training Loss (Cite solution_lesson_node_00012).

## Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained RI-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission (Cite solution_lesson_node_00036).
