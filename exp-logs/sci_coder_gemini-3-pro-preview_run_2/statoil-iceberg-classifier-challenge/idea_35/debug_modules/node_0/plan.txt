This script demonstrates the usage of the provided iceberg classification library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to enable debug mode, reduce the dataset size, and limit training epochs/folds for rapid execution.
2.  **Data Loading & Verification**: Explicitly calls data processing functions to verify data structures, shapes, and statistics.
3.  **Model Verification**: Instantiates the `RIWBN` model, performs a forward pass with dummy data to verify output shapes, and checks gradient propagation.
4.  **Full Pipeline Execution**: Runs the complete training and inference pipeline via `run_training()`, ensuring the end-to-end workflow functions correctly and produces a valid submission file.
