Based on the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **Input-Anchored Wide-Body Network (IA-WBN)**.

This solution represents a structural evolution that resolves the conflict between **Optimization Stability** (which requires Batch Normalization, Cite solution_lesson_node_00161) and **Absolute Signal Magnitude** (which is destroyed by Batch Normalization, Cite solution_lesson_node_00162). It retains the robust **Wide-Body Backbone** (Cite solution_lesson_node_00077) and **Deep Normalized Fusion** (Cite solution_lesson_node_00161) but introduces a novel **Input Anchor Branch**. This branch explicitly re-injects the absolute sensor intensity statistics (derived directly from the raw input) into the fusion head, bypassing the deep feature normalization to provide the classifier with a stable "brightness reference" critical for SAR interpretation.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and a multi-source fusion interface.

1.  **Visual Branch (Wide-Body Delayed-Integration Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across all four stages. This avoids underfitting (Cite solution_lesson_node_00077) and prevents destructive terminal bottlenecks (Cite solution_lesson_node_00055).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **256** (from the previous block's Dual-Pooling). The convolution maps $256 \to 128$ filters. This performs feature integration **at the start of the new receptive field**, satisfying **Delayed Integration** (Cite solution_lesson_node_00107).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Dual-Stream Pooling**: Apply **Max Pooling** (Peaks) and **Min Pooling** (Shadows) and concatenate the outputs. This expands the channel depth ($128 \to 256$), preserving the full dynamic range of the signal (Cite solution_lesson_node_00070).
    *   **Normalized Dual-Path Readout**:
        *   The output of Stage 4 is a $4 \times 4 \times 256$ tensor.
        *   **Path A (Spatial Context)**: Apply a **3x3 Convolution** (Padding=1, Stride=1) to compress channels from 256 to **64**, then **Flatten**.
            *   *Rationale*: Integrates spatial adjacency (Cite solution_lesson_node_00101) and preserves coarse geometry (Cite solution_lesson_node_00112).
            *   **Normalization**: Apply **Batch Normalization (1D)** to the flattened vector. This stabilizes gradients (Cite solution_lesson_node_00161).
        *   **Path B (Robust Intensity)**: Apply **Global Average Pooling** to the 256-channel volume.
            *   *Rationale*: Captures translation-invariant signal statistics robust to speckle noise (Cite solution_lesson_node_00123).
            *   **Normalization**: Apply **Batch Normalization (1D)** to the pooled vector.

2.  **Metadata Branch (Deep Normalized Embedding)**:
    *   **Structure**: Linear $\to$ ReLU $\to$ Linear $\to$ **Batch Normalization** $\to$ ReLU.
    *   *Rationale*: Models the non-linear relationship of incidence angle (Cite solution_lesson_node_00158) while ensuring the embedding distribution matches the visual features (Cite solution_lesson_node_00155).

3.  **Structural Innovation: Input Anchor Branch**:
    *   **Input**: The raw 3-channel input image (Band 1, Band 2, Avg), globally scaled.
    *   **Operation**: Compute **Global Max** and **Global Mean** for each of the 3 channels (Result: 6 scalars).
    *   **Processing**: Pass through a small MLP: Linear (6 $\to$ 16) $\to$ ReLU.
    *   **Constraint**: **Do NOT apply Batch Normalization** to this branch.
    *   *Rationale*: This branch preserves the **Absolute Signal Magnitude** (dB level) which is critical for distinguishing bright icebergs from dim ships (Cite solution_lesson_node_00114). By bypassing the BN layers used in the deep branches, it resolves the "Relative Scaling Loss" identified in Lesson 162, providing the classifier with a fixed brightness anchor orthogonal to the texture features.

4.  **Fusion Head**:
    *   **Concatenation**: Fuse Path A (Normalized), Path B (Normalized), Metadata (Normalized), and Input Anchor (Un-normalized).
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)** (Cite solution_lesson_node_00077).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers which are captured by the Input Anchor Branch (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation** on the full dataset (Cite solution_lesson_node_00165).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Revert from AdamW to Adam. The aggressive weight decay of AdamW combined with high dropout caused underfitting (Cite solution_lesson_node_00124).
3.  **Optimization Protocol**: Strictly adhere to a **"Low and Slow"** strategy with a learning rate of **2e-4**.
    *   *Rationale*: Critical to stabilize the Batch Normalization layers in the fusion head (Cite solution_lesson_node_00157).
4.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
5.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained IA-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission (Cite solution_lesson_node_00036).
