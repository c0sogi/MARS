The scheduler no longer handles printing updates internally; instead, the learning rate should be logged manually. The existing training loop in `library/train_eval.py` already includes a print statement for the current learning rate (`Current LR: ...`), so simply removing the invalid `verbose=True` argument resolves the error without losing functionality.
