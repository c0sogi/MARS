Implementation strategy:
The script `runfile.py` orchestrates the complete machine learning pipeline for the iceberg classification task. It begins by setting random seeds for reproducibility and detecting the available hardware (GPU/CPU). The core logic revolves around a Stratified 5-Fold Cross-Validation loop. In each fold, the script utilizes the provided `get_loaders` function to fetch preprocessed data, initializes the `DMWBN` model (Decoupled Morphological Wide-Body Network), and trains it using the `Trainer` class. The training process includes an Adam optimizer, a learning rate scheduler, and early stopping to ensure efficiency and optimal performance. Best model weights for each fold are saved to the working directory.

After training, the script performs a comprehensive evaluation. It aggregates the validation predictions from all folds to compute the global Log Loss metric. It then conducts a failure analysis by calculating the Pearson correlation between the model's absolute errors and specific input features (incidence angle, image brightness, and image contrast) to diagnose potential biases. Finally, conditional on the validation metric meeting the strict threshold of `< 0.15744`, the script executes an ensemble inference on the test set. It averages the probability predictions from all five models and generates the final `submission.csv` file in the required format.
