This script demonstrates the end-to-end usage of the provided machine learning pipeline for the Iceberg vs. Ship classification task.

The implementation strategy is as follows:
1.  **Configuration Setup**: We override specific `Config` attributes to direct outputs to a demo directory and reduce training epochs for rapid execution.
2.  **Component Verification**: We explicitly verify the logic of custom layers like `DualPooling` and `WideBlock` by passing dummy tensors and asserting output shapes match the architectural design (e.g., channel doubling in dual pooling).
3.  **Data Pipeline**: We trigger the data processing and loading pipeline, verifying that the `DataLoader` yields batches with the correct shapes for images, incidence angles, and labels.
4.  **Model Training**: We instantiate the `DMWBN` model and the `Trainer` class, running a short training loop (2 epochs) to demonstrate the fitting process, metric calculation, and checkpoint saving.
5.  **Inference & Submission**: Finally, we load the best saved model, perform inference on the test set, and generate a submission file in the required format.
