Based on the accumulated lessons and the structural synthesis of previous successful and failed experiments, I propose the **Triple-Stream Wide-Body Network (TS-WBN)**.

This solution represents a structural evolution that resolves the limitation of "Noise Sensitivity" (Lesson 115) and "Texture Ambiguity" (Lesson 127) by explicitly propagating a **Background Reference Stream** throughout the network. It evolves the **Dual-Pooling** concept (Lesson 70) into **Triple-Stream Pooling**, ensuring that every convolutional block receives explicit information about Signal Peaks (Max), Signal Shadows (Min), and Background Clutter (Avg). This allows the network to learn robust local contrast features (e.g., Signal-to-Clutter Ratio) at every depth, superior to implicit learning from a single stream.

# Model

The architecture employs the **Split-Branch Topology** (Cite solution_lesson_node_00007) with a specifically engineered visual backbone and a multi-path readout.

1.  **Visual Branch (Triple-Stream Wide-Body Backbone)**:
    *   **Sustained Width Strategy**: Maintain a high channel capacity of **128 filters** for the convolutional kernels across all four stages. This avoids underfitting (Cite solution_lesson_node_00077) and prevents destructive terminal bottlenecks (Cite solution_lesson_node_00055).
    *   **Delayed-Integration Block Topology**:
        *   **Wide Convolution**: 3x3 Convolution $\to$ BatchNorm $\to$ ReLU.
            *   *Mechanism*: For Blocks 2, 3, and 4, the input channel depth is **384** (from the previous block's Triple-Pooling). The convolution maps $384 \to 128$ filters. This performs feature integration **at the start of the new receptive field**, satisfying **Delayed Integration** (Cite solution_lesson_node_00107).
        *   **Pre-Pooling Attention**: Apply **Convolutional Block Attention Modules (CBAM)** strictly **before** the pooling layer. This refines features at high resolution (Cite solution_lesson_node_00061). Crucially, utilize **Mixed Pooling (Max + Avg)** for the attention logic, explicitly avoiding Min-pooling to ensure stability (Cite solution_lesson_node_00095).
        *   **Structural Innovation: Triple-Stream Pooling**: Apply **Max Pooling** (Peaks), **Min Pooling** (Shadows), and **Average Pooling** (Clutter/Texture), then concatenate the outputs.
            *   *Rationale*: While Dual-Pooling (Max+Min) captures the dynamic range (Cite solution_lesson_node_00070), it lacks a robust reference for the "average" local background intensity, which is critical for distinguishing high-intensity speckle noise from true objects. Adding the **Average Pooling** stream allows the subsequent convolution to explicitly compute local contrast features (e.g., $Peak - Average$) and shadow depth (e.g., $Average - Min$) within the receptive field.
            *   *Result*: Expands channel depth from $128 \to 384$.
    *   **Normalized Triple-Path Readout**:
        *   The output of Stage 4 is a $4 \times 4 \times 384$ tensor.
        *   **Path A (Spatial Context)**: Apply a **3x3 Convolution** (Padding=1, Stride=1) to compress channels from 384 to **64**, then **Flatten**.
            *   *Rationale*: Integrates spatial adjacency between the three streams (Cite solution_lesson_node_00101) and preserves coarse geometry (Cite solution_lesson_node_00112).
            *   **Normalization**: Apply **Batch Normalization (1D)** to the flattened vector ($16 \times 64 = 1024$ dim) (Cite solution_lesson_node_00161).
        *   **Path B (Robust Intensity)**: Apply **Global Average Pooling** to the 384-channel volume.
            *   *Rationale*: Captures translation-invariant signal statistics. Because the input contains Max, Min, and Avg channels, this path effectively summarizes the Global Peak Strength, Global Shadow Depth, and Global Clutter Level.
            *   **Normalization**: Apply **Batch Normalization (1D)** to the pooled vector (384 dim).

2.  **Metadata Branch (Deep Normalized Embedding)**:
    *   **Structure**: Linear $\to$ ReLU $\to$ Linear $\to$ **Batch Normalization** $\to$ ReLU.
    *   *Rationale*: Models the non-linear incidence angle relationship (Cite solution_lesson_node_00158) while aligning the embedding distribution with the visual features (Cite solution_lesson_node_00155).

3.  **Fusion Head**:
    *   **Concatenation**: Fuse Path A (1024), Path B (384), and Metadata vectors.
    *   **Classification**: Process through a dense head with Batch Normalization, ReLU, and **High Dropout (0.5)** (Cite solution_lesson_node_00077).

# Data

1.  **Input Construction**: Construct 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`. Do not use inverted inputs (Cite solution_lesson_node_00076).
2.  **Global Normalization**: Apply **Independent Per-Channel Min-Max Scaling** using statistics derived from the **entire training dataset**.
    *   *Rationale*: Physical sensor data (dB) requires a consistent global reference. Fold-wise scaling introduces covariate shift due to local outliers (Cite solution_lesson_node_00114).
    *   **No Hard Clipping**: Allow scaled values in the validation/test sets to exceed the [0, 1] range (e.g., >1.0) if they are brighter than the training set maximum. This preserves high-intensity outliers which are critical signal indicators (Cite solution_lesson_node_00110).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of **0°, 90°, 180°, or 270°** combined with random **Horizontal Flips** (Cite solution_lesson_node_00014).
    *   **Constraints**: Exclude Vertical Flips (Cite solution_lesson_node_00015) and Mixup (Cite solution_lesson_node_00031).

# Training

1.  **Strategy**: Implement **Stratified 5-Fold Cross-Validation** using the **Full Dataset** (Cite solution_lesson_node_00165).
2.  **Optimizer**: Use the standard **Adam** optimizer.
    *   *Rationale*: Revert from AdamW to Adam. The aggressive weight decay of AdamW combined with high dropout caused underfitting (Cite solution_lesson_node_00124).
3.  **Optimization Protocol**: Strictly adhere to a **"Low and Slow"** strategy with a learning rate of **2e-4**.
    *   *Rationale*: Critical to stabilize the Batch Normalization layers in the readout and fusion head (Cite solution_lesson_node_00157).
4.  **Scheduler**: Use `ReduceLROnPlateau` to decay the learning rate when validation loss stagnates (Cite solution_lesson_node_00009).
5.  **State Management**: Use `copy.deepcopy(model.state_dict())` in the Early Stopping callback to strictly preserve the best weights (Cite solution_lesson_node_00001).

# Evaluation

1.  **Inference**: Process test images into the 3-channel format using the global scaling statistics.
2.  **Ensemble Prediction**: Pass the test data through all 5 trained TS-WBN models.
3.  **Aggregation**: Compute the **mean** of the predicted probabilities to generate the final submission (Cite solution_lesson_node_00036).
