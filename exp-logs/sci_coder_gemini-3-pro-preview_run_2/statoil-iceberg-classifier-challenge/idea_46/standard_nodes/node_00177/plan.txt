The `RuntimeError` is caused by a dimension mismatch in the fusion head of the neural network. The model architecture uses `DualStreamPooling` (which expands channels by a factor of 2) in the backbone, resulting in a feature vector of size 1312 (1024 spatial + 256 intensity + 32 metadata). However, the `fusion_input_dim` calculation incorrectly assumes a factor of 3 (likely from a previous "Triple-Stream" iteration), expecting an input size of 1440. This discrepancy causes the matrix multiplication failure.

To fix this, I will update the `fusion_input_dim` calculation in `library/model.py` to use `Config.FILTERS * 2` instead of `Config.FILTERS * 3`, aligning the linear layer's input size with the actual tensor dimensions produced by the network. This resolves the partial update issue (Cite debug_lesson_14).
