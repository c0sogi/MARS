### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override hyperparameters (Epochs, Batch Size, Number of Folds) to ensure the demonstration runs quickly (1 epoch, 2 folds).
2.  **Data Processing Verification**:
    *   Invoke `load_data()` to process the raw JSON files into numpy arrays.
    *   Verify the integrity of the processed data (shapes of images, incidence angles, and labels).
    *   Test the `IcebergDataset` class to ensure it correctly handles item retrieval, normalization, and tensor conversion.
    *   Validate the `get_fold_loaders` function to ensure it returns iterable DataLoaders with the correct batch size.
3.  **Component-Level Verification**:
    *   Instantiate and test custom layers (`DualPooling`, `CBAM`, `TriPathReadout`) with dummy tensors to confirm they produce outputs with expected dimensions.
4.  **Model Architecture Verification**:
    *   Instantiate the full `TriPathWideBodyNet`.
    *   Perform a forward pass with dummy data to verify the end-to-end flow and output shape.
5.  **Training Loop Demonstration**:
    *   Execute `train_fold(0)` using the `training_engine` module.
    *   Assert that the training completes and returns a valid validation loss.
    *   Verify that the model checkpoint file is created.
6.  **Inference Demonstration**:
    *   Load the trained model checkpoint.
    *   Use `get_test_loader` to retrieve test data.
    *   Perform inference on a single batch to demonstrate prediction generation.
