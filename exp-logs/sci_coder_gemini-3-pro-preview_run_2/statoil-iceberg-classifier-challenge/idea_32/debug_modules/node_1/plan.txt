The `FileNotFoundError` occurs because `Config.PROCESSED_DATA_PATH` is defined at the class level in `library/config.py` and evaluated at import time (early binding). When `runfile.py` patches `Config.WORK_DIR` and `Config.CACHE_DIR` to point to the demo directory, `Config.PROCESSED_DATA_PATH` remains stale, pointing to the original `./working/idea_32/cache` directory which does not exist in the demo environment. To fix this, we must explicitly update derived configuration paths like `PROCESSED_DATA_PATH` and `SUBMISSION_PATH` immediately after patching their base directories in `runfile.py`. This ensures the configuration remains consistent, addressing the "Stale Defaults" issue (Cite debug_lesson_10).
