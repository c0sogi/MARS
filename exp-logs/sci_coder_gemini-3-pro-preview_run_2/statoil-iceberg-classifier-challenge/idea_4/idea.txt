Based on the accumulated lessons, I propose a **Densely Connected Hybrid Network (DCHN)**. This solution introduces a structural innovation by replacing the simple sequential convolutional layers of the previous best model with a **custom DenseNet-style backbone**. This architecture maximizes information flow and feature reuse—critical for small datasets—while avoiding the aggressive downsampling that caused the failure of the ResNet approach.

# Model

The architecture follows a **split-branch topology** (Cite solution_lesson_node_00007) to process the heterogeneous data modalities, but significantly upgrades the visual feature extractor.

1.  **Visual Branch (Custom DenseNet Backbone)**:
    *   **Motivation**: Standard pre-trained backbones (like ResNet) fail on this task because their initial layers (large strides and pooling) destroy fine spatial details in small 75x75 images (Cite solution_lesson_node_00016). A simple sequential CNN (previous best) lacks the capacity to capture complex multi-scale textures.
    *   **Architecture**: I will construct a **custom Densely Connected Network** specifically designed for 75x75 inputs.
        *   **Stem**: A single 3x3 Convolution layer with stride 1 (preserving 75x75 resolution) to extract initial features without information loss (Cite solution_lesson_node_00004).
        *   **Dense Blocks**: Three dense blocks. Within each block, every layer is connected to every other layer in a feed-forward fashion. This encourages feature reuse and mitigates the vanishing gradient problem, allowing for a deeper network than the previous 4-layer CNN.
        *   **Transition Layers**: Between dense blocks, use 1x1 Convolutions followed by 2x2 Average Pooling to control dimensionality gradually (75$\to$37$\to$18$\to$9).
        *   **Global Average Pooling (GAP)**: Instead of flattening the feature map (which creates a massive parameter count and encourages overfitting to spatial locations), apply GAP to the final feature map. This produces a compact, rotation-invariant feature vector.
2.  **Metadata Branch**:
    *   Process the scalar `inc_angle` using a Multi-Layer Perceptron (MLP) consisting of Dense $\to$ BatchNorm $\to$ ReLU layers.
3.  **Fusion Head**:
    *   Concatenate the output vector from the Visual Branch (GAP) with the output of the Metadata Branch.
    *   Pass the combined vector through a classification head: `Dense -> BatchNorm -> ReLU -> Dropout -> Dense (Output) -> Sigmoid`.

# Data

1.  **Input Construction**: Create 3-channel images using `Band_1`, `Band_2`, and the arithmetic mean `(Band_1 + Band_2) / 2`.
2.  **Resolution**: Maintain the raw **75x75** resolution to preserve high-frequency speckle patterns (Cite solution_lesson_node_00004).
3.  **Augmentation**:
    *   **Rotational Invariance**: Apply random rotations of 0°, 90°, 180°, or 270° combined with random Horizontal Flips. This is critical for top-down radar imagery (Cite solution_lesson_node_00014).
    *   **Efficiency**: Implement these transformations using **native tensor operations** (e.g., `torch.rot90`, `torch.flip`) to maximize training speed (Cite solution_lesson_node_00011).
    *   **Non-Redundancy**: Explicitly exclude Vertical Flips, as they are mathematically redundant given the rotation and horizontal flip generators (Cite solution_lesson_node_00015).
4.  **Preprocessing**:
    *   Scale pixel values to [0, 1] using Min-Max scaling.
    *   Impute missing `inc_angle` values with the training set median.

# Training

1.  **Loss Function**: Binary Cross-Entropy (Log Loss).
2.  **Optimizer**: Adam optimizer.
3.  **Learning Rate Scheduler**: Use `ReduceLROnPlateau` to dynamically decay the learning rate when validation loss stagnates. This allows the model to settle into deeper minima that a static rate would miss, which is essential when using heavy augmentation (Cite solution_lesson_node_00009).
4.  **Regularization**:
    *   **Dropout**: Apply a moderate dropout rate (e.g., 0.2) in the fusion head. High dropout (0.5) is unnecessary because the heavy rotational augmentation already acts as a strong regularizer (Cite solution_lesson_node_00014).
    *   **Weight Decay**: Do not apply L2 regularization initially. Monitor the training vs. validation loss; only introduce it if the model shows clear overfitting (Validation Loss > Training Loss) (Cite solution_lesson_node_00012).
5.  **Early Stopping**:
    *   Monitor validation loss with patience.
    *   **Crucial Step**: Use `copy.deepcopy(model.state_dict())` when saving the best model. This prevents the "mutable reference" bug where the saved model inadvertently updates to the final, overfitted state (Cite solution_lesson_node_00001).

# Evaluation

1.  **Inference**: Process test images into the same 3-channel, scaled format.
2.  **Prediction**: Pass the test data through the trained DCHN. The use of Global Average Pooling in the visual branch ensures that predictions are robust to object translation and rotation, providing a more stable probability score than the previous flattened architectures.
