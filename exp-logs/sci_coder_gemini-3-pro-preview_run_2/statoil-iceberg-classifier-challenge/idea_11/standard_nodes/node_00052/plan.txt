The solution implements the **Wide-Expanded Bottleneck Network (WEBN)** pipeline within the `runfile.py` script. 

**Implementation Strategy:**
1.  **Setup & Imports**: The script imports necessary standard libraries and the provided `library` modules (`config`, `utils`, `model`, `data_loader`). It avoids importing `library.train` to prevent triggering its automatic execution block.
2.  **Configuration**: It overrides `config.NUM_EPOCHS` to 20 and `config.PATIENCE` to 5 to satisfy the "fast baseline" requirement while ensuring sufficient convergence for the small dataset.
3.  **Training Orchestration**: It implements a stratified 5-fold cross-validation loop. For each fold:
    *   A fresh `WEBN` model is initialized.
    *   The model is trained using the shared `train_loader` and validated against `val_loader`.
    *   The `EarlyStopping` mechanism is used to save the best model weights to the working directory.
4.  **Ensemble Validation**: After training, the script reloads the best weights from all 5 folds. It performs inference on the hold-out validation set, averages the predictions (Deep Ensemble), and calculates the **Log Loss**. The result is printed strictly as `Final Validation Metric: <value>`.
5.  **Failure Analysis**: The script calculates the absolute error for each validation sample and computes the Pearson correlation coefficient between the error magnitude and the incidence angle (`inc_angle`) using `np.corrcoef`.
6.  **Conditional Submission**: If the validation log loss is below the threshold (`0.17493283735739185`), the script proceeds to generate predictions for the test set using the full ensemble and saves the result to `submission/submission.csv`.
