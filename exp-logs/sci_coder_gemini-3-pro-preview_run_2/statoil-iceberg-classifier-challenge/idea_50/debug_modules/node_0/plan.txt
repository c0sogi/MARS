This script demonstrates the functionality of the provided machine learning library for the iceberg classification task. It systematically validates the utility functions, custom neural network layers, model architecture, data loading pipeline, and the training loop. To ensure the demonstration runs quickly within the time limit, it utilizes the `debug=True` flag provided in the library functions, which restricts the dataset to a small subset, and monkey-patches the training configuration to run for only a single epoch on a single fold.
