The implementation strategy involves the following steps:

1.  **Setup**: Define the input directory (`./input`) and the output directory (`./metadata`). Ensure the output directory exists.
2.  **Data Loading**: Read the raw `train.csv` and `test.csv` files using pandas.
3.  **Splitting**: Perform a stratified split on the training data to create a validation set.
    *   Use a fixed 80:20 ratio and `random_state=42`.
    *   Stratify based on the `score` column. This is crucial because the scores are discrete (0.0, 0.25, 0.5, 0.75, 1.0), and we want to ensure the validation set has the same distribution of labels as the training set to accurately evaluate the Pearson correlation.
4.  **Metadata Generation**: Save the split datasets (`train.csv`, `val.csv`) and the test dataset (`test.csv`) to the `./metadata` directory. In this text-based task, the CSVs themselves serve as the metadata containing the samples.
5.  **Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (row counts, score distributions).
    *   Programmatically assert that the validation split ratio is correct (~20%).
    *   Programmatically assert that the stratification was successful by comparing the normalized value counts of the `score` column in the training and validation sets.
    *   Since the dataset contains self-contained text and does not reference external media files (like images or audio), the file path resolution check is skipped as it is not applicable.
