The `RuntimeError: Trying to backward through the graph a second time` is caused by the default behavior of gradient checkpointing in the `transformers` library, which uses `use_reentrant=True`. This interacts poorly with the current PyTorch autograd engine in this setup. The fix is to explicitly disable reentrant checkpointing in `library/model.py`.

Additionally, a `UserWarning` was observed regarding the construction of a tensor from a tensor in `get_expected_scores`. This is fixed in `library/engine.py` by using `torch.as_tensor()`, which handles both NumPy arrays and PyTorch tensors efficiently, and ensuring proper device placement and detachment.
