Based on the "Lessons" learned from previous iterations, I propose the following optimized strategy. This solution advances the "Two-Stage Stacking" concept (Idea 8) by replacing the linear meta-learner with a **Non-Linear Gradient Boosting Machine**. This addresses the limitation that linear models cannot capture context-dependent thresholds for structural features (e.g., a small Levenshtein distance might imply a "typo" in one context but a distinct chemical compound in another).

# Proposed Solution: Non-Linear Stacked Generalization of Adversarial Hybrid Ensembles

### Model
**Level 1: Homogeneous Adversarial Hybrid Ensemble**
We will construct a **Stratified 5-Fold Ensemble** using exclusively the **`microsoft/deberta-v3-large`** backbone. We reject heterogeneous ensembling with weaker models (e.g., RoBERTa) as this was proven to dilute performance (Cite **solution_lesson_node_00020**).
*   **Pooling:** We will use **Attention Pooling** on the last hidden state, which outperforms `[CLS]` fusion (Cite **solution_lesson_node_00014**).
*   **Internal Fusion:** We will concatenate the pooled embedding with explicit structural features (**Normalized Levenshtein Distance, Jaccard Similarity, Length Ratio**) before the classification head. This provides the network with deterministic signals for "exact match" alignment (Cite **solution_lesson_node_00015**).
*   **Head:** A **5-Class Classification Head** will output the probability distribution over `{0.0, 0.25, 0.5, 0.75, 1.0}` (Cite **solution_lesson_node_00008**).

**Level 2: Non-Linear Meta-Learner (LightGBM)**
Instead of simple averaging or linear regression, we will train a **LightGBM Regressor** on the Out-Of-Fold (OOF) predictions from Level 1.
*   **Inputs:** The meta-learner will receive the **full probability distribution** (5 columns) from the Level 1 models, the **Raw Structural Features**, and the **Context ID** (Categorical).
*   **Rationale:** The relationship between structural features and similarity is non-linear and context-dependent (e.g., small edit distances may be tolerated in "Engineering" but penalized in "Chemistry"). A tree-based model can learn these specific interaction thresholds, effectively calibrating the deep semantic predictions (Cite **solution_lesson_node_00020**).

### Data
**Preprocessing:**
*   **Context Enrichment:** We will map CPC context codes (e.g., "A47") to their full textual descriptions for the Level 1 input to provide semantic grounding (Cite **solution_lesson_node_00008**).
*   **Feature Engineering:** We will pre-compute Jaccard, Levenshtein, and Length statistics. These are used both for the Level 1 internal fusion and as direct inputs to the Level 2 LightGBM.

### Training
**Level 1 Strategy (Stability & Convergence):**
*   **Duration:** Each fold will be trained for **5 epochs**. This ensures full convergence, addressing the undertraining failure observed in 1-epoch experiments (Cite **solution_lesson_node_00013**).
*   **Adversarial Weight Perturbation (AWP):** We will apply AWP (activated after epoch 1) to flatten the loss landscape and improve generalization.
*   **Optimization:** We will strictly employ **Gradient Accumulation** (Effective Batch Size = 32) and **Gradient Clipping** (Max Norm = 1.0) to prevent the loss stagnation/divergence observed in large model fine-tuning (Cite **solution_lesson_node_00016**).
*   **Loss:** Cross-Entropy Loss with mild label smoothing (0.1) (Cite **solution_lesson_node_00008**).

**Level 2 Strategy:**
*   The LightGBM model will be trained using the OOF predictions and features from the training set, optimizing for **RMSE** (a proxy for Pearson Correlation).

### Evaluation
**Inference:**
1.  **Level 1:** Generate 5-class probability predictions for the test set using the 5-fold DeBERTa ensemble.
2.  **Level 2:** Feed these probabilities, along with the test set's structural features and context IDs, into the trained LightGBM model.
3.  **Output:** The scalar output from LightGBM is clipped to [0, 1] and used as the final similarity score.
