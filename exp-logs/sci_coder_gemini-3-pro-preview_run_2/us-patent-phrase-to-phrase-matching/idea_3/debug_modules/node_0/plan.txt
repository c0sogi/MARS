This script demonstrates the usage of the provided library modules for the Phrase Similarity task. It overrides the default configuration to run in "debug" mode with a smaller model (`microsoft/deberta-v3-xsmall`) and a subset of data (100 samples) to ensure the demonstration executes quickly (under 1 minute on an A100). It verifies the data loading, model initialization, forward pass, adversarial weight perturbation (AWP), training loop, and validation logic.
