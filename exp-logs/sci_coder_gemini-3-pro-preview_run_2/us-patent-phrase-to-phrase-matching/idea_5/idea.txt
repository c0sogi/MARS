# Proposed Solution: Hybrid Feature-Fused DeBERTa-v3-Large Ensemble

### Model
**Architecture:**
We will utilize the **`microsoft/deberta-v3-large` Cross-Encoder** backbone, as it has been proven to significantly outperform Bi-Encoders for capturing fine-grained semantic interactions (Cite **solution_lesson_node_00003**).

**Structural Innovation (Hybrid Feature Fusion):**
To address the scoring rubric's specific constraints—where the distinction between "Very close match" (1.0) and "Close synonym" (0.75) often depends on surface-level differences like stopwords or abbreviations—we will implement a **Hybrid Architecture**.
1.  **Semantic Stream:** We will apply **Attention Pooling** to the backbone's last hidden state. This is retained over the "Multi-Layer Fusion" of Idea 3, as attention pooling on the final layer was empirically shown to be superior for this dataset (Cite **solution_lesson_node_00014**).
2.  **Structural Stream:** We will explicitly calculate a vector of surface-level features for each pair: **Normalized Levenshtein Distance**, **Jaccard Similarity**, and **Length Ratio**.
3.  **Fusion:** The dense semantic embedding (1024-dim) will be concatenated with these explicit structural features before being passed to the classification head. This ensures the model has direct access to "exact match" signals that deep semantic models might occasionally overlook.

**Classification Head:**
We will use a **5-Class Classification Head** (outputting probabilities for scores 0.0, 0.25, 0.5, 0.75, 1.0) rather than a regression head, as this formulation better handles the discrete ordinal nature of the target (Cite **solution_lesson_node_00008**).

### Data
**Preprocessing:**
*   **Context Enrichment:** We will map the CPC context codes (e.g., "A47") to their full textual descriptions to provide explicit domain grounding (Cite **solution_lesson_node_00008**).
*   **Input Format:** `[CLS] Context Description [SEP] Anchor [SEP] Target [SEP]`.
*   **Feature Engineering:** Pre-compute the Levenshtein, Jaccard, and Length features for all training and test pairs to feed the structural stream.

### Training
**Strategy:**
We will employ **Stratified 5-Fold Cross-Validation**. This ensures robustness against data splits, which is critical given the small dataset size.

**Convergence Correction:**
Crucially, we will train each fold for **4 epochs**. Previous attempts with advanced architectures (Idea 3) failed because training was restricted to 1 epoch, which was insufficient for convergence (Cite **solution_lesson_node_00013**). With the 24-hour budget, we have ample time to allow the model to fully converge.

**Regularization:**
We will avoid "Multi-Sample Dropout" as it was shown to degrade performance in this specific fine-tuning setup (Cite **solution_lesson_node_00012**). We will instead rely on standard weight decay and the inherent regularization of the ensemble.

### Evaluation
**Inference:**
For each fold, we will predict the **Expected Value** of the probability distribution ($\sum P(c) \times c$) rather than the argmax class. This method generates smooth, continuous scores that maximize the Pearson correlation metric (Cite **solution_lesson_node_00008**).

**Ensembling:**
The final submission will be the simple average of the Expected Value predictions from all 5 folds. This reduces variance and produces a highly stable prediction.
