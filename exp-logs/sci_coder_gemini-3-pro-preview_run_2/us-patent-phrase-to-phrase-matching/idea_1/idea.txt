To establish a highly efficient baseline, I propose a **Frozen Bi-Encoder with a Linear Regression Head**. This approach balances the semantic understanding of Transformers with the speed of simple regression, avoiding the heavy computational cost of Cross-Encoders (Model 1) or the complexity of manual feature engineering (Model 2).

### Model
The architecture is a **Siamese (Bi-Encoder) Network** utilizing a pre-trained, lightweight Transformer (e.g., `all-MiniLM-L6-v2`) as a static feature extractor.
*   **Input Processing:** Unlike the Cross-Encoder (Model 1) which processes pairs together, this model processes the `anchor` and `target` phrases independently. To incorporate domain knowledge, the `context` code is appended to the `anchor` text string before encoding.
*   **Embedding Generation:** Both inputs are passed through the same **frozen** Transformer backbone. A pooling strategy (such as Mean Pooling) is applied to the output hidden states to derive fixed-size dense vector representations for the anchor ($u$) and the target ($v$).
*   **Interaction & Prediction:** The two vectors are combined via concatenation and element-wise absolute difference ($|u - v|$). This combined feature vector is fed directly into a simple **Ridge Regression (Linear)** layer to predict the similarity score.

### Data
1.  **Preprocessing:** Text is lowercased to normalize inputs. The `context` column is concatenated to the `anchor` column (e.g., "`anchor_text` [SEP] `context_code`") to condition the anchor's representation on its subject domain.
2.  **Tokenization:** The processed strings are tokenized using the pre-trained tokenizer corresponding to the chosen Transformer backbone, with truncation applied to a fixed maximum length.
3.  **Vectorization:** The entire dataset is passed through the frozen backbone once to pre-compute the embeddings ($u$ and $v$), effectively converting the NLP task into a tabular regression problem for the training phase.

### Training
1.  **Strategy:** Since the backbone is frozen, we only train the final linear layer. This reduces the optimization problem to a convex linear solve (or very fast gradient descent), taking seconds rather than hours.
2.  **Loss Function:** The model minimizes **Mean Squared Error (MSE)**. While the metric is Pearson correlation, MSE is a stable and differentiable proxy for regression tasks that correlates well with Pearson for linear outputs.
3.  **Regularization:** L2 regularization (Ridge) is applied to the linear weights to prevent overfitting, given the high dimensionality of the embeddings.

### Evaluation
1.  **Inference:** The test set `anchor` (with context) and `target` phrases are tokenized and passed through the frozen backbone to generate embeddings.
2.  **Prediction:** The pre-trained linear head computes the scores based on the embedding features.
3.  **Post-processing:** Predictions are clipped to the range [0, 1] to ensure valid output values before saving to the submission file.
