This script demonstrates the end-to-end pipeline for the Phrase Similarity task using the provided library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to use a lightweight model (`prajjwal1/bert-tiny`), reduces epochs, and sets a temporary working directory to ensure the demonstration runs quickly (under 5 minutes) and doesn't interfere with main training artifacts.
2.  **Data Processing Verification**: Loads a small debug subset of the data using `load_and_process_data`, verifies the generation of structural features, and checks the integrity of the `PhraseDataset` class.
3.  **Model Architecture Verification**: Instantiates the `DebertaV3WithFeatures` model (using the tiny backbone) and performs a forward pass with dummy data to validate tensor shapes and data flow.
4.  **Stage 1 Training (K-Fold)**: Executes the `run_kfold` function in debug mode. This simulates the cross-validation process, training the neural network on the phrase pairs and generating Out-of-Fold (OOF) predictions.
5.  **Stage 2 Training (Meta-Learner)**: Executes `train_and_predict_stacker`, which loads the predictions from Stage 1, combines them with structural features, trains a Ridge regression meta-model, and generates the final submission.
6.  **Final Validation**: Checks the generated submission file for correct formatting and value ranges.
