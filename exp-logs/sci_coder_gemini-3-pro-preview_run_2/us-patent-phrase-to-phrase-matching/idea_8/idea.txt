Based on the lessons learned from previous iterations, I propose the following optimized strategy. This solution synthesizes the architectural superiority of the **Hybrid DeBERTa-v3-Large** (Lesson 15) with the critical **Optimization Stability Protocols** (Lesson 16) and introduces a **Two-Stage Stacking** architecture to refine predictions, adhering to the guidance on ensemble quality (Lesson 20).

# Proposed Solution: Two-Stage Feature-Calibrated Homogeneous Ensemble

### Model
**Stage 1: Deep Semantic Learners (Homogeneous Ensemble)**
We will employ a **Stratified 5-Fold Ensemble** of identical, high-capacity Cross-Encoders.
*   **Backbone:** We will strictly use **`microsoft/deberta-v3-large`**, as it is the superior "strong learner" for this task. We will avoid mixing in weaker architectures like `roberta-large`, which were shown to dilute performance (Cite **solution_lesson_node_00020**).
*   **Pooling:** We will utilize **Attention Pooling** on the last hidden state, which empirically outperforms `[CLS]` token fusion (Cite **solution_lesson_node_00014**).
*   **Internal Feature Fusion:** We will concatenate the pooled semantic embedding with a vector of explicit structural features (**Normalized Levenshtein Distance, Jaccard Similarity, Length Ratio**) before the final layer. This injects deterministic "exact match" signals directly into the network (Cite **solution_lesson_node_00015**).
*   **Head:** A **5-Class Classification Head** will output probabilities for the discrete scores {0.0, 0.25, 0.5, 0.75, 1.0} (Cite **solution_lesson_node_00008**).

**Stage 2: Structural Innovation (Linear Calibration Stack)**
Instead of simple averaging, we will implement a **Ridge Regression Meta-Learner**.
*   **Input:** The meta-learner will be trained on the **Expected Value** predictions from the Stage 1 models *plus* the **Raw Structural Features** (Levenshtein, Jaccard, Length) and **One-Hot Encoded Contexts**.
*   **Purpose:** While Stage 1 fuses features internally, deep networks can sometimes "over-smooth" or hallucinate semantic connections in the presence of strong structural contradictions (e.g., antonyms that look structurally identical). This lightweight linear second stage acts as a calibration layer, allowing deterministic features to explicitly correct the neural bias (e.g., forcing a 1.0 score if Levenshtein distance is 0), effectively implementing the "Stacking" suggestion for robust aggregation (Cite **solution_lesson_node_00020**).

### Data
**Preprocessing:**
*   **Context Enrichment:** We will map CPC context codes (e.g., "A47") to their full textual descriptions to provide explicit domain grounding (Cite **solution_lesson_node_00008**).
*   **Input Format:** `[CLS] Context Description [SEP] Anchor [SEP] Target [SEP]`.
*   **Feature Engineering:** Pre-compute Jaccard, Levenshtein, and Length statistics for all pairs to feed both the Stage 1 internal fusion and the Stage 2 meta-learner.

### Training
**Strategy (Stability & Convergence):**
*   **Duration:** We will train each of the 5 folds for **5 epochs**. This ensures full convergence, correcting the undertraining issues observed in previous 1-epoch experiments (Cite **solution_lesson_node_00013**).
*   **Optimization:** We will strictly employ **Gradient Accumulation** (Effective Batch Size = 32) and **Gradient Clipping** (Max Norm = 1.0). This decouples the batch size from memory constraints and prevents the loss stagnation/divergence observed in large model fine-tuning (Cite **solution_lesson_node_00016**).
*   **Loss Function:** Cross-Entropy Loss with mild label smoothing (0.1) (Cite **solution_lesson_node_00008**).
*   **Regularization:** We will rely on standard weight decay and the ensemble itself, avoiding Multi-Sample Dropout which was shown to degrade performance (Cite **solution_lesson_node_00012**).

### Evaluation
**Inference:**
1.  **Level 1 Prediction:** For each fold, predict the **Expected Value** ($\sum P(c) \times c$) for the test set.
2.  **Level 2 Prediction:** Feed the Level 1 predictions and the explicit features into the trained Ridge Regression meta-learner to generate the final calibrated score. This ensures the submission maximizes Pearson correlation by balancing semantic understanding with structural precision.
