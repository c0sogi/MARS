### Idea 3: Rasterized BEV-YOLO

This approach simplifies the 3D detection problem into a standard 2D object detection task by converting the LiDAR point cloud into a fixed, hand-crafted "Bird's Eye View" (BEV) image. Unlike Idea 1, which uses a neural network (Pillar Feature Net) to learn how to encode point features, this method uses fast, non-parametric statistical rasterization. Unlike Idea 2, it leverages the power of Convolutional Neural Networks (CNNs) rather than classical clustering.

#### Model
The architecture consists of three streamlined components:
1.  **Input Encoder (Rasterizer)**: Instead of learning features from points, this stage deterministically quantizes the LiDAR point cloud into a 2D grid (e.g., $0.1m \times 0.1m$ resolution). For each grid cell, three fixed statistics are computed to form a 3-channel pseudo-image $(H, W, 3)$:
    *   **Max Height**: The maximum Z-coordinate of points in the cell (encoding geometry).
    *   **Mean Intensity**: The average reflectance intensity (encoding surface material).
    *   **Density**: The normalized count of points in the cell (encoding occupancy).
2.  **Backbone**: A lightweight, off-the-shelf 2D CNN, such as **ResNet-18** or **Darknet-19**. This network extracts spatial features from the pseudo-image, treating the LiDAR data exactly like a standard RGB photograph.
3.  **Detection Head**: A single-stage, anchor-based head (inspired by YOLO or SSD). For each grid cell in the final feature map, it predicts a vector containing:
    *   **2D Box**: Center offsets $(\Delta x, \Delta y)$ and dimensions $(w, l)$ in the BEV plane.
    *   **3D Extensions**: Z-coordinate $(z)$ and height $(h)$ regressions.
    *   **Orientation**: A continuous representation of the yaw angle (e.g., $\sin \theta, \cos \theta$) to avoid angle discontinuity issues.
    *   **Confidence**: Objectness score and class probabilities.

#### Data
1.  **Coordinate Transformation**: Transform all ground truth bounding boxes from the global frame to the **LiDAR sensor frame** using the provided calibration data.
2.  **Image Generation**:
    *   Define a fixed spatial range (e.g., $[-50m, 50m]$ for X/Y).
    *   Filter points outside this range.
    *   Map remaining points to grid indices and compute the Max Height, Mean Intensity, and Density maps to create the input tensors.
3.  **Target Construction**: Project the 3D ground truth boxes onto the 2D BEV grid. Assign ground truth boxes to specific anchor scales and grid cells based on Intersection over Union (IoU), creating the regression targets for the training loss.

#### Training
*   **Loss Function**: Use a standard multi-part object detection loss (e.g., YOLO Loss):
    *   **MSE (Mean Squared Error)** for regressing box dimensions, location, and 3D extensions ($z, h$).
    *   **Binary Cross-Entropy** for the objectness score (confidence) and class predictions.
    *   **Directional Loss**: A cosine similarity loss or simple MSE on the sine/cosine components for orientation.
*   **Optimizer**: Use **SGD with Momentum** or **Adam**, with a standard learning rate schedule (warmup followed by decay).
*   **Strategy**: Since the input is effectively an image, standard data augmentations like random rotation and scaling can be applied to the point cloud *before* rasterization to improve robustness.

#### Evaluation
1.  **Inference**: Pass the test set LiDAR data (converted to BEV images) through the network to obtain tensor predictions.
2.  **Decoding**: Convert the network outputs (offsets, log-dimensions, sine/cosine) back into geometric values ($x, y, z, w, l, h, \theta$) in the sensor coordinate system.
3.  **NMS**: Apply 2D Non-Maximum Suppression (NMS) on the BEV boxes to remove overlapping duplicates based on the predicted confidence scores.
4.  **Submission**: Transform the remaining valid bounding boxes from the **LiDAR sensor frame** back to the **Global frame** and format them into the required prediction string.
