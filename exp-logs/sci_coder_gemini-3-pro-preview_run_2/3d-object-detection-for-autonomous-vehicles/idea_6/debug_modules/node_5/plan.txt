The `RuntimeError` occurs because `PillarFeatureNet` attempts to reshape a zero-element tensor (resulting from an empty point cloud) using an implicit dimension (`-1`). When the total number of elements is 0, PyTorch cannot infer the size of the `-1` dimension, leading to ambiguity. To fix this, we must explicitly specify the output dimension size (`self.conv.out_features`) instead of relying on inference. Additionally, we will add a guard clause in `PointPillarsScatter` to handle empty feature tensors immediately, ensuring the pipeline robustly handles empty data states without unnecessary computation or indexing errors.
