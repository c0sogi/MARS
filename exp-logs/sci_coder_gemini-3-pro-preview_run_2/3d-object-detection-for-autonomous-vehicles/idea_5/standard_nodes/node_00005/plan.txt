Implementation strategy:
1.  **Configuration & Setup**: Import necessary modules and set random seeds. Modify `TrainConfig` to run a "fast baseline" (fewer epochs, subset of data) to ensure the task completes within the time limit while still learning.
2.  **Training**: Initialize the `Trainer` and execute the training loop. This uses the provided `CenterPointPillars` model and `LidarDataset`.
3.  **Validation & Metric Calculation**:
    *   Implement a custom evaluation loop since the provided `Trainer.validate` only returns loss.
    *   Load the validation metadata to access ground truth bounding boxes in global coordinates.
    *   Run inference on the validation set. Convert predictions from sensor coordinates to global coordinates.
    *   Implement the specific 3D IoU calculation (Ground Box Intersection $\times$ Height Intersection) using `cv2.rotatedRectangleIntersection` for the 2D component.
    *   Calculate the Mean Average Precision (mAP) across the specified IoU thresholds (0.5 to 0.95).
    *   Print the `Final Validation Metric`.
4.  **Failure Analysis**:
    *   Analyze the validation results to find True Positives.
    *   Calculate the localization error (L2 distance) for matched objects.
    *   Compute the Pearson correlation between this error and the object's distance from the ego vehicle to identify if distance is a failure factor.
5.  **Submission**:
    *   If the validation metric is positive, generate the submission file using the trained model on the test set.
