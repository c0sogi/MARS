The following script demonstrates the usage of the provided 3D object detection library. It performs the following steps:

1.  **Configuration**: Adjusts `TrainConfig` to run a minimal demonstration (1 epoch, small subset of data) to ensure execution within the time limit.
2.  **Component Verification**:
    *   **Voxelization**: Verifies the `create_voxel_grid` function transforms point clouds into the expected pillar format.
    *   **Model Architecture**: Instantiates the `CenterPointPillars` model, passes synthetic data through it, and validates the output shapes of the detection heads.
    *   **Loss Function**: Computes the loss on synthetic predictions and targets to verify the `CenterPointLoss` logic.
3.  **Pipeline Execution**:
    *   **Training**: Runs a full training cycle using the `Trainer` class on a small subset of the training data.
    *   **Inference**: Generates predictions on a small subset of the test data using the `InferenceRunner`.
