The error `ValueError: DataFrame index must be unique for orient='index'.` indicates that the `ego_pose.json` (and potentially `calibrated_sensor.json`) files contain duplicate entries for the same `token` identifier. When `set_index("token")` is called, it creates a non-unique index, which causes `to_dict("index")` to fail because it cannot map a single key to a unique row. To fix this, we must enforce uniqueness by removing duplicate tokens before creating the dictionary lookup. Cite debug_lesson_3.
