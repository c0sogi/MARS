The following script demonstrates the end-to-end usage of the provided 3D object detection library. It covers configuration setup, utility verification, dataset loading, model instantiation, loss calculation, a minimal training loop, and inference generation.

The strategy is as follows:
1.  **Configuration**: Initialize the `Config` class and override parameters (Batch Size, Epochs, Workers) to ensure the script runs quickly (debug mode).
2.  **Utilities**: Verify core geometric transformations (Quaternion to Matrix, 3D to 2D projection) using assertions.
3.  **Dataset**: Instantiate the `Mono3DDataset` in debug mode to load a small subset of data and verify tensor shapes.
4.  **Model & Loss**: Perform a forward pass with the model using real data from the dataset, calculate the loss, and verify the output structure.
5.  **Training**: Execute a single-epoch training loop using the `train_model` wrapper to generate a model checkpoint.
6.  **Inference**: Use the generated checkpoint to run the `generate_submission` function, producing a submission CSV file.
