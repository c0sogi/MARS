The issue is caused by the inference pipeline using cached metadata (`test_processed.parquet`) that contains file paths and IDs from the sample test set, rather than dynamically scanning the hidden test set provided at runtime during grading. This results in missing predictions for the actual test images, causing the grader to fail with a shape mismatch error when reconstructing 3D volumes. To fix this, we must force the inference function to ignore the cache and rescan the input directory to discover the correct files (Cite debug_lesson_7).
