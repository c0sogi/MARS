### Idea 8: 2.5D Attention U-Net

#### Model
I propose a **2.5D Attention U-Net** architecture. This design directly implements the **Attention Gates** component described in **Model 1**, which was explicitly excluded in Idea 1. It offers a structural improvement over the standard U-Net by incorporating learnable gating mechanisms that focus the model on relevant anatomical structures.

*   **Encoder (Backbone):** The model utilizes an **EfficientNet-B0** backbone pre-trained on ImageNet. This encoder extracts robust multi-scale features while remaining computationally efficient.
*   **Attention Gates:** Unlike the standard U-Net (Idea 1) or LinkNet (Idea 6) which directly merge encoder and decoder features, this model employs **Attention Gates** at the skip connections. These gates use the coarser, high-level features from the decoder as a "gating signal" to filter the high-resolution features from the encoder. This process suppresses irrelevant background noise in the skip connections and highlights the target organs (stomach, intestines) before concatenation.
*   **Decoder:** The decoder uses transposed convolutions to upsample feature maps. These upsampled maps are concatenated with the *gated* features from the encoder, followed by standard convolution blocks to refine the segmentation.
*   **Input:** The model processes **2.5D inputs** (3 channels: Slice $i-1$, Slice $i$, Slice $i+1$) to incorporate volumetric context.

#### Data
The data preparation strategy introduces contrast enhancement to improve boundary definition, distinct from the simple normalization used in previous ideas.

1.  **2.5D Stack Generation:** For every slice, we construct a 3-channel input comprising the target slice and its immediate superior and inferior neighbors. Replicate padding is used for boundary slices.
2.  **CLAHE Normalization:** Instead of simple Min-Max scaling, we apply **Contrast Limited Adaptive Histogram Equalization (CLAHE)** to each slice. This technique locally enhances contrast, helping to distinguish the subtle boundaries between the intestines and surrounding soft tissue, which is often difficult in MRI.
3.  **Resizing:** All images are resized to a fixed resolution of **256x256** pixels to maintain processing speed.
4.  **Balanced Sampling:** The training set is constructed using all positive slices (containing masks) and a random subsample (e.g., 30%) of background-only slices.

#### Training
The training pipeline employs a specialized loss function to handle the small structure of the intestines better than standard BCE.

*   **Loss Function:** We utilize **Tversky Loss**. This is a generalization of the Dice coefficient that adds hyperparameters ($\alpha$ and $\beta$) to weigh false positives and false negatives differently. By placing a higher penalty on false negatives (missing the organ), Tversky Loss effectively combats the class imbalance inherent in small organ segmentation.
*   **Optimizer:** **AdamW** is used for optimization.
*   **Scheduler:** A **Cosine Annealing** scheduler is employed to gradually reduce the learning rate, ensuring convergence to a robust minimum.
*   **Augmentation:** Standard geometric augmentations are applied: Random Horizontal/Vertical Flips and Rotations ($\pm 15^\circ$).

#### Evaluation
The evaluation process includes post-processing to optimize the 3D Hausdorff distance.

1.  **Inference:** The model generates probability maps for the test set using the 2.5D input format.
2.  **Thresholding:** A fixed threshold (0.5) is applied to binarize the predictions.
3.  **3D Connected Component Analysis:** To optimize the **3D Hausdorff distance**, the 2D predictions are stacked into 3D volumes. We identify 3D connected components for each class and **retain only the largest connected component**, removing smaller clusters of noise.
4.  **Submission:** The refined masks are converted to Run-Length Encoding (RLE) for submission.
