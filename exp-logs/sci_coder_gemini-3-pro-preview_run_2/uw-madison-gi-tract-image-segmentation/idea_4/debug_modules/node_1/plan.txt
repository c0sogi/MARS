The error is caused by Python's behavior regarding default argument values, which are evaluated at function definition time (Cite debug_lesson_5). In `library/utils.py`, `load_image` binds `resize_to=config.IMG_SIZE` when the module is imported, capturing the initial value `(266, 266)`. When `runfile.py` later updates `config.IMG_SIZE` to `(128, 128)`, `load_image` continues to use the stale default `(266, 266)`, causing a shape mismatch against the masks generated using the updated configuration.

To fix this, I will modify `load_image` to accept `None` as the default value for `resize_to` and assign `config.IMG_SIZE` inside the function body. This ensures the current runtime value of `config.IMG_SIZE` is used.
