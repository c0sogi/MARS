Based on the previous ideas and the requirement for a distinct, efficient baseline, I propose **Idea 7**, which implements a **2.5D Feature Pyramid Network (FPN)**.

### Idea 7: 2.5D EfficientNet-FPN

#### Model
I propose a **Feature Pyramid Network (FPN)** architecture. This design synthesizes the hierarchical feature extraction of **Model 2** with the lateral connectivity concepts of **Model 1**, but arranges them in a top-down pathway that is distinct from both U-Net (symmetric) and DeepLab (dilated) architectures.

*   **Encoder (Backbone):** The model utilizes an **EfficientNet-B0** backbone pre-trained on ImageNet. This encoder is chosen for its efficiency and ability to extract rich features at multiple scales (strides of 4, 8, 16, and 32) while maintaining a lower parameter count than ResNet or MobileNet.
*   **Neck (FPN):** The core component is the Feature Pyramid Network. It creates a top-down pathway that progressively upsamples semantically strong features from the deepest layer. Crucially, it uses **lateral connections** (1x1 convolutions) to merge these upsampled features with the spatially rich feature maps from the corresponding encoder stages. This results in a pyramid of feature maps (P2, P3, P4, P5) that contain both high-level semantics and low-level localization details at every scale.
*   **Head:** A lightweight segmentation head aggregates the multi-scale feature maps. It upsamples all pyramid levels to a common resolution (e.g., 1/4 of the input size), concatenates them, and applies a final convolution to predict the class probabilities.
*   **Input:** The model processes **2.5D inputs** (3 channels: Slice $i-1$, Slice $i$, Slice $i+1$) to provide volumetric context to the 2D network.

#### Data
The data preparation strategy focuses on normalizing inputs to ensure stable training for the EfficientNet backbone.

1.  **2.5D Stack Generation:** For every slice, we generate a 3-channel input image consisting of the target slice and its immediate superior and inferior neighbors. Replicate padding is used for boundary slices.
2.  **Instance Normalization:** To handle the high variance in MRI intensity, we apply **Min-Max Normalization** to each 3-channel stack individually, scaling pixel values to $[0, 1]$.
3.  **Resizing:** All input images are resized to a standard resolution of **256x256** pixels. This resolution is optimal for FPN, allowing the pyramid levels to retain sufficient spatial dimensions for accurate boundary prediction.
4.  **Stratified Sampling:** The training set is constructed using all positive slices (containing masks) and a random 50% subsample of negative slices (background). This balances the need for background context with training speed.

#### Training
The training procedure is designed to be robust and converge quickly without complex regularization.

*   **Loss Function:** We use a sum of **Binary Cross Entropy (BCE) and Dice Loss**. BCE ensures pixel-wise classification accuracy, while Dice Loss improves the overlap of the predicted masks, directly optimizing the competition metric.
*   **Optimizer:** **AdamW** is used to optimize the model weights, providing efficient convergence with decoupled weight decay.
*   **Scheduler:** A **Cosine Annealing** learning rate scheduler is employed to gradually reduce the learning rate from 1e-3 to 1e-6, allowing the model to fine-tune its weights in the final epochs.
*   **Augmentation:** Minimal, low-cost augmentations are applied: Random Horizontal Flips, Vertical Flips, and 90-degree Rotations.

#### Evaluation
The evaluation pipeline includes specific post-processing to minimize the 3D Hausdorff distance.

1.  **Inference:** The model predicts class probability maps for the test set using the 2.5D input format.
2.  **Thresholding:** A fixed threshold of 0.5 is applied to binarize the probability maps.
3.  **3D Connected Component Analysis:** To optimize the **3D Hausdorff distance**, the 2D predictions are stacked into 3D volumes for each case. We identify 3D connected components for each class and **retain only the largest connected component**, removing smaller clusters of false positives which disproportionately penalize the Hausdorff metric.
4.  **Submission:** The refined masks are converted to Run-Length Encoding (RLE) for submission.
