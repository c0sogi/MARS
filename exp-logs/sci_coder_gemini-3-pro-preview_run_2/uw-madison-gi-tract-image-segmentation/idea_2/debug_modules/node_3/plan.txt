The error `RuntimeError: Unknown model (mit_b0)` occurs because `mit_b0` is not a valid model name in the installed version of the `timm` library. To resolve this, I will switch the backbone to `resnet18`, which is a standard and available model. Since `resnet18` typically returns 5 feature maps (including the stem) when `features_only=True`, while the SegFormer decoder implementation expects exactly 4, I will also update `library/model.py` to discard the first feature map (the stem) if 5 are returned, ensuring the shapes match the decoder's expectations. I will ensure the `SEARCH` blocks match the file content exactly (Cite debug_lesson_4).
