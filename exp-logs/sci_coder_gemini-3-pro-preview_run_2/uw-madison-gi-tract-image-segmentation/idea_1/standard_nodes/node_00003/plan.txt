The issue is a resolution mismatch between the model's output and the required submission format. The model predicts masks at a fixed 256x256 resolution, but the submission requires RLE encoding based on the original image dimensions, which vary across the dataset. This causes the "all input arrays must have the same shape" error during grading when the RLEs are decoded.

To fix this:
1.  Modify `library/dataset.py` to return the original image height and width in `__getitem__` when in test mode.
2.  Modify `library/inference.py` to import `cv2`, unpack the dimensions from the dataloader, and resize the predicted masks to the original dimensions before RLE encoding.
