This script demonstrates the end-to-end pipeline for the MRI segmentation task using the provided library files. It begins by configuring the environment for a rapid debug run, ensuring the code executes quickly. It then verifies the data loading logic by inspecting the 2.5D dataset structure. Following this, it validates the `GhostUNet` model architecture by performing a forward pass with dummy data. The script then executes the full training loop using `library.train.run_training`, which handles data balancing, training, and validation. After training, it runs the inference pipeline via `library.inference.run_inference` to generate predictions on the test set. Finally, it validates the generated submission file and performs unit tests on the custom evaluation metrics (Dice coefficient and 3D Hausdorff distance).
