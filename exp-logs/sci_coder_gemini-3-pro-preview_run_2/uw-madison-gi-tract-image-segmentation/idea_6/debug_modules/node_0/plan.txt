The following script demonstrates the end-to-end usage of the provided library files for the stomach and intestine segmentation task.

**Implementation Strategy:**
1.  **Configuration Setup**: We modify the global `Config` class to enable `DEBUG` mode, reduce `EPOCHS` to 1, and lower the `BATCH_SIZE`. This ensures the demonstration runs quickly on a small subset of data.
2.  **Logic Verification**:
    *   **Dataset**: We manually instantiate the `UWDataset` to verify that data loading, 2.5D stacking, and transformations produce tensors of the correct shape `(3, 256, 256)`.
    *   **Model**: We instantiate the `LinkNet` model and perform a forward pass with dummy data to confirm the architecture outputs the expected shape `(B, 3, 256, 256)`.
    *   **Metrics**: We validate the `dice_coefficient` and `hausdorff_distance_3d` functions with known inputs to ensure metric calculation correctness.
3.  **Training Pipeline**: We execute the `train()` function from `library.train`. This handles metadata processing, data loading, and the training loop with backpropagation and validation.
4.  **Inference Pipeline**: We execute the `run_inference()` function from `library.inference`. This loads the trained model, generates predictions on the test set, applies 3D post-processing, and saves the submission file.
5.  **Output Verification**: Finally, we check that the model checkpoint and submission CSV are generated correctly.
