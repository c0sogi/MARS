The following script demonstrates the end-to-end usage of the provided library components for the Stomach and Intestines Segmentation task.

The implementation strategy includes:
1.  **Configuration Setup**: Overrides default `Config` settings to use a temporary working directory and enables debug mode for rapid execution.
2.  **Utility Verification**: Validates the correctness of RLE encoding/decoding and 3D post-processing (largest connected component) using synthetic data.
3.  **Data Loading**: Loads a small subset of the provided metadata, creates a `UWMDataset`, and verifies the shape and integrity of the 2.5D image stacks and segmentation masks.
4.  **Model Initialization**: Instantiates the `BiSeNet25D` model and performs a forward pass with dummy data to verify output dimensions.
5.  **Training Loop**: Runs a single epoch of training and validation on the subset data using `train_one_epoch` and `validate` functions to demonstrate the training pipeline.
6.  **Inference & Submission**: Simulates the inference process by generating a mock test set, running predictions, applying 3D post-processing, and generating a submission file.
