### Idea 9: 2.5D Bilateral Segmentation Network (BiSeNet)

#### Model
I propose a **2.5D BiSeNet** architecture. This design diverges from the encoder-decoder topology of U-Net (Idea 1) and the dilated strategies of DeepLab (Idea 3) by explicitly decoupling "spatial detail" and "semantic context" into two parallel processing paths. This structure is specifically optimized for real-time inference speed while maintaining high boundary precision.

*   **Spatial Path:** This branch consists of a shallow, wide CNN (3 convolution layers with stride 2) operating directly on the high-resolution input. It preserves a large spatial dimension (1/8th of the original image size), ensuring that fine anatomical details and the exact boundaries of the intestines are encoded without being lost to aggressive downsampling.
*   **Context Path:** This branch utilizes a lightweight **MobileNetV2** backbone (derived from Model 5) that downsamples the input rapidly. Its purpose is to extract high-level semantic information (distinguishing "organ" from "background") and a large receptive field, without the computational burden of maintaining high resolution.
*   **Feature Fusion Module (FFM):** The outputs of the two paths are merged using a fusion module. This module concatenates the features and applies channel-wise attention to balance the trade-off between the rich spatial details from the Spatial Path and the semantic class information from the Context Path.
*   **Input:** The model processes **2.5D inputs** (3 channels: Slice $i-1$, Slice $i$, Slice $i+1$) to incorporate volumetric context into the 2D network.

#### Data
The data preparation strategy focuses on creating a standardized input stream that maximizes the efficiency of the two-path architecture.

1.  **2.5D Stack Generation:** For every target slice, we construct a 3-channel image containing the target slice flanked by its superior ($i-1$) and inferior ($i+1$) neighbors. Replicate padding is used for the start and end of scans.
2.  **Min-Max Normalization:** We apply min-max normalization to each 3-channel stack, scaling pixel intensities to the range $[0, 1]$. This standardizes the MRI data, which often varies in intensity ranges between cases.
3.  **Resizing:** All input images are resized to a fixed resolution of **256x256** pixels. This resolution is sufficient for the Spatial Path to resolve boundaries while keeping the Context Path extremely fast.
4.  **Balanced Sampling:** The training set is constructed using all positive slices (containing masks) and a random 50% subsample of negative slices (background). This ensures the model learns to reject background artifacts without wasting time on the vast majority of empty slices.

#### Training
The training pipeline utilizes auxiliary supervision to ensure rapid and stable convergence of the deep Context Path.

*   **Loss Function:** We employ a composite **BCE + Dice Loss** as the primary objective.
*   **Auxiliary Loss:** To facilitate gradient flow in the deep Context Path, we attach an **Auxiliary Head** to the output of the MobileNetV2 backbone. The total loss is calculated as $L_{total} = L_{primary} + 0.1 \times L_{aux}$. This "Booster Training" strategy helps the semantic branch learn faster.
*   **Optimizer:** **AdamW** is used for its efficiency and handling of weight decay.
*   **Scheduler:** A **Cosine Annealing** learning rate scheduler is implemented to gradually lower the learning rate, allowing the model to settle into a robust minimum.

#### Evaluation
The evaluation process focuses on 3D consistency to maximize the Hausdorff distance score.

1.  **Inference:** The model generates probability maps for every slice in the test set using the 2.5D input format.
2.  **Thresholding:** A fixed threshold (0.5) is applied to binarize the predictions.
3.  **3D Connected Component Analysis:** To optimize the **3D Hausdorff distance**, the 2D predictions are stacked into 3D volumes for each case. We identify 3D connected components for each class and **retain only the largest connected component**, discarding smaller floating artifacts (noise) that would otherwise severely penalize the Hausdorff metric.
4.  **Submission:** The refined masks are converted to Run-Length Encoding (RLE) for the final submission.
