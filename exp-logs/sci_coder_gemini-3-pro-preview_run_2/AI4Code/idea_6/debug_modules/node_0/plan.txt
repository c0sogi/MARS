The following script demonstrates the usage of the provided Stacked Hybrid Linear-Tree Ranking pipeline. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to run in `DEBUG` mode with a small sample size and reduced model complexity (fewer trees, lower dimensionality) to ensure execution within the time limit.
2.  **Reproducibility**: Sets random seeds using the provided utility.
3.  **Data Loading**: Uses `NotebookDataLoader` to load a small subset of training data and validates the schema.
4.  **Feature Extraction**: Instantiates `FeaturePipeline`, fits it on the data, and transforms text into both sparse (Level 1) and dense (Level 2) features. It verifies the output dimensions.
5.  **Model Training**: Demonstrates the training and prediction interfaces for both `Level1Ridge` and `Level2GBM` using the generated features.
6.  **Pipeline Orchestration**: Uses `PipelineManager` to run the full end-to-end flow: `train_stacking_ensemble` (generating OOF preds, stacking, training) and `predict_and_sort` (inference on test set and anchor-based sorting).
7.  **Metric Validation**: Manually verifies the `kendall_tau_metric` function with a known synthetic example to ensure the scoring logic is correct.
