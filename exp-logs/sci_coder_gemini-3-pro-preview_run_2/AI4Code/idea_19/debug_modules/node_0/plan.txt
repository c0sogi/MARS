The following script demonstrates the usage of the provided library files for the AI4Code notebook sorting task. It follows a step-by-step approach:

1.  **Configuration Override**: Adjusts global settings (paths, debug mode, hyperparameters) to ensure the demonstration runs quickly (under 1 minute) and uses a small subset of data.
2.  **Utility Verification**: Validates the text preprocessing and Kendall Tau metric calculation logic.
3.  **Data Loading**: Demonstrates loading the training and validation data using `data_loader.py`.
4.  **Feature Engineering**: Generates Multi-View features (Lexical, Latent, Symbolic) using `feature_engineering.py`.
5.  **Model Training (Stage 1 & 2)**: Trains the Ridge Regressor (Stage 1) and LightGBM (Stage 2) using `model_zoo.py`.
6.  **Pipeline Execution**: Runs the full inference pipeline using `pipeline.py` to generate a submission file.
