The issue is caused by Python's early binding of default argument values. In `library/sparse_engine.py`, the `save` and `load` methods define `output_dir=Config.WORKING_DIR` and `input_dir=Config.WORKING_DIR` in their signatures. Python evaluates `Config.WORKING_DIR` at import time (resolving to `./working/idea_3`), so when `runfile.py` later updates `Config.WORKING_DIR` to `./working/demo_output`, the methods continue to use the stale default value.

To fix this, I will modify `library/sparse_engine.py` to set the default value of these arguments to `None` and resolve the current value of `Config.WORKING_DIR` inside the function body. This ensures the method always uses the runtime configuration. Cite debug_lesson_2.
