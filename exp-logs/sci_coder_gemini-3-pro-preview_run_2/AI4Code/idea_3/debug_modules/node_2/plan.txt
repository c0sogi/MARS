The `AssertionError` occurs because the `save` and `load` methods in `SparseRanker` and `DenseEngine` use `Config.WORKING_DIR` as a default argument. In Python, default arguments are evaluated only once at function definition time. Consequently, even though `runfile.py` updates `Config.WORKING_DIR` to `./working/demo_output` at runtime, the methods continue to use the original value (`./working/idea_3`) captured during import. This causes the models to be saved in the wrong directory, leading to the file not found error during verification.

To fix this, I will change the default value of the directory arguments to `None` and assign `Config.WORKING_DIR` inside the method body. This ensures that the current runtime value of `Config.WORKING_DIR` is used.
