### Implementation Strategy

1.  **Configuration Override**: We modify the `Config` class attributes at runtime to enable `DEBUG` mode, reduce the `EPOCHS` to 1, set a small `BATCH_SIZE`, and limit the `VOCAB_SIZE`. This ensures the script processes only a tiny subset of the data (20 samples) and completes training quickly.
2.  **Data Pipeline Verification**: We utilize `load_data_factory` to load and preprocess the data. We assert that the resulting dataframes are non-empty and contain the necessary columns (`source`, `rank`, `id`).
3.  **Sparse Engine Demo**: We execute `train_sparse_model` to train the TF-IDF + Ridge Regression pipeline. We verify that the model artifacts (vectorizer and model files) are correctly saved to the working directory and that the model can generate predictions of the correct shape.
4.  **Dense Engine Demo**: We execute `train_dense_model` to train the Transformer-based pipeline. We verify that the PyTorch model weights are saved and that the engine produces valid predictions on the validation set.
5.  **Inference & Submission**: We run `generate_submission`, which uses the trained models to predict ranks for the test set and reconstructs the cell order using `sort_notebooks`. We validate the output CSV format.
6.  **Metric Validation**: We explicitly test the `compute_kendall_tau` function with synthetic perfect and reversed predictions to ensure the scoring logic is correct (expecting 1.0 and -1.0 respectively).
