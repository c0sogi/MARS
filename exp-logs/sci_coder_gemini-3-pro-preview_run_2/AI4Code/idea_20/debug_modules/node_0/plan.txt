Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override key parameters (e.g., `DEBUG=True`, `DEBUG_SAMPLE_SIZE=50`, `n_estimators=10`) to ensure the entire pipeline runs within minutes while using minimal resources.
2.  **Utility Verification**: distinctively test `count_inversions` and `kendall_tau` from `library.utils` with hardcoded examples to verify mathematical correctness.
3.  **Component Integration**: Instead of testing each class in isolation, execute the high-level `run_training` and `run_inference` functions from the pipeline modules. This implicitly demonstrates and verifies `data_loader`, `vectorizer`, `feature_extractor`, and `model_wrapper` working in concert.
4.  **Output Validation**: After the pipelines execute, verify that the expected artifacts (models, parquet files, submission CSV) exist and have the correct dimensions/formats.
5.  **Reproducibility**: Set global random seeds at the start.
