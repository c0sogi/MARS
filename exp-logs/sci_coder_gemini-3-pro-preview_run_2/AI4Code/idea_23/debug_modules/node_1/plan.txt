The issue is that the `NotebookLoader` discards the raw `cell_order` string during data processing, but the evaluation function `compute_score` explicitly requires this column to reconstruct the ground truth sequence for the Kendall Tau metric. Furthermore, `runfile.py` passes the cell-level DataFrame directly to `compute_score`, which would result in an incorrect metric calculation (weighting notebooks by their cell count) even if the column were present.

To fix this, I will:
1.  Update `library/data_loader.py` to preserve the `cell_order` column in the processed DataFrame when loading training/validation data (Cite debug_lesson_6).
2.  Update `runfile.py` to deduplicate the validation DataFrame by `id` before passing it to `compute_score`, ensuring each notebook is evaluated exactly once.
