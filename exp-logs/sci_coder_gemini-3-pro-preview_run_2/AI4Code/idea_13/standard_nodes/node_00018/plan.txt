The implementation strategy follows a sequential orchestration of the three-stage pipeline defined in the task. 

1.  **Configuration & Setup**: The script initializes the environment by setting random seeds for reproducibility and monkeypatching `tqdm` to suppress progress bars as required. It overrides specific `Config` parameters (reducing epochs and estimators) to ensure the pipeline completes within the 2-hour limit while maintaining sufficient capacity to beat the baseline.
2.  **Stage 1 (Ridge Regression)**: The script instantiates `Stage1Ridge` and runs it. This generates sparse TF-IDF features and trains a Ridge regressor to produce Out-Of-Fold (OOF) predictions, which serve as a strong lexical baseline.
3.  **Stage 2 (Metric Learning)**: The script instantiates `Stage2Metric` and trains a Siamese Network. This model learns to project markdown and code cells into a shared metric space where semantically related cells are geometrically close, addressing the vocabulary mismatch problem.
4.  **Stage 3 (LightGBM)**: The script instantiates `Stage3LGBM`. It generates "Anchor Features" (statistics of the nearest code cells in the learned metric space) and combines them with Ridge predictions to train a LightGBM ranker.
5.  **Validation & Analysis**: After training, the script loads the validation features, generates predictions, and reconstructs the cell order. It calculates the **Kendall Tau** metric and prints it in the specific format required. It then performs failure analysis by correlating prediction errors with input features to identify systematic weaknesses.
6.  **Submission**: Finally, the script checks if the validation metric exceeds the strict threshold of `0.7959051868218839`. If successful, it runs the inference pipeline on the test set and generates `submission.csv`.
