The following script demonstrates the usage of the provided library modules for the Notebook Cell Ordering task. It performs the following steps:

1.  **Configuration**: Overrides default hyperparameters in `Config` to enable a fast, low-resource demonstration (Debug mode, small vocabulary, few boosting rounds).
2.  **Metrics Verification**: Validates the `count_inversions` and `score_dataframe` functions with known inputs to ensure the scoring logic is correct.
3.  **Data Loading**: Uses `load_dataset` to parse a subset of training notebooks and verifies the structure of the returned DataFrames.
4.  **Feature Engineering**: Demonstrates the `FeatureEngineer` class to generate TF-IDF, LSA, and Anchor features, validating the output dimensions.
5.  **Modeling Pipeline**: Instantiates `StackedRanker` to execute the full two-stage training (Ridge + LightGBM) and inference pipeline, resulting in a submission file.
