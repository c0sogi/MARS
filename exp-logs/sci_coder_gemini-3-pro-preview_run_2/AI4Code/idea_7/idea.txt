Based on the "Lessons" learned, particularly the success of the **Anchor-Based Regression** (Cite solution_lesson_node_00001), the necessity of the **Full Dataset** with **Bigrams** (Cite solution_lesson_node_00002, solution_lesson_node_00004), and the efficacy of **Hybrid Stacking** (Cite solution_lesson_node_00011), I propose a **Stacked Hybrid with Nearest-Neighbor Semantic Anchoring**.

This solution structurally evolves the "Stacked Hybrid" approach (Idea 6) by revolutionizing how "Context" is fed into the refinement stage. Previous attempts to use "Global Code Context" (Lesson 11) or "Dense Transformer Context" (Lesson 10) treated the notebook's code as a bag-of-words or a monolithic vector, losing the critical spatial information provided by the ordered code skeleton. This new architecture explicitly calculates the **relative semantic position** of a markdown cell by finding its "Nearest Neighbor" among the ordered code cells.

### Model
The architecture is a **Two-Stage Stacked Regression Pipeline**:

1.  **Stage 1: Sparse Lexical Regressor (The "Signpost" Model)**
    *   **Component:** A **Ridge Regression** model.
    *   **Role:** This component is strictly preserved from the lessons to capture explicit "signpost" keywords (e.g., "Introduction" $\to$ 0.0).
    *   **Input:** High-dimensional **TF-IDF** vectors (Unigrams + Bigrams).

2.  **Stage 2: Anchor-Aware Gradient Booster (The "Refinement" Model)**
    *   **Component:** A **LightGBM Regressor**.
    *   **Role:** This model refines the linear prediction by incorporating non-linear interactions and, crucially, **Local Semantic Anchoring**.
    *   **Input Features:**
        *   **Ridge Prediction:** The output from Stage 1.
        *   **Markdown LSA:** Latent Semantic Analysis vectors (128-dim) of the markdown text (Cite solution_lesson_node_00011).
        *   **Nearest-Neighbor Anchor Features (Innovation):** Instead of a global context vector, we compute the similarity between the markdown cell and *every* ordered code cell in the notebook. We extract:
            *   **Anchor Rank:** The normalized rank (0.0-1.0) of the code cell with the highest cosine similarity to the markdown cell. This tells the tree: "This text is semantically most similar to the code at position $X$."
            *   **Anchor Similarity:** The cosine similarity score to that nearest code cell (confidence).
            *   **Top-3 Anchor Mean:** The average rank of the top-3 most similar code cells (for robustness).
        *   **Notebook Metadata:** Total cells, markdown ratio.

### Data
**Preprocessing for Training:**
1.  **Target Generation:** Compute **Normalized Rank** $y \in [0, 1]$ for all markdown cells in the **Full Training Dataset** (Cite solution_lesson_node_00001, solution_lesson_node_00002).
2.  **Global Vectorization (Stage 1):**
    *   Fit a **TF-IDF Vectorizer** on the full markdown corpus.
    *   **Configuration:** **Vocabulary=60,000**, **N-gram range=(1, 2)**, **Sublinear TF=True**, and **No Accent Stripping** (Cite solution_lesson_node_00004, solution_lesson_node_00005).
3.  **Feature Engineering (Stage 2):**
    *   **LSA:** Fit `TruncatedSVD` (n_components=128) on the TF-IDF matrix.
    *   **Anchor Calculation:** For each notebook, use the TF-IDF vectors of its markdown cells ($M$) and code cells ($C$). Compute the similarity matrix $S = M \cdot C^T$. For each markdown row, find the column index $j$ (code cell) with the maximum value. Retrieve the fixed rank of code cell $j$ to create the `Anchor Rank` feature.

**Preprocessing for Evaluation:**
1.  Apply the fitted TF-IDF and SVD pipelines to the test data.
2.  Perform the **Anchor Calculation** on each test notebook using its provided (ordered) code cells to generate the Stage 2 features.

### Training
1.  **Stage 1 (Cross-Validation):**
    *   Train the Ridge Regressor using **5-Fold Cross-Validation** on the full dataset.
    *   Generate **Out-Of-Fold (OOF)** predictions for the entire training set to serve as unbiased features for Stage 2.
    *   Retrain the Ridge model on the full dataset for inference.
2.  **Stage 2 (Stacking):**
    *   Construct the Stage 2 dataset using OOF predictions, LSA vectors, and Anchor Features.
    *   Train the **LightGBM Regressor** to predict Normalized Rank, minimizing **Mean Absolute Error (MAE)**.
    *   **Strategy:** Use early stopping with a validation split. This stage learns to correct the Ridge model (e.g., "If Ridge says 0.8 but the Nearest Anchor Rank is 0.4 with high confidence, shift prediction towards 0.4").

### Evaluation
1.  **Pipeline Inference:**
    *   Generate Stage 1 predictions (Ridge).
    *   Generate Stage 2 features (LSA + Nearest Anchor Ranks).
    *   Generate Final Predictions using the LightGBM model.
2.  **Anchor-Based Sorting:**
    *   Assign fixed, equidistant ranks ($0.0, \dots, 1.0$) to the ordered code cells (Cite solution_lesson_node_00001).
    *   Combine code cells (fixed ranks) and markdown cells (Stage 2 predicted ranks) into a unified list.
    *   Sort the list by rank to produce the final `cell_order`.
