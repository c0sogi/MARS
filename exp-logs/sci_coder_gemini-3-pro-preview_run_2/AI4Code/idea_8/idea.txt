Based on the comprehensive analysis of the "Lessons" and "Previous Ideas," I propose a **Dual-View Stacked Ranking with Lexical and Semantic Anchoring**.

This solution structurally evolves the state-of-the-art "Stacked Hybrid with Nearest-Neighbor Anchoring" (Idea 7 / Lesson 00012) by addressing its primary limitation: the reliance on purely lexical (TF-IDF) matching to locate the "anchor" code cells. By introducing a parallel **Dense Semantic Retrieval** stream, the model can correctly localize markdown cells that describe code concepts (e.g., "Preprocessing") without sharing exact vocabulary (e.g., `StandardScaler`), while retaining the precision of exact keyword matching.

# Model

The architecture is a **Two-Stage Stacked Regression Pipeline** that integrates a linear "signpost" model with a non-linear "refinement" model, enhanced by a novel Dual-View Anchoring mechanism.

1.  **Stage 1: Sparse Lexical Regressor (The "Signpost" Model)**
    *   **Component:** A **Ridge Regression** model.
    *   **Role:** Preserved from the lessons to serve as the high-bias baseline. It maps explicit "signpost" keywords (e.g., "Introduction", "Submission") directly to normalized ranks using high-dimensional sparse features.
    *   **Input:** **TF-IDF** vectors (Unigrams + Bigrams) of the markdown text.

2.  **Stage 2: Dual-Anchor Gradient Booster (The "Refinement" Model)**
    *   **Component:** A **LightGBM Regressor**.
    *   **Role:** This model refines the Ridge prediction by arbitrating between two distinct "localization" signals—Lexical and Semantic—to determine the markdown cell's position relative to the code skeleton.
    *   **Input Features:**
        *   **Ridge Prediction:** The output from Stage 1.
        *   **Lexical Anchor Features (Exploitation):** Derived from TF-IDF similarity (Cite Lesson 00012). Includes the **Rank** of the code cell with the highest cosine similarity to the markdown, and the **Similarity Score**. Captures exact matches (e.g., "plot" $\leftrightarrow$ `plt.plot`).
        *   **Semantic Anchor Features (Innovation):** Derived from **Dense Embeddings**. We use a lightweight pre-trained Transformer (e.g., `all-MiniLM-L6-v2`) to embed all markdown and code cells. We identify the "Semantic Nearest Neighbor" code cell for each markdown cell. Features include the **Rank** of this semantic neighbor and the **Dense Similarity Score**. Captures conceptual matches (e.g., "Scaling" $\leftrightarrow$ `RobustScaler`).
        *   **Context & Metadata:** LSA vectors of the markdown text (Cite Lesson 00011) and notebook metadata (length, ratios).

# Data

**Preprocessing for Training:**
1.  **Target Generation:** Calculate the **Normalized Rank** $y \in [0, 1]$ for all markdown cells in the **Full Training Dataset** relative to the fixed code cell skeleton (Cite Lesson 00001, Lesson 00002).
2.  **Sparse Pipeline (Stage 1 & Lexical Anchor):**
    *   Fit a **TF-IDF Vectorizer** on the full markdown corpus.
    *   **Configuration:** Vocabulary=60,000, N-gram range=(1, 2), Sublinear TF=True, and **No Accent Stripping** (Cite Lesson 00004, Lesson 00005).
    *   Compute the **Lexical Anchor** for each markdown cell by calculating the sparse cosine similarity against all code cells in its notebook and selecting the argmax.
3.  **Dense Pipeline (Semantic Anchor):**
    *   Use a pre-trained `sentence-transformers` model to generate dense embeddings for all markdown and code cells (batched inference).
    *   Compute the **Semantic Anchor** for each markdown cell by calculating the dense cosine similarity against all code cells in its notebook and selecting the argmax.

**Preprocessing for Evaluation:**
1.  Apply the TF-IDF and Dense Embedding pipelines to the test data.
2.  Extract the fixed sequence of **Code Cell IDs** for each test notebook.
3.  Compute both Lexical and Semantic Anchor features (Rank and Similarity) relative to the test notebook's code skeleton.

# Training

1.  **Stage 1 (Cross-Validation):**
    *   Train the Ridge Regressor using **5-Fold Cross-Validation** on the full dataset.
    *   Generate **Out-Of-Fold (OOF)** predictions for the entire training set.
    *   Retrain the Ridge model on the full dataset for final inference.
2.  **Stage 2 (Stacking):**
    *   Construct the Stage 2 dataset combining: OOF Ridge Predictions, Lexical Anchor Features, Semantic Anchor Features, and LSA vectors.
    *   Train the **LightGBM Regressor** to predict Normalized Rank, minimizing **Mean Absolute Error (MAE)**.
    *   **Strategy:** Use early stopping with a validation split. The tree will learn to weight the Lexical Anchor higher when exact keywords are present (high sparse sim) and switch to the Semantic Anchor when vocabulary is disjoint (high dense sim but low sparse sim).

# Evaluation

1.  **Pipeline Inference:**
    *   Generate Stage 1 predictions (Ridge).
    *   Generate Stage 2 features (Dual Anchors + LSA).
    *   Predict Final Rank using the LightGBM model.
2.  **Anchor-Based Sorting:**
    *   Assign fixed, equidistant ranks ($0.0, \dots, 1.0$) to the ordered code cells (Cite Lesson 00001).
    *   Combine the code cells (fixed ranks) and markdown cells (predicted ranks) into a single list.
    *   Sort the list by rank to produce the final `cell_order`.
