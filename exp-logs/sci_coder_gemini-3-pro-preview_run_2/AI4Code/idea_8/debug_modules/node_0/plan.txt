The following script demonstrates the usage of the provided library components to solve the notebook ordering task. It first validates the Kendall Tau metric implementation with a controlled example. Then, it configures the pipeline for a rapid demonstration run by overriding configuration parameters (reducing feature dimensions and model complexity) and directing outputs to a specific working directory. Finally, it executes the full training and inference pipeline on a small subset of data (`debug=True`) and asserts the generation of valid model artifacts and submission files.
