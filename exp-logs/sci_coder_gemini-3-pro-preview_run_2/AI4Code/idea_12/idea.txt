Based on the "Lessons" learned, particularly the trade-off between semantic depth and scalability (Cite solution_lesson_node_00013) and the superiority of smoothed neighborhood statistics over single-point estimates (Cite solution_lesson_node_00015), I propose a **Stacked Hybrid Ranking with Uncertainty-Aware Multi-View Anchoring**.

This solution structurally evolves the "Stacked Hybrid" architecture by introducing a **Dual-Pipeline Neighborhood Mechanism**. It replaces the computationally expensive and data-limited Transformer approaches with a scalable **Latent Semantic Analysis (LSA)** stream, and it replaces brittle "nearest neighbor" features with robust **Top-K Neighborhood Aggregations**.

# Model

The architecture is a **Two-Stage Stacked Regression Pipeline** designed to arbitrate between explicit lexical signals ("Lexical View") and implicit conceptual relationships ("Latent View") to determine the optimal cell order.

1.  **Stage 1: Sparse Lexical Regressor (The "Signpost" Model)**
    *   **Component:** A **Ridge Regression** model.
    *   **Role:** Explicitly preserved from the lessons to serve as the high-bias, low-variance baseline. It maps "signpost" keywords (e.g., "Introduction", "Submission") directly to normalized ranks using high-dimensional sparse features (Cite solution_lesson_node_00010).
    *   **Input:** High-dimensional **TF-IDF** vectors.

2.  **Stage 2: Multi-View Neighborhood Gradient Booster (The "Refinement" Model)**
    *   **Component:** A **LightGBM Regressor**.
    *   **Role:** This model refines the linear prediction by integrating non-linear interactions and **Uncertainty-Aware Anchoring**. It consumes signals from two distinct "views" of the notebook content:
        *   **Lexical View (Exploitation):** Based on Sparse TF-IDF similarity. Captures exact keyword matches (e.g., `plt.plot` $\leftrightarrow$ "plot").
        *   **Latent View (Innovation):** Based on Dense SVD similarity. Captures conceptual alignment (e.g., `StandardScaler` $\leftrightarrow$ "Preprocessing") efficiently across the full dataset (Cite solution_lesson_node_00013).
    *   **Input Features:**
        *   **Ridge Prediction:** The output from Stage 1 (Cite solution_lesson_node_00011).
        *   **Lexical Neighborhood Features:** Aggregated statistics (Mean Rank, Weighted Mean Rank) of the **Top-K** code cells most similar to the markdown cell in TF-IDF space (Cite solution_lesson_node_00015).
        *   **Latent Neighborhood Features:** Aggregated statistics (Mean Rank, Weighted Mean Rank) of the **Top-K** code cells most similar to the markdown cell in SVD space.
        *   **Uncertainty Features:** The **Standard Deviation** of the ranks of the Top-K neighbors in both views. This allows the tree to assess the "confidence" of the anchor signal (e.g., low std dev = focused signal, high std dev = ambiguous signal).
        *   **Context & Metadata:** LSA vectors of the markdown text and notebook metadata.

# Data

**Preprocessing for Training:**
1.  **Target Generation:** Calculate the **Normalized Rank** $y \in [0, 1]$ for all markdown cells in the **Full Training Dataset** relative to the fixed code cell skeleton (Cite solution_lesson_node_00001, solution_lesson_node_00002).
2.  **Global Vectorization:**
    *   Fit a **TF-IDF Vectorizer** on the full markdown corpus.
    *   **Configuration:** Vocabulary=60,000, N-gram range=(1, 2), Sublinear TF=True, and **No Accent Stripping** (Cite solution_lesson_node_00004, solution_lesson_node_00005).
3.  **Latent Semantic Space Construction:**
    *   Fit **Truncated SVD** (e.g., 128 components) on the Markdown TF-IDF matrix.
    *   **Project Code Cells:** Transform the notebook's code cells into this same SVD space by projecting their TF-IDF vectors. This aligns code and text in a shared "Topic Space" without the overhead of Transformers (Cite solution_lesson_node_00013).
4.  **Neighborhood Extraction (The Core):**
    *   **Lexical View:** Compute sparse cosine similarity between each markdown cell and all code cells in its notebook. Retrieve the ranks of the **Top-K** (e.g., K=5) matches. Compute Mean, Weighted Mean, and Standard Deviation of these ranks.
    *   **Latent View:** Compute dense cosine similarity between each markdown cell and all code cells in the SVD space. Retrieve the ranks of the **Top-K** matches. Compute Mean, Weighted Mean, and Standard Deviation.

**Preprocessing for Evaluation:**
1.  Apply the fitted TF-IDF and SVD pipelines to the test data.
2.  Extract the fixed sequence of **Code Cell IDs** for each test notebook.
3.  Compute Lexical and Latent Neighborhood features relative to the test notebook's code skeleton.

# Training

1.  **Stage 1 (Cross-Validation):**
    *   Train the Ridge Regressor using **5-Fold Cross-Validation** on the full dataset.
    *   Generate **Out-Of-Fold (OOF)** predictions for the entire training set to serve as unbiased features for Stage 2 (Cite solution_lesson_node_00011).
    *   Retrain the Ridge model on the full dataset for final inference.
2.  **Stage 2 (Stacking):**
    *   Construct the Stage 2 dataset combining: OOF Ridge Predictions, Lexical Neighborhood Features, Latent Neighborhood Features, Uncertainty Features, and Metadata.
    *   Train the **LightGBM Regressor** to predict Normalized Rank, minimizing **Mean Absolute Error (MAE)**.
    *   **Strategy:** Use early stopping with a validation split. The model will learn to trust the Ridge baseline when neighborhood variance is high, and trust the anchors when variance is low and similarity is high.

# Evaluation

1.  **Pipeline Inference:**
    *   Generate Stage 1 predictions (Ridge).
    *   Generate Stage 2 features (Multi-View Neighborhoods + Uncertainty).
    *   Predict Final Rank using the LightGBM model.
2.  **Anchor-Based Sorting:**
    *   Assign fixed, equidistant ranks ($0.0, \dots, 1.0$) to the ordered code cells (Cite solution_lesson_node_00001).
    *   Combine the code cells (fixed ranks) and markdown cells (predicted ranks) into a single list.
    *   Sort the list by rank to produce the final `cell_order`.
