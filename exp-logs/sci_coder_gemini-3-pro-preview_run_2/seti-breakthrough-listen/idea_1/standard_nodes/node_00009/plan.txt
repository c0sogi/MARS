To resolve the `torch.OutOfMemoryError` caused by the large input resolution and batch size filling the GPU VRAM, I will implement the strategies outlined in **debug_lesson_2**. First, I will reduce the `BATCH_SIZE` in `library/config.py` from 32 to 16 to immediately lower the memory footprint of activations. Second, I will modify `library/trainer.py` to implement Automatic Mixed Precision (AMP) using `torch.cuda.amp`. This involves initializing a `GradScaler`, wrapping the forward pass and loss calculation in an `autocast` context (for both training and validation), and using the scaler to handle backward passes and optimizer steps. This allows the model to use half-precision (`float16`) where safe, significantly reducing memory usage (Cite debug_lesson_2).
