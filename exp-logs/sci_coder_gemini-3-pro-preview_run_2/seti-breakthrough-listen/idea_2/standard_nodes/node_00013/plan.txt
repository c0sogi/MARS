The previous implementation encountered a `torch.OutOfMemoryError` because the high-resolution spectrogram inputs combined with a batch size of 32 and full precision training exhausted the GPU's VRAM. To fix this, I will reduce the batch size to 16 and implement Automatic Mixed Precision (AMP) training. Reducing the batch size lowers the immediate memory requirement for storing activations. Enabling AMP via `torch.cuda.amp` allows the model to use `float16` for certain operations, significantly reducing memory usage and computational load (Cite debug_lesson_2).
