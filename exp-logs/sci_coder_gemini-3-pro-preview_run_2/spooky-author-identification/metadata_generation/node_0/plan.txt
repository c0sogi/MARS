The following script generates metadata for the Author Identification task. It reads the raw CSV files from the `./input` directory, creates a stratified 80:20 train-validation split from the training data, and saves the resulting datasets (including the test set) to the `./metadata` directory. It adds a `source_path` column to track the origin of each sample. Finally, it performs rigorous validation to ensure the files are correctly saved, the split ratio and stratification are accurate, and the referenced source paths exist.
