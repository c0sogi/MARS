The following script demonstrates the complete pipeline for the Author Identification task using the provided library files. It covers data loading, feature extraction, stacking ensemble training (OOF generation, meta-learner training), and final submission generation.

To ensure the demonstration runs quickly and efficiently, the script modifies the global `Config` to use a smaller subset of data, fewer cross-validation folds, and reduced model complexity (fewer trees, lower dimensionality). It includes assertions at each step to verify the correctness of data shapes and logic.
