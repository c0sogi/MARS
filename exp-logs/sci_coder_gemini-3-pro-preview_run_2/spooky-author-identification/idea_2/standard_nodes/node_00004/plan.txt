The solution implements the `runfile.py` script to orchestrate the Two-Layer Stacking Ensemble for Author Identification. It follows the defined strategy:

1.  **Setup & Configuration**: Sets random seeds and detects GPU availability to optimize XGBoost training.
2.  **Data Pipeline**: Loads data and generates Hybrid N-Gram features (sparse) and SVD-projected features (dense) using the provided `HybridFeatureGenerator`.
3.  **Stacking Workflow**:
    *   Generates Out-Of-Fold (OOF) predictions for the training set using `StackingManager`.
    *   Trains the Meta-Learner (Logistic Regression) on these OOF predictions.
    *   Validates the ensemble by training base models on the training set and predicting on the validation set.
4.  **Evaluation**: Computes the Log Loss metric and performs failure analysis by correlating error magnitude with text length.
5.  **Submission**: If the validation score meets the threshold, it refits the base models on the combined Training + Validation set for maximum performance, generates predictions for the test set, and saves the submission file.
