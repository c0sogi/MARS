The error `TypeError: got an unexpected keyword argument 'eps'` occurs because the `eps` parameter was removed from `sklearn.metrics.log_loss` in recent versions of scikit-learn (specifically 1.5+). To fix this while maintaining the competition's requirement to clip probabilities to the range $[10^{-15}, 1-10^{-15}]$, I will manually clip the predicted probabilities using `numpy.clip` before passing them to the `log_loss` function.
