The following implementation orchestrates the author identification pipeline using the provided library modules.

**Strategy:**
1.  **Setup & Configuration:** Initialize the environment with a fixed random seed for reproducibility.
2.  **Data Loading:** Utilize `load_datasets` from the library to retrieve training, validation, and test sets. This leverages caching to speed up execution.
3.  **Feature Engineering:** Apply `extract_features` to transform raw text into a high-dimensional sparse feature space using the dual-stream TF-IDF (word and character n-grams) approach defined in the library.
4.  **Model Training:** Instantiate and train the `AuthorClassifier` (Logistic Regression). The training process uses the validation set to monitor performance and applies early stopping to prevent overfitting and reduce unnecessary computation time.
5.  **Validation & Metrics:** Perform inference on the validation set. Calculate the Multi-class Logarithmic Loss using the competition metric definition and print it in the required format.
6.  **Failure Analysis:** Analyze the model's errors on the validation set. Specifically, calculate the correlation between the error magnitude (negative log-likelihood of the true class) and the length of the input text to determine if sentence length impacts prediction accuracy.
7.  **Submission Generation:** Generate probability predictions for the test set and save them to `submission.csv` using the provided helper function.
