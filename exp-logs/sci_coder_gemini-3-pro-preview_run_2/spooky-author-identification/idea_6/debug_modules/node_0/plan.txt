This script demonstrates the end-to-end usage of the provided Author Identification library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to run in a lightweight "debug" mode (fewer samples, 1 epoch, minimal SVD components) to ensure the script completes quickly.
2.  **Data Loading**: Uses `data_factory` to load a small subset of training and test data.
3.  **Feature Engineering**: Generates TF-IDF and SVD features using `feature_engineering`.
4.  **Classical Modeling**: Simulates a single fold of training for Logistic Regression, Naive Bayes, and XGBoost using `training_engine`.
5.  **Neural Modeling**: Simulates a single fold of training for the DeBERTa-based model using `training_engine`.
6.  **Ensembling**: Uses `stacking` to combine predictions from all models and generate a submission file.
7.  **Validation**: Includes assertions throughout to verify data shapes, types, and file outputs.
