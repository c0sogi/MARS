This script demonstrates the end-to-end pipeline for the Author Identification task using the provided library files. It overrides the default configuration to run a fast, minimal version of the experiment (fewer epochs, smaller data subset, reduced dimensionality) to verify the logic and functionality of the components.

It performs the following steps:
1.  **Configuration Override**: Sets up a temporary working directory and reduces hyperparameters for speed.
2.  **Feature Engineering**: Generates TF-IDF and Stylometric features using `FeatureEngineer`.
3.  **Data Subsetting**: Selects a small subset of data to ensure the neural network training completes in seconds.
4.  **Model Training**:
    *   Trains a **DeBERTa** neural network (via `ModelTrainer`) on the subset.
    *   Trains classical models (**Logistic Regression**, **Naive Bayes**, **XGBoost**) on the subset.
5.  **Ensembling**: Uses the `StackingEnsemble` meta-learner to combine predictions.
6.  **Submission Generation**: Creates a sample submission file.
7.  **Validation**: Asserts that outputs have correct shapes and files are created.
