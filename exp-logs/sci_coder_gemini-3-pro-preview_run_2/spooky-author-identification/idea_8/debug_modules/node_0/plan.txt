This script demonstrates the end-to-end pipeline for the Author Identification task using the provided library files. It validates the data loading, feature engineering, classical model training, neural network training, and the final meta-learner stacking ensemble.

### Strategy
1.  **Configuration Setup**: We override default `Config` parameters (e.g., reducing folds to 2, epochs to 1, using a smaller transformer backbone) to ensure the demonstration runs quickly on the available hardware while still verifying all code paths.
2.  **Data Verification**: We use `DataManager` to load metadata and generate/validate the shapes of Stylometric, TF-IDF, and SVD features.
3.  **Classical Models**: We instantiate `ClassicalModels` and run the Cross-Validation pipeline for Logistic Regression, Naive Bayes, and XGBoost.
4.  **Neural Model**: We instantiate `NeuralTrainer` and run a simplified Cross-Validation loop for a Transformer-based model (`roberta-base`) fused with stylometric features.
5.  **Ensemble**: We collect the Out-of-Fold (OOF) predictions from all models and pass them to the `MetaLearner` to train the stacking classifier and generate the final submission.
6.  **Validation**: Assertions are placed throughout to confirm data shapes, file existence, and logical consistency.
