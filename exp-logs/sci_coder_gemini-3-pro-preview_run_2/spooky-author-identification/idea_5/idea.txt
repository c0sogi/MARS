# Solution Strategy: Deep Stylometric Stacking with Multi-Layer Aggregation

## Model
The architecture evolves the previous stacking ensemble by introducing a **Multi-View Neural Representation** designed to capture both the semantic content and the syntactic style of the authors.

*   **Level 1: Base Estimators (Heterogeneous 5-Branch System)**
    *   **Branch A: Syntactic-Semantic Transformer (Primary):** We will utilize **`microsoft/deberta-v3-large`** (Cite solution_lesson_node_00009).
        *   **Structural Innovation:** Instead of using the standard `[CLS]` token, we will implement **Weighted Layer Pooling**. We will extract the hidden states from the **last 4 layers**, compute a learnable weighted average, and feed this into the classification head.
        *   **Rationale:** Authorship is often defined by syntax and grammar (style) rather than just topic (semantics). Lower transformer layers preserve more syntactic information, while top layers are semantically abstract. This mechanism allows the model to dynamically select the level of abstraction that best distinguishes the authors.
    *   **Branch B: Global Context Transformer (Secondary):** We will re-introduce **`roberta-large`**.
        *   **Pooling:** We will use **Mean Pooling** over the entire sequence. This forces the model to aggregate signals from every token, providing a "global" view of the sentence structure that complements the token-specific attention of DeBERTa.
    *   **Branch C: Classical Statistical Models (Retained):** We will preserve the three "shallow" models that excel at explicit lexical matching:
        1.  **Logistic Regression** (Sparse TF-IDF)
        2.  **Multinomial Naive Bayes** (Sparse TF-IDF)
        3.  **XGBoost** (Dense SVD-Projected)
        *   These models capture specific n-gram signatures (e.g., punctuation habits, rare words) that deep models sometimes smooth over (Cite solution_lesson_node_00008).

*   **Level 2: Meta-Learner**
    *   A **Logistic Regression** model will blend the probability predictions from all five base estimators.

## Data
The data pipeline is designed to maximize signal density while respecting the specific constraints identified in the failure analysis.

*   **Classical Feature Engineering:**
    *   **Hybrid N-Grams:** We will generate **Word N-grams (1-3)** and **Character N-grams (2-5)**. This concatenation is non-negotiable for capturing sub-word stylistic markers (Cite solution_lesson_node_00001).
    *   **Noise Pruning:** We will strictly enforce **`min_df=2`** to remove singleton terms that cause overfitting (Cite solution_lesson_node_00002).
    *   **Dimensionality Reduction:** We will apply **Truncated SVD** (100 components) specifically for the XGBoost branch to enable tree-based learning on dense vectors (Cite solution_lesson_node_00004).

*   **Neural Preprocessing:**
    *   **Sequence Length:** We will set **`max_length=85`**. Analysis confirms this covers the vast majority of the data. Capping it here prevents the batch instability and memory waste associated with processing excessive padding (Cite solution_lesson_node_00013).

## Training
The training strategy is optimized to balance model diversity with data volume, correcting the strategic error from the previous iteration.

*   **Cross-Validation Strategy:** We will strictly enforce **Stratified 5-Fold Cross-Validation** for *all* models.
    *   **Correction:** We will not reduce the fold count to accommodate the second transformer. Instead, we will leverage the full 24-hour runtime to train the models **sequentially**. Sacrificing training data (dropping to 3 folds) degrades the performance of the strongest learner (DeBERTa), which outweighs the benefit of the second model (Cite solution_lesson_node_00015).
*   **Optimization & Regularization:**
    *   **Aggressive Early Stopping:** For both Transformers, we will set **`patience=1`**. This prevents the models from memorizing fold-specific noise and ensures robust Out-Of-Fold (OOF) generalization (Cite solution_lesson_node_00010).
    *   **Configuration Caching:** All intermediate artifacts (features, OOF predictions) will be cached using hash-based filenames to ensure reproducibility (Cite solution_lesson_node_00003).

## Evaluation
*   **Inference:** The test set will be processed through all five branches. The two Transformers will utilize their respective tokenizers and pooling heads, while the classical models will use the fitted TF-IDF/SVD pipelines.
*   **Aggregation:** The probability vectors from the 5 base models will be concatenated and fed to the Meta-Learner.
*   **Post-Processing:** Final probabilities will be clipped to \\([10^{-15}, 1-10^{-15}]\\) to satisfy the metric requirements.
