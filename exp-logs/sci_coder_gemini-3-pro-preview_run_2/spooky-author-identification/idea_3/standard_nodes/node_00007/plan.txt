The strategy involves implementing a Hybrid Classical-Neural Stacking Ensemble. The pipeline begins by loading the dataset and identifying the specific hold-out validation subset using metadata to ensure accurate metric reporting. Feature extraction is split into two parallel streams: a classical pipeline generating sparse TF-IDF and dense SVD features, and a neural pipeline generating tokenized inputs for a Transformer. Level 1 base models (Logistic Regression, Naive Bayes, XGBoost, and a Fine-Tuned RoBERTa) are trained using Stratified K-Fold Cross-Validation to produce Out-Of-Fold (OOF) predictions. These OOF predictions serve as input for a Level 2 Logistic Regression Meta-Learner. The final validation metric is computed by evaluating the Meta-Learner's predictions on the hold-out validation subset. Failure analysis is performed by correlating sample-wise log loss with text length features. Finally, if the validation metric meets the specified threshold, the model generates predictions on the test set and saves the submission file.
