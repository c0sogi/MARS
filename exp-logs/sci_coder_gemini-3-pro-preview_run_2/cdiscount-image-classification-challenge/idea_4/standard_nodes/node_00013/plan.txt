Implementation strategy:
1.  **Setup & Configuration**: Import necessary libraries and the provided `library` modules. Set random seeds for reproducibility. Update the `Config` to limit the training to 2 epochs and define a subset size (800,000 samples) to ensure the pipeline fits within the 2-hour limit on the A100 GPU.
2.  **Data Preparation**: Load the full `train.csv` metadata, sample 800,000 records, and save this subset to `working/train_subset.csv`. Point the configuration to this new metadata file.
3.  **Data Loading**: Initialize `BSONDataset` and `DataLoader` for the training subset, the full validation set, and the test set. Use the provided transforms and collate functions.
4.  **Model & Training Setup**: Instantiate the `convnext_tiny` model, `AdamW` optimizer, `GradScaler` for AMP, and the `OneCycleLR` scheduler. The scheduler steps are calculated based on the subset size.
5.  **Execution Loop**: Run the training loop for 2 epochs. For each epoch, perform training and validation using the imported `train_one_epoch` and `validate` functions. Track the best validation accuracy and save the best model checkpoint.
6.  **Metric Reporting**: Print the `Final Validation Metric` as required.
7.  **Failure Analysis**: Load the best model and run inference on the validation set. Collect prediction correctness and the number of images per product. Calculate and print the correlation between correctness and image count to identify systematic errors.
8.  **Submission**: Check if the best validation accuracy is greater than 0.6116. If so, generate predictions for the test set using the `predict` function and save the result to `./submission/submission.csv`.
