An outline of the implementation strategy:
1.  **Define Constants and Paths**: Set up paths for input (`./input`) and output (`./metadata`) directories. Define filenames for train and test BSON files.
2.  **Implement BSON Parser**: Create a robust function to parse BSON files sequentially.
    *   Iterate through the file by reading the document size (first 4 bytes).
    *   Read the full document data into memory (feasible given 220GB RAM and typical image sizes).
    *   Parse the BSON structure to extract `_id` and `category_id`.
    *   Handle standard BSON types (Double, String, Document, Array, Binary, Int32, Int64, etc.) to correctly traverse the byte stream.
    *   Store metadata: `product_id`, `category_id`, `bson_offset`, `bson_length`, and `file_path`.
    *   Optimize by stopping the parse of a document as soon as required fields are found (if applicable), though reading the full object ensures pointer correctness.
3.  **Generate Metadata**:
    *   Process `train.bson` to extract IDs and labels.
    *   Process `test.bson` to extract IDs.
4.  **Create Validation Split**:
    *   Identify categories with only 1 sample and segregate them to the training set to prevent errors during stratified splitting.
    *   Perform a stratified 80/20 split on the remaining multi-sample data using `sklearn.model_selection.train_test_split` with `random_state=42`.
    *   Combine the single-sample data back into the training set.
5.  **Save Metadata**: Write the resulting DataFrames to `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
6.  **Validation and Verification**:
    *   Print summary statistics (counts, unique categories).
    *   Verify file paths exist (programmatic check).
    *   Verify BSON offsets by randomly sampling 5 records from each dataset, seeking to the offset, and verifying the BSON document size/integrity.
    *   Assert that the validation set contains a proper distribution of categories.
