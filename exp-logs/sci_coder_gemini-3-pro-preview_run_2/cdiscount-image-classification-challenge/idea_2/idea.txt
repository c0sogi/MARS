# Optimized Strategy: Deep Residual Learning at Scale with Mixup Regularization

### Model
I propose upgrading the backbone architecture from ResNet-18 to **ResNet-50**.
*   **Rationale:** The previous experiments utilized a relatively shallow network (ResNet-18). Given the high cardinality of the target space (5270 categories) and the visual complexity of the products, a deeper model with higher parameter capacity is necessary to capture fine-grained discriminative features. ResNet-50 provides a balanced increase in depth and width, allowing for richer feature extraction without exceeding the memory constraints of the A100 GPU.
*   **Head:** The classification head will remain a standard fully connected layer mapping the 2048-dimensional embedding to the 5270 class logits.

### Data
*   **Preprocessing (Training):**
    *   **Full Dataset Utilization:** Building on the finding that "scaling data diversity" yields massive gains (Cite solution_lesson_node_00007), we will scale the training set to include the **entire labeled dataset** (approx. 12 million images across ~7 million products), rather than a subset.
    *   **Flattened Random Access:** We will retain the highly efficient metadata-based indexing system (Cite solution_lesson_node_00004). The data loader will treat every image as an independent sample, reading directly from the monolithic BSON file using byte offsets.
    *   **Augmentation:** We will employ standard geometric augmentations (random resized crop, flip) and the color jittering strategy that proved effective previously.
*   **Preprocessing (Evaluation):**
    *   Validation and Test loaders will continue to group images by `product_id` to facilitate the aggregation logic.

### Training
*   **Strategy:**
    *   **One-Cycle Policy:** We will continue to use the **`OneCycleLR`** scheduler (Cite solution_lesson_node_00007). This is crucial for training on the full dataset within the time limit, as it allows for super-convergence in fewer epochs (targeted: 2 epochs on the full 12M dataset, estimated ~20 hours).
    *   **Mixup Regularization:** To further improve generalization and handle the long-tail class distribution, we will introduce **Mixup**. This technique trains the model on convex combinations of pairs of examples and their labels. It encourages the model to behave linearly in-between training examples, reducing overconfidence and improving robustness.
    *   **Label Smoothing:** We will replace the standard Cross-Entropy Loss with **Label Smoothing Cross-Entropy**. This prevents the model from predicting training examples too confidently (forcing logits to infinity), which is particularly beneficial for datasets with thousands of classes where label noise may exist.
*   **Technical:**
    *   Automatic Mixed Precision (AMP) will be used to maximize throughput.

### Evaluation
*   **Inference:** We will strictly maintain the **Late Fusion** strategy (Cite solution_lesson_node_00004).
    *   The model will predict probabilities for every image associated with a product.
    *   These probabilities will be averaged to form a consensus prediction.
    *   This method effectively leverages the multi-view nature of the data without complicating the training pipeline.
