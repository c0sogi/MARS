This script demonstrates the end-to-end usage of the provided library modules to train a Granular Siamese DeBERTa model on the StackExchange dataset.

### Implementation Strategy
1.  **Configuration Override**: We modify the `Config` class attributes at runtime to enable a "Debug Mode". This reduces the batch size, number of epochs, and dataset size (using `DEBUG_SAMPLE_SIZE`) to ensure the script runs quickly (within minutes) while exercising all code paths.
2.  **Data Loading**: We utilize `library.data.get_dataloaders` with `debug=True`. This function automatically handles tokenization, categorical mapping, and tensor creation for a small subset of the data.
3.  **Model Instantiation**: We initialize the `GranularSiameseModel` using the categorical dimensions returned by the data loader. We then perform a dummy forward pass to verify tensor shapes and data flow.
4.  **Training & Evaluation**: We use `library.engine.train_one_epoch` to perform a single training pass and `library.engine.evaluate` to calculate the validation loss and Spearman correlation.
5.  **Inference**: We generate predictions on the test set using `library.model.predict_fn` and format the results into a submission CSV, verifying the output structure.
6.  **Validation**: Assertions are placed throughout the script to confirm data integrity, tensor shapes, and successful file generation.
