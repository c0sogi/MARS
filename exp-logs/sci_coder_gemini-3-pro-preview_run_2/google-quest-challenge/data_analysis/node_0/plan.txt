The following strategy outlines the implementation of the Exploratory Data Analysis (EDA) script:

1.  **Setup & Configuration**: Import necessary libraries (pandas, numpy, sklearn, scipy) and set fixed random seeds for reproducibility. Define the list of 30 target column names based on the provided dataset description.
2.  **Data Loading**: Load the training data from `./metadata/train.csv` to ensure data integrity and avoid leakage.
3.  **Target Variable Analysis**:
    *   Calculate and report the global mean and standard deviation for the targets.
    *   Compute Skewness and Kurtosis for each of the 30 target columns to assess normality. Summarize these by reporting the range (min/max) and the average values across all targets.
4.  **Text Data Analysis**:
    *   Focus on the three main text features: `question_title`, `question_body`, and `answer`.
    *   Compute sequence length statistics (character counts and word counts) for each text column.
    *   Estimate the vocabulary size by fitting a `CountVectorizer` on a subset of the text data (to keep runtime low) or the full text if feasible, reporting the unique token count.
5.  **Categorical & Metadata Analysis**:
    *   Analyze the `category` and `host` columns. Report cardinality and check for rare labels.
6.  **Feature/Signal Relationships**:
    *   **Meta-Feature Extraction**: Create numerical features representing text lengths (e.g., `answer_word_count`).
    *   **Correlation**: Calculate Spearman's correlation between these meta-features and the average target value.
    *   **Feature Importance**: Train a lightweight Random Forest Regressor using the meta-features and encoded categorical variables to predict the mean target value. Report the top 5 most important features to understand which metadata drives the labels.
7.  **Output Formatting**: Ensure all outputs are printed to stdout with distinct capitalized headers and floating-point numbers formatted to 4 decimal places.
