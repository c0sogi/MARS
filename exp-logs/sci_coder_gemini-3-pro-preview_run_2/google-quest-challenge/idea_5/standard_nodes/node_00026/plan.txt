The `torch.OutOfMemoryError` occurs because the `HybridDeberta` architecture executes the heavy transformer backbone twice per training step (once for the "Intrinsic" view and once for the "Relational" view), requiring PyTorch to store two full sets of intermediate activations for backpropagation. To resolve this without reducing the batch size to inefficient levels, I will enable **Gradient Checkpointing** on the backbone model. This technique significantly reduces memory usage by recomputing activations during the backward pass instead of storing them, allowing the multi-pass architecture to fit within the GPU memory limits (Cite debug_lesson_4).
