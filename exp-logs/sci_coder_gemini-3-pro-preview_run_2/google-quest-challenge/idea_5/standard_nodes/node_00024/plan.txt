Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Import the provided library modules. Override `Config.epochs` to 4 to ensure the "fast baseline" requirement is met while allowing sufficient convergence. Set random seeds for reproducibility.
2.  **Data Loading**: Use `get_dataloaders(load_cached_data=True)` from `library.dataset` to efficiently load the preprocessed Train, Validation, and Test sets.
3.  **Model Training**:
    *   Initialize the `HybridDeberta` model and move it to the GPU.
    *   Configure the Optimizer (AdamW) with differential learning rates for the backbone and heads, and the Scheduler (CosineAnnealingWarmRestarts).
    *   Execute the training loop for the specified epochs using `train_fn` and `eval_fn` from `library.trainer`.
    *   Save the model state whenever the validation Spearman correlation improves.
4.  **Validation & Metrics**:
    *   Load the best saved model checkpoint.
    *   Perform a full inference pass on the validation set to retrieve predictions and targets.
    *   Compute and print the `Final Validation Metric` with full precision.
5.  **Failure Analysis**:
    *   Calculate the Mean Absolute Error (MAE) for each validation sample.
    *   Load the raw validation metadata to extract text length features (Question Length, Answer Length).
    *   Compute and print the Spearman correlation between the MAE and these length features to identify systematic errors.
6.  **Submission**:
    *   Compare the final validation metric against the threshold (`0.41003785424660755`).
    *   If the metric exceeds the threshold, generate predictions for the test set using `predict_fn`.
    *   Format the predictions into a DataFrame with `qa_id` and the 30 target columns, and save it to `./submission/submission.csv`.
