The following code demonstrates the complete pipeline for the Text Normalization task using the provided library files.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to adapt the pipeline for a quick demonstration. This includes enabling debug mode, reducing model dimensions, setting the number of epochs to 1, and redirecting file paths to a temporary `./working/demo` directory.
2.  **Synthetic Data Generation**: To avoid the time-consuming process of loading and processing the large original datasets (7M+ rows), we create small "dummy" CSV files for training, validation, and testing. These files adhere to the required schema and are placed in the working directory.
3.  **Vocabulary & Dataset**: We demonstrate how to build the vocabulary from the synthetic data and instantiate the `TextNormalizationDataset`. We include assertions to verify that data loading, context window creation, and batch collation work as expected.
4.  **Model Initialization**: We instantiate the `Encoder`, `Decoder`, `Attention`, and `Seq2Seq` classes with the reduced hyperparameters. A dummy forward pass verifies that the tensor shapes match the expected dimensions.
5.  **Training Loop**: We initialize the `Trainer` and run a single epoch of training (`fit()`). This proves that the training logic, loss calculation, and model checkpointing are functional.
6.  **Inference**: Finally, we call `generate_submission` to produce predictions on the dummy test set, verifying that the output submission file is created correctly.
