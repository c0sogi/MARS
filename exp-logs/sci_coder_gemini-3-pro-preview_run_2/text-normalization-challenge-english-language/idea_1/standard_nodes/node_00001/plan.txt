Implementation strategy:
1.  **Setup and Configuration**: Initialize the environment using the provided `Config` class. Set random seeds for reproducibility. Override `Config.N_EPOCHS` to 3 to ensure the training completes quickly (fast baseline) while still learning effectively from the downsampled balanced dataset.
2.  **Data Loading**: Use `library.vocabulary` and `library.dataset` to load the training and validation data. The dataset class handles caching and class balancing (downsampling trivial "PLAIN" tokens) automatically. Create PyTorch DataLoaders with appropriate batch sizes and workers.
3.  **Model Initialization**: Instantiate the Seq2Seq model components (`Encoder`, `Decoder`, `Attention`) using the hyperparameters defined in `Config`. Move the model to the GPU.
4.  **Training**: Initialize the `Trainer` with the model and data loaders. Execute the `fit()` method to train the model. The trainer handles the training loop, validation loss monitoring, and saving the best model checkpoint.
5.  **Validation and Failure Analysis**:
    *   Load the best model checkpoint.
    *   Iterate through the full validation set in evaluation mode.
    *   Compute the **Prediction Accuracy** (exact string match) as the primary metric.
    *   Compute the **Levenshtein distance** between predicted and actual strings to quantify error magnitude.
    *   Calculate the correlation between input token length and error magnitude to identify if longer tokens are more prone to errors.
    *   Print the required `Final Validation Metric`.
6.  **Submission**: Clean up memory and call `generate_submission()` from `library.inference`. This function reloads the best model, generates predictions for the test set, and saves the `submission.csv` file in the correct format.
