Based on the lessons learned, specifically the success of the **Hybrid Router-Generator (Idea 7)** and the identified limitation regarding context-blind generation, I propose the following optimized strategy.

# Idea 8: Context-Enhanced Hybrid Router-Generator

This strategy evolves the **Hybrid Router-Generator (Idea 7)** by introducing **Contextual Serialization** to the neural generator component and expanding the scope of the neural subsystem. While Idea 7 successfully decoupled classification from generation (Cite {solution_lesson_node_00006}), its generator processed tokens in isolation (`[CLASS] token`), relying entirely on the Router's class tag for disambiguation. This failed for classes like `DATE` or `MEASURE` where the normalization logic (e.g., "12" $\to$ "twelve" vs. "twelfth") depends on immediate neighbors (e.g., "Jan 12") even within the same semiotic class.

### Model
**Architecture**: The solution utilizes a two-stage pipeline:
1.  **The Router (Contextual Classifier)**:
    *   **Backbone**: **DeBERTa-v3-base**. We upgrade from RoBERTa (used in Idea 7) to DeBERTa-v3 due to its superior disentangled attention mechanism, which is highly effective for the subtle positional cues required in text normalization.
    *   **Role**: Predicts the semiotic `class` for each token using full sentence context.
2.  **The Refiners (Dual-Path Execution)**:
    *   **Path A: Deterministic Rule Engine**: For strictly rigid classes (`PLAIN`, `PUNCT`, `CARDINAL`, `ORDINAL`, `DIGIT`, `LETTERS`), we retain the Python rule registry. These classes require mathematical precision where neural hallucination is unacceptable (Cite {solution_lesson_node_00017}).
    *   **Path B: Context-Aware Neural Generator**: For semi-structured and unstructured classes (`DATE`, `TIME`, `MONEY`, `MEASURE`, `ADDRESS`, `TELEPHONE`, `ELECTRONIC`, `VERBATIM`), we use a **ByT5-small** Sequence-to-Sequence model.
    *   **Structural Innovation**: Unlike Idea 7, the input to this generator is **Context-Augmented**. We feed a window of tokens surrounding the target (e.g., `[DATE] ... Jan [ 12 ] 2022 ...`). This allows the model to attend to local cues (like "Jan" preceding "12") to correctly generate "twelfth" instead of "twelve", solving the intra-class ambiguity without brittle inverse label engineering (Cite {solution_lesson_node_00014}).

### Data
**Preprocessing**:
1.  **Router Dataset**: We employ **Strategic Sampling**. We retain 100% of sentences containing non-`PLAIN` tokens. For `PLAIN` sentences, we apply hard-negative mining (keeping those with digits/caps) and downsample trivial lowercase sentences to 1%. This focuses the Router on the decision boundary.
2.  **Generator Dataset**: We construct a specialized dataset containing only tokens belonging to the "Path B" classes.
    *   **Input Formatting**: We format the input as: `[CLASS_TAG] left_context <extra_id_0> target_token <extra_id_1> right_context`. The context window is set to $\pm 3$ tokens.
    *   **Target**: The ground-truth `after` text.
    *   **Benefit**: This allows the generator to learn context-dependent patterns (e.g., `$3m` vs `$3`) that rules struggle with, while the class tag provides the high-level intent.

### Training
**Procedure**:
1.  **Stage 1: Train Router**: Fine-tune DeBERTa-v3-base on the Router Dataset using Cross-Entropy Loss. We use a linear learning rate decay and early stopping based on validation accuracy.
2.  **Stage 2: Train Generator**: Train ByT5-small on the Generator Dataset. We use standard Seq2Seq Cross-Entropy Loss with Teacher Forcing.
    *   **Efficiency**: Since "Path B" classes constitute less than 5% of the total tokens, this model will train rapidly despite being generative.

### Evaluation
**Inference**:
1.  **Classify**: Pass test sentences through the **Router** to obtain the predicted class for every token.
2.  **Route & Execute**:
    *   **Structured Classes**: Pass the raw token to the deterministic Python function (e.g., `cardinal_to_words`).
    *   **Unstructured Classes**: Construct the context-augmented string (e.g., `[DATE] Jan [ 12 ] 2022`) and pass it to the **Generator** (ByT5). Decode greedily.
    *   **Copy Classes**: Directly copy the raw text for `PLAIN` and `PUNCT`.
3.  **Merge**: Combine outputs into the submission format. This strategy leverages the "Hybrid Router" design (Cite {solution_lesson_node_00017}) while fixing its primary weakness (lack of context in generation) and avoiding the pitfalls of derived labels (Cite {solution_lesson_node_00014}).
