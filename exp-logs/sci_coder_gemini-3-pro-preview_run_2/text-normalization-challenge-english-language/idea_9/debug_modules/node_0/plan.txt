This script demonstrates the end-to-end workflow for the text normalization task using the provided library files. It performs the following steps:

1.  **Configuration Override**: It creates a temporary working environment and overrides the default `Config` paths to use small, synthesized dummy datasets instead of the massive original files. This ensures the demo runs quickly (within minutes) and validates the logic without resource bottlenecks.
2.  **Rule Validation**: It explicitly tests the deterministic normalization rules (e.g., number conversion, ordinal logic) to ensure correctness.
3.  **Data Preparation**: It generates dummy CSV files for training, validation, and testing that mimic the schema of the real metadata.
4.  **Model Training**: It runs a single epoch of training for both the Router (DeBERTa-v3) and Generator (ByT5) models using the dummy data.
5.  **Inference Pipeline**: It executes the full inference pipeline on the dummy test set, routing tokens to either the deterministic rules or the neural generator, and produces a submission file.
6.  **Verification**: It asserts that the output files (checkpoints, submission CSV) are created correctly.
