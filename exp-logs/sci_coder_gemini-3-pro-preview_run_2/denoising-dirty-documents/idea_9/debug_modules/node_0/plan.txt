The following script demonstrates the end-to-end pipeline for the denoising task using the provided library. It covers configuration setup, dataset validation, model verification, training, and inference.

Strategy:
1.  **Configuration**: Initialize the `Config` class in debug mode to minimize runtime (fewer epochs, smaller dataset subset). Redirect output paths to a temporary directory.
2.  **Dataset Validation**: Instantiate the `DenoisingDataset` for training and verify that it yields tensors of the correct shape and value range.
3.  **Model Verification**: Instantiate the `CoRes2NetUNet` model, perform a forward pass with dummy data, and assert output shapes to ensure architectural correctness.
4.  **Training**: Initialize the `Trainer`, run the training loop (which uses the debug configuration), and verify that a model checkpoint is saved.
5.  **Inference & Submission**: Use the `InferenceEngine` to load the trained checkpoint, calculate validation RMSE, and generate a submission file. Verify the submission file's existence and format.
6.  **Utility Check**: Validate the RMSE calculation utility with known inputs.
