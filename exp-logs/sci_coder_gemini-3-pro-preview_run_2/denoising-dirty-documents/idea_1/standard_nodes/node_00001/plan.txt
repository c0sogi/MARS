Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and detecting the available computation device (GPU/CPU).
2.  **Training**: Execute the training pipeline using `library.train.run_training`. To ensure a fast baseline as requested, we will override the default epoch count to 30. This balances training time with sufficient convergence for a baseline model.
3.  **Validation & Metric Calculation**:
    *   Load the best saved model state.
    *   Iterate through the hold-out validation dataset.
    *   Compute predictions for all validation images.
    *   Flatten the pixel arrays to calculate the global Root Mean Squared Error (RMSE).
    *   Print the `Final Validation Metric` with full precision.
4.  **Failure Analysis**:
    *   During the validation loop, compute the Mean Absolute Error (MAE) for each individual image to represent "error magnitude".
    *   Extract simple input features: Mean Intensity (brightness) and Standard Deviation (contrast) of the noisy input images.
    *   Calculate the Pearson correlation between the error magnitude and these input features to identify if specific image characteristics lead to higher errors.
5.  **Submission**: Run the inference pipeline using `library.inference.generate_submission` to process the test set and save the `submission.csv` file.
