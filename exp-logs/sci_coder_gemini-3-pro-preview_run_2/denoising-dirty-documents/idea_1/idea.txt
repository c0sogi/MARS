To establish a robust and efficient baseline, I propose a **Plain Multi-Layer Convolutional Network (Flat-CNN)**. This approach focuses on local feature extraction at the original image resolution, avoiding the structural complexity of U-Nets or Transformers.

### Model
The architecture is a straightforward stack of convolutional layers that operates entirely at the input resolution, distinct from the U-Net (Model 1) which relies on an encoder-decoder (downsampling/upsampling) structure.
*   **Structure**: The network consists of a sequence of 3 to 5 standard 2D convolutional layers.
*   **Configuration**: All layers use small kernels (e.g., 3x3) with "same" padding to preserve spatial dimensions.
*   **Activations**: ReLU activation functions follow each convolutional layer, except for the final layer.
*   **Output**: The final layer consists of a single convolutional filter (1x1 or 3x3) with a Sigmoid activation (or linear clipped) to project the features back to a single-channel grayscale intensity map in the [0, 1] range.
*   **Principle**: This model acts as a learnable, non-linear spatial filter. By stacking layers, it learns to correct pixel intensities based on the immediate neighborhood context without losing spatial fidelity through pooling.

### Data
*   **Preprocessing**:
    *   Load all images in grayscale mode.
    *   Normalize pixel intensities to the range [0, 1] by dividing by 255.
*   **Patch Extraction**:
    *   Since training images have variable heights, training directly on full images prevents efficient batching.
    *   Extract random, fixed-size patches (e.g., 64x64 pixels) from the source (noisy) and target (clean) images. This creates a uniform dataset suitable for mini-batch training.
    *   No data augmentation (e.g., flips or rotations) is applied, adhering to the requirement for a lightweight baseline.

### Training
*   **Loss Function**: Mean Squared Error (MSE) is used as the objective function, as minimizing MSE directly optimizes the RMSE metric required by the task.
*   **Optimizer**: The Adam optimizer is employed for its ability to handle sparse gradients and rapid convergence with default parameters.
*   **Procedure**:
    *   Train the model on batches of the extracted patches.
    *   Monitor the RMSE on the validation set (using full validation images) to implement early stopping, preventing overfitting.

### Evaluation
*   **Inference**:
    *   Because the model is fully convolutional and uses fixed padding, it can accept input images of arbitrary size during inference.
    *   Feed the full-sized noisy test images into the network to generate denoised predictions in a single forward pass.
*   **Post-processing**:
    *   Clip the output values to the [0, 1] range to ensure valid intensity values.
    *   Flatten the resulting pixel arrays into the required `id,value` format (`image_row_col`) for submission.
