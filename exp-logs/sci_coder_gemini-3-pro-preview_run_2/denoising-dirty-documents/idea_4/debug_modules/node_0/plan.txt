The following implementation strategy outlines the steps to demonstrate the denoising pipeline:

1.  **Environment Configuration**: We will override the default settings in `Config` to create a lightweight execution environment. This involves reducing the number of epochs to 1, limiting the number of patches per image, and setting a small batch size. We also define a specific working directory for this demo to avoid conflicts with existing files.
2.  **Dataset Verification**: We will instantiate the `DenoisingDataset` in both 'train' and 'val' modes. We will assert that the data is loaded correctly and that the output tensors have the expected dimensions (patches for training, full images for validation).
3.  **Model Verification**: We will initialize the `ResUNetPlusPlus` model and perform forward passes with dummy data. We will verify that the model returns a list of tensors in training mode (due to Deep Supervision) and a single tensor in evaluation mode.
4.  **Training Execution**: We will invoke the `run_training` function. This serves as an integration test, running the full training loop, saving the best model, and generating a submission file using the test dataset.
5.  **Inference Logic Verification**: We will manually load the saved model checkpoint and test the `predict_tiled` and `apply_tta` functions on a large dummy image. This ensures that the sliding window inference and test-time augmentation logic handle dimensions correctly.
6.  **Submission Validation**: Finally, we will check the generated submission file to ensure it exists, contains the correct headers, and follows the required row format.
