The following script demonstrates the end-to-end usage of the provided library files for the image denoising task.

### Implementation Strategy
1.  **Setup & Configuration**: Initialize the working directory and set a random seed for reproducibility. Define parameters optimized for a quick demonstration (e.g., small batch sizes, limited training steps).
2.  **Data Loading**: Utilize `library.dataset.get_dataloaders` to load metadata and prepare the training `DataLoader` and validation/test lists. We verify the data structures and shapes using assertions.
3.  **Model Verification**: Instantiate the `ResUNet` model from `library.model` and perform a forward pass with a dummy tensor to confirm the architecture outputs the correct dimensions.
4.  **Training Loop**: Execute `library.engine.train_engine` for a single epoch with a strictly limited number of batches. This demonstrates the training pipeline, loss calculation, and model checkpointing without consuming excessive time.
5.  **Inference**: Use `library.inference.run_inference` to generate predictions on the test set using the trained model. We employ Test Time Augmentation (TTA) as implemented in the library.
6.  **Submission Validation**: Check the generated submission CSV file to ensure it strictly adheres to the required format (header, columns, and value types).
