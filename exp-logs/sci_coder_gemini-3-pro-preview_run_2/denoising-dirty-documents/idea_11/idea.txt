Based on the comprehensive analysis of the previous experiments and lessons learned, I propose the **Coordinate Selective Kernel ResUNet (CSK-ResUNet)**.

This strategy introduces a **Structural Innovation** by replacing standard residual blocks with **Selective Kernel (SK) Blocks**. This architecture directly resolves the conflict between the need for a large receptive field to capture context (Lesson 00001) and the need for strong local inductive biases to prevent overfitting (Lesson 00031), while integrating the spatial precision of Coordinate Attention (Lesson 00026).

### Model: Coordinate Selective Kernel ResUNet (CSK-ResUNet)
The architecture is a U-Net that fundamentally redesigns the feature extraction mechanism to be **dynamic** and **adaptive**.

*   **Structural Innovation: Selective Kernel (SK) Blocks**:
    *   **Mechanism**: Instead of a fixed 3x3 convolution, each block splits the input into two parallel branches:
        1.  **Local Branch**: A standard $3 \times 3$ convolution (captures fine details/edges).
        2.  **Context Branch**: A $3 \times 3$ convolution with **dilation rate 2** (effectively $5 \times 5$ receptive field, capturing broader texture).
    *   **Selection**: The branches are fused using a channel-wise attention mechanism (Softmax) that allows the network to adaptively weight the importance of local vs. context information for each feature channel.
    *   **Rationale**: This solves the **Receptive Field Limitation** (Cite solution_lesson_node_00001) without imposing the fixed large kernels of ConvNeXt that led to overfitting (Cite solution_lesson_node_00031). The model learns to use large kernels only where necessary (e.g., broad background noise) and small kernels for structure (e.g., text strokes).
*   **Coordinate Attention (CA)**: We insert a **Coordinate Attention** module after the SK fusion in every block. This ensures that the adaptively selected features are further refined by preserving vertical and horizontal positional information, critical for distinguishing text structure (Cite solution_lesson_node_00026).
*   **Backbone Configuration**:
    *   **Capacity**: We strictly maintain a base filter count of **64** to ensure sufficient representational power (Cite solution_lesson_node_00021).
    *   **Normalization & Activation**: We use **Batch Normalization** (Cite solution_lesson_node_00005) and **SiLU (Swish)** activations (Cite solution_lesson_node_00016) throughout to ensure convergence stability and smooth gradient flow.
*   **Global Context**: We retain the **Atrous Spatial Pyramid Pooling (ASPP)** module at the bottleneck to capture the broadest multi-scale context (Cite solution_lesson_node_00026).
*   **Upsampling**: We utilize **Transposed Convolutions** (Learnable Upsampling) to preserve sharp text edges, explicitly rejecting fixed bilinear interpolation (Cite solution_lesson_node_00020).
*   **Global Residual Learning**: The network is designed to predict the **noise residual** ($Clean = Input - Prediction$) (Cite solution_lesson_node_00013).

### Data: High-Density Contextual Processing
*   **Preprocessing**: Images are loaded in grayscale and normalized to [0, 1].
*   **Patch Size**: We will strictly use **128x128** patches. This provides the necessary spatial context for the dilated branches of the SK blocks and the ASPP module to function effectively (Cite solution_lesson_node_00022).
*   **Sampling Density**: We will employ **High-Density Sampling**, extracting **100 random patches per image per epoch**. This ensures the complex SK-Net receives a sufficiently rich gradient signal to learn the adaptive selection weights (Cite solution_lesson_node_00014).
*   **Augmentation**: We will apply aggressive geometric augmentations (random horizontal flips, vertical flips, and discrete 90-degree rotations) to exploit the rotational symmetry of the noise (Cite solution_lesson_node_00010).

### Training: Regularized Residual Optimization
*   **Objective**: Minimize **Mean Squared Error (MSE)** on the predicted noise residual. We avoid Deep Supervision to prevent optimization conflicts (Cite solution_lesson_node_00030).
*   **Optimizer**: We will use **AdamW** with an aggressive **weight decay of 1e-2**. This strong regularization is essential to prevent the increased parameter count of the SK blocks from overfitting the small dataset (Cite solution_lesson_node_00015).
*   **Scheduler**: A **Cosine Annealing** learning rate scheduler will be used to gradually reduce the learning rate, ensuring convergence to a sharp minimum (Cite solution_lesson_node_00014).
*   **Duration**: We will train for **100 epochs**. We explicitly acknowledge the "convergence tax" of this sophisticated architecture and allocate sufficient time for the adaptive mechanisms to settle (Cite solution_lesson_node_00019).

### Evaluation: Robust Ensemble Inference
*   **Tiled Inference with Overlap**: Test images will be processed using a sliding window with **50% overlap**. Predictions in overlapping regions will be averaged to eliminate boundary artifacts and ensure every pixel is predicted with centered context (Cite solution_lesson_node_00023).
*   **Test-Time Augmentation (TTA)**: We will generate predictions for the original image and its geometric transformations (flips/rotates) and average the results. This ensemble approach reduces variance and improves robustness against random noise patterns (Cite solution_lesson_node_00013).
