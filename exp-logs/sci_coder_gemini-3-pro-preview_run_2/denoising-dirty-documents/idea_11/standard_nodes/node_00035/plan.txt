Implementation strategy:
1.  **Configuration**: Import the `Config` class and override key parameters (`NUM_EPOCHS`, `PATCHES_PER_IMAGE`) to ensure the training runs quickly as a baseline (10 epochs, 50 patches). Set the `SUBMISSION_PATH` to the required `./submission/submission.csv`.
2.  **Training**: Execute the `run_training()` function from the library, which handles the training loop, optimizer setup, and saves the best model based on validation RMSE.
3.  **Validation & Analysis**:
    *   Load the best saved model.
    *   Iterate through the validation dataset using `DenoisingDataset`.
    *   Perform inference on validation images to calculate the **Final Validation Metric** (Global RMSE across all pixels).
    *   Collect per-image error magnitudes (RMSE) and input features (Mean Intensity, Std Dev) to compute Pearson correlations for failure analysis.
4.  **Submission**: Compare the final validation metric against the threshold (`0.0076658159`). If the metric is lower, call `run_inference()` to generate the submission file on the test set.
