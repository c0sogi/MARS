Based on the comprehensive analysis of the provided lessons and the identification of the "Inverted Residual" opportunity to safely increase capacity without sacrificing local inductive bias, I propose the **Inverted Coordinate ResUNet (IC-ResUNet)**.

This strategy introduces a **Structural Innovation** by replacing the standard Basic Residual Blocks with **Inverted Residual Blocks** utilizing **Standard Convolutions** (not depthwise). This addresses the "Capacity vs. Complexity" trade-off (Lesson 00021) by expanding the feature space internally for richer representation, while strictly maintaining the strong local inductive bias (Lesson 00031) and attention mechanisms (Lesson 00026) proven essential for this task.

### Model: Inverted Coordinate ResUNet (IC-ResUNet)
The architecture is a U-Net that fundamentally redesigns the building blocks to decouple channel mixing from spatial filtering, maximizing the effectiveness of the Coordinate Attention.

*   **Structural Innovation: Inverted Residual Blocks with Standard Convolutions**
    *   **Mechanism:** Instead of the standard `3x3 -> 3x3` block, we implement an **Inverted Bottleneck** design:
        1.  **Expansion (1x1 Conv):** Expands the channel dimension by a factor of **2** (e.g., $64 \to 128$). This projects the features into a higher-dimensional manifold where they can be more easily disentangled.
        2.  **Spatial Filtering (3x3 Conv):** A **Standard 3x3 Convolution** (not depthwise) operates on the expanded features. We explicitly reject depthwise convolutions to avoid the "weak local bias" that contributed to the failure of ConvNeXt (Cite solution_lesson_node_00031).
        3.  **Projection (1x1 Conv):** Projects the features back to the base channel dimension (e.g., $128 \to 64$) for the residual addition.
    *   **Rationale:** This structure increases the non-linearity and representational capacity of the network significantly more than a standard block, without the parameter explosion of simply widening the whole network.
*   **Enhanced Coordinate Attention (CA):** We insert the **Coordinate Attention** module **inside** the block, specifically after the spatial 3x3 convolution (on the expanded channels).
    *   **Rationale:** Applying attention on the high-dimensional expanded features allows the network to select relevant spatial/channel information with greater granularity before projecting back, maximizing the impact of the attention mechanism (Cite solution_lesson_node_00026).
*   **Backbone Configuration:**
    *   **Base Capacity:** We strictly maintain a base interface width of **64 filters** (Cite solution_lesson_node_00021).
    *   **Normalization & Activation:** We use **Batch Normalization** (Cite solution_lesson_node_00005) and **SiLU (Swish)** activations (Cite solution_lesson_node_00016) throughout to ensure convergence stability.
    *   **Bottleneck:** We retain the **Atrous Spatial Pyramid Pooling (ASPP)** module to capture multi-scale context (Cite solution_lesson_node_00026).
    *   **Upsampling:** We utilize **Transposed Convolutions** to ensure sharp edge reconstruction, rejecting fixed interpolation or PixelShuffle (Cite solution_lesson_node_00020, solution_lesson_node_00036).
*   **Global Residual Learning:** The network predicts the **noise residual** ($Clean = Input - Prediction$) (Cite solution_lesson_node_00013).

### Data: High-Density Contextual Processing
*   **Preprocessing:** Images are loaded in grayscale and normalized to [0, 1].
*   **Patch Size:** We will strictly use **128x128** patches. This ensures sufficient spatial context for the Coordinate Attention and ASPP modules (Cite solution_lesson_node_00022).
*   **Sampling Density:** We will employ **High-Density Sampling**, extracting **100 random patches per image per epoch**. This provides the rich gradient signal necessary to train the increased parameters of the Inverted Residual blocks (Cite solution_lesson_node_00014).
*   **Augmentation:** We will apply aggressive geometric augmentations (random horizontal flips, vertical flips, and discrete 90-degree rotations) to exploit the rotational symmetry of the noise (Cite solution_lesson_node_00010).

### Training: Regularized Residual Optimization
*   **Objective:** Minimize **Mean Squared Error (MSE)** on the predicted noise residual.
*   **Optimizer:** We will use **AdamW** with an aggressive **weight decay of 1e-2**. This strong regularization is essential to prevent the increased capacity of the inverted blocks from overfitting (Cite solution_lesson_node_00015).
*   **Scheduler:** A **Cosine Annealing** learning rate scheduler will be used to gradually reduce the learning rate, ensuring convergence to a sharp minimum (Cite solution_lesson_node_00014).
*   **Duration:** We will train for **100 epochs**. We explicitly acknowledge the "convergence tax" and allocate sufficient time for the heavier model to converge (Cite solution_lesson_node_00019).

### Evaluation: Robust Ensemble Inference
*   **Tiled Inference with Overlap:** Test images will be processed using a sliding window with **50% overlap**. Predictions in overlapping regions will be averaged to eliminate boundary artifacts and ensure every pixel is predicted with centered context (Cite solution_lesson_node_00023).
*   **Test-Time Augmentation (TTA):** We will generate predictions for the original image and its geometric transformations (flips/rotates) and average the results. This ensemble approach reduces variance and improves robustness (Cite solution_lesson_node_00013).
