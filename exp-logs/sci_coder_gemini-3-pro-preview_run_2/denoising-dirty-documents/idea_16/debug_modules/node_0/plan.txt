This script demonstrates the end-to-end workflow for the denoising task using the provided library.

**Implementation Strategy:**
1.  **Environment Setup**: Initialize the environment and set random seeds using `library.utils.seed_everything` to ensure reproducibility.
2.  **Data Loading Verification**: Instantiate `DenoisingDataset` in both 'train' and 'val' modes. We verify that the training set yields random crops of the correct patch size and the validation set yields full images.
3.  **Model Architecture Test**: Initialize the `ICResUNet` model and perform a forward pass with a dummy input tensor to confirm that the model graph is valid and input/output shapes match.
4.  **Training Loop Execution**: Run the `run_training` function in debug mode (`debug=True`) for a single epoch. This uses a small subset of data to quickly demonstrate the training process, loss calculation, and checkpoint saving without consuming excessive time.
5.  **Inference and Submission**: Validate the inference logic by running `predict_with_tta` on a single test image. Finally, execute `generate_submission` to process the entire test set using the trained model and generate the submission CSV file, followed by assertions to verify the file's structure.
