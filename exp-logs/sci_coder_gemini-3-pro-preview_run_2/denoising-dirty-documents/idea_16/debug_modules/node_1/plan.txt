Specifically, a single tensor in the decoder's coordinate attention block required 512 MiB, and the cumulative memory usage exceeded the limit. To resolve this, I will reduce the `BATCH_SIZE` in `library/config.py` from 64 to 16, which will significantly lower the memory footprint and allow the model to train within the hardware constraints.
