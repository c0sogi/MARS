The following script generates metadata for the image denoising task.

**Implementation Strategy:**
1.  **Setup and Discovery**: The script defines the input directory (`./input`) and output directory (`./metadata`). It scans the `train`, `train_cleaned`, and `test` subdirectories to identify image files.
2.  **Data Pairing**: For the training set, it identifies common image IDs between the noisy (`train`) and cleaned (`train_cleaned`) folders to ensure every training sample has a corresponding ground truth label.
3.  **DataFrame Construction**: It constructs Pandas DataFrames containing the relative file paths for features (noisy images) and labels (cleaned images).
4.  **Splitting**: It performs a random 80/20 train-validation split on the paired training data using `sklearn.model_selection.train_test_split` with a fixed random state (42), as this is a regression/generation task without discrete classes for stratification.
5.  **Saving**: The resulting DataFrames for training, validation, and testing are saved as CSV files in the `./metadata` directory.
6.  **Validation**:
    - It reloads the generated metadata files.
    - It prints summary statistics (row counts).
    - It verifies that the split ratio is approximately 80:20.
    - It performs a file existence check on a random sample of paths (up to 1000 per file) to ensure the metadata points to valid files in `./input`.
