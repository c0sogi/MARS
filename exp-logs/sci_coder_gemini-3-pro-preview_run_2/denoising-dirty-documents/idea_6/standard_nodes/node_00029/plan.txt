The implementation strategy involves initializing the `AG_CAC_ResUNet` model and training it using the `DenoisingDataset` with high-density patching as defined in the configuration. I will use the provided `library` modules for data loading, model definition, training engine, and inference. The training will run on the available GPU (A100) for a set number of epochs (controlled to ensure runtime compliance) with early stopping. After training, I will load the best checkpoint to compute the final validation RMSE. I will then perform a failure analysis by correlating the per-image RMSE with input image statistics (mean intensity and standard deviation) to identify error patterns. Finally, if the validation metric meets the specified threshold, I will generate the submission file using Test-Time Augmentation (TTA) via the `generate_submission_inference` function.
