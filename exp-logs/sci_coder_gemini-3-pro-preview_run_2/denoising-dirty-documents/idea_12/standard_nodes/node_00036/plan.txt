Here is the implementation strategy for the `runfile.py` script:

1.  **Setup & Configuration**: Initialize the environment and seed for reproducibility. Override specific `Config` parameters (specifically `EPOCHS` and `PATCHES_PER_EPOCH`) to create a "fast baseline" that runs efficiently within the time limit while still training on the full dataset diversity.
2.  **Training**: Execute the `train_model` function from the library, explicitly passing the modified configuration values to ensure they take effect.
3.  **Validation & Metric Calculation**:
    *   Load the best saved model checkpoint.
    *   Iterate through the validation dataset using `predict_tiled` to perform high-quality inference (handling image sizes robustly).
    *   Compute the RMSE for each image and aggregate to find the global validation metric.
    *   Print the required `Final Validation Metric: <value>` string.
4.  **Failure Analysis**:
    *   During validation, collect input image statistics (Mean Intensity, Standard Deviation) alongside the prediction error (RMSE).
    *   Calculate and print the Pearson correlation between the error magnitude and these input features to identify systematic weaknesses (e.g., if the model fails on low-contrast images).
5.  **Submission Generation**:
    *   Compare the calculated final validation metric against the specified threshold (`0.0076658159`).
    *   If the metric is lower (better), call `generate_submission` to create the `submission.csv` file using the test dataset.
