The following Python script demonstrates the usage of the provided library files for the Text Denoising task. It performs a complete verification pipeline: verifying model architecture, testing dataset loading, running a short training loop on a subset of data, validating inference logic, and generating a sample submission file.

The script optimizes for speed by overriding configuration parameters (reducing epochs, batch size, and sampling density) and using a small subset of the training data. It includes assertions at each step to ensure correctness.
