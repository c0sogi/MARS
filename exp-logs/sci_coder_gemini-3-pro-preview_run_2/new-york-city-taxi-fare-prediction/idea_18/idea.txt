Based on the comprehensive analysis of the provided lessons and the evolution of previous experiments, I propose a **Multi-Moment Hierarchical Dual-Hygiene Gradient Boosting** strategy. This approach synthesizes the stability of **Dual-Hygiene** data processing (Cite {solution_lesson_node_00066}), the information density of **Multi-Scale Hierarchies** (Cite {solution_lesson_node_00072}), and the risk-awareness of **Distributional Moments** (Cite {solution_lesson_node_00071}) to robustly predict heavy-tailed fares without gradient instability.

# Model
I will utilize the **XGBoost Regressor** as the backbone, leveraging its proven superiority for spatial tabular tasks Cite {solution_lesson_node_00030}.

*   **Structural Innovation (Multi-Moment Hierarchical Priors):** Previous successful ideas used the "Mean Fare" (1st Moment) as a feature. I will expand this to encode the **Pricing Distribution** by providing the **Mean**, **Standard Deviation (2nd Moment)**, and **Count** for every route.
    *   **Rationale:** A route with a high Mean Fare could be a long trip or a highly variable short trip (e.g., traffic-prone). By explicitly feeding the **Standard Deviation**, the model can distinguish between "consistent" routes and "risky" routes, allowing it to conditionally predict heavy-tail outliers only when variance is historically high.
    *   **Hierarchy:** These moments will be provided at three spatial resolutions simultaneously: **Micro** (Geohash L7, ~150m), **Meso** (Geohash L6, ~1km), and **Macro** (Geohash L5, ~5km). This creates a "Pyramid of Priors" that allows the tree to dynamically shift attention from fine-grained memorization (in dense areas) to regional smoothing (in sparse areas) via Soft Integration Cite {solution_lesson_node_00055}, Cite {solution_lesson_node_00072}.

# Data
The data pipeline employs a **Dual-Hygiene Strategy** combined with **K-Fold Vectorized Subtraction** to maximize signal quality while preventing the leakage observed in LOO approaches.

1.  **Input Sanitization (Safety First):**
    *   Strictly clamp all pickup and dropoff coordinates in the **Training, Validation, and Test sets** to the NYC bounding box. This mitigates the risk of linear extrapolation from corrupt GPS data, which destroyed previous hybrid models Cite {solution_lesson_node_00003}, Cite {solution_lesson_node_00070}.

2.  **Dual-Hygiene Definitions:**
    *   **Wisdom Set (Full 55M):** Apply **Strict Filtering** (Fare between $2.50-$200, Fare/Km < $10). This dataset is used *exclusively* to generate clean, robust statistical priors (Mean, Std, Count) Cite {solution_lesson_node_00066}.
    *   **Learner Set (Subsample 5M):** Apply **Loose Filtering** (Fare > $2.50). Retain valid high-fare outliers (e.g., >$500) to ensure the model learns to predict the "Heavy Tail" required for the RMSE metric Cite {solution_lesson_node_00018}.

3.  **Feature Engineering (K-Fold Vectorized Subtraction):**
    *   **Global Aggregation:** Compute `Sum_Fare`, `Sum_FareSq`, and `Count` for all three Geohash levels (L5, L6, L7) using the **Wisdom Set**.
    *   **Training Encoding:** For the Learner Set, use **K-Fold Vectorized Subtraction** (Global Stats - Fold Stats).
        *   *Correction:* Unlike Idea 17 which failed due to Leave-One-Out (LOO) leakage Cite {solution_lesson_node_00071}, this uses **K-Fold** separation. The statistics for Fold $k$ are derived strictly from the other $K-1$ folds, ensuring no target leakage.
    *   **Orthogonal Signals:** Retain explicit geometric features (Haversine, Manhattan, Rotated Coordinates) and raw temporal features (Hour, Year) to allow the model to predict deviations from the priors Cite {solution_lesson_node_00046}, Cite {solution_lesson_node_00065}.

# Training
1.  **Objective Function:** Use **`reg:squarederror`** (Standard L2 Loss).
    *   **Rationale:** We are training on a stable subsample with robust, clean Multi-Moment Priors as features. The optimization landscape is stable enough to use L2 loss, which aligns perfectly with the RMSE metric. We avoid robust losses (Huber) as they fail to prioritize the high-fare outliers explicitly retained in the Learner target Cite {solution_lesson_node_00037}.
2.  **Target:** Train on the **raw `fare_amount`**. Do not log-transform, as this biases the RMSE Cite {solution_lesson_node_00025}.

# Evaluation
1.  **Inference:**
    *   **Clamp Test Coordinates** to the NYC bounding box immediately upon loading Cite {solution_lesson_node_00070}.
    *   Map coordinates to Geohashes (L5, L6, L7).
    *   Retrieve `Mean`, `StdDev`, and `Count` priors from the **Global Wisdom Aggregates** (no subtraction needed).
2.  **Prediction:** Generate predictions using the XGBoost model.
3.  **Post-Processing:** Apply a minimum fare floor ($2.50).
