This occurs because `load_cached_data=True` is passed to the feature engineering methods, causing the system to prioritize existing files in the working directory over the fresh data objects. To fix this, I will set `load_cached_data=False` for the training, validation, and test feature processing steps in `runfile.py`. This forces the regeneration of features using the correct dataset size, ensuring the model trains on the intended data volume. Cite debug_lesson_13.
