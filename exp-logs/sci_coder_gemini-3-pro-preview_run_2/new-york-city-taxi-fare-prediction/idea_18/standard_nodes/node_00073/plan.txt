The implementation strategy follows the Multi-Moment Hierarchical Dual-Hygiene Gradient Boosting pipeline described.

1.  **Initialization**: Set random seeds and initialize the `FeatureEngineer` and `XGBTrainer` classes from the provided library.
2.  **Data Loading**: Use the `data_loader` module to load the training (split into Wisdom and Learner sets), validation, and test datasets. We enable caching to speed up subsequent runs.
3.  **Feature Engineering**:
    *   Process the training data using `process_train_data`, which fits the hierarchical stats engine on the Wisdom set and applies K-Fold Vectorized Subtraction to the Learner set.
    *   Process validation and test data using the global priors derived from the Wisdom set without subtraction.
4.  **Model Training**: Train the XGBoost model using the processed Learner set and Validation set. The configuration ensures GPU acceleration (`device='cuda'`) and histogram-based learning for speed.
5.  **Evaluation**: Compute the RMSE on the full validation set and print it in the required format.
6.  **Failure Analysis**: Calculate residuals on the validation set and compute Pearson correlations between features and the absolute error to identify sources of model failure.
7.  **Submission**: If the validation RMSE meets the specified threshold (< 3.4389...), generate the `submission.csv` file using the processed test set.
