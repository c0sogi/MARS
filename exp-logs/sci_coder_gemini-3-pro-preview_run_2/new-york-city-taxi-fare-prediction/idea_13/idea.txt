Based on the comprehensive analysis of the provided lessons, I propose a **Multi-Resolution Global-Prior Gradient Boosting** strategy. This approach synthesizes the stability of subsampled training with the information density of the full dataset, while resolving the critical conflict between "Hard Integration" (Base Margins) and "Soft Integration" (Features).

# Model
I will utilize the **XGBoost Regressor** as the backbone, leveraging its proven superiority over Deep Learning for low-dimensional spatial tasks **Cite {solution_lesson_node_00030}**.
*   **Structural Innovation (Multi-Resolution Soft Integration):** Instead of relying on a single spatial resolution or forcing a hierarchical fallback via Base Margins (which risks failure in sparse regions **Cite {solution_lesson_node_00055}**), I will provide the model with a **Pyramid of Spatial Priors**. I will generate K-Fold Target Encodings at three distinct resolutions:
    1.  **Micro-Scale:** ~100m (3 decimal places) to capture specific building/corner pricing.
    2.  **Meso-Scale:** ~1km (2 decimal places) to capture neighborhood trends.
    3.  **Macro-Scale:** ~10km (1 decimal place) to capture regional/borough baselines.
    These will be fed as **Input Features** ("Soft Integration"). This allows the Gradient Boosted Tree to dynamically select the most relevant resolution for each specific query—relying on Micro-Scale for dense urban areas and falling back to Meso/Macro-Scale for sparse outer regions—without the brittleness of manual fallback logic.

# Data
The data pipeline employs **Differential Data Hygiene** and **Vectorized Subtraction** to maximize signal quality.

1.  **Input Sanitization (Clamping):** Strictly clamp all pickup and dropoff coordinates in the Training and Test sets to the NYC bounding box. This prevents the linear extrapolation of massive distances from corrupt GPS data **Cite {solution_lesson_node_00003}**.

2.  **Global Feature Engineering (The "Wisdom"):**
    *   **Source:** Use the **Full 55M Dataset**.
    *   **Physics-Consistent Hygiene:** Before calculating statistics, filter the *source data* to remove "garbage" outliers (e.g., Fare > $500 AND Fare/Distance > $50/km). This ensures the priors represent valid pricing signals, not noise **Cite {solution_lesson_node_00017}**.
    *   **K-Fold Vectorized Subtraction:** Partition the full dataset into $K$ folds. For each fold, calculate the Multi-Resolution Priors (Micro, Meso, Macro) using the **Vectorized Subtraction Method** (Global Stats - Fold Stats). This allows us to generate high-cardinality features from the full 55M dataset without data leakage and without the computational cost of re-aggregating for every fold **Cite {solution_lesson_node_00045}**. **Cite {solution_lesson_node_00060}** confirms this K-Fold approach is superior to disjoint splitting.

3.  **Training Set Construction (The "Learner"):**
    *   **Subsampling:** Select a stable subsample of **5 million rows** for the actual model training to avoid gradient instability **Cite {solution_lesson_node_00017}**.
    *   **Target Preservation:** Use the **raw `fare_amount`** for the training target. Do **not** truncate valid high fares (e.g., >$500) and do **not** log-transform. This ensures the model optimizes the RMSE metric for the "Heavy Tail" **Cite {solution_lesson_node_00018}**, **Cite {solution_lesson_node_00025}**.
    *   **Inductive Bias Features:** Include Haversine distance, Manhattan distance, and Rotated Coordinates. This ensures the model retains generalizable physical rules and does not rely solely on memorization **Cite {solution_lesson_node_00046}**.

# Training
1.  **Objective Function:** Use **`reg:squarederror`** (Standard L2 Loss).
    *   **Rationale:** We are training on a stable subsample with robust, clean Multi-Resolution Priors as features. The optimization landscape is therefore stable enough to use the L2 loss, which aligns perfectly with the RMSE metric. We avoid robust losses (Huber) as they fail to prioritize the high-fare outliers we explicitly retained in the target **Cite {solution_lesson_node_00037}**.
2.  **Strategy:** Train the XGBoost model to map the inputs (Distances + Multi-Resolution Priors) to the Raw Target.

# Evaluation
1.  **Inference:**
    *   For the test set, generate the Multi-Resolution Priors (Micro, Meso, Macro) using the **Global Statistics** derived from the full 55M dataset (no subtraction needed).
2.  **Prediction:** Generate predictions using the XGBoost model.
3.  **Post-Processing:** Apply a minimum fare floor ($2.50) and ensure coordinate clamping is applied to test inputs **Cite {solution_lesson_node_00003}**.
