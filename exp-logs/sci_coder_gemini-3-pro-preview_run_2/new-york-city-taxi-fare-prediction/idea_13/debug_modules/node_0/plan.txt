This script demonstrates the end-to-end usage of the provided NYC Taxi Fare Prediction library. To ensure the demonstration runs quickly within the time limit, it performs the following optimizations:
1.  **Data Subsampling**: It creates small subsets (20,000 rows) of the original training and validation data and saves them to the working directory.
2.  **Configuration Patching**: It monkey-patches the module-level constants in the library files to point to these smaller datasets and reduces the XGBoost training iterations.
3.  **Pipeline Execution**: It runs the full `DataManager` pipeline (loading, spatial prior generation, feature engineering) and `ModelTrainer` workflow (training, prediction, submission generation).
4.  **Verification**: It includes assertions to verify data shapes, feature generation, and prediction validity.
