The issue is a `UFuncOutputCastingError` occurring during the in-place subtraction `curr_count -= sub_count`. This happens because `curr_count` is derived from the global statistics DataFrame where the count column is of integer type (dtype `int64`), while `sub_count` is derived from the local fold statistics which contains `NaN`s (due to filtering) and is therefore of floating-point type (dtype `float64`). NumPy prevents in-place subtraction of a float array from an integer array because it would require casting the integer array to float, which is not allowed for in-place operations.

To fix this, we must explicitly cast the statistical vectors (`curr_sum`, `curr_sum_sq`, `curr_count`) to `float` immediately upon extraction. This ensures that the destination array for the subtraction operation is already a floating-point array, allowing it to accommodate the floating-point values from `sub_count`. This applies to both the Route Stats and Rate Stats sections of the `enrich_data` method.
