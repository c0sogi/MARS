Based on the comprehensive analysis of the provided lessons and the evolution of previous ideas, I propose a **Hierarchical Residual Gradient Boosting** strategy. This approach structurally resolves the conflict between the need for massive data to capture "Heavy Tail" outliers (Lesson 00018) and the gradient instability caused by training on that data (Lesson 00017).

# Model
I will utilize the **XGBoost Regressor** as the backbone, leveraging its superiority for spatial tabular tasks **Cite {solution_lesson_node_00030}**.
*   **Structural Innovation (Hierarchical Base Margin):** Instead of using a single "Route Average" feature or a simple base margin, I will construct a **Hierarchical Prior** to serve as the `base_margin` for the model. This prior will dynamically fallback based on information density:
    1.  **Level 1 (Exact Route):** High-resolution Grid Average (Fine-grained memorization).
    2.  **Level 2 (Neighborhood):** Low-resolution Grid Average (Coarse smoothing).
    3.  **Level 3 (Physics):** A simple linear estimate ($Rate \times Distance$).
    The model will then perform **Residual Learning**, predicting only the deviation from this robust prior. This anchors the predictions, stabilizing the L2 gradients **Cite {solution_lesson_node_00048}** while retaining the "Inductive Bias" of physical distance features **Cite {solution_lesson_node_00046}**.

# Data
The data pipeline employs a **Two-Stage Global-Local Architecture** with strict **Physics-Consistent Hygiene**.

**Stage 1: Global Knowledge Base (The "Prior")**
1.  **Source:** Use the **Full 55M Dataset** to maximize coverage of rare routes.
2.  **Physics-Consistent Filtering:** Apply a strict consistency filter to this data: Remove rows where `Fare_Amount > $500` **AND** `Fare_Per_Km > Threshold` (e.g., >$50/km). This removes "garbage" outliers (e.g., $93k for 100m) that corrupt statistical averages **Cite {solution_lesson_node_00017}**, while preserving valid long-distance high fares needed for the test set **Cite {solution_lesson_node_00018}**.
3.  **Hierarchical Aggregation:**
    *   **Fine Grid:** Round coordinates to 3 decimal places (~100m) and compute `Sum` and `Count` of fares.
    *   **Coarse Grid:** Round coordinates to 2 decimal places (~1km) and compute `Sum` and `Count`.
    *   **Global Rates:** Calculate the global mean fare per km.

**Stage 2: Training Set Construction (The "Learner")**
1.  **Subsampling:** Select a stable subsample of **5-10 million rows** for the actual gradient boosting. This avoids the convergence failure associated with the full dataset **Cite {solution_lesson_node_00017}**.
2.  **Input Clamping:** Strictly clamp all spatial coordinates to the NYC bounding box to prevent linear extrapolation risks **Cite {solution_lesson_node_00003}**.
3.  **Base Margin Construction (Vectorized Subtraction):** For each training row, construct the `base_margin` using the Global Knowledge Base.
    *   Use **Vectorized Subtraction** to subtract the current training batch's statistics from the Global Aggregates to ensure no data leakage **Cite {solution_lesson_node_00045}**.
    *   **Logic:** If `Fine_Grid_Count > Threshold`, use Fine Average. Else if `Coarse_Grid_Count > Threshold`, use Coarse Average. Else, use `Global_Rate * Distance`.
4.  **Feature Engineering:** Retain explicit physical features (Haversine, Manhattan, Rotated Coordinates) to allow the model to generalize to unseen locations, preventing the failure of pure memorization **Cite {solution_lesson_node_00046}**.

# Training
1.  **Objective Function:** Use **`reg:squarederror`** (Standard L2 Loss).
    *   **Rationale:** By using a robust Hierarchical Prior as the `base_margin` and filtering "garbage" outliers, the residuals become well-behaved. We can thus safely use the L2 loss that aligns with the RMSE metric, avoiding the underperformance of robust losses like Huber **Cite {solution_lesson_node_00037}**.
2.  **Target:** Train on the **raw `fare_amount`** (after Physics-Consistent Filtering). Do not log-transform, as this biases the RMSE **Cite {solution_lesson_node_00025}**.
3.  **Optimization:** Train the XGBoost model to minimize the residual error between the `base_margin` and the target.

# Evaluation
1.  **Inference:**
    *   Construct the `base_margin` for the test set using the **Global Knowledge Base** (Stage 1). Since test data is not in the training set, use the full global statistics directly.
    *   Apply the fallback logic (Fine -> Coarse -> Physics) to ensure every test sample has a robust prior.
2.  **Prediction:** The model predicts the residual. Final Prediction = `base_margin` + `predicted_residual`.
3.  **Post-Processing:** Apply a minimum fare floor ($2.50) and ensure coordinate clamping **Cite {solution_lesson_node_00003}**.
