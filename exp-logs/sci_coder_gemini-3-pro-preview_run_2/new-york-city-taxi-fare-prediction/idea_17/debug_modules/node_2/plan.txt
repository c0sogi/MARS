The `IndexError` occurs because the `merge` operation in `retrieve_and_subtract_priors` creates a new DataFrame with a reset index (0 to N-1), while the `is_wisdom` Series retains the original sparse index from the sampled DataFrame. When subtracting `is_wisdom` from `merged["count"]`, Pandas attempts to align these mismatched indices, creating a union of indices that inflates the size of the resulting Series (to ~9.4M rows) beyond the size of the DataFrame (~5M rows). I will fix this by using `.values` on `is_wisdom` to perform a positional subtraction, ignoring indices (Cite debug_lesson_5).

Additionally, the pipeline is processing the full 5M dataset instead of the intended 5,000-row snapshot because `TRAIN_SAMPLE_SIZE` is imported by value in `feature_builder.py`. I will update the import to access the configuration module dynamically (`import library.config as config`), ensuring the runtime patch in `runfile.py` is respected (Cite debug_lesson_7).
