The `AssertionError` occurs because the synthetic data generated for the demo has a high fare-per-km ratio (due to a fixed base fare on short trips), which exceeds the strict `WISDOM_MAX_FARE_PER_KM` threshold (10.0) defined in `ProjectConfig`. This causes the `StatsManager` to filter out all data, resulting in empty statistics tables. To resolve this, I will relax the `WISDOM_MAX_FARE_PER_KM` constraint to 1000.0 within the `setup_demo_environment` function in `runfile.py`. This ensures the demo environment accommodates the properties of the synthetic data, preventing the data cleaning side effect from emptying the dataset (Cite debug_lesson_4).
