Based on the comprehensive analysis of the provided lessons and the evolution of previous experiments, I propose a **Hierarchical Residual Dual-Hygiene Gradient Boosting** strategy. This approach structurally synthesizes the data efficiency of **Residual Learning** (Lesson 00048), the robustness of **Dual-Hygiene** (Lesson 00066), and the safety of **Hierarchical Fallbacks** (Lesson 00055) to resolve the conflict between using clean priors and predicting heavy-tail outliers.

# Model
I will utilize the **XGBoost Regressor** as the backbone, leveraging its proven superiority for spatial tabular tasks **Cite {solution_lesson_node_00030}**.

*   **Structural Innovation (Hierarchical Residual Learning):** Instead of using target encodings merely as input features ("Soft Integration") or using a single brittle prior as a base margin ("Hard Integration"), I will construct a **Robust Hierarchical Base Margin**.
    *   The model will be trained to predict the **residual** ($y - \text{Margin}$).
    *   The Margin will be dynamically constructed for every row using a **Waterfall Logic** that prioritizes specificity but guarantees validity:
        1.  **Level 1 (Micro-Interaction):** Mean Fare for `(Pickup_Geohash7, Dropoff_Geohash7)` (~150m).
        2.  **Level 2 (Meso-Interaction):** Mean Fare for `(Pickup_Geohash6, Dropoff_Geohash6)` (~1km).
        3.  **Level 3 (Physics Baseline):** `Global_Fare_Per_Km * Haversine_Distance`.
    *   **Rationale:** This ensures the model always starts from a high-quality, physics-grounded baseline, focusing its capacity entirely on learning temporal deviations (traffic) and heavy-tail outliers, without the risk of "Zero" or "NaN" margins causing instability **Cite {solution_lesson_node_00055}**.

# Data
The data pipeline employs a **Dual-Hygiene Strategy** combined with **Vectorized Subtraction** to maximize signal quality while preventing leakage.

1.  **Dual-Hygiene Preprocessing (Cite {solution_lesson_node_00066}):**
    *   **Wisdom Set (Statistics Generation):** Use the **Full 55M Dataset**. Apply **Strict Physics-Consistent Filtering**: Remove outliers (e.g., Fare > $200, Fare/Km > $10) and short trips. This ensures the Hierarchical Margins represent the "True Expected Price," free from noise **Cite {solution_lesson_node_00017}**.
    *   **Learner Set (Model Training):** Select a stable **Subsample (5M rows)**. Apply **Loose Filtering**: Retain valid high-fare outliers (e.g., long trips > $500) to ensure the model learns to predict the "Heavy Tail" required for the RMSE metric **Cite {solution_lesson_node_00018}**.

2.  **Hierarchical Margin Construction:**
    *   Compute the Level 1, Level 2, and Level 3 statistics on the Wisdom Set.
    *   For the Learner Set, use **K-Fold Vectorized Subtraction** (Global Stats - Fold Stats) to derive these values without data leakage **Cite {solution_lesson_node_00045}**.
    *   Apply the Waterfall Logic: If `Level1_Count > Threshold`, use Level 1; else if `Level2_Count > Threshold`, use Level 2; else use Level 3. Set this resulting scalar as the `base_margin`.

3.  **Feature Engineering:**
    *   **Orthogonal Signals:** Retain raw temporal features (Hour, Year, Weekday) to allow the model to predict time-based deviations from the static spatial margin **Cite {solution_lesson_node_00065}**.
    *   **Inductive Bias:** Retain explicit geometric features (Haversine, Manhattan, Rotated Coordinates) **Cite {solution_lesson_node_00046}**.
    *   **Soft Integration:** Include the raw `Level1_Mean` and `Level2_Mean` as input features as well. This allows the tree to "correct" the margin if the fallback logic was suboptimal for a specific case.
    *   **Sanitization:** Strictly clamp all coordinates to the NYC bounding box **Cite {solution_lesson_node_00003}**.

# Training
1.  **Objective Function:** Use **`reg:squarederror`** (Standard L2 Loss).
    *   **Rationale:** By anchoring the prediction with a clean, robust Base Margin, the residuals become centered and well-behaved. We can thus safely use L2 loss to optimize the specific RMSE metric, capturing the heavy tail without the gradient instability that previously required robust losses **Cite {solution_lesson_node_00037}**.
2.  **Mechanism:** Pass the constructed `Hierarchical_Margin` as the `base_margin` argument to the XGBoost training API **Cite {solution_lesson_node_00048}**.
3.  **Target:** Train on the **raw `fare_amount`** (Loose Filtered). Do not log-transform **Cite {solution_lesson_node_00025}**.

# Evaluation
1.  **Inference:**
    *   Map the test set coordinates to Geohashes (L6, L7).
    *   Construct the `Hierarchical_Margin` using the **Strict Global Statistics** derived from the full 55M Wisdom Set (no subtraction needed).
    *   Apply the same Waterfall Logic (L1 -> L2 -> L3) to ensure every test sample has a valid margin.
2.  **Prediction:** The model predicts the residual. `Final_Prediction = Margin + Predicted_Residual`.
3.  **Post-Processing:** Apply a minimum fare floor ($2.50) and clamp predictions to be non-negative.
