### Implementation Strategy

1.  **Environment Setup & Reproducibility**: Set random seeds for NumPy and Python to ensure consistent results.
2.  **Data Subsampling for Speed**:
    *   The original dataset is massive (55M+ rows). To demonstrate the pipeline quickly (within seconds/minutes), we will create small subsets of the training and validation data (e.g., 10,000 rows) and save them to the `./working` directory.
    *   We will dynamically patch the file paths and constants in the `library.data_loader` module to point to these small files instead of the full metadata files. This ensures the `GlobalRouteStats` and `DatasetBuilder` classes process data rapidly.
3.  **Pipeline Execution**:
    *   **Data Loading**: Instantiate `DatasetBuilder` to generate processed training, validation, and test sets. This demonstrates the "Stage 1" (Global Stats) and "Stage 2" (Vectorized Subtraction) logic provided in the library.
    *   **Verification**: Assert that the processed dataframes contain the expected feature columns (e.g., `base_margin`, `distance_haversine`) and that the shapes match our subsample settings.
    *   **Model Training**: Use `model_trainer.train_model` with highly optimized hyperparameters (e.g., `n_estimators=10`, `max_depth=3`) to ensure the XGBoost training completes almost instantly while still exercising the code paths (GPU/CPU).
    *   **Prediction**: Generate a submission file using `model_trainer.generate_submission`.
4.  **Output Validation**:
    *   Verify the submission file exists.
    *   Check that predictions follow the expected format and constraints (e.g., no negative fares).
