My strategy to optimize performance is as follows:

1.  **Target Variable Sanitization**: I will implement strict filtering on the training data to remove `fare_amount` outliers (keeping only values between $2.50 and $500.00). This directly addresses the instability observed in the previous "Lesson Learned" (Cite solution_lesson_node_00017), where extreme outliers caused the loss function to explode when scaling up the data.
2.  **Feature Engineering**: I will add 45-degree rotated coordinate features (`pickup_rot45_lat`, etc.) to the `TaxiDataProcessor`. This transformation aligns the coordinate system with the Manhattan street grid, allowing the decision-tree splits (which are axis-aligned) to better capture diagonal distances.
3.  **Scale Up Training**: With the target variable sanitized, I will safely increase the training sample size in `runfile.py` from 5 million to 20 million rows. This utilizes the powerful A100 GPU to learn from a larger portion of the dataset.
4.  **Configuration**: I will update the cache directory to ensure the new features are generated and increase the `num_boost_round` to 5000 to allow the model to converge on the larger dataset.
