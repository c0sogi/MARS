The strategy involves applying strict target variable sanitization to both the training and validation sets. Previous lessons identified that extreme outliers in the `fare_amount` (up to $93k) destabilize the L2 loss function used by XGBoost (Cite `solution_lesson_node_00017`) and that evaluating on an uncleaned validation set containing these outliers results in misleadingly high RMSE scores (Cite `solution_lesson_node_00018`). By enforcing reasonable bounds ($2.50 - $500.00) and consistency checks on the validation set, we ensure the metric reflects performance on the "clean" distribution expected in the test set. I will modify `config.py` to define these bounds and update `data_handler.py` to apply the filtering logic universally to any dataset containing the target variable.
