Implementation strategy:
1.  **Environment & Setup**: Initialize the environment by setting random seeds for reproducibility and detecting the computation device (GPU/CPU).
2.  **Data Preparation**: Load the training, validation, and test DataLoaders using the provided `get_dataloaders` function. Compute inverse class frequency weights to handle class imbalance, which will be passed to the loss function.
3.  **Model Initialization**: Instantiate the `AppleClassifier` (EfficientNet-B5 based) and the `WeightedLabelSmoothCrossEntropy` loss function. Set up the AdamW optimizer and Cosine Annealing scheduler.
4.  **Training Loop**: Execute the training for the number of epochs specified in the configuration. In each epoch, perform a training pass and a validation pass. Track the best model based on the validation ROC AUC score and save the weights.
5.  **Final Validation & Failure Analysis**: Load the best saved model. Perform a full inference pass on the validation set to calculate the `Final Validation Metric`. Conduct failure analysis by computing the correlation between the prediction error magnitude (MAE) and image meta-features (width, height, intensity) to identify systematic weaknesses.
6.  **Conditional Submission**: Compare the final validation metric against the strict threshold (0.9902480620249655). If the metric exceeds the threshold, generate predictions for the test set (using Test Time Augmentation) and save the `submission.csv` file.
