The implementation strategy involves the following steps:

1.  **Setup and Initialization**: Set random seeds for reproducibility using the provided utility function.
2.  **Data Loading**: Initialize the data loaders for training, validation, and testing using the `create_dataloaders` function. The dataset is small (~1300 training images), so we will use the full dataset to maximize performance while keeping the epoch count moderate (10 epochs) to satisfy the "fast baseline" requirement.
3.  **Model Construction**: Build a ResNet-18 model pre-trained on ImageNet using `build_model`, modified for the 4-class classification task.
4.  **Training Loop**:
    *   Configure the Adam optimizer and Cosine Annealing scheduler.
    *   Execute the training process using the `fit` function, which handles class weighting, backpropagation, and saving the best model based on validation ROC AUC.
5.  **Validation & Metrics**:
    *   Reload the best saved model.
    *   Evaluate it on the validation set to compute the final "Mean Column-wise ROC AUC".
    *   Print the metric in the strictly required format.
6.  **Failure Analysis**:
    *   Compute prediction errors on the validation set (defined as `1 - probability_of_true_class`).
    *   Extract basic image metadata (file size, aspect ratio, mean intensity) for the validation images.
    *   Calculate and print the Pearson correlation between these features and the prediction error to identify potential biases.
7.  **Submission**:
    *   Generate predictions for the test set using the best model.
    *   Save the results to `submission.csv` in the specified format.
