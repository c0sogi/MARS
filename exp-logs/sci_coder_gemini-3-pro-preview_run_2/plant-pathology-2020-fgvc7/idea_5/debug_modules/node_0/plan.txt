I will switch the model backbone to a lightweight `resnet18` (initialized without pre-trained weights for speed), reduce the image size to 224x224, and set the batch size to 4.
2.  **Data Loading & Verification**: I will load the provided metadata files and sample a tiny subset (e.g., 10 images) to create instances of `AppleDataset`. I will verify that the dataset correctly loads images and transforms the one-hot encoded targets into the required multi-label format (Rust, Scab).
3.  **Model Initialization**: I will instantiate the `AppleDiseaseModel` with the lightweight backbone and verify the output shape of the forward pass.
4.  **Logic Verification**: I will explicitly test the `reconstruct_probabilities` function from `library.engine` with known input values to ensure the mathematical decomposition of the 4-class probabilities is correct.
5.  **Training & Inference Simulation**: Instead of running the full `train_model` function (which would take too long), I will execute a single training epoch and an evaluation step using the `train_one_epoch` and `evaluate` functions from `library.engine` on the data subset. Finally, I will simulate the inference pipeline to demonstrate how predictions are generated and formatted.
