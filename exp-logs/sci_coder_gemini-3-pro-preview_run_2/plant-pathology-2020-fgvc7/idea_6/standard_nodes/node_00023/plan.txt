Implementation strategy:
1.  **Setup & Configuration**: Initialize the `Config` (ensuring `debug=False` to use the full dataset for maximum performance) and set random seeds for reproducibility using `seed_everything`. Detect the available computing device (GPU).
2.  **5-Fold Cross-Validation Training**: Implement a loop over the 5 folds defined in the configuration.
    *   For each fold, initialize the `AppleDiseaseModel` (EfficientNetV2-L), `AdamW` optimizer, `ReduceLROnPlateau` scheduler, and `BCEWithLogitsLoss` with positive class weights to handle imbalance.
    *   Use the `fit` function from `library.engine` to train the model and save the best checkpoint based on validation AUC.
    *   Store the trained model (moved to CPU to save memory) in a list for the final ensemble.
    *   Generate Out-Of-Fold (OOF) predictions for the validation set of the current fold to construct a global validation assessment.
3.  **Validation Assessment**: Concatenate all OOF predictions and targets to calculate the global Mean Column-wise ROC AUC. Print this metric in the strictly required format.
4.  **Failure Analysis**: Compute the mean absolute error for each validation sample. Extract image metadata (width, height, file size, aspect ratio) and calculate the Pearson correlation between these features and the error magnitude to identify potential failure modes.
5.  **Submission**: Check if the final validation metric exceeds the specified threshold (`0.9954104122251848`). If successful, load the test dataset and use the `predict_ensemble` function (which applies Test Time Augmentation and model averaging) to generate predictions. Save the final output to `submission.csv`.
