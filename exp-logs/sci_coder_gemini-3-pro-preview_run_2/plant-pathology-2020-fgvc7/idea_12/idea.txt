# Model
I propose a **Heterogeneous Ensemble** comprising two high-capacity backbones: **EfficientNetV2-L** and **ConvNeXt-Base**. These models will be structurally modified to form a specialized "Fine-Grained Pathology" architecture.
*   **Structural Innovation (GeM Pooling):** I will replace the standard Global Average Pooling (GAP) layer in both backbones with **Generalized Mean (GeM) Pooling**.
    *   **Rationale:** Standard GAP dilutes the signal of small, localized disease spots (e.g., rust pustules) by averaging them with the large healthy leaf background. GeM Pooling ($f(x) = (\frac{1}{N}\sum x^p)^{1/p}$) introduces a learnable parameter $p$ to focus on high-activation regions (the lesions) while retaining spatial context, structurally aligning the network with the fine-grained nature of the task `Cite solution_lesson_node_00045`.
*   **Structural Innovation (Multi-Sample Dropout):** The classification head will be upgraded to use **Multi-Sample Dropout**. Instead of a single dropout path, the features will pass through multiple parallel dropout layers with distinct masks. The loss is calculated for each branch and averaged. This technique accelerates convergence and improves generalization on small datasets by creating an implicit ensemble within the network `Cite solution_lesson_node_00045`.
*   **Head Design (Multi-Label Decomposition):** Both models will utilize the **Multi-Label Decomposition** strategy, outputting 2 binary logits ("Is Rust" and "Is Scab"). This allows the model to learn shared representations for the "Multiple Diseases" class (the intersection of Rust and Scab) rather than treating it as a disjoint minority class `Cite solution_lesson_node_00020`.

# Evaluation
*   **Inference:** We will apply **Test Time Augmentation (TTA)** (horizontal flip) for all 10 base models `Cite solution_lesson_node_00002`.
*   **Structural Innovation (Rank-Calibrated Averaging):** To resolve the **calibration drift** that degraded previous cross-validation attempts `Cite solution_lesson_node_00030`, we will implement **Rank Averaging**:
    1.  Convert the raw probability predictions of each model to **percentile ranks** (0-1) on the test set.
    2.  Compute the arithmetic mean of these ranks across all 10 models. This ensures that fold-specific calibration biases do not disrupt the global ordering required for the ROC AUC metric.
*   **Reconstruction:** The aggregated rank scores for "Rust" ($S_r$) and "Scab" ($S_s$) will be mapped to the 4-class format:
    *   `Healthy`: $(1 - S_r)(1 - S_s)$
    *   `Rust`: $S_r(1 - S_s)$
    *   `Scab`: $(1 - S_r)S_s$
    *   `Multiple`: $S_r S_s$
