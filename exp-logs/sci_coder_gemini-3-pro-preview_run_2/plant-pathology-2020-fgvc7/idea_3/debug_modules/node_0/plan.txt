### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by importing necessary libraries and setting random seeds using `library.utils.seed_everything` to ensure reproducibility.
2.  **Component Verification**:
    *   **Utils**: Verify the `calculate_roc_auc` metric function using synthetic ground truth and prediction arrays.
    *   **Augmentations**: Instantiate the `CutMix` class and apply it to a dummy batch of tensors to verify output shapes and mixing logic. Initialize training transformations.
    *   **Dataset**: Instantiate `AppleDataset` for training, validation, and testing modes using a small `debug_subset_size`. This ensures the data loading pipeline (reading metadata, loading images via OpenCV, applying transforms) works correctly without processing the entire dataset.
    *   **Model**: Initialize the `AppleDiseaseModel` with `pretrained=False` to avoid downloading weights and speed up initialization. Pass a dummy input batch to verify the forward pass and output dimensions.
    *   **Loss**: Calculate class weights using `library.loss.get_class_weights` and verify the `WeightedSoftCrossEntropy` loss function with dummy logits and targets.
3.  **Integration & Execution (Engine)**:
    *   Create PyTorch `DataLoader` instances for the subset datasets.
    *   Run `library.engine.train_model` for a single epoch with the subset data. This demonstrates the full training loop (forward pass, loss calculation, backward pass, optimizer step, validation) efficiently.
    *   Run `library.engine.generate_submission` to demonstrate inference and Test Time Augmentation (TTA), producing a submission file in the `./working` directory.
4.  **Final Validation**: Assert that the model checkpoint and submission file were successfully created.
