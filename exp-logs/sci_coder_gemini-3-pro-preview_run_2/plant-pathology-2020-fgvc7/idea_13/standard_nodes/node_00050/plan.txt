I will implement the orchestration script `runfile.py` to train the heterogeneous ensemble (EfficientNetV2-L and ConvNeXt-Base) using 5-fold cross-validation. I will optimize the training for speed by setting `Config.EPOCHS` to 10, which is sufficient for convergence on this small dataset (~1600 images) using the A100 GPU, while remaining well within the time limit.

The script will:
1.  **Train** both architectures across all 5 folds.
2.  **Generate** Out-Of-Fold (OOF) predictions and raw Test predictions.
3.  **Perform Rank-Calibrated Stacking** to combine the models. I will use `cross_val_predict` on the OOF predictions to generate unbiased "Stacked OOF" predictions for validation purposes.
4.  **Evaluate** the model on the designated hold-out validation set (subset of OOF corresponding to `val_metadata.csv`) and print the required metric.
5.  **Conduct Failure Analysis** by correlating prediction errors with image metadata (file size, dimensions).
6.  **Submit** the predictions if the validation AUC exceeds the specified threshold.
