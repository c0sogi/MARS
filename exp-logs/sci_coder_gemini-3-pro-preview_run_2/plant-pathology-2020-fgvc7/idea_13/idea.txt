# Model
I propose a **Heterogeneous Ensemble** comprising two high-capacity backbones: **EfficientNetV2-L** and **ConvNeXt-Base**. These models will be structurally modified to form a specialized "Fine-Grained Pathology" architecture.
*   **Structural Innovation (GeM Pooling):** I will replace the standard Global Average Pooling (GAP) layer in both backbones with **Generalized Mean (GeM) Pooling**.
    *   **Rationale:** Standard GAP dilutes the signal of small, localized disease spots (e.g., rust pustules) by averaging them with the large healthy leaf background. GeM Pooling ($f(x) = (\frac{1}{N}\sum x^p)^{1/p}$) introduces a learnable parameter $p$ to focus on high-activation regions (the lesions) while retaining spatial context `Cite solution_lesson_node_00045`.
*   **Structural Innovation (Multi-Sample Dropout):** The classification head will be upgraded to use **Multi-Sample Dropout**. Instead of a single dropout path, the features will pass through multiple parallel dropout layers with distinct masks. The loss is calculated for each branch and averaged. This accelerates convergence and improves generalization on small datasets `Cite solution_lesson_node_00045`.
*   **Head Design (Multi-Label Decomposition):** Both models will utilize the **Multi-Label Decomposition** strategy, outputting 2 binary logits ("Is Rust" and "Is Scab"). This allows the model to learn shared representations for the "Multiple Diseases" class (the intersection of Rust and Scab) rather than treating it as a disjoint minority class `Cite solution_lesson_node_00020`.

*   **Strategy:** **5-Fold Cross-Validation** will be performed for both architectures (10 models total).
*   **Convergence Mandate:** Addressing the failure of previous ensemble attempts `Cite solution_lesson_node_00043`, we will allocate sufficient runtime (e.g., 30-40 epochs per fold) to ensure each model reaches a true performance plateau.
*   **Optimization:**

# Evaluation
*   **Inference:** We will apply **Test Time Augmentation (TTA)** (horizontal flip) for all 10 base models `Cite solution_lesson_node_00002`.
*   **Structural Innovation (Rank-Calibrated Stacking):** To resolve calibration drift `Cite solution_lesson_node_00030` while optimizing the ensemble weights, we will implement a **Rank-Based Stacking Meta-Learner**:
    1.  **Rank Normalization:** Convert the Out-Of-Fold (OOF) probabilities of all 10 models to **percentile ranks** (0-1). This removes fold-specific calibration biases.
    2.  **Meta-Training:** Train two **Logistic Regression** models (one for "Rust", one for "Scab") using the *ranked* OOF predictions as features. This learns the optimal weighted combination of the EfficientNet and ConvNeXt ranks.
    3.  **Prediction:** Apply the same ranking and meta-model to the test set predictions.
*   **Reconstruction:** The final stacked probabilities for "Rust" ($P_r$) and "Scab" ($P_s$) will be mapped to the 4-class format:
    *   `Healthy`: $(1 - P_r)(1 - P_s)$
    *   `Rust`: $P_r(1 - P_s)$
    *   `Scab`: $(1 - P_r)P_s$
    *   `Multiple`: $P_r P_s$
