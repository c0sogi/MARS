Implementation strategy:

1.  **Setup**: Import necessary modules and the provided library classes. Define a `main` execution block.
2.  **Configuration Override**: Dynamically modify the `Config` class attributes to create a fast "demo" environment. This includes enabling `debug` mode (limits dataset to 50 images), reducing `epochs` to 1, reducing `num_folds` to 2, and swapping the complex ensemble models for a single lightweight `resnet18` to ensure the script runs quickly (under 1 hour).
3.  **Data Verification**: Call `prepare_data` to generate the processed dataframes and verify their structure and content using assertions.
4.  **DataLoader Verification**: Instantiate DataLoaders using `get_dataloaders` and fetch a single batch to verify tensor shapes and data types.
5.  **Model Verification**: Instantiate the `AppleDiseaseModel` and perform a dummy forward pass to ensure the architecture produces the correct output shape.
6.  **Training Loop**: Execute `run_fold` for the configured folds (0 and 1). This tests the training engine, loss calculation, backpropagation, and model checkpointing.
7.  **Stacking Pipeline**: Initialize the `StackingPipeline` and call `generate_submission`. This tests the generation of Out-Of-Fold (OOF) predictions, the training of the meta-learner (Logistic Regression), and the inference on the test set.
8.  **Result Validation**: Check for the existence of the final `submission.csv`, verify its column structure, row count, and that probability predictions sum to 1.0.
