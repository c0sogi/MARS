Based on the comprehensive analysis of previous experiments and lessons learned, I propose the **Attention-Pooled Hybrid EfficientNet** architecture.

This strategy introduces a structural innovation in how the Convolutional Neural Network (CNN) aggregates features. Previous iterations used Global Average Pooling (GAP), which indiscriminately averages the signal over the entire 10-minute window. Since seismic precursors (tremors) are often transient and sparse (lasting seconds to minutes), GAP dilutes these critical signals with the background noise of the inactive periods. The proposed **Gated Attention Pooling** mechanism allows the model to dynamically learn *where* (in time and frequency) the relevant signal exists and weight it accordingly, treating the feature map as a "bag of textures" rather than a single static image.

### Model
The architecture is a dual-branch network designed to fuse high-resolution textural information with robust global statistics:

1.  **Branch 1: Spectrogram Encoder with Attention Pooling**
    *   **Backbone:** **EfficientNet-B0**. This replaces the ResNet18 used previously. EfficientNet's MBConv blocks are highly effective at capturing local texture dependencies, and the architecture is more parameter-efficient.
    *   **Input Adaptation:** The first convolutional layer will be modified to accept **10 input channels** (one per sensor). We will initialize this layer by averaging the pre-trained ImageNet weights across the RGB dimension and replicating them 10 times to preserve learned spatial filters **Cite solution_lesson_node_00009**.
    *   **Structural Innovation (Gated Attention Pooling)**: Instead of the standard Global Average Pooling layer at the end of the backbone, we will implement a **Gated Attention mechanism** (inspired by Multiple Instance Learning).
        *   The final feature map of shape $(C, H, W)$ is flattened into a sequence of $H \times W$ feature vectors.
        *   A small dense layer computes a learnable "attention score" ($a_i \in [0, 1]$) for each vector, effectively creating a heat map of importance over the time-frequency grid.
        *   The final embedding is the weighted sum of the feature vectors: $E = \sum a_i v_i$. This allows the model to "attend" specifically to high-energy tremor textures and ignore the silence/noise that dominates the 10-minute window, addressing the resolution/texture insights from **Cite solution_lesson_node_00011**.
2.  **Branch 2: Statistical MLP**
    *   **Input:** A vector of engineered statistics: Mean, Std, Skew, Kurtosis, Quantiles (5%, 25%, 50%, 75%, 95%), and **NaN counts** (to capture sensor reliability) for all 10 sensors.
    *   **Architecture:** A Multi-Layer Perceptron (Dense $\rightarrow$ BN $\rightarrow$ ReLU $\rightarrow$ Dropout). This branch is retained to preserve explicit access to global signal magnitudes and data quality metrics **Cite solution_lesson_node_00006**.
3.  **Fusion Head:**
    *   The Attention-weighted embedding from the EfficientNet and the output of the MLP are concatenated.
    *   A final regression block predicts the scaled target value.

### Data
1.  **Preprocessing**:
    *   **Handling Missing Data**: Fill `NaN` values in the raw sensor data with **zeros**. Do not use linear interpolation, as it creates artificial ramps that manifest as false low-frequency energy in spectrograms **Cite solution_lesson_node_00012**.
    *   **Spectrogram Generation**: Generate Log-Mel Spectrograms with **high resolution**:
        *   **Mel Bins:** 128 (to capture fine spectral details).
        *   **Scaling:** Apply **`AmplitudeToDB`** (with `top_db=80`) instead of raw log. This normalizes the dynamic range relative to the peak, ensuring the model focuses on signal structure rather than absolute gain **Cite solution_lesson_node_00013**.
    *   **Target Scaling**: Apply **StandardScaler** to the `time_to_eruption` target variable to resolve convergence issues caused by large magnitudes **Cite solution_lesson_node_00001**.
2.  **Augmentation**:
    *   Apply **SpecAugment** (Time and Frequency Masking) **conservatively**. Use small mask parameters (e.g., masking <15% of the spectrum) to improve generalization without destroying contiguous seismic artifacts **Cite solution_lesson_node_00007** **Cite solution_lesson_node_00008**.

### Training
*   **Loss Function**: Mean Absolute Error (MAE) on the scaled target.
*   **Optimizer**: AdamW with weight decay.
*   **Strategy**:
    *   **Initialization**: Initialize the EfficientNet backbone with ImageNet weights (adapted for 10 channels) **Cite solution_lesson_node_00009**.
    *   **Patience**: Set Early Stopping patience to **15-20 epochs**. This allows the optimizer to navigate the noisy validation landscape and escape local minima, which is critical for regression on stochastic signals **Cite solution_lesson_node_00003**.

### Evaluation
1.  **Inference**: Generate 128-bin spectrograms (zero-filled) and statistical features for the test set.
2.  **Prediction**: Pass inputs through the trained Attention-Pooled Hybrid model.
3.  **Inverse Scaling**: Apply the inverse transform (multiply by training std, add training mean) to the model outputs to restore the `time_to_eruption` to its original scale.
4.  **Submission**: Format the `segment_id` and restored predictions into the required CSV file.
