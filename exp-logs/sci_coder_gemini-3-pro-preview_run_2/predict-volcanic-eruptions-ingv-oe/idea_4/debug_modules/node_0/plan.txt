Implementation Strategy:
1.  **Environment Setup**: Import necessary standard libraries and the provided library modules. Set the random seed using `seed_everything` to ensure reproducibility.
2.  **Configuration Override**: To ensure the demonstration runs quickly, I will override the default `Config` parameters. I will point the metadata paths to temporary "mini" CSV files (created by sampling the original metadata) and reduce the number of epochs and batch size.
3.  **Data Preparation**: Create small subsets of the training, validation, and test metadata (e.g., 20 rows each) and save them to the working directory. This prevents the feature engineering step from processing the entire dataset, drastically reducing runtime.
4.  **Component Verification**:
    *   **Utils**: Verify `TargetScaler` logic (fit, save, load, transform, inverse_transform) using dummy data.
    *   **Dataset**: Instantiate `VolcanoDataset` with the mini metadata. Verify the shape and types of the yielded dictionary (spectrogram, features, target).
    *   **Model**: Instantiate `AttentionPooledHybridEfficientNet`. Pass a dummy batch of tensors matching the dataset output shapes to verify the forward pass and output dimensions.
5.  **Pipeline Execution**:
    *   **Training**: Execute `run_training` for 1 epoch using the mini datasets. Verify that the model checkpoint is saved.
    *   **Inference**: Execute `generate_predictions` using the mini test set. Verify that the submission file is generated and follows the correct format.
6.  **Cleanup**: Leave the generated files in the `./working` directory as per instructions, but ensure no side effects occurred in `./input`.
