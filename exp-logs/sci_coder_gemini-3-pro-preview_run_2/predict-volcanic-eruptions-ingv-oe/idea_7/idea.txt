Based on the lessons learned from previous experiments, I propose the **Spectrally-Enhanced SE-ResNet Hybrid** architecture.

This strategy introduces a structural evolution by integrating **Squeeze-and-Excitation (SE)** dynamics directly into the ResNet backbone. This addresses the need for channel-adaptive modeling (identified in the EfficientNet experiment) while retaining the robust correlation capturing capabilities of standard convolutions (identified in the ResNet vs. EfficientNet comparison). Furthermore, it expands the tabular branch with explicit **frequency-domain statistics**, ensuring the high-SNR MLP branch has access to spectral summaries that might be subtle in the visual spectrogram representation.

### Model
The architecture is a dual-branch network designed to fuse channel-aware visual feature extraction with a domain-enriched statistical encoder:

1.  **Branch 1: SE-ResNet18 Spectrogram Encoder**
    *   **Backbone:** **SE-ResNet18**. We will modify the standard ResNet18 architecture by inserting a **Squeeze-and-Excitation (SE)** block after each residual unit.
        *   **Mechanism:** The SE block explicitly models the interdependencies between the 10 seismic sensors by learning a weight vector that recalibrates channel feature responses. This allows the network to selectively emphasize informative sensors and suppress noise **Cite solution_lesson_node_00006**.
        *   **Advantage:** Unlike EfficientNet (which uses depthwise separable convolutions that decouple spatial and channel information, leading to performance degradation **Cite solution_lesson_node_00025**), the SE-ResNet retains **standard convolutions** to capture inter-sensor correlations while adding the necessary channel adaptivity.
    *   **Pooling:** Use **Global Average Pooling (GAP)** to aggregate the feature maps, as the target variable represents a cumulative global state **Cite solution_lesson_node_00015**.
    *   **Initialization:** Initialize the convolutional layers with **ImageNet weights**. Adapt the first layer to 10 channels by averaging and replicating the RGB weights **Cite solution_lesson_node_00009**.

2.  **Branch 2: Spectrally-Enriched MLP**
    *   **Input:** A comprehensive vector of engineered statistics.
        *   **Time-Domain:** Mean, Std, Skew, Kurtosis, Quantiles (5%, 25%, 50%, 75%, 95%), and NaN counts **Cite solution_lesson_node_00013**.
        *   **Frequency-Domain (New):** Explicitly calculate **Spectral Centroid**, **Spectral Bandwidth**, and **Dominant Frequency** for each sensor from the raw signal. This ensures the MLP branch—which has high Signal-to-Noise Ratio—is not blind to global spectral properties, reinforcing the visual features extracted by the CNN.
    *   **Architecture:** A **Wide Multi-Layer Perceptron** (e.g., Hidden Dim 256 $\to$ 128). We explicitly maintain high capacity in this branch to avoid the information bottleneck observed when the MLP was under-parameterized **Cite solution_lesson_node_00026**.

3.  **Fusion Head:**
    *   Concatenate the GAP output from the SE-ResNet and the output of the MLP.
    *   Pass through a final regression block to predict the scaled target.

### Data
1.  **Preprocessing:**
    *   **Imputation:** Fill `NaN` values in the raw sensor data with **zeros**. Do not use linear interpolation **Cite solution_lesson_node_00012**.
    *   **Spectrogram Generation:**
        *   **Configuration:** Generate Log-Mel Spectrograms with **`n_mels=128`** to ensure sufficient frequency resolution **Cite solution_lesson_node_00013**. Use a single optimized view (e.g., `n_fft=1024`, `hop_length=256`) rather than multi-view stacking **Cite solution_lesson_node_00019**.
        *   **Normalization:** Apply **Slaney Area Normalization** (`norm='slaney'`) to the Mel filterbanks. This is critical to prevent high-frequency noise from dominating the feature map **Cite solution_lesson_node_00027**.
        *   **Scaling:** Apply **`AmplitudeToDB(top_db=80)`** to normalize the dynamic range **Cite solution_lesson_node_00013**.
    *   **Target Scaling:** Apply **StandardScaler** (subtract mean, divide by std) to the `time_to_eruption` target **Cite solution_lesson_node_00001**.

2.  **Augmentation:**
    *   Apply **SpecAugment** (Time and Frequency Masking) to the spectrograms.
    *   **Constraint:** Keep masking parameters **conservative** (e.g., mask <15% of the spectrum) to preserve contiguous signal structures **Cite solution_lesson_node_00008**.

### Training
*   **Loss Function:** Mean Absolute Error (MAE) on the scaled target.
*   **Optimizer:** **AdamW** with weight decay.
*   **Scheduler:** Implement **`ReduceLROnPlateau`**. This is mandatory to fine-tune weights and achieve high precision in the final epochs **Cite solution_lesson_node_00017**.
*   **Patience:** Set Early Stopping patience to **20 epochs** to allow the model to navigate the noisy validation landscape **Cite solution_lesson_node_00003**.

### Evaluation
1.  **Inference:**
    *   For each test segment, generate the zero-filled, Slaney-normalized, dB-scaled spectrogram.
    *   Compute the full set of Time-Domain and Frequency-Domain statistical features.
2.  **Prediction:** Pass inputs through the trained SE-ResNet Hybrid model to obtain the scaled prediction.
3.  **Inverse Scaling:** Apply the inverse transform (multiply by training std, add training mean) to restore the `time_to_eruption` to its original scale.
4.  **Submission:** Format the `segment_id` and restored predictions into the required CSV file.
