The following is an outline of the implementation strategy:

1.  **Setup and Directory Preparation**: Initialize the random state and ensure the output directory (`./metadata`) exists.
2.  **Process Training Data**:
    *   Load the provided `input/train.csv` which contains segment IDs and target labels (`time_to_eruption`).
    *   Construct relative file paths for each segment (e.g., `train/{segment_id}.csv`).
    *   **Stratified Split**: Since this is a regression task, create a temporary binning of the continuous target variable (`time_to_eruption`) to allow for stratified sampling. This ensures the validation set has a representative distribution of eruption times.
    *   Split the data into training (80%) and validation (20%) sets using `train_test_split` with the bins as the stratification key and a fixed random seed.
    *   Save the resulting dataframes to `metadata/train.csv` and `metadata/val.csv`.
3.  **Process Test Data**:
    *   List all CSV files in the `input/test/` directory.
    *   Extract `segment_id` from the filenames.
    *   Construct relative file paths.
    *   Save the test metadata to `metadata/test.csv`.
4.  **Verification**:
    *   **Load Metadata**: Read the newly created files back into memory.
    *   **Statistics**: Print counts and distribution statistics.
    *   **File Existence Check**: Randomly sample 1000 paths from each dataset and verify that the files actually exist in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
    *   **Split Validation**: Verify that the split ratio is approximately 80:20 and that the distribution of targets in the validation set matches the training set (using the Kolmogorov-Smirnov test or simple statistical comparison).
