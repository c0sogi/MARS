To establish a robust and highly efficient baseline for detecting catheters and lines, I propose using a **ResNet-18** architecture. This approach prioritizes training speed and architectural simplicity, distinguishing it from the more complex EfficientNetV2 and Transformer-based models listed previously, while offering a fully end-to-end trainable solution unlike the frozen-backbone hybrid approaches.

# Model
The core of the solution is the **ResNet-18** architecture, a lightweight convolutional neural network characterized by its use of residual skip connections and standard 3x3 convolutions. Unlike the EfficientNetV2 (Model 1) which relies on complex MBConv blocks and compound scaling, or the Swin Transformer (Model 2) which uses attention mechanisms, ResNet-18 offers a straightforward, low-latency design with significantly fewer parameters.
*   **Backbone:** We will utilize a ResNet-18 backbone pre-trained on ImageNet to leverage learned feature extractors.
*   **Head:** The original fully connected layer will be removed and replaced with a Global Average Pooling layer followed by a single dense linear layer with 11 output neurons (matching the number of target classes).
*   **Activation:** A Sigmoid activation function will be applied to the outputs to generate independent probabilities for each class.

# Data
*   **Preprocessing:** All chest x-rays will be resized to a fixed resolution of **512x512** pixels. This resolution is chosen as a baseline trade-off: it is high enough to retain visibility of thin catheter lines (which might be lost at 224x224) but small enough to allow for large batch sizes and rapid epoch times compared to the original 2k+ resolution.
*   **Normalization:** Images will be normalized using the standard ImageNet mean and standard deviation values to align with the pre-trained weights.
*   **Augmentation:** To maintain the "lightweight" philosophy and avoid CPU bottlenecks, we will apply only minimal augmentations: random horizontal flips and slight random rotations (e.g., +/- 10 degrees).

# Training
*   **Loss Function:** We will use **Binary Cross-Entropy with Logits Loss** (`BCEWithLogitsLoss`). This is the standard loss for multi-label classification tasks and is numerically stable.
*   **Optimizer:** The **AdamW** optimizer will be employed for its ability to handle sparse gradients and decouple weight decay, often leading to faster convergence than standard SGD.
*   **Strategy:** Training will proceed for a fixed, low number of epochs (e.g., 10-15) utilizing a **One-Cycle Learning Rate Policy**. This scheduler rapidly increases the learning rate to a maximum value and then decays it, allowing the model to super-converge quickly within the limited runtime.
*   **Precision:** Automatic Mixed Precision (AMP) will be enabled to reduce memory usage and speed up computations on the A100 GPU.

# Evaluation
*   **Inference:** For the test set, images will be resized to the same 512x512 resolution used in training.
*   **Prediction:** The model will perform a single forward pass per image (no Test Time Augmentation) to generate the raw logits.
*   **Post-processing:** The Sigmoid function will be applied to the logits to produce the final probability scores for submission. These scores will be saved directly to the submission file format.
