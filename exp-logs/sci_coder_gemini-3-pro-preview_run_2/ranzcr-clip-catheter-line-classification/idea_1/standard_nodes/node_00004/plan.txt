I will optimize the catheter detection pipeline by upgrading the model architecture and input resolution, while also enhancing the data augmentation strategy.

**Strategy:**
1.  **Upgrade Architecture**: Replace the ResNet18 backbone with **ResNet34**. The failure analysis indicates correlation between errors and specific classes, suggesting the smaller model might be underfitting the complexity of 11 distinct labels. ResNet34 offers a better balance of capacity and speed for this task.
2.  **Increase Resolution**: Increase the input image size from 512x512 to **640x640**. Catheters are thin, linear structures; higher resolution helps the model resolve these fine details, especially after the aspect-ratio preserving resize (Cite `solution_lesson_node_00001`).
3.  **Enhance Contrast**: Add **CLAHE** (Contrast Limited Adaptive Histogram Equalization) to the training augmentations. X-ray images often have low local contrast, making tubes difficult to distinguish from soft tissue. CLAHE improves local contrast, helping the model identify these features.
4.  **Refactor**: Rename the model class to `CatheterModel` to reflect the architecture change and update all references in the codebase.
5.  **Update Threshold**: Raise the submission generation threshold to the previous best validation score (`0.93029...`) to ensure we only submit improved models.
