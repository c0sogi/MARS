Here is the implementation strategy and the complete Python script.

### Implementation Strategy

1.  **Setup & Imports**: Import the necessary standard libraries (`os`, `numpy`, `pandas`, `torch`, `cv2`, `scikit-learn`, `scipy`) and the required components from the provided `library` modules (`Config`, `fit`, `create_submission`, `get_dataloaders`, `ResNet18Model`, `set_seed`).
2.  **Training**: Execute the `fit` function from `library.trainer`. To ensure a "fast baseline" as requested, I will limit the training to **5 epochs** while using the full dataset (`debug=False`). This balances speed with enough data to learn meaningful features.
3.  **Validation & Metric**:
    *   Load the trained model (`best_model.pth`) and the validation data loader.
    *   Perform inference on the validation set in evaluation mode.
    *   Calculate the Area Under the ROC Curve (AUC) for each label and compute the average.
    *   Print the result strictly in the format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the **Mean Absolute Error (MAE)** per sample between the model's predicted probabilities and the ground truth labels.
    *   **Correlation with Labels**: Calculate the Pearson correlation between the per-sample MAE and the presence of each target label to identify difficult classes.
    *   **Correlation with Image Features**: To analyze input features, sample a subset (e.g., 1000 images) of the validation set, extract basic image statistics (Width, Height, Aspect Ratio) using OpenCV, and correlate these with the error magnitude.
5.  **Submission**: Call `create_submission` from `library.inference` to generate predictions for the test set and save the `submission.csv` file.
6.  **Reproducibility**: Set the random seed at the start using `set_seed`.
