Implementation Strategy:
1.  **Setup & Config**: Initialize the environment and set random seeds using `library.training.set_seed`. I will override `config.EPOCHS` to 10 to ensures the pipeline completes quickly (fast baseline) while still allowing sufficient convergence for the MLP on the tracking data.
2.  **Training**: Execute the training pipeline using `library.training.train()`. This function manages the data loading, training loop with weighted Binary Cross Entropy loss (to handle class imbalance), and early stopping. It saves the best model checkpoint to disk and returns the optimal decision threshold.
3.  **Validation & Metrics**:
    *   Load the validation dataset using `library.dataset.NFLContactDataset`.
    *   Load the saved best model checkpoint from `config.MODEL_SAVE_PATH`.
    *   Perform inference on the validation set to generate probability scores.
    *   Compute the **Matthews Correlation Coefficient (MCC)** using the optimal threshold and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the absolute error magnitude (`|y_true - y_prob|`) for every validation sample.
    *   Retrieve feature names by accessing the dataframe from `library.feature_engineering`.
    *   Compute the Pearson correlation between the error magnitude and each input feature to identify which kinematic variables (e.g., relative speed, distance) are most associated with model failure.
    *   Print the top 10 correlated features.
5.  **Submission**: Call `library.training.predict()` with the optimal threshold. This function loads the test set, generates predictions, applies the threshold, and saves the final `submission.csv` to the submission directory.
