### Implementation Strategy

1.  **Configuration Setup**: We will override specific `Config` attributes (directories, batch size, epochs) to ensure the script runs quickly and writes temporary outputs to a dedicated `./working/demo` directory.
2.  **Data Subsetting**: Instead of processing the full dataset, we will load a small fraction of the training metadata and tracking data. This ensures the feature engineering pipeline completes in seconds rather than minutes.
3.  **Feature Engineering Demonstration**: We will call `prepare_wide_dataset` from `library.feature_engineering` on the subset. We will verify the output shapes, the existence of generated lag features, and the correctness of ground physics imputation using assertions.
4.  **Model & DataLoader Demonstration**: We will instantiate the `ContactDataset` and `get_dataloader` from `library.dataset`. We will then initialize the `WideResNetMLP` model and `FocalLoss`. We will verify the forward pass and loss calculation on a single batch.
5.  **Training Loop Simulation**: We will manually execute a minimal training loop (similar to `Trainer.train_one_epoch`) for a few iterations to verify backpropagation and optimizer steps.
6.  **Inference Demonstration**: We will simulate the test phase by processing a subset of test metadata, generating features, and running a forward pass to produce predictions.
