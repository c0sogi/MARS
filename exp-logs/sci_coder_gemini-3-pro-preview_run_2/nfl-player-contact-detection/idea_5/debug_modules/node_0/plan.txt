### Implementation Strategy

1.  **Configuration Setup**: We will import the `Config` class and override specific paths and hyperparameters (e.g., `EPOCHS`, `METADATA_DIR`, `WORKING_DIR`) to ensure the script runs quickly and uses a temporary workspace.
2.  **Data Subsetting**: To demonstrate the pipeline without processing the entire dataset, we will create a subset of the provided metadata (containing only one unique `game_play`) and save it to a temporary directory. This forces the data processing pipeline to work on a tiny slice of data.
3.  **Data Processing & Loading**: We will use `library.data_loader.prepare_data` to generate features and create PyTorch Datasets. We will verify the integrity of the generated data (shapes, non-null values).
4.  **Model Initialization**: We will instantiate the `CFTCN` model from `library.architecture` and the `FocalLoss` from `library.losses`. We will perform a dummy forward pass to verify tensor shapes match the architecture.
5.  **Training Loop**: We will execute the training process using `library.engine.fit` for a minimal number of epochs.
6.  **Inference**: We will simulate the inference phase using `library.engine.inference` on a subset of test data and verify the generation of the submission file.
7.  **Cleanup**: Temporary files in the working directory are left as is (allowed by instructions), but the script is designed to be self-contained.
