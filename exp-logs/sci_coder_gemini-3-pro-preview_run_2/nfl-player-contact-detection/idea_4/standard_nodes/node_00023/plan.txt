Implementation strategy:
1.  **Setup & Configuration**: Initialize random seeds and detect the computing device (GPU) to ensure reproducibility and performance.
2.  **Data Processing**:
    *   Load pre-processed training, validation, and test dataframes using `library.data_utils`.
    *   **Subsampling**: To satisfy the "Fast Baseline" requirement, randomly subsample the training dataset to 200,000 samples. This ensures the training completes quickly while maintaining the approximate class distribution.
    *   **Scaling**: Apply standard scaling to the features. Fit the scaler on the training subset and transform validation and test sets.
3.  **Dataset Construction**: Wrap the processed arrays into `ContactDataset` objects and create PyTorch `DataLoader`s. Crucially, set `shuffle=False` for validation and test loaders to preserve alignment for analysis and submission.
4.  **Model Training**:
    *   Initialize the `WITRGN` model from `library.model`.
    *   Train the model using `library.train_utils.train_model` for a reduced number of epochs (5) to meet time constraints.
5.  **Validation & Optimization**:
    *   Optimize the decision threshold on the validation set to maximize the Matthews Correlation Coefficient (MCC).
    *   Compute and print the **Final Validation Metric** on the full hold-out validation set.
6.  **Failure Analysis**:
    *   Calculate the absolute error between predicted probabilities and ground truth on the validation set.
    *   Compute correlations between this error and key input features (e.g., distance, speed) to identify sources of model failure.
7.  **Submission**:
    *   Compare the Final Validation MCC against the target threshold (0.62458462731896).
    *   If the model performs sufficiently well, generate the `submission.csv` using the optimized threshold.
