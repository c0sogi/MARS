# Proposed Solution: Wide-Input Time-Resolved Gated Network (WI-TRGN)

### Model
The proposed architecture, the **Wide-Input Time-Resolved Gated Network (WI-TRGN)**, synthesizes the robustness of the baseline MLP with the temporal feature extraction of a CNN, while explicitly solving the "Ground vs. Player" physical distinction.

1.  **Wide-Input Reshaping:** The model accepts a **flattened wide feature vector** (e.g., size $11 \times N_{features}$) as input. Inside the model `forward` pass, this vector is reshaped into a temporal tensor of shape $(Batch, Channels, Window\_Size)$. This structural choice bypasses the data pipeline failures associated with vertical expansion (Cite Lesson 15) while enabling convolutional processing.
2.  **Time-Resolved Convolutional Encoder:** The reshaped tensor is passed through a stack of **1D Convolutional Layers** with Residual Connections and `padding='same'`.
    *   **No Global Pooling:** Crucially, we strictly **exclude Global Pooling layers** (Cite Lesson 11). This preserves the temporal dimension, allowing the network to retain the "center frame" context (identifying *when* contact happens, not just *if* it happens).
    *   **Flattening:** The output of the convolutional stack is flattened back into a vector. This allows the subsequent dense layers to learn position-specific weights (e.g., weighting the center frame features higher than the edges).
3.  **Gated Dual-Head Output:** The dense section splits into two independent heads to address the high error rate on ground contacts (Cite Lesson 2):
    *   **Player Interaction Head:** Learns momentum transfer patterns between two players.
    *   **Ground Interaction Head:** Learns sudden deceleration and vertical drop patterns.
    *   **Hard Gating:** The final logit is computed as: $Logit = Logit_{player} \cdot (1 - I_{ground}) + Logit_{ground} \cdot I_{ground}$, where $I_{ground}$ is the binary input feature indicating if the second "player" is the ground.

### Data
The data pipeline prioritizes numerical stability and alignment integrity, leveraging the "Wide Format" strategy.

1.  **Vectorized Lag Construction:** We construct the temporal window (e.g., $t-5$ to $t+5$) using **vectorized `shift()` operations** on the dataframe. We explicitly reject vertical expansion (repeating rows) to avoid the alignment failures and NaN generation observed in previous attempts (Cite Lesson 15).
2.  **Feature Engineering:**
    *   **Logarithmic Distance:** Apply `np.log1p(distance)` to expand feature resolution near the contact boundary (Cite Lesson 5).
    *   **Clamped Closing Speed:** Calculate the closing speed using a **clamped denominator** (e.g., `max(distance, 1e-6)`) to prevent gradient instability at the singularity where distance approaches zero (Cite Lesson 7).
    *   **Raw Kinematics:** Include raw speed, acceleration, and orientation for each step in the window, allowing the 1D-CNN to learn higher-order derivatives (jerk) internally.

### Training
The training strategy focuses on handling the extreme class imbalance without uncalibrating the model.

1.  **Loss Function:** Use **Weighted Binary Cross-Entropy Loss** with a static positive class weight approximating the inverse frequency (~72). We select this over Focal Loss, as empirical evidence suggests static weighting is more effective for this specific dataset's extreme imbalance (Cite Lesson 8).
2.  **Optimization:** Train using **AdamW** with a standard learning rate.
3.  **Regularization:** Use Early Stopping monitoring the **Validation MCC**.

### Evaluation
The evaluation pipeline includes a mandatory calibration step to address the probability shift caused by the weighted loss.

1.  **Threshold Optimization:** After training, perform a grid search on the **validation set** to determine the optimal decision threshold $T$ that maximizes the Matthews Correlation Coefficient (MCC). This compensates for the probability distribution shift toward 1.0 caused by the heavy positive class weights (Cite Lesson 2).
2.  **Inference:** Apply this optimized threshold $T$ to the test set predictions to generate the final binary submission.
