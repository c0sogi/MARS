Based on the accumulated lessons, specifically the proven superiority of **Residual-Visual Fusion** (Cite solution_lesson_node_00071) and the critical need for **Explicit Numerical Stability** when using context-aware features (Cite solution_lesson_node_00081), I propose the **Time-Distributed Stabilized Residual-Visual Network (TD-SRV-Net)**.

This solution represents a structural evolution from the "Flattened MLP" baseline. It introduces a **Time-Distributed Encoder** to learn shared, frame-level physical representations (e.g., "Impact State") before temporal aggregation. This enforces a consistent physics manifold across the window while retaining the strict temporal alignment required for the task, avoiding the pitfalls of Global Pooling (Cite solution_lesson_node_00011). Furthermore, it re-integrates **Entity Embeddings** under strict numerical clamping to capture role-based priors without destabilizing the network.

# Model
The architecture is a **Dual-Stream Network** fusing a Time-Distributed Kinematic backbone with a Visual Correction branch.

1.  **Kinematic Stream (Time-Distributed Backbone):**
    *   **Input:** A **flattened wide feature vector** of player tracking data (Window $t-5$ to $t+5$).
    *   **Input Clamping (Structural Correction):** A fixed, non-trainable layer immediately following the input that strictly clamps all continuous features to a pre-defined physical range (e.g., `[-100, 100]`). This guarantees that outliers in derivative features (like closing speed) cannot destabilize the gradients, specifically addressing the failure of previous context-aware attempts (Cite solution_lesson_node_00081).
    *   **Time-Distributed Encoder:** The clamped input is reshaped to $(Batch, Window\_Size, Features)$. A **Dense Residual Block** is applied independently to each time step (sharing weights across the window). This learns a consistent "Frame Embedding" for every moment in the window.
    *   **Flattening:** The sequence of Frame Embeddings is flattened into a single vector. This preserves the absolute temporal position of every frame, avoiding the alignment loss caused by Global Pooling (Cite solution_lesson_node_00011).
    *   **Context Fusion:** Learnable **Entity Embeddings** for categorical features (`position`, `team`) are concatenated with the flattened vector. This allows the model to learn role-specific priors (e.g., QBs avoid contact).
    *   **Temporal Aggregator:** A **Deep Residual MLP** processes the fused vector to capture temporal dynamics (e.g., "Approaching" vs. "Retreating").
    *   **Output:** A single scalar logit ($L_{kin}$).

2.  **Visual Stream (Shallow Correction):**
    *   **Input:** A **flattened wide feature vector** of helmet bounding box metrics, derived using a **Max-Pooling Selection Strategy** (Cite solution_lesson_node_00074).
    *   **Backbone:** A **Shallow MLP**. This prevents overfitting to the noisy visual proxy while capturing simple geometric rules (Cite solution_lesson_node_00071).
    *   **Output:** A single scalar logit ($L_{vis}$).

3.  **Residual Fusion:**
    *   **Operation:** $Logit_{final} = L_{kin} + \lambda \cdot L_{vis}$.
    *   **Logits-Only:** The final output is raw logits, strictly adhering to the requirement for numerically stable loss functions (Cite solution_lesson_node_00048).

# Data
The data pipeline synthesizes the "Entity-First" tracking approach with strict physical constraints and ground imputation rules.

1.  **Entity-First Feature Generation:** Generate lags and windowed features on the `player_tracking` dataframe **before** merging it with `train_labels`. This prevents O(N²) scaling errors (Cite solution_lesson_node_00045).
2.  **Explicit Numerical Stability:**
    *   **Pre-Clamping:** During feature engineering, explicitly clamp derived kinematic features (e.g., `closing_speed`) to match the model's clamping layer (Cite solution_lesson_node_00081).
    *   **Angular Continuity:** Use the **Shortest Arc** method (e.g., `min(|a-b|, 360-|a-b|)`) for relative angles to avoid manifold discontinuities (Cite solution_lesson_node_00076).
    *   **Resolution:** Apply `np.log1p(distance)` (Cite solution_lesson_node_00005) and `clamped_closing_speed` (Cite solution_lesson_node_00007).
3.  **Hybrid Ground Imputation:**
    *   **Kinematics:** Impute Ground Position = Player Position (Distance=0) and Ground Velocity = 0. This preserves the "Relative Motion" signal (Cite solution_lesson_node_00034).
    *   **Visuals:** For Ground interactions, set `Visual_IoU` to 0 but retain the **Player's Helmet Box Top** features to capture the "falling" visual signature (Cite solution_lesson_node_00071).
4.  **Visual Feature Selection:** Apply **Max-Pooling** per timestamp to select the single "best" view (largest box area) for each player, creating a dense feature vector (Cite solution_lesson_node_00074).
5.  **Normalization:** Apply **StandardScaler** to the final fused vector (Cite solution_lesson_node_00037).

# Training
The training strategy is optimized for stability and calibration on the full dataset.

1.  **Loss Function:** Use **Focal Loss** implemented via `BCEWithLogitsLoss`. Crucially, set `alpha=0.25` and `gamma=2.0`. This maintains the correct balance between negative suppression and positive signal conservation, correcting previous tuning errors (Cite solution_lesson_node_00077).
2.  **Full Dataset:** Train on the **entire training set** (3.4M rows). The efficient tabular architecture allows this within the compute budget, prioritizing data volume over architectural complexity (Cite solution_lesson_node_00023, solution_lesson_node_00075).
3.  **Optimizer:** Use **AdamW** with **Early Stopping** monitoring the Validation MCC.

# Evaluation
The evaluation pipeline includes a mandatory calibration step.

1.  **Threshold Optimization:** Post-training, perform a grid search on the **validation set** to find the decision threshold $T$ that maximizes the Matthews Correlation Coefficient (MCC). This aligns the decision boundary with the probability distribution (Cite solution_lesson_node_00002).
2.  **Inference:** Apply the optimized threshold $T$ to the test set predictions to generate the final binary submission.
