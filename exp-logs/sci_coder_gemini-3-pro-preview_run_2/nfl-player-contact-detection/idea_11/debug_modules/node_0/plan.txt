### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override specific parameters (e.g., `EPOCHS`, `DEBUG`, `WORK_DIR`) to ensure the demonstration runs quickly and uses a separate working directory.
2.  **Data Processing Verification**:
    *   Create synthetic tracking data to verify the `process_tracking_data` function, ensuring temporal lags are correctly computed.
    *   Create synthetic merged data to verify `impute_ground_and_engineer_features`, ensuring Ground ('G') entities inherit Player 1's position and have zero velocity, and that relative features (distance, speed) are calculated correctly.
3.  **Model Architecture Verification**:
    *   Instantiate the `ECGRN` model with dummy dimensions.
    *   Pass a random tensor through the model to confirm the forward pass works and output shapes are correct.
    *   Test the `FocalLoss` function with dummy predictions and targets.
4.  **Training Pipeline Integration**:
    *   Load a small subset of the real training data using `get_data(mode='train')` with `Config.DEBUG = True`.
    *   Manually execute the training components: `train_epoch`, `validate`, and `optimize_threshold` from `library.train`.
    *   Assert that the loss is a finite number and the optimized threshold is within valid bounds.
5.  **Inference Verification**:
    *   Load the test data using `get_data(mode='test')`.
    *   Perform a mock inference pass using the trained model to ensure the submission generation logic works.
6.  **Cleanup**: Remove the temporary working directory created for this demonstration.
