This script implements the end-to-end orchestration for the NFL Contact Detection task. It leverages the provided `ECGRN` model and data processing pipeline, optimizing for a fast baseline execution by subsampling the training data and limiting epochs, while ensuring rigorous validation on the full hold-out set.

**Implementation Strategy:**
1.  **Configuration & Setup:** Monkey-patch `Config` parameters to reduce epochs to 5 and increase batch size to 4096 for efficient A100 GPU utilization.
2.  **Data Loading:** Use `get_data(mode='train')` to load the dataset. Split into training and validation sets based on the `is_val` flag derived from the metadata.
3.  **Fast Baseline Optimization:** Subsample the training data to 1,000,000 samples to satisfy the runtime constraint while maintaining sufficient diversity for learning. The validation set is kept intact (full size) to ensure the metric is valid.
4.  **Training:** Train the `ECGRN` model using `FocalLoss` and `AdamW` for 5 epochs.
5.  **Validation & Threshold Optimization:** Evaluate the model on the full validation set. Perform a grid search to find the decision threshold that maximizes the Matthews Correlation Coefficient (MCC).
6.  **Failure Analysis:** Calculate and print the Pearson correlation between the model's absolute error and input features to identify sources of systematic failure.
7.  **Submission:** If the optimized validation MCC exceeds the target (0.62458462731896), generate predictions for the test set and save `submission.csv`.
