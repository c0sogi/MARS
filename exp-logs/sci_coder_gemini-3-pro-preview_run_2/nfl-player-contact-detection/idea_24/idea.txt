Based on the comprehensive analysis of previous attempts and the accumulated lessons, I propose the **Entity-Augmented Residual-Visual Network (EA-RVN)**.

This solution represents a structural evolution of the successful **Residual-Visual Fusion** architecture (RVC-Net). It integrates **Entity Embeddings** to capture role-based contact priors (e.g., a "Quarterback" avoids contact, a "Linebacker" seeks it) and introduces **Reliability Gating** to the fusion layer. Crucially, it re-implements these high-capacity components while strictly enforcing the **Numerical Stability** constraints that caused previous complex architectures (like Idea 22) to fail.

# Model
The architecture is a **Dual-Stream Network** that fuses a context-aware kinematic backbone with a gated visual correction branch.

1.  **Kinematic Stream (Context-Aware Backbone):**
    *   **Input:** A **flattened wide feature vector** of player tracking data (Window $t-5$ to $t+5$). This preserves the superior temporal alignment of the wide format (Cite solution_lesson_node_00015).
    *   **Entity Embeddings (Structural Re-introduction):** Unlike the baseline RVC-Net, we introduce learnable **Entity Embeddings** for categorical features (`position`, `team`). These are concatenated with the continuous kinematic features. This allows the model to learn role-specific physics (e.g., "WR vs DB" interactions differ from "OL vs DL"), addressing the context gap in pure kinematic models. We explicitly enable this by ensuring all accompanying continuous features are numerically bounded (Cite solution_lesson_node_00081).
    *   **Backbone:** A **Deep Residual MLP** (Linear $\to$ BatchNorm $\to$ ReLU $\to$ Dropout $\to$ Linear $\to$ Add). This provides the capacity to learn non-linear interactions between the embeddings and the kinematics (Cite solution_lesson_node_00059).
    *   **Output:** A single scalar logit ($L_{kin}$).

2.  **Visual Stream (Shallow Correction):**
    *   **Input:** A **flattened wide feature vector** of helmet bounding box metrics, derived using a **Max-Pooling Selection Strategy** (Cite solution_lesson_node_00074).
    *   **Backbone:** A **Shallow MLP**. This prevents overfitting to the noisy visual proxy while capturing simple geometric rules (Cite solution_lesson_node_00071).
    *   **Output:** A single scalar logit ($L_{vis}$).

3.  **Reliability-Gated Fusion (Structural Innovation):**
    *   Instead of a fixed additive residual ($L_{kin} + L_{vis}$), we implement **Reliability Gating**:
        $$L_{final} = L_{kin} + (L_{vis} \cdot \sigma(W_{gate} \cdot M_{vis}))$$
        where $M_{vis}$ represents visual metadata features (e.g., `view_available_flags`, `box_confidence_scores`).
    *   **Rationale:** This allows the network to dynamically "silence" the visual correction stream if the visual data is missing or low-quality, preventing noise injection while retaining the correction for high-confidence frames.
    *   **Logits-Only:** The final output is raw logits, strictly adhering to the requirement for numerically stable loss functions (Cite solution_lesson_node_00048).

# Data
The data pipeline synthesizes the "Entity-First" tracking approach with strict corrections for numerical stability, angular continuity, and ground physics.

1.  **Entity-First Feature Generation:** Generate lags and windowed features on the `player_tracking` dataframe **before** merging it with `train_labels`. This prevents O(N²) scaling errors (Cite solution_lesson_node_00045).
2.  **Explicit Numerical Stability (Correction):**
    *   **Clamping:** Explicitly clamp derived kinematic features (e.g., `closing_speed`) to a fixed range (e.g., `[-50, 50]`) or use robust scaling. This corrects the failure where unbounded derivative features destabilized the previous embedding-based attempt (Cite solution_lesson_node_00081).
    *   **Angular Continuity:** Use the **Shortest Arc** method (e.g., `min(|a-b|, 360-|a-b|)`) for relative angles. This corrects the feature discontinuity that degraded previous attempts (Cite solution_lesson_node_00076).
3.  **Hybrid Ground Imputation:**
    *   **Kinematics:** Impute Ground Position = Player Position (Distance=0) and Ground Velocity = 0. This preserves the "Relative Motion" signal (Cite solution_lesson_node_00034).
    *   **Visuals:** For Ground interactions, set `Visual_IoU` to 0 but retain the **Player's Helmet Box Top** features to capture the "falling" visual signature (Cite solution_lesson_node_00071).
4.  **Visual Feature Selection (Max-Pooling):** Apply a **Max-Pooling Strategy** per timestamp to select the single "best" view (largest box area) for each player. This creates a dense, consistent visual feature vector (Cite solution_lesson_node_00074).
5.  **Normalization:** Apply **StandardScaler** to the final fused vector (Cite solution_lesson_node_00037).

# Training
The training strategy is optimized for stability and calibration on the full dataset, correcting previous Focal Loss tuning errors.

1.  **Loss Function:** Use **Focal Loss** implemented via `BCEWithLogitsLoss`. Crucially, set `alpha=0.25` and `gamma=2.0`. This corrects the error of aggressively increasing `alpha` (to 0.75), ensuring the loss properly balances the suppression of easy negatives with the regularization of noisy labels (Cite solution_lesson_node_00077).
2.  **Full Dataset:** Train on the **entire training set** (3.4M rows). The efficient tabular architecture allows this within the compute budget, avoiding the performance degradation associated with subsampling (Cite solution_lesson_node_00023).
3.  **Optimizer:** Use **AdamW** with **Early Stopping** monitoring the Validation MCC.

# Evaluation
The evaluation pipeline includes a mandatory calibration step.

1.  **Threshold Optimization:** Post-training, perform a grid search on the **validation set** to find the decision threshold $T$ that maximizes the Matthews Correlation Coefficient (MCC). This aligns the decision boundary with the probability distribution (Cite solution_lesson_node_00002).
2.  **Inference:** Apply the optimized threshold $T$ to the test set predictions to generate the final binary submission.
