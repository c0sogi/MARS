Implementation Strategy:
1.  **Configuration Overrides**: To ensure the script runs quickly (within the time limit) and is self-contained, I will override specific configuration variables (e.g., `EPOCHS`, `WORKING_DIR`) by modifying the imported module attributes directly. This redirects output to a demo directory and limits the training duration to 1 epoch.
2.  **Data Subsetting via Monkey-Patching**: Since the library functions load the full dataset by default, I will use `unittest.mock.patch` to wrap `pandas.read_csv`. This wrapper will intercept calls to read the metadata CSV files and enforce an `nrows` limit (e.g., 2000 rows). This ensures the data processing pipeline only loads and processes a tiny fraction of the data, significantly speeding up execution while still verifying the entire pipeline logic.
3.  **Pipeline Execution**:
    *   Initialize the random seed for reproducibility.
    *   Call `library.dataset.get_dataloaders` to generate training, validation, and test loaders from the subsetted data.
    *   Instantiate the `EARVN` model using the input dimensions derived from the data.
    *   Execute `library.trainer.train_model` to run the training loop, validation, and inference.
4.  **Verification**: After execution, I will assert the existence and validity of the generated submission file and model artifacts to confirm the task was completed successfully.
