The `runfile.py` script fails with an `AssertionError` because it attempts to verify the creation of cache files (`train_features.parquet`, etc.) after running `prepare_data` in debug mode. However, the `prepare_data` function in `library/data_processing.py` contains logic (`if not debug:`) that explicitly prevents saving files when `debug=True` to avoid overwriting production cache with debug data.

To fix this while preserving the safety mechanism for standard runs, I will:
1.  Update `prepare_data` in `library/data_processing.py` to accept a `force_save` argument, allowing callers to override the debug-save restriction.
2.  Update `runfile.py` to call `prepare_data` with `force_save=True`, enabling the demo to verify that cache files are correctly generated.
