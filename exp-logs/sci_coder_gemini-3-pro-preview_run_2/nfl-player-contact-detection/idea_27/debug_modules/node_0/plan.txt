The following script demonstrates the end-to-end workflow using the provided library. It begins by initializing the data processor in debug mode to generate features from a subset of the data. It then verifies the data loading pipeline, trains the `SEARVN` model using the `train_model` orchestrator, optimizes the decision threshold on the validation set, and finally generates a submission file. Assertions are included at key steps to validate tensor shapes, file existence, and data integrity.
