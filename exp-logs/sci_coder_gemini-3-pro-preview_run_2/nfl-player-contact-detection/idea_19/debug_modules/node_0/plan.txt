The following script demonstrates the end-to-end usage of the provided library modules for the football contact detection task. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters (epochs, batch size, directories) to ensure the demo runs quickly and uses a temporary working directory.
2.  **Data Subsetting**: Creates a small subset of the metadata (containing only one game play per split) to significantly reduce processing time while maintaining the pipeline's integrity.
3.  **Data Processing**: Uses `process_data` to generate kinematic and visual features from the raw tracking and helmet data. It verifies the output shapes against the expected dimensions.
4.  **Model Initialization**: Instantiates the `SRVNet` model and verifies the forward pass logic with a single batch.
5.  **Training**: Runs a single epoch of training and an evaluation step using `train_one_epoch` and `evaluate`, utilizing the `FocalLoss`.
6.  **Inference & Optimization**: Demonstrates the inference pipeline and the MCC threshold optimization utility.
