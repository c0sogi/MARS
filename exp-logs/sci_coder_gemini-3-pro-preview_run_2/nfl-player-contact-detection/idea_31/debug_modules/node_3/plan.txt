The error `ValueError: could not convert string to float: 'Endzone'` is caused by the inclusion of the string-based columns `view_1` and `view_2` in the set of continuous kinematic features (`kin_cols`). The `DataProcessor` defines `kin_cols` by excluding a specific set of metadata columns (`exclude_cols`) and visual columns (`vis_cols`) from the dataframe, assuming everything remaining is a numeric feature to be cast to `float32`. Since `view_1` and `view_2` (originating from the helmet data) were not explicitly excluded, the code attempted to convert strings like "Endzone" to floats, causing the crash (Cite debug_lesson_14). I will fix this by adding `"view_1"` and `"view_2"` to the `exclude_cols` set in `library/dataset.py`.
