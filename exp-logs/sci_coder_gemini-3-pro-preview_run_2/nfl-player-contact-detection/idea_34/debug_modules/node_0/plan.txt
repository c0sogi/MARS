To demonstrate the usage of the provided library files for the NFL Contact Detection task, I will implement a script that performs the following steps:

1.  **Environment Setup**: Configure a separate working directory and set random seeds for reproducibility.
2.  **Data Subsetting**: Create a small, consistent subset of the training data (metadata, tracking, and helmets) to ensure the demonstration runs quickly and respects the time limit.
3.  **Feature Generation**: Use `library.data_processing.generate_contact_features` to process the raw subset into kinematic and visual feature tensors, verifying the shapes and integrity of the output.
4.  **Model Initialization**: Instantiate the `PIRVNet` model from `library.model` and perform a dummy forward pass to verify architecture correctness.
5.  **Training Loop**: Initialize the `Trainer` from `library.train`, point it to the subset data, and execute a short training run (2 epochs) to demonstrate the fitting process and artifact saving.
6.  **Inference & Evaluation**: Load the trained model, perform inference on the validation subset, and calculate the Matthews Correlation Coefficient (MCC) using `library.utils.optimize_threshold`.
