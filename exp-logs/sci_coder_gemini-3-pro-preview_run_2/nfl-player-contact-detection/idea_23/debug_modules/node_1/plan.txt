The issue is that the `HELMET_COLS` list in `library/config.py` includes `"step"`, which is a derived feature calculated from the `"frame"` column and is not present in the raw `baseline_helmets.csv` files. This causes `pd.read_csv` to fail because it cannot find the `"step"` column in the source file. To fix this, I will remove `"step"` from `HELMET_COLS`. The `step` column is already correctly computed in `library/feature_engineering.py` immediately after loading the data (Cite debug_lesson_17).
