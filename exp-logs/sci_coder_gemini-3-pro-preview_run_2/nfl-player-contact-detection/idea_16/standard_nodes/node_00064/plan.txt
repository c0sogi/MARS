The implementation strategy is as follows:

1.  **Environment Setup**: Initialize random seeds using `seed_everything` for reproducibility and set the computation device (GPU/CPU) using `Config.DEVICE`.
2.  **Data Loading**: Instantiate `DataProcessor` to load training and validation data. To satisfy the "fast baseline" requirement, the training dataset is limited to 1,000,000 randomly sampled rows, while the full validation set is retained for accurate metrics. Data is wrapped in `ContactDataset` and `DataLoader` with pinned memory.
3.  **Model Training**: Execute the training loop using `train_model`, which handles epoch iterations, validation, focal loss calculation, and early stopping, returning the best-performing model.
4.  **Validation & Metrics**: Perform inference on the full validation set using the optimized threshold found during training. Calculate the Matthews Correlation Coefficient (MCC) and print it in the required format.
5.  **Failure Analysis**: Calculate the absolute error magnitude on the validation set and correlate it with key features (e.g., distance, speed) from the center frame to identify error patterns.
6.  **Submission**: If the final MCC exceeds the target threshold (`0.62458462731896`), generate predictions for the test set using the best model and threshold, and save the result to `./submission/submission.csv`.
