Based on the comprehensive analysis of the accumulated lessons, specifically the need for **Explicit Numerical Stability** (Cite solution_lesson_node_00081), the superiority of **Residual-Visual Fusion** (Cite solution_lesson_node_00071), and the potential for **Weight Sharing** to learn consistent physics across the temporal window without the alignment loss of Global Pooling (Cite solution_lesson_node_00011), I propose the **Time-Distributed Stabilized Residual Network (TD-SRN)**.

This solution represents a structural evolution from the "Flattened MLP" baseline. It introduces a **Time-Distributed Encoder** to learn shared, frame-level physical representations (e.g., "Impact Physics") before flattening, enforcing a consistent physics manifold across the window while retaining the strict temporal alignment required for the task.

# Model
The architecture is a **Dual-Stream Network** fusing a Time-Distributed Kinematic backbone with a Visual Correction branch.

1.  **Kinematic Stream (Time-Distributed Backbone):**
    *   **Input:** A **flattened wide feature vector** of player tracking data (Window $t-5$ to $t+5$).
    *   **Reshape & Clamp:** The input is reshaped to $(Batch, Window\_Size, Features)$. A fixed **Clamping Layer** restricts derived features (e.g., `closing_speed`) to bounded ranges (e.g., `[-50, 50]`). This prevents outliers from destabilizing the shared weights, addressing the failure of previous complex architectures (Cite solution_lesson_node_00081).
    *   **Time-Distributed Encoder:** A stack of **Dense Residual Blocks** applied independently to each time step (sharing weights across the window).
        *   *Rationale:* Unlike a standard MLP which must learn "Force=Mass$\times$Accel" separately for $t=0$ and $t=1$, this shared encoder learns a consistent physical state representation for every frame.
    *   **Flattening:** The output of the encoder is flattened into a single vector. This preserves the absolute temporal position of every frame, avoiding the alignment loss caused by Global Pooling in CNNs/TCNs (Cite solution_lesson_node_00011).
    *   **Temporal Aggregator:** A **Deep Residual MLP** processes the flattened vector to capture temporal dynamics (e.g., "Approaching" vs. "Retreating").
    *   **Entity Embeddings:** Embeddings for `position` and `team` are concatenated here to provide context (Cite solution_lesson_node_00081).

2.  **Visual Stream (Shallow Correction):**
    *   **Input:** A **flattened wide feature vector** of helmet bounding box metrics, derived using a **Max-Pooling Selection Strategy** (Cite solution_lesson_node_00074).
    *   **Backbone:** A **Shallow MLP** to capture simple geometric rules (e.g., "Zero IoU $\to$ No Contact") without overfitting (Cite solution_lesson_node_00071).

3.  **Residual Fusion:**
    *   **Operation:** $Logit_{final} = Logit_{kinematic} + \lambda \cdot Logit_{visual}$.
    *   **Logits-Only:** The final output is raw logits, strictly adhering to the requirement for numerically stable loss functions (Cite solution_lesson_node_00048).

# Data
The data pipeline synthesizes the "Entity-First" tracking approach with strict physical constraints.

1.  **Entity-First Feature Generation:** Generate lags and windowed features on the `player_tracking` dataframe **before** merging it with `train_labels`. This prevents O(N²) scaling errors (Cite solution_lesson_node_00045).
2.  **Explicit Numerical Stability:**
    *   **Clamping:** Explicitly clamp derived kinematic features during engineering to match the model's clamping layer (Cite solution_lesson_node_00081).
    *   **Angular Continuity:** Use the **Shortest Arc** method (e.g., `min(|a-b|, 360-|a-b|)`) for relative angles to avoid manifold discontinuities (Cite solution_lesson_node_00076).
    *   **Resolution:** Apply `np.log1p(distance)` (Cite solution_lesson_node_00005) and `clamped_closing_speed` (Cite solution_lesson_node_00007).
3.  **Hybrid Ground Imputation:**
    *   **Kinematics:** Impute Ground Position = Player Position (Distance=0) and Ground Velocity = 0. This preserves the "Relative Motion" signal (Cite solution_lesson_node_00034).
    *   **Visuals:** For Ground interactions, set `Visual_IoU` to 0 but retain the **Player's Helmet Box Top** features to capture the "falling" visual signature (Cite solution_lesson_node_00071).
4.  **Visual Feature Selection:** Apply **Max-Pooling** per timestamp to select the single "best" view (largest box area) for each player, creating a dense feature vector (Cite solution_lesson_node_00074).
5.  **Normalization:** Apply **StandardScaler** to the final fused vector (Cite solution_lesson_node_00037).

# Training
The training strategy is optimized for stability and calibration on the full dataset.

1.  **Loss Function:** Use **Focal Loss** implemented via `BCEWithLogitsLoss`. Crucially, set `alpha=0.25` and `gamma=2.0`. This maintains the correct balance between negative suppression and positive signal conservation (Cite solution_lesson_node_00077).
2.  **Full Dataset:** Train on the **entire training set** (3.4M rows). The efficient architecture allows this within the compute budget (Cite solution_lesson_node_00023).
3.  **Optimizer:** Use **AdamW** with **Early Stopping** monitoring the Validation MCC.

# Evaluation
1.  **Threshold Optimization:** Post-training, perform a grid search on the **validation set** to find the decision threshold $T$ that maximizes the Matthews Correlation Coefficient (MCC). This aligns the decision boundary with the probability distribution (Cite solution_lesson_node_00002).
2.  **Inference:** Apply the optimized threshold $T$ to the test set predictions to generate the final binary submission.
