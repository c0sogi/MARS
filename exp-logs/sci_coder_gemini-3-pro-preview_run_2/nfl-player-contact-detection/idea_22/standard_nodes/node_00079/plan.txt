This script orchestrates the training, evaluation, and submission process for the NFL Contact Detection task using the Enhanced Gated Residual-Visual Network (E-GRV-Net).

**Implementation Strategy:**
1.  **Setup & Reproducibility:** Initialize the environment and set random seeds to ensure consistent results.
2.  **Training:** Instantiate the `Trainer` class and execute the training loop using the full dataset. The training is capped at 10 epochs to ensure execution within the time limit while allowing sufficient convergence for the tabular architecture.
3.  **Validation & Metric Reporting:** Retrieve the best Matthews Correlation Coefficient (MCC) achieved during training. Print this metric in the strictly required format.
4.  **Failure Analysis:** Perform a post-hoc analysis on the validation set.
    *   Reload the validation dataset and generate probability predictions using the best trained model.
    *   Calculate the absolute error magnitude ($|y_{true} - y_{pred}|$).
    *   Extract key kinematic features (specifically `distance` and `speed` at the center time-lag $t=0$) from the feature tensors.
    *   Compute and print the Pearson correlation between the model's error and these physical features to identify failure modes (e.g., high error at specific distances).
5.  **Submission:** Compare the final validation metric against the threshold ($0.6634847318478787$). If the model performance exceeds this benchmark, generate predictions for the test set and save `submission.csv`.
