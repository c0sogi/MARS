Implementation Strategy:
1.  **Environment Setup**: Initialize random seeds for reproducibility using the provided `seed_everything` utility.
2.  **Data Subsetting**: To satisfy the "Optimize for Speed" requirement, create a "mini" dataset by sampling a few game plays from the provided metadata and filtering the corresponding tracking and helmet data. This ensures the pipeline runs in minutes rather than hours.
3.  **Configuration Override**: runtime-patch the `Config` class to point to the newly created mini-datasets and adjust training hyperparameters (e.g., 1 epoch, small batch size) to facilitate a quick demonstration.
4.  **Pipeline Execution**:
    *   Run `train_model(load_cached_data=False)`: This triggers the full data processing pipeline (`create_datasets`), initializes the `RVCNet` model, trains it using `FocalLoss`, and performs validation/threshold optimization.
    *   Run `generate_submission()`: This loads the best model and threshold to generate predictions for the test set.
5.  **Verification**: Perform assertions to verify that the model output shapes are correct, the submission file is generated, and the output format matches the requirements.
