This script demonstrates the usage of the provided machine learning pipeline components. It performs the following steps:
1.  **Configuration Override**: Patches the `Config` class to run in a lightweight "debug" mode (fewer epochs, limited samples, single seed) to ensure quick execution.
2.  **Utility Verification**: Validates the reproducibility of the seeding function and the correctness of the ROC AUC calculation metric.
3.  **Dataset Verification**: Instantiates the `CactusDataset`, verifies data loading, image transformations, and tensor shapes.
4.  **Model Verification**: Instantiates the `CustomSEResNet` model, performs a forward pass with dummy data, and validates output dimensions.
5.  **Training Pipeline**: Executes the `run_training` function to simulate a full training cycle on the debug subset and verifies that model checkpoints are saved.
6.  **Inference Pipeline**: Executes the `run_inference` function to generate predictions using the trained model and verifies the format of the submission file.
