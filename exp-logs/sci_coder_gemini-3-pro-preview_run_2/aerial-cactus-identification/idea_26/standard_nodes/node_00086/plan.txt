Implementation strategy:
1.  **Setup & Imports**: Import necessary libraries and the provided modules (`library.utils`, `library.model`, `library.dataset`, `library.engine`). Define configuration constants for a fast baseline (5 epochs, 5 seeds).
2.  **Data Loading**: Use `get_dataloaders` to load train, validation, and test sets. Extract validation targets and test IDs for later use.
3.  **Training Loop**: Iterate through 5 random seeds. For each seed:
    *   Initialize the `WideCoordinateResNeXt` model, optimizer (AdamW), and scheduler (CosineAnnealing).
    *   Train for 5 epochs using `train_one_epoch` and monitor performance with `evaluate`.
    *   Save the best model based on validation AUC.
    *   Reload the best model and perform inference on the validation set (for ensemble scoring) and the test set (using Test Time Augmentation via `predict_with_tta`).
4.  **Ensemble Aggregation**: Average the predictions from all 5 seeds for both validation and test sets.
5.  **Final Validation**: Compute the AUC score on the aggregated validation predictions and print it in the required format (`Final Validation Metric: <value>`).
6.  **Failure Analysis**:
    *   Calculate the absolute error between the ensemble validation predictions and the ground truth.
    *   Extract meta-features (brightness, contrast, channel means) from the validation images.
    *   Compute and print the correlation between the error magnitude and these features.
7.  **Submission**: Create the `submission.csv` file using the aggregated test predictions.
