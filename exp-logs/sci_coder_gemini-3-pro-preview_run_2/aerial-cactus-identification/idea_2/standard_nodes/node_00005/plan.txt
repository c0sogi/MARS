The implementation strategy involves the following steps:

1.  **Setup and Initialization**: Initialize the environment by setting random seeds for reproducibility and creating necessary directories using the provided `Config` class.
2.  **Data Loading**: Utilize the `get_dataloaders` function from the `library` to load the training, validation, and test datasets. We enable `load_cached_data=True` to speed up loading if pre-processed arrays exist.
3.  **Model Training**: Instantiate the `CactusResNet` model and move it to the GPU (A100). Train the model using the provided `train_model` function, which handles the training loop, validation monitoring, early stopping, and saving the best checkpoint. We adhere to the default 50 epochs as the dataset is small (32x32 images) and will train quickly on the available hardware.
4.  **Validation and Evaluation**:
    *   Load the best model checkpoint saved during training.
    *   Perform inference on the full validation set in evaluation mode (`torch.no_grad()`).
    *   Compute the Area Under the ROC Curve (AUC) score.
    *   Print the metric in the strictly required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Compute the absolute error magnitude (`|y_true - y_pred|`) for each validation sample.
    *   Extract simple image statistics (brightness, contrast, channel means) from the validation tensors.
    *   Calculate and print the Pearson correlation between these image features and the error magnitude to identify potential weaknesses.
6.  **Submission**:
    *   Compare the final validation AUC against the specified threshold (0.9997903583412834).
    *   If the metric exceeds the threshold, execute `predict_and_submit` to generate predictions on the test set using Test Time Augmentation (TTA) and save the `submission.csv`. Otherwise, skip submission.
