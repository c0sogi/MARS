2.  **Component Verification**:

    *   **Data**: Instantiate `get_dataloaders` in debug mode. Fetch a single batch to verify tensor shapes (Batch Size, Channels, Height, Width) and data types.

3.  **Pipeline Execution**:
    *   **Training**: Execute `run_training` with `debug=True`. This trains on a small subset of data for 1 epoch, ensuring the training loop, backward pass, and checkpoint saving mechanisms function correctly without consuming excessive time. Verify the model checkpoint is saved.
    *   **Inference**: Execute `run_inference` with `debug=False`. We use the full test set here because the library's `predict_and_submit` function expects the full metadata ID list. Since the test set is small (~3300 32x32 images) and we have a GPU, inference will be very fast. Verify the submission file is generated.
4.  **Result Validation**: Load the generated `submission.csv`, check for correct columns (`id`, `has_cactus`), value ranges (probabilities between 0 and 1), and non-empty content.
