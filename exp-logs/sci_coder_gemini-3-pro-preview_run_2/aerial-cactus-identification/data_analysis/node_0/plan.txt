The following script performs a comprehensive Exploratory Data Analysis (EDA) on the training dataset. It is designed to handle the specific requirements of the image classification task, ensuring data integrity by strictly using the metadata generated for the training split.

**Implementation Strategy:**
1.  **Setup & Configuration**: Define constants, paths, and seed the random number generators for reproducibility.
2.  **Data Loading**: Load the `train_metadata.csv` file to access the training set labels and file paths without touching the validation or test sets.
3.  **Target Variable Analysis**: Analyze the `has_cactus` column to report class distribution and imbalance ratios.
4.  **Image Data Analysis**:
    *   Iterate through the training images to extract physical properties (dimensions, channels) and pixel statistics.
    *   Load images into memory (feasible due to small 32x32 size) to compute global mean and standard deviation efficiently.
5.  **Meta-Feature Extraction & Relationship Analysis**:
    *   Extract interpretable meta-features from the images: Average Brightness, Channel-specific means (Red, Green, Blue), and Contrast (Standard Deviation).
    *   Analyze the relationship between these meta-features and the target variable (e.g., "Are cactus images greener?").
    *   Compute correlations between meta-features and the target.
6.  **Reporting**: Format the output into clear, capitalized sections with 4-decimal precision as requested.
