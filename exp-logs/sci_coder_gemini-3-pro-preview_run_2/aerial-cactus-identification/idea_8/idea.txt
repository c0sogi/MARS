Based on the progression of experiments and the specific lessons learned, I propose a **Custom Lightweight Feature Pyramid Classifier**. This strategy evolves the "Multi-Scale" concept from Idea 6 and the "Channel Efficiency" of Idea 7 into a unified architecture that fuses semantic context with spatial detail at an optimal intermediate resolution.

### Model
I propose a **Custom Lightweight Feature Pyramid Classifier** designed to maximize feature expressiveness while minimizing parameter count.

*   **Backbone (Narrow ResNet):** We will utilize a custom ResNet backbone optimized for 32x32 inputs.
    *   **Channel Configuration:** We will strictly adhere to the narrow channel width strategy (`[16, 32, 64]`) identified in **Cite solution_lesson_node_00019**. Starting with 16 filters significantly reduces computational cost without sacrificing accuracy, as the dataset complexity is low.
    *   **Kernel Size:** We will exclusively use **3x3 convolutions**, avoiding larger kernels which were proven inefficient for this resolution (**Cite solution_lesson_node_00011**).
    *   **Structure:** The backbone will have three stages, downsampling the input from 32x32 $\to$ 16x16 $\to$ 8x8.
*   **Neck (Feature Pyramid Fusion):** Instead of concatenating pooled vectors (Idea 6) or fully reconstructing the image (Idea 7), we will implement a **Spatial Feature Fusion** block at the **16x16 resolution**.
    *   We will project the final Stage 3 output (8x8, 64 channels) to 32 channels using a $1\times1$ convolution and **upsample** it to 16x16.
    *   We will project the Stage 2 output (16x16, 32 channels) to 32 channels using a $1\times1$ convolution.
    *   These two feature maps will be combined via **element-wise addition**.
    *   **Rationale:** This fuses the strong semantic context of the deeper layer with the fine-grained spatial details of the mid-level layer *before* global pooling. This addresses the bottleneck limitation (**Cite solution_lesson_node_00016**) more efficiently than vector concatenation, resulting in a smaller input dimension for the final classifier.
*   **Head:** The fused 16x16 feature map will undergo **Global Average Pooling (GAP)** followed by a single dense classification layer. This maintains translation invariance (**Cite solution_lesson_node_00005**) and ensures the model is lightweight.

### Data
*   **Preprocessing:** Images will be loaded in their native **32x32** resolution and normalized to the [0, 1] range. We will strictly avoid resizing or upscaling (**Cite solution_lesson_node_00001**).
*   **Augmentation:** We will apply only **Random Horizontal Flips** and **Random Vertical Flips**. We will explicitly avoid geometric rotations, color jittering, or cutout, as these techniques act as noise on this high-signal dataset (**Cite solution_lesson_node_00002**).

### Training
*   **Ensembling Strategy:** We will employ **Homogeneous Seed Averaging**. We will train **5 independent instances** of the model using different random seeds. This is preferred over heterogeneous ensembles because the architecture is expected to saturate the metric, and mixing in less stable models introduces risk (**Cite solution_lesson_node_00008**).
*   **Optimizer & Scheduler:** We will use **AdamW** combined with a **Cosine Annealing** learning rate scheduler. This setup is critical for eliminating residual ranking errors and ensuring robust convergence (**Cite solution_lesson_node_00007**).
*   **Loss Function:** Binary Cross-Entropy with Logits Loss.
*   **Duration:** We will train for a reduced number of epochs (e.g., 15-20), as the narrow architecture and SE-like fusion facilitate rapid convergence (**Cite solution_lesson_node_00019**).

### Evaluation
*   **Test Time Augmentation (TTA):** During inference, we will generate predictions for the original image, a horizontally flipped version, and a vertically flipped version for each of the 5 model instances (**Cite solution_lesson_node_00005**).
*   **Aggregation:** The final submission probability for each image will be the arithmetic mean of all TTA predictions across all 5 seeds. This maximizes robustness against stochastic noise (**Cite solution_lesson_node_00007**).
