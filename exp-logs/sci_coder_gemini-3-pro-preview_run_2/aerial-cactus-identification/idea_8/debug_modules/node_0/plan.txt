4.  **Training Loop Verification**: Execute `run_training` for a short duration (2 epochs) with a larger batch size for speed. This will verify the loss calculation, backpropagation, validation metric computation (AUC), and model checkpoint saving. We will assert that the best model is saved and the AUC is within a valid range.
5.  **Inference Verification**: Call `generate_submission` using the model trained in the previous step. We will verify that the submission CSV is created, contains the correct number of rows (matching the test set), has the required columns, and contains valid probability values.
