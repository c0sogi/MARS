The implementation strategy involves the following steps:

1.  **Initialization**: Set up the environment by defining the device and ensuring reproducibility using the provided utility functions.
2.  **Training Phase**: Iterate through the seeds defined in the configuration (`0` to `4`). For each seed, execute the `run_training` function from `library.train`. This will train the custom Wide ResNet with Deep Supervision and save the best model checkpoints to the working directory.
3.  **Ensemble Validation**:
    *   Load the validation dataset using `library.dataset`.
    *   Perform inference on the validation set using an ensemble of the 5 trained models. To optimize speed, we will use a single forward pass (no Test-Time Augmentation) for validation, averaging the predictions across all seeds.
    *   Compute the final **ROC AUC** score on the aggregated ensemble predictions.
    *   Print the required metric string: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the absolute error between the ensemble predictions and the ground truth labels.
    *   Compute basic image statistics (brightness, contrast, red/green/blue means) for the validation images on-the-fly.
    *   Calculate the correlation between these image features and the model's error magnitude using `numpy`. This identifies if specific image characteristics (e.g., low brightness) correlate with higher prediction errors.
5.  **Submission Generation**:
    *   Load the test dataset.
    *   Use the provided `library.inference.predict_ensemble` function to generate predictions. This function handles model loading and applies Test-Time Augmentation (TTA) for robust test predictions.
    *   Format the output into a DataFrame and save it to `./submission/submission.csv`.
