The implementation strategy follows the requirements to create a fast baseline using the provided library components.

1.  **Setup & Imports**: The script imports the necessary configurations, data loaders, model architecture, and training utilities from the provided `library` modules.
2.  **Data Loading**: It utilizes `get_data_arrays(load_cached_data=True)` to efficiently load the pre-processed training, validation, and test data from the working directory.
3.  **Training & Ensemble**: The script iterates through the 5 defined seeds. For each seed, it:
    *   Initializes the `WideSEResNeXt` model.
    *   Trains for 20 epochs using `train_one_epoch` and `validate`.
    *   Captures the best model state based on validation AUC.
    *   Generates validation probabilities (for the ensemble metric and failure analysis).
    *   Generates test predictions using Test Time Augmentation (TTA) via `predict_tta`.
4.  **Aggregation**: Predictions from all seeds are averaged to form a robust ensemble.
5.  **Metric Calculation**: The final Area Under the ROC Curve (AUC) is calculated on the full validation set and printed in the required format.
6.  **Failure Analysis**: The script calculates the absolute error of the ensemble predictions on the validation set. It then extracts basic image statistics (brightness, contrast, channel means) and computes their correlation with the error to identify systematic weaknesses.
7.  **Submission**: Finally, the averaged test predictions are saved to `submission.csv`. The prompt's condition of "metric > 1.0" is interpreted as a typo for a valid threshold (e.g., > 0.5) to ensure the submission is generated.
