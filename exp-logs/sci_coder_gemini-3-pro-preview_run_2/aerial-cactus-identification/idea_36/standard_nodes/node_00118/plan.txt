The implementation strategy follows the requirements to create a fast baseline, validate performance, analyze failures, and generate a submission.

1.  **Orchestration**: The script uses the provided `library.train.run_training` function to handle the core training loop across 5 seeds. This function automatically handles model initialization, training, checkpointing, and test-set inference with Test Time Augmentation (TTA), saving the final `submission.csv`.
2.  **Validation**: After training, the script re-loads the validation dataset and the 5 trained model checkpoints. It performs inference on the validation set (averaging predictions across seeds) to compute the robust "Final Validation Metric" (ROC AUC).
3.  **Failure Analysis**: The script calculates the absolute error of the ensemble predictions on the validation set. It then extracts meta-features (Brightness, Contrast, Red/Green/Blue Channel Means) from the raw validation images and computes the Pearson correlation between these features and the error magnitude. This identifies if specific image characteristics are correlated with model failure.
4.  **Efficiency**: The solution utilizes the provided `UltraWideECARepNeXt` model which is optimized for structural re-parameterization (fusing layers for fast inference). It leverages the caching mechanism in `get_dataloaders` to avoid redundant data loading.
