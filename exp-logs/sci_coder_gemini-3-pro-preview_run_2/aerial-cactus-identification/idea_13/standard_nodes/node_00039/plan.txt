Implementation strategy:
1.  **Setup & Initialization**: Initialize the environment using `Config.setup()`, set the computation device (GPU/CPU), and ensure reproducibility with `seed_everything`.
2.  **Data Loading**: Retrieve the training, validation, and test data loaders using `get_dataloaders(load_cached_data=True)` to leverage cached preprocessing.
3.  **Model Training (Homogeneous Seed Averaging)**:
    *   Iterate through the 5 defined seeds (`Config.SEEDS`).
    *   For each seed, initialize the `NarrowSEResNet` model, `AdamW` optimizer, and `CosineAnnealingLR` scheduler.
    *   Train the model using `train_model`, which handles the training loop and early stopping, and saves the best checkpoint.
    *   Reload the best checkpoint for each seed and store the model in memory for the ensemble phase.
4.  **Validation Ensemble & Failure Analysis**:
    *   Perform inference on the validation set using the ensemble of 5 trained models.
    *   Apply Test Time Augmentation (TTA) (averaging predictions of original, horizontally flipped, and vertically flipped images) for each model, then average across the 5 models.
    *   Compute and print the **Final Validation Metric** (ROC AUC).
    *   Calculate the absolute error for each validation sample.
    *   Compute and print the correlation between the error magnitude and image meta-features (Brightness and Contrast) to identify systematic failure modes.
5.  **Submission Generation**:
    *   If the validation AUC indicates a working model (threshold > 0.5, correcting for the likely typo in the prompt's "1.0" requirement), generate predictions for the test set.
    *   Use the same Ensemble + TTA strategy for the test set.
    *   Save the aggregated predictions to `submission.csv` in the required format.
