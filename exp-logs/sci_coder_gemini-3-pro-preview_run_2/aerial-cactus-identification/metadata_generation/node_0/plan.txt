The script will perform the following steps:
1.  **Setup and Directory Creation**: It will define the input and output directories and ensure the `./metadata` directory exists.
2.  **Data Loading**: It will read the `train.csv` and `sample_submission.csv` files from the input directory.
3.  **Path Construction**: It will construct relative file paths for the images. For the training set, paths will be `train/<id>`, and for the test set, `test/<id>`.
4.  **Data Splitting**: It will split the training data into training and validation sets using an 80:20 ratio, stratified by the `has_cactus` label to maintain class distribution, using a fixed random state.
5.  **Metadata Saving**: It will save the processed DataFrames (train, validation, test) to the `./metadata` directory.
6.  **Verification**:
    - It will reload the saved metadata files.
    - It will print summary statistics (counts, class balance).
    - It will randomly check 1000 file paths from each set to ensure they exist relative to the `./input` directory, raising an error if too many are missing.
    - It will assert that the validation split preserved the class distribution close to the original training set.
