To establish a robust and efficient baseline, I propose a **Shallow Convolutional Neural Network (CNN)**. This approach distills the convolutional concepts found in Model 1 (MobileNetV3) down to their most fundamental components, stripping away complex structures like inverted residual blocks and squeeze-and-excitation modules in favor of raw computational speed and architectural simplicity.

### Model
The architecture is a straightforward, sequential CNN designed for 32x32 pixel inputs. It consists of three convolutional blocks followed by a classification head.
*   **Convolutional Blocks:** Each block is composed of a standard 3x3 Convolutional layer, followed by Batch Normalization to stabilize learning, a ReLU activation function for non-linearity, and a 2x2 Max Pooling layer to downsample the spatial dimensions. The number of filters increases progressively (e.g., 32, 64, 128) to capture increasingly complex features.
*   **Classification Head:** After the third pooling layer, the feature maps are flattened into a 1D vector. This vector is passed through a single fully connected (dense) layer that projects the features directly to a single output neuron.
*   **Output:** A Sigmoid activation is applied to the final neuron to produce a probability score between 0 and 1, representing the likelihood of a cactus being present.

### Data
*   **Preprocessing:** Pixel values will be normalized to the range [0, 1] by dividing by 255. This ensures numerical stability and faster convergence during training.
*   **Augmentation:** To improve generalization without significant computational overhead, simple geometric transformations will be applied during training. specifically Random Horizontal Flips and Random Vertical Flips. This is appropriate given the aerial nature of the imagery, where orientation is largely arbitrary.
*   **Loaders:** Data will be batched (e.g., batch size of 64 or 128) to leverage GPU parallelization.

### Training
*   **Loss Function:** Binary Cross-Entropy with Logits Loss will be used, which is the standard objective function for binary classification tasks.
*   **Optimizer:** The Adam optimizer will be employed for its ability to adapt learning rates for each parameter, requiring less hyperparameter tuning than SGD.
*   **Procedure:** The model will be trained for a fixed number of epochs (e.g., 20-30). To prioritize efficiency, an Early Stopping mechanism will monitor the validation ROC AUC score and terminate training if no improvement is observed for a set number of epochs, preventing waste of compute resources.

### Evaluation
*   **Inference:** The trained model will be set to evaluation mode (disabling batch norm updates and dropout if present). The test set images will be passed through the network to generate raw logits.
*   **Post-processing:** The Sigmoid function will be applied to these logits to obtain the final probability scores required for the submission.
*   **Submission:** These probabilities will be paired with their corresponding image IDs and saved to a CSV file in the specified format.
