### Implementation Strategy

1.  **Setup and Reproducibility**: Initialize the environment by setting random seeds using the provided `library.utils.seed_everything` function to ensure deterministic behavior.
2.  **Data Loading**: Utilize `library.dataset.get_datasets` to load the training, validation, and test datasets. We will wrap these in PyTorch `DataLoader` instances to handle batching. We will verify the data loading process by checking the shape of a single batch.
3.  **Model Initialization**: Instantiate the custom `NarrowSEResNet` model from `library.model`. We will verify the model architecture by performing a forward pass with a dummy input tensor and asserting the output shape is correct.
4.  **Training Simulation**: configure the optimizer (AdamW) and loss function (BCEWithLogitsLoss). We will run the training loop using `library.engine.train_model` for a reduced number of epochs (2 epochs) to demonstrate functionality quickly while adhering to the time constraints.
5.  **Inference**: Use `library.engine.predict_tta` to generate predictions on the test set using Test-Time Augmentation. We will validate that the predictions are valid probabilities (between 0 and 1).
6.  **Submission Generation**: Construct a submission DataFrame matching the required format using the test IDs and generated probabilities, and save it to the working directory.
