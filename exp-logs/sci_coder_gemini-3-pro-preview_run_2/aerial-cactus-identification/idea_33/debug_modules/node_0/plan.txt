The following implementation demonstrates the usage of the provided library components.

**Implementation Strategy:**
1.  **Configuration Override**: We programmatically modify the `Config` class to set a dedicated working directory for this demonstration and reduce the training duration to 1 epoch to satisfy the speed requirement.
2.  **Utility Verification**: We validate the `calculate_roc_auc` function using synthetic data to ensure metric calculation is correct.
3.  **Component Verification**: We instantiate a `RepNeXtBlock`, perform a forward pass in its training configuration (multi-branch), switch it to deployment mode (structural re-parameterization), and verify that the output remains consistent within numerical tolerance.
4.  **Data Loading**: We initialize the data loaders and verify the tensor shapes and data types of a single training batch.
5.  **Training Execution**: We run the training loop for one epoch with a fixed seed, ensuring the model trains and saves a checkpoint correctly.
6.  **Inference Execution**: We run the inference pipeline, which loads the saved checkpoint, applies Test Time Augmentation (TTA), and generates a submission file. We then validate the format of the output CSV.
