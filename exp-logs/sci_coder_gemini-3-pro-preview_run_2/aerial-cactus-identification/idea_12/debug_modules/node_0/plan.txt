This script demonstrates the usage of the provided library modules for the cactus classification task. It performs the following steps:
1.  **Configuration Patching**: Modifies hyperparameters (Epochs, Seeds, Debug mode) in the imported modules to ensure the demonstration runs quickly (under 1 minute) while validating the logic.
2.  **Utility Verification**: Tests the AUC computation and seed setting functions.
3.  **Data Loading**: Initializes DataLoaders using `dataset.py`, verifies batch shapes, data types, and value ranges.
4.  **Model Initialization**: Instantiates the `NarrowSEResNet` model, counts parameters, and verifies the forward pass on a dummy batch.
5.  **Training & Validation Loop**: Runs a single epoch of training and validation using `engine.py` functions to verify the optimization step and metric calculation.
6.  **Inference & Submission**: Simulates the test set prediction pipeline using Test Time Augmentation (TTA) and generates a submission file.
