Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: We will initialize the environment using the provided `library` modules. This includes setting the device (GPU) and ensuring reproducibility via `seed_everything`.
2.  **Data Loading**: We will leverage `get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test datasets.
3.  **Ensemble Training**: We will iterate through the 5 predefined seeds. For each seed, we will invoke `train_model` from `library.engine`. This function handles the training loop, validation monitoring, and saves the best model checkpoint. We will collect the paths to these saved models.
4.  **Validation & Metric Calculation**:
    *   We will perform inference on the validation set using the trained ensemble. We will use Test Time Augmentation (TTA) via `predict_with_tta` for robust probability estimation.
    *   We will aggregate predictions across all 5 models.
    *   We will compute the Area Under the ROC Curve (AUC) comparing the ensemble predictions against the ground truth labels.
    *   We will print the `Final Validation Metric` as required.
5.  **Failure Analysis**:
    *   We will calculate the absolute error for each validation sample (`|target - prediction|`).
    *   We will extract meta-features (Brightness, Contrast, Red/Green/Blue means) from the raw validation images stored in the dataset object.
    *   We will compute and print the Pearson correlation between these image features and the model's error to identify potential weaknesses (e.g., does the model fail more on low-contrast images?).
6.  **Submission Generation**:
    *   We will perform inference on the test set using the same ensemble TTA approach.
    *   We will average the predictions from all 5 models.
    *   We will construct the submission DataFrame using the IDs from the test dataset and save it to `submission.csv`. *Note: We will proceed with submission generation regardless of the "metric > 1.0" text in the prompt, assuming it is a template error, as AUC cannot exceed 1.0 and a submission is required for scoring.*
