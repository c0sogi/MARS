Based on the lessons learned and the analysis of the previous solution, I will implement the following optimizations:

1.  **Architecture Simplification (GeM $\to$ GAP):** I will replace the learnable Generalized Mean Pooling (GeM) with standard Global Average Pooling (GAP). While GeM is effective for fine-grained retrieval, on this low-resolution, high-signal task, the learnable parameter `p` can introduce optimization instability. Reverting to GAP aligns strictly with the findings in **Lesson 16** ("concatenating the Global Average Pooled (GAP) outputs") and **Lesson 5**, reducing model complexity while maintaining the multi-scale aggregation strategy. Cite {solution_lesson_node_00005}, Cite {solution_lesson_node_00016}.
2.  **Enhanced Test Time Augmentation (TTA):** I will expand the TTA pipeline to include a "Horizontal + Vertical Flip" (180-degree rotation). The previous solution only used horizontal and vertical flips independently. Adding the combination provides a more complete coverage of the geometric symmetries (D2 dihedral group subset), which is beneficial for aerial imagery.
3.  **Extended Training Schedule:** I will increase `EPOCHS` from 15 to 20. The previous logs indicated that models were still refining their weights at epoch 15. Extending the schedule ensures the Cosine Annealing scheduler decays the learning rate closer to zero, allowing the model to converge to a better optimum as noted in **Lesson 12**. Cite {solution_lesson_node_00012}.

class GeM(nn.Module):
    """
    Generalized Mean Pooling (GeM) with learnable parameter p per channel.
    f = (1/|Omega| * sum(x^p))^(1/p)
    """

    def __init__(self, channels, p=GEM_P_INIT, eps=1e-6):
        super(GeM, self).__init__()
        # Learnable p per channel: shape (1, C, 1, 1) for broadcasting
        self.p = nn.Parameter(torch.ones(1, channels, 1, 1) * p)
        self.eps = eps

    def forward(self, x):
        # x: (B, C, H, W)
        # Clamp x to avoid NaN in power operation
        x = x.clamp(min=self.eps)

        # Calculate x^p
        x_pow = x.pow(self.p)

        # Average pooling over spatial dimensions (H, W)
        # This computes (1/|Omega| * sum(x^p))
        pooled = F.avg_pool2d(x_pow, (x.size(-2), x.size(-1)))

        # Apply ( )^(1/p)
        return pooled.pow(1.0 / self.p)
