This script demonstrates the end-to-end usage of the provided library modules for the cactus identification task. It performs the following steps:
1.  **Data Loading Verification**: Initializes the data loaders using `library.dataset` and asserts that the batch shapes and data types are correct.
2.  **Model Architecture Verification**: Instantiates the `CustomNarrowSEMultiScaleResNet` from `library.model`, performs a forward pass with a dummy batch, and verifies the output shape.
3.  **Training Demonstration**: Runs a single epoch of training for a specific seed using `library.train.train_single_seed`, ensuring the training pipeline functions correctly and produces a model checkpoint.
4.  **Inference Demonstration**: Executes the inference pipeline using `library.inference.run_inference` with the trained model, applying Test Time Augmentation (TTA).
5.  **Submission Validation**: Checks the generated `submission.csv` to ensure it meets the required format and dimensions.
