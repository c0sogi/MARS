Based on the failure analysis of the previous solution (`idea_4`), the model exhibited a strong negative correlation (-0.55) between localization error and object size, indicating a significant degradation in detecting small objects compared to the baseline. This was caused by attaching the `SpatialAttentionHead` to high-resolution FPN levels (P3) and applying spatial attention mechanisms that biased the shared backbone features toward large, salient regions (Cite solution_lesson_node_00027). Furthermore, using high-resolution features for the global classification task introduced conflicting gradients that washed out the fine-grained spatial details required for localization (Cite solution_lesson_node_00026).

To address this, I will:
1.  **Replace `SpatialAttentionHead` with a `GlobalHead`**: This simplified head will use **only** the lowest-resolution, highest-semantic feature map (P5) for the auxiliary study-level classification task. This decouples the global task from the high-resolution maps (P3/P4) needed for small object detection.
2.  **Increase Training Epochs**: I will increase `Config.NUM_EPOCHS` from 4 to 8. The previous run completed 4 epochs in 41 minutes; 8 epochs will comfortably fit within the 3-hour limit and allow for better convergence (Cite solution_lesson_node_00022).
3.  **Maintain Auxiliary Loss Weight**: I will ensure the auxiliary loss weight remains at 0.5 to prevent the global task from dominating the optimization (Cite solution_lesson_node_00013).

class SpatialAttentionHead(nn.Module):
    """
    Multi-Scale Spatial Attention Head for Study Classification.
    Extracts features from FPN levels P3, P4, P5, applies spatial attention,
    and performs global classification.
    """

    def __init__(self, in_channels=256, num_classes=4):
        super().__init__()
        # Attention mechanisms for FPN levels P3 (key '1'), P4 (key '2'), P5 (key '3')
        self.att_convs = nn.ModuleDict(
            {
                "1": nn.Conv2d(in_channels, 1, kernel_size=1),
                "2": nn.Conv2d(in_channels, 1, kernel_size=1),
                "3": nn.Conv2d(in_channels, 1, kernel_size=1),
            }
        )

        # Classifier: Concatenated features from 3 levels -> num_classes
        self.classifier = nn.Linear(in_channels * 3, num_classes)

    def forward(self, features):
        """
        Args:
            features (OrderedDict): Output from FPN backbone.
        Returns:
            logits (Tensor): (N, num_classes)
        """
        pooled_feats = []
        # Process specific FPN levels: P3, P4, P5
        # Keys in resnet_fpn_backbone are '0' (P2), '1' (P3), '2' (P4), '3' (P5)
        target_keys = ["1", "2", "3"]

        for key in target_keys:
            if key in features:
                x = features[key]  # (N, C, H, W)

                # Generate Spatial Attention Map
                att_logit = self.att_convs[key](x)  # (N, 1, H, W)
                att_map = torch.sigmoid(att_logit)

                # Apply Attention
                x_weighted = x * att_map

                # Global Average Pooling
                # Result: (N, C)
                x_pooled = x_weighted.mean(dim=(2, 3))
                pooled_feats.append(x_pooled)
            else:
                # Should not happen with standard ResNet-FPN
                continue

        if not pooled_feats:
            return None

        # Concatenate multi-scale features: (N, C * 3)
        concat_feats = torch.cat(pooled_feats, dim=1)

        # Classification
        logits = self.classifier(concat_feats)
        return logits

class GlobalHead(nn.Module):
    """
    Simple Global Average Pooling Head for Study Classification.
    Uses only the highest-level feature map (P5) to avoid conflicting gradients
    with localization tasks on high-resolution maps.
    Cite solution_lesson_node_00026.
    """

    def __init__(self, in_channels=256, num_classes=4):
        super().__init__()
        self.avgpool = nn.AdaptiveAvgPool2d(1)
        self.fc = nn.Linear(in_channels, num_classes)

    def forward(self, features):
        """
        Args:
            features (OrderedDict): Output from FPN backbone.
        Returns:
            logits (Tensor): (N, num_classes)
        """
        # Use only P5 (key '3') for global classification
        # P5 has the largest receptive field and lowest resolution (stride 32)
        if "3" in features:
            x = features["3"]
        else:
            # Fallback to the last available feature if '3' is missing
            x = list(features.values())[-1]

        x = self.avgpool(x)
        x = torch.flatten(x, 1)
        x = self.fc(x)
        return x
