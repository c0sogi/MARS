# Stabilized Multi-Task Faster R-CNN with Spatial Attention

This solution synthesizes the "Unified" multi-task philosophy of Idea 2 with the structural ambition of Idea 3, while rigorously applying the stability and efficiency constraints identified in the failure analyses. The core structural innovation is the replacement of the simple Global Average Pooling head with a **Multi-Scale Spatial Attention Module**, stabilized by a specific optimization regimen to prevent the gradient explosion observed in previous attempts.

### 1. Model
**Architecture:** Multi-Task Faster R-CNN with **ResNet-101-FPN**.
*   **Backbone Selection:** We revert to the **ResNet-101** backbone. While ResNeXt (Idea 3) offered higher theoretical capacity, it caused a "Capacity-Budget Mismatch" that forced data subsampling and led to underfitting on small objects (Cite solution_lesson_node_00022). ResNet-101 provides the optimal balance of depth for feature extraction and computational efficiency for full-dataset training.
*   **Structural Innovation (Spatial Attention Head):** Instead of standard Global Average Pooling (GAP), we introduce a **Multi-Scale Spatial Attention Head** as the auxiliary branch.
    *   *Mechanism:* This module extracts feature maps from FPN levels P3, P4, and P5. For each level, it applies a 1x1 convolution followed by a sigmoid activation to generate a spatial attention map. This map weights the original features before pooling, allowing the global classifier to focus on relevant opacity textures while ignoring background noise.
    *   *Rationale:* This explicitly addresses the "Indeterminate" class ambiguity by enabling the global classifier to learn from diffuse feature distributions that the object detector might suppress (Cite solution_lesson_node_00008).
*   **Detection Head Configuration:** We configure the Region Proposal Network (RPN) with **3000 post-NMS proposals** and allow **200 detections per image**. This high-capacity setting is mandatory to overcome the density bottleneck, where default limits caused linear performance degradation in complex scenes (Cite solution_lesson_node_00005, solution_lesson_node_00013).

### 2. Data
**Preprocessing:**
*   **Contrast Enhancement:** Apply **CLAHE** (Contrast Limited Adaptive Histogram Equalization) to all images. This is proven to enhance the visibility of subtle opacities in monochromatic X-rays (Cite solution_lesson_node_00005).
*   **Resolution:** Fix input resolution at **800x800**. This avoids the optimization instability and reduced batch sizes associated with 1024x1024 resolution (Cite solution_lesson_node_00017, solution_lesson_node_00022).
*   **Label Engineering:**
    *   **Training:** Use granular class labels (Typical, Indeterminate, Atypical) for bounding boxes to supervise the backbone with rich semantic information (Cite solution_lesson_node_00020).
    *   **Study Level:** Use the study labels to supervise the Spatial Attention Head.

### 3. Training
**Strategy:**
*   **Loss Function:** $L_{total} = L_{RPN} + L_{ROI} + 0.5 \times L_{Global}$. We explicitly set the auxiliary loss weight to **0.5**. Previous experiments showed that a weight of 1.0 caused the easier global task to dominate gradients, hindering localization learning (Cite solution_lesson_node_00013).
*   **Optimization Stability:**
    *   **Gradient Clipping:** Apply gradient clipping (norm value 10.0) to prevent the explosion observed when training complex heads (Cite solution_lesson_node_00024).
    *   **Warmup:** Implement a linear learning rate warmup for the first epoch to stabilize the Attention Head weights.
*   **Scheduling:** Decay the learning rate after **60% of the total epochs** (e.g., epoch 7 of 12). This ensures the model benefits from a low-LR fine-tuning phase *before* early stopping can trigger (Cite solution_lesson_node_00014).
*   **Checkpointing:** Save the model with the **Minimum Validation Loss**. Do not use mAP for checkpointing, as loss is a more efficient and sufficiently correlated proxy for this architecture (Cite solution_lesson_node_00006, solution_lesson_node_00007).

### 4. Evaluation
**Inference Pipeline:**
*   **Class Collapsing:** During inference, map all predicted bounding box classes (Typical, Indeterminate, Atypical) to the single generic class **"opacity"**. This aligns the evaluation with the competition metric and prevents penalizing the model for subtype confusion when localization is correct (Cite solution_lesson_node_00020).
*   **Study Prediction Ensemble:** The final study label will be determined by combining the **Spatial Attention Head's prediction** with the **maximum confidence score** of the detected boxes.
*   **Consistency:** If the predicted study label is "Negative", explicitly override the detection output to "none 1 0 0 1 1" to eliminate false positives.
