The implementation strategy is as follows:

1.  **Setup & Data Loading**: Initialize the environment, set random seeds for reproducibility, and load the training metadata from `./metadata/train.csv`.
2.  **Target Variable Analysis**: Analyze the four study-level binary classification targets (`Negative for Pneumonia`, `Typical Appearance`, `Indeterminate Appearance`, `Atypical Appearance`). Calculate class counts and balance ratios to identify imbalance.
3.  **Image Data Analysis**:
    *   Attempt to read DICOM images using `pydicom` (or `cv2` as a fallback).
    *   Iterate through a stratified sample of the dataset (to ensure execution within time limits) to extract image dimensions (Height, Width) and calculate Aspect Ratios.
    *   Compute pixel statistics (Mean, Std) on this sample to inform normalization strategies.
    *   Handle cases where image reading libraries might be missing gracefully.
4.  **Feature Engineering (Bounding Boxes)**:
    *   Parse the `boxes` column to extract metadata about opacities (count of boxes per image, average area of boxes).
    *   Construct a tabular representation of these meta-features.
5.  **Feature/Signal Relationships**:
    *   **Structured**: Calculate correlations between the extracted meta-features (e.g., Number of Boxes, Box Area) and the target classes.
    *   **Importance**: Train a lightweight Random Forest classifier using the extracted meta-features to predict the study label and report feature importance.
6.  **Reporting**: Output the findings in the requested format (capitalized sections, 4 decimal places) to standard output.
