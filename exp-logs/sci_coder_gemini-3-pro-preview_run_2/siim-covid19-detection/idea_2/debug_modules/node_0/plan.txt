2.  **Dataset Verification**:
    *   Instantiate `SIIMDataset` for both training and validation splits using the `debug=True` flag.

    *   Retrieve a single batch using a `DataLoader` and `collate_fn`.

3.  **Model Initialization and Forward Pass**:
    *   Instantiate the `MultiTaskFasterRCNN` model and move it to the appropriate device (CPU/GPU).
    *   Perform a **training forward pass** with the batch retrieved earlier. Verify that the output is a dictionary of scalar losses (e.g., `loss_classifier`, `loss_box_reg`, `loss_global_classifier`).
    *   Perform an **inference forward pass** (eval mode) with the same batch. Verify that the output consists of detections (boxes, scores, labels) and global logits.

4.  **Training Loop Execution**:
    *   Set up the optimizer (`SGD`) and run the `train_model` function for one epoch.
    *   This verifies the integration of the engine, model, and data loading, and ensures checkpoints are saved correctly to the working directory.

5.  **Inference Logic Verification**:
    *   Manually execute the inference logic on a small subset of data (simulating the test phase).
    *   Process the model outputs to generate prediction strings in the required format (`opacity confidence xmin ymin xmax ymax` or `none 1 0 0 1 1`).

6.  **Cleanup**:
