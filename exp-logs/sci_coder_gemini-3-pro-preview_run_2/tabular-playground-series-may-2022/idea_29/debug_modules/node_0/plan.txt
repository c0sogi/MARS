Implementation Strategy:
1.  **Environment Setup**: Import necessary libraries and the provided modules from the `library` package. Set random seeds for reproducibility.
2.  **Data Loading Verification**: Utilize `library.data_loader.get_dataloaders` with a small `data_fraction` (e.g., 5%) to quickly load a subset of the data. Verify that the returned DataLoaders yield batches with the expected shapes and data types (continuous features, categorical features, and targets).
3.  **Component Testing**: Instantiate individual custom layers (`SwiGLU`, `PreNormResBlock`) from `library.layers` and perform forward passes with dummy tensors to verify input/output consistency and shape transformations.
4.  **Model Architecture Verification**: Instantiate the full `ContextAwareSwishGatedResFunnel` model from `library.model`. Perform a forward pass using a real batch from the data loader to ensure the integration of the categorical and continuous streams works correctly.
5.  **Training Loop Execution**: Run a minimal training session using `library.train.run_training`. We will override the default epoch count to 1 and use the small data fraction to ensure this completes in seconds. We will verify that the function returns a valid AUC score and saves the model file.
6.  **Inference Demonstration**: Load the trained model weights saved in the previous step. Perform inference on a single batch from the test loader to demonstrate how to generate predictions.
