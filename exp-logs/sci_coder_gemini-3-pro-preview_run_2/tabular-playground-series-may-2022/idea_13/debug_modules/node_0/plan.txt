Here is the implementation strategy and the complete Python script.

### Implementation Strategy

1.  **Setup & Imports**: The script imports the necessary classes and functions from the provided `library` modules (`utils`, `data`, `model`, `train`) and sets the random seed for reproducibility.
2.  **Model Verification**: A dedicated function `demo_model_instantiation` is created to verify the model architecture.
    *   It instantiates the `DualViewHybridResFunnel` model with reduced parameters for speed.
    *   It generates a small dummy batch of continuous and categorical data on the available device (CPU/GPU).
    *   It performs a forward pass and asserts that the output shape and value range (probabilities between 0 and 1) are correct.
3.  **Pipeline Execution**: A function `demo_training_pipeline` demonstrates the end-to-end usage of the library.
    *   It defines a specific working directory (`./working/demo_execution`) to store artifacts.
    *   It calls `library.train.run_training` with `epochs=1` and a large `batch_size=4096`. This configuration ensures the code runs very quickly (seconds on an A100) while still executing the full data loading, training, validation, and inference workflow.
4.  **Result Validation**: The script verifies that the expected output files (`best_model.pth` and `submission.csv`) are generated and that the submission file follows the correct format and length.
