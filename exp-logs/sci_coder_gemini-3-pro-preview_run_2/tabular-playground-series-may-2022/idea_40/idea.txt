Based on the accumulated empirical evidence and the derived lessons, I propose the implementation of a **Homogeneous Direct-SwiGLU Hybrid Network with Affine-Free Alignment**.

This strategy represents a structural synthesis that harmonizes the network's inductive bias and resolves the critical **Normalization Scope Mismatch** at the fusion interface (Cite solution_lesson_node_00124). It unifies the architecture by deploying **Direct SwiGLU Blocks** (Cite solution_lesson_node_00129) across *both* the Transformer Encoder and the Residual Backbone, ensuring consistent gradient dynamics. Furthermore, it introduces **Affine-Free Batch Normalization** to the sequence stream, strictly aligning the categorical distribution with the Z-scored continuous features without introducing the learnable parameters that caused previous fusion attempts to overfit (Cite solution_lesson_node_00118, solution_lesson_node_00074).

# Model

The architecture is a dual-stream network that fuses a statistically aligned, SwiGLU-enhanced categorical sequence with a raw continuous stream into a deep, homogeneous residual funnel.

1.  **Stream 1: Categorical Sequence (Homogeneous SwiGLU Transformer)**
    *   **Input**: The `f_27` feature is decomposed into 10 distinct character tokens.
    *   **Embedding**: Tokens are passed through a shared embedding layer (dimension 32).
        *   **Initialization**: Explicitly initialize with **Unit Variance** (`std=1.0`) to ensure robust signal propagation in the Post-Norm architecture (Cite solution_lesson_node_00114).
    *   **Positional Encoding**: **Learnable Absolute Positional Embeddings** are added.
        *   **Initialization**: Explicitly initialize with **Low Variance Random Noise** (`std=0.02`) to break symmetry without introducing high-magnitude noise (Cite solution_lesson_node_00081).
    *   **Encoder (Structural Innovation)**: The sequence is processed by a **Modified Transformer Encoder** (2 layers, 4 heads).
        *   **Homogeneity**: Replace the standard Feed-Forward Network (`Linear -> GELU -> Linear`) with a **Direct SwiGLU Block** (`Linear(d->2d) -> SwishGate -> Output(d)`). This aligns the encoder's non-linearity with the backbone, improves parameter efficiency, and leverages the superior gating of SwiGLU (Cite solution_lesson_node_00090, solution_lesson_node_00129).
        *   **Configuration**: Use **Post-Normalization** (`norm_first=False`) (Cite solution_lesson_node_00095).
        *   **Regularization**: Apply **Low Dropout (0.1)** (Cite solution_lesson_node_00048).
    *   **Structural Innovation: Affine-Free Alignment**:
        *   The output sequence is flattened and passed through a **BatchNorm1d** layer with `affine=False`.
        *   **Rationale**: The Post-Norm Transformer output has unbounded variance (Local Scope), while continuous features are Z-scored (Global Scope). This layer strictly forces the flattened sequence to $\sim N(0,1)$ global statistics, perfectly aligning it with the continuous stream. Disabling affine parameters (`affine=False`) prevents the model from learning to "undo" this normalization or overfitting via scale/shift parameters (Cite solution_lesson_node_00118), satisfying Lesson 124 without the coupling risks of Lesson 74.

2.  **Stream 2: Continuous Preservation**
    *   **Input**: The 30 numerical features are standardized.
    *   **Preservation**: Features are maintained in their **raw, normalized form** (Cite solution_lesson_node_00038).

3.  **Fusion Layer: The Linear Stem**
    *   **Concatenation**: The **Aligned Transformer Output** and the **Raw Continuous Features** are concatenated.
    *   **Linear Stem**: The concatenated vector is passed through a **Linear Projection Layer** to map to the backbone width (512).
        *   **Initialization**: Use default **Uniform Bias** (do not zero-init) to preserve initial variance (Cite solution_lesson_node_00130).

4.  **Backbone: LayerNorm SwiGLU ResFunnel**
    *   **Topology**: The backbone is organized into 3 stages (512 $\to$ 256 $\to$ 128) (Cite solution_lesson_node_00084).
    *   **Sustained Depth**: Each stage consists of **3 stacked Residual Blocks** (Cite solution_lesson_node_00070).
    *   **Blocks**: Use **Pre-LayerNorm Direct SwiGLU Residual Blocks**.
        *   **Structure**: $x_{out} = x + \text{DropPath}(\text{Dropout}(\text{SwiGLU}(\text{Linear}(\text{LayerNorm}(x)))))$.
        *   **Normalization**: Use **LayerNorm** (Cite solution_lesson_node_00087).
    *   **Transitions**: Use **Pre-Norm Transitions** (`LayerNorm -> Linear`) (Cite solution_lesson_node_00088).
    *   **Regularization**: Linear **Stochastic Depth** schedule (0.0 to 0.2) (Cite solution_lesson_node_00086) + **Dropout (0.35)**.

5.  **Output Head**
    *   **Minimalist Design**: Single `Linear` layer with Sigmoid activation (Cite solution_lesson_node_00060).

# Training

1.  **Optimizer**: Use **AdamW**.
2.  **Strict Decoupled Weight Decay**:
    *   **Group 1 (Decay 1e-2)**: Weights of Linear layers, Embeddings, and Attention projections.
    *   **Group 2 (Decay 0.0)**: Biases, **LayerNorm parameters**, and **Positional Embeddings**. Explicitly filter by name (e.g., `pos_embed`) (Cite solution_lesson_node_00098).
3.  **Initialization**:
    *   **SwiGLU Blocks (Encoder & Backbone)**: Use **Kaiming (He) Uniform** (Cite solution_lesson_node_00090).
    *   **Attention**: Use **Xavier (Glorot)** (Cite solution_lesson_node_00082).
4.  **Optimization Granularity**:
    *   **Batch Size**: 1024 (Cite solution_lesson_node_00044).
    *   **Scheduler**: Aggressive Step Decay (factor 0.1 every 10 epochs) (Cite solution_lesson_node_00033).
5.  **Duration**: Train for **40 epochs** to ensure multiple learning rate decay stages (Cite solution_lesson_node_00128).
6.  **Metric**: Monitor **Validation AUC** (Cite solution_lesson_node_00003).
