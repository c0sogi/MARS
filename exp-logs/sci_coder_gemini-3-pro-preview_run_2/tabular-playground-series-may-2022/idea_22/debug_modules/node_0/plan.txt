The following script demonstrates the usage of the provided library components. It performs the following steps:
1.  **Configuration Setup**: Sets random seeds and overrides configuration parameters (like batch size and epochs) to ensure the demonstration runs quickly.
2.  **Data Pipeline Verification**: loads the data using `process_data` and `get_dataloaders`, verifying the shapes and types of the resulting tensors.
3.  **Component Verification**: Instantiates individual model blocks (`PreActGLUBlock`, `TransformerStream`) and tests their forward passes with dummy data to ensure correct dimensionality.
4.  **Model Integration**: Instantiates the full `SustainedDepthHybridNet`, performs a forward pass with a real data batch, and verifies the output shape and gradient propagation.
5.  **Training Loop Execution**: Runs a complete training cycle for 1 epoch using `run_training`, generating a submission file, and verifies the output format.
