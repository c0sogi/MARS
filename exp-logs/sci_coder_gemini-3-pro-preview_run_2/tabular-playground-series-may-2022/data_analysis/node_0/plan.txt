### Implementation Strategy

1.  **Environment Setup**: Import necessary libraries (pandas, numpy, sklearn) and set random seeds for reproducibility. Suppress warnings to keep output clean.
2.  **Data Loading**:
    *   Load the training metadata from `./metadata/train_metadata.csv` to identify the specific rows allocated for training (avoiding validation data leakage).
    *   Load the raw `./input/train.csv`.
    *   Filter the raw data to include only the `id`s present in the training metadata.
3.  **Modality Detection**: Inspect the dataframe columns to confirm the data is tabular (mixture of numeric and object types) as described in the task.
4.  **Target Analysis**:
    *   Compute the distribution of the `target` column.
    *   Calculate class balance ratios.
5.  **Tabular Feature Analysis**:
    *   **Numerical Features**: Calculate mean, std, min, max. Detect outliers using the Interquartile Range (IQR) method.
    *   **Categorical Features**: Calculate cardinality. Identify columns with high cardinality (>50) or rare labels (<1%).
    *   **Missing Values**: Report percentage of NaNs.
6.  **Feature Relationships**:
    *   **Correlation**: Compute the correlation matrix (using a sample if the dataset is too large) to identify collinear features (>0.90).
    *   **Feature Importance**: Preprocess data (simple encoding for categoricals, imputation for NaNs) and train a lightweight Random Forest classifier. Extract and report the top 5 most important features.
7.  **Output Formatting**: Ensure all results are printed in distinct, capitalized sections with floats formatted to 4 decimal places.
