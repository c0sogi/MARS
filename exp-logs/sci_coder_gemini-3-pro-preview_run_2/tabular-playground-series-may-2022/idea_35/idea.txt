# Solution Strategy

Based on the accumulated empirical evidence and the derived lessons, I propose the implementation of a **LayerScaled-Fusion Hybrid SwiGLU Network**.

This strategy represents a structural synthesis that addresses the subtle "Scale Mismatch" inherent in fusing Post-Norm Transformers with continuous features (Cite solution_lesson_node_00095, solution_lesson_node_00069) and overcomes the "Diminishing Returns of Depth" (Cite solution_lesson_node_00075) by integrating **LayerScale** stabilization. It retains the highly optimized SwiGLU backbone and initialization protocols from the current best solution while introducing targeted normalization and scaling mechanisms to maximize gradient fidelity.

# Model

The architecture is a dual-stream network that fuses a stabilized categorical stream with a raw continuous stream into a deep, LayerScaled residual funnel.

1.  **Stream 1: Categorical Sequence (Stabilized Post-Norm Transformer)**
    *   **Input**: The `f_27` feature is decomposed into 10 distinct character tokens.
    *   **Embedding**: Tokens are passed through a shared embedding layer (dimension 32).
        *   **Initialization**: Explicitly initialize with **Unit Variance** (`std=1.0`) to ensure robust signal propagation in the Post-Norm architecture (Cite solution_lesson_node_00114).
    *   **Positional Encoding**: **Learnable Absolute Positional Embeddings** are added.
        *   **Initialization**: Explicitly initialize with **Low Variance Random Noise** (`std=0.02`) to break symmetry without introducing noise (Cite solution_lesson_node_00081).
    *   **Encoder**: The sequence is processed by a **Standard Transformer Encoder** (2 layers, 4 heads).
        *   **Configuration**: Use **Post-Normalization** (`norm_first=False`) (Cite solution_lesson_node_00095).
        *   **Activation**: Explicitly set `activation="gelu"` (Cite solution_lesson_node_00068).
        *   **Regularization**: Apply **Low Dropout (0.1)** (Cite solution_lesson_node_00048).
    *   **Structural Innovation: Branch Normalization**:
        *   The output sequence is flattened and passed through a **LayerNorm** layer *before* concatenation.
        *   **Rationale**: Post-Norm Transformers have unbounded output variance that grows with depth. This layer strictly aligns the categorical signal's distribution with the unit-variance continuous features (Stream 2), ensuring the Linear Stem receives a balanced multi-modal signal. This resolves the fusion instability identified in Lesson 69 while avoiding the destructive Batch Normalization of Lesson 74.

2.  **Stream 2: Continuous Preservation**
    *   **Input**: The 30 numerical features are standardized.
    *   **Preservation**: Features are maintained in their **raw, normalized form** (Cite solution_lesson_node_00038).

3.  **Fusion Layer: The Linear Stem**
    *   **Concatenation**: The **Normalized Transformer Output** and the **Raw Continuous Features** are concatenated.
    *   **Linear Stem**: The concatenated vector is passed through a **Linear Projection Layer** to map to the backbone width (512) (Cite solution_lesson_node_00073).

4.  **Backbone: LayerScaled SwiGLU ResFunnel (Structural Innovation)**
    *   **Topology**: The backbone is organized into 3 stages (512 $\to$ 256 $\to$ 128) (Cite solution_lesson_node_00084).
    *   **Sustained Depth**: Each stage consists of **3 stacked Residual Blocks** (Cite solution_lesson_node_00070).
    *   **Blocks**: Use **LayerScaled Pre-Norm SwiGLU Blocks**.
        *   **Structure**: $x_{out} = x + \text{DropPath}(\text{LayerScale}(\text{Dropout}(\text{SwiGLU}(\text{Linear}(\text{LayerNorm}(x))))))$.
        *   **LayerScale**: Introduce a learnable diagonal scaling matrix (initialized to a small value, e.g., `1e-5`) that scales the residual branch output. This allows the network to behave closer to identity at initialization, facilitating the training of deeper/wider backbones and counteracting the saturation observed in Lesson 75.
        *   **Activation**: **SwiGLU** (Cite solution_lesson_node_00090).
        *   **Normalization**: **LayerNorm** (Cite solution_lesson_node_00087).
    *   **Transitions**: Use **Pre-Norm Transitions** (`LayerNorm -> Linear`) (Cite solution_lesson_node_00088).
    *   **Regularization**: Linear **Stochastic Depth** (0.0 to 0.2) (Cite solution_lesson_node_00086) + **Dropout (0.35)**.

5.  **Output Head**
    *   **Minimalist Design**: Single `Linear` layer with Sigmoid activation (Cite solution_lesson_node_00060).

# Data

1.  **Decomposition**: The string feature `f_27` is strictly split into 10 integer-encoded columns.
2.  **Normalization**: Continuous features (`f_00` - `f_30`) are Z-score normalized (StandardScaler).
3.  **Splitting**: Use the metadata-defined stratified validation split.
4.  **Volume**: Use the **Full Training Dataset** (640,000 samples) (Cite solution_lesson_node_00058).

# Training

1.  **Optimizer**: Use **AdamW**.
2.  **Strict Decoupled Weight Decay**:
    *   **Group 1 (Decay 1e-2)**: Weights of Linear layers, Embeddings, and Attention projections.
    *   **Group 2 (Decay 0.0)**: Biases, **LayerNorm parameters**, **Positional Embeddings**, and **LayerScale parameters**. Explicitly exclude LayerScale factors to prevent them from decaying to zero (Cite solution_lesson_node_00090, solution_lesson_node_00098).
3.  **Initialization**:
    *   **SwiGLU Blocks**: Use **Kaiming (He) Uniform** (Cite solution_lesson_node_00090).
    *   **Transformer**: Use **Xavier (Glorot)** (Cite solution_lesson_node_00082).
4.  **Optimization Granularity**:
    *   **Batch Size**: 1024 (Cite solution_lesson_node_00044).
    *   **Scheduler**: Aggressive Step Decay (factor 0.1 every 10 epochs) (Cite solution_lesson_node_00033).
5.  **Duration**: Train for **40 epochs** (Cite solution_lesson_node_00045).
6.  **Metric**: Monitor **Validation AUC** (Cite solution_lesson_node_00003).

# Evaluation

1.  **Inference**: Iterate through the test set using the trained LayerScaled-Fusion Hybrid SwiGLU Network.
2.  **Prediction**: Generate predictions using the single output head.
3.  **Submission**: The raw probability outputs are saved directly to the submission file.
