The implementation strategy is as follows:
1.  **Setup & Configuration**: Import the provided library modules. Set the random seed for reproducibility. Define training hyperparameters (20 epochs, 2048 batch size) to ensure the "fast baseline" requirement is met while utilizing the A100 GPU efficiently.
2.  **Training**: Invoke `library.train.run_training` with the adjusted hyperparameters. This handles the training loop, validation monitoring, and saving the best model.
3.  **Validation & Analysis**:
    *   Load the best model state from disk.
    *   Load the validation `DataLoader` using `library.data.get_dataloaders`.
    *   Run inference in `torch.no_grad()` mode to obtain predictions and ground truth targets.
    *   Compute and print the **Final Validation Metric** (AUC).
    *   Compute the absolute prediction error ($|y_{true} - y_{pred}|$).
    *   Calculate the Pearson correlation coefficient between the error and each continuous feature to identify features contributing to model failure. Print the top correlations.
4.  **Submission**: Compare the final AUC against the strict threshold (`0.9972336610045187`). If the model performance exceeds this threshold, call `library.train.generate_submission` to create the output file.
