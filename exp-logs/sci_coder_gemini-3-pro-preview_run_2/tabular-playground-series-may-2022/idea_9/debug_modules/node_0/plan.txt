Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override key parameters (epochs, batch size, working directory, and output paths) to ensure the script runs quickly and writes to a designated demo folder without overwriting existing work.
2.  **Data Loading**: Use `get_dataloaders` to load the dataset. To ensure the demonstration finishes within the time limit, I will create `Subset` wrappers around the datasets (Train, Validation, Test) to use only a small fraction of the data (e.g., 2000 samples).
3.  **Model Initialization**: Instantiate the `HybridAttentionResFunnel` model. I will perform a dummy forward pass with a single batch to verify the architecture and output shapes.
4.  **Training Loop**: Initialize the `Trainer` and call the `fit` method using the subsetted data loaders. This will demonstrate the training process, validation logging, and model checkpointing.
5.  **Submission Generation**: Use the trained model to generate predictions on the test subset using `trainer.generate_submission`.
6.  **Verification**: Throughout the script, I will use assertions to verify:
    *   Model output shapes.
    *   Existence of the saved model checkpoint.
    *   Existence and format (columns, value ranges) of the submission file.
