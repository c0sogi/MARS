The implementation strategy follows the standard machine learning workflow orchestrated through the provided library modules.

1.  **Configuration & Setup**: Initialize the environment by setting random seeds for reproducibility. We override specific `Config` parameters (like `EPOCHS`) to ensure the training fits within the "Fast Baseline" time constraints while utilizing the powerful A100 GPU.
2.  **Data Loading**: Leverage `get_dataloaders` to efficiently load the preprocessed training, validation, and test sets. We also retrieve `test_ids` from the cached data to align predictions later.
3.  **Model Training**: Instantiate the `HybridAttentionResFunnel` and `Trainer`. The training loop (`trainer.fit`) manages the optimization, learning rate scheduling, and early stopping based on Validation AUC.
4.  **Validation & Metric**: After training, load the best model checkpoint and perform a full evaluation on the validation set. The final AUC is printed strictly in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: We perform inference on the validation set to compute element-wise prediction errors. We then construct a DataFrame containing both continuous features and decomposed categorical tokens to calculate their Pearson correlation with the error magnitude. This identifies which features contribute most to model uncertainty.
6.  **Submission**: Conditional on the validation metric exceeding the specified threshold (0.9957464342157875), we generate predictions for the test set and save the submission file using the `trainer.generate_submission` method.
