The following script demonstrates the usage of the provided library files to solve the manufacturing control task. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to run in `DEBUG` mode with a small subset of data and fewer epochs, ensuring the script completes quickly.
2.  **Component Verification**:
    *   Validates the feature engineering logic (`decompose_f27`) to ensure character-to-integer mapping is correct.
    *   Instantiates the `ManufacturingDataset` and `DataLoader` to verify data shapes and types.
    *   Initializes the `WideDeepResFunnel` model and performs a forward pass with a dummy batch to confirm architecture correctness and output dimensions.
3.  **Pipeline Execution**: Runs the complete `train_model` pipeline, which includes data loading, training, validation, and submission generation.
4.  **Result Validation**: Verifies that the submission file is generated correctly and matches the expected format.
