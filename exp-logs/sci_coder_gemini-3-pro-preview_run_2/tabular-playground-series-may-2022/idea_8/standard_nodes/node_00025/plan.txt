Implementation Strategy:
The implementation orchestrates the full machine learning pipeline using the provided library modules. It begins by setting up the environment (seeds, device) and ensuring the output directory exists. Data is loaded using the cached `get_dataloaders` function for efficiency. The `WideDeepResFunnel` model is initialized and trained for a maximum of 20 epochs using `AdamW` and `BCEWithLogitsLoss`, with early stopping logic to save the best model based on validation AUC. After training, the best model is re-loaded to compute the final validation metric on the full hold-out set, which is printed in the required format. Failure analysis is performed by correlating prediction errors with input features. Finally, if the validation AUC exceeds the specified threshold, inference is run on the test set, and the submission file is generated at `./submission/submission.csv`.
