Based on the comprehensive empirical analysis and the derived lessons, I propose the implementation of a **Stem-Projected Sustained-Depth Hybrid Network**.

This strategy represents a structural synthesis that corrects the specific architectural flaws identified in the "Sustained Depth" (Idea 22) and "Rapid Funnel" (Idea 21) experiments. It unifies the superior **GELU-Transformer** for sequence modeling (Cite Lesson 68) with a **Pre-Activation Direct GLU** backbone (Cite Lesson 54). Crucially, it re-introduces a **Dedicated Input Stem** (Cite Lesson 73) and removes the detrimental **Fusion Normalization** (Cite Lesson 74), enabling the successful application of the **"Process-then-Compress"** topology (Cite Lesson 70) that previously failed due to connectivity errors.

# Model

The architecture is a dual-stream network that fuses a strictly configured sequence encoder with a raw continuous stream into a deep, sustained-depth residual backbone via a dedicated projection stem.

1.  **Stream 1: Categorical Sequence (GELU-Transformer)**
    *   **Input**: The `f_27` feature is decomposed into 10 distinct character tokens (Cite Lesson 1).
    *   **Embedding**: Tokens are passed through a shared embedding layer (dimension 32).
    *   **Positional Encoding**: **Learnable Positional Embeddings** are added to the token vectors to explicitly encode sequence order (Cite Lesson 30).
    *   **Encoder**: The sequence is processed by a **Standard Transformer Encoder** (2 layers, 4 heads).
        *   **Activation**: Explicitly set `activation="gelu"`. This corrects the performance regression caused by the default ReLU (Cite Lesson 68).
        *   **Regularization**: Apply **Low Dropout (0.1)** to preserve gradient flow in the attention mechanism (Cite Lesson 48).
        *   **Complexity**: Use standard Feed-Forward Networks, avoiding complex Gated variants or Conformer blocks in the encoder (Cite Lesson 46, Lesson 55).
    *   **Output**: The resulting sequence is flattened.

2.  **Stream 2: Continuous Preservation**
    *   **Input**: The 30 numerical features are standardized.
    *   **Preservation**: Features are maintained in their **raw, normalized form**. No early projection or tokenization is applied to avoid signal dilution (Cite Lesson 38).

3.  **Fusion Layer (Structural Correction)**
    *   **Concatenation**: The **Flattened Transformer Output** and the **Raw Continuous Features** are concatenated.
    *   **No Normalization**: Do **not** apply Batch Normalization immediately after concatenation, as this distorts the semantic signal of the embeddings (Cite Lesson 62, Lesson 74).
    *   **Dedicated Input Stem**: The concatenated vector is passed through a **Linear Projection Layer** to map the heterogeneous input dimensions to the backbone's hidden dimension (512). This decouples feature alignment from the first residual block, correcting the bottleneck identified in Lesson 73.

4.  **Backbone: Sustained-Depth Pre-Activation ResFunnel**
    *   **Topology**: The backbone is organized into 3 stages with progressively decreasing widths (512 $\to$ 256 $\to$ 128) (Cite Lesson 15).
    *   **Sustained Depth (Exploitation)**: Each stage consists of **3 stacked Residual Blocks** operating at constant width. This enforces the **"Process-then-Compress"** heuristic, allowing the model to refine features before discarding information (Cite Lesson 70).
    *   **Blocks**: Use **Pre-Activation Direct GLU Residual Blocks**.
        *   **Structure**: $x_{out} = x + \text{Dropout}(\text{GLU}(\text{Linear}(\text{BatchNorm}(x))))$.
        *   **Rationale**: Pre-Activation stabilizes gating (Cite Lesson 54). Direct GLU is efficient (Cite Lesson 51).
    *   **Regularization**: Apply **High Dropout (0.35)** within the backbone blocks to prevent memorization (Cite Lesson 16, Lesson 48).
    *   **Downsampling**: Transitions between stages use **Projected Residual Connections** to strictly preserve gradient flow (Cite Lesson 24).

5.  **Output Head**
    *   **Minimalist Design**: The final stage output is passed through a single `Linear` layer with Sigmoid activation. No additional Dropout or Batch Normalization is applied in the head (Cite Lesson 60).

# Data

1.  **Decomposition**: The string feature `f_27` is strictly split into 10 integer-encoded columns.
2.  **Normalization**: Continuous features (`f_00` - `f_30`) are Z-score normalized (StandardScaler).
3.  **Splitting**: Use the metadata-defined stratified validation split.
4.  **Volume**: Use the **Full Training Dataset** (640,000 samples). Do not subsample (Cite Lesson 58).

# Training

1.  **Optimizer**: Use **AdamW** with a high weight decay of `1e-2` (Cite Lesson 8).
2.  **Initialization**:
    *   Use **Kaiming (He) Uniform** for Linear layers (PyTorch default). Do not use Xavier for GLU blocks (Cite Lesson 71).
    *   Use **Xavier (Glorot)** for Transformer attention layers (PyTorch default).
    *   Explicitly initialize **Positional Embeddings** with **Random Noise** (Cite Lesson 72).
3.  **Optimization Granularity**:
    *   **Batch Size**: Use a reduced batch size of **1024** to improve generalization via gradient noise (Cite Lesson 44).
    *   **Scheduler**: Use an **Aggressive Step Learning Rate Scheduler** (decay by factor 0.1 every 10 epochs). This "shake-and-settle" dynamics is critical for high-precision convergence (Cite Lesson 33).
4.  **Duration**: Train for **40 epochs**. This ensures the model fully utilizes the final, lowest learning rate stage ($10^{-6}$) where significant ranking improvements occur (Cite Lesson 45).
5.  **Loss Function**: Use `BCEWithLogitsLoss` for numerical stability (Cite Lesson 68).
6.  **Metric**: Monitor **Validation AUC** for checkpointing, decoupling it from the loss function (Cite Lesson 3).

# Evaluation

1.  **Inference**: Iterate through the test set using the trained Stem-Projected Sustained-Depth Hybrid Network.
2.  **Prediction**: Generate predictions using the single output head.
3.  **Submission**: The raw probability outputs are saved directly to the submission file.
