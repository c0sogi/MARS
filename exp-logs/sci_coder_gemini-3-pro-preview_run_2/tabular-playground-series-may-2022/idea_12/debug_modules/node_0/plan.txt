Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and modify its attributes to define a separate working directory for the demo (`./working/demo_execution`) and enable `DEBUG` mode. This ensures the code runs on a small subset of the data (5,000 samples) and uses fewer epochs (2) to satisfy the time constraints.
2.  **Data Loading Demonstration**: Use `get_dataloaders` to load the data. Explicitly check the structure and shapes of the yielded batches (continuous features, sequences, targets) using assertions to verify the data pipeline is functioning correctly.
3.  **Model Verification**: Instantiate the `GlobalContextTransformerResFunnel` model. Perform a dummy forward pass with a batch of data to confirm the model architecture accepts the inputs and produces outputs of the correct shape and value range (probabilities between 0 and 1).
4.  **Training Execution**: Invoke the `run_training` function from the library. This demonstrates the full training loop, including loss calculation, backpropagation, validation, and model checkpointing.
5.  **Inference and Submission**: Call `generate_submission` to create predictions using the trained model.
6.  **Result Validation**: Load the generated submission CSV file. Verify its schema (columns `id`, `target`), value ranges, and ensure the IDs match the test set subset used during the debug run.
