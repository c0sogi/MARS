This script demonstrates the end-to-end usage of the provided machine learning library for the manufacturing control task. It performs the following steps:
1.  **Configuration Override**: Adjusts hyperparameters (epochs, batch size) and enables debug mode to ensure the demonstration runs quickly within the time limit.
2.  **Data Loading**: Uses `get_dataloaders` to load a subset of the data, verifying the shape and structure of the batches (categorical, continuous, and target tensors).
3.  **Model Initialization & Verification**: Instantiates the `ResGLUNet` model and performs a dummy forward pass to validate the input/output dimensions and value ranges.
4.  **Training Loop**: Uses the `Trainer` class to train the model for a few epochs, validating that the loss decreases and the model checkpoints are saved.
5.  **Inference**: Generates predictions on the test set and verifies the output format.
