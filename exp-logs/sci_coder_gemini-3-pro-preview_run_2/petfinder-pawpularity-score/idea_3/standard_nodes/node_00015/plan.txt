The issue is that the parameter grouping logic in `library/train.py` uses substring matching (`if "backbone" in n` and `if "head" in n`). The `convnext_large` model backbone contains parameters with "head" in their names (e.g., `backbone.norm_head`), causing them to satisfy both conditions and be added to multiple optimizer parameter groups, which triggers the `ValueError`.

To fix this, I will update the filtering logic to use strict prefix matching (`startswith("backbone")` and `startswith("head")`) since the `PawpularityModel` explicitly assigns the submodules to `self.backbone` and `self.head`. I will also add a check to skip training if the model checkpoint already exists to prevent re-training the already completed Swin Transformer folds.
