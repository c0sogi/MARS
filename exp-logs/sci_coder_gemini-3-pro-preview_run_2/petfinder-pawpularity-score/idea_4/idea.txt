# Strategy: Tri-Model Stacking with MIM-Pretrained Backbone

To surpass the performance of the heterogeneous ensemble, I propose a structural evolution that introduces a third distinct architectural family (Masked Image Modeling) and replaces the arithmetic mean aggregation with a learnable Stacking Meta-Model.

### Model
I will implement a **Two-Stage Stacking Ensemble**.

**Level 1: Diverse Base Learners**
The first stage consists of three high-capacity backbones, each pre-trained with a different objective or architectural philosophy to maximize error decorrelation.
1.  **Swin Transformer Large (384x384)**: Retained for its hierarchical attention mechanism which captures global semantic context (Cite solution_lesson_node_00016).
2.  **ConvNeXt Large (384x384)**: Retained for its pure CNN inductive bias, excelling at local texture and shape extraction (Cite solution_lesson_node_00016).
3.  **BEiT Large (384x384) (New)**: I will introduce a **BEiT (Bidirectional Encoder representation from Image Transformers)** backbone. Unlike Swin and ConvNeXt which use supervised ImageNet pre-training, BEiT is pre-trained using **Masked Image Modeling (MIM)** (similar to BERT in NLP). This objective forces the model to reconstruct image patches, learning robust structural representations that are often superior for downstream fine-tuning and complementary to supervised features.

All base learners will utilize the **Narrow MLP Head** (Cite solution_lesson_node_00013) to prevent overfitting and **Sigmoid activation** (Cite solution_lesson_node_00010) to enforce target bounds.

**Level 2: Meta-Learner**
Instead of the simple averaging used previously, I will implement a **Ridge Regression Meta-Learner**. This lightweight linear model will take the predictions from the base learners as input and output the final score. This allows the ensemble to learn the optimal weighting for each architecture rather than assuming equal importance.

### Data
1.  **Resolution**: All models will operate at **384x384** resolution to capture fine-grained aesthetic details (Cite solution_lesson_node_00017).
2.  **Preprocessing**: Images will be normalized using ImageNet statistics.
3.  **Augmentation**: I will strictly limit augmentation to **RandomHorizontalFlip**. Heavier augmentations like Mixup or ColorJitter will be excluded as they have been proven detrimental for this regression task (Cite solution_lesson_node_00005, solution_lesson_node_00009).
4.  **Target Scaling**: Targets will be scaled to the **[0, 1]** range to align with the Sigmoid output and stabilize gradients (Cite solution_lesson_node_00010).

### Training
The training will proceed in two distinct stages using **5-Fold Stratified Cross-Validation**:

**Stage 1: Base Learner Training**
*   Train 5 folds for each of the 3 architectures (15 models total).
*   **Loss Function**: **BCEWithLogitsLoss** will be used to optimize the probabilistic output (Cite solution_lesson_node_00010).
*   **Optimization**: Use **Differential Learning Rates** (lower for backbone, higher for head) (Cite solution_lesson_node_00006) and **Early Stopping** based on validation loss (Cite solution_lesson_node_00007).
*   **OOF Generation**: During training, generate and store **Out-Of-Fold (OOF)** predictions for every training sample. This creates a new dataset of shape `(N_train, 3)`, where the columns are the predictions from Swin, ConvNeXt, and BEiT.

**Stage 2: Meta-Learner Training**
*   Train the **Ridge Regression** model on the OOF prediction dataset.
*   The meta-learner learns to map the vector `[Pred_Swin, Pred_ConvNeXt, Pred_BEiT]` to the true target `Pawpularity`.

### Evaluation
1.  **Inference**: Pass each test image through all 15 trained base models.
2.  **Aggregation**:
    *   Calculate the arithmetic mean across the 5 folds for each architecture to get 3 robust architecture-level predictions per image.
    *   Feed these 3 values into the trained Ridge Meta-Learner to generate the final scalar prediction.
3.  **Post-Processing**: Rescale the output from [0, 1] back to [1, 100].
