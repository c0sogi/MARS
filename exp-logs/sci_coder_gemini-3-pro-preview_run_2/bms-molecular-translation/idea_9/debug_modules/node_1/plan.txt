The issue is caused by a stale vocabulary cache file (`vocab.npy`) in the working directory that was created with an older configuration missing the `<BLK>` token. When `InChiTokenizer` loads this cached file, it fails to find the index for `Config.CTC_BLANK`, resulting in a `KeyError`. The fix is to explicitly delete this cache file in `runfile.py` before initializing the tokenizer, forcing it to rebuild the vocabulary with the correct special tokens from the current configuration.
