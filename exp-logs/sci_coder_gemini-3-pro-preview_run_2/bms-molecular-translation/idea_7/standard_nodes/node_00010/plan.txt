The strategy for the `runfile.py` script is to orchestrate a fast but complete training and evaluation pipeline using the provided library components.

1.  **Setup & Configuration**: Initialize the environment with a fixed random seed for reproducibility. Modify the `Config` class to adapt to the "fast baseline" requirement and the available hardware (A100 GPU). Specifically, reduce `EPOCHS` to 1, increase `BATCH_SIZE` to 256 for high throughput, and utilize all 12 vCPUs for data loading.
2.  **Data Preparation**: Load the metadata DataFrames using `load_dataframe`. To ensure the training completes quickly, subset the training data to 50,000 samples and the validation subset (for monitoring) to 5,000 samples. Instantiate `ChemicalDataset` and `DataLoader` for these subsets.
3.  **Training**: Initialize the `ViT2InChI` model, `AdamW` optimizer, and `CrossEntropyLoss`. Execute the training loop for 1 epoch using `train_one_epoch`. Perform an intermediate validation step using `validate` and save the model checkpoint.
4.  **Full Validation & Failure Analysis**: Load the best saved model. Run inference on the **entire** hold-out validation set (approx. 380k samples) to compute the official "Final Validation Metric" (Levenshtein distance). Concurrently, collect predictions and ground truth lengths to calculate the correlation between sequence length and error rate, identifying if longer molecules are harder to predict.
5.  **Submission**: Generate predictions for the entire test set (approx. 480k samples) using the `predict_and_submit` function. Ensure the output is saved to the required `./submission/submission.csv` path.
