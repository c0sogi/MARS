Based on the dataset analysis and the requirement for a novel, efficient baseline distinct from previous ideas, I propose the **Pure Vision Transformer (ViT) for Sequence Generation**.

### Model
This approach establishes a modern, simplified baseline by eliminating Convolutional Neural Networks (CNNs) and Recurrent Neural Networks (RNNs) entirely. Instead, it treats the image-to-text task as a pure sequence-to-sequence translation problem using the Transformer architecture.

1.  **Patch-Based Visual Encoder**: The architecture employs a standard **Vision Transformer (ViT)** (e.g., a lightweight variant like `ViT-Tiny` or `ViT-Small`) as the encoder.
    *   **Patching**: The input chemical image is divided into a grid of fixed-size non-overlapping patches (e.g., $16 \times 16$ pixels).
    *   **Projection**: Each patch is flattened and linearly projected into a 1D embedding vector.
    *   **Position Embeddings**: Learnable 1D position embeddings are added to each patch embedding to retain spatial information (critical for distinguishing atom positions).
    *   **Self-Attention**: The sequence of patch embeddings is processed by a stack of Transformer Encoder layers. Unlike CNNs which process features locally, the ViT allows every patch to attend to every other patch from the first layer, capturing global molecular structures (like large rings or distant chains) efficiently.
2.  **Transformer Decoder**: The encoded sequence of visual patches is passed to a standard Transformer Decoder.
    *   It uses **Cross-Attention** to attend to the visual patch sequence.
    *   It uses **Masked Self-Attention** to model the autoregressive generation of the InChI string.
3.  **Prediction Head**: A linear layer projects the decoder output to the vocabulary size to predict the next character.

### Data
*   **Image Preprocessing**:
    *   **Resizing**: Images are resized to a standard resolution compatible with the ViT patch size (e.g., $224 \times 224$ or $384 \times 384$).
    *   **Channel Replication**: Since most pre-trained ViT models (available via `timm`) expect RGB inputs, the single-channel grayscale chemical images are replicated 3 times to form a pseudo-RGB image ($H \times W \times 3$). This allows the use of powerful pre-trained weights (e.g., ImageNet) without modifying the input projection layer.
    *   **Normalization**: Pixel values are normalized using standard ImageNet mean and standard deviation.
*   **Label Preprocessing**:
    *   InChI strings are tokenized at the character level.
    *   Special tokens `<SOS>` (Start of Sequence), `<EOS>` (End of Sequence), and `<PAD>` are added to the vocabulary.

### Training
*   **Loss Function**: The model is trained using **Cross-Entropy Loss**, minimizing the difference between the predicted character probability distribution and the ground truth character at each position.
*   **Optimizer**: The **AdamW** optimizer is used, which is standard for Transformers. A learning rate scheduler with a linear warmup phase followed by cosine decay is implemented to stabilize the training of the attention mechanisms.
*   **Strategy**: **Teacher Forcing** is utilized, where the decoder is fed the ground truth tokens from the previous step during the forward pass. This allows for highly efficient parallelized training (unlike RNNs which must be unrolled sequentially).

### Evaluation
*   **Inference**: The test image is passed through the ViT encoder to obtain the visual memory bank (sequence of patch embeddings).
*   **Decoding**: A **Greedy Decoding** loop is used for speed.
    1.  The decoder is initialized with the `<SOS>` token.
    2.  At each step, the token with the highest probability is selected.
    3.  This token is appended to the sequence and fed back into the decoder.
    4.  The process terminates when the `<EOS>` token is generated or a maximum length (e.g., 400 characters) is reached.
