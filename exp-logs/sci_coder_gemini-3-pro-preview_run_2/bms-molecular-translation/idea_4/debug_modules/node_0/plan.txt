Based on the provided library files, I have implemented a self-contained Python script to demonstrate the utilization of the `Tokenizer`, `Dataset`, `Model`, and training/inference pipelines.

### Implementation Strategy
1.  **Configuration Override**: The script modifies the `Config` class at runtime to enable `DEBUG` mode, reduce `EPOCHS` to 1, set a small `BATCH_SIZE`, and limit the `DEBUG_SAMPLE_SIZE`. This ensures the script executes quickly (within a few minutes) while still exercising all code paths.
2.  **Tokenizer Verification**: It instantiates the `Tokenizer` (forcing a rebuild from metadata to verify logic), checks vocabulary size, and verifies the round-trip conversion from text to sequence and back.
3.  **Data Loading**: It utilizes `get_train_dataloader` to load a batch of data. It asserts that the image tensor shapes matches `(B, 1, 320, 320)` and caption shapes match `(B, 450)`.
4.  **Model Execution**: It initializes the `ShowAttendTell` model and performs a forward pass in both training mode (with teacher forcing) and inference mode (greedy decoding). It validates the output tensor shapes.
5.  **Training & Validation**: It runs `train_one_epoch` and `validate` using the small debug dataset to ensure the optimization step, loss calculation, and Levenshtein metric computation function correctly without errors.
6.  **Inference**: It simulates the inference process on a batch from the test dataloader to verify that predictions can be generated and decoded into strings.
