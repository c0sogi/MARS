Implementation strategy:
1.  **Configuration**: Override default configuration parameters to create a "Fast Baseline". Enable `DEBUG` mode with a sample size of 20,000 and limit training to 5 epochs. Increase batch size to 96 to utilize the A100 GPU efficiently.
2.  **Setup**: Initialize the Tokenizer (loading from cache), DataLoaders, and the GFCN model. Define the Adam optimizer and ReduceLROnPlateau scheduler.
3.  **Training Loop**: Implement the training loop explicitly (mirroring `library.train`) to retain control. Train for the specified epochs, performing validation at each step, and saving the best model based on Levenshtein distance.
4.  **Failure Analysis**: After training, load the best model. Perform a detailed inference pass on the validation set. Calculate Levenshtein distance for each sample. Extract metadata (image width, height, target length) from the validation dataset and compute Pearson correlations between these features and the prediction error.
5.  **Submission**: Generate predictions for the test set using the best model and save to `submission.csv`.
6.  **Output**: Print the final validation metric and failure analysis correlations as required.
