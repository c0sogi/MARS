The following script performs Exploratory Data Analysis (EDA) on the training dataset. It is adapted for an Image-to-Text task (Image Captioning/OCR for chemical structures).

**Strategy:**
1.  **Setup & Data Loading**: Initialize the environment with a fixed random seed and load the training metadata generated in the previous step.
2.  **Target Analysis (Text)**: Analyze the `InChI` strings from the metadata. This includes calculating the distribution of string lengths (character count) and determining the unique vocabulary (character set) required for the model.
3.  **Input Analysis (Image)**: Since the dataset is large (~1.5M images), we will randomly sample 5,000 images to estimate global statistics. We will analyze image dimensions (width, height, aspect ratio), channel counts, and pixel intensity statistics (mean, std).
4.  **Relationship Analysis**: Investigate correlations between image meta-features (e.g., file size, dimensions) and the target text length. For instance, determining if larger images tend to contain longer InChI strings (implying more complex molecules).
5.  **Reporting**: Output the findings in a structured, readable text format as specified.
