The solution implements the `runfile.py` script to orchestrate the forest cover type prediction pipeline. It leverages the provided library modules for configuration, data management, and model training. The script proceeds in four main stages:

1.  **Data Loading**: Utilizes `data_manager.load_dataset` to efficiently load the pre-processed Parquet files for training, validation, and testing.
2.  **Model Training**: Instantiates the `GradientBoostingTrainer` and executes the training process using LightGBM with the configuration defined in `Config`. This includes early stopping to ensure efficiency.
3.  **Validation & Analysis**: Performs inference on the validation set to compute the multi-class accuracy. It then conducts a failure analysis by correlating the binary error vector (correct vs. incorrect) with input features to identify systematic weaknesses.
4.  **Submission**: Generates predictions for the test set, maps the internal 0-indexed class labels back to the original `Cover_Type` values using `LabelMapper`, and saves the final submission file.

The script ensures reproducibility by adhering to the fixed seeds in the configuration and optimizes runtime by using the pre-configured GPU settings.
