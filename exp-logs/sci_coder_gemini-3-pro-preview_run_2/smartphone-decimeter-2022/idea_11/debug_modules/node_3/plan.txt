The `ValueError: not enough values to unpack (expected 3, got 1)` occurs in `library/data_loader.py` because the `X_test` array is empty (shape `(0,)`) when the code attempts to unpack its shape into `N, W, F`. This happens because inside the test data processing loop, the processed window data (`window_data`) is appended to a local list `trip_X` instead of the main accumulator list `X_list`. As a result, `X_list` remains empty after processing all trips, leading to an empty dataset array.

To fix this, I will modify `library/data_loader.py` to append `window_data` directly to `X_list`.
