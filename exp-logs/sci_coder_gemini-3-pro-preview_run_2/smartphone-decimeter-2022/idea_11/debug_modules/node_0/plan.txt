Implementation strategy:
1.  **Setup Configuration**: Import the `Config` class and override key parameters (`WORKING_DIR`, `EPOCHS`, `BATCH_SIZE`, `DEBUG_SAMPLE_SIZE`) to create a lightweight execution environment (`./working/demo_run`). Update dependent path attributes in `Config` to reflect the new working directory.
2.  **Training Demonstration**: Call `train_model` with `load_cached_data=False` and a small `debug_sample_fraction`. This triggers the raw data processing pipeline (GNSS/IMU aggregation), dataset creation, and a short training loop.
3.  **Validation**: Assert that the model artifact (`best_model.pth`) and scaler configuration (`scaler.json`) are created successfully.
4.  **Inference Demonstration**: Call `generate_submission` with `load_cached_data=False`. This processes the test set, loads the trained model, performs inference, and generates the submission CSV.
5.  **Final Verification**: Check the existence and dimensions of the generated submission file to ensure the pipeline ran to completion and produced valid output.
