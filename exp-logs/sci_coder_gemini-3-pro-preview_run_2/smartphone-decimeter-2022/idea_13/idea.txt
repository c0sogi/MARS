Based on the accumulated lessons, I propose the **Multi-Scale Kinematic CNN with Environmental Gating**. This solution introduces a structural innovation by processing the trajectory using parallel convolutional filters of varying kernel sizes to capture multi-frequency motion patterns, while simultaneously injecting environmental context (derived from satellite geometry) to correct systematic biases without spatial overfitting.

### Model
**Architecture: Multi-Scale Sequence-to-Point 1D-CNN**
The model uses a dual-stream approach to fuse local kinematic smoothing with environmental state awareness.

1.  **Kinematic Stream (Multi-Scale Backbone):**
    *   **Input:** A sliding time-series window of size $N$ (e.g., 15 epochs).
    *   **Multi-Scale Convolutions:** The input sequence is passed through three parallel **1D Convolutional layers** with different kernel sizes (e.g., $k=3, 5, 7$). This design allows the model to simultaneously act as a low-pass filter (smoothing trajectory jitter) and a high-pass filter (detecting sudden stops or turns) **Cite solution_lesson_node_00013**.
    *   **Feature Aggregation:** The outputs of the parallel branches are concatenated channel-wise.
    *   **Center Extraction:** Crucially, instead of Global Average Pooling (which destroys temporal alignment **Cite solution_lesson_node_00032**), the feature vector corresponding specifically to the **center timestamp** of the window is extracted.

2.  **Environmental Context Stream (MLP):**
    *   **Input:** A vector of aggregated **Satellite Geometry Statistics** for the window (e.g., Mean Satellite Elevation, Azimuth Spread, and Mean Signal Strength).
    *   **Purpose:** This stream serves as a proxy for the environmental state (e.g., "Deep Urban Canyon" vs. "Open Highway"). By using satellite geometry instead of absolute coordinates, the model can learn state-dependent bias corrections **Cite solution_lesson_node_00011** while strictly preventing the spatial overfitting observed with geospatial inputs **Cite solution_lesson_node_00017**.

3.  **Fusion & Prediction Head:**
    *   The extracted center kinematic features and the environmental context embedding are concatenated.
    *   A Multi-Layer Perceptron (MLP) projects this fused representation to a 2D output vector: the residual correction ($\Delta$East, $\Delta$North) in meters.

### Data
**Preprocessing Pipeline:**
1.  **Target Transformation:** Calculate ground truth residuals in a local metric frame (ENU - East, North, Up). The target is the difference in **meters** between the Ground Truth and the WLS baseline **Cite solution_lesson_node_00001**.
2.  **Sequence Feature Engineering:**
    *   **Window-Relative Coordinates:** For each window, subtract the WLS Latitude/Longitude/Altitude of the *center* timestamp from all steps. Convert these differences to meters using **Simple Element-wise Scaling** (e.g., $\Delta Lat^\circ \times 111,320$). This preserves the geometric shape of the path while ensuring translation invariance and avoiding the numerical instability of complex projections **Cite solution_lesson_node_00020**.
    *   **Dynamics:** Explicitly include first-order differences (velocities) for Latitude, Longitude, and **Altitude**. Vertical dynamics are retained as a critical orthogonal signal for detecting GNSS anomalies **Cite solution_lesson_node_00005**, **Cite solution_lesson_node_00006**.
    *   **Signal Metrics:** Include standardized Cn0 and Uncertainty estimates for each timestep.
3.  **Context Feature Engineering:**
    *   Aggregate `SvElevationDegrees` from the raw logs. Compute the mean and standard deviation for the window. Low mean elevation is a strong indicator of urban canyon multipath.
4.  **Windowing:** Use a short sliding window (e.g., 15 seconds) to prevent overfitting to long-term trajectory signatures **Cite solution_lesson_node_00010**.
5.  **Normalization:** Apply Standard Scaling (Z-score) to all inputs.

### Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss is selected for its robustness to the extreme outliers (multipath effects) inherent in the dataset.
*   **Optimizer:** **AdamW** optimizer with a `ReduceLROnPlateau` learning rate scheduler to ensure stable convergence.
*   **Regularization:** Apply Batch Normalization within the CNN blocks and Dropout in the Fusion MLP.

### Evaluation
**Inference Process:**
1.  **Preprocessing:** Apply the same windowing, relative-centering, simple scaling, and geometry aggregation steps to the test data.
2.  **Prediction:** Feed the processed windows into the model to predict the metric residuals ($\Delta$East, $\Delta$North).
3.  **Reconstruction:** Convert the predicted metric residuals back to decimal degrees using the local approximation factors derived from the test sample's latitude. Add these corrections to the baseline WLS Latitude/Longitude to generate the final submission.
