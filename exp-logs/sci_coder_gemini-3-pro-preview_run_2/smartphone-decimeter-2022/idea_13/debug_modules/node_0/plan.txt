The following script demonstrates the usage of the provided GNSS positioning library. It covers:
1.  **Utility Verification**: Testing coordinate conversion functions.
2.  **Data Loading**: Initializing the preprocessor and dataloader with a small subset of data for speed (`max_samples=100`, `load_cached_data=False`).
3.  **Model Instantiation**: Creating the `MultiScaleKinematicCNN` model.
4.  **Training Loop**: Running a single epoch of training using the `library.engine.fit` function.
5.  **Inference**: demonstrating a forward pass and checking output shapes.
