An outline of the implementation strategy:

1.  **Setup**: Initialize the environment, set random seeds for reproducibility, and define the computation device (GPU).
2.  **Data Loading**: Use the provided `get_dataloader` function to load training and validation datasets. Ensure `shuffle=False` for validation to maintain alignment with metadata.
3.  **Model Initialization**: Instantiate the `MultiScaleKinematicCNN` model and move it to the device.
4.  **Training**: Use the `fit` function from the engine to train the model. This handles the training loop, validation, learning rate scheduling, and saving the best model checkpoint.
5.  **Validation & Metric Calculation**:
    *   Load the best saved model state.
    *   Run inference on the validation set to get predicted residuals.
    *   Retrieve target residuals from the dataset.
    *   Compute the Euclidean distance error (in meters) between predictions and targets.
    *   Aggregate errors by `tripId` to compute the competition-specific metric (mean of 50th and 95th percentiles).
6.  **Failure Analysis**:
    *   Extract environmental context features from the validation set.
    *   Calculate the correlation between the prediction errors and these context features to identify failure modes (e.g., low signal strength, poor satellite geometry).
7.  **Submission**:
    *   Check if the validation score meets the threshold (< 4.2569...).
    *   If successful, invoke `generate_submission` to process the test set, reconstruct global coordinates, and save the `submission.csv` file.
