Additionally, the `runfile.py` script modifies the `config` module at runtime (monkey-patching) to point to demonstration datasets. If `preprocessing.py` were to import these variables directly (e.g., `from library.config import TRAIN_METADATA_PATH`), it would capture their original values at import time, ignoring the runtime updates made by `runfile.py`. To fix the error and ensure the preprocessing pipeline uses the correct, patched configuration, `preprocessing.py` must import the `config` module itself and access the variables as attributes (e.g., `config.TRAIN_METADATA_PATH`) Cite debug_lesson_3.
