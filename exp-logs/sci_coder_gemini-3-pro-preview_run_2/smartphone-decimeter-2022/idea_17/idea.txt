Based on the accumulated lessons, particularly the trade-off between the need for environmental bias correction and the risk of spatial overfitting, I propose the **Sky-Contextualized Relative-Motion CNN (SCR-CNN)**.

This solution structurally evolves the successful Windowed MLP (Idea 1) and the Dual-Stream concepts (Idea 16) by replacing the kinematic MLP with a **Shallow 1D-CNN**. This leverages the inductive bias of convolutions for smoothing trajectory noise (filtering) while maintaining the center-focused temporal alignment that previous pooling-based CNNs lost. It simultaneously uses a satellite geometry stream to correct environmental biases without memorizing absolute coordinates.

### Model
**Architecture: Dual-Stream Sequence-to-Point Network**
The model processes a temporal window of sensor data to predict the residual correction for the *center* timestamp using two specialized branches.

1.  **Kinematic Stream (Shallow 1D-CNN):**
    *   **Input:** A sliding time-series window of size $N$ (e.g., 15 epochs). Features include **Window-Relative Coordinates** (meters), **Dynamics** (Velocity/Deltas), and **Signal Metrics** (Cn0).
    *   **Backbone:** A shallow stack of **Residual 1D Convolutional Layers** (2-3 layers). Unlike an MLP, the CNN explicitly learns local smoothing filters (like a learnable moving average) to reduce jitter while preserving the trajectory's geometric shape **Cite solution_lesson_node_00013**.
    *   **Temporal Preservation:** Crucially, **Global Pooling is strictly avoided**. The output of the CNN is **flattened**. This preserves the specific feature representation of the *center* timestamp and its immediate neighbors, ensuring the model can distinguish the target moment from the context **Cite solution_lesson_node_00032**.

2.  **Sky-Context Stream (MLP):**
    *   **Input:** A vector of aggregated **Satellite Geometry Statistics** for the window (e.g., Mean/Std of Satellite Elevation and Azimuth, Signal Strength distribution).
    *   **Purpose:** This stream creates an embedding of the environmental state (e.g., "High Occlusion" vs. "Open Sky"). By relying on satellite configuration rather than absolute Latitude/Longitude, the model learns to correct state-dependent biases **Cite solution_lesson_node_00011** while strictly preventing spatial overfitting to training locations **Cite solution_lesson_node_00017**.

3.  **Fusion Head:**
    *   The flattened kinematic features and the sky-context embedding are concatenated.
    *   A Multi-Layer Perceptron (MLP) projects this fused vector to a 2D output: the residual correction ($\Delta$East, $\Delta$North) in meters.

### Data
**Preprocessing Pipeline:**
1.  **Target Transformation:** Calculate ground truth residuals in a local metric frame (Meters). The target is the difference between Ground Truth and the WLS Baseline **Cite solution_lesson_node_00001**.
2.  **Sequence Feature Engineering:**
    *   **Relative Centering:** For each window, subtract the WLS Latitude/Longitude/Altitude of the *center* timestamp from all steps.
    *   **Simple Scaling:** Convert these relative differences to meters using simple element-wise scaling (e.g., $\Delta Lat^\circ \times 111,320$). This avoids the numerical instability of complex ECEF/ENU projections on noisy data **Cite solution_lesson_node_00020**.
    *   **Dynamics:** Explicitly include first-order differences (velocities) for Latitude, Longitude, and **Altitude**. Vertical dynamics serve as a critical orthogonal signal for detecting GNSS anomalies **Cite solution_lesson_node_00005**, **Cite solution_lesson_node_00006**.
3.  **Windowing:** Use a short sliding window (e.g., 15 seconds) to capture local motion context without overfitting to long-term trajectory signatures **Cite solution_lesson_node_00010**.
4.  **Filtering:** Train only on windows where the center timestamp has valid ground truth. **Do not use interpolation** to fill gaps, as this creates artificial error signals **Cite solution_lesson_node_00035**.
5.  **Normalization:** Apply Standard Scaling (Z-score) to all inputs.

### Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss is selected for its robustness to the extreme outliers (multipath effects) inherent in the dataset.
*   **Optimizer:** **AdamW** optimizer with a `ReduceLROnPlateau` learning rate scheduler.
*   **Strategy:** Train on the **full dataset**. Simple models trained on all data outperform complex models trained on subsets **Cite solution_lesson_node_00040**.
*   **Cache Safety:** Use configuration hashing for data caching to prevent training on stale features **Cite solution_lesson_node_00037**.

### Evaluation
**Inference Process:**
1.  **Preprocessing:** Apply the same windowing, relative-centering, simple scaling, and sky-context aggregation steps to the test data.
2.  **Prediction:** Feed the processed windows into the SCR-CNN to predict the metric residuals ($\Delta$East, $\Delta$North).
3.  **Reconstruction:** Convert the predicted metric residuals back to decimal degrees using the local approximation factors derived from the test sample's latitude. Add these corrections to the baseline WLS Latitude/Longitude to generate the final submission.
