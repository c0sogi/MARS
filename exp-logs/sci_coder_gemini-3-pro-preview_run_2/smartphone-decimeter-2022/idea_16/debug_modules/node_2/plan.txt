The `TypeError` in the `DataLoader` arises because the `GNSSWindowDataset.__getitem__` method returns a dictionary containing a `"meta"` key, which holds a NumPy array of objects (strings for trip IDs, etc.). PyTorch's default collation function cannot batch these object arrays into tensors. To fix this, I will modify `library/data_loader.py` to remove the `"meta"` key from the sample dictionary returned by `__getitem__`. The metadata is still preserved in the `self.meta` attribute of the dataset object, which is correctly accessed directly during inference in `library/inference.py`, so removing it from the training/validation batches resolves the error without breaking downstream logic.
