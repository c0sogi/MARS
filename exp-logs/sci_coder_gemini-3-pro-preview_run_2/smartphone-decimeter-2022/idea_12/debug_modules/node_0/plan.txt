Implementation strategy:
1.  **Environment Setup**: Import necessary libraries and suppress warnings. Mock `tqdm` to comply with the requirement of not printing progress bars.
2.  **Configuration Override**: Subclass or modify the `Config` class attributes at runtime to point to a temporary demo directory (`./working/demo`) and use reduced hyperparameters (1 epoch, small batch size) for speed.
3.  **Data Preparation**: Read the original metadata files, select a very small subset of trips (1 for train, 1 for val, 1 for test), and save these as new metadata CSVs in the demo directory. This ensures the pipeline runs on real data but finishes quickly.
4.  **Utility Verification**: Execute assertions on provided utility functions (`haversine_distance`, coordinate conversions) to verify correctness.
5.  **Model Verification**: Instantiate the `SkyContextualizedCNN` model with dummy tensors to verify the forward pass and output shapes.
6.  **Pipeline Execution**:
    *   Run `train_model(load_cached_data=False)` to process the subset data, cache it, and train the model.
    *   Run `generate_submission(load_cached_data=False)` to generate predictions on the test subset.
7.  **Result Validation**: Assert that the model file and submission file are created and that the submission format matches expectations.
