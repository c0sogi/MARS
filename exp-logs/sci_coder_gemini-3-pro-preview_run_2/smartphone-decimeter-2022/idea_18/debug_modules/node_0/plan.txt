This script demonstrates the end-to-line pipeline for the GNSS positioning task using the provided library. It performs the following steps:
1.  **Setup**: Configures a temporary working directory and overrides default configuration parameters (epochs, batch size) to ensure a fast run.
2.  **Data Subsetting**: Creates small subsets of the provided metadata (Train, Validation, Test) to limit the amount of data processed.
3.  **Preprocessing**: Uses `GNSSPreprocessor` to load raw GNSS data, engineer features, and create sliding windows for the subsetted data.
4.  **Dataset Verification**: Instantiates `SKFDataset` and verifies the shape of the tensors produced.
5.  **Model Verification**: Instantiates `SKFNet`, performs a forward pass with dummy data, and validates output dimensions.
6.  **Training**: Uses `Trainer` to train the model for a few epochs on the subset data.
7.  **Inference**: Uses `InferenceEngine` to generate predictions and a submission file for the test subset.
