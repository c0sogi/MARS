Implementation strategy:
1.  **Environment Setup**: Create a temporary directory structure to store subset metadata and outputs, ensuring the original `./input` directory remains untouched.
2.  **Configuration Override**: Import the `Config` class and monkey-patch its attributes (paths, epochs, batch size) to point to the temporary directory and use minimal hyperparameters for speed.
3.  **Data Subsetting**: Read the original metadata files, select a single trip for training, validation, and testing, and save these subsets to the temporary directory. This ensures the pipeline runs on a tiny fraction of the data.
4.  **Pipeline Execution**:
    *   **Data Loading**: Call `get_dataloaders` to process the raw data from the subset metadata. Verify the shape of the resulting batches.
    *   **Model Initialization**: Instantiate the `BiGRUModel` and perform a dummy forward pass to verify architecture and tensor shapes.
    *   **Training**: Initialize the `Trainer` and run the training loop for 1 epoch. Verify that the model checkpoint is saved.
    *   **Inference**: Generate a submission file using the trained model on the test subset. Verify the output file format and dimensions.
5.  **Cleanup**: Remove the temporary directory.
