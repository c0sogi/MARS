This script orchestrates the Relative-Trajectory 1D-CNN pipeline. It first trains the model using the provided trainer module. Then, it performs a detailed validation on the hold-out set, reconstructing absolute coordinates from the predicted local residuals to calculate the competition-specific metric (mean of 50th and 95th percentile errors). It also conducts a failure analysis by correlating prediction errors with signal quality metrics. Finally, if the validation score meets the required threshold, it generates the submission file for the test set.
