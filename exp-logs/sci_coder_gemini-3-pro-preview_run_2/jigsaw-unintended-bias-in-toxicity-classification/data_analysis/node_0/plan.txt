The following script performs a robust Exploratory Data Analysis (EDA) on the training dataset for the toxicity classification task.

**Strategy:**
1.  **Setup & Loading**: We set random seeds for reproducibility and load the training metadata from `./metadata/train.csv`. We then load the text content from `./input/train.csv` (using only necessary columns) and merge it with the metadata to create a complete training dataframe without data leakage from validation/test sets.
2.  **Target Analysis**: We analyze the `target` column, treating it both as a continuous variable (regression perspective) and a binary variable (classification perspective with threshold 0.5), reporting distribution statistics and class imbalance.
3.  **Text Data Analysis**: We compute text-specific metrics:
    *   **Sequence Lengths**: Character and word counts.
    *   **Vocabulary**: We estimate vocabulary size and unique token counts using a whitespace tokenizer.
4.  **Tabular/Identity Analysis**: We analyze the identity columns (e.g., `male`, `female`, `black`, `white`) which are crucial for the bias mitigation task. We report their sparsity (how often they are non-zero) and distribution.
5.  **Feature Relationships**:
    *   **Correlations**: We calculate Pearson correlations between the target, text lengths, and identity attributes.
    *   **Meta-Feature Analysis**: We investigate if comment length correlates with toxicity.
6.  **Output**: The results are printed in the requested format with capitalized sections and 4-decimal precision.
