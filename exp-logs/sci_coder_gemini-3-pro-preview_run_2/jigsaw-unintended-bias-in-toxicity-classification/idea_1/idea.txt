To establish a robust and highly efficient baseline, I propose a **Multi-Task Bidirectional LSTM** model. This approach prioritizes speed and structural simplicity while directly addressing the bias mitigation requirement through auxiliary supervision.

### Model
The architecture is designed to decouple the concept of "identity mentions" from "toxicity" by forcing the model to learn them as separate tasks sharing the same feature extractor.
*   **Embedding Layer:** A trainable embedding layer maps tokenized words to dense vectors.
*   **Encoder:** A single-layer Bidirectional Long Short-Term Memory (Bi-LSTM) unit processes the sequence. This captures sequential dependencies and context (e.g., negation) better than bag-of-words models but is significantly faster and lighter than Transformer-based architectures.
*   **Aggregation:** A Global Max Pooling layer extracts the most salient features from the LSTM hidden states across the time dimension.
*   **Multi-Task Heads:** The pooled features feed into two separate fully connected output heads:
    1.  **Toxicity Head:** A single neuron with a sigmoid activation to predict the main `target` toxicity score.
    2.  **Identity Head:** A dense layer with 9 neurons (one for each identity subgroup) and sigmoid activations. This head predicts the presence of the specific identity attributes (e.g., "male", "female", "muslim").
*   **Rationale:** By training the shared LSTM to predict both toxicity and identity tags simultaneously, the model learns to recognize identity terms (to satisfy the Identity Head) without necessarily associating them directly with toxicity (unless the Toxicity Head requires it), thereby reducing correlation bias.

### Data
*   **Text Preprocessing:** The `comment_text` will be processed using a standard tokenizer to convert text into sequences of integers. We will limit the vocabulary to the top frequent words (e.g., 20,000 - 50,000) to keep the model lightweight. Sequences will be padded or truncated to a fixed length (e.g., 250 tokens) to allow for efficient batch processing.
*   **Label Processing:**
    *   **Main Target:** The provided fractional `target` column will be used directly as soft labels for the Toxicity Head.
    *   **Auxiliary Targets:** The 9 identity columns (e.g., `male`, `female`, etc.) will be converted into binary labels (1 if the value is $\ge 0.5$, else 0) to serve as targets for the Identity Head.
    *   **Test Data:** The test set `id`s will be mapped to their corresponding text in `input/test.csv`, tokenized, and padded using the same parameters as the training set.

### Training
*   **Loss Function:** We will use a weighted Multi-Task Loss.
    *   $L_{total} = L_{toxicity} + \lambda L_{identity}$
    *   Both components will use **Binary Cross Entropy (BCE)**. BCE is suitable for the fractional toxicity targets (acting as soft labels) and the multi-label identity classification.
    *   $\lambda$ is a hyperparameter (e.g., 0.5) to balance the influence of the auxiliary task.
*   **Optimizer:** The Adam optimizer will be used for its adaptive learning rate capabilities, ensuring fast convergence.
*   **Strategy:** We will train for a small number of epochs (e.g., 3-5) with Early Stopping based on the validation loss of the Toxicity Head. This ensures we do not overfit to the training noise while maintaining a short runtime.

### Evaluation
*   **Inference:** The trained model will process the preprocessed test data. We will only extract the output from the **Toxicity Head** for the final submission.
*   **Post-Processing:** The resulting probability scores will be paired with their corresponding `id`s and formatted into the required CSV structure for submission.
