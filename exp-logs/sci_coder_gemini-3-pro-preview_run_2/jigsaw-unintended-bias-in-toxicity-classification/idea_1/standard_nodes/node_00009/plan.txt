The `UnboundLocalError` occurs because the variable `submission_df` is defined only within the `if` block (when the score threshold is met) but is accessed unconditionally after the `if/else` structure. When the `else` branch is taken, `submission_df` remains undefined, causing the crash when `submission_df.shape` is called. To fix this, I will move the verification code (printing shape and head) inside the `if` block, ensuring it is only executed when `submission_df` has been successfully created. This adheres to the principle of ensuring variables are defined in the control path before access (Cite debug_lesson_1).
