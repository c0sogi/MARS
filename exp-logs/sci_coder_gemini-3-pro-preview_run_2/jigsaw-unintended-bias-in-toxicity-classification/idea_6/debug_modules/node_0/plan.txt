The following implementation demonstrates the end-to-end usage of the provided library files. It performs the following steps:
1.  **Configuration Override**: Modifies the `Config` class at runtime to enable `DEBUG` mode, reduce the dataset size, and set up a temporary working directory. This ensures the script runs quickly (within minutes) while exercising all code paths.
2.  **Data Loading**: Uses `load_datasets` to process the raw metadata and text into memory-mapped numpy arrays and PyTorch Datasets.
3.  **Model & Training**: Instantiates the `ToxicityModel`, `WeightedMultiTaskLoss`, and `Engine`. It runs a single training epoch on the small debug subset.
4.  **Evaluation**: Evaluates the model on the validation set and prints the bias metrics.
5.  **Prediction**: Generates predictions for the test set.
6.  **Metric Logic Verification**: Independently verifies the `BiasMetricCalculator` using synthetic data to ensure the bias metrics (Subgroup AUC, BPSN, BNSP) and the generalized mean logic are functioning correctly.
