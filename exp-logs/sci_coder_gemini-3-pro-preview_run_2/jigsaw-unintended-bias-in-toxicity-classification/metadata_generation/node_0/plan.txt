The strategy for generating the metadata is as follows:

1.  **Setup and Loading**: Define the input (`./input`) and output (`./metadata`) directories. Load the `train.csv` dataset using pandas.
2.  **Preprocessing for Split**: Create a binary stratification label (`is_toxic`) derived from the continuous `target` column (threshold $\ge 0.5$), as the task requires stratifying by the target label and the primary metric relies on this binary distinction.
3.  **Stratified Split**: Use `StratifiedShuffleSplit` with a fixed random state (42) to split the training data into 80% training and 20% validation sets. This ensures the class distribution is preserved.
4.  **Metadata Generation**:
    *   For the **Train** and **Validation** sets: Create metadata DataFrames containing the `id`, `target` (ground truth), identity attributes, and a `source_file` column pointing to `train.csv`. To adhere to the "metadata" concept and avoid data duplication, the large `comment_text` column is excluded.
    *   For the **Test** set: Load `test.csv`, create a metadata DataFrame with `id` and `source_file` pointing to `test.csv`, excluding the text.
    *   Save these DataFrames as `.csv` files in the `./metadata` directory.
5.  **Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (row counts, class distributions).
    *   **File Path Check**: Randomly sample 1000 rows from each metadata file and verify that the relative path in `source_file` resolves to an existing file in `./input`.
    *   **Split Validation**: Programmatically assert that the validation split ratio is approximately 20% and that the positive class prevalence in the validation set matches the training set (stratification check).
