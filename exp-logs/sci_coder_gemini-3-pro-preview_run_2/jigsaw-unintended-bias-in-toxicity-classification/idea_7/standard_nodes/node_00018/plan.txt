The implementation strategy focuses on building a robust yet efficient pipeline to train a RoBERTa-Large model with a custom Hybrid Contrastive Loss. To satisfy the "Fast Baseline" requirement within the 2-hour limit, the training data is subsampled to 150,000 examples, which allows for approximately 3 epochs of training on an NVIDIA A100 GPU. The pipeline leverages Stochastic Weight Averaging (SWA) to stabilize the model and improve generalization on the bias metrics.

**Strategy Outline:**
1.  **Setup & Data Loading**: Initialize the environment with fixed seeds. Load the pre-processed dataloaders using `library.data`. Subsample the training dataset to 150,000 samples using `torch.utils.data.Subset` to ensure the training completes quickly.
2.  **Model Configuration**: Instantiate the `MultiTaskRoBERTa` model. Set up the `AdamW` optimizer and a linear learning rate scheduler with warmup. Initialize the `AveragedModel` for SWA to be applied in later epochs.
3.  **Training Loop**: Execute a 3-epoch training loop. In each epoch, run the training step using `library.engine.train_one_epoch`, update SWA parameters (starting from epoch 2), and validate the model using `library.engine.valid_fn`. The best model based on the competition metric is saved.
4.  **Final Evaluation**: Select the SWA model (or the best checkpoint) for the final evaluation. Compute and print the "Final Validation Metric" with full precision.
5.  **Failure Analysis**: Perform inference on the validation set to get raw predictions. Calculate the absolute error between predictions and targets. Correlate these errors with identity attributes to identify which subgroups are associated with higher model error.
6.  **Submission**: Compare the final validation metric against the specified threshold (0.9273...). If the model passes, generate predictions for the test set and save the `submission.csv` file.
