This script demonstrates the end-to-end usage of the provided machine learning library for the sentence word insertion task. It follows these steps:

1.  **Configuration Setup**: Overrides default `Config` parameters to define a fast "demo" mode (reduced dataset size, 1 epoch, specific working directory) to ensure the script completes quickly.
2.  **Data Loading**: Uses `get_dataloaders` to prepare training, validation, and test sets, handling tokenization and synthetic data corruption automatically.
3.  **Model Verification**: Instantiates the `LocatorModel` and `InfillerModel` and performs a dummy forward pass to verify input/output tensor shapes.
4.  **Training Loop**: Uses the `Trainer` class to train both models on the small subset of data.
5.  **Inference & Submission**: Uses the `BeamSearchPipeline` to predict missing words on the test set and generates a submission file formatted according to the task requirements.
6.  **Validation**: Includes assertions throughout to confirm data integrity, model behavior, and file generation.
