To address the `TimeoutError` caused by the inefficient inference pipeline, I will implement the following optimizations:

1.  **Eliminate Redundant Tokenization**: I will modify `TestDataset` in `library/data.py` to compute and return `offset_mapping`. This allows the inference pipeline to use pre-tokenized inputs instead of re-tokenizing raw text on the fly, removing a significant CPU bottleneck.
2.  **Vectorize Decoding**: I will update `library/inference.py` to use `batch_decode` instead of iterating through candidates and decoding them one by one. This reduces Python loop overhead.
3.  **Maximize GPU Utilization**: I will increase the `BATCH_SIZE` in `runfile.py` from 8 to 128. The A100 GPU is currently underutilized, and a larger batch size will significantly improve throughput.

These changes target the performance bottlenecks identified in the error analysis without altering the model logic.
