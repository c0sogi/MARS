# Transformer-Based Dual-Head Sequence Tagger

Based on the empirical success of the dual-head architecture in decoupling localization and prediction, I propose replacing the recurrent backbone with a Transformer encoder. This strategy combines the structural efficiency of the sequence tagging approach with the superior contextual representation of attention-based models.

### Model
The architecture is a **Transformer-Based Dual-Head Network**.
*   **Backbone**: A pre-trained lightweight Transformer encoder (e.g., `distilroberta-base`) replaces the Bi-LSTM. This allows the model to capture long-range dependencies and bidirectional context more effectively than recurrent layers, addressing the semantic ambiguity observed in previous attempts.
*   **Dual-Head Output**: We retain the parallel output structure **Cite solution_lesson_node_00004**:
    1.  **Location Head**: A linear projection followed by a Sigmoid activation applied to every token's embedding. It predicts the probability that the missing word belongs *immediately after* the current token.
    2.  **Word Prediction Head**: A dense classification layer over a fixed **word-level vocabulary** (e.g., the top 50,000 most frequent whitespace-delimited words). This is distinct from the standard sub-word MLM head; it ensures the model predicts complete words rather than sub-word fragments, aligning with the task constraint of inserting exactly "one word".

### Data
*   **Vocabulary Construction**: We will build a target vocabulary of the $K$ most frequent words from the training corpus. Words outside this set will be mapped to an `<UNK>` token.
*   **Synthetic Corruption**: Training samples are generated by uniformly removing one word from valid training sentences.
*   **Input Processing**: The input sentence (with the gap) is tokenized using the Transformer's sub-word tokenizer.
*   **Label Alignment**:
    *   **Location Label**: A binary vector where the position of the token *preceding* the gap is marked as 1.
    *   **Word Label**: The integer ID of the removed word from our word-level vocabulary. This label is associated with the token position marked as 1.

### Training
*   **Objective**: We frame the problem as **sequence tagging** rather than autoregressive generation **Cite solution_lesson_node_00004**. The loss function is a weighted sum: $L = L_{loc} + \lambda L_{word}$.
    *   $L_{loc}$: Binary Cross-Entropy loss calculated over all sequence positions.
    *   $L_{word}$: Cross-Entropy loss calculated *only* at the ground-truth gap location.
*   **Optimization**: We will use the AdamW optimizer with a linear learning rate scheduler, fine-tuning the Transformer backbone and training the new heads from scratch.

### Evaluation
*   **Inference Strategy**: We utilize **single-pass inference** **Cite solution_lesson_node_00004**. The test sentence is fed through the model once.
*   **Decoding**:
    1.  The model outputs location probabilities $P_{loc}$ and word distributions $P_{word}$ for all tokens.
    2.  We identify the insertion index $i^* = \text{argmax}(P_{loc})$.
    3.  We select the word $w^* = \text{argmax}(P_{word}[i^*])$.
    4.  The word $w^*$ is inserted into the original text after the token at $i^*$.
