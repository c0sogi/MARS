Based on the task description and the constraints provided, I propose a **Bi-Directional LSTM with Dual-Head Prediction**. This approach prioritizes inference speed and architectural simplicity by decoupling the tasks of "locating the gap" and "filling the gap" into a single-pass network, avoiding the computationally expensive sliding-window iteration used in Idea 1.

# Model
The architecture is a **Bi-directional Long Short-Term Memory (Bi-LSTM)** network designed to process the sequence as a whole and make predictions at every timestep simultaneously.
*   **Embedding Layer**: Maps input tokens to dense vectors.
*   **Encoder**: A Bi-LSTM layer that processes the sentence in both forward and backward directions, creating a context-aware hidden state for each token that captures information from the entire sentence.
*   **Dual Heads**: The hidden states are fed into two parallel output layers:
    1.  **Location Head (Binary Classifier)**: A linear layer with a sigmoid activation that outputs a scalar probability for each token position, representing the likelihood that the missing word belongs *immediately after* this token.
    2.  **Generation Head (Word Classifier)**: A linear layer with a softmax activation over the vocabulary size. It predicts the identity of the missing word assuming it is located at the current position.

# Data
*   **Preprocessing**: The training text will be tokenized, and a fixed-size vocabulary (e.g., top 50,000 frequent words) will be constructed. Rare words will be mapped to an `<UNK>` token.
*   **Synthetic Training Set**: We will transform the provided `train.txt` into a supervised dataset. For each sentence in the training set, we will uniformly randomly remove one word (excluding the first and last words, matching the test set distribution).
*   **Inputs & Targets**:
    *   **Input**: The sentence with the word removed.
    *   **Target 1 (Location)**: A binary vector of the same length as the input, with a `1` at the index of the token immediately preceding the removed word, and `0` elsewhere.
    *   **Target 2 (Word)**: The integer ID of the removed word.

# Training
*   **Objective Function**: The model will be trained to minimize a combined loss function: $L_{total} = L_{loc} + \lambda L_{word}$.
    *   $L_{loc}$: Binary Cross-Entropy loss for the Location Head (learning *where* to insert).
    *   $L_{word}$: Sparse Categorical Cross-Entropy loss for the Generation Head (learning *what* to insert), calculated only at the ground-truth gap position to avoid noise from non-gap positions.
*   **Optimization**: We will use the **Adam** optimizer. Given the large dataset, we will train for a limited number of epochs (e.g., 1-2) with a large batch size to maximize GPU throughput on the A100.

# Evaluation
*   **Single-Pass Inference**: Unlike the sliding-window approach which requires $N$ forward passes for a sentence of length $N$, this model requires only **one** forward pass per test sentence.
*   **Decoding**:
    1.  The model outputs a sequence of gap probabilities (from the Location Head) and word distributions (from the Generation Head).
    2.  We identify the time step $t$ with the maximum probability from the Location Head.
    3.  We select the word $w$ with the highest probability from the Generation Head at time step $t$.
    4.  The word $w$ is inserted into the sentence after the token at position $t$ to form the final submission.
