The strategy for the implementation is as follows:

1.  **Setup and Directory Creation**: Initialize the paths for input data and output metadata. Create the `./metadata` directory if it doesn't exist.
2.  **Loading Metadata**:
    *   Load the training metadata from `input/nybg2020/train/metadata.json`. This file contains image information and annotations (labels).
    *   Load the test metadata from `input/nybg2020/test/metadata.json`. This file contains image information for the test set.
    *   Use the standard `json` library to parse these files. Given the large memory available (220 GB RAM), loading the full JSONs into memory is feasible.
3.  **Data Processing**:
    *   **Training Data**: Convert the lists of images and annotations into Pandas DataFrames. Merge them on the image ID to associate each image with its class label (`category_id`). Construct the relative file path for each image by prepending `nybg2020/train/` to the `file_name` provided in the JSON.
    *   **Test Data**: Convert the list of images into a DataFrame. Construct the relative file path by prepending `nybg2020/test/` to the `file_name`. Ensure image IDs are consistent with the submission format (integers).
4.  **Train/Validation Split**:
    *   Perform a stratified split on the training data to create a validation set.
    *   Handle rare classes: Since some classes may have only one sample (singletons), standard stratified splitting would fail. Identify these singleton classes and assign them to the training set to preserve them. Perform the stratified split (80/20) on the subset of data containing classes with at least 2 samples.
    *   Combine the split data with the singletons to form the final training and validation sets.
5.  **Saving Metadata**: Save the processed DataFrames (Train, Validation, Test) as CSV files in the `./metadata` directory.
6.  **Verification**:
    *   **Statistics**: Print counts of images, classes, and split ratios.
    *   **File Path Check**: Randomly sample 1000 paths from the generated metadata and verify they exist in the `./input` directory. Raise an error if the missing file ratio exceeds 0.5.
    *   **Split Verification**: Assert that the validation set does not overlap with the training set and that the split size is approximately correct.
