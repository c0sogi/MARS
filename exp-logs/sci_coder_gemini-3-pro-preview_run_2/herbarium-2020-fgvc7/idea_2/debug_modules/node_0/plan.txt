The following script demonstrates the usage of the provided library components for the plant species classification task. It performs the following steps:
1.  **Configuration**: Adjusts the global `Config` to run in a fast "debug" mode with a minimal dataset subset and reduced training epochs.
2.  **Data Loading**: Uses `get_dataloaders` to load training, validation, and test batches, verifying data shapes and types.
3.  **Model Initialization**: Instantiates the `PlantClassifier` (EfficientNet-B0) and performs a forward pass with a dummy batch to verify output dimensions.
4.  **Loss Calculation**: Demonstrates the `FocalLoss` computation on the model's output.
5.  **Training Loop**: Executes `train_model` for a single epoch to demonstrate the training and validation process, ensuring the best model checkpoint is saved.
6.  **Inference**: Generates predictions using the `predict` function and verifies the format of the generated submission file.
7.  **Metrics**: Validates the `calculate_macro_f1` utility with synthetic data.
