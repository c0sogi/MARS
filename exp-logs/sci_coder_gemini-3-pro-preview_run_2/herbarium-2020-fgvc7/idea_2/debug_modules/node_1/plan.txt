The `KeyError` occurs because the `label_map` is constructed from the training data *after* it has been subsetted for debugging. This results in a partial label map that only contains the classes present in the small training subset (100 images). When the validation set (also subsetted) contains a class (e.g., `9477`) that wasn't in the training subset, the lookup fails. To fix this, the debug subsetting logic must be moved to *after* the label map construction so that the map is built from the full dataset. Additionally, I will add a check to invalidate any cached label map that doesn't match the expected full number of classes, preventing the use of a stale, incomplete map from a previous debug run.
