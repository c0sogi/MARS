This script demonstrates the end-to-end workflow for the plant species classification task using the provided library files. It covers data loading, model instantiation, training, and inference.

To ensure the script runs quickly and correctly within the read-only environment:
1.  It creates a **proxy input directory** in `./working` using symlinks. This allows us to point the data loader to a writable location where we can provide a truncated `test.csv` (for fast inference) while still accessing the read-only images and original metadata structure.
2.  It uses the `debug_size` parameter to load only a tiny subset of the training data.
3.  It initializes the model with `pretrained=False` to avoid downloading weights during the demonstration.
4.  It runs training for a single epoch and generates predictions for the truncated test set.
