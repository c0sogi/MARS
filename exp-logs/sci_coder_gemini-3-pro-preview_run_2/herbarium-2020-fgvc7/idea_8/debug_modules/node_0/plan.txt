This script demonstrates the end-to-end workflow using the provided library files. It performs the following steps:
1.  **Taxonomy Processing**: Generates the hierarchical class mapping from the raw metadata.
2.  **Data Preparation**: Creates small subsets of the training, validation, and test data to ensure the demonstration runs quickly.
3.  **Dataset & DataLoader**: Instantiates the `HerbariumDataset` and `DataLoader` with appropriate transforms.
4.  **Model Initialization**: Sets up the `CascadedEfficientNet` model using the class counts derived from the taxonomy.
5.  **Training**: Runs a single epoch of training using the `train_model` engine function, validating the loss calculation and backpropagation.
6.  **Inference**: Generates predictions on the test subset using `predict_test_set`.
