This is an implementation of the orchestration script `runfile.py`.

### Strategy Outline
1.  **Setup & Configuration**: The script initializes the environment, sets random seeds for reproducibility, and detects the available computation device (NVIDIA A100).
2.  **Taxonomy Loading**: It loads the taxonomy mapping (Species -> Genus -> Family) to determine the dimensions required for the hierarchical model heads.
3.  **Data Preparation**:
    *   It initializes the `HerbariumDataset` for training and validation.
    *   **Optimization**: To ensure the task completes within the 1-hour limit, the training dataset is subsampled to 80,000 images. This balances the need for data diversity with the strict runtime constraints.
4.  **Model Initialization**: Instantiates the `HierarchicalEfficientNet` (EfficientNet-B3 backbone with GeM pooling and Cosine Classifier).
5.  **Progressive Resizing Training**:
    *   **Phase 1 (Coarse)**: Trains for 1 epoch at 224x224 resolution to establish feature baselines.
    *   **Phase 2 (Fine)**: Loads the Phase 1 weights and fine-tunes for 1 epoch at 300x300 resolution (native B3 size) to resolve fine-grained details.
6.  **Validation & Analysis**:
    *   Evaluates the model on the **full** validation set to compute the official Macro F1 score.
    *   Performs the required failure analysis by correlating prediction errors with metadata features (Region, Family, Genus).
7.  **Submission**:
    *   Checks if the validation F1 exceeds the threshold (0.430087).
    *   If successful, generates predictions for the test set and saves `submission.csv`.
