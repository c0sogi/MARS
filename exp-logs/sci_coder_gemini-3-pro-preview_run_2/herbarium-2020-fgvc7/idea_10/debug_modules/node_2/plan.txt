The issue arises because Python evaluates default argument values at function definition time, not at runtime. In `library/dataset.py`, `HerbariumDataset.__init__` sets `debug=Config.DEBUG` as a default parameter. When the module is imported, `Config.DEBUG` is `False`, so the default value is permanently bound to `False`. Although `runfile.py` later updates `Config.DEBUG` to `True`, the `HerbariumDataset` constructor continues to use the stale default value (`False`) when instantiated without an explicit `debug` argument, causing the dataset to load all images instead of the debug subset.
