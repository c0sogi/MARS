This script orchestrates the end-to-end pipeline for the Herbarium 2020 plant species classification task.

**Strategy:**
1.  **Fast Baseline Configuration**: To ensure the task completes within the 2-hour limit while establishing a strong baseline, I override `Config.EPOCHS` to 1. Using the NVIDIA A100 GPU, one epoch over the full dataset (approx. 650k images) is feasible and provides better results than training for multiple epochs on a small subset.
2.  **Training**: The script initializes the `Trainer` class and calls `fit()`. This handles the training loop with Automatic Mixed Precision (AMP), evaluates on the validation set, saves the best checkpoint, and automatically generates the submission file for the test set.
3.  **Validation & Failure Analysis**: After training, the script reloads the best model checkpoint and performs a dedicated inference pass on the hold-out validation set. It calculates the final Macro F1 score and computes the correlation between prediction errors and the `region_id` feature to identify potential biases.
4.  **Submission**: The script verifies that the submission file has been generated at the specified location.
