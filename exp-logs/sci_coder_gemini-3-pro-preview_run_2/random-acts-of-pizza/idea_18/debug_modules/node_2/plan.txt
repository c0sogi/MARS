The `ValueError` arises because both the metadata DataFrame (loaded from `metadata/train.csv`) and the raw training DataFrame (loaded from `input/train.json`) contain the column `requester_received_pizza`. When performing a join operation without specifying suffixes, Pandas raises an error due to the column name collision. To fix this, I will add an `rsuffix="_raw"` argument to the `join` calls in `_process_split`. This resolves the ambiguity by renaming the colliding columns from the raw dataset (e.g., to `requester_received_pizza_raw`), allowing the join to proceed while preserving the target labels from the metadata.
