This script demonstrates the usage of the provided library modules. It first configures the environment for a fast execution by overriding hyperparameters in the `Config` class. It then validates the individual feature engineering components (`UserPersonaTransformer` and `MetadataTransformer`) using synthetic data. Finally, it demonstrates the full training pipeline by monkey-patching the data loader to use a small subset of the real data, ensuring the entire process completes quickly and verifies the generation of the submission file.
