This script orchestrates the entire pipeline by leveraging the provided library modules. It first initializes the environment and random seeds. Then, it uses the `FeatureEngineer` to generate fine-tuned embeddings and scaled metadata features (utilizing caching where available). A `PizzaClassifier` (Logistic Regression with Grid Search) is trained on these features. The model is evaluated on the validation set, and the final AUC is printed. A failure analysis is performed by correlating prediction errors with the tabular features. Finally, if the performance threshold is met, a submission file is generated for the test set.
