Implementation strategy:
1.  **Environment Setup**: Initialize the logger and set random seeds for reproducibility using the provided utility functions.
2.  **Data Processing**: Trigger the `EmbeddingGenerator` to compute and cache embeddings for all splits (train, val, test) and backbones (anchor, aux). This ensures all heavy computation is handled before the training loop and utilizes the GPU.
3.  **Model Training**: Call `model_trainer.train_model()`. This function executes the 5-fold Stratified Cross-Validation using the `ContextAwareFusionTransformer` and `BaggingClassifier`. It returns the overall OOF ROC AUC score.
4.  **Validation Reporting**: Print the `Final Validation Metric` using the score returned by the training process.
5.  **Failure Analysis**:
    - Reconstruct the OOF predictions by reloading the saved fold-models and predicting on the validation folds. This ensures we analyze unbiased predictions.
    - Calculate the absolute error for each sample.
    - Compute and print the correlation between the error magnitude and the numerical metadata features to identify sources of difficulty.
6.  **Submission Management**: Check if the validation metric exceeds the threshold (0.7190361601447052). If it does, the submission file (already generated by `train_model`) is kept. If not, it is removed to strictly comply with the "if and only if" requirement.
