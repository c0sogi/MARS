The following script demonstrates the Context-Aware Asymmetric Early Fusion (CAAEF) pipeline. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to run in `DEBUG` mode with a small subset of data (50 samples), reduced cross-validation folds (2), and minimal estimators for speed. It also redirects file paths to a demo-specific location to avoid conflicts.
2.  **Data Loading**: Demonstrates loading the raw text and metadata using `load_dataset`, verifying the subset size.
3.  **Embedding Generation**: Uses `EmbeddingGenerator` to compute text embeddings (Anchor and Aux views) for the data subset, verifying dimensions.
4.  **Feature Assembly**: Combines embeddings and numerical metadata into a single feature matrix using `assemble_features`.
5.  **Feature Engineering**: Instantiates and validates the `ContextAwareFusionTransformer`. It checks that the transformer correctly splits the input, applies PCA/Scaling, generates interaction features, and produces a fused output of the expected dimensionality.
6.  **Model Training**: Executes the full `train_model` pipeline, which performs stratified K-Fold cross-validation, hyperparameter tuning (simplified for demo), and generates a submission file.
7.  **Submission Validation**: Verifies the format and content of the generated submission CSV.
