The following script demonstrates the usage of the provided machine learning library for the "Random Acts of Pizza" task.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes at runtime to create a "demo" environment. This includes setting a small `DEBUG_SAMPLE_SIZE` (20 samples), reducing `NUM_FOLDS` to 2, and lowering `PCA_COMPONENTS` to ensure the code runs quickly (within seconds/minutes) and handles the small sample size correctly without errors.
2.  **Component Verification**: We systematically instantiate each core class (`PizzaDataLoader`, `FeatureExtractor`, `MultiModalTransformer`, `ModelFactory`) and assert that their outputs (dataframes, feature arrays, model objects) have the expected shapes and types.
3.  **Pipeline Execution**: We utilize the `CrossValidationManager` to execute the full workflow—loading data, extracting features, running stratified cross-validation, training models, and generating a submission file—ensuring that the integrated system functions as expected.
4.  **Artifact Validation**: Finally, we verify that the model files and the submission CSV are correctly created in the specified directories.
