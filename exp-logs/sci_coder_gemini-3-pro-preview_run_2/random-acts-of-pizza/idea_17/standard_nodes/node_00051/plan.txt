The error occurs because the keys in `GRID_SEARCH_PARAMS` ("C", "class_weight") do not correspond to parameters of the top-level `Pipeline` object. The `LogisticRegression` model is nested inside the `BaggingClassifier` (step name "ensemble"), which is a step in the pipeline. In scikit-learn, parameters of nested estimators must be accessed using the double-underscore notation (`<step>__<sub_estimator>__<parameter>`). I will update `library/config.py` to use the correct parameter paths: `ensemble__estimator__C` and `ensemble__estimator__class_weight`.
