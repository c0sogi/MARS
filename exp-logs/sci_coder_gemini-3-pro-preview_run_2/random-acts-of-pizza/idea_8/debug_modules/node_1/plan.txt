I will sanitize this column by converting it to a binary integer format (0 for False, 1 for edited/timestamp) before saving to the Parquet cache.

However, the demonstration script subsamples the data to ~230 samples. PCA cannot compute more components than there are samples. I will modify the `fit` method to dynamically cap `n_components` at `min(Config.N_PCA_COMPONENTS, n_samples)`.

3.  **Update Demo Configuration:** In `runfile.py`, I will override `Config.N_PCA_COMPONENTS` to a lower value (100) for the demonstration run. This ensures that the number of requested components is well within the subsampled data size and that the subsequent dimension assertions in the script pass successfully.
