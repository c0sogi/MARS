The issue stems from Python's behavior of evaluating default arguments at function definition time (import time) rather than at execution time. In `library/data_manager.py`, the `load_dataset` method defines `debug: bool = Config.DEBUG`. Since `Config.DEBUG` is `False` initially, this value is baked into the function signature. When `runfile.py` subsequently updates `Config.DEBUG = True`, the `load_dataset` method continues to use the stale `False` default, causing it to load the full dataset instead of the requested debug subset.

To fix this, I will change the default value of the `debug` parameter to `None` and add logic inside the function to explicitly fetch `Config.DEBUG` if the argument is not provided. This ensures the function performs a dynamic lookup of the configuration value at runtime, correctly reflecting the overrides made in the main script (Cite debug_lesson_12).
