To optimize the model's performance, I will transition from the linear Logistic Regression model to a Gradient Boosting Machine (LightGBM). The previous failure analysis revealed that prediction errors were strongly correlated with numerical activity metrics (e.g., `requester_number_of_posts_at_request`), suggesting that the linear model failed to capture non-linear relationships and interactions between these features and the text embeddings.

However, given the small dataset size (~2,300 training samples) and high dimensionality of the embeddings, high-capacity models are prone to overfitting (Cite solution_lesson_node_00003). To mitigate this, I will configure LightGBM with strict constraints on model complexity: using shallow trees (controlled by `num_leaves`), enforcing a minimum number of samples per leaf (`min_child_samples`), and applying feature subsampling (`colsample_bytree`) to reduce reliance on specific embedding dimensions (Cite solution_lesson_node_00002). I will also implement a grid search over regularization parameters (`reg_alpha`) to further prevent overfitting.

        """

            X_train (np.ndarray): Training feature matrix.

            float: The best C value found.

                # Evaluate
                auc = compute_auc(y_fold_val, preds)
