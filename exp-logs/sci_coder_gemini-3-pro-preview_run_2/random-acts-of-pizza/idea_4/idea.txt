Based on the lessons learned from the previous iterations—specifically the failure of Random Forests on sparse hashes (Cite solution_lesson_node_00001), the success of linear models on dense embeddings (Cite solution_lesson_node_00005), and the critical need for robust scaling (Cite solution_lesson_node_00006)—I propose a **Hybrid Kernel-Linear Ensemble**.

This approach structurally evolves the solution by moving away from tree-based non-linearity (which failed to generalize on this small, continuous dataset) to **Kernel-based non-linearity (SVM)**, and improves feature extraction by replacing unsupervised PCA with **Supervised Partial Least Squares (PLS)**.

# Model
The architecture consists of two parallel branches that are ensembled via soft voting. This design combines the stability of the linear baseline with a specialized non-linear component designed for small-sample continuous data.

1.  **Branch A: The Linear Anchor (High-Bias, Low-Variance)**
    *   **Algorithm:** **Logistic Regression** with L2 regularization.
    *   **Input:** Full 384-dimensional Sentence Transformer embeddings concatenated with RobustScaled metadata.
    *   **Rationale:** This preserves the most successful component of the previous attempts. As identified in the failure analysis, linear models efficiently find separating hyperplanes in high-dimensional embedding spaces where tree-based models fail (Cite solution_lesson_node_00005).

2.  **Branch B: The Non-Linear Expert (Supervised Projection + Kernel Method)**
    *   **Step 1: Supervised Dimensionality Reduction (PLS):** Instead of using PCA (unsupervised) which preserves variance but not necessarily predictive signal, we will use **Partial Least Squares (PLS)**. PLS projects the high-dimensional text embeddings into a low-dimensional latent space (e.g., 10 components) that maximizes covariance with the target variable (Success). This explicitly extracts "success-oriented" semantic directions (e.g., gratitude, urgency).
    *   **Step 2: Non-Linear Classifier (SVM):** The PLS components and scaled metadata are fed into a **Support Vector Machine (SVM)** with an **RBF (Radial Basis Function) Kernel**.
    *   **Rationale:** Unlike Random Forests or GBDTs, which struggle to approximate smooth functions on small datasets (Cite solution_lesson_node_00003), SVMs with RBF kernels are mathematically suited to finding smooth, non-linear decision boundaries in dense, continuous spaces with limited samples (~2,300).

# Data
1.  **Text Encoding:** Use the pre-trained `sentence-transformers/all-MiniLM-L6-v2` to convert `request_title` and `request_text_edit_aware` into dense vectors.
2.  **Tabular Preprocessing:** Apply **RobustScaler** to all numerical metadata features. This is strictly required to decouple the model's prediction error from the extreme outliers present in the Reddit karma and account age distributions (Cite solution_lesson_node_00006).
3.  **Feature Construction:**
    *   **Set A (Linear):** `[Raw Embeddings (384) + Scaled Metadata]`
    *   **Set B (Non-Linear):** Fit PLS on the training embeddings to transform them into `[PLS Components (10)]`. Concatenate with `[Scaled Metadata]`.

# Training
1.  **Stratified Cross-Validation:** Perform 5-Fold Stratified CV to train both branches.
2.  **Calibration:** Since SVMs do not output probabilities natively (they output distance to the hyperplane), wrap the SVM in a `CalibratedClassifierCV` (using sigmoid calibration) within the cross-validation loop to generate valid probability estimates.
3.  **Hyperparameter Tuning:** Use Grid Search within the folds to tune:
    *   Logistic Regression: Inverse regularization strength `C`.
    *   SVM: Regularization `C` and Kernel coefficient `gamma`.
    *   PLS: Number of components (e.g., 5, 10, 15).

# Evaluation
1.  **Inference:**
    *   Generate embeddings for test samples.
    *   Scale metadata using the training set's RobustScaler statistics.
    *   Project test embeddings using the trained PLS model.
2.  **Prediction:**
    *   Generate probability outputs from Branch A (Linear) and Branch B (SVM).
    *   Calculate the **Weighted Average** of the probabilities (e.g., 0.6 * Linear + 0.4 * SVM).
    *   The final output is the ensemble probability, leveraging the linear model's safety and the SVM's capacity to capture complex interactions without the overfitting risks of decision trees.
