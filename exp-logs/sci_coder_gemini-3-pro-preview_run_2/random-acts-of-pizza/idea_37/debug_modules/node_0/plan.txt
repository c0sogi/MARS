The following script demonstrates the complete pipeline by instantiating and utilizing the provided library components. It performs the following steps:
1.  **Configuration**: Patches the `Config` class to use a temporary working directory and reduced hyperparameters (fewer splits, smaller grid search, fewer estimators) for rapid execution.
2.  **Data Loading**: Uses `load_dataset` to retrieve the data, then subsets it to a small number of samples (20 training, 10 validation, 10 test) to ensure the demo finishes quickly.
3.  **Feature Engineering**: Instantiates `EmbeddingGenerator` to compute embeddings for the text data in the subset. It verifies the output shapes match the input counts.
4.  **Preprocessing**: Uses `FoldProcessor` to combine metadata and embeddings into feature views (`view_A` and `view_B`), handling imputation, scaling, and PCA. It asserts that no data leakage occurs (validation data is transformed, not fitted).
5.  **Model Training**: Demonstrates the `tune_and_train` logic from the `CrossValidator` (replicated manually for the subset) using `get_bagged_lr_pipeline`. It fits the model on the generated views.
6.  **Inference**: Generates predictions on the test subset and verifies the output format.
