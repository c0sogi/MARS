The strategy involves the following steps:
1.  **Setup and Loading**: Initialize the metadata directory. Load the `train.json` and `test.json` files from the `./input` directory using Pandas.
2.  **Preprocessing**: For each dataset, create a DataFrame containing the `request_id` and the ground truth label `requester_received_pizza` (for the training set). Add a `source_file` column pointing to the relative path of the source JSON file and a `sample_index` column representing the position of the record in the original JSON list. This ensures data can be retrieved efficiently without duplicating the heavy text fields.
3.  **Splitting**: Perform a stratified split on the training data to create a validation set. Use an 80:20 ratio with `random_state=42`, stratifying on the `requester_received_pizza` label to maintain class distribution.
4.  **Saving**: Save the resulting training, validation, and test metadata DataFrames as CSV files in the `./metadata` directory.
5.  **Verification**:
    *   Reload the saved metadata files.
    *   Print summary statistics (count, class balance).
    *   Verify that the `source_file` paths exist (checking a random sample).
    *   Assert that the validation split proportions and stratification are correct.
