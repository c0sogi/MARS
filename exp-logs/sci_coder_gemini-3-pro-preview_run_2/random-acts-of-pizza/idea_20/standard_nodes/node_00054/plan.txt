The implementation strategy involves the following steps:

1.  **Setup**: Initialize the environment and set random seeds to ensure reproducibility.
2.  **Training**: Execute the `run_stratified_cv` function from the `training_pipeline` library. This handles the heavy lifting: it loads the training data, performs 5-fold stratified cross-validation with nested hyperparameter tuning (optimizing PLS components and Logistic Regression regularization), and saves the trained model artifacts for each fold.
3.  **Validation**: Load the hold-out validation dataset (`metadata/val.csv`) and its corresponding features (SBERT embeddings, subreddits, metadata). Load the saved model artifacts from the training step. Perform inference using the ensemble of 5 fold models and calculate the Area Under the ROC Curve (AUC).
4.  **Failure Analysis**: Compute the absolute error of predictions on the validation set. Calculate the Pearson correlation between this error and the input numerical features to identify which features are most associated with prediction failure.
5.  **Submission Logic**: Compare the calculated validation AUC against the strict threshold of `0.7141749705260098`. If the model passes, generate the final submission file using the `inference_pipeline`. If it fails, ensure no submission file remains.
