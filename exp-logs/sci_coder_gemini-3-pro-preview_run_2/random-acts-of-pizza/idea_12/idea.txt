Based on the comprehensive failure analysis and the synthesis of lessons learned—specifically the superiority of **Early Fusion** with dense embeddings (Cite solution_lesson_node_00033), the critical need for **Differential Regularization** between high-dimensional text and low-dimensional metadata (Cite solution_lesson_node_00026), and the necessity of **Robust Scaling** (Cite solution_lesson_node_00019)—I propose a **Differentially-Regularized Bagged Linear Ensemble**.

This strategy structurally evolves the solution by introducing **Modality-Aware Feature Scaling**. Instead of treating all features equally or isolating them in a stacked architecture (which failed in Cite solution_lesson_node_00020), we will manipulate the feature scales *prior* to concatenation. This forces the unified linear solver to apply different effective regularization strengths to the noisy high-dimensional text embeddings and the high-signal low-dimensional metadata, resolving the "Signal Dilution" conflict.

# Model
The architecture is a **Bagged Ensemble of Logistic Regression Classifiers** that operates on a differentially scaled feature space.

1.  **Backbone (Frozen):** `sentence-transformers/all-MiniLM-L6-v2`.
    *   **Rationale:** We retain the compact 384-dimensional model to strictly avoid the "curse of dimensionality" observed with larger 768d models (Cite solution_lesson_node_00017) and keep it frozen to prevent manifold collapse (Cite solution_lesson_node_00014).
2.  **Differential Scaling Mechanism:**
    *   **Concept:** In linear models with L2 regularization, the penalty applied to a feature's weight is proportional to the weight's magnitude. By artificially **scaling up** the metadata features by a factor $\alpha > 1$, we force the model to learn smaller weights for them to achieve the same logit contribution. Smaller weights incur a smaller L2 penalty.
    *   **Effect:** This effectively applies **weaker regularization** to the reliable metadata (allowing the model to trust it) while maintaining **strong regularization** on the noisy text embeddings. This achieves the benefits of Stacking without the information bottleneck of Late Fusion.
3.  **Classifier:**
    *   **BaggingClassifier** wrapping **Logistic Regression**.
    *   **Rationale:** We preserve the high-bias linear core that outperforms non-linear methods on this dataset (Cite solution_lesson_node_00005) and use Bagging to reduce variance (Cite solution_lesson_node_00022).

# Data
1.  **Text Preprocessing:**
    *   Concatenate `request_title` and `request_text_edit_aware` to ensure context preservation (Cite solution_lesson_node_00025).
    *   Encode using `all-MiniLM-L6-v2`.
    *   **Crucial Step:** Apply **L2 Normalization** to project embeddings onto the hypersphere (Cite solution_lesson_node_00015).
2.  **Tabular Preprocessing:**
    *   Include `unix_timestamp_of_request`. **Do not drop it**, as it is a top predictor (Cite solution_lesson_node_00033).
    *   Apply **QuantileTransformer (output_distribution='normal')** (RankGauss) to all numerical metadata. This neutralizes outliers while preserving rank order (Cite solution_lesson_node_00006, Cite solution_lesson_node_00019).
3.  **Differential Fusion:**
    *   Multiply the RankGauss-transformed metadata matrix by a scalar hyperparameter $\alpha$ (e.g., 5.0).
    *   Concatenate `[L2-Norm Text Embeddings] + [Scaled Metadata]`.

# Training
1.  **Pipeline Efficiency:**
    *   Pre-compute text embeddings **outside** the cross-validation loop to avoid redundant GPU inference (Cite solution_lesson_node_00031).
2.  **Stratified Cross-Validation:**
    *   Use 5-Fold Stratified CV.
    *   **Hyperparameter Tuning:** Perform Grid Search within each fold for:
        *   **Regularization `C`:** Focus on the **High-Regularization Regime** (e.g., `1e-4`, `1e-3`, `0.01`) to suppress text noise (Cite solution_lesson_node_00012).
        *   **Metadata Scaler $\alpha$:** Search values $>1$ (e.g., `1.0`, `2.0`, `5.0`, `10.0`) to tune the relative regularization strength.
        *   **Class Weights:** Search `['balanced', None]` instead of hardcoding (Cite solution_lesson_node_00028).
3.  **Ensemble Strategy:**
    *   Train a Bagged Ensemble on each fold using the best parameters found for that fold.

# Evaluation
1.  **Inference:**
    *   Generate L2-normalized embeddings for the test set.
    *   Transform test metadata using the training set's QuantileTransformer and multiply by the optimal $\alpha$.
    *   Pass features to the 5 trained fold-models.
2.  **Prediction:**
    *   **Average the probability outputs** from all 5 fold-models. This "CV-Bagging" strategy maximizes stability and generalization (Cite solution_lesson_node_00027).
