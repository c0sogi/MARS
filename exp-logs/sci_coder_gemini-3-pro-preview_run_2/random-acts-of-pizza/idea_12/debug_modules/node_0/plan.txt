The following script demonstrates the end-to-end usage of the provided library components for the "Random Acts of Pizza" prediction task. It optimizes for speed by enabling `DEBUG` mode (using only 20 samples), reducing the number of cross-validation folds to 2, and minimizing the hyperparameter search space. The script sequentially validates data loading, feature engineering, the custom differential scaling logic, model training, and submission generation, asserting correctness at each step.
