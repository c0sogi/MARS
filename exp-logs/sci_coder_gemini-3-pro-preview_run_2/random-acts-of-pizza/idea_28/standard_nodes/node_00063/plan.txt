Implementation strategy:
1.  **Setup & Initialization**: Initialize the logger and set random seeds using the provided utility functions to ensure reproducibility.
2.  **Data Loading**: Utilize the `DatasetBuilder` class to load the datasets. This class handles the complexity of loading metadata, checking for cached embeddings, generating them via `EmbeddingGenerator` (using GPU if available) if missing, and constructing the final feature matrices (`X_train`, `y_train`, `X_val`, `y_val`, `X_test`).
3.  **Model Training**: 
    *   Instantiate a base pipeline using `PipelineFactory`.
    *   Map the hyperparameter grid from `Config.PARAM_GRID` to the specific parameter names required by the pipeline (targeting the Logistic Regression estimator inside the Bagging Classifier).
    *   Perform a `GridSearchCV` on the **training split only** (`X_train`, `y_train`). This strictly preserves the `X_val` split as a hold-out set for the final metric calculation, preventing data leakage.
4.  **Validation**:
    *   Use the best estimator found by Grid Search to predict probabilities on the `X_val` hold-out set.
    *   Calculate the ROC AUC score.
    *   **Output**: Print the "Final Validation Metric" in the specified format.
5.  **Failure Analysis**:
    *   Compute the absolute prediction error for each validation sample.
    *   Calculate the Pearson correlation between the error and all input features in `X_val`.
    *   Print the top 10 features most correlated with model error to identify weaknesses.
6.  **Submission**:
    *   Compare the calculated validation AUC against the threshold (`0.7160806860575912`).
    *   If the metric is higher, generate predictions for `X_test` and save the `submission.csv` file to the configured path.
