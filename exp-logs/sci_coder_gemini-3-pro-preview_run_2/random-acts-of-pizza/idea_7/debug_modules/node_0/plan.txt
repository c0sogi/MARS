Implementation Strategy:
1.  **Setup & Configuration**: Import the provided library modules. Override the `Config` class attributes to direct outputs to a temporary working directory (`./working/demo_execution`), reduce the number of folds for Cross-Validation to 2, and simplify the hyperparameter grids to single values. This ensures the script runs quickly (under 1 minute) while exercising all code paths.
2.  **Data Loading**: Use `load_and_merge_data` with `debug=True` and `debug_size=100` to load a small subset of the data.
3.  **Metadata Alignment**: Since the `StackingEngine` reads the test metadata file from disk to generate the submission, create a temporary truncated test metadata file matching the debug dataset and update `Config.TEST_META_PATH` to point to it. This prevents length mismatch errors during submission generation.
4.  **Feature Extraction**: Call `extract_features` with `load_cached_data=False` to force the execution of the text (Sentence Transformer) and tabular (RankGauss) pipelines.
5.  **Model Execution**: Instantiate `StackingEngine` and run the full pipeline (Base Learners -> Meta Learner -> Prediction).
6.  **Verification**: Validate the output shapes, check for NaNs, and confirm the submission file is correctly formatted and contains valid probabilities.
