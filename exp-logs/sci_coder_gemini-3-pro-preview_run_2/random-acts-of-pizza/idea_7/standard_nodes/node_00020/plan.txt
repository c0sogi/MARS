Implementation Strategy:
1.  **Setup & Imports**: Import necessary libraries and the provided helper modules (`library.*`). Set the random seed for reproducibility.
2.  **Data Loading & Feature Extraction**: Use `load_and_merge_data` to get the data splits. Use `extract_features` to generate the text embeddings (View A) and RankGauss-transformed metadata (View B), enabling caching to save time.
3.  **Stacking Workflow**:
    *   Implement a **Stratified K-Fold** loop (5 folds).
    *   Inside the loop, perform **Grid Search** to tune the `C` parameter for both the Text Expert (Bagged Logistic Regression) and the Metadata Expert.
    *   Train the best models for each view on the fold's training data.
    *   Generate **OOF predictions** for the meta-learner training and accumulate predictions for the validation and test sets.
4.  **Meta-Learning**: Train the Meta-Learner (Logistic Regression) on the OOF predictions.
5.  **Evaluation & Analysis**:
    *   Predict on the validation set using the Meta-Learner.
    *   Print the required `Final Validation Metric: <value>`.
    *   Calculate the absolute error of predictions and compute correlations with input features to perform the required failure analysis.
6.  **Submission**: If the validation AUC meets the threshold, generate the final submission file using the averaged test predictions.
