The following script demonstrates the usage of the provided machine learning library to solve the pizza request prediction task. It performs the following steps:

1.  **Setup**: Initializes the environment and random seeds.
2.  **Data Loading**: Uses `get_data_splits` to load the dataset.
3.  **Subset Creation**: Selects a small subset of data to ensure the demo runs quickly (optimizing for speed as requested).
4.  **Feature Extraction**: Generates semantic embeddings (High-Res and Low-Res) and extracts metadata features using `EmbeddingGenerator` and `extract_metadata_features`.
5.  **Feature Combination**: Merges features into a single matrix using `combine_features`.
6.  **Model Training**: Builds the ADRSF pipeline using `build_adrsf_pipeline` and trains it on the subset.
7.  **Inference**: Generates predictions for the test subset and saves a submission file.
8.  **Validation**: Includes assertions to verify data shapes and output formats.
