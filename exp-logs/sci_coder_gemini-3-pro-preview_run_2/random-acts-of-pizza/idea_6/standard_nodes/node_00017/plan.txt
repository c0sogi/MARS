The implementation strategy is as follows:

1.  **Setup and Initialization**: Set the random seed for reproducibility and suppress unnecessary warnings.
2.  **Data Loading & Feature Engineering**: Utilize the provided `get_features` function to generate or load cached features for the training, validation, and test splits. This leverages the MPNet transformer for text and QuantileTransformer for tabular data as defined in the library.
3.  **Hyperparameter Tuning**: Execute `run_stratified_cv` on the training set to identify the optimal regularization strength (`C`) for the Bagged Logistic Regression model.
4.  **Model Training & Validation**:
    *   Train a new instance of the Bagged Linear Model using the best `C` on the full training split.
    *   Generate probability predictions on the hold-out validation split.
    *   Compute the Area Under the ROC Curve (AUC) as the final validation metric.
5.  **Failure Analysis**:
    *   Calculate the absolute prediction error (residuals) for the validation set.
    *   Compute the correlation between this error signal and the interpretable numerical features to identify sources of model failure.
6.  **Submission Generation**:
    *   Compare the validation AUC against the specified threshold (0.6994047619047619).
    *   If the model passes the threshold, invoke `train_and_predict_submission` to retrain on the training set and generate the final `submission.csv` for the test set.
