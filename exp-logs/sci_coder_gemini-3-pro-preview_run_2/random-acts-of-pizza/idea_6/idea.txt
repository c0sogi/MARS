Based on the comprehensive failure analysis and lessons learned from previous iterations, I propose a **Bagged Linear Ensemble with Quantile Feature Alignment**.

This strategy structurally evolves the solution by moving from a **Single Deterministic Linear Model** (which struggles with the variance inherent in high-dimensional, small-sample data) to a **Stochastic Ensemble of Linear Probes**. It also introduces **Non-Linear Feature Transformation** (RankGauss) to resolve the critical conflict between outlier handling and regularization scale identified in Lesson 15.

### Model
The architecture is an **Ensemble of Logistic Regression Classifiers** constructed using **Bagging (Bootstrap Aggregating)** with **Random Subspace Sampling**.

1.  **Backbone (Semantic Feature Extractor):** We will upgrade the text encoder from `all-MiniLM-L6-v2` to **`sentence-transformers/all-mpnet-base-v2`**.
    *   **Rationale:** While slightly heavier, MPNet provides significantly richer semantic representations (768 dimensions). This leverages the "generic semantic knowledge" identified in **Cite solution_lesson_node_00014** as a crucial regularizer, providing a more robust signal than the smaller model.
2.  **Base Learner:** **Logistic Regression** with L2 regularization.
    *   **Rationale:** We retain the linear decision boundary to strictly adhere to **Cite solution_lesson_node_00005** and **Cite solution_lesson_node_00010**, which proved that linear probes outperform complex non-linear heads (SVM/GBDT) on these dense embeddings.
3.  **Ensemble Mechanism:** The base learners are wrapped in a `BaggingClassifier` that samples both data instances (bootstrap) and feature subsets (random subspaces, e.g., 80% of dimensions).
    *   **Rationale:** In a regime with high dimensionality (768 dims) and small sample size (~2,300), a single linear model can overfit to specific noisy dimensions (**Cite solution_lesson_node_00002**). Bagging with feature subsampling forces the ensemble to learn robust, redundant patterns rather than relying on a few specific embedding artifacts, reducing variance without introducing the bias of shallow trees.

### Data
1.  **Text Preprocessing:**
    *   Generate embeddings using `all-mpnet-base-v2`.
    *   **Crucial Step:** Apply **L2 Normalization** to the embeddings. This ensures they lie on the hypersphere surface, strictly aligning their magnitude (norm=1) for the linear classifier (**Cite solution_lesson_node_00015**).
2.  **Tabular Preprocessing:**
    *   Apply **QuantileTransformer (output_distribution='normal')** (often called "RankGauss") to all numerical metadata.
    *   **Rationale:** This is the structural fix for the conflict between `RobustScaler` and `StandardScaler` (**Cite solution_lesson_node_00006**, **Cite solution_lesson_node_00015**). By mapping the heavy-tailed distribution of Reddit karma to a strict Gaussian, we eliminate the magnitude of extreme outliers (solving Lesson 6) while ensuring the features have zero mean and unit variance, perfectly aligning with the L2-normalized embeddings for regularization (solving Lesson 15).

### Training
1.  **Hyperparameter Tuning:** Perform a Grid Search within the Cross-Validation loop to tune:
    *   **Regularization Strength (`C`):** Explore a range focusing on **strong regularization** (e.g., `1e-4`, `1e-3`, `1e-2`). This is critical to prevent overfitting the 768-dimensional embedding space (**Cite solution_lesson_node_00012**).
    *   **Ensemble Size:** Set a sufficient number of estimators (e.g., 50-100) to stabilize predictions.
2.  **Class Weighting:** Configure the base Logistic Regression learners with `class_weight='balanced'` to handle the 3:1 imbalance.

### Evaluation
1.  **Inference:**
    *   Encode test text with the frozen MPNet model and L2-normalize.
    *   Transform test metadata using the `QuantileTransformer` fitted on the training set.
    *   Pass the combined features to the Bagging Ensemble.
2.  **Prediction:** Aggregating the probability outputs (soft voting) from all linear base learners to produce the final score. This should yield a smoother, more reliable ranking for the ROC AUC metric than any single model.
