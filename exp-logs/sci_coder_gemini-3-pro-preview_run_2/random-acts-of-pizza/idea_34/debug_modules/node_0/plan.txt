The following script demonstrates the usage of the provided machine learning library for the pizza request prediction task.

### Implementation Strategy
1.  **Environment Setup**: Imports necessary modules, sets random seeds for reproducibility, and suppresses warnings for clean output.
2.  **Component-Level Demonstration**:
    *   **Data Loading**: Uses `DataLoader` to load a small subset of the training data (`debug_limit=100`) to verify data parsing and metadata extraction.
    *   **Embedding Generation**: Uses `EmbeddingManager` to compute text embeddings for the subset using the dual-backbone strategy (MiniLM + MPNet).
    *   **Feature Engineering**: Manually instantiates `JointPCATransformer` and builds a complete pipeline using `build_jbpce_pipeline` with reduced parameters (e.g., fewer PCA components) to verify the logic flow and shape transformations.
3.  **End-to-End Workflow Demonstration**:
    *   Uses the `Trainer` class to orchestrate the full process: data loading, embedding generation, stratified cross-validation with grid search, and inference.
    *   Sets `debug_limit=200` to ensure enough samples are available for the hardcoded PCA components (min 100) within the Trainer's internal grid search.
    *   Validates the final submission file generation.
