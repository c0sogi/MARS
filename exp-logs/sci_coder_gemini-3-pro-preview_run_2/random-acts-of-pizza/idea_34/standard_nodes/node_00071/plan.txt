The strategy for the implementation is as follows:
1.  **Initialization**: Set fixed random seeds using the provided utility to ensure reproducibility.
2.  **Data Preparation**: Utilize the `Trainer` class from the library to load the dataset and retrieve the pre-computed dual-backbone embeddings (MiniLM and MPNet) and metadata. This leverages the existing caching mechanism to save time.
3.  **Stratified Cross-Validation**: Implement a 5-fold Stratified Cross-Validation loop manually within the script. This allows explicit capture of Out-of-Fold (OOF) predictions which are necessary for the required failure analysis and precise metric calculation.
4.  **Model Training & Tuning**: Within each fold, construct the **Joint-Backbone Principal Component Ensemble (JBPCE)** pipeline using `build_jbpce_pipeline`. Perform hyperparameter tuning (PCA components, regularization, class weights) using `GridSearchCV` to optimize the model.
5.  **Failure Analysis**: Calculate the absolute prediction error on the validation set. Compute and print the correlation between this error and the metadata features to identify systematic failure modes.
6.  **Submission Generation**: Compute the final ROC AUC score. If it exceeds the threshold of `0.7190361601447052`, average the test set predictions from all folds and save the result to `submission.csv`.
