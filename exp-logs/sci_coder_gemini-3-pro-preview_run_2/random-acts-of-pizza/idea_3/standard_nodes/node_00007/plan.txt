Implementation strategy:
1.  **Setup & Imports**: Import necessary standard libraries and the provided custom modules (`Config`, `load_data`, `process_data`, `StackingEngine`, etc.). Set the random seed for reproducibility.
2.  **Data Loading**: Use `load_data` to retrieve the train, validation, and test DataFrames. These are needed for ID retrieval and failure analysis.
3.  **Feature Processing**: Use `process_data` to generate the numpy feature arrays (`linear` and `tree` views) for all splits. This leverages the cached parquet/npy files to speed up execution.
4.  **Model Training**:
    *   Initialize the `StackingEngine`.
    *   Run Cross-Validation (`train_cv`) on the training set to generate Out-Of-Fold (OOF) predictions and determine optimal tree iterations.
    *   Train the Meta-Learner (`train_meta_learner`) using the OOF predictions.
    *   Retrain the Base Models (`train_final_base_models`) on the full training set.
5.  **Validation**:
    *   Generate predictions for the hold-out validation set using the trained ensemble.
    *   Compute and print the exact `Final Validation Metric` (ROC AUC).
6.  **Failure Analysis**:
    *   Compute absolute prediction errors on the validation set.
    *   Calculate correlations between these errors and the numerical features from the validation DataFrame.
    *   Print the top correlations to identify sources of error.
7.  **Submission**:
    *   Compare the validation AUC against the required threshold (0.6994047619047619).
    *   If the threshold is met, generate predictions for the test set and save the submission file using `save_submission`.
