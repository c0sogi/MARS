The implementation strategy follows a robust machine learning workflow designed for the "Heterogeneous Linear Ensemble" architecture.

1.  **Setup & Data Loading**: We initialize the environment with fixed seeds for reproducibility. We load the labeled training data and perform feature extraction. Text data is converted into dense embeddings using a pre-trained SBERT model (cached for speed), and numerical metadata is extracted. These are concatenated into a single design matrix.
2.  **Stratified Cross-Validation**: We execute a 5-fold stratified cross-validation loop. This ensures that our validation metrics are reliable and representative of the class distribution.
3.  **Hyperparameter Tuning & Training**: Inside each fold, we tune the hyperparameters for the three distinct linear base learners (Logistic Regression, Linear SVM, Ridge Classifier) using Grid Search. This allows each component of the ensemble to optimize its specific loss function (Log-Likelihood, Hinge, Squared Error) effectively. We then build and fit the ensemble pipeline and save the trained model for later inference.
4.  **Validation & Analysis**: We aggregate the Out-Of-Fold (OOF) predictions to compute the overall ROC AUC score. We then perform failure analysis by correlating the prediction error magnitude with input features to understand model weaknesses.
5.  **Conditional Inference**: Finally, we check if the validation score meets the required threshold. If successful, we trigger the inference process to predict on the test set and generate the submission file.
