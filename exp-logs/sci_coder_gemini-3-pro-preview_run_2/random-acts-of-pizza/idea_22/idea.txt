Based on the comprehensive failure analysis and the synthesis of lessons learned—specifically the proven superiority of **Linear Models** on dense embeddings (Cite solution_lesson_node_00005), the effectiveness of **Early Fusion** (Cite solution_lesson_node_00020), and the benefits of **Ensembling** for variance reduction (Cite solution_lesson_node_00027)—I propose the **Heterogeneous Linear Ensemble (HLE)** strategy.

This approach structurally evolves the solution from a "Single-Objective Linear Model" (Logistic Regression) to a "Multi-Objective Linear Consensus". By ensembling linear classifiers that optimize distinct loss functions (Log-Likelihood, Hinge Loss, and Squared Error), we create a decision boundary that is robust to the specific idiosyncrasies of any single optimization surface, effectively mitigating the overfitting risks inherent in small-sample, high-dimensional regimes.

# Model
The architecture is a **Voting Ensemble** of three distinct, **Bagged Linear Base Learners**. This combines the variance reduction of Bagging with the bias diversity of heterogeneous loss functions.

1.  **Backbone (Frozen):** `sentence-transformers/all-MiniLM-L6-v2`.
    *   **Rationale:** We strictly retain the compact 384d model. Larger models (`mpnet`) failed due to the curse of dimensionality (Cite solution_lesson_node_00017), and fine-tuning failed due to data scarcity (Cite solution_lesson_node_00014).

2.  **Heterogeneous Base Learners:**
    *   **Learner A: Bagged Logistic Regression.** Optimizes **Log-Likelihood**. This is the probabilistic baseline that has performed well.
    *   **Learner B: Bagged Linear SVM.** Optimizes **Hinge Loss** (Margin Maximization). Implemented via `SGDClassifier(loss='hinge')` wrapped in `CalibratedClassifierCV` to provide probability outputs. This focuses on the decision boundary margin rather than probability mass.
    *   **Learner C: Bagged Ridge Classifier.** Optimizes **Squared Error** (MSE). Wrapped in `CalibratedClassifierCV`. This treats the classification as a regression problem, offering a distinct gradient path.
    *   **Rationale:** While non-linear models (Trees, RBF SVM) failed (Cite solution_lesson_node_00005, Cite solution_lesson_node_00010), diverse *linear* models can capture complementary views of the separating hyperplane without introducing the complexity that leads to overfitting.

3.  **Ensemble Mechanism:** **Soft VotingClassifier**.
    *   **Rationale:** Averaging the calibrated probabilities from these diverse linear solvers stabilizes the prediction, adhering to the lesson that ensembling reduces generalization error (Cite solution_lesson_node_00027).

# Data
We utilize an **Early Fusion** strategy with strict scaling alignment (Cite solution_lesson_node_00020).

1.  **Text View:**
    *   **Input:** Concatenation of `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00025).
    *   **Processing:** Encode with `all-MiniLM-L6-v2`.
    *   **Normalization:** Apply **L2 Normalization** to project onto the hypersphere. This is critical for the convergence and comparability of the linear solvers (Cite solution_lesson_node_00015).

2.  **Metadata View:**
    *   **Features:** All numerical metadata, **explicitly including** `unix_timestamp_of_request` (Cite solution_lesson_node_00033).
    *   **Scaling:** Apply **QuantileTransformer (output_distribution='normal')** (RankGauss).
    *   **Rationale:** This neutralizes heavy-tailed outliers (Cite solution_lesson_node_00006) and aligns the metadata distribution with the unit-norm embeddings (Cite solution_lesson_node_00019), avoiding the need for manual scaling factors (Cite solution_lesson_node_00035).

3.  **Exclusions:**
    *   **User History:** Explicitly excluded. Previous attempts (SBERT, PLS, LDA) consistently failed or introduced noise (Cite solution_lesson_node_00051, Cite solution_lesson_node_00056).
    *   **Heuristics:** Explicitly excluded weak heuristic features (e.g., punctuation counts) to prevent signal dilution (Cite solution_lesson_node_00038).

# Training
1.  **Pipeline Efficiency:**
    *   Pre-compute SBERT embeddings **outside** the cross-validation loop to avoid redundant inference (Cite solution_lesson_node_00031).
    *   **Encapsulation:** Fit the `QuantileTransformer` and `CalibratedClassifierCV` **inside** the cross-validation loop to prevent statistical leakage (Cite solution_lesson_node_00047).

2.  **Stratified Cross-Validation:**
    *   Use 5-Fold Stratified CV.
    *   **Hyperparameter Tuning:** Perform Grid Search within each fold for each base learner.
        *   **Regularization:** Search the **High-Regularization Regime** (e.g., `C` from `1e-4` to `10.0`, `alpha` for Ridge from `0.1` to `1000`). **Cap maximum complexity** to prevent overfitting (Cite solution_lesson_node_00012, Cite solution_lesson_node_00022).
        *   **Class Weights:** Search `['balanced', None]` (Cite solution_lesson_node_00028).
        *   **Bagging:** Use `max_samples=1.0` (standard bootstrapping) (Cite solution_lesson_node_00031).

# Evaluation
1.  **Inference:**
    *   Generate SBERT embeddings for the test set (L2 normalized).
    *   For each of the 5 trained fold-ensembles:
        *   Transform test metadata using that fold's QuantileTransformer.
        *   Concatenate features.
        *   Get probability predictions from the Heterogeneous Voting Ensemble.
2.  **Prediction:**
    *   **Average the probability outputs** from all 5 fold-ensembles (CV-Bagging) to produce the final score. This "Ensemble of Ensembles" strategy maximizes stability (Cite solution_lesson_node_00027).
