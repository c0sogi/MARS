This script demonstrates the end-to-end usage of the provided machine learning library components. It performs the following steps:
1.  **Configuration Override**: Enables debug mode and reduces the number of folds/jobs to ensure rapid execution.
2.  **Data Loading**: Loads a small subset of the training data using the `debug=True` flag to verify data ingestion logic.
3.  **Feature Engineering**: Generates SBERT text embeddings and extracts numerical metadata, combining them into a single design matrix. It asserts the correctness of feature dimensions.
4.  **Model Component Tuning**: Demonstrates how to tune a specific component (Logistic Regression) of the ensemble using a simplified grid search via `tune_component`.
5.  **Pipeline Construction & Training**: Builds the full heterogeneous ensemble pipeline using `build_ensemble_pipeline` and trains it on the debug dataset.
6.  **Inference**: Loads a subset of the test data, generates features, and produces predictions using the trained pipeline.
7.  **Validation**: Includes assertions at each step to verify shapes, data types, and logic correctness.
