This script demonstrates the usage of the provided library components to build a solution for the Random Acts of Pizza prediction task. It overrides the default configuration to run in a "debug" mode with a small subset of data, ensuring rapid execution and verification of the pipeline's logic.

The script performs the following steps:
1.  **Configuration**: Sets up a temporary working directory and reduces data size/hyperparameters for speed.
2.  **Data Loading**: Uses `load_dataset` to retrieve and verify training, validation, and test splits.
3.  **Feature Extraction**: Demonstrates and validates the `TextEmbedder` (SBERT), `BayesianSubredditEncoder`, and `RankGaussScaler`.
4.  **Model Training**: Validates the `TunedLogisticRegression` wrapper with a synthetic test.
5.  **Full Pipeline**: Executes the `CrossValidationStacker` to run the end-to-end training and inference process, producing a submission file.
