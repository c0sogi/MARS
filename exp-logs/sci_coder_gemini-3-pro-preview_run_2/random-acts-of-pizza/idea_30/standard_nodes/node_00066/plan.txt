The implementation strategy follows the orchestration of the Asymmetric Dual-Backbone Consensus (ADBC) pipeline.

1.  **Initialization**: We set the random seed and initialize the logger to ensure reproducibility and traceability.
2.  **Training**: We invoke `library.trainer.run_training(debug=False)`. This function handles the loading of the training split (metadata/train.csv), generation/caching of embeddings (MiniLM and MPNet), and the execution of a 5-Fold Stratified Cross-Validation loop. It trains a Bagged Ensemble of Logistic Regressions on each fold, saving the models to disk.
3.  **Validation**:
    *   We explicitly load the hold-out validation set (metadata/val.csv) using `library.feature_extraction.FeaturePreprocessor`.
    *   We load the trained models and perform inference on the validation set, averaging the probabilities (CV-Bagging).
    *   We calculate the ROC AUC score and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   We compute the absolute error magnitude (`|y_true - y_pred|`) for the validation set.
    *   We extract the metadata features from the validation feature matrix.
    *   We calculate the Pearson correlation between each metadata feature and the error magnitude to identify which request characteristics are associated with model failure.
5.  **Submission**:
    *   We compare the final validation metric against the threshold (0.7160806860575912).
    *   If the threshold is met, we call `library.inference.generate_submission`, which processes the test set and generates the `submission.csv` file.
