This resulted in a validation set containing only a single class (e.g., all zeros), rendering the AUC metric undefined. Because `nan` is not greater than the initial best score (`-1.0`), the model checkpoint logic was never triggered, leading to a `FileNotFoundError` when the script attempted to load the non-existent `best_model.pth`.

I will fix this by modifying `library/train.py` to explicitly check if the target vector contains at least two unique classes before calculating the AUC. If only one class is present (or if the calculation returns `nan`), the code will default the metric to 0.5. This ensures a valid numeric score is always returned, allowing the training loop to proceed and save the model artifact.
