This script demonstrates the end-to-end pipeline for the glioblastoma genetic subtype prediction task using the provided library. It covers data loading, model instantiation, training loop execution, and inference with Test-Time Augmentation (TTA).

To ensure rapid execution within the time limit, the script overrides configuration parameters to use a small subset of the data (16 samples) and runs for only 1 epoch. It includes assertions to verify the correctness of data shapes, model outputs, and file generation.
