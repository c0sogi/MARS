Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `Config.setup()`, set random seeds for reproducibility, and determine the computation device (GPU/CPU).
2.  **Data Loading**: Load the pre-generated metadata for training and validation. Use the provided `process_dataset` function with caching enabled to efficiently load image data into memory. Wrap these in `BraTSDataset` and `DataLoader` objects.
3.  **Model Training**: Instantiate the `AsymmetricEfficientNet`. Execute a training loop for the configured number of epochs. Inside the loop, perform training and validation steps, track the best AUC score, and save the model checkpoint (`best_model.pth`) whenever performance improves.
4.  **Final Evaluation**: Load the best saved model and perform a final inference pass on the validation set to compute the `Final Validation Metric` (AUC).
5.  **Failure Analysis**: Calculate the absolute error between predictions and ground truth on the validation set. To identify systematic errors, extract basic metadata features (specifically `FLAIR_slices` as a proxy for brain volume/scan depth, which EDA identified as relevant) and calculate their correlation with the error magnitude.
6.  **Submission Generation**: Check if the final validation AUC exceeds the threshold (`0.6321818181818182`). If successful, execute the inference pipeline on the test set (using Test-Time Augmentation) and generate the `submission.csv` file.
