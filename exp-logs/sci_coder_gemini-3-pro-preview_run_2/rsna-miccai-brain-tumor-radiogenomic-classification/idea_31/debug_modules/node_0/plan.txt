The following script demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory and reduced hyperparameters (1 epoch, small batch size) for a fast demonstration.
2.  **Data Pipeline Verification**: Instantiates the `MRIDataset` and `DataLoader`, verifying that the input tensors have the correct shape `(12, 224, 224)` (representing 4 modalities × 3 slices) and that labels are correctly formatted.
3.  **Model Architecture Verification**: Instantiates the `AsymmetricEfficientNet`, passes a dummy batch through it, and asserts that the output logits have the expected shape `(Batch_Size, 1)`.
4.  **Training Loop Execution**: Runs the `run_training` function in debug mode (using a data subset) to ensure the training loop, backpropagation, and checkpoint saving mechanisms function correctly without errors.
5.  **Inference & Submission**: Uses the trained model to generate predictions on the test set via `predict_submission`, verifying the output CSV format.
