Implementation strategy:
1.  **Setup & Configuration**: Initialize the script by importing necessary standard libraries (`os`, `numpy`, `pandas`, `torch`) and the provided custom library modules (`Config`, `run_training`, `predict_submission`, `get_dataloader`, `AsymmetricEfficientNet`). Set random seeds to ensure reproducibility.
2.  **Training**: Execute the training pipeline using `run_training`. We will use the full training dataset (`debug=False`) and a reasonable number of epochs (10) to ensure the model converges sufficiently to meet the AUC threshold, while still completing well within the time limit given the small dataset size (~500 subjects).
3.  **Validation & Failure Analysis**:
    *   Reload the best saved model and the validation dataset.
    *   Perform inference on the validation set to generate predictions.
    *   Calculate the final ROC AUC metric on the validation set and print it in the required format: `Final Validation Metric: <value>`.
    *   Perform failure analysis by calculating the absolute error between predictions and targets.
    *   Compute and print correlations between the error magnitude and available metadata features (Target Label and Anchor Index) to identify systematic failure modes.
4.  **Submission**: Compare the final validation metric against the required threshold (`0.63218...`). If the threshold is exceeded, trigger the `predict_submission` function to generate the final `submission.csv` for the test set.
