The following script demonstrates the usage of the provided library modules for the Glioblastoma classification task.

### Strategy Outline
1.  **Configuration Setup**: We modify the global `Config` class to use a temporary working directory and reduce hyperparameters (1 epoch, small batch size) for a fast execution.
2.  **Data Subsetting**: We create small subsets (5-10 samples) of the original metadata files (`train.csv`, `val.csv`, `test.csv`) and save them to the working directory. This ensures the data loading and preprocessing steps run quickly.
3.  **Component Verification**:
    *   **DICOM Utils**: We verify `read_dicom_robust` and `map_slice_ids` by reading a real sample image and checking its shape and data type.
    *   **Network**: We instantiate `GroupedEfficientNetV2`, pass a dummy tensor with the expected shape `(Batch, 12, 224, 224)`, and assert the output shape is `(Batch, 1)`.
    *   **Data Pipeline**: We initialize the `BraTSDataset` and `DataLoader` using the subset metadata and verify that batches are yielded with the correct dimensions.
4.  **Training Integration**: We execute `run_training()`, which runs the full pipeline (training, validation, and submission generation) on the subset data. We then verify that the submission file is created correctly.
