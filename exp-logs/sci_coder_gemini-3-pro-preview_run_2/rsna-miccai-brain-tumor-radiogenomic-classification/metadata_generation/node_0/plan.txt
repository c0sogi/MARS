The following script generates the required metadata files for the RSNA-MICCAI Brain Tumor Radiogenomic Classification task.

**Implementation Strategy:**
1.  **Setup**: Define input/output directories and constants, including the specific IDs to exclude. Ensure the output directory exists.
2.  **Data Loading & Cleaning**:
    *   Load `train_labels.csv`.
    *   Convert `BraTS21ID` to 5-digit zero-padded strings to match the folder structure.
    *   Remove the specified exclusion cases.
    *   Verify that the subject folders actually exist in `input/train/`.
3.  **Metadata Construction**:
    *   For the training data, create columns for the relative paths of the four MRI modalities (`FLAIR`, `T1w`, `T1wCE`, `T2w`).
    *   For the test data, scan the `input/test/` directory to identify subject IDs and construct similar path columns.
4.  **Splitting**:
    *   Perform a stratified 80/20 split on the training data using the `MGMT_value` target to create training and validation sets.
    *   Use `random_state=42` for reproducibility.
5.  **Saving**: Save the resulting DataFrames (`train`, `val`, `test`) to CSV files in the `./metadata` directory.
6.  **Verification**:
    *   Reload the saved metadata.
    *   Print summary statistics (count, class balance).
    *   **Path Check**: Randomly sample 1000 paths from the generated metadata and verify they exist on the filesystem. Raise an error if >50% fail.
    *   **Split Check**: Verify the split ratio and that the class distribution in the validation set roughly matches the training set. Verify no data leakage between splits.
