The following script demonstrates the usage of the provided library files for the Glioblastoma classification task. It performs the following steps:

1.  **Configuration Setup**: Modifies the global `Config` to use a smaller image size, fewer epochs, and a temporary working directory to ensure the demonstration runs quickly (under 1 hour).
2.  **Data Preparation**: Creates small subsets of the training, validation, and test metadata to simulate a quick training cycle without processing the entire dataset.
3.  **Utility Verification**: Tests the `read_dicom_file` and `normalize_min_max` functions to ensure image loading works correctly.
4.  **Pipeline Verification**:
    *   Generates the Region of Interest (ROI) cache using `generate_roi_cache`.
    *   Instantiates the `MGMTDataset` and validates the shape of the output tensors (Batch, Instances, Channels, Height, Width).
    *   Instantiates the `MILEfficientNet` model and performs a forward pass with dummy data to verify architecture compatibility.
5.  **Training Loop**: Runs a full training and validation epoch using the `Trainer` class on the subset data.
6.  **Inference**: Generates a submission file for the test subset and verifies the output format.
