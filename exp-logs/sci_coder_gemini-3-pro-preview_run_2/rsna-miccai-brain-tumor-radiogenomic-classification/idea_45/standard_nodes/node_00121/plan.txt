This failure stemmed from a brittle heuristic that only checked for fixed file sizes (corresponding to 512x512 or 256x256 resolutions) when falling back to raw binary reading. To fix this, I will implement a dynamic resolution check in `library/data_loader.py` that iterates through a list of common medical image dimensions (512, 256, 240, 192, 160, 128) to find the correct fit for each file size (Cite debug_lesson_5).
