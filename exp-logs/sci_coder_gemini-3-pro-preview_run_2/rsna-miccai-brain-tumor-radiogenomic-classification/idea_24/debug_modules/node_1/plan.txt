The error occurred because the library modules imported configuration variables (like `WORKING_DIR`) directly using `from library.config import ...`, which binds the values at import time. When `runfile.py` subsequently modified `library.config.WORKING_DIR` at runtime to point to the demo environment, the library modules continued to use the old values, causing the model to be saved in the wrong directory (`working/idea_24` instead of `working/demo_run`).

To fix this, I will modify `library/utils.py`, `library/data.py`, `library/model.py`, `library/train.py`, and `library/inference.py` to import the configuration module as a whole (`import library.config as config`) and access variables dynamically (e.g., `config.WORKING_DIR`). This ensures that the code always uses the current runtime values of the configuration variables. I will also update function signatures that used these variables as default arguments to use `None` and assign the config value inside the function body.

def read_dicom_raw(path, img_size=IMG_SIZE):
    """
    Reads DICOM pixel data using a raw binary tail-read to bypass headers.
    Infers resolution (512x512 vs 256x256) based on file size.
    Resizes to img_size using Area Interpolation.
    Returns float32 numpy array.
    """
    try:
        file_size = os.path.getsize(path)

        # Heuristic to determine dimensions based on file size
        # 512*512*2 bytes = 524,288 bytes. Files ~525kB are 512x512.
        # 256*256*2 bytes = 131,072 bytes. Files ~132kB are 256x256.
        if file_size > 200000:
            shape = (512, 512)
        else:
            shape = (256, 256)

        num_pixels = shape[0] * shape[1]
        num_bytes = num_pixels * 2  # uint16 = 2 bytes

        # Raw binary read from the end of the file
        with open(path, "rb") as f:
            f.seek(-num_bytes, 2)
            data = f.read()

        if len(data) < num_bytes:
            # Fallback for corrupted/unexpected files
            return np.zeros((img_size, img_size), dtype=np.float32)

        # Convert bytes to numpy array
        img = np.frombuffer(data, dtype=np.uint16).reshape(shape)
        img = img.astype(np.float32)

        # Resize if necessary using Area Interpolation (best for downsampling)
        if img.shape[0] != img_size:
            img = cv2.resize(img, (img_size, img_size), interpolation=cv2.INTER_AREA)

        return img

    except Exception:
        # Return black image on failure
        return np.zeros((img_size, img_size), dtype=np.float32)
