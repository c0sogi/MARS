The following script demonstrates the end-to-end usage of the provided library components. It employs a "monkey-patching" strategy to redirect the configuration paths to a temporary working directory. This allows the creation of a small subset of the metadata (sampling just enough data for one batch) to ensure the demonstration runs quickly and efficiently without modifying the original read-only input or metadata files.

The script performs the following steps:
1.  **Setup**: Configures temporary directories and overrides global configuration variables.
2.  **Data Subset Creation**: Loads the original metadata, samples a small fraction (32 training, 16 validation, 5 test samples), and saves these as new metadata files in the temporary directory.
3.  **Data Loading Verification**: Uses `get_dataloaders` to load the subset, verifying that the batch shapes match the expected volumetric input (Batch, 20 Channels, 224, 224).
4.  **Model Verification**: Instantiates the `AsymmetricEfficientNet`, performs a forward pass with a dummy batch, and asserts the output shape is correct.
5.  **Training Loop**: Executes `run_training` for 1 epoch on the subset.
6.  **Inference Loop**: Executes `run_inference` on the test subset.
7.  **Submission Validation**: Checks the generated submission file for correct formatting and value ranges.
