The implementation strategy involves utilizing the provided library modules to orchestrate the machine learning pipeline. The script will first set up the environment and random seeds for reproducibility. It will then execute the training process using `library.train.run_training` with a limited number of epochs to serve as a fast baseline. Following training, the script will reload the best saved model to perform inference on the validation set. It will calculate the Area Under the ROC Curve (AUC) and print it in the specified format. A failure analysis will be conducted by extracting metadata features (specifically slice counts for each MRI modality) from the validation set and calculating their correlation with the model's prediction error. Finally, if the validation AUC exceeds the specified threshold, the script will generate predictions for the test set using Test-Time Augmentation (TTA) and save the submission file.
