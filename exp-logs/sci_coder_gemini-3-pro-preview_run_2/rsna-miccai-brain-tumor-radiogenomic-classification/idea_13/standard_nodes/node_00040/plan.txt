Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds and detecting the computation device. Define paths for metadata, working directories, and output files.
2.  **Training Phase**: Execute the training pipeline using the provided `run_training` function from the library. This handles model initialization, the training loop, validation monitoring, and saving the best model checkpoint. We set a reasonable epoch count (15) to ensure execution finishes well within the time limit given the small dataset size.
3.  **Validation & Assessment**:
    *   Reload the best saved model state.
    *   Perform inference on the full validation set to obtain probabilities.
    *   Calculate the Area Under the ROC Curve (AUC) and print it in the specific format required: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the absolute error for each validation sample (`|Target - Prediction|`).
    *   Extract metadata features for analysis: specifically, the number of slices in the FLAIR modality (representing volume depth) and the relative ROI anchor position (representing tumor location).
    *   Calculate and print the Pearson correlation between these features and the model's error to identify potential biases.
5.  **Submission Generation**:
    *   Check if the final validation AUC exceeds the threshold `0.6254545454545455`.
    *   If the condition is met, trigger the `predict_and_submit` function to generate predictions for the test set using Test-Time Augmentation (TTA) and save the `submission.csv`.
