Implementation Strategy:
1.  **Environment Setup**: Import necessary libraries and the provided `library` modules. Set random seeds for reproducibility.
2.  **Configuration Override**: To ensure the demonstration runs quickly (within minutes) and does not process the entire dataset (which would take too long for ROI calculation), I will create a temporary "demo" subset of the metadata files (train, val, test) containing only 5 samples each. I will then override the paths in `library.config` to point to these small files.
3.  **Utility Verification**: Demonstrate and verify `utils.py` functions, including seed setting, device detection, and checkpoint saving/loading logic.
4.  **Data Pipeline Verification**:
    *   Initialize the `BraTSDataset` and `DataLoader` using the truncated metadata.
    *   This triggers the ROI consensus mechanism on just the small subset.
    *   Fetch a single batch to verify tensor shapes (Batch Size, 12 Channels, 224, 224) and data types.
5.  **Model Verification**:
    *   Instantiate the `AsymmetricEfficientNet`.
    *   Perform a forward pass with the batch fetched previously.
    *   Assert output shapes and value ranges (logits).
6.  **Full Training Loop Demonstration**:
    *   Execute `train.run_training` with `debug=True` and reduced epochs/batch size.
    *   This validates the integration of the data loader, model, loss calculation, backpropagation, validation loop, and inference step.
7.  **Inference Output Check**: Verify that the submission file is generated correctly in the specified output directory.
8.  **Cleanup**: Remove temporary directories created during the demo.
