The following script demonstrates the end-to-end usage of the provided library files. It performs the following steps:
1.  **Setup**: Creates a temporary working directory for the demo and overrides configuration parameters (paths, epochs) to ensure a fast execution on a small subset of data.
2.  **Data Preparation**: Samples a small subset (10 training, 5 validation, 5 test subjects) from the existing metadata to create "demo" metadata files. This avoids processing the entire dataset.
3.  **Component Verification**:
    *   **DICOM Utils**: Verifies that raw DICOM files can be read and resized correctly.
    *   **Data Factory**: Verifies that the data pipeline correctly loads, preprocesses (finding anchors, stacking modalities), and batches the data into tensors of shape `(B, 12, 256, 256)`.
    *   **Model Factory**: Instantiates the `GroupedEfficientNetV2S` and performs a forward pass to verify output shape `(B, 1)`.
4.  **Full Execution**: Runs the training and inference engine (`run_training`) using the demo configuration.
5.  **Output Validation**: Checks that the submission file is generated correctly.
