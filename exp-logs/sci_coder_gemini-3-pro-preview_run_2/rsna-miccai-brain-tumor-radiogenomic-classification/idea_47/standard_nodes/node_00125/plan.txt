The previous implementation of `runfile.py` attempted to suppress `tqdm` progress bars by creating a dummy class and manually injecting it into `sys.modules['tqdm']`. This "aggressive monkey-patching" replaced the real `tqdm` package with a simple object that lacked the `__spec__` attribute and submodule structure (e.g., `tqdm.auto`). This caused `torchvision` (and specifically `torch._dynamo`) to crash during import because it relies on inspecting module specifications, and it caused other libraries to fail when importing submodules like `tqdm.auto`.

The fix involves removing the `DummyTqdm` class and the `sys.modules` injection. Instead, we import the actual `tqdm` library and use `functools.partial` to wrap the `tqdm` constructor with `disable=True`. This preserves the valid module structure and `__spec__` required by `torch`, while still suppressing the progress bar output as intended.
