This script demonstrates the usage of the provided library files (`config.py`, `utils.py`, `data.py`, `model.py`, `train.py`, `predict.py`). It performs the following steps:
1.  **Configuration Override**: Adjusts global configuration settings (paths, batch size, epochs) to ensure the demonstration runs quickly and uses a temporary directory.
2.  **Subset Data Generation**: Creates small subsets of the training, validation, and test metadata to avoid processing the entire dataset during the demo.
3.  **Data Loading Verification**: Instantiates the `BrainTumorDataset` and `DataLoader`, fetching a single batch to verify input shapes (Batch, 20, 224, 224) and target shapes.
4.  **Model Architecture Verification**: Instantiates the `AsymmetricEfficientNet`, performs a forward pass with the sample batch, and verifies the output shape and gradient tracking.
5.  **Training Pipeline Verification**: Executes a short training run (1 epoch) on the subset data, ensuring the training loop functions correctly and saves a model checkpoint.
6.  **Inference Pipeline Verification**: Runs the inference function using the trained model and test subset, verifying that a submission file is generated with the correct format.
