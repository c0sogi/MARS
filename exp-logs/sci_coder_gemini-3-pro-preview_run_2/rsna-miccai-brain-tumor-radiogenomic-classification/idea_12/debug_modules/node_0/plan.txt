This script demonstrates the end-to-end usage of the provided library files for the Glioblastoma MGMT promoter methylation prediction task. It performs the following steps:

1.  **Data Preparation**: Loads the metadata and creates small subsets of training, validation, and test data to ensure the demonstration runs quickly (optimizing for speed).
2.  **Utility Verification**: explicitly tests the `read_dicom_robust`, `calculate_roi_index`, and `generate_roi_cache` functions from `library.utils` to ensure image processing logic is sound.
3.  **Dataset & DataLoader**: Instantiates the `MGMTDataset` via `get_dataloader` and verifies the batch shapes and data types (ensuring the custom 12-channel input is formed correctly).
4.  **Model & Training**: Uses the `Trainer` class to fine-tune the `AsymmetricEfficientNet` on the subset for 2 epochs. It validates the output shapes and the training loop execution.
5.  **Inference**: Runs the prediction pipeline on the test subset and verifies the format of the generated submission file.
