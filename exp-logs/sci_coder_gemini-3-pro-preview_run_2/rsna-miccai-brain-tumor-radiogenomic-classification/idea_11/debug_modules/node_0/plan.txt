The following script demonstrates the usage of the provided library files (`config.py`, `utils.py`, `data.py`, `model.py`, `train.py`) to build a complete pipeline for Glioblastoma subtype prediction.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to enable `DEBUG` mode, reduce `NUM_EPOCHS` to 1, and set a small `BATCH_SIZE`. This ensures the script executes quickly (within minutes) while exercising all code paths.
2.  **Utility Verification**: We explicitly test the DICOM reading and image preprocessing functions (`read_dicom_robust`, `preprocess_image`) to ensure data integrity.
3.  **Data Pipeline Verification**: We instantiate the `DataLoader` using `get_dataloader` and fetch a single batch to verify tensor shapes (batch size, channels, height, width) and data types.
4.  **Model Verification**: We instantiate the `AsymmetricEfficientNet`, perform a forward pass with the fetched batch, and assert the output dimensions.
5.  **Training & Inference Integration**: We execute the high-level `run_training` and `predict_and_submit` functions from `train.py`. This validates the full loop: training, validation, checkpoint saving, test-time augmentation (TTA), and submission file generation.
