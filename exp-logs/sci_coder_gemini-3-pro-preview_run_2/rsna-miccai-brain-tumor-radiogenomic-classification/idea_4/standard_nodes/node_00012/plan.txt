The implementation strategy is as follows:

1.  **Setup and Configuration**: Import necessary libraries and the provided modules (`library.config`, `library.utils`, `library.data_loader`, `library.trainer`). Set the random seed for reproducibility. Override `Config.NUM_EPOCHS` to a smaller value (e.g., 10) to ensure the baseline runs quickly within the time limit.
2.  **Data Preparation**: Load the training, validation, and test metadata CSVs. Initialize the DataLoaders using `get_dataloaders`. This handles the caching of "Peak Intensity" metadata required for the 2.5D ROI selection.
3.  **Training Loop**: Instantiate the `Trainer` class. Explicitly run a training loop for the specified number of epochs. Inside the loop:
    *   Train for one epoch using `trainer.train_one_epoch`.
    *   Validate using `trainer.validate_one_epoch`.
    *   Track the best validation AUC and save the model checkpoint to `Config.CHECKPOINT_PATH` whenever performance improves.
4.  **Final Evaluation**:
    *   Load the best saved model checkpoint.
    *   Perform a full inference pass on the validation set to collect predictions and ground truth labels.
    *   Calculate and print the `Final Validation Metric` (AUC) with full precision.
5.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample.
    *   Extract metadata features (`flair_slice_count`, `flair_peak_index`) from the validation dataset.
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify potential biases (e.g., does the model fail on scans with fewer slices?).
6.  **Conditional Submission**:
    *   Check if the Final Validation AUC exceeds the threshold `0.6254545454545455`.
    *   If the condition is met, call `trainer.predict_and_submit(test_loader)` to generate the submission file using Test-Time Augmentation (TTA).
