This script demonstrates the end-to-end usage of the provided machine learning pipeline for glioblastoma subtype prediction. It systematically verifies the functionality of the utility functions, the custom EfficientNet model architecture, the data loading pipeline (including 2.5D volume slicing and caching), and the training loop. To ensure the demonstration runs quickly within the time limit, the configuration is overridden to use a minimal subset of data (Debug Mode) and a single training epoch.
