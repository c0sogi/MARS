3.  **`library/train.py`**: Adds a `CosineAnnealingLR` scheduler to the training loop.
4.  **`runfile.py`**: Updates the training call to use the config epoch count and adds the conditional logic to generate a submission only if the validation AUC exceeds the baseline of 0.5696.
