The following script demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Data Utility Verification**: Validates that DICOM files can be read and processed into tensors of the correct shape using `dicom_utils`.
2.  **Dataset Loading**: Demonstrates loading a small subset of the data using `load_dataset` with the `debug_max_samples` parameter, ensuring the caching logic handles the subset correctly.
3.  **Model Instantiation**: Initializes the `AsymmetricEfficientNet` and verifies it produces the correct output shape for a given input tensor.
4.  **Training Loop**: Executes the `train_model` function on a small subset of data to demonstrate the training pipeline, loss calculation, and model checkpointing.
5.  **Inference & Submission**: Runs `generate_submission` on a subset of the test data to produce a valid submission CSV file, verifying the format and output path.
