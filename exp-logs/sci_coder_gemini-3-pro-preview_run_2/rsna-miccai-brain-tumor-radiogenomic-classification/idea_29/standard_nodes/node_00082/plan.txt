Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility using the provided `set_seed` utility (implicitly handled within modules, but good to reinforce).
2.  **Training**: Execute the `train_model` function from `library.trainer`. This handles the entire training loop, including data loading, caching, model optimization, and saving the best model checkpoint based on validation AUC. We will use the full dataset (`debug_max_samples=None`) to ensure maximum performance.
3.  **Validation & Metric Calculation**:
    *   Load the best saved model from disk.
    *   Load the validation dataset using `library.dataset.load_dataset` (leveraging the cache generated during training).
    *   Perform inference on the validation set in evaluation mode (disabling gradients).
    *   Compute the Area Under the ROC Curve (AUC) and print it in the strictly required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample (`|prediction - target|`).
    *   Extract a key metadata feature for analysis: **FLAIR Slice Count** (volume depth). This was identified in the EDA as a variable with high variance.
    *   Compute and print the Pearson correlation between the error magnitude and the slice count to identify if the model struggles with specific volume sizes.
5.  **Submission Generation**:
    *   Compare the calculated validation AUC against the threshold (`0.6303636363636363`).
    *   If the metric exceeds the threshold, invoke `library.inference.generate_submission` to predict on the test set and save the `submission.csv` file.
