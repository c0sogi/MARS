### Implementation Strategy

1.  **Environment Setup**: Import necessary standard libraries and the provided custom library modules (`library.utils`, `library.data`, `library.model`, `library.train`).
2.  **Isolation & Configuration**: Monkey-patch the hardcoded cache paths in `library.data` to point to a specific demo directory (`./working/demo_execution`). This ensures the demo is self-contained and does not conflict with other potential runs.
3.  **Data Preparation**:
    *   Load the existing metadata from `./metadata`.
    *   Create small subsets (e.g., 5-10 samples) of training, validation, and test data.
    *   Save these subsets to the demo directory. This allows the code to run quickly while demonstrating the full pipeline.
4.  **Pipeline Execution**:
    *   **Data Loading**: Initialize `get_dataloaders` using the subset metadata files. Verify the shape of the batches produced.
    *   **Model Initialization**: Instantiate `AsymmetricEfficientNet` and move it to the appropriate device (CPU/GPU). Verify the model output shape with a dummy input.
    *   **Training Loop**: Execute a custom, minimal training loop (1 epoch) using `train_one_epoch` and `validate` from `library.train`.
    *   **Inference**: Generate predictions on the test subset using the trained model.
5.  **Validation**: Assert that loss values are valid, output shapes are correct, and the submission file is generated with the expected format.
