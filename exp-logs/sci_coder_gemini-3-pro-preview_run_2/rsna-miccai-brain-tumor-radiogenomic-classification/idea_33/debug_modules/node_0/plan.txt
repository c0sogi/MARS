This script demonstrates the end-to-end usage of the provided Glioblastoma Subtype Prediction library. It performs the following steps:
1.  **Configuration**: Overrides default configuration settings (e.g., epochs, batch size) to ensure the demonstration runs quickly.
2.  **Data Processing**: Validates the robust DICOM reading and image normalization functions on a sample file.
3.  **ROI Selection**: Generates a Region-of-Interest (ROI) cache for a small subset of the data using the Logical-Consensus strategy.
4.  **Dataset & DataLoader**: Instantiates the custom PyTorch Dataset and DataLoaders, verifying input shapes and data types.
5.  **Model Initialization**: Instantiates the `AsymmetricGroupedEfficientNet` and validates the forward pass with a dummy tensor.
6.  **Training Loop**: Executes a short training run (1 epoch) on the data subset to demonstrate the engine's training logic.
7.  **Inference**: Runs the inference pipeline with Test-Time Augmentation (TTA) and generates a submission file.
