This solution implements the end-to-end pipeline for Glioblastoma Subtype Prediction using the **Asymmetric Grouped EfficientNet** and **Logical-Consensus ROI Selection**.

### Implementation Strategy

1.  **Setup & Configuration**: The script initializes the environment by setting reproducible seeds and loading the configuration from `library.config`.
2.  **Data Loading**: It utilizes the `create_dataloaders` factory to generate the training, validation, and test dataloaders. This step automatically handles the generation or loading of the ROI cache, which maps subjects to their optimal slice triplets based on the consensus of FLAIR and T1wCE intensity profiles.
3.  **Model Initialization**: The `AsymmetricGroupedEfficientNet` is instantiated. This model features a modified stem for 12-channel input (4 modalities $\times$ 3 slices) and asymmetric filter initialization to preserve ImageNet feature diversity across medical modalities.
4.  **Training Loop**: The model is trained using the AdamW optimizer. The training process is managed by `library.engine.run_training`, which handles forward passes, backpropagation, and early stopping based on validation AUC.
5.  **Validation & Failure Analysis**:
    *   The best model checkpoint is loaded.
    *   The final AUC is computed on the hold-out validation set and printed with high precision.
    *   A failure analysis is performed by correlating the prediction error magnitude with input features (specifically, the number of FLAIR slices as a proxy for scan resolution) and the target class, identifying potential biases.
6.  **Submission**: If the validation AUC exceeds the specified threshold (0.63218...), the model generates predictions for the test set using Test-Time Augmentation (TTA) and saves the submission file.
