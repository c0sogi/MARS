The implementation strategy involves the following steps:

1.  **Setup and Initialization**: Initialize the environment by setting random seeds for reproducibility and configuring the logger.
2.  **Model Training**: Execute the training pipeline using the provided `run_training` function from the engine. This handles the training loop, validation per epoch, early stopping, and saves the best model checkpoint.
3.  **Validation and Failure Analysis**:
    *   Load the best-saved model.
    *   Perform inference on the hold-out validation set to calculate the final ROC AUC score.
    *   Print the metric in the strictly required format: `Final Validation Metric: <value>`.
    *   Compute the absolute error for each validation sample.
    *   Extract the "FLAIR Slice Count" feature for each validation subject to serve as a proxy for scan complexity/volume.
    *   Calculate and print the Pearson correlation between the error magnitude and the slice count to identify if the model struggles with specific scan types.
4.  **Submission Generation**:
    *   Compare the final validation AUC against the specified threshold (0.6303636363636363).
    *   If the threshold is exceeded, invoke `generate_submission` to create the submission file using Test-Time Augmentation (TTA) on the test set.
