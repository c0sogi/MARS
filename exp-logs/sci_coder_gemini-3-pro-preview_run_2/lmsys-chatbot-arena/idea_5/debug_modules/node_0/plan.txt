### Implementation Strategy

1.  **Configuration Override**: We will modify the `Config` class attributes at runtime to adapt the pipeline for a quick demonstration. This includes reducing the number of epochs to 1, setting the number of folds to 1, reducing batch sizes, and redirecting output paths to a specific `./working/demo_execution` directory.
2.  **Data Loading & Subsetting**: We will use the `load_data` function to load the full dataset, then immediately slice it to a very small subset (e.g., 20 training samples, 10 test samples). We will save these subsets to the cache directory. This ensures that subsequent calls to `load_data` (used internally by the inference module) pick up this small dataset, guaranteeing fast execution.
3.  **Component Verification**:
    *   **Dataset**: We will instantiate `ChatbotDataset` with the subset and verify that `__getitem__` returns tensors with the correct shapes and types.
    *   **Model**: We will instantiate `SiameseModel`, perform a forward pass with dummy data, and assert the output shape corresponds to the 3 target classes.
4.  **Training Simulation**: We will execute `run_fold` for a single fold using the subsetted data. This demonstrates the training loop, optimizer setup, and model checkpointing without consuming excessive time.
5.  **Inference Simulation**: We will run `generate_submission`. This function will load the model trained in the previous step and the cached test subset to generate a submission file.
6.  **Final Validation**: We will verify that the submission file exists and follows the expected format.
