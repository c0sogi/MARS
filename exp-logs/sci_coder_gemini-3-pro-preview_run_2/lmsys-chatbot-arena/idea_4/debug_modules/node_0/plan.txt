### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and modify runtime parameters (`DEBUG`, `EPOCHS`, `WORKING_DIR`) to ensure the script runs quickly (using a small data subset) and saves outputs to a dedicated demo directory.
2.  **Environment Preparation**: Set random seeds for reproducibility and suppress verbose logging from `transformers` and `torch`.
3.  **Data Pipeline Verification**:
    *   Initialize the tokenizer for `microsoft/deberta-v3-base`.
    *   Generate DataLoaders using `get_dataloaders` with `load_cached_data=False` to trigger fresh processing on the debug subset.
    *   Fetch a single batch from the training loader to validate tensor shapes (input IDs, attention masks, meta-features, and labels).
4.  **Model Architecture Verification**:
    *   Instantiate the `SiameseDeberta` model.
    *   Perform a forward pass with the fetched batch to ensure the model produces logits of the correct shape `(batch_size, 3)`.
5.  **Training Loop Execution**:
    *   Execute `train_model` to simulate a full training cycle (1 epoch on the debug subset).
    *   Verify that the model checkpoint (`demo_model.pth`) is successfully saved.
6.  **Inference and Submission**:
    *   Run `infer` using the trained model on the test set.
    *   Construct a submission DataFrame from the predictions.
    *   Validate the submission format and save it to CSV.
