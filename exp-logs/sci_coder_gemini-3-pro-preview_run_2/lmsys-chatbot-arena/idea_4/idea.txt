# Proposed Strategy: Siamese DeBERTa-Base with Dynamic Layer Fusion

### Model
I propose a **Siamese DeBERTa-Base with Dynamic Layer Fusion**, which upgrades the backbone capacity while introducing a more sophisticated pooling mechanism to capture linguistic features at varying levels of abstraction.

*   **Backbone Architecture:** The model will utilize **`microsoft/deberta-v3-base`**. 
    *   *Rationale:* Previous attempts with this backbone failed because the dataset was subsampled to save time (Cite solution_lesson_node_00015). However, with 24 hours available and an A100 GPU, training this larger model on the **full dataset** is computationally feasible (estimated ~4-5 hours). This addresses the capacity limitations of the `xsmall` model used in the current best solution.
*   **Siamese Processing:** The model will retain the **Siamese Dual-Encoder** structure, processing `(Prompt, Response A)` and `(Prompt, Response B)` as independent passes. This ensures the model can utilize the full 512-token context window for each response without the truncation issues inherent to Cross-Encoders (Cite solution_lesson_node_00002).
*   **Dynamic Layer Fusion (Structural Innovation):** Instead of simple Mean Pooling of the final layer (Cite solution_lesson_node_00008), I will implement **Weighted Layer Pooling**.
    *   *Mechanism:* The model will extract the hidden states from the **last 4 layers** of the transformer. A learnable set of scalar weights (softmax-normalized) will dynamically average these layers to produce the final sentence representations ($u$ and $v$).
    *   *Benefit:* This allows the model to leverage both the high-level semantic reasoning (top layers) and the lower-level syntactic/structural features (middle layers) that are crucial for judging writing quality.
*   **Augmented Classification Head:** The final representations will be fed into a classifier that explicitly combines:
    1.  The fused embeddings: $u, v$.
    2.  Explicit interaction terms: $|u - v|$ and $u \cdot v$ (Cite solution_lesson_node_00009).
    3.  **Meta-Features:** The normalized character lengths of the prompt and both responses, injected directly into the dense layer (Cite solution_lesson_node_00017).

### Data
*   **Preprocessing:** Text will be cleaned, and character lengths will be calculated and normalized (StandardScaler) based on the training set statistics.
*   **Tokenization:** Inputs will be tokenized into pairs `(Prompt, Response A)` and `(Prompt, Response B)` with a maximum length of **512 tokens**.
*   **Dataset Usage:** Crucially, the model will be trained on the **Full Training Dataset** (41,383 samples). We will **not** subsample the data, as data volume was identified as more critical than model size in previous failures (Cite solution_lesson_node_00015).

### Training
*   **Precision:** **Mixed Precision (FP16)** will be enabled to accelerate training and reduce memory usage, ensuring the `base` model fits comfortably on the A100 GPU.
*   **Optimization:** The model will be trained with the AdamW optimizer.
*   **Learning Rate:** A learning rate of **2e-5** will be used to ensure stable fine-tuning of the pre-trained backbone (Cite solution_lesson_node_00004).
*   **Batch Size:** The effective batch size will be kept small (e.g., **8**) to preserve the regularization benefits observed in previous experiments (Cite solution_lesson_node_00018). If memory constraints arise, Gradient Accumulation will be used to match this target, but A100 memory should suffice.
*   **Duration:** Training will be limited to **2 epochs** to prevent the overfitting observed in longer schedules (Cite solution_lesson_node_00011).
*   **Loss Function:** Cross-Entropy Loss.

### Evaluation
*   **Inference:** The test set will be processed through the Siamese backbone. The Dynamic Layer Fusion mechanism will aggregate the hidden states, and the meta-features will be computed and injected to generate the final probability distribution.
