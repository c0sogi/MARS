# Baseline Approach: Frozen Siamese Transformer with MLP Head

### Model
The proposed solution is a **Frozen Siamese Transformer with an MLP Head**. 
*   **Backbone:** Instead of fine-tuning a heavy transformer (like Model 1), this approach uses a lightweight, pre-trained Sentence Transformer (e.g., `all-MiniLM-L6-v2`) strictly as a **frozen feature extractor**. 
*   **Architecture:** The model processes the `Prompt`, `Response A`, and `Response B` independently to produce three dense embedding vectors. 
*   **Feature Construction:** To capture the interaction between the prompt and the responses, these vectors are combined into a single feature representation by concatenating:
    1. The Prompt embedding.
    2. The Response A and Response B embeddings.
    3. The element-wise difference between Response A and Response B (to highlight contrasts).
    4. The element-wise product of Response A and Response B (to highlight similarities).
*   **Classifier:** This rich feature vector is fed into a simple **Multi-Layer Perceptron (MLP)** consisting of fully connected layers, ReLU activations, and Dropout, ending with a Softmax layer to predict the 3-class probabilities (Winner A, Winner B, Tie).

### Data
*   **Preprocessing:** Basic text cleaning will be applied (e.g., handling missing values, trimming whitespace).
*   **Vectorization:** The critical data preparation step involves passing the entire dataset (Train, Validation, and Test) through the frozen transformer backbone **once** before training begins. 
*   **Caching:** The resulting high-dimensional embeddings are cached in memory (RAM). This transforms the complex NLP task into a computationally efficient tabular deep learning task, where the inputs are fixed dense vectors rather than raw text.

### Training
*   **Procedure:** The training loop iterates only over the lightweight MLP, using the pre-computed embeddings as input.
*   **Techniques:** 
    *   **Loss Function:** Cross-Entropy Loss is used to directly minimize the Log Loss metric.
    *   **Optimizer:** The Adam optimizer is employed for stable convergence.
    *   **Efficiency:** Since the backbone is frozen, the model can be trained with large batch sizes (e.g., 256 or 512) and completes epochs in seconds rather than hours.
    *   **Regularization:** Early stopping based on validation loss is used to prevent overfitting.

### Evaluation
*   **Inference:** The test set prompts and responses are vectorized using the same frozen backbone.
*   **Prediction:** These vectors are passed through the trained MLP to output the probability distribution for the three classes.
*   **Output:** The final probabilities are formatted into the submission CSV file.
