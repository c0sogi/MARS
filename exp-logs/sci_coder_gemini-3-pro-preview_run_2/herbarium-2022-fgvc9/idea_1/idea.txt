Based on the task requirements and the provided dataset analysis, here is a highly efficient baseline approach.

### Fixed-Feature Prototype Classifier (Nearest Class Mean)

This approach establishes a performance floor by treating the problem as a "few-shot" retrieval task using robust, pre-trained features. It prioritizes speed by completely eliminating iterative gradient descent training.

**Model**
*   **Architecture**: Use a pre-trained **EfficientNet-B0** (or MobileNetV3) initialized with ImageNet weights. This backbone serves strictly as a **fixed feature extractor**; its weights are frozen and never updated.
*   **Classifier Component**: Instead of a neural layer or decision tree, the classifier is a non-parametric **Prototype Matrix** of shape $(15501, D)$, where $D$ is the feature dimension of the backbone (e.g., 1280 for EfficientNet-B0). Each row in this matrix represents the "Prototype" (centroid) of one species.
*   **Inference Mechanism**: Classification is performed by computing the **Cosine Similarity** between the feature vector of a query image and the 15,501 class prototypes. The class with the highest similarity score is selected.

**Data**
*   **Preprocessing**: All images (train and test) are resized to a standard resolution of **224x224** pixels.
*   **Normalization**: Pixel values are normalized using standard ImageNet mean (`[0.485, 0.456, 0.406]`) and standard deviation (`[0.229, 0.224, 0.225]`).
*   **Augmentation**: **None**. To ensure maximum throughput and reproducibility, no geometric or color augmentations are applied.

**Training**
*   **Strategy**: **One-Shot Calibration** (No Gradient Descent).
    1.  **Extraction**: Perform a single forward pass over the entire training dataset using the frozen backbone to extract a feature vector for every image.
    2.  **Aggregation**: Group the extracted vectors by their ground-truth `category_id`.
    3.  **Prototyping**: Calculate the **mean vector** for each category.
    4.  **Normalization**: L2-normalize each mean vector to unit length and store them in the Prototype Matrix.
*   **Efficiency**: This process requires only one epoch of "training" (feature extraction) and involves no backpropagation, optimizers, or hyperparameter tuning, making it orders of magnitude faster than deep learning or tree-based approaches.

**Evaluation**
*   **Inference**: For each image in the test set:
    1.  Pass the image through the frozen backbone to obtain its feature vector.
    2.  L2-normalize the vector.
    3.  Compute the dot product between this vector and the Prototype Matrix (vectorized matrix multiplication).
    4.  Select the `category_id` corresponding to the maximum dot product.
*   **Submission**: Map the predicted `category_id` to the corresponding image `Id` as required by the submission format.
