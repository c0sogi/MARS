The following script demonstrates the complete pipeline using the provided library files. It first creates a lightweight subset of the training, validation, and test metadata to ensure the demonstration runs quickly (within minutes) while exercising all components. It then initializes the `PlantDataset`, trains the `PrototypeClassifier` (which uses the `FeatureExtractor`), evaluates performance, and generates a submission file. Assertions are included to verify data integrity and output correctness.
