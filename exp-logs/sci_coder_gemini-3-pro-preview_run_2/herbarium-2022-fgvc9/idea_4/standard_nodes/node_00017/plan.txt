The error `RuntimeError: cuDNN error: CUDNN_STATUS_EXECUTION_FAILED` is caused by a mismatch between the model's output dimension (hardcoded as 15501) and the dataset's label indices (which extend to 15505 due to gaps in the taxonomic IDs). This triggers a CUDA device-side assert when the loss function receives a label index outside the valid range `[0, 15500]` (Cite `debug_lesson_2`).

To fix this, I will:
1.  Update `process_taxonomy` in `library/dataset.py` to generate a contiguous `species_idx` mapping (0 to N-1) for the sparse `category_id`s and return the dynamic `num_species` count (Cite `debug_lesson_3`).
2.  Modify `PlantTaxonomyDataset` to use this mapped `species_idx` as the ground truth label.
3.  Update `Trainer` and `InferenceRunner` to initialize the model using the dynamic `num_species` from the metadata, ensuring the model architecture matches the data.
4.  Update `InferenceRunner` to map the model's predicted indices back to the original `category_id`s for the submission.
