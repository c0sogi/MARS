The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup & Data Loading**: Initialize the environment with fixed random seeds for reproducibility. Load the training data from the pre-generated `./metadata/train.csv` file.
2.  **Modality Detection**: Identify the dataset as **Text** based on the columns (`text`, `selected_text`).
3.  **Target Variable Analysis**: Treat `sentiment` as the class label governing the extraction task. Calculate the distribution of sentiments and the class balance ratio.
4.  **Input Data Analysis (Text)**:
    *   **Lengths**: Calculate character and word counts for the input `text`. Report descriptive statistics (mean, std, min, max).
    *   **Vocabulary**: Tokenize the text (whitespace split) to compute the unique vocabulary size and the proportion of rare words (appearing only once) to assess Out-of-Vocabulary (OOV) potential.
5.  **Feature/Signal Relationships**:
    *   **Meta-Feature Creation**: Generate numerical meta-features, including the length of the `selected_text` (target) and the Jaccard similarity score between the input `text` and the `selected_text`.
    *   **Unstructured Relationships**: Analyze how the metadata (`sentiment`) correlates with these meta-features. Specifically, report the mean Jaccard score per sentiment (to reveal if certain sentiments imply copying the whole text) and the correlation between input length and target length.
6.  **Formatting**: Ensure the output is printed in distinct, capitalized sections with floating-point numbers formatted to 4 decimal places.
