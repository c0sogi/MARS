Based on the accumulated lessons, I propose the following optimized strategy. This solution synthesizes the structural superiority of DeBERTa-v3 with the training stability and efficiency protocols required to successfully fine-tune a "Large" architecture on the full dataset.

### Model
- **Backbone Architecture:** Utilize **`microsoft/deberta-v3-large`** as the encoder. This choice is critical for two reasons:
    1.  **Disentangled Attention:** Unlike RoBERTa, DeBERTa uses disentangled matrices for content and position, allowing it to model the *relative* positioning of tokens more effectively. This is superior for span extraction tasks where boundaries depend on local context `Cite solution_lesson_node_00019`.
    2.  **Model Capacity:** Previous experiments confirmed that the "Large" variant (approx. 300M+ parameters) is necessary to capture the nuanced semantic dependencies of this specific dataset `Cite solution_lesson_node_00013`.
- **Structural Innovation (Weighted Layer Pooling):** Replace the standard prediction head (which uses only the final hidden state) with a **Weighted Layer Pooling** head. The model will compute a learnable weighted average of the **last four hidden layers** of the Transformer.
    - *Rationale:* The final layer of a Transformer is often highly specialized for the pre-training objective (MLM). By aggregating the last four layers, the span predictor gains access to a richer hierarchy of features—combining the high-level semantic abstraction of the top layer with the lower-level syntactic information (crucial for boundary detection) preserved in lower layers.
- **Input Representation:** Format the input as `[CLS] <Sentiment> [SEP] <Tweet Text> [SEP]`. This allows the model to dynamically condition the text representation on the sentiment token via self-attention `Cite solution_lesson_node_00009`.

### Data
- **Alignment-Preserving Tokenization:** Perform tokenization strictly on the **raw, un-normalized text**. Do not strip whitespace or normalize punctuation. Crucially, generate and store **offset mappings** that link every sub-word token back to its exact character start and end positions in the original string. This prevents the misalignment issues observed when normalizing text `Cite solution_lesson_node_00017`.
- **Dynamic Padding (Smart Batching):** To address the computational constraints of training a "Large" model, implement **Dynamic Padding**. Sort the training data by sequence length and construct batches from samples of similar lengths. This drastically reduces the number of padding tokens processed, improving training throughput and allowing the model to be trained on the **Full Dataset** within the time limit `Cite solution_lesson_node_00023`.
- **Stratification:** Implement a **5-Fold Stratified Cross-Validation** scheme, stratifying by the `sentiment` label to ensure consistent class distribution across all folds `Cite solution_lesson_node_00014`.

### Training
- **Objective Function:** Utilize **Cross Entropy with Label Smoothing** ($\epsilon=0.1$) for both start and end targets.
    - We explicitly **reject** complex hybrid losses (like Soft Jaccard) proposed in failed ideas. Standard Cross Entropy provides smoother gradients for faster convergence `Cite solution_lesson_node_00026`, while Label Smoothing prevents the model from overfitting to the noisy/subjective boundaries of the manual annotations `Cite solution_lesson_node_00012`.
- **Efficiency Protocol:** Mandate the use of **Mixed Precision (AMP)** training. This is the non-negotiable enabler that allows the memory-heavy "Large" backbone to be trained on the full dataset without subsampling `Cite solution_lesson_node_00023`.
- **Optimization:** Use the **AdamW** optimizer with a **Uniform Learning Rate** (e.g., 1e-5). Avoid complex schedules like Layer-wise Learning Rate Decay (LLRD), which have been proven to cause instability and divergence in this specific fine-tuning setup `Cite solution_lesson_node_00020`.

### Evaluation
- **Ensemble Inference:** For every test sample, generate start and end logit vectors from all 5 trained fold models. **Sum these logits** to create a single, robust probability distribution. This leverages variance reduction to bridge the gap between validation and test performance, ensuring the final prediction is more reliable than any single model `Cite solution_lesson_node_00014`.
- **Decoding & Reconstruction:** Select the indices `(start, end)` that maximize the sum of the averaged log-probabilities (subject to `start <= end`). Use the stored **offset mappings** to extract the exact substring from the original raw tweet `Cite solution_lesson_node_00017`.
- **Neutral Heuristic:** Apply a deterministic override: if the sentiment is "neutral", predict the **entire text** of the tweet.
