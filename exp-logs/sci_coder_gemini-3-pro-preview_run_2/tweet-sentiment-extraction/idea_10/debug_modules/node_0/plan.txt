The following implementation demonstrates the usage of the provided library files for the Tweet Sentiment Extraction task. It covers data loading, model instantiation, training loop execution, evaluation, and utility verification.

**Strategy:**
1.  **Configuration**: Initialize the `Config` class with `debug=True` to use a small subset of the data (100 samples) for rapid execution.
2.  **Data Pipeline**: Use `get_data_loaders` to load the stratified metadata and create PyTorch DataLoaders. We verify the batch structure and the "Smart Batching" logic by checking sequence lengths.
3.  **Model Initialization**: Instantiate the `TweetModel` (DeBERTa-v3-large backbone with custom head). We verify the forward pass output shapes.
4.  **Training & AWP**: Run a single training epoch using `train_fn`. We also explicitly verify the `AWP` (Adversarial Weight Perturbation) class by simulating a gradient step and checking if weights are perturbed and restored correctly.
5.  **Evaluation**: Run `eval_fn` to ensure the decoding logic (converting logits to text) and Jaccard metric computation work as expected.
6.  **Utilities**: Verify the standalone `jaccard` function.
