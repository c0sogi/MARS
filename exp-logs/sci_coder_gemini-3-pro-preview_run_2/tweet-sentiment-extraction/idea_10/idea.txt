Based on the accumulated lessons and the analysis of previous attempts, I propose the following optimized strategy. This solution introduces a **CNN-Enhanced Span Head** and **Adversarial Weight Perturbation (AWP)** to structurally evolve the architecture and training pipeline, addressing the specific challenges of boundary precision and label noise.

### Model

*   **Backbone Architecture:** Utilize **`microsoft/deberta-v3-large`** as the encoder.
    *   **Retention:** This choice is maintained to leverage the **Model Capacity** required for semantic nuance `Cite solution_lesson_node_00013` and the **Disentangled Attention** mechanism, which is superior for modeling relative token positions `Cite solution_lesson_node_00019`.
*   **Structural Innovation (CNN-Enhanced Span Head):** Instead of a simple linear output or the previously proposed pooling, implement a **1D-Convolutional Head** on top of **Weighted Layer Pooling**.
    *   **Mechanism:** First, compute a learnable weighted average of the last four hidden layers of the Transformer to aggregate hierarchical features. Pass this sequence representation through a **1D Convolutional Layer** (kernel size=3, padding=1, GELU activation) before the final linear predictors.
    *   **Rationale:** While Transformers are excellent at capturing global context, the specific start/end boundaries of a phrase often depend on local syntactic cues (e.g., transitions between adjectives and nouns). The CNN layer explicitly refines these local n-gram features, sharpening the boundary detection that the self-attention mechanism might otherwise smooth over.
*   **Input Representation:** Format the input as `[CLS] <Sentiment> [SEP] <Tweet Text> [SEP]` to condition the text representation on the sentiment token `Cite solution_lesson_node_00009`.

### Data

*   **Alignment-Preserving Tokenization:** Perform tokenization strictly on the **raw, un-normalized text**. Do not strip whitespace or normalize punctuation.
    *   **Retention:** Crucially, generate and store **offset mappings** that link every sub-word token back to its exact character start and end positions. This prevents the misalignment issues observed when normalizing text `Cite solution_lesson_node_00017`.
*   **Dynamic Padding (Smart Batching):** Sort the training data by sequence length and construct batches from samples of similar lengths.
    *   **Retention:** This minimizes padding tokens, maximizing computational throughput and allowing the "Large" model to be trained on the full dataset efficiently `Cite solution_lesson_node_00023`.
*   **Stratification:** Implement a **5-Fold Stratified Cross-Validation** scheme, stratifying by the `sentiment` label to ensure consistent class distribution `Cite solution_lesson_node_00014`.

### Training

*   **Objective Function:** Use **Cross Entropy with Label Smoothing** ($\epsilon=0.1$) for both start and end targets.
    *   **Retention:** This stabilizes training by penalizing overconfidence in the noisy/subjective boundaries of the training data `Cite solution_lesson_node_00012`, while avoiding the convergence issues of complex hybrid losses `Cite solution_lesson_node_00026`.
*   **Structural Innovation (Adversarial Training):** Implement **Adversarial Weight Perturbation (AWP)**.
    *   **Mechanism:** Starting from the second epoch, inject small, worst-case perturbations to the model weights during the training step and minimize the loss with respect to these perturbed weights.
    *   **Rationale:** The dataset contains inherent label noise and ambiguity. AWP explicitly flattens the loss landscape, preventing the model from overfitting to sharp, noisy minima. This acts as a powerful regularizer for the high-capacity "Large" backbone, ensuring better generalization to unseen test data.
*   **Efficiency Protocol:** Mandate the use of **Mixed Precision (AMP)** training.
    *   **Retention:** This is the critical enabler that allows the computationally heavier backbone and AWP (which requires extra forward/backward passes) to be trained on the **Full Dataset** within the 24-hour limit `Cite solution_lesson_node_00023`.
*   **Optimization:** Use the **AdamW** optimizer with a **Uniform Learning Rate** (e.g., 1e-5). Avoid complex layer-wise decay schedules `Cite solution_lesson_node_00020`.

### Evaluation

*   **Ensemble Inference:** For every test sample, generate start and end logit vectors from all 5 trained fold models. **Sum these logits** to create a single, robust probability distribution.
    *   **Retention:** This leverages variance reduction to bridge the gap between validation and test performance `Cite solution_lesson_node_00014`.
*   **Decoding & Reconstruction:** Select the indices `(start, end)` that maximize the sum of the averaged log-probabilities (subject to `start <= end`). Use the stored **offset mappings** to extract the exact substring from the original raw tweet `Cite solution_lesson_node_00017`.
*   **Neutral Heuristic:** Apply a deterministic override: if the sentiment is "neutral", predict the **entire text** of the tweet.
