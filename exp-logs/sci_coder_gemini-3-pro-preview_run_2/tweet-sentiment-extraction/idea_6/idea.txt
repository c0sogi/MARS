Based on the comprehensive analysis of the provided lessons and the progression of previous ideas, I propose the following optimized strategy. This solution retains the high-capacity **DeBERTa-v3-Large** backbone (proven superior in `Cite solution_lesson_node_00019` and `Cite solution_lesson_node_00013`) but introduces a **Hybrid Loss Function** and a **Multi-Sample Dropout Head** to explicitly align the optimization process with the Jaccard metric and improve generalization.

### Model
- **Backbone Architecture:** Utilize **`microsoft/deberta-v3-large`** as the encoder. This preserves the **Disentangled Attention** mechanism, which is critical for modeling relative token positions in span extraction `Cite solution_lesson_node_00019`, and maintains the **Large-scale capacity** required to capture nuanced sentiment semantics `Cite solution_lesson_node_00013`.
- **Structural Innovation (Prediction Head):** Replace the standard linear output layer with a **Multi-Sample Dropout** head. Instead of a single path, the output of the transformer is fed into multiple parallel branches (e.g., 5), each with a different dropout mask and a shared linear projection. The outputs are averaged to produce the final logits. This technique acts as an internal ensemble within the model, accelerating convergence and acting as a robust regularizer for the large backbone.
- **Input Representation:** Format the input as `[CLS] <Sentiment> [SEP] <Tweet Text> [SEP]`, allowing the model to condition the text representation on the sentiment token via self-attention `Cite solution_lesson_node_00009`.

### Data
- **Alignment-Preserving Tokenization:** Perform tokenization strictly on the **raw, un-normalized text**. Generate and store **offset mappings** that link every token back to its exact character start and end positions in the original string. This prevents the misalignment issues observed when normalizing text `Cite solution_lesson_node_00017`.
- **Stratification:** Implement a **5-Fold Stratified Cross-Validation** scheme. Split the training data into 5 folds, stratifying by the `sentiment` label to ensure consistent class distribution `Cite solution_lesson_node_00014`.

### Training
- **Objective Function (Structural Innovation):** Implement a **Hybrid Loss Function** that combines **Cross Entropy with Label Smoothing** and a **Soft Jaccard Loss**.
    - **Component 1:** Cross Entropy with Label Smoothing ($\epsilon=0.1$) stabilizes the probability distributions and prevents overconfidence in noisy boundaries `Cite solution_lesson_node_00012`.
    - **Component 2:** Soft Jaccard Loss is a differentiable approximation of the Jaccard metric. By adding this term, the model is explicitly optimized to maximize the overlap between the predicted and target spans, rather than just matching exact indices. This aligns the training objective directly with the competition metric.
- **Optimization:** Train 5 independent models (one per fold) using the **AdamW** optimizer. Crucially, use a **Uniform Learning Rate** (e.g., 1e-5 or 2e-5) for the entire model. Avoid complex schedules like Layer-wise Learning Rate Decay (LLRD), which have been shown to cause instability and divergence when fine-tuning this specific large architecture `Cite solution_lesson_node_00020`.

### Evaluation
- **Ensemble Inference:** For every test sample, generate start and end logit vectors from all 5 trained models. **Sum these logits** to create a single, robust probability distribution. This leverages the variance reduction of the ensemble to outperform single-model baselines `Cite solution_lesson_node_00014`.
- **Decoding & Reconstruction:** Select the indices `(start, end)` that maximize the sum of the averaged log-probabilities (subject to `start <= end`). Use the **offset mappings** derived from the raw-text tokenization to extract the exact substring from the original tweet `Cite solution_lesson_node_00017`.
- **Neutral Heuristic:** Apply a deterministic override: if the sentiment is "neutral", predict the **entire text** of the tweet. This exploits the high correlation (Jaccard $\approx$ 0.98) effectively.
