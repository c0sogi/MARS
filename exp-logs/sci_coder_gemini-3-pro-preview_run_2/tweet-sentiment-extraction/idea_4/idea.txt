Based on the accumulated lessons, I propose the following optimized strategy. This approach combines the structural superiority of the DeBERTa architecture with the high model capacity proven necessary for this task, stabilized by robust regularization and ensembling techniques.

### Model
- **Backbone Architecture (Structural Innovation):** Adopt **`microsoft/deberta-v3-large`** as the encoder backbone. This decision synthesizes two critical insights: it utilizes the **Disentangled Attention** mechanism of DeBERTa (superior for modeling relative positions in span extraction) while adhering to the finding that **Large-scale capacity** (approx. 300M+ parameters) is required to outperform simpler baselines on this specific dataset `Cite solution_lesson_node_00013`.
- **Span Prediction Head:** Maintain the **Pointer Network** architecture `Cite solution_lesson_node_00001`. The model will output two vectors of logits (size `sequence_length`) representing the unnormalized probabilities for the `start` and `end` tokens of the sentiment phrase.
- **Input Representation:** Format the input as `[CLS] <Sentiment> [SEP] <Tweet Text> [SEP]`. This allows the self-attention layers to condition the text representation on the sentiment token `Cite solution_lesson_node_00009`.

### Data
- **Tokenization:** Use the DeBERTa-v3 SentencePiece tokenizer. Crucially, generate and store **offset mappings** that link every token back to its character positions in the original string. This is essential for reconstructing the exact whitespace and punctuation required by the Jaccard metric `Cite solution_lesson_node_00009`.
- **Stratification:** Implement a **5-Fold Stratified Cross-Validation** scheme. The data will be split into 5 folds, stratifying by the `sentiment` label to ensure consistent class distribution. This prepares the data for a robust ensemble `Cite solution_lesson_node_00014`.

### Training
- **Loss Function:** Utilize **Cross Entropy with Label Smoothing** ($\epsilon=0.1$) for both the start and end targets. This specific regularization technique is chosen to prevent the "Large" model from overfitting to the noisy/fuzzy boundaries of the manual annotations, encouraging better generalization `Cite solution_lesson_node_00012`.
- **Optimization:** Train 5 independent models (one per fold) using the AdamW optimizer. Use a linear learning rate scheduler with a warmup period to preserve pre-trained knowledge.
- **Regularization:** Apply dropout within the transformer and the prediction head.

### Evaluation
- **Ensemble Inference:** For every test sample, pass the input through all 5 trained models to generate 5 pairs of start/end logit vectors. **Sum these logits** to create a single averaged probability distribution. This addresses the "OOF-Ensemble Gap" by leveraging the variance reduction of the ensemble, rather than relying on the performance of a single model `Cite solution_lesson_node_00014`.
- **Decoding:** Select the indices `(start, end)` that maximize the sum of the averaged log-probabilities, subject to `start <= end`.
- **Neutral Heuristic:** Apply a deterministic override: if the sentiment is "neutral", predict the **entire text** of the tweet. The data analysis confirms that neutral tweets have a Jaccard score of ~0.98 with the full text, making this a high-confidence shortcut.
- **Reconstruction:** Use the stored **offset mappings** to extract the substring from the original raw text corresponding to the predicted token span.
