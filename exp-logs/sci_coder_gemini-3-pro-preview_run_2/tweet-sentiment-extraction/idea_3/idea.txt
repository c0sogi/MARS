Based on the empirical insights from the provided lessons, I propose the following optimized strategy. This solution moves beyond single-model architectures to a robust **Ensemble of DeBERTa-v3-base** models, integrating structural improvements in the backbone, loss function, and inference pipeline.

### Model
- **Backbone Architecture (Structural Innovation):** Replace the RoBERTa backbone with **DeBERTa-v3-base**. This introduces a fundamental structural change via **Disentangled Attention**, which separates content and position embeddings. This mechanism is superior for span extraction tasks as it better models the relative positioning of words compared to RoBERTa's absolute positional embeddings. This adheres to the guidance to use pre-trained Transformers `Cite solution_lesson_node_00009` while innovating on the specific architecture.
- **Span Prediction Head:** Retain the **Pointer Network** formulation `Cite solution_lesson_node_00001`, where the model outputs two probability distributions (Start and End) over the sequence length.
- **Ensemble Structure:** Instead of scaling to a single "Large" model (which led to overfitting and diminishing returns), implement a **5-Fold Cross-Validation Ensemble**. This aggregates predictions from five independent "Base" models, directly addressing the overfitting and noise issues identified in `Cite solution_lesson_node_00010`.

### Data
- **Tokenization:** Use the DeBERTa-v3 **SentencePiece tokenizer**. Crucially, generate **offset mappings** to map sub-word tokens back to original character indices, ensuring precise extraction.
- **Input Formatting:** Construct the input sequence as `[CLS] <Sentiment> [SEP] <Tweet Text> [SEP]`. This allows the disentangled attention mechanism to condition the text representation on the sentiment token.
- **Stratification:** Split the training data into 5 folds using **Stratified K-Fold**, ensuring that the distribution of sentiment labels is preserved across all folds.

### Training
- **Loss Function:** Apply **Cross Entropy with Label Smoothing** ($\epsilon=0.1$) for both start and end targets. This prevents the model from becoming overconfident in the noisy/subjective boundaries of the training data, improving generalization `Cite solution_lesson_node_00012`.
- **Optimization:** Train each of the 5 fold models independently using the AdamW optimizer with a linear learning rate decay schedule.
- **Regularization:** Apply dropout within the DeBERTa layers and the prediction head.

### Evaluation
- **Inference Aggregation:** For each test sample, generate start and end logit vectors from all 5 ensemble models. **Sum the logits** across models to produce a robust, averaged probability distribution.
- **Decoding:** Select the pair of indices `(start, end)` that maximizes the joint probability (sum of averaged logits), subject to `start <= end`.
- **Sentiment-Conditional Post-Processing:** Explicitly handle the "neutral" class. If the sentiment is "neutral", bypass the span prediction and output the **full text** of the tweet. This exploits the data analysis finding that neutral tweets have a Jaccard score of ~0.98 with the full text, effectively removing the error source for ~40% of the data.
