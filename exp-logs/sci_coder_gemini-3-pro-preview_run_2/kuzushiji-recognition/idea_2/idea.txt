### Model
**Architecture: Cascade R-CNN with ResNet-101-FPN**
I propose a structural evolution from the standard Faster R-CNN to a **Cascade R-CNN** architecture.
*   **Structural Innovation:** Unlike Faster R-CNN, which uses a single detection head with a fixed IoU threshold (0.5), Cascade R-CNN employs a sequence of three detection heads trained with increasing IoU thresholds (e.g., 0.5, 0.6, 0.7). This multi-stage architecture progressively refines the bounding boxes. This is a direct response to **Cite solution_lesson_node_00001**, where the previous segmentation approach failed to separate touching characters. The cascade structure forces the model to learn higher-quality localization, effectively disentangling dense, cursive characters that a single-stage regressor might merge.
*   **Backbone:** Upgrade from ResNet-50 to **ResNet-101**. Given the extreme cardinality of the dataset (3,800+ classes), the deeper network provides the necessary capacity to learn discriminative features for rare characters.
*   **Configuration:** The model will be instantiated using a configuration object to inject parameters, ensuring no silent defaults persist **Cite solution_lesson_node_00023**.

### Data
**Preprocessing & Augmentation**
1.  **Resolution Scaling:** The input images will be resized with `min_size=1024` and `max_size=2048`. This explicit high-resolution constraint is critical to preserving the spatial fidelity of small characters **Cite solution_lesson_node_00005**, **Cite solution_lesson_node_00015**.
2.  **Label Encoding:** Class labels will be offset by `+1` during loading (mapping 0-3847 to 1-3848) to ensure the `0` index is strictly reserved for the background class, preventing the silent suppression of the first character class **Cite solution_lesson_node_00022**.
3.  **Photometric Augmentation:** A `ColorJitter` transform (brightness, contrast, saturation) will be applied to the training pipeline. This acts as a regularizer to prevent overfitting to the paper background, which is necessary when training for extended durations **Cite solution_lesson_node_00020**.

### Training
**Procedure & Optimization**
1.  **Hyperparameters:**
    *   **Batch Size:** 4 (to accommodate the larger ResNet-101 backbone and high resolution).
    *   **Learning Rate:** 0.005. This adheres to the Linear Scaling Rule ($0.02 \times 4/16$) to ensure proper convergence with the reduced batch size **Cite solution_lesson_node_00012**.
2.  **Schedule:** The model will be trained for **15 epochs**, with learning rate decays at epochs 10 and 13. This extended schedule, combined with the delayed annealing, ensures the model has sufficient gradient updates to converge despite the high class count and data augmentation **Cite solution_lesson_node_00007**, **Cite solution_lesson_node_00020**.
3.  **Loss Function:** The Cascade R-CNN will utilize the standard sum of Cross-Entropy (classification) and Smooth L1 (regression) losses across all three stages.

### Evaluation
**Inference Pipeline**
1.  **Proposal Limits:** The Region Proposal Network (RPN) will be configured to keep **2,000 post-NMS proposals** (up from the default 1,000) to prevent valid characters from being discarded before the classification stage **Cite solution_lesson_node_00016**.
2.  **Detection Cap:** The maximum detections per image will be set to **1,200**. This overrides the default cap of 100, ensuring the model can output predictions for the most dense pages (which contain ~600 characters) **Cite solution_lesson_node_00008**.
3.  **Thresholding:** The final confidence threshold for acceptance will be set to **0.35**. This prioritizes Recall in this high-density task, recovering "borderline" characters that may be partially occluded or ambiguous **Cite solution_lesson_node_00013**.
4.  **Submission:** The center point of each predicted bounding box will be calculated and formatted alongside the predicted label.
