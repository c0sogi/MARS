Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `seed_everything` to ensure reproducibility. Define the output path for the submission file as required (`./submission/submission.csv`).

2.  **Training**:
    *   Execute `train_segmenter` to train the Stage 1 U-Net model for character localization.
    *   Execute `train_classifier` to train the Stage 2 ResNet model for character recognition.
    *   Both training functions utilize the provided library code and save model weights to the cache directory.

3.  **Validation**:
    *   Load the validation metadata (`./metadata/val.csv`).
    *   Load the trained models in evaluation mode.
    *   Iterate through the validation dataset, running the full inference pipeline (`process_page`) for each image.
    *   **Metric Calculation**: Implement the modified F1 score logic. For each image, match predicted points to ground truth bounding boxes based on spatial inclusion and label equality. Accumulate True Positives (TP), False Positives (FP), and False Negatives (FN) globally to compute the final F1 score.

4.  **Failure Analysis**:
    *   During validation, record the F1 score and metadata (image width, height, area, number of characters) for each image.
    *   Compute the Pearson correlation coefficient between the F1 score and these metadata features to identify if performance degrades with image size or density.
    *   Print the correlations as required.

5.  **Submission**:
    *   Generate the submission file for the test set using `generate_submission`.
    *   Ensure the file is saved to the specific path `./submission/submission.csv`.

6.  **Output**: Print the final validation metric in the specified format and the failure analysis results.
