### 1. Model: EfficientNet-V2 with Multi-Head Attention Pooling
I propose a structural evolution of the backbone and the aggregation head.
*   **Backbone (EfficientNet-V2-B0)**: We will transition from the standard EfficientNet-B0 to **EfficientNet-V2-B0**. This architecture introduces **Fused-MBConv** blocks in the early stages, replacing the standard depthwise separable convolutions. This structural change is better suited for the dense, continuous nature of spectrograms, offering improved feature extraction efficiency and faster training speeds while maintaining a similar parameter count (~7M) to avoid the overfitting risks of larger models **(Cite solution_lesson_node_00026)**.
    *   **Input Adaptation**: The first projection layer will be modified to accept 1-channel input. Crucially, we will initialize the weights by **summing** the original RGB weights to preserve activation magnitudes **(Cite solution_lesson_node_00019)**.
*   **Head (Multi-Head Attention Pooling)**: We will evolve the single Attention Pooling layer into a **Multi-Head Attention Pooling (MHAP)** mechanism.
    *   *Rationale*: Standard Attention Pooling **(Cite solution_lesson_node_00011)** learns a single saliency map, which forces the model to focus on the "most dominant" feature. However, speech commands often contain disjoint discriminative parts (e.g., the initial "s" and final "p" in "stop").
    *   *Structure*: We will project the feature map into $N$ (e.g., 4) parallel subspaces. In each subspace, we apply **2D Spatial Attention** **(Cite solution_lesson_node_00032)** to generate a head-specific context vector. These vectors are concatenated to form the final representation. This allows the model to attend to multiple distinct temporal-spectral regions simultaneously.

### 2. Data: High-Fidelity Spectral Oversampling & Noise Injection
The data pipeline will be structurally enhanced to maximize signal quality and robustness.
*   **Spectral Oversampling**: We will generate Log-Mel Spectrograms on-the-fly using a window size of **25ms** (400 samples) but an FFT size (`n_fft`) of **1024**.
    *   *Rationale*: This configuration implicitly applies zero-padding to the windowed signal, interpolating the frequency spectrum. This increases the density of the Mel-filterbank inputs, reducing quantization noise and improving feature robustness **(Cite solution_lesson_node_00034)**.
*   **High Temporal Resolution**: We will maintain a hop length of **10ms** (160 samples) to ensure rapid phonemic transitions are resolved and not smeared **(Cite solution_lesson_node_00016)**.
*   **Background Noise Injection**: We will introduce a new augmentation step: dynamically mixing random segments from the `_background_noise_` folder into the speech command clips with varying Signal-to-Noise Ratios (SNR). This forces the Attention mechanism to actively learn to suppress non-stationary noise, complementing the static masking of SpecAugment.
*   **Calibrated SpecAugment**: We will apply Time and Frequency masking. The mask parameters will be calibrated to be a conservative fraction (<20%) of the input dimensions to act as a regularizer without destroying the signal **(Cite solution_lesson_node_00005)**.
*   **Sampling**: We will strictly employ a `WeightedRandomSampler` to ensure every training batch contains a balanced distribution of the 12 classes **(Cite solution_lesson_node_00001)**.

### 3. Training: Optimization for Generalization
*   **Loss Function**: We will use Cross-Entropy Loss with **Label Smoothing (0.1)**. This prevents the model from becoming overconfident and encourages the learning of robust, clustered feature representations **(Cite solution_lesson_node_00013)**.
*   **Batch Size Strategy**: We will use a small batch size of **32**. This ensures a high frequency of gradient updates, which is critical for convergence and generalization on this dataset size, avoiding the pitfalls of large-batch training **(Cite solution_lesson_node_00031)**.
*   **Optimizer**: We will use **AdamW** with a **Cosine Annealing** learning rate scheduler.
*   **Regularization**: We will **exclude Mixup** to prioritize faster convergence, relying on the Noise Injection and calibrated SpecAugment for regularization **(Cite solution_lesson_node_00007)**.

### 4. Evaluation
*   **Inference**: Test audio clips will be processed using the same high-fidelity parameters (1024 FFT, 10ms hop) and passed through the trained model.
*   **Prediction**: The model will output class probabilities via Softmax. The label corresponding to the highest probability will be selected. The `unknown` label is predicted naturally if its probability is highest.
