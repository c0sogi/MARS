Implementation strategy:
1.  **Setup**: Initialize the environment using the provided `library` modules. Set random seeds and detect the computation device (GPU).
2.  **Training**: Execute the training pipeline using `train.run_training`. To comply with the "fast baseline" requirement while working within the constraints of the provided library (which hardcodes the dataset path in default arguments), I will limit the training to **10 epochs**. This ensures the run completes quickly (approx. 10-15 minutes on A100) while utilizing the full dataset to maximize performance.
3.  **Validation**: Load the best model checkpoint saved during training. Run inference on the validation set to collect predictions, true labels, and confidence scores. Calculate and print the **Multiclass Accuracy** with full precision.
4.  **Failure Analysis**: Analyze the validation results to identify error patterns.
    *   Calculate the correlation between the **Error Magnitude** (0 for correct, 1 for incorrect) and the **Label ID** to see if specific classes are more error-prone.
    *   Calculate the correlation between **Error** and **Prediction Confidence** (max probability) to assess model calibration.
    *   Print class-wise accuracy.
5.  **Submission**: Compare the final validation accuracy against the strict threshold of `0.9853666694539677`. If the threshold is exceeded, generate the submission file using `inference.generate_submission`.
