The following script demonstrates the usage of the provided library modules for the Speech Command Recognition task.

**Implementation Strategy:**
1.  **Configuration & Setup**: Verify the configuration module and set random seeds for reproducibility.
2.  **Data Preparation (Subset)**: To ensure the demonstration runs quickly, we create small subsets (100 samples) of the training, validation, and test metadata files. We then dynamically update the `config` module paths to point to these temporary subsets.
3.  **Dataset & DataLoader Verification**: Instantiate the `SpeechCommandDataset` and `DataLoader`. We fetch a single batch to verify the shape of the input spectrograms (Batch, 1, n_mels, time) and the targets.
4.  **Model Verification**: Instantiate the `ConvNeXtSpeech` model. We perform a dummy forward pass with the fetched batch to confirm the output shape matches `(Batch, Num_Classes)` and check parameter counts.
5.  **Training Loop Demonstration**: Execute a short training run (2 epochs) using `train.run_training`. This verifies the training pipeline, loss calculation, backpropagation, and checkpoint saving.
6.  **Inference Demonstration**: Run the inference pipeline using `inference.generate_submission` on the test subset. We verify that the submission file is generated correctly and matches the expected format.
7.  **Cleanup**: The script uses the `./working` directory for temporary files and model checkpoints.
