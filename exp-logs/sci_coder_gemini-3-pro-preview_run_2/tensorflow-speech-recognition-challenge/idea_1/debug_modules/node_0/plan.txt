### Implementation Strategy

1.  **Configuration Setup**: We will import the `Config` class and override specific parameters (`NUM_EPOCHS`, `DEBUG`, `DEBUG_SUBSET_SIZE`) to ensure the demonstration runs quickly (within minutes) while still exercising the full pipeline.
2.  **Dataset Verification**: We will instantiate the `SpeechCommandDataset` and `DataLoader` to verify that audio files are correctly loaded, processed into Mel-Spectrograms, and batched. We will assert the tensor shapes of the inputs and labels.
3.  **Model Verification**: We will instantiate the `SimpleConvNet` model and perform a forward pass with a batch of data from the loader. We will assert that the output logits have the expected shape `(Batch_Size, Num_Classes)`.
4.  **Training Pipeline**: We will execute the `train()` function from the `trainer` module. This will demonstrate the training loop, loss calculation, backpropagation, validation, and model checkpointing.
5.  **Inference Pipeline**: We will execute the `generate_submission()` function from the `inference` module. This will load the trained checkpoint, perform inference on the test set, and generate the `submission.csv` file.
6.  **Output Validation**: Finally, we will verify that the submission file exists and follows the required format.
