This script demonstrates the end-to-end workflow of the speech command recognition system using the provided library. It performs the following steps:
1.  **Configuration**: Overrides default configuration parameters (batch size, epochs, subset size) to ensure the demo runs quickly and uses a separate working directory.
2.  **Data Loading**: Uses `get_dataloaders` to process a small subset of the audio data, converting waveforms into spectrograms and creating PyTorch DataLoaders. It verifies the shape of the generated batches.
3.  **Model Initialization**: Instantiates the `SwinAudioClassifier`, moves it to the appropriate device, and performs a dummy forward pass to verify output dimensions.
4.  **Training**: Runs a single epoch of training using the `Trainer` class to demonstrate the training loop and checkpoint saving mechanism.
5.  **Inference**: Generates predictions on the test subset using `generate_submission` and validates the format of the output CSV file.
