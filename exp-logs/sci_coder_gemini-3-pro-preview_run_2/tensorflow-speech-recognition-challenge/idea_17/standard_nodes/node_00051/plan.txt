The implementation strategy follows the "Fully GPU-Resident End-to-End Pipeline" design.

1.  **Initialization**: We set the random seed for reproducibility and detect the available device (A100 GPU).
2.  **Data Loading**: We use `load_dataset_to_memory` to load the entire dataset (waveforms and labels) into RAM. The `Trainer` class will subsequently move these tensors to the GPU VRAM, eliminating CPU-GPU transfer bottlenecks during training.
3.  **Training**: We instantiate the `Trainer` and execute `trainer.fit()`. This runs the training loop with:
    *   Weighted Random Sampling for class balance.
    *   On-the-fly GPU augmentation (Noise Mixing, SpecAugment).
    *   EfficientNetV2-B0 backbone with EMA (Exponential Moving Average) updates.
4.  **Evaluation**:
    *   We compute the `Final Validation Metric` using the best EMA model weights.
    *   We perform **Failure Analysis** by running inference on the validation set to obtain element-wise predictions. We calculate signal metrics (Max Amplitude, RMS Energy) from the raw waveforms and compute their correlation with prediction errors to identify potential systematic weaknesses (e.g., sensitivity to low volume).
5.  **Submission**:
    *   We check if the validation accuracy exceeds the strict threshold of `0.9867045739610335`.
    *   If successful, we generate the submission file using `trainer.predict_submission()`.
