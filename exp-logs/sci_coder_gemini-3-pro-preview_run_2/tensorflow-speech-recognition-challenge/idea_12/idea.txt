### 1. Model: EfficientNetV2-B0 with Fused-MBConv & Single-Head Attention
I propose a structural evolution that combines the architectural efficiency of **EfficientNetV2** with the proven **Single-Head Attention Pooling**, explicitly correcting the normalization error that caused the failure of Idea 10.

*   **Backbone (EfficientNetV2-B0)**: We will utilize the **EfficientNetV2-B0** architecture.
    *   **Structural Innovation**: Unlike V1 (used in Idea 8), V2 employs **Fused-MBConv** blocks in the early stages. This replaces depthwise-separable convolutions with standard convolutions, which are empirically better suited for the dense, continuous nature of spectrograms compared to the sparse patterns of natural images **(Cite solution_lesson_node_00035)**.
    *   **Input Adaptation**: We will modify the first projection layer to accept 1-channel input. Crucially, we will initialize the weights by **summing** the original RGB weights to preserve activation magnitudes **(Cite solution_lesson_node_00019)**.
*   **Head (Single-Head 2D Attention Pooling)**: We will employ a **Single-Head Attention Pooling** layer.
    *   *Mechanism*: This layer applies a learned weighting mask over the 2D (Time-Frequency) feature map. It acts as a "Voice Activity Detector," localizing the speech command and suppressing background noise before aggregation. We reject Multi-Head variants as they introduce redundancy for single-event detection **(Cite solution_lesson_node_00035)** and reject 1D pooling to preserve spectral discrimination **(Cite solution_lesson_node_00032)**.

### 2. Data: High-Fidelity Signal Pipeline with Waveform Noise Injection
The data pipeline will be restructured to combine **Waveform-Domain Augmentation** with **High-Fidelity Spectral Extraction**, ensuring the model learns robustness to noise without sacrificing signal resolution.

*   **Waveform Noise Injection**: Before spectrogram generation, we will dynamically mix random segments from the `_background_noise_` folder into the training clips with a randomized Signal-to-Noise Ratio (SNR). This forces the Attention mechanism to actively learn to suppress non-stationary noise, a capability that static SpecAugment cannot fully provide.
*   **Spectral Oversampling**: We will generate Log-Mel Spectrograms on-the-fly using a window size of **25ms** (400 samples) but an FFT size (`n_fft`) of **1024**. This zero-padding interpolates the frequency spectrum, reducing quantization noise and increasing feature density **(Cite solution_lesson_node_00034)**.
*   **High Resolution**: We will use **128 Mel bins** to capture fine phonetic details **(Cite solution_lesson_node_00039)** and a **10ms hop length** to resolve rapid temporal transitions **(Cite solution_lesson_node_00011)**.
*   **Instance Normalization**: We will apply **Instance Normalization** to each spectrogram (standardizing to zero mean, unit variance). This is the critical correction to Idea 10, ensuring the input distribution matches the pretrained backbone's expectations **(Cite solution_lesson_node_00038)**.
*   **Calibrated SpecAugment**: We will apply Time and Frequency masking. Mask parameters will be calibrated to be a conservative fraction (<20%) of the input dimensions **(Cite solution_lesson_node_00005)**.
*   **Sampling**: We will strictly employ a `WeightedRandomSampler` to balance the 12 classes in every batch **(Cite solution_lesson_node_00001)**.

### 3. Training: Robust Optimization with EMA
*   **Model EMA (Exponential Moving Average)**: We will maintain a shadow copy of the model weights updated via a moving average. This stabilizes training against the high variance introduced by the Waveform Noise Injection and typically yields better generalization.
*   **Loss Function**: We will use Cross-Entropy Loss with **Label Smoothing (0.1)** to prevent overconfidence and encourage robust clustering **(Cite solution_lesson_node_00013)**.
*   **Batch Size**: We will use a small batch size of **32**. This ensures a high frequency of gradient updates (~14k updates), which is critical for convergence on this dataset size **(Cite solution_lesson_node_00031)**.
*   **Optimizer**: We will use **AdamW** with a **Cosine Annealing** learning rate scheduler.

### 4. Evaluation
*   **Inference**: Test audio clips will be processed using the **EMA weights** of the trained model. The preprocessing will mirror the training pipeline (Spectral Oversampling: 1024 FFT, 128 Mels, 10ms Hop) and strictly apply **Instance Normalization**.
*   **Prediction**: The model will output class probabilities via Softmax. The label corresponding to the highest probability will be selected.
