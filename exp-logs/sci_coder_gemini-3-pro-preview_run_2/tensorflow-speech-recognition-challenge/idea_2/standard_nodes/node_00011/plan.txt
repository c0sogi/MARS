The implementation strategy involves the following steps:

1.  **Setup and Configuration**: Initialize the environment using the provided `Config` and `set_seed` to ensure reproducibility.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. This utilizes the `AudioEfficientNet` with Attention Pooling and the `WeightedRandomSampler` to handle class imbalance. We will use the full dataset to ensure we meet the high accuracy threshold required for submission, relying on the A100 GPU for speed.
3.  **Validation and Metrics**: Load the best saved model state. Perform inference on the validation set to calculate the final Multiclass Accuracy. This metric determines whether we proceed to submission.
4.  **Failure Analysis**: Analyze the validation results by calculating the "Error Magnitude" (confidence gap for the true class) and correlating it with input signal statistics (mean and standard deviation of the spectrograms). This identifies if signal loudness or complexity affects performance.
5.  **Submission**: If the validation accuracy exceeds the strict threshold of `0.9539259135379212`, generate predictions for the test set. Map the predicted class IDs back to string labels and save the `submission.csv` in the required format.
