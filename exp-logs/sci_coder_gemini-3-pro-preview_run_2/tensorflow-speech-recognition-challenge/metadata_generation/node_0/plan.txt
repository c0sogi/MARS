The following script generates metadata files for the Speech Commands dataset.

**Implementation Strategy:**
1.  **Data Discovery**: The script traverses the `./input/train/audio` directory. It identifies the label for each file based on its parent folder.
    *   Files in `_background_noise_` are labeled as `silence`.
    *   Files in folders matching the 10 target commands (`yes`, `no`, `up`, `down`, `left`, `right`, `on`, `off`, `stop`, `go`) keep their folder name as the label.
    *   Files in all other folders are labeled as `unknown`.
2.  **User ID Extraction**: For all non-noise files, the script extracts the User ID from the filename (the part before the first underscore) to enable group-based splitting.
3.  **Dataset Splitting**:
    *   It uses `GroupShuffleSplit` (with `RANDOM_STATE=42`) to split the data into 80% training and 20% validation based on User IDs. This ensures that clips from the same speaker do not leak between training and validation sets.
    *   The `_background_noise_` files (which lack User IDs) are assigned exclusively to the training set to serve as source material for silence augmentation.
4.  **Test Data**: It traverses `./input/test/audio` to generate metadata for the test set.
5.  **Output**: The metadata is saved as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
6.  **Validation**: The script reloads the generated metadata to verify file existence (checking 1000 random paths), asserts that there is no user leakage between train and validation sets, and prints summary statistics.
