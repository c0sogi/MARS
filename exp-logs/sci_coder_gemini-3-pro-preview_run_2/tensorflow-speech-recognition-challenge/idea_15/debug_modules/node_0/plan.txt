This script demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Data Preparation**: Creates small subsets of the training, validation, and test metadata to ensure the demonstration runs quickly.
2.  **Configuration Override**: Modifies the global `Config` to point to these subsets and sets temporary cache locations.
3.  **Dataset Initialization**: Instantiates `GPUResidentDataset` for all three splits, verifying data loading and tensor shapes.
4.  **Model & Frontend Verification**: Instantiates `EfficientNetV2Audio`, runs a dummy forward pass to verify output shapes, and checks the background noise buffer.
5.  **Training Loop**: Uses the `Engine` class to train the model for a few epochs on the subset, validating the training process and checkpoint saving.
6.  **Inference**: Runs predictions on the test subset and generates a submission file.
