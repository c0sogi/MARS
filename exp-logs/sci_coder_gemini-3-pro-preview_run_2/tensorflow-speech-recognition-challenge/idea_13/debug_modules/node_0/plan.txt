This script demonstrates the end-to-end usage of the provided library files to train a speech command recognition model.

**Strategy:**
1.  **Configuration Override**: We dynamically modify the default values of the `TrainConfig` dataclass to enable `debug` mode and reduce training epochs/batch size. This ensures the demonstration runs quickly (under 5 minutes) without modifying the source files.
2.  **Component Verification**: We instantiate the `SpeechCommandsDataset` and `AudioEfficientNetV2` individually to verify their input/output shapes and logic (e.g., spectrogram dimensions, class count).
3.  **Training Loop**: We utilize the `Trainer` class to execute a short training run (2 epochs). This demonstrates the integration of the dataset, model, optimizer, and scheduler.
4.  **Inference & Submission**: We load the trained model checkpoint, run inference on a subset of the test data, and generate a valid `submission.csv` file, verifying the format.
