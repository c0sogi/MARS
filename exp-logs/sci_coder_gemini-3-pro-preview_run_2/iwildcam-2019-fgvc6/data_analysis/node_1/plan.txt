The execution failure is caused by a `PicklingError` because `ProcessPoolExecutor` attempts to pickle the `process_image` function to send it to worker processes. However, since the script is running inside an `exec()` environment, the function cannot be properly looked up by the child processes. To fix this, I will replace `ProcessPoolExecutor` with `ThreadPoolExecutor` in `runfile.py`. This approach uses threads instead of processes, which share the same memory space and do not require pickling the function, thereby resolving the error while maintaining parallel execution for the I/O-bound image processing tasks.
