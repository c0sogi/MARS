I will optimize the solution by upgrading the model architecture and extending the training duration, guided by the provided lessons.

1.  **Model Upgrade (EfficientNet-B4)**: I will replace EfficientNet-B3 (300x300) with **EfficientNet-B4 (380x380)**. The higher native resolution of B4 (380px vs 300px) will better preserve fine-grained features of small animals, directly addressing the need to "match model resolution to object scale" (Cite `solution_lesson_node_00022`).
2.  **Extended Linear Warmup**: I will increase the Stage 1 (Head Alignment) training from 1 epoch to **3 epochs**. This ensures the classification head is robustly aligned with the feature space before unfreezing the backbone, preventing gradient shock (Cite `solution_lesson_node_00018`).
3.  **Extended Fine-Tuning**: I will increase the Stage 2 (Fine-Tuning) training from 3 epochs to **8 epochs**. The previous run showed the validation F1 score rising sharply at the end of epoch 3 (0.33 -> 0.37 -> 0.39), indicating premature termination. With the 4-hour time limit, we can afford the additional compute time for B4 (estimated ~2.5 hours total).
4.  **Batch Size Adjustment**: I will reduce the batch size from 64 to **32** to accommodate the larger memory footprint of EfficientNet-B4 and the increased resolution.
