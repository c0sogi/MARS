Based on the lessons learned from the previous Linear Probing experiments, I propose a **Two-Stage Transfer Learning Strategy with Hybrid Pooling**. This approach evolves the solution from a static feature extraction pipeline to a dynamic, end-to-end learning framework. This structural innovation addresses the primary weakness of the previous attempts: the inability of fixed ImageNet features to adapt to the specific domain shift between the Southern California training set and the Idaho test set.

### Model
The architecture will be a custom modification of a standard **ResNet50** backbone.
*   **Backbone:** We will use a ResNet50 pre-trained on ImageNet. Unlike previous iterations, this backbone will not remain entirely frozen; specific stages will be unlocked for training.
*   **Hybrid Pooling Neck:** Standard CNNs typically use only Global Average Pooling (GAP) before the classifier. We will replace this with a **Concatenated Pooling Layer** that joins the output of Global Average Pooling (GAP) and Global Max Pooling (GMP). This ensures the model captures both the general scene context (via GAP) and the high-intensity features of small or partially occluded animals (via GMP), which are critical for this task. **Cite {solution_lesson_node_00010}**.
*   **Head:** A single Linear layer mapping the concatenated features (4096 dimensions) to the 23 class logits.

### Data
*   **Preprocessing:** Images will be resized to 224x224 and normalized using ImageNet statistics.
*   **Augmentation:** During the training phase, we will introduce mild geometric augmentations (e.g., Random Horizontal Flip) to improve the robustness of the fine-tuned features. Validation and Testing will remain deterministic.
*   **Sampling:** We will continue to use the provided metadata to ensure the validation set respects the location-based split, preventing data leakage.

### Training
The training procedure is a **Two-Stage Pipeline** designed to maximize convergence speed and stability:

1.  **Stage 1: Linear Warmup (Convex Optimization)**
    *   **Configuration:** The ResNet50 backbone is completely frozen. Only the linear classification head is trainable.
    *   **Optimizer:** We will use **L-BFGS** with a learning rate of **1.0**. This leverages the convexity of the linear problem to rapidly find the optimal initialization for the classifier weights without fiddling with step sizes. **Cite {solution_lesson_node_00008}**.
    *   **Loss:** Cross-Entropy Loss weighted inversely by class frequency to handle the severe class imbalance.

2.  **Stage 2: Fine-Tuning (Feature Adaptation)**
    *   **Configuration:** We will unfreeze the final convolutional block (Layer 4) of the ResNet50 backbone. This allows the model to adjust its high-level feature representations to the specific textures and lighting of the camera trap data (domain adaptation).
    *   **Optimizer:** We will switch to **AdamW** with a significantly lower learning rate (e.g., 1e-4) and cosine annealing scheduler to carefully adjust the pre-trained weights without destroying them.
    *   **Checkpointing:** To ensure we capture the true optimal state during this non-convex optimization phase, we will implement a validation loop that saves the best model weights using `copy.deepcopy(model.state_dict())`. This prevents the "saved" weights from being implicitly updated by the optimizer in subsequent steps. **Cite {solution_lesson_node_00003}**.

### Evaluation
*   **Inference:** The final model (restored from the best deep-copied checkpoint) will be used to predict classes for the test set.
*   **TTA (Optional):** If compute time permits, we may apply Test Time Augmentation (averaging predictions of the original and horizontally flipped images) to further boost robustness.
