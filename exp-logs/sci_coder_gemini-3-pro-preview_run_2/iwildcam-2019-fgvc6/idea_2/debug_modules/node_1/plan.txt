The issue identified in the execution traceback is a `TypeError` caused by passing a NumPy array (loaded via OpenCV) directly to `torchvision.transforms.Resize`, which expects a PIL Image or PyTorch Tensor. To fix this, the image must be converted from a NumPy array to a PIL Image within the `AnimalDataset` class before any transformations are applied. This ensures compatibility with the transformation pipeline defined in `library/utils.py`.
