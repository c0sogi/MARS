The strategy involves the following steps:
1.  **Setup and Directory Creation**: Initialize the script, define input/output directories, and create the `./metadata` directory.
2.  **Data Loading**: Read `train.csv` and `test.csv` from the `./input` directory.
3.  **Path Construction**: Generate relative file paths for images (e.g., `train_images/{id}.jpg`) and append them to the DataFrames.
4.  **Dataset Splitting**:
    *   Check for the presence of a `location` column to decide between Group Sampling and Stratified Sampling. If `location` is absent, default to Stratified Sampling based on the `Category` column as per the requirements for a classification task.
    *   Split the training data into training and validation sets with an 80:20 ratio using `RANDOM_STATE = 42`.
5.  **Metadata Generation**: Save the processed DataFrames (train, val, test) to `./metadata` as CSV files.
6.  **Verification**:
    *   **Load**: Read the generated metadata files back.
    *   **Statistics**: Print shapes and class distributions.
    *   **File Resolution**: Randomly sample 1000 paths from each dataset and verify they exist in `./input`. Raise an error if the missing ratio exceeds 0.5.
    *   **Split Validation**: Assert the split ratio is correct and that the stratification/grouping logic held.
