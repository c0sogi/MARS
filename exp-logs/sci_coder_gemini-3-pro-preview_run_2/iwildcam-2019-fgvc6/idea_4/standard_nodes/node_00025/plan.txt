The implementation strategy involves creating a single, self-contained Python script `runfile.py` that orchestrates the entire machine learning pipeline using the provided library modules (`config`, `dataset`, `model`).

1.  **Setup and Configuration**: The script starts by importing necessary libraries and the provided modules. It overrides specific configurations in `config.py` to enable a "Fast Baseline" mode. This involves setting `DEBUG = True` and defining a `DEBUG_SAMPLE_SIZE` (30,000 images) to limit the training data, ensuring the process completes within the time limit. Epoch counts for both training stages are also reduced.
2.  **Data Loading**: It calls `dataset.get_dataloaders()` to retrieve the training and validation data loaders.
3.  **Model Initialization**: The `EfficientNetB4Native` model is initialized and moved to the GPU. A weighted CrossEntropyLoss is set up to handle class imbalance.
4.  **Two-Stage Training**:
    *   **Stage 1**: The backbone is frozen, and only the head is trained using the Adam optimizer. The best model based on validation F1 score is saved.
    *   **Stage 2**: The top blocks of the backbone are unfrozen. The model is fine-tuned using AdamW and a Cosine Annealing scheduler. The best model weights are updated if performance improves.
5.  **Full Validation**: After training, `config.DEBUG` is set to `False`, and data loaders are re-initialized to load the **entire** validation and test sets. The best model is loaded, and the final validation metric (Macro F1) is computed and printed in the required format.
6.  **Failure Analysis**: The script performs inference on the validation set to identify errors. It loads the validation metadata, calculates the error magnitude (binary error), and computes the correlation between this error and input features like `location`, `hour`, and `frame_num`.
7.  **Submission**: If the final validation F1 score exceeds the specified threshold, the model generates predictions for the test set. These are saved to `./submission/submission.csv` in the required `Id,Predicted` format.
