Implementation Strategy:
1.  **Configuration Setup**: Import the `library.config` module and override key parameters to optimize for speed. This includes enabling `DEBUG` mode (to use a small data subset), reducing `BATCH_SIZE`, setting `NUM_EPOCHS` for both stages to 1, and disabling `PRETRAINED` weight downloads to save time.
2.  **Dataset Verification**: Use `library.dataset` to initialize DataLoaders. Fetch a single batch to verify the shape and data types of inputs (images) and targets (labels). Verify that class weights can be calculated without error.
3.  **Model Verification**: Instantiate the `EfficientNetB4Native` model from `library.model`. Perform a forward pass with the sample batch to confirm the output shape corresponds to `(Batch_Size, Num_Classes)`. Verify the logic of `freeze_backbone` and `unfreeze_blocks` by inspecting the `requires_grad` attribute of specific parameters.
4.  **Pipeline Integration**: Execute the full training pipeline using `library.trainer.run()`. Since the configuration has been adjusted for speed, this serves as a fast integration test to ensure all components work together correctly.
5.  **Output Validation**: After the training run, verify that the submission CSV file is created at the expected path and contains the required columns (`Id`, `Predicted`) with the correct data types.
