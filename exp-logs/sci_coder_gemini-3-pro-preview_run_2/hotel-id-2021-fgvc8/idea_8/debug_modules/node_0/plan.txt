### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `seed_everything` and access the `Config` class. We will define a lightweight backbone (`resnet18`) and reduced image size for the demonstration to ensure rapid execution.
2.  **Data Pipeline Verification**: Use `get_dataloaders` with `debug=True` and a small `debug_sample_size` (50 images). Verify that the `train_loader` produces batches of the correct shape and type.
3.  **Model Initialization & Forward Pass**: Instantiate the `HotelRecognitionModel`. Perform a forward pass with labels (training mode) to verify the output logits shape (checking the Sub-Center ArcFace head) and without labels (inference mode) to verify the embedding shape.
4.  **Training Loop Demonstration**: Initialize the `SubCenterArcFaceLoss` and an optimizer. Use the `Trainer` class to run a single epoch of training on the debug subset. Verify that the loss decreases or is at least calculated without error, and that a checkpoint is saved.
5.  **Inference Component Verification**:
    *   Extract features using `extract_features` on the validation loader (acting as a gallery) and test loader (query).
    *   Demonstrate `database_augmentation` (DBA) on the gallery embeddings.
    *   Demonstrate `query_expansion` (QE) using the query and refined gallery embeddings.
    *   Verify that the shapes of the embeddings remain consistent after these operations.
6.  **Submission Generation**: Use the `generate_submission` function with the processed embeddings to create a sample submission file. Verify the file's existence and format.
