This script orchestrates the end-to-end training and evaluation pipeline for the Hotel ID classification task. It leverages the provided library modules to load data, initialize a ResNet-18 model, and perform training with a limited number of epochs (5) to ensure execution within the time limits while establishing a solid baseline.

The script performs the following key steps:
1.  **Setup**: Initializes random seeds and detects the computation device (GPU).
2.  **Data Loading**: Loads training, validation, and test DataLoaders using cached metadata.
3.  **Training**: Trains the model using Adam optimizer and ReduceLROnPlateau scheduler. It uses a CrossEntropyLoss with label smoothing to handle the large number of classes.
4.  **Validation**: Computes and prints the final Mean Average Precision @ 5 (MAP@5) on the hold-out validation set.
5.  **Failure Analysis**: Evaluates the model on the validation set to calculate per-sample error. It then correlates this error with input features such as the number of training samples per class (class frequency) and the hotel chain ID to identify performance drivers.
6.  **Submission**: Generates predictions for the test set and saves them to `submission.csv`.
