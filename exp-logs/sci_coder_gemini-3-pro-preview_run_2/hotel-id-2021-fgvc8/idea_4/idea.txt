# Idea 4: Hierarchical Multi-Task Metric Learning with Query Expansion

### Model
To further refine the embedding space and leverage the available metadata, I propose a **Hierarchical Multi-Task** architecture.
*   **Backbone**: Upgrade the backbone to **EfficientNet-B5**. This model offers a higher capacity than the EfficientNet-B4 used previously (Cite solution_lesson_node_00011), allowing it to capture even finer architectural details required to distinguish between the 7,770 hotels.
*   **Neck**: Retain the **Generalized Mean (GeM) Pooling** layer to efficiently aggregate spatial features.
*   **Heads (Structural Innovation)**: Instead of a single output head, the model will feature a **Dual-Head** design to exploit the dataset's hierarchical taxonomy:
    1.  **Fine-Grained Head**: A **Sub-Center ArcFace** head ($K=3$) for the 7,770 `hotel_id` classes. This preserves the successful multi-modal handling of intra-class variance (e.g., bedrooms vs. exteriors) established in previous experiments (Cite solution_lesson_node_00011).
    2.  **Coarse-Grained Head**: An auxiliary **ArcFace** head ($K=1$) for the 88 `chain_id` classes.
    *   *Mechanism*: By jointly optimizing for both Hotel and Chain ID, the backbone is encouraged to learn robust, high-level features (e.g., brand-specific design patterns) that support fine-grained classification. The Chain loss acts as a semantic regularizer, stabilizing the feature space.

### Data
*   **Resolution**: Maintain the input resolution of **384 $\times$ 384** pixels, which was proven effective for this backbone family (Cite solution_lesson_node_00011).
*   **Augmentation**: Continue using the strong `albumentations` pipeline (HorizontalFlip, ColorJitter, CoarseDropout) to prevent overfitting and force the model to focus on structural identity.
*   **Preprocessing**: Standard ImageNet normalization.

### Training
*   **Loss Function**: Employ a weighted Multi-Task Loss: $L_{total} = L_{SubCenter}(Hotel) + \lambda \cdot L_{ArcFace}(Chain)$.
    *   *Robustness*: Apply a mask to the Chain loss to ignore samples where `chain == 0` (unknown/no chain), preventing the model from learning a "garbage" class.
    *   *Constraint*: Explicitly **disable Label Smoothing** for both heads. As learned, smoothing conflicts with the margin-based objective and hinders convergence in high-cardinality tasks (Cite solution_lesson_node_00009).
*   **Optimizer**: Use **AdamW** with a Cosine Annealing scheduler.
*   **Duration**: Train for a minimum of **12 epochs**. Previous lessons demonstrated that margin-based models require extended training durations to fully compact intra-class clusters and converge (Cite solution_lesson_node_00013).

### Evaluation
*   **Inference**: Generate embeddings using only the Fine-Grained (Hotel) head.
*   **Test-Time Augmentation (TTA)**: Perform inference on both the original and horizontally flipped versions of each test image, averaging the resulting embeddings.
*   **Query Expansion (QE)**: Implement **Average Query Expansion** to improve retrieval quality.
    1.  For each test query, retrieve the top $N$ (e.g., 3) most similar images from the gallery.
    2.  Construct a refined query vector by averaging the original query embedding with the embeddings of these top $N$ neighbors.
    3.  Perform a final retrieval using this refined query.
    *   *Rationale*: This reduces the impact of noise or occlusion in the query image by supplementing it with information from high-confidence matches, a standard technique to boost MAP in retrieval tasks.
