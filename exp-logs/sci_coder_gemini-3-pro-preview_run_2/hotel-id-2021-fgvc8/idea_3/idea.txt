# Idea 3: Multi-Modal Metric Learning with Sub-Center ArcFace and EfficientNet

### Model
To address the high intra-class variance inherent in hotel imagery (where a single class contains visually disjoint images like "bathrooms," "exteriors," and "lobbies"), I propose evolving the architecture from a single-center model to a **Sub-Center** approach.

*   **Backbone**: Replace the ResNet-50 used in Idea 2 with **EfficientNet-B4**. EfficientNet architectures generally provide a better parameter-to-accuracy ratio and are specifically designed to handle higher resolution inputs effectively, which is crucial for capturing fine-grained details (like logos or architectural patterns) in hotel images.
*   **Pooling**: Retain the **Generalized Mean (GeM) Pooling** layer from Idea 2 to capture domain-specific features effectively (Cite Idea 2).
*   **Head (Structural Innovation)**: Replace the standard ArcFace head with a **Sub-Center ArcFace** head. Standard ArcFace enforces a single cluster center for every hotel ID. Given that the "average" of a bedroom and a building facade is visually meaningless, forcing them into one point degrades performance. Sub-Center ArcFace initializes $K$ (e.g., $K=3$) learnable centers per class. During the forward pass, the algorithm dynamically selects the sub-center with the highest cosine similarity to the current image and only optimizes that specific center. This allows the model to naturally form distinct sub-clusters for different views (e.g., one center for interiors, one for exteriors) while mapping them to the same Hotel ID.

### Data
*   **Resolution**: Increase the input image size to **384 $\times$ 384** pixels (up from 256 $\times$ 256). EfficientNet-B4 is optimized for higher resolutions, and this increase is vital for resolving small discriminative features in the hotel environment.
*   **Augmentation**: Maintain the strong augmentation pipeline (Albumentations with HorizontalFlip, ColorJitter, CoarseDropout) established in Idea 2 to force the model to learn structural identity over pixel statistics.
*   **Preprocessing**: Normalize images using ImageNet mean and standard deviation.

### Training
*   **Loss Function**: Use **Sub-Center ArcFace Loss**. Crucially, **do not use Label Smoothing**. As established in previous experiments, label smoothing dilutes the gradient signal required for margin-based loss functions to converge in high-cardinality regimes, leading to catastrophic underfitting (Cite Lesson 00009). The margin-based loss itself acts as the necessary regularizer.
*   **Optimizer**: Use **AdamW** with a cosine decay learning rate schedule.
*   **Strategy**: Employ a "warm-up" period where the backbone is frozen and only the Sub-Center head is trained to stabilize the centers before fine-tuning the full network. This prevents the randomly initialized head from distorting the pre-trained backbone features early in training.

### Evaluation
*   **Inference**: The inference process remains a **Retrieval Task** (Cite Lesson 00001).
    1.  **Gallery**: Generate embeddings for all training images using the trained EfficientNet backbone (ignoring the Sub-Center head).
    2.  **Query**: Generate embeddings for the test images.
    3.  **Search**: Perform a Nearest Neighbor search using Cosine Similarity.
    4.  **Prediction**: For each test image, retrieve the top $N$ matches from the gallery. Aggregating the Hotel IDs of these matches (weighted by similarity score) provides the final prediction.
