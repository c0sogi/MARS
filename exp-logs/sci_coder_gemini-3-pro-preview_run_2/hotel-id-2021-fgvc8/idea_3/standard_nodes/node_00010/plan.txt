Implementation strategy:
1.  **Configuration**: Override `Config` parameters to ensure the script runs quickly and efficiently on the A100 GPU. Set `EPOCHS` to 1, `WARMUP_EPOCHS` to 0, and `BATCH_SIZE` to 48.
2.  **Data Loading**: Use `get_dataloaders` to load training and validation sets. Use `get_label_mapping` to handle class ID conversions.
3.  **Training**: Initialize `HotelModel` and run the training loop via `run_training`.
4.  **Validation**:
    *   Load the best saved model.
    *   Generate embeddings for the training set (Gallery) and validation set (Query) using `generate_embeddings`.
    *   Compute the cosine similarity matrix between Query and Gallery.
    *   Retrieve the top 5 unique hotel IDs for each validation image.
    *   Calculate the Mean Average Precision @ 5 (MAP@5).
    *   Print the metric in the required format.
5.  **Failure Analysis**:
    *   Calculate the Average Precision (AP) for each validation sample.
    *   Correlate the error (1 - AP) with the number of training samples for the ground truth class (class frequency).
    *   Print this correlation to identify if rare classes are the source of errors.
6.  **Submission**:
    *   Check if the validation MAP@5 exceeds the specified threshold (0.0695331928545665).
    *   If passed, use the `predict` function from `inference.py` to generate the `submission.csv` for the test set.
