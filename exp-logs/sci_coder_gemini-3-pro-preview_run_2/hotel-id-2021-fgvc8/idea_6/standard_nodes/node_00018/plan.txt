Strategy:
1.  **Configuration & Setup**: Initialize the environment and set random seeds. Override `Config` parameters to establish a "fast baseline": reduce `EPOCHS` to 3 and set `BATCH_SIZE` to 32 to maximize A100 GPU utilization.
2.  **Data Sampling**: Load the training metadata and generate a stratified sample of approximately 30,000 images. Crucially, ensure every unique `hotel_id` is retained (using `groupby().head(1)`) to maintain the full class space for ArcFace training. Save this sampled metadata and update `Config.TRAIN_METADATA_PATH`. Clear cached class mappings to force regeneration based on this valid subset.
3.  **Training**: Train both `efficientnet_b5` and `convnext_base` models using the sampled dataset. Utilizes the provided `train_model` function with `SubCenterArcFaceLoss`.
4.  **Validation Inference**: Extract embeddings for the Train set (acting as Gallery) and the full Validation set (acting as Query). Concatenate the L2-normalized embeddings from both models. Apply **Database Augmentation (DBA)** to the Gallery and **Query Expansion (QE)** to the Query to refine the feature space.
5.  **Evaluation & Analysis**: Compute the final **MAP@5** score. Perform failure analysis by calculating the correlation between prediction error (1 - AP) and metadata features (Chain ID, Timestamp components).
6.  **Submission**: If the validation MAP exceeds the specified threshold (0.712), execute the inference pipeline on the Test set (using Train as Gallery) and generate the `submission.csv` file.
