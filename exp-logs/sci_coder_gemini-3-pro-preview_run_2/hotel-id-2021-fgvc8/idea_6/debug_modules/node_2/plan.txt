The `RuntimeError` is caused by the Python behavior where default arguments are evaluated at function definition time (import time). `SubCenterArcFaceLoss` captures the original `Config.NUM_CLASSES` (7770) when `library.loss` is imported, ignoring the subsequent update to `Config.NUM_CLASSES` (5) made by the `runfile.py` script for the demo. This results in the loss function initializing weights for 7770 classes, creating a tensor size mismatch when the validation loop tries to reshape the output based on the runtime configuration of 5 classes. To fix this, I will modify `library/engine.py` to explicitly pass the current runtime values of `Config.NUM_CLASSES` and `Config.EMBEDDING_SIZE` when instantiating `SubCenterArcFaceLoss`.
