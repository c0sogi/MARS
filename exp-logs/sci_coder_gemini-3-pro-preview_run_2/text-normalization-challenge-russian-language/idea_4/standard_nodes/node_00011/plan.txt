Implementation strategy:
1.  **Configuration**: Import `Config` and modify parameters to ensure fast execution (`DEBUG=True`, `DEBUG_SIZE=200000`, `NUM_EPOCHS=2`, `BATCH_SIZE=256`).
2.  **Training**: Explicitly call `fit_transformer(load_cached_data=True, debug=True)` to train the Transformer model quickly on a subset of data before initializing the inference system. This ensures the checkpoint exists and respects the time constraints.
3.  **Inference System Setup**: Initialize `HybridSystem` and call `prepare_models()`. Since the Transformer checkpoint was just created, it will load it along with the HFBB model.
4.  **Validation**:
    *   Load the validation dataset (`metadata/val.csv`).
    *   Replicate the hybrid inference logic (HFBB -> Gate -> Transformer -> Identity) on the validation set.
    *   Compute the accuracy metric.
    *   Print `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Calculate and print correlations between prediction errors and input features (token length, class).
6.  **Submission**: If the validation accuracy exceeds the threshold (`0.9784022349361615`), call `system.generate_submission()` to create the submission file.
