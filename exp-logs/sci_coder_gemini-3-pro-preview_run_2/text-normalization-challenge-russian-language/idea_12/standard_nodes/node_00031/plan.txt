Implementation Strategy:
1.  **Configuration & Setup**: Initialize the `ModelConfig` with `debug=False` but restrict `num_epochs` to 3 to ensure the execution completes within the 2-hour limit while still providing sufficient training for the semiotic subset. Set up the environment and random seeds.
2.  **Data Loading & Preparation**: Load the training and validation metadata. Build the Character Tokenizer (for the encoder) and train the BPE Tokenizer (for the decoder) using the training data.
3.  **Tier 1 (HFBB) Construction**: Initialize and build the Hierarchical Frequency-Based Backoff (HFBB) model using the full training set. This creates the statistical lookup tables for high-confidence normalization.
4.  **Tier 2 (Transformer) Training**: Prepare the "Density-Maximized" datasets (filtered for semiotic tokens and class-balanced) using `get_dataloaders`. Train the Sequence-to-Sequence Transformer model on this subset to learn the generative rules for complex tokens.
5.  **Validation Inference**: Instantiate the `HybridNormalizer` (which combines HFBB and the trained Transformer). Run inference on the full validation set.
6.  **Evaluation & Analysis**: Calculate the prediction accuracy by comparing predictions to the ground truth. Perform failure analysis by computing the correlation between error occurrence and input token length.
7.  **Submission**: Check if the validation accuracy exceeds the specified threshold (0.9788...). If successful, load the test set, generate predictions using the hybrid engine, and save the submission file.
