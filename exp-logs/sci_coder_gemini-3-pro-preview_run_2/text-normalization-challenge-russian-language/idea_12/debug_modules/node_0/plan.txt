Implementation Strategy:
The following script demonstrates the end-to-end usage of the provided text normalization library. It performs the following steps:
1.  **Configuration & Setup**: Initializes the `ModelConfig` with debug settings (small subset, 1 epoch, reduced vocabulary) and cleans the working directory to ensure a fresh run.
2.  **Data Preparation**: Manually loads a small subset of the training metadata to be used for building tokenizers and the statistical model.
3.  **Tokenizer Generation**: Builds the Character and BPE tokenizers from scratch (`load_cached_data=False`) using the data subset and verifies their vocabulary sizes.
4.  **Tier 1 (HFBB) Model**: Instantiates and builds the Hierarchical Frequency-Based Backoff model, verifying its ability to query a known token.
5.  **Tier 2 (Transformer) Model**: Uses the `dataset_factory` to create DataLoaders (which handles context formatting and class balancing) and trains the `CharToBPESeq2Seq` transformer for one epoch. It asserts that a model checkpoint is saved.
6.  **Inference Pipeline**: Simulates a test scenario by creating a dummy test set from validation data. It runs the `HybridNormalizer` (which combines HFBB and Transformer) to generate predictions and verifies the output submission format.
