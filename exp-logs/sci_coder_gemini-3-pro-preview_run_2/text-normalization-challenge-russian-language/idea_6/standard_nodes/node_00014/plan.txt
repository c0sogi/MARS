Implementation Strategy:
1.  **Configuration**: Modify `Config` at runtime to enable `DEBUG` mode and set a reasonable `DEBUG_SIZE` (500,000 samples). This ensures the resource-intensive "Jackknifing" process for generating neural network training data runs quickly (on a subset), fulfilling the "fast baseline" requirement while providing enough data for the model to learn. Reduce `NUM_EPOCHS` to 5 to further speed up training.
2.  **Tier 1 Training (HFBB)**: Train the Hierarchical Frequency Back-Off (HFBB) memory model on the *full* training dataset. This is computationally cheap (hash map construction) and ensures the primary engine has maximum coverage.
3.  **Tier 2 Training (Neural)**: Instantiate and train the `Trainer` for the Residual Transformer. This handles data loading (respecting the `DEBUG` flag to generate residuals from the subset) and the training loop.
4.  **Validation**: Load the *full* hold-out validation set (`metadata/val.csv`). Reconstruct the trained HFBB and Neural models from their saved states. Run the hybrid cascade inference pipeline on the full validation set to compute the final metric.
5.  **Failure Analysis**: Compare predictions with targets on the validation set. Calculate accuracy and correlations between error occurrence and input length to identify weak points.
6.  **Submission**: If the validation accuracy exceeds the specified threshold, generate predictions for the test set and save the submission file.
