The issue stems from an inconsistency between the model checkpoint and the vocabulary file. The script detects an existing model checkpoint (`transformer_best.pth`) and skips the training phase, assuming all artifacts are present. However, the vocabulary file (`vocab.json`) is missing because the training logic for the `max_train_samples` path (used in the previous run) failed to save the tokenizer to disk. This causes a `FileNotFoundError` when the inference phase attempts to load the non-existent vocabulary.

To fix this, I will modify `library/hybrid_system.py` to:
1.  Update the `should_train` condition to ensure training runs if the vocabulary file is missing, even if a checkpoint exists. This prevents the system from relying on incomplete artifacts (Cite debug_lesson_1).
2.  Add a call to `tokenizer.save(Config.VOCAB_PATH)` within the `max_train_samples` training block to ensure the vocabulary is correctly persisted after being fitted.
