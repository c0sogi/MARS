Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the environment using `Config` and `utils`. Set random seeds for reproducibility.
2.  **Tokenization**: Load or build the Character and BPE tokenizers using `library.tokenization`.
3.  **HFBB Initialization**: Initialize the Tier 1 statistical model (HFBB) using `library.hfbb_layer`. This handles the majority of "easy" cases.
4.  **Transformer Training (Tier 2)**: Train the neural network on a subset of the data (100k samples) for 2 epochs to satisfy the "fast baseline" requirement while ensuring the model learns the semiotic patterns. Use `library.trainer.train_model`.
5.  **Hybrid Validation**:
    *   Load the full validation set.
    *   Implement the **Strict-Priority Routing Logic**: Try HFBB first; if no confident match, check if the token is semiotic (digits/latin). If semiotic, route to the trained Transformer; otherwise, use identity fallback.
    *   Batch process the Transformer requests on the GPU for speed.
    *   Compute the exact string match accuracy.
6.  **Metric Reporting**: Print the `Final Validation Metric` with full precision.
7.  **Failure Analysis**:
    *   Identify error rows.
    *   Calculate error rates by token class.
    *   Compute point-biserial correlation between error occurrence and input token length.
8.  **Submission**: If the validation accuracy exceeds the threshold (`0.9788071831831453`), generate the submission file using `library.trainer.generate_submission`.
