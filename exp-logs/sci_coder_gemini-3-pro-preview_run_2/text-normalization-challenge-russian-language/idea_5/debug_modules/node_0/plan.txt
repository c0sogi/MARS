This script demonstrates the end-to-end usage of the provided Text Normalization library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to use a temporary directory and reduced hyperparameters (small batch size, fewer epochs, smaller model dimensions) to ensure the script completes quickly (within ~1 minute).
2.  **Data Preparation**: Creates "mini" versions of the training, validation, and test datasets by sampling from the original metadata. This ensures the demonstration runs on real data structures without processing millions of records. It specifically ensures "semiotic" (non-plain) tokens are included to exercise the neural network components.
3.  **HFBB Engine (Tier 1) Demo**: Initializes and fits the Hierarchical Frequency-Based Backoff engine, verifying it correctly memorizes and retrieves normalization statistics.
4.  **Tokenizer Demo**: Initializes and fits the `HeterogeneousTokenizer` (Character-level source, BPE-level target), verifying encoding and decoding logic.
5.  **Model & Training Demo**: Uses the `Trainer` class to train the `CharToSubwordTransformer` on the mini-dataset. It verifies that the model artifacts are saved correctly.
6.  **Inference Pipeline Demo**: Uses the `HybridInference` class to generate predictions on the mini-test set, verifying the output format and logic flow.
