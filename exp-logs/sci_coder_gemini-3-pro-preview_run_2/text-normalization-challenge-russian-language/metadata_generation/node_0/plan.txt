The strategy for the implementation is as follows:

1.  **Setup and Loading**: Initialize paths for input (`./input`) and output (`./metadata`). Load the training data (`ru_train.csv`) and test data (`ru_test_2.csv`) using pandas. The training data is expected to contain `sentence_id`, `token_id`, `class`, `before`, and `after` columns.
2.  **Group Splitting**: Since the data consists of sentences divided into tokens, it is crucial to keep tokens from the same sentence together to maintain context. We will use `GroupShuffleSplit` from scikit-learn with `sentence_id` as the group identifier. We will split the training data into 80% training and 20% validation sets using a fixed random state (42).
3.  **Metadata Generation**: Save the split datasets (train, validation) and the test dataset as CSV files in the `./metadata` directory. This effectively creates the metadata/data split required for downstream tasks.
4.  **Verification and Statistics**:
    *   Reload the generated metadata files to ensure integrity.
    *   Print summary statistics: total token counts, unique sentence counts, and class distributions for the training and validation sets.
    *   **Group Split Verification**: Programmatically assert that there is no overlap of `sentence_id` between the training and validation sets to confirm the group split was successful.
    *   **File Path Check**: Since this is a text dataset where the "metadata" contains the text itself rather than paths to external files, the file path resolution check is not strictly applicable to the row content. However, we will verify the existence of the source input files to satisfy the spirit of the requirement.
