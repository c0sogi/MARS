Implementation Strategy:
1.  **Configuration Override**: Import the `Config` class and modify global parameters (e.g., `EPOCHS`, `SAMPLE_SIZE`, `PRETRAINED`, `SCAN_OFFSETS`) to ensure the script runs quickly (using a tiny subset of data) and does not attempt to download model weights.
2.  **Utility Verification**: Demonstrate and validate the `rle_encoding` function with a known binary array and the `fbeta_score` and `BCEDiceLoss` with dummy tensors.
3.  **Dataset Pipeline**: Instantiate the `InkDataset` for both training and testing modes. Verify that it correctly loads 3D slabs, generates crops, and returns tensors of the expected shapes.
4.  **Model Architecture**: Initialize the `HybridSegFormerUNet` (with pretrained weights disabled for speed/offline safety) and perform a forward pass with dummy data to verify input/output dimensions.
5.  **Training Loop**: Initialize the `TrainingEngine`. Run a single training epoch and a validation step on the reduced dataset. Verify that loss and scores are calculated and that checkpoints are saved.
6.  **Inference & Submission**: Initialize the `InferenceEngine`. Execute the submission generation process (using a single Z-offset to save time) and verify that the output CSV is created with the correct format.
