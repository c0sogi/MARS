Based on the comprehensive empirical history and lessons learned, I propose the **Hybrid SegFormer-UNet (MiT-B2) with Decoupled Inference Scanning**.

This strategy synthesizes the robust feature extraction of the **MiT-B2** backbone (proven superior to larger models in Lesson 00040) with the high-resolution reconstruction of a **U-Net Decoder**, addressing the precision limitations of the standard SegFormer MLP. Furthermore, it resolves the "Wandering Ink" vs. "Signal Dilution" conflict (Lessons 00034/00035) by training on high-SNR narrow data and utilizing a **Decoupled Z-Scanning** protocol at inference.

### Model
**Architecture:** I propose a **Hybrid SegFormer-UNet**.
*   **Backbone (Encoder):** We will utilize the **SegFormer MiT-B2** encoder. We strictly retain the B2 architecture (~25M parameters) rather than scaling up to B3 or B4, as previous experiments demonstrated that larger models in this low-data regime overfit to intensity artifacts and degrade performance (Cite Lesson 00040).
*   **Structural Innovation (Decoder Swap):** Instead of the standard SegFormer "All-MLP" decoder (which upsamples all feature maps to 1/4 resolution), we will implement a **U-Net Style Decoder**.
    *   *Mechanism:* The decoder will progressively upsample features from the encoder's deepest layers ($1/32$) to the highest resolution ($1/1$), fusing them with corresponding multi-scale feature maps from the encoder via **skip connections** at each stage.
    *   *Rationale:* The standard MLP decoder is designed for semantic segmentation of large objects (cars, roads). Ink detection requires pixel-perfect precision for fine strokes. The U-Net decoder preserves high-frequency spatial details lost in the MLP's aggressive aggregation, improving the F0.5 precision score.
*   **Input Interface:** We strictly maintain the **3-channel input interface** to utilize **ImageNet-pretrained weights** without modification (Cite Lesson 00024, 00025).

### Data
**Preprocessing (Training):**
*   **Overlapping Stratified Depth Projection:** We retain the highly effective "Overlapping Thick Slab" strategy (Cite Lesson 00029). We define a **Fixed Narrow Context** (slices 20-44) and split it into three overlapping, thick Maximum Intensity Projections (MIPs).
    *   **Channel 1:** MIP of slices **20-32** (12 slices).
    *   **Channel 2:** MIP of slices **26-38** (12 slices).
    *   **Channel 3:** MIP of slices **32-44** (12 slices).
    *   *Rationale:* This configuration optimizes for **Signal Continuity** (Cite Lesson 00026) and **Boundary Preservation** (Cite Lesson 00029). We strictly reject "Wide Context" (slices 14-50) to avoid Signal Dilution (Cite Lesson 00034).
*   **Normalization:** Pixel values are normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** Random horizontal/vertical flips and 90-degree rotations.
*   **Exclusion of Z-Jitter:** We explicitly **exclude** Volumetric Z-Jitter during training. Shifting the input slab while keeping the 2D label static creates false positive training samples (Cite Lesson 00035).
*   **Exclusion of Intensity Augmentation:** We explicitly **exclude** brightness/contrast augmentations to preserve physical radiodensity semantics (Cite Lesson 00006).

### Training
*   **Optimization Protocol:** We will use a **Conservative Learning Rate** (e.g., `6e-5`) with the **AdamW** optimizer. Previous attempts to scale up models (Idea 11/12) failed due to aggressive learning rates (`2e-4`) causing divergence (Cite Lesson 00037).
*   **Loss Function:** **BCE + Dice Loss**. We utilize the balanced Dice Loss, as weighted variants (Tversky) failed to improve the F0.5 metric (Cite Lesson 00031).
*   **Validation Gating:** The execution script will implement a strict logic gate. The submission file will **only** be generated if the current model's best validation F0.5 score exceeds the previous best baseline (0.598) (Cite Lesson 00004).

### Evaluation
**Structural Innovation: Decoupled Volumetric Z-Scanning**
To detect ink strokes that wander outside the fixed training window (20-44) without polluting the training data with noise, we employ a **Multi-Pass Z-Scanning** protocol at inference time.
1.  **Scanning:** For each test fragment, we generate three distinct input tensors corresponding to different depth offsets:
    *   **Scan A (High):** Slabs starting at slice 16 (covering 16-40).
    *   **Scan B (Center):** Slabs starting at slice 20 (covering 20-44).
    *   **Scan C (Low):** Slabs starting at slice 24 (covering 24-48).
2.  **Inference:** The trained model predicts a probability map for each of the three scans.
3.  **Max-Fusion:** We compute the **Maximum Probability Projection** across the three predictions per pixel.
    *   *Rationale:* Since the model is trained on high-SNR centered data, it will output high confidence only when the ink is properly focused within the slab. By taking the maximum, we effectively "search" for the ink's true depth at inference time (Cite Lesson 00042: Early Fusion preferred for training, but Max Fusion valid for inference ensembles).
4.  **Defensive Inference:** Explicitly check input tensor shapes `(Batch, 3, H, W)` before batching (Cite Lesson 00005).
