Based on the comprehensive analysis of the "Lessons" and "Previous Ideas," I propose the **Overlapping Stratified SegFormer (OSS-Net)**.

This strategy synthesizes the success of the SegFormer architecture (Idea 5) with a robust data representation that resolves the "Signal Dilution" (Idea 2/6) and "Boundary Fragmentation" issues, while strictly adhering to the pretraining constraints identified in the failure of Idea 6.

### Model
**Architecture:** I propose upgrading the backbone to the **SegFormer MiT-B2** (Mix Transformer B2).
*   **Backbone:** We will utilize the **MiT-B2** encoder. This model provides a larger effective receptive field and higher parameter count than the MiT-B1 used in Idea 5, allowing it to capture more complex spatial dependencies in the ink strokes. Crucially, unlike the ResNet34 experiment which failed due to local noise sensitivity (Cite Lesson 00014), the Transformer's self-attention mechanism inherently integrates global context, making it robust to local artifacts (Cite Lesson 00024).
*   **Input Interface:** We will revert to the standard **3-channel input interface**. Idea 6 failed because modifying the input layer to accept 6 channels destroyed the pretrained feature correlations (Cite Lesson 00025). By strictly maintaining a 3-channel input, we ensure we can load **ImageNet-pretrained weights** without modification, guaranteeing stable convergence (Cite Lesson 00024).
*   **Decoder:** A standard MLP decoder aggregates the multi-level features from the MiT-B2 encoder to predict the binary mask.

### Data
**Preprocessing:**
*   **Overlapping Stratified Depth Projection:** To resolve the conflict between "Thick Slabs" (Cite Lesson 00026) and depth resolution, I propose constructing the 3 input channels using **overlapping, thick Maximum Intensity Projections (MIPs)**.
    *   **Concept:** Idea 5 used disjoint slabs (e.g., 22-28, 29-35), which risks fragmenting ink strokes that lie on the boundary (e.g., slice 28/29). Idea 6 used thin slabs, which lacked the Z-variance to form coherent shapes (Cite Lesson 00026).
    *   **Implementation:** We will define three overlapping zones covering the central volume (e.g., slices 20-44):
        *   **Channel 1 (Top):** MIP of slices **20-32** (12 slices).
        *   **Channel 2 (Middle):** MIP of slices **26-38** (12 slices).
        *   **Channel 3 (Bottom):** MIP of slices **32-44** (12 slices).
    *   **Rationale:** Each channel represents a "thick" slab (12 slices) to preserve signal continuity (Cite Lesson 00026), while the 50% overlap ensures that any ink stroke located at a boundary of one channel is fully captured in the center of the adjacent channel.
    *   **Projection Type:** We strictly use **MIP** (Max) rather than Mean or Std, as statistical averaging dilutes the sparse high-intensity ink signal (Cite Lesson 00015).
    *   **Strict Stratification:** We exclude any "Global MIP" channel to prevent the model from learning shortcut solutions based on absolute intensity thresholds (Cite Lesson 00018).
*   **Normalization:** Pixel values will be normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** Random horizontal/vertical flips and 90-degree rotations.
*   **Intensity Constraints:** We explicitly **exclude** brightness, contrast, and gamma augmentations. The model relies on physical radiodensity to distinguish ink, and intensity perturbations destroy this signal (Cite Lesson 00006).

### Training
*   **Initialization:** We will load **ImageNet-pretrained weights** for the MiT-B2 model. Since our input is formatted as a standard 3-channel image, these weights are directly compatible, avoiding the "Random Initialization" failure mode (Cite Lesson 00024).
*   **Loss Function:** A composite **BCE + Dice Loss** to optimize for both pixel accuracy and the F0.5 overlap metric.
*   **Validation Gating:** The execution script will include a strict logic gate. The submission file will **only** be generated if the current model's best validation F0.5 score exceeds the previous best baseline (0.551). This prevents inferior stochastic runs from overwriting the best result (Cite Lesson 00004).
*   **Optimizer:** AdamW optimizer with a `ReduceLROnPlateau` scheduler.

### Evaluation
*   **Defensive Inference:** The inference pipeline will explicitly check the input tensor shape to ensure it matches `(Batch, 3, H, W)` before processing. This prevents runtime errors related to dimension squeezing (Cite Lesson 00005).
*   **Test Time Augmentation (TTA):** We will average predictions from the original input and its geometric transformations (flips/rotations) to smooth out prediction noise and maximize the F0.5 score.
