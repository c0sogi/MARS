The `RuntimeError: Unknown model (mit_b2)` indicates that the model name `"mit_b2"` is not found in the `timm` model registry. While `"mit_b2"` is the encoder name used in `segmentation_models_pytorch` (SMP), the `timm` library (v1.0.20) registers this model as `"segformer_mit_b2"`. The fix is to update the `ENCODER_NAME` in the configuration file to match the correct `timm` identifier.

```diff
library/config.py
<<<<<<< SEARCH
    ENCODER_NAME = "mit_b2"
=======
    ENCODER_NAME = "segformer_mit_b2"
>>>>>>> REPLACE
```
