### Baseline Approach: Maximum Intensity Projection (MIP) U-Net

#### Model
I propose a **Maximum Intensity Projection (MIP) U-Net**. This architecture simplifies the volumetric 3D problem into a standard 2D image segmentation task by applying a deterministic projection prior to the neural network.

*   **Input Representation**: Unlike Model 1 (which treats Z-slices as separate channels) or Model 5 (which learns how to compress dimensions), this approach applies a static **Maximum Intensity Projection (MIP)**. By taking the maximum pixel value across a defined range of Z-slices for every (x, y) coordinate, we collapse the 3D volume into a single-channel 2D "summary" image. This highlights the ink, which is radiographically denser (brighter) than the papyrus, even if the papyrus surface fluctuates slightly in depth.
*   **Architecture**: The core network is a standard **2D U-Net**. To maintain a lightweight baseline, we will use a **ResNet-18** encoder (smaller than the ResNet-34 used in Model 1) initialized with pre-trained ImageNet weights. The encoder extracts spatial features from the MIP image, while the decoder uses symmetric upsampling with skip connections to restore the spatial resolution for pixel-level segmentation.
*   **Output**: A single-channel probability map indicating the likelihood of ink presence for each pixel.

#### Data
*   **Preprocessing**:
    1.  **Slice Selection**: Instead of loading all 65 slices, load a "central slab" (e.g., slice indices 22 to 42). This range captures the most likely location of the ink while ignoring noise from the empty air above or below the fragment.
    2.  **Projection**: Compute the pixel-wise maximum value across these selected slices to generate a single 2D grayscale image per fragment.
    3.  **Normalization**: Normalize the 16-bit integer pixel values to a [0, 1] floating-point range using min-max scaling derived from the training set statistics.
    4.  **Tiling**: Divide the large 2D projection images and their corresponding binary masks into fixed-size non-overlapping patches (e.g., 512x512 pixels) to fit within GPU memory constraints.
*   **Augmentation**: Apply minimal geometric augmentations, such as random horizontal/vertical flips and 90-degree rotations, to improve generalization without increasing preprocessing time.

#### Training
*   **Loss Function**: Use a composite loss function combining **Binary Cross Entropy (BCE)** and **Dice Loss**. BCE handles pixel-level classification accuracy, while Dice Loss optimizes the overlap between the predicted and ground truth masks, directly benefiting the F0.5 metric.
*   **Optimizer**: Use the **Adam** optimizer with a standard learning rate (e.g., 1e-4) and a learning rate scheduler that reduces the rate upon validation loss plateauing.
*   **Procedure**: Train the model on the generated 2D patches. Monitor the F0.5 score on the validation set (the hold-out patches defined in the metadata) to perform early stopping, ensuring the model does not overfit.

#### Evaluation
*   **Inference**:
    1.  Load the test fragments and extract the same central slab of Z-slices used in training.
    2.  Generate the 2D MIP image for the test fragment.
    3.  Tile the image into 512x512 patches (padding edges if necessary).
    4.  Feed patches through the trained U-Net to generate probability maps.
*   **Post-Processing**:
    1.  Stitch the predicted patches back together to reconstruct the full-size probability map for the fragment.
    2.  Apply a global threshold (determined by optimizing the F0.5 score on the validation set) to convert probabilities into a binary mask.
    3.  Convert the binary mask into the required Run-Length Encoding (RLE) format for the `submission.csv` file.
