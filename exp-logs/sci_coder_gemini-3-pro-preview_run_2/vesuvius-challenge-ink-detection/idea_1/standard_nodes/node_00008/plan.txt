The error `ValueError: too many values to unpack (expected 2)` occurs because the `get_fragment_mip` function now returns a 3-channel image (shape `(H, W, 3)`), but the code in `library/dataset.py` attempts to unpack the shape into just two variables (`img_h, img_w`). This mismatch causes the crash. The same issue exists in `library/inference.py` and `library/engine.py` where the code expects a 2D shape for the MIP image.

To fix this, I will modify the code to unpack only the first two dimensions (height and width) of the shape tuple by slicing it with `[:2]`.
