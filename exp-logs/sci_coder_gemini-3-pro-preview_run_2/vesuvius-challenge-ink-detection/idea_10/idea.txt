Based on the comprehensive analysis of the "Lessons" and "Previous Ideas," I propose the **Z-Scanning SegFormer (MiT-B4)**.

This strategy addresses the "Signal Dilution" failure of Idea 9 (Lesson 00034) by decoupling the training context from the inference search space. It combines the high-SNR "Narrow Context" training of Idea 8 with a novel **Volumetric Z-Scanning** inference protocol to capture wandering ink strokes without confusing the model during training.

# Model
**Architecture:** I propose upgrading the backbone to the **SegFormer MiT-B4** (Mix Transformer B4).
*   **Backbone:** The **MiT-B4** encoder (~64M parameters) provides a significant capacity increase over the MiT-B3 used in Idea 8. This allows for finer discrimination between ink and papyrus texture. Unlike Idea 9, which failed because it coupled this larger model with noisy "Wide Context" data, we will feed it high-SNR narrow data to ensure stable convergence (Cite Lesson 00034).
*   **Input Interface:** We strictly maintain the **3-channel input interface**. This ensures we can utilize **ImageNet-pretrained weights** without modification, preserving the spatial filters learned on massive datasets and avoiding the failure of random initialization (Cite Lesson 00024) or channel expansion (Cite Lesson 00025).
*   **Decoder:** The standard MLP decoder aggregates multi-scale features to predict the binary mask.

# Data
**Preprocessing:**
*   **Overlapping Stratified Depth Projection:** We retain the "Overlapping Thick Slab" strategy (Cite Lesson 00029) with the **Standard Narrow Context** (approx slices 20-44).
    *   **Channel 1 (Top):** MIP of slices **20-32** (12 slices).
    *   **Channel 2 (Middle):** MIP of slices **26-38** (12 slices).
    *   **Channel 3 (Bottom):** MIP of slices **32-44** (12 slices).
    *   *Rationale:* We strictly avoid the "Wide Context" (slices 14-50) attempted in Idea 9, as including these outer slices during training dilutes the signal-to-noise ratio (SNR) and degrades performance (Cite Lesson 00034).
*   **Normalization:** Pixel values are normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Volumetric Z-Jitter:** During training, we randomly shift the start index of the slab window by $\pm N$ slices (e.g., $\pm 5$). This forces the model to learn features that are robust to small depth variations, preventing overfitting to a specific absolute Z-position (Cite Idea 8).
*   **Geometric Only:** Random horizontal/vertical flips and 90-degree rotations.
*   **Intensity Constraints:** Explicitly **exclude** brightness/contrast augmentations to preserve physical radiodensity semantics (Cite Lesson 00006).

# Training
*   **Loss Function:** **BCE + Dice Loss**. We reject Tversky Loss as it failed to outperform the balanced Dice baseline (Cite Lesson 00031).
*   **Optimizer:** **AdamW** with `ReduceLROnPlateau` scheduler.
*   **Validation Gating:** The execution script will implement a strict logic gate. The submission file will **only** be generated if the current model's best validation F0.5 score exceeds the previous best baseline (0.5976). (Cite Lesson 00004).

# Evaluation
**Structural Innovation: Volumetric Z-Scanning Inference**
Instead of predicting on a single fixed Z-window (which misses ink that wanders outside the center) or training on a noisy wide window (which confuses the model), we introduce a **Multi-Pass Z-Scanning** protocol at inference time.
1.  **Scanning:** For each test fragment, we generate inputs at three distinct Z-offsets:
    *   **Offset -4:** Slabs starting at slice 16 (covering 16-40).
    *   **Offset 0:** Slabs starting at slice 20 (covering 20-44).
    *   **Offset +4:** Slabs starting at slice 24 (covering 24-48).
2.  **Inference:** The model predicts a probability map for each offset.
3.  **Fusion:** We compute the **Maximum Probability Projection** across the three predictions per pixel.
    *   *Rationale:* Since the model is trained on high-SNR narrow slabs, it will output low probabilities when the ink is out of focus (i.e., not in the current Z-window). By taking the maximum across offsets, we effectively "search" for the ink's true depth at inference time without penalizing the training process with noise.
4.  **Defensive Inference:** Explicitly check input tensor shapes before batching (Cite Lesson 00005).
5.  **Test Time Augmentation (TTA):** Average predictions from geometric flips within each Z-offset before the final fusion.
