Based on the comprehensive empirical history and the specific failure analysis of previous attempts (Ideas 11, 12, 15), I propose the **Decoupled Z-Scanning SegFormer (MiT-B2)**.

This strategy represents the "Goldilocks" synthesis of the project's lessons. It resolves the conflict between the need for **High-SNR Training Data** (Lesson 00034) and **Flexible Inference Depth** (Lesson 00035) by structurally decoupling the training view from the inference search space. Crucially, it reverts the backbone to the **MiT-B2** and the decoder to the **MLP**, correcting the overfitting observed with larger models (Lesson 00040) and the noise sensitivity of U-Net decoders (Lesson 00043).

# Model
**Architecture:** I propose the **SegFormer MiT-B2** with the standard **MLP Decoder**.
*   **Backbone:** We utilize the **MiT-B2** encoder (~25M parameters).
    *   *Rationale:* Previous experiments demonstrated that scaling up to MiT-B3 or MiT-B4 in this low-data regime (~400 samples) causes the model to overfit to intensity artifacts, degrading the F0.5 score (Cite Lesson 00040). The B2 backbone offers the optimal balance of receptive field and regularization.
*   **Decoder:** We strictly retain the standard **All-MLP Decoder**.
    *   *Rationale:* Idea 15 failed because the U-Net decoder's skip connections propagated high-frequency substrate noise (papyrus fibers) to the output, confusing the model (Cite Lesson 00043). The MLP decoder's bottleneck forces the model to learn robust semantic features rather than relying on low-level intensity cues.
*   **Input Interface:** We maintain the **3-channel input interface** to utilize **ImageNet-pretrained weights** without modification, ensuring stable convergence (Cite Lesson 00024, 00025).

# Data
**Preprocessing (Training):**
*   **Overlapping Stratified Depth Projection:** We employ the "Overlapping Thick Slab" strategy (Cite Lesson 00029). We define a **Fixed Narrow Context** (slices 20-44) and split it into three overlapping Maximum Intensity Projections (MIPs):
    *   **Channel 1:** MIP of slices **20-32** (12 slices).
    *   **Channel 2:** MIP of slices **26-38** (12 slices).
    *   **Channel 3:** MIP of slices **32-44** (12 slices).
    *   *Rationale:* This maximizes Signal-to-Noise Ratio (SNR) for training. We strictly reject "Wide Context" (slices 14-50) to avoid Signal Dilution (Cite Lesson 00034).
*   **Normalization:** Pixel values are normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** Random horizontal/vertical flips and 90-degree rotations.
*   **Exclusion of Z-Jitter:** We explicitly **exclude** Volumetric Z-Jitter during training. Shifting the input slab while keeping the 2D label static creates false positive training samples (Cite Lesson 00035).
*   **Exclusion of Intensity Augmentation:** We explicitly **exclude** brightness/contrast augmentations to preserve physical radiodensity semantics (Cite Lesson 00006).

# Training
*   **Optimization Protocol:** We will use a **Conservative Learning Rate** (e.g., `6e-5`) with the **AdamW** optimizer.
    *   *Rationale:* Idea 12 failed because aggressive learning rates (`2e-4`) caused divergence when fine-tuning Transformers on small datasets (Cite Lesson 00037).
*   **Loss Function:** **BCE + Dice Loss**. We utilize the balanced Dice Loss, as weighted variants (Tversky) failed to improve the F0.5 metric (Cite Lesson 00031).
*   **Validation Gating:** The submission file will **only** be generated if the current model's best validation F0.5 score exceeds the previous best baseline (approx. 0.598), ensuring only superior models are submitted (Cite Lesson 00004).

# Evaluation
**Structural Innovation: Decoupled Volumetric Z-Scanning**
To detect ink strokes that wander outside the fixed training window (20-44) without polluting the training data with noise, we employ a **Multi-Pass Z-Scanning** protocol at inference time.
1.  **Scanning:** For each test fragment, we generate three distinct input tensors corresponding to different depth offsets:
    *   **Scan A (High):** Slabs starting at slice 16 (covering 16-40).
    *   **Scan B (Center):** Slabs starting at slice 20 (covering 20-44).
    *   **Scan C (Low):** Slabs starting at slice 24 (covering 24-48).
2.  **Inference:** The trained MiT-B2 model predicts a probability map for each of the three scans.
3.  **Max-Fusion:** We compute the **Maximum Probability Projection** across the three predictions per pixel.
    *   *Rationale:* Since the model is trained on high-SNR centered data, it will output high confidence only when the ink is properly focused within the slab. By taking the maximum, we effectively "search" for the ink's true depth at inference time (Cite Lesson 00042: Max Fusion is valid for inference ensembles).
4.  **Defensive Inference:** Explicitly check input tensor shapes `(Batch, 3, H, W)` before batching to prevent runtime errors (Cite Lesson 00005).
