Implementation Strategy:
The following script demonstrates the end-to-end usage of the provided Vesuvius Ink Detection library.
1.  **Setup**: We import the required modules and set the random seed for reproducibility.
2.  **Configuration**: We override the default `CFG` parameters (epochs, batch size, working directory) to ensure the script executes quickly within the demonstration limits.
3.  **Verification**: We perform assertion checks on utility functions like `rle_encoding` and `fbeta_score` to ensure correctness.
4.  **Data Loading**: We load the training metadata, subset it to a minimal number of samples, and instantiate the `InkDataset` and `DataLoader`. We verify the shapes of the loaded tensors.
5.  **Model & Training**: We instantiate the `WideContextSegFormer` model and the `BCEDiceLoss`. We run a single training epoch on the subsetted data and verify that the loss is calculated correctly. We then save the model checkpoint.
6.  **Inference**: We use the saved model to perform inference on a test fragment. To optimize speed, we limit the inference to a few batches using `debug_max_batches`. We generate the Run-Length Encoding (RLE) for the prediction and save the final `submission.csv`.
