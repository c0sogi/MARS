4.  **Inference (Multi-View Ensemble)**: If the best validation F0.5 score exceeds the threshold (0.597622633), I will proceed to inference.
    *   To implement the **Discrete Multi-View Training Protocol** at inference time (Scanning), I will perform three separate inference passes on the test set.
    *   Since the provided `InkDataset` hardcodes `Config.VIEW_B_START` for the test split, I will temporarily modify `Config.VIEW_B_START` to `VIEW_A_START` and `VIEW_C_START` in the main script to force the dataloader to generate the different depth views.
    *   Inside each pass, I will apply **Test Time Augmentation (TTA)** by averaging predictions from the original image, a horizontal flip, and a vertical flip.
    *   I will aggregate the predictions from all three views using **Max-Fusion** (taking the maximum probability per pixel across views).

5.  **Submission**: I will reconstruct the full prediction maps for each test fragment from the tiled patches. I will apply the binary threshold, mask the output with the valid fragment mask, and generate the Run-Length Encoding (RLE). The final `submission.csv` will be saved to the home directory.
