Here is the implementation strategy:

1.  **Environment Setup**: We will import the necessary modules and the provided library classes (`Config`, `InkSegFormer`, `InkDataset`, etc.). We will explicitly set the random seed for reproducibility.
2.  **Configuration Override**: To ensure the demonstration runs quickly, we will override `Config` parameters. Specifically, we will point `Config.METADATA_DIR` to a temporary directory containing only a tiny subset of the original metadata (e.g., 2 batches worth of data). We will also set `Config.EPOCHS` to 1.
3.  **Data Preparation**: We will read the provided metadata files, slice them to a minimal size (e.g., 16 samples for training, 8 for validation), and save these subsets to the temporary metadata directory. This ensures the `get_dataloaders` function creates loaders that iterate very quickly.
4.  **Component Verification**:
    *   **Data Loading**: Initialize dataloaders and verify batch shapes.
    *   **Model**: Instantiate the `InkSegFormer`, perform a forward pass with a dummy batch, and assert output dimensions.
    *   **Loss**: Instantiate `BCEDiceLoss` and calculate loss on the dummy output.
    *   **Metrics**: specific checks for `dice_coef` and `fbeta_score`.
5.  **Execution Loop**: Run `train_one_epoch` and `validate` using the subset dataloaders to demonstrate the full training pipeline.
6.  **Inference & Submission**: Run the test dataloader, generate predictions, apply Run-Length Encoding (`rle_encoding`), and generate a sample `submission.csv`.
