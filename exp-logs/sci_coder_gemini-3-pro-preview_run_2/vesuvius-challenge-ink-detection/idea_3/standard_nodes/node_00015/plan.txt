Implementation strategy:
1.  **Setup**: Initialize the environment, set random seeds for reproducibility, and create the required output directory (`./submission`).
2.  **Training**: Execute the `train_model` function from the provided library. We will limit the number of training samples (`max_train_samples=2000`) and epochs (`num_epochs=5`) to ensure the script completes quickly (Fast Baseline) while still learning useful features. We pass the specific baseline score threshold (`0.4738558828830719`) to the training function.
3.  **Validation & Failure Analysis**:
    *   Load the best model checkpoint saved during training.
    *   Iterate through the validation dataset to collect predictions, targets, and input features.
    *   Compute the global F0.5 score and print it in the required format.
    *   Calculate pixel-wise absolute errors.
    *   Compute and print the Pearson correlation between the error magnitude and the three input channels (Max, Mean, Std) to identify which features correlate with model failure.
4.  **Submission Handling**:
    *   Check if the training process generated a submission file (which happens if the score exceeds the baseline).
    *   If generated, move it to the required location (`./submission/submission.csv`).
    *   If not generated by the training loop but the re-calculated metric exceeds the threshold (due to minor floating point differences or if the training loop skipped it), explicitly generate the submission using `run_inference`.
