Based on the empirical findings and lessons learned, I propose the following optimized strategy. This solution introduces a **Statistical Projection (StatProj)** feature engineering paradigm to synthesize the benefits of global signal preservation (MIP) with the information density of multi-channel inputs, while avoiding the overfitting issues observed with stratification.

# Statistical Projection (StatProj) U-Net

### Model
**Architecture:** I propose a **ResNet34 U-Net**.
*   **Backbone:** We will utilize a **ResNet34** encoder initialized with ImageNet weights. While previous experiments suggested the deeper ResNet34 model was hypersensitive to noise when paired with stratified inputs (Cite Lesson 00014), the proposed "Statistical Projection" input (described below) is inherently less noisy and more robust than raw stratified slices. This cleaner signal allows us to leverage the increased capacity of ResNet34 to capture complex ink stroke morphologies without overfitting to depth-specific artifacts.
*   **Decoder:** A standard U-Net decoder with skip connections will reconstruct the segmentation mask from the encoder's multi-scale features.
*   **Input Layer:** The first convolutional layer will be adapted to accept a **3-channel** input tensor, corresponding to the three statistical moments of the volumetric data.

### Data
**Preprocessing:**
*   **Statistical Depth Compression:** Instead of a single Maximum Intensity Projection (MIP) or splitting the volume into arbitrary sub-slabs (Stratification), we will compute three distinct statistical projections across the central Z-slice range (22-42). These three projections will form the channels of our input image:
    1.  **Channel 1 (Max):** The Maximum Intensity Projection (MIP). This captures the strongest ink signal, preserving the primary feature used in the successful baseline (Cite Lesson 00003).
    2.  **Channel 2 (Mean):** The Mean Intensity Projection. This provides context regarding the average density of the papyrus substrate, helping the model distinguish between high-density ink and random high-intensity noise outliers.
    3.  **Channel 3 (Std):** The Standard Deviation Projection. This captures the texture and fiber structure of the papyrus. Ink sits on the surface and alters the local variance differently than the internal fiber mesh, providing a texture-based feature to complement the intensity-based MIP.
    *   *Rationale:* This approach respects the directive to "prefer global MIP... when target signal is sparse" (Cite Lesson 00014) by collapsing the Z-dimension, but avoids information loss by retaining statistical moments. It solves the "dilution" problem of stratification (Cite Lesson 00014) while still providing a rich 3-channel input (Cite Lesson 00010).
*   **Normalization:** The 16-bit input data will be normalized to the [0, 1] range using global dataset statistics (Mean ~24000, Std ~8600) derived from the training set.

**Augmentation:**
*   **Geometric Only:** We will apply random horizontal/vertical flips and 90-degree rotations.
*   **Intensity Constraints:** We will strictly **exclude** brightness, contrast, and gamma augmentations. The model must learn to rely on the absolute and relative physical density values (Max/Mean/Std) to detect ink. (Cite Lesson 00006).

### Training
*   **Loss Function:** A composite **BCE + Dice Loss** will be used. The Dice component specifically targets the overlap metric, aligning with the F0.5 objective.
*   **Validation Gating:** The execution script will include a logic gate that only generates a submission file if the current model's best validation F0.5 score exceeds the previous best baseline (0.474). This prevents inferior stochastic runs from overwriting good results (Cite Lesson 00004).
*   **Optimizer:** Adam optimizer with a `ReduceLROnPlateau` scheduler to fine-tune weights as convergence slows.

### Evaluation
*   **Defensive Inference:** The inference pipeline will explicitly check the dimensions of the input tensor. Since we are constructing a 3-channel input from single-channel slices, we will ensure the tensor shape is `(Batch, 3, Height, Width)` before feeding it to the model, preventing shape mismatch errors (Cite Lesson 00005).
*   **Test Time Augmentation (TTA):** We will perform inference on the original image and its geometric transformations (flips/rotations). The predictions will be averaged to smooth out noise and improve the precision of the final mask.
*   **Threshold Optimization:** The binarization threshold will be dynamically selected by maximizing the F0.5 score on the validation set, rather than using a fixed 0.5 cutoff.
