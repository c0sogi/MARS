This script performs an Exploratory Data Analysis (EDA) on the Vesuvius Challenge Ink Detection dataset.

**Strategy:**
1.  **Setup & Configuration**: Initialize random seeds and define paths. Load the provided `metadata/train.csv` to ensure we only analyze the training split defined by the metadata generation step.
2.  **Modality Detection**: Inspect the metadata columns and file extensions to confirm the dataset modality (Image/Volumetric).
3.  **Target Variable Analysis**:
    *   Iterate through unique fragments identified in the training metadata.
    *   Load the ground truth `inklabels.png` and validity `mask.png`.
    *   Calculate the pixel-level class balance (Ink vs. No-Ink) specifically within the valid mask regions.
4.  **Input Data Analysis (Image/Volume)**:
    *   Analyze the dimensions of the full fragment images.
    *   Perform statistical analysis on the 3D volume data. Since the volumes are too large to load entirely into memory, we will sample a subset of patches defined in the metadata.
    *   For sampled patches, load the central slice (slice 32) of the 3D stack to compute pixel value statistics (mean, std, min, max) and check data types (e.g., uint16).
5.  **Feature/Signal Relationships**:
    *   Investigate the relationship between input signal intensity and the target.
    *   Compare the mean pixel intensity of the central volume slice for "Ink" patches vs. "No-Ink" patches.
    *   Calculate the Point-Biserial correlation between slice intensity and ink presence.
6.  **Reporting**: Output the results in the specified format with distinct capitalized sections.
