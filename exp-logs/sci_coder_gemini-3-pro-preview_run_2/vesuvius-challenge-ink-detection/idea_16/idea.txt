Based on the comprehensive empirical history and lessons learned, I propose the **Precision-Enhanced Hybrid SegFormer (MiT-B2)**.

This strategy introduces a structural evolution by replacing the standard SegFormer MLP decoder with a **U-Net Style Decoder**. This addresses the resolution bottleneck of the standard architecture (which limits output precision to 1/4th of the input size) while retaining the robust feature extraction of the **MiT-B2** backbone. Furthermore, it resolves the "Wandering Ink" vs. "Signal Dilution" conflict by strictly enforcing high-SNR training data and utilizing a **Decoupled Z-Scanning** protocol at inference.

### Model
**Architecture:** I propose a **Hybrid SegFormer-UNet**.
*   **Backbone (Encoder):** We will utilize the **SegFormer MiT-B2** encoder. We strictly retain the B2 architecture (~25M parameters) rather than scaling up to B3 or B4. Previous experiments demonstrated that larger models (B3/B4) in this low-data regime tend to overfit to intensity artifacts and degrade performance (Cite Lesson 00040). The B2 backbone offers the optimal balance of capacity and generalization.
*   **Structural Innovation (Decoder Swap):** We will replace the standard SegFormer "All-MLP" decoder with a **U-Net Style Decoder**.
    *   *Problem:* The standard SegFormer decoder aggregates features and upsamples them to $H/4, W/4$, relying on bilinear interpolation for the final mask. This is insufficient for pixel-perfect detection of fine ink strokes.
    *   *Solution:* The new decoder will progressively upsample features from the deepest encoder layer ($1/32$) back to full resolution ($1/1$). At each upsampling stage ($1/16, 1/8, 1/4$), it will concatenate the corresponding high-resolution feature maps from the encoder via **skip connections**. This preserves high-frequency spatial details lost in the MLP aggregation.
*   **Input Interface:** We strictly maintain the **3-channel input interface** to utilize **ImageNet-pretrained weights** without modification, avoiding the failure modes associated with channel expansion or random initialization (Cite Lesson 00024, 00025).

### Data
**Preprocessing (Training):**
*   **Overlapping Stratified Depth Projection:** We retain the highly effective "Overlapping Thick Slab" strategy (Cite Lesson 00029). We define a **Fixed Narrow Context** (slices 20-44) and split it into three overlapping, thick Maximum Intensity Projections (MIPs).
    *   **Channel 1:** MIP of slices **20-32** (12 slices).
    *   **Channel 2:** MIP of slices **26-38** (12 slices).
    *   **Channel 3:** MIP of slices **32-44** (12 slices).
    *   *Rationale:* This configuration optimizes for **Signal Continuity** (Cite Lesson 00026) and **Boundary Preservation** (Cite Lesson 00029). We strictly reject "Wide Context" (slices 14-50) to avoid Signal Dilution (Cite Lesson 00034).
*   **Normalization:** Pixel values are normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** Random horizontal/vertical flips and 90-degree rotations.
*   **Exclusion of Z-Jitter:** We explicitly **exclude** Volumetric Z-Jitter during training. Shifting the input slab while keeping the 2D label static creates false positive training samples (Cite Lesson 00035).
*   **Exclusion of Intensity Augmentation:** We explicitly **exclude** brightness/contrast augmentations to preserve the physical radiodensity semantics required for ink detection (Cite Lesson 00006).

### Training
*   **Optimization Protocol:** We will use a **Conservative Learning Rate** (e.g., `6e-5`) with the **AdamW** optimizer. Previous attempts to scale up models or hyperparameters failed due to aggressive learning rates causing divergence (Cite Lesson 00037).
*   **Loss Function:** **BCE + Dice Loss**. We utilize the balanced Dice Loss, as weighted variants (Tversky) failed to improve the F0.5 metric in previous trials (Cite Lesson 00031).
*   **Validation Gating:** The execution script will implement a strict logic gate. The submission file will **only** be generated if the current model's best validation F0.5 score exceeds the previous best baseline (approx. 0.598). This prevents inferior stochastic runs from overwriting the best result (Cite Lesson 00004).

### Evaluation
**Structural Innovation: Decoupled Volumetric Z-Scanning**
To detect ink strokes that wander outside the fixed training window (20-44) without polluting the training data with noise, we employ a **Multi-Pass Z-Scanning** protocol at inference time.
1.  **Scanning:** For each test fragment, we generate three distinct input tensors corresponding to different depth offsets:
    *   **Scan A (High):** Slabs starting at slice 16 (covering 16-40).
    *   **Scan B (Center):** Slabs starting at slice 20 (covering 20-44).
    *   **Scan C (Low):** Slabs starting at slice 24 (covering 24-48).
2.  **Inference:** The trained model predicts a probability map for each of the three scans.
3.  **Max-Fusion:** We compute the **Maximum Probability Projection** across the three predictions per pixel.
    *   *Rationale:* Since the model is trained on high-SNR centered data, it will output high confidence only when the ink is properly focused within the slab. By taking the maximum, we effectively "search" for the ink's true depth at inference time (Cite Lesson 00042: Max Fusion valid for inference ensembles).
4.  **Defensive Inference:** Explicitly check input tensor shapes `(Batch, 3, H, W)` before batching to prevent runtime errors (Cite Lesson 00005).
