Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override key parameters to ensure the script runs quickly and uses a temporary working directory (`./working/demo_execution`). We will reduce the number of epochs, batch size, and dataset size (using the `DEBUG` flag).
2.  **Utility Verification**: Demonstrate and verify the correctness of the `rle_encoding` and `fbeta_score` functions using synthetic data.
3.  **Data Loading Demonstration**: Initialize the `InkDataset` and `DataLoader` for the "Mid" specialist. Fetch a single batch to verify tensor shapes and data types. This implicitly tests the slab generation and caching logic in `utils.py`.
4.  **Model Initialization & Forward Pass**: Instantiate the `SegFormerSpecialist` model. Perform a forward pass with the batch fetched in the previous step to confirm the model architecture and output dimensions (checking for the correct upsampling behavior).
5.  **Training Loop Execution**: Execute `train_specialist` for a single epoch on the reduced dataset. Verify that the model checkpoint is successfully saved to the working directory.
6.  **Inference Pipeline**: Run the `predict_and_submit` function. This will load the trained "Mid" model (and handle the missing "High"/"Low" models gracefully), perform tiled inference on the test set, and generate the `submission.csv` file.
7.  **Validation**: Throughout the script, `assert` statements will enforce expected behaviors (e.g., output shapes, file existence, score ranges).
