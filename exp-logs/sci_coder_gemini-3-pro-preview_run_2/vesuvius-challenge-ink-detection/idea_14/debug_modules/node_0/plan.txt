Implementation Strategy:
1.  **Environment Setup**: Initialize the environment by setting seeds and creating a temporary working directory structure to hold demo metadata and checkpoints.
2.  **Data Preparation**: Load the existing metadata from `./metadata`, sample a very small subset (e.g., 4 rows for training, 1 fragment for testing), and save these as demo metadata files. This ensures the code runs quickly.
3.  **Configuration Override**: Modify the `Config` class attributes at runtime to point to the demo metadata, reduce the number of epochs to 1, disable pretrained weight downloading (to ensure offline execution capability), and set a small batch size.
4.  **Component Verification**:
    *   **Dataset**: Instantiate `InkDataset` with the demo metadata. Retrieve a single sample to verify the shape and data types of the Siamese inputs (`view_1`, `view_2`, `view_3`) and the target mask.
    *   **Model**: Instantiate `SiameseSegFormer` (without pretrained weights). Perform a forward pass with the sample data to verify the output shape matches the expected segmentation map dimensions.
    *   **Loss**: Compute `BCEDiceLoss` on the model output and verify it produces a valid scalar.
5.  **Training Simulation**: Run a single epoch of training using `train_one_epoch` and a validation step using `validate`. Save the resulting model as a checkpoint to verify the saving mechanism.
6.  **Inference Simulation**: Initialize the `InferenceEngine` using the saved checkpoint. Execute `generate_submission` to process the demo test fragment and produce a `submission.csv`.
7.  **Final Validation**: Assert that the submission file was created and contains the expected columns.
