Based on the comprehensive empirical analysis and the synthesis of the "Lessons Learned," I propose the **Depth-Specialist SegFormer Ensemble (DS-SegFormer)**.

This strategy introduces a structural evolution by shifting from a "Single Generalist" paradigm (which struggles to learn invariance on micro-datasets) to a "Multi-Model Specialist" paradigm. It resolves the conflict between the need for **High-SNR Training Data** (Lesson 00034) and **Flexible Inference Depth** (Lesson 00035) by training three independent models, each specialized to a specific depth view. This ensures that during inference scanning, the ink is always detected by a model explicitly trained for that specific Z-configuration, avoiding the "Channel Variance" failure mode of previous attempts.

### Model
**Architecture:** I propose an **Ensemble of three independent SegFormer MiT-B2** networks.
*   **Backbone:** Each model utilizes the **MiT-B2** encoder (~25M parameters).
    *   *Rationale:* Previous experiments confirmed that scaling up to MiT-B3 or MiT-B4 in this low-data regime (~400 samples) causes the model to overfit to intensity artifacts, degrading the F0.5 score (Cite Lesson 00040). The B2 backbone provides the optimal balance of receptive field and regularization.
*   **Decoder:** We strictly retain the standard **All-MLP Decoder** for each model.
    *   *Rationale:* Experiments demonstrated that U-Net decoders with direct skip connections propagate high-frequency substrate noise (papyrus fibers) to the output, reducing precision (Cite Lesson 00043). The MLP decoder's bottleneck forces the model to learn robust semantic features.
*   **Input Interface:** All models maintain the **3-channel input interface** to utilize **ImageNet-pretrained weights** without modification (Cite Lesson 00024, 00025).

### Data
**Preprocessing (Training):**
*   **Overlapping Stratified Depth Projection:** We employ the "Overlapping Thick Slab" strategy (Cite Lesson 00029) to generate high-SNR inputs. We define a slab thickness of 12 slices with 50% overlap.
*   **Structural Innovation: Specialist Dataset Generation:** Instead of training one model on a single view or randomized views, we generate **three distinct fixed datasets**, one for each specialist model:
    1.  **Dataset A (High):** Fixed Z-window **16–40**. (Ink appears primarily in Channel 2/3).
    2.  **Dataset B (Center):** Fixed Z-window **20–44**. (Ink appears primarily in Channel 2).
    3.  **Dataset C (Low):** Fixed Z-window **24–48**. (Ink appears primarily in Channel 1/2).
    *   *Rationale:* This approach strictly adheres to the "Narrow Context" principle (Cite Lesson 00034) to maximize SNR, while ensuring that the ensemble collectively covers the "Wandering Ink" range without introducing label noise (Cite Lesson 00035).
*   **Normalization:** Pixel values are normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** Random horizontal/vertical flips and 90-degree rotations.
*   **Exclusion of Intensity Augmentation:** We explicitly **exclude** brightness/contrast augmentations to preserve physical radiodensity semantics (Cite Lesson 00006).

### Training
*   **Independent Specialist Training:** We execute three separate training runs to produce `Model_A`, `Model_B`, and `Model_C`.
*   **Micro-Dataset Optimization Protocol:**
    *   **Batch Size:** We strictly set the batch size to **8**. This maximizes the number of gradient updates per epoch, preventing the underfitting observed with larger batches on this small dataset (Cite Lesson 00044).
    *   **Learning Rate:** We use a **Conservative Learning Rate** of `6e-5` with the **AdamW** optimizer. Aggressive rates (e.g., `2e-4`) caused divergence in previous Transformer experiments (Cite Lesson 00037).
*   **Loss Function:** **BCE + Dice Loss**. We utilize the balanced Dice Loss, as weighted variants (Tversky) failed to improve the F0.5 metric (Cite Lesson 00031).
*   **Validation Gating:** Each model is saved only if its validation F0.5 score exceeds a high-quality baseline (e.g., 0.55), ensuring the ensemble is composed of competent predictors (Cite Lesson 00004).

### Evaluation
**Inference Strategy: Matched-View Ensemble Fusion**
We leverage the ensemble to perform robust Z-scanning.
1.  **Matched Scanning:** For each test fragment, we generate the three specific views used in training (View A, View B, View C).
2.  **Specialist Prediction:**
    *   `Model_A` predicts on `View A`.
    *   `Model_B` predicts on `View B`.
    *   `Model_C` predicts on `View C`.
    *   *Rationale:* This guarantees that the input data distribution at inference matches the training distribution for each model. For example, if ink is high in the volume, `Model_A` will see it in the channel configuration it was trained to recognize.
3.  **Max-Fusion:** We compute the **Maximum Probability Projection** across the three predictions per pixel.
    *   *Rationale:* Max-fusion effectively aggregates the confident detections from the specialist that had the optimal view of the ink (Cite Lesson 00042).
4.  **Defensive Inference:** Explicitly check input tensor shapes `(Batch, 3, H, W)` before batching (Cite Lesson 00005).
