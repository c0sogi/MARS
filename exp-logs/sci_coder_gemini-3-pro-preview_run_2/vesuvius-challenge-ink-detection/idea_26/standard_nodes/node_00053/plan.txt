Implementation Strategy:
1.  **Setup and Configuration**: Import necessary libraries and the provided modules (`library.config`, `library.train`, `library.inference`, etc.). Override `Config.SUBMISSION_FILE` to point to `./submission/submission.csv` and ensure the directory exists, satisfying the specific path requirement.
2.  **Training**: Execute `train_model(load_cached_data=True)`. This runs the SegFormer training pipeline for 15 epochs (fast baseline) and saves the best model based on the F0.5 score.
3.  **Validation and Failure Analysis**:
    *   Load the best saved model (`best_model.pth`).
    *   Iterate through the validation set using `get_loaders`.
    *   Compute the global F0.5 score on the entire validation set to determine if the solution meets the success criteria.
    *   Simultaneously, collect error metrics (1 - F0.5) and input features (Mean Intensity) for each sample to perform failure analysis.
    *   Calculate and print the Pearson correlation between error magnitude and input intensity.
4.  **Submission**:
    *   Print the "Final Validation Metric" in the required format.
    *   Check if the metric exceeds the threshold (0.597622633).
    *   If successful, call `predict_and_submit(load_cached_data=True)` to generate the run-length encoded submission file.
