The implementation strategy involves creating a self-contained script that validates the core components of the provided library. First, we will override the global `Config` to point to a temporary working directory and reduce hyperparameters (1 epoch, reduced batch size, single Z-slice inference) to ensure rapid execution. We will then create a tiny subset of the metadata (5 samples) to simulate a small dataset, ensuring the data loading and caching mechanisms run quickly without processing the full gigabyte-scale volumes.

The script will proceed through the following stages:
1.  **Utility Verification**: Test the `sigmoid`, `rle_encoding`, and `dice_coefficient` functions with known inputs to ensure mathematical correctness.
2.  **Model Verification**: Instantiate the `InkSegFormer`, pass a dummy tensor, and assert the output shape matches the expected segmentation map dimensions.
3.  **Training Loop**: Execute `train_model()` using the subset metadata. This validates the data loading pipeline, the volume caching logic, the forward/backward pass, and the checkpoint saving mechanism.
4.  **Inference Loop**: Execute `predict_and_submit()` to verify the inference logic, including windowing, probability aggregation, and RLE submission generation.
5.  **Final Checks**: Confirm the generation of `submission.csv` and clean up temporary artifacts.
