This script demonstrates the end-to-end usage of the provided Vesuvius Ink Detection library. It begins by configuring the environment for a rapid test run (Debug mode, 1 epoch). It then verifies the core utility functions (RLE encoding, F-beta score), tests the dataset loading and preprocessing pipeline (including 3D-to-2D projection), validates the model architecture and loss function, and finally executes the full training and inference workflows to generate a submission file.
