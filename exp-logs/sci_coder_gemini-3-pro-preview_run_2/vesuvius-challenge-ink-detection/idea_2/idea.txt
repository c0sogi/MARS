Based on the empirical findings and lessons learned, I propose the following optimized strategy. This solution evolves the successful "Stratified Depth Projection" baseline by significantly increasing the encoder's feature extraction capacity and introducing robust inference techniques.

# Deep 2.5D ResNet34 U-Net with Stratified Depth Projection

### Model
**Architecture:** I propose upgrading the backbone architecture from the previously used ResNet18 to a **ResNet34** encoder within a U-Net framework.
*   **Rationale:** The transition from a single-channel MIP to a 3-channel stratified input (Cite Lesson 00010) successfully enriched the feature space, improving the F0.5 score to 0.4739. However, the lightweight ResNet18 backbone may be underfitting this denser, multi-channel representation. By adopting ResNet34, we increase the network's depth and receptive field, allowing it to better capture the complex, non-local spatial dependencies of ink strokes that span across the stratified depth channels.
*   **Input:** The model will accept a 3-channel input tensor `(Batch, 3, Height, Width)`, corresponding to the stratified sub-volumes.
*   **Initialization:** The encoder will be initialized with pre-trained ImageNet weights to leverage learned texture and edge detection filters.

### Data
**Preprocessing:**
*   **Stratified Depth Projection:** We will retain the successful "2.5D" approach. The central Z-slice range (22-42) will be split into three contiguous sub-volumes. A Maximum Intensity Projection (MIP) will be computed for each sub-volume, and these three projections will be stacked to form the 3-channel input image. **Cite Lesson 00010**.
*   **Normalization:** Pixel values will be normalized to [0, 1] based on dataset statistics.

**Augmentation:**
*   **Geometric Only:** We will apply random horizontal/vertical flips and 90-degree rotations.
*   **Intensity Constraints:** We will explicitly **exclude** brightness, contrast, and gamma augmentations. As observed in previous experiments, these transformations destroy the physical radiodensity signal required to distinguish ink from papyrus. **Cite Lesson 00006**.

### Training
*   **Loss Function:** We will use a composite loss of Binary Cross Entropy (BCE) and Dice Loss to optimize for both pixel-wise accuracy and overlap (F0.5 score).
*   **Validation Gating:** The training loop will implement a strict check at the end of execution. The submission file will only be generated if the current model's best validation F0.5 score exceeds the previous best baseline. **Cite Lesson 00004**.
*   **Optimizer:** Adam optimizer with a learning rate scheduler (ReduceLROnPlateau).

### Evaluation
*   **Defensive Inference:** The inference pipeline will include explicit checks to ensure input tensors have the correct `(1, C, H, W)` shape before batching, preventing runtime errors with grayscale or stratified inputs. **Cite Lesson 00005**.
*   **Test Time Augmentation (TTA):** To further boost the F0.5 score, we will implement Test Time Augmentation. During inference, the model will predict on the original image patches as well as their horizontally and vertically flipped versions. The resulting probability maps will be averaged before applying the threshold. This leverages the geometric invariance of the ink to smooth out random prediction noise and improve segmentation continuity.
