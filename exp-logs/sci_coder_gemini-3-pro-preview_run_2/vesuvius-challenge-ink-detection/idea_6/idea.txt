Based on the comprehensive empirical history provided in the "Lessons" and "Previous Ideas", I propose the **Fine-Grained Stratified SegFormer**.

This strategy evolves the high-performing SegFormer architecture (Lesson 00024) by structurally modifying it to accept a higher-dimensional **Fine-Grained Stratified** input. This directly addresses the "Signal Dilution" observed in thick projections (Lesson 00015) and leverages the "Strict Stratification" principle (Lesson 00018) to maximize feature resolution along the Z-axis.

# Fine-Grained Stratified SegFormer (MiT-B2)

### Model
**Architecture:** I propose upgrading the backbone to the **SegFormer MiT-B2** (Mix Transformer B2).
*   **Structural Innovation (Input Adapter):** Standard ImageNet models accept 3 channels. We will modify the first **Patch Embedding layer** of the MiT-B2 encoder to accept **6 input channels**. This allows the model to process a finer-grained stratification of the 3D volume without compressing the depth information into the arbitrary 3-channel limit of RGB images.
*   **Backbone:** The MiT-B2 encoder is larger and more powerful than the B1 used in the previous best run (0.551 F0.5). Its hierarchical Transformer design captures the global context required to distinguish ink strokes from noise (Cite Lesson 00024), while being more robust to local intensity artifacts than deep CNNs like ResNet34 (Cite Lesson 00014).
*   **Decoder:** A lightweight MLP decoder aggregates multi-scale features to predict the binary mask.

### Data
**Preprocessing:**
*   **Fine-Grained Stratified Projection:** Instead of splitting the volume into 3 thick slabs (which dilutes the signal, Cite Lesson 00015), we will split the central Z-volume (approx. slices 20-44) into **6 contiguous slabs** of 4 slices each.
*   **Projection:** For each of the 6 slabs, we compute the **Maximum Intensity Projection (MIP)**.
    *   *Rationale:* Thinner slabs reduce the amount of empty space included in the max operation, increasing the contrast of the ink signal against the background noise (Cite Lesson 00015).
    *   *Strict Stratification:* We strictly avoid adding a global full-volume MIP channel to prevent the model from shortcutting learning via global intensity thresholds (Cite Lesson 00018).
*   **Tensor Construction:** These 6 MIPs are stacked to form a `(6, Height, Width)` input tensor.
*   **Normalization:** Pixel values are normalized to [0, 1] using dataset statistics.

**Augmentation:**
*   **Geometric Only:** We apply random horizontal/vertical flips and 90-degree rotations.
*   **Intensity Constraints:** We explicitly **exclude** brightness, contrast, and gamma augmentations. The model relies on physical radiodensity values to detect ink, and intensity perturbations destroy this signal (Cite Lesson 00006).

### Training
*   **Weight Initialization (Channel Expansion):** We load **ImageNet-pretrained weights** for the MiT-B2 model (Cite Lesson 00024). To handle the 6-channel input, we initialize the weights of the modified Patch Embedding layer by replicating the pretrained RGB weights (e.g., copying the weights for channels 0-2 into channels 3-5) and scaling them mathematically to preserve the output distribution. This ensures we retain the benefit of transfer learning.
*   **Loss Function:** A composite **BCE + Dice Loss** is used to optimize for both pixel accuracy and the F0.5 overlap metric.
*   **Optimizer:** AdamW optimizer with a `ReduceLROnPlateau` scheduler.
*   **Validation Gating:** The execution script will strictly compare the current model's best validation F0.5 score against the previous best baseline (0.551). The submission file will **only** be generated if the new model outperforms this baseline, preventing inferior runs from overwriting the best result (Cite Lesson 00004).

### Evaluation
*   **Defensive Inference:** The inference pipeline will explicitly check the input tensor shape to ensure it matches the expected `(Batch, 6, H, W)` dimensions. This prevents runtime errors related to channel squeezing often seen with custom input depths (Cite Lesson 00005).
*   **Test Time Augmentation (TTA):** We will average predictions from the original input and its geometric transformations (flips/rotations) to smooth out prediction noise.
