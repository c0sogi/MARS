Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment with a fixed random seed. Override `CFG.epochs` to 50 to ensure the pipeline completes comfortably within the 2-hour limit while still providing sufficient training steps for the small dataset.
2.  **Data Preparation**: Load the pre-generated metadata files (`train.csv`, `val.csv`, `test.csv`). Combine the training data and use `IterativeStratifiedKFold` (K=5) to create robust training/validation splits that preserve multi-label distribution.
3.  **Model Training (Heterogeneous Ensemble with SAM)**:
    *   Iterate through three distinct backbones: `resnet18`, `efficientnet_b0`, and `densenet121`.
    *   For each fold and backbone, instantiate the `BirdModel` (with Multi-Sample Dropout head).
    *   Use the `SAM` optimizer (wrapping `AdamW`) to minimize both loss value and sharpness, improving generalization on this small dataset.
    *   Calculate class-specific `pos_weight` to handle imbalance.
    *   Train for the specified epochs, saving the best model based on internal fold validation AUC.
4.  **Inference & Validation**:
    *   Load the hold-out validation set (`val.csv`).
    *   Perform Test-Time Augmentation (TTA) with 4 temporal shifts (0%, 25%, 50%, 75%) for every model in the ensemble (15 models total).
    *   Average the predictions to form a "Grand Ensemble".
    *   Compute and print the `Final Validation Metric` (Macro-Averaged ROC AUC).
5.  **Failure Analysis**:
    *   Calculate the Mean Absolute Error (MAE) per sample on the validation set.
    *   Compute and print correlations between this error and (a) label cardinality (number of species) and (b) image brightness (input feature).
6.  **Submission**:
    *   Check if the validation metric exceeds the threshold (0.91677...).
    *   If passed, generate predictions for the test set (`test.csv`) using the full ensemble and TTA.
    *   Format the output as `Id,Probability` (mapping `rec_id` and `species_id` to `Id`) and save to `submission.csv`.
