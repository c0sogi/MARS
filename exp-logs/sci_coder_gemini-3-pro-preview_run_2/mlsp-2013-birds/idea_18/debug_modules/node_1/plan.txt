The issue is caused by Python's behavior where default arguments are evaluated only once at function definition time. In `library/data.py`, `get_dataloaders` sets `batch_size=Config.BATCH_SIZE` (defaulting to 32). Although `runfile.py` updates `Config.BATCH_SIZE` to 8 at runtime, the function call `get_dataloaders(fold_idx=0, debug=Config.DEBUG)` does not pass the new batch size, causing it to revert to the stale default of 32. Cite debug_lesson_4. Because the debug dataset contains only ~20 samples, a batch size of 32 with `drop_last=True` results in all data being dropped, creating an empty loader. The fix is to explicitly pass `batch_size=Config.BATCH_SIZE` when calling the function in `runfile.py`.
