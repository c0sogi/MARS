The `IterativeStratifiedKFold` class belongs to a different library (`iterative-stratification`) which is not being used here. To fix this, I will correct the import to use `IterativeStratification` and update the instantiation to match its API, which does not accept `shuffle` or `random_state` arguments (Cite debug_lesson_2).
