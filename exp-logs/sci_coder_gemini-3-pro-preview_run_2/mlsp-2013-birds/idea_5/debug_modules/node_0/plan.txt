The following script demonstrates the usage of the provided library files (`utils.py`, `model.py`, `data_loader.py`, `train_eval.py`). It performs the following steps:

1.  **Setup**: Configures paths and sets random seeds for reproducibility.
2.  **Data Verification**: Initializes the `BirdDataset` and `DataLoader` to fetch a batch of data, verifying the tensor shapes (specifically the multi-instance tiling structure).
3.  **Model Verification**: Instantiates the `MILResNet18` model and performs a forward pass to ensure the architecture accepts the input format and produces valid logits.
4.  **Pipeline Execution**: Runs a simplified version of the K-Fold training and inference pipeline (2 folds, 1 epoch) to demonstrate the end-to-end process quickly.
5.  **Output Validation**: Checks the generated `submission.csv` for correct formatting, row count, and value ranges.
