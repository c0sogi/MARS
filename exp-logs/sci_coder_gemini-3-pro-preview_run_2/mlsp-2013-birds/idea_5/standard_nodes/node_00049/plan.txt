1.  **Data Processing (Cite solution_lesson_node_00027, solution_lesson_node_00030, solution_lesson_node_00034):**
    -   Revert the tiling/MIL logic. Instead, resize spectrograms to a rectangular shape of **224x448** to preserve temporal resolution.
    -   Convert single-channel spectrograms to 3-channel "Pseudo-RGB" by replicating the channel, allowing the use of unmodified ImageNet-pretrained models.
2.  **Model Architecture (Cite solution_lesson_node_00034, solution_lesson_node_00042):**
    -   Implement a heterogeneous ensemble of **ResNet18** and **DenseNet121**. This combines the robustness of ResNet with the feature reuse of DenseNet, stabilizing predictions on this small dataset.
3.  **Training Stability (Cite solution_lesson_node_00045, solution_lesson_node_00042, solution_lesson_node_00040):**
    -   Implement `worker_init_fn` and `torch.Generator` in DataLoaders to ensure proper RNG seeding across worker processes, maximizing augmentation diversity.
    -   Reduce **Batch Size to 16** to increase gradient update frequency and regularization noise.
    -   Use an aggressive **Learning Rate of 1e-3** to ensure effective adaptation from ImageNet to spectrograms.
    -   Increase **Epochs to 50** to ensure convergence given the small dataset size.

class MILResNet18(nn.Module):
    def __init__(self, num_classes=19, pretrained=True):
        super(MILResNet18, self).__init__()

        # Load backbone
        weights = ResNet18_Weights.DEFAULT if pretrained else None
        self.backbone = resnet18(weights=weights)

        # Modify first layer for 1-channel input
        # Original: Conv2d(3, 64, kernel_size=7, stride=2, padding=3, bias=False)
        # We sum the weights across the channel dimension to preserve pretrained features
        old_conv = self.backbone.conv1
        new_conv = nn.Conv2d(1, 64, kernel_size=7, stride=2, padding=3, bias=False)

        with torch.no_grad():
            # Sum weights across input channels (dim 1) -> (64, 1, 7, 7)
            new_conv.weight.copy_(torch.sum(old_conv.weight, dim=1, keepdim=True))

        self.backbone.conv1 = new_conv

        # Replace FC layer
        num_ftrs = self.backbone.fc.in_features
        self.backbone.fc = nn.Linear(num_ftrs, num_classes)

    def forward(self, x):
        # x shape: (Batch, Tiles, Channels, Height, Width) -> (B, 3, 1, 224, 224)
        b, t, c, h, w = x.size()

        # Merge Batch and Tiles dimensions
        x = x.view(b * t, c, h, w)

        # Pass through backbone
        logits = self.backbone(x)  # (B*T, Num_Classes)

        # Reshape back to separate tiles
        logits = logits.view(b, t, -1)  # (B, 3, Num_Classes)

        # MIL Aggregation: Max Pooling across tiles
        # We take the max logit for each class across the 3 tiles
        aggregated_logits, _ = torch.max(logits, dim=1)  # (B, Num_Classes)

        return aggregated_logits
