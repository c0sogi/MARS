This script demonstrates the end-to-end pipeline for the bird species classification task using the provided library files. It covers data loading, dataset creation, model instantiation, training, validation, TTA inference, and submission generation.

To ensure the execution completes within the 5-minute limit, the script dynamically overrides configuration parameters to use a minimal subset of data (8 samples), a lightweight model (`resnet18`), and reduces training epochs and TTA steps. It includes assertions to verify the correctness of shapes and outputs at each stage.
