The following script demonstrates the end-to-end usage of the provided library files for the bird species classification task. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters to run a fast, lightweight demonstration (small batch size, few epochs, subset of data) within the provided `./working` directory.
2.  **Data Loading & Validation**: Loads the metadata CSVs, creates a subset for testing, and verifies the `BirdDataset` class functionality, including shape checks for images and labels.
3.  **Transform Verification**: Explicitly tests the `cyclic_roll` function to ensure time-shifting logic works as expected.
4.  **Model Instantiation**: Initializes the `BirdClassifier` (using ResNet18) and performs a forward pass with dummy data to verify output dimensions.
5.  **Training Loop Execution**: Runs a complete training epoch using `train_one_epoch` and evaluates performance using `evaluate`, ensuring the loss calculation and AUC metrics function correctly.
6.  **Inference with TTA**: Demonstrates the Test-Time Augmentation (TTA) inference pipeline and verifies the shape of the generated predictions.
7.  **Submission Generation**: Creates a sample submission file formatted correctly for the competition.
