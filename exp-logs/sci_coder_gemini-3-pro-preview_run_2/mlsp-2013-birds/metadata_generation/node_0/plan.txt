The implementation strategy is as follows:

1.  **Setup**: Define input and output directories. Initialize constants for the random state (42) and validation split ratio (0.2).
2.  **Data Loading**: Parse the raw text files (`rec_id2filename.txt`, `CVfolds_2.txt`, `rec_labels_test_hidden.txt`) from the `./input` directory into Pandas DataFrames. Handle potential header variations and variable-length label lines.
3.  **Data Merging & Processing**: Merge all data on `rec_id`. Construct relative file paths for the audio files and spectrograms. Convert the list of species IDs into a multi-hot encoded format (19 columns) for classification.
4.  **Dataset Splitting**:
    *   Isolate the official competition test set (Fold 1).
    *   Isolate the training/development set (Fold 0).
    *   Shuffle the development set and apply `iterative_train_test_split` from `skmultilearn` to create a stratified 80/20 train/validation split, ensuring balanced multi-label distributions.
5.  **Metadata Generation**: Save the `train.csv`, `val.csv`, and `test.csv` files to the `./metadata` directory.
6.  **Verification**: Reload the metadata to verify dataset sizes, split ratios, and label distributions. Programmatically check the existence of all referenced file paths to ensure data integrity.
