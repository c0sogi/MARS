Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override settings to optimize for speed. This includes enabling `DEBUG` mode (to use a tiny data subset), reducing `NUM_EPOCHS` to 1, and setting a small `BATCH_SIZE`.
2.  **Data Pipeline Verification**: Call `make_folds` to generate the cross-validation splits. Then, instantiate training and validation `DataLoaders` using `get_dataloaders` and verify the shape and data types of the resulting batches (images and multi-hot labels).
3.  **Model Initialization**: Use the `get_model` factory to create a `resnet18` instance. We disable pre-trained weights (`pretrained=False`) to avoid network overhead and ensure immediate initialization. We verify the model by running a forward pass with a dummy batch.
4.  **Metric Utility Check**: Explicitly test the `calculate_roc_auc` function with synthetic numpy arrays to ensure it correctly handles multi-label inputs.
5.  **Training Loop Execution**: Run the `train_model` function. This integrates the model, data loaders, optimizer, and loss function (including class weighting and mixup augmentation) into a single execution flow to verify end-to-end stability.
6.  **Inference Verification**: Instantiate the test data loader using `get_test_dataloader` and verify that it yields images and recording IDs (instead of labels) for submission generation.
