This script demonstrates the end-to-end usage of the provided library modules for the Bird Species Classification task. It covers data loading with caching, model initialization (ResNet18), loss function calculation (Weighted BCE and Distillation), training loops (standard and distillation), validation, and Test-Time Augmentation (TTA) inference. To ensure execution within the time limit, the script operates on a small subset of the data and runs for a single epoch.
