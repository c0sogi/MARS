**Implementation Strategy:**
1.  **Setup & Configuration:** Initialize the environment using the provided `Config` and `utils`. Load the metadata CSVs (`train.csv`, `val.csv`, `test.csv`).
2.  **Stage 1: Teacher Training:**
    *   Iterate through the three backbone architectures: `resnet18`, `densenet121`, `efficientnet_b0`.
    *   Train each model on the supervised training set using `BCEWithLogitsLoss` balanced by positive class weights.
    *   Use `Mixup` augmentation and `AdamW` optimization.
    *   Save the best checkpoint for each model based on validation AUC.
3.  **Stage 2: Pseudo-Labeling:**
    *   Load the best Teacher models.
    *   Generate soft probability predictions for the unlabelled test set.
    *   Ensemble (average) these predictions to create high-quality soft pseudo-labels.
4.  **Stage 3: Student Training:**
    *   Re-initialize the three backbone models (Students).
    *   Create a combined dataset: Original Labeled Train Data (Hard Labels) + Pseudo-Labeled Test Data (Soft Labels).
    *   Train the Students on this expanded dataset. This allows the models to learn from the "dark knowledge" distilled from the Teachers.
5.  **Final Evaluation & Submission:**
    *   Ensemble the predictions from the trained Student models on the validation set to compute the `Final Validation Metric`.
    *   Perform Failure Analysis by correlating prediction errors with validation sample metadata (Label Cardinality and Signal Intensity).
    *   If the validation AUC exceeds the threshold (0.91295...), generate predictions for the test set using the Student Ensemble.
    *   Format the submission as required (`rec_id * 100 + species_id`) and save to `submission.csv`.
