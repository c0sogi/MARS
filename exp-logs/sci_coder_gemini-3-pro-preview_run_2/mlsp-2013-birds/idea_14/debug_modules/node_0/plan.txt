This script demonstrates the end-to-end usage of the provided library modules for the bird species classification task. It covers configuration setup, data loading with caching, model initialization, training with mixup augmentation, validation, inference, and semi-supervised learning data preparation.

The script is optimized for speed by using a small subset of the data and a lightweight model configuration (ResNet18, 1 epoch, no pre-training weights download). It includes assertions to verify the correctness of tensor shapes and logic flow.
