# Proposed Strategy: Fine-Tuning a Pre-trained Transformer

## Model
I propose evolving the architecture from a Recurrent Neural Network (BiLSTM) trained from scratch to a **Pre-trained Transformer (e.g., DistilRoBERTa)**. This represents a structural shift from processing text via temporal recurrence to using **Self-Attention** mechanisms backed by **Transfer Learning**.

- **Backbone**: The model will utilize a pre-trained Transformer encoder. This architecture inherently preserves the sequential context of the input (Cite solution_lesson_node_00002) but processes it via multi-head attention, allowing for the capture of complex, non-local dependencies in the text.
- **Transfer Learning**: The failure of the custom attention mechanism in previous attempts was attributed to overfitting on the small dataset (Cite solution_lesson_node_00004). By using a backbone pre-trained on a massive corpus, we bypass the need to learn linguistic structure from scratch, effectively mitigating the data scarcity issue while retaining the benefits of a complex, deep architecture.
- **Classification Head**: The output of the `[CLS]` token (or mean pooled representation) will be passed through a classification head. To ensure generalization, this head will include **Dropout**, preserving the regularization strategy that proved effective in the deep BiLSTM (Cite solution_lesson_node_00003).

## Data
- **Tokenization**: We will replace the whitespace/character-based tokenization used in the previous ideas with **Subword Tokenization** (e.g., Byte-Pair Encoding) corresponding to the chosen pre-trained model. This method is more robust to the "occasional formatting" and noise mentioned in the dataset description.
- **Preprocessing**: We will retain the basic unicode un-escaping and quote removal to ensure the text is clean before tokenization.

## Training
- **Optimization**: The model will be trained using the **AdamW** optimizer with a linear learning rate scheduler (including warmup), which is standard for stabilizing Transformer fine-tuning.
- **Checkpointing Strategy**: We will implement a strict checkpointing logic. When the validation AUC improves, we will save the model weights using **`copy.deepcopy(model.state_dict())`**. This explicitly addresses the critical engineering failure identified in the previous iteration where relying on reference assignment caused the saved model to drift (Cite solution_lesson_node_00004).
- **Regularization**: In addition to the pre-training and dropout, we will use Weight Decay to further prevent overfitting, respecting the lesson that regularization is key for model performance on this dataset (Cite solution_lesson_node_00003).

## Evaluation
- **Inference**: The test set will be processed using the same subword tokenizer. The model will be loaded from the deep-copied best state, and predictions will be generated in batches to produce the final probability scores for submission.
