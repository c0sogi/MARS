This script demonstrates the usage of the provided library modules for the Insult Detection task. It covers vocabulary creation, dataset handling, model instantiation, and a full execution of the training pipeline.

1.  **Vocabulary**: Demonstrates fitting a vocabulary on sample text, transforming text to indices, and saving/loading the vocabulary.
2.  **Dataset & DataLoader**: Manually creates an `InsultDataset` and verifies the `collate_fn` logic by checking tensor shapes for a batch.
3.  **Model**: Instantiates the `NeuralBoE` model and performs a forward pass with dummy data to verify output dimensions.
4.  **Full Pipeline**: Executes `run_training_pipeline` with a minimal configuration (1 epoch) to demonstrate end-to-end training, validation, and submission generation using the real metadata.
