Based on the comprehensive analysis of previous attempts and the specific lessons learned, I propose a **Self-Training Pipeline with Adversarial Weight Perturbation (AWP)**. This strategy evolves the solution from a standard supervised learning approach to a semi-supervised, robust optimization pipeline. It leverages the high-capacity backbone identified in previous experiments while addressing the "small data" constraint through pseudo-labeling and the "overfitting" risk through adversarial training.

# Model
We will utilize the **`microsoft/deberta-v3-large`** architecture as the sole backbone.
- **Backbone Selection**: We retain the "Large" variant as it demonstrated a superior ability to capture semantic nuances compared to the "Base" model (Cite solution_lesson_node_00016). We explicitly reject the Heterogeneous Ensemble approach (mixing DeBERTa with RoBERTa), as previous experiments showed that including weaker architectures dilutes the performance of the state-of-the-art model (Cite solution_lesson_node_00022).
- **Pooling & Head**: The model will employ **Mean Pooling** of the last hidden state to aggregate signal across the sequence (Cite solution_lesson_node_00009). This pooled representation will be passed to a **Multi-Sample Dropout** head, which averages predictions across multiple dropout masks to reduce variance within a single forward pass (Cite solution_lesson_node_00015).

# Data
We will implement a **Two-Stage Data Augmentation** strategy using Self-Training (Pseudo-Labeling).
- **Preprocessing**: We will maintain the unicode un-escaping and quote removal to ensure clean text input.
- **Pseudo-Labeling (Structural Innovation)**: Recognizing that the test set (~2,600 samples) is comparable in size to the training set (~3,000 samples), we will leverage the unlabeled test data. 
    1.  We will first train a "Teacher" ensemble on the original labeled data.
    2.  This ensemble will predict labels for the test set.
    3.  High-confidence predictions (e.g., probability > 0.9 or < 0.1) will be assigned their predicted class as a "Hard Label" and added to the training pool.
    This effectively expands the training dataset, allowing the model to densify the decision boundary in regions represented in the test set but sparse in the training set.

# Training
The training process will be divided into two distinct stages to maximize the utility of the computational budget (24 hours) while ensuring robustness.

**Stage 1: Teacher Training (Standard Fine-Tuning)**
- **Objective**: Train the initial 5-fold ensemble to generate high-quality pseudo-labels.
- **Configuration**: We will use **Stratified 5-Fold Cross-Validation** (Cite solution_lesson_node_00015) with **Layer-wise Learning Rate Decay (LLRD)** to preserve pre-trained features (Cite solution_lesson_node_00015).
- **Checkpointing**: We will save the best model state using **`copy.deepcopy(model.state_dict())`** based on **Validation AUC**, explicitly ignoring Validation Loss to avoid early stopping due to calibration drift (Cite solution_lesson_node_00004, solution_lesson_node_00006).

**Stage 2: Student Training (Adversarial Optimization)**
- **Objective**: Train the final ensemble on the Augmented Dataset (Original + Pseudo-labels).
- **Adversarial Weight Perturbation (AWP)**: We will integrate AWP into the training loop. This technique injects a minimax optimization step (maximizing loss by perturbing weights, then minimizing it) to smooth the loss landscape.
- **Correction of Previous Failure**: Unlike the failed "Idea 4" which cut training short, we will run AWP for the full duration (e.g., 5-6 epochs). We have sufficient time (24h) to accommodate the ~2x computational cost of AWP, ensuring the model fully converges (Cite solution_lesson_node_00022).
- **Optimization**: We will continue to use AdamW with LLRD. The learning rate will be halved compared to the Base model experiments to ensure stability with the Large backbone (Cite solution_lesson_node_00016).

# Evaluation
- **Inference**: The final predictions will be generated using the **Stage 2 (Student) Ensemble** consisting of 5 models (one from each fold).
- **Aggregation**: We will compute the arithmetic mean of the probabilities from these 5 models. This **Homogeneous Ensemble** ensures that every contributor to the final score is a high-capacity, adversarially robust model, avoiding the dilution caused by weaker architectures (Cite solution_lesson_node_00022).
