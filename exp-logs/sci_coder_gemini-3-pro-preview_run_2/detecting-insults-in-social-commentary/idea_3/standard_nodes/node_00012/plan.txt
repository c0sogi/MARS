The implementation strategy follows a robust Cross-Validation Ensemble approach to maximize performance on the small dataset. We utilize the provided library modules to load the preprocessed data, which combines the training and validation sets for a Stratified K-Fold split. We train a DeBERTa-v3-base model with Multi-Sample Dropout for each of the 5 folds. The training process employs Layer-wise Learning Rate Decay (LLRD) and a cosine schedule to fine-tune the model effectively. After training, we perform ensemble inference on the hold-out validation set (identified by index splitting) to compute the final validation metric and conduct failure analysis. Finally, if the metric exceeds the threshold, we generate predictions for the test set using the ensemble of all 5 models and save the submission.
