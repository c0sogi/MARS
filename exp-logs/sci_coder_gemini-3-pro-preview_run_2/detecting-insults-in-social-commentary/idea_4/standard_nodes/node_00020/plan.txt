The error analysis indicates that the training process crashed due to a `torch.OutOfMemoryError` on a 16GB GPU. The current configuration (`batch_size = 16`) was optimized for an A100 40GB GPU, which exceeds the available VRAM capacity of the current environment (~15.77 GiB), especially when Adversarial Weight Perturbation (AWP) is active. Additionally, the memory-saving feature Gradient Checkpointing is currently disabled in the model definition.

To resolve this, I will:
1.  **Enable Gradient Checkpointing** in `library/model.py` to significantly reduce activation memory usage by trading compute for memory.
2.  **Reduce Batch Size** in `library/config.py` from 16 to 8 to fit the model and AWP overhead within the 16GB VRAM limit, adhering to the hardware constraints identified (Cite debug_lesson_2).
