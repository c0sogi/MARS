Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override specific paths and parameters (e.g., batch size, epochs, working directory) to create a lightweight "demo" environment. This ensures the script runs quickly and doesn't interfere with existing experiment files.
2.  **Data Loading & Processing**: Use `get_metadata` to load the dataframe, then slice it to a very small subset (e.g., 20 samples) for speed. Instantiate `PetDataset` and `DataLoader` for training, validation, and testing. Verify the output shapes of the data loaders.
3.  **Model Instantiation**: Initialize the `PetModel` using a lightweight architecture (`resnet18`) instead of the heavy transformers listed in the config. Perform a forward pass with a dummy batch to validate the output shape matches the binary classification requirement (Batch, 1).
4.  **Training & Evaluation Loop**: Run a single epoch of training using `train_one_epoch` and a validation pass using `evaluate`. Check that the loss decreases or is valid (not NaN) and that metrics are returned correctly.
5.  **Inference (TTA)**: Run `predict_tta` on the test subset to demonstrate test-time augmentation and prediction generation.
6.  **Model Soup Demonstration**: Save two distinct checkpoints from the model (e.g., before and after a weight update). Use `generate_model_soup` to combine them. Verify that the resulting model weights are the numerical average of the inputs.
7.  **Validation**: Throughout the script, assertions are used to strictly verify shapes, types, and logic correctness.
