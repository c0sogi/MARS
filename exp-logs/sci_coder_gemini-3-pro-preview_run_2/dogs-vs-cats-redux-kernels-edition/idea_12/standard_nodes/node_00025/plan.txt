Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds, and detect the computing device. Override `Config` parameters (epochs, sample size) to ensure the script runs within the "fast baseline" time limits while maintaining the integrity of the 5-fold stacking strategy.
2.  **Data Preparation**: Load the training, validation, and test metadata. Subsample the training data to speed up the baseline execution. Initialize `StratifiedKFold` for the training set to generate Out-Of-Fold (OOF) predictions.
3.  **Model Training & Souping Loop**: Iterate through the three specified architectures (`ConvNeXt`, `Swin`, `EfficientNetV2`) and five folds.
    *   Train each model using the `fit` function.
    *   Generate a "Model Soup" by averaging the weights of the last few checkpoints.
    *   Perform inference with the soup model to generate OOF predictions (for the meta-learner), hold-out validation predictions (for final scoring), and test predictions (for submission).
4.  **Stacking (Meta-Learner)**: Concatenate the OOF predictions from all models to form a feature set. Train a Logistic Regression meta-learner to map these features to the ground truth labels.
5.  **Validation & Failure Analysis**: Apply the trained meta-learner to the hold-out validation set predictions. Calculate the final Log Loss. Perform failure analysis by correlating prediction errors with image metadata (width, height, aspect ratio).
6.  **Submission**: If the final validation metric meets the specified threshold, apply the meta-learner to the test set predictions and generate the submission file.
