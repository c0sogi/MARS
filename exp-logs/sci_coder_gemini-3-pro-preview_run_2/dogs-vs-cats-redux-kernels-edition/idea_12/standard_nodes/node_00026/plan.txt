The issue is that the `runfile.py` script does not initialize the required directory structure before starting the training process. specifically, the `checkpoints` directory defined in `Config` is never created on the filesystem, causing `torch.save` to fail with a `RuntimeError` when it attempts to save the model. To fix this, I will add a call to `Config.setup_directories()` in the setup phase of the `main` function in `runfile.py`.
