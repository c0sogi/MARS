Implementation Strategy:
1.  **Environment Setup**: Import libraries and configure the `Config` class to run a minimal version of the task (1 epoch, 1 fold, small batch size).
2.  **Data Preparation**: Manually create small subsets of the training and test metadata (using Pandas) and save them to the working directory. This ensures the data loaders read only a tiny fraction of the data, satisfying the speed constraint.
3.  **Data Loading Verification**: Instantiate the training and validation loaders using the subset data and assert that they yield batches of the correct shape.
4.  **Model & Training**: Initialize the `convnext_small` model and run the training loop for the single fold. Verify that the model trains without error and saves a checkpoint.
5.  **Inference & Submission**: Execute the inference pipeline using the generated checkpoint and the subset test data. Verify that the submission file is generated with the correct schema and value ranges.
6.  **Validation**: Use assertions throughout to confirm file existence, tensor shapes, and data integrity.
