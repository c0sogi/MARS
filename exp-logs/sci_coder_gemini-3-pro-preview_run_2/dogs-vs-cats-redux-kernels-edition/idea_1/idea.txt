To establish a robust and highly efficient baseline, I propose a **Fine-Tuned ResNet-18** approach. This solution synthesizes the convolutional feature extraction strengths of Model 1 with the pre-training efficiency of Model 3, but simplifies the pipeline into a single, end-to-end differentiable architecture. It avoids the complexity of the progressive learning schedules in Model 1 and the separate multi-stage training (CNN + GBDT) of Model 3.

### Model
The architecture is based on **ResNet-18**, a lightweight 18-layer Convolutional Neural Network.
*   **Backbone**: The model utilizes a ResNet-18 backbone pre-trained on the ImageNet dataset. This allows the model to leverage learned low-level features (edges, textures) and high-level semantic patterns (shapes, object parts) without training from scratch.
*   **Head**: The original 1000-class classification layer is removed and replaced with a **single fully connected linear layer** with one output neuron. This neuron outputs a raw logit score representing the confidence that the image belongs to the "Dog" class.
*   **Activation**: A Sigmoid activation function is applied to the output logit during inference to squash the value between 0 and 1, representing a probability.

### Data
*   **Preprocessing**: All images (train and test) are resized to a fixed resolution of **224x224 pixels**. The pixel values are normalized using the standard ImageNet mean and standard deviation to ensure consistent input distributions for the pre-trained weights.
*   **Augmentation**: To maintain speed and simplicity while preventing basic overfitting, only **Random Horizontal Flipping** is applied during training. No heavy augmentations (like Mixup or Cutmix) are used.
*   **Loading**: Data is loaded in batches (e.g., batch size of 32 or 64) using standard data loaders with shuffling enabled for the training set.

### Training
*   **Loss Function**: The model is trained using **Binary Cross-Entropy with Logits Loss**. This combines the Sigmoid activation and the Binary Cross-Entropy loss into a single class for numerical stability.
*   **Optimizer**: The **AdamW** optimizer is used for its ability to converge quickly without extensive hyperparameter tuning. A relatively low learning rate (e.g., 1e-4) is employed to adjust the pre-trained weights gently without destroying the learned features.
*   **Procedure**: The model undergoes a short training cycle (e.g., 3 to 5 epochs). This is sufficient for the pre-trained backbone to adapt to the specific Dog vs. Cat domain.

### Evaluation
*   **Inference**: Test images are processed using the same resizing and normalization steps as the training data (without augmentation).
*   **Prediction**: The model computes the forward pass for each test image to generate a logit. The Sigmoid function is applied to this logit to produce the final probability score required for the submission format.
*   **Submission**: The resulting probabilities are paired with their corresponding image IDs and saved to a CSV file.
