The issue arises because Python evaluates default function arguments at definition time (when the module is imported), not at call time. In `library/inference.py`, `run_inference` captures the original `Config.CHECKPOINT_DIR` value. When `runfile.py` modifies `Config.CHECKPOINT_DIR` at runtime inside `run_demo`, the `run_inference` function does not see this change and attempts to load checkpoints from the original path, failing to find the demo models. To fix this, I will explicitly pass the updated `Config.CHECKPOINT_DIR` and `Config.SUBMISSION_DIR` to `run_inference` within `runfile.py`.
