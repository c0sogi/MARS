The issue is caused by Python's behavior where default argument values are evaluated once at function definition time. In `library/utils.py`, the `save_checkpoint` function defines `dir_path=Config.CHECKPOINT_DIR` in its signature. When `runfile.py` later updates `Config.CHECKPOINT_DIR` to the demo directory, `save_checkpoint` continues to use the stale original path captured at import time, resulting in checkpoints being saved to the wrong location and triggering the `AssertionError` (Cite debug_lesson_4).

To fix this, I will modify `save_checkpoint` in `library/utils.py` to set the default value of `dir_path` to `None` in the signature, and then resolve `Config.CHECKPOINT_DIR` inside the function body. This ensures the current runtime value of the configuration is used.
