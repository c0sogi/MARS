Implementation Strategy:
1.  **Setup & Reproducibility**: Initialize the environment by setting fixed random seeds using `library.utils.set_seed`.
2.  **Data Loading Demonstration**: Use `library.data.get_dataloaders` with a small `debug_subset_size` (e.g., 50 samples) and a small `batch_size` to verify data loading mechanics without processing the entire dataset. We will assert that the returned DataLoaders yield batches of the correct shape.
3.  **Model Initialization**: Instantiate the model using `library.model.create_model` with `pretrained=False` to avoid potential network latency or errors during this quick demonstration. We will verify the model's output shape with a dummy input.
4.  **Training Loop Execution**: Run a minimal training session using `library.engine.train_model` for 1 epoch on the subset data. This verifies the integration of the optimizer, loss calculation, backpropagation, and checkpoint saving mechanisms.
5.  **Inference & Submission**: Execute the inference pipeline using `library.inference.run_inference` on the test subset. We will verify that the submission file is generated correctly, follows the required format (headers `id,label`), and contains valid probability values.
6.  **Validation**: Throughout the script, assertions will be used to validate shapes, types, and file existence to ensure all components function as expected.
