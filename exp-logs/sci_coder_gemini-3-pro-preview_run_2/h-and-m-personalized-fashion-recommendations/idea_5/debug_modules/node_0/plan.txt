Implementation Strategy:
1.  **Setup & Configuration**: Import necessary modules and override configuration parameters (epochs, batch sizes, estimators) to ensure the script runs within the time limit. Set random seeds for reproducibility.
2.  **Data Loading & Subsetting**: Load the raw data using `data_loader`. To optimize speed, filter the dataset to include only the top 500 most active customers. This ensures the pipeline processes dense data quickly.
3.  **Time Splitting**: Split the subsetted data into a training set (history) and a validation set (ground truth) using `data_loader.get_time_split`.
4.  **Sequential Model Workflow**:
    *   Preprocess the training data into sequences.
    *   Train the SASRec model (1 epoch) using `sequential_encoder`.
    *   Extract user and item embeddings for downstream feature engineering.
5.  **Co-occurrence Model Workflow**:
    *   Explicitly instantiate and fit the `CooccurrenceMatrix` from `heuristics` on the training data. This will be passed to the feature builder later.
6.  **Candidate Generation**:
    *   Initialize the `CandidateOrchestrator`.
    *   Generate candidates for the validation customers based on their training history. This demonstrates the multi-source retrieval (Co-occurrence, Sequence, Repurchase, Popularity).
7.  **Feature Engineering**:
    *   Initialize the `FeatureBuilder`.
    *   Compute features for the generated candidates, injecting the pre-trained embeddings and the fitted co-occurrence matrix.
8.  **Ranking Workflow**:
    *   Split the feature-enriched candidates into a training set and a validation set for the ranker.
    *   Initialize the `LGBMRankerWrapper`.
    *   Train the LightGBM model with reduced estimators.
    *   Generate predictions for the validation subset.
9.  **Validation**:
    *   Calculate the MAP@12 score using `utils.calculate_map12` to verify the end-to-end pipeline performance on the subset.
    *   Assert output shapes and data integrity throughout the process.
