The proposed solution implements the "Hybrid Multi-Source Retrieval & Interaction-Aware Ranking" strategy using the provided library modules. It orchestrates the pipeline by loading data, creating a local training split for the ranker (to avoid data leakage and simulate the test scenario), generating candidates and features, training the LightGBM ranker, and evaluating the performance.

**Implementation Strategy:**

1.  **Data Loading**: Uses `DataManager` to load cached parquet files. This provides the main training history (`train`), the validation set (`val`), and metadata.
2.  **Ranker Data Preparation**:
    *   **Internal Split**: To train the ranker, we cannot simply use the provided `val` set (as that is for final evaluation). We create a "Ranker Train" set by slicing the last 7 days of the provided `train` data as a local target, and using the data prior to that as history.
    *   **Sampling**: To ensure the "Fast Baseline" requirement (running within 2 hours), we sample 50,000 active customers from this local target period for training the ranker.
    *   **Retrieval & Features**: We use `HybridRetrieval` and `FeatureEngineer` to generate labeled training examples for these sampled users.
3.  **Validation Data Preparation**:
    *   We process the *entire* provided `val` set to meet the requirement of evaluating on the full hold-out set.
    *   Candidates are generated using the full `train` history.
4.  **Modeling**:
    *   We train the `Ranker` (LightGBM) using the prepared training and validation feature sets.
    *   We predict on the validation set and compute the MAP@12 score using `Evaluator`.
5.  **Failure Analysis**:
    *   We calculate the Average Precision (AP) for each user in the validation set.
    *   We correlate this AP with user metadata (Age, Club Status, Activity) to identify performance drivers.
6.  **Submission**:
    *   If the validation MAP@12 exceeds the threshold (0.022018...), we retrain the retrieval/feature pipeline on the full dataset (Train + Val) and generate predictions for the `test` set.
