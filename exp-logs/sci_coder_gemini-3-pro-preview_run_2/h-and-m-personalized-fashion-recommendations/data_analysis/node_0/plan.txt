Implementation Strategy:
1.  **Setup & Data Loading**: Initialize the environment with fixed random seeds. Load the training data from `./metadata/train.parquet`, and auxiliary metadata from `./input/articles.csv` and `./input/customers.csv`.
2.  **Preprocessing**: Merge customer and article metadata onto the transaction training data. This creates a master DataFrame for analysis. Due to the large size, we will use appropriate data types to optimize memory.
3.  **Target Variable Analysis**: Treat `article_id` as the target class. Analyze the distribution of purchase frequencies to highlight the "long tail" nature of the data (Class Imbalance).
4.  **Tabular Data Analysis**:
    *   **Numerical**: Analyze `price` (from transactions) and `age` (from customers). Report statistics and outliers.
    *   **Categorical**: Analyze key categorical features like `sales_channel_id`, `index_group_name`, and `club_member_status`. Check for high cardinality and rare labels.
    *   **Missing Values**: Quantify missing data across the merged dataset.
5.  **Image Data Analysis**:
    *   Sample a subset of images (e.g., 2000) using the `image_path` column.
    *   Load images using `cv2` to analyze dimensions (Height, Width), Aspect Ratios, and Pixel Intensity (Mean/Std).
6.  **Feature/Signal Relationships**:
    *   **Structured**: Calculate correlations between numerical features (`age` vs `price`). Check for redundancy among article hierarchy codes (e.g., `product_type_no` vs `department_no`).
    *   **Importance**: Train a lightweight Random Forest Regressor. The task will be to predict the **log-popularity** (log of purchase count) of an article based on its metadata features (e.g., `product_group`, `colour_group`). This identifies which item attributes drive sales.
    *   **Unstructured**: Analyze if image metadata (e.g., Aspect Ratio) correlates with the target proxy (Article Popularity).
7.  **Output**: Print the findings in the specified format without interactive plots.
