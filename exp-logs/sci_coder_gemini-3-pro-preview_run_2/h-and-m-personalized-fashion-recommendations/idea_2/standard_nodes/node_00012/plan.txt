**Strategy:**

2.  **Enhance Feature Set**: I will replace the visual features with lightweight, high-signal statistical features:
    *   `user_mean_price`: Captures the user's spending power/tier.
    *   `item_age`: Captures the "freshness" of an item (days since first appearance), which is critical in fast fashion.
3.  **Optimize Retrieval Window**: Based on Lesson 00011 (Signal Density), I will slightly extend the retrieval window from 4 weeks to **5 weeks**. Combined with the existing linear time-decay, this ensures sufficient signal density for the co-occurrence matrix without introducing excessive noise from obsolete trends.
4.  **Update Threshold**: Set the submission threshold to the previous best validation score (0.0220) to ensure only superior models generate a submission.

        """
        Computes user visual profiles based on history.
        Profile = Mean of normalized embeddings of purchased items.

        user_groups = valid_history.groupby(USER_ID_COL)["emb_idx"].apply(list)

            vecs = emb_matrix[indices]
