The following script demonstrates the end-to-end pipeline using the provided library modules. It performs the following steps:

1.  **Setup & Configuration**: Initializes the environment, seeds, and overrides hyperparameters for a fast demonstration (1 epoch, reduced data subset).
2.  **Data Loading & Preprocessing**: Loads the metadata, creates a time-based split, and downsamples the data to the top 500 active users to ensure the script runs within minutes.
3.  **Graph Training (Source A)**: Prepares the bipartite graph from the training subset and trains the LightGCN model to generate user and item embeddings.
4.  **Retrieval (Source B & C)**: Builds the Co-occurrence matrix and orchestrates candidate generation (Graph + Co-occurrence + Repurchase + Popularity) for the validation users.
5.  **Feature Engineering**: Computes interaction-aware features (Sales Velocity, Department Affinity, Graph Dot Product) for the retrieved candidates.
6.  **Ranking**: Trains the LightGBM ranker on the validation candidates (using actual purchases as positive labels) and predicts scores for a test subset.
7.  **Submission**: Generates a sample submission file from the ranked predictions.

Validation assertions are included at key stages to verify data shapes, embedding integrity, and prediction formats.
