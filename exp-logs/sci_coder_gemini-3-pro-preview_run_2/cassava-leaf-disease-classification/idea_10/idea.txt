Based on the empirical lessons learned and the analysis of previous attempts, I propose the following optimized strategy. This approach structurally evolves the solution by integrating **Progressive Resolution Training** with **Regularization Annealing** within a fully executed **5-Fold Cross-Validation** framework.

# Model
I propose using the **ConvNeXt Small** architecture, initialized with pre-trained ImageNet-1k weights.
*   **Architecture**: We will utilize **ConvNeXt Small** (approx. 50M parameters). Previous experiments confirmed that this capacity is superior to the "Tiny" variant and ResNet baselines when trained to convergence **(Cite solution_lesson_node_00027)**.
*   **Weight Averaging**: We will implement **Model EMA (Exponential Moving Average)**. By maintaining a moving average of the model weights during training, we ensure stability when transitioning between resolution stages and find flatter minima in the loss landscape. We will ensure the training duration is sufficient to allow the EMA weights to converge, addressing the latency issue identified in short runs **(Cite solution_lesson_node_00030)**.
*   **Internal Regularization**: We will implement **Stochastic Depth (Drop Path)** with a rate of 0.4 to prevent co-adaptation of weights in this deeper network **(Cite solution_lesson_node_00011)**.

# Data
*   **Preprocessing**: We will strictly utilize **PIL (Python Imaging Library)** for image loading. This ensures native alignment with the augmentation pipeline and avoids the computational overhead and potential color-space errors associated with OpenCV conversions **(Cite solution_lesson_node_00010)**.
*   **Augmentation Pipeline**:
    1.  **Geometric**: **RandomResizedCrop** is mandatory. It forces the model to learn scale-invariant features and prevents memorization of global image patterns **(Cite solution_lesson_node_00013)**.
    2.  **Photometric**: **RandAugment** will be used for automated, diverse distortions **(Cite solution_lesson_node_00005)**.
    3.  **Mixing**: **MixUp and CutMix** will be applied dynamically based on the training phase (see Training).

# Training
*   **Strategy (Structural Innovation)**: We will implement **5-Fold Stratified Cross-Validation** with a **Progressive Resolution and Regularization Annealing Curriculum**. Unlike previous attempts that failed due to truncated epochs **(Cite solution_lesson_node_00022)**, we will leverage the 24-hour budget to train 5 independent models to full convergence.
    *   **Phase 1 (Coarse Learning)**: Train with input resolution **$224 \times 224$** for the first ~60% of epochs. Set MixUp/CutMix probability to **0.5**. This allows the model to learn robust global features while frequently seeing "clean" data to aid convergence, correcting the underfitting observed with p=1.0 **(Cite solution_lesson_node_00023)**.
    *   **Phase 2 (Fine-Tuning)**: Increase input resolution to **$384 \times 384$** for the remaining ~40% of epochs to resolve fine-grained disease artifacts **(Cite solution_lesson_node_00027)**. **Crucially, we will disable MixUp/CutMix (p=0.0) during this phase.** This "Regularization Annealing" removes interpolation noise, allowing the model to focus purely on refining high-frequency spatial details.
*   **Batch Size Management**: We will use **Gradient Accumulation** to maintain an effective **Batch Size of 32** during the high-resolution phase. This ensures we fit the model in GPU memory while retaining the beneficial gradient noise that aids generalization **(Cite solution_lesson_node_00008)**.
*   **Loss Function**: **Soft Target Cross-Entropy Loss** during Phase 1 (to handle mixed labels) and **Cross-Entropy with Label Smoothing (0.1)** during Phase 2 **(Cite solution_lesson_node_00006)**.
*   **Optimizer**: **AdamW** with a **Cosine Annealing** scheduler **(Cite solution_lesson_node_00005)**.

# Evaluation
*   **Ensemble Inference**: The final submission will be generated by averaging the softmax probabilities from the **EMA weights** of all **5 Fold Models**. This ensures maximum robustness against dataset noise and prevents the "stale artifact" issue by ensuring a clean execution scope for each fold **(Cite solution_lesson_node_00028)**.
*   **Test Time Augmentation (TTA)**: We will average predictions from the original and a horizontally flipped view for each image to leverage orientation invariance **(Cite solution_lesson_node_00013)**.
