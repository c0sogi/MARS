The issue is that `albumentations` version 2.0.8 introduced a breaking API change where transforms like `RandomResizedCrop`, `Resize`, and `CenterCrop` now require a single `size` argument (passed as a tuple `(height, width)`) instead of separate `height` and `width` arguments. The fix involves updating the `get_transforms` function in `library/dataset.py` to replace the deprecated arguments with the new `size` parameter syntax.
