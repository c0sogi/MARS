The issue is caused by using the incorrect argument `size` for `albumentations.Resize` and `albumentations.CenterCrop` in `library/dataset.py`. As identified in the error analysis and `debug_lesson_4`, while some transforms like `RandomResizedCrop` updated to use a `size` parameter in `albumentations` 2.0, `Resize` and `CenterCrop` still require separate `height` and `width` arguments. The fix is to replace the `size` tuple with explicit `height` and `width` parameters in the validation and fallback transform pipelines.
