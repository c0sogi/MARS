The following is a complete Python script demonstrating the usage of the provided Cassava Leaf Disease Classification library.

### Implementation Strategy
1.  **Environment Setup**: Import necessary system libraries and the provided modules from the `library` package.
2.  **Configuration Override**: Modify the `Config` class to use a temporary working directory and enable `debug` mode. This limits the dataset size (e.g., 32 samples) and epochs (1) to ensure the script completes quickly.
3.  **Data Preparation**: Generate a small subset of the test metadata (16 samples) so that the inference step runs almost instantly.
4.  **Component Verification**:
    *   **Utils**: validate `AverageMeter` aggregation and `accuracy` calculation logic.
    *   **Data**: Validate `CassavaDataset` integration, image transformations, and `DataLoader` batch dimensions.
    *   **Model**: Validate `CassavaNet` instantiation and output shapes using dummy tensors.
5.  **Workflow Execution**:
    *   **Training**: Run `train_fold` for 2 folds. This tests the training loop, loss calculation, backpropagation, and checkpoint saving.
    *   **Inference**: Run `ensemble_inference` using the generated checkpoints. This tests model loading, TTA (Test Time Augmentation), and submission file generation.
6.  **Validation**: Assertions are used throughout to confirm that files are created and shapes are correct.
