Implementation Strategy:
1.  **Configuration & Setup**: Initialize the environment with fixed seeds for reproducibility. Override the default epoch counts in `Config` to `P1_EPOCHS=6` and `P2_EPOCHS=4` to ensure the 5-fold training completes well within the 2-hour limit on the A100 GPU, while maintaining sufficient convergence for high accuracy.
2.  **5-Fold Stratified Training**: Implement a loop over 5 folds.
    *   **Phase 1 (Coarse)**: Initialize the model and `ModelEMA`. Train on 224x224 images with MixUp (p=0.5) to learn robust global features.
    *   **Phase Reset**: Synchronize the EMA model weights with the current training weights to eliminate lag before fine-tuning.
    *   **Phase 2 (Fine)**: Re-initialize the optimizer and scheduler. Train on 384x384 images with MixUp disabled and Label Smoothing enabled to refine high-frequency details. Save the best checkpoint based on validation accuracy.
3.  **Validation & Failure Analysis**:
    *   Perform inference on the validation set of each fold using the best EMA model.
    *   Aggregate predictions to compute the global `Final Validation Metric`.
    *   Calculate the correlation between prediction error magnitude and image file size to identify systematic failures related to image complexity.
4.  **Submission**:
    *   Check if the validation metric exceeds the threshold (0.9076).
    *   If passed, load the best models from all 5 folds.
    *   Perform Test Time Augmentation (TTA) inference on the test set.
    *   Average the predictions and generate the `submission.csv`.
