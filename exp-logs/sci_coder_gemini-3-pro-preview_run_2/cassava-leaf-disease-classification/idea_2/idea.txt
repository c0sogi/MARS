Based on the empirical lessons learned, I propose the following optimized strategy. This approach structurally evolves the solution from a standard ResNet baseline to a modern **ConvNeXt** architecture, while retaining the successful regularization and data pipeline components identified in previous experiments.

# Model
I propose replacing the ResNet architecture with **ConvNeXt-Tiny**, initialized with pre-trained ImageNet weights via the `timm` library.
*   **Structural Innovation**: ConvNeXt represents a fundamental architectural shift from the standard ResNet used previously. While maintaining a similar computational footprint, it modernizes the Convolutional Neural Network (CNN) design by incorporating "Vision Transformer" principles—such as larger kernel sizes ($7\times7$), inverted bottleneck layers, and fewer activation functions. This addresses the need for high model capacity identified in **Cite solution_lesson_node_00012** (where ResNet50 significantly outperformed ResNet18) but utilizes a more efficient and representationally powerful feature extractor.
*   **Weights**: We will utilize the most recent pre-trained weights available in `timm`, aligning with the finding that modern weight initializations (like ImageNet V2) significantly boost performance **(Cite solution_lesson_node_00006)**.

# Data
*   **Preprocessing**: We will strictly adhere to the **PIL-based** loading pipeline. Images will be loaded directly using `Image.open()` to ensure native alignment with the augmentation library, avoiding the overhead and potential color-space mismatches of OpenCV conversions **(Cite solution_lesson_node_00010)**.
*   **Augmentation**: We will retain **RandAugment** as the primary augmentation strategy. Previous experiments demonstrated that this automated policy converges faster and generalizes better than manually tuned pipelines **(Cite solution_lesson_node_00005)**.

# Training
*   **Regularization**: We will apply **Label Smoothing (0.1)** to the Cross-Entropy Loss. This has been proven to prevent the model from becoming overconfident on noisy labels, a critical factor in achieving the best performance so far **(Cite solution_lesson_node_00006)**.
*   **Batch Size**: We will use a **Batch Size of 32**. This smaller batch size acts as an implicit regularizer by introducing gradient noise, which helps the model escape sharp minima and generalize better than larger batch sizes on this dataset **(Cite solution_lesson_node_00008)**.
*   **Optimizer & Scheduler**: We will use the **AdamW** optimizer (standard for ConvNeXt) combined with the **Cosine Annealing** scheduler, which was shown to facilitate rapid and stable convergence **(Cite solution_lesson_node_00005)**.

# Evaluation
*   **Inference Strategy**: We will introduce **Test Time Augmentation (TTA)**. Instead of a single forward pass, the model will predict on both the original image and a horizontally flipped version. The logits from these views will be averaged before applying the Argmax operation. This structural change to the inference pipeline exploits the model's learned invariance to orientation, further boosting robustness without retraining.
