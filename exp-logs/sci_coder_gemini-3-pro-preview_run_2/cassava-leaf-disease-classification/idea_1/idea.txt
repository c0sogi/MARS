To establish a reliable and highly efficient baseline, I propose using the **ResNet-18** architecture. This approach prioritizes simplicity and training speed, serving as a standard benchmark against which more complex models can be compared.

### Model
We will utilize the **ResNet-18** architecture, a lightweight Convolutional Neural Network (CNN) characterized by its use of residual blocks with skip connections. Unlike the EfficientNetV2 (Model 1) which relies on complex compound scaling and depthwise separable convolutions, ResNet-18 uses standard $3\times3$ convolutions and is significantly shallower, making it faster to train and less prone to overfitting on smaller datasets without heavy regularization.
- **Initialization**: The model will be initialized with weights pre-trained on ImageNet to leverage learned low-level features (edges, textures).
- **Adaptation**: The final fully connected layer (originally 1000 classes) will be replaced with a new linear layer projecting to the 5 target classes (4 diseases + 1 healthy).

### Data
To ensure high throughput and minimal preprocessing overhead:
- **Preprocessing**: All images will be resized to a standard resolution of $224\times224$ pixels. Pixel values will be normalized using the standard ImageNet mean and standard deviation.
- **Augmentation**: We will employ only **Random Horizontal Flips** during training. This satisfies the requirement to exclude heavy augmentations while providing just enough invariance to orientation to prevent trivial overfitting.
- **Validation/Test**: Images will be resized directly to $224\times224$ (without cropping) and normalized.

### Training
The training process will focus on speed and stability:
- **Loss Function**: We will use standard **Cross-Entropy Loss**. While the dataset is imbalanced, this standard loss serves as the most neutral baseline.
- **Optimizer**: We will use the **Adam** optimizer, which generally converges faster than SGD without requiring extensive hyperparameter tuning for learning rate schedules.
- **Strategy**: We will perform **end-to-end fine-tuning** of the model for a small number of epochs (e.g., 5-10). This differs from Model 3 (which freezes the backbone) by allowing the feature extractor to adjust slightly to the specific visual characteristics of cassava leaves.

### Evaluation
For the inference phase:
- The test images will be loaded, resized to $224\times224$, and normalized using the same statistics as the training set.
- The model will output raw logits for each image.
- We will apply an **Argmax** operation to the logits to select the class index with the highest probability as the final prediction.
- These predictions will be mapped to the submission format (`image_id`, `label`).
