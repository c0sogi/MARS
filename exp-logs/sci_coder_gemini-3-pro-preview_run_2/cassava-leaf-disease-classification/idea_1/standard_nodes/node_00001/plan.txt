The implementation strategy involves the following steps:

1.  **Initialization**: Set up the environment using the provided `Config` class and ensure reproducibility with `seed_everything`. We will slightly reduce the number of epochs to 5 to guarantee the "fast baseline" requirement is met while still allowing sufficient convergence for ResNet-18 on this dataset.
2.  **Training**: Utilize the `train_model` function from the `library.engine` module. This handles the training loop, validation monitoring, and saving the best model checkpoint.
3.  **Validation Assessment**:
    *   Reload the validation data using `get_dataloaders` and `pd.read_csv`.
    *   Perform a dedicated inference pass on the validation set to gather predictions and probabilities.
    *   Calculate the categorization accuracy and print it in the specific format `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the "error magnitude" for each validation sample, defined as $1.0 - P(\text{true\_class})$.
    *   Extract the `file_size` for each validation image as the primary input feature (since dimensions are constant).
    *   Calculate and print the Pearson correlation between the error magnitude and the file size to identify if image complexity/quality affects performance.
5.  **Submission**: Call the `predict` function from `library.engine`, which loads the best saved model, performs inference on the test set, and generates the `submission.csv` file in the required format.
