Here is the implementation strategy and the complete Python script for the EDA task.

### Implementation Strategy
1.  **Setup and Configuration**: Initialize the environment, set random seeds for reproducibility, and define paths. Load the generated training metadata (`./metadata/train.csv`) and the disease map JSON.
2.  **Target Variable Analysis**: Analyze the `label` column to report class distributions and check for imbalance. Map numeric labels to disease names for context.
3.  **Image Data Analysis**:
    *   **Dimensions & Properties**: Use parallel processing (`ThreadPoolExecutor`) to efficiently extract image dimensions (width, height), aspect ratios, and file sizes from the entire training set without fully decoding pixel data where possible (using `PIL`).
    *   **Pixel Statistics**: Perform a computationally efficient analysis by sampling a subset of images (e.g., 1000 samples). Calculate global channel-wise mean and standard deviation to inform normalization strategies.
4.  **Meta-Feature Relationships**: Investigate correlations between image properties (file size, dimensions) and the target labels to see if specific diseases are associated with image quality or size artifacts.
5.  **Reporting**: Output the findings in the specified format, ensuring all floating-point numbers are formatted to 4 decimal places.
