I will implement the orchestration script `runfile.py` to execute the **Calibrated Progressive Resolution Curriculum** strategy. 1.  **Data Loading**: Combine metadata and create stratified folds.
2.  **Phase 1 Training**: Train on 224x224 images using MixUp and Soft Target Cross-Entropy.
3.  **Phase Reset**: Synchronize EMA weights with the model to prevent feature lag.
4.  **Phase 2 Training**: Fine-tune on 384x384 images using Label Smoothing Cross-Entropy without MixUp.
5.  **Validation**: Evaluate the best EMA model for each fold and aggregate Out-Of-Fold (OOF) predictions.
6.  **Analysis**: Calculate the global validation accuracy and analyze failure patterns by correlating errors with class labels.
7.  **Submission**: Generate predictions on the test set if the validation accuracy exceeds 0.9076.
