Based on the accumulated lessons, I propose the following **Marginalized Depth-Scan Ensemble (MDSE)** strategy.

This solution resolves the central "Depth Paradox" identified in the experiments: **Depth information is critical for performance (Cite solution_lesson_node_00001)**, yet **depth metadata is missing for the test set (Cite solution_lesson_node_00020)**.

Previous attempts to bridge this gap failed because:
1.  **Regression** lacks sufficient local signal (Cite solution_lesson_node_00022).
2.  **Distillation** fails because the image-only student faces an information bottleneck (Cite solution_lesson_node_00032).
3.  **Zero-Masking** creates contradictory training signals (Cite solution_lesson_node_00051).

My proposed structural innovation is **Marginalized Inference**. Instead of trying to impute a single depth or train a weaker depth-blind student, we deploy the high-performance "Specialist" model and treat the missing test depth as a **latent variable**. By integrating predictions across a spectrum of plausible depths (Marginalization), we recover the signal for structures that are visually consistent across the depth manifold, effectively bypassing the missing metadata problem without compromising model capacity.

### Model: ResNet34-WideLinkNet with Depth Concatenation

I propose a specialized U-shape architecture optimized for information flow and conditional execution.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed (Cite solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** by summing the original RGB weights. This preserves pretrained feature detectors without the redundancy of data repetition (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Optimization):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map is passed to the decoder to preserve maximum semantic information (Cite solution_lesson_node_00019).
    *   **Depth Injection:** The scalar depth $z$ is projected through a **Non-Linear MLP** (Linear $\rightarrow$ ReLU $\rightarrow$ Linear) to a 32-channel embedding (Cite solution_lesson_node_00029). This embedding is **concatenated** with the encoder features. Concatenation is chosen over FiLM or Residual Injection because it forces the model to utilize the signal and is robust to initialization (Cite solution_lesson_node_00037, solution_lesson_node_00041).
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** for efficiency (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` rather than `out_channels // 4`. This prevents the aggressive semantic information loss observed in standard implementations (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding. This ensures dimensions are multiples of the network's stride (32), preventing spatial aliasing (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std). Even with the 1-channel modification, scaling to the pretrained distribution is critical (Cite solution_lesson_node_00025).
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the training depth values (Cite solution_lesson_node_00010).
    *   **Cache Safety:** Explicitly validate dataset configuration to prevent loading stale caches (Cite solution_lesson_node_00056).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate organic salt plasticity. This is mandatory for performance (Cite solution_lesson_node_00055). Apply with moderate probability ($p=0.2$) to avoid domain shift (Cite solution_lesson_node_00073).
    *   **Rigid:** Apply conservative **ShiftScaleRotate** ($p=0.2$) for geometric invariance (Cite solution_lesson_node_00054).

### Training: 5-Fold Specialist Ensemble

I propose a robust supervised training pipeline focused on maximizing the "Specialist" capability of the model.

*   **Strategy:** **5-Fold Cross-Validation**. This provides a reliable estimate of generalization and allows for ensemble averaging (Cite solution_lesson_node_00079).
*   **Depth Jitter:** During training, add small **Gaussian Noise** ($\sigma=0.1$) to the normalized depth input. This acts as a regularizer, smoothing the model's decision boundary with respect to depth and ensuring the subsequent marginalization scan is effective. It avoids the pitfalls of "Zero Masking" (Cite solution_lesson_node_00051) by preserving the local correlation between depth and texture.
*   **Loss Function:** Sum of **Lovasz-Hinge** (calculated per-image) and **BCE**. Summing maintains gradient magnitude (Cite solution_lesson_node_00036), and per-image aggregation prevents outlier dominance (Cite solution_lesson_node_00044).
*   **Optimizer:** **AdamW** with a conservative learning rate of **1e-4** and weight decay of **1e-2** (Cite solution_lesson_node_00022).
*   **Scheduler:** **Cosine Annealing** ($T_{max}=50$) to ensure convergence into a broad minimum (Cite solution_lesson_node_00068).
*   **Horizon:** Train for **50 epochs** to ensure full convergence (Cite solution_lesson_node_00006).

### Evaluation: Marginalized Depth-Scan Inference

I propose a novel inference strategy to handle the missing test metadata.

*   **Quality Gating:** Before inference, evaluate each fold model. Discard any model with validation mAP < 0.75 to prevent collapsed models from polluting the ensemble (Cite solution_lesson_node_00067).
*   **Marginalization Process:**
    1.  Define a set of candidate depths $Z_{scan}$ (e.g., 10 values linearly spaced from -2.0 to +2.0 standard deviations).
    2.  For each test image $x$, run the valid ensemble models for *every* $z \in Z_{scan}$.
    3.  **Average** the resulting probability maps. This computes $\mathbb{E}[y|x] = \int p(y|x,z)p(z)dz$, effectively integrating out the unknown depth variable. Structures that are consistently detected across plausible depths will be reinforced, while depth-specific noise will be suppressed.
*   **Test-Time Augmentation (TTA):** Combine Depth-Scan with Horizontal Flip TTA (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set (OOF) predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
