The issue stems from a shape mismatch between the model predictions and the ground truth masks. The dataset loads masks in HWC format `(H, W, 1)`, and `albumentations.pytorch.ToTensorV2` preserves this format by default for masks, resulting in a batch shape of `(Batch, H, W, 1)`. However, the PyTorch model outputs predictions in NCHW format `(Batch, 1, H, W)`, causing a `ValueError` in the loss function. To resolve this, I will update `ToTensorV2` in `library/dataset.py` with `transpose_mask=True` to ensure masks are transposed to CHW format (Cite debug_lesson_4).
