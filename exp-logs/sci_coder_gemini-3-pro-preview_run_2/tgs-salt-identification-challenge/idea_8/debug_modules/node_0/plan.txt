### Implementation Strategy

1.  **Environment Setup**: We import necessary libraries and the provided modules (`library.*`). We set the random seed for reproducibility.
2.  **Data Preparation (Optimization)**: To ensure the script runs quickly (within the time limit), we create "mini" versions of the metadata CSV files (train, val, test) containing only a small subset of the data (e.g., 32 samples). This avoids loading and processing the entire dataset.
3.  **Utility Verification**: We demonstrate and verify the correctness of the `rle_encode`, `rle_decode`, and `metric_map` functions using synthetic data.
4.  **Dataset & DataLoader**: We instantiate the `SaltDataset` class using the mini metadata files. We verify that the data loader yields batches of the correct shape (Images: `B, 3, 128, 128`, Masks: `B, 1, 128, 128`, Depths: `B, 1`).
5.  **Model Initialization**: We instantiate the `DepthRegularizedWideLinkNet` and move it to the configured device (GPU/CPU). We perform a dummy forward pass to confirm the output shape matches the input resolution.
6.  **Loss Function**: We initialize `MixedLoss` (BCE + Lovasz) and verify it computes a scalar loss value on the dummy output.
7.  **Training & Validation Loop**: We execute a single epoch of training using `train_one_epoch` and a validation pass using `validate`. We assert that the loss decreases or is valid and that an optimal threshold is found.
8.  **Inference**: We run the `predict_test` function on the mini test set to generate a submission file and verify its format.
