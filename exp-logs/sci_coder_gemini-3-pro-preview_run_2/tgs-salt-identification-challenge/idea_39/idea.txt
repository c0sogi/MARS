Based on the comprehensive analysis of the accumulated lessons, I propose the following **FP32-Stabilized Multi-Task Specialist with Marginalized Depth-Scan** strategy.

This solution resolves the central "Depth Paradox": **Depth information is critical for performance (Cite solution_lesson_node_00001)**, yet **depth metadata is missing for the test set (Cite solution_lesson_node_00020)**.

Previous attempts failed due to:
1.  **Regression Inaccuracy:** Image-to-depth regression lacks sufficient precision to replace explicit injection (Cite solution_lesson_node_00022).
2.  **Information Bottleneck:** Distillation to an image-only student fails because the student cannot infer depth-dependent rules (Cite solution_lesson_node_00032).
3.  **Instability:** Mixed Precision (AMP) causes failure with ranking losses (Cite solution_lesson_node_00097).
4.  **Implementation Bugs:** Previous multi-task attempts failed due to "silent disconnection" of the auxiliary head (Cite solution_lesson_node_00062).

My proposed structural innovation is **Marginalized Inference** supported by **Multi-Task Regularization**. We train a "Specialist" model that uses explicit depth injection *and* an auxiliary depth prediction head (to align features). At inference, since test depth is unknown, we treat it as a latent variable and "scan" the model across a spectrum of plausible depths, averaging the predictions. This recovers the signal for structures that are visually consistent across the depth manifold. The entire pipeline is stabilized using **Strict FP32** to prevent Lovasz loss divergence.

### Model: Multi-Task ResNet34-WideLinkNet

I propose a specialized U-shape architecture optimized for information flow and conditional execution.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed (Cite solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** by summing the original RGB weights. This preserves pretrained feature detectors without the redundancy of data repetition (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Optimization):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map is passed to the decoder (Cite solution_lesson_node_00019).
    *   **Depth Injection:** The scalar depth $z$ is projected through a **Non-Linear MLP** (Linear $\rightarrow$ ReLU $\rightarrow$ Linear) to a 32-channel embedding (Cite solution_lesson_node_00029). This embedding is **concatenated** with the encoder features (Cite solution_lesson_node_00041).
    *   **Corrected Auxiliary Head:** A regression head (GlobalAvgPool $\rightarrow$ MLP $\rightarrow$ Scalar) is attached to the bottleneck. Crucially, I will implement a runtime check to ensure this head is **connected** to the loss function (Cite solution_lesson_node_00062). This forces the encoder to extract depth-correlated texture features, which enhances the effectiveness of the depth scan during inference.
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` rather than `out_channels // 4`. This prevents the aggressive semantic information loss observed in standard implementations (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding to ensure divisibility by 32 (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std) (Cite solution_lesson_node_00025). Apply **Standard Scaling** to depth values (Cite solution_lesson_node_00010).
    *   **Cache Safety:** Explicitly validate dataset configuration to prevent loading stale caches (Cite solution_lesson_node_00056).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) and `alpha_affine` (Cite solution_lesson_node_00095). This is mandatory for performance (Cite solution_lesson_node_00055). Apply with moderate probability ($p=0.2$) to avoid domain shift (Cite solution_lesson_node_00073).
    *   **Rigid:** Apply conservative **ShiftScaleRotate** ($p=0.2$) for geometric invariance (Cite solution_lesson_node_00054).

### Training: FP32-Stabilized Specialist Ensemble

I propose a robust supervised training pipeline focused on maximizing the "Specialist" capability of the model.

*   **Strategy:** **5-Fold Cross-Validation**. This provides a reliable estimate of generalization and allows for ensemble averaging (Cite solution_lesson_node_00079).
*   **Precision:** **Strictly use FP32**. Do not use Mixed Precision (AMP). The Lovasz Hinge loss relies on sorting and cumulative sums, which are unstable in FP16 and caused previous attempts to fail (Cite solution_lesson_node_00097).
*   **Depth Fidelity:** Train using **Exact True Depths**. Do not apply Jitter or Zero-Masking. We need the model to learn the precise correlation between depth and texture to maximize the effectiveness of the subsequent marginalization scan (Cite solution_lesson_node_00051, solution_lesson_node_00094).
*   **Loss Function:** Sum of **Lovasz-Hinge** (calculated per-image) and **BCE** + **0.1 * MSE** (Auxiliary). Summing maintains gradient magnitude (Cite solution_lesson_node_00036), and per-image aggregation prevents outlier dominance (Cite solution_lesson_node_00044).
*   **Optimizer:** **AdamW** with a conservative learning rate of **1e-4** and weight decay of **1e-2** (Cite solution_lesson_node_00022).
*   **Scheduler:** **Cosine Annealing** ($T_{max}=50$) (Cite solution_lesson_node_00068).
*   **Horizon:** Train for **50 epochs** to ensure full convergence (Cite solution_lesson_node_00006).

### Evaluation: Marginalized Depth-Scan Inference

I propose a novel inference strategy to handle the missing test metadata.

*   **Quality Gating:** Before inference, evaluate each fold model. Discard any model with validation mAP < 0.75 to prevent collapsed models from polluting the ensemble (Cite solution_lesson_node_00067).
*   **Marginalization Process:**
    1.  Define a set of candidate depths $Z_{scan}$ representing the training distribution (e.g., $\{-1.5, -0.75, 0, 0.75, 1.5\}$ standard deviations).
    2.  For each test image $x$, run the valid ensemble models for *every* $z \in Z_{scan}$.
    3.  **Average** the resulting probability maps. This computes the expected mask $\mathbb{E}[y|x] = \int p(y|x,z)p(z)dz$, effectively integrating out the unknown depth variable.
*   **Test-Time Augmentation (TTA):** Combine Depth-Scan with Horizontal Flip TTA (Cite solution_lesson_node_00095).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set (OOF) predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
