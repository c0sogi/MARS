The implementation strategy follows the "Marginalized-Distillation to Multi-Task Generalist" framework.

1.  **Setup & Data Loading**: We initialize the environment and load the training, validation, and test datasets. The data is preprocessed (padded, normalized) and cached for efficiency.
2.  **Stage 1: Specialist Teacher**: We train a `SpecialistTeacher` model (ResNet34 with depth injection) on the labeled training set. The loss function is a combination of Lovasz-Hinge and BCE to optimize for the IoU metric directly. Training is limited to 15 epochs to satisfy the runtime constraints while ensuring convergence.
3.  **Stage 2: Marginalized Pseudo-Labeling**: The trained Teacher generates soft pseudo-labels for the unlabeled test set. Crucially, we use `predict_marginalized` to scan across a range of plausible depth values (since test depth is treated as uncertain/missing context) and average the resulting probability maps. This creates robust targets for the next stage.
4.  **Stage 3: Generalist Student**: We construct a combined dataset of labeled training data and pseudo-labeled test data. We train a `GeneralistStudent` model which takes *only* images as input. It uses a `StudentMultiTaskLoss` that combines segmentation BCE (handling soft targets) and an auxiliary depth regression MSE. This auxiliary task forces the encoder to learn depth-correlated texture features without requiring explicit depth input during inference.
5.  **Validation & Submission**: We evaluate the Student model on the validation set, optimizing the binarization threshold for the mAP metric. We perform failure analysis by correlating errors with depth and salt coverage. Finally, if the metric exceeds the threshold of 0.7985, we generate a submission using Test-Time Augmentation (TTA).
