Based on the comprehensive analysis of the accumulated lessons, I propose the following **Robust Soft-Self-Training Wide-LinkNet** strategy.

This solution synthesizes the conflicting findings regarding depth utilization: while depth injection is critical for performance (Cite solution_lesson_node_00001), the metadata is missing at test time (Cite solution_lesson_node_00020). Previous attempts to bridge this gap via regression (Cite solution_lesson_node_00022) or naive hard pseudo-labeling (Cite solution_lesson_node_00049) failed due to weak signals or gradient instability.

My proposed structural innovation is a **Stabilized Two-Stage Soft-Self-Training Pipeline**. This approach combines **Bernoulli Depth Masking** (to learn a robust fallback for missing depth) with **Soft-Target Distillation** (to prevent divergence during pseudo-labeling). This allows the model to safely adapt to the test distribution without requiring the missing metadata.

### Model: ResNet34-WideLinkNet with MLP-Concatenation

I propose a specialized U-shape architecture optimized for information flow and robust conditional execution.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed for this dataset size (Cite solution_lesson_node_00002, solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** by summing the original RGB weights. This preserves pretrained feature detectors without the redundancy and inefficiency of repeating input data (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Optimization):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map from the encoder is passed to the decoder to preserve maximum semantic information (Cite solution_lesson_node_00019).
    *   **Depth Injection:** The scalar depth $z$ is projected through a **Non-Linear MLP** (Linear $\rightarrow$ ReLU $\rightarrow$ Linear) to a 32-channel embedding (Cite solution_lesson_node_00029). This embedding is **concatenated** with the encoder features. Concatenation is chosen over FiLM or Residual Injection because it forces the model to utilize the signal and is robust to initialization (Cite solution_lesson_node_00037, solution_lesson_node_00041).
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** for efficiency (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` rather than `out_channels // 4`. This prevents the aggressive semantic information loss observed in standard implementations (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding. This ensures dimensions are multiples of the network's stride (32), preventing spatial aliasing (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std). Even with the 1-channel modification, scaling to the pretrained distribution is critical for transfer learning (Cite solution_lesson_node_00025).
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the training depth values (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate organic salt plasticity (Cite solution_lesson_node_00003, solution_lesson_node_00055).
    *   **Rigid:** Apply **ShiftScaleRotate** to ensure geometric invariance (Cite solution_lesson_node_00010).
    *   **Regularization:** Apply these augmentations with a moderate probability ($p=0.2$) (Cite solution_lesson_node_00007).

### Training: Stabilized Two-Stage Soft-Self-Training

I propose a multi-stage training process designed to bridge the metadata gap while maintaining stability.

*   **Technique 1: Bernoulli Depth Masking.** During training, with probability $p=0.5$, replace the normalized depth input $z$ with the **dataset mean (0)**. This forces the model to learn a dual representation: a "Specialist" mode that uses depth to refine boundaries, and a "Generalist" mode that relies solely on visual texture when depth is missing.
*   **Technique 2: Per-Image Loss Aggregation.** To fix the divergence issue seen in previous self-training attempts (Cite solution_lesson_node_00044), the loss function must calculate error **per image** and average across the batch, rather than flattening the batch.

**Pipeline:**
1.  **Stage 1: Teacher Training (Supervised)**
    *   Train the model on the labeled training set using Bernoulli Depth Masking.
    *   **Loss:** Sum of **Lovasz-Hinge** (per-image) and **BCE**. Summing maintains gradient magnitude (Cite solution_lesson_node_00036).
    *   **Horizon:** Train for **50 epochs** to ensure full convergence (Cite solution_lesson_node_00045).

2.  **Stage 2: Soft-Distillation & Retraining**
    *   **Inference:** Use the Stage 1 Teacher to predict **Soft Probability Maps** for the **unlabeled test set**. Input a **constant depth of 0** for all test images. The Bernoulli Masking in Stage 1 ensures the Teacher handles this gracefully.
    *   **Retraining:** Train a new Student model (same architecture) from scratch on the combined dataset.
        *   **Labeled Data:** Use True Depth (with Bernoulli Masking). Target: GT Masks. Loss: Lovasz+BCE.
        *   **Unlabeled Data:** Use Fixed Depth 0. Target: **Soft Pseudo-Labels**. Loss: **BCE** (Soft Targets).
    *   **Rationale:** Using soft labels prevents the confirmation bias and divergence risks of hard thresholding (Cite solution_lesson_node_00049), while allowing the model to adapt to the specific visual structure of the test set.

### Evaluation

*   **Inference:**
    *   Use the **Stage 2 Student Model**.
    *   **Depth Handling:** Input a **constant depth value of 0** for all test images.
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
