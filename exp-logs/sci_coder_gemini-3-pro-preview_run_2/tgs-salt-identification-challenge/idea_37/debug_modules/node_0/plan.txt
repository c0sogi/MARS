### Implementation Strategy

1.  **Environment Setup**: Set the random seed for reproducibility using the provided `library.utils.set_seed`. Define constants for a "Debug Mode" (small batch size, limited dataset size) to ensure the script runs quickly.
2.  **Utility Verification**:
    *   Validate `pad_image` and `unpad_image` by transforming a dummy array and asserting the original shape and values are restored.
    *   Validate `rle_encode` and `rle_decode` by encoding a known binary mask and ensuring the decoded version matches the original.
    *   Validate `calc_iou_batch` and `calc_map` with synthetic prediction and ground truth tensors.
3.  **Dataset Verification**:
    *   Instantiate `SaltDataset` in 'train' mode with a small `debug_size`.
    *   Iterate through a batch to verify tensor shapes (Image: `[1, 128, 128]`, Mask: `[1, 128, 128]`, Depth: `[1]`) and data types.
4.  **Model & Loss Verification**:
    *   Instantiate `SaltNet` in 'teacher' mode. Pass a dummy batch (image + depth) and verify the output shape matches the segmentation target.
    *   Instantiate `SaltNet` in 'student' mode. Pass a dummy batch (image only) and verify it returns both segmentation logits and auxiliary depth predictions.
    *   Compute losses using `TeacherComboLoss` and `DepthMSELoss` to ensure the forward passes are numerically stable.
5.  **Engine & Workflow Verification**:
    *   **Teacher Training**: Initialize `SaltEngine` with the teacher model. Run `train_one_epoch` on a small subset to verify the training loop and backpropagation.
    *   **Marginalized Inference**: Use `SaltEngine.predict_marginalized` on a sample image to verify the depth-scanning logic used for pseudo-label generation.
    *   **Student Training**: Initialize `SaltEngine` with the student model. Run `train_one_epoch` to verify the multi-task loss calculation (Segmentation + Aux Depth).
    *   **Submission**: Run `generate_submission_csv` on a small test subset to verify the inference, TTA (Test-Time Augmentation), and RLE formatting pipeline.
