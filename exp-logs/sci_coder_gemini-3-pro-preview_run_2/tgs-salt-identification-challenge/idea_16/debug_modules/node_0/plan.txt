### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by setting random seeds for reproducibility and defining working directories.
2.  **Utility Verification**: Validate the correctness of the Run-Length Encoding (RLE) logic (`rle_encode`, `rle_decode`) and metric calculations (`calculate_iou_batch`) using synthetic data.
3.  **Data Preparation**: Create a small subset of the training and validation metadata (e.g., 16 samples) to ensure the training loop executes quickly.
4.  **Dataset Instantiation**: Initialize the `SaltDataset` with the subset metadata. Verify that the data loading, augmentation (padding to 128x128), and depth normalization logic work as expected.
5.  **Model Initialization**: Instantiate the `ResNet34WideLinkNet` model and the `CombinedLoss` function. Perform a dummy forward pass to verify input/output shapes (expecting 128x128 outputs from the model).
6.  **Training Loop Execution**: Run the `train_model` function for a single epoch with a small batch size. This demonstrates the integration of the engine, model, and data loaders.
7.  **Inference & Submission**: Use the trained model to generate predictions via `predict_with_tta` (Test-Time Augmentation) and format the results into a submission CSV using `generate_submission`.
8.  **Cleanup**: Ensure all outputs are directed to the `./working` directory.
