The following is the implementation of the `runfile.py` script. It orchestrates the Marginalized-Distillation Multi-Task Wide-LinkNet strategy, including training the specialist teacher ensemble, generating marginalized pseudo-labels, training the generalist student, and performing validation and submission generation.

**Strategy Outline:**
1.  **Setup**: Initialize environment, seeds, and override configuration for a fast but effective run (15 epochs).
2.  **Stage 1 (Teacher)**: Train a 5-fold ensemble of Depth-Injected Specialist Teachers on the training set. Each teacher learns to predict salt masks conditioned on depth.
3.  **Stage 2 (Distillation)**: Use the teacher ensemble to generate soft pseudo-labels for the unlabeled test set. This utilizes the **Marginalized Depth-Scan** technique to integrate predictions across a range of latent depths, robustifying the targets against depth uncertainty.
4.  **Stage 3 (Student)**: Train a single Generalist Student model on the combined dataset (Labeled Train + Pseudo-Labeled Test). The student employs a **Multi-Task** architecture with an auxiliary depth regression head to force texture-depth feature correlation.
5.  **Validation**: Evaluate the student on the hold-out validation set. Optimize the binarization threshold to maximize the mAP metric.
6.  **Analysis**: Compute the correlation between prediction error and depth to diagnose systematic failures.
7.  **Submission**: If the validation metric exceeds the threshold (0.7985), generate the submission file using Test-Time Augmentation (TTA).
