Implementation strategy:
1.  **Environment Setup**: Import necessary libraries and functions from the provided `library` modules. Set random seeds for reproducibility.
2.  **Training**: Execute the `run_training` function from `library.train`. This will train the `DepthConditionedUNetPlusPlus` model for 50 epochs using the pre-configured parameters and save the best model to `./working/idea_2/best_model.pth`.
3.  **Validation**:
    *   Load the trained model and the validation dataset (using `library.dataset.SaltDataset`).
    *   Perform inference on the validation set. To maximize performance and match the testing strategy, apply Test-Time Augmentation (horizontal flip) and Deep Supervision ensemble averaging.
    *   Crop the predictions and ground truth masks from the padded 128x128 size back to the original 101x101 size.
    *   Calculate the competition metric: Mean Average Precision at IoU thresholds ranging from 0.5 to 0.95.
    *   Print the `Final Validation Metric`.
4.  **Failure Analysis**:
    *   Calculate the prediction error (1 - Average Precision) for each validation image.
    *   Compute and print the Pearson correlation between this error and two metadata features: Depth (`z`) and Salt Coverage.
5.  **Submission**:
    *   Compare the calculated validation metric against the threshold (0.7893333333333333).
    *   If the metric exceeds the threshold, call `library.inference.predict_and_submit` to generate the final `submission.csv`.
