The following strategy orchestrates the "Noisy Student Wide-LinkNet" solution. It begins by setting reproducible seeds and defining hyperparameters optimized for the A100 GPU. The pipeline executes in two main stages:

1.  **Teacher Training (Stage 1)**: A `ResNet34WideLinkNet` is trained on the labeled dataset. We employ Bernoulli Depth Masking (50% probability of zeroing depth) to force the teacher to learn both depth-dependent and visual features. The model is trained for 20 epochs using a combined Lovasz-Hinge and BCE loss.
2.  **Pseudo-Labeling**: The best performing Teacher model generates soft probability masks for the entire unlabeled test set. These predictions serve as "soft targets" for the next stage.
3.  **Student Training (Stage 2)**: A fresh Student model is initialized. It is trained simultaneously on labeled data (with ground truth) and unlabeled data (with Teacher's soft targets). The Student sees strongly augmented versions of the unlabeled images but is supervised by the Teacher's stable predictions (Consistency Regularization).
4.  **Evaluation & Analysis**: The Student model is evaluated on the validation set. We perform a threshold sweep to maximize the Mean Average Precision (mAP). We then conduct a failure analysis by correlating prediction errors (1 - IoU) with depth and salt coverage to understand performance characteristics.
5.  **Submission**: If the validation mAP exceeds the required threshold (0.7985), predictions are generated for the test set using Test-Time Augmentation (TTA) and the optimized binarization threshold, then saved to the submission file.
