Based on the comprehensive analysis of the accumulated lessons, I propose the following **Soft-Distilled Robust Wide-LinkNet** strategy.

This solution addresses the central paradox: **Depth information is critical for performance (Cite solution_lesson_node_00001)**, yet **depth metadata is missing for the test set (Cite solution_lesson_node_00020)**. Previous attempts to bridge this gap via regression (Cite solution_lesson_node_00022) or naive hard pseudo-labeling (Cite solution_lesson_node_00049) failed due to weak signals or gradient instability caused by label noise.

My proposed structural innovation is a **Soft-Target Distillation Pipeline**. Instead of retraining on hard, potentially incorrect pseudo-labels, we train a Student model to minimize the divergence from the Teacher's probability distribution on the unlabeled test set. This preserves uncertainty information and prevents the catastrophic divergence observed with hard thresholding.

### Model: ResNet34-WideLinkNet with MLP-Concatenation

I propose a specialized U-shape architecture optimized for information flow and robust conditional execution.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed (Cite solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** by summing the original RGB weights. This preserves pretrained feature detectors without the redundancy of data repetition (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Optimization):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map is passed to the decoder to preserve maximum semantic information (Cite solution_lesson_node_00019).
    *   **Depth Injection:** The scalar depth $z$ is projected through a **Non-Linear MLP** (Linear $\rightarrow$ ReLU $\rightarrow$ Linear) to a 32-channel embedding (Cite solution_lesson_node_00029). This embedding is **concatenated** with the encoder features. Concatenation is chosen over FiLM or Residual Injection because it forces the model to utilize the signal and is robust to initialization (Cite solution_lesson_node_00037, solution_lesson_node_00041).
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** for efficiency (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` rather than `out_channels // 4`. This prevents the aggressive semantic information loss observed in standard implementations (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding. This ensures dimensions are multiples of the network's stride (32), preventing spatial aliasing (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std). Even with the 1-channel modification, scaling to the pretrained distribution is critical (Cite solution_lesson_node_00025).
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the training depth values (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate organic salt plasticity (Cite solution_lesson_node_00003, solution_lesson_node_00004).
    *   **Rigid:** Apply **ShiftScaleRotate** to ensure geometric invariance (Cite solution_lesson_node_00010).
    *   **Regularization:** Apply these augmentations with a moderate probability ($p=0.2$) (Cite solution_lesson_node_00007).

### Training: Soft-Target Distillation Pipeline

I propose a two-stage training process designed to leverage the unlabeled test data safely.

*   **Technique 1: Bernoulli Depth Masking.** During training, with probability $p=0.5$, replace the normalized depth input $z$ with the **dataset mean (0)**. This forces the model to learn a dual representation: a "Specialist" mode (using depth) and a "Generalist" mode (robust to missing depth).
*   **Technique 2: Per-Image Loss Aggregation.** Calculate loss **per image** and average across the batch to prevent outliers from dominating gradients (Cite solution_lesson_node_00044).

**Pipeline:**
1.  **Stage 1: Teacher Training (Supervised)**
    *   Train the model on the labeled training set using Bernoulli Depth Masking.
    *   **Loss:** Sum of **Lovasz-Hinge** (per-image) and **BCE** (Cite solution_lesson_node_00036).
    *   **Horizon:** Train for **50 epochs** to ensure full convergence (Cite solution_lesson_node_00045).

2.  **Stage 2: Student Distillation (Semi-Supervised)**
    *   **Soft Pseudo-Labeling:** Use the converged Teacher to predict **probability maps (soft targets)** for the unlabeled test set. Input a **constant depth of 0** for these predictions.
    *   **Student Training:** Initialize a new model (Student) from scratch. Train on a combined dataset:
        *   **Labeled Data:** Use Ground Truth masks and True Depths (with Bernoulli Masking). Loss: Lovasz + BCE.
        *   **Unlabeled Data:** Use Teacher's Soft Targets and Fixed Depth (0). Loss: **BCE (Soft Targets)**. This effectively distills the Teacher's generalist knowledge into the Student without the risk of hard thresholding noise (Cite solution_lesson_node_00049).
    *   **Horizon:** 50 epochs.

### Evaluation

*   **Inference:**
    *   Use the **Student Model**.
    *   **Depth Handling:** Input a **constant depth value of 0** for all test images.
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
