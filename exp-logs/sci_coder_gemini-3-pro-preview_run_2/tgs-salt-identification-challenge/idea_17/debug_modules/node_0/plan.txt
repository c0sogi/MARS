The following script demonstrates the end-to-end pipeline for the salt segmentation task using the provided library files. It covers data loading, model initialization, training, validation, threshold optimization, and inference.

### Implementation Strategy
1.  **Setup & Configuration**: Define constants for device, batch size, and paths. Set the random seed for reproducibility using `library.utils.set_seed`.
2.  **Data Preparation**: Utilize `library.dataset.get_loaders` to process the raw images and metadata into PyTorch DataLoaders. This handles caching, normalization, and augmentation automatically.
3.  **Model Instantiation**: Create an instance of `library.model.ResNet34WideLinkNet`. Move the model to the appropriate computational device (GPU/CPU).
4.  **Training**: Initialize the `CombinedLoss` and an Adam optimizer. Execute a single training epoch using `library.engine.train_one_epoch` to update model weights.
5.  **Evaluation**: Run `library.engine.validate` to compute validation loss and baseline mAP. Use the resulting predictions to perform a threshold search via `library.engine.threshold_search`, identifying the optimal binarization threshold.
6.  **Inference & Submission**: Apply the trained model and optimal threshold to the test set using `library.engine.inference`. This generates the RLE-encoded submission file.
7.  **Verification**: Load the generated CSV to assert its dimensions and column structure match the competition requirements.
