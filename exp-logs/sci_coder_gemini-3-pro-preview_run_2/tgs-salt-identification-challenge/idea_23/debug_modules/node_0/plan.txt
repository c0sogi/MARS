This script demonstrates the end-to-end usage of the provided machine learning library for the salt segmentation task. It covers data loading, model initialization, training (supervised and semi-supervised/student), validation, inference, and submission generation.

**Implementation Strategy:**
1.  **Setup**: Initialize the environment and random seeds using `library.config` and `library.utils`.
2.  **Data Preparation**: Load the metadata using `library.dataset.get_data_arrays`. To ensure the script runs quickly (within the time limit), we slice the data to a small subset (e.g., 32 samples) and use a small batch size.
3.  **Dataset & Loader**: Instantiate `SaltDataset` with the appropriate transforms from `library.dataset`. We verify the padding logic (101x101 -> 128x128) to ensure we can correctly crop predictions later.
4.  **Model & Training**: Initialize the `ResNet34WideLinkNet` model and `CombinedLoss`. Run a short training loop (1 epoch) using `library.engine.train_one_epoch` and verify that the loss is finite.
5.  **Validation**: Run `library.engine.validate` to compute the validation loss and mAP score.
6.  **Student Training**: Demonstrate the semi-supervised loop by creating a "student" loader (simulating unlabeled data) and running `library.engine.train_student_epoch`.
7.  **Inference & Submission**: Use `library.engine.predict` to generate predictions. Since the model operates on 128x128 padded images, we implement a post-processing step to center-crop the predictions back to the original 101x101 size before generating the RLE submission using `library.utils.create_submission`.
8.  **Verification**: Includes assertions to check data shapes, loss validity, and RLE encoding/decoding correctness.
