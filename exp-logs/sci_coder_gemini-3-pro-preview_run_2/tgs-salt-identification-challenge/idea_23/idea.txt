Based on the comprehensive analysis of the accumulated lessons and the persistent challenge of the "Depth Paradox" (depth is critical for performance but missing at test time), I propose the following **Ensemble-Distilled Noisy Student** strategy.

This solution synthesizes the architectural robustness of the **Wide-LinkNet** (Idea 8) with a rigorous **Semi-Supervised Learning (SSL)** pipeline. It explicitly resolves the failure modes of previous SSL attempts (noise, divergence, premature execution) by employing **Ensemble-Based Soft Distillation** and **Bernoulli Depth Masking**.

### Model: ResNet34-WideLinkNet with MLP-Concatenation

I propose a specialized U-shape architecture optimized for information flow and robust conditional execution.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed, avoiding the optimization inertia of heavier backbones like ResNeXt50 (Cite solution_lesson_node_00011, solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** by summing the original RGB weights. This preserves pretrained feature detectors without the redundancy and inefficiency of repeating input data (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Optimization):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map from the encoder is passed to the decoder to preserve maximum semantic information (Cite solution_lesson_node_00019).
    *   **Depth Injection:** The scalar depth $z$ is projected through a **Non-Linear MLP** (Linear $\rightarrow$ ReLU $\rightarrow$ Linear) to a 32-channel embedding (Cite solution_lesson_node_00029). This embedding is **concatenated** with the encoder features. Concatenation is chosen over FiLM or Residual Injection because it forces the model to utilize the signal and is robust to initialization (Cite solution_lesson_node_00037, solution_lesson_node_00041).
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** for efficiency (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` rather than `out_channels // 4`. This prevents the aggressive semantic information loss observed in standard implementations (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding. This ensures dimensions are multiples of the network's stride (32), preventing spatial aliasing (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std). Even with the 1-channel modification, scaling to the pretrained distribution is critical for transfer learning (Cite solution_lesson_node_00025).
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the training depth values (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Teacher/Labeled Data:** Apply **ElasticTransform** (Cite solution_lesson_node_00055) and conservative **ShiftScaleRotate** ($p=0.2$) (Cite solution_lesson_node_00054).
    *   **Student/Unlabeled Data:** Apply **Strong Augmentation** (Increased Elastic Deformation + Grid Distortion) to enforce consistency regularization.

### Training: Ensemble-Distilled Noisy Student Pipeline

I propose a three-stage pipeline designed to bridge the metadata gap safely.

*   **Stage 1: Teacher Ensemble Training (Supervised)**
    *   Train a **5-Fold Ensemble** of the model on the labeled training set.
    *   **Bernoulli Depth Masking:** During training, with probability $p=0.5$, replace the normalized depth input $z$ with the **dataset mean (0)**. This forces the Teachers to learn a "Generalist" mode robust to missing depth (Cite solution_lesson_node_00051 context).
    *   **Loss:** Sum of **Lovasz-Hinge** (calculated per-image) and **BCE**. Summing maintains gradient magnitude (Cite solution_lesson_node_00036), and per-image aggregation prevents outlier dominance (Cite solution_lesson_node_00044).
    *   **Horizon:** Train for **50 epochs** to ensure full convergence (Cite solution_lesson_node_00045).

*   **Stage 2: Soft Pseudo-Label Generation**
    *   Use the converged 5-Fold Teacher Ensemble to predict masks for the **unlabeled test set**.
    *   **Input:** Test Image + **Constant Depth (0)**. The Bernoulli Masking in Stage 1 ensures the models handle this gracefully.
    *   **Soft Averaging:** Average the **probability maps** (Soft Labels) from all 5 models. This reduces the label noise inherent in single-model predictions (Cite solution_lesson_node_00049).

*   **Stage 3: Student Training (Distillation)**
    *   Train a single Student model (same architecture) from scratch on the combined dataset.
    *   **Labeled Batch:** Input (Image + True Depth). Target (GT Mask). Loss: Lovasz + BCE.
    *   **Unlabeled Batch:** Input (**Strongly Augmented** Image + **Constant Depth 0**). Target (**Soft Pseudo-Label**). Loss: **BCE** (Consistency Loss).
    *   **Rationale:** The Student learns "Specialist" features from the labeled data and adapts to the test distribution via the "Generalist" guidance of the Ensemble Teacher.

### Evaluation

*   **Inference:**
    *   Use the **Stage 3 Student Model**.
    *   **Depth Handling:** Input a **constant depth value of 0** for all test images.
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score, rather than using a fixed 0.5 cutoff (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
