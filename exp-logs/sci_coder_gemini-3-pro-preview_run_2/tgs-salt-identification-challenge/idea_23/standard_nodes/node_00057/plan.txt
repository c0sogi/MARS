The implementation strategy follows the "Ensemble-Distilled Noisy Student" pipeline designed to handle the depth availability shift between training and testing.

1.  **Setup & Data Loading**: Initialize the environment and load the pre-stratified metadata (`train.csv`, `val.csv`, `test.csv`). Load the actual image/mask arrays using the provided `get_data_arrays` utility, which handles caching.
2.  **Stage 1: Teacher Ensemble (Supervised)**:
    *   Perform 5-Fold Cross-Validation on the `train` dataset.
    *   Train 5 instances of `ResNet34WideLinkNet`.
    *   **Key Feature**: Apply `Bernoulli Depth Masking` (p=0.5) during training to force the teachers to learn features robust to missing depth information.
    *   Use `CombinedLoss` (Lovasz + BCE) and `AdamW` optimizer.
    *   Limit training to a moderate number of epochs (e.g., 10) to ensure the script completes within the time limit while ensuring convergence.
3.  **Stage 2: Pseudo-Label Generation**:
    *   Use the 5 trained Teacher models to predict on the unlabeled `test` dataset.
    *   Input `depth=0` (mean) for all test images.
    *   Average the probability maps from all teachers to create stable "Soft Pseudo-Labels".
4.  **Stage 3: Student Training (Semi-Supervised)**:
    *   Initialize a fresh Student model.
    *   Construct a `labeled_loader` from the original train set and an `unlabeled_loader` from the test set with soft labels.
    *   Train using `train_student_epoch`, which alternates between labeled (Ground Truth) and unlabeled (Consistency Loss) batches.
    *   Apply strong augmentations to the student inputs.
5.  **Validation & Analysis**:
    *   Evaluate the Student model on the hold-out `val` set.
    *   **Threshold Optimization**: Perform a linear search to find the binarization threshold that maximizes the mAP metric.
    *   **Failure Analysis**: Calculate per-image IoU and correlate error rates with depth and salt coverage to identify weaknesses.
6.  **Submission**:
    *   If the validation mAP exceeds the target (0.7985), generate predictions for the test set using the optimized threshold.
    *   Format as Run-Length Encoding (RLE) and save to `submission.csv`.
