### Implementation Strategy

1.  **Configuration Setup**: We will initialize the `Config` class and override specific parameters (e.g., `BATCH_SIZE`, `EPOCHS`, `WORKING_DIR`) to ensure the script runs quickly and stores outputs in a temporary directory (`./working/demo_run`).
2.  **Utility Verification**: We will verify the correctness of core utility functions like `pad_image`, `unpad_image`, and `rle_encode` using dummy data to ensure data preprocessing logic is sound.
3.  **Data Loading**: We will use `get_fold_datasets` to load the training data. To optimize speed, we will create `Subset`s of the training and validation datasets (e.g., 16 samples) for the demonstration.
4.  **Teacher Model Training (Stage 1)**: We will instantiate the `SaltNet` in "teacher" mode and run a single training epoch using `train_teacher_epoch`. We will then validate the model and save the checkpoint.
5.  **Pseudo-Label Generation**: We will use the trained teacher model to generate marginalized soft pseudo-labels for a small subset of the test data (10 images) using `generate_marginalized_labels`.
6.  **Student Model Training (Stage 3)**: We will instantiate the `SaltNet` in "student" mode. We will create a `PseudoDataset` using the generated soft labels and run a single epoch of multi-task distillation training using `train_student_epoch`.
7.  **Inference & Submission**: We will run `generate_submission` using the student model on the test subset and verify that the output CSV follows the required format.
