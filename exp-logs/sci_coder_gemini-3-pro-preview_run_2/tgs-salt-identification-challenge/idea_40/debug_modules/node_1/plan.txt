The `RuntimeError` during student training occurs because `PseudoDataset` returns raw 2D numpy arrays `(128, 128)` when initialized with `transform=None` (as configured in the demo run). The `DataLoader` collates these into a `(Batch_Size, 128, 128)` tensor. The model's first `Conv2d` layer interprets this 3D tensor as a single unbatched image where the batch size acts as the channel count (e.g., 8 channels), causing a mismatch with the expected 1-channel input.

To fix this, I will modify `PseudoDataset.__getitem__` in `library/data.py` to:
1.  Explicitly handle the shape of `soft_mask` (squeezing the channel dimension `(1, H, W) -> (H, W)`) to ensure compatibility with Albumentations.
2.  Add a fallback `else` block for the `if self.transform:` check. This fallback will apply `ToTensorV2()` when no external transform is provided, ensuring that images are correctly converted to `(1, H, W)` tensors (Cite debug_lesson_4, debug_lesson_20).
