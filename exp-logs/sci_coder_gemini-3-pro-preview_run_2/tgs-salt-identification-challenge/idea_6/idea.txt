Based on the comprehensive analysis of the previous experiments and the specific failure modes identified, I propose the following **Depth-Imputed Cascade Strategy**.

This approach resolves the critical conflict between **Lesson 00001** (Depth conditioning improves performance) and **Lesson 00020** (Missing depth metadata in the test set causes failure). By introducing a preliminary regression stage, we can synthesize the missing metadata, allowing us to deploy the highly effective depth-conditioned architecture on the test set.

### Model: Cascade Depth-Regressed LinkNet

I propose a two-stage cascade architecture:

1.  **Stage 1: Depth Regressor (Auxiliary Network)**
    *   **Architecture:** A lightweight **ResNet18** backbone pretrained on ImageNet.
    *   **Head:** A Global Average Pooling layer followed by a simple fully connected layer projecting to a single scalar output ($z$).
    *   **Purpose:** To learn the mapping between visual seismic textures and subsurface depth from the training set, and subsequently **impute** the missing depth values for the unlabeled test set. This directly addresses the data availability mismatch identified in **Cite solution_lesson_node_00020**.

2.  **Stage 2: Depth-Conditioned ResNet34-LinkNet (Primary Network)**
    *   **Backbone:** **ResNet34** pretrained on ImageNet. This balances feature extraction power with convergence speed, avoiding the optimization inertia of heavier backbones like ResNeXt50 **Cite solution_lesson_node_00011, solution_lesson_node_00012**.
    *   **Bottleneck Optimization:** The explicit bottleneck compression layer (typically reducing channels from 512 to 256) is **removed**. The full 512-channel feature map from the encoder is passed to the decoder to preserve maximum semantic information **Cite solution_lesson_node_00019**.
    *   **Depth Injection:** The scalar depth (ground truth for train, imputed for test) is normalized, projected to a low-dimensional embedding (e.g., 16 channels), and **concatenated** with the encoder's feature map at the bottleneck. This effectively conditions the decoding process on the geological context **Cite solution_lesson_node_00001, solution_lesson_node_00009**.
    *   **Decoder:** A **LinkNet** decoder using **additive skip connections**. This is chosen over U-Net++ or ASPP because its efficiency allows for better convergence on small datasets without the parameter explosion of dense concatenation **Cite solution_lesson_node_00008, solution_lesson_node_00017**.

### Data

1.  **Preprocessing:**
    *   **Depth Imputation:** Before the main training loop, run the Stage 1 Depth Regressor on the test images to generate `test_depths.npy`.
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to all depth values. This ensures the injected features align with the network's weight initialization statistics **Cite solution_lesson_node_00010**.
    *   **Image Formatting:** Convert images to single-channel grayscale and pad them from 101x101 to **128x128** using reflection padding to align with the network's downsampling factors.

2.  **Augmentation:**
    *   **Elastic Deformations:** Apply `ElasticTransform` with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate the organic plasticity of salt bodies **Cite solution_lesson_node_00003, solution_lesson_node_00004**.
    *   **Affine Transformations:** Apply `ShiftScaleRotate` to ensure geometric invariance, which is critical for seismic data **Cite solution_lesson_node_00010**.
    *   **Regularization:** Apply these non-rigid augmentations with a moderate probability ($p=0.2$) to act as a regularizer without shifting the training distribution too aggressively **Cite solution_lesson_node_00007**.

### Training

1.  **Stage 1 (Regression):** Train the Depth Regressor on the labeled training set using **MSE Loss** for 20 epochs. Freeze this model and generate predictions for the test set.
2.  **Stage 2 (Segmentation):** Train the Primary Network using the combined (Image + Depth) inputs.
    *   **Loss Function:** Use **BCE + Dice Loss**. This combination is robust and converges reliably for this dataset **Cite solution_lesson_node_00018**.
    *   **Optimizer:** AdamW with weight decay.
    *   **Scheduler:** Cosine Annealing LR scheduler.
    *   **Horizon:** Train for **50 epochs**. This ensures the model reaches its true peak performance, avoiding the premature truncation observed in 20-epoch runs **Cite solution_lesson_node_00006**.

### Evaluation

1.  **Inference:**
    *   Load the test images and their **imputed depths** (from Stage 1).
    *   Apply **Test-Time Augmentation (TTA)** by averaging predictions from the original image and a horizontally flipped version **Cite solution_lesson_node_00002**.
    *   Center crop the 128x128 predictions back to 101x101.
2.  **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP metric, rather than using a default of 0.5 **Cite solution_lesson_node_00018**.
    *   Convert the resulting binary masks to Run-Length Encoding (RLE) for submission.
