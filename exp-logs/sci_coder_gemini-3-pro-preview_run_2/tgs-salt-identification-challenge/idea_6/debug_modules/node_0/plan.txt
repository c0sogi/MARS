This script demonstrates the end-to-end usage of the provided library files for the salt segmentation task. It covers data preparation, utility verification, model instantiation, training (regression and segmentation), inference, and submission file generation.

**Implementation Strategy:**
1.  **Setup**: Initialize random seeds and verify environment.
2.  **Utility Verification**: Test `rle_encode`, `rle_decode`, `calc_iou`, and `calc_map` from `library.utils` using synthetic data to ensure correctness.
3.  **Data Loading**: Use `library.dataset.prepare_data` to load and process images/metadata, then create DataLoaders using `get_dataloaders`. Verify batch shapes and content.
4.  **Model Instantiation**: Initialize `DepthRegressor` and `DepthAwareLinkNet34` from `library.models` and perform a dummy forward pass to verify architecture and tensor shapes.
5.  **Training Loop**: Execute `run_regression_training` and `run_segmentation_training` from `library.engine` for a single epoch to demonstrate the training pipeline and checkpoint saving.
6.  **Inference & Submission**: Use the trained segmenter to predict on the test set via `predict_segmentation`, encode the results, and generate a valid CSV submission file.
