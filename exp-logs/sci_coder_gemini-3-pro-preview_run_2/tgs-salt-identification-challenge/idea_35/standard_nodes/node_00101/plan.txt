The implementation strategy for the `runfile.py` script is as follows:

1.  **Configuration Setup**: Import the `Config` class and override specific training hyperparameters (`EPOCHS_STAGE1`, `EPOCHS_STAGE3`, `N_FOLDS`) to ensure the pipeline runs quickly as a "fast baseline" while still allowing sufficient convergence (e.g., 20 epochs, 3 folds).
2.  **Data Preparation**: Initialize the data pipeline by calling `prepare_data(load_cached_data=True)`.
3.  **Pipeline Orchestration**: Sequentially execute the three stages of the proposed strategy:
    *   **Stage 1**: Train the Teacher Ensemble using `run_stage_1_teacher_ensemble`.
    *   **Stage 2**: Generate marginalized soft pseudo-labels using `run_stage_2_marginalization`.
    *   **Stage 3**: Distill knowledge into the Student model using `run_stage_3_student_distillation`.
4.  **Final Evaluation**: Load the best student model and compute the `Final Validation Metric` on the hold-out validation set.
5.  **Failure Analysis**: Iterate through the validation set to calculate per-image errors and compute their Pearson correlation with input features (Depth and Salt Coverage).
6.  **Submission Generation**: Compare the validation metric against the threshold (0.7985). If the condition is met, optimize the binarization threshold and generate the `submission.csv` file.
