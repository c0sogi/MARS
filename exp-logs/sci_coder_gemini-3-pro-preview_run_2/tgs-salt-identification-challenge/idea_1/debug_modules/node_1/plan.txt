The issue lies in the `metric_iou` function in `library/utils.py`, which uses a smoothing factor (`smooth=1e-6`) in the IoU calculation `(intersection + smooth) / (union + smooth)`. This causes the IoU for disjoint masks (where intersection is 0 and union is non-zero) to be a small non-zero value (approx. 1.11e-7) instead of exactly 0.0, which fails the strict assertion in the `runfile.py` test script. To fix this, I will update the function to calculate the exact IoU by handling the division explicitly: returning 1.0 if the union is zero (both empty), and `intersection / union` otherwise, removing the smoothing artifact from the result.
