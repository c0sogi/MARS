Based on the dataset characteristics and the need for a highly efficient, lightweight baseline distinct from the provided examples, I propose the following solution:

### Model: Depth-Conditioned LinkNet
I propose a **LinkNet-style Fully Convolutional Network (FCN)** trained from scratch. Unlike the U-Net in Model 1 (which uses concatenation for skip connections and a heavy pre-trained encoder), LinkNet uses **element-wise addition** for skip connections. This significantly reduces the parameter count and memory footprint in the decoder, making it highly efficient.

*   **Encoder**: A custom, lightweight CNN consisting of 4 encoder blocks. Each block utilizes strided convolutions for downsampling (instead of max pooling) to learn spatial reduction, followed by Batch Normalization and ReLU activation.
*   **Depth Injection**: To utilize the provided `z` (depth) metadata, the scalar depth value is normalized and projected via a small dense layer. This vector is replicated spatially and concatenated with the feature maps at the network's bottleneck (the deepest point). This allows the model to condition its segmentation on the geological depth, which the EDA suggests has a non-linear relationship with salt presence.
*   **Decoder**: A symmetric path of 4 decoder blocks using Transposed Convolutions for upsampling.
*   **Skip Connections**: The feature maps from the encoder are added directly to the corresponding decoder feature maps (Element-wise Sum). This recovers spatial information without the channel explosion associated with U-Net concatenation.
*   **Output Head**: A final 1x1 convolution followed by a Sigmoid activation to produce the probability map.

### Data
*   **Preprocessing**:
    *   **Channel Standardization**: Convert all images to single-channel grayscale. The EDA indicates a mix of 3 and 4-channel images; reducing this to 1 channel standardizes the input and reduces computational load.
    *   **Padding**: Pad the 101x101 images to **128x128** using reflection padding. This ensures the spatial dimensions are divisible by $2^4$ (necessary for the 4-level encoder/decoder) without introducing interpolation artifacts caused by resizing.
    *   **Normalization**: Scale pixel values to the [0, 1] range. Standardize the depth values ($z$) to have zero mean and unit variance based on training set statistics.
*   **Augmentation**: Apply minimal augmentations to prevent overfitting while maintaining speed: only **Horizontal Flips** will be used. Vertical flips are excluded because seismic geology has distinct directional properties (gravity/depth).

### Training
*   **Loss Function**: A combination of **Binary Cross-Entropy (BCE)** and **Dice Loss**. BCE handles pixel-level classification accuracy, while Dice Loss optimizes the intersection-over-union metric directly, helping with class imbalance (salt vs. sediment).
*   **Optimizer**: **AdamW** with a standard learning rate (e.g., 1e-3) and weight decay to prevent overfitting.
*   **Scheduler**: Use a **Cosine Annealing** learning rate scheduler. This allows for a rapid convergence in the early phase and fine-tuning in later epochs.
*   **Strategy**: Train from scratch for a fixed number of epochs (e.g., 50) with Early Stopping monitoring the validation Dice score.

### Evaluation
*   **Inference**:
    1.  Preprocess test images (Grayscale, Pad to 128x128, Normalize).
    2.  Pass through the trained LinkNet.
    3.  **Center Crop** the 128x128 prediction back to the original 101x101 dimension.
*   **Post-processing**:
    *   Apply a fixed threshold of **0.5** to the probability map to generate the binary mask.
    *   Convert the binary mask to the required Run-Length Encoding (RLE) format.
    *   Ensure predictions are sorted and non-overlapping as per the submission format requirements.
