Based on the comprehensive analysis of previous experiments and lessons learned, I propose the following **Multi-Task Wide-LinkNet Strategy**.

This approach addresses the critical conflict between the proven benefit of depth conditioning (Lesson 00001) and the failure of depth availability/imputation at test time (Lesson 00020, 00022). Instead of using depth as an *input*, we treat it as an *auxiliary prediction target*. This forces the encoder to learn depth-correlated features (latent regularization) during training while keeping the inference pipeline purely image-based and robust to missing metadata.

### Model: Multi-Task Wide-LinkNet34

I propose a **ResNet34-LinkNet** architecture modified for Multi-Task Learning and enhanced information flow.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed for this dataset size Cite solution_lesson_node_00002, solution_lesson_node_00012.
*   **Bottleneck Optimization:**
    *   **No Compression:** The explicit bottleneck layer (reducing channels before the decoder) is removed. The full 512-channel feature map from the encoder is passed to the decoder to preserve semantic information Cite solution_lesson_node_00019.
    *   **Auxiliary Depth Head:** A lightweight regression head (Global Average Pooling $\rightarrow$ Dense Layer $\rightarrow$ Scalar Output) is attached to the bottleneck. This head predicts the normalized depth ($z$) of the image. This auxiliary task forces the backbone to encode geological context (e.g., texture variations correlated with depth) without requiring depth as an input during inference.
*   **Decoder (Structural Innovation):**
    *   **Wide-LinkNet Blocks:** The decoder utilizes LinkNet blocks with **Additive Skip Connections** Cite solution_lesson_node_00008. Crucially, the internal dimension of the decoder blocks is calculated as a fraction of the **input channels** (e.g., `in_channels // 4`) rather than the output channels. This prevents the aggressive information bottleneck identified in previous experiments, ensuring high-dimensional semantic features are preserved during upsampling Cite solution_lesson_node_00023.

### Data

*   **Preprocessing:**
    *   **Image:** Convert to single-channel grayscale and pad from 101x101 to **128x128** using reflection padding.
    *   **Depth Targets:** Apply **Standard Scaling** (zero mean, unit variance) to the ground truth depth values to stabilize the auxiliary regression loss Cite solution_lesson_node_00010.
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate organic salt plasticity Cite solution_lesson_node_00003, solution_lesson_node_00004.
    *   **Rigid:** Apply **ShiftScaleRotate** to ensure geometric invariance Cite solution_lesson_node_00010.
    *   **Regularization:** Apply these augmentations with a moderate probability ($p=0.2$) to act as a regularizer without shifting the training distribution too aggressively Cite solution_lesson_node_00007.

### Training

*   **Loss Function:** A composite Multi-Task Loss: $L_{total} = L_{seg} + \lambda L_{reg}$.
    *   **Segmentation ($L_{seg}$):** **Lovasz-Hinge Loss** combined with Binary Cross Entropy (BCE). Lovasz-Hinge directly optimizes the Jaccard index (IoU), aligning the objective with the competition metric better than Dice Loss Cite solution_lesson_node_00021.
    *   **Regression ($L_{reg}$):** **MSE Loss** on the auxiliary depth prediction, weighted by $\lambda=0.1$.
*   **Optimizer:** **AdamW** with a conservative learning rate of **1e-4**. This prevents catastrophic forgetting of the pretrained ResNet34 features, which was observed with more aggressive rates Cite solution_lesson_node_00022.
*   **Scheduler:** **Cosine Annealing** learning rate scheduler.
*   **Horizon:** Train for **50 epochs**. This ensures the model reaches peak performance, avoiding the premature truncation observed in shorter runs Cite solution_lesson_node_00006.

### Evaluation

*   **Inference:**
    *   Pass the test images through the model. **Ignore the auxiliary depth prediction**; use only the segmentation mask output. This bypasses the issue of missing/unreliable test depths entirely Cite solution_lesson_node_00020.
    *   **Test-Time Augmentation (TTA):** Average predictions from the original image and a horizontally flipped version Cite solution_lesson_node_00002.
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score, rather than using a fixed 0.5 cutoff Cite solution_lesson_node_00018.
    *   **Formatting:** Center crop to 101x101 and convert to Run-Length Encoding (RLE).
