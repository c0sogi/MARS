Based on the comprehensive analysis of the accumulated lessons, I propose the following **Corrected Multi-Task Wide-LinkNet with Gated Noisy Student** strategy.

This solution addresses the central "Depth Paradox": explicit depth injection improves performance (Cite solution_lesson_node_00001) but is impossible at test time due to missing metadata (Cite solution_lesson_node_00020). Previous attempts to use depth as a training target failed due to "silent disconnection" bugs (Cite solution_lesson_node_00062) or lack of non-rigid augmentation (Cite solution_lesson_node_00055). Furthermore, previous ensembling/self-training attempts failed because they included collapsed models (Cite solution_lesson_node_00067) or used naive hard labels (Cite solution_lesson_node_00049).

My proposed structural innovation is a **Corrected Multi-Task Regularization** combined with a **Quality-Gated Self-Training Pipeline**. By ensuring the auxiliary depth head is computationally connected and using Elastic transforms, we force the encoder to extract depth-correlated texture features. We then leverage the unlabeled test data using a rigorous ensemble distillation process that explicitly filters out failed models.

### Model: Corrected Multi-Task ResNet34-WideLinkNet

I propose a specialized architecture designed to learn depth-correlated texture features without requiring depth as an input during inference.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This remains the optimal balance of capacity and convergence speed for this dataset size (Cite solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer of the ResNet backbone to accept **1-channel input** by summing the original RGB weights. This preserves pretrained feature detectors without the redundancy of data repetition (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Optimization):**
    *   **No Compression:** The explicit bottleneck compression layer is removed; the full 512-channel feature map is passed to the decoder (Cite solution_lesson_node_00019).
    *   **Corrected Auxiliary Depth Head:** Attach a regression head (GlobalAveragePooling $\rightarrow$ MLP $\rightarrow$ Scalar) to the bottleneck. **Crucially**, implement a runtime assertion in the training loop to verify `loss_depth.requires_grad` is True and `loss_depth.item() > 0`. This fixes the "silent disconnection" bug that rendered previous multi-task attempts inert (Cite solution_lesson_node_00062).
    *   **No Injection:** Depth is *not* injected into the decoder. This ensures the model is fully compatible with the test set (Cite solution_lesson_node_00020).
*   **Decoder:**
    *   **Wide-LinkNet Architecture:** Utilize LinkNet blocks with **Additive Skip Connections** (Cite solution_lesson_node_00008).
    *   **Width Correction:** Calculate the internal dimension of decoder blocks as `in_channels // 4` rather than `out_channels // 4`. This prevents semantic information loss during upsampling (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding. This ensures dimensions are multiples of the network's stride (32), preventing spatial aliasing (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std). Even with the 1-channel modification, scaling to the pretrained distribution is critical (Cite solution_lesson_node_00025).
    *   **Depth Normalization:** Apply **Standard Scaling** (zero mean, unit variance) to the training depth values for the auxiliary regression target (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Mandatory Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6). This is critical for modeling organic salt structures and was missing in previous Multi-Task experiments (Cite solution_lesson_node_00055).
    *   **Rigid:** Apply **ShiftScaleRotate** with low probability ($p=0.2$) to ensure geometric invariance without destroying high-precision boundaries (Cite solution_lesson_node_00054).

### Training: Gated Noisy Student Pipeline

I propose a three-stage pipeline to bridge the performance gap between depth-injected and image-only models.

*   **Stage 1: Multi-Task Ensemble (Supervised)**
    *   Train a **5-Fold Ensemble** of the Multi-Task model on the labeled training set.
    *   **Loss:** $L = \text{Sum}(L_{\text{Lovasz}}(Mask, GT) + L_{\text{BCE}}(Mask, GT)) + 0.1 \cdot L_{\text{MSE}}(PredDepth, TrueDepth)$.
    *   **Aggregation:** Compute Lovasz loss **per-image** and average across the batch to prevent outlier dominance (Cite solution_lesson_node_00044). Sum the loss terms to maintain gradient magnitude (Cite solution_lesson_node_00036).
    *   **Optimizer:** AdamW with conservative LR (`1e-4`) and **Cosine Annealing** scheduler (Cite solution_lesson_node_00068).
    *   **Horizon:** Train for **50 epochs** to ensure full convergence (Cite solution_lesson_node_00006).

*   **Stage 2: Quality Gating & Soft Pseudo-Labeling**
    *   **Quality Gating:** Before generating labels, evaluate each of the 5 models on its validation fold. **Discard** any model with mAP < 0.75. This prevents collapsed models (e.g., all-background predictors) from corrupting the pseudo-labels (Cite solution_lesson_node_00067).
    *   **Soft Averaging:** Use the remaining valid models to predict on the **unlabeled test set**. Average the **probability maps** (Soft Labels). This captures uncertainty better than hard thresholding (Cite solution_lesson_node_00049).

*   **Stage 3: Student Distillation (Semi-Supervised)**
    *   Train a single Student model (same architecture) from scratch on the combined dataset (Train + Test).
    *   **Labeled Batch:** Loss = Lovasz + BCE + MSE.
    *   **Unlabeled Batch:** Apply **Strong Augmentation** (Elastic + Grid Distortion). Loss = **BCE** (vs Soft Pseudo-Labels). Ignore depth loss for these samples.
    *   **Rationale:** The Student learns robust features from the labeled data (regularized by depth) and adapts to the test distribution via the smoothed guidance of the Gated Ensemble.

### Evaluation

*   **Inference:**
    *   Use the **Stage 3 Student Model**.
    *   **Input:** Image only (Auxiliary depth head is ignored).
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score, rather than using a fixed 0.5 cutoff (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
