### Implementation Strategy

1.  **Setup and Configuration**: Initialize the environment, set random seeds for reproducibility, and define constants (paths, batch size, device). We will use a small subset of the data (e.g., 16 samples) to ensure the script runs quickly within the time limit.
2.  **Data Loading Demonstration**:
    *   Load the provided metadata (`train.csv` and `test.csv`).
    *   Use `preload_data` from `library.dataset` to load images and depths, caching them to the writable `./working` directory.
    *   Calculate depth statistics for normalization.
    *   Instantiate `SaltDataset` and wrap it in a PyTorch `DataLoader`.
    *   **Validation**: Verify the shape and types of the batch yielded by the dataloader (Images: `[B, 1, 128, 128]`, Masks: `[B, 1, 128, 128]`, Depths: `[B, 1]`).
3.  **Model Initialization**:
    *   Instantiate the `SaltNet` architecture from `library.model`.
    *   Move the model to the GPU.
    *   **Validation**: Perform a dummy forward pass to confirm the output shape matches the expected logits dimensions.
4.  **Training Loop Demonstration**:
    *   Define the `MixedLoss` function and an optimizer (Adam).
    *   Run `train_one_epoch` from `library.engine` for a single epoch on the subset.
    *   **Validation**: Assert that the returned loss is a valid finite number.
5.  **Evaluation and Inference Demonstration**:
    *   Run `validate` to compute validation loss and Mean Average Precision (mAP).
    *   Demonstrate `optimize_threshold` to find the best binarization threshold.
    *   Run `generate_submission` using the test dataset subset to produce a submission file in `./working`.
    *   **Validation**: Check that the submission CSV exists and contains the correct columns (`id`, `rle_mask`).
