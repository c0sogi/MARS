Implementation strategy:
1.  **Configuration & Setup**: Initialize the `Config` and override specific parameters to create a "Fast Baseline". We will limit `MAX_TRAIN_SAMPLES` to 2400 (the size of the training set) to ensure the validation set (600 samples) remains a strict holdout. We will also reduce epochs (to 10) and folds (to 2) to satisfy the 2-hour runtime constraint while maintaining the integrity of the "Marginalized Distillation" pipeline.
2.  **Pipeline Execution**: Instantiate the `Pipeline` class and manually execute the stages in sequence:
    *   **Stage 1**: Train the Specialist Teacher Ensemble (Depth-Injected).
    *   **Stage 2**: Generate Marginalized Soft Pseudo-Labels for the test set.
    *   **Stage 3**: Train the Generalist Student (Image-Only) using distillation.
    *   **Optimization**: Determine the optimal binarization threshold.
3.  **Validation & Failure Analysis**: Manually load the holdout validation dataset (`metadata/val.csv`) which was excluded from training. Perform inference using the trained Student model. Calculate the competition metric (mAP) and perform failure analysis by correlating the prediction error (1 - IoU) with the depth feature.
4.  **Submission**: Check if the calculated validation metric exceeds the required threshold (0.7985). If successful, trigger the submission generation function.
