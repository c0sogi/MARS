The strategy implements a **Corrected Multi-Task Wide-LinkNet with Gated Noisy Student** pipeline.

1.  **Setup & Configuration**: We initialize the environment, set random seeds, and configure the run for a fast baseline (10 epochs per stage) to ensure execution within the time limit. We prepare and cache the training and test metadata.
2.  **Stage 1: Ensemble Training**: We train a 5-fold ensemble of `SaltNet` models. Each model is trained using a Multi-Task Loss (Lovasz + BCE + Depth MSE) to force the encoder to learn depth-correlated features. We save the best checkpoint for each fold based on validation mAP.
3.  **Stage 2: Quality Gating & Pseudo-Labeling**: We evaluate the trained models and discard any with a validation mAP below 0.75 to prevent low-quality guidance. The remaining models predict on the unlabeled test set (using Test-Time Augmentation), and their predictions are averaged to create soft pseudo-labels.
4.  **Stage 3: Student Training**: We construct a semi-supervised dataset combining the labeled training data (excluding the hold-out validation set) and the pseudo-labeled test data. A new Student model is trained on this combined dataset to learn robust features.
5.  **Validation & Analysis**: We validate the Student model on the strict hold-out validation set (`val.csv`), optimizing the pixel probability threshold to maximize the competition metric. We then perform failure analysis by correlating prediction errors with depth and salt coverage.
6.  **Submission**: If the final validation metric exceeds the required threshold (0.7985), we generate the submission file using the Student model and the optimized threshold.
