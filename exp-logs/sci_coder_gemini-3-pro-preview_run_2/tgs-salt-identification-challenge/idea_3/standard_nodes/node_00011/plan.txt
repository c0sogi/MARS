The implementation strategy follows the provided requirements to establish a fast baseline for salt segmentation.

1.  **Configuration Adjustment**: The `Config` class attributes are modified at runtime to reduce the number of epochs (set to 15) to ensure the code completes within the "fast baseline" time constraints while still allowing for convergence on the A100 GPU.
2.  **Data Loading**: The `get_dataloaders` function is used with `load_cached_data=True` to efficiently load preprocessed tensors from the working directory.
3.  **Training**: The `SaltTrainer` class is instantiated and the `fit` method is called to train the `SaltLinkNet` (SE-ResNeXt50 + Attention LinkNet) using the training and validation loaders.
4.  **Validation & Threshold Optimization**: After training, `optimize_threshold` is used to find the best binarization threshold. The final validation metric (mAP) is computed using this threshold and printed in the required format.
5.  **Failure Analysis**: A specific analysis block iterates through the validation set to compute the Average Precision (AP) for each image. It then calculates and prints the Pearson correlation between the model's performance (AP) and the image depth ($z$) as well as salt coverage, identifying systematic weaknesses.
6.  **Submission**: Conditional on the validation metric exceeding the specified threshold (0.78933...), the `predict` method generates the submission file for the test set.
