This script demonstrates the end-to-end usage of the provided library modules for the salt segmentation task. It covers data loading with the `dataset` module, model instantiation from `model.py`, loss calculation using `loss.py`, training routines via `engine.py`, and utility functions for RLE encoding/decoding.

The script uses `debug=True` for data loading and `pretrained=False` for the model to ensuring fast execution and independence from external network connections.
