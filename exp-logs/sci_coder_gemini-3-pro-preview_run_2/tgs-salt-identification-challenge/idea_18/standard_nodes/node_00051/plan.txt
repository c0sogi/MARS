### Implementation Strategy

1.  **Initialization**: Set random seeds for reproducibility and define the computation device (CUDA).
2.  **Data Loading**: Use `get_dataloaders` to load training, validation, and test sets. The data is already preprocessed (padded to 128x128) and cached.
3.  **Model Setup**: Initialize the `ResNet34WideLinkNet` model. This architecture is designed to handle 1-channel seismic images and inject depth information via an MLP.
4.  **Phase 1 Training (Internal Consistency)**: Train the model for 25 epochs using `train_ict_epoch`. This enforces consistency by training on both (Image + True Depth) and (Image + Zero Depth) in every step, making the model robust to missing depth information at inference time.
5.  **Pseudo-Labeling**: Generate soft probability maps for the unlabeled test set using the Phase 1 model with zero depth inputs.
6.  **Phase 2 Training (Soft-Adaptation)**: Fine-tune the model for 10 epochs using `train_adapt_epoch`. This combines the labeled training set (with true depth) and the pseudo-labeled test set (with zero depth) to adapt the batch normalization statistics and features to the test distribution.
7.  **Validation & Thresholding**: Evaluate the final model on the validation set using `evaluate`. This function applies Test-Time Augmentation (TTA) and performs a linear search to find the optimal probability threshold for the IoU metric.
8.  **Failure Analysis**: Compute per-image validation scores to identify error patterns. Calculate Pearson correlations between the error magnitude ($1 - \text{mAP}$) and metadata features (Depth and Salt Coverage).
9.  **Submission**: If the validation metric exceeds the threshold (0.7985), generate predictions for the test set using the optimized threshold, encode them using RLE, and save the submission file.
