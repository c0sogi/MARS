Implementation Strategy:
1.  **Environment Setup**: Import necessary standard libraries and the provided library modules (`config`, `utils`, `losses`, `model`, `dataset`, `train_eval`). Set the random seed using `utils.set_seed`.
2.  **Configuration Override**: Monkey-patch the `Config` class to reduce `EPOCHS` to 1 and `BATCH_SIZE` to 4. This ensures the demonstration runs quickly.
3.  **Utility Verification**: Validate the `rle_encode` and `rle_decode` functions by encoding a synthetic mask and asserting that decoding it returns the original mask.
4.  **Data Loading & Subsetting**: Use `dataset.load_data` to load the training metadata. Slice the returned arrays to create a tiny subset (e.g., 16 samples) to speed up the training loop demonstration.
5.  **Dataset & DataLoader**: Instantiate `SaltDataset` with the subsetted data and the training transforms. Create a `DataLoader`.
6.  **Model Initialization**: Instantiate `DepthAwareLinkNet`, move it to the GPU, and perform a dummy forward pass to verify input/output shapes (expecting 128x128 output due to padding).
7.  **Loss Calculation**: Instantiate `BCEDiceLoss` and verify it computes a scalar loss on the dummy output.
8.  **Training Loop**: Run `train_eval.train_one_epoch` on the subset to demonstrate the training process.
9.  **Validation Loop**: Run `train_eval.validate` on the same subset to demonstrate metric calculation and threshold finding.
10. **Inference & Post-processing**: Run `train_eval.predict_with_tta`. Demonstrate how to crop the 128x128 model output back to the original 101x101 size (reversing the padding) before RLE encoding.
