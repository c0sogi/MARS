Based on the comprehensive analysis of the accumulated lessons, I propose the following **FP32-Stabilized Marginalized-Distillation to Corrected Multi-Task Student** strategy.

This solution resolves the central "Depth Paradox": **Depth information is critical for performance (Cite solution_lesson_node_00001)**, yet **depth metadata is missing for the test set (Cite solution_lesson_node_00020)**.

Previous attempts failed due to:
1.  **Regression Inaccuracy:** Image-to-depth regression lacks sufficient precision to replace explicit injection (Cite solution_lesson_node_00022).
2.  **Information Bottleneck:** Standard distillation fails because an image-only student cannot infer depth-dependent rules (Cite solution_lesson_node_00032).
3.  **Instability:** Mixed Precision (AMP) causes failure with ranking losses (Cite solution_lesson_node_00097), and naive pseudo-labeling causes divergence (Cite solution_lesson_node_00049).
4.  **Implementation Bugs:** Previous multi-task attempts failed due to "silent disconnection" of the auxiliary head (Cite solution_lesson_node_00062).

My proposed structural innovation is **Marginalized Distillation**. We first train a "Specialist" Teacher that relies on explicit depth. We then generate robust targets for the unlabeled test set by "scanning" the Specialist across a spectrum of plausible depths and averaging the results (Marginalization). Finally, we distill this marginalized knowledge into a "Generalist" Student. Crucially, the Student is equipped with a **Corrected Auxiliary Depth Head**, forcing it to learn depth-correlated texture features to mitigate the information bottleneck, and the entire pipeline is stabilized using **FP32** and **Soft-Target BCE**.

### Model: Teacher-Student Wide-LinkNet Framework

I propose two distinct model variants sharing a high-performance backbone.

1.  **Specialist Teacher (Depth-Injected):**
    *   **Backbone:** **ResNet34** pretrained on ImageNet (Cite solution_lesson_node_00012).
    *   **Input:** First convolution modified to accept **1-channel input** (summing weights) to avoid data repetition inefficiency (Cite solution_lesson_node_00028).
    *   **Bottleneck:** No compression layer; passes full 512 channels (Cite solution_lesson_node_00019).
    *   **Depth Injection:** Projects scalar depth via a **Non-Linear MLP** and **concatenates** it with encoder features (Cite solution_lesson_node_00029, solution_lesson_node_00041).
    *   **Decoder:** **Wide-LinkNet** (internal width = `in_channels // 4`) with **Additive Skip Connections** (Cite solution_lesson_node_00008, solution_lesson_node_00023).

2.  **Generalist Student (Multi-Task):**
    *   **Architecture:** Identical to the Teacher, but **removes the Depth Injection module**.
    *   **Auxiliary Head (Structural Innovation):** Attaches a regression head (GlobalAvgPool $\rightarrow$ MLP $\rightarrow$ Scalar) to the bottleneck. This head is **explicitly connected** to the loss function via a runtime check (Cite solution_lesson_node_00062) to force the encoder to extract depth-correlated texture features.
    *   **Inference:** Uses **only the image** input.

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding to ensure divisibility by 32 (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Mean/Std) (Cite solution_lesson_node_00025). Apply **Standard Scaling** to depth values (Cite solution_lesson_node_00010).
    *   **Cache Safety:** Explicitly validate dataset configuration to prevent loading stale caches (Cite solution_lesson_node_00056).
*   **Augmentation:**
    *   **Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) and `alpha_affine` (Cite solution_lesson_node_00095). This is mandatory for performance (Cite solution_lesson_node_00055). Apply with moderate probability ($p=0.2$) (Cite solution_lesson_node_00073).
    *   **Rigid:** Apply conservative **ShiftScaleRotate** ($p=0.2$) for geometric invariance (Cite solution_lesson_node_00054).

### Training: FP32 Marginalized Distillation Pipeline

I propose a three-stage pipeline to robustly transfer knowledge to the depth-blind domain. **Strictly use FP32** to avoid instability (Cite solution_lesson_node_00097).

*   **Stage 1: Train Specialist Teacher (Supervised)**
    *   Train a **5-Fold Ensemble** of the Depth-Injected Teacher on the labeled dataset.
    *   **Depth Fidelity:** Use exact true depths. Do not use Jitter or Zero-Masking, as this dilutes the conditioning signal (Cite solution_lesson_node_00051, solution_lesson_node_00094).
    *   **Loss:** Sum of **Lovasz-Hinge** (per-image) and **BCE** (Cite solution_lesson_node_00044, solution_lesson_node_00036).
    *   **Horizon:** 50 epochs (Cite solution_lesson_node_00006).
    *   **Gating:** Discard any fold model with validation mAP < 0.75 (Cite solution_lesson_node_00067).

*   **Stage 2: Marginalized Soft Pseudo-Labeling**
    *   **Depth-Scan Inference:** For each unlabeled test image $x$, generate predictions using the valid Teacher models across a **spectrum of depths** $Z_{scan}$ (e.g., $\{-1.5, -0.75, 0, 0.75, 1.5\}$ standard deviations).
    *   **Marginalization:** Average the probability maps across all $z \in Z_{scan}$ and all models. This computes the expected mask $\mathbb{E}_z[P(y|x, z)]$, integrating out the missing depth variable.
    *   **Output:** High-quality **Soft Probability Maps** robust to depth uncertainty.

*   **Stage 3: Student Distillation (Multi-Task)**
    *   Train a single Generalist Student from scratch on the Combined (Train + Test) dataset.
    *   **Labeled Batch:** Input: Image. Target: GT Mask + True Depth. Loss: **Lovasz+BCE** (Mask) + **MSE** (Depth).
    *   **Unlabeled Batch:** Input: Image. Target: Soft Pseudo-Labels. Loss: **BCE** (vs Soft Targets). Note: We use BCE because Lovasz is incompatible with soft targets (Cite solution_lesson_node_00071).
    *   **Optimizer:** AdamW (`lr=1e-4`) with **Cosine Annealing** (Cite solution_lesson_node_00022, solution_lesson_node_00068).

### Evaluation

*   **Inference:**
    *   Use the **Stage 3 Student Model**.
    *   **Input:** Image only (Auxiliary depth head is ignored).
    *   **Test-Time Augmentation (TTA):** Average predictions of original and horizontally flipped images (Cite solution_lesson_node_00095).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00018, solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
