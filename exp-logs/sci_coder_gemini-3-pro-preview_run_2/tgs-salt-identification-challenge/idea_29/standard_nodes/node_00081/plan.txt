The `AttributeError` indicates that the `StudentLoss` class in `library/losses.py` attempts to access `LOSS_WEIGHT_MSE` and `LOSS_WEIGHT_BCE_DISTILL` from the global `Config` object, but these attributes are not defined in `library/config.py`. This issue arises from the tight coupling between the loss function implementation and the static configuration schema (Cite debug_lesson_14).
