Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by setting random seeds for reproducibility and selecting the compute device (CUDA). Ensure all necessary directories exist.
2.  **Data Loading**: Initialize the `SaltDataset` for training and validation. Create DataLoaders with appropriate batch sizes.
3.  **Stage 1 - Teacher Training**:
    *   Instantiate the `ResNet34WideLinkNetMTL` model.
    *   Train for a fixed number of epochs (reduced to 30 for the fast baseline constraint) using the `CombinedMTLLoss`.
    *   Use `train_teacher_epoch` which handles Bernoulli depth masking.
    *   Validate after each epoch and save the model with the best mAP.
4.  **Stage 2 - Pseudo-Label Generation**:
    *   Load the best Teacher model.
    *   Generate soft probability predictions on the unlabeled test set using `predict` (with TTA).
    *   These soft labels serve as targets for the Student.
5.  **Stage 3 - Student Training**:
    *   Instantiate a fresh `ResNet34WideLinkNetMTL` Student model.
    *   Initialize `PseudoLabelDataset` with the generated soft labels.
    *   Train for 30 epochs using `train_student_epoch`, which mixes labeled data (MTL loss) and unlabeled data (distillation loss).
    *   Validate and save the best Student model.
6.  **Threshold Optimization**:
    *   Using the best Student model, generate validation predictions.
    *   Perform a linear search over threshold values (0.0 to 1.0) to find the threshold that maximizes mAP.
7.  **Failure Analysis**:
    *   Compute per-image IoU on the validation set using the optimal threshold.
    *   Calculate correlations between error (1 - IoU) and metadata features (Depth, Salt Coverage) to identify weaknesses.
8.  **Submission**:
    *   If the final validation mAP exceeds the threshold (0.7985), generate final test predictions using the optimized threshold.
    *   Encode predictions to RLE format and save to `submission.csv`.
