Based on the comprehensive analysis of the accumulated lessons, I propose the following **Multi-Task Depth-Regularized Noisy Student** strategy.

This solution addresses the core "Depth Paradox": explicit depth injection is critical for segmentation performance (Cite solution_lesson_node_00001), but depth metadata is missing at test time (Cite solution_lesson_node_00020). Previous attempts failed due to disconnected auxiliary heads (Cite solution_lesson_node_00062), weak signals in naive distillation (Cite solution_lesson_node_00032), or divergence in hard pseudo-labeling (Cite solution_lesson_node_00049).

My proposed structural innovation is to combine **Bernoulli Injection Masking** with a **Corrected Auxiliary Depth Head**. By forcing the encoder to predict depth from texture (Auxiliary Task) while simultaneously training the decoder to operate with and without explicit depth (Bernoulli Masking), we create a robust "Generalist" mode for the test set that is far superior to simple depth-dropout. This is then leveraged in a rigorous **Noisy Student** pipeline.

### Model: Multi-Task ResNet34-WideLinkNet

I propose a specialized architecture designed to extract depth from texture while retaining the ability to use explicit depth when available.

*   **Backbone:** **ResNet34** pretrained on ImageNet. This balances capacity and convergence speed (Cite solution_lesson_node_00012).
*   **Input Adaptation:** Modify the first convolutional layer to accept **1-channel input** by summing the original RGB weights. This avoids the inefficiency of data repetition (Cite solution_lesson_node_00028).
*   **Bottleneck (Structural Innovation):**
    *   **No Compression:** The full 512-channel feature map is passed to the decoder (Cite solution_lesson_node_00019).
    *   **Corrected Auxiliary Head:** A regression head (GlobalAvgPool $\rightarrow$ MLP $\rightarrow$ Scalar) is attached to the encoder output. Crucially, this head is **explicitly connected** to the return values and loss function, fixing the "silent disconnection" bug from previous experiments (Cite solution_lesson_node_00062). It predicts the true depth $z$ from the image features.
    *   **Conditional Injection:** A parallel branch projects the input depth scalar via a **Non-Linear MLP** (Cite solution_lesson_node_00029) and **concatenates** it with the encoder features (Cite solution_lesson_node_00037).
*   **Decoder:**
    *   **Wide-LinkNet:** Uses **Additive Skip Connections** (Cite solution_lesson_node_00008).
    *   **Width Correction:** Internal block width is calculated as `in_channels // 4` to prevent information bottlenecks (Cite solution_lesson_node_00023).

### Data

*   **Preprocessing:**
    *   **Spatial Alignment:** Pad all images from 101x101 to **128x128** using reflection padding to ensure divisibility by 32 (Cite solution_lesson_node_00034).
    *   **Normalization:** Normalize pixel values using **Standard ImageNet Statistics** (Cite solution_lesson_node_00025). Apply **Standard Scaling** to depth values (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Mandatory Non-Rigid:** Apply **ElasticTransform** with tuned parameters (`alpha` $\approx$ 120, `sigma` $\approx$ 6) to simulate organic salt plasticity (Cite solution_lesson_node_00055).
    *   **Conservative Rigid:** Apply **ShiftScaleRotate** with low probability ($p=0.2$) to preserve high-precision boundaries (Cite solution_lesson_node_00054).

### Training: Multi-Task Noisy Student Pipeline

I propose a stabilized three-stage pipeline.

*   **Stage 1: Supervised Multi-Task Training**
    *   **Bernoulli Injection Masking:** For the *Injection* branch, randomly replace the true depth with **0** (mean depth) with $p=0.5$.
    *   **Auxiliary Consistency:** The *Auxiliary Head* always trains to predict the **True Depth**, regardless of whether the Injection branch received True Depth or 0. This forces the encoder to learn intrinsic depth cues from the texture, strengthening the model's performance when explicit depth is missing.
    *   **Loss:** $L = \text{Sum}(\text{Lovasz}_{\text{per-image}} + \text{BCE}) + 0.1 \cdot \text{MSE}_{\text{depth}}$. Summing losses maintains gradient magnitude (Cite solution_lesson_node_00036).
    *   **Horizon:** 50 epochs (Cite solution_lesson_node_00006).

*   **Stage 2: Soft Pseudo-Label Generation**
    *   Use the Stage 1 model to predict on the **unlabeled test set**.
    *   **Input:** Image + **Injection Depth 0**.
    *   **Output:** **Soft Probability Maps**. Using soft labels prevents the divergence caused by hard thresholding (Cite solution_lesson_node_00049).

*   **Stage 3: Noisy Student Distillation**
    *   Train a new Student model from scratch on Combined Data (Labeled + Unlabeled).
    *   **Labeled Batch:** Input (Image + True Depth). Loss: Lovasz + BCE + MSE.
    *   **Unlabeled Batch:** Input (**Strongly Augmented** Image + Injection Depth 0). Target: Soft Pseudo-Labels. Loss: **BCE**.
    *   **Rationale:** The Student learns "Specialist" features from the labeled data and adapts to the test distribution via the "Generalist" guidance of the Teacher.

### Evaluation

*   **Inference:**
    *   Use the **Stage 3 Student Model**.
    *   **Input:** Image + **Injection Depth 0**.
    *   **Test-Time Augmentation (TTA):** Predict on the original image and a horizontally flipped version, averaging the probability maps (Cite solution_lesson_node_00002).
*   **Post-Processing:**
    *   **Threshold Optimization:** Perform a linear search on the validation set predictions to find the optimal binarization threshold that maximizes the mAP score (Cite solution_lesson_node_00033).
    *   **Formatting:** Center crop the 128x128 predictions back to 101x101 and convert to Run-Length Encoding (RLE).
