The strategy implements a robust 5-fold cross-validation pipeline using an EfficientNetV2-Medium backbone with a regression head to predict diabetic retinopathy severity. The training process utilizes a **Progressive Resizing** protocol: Phase 1 trains on 384x384 resolution images for 14 epochs to learn coarse features, followed by Phase 2 on 512x512 images for 6 epochs to refine fine-grained details. **Stochastic Weight Averaging (SWA)** is applied during Phase 2 to improve generalization. Inference is performed using an ensemble of the 5 fold models with **Test-Time Augmentation (TTA)** (horizontal flipping). The pipeline evaluates performance on a hold-out validation set using the Quadratic Weighted Kappa metric and performs failure analysis by correlating prediction errors with image meta-features. A submission file is generated only if the validation metric exceeds the specified threshold.
