Here is the implementation strategy:

1.  **Configuration Setup**: I will start by overriding the default configuration in `Config` to enable `DEBUG` mode (which uses a small subset of data), set `EPOCHS` to 1, and reduce `NUM_FOLDS` to 1. This ensures the code runs quickly within the time limit.
2.  **Data Pipeline Verification**: I will instantiate the data loaders using `get_dataloaders` and fetch a single batch to verify that images and labels have the correct tensor shapes and data types.
3.  **Model Training**: I will execute `run_fold` for the first fold of the CNN model. This demonstrates the training loop, mixed-precision scaling, and checkpoint saving (including SWA logic).
4.  **Inference & Submission**: I will call `predict_ensemble`, which will pick up the checkpoint generated in the previous step, perform Test-Time Augmentation (TTA), and generate a `submission.csv`.
5.  **Metric Validation**: I will explicitly test the `quadratic_weighted_kappa` function with known dummy inputs to ensure the scoring metric behaves correctly.
6.  **Assertions**: Throughout the script, I will use `assert` statements to validate file existence, tensor shapes, and data integrity.
