The following Python script demonstrates the complete pipeline for the Diabetic Retinopathy Severity Prediction task using the provided library files.

### Strategy Outline
1.  **Configuration Setup**: We override the default `Config` parameters to adapt the execution for a quick demonstration. This includes reducing the image size, batch size, number of epochs, and number of folds. We also enable debug mode and set a specific working directory.
2.  **Data Preparation**: To ensure the training loop runs without statistical errors (like missing classes in Stratified K-Fold), we create small, balanced subsets of the original metadata and save them to the working directory. We then redirect the `Config` file paths to these new subsets.
3.  **Training Demonstration**: We utilize the `run_training` function from `library.train` to train a lightweight `resnet18` model. This demonstrates the interaction between the `RetinopathyDataset`, `RetinopathyModel`, and the training engine.
4.  **Inference Demonstration**: We use the `predict` function from `library.inference` to generate predictions on a test subset using the models trained in the previous step. This showcases the ensemble logic and Test-Time Augmentation (TTA).
5.  **Verification**: Throughout the script, we use assertions to verify data shapes, model output dimensions, metric correctness, and the existence of output files.
