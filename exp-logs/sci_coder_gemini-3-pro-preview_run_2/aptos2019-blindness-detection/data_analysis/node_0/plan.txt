This script performs a comprehensive Exploratory Data Analysis (EDA) on the Diabetic Retinopathy dataset. It begins by setting reproducible seeds and loading the training metadata. It analyzes the target variable (`diagnosis`) to report class distributions and imbalance. Then, it utilizes parallel processing to efficiently extract metadata (dimensions, channels, pixel statistics) from the image files. Finally, it aggregates these statistics to report global image properties and analyzes the relationship between image meta-features (like size and aspect ratio) and the diagnosis severity.
