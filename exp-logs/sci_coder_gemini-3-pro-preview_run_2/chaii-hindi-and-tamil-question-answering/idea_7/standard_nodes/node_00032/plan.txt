The implementation strategy follows a standard supervised learning pipeline adapted for the specific constraints of the task.

1.  **Initialization**: We set random seeds for reproducibility and configure the device (GPU) using the provided `Config`.
2.  **Data Loading**: We utilize the provided `get_data` function to load and tokenize the training and validation sets. This function handles the sliding window mechanism required for long contexts. We wrap these in `QADataset` and `DataLoader` objects.
3.  **Training**: We initialize the `XLMRobertaForMultiTaskQA` model and optimize it using `AdamW` with a linear learning rate scheduler. The training loop runs for the configured number of epochs, utilizing the `train_one_epoch` engine function which supports mixed-precision training.
4.  **Validation & Evaluation**: We run inference on the validation set to obtain logits. These are post-processed into text spans using the `postprocess_predictions` library function. We then compute the Word-level Jaccard score against the ground truth in the metadata.
5.  **Failure Analysis**: We calculate the correlation between the prediction error (1 - Jaccard) and input features (Context Length, Question Length) to identify potential biases or weaknesses.
6.  **Submission**: If the calculated validation metric exceeds the specified threshold, we proceed to load the test set, generate predictions, and save the `submission.csv` file.
