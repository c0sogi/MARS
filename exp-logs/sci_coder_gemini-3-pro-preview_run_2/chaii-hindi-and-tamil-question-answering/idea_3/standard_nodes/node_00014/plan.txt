The issue is that the directory specified by `Config.WORKING_DIR` (i.e., `./working/idea_3`) is not created before the script attempts to save the model checkpoint, causing a `RuntimeError`. While the `Config` class includes directory creation in its `__init__` method, the class is used statically in `runfile.py` (i.e., it is never instantiated), so that logic is never executed. To fix this, I will add `os.makedirs(Config.WORKING_DIR, exist_ok=True)` explicitly at the beginning of the `run_training` function in `runfile.py`.
