The implementation strategy involves the following steps:
1.  **Setup**: Define input (`./input`) and output (`./metadata`) directories. Ensure the output directory exists.
2.  **Data Loading**: Read `train.csv` and `test.csv` using pandas.
3.  **Splitting**: Perform a train-validation split on `train.csv` using `GroupShuffleSplit` with a fixed random state (42) and an 80:20 ratio. The split is grouped by the `context` column to ensure that all questions derived from the same text passage remain in the same subset, preventing data leakage.
4.  **Metadata Generation**: Save the resulting training, validation, and test dataframes as CSV files in the `./metadata` directory. These files serve as the metadata/dataset for downstream tasks.
5.  **Verification**:
    *   Reload the generated files.
    *   Print summary statistics (sample counts, language distribution).
    *   **Leakage Check**: Assert that the set of contexts in the training set and validation set are mutually exclusive.
    *   **Ratio Check**: Verify the split ratio is approximately 80:20.
    *   **File Path Check**: Scan columns for file-path-like patterns. If found, verify that referenced files exist relative to `./input`. (Note: This is likely not applicable for this text-based dataset but is included for compliance).
