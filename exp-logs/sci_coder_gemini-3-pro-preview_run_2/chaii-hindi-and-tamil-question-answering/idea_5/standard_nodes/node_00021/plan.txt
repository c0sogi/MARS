    *   Prepare features using `prepare_train_features`.

3.  **Ensemble Validation**: After training, I will load the validation set (`metadata/val.csv`), process it into features, and run inference using an ensemble of the 3 trained models. I will manually aggregate the logits from all models, apply the sliding window post-processing logic to extract answer spans, and compute the Jaccard metric.
4.  **Failure Analysis**: I will calculate the correlation between the prediction error (1 - Jaccard) and the lengths of the context and question to identify performance bottlenecks.
5.  **Submission**: If the validation metric exceeds the threshold (0.2522), I will use the `Predictor` class to generate the final submission for the test set.
