### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and define file paths. We will use the pre-generated metadata at `./metadata/train.csv`.
2.  **Target Variable Analysis**: Load the training metadata and analyze the distribution of the `label` column (Cover vs. Stego) to check for class imbalance.
3.  **Image Data Analysis (Sampling)**:
    *   Since the training set contains ~224,000 images, processing all of them is computationally expensive. We will sample 5,000 images (stratified by class) to perform the heavy lifting.
    *   For each sampled image, we will extract:
        *   **Dimensions**: Width, Height, and Aspect Ratio.
        *   **Channels**: Number of color channels.
        *   **Pixel Statistics**: Mean and Standard Deviation of pixel values.
        *   **File Metadata**: File size in bytes.
    *   We will aggregate these statistics to report global distributions.
4.  **Feature/Signal Relationships**:
    *   We will treat the extracted image properties (File Size, Dimensions, Mean Intensity) as meta-features.
    *   We will calculate the Point Biserial correlation (or Pearson) between these numerical meta-features and the binary target `label`.
    *   We will compare the average file size between Cover and Stego images to see if the embedding process alters the file size significantly.
5.  **Reporting**: The results will be printed to the standard output, organized into the specific sections requested, with floats formatted to 4 decimal places.
