To address the steganography detection task, I propose a **Baseline SRM-EfficientNet** approach. This solution prioritizes computational efficiency and implementation simplicity while leveraging domain-specific feature extraction (residuals) required for steganalysis.

### Model
The architecture is a lightweight Convolutional Neural Network (CNN) that fuses a steganalysis-specific "stem" with a standard, pre-trained backbone.
*   **SRM Stem (Residual Extractor):** The network begins with a fixed, non-trainable 2D convolution layer. This layer is initialized with 30 Spatial Rich Model (SRM) high-pass filters (kernel size 5x5). These filters suppress the high-level image content (edges, textures) and expose the low-level noise residuals where steganographic signals hide.
*   **Feature Adaptation:** A trainable convolutional layer follows the stem to project the 30-channel residual maps into 3 channels. This allows the residuals to be compatible with standard RGB-input backbones.
*   **Backbone:** An **EfficientNet-B0** initialized with ImageNet weights serves as the primary feature extractor. EfficientNet-B0 is chosen for its superior speed-to-accuracy ratio and low parameter count compared to ResNets or larger EfficientNets.
*   **Classification Head:** The standard final fully connected layer is replaced with a single linear output neuron to predict the binary probability of the image containing a hidden message.

### Data
*   **Input Handling:** Images are loaded in their native resolution (512x512) without resizing, as resizing destroys the fragile steganographic signal. Pixel values are normalized to the [0, 1] range.
*   **Class Balancing:** The training set is highly imbalanced (1 Cover vs. 3 Stego variants). A balanced sampler is used during training: for every Cover image loaded, one of its three corresponding Stego versions (JMiPOD, JUNIWARD, or UERD) is randomly selected. This ensures a 50/50 class distribution in every batch.
*   **Augmentation:** To improve robustness, "D4" augmentations (rotations of 0, 90, 180, 270 degrees and horizontal/vertical flips) are applied randomly during training. This exploits the rotational invariance of natural image statistics versus the grid-aligned nature of JPEG steganography.

### Training
*   **Loss Function:** Binary Cross Entropy with Logits Loss (`BCEWithLogitsLoss`) is used as the objective function.
*   **Optimizer:** The AdamW optimizer is employed for its ability to handle weight decay effectively, preventing overfitting on the noise residuals.
*   **Scheduler:** A Cosine Annealing learning rate scheduler is utilized to converge quickly, starting with a warm-up phase to stabilize the pre-trained weights.
*   **Precision:** Mixed Precision (FP16) training is enabled to maximize throughput on the NVIDIA A100 GPU and reduce memory usage, allowing for larger batch sizes.

### Evaluation
*   **Inference:** Predictions are generated on the test set using the trained model.
*   **Test-Time Augmentation (TTA):** To boost the weighted AUC score without significant architectural complexity, a simple 2-view TTA is applied: the model predicts on the original image and its horizontally flipped version. The final score is the average of these two predictions.
*   **Metric Calculation:** The validation set is scored using the custom Weighted AUC metric (weighting the 0.0-0.4 TPR region 2x) to monitor performance and save the best checkpoint.
