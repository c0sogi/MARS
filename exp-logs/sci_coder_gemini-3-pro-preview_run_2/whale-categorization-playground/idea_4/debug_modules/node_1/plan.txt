To address the `RuntimeError` caused by a model architecture mismatch, I will implement two targeted fixes:

1.  **Fix Default Argument Binding in Inference**: The `WhaleModel` class uses `Config.MODEL_NAME` as a default argument, which is bound to the value `"tf_efficientnet_b4"` at import time. The demo script changes `Config.MODEL_NAME` to `"tf_efficientnet_b0"` at runtime, but the inference script initializes the model without arguments, causing it to revert to the stale default (B4) instead of the configured B0. I will modify `library/inference.py` to explicitly pass `model_name=Config.MODEL_NAME` during instantiation.
2.  **Prevent Stale Checkpoint Loading**: The demo training loop failed to save the new model because the validation score (0.0) did not exceed the initial best score (0.0). Consequently, the inference step loaded a pre-existing "stale" checkpoint (likely a ResNet) found in the directory. I will modify `runfile.py` to delete any existing checkpoint file before training starts. This ensures the fallback logic ("Saving manually") triggers correctly if the training loop doesn't save, guaranteeing the correct model weights are used.
