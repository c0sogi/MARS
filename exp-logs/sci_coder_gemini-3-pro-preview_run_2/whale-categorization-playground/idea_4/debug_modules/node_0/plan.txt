The following script demonstrates the usage of the provided Whale Species Prediction library. It performs the following steps:
1.  **Configuration**: Overrides default configuration for a fast, low-resource demonstration (Debug mode, small images, fewer epochs).
2.  **Data Loading**: Uses `get_dataloaders` to process a small subset of images and create PyTorch loaders.
3.  **Model Initialization**: Instantiates the `WhaleModel` (EfficientNet backbone with ArcFace head).
4.  **Forward Pass Verification**: Validates model output shapes for both training (logits) and inference (embeddings).
5.  **Loss Calculation**: Verifies `ArcFaceLoss` computation.
6.  **Re-ranking**: Demonstrates the k-reciprocal re-ranking function on dummy features.
7.  **Training Loop**: Runs a single epoch of training using `WhaleEngine`.
8.  **Inference**: Generates a submission file using the `generate_predictions` pipeline.
9.  **Metric Check**: Validates the MAP@5 calculation logic.
