To fix this, I will modify `predict_test` to respect `Config.DEBUG` and slice the test dataframe to `Config.DEBUG_SAMPLES`, ensuring the list of filenames matches the number of predictions generated. This applies the principle of ensuring data structures align with the actual data dimensions available in the current context (Cite debug_lesson_1).
