    *   I will load the best saved model and the validation dataset defined in `./metadata/val.csv`.

    *   I will print the `Final Validation Metric` with full precision.
4.  **Failure Analysis**:
    *   I will iterate through the validation images to extract metadata (Width, Height, Aspect Ratio, Pixel Intensity).
    *   I will calculate the "Error Magnitude" for each sample (defined as `1.0 - (1/rank)` if the target is in the top 5, else `1.0`).
    *   I will compute and print the Pearson correlation between the error magnitude and the extracted features to identify systematic weaknesses.
5.  **Submission**:
    *   I will check if the validation metric exceeds the threshold `0.756541`.
    *   If passed, I will clear any stale embedding cache files (to ensure the new model is used) and call `run_inference()` from `library.inference` to generate the `submission.csv`.
