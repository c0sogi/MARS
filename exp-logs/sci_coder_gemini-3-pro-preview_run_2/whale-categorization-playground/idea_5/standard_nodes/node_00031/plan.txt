Implementation strategy:
1.  **Setup & Initialization**: Import necessary modules and set random seeds using `library.utils.seed_everything`. Initialize the `Config` and set the device (GPU).
2.  **Data Loading**: Use `library.dataset.get_loaders` with `load_cached_data=True` to efficiently load the training, validation, gallery, and test dataloaders.
3.  **Model Configuration**: Instantiate the `WhaleModel` (EfficientNet-B4 backbone) and `ArcFaceLoss`. Move them to the GPU.
4.  **Optimization Setup**: Configure the `AdamW` optimizer (optimizing both model and loss parameters) and `ReduceLROnPlateau` scheduler to maximize the MAP@5 metric.
5.  **Training Loop**: Implement a custom training loop using `library.engine.train_fn` and `library.engine.eval_fn`. This allows control over the number of epochs (limited to 10 for a fast baseline) and avoids the unconditional submission generation present in the provided `run_training` function. The loop will handle early stopping and checkpointing the best model based on Validation MAP@5.
6.  **Final Evaluation**: Load the best model checkpoint and compute the final MAP@5 score on the validation set. Print this metric in the required format.
7.  **Failure Analysis**: Perform analysis on the validation set by extracting features and computing the correlation between the error magnitude (defined as `1.0 - Average Precision`) and the model's confidence (Max Cosine Similarity).
8.  **Conditional Submission**: Check if the final validation metric exceeds the threshold (0.756541). If it does, generate the submission file using `library.engine.generate_submission`.
