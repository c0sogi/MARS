The `_pickle.UnpicklingError` occurs because the checkpoint file contains a NumPy scalar (`best_map`), which is blocked by default in newer PyTorch versions where `torch.load` enforces `weights_only=True` for security. Since the checkpoint is a trusted local file generated by the training script, the fix is to explicitly set `weights_only=False` in `runfile.py` to allow loading the full checkpoint dictionary, consistent with how it is handled in `library/train.py` and `library/inference.py`.
