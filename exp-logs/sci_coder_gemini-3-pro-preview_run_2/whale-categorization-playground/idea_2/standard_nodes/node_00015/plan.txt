The `KeyError: np.int64(-1)` arises in the `Trainer.predict` method when attempting to decode predicted integer labels back into string IDs for the submission file. The `gallery_loader` (used for retrieval) includes the "new_whale" class, which the `WhaleDataset` assigns the sentinel value `-1` because it is excluded from the primary `label_encoder` used for ArcFace training. However, the `id_encoder` (the inverse of `label_encoder`) does not contain a key for `-1`. To resolve this, I will explicitly add the mapping `{-1: "new_whale"}` to `self.id_encoder` in the `Trainer.__init__` method, ensuring that the sentinel value can be successfully mapped back to its string label during inference. This applies the lesson on explicitly mapping sentinel values in inverse encoders (Cite debug_lesson_3).
