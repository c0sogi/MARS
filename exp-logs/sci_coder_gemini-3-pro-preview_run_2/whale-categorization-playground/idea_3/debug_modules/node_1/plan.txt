The `RuntimeError: selected index k out of range` occurs because the code attempts to find the top 50 nearest neighbors (`k=50`) in a dataset that, during debug mode, only contains 30 images (`Config.debug_sample_size = 30`). This causes the dimension of the similarity matrix (30) to be smaller than `k` (50).

To fix this, I will update `library/trainer.py` to dynamically set `k` as the minimum of the desired count (50) and the actual size of the gallery (the number of columns in the similarity matrix). I will also apply a similar safeguard in `library/inference.py`, where `Config.knn_k` (100) would otherwise cause the same crash during the inference phase of the demonstration run.
