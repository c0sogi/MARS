The strategy for the implementation of `runfile.py` is as follows:

1.  **Environment & Configuration**: Initialize the environment by setting random seeds for reproducibility using `seed_everything` from the provided `Config`. The default configuration (15 epochs, batch size 24) is suitable for the available hardware (A100 GPU) and time constraints.
2.  **Training**: Instantiate the `Trainer` class and execute the `fit()` method. This will train the `WhaleModel` using `ArcFaceLoss` on the training set and validate it against the validation set. The best model will be automatically saved to `best_model.pth`.
3.  **Metric Reporting**: After training, retrieve the best validation score (`MAP@5`) from the trainer and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Load the best saved model and switch to evaluation mode.
    *   Extract embeddings for the validation set and the gallery (training set) using the `extract_features` helper.
    *   Compute the cosine similarity matrix between validation queries and gallery images.
    *   For each validation image, determine the rank of the true identity in the retrieved gallery list. Calculate the error magnitude (defined as `1.0 - Score`, where Score is the reciprocal rank if in top-5, else 0).
    *   Load metadata to retrieve image properties (Width, Height) and class frequencies.
    *   Calculate and print the Pearson correlation coefficient between the error magnitude and these features (Width, Height, Aspect Ratio, Class Frequency) to identify sources of error.
5.  **Submission Generation**: Compare the final validation metric against the threshold (0.638101). If the metric exceeds the threshold, invoke `generate_submission(load_cached_data=True)` to produce the `submission.csv` file using k-reciprocal re-ranking.
