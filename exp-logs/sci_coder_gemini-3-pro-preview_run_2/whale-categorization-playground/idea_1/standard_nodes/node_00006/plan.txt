2.  **Implement Metric-Based Validation**: I will modify the training engine to support a custom validation callback. Instead of monitoring the contrastive loss (which is unreliable for sparse datasets), I will calculate the MAP@5 score using KNN retrieval on the validation set at the end of every epoch and use this metric to drive Early Stopping and Model Checkpointing (Cite `solution_lesson_node_00002`).
3.  **Ensure Cache Coherency**: I will update the inference and evaluation calls to explicitly disable loading from cache (`load_cached_data=False`) during the validation and final submission phases. This ensures that the embeddings are generated using the latest trained model weights rather than stale files from previous runs (Cite `solution_lesson_node_00003`).
4.  **Refine Inference Logic**: I will update the inference pipeline to exclude `new_whale` from the reference database, ensuring that "new_whale" predictions are solely driven by the distance threshold rather than retrieval of a generic class.
