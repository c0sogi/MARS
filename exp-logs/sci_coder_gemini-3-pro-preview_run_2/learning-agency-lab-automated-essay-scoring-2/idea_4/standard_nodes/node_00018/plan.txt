The implementation strategy for the `runfile.py` script is as follows:

1.  **Configuration & Setup**: Import the necessary modules from the provided library files. Dynamically override `Config` parameters to enable a "fast baseline" mode suitable for the 2-hour time limit. This involves setting `DEBUG=True`, reducing the sample size to 2000, and limiting training to 2 epochs.
2.  **Lexical Branch Execution**: Call `run_tfidf_ridge` with `debug=True` and `load_cached_data=False`. This trains the TF-IDF + Ridge model on the data subset and returns dataframes containing the lexical predictions (`ridge_pred`).
3.  **Semantic Branch Execution**: Call `run_semantic_training` with `debug=True` and `load_cached_data=False`. This trains the DeBERTa-v3-Large model on the same data subset and returns dataframes containing the semantic predictions (`semantic_pred`).
4.  **Data Merging**: Merge the predictions from both branches into unified training, validation, and test dataframes using `essay_id` as the key.
5.  **Meta-Learner Training**: Train a Ridge Regression meta-learner on the Out-Of-Fold (OOF) predictions from the training set to learn the optimal weighting between lexical and semantic signals.
6.  **Validation & Threshold Optimization**: Generate continuous predictions for the hold-out validation set. Use the `optimize_thresholds` function (Nelder-Mead) to find the optimal decision boundaries that maximize the Quadratic Weighted Kappa (QWK) on the validation set.
7.  **Failure Analysis**: Compute the final validation metric. Calculate the correlation between the absolute prediction error and the essay word count to identify potential length bias.
8.  **Submission Generation**: Compare the final validation QWK against the required threshold (0.8307...). If the condition is met, apply the optimized thresholds to the test set predictions and generate the `submission.csv` file.
