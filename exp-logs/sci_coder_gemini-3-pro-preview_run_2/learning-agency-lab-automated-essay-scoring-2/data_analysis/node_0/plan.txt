Here is the implementation strategy and the complete Python script for the Exploratory Data Analysis.

### Implementation Strategy
1.  **Environment Setup**: Import necessary libraries (`pandas`, `numpy`, `re`, `collections`) and set random seeds for reproducibility.
2.  **Data Loading**: Load the training data specifically from `./metadata/train.csv` to ensure the analysis is performed on the designated training split without data leakage.
3.  **Target Variable Analysis**: Analyze the `score` column. Since the scores are discrete integers (1-6), we will treat this as a classification task for distribution analysis (class balance) and as a numerical variable to check for skewness and kurtosis, which helps in understanding if regression approaches are viable.
4.  **Text Data Analysis**:
    *   **Feature Engineering**: Generate meta-features: `char_count` (length of string) and `word_count` (using regex tokenization).
    *   **Length Statistics**: Report descriptive statistics for these meta-features.
    *   **Vocabulary Analysis**: specific analysis on unique words to estimate vocabulary size and diversity.
5.  **Feature/Signal Relationships**:
    *   **Correlation**: Calculate Pearson and Spearman correlations between text length metrics and the essay score.
    *   **Grouped Analysis**: Calculate the average word count per score category to see if longer essays tend to score higher.
6.  **Formatting**: Ensure all outputs are printed in distinct, capitalized sections with floating-point numbers formatted to 4 decimal places.
