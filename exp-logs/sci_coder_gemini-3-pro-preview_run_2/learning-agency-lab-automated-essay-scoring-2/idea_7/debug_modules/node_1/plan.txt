The issue is that the `FeatureExtractor` class loads the full datasets in its `__init__` method without checking the global `Config.DEBUG` flag. As a result, even when the environment is set to debug mode (expecting only 50 samples), the extractor processes all 12,460 rows, causing the assertion error `Expected 50 samples in Debug mode, got 12460`.

To fix this, I will modify `library/feature_engineering.py` to check `Config.DEBUG` immediately after loading the dataframes and subsample them to 50 rows if the flag is set. This ensures consistency with the other components of the pipeline.
