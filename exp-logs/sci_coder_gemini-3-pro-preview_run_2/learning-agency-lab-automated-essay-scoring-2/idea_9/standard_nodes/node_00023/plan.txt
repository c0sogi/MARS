To implement the end-to-end orchestration script, I will adopt a strategy that balances the need for high performance with the strict time constraint of one hour.

**Strategy:**
1.  **Data Subsetting for Speed**: The full dataset combined with a 5-fold Cross-Validation of a Large Language Model (DeBERTa-Large) would exceed the 1-hour limit. To address this, I will create a consistent stratified subset of the training and validation data (approximately 6000 samples total). This ensures that all branches of the heterogeneous architecture (Semantic, Lexical, Morphological) train on the exact same data distribution, preventing shape mismatches during stacking.
2.  **Configuration Overrides**: I will override the default `Config` parameters within the script. Specifically, I will point the data paths to the newly created subsets, reduce `epochs` to 1 (sufficient for a strong baseline), and disable `use_awp` (Adversarial Weight Perturbation) to save computational overhead.
3.  **Pipeline Execution**: The script will sequentially execute the Semantic branch (DeBERTa), the Classic branches (Ridge Regression on N-grams), and finally the Stacking Meta-Learner (LightGBM).
4.  **Validation and Analysis**: After training, I will compute the final Quadratic Weighted Kappa (QWK) on the validation set. I will also perform the required failure analysis by correlating the prediction errors with linguistic features (e.g., word count, sentence length) to identify systematic weaknesses.
5.  **Conditional Submission**: The script will check if the validation QWK exceeds the target threshold (`0.8307992749024942`). If successful, it will optimize decision thresholds using the Nelder-Mead algorithm, generate predictions for the full test set, and save the `submission.csv`.
