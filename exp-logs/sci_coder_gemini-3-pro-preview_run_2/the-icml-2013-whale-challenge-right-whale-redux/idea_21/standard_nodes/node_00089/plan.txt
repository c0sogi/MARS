The `IndexError` is caused by a **stale cache collision** (Cite debug_lesson_4). The `DataLoader` expects a dataset size matching the current dataframe (100 samples), but the caching mechanism blindly loads an existing `.npy` file from a previous run that contains a different number of samples (32). This mismatch causes the sampler to request indices (e.g., 35) that exist in the current configuration but are out of bounds in the loaded cached array.

To fix this, I will update `load_dataset_data` in `library/dataset.py` to explicitly validate that the length of the loaded cached data matches the length of the input dataframe. If the lengths differ, the code will treat it as a cache miss and trigger re-computation.
