This script demonstrates the usage of the provided Right Whale Detection library. It validates the core components (Utils, Dataset, Model, Training Loop) and executes the full training pipeline in a highly optimized "Debug" mode to ensure it completes quickly within the runtime limits.

The strategy involves:
1.  **Configuration Override**: Modifying the global `Config` class to enable `DEBUG` mode (using only a small subset of data) and reducing training epochs to 1.
2.  **Component Validation**: Systematically instantiating and testing `MetricMonitor`, `WhaleDataset`, `WhaleEfficientNet`, and Mixup augmentation logic with assertions to verify correctness.
3.  **Pipeline Execution**: Running the full `run_training()` function to demonstrate end-to-end execution, resulting in a `submission.csv`.
