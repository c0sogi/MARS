The following implementation orchestrates the training of a heterogeneous ensemble (EfficientNet-B0 and ResNet-34) on the Right Whale Detection task. It leverages the provided library modules to load data, train models using a weighted sampler to handle class imbalance, and perform inference. The script includes a custom failure analysis routine that correlates prediction errors with spectrogram statistics (mean, std, max) on the validation set. Finally, it evaluates the ensemble's performance against the specified AUC threshold and, if successful, generates and saves the submission file for the test set.
