The validation failure was caused by data leakage: the meta-learner was trained on Out-Of-Fold (OOF) predictions that included the validation set, and then evaluated on that same validation set. This violates the principle of using a strictly segregated hold-out set for final evaluation.

To fix this, I will modify `runfile.py` and `library/inference.py` to:
1.  **Segregate Data:** Train base models and generate OOF predictions using **only** the training set (`train.csv`). Cite debug_lesson_12.
2.  **Unbiased Evaluation:** Evaluate the ensemble on the hold-out validation set (`val.csv`) by generating features via bagging (averaging predictions from models trained on the training folds) and passing them to the meta-learner.
3.  **Refactor Inference:** Update the `Predictor` class to support generating bagged features for any dataset (enabling validation set processing) and to allow passing a pre-trained meta-learner to the submission generation step.
