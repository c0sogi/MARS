Based on the comprehensive analysis of the provided lessons, I propose the **Objective-Diverse Heterogeneous Stacked Ensemble**.

This strategy introduces a structural evolution by resolving the conflict between **Ranking** (AUC) and **Calibration** (Loss) identified in Lessons 00066 and 00055. Instead of choosing a single convergence criterion, we will construct the ensemble using base learners explicitly optimized for *different* objectives. This provides the meta-learner with a rich feature set containing both "sharp discriminators" (high AUC, potentially overconfident) and "reliable estimators" (low Loss, well-calibrated), maximizing the stack's performance.

### Model
We will construct a **Two-Stage Stacked Generalization Ensemble** composed of **20 Base Learners** (4 Configurations $\times$ 5 Folds).

**Level 0: Objective-Diverse Base Learners**
We will employ two robust "Legacy" architectures, each trained with two distinct convergence criteria.
1.  **Architecture A: EfficientNet-B0 (Noisy Student)**
    *   **Initialization:** `ns_jft_in1k` weights. These leverage massive pre-training and outperform standard ImageNet weights **Cite solution_lesson_node_00054**.
    *   **Adaptation:** First layer modified to **1-channel** via weight averaging **Cite solution_lesson_node_00001**.
    *   **Pooling:** **Generalized Mean (GeM) Pooling** to detect transient calls **Cite solution_lesson_node_00017**.
2.  **Architecture B: ResNet-34 (ImageNet)**
    *   **Role:** Provides deep residual learning biases to decorrelate errors from the MBConv-based EfficientNet **Cite solution_lesson_node_00053**.
    *   **Adaptation:** 1-channel input, GeM Pooling.

**Configuration Matrix (The Structural Innovation):**
*   **Subset 1 (Rank-Specialists):** EfficientNet-B0 and ResNet-34 trained with **Early Stopping on Validation AUC**. These models maximize discrimination power **Cite solution_lesson_node_00066**.
*   **Subset 2 (Calibration-Specialists):** EfficientNet-B0 and ResNet-34 trained with **Early Stopping on Validation Loss**. These models prioritize probability calibration, enhancing "stackability" **Cite solution_lesson_node_00055**.

**Level 1: Meta-Learner**
*   A **Logistic Regression** model trained on the concatenated Out-Of-Fold (OOF) probabilities from all 4 configurations. It learns to balance the sharp boundaries of the Rank-Specialists with the reliability of the Calibration-Specialists.

### Data
We strictly adhere to the "Golden Recipe" for signal fidelity, correcting previous implementation flaws.
1.  **Spectrogram Generation:**
    *   **FFT Parameters:** `n_fft=1024` (High Freq Res) and `hop_length=64` (High Time Res) to prevent aliasing and resolving short contours **Cite solution_lesson_node_00008**, **Cite solution_lesson_node_00016**.
    *   **Mel Filterbank:** `n_mels=128`, `normalized=False` to preserve environmental spectral tilt **Cite solution_lesson_node_00022**.
    *   **Dynamic Range:** Apply **`top_db=80`** clamping to fix the noise floor **Cite solution_lesson_node_00062**.
2.  **Preprocessing:**
    *   **Native Resolution:** Inputs fed at generated dimensions (~128x63). **No resizing** to 224x224 **Cite solution_lesson_node_00031**.
    *   **Instance Standardization:** Zero-Mean, Unit-Variance applied per clip **Cite solution_lesson_node_00025**.
3.  **Augmentation:**
    *   **Aggressive SpecAugment:** `freq_mask_param=20`. This forces the model to learn robust temporal dependencies for narrow-band signals **Cite solution_lesson_node_00071**. Mixup is excluded **Cite solution_lesson_node_00018**.

### Training
We implement a **5-Fold Stratified Cross-Validation** workflow.
1.  **Sampling:** **WeightedRandomSampler** to balance classes in every batch **Cite solution_lesson_node_00004**.
2.  **Batch Size:** Maximize to **128** for stability **Cite solution_lesson_node_00004**.
3.  **Optimization:**
    *   **Optimizer:** AdamW with **Low Weight Decay (`1e-4`)** to accommodate Noisy Student weights **Cite solution_lesson_node_00039**.
    *   **Scheduler:** Cosine Annealing to ensure effective fine-tuning **Cite solution_lesson_node_00046**.
4.  **Convergence (Objective Diversity):**
    *   For **Rank-Specialists**, monitor **Val AUC**.
    *   For **Calibration-Specialists**, monitor **Val Loss**.
    *   **Patience:** Strict (e.g., 5 epochs) to prevent overfitting to fold noise **Cite solution_lesson_node_00072**.

### Evaluation
We utilize a **Bagged-Stacking** protocol **Cite solution_lesson_node_00061**.
1.  **Base Prediction:** For the Test set, generate predictions from all 20 trained models (4 Configs $\times$ 5 Folds).
2.  **Bagging:** Average the 5 fold-predictions for each configuration to produce 4 robust probability vectors (`EffNet_AUC`, `ResNet_AUC`, `EffNet_Loss`, `ResNet_Loss`).
3.  **Stacking:** Feed these bagged probabilities into the Level 1 Logistic Regression model to generate the final submission.
