The issue is a `AttributeError` caused by a missing configuration parameter `TIME_MASK_PARAM` in the `Config` class, which is required by the `WhaleDataset` class for time masking augmentation. This is a case of configuration desynchronization where a dependency was added to the logic without updating the central configuration (Cite debug_lesson_9). To fix this, I will add `TIME_MASK_PARAM` to `library/config.py` with a default value of 20, matching the existing frequency masking parameter.
