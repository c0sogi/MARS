This script demonstrates the end-to-end pipeline for the Right Whale Detection task using the provided library modules. It covers configuration setup, data preparation (using a subset for speed), model training, inference, pseudo-labeling, and ensemble submission generation.

**Implementation Strategy:**
1.  **Configuration & Setup**: Initialize the `Config` class with debug settings (1 epoch, small batch size). Create a temporary working directory.
2.  **Data Subsampling**: To ensure the demonstration runs quickly (< 1 hour), we create "mini" versions of the training, validation, and test metadata files containing only a few samples. We update the configuration object to point to these mini-datasets.
3.  **Data Loading**: Demonstrate `get_dataloaders` to create PyTorch DataLoaders for training and validation. Verify batch shapes.
4.  **Model Initialization**: Instantiate the `WhaleClassifier` (using `resnet34` for speed/compatibility).
5.  **Training**: Set up the `Trainer` with an optimizer and scheduler, then run `trainer.fit()` for one epoch. This produces model checkpoints.
6.  **Inference**: Use the trained model to predict on the test set via `infer_on_test`.
7.  **Pseudo-Labeling**: Generate pseudo-labels from the test predictions using `generate_pseudo_labels`.
8.  **Ensembling**: Simulate the existence of Out-Of-Fold (OOF) predictions and test predictions for multiple folds (required by the ensemble module). Then, run `load_oof_features`, `train_meta_learner`, and `generate_submission` to produce the final CSV.
