My implementation strategy is as follows:

1.  **Configuration**: Initialize the `Config` class, overriding `num_epochs` to 3 to ensure the pipeline completes within the time limit while maintaining sufficient convergence for a baseline. Set up logging and random seeds.
2.  **Round 1 (Supervised Training)**: Iterate through the 5 folds and 2 model architectures (EfficientNet-B0, ResNet-34). Train them on the original labeled dataset using the provided `Trainer` class. Save the "Best AUC" checkpoints.
3.  **Pseudo-Labeling**: Load the Round 1 checkpoints and perform inference on the test set. Average the predictions and generate pseudo-labels for samples with high confidence ($p > 0.95$ or $p < 0.05$).
4.  **Round 2 (Semi-Supervised Training)**: Retrain the models on an expanded dataset containing both the original labeled data and the pseudo-labeled test data. Crucially, use the original validation splits to prevent leakage.
5.  **OOF & Test Inference**: After training each fold in Round 2, load the best saved checkpoints and generate:
    *   **OOF Predictions**: On the validation fold (saved to `./working/idea_20/oof`).
    *   **Test Predictions**: On the test set (saved to `./working/idea_20/preds`).
6.  **Ensembling**: Use `library.ensemble` to load the Round 2 OOF and Test features. Train a Logistic Regression Meta-Learner on the OOF features to learn optimal blending weights.
7.  **Validation & Failure Analysis**: Calculate the global ROC AUC on the OOF predictions as the final validation metric. Perform failure analysis by correlating prediction errors with audio signal properties (Duration, RMS) extracted from the validation set.
8.  **Submission**: If the final validation AUC exceeds the strict threshold (0.9998881660199745), generate the final `submission.csv` using the Meta-Learner.
