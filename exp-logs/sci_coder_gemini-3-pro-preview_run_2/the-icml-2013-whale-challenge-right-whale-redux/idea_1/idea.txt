To establish a robust and highly efficient baseline, I propose a **ResNet-18 Convolutional Neural Network (CNN)** trained on **Log-Mel Spectrograms**. This approach adapts the conceptual foundation of image-based audio classification (Model 1) but utilizes a ubiquitous, lightweight architecture and standard preprocessing to maximize reliability and training speed.

### Model
The core architecture is a **ResNet-18**, a widely adopted convolutional neural network known for its balance between computational efficiency and performance.
- **Backbone:** The model utilizes the ResNet-18 architecture, which employs residual connections to facilitate effective gradient flow and convergence.
- **Adaptation:** The first convolutional layer is adapted to accept the single-channel audio input (or the input is replicated to 3 channels to match standard pre-trained weights). The final fully connected layer is replaced with a single neuron followed by a **Sigmoid activation function** to output a probability score between 0 and 1.
- **Initialization:** The backbone is initialized with weights pre-trained on ImageNet to leverage learned feature extractors, significantly reducing the training time required to reach convergence compared to training from scratch.

### Data
The raw audio waveforms are converted into 2D time-frequency representations to leverage the CNN's image processing capabilities.
- **Preprocessing:** Each `.aif` clip is loaded at its native sampling rate (2000 Hz).
- **Spectrogram Generation:** A Short-Time Fourier Transform (STFT) is computed, followed by mapping the magnitude spectrum to the **Mel scale** (e.g., 64-128 Mel bins). This focuses the model on the low-frequency regions where Right Whale calls (typically 50-250 Hz) reside.
- **Log Scaling:** A logarithmic operation is applied to the Mel-spectrograms (Log-Mel) to compress the dynamic range of the audio amplitudes.
- **Formatting:** The resulting 2D spectrograms are resized to a fixed input dimension (e.g., 224x224) and normalized using standard statistics (mean and standard deviation) to stabilize training.

### Training
The training process prioritizes stability and handling the known class imbalance (approx. 1:9).
- **Loss Function:** **Binary Cross Entropy with Logits Loss** is used as the objective function.
- **Imbalance Handling:** A **Weighted Random Sampler** is employed to oversample the minority class (whale calls) in each batch, ensuring the model sees a balanced distribution of positive and negative examples during training.
- **Optimizer:** The **Adam** optimizer is selected for its adaptive learning rate capabilities, allowing for rapid convergence without extensive hyperparameter tuning.
- **Procedure:** The model is trained for a small number of epochs (e.g., 5-10) with a validation set used to monitor AUC and prevent overfitting.

### Evaluation
- **Inference:** The test set recordings undergo the exact same preprocessing pipeline (Log-Mel conversion, resizing, normalization).
- **Prediction:** The trained model performs a forward pass on each processed test clip. The sigmoid output is recorded as the final probability of a whale call.
- **Submission:** The resulting probabilities are paired with their corresponding clip filenames to generate the submission file in the required CSV format.
