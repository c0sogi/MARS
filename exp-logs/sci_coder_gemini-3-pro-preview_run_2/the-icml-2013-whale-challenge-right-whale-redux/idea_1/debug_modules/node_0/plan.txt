The following implementation strategy outlines how the provided library components will be utilized and validated:

1.  **Configuration Setup**: The `Config` class will be modified at runtime to enable `DEBUG` mode, reduce `DEBUG_SAMPLES` to 20, and set `NUM_EPOCHS` to 1. This ensures the demonstration runs rapidly on a tiny subset of data.
2.  **Dataset Validation**: The `WhaleDataset` class will be instantiated for both training and testing. We will assert that the output tensor shapes match the expected dimensions `(1, 224, 224)` and that labels/clip names are correctly formatted.
3.  **Model Verification**: The `WhaleResNet` model will be initialized. A forward pass with a dummy batch (derived from the dataset) will be performed to verify that the output logits have the correct shape `(Batch_Size, 1)`.
4.  **Training Pipeline**: The `train_model` function will be executed. We will verify that the training completes without error, produces a trained model instance, and saves the `best_model.pth` checkpoint to the working directory.
5.  **Submission Generation**: The `generate_submission` function will be called using the trained model. We will validate the resulting CSV file for correct dimensions and column headers.
6.  **Inference Wrapper**: Finally, `run_inference` will be called with `load_cached_data=True` to demonstrate the end-to-end wrapper's ability to utilize the previously saved checkpoint.
