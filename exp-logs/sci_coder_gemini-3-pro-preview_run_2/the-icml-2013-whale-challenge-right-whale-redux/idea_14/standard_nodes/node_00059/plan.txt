Implementation strategy:
1.  **Configuration & Setup**: Import necessary modules and override `Config.EPOCHS` to 5 to ensure the execution completes within the 2-hour limit while providing a meaningful baseline. Set the device to GPU.
2.  **Data Initialization**: Explicitly call `library.data.get_data_loaders(0)` to trigger the caching of preprocessed data (numpy arrays) if they don't exist.
3.  **Label & Split Reconstruction**: Load the cached labels and metadata to reconstruct the exact `StratifiedKFold` splits used in `data.py`. This is crucial to map the Out-Of-Fold (OOF) predictions from the shuffled folds back to their original indices in the full dataset (Train + Val).
4.  **Ensemble Training Loop**:
    *   Iterate through the 3 model architectures defined in `Config.MODEL_NAMES`.
    *   For each model, run the 5-Fold Cross-Validation.
    *   Inside each fold:
        *   Initialize the specific model architecture.
        *   Train using `library.engine.fit_model`.
        *   Generate OOF predictions on the validation loader and store them in the global `oof_preds` array using the reconstructed split indices.
        *   Generate Test predictions and accumulate them for averaging.
    *   Average the test predictions across folds for the current model.
5.  **Meta-Learner Training**:
    *   Construct the Level-1 training set using the collected OOF predictions (`X`) and the full ground truth labels (`y`).
    *   Train the Logistic Regression meta-learner using `library.stacking.train_meta_learner`.
6.  **Validation & Analysis**:
    *   Generate probability predictions on the full OOF set using the trained meta-learner.
    *   Extract the subset of predictions corresponding to the original `val.csv` (hold-out set) to compute the "Final Validation Metric".
    *   Perform failure analysis by calculating the correlation between the absolute error and the target labels on this set.
7.  **Submission**:
    *   Check if the validation AUC exceeds the threshold (0.9959928858461402).
    *   If passed, use the meta-learner to predict on the averaged test predictions from the base models.
    *   Save the final submission to `submission.csv`.
