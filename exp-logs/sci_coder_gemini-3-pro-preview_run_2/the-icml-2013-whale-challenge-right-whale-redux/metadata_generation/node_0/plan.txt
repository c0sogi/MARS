The strategy is to scan the `./input/train2` and `./input/test2` directories to identify all audio files. For the training data, labels will be parsed directly from the filenames (files ending in `_1.aif` are positive samples, and `_0.aif` are negative). The training data will then be split into training and validation sets using an 80:20 ratio with stratified sampling to maintain class balance. Metadata CSV files containing relative file paths and labels will be saved to the `./metadata` directory. Finally, the script will reload these files to verify file path existence, check the integrity of the split, and print summary statistics.
