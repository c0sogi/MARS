The following script generates metadata files for the training, validation, and test datasets. It reads the raw CSV files from the `./input` directory, constructs relative file paths for the JPEG images, and performs a Stratified Group K-Fold split (80/20) on the training data to create a validation set. The split ensures that patients are not shared between training and validation sets (preventing data leakage) while attempting to maintain the class distribution. Finally, the script verifies the generated metadata by checking file existence, split ratios, and patient overlap.
