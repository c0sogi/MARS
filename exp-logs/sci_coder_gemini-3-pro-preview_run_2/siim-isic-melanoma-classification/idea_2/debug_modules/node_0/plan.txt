This script demonstrates the complete pipeline for the Melanoma Classification task using the provided library files. It sets up a fast debug environment, verifies data loading, initializes the hybrid model, runs a training epoch, and generates predictions.

Strategy:
1.  **Configuration Override**: Modify `Config` parameters at runtime to enable debug mode (`DEBUG=True`), reduce sample size (`DEBUG_SAMPLE_SIZE=20`), and set a temporary working directory. This ensures the script runs quickly and doesn't interfere with existing work.
2.  **Data Loading**: Use `get_dataloaders` to create training, validation, and test loaders. Assertions verify that the data shapes (images, metadata, targets) are correct.
3.  **Model Verification**: Instantiate `DeepHybridEfficientNet` with the dynamically detected metadata dimension. Perform a forward pass with a batch of data to verify tensor shapes and compatibility.
4.  **Loss Calculation**: Compute `FocalLoss` on the model outputs to verify the loss function.
5.  **Training & Inference Simulation**: Run `train_one_epoch` and `valid_one_epoch` to verify the training loop logic. Finally, run `predict_test` to demonstrate how to generate predictions for the submission.
