I will implement a comprehensive Exploratory Data Analysis script that handles both the tabular metadata and the image data provided in the ISIC dataset.

**Strategy:**
1.  **Setup & Configuration**: Initialize random seeds and define paths. Load the training metadata from `./metadata/train.csv`.
2.  **Target Analysis**: Analyze the `target` column to report class distribution and imbalance ratios.
3.  **Tabular Data Analysis**:
    *   Analyze numerical columns (e.g., `age_approx`) for statistics and outliers.
    *   Analyze categorical columns (e.g., `sex`, `anatom_site_general_challenge`) for cardinality and rare labels.
    *   Report missing value statistics.
4.  **Image Data Analysis**:
    *   Since processing 23k+ images is time-consuming, I will perform analysis on a stratified sample (e.g., 2,000 images).
    *   Load images to calculate distribution of dimensions (Width, Height, Aspect Ratio).
    *   Compute global pixel mean and standard deviation.
5.  **Feature Relationships**:
    *   **Tabular**: Encode categorical features and calculate correlations. Train a lightweight Random Forest (excluding the train-only `diagnosis` column and identifiers) to determine feature importance.
    *   **Meta-Features**: Analyze if image properties (size, aspect ratio) or patient metadata correlate with malignancy.
6.  **Output**: Format the results into a clean, text-based report.
