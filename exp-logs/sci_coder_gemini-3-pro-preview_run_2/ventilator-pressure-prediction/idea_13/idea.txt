# Model: Deep Gated-Cascade BiLSTM (DGC-BiLSTM)

I propose a structural evolution of the recurrent backbone that integrates the "Gating" success of input processing directly into the deep temporal signal propagation.

*   **Bottlenecked Dual-Path Injection (Retention):**
    *   We retain the highly effective injection mechanism from Lesson 00045. A **Dual-Path Block** (Identity + GLU) processes the raw inputs to generate a "Physics Context".
    *   This context is projected down to a compressed dimension (e.g., 128 units) via a **Linear Bottleneck** to prevent overfitting and reduce compute (Cite Lesson 00045).
    *   This payload is concatenated to the input of **every** LSTM layer (Cite Lesson 00021).
*   **Gated-Cascade Inter-Layer Connectivity (Structural Innovation):**
    *   Standard Stacked LSTMs simply pass the hidden state sequence from Layer $N$ to Layer $N+1$.
    *   I propose inserting a **Gated Linear Unit (GLU)** block *between* the LSTM layers.
    *   **Flow:** $Output_{Layer N} \rightarrow \text{LayerNorm} \rightarrow \textbf{GLU} \rightarrow \text{Dropout} \rightarrow \text{Concat}(\cdot, Injection) \rightarrow Input_{Layer N+1}$.
    *   **Rationale:** Lesson 00035 proved that GLUs are superior feature selectors for this physical task. By applying GLUs *between* recurrent layers, we allow the model to dynamically "gate" the temporal state transitions. This enables the network to suppress noise or irrelevant high-frequency oscillations from lower layers before they are processed by deeper, more abstract layers. This effectively creates a "Denoising Cascade" that refines the signal as it propagates through the depth of the network.
*   **Backbone:** 4 layers of Bidirectional LSTMs.
*   **Head:** A final Dense layer projects the output of the last LSTM layer to the pressure prediction. We reject Output Skip-Connections to force the physics to interact with the temporal state (Cite Lesson 00036).

# Data: Robust Physics-Fidelity Engineering

We will implement the refined feature engineering pipeline that strictly adheres to the calculus of the physical system and robust statistical principles.

*   **Robust Scaling:**
    *   We will apply **RobustScaler** (Median/IQR) to all continuous inputs. Lesson 00044 demonstrated that this accelerates convergence by >5x compared to Standard Scaling by effectively handling the ~14% outliers in the control signal `u_in` (Cite Lesson 00044).
*   **Time-Weighted Integration:**
    *   We will calculate the time delta `dt` and generate the volume feature as `u_in_cumsum = cumsum(u_in * dt)`. This corrects the integration error of early baselines (Cite Lesson 00032).
*   **Physics Interaction Terms:**
    *   We will calculate `R * u_in` (Resistive Pressure) and `u_in_cumsum / C` (Elastic Pressure) using the time-weighted volume (Cite Lesson 00004).
*   **Explicit Dynamics:**
    *   We will augment the input with **Lag features** and **Finite Differences** (1st and 2nd derivatives of `u_in`) (Cite Lesson 00008).
*   **Signal Fidelity:**
    *   Lung Resistance (`R`) and Compliance (`C`) will be treated strictly as **continuous numerical features**. We reject embeddings (Cite Lesson 00018) and CNN stems (Cite Lesson 00017) to preserve ordinal magnitude information.

# Training: Stretched-Horizon Convergence Protocol

*   **Loss Function:** We will use a **Weighted L1 Loss**, assigning a weight of **1.0** to the inspiratory phase and **0.1** to the expiratory phase. This focuses capacity on the metric while maintaining the temporal context required for stable hidden states (Cite Lesson 00021).
*   **Optimizer:** We will use **AdamW** with a **Cosine Annealing** scheduler.
*   **Stretched Horizon:** We will set the training duration to **200 epochs** and explicitly set the scheduler's `T_max=200`.
    *   Deep recurrent models on this task exhibit "long-tail convergence" (Cite Lesson 00029).
    *   Stretching the scheduler horizon keeps the learning rate higher for longer, preventing premature convergence to shallow local minima and yielding superior final accuracy (Cite Lesson 00043).
