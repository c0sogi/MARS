# Model: Fidelity-Preserving Bottlenecked-Context BiLSTM (FPBC-BiLSTM)

I propose a structural evolution that resolves the conflict between "Context Compression" (Lesson 00045) and "Signal Fidelity" (Lesson 00056) while restoring the representational capacity required for this high-precision task.

*   **Monolithic Context Extractor with Bottleneck (Structural Synthesis):**
    *   **Wide Extraction:** We will process *all* input features through a **Wide Monolithic Gated Linear Unit (GLU)** (e.g., 256 units). We explicitly reject feature partitioning to allow the model to learn cross-term interactions (e.g., $R \times Flow$) immediately (Cite solution_lesson_node_00059).
    *   **Strategic Bottleneck:** The output of this Wide GLU will be projected down to a **Compressed Context** (e.g., 128 units). This retains the regularization and efficiency benefits of bottlenecking (Cite solution_lesson_node_00045) without compressing the raw signal path.
*   **Fidelity-Preserving Injection Payload:**
    *   We will construct the injection payload by concatenating two distinct paths:
        1.  **Identity Path (Fidelity):** The raw, uncompressed input features. This ensures deep layers have access to the exact numerical magnitudes required for physics calculations, preventing the signal degradation observed when bottlenecking the entire payload (Cite solution_lesson_node_00056, solution_lesson_node_00018).
        2.  **Context Path (Abstract):** The Compressed Context generated above.
    *   **Deterministic Constraint:** We strictly **exclude Dropout** from this injection payload to ensure it serves as a stable ground truth for the deep layers (Cite solution_lesson_node_00030).
*   **Wide Deep Recurrent Backbone:**
    *   The core will consist of **4 layers of Bidirectional LSTMs** with **512 hidden units**. We explicitly restore the large model width, as Lesson 00064 proved that feature engineering cannot compensate for the loss of capacity (Cite solution_lesson_node_00064).
    *   **Deep Injection:** The "Fidelity-Preserving Payload" is concatenated to the input of **every** LSTM layer (Cite solution_lesson_node_00021).
    *   **Inter-Layer Connectivity:** We use **Layer Normalization** and **Dropout** *between* LSTM layers (Cite solution_lesson_node_00023) but reject complex inter-layer gating to maintain high gradient flow (Cite solution_lesson_node_00048).

# Data: Corrected Segregated-Scaling Pipeline

We will implement a corrected feature engineering pipeline that addresses the "Silent Peril" of scaling binary flags while optimizing dynamic feature stability.

*   **Segregated Robust Scaling (Critical Correction):**
    *   We will explicitly **segregate** the scaling logic.
    *   **Continuous Features** ($u_{in}$, $R$, $C$, Time, Derivatives): Apply **RobustScaler** (Median/IQR) to handle the ~14% outliers in control signals (Cite solution_lesson_node_00044).
    *   **Binary Features** ($u_{out}$): Pass through **Raw** (unscaled).
    *   **Rationale:** Lesson 00062 demonstrated that scaling the binary flag $u_{out}$ inverts the validation logic, leading to deceptive metrics. This correction is mandatory for valid learning (Cite solution_lesson_node_00062).
*   **Time-Weighted Integration:**
    *   Calculate volume as `u_in_cumsum = cumsum(u_in * dt)` to correct integration error (Cite solution_lesson_node_00032).
*   **Stable Dynamic Features (Multi-Step Deltas):**
    *   We will implement **Multi-Step Deltas** ($x_t - x_{t-k}$ for $k \in \{1, 2, 3, 4\}$). We reject "Iterated Finite Differences" (acceleration of acceleration) as they amplify high-frequency noise (Cite solution_lesson_node_00068) and reject "Future Lags" to prevent overfitting (Cite solution_lesson_node_00055).
*   **Signal Fidelity:**
    *   Treat $R$ and $C$ strictly as **continuous numerical features** (Cite solution_lesson_node_00018).

# Training: Stretched-Horizon Convergence Protocol

*   **Loss Function:** We will use a **Weighted L1 Loss**, assigning a weight of **1.0** to the inspiratory phase and **0.1** to the expiratory phase. This focuses capacity on the metric while maintaining the temporal context required for stable hidden states (Cite solution_lesson_node_00021).
*   **Optimizer:** We will use **AdamW** with a **Cosine Annealing** scheduler.
*   **Stretched Horizon:** We will set the training duration to **200 epochs** and explicitly set the scheduler's `T_max=200`.
    *   Deep recurrent models on this task exhibit "long-tail convergence" and "spectral bias," learning low-frequency terms (Volume) early and high-frequency terms (Resistance) late (Cite solution_lesson_node_00075).
    *   Stretching the scheduler horizon keeps the learning rate higher for longer, preventing premature convergence to shallow local minima (Cite solution_lesson_node_00043).
