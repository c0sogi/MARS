Implementation Strategy:
1.  **Setup**: Configure paths and parameters for a lightweight run (debug mode, CPU, minimal epochs) by overriding the default `Config`.
2.  **Data**: Invoke `prepare_datasets` to generate feature-engineered datasets. Validate the structure and shapes of the output (ensuring 80 time steps per breath and correct feature dimensionality).
3.  **Model**: Instantiate the `GIDBiLSTM` model. Perform a dummy forward pass with random tensors to verify tensor shape compatibility.
4.  **Loss**: Validate `WeightedL1Loss` logic by manually computing expected loss for inspiratory (weight 1.0) and expiratory (weight 0.1) phases and asserting the result.
5.  **Training**: Execute a single training epoch using the `Trainer` class to demonstrate the training loop. Verify that a valid loss is returned and a checkpoint is saved.
6.  **Inference**: Perform inference on a subset of the test data to verify the prediction pipeline without processing the entire test set (optimizing for speed).
7.  **Cleanup**: Ensure all temporary files are contained within the working directory.
