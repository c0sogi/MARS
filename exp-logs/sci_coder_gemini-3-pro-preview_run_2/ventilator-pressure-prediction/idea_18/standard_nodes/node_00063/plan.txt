Here is the implementation strategy for the `runfile.py` script:

1.  **Environment Setup**: Import necessary standard libraries (`os`, `sys`, `numpy`, `pandas`, `torch`) and the provided library modules (`config`, `data_factory`, `model_factory`, `trainer`, `utils`). Set the random seed for reproducibility.
2.  **Data Loading**: Call `prepare_data(load_cached_data=True)` to retrieve the training, validation, and test datasets.
3.  **Fast Baseline Configuration**: To ensure the script completes quickly (well within the 2-hour limit), subsample the training data to 20,000 breaths and reduce the training epochs to 15.
4.  **Dataset Preparation**: Create `VentilatorDataset` and `DataLoader` instances for training, validation, and testing. Create a specific validation loader without targets for inference-based failure analysis.
5.  **Model Initialization**: Instantiate the `WCMI_BiLSTM` model using the input dimensions from the data and move it to the detected device (GPU/CPU).
6.  **Training**: Initialize the `Trainer` and execute the training loop using the `fit` method with the reduced epoch count.
7.  **Validation**: Compute the final validation metric (MAE on inspiratory phase) using the best model weights. Print the metric in the required format: `Final Validation Metric: <value>`.
8.  **Failure Analysis**: Generate predictions on the validation set. Calculate the absolute error for the inspiratory phase and compute the Pearson correlation between the error magnitude and each input feature. Print the top correlated features to identify error sources.
9.  **Submission Logic**: Compare the final validation metric against the threshold `0.1619843989610672`. If the metric is lower (better), generate predictions for the test set and save `submission.csv`.
