# Model: Wide-Context Monolithic-Injection BiLSTM (WCMI-BiLSTM)

I propose a structural evolution that maximizes **Signal Fidelity** and **Interaction Modeling** while strictly correcting the data pipeline logic error that invalidated previous results.

*   **Monolithic Context Extractor (Structural Innovation):**
    *   Previous attempts experimented with "Partitioned" context (separating static/dynamic features, Cite solution_lesson_node_00059) or "Bottlenecked" context (compressing features to low dimensions, Cite solution_lesson_node_00056). Both approaches degraded performance by limiting the model's ability to learn cross-term interactions (e.g., $R \times Flow$).
    *   I propose a **Wide Monolithic Context Block**. All input features (Static $R, C$, Dynamic $u_{in}$, Derivatives, Interactions) will be fed into a **single, wide Gated Linear Unit (GLU)** (e.g., 256 units).
    *   **Rationale:** By processing all features together in a high-dimensional non-linear layer without partitioning, we maximize the network's ability to learn complex multiplicative interactions immediately. By avoiding a bottleneck (Cite solution_lesson_node_00056), we ensure this rich context is preserved.
*   **Dual-Path Injection Payload:**
    *   We retain the **Dual-Path** strategy (Cite solution_lesson_node_00039). The "Wide Monolithic Context" generated above is concatenated with the **Identity Path** (raw uncompressed features).
    *   **Deterministic Constraint:** We strictly **exclude Dropout** from this injection payload to ensure it serves as a stable ground truth for the deep layers (Cite solution_lesson_node_00030).
*   **Deep Recurrent Backbone:**
    *   The core consists of **4 layers of Bidirectional LSTMs**.
    *   **Deep Injection:** The "Injection Payload" is concatenated to the input of **every** LSTM layer (Cite solution_lesson_node_00021).
    *   **Inter-Layer Connectivity:** We use **Layer Normalization** and **Dropout** *between* LSTM layers (Cite solution_lesson_node_00023) but reject complex inter-layer gating to maintain high gradient flow (Cite solution_lesson_node_00048).

# Data: Corrected Physics-Fidelity Pipeline

We will implement a corrected feature engineering pipeline that addresses the "Silent Peril" of scaling binary flags while maintaining robust physics calculations.

*   **Segregated Robust Scaling (Critical Correction):**
    *   We will explicitly **segregate** the input features.
    *   **Continuous Features** ($u_{in}$, $R$, $C$, Time, Derivatives): Apply **RobustScaler** (Median/IQR) to handle the ~14% outliers in control signals (Cite solution_lesson_node_00044).
    *   **Binary Features** ($u_{out}$): Pass through **Raw** (unscaled).
    *   **Rationale:** Lesson 00062 demonstrated that scaling the binary flag $u_{out}$ inverts the validation logic, leading to deceptive metrics. This correction is mandatory for valid learning.
*   **Time-Weighted Integration:**
    *   Calculate volume as `u_in_cumsum = cumsum(u_in * dt)` to correct integration error (Cite solution_lesson_node_00032).
*   **Physics Interaction Terms:**
    *   Calculate `R * u_in` (Resistive Pressure) and `u_in_cumsum / C` (Elastic Pressure) (Cite solution_lesson_node_00004).
*   **Explicit Dynamics:**
    *   Augment input with **Past Lags** and **Finite Differences** (1st/2nd derivatives) (Cite solution_lesson_node_00008).
    *   **Exclude Future Lags** to prevent overfitting (Cite solution_lesson_node_00055).
*   **Signal Fidelity:**
    *   Treat $R$ and $C$ strictly as **continuous numerical features** (Cite solution_lesson_node_00018).

# Training: Stretched-Horizon Convergence Protocol

*   **Loss Function:** Use **Weighted L1 Loss** (1.0 for Inspiratory, 0.1 for Expiratory) to focus on the metric while maintaining temporal context (Cite solution_lesson_node_00021).
*   **Optimizer:** Use **AdamW** with a **Cosine Annealing** scheduler.
*   **Stretched Horizon:** Set training duration to **200 epochs** and explicitly set the scheduler's `T_max=200`.
    *   Deep recurrent models exhibit "long-tail convergence" (Cite solution_lesson_node_00029).
    *   Stretching the scheduler prevents premature convergence to shallow local minima (Cite solution_lesson_node_00043).
