The implementation strategy is as follows:

1.  **Setup and Initialization**: Define the input directory (`./input`) and the output directory (`./metadata`). Set the random seed to 42 for reproducibility.
2.  **Data Loading**: Read the `train.csv` file using pandas. Identify unique `breath_id`s, which represent individual time-series groups.
3.  **Group Splitting**: Shuffle the unique `breath_id`s and perform an 80:20 split to create training and validation sets. This ensures that all time steps for a specific breath remain in the same set, preventing data leakage (Group Sampling).
4.  **Metadata Generation**:
    *   For the **Training** and **Validation** sets: Filter the original training data based on the split `breath_id`s. Create metadata files containing `id`, `breath_id`, `pressure` (ground-truth label), and `source_file` (relative path `train.csv`).
    *   For the **Test** set: Read `test.csv` and create a metadata file containing `id`, `breath_id`, and `source_file` (relative path `test.csv`).
5.  **Saving**: Save the generated metadata DataFrames as CSV files in the `./metadata` directory.
6.  **Validation**:
    *   **Load**: Immediately load the generated metadata files.
    *   **Statistics**: Print summary statistics (sample counts, unique breaths).
    *   **File Path Check**: Randomly sample 1000 rows from each metadata file and verify that the `source_file` (relative to `./input`) exists. Raise an error if the missing ratio exceeds 0.5.
    *   **Split Integrity**: Assert that there is no overlap of `breath_id`s between the training and validation sets and verify that the split ratio is approximately 80:20.
