The following script demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Setup**: Initializes the environment and seeds for reproducibility.
2.  **Data Preparation**: Uses `prepare_data_loaders` with `debug=True` to quickly load and process a small subset of the data (100 breaths) into PyTorch DataLoaders. It verifies the shape of the resulting tensors.
3.  **Model Initialization**: Instantiates the `DPI_BiLSTM` model, moving it to the appropriate device (CPU or GPU).
4.  **Training Loop**: Configures the `WeightedL1Loss`, `AdamW` optimizer, and `CosineAnnealingLR` scheduler, then runs a short training session (2 epochs) using the `fit` engine.
5.  **Inference**: Generates predictions on the test set using `predict_and_submit` and verifies the output format of the submission file.
