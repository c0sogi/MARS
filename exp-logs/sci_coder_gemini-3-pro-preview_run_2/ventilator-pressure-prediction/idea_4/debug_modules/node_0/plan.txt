The following script demonstrates the end-to-end usage of the provided library files for the ventilator pressure prediction task.

### Implementation Strategy
1.  **Setup**: Initialize the environment and set random seeds for reproducibility using `library.utils.seed_everything`.
2.  **Data Loading & Processing**: Use `library.dataset.get_dataloaders` to load the raw CSV data, perform physics-based feature engineering, reshape the data into sequences, and normalize it. We use a dedicated working directory to demonstrate the caching mechanism.
3.  **Data Verification**: Inspect a single batch from the training loader to verify the tensor shapes (Batch Size, Sequence Length, Feature Dimension) and data types.
4.  **Model Initialization**: Instantiate the `ResBiLSTM` model from `library.model` with reduced hyperparameters (hidden dimension, layers) to ensure the demonstration runs quickly.
5.  **Training Loop**: Use the `Trainer` class from `library.trainer` to train the model for a single epoch. This validates the training pipeline, loss calculation, and backpropagation.
6.  **Inference**: Use the `Trainer.predict` method to generate predictions on the test set and create a submission file.
7.  **Output Validation**: Verify the generated `submission.csv` against the expected format and row count.
