# Model: Wide-Bandwidth Physics-Augmented BiLSTM (WPA-BiLSTM)

I propose a structural evolution that resolves the tension between "Context Compression" and "Signal Fidelity" by removing the injection bottleneck, while strictly enforcing the explicit physics and data pipeline corrections identified in the most recent failure analyses.

*   **Uncompressed Dual-Path Injection (Structural Innovation):**
    *   Previous iterations (Idea 22) employed a "Bottlenecked Context" to save compute. However, Lesson 00056 and Lesson 00064 demonstrated that in high-precision physical regression, restricting capacity or compressing the signal path degrades performance.
    *   I propose an **Uncompressed Dual-Path Injection Block**:
        1.  **Path A (Explicit Fidelity):** An **Identity** mapping of the raw input features *plus* explicitly engineered physics interaction terms ($R \cdot u_{in}$, $Vol/C$). This ensures the deep layers have direct access to the terms of the Equation of Motion (Cite solution_lesson_node_00076, solution_lesson_node_00018).
        2.  **Path B (Wide Context):** A **Wide Monolithic Gated Linear Unit (GLU)** (e.g., 256 units) processes *all* inputs. Crucially, we **remove the bottleneck projection**. We feed the full high-dimensional output of the GLU into the injection payload. This maximizes the bandwidth of the learned non-linear context, preventing the loss of high-frequency details required to resolve resistive pressure (Cite solution_lesson_node_00056, solution_lesson_node_00059).
    *   **Fusion:** Path A and Path B are concatenated. We strictly **exclude Dropout** from this payload to ensure it serves as a stable ground truth (Cite solution_lesson_node_00030).
*   **Wide Deep Recurrent Backbone:**
    *   The core will consist of **4 layers of Bidirectional LSTMs** with **512 hidden units**. We explicitly restore the large model width, prioritizing representational capacity over training speed (Cite solution_lesson_node_00064).
    *   **Deep Injection:** The "Wide-Bandwidth Payload" is concatenated to the input of **every** LSTM layer (Cite solution_lesson_node_00021).
    *   **Inter-Layer Connectivity:** We use **Layer Normalization** and **Dropout** *between* LSTM layers to stabilize the deep stack (Cite solution_lesson_node_00023) but reject complex inter-layer gating to maintain high gradient flow (Cite solution_lesson_node_00048).

# Data: Segregated Physics-Fidelity Pipeline

We will implement a corrected feature engineering pipeline that addresses the "Silent Peril" of scaling binary flags while strictly enforcing the inclusion of physics-based features.

*   **Segregated Robust Scaling (Critical Correction):**
    *   We will explicitly **segregate** the scaling logic.
    *   **Continuous Features** ($u_{in}$, $R$, $C$, Time, Derivatives, Interactions): Apply **RobustScaler** (Median/IQR) to handle the ~14% outliers in control signals (Cite solution_lesson_node_00044).
    *   **Binary Features** ($u_{out}$): Pass through **Raw** (unscaled).
    *   **Rationale:** Lesson 00062 demonstrated that scaling the binary flag $u_{out}$ inverts the validation logic, leading to deceptive metrics. This correction is mandatory for valid learning (Cite solution_lesson_node_00062).
*   **Explicit Physics Interactions:**
    *   We will explicitly calculate and include the interaction terms: `R * u_in` (Resistive Pressure) and `u_in_cumsum / C` (Elastic Pressure). Lesson 00076 proved that removing these in favor of latent learning degrades performance significantly (Cite solution_lesson_node_00076).
*   **Time-Weighted Integration:**
    *   Calculate volume as `u_in_cumsum = cumsum(u_in * dt)` to correct integration error (Cite solution_lesson_node_00032).
*   **Stable Dynamic Features:**
    *   We will implement **Multi-Step Deltas** ($x_t - x_{t-k}$ for $k \in \{1, 2, 3, 4\}$). We reject "Iterated Finite Differences" (acceleration of acceleration) as they amplify noise (Cite solution_lesson_node_00068) and reject "Future Lags" to prevent overfitting (Cite solution_lesson_node_00055).

# Training: Stretched-Horizon Convergence Protocol

*   **Loss Function:** We will use a **Weighted L1 Loss**, assigning a weight of **1.0** to the inspiratory phase and **0.1** to the expiratory phase. This focuses capacity on the metric while maintaining the temporal context required for stable hidden states (Cite solution_lesson_node_00021).
*   **Optimizer:** We will use **AdamW** with a **Cosine Annealing** scheduler.
*   **Stretched Horizon:** We will set the training duration to **200 epochs** and explicitly set the scheduler's `T_max=200`.
    *   Deep recurrent models on this task exhibit "long-tail convergence" and "spectral bias" (Cite solution_lesson_node_00075).
    *   Stretching the scheduler horizon keeps the learning rate higher for longer, preventing premature convergence to shallow local minima (Cite solution_lesson_node_00043).
