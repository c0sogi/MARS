# Model: Dual-Path Gated-Injection BiLSTM (DP-GI-BiLSTM)

I propose a structural evolution that synthesizes the signal fidelity of "Raw Feature Preservation" with the convergence speed of "Gated Context," while addressing the bottleneck issues identified in previous unified architectures.

*   **Dual-Path Injection Block (Structural Innovation):**
    *   Previous "Projected-Injection" architectures (Idea 7) bottlenecked the input signal by forcing it through a dense projection, diluting the physical magnitudes.
    *   I propose a **Dual-Path Injection Mechanism** that generates a composite "Injection Payload" via two parallel paths:
        1.  **Path A (Signal Preservation):** An **Identity** mapping of the raw input features (Flow, Resistance, Compliance, Derivatives). This ensures deep layers have direct access to the exact numerical magnitudes required for the Equation of Motion (Cite solution_lesson_node_00018, solution_lesson_node_00039).
        2.  **Path B (Physics Context):** A **Gated Linear Unit (GLU)** projection of the raw inputs. This allows the network to learn a non-linear, state-dependent "Physics Context" (e.g., emphasizing Resistance only during high-flow events) (Cite solution_lesson_node_00035).
    *   **Fusion:** These two paths are concatenated to form the **Injection Payload**.
*   **Deep Recurrent Backbone with Deterministic Injection:**
    *   The core will consist of **4 layers of Bidirectional LSTMs**.
    *   **Deep Injection:** The "Injection Payload" defined above will be concatenated to the input of **every** LSTM layer in the stack (Cite solution_lesson_node_00021).
    *   **Deterministic Highway:** We will strictly **exclude Dropout** from the Injection Payload itself. This signal must serve as a stable "ground truth" reference for the deep layers (Cite solution_lesson_node_00030).
*   **Internal Regularization:**
    *   To prevent the deep layers from simply memorizing the injected features, we will apply **Dropout** and **Layer Normalization** *within* the recurrent blocks (applied to the LSTM output before the next layer). This forces the RNN to learn generalizable temporal dynamics rather than overfitting the shortcut connections (Cite solution_lesson_node_00037, solution_lesson_node_00023).
    *   We explicitly reject Output Skip-Connections to force static attributes to interact with the temporal state (Cite solution_lesson_node_00036).

# Data: Time-Weighted Physics Engineering

We will implement the refined feature engineering pipeline that strictly adheres to the calculus of the physical system.

*   **Time-Weighted Integration:**
    *   We will calculate the time delta `dt` between steps and generate the volume feature as the cumulative sum of the product of flow and time: `u_in_cumsum = cumsum(u_in * dt)`. This provides a mathematically accurate integral of flow (Volume), significantly reducing error compared to simple cumulative sums (Cite solution_lesson_node_00032).
*   **Physics Interaction Terms:**
    *   We will calculate the interaction terms using this improved volume feature: `R * u_in` (Resistive Pressure) and `u_in_cumsum / C` (Elastic Pressure) (Cite solution_lesson_node_00004).
*   **Explicit Dynamics:**
    *   We will augment the input with **Lag features** and **Finite Differences** (1st and 2nd derivatives of `u_in`) to provide explicit velocity and acceleration data (Cite solution_lesson_node_00008).
*   **Signal Fidelity:**
    *   Lung Resistance (`R`) and Compliance (`C`) will be treated strictly as **continuous numerical features**. We reject embeddings to preserve ordinal magnitude information (Cite solution_lesson_node_00018). We also reject CNN stems to avoid signal distortion (Cite solution_lesson_node_00017).

# Training: Stretched-Horizon Convergence Protocol

*   **Loss Function:** We will use a **Weighted L1 Loss**, assigning a weight of **1.0** to the inspiratory phase and **0.1** to the expiratory phase. This focuses capacity on the metric while maintaining the temporal context required for stable hidden states (Cite solution_lesson_node_00021).
*   **Optimizer:** We will use **AdamW** with a **Cosine Annealing** scheduler.
*   **Stretched Horizon:** We will set the training duration to **200 epochs** and explicitly set the scheduler's `T_max` to match this duration.
    *   Deep recurrent models on this physical task exhibit "long-tail convergence." Previous experiments showed significant gains by extending training to 150 epochs (Cite solution_lesson_node_00029).
    *   Crucially, we will **stretch the scheduler horizon** (`T_max=200`). This keeps the learning rate higher for a longer duration, preventing the optimizer from settling into shallow local minima too early, which has been shown to yield superior final convergence compared to simply training longer with a short decay schedule (Cite solution_lesson_node_00043).
