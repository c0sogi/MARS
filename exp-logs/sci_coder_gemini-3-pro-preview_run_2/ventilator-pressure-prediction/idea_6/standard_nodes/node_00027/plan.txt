Implementation strategy:
1.  **Configuration**: Initialize the `Config` class and override `EPOCHS` to 20 to ensure the training completes quickly (Fast Baseline).
2.  **Training**: Execute `run_training` with `limit_breaths=30000` (approx. 50% of data) and `debug=False`. This ensures the model trains on a representative subset to save time, generates the necessary `scaler_params.npz` based on this subset, and saves the `best_model.pth`.
3.  **Full Validation**: Reload the validation data using `prepare_data` with `split='val'`, `load_cached_data=False`, and `limit_breaths=None`. This forces the regeneration of the validation dataset to include *all* validation breaths (ensuring the metric is calculated on the full hold-out set) while utilizing the scaler parameters learned during the limited training.
4.  **Inference & Metric**: Load the trained `best_model.pth`. Run inference on the full validation set. Calculate the Mean Absolute Error (MAE) specifically for the inspiratory phase (`u_out == 0`). Print the result in the required format.
5.  **Failure Analysis**: aggregate predictions and features. Calculate the correlation between the absolute error and each input feature to identify sources of model failure. Print these correlations.
6.  **Submission**: If the validation MAE is below the threshold (`0.20567339658737183`), generate predictions for the test set using `prepare_data` (loading cached data if available) and save the result to `submission.csv`.
