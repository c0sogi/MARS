This script demonstrates the end-to-end usage of the provided plant classification library. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters to run in a lightweight "debug" mode (small sample size, minimal epochs, small batch size) to ensure quick execution. It also points the taxonomy cache to an existing file to avoid re-parsing the large metadata JSON.
2.  **Taxonomy Management**: Initializes the `TaxonomyManager` to load hierarchical mappings (Species -> Family -> Order) and verifies the integrity of the loaded data.
3.  **Data Loading**: Uses `get_dataloaders` to create PyTorch DataLoaders for training, validation, and testing. It verifies the structure and shapes of the batches produced.
4.  **Model Initialization**: Instantiates the `HierarchicalConvNeXt` model, dynamically setting the size of the auxiliary heads based on the loaded taxonomy. It verifies the forward pass output shapes and the freezing logic for the two-stage training.
5.  **Training & Inference**: Uses the `Trainer` class to simulate the two-stage training process:
    *   **Stage 1 (Representation Learning)**: Trains the backbone and all heads.
    *   **Stage 2 (Classifier Re-balancing)**: Freezes the backbone and auxiliary heads, fine-tuning only the species head.
    *   **Inference**: Generates predictions on the test set and saves the submission file.
