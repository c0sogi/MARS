The following script demonstrates the usage of the provided library modules (`utils`, `model`, `dataset`, `trainer`) to build a plant species classification workflow.

The implementation strategy is as follows:
1.  **Setup & Taxonomy**: Initialize the environment with a fixed seed and retrieve taxonomy mappings (species, family, order) using `library.utils`.
2.  **Data Preparation**: Load a small subset (debug mode) of the pre-generated metadata CSVs to ensure the demonstration runs quickly. Instantiate `HerbariumDataset` and `DataLoader` for training, validation, and testing using `library.dataset`.
3.  **Model Verification**: Instantiate the `MultiTaskResNet` from `library.model`. Perform a forward pass with a dummy batch to verify that the model architecture correctly outputs logits for species, family, and order heads.
4.  **Training Loop**: Initialize the `Trainer` class from `library.trainer` with the model, loss function, and optimizer. Execute a short training run (1 epoch) on the subset data to demonstrate the training process.
5.  **Inference**: Use the trained model to generate predictions on the test subset and verify the output submission file format.
