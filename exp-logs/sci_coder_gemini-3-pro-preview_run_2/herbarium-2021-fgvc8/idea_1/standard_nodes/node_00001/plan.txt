The following implementation orchestrates the training of a Multi-Task ResNet model for plant species classification. It leverages the provided library modules for data handling, model architecture, and training logic. The script performs the following steps:
1.  **Setup**: Sets random seeds and loads taxonomy mappings.
2.  **Data Loading**: Loads training, validation, and test metadata. It subsamples the training and validation sets (50k and 10k samples respectively) to ensure the baseline runs quickly within the time limit.
3.  **Model Initialization**: Instantiates the `MultiTaskResNet` and moves it to the GPU.
4.  **Training**: Uses the `Trainer` class to train the model for 2 epochs using a Multi-Task loss (Species + Family + Order).
5.  **Validation**: Evaluates the best model on the validation set and prints the `Final Validation Metric` (Macro F1).
6.  **Failure Analysis**: Computes the correlation between prediction errors and input features (Class Frequency and File Size) to identify systematic weaknesses.
7.  **Submission**: Generates predictions for the full test set and saves them to `./submission/submission.csv`.
