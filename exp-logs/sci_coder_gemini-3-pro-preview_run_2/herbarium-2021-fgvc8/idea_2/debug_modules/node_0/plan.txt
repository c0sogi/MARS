This script demonstrates the usage of the provided library modules for the plant species classification task. It covers the following steps:
1.  **Configuration**: Overrides default configuration for a fast, lightweight demonstration (CPU-friendly, small batch size, debug mode).
2.  **Taxonomy**: Demonstrates loading and processing hierarchical labels (Species -> Family -> Order).
3.  **Dataset & Transforms**: Shows how to initialize the dataset, apply augmentations, and inspect sample data.
4.  **DataLoader & CutMix**: Verifies the custom collator that applies CutMix regularization and formats targets for the hierarchical loss.
5.  **Model**: Instantiates the Hierarchical EfficientNet with ArcFace and verifies output shapes.
6.  **Loss**: Computes the hierarchical loss (Species + Family + Order) on a dummy batch.
7.  **Training & Evaluation**: Runs a single epoch of training and validation using the engine functions to ensure the full pipeline works.
