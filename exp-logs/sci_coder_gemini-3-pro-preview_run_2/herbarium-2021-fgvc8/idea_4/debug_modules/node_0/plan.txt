This script demonstrates the usage of the provided library modules for the Herbarium 2021 plant classification task. It performs the following steps:

1.  **Configuration**: Overrides default `Config` settings to enable debug mode (subsampling data), reduce batch sizes, disable pretrained weight downloads, and point to an existing taxonomy cache for speed.
2.  **Taxonomy**: Uses `TaxonomyManager` to load hierarchical class mappings (Species -> Family -> Order).
3.  **Data Loading**: Demonstrates `HerbariumDataset` instantiation and `get_dataloaders` to prepare training and validation batches.
4.  **Modeling**: Instantiates the `HierarchicalConvNeXt` model and verifies the output shapes of the multi-task heads.
5.  **Training**: Uses the `Trainer` class to run a single training epoch and validation step, verifying loss calculation and metric reporting.
6.  **Inference**: Uses the `InferenceEngine` to generate predictions on the test set and create a submission file.
