The following script demonstrates the complete pipeline for training and evaluating the pathology classification model using the provided library files.

**Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes to run in `DEBUG` mode with a very small sample size (64 images) and only 1 epoch. This ensures the script executes within seconds while exercising all code paths.
2.  **Environment Setup**: We patch `tqdm` to suppress progress bars as requested and initialize the random seeds using `seed_everything`.
3.  **Data Loading**: We utilize `get_loaders` to prepare training and validation data for a single fold, verifying the data shapes.
4.  **Model Initialization**: We instantiate the `PathologyModel` (ConvNeXt-Tiny) and the `ModelEma` wrapper.
5.  **Training Loop**: We execute `train_one_epoch` to update model weights and the EMA shadow model, verifying the loss calculation.
6.  **Validation**: We run `validate` to compute the ROC AUC score on the validation set.
7.  **Inference**: We generate predictions on the test set using `predict_tta` (Test Time Augmentation) and verify the output dimensions.
8.  **Submission**: We save the results using `save_submission` and confirm the file creation.
