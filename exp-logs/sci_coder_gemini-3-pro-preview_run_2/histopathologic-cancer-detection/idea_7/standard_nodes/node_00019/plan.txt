To address the issues identified in the error analysis, I will implement two targeted fixes:

1.  **Fix Data Leakage (`library/train.py`):** The previous implementation merged the hold-out validation set (`val`) into the training data before performing Cross-Validation. This caused the models to see the validation data during training, invalidating the final evaluation in `runfile.py`. I will modify `run_training` to load only the `train` dataset for the Cross-Validation process, ensuring the `val` dataset remains strictly unseen.

2.  **Fix Normalization Mismatch (`library/config.py`):** The models are initialized with `pretrained=True`, expecting ImageNet normalization statistics. The previous code used custom statistics derived from the dataset, which caused a distribution shift and poor convergence. I will update `MEAN` and `STD` in `Config` to the standard ImageNet values.
