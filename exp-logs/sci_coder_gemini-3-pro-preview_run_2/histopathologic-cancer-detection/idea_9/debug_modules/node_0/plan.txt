This script demonstrates the end-to-end execution of the provided machine learning pipeline for digital pathology classification. It performs the following steps:

1.  **Configuration Override**: Adjusts the global `Config` to create a lightweight "demo" environment (reduced epochs, batch size, and dataset size) to ensure execution within the time limit.
2.  **Data Loading Verification**: Initializes the data loaders using a small debug subset and asserts that the data shapes (batch size, channels, height, width) match the expected dimensions.
3.  **Model Initialization**: Instantiates the `PathologyClassifier` and performs a dummy forward pass to verify the architecture and output dimensions.
4.  **Training Loop Execution**: Runs the `Trainer` for a single epoch on a single fold, ensuring that the training process completes and saves a valid checkpoint.
5.  **Inference & Submission**: Executes the inference engine on the test set (debug subset) using the trained checkpoint and verifies that the submission file is generated with the correct format.
