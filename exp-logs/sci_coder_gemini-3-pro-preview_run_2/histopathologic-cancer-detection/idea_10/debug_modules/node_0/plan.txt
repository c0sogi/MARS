    *   Evaluation mode outputs averaged logits (Batch, Classes).
    *   Loss calculation returns a valid scalar.
4.  **Training Pipeline Verification**: Initialize the `Trainer` with the mocked data and run `trainer.fit()` for a single epoch. Assert that the training completes and produces a model checkpoint file.
5.  **Inference Pipeline Verification**: Execute `inference_single_fold` using the trained checkpoint on the mocked test set. Verify that predictions are generated, have the correct shape, and fall within the valid probability range [0, 1]. Verify TTA logic on a single batch.
