Implementation Strategy:
1.  **Configuration Patching**: Directly modify the static attributes of the `Config` class (imported from `library.config`) to enable debug mode, reduce the number of epochs to 1, set a small batch size, and define a tiny sample size (e.g., 50 images). This ensures the demonstration runs quickly within the time limit.
2.  **Component Verification**:
    *   **Dataset**: Instantiate `ArtworkDataset` and `DataLoader` to verify image loading, transformation, and label encoding shapes.
    *   **Model**: Instantiate `ArtworkConvNeXt`, perform a forward pass with dummy data, and verify output logits shape.
    *   **Loss**: Instantiate `AsymmetricLoss`, compute loss on dummy predictions, and verify the result is a valid scalar.
3.  **Pipeline Execution**:
    *   **Training**: Execute `run_training(debug=True)` to simulate a full training cycle (1 epoch) and generate a model checkpoint.
    *   **Optimization**: Execute `main_optimization_pipeline` to generate predictions on the validation set and find optimal thresholds.
4.  **Inference Simulation**: Manually run a small inference loop using the trained model and optimized thresholds on a batch of test data to demonstrate how to generate the final submission format.
5.  **Assertions**: Insert assertions at every step to validate shapes, types, and file existence.
