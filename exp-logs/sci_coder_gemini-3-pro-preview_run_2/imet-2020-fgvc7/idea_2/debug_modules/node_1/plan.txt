The `ValueError` in `library/dataset.py` occurs because `albumentations` version 2.0.8 introduced breaking changes to the `RandomResizedCrop` API. Specifically, it now requires a `size` argument (a tuple of `(height, width)`) instead of separate `height` and `width` arguments. This is enforced by strict Pydantic validation (Cite {1}).

To fix this, I will update the `A.RandomResizedCrop` instantiation in `library/dataset.py` to use the `size` parameter.
