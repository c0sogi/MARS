The following implementation demonstrates the end-to-end usage of the provided library for the Cervical Spine Fracture Detection task.

**Implementation Strategy:**
1.  **Configuration Patching**: We first modify the `Config` class attributes to adapt the pipeline for a rapid demonstration. This includes enabling debug mode (reducing dataset size), switching to a lightweight backbone (`resnet18`), reducing image resolution, and minimizing training epochs/steps.
2.  **Dataset Verification**: We instantiate the `CervicalSpineDataset` and validate that it correctly loads DICOM images, applies 2.5D stacking, and produces tensors of the expected shape `(Seq_Len, Channels, Height, Width)`.
3.  **Model & Forward Pass**: We initialize the `AnatomicallyAwareModel` and perform a forward pass with a dummy batch derived from the dataset to verify the architecture's connectivity and output shape `(Batch, Num_Classes)`.
4.  **Loss Calculation**: We demonstrate the `WeightedFractureLoss` by calculating the loss between the model's logits and the ground truth targets.
5.  **Full Training Loop**: We execute the `run_training` function from the library. Thanks to the patched configuration, this runs a complete epoch on a tiny subset of data, validating the optimizer, scaler, and checkpointing mechanisms.
6.  **Inference & Submission**: Finally, we simulate the inference phase using the test dataset, generating predictions and formatting them into the required submission structure.
