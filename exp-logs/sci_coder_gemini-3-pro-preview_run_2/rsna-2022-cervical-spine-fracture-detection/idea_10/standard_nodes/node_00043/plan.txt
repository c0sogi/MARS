**Implementation Strategy**
1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility. Import necessary components from the provided library files.
2.  **Training**: Execute the `run_training()` function from `library.train`. This handles the entire training loop, mixed-precision optimization, and saves the best model checkpoint based on validation performance.
3.  **Validation Inference**: Load the best model checkpoint (`best_model.pth`) and perform inference on the full validation dataset to obtain probabilities.
4.  **Metric Calculation**: Compute the "Final Validation Metric" using the `get_weighted_log_loss_score` function, ensuring full precision output as required.
5.  **Failure Analysis**: Calculate the log loss per study. Extract the slice count (Z-depth) for each validation study and compute the Pearson correlation coefficient between the error magnitude (loss) and the slice count to identify potential bias regarding scan size.
6.  **Conditional Submission**: Check if the validation metric is below the specified threshold (0.15364714496434773). If satisfied, execute `predict_test_set()` to generate the `submission.csv`; otherwise, skip submission generation.
