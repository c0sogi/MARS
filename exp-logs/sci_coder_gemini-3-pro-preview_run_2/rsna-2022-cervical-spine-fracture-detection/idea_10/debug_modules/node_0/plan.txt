This script demonstrates the end-to-end pipeline for the Cervical Spine Fracture Detection task using the provided library. It performs the following steps:
1.  **Configuration Override**: Modifies the `Config` class at runtime to use a lightweight backbone (`resnet18`) and reduced sequence length/batch size for rapid execution.
2.  **Data Preparation**: Creates a small subset of the training and validation metadata to ensure the demonstration runs quickly (using only 4 samples).
3.  **Dataset & DataLoader Verification**: Instantiates the `CervicalSpineDataset`, loads a batch, and asserts the correctness of input tensor shapes (images, masks, labels).
4.  **Model Initialization**: Initializes the `CervicalFractureNet` and performs a forward pass with dummy data to verify output shapes (logits, spatial maps).
5.  **Loss Function Verification**: Computes the loss using `CervicalSpineLoss` and asserts it produces a valid scalar value.
6.  **Training Loop Demonstration**: Runs a single epoch of training using `train_one_epoch` on the subset data.
7.  **Validation Loop Demonstration**: Runs the validation step using `validate` and calculates the weighted log loss metric.
8.  **Metric Verification**: Unit tests the `get_weighted_log_loss_score` function with known inputs.
