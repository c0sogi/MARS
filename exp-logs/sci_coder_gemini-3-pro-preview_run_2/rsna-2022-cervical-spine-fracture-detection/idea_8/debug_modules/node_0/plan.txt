### Implementation Strategy

1.  **Configuration Setup**: Create a `DemoConfig` class inheriting from the provided `Config`. This class overrides paths to point to temporary subset metadata files in `./working` and adjusts hyperparameters (Sequence Length, Image Size, Backbone, Epochs) to ensure the script executes rapidly (within minutes) while exercising the full pipeline.
2.  **Data Preparation**:
    *   Load the provided metadata files.
    *   Filter them to include only a small number of valid studies (e.g., 4 studies) that exist in the input directories.
    *   Save these subsets to `./working` to serve as the dataset for the demo.
3.  **Component Verification**:
    *   **Dataset & Loader**: Instantiate `RSNADataset` and `DataLoader`. Fetch a single batch to verify tensor shapes (Sequence, Channels, Height, Width) and data types.
    *   **Model**: Instantiate `DualAttentionNetwork` with the demo configuration. Perform a forward pass with the fetched batch to verify output logits (`study`, `slice`, `spatial`) and their dimensions.
    *   **Loss**: Instantiate `TriLevelLoss`. Calculate the loss on the model output and verify it produces a valid scalar.
4.  **Training Loop**: Initialize the `Trainer` with the demo configuration and run `fit()`. This verifies the optimizer, gradient scaling, and backpropagation logic on the subset data.
5.  **Inference**: Run the `inference()` function using the trained model (saved during `fit`) to generate predictions on a small test subset and produce a submission file.
6.  **Validation**: Throughout the script, use `assert` statements to strictly validate shapes, types, and file existence.
