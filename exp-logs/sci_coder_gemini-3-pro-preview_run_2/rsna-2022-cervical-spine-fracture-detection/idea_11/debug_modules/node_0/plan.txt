This script demonstrates the usage of the provided library files (`config.py`, `utils.py`, `dataset.py`, `model.py`, `trainer.py`).

### Implementation Strategy
1.  **Configuration Override**: We use `Config.setup(debug=True)` to switch to a lightweight configuration (reduced sequence length, image resolution, and epochs) to ensure the script runs quickly.
2.  **Data Preparation**: Instead of using the full dataset, we generate "mini" metadata files containing just a few rows from the original metadata. This allows us to test the data loading and training pipeline without processing thousands of images.
3.  **Component Verification**:
    *   **Utils**: We verify the reproducibility of the random seed, the logic of the weighted log loss function, and the ability to load DICOM images.
    *   **Dataset**: We instantiate the `CervicalSpineDataset` with the mini metadata and verify that the output tensors have the correct shapes `(Seq_Len, 3, H, W)`.
    *   **Model**: We initialize the `CervicalFractureNet` and perform a forward pass with a sample batch to ensure the architecture is valid and outputs probabilities in the correct shape `(Batch, 8)`.
    *   **Training Loop**: We run the `Trainer.fit()` method for one epoch using the mini dataset. This integration test confirms that the entire pipeline (data loading, forward pass, backward pass, optimization, and model saving) functions correctly.
