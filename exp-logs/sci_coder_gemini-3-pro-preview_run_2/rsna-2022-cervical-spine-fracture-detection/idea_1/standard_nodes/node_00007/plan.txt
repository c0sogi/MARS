The `torch.OutOfMemoryError` indicates that the GPU memory is insufficient to handle the effective batch size created by collapsing the batch and slice dimensions (Batch Size 8 * 64 Slices = 512 images). This is a known issue when processing volumetric data with 2D backbones (Cite debug_lesson_1). To fix this, I will reduce the `BATCH_SIZE` to 2 in `library/config.py` and implement Mixed Precision Training (AMP) in `library/train.py` using `torch.amp.autocast` and `torch.amp.GradScaler` to optimize memory usage.
