This script implements the full training and evaluation pipeline for the Cervical Spine Fracture Detection task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We initialize the environment and set random seeds for reproducibility. We override `Config.EPOCHS` to 5 to ensure a fast baseline execution as requested, while still allowing the model to converge on the small training set.
2.  **Data Loading**: We utilize the provided `get_loaders` function with `load_cached_data=True` to efficiently load the pre-processed dataset.
3.  **Training**: The `RSNAEngine` is initialized, and the `fit` method is called to train the model. The engine handles the training loop, validation, and checkpointing of the best model.
4.  **Validation & Metric Calculation**: We load the best model checkpoint and perform inference on the validation set. We explicitly calculate the **Weighted Multi-Label Logarithmic Loss** on the full validation set to report the `Final Validation Metric` with high precision.
5.  **Failure Analysis**: We perform a failure analysis by calculating the per-sample loss and correlating it with the sequence length (slice count) of the input scans. This helps identify if the model struggles with larger or smaller volumes.
6.  **Conditional Submission**: Finally, we check if the validation metric meets the strict threshold of `0.1241588886`. If the model performs sufficiently well, we generate the submission file using the test set; otherwise, we skip this step to save resources.
