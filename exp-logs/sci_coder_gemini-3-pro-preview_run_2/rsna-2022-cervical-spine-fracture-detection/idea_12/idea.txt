Based on the analysis of the provided lessons and the trajectory of previous experiments, I propose the **Calibrated 2.5D Multi-Level Sequence Network**.

This solution structurally evolves the high-performing **Class-Specific Attention** architecture (Idea 4) by integrating **Multi-Level Feature Aggregation** (refining Idea 7) to capture fine fracture details without the instability of custom pooling layers (addressing Lesson 00052). Crucially, it fundamentally alters the training objective to prioritize **Probabilistic Calibration** (addressing Lesson 00042), discarding the aggressive weighting strategies that previously degraded the Log Loss metric.

# Proposed Solution: Calibrated 2.5D Multi-Level Sequence Network

## Model
The architecture is a robust, weakly-supervised sequence network designed to maximize sensitivity to fine fractures while maintaining strict probabilistic calibration.

1.  **2.5D Input Representation:**
    The model processes **2.5D stacks** (slices $z-1, z, z+1$) to provide local volumetric continuity to the 2D backbone (Cite solution_lesson_node_00014).

2.  **Backbone with Multi-Level Global Pooling (Structural Innovation):**
    *   **Backbone:** An **EfficientNet-B4** is used as the feature extractor.
    *   **Innovation:** Instead of using the final feature map (P5) alone (which lacks resolution) or applying complex custom pooling layers (which block gradients, Cite solution_lesson_node_00052), the model employs **Multi-Level Global Pooling**.
    *   Feature maps are extracted from both the **penultimate block (P4)** and the **final block (P5)**.
    *   **Standard Global Average Pooling (GAP)** is applied to *each* map independently. The resulting vectors are **concatenated** to form the slice embedding. This ensures the sequence model receives both high-level semantic context (P5) and finer texture details (P4) necessary for detecting hairline fractures (Cite solution_lesson_node_00035), using only robust, gradient-friendly operations.

3.  **Sequence Modeling with Positional Injection:**
    *   **Bi-LSTM:** The sequence of multi-level embeddings is processed by a Bidirectional LSTM to model the anatomical continuity of the spine along the Z-axis (Cite solution_lesson_node_00014).
    *   **Positional Embeddings:** Learnable positional vectors are added to the LSTM outputs. This provides the explicit spatial references (e.g., top vs. bottom) required to disentangle visually similar vertebrae (Cite solution_lesson_node_00029).

4.  **Disentangled Attention Aggregation:**
    *   **Class-Specific Heads:** The model utilizes **8 Independent Attention Heads** (C1-C7, Patient Overall). Each head computes unique attention weights to aggregate the LSTM sequence into a study-level embedding. This allows the "C1 Head" to focus on the top of the scan and the "C7 Head" on the bottom, preventing feature crosstalk (Cite solution_lesson_node_00029).

## Data
1.  **Preprocessing:**
    *   **High-Density Sampling:** The loader samples a sequence of **96 slices**. This prioritizes Z-axis coverage to ensure small fractures are not skipped, adhering to the lesson that sampling density outweighs model complexity (Cite solution_lesson_node_00032).
    *   **2.5D Stacking:** Inputs are constructed by stacking 3 adjacent slices.

2.  **Augmentation:**
    *   **Dataset-Encapsulated Volumetric Augmentation:** Geometric transformations (rotation, shift, scale) are sampled *once* per study and applied identically to every slice in the stack within the `__getitem__` method. This preserves the physical alignment of the spine required for the sequence model (Cite solution_lesson_node_00008, solution_lesson_node_00010).

## Training
1.  **Calibrated Loss Function:**
    *   The model is trained using **Weighted Multi-Label Logarithmic Loss** applied to the study-level predictions.
    *   **Crucial Calibration:** The loss function will use **NO Positive Class Weighting** (i.e., `pos_weight=1.0`). Since the training set is roughly balanced (~46% positive), adding positive weights forces the model to over-predict fractures, destroying probability calibration and degrading the Log Loss metric despite high sensitivity (Cite solution_lesson_node_00042).
    *   **Weak Supervision:** The model relies solely on the study-level labels. Auxiliary tasks (bounding boxes/segmentations) are avoided to prevent the instability observed when training multi-task models on small datasets with sparse annotations (Cite solution_lesson_node_00047).

2.  **Optimization:**
    *   **Gradient Accumulation:** Employed to simulate a stable batch size (e.g., 16 studies) despite the memory footprint of the EfficientNet-B4 backbone and dense sampling (Cite solution_lesson_node_00007).

## Evaluation
1.  **Inference:**
    *   Test studies are loaded, preprocessed into 2.5D stacks (96 slices), and passed through the pipeline.
    *   The **Multi-Level GAP** ensures fine details are preserved.
    *   The **Class-Specific Attention Heads** aggregate the sequence and output the final, well-calibrated probabilities for the 8 target columns.
