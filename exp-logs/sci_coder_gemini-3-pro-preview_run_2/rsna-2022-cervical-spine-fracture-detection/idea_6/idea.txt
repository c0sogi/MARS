# Proposed Solution: 2.5D Sequence-to-Set Transformer with Anatomical Query Tuning

## Model
The proposed architecture evolves the spatially-aware design of Idea 4 by transitioning from independent attention heads to a **Transformer Decoder** framework. This allows the model to learn not just the features of specific vertebrae, but also the correlations between them (e.g., adjacent fractures), effectively treating the problem as a "set prediction" task similar to modern object detection (e.g., DETR).

1.  **2.5D High-Resolution Backbone:**
    The model utilizes an **EfficientNet-B4** backbone processing **2.5D input stacks** (slices $z-1, z, z+1$). This retains the successful local volumetric context strategy (Cite solution_lesson_node_00014) while prioritizing high spatial resolution (e.g., 384x384) to resolve fine fracture lines, as sequence length was found to be less critical than image detail (Cite solution_lesson_node_00015).

2.  **Sequential Context Encoding:**
    The sequence of feature vectors extracted by the backbone is passed through a **Bidirectional LSTM**. This preserves the crucial modeling of anatomical continuity along the Z-axis (Cite solution_lesson_node_00014).
    *   **Positional Injection:** Learnable **Positional Embeddings** are added to the LSTM outputs. This provides the explicit spatial cues necessary for the attention mechanism to distinguish between visually similar vertebrae (Cite solution_lesson_node_00029).

3.  **Structural Innovation: Transformer Decoder Aggregation:**
    Instead of 8 independent attention heads (which cannot share information), the aggregation layer is replaced by a **Transformer Decoder**.
    *   **Learnable Queries:** The model initializes **8 Learnable Query Embeddings**, each representing a specific target (C1, C2... C7, Patient Overall).
    *   **Inter-Label Communication (Self-Attention):** In the self-attention layers, these queries interact with each other. This allows the model to learn anatomical dependencies (e.g., "If C1 is fractured, C2 is likely involved") and enforce consistency between the "Overall" query and the subtype queries.
    *   **Feature Extraction (Cross-Attention):** The queries attend to the LSTM-encoded image sequence (Keys/Values) to extract relevant features. The Positional Embeddings guide the "C1 Query" to attend to the top of the sequence and the "C7 Query" to the bottom.
    *   **Embedding-Space Output:** The final updated queries are passed to linear classifiers, adhering to the superior Embedding-Space Aggregation paradigm (Cite solution_lesson_node_00005).

## Data
1.  **Dataset-Encapsulated Volumetric Augmentation:**
    To ensure physical consistency, geometric augmentations (rotation, shift, scale) are applied **identically across the entire volume** within the `Dataset.__getitem__` method. This prevents the "jitter" artifacts caused by independent slice augmentation (Cite solution_lesson_node_00008, solution_lesson_node_00010).

2.  **Input Pipeline:**
    The pipeline uses **2.5D Stacking** (3 channels) and uniform sampling of the Z-axis (Cite solution_lesson_node_00014).

## Training
1.  **Robust Loss Function:**
    The model is trained using **Weighted Multi-Label Logarithmic Loss** with a **Positive Class Weight > 1** (e.g., 2.0 - 2.5). This retains the sensitivity improvements observed in Idea 4 (Cite solution_lesson_node_00029).
    *   **Correction:** The use of Focal Loss with suppressing parameters (alpha < 0.5) and auxiliary branches relying on partial data is explicitly rejected to avoid the noise injection and sensitivity collapse observed in Idea 5 (Cite solution_lesson_node_00031).

2.  **Gradient Accumulation:**
    To support the memory-intensive EfficientNet-B4 backbone and Transformer Decoder without reducing the effective bag-level batch size, **Gradient Accumulation** is employed. This ensures stable convergence by simulating a batch size of 8-16 studies (Cite solution_lesson_node_00007).

## Evaluation
1.  **Inference:**
    The test study is loaded, preprocessed into 2.5D stacks, and passed through the backbone and LSTM.
2.  **Structured Prediction:**
    The Transformer Decoder processes the sequence. The 8 queries effectively "scan" the volume, communicating with each other to ensure a coherent diagnosis before outputting the final probabilities.
