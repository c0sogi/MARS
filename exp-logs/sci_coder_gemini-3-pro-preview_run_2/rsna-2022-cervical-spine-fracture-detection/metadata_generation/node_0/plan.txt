The solution involves a Python script that generates metadata for the RSNA Cervical Spine Fracture Detection dataset.

### Implementation Strategy
1.  **Environment Setup**: Define paths for input (`./input`) and output (`./metadata`). Ensure the output directory exists.
2.  **Data Loading**: Load `train.csv` and `test.csv` using pandas.
3.  **Feature Engineering (Metadata)**:
    *   For the training data, construct the relative file path to the image directory for each study (`train_images/{StudyInstanceUID}`).
    *   For the test data, aggregate `test.csv` (which is row-based) to the study level (unique `StudyInstanceUID`) and construct relative file paths (`test_images/{StudyInstanceUID}`).
4.  **Data Splitting**:
    *   Use `StratifiedShuffleSplit` from scikit-learn to create a training and validation set with an 80:20 ratio.
    *   Stratify based on the `patient_overall` label to ensure balanced fracture prevalence.
    *   Use `random_state=42` for reproducibility.
5.  **Saving**: Save the processed DataFrames as `train_metadata.csv`, `val_metadata.csv`, and `test_metadata.csv` in the `./metadata` directory.
6.  **Verification**:
    *   **Statistics**: Print shapes and label distributions.
    *   **File Integrity**: Randomly sample 1,000 paths from each metadata file and verify their existence on the filesystem. Raise an error if the missing ratio exceeds 0.5.
    *   **Split Validity**: Assert that there is no overlap of `StudyInstanceUID` between train and validation sets and that the class distribution is similar.
