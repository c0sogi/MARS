Implementation Strategy:
1.  **Environment Setup**: Import necessary modules and configure the environment, including setting random seeds for reproducibility and suppressing warnings.
2.  **Configuration Override**: Dynamically modify the `Config` class parameters to create a lightweight "demo" mode. This involves reducing the number of epochs (to 1), batch size (to 2), sequence length (to 16), and image size (to 256) to ensure the script runs quickly within the compute constraints.
3.  **Data Preparation**: Load the provided metadata files and subsample them (taking only a few rows for train, validation, and test) to minimize I/O and processing time.
4.  **Dataset & DataLoader Initialization**: Initialize the `CervicalSpineDataset` and `DataLoader`s using the subsampled metadata. Verify the data shapes (batch dimensions) using assertions to ensure pipeline correctness.
5.  **Model Initialization**: Instantiate the `CervicalFractureNet` model. We set `pretrained=False` to avoid potential network timeouts and speed up initialization. We perform a dummy forward pass to verify that output shapes match expected dimensions.
6.  **Training Loop**: Execute the training process using the `fit` function from the provided `library.engine`. This runs a complete training and validation cycle for the configured number of epochs.
7.  **Inference**: Generate predictions for the subsampled test set using the `generate_submission` function. This requires temporarily saving the subsampled test metadata to disk so the library function can read it.
8.  **Validation**: Verify the generated `submission.csv` file to ensure it contains the correct columns and the expected number of rows based on the test set size.
