# Proposed Strategy: Tri-Branch Heterogeneous Ensemble with DeBERTa-v3 and Advanced Fine-Tuning

I propose a structural evolution of the previous "Heterogeneous Architecture" by upgrading the transformer backbone to **DeBERTa-v3**, implementing **Multi-Sample Dropout** in the classification head, and utilizing **Layer-wise Learning Rate Decay (LLRD)** during training. This strategy maximizes architectural diversity and fine-tuning stability while retaining the robust linear baseline.

### Model
The solution is a weighted ensemble of three distinct modeling branches, combining state-of-the-art Natural Language Understanding (NLU) with robust surface-level pattern matching.

1.  **Branch A: DeBERTa-v3 Backbone (Structural Innovation)**
    *   Replace the `bert-base-uncased` model with **DeBERTa-v3-base**. DeBERTa (Decoding-enhanced BERT with disentangled attention) significantly outperforms BERT and RoBERTa on NLU tasks by separating content and position embeddings. This introduces a stronger, architecturally distinct inductive bias to the ensemble [Cite solution_lesson_node_00007].
    *   **Head Design:** Replace the standard linear classification head with **Multi-Sample Dropout**. Instead of a single dropout layer, we will use multiple dropout masks in parallel, pass the results through the linear layer, and average the outputs. This technique accelerates convergence and acts as an internal ensemble within the network.

2.  **Branch B: RoBERTa Backbone (Retention)**
    *   Retain the **RoBERTa-base** model to preserve the successful heterogeneous pairing established in previous iterations. Its standard self-attention mechanism provides a necessary counterpoint to DeBERTa's disentangled attention, ensuring ensemble diversity [Cite solution_lesson_node_00007].
    *   This branch will also utilize the Multi-Sample Dropout head for consistency and improved generalization.

3.  **Branch C: Linear Baseline (Retention)**
    *   Maintain the **TF-IDF (Word 1-2 n-grams + Character 2-6 n-grams) with Logistic Regression** pipeline. This branch acts as a critical stabilizer, handling "out-of-vocabulary" noise and specific character-level obfuscations that subword tokenizers might miss [Cite solution_lesson_node_00001].

### Data
1.  **Feature Caching:** Continue to decouple the TF-IDF vectorization from the training loop by caching the sparse matrices to disk. This ensures zero overhead for the linear branch during iterative runs [Cite solution_lesson_node_00005].
2.  **Extended Context Window:** Increase the maximum sequence length for the Transformer branches from 160 to **200 tokens**. The A100 GPU can easily accommodate this increase, and previous lessons indicated that longer contexts improve the detection of toxicity in "rant-style" comments where the toxic signal may appear late in the text [Cite solution_lesson_node_00008].

### Training
1.  **Layer-wise Learning Rate Decay (LLRD):**
    *   Instead of a flat learning rate, implement LLRD for the Transformer branches. The learning rate will be highest at the classification head and decay multiplicatively (e.g., by a factor of 0.9) for each underlying transformer layer. This preserves the robust, general-purpose features of the pre-trained lower layers while allowing the top layers to adapt aggressively to the specific toxicity semantics.
2.  **Scheduler:**
    *   Utilize a **Cosine Learning Rate Scheduler with Warmup** for the deep learning branches. This smooth decay profile has been proven to yield better convergence and higher AUC than linear schedulers [Cite solution_lesson_node_00008].
3.  **Loss Function:**
    *   Use Binary Cross-Entropy with Logits Loss for all branches.

### Evaluation
1.  **Inference:**
    *   Generate probability predictions for the test set using all three models: DeBERTa, RoBERTa, and the Linear model.
2.  **Optimized Blending:**
    *   Perform a **validation-driven grid search** (or use `scipy.optimize`) to find the optimal scalar weights $w_1, w_2, w_3$ for combining the three probability vectors ($P_{final} = w_1 P_{DeBERTa} + w_2 P_{RoBERTa} + w_3 P_{Linear}$). This ensures the contribution of the linear baseline is mathematically determined based on its complementary value to the deep models [Cite solution_lesson_node_00007].
