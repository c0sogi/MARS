To improve the model's performance and exceed the target AUC of 0.9926, I will implement a **Heterogeneous Ensemble** strategy (Cite solution_lesson_node_00007).

The strategy involves the following key changes:
1.  **Architectural Diversity**: Instead of relying on a single `roberta-base` model, I will train two distinct transformer architectures: `roberta-base` and `bert-base-uncased`. Ensembling models with different inductive biases and tokenizers typically reduces variance and improves generalization.
2.  **Dynamic Training Pipeline**: I will refactor the `TransformerTrainer` and data loading utilities to dynamically handle multiple model architectures within a single execution loop.
3.  **Optimized Blending**: Rather than using hardcoded ensemble weights (e.g., 0.3/0.7), I will implement a **validation-driven grid search** to mathematically determine the optimal blending weight between the Linear baseline and the Deep Learning ensemble (Cite solution_lesson_node_00007). This ensures the contribution of the linear model is exactly tuned to correct the residual errors of the stronger deep learning ensemble.

This approach leverages the available compute time (~2 hours for two models) to maximize metric gain without exceeding the 4-hour limit.
