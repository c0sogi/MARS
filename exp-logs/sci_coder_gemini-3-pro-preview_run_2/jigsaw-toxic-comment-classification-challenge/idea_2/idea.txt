# Proposed Strategy: Hybrid Symbolic-Semantic Ensemble

I propose a **Hybrid Ensemble** architecture that combines the efficiency and robustness of the "shallow" n-gram baseline with the semantic understanding of a deep Transformer model. This strategy leverages the available GPU resources to introduce structural innovation while explicitly retaining the high-performance components identified in previous iterations.

### Model
The solution will consist of two distinct modeling branches whose predictions are combined via weighted averaging. This approach maximizes **ensemble diversity** by combining models with fundamentally different inductive biases (symbolic pattern matching vs. contextual semantic embedding) [Cite solution_lesson_node_00003].

1.  **Branch A: Diversity-Enhanced Linear Ensemble (Exploitation)**
    *   This branch retains the **One-Vs-Rest Logistic Regression** architecture.
    *   It utilizes the proven **Word (1-2 n-grams) and Character (2-6 n-grams)** feature set, which acts as a robust fallback for noisy text and misspellings [Cite solution_lesson_node_00001].
    *   To address the lack of diversity observed in previous attempts, this branch will consist of multiple Logistic Regression models trained with **varying inverse regularization strengths** (e.g., $C \in [0.5, 1.0, 2.0, 4.0]$). This ensures the constituent models produce uncorrelated errors, making the ensemble effective [Cite solution_lesson_node_00003].

2.  **Branch B: Transformer Backbone (Exploration)**
    *   This branch introduces a **RoBERTa (or DistilBERT)** backbone fine-tuned for multi-label classification.
    *   Unlike the linear model, the Transformer captures deep semantic context, sarcasm, and long-range dependencies, addressing the limitations of the n-gram approach.
    *   A classification head (Dropout + Linear + Sigmoid) will be attached to the `[CLS]` token embedding to predict the six toxicity probabilities.

### Data
1.  **TF-IDF Caching (Branch A):** We will continue to decouple feature extraction from model training. The Word and Character TF-IDF sparse matrices will be computed once and **cached to disk** (e.g., as `.npz` or `.npy` files). This allows for rapid iteration and tuning of the linear ensemble without re-incurring the vectorization overhead [Cite solution_lesson_node_00005].
2.  **Transformer Tokenization (Branch B):** The raw text will be processed using the specific tokenizer associated with the chosen pre-trained model (e.g., Byte-Pair Encoding), handling truncation and padding to a fixed sequence length (e.g., 128 or 256 tokens) suitable for the GPU memory.

### Training
1.  **Branch A (CPU):** The ensemble of Logistic Regression models will be trained using the cached sparse features. We will use the `sag` or `liblinear` solvers for efficiency.
2.  **Branch B (GPU):** The Transformer model will be fine-tuned on the NVIDIA A100. We will use **Binary Cross-Entropy with Logits Loss**, an `AdamW` optimizer, and a linear learning rate scheduler with warmup. Mixed-precision training (FP16) will be enabled to maximize throughput.

### Evaluation
1.  **Inference:**
    *   Branch A will generate predictions using the transformed test set features.
    *   Branch B will generate predictions by passing tokenized test data through the fine-tuned GPU model.
2.  **Ensembling:** The final submission will be a weighted average of the probabilities from Branch A and Branch B. This combines the "surface-level" precision of n-grams with the "deep" understanding of the Transformer.
