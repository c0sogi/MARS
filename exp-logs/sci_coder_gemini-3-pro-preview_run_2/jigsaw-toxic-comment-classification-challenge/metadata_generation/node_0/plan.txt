The implementation strategy involves the following steps:

1.  **Setup and Loading**: Define the input (`./input`) and output (`./metadata`) directories. Load the raw `train.csv` and `test.csv` datasets using pandas.
2.  **Stratified Validation Split**:
    *   Since this is a multi-label classification task, we create a "stratification key" for each sample in the training set by concatenating the six binary label columns into a string. This represents the unique combination of labels for each comment.
    *   We identify "singleton" groups (label combinations that appear less than twice) and separate them, as they cannot be stratified. These are forced into the training set to preserve data.
    *   We perform an 80:20 stratified split on the remaining data using `sklearn.model_selection.train_test_split` with `random_state=42`.
    *   The singletons are added back to the training split, and the training set is shuffled.
3.  **Metadata Generation**: Save the resulting `train`, `val`, and `test` dataframes as CSV files in the `./metadata` directory. These files serve as the metadata (containing the text and labels directly).
4.  **Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (shapes, label means).
    *   Programmatically verify the split ratio is approximately 20% (allowing for minor deviations due to singleton handling).
    *   Verify stratification by asserting that the difference in label prevalence between the training and validation sets is minimal (threshold < 0.015).
    *   Since the dataset consists of inline text and not external file paths, the file path resolution check is skipped, but this is explicitly noted in the output.
