Implementation strategy:
1.  **Configuration Override**: To adhere to the 2-hour limit while maximizing performance, I will dynamically adjust `Config` parameters. I will set `Config.DEBUG_SAMPLES` to 40,000 and run TAPT in debug mode (resulting in ~120k samples total) and Supervised Fine-Tuning in full mode (127k samples) but for only 1 epoch.
2.  **TAPT Execution**: Run `run_tapt` for both DeBERTa and RoBERTa backbones. This adapts the models to the domain vocabulary using the unlabelled corpus.
3.  **Linear Baseline**: Train the TF-IDF + Logistic Regression model on the full dataset to capture low-level textual patterns and serve as a robust anchor for the ensemble.
4.  **Supervised Fine-Tuning**: Fine-tune the domain-adapted transformers on the labeled training set. I will use the `run_supervised_training` function, ensuring the TAPT weights are loaded.
5.  **Ensemble Optimization**: Load validation predictions from all three models. Use `optimize_blending_weights` to find the optimal linear combination that maximizes ROC AUC.
6.  **Validation & Analysis**: Compute the final validation metric. Perform failure analysis by correlating prediction error with comment length to understand model biases.
7.  **Submission**: If the validation score exceeds the specified threshold, generate the final submission file using the optimized ensemble weights.
