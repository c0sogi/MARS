The `RuntimeError: unscale_() has already been called on this optimizer since the last update()` occurs because `scaler.unscale_(optimizer)` is invoked twice within a single training iteration: first inside the Adversarial Weight Perturbation (AWP) block (to calculate perturbations based on true gradients) and again in the standard optimizer step block (to prepare for gradient clipping). PyTorch's `GradScaler` enforces that `unscale_` is called exactly once per optimizer step.

To fix this, I will modify `library/loops.py` to:
1.  Initialize a flag `gradients_unscaled = False` at the start of each training step.
2.  Set `gradients_unscaled = True` inside the AWP block after the first unscale operation.
3.  Condition the second unscale operation in the optimizer step block on `if not gradients_unscaled`.

This ensures `unscale_` is called exactly once regardless of whether AWP is active or not.
