Based on the comprehensive analysis of previous experiments and the accumulated lessons, I propose the **Stoichiometry-Preserving Receiver-Aware Crystal Graph Network (SP-RA-CGN)**.

This strategy synthesizes the superior local interaction modeling of **Receiver-Awareness** (Lesson 00072) with a structural evolution designed to explicitly preserve compositional information. While **Learnable Residuals** (Lesson 00060) help maintain atomic identity within the GNN, previous attempts to use global skip connections (Lesson 00069) failed because they compromised the internal identity path. This solution corrects that flaw: it combines a **stable, identity-preserving GNN backbone** with a **Late-Fusion Stoichiometric Skip Connection**. This allows the readout head to simultaneously access the complex structural representations learned by the GNN and the pristine compositional baseline (atomic fractions) derived from the initial embeddings, maximizing the model's ability to predict formation energy (highly dependent on stoichiometry) and bandgap (dependent on structure).

### Model

1.  **Embeddings & Shared Projection:**
    *   **Nodes:** Atoms are embedded into **128-dimensional** vectors ($h^{(0)}$) based on their atomic number (Cite solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static **60-bin Gaussian RBF** filter (Cite solution_lesson_node_00005). These features are projected into the 128-dimensional space using a **Shared Linear Layer** across all interaction blocks to enforce consistent geometric interpretation and reduce parameters (Cite solution_lesson_node_00076).

2.  **Receiver-Aware Interaction Backbone:**
    *   The network consists of **4 Interaction Blocks** (Cite solution_lesson_node_00006).
    *   **Receiver-Aware Gated Convolution:** We employ a custom message passing function where the input is the concatenation of the **Target Node ($h_i$), Source Node ($h_j$), and Edge Feature ($e_{ij}$)**: $z_{ij} = [h_i || h_j || e_{ij}]$. This explicitly models asymmetric pairwise interactions (Cite solution_lesson_node_00072).
    *   **Non-Linear Gating:** The message is computed as $m_{ij} = \text{Softplus}(\text{Linear}_1(z_{ij})) \odot \text{Sigmoid}(\text{Linear}_2(z_{ij}))$. Using Softplus for the content signal is crucial for performance compared to linear GLUs (Cite solution_lesson_node_00088).
    *   **Learnable Scalar Residuals:** The node update rule is $h^{(l+1)} = \text{Softplus}(\text{BatchNorm}(\text{Agg}(m_{ij}) + (1 + \epsilon_l) \cdot h^{(l)}))$. The scalar $\epsilon_l$ is a learnable parameter initialized to 0. This ensures a stable identity path through the network depth (Cite solution_lesson_node_00060, solution_lesson_node_00065).

3.  **Stoichiometric Skip Readout (Structural Innovation):**
    *   **Structural Feature:** The final node embeddings ($h^{(L)}$) are aggregated via **Global Mean Pooling** to form $z_{struct}$ (Cite solution_lesson_node_00033).
    *   **Compositional Feature:** The *initial* node embeddings ($h^{(0)}$) are also aggregated via **Global Mean Pooling** to form $z_{comp}$. This vector represents the pure stoichiometry of the crystal, untainted by geometric smoothing.
    *   **Fusion:** The final representation is the concatenation $z_{final} = [z_{struct} || z_{comp}]$.
    *   **Prediction:** This fused vector is passed to two separate, independent MLPs to predict `formation_energy_ev_natom` and `bandgap_energy_ev` (Cite solution_lesson_node_00039).

### Data

1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This ensures the graph captures high-signal local bonds, relying on the Stoichiometric Skip to handle global compositional trends.
3.  **Normalization:** Target variables are standardized (zero mean, unit variance). We exclude explicit global features (lattice parameters) to avoid optimization interference (Cite solution_lesson_node_00022).

### Training

1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks and prediction heads to prevent overfitting (Cite solution_lesson_node_00089).
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.
5.  **Scheduler:** A `ReduceLROnPlateau` scheduler is used to anneal the learning rate (Cite solution_lesson_node_00083).

### Evaluation

1.  **Inference:** Test set structures are processed into PBC-aware graphs using the same 5.0 Å cutoff and edge encoding.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
