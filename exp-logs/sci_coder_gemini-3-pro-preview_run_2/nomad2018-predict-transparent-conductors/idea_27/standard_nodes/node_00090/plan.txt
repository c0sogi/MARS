5.  **Failure Analysis**: Calculate the Mean Absolute Error (MAE) for each validation sample. Correlate these errors with material properties (e.g., atomic percentages, lattice vectors) from the validation metadata to identify sources of error.
6.  **Submission**: Compare the final validation metric against the specified threshold (0.049412816762924194). If the model performs better (lower metric), generate predictions for the test set, inverse transform them to the original scale, and save them to `submission.csv` in the required format.
