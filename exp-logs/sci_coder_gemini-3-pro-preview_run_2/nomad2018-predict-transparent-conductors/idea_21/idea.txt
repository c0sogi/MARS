Based on the lessons learned, I propose the **Stoichiometry-Skip Crystal Graph Convolutional Network (SS-CGCNN)**.

This strategy introduces a structural evolution to the readout mechanism. While previous experiments highlighted the critical importance of stoichiometric information (atomic identity) for predicting formation energy (Lesson 54, Lesson 40), methods to enforce this within the GNN layers (Amplified Residuals, Initial Residuals) often led to instability or over-regularization (Lesson 55, Lesson 57). This solution explicitly preserves the compositional signal by creating a **skip connection from the initial node embeddings directly to the readout stage**, bypassing the graph convolution layers entirely. This allows the final classifier to utilize a "pure" learned compositional baseline ($h_0$) alongside the structure-aware features ($h_L$) processed by the GNN, without forcing the GNN to maintain that identity information against geometric noise.

### Model
The architecture is a Message Passing Graph Neural Network with a dual-pathway readout:

1.  **Node & Edge Embedding:**
    *   **Nodes:** Atoms are embedded into **128-dimensional** vectors ($h_0$) based on their atomic number. This width provides sufficient capacity for multi-target prediction (Cite solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static **60-bin Gaussian Radial Basis Function (RBF)** filter (Cite solution_lesson_node_00005). These features are projected into the 128-dimensional node space using a learnable **Linear Layer** *before* entering the convolution (Cite solution_lesson_node_00042).

2.  **Structural Pathway (GNN Backbone):**
    *   We employ **4 Interaction Blocks** using **Gated Graph Convolutions (CGConv)**. This mechanism uses edge features to modulate message content, providing the necessary physical inductive bias (Cite solution_lesson_node_00011, solution_lesson_node_00018).
    *   **Learnable Scalar Residuals:** Inside the blocks, we use the update rule $h_{l+1} = \text{Softplus}(\text{BatchNorm}(\text{CGConv}(h_l) + (1 + \epsilon) \cdot h_l))$. The learnable scalar $\epsilon$ (initialized to 0) allows the network to dynamically tune signal preservation without the instability of fixed amplification (Cite solution_lesson_node_00060, solution_lesson_node_00065). The activation is applied *after* the residual (Cite solution_lesson_node_00041).

3.  **Stoichiometric Skip-Readout (Structural Innovation):**
    *   **Structural Context:** The output of the final GNN layer ($h_L$) is aggregated via **Global Mean Pooling** to form vector $z_{struct}$ (Cite solution_lesson_node_00033).
    *   **Compositional Context:** The *initial* node embeddings ($h_0$) are also aggregated via **Global Mean Pooling** to form vector $z_{comp}$. This vector represents the learned chemical composition of the crystal, independent of structure.
    *   **Fusion:** $z_{struct}$ and $z_{comp}$ are **concatenated** to form the final representation.

4.  **Decoupled Prediction:**
    *   The fused vector is passed into two separate, independent Multi-Layer Perceptrons (MLPs) to predict `formation_energy_ev_natom` and `bandgap_energy_ev` (Cite solution_lesson_node_00039).

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This ensures the GNN focuses on high-signal local bonds, while the Stoichiometric Skip handles the global compositional baseline.
3.  **Normalization:** Target variables are standardized (zero mean, unit variance) to ensure balanced gradients. We exclude explicit global features (lattice parameters) to avoid optimization interference (Cite solution_lesson_node_00022).

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks and prediction heads.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs using the same 5.0 Å cutoff and edge encoding.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
