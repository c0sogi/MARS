The implementation strategy involves the following steps:

1.  **Setup and Loading**: Initialize paths for input and metadata directories. Load the raw `train.csv` and `test.csv` files using pandas.
2.  **Path Generation**: Augment the dataframes with a `file_path` column. For the training set, paths will be formatted as `train/{id}/geometry.xyz`, and for the test set as `test/{id}/geometry.xyz`, relative to the input directory.
3.  **Stratified Splitting**: Since this is a regression task, create a temporary binning column based on the `formation_energy_ev_natom` target variable to facilitate stratified sampling. Split the training data into training (80%) and validation (20%) sets using `sklearn`'s `train_test_split` with a fixed random state.
4.  **Saving Metadata**: Save the resulting training, validation, and test dataframes as CSV files in the `./metadata` directory.
5.  **Validation - Statistics**: Load the generated metadata files and print summary statistics (counts, mean/std of targets) to verify data integrity.
6.  **Validation - File Existence**: Randomly sample 1000 file paths from the metadata and verify their existence in the `./input` directory. If more than 50% are missing, raise an error.
7.  **Validation - Split Distribution**: Verify that the split ratio is correct and that the distribution of the stratification variable is consistent between the training and validation sets.
