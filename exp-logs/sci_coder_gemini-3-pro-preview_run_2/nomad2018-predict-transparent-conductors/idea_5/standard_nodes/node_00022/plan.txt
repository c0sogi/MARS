To optimize the performance of the Global-Conditioned Crystal Graph Convolutional Neural Network (GC-CGCNN), I will implement input scaling for the global features. The previous failure analysis indicated a strong correlation between prediction errors and unscaled global properties (e.g., lattice angles), which likely caused ill-conditioned optimization. As per **Lesson 21**, explicit normalization of auxiliary global inputs is mandatory in hybrid GNN architectures.

Here is the plan:
1.  **`library/config.py`**: Update the working directory and increase `BATCH_SIZE` to 64 to improve training throughput (Cite **Lesson 4**).
2.  **`library/engine.py`**: Modify `train_one_epoch` and `evaluate` to accept a `global_scaler` and normalize `data.global_feat` on-the-fly before the forward pass.
3.  **`runfile.py`**: Calculate statistics for global features from the training set, fit a `StandardScaler`, and pass it to the engine functions.
