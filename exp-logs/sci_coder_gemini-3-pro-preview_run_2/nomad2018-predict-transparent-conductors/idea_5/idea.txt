Based on the lessons learned from previous experiments and the data analysis, I propose a **Global-Conditioned Crystal Graph Convolutional Network (GC-CGCNN)**.

### Model
The architecture is a structural evolution of the **Crystal Graph Convolutional Neural Network (CGCNN)** that introduces a **Feature-wise Linear Modulation (FiLM)** mechanism to explicitly condition local atomic interactions on global crystal properties.

1.  **Inputs**:
    *   **Graph**: Nodes representing atoms and edges representing chemical bonds derived from spatial proximity.
    *   **Global Features**: A vector containing the **Lattice Parameters** (lengths $a, b, c$ and angles $\alpha, \beta, \gamma$) and **Chemical Composition** (fractions of Al, Ga, In, O). The data analysis revealed strong correlations between these global properties and the targets (e.g., Lattice Vector 3 with Formation Energy, Indium percentage with Bandgap).
2.  **Embeddings**:
    *   **Nodes**: Atomic numbers are mapped to learnable embeddings of dimension **64** (Cite solution_lesson_node_00004).
    *   **Edges**: Interatomic distances are expanded using a static **Radial Basis Function (RBF)** filter with **60 bins** (Cite solution_lesson_node_00002, solution_lesson_node_00005).
    *   **Global**: The global feature vector is projected via an MLP to the same dimension as the nodes.
3.  **FiLM-CGCNN Block**: The model consists of **4 interaction blocks** (Cite solution_lesson_node_00006). In each block:
    *   **Conditioning**: A FiLM layer uses the Global embedding to generate scale ($\gamma$) and shift ($\beta$) vectors. The node features $h_i$ are modulated: $h_i' = \gamma \odot h_i + \beta$. This allows the macroscopic strain and composition to dynamically adapt how atoms process local chemical environments.
    *   **Convolution**: The modulated nodes are processed by a standard **CGCNN convolution**, where messages are gated by the RBF edge features (Cite solution_lesson_node_00018). We strictly avoid dynamic edge updates (Cite solution_lesson_node_00008).
    *   **Residuals**: Residual connections and Layer Normalization are applied.
4.  **Readout**: A global **Mean Pooling** operation aggregates node features. This pooled vector is concatenated with the Global embedding and passed through a final MLP to predict Formation Energy and Bandgap Energy.

### Data
1.  **Graph Construction**: We will use a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to identify edges.
2.  **Cutoff Radius**: The neighbor cutoff is set to **5.0 Å** (Cite solution_lesson_node_00007). This captures the first few coordination shells without introducing noise from distant, non-interacting atoms.
3.  **Feature Extraction**: In addition to the graph, we will extract the 6 lattice parameters and 4 composition fractions for each crystal to form the global feature vector.
4.  **Normalization**: Target variables and global lattice parameters will be standardized (zero mean, unit variance).

### Training
1.  **Optimizer**: We will use **AdamW** (Cite solution_lesson_node_00019) to ensure effective decoupled weight decay regularization.
2.  **Loss Function**: Mean Squared Error (MSE).
3.  **Regularization**: We will apply **Dropout (0.1)** and a **Weight Decay of 1e-4** (Cite solution_lesson_node_00003) to prevent overfitting on this small dataset.
4.  **Batch Size**: A batch size of **48** will be used (Cite solution_lesson_node_00005).

### Evaluation
1.  **Inference**: Test structures will be processed into graphs (with PBC) and global feature vectors.
2.  **Prediction**: The model will predict standardized values, which will be inverse-transformed using the training set statistics to yield the final predictions in eV.
