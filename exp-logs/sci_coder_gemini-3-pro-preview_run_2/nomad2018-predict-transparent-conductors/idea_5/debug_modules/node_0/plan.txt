The following implementation outlines the strategy to instantiate and utilize the provided library classes for the crystal property prediction task.

### Implementation Strategy

1.  **Configuration**: Modify the `Config` class attributes at runtime to set up a "demo mode". This involves enabling debug flags, reducing the sample size to 100, setting epochs to 2, and redirecting output paths to a `./working/demo_run` directory to ensure a fast and isolated execution.
2.  **Setup**: Call `Config.setup()` to create necessary directories and `set_seed()` to ensure reproducibility.
3.  **Data Loading**: Use `get_train_val_datasets` and `get_test_dataset` with `load_cached=False` to process the small debug subset of data from the provided metadata and XYZ files. PyTorch Geometric `DataLoader`s are then created for batching.
4.  **Scaling**: Instantiate `StandardScaler` and fit it on the training targets to normalize the regression outputs (formation energy and bandgap).
5.  **Model Initialization**: Instantiate the `GCCGCNN` model using the configuration.
6.  **Training**: Execute a training loop for the specified number of epochs using `train_one_epoch` and `evaluate` functions from the engine.
7.  **Inference**: Run inference on the test dataset using the trained model and the `evaluate` function.
8.  **Submission**: Construct a Pandas DataFrame from the test predictions and save it to the specified submission path in CSV format.
