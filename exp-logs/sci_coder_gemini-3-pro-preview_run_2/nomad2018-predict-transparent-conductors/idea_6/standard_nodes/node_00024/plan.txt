Implementation Strategy:
1.  **Setup and Configuration**: Initialize random seeds and device. Override `Config` parameters (`NUM_EPOCHS=60`, `BATCH_SIZE=48`) to ensure the pipeline runs quickly as a baseline.
2.  **Data Loading**: Use `get_dataloaders` to load train, validation, and test data. This handles graph construction, caching, and scaling (StandardScaler for global features and targets).
3.  **Model Initialization**: Instantiate the `VNCGCNN` model, which augments standard CGCNN with a Virtual Node to capture global crystal properties (lattice, composition). Move model to GPU if available.
4.  **Training**: Execute a training loop using `AdamW` optimizer and `ReduceLROnPlateau` scheduler. Use `MSELoss`. Implement checkpointing to save the best model based on validation loss.
5.  **Validation**: Load the best model. Perform inference on the validation set. Inverse-transform the scaled predictions to original units. Calculate the **Mean Column-wise RMSLE** metric.
6.  **Failure Analysis**: Calculate the mean absolute error for each validation sample. Compute Pearson correlations between this error and material properties (from metadata) to identify failure modes. Print these correlations.
7.  **Submission**: If the validation metric is below the specified threshold (0.05085...), generate predictions for the test set, inverse-transform them, and save the submission file in the required format.
