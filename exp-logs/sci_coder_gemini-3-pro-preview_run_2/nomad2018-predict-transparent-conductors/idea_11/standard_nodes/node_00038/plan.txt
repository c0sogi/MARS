The `_pickle.UnpicklingError` in `runfile.py` occurs because `torch.load` defaults to `weights_only=True` in newer PyTorch versions, which blocks loading numpy arrays contained in the `StandardScaler` state dictionary. I will fix this by explicitly setting `weights_only=False` in `runfile.py`. Additionally, to improve model performance and meet the validation threshold, I will increase the model capacity in `library/config.py` by doubling the hidden channels and adding more interaction layers.
