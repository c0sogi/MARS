Based on the comprehensive analysis of previous experiments and the lessons learned, I propose the **Multi-Scale Readout Crystal Graph Convolutional Network (MSR-CGCNN)**.

This solution introduces a structural innovation by implementing a **Jumping Knowledge (JK)** aggregation scheme. Instead of using only the final graph representation for prediction, this architecture aggregates node features from *every* interaction layer. This addresses the "oversmoothing" issue observed in deeper networks (Cite solution_lesson_node_00006) by preserving high-frequency local information from early layers while also utilizing the contextual information from later layers. Furthermore, it integrates the highly correlated global crystal properties via a decoupled stream to avoid the optimization interference observed in previous conditioning attempts.

### Model
The architecture is composed of a graph backbone, a global feature stream, and a multi-scale fusion readout:

1.  **Graph Backbone (CGCNN):**
    *   We retain the **Crystal Graph Convolutional Neural Network (CGCNN)** layers as the core message-passing unit. This choice is based on the finding that Gated Convolutions with static edge gating provide a stronger physical inductive bias than Graph Transformers or dynamic edge updates for this dataset (Cite solution_lesson_node_00011, solution_lesson_node_00008, solution_lesson_node_00018).
    *   **Configuration:** The backbone will consist of **4 interaction layers** with a hidden dimension of **64** to prevent overfitting (Cite solution_lesson_node_00004).
    *   **Static Edges:** Edge features are **Radial Basis Function (RBF)** expansions of interatomic distances (Cite solution_lesson_node_00002) and remain fixed throughout the network to enforce geometric constraints.

2.  **Multi-Scale Readout (Jumping Knowledge):**
    *   Unlike standard GNNs that pool only the final layer, we apply **Global Mean Pooling** (Cite solution_lesson_node_00033) to the node features output by **each** of the 4 interaction layers individually.
    *   These pooled vectors ($h_1, h_2, h_3, h_4$) are concatenated to form a rich graph embedding that contains information at varying scales of local-to-global context.

3.  **Global Feature Stream:**
    *   A separate **Multi-Layer Perceptron (MLP)** processes the **Global Features**: Lattice Parameters (lengths/angles) and Atomic Composition.
    *   This stream operates independently of the graph backbone to prevent the "noise injection" effects observed when global features modulate local nodes directly (Cite solution_lesson_node_00022, solution_lesson_node_00025).

4.  **Late Fusion:**
    *   The Multi-Scale Graph Embedding and the Global Embedding are concatenated and passed through a final regression MLP to predict `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This ensures the graph captures only high-signal local bonds, relying on the Global Stream and deeper GNN layers to handle longer-range dependencies.
3.  **Feature Engineering:**
    *   **Nodes:** Atoms are embedded into **64-dimensional** vectors.
    *   **Edges:** Interatomic distances are encoded using a **60-bin** Gaussian RBF expansion (Cite solution_lesson_node_00005).
    *   **Global Features:** Lattice parameters and composition fractions are extracted and **Standardized** (Z-score normalization) based on training set statistics. This is mandatory to ensure stable gradient flow (Cite solution_lesson_node_00021).
4.  **Target Normalization:** Target variables are standardized to zero mean and unit variance.

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization, which is crucial for generalization in GNNs (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the update blocks.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs and standardized global feature vectors.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions.
