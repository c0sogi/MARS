To optimize the performance of the Crystal Graph Network, I will implement several targeted modifications based on the provided lessons.

1.  **Graph Construction**: I will switch from a dense radius graph to a **k-Nearest Neighbor (k-NN)** topology by reducing `MAX_NEIGHBORS` from 50 to 12. This focuses message passing on the most chemically relevant neighbors and reduces noise from distant atoms (Cite `solution_lesson_node_00078`).
2.  **Model Capacity**: I will increase the model's capacity by raising `HIDDEN_DIM` to 160 and `NUM_LAYERS` to 5. This allows the network to capture more complex structural features (Cite `solution_lesson_node_00005`).
3.  **Residual Connections**: I will implement **Amplified Residuals** ($x' = 2x + m$) in the interaction blocks and remove dropout. This strong identity bias helps preserve stoichiometric information and improves generalization in deep GNNs (Cite `solution_lesson_node_00054`).
4.  **Pooling**: I will replace the learnable `SpeciesWeightedReadout` with standard **Global Mean Pooling**. For intensive properties like formation energy, parameter-free mean pooling is often more robust and less prone to overfitting (Cite `solution_lesson_node_00033`).
5.  **Training**: I will increase the training duration to 100 epochs to ensure convergence with the larger model capacity.

class ReceiverAwareBlock(MessagePassing):
    def __init__(self, hidden_dim, dropout=0.1):
        super().__init__(aggr="add")
        self.hidden_dim = hidden_dim
        self.dropout = dropout

        # Message function: Gated MLP on [h_i, h_j, e_ij]
        # Input dim: hidden_dim (i) + hidden_dim (j) + hidden_dim (e) = 3 * hidden_dim
        # Project to 2 * hidden_dim for GLU-like gating
        self.message_mlp = nn.Linear(3 * hidden_dim, 2 * hidden_dim)

        # Learnable scalar residual
        self.epsilon = nn.Parameter(torch.zeros(1))

        # BatchNorm + Activation for update
        self.bn = nn.BatchNorm1d(hidden_dim)

class SpeciesWeightedReadout(nn.Module):
    def __init__(self, max_atomic_num, hidden_dim):
        super().__init__()
        # Learnable weights for each atomic number
        # Initialize to 0 (softplus(0) approx 0.69) to start near uniform
        self.species_weights = nn.Parameter(torch.zeros(max_atomic_num + 1))

    def forward(self, x, z, batch):
        # x: (N, hidden_dim)
        # z: (N,) atomic numbers
        # batch: (N,)

        # Get scalar weights for each atom based on atomic number
        w = self.species_weights[z]  # (N,)

        # Ensure positivity using Softplus
        w = F.softplus(w).unsqueeze(1)  # (N, 1)

        # Weight the node features
        x_weighted = x * w

        # Global Mean Pooling
        # This computes (1/N_g) * sum(w_i * x_i) for each graph g
        out = global_mean_pool(x_weighted, batch)

        return out
