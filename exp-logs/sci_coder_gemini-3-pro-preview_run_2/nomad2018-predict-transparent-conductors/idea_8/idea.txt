Based on the lessons learned, I propose the **Composition-Aware CGCNN with Attention Pooling**.

This solution structurally evolves the successful Crystal Graph Convolutional Neural Network (CGCNN) by improving how local features are aggregated (Attention Pooling) and how global features are integrated (Late Fusion). This addresses the limitations of previous global conditioning attempts (FiLM, Virtual Nodes) while retaining the strong inductive bias of the CGCNN backbone.

### Model
The architecture consists of a graph backbone, a global feature stream, and a specialized readout mechanism:

1.  **CGCNN Backbone:** We retain the **Gated Graph Convolution** layers as the core feature extractor. This architecture uses static **Radial Basis Function (RBF)** edge features to gate information flow, providing the necessary physical inductive bias that outperformed generic Transformers and dynamic edge updates (Cite solution_lesson_node_00011, solution_lesson_node_00008). We use **4 layers** to prevent oversmoothing (Cite solution_lesson_node_00006).
2.  **Attention Pooling:** Instead of the standard Mean or Sum pooling, we implement **Global Attention Pooling** (e.g., a Softmax-based aggregation). This allows the model to learn a weighted sum of atomic representations, enabling it to focus on the most chemically relevant local environments (e.g., active sites or defects) and filter out noise, which is critical given the sensitivity to graph density (Cite solution_lesson_node_00007).
3.  **Late Fusion of Global Features:** A separate MLP processes global crystal properties: **Lattice Parameters** (lengths/angles) and **Atomic Composition**. The output of this MLP is concatenated with the graph embedding *after* the pooling layer. This integration strategy leverages the strong correlation of global features with the targets without interfering with the local message-passing optimization, avoiding the degradation seen with FiLM and Virtual Nodes (Cite solution_lesson_node_00022, solution_lesson_node_00025).
4.  **Dual-Head Output:** The fused vector is passed to two separate MLP heads to predict `formation_energy_ev_natom` and `bandgap_energy_ev` independently, allowing the model to specialize for each target's distinct feature dependencies.

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to construct the atom graph.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007) to preserve the high signal-to-noise ratio of local bonds.
3.  **Feature Engineering:**
    *   **Nodes:** Atoms are embedded into **64-dimensional** vectors (Cite solution_lesson_node_00004).
    *   **Edges:** Interatomic distances are encoded using a static **60-bin** Gaussian RBF expansion (Cite solution_lesson_node_00002, solution_lesson_node_00005).
    *   **Global:** Lattice parameters and composition fractions are extracted and **Standardized** (Z-score) to ensure numerical stability during the late fusion step (Cite solution_lesson_node_00021).

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the network.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise for generalization (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized target values.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs and standardized global feature vectors.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
