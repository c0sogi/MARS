This script demonstrates the usage of the provided Composition-Aware CGCNN library. It performs the following steps:
1.  **Configuration**: Modifies the global `Config` to use a temporary working directory and reduced hyperparameters for a quick demonstration.
2.  **Utils Verification**: Tests the `GaussianSmearing` and `Standardizer` classes to ensure they function as expected.
3.  **Data Loading**: Instantiates the `CrystalGraphDataset` in debug mode (loading a small subset of data) and verifies the data structure and batch collation.
4.  **Model Initialization**: Instantiates the `CompositionAwareCGCNN` model and performs a forward pass with a dummy batch to verify input/output shapes.
5.  **Training and Prediction**: Runs a full training cycle (train/val) for a few epochs using the `Trainer` class, followed by a prediction step on the test set, producing a submission file.
