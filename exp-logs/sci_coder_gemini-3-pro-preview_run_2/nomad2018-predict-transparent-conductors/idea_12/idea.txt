Based on the lessons learned from previous experiments, I propose the **Additive Composition-Structure Residual Network (ACSR-Net)**.

This solution represents a structural evolution from the standard CGCNN by explicitly decoupling the learning of **compositional properties** (stoichiometry) from **structural properties** (geometry/topology). Instead of forcing the Graph Neural Network to learn the entire mapping from scratch, this architecture enforces a physical prior: that material properties can be modeled as a compositional baseline (e.g., Vegard's Law) plus a structural correction (residual) derived from the specific crystal lattice. This addresses the "oversmoothing" and "noise injection" issues observed in previous global-conditioning attempts by isolating global compositional features from the local message-passing loop.

### Model
The architecture consists of two parallel streams that combine via an **additive** (not concatenated) readout:

1.  **Compositional Baseline Stream (MLP):**
    *   **Input:** A vector of **Atomic Composition Fractions** (e.g., %Al, %Ga, %In, %O).
    *   **Architecture:** A Multi-Layer Perceptron (MLP) that maps composition directly to a baseline scalar prediction for each target. This stream captures the macroscopic trends driven purely by stoichiometry, which data analysis showed to be highly correlated with the targets.
    *   **Constraint:** By isolating composition here, we prevent the GNN from wasting capacity relearning basic elemental averages.

2.  **Structural Residual Stream (CGCNN Backbone):**
    *   **Architecture:** We retain the **Crystal Graph Convolutional Neural Network (CGCNN)** backbone (Cite solution_lesson_node_00011).
    *   **Function:** This stream learns the **residual correction** ($\Delta$) to the baseline, capturing deviations caused by specific atomic arrangements, defects, or lattice strain.
    *   **Configuration:** 
        *   **Nodes:** 64-dimensional learnable embeddings (Cite solution_lesson_node_00004).
        *   **Edges:** Static **60-bin Gaussian RBF** expansion of interatomic distances (Cite solution_lesson_node_00002, solution_lesson_node_00005). We strictly avoid dynamic edge updates (Cite solution_lesson_node_00008).
        *   **Layers:** 4 Gated Convolution blocks to capture local context without oversmoothing (Cite solution_lesson_node_00006).
        *   **Pooling:** **Global Mean Pooling** (Cite solution_lesson_node_00033) to aggregate local residuals into a graph-level correction.

3.  **Additive Fusion:**
    *   The final prediction is the **sum** of the two streams: $\hat{y} = f_{MLP}(x_{comp}) + g_{GNN}(G_{struct})$.
    *   This enforces the inductive bias that structure *modifies* the intrinsic properties of the composition, rather than just being another feature concatenated in a high-dimensional vector (addressing solution_lesson_node_00038).
    *   **Heads:** Separate additive pathways are used for `formation_energy` and `bandgap` to decouple the tasks (Cite solution_lesson_node_00039).

### Data
1.  **Graph Construction:** Use **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to construct the atom graph.
2.  **Local Constraints:** Strictly enforce a **5.0 Å neighbor cutoff** (Cite solution_lesson_node_00007). This ensures the GNN focuses solely on high-signal local bonds, leaving global trends to the Compositional Stream.
3.  **Feature Engineering:**
    *   **Composition:** Extract atomic fractions for the MLP stream. These must be **Standardized** (Z-score) to ensure stable gradient flow (Cite solution_lesson_node_00021).
    *   **Targets:** Apply a **Log1p transformation** followed by **Standardization** to the target variables. This aligns the training objective (MSE) with the evaluation metric (RMSLE) and handles the different scales of the two targets.

### Training
1.  **Optimizer:** Use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:** Apply **Weight Decay of 1e-4** (Cite solution_lesson_node_00003) and **Dropout (0.1)** within both streams.
3.  **Batch Size:** Use a batch size of **48** to introduce beneficial gradient noise (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on the log-standardized targets.

### Evaluation
1.  **Inference:** Test structures are processed into PBC-graphs and standardized composition vectors.
2.  **Prediction:** The model predicts log-standardized values. These are inverse-transformed (inverse standard scaler -> exp(x) - 1) to produce the final predictions in eV.
