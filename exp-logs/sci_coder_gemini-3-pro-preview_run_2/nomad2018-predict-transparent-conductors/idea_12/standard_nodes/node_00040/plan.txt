Here is the complete orchestration script `runfile.py` implementing the ACSR-Net workflow.

1.  **Training**: It initiates the training process for 80 epochs using the `run_training` function. This trains the dual-stream (Composition MLP + Structural GNN) model, saves the best checkpoint based on validation RMSLE, and caches the scalers.
2.  **Validation**: It loads the best model and the validation dataset. It computes the predictions and calculates the final RMSLE metric, printing it in the required format.
3.  **Failure Analysis**: It calculates the error magnitude for each validation sample and computes Pearson correlations between the error and input features (e.g., lattice vectors, angles, atomic percentages) to identify sources of systematic error.
4.  **Submission**: If the validation metric is below the specified threshold (0.05085), it generates the submission file for the test set using `generate_predictions`.
