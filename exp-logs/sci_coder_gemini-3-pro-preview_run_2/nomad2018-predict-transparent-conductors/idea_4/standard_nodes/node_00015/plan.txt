5.  **Metric Calculation**: Compute the Column-wise Root Mean Squared Logarithmic Error (RMSLE) on the validation set and print it in the required format.
6.  **Failure Analysis**: Calculate the absolute error for each validation sample. Compute and print the Pearson correlation between this error magnitude and key material properties (e.g., lattice vectors, atomic composition) to identify sources of systematic error.
7.  **Submission Generation**: Check if the validation RMSLE is below the specified threshold (0.053007537912991315). If so, perform inference on the test set and generate the `submission.csv` file in the `./submission` directory.
