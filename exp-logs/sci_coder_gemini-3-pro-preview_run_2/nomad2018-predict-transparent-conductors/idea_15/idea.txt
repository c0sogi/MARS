Based on the comprehensive analysis of previous experiments and the lessons learned, I propose the **Hybrid Amplified-Structural and Compositional Network (HASC-Net)**.

This solution represents a structural evolution that synthesizes the most effective components identified in the lessons: it combines the robust **Amplified Residual** update rule (which preserves stoichiometric signal) with a **Late Fusion** of global crystal features. This design addresses the "oversmoothing" of atomic identity in standard GNNs while simultaneously capturing macroscopic lattice properties, avoiding the optimization interference observed in previous "early fusion" attempts like FiLM.

### Model
The architecture consists of two parallel processing streams that converge at the readout stage:

1.  **Structural Stream (GNN Backbone):**
    *   **Architecture:** We utilize the **Crystal Graph Convolutional Neural Network (CGCNN)** layers (Cite solution_lesson_node_00011).
    *   **Amplified Residuals:** Crucially, we modify the update rule to **$h_{l+1} = \text{Activation}(2h_l + \text{Message}(h_l))$**. By weighting the node's current state ($h_l$) by a factor of 2, we enforce a strong inductive bias that preserves atomic identity and stoichiometry against geometric noise, which was the key factor in the best-performing model to date (Cite solution_lesson_node_00054).
    *   **Edge Encoding:** Interatomic distances are expanded via static Gaussian RBFs (Cite solution_lesson_node_00005) and then projected into the node embedding space using a learnable **Linear Layer** before the convolution (Cite solution_lesson_node_00042).
    *   **Configuration:** The backbone uses **4 layers** with a hidden dimension of **128** (Cite solution_lesson_node_00006, solution_lesson_node_00039).
    *   **Pooling:** We employ **Global Mean Pooling** to aggregate node features, as it is parameter-free and robust for intensive properties (Cite solution_lesson_node_00033).

2.  **Compositional/Global Stream:**
    *   **Input:** A vector containing **Standardized Global Features**: Lattice Parameters (lengths/angles) and Atomic Composition Fractions.
    *   **Processing:** A dedicated Multi-Layer Perceptron (MLP) processes these features. This stream explicitly captures macroscopic strain and stoichiometry, which data analysis showed to be highly correlated with targets, without disrupting the local GNN optimization (addressing solution_lesson_node_00022).

3.  **Fusion & Readout:**
    *   The pooled graph embedding and the global embedding are **concatenated**.
    *   **Decoupled Heads:** The fused vector is passed into two separate, independent MLPs to predict `formation_energy_ev_natom` and `bandgap_energy_ev`. This prevents task interference and allows specialized feature extraction for each property (Cite solution_lesson_node_00039).

### Data
1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This ensures the GNN focuses on high-signal local bonds, while the Global Stream handles long-range dependencies.
3.  **Feature Engineering:**
    *   **Global Features:** Lattice parameters and composition fractions are extracted and **Standardized** (Z-score normalization) based on training set statistics. This is mandatory to ensure stable gradient flow in the Global Stream (Cite solution_lesson_node_00021).
4.  **Target Normalization:** Target variables are standardized to zero mean and unit variance.

### Training
1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the network.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise for generalization (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation
1.  **Inference:** Test set structures are processed into PBC-aware graphs and standardized global feature vectors.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
