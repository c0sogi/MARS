Based on the accumulated lessons from previous experiments, I propose the **Adaptive-Identity Crystal Graph Network (AI-CGN)**.

This solution is a structural evolution of the Crystal Graph Convolutional Neural Network (CGCNN). It directly addresses the trade-off between the high performance of "Amplified Residuals" (Lesson 00054) and the training stability required for convergence (Lesson 00055). By replacing fixed residual connections with **Learnable Scalar Residuals**, the model can dynamically optimize the preservation of atomic identity (stoichiometry) versus geometric mixing at each layer. Furthermore, it streamlines the readout architecture by reverting to **Global Mean Pooling** to align with the intensive nature of the target properties, discarding the ineffective dual-pooling and global-conditioning strategies attempted previously.

### Model

1.  **Graph Backbone (CGCNN):**
    *   **Interaction:** We retain the **Gated Graph Convolution** as the core message-passing mechanism. This architecture uses edge features to modulate both the content and strength of messages, providing the strong physical inductive bias that has consistently outperformed Graph Transformers and dynamic edge updates (Cite solution_lesson_node_00011, solution_lesson_node_00018).
    *   **Configuration:** The network will consist of **4 interaction layers** with a hidden dimension of **128**. This width ensures sufficient capacity for multi-target prediction without the overfitting risks of deeper or wider networks (Cite solution_lesson_node_00006, solution_lesson_node_00039).

2.  **Structural Innovation: Adaptive Identity Update:**
    *   Standard ResNets use the update $h_{l+1} = \sigma(h_l + \text{Conv}(h_l))$.
    *   The "Amplified Residual" ($2h_l$) improved generalization but caused instability.
    *   **Our Update Rule:** We implement a **Learnable Scalar Residual**:
        $$ h_{l+1} = \text{Softplus}(\text{BatchNorm}(\text{CGConv}(h_l, e_{ij}) + (1 + \epsilon_l) \cdot h_l)) $$
    *   Here, $\epsilon_l$ is a **learnable scalar parameter** for layer $l$, initialized to 0.0. This allows the network to start with stable unit-scaling but learn to amplify the identity path (preserving stoichiometric signal) where beneficial, automating the insight from Lesson 00054 while maintaining the stability noted in Lesson 00060. We strictly use a **scalar** rather than a vector to prevent feature distortion (Cite solution_lesson_node_00065). The activation is applied *after* the residual addition (Cite solution_lesson_node_00041).

3.  **Feature Encoding:**
    *   **Nodes:** Atoms are embedded into 128-dimensional vectors (Cite solution_lesson_node_00039).
    *   **Edges:** Interatomic distances are expanded using a static **60-bin Gaussian RBF** filter (Cite solution_lesson_node_00005). Crucially, these features are projected into the node dimension via a learnable **Linear Layer** *before* convolution to increase geometric expressivity (Cite solution_lesson_node_00042).

4.  **Readout:**
    *   **Pooling:** We use **Global Mean Pooling** exclusively. Previous experiments showed that Max Pooling (Lesson 00068) and Attention Pooling (Lesson 00033) degraded performance for these intensive properties (formation energy/bandgap). Mean pooling correctly averages local environments to a bulk property.
    *   **Decoupled Heads:** The pooled graph embedding is fed into two separate, independent Multi-Layer Perceptrons (MLPs) to predict `formation_energy_ev_natom` and `bandgap_energy_ev`, preventing task interference (Cite solution_lesson_node_00039).

### Data

1.  **Graph Construction:** We utilize a **Periodic Boundary Condition (PBC)** aware neighbor search (Cite solution_lesson_node_00009) to correctly model the infinite crystal lattice.
2.  **Local Constraints:** The neighbor cutoff radius is strictly set to **5.0 Å** (Cite solution_lesson_node_00007). This ensures the graph captures high-signal local bonds without introducing noise from distant, weakly interacting atoms.
3.  **Normalization:** Target variables are standardized (zero mean, unit variance) to ensure balanced gradients. We explicitly **exclude** auxiliary global features (lattice/composition) from the input, as previous attempts to fuse them (FiLM, Late Fusion) consistently interfered with the GNN's optimization (Cite solution_lesson_node_00022).

### Training

1.  **Optimizer:** We use **AdamW** to ensure effective decoupled weight decay regularization (Cite solution_lesson_node_00019).
2.  **Regularization:**
    *   **Weight Decay:** Set to **1e-4** (Cite solution_lesson_node_00003).
    *   **Dropout:** Applied at a rate of **0.1** within the interaction blocks.
3.  **Batch Size:** A batch size of **48** is selected to introduce beneficial gradient noise for generalization (Cite solution_lesson_node_00005).
4.  **Loss Function:** Mean Squared Error (MSE) on standardized targets.

### Evaluation

1.  **Inference:** Test set structures are processed into PBC-aware graphs using the same 5.0 Å cutoff and edge encoding.
2.  **Prediction:** The model predicts standardized values, which are inverse-transformed using the training set's mean and standard deviation to produce the final predictions in eV.
