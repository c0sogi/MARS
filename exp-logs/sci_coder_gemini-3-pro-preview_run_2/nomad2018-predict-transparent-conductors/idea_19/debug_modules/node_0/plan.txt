This script demonstrates the end-to-step usage of the provided library components. It performs the following steps:
1.  **Configuration Override**: redirects output directories to `./working/demo_run` to avoid clutter and conflicts, and suppresses progress bars.
2.  **Data Loading**: Instantiates data loaders using `get_dataloaders` with a small subset of the data (`data_sample_size=50`) for speed. It verifies the structure of the loaded batches.
3.  **Model Initialization**: Initializes the `SR_CGN_DP` model and verifies the forward pass on a single batch.
4.  **Training Pipeline**: Executes `run_training` for a few epochs to demonstrate the training loop, checkpointing, and submission generation.
5.  **Output Verification**: Validates that the submission file is created and has the correct format.
