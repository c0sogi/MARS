The following script demonstrates the usage of the provided library files for the Apple Disease Detection task.

### Strategy Outline
1.  **Configuration Setup**: We modify the global `CFG` class to enable debug mode (reducing dataset size) and set the number of epochs to 1. This ensures the script runs quickly within the demonstration limits.
2.  **Utility Verification**: We unit-test the `get_score` function with synthetic data to ensure the F1 metric calculation is correct.
3.  **Component Verification**: We verify the custom `GeM` pooling layer by passing a random tensor and checking the output dimensions.
4.  **Data Pipeline**: We initialize the DataLoaders using `get_loaders()` and verify that the data shapes (images and multi-hot targets) are correct.
5.  **Model Initialization & Forward Pass**: We instantiate the `AppleDiseaseModel`, perform a forward pass with a batch of data, and confirm the output logits shape matches the number of classes.
6.  **Training Loop**: We execute `fit_model` for a single epoch. This tests the training logic, validation step, backpropagation, and model checkpointing.
7.  **Inference & Submission**: We use the checkpoint generated in the previous step to run `generate_submission`, ensuring the full inference pipeline (including TTA and ensembling) works and produces a correctly formatted CSV file.
