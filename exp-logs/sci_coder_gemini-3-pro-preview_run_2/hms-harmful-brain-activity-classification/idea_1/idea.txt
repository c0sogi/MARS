Based on the task description and the provided model architectures, here is a proposal for a highly efficient baseline approach. This solution synthesizes the strength of 2D CNNs (from Model 2) with the high-resolution temporal data of raw EEG (from Model 3), creating a distinct and lightweight "EEG-to-Image" pipeline.

### Model
The proposed architecture is a **Spectrogram-Conversion CNN (Spec-CNN)**. Instead of using the pre-computed 10-minute spectrograms (which contain significant unlabelled context) or processing raw waveforms with 1D convolutions, this model dynamically converts the relevant 50-second EEG window into a high-resolution image representation.

*   **Input**: 50-second, multi-channel raw EEG signals (10,000 time steps).
*   **Feature Engineering Block**: A strictly defined signal processing layer that transforms the raw EEG into a **Log-Mel Spectrogram**.
    *   First, the EEG channels are combined into a **Longitudinal Bipolar Montage** (the "Double Banana" montage). This involves subtracting adjacent electrode signals (e.g., Fp1-F7, F7-T3) to create 4 distinct spatial chains (Left/Right Lateral, Left/Right Parasagittal). This standard clinical technique reduces noise and highlights the specific rhythmic patterns (LPD/GPD/LRDA) required for classification.
    *   Short-Time Fourier Transform (STFT) is applied to these chains, followed by a Mel-filterbank projection and Log transformation.
    *   The resulting spectrograms for the 4 chains are stacked vertically to form a single 2D composite image (Time x Frequency x Channels).
*   **Backbone**: A lightweight **EfficientNet-B0** pre-trained on ImageNet. This backbone is chosen for its balance of speed and accuracy, leveraging transfer learning to recognize visual patterns (spikes, waves) in the spectrograms.
*   **Head**: A Global Average Pooling layer followed by a single fully connected layer with **Softmax** activation to output the 6 class probabilities.

### Data
*   **Loading**: Iterate through `train.csv`. Use `eeg_id` to locate the parquet file and `eeg_label_offset_seconds` to slice the exact 50-second annotated window (start_sample = offset * 200).
*   **Preprocessing**:
    *   **Imputation**: Replace any `NaN` values in the EEG signal with the channel mean (or 0) to ensure continuous data for the FFT.
    *   **Image Construction**: Apply the montage and spectrogram conversion described above. Resize the output to a standard resolution (e.g., 512 x 512) compatible with the CNN.
    *   **Normalization**: Normalize the spectrogram pixel values using ImageNet statistics (mean/std) to facilitate faster convergence of the pre-trained backbone.

### Training
*   **Loss Function**: **Kullback-Leibler (KL) Divergence**. Since the targets are soft probabilities (vote counts normalized to sum to 1), KL Divergence is the mathematically correct loss function and directly optimizes the competition metric.
*   **Optimizer**: **AdamW** with a Cosine Annealing learning rate scheduler. This ensures rapid initial learning and stable fine-tuning.
*   **Validation Strategy**: **GroupKFold** (5 splits) grouped by `patient_id`. This is critical to avoid data leakage, as samples from the same patient often exhibit similar artifacts or background activity.
*   **Augmentation**: **SpecAugment**. Apply random time masking and frequency masking to the generated spectrograms during training. This forces the model to learn robust features rather than relying on specific artifacts.

### Evaluation
*   **Pipeline**: For each row in `test.csv`:
    1.  Load the corresponding file from `test_eegs/`. These files are exactly 50 seconds long, so no offset slicing is required.
    2.  Apply the identical Bipolar Montage -> Mel-Spectrogram -> Normalization pipeline used in training.
    3.  Pass the image through the trained model.
*   **Submission**: Collect the softmax probability outputs for the 6 classes (`seizure_vote`, `lpd_vote`, etc.) and write them to the submission CSV, ensuring the row probabilities sum to 1.
