2.  **Regularization (MixUp)**: I will implement MixUp augmentation in the training loop. This technique mixes input images and their corresponding target probabilities, encouraging the model to learn smoother decision boundaries and improving performance on the KL Divergence metric.
3.  **Refined Training**: I will reduce the number of epochs to 6, as the full dataset provides more updates per epoch, ensuring the run completes within the 4-hour limit.
4.  **Conditional Submission**: I will enforce the logic to only generate the submission file if the validation KL divergence improves upon the previous baseline (1.0346).
