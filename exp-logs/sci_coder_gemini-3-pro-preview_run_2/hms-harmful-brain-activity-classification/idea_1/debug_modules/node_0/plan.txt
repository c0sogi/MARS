The following script demonstrates the usage of the provided library modules to build, train, and validate the EEG classification pipeline.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the static `Config` attributes at runtime to adapt the pipeline for a quick demonstration (e.g., reducing epochs, batch size, and disabling pretrained weight downloads to ensure offline compatibility).
2.  **Component Verification**: We systematically instantiate and verify the logic of the `EEGProcessor`, `EEGDataset`, and `SpecEfficientNet` classes using assertions to ensure shapes and data types are correct.
3.  **Training Simulation**: We create a small subset of the training data (16 samples) and run a complete training epoch using the `Trainer` class. This verifies the integration of the data loader, model, loss function, and optimizer.
4.  **Inference & Submission**: We demonstrate how to generate predictions on a test set and format the results into the required submission format.
