The implementation strategy is as follows:

1.  **Setup & Configuration**: Define input/output directories and the random state for reproducibility.
2.  **Data Loading**: Load the provided JSON annotation files (`iwildcam2020_train_annotations.json` and `iwildcam2020_test_information.json`).
3.  **Data Processing**:
    *   Convert the JSON data into Pandas DataFrames.
    *   Merge image metadata with annotation data to associate labels with images.
    *   Construct relative file paths (e.g., `train/<filename>`) for all images.
    *   Handle missing values by filling missing categories with `0` (representing "empty").
4.  **Dataset Splitting**:
    *   Check if the `location` attribute exists in the training data.
    *   If `location` exists, perform **Group Sampling** (using `GroupShuffleSplit`) to split data 80:20 by location. This prevents data leakage where images from the same camera trap appear in both train and validation sets.
    *   If `location` is missing, fall back to **Stratified Sampling** (using `StratifiedShuffleSplit`) based on the category label.
5.  **Metadata Generation**: Save the final training, validation, and test DataFrames as CSV files in the `./metadata` directory.
6.  **Verification**:
    *   Reload the saved metadata.
    *   Print summary statistics (count, unique classes, etc.).
    *   **File Existence Check**: Randomly sample 1000 paths from each dataset and verify they exist on disk. Raise an error if >50% are missing.
    *   **Split Validation**: Programmatically verify that the split requirements are met (e.g., no overlapping locations between train and val).
