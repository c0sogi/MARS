This script demonstrates the end-to-end usage of the provided machine learning pipeline for the iWildCam 2020 task. It overrides specific configurations to ensure a rapid execution (under a few minutes) by using a small subset of the data and a single training epoch.

**Implementation Strategy:**
1.  **Setup & Configuration**: Initialize the random seed and override default `Config` parameters (Batch Size, Epochs, Paths) to create a lightweight "Demo" environment.
2.  **Data Loading**: Use `get_dataloaders` with a `sample_size` of 50 images. This triggers the MegaDetector processing (if not cached) and creates PyTorch DataLoaders. We verify the batch shapes and the Mixup/CutMix collator logic.
3.  **Model Initialization**: Instantiate the EfficientNetV2 model using `get_model` and verify it moves to the correct device (GPU/CPU).
4.  **Training Loop**: Execute `train_one_epoch` with a `GradScaler` for mixed precision. We assert that the loss is a valid finite number.
5.  **Validation Loop**: Execute `validate` on the validation subset and assert that the accuracy is within the valid range [0, 1].
6.  **Inference**: Run `generate_submission` to produce predictions on the test subset. We verify the output CSV's existence, dimensions, and column names.
