To establish a highly efficient baseline that balances speed and accuracy while remaining distinct from the provided architectures, I propose a **Deep Averaging Network (DAN)**. This architecture offers a neural alternative to linear models and is significantly faster than recurrent or transformer-based approaches.

### Model
The architecture is a **Deep Averaging Network (DAN)**, which functions as a "bag-of-embeddings" model with added non-linearity.
1.  **Embedding Layer**: The model begins with a learnable embedding layer that maps each word index in the input sequence to a dense vector representation. Unlike Model 4, these embeddings are initialized randomly and trained from scratch on this specific dataset.
2.  **Global Average Pooling**: The sequence of word embeddings is aggregated by computing their mean. This operation compresses the variable-length text into a fixed-size vector efficiently, ignoring word order but capturing the global semantic content.
3.  **Deep Feature Extraction**: The averaged vector is passed through a series of fully connected (dense) hidden layers with non-linear activation functions (e.g., ReLU) and Batch Normalization. This allows the model to learn complex interactions between words (e.g., "python" + "list" implying a specific coding context) that a simple linear model might miss.
4.  **Output Layer**: The final layer is a dense projection to the output size equal to the number of target tags, followed by a Sigmoid activation function to produce independent probabilities for each tag.

### Data
1.  **Text Preprocessing**:
    *   Concatenate the `Title` and `Body` columns to form a single input text.
    *   Remove HTML tags using regex to reduce noise.
    *   Normalize text to lowercase and remove non-alphanumeric characters.
2.  **Tokenization & Vocabulary**:
    *   Tokenize the cleaned text by splitting on whitespace.
    *   Construct a vocabulary from the top $N$ (e.g., 50,000) most frequent words in the training set. Map rare words to an `<UNK>` token.
3.  **Label Processing**:
    *   Identify the top $K$ (e.g., 2,000–5,000) most frequent tags. This covers the vast majority of the dataset's volume while filtering out the "long tail" of rare tags that add computational overhead with minimal gain for a baseline.
    *   Encode the targets as Multi-Hot vectors (binary vectors of length $K$, where 1 indicates the presence of a tag).

### Training
1.  **Loss Function**: Use **Binary Cross-Entropy with Logits Loss** (BCEWithLogitsLoss). This treats the prediction of each tag as an independent binary classification problem, which is standard for multi-label tasks.
2.  **Optimizer**: Use the **Adam** optimizer, which handles sparse updates for the embedding layer effectively.
3.  **Strategy**:
    *   Train with a large batch size (e.g., 512 or 1024) to maximize GPU utilization, as the model is computationally lightweight.
    *   Implement Early Stopping based on the validation loss to prevent overfitting.
    *   Use Mixed Precision training to further reduce memory usage and increase speed.

### Evaluation
1.  **Inference**: Pass the preprocessed test data through the trained model to obtain probability scores for each of the $K$ tags.
2.  **Thresholding**:
    *   Apply a probability threshold to convert scores into binary predictions.
    *   To optimize the Mean F1-Score, determine the optimal threshold by evaluating the model on the validation set (e.g., finding a threshold $t$ such that probabilities $> t$ are predicted as positive).
3.  **Formatting**: Convert the indices of the predicted positive classes back to their string tag representations and join them with spaces for the final submission.
