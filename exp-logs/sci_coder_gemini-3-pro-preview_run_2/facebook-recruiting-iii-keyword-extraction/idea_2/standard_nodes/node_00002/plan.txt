Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Setup and Configuration**: Initialize random seeds and define constants for data limits (1M training samples for speed, 50k validation samples) and paths.
2.  **Data Loading**: Use `library.data_processing.get_processed_data` to load training and validation sets.
3.  **Feature Extraction**: Use `library.feature_extraction.TfidfEmbedder` to vectorize text data. Fit on training data and transform validation data.
4.  **Target Encoding**: Use `library.label_manager.TagEncoder` to encode tags into sparse binary matrices.
5.  **Model Training**: Instantiate and fit the `library.centroid_classifier.SparseNCC` model on the training features and targets.
6.  **Validation and Threshold Optimization**:
    *   Predict probability scores on the validation set.
    *   Use `library.evaluation.optimize_threshold` to find the best decision threshold maximizing the F1-Score.
    *   Report the **Final Validation Metric** with full precision.
7.  **Failure Analysis**:
    *   Compute F1-Score per sample for the validation set.
    *   Calculate the error magnitude ($1 - F1$).
    *   Compute the correlation between error magnitude and input text length to identify performance bottlenecks.
8.  **Submission Generation**:
    *   Load the full test set.
    *   Transform test text using the fitted TF-IDF embedder.
    *   Generate predictions using the trained model and optimal threshold.
    *   Decode binary predictions back to tag strings using the encoder.
    *   Save the results to `./submission/submission.csv` using `library.utils.save_submission`.
