# Strategy: Hybrid Wide-and-Deep Network with Attention-Pooled Multi-Scale CNN

### Model
I propose a **Wide-and-Deep** architecture that structurally evolves the previous TextCNN idea by incorporating **Attention Pooling** and a dedicated **Lexical Shortcut**.

1.  **Wide Component (Lexical Precision):**
    *   **Input:** High-dimensional sparse **TF-IDF vectors** (unigrams and bigrams).
    *   **Layer:** A single fully connected linear layer mapping the TF-IDF features directly to the output tags.
    *   **Rationale:** This component explicitly preserves the "simple count-based" modeling approach that was found to be superior for this high-cardinality task **Cite {solution_lesson_node_00007}**. It ensures that specific technical keywords (e.g., "NullPointerException") trigger their corresponding tags directly without being diluted by dense embeddings.

2.  **Deep Component (Semantic Context):**
    *   **Backbone:** A **Multi-Scale 1D Convolutional Network (TextCNN)**. It uses parallel convolutional filters with varying kernel sizes (e.g., 3, 4, and 5) to detect local n-gram patterns (phrases) dynamically.
    *   **Innovation (Attention Pooling):** Instead of the standard Global Max Pooling (which extracts only the single strongest feature, potentially ignoring secondary tags), I will implement a **Self-Attention Pooling** layer. This mechanism computes a weighted sum of the convolutional feature maps, allowing the model to aggregate evidence for multiple distinct tags appearing in different parts of the document.
    *   **Rationale:** This addresses the multi-label nature of the problem better than Max Pooling while remaining significantly faster than Transformers, enabling full-dataset training.

3.  **Fusion & Output:**
    *   The logits from the Wide and Deep paths are summed.
    *   **Activation:** A **Sigmoid** activation function is applied to the final output. This ensures predictions are bounded probabilities in the range $[0, 1]$, directly resolving the issue of unbounded scores that caused the failure of the Naive Bayes approach **Cite {solution_lesson_node_00006}**.

### Data
1.  **Full Dataset Utilization:** We will train on the **entire 4.3M sample training set**. We will strictly avoid subsampling, as previous experiments demonstrated that data coverage is more critical than model complexity for this task **Cite {solution_lesson_node_00007}**.
2.  **Dual Preprocessing:**
    *   **Wide Stream:** Concatenate Title and Body, clean HTML, and compute TF-IDF features retaining the top 150,000 unigrams and bigrams.
    *   **Deep Stream:** Tokenize text using a vocabulary of the top 50,000 words. Pad/truncate sequences to a fixed length (e.g., 200 tokens) to capture the most informative initial content (Title + first paragraph) efficiently.
3.  **Targets:** Encode the top 5,000 most frequent tags as Multi-Hot binary vectors.

### Training
1.  **Loss Function:** Implement **Focal Loss**. Standard Binary Cross Entropy struggled with the massive class imbalance (sparsity) in previous attempts. Focal Loss will dynamically down-weight the contribution of easy negatives (the vast majority of labels) and focus gradient updates on hard, misclassified examples **Cite {solution_lesson_node_00007}**.
2.  **Optimization:** Use the **AdamW** optimizer.
3.  **Efficiency:** Utilize **Mixed Precision (FP16)** training. This is essential to fit the large sparse weights of the Wide component and the dense parameters of the Deep component simultaneously on the GPU memory.

### Evaluation
1.  **Inference:** Generate probability scores for the validation set using the trained model.
2.  **Dynamic Thresholding:** We will not use a hard-coded search range. Instead, we will calculate the **percentiles of the predicted probabilities** on the validation set. The optimal threshold will be searched for dynamically within a range defined by these percentiles (e.g., between the 95th and 99.9th percentile) to ensure the decision boundary adapts to the model's confidence distribution **Cite {solution_lesson_node_00006}**.
3.  **Prediction:** Apply the tuned threshold to the test set predictions and format the output.
