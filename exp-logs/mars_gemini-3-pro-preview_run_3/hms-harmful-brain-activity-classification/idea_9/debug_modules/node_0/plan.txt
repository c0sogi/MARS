### Implementation Strategy

1.  **Configuration Setup**: We will dynamically override the default `Config` parameters (e.g., batch size, epochs, pretrained status) to ensure the script runs quickly and does not require internet access for downloading model weights.
2.  **Utility Verification**: We will demonstrate the `seed_everything` function for reproducibility and the `AverageMeter` class to ensure metric tracking works as expected.
3.  **Transform Logic Check**: We will manually create dummy data (a Pandas DataFrame for EEG and a NumPy array for Spectrograms) and pass them through the `EEGTransform` and `SpectrogramTransform` classes. We will assert that the output tensor shapes match the dimensions expected by the model (Siamese streams).
4.  **Data Pipeline Verification**: We will initialize the `EEGDataset` and `DataLoader` using the provided `get_dataloaders` function in debug mode. We will iterate through a single batch to verify data loading, shape consistency, and target alignment.
5.  **Model Initialization**: We will instantiate the `SiameseEquivariantNet` using `get_model` (with `pretrained=False` for speed). We will perform a dummy forward pass with the batch loaded in the previous step to verify the network architecture and output dimensions.
6.  **Training Loop Demonstration**: We will execute a single training epoch using `train_one_epoch` and a validation run using `validate` on the subset of data. This verifies the integration of the model, data, and loss calculation.
7.  **Inference Demonstration**: Finally, we will run the `inference` function to generate predictions and verify the output submission file format.
