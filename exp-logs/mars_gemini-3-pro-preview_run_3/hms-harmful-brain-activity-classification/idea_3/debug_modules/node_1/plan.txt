The `OSError: [Errno 24] Too many open files` is caused by the `DataLoader` creating an excessive number of worker processes, which exhausts the system's file descriptor limit. This happens because `NUM_WORKERS` is initialized to `os.cpu_count()` (which can be high on the host machine) and multiple `DataLoader` instances are active simultaneously (one in the verification step and two in the training loop). I will fix this by reducing `NUM_WORKERS` to a fixed, safe value of 4 in `library/config.py`.
