Implementation Strategy:
1.  **Setup & Configuration**: Import necessary modules and the provided `library`. Override `Config` settings to ensure a fast baseline execution. This involves creating smaller subsets of the training and validation metadata (10,000 and 2,000 samples respectively) saved to the working directory, and updating `Config.TRAIN_CSV`, `Config.VAL_CSV`, and `Config.EPOCHS` (reduced to 5).
2.  **Training**: Execute the training pipeline by calling `library.train.train_model()`. This uses the subsets and reduced epochs to train the Bi-GRU model quickly.
3.  **Validation & Failure Analysis**:
    *   Reload the validation dataset and the best model checkpoint.
    *   Perform inference on the validation set to compute the Kullback-Leibler (KL) Divergence for each sample.
    *   Calculate and print the `Final Validation Metric` (mean KL Divergence).
    *   Merge error metrics with metadata to calculate and print correlations between error magnitude and features like `total_votes`.
4.  **Submission**: Generate the final submission file for the test set by calling `library.inference.generate_submission()`.
5.  **Environment**: Ensure `load_cached_data=True` is used where applicable, random seeds are set, and warnings are suppressed.
