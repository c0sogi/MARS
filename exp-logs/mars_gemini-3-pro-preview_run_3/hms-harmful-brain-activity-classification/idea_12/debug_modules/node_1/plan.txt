The `TimeoutError` is caused by `load_and_cache_data` processing the entire dataset (over 81,000 files) even when the pipeline is running in debug mode. This happens because the `debug` flag in `get_dataloaders` is not passed down to `load_and_cache_data`, preventing it from slicing the metadata dataframe before the expensive file processing loop begins. To fix this, I will modify `load_and_cache_data` to accept a `debug` parameter and slice the dataframe to a small subset (200 samples) immediately after loading the CSVs. I will also update `get_dataloaders` to pass the `debug` flag to this function.
