This script demonstrates the end-to-end usage of the provided EEG classification library. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory and reduces epochs/batch size for a rapid demonstration.
2.  **Utility Verification**: Validates the `kl_divergence` metric and `AverageMeter` logic with assertions.
3.  **Data Pipeline Verification**: Initializes the data loaders in debug mode (subset of data), fetches a single batch, and asserts that the input shapes for both Stream A (EEG signals) and Stream B (Spectrograms) match the architectural requirements.
4.  **Model Verification**: Instantiates the `MultiResNetwork`, performs a forward pass with the fetched batch, and verifies that outputs are valid probability distributions (shape, summation, range).
5.  **Training Loop Execution**: Runs the `Trainer` for a single epoch to demonstrate the training, validation, and checkpointing workflow.
6.  **Inference & Submission**: Generates predictions on the test set using the trained model and creates a sample submission file.
