The following implementation demonstrates the usage of the provided library files to train and evaluate the brain activity classification model. It performs the following steps:

1.  **Configuration**: Defines a `DemoConfig` class that overrides the default configuration to run a fast, lightweight demonstration (1 epoch, small batch size, tiny dataset subset).
2.  **Data Transform Verification**: Validates the custom `MultiResolutionSTFT` and Albumentations pipeline using synthetic data to ensure input shapes match model expectations.
3.  **Dataset Verification**: Instantiates the `EEGDataset` with the demo configuration, processes a small subset of real data from the `./input` directory, and verifies the integrity of the generated tensors.
4.  **Model Verification**: Instantiates the `MultiResDualStreamNet`, performs a forward pass with a batch of data, and asserts that the output dimensions are correct.
5.  **Training Loop**: Uses the `Trainer` class to train the model for one epoch on the debug subset, verifying that the loss is computed and model checkpoints are saved.
6.  **Inference**: Runs the inference pipeline on the test set (using the trained demo model) and generates a valid `submission.csv`.
