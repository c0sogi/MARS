Implementation strategy:
1.  **Configuration**: Import the `Config` class and override `Config.EPOCHS` to 2 to ensure the training completes quickly (Fast Baseline).
2.  **Training**: Execute `library.train.run_training` to train the `AttentiveDualScaleNetwork`. This utilizes the provided data loading, augmentation, and training loop.
3.  **Validation & Metric**:
    *   Load the best saved model state.
    *   Initialize a validation `DataLoader` using the full validation set (`metadata/val.csv`).
    *   Run inference in `eval` mode to collect predictions and ground truth targets.
    *   Compute the global KL Divergence metric and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the KL divergence error for each individual sample in the validation set.
    *   Load the validation metadata.
    *   Calculate Pearson correlations between the per-sample error and metadata features (e.g., `total_votes`, `eeg_label_offset_seconds`).
    *   Print the correlation table to identify systematic failure modes.
5.  **Submission**:
    *   Compare the final validation metric against the threshold `0.9081844091415405`.
    *   If the model performance is sufficient (metric < threshold), run the `library.inference.predict` function to generate predictions for the test set.
    *   Save the resulting dataframe to `./submission/submission.csv` as specified.
