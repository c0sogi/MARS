The previous implementation caused a `numpy._core._exceptions._ArrayMemoryError` because it attempted to store the entire processed dataset (approximately 100GB) in a Python list and then stack it into a single NumPy array in RAM. This exceeded the available memory.

This allows creating the `.npy` files directly on disk and writing to them incrementally during the processing loop, rather than accumulating data in memory.
