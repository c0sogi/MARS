The following strategy outlines the implementation of a self-contained Python script to demonstrate the artwork attribute labeling pipeline:

1.  **Configuration Override**: We will first import the `Config` class and override specific settings to enable "Debug Mode". This involves setting `debug=True` (to use a small subset of data), reducing `epochs` to 2, setting `pretrained=False` (to skip downloading heavy weights), and defining a separate working directory (`./working/demo_run`) to isolate outputs.
2.  **Component Verification**: We will systematically instantiate and verify the core components:
    *   **Data**: Initialize `ArtworkDataset` and `DataLoader` to verify image loading, transformation, and target shape correctness.
    *   **Model**: Instantiate the ResNet-101 based model and perform a forward pass with a dummy batch to verify output dimensions.
    *   **Loss**: Compute `AsymmetricLoss` on the dummy output to ensure numerical stability and non-negativity.
    *   **Metrics**: validate the `calculate_micro_f1` function with known synthetic inputs.
3.  **Pipeline Execution**:
    *   **Training**: Execute `run_training()`. This will run a complete training loop (train and validation steps) on the debug subset and save the best model checkpoint.
    *   **Inference**: Execute `run_inference()`. This will load the saved checkpoint, optimize the decision threshold on the validation set, and generate a submission file for the test set.
4.  **Output Validation**: Finally, we will check for the existence of the generated submission file and verify its structure (columns and row count) against the expected debug dataset size.
