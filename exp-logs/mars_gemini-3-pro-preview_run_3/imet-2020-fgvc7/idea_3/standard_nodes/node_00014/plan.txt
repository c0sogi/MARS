To improve the model's performance, I will implement a strategy focused on upgrading the backbone architecture and increasing input resolution, leveraging the available computational budget and the `timm` library.

1.  **Architecture Upgrade (Cite Lesson 10, 11)**: I will switch the backbone from the standard `torchvision` ResNet101 to `timm`'s `resnet101d`. The "d" variant (Deep Stem) improves feature extraction by replacing the 7x7 input convolution with three 3x3 convolutions, preserving more information from the input image. This is particularly beneficial for fine-grained attribute recognition. I will maintain the aggressive learning rate (`1e-3`) as suggested in Lesson 10 to ensuring convergence.

2.  **Resolution Increase (Cite Lesson 8)**: I will increase the image size from 320x320 to 352x352. Lesson 8 highlighted that resolution matters, provided we don't sacrifice data volume. Since we are training on the full dataset, this moderate increase in resolution (approx +20% pixels) allows the model to resolve smaller details without incurring the massive penalty of 384+ sizes that required data subsampling in previous experiments.

3.  **Extended Training (Cite Lesson 3, 12)**: I will extend the training duration from 10 to 12 epochs. The previous run completed in ~1 hour, leaving ample time within the 4-hour limit. This extension allows the `OneCycleLR` scheduler to anneal more slowly, potentially improving convergence on the high-cardinality label space.

4.  **Batch Size Adjustment**: To accommodate the larger model and resolution on the GPU, I will reduce the batch size from 128 to 96.

from library.config import Config


def get_artwork_model(num_classes=Config.num_classes, pretrained=Config.pretrained):
    """
    Constructs the ResNet-101 model for multi-label artwork attribute classification.

    Args:
        num_classes (int): The number of output classes (attributes).
        pretrained (bool): Whether to load ImageNet pretrained weights.

    Returns:
        torch.nn.Module: The configured ResNet-101 model.
    """
    # Determine weights parameter based on pretrained flag
    # Using 'DEFAULT' loads the best available weights for the version
    weights = "DEFAULT" if pretrained else None

    # Load the ResNet-101 backbone
    # This architecture provides the depth required to disentangle complex attributes
    model = models.resnet101(weights=weights)

    # The standard ResNet architecture ends with:
    # 1. Global Average Pooling (avgpool)
    # 2. Fully Connected layer (fc)

    # We retrieve the input feature dimension of the final layer
    # For ResNet-101, this is 2048
    in_features = model.fc.in_features

    # Replace the final fully connected layer
    # This acts as the linear projection from the 2048-dim feature space to class logits
    model.fc = nn.Linear(in_features, num_classes)

    return model
