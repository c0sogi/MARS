Implementation Strategy:
1.  **Environment Setup**: Define paths for input (`./input`) and output (`./metadata`). Ensure the output directory is clean.
2.  **Data Loading**: Load `articles.csv` to generate image paths and `transactions_train.csv` for the interaction history. Load `sample_submission.csv` for the test set user list.
3.  **Metadata Enrichment**:
    *   Convert `article_id` to string format (padded with zeros to length 10) to construct relative image paths (e.g., `images/010/0108775015.jpg`).
    *   Merge these image paths into the transactions dataframe.
4.  **Data Splitting (Group Sampling)**:
    *   Extract unique `customer_id`s from the transactions.
    *   Shuffle these IDs using `RANDOM_STATE = 42`.
    *   Split the IDs into 80% training and 20% validation sets.
    *   Partition the transaction data based on these customer sets to ensure no data leakage between users (Group Split).
5.  **Output Generation**: Save the partitioned dataframes (Train, Validation) and the Test dataframe (from sample submission) as Parquet files in the `./metadata` directory.
6.  **Verification**:
    *   Reload the generated metadata.
    *   Print summary statistics (shapes, unique users, etc.).
    *   Verify the group split (check for user overlap).
    *   Perform the "Missing File Ratio" check by sampling 1000 image paths and checking their existence in `./input`. Raise an error if >50% are missing.
