This script demonstrates the end-to-end usage of the provided machine learning pipeline for the H&M Recommendation task. It performs the following steps:

1.  **Data Loading & Sampling**: Loads the transaction data and splits it into history (training input) and target (ground truth). To ensure the demonstration runs quickly, it samples the datasets to a manageable size (100k transactions for history, 1k users for training/testing).
2.  **Retrieval (Stage 1)**: Initializes the `SparseGraphRetriever` to build a transition matrix from the user history. It then queries this model to generate candidate items for both the training set users and the test set users.
3.  **Feature Engineering**: Uses the `FeatureEngineer` to enrich the candidate items with static metadata (user/item features) and dynamic features (e.g., popularity, days since last purchase). It generates labeled data for training and unlabeled data for inference.
4.  **Ranking (Stage 2)**: Initializes and trains the `LGBMRanker` (LightGBM) on the processed training features. It uses a simplified configuration (fewer trees) for speed.
5.  **Inference & Submission**: Uses the trained ranker to predict scores for the test candidates, selects the top 12 items per user, and generates a submission file in the correct format, handling missing predictions with a fallback strategy.
