The issue is that `LGBM_PARAMS` is defined as a dataclass field using `field(default_factory=...)`. In Python `dataclasses`, fields defined this way are intended to be instance attributes initialized during `__init__`, and they are not accessible as direct attributes of the class itself (i.e., `Config.LGBM_PARAMS` raises an `AttributeError` or returns a `Field` object, not the dictionary). However, the codebase treats `Config` as a static configuration namespace and attempts to access and modify `Config.LGBM_PARAMS` directly in `runfile.py` without instantiating `Config`.

To fix this, I will modify `library/config.py` to define `LGBM_PARAMS` as a standard class attribute by removing the type annotation and the `field` wrapper. This ensures it is treated as a plain class variable (a dictionary) that is accessible statically, which aligns with the usage pattern in `runfile.py` and `library/ranking_model.py`.
