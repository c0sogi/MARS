The implementation strategy is as follows:

1.  **Configuration & Setup**: Import the provided library modules. Override `Config.EPOCHS` to a smaller value (e.g., 15) to ensure the training completes quickly while still learning effectively. Set the random seed for reproducibility.
2.  **Data Loading**: Use `load_and_process_data(load_cached_data=True)` to efficiently load the preprocessed training, validation, and test datasets. Wrap these in `VentilatorDataset` and `DataLoader` instances.
3.  **Model Training**: Initialize the `PhysicsGRU` model and `AdamW` optimizer. Use the provided `Trainer` class to fit the model. The trainer handles the masked L1 loss (focusing only on the inspiratory phase) and saves the best model checkpoint.
4.  **Validation & Metrics**: Load the best saved model state. Run inference on the full validation set to compute the final Mean Absolute Error (MAE) on the inspiratory phase. Print this metric in the required format.
5.  **Failure Analysis**: Calculate the absolute error for each prediction in the validation set. Compute and print the Pearson correlation between the error magnitude and each input feature to identify which conditions lead to higher errors.
6.  **Submission Generation**: Run inference on the test set. Flatten the sequence predictions to match the tabular format of `sample_submission.csv`. Load the test metadata to retrieve the correct `id`s and save the final `submission.csv`.
