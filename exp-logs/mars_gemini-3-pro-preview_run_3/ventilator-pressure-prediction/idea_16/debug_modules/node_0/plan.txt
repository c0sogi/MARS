This script demonstrates the end-to-end usage of the provided library for the Ventilator Pressure Prediction task. It covers configuration setup, feature engineering, dataset creation, model instantiation, training, and inference.

To ensure the demonstration runs quickly within the time limit, the script overrides global configuration settings to enable `DEBUG` mode (using a small subset of data) and reduces the number of training epochs. It includes assertions at each step to verify the correctness of shapes, data types, and logic.
