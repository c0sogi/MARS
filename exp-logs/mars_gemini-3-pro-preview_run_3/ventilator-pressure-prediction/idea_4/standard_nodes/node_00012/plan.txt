This implementation orchestrates the "Physically-Disentangled Hybrid Strategy" (Idea 4) as a fast baseline.

**Implementation Strategy:**
1.  **Setup & Configuration**: Imports necessary components from the provided library. Modifies the `Config` at runtime to enable `DEBUG` mode and limit the training set to 15,000 breaths (approx. 20% of data) and 10 epochs. This ensures the execution completes rapidly while still learning a valid model.
2.  **Data Loading**:
    *   Initializes the `DataManager`.
    *   Loads the **Training Set** in `DEBUG` mode (truncated) for speed.
    *   Switches `Config.DEBUG` to `False` before loading the **Validation Set** to ensure evaluation is performed on the **entire hold-out dataset** as required.
3.  **Training**: Runs a standard training loop using `AdamW` and `ReduceLROnPlateau`. Utilizes the `DisentangledTCNLSTM` model and `MaskedMAELoss` (inspiratory phase only). Saves the best model based on validation loss.
4.  **Metric Reporting**: Prints the final validation metric with full precision.
5.  **Failure Analysis**: Reloads the best model and iterates through the validation set to compute element-wise absolute errors. Calculates and prints the Pearson correlation between the error magnitude and key physical features (`u_in`, `R`, `C`) to identify error sources.
6.  **Submission**: Checks if the validation metric meets the threshold (< 0.8097). If successful, loads the full Test Set, generates predictions, aligns them with the `id` column from the test metadata, and saves `submission.csv`.
