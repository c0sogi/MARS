This script demonstrates the end-to-end usage of the provided ventilator pressure prediction library. It configures the environment for a fast "debug" run, verifying the data pipeline, model architecture, loss calculation, and training loop without processing the entire dataset or running for a long duration.

Key steps implemented:
1.  **Configuration Override**: Modifies `Config` to use a temporary directory and enables `DEBUG` mode to limit data size (processing only a small subset of breaths).
2.  **Data Pipeline Verification**: Uses `DataManager` to load and preprocess data, then asserts that the resulting tensor shapes match the expected dimensions (Batch, Time Steps, Features).
3.  **Model Logic Check**: Instantiates the `DisentangledTCNLSTM` model, performs a forward pass with a dummy batch, and validates the output shape.
4.  **Loss Function Validation**: Manually computes the Masked MAE for a synthetic case and asserts that the `MaskedMAELoss` class produces the identical result.
5.  **Training Loop Execution**: Runs a single epoch of training and evaluation using the `engine` module to ensure the optimization pipeline functions correctly.
