The following script demonstrates the usage of the provided library files for the ventilator pressure prediction task. It follows a structured approach:
1.  **Configuration**: Defines a `DemoConfig` subclass to enable `DEBUG` mode, reduce epochs, and set specific paths for the demonstration to ensure it runs quickly (under 1 minute).
2.  **Unit Testing**: Verifies the logic of the `compute_mae` utility and the `PSANet` model architecture using dummy data.
3.  **Data Processing**: Uses `DataProcessor` to load, feature-engineer, and scale a small subset of the data, asserting correct output shapes.
4.  **Dataset Loading**: Verifies the `VentilatorDataset` correctly yields tensors.
5.  **Full Pipeline Execution**: Uses the `Trainer` class to run the complete workflow (data prep -> training -> validation -> prediction -> submission) and verifies the final output file.
