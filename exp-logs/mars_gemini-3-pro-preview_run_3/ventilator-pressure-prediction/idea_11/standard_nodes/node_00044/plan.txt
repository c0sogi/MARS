The `FileNotFoundError` occurs because the script attempts to save the scaler statistics (`scaler_stats.npz`) to the working directory before that directory has been created. The directory creation logic (`os.makedirs`) is currently placed later in the `prepare_datasets` function, intended for the main dataset cache. To fix this, I will move the `os.makedirs(Config.WORKING_DIR, exist_ok=True)` call to immediately precede the `np.savez` call, ensuring the directory exists before any artifacts are written. I will also remove the subsequent, now redundant, directory creation call.
