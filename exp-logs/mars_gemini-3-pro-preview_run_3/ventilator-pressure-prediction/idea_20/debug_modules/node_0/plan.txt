This script demonstrates the end-to-end usage of the provided ventilator pressure prediction library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` class to run in `DEBUG` mode (using a small data subset), reduces the number of epochs for speed, and redirects output to a demo directory. It explicitly updates dependent file paths.
2.  **Data Preparation**: Calls `prepare_datasets` to load, feature-engineer, scale, and reshape the data. It verifies the shape and integrity of the generated tensors.
3.  **Model Verification**: Instantiates the `CWDHNet` model and performs a forward pass with dummy data to verify the architecture and output dimensions.
4.  **Loss Function Verification**: Tests the `MaskedMAELoss` to ensure it correctly ignores the expiratory phase (where `u_out=1`) and computes error only for the inspiratory phase.
5.  **Training Loop**: Executes `run_training` from the library to train the model on the subset of data.
6.  **Inference**: Runs `generate_predictions` to create a submission file using the trained model and verifies the output format.
