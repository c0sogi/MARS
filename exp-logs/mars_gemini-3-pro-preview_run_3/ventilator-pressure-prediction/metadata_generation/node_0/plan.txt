The implementation strategy involves the following steps:

1.  **Setup and Configuration**: Define the input directory (`./input`) and the output metadata directory (`./metadata`). Set the random seed to 42 for reproducibility.
2.  **Data Loading**: Read the raw `train.csv` and `test.csv` files using pandas.
3.  **Group-based Splitting**:
    *   Identify unique `breath_id`s from the training data to ensure that time steps belonging to the same breath are not split across datasets (Group Sampling).
    *   Shuffle the unique `breath_id`s and split them into an 80% training set and a 20% validation set.
4.  **Metadata Generation**:
    *   Filter the original training data based on the split `breath_id`s to create the final training and validation dataframes.
    *   Save these dataframes, along with the test dataframe, as CSV files in the `./metadata` directory. This creates self-contained split datasets that allow for efficient loading without repeated filtering.
5.  **Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (shapes, unique breath counts, target distribution).
    *   Programmatically verify that the group split was successful (no `breath_id` leakage between train and validation).
    *   Verify that the split ratio is correct.
    *   Verify that ground-truth labels (`pressure`) are present in the training and validation sets.
