The following strategy outlines the implementation of the demonstration script:

1.  **Environment Setup**: Initialize the random seeds using `seed_everything` to ensure reproducibility.
2.  **Data Subsetting**: To satisfy the "Optimize for Speed" requirement, create a temporary directory and generate small subsets of the original metadata files (Train, Validation, Test). This ensures the demonstration runs quickly (seconds instead of hours) while exercising the full pipeline. We will extract exactly 100 breaths (8000 rows) per file to maintain the sequence integrity required by the reshaping logic.
3.  **Configuration Override**: Dynamically modify the `Config` class attributes to point to these new temporary subset files and a temporary working directory. This redirects the library functions to use our demo data.
4.  **Pipeline Component Verification**:
    *   **Data Processing**: Call `prepare_datasets` to verify feature engineering, normalization, and reshaping logic. Assert that the output shapes match the expected dimensions `(N_breaths, 80, N_features)`.
    *   **Model Architecture**: Instantiate `PCANet`, pass a dummy batch through it, and verify the output shape is `(Batch, 80)`.
    *   **Loss Function**: Manually verify `MaskedMAELoss` by creating synthetic predictions and targets with known `u_out` masks to ensure expiratory phases are correctly ignored.
5.  **Full Training Loop Execution**: Run `train_model` for a single epoch using the subset data. This validates the integration of the data loader, model, optimizer, scheduler, and submission generation.
6.  **Output Verification**: Assert that the submission file is generated and follows the correct format.
