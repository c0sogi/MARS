The error `TypeError: ReduceLROnPlateau.__init__() got an unexpected keyword argument 'verbose'` arises because the `verbose` parameter has been removed from the `__init__` method of learning rate schedulers in recent PyTorch versions (specifically `torch>=2.2`). To fix this, I will remove the `verbose=True` argument from the `ReduceLROnPlateau` instantiation in both `library/train_eval.py` (where the traceback indicated the failure) and `library/model.py` (to prevent potential future failures in that module).
