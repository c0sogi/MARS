Hybrid architectures for physical systems require sufficient gradient updates to synchronize the recurrent and convolutional branches (Cite solution_lesson_node_00039, solution_lesson_node_00054).
2.  **Add Explicit Derivative Features**: I will add `u_in_diff` (backward difference) and `u_in_diff_next` (forward difference) to the input features. Explicitly providing the rate of change helps the model capture high-frequency resistive dynamics ($P \propto \dot{V}$) more effectively than asking it to infer gradients from raw values (Cite solution_lesson_node_00052).
