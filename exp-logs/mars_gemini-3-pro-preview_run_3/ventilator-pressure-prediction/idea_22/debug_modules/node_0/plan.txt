The following script demonstrates the end-to-end usage of the provided library modules for the Ventilator Pressure Prediction task.

### Strategy
1.  **Setup & Initialization**: We import the library modules and set the random seed for reproducibility using `utils.seed_everything`.
2.  **Data Preparation**: We utilize `data.prepare_data` with `debug=True` and `load_cached_data=False`. This forces the pipeline to process a small subset of the data (100 training breaths, 50 validation breaths) from scratch, ensuring the demo runs quickly (seconds instead of hours). We include assertions to verify the shape of the generated batches.
3.  **Model & Training**: We instantiate the `model.PERDHNet` and wrap it in the `train.Trainer` class along with the optimizer and `MaskedL1Loss`. We run the training loop for 1 epoch to demonstrate the fitting process.
4.  **Inference & Submission**: We perform inference on the test set using the trained model. **Note**: Since the provided `train.run_training` function contains a bug when handling the `debug` subset for submission generation (it expects the full test set size), we manually implement the submission generation logic. We filter the test metadata to match the debug subset and save the predictions to `demo_submission.csv`.
