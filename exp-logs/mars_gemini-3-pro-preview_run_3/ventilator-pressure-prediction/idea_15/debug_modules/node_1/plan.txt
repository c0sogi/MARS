The issue is caused by Python's handling of default arguments, which are evaluated only once at function definition time. The `prepare_data` function in `library/dataset.py` binds `batch_size` to the initial value of `Config.BATCH_SIZE` (128) when the module is imported. Although `run_demo` updates `Config.BATCH_SIZE` to 32 at runtime, calling `prepare_data` without arguments uses the stale default value of 128 (Cite debug_lesson_6). To fix this, we must explicitly pass the updated `batch_size=Config.BATCH_SIZE` when calling `prepare_data` in `runfile.py`.
