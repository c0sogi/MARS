I will address the `AttributeError` in `library/model.py` and the latent data corruption issue in `library/features.py`.

1.  **Fix `AttributeError` in `library/model.py`**: The traceback indicates that `FMDHNet.forward` attempts to access `self.tcn_blocks`, but the attribute initialized in `__init__` is named `self.cnn_blocks`. I will rename the reference in the forward pass to match the initialization.
2.  **Fix Improper Scaling in `library/features.py`**: The current implementation applies `RobustScaler` to all features, including the binary control flag `u_out`. This transforms the discrete `0`/`1` values into floats (e.g., `-0.6`), causing the downstream masking logic (`mask = u_out == 0`) to fail (Cite debug_lesson_7). I will modify the scaling logic to explicitly exclude `u_out` from the scaler, preserving its binary integrity.
