### Strategy: Context-Aware Parallel Hybrid Network (CAP-Net)

Based on the analysis of previous failures and successes, I propose a **Context-Aware Parallel Hybrid** strategy. This approach synthesizes the structural efficiency of the "Parallel TCN-LSTM" (Idea 4) with the critical data handling insights regarding "Contextual Parameter Injection" (Lesson 13). It corrects the "Late Fusion" flaw that crippled the previous hybrid attempt by ensuring that the deep neural components are explicitly conditioned on the physical lung attributes from the start.

#### 1. Model: Context-Aware Parallel Backbone
The architecture is designed to decouple the learning of high-frequency (resistive) and low-frequency (elastic) dynamics, while ensuring both processes are modulated by the governing physical constants ($R$ and $C$).

*   **Branch 1: The Contextualized Resistive Stream (TCN)**
    *   **Function:** Models the **Resistive Pressure** component ($P_R = R \cdot \dot{V}$), which is driven by rapid changes in flow and valve acceleration.
    *   **Architecture:** A Temporal Convolutional Network (TCN) with dilated convolutions to act as learnable finite-difference operators. **Cite solution_lesson_node_00010**.
    *   **Input:** Receives the "Fast" dynamic features (Flow, Acceleration) **concatenated with the static lung attributes ($R, C$) at every time step**. This allows the convolutional filters to dynamically adapt their response (e.g., dampening) based on the specific resistance of the lung, correcting the "Late Fusion" error. **Cite solution_lesson_node_00013**.

*   **Branch 2: The Contextualized Elastic Stream (Bidirectional LSTM)**
    *   **Function:** Models the **Elastic Pressure** component ($P_E = \frac{V}{C}$), which is driven by the accumulation of volume over time.
    *   **Architecture:** A deep Bidirectional LSTM to capture long-term state dependencies. **Cite solution_lesson_node_00010**.
    *   **Input:** Receives the "Slow" state features (Volume/Integral) **concatenated with the static lung attributes ($R, C$) at every time step**. This allows the recurrent state updates to be conditioned on the lung's compliance, ensuring the learned integration curve matches the physical reality. **Cite solution_lesson_node_00013**.

*   **Fusion Head:**
    *   The outputs of both branches are concatenated and passed to a final Dense regression layer to predict `pressure`.

#### 2. Data: Robust PID-Physics Pipeline
The data processing will combine the successful feature engineering of the PID state with rigorous pipeline controls to prevent silent failures.

*   **Feature Engineering (PID + Physics):**
    *   **Proportional (P):** Raw `u_in` (Flow proxy).
    *   **Integral (I):** Cumulative sum of `u_in` (Volume proxy). **Cite solution_lesson_node_00001**.
    *   **Derivative (D):** Finite differences of `u_in` (Acceleration proxy). **Cite solution_lesson_node_00003**.
    *   **Interaction Terms:** Explicitly computed physics terms $R \cdot u_{in}$ and $Volume / C$ are included to provide a "head start" to the network. **Cite solution_lesson_node_00001**.

*   **Pipeline Integrity:**
    *   **Unified Configuration:** A single configuration object will define both the feature generation logic and the model input dimensions to ensure synchronization. **Cite solution_lesson_node_00005**.
    *   **Automated Cache Invalidation:** The script will explicitly delete any pre-existing `.npy` or `.pt` files in the working directory at the start of execution. This guarantees that the model trains on fresh data containing the correct context-injected features. **Cite solution_lesson_node_00006**.

#### 3. Training: Metric-Aligned & Convergent
The training regime is optimized to focus solely on the scored objective and ensure the hybrid architecture reaches its potential.

*   **Loss Function:** **Masked L1 Loss (MAE)**. The loss will be calculated strictly where `u_out == 0` (inspiratory phase). Gradients from the expiratory phase will be masked out to prevent the model from wasting capacity on unscored dynamics. **Cite solution_lesson_node_00001**.
*   **Optimizer & Schedule:**
    *   Use **AdamW** with **ReduceLROnPlateau**.
    *   **Extended Budget:** Unlike the previous hybrid experiment which was cut short, we will train for **50-70 epochs**. While the hybrid architecture is efficient per step, the complex interaction between the branches requires sufficient iterations to fully converge. **Cite solution_lesson_node_00010**.

#### 4. Evaluation
*   The test set will be processed using the identical, cache-cleared pipeline.
*   Inference will be performed in batches, and the predictions will be flattened and joined with `id` for the final submission.
