The following script demonstrates the usage of the provided library files for the Ventilator Pressure Prediction task.

**Implementation Strategy:**
1.  **Data Subsetting**: To ensure the demonstration runs quickly, the script first creates small subsets (50 breaths each) of the original metadata files (`train.csv`, `validation.csv`, `test.csv`) and saves them to a temporary working directory.
2.  **Configuration Override**: It modifies the `Config` class at runtime to point to these subset files and sets execution parameters (Debug mode, 1 Epoch, small Batch Size) for speed.
3.  **Feature Engineering**: It calls `engineer_features` to process the raw subset data into features (calculating derivatives, integrals, etc.) and asserts that the output shapes are correct.
4.  **Dataset & Model Verification**: It initializes the `VentilatorDataset` and `DCLKNet` model, runs a forward pass with a single batch to verify tensor shapes, and checks the loss function.
5.  **Full Pipeline Execution**: It executes the full training loop via `run_training` and the prediction pipeline via `generate_predictions` to ensure end-to-end functionality, verifying that model checkpoints and submission files are generated.
