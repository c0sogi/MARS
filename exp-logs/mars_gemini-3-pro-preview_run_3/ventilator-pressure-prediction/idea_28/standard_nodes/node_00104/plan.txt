6.  **Failure Analysis**: Run inference on the validation set to calculate element-wise absolute errors. Apply the inspiratory phase mask (`u_out == 0`) to filter relevant data. Compute and print the Pearson correlation between the model's error magnitude and the input features to identify sources of error.
7.  **Conditional Submission**: Compare the final validation metric against the threshold (0.16391726930343686). If the model performs well enough, generate predictions for the test set, format them into a CSV file, and save it to the submission directory.
