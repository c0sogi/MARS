This script implements the end-to-end pipeline for the RPC-Net model. It overrides the default epoch count to 15 to ensure a fast baseline execution within the time limit while using the full dataset. It orchestrates data loading, model training, and validation. Following training, it loads the best model checkpoint to compute the final validation metric (Masked MAE) and performs failure analysis by correlating prediction errors with input features. Finally, it checks the validation metric against the specified threshold and generates a submission file only if the performance criteria are met.
