The implementation strategy involves the following steps:
1.  **Setup and Configuration**: Initialize the environment using `Config`, set random seeds for reproducibility, and suppress unnecessary warnings.
2.  **Data Loading**: Utilize `get_dataloaders` with `load_cached_data=True` to quickly load the pre-processed tensors.
3.  **Model Training**: Instantiate the `HybridCNNLSTM` model and run a custom training loop. To ensure a fast baseline, the loop is limited to 15 epochs with early stopping, which is sufficient for convergence on the A100 GPU given the dataset size.
4.  **Validation**: Load the best model checkpoint and compute the `Final Validation Metric` (Masked MAE) on the hold-out validation set, printing it in the strict format required.
5.  **Failure Analysis**: Analyze the model's errors on the validation set by calculating the correlation between the error magnitude and input features, focusing specifically on the inspiratory phase where the metric is active.
6.  **Conditional Submission**: Compare the final validation metric against the threshold (0.8097341656684875). If the model performs better (lower metric), generate the submission file using `predict`; otherwise, skip this step.
