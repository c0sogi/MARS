# Proposed Strategy: K-Fold Ensemble of Hybrid EfficientNet-B4 Models

This strategy introduces a structural shift from a **Single-Split Training** paradigm to a **Stratified Group K-Fold Ensemble** pipeline. This change directly addresses the high stochastic variance observed in the minority class (Cite {solution_lesson_node_00018}) and allows the model to utilize 100% of the available training data, rather than leaving 20% locked in a fixed validation set.

### Model
*   **Architecture:** Upgrade the visual backbone to **EfficientNet-B4**. This model offers a higher parameter count and receptive field than the previously used B3, allowing for the capture of more complex dermatoscopic structures while remaining well within the A100 computational budget.
*   **Hybrid Fusion:** Retain the successful **Hybrid Architecture** design. The EfficientNet-B4 backbone will extract a feature vector (via Global Average Pooling) which is concatenated with the output of a lightweight MLP processing the tabular metadata (`age`, `sex`, `anatom_site`). This explicitly encodes clinical priors that the CNN alone might miss (Cite {solution_lesson_node_00011}).
*   **Head:** The concatenated features will pass through a dropout layer (rate 0.3) and a final fully connected layer to produce the malignancy logit.

### Data
*   **Splitting Strategy:** Instead of using the pre-generated fixed train/validation split, combine all labeled data and generate a **5-Fold Stratified Group K-Fold** split based on `patient_id`. This ensures no patient leakage while maximizing data utility and providing statistically robust performance estimates (Cite {solution_lesson_node_00018}).
*   **Preprocessing:** Resize all images to **384x384**. This resolution balances the need for fine-grained detail with training speed.
*   **Augmentation:**
    *   **Geometric Only:** Apply random flips (horizontal/vertical) and rotations. Strictly **exclude color augmentations** (Hue/Saturation) to preserve diagnostic chromatic signals (Cite {solution_lesson_node_00003}).
    *   **Micro-Hole CoarseDropout:** Apply `CoarseDropout` with small hole sizes (e.g., 8-12 pixels) relative to the image size. This prevents the occlusion of entire focal lesions, serving as noise injection rather than destructive occlusion (Cite {solution_lesson_node_00006}, {solution_lesson_node_00009}).

### Training
*   **Loss Function:** Use **BCEWithLogitsLoss** with a **Dampened Positive Weight** of **10.0**. This value balances the need to emphasize the minority class without causing the gradient instability and overfitting associated with the theoretical inverse frequency (~55.0) (Cite {solution_lesson_node_00001}, {solution_lesson_node_00004}).
*   **Optimization:** Use **AdamW** with standard weight decay (`0.01`). Avoid aggressive weight decay to ensure the model can learn the high-magnitude weights required for confident logit predictions (Cite {solution_lesson_node_00005}).
*   **Procedure:** Train each of the 5 folds for **8-10 epochs**.
*   **Metric-Based Checkpointing:** Explicitly ignore Validation Loss for early stopping. Save the model checkpoint that achieves the maximum **Validation ROC AUC** for each fold. This decouples the ranking objective from probability calibration (Cite {solution_lesson_node_00016}).
*   **Regularization:** Maintain moderate regularization (Dropout 0.3, DropPath 0.2) to prevent underfitting fine-grained features (Cite {solution_lesson_node_00015}).

### Evaluation
*   **Test Time Augmentation (TTA):** For every test image, generate predictions using 4 views: Original, Horizontal Flip, Vertical Flip, and 180-degree Rotation (Cite {solution_lesson_node_00012}).
*   **Ensemble Aggregation:** For each image, average the TTA probabilities from **all 5 trained fold models**. This bagging approach smooths out model-specific noise and stochastic errors, providing a robust final prediction.
