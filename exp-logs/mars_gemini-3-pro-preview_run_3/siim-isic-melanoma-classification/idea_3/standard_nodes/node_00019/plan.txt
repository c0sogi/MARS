Implementation Strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided helper modules (`library`). Override `Config` parameters to define a "Fast Baseline" mode: set `EPOCHS` to 1 and `NUM_FOLDS` to 2. This ensures the script completes well within the 23-minute limit.
2.  **Data Processing & Subsampling**: Call `process_data` to generate the full preprocessed dataset. To speed up training, load this dataset and subsample it to approximately 10,000 samples, ensuring all minority class (malignant) samples are retained. Re-apply `StratifiedGroupKFold` to this subsampled dataset to ensure valid cross-validation splits without patient leakage. Overwrite the cached `processed_train.parquet` with this smaller dataset.
3.  **Training**: Execute the training loop for the defined 2 folds using `run_fold`. This utilizes the subsampled data and the `HybridEfficientNet` model.
4.  **Validation**: Load the strictly hold-out validation set (`metadata/val.csv`). Extract the corresponding preprocessed features for these samples from the original full dataset (before subsampling). Run inference using the trained ensemble (averaging predictions from both folds) with Test-Time Augmentation (TTA). Calculate and print the `Final Validation Metric` (AUC).
5.  **Failure Analysis**: Compute the absolute error between predictions and targets. Calculate correlations between this error and patient metadata (Age, Sex, Anatomical Site) to identify failure modes.
6.  **Submission**: Check if the validation AUC exceeds the specified threshold (0.909459...). If successful, call `generate_submission` to produce the final `submission.csv` for the test set.
