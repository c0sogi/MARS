This script demonstrates the end-to-end usage of the provided library files for the Skin Lesion Classification task. It performs the following steps:
1.  **Data Preparation**: Creates a small, balanced subset of the training and test data to ensure the demonstration runs quickly (within seconds/minutes) while satisfying class balance requirements for metric calculation.
2.  **Configuration Override**: Dynamically modifies the `Config` class to point to the subset data, reduces the number of epochs to 1, sets batch size to 8, and configures the working directory.
3.  **Data Processing**: Calls `process_data` to generate tabular features and create stratified folds.
4.  **Training**: Executes `run_fold(0)` to train the `HybridEfficientNet` model on the first fold.
5.  **Inference**: Adjusts the fold count configuration to match the single trained model and calls `generate_submission` to produce predictions on the test set.
6.  **Verification**: Includes assertions at key stages to verify data shapes, file generation, and output validity.
