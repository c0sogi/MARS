The following script generates metadata for the ISIC skin lesion classification task. It reads the raw CSV files, constructs relative file paths for the JPEG images, and creates a validation split. The splitting strategy uses `StratifiedGroupKFold` to ensure that:
1.  **Group Integrity**: All images from a single patient (`patient_id`) are kept in either the training or validation set, preventing data leakage.
2.  **Stratification**: The distribution of the target variable (benign/malignant) is preserved across splits.
3.  **Ratio**: A 5-fold split is used, and one fold is selected as the validation set, resulting in an approximately 80:20 split.

After generating the files in `./metadata`, the script reloads them to perform rigorous validation checks, including verifying file existence, checking for patient overlap (leakage), and printing summary statistics.
