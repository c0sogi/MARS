This script demonstrates the end-to-end usage of the provided speech command recognition library. It performs the following steps:
1.  **Setup**: Initializes the environment and random seeds using `library.config`.
2.  **Data Loading & Processing**: Demonstrates `library.utils.load_and_pad_audio` to load a raw audio file and convert it to a tensor. It also verifies the spectrogram generation.
3.  **Dataset Management**: Instantiates `library.dataset.SpeechCommandsDataset` using a subset of the training metadata to demonstrate data balancing and item retrieval logic.
4.  **Model Initialization**: Instantiates `library.model.SimpleAudioCNN`, moves it to the configured device (GPU/CPU), and verifies the forward pass with dummy input.
5.  **Training Loop**: Uses `library.trainer.Trainer` to train the model for one epoch on the subset of data. This validates the optimization step and loss calculation without the time cost of a full training run.
6.  **Inference & Submission**: Generates predictions for the full test set using `library.trainer.generate_submission` and verifies the output format.
