Based on the comprehensive analysis of the provided lessons, I propose the **Multi-Scale Hierarchical SK-ResNet-CRNN**.

This strategy represents a structural evolution of the successful "Idea 7" (Multi-Resolution SK-ResNet-CRNN). While Idea 7 optimized the *input* resolution (using multi-window spectrograms) and the *kernel* receptive field (using SK-Net), it relied solely on the final layer of the CNN for feature extraction. Deep CNNs naturally abstract data, potentially losing fine-grained low-level spectral details (like rapid transient onsets) that are crucial for distinguishing short commands. This solution introduces **Hierarchical Feature Aggregation** (Feature Pyramid) to fuse features from multiple depth stages of the backbone, ensuring the recurrent layer receives a complete representation of the signal's evolution.

### Model
I propose the **Multi-Scale Hierarchical SK-ResNet-CRNN**.

*   **Input:** **3-Channel Multi-Resolution Log-Mel Spectrogram**.
    *   We retain the proven input strategy: 3 channels corresponding to Short (20ms), Medium (40ms), and Long (60ms) STFT windows. This maps the time-frequency uncertainty trade-off directly to the channel dimension **Cite solution_lesson_node_00020**.
*   **Backbone:** **Selective Kernel ResNet34 (SK-ResNet34)**.
    *   We utilize the SK-ResNet34 backbone. Its "Split-Attention" mechanism dynamically adjusts receptive fields, perfectly complementing the multi-resolution input **Cite solution_lesson_node_00029**.
    *   **Adaptation:** Input weights are summed to adapt the pretrained RGB layer **Cite solution_lesson_node_00005**.
    *   **Temporal Preservation:** Strides in the final two stages (Layer 3 and Layer 4) are set to `(1, 1)` to maintain temporal resolution **Cite solution_lesson_node_00017**.
*   **Structural Innovation: Hierarchical Feature Aggregation.**
    *   Instead of using only the output of the final stage (Layer 4), we extract feature maps from **Layer 2, Layer 3, and Layer 4**.
    *   **Mechanism:**
        1.  **Pooling:** Apply Global Average Pooling along the *Frequency* dimension for each stage's output, resulting in three sequence vectors of shape $(B, T, C_2)$, $(B, T, C_3)$, and $(B, T, C_4)$.
        2.  **Projection:** Apply a $1\times1$ convolution to each vector to normalize channel dimensions.
        3.  **Fusion:** Concatenate these sequences along the channel dimension. Since we modified the strides of Layers 3 and 4 to be 1, these feature maps share the same temporal resolution as Layer 2, allowing direct alignment.
    *   **Benefit:** This provides the recurrent layer with both high-level semantic features (from Layer 4) and low-level structural/transient features (from Layer 2), preventing the loss of critical micro-details in deep layers.
*   **Neck:** **Bidirectional GRU (BiGRU)**.
    *   The fused multi-scale sequence is passed to a BiGRU. We prioritize the BiGRU over the Conformer/Transformer, as previous lessons demonstrated its superior convergence and performance for these short, fixed-length sequences **Cite solution_lesson_node_00034**.
*   **Head:** **Multi-Head Attention Pooling**.
    *   The recurrent states are aggregated using Multi-Head Attention (e.g., 4 heads). This allows the model to simultaneously attend to distinct temporal events (e.g., the initial plosive and the final vowel) rather than averaging them **Cite solution_lesson_node_00031**.

### Data
*   **Preprocessing & Caching:**
    *   We will **pre-compute** the 3-Channel Multi-Resolution Spectrograms (16kHz, padded to 1s, `n_mels=64`) and save them to disk as `.npy` files. This is critical to avoid the CPU bottleneck identified in previous runs **Cite solution_lesson_node_00028**.
*   **Sampling Strategy:**
    *   We will use the **Full Unknown Dataset** (~30k samples) and employ a **Weighted Random Sampler**. This ensures balanced batches without discarding the diversity of the negative class **Cite solution_lesson_node_00022**.
*   **Augmentation:**
    *   **SpecAugment Only:** Apply Frequency and Time Masking to the cached features.
    *   **Configuration:** Use **inclusive bounds** for mask generation **Cite solution_lesson_node_00011**. Fill masks with the **minimum value** of the spectrogram **Cite solution_lesson_node_00010**. Strictly limit time masks to **<20%** of the duration **Cite solution_lesson_node_00008**.
    *   **Exclusion:** We will **NOT** use MixUp or Label Smoothing, as these have consistently caused underfitting by over-regularizing the model **Cite solution_lesson_node_00016** **Cite solution_lesson_node_00019**.

### Training
*   **Loss Function:** Standard **Cross-Entropy Loss**.
*   **Optimizer:** **AdamW** with weight decay.
*   **Scheduler:** **Cosine Annealing** learning rate scheduler.
*   **Procedure:** Train on the cached features using the Weighted Random Sampler. Monitor performance on the speaker-disjoint validation set.

### Evaluation
*   **Inference:** For each test file, generate the 3-Channel Multi-Resolution Spectrogram (without augmentation).
*   **Prediction:** Pass the input through the Multi-Scale Hierarchical SK-ResNet-CRNN. The Multi-Head Attention Pooling will aggregate features from the active speech segments. Output the class with the highest probability.
