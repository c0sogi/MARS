The `StopIteration` error occurs because the `DataLoader` is empty. This happens because `library.dataset.py` imports the `train_cfg` object directly. When `runfile.py` assigns a new object to `library.config.train_cfg`, the reference in `library.dataset.py` remains pointing to the old configuration object (with `batch_size=64`), while the demo data only has 32 samples. With `drop_last=True`, this results in zero batches.
