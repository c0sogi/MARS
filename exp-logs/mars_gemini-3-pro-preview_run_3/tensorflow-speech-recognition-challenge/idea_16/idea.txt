Based on the progression of experiments and the specific lessons learned, I propose the **Frequency-Attentive Multi-Resolution ResNeSt-CRNN with GPU-Native Physics Augmentation**.

This strategy synthesizes the most successful components of previous iterations: the **Multi-Resolution Input** (Lesson 00020), the **ResNeSt Backbone** (Lesson 00029), and the **GPU-Native Pipeline** (Lesson 00052). It introduces two key structural innovations to address remaining bottlenecks: **Frequency-Attentive Pooling** to resolve the information loss at the CNN-RNN interface (Lesson 00041), and **Physics-Based Augmentation** (Pitch/Time shifting) enabled by the GPU pipeline to improve speaker invariance.

### Model
I propose a **Frequency-Attentive Multi-Resolution ResNeSt-CRNN**.

*   **Input:** **3-Channel Multi-Resolution Log-Mel Spectrogram**.
    *   We retain the highly effective strategy of stacking Short (20ms), Medium (40ms), and Long (60ms) window spectrograms as RGB channels. This explicitly maps the time-frequency uncertainty trade-off to the channel dimension **Cite solution_lesson_node_00020**.
    *   **Resolution Scaling:** We will increase the frequency resolution to **224 Mel bands**. This aligns the spectral dimension with the native spatial resolution ($224 \times 224$) of the ImageNet-pretrained backbone, ensuring feature fidelity scales with model capacity **Cite solution_lesson_node_00006**.
*   **Backbone:** **ResNeSt50 (Split-Attention Network)**.
    *   We utilize ResNeSt50, which employs a "Split-Attention" mechanism to dynamically reweight channel groups. This is superior for multi-resolution inputs compared to standard ResNets, as the model can adaptively focus on the resolution channel (transient vs. tonal) most relevant to the current signal **Cite solution_lesson_node_00029**.
    *   **Adaptation:** The 3-channel input is mapped directly to the pretrained RGB weights **Cite solution_lesson_node_00005**.
    *   **Temporal Preservation:** The strides of the final two residual stages (Layer 3 and 4) will be set to `(1, 1)` to prevent excessive downsampling, ensuring the feature map retains sufficient temporal length for the recurrent layer **Cite solution_lesson_node_00017**.
*   **Neck (Structural Innovation):** **Frequency-Attentive Pooling**.
    *   To address the trade-off between **Global Average Pooling** (which loses spectral structure, **Cite solution_lesson_node_00041**) and **Flattening** (which explodes parameters), we introduce a learnable **Attention Mechanism** over the frequency dimension.
    *   *Mechanism:* For the feature map $(B, C, F, T)$, the model computes an attention score $\alpha_{f,t}$ for each frequency bin $f$ at each time step $t$. The features are then aggregated via a weighted sum: $x_t = \sum_{f} \alpha_{f,t} \cdot x_{f,t}$.
    *   *Benefit:* This allows the model to dynamically highlight specific frequency bands (e.g., formants) crucial for the current phoneme while maintaining a compact feature vector for the RNN.
*   **Sequence Modeling:** **Bidirectional GRU (BiGRU)**.
    *   The aggregated sequence is passed to a BiGRU. We prioritize BiGRU over Transformers/Conformers for this task due to its superior convergence on short, fixed-length sequences **Cite solution_lesson_node_00034**.
*   **Head:** **Multi-Head Attention Pooling**.
    *   The recurrent states are aggregated using Multi-Head Attention (4 heads). This allows the model to simultaneously attend to distinct temporal events (e.g., onset and offset) rather than averaging them **Cite solution_lesson_node_00031**.

### Data
*   **Pipeline:** **GPU-Native Data Loading**.
    *   We will load **Raw Audio Waveforms** and perform all signal processing (STFT, Mel-scale, Log) on the GPU. This eliminates the CPU bottleneck associated with high-resolution STFT computation **Cite solution_lesson_node_00052**.
*   **Augmentation 1: Physics-Based Transformations (New).**
    *   Leveraging the GPU pipeline, we will apply **Random Pitch Shifting** and **Time Stretching** (Resampling) to the raw waveform *before* spectrogram generation. These augmentations simulate variations in speaker vocal tract length and speaking rate, which are impossible to accurately replicate on cached spectrograms.
*   **Augmentation 2: Environmental Robustness.**
    *   **Background Noise Injection:** Dynamically mix background noise into the waveform on the GPU **Cite solution_lesson_node_00052**.
    *   **SpecAugment:** Apply Frequency and Time Masking to the generated spectrograms.
    *   **Configuration:** Use **inclusive bounds** **Cite solution_lesson_node_00011**, fill masks with the **minimum value** **Cite solution_lesson_node_00010**, and strictly limit time masks to **<20%** of the duration **Cite solution_lesson_node_00008**.
*   **Sampling:**
    *   Use the **Full Unknown Dataset** (~30k samples) and employ a **Weighted Random Sampler** to ensure balanced batches. This maximizes the diversity of negative examples the model sees **Cite solution_lesson_node_00022**.

### Training
*   **Loss Function:** Standard **Cross-Entropy Loss**.
*   **Optimizer:** **AdamW** with weight decay.
*   **Scheduler:** **Cosine Annealing** learning rate scheduler.
*   **Exclusion:** We will **NOT** use MixUp or Label Smoothing, as these have been shown to cause underfitting by over-regularizing the model given the small generalization gap **Cite solution_lesson_node_00016**.

### Evaluation
*   **Inference:**
    1.  Load Raw Waveform.
    2.  Generate 3-Channel Multi-Resolution Spectrogram ($224$ mels) on GPU (no augmentation).
    3.  Pass through the Frequency-Attentive ResNeSt-CRNN.
    4.  The Multi-Head Attention Pooling will aggregate features from the active speech segments. Output the class with the highest probability.
