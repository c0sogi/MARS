This script demonstrates the end-to-end usage of the provided speech command recognition library. It performs the following steps:
1.  **Configuration Override**: Modifies the `Config` class to run in `DEBUG` mode with a small dataset subset, reduced epochs, and disabled pretraining/multiprocessing for maximum speed and stability.
2.  **Initialization**: Instantiates the `Trainer` class, which automatically sets up the data loaders, audio processor, and model.
3.  **Component Verification**:
    *   Fetches a real batch of audio data from the training loader.
    *   Verifies the raw waveform shape.
    *   Passes the waveform through the `GPUAudioProcessor` to verify the multi-resolution spectrogram generation and shape `(Batch, 3, 224, 224)`.
    *   Passes the processed features through the `FreqAttnResNeStCRNN` model to verify the output logits shape `(Batch, Num_Classes)`.
4.  **Training Loop Execution**: Runs the `fit()` method to execute a complete training and validation epoch.
5.  **Inference Execution**: Runs the `predict()` method to generate predictions on the test set.
6.  **Output Validation**: loads the generated submission file to ensure it follows the correct format.
