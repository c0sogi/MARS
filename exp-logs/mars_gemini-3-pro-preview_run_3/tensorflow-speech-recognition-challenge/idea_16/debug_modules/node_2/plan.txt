The `ValueError` occurs because the `ResNeSt` backbone is initialized in training mode, where Batch Normalization layers require more than one value per channel to calculate variance. The dummy input used for shape inference has a batch size of 1, and since the architecture's Split-Attention blocks use global pooling (reducing spatial dimensions to $1 \times 1$), the BatchNorm layer receives a single scalar per channel, causing the calculation to fail. To resolve this, I will increase the batch size of the dummy input to 2, which provides sufficient data points for the variance calculation (Cite debug_lesson_6).
