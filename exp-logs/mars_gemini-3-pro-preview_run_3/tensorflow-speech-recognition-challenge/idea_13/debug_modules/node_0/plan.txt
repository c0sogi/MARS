Here is the implementation strategy:

1.  **Setup and Data Preparation**: We will start by creating a small subset of the training, validation, and test metadata (100 samples each) and saving them to the `./working` directory. This ensures the demonstration runs quickly while exercising the full data loading pipeline.
2.  **Component Verification**: We will manually instantiate the `SpeechDataset`, `AudioProcessor`, and `HybridSKCRNN` classes. We will pass a dummy batch through the processor and model to verify input/output shapes and data types using assertions.
3.  **Training Execution**: We will utilize the `Trainer` class from `library.engine` to train the model on the subset data for a few epochs. We will explicitly handle the creation of DataLoaders pointing to our demo metadata to bypass the hardcoded paths in the default `get_dataloaders` function.
4.  **Inference and Submission**: After training, we will use the trained model to generate predictions on the demo test set using the `generate_submission` method, verifying the final output file format.
