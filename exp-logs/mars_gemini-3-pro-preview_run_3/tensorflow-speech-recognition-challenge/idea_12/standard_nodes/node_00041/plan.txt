Implementation strategy:
1.  **Configuration & Setup**: Import the provided library modules. Override `Config.EPOCHS` to a smaller value (12) to ensure the training completes quickly as a baseline. Set random seeds for reproducibility.
2.  **Preprocessing**: Initialize the `Preprocessor` and call `cache_dataset(load_cached_data=True)` to ensure all audio files are converted to spectrograms and cached.
3.  **Training**: Initialize the `Trainer` and execute the `fit()` method. This handles the training loop, validation monitoring, and saving the best model checkpoint.
4.  **Evaluation**:
    *   Load the best model from the checkpoint saved by the trainer.
    *   Iterate through the validation dataset using `CachedSpeechDataset` and `DataLoader`.
    *   Compute the Multiclass Accuracy on the full validation set.
    *   **Failure Analysis**: During validation inference, compute the mean energy of each input spectrogram. Calculate and print the Pearson correlation coefficient between the prediction error (binary: 0 or 1) and this input feature (energy) to identify if signal intensity correlates with failure.
    *   Print the `Final Validation Metric` in the required format.
5.  **Submission**:
    *   Compare the validation accuracy against the strict threshold (0.9832324978392394).
    *   If the threshold is exceeded, load the test dataset metadata.
    *   Run inference on the test set (using GPU, no gradients).
    *   Map the predicted class IDs back to their string labels.
    *   Construct the submission DataFrame with `fname` and `label` columns and save it to `./submission/submission.csv`.
