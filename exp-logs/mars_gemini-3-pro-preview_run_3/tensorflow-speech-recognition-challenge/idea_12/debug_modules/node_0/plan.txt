The following script demonstrates the end-to-end usage of the provided library files to solve the speech command recognition task.

**Implementation Strategy:**
1.  **Environment Setup**: We initialize the random seeds to ensure reproducibility.
2.  **Data Subsetting**: To satisfy the "Optimize for Speed" requirement, we create small subsets (100 training samples, 50 validation, 50 test) of the original metadata. This ensures the demonstration completes quickly while still exercising the full pipeline.
3.  **Configuration Override**: We modify the static `Config` attributes at runtime. We point the metadata paths to our new subsets and reduce the number of epochs (to 2) and batch size (to 8).
4.  **Preprocessing**: We instantiate the `Preprocessor` and run `cache_dataset()`. This demonstrates the offline feature extraction logic, ensuring audio files are converted to spectrograms and cached.
5.  **Component Verification**: We explicitly verify the correctness of the `CachedSpeechDataset` (checking feature shapes) and the `FrequencyPreservingSKResNetCRNN` model (checking output dimensions) using assertions.
6.  **Training**: We use the `Trainer` class to run the training loop (`fit`). This handles data loading, backpropagation, validation, and model checkpointing.
7.  **Inference**: After training, we load the best model checkpoint. We then iterate through the test subset, process the audio using `AudioProcessor`, and generate predictions.
8.  **Submission**: Finally, we format the predictions into a CSV file matching the required submission format.
