Based on the lessons learned from the previous experiments, I propose the **Multi-Resolution SK-ResNet-CRNN**.

This solution structurally evolves the successful "Idea 4" by replacing the standard ResNet backbone with a **Selective Kernel (SK) ResNet**. While Idea 4 solved the resolution trade-off at the *input* level (using multi-window spectrograms), this approach empowers the *model* to dynamically adapt its receptive field size to different features (e.g., short transients vs. long vowels), further optimizing the feature extraction process. It also integrates the critical data pipeline optimizations identified in Idea 5 (Full Unknown Dataset) and Idea 5's failure analysis (Caching).

### Model
I propose a **Multi-Resolution Selective Kernel CRNN (MR-SK-CRNN)**.

*   **Input:** **3-Channel Multi-Resolution Log-Mel Spectrogram**.
    *   We retain the highly effective input strategy of generating three spectrograms with varying STFT window sizes (e.g., 20ms, 40ms, 60ms) and stacking them as the R, G, and B channels. This maps the time-frequency trade-off directly to the channel dimension **Cite solution_lesson_node_00020**.
*   **Backbone (Structural Innovation):** **Selective Kernel ResNet34 (SK-ResNet34)**.
    *   *Concept:* Standard ResNets use fixed $3 \times 3$ convolution kernels, forcing a static receptive field. **SK-ResNet** blocks introduce a "Split-Attention" mechanism where the input is processed by multiple branches with different kernel sizes (e.g., $3 \times 3$ and $5 \times 5$, or different dilations). The network learns to calculate attention weights to fuse these branches dynamically.
    *   *Benefit:* This allows the model to adaptively adjust its receptive field for each audio segment. It can focus on fine-grained temporal details (using small kernels) for plosive sounds like "t" or "p", and broader spectral contexts (using large kernels) for vowels, perfectly complementing the Multi-Resolution input **Cite solution_lesson_node_00024**.
    *   *Adaptation:* The 3-channel input is mapped to the pretrained RGB weights **Cite solution_lesson_node_00005**.
    *   *Temporal Preservation:* The strides of the final two stages are set to `(1, 1)` to maintain a long temporal sequence for the recurrent layer **Cite solution_lesson_node_00017**.
*   **Neck:** **Bidirectional GRU (BiGRU)**.
    *   The feature maps are averaged over the frequency dimension and passed to a BiGRU to explicitly model the sequential phoneme dependencies **Cite solution_lesson_node_00017**.
*   **Head:** **Attention Pooling**.
    *   This layer aggregates the recurrent states using learnable weights, allowing the model to focus on the speech command and ignore padding/silence **Cite solution_lesson_node_00017**.

### Data
*   **Preprocessing & Caching:**
    *   We will **pre-compute** the 3-Channel Multi-Resolution Spectrograms (16kHz, padded to 1s, `n_mels=64`) and save them to disk as `.npy` files.
    *   *Reasoning:* Previous experiments showed that performing STFT on-the-fly for a complex multi-resolution pipeline creates a massive CPU bottleneck, slowing training by ~3x. Caching eliminates this overhead **Cite solution_lesson_node_00028**.
*   **Sampling Strategy:**
    *   We will use the **Full Unknown Dataset** (approx. 30k samples) rather than undersampling it.
    *   We will employ a **Weighted Random Sampler** to ensure that every batch contains a balanced mix of the 12 classes (target commands + silence + unknown). This maximizes the diversity of "negative" examples the model sees, improving its ability to reject non-target words **Cite solution_lesson_node_00022**.
*   **Augmentation:**
    *   **SpecAugment Only:** Apply Frequency and Time Masking to the cached `.npy` tensors.
    *   **Configuration:** Use **inclusive bounds** for mask generation **Cite solution_lesson_node_00011**. Fill masks with the **minimum value** of the spectrogram **Cite solution_lesson_node_00010**. Strictly limit time masks to **<20%** of the duration to preserve short commands **Cite solution_lesson_node_00008**.
    *   **Exclusion:** Do **not** use MixUp or Label Smoothing, as the generalization gap is already small and these techniques lead to underfitting **Cite solution_lesson_node_00016** **Cite solution_lesson_node_00019**.

### Training
*   **Loss Function:** Standard **Cross-Entropy Loss**.
*   **Optimizer:** **AdamW** with weight decay.
*   **Scheduler:** **Cosine Annealing** learning rate scheduler.
*   **Procedure:** Train on the cached features using the Weighted Random Sampler. Monitor performance on the speaker-disjoint validation set.

### Evaluation
*   **Inference:** For each test file, generate the 3-Channel Multi-Resolution Spectrogram (without augmentation).
*   **Prediction:** Pass the input through the MR-SK-CRNN. The Attention Pooling head will naturally handle the uncropped nature of the test data by attending to the speech segment. Output the class with the highest probability.
