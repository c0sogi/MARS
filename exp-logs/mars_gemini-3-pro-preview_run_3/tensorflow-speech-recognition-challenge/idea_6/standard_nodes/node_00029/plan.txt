Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and set random seeds for reproducibility. Adjust `Config.EPOCHS` to 20 to ensure the training completes well within the 2-hour limit while providing sufficient convergence to meet the high accuracy threshold.
2.  **Training**: Execute `library.train.run_training()`. This function handles feature caching (using the provided `cache_dataset` logic), initializes the `SKResNetCRNN` model, and runs the training loop with the `WeightedRandomSampler` to handle class imbalance. It saves the best model checkpoint based on validation accuracy.
3.  **Validation & Metric Calculation**:
    *   Retrieve the validation `DataLoader` using `library.dataset.get_dataloaders()`.
    *   Load the best model checkpoint.
    *   Perform a full inference pass on the validation set to collect predictions and ground truth labels.
    *   Calculate the multiclass accuracy and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Load the validation metadata (`val.csv`) to access file properties.
    *   Extract audio duration for each validation file using `soundfile`.
    *   Calculate the binary error vector (1 for incorrect, 0 for correct).
    *   Compute and print the correlation between the error magnitude and audio duration using `numpy.corrcoef` to identify if clip length impacts performance.
    *   Print error rates per class to identify weak points.
5.  **Submission**:
    *   Compare the calculated validation accuracy against the strict threshold (`0.9771823681936042`).
    *   If the threshold is exceeded, call `library.train.generate_submission()` with the test loader to produce `submission.csv`.
