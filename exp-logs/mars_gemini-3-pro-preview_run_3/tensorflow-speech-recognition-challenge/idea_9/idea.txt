Based on the progression of experiments and the specific lessons learned, I propose the **Multi-Resolution SK-ResNet-Conformer**.

This strategy represents a structural evolution from the Recurrent Neural Network (RNN) paradigm used in the current best solution (Idea 7) to the **Conformer (Convolutional Transformer)** paradigm. While Idea 7 successfully utilized a BiGRU to model temporal dependencies, RNNs are inherently limited to sequential processing and struggle to capture global context efficiently. By replacing the GRU with a Conformer Encoder—the current state-of-the-art architecture for Audio Speech Recognition (ASR)—we combine the local feature extraction of CNNs with the global attention mechanisms of Transformers, all while retaining the highly effective Multi-Resolution input and Selective Kernel backbone.

# Model
I propose the **Multi-Resolution SK-ResNet-Conformer**.

*   **Input:** **3-Channel Multi-Resolution Log-Mel Spectrogram**.
    *   We retain the input strategy of generating three spectrograms with varying STFT window sizes (e.g., 20ms, 40ms, 60ms) and stacking them as RGB channels. This explicitly maps the time-frequency trade-off to the channel dimension, allowing the model to see both transient phonemes and tonal structures simultaneously **Cite solution_lesson_node_00020**.
*   **Backbone:** **Selective Kernel ResNet34 (SK-ResNet34)**.
    *   We use the SK-ResNet34 backbone pretrained on ImageNet. Its "Split-Attention" mechanism is ideally suited for the multi-resolution input, as it can dynamically reweight the channels to focus on the most relevant resolution (Short vs. Long window) for each audio segment **Cite solution_lesson_node_00029**.
    *   **Adaptation:** The 3-channel input is mapped directly to the pretrained RGB weights **Cite solution_lesson_node_00005**.
    *   **Temporal Preservation:** The strides of the final two residual stages (Layer 3 and 4) will be set to `(1, 1)` to prevent excessive downsampling, ensuring the feature map retains sufficient temporal resolution **Cite solution_lesson_node_00017**.
*   **Neck (Structural Innovation):** **Conformer Encoder**.
    *   I will replace the Bidirectional GRU with a **Conformer Encoder Block**.
    *   *Architecture:* The Conformer block integrates two key mechanisms: **Multi-Head Self-Attention** (to capture global dependencies across the entire 1-second clip) and a **Convolution Module** (to capture local temporal nuances).
    *   *Advantage:* Unlike the GRU, which processes data sequentially, the Conformer allows every time step to attend to every other time step while maintaining the inductive bias of locality. This is superior for distinguishing commands that depend on the relative timing of non-adjacent phonemes.
*   **Head:** **Multi-Head Attention Pooling**.
    *   The output of the Conformer is aggregated using Multi-Head Attention Pooling. This allows the model to learn multiple distinct attention masks, focusing simultaneously on different critical parts of the command (e.g., onset and offset) **Cite solution_lesson_node_00031**.

# Data
*   **Preprocessing & Caching:**
    *   We will **pre-compute** the 3-Channel Multi-Resolution Spectrograms (16kHz, padded to 1s, `n_mels=64`) and save them to disk. This eliminates the CPU bottleneck associated with on-the-fly STFT computation **Cite solution_lesson_node_00028**.
*   **Sampling Strategy:**
    *   We will use the **Full Unknown Dataset** (approx. 30k samples) and employ a **Weighted Random Sampler**. This ensures every batch is balanced across all 12 classes, maximizing the diversity of negative examples the model sees without discarding data **Cite solution_lesson_node_00022**.
*   **Augmentation:**
    *   **SpecAugment Only:** We will apply Frequency and Time Masking to the cached features.
    *   **Configuration:** Use **inclusive bounds** for mask generation **Cite solution_lesson_node_00011**. Fill masks with the **minimum value** of the spectrogram **Cite solution_lesson_node_00010**. Strictly limit time masks to **<20%** of the duration to preserve short command context **Cite solution_lesson_node_00008**.
    *   **Exclusion:** We will **NOT** use MixUp or Label Smoothing, as these have been shown to cause underfitting by over-regularizing the model given the small generalization gap **Cite solution_lesson_node_00016** **Cite solution_lesson_node_00019**.

# Training
*   **Loss Function:** Standard **Cross-Entropy Loss**.
*   **Optimizer:** **AdamW** with weight decay.
*   **Scheduler:** **Cosine Annealing** learning rate scheduler.
*   **Procedure:** Train on the cached features using the Weighted Random Sampler. Monitor performance on the speaker-disjoint validation set.

# Evaluation
*   **Inference:** For each test file, generate the 3-Channel Multi-Resolution Spectrogram (without augmentation).
*   **Prediction:** Pass the input through the SK-ResNet-Conformer. The Multi-Head Attention Pooling will aggregate features from the active speech segments. Output the class with the highest probability.
