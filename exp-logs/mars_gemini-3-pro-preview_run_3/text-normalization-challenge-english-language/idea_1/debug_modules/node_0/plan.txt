This script demonstrates the usage of the provided library modules to solve the text normalization task. It follows these steps:
1.  **Setup**: Sets the random seed for reproducibility.
2.  **Component Verification**: Validates the `RegexTransducer` logic with specific assertions to ensure the heuristic rules function as expected (e.g., converting "$3.16" to "three dollars, sixteen cents").
3.  **Data Loading**: Demonstrates loading a subset of the training data using `load_dataset` with a sampling ratio, ensuring the pipeline can handle the data format efficiently.
4.  **Model Training**: Instantiates and trains the `HierarchicalLookupModel` on a 5% subset of the training data. This demonstrates the "L1" (unigram) and "L2" (bigram) caching mechanism without consuming excessive time.
5.  **Evaluation**: Runs the model on the validation set to calculate accuracy.
6.  **Inference**: Generates a submission file for the test set.
