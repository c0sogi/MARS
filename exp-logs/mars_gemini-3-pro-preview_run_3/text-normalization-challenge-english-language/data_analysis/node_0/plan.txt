The following script performs a comprehensive Exploratory Data Analysis (EDA) on the text normalization training dataset.

**Strategy Outline:**
1.  **Setup & Loading**: Initialize the environment, set random seeds for reproducibility, and load the training data from `./metadata/train.parquet`.
2.  **Target Analysis**: Analyze the distribution of the `class` column (the type of token) and the `after` column (the normalized text). This identifies class imbalances and the frequency of distinct target tokens.
3.  **Text Analysis**: Calculate statistics on the length of input (`before`) and output (`after`) tokens. Analyze the vocabulary size and character composition (digits, punctuation, casing) of the input text.
4.  **Relationship Analysis**:
    *   **Identity Mapping**: Quantify how often the input text matches the output text (a crucial baseline for normalization tasks), broken down by class.
    *   **Meta-Feature Extraction**: Generate numerical features from the raw text (e.g., length, digit count, capitalization status).
    *   **Feature Importance**: Train a lightweight Random Forest classifier on a subset of data using these meta-features to predict the token `class`, identifying which text characteristics define specific token types.
    *   **Correlations**: Analyze correlations between input length and output length.
5.  **Sentence-Level Analysis**: Aggregate tokens by `sentence_id` to analyze sentence length distributions.
