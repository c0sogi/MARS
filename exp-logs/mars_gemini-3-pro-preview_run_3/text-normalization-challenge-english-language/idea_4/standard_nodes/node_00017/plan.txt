Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration Setup**: Override default `Config` parameters to create a "fast baseline". This involves limiting the number of training samples (e.g., to 100,000) and reducing the number of epochs (e.g., to 5) to ensure the script completes well within the time limit while still demonstrating the learning capability.
2.  **Reproducibility**: Initialize random seeds for `random`, `numpy`, and `torch` to ensure deterministic results.
3.  **Data Pipeline**: Use `create_dataloaders` to prepare the tokenizer, retrieval index, and PyTorch DataLoaders. This leverages the cached parquet files if available or processes them on the fly.
4.  **Symbolic & Retrieval Initialization**: Explicitly build/load the `SymbolicMemory` and `SimilarityIndex`. These are critical components of the hybrid cascade.
5.  **Model Training**: Instantiate the `ModelTrainer` and execute the training loop (`fit`). The best model based on validation loss is automatically saved.
6.  **Validation & Metric Calculation**:
    *   Load the full validation set from `./metadata/val.parquet`.
    *   Use the `CascadeSolver` (which loads the trained neural model) to generate predictions for the validation set.
    *   Compute the exact token match accuracy.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
7.  **Failure Analysis**:
    *   Identify incorrect predictions.
    *   Calculate the Levenshtein edit distance between the predicted and actual strings as a proxy for "error magnitude".
    *   Compute the Pearson correlation between this error magnitude and the input token length to identify if longer tokens are more prone to errors.
8.  **Submission Generation**:
    *   Check if the validation accuracy exceeds the specified threshold (0.9943860453286453).
    *   If the condition is met, use the `CascadeSolver` to predict on the test set (`./metadata/test.parquet`) and save the results to `./submission/submission.csv`.
