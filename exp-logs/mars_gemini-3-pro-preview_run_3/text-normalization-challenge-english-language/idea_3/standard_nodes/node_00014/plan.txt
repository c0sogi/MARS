Implementation strategy:
1.  **Configuration**: Adjust `Config` hyperparameters (Epochs, Batch Size, Workers) to optimize for the available hardware (A100 GPU, 12 vCPUs) and ensure the training completes within the time limit while maintaining high accuracy.
2.  **Training**: Execute the `train_neural_model` function from the provided library. This handles data preprocessing, tokenizer creation, and the training of the Transformer-based character transducer on the "hard" subset of the data.
3.  **Validation**: Load the validation dataset using `load_parquet_data`. Initialize the `HybridNormalizer` (which loads the trained neural model and symbolic statistics) and run inference on the validation set.
4.  **Metric Calculation**: Compare the predicted normalized text against the ground truth (`after` column) using exact string matching to compute the accuracy. Print this metric in the required format.
5.  **Failure Analysis**: Analyze the validation results by calculating the correlation between prediction errors and input features (token length and token class). This provides insights into model weaknesses.
6.  **Submission**: If the validation accuracy exceeds the specified threshold, generate the submission file for the test set using `generate_submission`.
