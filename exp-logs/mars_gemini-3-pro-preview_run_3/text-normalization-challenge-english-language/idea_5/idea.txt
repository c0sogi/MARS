Based on the progression of experiments and the specific insights from the provided lessons, I propose a **Class-Conditioned Transformer with Hierarchical Symbolic Backoff**.

This strategy evolves the architecture by replacing the recurrent "Tail" solver with a **Transformer** (addressing Lesson 00010) and introducing a **Chain-of-Thought** generation objective that leverages the previously unused `class` labels to resolve ambiguity. It explicitly avoids the retrieval-based pitfalls identified in Lesson 00017.

# Model

The solution employs a three-stage "Specificity-Based Cascade" (Cite solution_lesson_node_00008):

1.  **Stage 1: Bidirectional Symbolic Memory (The "Head")**
    *   **Component:** A prioritized lookup hierarchy: **Trigrams** ($t_{i-1}, t_i, t_{i+1}$) $\to$ **Left/Right Bigrams** $\to$ **Unigrams**.
    *   **Role:** This layer handles the Zipfian "head" of the distribution. By using **Trigrams**, it resolves context-dependent ambiguities (e.g., "St." $\to$ "Street" vs. "Saint") via exact memorization, ensuring 100% precision for seen patterns (Cite solution_lesson_node_00006).

2.  **Stage 2: Heuristic Router (The "Gate")**
    *   **Component:** A logical filter that checks if an Out-Of-Vocabulary (OOV) token is **purely alphabetic**.
    *   **Role:** If true, it predicts the **Identity** (raw token). This prevents the neural model from processing rare proper nouns, restricting the neural problem space strictly to complex, structure-rich entities (digits, symbols) (Cite solution_lesson_node_00008).

3.  **Stage 3: Class-Conditioned Character Transformer (The "Tail")**
    *   **Component:** A **Character-Level Transformer** (Encoder-Decoder).
    *   **Structural Innovation:** Unlike previous iterations that mapped `Input` $\to$ `Text`, this model maps `Input` $\to$ `[Class_Token] [Text]`.
    *   **Rationale:** The training data contains `class` labels (e.g., DATE, MONEY, CARDINAL) which define the normalization rules. By forcing the model to generate the **Class** first (e.g., `<DATE>`), we explicitly condition the subsequent character generation on this semantic category. This acts as a "Chain-of-Thought" mechanism, helping the model distinguish ambiguous inputs (e.g., "1998" $\to$ `<DATE>` nineteen... vs `<CARDINAL>` one thousand...) without the information bottleneck of RNNs (Cite solution_lesson_node_00010) or the context saturation of RAG (Cite solution_lesson_node_00017).

# Data

**Preprocessing for Training:**
1.  **Symbolic Aggregation:** Construct Trigram, Bigram, and Unigram frequency maps from the full `train.parquet` using Maximum Likelihood Estimation.
2.  **Neural Dataset Construction:**
    *   **Filter:** Retain only "Hard" samples (exclude `PLAIN`, `PUNCT`, and purely alphabetic tokens) (Cite solution_lesson_node_00001).
    *   **Input Formatting:** Create a context-aware character sequence: `[prev_token] <SEP> [target_token] <SEP> [next_token]`. This local window is essential for disambiguation (Cite solution_lesson_node_00006).
    *   **Target Formatting:** Prepend the ground-truth class label to the normalized text: `<CLASS_LABEL> <SEP> normalized_text`.

**Preprocessing for Evaluation:**
*   Generate N-gram keys for all test tokens.
*   Identify "Neural Candidates" (OOV + Non-Alpha).
*   Format inputs as `[prev] <SEP> [target] <SEP> [next]` for the Transformer.

# Training

1.  **Symbolic Training:** Instantaneous count-based aggregation.
2.  **Neural Training:**
    *   **Architecture:** A lightweight Transformer (e.g., 4-6 layers, 4 heads).
    *   **Objective:** Standard Cross-Entropy Loss on the sequence `<CLASS> ... <EOS>`.
    *   **Strategy:** The loss on the first token (the Class) provides strong, direct supervision for the encoder to learn semantic features, while the subsequent tokens learn the transduction rules conditioned on that class. This effectively turns the task into a Multi-Task Learning problem (Classification + Generation) within a single sequence.

# Evaluation

The inference pipeline follows the strict cascade:
1.  **Lookup:** Query Trigram $\to$ Bigram $\to$ Unigram. If found, return value.
2.  **Safety Check:** If OOV and `isalpha()`, return Identity.
3.  **Neural Generation:**
    *   Pass the context-augmented input to the Transformer.
    *   Decode the output sequence.
    *   **Post-Processing:** Strip the leading `<CLASS>` token to obtain the final normalized text.
