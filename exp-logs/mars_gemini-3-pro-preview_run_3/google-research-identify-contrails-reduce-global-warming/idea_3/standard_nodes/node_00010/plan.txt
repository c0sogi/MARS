Implementation strategy:
1.  **Configuration Override**: Adjust `Config` parameters (Epochs, T_Max) to create a fast baseline that fits within the 2-hour limit while still utilizing the full dataset for maximum performance.
2.  **Initialization**: Instantiate the `ContrailTrainer` and create DataLoaders for training and validation using the provided library classes.
3.  **Training Loop**: Execute a custom training loop for the specified number of epochs. In each epoch, perform training and validation, step the scheduler, and manage checkpoints using the trainer's methods.
4.  **Weight Averaging**: Trigger the convergence-aware weight averaging method to create a robust final model from the best checkpoints.
5.  **Final Evaluation**: Load the best averaged model and perform a detailed validation pass. Calculate the Global Dice coefficient by accumulating intersection and union statistics across the entire validation set.
6.  **Failure Analysis**: Compute per-sample Dice scores and correlate the error magnitude ($1 - Dice$) with metadata features (Timestamp, Latitude, Longitude) to identify systematic failure modes.
7.  **Submission Logic**: Compare the final Global Dice against the specified threshold ($0.5723259114122367$). If the metric exceeds the threshold, generate the submission file using the trainer's inference method.
