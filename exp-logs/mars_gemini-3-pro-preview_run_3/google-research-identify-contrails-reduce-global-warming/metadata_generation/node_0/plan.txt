I will create a Python script that generates `train.csv`, `validation.csv`, and `test.csv` in the `./metadata` directory.

### Strategy
1.  **Scan Input Directories**: The script will iterate through the `./input/train`, `./input/validation`, and `./input/test` directories to identify all unique `record_id` folders.
2.  **Metadata Construction**: For each record, it will construct the relative file paths for all satellite bands (`band_08.npy` through `band_16.npy`).
    *   For the **train** set, it will include paths to `human_pixel_masks.npy` and `human_individual_masks.npy`.
    *   For the **validation** set, it will include paths to `human_pixel_masks.npy`.
    *   It will also merge the additional metadata (timestamps, projection info) provided in `train_metadata.json` and `validation_metadata.json`.
3.  **Validation Split Handling**: The script will check if the `./input/validation` directory contains data. If it is empty, it will perform an 80:20 random split of the training data to create a validation set, ensuring reproducibility with a fixed random seed.
4.  **Verification**: After saving the CSV files, the script will reload them to:
    *   Print summary statistics (count of records).
    *   Verify the integrity of the data by checking the existence of 1000 randomly sampled file paths from each dataset. If more than 50% are missing, it will raise an error.
