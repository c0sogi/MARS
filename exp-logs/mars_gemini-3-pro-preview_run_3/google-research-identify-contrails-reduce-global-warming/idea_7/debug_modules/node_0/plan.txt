The following code demonstrates how to utilize the provided library files to build and verify a complete training and inference pipeline for contrail identification. It overrides the default configuration to run a fast, lightweight demonstration using a subset of the data.

### Implementation Strategy
1.  **Environment Setup**: Import libraries and configure the `Config` class for a lightweight demo (Debug mode, small batch size, few epochs).
2.  **Data Pipeline Verification**: Initialize the `ContrailDataset` and `DataLoader`. Fetch a single batch to verify tensor shapes (Batch, Channel, Height, Width) and data types.
3.  **Model Initialization**: Instantiate the `ContrailModel`. Perform a forward pass with the fetched batch to verify the output shape matches the expected segmentation map dimensions.
4.  **Loss Calculation**: Compute the loss using `ContrailLoss` to ensure the mathematical operations (BCE + Dice) function correctly and return a valid scalar.
5.  **Training Loop Simulation**: Execute the `train_one_epoch` and `validate` functions from the `engine` module to demonstrate the optimization process.
6.  **Checkpointing**: Use `CheckpointManager` to save the model state, verifying that the file is correctly written to the disk.
7.  **Utility Verification**: Test the `rle_encode` function with a known synthetic mask to confirm the run-length encoding logic is correct.
