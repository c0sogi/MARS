The strategy for the `runfile.py` implementation is as follows:

1.  **Setup and Initialization**: Import necessary libraries and the provided modules from the `library` package. Set the random seed for reproducibility and suppress warnings to keep the output clean.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. To satisfy the "fast baseline" requirement while maintaining performance, the number of epochs will be set to 5. This allows the model to converge sufficiently on the GPU without exceeding the time limit.
3.  **Validation and Metric Calculation**:
    *   Load the best model saved during training.
    *   Iterate through the full validation dataset using the data loader.
    *   Calculate the **Global Dice coefficient** exactly as defined in the metric description (aggregating total intersection and total union across the entire dataset) rather than averaging batch-wise scores.
    *   Print the final metric with full precision.
4.  **Failure Analysis**:
    *   During the validation loop, compute the error magnitude ($1 - \text{Dice}$) for each individual image.
    *   Correlate these error magnitudes with metadata features (Timestamp, Latitude proxy `row_min`, Longitude proxy `col_min`) to identify systematic weaknesses.
    *   Print the correlation coefficients.
5.  **Submission Generation**: Use `library.inference.generate_submission` to generate predictions for the test set using the best trained model and save the results to the specified submission path.
