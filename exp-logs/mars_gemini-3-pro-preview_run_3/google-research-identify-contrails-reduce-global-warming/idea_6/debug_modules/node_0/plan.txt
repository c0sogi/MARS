This script demonstrates the usage of the provided library files for the contrail segmentation task. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory and reduced hyperparameters (1 epoch, small batch size) for a fast demonstration.
2.  **Utility Verification**: Validates the Run-Length Encoding (RLE) logic with a known simple mask.
3.  **Data Loading**: Uses `get_loaders` in debug mode to load a tiny subset of the data and verifies input/output tensor shapes and types.
4.  **Model Inference**: Instantiates the `ContrailUnet` model, performs a forward pass on a batch of data, and asserts the output dimensions are correct.
5.  **Loss & Metric Calculation**: Computes the `DiceBCELoss` and the `dice_score` metric, ensuring they return valid scalar values.
6.  **Full Training Cycle**: Initializes the `Trainer` class and runs the `fit()` method for one epoch to demonstrate the training loop, validation, and checkpoint saving mechanisms.
7.  **Artifact Verification**: Checks that model checkpoints were successfully saved to the designated directory.
