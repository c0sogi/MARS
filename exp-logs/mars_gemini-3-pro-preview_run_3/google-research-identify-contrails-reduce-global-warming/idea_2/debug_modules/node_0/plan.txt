Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and modify hyperparameters (Epochs, Batch Size, Debug Sample Size) to ensure the script runs quickly (under a few minutes) while still exercising all code paths.
2.  **Utility Verification**: Test the `rle_encode` and `dice_coef` functions with synthetic data to ensure mathematical correctness.
3.  **Data Pipeline Verification**: Initialize the DataLoaders using `get_loaders(debug=True)`. Fetch a single batch to verify input tensor shapes (Batch x 6 x 256 x 256) and mask shapes.
4.  **Model Architecture Verification**: Instantiate the `ContrailUNet`, pass the fetched batch through it, and verify that the output dimensions match the ground truth masks.
5.  **Training Loop Execution**: Run the full `train_model(debug=True)` function. This will verify the training loop, loss calculation (DiceBCELoss), backpropagation, validation step, and the checkpoint manager (saving/averaging weights).
6.  **Inference & Submission**: Load the best model saved by the training loop, perform inference on a batch from the test set, apply Run-Length Encoding (RLE) to the predictions, and verify the format of the resulting submission data.
