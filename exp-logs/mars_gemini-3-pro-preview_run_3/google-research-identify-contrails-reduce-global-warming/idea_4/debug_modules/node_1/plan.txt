The previous implementation failed with a `RuntimeError` because the string `"efficientnet-b4"` was passed to `timm.create_model`, but the `timm` library's model registry strictly requires underscores for this architecture (i.e., `"efficientnet_b4"`). To fix this, I will update the `BACKBONE` variable in `library/config.py` to use the correct identifier `"efficientnet_b4"`. This ensures the model factory can correctly locate and instantiate the requested architecture. Cite debug_lesson_3.
