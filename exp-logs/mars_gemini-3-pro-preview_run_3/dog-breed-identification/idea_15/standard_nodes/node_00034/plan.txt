Implementation Strategy:
1.  **Configuration Override**: I will modify the `Config` class attributes at runtime to enable `DEBUG` mode (limiting data to 500 samples) and reduce the number of folds and epochs (1 fold, 1 warmup epoch, 1 fine-tuning epoch). This ensures the script executes quickly as a baseline within the 57-minute limit.
2.  **Training Orchestration**: I will execute the training pipeline for the first fold only (`train_fold(0)`). This generates a "Manual Soup" model checkpoint.
3.  **Validation & Failure Analysis**:
    *   I will load the trained model and the validation dataset for the specific fold.
    *   I will perform inference to calculate the `Multi Class Log Loss` and print it as the "Final Validation Metric".
    *   I will extract metadata features (file size, width, height) for the validation images and calculate their Pearson correlation with the model's prediction error (per-sample Cross Entropy Loss).
4.  **Conditional Submission**: I will check if the validation metric is below the specified threshold (0.14004325100369866). If satisfied, I will trigger the `predict_and_submit` function to generate the submission file; otherwise, I will skip this step.
