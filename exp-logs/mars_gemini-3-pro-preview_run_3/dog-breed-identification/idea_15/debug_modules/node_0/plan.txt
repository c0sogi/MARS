This script demonstrates the end-to-end usage of the provided machine learning library for the Dog Breed Classification task. It performs the following steps:

1.  **Configuration Override**: Patches the `Config` class to run in `DEBUG` mode with reduced epochs (1 warmup, 1 fine-tune) and fewer folds (2) to ensure the demonstration completes quickly (under 2 minutes).
2.  **Data Preparation**: Validates the `prepare_folds` function, ensuring metadata is correctly loaded and stratified folds are generated.
3.  **Dataset & DataLoader Verification**: Instantiates the `DogDataset` and checks the dimensions of the data batches produced by the `DataLoader`.
4.  **Model Verification**: Initializes the `DogModel` (ConvNeXt-Small), passes a sample batch through it, and verifies the output shape matches the number of classes (120).
5.  **Training Pipeline**: Executes `train_fold` for two folds. This demonstrates the full training lifecycle: head warmup (freezing backbone), fine-tuning (unfreezing all), and "Manual Soup" model averaging.
6.  **Inference Pipeline**: Runs `predict_and_submit` to generate predictions on the test set using the trained fold models, applying Test-Time Augmentation (TTA) and ensemble averaging.
7.  **Validation**: Asserts the existence and correct format of the generated submission file.
