The issue is that the code subsets the training data for debugging *before* deriving the list of unique classes (breeds). When `Config.DEBUG` is True, the training set is truncated to 50 samples, which likely does not contain all 120 breeds. Consequently, the `class_to_idx` mapping is incomplete. When the validation set (which is also subsetted, but independently) contains a breed like 'irish_wolfhound' that wasn't in the training subset, the lookup fails with a `KeyError`.

To fix this, I will move the data subsetting logic in `library/dataset.py` to occur *after* the global class schema (`classes` and `class_to_idx`) has been derived from the full dataset. This ensures the model always has the complete label space even when training on a small sample, applying the principle of "Derive Global Schemas Before Subsetting Data" (Cite debug_lesson_3).
