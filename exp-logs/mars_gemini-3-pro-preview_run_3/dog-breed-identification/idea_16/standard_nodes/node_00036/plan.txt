Implementation of the Hierarchical Stratified Ensemble pipeline. The strategy involves a single-fold fast baseline execution (due to time constraints) using a ConvNeXt-Small backbone. The training process includes a Head Warmup phase followed by Fine-tuning with Cosine Annealing. The final model is a "Soup" of the top 3 checkpoints. Failure analysis correlates loss with image metadata, and Test-Time Augmentation (TTA) is applied for inference.
