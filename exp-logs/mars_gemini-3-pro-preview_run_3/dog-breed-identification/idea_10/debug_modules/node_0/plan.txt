The following script demonstrates the end-to-end usage of the provided library components for the Dog Breed Classification task. It optimizes for speed by enabling debug mode (using a small subset of data), reducing the number of training epochs to 1, and limiting the cross-validation to a single fold.

The script performs the following steps:
1.  **Configuration Override**: Modifies the `Config` class to set up a fast demonstration run (Debug mode, 1 epoch, 1 fold).
2.  **Dataset Verification**: Initializes data loaders and verifies the shape and type of the data batches.
3.  **Model Verification**: Instantiates the model, checks the freezing/unfreezing logic of the backbone, and validates the output shape of a forward pass.
4.  **Training Loop Execution**: Runs the `train_fold` function to train the model for one fold, including warm-up and fine-tuning phases, and verifies that checkpoints are saved.
5.  **Inference Execution**: Runs the `run_inference` pipeline to generate predictions on the test set using the trained model and verifies the format of the submission file.
