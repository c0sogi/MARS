# Proposed Baseline Approach: End-to-End Fine-Tuned ResNet-50

## Model
We will utilize the **ResNet-50** architecture as our baseline model. This architecture is chosen for its proven balance between computational efficiency and classification accuracy, serving as a standard benchmark in computer vision.
*   **Architecture:** The model consists of a convolutional backbone with 50 layers, utilizing residual connections (skip connections) to allow for effective deep feature extraction without vanishing gradient issues.
*   **Head Replacement:** We will discard the original ImageNet classification head (1000 classes) and replace it with a single fully connected (dense) layer with 120 output neurons, corresponding to the specific dog breeds in our dataset.
*   **Initialization:** The backbone will be initialized with weights pre-trained on the ImageNet-1k dataset to leverage learned feature representations, while the new head will be initialized randomly.

## Data
Data processing will focus on standardizing inputs for the pre-trained network while keeping overhead low.
*   **Preprocessing:** All images will be resized to 256x256 pixels. We will then extract a 224x224 central crop. Pixel values will be normalized using the standard ImageNet mean (`[0.485, 0.456, 0.406]`) and standard deviation (`[0.229, 0.224, 0.225]`).
*   **Training Augmentation:** To prevent overfitting while maintaining speed, we will apply lightweight augmentations: Random Resized Crops (scaling the image between 80% and 100% before cropping to 224x224) and Random Horizontal Flips.
*   **Validation/Test Preprocessing:** For evaluation, we will strictly use resizing to 256x256 followed by a Center Crop of 224x224 to ensure deterministic inputs.

## Training
The training process is designed to be stable and fast, utilizing the available GPU acceleration.
*   **Loss Function:** We will use **Cross-Entropy Loss**, the standard objective function for multi-class classification tasks.
*   **Optimizer:** We will use the **AdamW** optimizer, which decouples weight decay from gradient updates, often leading to better generalization than standard Adam.
*   **Strategy:** We will employ a two-phase fine-tuning strategy:
    1.  **Warm-up:** Initially, the backbone weights will be frozen, and only the new classification head will be trained for a few epochs. This prevents the large gradients from the randomly initialized head from destroying the pre-trained backbone features.
    2.  **Fine-tuning:** We will then unfreeze the entire network (or the top residual blocks) and train with a significantly lower learning rate (e.g., 1e-4 or 1e-5) to adapt the features to the specific nuances of dog breeds.
*   **Acceleration:** We will utilize **Automatic Mixed Precision (AMP)** to perform computations in float16 where possible, reducing memory usage and speeding up training on the NVIDIA A100 GPU.

## Evaluation
*   **Inference:** The model will iterate through the test dataset using the validation preprocessing pipeline (Resize -> Center Crop -> Normalize).
*   **Prediction:** The raw output logits from the model will be passed through a **Softmax** function to generate a probability distribution over the 120 breeds.
*   **Submission:** The resulting probabilities will be formatted into a CSV file, mapping each image ID to its respective breed probabilities as required by the submission format.
