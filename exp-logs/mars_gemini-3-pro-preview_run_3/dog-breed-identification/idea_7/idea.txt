# Proposed Solution: Heterogeneous Ensemble with Layer-Wise Decay and Calibrated SWA

## Model
We will construct a **Heterogeneous Ensemble** consisting of two distinct architectures to maximize feature diversity while respecting the capacity "sweet spot" identified in previous runs.
1.  **Backbone A: ConvNeXt-Small.** We retain this architecture as the primary component. It has been empirically proven to offer the optimal balance of capacity and generalization for this dataset, significantly outperforming "Tiny" variants (Cite solution_lesson_node_00009) while avoiding the overfitting observed with "Large" variants (Cite solution_lesson_node_00013).
2.  **Backbone B: Swin-Small (v2).** We introduce a hierarchical Vision Transformer (Swin-S) as the secondary component. While ConvNeXt excels at capturing local texture details (fur patterns), Swin Transformers leverage self-attention to model long-range dependencies and global shape. Ensembling these distinct inductive biases typically yields higher gains than ensembling identical architectures.
3.  **Head Design:** Both backbones will utilize a standard linear classification head. We will explicitly **unwrap** any model wrappers (e.g., `AveragedModel`) before saving checkpoints to prevent the "silent failure" of initialization observed in previous attempts (Cite solution_lesson_node_00021).

## Data
We will enforce a rigid preprocessing pipeline that prioritizes geometric diversity and metric alignment, strictly avoiding the pitfalls of high-resolution scaling and label smoothing.
*   **Preprocessing Pipeline:** The training data will undergo **`RandomResizedCrop`** $\rightarrow$ **`RandomHorizontalFlip`** $\rightarrow$ **`RandAugment`**.
    *   We explicitly retain `RandomResizedCrop` to prevent the overfitting caused by static resizing (Cite solution_lesson_node_00012).
    *   We ensure `RandomHorizontalFlip` is applied *before* `RandAugment` to guarantee the model learns essential spatial symmetries (Cite solution_lesson_node_00014).
*   **Resolution:** Inputs will be fixed at **224x224**. We explicitly reject scaling to higher resolutions (e.g., 384x384) as this necessitates reducing batch size, which destabilizes training and degrades performance (Cite solution_lesson_node_00016).
*   **Targets:** We will use **Hard Labels** (0 or 1) and strictly avoid Label Smoothing. This ensures the training objective maximizes the Log Loss metric without artificial penalties (Cite solution_lesson_node_00003).

## Training
We will employ a **5-Fold Stratified Cross-Validation** strategy enhanced by **Layer-Wise Learning Rate Decay (LLRD)** and **Stochastic Weight Averaging (SWA)**.
*   **Layer-Wise Learning Rate Decay (Structural Innovation):** Instead of a uniform learning rate during the fine-tuning phase, we will apply a decay factor (e.g., 0.8) to the learning rate of each preceding layer. This allows the randomly initialized head to learn rapidly while the deep backbone layers update gently, preserving the high-quality pre-trained features better than the standard "Two-Phase" approach (Cite solution_lesson_node_00001, Cite solution_lesson_node_00004).
*   **Schedule:** We will use a **Cosine Annealing** scheduler with `T_max=30` epochs. This extended horizon allows the optimizer to escape local minima more effectively than shorter schedules (Cite solution_lesson_node_00007).
*   **SWA with Safe Checkpointing:** We will activate Stochastic Weight Averaging in the final epochs to flatten the loss landscape. Crucially, we will implement a safe saving mechanism that strips the `module.` prefix or saves the unwrapped model, ensuring that the SWA weights are correctly loaded during inference (Cite solution_lesson_node_00021).
*   **Loss Function:** Standard **Cross-Entropy Loss** will be used for both optimization and validation to ensure metric coupling (Cite solution_lesson_node_00002).

## Evaluation
*   **Post-Hoc Calibration (Structural Innovation):** Before aggregating the ensemble, we will perform **Temperature Scaling**. Using the Out-Of-Fold (OOF) predictions from the cross-validation, we will optimize a scalar temperature parameter $T$ for each model to minimize the Cross-Entropy of the validation set. This explicitly aligns the model's confidence distribution with the Log Loss metric.
*   **Ensemble Inference:** We will average the calibrated probabilities from all 5 folds of both the ConvNeXt-Small and Swin-Small models.
*   **Test-Time Augmentation (TTA):** For each model, we will average predictions from the original image and a horizontally flipped version to reduce variance.
