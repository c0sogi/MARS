Since 50 random samples cannot contain all 120 dog breeds, the resulting class list is incomplete (42 classes), causing the assertion error in `runfile.py`. The fix is to generate the class mapping from the full training dataset first, ensuring all 120 classes are registered, and then subset the dataframes if debugging is enabled.
