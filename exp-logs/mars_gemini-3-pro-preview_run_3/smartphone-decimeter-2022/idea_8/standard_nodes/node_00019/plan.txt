Implementation Strategy:
1.  **Setup & Configuration**: Initialize random seeds and define feature columns based on the provided feature engineering logic.
2.  **Data Loading**: Use `get_processed_dataset` to load training and validation data. This handles the complex merging of GNSS, IMU, and Ground Truth.
3.  **Model Training**: Train two separate LightGBM models (East and North residuals) using `train_residual_model`. This uses GroupKFold to ensure robust generalization to unseen drives.
4.  **Validation Pipeline**:
    *   Predict raw residuals for the validation set.
    *   Reconstruct "Raw ML" geodetic coordinates by applying the predicted ENU offsets to the WLS baseline.
    *   Apply the `RobustKalmanSmoother` to each trip in the validation set. This smoother includes the critical velocity initialization and innovation gating.
    *   Compute the official competition metric.
5.  **Failure Analysis**: Calculate correlations between the final distance error and input features (e.g., signal strength, satellite count) to understand error sources.
6.  **Inference & Submission**:
    *   If the validation score meets the threshold, load test data.
    *   Predict residuals and reconstruct coordinates.
    *   Apply smoothing.
    *   Format and save the submission file.
