Based on the accumulated lessons, specifically the high performance of point-wise gradient boosting (Cite solution_lesson_node_00010), the effectiveness of residual learning (Cite solution_lesson_node_00007), and the catastrophic failure of temporal smoothing on heavy-tailed outliers (Cite solution_lesson_node_00014), I propose the **Physics-Consistency Featurized Median-Ensemble** strategy.

This approach introduces a structural evolution in two areas:
1.  **Feature Engineering Paradigm:** Shifts from raw signal statistics (e.g., signal strength) to **Physics-Consistency Metrics**. We explicitly calculate how well the raw measurements align with the provided baseline solution (Post-Fit Residuals) and with the laws of physics (Doppler Consistency), providing the model with direct indicators of baseline reliability.
2.  **Inference Structure:** Replaces the single-model regression and Kalman Smoothing pipeline with a **Median-Aggregated Ensemble**. This addresses the "outlier smearing" problem by using the robust median of multiple independent models to filter stochastic prediction errors, rather than relying on a temporal smoother that propagates them.

### 1. Model
The architecture consists of an **Ensemble of LightGBM Regressors**.
*   **Backbone:** We will train $K$ independent LightGBM models (e.g., $K=5$ from cross-validation folds).
*   **Targets:** Each model independently predicts the **ENU (East-North-Up) Residuals** in meters:
    $$ \Delta E = East_{GT} - East_{WLS}, \quad \Delta N = North_{GT} - North_{WLS} $$
    This retains the residual learning strategy (Cite solution_lesson_node_00007) but distributes the learning process to reduce variance.

### 2. Data
The preprocessing pipeline combines the successful point-wise aggregation (Cite solution_lesson_node_00011) with new physics-derived consistency features.

*   **Base Features:** Aggregated statistics (Mean, Max, Std) of `Cn0DbHz`, satellite counts, and IMU accelerometer magnitude.
*   **Physics-Consistency Features (Innovation):**
    *   **Geometric Consistency (Post-Fit Residuals):** For each timestamp, calculate the theoretical distance from the provided `WlsPosition` to each satellite. Subtract this from the `RawPseudorangeMeters`. Remove the common clock bias (estimated as the median difference). Compute statistics (Std, Max, Mean-Abs) of these residuals. High variance indicates a poor geometric fix (multipath).
    *   **Dynamic Consistency (Doppler Residuals):** Calculate the theoretical range rate by projecting the satellite velocity onto the user-satellite line-of-sight vector. Compare this with the measured `PseudorangeRateMetersPerSecond`. Compute statistics of these differences. This captures discrepancies between the signal's phase change and the geometric solution, identifying non-line-of-sight signals without enforcing a noisy velocity constraint (addressing Lesson 00027).
*   **Constraint:** Strictly **no temporal windowing** of features to ensure the model learns signal properties rather than memorizing trajectory shapes (Cite solution_lesson_node_00011).

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss is critical for robustness against the heavy-tailed error distribution inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Strategy:** Train $K$ models using **GroupKFold** cross-validation grouped by `drive_id`. This ensures each model in the ensemble is validated on completely unseen drives, enforcing generalization.

### 4. Evaluation
The inference pipeline replaces temporal smoothing with robust ensemble aggregation.
1.  **Feature Generation:** Compute point-wise consistency features for the test set.
2.  **Ensemble Prediction:** Generate $K$ predictions for each timestamp (one from each fold model).
3.  **Robust Aggregation:** Compute the **Pixel-wise Median** of the $K$ predictions for $\Delta E$ and $\Delta N$.
    *   *Why:* Single models occasionally output massive outliers due to specific noise patterns. The median operator naturally filters these out without the "smearing" effect of a Kalman Filter (Cite solution_lesson_node_00014).
4.  **Reconstruction:** Apply the median residuals to the WLS baseline to obtain the final coordinates.
