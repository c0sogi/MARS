Implementation strategy:
1.  **Setup**: Initialize random seeds and configure paths.
2.  **Data Loading**: Load training data (with a limit for speed), hold-out validation data, and test data using the provided `library.data_loader`.
3.  **Training**: Instantiate the `PhysicsEnsembleModel` from `library.model`. Train it using only the training data. The model class handles Cross-Validation internally.
4.  **Validation Inference**: Use the trained ensemble to predict ENU residuals for the validation set. Reconstruct the absolute Latitude/Longitude coordinates.
5.  **Metric Calculation**: Compute the Haversine distance between predicted and ground truth coordinates. Group by phone to calculate the 50th and 95th percentiles, average them per phone, and then average across all phones to obtain the final validation metric.
6.  **Failure Analysis**: Calculate Pearson correlation coefficients between the validation distance errors and the input features to identify sources of error. Print the top correlations.
7.  **Submission**: Check if the validation metric meets the threshold (< 4.32379283550646). If successful, predict on the test set, reconstruct coordinates, and save the `submission.csv` file.
