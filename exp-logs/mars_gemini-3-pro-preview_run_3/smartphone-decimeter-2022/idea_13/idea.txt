Based on the accumulated lessons, specifically the success of **Sector-Based Feature Aggregation** (Cite solution_lesson_node_00036) and the superiority of **Gradient Boosting** for sensor residuals (Cite solution_lesson_node_00010), I propose the **Sector-Based Pseudorange-Residual Boosting** strategy.

This strategy evolves the previous best approach (Idea 12) by incorporating **Pseudorange Residuals**—the direct driver of position error—into the directional feature space, alongside the previously used Doppler residuals. It maintains the robust point-wise regression framework and explicitly rejects temporal smoothing to avoid outlier smearing (Cite solution_lesson_node_00014).

### 1. Model
The core architecture consists of an **Ensemble of LightGBM Regressors**.
*   **Backbone:** Independent LightGBM models trained on $K$ cross-validation folds.
*   **Targets:** The models predict the **ENU (East-North-Up) Residuals** in meters.
    *   $\Delta E = East_{GT} - East_{WLS}$
    *   $\Delta N = North_{GT} - North_{WLS}$
    *   Predicting in the local metric frame ensures the loss function aligns with physical distance, avoiding the distortions of geodetic coordinates (Cite solution_lesson_node_00036).
    *   This retains the residual learning paradigm, leveraging the WLS baseline as a strong physical prior (Cite solution_lesson_node_00007).

### 2. Data
The preprocessing pipeline focuses on extracting physics-based error signals and aggregating them spatially to resolve the *direction* of the necessary correction.

*   **Coordinate Transformation:** Convert Ground Truth and WLS positions from Latitude/Longitude to a local ENU Cartesian frame.
*   **Physics Feature Extraction (Innovation):**
    *   **Pseudorange Residuals:** For every satellite, calculate the theoretical distance to the WLS baseline position. Subtract this from the measured `RawPseudorangeMeters` (corrected for clock bias). This residual represents the "force" a satellite is exerting on the WLS solution; a large positive residual implies the satellite is "pushing" the solution away.
    *   **Doppler Residuals:** Calculate the difference between measured `PseudorangeRateMetersPerSecond` and the theoretical range rate. This identifies non-line-of-sight signals (Cite solution_lesson_node_00033).
*   **Sector-Based Aggregation:**
    *   Divide the sky view into **Azimuthal Sectors** (e.g., 4 quadrants: NE, SE, SW, NW).
    *   For each sector, compute aggregated statistics (Mean, Max, Std) of:
        *   **Pseudorange Residuals** (New): Explicitly maps ranging errors to specific directions.
        *   **Doppler Residuals**: Captures dynamic inconsistency per direction.
        *   **Signal Quality**: `Cn0DbHz` and `SvElevationDegrees`.
    *   *Rationale:* This allows the model to learn vector corrections like "High pseudorange error in the North Sector requires a Southward correction" (Cite solution_lesson_node_00036).
*   **Global Features:** IMU acceleration magnitude (Mean/Std) to capture device dynamics (Cite solution_lesson_node_00007).
*   **Constraint:** Strictly **Point-Wise** features only. No temporal windowing is used to prevent the model from overfitting to specific training trajectories (Cite solution_lesson_node_00011).

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss is essential to minimize the influence of the heavy-tailed outliers inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Validation Strategy:** **GroupKFold** cross-validation grouped by `drive_id`. This ensures the model is evaluated on completely unseen drives, enforcing generalization to new environments.

### 4. Evaluation
The inference pipeline relies on robust ensemble aggregation rather than temporal smoothing.
1.  **Feature Generation:** Compute the Sector-Based Pseudorange/Doppler features for the test set.
2.  **Ensemble Prediction:** Generate predictions ($\Delta E, \Delta N$) from all $K$ fold models.
3.  **Robust Aggregation:** Compute the **Pixel-wise Median** of the predictions.
    *   This filters out stochastic prediction errors from individual models without "smearing" outliers across time, which was the primary failure mode of Kalman Smoothing in previous attempts (Cite solution_lesson_node_00014).
4.  **Reconstruction:** Convert the median ENU residuals back to Geodetic offsets and apply them to the WLS baseline to generate the final trajectory.
