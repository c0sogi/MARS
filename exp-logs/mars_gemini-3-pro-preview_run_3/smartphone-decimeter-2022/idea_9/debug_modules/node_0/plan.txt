Implementation Strategy:
1.  **Configuration Override**: Import the `Config` class and modify `LGBM_PARAMS` to reduce `n_estimators` to 10 and `num_leaves` to 8. This ensures the training step in the demonstration runs almost instantly.
2.  **Geospatial Utility Verification**: Instantiate `GeoUtils` and perform a round-trip coordinate transformation (LLA -> ECEF -> LLA) to verify the mathematical correctness of the utility functions.
3.  **Feature Generation (Train)**: Initialize `FeatureGenerator`. Call `generate_features` for the 'train' split with a limit of 1 drive (`limit=1`) and `load_cached_data=False` to force the execution of the feature engineering pipeline (Doppler estimation, IMU processing, etc.) on a small subset of data. Verify the resulting DataFrame contains expected columns (e.g., `v_east`, `signal_Cn0DbHz_mean`) and is not empty.
4.  **Model Training**: Initialize `LGBMResidualModel`. Train the model using the small feature set generated in the previous step. Since we have limited data, we'll use the same dataset for validation to simply demonstrate the API. Verify that the model files (`lgbm_east.txt`, `lgbm_north.txt`) are created.
5.  **Feature Generation (Test)**: Call `generate_features` for the 'test' split with `limit=1` to prepare data for inference.
6.  **Inference**: Use the trained `LGBMResidualModel` to predict residuals on the test feature set. Verify the output contains prediction columns.
7.  **Kalman Smoothing**: Initialize `KinematicKalmanSmoother`. Construct a trip-specific DataFrame from the predictions and features (simulating the data structure required by the smoother). Run `smooth_trip` and verify that the smoothed trajectory has the same length as the input and contains valid finite values.
8.  **Completion**: Print a success message if all steps and assertions pass.
