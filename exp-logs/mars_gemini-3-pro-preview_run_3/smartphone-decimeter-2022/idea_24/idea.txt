Based on the comprehensive analysis of previous experiments and lessons learned, I propose the **Unified Geometric-Boosting with Robust Carrier-Phase Graph Optimization** strategy.

This strategy synthesizes the high-precision "Anchor" generation of **Gradient Boosting** on **Geometric Projections** (Cite solution_lesson_node_00010, solution_lesson_node_00043) with the trajectory reconstruction power of **Carrier Phase (TDCP)** (Cite solution_lesson_node_00046). Crucially, it corrects the feature engineering flaws of recent attempts by strictly **excluding Doppler features** from the ML model (Cite solution_lesson_node_00056) and **unifying frequency bands** (Cite solution_lesson_node_00055), while enhancing the graph optimizer with robust loss functions to handle cycle slips.

### 1. Model: Unified Geometric-Projected LightGBM
The predictive core is an ensemble of **LightGBM Regressors**, designed to predict the position error of the WLS baseline based on instantaneous signal geometry and quality.

*   **Architecture:** Two independent models per fold:
    *   **East Model:** Predicts the Easting residual ($\Delta E$).
    *   **North Model:** Predicts the Northing residual ($\Delta N$).
*   **Target:** The model predicts the **ENU (East-North-Up) Residuals** ($P_{GT} - P_{WLS}$) in meters. This leverages the WLS baseline as a robust prior (Cite solution_lesson_node_00007).
*   **Input Features (Unified Physics):**
    The feature set focuses on the **Geometric Gradient** of the position error, aggregated across *all* visible satellites (L1 + L5) to maximize observability (Cite solution_lesson_node_00055).
    1.  **Net Pseudorange Force:** $\vec{F}_{PR} = \sum_{all} w_i \cdot r_{pr,i} \cdot \vec{u}_i$.
        *   $r_{pr,i}$: Post-fit pseudorange residual for satellite $i$.
        *   $\vec{u}_i$: Line-of-Sight unit vector to satellite $i$.
        *   $w_i$: Weight based on signal strength ($Cn0$).
        *   *Note:* This vector physically describes the direction and magnitude of the "pull" exerted by ranging errors on the solution.
    2.  **Geometry Stiffness:** Elements of the weighted Geometry Matrix $\mathbf{G} = \sum w_i \vec{u}_i \vec{u}_i^T$. This captures the constellation's Dilution of Precision (DOP).
    3.  **Global Context:** Aggregated signal quality (Mean/Std Cn0) and IMU dynamics (Accel Mean/Std).
    *   **Exclusion:** Explicitly **exclude Doppler-derived features** (forces/residuals) from the input, as they are derivative-domain signals that fail to predict integral-domain position biases (Cite solution_lesson_node_00056).

### 2. Data: Parallel Processing Streams
The preprocessing pipeline generates two distinct data streams: one for the ML model (Anchors) and one for the Graph Optimizer (Shape).

*   **Stream A: Point-Wise ML Features**
    *   Convert Ground Truth and WLS positions to a local ENU frame.
    *   Compute the **Unified Geometric Projection** features for every timestamp. Strictly **no temporal windowing** is used to prevent trajectory memorization (Cite solution_lesson_node_00011).
*   **Stream B: Robust Kinematics (Odometry)**
    *   For every consecutive pair of timestamps $(t-1, t)$, estimate the relative displacement vector $\Delta \vec{x}_{odom, t}$.
    *   **Method:** Use **RANSAC** to solve the **Time-Differenced Carrier Phase (TDCP)** equation.
    *   **Fallback:** If RANSAC fails (insufficient inliers due to signal blockage), fallback to a WLS solution using raw Doppler measurements.
    *   **Output:** A sequence of relative vectors $\Delta \vec{x}_{odom}$ and associated weights based on the method used (High for TDCP, Low for Doppler).

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss minimizes the median error, ensuring the ML predictions ("Anchors") are robust to the massive outliers inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Validation:** **GroupKFold** cross-validation grouped by `drive_id`. This strictly enforces evaluation on unseen drives to ensure generalization.

### 4. Evaluation: Robust Global Graph Optimization
The inference pipeline fuses the ML Anchors and Kinematic Shape using a global optimization framework that is robust to outliers in *both* streams.

1.  **Anchor Prediction:** Generate predicted residuals using the LightGBM ensemble and add them to the WLS baseline to obtain noisy absolute positions $\hat{P}_{ML}$.
2.  **Graph Optimization:** Solve for the trajectory $X = \{x_0, \dots, x_N\}$ that minimizes the composite objective:
    $$ J(X) = \sum_{t} \rho_{anchor}(x_t - \hat{P}_{ML, t}) + \lambda \sum_{t} \rho_{odom}( (x_t - x_{t-1}) - \Delta \vec{x}_{odom, t} ) $$
    *   **$\rho_{anchor}$ (Huber Loss):** Pulls the trajectory towards the ML predictions but allows "breaking" away from large ML outliers (fixing the smearing issue of Cite solution_lesson_node_00014).
    *   **$\rho_{odom}$ (Huber Loss):** Enforces the precise relative shape derived from TDCP. Using a robust loss here (instead of L2) allows the trajectory to handle rare cycle slips or odometry failures without distorting the entire path.
3.  **Reconstruction:** The optimized $X$ is converted back to Latitude/Longitude for the final submission.
