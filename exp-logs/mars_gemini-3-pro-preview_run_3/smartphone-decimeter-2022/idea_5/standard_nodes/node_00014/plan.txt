The issue is a `KeyError` in `library/postprocess.py` because the code attempts to look up original irregular timestamps in a DataFrame that has been reindexed to a regular 1Hz grid. The reindexing process drops rows that don't match the new index exactly, causing the lookup to fail (Cite debug_lesson_5). Additionally, the Kalman Smoother initialization is fragile if the first observation is NaN.

To fix this:
1.  Update `KalmanSmoother.smooth` to initialize the state estimate using the first *valid* observation instead of assuming index 0 is valid.
2.  Update `apply_kalman_smoothing` to use `reindex` with `method='nearest'` and a tolerance to snap observations to the grid for smoothing.
3.  Replace the `.loc[]` lookup with `np.interp` to interpolate the smoothed trajectory (calculated on the regular grid) back to the exact original timestamps required for the submission.
