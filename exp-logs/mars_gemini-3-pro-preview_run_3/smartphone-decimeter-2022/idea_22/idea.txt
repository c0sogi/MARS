Based on the accumulated lessons, specifically the superiority of **Gradient Boosting** for sensor residuals (Cite solution_lesson_node_00010), the effectiveness of **Geometric Projection** features (Cite solution_lesson_node_00043), and the high precision of **Carrier Phase (TDCP)** for relative motion (Cite solution_lesson_node_00046), I propose the **Split-Band Projected Boosting with Reliability-Weighted Graph Optimization** strategy.

This strategy introduces two key structural innovations:
1.  **Split-Band Feature Engineering:** It decomposes the geometric error projections by frequency band (**L1 vs. L5**). Since L5 signals are physically more robust to multipath, explicitly separating their error gradients allows the model to learn a dynamic weighting scheme superior to the fixed WLS baseline.
2.  **Reliability-Weighted Graph Fusion:** It upgrades the trajectory reconstruction from a static global optimization to a **Dynamic Factor Graph**. The strength of the kinematic constraints is modulated by the **Odometry Reliability** (derived from RANSAC inliers), ensuring the trajectory becomes rigid only when high-precision carrier phase measurements are verified, preventing the propagation of kinematic errors.

### 1. Model: Split-Band LightGBM Ensemble
The predictive core remains an ensemble of **LightGBM Regressors**, optimized to map instantaneous signal snapshots to position errors.

*   **Architecture:** Two independent models will be trained:
    *   **East Model:** Predicts the Easting error ($\Delta E$).
    *   **North Model:** Predicts the Northing error ($\Delta N$).
*   **Target:** The model predicts the **ENU (East-North-Up) Residuals** ($P_{GT} - P_{WLS}$) in meters. This leverages the WLS baseline as a robust physical prior (Cite solution_lesson_node_00007).
*   **Input Features (Structural Innovation):**
    Instead of a single "Net Error Force" vector (Cite solution_lesson_node_00043), the model receives **Split-Band Projections**:
    *   **L1 Pseudorange Force:** $\vec{F}_{L1} = \sum_{i \in L1} w_i r_i \vec{u}_i$. The net error gradient derived only from L1 signals (GPS L1, GAL E1, etc.).
    *   **L5 Pseudorange Force:** $\vec{F}_{L5} = \sum_{i \in L5} w_i r_i \vec{u}_i$. The net error gradient derived only from L5 signals, which are cleaner but sparser.
    *   **Doppler Force:** $\vec{F}_{Dop} = \sum w_i r_{dop, i} \vec{u}_i$. The net error gradient derived from Doppler residuals, indicating dynamic inconsistency (Cite solution_lesson_node_00033).
    *   **Geometry Context:** Elements of the DOP matrix calculated separately for L1 and L5 subsets.
    *   **Global Context:** Aggregated signal quality and IMU dynamics.

### 2. Data: Point-Wise Physics & Robust Odometry
The preprocessing pipeline splits into Feature Engineering (ML) and Kinematic Estimation (Physics).

*   **Coordinate Transformation:** Convert Ground Truth and WLS positions to a local ENU frame.
*   **Feature Engineering:** Compute the Split-Band Projected features described above for every timestamp. Strictly **no temporal windowing** is used to prevent trajectory memorization (Cite solution_lesson_node_00011).
*   **Robust Odometry Estimation:**
    For every pair of timestamps $(t-1, t)$, estimate the relative displacement $\Delta \vec{x}_{odom, t}$ and a **Reliability Score** $S_t$:
    *   **Primary (TDCP):** Attempt to solve Time-Differenced Carrier Phase using **RANSAC**.
        *   If successful ($>4$ inliers), set $\Delta \vec{x}_{odom} = \Delta \vec{x}_{TDCP}$ and $S_t = 1.0$ (High Confidence).
    *   **Secondary (Doppler):** If TDCP fails (cycle slips), solve for velocity using RANSAC on Doppler measurements.
        *   Set $\Delta \vec{x}_{odom} = \vec{v}_{Dop} \cdot \Delta t$ and $S_t = 0.1$ (Low Confidence).

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss minimizes the median error, ensuring the predicted "anchors" are robust to the massive outliers inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Validation:** **GroupKFold** cross-validation grouped by `drive_id`. This ensures the model is evaluated on completely unseen drives, enforcing generalization.

### 4. Evaluation: Reliability-Weighted Graph Optimization
The inference pipeline solves a global optimization problem to fuse the ML anchors with the adaptive kinematic constraints.

1.  **Anchor Generation:** Use the trained LightGBM ensemble to predict residuals and correct the WLS baseline, producing a sequence of absolute positions $\hat{P}_{ML}$.
2.  **Graph Optimization:** Solve for the trajectory $X = \{x_0, \dots, x_N\}$ that minimizes:
    $$ J(X) = \sum_{t} \rho(x_t - \hat{P}_{ML, t}) + \sum_{t} \lambda \cdot S_t \cdot ||(x_t - x_{t-1}) - \Delta \vec{x}_{odom, t}||^2 $$
    *   **Anchor Term:** $\rho$ is a **Huber Loss**. It pulls the trajectory towards the ML predictions but allows it to "break" away from large ML outliers (fixing the smearing issue of Cite solution_lesson_node_00014).
    *   **Shape Term:** The weighted L2 penalty enforces the relative shape. The dynamic weight $\lambda \cdot S_t$ ensures the trajectory becomes **rigid** when carrier-phase measurements are valid (locking in the precise shape) and **flexible** when relying on noisy Doppler or ML predictions.
