Furthermore, the pipeline uses caching, so simply fixing the code won't work unless the stale cache files are removed.

1.  In `library/feature_engineering.py`, I will add `tripId` to the `target_keys` selection in `prepare_dataset` so it is preserved in the final dataframe.
