Based on the lessons learned, specifically the robustness of residual learning (Cite solution_lesson_node_00007), the superiority of Gradient Boosting for sensor data (Cite solution_lesson_node_00010), and the catastrophic failure of standard smoothing on heavy-tailed outliers (Cite solution_lesson_node_00014), I propose the **Point-Wise Residual Boosting with Global L1-Robust Trajectory Optimization** strategy.

### 1. Model: LightGBM for ENU Residuals
The core predictive model remains a **LightGBM Regressor**.
*   **Architecture:** Two independent models will be trained:
    *   **East Model:** Predicts the Easting error ($\Delta E$).
    *   **North Model:** Predicts the Northing error ($\Delta N$).
*   **Target:** The model predicts the **ENU (East-North-Up) Residuals** in meters:
    $$ \text{Target} = P_{GT} - P_{WLS} $$
    This leverages the robust physical prior of the WLS baseline while focusing the ML model on correcting non-linear biases (Cite solution_lesson_node_00007).

### 2. Data: Point-Wise Physics & Doppler Velocity
The preprocessing pipeline combines point-wise feature engineering (Cite solution_lesson_node_00011) with a physics-based velocity derivation.

*   **Feature Engineering:** For each timestamp, generate aggregated statistics (Mean, Max, Std) for `Cn0DbHz`, satellite counts, and IMU accelerometer magnitude. **Crucially, do not use temporal windowing** to prevent trajectory memorization (Cite solution_lesson_node_00011).
*   **Doppler Velocity Estimation (Innovation):**
    *   For each timestamp in both Train and Test, solve a Weighted Least Squares (WLS) problem using the raw `PseudorangeRateMetersPerSecond` and `SvVelocity` measurements to estimate the device's instantaneous velocity vector $\vec{V}_{doppler}$.
    *   Doppler measurements are independent of position multipath errors, providing a clean "relative motion" signal.

### 3. Training: Robust L1 Optimization
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss ensures the model learns the median error and remains robust to the massive outliers common in the dataset (Cite solution_lesson_node_00007).
*   **Validation:** **GroupKFold** cross-validation grouped by `drive_id` to strictly enforce evaluation on unseen drives.

### 4. Evaluation: Global L1 Trajectory Optimization
The inference pipeline replaces the recursive Kalman Filter with a **Global Optimization** approach implemented in PyTorch. This addresses the "smearing" of outliers (Cite solution_lesson_node_00014) and gating failures (Cite solution_lesson_node_00018) by solving for the entire trajectory simultaneously under robust constraints.

*   **Procedure:**
    1.  **Base Prediction:** Generate predicted position residuals using LightGBM and add them to the WLS baseline to get a sequence of "noisy anchor points" $\hat{P}_{LGBM}$.
    2.  **Optimization Problem:** Define a sequence of learnable variables $X = \{x_0, x_1, ..., x_N\}$ representing the refined trajectory.
    3.  **Loss Function:** Minimize a composite loss function using Gradient Descent (e.g., Adam):
        $$ \mathcal{L} = \sum_{t} ||x_t - \hat{P}_{LGBM, t}||_1 + \lambda \sum_{t} ||(x_t - x_{t-1}) - \vec{V}_{doppler, t} \cdot \Delta t||_2^2 $$
        *   **Term 1 (Anchor):** An **L1 Norm** penalty pulling the trajectory towards the ML predictions. The L1 norm allows the trajectory to "break" away from massive outliers in $\hat{P}_{LGBM}$ without incurring a huge penalty, effectively ignoring them.
        *   **Term 2 (Physics):** An **L2 Norm** penalty enforcing kinematic consistency with the computed Doppler velocities.
    4.  **Result:** The optimized $X$ is the final trajectory. This method fuses the absolute position accuracy of the ML model with the relative motion accuracy of the Doppler physics, while being mathematically robust to heavy-tailed position errors.
