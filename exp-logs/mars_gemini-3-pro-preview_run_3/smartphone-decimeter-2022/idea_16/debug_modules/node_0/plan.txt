Implementation Strategy:
1.  **Configuration Patching**: Modify `Config` attributes at runtime to enable debug mode and reduce model complexity (e.g., fewer trees) for rapid execution.
2.  **Data Loading**: Use `get_processed_dataset` to load a small subset of training and validation data (limited by `max_drives`).
3.  **Model Training**: Train the LightGBM residual regressor using `train_residual_model` on the training subset.
4.  **Prediction & Correction**: Generate predictions for the validation subset and apply ENU corrections to WLS baselines.
5.  **Trajectory Optimization**: Select a single drive from the validation set, compute TDCP displacements using `get_tdcp_displacement`, and refine the trajectory using `TrajectoryAligner`.
6.  **Evaluation**: Calculate the competition metric for the optimized trajectory using `score_submission`.
7.  **Verification**: Assert data shapes, prediction existence, and score validity throughout the process.
