Based on the accumulated lessons, specifically the superiority of **Gradient Boosting** for sensor residuals (Cite solution_lesson_node_00010), the effectiveness of **Geometric Projection** features (Cite solution_lesson_node_00043), and the high precision of **Carrier Phase (TDCP)** for relative motion (Cite solution_lesson_node_00046), I propose the **Split-Band Projected Boosting with Adaptive Graph Optimization** strategy.

This strategy structurally evolves the previous best approach (Idea 16) in two key ways:
1.  **Feature Engineering:** It refines the geometric projection by **splitting signals by frequency (L1 vs. L5)** and measurement type (**Pseudorange vs. Doppler**). This allows the GBDT to explicitly distinguish between noisy L1 geometry, clean L5 geometry, and dynamic multipath indicators, rather than aggregating them into a single "net force".
2.  **Trajectory Reconstruction:** It upgrades the global optimization to an **Adaptive Factor Graph**. Instead of a fixed shape constraint, this graph dynamically selects between Carrier Phase (TDCP) and Doppler velocity constraints based on signal integrity (RANSAC inliers), ensuring robustness against cycle slips.

### 1. Model: Multi-Stream Projected LightGBM
The predictive core remains an ensemble of **LightGBM Regressors**, optimized to map instantaneous signal snapshots to position errors.

*   **Architecture:** Two independent models will be trained:
    *   **East Model:** Predicts the Easting error ($\Delta E$).
    *   **North Model:** Predicts the Northing error ($\Delta N$).
*   **Target:** The model predicts the **ENU (East-North-Up) Residuals** ($P_{GT} - P_{WLS}$) in meters. This leverages the WLS baseline as a robust physical prior (Cite solution_lesson_node_00007).
*   **Input Features (Structural Innovation):**
    Instead of a single projection vector, the model receives a **Multi-Stream Geometric Representation**:
    1.  **L1 Pseudorange Force:** $\vec{F}_{L1} = \sum_{i \in L1} w_i r_{pr,i} \vec{u}_i$. The net error gradient derived from L1 signals (prone to multipath).
    2.  **L5 Pseudorange Force:** $\vec{F}_{L5} = \sum_{i \in L5} w_i r_{pr,i} \vec{u}_i$. The net error gradient from L5 signals (cleaner, sparser).
    3.  **Doppler Force:** $\vec{F}_{Dop} = \sum_{all} w_i r_{dop,i} \vec{u}_i$. The net error gradient derived from Doppler residuals, explicitly indicating the direction of non-line-of-sight reflections (Cite solution_lesson_node_00033).
    *   **Geometry Context:** Elements of the DOP matrix calculated separately for L1 and L5 subsets.
    *   **Global Context:** Aggregated signal quality and IMU dynamics.

### 2. Data: Point-Wise Physics & Adaptive Kinematics
The preprocessing pipeline combines point-wise feature engineering (Cite solution_lesson_node_00011) with a robust kinematic derivation stage.

*   **Coordinate Transformation:** Convert Ground Truth and WLS positions to a local ENU frame.
*   **Adaptive Kinematics (Odometry):**
    For every pair of timestamps $(t-1, t)$, estimate the relative displacement $\Delta \vec{x}_{kin, t}$:
    *   **Primary (TDCP):** Attempt to solve Time-Differenced Carrier Phase using **RANSAC**. This rejects cycle slips and provides mm-level precision.
    *   **Secondary (Doppler):** If TDCP RANSAC fails (insufficient inliers), solve for velocity using raw Doppler measurements.
    *   **Metric:** Store the displacement vector and a "Confidence Weight" $w_{kin, t}$ based on the method used (TDCP > Doppler).
*   **Feature Engineering:** Compute the Split-Band Projected features for every timestamp in Train and Test.

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss minimizes the median error, ensuring the predicted "anchors" are robust to the massive outliers inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Validation:** **GroupKFold** cross-validation grouped by `drive_id`. This ensures the model is evaluated on completely unseen drives, enforcing generalization.

### 4. Evaluation: Adaptive Global Graph Optimization
The inference pipeline solves a global optimization problem to fuse the ML anchors with the adaptive kinematic constraints.

1.  **Anchor Generation:** Use the trained LightGBM ensemble to predict residuals and correct the WLS baseline, producing a sequence of absolute positions $\hat{P}_{ML}$.
2.  **Graph Construction:** Define a cost function over the trajectory $X = \{x_0, \dots, x_N\}$:
    $$ J(X) = \sum_{t} \rho(x_t - \hat{P}_{ML, t}) + \sum_{t} w_{kin, t} ||(x_t - x_{t-1}) - \Delta \vec{x}_{kin, t}||^2 $$
    *   **Anchor Term:** $\rho$ is a **Huber Loss**. It pulls the trajectory towards the ML predictions but allows it to "break" away from large ML outliers (fixing the smearing issue of Cite solution_lesson_node_00014).
    *   **Shape Term:** The weighted L2 penalty enforces the precise relative shape derived from the Adaptive Kinematics. The weight $w_{kin, t}$ ensures the trajectory becomes rigid when TDCP is available and more flexible when relying on Doppler.
3.  **Optimization:** Minimize $J(X)$ using a sparse solver (e.g., `scipy.optimize` or PyTorch) to obtain the final trajectory.
