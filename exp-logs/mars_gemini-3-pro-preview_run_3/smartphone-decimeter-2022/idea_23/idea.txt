Based on the accumulated lessons, specifically the high performance of **Geometric Projection** features (Cite solution_lesson_node_00043), the precision of **Carrier Phase (TDCP)** constraints (Cite solution_lesson_node_00046), and the critical failure of **Feature Splitting** (Cite solution_lesson_node_00055), I propose the **Unified Physics-Projected Boosting with Hybrid-Kinematic Graph Fusion** strategy.

This strategy optimizes the previous best approach (Idea 16) by reinforcing the kinematic constraints. While Idea 16 relied solely on TDCP (which can fail due to cycle slips), this approach introduces a **Hybrid Kinematic Stream** that seamlessly falls back to Doppler velocity when phase locks are lost. Crucially, it avoids the feature engineering pitfall of Idea 22 by maintaining a **Unified Feature Space** for the ML model, ensuring geometric observability is preserved.

### 1. Model: Unified LightGBM Ensemble
The predictive core remains an ensemble of **LightGBM Regressors**.
*   **Architecture:** Two independent models predicting **East** and **North** error components.
*   **Target:** The model predicts the **ENU (East-North-Up) Residuals** ($P_{GT} - P_{WLS}$) in meters. This leverages the WLS baseline as a robust physical prior (Cite solution_lesson_node_00007).
*   **Input Features (Unified Physics):**
    Instead of splitting features by band (which degrades performance, Cite solution_lesson_node_00055), the model receives **Unified Geometric Projections** aggregated across *all* visible satellites (L1 + L5):
    1.  **Net Pseudorange Force:** $\vec{F}_{PR} = \sum_{all} w_i r_{pr,i} \vec{u}_i$. The weighted sum of pseudorange residuals projected onto the Line-of-Sight vectors. This describes the net geometric "pull" of the errors.
    2.  **Net Doppler Force:** $\vec{F}_{Dop} = \sum_{all} w_i r_{dop,i} \vec{u}_i$. The weighted sum of Doppler residuals projected onto the LOS vectors. This explicitly encodes the direction of non-line-of-sight multipath (Cite solution_lesson_node_00033).
    3.  **Geometry Stiffness:** Elements of the unified Geometry Matrix ($\sum \vec{u}_i \vec{u}_i^T$) representing the constellation's resistance to error (DOP).
    4.  **Global Context:** Aggregated signal quality and IMU dynamics.

### 2. Data: Point-Wise Features & Hybrid Kinematics
The preprocessing pipeline generates two parallel data streams: one for the ML model (Anchors) and one for the Graph Optimizer (Shape).

*   **Stream A: Point-Wise ML Features**
    *   Convert Ground Truth and WLS positions to a local ENU frame.
    *   Compute the Unified Geometric Projection features for every timestamp. Strictly **no temporal windowing** is used to prevent trajectory memorization (Cite solution_lesson_node_00011).
*   **Stream B: Hybrid Kinematic Shape (Innovation)**
    For every consecutive pair of timestamps $(t-1, t)$, estimate the relative displacement $\Delta \vec{x}_{kin, t}$ and a confidence weight $\omega_{kin, t}$:
    *   **Primary (TDCP):** Attempt to solve Time-Differenced Carrier Phase using **RANSAC**.
        *   If successful (sufficient inliers), set $\Delta \vec{x}_{kin, t} = \Delta \vec{x}_{TDCP}$ and $\omega_{kin, t} = \text{High}$. This provides mm-level precision (Cite solution_lesson_node_00046).
    *   **Fallback (Doppler):** If TDCP fails (cycle slips), solve for velocity using RANSAC on Doppler measurements.
        *   Set $\Delta \vec{x}_{kin, t} = \vec{V}_{Doppler} \cdot \Delta t$ and $\omega_{kin, t} = \text{Medium}$. This ensures continuity when carrier phase is unavailable.

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss minimizes the median error, ensuring the ML predictions ("Anchors") are robust to the massive outliers inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Validation:** **GroupKFold** cross-validation grouped by `drive_id`. This strictly enforces evaluation on unseen drives.

### 4. Evaluation: Hybrid Graph Optimization
The inference pipeline fuses the ML Anchors and Hybrid Kinematics using a global optimization framework.

1.  **Anchor Prediction:** Generate predicted residuals using the LightGBM ensemble and correct the WLS baseline to obtain noisy absolute positions $\hat{P}_{ML}$.
2.  **Global Optimization:** Solve for the trajectory $X = \{x_0, \dots, x_N\}$ that minimizes:
    $$ J(X) = \sum_{t} \rho(x_t - \hat{P}_{ML, t}) + \sum_{t} \omega_{kin, t} ||(x_t - x_{t-1}) - \Delta \vec{x}_{kin, t}||^2 $$
    *   **Anchor Term:** $\rho$ is a **Huber Loss**. It pulls the trajectory towards the ML predictions but allows it to "break" away from large outliers (fixing the smearing issue of Cite solution_lesson_node_00014).
    *   **Shape Term:** The weighted L2 penalty enforces the precise relative shape derived from the Hybrid Kinematics stream. The dynamic weight $\omega_{kin, t}$ ensures the trajectory is rigid during valid carrier-phase segments and more compliant during Doppler fallback segments.
