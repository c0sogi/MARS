The following script demonstrates the complete pipeline for the smartphone location task using the provided library classes.

To ensure the demonstration runs quickly and stays within the time limit, the script first creates a "mini" metadata set pointing to a small subset of the available drives. It then uses the `MultiHypothesisFeaturizer` to process raw GNSS/IMU data for these drives into features, trains a LightGBM ensemble using `ResidualLGBMEnsemble`, and generates a submission file.
