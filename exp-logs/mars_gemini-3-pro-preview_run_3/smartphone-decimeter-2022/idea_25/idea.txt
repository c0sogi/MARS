Based on the accumulated lessons, specifically the high precision of **Carrier Phase (TDCP)** for trajectory reconstruction (Cite solution_lesson_node_00046), the effectiveness of **Geometric Projection** features (Cite solution_lesson_node_00043), and the critical insight that **Receiver State Metadata** is essential for prediction even when targets are cleaned (Cite solution_lesson_node_00058), I propose the **Altitude-Corrected Geometric Boosting with Reliability-Weighted Graph Fusion** strategy.

This strategy synthesizes the strengths of previous iterations while correcting specific failure modes. It adopts the cleaner "Altitude-Corrected" target definition from Idea 24 but explicitly retains the rich receiver state features (Clock Bias, Uncertainty) that were fatally pruned in that attempt. It also enforces the **Unified Feature** paradigm (Cite solution_lesson_node_00055) and removes noisy Doppler features from the ML input (Cite solution_lesson_node_00056).

### 1. Model: Context-Aware LightGBM Ensemble
The predictive core remains an ensemble of **LightGBM Regressors**, designed to predict the position error of the WLS baseline based on instantaneous signal conditions.

*   **Architecture:** Two independent models per fold:
    *   **East Model:** Predicts the Easting residual ($\Delta E$).
    *   **North Model:** Predicts the Northing residual ($\Delta N$).
*   **Target (Refined):** The model predicts the **ENU (East-North-Up) Residuals** in meters.
    *   **Correction:** Before computing residuals, project the Ground Truth (GT) latitude/longitude to the **WLS estimated altitude**.
    *   **Rationale:** Large vertical errors in the WLS baseline can project into horizontal errors during ENU conversion. By forcing the GT altitude to match the WLS altitude, we isolate the pure horizontal error, creating a cleaner target for the regressor (Refining Idea 24).
*   **Input Features (Unified & Contextual):**
    *   **Unified Geometric Force:** $\vec{F}_{PR} = \sum_{all} w_i \cdot r_{pr,i} \cdot \vec{u}_i$. The net error gradient derived from pseudorange residuals of *all* visible satellites (L1+L5), weighted by signal strength.
    *   **Geometry Stiffness:** Elements of the weighted Geometry Matrix (DOP).
    *   **Receiver State (Crucial Retention):** `BiasNanos`, `BiasUncertaintyNanos`, `DriftNanosPerSecond`, `DriftUncertaintyNanosPerSecond`. These features serve as proxies for internal hardware stability and signal lock quality (Cite solution_lesson_node_00058).
    *   **Exclusion:** Explicitly **exclude Doppler-derived features** from the ML input, as they are derivative-domain signals that correlate poorly with position bias (Cite solution_lesson_node_00056).

### 2. Data: Point-Wise Features & Robust Kinematics
The preprocessing pipeline generates two parallel data streams: one for the ML model (Anchors) and one for the Graph Optimizer (Shape).

*   **Stream A: Point-Wise ML Features**
    *   Convert Ground Truth and WLS positions to a local ENU frame (using the Altitude Correction described above).
    *   Compute the Unified Geometric Projection features and Receiver State statistics for every timestamp. Strictly **no temporal windowing** is used to prevent trajectory memorization (Cite solution_lesson_node_00011).
*   **Stream B: Reliability-Weighted Odometry**
    *   For every consecutive pair of timestamps, estimate the relative displacement vector $\Delta \vec{x}_{odom}$.
    *   **Method:** Use **RANSAC** to solve the **Time-Differenced Carrier Phase (TDCP)** equation.
    *   **Reliability Weight ($W_t$):** Calculate a confidence score for each step based on the number of RANSAC inliers. If inliers are low (indicating cycle slips or blockage), the weight is reduced, allowing the graph optimizer to rely more on the ML anchors.

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss minimizes the median error, ensuring the ML predictions ("Anchors") are robust to the massive outliers inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Validation:** **GroupKFold** cross-validation grouped by `drive_id`. This strictly enforces evaluation on unseen drives to ensure generalization.

### 4. Evaluation: Reliability-Weighted Graph Optimization
The inference pipeline fuses the ML Anchors and Kinematic Shape using a global optimization framework.

1.  **Anchor Prediction:** Generate predicted residuals using the LightGBM ensemble and add them to the WLS baseline to obtain noisy absolute positions $\hat{P}_{ML}$.
2.  **Global Optimization:** Solve for the trajectory $X = \{x_0, \dots, x_N\}$ that minimizes the composite objective:
    $$ J(X) = \sum_{t} \rho_{Huber}(x_t - \hat{P}_{ML, t}) + \lambda \sum_{t} W_t \cdot ||(x_t - x_{t-1}) - \Delta \vec{x}_{TDCP, t}||^2 $$
    *   **Anchor Term:** Uses a Huber Loss to pull the trajectory towards ML predictions while ignoring large outliers (Cite solution_lesson_node_00014).
    *   **Shape Term:** Enforces the precise relative shape derived from TDCP. The **Reliability Weight ($W_t$)** dynamically relaxes this constraint during signal outages (cycle slips), preventing the propagation of erroneous kinematic vectors.
3.  **Reconstruction:** The optimized $X$ is converted back to Latitude/Longitude for the final submission.
