Based on the accumulated lessons and the analysis of previous attempts, I propose the following strategy. This approach structurally evolves the "Hybrid Ensemble" concept by integrating **Regime-Adaptive Ensembling** with **Multi-Layer Domain-Adapted Transformers**.

# Model

The solution employs a **Heterogeneous Hybrid Ensemble** designed to exploit the orthogonal error profiles of statistical and neural models, specifically addressing the dependency between model performance and text length.

1.  **Neural Branch (The Hierarchical Context Experts):**
    *   **Backbones:** Deploy **`microsoft/deberta-v3-base`** and **`roberta-base`**. This combination is retained to preserve the architectural diversity (Disentangled Attention vs. Absolute Positional Embeddings) that yields uncorrelated errors **Cite {solution_lesson_node_00008}**.
    *   **Multi-Layer Concatenation Head:** Instead of relying on the final layer's `[CLS]` token, which often abstracts away stylistic nuances, the model will extract and concatenate the `[CLS]` tokens from the **last four hidden layers**. This creates a rich representation capturing the hierarchy from morphological style to semantic context **Cite {solution_lesson_node_00019}**.
    *   **Pooling:** We explicitly reject Mean Pooling in favor of `[CLS]` token extraction to prevent the neural representations from degenerating into "bag-of-words" equivalents, thereby maintaining orthogonality with the statistical branch **Cite {solution_lesson_node_00010}**.

2.  **Statistical Branch (The Surface Anchor):**
    *   **Features:** A concatenation of **Word N-grams (1-2)** and **Character N-grams (3-5)**. This explicitly captures sub-word morphological signatures and punctuation habits, which are critical for authorship attribution **Cite {solution_lesson_node_00002}**.
    *   **Classifier:** A weighted sub-ensemble of **Logistic Regression (Discriminative)** and **Multinomial Naive Bayes (Generative)**. The internal mixing weights will be mathematically optimized on the validation data rather than hardcoded, respecting the dataset's specific preference for generative signals **Cite {solution_lesson_node_00014}**.

# Data

1.  **Domain-Adaptive Pre-training (DAPT):**
    *   Before supervised fine-tuning, concatenate the raw text from `train.csv` and `test.csv`.
    *   Train both Transformer backbones on this combined corpus using the **Masked Language Modeling (MLM)** objective. This adapts the pre-trained weights to the specific 19th-century literary vocabulary and syntax **Cite {solution_lesson_node_00017}**.
2.  **Preprocessing:**
    *   **Statistical:** Apply `sublinear_tf` scaling to the TF-IDF vectorizer to dampen the effect of high-frequency tokens **Cite {solution_lesson_node_00003}**.
    *   **Neural:** Use the specific tokenizers for DeBERTa and RoBERTa.

# Training

1.  **Stratified K-Fold Bagging (k=5):**
    *   The entire training process will use a 5-fold stratified cross-validation scheme. This ensures that 100% of the training data is utilized for model building and provides robust **Out-Of-Fold (OOF)** predictions for weight optimization **Cite {solution_lesson_node_00011}**.
2.  **Adversarial Fine-Tuning:**
    *   Train the neural models using **Categorical Cross-Entropy Loss**.
    *   Implement **Adversarial Weight Perturbation (AWP)**. By perturbing weights to maximize loss in a local neighborhood during training, we flatten the loss landscape. This is crucial to prevent the "base" models from overfitting the small dataset, a failure mode observed in previous iterations.
3.  **Statistical Optimization:**
    *   Train the Logistic Regression and Naive Bayes models on the TF-IDF features for each fold.
    *   Optimize the internal blending weight $\alpha$ (where $P_{stat} = \alpha P_{LR} + (1-\alpha) P_{NB}$) using the OOF predictions **Cite {solution_lesson_node_00014}**.

# Evaluation

The core structural innovation lies in the **Regime-Adaptive Blending** strategy, which replaces global averaging with a context-aware approach.

1.  **Regime Identification:**
    *   Calculate the character length for all validation (OOF) samples.
    *   Partition the data into **3 Regimes** (Short, Medium, Long) based on **quantiles** (0-33%, 33-66%, 66-100%) of the length distribution. This ensures balanced data for optimization, unlike arbitrary fixed bins.
2.  **Regime-Specific Optimization:**
    *   For each regime, mathematically optimize the ensemble weights ($w_{stat}, w_{deberta}, w_{roberta}$) to minimize Log Loss.
    *   This strategy directly addresses the finding that statistical models outperform transformers on short texts while transformers dominate on long texts **Cite {solution_lesson_node_00029}**. It allows the system to dynamically shift reliance to the "Surface Anchor" when context is sparse and the "Context Expert" when signal is dense.
3.  **Inference:**
    *   Generate predictions for the test set using the bagged models.
    *   Calculate test sample lengths and assign them to the corresponding regime.
    *   Apply the regime-specific weights to combine the predictions.
    *   Apply numerical stability clipping ($max(min(p, 1-10^{-15}), 10^{-15})$).
