Implementation Strategy:
1.  **Initialization**: Configure the environment, setting random seeds and overriding default hyperparameters (epochs, batch size) to ensure the pipeline runs within the time limit while utilizing the A100 GPU effectively.
2.  **Data Loading**: Load the raw training, validation, and test datasets using the provided `load_raw_data` utility.
3.  **Domain-Adaptive Pretraining (DAPT)**: Execute `run_dapt_pipeline` to fine-tune the `microsoft/deberta-v3-base` and `roberta-base` backbones on the combined text corpus via Masked Language Modeling.
4.  **Phase 1 - Teacher Training**:
    *   Train the **Statistical Model** (Logistic Regression + Naive Bayes) and optimize its internal blending weights.
    *   Train the **Neural Models** (DeBERTa, RoBERTa) on the labeled training set using the `DistillationEngine` in supervised mode.
    *   Collect Out-Of-Fold (Validation) and Test predictions from all models.
5.  **Ensemble Optimization**: Use `EnsembleOptimizer` to determine the optimal mixing weights for the Statistical and Neural branches based on validation performance.
6.  **Phase 2 - Soft Target Generation**: Apply the optimized ensemble weights to the Phase 1 Test predictions to create high-quality soft targets.
7.  **Phase 3 - Student Distillation**:
    *   Re-initialize the Neural Models with DAPT weights.
    *   Train them using `DistillationEngine.train_distilled` on the combined dataset, utilizing Hard Labels for training data and Soft Targets for test data.
    *   The Statistical Model remains static to preserve error orthogonality.
8.  **Final Evaluation**:
    *   Blend the predictions from the Distilled Students and the Static Statistical Anchor.
    *   Compute and print the **Final Validation Metric** (Log Loss).
    *   Perform **Failure Analysis** by calculating the correlation between prediction error and text length.
9.  **Submission**: If the validation score meets the threshold, generate and save `submission.csv`.
