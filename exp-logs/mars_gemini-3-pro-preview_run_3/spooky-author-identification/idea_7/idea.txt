# Proposed Strategy: Transductive Knowledge Distillation with Orthogonal Stylometric Augmentation

## Model
The proposed solution implements a **Transductive Ensemble** architecture. It leverages the unlabeled test data not just for feature adaptation (DAPT) but for refining the decision boundaries via Knowledge Distillation, while explicitly preserving a static statistical branch to maintain error orthogonality.

1.  **Neural Branch (The Students):**
    *   **Backbones:** `microsoft/deberta-v3-base` and `roberta-base`. These are selected to maintain the architectural diversity (Disentangled Attention vs. Absolute Positional Embeddings) that proved effective in previous iterations **Cite {solution_lesson_node_00008}**.
    *   **Head Architecture:** Both models will utilize the **Multi-Layer Concatenation** strategy, extracting and concatenating `[CLS]` tokens from the last four hidden layers. This ensures the retention of hierarchical stylistic features (morphology $\to$ syntax) that are often lost in the final semantic layer **Cite {solution_lesson_node_00019}**.
    *   **Role:** These models will act as "Students" in a self-distillation loop, learning from the aggregated wisdom of the ensemble.

2.  **Statistical Branch (The Static Anchor):**
    *   **Sparse Features:** Retain the **TF-IDF pipeline** combining **Word N-grams (1-2)** and **Character N-grams (3-5)** to capture explicit vocabulary and orthography **Cite {solution_lesson_node_00002}**.
    *   **Dense Augmentation (Structural Evolution):** To address the weakness where models struggle with varying text lengths **Cite {solution_lesson_node_00002}**, we will augment the sparse matrix with a vector of **Explicit Stylometric Features**: log-transformed Character Count, Punctuation Density, and Type-Token Ratio.
    *   **Classifier:** A weighted ensemble of **Logistic Regression** and **Multinomial Naive Bayes**, with weights optimized on the validation set **Cite {solution_lesson_node_00003}**.
    *   **Role:** Crucially, this branch will **NOT** be retrained on pseudo-labels. It serves as a "Static Anchor" to provide ground-truth stylistic signals, preventing the neural models from drifting into a "consensus hallucination" during self-training and maintaining the ensemble's orthogonality **Cite {solution_lesson_node_00010}**.

## Data
1.  **Domain-Adaptive Pre-training (DAPT):**
    *   Concatenate `train.csv` and `test.csv` (text only).
    *   Train both Transformer backbones on this corpus using the **Masked Language Modeling (MLM)** objective to adapt the encoders to the 19th-century literary domain **Cite {solution_lesson_node_00017}**.
2.  **Distillation Dataset Construction:**
    *   **Source:** The original labeled training set.
    *   **Target:** The unlabeled test set, which will be paired with **Soft Targets** (probability distributions) generated by the "Teacher" ensemble (Phase 1).

## Training
The training procedure follows a **Teacher-Student Distillation** pipeline:

1.  **Phase 1: Teacher Training (Standard):**
    *   Train the Neural models (DeBERTa, RoBERTa) and the Statistical Anchor on the labeled training data using **Stratified K-Fold Cross-Validation (k=5)**.
    *   Generate **Out-Of-Fold (OOF)** predictions for the training set and predictions for the Test set.
    *   Optimize the ensemble weights ($w_{stat}, w_{deberta}, w_{roberta}$) to minimize Log Loss on the OOF predictions **Cite {solution_lesson_node_00014}**.

2.  **Phase 2: Soft Target Generation:**
    *   Compute the weighted average of the Phase 1 Test predictions using the optimized weights. These **Soft Targets** represent the "Teacher's" knowledge, capturing the uncertainty and calibration of the ensemble.

3.  **Phase 3: Student Retraining (Distillation):**
    *   Re-initialize the Neural models (DeBERTa, RoBERTa) with the DAPT weights.
    *   Train them on the combined dataset (Train + Test).
    *   **Loss Function:** Use a weighted combination of **Categorical Cross-Entropy** (for labeled Train data) and **KL-Divergence** (for Test data with Soft Targets). This allows the models to learn the test distribution's structure while remaining anchored to the gold labels.
    *   **Note:** The Statistical Anchor is *not* retrained here, preserving its role as an independent expert **Cite {solution_lesson_node_00008}**.

## Evaluation
1.  **Inference:**
    *   Pass the test data through the **Student Neural Models** (Phase 3) and the **Static Statistical Anchor** (Phase 1).
2.  **Blending:**
    *   Combine the predictions using the weights learned in Phase 1. We assume the optimal mixing ratio between "Context" (Neural) and "Surface" (Statistical) signals remains stable.
    *   Apply numerical stability clipping ($max(min(p, 1-10^{-15}), 10^{-15})$) to the final output.
