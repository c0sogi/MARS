This script demonstrates the end-to-end usage of the provided library for the Author Identification task. It performs the following steps:

1.  **Configuration Override**: Adjusts `Config` parameters at runtime to enable "Debug Mode" (using a small data subset, fewer epochs, and reduced features) ensuring the script executes quickly.
2.  **Data Loading**: Loads a small subset of the training, validation, and test data using `load_raw_data`.
3.  **Statistical Pipeline**: Executes the TF-IDF based Logistic Regression and Naive Bayes ensemble via `run_statistical_pipeline`.
4.  **Neural Pipeline (MLM + Fine-tuning)**:
    *   Prepares a corpus for domain adaptation.
    *   Runs Masked Language Modeling (MLM) pre-training on the text data.
    *   Fine-tunes the adapted backbone for classification.
    *   Generates predictions.
    *   This is repeated for both DeBERTa and RoBERTa architectures (using the small debug subset).
5.  **Ensemble Optimization**: Calculates the optimal weights to blend the Statistical, DeBERTa, and RoBERTa predictions.
6.  **Submission**: Generates the final CSV file using the optimized weights.

The script includes assertions at key stages to verify data shapes, file existence, and logic correctness.
