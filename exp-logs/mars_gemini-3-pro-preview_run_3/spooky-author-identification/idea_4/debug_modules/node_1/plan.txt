The `AssertionError` in `runfile.py` occurs because the `load_raw_data` function uses a default argument for `debug_size` that is evaluated and bound at import time (value 100). Although `runfile.py` updates `Config.DEBUG_SAMPLE_SIZE` to 60 at runtime, calling `load_raw_data(debug=True)` without the `debug_size` argument uses the stale default value of 100. This results in a dataset of size 100, causing the assertion `len(train_df) == Config.DEBUG_SAMPLE_SIZE` (100 == 60) to fail. To fix this, we must explicitly pass the updated `Config.DEBUG_SAMPLE_SIZE` to the function. The provided `library/utils.py` already handles the log loss calculation correctly (Cite debug_lesson_1), so no changes are needed there.
