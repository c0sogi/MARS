# Proposed Strategy: Feature-Augmented Stacking of Heterogeneous Stylometric Experts

## Model
The proposed solution evolves the previous "Hybrid Ensemble" (Idea 2) into a **Feature-Augmented Stacking Architecture**. Instead of a simple linear weighted average, this approach uses a trained meta-learner to dynamically weigh the contributions of distinct "expert" branches based on the input's characteristics (specifically text length).

1.  **Statistical Branch (The Surface Expert):**
    *   Retain the highly effective **TF-IDF pipeline** feeding into a **Logistic Regression and Multinomial Naive Bayes** ensemble **Cite {solution_lesson_node_00003}**.
    *   This branch utilizes **Word N-grams (1-2)** and **Character N-grams (3-5)** to capture explicit morphological signatures and punctuation styles **Cite {solution_lesson_node_00002}**.
2.  **Neural Branch (The Context Experts):**
    *   Deploy **two distinct Transformer architectures** to introduce neural diversity:
        *   **DeBERTa-v3-large:** Chosen for its superior disentangled attention mechanism.
        *   **RoBERTa-large:** Chosen for its differing pre-training objectives and tokenizer (BPE vs SentencePiece), ensuring error decorrelation.
    *   Crucially, both models will utilize the **`[CLS]` token** for classification rather than Mean Pooling. This ensures the neural representations remain structurally distinct from the "bag-of-words" nature of the statistical branch, maximizing the ensemble's orthogonality **Cite {solution_lesson_node_00010}**.
3.  **Meta-Learner (The Arbitrator):**
    *   A **Logistic Regression** meta-model that takes the concatenated probability distributions from the three base experts (Statistical, DeBERTa, RoBERTa) as input.
    *   **Structural Innovation:** The meta-learner will be augmented with a **Text Length** feature (log-transformed character count). This allows the system to learn a dynamic policy: relying more on the Statistical branch for shorter texts (where neural context is sparse) and the Neural branch for longer texts, directly addressing the length-dependent error correlation identified in **Cite {solution_lesson_node_00002}**.

## Data
1.  **Preprocessing:**
    *   **Neural:** Tokenization using the respective tokenizers for DeBERTa and RoBERTa.
    *   **Statistical:** Standard text cleaning (lowercasing) followed by TF-IDF vectorization.
    *   **Meta:** Calculation of character counts for every sample, log-transformed to reduce skew.
2.  **Cross-Validation Setup:**
    *   The entire training process will be wrapped in a **Stratified K-Fold (k=5)** loop. This is essential to generate unbiased **Out-of-Fold (OOF)** predictions for training the meta-learner without data leakage.

## Training
1.  **Base Model Training (Level 0):**
    *   For each fold, train the Statistical Ensemble, DeBERTa-v3-large, and RoBERTa-large on the training subset.
    *   Predict on the validation subset of the fold to generate OOF probabilities.
    *   The Neural models will use **Categorical Cross-Entropy Loss**, **AdamW**, and a linear scheduler with warmup.
2.  **Meta-Learner Training (Level 1):**
    *   Construct a training set for the meta-learner consisting of the OOF probability vectors from all three base models concatenated with the **Text Length** feature.
    *   Train the Logistic Regression meta-learner to minimize Log Loss on this composite dataset.
3.  **Final Retraining:**
    *   While the meta-learner is trained on OOFs, the final inference will use the average predictions of the 5 fold-models for each branch to ensure robustness.

## Evaluation
1.  **Inference:**
    *   Pass test data through all 5 folds of the Statistical, DeBERTa, and RoBERTa models.
    *   Average the predictions across folds for each branch to get stable Level 0 probabilities.
    *   Calculate the log-length feature for the test set.
2.  **Stacking:**
    *   Feed the averaged Level 0 probabilities and the length feature into the trained Meta-Learner.
    *   Apply the numerical stability clipping ($max(min(p, 1-10^{-15}), 10^{-15})$) to the final output.
