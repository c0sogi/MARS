The script expects OOF predictions for the combined training and validation sets (120 samples), but `StatisticalTrainer.run_cv` was called with only the training set (60 samples). To fix this, I will import `scipy.sparse` in `runfile.py` and manually concatenate the training and validation features (`X_train`, `X_val`) and labels (`y_train`, `y_val`) before passing them to `run_cv`. This ensures the cross-validation runs on the full dataset, producing the expected output shape.
