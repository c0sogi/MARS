# Baseline Approach: Logistic Regression with N-gram TF-IDF

## Model
The proposed model is a **Logistic Regression** classifier operating on high-dimensional sparse text features. This architecture is chosen as the baseline because it directly optimizes the evaluation metric (Multi-class Logarithmic Loss) without requiring the secondary probability calibration steps needed by Support Vector Machines (Model 1).
- **Feature Representation**: The model utilizes a **TF-IDF (Term Frequency-Inverse Document Frequency) Vectorizer**. To capture both semantic content and stylistic signatures (such as suffix usage, punctuation habits, and vocabulary richness), the representation will concatenate:
    - **Word N-grams**: (e.g., unigrams and bigrams) to capture specific words and short phrases.
    - **Character N-grams**: (e.g., 3-grams to 5-grams) to capture sub-word structures and morphological style.
- **Classifier**: A multinomial Logistic Regression layer. This linear model maps the input TF-IDF vectors to class probabilities using the Softmax function.

## Data
1.  **Preprocessing**: Apply minimal preprocessing to the raw text, specifically lowercasing, to normalize the input while preserving punctuation which may contain author-specific signals.
2.  **Vectorization**:
    - Learn the vocabulary and inverse document frequencies from the training corpus.
    - Transform both the training and test text data into sparse matrices using the learned vocabulary.
    - Combine the word-level and character-level sparse matrices into a single feature set.

## Training
- **Objective Function**: The model will be trained to minimize the **categorical cross-entropy loss** (Log Loss), which aligns perfectly with the competition metric.
- **Optimization**: Use an efficient solver for high-dimensional sparse data, such as **L-BFGS** or **SAGA**.
- **Regularization**: Apply **L2 regularization** (Ridge) to constrain the model weights and prevent overfitting given the large feature space (vocabulary size).

## Evaluation
1.  **Inference**: Pass the vectorized test data through the trained Logistic Regression model.
2.  **Probability Estimation**: Use the model's `predict_proba` method to generate a probability distribution over the three classes (EAP, HPL, MWS) for each sample.
3.  **Formatting**: Ensure the output probabilities are formatted according to the submission requirement (ID, EAP, HPL, MWS) and saved to a CSV file.
