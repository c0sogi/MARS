This script demonstrates the end-to-end pipeline for the SETI signal detection task using the provided library files. It covers data loading, model instantiation, training (with a reduced configuration for speed), and inference with Test Time Augmentation (TTA).

Strategy:
1.  **Configuration Override**: We modify the `Config` class attributes at runtime to reduce the number of epochs, batch size, and dataset size. This ensures the demo runs quickly (within seconds/minutes) while exercising all code paths.
2.  **Data Loading**: We utilize `get_loaders(debug=True)` to load a small subset of the training data and verify the shapes of the resulting tensors, ensuring the custom padding and splitting logic works as expected.
3.  **Model Verification**: We instantiate the `SiameseMultiScaleDiffNet`, move it to the appropriate device, and perform a forward pass with a dummy batch to confirm the architecture produces the correct output dimensions.
4.  **Training Loop**: We execute the `fit` function for a single epoch. This validates the optimizer setup, loss calculation (Mixup), backpropagation, and model checkpointing.
5.  **Inference**: We create a small dummy test set and override `Config.TEST_CSV` to demonstrate the inference pipeline. We call `generate_submission` to verify TTA and submission file generation.
