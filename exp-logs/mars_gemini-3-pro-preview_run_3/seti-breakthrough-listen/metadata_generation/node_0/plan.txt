The following script generates the required metadata files for the SETI Breakthrough Listen technosignature detection task.

**Implementation Strategy:**
1.  **Setup & Loading**: The script initializes paths and loads the provided `train_labels.csv` and `sample_submission.csv` from the `./input` directory.
2.  **Path Construction**: It constructs relative file paths for the `.npy` files. Based on the dataset structure, files are organized in subdirectories named after the first character of the `id` (e.g., `train/0/000...npy`).
3.  **Data Splitting**: The training data is split into training and validation sets using an 80:20 ratio with stratification on the `target` variable to maintain class balance. A fixed random state (42) is used for reproducibility.
4.  **Saving Metadata**: The resulting DataFrames are saved as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
5.  **Verification**:
    *   **Statistics**: Summary statistics (count, class balance) are printed for each set.
    *   **File Existence**: The script randomly samples 1000 paths from each generated metadata file and verifies their existence in the `./input` directory. It raises an error if more than 50% are missing.
    *   **Split Validation**: It asserts that the train/val split is disjoint (no data leakage) and that the stratification was successful.
