The following script demonstrates the end-to-end pipeline for the SETI technosignature detection task using the provided library files.

**Strategy:**
1.  **Configuration & Setup**: Initialize the `Config` class and override specific parameters (e.g., `EPOCHS`, `DEBUG` mode, `BATCH_SIZE`) to ensure the demonstration runs quickly on a minimal subset of data.
2.  **Data Loading & verification**: Load the pre-generated metadata, create a small subset, and instantiate the `SETIDataset` and `DataLoader`. We verify the data shapes to ensure the loading and preprocessing (padding, channel reordering) logic functions correctly.
3.  **Model Initialization & Forward Pass**: Instantiate the `SiameseEfficientNetV2` model. Perform a dummy forward pass with a single batch to verify the model architecture, input/output dimensions, and device compatibility.
4.  **Training & Validation Loop**: Use the `train_model` function from the `engine` module to run a single epoch of training and validation. This validates the integration of the loss function, optimizer, scheduler, and mixup augmentation.
5.  **Inference & Submission**: Run the `create_submission` function to generate predictions on a subset of the test data and save the result to the working directory, verifying the output file format.
