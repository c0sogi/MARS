The implementation strategy for the `runfile.py` script is as follows:

1.  **Setup and Configuration**: The script initializes the environment by setting random seeds for reproducibility and loading the configuration from `library.config`. It overrides the default epoch count to 8 to ensure the "fast baseline" requirement is met while utilizing the powerful A100 GPU.
2.  **Data Loading**: It reads the metadata CSV files (`train.csv`, `val.csv`, `test.csv`) generated in the `./metadata` directory. It then initializes the `SETIDataset` and `DataLoader` for training, validation, and testing, utilizing the transformations defined in `library.dataset`.
3.  **Model Training**: The script initializes the `SiameseEfficientNetV2` model, the AdamW optimizer, and the CosineAnnealingLR scheduler. It executes the training loop using the `train_model` function from `library.engine`, which handles the training process, logging, and saving the best model based on validation AUC.
4.  **Validation**: After training, the best model is re-loaded. The script performs a full evaluation on the validation set to compute the `Final Validation Metric` (ROC AUC).
5.  **Failure Analysis**: During the validation pass, the script extracts basic statistical features (mean, std, max intensity for On-Target vs. Off-Target channels) from the validation images. It then calculates the absolute prediction error and computes the correlation between these image statistics and the error magnitude to identify potential failure modes.
6.  **Submission**: The script compares the final validation AUC against the specified threshold (0.7930069652683209). If the model's performance exceeds this threshold, it generates predictions for the test set using Test Time Augmentation (TTA) via `library.engine.create_submission` and saves the results to `./submission/submission.csv`.
