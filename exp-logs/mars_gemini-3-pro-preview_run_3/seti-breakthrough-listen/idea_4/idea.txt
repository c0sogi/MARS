Based on the comprehensive analysis of the "Lessons" and "Previous Ideas," I propose a **Siamese Two-Stream Convolutional Neural Network**. This architecture explicitly addresses the failure of standard 2D CNNs to learn the "On-Off" comparison logic while avoiding the pitfalls of rigid pixel-wise subtraction and 3D convolutions.

### Model
**Architecture: Siamese EfficientNet-B0 with Feature-Space Difference**
I propose a Siamese network architecture that processes the "On-Target" and "Off-Target" observations in two parallel streams sharing the same weights.

*   **Backbone:** We will use **EfficientNet-B0** initialized with **ImageNet weights**.
    *   **Input Streams:** Unlike previous iterations that stacked all 6 frames into a single 6-channel input (which required modifying the first layer and failed to learn the comparison logic, Cite `solution_lesson_node_00001`), we will split the input into two distinct 3-channel tensors:
        *   **Stream A (Signal):** Stacks the 3 "On-Target" frames (Index 0, 2, 4) as channels.
        *   **Stream B (Reference):** Stacks the 3 "Off-Target" frames (Index 1, 3, 5) as channels.
    *   **Justification:** This 3-channel structure perfectly matches the standard input of pretrained ImageNet models, allowing us to leverage robust, unmodified pretrained weights (Cite `solution_lesson_node_00011`). It preserves the "Channel Stacking" alignment for the drifting signal within the "On" set (Cite `solution_lesson_node_00003`).

*   **Feature Extraction:** Both streams pass their respective inputs through the shared EfficientNet backbone.
    *   $F_{on} = \text{Backbone}(Input_A)$
    *   $F_{off} = \text{Backbone}(Input_B)$
    *   Global Average Pooling is applied to obtain feature vectors $v_{on}$ and $v_{off}$.

*   **Interaction & Classification Head:**
    *   Instead of relying on the network to implicitly learn subtraction from a concatenated input, we explicitly engineer the comparison in the high-level feature space.
    *   **Fusion Vector:** We concatenate the On-target features, the Off-target features, and their element-wise difference: $V_{final} = \text{Concat}(v_{on}, v_{off}, v_{on} - v_{off})$.
    *   **Reasoning:** This allows the classifier to detect "Needles" (high activation in $v_{on}$, low in $v_{off}$) while rejecting RFI (high activation in both, resulting in near-zero difference). This avoids the artifacts of pixel-wise subtraction (Cite `solution_lesson_node_00002`) while enforcing the comparison logic that 2D CNNs missed.

### Data
**Preprocessing & Augmentation**
*   **Splitting & Stacking:** For each cadence ID, load the `.npy` file. Separate the 6 panels into two groups: `On` (indices 0, 2, 4) and `Off` (indices 1, 3, 5). Stack these to form two `(3, 273, 256)` arrays.
*   **Resizing:** Resize both arrays to `(224, 224)`. As established, moderate downsampling acts as a beneficial low-pass filter for these low-SNR signals and enables the use of standard backbones (Cite `solution_lesson_node_00006`, `solution_lesson_node_00004`).
*   **Normalization:** Normalize the arrays to standard ImageNet statistics (mean/std) to align with the pretrained weights.
*   **Augmentation:** Apply **Mixup** ($\alpha=0.2$) during training. This is critical for preventing the model from memorizing noise patterns in the "haystack" and smoothing the decision boundary.

### Training
*   **Loss Function:** `BCEWithLogitsLoss` (Binary Cross Entropy).
*   **Optimizer:** `AdamW` with a learning rate of `1e-3` and weight decay `1e-2`.
*   **Scheduler:** `CosineAnnealingLR` (T_max=10 epochs) to facilitate convergence from the pretrained initialization.
*   **Strategy:** Train for 10-12 epochs. The use of unmodified pretrained weights should result in stable and faster convergence compared to the custom 6-channel attempts.

### Evaluation
*   **Inference:** Iterate through the test set metadata. For each sample, generate the `On` and `Off` stacks, pass them through the Siamese network, and apply a Sigmoid activation to the output.
*   **TTA:** Perform Test Time Augmentation by horizontally flipping both `On` and `Off` inputs (frequency reversal). Average the predictions with the original pass to improve robustness.
