### Implementation Strategy

1.  **Environment Setup**: Import necessary modules (`torch`, `pandas`, `os`) and the provided library components (`Config`, `engine`, `model`, `dataset`, `utils`). Set a fixed random seed for reproducibility.
2.  **Configuration Override**: To ensure the demonstration runs quickly, create a small subset of the test metadata (50 samples) and monkey-patch `Config.TEST_METADATA` to point to this subset. This prevents the inference step from processing the full 6,000-sample test set.
3.  **Component Verification**:
    *   **Data Loaders**: Use `get_train_val_loaders(debug=True)` to load a small subset of training data. Fetch one batch to verify that the input tensors (`on_target`, `off_target`) have the expected shape `(B, 3, 288, 256)` and targets have shape `(B,)`.
    *   **Model**: Instantiate `SiameseDifferenceNet`. Pass the verified batch through the model to confirm the forward pass works and outputs logits of shape `(B, 1)`.
    *   **Utilities**: Create dummy tensors to test `mixup_data`, asserting that the output shapes remain consistent and the mixing coefficient `lam` is within bounds.
4.  **Pipeline Execution**:
    *   **Training**: Execute `engine.run_training` with `debug=True`, `epochs=2`, and `patience=1`. This tests the full training loop, loss calculation, backpropagation, and model checkpointing without consuming excessive time. Assert that the model checkpoint file is created.
    *   **Inference**: Execute `engine.predict` using the newly trained model and the overridden test metadata. Assert that the submission file is created and matches the expected dimensions of the mini-test set.
