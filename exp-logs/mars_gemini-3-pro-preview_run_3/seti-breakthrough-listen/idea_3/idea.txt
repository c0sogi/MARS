Based on the analysis of the previous failures and the specific lessons learned, I propose a **Shallow 3D Convolutional Neural Network (3D CNN)**. This represents a structural shift from 2D spatial aggregation to spatiotemporal volumetric processing, explicitly designing the model to capture the "ON-OFF" cadence logic that previous 2D architectures failed to learn.

### Model
**Architecture:** Custom Lightweight 3D CNN
I propose a 3D CNN that treats the cadence snippets as volumetric data of shape `(1, 6, H, W)` (Channels, Depth, Height, Width), where the depth dimension corresponds to the 6 cadence observations (ABACAD).
*   **Volumetric Input:** Unlike the previous 2D approaches that stacked observations as channels (summing them in the first layer), a 3D CNN maintains the temporal/cadence dimension. This allows the network to apply 3D kernels (e.g., $3 \times 3 \times 3$) that slide across the cadence axis.
*   **Comparison Logic:** A kernel of depth 3 covering indices $[t, t+1, t+2]$ can effectively learn the specific "High-Low-High" contrast pattern of the technosignatures (e.g., A-B-A) while simultaneously tracking the spatial drift of the signal via the spatial dimensions of the kernel. This directly addresses the failure of standard 2D CNNs to implicitly learn set comparisons (Cite `solution_lesson_node_00001`).
*   **Structure:** The network will consist of 4 blocks. Each block will contain a `Conv3d` layer, `BatchNorm3d`, `ReLU`, and `MaxPool3d`.
    *   **Pooling Strategy:** We will use asymmetric pooling. Early layers will pool only spatial dimensions `(1, 2, 2)` to preserve the short cadence depth (6) for as long as possible, allowing deep layers to capture the full temporal context.
*   **Head:** Global Average Pooling (3D) followed by a single Linear layer.

### Data
**Preprocessing:**
*   **Input Representation:** Load the 6 cadence observations. Instead of stacking them as a 6-channel 2D image, we add a channel dimension to create a 5D tensor for the batch: `(Batch, 1, 6, 273, 256)`. This preserves the alignment of pixels across the cadence, which is superior to spatial stacking (Cite `solution_lesson_node_00003`).
*   **Resizing:** Resize the spatial dimensions from `(273, 256)` to `(256, 256)`. While earlier lessons warned against resizing, the most recent empirical findings suggest that moderate downsampling acts as a beneficial low-pass filter, improving the effective SNR for these faint signals (Cite `solution_lesson_node_00006`).
*   **No Subtraction:** We will strictly feed the raw intensity data. We will not perform manual `A - B` subtraction, allowing the 3D kernels to learn non-linear comparisons that account for Doppler drift (Cite `solution_lesson_node_00002`).

### Training
*   **Loss Function:** `BCEWithLogitsLoss`.
*   **Optimizer:** `AdamW` with a learning rate of `1e-3` and weight decay `1e-2`.
*   **Scheduler:** `CosineAnnealingLR` for smooth decay.
*   **Augmentation:** We will apply **Mixup** ($\alpha=0.2$). Since the dataset is small and noisy, Mixup helps the model learn a linear transition between signal and noise, preventing it from memorizing specific noise artifacts in the "haystack".

### Evaluation
*   **Inference:** The model will predict probabilities for the test set using the same 3D pipeline.
*   **TTA:** We will perform Test Time Augmentation by horizontally flipping the spatial dimensions of the volume (frequency reversal) and averaging the predictions. This exploits the symmetry of the signals (diagonal lines) without altering the temporal cadence logic.
