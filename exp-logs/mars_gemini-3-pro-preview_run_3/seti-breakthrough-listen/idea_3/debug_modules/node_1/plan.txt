The `RuntimeError` indicates that the output directory (`./working/idea_3`) does not exist when the model attempts to save a checkpoint. This happens because `Config.setup()`, which creates the required directories, is not called in `runfile.py`. I will add this call to `runfile.py`.

Additionally, because `runfile.py` runs in debug mode with a subset of the data, the submission generation logic in `library/engine.py` (and `library/model.py`) will fail. The original code reads the full test metadata from disk, which will have a different length than the predictions generated from the subsetted `test_loader`. To fix this, I will modify the code to retrieve the DataFrame directly from `test_loader.dataset.df`, ensuring the IDs match the predictions (Cite debug_lesson_2).
