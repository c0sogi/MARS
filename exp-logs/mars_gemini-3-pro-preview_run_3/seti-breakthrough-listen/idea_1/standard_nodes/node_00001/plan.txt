This script orchestrates the SETI signal detection pipeline. It first trains a custom shallow CNN using the provided engine, limiting training to 5 epochs for a fast baseline. It then reloads the best-performing model to evaluate it on the validation set, calculating the Area Under the ROC Curve (AUC). Simultaneously, it performs failure analysis by extracting signal intensity statistics (mean and max of on-target vs. off-target panels) and correlating them with the model's prediction errors. Finally, it generates the submission file for the test set.
