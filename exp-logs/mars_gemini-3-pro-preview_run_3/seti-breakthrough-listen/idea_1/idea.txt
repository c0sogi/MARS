To establish a robust and efficient baseline for identifying technosignatures, I propose a **Custom Shallow Multi-Channel CNN**. This approach prioritizes low latency and architectural simplicity, avoiding the complexity of heavy backbones like EfficientNet or Transformers while effectively leveraging the multi-cadence structure of the data.

### Model
The architecture is a lightweight, custom 2D Convolutional Neural Network designed to process the 6-channel input directly.
*   **Input Layer:** Accepts tensors of shape `(6, 273, 256)`, treating the 6 cadence positions (ABACAD) as depth channels. This allows the network to learn spatial features (like diagonal Doppler drifts) while simultaneously capturing the contrast between "On-target" (channels 0, 2, 4) and "Off-target" (channels 1, 3, 5) panels via the channel dimension.
*   **Feature Extractor:** Consists of a stack of 4 Convolutional Blocks. Each block comprises:
    *   A `Conv2d` layer with a 3x3 kernel and padding to preserve spatial resolution initially.
    *   `BatchNorm2d` for training stability.
    *   `ReLU` activation.
    *   `MaxPool2d` (2x2) to progressively downsample the spatial dimensions.
    *   Filter counts will increase progressively (e.g., 32 $\rightarrow$ 64 $\rightarrow$ 128 $\rightarrow$ 256).
*   **Classifier Head:** A Global Average Pooling layer collapses the spatial feature maps into a single feature vector. This is followed by a `Dropout` layer (e.g., p=0.5) for regularization and a single `Linear` layer to output the logit for the binary target.

### Data
*   **Loading:** Data will be loaded directly from the `.npy` files using the paths generated in the metadata.
*   **Preprocessing:** The analysis indicates the data is already globally standardized (mean $\approx$ 0, std $\approx$ 1). Therefore, no additional normalization or resizing is required. The arrays will be cast to `float32` tensors.
*   **Augmentation:** To strictly adhere to the "baseline" philosophy and maximize training speed, no data augmentation (e.g., flips, time-shifts) will be applied. The model will learn solely from the raw, static spectral data.
*   **Splitting:** The provided stratified validation split (from `metadata/val.csv`) will be used to monitor performance.

### Training
*   **Loss Function:** `BCEWithLogitsLoss` (Binary Cross Entropy) will be used to optimize the binary classification task.
*   **Optimizer:** The Adam optimizer will be utilized with a standard initial learning rate (e.g., 1e-3) and weight decay (e.g., 1e-4) to prevent overfitting.
*   **Scheduler:** A `ReduceLROnPlateau` scheduler will monitor the validation ROC AUC, reducing the learning rate by a factor of 0.1 if performance plateaus for a set number of epochs.
*   **Strategy:** Training will run for a maximum of 15 epochs with Early Stopping enabled (patience of 3 epochs) to prevent wasted computation once convergence is reached.

### Evaluation
*   **Inference:** The model will iterate through the test set loader. For each sample, it will compute the forward pass and apply a Sigmoid activation to the output logit to obtain a probability score $[0, 1]$.
*   **Submission:** The resulting probabilities will be paired with their corresponding `id`s and written to a CSV file matching the submission format.
