Based on the comprehensive analysis of the "Lessons" and the trajectory of previous experiments, I propose the **Siamese EfficientNet-B0 with Difference-Gated Feature Aggregation**.

This solution structurally evolves the successful "Siamese Difference" architecture (Idea 8) by introducing a **Difference-Gating Mechanism**. While Idea 8 proved that explicit differencing ($F_{on} - F_{off}$) and hybrid pooling (GAP+GMP) are critical, it treated the difference map merely as an additional feature set. The proposed evolution uses the difference map to actively **filter** the source signal, suppressing features that are not differentially significant (i.e., RFI) *before* pooling. This enforces a stricter "Signal > Noise" condition directly in the feature space. Additionally, it strictly implements the data pipeline corrections identified in the most recent lessons regarding padding consistency and feature extraction depth.

### Model
**Architecture: Siamese EfficientNet-B0 with Difference-Gated Aggregation**

1.  **Backbone:** We will use **EfficientNet-B0** initialized with ImageNet weights. We strictly retain this Batch Normalization-based backbone and avoid upgrading to LayerNorm-based models (like ConvNeXt or EfficientNet-V2), which have proven fragile on this raw spectral data (Cite `solution_lesson_node_00030`, `solution_lesson_node_00033`).
    *   **Dual Inputs:** The model processes two streams via shared weights:
        *   **Stream A (Signal):** "On-Target" frames (Indices 0, 2, 4) stacked depth-wise (Cite `solution_lesson_node_00003`).
        *   **Stream B (Reference):** "Off-Target" frames (Indices 1, 3, 5) stacked depth-wise.
    *   **Feature Extraction:** We will extract features using `features_only=True` from the **final convolutional block** (Stride 32, 320 channels), explicitly avoiding the final projection layer (1280 channels). This lower-dimensional representation reduces overfitting and improves generalization (Cite `solution_lesson_node_00035`, `solution_lesson_node_00026`).

2.  **Difference-Gated Interaction Module (Structural Innovation):**
    *   **Explicit Difference:** Compute $F_{diff} = F_{on} - F_{off}$ (Cite `solution_lesson_node_00019`).
    *   **Attentional Gating:** Instead of only pooling $F_{diff}$, we use it to create a soft attention mask: $G = \sigma(F_{diff})$ (Sigmoid activation).
    *   **Feature Filtering:** We compute a gated signal representation: $F_{gated} = F_{on} \odot G$ (Element-wise multiplication).
    *   **Rationale:** This operation suppresses features in the "On" stream that do not have a corresponding positive activation in the difference map (i.e., where Signal $\le$ Noise), effectively cleaning the signal representation before pooling.

3.  **Expanded Hybrid Pooling Head:**
    *   We apply **Global Average Pooling (GAP)** and **Global Max Pooling (GMP)** to four distinct feature maps:
        1.  $F_{on}$ (Raw Signal Context)
        2.  $F_{off}$ (Raw Noise Context)
        3.  $F_{diff}$ (Explicit Difference)
        4.  $F_{gated}$ (Filtered Signal - **New**)
    *   This results in a concatenated vector of $8 \times 320$ features. This explicitly preserves the "Source-Stream Max Pooling" required for detecting sparse anomalies (Cite `solution_lesson_node_00027`) and avoids the pitfalls of learnable pooling (Cite `solution_lesson_node_00034`).

4.  **Classifier:**
    *   A **Single Linear Layer** maps the concatenated vector to the output logit (Cite `solution_lesson_node_00021`).

### Data
**Preprocessing & Augmentation**
1.  **Full Dataset:** Train on the entire training set (~43,000 samples) to maximize RFI coverage (Cite `solution_lesson_node_00024`).
2.  **Native Resolution:** We will use the native input resolution of `(273, 256)`. We will **not resize**, preserving fine-grained spectral details (Cite `solution_lesson_node_00004`).
3.  **Post-Augmentation Padding:** We will **pad** the arrays to `(288, 256)` (nearest multiple of 32) **strictly after** applying geometric augmentations. This ensures the zero-padding artifact remains spatially consistent (at the bottom/right) and does not jump around due to flipping, preventing the model from wasting capacity on artifact invariance (Cite `solution_lesson_node_00036`).
4.  **No Normalization:** Feed the raw, standardized data directly. Do **not** apply ImageNet normalization (Cite `solution_lesson_node_00031`).
5.  **Synchronized Augmentation:**
    *   Apply **Horizontal Flip** (Time Reversal) and **Vertical Flip** (Frequency Inversion) (Cite `solution_lesson_node_00014`).
    *   Apply identical transforms to both Stream A and Stream B to maintain pixel-wise correspondence (Cite `solution_lesson_node_00015`).

### Training
*   **Loss Function:** `BCEWithLogitsLoss`.
*   **Optimizer:** `AdamW` with learning rate `1e-3` and weight decay `1e-2`.
*   **Regularization:** **Mixup** ($\alpha=0.2$) applied to the inputs (Cite `solution_lesson_node_00011`).
*   **Scheduler:** `CosineAnnealingLR` with `T_max=15` epochs.
*   **Strategy:** Train for 15 epochs.

### Evaluation
*   **Inference:** Process the test set using the "Pad-After" logic.
*   **Test Time Augmentation (TTA):** Perform inference on 4 variations: Original, Horizontal Flip, Vertical Flip, and Horizontal+Vertical Flip. Crucially, ensure the padding is applied/removed consistently for each view. Average the predictions (Cite `solution_lesson_node_00014`).
