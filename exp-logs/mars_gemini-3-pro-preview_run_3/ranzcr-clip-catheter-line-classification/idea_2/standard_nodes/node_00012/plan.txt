The `torch.OutOfMemoryError` occurred because the combination of a 640x640 image resolution and the memory-intensive U-Net decoder exceeded the 16GB VRAM capacity of the GPU. As explained in **Cite debug_lesson_1**, memory usage for activation maps scales quadratically with image resolution. To resolve this, I will reduce the `IMG_SIZE` in `library/config.py` from 640 to 512, which significantly lowers the memory footprint and allows the training to proceed within the hardware constraints.
