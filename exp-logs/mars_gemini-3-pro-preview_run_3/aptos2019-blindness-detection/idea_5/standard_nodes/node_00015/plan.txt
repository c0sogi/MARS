This script implements the orchestration for the Batch-Independent High-Resolution ConvNeXt Regression strategy.

**Implementation Strategy:**
1.  **Setup & Configuration**: Initializes the environment with fixed seeds for reproducibility and detects the A100 GPU. Defines hyperparameters suitable for high-resolution training (Batch Size 4, Accumulation Steps 8 to simulate Batch Size 32, Image Size 768).
2.  **Data Preparation**: Calls `library.dataset.prepare_datasets` to load and preprocess the data. This handles caching automatically in `./working/idea_5`.
3.  **Model Initialization**: Instantiates the `convnext_base` model via `library.model.get_model`. This model uses Layer Normalization, making it robust to the small physical batch size required by 768x768 inputs.
4.  **Training**: Executes the training loop using `library.engine.train_loop`. It uses Mean Squared Error loss and gradient accumulation. The best model based on Validation Kappa is saved.
5.  **Evaluation & Failure Analysis**:
    *   Reloads the best model weights.
    *   Computes the final Quadratic Weighted Kappa on the validation set.
    *   Performs failure analysis by extracting meta-features (width, height, intensity) from validation images and calculating their Spearman correlation with the model's prediction error. This identifies if specific image characteristics drive performance drops.
6.  **Submission**: Checks if the validation metric exceeds the threshold (0.9147...). If so, generates predictions for the test set using `library.engine.generate_submission`.
