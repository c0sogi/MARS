This script demonstrates the end-to-end usage of the provided library files for the Diabetic Retinopathy classification task. It performs the following steps:

1.  **Setup & Configuration**: Sets random seeds and defines paths. It creates a temporary "mini-metadata" set by sampling a small fraction of the original metadata. This ensures the demonstration runs quickly (processing ~30 images instead of thousands).
2.  **Data Preparation (`library.data`)**: Uses `get_datasets` to load images based on the mini-metadata. It verifies that the caching mechanism works by checking for generated `.npy` files.
3.  **Model Initialization (`library.model`)**: Instantiates the `DRModel` using a lightweight backbone (`resnet18`) for speed. It verifies the model architecture by passing a dummy tensor and checking the output shape.
4.  **Training (`library.engine`)**: Runs the `train_model` function for a single epoch on the subset. It validates that the training loop completes and produces a saved model file.
5.  **Inference (`library.engine`)**: Uses `predict_and_submit` to generate predictions on the test subset. It asserts that the submission file is created and has the correct format.
6.  **Metric Verification (`library.utils`)**: Manually verifies the `quadratic_weighted_kappa` function with known inputs to ensure metric calculation correctness.
