The following script performs a comprehensive Exploratory Data Analysis (EDA) on the Diabetic Retinopathy training dataset. It adheres to the constraints by using the pre-generated metadata, operating strictly on the training set to prevent leakage, and employing memory-efficient techniques to calculate global pixel statistics across the image dataset.

**Implementation Strategy:**
1.  **Setup & Integrity**: Fix random seeds for reproducibility. Load the `./metadata/train.csv` file to ensure we only analyze the training split defined in the previous step.
2.  **Target Analysis**: Analyze the `diagnosis` column to report class distributions and identify potential imbalances in the 5-point severity scale.
3.  **Image Data Analysis**:
    *   Iterate through the training images using the file paths provided in the metadata.
    *   Extract physical properties: Width, Height, and Aspect Ratio.
    *   Compute global pixel statistics (Mean and Std Dev) for RGB channels using an online algorithm (running sums) to avoid loading the entire dataset into RAM.
    *   Verify channel consistency (e.g., ensure all are 3-channel RGB).
4.  **Feature Relationships**:
    *   Construct a meta-feature dataframe containing image properties and the target variable.
    *   Analyze correlations between metadata (e.g., image size, aspect ratio, brightness) and the severity of the diagnosis to identify potential biases or signals (e.g., "Are higher resolution images easier to diagnose?").
5.  **Reporting**: Output the results in the specified format with distinct capitalized sections and 4-decimal precision.
