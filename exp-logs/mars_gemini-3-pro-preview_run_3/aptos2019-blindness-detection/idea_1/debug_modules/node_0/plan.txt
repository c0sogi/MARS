This script demonstrates the end-to-end workflow for the Diabetic Retinopathy severity prediction task using the provided library modules. It covers data loading, model instantiation, training, evaluation, and submission generation. To ensure quick execution within the demonstration context, it utilizes the `debug` mode to load a small subset of the data and trains for a single epoch. It also includes verification steps for the custom metric (Quadratic Weighted Kappa) and data integrity.
