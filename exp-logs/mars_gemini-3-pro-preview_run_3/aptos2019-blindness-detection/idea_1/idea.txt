To establish a highly efficient and reliable baseline for diabetic retinopathy severity prediction, I propose a **ResNet18 Regression** approach. This solution prioritizes computational speed and architectural simplicity, distinguishing itself from the heavier EfficientNet-B3, complex Transformer-based models, and hybrid ensemble methods listed in the provided architectures.

### Model
The core of the solution is the **ResNet18** architecture, a standard and lightweight Convolutional Neural Network (CNN).
*   **Backbone**: Unlike the EfficientNet-B3 (Model 1) which relies on complex Mobile Inverted Bottleneck and Squeeze-and-Excitation blocks, ResNet18 utilizes simple residual blocks with standard convolutions. This results in significantly fewer parameters and faster inference times.
*   **Head**: The standard 1000-class classification head is replaced with a **single neuron** with a linear activation function. This setup treats the task as a regression problem rather than a classification one, directly outputting a continuous severity score.
*   **Initialization**: The backbone will be initialized with pre-trained ImageNet weights to leverage learned feature representations, accelerating convergence on the smaller diabetic retinopathy dataset.

### Data
Preprocessing is kept minimal to maximize throughput and minimize CPU overhead:
*   **Resizing**: All input images are resized directly to **224 x 224** pixels. This resolution is standard for ResNet architectures and significantly reduces the computational load compared to processing high-resolution fundus images.
*   **Normalization**: Pixel values are normalized using the standard ImageNet mean and standard deviation to ensure consistent input distributions.
*   **Augmentation**: To prevent overfitting while maintaining training speed, only **Random Horizontal Flips** are applied. This is medically valid as the laterality (left/right eye) does not determine disease severity.

### Training
The training procedure focuses on optimizing the metric-aligned objective function:
*   **Loss Function**: The model is trained using **Mean Squared Error (MSE) Loss**. Since the target labels (0, 1, 2, 3, 4) represent an ordinal scale of severity, MSE naturally penalizes predictions that are far from the true severity (e.g., predicting 0 for a label of 4 is penalized much more than predicting 3). This aligns well with the Quadratic Weighted Kappa metric.
*   **Optimizer**: The **Adam** optimizer is used for its robust convergence properties with default parameters, avoiding the need for extensive hyperparameter tuning.
*   **Label Handling**: The integer class labels are cast to floating-point values to facilitate regression training.

### Evaluation
Inference and scoring follow a deterministic post-processing step:
*   **Prediction**: The model outputs a continuous scalar value for each test image.
*   **Post-processing**: These continuous predictions are first **clipped** to the range [0, 4] to handle potential outliers. Then, they are **rounded** to the nearest integer to produce the final discrete diagnosis class (0, 1, 2, 3, or 4).
*   **Metric**: These rounded integers are used to compute the Quadratic Weighted Kappa score against the ground truth.
