The script below performs the following steps:
1.  **Setup**: Creates the `./metadata` directory if it doesn't exist.
2.  **Data Loading**: Reads `train.csv` and `test.csv` from the `./input` directory.
3.  **Path Generation**: Adds a `file_path` column to the dataframes containing the relative path to the image files (e.g., `train_images/{id_code}.png`).
4.  **Splitting**: Splits the training data into training (80%) and validation (20%) sets using stratified sampling based on the `diagnosis` label to ensure class distribution is preserved.
5.  **Saving**: Saves the resulting dataframes as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
6.  **Verification**:
    -   Loads the generated metadata files.
    -   Prints summary statistics (counts, class distributions).
    -   Verifies that the stratification was successful by comparing class proportions.
    -   Checks a random sample of 1000 file paths from each dataset to ensure they resolve to existing files in `./input`, raising an error if the missing file ratio exceeds 50%.
