The error arises because the `verbose` parameter was deprecated and removed from the `ReduceLROnPlateau` scheduler in recent PyTorch versions (including the installed version 2.8.0), causing a `TypeError` during initialization. To fix this, I will remove the `verbose=False` argument from the `ReduceLROnPlateau` constructor in both `library/train.py` and `library/model.py`.
