The following implementation demonstrates how to utilize the provided Diabetic Retinopathy classification library. It executes a complete pipeline including data processing, model verification, training (on a subset for speed), and inference.

### Implementation Strategy
1.  **Setup & Verification**: Initialize the random seed and verify the `quadratic_weighted_kappa` metric logic.
2.  **Data Processing**: Invoke `get_dataloaders` to process images (crop/resize) and cache them. This step verifies the data pipeline and prepares `.npy` cache files for subsequent steps. We assert correct tensor shapes.
3.  **Model Verification**: Instantiate the `RetinopathyModel` and perform a forward pass with a dummy batch to confirm the architecture outputs the expected regression shape.
4.  **Training Integration**: Execute the `train` function with `debug_subset_size` and reduced epochs. This tests the training loop, loss calculation, backpropagation, and checkpoint saving without consuming excessive time.
5.  **Inference Integration**: Execute `inference_fn` using the model checkpoint generated in the previous step to produce a submission file, verifying the prediction pipeline.
