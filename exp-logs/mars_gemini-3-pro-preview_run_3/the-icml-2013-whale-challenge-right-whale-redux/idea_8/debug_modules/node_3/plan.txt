The `RuntimeError: Unknown model (convnext_tiny)` indicates that the model identifier `"convnext_tiny"` is not registered in the installed version of the `timm` library (1.0.20). Newer versions of `timm` often require a specific "tag" suffix in the model name to distinguish between different pre-training sources and configurations (e.g., weights from Facebook vs. other sources).

To fix this, I will update the `BACKBONE` parameter in `library/config.py` to use the fully qualified identifier `convnext_tiny.fb_in1k`. This explicitly selects the ConvNeXt-Tiny model with the original ImageNet-1k weights from Facebook, which is a standard valid identifier in the `timm` registry. Cite debug_lesson_1.
