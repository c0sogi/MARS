Based on the progression of empirical findings and the lessons learned, I propose the following optimized strategy. This approach structurally evolves the solution from a standard supervised learning paradigm to a **Multi-Stage Self-Training (Noisy Student)** pipeline. This strategy leverages the large unlabeled test set to overcome the data scarcity of the minority class, while retaining the highly optimized single-stream architecture and signal processing configurations identified as superior in previous lessons.

# Model

**Backbone: EfficientNetV2-Medium**
I will utilize the **EfficientNetV2-Medium** architecture.
*   **Rationale:** Previous lessons demonstrated that established CNN backbones significantly outperform Transformer-based architectures (like ConvNeXt) for spectrogram analysis (Cite solution_lesson_node_00016). The "Medium" variant provides the necessary depth and capacity to model complex spectral textures without the overfitting risks or computational overhead of larger models, as validated by the best-performing solution to date (Cite solution_lesson_node_00019).

**Head: Generalized Mean (GeM) Pooling**
I will retain **Generalized Mean (GeM) Pooling** to aggregate feature maps.
*   **Rationale:** Whale calls are transient events localized in time and frequency. GeM pooling allows the model to dynamically learn to focus on high-activation regions (the call) while suppressing the dominant background noise, a critical mechanism for this weakly supervised task that outperforms Global Average Pooling (Cite solution_lesson_node_00009).

# Data

**Input Representation: High-Fidelity Log-Mel Spectrograms**
I will generate a single, high-resolution Log-Mel Spectrogram for each clip, strictly adhering to the signal processing parameters found to resolve the resolution trade-off (Cite solution_lesson_node_00019).
*   **Frequency Resolution:** Use **384 Mel bands**. This high vertical resolution matches the capacity of the EfficientNetV2 backbone (Compound Scaling) (Cite solution_lesson_node_00010) and prevents the loss of fine-grained spectral texture observed with fewer bands (Cite solution_lesson_node_00017).
*   **Temporal/Spectral Fidelity:** Use a **large FFT window (e.g., N_FFT=1024)** to maximize frequency resolution, paired with a **high overlap/short hop length (approx. 10ms)** to simultaneously preserve rapid temporal dynamics. This renders multi-stream architectures redundant (Cite solution_lesson_node_00019).
*   **Normalization:** Apply **Instance-level Min-Max Normalization** to preserve the spectral contrast between the call and the background noise, avoiding the signal degradation caused by frequency-wise standardization (Cite solution_lesson_node_00015).

# Training

**Strategy: Multi-Stage Noisy Student Self-Training**
Instead of a single supervised training run, I will implement a multi-stage pipeline to leverage the unlabeled test data.
1.  **Teacher Training:** Train an initial EfficientNetV2-Medium on the labeled training set using the optimized hyperparameters defined below.
2.  **Pseudo-Labeling:** Use the converged Teacher model to generate soft probability predictions for the entire unlabeled `test2` dataset.
3.  **Student Training:** Train a fresh EfficientNetV2-Medium instance (the Student) on a combined dataset of the original labeled data and the pseudo-labeled test data.
    *   **Rationale:** This effectively expands the training set size and diversity, allowing the model to learn decision boundaries that generalize better to the test distribution.

**Loss Function: Binary Cross-Entropy with Inverse Class Frequency Weighting**
I will use **BCE Loss weighted by the inverse class frequency**. This remains the most robust method for handling the ~9:1 class imbalance (Cite solution_lesson_node_00001).

**Regularization & Augmentation**
*   **Mixup with Mixed Losses:** I will apply Mixup augmentation to the Student model. Crucially, I will compute the loss by mixing the **weighted scalar losses** of the input pair rather than mixing the labels or weights, ensuring minority class gradients are preserved (Cite solution_lesson_node_00005).
*   **SpecAugment:** I will apply random time and frequency masking to force the model to learn robust partial features (Cite solution_lesson_node_00003).

**Optimization**
*   **Optimizer:** Use **AdamW** combined with a **Cosine Annealing Learning Rate Scheduler** to ensure stable convergence (Cite solution_lesson_node_00003).

# Evaluation

**Inference Strategy**
*   **Checkpoint Reloading:** The training pipeline will explicitly monitor Validation AUC and save the model state with the highest score. Before generating the final submission (or pseudo-labels), the system will **reload these best-saved weights**, discarding the state from the final training epoch (Cite solution_lesson_node_00008).
