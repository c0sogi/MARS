The following script demonstrates the end-to-end usage of the provided library files for the Right Whale Detection task. It covers configuration, data processing, model initialization, training, inference, and the student-teacher pseudo-labeling workflow.

### Implementation Strategy
1.  **Configuration Override**: We modify `TrainConfig` and `PathConfig` to use a temporary working directory and limit the dataset size (20 samples) and training duration (1 epoch) for rapid execution.
2.  **Data Verification**: We explicitly test the `compute_spectrogram` function on a real audio file to ensure signal processing works as expected.
3.  **Pipeline Execution**:
    *   **Teacher Phase**: We initialize DataLoaders and the `WhaleEfficientNet` model, then run the `Trainer` to train on labeled data.
    *   **Inference**: We generate predictions on the test set (debug subset) and verify the submission file format.
    *   **Student Phase**: We feed the generated predictions back into the DataLoader as pseudo-labels to demonstrate the semi-supervised learning capability.
4.  **Assertions**: Critical steps include assertions to verify tensor shapes, file existence, and data types.
