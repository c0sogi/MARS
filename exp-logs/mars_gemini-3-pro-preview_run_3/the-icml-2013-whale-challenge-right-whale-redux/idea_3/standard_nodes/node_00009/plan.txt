To implement the Right Whale Detection task, I will orchestrate the training and evaluation pipeline using the provided library modules.

### Implementation Strategy

1.  **Configuration Setup**: I will override specific hyperparameters in `library.config.Config` to ensure the solution runs efficiently as a "fast baseline" while maintaining high performance. Specifically, I will set `EPOCHS` to 15 and `T_MAX` to 15 to match, and utilize 8 workers for data loading. This ensures the training completes well within the 2-hour limit on the A100 GPU.
2.  **Training**: I will instantiate the `Trainer` class from `library.trainer`. This handles the initialization of the **EfficientNet-B0** model with **GeM Pooling**, the loading of cached spectrogram data (or computing it if missing), and the training loop with **Mixup** augmentation and **BCE loss**.
3.  **Validation & Failure Analysis**: After training, I will implement a custom `run_validation_and_analysis` function. This function will:
    *   Reload the best model weights saved during training.
    *   Perform inference on the full validation set to calculate predictions.
    *   Compute the **Final Validation Metric (AUC)**.
    *   Perform failure analysis by extracting raw spectrogram features (Mean Intensity and Standard Deviation) from the underlying dataset and calculating their Pearson correlation with the model's error magnitude. This identifies if the model struggles with specific signal characteristics like low volume or low contrast.
4.  **Submission**: I will compare the calculated validation AUC against the strict threshold of `0.9913801393656689`. If the model's performance exceeds this threshold, I will trigger the `trainer.predict()` method to generate the `submission.csv` file for the test set.
