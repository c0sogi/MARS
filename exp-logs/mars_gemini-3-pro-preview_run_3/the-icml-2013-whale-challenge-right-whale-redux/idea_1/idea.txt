To establish a highly efficient baseline that balances speed, simplicity, and accuracy, I propose a **Shallow 2D Convolutional Neural Network (CNN)** trained from scratch on Log-Mel Spectrograms. This approach differs from Model 1 by avoiding heavy, pre-trained backbones like EfficientNet, differs from Model 2 by operating in the time-frequency domain rather than the time domain, and differs from Model 4 by removing recurrent layers (GRU) to rely solely on spatial feature extraction.

# Model
The architecture is a lightweight, custom 2D CNN designed to treat audio spectrograms as small, single-channel images.
*   **Backbone:** The network consists of a stack of 3 convolutional blocks. Each block comprises a 2D Convolution layer (kernel size 3x3), followed by Batch Normalization to stabilize learning, a ReLU activation function, and a 2D Max Pooling layer to reduce spatial dimensions.
*   **Head:** The convolutional stack feeds into a Global Average Pooling layer, which aggregates the feature maps into a single vector. This is followed immediately by a single dense output neuron with a Sigmoid activation function to produce the probability score.
*   **Design Philosophy:** By removing fully connected hidden layers and recurrent units, this model minimizes parameter count and inference time, relying on the CNN's receptive field to detect the specific time-frequency texture of whale calls.

# Data
*   **Spectrogram Generation:** Convert the raw .aif waveforms (2000 Hz sample rate) into Mel-spectrograms. Given the low-frequency nature of right whale calls (50-250 Hz), use a window size of approximately 100-128ms (e.g., n_fft=256) and a hop length of 50% to capture sufficient frequency resolution.
*   **Log Scaling:** Apply a logarithmic operation to the Mel-spectrogram power to compress the dynamic range (Log-Mel Spectrogram).
*   **Normalization:** Apply instance-level normalization (e.g., Min-Max scaling or Standardization) to each spectrogram to ensure input values are within a trainable range (0-1 or roughly -1 to 1).
*   **Input Shape:** Ensure all inputs have fixed dimensions (Frequency Bins $\times$ Time Frames) by padding or truncating to the target duration (2 seconds).

# Training
*   **Loss Function:** Use Binary Cross-Entropy (BCE) Loss.
*   **Optimizer:** Utilize the Adam optimizer with a standard learning rate (e.g., 0.001) for fast convergence.
*   **Imbalance Handling:** Address the ~9:1 class imbalance by applying a static class weight to the positive class within the loss function (e.g., weighting positive samples by a factor of 9), avoiding the overhead of complex sampling schemes.
*   **Regularization:** Implement Early Stopping based on validation AUC to prevent overfitting and reduce unnecessary training time.

# Evaluation
*   **Inference:** Preprocess the test set recordings into Log-Mel Spectrograms using the exact parameters defined in the Data step.
*   **Prediction:** Perform a forward pass with the trained model to generate a scalar probability (0-1) for each clip.
*   **Submission:** Map these probabilities to the corresponding clip filenames as required by the submission format.
