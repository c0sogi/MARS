The `KeyError: 'data'` occurs because the code attempts to access a convenience key (`'data'`) in the `sample` dictionary that maps sensor names to tokens. This key exists in NuScenes SDK objects but not in the raw JSON tables provided in this dataset. In the raw schema, the relationship is inverted: `sample_data` entries contain a `sample_token` foreign key pointing to their parent sample.

To fix this, I will modify `library/dataset.py` to manually build a lookup dictionary mapping `sample_token`s to their corresponding LIDAR `sample_data` records (identified by the `.bin` filename extension). I will then use this lookup to retrieve the correct sensor record for each sample, bypassing the missing `'data'` key.
