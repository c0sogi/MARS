The issue is that `gaussian_radius` is a NumPy-based utility function, but it is being passed PyTorch tensors residing on the CUDA device (`l_m / stride_y` and `w_m / stride_x`). NumPy cannot operate directly on CUDA tensors, causing a `TypeError`. To fix this, I will explicitly convert the scalar tensors to Python floats using the `.item()` method before passing them to `gaussian_radius`.
