The execution failure was caused by an **Off-By-One Error** in the grid size calculation within `runfile.py`. The expression `int((max - min) / voxel_size)` truncated the floating-point result (e.g., `767.999...`) to `767` instead of the expected `768`. This mismatch resulted in the `PointPillarsScatter` module allocating an undersized canvas, leading to an out-of-bounds write and a CUDA assertion failure when the Voxelizer produced indices up to `767`.
