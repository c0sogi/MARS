The `torch.OutOfMemoryError` is caused by the excessively high resolution of the Bird's Eye View (BEV) grid ($1920 \times 1920$) resulting from a small `VOXEL_SIZE` of `[0.08, 0.08, 4.0]`. This leads to massive feature map allocations in the `ResNetFPN` backbone that exceed the GPU memory capacity. To fix this, I will increase the `VOXEL_SIZE` to `[0.2, 0.2, 4.0]`, which reduces the grid dimensions to $768 \times 768$, significantly lowering memory consumption while maintaining adequate resolution for detection. This addresses the root cause of the memory explosion by reducing the size of dense tensors allocated during the forward pass (Cite debug_lesson_18).
