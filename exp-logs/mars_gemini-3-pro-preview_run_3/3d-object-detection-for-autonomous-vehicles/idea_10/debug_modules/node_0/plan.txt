To demonstrate the usage of the provided 3D object detection library, I will implement a script that performs the following steps:

1.  **Environment Setup**: Fix random seeds for reproducibility and prepare a temporary working directory.
2.  **Data Subsetting**: Create a small subset of the metadata (training, validation, and test) to ensure the demonstration runs quickly (within minutes) compared to the full dataset.
3.  **Configuration Override**: Dynamically patch the `Config` class to point to the subset metadata and reduce training hyperparameters (e.g., 1 epoch, small batch size) for the demo.
4.  **Component Verification**:
    *   **Geometric Utils**: Verify the correctness of `box3d_to_corners` and `iou3d_shapely` using synthetic bounding boxes with known intersections.
    *   **Dataset & Transforms**: Verify that the `LidarDataset` correctly loads point clouds and applies the `GTDatabaseSampler` (which will build a mini-database from the subset).
5.  **End-to-End Execution**: Run the `run_engine` function to simulate a full training epoch, validation step, and submission generation using the subset data.
