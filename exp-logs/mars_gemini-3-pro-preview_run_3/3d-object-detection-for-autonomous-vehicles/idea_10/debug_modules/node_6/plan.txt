The `OutOfMemoryError` is caused by an incorrect tensor broadcasting operation in `library/modules.py` within the `roi_align_rotated` method. The code concatenates width and length tensors into a shape of `(N, 1, 1, 2)` but then redundantly applies `.unsqueeze(2)`, resulting in a 5D tensor `(N, 1, 1, 1, 2)`. When multiplied by the grid tensor `(N, 7, 7, 2)`, PyTorch broadcasts these shapes to `(N, N, 7, 7, 2)`, causing memory usage to scale quadratically with the number of proposals ($N^2$) instead of linearly. To fix this, I will remove the `.unsqueeze(2)` call, ensuring the dimensions align correctly for element-wise multiplication (Cite debug_lesson_20).
