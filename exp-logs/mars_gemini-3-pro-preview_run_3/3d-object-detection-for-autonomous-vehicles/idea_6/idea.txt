Based on the critical lessons learned from the failure of the geometric baseline (Idea 2) and the optimization instability of the anchor-based deep learning approach (Idea 4), I propose a **Temporal PointPillars model with an Anchor-Free Center Regression Head**.

This strategy introduces **Multi-Sweep Temporal Aggregation** to structurally solve the sparsity issue identified in Lesson 00005, and adopts an **Anchor-Free CenterPoint** architecture with strict **Target Normalization** to resolve the optimization instability identified in Lesson 00008.

### Model
The architecture is a single-stage, end-to-end 3D detector designed for stability and semantic context.
1.  **Input & Encoder (Temporal PointPillars):**
    *   The model accepts a point cloud with 5 dimensions: $(x, y, z, intensity, \Delta t)$. $\Delta t$ represents the time lag of a point relative to the current frame.
    *   We utilize the **PointPillars** encoder to discretize this 5D data into a 2D pseudo-image. This learned encoding preserves local geometry and allows the model to infer object shape from context, addressing the "L-shape" occlusion failure of geometric heuristics **Cite solution_lesson_node_00005**.
2.  **Backbone:**
    *   A standard 2D Convolutional Neural Network (e.g., ResNet or VGG-based FPN) processes the pseudo-image to extract high-level spatial features.
3.  **Detection Head (Anchor-Free Center Regression):**
    *   We replace the SSD Head with a **Center Head**. Instead of matching thousands of anchors (which caused the gradient explosion in **Cite solution_lesson_node_00008**), this head predicts a dense **Heatmap** where peaks represent object centers.
    *   Parallel regression branches predict the object properties at these center locations: **Size** (log-dimensions), **Offset** (sub-voxel correction), and **Rotation** (sin/cos).

### Data
1.  **Temporal Aggregation (Multi-Sweep):**
    *   We will parse `sample_data.json` to identify the $N$ (e.g., 10) preceding Lidar sweeps for each sample. Using `ego_pose.json` and `calibrated_sensor.json`, we will transform points from these past frames into the current frame's coordinate system and append the time difference $\Delta t$.
    *   **Purpose:** This densifies the point cloud, filling in the "variable density" gaps and completing the partial "L-shapes" that confused the geometric clustering algorithms **Cite solution_lesson_node_00005**.
2.  **Target Normalization:**
    *   **Log-Space Dimensions:** Ground truth box dimensions $(l, w, h)$ will be log-transformed ($\log(x)$) for regression targets. This compresses the dynamic range (e.g., between buses and pedestrians), preventing the "unnormalized regression targets" that led to pathological loss values **Cite solution_lesson_node_00008**.
    *   **Offset Normalization:** Regression offsets will be normalized by the voxel stride to ensure they remain within a small, stable range (typically $[0, 1]$).
3.  **Augmentation:**
    *   We will employ **GT Database Sampling** (copy-pasting objects from other scenes) to further combat sparsity and **Global Rotation/Scaling** to improve generalization.

### Training
1.  **Loss Functions:**
    *   **Gaussian Focal Loss:** Applied to the heatmap branch. This creates a smooth gradient around object centers rather than a harsh binary target, stabilizing convergence.
    *   **Masked L1 Loss:** Applied to the regression branches (Size, Offset, Rotation). Crucially, this loss is **only calculated at the ground truth center indices**. This prevents the network from trying to regress shapes in empty space, a key factor in the previous optimization failure **Cite solution_lesson_node_00008**.
2.  **Optimization:**
    *   **Gradient Clipping:** We will clip global gradient norms to prevent explosion during the initial training phase.
    *   **Scheduler:** An AdamW optimizer with a One-Cycle Learning Rate policy will be used to warm up training and ensure convergence within the 24-hour limit.

### Evaluation
1.  **Inference:**
    *   The model processes the multi-sweep point cloud to generate a heatmap and regression maps.
    *   We apply a $3 \times 3$ Max Pooling operation on the heatmap to extract local peaks (candidate centers).
2.  **Decoding:**
    *   For the top $K$ peaks, we extract the regression values. The log-dimensions are exponentiated ($\exp(x)$) to recover physical sizes, and offsets are added to the grid coordinates to obtain the final 3D bounding boxes.
    *   This approach naturally handles Non-Maximum Suppression (NMS) via the heatmap peak extraction, though a final IoU-based NMS will be applied for precision.
