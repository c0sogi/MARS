This script demonstrates the usage of the provided library files for the 3D object detection task. It performs the following steps:
1.  **Configuration**: Overrides default configuration settings to run in a "fast mode" (fewer epochs, small dataset subset, disabled heavy augmentation) suitable for demonstration.
2.  **Utility Verification**: Validates the logic of bounding box encoding/decoding and IoU calculations using assertions.
3.  **Dataset & DataLoader**: Instantiates the `LidarDataset`, loads a small batch of data, and verifies the structure and shapes of the output tensors.
4.  **Model Architecture**: Initializes the `TwoStagePointPillars` model, performs a forward pass with the loaded batch, and asserts the output shapes of the heatmap, regression maps, and proposal features.
5.  **Full Training Loop**: Uses the `Trainer` class to execute a complete training, validation, and submission pipeline on the reduced dataset, ensuring end-to-end functionality.
