This script demonstrates the usage of the provided 3D object detection library. It covers the following steps:
1.  **Dataset Loading**: Instantiates `LidarDataset` with a small subset and verifies data integrity (shapes, keys).
2.  **Data Collation**: Demonstrates how `collate_fn` batches individual samples.
3.  **Model Components**: Individually tests the `PillarFeatureNet` (Voxelization), `Backbone`, and `CenterHead`.
4.  **Full Model Forward Pass**: Runs data through the end-to-end `CenterPointNet`.
5.  **Loss Calculation**: Computes the loss using `LossWrapper` and verifies it produces a valid scalar.
6.  **Prediction Decoding**: Decodes model outputs into bounding boxes using `decode_predictions`.
7.  **Training Loop**: Runs a minimal training loop (1 epoch, limited samples) to demonstrate the optimization process.
