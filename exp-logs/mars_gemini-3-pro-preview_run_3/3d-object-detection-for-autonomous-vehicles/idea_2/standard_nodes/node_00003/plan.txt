The error analysis reveals a **Coordinate System Mismatch**. The Lidar points are loaded in the **Sensor Coordinate Frame**, but the Ground Truth bounding boxes are provided in the **World Coordinate Frame**. Consequently, the geometric proposals (generated in Sensor Frame) never overlap with the Ground Truth, resulting in 0.0 IoU, no positive training samples, and a failed model.

To fix this, I will implement a transformation stack to convert Lidar points from Sensor Frame to World Frame before proposal generation.

**Plan:**
1.  **Update `library/utils.py`**: Add helper functions `quaternion_to_matrix`, `get_transform_matrix`, and `transform_points` to handle 3D transformations.
2.  **Update `library/cluster_proposal.py`**: Modify `GeometricProposalGenerator.process_lidar_file` to accept an optional `transform_matrix` and apply it to the point cloud immediately after loading.
3.  **Update `library/feature_engineering.py`**:
    *   In `create_dataset`, load the `sample_data.json`, `calibrated_sensor.json`, and `ego_pose.json` files (inferring the correct `train_data` or `test_data` directory).
    *   For each sample, compute the full transformation matrix ($T_{world} = T_{ego \to world} \times T_{sensor \to ego}$) using the calibration tokens.
    *   Pass this matrix to the `process_sample_wrapper` via the `row` dictionary, ensuring proposals are generated in the World Frame.

def quaternion_to_matrix(q):
    """
    Converts a quaternion [w, x, y, z] to a 3x3 rotation matrix.
    """
    w, x, y, z = q
    return np.array([
        [1 - 2*y*y - 2*z*z, 2*x*y - 2*z*w, 2*x*z + 2*y*w],
        [2*x*y + 2*z*w, 1 - 2*x*x - 2*z*z, 2*y*z - 2*x*w],
        [2*x*z - 2*y*w, 2*y*z + 2*x*w, 1 - 2*x*x - 2*y*y]
    ])


def get_transform_matrix(translation, rotation):
    """
    Constructs a 4x4 homogeneous transformation matrix.
    Args:
        translation: [x, y, z]
        rotation: [w, x, y, z] quaternion
    """
    R = quaternion_to_matrix(rotation)
    T = np.array(translation).reshape(3, 1)
    M = np.eye(4)
    M[:3, :3] = R
    M[:3, 3] = T.flatten()
    return M


def transform_points(points, matrix):
    """
    Applies a 4x4 transformation matrix to points.
    Args:
        points: (N, 4) array [x, y, z, intensity]
        matrix: (4, 4) transformation matrix
    Returns:
        Transformed points (N, 4)
    """
    if len(points) == 0:
        return points

    # Extract XYZ
    xyz = points[:, :3]

    # Homogeneous coordinates
    ones = np.ones((xyz.shape[0], 1))
    xyz_h = np.hstack([xyz, ones])

    # Transform: (M @ P.T).T = P @ M.T
    xyz_transformed = (matrix @ xyz_h.T).T

    # Update points (preserve intensity)
    points_new = points.copy()
    points_new[:, :3] = xyz_transformed[:, :3]

    return points_new
