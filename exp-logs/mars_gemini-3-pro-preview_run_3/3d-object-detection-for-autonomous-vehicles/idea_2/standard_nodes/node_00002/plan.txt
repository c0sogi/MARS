The implementation strategy is as follows:

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility. Define the maximum number of samples for training (5000) and validation (1000) to ensure the pipeline executes quickly within the time limit, while processing the full test set for submission.
2.  **Data Preparation**: Use the provided `dataset_factory` to build tabular datasets from the metadata. This involves extracting geometric features (using the pre-implemented `FeatureEngineer`) from the LIDAR point clouds. The training and validation sets are subsetted for speed, while the test set is processed in full.
3.  **Model Training**: Instantiate the `ObjectDetector` (LightGBM wrapper). Train the classifier to distinguish objects from background and the regressors to refine bounding box coordinates, using the training and validation dataframes.
4.  **Validation and Metric Calculation**:
    *   Run inference on the validation set to get predictions.
    *   Load the ground truth annotations from the validation metadata.
    *   Implement the specific Mean Average Precision (mAP) metric defined in the task: iterate through IoU thresholds (0.5 to 0.95), match predictions to ground truth, and calculate the custom precision score $\frac{TP}{TP+FP+FN}$ for each image.
    *   Print the "Final Validation Metric".
5.  **Failure Analysis**:
    *   Analyze the model's performance on positive validation samples.
    *   Calculate the correlation between regression errors (positional and dimensional) and input features like point count and distance to sensor to identify weak points.
6.  **Submission Generation**: Generate the final predictions for the test set and save them to `submission.csv` in the required format.
