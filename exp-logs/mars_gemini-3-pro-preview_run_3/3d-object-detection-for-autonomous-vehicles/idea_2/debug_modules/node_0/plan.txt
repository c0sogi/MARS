The following script demonstrates the end-to-end usage of the provided 3D object detection library. It begins by verifying utility functions like 3D IoU calculation and bounding box corner generation. It then proceeds to run the geometric proposal generation pipeline on a sample LIDAR file, extracts features, builds a small tabular dataset using the factory pattern, and finally trains the LightGBM object detector and generates a submission file. Configuration parameters are overridden to ensure the script executes quickly within the provided environment.
