### Implementation Strategy

1.  **Configuration Setup**: We will first override specific configurations in `library.config.Config` to ensure the script runs quickly. This includes reducing the number of epochs to 1, setting a small batch size, and pointing the test metadata path to a temporary subset file to speed up the inference/submission step.
2.  **Data Preparation**: We will create a temporary subset of the test metadata (first 10 samples) in the `./working` directory. This allows the submission generation function to run in seconds rather than processing the entire test set.
3.  **Component Verification**:
    *   **Dataset**: We will instantiate `NuScenesDataset` with the training split, retrieve a single sample, and assert the shapes of the generated pillars and coordinates to verify the voxelization logic.
    *   **Model**: We will instantiate the `PointPillars` model, perform a forward pass with a dummy batch derived from the dataset, and verify that the output contains the expected classification and regression predictions with correct shapes.
4.  **Integration Run (Training & Inference)**: We will execute the `train_model` function with `max_samples=10`. This function encapsulates the entire pipeline: training loop, validation, model saving, and submission generation.
5.  **Output Validation**: Finally, we will check if the model checkpoint and submission file were created successfully and verify the format of the submission file.
