This script demonstrates the end-to-end usage of the provided 3D object detection library. It performs the following steps:
1.  **Configuration Setup**: Creates a lightweight subset of the training, validation, and test metadata to ensure the demonstration runs quickly. It overrides the global `Config` to point to these subsets and adjusts hyperparameters (batch size, epochs).
2.  **Dataset & Voxelization Verification**: Instantiates the `LyftDataset` and verifies that the voxelization process (converting point clouds to pillars) produces tensors with the expected shapes.
3.  **Model Forward Pass Verification**: Manually runs a batch of data through the `PointPillars` model to confirm that the backbone and detection head produce outputs with correct dimensions.
4.  **Loss Calculation Verification**: Computes the loss using `PointPillarsLoss` on the manual batch to ensure the training objective is valid (finite and scalar).
5.  **Training Loop**: Uses the `Trainer` class to run a full training epoch on the subset, saving the model checkpoint.
6.  **Inference & Submission**: Generates predictions using `SubmissionGenerator` and saves the results to a CSV file.
