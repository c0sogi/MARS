This script performs an Exploratory Data Analysis (EDA) on the 3D Object Detection dataset. It focuses on the training set defined in `./metadata/train_metadata.csv`. The analysis is divided into three main parts:
1.  **Target Variable Analysis**: Parses the bounding box strings to analyze class distributions, object dimensions (width, length, height), and spatial distributions.
2.  **Input Data Analysis (Lidar)**: Samples the binary Lidar files to analyze point cloud characteristics such as point counts, spatial extent (XYZ ranges), and intensity distributions.
3.  **Feature Relationships**: Examines correlations between object properties and metadata features (e.g., number of points vs. number of objects).
