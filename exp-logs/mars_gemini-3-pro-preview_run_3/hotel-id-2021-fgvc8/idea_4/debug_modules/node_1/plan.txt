The `KeyError: np.int64(54037)` occurs because the label encoder (`hotel_to_idx`) is generated after the training set has been downsampled in Debug Mode. Since the validation set is sampled independently, it contains hotel classes that were not selected in the training subset, leading to missing keys during lookup. The fix is to generate the label encoding using the full training dataset *before* applying the Debug Mode sampling. This ensures the encoder includes all 7770 classes (matching the model's output dimension) and can handle any hotel ID present in the validation sample.
