The following implementation demonstrates the end-to-end usage of the provided Hotel Identification library. It systematically verifies the utility functions, dataset loading, model architecture, training loop, and inference pipeline.

### Implementation Strategy
1.  **Environment Setup**: Imports necessary modules from the `library` package, ensuring the script runs from the root directory.
2.  **Utility Verification**: validating the `LabelEncoder` logic and the `MAP@5` metric calculation with deterministic assertions.
3.  **Dataset Inspection**: Instantiates the `HotelDataset` to confirm image loading, transformation pipelines, and label encoding correctness.
4.  **Model Forward Pass**: Initializes the `HotelResNet` and performs a dummy forward pass to verify output tensor shapes match the number of classes.
5.  **Training Simulation**: Executes `run_training` in debug mode (subset of data) for a single epoch to demonstrate the training loop and checkpoint generation without consuming excessive time.
6.  **Inference Simulation**: Uses the generated checkpoint to run `generate_submission` in debug mode, verifying the output file format and content.
