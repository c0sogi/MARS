Based on the task description and the provided model architectures, here is a proposal for a highly efficient **baseline approach**.

### Baseline Approach: Standard ResNet Classification

This approach establishes a fundamental performance benchmark by stripping away the complexities of metric learning (ArcFace), transformers (Swin), and aggregation layers (NetVLAD). It combines the robust CNN backbone concept from Model 1 with the direct classification philosophy of Model 2, resulting in a lightweight, end-to-end parametric model.

#### Model
The architecture utilizes a **ResNet-18** backbone, chosen for its balance between inference speed and feature extraction capability.
*   **Backbone:** The network is initialized with pre-trained ImageNet weights to leverage learned low-level visual features.
*   **Neck:** The output of the final convolutional block is processed via a Global Average Pooling layer, reducing the feature maps to a compact 512-dimensional vector.
*   **Head:** A single Fully Connected (Linear) layer maps the 512-dimensional vector directly to the 7,770 output classes (hotels). Unlike Model 1, which uses an embedding head, this model outputs raw class logits.

#### Data
Preprocessing is kept minimal to maximize throughput and establish a raw data baseline.
*   **Input Processing:** All images are resized to 256x256 pixels, followed by a Center Crop of 224x224 pixels to focus on the central subject.
*   **Normalization:** Pixel values are normalized using standard ImageNet mean and standard deviation values.
*   **Augmentation:** No data augmentation is applied during training, ensuring the baseline reflects the model's ability to learn from the provided data distribution without synthetic variance.

#### Training
The model is trained as a standard multi-class classification problem.
*   **Loss Function:** **Categorical Cross-Entropy Loss** is used to penalize probability divergence between predictions and ground truth labels. This differs from the Angular Margin loss in Model 1, prioritizing probability calibration over embedding space geometry.
*   **Optimizer:** Stochastic Gradient Descent (SGD) with Momentum or Adam is used to update weights.
*   **Strategy:** The model is trained for a fixed number of epochs. To handle class imbalance (e.g., singleton classes), a simple class-weighting scheme or random oversampling of minority classes can be optionally applied within the data loader.

#### Evaluation
Inference is performed directly on the test images without complex retrieval mechanisms.
*   **Prediction:** For each test image, the model performs a forward pass to generate a probability distribution over the 7,770 classes.
*   **Ranking:** The logits are sorted in descending order. The top 5 indices are selected and mapped back to their corresponding `hotel_id` strings.
*   **Output:** The result is a space-delimited string of the top 5 hotel IDs for each image, matching the required submission format.
