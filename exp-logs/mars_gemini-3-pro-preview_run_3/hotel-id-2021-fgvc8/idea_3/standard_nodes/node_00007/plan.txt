The issue lies in the `BalanceClassSampler` class within `library/dataset.py`. This sampler is passed to the `DataLoader` using the `batch_sampler` argument, which expects the iterator to yield a complete list of indices (a batch) at each step. However, the current implementation uses `yield from batch_indices`, which unpacks the list and yields individual indices one by one. Consequently, the `DataLoader` receives a single integer (specifically a `numpy.int64`) instead of a list of integers, causing a `TypeError` when it attempts to iterate over that single integer to fetch the batch data. The fix is to change `yield from batch_indices` to `yield batch_indices` so that the full list of indices is yielded for each batch.
