Based on the empirical evidence gathered from previous experiments, I propose the following optimized strategy. This solution scales the successful retrieval-based architecture to a higher capacity and resolution to better capture fine-grained details, while strictly adhering to the stability constraints identified in the failure analysis.

# Model
**Architecture: EfficientNet-B1 with GeM Pooling and BN-Neck**
*   **Backbone:** Upgrade the backbone from EfficientNet-B0 to **EfficientNet-B1**. This provides a necessary increase in model capacity and receptive field to capture intricate hotel details (e.g., signage, architectural patterns) without incurring the massive computational cost and convergence difficulties of the ResNet50 model, which failed to converge (Cite `solution_lesson_node_00004`).
*   **Aggregation:** Retain **Generalized Mean (GeM) Pooling**. This layer is critical for focusing on salient regions in the image (e.g., a hotel logo) while ignoring background noise, a capability that standard Global Average Pooling lacks (Cite `solution_lesson_node_00008`).
*   **Neck:** Retain the **Batch Normalization (BN) Neck** (Linear -> BN) between the pooling layer and the head. This stabilizes the feature distribution on the hypersphere, which is essential for the convergence of the metric learning loss (Cite `solution_lesson_node_00008`).
*   **Head:** Retain the **ArcFace (ArcMarginProduct)** head. This loss function has proven to be the single most effective component for handling the high-cardinality (7,770 classes) nature of the dataset (Cite `solution_lesson_node_00002`).

# Data
**Preprocessing & Resolution Scaling**
*   **Input Resolution:** Increase the input image size to **384x384 pixels** (up from 256x256). Fine-grained hotel identification often relies on legible text and small architectural details that are lost at lower resolutions. The EfficientNet-B1 backbone is designed to handle this increased resolution effectively.
*   **Sampling:** Use **Standard Random Sampling**. We explicitly reject Class-Balanced (P-K) sampling, as previous experiments demonstrated it causes model collapse due to the high frequency of singleton classes (Cite `solution_lesson_node_00007`).
*   **Augmentation:** Maintain a **Mild Augmentation** policy (Resize, Random Crop, Horizontal Flip). We will strictly avoid aggressive spatial distortions like `RandomResizedCrop`, which were shown to hinder convergence in this sparse-data regime (Cite `solution_lesson_node_00004`).

# Training
**Procedure & Optimization**
*   **Loss Function:** Minimize **ArcFace Loss** combined with Cross-Entropy.
*   **Optimizer:** Use **AdamW** with a cosine decay learning rate schedule, which provided stable convergence in the successful EfficientNet-B0 experiment (Cite `solution_lesson_node_00008`).
*   **Strategy:** Train for a fixed number of epochs (e.g., 10-12) to allow the model to adapt to the higher resolution inputs.

# Evaluation
**Inference with Test-Time Augmentation**
*   **Prediction:** Extract embeddings using the trained EfficientNet-B1 + GeM + BN-Neck model.
*   **Test-Time Augmentation (TTA):** Perform inference on the original image and a horizontally flipped version. Average the resulting embedding vectors to improve robustness.
*   **Ranking:** Compute Cosine Similarity between the averaged test embedding and the learned ArcFace class centers. Output the top 5 hotel IDs.
