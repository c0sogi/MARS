Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment with a fixed random seed. Override the default `Config.EPOCHS` to 8 to ensure the training completes well within the 2-hour limit while still providing sufficient convergence for the baseline.
2.  **Data Loading**: Utilize `get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test sets using the pre-calculated metadata and label encoders.
3.  **Training**: Execute the `train_loop` to train the `HotelEfficientNet` (EfficientNet-B0 + GeM + ArcFace). This handles the training epochs, validation monitoring, and saving the best model checkpoint.
4.  **Validation & Failure Analysis**:
    *   Load the best saved model.
    *   Perform inference on the full validation set to calculate the exact `Final Validation Metric` (MAP@5).
    *   Conduct failure analysis by calculating the correlation between the prediction error magnitude (1 - AP) and the class frequency (number of training samples for that hotel). This identifies if the model struggles with rare classes.
5.  **Submission**: Check if the validation metric exceeds the specified threshold (0.1457). If successful, generate predictions for the test set using Test-Time Augmentation (TTA) via `predict_and_submit` and save the `submission.csv`.
