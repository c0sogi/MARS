Based on the lessons learned from the previous experiments, I propose the following optimized strategy. This solution introduces a **Multi-Stage Progressive Resolution Pipeline** combined with a higher-capacity backbone. This approach is designed to resolve the conflict between the need for high-resolution features (to capture fine details) and the constraints of throughput and stability that caused previous high-resolution attempts to fail.

# Model
**Architecture: EfficientNet-V2-M with GeM Pooling and Sub-center ArcFace**
*   **Backbone (Structural Innovation):** Upgrade the backbone to **EfficientNet-V2-M**. While EfficientNet-V2-S (Idea 8) proved efficient and effective (Cite `solution_lesson_node_00013`), the "Medium" variant offers increased parameter capacity to better model the 7,770 classes without the massive computational overhead of the "Large" or "XL" variants. This balances the need for deeper feature extraction with the runtime constraints.
*   **Aggregation (Strategic Retention):** Retain **Generalized Mean (GeM) Pooling**. This layer is essential for fine-grained identification, enabling the model to spatially focus on discriminative regions (e.g., logos, text) while suppressing background noise (Cite `solution_lesson_node_00008`).
*   **Neck (Strategic Retention):** Retain the **Batch Normalization (BN) Neck**. This stabilizes the feature distribution before projection onto the hypersphere, ensuring the convergence of the metric learning loss (Cite `solution_lesson_node_00008`).
*   **Head (Strategic Retention):** Retain **Sub-center ArcFace** (with $K=3$). This head handles the high intra-class variance (multi-modality) of hotel images better than single-center ArcFace by allowing multiple prototypes per class (Cite `solution_lesson_node_00013`).

# Data
**Preprocessing & Sampling**
*   **Sampling:** Strictly use **Standard Random Sampling**. We continue to reject Class-Balanced (P-K) sampling to avoid the model collapse observed with the dataset's heavy singleton tail (Cite `solution_lesson_node_00007`).
*   **Augmentation:** Maintain **Mild Augmentation** (Resize, Random Crop, Horizontal Flip). We avoid aggressive spatial distortions like `RandomResizedCrop` to prevent convergence issues in this sparse-data regime (Cite `solution_lesson_node_00004`).

# Training
**Procedure: Multi-Stage Progressive Resolution**
This pipeline explicitly addresses the "Resolution-Throughput Trade-off" (Cite `solution_lesson_node_00011`) and stability issues (Cite `solution_lesson_node_00009`).

*   **Stage 1: Low-Resolution Training (224x224)**
    *   **Resolution:** Train the model initially on **224x224** images.
    *   **Objective:** This stage leverages high throughput (larger batch size) to rapidly learn robust global features and converge the ArcFace margins. This avoids the underfitting caused by the slow iteration speed of high-resolution training from scratch (Cite `solution_lesson_node_00011`).
    *   **Optimizer:** AdamW with standard learning rate and cosine decay.

*   **Stage 2: High-Resolution Fine-Tuning (384x384)**
    *   **Resolution:** Fine-tune the pre-trained model on **384x384** images.
    *   **Objective:** This stage allows the model to resolve fine-grained details (e.g., reading text on signs) that are lost at 224px.
    *   **Stability Control:** Use a **significantly reduced learning rate** (e.g., 10x lower than Stage 1) and a **Linear Warmup**. This prevents the gradient explosion and numerical instability previously observed when introducing high-resolution inputs to a GeM-pooling network (Cite `solution_lesson_node_00009`).

# Evaluation
**Inference with Test-Time Augmentation**
*   **Prediction:** Perform inference using the final model at **384x384 resolution**.
*   **Test-Time Augmentation (TTA):** Extract embeddings for the original and horizontally flipped images, then average them (Cite `solution_lesson_node_00008`).
*   **Ranking:** Compute Cosine Similarity between the averaged test embedding and the learned sub-centers (using max-similarity across sub-centers) to generate the top 5 hotel IDs.
