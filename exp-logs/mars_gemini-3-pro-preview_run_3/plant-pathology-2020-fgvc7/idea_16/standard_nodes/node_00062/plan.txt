Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment with fixed seeds for reproducibility. Override `Config` parameters to ensure the pipeline runs quickly (reducing epochs to 10) and sets the correct submission path.
2.  **Data Loading**: Utilize the provided `get_loaders` and `load_data` functions to load training, validation, and test datasets. Pre-compute class weights for the loss function.
3.  **Training Loop**: Implement a loop over the defined backbones (Heterogeneous Ensemble). For each backbone:
    *   Initialize the `AppleNet` model, optimizer, scheduler, and `ModelEMA`.
    *   Train for the specified number of epochs using `train_one_epoch`.
    *   Validate after each epoch using `validate` and save the model with the best ROC AUC score.
4.  **Inference**: Load the best weights for each backbone. Perform inference on the validation set (for ensemble scoring) and the test set (using Test-Time Augmentation via `predict_tta`).
5.  **Ensemble & Evaluation**: Average the predictions from all backbones. Calculate the final "Mean Column-wise ROC AUC" on the validation set.
6.  **Failure Analysis**: Calculate the Mean Absolute Error (MAE) for each validation sample. Extract simple image statistics (brightness, contrast) from the validation images and compute their Pearson correlation with the error magnitude to identify systematic weaknesses.
7.  **Submission**: Check if the validation metric meets the threshold (interpreted as > 0.5 given AUC constraints). If passed, format and save the test predictions to `submission.csv`.
