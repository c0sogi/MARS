To implement the "Heterogeneous Ensemble with Decoupled Multi-Task Learning" as a fast baseline, I will orchestrate the training of two distinct architectures (EfficientNetV2-M and MaxViT-Small) using the provided training and validation metadata.

**Implementation Strategy:**

1.  **Setup & Configuration**: I will override the default `EPOCHS` in `Config` to 5 to ensure the pipeline completes within the time limit while still providing a meaningful signal. I will use the single train/validation split provided in the metadata directory.
2.  **Data Preparation**: I will load the metadata and compute inverse frequency class weights to handle the class imbalance, specifically targeting the "Multiple Diseases" class.
3.  **Model Training Loop**: I will iterate through the two model configurations defined in `Config`. For each model:
    *   Initialize the `AppleMultiTaskModel` and `DecoupledMultiTaskLoss`.
    *   Train using the `engine.train_model` function with Automatic Mixed Precision (AMP) and Model EMA.
    *   Save the best checkpoint based on validation AUC.
4.  **Ensemble Inference**:
    *   I will load the best weights for both models.
    *   I will perform inference on both the validation and test sets.
    *   I will implement **Domain-Aware TTA** (Horizontal Flip) manually during the inference loop by flipping tensors on the GPU.
    *   Predictions from both models will be averaged (soft voting) to form the final ensemble.
5.  **Validation & Failure Analysis**:
    *   I will compute the final Mean Column-wise ROC AUC on the ensemble predictions.
    *   I will perform failure analysis by correlating prediction errors (1 - probability of ground truth) with image metadata (brightness, contrast) to identify systematic weaknesses.
6.  **Submission**: I will generate the `submission.csv` file using the ensemble predictions on the test set.
