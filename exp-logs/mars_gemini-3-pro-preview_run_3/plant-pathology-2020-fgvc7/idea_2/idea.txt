To improve upon the current best ROC AUC of 0.9772, I propose a solution that introduces architectural diversity via ensembling and enhances generalization through weight averaging, while strictly adhering to the data augmentation constraints identified in the lessons.

### Model
**Ensemble of EfficientNet-B0 and ConvNeXt-Tiny**
I propose a structural evolution from a single-model baseline to a heterogeneous ensemble.
1.  **EfficientNet-B0:** We will retain the **Fine-Tuned EfficientNet-B0** as the anchor model, as it has proven effective for this specific resolution and dataset size.
2.  **ConvNeXt-Tiny:** We will introduce **ConvNeXt-Tiny** as the second component. This architecture represents a fundamental shift in feature engineering paradigm compared to EfficientNet. While EfficientNet relies on inverted residual blocks with standard 3x3 convolutions, ConvNeXt adopts "Transformer-style" design principles—using larger kernels (7x7), fewer activation functions, and Layer Normalization. This allows the model to capture global context and long-range dependencies more effectively than standard CNNs, providing complementary predictions to the EfficientNet.

### Data
*   **Preprocessing:** All images will be resized to **224x224** pixels and normalized.
*   **Augmentation:** We will employ a **Strong Geometric Augmentation** strategy (specifically `ShiftScaleRotate` and `RandomFlip`) to force the model to learn invariant features **Cite solution_lesson_node_00003**. Crucially, we will **exclude** any spatial occlusion augmentations (like Cutout or CoarseDropout) to prevent the loss of small, discriminative disease lesions, which was shown to degrade performance **Cite solution_lesson_node_00004**.

### Training
*   **Loss Function:** Both models will be trained using **Cross-Entropy Loss with Inverse Frequency Class Weights**. This ensures that the optimization process explicitly accounts for the significant class imbalance (specifically the rare "multiple_diseases" class), aligning the training objective with the macro-averaged metric **Cite solution_lesson_node_00001**.
*   **Stochastic Weight Averaging (SWA):** For the ConvNeXt-Tiny model, we will implement **Stochastic Weight Averaging**. Instead of using the weights from the single epoch with the lowest validation loss, we will average the weights of the model captured at the end of each epoch during the final phase of training. This technique finds a broader, flatter minimum in the loss landscape, which significantly improves generalization on small datasets where standard models might settle into sharp, overfitting minima.
*   **Optimizer:** We will use **AdamW** for ConvNeXt (to handle weight decay correctly) and **Adam** for EfficientNet.

### Evaluation
*   **Test-Time Augmentation (TTA):** During inference, we will generate predictions for the original image and its horizontally/vertically flipped versions for *both* models **Cite solution_lesson_node_00002**.
*   **Ensemble Strategy:** The final prediction for each image will be the unweighted average of the probability vectors produced by the EfficientNet-B0 (with TTA) and the ConvNeXt-Tiny (SWA + TTA). This combines the local texture bias of the CNN with the global context bias of the ConvNeXt.
