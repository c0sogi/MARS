The error `RuntimeError: Unknown model (convnext_tiny.fb_in1k)` indicates that the model identifier `convnext_tiny.fb_in1k` is not found in the registry of the installed `timm` library version (1.0.20). While `timm` has moved towards a `model.tag` naming convention, specific tags like `fb_in1k` may vary or be implicit defaults in newer versions. As per **Cite debug_lesson_2**, blindly using a specific configuration string without verifying it against the library's registry (`timm.list_models()`) causes failures when library versions update. The fix is to use the stable, base model name `convnext_tiny`, which `timm` maps to the default pre-trained weights (typically the original 1k weights).
