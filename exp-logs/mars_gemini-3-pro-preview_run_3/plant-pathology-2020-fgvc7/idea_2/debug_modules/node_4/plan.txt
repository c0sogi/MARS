The error `RuntimeError: Unknown model (convnext_tiny.in12k_ft_in1k)` occurs because the specific model identifier `convnext_tiny.in12k_ft_in1k` is not present in the registry of the installed version of the `timm` library (v1.0.20). As explained in **Cite debug_lesson_2**, hardcoded configuration strings for model variants often become invalid as libraries evolve and rename or deprecate specific weight tags. To fix this, I will update `library/config.py` to use the standard, stable identifier `convnext_tiny`, which allows the library to resolve the best available default weights for the architecture automatically.
