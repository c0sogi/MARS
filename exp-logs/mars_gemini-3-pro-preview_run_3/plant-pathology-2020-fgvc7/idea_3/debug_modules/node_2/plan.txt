The `RuntimeError: Unknown model (convnext_tiny)` occurs because the generic model alias `"convnext_tiny"` is not registered in the installed version of the `timm` library. As explained in **debug_lesson_2** (Cite debug_lesson_2), libraries often require fully qualified identifiers—such as those specifying the pretraining source or dataset—instead of generic aliases, especially as versions evolve. To fix this, I will update `library/config.py` to use the specific identifier `"convnext_tiny.fb_in1k"`, which explicitly refers to the ConvNeXt-Tiny model with Facebook-pretrained weights on ImageNet-1k.
