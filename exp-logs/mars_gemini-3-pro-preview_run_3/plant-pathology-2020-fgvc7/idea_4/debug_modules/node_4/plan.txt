The `RuntimeError: Unknown model (convnext_tiny)` occurs because the identifier `convnext_tiny` has been removed or renamed in the installed version of `timm` (likely v1.0+). The correct identifier for the ConvNeXt Tiny model pretrained on ImageNet-1k in newer versions is `convnext_tiny.fb_in1k`. I will update the configuration in `library/config.py` and the hardcoded strings in `runfile.py` to use this valid model name. This aligns with the guidance to use library-specific identifiers rather than guessing (Cite debug_lesson_2).
