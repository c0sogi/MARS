The issue is that `scikit-learn`'s `StratifiedKFold` requires at least 2 splits (`n_splits=2`) to define a training and validation set, but the configuration in `runfile.py` sets `CFG.n_folds = 1`. This causes a `ValueError` during initialization. To fix this, I will update `CFG.n_folds` to `2` in `runfile.py`. This satisfies the library's requirement while the script continues to explicitly run only the first fold (Fold 0) for the demo, and the inference loop gracefully skips the missing second fold model.
