This script demonstrates the end-to-end workflow for the Apple Disease Detection task using the provided library modules. It covers data loading, model instantiation, training loop execution, and inference generation.

To ensure rapid execution for demonstration purposes, the script configures the system to run in `DEBUG` mode (using a small subset of data) and limits the training to a single epoch. It includes assertions to verify the shapes of data tensors, the correctness of model outputs, and the generation of required files.
