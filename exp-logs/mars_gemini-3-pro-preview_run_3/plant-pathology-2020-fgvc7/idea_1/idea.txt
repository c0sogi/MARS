To establish a robust and highly efficient baseline, I propose a solution centered on a lightweight Convolutional Neural Network trained end-to-end. This approach synthesizes the architectural strengths of the CNN mentioned in Model 1 with the lightweight efficiency targets of Model 3, while remaining distinct from both by avoiding heavy B3 complexity and the multi-stage complexity of XGBoost pipelines.

### Model
The core architecture will be a **Fine-Tuned EfficientNet-B0**.
*   **Design:** We will utilize the EfficientNet-B0 architecture, which is significantly smaller and faster than the B3 variant (Model 1) while still providing state-of-the-art feature extraction capabilities. Unlike Model 3, which freezes the backbone, we will fine-tune the entire network to learn specific features of apple leaf diseases.
*   **Components:** The model consists of the pre-trained EfficientNet-B0 backbone (initialized with ImageNet weights), followed by a Global Average Pooling layer, a Dropout layer (to prevent overfitting given the small dataset), and a final fully connected (Dense) layer with 4 output units.
*   **Activation:** A Softmax activation function will be applied to the output to produce a probability distribution across the four mutually exclusive classes (healthy, multiple_diseases, rust, scab).

### Data
*   **Preprocessing:** All images will be resized to **224x224** pixels. This resolution matches the native input size of EfficientNet-B0, maximizing computational efficiency on the A100 GPU while retaining sufficient detail for disease identification. Pixel values will be normalized using standard ImageNet mean and standard deviation.
*   **Augmentation:** To maintain high training speed while improving generalization, we will apply only lightweight augmentations during training: Random Horizontal Flip and Random Vertical Flip.
*   **Class Imbalance Handling:** We will compute class weights inversely proportional to the frequency of classes in the training set. These weights will be used in the loss function to ensure the model pays sufficient attention to the rare "multiple_diseases" class (approx. 5% of data).

### Training
*   **Loss Function:** We will use **Weighted Cross-Entropy Loss**, incorporating the calculated class weights to penalize misclassifications of the minority class more heavily.
*   **Optimizer:** The **Adam** optimizer will be employed for its ability to handle sparse gradients and rapid convergence, initialized with a standard learning rate (e.g., 0.001).
*   **Strategy:** Training will proceed for a maximum of 20 epochs. We will implement a **ReduceLROnPlateau** scheduler to lower the learning rate if validation ROC AUC stagnates, and **Early Stopping** to terminate training if the metric does not improve for 3 consecutive epochs, ensuring we do not waste runtime.

### Evaluation
*   **Inference:** Test images will be resized to 224x224 and normalized using the same statistics as the training set.
*   **Prediction:** The model will perform a single forward pass for each image to generate the Softmax probabilities.
*   **Submission:** The resulting probabilities for `healthy`, `multiple_diseases`, `rust`, and `scab` will be mapped directly to the submission format. No test-time augmentation (TTA) will be used to prioritize inference speed.
