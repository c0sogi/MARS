This implementation strategy outlines a complete, self-contained Python script to demonstrate the Apple Disease Detection pipeline.

### Strategy
1.  **Configuration Override**: At runtime, modify the `Config` class attributes to adapt the pipeline for a quick demonstration. This includes enabling `DEBUG` mode (using a tiny subset of data), reducing `EPOCHS` to 1, setting `N_FOLDS` to 2, and redirecting outputs to a temporary working directory.
2.  **Monkeypatching for Speed**: To ensure the script runs immediately without downloading large pre-trained weights (which takes time and bandwidth), we will intercept calls to `timm.create_model` and force `pretrained=False`.
3.  **Component Verification (Unit Tests)**:
    *   **Utils**: Verify random seeding and ROC AUC calculation logic.
    *   **Data**: Verify the fold preparation logic and DataLoader shapes (batch dimensions, channel counts).
    *   **Models**: Instantiate both `AppleEfficientNet` and `AppleSwin` with dummy data to verify forward pass mechanics and output shapes.
4.  **Pipeline Execution (Integration Tests)**:
    *   **Training**: Execute `run_training(debug=True)`. This exercises the full training loop, loss calculation, backpropagation, and checkpoint saving for the configured folds and models.
    *   **Inference**: Execute `run_inference()`. This validates the model loading, Test-Time Augmentation (TTA), prediction aggregation, and submission file generation.
5.  **Validation**: Throughout the script, `assert` statements will ensure that files are created where expected and data shapes are correct.
