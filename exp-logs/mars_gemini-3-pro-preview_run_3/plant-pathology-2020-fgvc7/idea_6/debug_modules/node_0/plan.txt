The following strategy outlines the implementation of the demonstration script:

1.  **Configuration Setup**: We will import the `Config` class and override specific parameters (e.g., enabling `DEBUG` mode, reducing `EPOCHS` to 1, setting a small `BATCH_SIZE`) to ensure the script executes quickly and uses a minimal subset of data.
2.  **Utility Verification**: We will demonstrate `utils.py` by setting the random seed and calculating class weights using `get_class_weights`, verifying the output shape and values.
3.  **Dataset Pipeline**: We will utilize `dataset.py` to prepare stratified folds and instantiate the `AppleDataset` and DataLoaders. We will fetch a single batch to verify tensor shapes and data types.
4.  **Model Instantiation**: We will instantiate both `HierarchicalEfficientNet` and `HierarchicalSwin` from `models.py` with `pretrained=False` to avoid large downloads and ensure speed. We will perform a dummy forward pass to confirm output dimensions match the number of classes.
5.  **Training Loop Simulation**: Instead of running the full `run_fold` (which enforces pretrained weights), we will manually construct a training loop using `train_fn` and `valid_fn` from `training.py`. This allows us to use the lightweight, non-pretrained model and verify the training logic efficiently.
6.  **Inference & TTA**: We will demonstrate `inference.py` by running `predict_with_tta` on the test set using the trained model, verifying that predictions are generated for all test images.
7.  **Assertions**: Throughout the script, assertions will be used to validate shapes, types, and logic correctness.
