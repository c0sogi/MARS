The implementation strategy follows a rigorous 5-Fold Stratified Cross-Validation approach to ensure robustness given the small dataset size. We will use the provided `metadata/train.csv` as our development set, splitting it into 5 folds to train an ensemble of 10 models (5 Multi-Level EfficientNet-B4 and 5 Swin Transformer Tiny). The provided `metadata/val.csv` will be treated as a strict hold-out validation set to compute the "Final Validation Metric" and perform failure analysis, ensuring unbiased evaluation.

The workflow is as follows:
1.  **Setup**: Initialize random seeds and load metadata.
2.  **Training**: Iterate through 5 folds. For each fold, train both EfficientNet and Swin Transformer models using the `train_fold` function, which handles optimization, class weighting, and checkpoint saving.
3.  **Evaluation**: Load all 10 trained model checkpoints. Perform inference on the hold-out validation set using Test-Time Augmentation (TTA). Average the predictions to form an ensemble.
4.  **Metric Calculation**: Compute the Mean Column-wise ROC AUC on the hold-out set and print it with full precision.
5.  **Failure Analysis**: Calculate the error magnitude for each validation sample. Extract image brightness and contrast features, then compute and print their Pearson correlation with the error magnitude to identify systematic weaknesses.
6.  **Submission**: If the validation metric exceeds the specified threshold, generate the final submission for the test set using the ensemble.
