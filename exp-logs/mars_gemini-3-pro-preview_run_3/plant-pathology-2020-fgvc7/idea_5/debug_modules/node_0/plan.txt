Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override specific parameters (e.g., `DEBUG`, `EPOCHS`, `BATCH_SIZE`, `N_FOLDS`) to ensure the pipeline runs on a tiny subset of data for rapid execution.
2.  **Utility Verification**: Test the `get_class_weights` function to ensure it computes correct weights for the imbalanced dataset and verify `calculate_metric` with dummy data.
3.  **Dataset Verification**: Instantiate the `AppleDataset` with the training metadata and check that it correctly loads images and applies transformations, returning tensors of the expected shape.
4.  **Model Verification**: Instantiate the `MultiLevelEfficientNet` model (with `pretrained=False` to avoid download overhead during this specific check) and perform a dummy forward pass to verify the output shape matches the number of classes.
5.  **Training Loop Execution**: Execute `train_fold` for a single fold and a single epoch using the debug subset. This verifies the integration of the dataset, model, loss function, and optimizer, and ensures the model checkpoint is saved correctly.
6.  **Inference Execution**: Run `generate_submission` in debug mode. This tests the loading of the saved checkpoint, Test-Time Augmentation (TTA), ensemble logic, and the generation of the final CSV submission file.
7.  **Assertions**: Throughout the script, use assertions to validate shapes, file existence, and data integrity, ensuring the logic is correct.
