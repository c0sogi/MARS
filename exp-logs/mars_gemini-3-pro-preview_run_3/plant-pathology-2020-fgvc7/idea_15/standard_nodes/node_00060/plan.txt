Implementation strategy:
1.  **Configuration & Setup**: Import necessary modules and the provided library. Override `Config.EPOCHS` to a reasonable number (e.g., 15) to ensure the "fast baseline" constraint is met while allowing convergence. Set random seeds.
2.  **Data Loading**: Use `get_dataloaders` to load the stratified training and validation sets.
3.  **Training Loop**: Iterate through the defined `Config.BACKBONES` (EfficientNetV2-M and Swin-Small). For each backbone, invoke `train_fold` to train the model on the training set and save the best checkpoint (based on validation AUC) to the working directory.
4.  **Ensemble Validation**:
    *   Load the best saved checkpoints for all backbones.
    *   Perform inference on the validation set using the ensemble (averaging predictions).
    *   Calculate the "Mean Column-wise ROC AUC" using `calculate_roc_auc`.
    *   Print the result in the strict format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the error magnitude for each validation sample (Mean Absolute Error between prediction and ground truth).
    *   Extract simple image features (Mean Brightness, Contrast/StdDev) for each validation image.
    *   Compute and print the Pearson correlation between the error magnitude and these image features to identify systematic weaknesses.
6.  **Submission**:
    *   Check if the validation metric is valid (ignoring the likely erroneous "> 1.0" instruction in favor of a sanity check like > 0.5).
    *   Use `generate_submission` from `library.inference` to predict on the test set using the ensemble and save `submission.csv`.
