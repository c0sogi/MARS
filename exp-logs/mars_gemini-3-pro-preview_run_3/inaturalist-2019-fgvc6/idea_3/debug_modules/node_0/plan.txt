This script demonstrates the end-to-end usage of the provided library components for the iNaturalist species classification task. It performs the following steps:
1.  **Configuration**: Overrides the default `Config` to enable `DEBUG` mode (using a small subset of data) and adjusts hyperparameters (batch size, epochs, image size) for rapid execution.
2.  **Data Loading**: Uses `get_loaders` to create training, validation, and test dataloaders, verifying the batch dimensions and data integrity.
3.  **Model Initialization**: Instantiates a lightweight model (`resnet18`) using `get_model` to ensure quick initialization and low memory usage, verifying it is placed on the correct device.
4.  **Training**: Runs `train_one_epoch` to demonstrate the training loop with Mixup augmentation, asserting that loss and accuracy metrics are computed correctly.
5.  **Validation**: Executes `validate` to evaluate the model on the validation set, ensuring metrics are returned.
6.  **Inference**: Runs `predict` to generate predictions on the test set, verifying that the output submission CSV is created with the correct format and row count.
