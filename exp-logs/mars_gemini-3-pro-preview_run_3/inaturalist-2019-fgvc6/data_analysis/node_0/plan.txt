I will implement a Python script to perform Exploratory Data Analysis (EDA) on the training dataset.

**Strategy:**
1.  **Setup & Loading**: I will load the `train_metadata.csv` file to access the training set structure without touching the validation/test sets to prevent leakage.
2.  **Target Variable Analysis**: I will analyze the `category_id` column to report the number of classes, the distribution of samples per class (identifying the "long tail" typical of iNaturalist datasets), and the class balance ratio.
3.  **Image Data Analysis**:
    *   Since processing all ~186k images is computationally expensive and time-consuming, I will sample a representative subset (e.g., 2,500 images) to estimate dataset statistics.
    *   I will iterate through this sample to collect image dimensions (Height, Width), Aspect Ratios, and Channel counts.
    *   I will compute the global pixel mean and standard deviation using the sample.
4.  **Meta-Feature Analysis**:
    *   I will parse the `file_name` to extract the "Super Category" (e.g., 'Birds', 'Reptiles', 'Plants') which is the top-level directory in the path.
    *   I will analyze the relationship between these super-categories and image properties (e.g., do 'Birds' have different aspect ratios compared to 'Plants'?).
5.  **Reporting**: The results will be printed to standard output in the specified format, ensuring all floating-point numbers are formatted to 4 decimal places.
