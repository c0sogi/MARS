The issue is caused by an API change in XGBoost 3.0+, where the `early_stopping_rounds` parameter was removed from the `.fit()` method and must now be passed to the `XGBClassifier` constructor instead. To fix this, I will modify `library/model.py` to add `early_stopping_rounds` to the model parameters during initialization in `__init__` and remove the argument from the `fit` method call. This applies the knowledge from Cite debug_lesson_1 regarding the migration of early stopping configuration.
