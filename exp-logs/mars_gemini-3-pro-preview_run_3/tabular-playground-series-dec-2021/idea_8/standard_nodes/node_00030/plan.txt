Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Configuration & Setup**: Import necessary modules and the provided library files (`config`, `data_loader`, `trainer`). Set the device to CUDA (A100) for acceleration.
2.  **Data Loading**: Use `data_loader.get_dataloaders(load_cached_data=True)` to efficiently load the pre-processed training, validation, and test sets.
3.  **Model Training**: Initialize the `Trainer` class from `library.trainer`. Execute the training loop for the full 60 epochs defined in the configuration to ensure the Stochastic Weight Averaging (SWA) strategy is effective. The A100 GPU is sufficient to complete this within the time limit.
4.  **SWA Validation**: After training, retrieve the averaged SWA model from the trainer's handler. Perform a dedicated validation pass using this specific model (as opposed to the last epoch's model) to calculate the `Final Validation Metric`.
5.  **Failure Analysis**: Using the SWA model's predictions on the validation set, calculate the binary error (correct/incorrect). Compute and print the correlation between this error signal and the input features to identify systematic weaknesses.
6.  **Conditional Submission**: Compare the calculated validation accuracy against the strict threshold (`0.9625041666666667`). If the model passes, trigger the `trainer.predict()` method to generate and save `submission.csv`.
