This script demonstrates the usage of the provided library files to train a model and generate predictions for the Forest Cover Type dataset.

**Implementation Strategy:**
1.  **Configuration Setup**: We import the `Config` class and override specific parameters (like `EPOCHS`, `BATCH_SIZE`, and model dimensions) to ensure the script runs quickly (within minutes) while still exercising all code paths. We also set the random seed for reproducibility.
2.  **Data Pipeline**: We utilize `get_dataloaders` with `max_samples=1000` and `load_cached_data=False`. This forces the script to perform feature engineering and normalization on a small subset of the data, verifying the data processing logic without the overhead of the full 3M+ row dataset.
3.  **Model Verification**: We verify the `ParallelDCNResNet` architecture by manually instantiating it and passing a dummy batch through it to ensure the input/output shapes are correct.
4.  **Training**: We execute the full training loop using `run_training`. Thanks to the overridden configuration, this runs a minimal number of epochs.
5.  **Inference**: We generate predictions using `generate_predictions`. We ensure the test IDs are sliced to match the subsampled data to avoid length mismatch errors during submission file generation.
6.  **Validation**: Finally, we assert that the submission file exists and follows the required format.
