Implementation strategy:
1.  **Configuration**: Import the provided `Config` and override `Config.EPOCHS` to 20. This balances the need for high accuracy (using the full dataset) with the requirement for a fast baseline execution within the time limit.
2.  **Data Loading**: Use `get_dataloaders` with `debug=False` to load the full dataset, ensuring the model has enough data to reach the target metric (>0.9625).
3.  **Model Initialization**: Instantiate the `ParallelLowRankDCNResNet` using the input dimension derived from the data loader.
4.  **Training**: Execute the training loop using `run_training`, which manages the optimizer, Cosine Annealing scheduler, and early stopping.
5.  **Validation**: Perform a final validation pass to compute and print the exact `Final Validation Metric`.
6.  **Failure Analysis**:
    *   Reconstruct feature names by processing a small sample of the raw data.
    *   Compute predictions on the validation set.
    *   Calculate the Pearson correlation between the binary error vector (1 for incorrect, 0 for correct) and each input feature.
    *   Print the top features most correlated with model failure.
7.  **Submission**: Check if the validation accuracy exceeds the strict threshold. If so, generate predictions on the test set and save `submission.csv`.
