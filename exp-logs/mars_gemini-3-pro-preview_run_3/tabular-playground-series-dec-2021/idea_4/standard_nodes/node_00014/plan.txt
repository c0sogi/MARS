The implementation strategy is as follows:

1.  **Setup & Initialization**: Set random seeds for reproducibility and detect the available computation device (GPU/CPU).
2.  **Data Loading**: Utilize the provided `load_and_preprocess` function to load the training, validation, and test datasets. We will leverage the caching mechanism to speed up this step.
3.  **Unsupervised Pretraining (DAE)**:
    *   Combine features from Train, Validation, and Test sets to form a large unlabeled dataset.
    *   Initialize the `DenoisingAutoencoder` and wrap the data in `DAEDataset` (which applies swap noise).
    *   Train the DAE using `train_dae` to learn robust latent representations of the data manifold.
4.  **Supervised Fine-tuning (Classifier)**:
    *   Extract the pretrained `encoder` from the DAE.
    *   Initialize the `ResNetClassifier` using this encoder.
    *   Create `CoverTypeDataset` for the labeled training and validation sets.
    *   Train the classifier using `train_classifier`, which includes early stopping based on validation accuracy.
5.  **Evaluation & Failure Analysis**:
    *   Perform inference on the full validation set to compute the final accuracy.
    *   Calculate the correlation between the error vector (incorrect predictions) and input features to identify failure modes.
6.  **Submission**:
    *   Compare the validation accuracy against the required threshold (0.9622416666666667).
    *   If the threshold is met, generate predictions for the test set, map the class indices back to the original labels (1-7), and save the `submission.csv`.
