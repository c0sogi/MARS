Implementation Strategy:
1.  **Setup**: Initialize the environment, set random seeds for reproducibility, and detect the computation device (GPU).
2.  **Data Loading**: Use the provided `get_dataloaders` function to load the preprocessed training, validation, and test datasets. This function handles feature engineering and caching automatically. We utilize the full dataset to ensure the high accuracy requirement is met, relying on the A100 GPU for speed.
3.  **Model Initialization**: Instantiate the `DeepPreActDCNResNet` model. The input dimension is automatically inferred from the data loading step via the shared `Config`.
4.  **Training**: Initialize the `Trainer` class and execute the training loop using `trainer.fit()`. This handles the optimization (AdamW), scheduling (ReduceLROnPlateau), and early stopping.
5.  **Validation**: After training, evaluate the model on the full validation set to compute the final accuracy metric.
6.  **Failure Analysis**:
    *   Generate predictions for the validation set.
    *   Compute the error vector (binary: 1 for incorrect, 0 for correct).
    *   Calculate the Pearson correlation between each input feature and the error vector to identify features associated with poor performance.
    *   Print the top 5 correlated features.
7.  **Submission**: Compare the final validation accuracy against the strict threshold (0.962504...). If the threshold is exceeded, generate predictions for the test set using `trainer.predict()` and save them to `submission.csv`.
