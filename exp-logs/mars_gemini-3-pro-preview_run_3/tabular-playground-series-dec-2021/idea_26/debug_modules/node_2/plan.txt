The issue is that the `Trainer.predict` method uses `Config.SUBMISSION_PATH` as a default argument, which is evaluated only once when the module is imported (Cite debug_lesson_10). Consequently, the runtime configuration override in `runfile.py` is ignored, and the submission file is saved to the default location instead of the expected demo directory. The fix is to change the default argument to `None` and resolve `Config.SUBMISSION_PATH` dynamically within the function body.
