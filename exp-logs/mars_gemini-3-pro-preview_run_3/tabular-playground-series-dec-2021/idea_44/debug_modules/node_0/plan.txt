Here is the implementation strategy:

1.  **Environment Setup**: Import necessary modules and the provided library components. Set a fixed random seed for reproducibility.
2.  **Data Subsetting**: Create a temporary directory in `./working` to store a small subset of the training, validation, and test data. This ensures the demonstration runs quickly without processing the full multi-million row dataset. We will read a small sample from the original parquet files and save them to this new location.
3.  **Configuration Override**: Monkey-patch the `Config` class to point to the new subset data paths, reduce the number of epochs to 1, set a small batch size, and define a temporary cache directory. This forces the provided library code to use our lightweight environment.
4.  **Component Verification**:
    *   **Data Loading**: Verify `engineer_features` adds the expected columns and `ForestDataset` yields tensors of the correct shape.
    *   **Model**: Instantiate `AsymmetricParallelNet`, pass a dummy input batch, and assert the output shape matches `(batch_size, num_classes)`.
5.  **Pipeline Execution**: Run the full training and inference pipeline using the subset data. This demonstrates `get_dataloaders`, `train_model`, `inference`, and `save_submission` working together.
6.  **Final Validation**: Check that the submission file is generated correctly and clean up temporary directories.
