The `AssertionError` is caused by Python's behavior regarding default argument evaluation. The `save_submission` function in `library/utils.py` uses `Config.SUBMISSION_FILE` as a default value for the `output_path` argument. Since default arguments are evaluated only once at function definition time (when the module is imported), the function captures the initial configuration path (`./submission/submission.csv`). Consequently, when `runfile.py` later updates `Config.SUBMISSION_FILE` to point to the demo directory, `save_submission` continues to use the stale, originally captured path, causing the file to be saved in the wrong location and the existence check to fail. To fix this, I will change the default value of `output_path` to `None` and resolve `Config.SUBMISSION_FILE` dynamically within the function body, ensuring the current runtime configuration is always respected.
