The following script demonstrates the usage of the provided library modules for the Forest Cover Type prediction task. 

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to point to a temporary directory and use minimal hyperparameters (e.g., `EPOCHS=2`, `BATCH_SIZE=16`) to ensure the demonstration runs almost instantly.
2.  **Synthetic Data Generation**: Instead of loading the large 3.6M row dataset, we generate a small synthetic dataset (100 samples) with the exact schema required (Numerical features, Soil Types, Wilderness Areas). This validates the data pipeline without the I/O overhead.
3.  **Component Verification**:
    *   **Data Loader**: We verify that `get_dataloaders` correctly processes features, handles scaling, and returns tensors of the expected shape.
    *   **Model**: We instantiate `TriBranchWDCNet` and perform a forward pass with a dummy batch to verify architecture validity and output dimensions.
    *   **Training Loop**: We initialize the `Trainer` and run a short training cycle (2 epochs) to verify the optimization step, loss calculation, and early stopping logic.
    *   **Inference & Submission**: We run inference on the test set and use `save_submission` to generate a valid CSV, checking the file format programmatically.
