The following implementation demonstrates the usage of the provided library modules (`config`, `model`, `data_utils`, `train_eval`) to train a Gated Residual Network (GRN) on the Cover Type dataset.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class at runtime to enable `DEBUG` mode. This limits the dataset to 2,000 rows and reduces the number of epochs to 2, ensuring the script executes quickly (typically under a minute) while still exercising the full pipeline. We also redirect output paths to a temporary `./working/demo_task` directory to avoid conflicts.
2.  **Component Verification**:
    *   **Model Logic**: We instantiate the model using `build_model` and perform a forward pass with dummy data to verify the architecture and output shape.
    *   **Data Pipeline**: We invoke `get_dataloaders` to verify that data is correctly loaded, preprocessed, and batched.
3.  **Full Training Loop**: We execute `train_model` to run the end-to-end training process, including feature engineering, training, validation, and prediction.
4.  **Output Validation**: We explicitly check for the existence of the saved model and submission file, and verify that the submission file follows the expected format.
