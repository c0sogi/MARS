Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Import necessary libraries and the provided `library` modules. Override `Config.EPOCHS` to 12 to ensure the training completes within the "fast baseline" time limit while providing sufficient convergence for the high accuracy threshold. Set random seeds and detect the compute device.
2.  **Data Loading**: Use `get_dataloaders(load_cached_data=True)` to efficiently load the training, validation, and test sets. This leverages the cached preprocessed `.npy` files if they exist, saving significant time.
3.  **Model Initialization**: Instantiate the `DualViewDCNResNet` model with the correct input dimensions and move it to the GPU (A100).
4.  **Training**: Initialize the `Trainer` class and execute the `fit()` method. This handles the training loop, loss annealing, validation monitoring, and saving the best model checkpoint.
5.  **Evaluation**: Load the best model checkpoint. Perform inference on the full validation set to calculate the overall accuracy.
6.  **Metric Reporting**: Print the required `Final Validation Metric: <value>` string.
7.  **Failure Analysis**: Compare predictions with targets to identify errors. Calculate the Pearson correlation between the binary error vector (1 for error, 0 for correct) and each input feature to identify which features are most associated with model failure.
8.  **Submission**: Check if the validation accuracy exceeds the threshold (0.962629...). If successful, generate predictions for the test set (mapping class indices back to 1-7), format them into a DataFrame, and save the `submission.csv` file.
