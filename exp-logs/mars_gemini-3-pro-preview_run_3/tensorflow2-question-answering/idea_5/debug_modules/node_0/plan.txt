The following code demonstrates the complete pipeline for the Natural Questions task using the provided library files. It includes:

1.  **Configuration Setup**: Overrides default paths and hyperparameters to use a temporary directory and execute quickly (e.g., fewer epochs, small data subsets).
2.  **Text Processing Verification**: Validates tokenization and HTML tag stripping functions.
3.  **Feature Engineering Verification**: Tests the BM25 and feature extraction logic on dummy data.
4.  **Ranker Model**: Builds a small dataset from the training metadata, trains the LightGBM ranker, and verifies predictions.
5.  **Reader Model**: Builds a small dataset, trains the Bi-GRU reader for one epoch, and verifies model artifacts.
6.  **Full Inference Pipeline**: Generates a submission file for a subset of the test data using the trained models.
