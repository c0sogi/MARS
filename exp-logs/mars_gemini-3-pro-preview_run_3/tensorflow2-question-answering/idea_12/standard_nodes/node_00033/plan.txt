This script orchestrates the full pipeline for the 2D Ranker and 1D Reader architecture. It begins by setting up the environment and building the vocabulary. It then proceeds to train both the Ranker and Reader models using a subset of the data to ensure execution within the time limit. After training, it performs a comprehensive validation on the hold-out set, chaining the Ranker and Reader to predict answers and comparing them against ground truth to calculate the Micro F1 score. A failure analysis follows, correlating prediction errors with input sequence lengths. Finally, it executes the inference pipeline on the test set to generate the `submission.csv` file.
