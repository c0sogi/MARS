Implementation Strategy:
1.  **Configuration & Setup**: Override `TrainingConfig` to ensure a fast execution (1 epoch, small training subset of 2000 samples) to fit within the time limit while demonstrating functionality. Set random seeds for reproducibility.
2.  **Training**: Invoke `library.train.run_training()` to train the Ranker and Reader models using the provided data loaders and training loop.
3.  **Validation & Failure Analysis**:
    *   Implement a custom validation loop `validate_and_analyze` that iterates over the full validation metadata.
    *   Load the raw data using byte offsets.
    *   Perform inference: Rank candidates using the trained Ranker, then extract answers from the top candidate using the Reader.
    *   Compute metrics: Calculate True Positives, False Positives, and False Negatives for both Long and Short answers to compute the global Micro F1 score.
    *   Perform Failure Analysis: Record error status (1 for error, 0 for correct) along with document and question lengths. Compute and print Pearson correlations between errors and these features.
    *   Print the `Final Validation Metric` as required.
4.  **Submission**: Call `library.evaluate.predict_submission()` to generate predictions for the test set and save them to `submission.csv`.
