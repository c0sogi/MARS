This script demonstrates the end-to-end usage of the provided Natural Questions library. It performs the following steps:

1.  **Configuration Override**: Modifies the `Config` class to use a small subset of data and fewer epochs for rapid execution.
2.  **Model Verification**: Instantiates the `SiameseDANRanker` and `ShallowCNNReader` models with dummy data to verify input/output tensor shapes and forward pass logic.
3.  **Training Pipeline**: Initializes the `Trainer` class with a debug sample size, triggering data loading, vocabulary building, and the training loop for both the Ranker and Reader models. It verifies that model checkpoints are saved.
4.  **Inference Pipeline**: Initializes the `NQPipeline`, loads the trained models, runs inference on a subset of the test data, and generates a submission file.
5.  **Output Verification**: Validates the format and content of the generated submission CSV.
