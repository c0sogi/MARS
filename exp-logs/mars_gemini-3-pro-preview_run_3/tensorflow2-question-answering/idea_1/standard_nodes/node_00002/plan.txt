The issue is that the `InferenceDataset` retrieves the `example_id` from the metadata CSV row (`row["example_id"]`), which appears to be corrupted or misinterpreted during loading, leading to malformed entries in the submission file (e.g., containing text with commas instead of a clean ID). The fix is to extract the `example_id` directly from the source JSON object (`data["example_id"]`) loaded from the file, which is the reliable source of truth.
