The issue stems from Python's default argument evaluation, where the `Tokenizer` and `EmbeddingLoader` classes bind `Config` values (like `VOCAB_SIZE=40000`) at import time. To fix this, I will update the factory functions `get_tokenizer` and `get_embedding_matrix` in `library/preprocessing.py` to explicitly pass the current `Config` values during instantiation, ensuring the runtime configuration is respected.
