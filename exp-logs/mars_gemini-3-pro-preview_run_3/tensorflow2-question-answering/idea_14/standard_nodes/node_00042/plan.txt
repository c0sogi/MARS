This metadata CSV likely contains parsing errors or unescaped characters, which propagate into the submission file, causing CSV parsing errors during grading. Additionally, the pipeline is loading cached test data that contains these corrupted IDs.

To fix this, I will modify `library/data_factory.py` to extract the `example_id` directly from the raw JSON record and sanitize it by removing commas and newlines (Cite debug_lesson_1, debug_lesson_4).
