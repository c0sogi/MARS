The implementation strategy for `runfile.py` is as follows:

1.  **Setup & Configuration**: Initialize the `Config` class. Modify hyperparameters (e.g., `DEBUG_SAMPLE_SIZE = 5000`, `EPOCHS = 2`) to ensure the training completes quickly as a baseline. Set random seeds for reproducibility.
2.  **Training**: Instantiate `RankerTrainer` and `ReaderTrainer`. Call their `train()` methods with `load_cached_data=False` to ensure the models are trained on the configured subset of data.
3.  **Validation**:
    *   Load the validation metadata.
    *   Iterate through the **entire** validation set.
    *   For each example, retrieve the ground truth annotations (Long Answer spans and Short Answer spans/Yes-No).
    *   Use the `QuestionAnsweringPredictor` to generate predictions.
    *   Compare predictions against ground truth to accumulate True Positive, False Positive, and False Negative counts for both long and short answers.
    *   Compute the global **Micro F1** score and print it.
4.  **Failure Analysis**:
    *   During the validation loop, collect metadata (Question Length, Document Length) and error status (Correct/Incorrect) for each sample.
    *   Compute and print the correlation between error magnitude and these features.
    *   Analyze error rates specifically for samples that *should* have had an answer.
5.  **Submission**: Call the `generate_submission()` method of the `QuestionAnsweringPredictor` to produce the `submission.csv` file for the test set.
