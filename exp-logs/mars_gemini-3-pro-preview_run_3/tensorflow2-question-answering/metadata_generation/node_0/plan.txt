The implementation strategy involves the following steps:

1.  **Setup and Configuration**: Define input and output directories and file names. Ensure the output directory `./metadata` exists.
2.  **Data Parsing**: Implement a function to read the large JSONL files line-by-line. To handle the large file size efficiently and allow for quick data loading later, the script will capture the **byte offset** of each record.
    *   For the training set, parse the `annotations` field to derive ground-truth labels. Create a `stratify_label` based on whether the example has a short answer, only a long answer, or no answer.
    *   For the test set, extract `example_id` and store the file path and offset.
3.  **Dataset Splitting**: Load the parsed training metadata into a Pandas DataFrame. Use `train_test_split` with `stratify` on the derived label to create an 80/20 train/validation split, ensuring the `RANDOM_STATE` is fixed at 42.
4.  **Metadata Persistence**: Save the resulting DataFrames (Train, Validation, Test) as CSV files in the `./metadata` directory.
5.  **Validation**:
    *   **Statistics**: Print counts and label distributions for all sets.
    *   **File Path Check**: Randomly sample 1000 paths from each metadata file and verify they resolve to existing files in `./input`. Raise an error if the failure rate > 0.5.
    *   **Stratification Check**: Compare the label distribution of the training and validation sets to ensure they are similar (within a small tolerance). Raise an `AssertionError` if they diverge significantly.
