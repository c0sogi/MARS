The following script demonstrates the usage of the provided library components for the lung function decline prediction task. It validates the data loading pipeline, the model architecture, the custom metric, and executes a simplified training and inference workflow.

The strategy involves:
1.  **Configuration Override**: Modifying `Config` parameters (epochs, batch size) to ensure the script runs quickly within the demo environment.
2.  **Component Verification**:
    *   **Data**: Inspecting a batch from the `DataLoader` to verify tensor shapes and metadata.
    *   **Metric**: validating the `laplace_log_likelihood` function against a manually calculated value.
    *   **Model**: Instantiating `SCOSRNet` and performing a forward pass to check output dimensions and value ranges.
3.  **Workflow Execution**: Running a single epoch of training using `train_one_epoch`, performing validation, saving the model, and generating predictions using `run_inference`.
