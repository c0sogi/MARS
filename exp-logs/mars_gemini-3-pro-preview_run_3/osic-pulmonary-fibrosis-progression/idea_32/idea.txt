Based on the comprehensive analysis of the accumulated lessons, I propose the **Output-Space Probabilistic Residual Network (OSPR-Net)**.

This solution represents a structural synthesis of the **Dual-Stream** architecture (**Cite solution_lesson_node_00052**) and **Over-Parameterized Clinical Anchors** (**Cite solution_lesson_node_00060**), while introducing a novel **Output-Space Zero-Initialization** strategy. This approach explicitly resolves the initialization instability identified in Latent Fusion models (**Cite solution_lesson_node_00118**) and the capacity bottlenecks of previous additive models (**Cite solution_lesson_node_00060**), ensuring the model behaves as a robust clinical regressor that is progressively fine-tuned by deep visual residuals.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Dual-Stream Output-Space Summation** topology. Unlike previous latent fusion models, this design sums the predictions of two independent branches in the final output space ($\mu, \sigma$), allowing for precise initialization control.

*   **Stream A: Over-Parameterized Clinical Anchor (The Prior):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to avoid proxy leakage (**Cite solution_lesson_node_00069**, **Cite solution_lesson_node_00098**).
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64) -> Linear(64 -> 2)`).
    *   **Outputs:** Raw Mean ($\mu_{clin}$) and Raw Uncertainty ($\sigma_{clin\_raw}$).
    *   **Purpose:** This stream learns the baseline disease trajectory. By using an MLP instead of a single linear layer, we ensure sufficient capacity to model the identity mapping and linear decay without optimization bottlenecks (**Cite solution_lesson_node_00060**).

*   **Stream B: Visual Residual Stream (The Correction):**
    *   **Image Backbone:** **EfficientNet-B2**. Selected for its balance of texture resolution (260x260) and parameter efficiency, avoiding the underfitting of B0 (**Cite solution_lesson_node_00071**) and overfitting of V2-S (**Cite solution_lesson_node_00054**).
    *   **Fine-Tuning:** Unfreeze top two stages; keep bottom frozen (**Cite solution_lesson_node_00027**).
    *   **Fusion:** Concatenate Global Average Pooled image features with the clinical inputs (**Early Fusion** within this stream) to capture cross-modal interactions like "Fibrosis $\times$ Time" (**Cite solution_lesson_node_00032**, **Cite solution_lesson_node_00103**).
    *   **Architecture:** An **MLP** projecting the fused vector to 2 outputs: $\delta_\mu$ and $\delta_\sigma$.
    *   **Structural Innovation (Zero Initialization):** The weights and biases of the **final Linear layer** of this stream are explicitly initialized to **zero**.
    *   **Purpose:** This forces the visual stream to output exactly 0 correction at epoch 0. Unlike latent zero-initialization (which fails because the parallel branch is random, **Cite solution_lesson_node_00118**), output-space zero-initialization is stable because Stream A provides a valid, trained gradient path from the start.

*   **Probabilistic Output Fusion:**
    *   **Mean:** $\mu_{final} = \mu_{clin} + \delta_\mu$.
    *   **Uncertainty:** $\sigma_{final} = \text{Softplus}(\sigma_{clin\_raw} + \delta_\sigma) + \epsilon$.
    *   **Rationale:** This structure ensures uncertainty estimation has a direct, low-complexity pathway from the clinical priors (**Cite solution_lesson_node_00055**), while allowing the image stream to learn heteroscedastic corrections (e.g., increasing uncertainty for noisy scans).

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply standard **Lung Window (Level: -600 HU, Width: 1500 HU)**. Reject arbitrary clipping (**Cite solution_lesson_node_00090**).
    *   **Content-Adaptive Slice Selection:** Select "Anchor" slice (Max Lung Area) and two boundary slices (50% area) (**Cite solution_lesson_node_00015**).
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. Do **not** Z-score, preserving the zero origin (**Cite solution_lesson_node_00036**).
    *   **Feature Encoding:** Use **Ordinal Encoding** for `SmokingStatus` (0, 1, 2) (**Cite solution_lesson_node_00103**).
    *   **Normalization:** Target `FVC` is Z-score standardized (**Cite solution_lesson_node_00001**). Input scalars are standardized but passed **raw** (no Batch Norm) (**Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**).

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   Explicitly includes $\sqrt{2}$ constants to correct systematic uncertainty underestimation (**Cite solution_lesson_node_00066**).
*   **Uncertainty Constraints:**
    *   Do **not** enforce the metric's 70ml clip in the architecture (**Cite solution_lesson_node_00014**).
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs (**Cite solution_lesson_node_00100**).
    *   **Differential Learning Rates:** `1e-4` (Backbone) vs `1e-3` (Heads) (**Cite solution_lesson_node_00027**).
    *   **Batch Size:** Strictly $\ge 32$ (**Cite solution_lesson_node_00094**).
    *   **Duration:** **50 Epochs** (**Cite solution_lesson_node_00011**).

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$ for each test week.
    *   Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via OSPR-Net.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) (**Cite solution_lesson_node_00006**).
*   **Post-Processing:**
    *   Apply hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for submission (**Cite solution_lesson_node_00014**).
