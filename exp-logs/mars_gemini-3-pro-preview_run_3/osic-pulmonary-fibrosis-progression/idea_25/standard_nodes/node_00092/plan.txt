The implementation strategy follows the provided requirements to orchestrate the Cascaded Clinical-Visual Residual Network (CCVR-Net) pipeline.

1.  **Configuration**: We override `Config.EPOCHS` to 20 to ensure the training completes quickly while allowing sufficient convergence for a baseline check. We disable debug mode to use the full dataset.
2.  **Training**: We utilize `library.train.train_model` to handle the training loop, validation monitoring, and checkpointing of the best model based on the metric.
3.  **Validation**: We load the best checkpoint and perform inference on the hold-out validation set. We compute the `laplace_log_likelihood` metric and print it in the required format.
4.  **Failure Analysis**: We calculate the absolute error of predictions on the validation set and compute correlations with key clinical features (Age, Weeks, Baseline FVC, etc.) to identify error sources.
5.  **Submission**: If the validation metric exceeds the specified threshold, we generate predictions for the test set, apply the required post-processing (clipping sigma at 70ml), and save the `submission.csv` file.
