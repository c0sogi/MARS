1.  **Latent Fusion Architecture (Cite `solution_lesson_node_00052`, `solution_lesson_node_00060`):**
    The previous solution fused the streams at the *output* level (summing predictions). I will switch to **Latent Fusion**, where the Linear Stream (Stream A) and the Deep Stream (Stream B) project to a shared latent space (64-dim) before being summed and passed to a shared head. This allows the model to learn a richer interaction between the dominant linear baseline and the non-linear residuals before committing to the final scalar outputs.

2.  **Over-Parameterized Linear Stream (Cite `solution_lesson_node_00060`):**
    I will modify Stream A to be a direct `Linear(5, 64)` projection (without ReLU). This creates an over-parameterized linear pathway that can robustly capture the strong autoregressive signal (Baseline FVC + Time) without being bottlenecked by low dimensionality or distorted by non-linearities.

3.  **Extended Training Duration (Cite `solution_lesson_node_00100`):**
    I will increase the training epochs from 20 to 30. The previous solution showed signs of premature stopping/plateauing, and lesson 100 highlights the importance of linking the scheduler horizon to a sufficient training duration to allow convergence in regression tasks.

    Standardized Constraint-Aware Residual Network (Latent Fusion Variant).
    Fuses a linear stream and a deep stream in a shared latent space before final projection.
    """

    def __init__(self):

        # 1. Image Branch
        self.image_branch = ImageBranch()

        # Clinical features dimension is 5:
        # [Baseline_FVC_Scaled, Time_Scaled, Age_Scaled, Sex_Code, Smoking_Code]
        self.clinical_dim = 5

        # Input: Image Projection (64) + Clinical (5)
        self.stream_b_input_dim = Config.PROJECTION_DIM + self.clinical_dim
        self.stream_b = StreamB(input_dim=self.stream_b_input_dim)

        # Projects fused latent (64) to Output (2)
        self.head = nn.Linear(Config.PROJECTION_DIM, Config.OUTPUT_DIM)

        self.sigma_floor = Config.SIGMA_FLOOR_STD

    def forward(self, images, tabular):

        Args:
            images (torch.Tensor): Batch of images (B, 3, H, W)
            tabular (torch.Tensor): Batch of clinical features (B, 5)
        Returns:
            preds (torch.Tensor): (B, 2) -> [mu_scaled, sigma_scaled]

        # Summing the latent vectors allows the linear stream to provide a robust base
        # while the deep stream adds non-linear corrections.
        h_fused = h_linear + h_deep

        mu_scaled = mu_raw
        sigma_scaled = F.softplus(sigma_raw) + self.sigma_floor

        preds = torch.cat([mu_scaled, sigma_scaled], dim=1)
