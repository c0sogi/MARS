Based on the comprehensive analysis of the accumulated lessons, I propose the **Standardized Constraint-Aware Residual Network (SCAR-Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream** topology **Cite solution_lesson_node_00052** with critical corrections for **Metric Alignment** **Cite solution_lesson_node_00164**, **Optimization Stability** **Cite solution_lesson_node_00165**, and **Dimensionality Balance** **Cite solution_lesson_node_00146**. It explicitly resolves the conflict between regularization and signal preservation **Cite solution_lesson_node_00126** by replacing stochastic dropout with strict capacity bottlenecks, and ensures physical consistency via **Standardized Constraint Enforcement**.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Output-Space Summation** topology.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. Selected for its balance of native resolution (260x260) and parameter efficiency, avoiding the underfitting of B0 **Cite solution_lesson_node_00071** and the overfitting of V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** Unfreeze the top two convolutional stages; keep lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** **Global Average Pooling** from the final layer.
    *   **Bottleneck Projection:** The high-dimensional output (1408-dim) is immediately projected to **64 dimensions** via a Linear layer. This acts as a structural regularizer, preventing high-dimensional image noise from statistically dominating the fusion layer **Cite solution_lesson_node_00146**.

*   **Stream A: Over-Parameterized Clinical Anchor (The Foundation):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to prevent proxy leakage **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64) -> Linear(64 -> 2)`).
    *   **Outputs:** Base Mean ($\mu_{base}$) and Base Uncertainty ($\sigma_{base\_raw}$).
    *   **Purpose:** This stream learns the baseline disease trajectory ($FVC(t) \approx Base + Rate \times t$). The MLP provides sufficient capacity to model linear trends without optimization bottlenecks **Cite solution_lesson_node_00060**.

*   **Stream B: Context-Injected Visual Residual (The Correction):**
    *   **Input:** Concatenation of [**Projected Image (64-dim)**, **Raw Clinical Scalars**].
    *   **Context Injection:** By providing raw scalars (Baseline FVC, Time) directly to this stream, we ensure the deep branch is conditioned on the patient's initial severity, allowing it to learn patient-specific residuals **Cite solution_lesson_node_00139**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 128) -> ReLU -> Linear(128 -> 64) -> Linear(64 -> 2)`).
    *   **Outputs:** Residuals $\delta_\mu, \delta_{\sigma\_raw}$.
    *   **Regularization:** We explicitly **exclude Dropout**. Since this stream learns a weak residual correction, stochastic regularization drowns out the gradient signal. We rely on the **Bottleneck Projection** (64-dim) to limit capacity and prevent overfitting **Cite solution_lesson_node_00126**.
    *   **Initialization:** We use **Standard Random Initialization**. We reject Zero-Initialization for this branch because the parallel Stream A is a learnable projection, making zero-init unstable **Cite solution_lesson_node_00118**.

*   **Constraint-Aware Fusion:**
    *   **Mean:** $\mu_{scaled} = \mu_{base} + \delta_\mu$.
    *   **Uncertainty (Structural Innovation):**
        *   Calculate the standardized floor: $\epsilon_{std} = 70 / \sigma_{global\_target}$.
        *   $\sigma_{scaled} = \text{Softplus}(\sigma_{base\_raw} + \delta_{\sigma\_raw}) + \epsilon_{std}$.
    *   **Rationale:** By enforcing the metric's 70ml floor *architecturally* within the standardized space, we align the optimization landscape with the evaluation metric. This prevents the model from "cheating" the loss function by predicting $\sigma \to 0$ on easy samples, resolving the divergence between validation loss and metric score **Cite solution_lesson_node_00164**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Standard **Lung Window (Level: -600 HU, Width: 1500 HU)** **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select "Anchor" slice (Max Lung Area) and two boundary slices (50% area) **Cite solution_lesson_node_00124**.
    *   **Relative Time ($t_{rel}$):** $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. **No Z-score** **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** **Ordinal Encoding** for `SmokingStatus` **Cite solution_lesson_node_00103**.
    *   **Target Normalization:** Normalize targets using **Global Statistics** (all visits), not baseline statistics, to avoid covariate shift **Cite solution_lesson_node_00155**.
    *   **Input Normalization:** Input scalars are standardized but passed **raw** (no Batch Norm) **Cite solution_lesson_node_00017**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood (Standardized)**.
    *   $L = \frac{\sqrt{2} |y_{scaled} - \mu_{scaled}|}{\sigma_{scaled}} + \ln(\sqrt{2} \sigma_{scaled})$.
    *   We optimize in the standardized space to avoid gradient instability **Cite solution_lesson_node_00165** while explicitly including the $\sqrt{2}$ constants **Cite solution_lesson_node_00066**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` (Backbone) vs `1e-3` (Heads) **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly $\ge 32$ **Cite solution_lesson_node_00094**.
    *   **No Auxiliary Loss:** We train only on the final output to avoid conflicting objectives **Cite solution_lesson_node_00159**.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$. Predict $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{global} + \mu_{global}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{global}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for submission **Cite solution_lesson_node_00014**.
