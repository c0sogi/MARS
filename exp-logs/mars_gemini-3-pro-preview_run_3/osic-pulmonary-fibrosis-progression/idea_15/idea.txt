Based on the systematic analysis of the previous experiments and the derived lessons, I propose the **Explicit Additive Dual-Stream Network (EADS-Net)**.

This solution represents a structural evolution of the successful **Dual-Stream Point-Wise Residual** approach (Idea 13). While Idea 13 summed the "Wide" and "Deep" streams in a latent feature space, this new approach sums them in the **Output Space**. This explicitly decouples the learning of the robust linear trends (Base Decay, Uncertainty Growth) from the complex non-linear corrections, ensuring that the strong physical priors of the problem are not entangled with or obscured by the high-dimensional image representations.

### 1. Model
The architecture is a hybrid CNN-MLP that predicts lung function ($\mu$) and confidence ($\sigma$) for a specific time point $t$ by summing the outputs of two independent functional branches.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We retain the B2 variant as it offers the optimal balance between capturing fine-grained fibrotic textures and maintaining a parameter count feasible for this small dataset, avoiding the overfitting observed with heavier backbones like V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Projection:** The concatenated vector (3 slices) is projected to 128 dimensions via a learnable Linear layer **Cite solution_lesson_node_00008**.

*   **Stream A: The Wide Linear Branch (Robust Trend):**
    *   **Input:** `Baseline FVC` (Raw Standardized) and `Relative Time` ($t_{rel}$).
    *   **Architecture:** A single **Linear Layer** mapping inputs directly to 2 outputs: $[\mu_{wide}, \sigma_{wide}]$.
    *   **Purpose:** This branch explicitly learns the dominant linear physics of the problem:
        *   $\mu_{wide} \approx \alpha \cdot \text{Base} + \beta \cdot t$ (Autoregressive Decay).
        *   $\sigma_{wide} \approx \delta \cdot t + \epsilon$ (Time-Dependent Uncertainty Growth).
    *   By forcing this branch to output predictions directly (rather than latent codes), we guarantee the preservation of these strong linear signals **Cite solution_lesson_node_00052**, **Cite solution_lesson_node_00036**.

*   **Stream B: The Deep Interaction Branch (Non-Linear Correction):**
    *   **Input:** Concatenation of [Image Projection, Tabular Features, `Relative Time`].
    *   **Architecture:** A Multi-Layer Perceptron (MLP) mapping inputs to 2 outputs: $[\mu_{deep}, \sigma_{deep}]$.
    *   **Purpose:** This branch captures complex corrections (e.g., "Fibrosis accelerates decline") and patient-specific uncertainty adjustments **Cite solution_lesson_node_00032**.

*   **Explicit Additive Fusion:**
    *   **Mean:** $\mu_{final} = \mu_{wide} + \mu_{deep}$.
    *   **Uncertainty:** $\sigma_{final} = \text{Softplus}(\sigma_{wide} + \sigma_{deep}) + \epsilon$.
    *   **Rationale:** This structure ensures that the uncertainty estimate has a **direct, low-complexity pathway** from the time variable (via Stream A), preventing the instability observed when uncertainty was relegated solely to the deep branch **Cite solution_lesson_node_00055**.

### 2. Data
*   **Preprocessing:**
    *   **Content-Adaptive Slice Selection:** For each patient, select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency without geometric registration **Cite solution_lesson_node_00015**, **Cite solution_lesson_node_00012**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to ensure the linear branch correctly models "distance from origin" **Cite solution_lesson_node_00036**.
    *   **Target Standardization:** The target `FVC` is **Z-score standardized** during training to resolve the magnitude gap **Cite solution_lesson_node_00001**, **Cite solution_lesson_node_00006**.
    *   **Input Normalization:** `Baseline FVC` and `Age` are standardized but passed as raw scalars to the Wide Branch **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** Modified Laplace Log Likelihood ($L = \frac{|y - \mu|}{\sigma} + \ln(\sigma)$).
*   **Uncertainty Constraints:**
    *   We use a small numerical floor ($\epsilon=0.05$ scaled) for stability but **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream Heads. This ensures the pre-trained features are adapted gently while the new heads converge rapidly **Cite solution_lesson_node_00027**.
    *   **Duration:** **50 Epochs**. This extended duration is mandatory to allow the uncertainty estimation to calibrate **Cite solution_lesson_node_00011**.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via the additive fusion.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file.
