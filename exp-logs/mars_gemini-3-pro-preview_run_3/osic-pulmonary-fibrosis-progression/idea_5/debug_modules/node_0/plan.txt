The implementation strategy is as follows:

1.  **Configuration**: Initialize the environment by setting random seeds and adjusting the `Config` class to run in a lightweight "debug" mode (fewer epochs, small batch size, minimal data subset) to ensure rapid execution.
2.  **Data Pipeline Verification**: Manually instantiate the `LungDataset` and `DataLoaders` to verify that data is loaded, transformed, and batched correctly, asserting expected shapes and keys.
3.  **Model Logic Verification**: Instantiate the `WideAndDeepNet` model, perform a forward pass with the batch from the previous step, and assert that outputs (`mu`, `sigma`) have correct dimensions and valid values (e.g., positive sigma).
4.  **Metric Verification**: Compute the custom loss and competition metric using the model outputs to ensure the mathematical functions are operational and return finite values.
5.  **Full Pipeline Execution**: Call the high-level `run_training` function to simulate a complete training cycle (train, validate, save checkpoint, generate submission) and verify the final output file's existence and format.
