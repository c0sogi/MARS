Based on the comprehensive analysis of the accumulated lessons, I propose the **Metric-Calibrated Dual-Stream Residual Network (MCDSR-Net)**.

This solution represents a structural evolution of the high-performing **Dual-Stream** architecture (**Cite solution_lesson_node_00052**). It synthesizes the **Over-Parameterized Clinical Stream** (**Cite solution_lesson_node_00060**) and **Metric-Aligned Loss** (**Cite solution_lesson_node_00066**) while explicitly removing the **Time-Shortcut** that caused premature convergence in previous iterations (**Cite solution_lesson_node_00085**).

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Latent Summation** topology.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We select the B2 variant (native resolution 260x260) to ensure sufficient capacity for texture analysis, avoiding the underfitting of B0 (**Cite solution_lesson_node_00071**) and the overfitting of heavier models like V2-S (**Cite solution_lesson_node_00054**).
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection (**Cite solution_lesson_node_00027**).
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals (**Cite solution_lesson_node_00025**).
    *   **Projection:** The concatenated vector (3 slices) is projected to **64 dimensions** via a learnable Linear layer. We strictly constrain this dimension to prevent overfitting (**Cite solution_lesson_node_00065**).

*   **Stream A: Over-Parameterized Clinical Anchor:**
    *   **Input:** `Baseline FVC`, `Baseline Percent`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus`.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream learns the "Expected Clinical Trajectory" (Baseline + Decay). We use an MLP rather than a single layer to ensure the network has sufficient capacity to robustly map the linear trends into the latent space without optimization bottlenecks (**Cite solution_lesson_node_00060**). We include `Baseline Percent` (static) to capture normalized severity without leakage (**Cite solution_lesson_node_00069**).

*   **Stream B: Visual Interaction Stream:**
    *   **Input:** Concatenation of [Image Projection, `Baseline FVC`, `Baseline Percent`, $t_{rel}$, `Age`, `Sex`, `SmokingStatus`].
    *   **Architecture:** An **MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64)`).
    *   **Purpose:** This stream captures complex non-linear cross-modal interactions (e.g., "Fibrosis $\times$ Time") (**Cite solution_lesson_node_00032**).

*   **Latent Fusion & Shared Head:**
    *   **Fusion:** $H_{final} = \text{StreamA}_{output} + \text{StreamB}_{output}$. This summation enforces a residual learning paradigm where the visual stream corrects the robust clinical anchor (**Cite solution_lesson_node_00052**).
    *   **Head:** A single Linear layer projects $H_{final}$ to $\mu$ and $\sigma$.
    *   **Constraint:** We explicitly **remove the Time-Shortcut** (concatenating `|t|` at the head) used in Idea 22. Instead, we force the model to learn the time-dependent uncertainty through the deep layers of the streams, preventing the premature convergence to simple heuristics observed previously (**Cite solution_lesson_node_00085**). We use a shared head to ensure uncertainty estimation maintains a direct connection to the clinical priors (**Cite solution_lesson_node_00055**).

### 2. Data
*   **Preprocessing:**
    *   **Content-Adaptive Slice Selection:** For each patient, select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency (**Cite solution_lesson_node_00015**).
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline (**Cite solution_lesson_node_00036**).
    *   **Static Feature Extraction:** Use `Percent` from Week 0 as `Baseline Percent`. Ignore time-varying `Percent` to prevent leakage (**Cite solution_lesson_node_00069**).
    *   **Normalization:** Target `FVC` is Z-score standardized (**Cite solution_lesson_node_00001**). Input scalars are standardized but passed **raw** (no Batch Norm) to preserve absolute magnitude (**Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**).

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   We explicitly include the $\sqrt{2}$ constants to correct the systematic underestimation of uncertainty (approx 30%) observed when using standard NLL (**Cite solution_lesson_node_00066**).
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow (**Cite solution_lesson_node_00014**).
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs (**Cite solution_lesson_node_00027**).
    *   **Duration:** **50 Epochs**. This extended duration is mandatory to allow the uncertainty estimation to calibrate (**Cite solution_lesson_node_00011**).

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Pass inputs through MCDSR-Net to get $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) (**Cite solution_lesson_node_00006**).
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file (**Cite solution_lesson_node_00014**).
