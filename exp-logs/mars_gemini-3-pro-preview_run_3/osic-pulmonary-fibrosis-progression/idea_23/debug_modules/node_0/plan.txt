The implementation strategy is to verify the functionality of the provided Pulmonary Fibrosis Progression library components in a step-by-step manner.

1.  **Configuration & Setup**: Import the `Config` class and override specific hyperparameters (e.g., `EPOCHS`, `BATCH_SIZE`, `DEBUG`) to ensure the demonstration runs quickly within the time limit. Initialize the random seed using `seed_everything`.
2.  **Data Pipeline Verification**:
    *   Load the training metadata and manually apply feature engineering functions (`add_baseline_features`, `preprocess_tabular`) to verify the creation of clinical features like `t_rel` and scaled tabular data.
    *   Instantiate the `OSICDataset` with a small subset of data. Retrieve a single sample to assert the correctness of image tensor shapes (Channels, Height, Width) and tabular feature vectors.
3.  **Model Architecture Verification**:
    *   Instantiate the `MCDSRNet` model.
    *   Pass the sample batch through the model to verify the forward pass.
    *   Check that the model outputs two values per sample: `mu` (FVC prediction) and `sigma` (confidence), and ensure `sigma` is positive.
4.  **Metric & Loss Verification**:
    *   Calculate the custom `metric_aligned_loss` using the model outputs.
    *   Calculate the competition metric (`score_function`) using simulated raw values to ensure the logic handles the Laplace Log Likelihood correctly.
5.  **Training & Inference Integration**:
    *   Utilize `get_dataloaders(debug=True)` to set up data loaders for a rapid integration test.
    *   Run a minimal training loop (1 epoch) using `train_one_epoch` and `validate` to ensure the optimization step works without errors.
    *   Simulate the prediction phase using the trained model on the test loader to verify the submission format generation.
