The issue is that `LungDataProcessor.fit` calculates scaling statistics and merges the `Baseline_FVC` column but does not apply the feature transformations (like generating `Base_FVC_Scaled`) that `LungDataset` expects. The `get_dataloaders` function incorrectly treats `fit` as a `fit_transform` operation, passing the untransformed DataFrame directly to the dataset constructor, causing a `KeyError`. The fix is to explicitly call `processor.transform` on the training data after fitting the processor.
