Here is the implementation strategy and the complete execution script.

### Implementation Strategy
1.  **Setup & Configuration**: Import the provided library modules (`config`, `utils`, `data`, `model`, `train`). Override `Config.EPOCHS` to 15 to ensure the "fast baseline" requirement is met within the time limit. Set the submission directory to `./submission`.
2.  **Data Loading**: specific `get_dataloaders` function is called to prepare training, validation, and test loaders. This handles reading the CSVs, merging metadata, and preprocessing images/tabular features.
3.  **Training**: The `run_training` function is invoked to train the **CIDS-Net**. This encapsulates the training loop, optimizer stepping, and model checkpointing based on validation performance.
4.  **Validation & Failure Analysis**:
    *   The best model is re-loaded from the checkpoint.
    *   Inference is run on the full validation set to compute the `Final Validation Metric`.
    *   Pearson correlation is calculated between the absolute prediction error and input features (`Age`, `Weeks`, `Baseline_FVC`, `Percent`) to identify failure modes.
5.  **Submission Generation**:
    *   The script checks if the validation metric > -6.573619738753321.
    *   If passed, inference is run on the `test_loader`.
    *   Predictions are inverse-transformed (Z-score reversal) and the confidence is clipped at 70ml.
    *   The final CSV is written to `./submission/submission.csv`.
