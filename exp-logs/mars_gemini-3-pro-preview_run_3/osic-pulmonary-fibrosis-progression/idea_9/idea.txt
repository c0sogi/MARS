Based on the systematic analysis of the previous experiments and the derived lessons, I propose the **Origin-Corrected Parametric Network (OCP-Net)**.

This solution is a structural evolution of the **CAP-Net** (Idea 6) and **TAP-Net** (Idea 8). It retains the successful parametric trajectory modeling and content-adaptive vision backbone but introduces a fundamental correction to the coordinate system used for temporal modeling. This resolves the critical "Z-score Origin Shift" failure identified in **Cite solution_lesson_node_00036**, allowing the model to correctly implement physically constrained, time-dependent uncertainty without conflicting with data normalization.

### 1. Model
The architecture is a hybrid CNN-MLP that predicts the parameters of a patient-specific linear trajectory and a dynamic uncertainty envelope, rooted in a relative temporal coordinate system.

*   **Image Branch (Deep Semantic Fine-Tuning):**
    *   **Input:** Three slices per patient selected via the **Content-Adaptive Heuristic** (Apical, Middle, Basal) **Cite solution_lesson_node_00015**.
    *   **Backbone:** **EfficientNet-B0**. We unfreeze the top convolutional blocks to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer only. We explicitly reject multi-scale pyramids to prioritize deep semantic signals (lung volume/shape) **Cite solution_lesson_node_00025** and avoid attention mechanisms to prevent overfitting **Cite solution_lesson_node_00030**.
    *   **Projection:** The concatenated vector (3 slices) is projected to a lower dimension (e.g., 128) **Cite solution_lesson_node_00008**.

*   **Tabular Branch (Raw Signal Preservation):**
    *   **Input:** `Baseline FVC`, `Age`, `Sex`, `SmokingStatus`.
    *   **Processing:** These features are passed **raw** (normalized but not encoded) directly to the fusion layer. We explicitly avoid deep encoders for these strong scalar predictors to prevent signal obscuration **Cite solution_lesson_node_00035**.
    *   **Constraints:** Batch Normalization and Layer Normalization are **explicitly excluded** to preserve the absolute magnitude of the `Baseline FVC` **Cite solution_lesson_node_00017**.

*   **Fusion & Split Heads:**
    *   **Mixing:** The image projection and raw tabular features are concatenated and passed through a **shared Multi-Layer Perceptron (MLP)** (e.g., `Linear -> ReLU -> Linear`). This non-linear mixing is critical to capture cross-modal interactions (e.g., "Smokers with Fibrosis decline faster") **Cite solution_lesson_node_00032**.
    *   **Split Outputs:** The mixing layer branches into two separate linear heads to decouple the mean prediction from the slower-converging uncertainty estimation **Cite solution_lesson_node_00011**:
        1.  **Trajectory Head:** Outputs $\alpha$ (Autoregressive Coeff), $\beta$ (Offset), $\gamma$ (Slope).
        2.  **Uncertainty Head:** Outputs $\delta_{base}$ (Base Uncertainty), $\delta_{growth}$ (Uncertainty Growth Rate).

*   **Origin-Corrected Trajectory Logic:**
    *   The model uses a **Relative Coordinate System** where $t=0$ represents the baseline visit, not the dataset average.
    *   **Mean ($\mu$):** $\mu(t) = \alpha \cdot \text{Baseline}_{scaled} + \beta + \gamma \cdot t_{rel}$. This allows the model to learn the optimal autoregressive weight $\alpha$ rather than hard-coding a residual **Cite solution_lesson_node_00016**.
    *   **Uncertainty ($\sigma$):** $\sigma(t) = \text{softplus}(\delta_{base}) + \text{softplus}(\delta_{growth}) \cdot |t_{rel}|$.
    *   This formulation ensures uncertainty is minimized at the baseline (where ground truth exists) and grows linearly with time, respecting the physical constraints of the problem **Cite solution_lesson_node_00036**.

### 2. Data
*   **Content-Adaptive Slice Selection:**
    *   Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00015**.
*   **Relative Time Engineering (Crucial Correction):**
    *   Instead of Z-scoring the `Weeks` variable (which shifts the zero-point to the mean week), we create a new feature: $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$.
    *   We scale $t_{rel}$ by a fixed constant (e.g., dividing by 100) to keep the values within a neural-network-friendly range (approx -1 to 1) while **strictly preserving the zero at the origin**. This enables the $|t_{rel}|$ term in the uncertainty equation to function correctly **Cite solution_lesson_node_00036**.
*   **Target Standardization:**
    *   Target `FVC` and `Baseline FVC` are **Z-score standardized** to resolve the magnitude gap **Cite solution_lesson_node_00006**.

### 3. Training
*   **Loss Function:** Modified Laplace Log Likelihood. We **exclude** auxiliary MSE losses to prevent conflict with the probabilistic objective **Cite solution_lesson_node_00034**.
*   **Uncertainty Constraints:**
    *   We use a small numerical floor ($\epsilon=0.05$) for stability but **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the MLP Heads **Cite solution_lesson_node_00027**.
    *   **Duration:** 50 Epochs.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$ for each test week.
    *   Predict parameters and compute $\mu_{scaled}(t)$ and $\sigma_{scaled}(t)$ using the trajectory equations.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target\_dist} + \mu_{target\_dist}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target\_dist}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file.
