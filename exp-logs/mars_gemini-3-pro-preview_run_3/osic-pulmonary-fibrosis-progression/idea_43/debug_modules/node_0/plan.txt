The following code demonstrates the end-to-end usage of the provided machine learning pipeline for the FVC prediction task.

### Strategy
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to redirect outputs to a demo directory and adjust hyperparameters (e.g., reducing epochs and batch size) for rapid execution.
2.  **Data Loading & Verification**: We utilize `get_dataloaders` to load a small subset of the training and validation data. We explicitly verify the structure of the batches (shapes of images, tabular features, and targets) to ensure the `LungDataset` and `DataLoader` are functioning correctly.
3.  **Model Initialization & Forward Pass**: We instantiate the `SBPDSNet` model and perform a dummy forward pass with a single batch of data. We verify that the output dictionary contains the expected keys (`final_mean`, `final_sigma`, etc.) and that the tensor shapes align with the batch size.
4.  **Metric Calculation**: We demonstrate the `calculate_metric` function using synthetic numpy arrays to confirm the implementation of the modified Laplace Log Likelihood metric.
5.  **Training Loop**: We execute the `train_model` function with a constrained number of samples and epochs. This verifies the training pipeline, including loss calculation, backpropagation, validation, and checkpoint saving.
6.  **Inference & Submission**: We use the trained model to generate a submission file via `generate_submission`. Finally, we validate the generated CSV file's format and content against the competition requirements.
