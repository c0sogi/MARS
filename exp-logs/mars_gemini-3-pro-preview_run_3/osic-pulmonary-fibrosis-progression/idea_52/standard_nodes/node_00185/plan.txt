Implementation strategy:
1.  **Environment Setup**: Initialize the configuration and set random seeds using `Config.setup` and `seed_everything` to ensure reproducibility.
2.  **Configuration Override**: Reduce `Config.EPOCHS` to 15 to satisfy the "fast baseline" requirement while ensuring sufficient convergence for the small dataset.
3.  **Data Loading**: Use `get_dataloaders` to load training, validation, and test sets. This leverages the caching mechanism in `OSICDataset` for efficiency.
4.  **Model Initialization**: Instantiate the `AILRNet` model and move it to the appropriate computation device (GPU/CPU).
5.  **Training**: Execute the training pipeline using the `fit` function from the engine. This handles the training loop, validation monitoring, and checkpointing the best model.
6.  **Validation**: Load the best saved model checkpoint and compute the final metric on the validation set using `evaluate`. Print the metric in the required format.
7.  **Failure Analysis**: Perform inference on the validation set to calculate absolute errors. Compute and print correlations between these errors and key clinical features (`Weeks`, `Baseline_FVC`, `Age`, `Percent`) to identify systematic weaknesses.
8.  **Submission**: Compare the final validation metric against the specified threshold. If the model performs sufficiently well, generate the `submission.csv` file using the `predict` function.
