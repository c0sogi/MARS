Implementation Strategy:
1.  **Environment Setup**: Import necessary libraries and set random seeds for reproducibility.
2.  **Data Preparation**: Create a "mini" dataset by sampling a few patients from the provided metadata files. Save these subsets to a temporary working directory (`./working/demo`). This ensures the code runs quickly and adheres to the time limit.
3.  **Configuration Override**: Monkey-patch the file path constants in `library.data` and `library.config` to point to the created mini-datasets and a temporary cache directory. Disable pretrained weight downloading in `library.model` to avoid network dependency issues and speed up initialization.
4.  **Data Loading Demonstration**: Call `get_dataloaders` to generate PyTorch DataLoaders and the DataScaler. Verify the structure and shapes of the yielded batches (Images, Tabular features, Targets).
5.  **Model Instantiation & Forward Pass**: Initialize the `SAPNet` model. Perform a forward pass with a batch of data to demonstrate input/output flow and assert output shapes (Prediction `mu` and Confidence `sigma`).
6.  **Loss Function Usage**: Instantiate `LaplaceNLLLoss` and calculate the loss for the batch. Verify the loss is a valid scalar.
7.  **Metric Usage**: Demonstrate the `metric_laplace_log_likelihood` function with manual inputs to verify the scoring logic.
8.  **Training Loop Simulation**: Execute a minimal training loop (one epoch over the mini-dataset) using `train_one_epoch`. This demonstrates the optimization process.
9.  **Evaluation & Inference**: Run the `evaluate` function to get a validation score. Then, simulate the submission generation process by iterating over the test loader, applying the inverse transform to predictions, and formatting the results.
