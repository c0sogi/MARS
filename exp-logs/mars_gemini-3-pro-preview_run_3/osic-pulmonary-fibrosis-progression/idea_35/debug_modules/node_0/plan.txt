The following script demonstrates the end-to-end usage of the provided library files for the Pulmonary Fibrosis Progression task. It performs the following steps:

1.  **Configuration Setup**: Initializes the environment and overrides default configurations (epochs, batch size, image size) to ensure rapid execution.
2.  **Data Subsetting**: Creates a small subset of the metadata (train, val, test, sample submission) to verify the pipeline without processing the entire dataset.
3.  **Data Loading**: Uses `library.data.get_dataloaders` to process images (caching) and create PyTorch DataLoaders.
4.  **Model Initialization**: Instantiates the `UDSRNet` model from `library.model`.
5.  **Training & Validation**: Runs a single epoch of training and validation using `library.train` functions, verifying the loss and metric calculations.
6.  **Inference**: Generates a submission file using the trained model and verifies the output format.
