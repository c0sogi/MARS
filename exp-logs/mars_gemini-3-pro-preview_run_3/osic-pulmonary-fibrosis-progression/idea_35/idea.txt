Based on the comprehensive analysis of the accumulated lessons, I propose the **Unregularized Dual-Stream Residual Network (UDSR-Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream** architecture **Cite solution_lesson_node_00052** and the **Over-Parameterized Clinical Anchor** **Cite solution_lesson_node_00060**. It explicitly corrects the critical failure identified in **Cite solution_lesson_node_00126**, where stochastic regularization (Dropout) was found to destroy the weak but valuable signal in the visual residual branch. By removing this regularization and strictly enforcing domain-standard preprocessing **Cite solution_lesson_node_00090**, **Cite solution_lesson_node_00124**, this architecture allows the deep visual stream to effectively learn subtle non-linear corrections to the robust clinical baseline.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Output-Space Summation** topology.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Backbone:** **EfficientNet-B2**. We select the B2 variant (native resolution 260x260) to ensure sufficient capacity for fine-grained texture analysis (e.g., reticulation), avoiding the underfitting of B0 **Cite solution_lesson_node_00071** and the overfitting of heavier models like V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.

*   **Stream A: Over-Parameterized Clinical Anchor (The Foundation):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to prevent proxy leakage **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64) -> Linear(64 -> 2)`).
    *   **Outputs:** Base Mean ($\mu_{base}$) and Base Uncertainty ($\sigma_{base}$).
    *   **Purpose:** This stream learns the baseline disease trajectory. We use an MLP to ensure sufficient capacity to model the identity mapping and linear decay without optimization bottlenecks **Cite solution_lesson_node_00060**.

*   **Stream B: Visual Residual Stream (The Correction):**
    *   **Input:** Concatenation of [Image Features, `Baseline FVC`, $t_{rel}$, `Age`, `Sex`, `SmokingStatus`]. We employ **Early Fusion** within this stream to capture cross-modal interactions **Cite solution_lesson_node_00032**.
    *   **Architecture:** An **MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64) -> Linear(64 -> 2)`).
    *   **Outputs:** Residual Mean ($\delta_\mu$) and Residual Uncertainty ($\delta_\sigma$).
    *   **Structural Innovation (No Dropout):** We explicitly **exclude Dropout** from this stream. Since the visual signal is a weak residual correction to the strong linear baseline, stochastic regularization drowns out the gradient signal, causing the branch to collapse. We rely solely on the inductive bias of the architecture and early stopping for regularization **Cite solution_lesson_node_00126**.

*   **Probabilistic Output Fusion:**
    *   **Mean:** $\mu_{final} = \mu_{base} + \delta_\mu$.
    *   **Uncertainty:** $\sigma_{final} = \text{Softplus}(\sigma_{base} + \delta_\sigma) + \epsilon$.
    *   **Rationale:** This structure ensures uncertainty estimation has a direct pathway from the clinical priors **Cite solution_lesson_node_00055**, while allowing the image stream to learn heteroscedastic corrections.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply a standard **Lung Window (Level: -600 HU, Width: 1500 HU)**. We reject arbitrary clipping to ensure pathological features (like ground-glass opacity) are mapped to the active range of the network **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00124**, **Cite solution_lesson_node_00015**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** Use **Ordinal Encoding** for `SmokingStatus` (0, 1, 2) instead of One-Hot to preserve order and reduce sparsity **Cite solution_lesson_node_00103**.
    *   **Normalization:** Target `FVC` is Z-score standardized **Cite solution_lesson_node_00001**. Input scalars are standardized but passed **raw** (no Batch Norm) to preserve absolute magnitude **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   Formula: $L = \frac{\sqrt{2} |y_{true} - y_{pred}|}{\sigma} + \ln(\sqrt{2} \sigma)$.
    *   We explicitly include the $\sqrt{2}$ constants to correct the systematic underestimation of uncertainty (~30%) observed when using standard NLL **Cite solution_lesson_node_00066**.
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link the scheduler's `T_max` directly to the training epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly maintain a batch size of **32 or higher** (using Gradient Accumulation if necessary) to ensure stability of Batch Normalization statistics **Cite solution_lesson_node_00094**.
    *   **Duration:** **50 Epochs** to allow uncertainty calibration **Cite solution_lesson_node_00011**.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Pass inputs through UDSR-Net to get $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target} + \mu_{target}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
