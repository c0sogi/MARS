Based on the comprehensive analysis of the accumulated lessons, I propose the **Regularized Output-Space Dual-Stream Network (RODS-Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream** topology **Cite solution_lesson_node_00052** with critical corrections for **Linear Capacity** **Cite solution_lesson_node_00060**, **Dimensionality Balance** **Cite solution_lesson_node_00146**, and **Regularization** **Cite solution_lesson_node_00132**. It explicitly resolves the optimization instability of previous iterations by enforcing a strict "Boosting" paradigm via **Output-Space Zero-Initialization** **Cite solution_lesson_node_00118** and preventing signal drowning via **Context Injection** **Cite solution_lesson_node_00139**.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Output-Space Summation** topology. This design ensures the model preserves the robust clinical trajectory while allowing deep visual features to learn complex residual corrections without overfitting.

*   **Stream A: Over-Parameterized Clinical Anchor (The Base Learner):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to prevent proxy leakage **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64) -> Linear(64 -> 2)`).
    *   **Outputs:** Base Mean ($\mu_{base}$) and Base Uncertainty ($\sigma_{base}$).
    *   **Purpose:** This stream learns the baseline disease trajectory ($FVC(t) \approx Base + Rate \times t$). We use an MLP to ensure sufficient capacity to model the identity mapping and linear decay without optimization bottlenecks **Cite solution_lesson_node_00060**.

*   **Stream B: Regularized Visual Residual (The Correction):**
    *   **Backbone:** **EfficientNet-B2**. Selected for its balance of native resolution (260x260) and parameter efficiency, avoiding the underfitting of B0 **Cite solution_lesson_node_00071** and the overfitting of V2-S **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** We **unfreeze the top two convolutional stages** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer to prioritize deep semantic signals **Cite solution_lesson_node_00025**.
    *   **Bottleneck Projection:** The high-dimensional backbone output (1408-dim) is immediately projected to **64 dimensions** via a learnable Linear layer. This prevents the high-dimensional image noise from statistically dominating the fusion layer **Cite solution_lesson_node_00146**.
    *   **Context Injection:** We concatenate the **Projected Image** with the **Raw Clinical Scalars** (Baseline FVC, Time, etc.). This ensures the residual branch is conditioned on the patient's initial severity, allowing it to learn patient-specific residuals rather than generic corrections **Cite solution_lesson_node_00139**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 128) -> ReLU -> Dropout(p=0.2) -> Linear(128 -> 64) -> Dropout(p=0.2) -> Linear(64 -> 2)`).
    *   **Regularization:** We explicitly **include Dropout**. Since this stream learns a weak residual correction to the strong linear baseline, stochastic regularization is mandatory to prevent the high-capacity branch from memorizing noise **Cite solution_lesson_node_00132**.
    *   **Zero-Initialization:** The weights and biases of the **final Linear layer** of this stream are explicitly initialized to **zero**. This ensures the model starts as the robust Clinical Anchor, resolving initialization instability **Cite solution_lesson_node_00118**.
    *   **Outputs:** Residual Mean ($\delta_\mu$) and Residual Uncertainty ($\delta_\sigma$).

*   **Probabilistic Output Fusion:**
    *   **Mean:** $\mu_{final} = \mu_{base} + \delta_\mu$.
    *   **Uncertainty:** $\sigma_{final} = \text{Softplus}(\sigma_{base} + \delta_\sigma) + \epsilon$.
    *   **Rationale:** This structure ensures uncertainty estimation has a direct, low-complexity pathway from the clinical priors **Cite solution_lesson_node_00055**, without explicit shortcuts that cause premature convergence **Cite solution_lesson_node_00085**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Apply a standard **Lung Window (Level: -600 HU, Width: 1500 HU)**. We reject arbitrary clipping to ensure pathological features are mapped to the active range of the network **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) to ensure anatomical consistency **Cite solution_lesson_node_00124**.
    *   **Relative Time ($t_{rel}$):** Calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. We **do not** Z-score this variable, strictly preserving the zero at the baseline to ensure the model correctly interprets the physical origin **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** Use **Ordinal Encoding** for `SmokingStatus` (0, 1, 2) instead of One-Hot to preserve order and reduce sparsity **Cite solution_lesson_node_00103**.
    *   **Target Normalization:** We calculate the mean and standard deviation of the **Entire Training Target Distribution** (all visits) and use these to Z-score normalize the target `FVC`. We explicitly reject using baseline-only statistics **Cite solution_lesson_node_00155**.
    *   **Input Normalization:** Input scalars are standardized but passed **raw** (no Batch Norm) to preserve absolute magnitude **Cite solution_lesson_node_00017**, **Cite solution_lesson_node_00035**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood (Standardized)**.
    *   Formula: $L = \frac{\sqrt{2} |y_{scaled} - \mu_{scaled}|}{\sigma_{scaled}} + \ln(\sqrt{2} \sigma_{scaled})$.
    *   **Correction:** We explicitly include the $\sqrt{2}$ constants to correct the systematic underestimation of uncertainty (~30%) observed when using standard NLL **Cite solution_lesson_node_00066**.
    *   **Optimization Space:** We optimize in the **Standardized Space** to avoid gradient instability from large raw values **Cite solution_lesson_node_00165**. We do **not** apply hard clipping in the loss function to avoid zero-gradient regions **Cite solution_lesson_node_00138**.
*   **Uncertainty Constraints:**
    *   Use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link the scheduler's `T_max` directly to the training epochs to ensure the full decay cycle is completed **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone, `1e-3` for the Stream MLPs **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly maintain a batch size of **32 or higher** (using Gradient Accumulation if necessary) to ensure stability of Batch Normalization statistics **Cite solution_lesson_node_00094**.
    *   **Duration:** **50 Epochs** to allow uncertainty calibration **Cite solution_lesson_node_00011**.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.

    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{global}$ (Scale only) **Cite solution_lesson_node_00006**.
