The implementation strategy is as follows:

1.  **Setup & Configuration**: Initialize the environment by setting random seeds and selecting the compute device (GPU) using the provided `Config` and `utils`.
2.  **Data Loading**: Utilize `get_dataloaders` to load the training, validation, and test datasets. We will use the full dataset (`debug=False`) as the dataset size is small (~1k samples), ensuring the training completes quickly (within minutes) while maximizing performance. Cached data will be used to speed up loading.
3.  **Model Initialization**: Instantiate the `RaliNet` model and move it to the device.
4.  **Optimization**: Configure the optimizer (AdamW) with differential learning rates for the backbone and heads, and initialize the Cosine Annealing scheduler, mirroring the logic in `library/train.py`.
5.  **Training Loop**: Execute a training loop for `Config.EPOCHS` (50). In each epoch:
    *   Train for one epoch using `train_one_epoch`.
    *   Evaluate on the validation set using `evaluate`.
    *   Save the model checkpoint if the validation metric improves.
6.  **Final Evaluation**: Load the best saved model and compute the final validation metric on the hold-out set. Print this metric strictly in the required format.
7.  **Failure Analysis**: Perform a specific inference pass on the validation set to calculate per-sample absolute errors. Compute and print the Pearson correlation between these errors and key clinical features (`Age`, `Weeks`, `Base_FVC`, `Percent`) to identify systematic failure modes.
8.  **Submission**: Compare the final validation metric against the threshold (`-6.573619738753321`). If the model performs better (higher score), generate the submission file using `generate_submission`.
