Here is the implementation strategy and the self-contained Python script.

### Implementation Strategy

1.  **Environment Setup**: Import necessary libraries and set random seeds for reproducibility using the provided `seed_everything` utility.
2.  **Configuration Patching**: To ensure the demo runs quickly (within the time limit) and uses minimal resources, I will dynamically modify the `Config` class attributes. This includes reducing the number of epochs to 1, setting a small batch size, and redirecting metadata paths to a temporary directory.
3.  **Data Subsetting**: I will load the original `train.csv` metadata, sample a very small subset of patients (e.g., 4 patients), and save this subset to a temporary location. This ensures the `CTDataset` and `DataLoader` initialization is fast and processes real DICOM data without iterating through the entire dataset.
4.  **Component Verification**:
    *   **Metric**: Validate `calculate_metric` with manual inputs to ensure the mathematical formula (Laplace Log Likelihood) is implemented correctly.
    *   **Data Loading**: Initialize `get_dataloaders` with the subset data. Fetch a single batch to verify tensor shapes (Image: `[B, 3, 260, 260]`, Tabular: `[B, 5]`, Target: `[B]`) and value ranges.
    *   **Model**: Instantiate `MAOPDSNet`, perform a forward pass with the fetched batch, and verify the output shape `[B, 2]` (representing $\mu$ and raw $\sigma$).
    *   **Loss**: Compute the `MetricAlignedLLLoss` on the model output and verify it returns a valid scalar.
5.  **Integration Test**: Execute the `run_training` function (which runs the training and validation loops) for 1 epoch to demonstrate the full pipeline works end-to-end.
6.  **Cleanup**: Remove temporary files and directories created during the execution.
