### Implementation Strategy

1.  **Configuration Setup**: We will first import the `Config` class and override specific parameters (e.g., `EPOCHS`, `BATCH_SIZE`, `DEBUG`) to ensure the demonstration runs quickly and uses a small subset of the data.
2.  **Data Pipeline Verification**: We will instantiate the `LungDataset` and `DataLoader`s to verify that data loading, image processing (or caching), and clinical feature extraction function correctly. We will assert the shapes of the returned tensors.
3.  **Model Architecture Check**: We will instantiate the `BCOSRNet` model, pass a batch of dummy data through it, and verify that the output shapes match expectations (Batch Size, 2) and that the uncertainty estimates satisfy the architectural constraints (positive values).
4.  **Loss Function Test**: We will compute the `LaplaceNLLLoss` on the model outputs to ensure the custom loss function is differentiable and returns a valid scalar.
5.  **Training & Inference Simulation**: We will execute the high-level `run_training` function in debug mode to perform a complete but short training loop. Finally, we will call `generate_submission` to ensure the inference pipeline produces a correctly formatted CSV file.
