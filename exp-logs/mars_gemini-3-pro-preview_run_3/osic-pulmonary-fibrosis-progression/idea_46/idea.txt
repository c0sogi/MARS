Based on the comprehensive analysis of the accumulated lessons, I propose the **Boundary-Constrained Output-Space Residual Network (BC-OSR Net)**.

This solution represents a structural synthesis of the **Dual-Stream** topology **Cite solution_lesson_node_00052** with the **Over-Parameterized Clinical Anchor** **Cite solution_lesson_node_00060**. It explicitly resolves the optimization instability of previous iterations by enforcing a "Boosting" paradigm via **Output-Space Zero-Initialization** **Cite solution_lesson_node_00118** and **Regularization** **Cite solution_lesson_node_00132**, while correcting the critical **Loss-Metric Mismatch** identified in **Cite solution_lesson_node_00164** through architectural boundary enforcement.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Output-Space Summation** topology.

*   **Stream A: Over-Parameterized Clinical Anchor (The Base Learner):**
    *   **Input:** `Baseline FVC`, `Relative Time` ($t_{rel}$), `Age`, `Sex`, `SmokingStatus` (Ordinal). We explicitly **exclude** `Percent` to prevent proxy leakage **Cite solution_lesson_node_00069**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(Input -> 128) -> ReLU -> Linear(128 -> 64) -> Linear(64 -> 2)`).
    *   **Outputs:** Base Mean ($\mu_{base}$) and Base Uncertainty ($\sigma_{base}$).
    *   **Purpose:** This stream learns the baseline disease trajectory ($FVC(t) \approx Base + Rate \times t$). We use an MLP to ensure sufficient capacity to model the linear trends without optimization bottlenecks **Cite solution_lesson_node_00060**.

*   **Stream B: Regularized Visual Residual (The Correction):**
    *   **Backbone:** **EfficientNet-B2**. Selected for its balance of native resolution (260x260) and parameter efficiency **Cite solution_lesson_node_00071**, **Cite solution_lesson_node_00054**.
    *   **Fine-Tuning:** Unfreeze top two stages; keep bottom frozen **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** **Global Average Pooling** from the final layer.
    *   **Bottleneck Projection:** Project the 1408-dim output to **64 dimensions**. This prevents high-dimensional image noise from dominating the fusion **Cite solution_lesson_node_00146**.
    *   **Context Injection:** Concatenate the **Projected Image** with the **Raw Clinical Scalars**. This ensures the residual branch is conditioned on the patient's initial severity **Cite solution_lesson_node_00139**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 128) -> ReLU -> Dropout(p=0.2) -> Linear(128 -> 64) -> Dropout(p=0.2) -> Linear(64 -> 2)`).
    *   **Regularization:** We explicitly **include Dropout**. Since this stream learns a weak residual correction in an output-space topology, regularization is mandatory to prevent overfitting to noise **Cite solution_lesson_node_00132**.
    *   **Zero-Initialization:** The final layer is initialized to **zero**. This ensures the model starts as the robust Clinical Anchor **Cite solution_lesson_node_00118**.
    *   **Outputs:** Residuals $\delta_\mu, \delta_\sigma$.

*   **Boundary-Constrained Fusion:**
    *   **Mean:** $\mu_{final} = \mu_{base} + \delta_\mu$.
    *   **Uncertainty:** $\sigma_{final} = \text{Softplus}(\sigma_{base} + \delta_\sigma) + 70$.
    *   **Structural Innovation:** By architecturally enforcing the $+70$ floor (matching the metric's clipping threshold), we align the optimization landscape with the evaluation metric. This prevents the model from "cheating" the loss function by predicting $\sigma \to 0$ on easy samples, which previously caused divergence between validation loss and metric score **Cite solution_lesson_node_00164**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Standard **Lung Window (Level: -600 HU, Width: 1500 HU)** **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select "Anchor" slice (Max Lung Area) and two boundary slices (50% area) **Cite solution_lesson_node_00124**.
    *   **Relative Time ($t_{rel}$):** $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. **No Z-score** **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** **Ordinal Encoding** for `SmokingStatus` **Cite solution_lesson_node_00103**.
    *   **Target Normalization:** Normalize targets using **Global Statistics** (all visits), not baseline statistics **Cite solution_lesson_node_00155**.
    *   **Input Normalization:** Input scalars are standardized but passed **raw** (no Batch Norm) **Cite solution_lesson_node_00017**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood**.
    *   $L = \frac{\sqrt{2} |y - \mu_{final}|}{\sigma_{final}} + \ln(\sqrt{2} \sigma_{final})$.
    *   Because $\sigma_{final}$ is constrained to $\ge 70$ architecturally, this loss is perfectly aligned with the metric boundaries, preventing the optimization of "phantom gains" in the clipped region **Cite solution_lesson_node_00164**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` (Backbone) vs `1e-3` (Heads) **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly $\ge 32$ **Cite solution_lesson_node_00094**.
    *   **No Auxiliary Loss:** Train only on the final output to avoid conflicting objectives **Cite solution_lesson_node_00159**.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$. Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via BC-OSR Net.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{global} + \mu_{global}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{global}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for submission **Cite solution_lesson_node_00014**.
