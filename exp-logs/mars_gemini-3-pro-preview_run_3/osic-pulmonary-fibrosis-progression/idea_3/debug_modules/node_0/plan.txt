Implementation Strategy:
1.  **Environment Setup**: Import necessary modules and set random seeds for reproducibility.
2.  **Configuration Override**: Modify the `Config` class attributes to reduce `epochs` and `batch_size`, and create small subsets of the training/validation metadata in the working directory to ensure the demonstration runs quickly.
3.  **Data Pipeline Verification**: Initialize data loaders using the subset metadata. Fetch a single batch to verify tensor shapes for images, tabular data, and targets.
4.  **Model Verification**: Instantiate the `MultiViewNet` model on the appropriate device (CPU/GPU). Perform a forward pass with the fetched batch and verify that the outputs (Mean FVC and Confidence Sigma) have the correct dimensions and constraints (positivity).
5.  **Metric Verification**: Manually calculate the modified Laplace Log Likelihood metric for a known set of values and compare it against the output of the `calculate_metric` function to ensure correctness.
6.  **Training Loop Verification**: Execute a short training loop (2 epochs) using `train_one_epoch` and `validate`. Assert that loss values are valid and that the validation metric is computed correctly.
7.  **Inference Pipeline Verification**: Initialize the test data loader using `prepare_inference_data` and verify the structure of the resulting batch, ensuring the pipeline is ready for submission generation.
