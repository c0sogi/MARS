The implementation strategy follows the orchestration of the provided library components to establish a robust baseline for the Content-Adaptive 2.5D Multi-View Network.

1.  **Training Phase**: The script initiates the training process by calling `library.train.run_training()`. This leverages the pre-configured `MultiViewNet`, `LungDataset`, and `laplace_nll_loss` to train for 35 epochs. The best model, selected based on the validation metric, is saved to the checkpoint directory.
2.  **Validation & Failure Analysis**:
    *   The best model is reloaded in evaluation mode.
    *   Predictions are generated for the entire validation set.
    *   Inverse transformations are applied to the standardized model outputs to recover real-world FVC (ml) and Confidence (ml) values.
    *   The `Final Validation Metric` is computed and printed with full precision.
    *   A failure analysis is performed by calculating the absolute error for each prediction and computing the Pearson correlation coefficient between the error and input features (Age, Sex, SmokingStatus, Weeks, Baseline FVC). This helps identify if specific patient subgroups or timepoints are prone to higher errors.
3.  **Submission Generation**:
    *   The script checks if the final validation metric exceeds the threshold of `-6.7377055487078`.
    *   If the condition is met, the test set is prepared using `prepare_inference_data`, expanding the baseline test metadata to cover all requested prediction weeks.
    *   Inference is run on the test set, outputs are inverse-transformed, and confidence values are clipped at 70ml as per the metric definition.
    *   The final predictions are saved to `./submission/submission.csv`.
