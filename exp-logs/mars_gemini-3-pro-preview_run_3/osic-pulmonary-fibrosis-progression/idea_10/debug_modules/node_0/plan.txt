The following script demonstrates the end-to-end usage of the provided library components. It first configures the environment for a rapid demonstration by overriding default hyperparameters (enabling debug mode, reducing epochs and batch size). It then validates the data loading pipeline, performs a structural check on the model (forward pass and output shapes), and finally executes a full training loop using the `run_training` function. Assertions are included throughout to ensure logical correctness of shapes, data types, and file outputs.
