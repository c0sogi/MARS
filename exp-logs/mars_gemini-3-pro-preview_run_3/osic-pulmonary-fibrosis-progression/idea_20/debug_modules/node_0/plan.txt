This script demonstrates the end-to-end usage of the provided library files for the lung function decline prediction task. It covers:
1.  **Configuration**: Overriding default hyperparameters for a rapid demonstration.
2.  **Data Pipeline**: Loading data using `get_dataloaders` and verifying batch shapes and content.
3.  **Model Architecture**: Instantiating `TSCRNet`, performing a forward pass, and validating output dimensions and constraints (e.g., positive confidence).
4.  **Loss & Metric**: Computing the custom Laplace Log Likelihood loss and metric, including inverse scaling of predictions.
5.  **Training Loop**: Executing a short training simulation using `train_one_epoch` and `evaluate` to ensure the optimization process functions correctly.
