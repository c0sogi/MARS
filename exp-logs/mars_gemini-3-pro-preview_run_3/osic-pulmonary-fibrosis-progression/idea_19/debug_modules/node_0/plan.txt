The following script demonstrates the usage of the provided library files for the Lung Function Prediction task. It covers data loading, model instantiation, loss calculation, metric verification, training loop execution, and inference.

**Implementation Strategy:**
1.  **Configuration Override**: We first override the default `Config` parameters to optimize for speed (e.g., 1 epoch, small batch size, debug mode) and isolate the execution environment (using a unique `IDEA_ID`).
2.  **Data Pipeline Verification**: We call `get_dataloaders` to ensure data can be loaded and preprocessed correctly. We inspect the shapes of the returned tensors.
3.  **Model & Loss Verification**: We instantiate the `MACRNet` model and `MetricAlignedLLLoss`. We perform a dummy forward pass with random tensors to verify output shapes and loss calculation logic.
4.  **Metric Verification**: We test the `score_function` with specific values to ensure the custom Laplace Log Likelihood metric (with clipping) is calculated as expected.
5.  **Training & Inference**: We instantiate the `Trainer` class and run the `fit` method for a single epoch. Finally, we execute the `predict_test_set` function to generate a submission file, verifying the end-to-end workflow.
