Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the environment using `Config.setup()`. Override `Config.EPOCHS` to a lower value (20) to satisfy the "fast baseline" requirement while ensuring sufficient convergence for the trajectory network.
2.  **Data Loading**: Load the pre-generated metadata (`train.csv`, `val.csv`) and initialize the `CTScanProcessor` and `TabularScaler`. Fit the scaler on the training data.
3.  **Model Training**: Implement the training loop explicitly within the script (instead of calling `library.train.train`) to retain access to the model and scaler objects. Use `train_one_epoch` for training and `evaluate` for validation monitoring. Save the best model based on the Laplace Log Likelihood metric.
4.  **Final Validation**: Load the best checkpoint and perform inference on the full validation set. Compute the `Final Validation Metric` using the official metric function.
5.  **Failure Analysis**: Calculate the absolute error for each validation sample. Compute and print Pearson correlations between the error magnitude and key features (`Weeks`, `Age`, `Percent`, `Baseline FVC`) to identify systematic weaknesses.
6.  **Submission Generation**:
    *   Check if the validation metric exceeds the threshold (-6.6997912217).
    *   Use `prepare_inference_dataframe` to merge `sample_submission.csv` with `test.csv` metadata.
    *   Create a `PulmonaryDataset` for the test set.
    *   Run inference to predict parameters, calculate trajectories, and unscale the results.
    *   Apply the required clipping to confidence values ($\sigma \ge 70$).
    *   Save the formatted predictions to `submission.csv`.
