1.  **Setup & Configuration**: We will initialize the environment and set random seeds using `seed_everything`. We will instantiate the `Runner` class from `library.train`. To satisfy the "fast baseline" requirement, we will override the default epoch count to 15, which is sufficient for the pre-trained EfficientNet backbone (with frozen lower layers) to adapt its top layers and for the MLP streams to converge, while keeping runtime minimal.
2.  **Training**: We will execute the training loop via `runner.run()`. This handles data loading, forward passes, loss calculation, backpropagation, and validation monitoring.
3.  **Validation Reporting**: After training, we will retrieve `runner.best_metric` and print it in the specific format `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   We will load the best model checkpoint.
    *   We will iterate over the validation set in evaluation mode (`no_grad`) to generate predictions.
    *   We will calculate the absolute error between the denormalized predictions and the ground truth.
    *   We will construct a DataFrame containing these errors and the corresponding clinical input features (Baseline FVC, Time, Age, Sex, Smoking).
    *   We will compute and print the Pearson correlation between the error magnitude and these features to identify systematic weaknesses.
5.  **Submission**: We will compare the best validation metric against the threshold `-6.573619738753321`. If the model performs better (higher score), we will trigger `runner.generate_submission()`.
