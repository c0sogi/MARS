To improve the performance of the CI-OP-DS Net, I will implement two targeted optimizations based on the provided lessons and failure analysis.

1.  **Linearize the Anchor Stream (Cite Lesson 00052, 00060):** The current solution uses an MLP (`Linear -> ReLU -> Linear`) for `stream_a`, which processes standardized clinical features (Age, Sex, Smoke, RelWeeks, BaseFVC). Since `BaseFVC_s` and `RelWeeks_s` are Z-score standardized, they contain meaningful negative values. The `ReLU` activation likely suppresses these negative signals, preventing the model from effectively learning the dominant linear autoregressive trend ($FVC \approx BaseFVC + \text{rate} \times t$). I will replace `stream_a` with a single `nn.Linear` layer to project these features into the latent space while preserving their sign and magnitude.

2.  **Synchronize Scheduler and Training Horizon (Cite Lesson 00100):** The `CosineAnnealingLR` scheduler is configured with `T_max=Config.EPOCHS` (30), but the training loop in `runfile.py` was hardcoded to run for only 15 epochs. This mismatch prevents the learning rate from decaying fully, leaving the optimizer in a high-energy state that hinders convergence. I will update `runfile.py` to use `Config.EPOCHS` (30), ensuring the scheduler and training duration are coupled correctly.
