Implementation strategy:
1.  **Configuration**: Import the `Config` class and override `EPOCHS` to a smaller number (15) to ensure the training completes quickly while still learning enough to pass the metric threshold. Disable debug mode to use the full dataset.
2.  **Training**: Initialize the `Trainer` class from `library.train` and execute the `fit()` method. This handles the training loop, validation monitoring, and checkpoint saving.
3.  **Data Loading for Inference**: Since the `Trainer` does not expose the test loader, explicitly call `get_dataloaders` from `library.data` to retrieve the validation and test data loaders.
4.  **Validation & Failure Analysis**:
    *   Load the best model checkpoint (`best_model.pth`).
    *   Run inference on the validation set to collect predictions ($\mu$, $\sigma$) and targets.
    *   Compute the global Modified Laplace Log Likelihood metric.
    *   Calculate absolute prediction errors.
    *   Compute and print the Pearson correlation between the absolute errors and each tabular feature (Baseline FVC, Age, Sex, Smoking, Time) to identify failure modes.
5.  **Submission**:
    *   Check if the validation metric exceeds the threshold `-6.57744688338769`.
    *   If successful, run inference on the test set.
    *   Apply the inverse scaling to return to milliliters.
    *   Apply the confidence clipping ($\sigma \ge 70$).
    *   Format the results into a DataFrame matching `sample_submission.csv` and save it to `./submission/submission.csv`.
