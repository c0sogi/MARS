Based on the comprehensive analysis of the provided lessons, I propose the **Time-Conditioned Deep-Semantic Network (TCDS-Net)**.

This solution represents a structural evolution that synthesizes the superior "Point-Wise" temporal modeling identified in **Cite solution_lesson_node_00037** with the robust "Content-Adaptive 2.5D" vision backbone **Cite solution_lesson_node_00015**. It explicitly rejects the rigid "Parametric Trajectory" approach (predicting fixed slopes) in favor of a universal approximator conditioned on **Relative Time**, allowing the model to capture non-linear disease progression while strictly preserving the physical origin of the baseline measurement.

### 1. Model
The architecture is a hybrid CNN-MLP that predicts lung function ($\mu$) and confidence ($\sigma$) for a specific time point $t$, conditioned on the patient's static baseline context.

*   **Image Branch (Fine-Tuned Content-Adaptive 2.5D):**
    *   **Input:** Three slices per patient selected via the **Content-Adaptive Heuristic** (Apical, Middle, Basal) to ensure anatomical consistency without geometric registration **Cite solution_lesson_node_00012**, **Cite solution_lesson_node_00015**.
    *   **Backbone:** **EfficientNet-B2**. We upgrade the backbone from B0 to B2 (moderately heavier) to better capture fine-grained fibrotic textures (e.g., reticulation). Crucially, we **unfreeze the top two convolutional blocks** to allow domain adaptation while keeping lower layers frozen to preserve robust edge detection **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final layer. We explicitly reject multi-scale pyramids to prioritize deep semantic signals (lung volume/shape) **Cite solution_lesson_node_00025** and avoid attention mechanisms to prevent overfitting **Cite solution_lesson_node_00030**.
    *   **Projection:** The concatenated vector (3 slices) is projected to a lower dimension (e.g., 128) via a learnable Linear layer to balance modalities **Cite solution_lesson_node_00008**.

*   **Tabular & Temporal Inputs:**
    *   **Static Features:** `Baseline FVC`, `Age`, `Sex`, `SmokingStatus`. These are passed as **Raw Scalars** (normalized but not encoded/embedded) to preserve their strong linear signal **Cite solution_lesson_node_00035**. We explicitly **exclude Batch Normalization and Layer Normalization** from this branch to prevent the destruction of the absolute magnitude information in `Baseline FVC` **Cite solution_lesson_node_00017**.
    *   **Relative Time ($t_{rel}$):** Instead of Z-scoring the `Weeks` variable (which shifts the origin), we calculate $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. This feature is scaled by a constant (e.g., 0.01) to maintain numerical stability while **strictly preserving the zero at the baseline**. This ensures the model understands "distance from baseline" correctly **Cite solution_lesson_node_00036**.

*   **Fusion & Point-Wise Head:**
    *   **Concatenation:** The Image Projection, Raw Static Features, and $t_{rel}$ are concatenated into a single vector. Crucially, Time is included **early** in the dense layers to allow the network to model non-linear interactions (e.g., "Severe Fibrosis $\times$ Time = Fast Decline") **Cite solution_lesson_node_00022**, **Cite solution_lesson_node_00037**.
    *   **Mixing MLP:** The fused vector passes through a **Multi-Layer Perceptron** (e.g., 512 $\to$ ReLU $\to$ 256 $\to$ ReLU). This non-linear mixing is mandatory to capture conditional dependencies **Cite solution_lesson_node_00032**.
    *   **Constraints:** We explicitly **exclude Dropout** from this head to preserve the precision of the linear signal and uncertainty calibration **Cite solution_lesson_node_00007**.
    *   **Output:** The MLP projects to 2 scalars: $\mu$ (Standardized FVC) and $\sigma$ (Standardized Confidence).

### 2. Data
*   **Preprocessing:**
    *   **Slice Selection:** Identify the "Anchor" slice (Max Lung Area) and two boundary slices (50% area threshold) for each patient **Cite solution_lesson_node_00015**.
    *   **Target Standardization:** The target `FVC` is **Z-score standardized** during training to resolve the magnitude gap **Cite solution_lesson_node_00001**, **Cite solution_lesson_node_00006**.
    *   **Input Normalization:** `Baseline FVC` and `Age` are Z-score standardized. `Weeks` is converted to $t_{rel}$ and scaled.
*   **Augmentation:**
    *   Apply mild spatial augmentations (ShiftScaleRotate) to the images during training to improve backbone robustness, but avoid fixed intensity windowing **Cite solution_lesson_node_00031**.

### 3. Training
*   **Loss Function:** Modified Laplace Log Likelihood ($L = \frac{|y - \mu|}{\sigma} + \ln(\sigma)$).
*   **Uncertainty Constraints:**
    *   We use `sigma = softplus(raw_output) + epsilon`. We **do not** enforce the metric's 70ml clip in the architecture, allowing natural gradient flow for overconfident predictions during training **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the Unfrozen Backbone layers, `1e-3` for the MLP Head. This ensures the pre-trained features are adapted gently while the new head converges rapidly **Cite solution_lesson_node_00027**.
    *   **Duration:** **50 Epochs**. This extended duration is critical for the fine-tuning process and uncertainty calibration **Cite solution_lesson_node_00009**, **Cite solution_lesson_node_00011**.

### 4. Evaluation
*   **Inference:**
    *   For each test `Patient_Week`, calculate $t_{rel}$.
    *   Pass the baseline CT, metadata, and $t_{rel}$ through the network to predict $\mu_{scaled}$ and $\sigma_{scaled}$.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target\_dist} + \mu_{target\_dist}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target\_dist}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file **Cite solution_lesson_node_00014**.
