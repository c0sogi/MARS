Based on the lessons learned from previous experiments, I propose the **Time-Aware Parametric Network (TAP-Net)**.

This solution introduces two structural innovations to the successful parametric trajectory approach:
1.  **Time-Dependent Uncertainty Modeling:** Instead of predicting a static uncertainty value per patient, the model predicts the *rate of uncertainty growth*. This physically aligns with the reality that confidence should degrade as predictions move further in time from the baseline CT scan.
2.  **Auxiliary Slope Supervision:** It introduces a secondary training objective that forces the image features to explicitly predict the patient's historical rate of decline (calculated via OLS), stabilizing the learning of the prognosis parameter ($\gamma$).

### 1. Model
The architecture is a hybrid CNN-MLP that predicts the parameters of a dynamic linear trajectory and a dynamic uncertainty envelope.

*   **Image Branch (Deep Semantic Extraction):**
    *   **Input:** Three slices per patient selected via the **Content-Adaptive Heuristic** (Apical, Middle, Basal) **Cite solution_lesson_node_00015**.
    *   **Backbone:** **EfficientNet-B1**. This is a slight capacity upgrade from B0 to better capture texture details, utilizing **Differential Learning Rates** (frozen bottom, unfrozen top) to adapt to medical domains without overfitting **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** Features are extracted via **Global Average Pooling** from the final convolutional layer. We explicitly avoid multi-scale pyramids to preserve deep semantic signals **Cite solution_lesson_node_00025** and avoid attention mechanisms to maintain robustness in this low-data regime **Cite solution_lesson_node_00030**.
    *   **Projection:** The concatenated vector (3 slices) is projected to 128 dimensions **Cite solution_lesson_node_00008**.

*   **Tabular Branch (Signal Preservation):**
    *   **Input:** `Baseline FVC`, `Percent`, `Age`, `Sex`, `SmokingStatus`.
    *   **Constraints:** Batch Normalization and Layer Normalization are **explicitly excluded** to preserve the strong magnitude signal of the `Baseline FVC` **Cite solution_lesson_node_00017**.

*   **Fusion & Parametric Head:**
    *   **Mixing:** The image and tabular embeddings are concatenated and passed through a **Multi-Layer Perceptron (MLP)** (e.g., 512 $\to$ ReLU $\to$ 256 $\to$ ReLU). This non-linear mixing is critical to capture cross-modal interactions (e.g., "Smokers with Fibrosis decline faster") **Cite solution_lesson_node_00032**.
    *   **Outputs:** The head predicts 5 scalar parameters:
        1.  $\alpha$: Baseline Autoregressive Coefficient.
        2.  $\beta$: Intercept Adjustment.
        3.  $\gamma$: Rate of Decline (Slope).
        4.  $\delta_{base}$: Baseline Uncertainty.
        5.  $\delta_{growth}$: Uncertainty Growth Rate.

*   **Trajectory Logic (Structural Innovation):**
    *   **Mean ($\mu$):** $\mu(t) = \alpha \cdot \text{Baseline}_{scaled} + \beta + \gamma \cdot \text{Weeks}_{scaled}$. This retains the successful multiplicative interaction **Cite solution_lesson_node_00026**.
    *   **Uncertainty ($\sigma$):** $\sigma(t) = \text{softplus}(\delta_{base}) + \text{softplus}(\delta_{growth}) \cdot |\text{Weeks}_{scaled}| + \epsilon$.
    *   This formulation ensures that uncertainty is lowest at the baseline visit ($t=0$) and expands linearly as the model predicts into the future or past, preventing overconfidence on distant test points.

### 2. Data
*   **Content-Adaptive Slice Selection:**
    *   For each patient, identify the "Anchor" slice (Max Lung Area). Select two additional slices where lung area drops to 50% of the maximum (Apical/Basal). This ensures anatomical consistency **Cite solution_lesson_node_00012**.
*   **Auxiliary Target Generation:**
    *   During preprocessing, perform a simple Ordinary Least Squares (OLS) linear regression on each training patient's history (Weeks vs. FVC) to calculate their "True Slope" ($\gamma_{true}$). This will be used as a supervision target.
*   **Standardization:**
    *   Target `FVC` and inputs (`Baseline FVC`, `Weeks`, `Percent`, `Age`) are **Z-score standardized** **Cite solution_lesson_node_00006**. The $\gamma_{true}$ target is also calculated in this standardized space.

### 3. Training
*   **Loss Function:**
    *   **Primary:** Modified Laplace Log Likelihood ($L_{LL}$) calculated using the predicted $\mu(t)$ and $\sigma(t)$.
    *   **Auxiliary:** Mean Squared Error ($L_{MSE}$) between the predicted slope parameter $\gamma$ and the pre-calculated $\gamma_{true}$.
    *   **Total:** $L = L_{LL} + \lambda \cdot L_{MSE}$ (where $\lambda \approx 1.0$). This explicitly guides the image features to learn prognostic signs of decline.
*   **Uncertainty Constraints:**
    *   We use a small numerical floor ($\epsilon=0.05$) to prevent NLL singularity **Cite solution_lesson_node_00013**, but we **do not** enforce the metric's 70ml clip in the architecture **Cite solution_lesson_node_00014**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Differential Learning Rates:** `1e-4` for the EfficientNet backbone, `1e-3` for the MLP Head **Cite solution_lesson_node_00027**.
    *   **Duration:** 50 Epochs to allow for fine-tuning convergence **Cite solution_lesson_node_00009**.

### 4. Evaluation
*   **Inference:**
    *   Pass the baseline CT and metadata to generate the 5 parameters.
    *   For each requested `Week` in the test set, calculate $\mu_{scaled}(t)$ and $\sigma_{scaled}(t)$ using the trajectory equations.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{target\_dist} + \mu_{target\_dist}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{target\_dist}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply the hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for the submission file.
