Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and ensure reproducibility with `seed_everything`. We will use the provided `Config` settings but ensure the execution fits within the time limits (the default 50 epochs on this small dataset is very fast).
2.  **Training**: Execute the training pipeline using the imported `run_training` function. This handles data loading, model initialization, training loops, validation monitoring, and saving the best checkpoint.
3.  **Model Loading**: After training, re-initialize the `MAZR_DS` model and load the weights from the saved `best_model.pth` to ensure we are analyzing the optimal version of the model.
4.  **Validation & Metric Calculation**:
    *   Run inference on the hold-out validation set.
    *   Inverse-transform the normalized predictions and targets to their original scale (ml).
    *   Compute the official competition metric using `calculate_metric`.
    *   **Crucial**: Print the `Final Validation Metric` in the specified format.
5.  **Failure Analysis**:
    *   Compute the absolute error for each validation sample.
    *   Extract feature values (Baseline FVC, Weeks, Age) from the validation data.
    *   Calculate and print the Pearson correlation between the model's error and these input features to identify potential biases or weak points.
6.  **Submission Generation**:
    *   Check if the validation metric exceeds the threshold (`-6.573619738753321`).
    *   If passed, load the test set using `get_test_dataloader`.
    *   Generate predictions, inverse-transform them, and apply the specific post-processing rules (clipping sigma at 70ml).
    *   Save the formatted predictions to `submission.csv`.
