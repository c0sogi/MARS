Based on the comprehensive analysis of the accumulated lessons, I propose the **Balanced-Capacity Restricted-Anchor Network (BCRA-Net)**.

This solution represents a structural synthesis of the high-performing **Dual-Stream** topology **Cite solution_lesson_node_00052** with critical corrections for **Input Isolation** **Cite solution_lesson_node_00177**, **Dimensionality Balance** **Cite solution_lesson_node_00146**, **Visual Embedding Capacity** **Cite solution_lesson_node_00183**, and **Metric Alignment** **Cite solution_lesson_node_00164**. It explicitly resolves the conflict between signal preservation (via restricted anchors) and multi-modal fusion (via balanced bottlenecks) that hindered previous iterations.

### 1. Model
The architecture is a hybrid CNN-MLP utilizing a **Parallel Dual-Stream Latent Summation** topology designed to enforce a strong autoregressive bias while allowing for robust, balanced visual corrections.

*   **Stream A: Restricted-Input Affine Anchor (The Foundation):**
    *   **Input Restriction:** This stream receives **only** `Baseline FVC` and `Relative Time` ($t_{rel}$). We explicitly **exclude** static metadata (Age, Sex, Smoking) from this branch to strictly enforce the autoregressive inductive bias ($y_t \approx f(y_0, t)$) and prevent signal dilution **Cite solution_lesson_node_00177**.
    *   **Architecture:** An **Over-Parameterized MLP** (`Linear(2 -> 128) -> ReLU -> Linear(128 -> 128)`).
    *   **Capacity:** We maintain a latent width of **128 dimensions**. We reject narrower bottlenecks (e.g., 64) to ensure the anchor has sufficient capacity to model the identity mapping and linear decay without optimization bottlenecks **Cite solution_lesson_node_00060**.
    *   **Affine Constraints:** We strictly ensure `bias=True` in all layers to allow the model to learn stable global intercepts **Cite solution_lesson_node_00180**.

*   **Stream B: Balanced Contextual Residual (The Correction):**
    *   **Backbone:** **EfficientNet-B2**. Selected for its balance of native resolution (260x260) and parameter efficiency **Cite solution_lesson_node_00071**.
    *   **Fine-Tuning:** Unfreeze top two stages; keep bottom frozen **Cite solution_lesson_node_00027**.
    *   **Feature Extraction:** **Global Average Pooling** from the final layer.
    *   **Pre-Fusion Bottleneck (Structural Innovation):** The high-dimensional backbone output (1408-dim) is immediately projected to **128 dimensions** via a Linear layer. This prevents the high-dimensional image noise from statistically dominating the subsequent fusion step **Cite solution_lesson_node_00146**, while maintaining enough variance for texture representation **Cite solution_lesson_node_00183**.
    *   **Context Injection:** We concatenate the **Projected Image (128-dim)** with **All Raw Clinical Scalars** (`Baseline FVC`, `Time`, `Age`, `Sex`, `SmokingStatus`). This ensures the deep branch is conditioned on the full patient context **Cite solution_lesson_node_00139**.
    *   **Architecture:** An **MLP** (`Linear(Fused -> 256) -> ReLU -> Linear(256 -> 128)`).
    *   **Regularization:** We explicitly **exclude Dropout**. Since this stream learns a weak residual correction, stochastic regularization drowns out the gradient signal **Cite solution_lesson_node_00126**.

*   **Latent Fusion & Constraint-Aware Head:**
    *   **Fusion:** $H_{final} = \text{StreamA}_{output} + \text{StreamB}_{output}$. This summation enforces a residual learning paradigm in the 128-dimensional latent space **Cite solution_lesson_node_00052**.
    *   **Head:** A shared Linear layer projects $H_{final}$ to $\mu_{scaled}$ and $\sigma_{raw}$.
    *   **Metric Constraint:** We enforce the metric's 70ml floor *architecturally* within the standardized space.
        *   Calculate $\epsilon_{std} = 70 / \sigma_{global\_target}$.
        *   $\sigma_{scaled} = \text{Softplus}(\sigma_{raw}) + \epsilon_{std}$.
        *   This prevents the model from predicting uncertainties below the metric's threshold, resolving the divergence between validation loss and metric score **Cite solution_lesson_node_00164**.

### 2. Data
*   **Preprocessing:**
    *   **Radiological Windowing:** Standard **Lung Window (Level: -600 HU, Width: 1500 HU)** **Cite solution_lesson_node_00090**.
    *   **Content-Adaptive Slice Selection:** Select "Anchor" slice (Max Lung Area) and two boundary slices (50% area) **Cite solution_lesson_node_00124**.
    *   **Relative Time ($t_{rel}$):** $t_{rel} = \text{Weeks} - \text{Baseline\_Week}$. Scale by 0.01. **No Z-score** to preserve physical origin **Cite solution_lesson_node_00036**.
    *   **Feature Encoding:** **Ordinal Encoding** for `SmokingStatus` **Cite solution_lesson_node_00103**.
    *   **Target Normalization:** Normalize targets using **Global Statistics** (all visits), not baseline statistics, to avoid covariate shift **Cite solution_lesson_node_00155**.
    *   **Input Normalization:** Input scalars are standardized but passed **raw** (no Batch Norm) **Cite solution_lesson_node_00017**.
    *   **Exclusions:** Explicitly exclude `Percent` to avoid proxy leakage **Cite solution_lesson_node_00069**.

### 3. Training
*   **Loss Function:** **Metric-Aligned Laplace Log Likelihood (Standardized)**.
    *   $L = \frac{\sqrt{2} |y_{scaled} - \mu_{scaled}|}{\sigma_{scaled}} + \ln(\sqrt{2} \sigma_{scaled})$.
    *   We optimize in the standardized space to avoid gradient instability **Cite solution_lesson_node_00165** while explicitly including the $\sqrt{2}$ constants **Cite solution_lesson_node_00066** and avoiding arbitrary clipping **Cite solution_lesson_node_00138**.
*   **Optimizer & Schedule:**
    *   **AdamW** with **Cosine Annealing**.
    *   **Dynamic Horizon:** Link `T_max` to total epochs **Cite solution_lesson_node_00100**.
    *   **Differential Learning Rates:** `1e-4` (Backbone) vs `1e-3` (Heads) **Cite solution_lesson_node_00027**.
    *   **Batch Size:** Strictly $\ge 32$ **Cite solution_lesson_node_00094**.

### 4. Evaluation
*   **Inference:**
    *   Calculate $t_{rel}$. Predict $\mu_{scaled}$ and $\sigma_{scaled}$ via BCRA-Net.
*   **Inverse Transformation:**
    *   $\mu_{final} = \mu_{scaled} \times \sigma_{global} + \mu_{global}$.
    *   $\sigma_{final} = \sigma_{scaled} \times \sigma_{global}$ (Scale only) **Cite solution_lesson_node_00006**.
*   **Post-Processing:**
    *   Apply hard clip $\sigma_{final} = \max(\sigma_{final}, 70)$ strictly for submission **Cite solution_lesson_node_00014**.
