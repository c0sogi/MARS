The implementation strategy is as follows:

1.  **Setup**: Define input and output directories (`./input`, `./metadata`) and the random seed (`42`).
2.  **Data Loading**: Read the raw `train.csv` and `test.csv` files using pandas.
3.  **Path Generation**: Create a new column `image_path` in both dataframes. This column will contain the relative path to the patient's DICOM directory (e.g., `train/ID...` or `test/ID...`). This points to the folder containing the DICOM files, which is the standard way to reference volumetric CT data.
4.  **Data Splitting**:
    *   Use `GroupShuffleSplit` on the training data to create a training and validation set.
    *   Group by `Patient` ID to ensure that all records for a specific patient stay in the same split (preventing data leakage).
    *   Use an 80:20 split ratio.
5.  **Metadata Saving**: Save the resulting dataframes (`train.csv`, `val.csv`, `test.csv`) to the `./metadata` directory.
6.  **Validation**:
    *   Reload the generated metadata files.
    *   Print summary statistics (row counts, unique patients, FVC statistics).
    *   Verify that there is no overlap of Patient IDs between the training and validation sets.
    *   Perform a file existence check on a random sample of 1000 paths (or all if less than 1000) from each dataset. The script checks if the directory specified in `image_path` exists relative to `./input`.
    *   Raise an error if the missing file ratio exceeds 0.5 or if the split verification fails.
