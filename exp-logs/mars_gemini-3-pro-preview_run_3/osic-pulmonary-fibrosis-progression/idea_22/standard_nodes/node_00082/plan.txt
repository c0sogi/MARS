The implementation strategy for the **Static-Prior Preserving Dual-Stream Network (SPP-DS Net)** orchestration script (`runfile.py`) is as follows:

1.  **Initialization**: We will set random seeds for reproducibility and detect the available computation device (GPU/CPU).
2.  **Training**: We will invoke the `train_model` function from the library. This handles the data loading, model instantiation, training loop with the custom Laplace Log Likelihood loss, and saves the best model checkpoint based on validation performance.
3.  **Validation & Analysis**:
    *   We will load the saved best model checkpoint.
    *   We will run inference on the hold-out validation set to calculate the final competition metric.
    *   We will perform failure analysis by calculating the correlation between the absolute prediction error and key features (Age, Percent, Weeks) to understand model biases.
4.  **Submission**:
    *   If the validation metric exceeds the specified threshold, we will generate predictions for the test set.
    *   We will parse `sample_submission.csv` to identify all target `Patient_Week` combinations.
    *   We will manually construct the feature vectors for these targets by combining the static baseline metadata from `test.csv` with the computed relative weeks.
    *   We will use a custom Dataset wrapper to reuse the image loading and caching logic from the provided `LungDataset`.
    *   Finally, we will inverse-transform the predictions, apply the confidence clipping rule, and save the result to `submission.csv`.
