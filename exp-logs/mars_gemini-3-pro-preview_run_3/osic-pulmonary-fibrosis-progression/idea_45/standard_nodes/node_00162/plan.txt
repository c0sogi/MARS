Implementation Strategy:
My primary optimization is to structurally correct the "Stream A" of the dual-stream architecture. The previous solution implemented this stream as a non-linear MLP (`Linear -> ReLU -> Linear`), which violated the design principle of the high-performing DSPRNet. According to **Lesson 52 (Cite solution_lesson_node_00052)**, this stream should be a **Linear Residual Stream**—a direct linear mapping of the dominant autoregressive features (Baseline FVC and Time) to the latent space. This allows the model to trivially learn the strong identity relationship ($FVC \approx Baseline$) without optimization bottlenecks.

Furthermore, I will ensure this linear stream is "over-parameterized" by projecting the 5 clinical features to the 64-dimensional latent space using a single `nn.Linear` layer, as recommended by **Lesson 60 (Cite solution_lesson_node_00060)**. This avoids bottlenecking the strong signal while maintaining the necessary linearity to sum correctly with the deep interaction stream.
