# Optimized Strategy: Dual-Graph Interaction Network with Physics-Aware Auxiliary Tasks

This strategy addresses the need for angular information (critical for 3-bond couplings) while avoiding the numerical instability of Spherical Bessel Functions encountered in previous attempts. It synthesizes the robust feature engineering of the "Current Best" solution with a structural innovation inspired by Line Graph Neural Networks (like ALIGNN).

### Model
1.  **Backbone: Dual-Graph Architecture**
    *   The model will operate on two interlinked graphs to explicitly model many-body interactions:
        *   **Atom Graph:** Nodes represent atoms; edges represent inter-atomic distances.
        *   **Line Graph:** Nodes represent the *edges* of the Atom Graph (i.e., bonds); edges in this graph represent angles between bonds (triplets).
    *   **Feature Lifting (Distances):** We will retain the successful strategy of "lifting" scalar Euclidean distances in the Atom Graph into high-dimensional vectors using **Gaussian Radial Basis Functions (RBF)** followed by an MLP (Cite solution_lesson_node_00007). This ensures the model learns complex, non-linear edge filters.
    *   **Feature Lifting (Angles):** To capture angular dependencies without the numerical instability of recursive Bessel functions (Cite solution_lesson_node_00008), we will compute the cosine of the bond angles ($\cos \theta_{ijk}$) in the Line Graph. These scalar cosine values will be expanded using **Gaussian RBFs** defined over the interval $[-1, 1]$. This provides a numerically stable, high-dimensional representation of geometry.
    *   **Message Passing:** The network will alternate between **Line Graph Convolutions** (updating bond representations based on angles) and **Atom Graph Convolutions** (updating atom representations based on bonds). This flow allows the model to explicitly process the 3-body interactions required for the Karplus equation.

2.  **Type-Specific Readout Heads**
    *   Recognizing the heterogeneous nature of the target, the model will employ **8 distinct MLP heads**, one for each coupling type (e.g., `1JHC`, `3JHH`). The output of the backbone for the interacting atom pair will be routed to the specific head corresponding to the input coupling type.

3.  **Auxiliary Physics Heads**
    *   To regularize the latent space and enforce chemical realism, we will add auxiliary output heads to the Atom Graph nodes. These will predict the **Magnetic Shielding Tensors** and **Mulliken Charges**.

### Data
1.  **Preprocessing**:
    *   Construct the **Atom Graph** using a 5.0 Å radius cutoff.
    *   Construct the **Line Graph** by connecting all pairs of edges in the Atom Graph that share a common atom (forming triplets).
    *   Precompute RBF expansions for distances and angular cosines.
2.  **Target Standardization**:
    *   We will strictly apply **Per-Group Target Standardization** (Cite solution_lesson_node_00003).
    *   Calculate the mean ($\mu_{type}$) and standard deviation ($\sigma_{type}$) for the `scalar_coupling_constant` independently for each of the 8 coupling types.
    *   Transform the training targets: $z = \frac{y - \mu_{type}}{\sigma_{type}}$. This prevents the large-magnitude `1JHC` couplings from dominating the gradients.

### Training
1.  **Loss Function**:
    *   We will use a **Multi-Task Loss**: $L_{total} = L_{coupling} + \lambda_1 L_{shielding} + \lambda_2 L_{charge}$.
    *   $L_{coupling}$ will be the Mean Absolute Error (L1) on the standardized targets.
2.  **Optimizer**:
    *   Use **AdamW** with a **Cosine Annealing Warm Restarts** scheduler. This helps the model escape local minima and refine the solution within the computational budget.

### Evaluation
1.  **Inference**:
    *   Process test molecules to generate Atom and Line graphs.
    *   Pass data through the Dual-Graph Network.
    *   Route the embeddings to the appropriate **Type-Specific Head** to obtain the standardized prediction $z_{pred}$.
2.  **Inverse Transformation**:
    *   Convert the predictions back to the original physical scale using the pre-computed training statistics: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ (Cite solution_lesson_node_00003).
3.  **Submission**:
    *   Generate the final CSV with `id` and the restored `scalar_coupling_constant`.
