The following script demonstrates the end-to-end pipeline for the Scalar Coupling Prediction task using the provided library files. It covers configuration customization for rapid testing, data loading with the `MolecularGraphDataset`, model initialization with `DualGraphNetwork`, training and inference using the `Trainer` class, and validation of utility functions like `GroupScaler` and the evaluation metric.

To ensure the demonstration runs quickly (under 60 seconds), the script monkey-patches the `Config` class to enable debug mode (using only a small subset of molecules) and reduces model complexity (hidden dimensions, layers) and training epochs.
