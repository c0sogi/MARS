# Optimized Strategy: Physics-Calibrated Dual-Graph Network with Edge-Centric Readout

This strategy refines the "Dual-Graph" concept from Idea 5 by correcting three fatal flaws identified in the lessons: numerical instability in feature engineering, information bottlenecks in the readout layer, and task dominance in the loss function.

### Model
1.  **Backbone: Stabilized Dual-Graph Architecture**
    *   The model will process two coupled graphs to capture the 3-body geometric interactions (bond angles) required for the Karplus equation:
        *   **Atom Graph:** Nodes represent atoms; edges represent chemical bonds (distances).
        *   **Line Graph:** Nodes represent the *bonds* of the Atom Graph; edges represent the angles between adjacent bonds.
    *   **Stable Feature Lifting:**
        *   **Distances:** In the Atom Graph, scalar distances will be expanded using **Gaussian Radial Basis Functions (RBF)**. These are passed through an MLP to generate continuous edge filters **Cite solution_lesson_node_00007**.
        *   **Angles:** In the Line Graph, we will compute the cosine of bond angles ($\cos \theta_{ijk}$). Crucially, we will expand these values using **Gaussian RBFs** defined over $[-1, 1]$ rather than recursive Spherical Bessel Functions. This ensures numerical stability while retaining high-dimensional expressivity **Cite solution_lesson_node_00008**.
    *   **Message Passing:** The network will alternate updates between the Line Graph (updating bond embeddings based on angular geometry) and the Atom Graph (updating atom embeddings based on bond features).

2.  **Structural Innovation: Edge-Centric Readout**
    *   Previous iterations failed because they discarded the rich bond embeddings ($e_{ij}$) at the final layer, relying only on atom embeddings ($h_i, h_j$).
    *   **Direct Edge Injection:** The final readout module will explicitly concatenate the **learned bond embedding** ($e_{ij}$) from the last layer of the Line Graph with the node embeddings of the interacting pair. This ensures that the precise, high-frequency geometric information captured by the Line Graph is available for the final regression **Cite solution_lesson_node_00011**.

3.  **Type-Specific Prediction Heads**
    *   The concatenated representation ($h_i || h_j || e_{ij}$) will be routed to one of **8 distinct MLP heads**, selected based on the coupling type (e.g., `1JHC`). This allows specialized processing for the vastly different physical mechanisms of each coupling type.

4.  **Auxiliary Physics Heads**
    *   We retain the auxiliary heads on the Atom Graph nodes to predict **Magnetic Shielding Tensors** and **Mulliken Charges**, acting as a physics-informed regularizer.

### Data
1.  **Preprocessing**:
    *   Construct Atom and Line graphs with a 5.0 Å cutoff.
    *   Precompute Gaussian RBF expansions for distances and angular cosines.
2.  **Primary Target Standardization**:
    *   Apply **Per-Group Target Standardization**. Calculate $\mu_{type}$ and $\sigma_{type}$ for the `scalar_coupling_constant` for each of the 8 types. Transform training targets: $z = \frac{y - \mu_{type}}{\sigma_{type}}$ **Cite solution_lesson_node_00003**.
3.  **Auxiliary Target Normalization**:
    *   To prevent the auxiliary tasks from hijacking the gradient descent (as seen in Lesson 00009), we will also **standardize the auxiliary targets** (Shielding and Charges) to have zero mean and unit variance. This ensures that the loss magnitude for these tasks is comparable to the primary task (approx. range 0-1), preventing task dominance **Cite solution_lesson_node_00009**.

### Training
1.  **Loss Function**:
    *   $L_{total} = L_{coupling} + \lambda (L_{shielding} + L_{charge})$.
    *   With all targets (primary and auxiliary) standardized to unit variance, we can safely set $\lambda \approx 0.1$ without the auxiliary loss being orders of magnitude larger than the primary loss **Cite solution_lesson_node_00009**.
2.  **Optimizer**:
    *   **AdamW** with a **Cosine Annealing Warm Restarts** scheduler.

### Evaluation
1.  **Inference**:
    *   Pass test structures through the Dual-Graph Network.
    *   Extract $h_i, h_j$ (atoms) and $e_{ij}$ (bond) for the target pair.
    *   Route to the appropriate **Type-Specific Head** to predict $z_{pred}$.
2.  **Inverse Transformation**:
    *   Convert the predictions back to the original scale: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ **Cite solution_lesson_node_00003**.
3.  **Submission**:
    *   Generate the final CSV file.
