# Optimized Strategy: Stabilized Geometric Line Graph Network (S-GLGN) with Continuous Filter Convolutions

This strategy represents a structural evolution of the "Dual-Graph" concept (Idea 5). It synthesizes the high-frequency geometric filtering of SchNet (Idea 1) with the angular awareness of Line Graphs, while rigorously correcting the numerical instability, information bottlenecks, and optimization imbalances identified in the lessons.

### Model
1.  **Backbone: Dual-Graph with Continuous Filter Convolutions**
    *   **Hierarchical Structure:** The model will maintain two interlinked graphs:
        *   **Atom Graph:** Nodes are atoms; edges are bonds (distances).
        *   **Line Graph:** Nodes are the *edges* of the Atom Graph; edges represent bond angles (triplets).
    *   **Continuous Filter Convolutions (CFConv):** Instead of standard GCN layers or static weights, we will employ Continuous Filter Convolutions in *both* graphs.
        *   **Atom Level:** Scalar distances will be expanded using **Gaussian Radial Basis Functions (RBF)** and passed through an MLP to generate dynamic edge filters **Cite solution_lesson_node_00007**.
        *   **Line Level:** To capture angular dependencies (critical for 3-bond couplings), we will compute the cosine of bond angles ($\cos \theta_{ijk}$). Crucially, we will expand these cosine values using **Gaussian RBFs** defined over $[-1, 1]$ rather than recursive Spherical Bessel Functions. This ensures numerical stability while retaining the expressivity of high-dimensional geometric filters **Cite solution_lesson_node_00008**.
    *   **Message Passing:** Information will flow from the Line Graph (updating bond embeddings $e_{ij}$ based on angles) to the Atom Graph (updating atom embeddings $h_i$ based on bonds), allowing 3-body effects to propagate into the atomic representations.

2.  **Readout: Edge-Centric Injection & Type-Specific Routing**
    *   **Edge Injection:** We will explicitly resolve the "information bottleneck" identified in previous iterations. The final prediction vector will be constructed by concatenating the learned node embeddings of the interacting pair ($h_i, h_j$) *and* the learned edge embedding ($e_{ij}$) from the final layer of the Line Graph. This ensures the model retains precise, edge-specific geometric data for the regression **Cite solution_lesson_node_00011**.
    *   **Type-Specific Heads:** This concatenated vector will be routed to one of **8 distinct MLP heads** based on the coupling type (e.g., `1JHC`, `3JHH`), allowing the model to learn specialized physics for each interaction type.

3.  **Regularization: Physics-Calibrated Auxiliary Tasks**
    *   We will attach auxiliary heads to the Atom Graph nodes to predict **Magnetic Shielding Tensors** and **Mulliken Charges**. This forces the latent space to encode valid electronic environments.

### Data
1.  **Preprocessing**
    *   Construct **Atom Graphs** (cutoff 5.0 Å) and corresponding **Line Graphs** (connecting edges that share an atom).
    *   Precompute Gaussian RBF expansions for edge lengths and angular cosines.
2.  **Target Standardization (Primary)**
    *   We will strictly apply **Per-Group Target Standardization**. We will calculate the mean ($\mu_{type}$) and standard deviation ($\sigma_{type}$) for the `scalar_coupling_constant` independently for each of the 8 coupling types.
    *   The training targets will be transformed: $z = \frac{y - \mu_{type}}{\sigma_{type}}$. This prevents the large-magnitude `1JHC` couplings from dominating the loss **Cite solution_lesson_node_00003**.
3.  **Target Standardization (Auxiliary)**
    *   To prevent **Task Dominance**, we will also standardize the auxiliary targets (Shielding and Charges) to have zero mean and unit variance. This ensures that the auxiliary loss magnitude is comparable to the primary loss, preventing the optimizer from ignoring the coupling prediction **Cite solution_lesson_node_00009**.

### Training
1.  **Loss Function**
    *   We will use a balanced Multi-Task Loss: $L_{total} = L_{coupling} + \lambda (L_{shielding} + L_{charge})$.
    *   Since all targets are standardized to unit variance, we can set $\lambda \approx 0.1$ to treat physics prediction as a regularizer rather than a dominant objective **Cite solution_lesson_node_00009**.
2.  **Optimizer**
    *   **AdamW** with a **Cosine Annealing Warm Restarts** scheduler to efficiently navigate the loss landscape and escape local minima.

### Evaluation
1.  **Inference**
    *   Pass test structures through the S-GLGN.
    *   Extract $h_i, h_j$ and $e_{ij}$ for the target pair.
    *   Route to the appropriate **Type-Specific Head** to predict the standardized value $z_{pred}$.
2.  **Inverse Transformation**
    *   Convert the predictions back to the original physical scale using the pre-computed training statistics: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ **Cite solution_lesson_node_00003**.
