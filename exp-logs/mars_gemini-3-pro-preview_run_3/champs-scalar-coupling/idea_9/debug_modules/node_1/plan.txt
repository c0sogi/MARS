The issue is that the `dipole_moments.csv` file provides the vector components (`X`, `Y`, `Z`) of the dipole moment, but the preprocessing pipeline attempts to access a derived feature `dipole_mag` which does not exist in the raw data. This feature was calculated in the EDA script but omitted from the production code.

To fix this, I will modify `library/preprocessing.py` to explicitly calculate the Euclidean norm (magnitude) of the dipole moment vector immediately after loading the dataframe. This ensures the `dipole_mag` column is available when the code later attempts to access it via `.loc`.
