The following script implements the end-to-end orchestration for the scalar coupling prediction task. It leverages the provided library modules to load data, train the Distance-Weighted Graph Convolutional Network (DW-GCN), perform validation failure analysis, and generate the final submission.

**Implementation Strategy:**
1.  **Setup & Configuration**: We initialize the environment and set random seeds for reproducibility.
2.  **Data Loading**: We use the `get_dataloaders` function in **debug mode** with a sample size of 50,000. This ensures the pipeline runs efficiently within the time limit while providing enough data to establish a strong baseline.
3.  **Model Training**: We instantiate the `CouplingPredictor` and `ModelTrainer`. The training loop runs for a maximum of 25 epochs (as defined in the config) with early stopping.
4.  **Validation**: After training, we load the best model checkpoint and compute the `Final Validation Metric` (Log MAE) on the validation set.
5.  **Failure Analysis**: We perform a manual inference pass on the validation set to calculate the correlation between the model's absolute error and input features (Distance and Target Magnitude). This helps identify systematic weaknesses.
6.  **Submission**: Finally, we generate predictions for the test set and save them to `submission.csv`.
