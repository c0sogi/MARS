This script demonstrates the end-to-end usage of the provided machine learning library for the scalar coupling prediction task. It performs the following steps:
1.  **Setup**: Suppresses progress bars and sets random seeds for reproducibility.
2.  **Data Loading**: Uses `get_dataloaders` in debug mode to quickly load a small subset of the data (1000 samples) and verifies the structure of the generated batches.
3.  **Model Initialization**: Instantiates the `CouplingPredictor` (GCN + MLP) and performs a forward pass check to ensure dimension correctness.
4.  **Utility Verification**: Validates the `TargetScaler` logic (z-score normalization) and the `calculate_log_mae` metric function.
5.  **Training & Inference**: Initializes the `ModelTrainer`, runs a single training epoch, performs validation, and generates predictions for the test set, saving the result to a submission file.
