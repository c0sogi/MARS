# Optimized Strategy: Flattened Directional Message Passing with Stable Geometric Bases

This strategy introduces a **Directional Message Passing** architecture (capable of modeling bond angles) but fundamentally re-engineers the data and training pipeline to use **Flattened Contiguous Memory Layouts**. This ensures the model can train on the full dataset (3.3M+ samples) rather than a debug subset, overcoming the primary cause of failure in previous geometric approaches.

### Model
1.  **Backbone: Directional Message Passing (Edge-Centric)**
    *   Unlike the "Current Best" (which used node-centric SchNet), this model will maintain embeddings for **directed edges** (bonds) rather than atoms. This allows the explicit modeling of bond angles ($\theta_{ijk}$) by aggregating messages from "preceding" edges ($k \to j$) to update the "current" edge ($j \to i$) **Cite solution_lesson_node_00020**.
    *   **Stable Angular Features:** To capture the angular dependencies required for the Karplus equation (critical for 3-bond couplings), we will compute the cosine of bond angles ($\cos \theta_{ijk}$). Crucially, we will expand these values using **Gaussian Radial Basis Functions (RBF)** defined over $[-1, 1]$ rather than recursive Spherical Bessel Functions. This ensures numerical stability while retaining high-dimensional expressivity **Cite solution_lesson_node_00008**.
    *   **Distance Features:** Scalar bond lengths will be expanded using **Gaussian RBFs** and processed by an MLP to generate continuous filters, replacing static edge weights **Cite solution_lesson_node_00007**.

2.  **Readout: Edge-Injected Type-Specific Heads**
    *   **Edge Injection:** To avoid the information bottleneck identified in previous attempts, the final prediction will not rely solely on atom embeddings. We will explicitly concatenate the **learned edge embedding** ($e_{ij}$) of the interacting pair with the node embeddings ($h_i, h_j$) in the final layer. This injects precise, high-frequency geometric information directly into the regressor **Cite solution_lesson_node_00011**.
    *   **Type-Specific Routing:** The concatenated vector will be passed to one of **8 distinct MLP heads**, selected based on the coupling type (e.g., `1JHC`). This addresses the heterogeneity of the target variable **Cite solution_lesson_node_00003**.

### Data
1.  **Preprocessing: Flattened Structure-of-Arrays (SoA)**
    *   **Innovation:** We will abandon the object-oriented `InMemoryDataset` (list of `Data` objects) used in failed attempts. Instead, we will pre-compute the entire dataset into **monolithic, flattened Numpy arrays** (e.g., one giant `edge_index` tensor, one `triplet_index` tensor, one `attributes` tensor) with an offset map for efficient batching. This minimizes memory fragmentation and Python overhead, enabling training on the full 3.3M dataset **Cite solution_lesson_node_00016**.
    *   **Graph Construction:** We will generate a radius graph (cutoff 5.0 Å) and pre-calculate triplet indices ($k, j, i$) for the directional updates.
    *   **Target Standardization:** We will strictly apply **Per-Group Target Standardization**. We will calculate $\mu_{type}$ and $\sigma_{type}$ for each of the 8 coupling types and transform training targets $z = \frac{y - \mu_{type}}{\sigma_{type}}$. This prevents high-magnitude types from dominating the gradients **Cite solution_lesson_node_00003**.
    *   **Canonical Indexing:** We will ensure all categorical maps (like coupling types) use integer indices to prevent silent data corruption during lookups **Cite solution_lesson_node_00017**.

2.  **Auxiliary Data:**
    *   We will include Magnetic Shielding and Mulliken Charges as auxiliary targets. However, to prevent **Task Dominance**, these targets will also be standardized (z-scored) to ensure their loss magnitude is comparable to the primary task **Cite solution_lesson_node_00009**.

### Training
1.  **Loss Function:**
    *   **Primary:** We will use **L1 Loss (Mean Absolute Error)**. The target distribution is heavy-tailed, and previous experiments showed that MSE causes outliers to distort the gradients. L1 loss aligns the optimization with the competition metric **Cite solution_lesson_node_00013**.
    *   **Total:** $L_{total} = L_{coupling\_L1} + 0.1 \times (L_{shielding\_L1} + L_{charge\_L1})$.
2.  **Optimizer:**
    *   **AdamW** with a **Cosine Annealing Warm Restarts** scheduler. This allows the model to converge efficiently on the massive flattened dataset within the 24-hour limit.

### Evaluation
1.  **Inference:**
    *   Load test structures into the flattened format.
    *   Pass through the Directional Message Passing network.
    *   Extract $h_i, h_j$ and the specific directed edge embedding $e_{ij}$ (or $e_{ji}$) for the target pair.
    *   Route to the appropriate **Type-Specific Head** to predict $z_{pred}$.
2.  **Inverse Transformation:**
    *   Convert predictions back to the physical scale: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ **Cite solution_lesson_node_00003**.
