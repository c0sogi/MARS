The following Python script demonstrates the end-to-end usage of the provided scalar coupling prediction library.

**Implementation Strategy:**
1.  **Configuration Override**: We first modify the global `Config` class to enable `DEBUG` mode and set a small sample size (100 molecules). This ensures the demonstration runs quickly (within seconds/minutes) compared to the full dataset. We also redirect the working directory to `./working/demo_run` to keep outputs isolated.
2.  **Data Processing (`DataFactory`)**: We explicitly invoke the data processing pipeline to generate the flattened arrays from the raw CSV/XYZ files. We verify the integrity of the generated data dictionary.
3.  **Data Loading (`Loader`)**: We instantiate the `FlattenedGraphDataset` and `GraphCollator` to show how individual molecular graphs are sliced from the monolithic arrays and batched for the neural network.
4.  **Model Inference (`Model`)**: We initialize the `DirectionalMPNN` and perform a forward pass with a single batch of data to verify the input/output tensor shapes and types.
5.  **Training Loop (`Trainer`)**: We initialize the `Trainer` class and run a short training cycle (2 epochs) to demonstrate the integration of data loading, model forward/backward passes, loss calculation, and validation.
6.  **Verification**: Assertions are placed at every step to confirm that data shapes are correct, files are generated, and the model produces valid predictions.
