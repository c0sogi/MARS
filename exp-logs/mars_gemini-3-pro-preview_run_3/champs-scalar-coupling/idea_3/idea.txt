# Optimized Strategy: Physics-Regularized Directional Network with Type-Specific Readouts

This strategy evolves the **Directional Message Passing** concept (Idea 2) by integrating **Auxiliary Physics Supervision** and a **Type-Specific Readout Architecture**. It directly addresses the heterogeneity of the target variable (highlighted in Lesson 00003) and the need for expressive geometric filtering (highlighted in Lesson 00007).

### Model
1.  **Backbone: Directional Message Passing with Geometric Basis**
    *   We will employ a Directional Message Passing Neural Network (similar to DimeNet++) that updates **directed edge embeddings** rather than just node embeddings. This explicitly captures bond angles ($\theta_{ijk}$) by aggregating messages from triplets ($k \to j \to i$).
    *   **Basis Expansion:** We will explicitly "lift" the continuous scalar features into high-dimensional vector spaces. Distances will be expanded using **Radial Basis Functions (RBF)** (Cite solution_lesson_node_00007), and angles will be expanded using **Spherical Bessel Functions (SBF)**. This allows the model to learn complex, non-linear filtering functions (e.g., modeling electron orbital overlaps) rather than relying on static weights.

2.  **Structural Innovation: Auxiliary Physics Branches**
    *   To enforce chemically meaningful representations, we will add **Auxiliary Output Heads** to the backbone.
    *   These heads will project the learned node representations to predict the **Magnetic Shielding Tensors** (3x3 matrix flattened to 9 values) and **Mulliken Charges** (scalar) for each atom.
    *   Since scalar coupling is physically related to the second derivative of energy with respect to magnetic moments, forcing the model to predict these first-order magnetic and electronic properties will act as a powerful regularizer, guiding the latent space to encode the true electronic environment.

3.  **Structural Innovation: Type-Specific Readout Heads**
    *   The previous ideas used a single MLP to predict all coupling types, concatenated with a type embedding. However, the physical mechanisms for `1J` (Fermi contact dominated) and `3J` (Spin-orbit/Karplus dominated) couplings are vastly different.
    *   We will replace the single readout with a **Multi-Head Readout Module**. The model will have **8 distinct MLP heads**, one for each coupling type (e.g., `1JHC`, `2JHH`).
    *   During the forward pass, the model will route the atom-pair representation to the specific MLP head corresponding to the input coupling type. This allows the network to learn specialized functions for each interaction type without interference.

### Data
1.  **Preprocessing**:
    *   Generate a **Radius Graph** (cutoff 5.0 Å) from the XYZ files.
    *   Compute **Edge Indices** (pairs) and **Triplet Indices** (angles).
    *   Load `magnetic_shielding_tensors.csv` and `mulliken_charges.csv` and map them to the corresponding nodes in the training graphs.

2.  **Target Standardization**:
    *   We will strictly apply **Per-Group Target Standardization** (Cite solution_lesson_node_00003).
    *   Calculate the mean ($\mu_{type}$) and standard deviation ($\sigma_{type}$) for the `scalar_coupling_constant` independently for each of the 8 coupling types.
    *   Transform training targets: $z = \frac{y - \mu_{type}}{\sigma_{type}}$. This is critical to prevent the large-magnitude `1JHC` couplings from dominating the gradients.

### Training
1.  **Loss Function**:
    *   We will use a **Multi-Task Loss**: $L_{total} = L_{coupling} + \lambda_1 L_{shielding} + \lambda_2 L_{charge}$.
    *   $L_{coupling}$: Mean Absolute Error (L1) on the standardized scalar coupling constants.
    *   $L_{shielding}$ / $L_{charge}$: MSE or L1 loss on the auxiliary physics targets.
2.  **Optimizer**: AdamW with a cosine annealing scheduler to efficiently navigate the loss landscape.

### Evaluation
1.  **Inference**:
    *   Pass the test structures through the network. The auxiliary heads are ignored during inference.
    *   The appropriate **Type-Specific Head** will generate a prediction in the standardized space ($z_{pred}$).
2.  **Inverse Transformation**:
    *   Convert the predictions back to the original scale using the training statistics: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ (Cite solution_lesson_node_00003).
3.  **Submission**:
    *   Format the output into `id, scalar_coupling_constant` CSV format.
