# Optimized Strategy: Directional Message Passing with Geometric Basis Expansion

Based on the lessons learned, the previous isotropic Graph Convolutional Network (GCN) approaches fail to capture the angular dependencies critical for predicting scalar coupling constants (e.g., the Karplus equation for 3-bond couplings). To address this, I propose a structural evolution to a **Directional Message Passing** architecture (inspired by DimeNet++), which explicitly models the geometric interactions between atom triplets (angles) rather than just atom pairs (distances).

### Model
The core innovation is shifting from atom-centric message passing to **edge-centric message passing**.

1.  **Geometric Basis Expansion**:
    *   **Radial Basis Functions (RBF):** We will retain the successful strategy of "lifting" scalar Euclidean distances into a high-dimensional vector space using a basis expansion (e.g., Gaussian RBFs) Cite solution_lesson_node_00007. This allows the model to learn complex, non-linear distance-dependent filters.
    *   **Spherical Basis Functions (SBF):** We will introduce angular information by expanding the angle $\theta_{ijk}$ between atom triplets using Spherical Bessel Functions. This allows the network to distinguish between different bond angles, which is physically required to predict J-coupling accurately.

2.  **Directional Interaction Blocks**:
    *   Instead of aggregating messages from neighbors to a central node (Node $\leftarrow$ Neighbors), the model will aggregate messages to update **directed edges** (Edge $ji$ $\leftarrow$ Edges $kj$).
    *   This enables the model to process triplets of atoms ($k \to j \to i$), thereby explicitly incorporating the bond angle $\theta_{ijk}$ into the message passing flow. This is a fundamental structural change from the previous DW-GCN and SchNet-like ideas.

3.  **Prediction Head**:
    *   After several interaction layers, the learned representations for the atoms in the target pair (Atom 0 and Atom 1) are extracted.
    *   These are concatenated with the **Coupling Type Embedding** and the **RBF-expanded distance** between the pair.
    *   A multi-layer perceptron (MLP) regresses the final scalar coupling constant.

### Data
1.  **Graph Construction**:
    *   Construct a **Radius Graph** with a cutoff of 5.0 Å.
    *   Generate **Edge Indices** for all connected pairs ($j, i$).
    *   Generate **Triplet Indices** ($k, j, i$) for all paths of length 2 within the graph to facilitate angular message passing.

2.  **Target Preprocessing**:
    *   We will strictly explicitly preserve the **Per-Group Target Standardization** strategy. The target variable `scalar_coupling_constant` will be standardized ($z = \frac{y - \mu_{type}}{\sigma_{type}}$) independently for each of the 8 coupling types (e.g., `1JHC`, `2JHH`) Cite solution_lesson_node_00003. This ensures that high-magnitude coupling types do not dominate the gradients.

### Training
1.  **Loss Function**: We will use the **Mean Absolute Error (L1 Loss)** on the standardized targets.
2.  **Optimizer**: **AdamW** with a learning rate of 1e-3 (with warmup) and a cosine decay schedule.
3.  **Regularization**: We will apply **Auxiliary Task Learning** if memory permits, using the shared encoder to also predict the `mulliken_charges` (available in the dataset) for each atom. This forces the geometric representations to be chemically meaningful beyond just the coupling task.

### Evaluation
1.  **Inference Pipeline**:
    *   For the test set, generate the same radius graphs and triplet indices.
    *   Pass the data through the Directional Message Passing model.
    *   **Inverse Transformation**: The model outputs predictions in the standardized space. These must be inverse-transformed ($y = z \cdot \sigma_{type} + \mu_{type}$) using the statistics computed from the training set Cite solution_lesson_node_00003.
2.  **Submission**:
    *   Combine the `id` and the restored `scalar_coupling_constant` values into the submission file.
