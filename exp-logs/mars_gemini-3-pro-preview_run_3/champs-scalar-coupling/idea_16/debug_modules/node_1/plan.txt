The error `_pickle.UnpicklingError: Weights only load failed` occurs because the checkpoint file contains a NumPy scalar (the validation score), which is not on the default allowlist for `torch.load` in PyTorch 2.6+ (Cite debug_lesson_15). To resolve this, I will explicitly set `weights_only=False` in the `torch.load` call within `library/utils.py`, permitting the deserialization of the trusted checkpoint file containing the NumPy scalar.
