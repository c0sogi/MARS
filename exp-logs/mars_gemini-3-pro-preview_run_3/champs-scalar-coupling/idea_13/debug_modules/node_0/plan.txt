Implementation Strategy:
1.  **Configuration Override**: We will modify the global `Config` class attributes at runtime to enable `DEBUG` mode, reduce the sample size to 100 molecules, set `MAX_EPOCHS` to 1, and redirect outputs to a specific `./working/demo_run` directory. This ensures the script runs quickly and doesn't interfere with existing work.
2.  **Data Processing**: We will instantiate the `DataProcessor` to generate the Structure-of-Arrays (SoA) files for the small debug subset. We will verify that the expected numpy files are created.
3.  **Dataset & Batching**: We will load the `SoADataset` and use the `SoACollator` to create a mini-batch. We will assert that the resulting tensors (positions, edges, coupling indices) have consistent shapes and valid values.
4.  **Model Forward Pass**: We will initialize the `DMPNN` model and perform a forward pass with the mini-batch. We will verify that the output dictionary contains predictions for couplings, charges, and shielding with correct dimensions.
5.  **Loss Calculation**: We will use the `LossComputer` to calculate the standardized L1 loss and the competition metric (LogMAE), ensuring the loss pipeline functions correctly.
6.  **Training Loop**: We will run the `Trainer` for one epoch to demonstrate the integration of data loading, forward pass, backward pass, and validation.
7.  **Inference**: We will run the `Predictor` to generate a submission file from the trained model, verifying the output format.
