# Optimized Strategy: Heterogeneous Ensemble with Corrected SAM and Shift-TTA

### Model
The solution will implement a **Heterogeneous Ensemble** of three distinct CNN architectures. This leverages the "Diversity of Errors" principle to stabilize predictions and reduce variance on this micro-dataset (**Cite solution_lesson_node_00043**).
- **Backbones:**
    1.  **ResNet-18:** The proven baseline for capacity/generalization balance (**Cite solution_lesson_node_00003**).
    2.  **EfficientNet-B0:** For parameter efficiency and MBConv feature extraction.
    3.  **DenseNet-121:** For feature reuse and robustness in small-data regimes.
- **Input Adaptation:** Strictly adhere to the **3-Channel Rule** by replicating the single-channel spectrograms 3 times to form pseudo-RGB images. This preserves the pre-trained weights' integrity (**Cite solution_lesson_node_00014**).
- **Head Design:** Use the native classification heads. We explicitly reject complex heads like Multi-Sample Dropout or Concatenated Pooling, which were found to introduce unnecessary complexity and overfitting (**Cite solution_lesson_node_00053**, **Cite solution_lesson_node_00051**).

### Data
The pipeline prioritizes the "Golden Recipe" of domain-curated features and rigid spatial adherence.
- **Source Selection:** Strictly use the **Provided Standard Spectrograms** (`supplemental_data/spectrograms`). Explicitly exclude "Filtered Spectrograms" to avoid signal loss (**Cite solution_lesson_node_00048**) and avoid raw audio generation (**Cite solution_lesson_node_00028**).
- **Preprocessing:** Resize all spectrograms to **224x224**. This rigid adherence to the pre-trained model's spatial expectations is superior to tiling or custom aspect ratios for this micro-dataset (**Cite solution_lesson_node_00030**, **Cite solution_lesson_node_00019**).
- **Augmentation Pipeline:**
    1.  **Horizontal Translation:** Apply time-shifting using **Zero-Padding** (not wrapping) to preserve temporal causality (**Cite solution_lesson_node_00033**).
    2.  **Photometric Augmentation:** Apply **Brightness and Contrast Jitter** to mimic Gain and SNR variations (**Cite solution_lesson_node_00009**).
    3.  **Mixup:** Apply **Mixup Regularization** to prevent overfitting (**Cite solution_lesson_node_00007**).
    4.  **Constraint:** Strictly **disable Horizontal Flipping** (**Cite solution_lesson_node_00006**).

### Training
- **Structural Innovation (Optimization):** Implement **Sharpness-Aware Minimization (SAM)** wrapping the **AdamW** optimizer.
    - *Rationale:* Standard optimizers often converge to sharp minima on small datasets, leading to poor generalization. SAM explicitly minimizes both loss value and loss sharpness, finding a "flat minimum" that is robust to parameter perturbations. This addresses the high variance issues identified in **Cite solution_lesson_node_00043**.
    - *Correction:* Crucially, unlike the failed attempt in Idea 19, this implementation will strictly integrate SAM with a **Learning Rate Scheduler**. As established in **Cite solution_lesson_node_00059**, advanced optimizers cannot compensate for the lack of a decay schedule.
- **Training Configuration:**
    - **Scheduler:** Use **Monotonic Cosine Annealing** (decaying from `1e-3` to `1e-6` over the full duration) to ensure convergence (**Cite solution_lesson_node_00022**, **Cite solution_lesson_node_00059**).
    - **Regularization:** Maintain **High Weight Decay** (e.g., `1e-2`) within the base AdamW optimizer to strictly control model complexity (**Cite solution_lesson_node_00052**).
    - **Batch Size:** Maintain a physical batch size of **32**. We explicitly reject reducing the batch size (which destabilizes Batch Norm, **Cite solution_lesson_node_00054**) or using Gradient Accumulation (which reduces update frequency too much, **Cite solution_lesson_node_00057**).
    - **Stopping Criterion:** Re-implement **Aggressive Early Stopping** (Patience=15). We reject the "extended training" approach of Idea 19/60, as it led to overfitting the validation folds (**Cite solution_lesson_node_00060**).
- **Splitting Strategy:** Implement **Iterative Stratification** (5 Folds) to ensure representative distribution of rare classes (**Cite solution_lesson_node_00017**).
- **Loss Function:** Use **BCEWithLogitsLoss** (**Cite solution_lesson_node_00034**).
- **Validation:** Use a **Robust Metric Implementation** that explicitly handles missing classes in validation batches (**Cite solution_lesson_node_00038**).

### Evaluation
- **Test-Time Augmentation (TTA):** Implement **Horizontal Shift TTA**. For each test sample, generate predictions for:
    1.  Original Image.
    2.  Image shifted left (padded).
    3.  Image shifted right (padded).
    Average the predictions. This accounts for potential signal truncation at the edges during resizing.
- **Ensemble Inference:** The final prediction will be an average of **15 models** (3 Architectures $\times$ 5 Folds).
- **Process:** Pass the test set spectrograms (resized to 224x224) through all 15 models (using TTA) and average the resulting probabilities. This combines the variance reduction of the heterogeneous ensemble with the generalization benefits of SAM.
