This script demonstrates the end-to-end pipeline for the bird classification task using the provided library. It performs the following steps:

1.  **Configuration Setup**: Modifies the global `Config` to use a temporary working directory and reduces hyperparameters (epochs, folds, architectures) for a rapid execution suitable for demonstration.
2.  **Data Pipeline Verification**: Validates the creation of cross-validation folds, dataset instantiation, and DataLoader functionality, ensuring correct tensor shapes and data types.
3.  **Model & Training Verification**: Instantiates a ResNet-18 model and runs a complete training cycle (training and validation) for 2 folds for 1 epoch each. It verifies that checkpoints are correctly saved.
4.  **Metric Verification**: Tests the `RobustAUC` metric class with synthetic edge-case data (e.g., missing classes) to ensure stability.
5.  **Inference & Submission**: Executes the `InferenceEngine` to load the trained models, apply Test-Time Augmentation (TTA), and generate a submission file in the correct format.
