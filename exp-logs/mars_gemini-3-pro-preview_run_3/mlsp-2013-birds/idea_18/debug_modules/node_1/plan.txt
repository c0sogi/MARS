The error is caused by `pandas` treating empty label fields in the CSV files as `NaN` (Not a Number). When the code converts these `NaN` values to strings using `str()`, they become the string `"nan"`. The subsequent logic `if label_str != "?"` allows `"nan"` to pass, and `int("nan")` then raises a `ValueError`.

To fix this, I will modify `library/data.py` to explicitly check for `NaN` values using `pd.isna()` before attempting to parse the labels. This applies to both the `BirdDataset.__getitem__` method (to prevent runtime errors during training) and the `get_folds` function (to fix the immediate crash during setup). This ensures that empty labels are correctly treated as "no species present" rather than invalid data, adhering to the principle of sanitizing inputs for `NaN` values (Cite debug_lesson_3).
