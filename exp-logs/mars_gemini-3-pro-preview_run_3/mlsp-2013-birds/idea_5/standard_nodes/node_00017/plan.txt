4.  **Metric Calculation & Failure Analysis**:
    *   Aggregate the Out-Of-Fold (OOF) predictions and ground truth labels.
    *   Compute the global ROC AUC score on the OOF data.

    *   **Failure Analysis**: Calculate the Mean Absolute Error (MAE) for each OOF sample. Compute correlations between this error and input features (Signal Mean, Signal Std, Label Count) to identify error sources.

5.  **Submission Generation**:

    *   If passed, average the accumulated test predictions across the 5 folds.
    *   Format the predictions into the required `Id,Probability` CSV structure.
    *   Save the file to `./submission/submission.csv`.
