# Optimized Strategy: ResNet-18 with Spatial Pyramid Pooling (SPP) and Iterative Stratification

### Model
The solution will utilize a **ResNet-18** backbone, but with a critical structural innovation in the pooling layer to address the "Temporal Context" issue without incurring the "Parameter Overfitting" penalty.
- **Backbone:** Use **ResNet-18** (pretrained on ImageNet). This smaller backbone is selected over ResNet-34/50 to minimize overfitting on the extremely small dataset (206 samples), balancing capacity with generalization.
- **Structural Innovation (Spatial Pyramid Pooling):** Replace the standard Global Average Pooling (GAP) layer with a **Spatial Pyramid Pooling (SPP)** layer.
    - *Rationale:* **Cite solution_lesson_node_00001** established that global aggregation destroys the temporal context necessary to disentangle overlapping sounds. However, **Cite solution_lesson_node_00019** demonstrated that learnable heads (like Attention Pooling) fail due to parameter overfitting on small data. SPP solves both: it aggregates features from fixed grid regions (e.g., 1x1, 2x2, 4x4) of the feature map, preserving coarse spatial (time-frequency) localization without adding any learnable parameters.
- **Input Adaptation:** Strictly adhere to the "3-Channel Rule" by **replicating the single-channel Log-Mel spectrogram three times** to create a pseudo-RGB image. This ensures the pretrained filters are utilized effectively without modifying the first convolutional layer (**Cite solution_lesson_node_00014**).

### Data
The pipeline prioritizes "Rigid Adherence" to the pretrained model's expectations while simulating domain-specific variations.
- **Spectrogram Generation:** Generate Log-Mel Spectrograms from raw audio.
- **Resizing:** Resize the spectrograms to the standard **224x224** resolution. While this distorts the aspect ratio, **Cite solution_lesson_node_00019** proves that adhering to the spatial structure the model was pretrained on (square ImageNet inputs) outperforms domain-correct but custom aspect ratios in data-scarce regimes.
- **Augmentation Pipeline:**
    1.  **Photometric Augmentation:** Apply **Brightness and Contrast Jitter** to simulate recording gain and SNR variations (**Cite solution_lesson_node_00009**).
    2.  **Time Shifting:** Apply random **Horizontal Translation** to simulate temporal variability (**Cite solution_lesson_node_00007**).
    3.  **Mixup:** Apply **Mixup Regularization** to smooth decision boundaries (**Cite solution_lesson_node_00007**).
    4.  **Constraint:** Strictly **disable Horizontal Flipping**, as it violates temporal causality (**Cite solution_lesson_node_00006**).

### Training
- **Splitting Strategy:** Implement **Iterative Stratification** for Cross-Validation. Standard random splitting fails to distribute rare classes (some appearing only 2-3 times) across folds. Iterative Stratification ensures the joint distribution of label combinations is preserved, guaranteeing every fold has representative training data (**Cite solution_lesson_node_00017**).
- **Loss Function:** Use **BCEWithLogitsLoss** for multi-label classification.
- **Optimizer:** Use **AdamW** with a **Cosine Annealing** scheduler.

### Evaluation
- **Ensemble Inference:** Train 5 independent models (one for each fold of the Iterative Stratification).
- **Aggregation:** Pass the test set spectrograms through all 5 models and average the predicted probabilities. This ensemble approach is critical to mitigate the high variance inherent in learning from such a small dataset.
