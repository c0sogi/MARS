The implementation strategy follows the "Optimized Strategy" using a Multi-View ResNet-18 approach.

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class and set random seeds for reproducibility.
2.  **Training**: Iterate through all 5 folds defined in the configuration. For each fold, execute the `run_fold` function from `library.train`. This trains the Multi-View ResNet-18 model on the training set and validates it, saving the best checkpoint based on AUC score.
3.  **Validation & Failure Analysis**:
    *   After training, reload the best model for each fold.
    *   Perform inference on the validation set of that fold (Out-Of-Fold predictions).
    *   Aggregate predictions and targets across all folds to compute the global Cross-Validation AUC.
    *   Print the `Final Validation Metric`.
    *   Perform failure analysis by calculating the correlation between the prediction error (Mean Absolute Error) and the complexity of the sample (defined as the number of bird species present).
4.  **Submission**:
    *   Check if the validation metric exceeds the threshold (0.9072993371210134).
    *   If successful, perform inference on the test set using an ensemble of all 5 trained models (averaging the probabilities).
    *   Format the predictions according to the competition requirement (mapping `rec_id` and `species` to `Id`).
    *   Save the result to `submission.csv`.
