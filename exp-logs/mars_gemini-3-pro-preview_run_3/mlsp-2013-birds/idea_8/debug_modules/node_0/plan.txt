The following implementation demonstrates the end-to-end workflow using the provided library files.

**Strategy Outline:**
1.  **Configuration**: Initialize the `Config` class and override specific parameters (e.g., `EPOCHS`, `DEBUG`, `BATCH_SIZE`) to ensure the demonstration runs quickly (under a few minutes) while still exercising all code paths.
2.  **Data Pipeline**: Use `get_dataloaders` to initialize the data pipeline. This demonstrates caching, data splitting, and the custom `BirdDataset` class. We verify the shape of the output tensors to confirm the Multi-View tiling strategy (Batch, Tiles, Channels, Height, Width).
3.  **Model Initialization**: Instantiate the `MultiViewResNet` model and perform a forward pass with a dummy batch to verify the architecture and output dimensions.
4.  **Training Simulation**: Execute `run_fold` for a single fold in debug mode. This validates the training loop, loss calculation, backpropagation, validation routine, and checkpoint saving mechanisms in `train.py`.
5.  **Inference & Submission**: Load the trained model (or initialized model if training was too short to save a checkpoint), run inference on the test set, and generate a submission file formatted according to the competition requirements (`Id` = `rec_id * 100 + species`).
