The following script demonstrates the complete pipeline for the bird species classification task using the provided library files. It covers data loading, model instantiation, optimizer configuration with Layer-Wise Learning Rate Decay (LLRD), training, validation, and inference with Test-Time Augmentation (TTA).

To ensure rapid execution and verification:
1.  **Configuration Overrides**: Key hyperparameters (epochs, batch size, debug mode) are modified in the `Config` class to run on a tiny subset of data.
2.  **Data Pipeline**: Loads data using `get_data` with `debug=True`, verifying shapes and types.
3.  **Model & Optimization**: Instantiates a `resnet18` backbone, verifies the LLRD learning rate distribution in the optimizer, and checks the scheduler.
4.  **Execution Loop**: Runs a single epoch of training, a validation pass, and TTA inference, asserting valid outputs at each step.
5.  **Reproducibility**: Seeds are fixed at the start.
