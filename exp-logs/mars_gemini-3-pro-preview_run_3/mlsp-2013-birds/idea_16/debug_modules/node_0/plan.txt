The following script demonstrates the usage of the provided library files for the bird species classification task. It covers data preparation, dataset instantiation, model initialization, training logic (via a single fold execution in debug mode), and utility verification.

The strategy involves:
1.  **Configuration Override**: Modifying `Config` parameters (epochs, batch size, debug mode) to ensure the demonstration runs quickly (under a few minutes).
2.  **Data Loading**: Using `prepare_data` to load/create folds and verifying the dataframe structure.
3.  **Component Verification**: Instantiating `BirdDataset` and `BirdClassifier` to verify input/output shapes and data transformations.
4.  **Training Integration**: Executing `run_fold` for a single fold using a lightweight backbone (`resnet18`) and a tiny subset of data (`DEBUG=True`) to verify the training pipeline without waiting for full convergence.
5.  **Utility Testing**: Validating `calculate_multilabel_auc` and `average_checkpoints` with synthetic data to ensure correctness.
