To establish a robust and highly efficient baseline for the bird species classification task, I propose a **Shallow Multi-Layer Perceptron (MLP)** trained on the pre-computed bag-of-words features. This approach prioritizes speed and simplicity by bypassing raw audio or image processing, utilizing the low-dimensional feature representations provided in the dataset.

### Model
The architecture is a lightweight Feed-Forward Neural Network designed for multi-label classification.
*   **Input Layer:** Accepts a 100-dimensional feature vector corresponding to the "histogram of segments" for a recording.
*   **Hidden Layer:** A single dense layer with 64 neurons and ReLU activation to capture basic non-linear interactions between feature clusters.
*   **Regularization:** A Dropout layer (rate=0.5) follows the hidden layer to prevent overfitting on the small dataset.
*   **Output Layer:** A dense layer with 19 neurons (one per species) followed by a Sigmoid activation function. This produces independent probabilities for each class, suitable for the multi-label nature of the task.

### Data
The data processing pipeline focuses on utilizing the provided supplemental features:
1.  **Feature Loading:** Load the `supplemental_data/histogram_of_segments.txt` file. This file contains pre-computed, normalized 100-dimensional vectors for all recordings (train and test), representing the frequency of different sound segment clusters in each clip.
2.  **Data Merging:** Map the feature vectors to the training, validation, and test sets using the `rec_id` column found in the generated metadata files (`metadata/train.csv`, `metadata/val.csv`, `metadata/test.csv`).
3.  **Label Preparation:** For the training and validation sets, convert the space-separated string labels into multi-hot encoded vectors of length 19 (where 1 indicates the presence of a species).

### Training
The training procedure is designed for rapid convergence and stability:
*   **Loss Function:** Use Binary Cross-Entropy Loss (e.g., `BCEWithLogitsLoss` in PyTorch) which treats each species prediction as an independent binary classification problem.
*   **Optimizer:** Employ the Adam optimizer with a standard learning rate (e.g., 0.001) for efficient gradient descent.
*   **Loop:** Train for a fixed number of epochs (e.g., 50) or use Early Stopping based on the validation set's ROC AUC score to select the best model checkpoint. Given the small data size, training should complete in seconds.

### Evaluation
The evaluation phase generates the final submission:
1.  **Inference:** Pass the test set's histogram features through the trained MLP to obtain a `(n_test, 19)` matrix of probabilities.
2.  **Formatting:** Flatten the predictions into the required submission format. Iterate through each test `rec_id` and species index (0-18), calculating the submission `Id` as `rec_id * 100 + species_id`, and pairing it with the predicted probability.
