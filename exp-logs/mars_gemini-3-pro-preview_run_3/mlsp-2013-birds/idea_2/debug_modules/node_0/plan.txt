The following script demonstrates the usage of the provided library components for the bird species classification task. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration settings to optimize for a quick demonstration (disabling pretrained weight downloads, reducing worker count).
2.  **Dataset Verification**: Loads the training metadata, creates a `BirdDataset` instance with a small subset, and verifies the shape and type of the generated spectrograms and labels.
3.  **Model Verification**: Instantiates the `BirdClassifier`, performs a forward pass with a dummy input batch, and asserts that the output dimensions match the expected `(Batch_Size, Num_Classes)`.
4.  **Augmentation Verification**: Tests the Mixup augmentation logic to ensure inputs and targets are correctly processed.
5.  **Metric Verification**: Validates the `calculate_roc_auc` function using synthetic prediction data.
6.  **Pipeline Execution**: Runs the full training and inference pipeline in `debug` mode (reduced epochs and dataset size) via `train_and_evaluate`, and verifies that a submission file is correctly generated.
