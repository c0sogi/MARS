The `UnpicklingError` occurs because the `score` (AUC) saved in the PyTorch checkpoint is a Numpy scalar (e.g., `numpy.float64`) produced by `calculate_roc_auc`. Modern PyTorch versions (2.6+) default to `weights_only=True` in `torch.load`, which restricts unpickling to safe globals (like Tensors) and blocks arbitrary objects like Numpy scalars. To fix this, I will modify `library/utils.py` to explicitly cast the `score` to a native Python `float` in `save_checkpoint` and ensure `calculate_roc_auc` returns a native float.
