The implementation strategy is as follows:

1.  **Setup and Initialization**: Import necessary libraries and the provided modules (`library.config`, `library.utils`, `library.data`, `library.models`, `library.engine`). Initialize the environment using `Config.setup()` and ensure reproducibility with `seed_everything`.
2.  **Data Preparation**: Execute `prepare_folds` to generate the cross-validation splits and verify the creation of the cache file.
3.  **Data Loading**: Instantiate dataloaders for both CNN and MLP streams using `get_dataloaders` for a specific fold (Fold 0). Fetch a single batch from each loader to verify input/target shapes and data types.
4.  **Model Instantiation**: Create instances of `BirdCNN` (using ResNet18) and `BirdMLP`. Perform a forward pass with the fetched batch data to confirm the models process inputs correctly and produce outputs of the expected shape (Batch Size, Num Classes).
5.  **Training Loop**: Run `train_one_epoch` for a single epoch using the CNN model and a basic optimizer. This demonstrates the training logic and ensures the loss calculation works.
6.  **Validation Loop**: Run `validate` using the validation dataloader. Verify that it returns valid loss and AUC metrics, and that predictions match the target shape.
7.  **Checkpointing**: Use `CheckpointManager` to save the model state based on the validation metric, confirming that the file is correctly written to the checkpoint directory.
8.  **Inference**: Use `get_test_dataloaders` to load the test set and perform a forward pass (inference) on a single batch, verifying the output probabilities are within the valid range [0, 1].
