The following script demonstrates the usage of the provided library modules to perform a complete machine learning workflow: data loading, model instantiation, training, and inference.

**Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes to set up a "demo" environment. This includes creating a dedicated working directory, reducing the number of epochs to 2, setting the batch size to 8, and limiting the CNN models to just `resnet18` to ensure the script executes within the time limit.
2.  **Data Verification**: We utilize `library.data` to load data splits and create DataLoaders. We assert that the batches produced have the correct shapes for both image (CNN) and feature (MLP) streams.
3.  **Model Verification**: We instantiate both the CNN and MLP models using `library.models` and perform a forward pass with the dummy batches to verify output shapes.
4.  **Training Simulation**: We use `library.training.Trainer` to train both the MLP and CNN models for a few epochs. This verifies the training loop, loss calculation, backpropagation, and checkpoint saving mechanisms.
5.  **Inference Execution**: We initialize `library.inference.EnsemblePredictor`, which automatically detects the checkpoints created in the previous step, runs inference on the test set, and generates a submission file. We verify the existence and format of the output file.
6.  **Utility Testing**: We explicitly test the metric calculation (`calculate_roc_auc`) and the Mixup augmentation handler (`MixupHandler`) from `library.utils`.
