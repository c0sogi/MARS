The execution failure is caused by an `_pickle.UnpicklingError` when `torch.load` attempts to deserialize a checkpoint containing a Numpy scalar (`numpy.float64`) in the `score` field, which is restricted by the default `weights_only=True` security setting in PyTorch 2.6+. To fix this, I will modify `library/utils.py` to explicitly cast the metric to a native Python `float` and the epoch to a native Python `int` before saving them in the checkpoint dictionary. I will also ensure `calculate_robust_roc_auc` returns a native float to prevent this issue from propagating elsewhere. Cite debug_lesson_1.
