The strategy implements a Heterogeneous Ensemble using ResNet18, EfficientNet-B0, and DenseNet121 trained with Sharpness-Aware Minimization (SAM) and Mixup augmentation. The pipeline uses a 5-fold cross-validation scheme on the development set. For the final evaluation, the ensemble is tested on the hold-out validation set to compute the robust ROC AUC and perform failure analysis (correlating errors with image energy and standard deviation). If the validation metric exceeds the specified threshold, the system generates predictions for the test set using Horizontal Shift Test-Time Augmentation (TTA) to account for temporal alignment variations, averaging predictions from the original, left-shifted, and right-shifted spectrograms.
