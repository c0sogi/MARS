The following script demonstrates the end-to-end usage of the provided library modules for the bird species classification task. It follows these steps:

1.  **Configuration**: Initializes the `Config` class in debug mode to ensure fast execution with a small subset of data and fewer epochs.
2.  **Data Preparation**: Generates cross-validation folds using `prepare_folds` and creates PyTorch DataLoaders for training, validation, and testing using `get_loaders` and `get_test_loader`. It validates the shape of the data batches.
3.  **Model Initialization**: Instantiates the `BirdClassifier` using `get_model` and verifies the output shape with a dummy forward pass.
4.  **Loss Calculation**: Computes the loss using `AsymmetricLoss` on the dummy outputs to ensure the loss function operates correctly.
5.  **Training**: Runs a complete training cycle for one epoch using the `Trainer` class and verifies that the model checkpoint is saved successfully.
6.  **Metric Calculation**: Demonstrates the `calculate_roc_auc` function with synthetic data.
