Implementation Strategy:
1.  **Setup & Paths**: Define the paths for input data (`./input/essential_data`) and output metadata (`./metadata`).
2.  **Data Loading**:
    -   Load `rec_id2filename.txt` to map recording IDs to filenames.
    -   Load `CVfolds_2.txt` to identify the official training (fold 0) and test (fold 1) splits.
    -   Load `rec_labels_test_hidden.txt` to get the labels. Parse this manually since it has variable column lengths (e.g., `rec_id,label1,label2`).
3.  **Data Merging**: Merge all information into a single Pandas DataFrame based on `rec_id`.
4.  **Path Construction**: Create a `file_path` column containing relative paths to the WAV files (e.g., `essential_data/src_wavs/filename.wav`).
5.  **Splitting**:
    -   Separate the data into `official_train` (fold=0) and `test` (fold=1).
    -   Shuffle `official_train` with `RANDOM_STATE = 42`.
    -   Prepare a binary label matrix (One-Hot Encoded) for stratification.
    -   Use `iterative_train_test_split` from `scikit-multilearn` to split `official_train` into `train` (80%) and `val` (20%) while maintaining label distributions. Fallback to random split if stratification fails (e.g., due to extremely rare classes).
6.  **Metadata Saving**: Save `train.csv`, `val.csv`, and `test.csv` to the `./metadata` directory.
7.  **Verification**:
    -   Print summary statistics (counts, class distributions).
    -   Verify that at least 50% of a random sample of 1000 file paths exist (raising an error if not).
    -   Verify that the train/val split is disjoint and follows the 80:20 ratio logic.
