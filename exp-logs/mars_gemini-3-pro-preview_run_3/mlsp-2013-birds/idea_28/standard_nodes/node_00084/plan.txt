The `RuntimeError` is caused by **Artifact Pollution** in the checkpoint directory, where the inference loop indiscriminately loads all `*.pth` files, including incompatible artifacts (e.g., `best_model_fold_0.pth`) from previous runs or different configurations. This leads to a schema mismatch when `load_state_dict` attempts to load weights into the current model architecture. To fix this, I will tighten the file search pattern to `f"{model_name}_*.pth"`. This strictly matches the naming convention used by the `SnapshotManager` (e.g., `densenet121_fold0_epoch...pth`), ensuring that only valid, architecture-specific checkpoints are loaded for inference. This addresses the root cause by preventing the ingestion of invalid files. Cite {debug_lesson_13}.
