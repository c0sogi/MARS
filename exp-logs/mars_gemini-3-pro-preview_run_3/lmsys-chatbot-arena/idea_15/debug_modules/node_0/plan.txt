### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override specific parameters (`DEBUG`, `EPOCHS`, `TRAIN_BATCH_SIZE`) to ensure the demonstration runs quickly on a small subset of data.
2.  **Data Processing Verification**: Use `get_dataloaders` to load the debug dataset. Fetch a single batch from the training loader to verify the structure of the dictionary (keys, tensor shapes) and the correctness of the custom `CollateFn`.
3.  **Model Initialization and Forward Pass**: Instantiate the `SiameseDeberta` model. Perform a forward pass with the fetched batch to verify that the model architecture (shared backbone, pooling, interaction head) functions correctly and produces logits of the expected shape `(Batch_Size, 3)`.
4.  **Training Loop Simulation**: Initialize an optimizer and scheduler, then run the `train_fn` for a single epoch on the debug dataset. This verifies the gradient accumulation logic and mixed-precision training pipeline.
5.  **Inference and Metric Validation**: Run `inference_fn` on the test loader to demonstrate Test-Time Augmentation (TTA) and prediction generation. Finally, use `compute_log_loss` with dummy data to verify the metric calculation.
