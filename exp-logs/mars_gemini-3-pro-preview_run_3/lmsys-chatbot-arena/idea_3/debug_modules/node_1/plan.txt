The issue stems from the `sklearn.metrics.log_loss` function in scikit-learn version 1.7.2, which has removed the `eps` parameter that was previously used to clip probabilities. The current implementation passes `eps=1e-15`, resulting in a `TypeError`. To fix this, I will remove the `eps` argument from the function call in `library/utils.py`, allowing scikit-learn to handle clipping internally using its default behavior.
