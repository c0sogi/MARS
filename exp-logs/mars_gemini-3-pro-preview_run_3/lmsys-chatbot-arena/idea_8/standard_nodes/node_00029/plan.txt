5.  **Failure Analysis**:
    *   Generate predictions on the validation set using `inference_fn`.
    *   Calculate the element-wise Cross Entropy loss (error magnitude) for each validation sample.
    *   Compute correlations between this error magnitude and input text lengths (Prompt, Response A, Response B) to identify if verbosity or length differences drive errors.

6.  **Submission Generation with TTA**:
    *   Check if the validation metric meets the threshold (< 1.0061561136439758).
    *   If passed, perform **Test-Time Augmentation (TTA)**:
        *   Predict on the original test set.
        *   Create a swapped version of the test set (Response A <-> Response B).
        *   Predict on the swapped set.
        *   Average the predictions: $P(A) = 0.5 \times (P_{orig}(A) + P_{swapped}(B))$.
    *   Save the final probabilities to `./submission/submission.csv`.
