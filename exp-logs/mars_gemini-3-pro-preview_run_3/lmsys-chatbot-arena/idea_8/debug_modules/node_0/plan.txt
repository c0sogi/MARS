The following script demonstrates the end-to-end workflow using the provided library files. It performs the following steps:
1.  **Setup**: Initializes the environment and seeds for reproducibility.
2.  **Data Preparation**: Manually loads the dataframes using `library.data.load_dataset_df`, slices them to a small subset for rapid execution, and constructs `ChatbotDataset` and `DataLoader` instances.
3.  **Model Initialization**: Instantiates the `SiameseDeberta` model defined in `library.model`.
4.  **Sanity Checks**: Verifies the shape and content of a single data batch and the model's output logits.
5.  **Training & Evaluation**: Runs a short training loop (1 epoch on the subset) and validation using `library.engine`.
6.  **Inference**: Generates predictions on the test subset.
7.  **Submission**: Formats the predictions and saves a submission file, verifying its correctness.
