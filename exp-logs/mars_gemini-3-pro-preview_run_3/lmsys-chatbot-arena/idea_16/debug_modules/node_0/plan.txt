The following script demonstrates the end-to-end usage of the provided library modules for the Chatbot Arena preference prediction task. It performs the following steps:

1.  **Configuration**: Overrides default `Config` settings to run in a lightweight "Debug" mode (small sample size, 1 epoch) to ensure rapid execution.
2.  **Data Loading**: Uses `library.data.get_dataloaders` to load and process a subset of the training, validation, and test data. It verifies the structure and shapes of the generated batches.
3.  **Model Instantiation**: Initializes the `SiameseDeberta` model from `library.model` and performs a dry-run forward pass to validate input/output dimensions and loss calculation.
4.  **Training Loop**: Executes the training process using `library.engine.run_training`, which handles mixed-precision training, gradient scaling, and model checkpointing.
5.  **Inference**: Generates predictions on the test set using `library.engine.predict_and_submit`, utilizing Test-Time Augmentation (TTA) as defined in the library.
6.  **Metric Verification**: Demonstrates the `compute_log_loss` utility with synthetic data.

This script is self-contained and asserts the correctness of shapes, file outputs, and logic flow.
