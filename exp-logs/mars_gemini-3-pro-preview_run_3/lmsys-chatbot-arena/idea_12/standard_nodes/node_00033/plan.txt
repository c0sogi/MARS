The following strategy outlines the implementation of the `runfile.py` script:

1.  **Configuration & Setup**: Initialize the `Config` class and override `epochs` to 1 to satisfy the "fast baseline" requirement while maintaining sufficient training on the dataset. Set random seeds using `seed_everything` for reproducibility.
2.  **Training**: Execute the `run_training` function. This handles data loading, model initialization, the training loop, validation monitoring, and saving the best model checkpoint. It returns the best model instance.
3.  **Validation Assessment**:
    *   Load the full validation dataset using `get_dataloader` and `prepare_data` to ensure consistency.
    *   Generate predictions on the validation set using `predict_fn`.
    *   Compute the **Log Loss** metric manually using the ground truth targets and predicted probabilities.
    *   Print the metric in the exact required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the per-sample Cross Entropy loss to quantify error magnitude.
    *   Compute text length features (Prompt, Response A, Response B) and the length difference between responses.
    *   Calculate and print the Pearson correlation between these features and the error magnitude to identify systematic weaknesses.
5.  **Submission Logic**:
    *   Compare the calculated validation metric against the strict threshold (`1.0005665522536111`).
    *   If the model performs better (lower metric), call `generate_submission` to create `submission.csv` for the test set, utilizing Test-Time Augmentation (TTA) as configured.
