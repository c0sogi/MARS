This script demonstrates the end-to-end usage of the provided library components for the Chatbot Arena preference prediction task. It performs the following steps:
1.  **Configuration**: Overrides default `Config` settings to run in "Debug Mode" (using a small subset of data and 1 epoch) for rapid execution.
2.  **Data Loading**: Uses `get_dataloaders` to create PyTorch DataLoaders for training, validation, and testing, verifying batch structures and shapes.
3.  **Model Initialization**: Instantiates the `SiameseDeberta` model, moves it to the GPU, and verifies the architecture.
4.  **Training**: executes a training loop for one epoch using `train_fn`, including mixed-precision training and gradient scaling.
5.  **Evaluation**: Runs `eval_fn` on the validation set to compute loss and generate predictions, asserting output correctness.
6.  **Inference**: Generates predictions on the test set using `inference_fn`.
7.  **Submission**: Formats the test predictions into a submission DataFrame and saves it to the specified path.
