The `Truncation error` occurs because the tokenizer is configured with `truncation="only_second"`, which forbids truncating the prompt (the first sequence). However, some prompts in the dataset exceed the maximum sequence length (especially in debug configurations with small `max_length`), making it impossible to fit the input within the limit without truncating the prompt. To resolve this, I will change the truncation strategy to `truncation=True` (which defaults to `longest_first`), allowing the tokenizer to truncate the prompt if necessary to satisfy the length constraint.
