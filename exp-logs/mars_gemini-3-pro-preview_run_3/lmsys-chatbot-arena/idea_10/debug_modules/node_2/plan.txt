The issue is that the attention scores `w` are computed in `float16` (Half precision) due to the `autocast` context, but the code attempts to mask invalid tokens with `-1e9`, which exceeds the minimum representable value of `float16` (~ -65,504), causing an overflow. To fix this, I will cast the attention score tensor `w` to `float32` before applying the mask, as recommended in Cite debug_lesson_8. This also ensures the subsequent softmax operation is performed in full precision for numerical stability (Cite debug_lesson_6).
