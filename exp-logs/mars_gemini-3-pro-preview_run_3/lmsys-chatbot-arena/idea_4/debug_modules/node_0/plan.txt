This script demonstrates the end-to-end usage of the provided library files for the Chatbot Arena task. It covers data loading, custom dataset verification, model instantiation, a complete training run (optimized for speed using debug settings), inference, and metric calculation.

The strategy involves:
1.  **Configuration Override**: Modifying the `Config` class to enable `DEBUG` mode and reduce epochs/batch sizes, ensuring the demonstration completes quickly.
2.  **Component Verification**:
    *   **Data**: explicit checks on the `ChatbotDataset` output to verify tokenization and scalar feature generation.
    *   **Model**: performing a forward pass with a real batch to verify tensor shapes and compatibility.
    *   **Engine**: executing the training and prediction loops provided in `library.engine`.
    *   **Utils**: validating the scoring function with synthetic data.
