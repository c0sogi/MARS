To address the performance ceiling of the independent Siamese LSTM architecture (Log Loss ~1.042), I will implement a **Pseudo Cross-Encoder** strategy as suggested in `solution_lesson_node_00006`. Instead of encoding the prompt and responses separately, I will concatenate them into single sequences: `[Prompt] <SEP> [Response]`. This allows the LSTM to process the interaction between the prompt and the response directly within its recurrence, capturing context that is lost in the independent encoding approach.

To support this, I will:
1.  **Update Config**: Increase `MAX_SEQ_LEN` to 512 to accommodate the concatenated sequences and reduce `BATCH_SIZE` to 64 to manage memory.
2.  **Update Tokenizer**: Add a special `<SEP>` token to demarcate the prompt from the response.
3.  **Update Dataset**: Modify the preprocessing logic to construct `Prompt + SEP + Response` sequences for both branches (A and B).
4.  **Update Model**: Adapt the `SiameseLSTM` to accept two inputs (the paired sequences) instead of three, while retaining the hybrid scalar features (lengths) which proved useful in `solution_lesson_node_00004`.
