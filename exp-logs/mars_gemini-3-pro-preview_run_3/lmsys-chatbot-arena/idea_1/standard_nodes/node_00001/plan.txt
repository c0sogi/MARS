The implementation strategy involves the following steps:

1.  **Configuration & Setup**: Initialize the `Config` object, setting a fixed random seed for reproducibility. Adjust hyperparameters for a fast baseline (e.g., reducing epochs to 5 and setting a batch size suitable for the A100 GPU).
2.  **Training**: Execute the `run_training` function from the `library.engine` module. This handles data loading, model initialization, and the training loop with early stopping, saving the best model to disk.
3.  **Validation & Metric Calculation**:
    *   Reload the best saved model.
    *   Load the validation `DataLoader`.
    *   Perform inference on the validation set to obtain predicted probabilities.
    *   Extract ground truth targets from the validation batches.
    *   Compute the Log Loss metric using `sklearn.metrics.log_loss` and print it in the required format.
4.  **Failure Analysis**:
    *   Calculate the error magnitude for each validation sample (using Cross Entropy Loss per sample).
    *   Load the raw validation metadata to extract text features (lengths of prompt and responses).
    *   Compute and print the Pearson correlation between the error magnitude and these text features to identify potential sources of model failure.
5.  **Submission**: Call `generate_submission` from `library.engine` to predict on the test set and generate the `submission.csv` file.
