# Model: Siamese DeBERTa-v3-Base with Dual-Stream Multi-Layer Aggregation

I propose a **Siamese Contextual Transformer** that utilizes a **Dual-Stream Aggregation** mechanism. This architecture explicitly decouples the "Context" (Prompt) from the "Content" (Response) to maximize signal clarity while preserving the hierarchical depth that proved superior in previous iterations.

*   **Backbone Architecture:** I will utilize **`microsoft/deberta-v3-base`**.
    *   **Rationale:** Previous experiments established that pre-trained Transformers outperform LSTMs (Cite solution_lesson_node_00022). While "Large" models offer higher theoretical capacity, they have consistently failed to converge within the resource limits (Cite solution_lesson_node_00027). The "Base" variant provides the optimal balance, allowing for the necessary training epochs and batch sizes to reach a stable minimum (Cite solution_lesson_node_00029).
*   **Siamese Input Structure:** The model will process two parallel branches sharing weights:
    *   **Branch A:** `[CLS] Prompt [SEP] Response A [SEP]`
    *   **Branch B:** `[CLS] Prompt [SEP] Response B [SEP]`
    *   **Rationale:** This Siamese approach is strictly superior to Cross-Encoders for this task because it avoids the aggressive truncation required to fit `Prompt + Resp A + Resp B` into a single context window, ensuring the model accesses the full content (Cite solution_lesson_node_00023).
*   **Structural Innovation: Dual-Stream Multi-Layer Aggregation:**
    *   I will implement a pooling strategy that synthesizes the strengths of **Response-Isolation** (Cite solution_lesson_node_00025) and **Multi-Layer Concatenation** (Cite solution_lesson_node_00033), while correcting the "Layer Averaging" flaw identified in Lesson 33.
    *   **Stream 1 (Content):** For each branch, apply a binary mask to zero out `Prompt` tokens. Extract the hidden states from the **last 4 layers**. Apply independent **Learned Attention Pooling** (Cite solution_lesson_node_00011) to each layer and **concatenate** the results. This yields a deep, multi-scale response vector $R$ (approx. 3072 dim).
    *   **Stream 2 (Context):** Simultaneously, apply a binary mask to zero out `Response` tokens. Extract the **final hidden layer only** and apply Learned Attention Pooling. This yields a focused context vector $P$ (768 dim).
    *   **Rationale:** Lesson 33 proved that averaging layers destroys critical hierarchical signal, so we must concatenate the response layers. However, Lesson 25 showed that including the prompt in the main vector dilutes the difference signal. By extracting $P$ separately and concatenating it at the *end*, we re-introduce the necessary context (e.g., distinguishing "creative writing" vs. "math" intents) without polluting the comparative features $|R_A - R_B|$.
*   **Hybrid Classification Head:** The final feature vector will be a concatenation of:
    *   **Response Interaction:** $R_A, R_B, |R_A - R_B|, R_A \cdot R_B$ (Derived from the high-fidelity multi-layer streams).
    *   **Context Modulation:** $P$ (Averaged across branches to ensure stability: $P = 0.5(P_A + P_B)$).
    *   **Explicit Scalars:** Log-transformed lengths of Prompt, Response A, and Response B (Cite solution_lesson_node_00004).

# Data: Full Dataset with Symmetric Augmentation

*   **Dataset:** Train on the **Full Training Set** (approx. 41k samples). Do not downsample; data volume is the primary driver of performance (Cite solution_lesson_node_00015).
*   **Symmetric Augmentation:** Double the effective dataset size by creating a swapped copy $(B, A)$ with target $1-T$ for every pair $(A, B)$. This enforces permutation invariance and provides the model with a robust, balanced signal (Cite solution_lesson_node_00029).
*   **Preprocessing:**
    *   **Tokenization:** Use the `deberta-v3-base` tokenizer.
    *   **Feature Consistency:** Compute scalar length features from the **tokenized sequences** to ensure mathematical consistency with the encoder inputs (Cite solution_lesson_node_00005).
    *   **Sequence Length:** Set max length to **512 tokens per branch**. Truncate the Response if necessary, but **always preserve the full Prompt** to ensure the context vector $P$ is accurate (Cite solution_lesson_node_00013).

# Training: Efficiency-Optimized Fine-Tuning

*   **Optimization:** Use **AdamW** with a learning rate suitable for Base models (e.g., 1e-5) and a linear warmup schedule.
*   **Efficiency:** Enable **Gradient Checkpointing** and **Mixed Precision (FP16)**. This allows the model to fit into GPU memory with a sufficiently large batch size to ensure stable gradients (Cite solution_lesson_node_00027).
*   **Loss Function:** Standard Cross-Entropy Loss (Log Loss) on the soft probability targets.

# Evaluation: Robust Inference

*   **Test-Time Augmentation (TTA):** For every test instance, predict on both $(A, B)$ and $(B, A)$. Average the resulting probabilities (flipping the winner for the swapped pair) to produce the final prediction. This neutralizes any residual positional bias (Cite solution_lesson_node_00029).
*   **Pipeline:** Preprocess test data into Siamese pairs, extract scalar features, pass through the Dual-Stream model, and apply Softmax.
