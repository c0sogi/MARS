The `torch.OutOfMemoryError` is caused by the excessively large `batch_size` (2048) used in `runfile.py` and `library/config.py`. As explained in **Cite debug_lesson_1**, recurrent attention models exhibit quadratic memory scaling with respect to sequence length ($O(\text{Batch} \times \text{SrcLen} \times \text{TgtLen})$) because the attention mechanism broadcasts and stores large tensors for every decoding step during backpropagation. The fix is to aggressively reduce the batch size for training (to 32) and inference (to 256) to fit within the GPU memory limits.
