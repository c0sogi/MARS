The following script generates metadata for the text normalization task. It reads the raw CSV files, performs a group-based split on `sentence_id` to create a validation set (ensuring sentences are not split across sets), and saves the resulting datasets to the `./metadata` directory. It also includes a `source_file` column to track the origin of each row, which allows for the required file path verification. Finally, it reloads the generated metadata to verify the split integrity, statistics, and file path validity.
