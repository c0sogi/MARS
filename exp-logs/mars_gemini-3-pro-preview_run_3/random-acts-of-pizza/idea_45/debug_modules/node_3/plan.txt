The `TypeError: LGBMClassifier.fit() got an unexpected keyword argument 'verbose'` is caused by breaking API changes in LightGBM 4.0+, which removed `verbose` and `early_stopping_rounds` from the `.fit()` method in favor of a `callbacks` list. This issue was previously identified in **Cite debug_lesson_17**.

To fix this, I will segregate the training logic for `XGBClassifier` and `LGBMClassifier` in `library/models.py`. For LightGBM models, I will remove the incompatible arguments from `.fit()` and instead pass `lgb.early_stopping` and `lgb.log_evaluation` objects via the `callbacks` parameter. XGBoost handling will remain largely similar but separated to avoid argument contamination.
