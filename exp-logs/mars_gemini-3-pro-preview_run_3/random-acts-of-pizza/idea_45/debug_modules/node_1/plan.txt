The issue is that the `XGBClassifier.fit()` method no longer accepts `early_stopping_rounds` as a keyword argument in recent versions of the XGBoost library. Instead, this parameter must be set during model initialization or via the `set_params()` method before training. This aligns with **debug_lesson_10** (Migrate XGBoost Early Stopping from fit() to Initialization).

To fix this, I will modify `library/models.py` in two places (`train_oof` and `train_final`). I will update the training logic to conditionally set `early_stopping_rounds` using `model.set_params()` for XGBoost models, while retaining the keyword argument approach for LightGBM models (which still support it in `fit` or via callbacks passed as arguments). This ensures compatibility with the installed library versions.
