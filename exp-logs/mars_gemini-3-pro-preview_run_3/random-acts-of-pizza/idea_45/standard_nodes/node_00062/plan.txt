Implementation strategy:
1.  **Setup & Loading**: Initialize the environment with a fixed seed. Load the training, validation, and test datasets using `load_dataset`.
2.  **Feature Engineering**: Instantiate and fit the `FeaturePipeline` on the training data. Transform all three datasets (train, val, test) into the required feature views (Lexical, Behavioral, Semantic, Metadata).
3.  **Ensemble Training (Stage 1)**: Initialize the `HeptViewEnsemble`. Perform 5-fold Cross-Validation on the training set (`train_oof`) to generate Out-Of-Fold predictions. Train the Level 2 Meta-Learner (Logistic Regression) on these OOF predictions.
4.  **Validation Assessment**:
    *   Manually train each of the 7 base learners on the **Training set only**.
    *   For tree-boosters (XGBoost, LightGBM), use the Validation set for early stopping to prevent overfitting, mimicking the final training protocol.
    *   For baggers/linear models (Random Forest, Logistic Regression), train strictly on the Training set.
    *   Generate predictions on the Validation set using these base learners.
    *   Feed these Level 1 predictions into the trained Meta-Learner to get final validation probabilities.
    *   Compute and print the `Final Validation Metric` (ROC AUC).
5.  **Failure Analysis**: Calculate the absolute error between validation predictions and actual targets. Compute the Pearson correlation between this error and the numerical metadata features to identify sources of systematic failure.
6.  **Submission Generation**:
    *   Check if the validation AUC exceeds the threshold (0.7138293787137718).
    *   If passed, execute `ensemble.train_final` to retrain all base learners on the combined Training + Validation data (utilizing the validation set for early stopping where applicable).
    *   Generate predictions on the Test set.
    *   Save the submission file.
