The issue is that `early_stopping_rounds` was passed directly to `XGBClassifier.fit()`, which causes a `TypeError` in modern XGBoost versions where this parameter has been removed from the `fit` method. Similarly, LightGBM 4.0+ requires early stopping to be handled via callbacks. The fix involves updating `library/engine.py` to intercept `early_stopping_rounds` in the `fit_params`. For XGBoost, the parameter is moved to `model.set_params()` before training (Cite debug_lesson_10). For LightGBM, it is converted into an `lgb.early_stopping` callback (Cite debug_lesson_17). `lightgbm` is imported to facilitate the callback creation.
