Implementation strategy:
1.  **Setup & Configuration**: Import necessary libraries and the provided modules. Patch the `Config` class to reduce the number of estimators (trees) for the ensemble models. This ensures the training completes quickly as a baseline while maintaining the architecture.
2.  **Data Loading**: Use `load_datasets` to retrieve the train, validation, and test dataframes.
3.  **Feature Engineering**: Apply `get_features` to all splits. This handles TF-IDF vectorization, embedding generation (using the GPU), and metadata scaling. The pipeline fitted on the training set is reused for validation and test sets.
4.  **Training**: Initialize the `HybridTrainer`. Execute `train_stacking_layer` to train the Level 1 base learners (Lexical, Behavioral, Semantic, Contextual branches) using the defined cross-validation and full-retraining strategies. Then, train the Level 2 Meta-Learner on the Out-of-Fold predictions.
5.  **Validation Inference**: Generate predictions for the validation set. To prevent overwriting the final submission file during this step, temporarily redirect the submission path in `Config`.
6.  **Evaluation**: Compute the ROC AUC score on the validation set and print it in the required format.
7.  **Failure Analysis**: Calculate the absolute error of the predictions against the ground truth. Compute Pearson correlations between this error signal and the available numerical metadata features to identify sources of difficulty.
8.  **Submission**: Compare the validation score against the specified threshold. If the score is sufficient, generate predictions for the test set and save them to `./submission/submission.csv`.
