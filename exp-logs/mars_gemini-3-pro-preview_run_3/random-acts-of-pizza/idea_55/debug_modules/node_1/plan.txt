The error `TypeError: XGBClassifier.fit() got an unexpected keyword argument 'eval_metric'` occurs because modern XGBoost versions (scikit-learn interface) have removed `eval_metric` and `early_stopping_rounds` from the `.fit()` method, requiring them to be passed via `__init__` or `.set_params()` instead. Similarly, LightGBM 4.0+ has removed `early_stopping_rounds` and `verbose` from `.fit()`, necessitating the use of the `callbacks` parameter.

I will modify `library/training_engine.py` to:
1.  Detect the model type (XGBoost vs. LightGBM).
2.  For XGBoost, use `.set_params()` to configure `eval_metric` and `early_stopping_rounds` before fitting (Cite debug_lesson_10).
3.  For LightGBM, construct the appropriate `callbacks` for early stopping and logging (Cite debug_lesson_17).
4.  Remove incompatible arguments from the `fit_kwargs` dictionary.
