The following script demonstrates the complete workflow of the provided machine learning library. It performs the following steps:

1.  **Configuration Patching**: Modifies the imported configuration parameters (number of estimators, folds) to ensure the demonstration runs quickly on a small subset of data.
2.  **Data Loading**: Loads a small debug subset (50 samples) of the training, validation, and test data using the `load_datasets` function.
3.  **Feature Engineering**: Initializes the `FeaturePipeline`, fits it on the training data, and transforms all datasets into Lexical (sparse), Behavioral (sparse), and Dense (embeddings/metadata) views. It validates the output shapes.
4.  **Ensemble Modeling**: Initializes the `TriViewStackingEnsemble`. It runs the stacking procedure: generating Out-Of-Fold (OOF) predictions, training the meta-learner (Logistic Regression), and refitting the base models (Random Forest and XGBoost) on the full training subset.
5.  **Prediction & Verification**: Generates predictions for the test set and calculates the AUC score on the validation set to verify the pipeline's end-to-end functionality. Assertions are used throughout to guarantee data integrity.
