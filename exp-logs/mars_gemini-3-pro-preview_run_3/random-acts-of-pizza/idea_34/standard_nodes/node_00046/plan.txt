Implementation Strategy:
1.  **Environment Setup**: Initialize the environment by setting random seeds for reproducibility and suppressing warnings to keep the output clean.
2.  **Data Loading**: Use the `data_processing` module to load the train, validation, and test datasets. This handles text cleaning and metadata processing automatically.
3.  **Feature Engineering**: Instantiate the `FeatureEngineer` to generate all required feature views (Holistic, Lexical, Community, Semantic, Metadata). This step leverages caching to save time.
4.  **Ensemble Training (CV)**: Initialize the `StackingEnsemble`. Run `train_cv()` to perform 5-fold cross-validation on the training set. This generates Out-of-Fold (OOF) predictions and trains the Level 2 Meta-Learner.
5.  **Hold-out Validation**:
    - To compute a fair "Final Validation Metric", manually train each Level 1 base learner on the **Training Set only** and generate predictions for the **Validation Set**.
    - Feed these Level 1 validation predictions into the pre-trained Meta-Learner to get final probabilities.
    - Compute the ROC AUC score on the validation set.
6.  **Failure Analysis**: Calculate the absolute errors of the validation predictions. Compute and print the Pearson correlation between these errors and the metadata features to identify sources of systematic error.
7.  **Submission**: Compare the validation AUC against the required threshold (0.7138...). If successful, execute the ensemble's `train_final_models()` (which retrains base learners on the combined Train+Val set for maximum performance) and `predict()` to generate the `submission.csv`.
