Implementation strategy:
1.  **Setup & Initialization**: Import necessary libraries and the provided modules (`config`, `data_loader`, `feature_engineering`, `stacking_manager`). Set random seeds for reproducibility.
2.  **Feature Generation**: Call `get_all_features(load_cached_data=True)` to load or generate the feature matrices (Metadata, Lexical, Behavioral, Semantic) for Train, Validation, and Test sets.
3.  **Meta-Learner Training**: Instantiate `StackingManager` and run `train_cv(data)`. This performs 5-fold CV on the training set to generate Out-Of-Fold (OOF) predictions and trains the Level 2 Logistic Regression meta-learner on these predictions.
4.  **Validation Assessment**:
    *   To properly evaluate the ensemble on the hold-out validation set, we iterate through each Level 1 base learner.
    *   We train each base learner on the **Training Set**. For the XGBoost model (`SemanticBooster`), we internally split the training set (90/10) to provide an evaluation set for early stopping, ensuring the hold-out validation set remains unseen.
    *   We generate predictions on the **Validation Set** using these trained base learners.
    *   These predictions are fed into the pre-trained Meta-Learner to get the final ensemble probabilities.
    *   We compute and print the **Final Validation Metric** (ROC AUC).
5.  **Failure Analysis**:
    *   Calculate the absolute error between validation predictions and actual targets.
    *   Load the raw validation DataFrame to access interpretable numerical features.
    *   Compute and print the correlation between the model's error and these features to identify potential weaknesses.
6.  **Submission Generation**:
    *   Check if the validation AUC exceeds the specified threshold (0.7085870249842536).
    *   If passed, call `manager.retrain_and_predict(data)`. This retrains base learners on the full dataset (Train + Val for RF/Linear; Train with Val stopping for XGBoost) and generates predictions for the Test set.
    *   Save the predictions to `./submission/submission.csv`.
