The following Python script demonstrates the usage of the provided machine learning library components.

**Implementation Strategy:**
1.  **Configuration Override**: We monkey-patch the `Config` class to redirect output directories to `./working/demo_execution` and drastically reduce model complexity (e.g., `n_estimators=2`, `N_FOLDS=2`) to ensure the demo runs quickly.
2.  **Data Management**: We instantiate `DataManager` to load the dataset and verify the data structure.
3.  **Feature Engineering**: We explicitly demonstrate the `GranularLexicalVectorizer` to show how text features are processed and verify the output dimensions.
4.  **Training Pipeline**: We execute the `TrainingEngine` to train the Level 1 base models and generate Out-of-Fold (OOF) predictions. We verify that model artifacts and OOF files are created.
5.  **Inference Pipeline**: We execute the `InferenceEngine` to generate predictions on the test set using the trained models and the Level 2 meta-learner. We verify the final submission file.
6.  **Reproducibility**: We set a fixed seed at the start.
