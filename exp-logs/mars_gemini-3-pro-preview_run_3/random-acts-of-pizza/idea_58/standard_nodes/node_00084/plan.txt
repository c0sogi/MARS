### Implementation Strategy

1.  **Initialization**: Set random seeds for reproducibility using the provided `utils.set_seed` function.
2.  **Training Phase**: Instantiate and run the `TrainingEngine`. This processes the data (creating a Union of Train and Validation sets), generates OOF (Out-Of-Fold) predictions using a 5-fold cross-validation scheme for all Level 1 base learners, and retrains the "Stable" base learners on the full dataset.
3.  **Validation Phase**:
    *   Load the original `train.parquet` and `val.parquet` metadata to determine the exact split indices between the training and validation portions of the Union dataset.
    *   Load the `oof_predictions.csv` generated by the training engine.
    *   Split the OOF predictions into a training set (corresponding to the original `train.parquet`) and a validation set (corresponding to the original `val.parquet`).
    *   Train a fresh instance of the Level 2 Meta-Learner (Logistic Regression) on the OOF predictions from the training portion.
    *   Evaluate this Meta-Learner on the OOF predictions from the validation portion. This provides a rigorous "Hold-out Validation Metric" (AUC) without data leakage.
    *   Print the final validation metric.
4.  **Failure Analysis**:
    *   Calculate the absolute error between the model's predictions and the actual targets on the validation set.
    *   Compute Pearson correlations between this error magnitude and the numerical features in the validation metadata to identify conditions under which the model underperforms.
5.  **Submission Phase**:
    *   Check if the calculated Validation AUC exceeds the threshold (0.7222984867326668).
    *   If successful, instantiate and run the `InferenceEngine`. This engine retrains the Meta-Learner on *all* OOF predictions (Train + Val) to maximize performance, generates Level 1 predictions for the test set using the Hybrid Inference Protocol, and produces the final `submission.csv`.
