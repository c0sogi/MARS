Based on the comprehensive analysis of the provided "Lessons Learned," particularly the critical failures related to **retraining protocols** (Cite solution_lesson_node_00027), **embedding dimensionality** (Cite solution_lesson_node_00028), and the **representation of categorical sets** (Cite solution_lesson_node_00029), I propose a **Hex-View Hybrid-Topology Stacking Ensemble**.

This solution structurally evolves the previous "Pent-View" architecture by introducing a **Manifold Learning Branch (kNN)** to exploit local data density, strictly enforcing **Sparse Representations** for user history, and implementing a rigorous **Validation-Guided Retraining Protocol**.

# Model

The architecture is a **Stacking Ensemble** composed of **six** "Level 1" base learners, organized into three topology-matched branches (Sparse, Dense, Linear) to maximize algorithmic diversity (Cite solution_lesson_node_00025). These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Global Metadata Vector**.
        *   *Rationale:* Random Forests on sparse TF-IDF consistently outperform dense methods for capturing specific high-impact keywords (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent the overfitting observed in unregularized sparse models (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with the **Global Metadata Vector**.
        *   *Rationale:* We treat user history as a "Bag-of-Concepts" document. This sparse representation is superior to dense embeddings for unordered categorical sets (Cite solution_lesson_node_00029) and captures niche community signals effectively (Cite solution_lesson_node_00018).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Rationale:* Gradient Boosting excels at extracting non-linear signals from dense, continuous embeddings (Cite solution_lesson_node_00018).
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Rationale:* Using both Bagging and Boosting on the same dense view provides significant lift by capturing diverse structural patterns (Cite solution_lesson_node_00025).
    *   **Manifold Neighbor (Innovation):** A **k-Nearest Neighbors (kNN) Classifier** trained on **PCA-Reduced Embeddings** concatenated with Metadata.
        *   *Rationale:* This introduces a distinct inductive bias (Instance-Based Learning) that exploits the local manifold structure (e.g., retrieving semantically similar successful requests) which tree-based models might miss. PCA is applied to mitigate the curse of dimensionality (Cite solution_lesson_node_00028).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Rationale:* Acts as a high-bias regularizer based on robust heuristics (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and dimensionality management.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Global Metadata Vector:** User Stats (Age, Karma) + Temporal Features. Concatenate this to **all** base learners to preserve cross-modal interactions (Cite solution_lesson_node_00023).
        *   *Refinement:* Explicitly **exclude** derived text length features (e.g., character count), as they were found to be noisy and correlated with prediction error (Cite solution_lesson_node_00027).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams, Top 3,000) with `sublinear_tf=True` and `min_df=5` to ensure robust scaling (Cite solution_lesson_node_00024).
        *   *Text:* From request text.
        *   *History:* From robustly serialized subreddit list (Cite solution_lesson_node_00017).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim). We use this compact model instead of larger variants to avoid the curse of dimensionality in this small-sample regime (Cite solution_lesson_node_00028).
    *   **Manifold Features:** Apply **PCA** (e.g., 50 components) to the Dense Embeddings specifically for the kNN learner.
3.  **Preprocessing:**
    *   **Imputation:** Median imputation for numerical columns.
    *   **Scaling:** `StandardScaler` applied to dense inputs (Metadata, Embeddings, PCA).
    *   **No Caching:** Recompute features on-the-fly to prevent alignment corruption (Cite solution_lesson_node_00024).

# Training

The training procedure implements the **Validation-Guided Retraining Protocol** to prevent the specific overfitting failure observed in previous iterations.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear / kNN:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'` and `min_samples_leaf=2` for RFs.
    *   **XGBoost:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on OOF matrix.
4.  **Final Retraining (The Fix):**
    *   **RF / Linear / kNN:** Retrain on the **Full Training Set** (Train + Validation).
    *   **XGBoost:** Retrain on the **Full Training Set** but explicitly pass the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" caused by using fixed iteration counts derived from CV (Cite solution_lesson_node_00027).

# Evaluation

1.  Process the test set to generate all feature views (Lexical, Behavioral, Semantic, PCA-Semantic, Metadata).
2.  Pass specific views to the six base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
