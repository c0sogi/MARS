The following script demonstrates the usage of the provided library modules (`config`, `feature_engineering`, `model_definitions`, `ensemble_pipeline`).

**Implementation Strategy:**
1.  **Configuration Override**: We monkey-patch the `library.config` module to use a temporary working directory and significantly reduce hyperparameters (e.g., `n_estimators=5`, `n_folds=2`) to ensure the demo runs quickly.
2.  **Feature Engineering Demo**: We instantiate `FeatureProcessor` to generate and cache the Hex-View features (Lexical, Behavioral, Semantic, Contextual). We validate the output shapes and data types (sparse vs. dense).
3.  **Model Factory Demo**: We iterate through the `ModelFactory` methods to confirm they return the correct scikit-learn/XGBoost/LightGBM model objects with the patched configurations.
4.  **Ensemble Pipeline Demo**:
    *   **OOF Generation**: We run `train_and_predict_oof` to generate Level 1 predictions and train the Meta-Learner. We verify the dimensions of the Out-of-Fold (OOF) matrix.
    *   **Final Retraining**: We run `train_final_models` to retrain base learners on the full training set (plus validation set where applicable). We verify that model artifacts are saved to disk.
    *   **Test Prediction**: We execute `predict_test` to generate the final submission file. We verify the submission file's format and row count against the test metadata.
