The solution implements the `runfile.py` script to orchestrate the Clean-Signal Hex-View Stacking Ensemble.

### Strategy Outline:
1.  **Initialization**: Setup random seeds for reproducibility and initialize the `HexViewEnsemble` pipeline.
2.  **Meta-Learner Training**: Execute `train_and_predict_oof` to generate Out-of-Fold (OOF) predictions on the training set and train the Level 2 Logistic Regression meta-learner.
3.  **Honest Validation**:
    *   Load the preprocessed training and validation data.
    *   Manually instantiate and train fresh copies of the six base learners (Level 1) on the **Training set only**.
    *   For boosting models (XGBoost, LightGBM), use the Validation set for early stopping (consistent with the "Validation-Guided" protocol).
    *   Generate predictions on the **Validation set**.
    *   Feed these Level 1 predictions into the pre-trained Meta-Learner to get final probabilities.
    *   Compute and print the **Final Validation Metric (ROC AUC)**.
4.  **Failure Analysis**:
    *   Calculate the absolute error between predictions and ground truth on the validation set.
    *   Compute Pearson correlations between the error signal and all numerical metadata features to identify sources of systematic failure.
    *   Print the top 5 correlated features.
5.  **Submission**:
    *   Compare the validation AUC against the threshold (0.7138293787137718).
    *   If the threshold is met, execute `train_final_models` to retrain base learners on the full dataset (Train + Val) and `predict_test` to generate the `submission.csv`.
