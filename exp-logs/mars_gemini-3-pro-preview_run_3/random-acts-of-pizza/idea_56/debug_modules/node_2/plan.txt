The issue is that the `load_data` function in `library/utils.py` uses `Config.DEBUG` as a default argument value. In Python, default arguments are evaluated only once at function definition time (when the module is imported). Consequently, when `runfile.py` modifies `Config.DEBUG` to `True` at runtime, `load_data` continues to use the stale default value (`False`), causing it to load the full dataset instead of the debug subsample. This leads to a mismatch between the expected and actual data sizes during validation.

To fix this, I will modify `load_data` to use `None` as the default value for the `debug` parameter and resolve the actual value of `Config.DEBUG` inside the function body. This ensures the function accesses the current runtime value of the configuration variable (Cite debug_lesson_15).
