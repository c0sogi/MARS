# Solution Proposal: Corrected Hex-View Hybrid-Topology Stacking Ensemble

Based on the rigorous analysis of the "Lessons Learned," particularly the failures of Idea 23 (feature selection noise, capacity constraints) and Idea 16 (retraining protocols), I propose a **Corrected Hex-View Hybrid-Topology Stacking Ensemble**.

This solution structurally evolves the high-performing "Pent-View" architecture (Idea 15) by successfully integrating the **Manifold Learning Branch (kNN)** proposed in Idea 23. However, it critically diverges from Idea 23 by reverting to **Sparse Behavioral Representations** (Cite solution_lesson_node_00029), enforcing **Explicit Feature Allow-Listing** (Cite solution_lesson_node_00030), and restoring **High-Capacity Learners** (Cite solution_lesson_node_00022).

# Model

The architecture is a **Stacking Ensemble** composed of **six** "Level 1" base learners, organized into three topology-matched branches (Sparse, Dense, Linear) to maximize algorithmic diversity (Cite solution_lesson_node_00025). These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Global Metadata Vector**.
        *   *Retention:* Random Forests on sparse TF-IDF consistently outperform dense methods for capturing specific high-impact keywords (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with the **Global Metadata Vector**.
        *   *Correction:* We strictly reject the dense embedding approach for history (which failed in Idea 21/23). Treating user history as a "Bag-of-Concepts" document is superior for unordered categorical sets (Cite solution_lesson_node_00029) and captures niche community signals effectively (Cite solution_lesson_node_00018).

3.  **Dense Semantic Branch (Text Modality - The Diversity Trio)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Correction:* We restore **High Capacity** (2,000 estimators) which was wrongly cut in Idea 23 (Cite solution_lesson_node_00022). Gradient Boosting excels at extracting non-linear signals from dense embeddings (Cite solution_lesson_node_00018).
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Retention:* Using both Bagging and Boosting on the same dense view provides significant lift by capturing diverse structural patterns (Cite solution_lesson_node_00025).
    *   **Manifold Neighbor:** A **k-Nearest Neighbors (kNN) Classifier** trained on **PCA-Reduced Embeddings** concatenated with Metadata.
        *   *Innovation:* This introduces a distinct inductive bias (Instance-Based Learning) that exploits the local manifold structure (e.g., retrieving semantically similar successful requests). PCA is applied to mitigate the curse of dimensionality (Cite solution_lesson_node_00028).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer based on robust heuristics (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Positive Feature Selection**.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Global Metadata Vector:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) a curated set of dense features: User Stats (Age, Karma) and Temporal Features. Concatenate this to **all** base learners to preserve cross-modal interactions (Cite solution_lesson_node_00023).
        *   *Correction:* Explicitly **exclude** derived text length features, as they are noisy proxies (Cite solution_lesson_node_00027).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams, Top 3,000) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
        *   *Text:* From request text.
        *   *History:* From robustly serialized subreddit list (Cite solution_lesson_node_00017).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim). We use this compact model instead of larger variants to avoid the curse of dimensionality (Cite solution_lesson_node_00028).
    *   **Manifold Features:** Apply **PCA** (e.g., 50 components) to the Dense Embeddings specifically for the kNN learner.
3.  **Preprocessing:**
    *   **Imputation:** Median imputation for numerical columns.
    *   **Scaling:** `StandardScaler` applied to dense inputs (Metadata, Embeddings, PCA).
    *   **No Caching:** Recompute features on-the-fly to prevent alignment corruption (Cite solution_lesson_node_00024).

# Training

The training procedure implements the **Validation-Guided Retraining Protocol** to prevent the specific overfitting failure observed in Idea 16 and Idea 23.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear / kNN:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'` and `min_samples_leaf=2` for RFs.
    *   **XGBoost:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`, `n_estimators=2000`, and `early_stopping_rounds=50`.
3.  **Level 2 Training:** Train Meta-Learner on OOF matrix.
4.  **Final Retraining (The Fix):**
    *   **RF / Linear / kNN:** Retrain on the **Full Training Set** (Train + Validation).
    *   **XGBoost:** Retrain on the **Full Training Set** but explicitly pass the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" caused by using fixed iteration counts derived from CV (Cite solution_lesson_node_00027).

# Evaluation

1.  Process the test set to generate all feature views (Lexical, Behavioral, Semantic, PCA-Semantic, Metadata).
2.  Pass specific views to the six base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
