Based on the rigorous empirical analysis of the "Lessons Learned," particularly the critical importance of **Granular Signal Preservation** (Cite solution_lesson_node_00083), the necessity of **Differential Sparsity** strategies for different modalities (Cite solution_lesson_node_00090 vs. Cite solution_lesson_node_00042), and the robustness of **Consistent Hybrid Inference** (Cite solution_lesson_node_00081, Cite solution_lesson_node_00072), I propose a **High-Fidelity Symmetric Stacking Ensemble with Differential Sparsity**.

This solution structurally evolves the "Non-View" architecture by enforcing a **Differential Sparsity** paradigm: treating Text as an "Open Vocabulary" problem (to capture the long tail of narrative detail) while treating History as a "Closed Vocabulary" problem (to prevent overfitting to rare communities). It completes the **Symmetric Topology** by ensuring every modality is modeled by both Linear and Non-Linear backbones, and applies a **Hybrid Inference Protocol** to maximize data utilization.

# Model

The architecture is a **Stacking Ensemble** composed of **nine** "Level 1" base learners, organized into four topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Open-Vocabulary Lexical Branch (Text Modality)**
    *   **Granular Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Title and Edit-Aware Body** combined with the **Augmented Global Metadata**.
        *   *Structural Innovation:* We apply **Granular Tokenization** (`token_pattern=r"\w{1,}"`) to capture single-character agency tokens (e.g., "I", "$") (Cite solution_lesson_node_00083). Crucially, we enforce **Open Vocabulary** settings (`min_df=2`, no `max_features`) to preserve the predictive "long tail" of the text (Cite solution_lesson_node_00090).
        *   *Retention:* Concatenation maximizes signal (Cite solution_lesson_node_00044). Regularization (`min_samples_leaf=2`) prevents overfitting (Cite solution_lesson_node_00025).
    *   **Lexical Anchor:** A **Logistic Regression** model trained on the same granular feature set.
        *   *Retention:* Adds a high-bias linear baseline to the strongest modality (Cite solution_lesson_node_00025).

2.  **Closed-Vocabulary Behavioral Branch (History Modality)**
    *   **Constrained Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** combined with the **Augmented Global Metadata**.
        *   *Structural Innovation:* Unlike the text branch, we apply **Closed Vocabulary** constraints (Top 1,000 features). This **Differential Sparsity** prevents the model from overfitting to the noise of rare subreddits (Cite solution_lesson_node_00042) while maintaining the superiority of sparse representations for categorical sets (Cite solution_lesson_node_00029).
    *   **Community Anchor:** A **Logistic Regression** model trained on the same constrained feature set.
        *   *Retention:* Completes the symmetry, providing a robust linear baseline for behavioral signals.

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster (XGB):** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Correction:* We enforce **Conservative Boosting** (`learning_rate=0.01`, `colsample_bytree=0.6`) to reduce variance (Cite solution_lesson_node_00084) and explicitly use `scale_pos_weight` to handle class imbalance.
    *   **Semantic Gradient (LGBM):** A **LightGBM Classifier** trained on the same features.
        *   *Retention:* Provides algorithmic diversity via leaf-wise growth (Cite solution_lesson_node_00025).
    *   **Semantic Bagger (RF):** A **Random Forest Classifier** trained on the same features.
        *   *Retention:* Provides structural diversity. We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) to prevent memorization of dense noise (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor (Linear):** A **Logistic Regression** model trained on the **Augmented Global Metadata**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).
    *   **Temporal Booster (Non-Linear):** A **LightGBM Classifier** trained on the **Augmented Global Metadata**.
        *   *Retention:* Captures non-linear temporal drift via raw timestamps (Cite solution_lesson_node_00041).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Hygienic Feature Selection**.

1.  **Leakage Prevention:**
    *   **Source Text:** Use `request_text_edit_aware` exclusively (Cite solution_lesson_node_00062).
    *   **Exclusion:** Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Augmented Global Metadata:** Explicitly **Allow-List** (Cite solution_lesson_node_00030):
        *   **Raw Timestamp:** `unix_timestamp_of_request_utc` (Cite solution_lesson_node_00041).
        *   **Restored RAOP History:** Include `requester_number_of_posts_on_raop_at_request` etc. (Cite solution_lesson_node_00067).
        *   **User Stats:** Account Age, Karma, Post Counts.
        *   **Exclusion:** Exclude derived text length features (Cite solution_lesson_node_00027).
        *   *Note:* Concatenate this vector to **all** base learners (Cite solution_lesson_node_00023).
    *   **Text Concatenation:** Join `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00044).
    *   **Sparse Features:**
        *   *Text:* TF-IDF with `token_pattern=r"\w{1,}"`, `min_df=2`, `sublinear_tf=True`.
        *   *History:* TF-IDF with `max_features=1000`.
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Union Strategy:** Merge Training and Validation sets into a single **Union Dataset** (Cite solution_lesson_node_00081).
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs.

# Training

The training procedure implements a **Consistent Hybrid Inference Protocol** (Cite solution_lesson_node_00072, Cite solution_lesson_node_00081).

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation on the **Union Dataset**.
2.  **Ensemble Training (Per Fold):**
    *   **Volatile Learners (XGBoost / LightGBM):** Train on 4 folds, using the **1 validation fold** for **Early Stopping**.
        *   *Correction:* Explicitly set `load_best_model_at_end=True` and pass the validation set to `fit()` to ensure the optimal state is restored (Cite solution_lesson_node_00087).
    *   **Stable Learners (RF / Linear):** Train on 4 folds.
    *   **OOF Generation:** Generate predictions for the validation fold.
    *   **Persistence:** Save all 9 models for this fold.
3.  **Meta-Learner Training:** Train on the full matrix of OOF predictions from the Union Dataset.
4.  **Stable Learner Retraining:** Train single instances of the Stable Learners (RF/Linear) on the full Union Dataset to maximize data usage (Cite solution_lesson_node_00044).

# Evaluation

1.  **Hybrid Inference:**
    *   **Volatile Branches:** Generate predictions using all 5 saved fold-models and **average** them (CV-Bagging). This reduces variance without the risk of blind retraining (Cite solution_lesson_node_00027).
    *   **Stable Branches:** Generate predictions using the single fully-retrained model.
2.  **Stacking:** Feed the resulting 9 probability scores to the Meta-Learner for the final prediction.
