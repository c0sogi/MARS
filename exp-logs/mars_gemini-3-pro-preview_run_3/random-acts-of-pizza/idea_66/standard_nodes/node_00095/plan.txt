Implementation strategy:
1.  **Configuration Patching**: To ensure the solution runs within the strict time limit, I will monkey-patch the `Config` class to reduce the number of estimators for the ensemble models (e.g., reducing 2000 trees to 100). This maintains the architecture while significantly speeding up execution.
2.  **Training Pipeline**: Execute `run_training_pipeline` with `load_cached_data=False` to train the 5-fold stacking ensemble on the union of training and validation data.
3.  **Validation Evaluation**:
    *   Manually load the hold-out validation set (`val.parquet`).
    *   Since the provided `FeatureFactory` fits on the training set and transforms the test set without saving the vectorizer objects, I will invoke the factory methods passing the training union as "train" and the validation set as "test". This will generate the necessary feature matrices for the validation set.
    *   Perform inference using the trained Level 1 and Level 2 models.
    *   Compute and print the ROC AUC score.
4.  **Failure Analysis**: Calculate the absolute error on the validation set and compute Pearson correlations with metadata features to identify error sources.
5.  **Submission Generation**: If the validation score meets the threshold, execute `run_inference_pipeline` with `load_cached_data=False`. This ensures the feature factory correctly re-fits on the training data and transforms the *actual* test set (overwriting any temporary cache from the validation step) to generate the final submission.
