The implementation strategy follows the "Non-View Full-Spectrum Stacking Ensemble" architecture.

1.  **Data Loading**: We use `library.data_factory` to load the datasets. Crucially, we load the `union_train` (Train + Validation merged) for the cross-validation training process, and we also separately load the `val.parquet` to serve as the specific hold-out set for the final reporting requirement.
2.  **Feature Engineering**: We use `library.feature_pipeline` to generate Sparse Lexical, Sparse Behavioral, Dense Semantic, and Metadata features. This is performed on the `union_train` and `test` sets.
3.  **Training**: We use `library.stacking_engine` to orchestrate the training.
    *   **Level 1**: We perform 5-Fold Stratified CV on the `union_train` set. This generates Out-of-Fold (OOF) predictions for every sample (including those in the validation set).
    *   **Level 2**: We train a Logistic Regression Meta-Learner on these OOF predictions.
    *   **Refit**: We retrain the "Stable" base learners (Random Forest, Linear) on the full `union_train` dataset to maximize data utilization for the final test inference.
4.  **Validation**: To strictly satisfy the requirement of reporting the metric on the hold-out set while using the merged-data architecture:
    *   We extract the OOF predictions corresponding to the `request_id`s in `val.parquet`. These predictions are unbiased as they come from models that did not see these specific samples during training (due to k-fold CV).
    *   We feed these OOF predictions to the Meta-Learner to get the final validation probabilities.
    *   We compute and print the ROC AUC.
5.  **Failure Analysis**: We calculate the absolute error of the validation predictions and correlate it with input features to identify error sources.
6.  **Submission**: If the validation AUC exceeds the threshold, we generate test predictions using the **Hybrid Inference** strategy (averaging 5 folds for volatile models, using the single retrained model for stable models) and save the submission file.
