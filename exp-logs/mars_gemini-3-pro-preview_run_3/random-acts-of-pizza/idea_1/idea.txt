# Baseline Proposal: Bag-of-Words Random Forest

### Model
I propose a **Random Forest Classifier**, a bagging-based ensemble architecture. Unlike the boosting approach (Model 1) which builds trees sequentially to reduce bias, this model builds a large collection of de-correlated decision trees in parallel using bootstrap aggregation. The final prediction is obtained by averaging the probabilistic outputs of individual trees. This architecture is chosen for its robustness to noise, its ability to naturally model non-linear interactions between text and tabular data, and its resistance to overfitting without extensive hyperparameter tuning.

### Data
To prepare the data for this baseline:
1.  **Leakage Removal**: Strictly drop all features suffixed with `_at_retrieval` (e.g., `number_of_upvotes_of_request_at_retrieval`), as these represent future information not available at prediction time. Use only `_at_request` features and static metadata.
2.  **Text Processing**: Concatenate `request_title` and `request_text`. Apply a **TF-IDF Vectorizer** (Term Frequency-Inverse Document Frequency) to transform the text into a sparse matrix. Limit the vocabulary to the top frequent unigrams and bigrams to keep the dimensionality low and training fast.
3.  **Tabular Processing**: Impute missing values in numerical columns (e.g., `requester_account_age_in_days_at_request`) using median replacement.
4.  **Fusion**: Concatenate the sparse text vectors and the dense numerical features into a single feature matrix. Unlike SVMs or Neural Networks, feature scaling (normalization) is not required for this tree-based model.

### Training
The training procedure will follow the standard Random Forest algorithm:
-   **Bootstrapping**: Generate multiple subsets of the training data via random sampling with replacement.
-   **Tree Construction**: Train a decision tree on each subset. At each split node, consider only a random subset of features to ensure tree diversity.
-   **Class Balancing**: Address the dataset imbalance (~25% positive class) by applying "balanced" class weights, which automatically adjust the loss contribution of each sample inversely proportional to class frequency.
-   **Optimization**: Trees are grown using greedy minimization of Gini impurity. No gradient-based optimization is used.

### Evaluation
For evaluation on the test set:
1.  Apply the fitted TF-IDF vectorizer and imputer from the training step to the test data.
2.  Pass the processed test samples through the trained forest.
3.  Calculate the **predicted probability** of success by averaging the soft-vote probabilities of all trees (i.e., the fraction of trees voting for the positive class).
4.  These probabilities will be formatted into the submission CSV and evaluated against the Area Under the ROC Curve (AUC) metric.
