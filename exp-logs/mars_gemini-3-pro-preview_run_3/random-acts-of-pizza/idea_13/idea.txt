# Solution Proposal: Contextually-Unified Topology-Matched Stacking

### Model
I propose a **Contextually-Unified Topology-Matched Stacking Ensemble**. This architecture represents a structural synthesis of the "Topology-Matching" strategy (assigning algorithms based on data density) and the "Unified Context" principle (ensuring all models see global metadata).

The model consists of three "Level 1" base learners, each handling a specific high-dimensional view but sharing a common low-dimensional context, feeding into a "Level 2" meta-learner.

1.  **Lexical-Contextual Bagger (Sparse Text View):** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Global Metadata Vector**.
    *   *Rationale:* Random Forests outperform Boosting on high-dimensional sparse text (Cite solution_lesson_node_00005). By concatenating the metadata here, we correct the "siloing" error of previous iterations, allowing the tree to learn critical interactions (e.g., "keywords 'paycheck' + 'account_age > 1 year' = high probability") (Cite solution_lesson_node_00023).
2.  **Behavioral-Contextual Bagger (Sparse History View):** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with the **Global Metadata Vector**.
    *   *Rationale:* We treat the user's subreddit history as a "Bag-of-Concepts" document (Cite solution_lesson_node_00018). Since this produces a sparse, high-dimensional matrix, we use a Random Forest (Bagging) rather than XGBoost.
3.  **Semantic-Contextual Booster (Dense Embedding View):** An **XGBoost Classifier** trained on **Frozen SBERT Embeddings** concatenated with the **Global Metadata Vector**.
    *   *Rationale:* Gradient Boosting (XGBoost) is superior to Random Forests for extracting non-linear signals from dense, continuous embeddings (Cite solution_lesson_node_00018). We use frozen embeddings to prevent overfitting (Cite solution_lesson_node_00015).

**Level 2 Meta-Learner:**
*   **Logistic Regression:** A linear model to optimally calibrate the ensemble weights (Cite solution_lesson_node_00012).

### Data
The data pipeline enforces strict leakage prevention, robust typing, and—crucially—the construction of a unified metadata set for all learners.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Global Metadata Vector (The Unified Context):** Explicitly generate and **allow-list** (Cite solution_lesson_node_00007) a comprehensive set of dense features:
        *   *User Stats:* Account age, karma (up/downvotes), number of posts.
        *   *Temporal:* Request hour, day of week.
        *   *Text Complexity:* Word count, sentence count, sentiment polarity.
        *   *Note:* This vector is concatenated to **all three** views (Cite solution_lesson_node_00023).
    *   **Lexical View:** TF-IDF Matrix (Unigrams/Bigrams, Top 3,000) from request text.
    *   **Behavioral View:** Robustly serialize `requester_subreddits_at_request` (using duck typing, Cite solution_lesson_node_00017) into a string, then generate a TF-IDF Matrix (Unigrams, Top 1,000).
    *   **Semantic View:** Extract **Frozen SBERT Embeddings** (384-dim) (Cite solution_lesson_node_00015).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation for numerical columns.
    *   **Scaling:** Apply `StandardScaler` to the **Global Metadata Vector** before concatenation. This is critical for the XGBoost branch and ensures stability for the Random Forests (Cite solution_lesson_node_00006).

### Training
The training procedure utilizes **5-Fold Cross-Validation Stacking** with high-capacity base learners:

1.  **Fold Generation:** Split training data into 5 stratified folds.
2.  **Level 1 Training (OOF Generation):**
    *   **Lexical & Behavioral RFs:** Train on 4 folds, predict on the 5th. Use `class_weight='balanced'` and **n_estimators=500**. Do not reduce capacity (Cite solution_lesson_node_00022).
    *   **Semantic XGB:** Train on 4 folds, predict on the 5th. Use `scale_pos_weight` and **n_estimators=1000** with early stopping.
3.  **Level 2 Training:** Train the Logistic Regression meta-learner on the matrix of Out-Of-Fold (OOF) predictions.
4.  **Final Retraining:** Retrain all Level 1 models on the full training dataset and the Level 2 model on the full OOF matrix.

### Evaluation
1.  Process the test set to generate the three feature views (Lexical, Behavioral, Semantic) and the Global Metadata Vector.
2.  Concatenate the Global Metadata Vector to each specific view.
3.  Pass the combined feature sets to their respective Level 1 models to obtain probability scores.
4.  Feed the aggregated probabilities into the Level 2 Meta-Learner to generate the final prediction.
