Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and define the validation threshold.
2.  **Data Loading**: Use `DataFactory` to load the union dataset (Train + Val) and the Test dataset. Load the specific `val.parquet` metadata to identify the hold-out validation set for final evaluation.
3.  **Feature Engineering**: Execute the `FeaturePipeline` to generate the four feature modalities: Augmented Metadata, Granular Lexical (TF-IDF), Behavioral (Community TF-IDF), and Semantic (Dense Embeddings).
4.  **Model Training & Inference**: Instantiate and run the `HybridEnsembleEngine`. This will perform 5-fold CV on the union dataset, train Level 1 base learners, train the Level 2 meta-learner, retrain stable learners on the full dataset, and generate test predictions.
5.  **Validation Assessment**:
    *   Load the OOF predictions generated by the engine.
    *   Load the trained Meta-Learner.
    *   Isolate the predictions corresponding to the original `val.parquet` hold-out set.
    *   Generate final probabilities using the Meta-Learner on the OOF data.
    *   Compute and print the ROC AUC score.
6.  **Failure Analysis**:
    *   Calculate the absolute prediction error on the validation set.
    *   Compute correlations between the error and numerical features in the validation data.
    *   Print the top features associated with high error.
7.  **Submission Management**: Check if the validation AUC exceeds the required threshold (0.7222984867326668). If not, remove the generated submission file to comply with the "If and only if" requirement.
