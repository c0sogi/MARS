### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config`, ensuring reproducibility with `set_seed`.
2.  **Data Pipeline**: Utilize the `extract_features` function from `library.feature_extraction`. This function manages the loading of metadata, generation of TF-IDF vectors (for Lexical and Behavioral views), extraction of SBERT embeddings (for the Semantic view), and imputation of metadata. It leverages caching (`load_cache=True`) to optimize runtime.
3.  **Model Training**: Instantiate the `TriViewStackingClassifier`. Execute the `fit_cv` method, which performs the following:
    *   Generates Out-Of-Fold (OOF) predictions using 5-Fold Cross-Validation for the three base learners (Lexical RF, Semantic RF, Behavioral RF).
    *   Trains the Level 2 Logistic Regression Meta-Learner on these OOF predictions.
    *   Retrains all base learners on the full training dataset.
4.  **Validation**: Generate probability predictions for the hold-out validation set. Calculate and print the **Area Under the ROC Curve (AUC)** strictly in the required format (`Final Validation Metric: <value>`).
5.  **Failure Analysis**: Calculate the absolute error of predictions on the validation set. Correlate these errors with the numerical meta-features (e.g., account age, karma) to identify features associated with high model uncertainty.
6.  **Submission**: Compare the validation AUC against the required threshold (`0.6913548345419015`). If the model performs sufficiently well, generate predictions for the test set and save them to `./submission/submission.csv` in the specified format.
