The following script demonstrates the end-to-end execution of the provided machine learning pipeline. It performs the following steps:

1.  **Configuration Override**: Monkey-patches the `library.config` module to reduce the number of estimators, folds, and disable heavy computations (like large vectorizers) to ensure the demonstration runs quickly within the time limit. It also redirects artifacts to a specific `demo_run` directory.
2.  **Data Loading**: Uses `load_and_process_data` to load the pre-stratified metadata and prepare the union training set.
3.  **Feature Engineering**: Uses `get_processed_features` to generate Lexical, Behavioral, Semantic, and Metadata feature views. It validates the output shapes and types.
4.  **Ensemble Training**: Instantiates the `Trainer` class to train the Level 1 base learners (Volatile and Stable) and the Level 2 Meta-Learner. It validates that model artifacts are successfully saved.
5.  **Inference**: Instantiates the `Predictor` class to generate predictions on the test set using the trained ensemble.
6.  **Validation**: Verifies the final submission file's format, row count, and value ranges.
