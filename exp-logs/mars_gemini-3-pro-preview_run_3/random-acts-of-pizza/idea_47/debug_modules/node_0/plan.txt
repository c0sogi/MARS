The following script demonstrates the usage of the provided library modules to execute the full machine learning pipeline. It includes:

1.  **Configuration Overrides**: Modifies the global `Config` to use a small subset of data and lightweight model hyperparameters for rapid execution.
2.  **Data Preparation**: Creates a temporary "demo" dataset by sampling the original metadata files.
3.  **Feature Engineering**: Runs the `FeaturePipeline` to generate lexical, behavioral, semantic, and contextual features.
4.  **Training**: Executes the `CVEnsembleTrainer` to train base learners (Random Forests, XGBoost, LightGBM) and a meta-learner using 2-fold CV.
5.  **Inference**: Runs the `BaggingInference` pipeline to generate predictions on the test set.
6.  **Validation**: Asserts the correctness of output shapes and file generation at each step.
