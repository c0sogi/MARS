Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed and logger using the provided utility functions to ensure reproducibility and proper output formatting.
2.  **Data Loading**: Load the training, validation, and test datasets using `library.data_loader.load_data_splits`. The dataset is relatively small (~3000 samples), so we load the full dataset to maximize model performance without exceeding time limits.
3.  **Feature Processing**: Orchestrate feature engineering using `library.features.process_and_cache_data`. This handles TF-IDF vectorization, generation of semantic embeddings via a Transformer model (utilizing GPU if available), and processing of dense metadata. We enable caching to speed up subsequent runs.
4.  **Model Training**: Initialize and train the `MultiViewEnsemble` defined in `library.models`. This ensemble combines Logistic Regression and Random Forest models across lexical and semantic views.
5.  **Validation & Evaluation**:
    *   Generate probability predictions for the validation set.
    *   Compute the ROC AUC score.
    *   **Crucial Step**: Print the metric in the exact required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate the absolute prediction error for each validation sample.
    *   Compute the Pearson correlation between the error and each numerical feature (retrieved from the dense feature matrix).
    *   Print the top features associated with model error to provide insight into weaknesses.
7.  **Submission Generation**:
    *   Compare the validation AUC against the specified threshold (0.6565997512879729).
    *   If the model passes the threshold, generate predictions for the test set.
    *   Format the output as a CSV with `request_id` and `requester_received_pizza` (probability) and save it to the submission directory.
