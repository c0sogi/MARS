This script demonstrates the end-to-end usage of the provided machine learning pipeline components. It begins by configuring the global settings for rapid execution (reducing model complexity and data size). It then proceeds to load a subset of the data, process features using the `FeatureProcessor` (including TF-IDF and semantic embeddings), and finally trains and evaluates the `MultiViewEnsemble` model. Assertions are placed throughout to verify data integrity, shapes, and prediction validity.
