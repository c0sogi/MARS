The strategy for the `runfile.py` implementation is as follows:

1.  **Initialization**: Set the random seed and suppress warnings using the provided utility functions to ensure reproducibility and clean output.
2.  **Data Loading**: Use `load_and_clean_data` with caching enabled to efficiently load the training, validation, and test datasets.
3.  **Feature Engineering**: Execute `create_features` to generate the four feature views (Lexical, Behavioral, Semantic, Metadata) for all data splits.
4.  **Cross-Validation**: Initialize the `CrossValidationEngine` and run 5-fold CV on the training set to generate Out-of-Fold (OOF) predictions. These OOF predictions are essential for training the Level 2 Meta-Learner.
5.  **Validation Evaluation**:
    *   To strictly adhere to the requirement of printing the metric on the hold-out validation set *before* any leakage-prone retraining, we instantiate fresh base models and train them solely on the training set.
    *   We generate predictions on the validation set using these models.
    *   We train a temporary Meta-Learner on the OOF predictions and use it to aggregate the validation predictions.
    *   We compute and print the `Final Validation Metric` (ROC AUC).
6.  **Failure Analysis**: Calculate the absolute errors on the validation set and compute Pearson correlations with the dense metadata features to identify systematic error sources.
7.  **Submission Generation**:
    *   Check if the validation AUC exceeds the specified threshold (0.7138...).
    *   If successful, use the `ValidationGuidedRetrainer` to retrain the base models on the combined dataset (Train + Validation) and the Meta-Learner on the OOFs, maximizing data utilization.
    *   Generate the final predictions for the test set and save the `submission.csv`.
