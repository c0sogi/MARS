Based on the comprehensive empirical analysis of the "Lessons Learned," particularly the efficacy of **Textual Field Concatenation** (Cite solution_lesson_node_00044), the importance of **Restoring Valid Domain Priors** (Cite solution_lesson_node_00067), and the need for a **Hybrid Inference Protocol** to balance data utilization with early stopping stability (Cite solution_lesson_node_00036, Cite solution_lesson_node_00027), I propose a **Hex-View Stacking Ensemble with Hybrid Inference**.

This solution structurally evolves the "Pent-View" architecture by adding a dedicated **Temporal Booster** (LightGBM) to capture non-linear drift and implementing a novel **Hybrid Inference Protocol** that differentiates retraining strategies based on learner stability.

# Model

The architecture is a **Stacking Ensemble** composed of **six** "Level 1" base learners, organized into four topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Title and Edit-Aware Body** combined with the **Augmented Global Metadata**.
        *   *Retention:* Concatenating Title + Body maximizes signal (Cite solution_lesson_node_00044). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** combined with the **Augmented Global Metadata**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts." We strictly limit the vocabulary to the **Top 1,000** subreddits. This sparse representation is superior to dense embeddings for categorical sets (Cite solution_lesson_node_00029) and prevents overfitting to rare communities (Cite solution_lesson_node_00042).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster (XGB):** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Retention:* Captures non-linear signals in the continuous semantic space (Cite solution_lesson_node_00018). We use `scale_pos_weight` (Cite solution_lesson_node_00034) and maintain high capacity (2,000 estimators).
    *   **Semantic Bagger (RF):** A **Random Forest Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Retention:* Provides structural diversity (Cite solution_lesson_node_00025). We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) to prevent memorization of dense noise (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor (Linear):** A **Logistic Regression** model trained on the **Augmented Global Metadata**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).
    *   **Temporal Booster (Non-Linear):** A **LightGBM Classifier** trained on the **Augmented Global Metadata**.
        *   *Structural Innovation:* Unlike the linear anchor, this tree-based model can split on the **Raw Timestamp** to identify specific temporal regimes (e.g., "Pre-2012 vs. Post-2012") and non-linear interactions between user stats (Cite solution_lesson_node_00041).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Hygienic Feature Selection**.

1.  **Leakage Prevention:**
    *   **Source Text:** Use `request_text_edit_aware` exclusively. Do not touch `request_text` (Cite solution_lesson_node_00062).
    *   **Exclusion:** Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Augmented Global Metadata:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) a curated set of dense features:
        *   **Raw Timestamp:** `unix_timestamp_of_request_utc` (Cite solution_lesson_node_00041).
        *   **User Stats:** Account Age, Karma, Total Post Counts.
        *   **Restored RAOP History:** Explicitly include `requester_number_of_posts_on_raop_at_request`, `requester_number_of_comments_in_raop_at_request`, and `requester_days_since_first_post_on_raop_at_request`. These are valid pre-request signals of community participation (reciprocity) that were inadvertently pruned in previous attempts (Cite solution_lesson_node_00067).
        *   **Exclusion:** Explicitly exclude derived text length features (Cite solution_lesson_node_00027).
    *   **Text Concatenation:** Join `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00044).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs.
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

# Training

The training procedure implements a **Hybrid Inference Protocol** to resolve the conflict between early stopping and data utilization.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Level 1 Training (OOF Generation):**
    *   Train all models on 4 folds, predict on 5th.
    *   **XGBoost / LightGBM:** Use the fold's validation set for **Early Stopping**.
    *   **RF / Linear:** Train normally.
3.  **Hybrid Retraining (Structural Innovation):**
    *   **Stable Learners (RF / Linear):** Retrain a single model on the **Full Training Set** (Train + Validation). These models do not require early stopping and benefit significantly from maximum data availability (Cite solution_lesson_node_00044).
    *   **Volatile Learners (XGBoost / LightGBM):** Do *not* retrain a single model. Instead, **persist the 5 fold-models**. Retraining a booster on the full set requires "guessing" the iteration count or using a small nested validation set, both of which are unstable (Cite solution_lesson_node_00027, Cite solution_lesson_node_00036). CV-Bagging is the robust alternative.

# Evaluation

1.  **Hybrid Inference:**
    *   For **RF / Linear** branches: Generate predictions using the single fully-retrained model.
    *   For **XGBoost / LightGBM** branches: Generate predictions using all 5 fold-models and **average** them (CV-Bagging).
2.  **Stacking:** Feed the resulting 6 probability scores to the Meta-Learner for the final prediction.
