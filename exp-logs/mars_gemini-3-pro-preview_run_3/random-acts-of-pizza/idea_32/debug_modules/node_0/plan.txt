The following script demonstrates the end-to-end usage of the provided library to solve the Random Acts of Pizza task. It performs the following steps:

1.  **Configuration Overrides**: Modifies the global configuration to use lightweight hyperparameters (e.g., fewer trees) for rapid execution.
2.  **Feature Engineering**: Uses `FeatureFactory` to load metadata and generate Lexical (TF-IDF), Behavioral (History TF-IDF), Semantic (Embeddings), and Metadata (Dense) feature views.
3.  **Ensemble Training**: Instantiates the `StackingPipeline`, runs cross-validation to generate Out-of-Fold (OOF) predictions, and trains the Level 2 Meta-Learner.
4.  **Retraining & Inference**: Retrains base models on the full training set (using validation data for early stopping where applicable) and generates predictions for the test set.
5.  **Submission**: Formats and saves the final submission file.
6.  **Validation**: Includes assertions at key stages to verify data shapes and pipeline logic.
