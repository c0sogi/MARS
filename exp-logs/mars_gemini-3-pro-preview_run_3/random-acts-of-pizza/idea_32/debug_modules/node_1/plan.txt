The `AssertionError: Lexical vocab size exceeded` occurs because `library/features.py` imports configuration constants (like `TEXT_VOCAB_SIZE`) directly using `from library.config import ...`. This binds the values at import time. When `runfile.py` subsequently modifies `config.TEXT_VOCAB_SIZE` at runtime to reduce the vocabulary size for the demo, `library/features.py` continues to use the original, larger value (3000) instead of the updated one (500). This causes the vectorizer to produce more features than the assertion allows.

To fix this, I will modify `library/features.py` to import the entire `library.config` module as `config` and access the variables as attributes (e.g., `config.TEXT_VOCAB_SIZE`). This ensures that the code always retrieves the current runtime value of the configuration variables, reflecting the overrides made in `runfile.py`. Cite debug_lesson_5.
