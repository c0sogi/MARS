The implementation strategy follows the Multi-Paradigm Stacking Ensemble architecture defined in the problem description.

1.  **Initialization**: Set random seeds for reproducibility and initialize the `DataProcessor`, `FeatureGenerator`, and `StackingEngine`.
2.  **Data Loading**: Load the stratified training, validation, and test sets. The `DataProcessor` handles imputation and basic feature engineering (time-based features, word counts).
3.  **Feature Generation**:
    *   **Lexical View**: Generate sparse TF-IDF vectors concatenated with dense metadata using `FeatureGenerator`.
    *   **Semantic View**: Generate dense SBERT embeddings concatenated with dense metadata using `FeatureGenerator`.
    *   These views are generated for train, validation, and test sets.
4.  **Model Training (Stacking)**:
    *   **Level 1 & Meta-Learning**: Use `StackingEngine.fit_cv` to perform 5-fold cross-validation on the training set. This generates Out-Of-Fold (OOF) predictions to train the Level 2 Logistic Regression Meta-Learner without leakage.
    *   **Retraining**: Use `StackingEngine.retrain_base_models` to retrain all Level 1 base learners (Random Forests and XGBoost) on the full training dataset to maximize information for final inference.
5.  **Validation**:
    *   Generate predictions on the hold-out validation set.
    *   Compute the Area Under the ROC Curve (AUC).
    *   Print the required metric string: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample.
    *   Compute Pearson correlation coefficients between the error magnitude and available numerical features to identify conditions where the model underperforms.
7.  **Submission**:
    *   Compare the validation AUC against the threshold (0.6707957169850934).
    *   If successful, generate predictions for the test set and save the submission file to `./submission/submission.csv`.
