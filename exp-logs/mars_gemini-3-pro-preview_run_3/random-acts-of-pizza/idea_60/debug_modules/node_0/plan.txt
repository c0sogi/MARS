This script demonstrates the end-to-end execution of the Granular Hept-View Stacking Ensemble for the Random Acts of Pizza task. It performs the following steps:

1.  **Configuration Override**: Monkey-patches the `Config` class to enable `DEBUG` mode (reducing the dataset to 100 samples) and reduces model hyperparameters (e.g., `n_estimators=5`, `N_FOLDS=2`) to ensure the demonstration runs quickly (under 60 seconds).
2.  **Data Loading**: Uses `data_loader.get_data` to load the train/val/test metadata, demonstrating the automated union of train/val sets and debug downsampling.
3.  **Feature Engineering**: Instantiates `FeaturePipeline` to generate the four data views (Lexical, Behavioral, Semantic, Metadata). It verifies the shapes and types of the generated feature matrices.
4.  **Ensemble Training**: Initializes `EnsembleTrainer` to train the 7 base learners (mix of stable and volatile) and the meta-learner. It validates that model artifacts are correctly serialized to disk.
5.  **Inference**: Uses `EnsemblePredictor` to load the trained models, perform hybrid inference (averaging fold models for volatile learners, using full models for stable ones), and generate a submission file.
6.  **Validation**: Includes assertions at every stage to verify data integrity, file existence, and prediction consistency.
