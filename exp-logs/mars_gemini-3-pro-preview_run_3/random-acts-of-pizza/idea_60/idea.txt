# Solution Proposal: Granular Hept-View Stacking Ensemble with Robust Hybrid Inference

Based on the rigorous empirical analysis of the "Lessons Learned," particularly the critical importance of **Granular Tokenization** for preserving agency (Cite solution_lesson_node_00083), the necessity of **Explicit Model Restoration** in early stopping (Cite solution_lesson_node_00087), and the robustness of **Consistent Hybrid Inference** (Cite solution_lesson_node_00081, Cite solution_lesson_node_00072), I propose a **Granular Hept-View Stacking Ensemble with Robust Hybrid Inference**.

This solution structurally evolves the high-performing "Hept-View" architecture (Idea 51/59) by strictly enforcing **Signal Preservation** (via granular tokens and restored priors) and **Training Integrity** (via union-based CV and explicit best-model loading).

# Model

The architecture is a **Stacking Ensemble** composed of **seven** "Level 1" base learners, organized into four topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Granular Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Title and Edit-Aware Body** combined with the **Augmented Global Metadata**.
        *   *Structural Innovation:* We override the default token pattern with `token_pattern=r"\w{1,}"`. This forces the vectorizer to capture single-character tokens like **"I"** (agency) and **"$"** (financial context), which are highly predictive but discarded by standard tokenizers (Cite solution_lesson_node_00083).
        *   *Retention:* Concatenation maximizes signal (Cite solution_lesson_node_00044). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** combined with the **Augmented Global Metadata**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts" with a vocabulary limit of **Top 1,000** subreddits. This sparse representation is superior to dense embeddings for categorical sets (Cite solution_lesson_node_00029) and prevents overfitting to rare communities (Cite solution_lesson_node_00042).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster (XGB):** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Correction:* We enforce **Conservative Boosting** (`learning_rate=0.01`, `colsample_bytree=0.6`) to reduce variance (Cite solution_lesson_node_00084) and explicitly use `scale_pos_weight` to handle class imbalance (Cite solution_lesson_node_00084).
    *   **Semantic Gradient (LGBM):** A **LightGBM Classifier** trained on the same features.
        *   *Retention:* Provides algorithmic diversity via leaf-wise growth (Cite solution_lesson_node_00025).
    *   **Semantic Bagger (RF):** A **Random Forest Classifier** trained on the same features.
        *   *Retention:* Provides structural diversity. We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) to prevent memorization of dense noise (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor (Linear):** A **Logistic Regression** model trained on the **Augmented Global Metadata**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).
    *   **Temporal Booster (Non-Linear):** A **LightGBM Classifier** trained on the **Augmented Global Metadata**.
        *   *Retention:* Captures non-linear temporal drift via raw timestamps (Cite solution_lesson_node_00041).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Hygienic Feature Selection**.

1.  **Leakage Prevention:**
    *   **Source Text:** Use `request_text_edit_aware` exclusively (Cite solution_lesson_node_00062).
    *   **Exclusion:** Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Augmented Global Metadata:** Explicitly **Allow-List** (Cite solution_lesson_node_00030):
        *   **Raw Timestamp:** `unix_timestamp_of_request_utc` (Cite solution_lesson_node_00041).
        *   **Restored RAOP History:** Include `requester_number_of_posts_on_raop_at_request` and related pre-request counters. These are valid priors inadvertently pruned in previous attempts (Cite solution_lesson_node_00067).
        *   **User Stats:** Account Age, Karma, Post Counts.
        *   **Exclusion:** Exclude derived text length features (Cite solution_lesson_node_00027).
        *   *Note:* Concatenate this vector to **all** base learners (Cite solution_lesson_node_00023).
    *   **Text Concatenation:** Join `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00044).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) with `sublinear_tf=True`, `min_df=5`, and the custom `token_pattern=r"\w{1,}"` (Cite solution_lesson_node_00083).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Union Strategy:** Merge the provided Training and Validation sets into a single **Union Dataset** for the entire pipeline. This ensures the Meta-Learner is trained and evaluated on consistent distributions (Cite solution_lesson_node_00081).
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs.

# Training

The training procedure implements a **Robust Hybrid Inference Protocol** (Cite solution_lesson_node_00072, Cite solution_lesson_node_00081).

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation on the **Union Dataset**.
2.  **Ensemble Training (Per Fold):**
    *   **Volatile Learners (XGBoost / LightGBM):** Train on 4 folds, using the **1 validation fold** for **Early Stopping**.
        *   *Correction:* Explicitly set `load_best_model_at_end=True` (or equivalent) and pass the validation set to `fit()` to ensure the optimal state is restored, preventing the overfitting observed in previous iterations (Cite solution_lesson_node_00087).
    *   **Stable Learners (RF / Linear):** Train on 4 folds.
    *   **OOF Generation:** Generate predictions for the validation fold.
    *   **Persistence:** Save all 7 models for this fold.
3.  **Meta-Learner Training:** Train on the full matrix of OOF predictions from the Union Dataset.
4.  **Stable Learner Retraining:** Train single instances of the Stable Learners (RF/Linear) on the full Union Dataset to maximize data usage (Cite solution_lesson_node_00044).

# Evaluation

1.  **Hybrid Inference:**
    *   **Volatile Branches:** Generate predictions using all 5 saved fold-models and **average** them (CV-Bagging). This reduces variance without the risk of blind retraining (Cite solution_lesson_node_00027).
    *   **Stable Branches:** Generate predictions using the single fully-retrained model.
2.  **Stacking:** Feed the resulting 7 probability scores to the Meta-Learner for the final prediction.
