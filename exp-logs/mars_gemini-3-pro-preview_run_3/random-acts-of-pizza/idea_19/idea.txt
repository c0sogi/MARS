# Solution Proposal: Fully Symmetric Dual-Topology Stacking with Validation-Guided Inference

Based on the analysis of the "Lessons Learned," I propose a **Fully Symmetric Dual-Topology Stacking Ensemble**. This architecture structurally evolves the previous "Pent-View" and "Symmetric" concepts by rigorously applying the **Algorithmic Diversity** lesson (Cite solution_lesson_node_00025) to *both* the Text and Behavioral modalities. It also implements a refined feature engineering strategy to mitigate the noise identified in Lesson 00027 and strictly enforces the **Validation-Guided Retraining** protocol.

## Model

The architecture is a **Stacking Ensemble** composed of **seven** "Level 1" base learners, organized into three symmetric branches based on data modality and topology. This design ensures that both Text and User Behavior are modeled with equal rigor using Sparse (Bagging) and Dense (Hybrid) approaches.

**Level 1: Base Learners**

1.  **Text Modality Branch (3 Models)**
    *   **Lexical Bagger (Sparse):** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Unified Metadata Vector**.
        *   *Rationale:* Captures specific high-impact keywords (e.g., "paycheck") using the robustness of Bagging on sparse data (Cite solution_lesson_node_00013). Regularized with `min_samples_leaf=2` (Cite solution_lesson_node_00025).
    *   **Semantic Hybrid (Dense):** A pair of models—an **XGBoost Classifier** and a **Random Forest Classifier**—trained on **Frozen MPNet Embeddings** of the text concatenated with Metadata.
        *   *Rationale:* Uses XGBoost to capture non-linear semantic signals and Random Forest to capture structural patterns in the embedding space, providing significant lift over boosting alone (Cite solution_lesson_node_00025).

2.  **Behavioral Modality Branch (3 Models)**
    *   **Community Bagger (Sparse):** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with Metadata.
        *   *Rationale:* Treats user history as a "Bag-of-Concepts" to capture niche community memberships (Cite solution_lesson_node_00018).
    *   **Persona Hybrid (Dense):** A pair of models—an **XGBoost Classifier** and a **Random Forest Classifier**—trained on **Aggregated Subreddit Embeddings** concatenated with Metadata.
        *   *Innovation:* We treat the list of subreddits as a semantic string (e.g., "AskReddit frugal") and embed it using MPNet. We then apply the **Hybrid (RF + XGB)** strategy here (evolving from Idea 18 which used only XGB), ensuring the behavioral view benefits from the same algorithmic diversity as the text view (Cite solution_lesson_node_00025).

3.  **Contextual Modality Branch (1 Model)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained exclusively on the **Unified Metadata Vector**.
        *   *Rationale:* Acts as a high-bias regularizer based on robust heuristics (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the contributions of the seven base learners (Cite solution_lesson_node_00012).

## Data

The data pipeline enforces strict leakage prevention, robust typing, and noise reduction.

1.  **Leakage Prevention:**
    *   Source Text: `request_text_edit_aware` (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Unified Metadata Vector:** Explicitly generate and **allow-list** (Cite solution_lesson_node_00007) dense features: User Stats (Age, Karma, Post Counts) and Temporal (Hour, Day).
        *   *Refinement:* **Exclude explicit text length/complexity features.** Lesson 00027 indicated these were highly correlated with prediction error and exacerbated overfitting. We rely on the **Semantic View** (MPNet) to implicitly capture "effort" and "length" signals within the embeddings, avoiding the noisy proxy features.
    *   **Text Features:**
        *   *Sparse:* TF-IDF (Unigrams/Bigrams, Top 3,000) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
        *   *Dense:* Frozen `all-mpnet-base-v2` Embeddings (768-dim) (Cite solution_lesson_node_00015).
    *   **Behavioral Features:**
        *   *Sparse:* Robustly serialize `requester_subreddits_at_request` (Cite solution_lesson_node_00017) -> TF-IDF (Unigrams, Top 1,000).
        *   *Dense:* Serialize subreddits -> MPNet Embedding.
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to Unified Metadata (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

## Training

The training procedure implements the **Validation-Guided Retraining Protocol** to prevent the failure observed in Lesson 00027.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Level 1 Training (OOF Generation):**
    *   **Random Forests / Linear:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'` and `min_samples_leaf=2`.
    *   **XGBoost:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on OOF matrix.
4.  **Final Retraining:**
    *   **RF / Linear:** Retrain on the **Full Training Set** (Train + Validation).
    *   **XGBoost:** Retrain on the **Full Training Set** but explicitly pass the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents the "blind overfitting" caused by fixed iteration counts (Cite solution_lesson_node_00027).

## Evaluation

1.  Process the test set to generate all feature views.
2.  Pass specific views to the seven base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
