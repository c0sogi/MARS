The issue stems from a mismatch between the default hyperparameter configuration and the small dataset size used in the demo script. Specifically, the `min_df` parameter (minimum document frequency) is set to 5 in `library/config.py`, which instructs the TF-IDF vectorizer to ignore any token appearing in fewer than 5 documents. In `runfile.py`, the dataset is subsampled to only 40 rows. It is statistically improbable for sparse features like subreddit names to meet this frequency threshold in such a small sample, causing the vectorizer to filter out all tokens and raise a `ValueError: empty vocabulary`.

To fix this, I will modify `runfile.py` to explicitly relax the `min_df` constraint to 1 for the demo execution. This ensures that the vectorizers can function correctly on the small debug subset without altering the production configuration, applying the solution from `debug_lesson_12`.
