This script demonstrates the end-to-end execution of the Symmetric Multi-Modal Stacking Ensemble pipeline. It first overrides the default configuration to optimize for speed (reducing model estimators, folds, and data size). It then loads a sample of the dataset, generates multi-modal features (text, behavioral, contextual), trains the Level 1 base learners and Level 2 meta-learner, and finally generates predictions and a submission file. Verification steps are included to ensure data shapes and outputs are correct.
