# Solution Proposal: Symmetric Multi-Modal Stacking with Validation-Guided Retraining

Based on the extensive empirical analysis and lessons learned, I propose a **Symmetric Multi-Modal Stacking Ensemble**. This architecture structurally evolves the previous "Pent-View" approach by establishing a fully symmetric treatment of the Text and Behavior modalities—applying both Sparse (Lexical) and Dense (Semantic) modeling to each—and implementing a rigorous **Validation-Guided Retraining Protocol** to resolve the overfitting issues identified in Lesson 00027.

## Model

The architecture is a **Stacking Ensemble** composed of six "Level 1" base learners organized into three functional branches, feeding into a "Level 2" meta-learner.

**Level 1: Base Learners (The Symmetric Layer)**

1.  **Text Modality Branch**
    *   **Lexical Bagger (Sparse View):** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Unified Metadata Vector**.
        *   *Retention:* Random Forests on sparse TF-IDF features consistently provide the strongest predictive signal for specific keywords (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).
    *   **Semantic Ensemble (Dense View):** An **XGBoost Classifier** and a **Random Forest Classifier** trained on **Frozen MPNet Embeddings** of the text concatenated with Metadata.
        *   *Retention:* We use both algorithms to capture diverse structural patterns (Gradient Boosting for non-linearities, Bagging for stability) in the dense semantic space (Cite solution_lesson_node_00025).

2.  **Behavioral Modality Branch**
    *   **Community Bagger (Sparse View):** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with Metadata.
        *   *Retention:* Treating user history as a "Bag-of-Concepts" document captures niche community memberships effectively (Cite solution_lesson_node_00018).
    *   **Persona Booster (Dense View):** An **XGBoost Classifier** trained on **Aggregated Subreddit Embeddings** concatenated with Metadata.
        *   *Innovation:* Instead of using SVD (which relies solely on internal co-occurrence), we treat the list of subreddits as a semantic string (e.g., "AskReddit frugal gaming") and encode it using the pre-trained MPNet transformer. This leverages *external* semantic knowledge to cluster users by interest (e.g., relating "povertyfinance" to "assistance") even if they don't overlap in the training set, providing a high-quality dense input for Boosting.

3.  **Contextual Modality Branch**
    *   **Metadata Anchor:** A **Logistic Regression** model trained *exclusively* on the **Unified Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer based on robust heuristics (account age, karma), stabilizing the ensemble (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** A linear model to optimally calibrate the contributions of the six base learners (Cite solution_lesson_node_00012).

## Data

The data pipeline enforces strict leakage prevention, robust typing, and high-fidelity feature extraction.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Unified Metadata Vector:** Explicitly generate and **allow-list** (Cite solution_lesson_node_00007) dense features: User Stats (Age, Karma, Post Counts), Temporal (Hour, Day), and Text Complexity (Word Count, Sentiment). This vector is concatenated to **all** base learners to preserve cross-modal interactions (Cite solution_lesson_node_00023).
    *   **Text Features:**
        *   *Sparse:* TF-IDF (Unigrams/Bigrams, Top 3,000) using `sublinear_tf=True` and `min_df=5` to ensure robust scaling (Cite solution_lesson_node_00024).
        *   *Dense:* Extract **Frozen Embeddings** using `all-mpnet-base-v2` (768-dim). We upgrade to MPNet for better semantic resolution while avoiding the instability of fine-tuning (Cite solution_lesson_node_00015).
    *   **Behavioral Features:**
        *   *Sparse:* Robustly serialize `requester_subreddits_at_request` using duck typing (Cite solution_lesson_node_00017) -> TF-IDF (Unigrams, Top 1,000).
        *   *Dense:* Serialize subreddits into a space-separated string -> MPNet Embedding.
3.  **Preprocessing:**
    *   **Imputation:** Median imputation for numerical columns.
    *   **Scaling:** Apply `StandardScaler` to the Unified Metadata Vector before concatenation (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly to prevent alignment corruption (Cite solution_lesson_node_00024).

## Training

The training procedure implements a **Validation-Guided Retraining Protocol** to specifically address the failure observed in Lesson 00027.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Level 1 Training (OOF Generation):**
    *   Train all models on 4 folds and predict on the 5th.
    *   Use `class_weight='balanced'` for RF/Linear and `scale_pos_weight` for XGBoost.
    *   Use `min_samples_leaf=2` for all Random Forests (Cite solution_lesson_node_00025).
3.  **Level 2 Training:** Train the Meta-Learner on the OOF matrix.
4.  **Final Retraining (The Innovation):**
    *   **For Random Forests & Linear Models:** Retrain on the **Full Training Set** (Train + Validation).
    *   **For XGBoost Models:** Retrain on the **Full Training Set** but explicitly pass the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method. This enables **Early Stopping** based on the validation distribution, preventing the "blind overfitting" caused by using fixed iteration counts (Cite solution_lesson_node_00027).

## Evaluation

1.  Process the test set to generate all feature views (Lexical TF-IDF, Text Embeddings, Behavioral TF-IDF, Behavioral Embeddings, Metadata).
2.  Pass the specific feature subsets to their respective Level 1 models to obtain six probability scores per sample.
3.  Feed the aggregated probabilities into the Level 2 Meta-Learner to generate the final prediction.
