Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and define necessary constants.
2.  **Data Loading & Feature Engineering**: Use the provided `FeatureEngineer` to generate Lexical (TF-IDF), Style (Linguistic), and Metadata features for Train, Validation, and Test sets. Load tokenized data for the Semantic view using the `library.dataset` utilities.
3.  **Level 1 Model Training (Stacking Preparation)**:
    *   Perform 5-Fold Cross-Validation on the **Training Set** to generate Out-Of-Fold (OOF) predictions. This is crucial to train the Meta-Learner without leakage.
    *   Inside the CV loop, train the three base learners:
        *   **Lexical**: Random Forest on TF-IDF + Metadata.
        *   **Style**: XGBoost on Style Features + Metadata.
        *   **Semantic**: Fine-tune DistilBERT on raw text (using a subset of the fold for early stopping).
4.  **Meta-Learner Training**: Train the Level 2 Logistic Regression model on the OOF predictions generated from the Training Set.
5.  **Final Model Training**:
    *   Retrain all Level 1 base learners on the **Full Training Set**. For the Semantic model, use the **Validation Set** for early stopping to prevent overfitting.
    *   Generate predictions for the **Validation Set** and **Test Set** using these fully trained base learners.
6.  **Validation & Evaluation**:
    *   Feed the Validation Set base predictions into the Meta-Learner to get final probabilities.
    *   Compute and print the **Area Under the ROC Curve (AUC)** on the hold-out Validation Set.
7.  **Failure Analysis**: Calculate the correlation between the model's prediction error on the Validation Set and the input features to identify failure modes.
8.  **Submission**: If the validation AUC exceeds the specified threshold, feed the Test Set base predictions into the Meta-Learner and save the final probabilities to `submission.csv`.
