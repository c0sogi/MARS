Implementation Strategy:
1.  **Configuration Override**: We will modify the mutable dictionaries within the `Config` class (e.g., `RF_PARAMS`, `BERT_TRAIN_PARAMS`) to significantly reduce the computational load (fewer estimators, epochs, and batch size). This ensures the demonstration runs quickly.
2.  **Explicit Instantiation**: Since default arguments in Python functions are evaluated at definition time (import time), modifying `Config` constants like `DEBUG` or `N_FOLDS` after import won't affect functions that use them as defaults. Therefore, we will explicitly pass `debug=True` and `n_folds=2` when calling functions or instantiating classes.
3.  **Component Verification**: We will step through the pipeline:
    *   **Data Loading**: Verify `utils.load_data` returns the correct subset.
    *   **Feature Engineering**: Verify `FeatureEngineer` produces matrices with expected dimensions.
    *   **DataLoaders**: Verify `dataset.create_dataloaders` yields batches of the correct shape.
    *   **Models**: Instantiate and test-fit the Random Forest, XGBoost, and Transformer wrappers on dummy data to ensure they function.
    *   **Full Engine**: Run the `CrossValidationRunner` in debug mode to generate a submission file, then verify the output file's structure.
4.  **Safety**: We use assertions to validate logic and ensure no errors are suppressed.
