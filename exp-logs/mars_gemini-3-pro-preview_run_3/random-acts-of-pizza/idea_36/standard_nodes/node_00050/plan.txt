Implementation Strategy:
1.  **Setup & Data Loading**: Initialize the environment (seeds, logging) and load the pre-processed datasets (train, val, test) using the provided `DataLoader`. This leverages the existing caching mechanism to save time.
2.  **Feature Engineering**:
    *   Instantiate the `TfidfVectorizer` for the subreddit history (Behavioral View) and fit it on the training data.
    *   Implement the view construction logic for the five base learners (Lexical, Community, Semantic XGB, Semantic RF, Metadata) by combining sparse TF-IDF matrices, dense embeddings, and metadata.
    *   Apply the `CommunityProfiler` (Bayesian Target Encoding) within the cross-validation loop to generate the `community_success_score` without leakage.
3.  **Stacking Training (OOF)**:
    *   Perform Stratified K-Fold Cross-Validation on the training set.
    *   For each fold, train the five base models and generate Out-of-Fold (OOF) predictions.
    *   Train the Level 2 Logistic Regression Meta-Learner on these OOF predictions.
4.  **Validation & Failure Analysis**:
    *   Train the base models on the *full* training set (using a split for Early Stopping where necessary).
    *   Generate predictions on the hold-out validation set (`val.parquet`).
    *   Compute and print the **Final Validation Metric** (AUC).
    *   Calculate the absolute prediction error on the validation set and compute correlations with metadata features to identify failure modes.
5.  **Submission Generation**:
    *   If the validation AUC exceeds the threshold (0.7138), retrain the entire pipeline on the combined Training + Validation set to maximize performance.
    *   Generate predictions for the test set and save `submission.csv`.
