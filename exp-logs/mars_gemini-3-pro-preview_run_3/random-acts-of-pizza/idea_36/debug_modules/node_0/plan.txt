The following script demonstrates the usage of the provided library files. It follows a strategy of:
1.  **Configuration Override**: Modifying the `Config` class at runtime to use a small dataset subset (`DEBUG_SAMPLE_SIZE=50`) and lightweight model hyperparameters (e.g., 10 estimators) to ensure rapid execution.
2.  **Unit Testing Components**: Verifying the logic of individual classes like `CommunityProfiler`, `TextProcessor`, and `MetadataExtractor` using synthetic data and assertions.
3.  **Pipeline Integration**: Running the full `StackingTrainer` workflow to process data, train the ensemble, and generate a submission file, validating the final output.
