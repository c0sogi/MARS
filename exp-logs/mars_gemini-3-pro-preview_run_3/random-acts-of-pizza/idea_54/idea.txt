Based on the comprehensive empirical analysis of the "Lessons Learned," particularly the efficacy of **Hybrid Inference Protocols** (Cite solution_lesson_node_00072), the critical importance of **Restoring Valid Domain Priors** (Cite solution_lesson_node_00067), and the structural success of **Full-Spectrum Topology Matching** (Cite solution_lesson_node_00025), I propose an **Oct-View Full-Spectrum Stacking Ensemble with Hybrid Inference**.

This solution structurally evolves the "Hept-View" architecture (Idea 52) by introducing a **Lexical Anchor (Linear)** branch. This ensures that the dominant textual signal (Cite solution_lesson_node_00065) is modeled by both non-linear (Random Forest) and linear (Logistic Regression) paradigms, maximizing signal extraction. It rigorously applies the **Hybrid Inference Protocol** to decouple retraining strategies for stable vs. volatile learners.

# Model

The architecture is a **Stacking Ensemble** composed of **eight** "Level 1" base learners, organized into four topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Title and Edit-Aware Body** combined with the **Augmented Global Metadata**.
        *   *Retention:* Concatenation maximizes signal (Cite solution_lesson_node_00044). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).
    *   **Lexical Anchor (Linear):** A **Logistic Regression** model trained on the same sparse feature set.
        *   *Structural Innovation:* Adds a high-bias linear baseline to the strongest modality. This complements the Random Forest by capturing global linear separability in the high-dimensional text space, enhancing **Algorithmic Diversity** (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** combined with the **Augmented Global Metadata**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts." We strictly limit the vocabulary to the **Top 1,000** subreddits. This sparse representation is superior to dense embeddings for categorical sets (Cite solution_lesson_node_00029) and prevents overfitting to rare communities (Cite solution_lesson_node_00042).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster (XGB):** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Retention:* Captures non-linear signals in continuous semantic space (Cite solution_lesson_node_00018). We use `scale_pos_weight` (Cite solution_lesson_node_00034).
    *   **Semantic Gradient (LGBM):** A **LightGBM Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Retention:* Provides algorithmic diversity via leaf-wise growth (Cite solution_lesson_node_00025).
    *   **Semantic Bagger (RF):** A **Random Forest Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Retention:* Provides structural diversity. We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) to prevent memorization of dense noise (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor (Linear):** A **Logistic Regression** model trained on the **Augmented Global Metadata**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).
    *   **Temporal Booster (Non-Linear):** A **LightGBM Classifier** trained on the **Augmented Global Metadata**.
        *   *Retention:* Captures non-linear temporal drift via raw timestamps (Cite solution_lesson_node_00041).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Hygienic Feature Selection**.

1.  **Leakage Prevention:**
    *   **Source Text:** Use `request_text_edit_aware` exclusively to avoid post-hoc edit leakage (Cite solution_lesson_node_00062).
    *   **Exclusion:** Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Augmented Global Metadata:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) a curated set of dense features:
        *   **Raw Timestamp:** `unix_timestamp_of_request_utc` (Cite solution_lesson_node_00041).
        *   **User Stats:** Account Age, Karma, Total Post Counts.
        *   **Restored RAOP History:** Explicitly include `requester_number_of_posts_on_raop_at_request`, `requester_number_of_comments_in_raop_at_request`, and `requester_days_since_first_post_on_raop_at_request`. These are valid pre-request signals of community participation that were inadvertently pruned in previous attempts (Cite solution_lesson_node_00067).
        *   **Exclusion:** Explicitly exclude derived text length features as they are noisy proxies (Cite solution_lesson_node_00027).
        *   *Note:* Concatenate this vector to **all** base learners (Cite solution_lesson_node_00023).
    *   **Text Concatenation:** Join `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00044).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs.
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

# Training

The training procedure implements a **Hybrid Inference Protocol** to resolve the conflict between early stopping and data utilization (Cite solution_lesson_node_00036, Cite solution_lesson_node_00072).

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Ensemble Training (Per Fold):**
    *   **Volatile Learners (XGBoost / LightGBM):** Train on 4 folds, using the **1 validation fold** for **Early Stopping**. This ensures optimal tuning without "peeking" (Cite solution_lesson_node_00027).
    *   **Stable Learners (RF / Linear):** Train on 4 folds.
    *   **Meta-Learner:** Train on the OOF predictions.
3.  **Hybrid Retraining:**
    *   **Stable Learners:** Retrain a single model on the **Full Training Set** (Train + Validation). These models benefit significantly from maximum data availability and do not require early stopping (Cite solution_lesson_node_00044).
    *   **Volatile Learners:** Do *not* retrain a single model. Instead, **persist the 5 fold-models**. This avoids the instability of guessing iteration counts for full-retraining (Cite solution_lesson_node_00027).

# Evaluation

1.  **Hybrid Inference:**
    *   For **Stable Branches (RF / Linear)**: Generate predictions using the single fully-retrained model.
    *   For **Volatile Branches (XGBoost / LightGBM)**: Generate predictions using all 5 fold-models and **average** them (CV-Bagging).
2.  **Stacking:** Feed the resulting 8 probability scores to the Meta-Learner for the final prediction.
