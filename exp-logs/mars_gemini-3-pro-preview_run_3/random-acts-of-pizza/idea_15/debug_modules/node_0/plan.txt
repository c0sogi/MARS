This script demonstrates the end-to-end usage of the provided machine learning library for the Random Acts of Pizza task. It performs the following steps:

1.  **Data Processing**: Initializes the `DataPipeline` to load raw Parquet files, extract features (Metadata, Lexical TF-IDF, Behavioral TF-IDF, Semantic Embeddings), and cache the processed arrays.
2.  **Ensemble Initialization**: Instantiates the `PentViewStackingEnsemble`.
3.  **Optimization for Demonstration**: To ensure the script runs quickly (as requested), it overrides the hyperparameters of the internal Level 1 and Level 2 models (reducing estimators, depth, and iterations) and reduces the number of cross-validation folds. It also subsets the training data to a smaller fraction.
4.  **Training**: Fits the stacking ensemble on the processed training data.
5.  **Validation**: Generates predictions on the validation set and calculates the ROC AUC score to verify model performance.
6.  **Submission Generation**: Generates predictions on the test set and creates the final submission CSV file.
7.  **Logic Verification**: Includes assertions throughout to verify data shapes, prediction ranges, and file outputs.
