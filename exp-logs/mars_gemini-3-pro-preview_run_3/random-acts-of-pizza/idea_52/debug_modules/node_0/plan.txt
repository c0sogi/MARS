This script demonstrates the end-to-end usage of the provided library components to solve the Random Acts of Pizza prediction task. It performs the following steps:

1.  **Configuration Overrides**: Modifies the global configuration in `library.config` to use lightweight hyperparameters (fewer estimators, limited depth) and a small data subset. This ensures the demonstration runs quickly (under 5 minutes) while validating the logic.
2.  **Data Loading**: Uses `library.data_loader` to load the training and test datasets from the pre-generated metadata Parquet files. It samples a small subset (50 rows) for the demo.
3.  **Feature Engineering**: Initializes the `FeaturePipeline` from `library.feature_builder`. It fits vectorizers (TF-IDF) and scalers on the training data and transforms all splits (train, val, test) into a dictionary of feature matrices (lexical, behavioral, semantic, metadata).
4.  **Model Training**: Uses `library.hybrid_engine.HybridTrainer` to train a diverse set of models:
    *   **Volatile Learners** (e.g., `SemanticBooster` using XGBoost): Trained with Early Stopping on K-Folds; all fold models are saved.
    *   **Stable Learners** (e.g., `LexicalBagger` using Random Forest): Trained via CV for Out-of-Fold (OOF) predictions, then a single model is retrained on the full dataset.
    *   **Meta Learner**: A Logistic Regression model trained on the stacked OOF predictions from Level 1 models.
5.  **Inference**: Uses `library.hybrid_engine.HybridPredictor` to generate predictions on the test set. It aggregates predictions from volatile fold models and stable full models, then passes them through the meta-learner.
6.  **Submission**: Formats the final probabilities into the required CSV format and saves it.
7.  **Validation**: Includes assertions to verify data shapes, file existence, and prediction validity.
