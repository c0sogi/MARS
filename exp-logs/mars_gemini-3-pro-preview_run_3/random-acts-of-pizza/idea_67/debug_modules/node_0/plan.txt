The following script demonstrates the complete pipeline execution using the provided library files.

**Implementation Strategy:**
1.  **Configuration Overrides**: We monkey-patch the `Config` class to drastically reduce computational load. We set the number of cross-validation folds to 2, reduce vocabulary sizes, and limit the number of estimators (trees/iterations) for all models to ensure the script completes within seconds rather than hours. We also redirect the working directory to a demo-specific path.
2.  **Data Loading**: We use `load_and_process_data` to load the metadata. To further speed up the demonstration, we slice the resulting DataFrames to a tiny subset (50 training samples, 20 test samples).
3.  **Pipeline Execution**: We instantiate the `DecaViewEnsemble` class. This class encapsulates the entire workflow: feature extraction (text, metadata, embeddings), Level 1 model training (stacking base learners), Level 2 meta-learner training, and final inference.
4.  **Validation**: After execution, we verify that the submission file exists, has the correct dimensions, and contains valid probability predictions.
