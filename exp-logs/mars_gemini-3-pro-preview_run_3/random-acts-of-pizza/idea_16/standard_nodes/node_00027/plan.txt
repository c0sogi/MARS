The solution implements the **Regularized Pent-View Stacking Ensemble** pipeline. It begins by loading the dataset (utilizing caching for efficiency) and initializing the `FeatureExtractor` to generate the four specific feature views: Metadata (Dense), Lexical (Sparse TF-IDF), Behavioral (Sparse TF-IDF), and Semantic (Dense SBERT Embeddings). The `PentViewStackingEnsemble` is then trained using a 5-fold cross-validation strategy to optimize the Level 2 Meta-Learner, followed by a full retraining of the Level 1 Base Learners. The script evaluates the model on the hold-out validation set, performs a failure analysis by correlating prediction errors with input features, and finally generates a submission file if the validation AUC exceeds the specified threshold.
