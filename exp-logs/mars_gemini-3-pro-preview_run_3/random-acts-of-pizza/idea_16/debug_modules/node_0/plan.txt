This script demonstrates the end-to-end pipeline for predicting pizza request success using the provided library. It performs the following steps:
1.  **Data Loading**: Loads the training, validation, and test datasets, then subsamples them to 50 rows to ensure the demonstration runs quickly (under 1 minute).
2.  **Feature Extraction**: Initializes the `FeatureExtractor` to generate Metadata, Lexical (TF-IDF), Behavioral (TF-IDF), and Semantic (SBERT) feature views.
3.  **Model Configuration**: Instantiates the `PentViewStackingEnsemble` and dynamically reduces the number of estimators (trees) and iterations for all base learners to optimize execution speed for this demo.
4.  **Training**: Runs the Level 1 Out-Of-Fold (OOF) training to train the meta-learner, followed by a final retraining of base learners on the full (subsampled) training set.
5.  **Validation**: Includes assertions to verify the shape and range of predictions.
6.  **Prediction & Submission**: Generates predictions for the test set and saves the submission file in the required format.
