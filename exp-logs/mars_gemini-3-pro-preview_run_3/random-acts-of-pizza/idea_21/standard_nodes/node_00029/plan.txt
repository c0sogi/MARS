Implementation Strategy:
1.  **Setup & Initialization**: Import necessary modules from the provided library and standard packages. Set the random seed for reproducibility using `utils.set_seed`.
2.  **Feature Extraction**: Instantiate `FeatureExtractor` and generate feature dictionaries for train, validation, and test splits. Enable caching (`load_cached_data=True`) to optimize runtime.
3.  **Stacking Pipeline - Phase 1 (Training)**: Initialize `StackingTrainer`. Execute `_generate_oof` to create out-of-fold predictions on the training set. Train the Level 2 Meta-Learner using these OOF predictions.
4.  **Validation Evaluation**:
    *   To strictly evaluate the model without leakage, simulate the inference pipeline on the hold-out validation set.
    *   Split the training data (90/10) to create a pseudo-validation set for XGBoost early stopping.
    *   Train clones of all Level 1 base models on the training data (using the pseudo-val set for XGBoost early stopping; full training data for Random Forests/Linear models).
    *   Generate predictions on the hold-out validation set using these models.
    *   Feed these predictions to the trained Meta-Learner to get final ensemble probabilities.
    *   Calculate and print the `Final Validation Metric` (ROC AUC).
5.  **Failure Analysis**:
    *   Calculate absolute errors between validation targets and predictions.
    *   Reconstruct metadata feature names.
    *   Compute correlations between errors and metadata features to identify sources of systematic failure.
    *   Print the top correlated features.
6.  **Submission Generation**:
    *   Compare the Final Validation Metric against the required threshold (0.7085870249842536).
    *   If the threshold is met, execute `trainer._retrain_and_predict_test()`. This method retrains base models on the full available data (Train + Val for RF; Train with Val for ES for XGB) and generates test predictions.
    *   Save the predictions to `submission.csv` using `utils.save_submission`.
