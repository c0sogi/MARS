Implementation Strategy:
1.  **Setup & Configuration**: Initialize random seeds and define paths using the provided library configurations.
2.  **Data Loading**: Load the `train`, `val`, and `test` datasets separately using `library.data_loader.load_datasets`. This ensures a strict hold-out validation set for the final metric calculation.
3.  **Feature Engineering**: Instantiate the `FeaturePipeline`. Fit and transform the training data, then transform the validation and test data. This handles text vectorization (TF-IDF), semantic embeddings (SentenceTransformer), and metadata scaling.
4.  **Fold Generation**: Create 5-fold stratified splits on the training data to support the stacking engine's cross-validation requirement.
5.  **Model Training**: Initialize the `StackingEngine`. Train it using the training data and the generated folds. This process involves training Level 1 base learners (volatile and stable) and the Level 2 meta-learner.
6.  **Validation**: Use the trained engine to generate predictions on the hold-out validation set. Calculate the ROC AUC score.
7.  **Failure Analysis**: Compute the absolute error between predictions and ground truth on the validation set. Calculate and print the Pearson correlation between this error and the dense metadata features to identify sources of difficulty.
8.  **Submission**: Check if the validation AUC exceeds the specified threshold (0.7222984867326668). If successful, generate predictions for the test set and save the `submission.csv` file.
