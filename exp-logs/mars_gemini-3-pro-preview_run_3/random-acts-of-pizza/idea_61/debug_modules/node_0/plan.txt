This script demonstrates the end-to-end execution of the Hept-View Stacking Ensemble for the Random Acts of Pizza task. It performs the following steps:

1.  **Configuration Override**: Monkey-patches the hyperparameter dictionaries in `library.model_factory` to drastically reduce the number of estimators and iterations. This ensures the demonstration runs quickly (within minutes) while exercising the full code path.
2.  **Data Loading**: Uses `library.data_loader` to fetch training and test datasets. It subsets the training data to 100 samples to further optimize speed.
3.  **Feature Engineering**: Instantiates `library.features.FeaturePipeline` to generate Lexical, Behavioral, Semantic, and Metadata feature matrices. It disables caching to demonstrate the actual processing logic.
4.  **Model Training**: Sets up a 2-fold cross-validation scheme and utilizes `library.engine.StackingEngine` to train the ensemble. This involves training volatile models (with early stopping), stable models, and the Level 2 meta-learner.
5.  **Inference**: Generates predictions on the test set using the trained engine.
6.  **Submission & Verification**: Saves the predictions to `submission.csv` and performs assertion checks to validate the output format and data integrity.
