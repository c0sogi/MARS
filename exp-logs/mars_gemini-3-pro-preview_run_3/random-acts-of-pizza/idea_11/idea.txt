Based on the comprehensive empirical analysis and the specific architectural trade-offs identified in the "Lessons" (particularly the efficacy of "Bag-of-Concepts" for behavior in Lesson 00018 and the superiority of Boosting for dense features in Lesson 00005), I propose a **Tri-View Topology-Matched Stacking Ensemble with Dual-Representation Profiling**.

This solution structurally evolves the previous "Topology-Aware" approach by introducing a **Dual-Representation** strategy for the user's behavioral history. We will model subreddits *both* as a sparse "Bag-of-Concepts" (to capture specific niche communities via Random Forest) and as a dense "Latent Persona" (to capture broad interest clusters via XGBoost), thereby maximizing signal extraction across different algorithmic topologies.

# Model

The architecture is a **Stacking Ensemble** composed of three "Level 1" base learners, each explicitly matched to the data topology (Sparse vs. Dense) of its input view, feeding into a "Level 2" meta-learner.

**Level 1: Base Learners (Topology-Matched)**
1.  **Lexical Bagger (Sparse Text View):** A **Random Forest Classifier** trained on **TF-IDF** vectors of the request text concatenated with **User Metadata**.
    *   *Rationale:* Random Forests on sparse TF-IDF features consistently outperform dense embeddings for capturing specific high-impact keywords (e.g., "paycheck", "rent") (Cite solution_lesson_node_00013, Cite solution_lesson_node_00005).
2.  **Behavioral Bagger (Sparse History View):** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with **User Metadata**.
    *   *Rationale:* Treating subreddits as a sparse "Bag-of-Concepts" document proved highly effective (Cite solution_lesson_node_00018). We retain the Random Forest here as it excels at handling this high-dimensional sparse data without overfitting.
3.  **Contextual Booster (Dense Unified View):** An **XGBoost Classifier** trained on a unified dense feature set: **Frozen SBERT Embeddings** (Text) + **Latent Subreddit Components (SVD)** (History) + **Text Complexity Features** + **User Metadata**.
    *   *Innovation:* This branch consolidates all *dense* signals into a single Boosting model.
        *   It reintegrates the **XGBoost** estimator for dense data, addressing the performance drop observed when using RFs for embeddings (Cite solution_lesson_node_00018).
        *   It introduces **Subreddit SVD** (Latent Semantic Analysis) to capture broad "User Personas" (e.g., "Gamer", "Financial") that interact non-linearly with the semantic tone of the request.
        *   It includes explicit **Text Complexity** features (Sentiment, Length) to capture "effort" signals.

**Level 2: Meta-Learner**
*   **Stacking Classifier:** A **Logistic Regression** model that combines the probability outputs of the three base learners.
    *   *Rationale:* Stacking with a linear meta-learner effectively calibrates the ensemble, dynamically balancing the strong Lexical signal with the subtle Semantic/Behavioral signals (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and explicit feature allow-listing.

1.  **Leakage Prevention:**
    *   Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Rigorously exclude all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Lexical View (Sparse):** Generate a **TF-IDF Matrix** (Unigrams/Bigrams, Top 3,000) from the request text.
    *   **Behavioral View (Sparse & Dense):**
        *   **Robust Serialization:** Use duck typing to handle `requester_subreddits_at_request` (Cite solution_lesson_node_00017).
        *   **Sparse:** Flatten list to string -> TF-IDF (Unigrams, Top 1,000).
        *   **Dense:** Apply **Truncated SVD** (e.g., 20 components) to the Subreddit TF-IDF matrix to extract latent persona vectors.
    *   **Semantic View (Dense):** Extract **Frozen SBERT Embeddings** (384-dim). Do not fine-tune (Cite solution_lesson_node_00015).
    *   **Metadata (Dense):**
        *   Include standard user statistics.
        *   Generate and **allow-list** (Cite solution_lesson_node_00007) **Text Complexity Features**: Word Count, Sentence Count, Sentiment Polarity, and Subjectivity.
3.  **Preprocessing:**
    *   **Imputation:** Median imputation for numerical columns.
    *   **Scaling:** Apply `StandardScaler` to the dense inputs of the **Contextual Booster** (XGBoost) and the **Level 2 Meta-Learner**.

# Training

The training procedure utilizes **5-Fold Cross-Validation Stacking**:

1.  **Fold Generation:** Split the training data into 5 stratified folds.
2.  **Level 1 Training (OOF Generation):**
    *   **Lexical RF & Behavioral RF:** Train on 4 folds, predict on the 5th. Use `class_weight='balanced'`.
    *   **Contextual XGB:** Train on 4 folds, predict on the 5th. Use `scale_pos_weight` to handle class imbalance and early stopping based on validation loss.
3.  **Level 2 Training:** Train the Logistic Regression meta-learner on the matrix of Out-Of-Fold (OOF) predictions from all three branches.
4.  **Final Retraining:** Retrain all Level 1 models on the full training dataset. Retrain the Level 2 model on the full OOF matrix.

# Evaluation

For the test set:
1.  Process the test data to generate the three feature views (Lexical TF-IDF, Behavioral TF-IDF, and the Unified Dense Vector) using the transformers fitted on the training set.
2.  Pass each view to its specific Level 1 model to obtain probability scores.
3.  Feed the three probability scores into the Level 2 Meta-Learner.
4.  The output is the final predicted probability for `requester_received_pizza`.
