The following script demonstrates the end-to-end usage of the provided machine learning library for the pizza request prediction task.

**Implementation Strategy:**
1.  **Configuration Override**: We first modify the global `Config` class to enable `DEBUG` mode (using small data subsets) and reduce model complexity (fewer trees, smaller dimensions, fewer folds). This ensures the demonstration runs quickly (seconds/minutes) rather than hours.
2.  **Feature Engineering**: We instantiate the `FeaturePipeline` to process the raw metadata into multi-modal features (Lexical, Behavioral, Semantic, Manifold, Metadata). We verify the structure and shapes of the generated data dictionaries.
3.  **Model Training**: We initialize the `HexEnsemble` and execute the `fit` method. This triggers the validation-guided retraining protocol: generating Out-of-Fold (OOF) predictions, training the Meta-Learner, and retraining base learners on the full dataset.
4.  **Inference & Submission**: We generate predictions on the test set using the trained ensemble and create a submission CSV file. We validate the output file's existence and format.
5.  **Verification**: Throughout the script, assertions are used to validate data integrity, shape consistency, and logical correctness.
