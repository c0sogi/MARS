Implementation Strategy:
1.  **Configuration Override**: Modify the `Config` class attributes to point to a temporary working directory (`./working/demo`) and reduce model complexity (fewer trees, smaller max features, limited folds) to ensure rapid execution.
2.  **Data Subsampling**: Load the raw datasets using `load_dataset`, then create small subsets (e.g., 50 samples) of training, validation, and test data. Save these subsets as processed parquet files in the temporary working directory. This tricks the pipeline into using this small dataset for the subsequent heavy feature engineering (SBERT embeddings), saving significant time.
3.  **Feature Generation**: Manually invoke `get_features` with the subsampled data. This generates and caches the feature matrices (Lexical, Behavioral, Semantic) in the temporary directory.
4.  **Model Unit Testing**: Instantiate and test each model class (`SparseBagger`, `DenseBooster`, `StackingMetaLearner`) individually using synthetic random data to verify their `fit` and `predict_proba` methods work correctly and return expected shapes/values.
5.  **Pipeline Integration (Training)**: Execute `train_ensemble` with `load_cached_data=True`. It will detect the cached subsampled data and features, training the full stacking ensemble quickly on the small dataset.
6.  **Pipeline Integration (Prediction)**: Execute `generate_predictions` to verify the end-to-end inference flow and check if the submission file is generated correctly.
7.  **Validation**: Throughout the script, use `assert` statements to verify data shapes, file existence, and prediction probability ranges.
