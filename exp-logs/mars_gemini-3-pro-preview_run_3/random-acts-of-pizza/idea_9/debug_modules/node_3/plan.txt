The issue is caused by passing the `early_stopping_rounds` parameter to the `fit` method of `XGBClassifier`, which is no longer supported in `xgboost==3.0.5`. In newer versions of XGBoost, this parameter must be passed to the class constructor (`__init__`) instead. The current implementation explicitly removes it from the constructor parameters and injects it into `fit`, causing the `TypeError`.

To fix this, I will modify `library/models.py` to:
1.  Stop removing `early_stopping_rounds` from `self.params` in `DenseBooster.__init__`, allowing it to be passed directly to the `XGBClassifier` constructor.
2.  Remove the logic in `DenseBooster.fit` that injects `early_stopping_rounds` into `fit_params`. The `eval_set` logic remains, as the constructor-configured early stopping will automatically trigger when `eval_set` is provided.
