The issue is caused by passing a `PIL.Image` directly to `transforms.Normalize`, which expects a `torch.Tensor`. In the `extract_features` method, the transformation pipeline only includes normalization, missing the crucial step of converting the image to a tensor first. To fix this, I will use `transforms.Compose` to chain `transforms.ToTensor()` (which converts the PIL image to a Tensor) before `transforms.Normalize()`. This ensures the input to the normalization layer is the correct type, resolving the `TypeError`.
