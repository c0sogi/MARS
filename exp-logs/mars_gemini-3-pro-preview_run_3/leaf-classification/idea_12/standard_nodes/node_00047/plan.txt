The implementation strategy follows the "Cross-Validated Manifold-Expanded Linear Discriminant Ensemble" design. 

1.  **Setup & Data Loading**: We initialize the `LeafDataManager` and `FeatureExtractor`. The manager handles the loading of cached features (or computation via GPU-accelerated backbones if needed) and prepares the data.
2.  **Cross-Validation Loop**: We iterate through 10 folds. For each fold:
    *   **Data Topology**: We retrieve training data in "Expanded" mode (4 views per image) and validation data in "Centroid" mode (average of views).
    *   **Modeling**: We construct a Scikit-Learn pipeline (`ColumnTransformer` -> `PCA` -> `LDA`) and fit it on the expanded training set.
    *   **Inference**: We predict on the centroid validation set (for scoring) and the centroid test set (for submission).
    *   **Accumulation**: We store validation predictions for global metric calculation and accumulate test predictions for ensemble averaging.
3.  **Evaluation**: We compute the multi-class log loss on the concatenated out-of-fold predictions and print the `Final Validation Metric`.
4.  **Failure Analysis**: We calculate the per-sample log loss and compute its Pearson correlation with the 192 tabular features to identify which input signals correlate most with model error.
5.  **Submission**: We average the test probabilities across all 10 folds, apply clipping to avoid log-loss extremes, and save the result to `submission.csv`.
