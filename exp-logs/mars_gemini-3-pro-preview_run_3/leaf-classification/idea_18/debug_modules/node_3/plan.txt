With a small debug sample size of 6 drawn from 99 classes, the subset contains classes with only 1 sample, causing the `ValueError`.

Instead of taking the first N rows, the new logic will group the data by species and select pairs of samples to ensure that every class included in the debug subset has at least 2 instances (Cite debug_lesson_12).
