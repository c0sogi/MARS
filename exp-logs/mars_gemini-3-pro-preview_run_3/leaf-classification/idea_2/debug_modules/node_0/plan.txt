This script demonstrates the end-to-end execution of the provided leaf classification pipeline. It enables debug mode to process a small subset of data for speed, ensuring the demonstration completes quickly. It loads tabular and image data, aligns them, extracts deep features using ResNet50, reduces dimensionality via PCA, trains a hybrid ensemble (Logistic Regression + LDA), and generates a submission file. Assertions are included to verify data alignment and output integrity.
