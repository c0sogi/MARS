# Proposed Solution: Multi-Resolution Dual-Stream Feature Pyramid with Cross-Validated LDA Ensemble

## Model
The proposed architecture is a **Multi-Resolution Dual-Stream Feature Pyramid** coupled with a **Cross-Validated Linear Discriminant Analysis (LDA) Ensemble**. This design structurally evolves the previous "Dual-Backbone" approach by introducing multi-scale processing to explicitly capture both global geometry and fine-grained margin serrations, while replacing the failed Bagging strategy with a Cross-Validation ensemble to maximize data utilization without sample starvation.

1.  **Multi-Resolution Feature Extraction**:
    *   **Global Geometry Stream (Low Res)**: We will utilize **DINOv2 (ViT-Large)** with standard input resolution (e.g., 518x518). As established, DINOv2’s self-supervised training provides superior global shape priors (Cite solution_lesson_node_00021).
    *   **Local Margin Stream (High Res)**: We will employ **ConvNeXt Large** with **High-Resolution Input** (e.g., 1024x1024 or the maximum feasible size). Unlike previous iterations that resized images to standard dimensions (224 or 384), this stream preserves the high-frequency "tail" of the signal found in the binary leaf margins, which is critical for fine-grained separation (Cite solution_lesson_node_00019).
2.  **Dimensionality Reduction**: We will apply **Principal Component Analysis (PCA)** independently to each stream, retaining **99% of the variance**. This high retention threshold ensures that the subtle discriminative details captured by the high-resolution stream are not discarded (Cite solution_lesson_node_00019).
3.  **Tabular Transformation**: The 192 engineered features will be transformed using a **Quantile Transformer (Output distribution = Normal)** to satisfy the normality assumptions of the downstream LDA classifier (Cite solution_lesson_node_00021).
4.  **Classifier**: The classification head will be an **Ensemble of $K$ LDA models** (with Ledoit-Wolf shrinkage) derived from Stratified K-Fold Cross-Validation. This replaces the Bagging approach, which failed due to data starvation in small classes (Cite solution_lesson_node_00028), and the single-split approach, which left valuable data unused.

## Data
1.  **Multi-View Canonical Averaging**: To enforce strict rotation invariance, we will generate 4 canonical rotated views (0°, 90°, 180°, 270°) for every image. We will extract embeddings for all views using both backbones (at their respective resolutions) and compute the **element-wise average** of the raw embeddings before PCA (Cite solution_lesson_node_00017).
2.  **Preprocessing**:
    *   **Stream A**: Resize binary images to 518x518 (RGB replicated).
    *   **Stream B**: Resize binary images to 1024x1024 (RGB replicated).
    *   **Tabular**: Fit the Quantile Transformer within each cross-validation fold to prevent leakage.
3.  **Fusion**: The final feature vector for each sample is the concatenation of the PCA-reduced DINOv2 embeddings, PCA-reduced High-Res ConvNeXt embeddings, and Gaussianized tabular features.

## Training
The training procedure utilizes **Stratified K-Fold Cross-Validation** (e.g., $K=5$ or $K=10$) to build the ensemble:
1.  **Global Feature Extraction**: Pass the multi-view dataset through the frozen DINOv2 and High-Res ConvNeXt backbones once.
2.  **Fold Processing**: For each fold $k$:
    *   **Split**: Partition the data into training (approx. 90%) and validation (approx. 10%) sets. This ensures that even small classes (7 samples) retain ~6 samples for training, avoiding the "data starvation" observed with bootstrapping (Cite solution_lesson_node_00028).
    *   **Fit Transformers**: Fit PCA and Quantile Transformers on the training partition.
    *   **Transform**: Apply transformations to training and validation data.
    *   **Fit Classifier**: Train an **LDA model with Ledoit-Wolf shrinkage** on the transformed training data.
    *   **Store**: Save the fitted pipeline (Transformers + LDA) as member $k$ of the ensemble.

## Evaluation
1.  **Inference**: For each test sample:
    *   Generate multi-view averaged embeddings (at both resolutions) and raw tabular features.
    *   Pass these features through all $K$ saved pipelines. Each pipeline will apply its specific PCA/Quantile projections and LDA prediction.
2.  **Aggregation**: Compute the **arithmetic mean** of the probability vectors from all $K$ models. This averaging reduces the variance associated with any single training split while utilizing 100% of the available training data for the final prediction.
3.  **Formatting**: Apply the required probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the final CSV.
