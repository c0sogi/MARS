Implementation strategy:
1.  **Environment Setup**: Import necessary standard libraries and the provided custom library modules (`config`, `utils`, `execution_engine`, `data_manager`). Set the random seed for reproducibility.
2.  **Training**: Execute `execution_engine.train_ensemble(load_cached_data=True)`. This function orchestrates the entire pipeline: feature extraction (DINOv2 + ConvNeXt), manifold densification (generating 3 orthogonal centroids per image), and training a Stratified K-Fold ensemble of LDA models.
3.  **Validation Assessment**:
    *   Load the hold-out validation dataset (`./metadata/val.csv`) using `data_manager`.
    *   Perform inference using the trained ensemble on this validation set. This involves predicting on all 3 centroids per validation image, aggregating the probabilities, and averaging across the 10 ensemble models.
    *   Compute the Multi-class Log Loss against the true labels and print it as `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the per-sample log loss (negative log-likelihood of the true class).
    *   Compute the Pearson correlation between the per-sample loss and the tabular features to identify which leaf characteristics (shape, margin, texture) are most associated with model error.
    *   Print the top 5 features with the highest absolute correlation.
5.  **Submission**:
    *   Call `execution_engine.predict_submission(load_cached_data=True)` to generate predictions for the test set and save them to `./submission/submission.csv`.
