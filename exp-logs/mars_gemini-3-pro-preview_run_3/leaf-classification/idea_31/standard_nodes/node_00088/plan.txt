The `torch.OutOfMemoryError` is caused by the `LeafFeatureExtractor` expanding each input image into 12 rotated views, effectively multiplying the configured `BATCH_SIZE` by 12 during inference. With `BATCH_SIZE = 32`, the model attempts to process 384 images simultaneously, exceeding the GPU memory capacity. To resolve this, I will reduce the `BATCH_SIZE` in `library/config.py` to 4, resulting in a safe effective batch size of 48 (4 * 12). Cite debug_lesson_13.
