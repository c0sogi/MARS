The `CUDA out of memory` error is caused by the 36x expansion of input images (multi-view generation) combined with a default batch size of 16, resulting in an effective batch size of 576 images. This creates activation maps that exceed the available GPU memory (Cite debug_lesson_7). To fix this, I will reduce the default `batch_size` in `extract_features` from 16 to 2, which reduces the effective batch size to 72, ensuring the memory footprint fits within the GPU's capacity.
