The `'lsqr'` solver is optimized for classification only. To perform dimensionality reduction with shrinkage (regularization), as required by the first stage of the pipeline, the solver must be set to `'eigen'`. I will update the initialization of the `dino_lda`, `conv_lda`, and `tab_lda` components to use `solver='eigen'`.
