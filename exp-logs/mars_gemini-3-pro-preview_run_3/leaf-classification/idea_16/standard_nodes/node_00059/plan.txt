The error `ValueError: n_splits=10 cannot be greater than the number of members in each class` arises because the dataset contains rare classes with only 5 samples, while the cross-validation is configured for 10 folds. Stratified K-Fold requires that the number of splits ($K$) be less than or equal to the minimum number of samples per class ($N_{min}$) to ensure every fold receives at least one sample of each class (Cite debug_lesson_9). To resolve this, I will update `library/config.py` to reduce `N_FOLDS` from 10 to 5, ensuring $K \le N_{min}$.
