This design explicitly addresses the "High Dimension, Low Sample Size" (HDLSS) instability (Lesson 00033) by using supervised dimensionality reduction to compress the feature space before final classification, while leveraging "Hyper-Densification" (Lesson 00053) to maximize statistical robustness.

# Proposed Solution: Hierarchical Discriminant Stacking with Hyper-Densified Orthogonal Centroids

## Model
The architecture is a **Two-Stage Stacked Generalization** of Linear Discriminant Analysis (LDA) classifiers. This design decouples modality-specific class separation from cross-modal fusion, ensuring that the final decision boundary is learned in a highly compact, discriminative feature space.

1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: We will utilize **DINOv2 (ViT-Large)** to capture self-supervised geometric priors (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: We will utilize **ConvNeXt Large** to capture high-frequency margin details (Cite solution_lesson_node_00019).
2.  **Stage 1: Modality-Specific Discriminant Projection**:
    *   Instead of fusing PCA-reduced features directly (which results in a large vector, $P \approx 1600$), we process each stream independently.
    *   **Visual Streams**: Apply **Independent PCA** (99% variance) followed by a **Base LDA Transform** (with Ledoit-Wolf shrinkage). This projects the high-dimensional embeddings onto the $C-1$ (98) most discriminative axes for that specific modality (Cite solution_lesson_node_00052).
    *   **Tabular Stream**: Apply a **Quantile Transformer** (Gaussian output) followed by a **Base LDA Transform**. This aligns the engineered features with the Gaussian assumption (Cite solution_lesson_node_00021) and reduces them to 98 discriminative components.
3.  **Stage 2: Discriminant Fusion**:
    *   The output vectors from the three Base LDAs are concatenated. This creates a compact "super-feature" vector of size $3 \times (C-1) = 294$.
    *   **Meta-Classifier**: A final **Meta-LDA** model (with Ledoit-Wolf shrinkage) is trained on this concatenated vector. By operating in this compressed space ($P=294$) with a densified sample size ($N \approx 6400$), the Meta-LDA achieves a sample-to-feature ratio of $>20:1$, guaranteeing extreme stability compared to the previous ratio of $\approx 4:1$ (Cite solution_lesson_node_00033).

## Data
We employ **Hyper-Densification via Orthogonal View-Set Averaging** to strictly enforce variance alignment between training and inference while maximizing the sample size for the Base and Meta learners.

1.  **Multi-View Extraction**: For every image (Train and Test), we extract features for **36 equidistant rotations** (0°, 10°, ..., 350°).
2.  **Training Topology (Hyper-Densification)**: For the training set, we generate **9 distinct "Orthogonal Centroids"** per image by averaging mutually exclusive sets of 4 orthogonal views (e.g., Centroid 1: {0°, 90°, ...}, Centroid 2: {10°, 100°, ...}).
    *   This increases the effective training size to **$9N$** (approx. 6,400 samples). Crucially, each centroid has the exact same variance profile ($\sigma^2/4$) as the inference samples, satisfying the "Train on the Aggregation" principle (Cite solution_lesson_node_00049, solution_lesson_node_00053).
3.  **Inference Topology**: For validation and test sets, we generate a **single canonical centroid** per image (Average of {0°, 90°, 180°, 270°}).

## Training
We utilize **Stratified K-Fold Cross-Validation (K=10)** to construct a robust ensemble.

1.  **Feature Caching**: Execute the 36-view extraction pipeline once for the entire dataset using the GPU (Cite solution_lesson_node_00011).
2.  **Ensemble Construction**:
    *   For each fold $k$:
        *   **Expand**: Construct the **Hyper-Densified Training Set** ($9 \times$ samples) from the training IDs.
        *   **Fit Stage 1**: Fit the Independent PCAs, Quantile Transformer, and the three **Base LDA** models on the densified training set.
        *   **Transform**: Pass the densified training set through the Base LDAs to generate the 294-dimensional discriminant features.
        *   **Fit Stage 2**: Train the **Meta-LDA** on these discriminant features.
        *   **Store**: Save the entire pipeline (Transformers + Base LDAs + Meta LDA) as member $k$.

## Evaluation
1.  **Inference**: For each test image:
    *   Generate the canonical centroid (Average of 0°, 90°, 180°, 270°) for DINOv2 and ConvNeXt.
    *   Pass these centroids and tabular features through all 10 saved ensemble pipelines.
    *   Each pipeline projects the data through its specific PCAs and Base LDAs, concatenates the outputs, and predicts probabilities using its Meta-LDA.
2.  **Aggregation**: Compute the **arithmetic mean** of the probability vectors from all 10 models. This averaging smooths out residual variance while utilizing 100% of the training data (Cite solution_lesson_node_00028).
3.  **Formatting**: Apply probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the submission CSV.
