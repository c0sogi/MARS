# Proposed Solution: Convex-Densified Selective-Topology Linear Discriminant Analysis

## Model
The architecture employs a **Dual-Stream Early Fusion** design driven by a **Linear Discriminant Analysis (LDA)** classifier. The design is optimized to preserve the natural linear separability of deep features while enforcing strict statistical compliance for tabular data.

1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: We will utilize **DINOv2 (ViT-Large)** to capture self-supervised geometric priors (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: We will utilize **ConvNeXt Large** to capture high-frequency margin details (Cite solution_lesson_node_00019).
2.  **Independent Subspace Reduction (Linear)**: We will apply **Principal Component Analysis (PCA)** to each visual stream *independently*, retaining **99% of the variance** for each.
    *   *Crucial Correction*: We will **NOT** apply Quantile Transformation to these PCA-reduced embeddings. Deep feature manifolds are naturally linearly separable; forcing them into a Gaussian distribution destroys this geometry (Cite solution_lesson_node_00071). We strictly preserve the linear topology of the visual streams (Cite solution_lesson_node_00052).
3.  **Tabular Gaussianization (Non-Linear)**: We will apply a **Quantile Transformer (Output distribution = Normal)** *exclusively* to the 192 engineered tabular features. This aligns the arbitrary distributions of the handcrafted histograms with the Gaussian assumption of the LDA classifier (Cite solution_lesson_node_00071).
4.  **Early Fusion & Global Alignment**: The Linear PCA-reduced visual embeddings and the Non-Linear Gaussianized tabular features are concatenated. We then apply a **Global StandardScaler** to the fused vector. This ensures that the **Ledoit-Wolf shrinkage** (which targets a structured covariance matrix) applies regularization uniformly across the heterogeneous modalities (Cite solution_lesson_node_00039).
5.  **Classifier**: A single **Linear Discriminant Analysis (LDA)** model with **Ledoit-Wolf shrinkage**. We rely on this stable classifier to dominate the few-shot regime (Cite solution_lesson_node_00021).

## Data
We introduce **Convex-Interpolated Manifold Densification**. This topology extends the "Orthogonal View-Set" concept by explicitly filling the linear space between rotational centroids, providing the LDA classifier with a dense, convex hull of training samples.

1.  **Multi-View Extraction**: For every image (Train and Test), we extract features for **12 equidistant rotations** (0°, 30°, ..., 330°). This balances coverage with separability (Cite solution_lesson_node_00065, solution_lesson_node_00074).
2.  **Orthogonal Centroid Generation**: We generate **3 Primary Centroids** per image by averaging mutually exclusive sets of 4 orthogonal views:
    *   $C_1$: Average of {0°, 90°, 180°, 270°}
    *   $C_2$: Average of {30°, 120°, 210°, 300°}
    *   $C_3$: Average of {60°, 150°, 240°, 330°}
3.  **Convex Interpolation (Innovation)**: We generate **3 Secondary Centroids** by linearly interpolating between the primary centroids (MixUp in feature space):
    *   $C_{12} = 0.5 C_1 + 0.5 C_2$
    *   $C_{23} = 0.5 C_2 + 0.5 C_3$
    *   $C_{31} = 0.5 C_3 + 0.5 C_1$
    *   *Impact*: This expands the effective training set to **$6N$** (approx. 4,200 samples). By populating the linear volume between rotations, we explicitly teach the LDA that the space *between* views belongs to the class, enforcing a robust, rotation-invariant decision boundary (Cite solution_lesson_node_00053).

## Training
We utilize **Stratified K-Fold Cross-Validation (K=10)** to construct an ensemble, ensuring robustness against "lucky split" variance (Cite solution_lesson_node_00033).

1.  **Feature Caching**: Execute the 12-view extraction pipeline once for the entire dataset using the GPU (Cite solution_lesson_node_00011).
2.  **Ensemble Construction**:
    *   Split unique image IDs into 10 stratified folds.
    *   For each fold $k$:
        *   **Expand**: Construct the **Convex-Densified Training Set** ($6 \times$ samples) from the training IDs.
        *   **Fit Transformers**: Fit Independent PCAs, Quantile Transformer, and Global StandardScaler on this densified set.
        *   **Train Classifier**: Train the LDA model (Ledoit-Wolf) on the transformed densified set.
        *   **Store**: Save the pipeline as member $k$.

## Evaluation
1.  **Full-Manifold Test-Time Aggregation**: For each test image, we generate **all 6 Centroids** (3 Primary + 3 Secondary).
    *   Pass all 6 centroids through the saved ensemble pipelines.
    *   This adheres to the "Train on the Aggregation" principle (Cite solution_lesson_node_00049), ensuring the test distribution matches the dense convex hull seen during training.
2.  **Aggregation**:
    *   Compute the average probability vector across the 6 centroids for each model.
    *   Compute the average probability vector across the 10 K-Fold models (Cite solution_lesson_node_00028).
