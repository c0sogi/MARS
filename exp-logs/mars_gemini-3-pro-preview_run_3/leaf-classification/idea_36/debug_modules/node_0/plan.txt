The following script demonstrates the end-to-end execution of the provided machine learning pipeline. It covers configuration, feature extraction, manifold densification, ensemble training, and inference.

To ensure the demonstration runs quickly and reliably:
1.  **Configuration**: We subclass the provided `Config` to override defaults, setting a small dataset limit (12 samples) and reducing the number of folds to 2.
2.  **Data Mocking**: After feature extraction, we synthetically overwrite the target labels to `[0, 1, 0, 1, ...]` to guarantee that `StratifiedKFold` has sufficient samples per class even with a tiny dataset.
3.  **Verification**: Assertions are placed after each major step to verify output shapes, data types, and file generation.
