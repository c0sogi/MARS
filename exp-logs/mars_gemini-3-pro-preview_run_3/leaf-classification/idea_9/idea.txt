# Proposed Solution: Multi-Stream Modality-Specific LDA Ensemble with Cross-Validated Weight Optimization

## Model
The proposed architecture introduces a structural shift from **Early Fusion** (concatenating all features into a single vector) to **Late Fusion** (ensembling independent modality-specific classifiers). This design directly addresses the "High Dimension, Low Sample Size" (HDLSS) instability observed in previous experiments (Cite solution_lesson_node_00033) by reducing the dimensionality of the covariance matrix estimation for each Linear Discriminant Analysis (LDA) solver.

1.  **Triple-Stream Architecture**:
    *   **Stream A (Global Geometry)**: Utilizes **DINOv2 (ViT-Large)** to capture self-supervised geometric priors and part-whole relationships (Cite solution_lesson_node_00021).
    *   **Stream B (Local Texture)**: Utilizes **ConvNeXt Large** to capture high-frequency margin details and serrations (Cite solution_lesson_node_00019).
    *   **Stream C (Domain Features)**: Utilizes the 192 engineered tabular features (margin, shape, texture) (Cite solution_lesson_node_00001).
2.  **Independent Classifiers**: Instead of a single LDA trained on the concatenated vector $[X_A, X_B, X_C]$, we employ three independent **Linear Discriminant Analysis (LDA) models with Ledoit-Wolf shrinkage**—one for each stream. This ensures that the covariance matrix for each classifier is estimated in a lower-dimensional space ($P_{stream} \ll P_{total}$), improving stability and preventing noise from one modality (e.g., tabular) from corrupting the decision boundaries of another (e.g., DINO).
3.  **Ensemble Aggregation**: The final prediction is a weighted average of the probability vectors from the three streams, where weights are strictly optimized on Out-Of-Fold (OOF) predictions (Cite solution_lesson_node_00013).

## Data
1.  **Multi-View Canonical Averaging**: To enforce rotation invariance, we will generate 4 canonical rotated views (0°, 90°, 180°, 270°) for every image. We will extract embeddings for all views using both DINOv2 and ConvNeXt and compute the **element-wise average** of the raw embeddings *before* any dimensionality reduction. This creates a robust, orientation-invariant centroid for each sample (Cite solution_lesson_node_00017).
2.  **Independent Preprocessing**:
    *   **Visual Streams**: Apply **Principal Component Analysis (PCA)** independently to the averaged DINOv2 and ConvNeXt embeddings, retaining **99% of the variance** to preserve discriminative tail signals (Cite solution_lesson_node_00019).
    *   **Tabular Stream**: Apply a **Quantile Transformer (Output distribution = Normal)** to the 192 engineered features to strictly satisfy the Gaussian assumption of the LDA classifier (Cite solution_lesson_node_00021).
3.  **Cross-Validation Setup**: We will employ **Stratified K-Fold Cross-Validation (K=10)** to generate robust OOF predictions and train the final ensemble members.

## Training
1.  **Feature Extraction**: Execute the multi-view extraction pipeline once for the entire dataset using the GPU to generate the master feature matrices for DINOv2 and ConvNeXt (Cite solution_lesson_node_00011).
2.  **Stream-Specific Training (K-Fold)**:
    *   For each fold $k=1..10$:
        *   Split data into Train and Validation.
        *   Fit PCA and Quantile Transformers on the Train set of the current fold.
        *   Train three independent LDA models (Stream A, B, C) on the transformed Train data.
        *   Generate probability predictions for the Validation set (OOF predictions).
        *   Save the fitted transformers and LDA models for this fold.
3.  **Weight Optimization**:
    *   Concatenate the OOF predictions to form full-dataset probability matrices for each stream: $P_{A, oof}, P_{B, oof}, P_{C, oof}$.
    *   Perform a **Constrained Optimization** (or discrete grid search) to find scalar weights $w_A, w_B, w_C$ (summing to 1) that minimize the **Log Loss** of the combined prediction $P_{combo} = w_A P_{A} + w_B P_{B} + w_C P_{C}$ against the true labels. This prevents ensemble contamination by explicitly down-weighting weaker streams (Cite solution_lesson_node_00013).

## Evaluation
1.  **Inference**: For each test sample:
    *   Generate the multi-view averaged embeddings and raw tabular features.
    *   Pass the features through all $K=10$ saved pipelines for *each* stream.
    *   Compute the average probability vector for each stream across the $K$ folds (e.g., $P_{A, test} = \frac{1}{K} \sum P_{A, k}$). This averaging across folds mitigates the "lucky split" instability (Cite solution_lesson_node_00033) while using all available training data (Cite solution_lesson_node_00028).
2.  **Fusion**: Combine the stream-level averaged probabilities using the optimized weights: $P_{final} = w_A P_{A, test} + w_B P_{B, test} + w_C P_{C, test}$.
3.  **Formatting**: Apply the required probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the submission CSV.
