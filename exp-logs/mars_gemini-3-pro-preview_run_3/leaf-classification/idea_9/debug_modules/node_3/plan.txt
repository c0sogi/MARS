The `ValueError: The number of samples must be more than the number of classes` occurs because the Linear Discriminant Analysis (LDA) algorithm requires the number of samples ($N$) to be strictly greater than the number of classes ($K$) to properly estimate the within-class scatter matrix. The original demo code aggressively subsampled the dataset to exactly 1 sample per species for 5 species ($N=5, K=5$), which violates this statistical constraint ($5 \ngtr 5$).

To fix this, I will modify the subsampling logic in `runfile.py` to ensure $N > K$. I will sort the dataframe by species and select 2 samples for each of the first 5 species, resulting in 10 samples across 5 classes ($10 > 5$). I will also update the downstream assertions to reflect the new sample size of 10.
