To demonstrate the usage of the provided library files for the Leaf Classification task, I have created a self-contained Python script. This script overrides the default configuration to run on a small subset of data (10 samples per split) for speed, ensuring it completes quickly while validating the logic of the entire pipeline.

### Implementation Strategy

1.  **Configuration Override**: I modify `Config.DEBUG_SAMPLE_SIZE` to 10 and set a custom `WORKING_DIR`. This ensures the script runs the full feature extraction and training process on a tiny dataset, verifying functionality without the time cost of the full dataset.
2.  **Feature Extraction**: I instantiate `DualStreamExtractor` and run `extract_features`. I assert that the output shapes match the expected dimensions based on the number of samples and rotations (12 views per image).
3.  **Data Management**: I use `DataManager` to process the raw features into "densified" training data (flattening the 3 orthogonal centroids per image) and structured test data. I verify the resulting array shapes.
4.  **Model Pipeline**: I utilize `create_pipeline` to build the PCA + QuantileTransformer + LDA model. I fit this pipeline on the densified training data and verify that it produces predictions.
5.  **Inference & Submission**: I demonstrate how to perform inference on the structured test data by flattening it, predicting, and then averaging the probabilities across the 3 centroids. Finally, I use `format_submission` to generate a valid CSV and verify its content.
