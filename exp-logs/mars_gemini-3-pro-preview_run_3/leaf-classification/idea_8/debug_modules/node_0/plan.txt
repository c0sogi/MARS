The following script demonstrates the usage of the provided library components. It performs a complete walkthrough of the pipeline: loading data, extracting features (using DINOv2 and ConvNeXt), preprocessing with PCA, training the Random Subspace LDA ensemble, and generating a submission.

To ensure the demonstration runs quickly and does not interfere with existing files, the script overrides the default configuration to use a temporary cache directory and reduces the number of ensemble estimators.
