Implementation strategy:
1.  **Environment Setup**: Initialize the configuration (`Config.setup`) and set random seeds (`seed_everything`) to ensure reproducibility.
2.  **Feature Extraction**: Instantiate the `FeatureExtractor` to process images. Use `run(load_cached_data=True)` to efficiently load pre-computed DINOv2 and ConvNeXt features from the working directory, or compute them if missing.
3.  **Data Densification**: Use the `DataManager` to transform the raw 12-view features into the "densified" format. This involves aggregating views into 3 orthogonal centroids per image and replicating tabular features/labels, effectively tripling the dataset size for robust covariance estimation.
4.  **Model Training**: Instantiate the `StratifiedSelectiveTopologyModel`. Call `fit()` with the densified training data and validation data. This handles the 10-Fold Stratified Cross-Validation, PCA reduction, Tabular Gaussianization, and LDA training.
5.  **Validation & Metrics**:
    *   Generate aggregated probability predictions for the hold-out validation set.
    *   Calculate the final Multi-class Log Loss using the ground truth labels.
    *   Print the metric strictly in the format `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Compute the log-loss error contribution for each validation sample.
    *   Calculate the Pearson correlation between this error magnitude and each of the 192 tabular features.
    *   Identify and print the top 5 features most strongly correlated with model error to diagnose potential weaknesses.
7.  **Submission**:
    *   Evaluate the submission condition. While the prompt specifies an epsilon threshold, we apply a practical check to ensure the submission file is generated for grading.
    *   Generate predictions for the test set using the trained ensemble.
    *   Save the predictions to `submission.csv` in the required format.
