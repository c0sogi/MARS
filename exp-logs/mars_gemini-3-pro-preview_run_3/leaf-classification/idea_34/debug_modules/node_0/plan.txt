This script demonstrates the end-to-end pipeline for the Plant Species Identification task using the provided library classes. It performs the following steps:

1.  **Configuration**: Overrides default configuration settings to run a fast demonstration (limiting samples to 10 and cross-validation folds to 2) and sets up a dedicated working directory.
2.  **Feature Extraction**: Uses `FeatureExtractor` to load images, apply transformations, and extract features using DINOv2 and ConvNeXt models. It verifies the shape of the extracted multi-view features.
3.  **Data Densification**: Uses `DataManager` to transform the raw 12-view features into 3 orthogonal centroids (Manifold Densification) and aligns tabular data. It validates the data expansion logic (3x samples).
4.  **Model Training**: Instantiates `StratifiedSelectiveTopologyModel` to train a 2-fold ensemble of PCA+LDA pipelines on the densified data. It validates the training process and OOF scoring.
5.  **Inference & Submission**: Generates predictions on the training set (acting as a mock test set) and saves the results to a CSV file using the submission utility.
