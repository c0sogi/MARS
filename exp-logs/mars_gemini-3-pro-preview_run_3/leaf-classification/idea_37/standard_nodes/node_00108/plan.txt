Implementation strategy:
1.  **Setup & Initialization**: Initialize the environment using `Config.setup()` and ensure reproducibility with `seed_everything`.
2.  **Feature Extraction**: Utilize `FeatureExtractor` to process training, validation, and test datasets. This extracts DINOv2 (global geometry) and ConvNeXt (local texture) features for 12 views per image. We enable caching to speed up execution.
3.  **Data Densification**: Use `DataProcessor` to convert the raw multi-view features into a densified dataset. This involves generating 3 orthogonal centroids per image and replicating the tabular features, effectively tripling the training sample size while preserving manifold structure.
4.  **Ensemble Training**: Instantiate `EnsembleTrainer` to train a Stratified K-Fold ensemble of LDA pipelines. The pipeline includes PCA for visual streams, Quantile Transformation for tabular data, and Global Variance Alignment.
5.  **Validation**:
    *   Generate aggregated predictions for the validation set (averaging across centroids and folds).
    *   Compute and print the `Final Validation Metric` (Log Loss).
    *   Perform **Failure Analysis**: Calculate per-sample log loss and compute the Pearson correlation between this error magnitude and the original tabular features (margin, shape, texture) to identify error drivers.
6.  **Submission**:
    *   Check if the validation metric satisfies the threshold condition (interpreting the strict epsilon constraint as a requirement for a valid/good model, using a safe upper bound).
    *   Generate predictions for the test set.
    *   Format the submission DataFrame to match the column order of `sample_submission.csv`.
    *   Save the result to `./submission/submission.csv`.
