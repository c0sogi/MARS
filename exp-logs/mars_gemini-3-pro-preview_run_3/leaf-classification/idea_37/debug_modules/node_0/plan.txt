The following script demonstrates the end-to-end usage of the provided library modules (`FeatureExtractor`, `DataProcessor`, `EnsembleTrainer`) to solve the plant species identification task.

**Strategy Outline:**
1.  **Configuration & Setup**: Initialize the environment and override specific `Config` parameters (e.g., `N_FOLDS=2`) to ensure the demonstration runs quickly. Define a `DEMO_LIMIT` to process only a small subset of images (12 samples).
2.  **Feature Extraction**: Instantiate the `FeatureExtractor` to compute DINOv2 (global geometry) and ConvNeXt (local texture) features for the training subset. Validate the output shapes of the multi-view features (12 views per image).
3.  **Data Processing**: Use `DataProcessor` to perform "Orthogonal Manifold Densification". This converts the 12 raw views into 3 orthogonal centroids and replicates the tabular features to match. Validate that the resulting dataset size is exactly $3 \times N$.
4.  **Model Training**: Initialize `EnsembleTrainer` and train the Stratified Selective-Topology pipeline on the densified data. Verify that model artifacts (pipelines and class mappings) are saved correctly.
5.  **Inference & Submission**: Run the inference pipeline on the same subset (simulating test data) to generate probabilities. Aggregate predictions across the 3 centroids per image and format the output into a submission CSV matching the competition requirements.
