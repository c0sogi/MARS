The issue arises because the aggressive subsampling in debug mode (20 samples per fold) causes different folds to observe disjoint sets of classes. Consequently, the trained LDA models in the ensemble output probability matrices with different dimensions and column meanings (e.g., Model 1 knows classes A and B, while Model 2 knows classes B and C). The original code assumes all models share the exact same class list and order, leading to a `RuntimeError` when it attempts to aggregate them.

1.  Load the full list of 99 species from the training metadata to establish a global schema.
2.  Initialize the probability accumulator (`avg_probs`) based on this global schema.
3.  For each model, map its predictions to the correct columns in the global accumulator using the model's `classes_` attribute.
4.  This ensures that even if models are trained on partial data, their predictions are correctly aligned and averaged in the final submission.
