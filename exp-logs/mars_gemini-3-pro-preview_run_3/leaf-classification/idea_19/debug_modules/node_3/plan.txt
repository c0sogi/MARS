The `ValueError: Object arrays cannot be loaded when allow_pickle=False` is caused by attempting to load `classes.npy` (which contains string arrays of species names) using `np.load` with its default security settings. NumPy treats string arrays as object arrays, which requires explicit permission to unpickle. I will modify the `load_numpy` function in `library/utils.py` to set `allow_pickle=True`, enabling the loading of the class names and resolving the crash. Cite debug_lesson_20
