# Proposed Solution: Hyper-Densified Dual-Stream LDA with Full-Manifold Test-Time Aggregation

## Model
The architecture utilizes a **Dual-Stream Early Fusion** design driven by a single **Linear Discriminant Analysis (LDA)** classifier. This design leverages the proven linear separability of the feature space (Cite solution_lesson_node_00019) while enforcing the statistical assumptions required for stable covariance estimation.

1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: We will utilize **DINOv2 (ViT-Large)** to capture self-supervised geometric priors (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: We will utilize **ConvNeXt Large** to capture high-frequency margin details (Cite solution_lesson_node_00019).
2.  **Independent Subspace Reduction**: We will apply **Principal Component Analysis (PCA)** to each visual stream *independently*, retaining **99% of the variance** for each. This ensures that the distinct manifold structures of the ViT and CNN embeddings are preserved without one dominating the other (Cite solution_lesson_node_00052).
3.  **Global Gaussianization**: We will apply a **Quantile Transformer (Output distribution = Normal)** to **ALL** feature streams: the PCA-reduced DINOv2 embeddings, the PCA-reduced ConvNeXt embeddings, and the 192 tabular features. This explicitly warps the feature space to satisfy the Gaussian assumption of the LDA classifier (Cite solution_lesson_node_00021).
4.  **Early Fusion**: The Gaussianized vectors from all streams are concatenated into a single feature vector (Cite solution_lesson_node_00039).
5.  **Classifier**: A single **Linear Discriminant Analysis (LDA)** model with **Ledoit-Wolf shrinkage**. We rely on this stable classifier to dominate the few-shot regime (Cite solution_lesson_node_00009), avoiding the data starvation caused by bagging (Cite solution_lesson_node_00028).

## Data
We employ **Hyper-Densification via Orthogonal View-Set Averaging** to structurally increase the sample size for covariance estimation, and we extend this topology to the test set to maximize inference robustness.

1.  **Multi-View Extraction**: For every image in the dataset (Train and Test), we extract features for **36 equidistant rotations** (0°, 10°, 20°, ..., 350°).
2.  **Manifold Topology (Hyper-Densification)**: We generate **9 distinct "Orthogonal Centroids"** per image by averaging mutually exclusive sets of 4 orthogonal views:
    *   Centroid 1: Average of {0°, 90°, 180°, 270°}
    *   Centroid 2: Average of {10°, 100°, 190°, 280°}
    *   ...
    *   Centroid 9: Average of {80°, 170°, 260°, 350°}
    *   **Impact**: This increases the effective sample size from $N$ to **$9N$** (approx. 6,300 samples). Crucially, each centroid has the exact same variance profile ($\sigma^2/4$) as the others, creating a dense, variance-aligned cloud of valid representations (Cite solution_lesson_node_00053).
3.  **Tabular Augmentation**: The invariant tabular features are replicated for each of the 9 centroids.

## Training
We utilize **Stratified K-Fold Cross-Validation (K=10)** to construct an ensemble, ensuring robustness against "lucky split" variance (Cite solution_lesson_node_00033).

1.  **Feature Caching**: Execute the 36-view extraction pipeline once for the entire dataset using the GPU (Cite solution_lesson_node_00011).
2.  **Ensemble Construction**:
    *   Split the unique image IDs into 10 stratified folds.
    *   For each fold $k$:
        *   **Expand**: Construct the **Hyper-Densified Training Set** ($9 \times$ samples) from the training IDs.
        *   **Fit Transformers**: Fit the Independent PCAs and the Global Quantile Transformer on this densified training set.
        *   **Train Classifier**: Train the LDA model (Ledoit-Wolf) on the transformed densified set.
        *   **Store**: Save the pipeline as member $k$ of the ensemble.

## Evaluation
1.  **Full-Manifold Test-Time Aggregation (Innovation)**: Instead of inferring on a single canonical centroid (which discards 8/9ths of the test information), we generate **all 9 Orthogonal Centroids** for each test image.
    *   Pass all 9 centroids through the saved ensemble pipelines.
    *   This strictly adheres to the "Train on the Aggregation" principle (Cite solution_lesson_node_00049) while utilizing the full rotational manifold of the test data.
2.  **Aggregation**:
    *   Compute the average probability vector across the 9 centroids for each model.
    *   Compute the average probability vector across the 10 K-Fold models (Cite solution_lesson_node_00028).
3.  **Formatting**: Apply probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the submission CSV.
