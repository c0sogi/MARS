# Proposed Solution: Selective-Topology Orthogonal Manifold-Densified LDA

## Model
The architecture employs a **Dual-Stream Early Fusion** design driven by a **Linear Discriminant Analysis (LDA)** classifier. The structural innovation lies in the **Selective Feature Topology**, which applies distinct geometric transformations to visual and tabular streams to strictly preserve their optimal discriminative properties.

1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: We will utilize **DINOv2 (ViT-Large)** to capture self-supervised geometric priors (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: We will utilize **ConvNeXt Large** to capture high-frequency margin details (Cite solution_lesson_node_00019).
2.  **Independent Subspace Reduction (Linear)**: We will apply **Principal Component Analysis (PCA)** to each visual stream *independently*, retaining **99% of the variance** for each.
    *   *Crucial Correction*: We will **NOT** apply Quantile Transformation to these PCA-reduced embeddings. Deep feature manifolds are naturally linearly separable; forcing them into a Gaussian distribution destroys this geometry (Cite solution_lesson_node_00071). We strictly preserve the linear topology of the visual streams (Cite solution_lesson_node_00052).
3.  **Tabular Gaussianization (Non-Linear)**: We will apply a **Quantile Transformer (Output distribution = Normal)** *exclusively* to the 192 engineered tabular features. This aligns the arbitrary distributions of the handcrafted histograms with the Gaussian assumption of the LDA classifier (Cite solution_lesson_node_00071).
4.  **Early Fusion**: The Linear PCA-reduced visual embeddings and the Non-Linear Gaussianized tabular features are concatenated into a single feature vector. We prefer Early Fusion to leverage cross-modal correlations (Cite solution_lesson_node_00039).
5.  **Classifier**: A single **Linear Discriminant Analysis (LDA)** model with **Ledoit-Wolf shrinkage**. We rely on this stable classifier to dominate the few-shot regime (Cite solution_lesson_node_00009, solution_lesson_node_00021).

## Data
We employ **Orthogonal View-Set Averaging** (Manifold Densification) to structurally increase the sample size for covariance estimation ($N$) without crossing the threshold into manifold complexity.

1.  **Multi-View Extraction**: For every image in the dataset (Train and Test), we extract features for **12 equidistant rotations** (0°, 30°, 60°, ..., 330°). We limit this to 12 views to avoid the separability collapse observed with 36 views (Cite solution_lesson_node_00065) while exceeding the minimal 4 views to combat data starvation (Cite solution_lesson_node_00074).
2.  **Training Topology (Densification)**: We generate **3 distinct "Orthogonal Centroids"** per image by averaging mutually exclusive sets of 4 orthogonal views:
    *   Centroid A: Average of {0°, 90°, 180°, 270°}
    *   Centroid B: Average of {30°, 120°, 210°, 300°}
    *   Centroid C: Average of {60°, 150°, 240°, 330°}
    *   *Impact*: This triples the effective training sample size ($3N$) with high-quality, variance-aligned representations ($\sigma^2/4$). This ensures $N_{eff} > P_{dims}$, allowing the LDA to estimate a robust covariance matrix (Cite solution_lesson_node_00053).
3.  **Tabular Augmentation**: The invariant tabular features are replicated for each of the 3 centroids.

## Training
We utilize **Stratified K-Fold Cross-Validation (K=10)** to construct an ensemble, ensuring robustness against "lucky split" variance (Cite solution_lesson_node_00033).

1.  **Feature Caching**: Execute the 12-view extraction pipeline once for the entire dataset using the GPU (Cite solution_lesson_node_00011).
2.  **Ensemble Construction**:
    *   Split the unique image IDs into 10 stratified folds.
    *   For each fold $k$:
        *   **Expand**: Construct the **Densified Training Set** ($3 \times$ samples) from the training IDs (Union of Centroids A, B, C).
        *   **Fit Transformers**: Fit the Independent PCAs (on visual cols) and Quantile Transformer (on tabular cols) on this densified training set.
        *   **Train Classifier**: Train the LDA model (Ledoit-Wolf) on the transformed densified set.
        *   **Store**: Save the pipeline as member $k$ of the ensemble.

## Evaluation
1.  **Full-Manifold Test-Time Aggregation**: We generate **all 3 Orthogonal Centroids** (A, B, and C) for each test image.
    *   Pass all 3 centroids through the saved ensemble pipelines.
    *   This strictly adheres to the "Train on the Aggregation" principle (Cite solution_lesson_node_00049) while utilizing the full rotational manifold of the test data to smooth out alignment noise.
2.  **Aggregation**:
    *   Compute the average probability vector across the 3 centroids for each model.
    *   Compute the average probability vector across the 10 K-Fold models (Cite solution_lesson_node_00028).
