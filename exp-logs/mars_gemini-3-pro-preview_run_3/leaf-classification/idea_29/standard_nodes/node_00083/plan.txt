The error `ValueError: Object arrays cannot be loaded when allow_pickle=False` occurs because the cached label arrays contain string data (species names), which NumPy serializes as object arrays using the pickle protocol. Recent versions of NumPy default to `allow_pickle=False` for security, preventing these files from being read. To fix this, I will explicitly set `allow_pickle=True` in the `load_numpy` function within `library/utils.py`, as the files are trusted artifacts generated by the script itself.
