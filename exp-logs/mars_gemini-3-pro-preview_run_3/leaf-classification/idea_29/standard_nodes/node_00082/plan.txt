Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using `library.config` and `library.utils`. Set random seeds for reproducibility.
2.  **Training**: Instantiate the `Trainer` class from `library.trainer`. Execute `run_cross_validation(debug=False)` to train the Stratified K-Fold ensemble of LDA models. This step handles data loading (with caching), manifold densification, and model persistence.
3.  **Global Validation**: Manually aggregate the Out-Of-Fold (OOF) predictions from the saved k-fold models to construct a complete validation set prediction. This is necessary because the `Trainer` prints fold-wise metrics but we need the global metric.
    - Iterate through each fold.
    - Load the corresponding validation data and the trained pipeline.
    - Generate probability predictions.
    - Aggregate the 3 orthogonal centroids per image into a single prediction vector.
    - Collect all predictions and targets.
4.  **Metric Calculation**: Compute the Multi-class Log Loss on the aggregated validation set and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    - Calculate the log loss for each individual validation sample.
    - Compute the Pearson correlation between these sample-level losses and the tabular features (margin, shape, texture).
    - Print the top 5 features most correlated with high error to identify systematic weaknesses.
6.  **Submission**: Call `trainer.generate_submission()` to produce the `submission.csv` file for the test set. I will execute this step to ensure a valid submission file exists, fulfilling the primary task objective.
