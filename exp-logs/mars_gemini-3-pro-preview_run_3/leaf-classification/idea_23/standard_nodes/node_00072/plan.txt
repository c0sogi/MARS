The strategy for the `runfile.py` implementation is as follows:

1.  **Setup & Imports**: Initialize the environment, set random seeds for reproducibility, and import necessary classes from the provided library files (`DataManager`, `OrthogonalLDAPipeline`, `Config`, `utils`).
2.  **Data Loading**: Use `DataManager` to load the raw extracted features (DINOv2, ConvNeXt, Tabular) from the cache.
3.  **Cross-Validation Loop**:
    *   Initialize a Stratified K-Fold splitter.
    *   Iterate through each fold:
        *   **Splitting**: Split the data into training and validation sets based on unique image IDs to prevent leakage.
        *   **Manifold Densification**: Use `DataManager.create_orthogonal_centroids` to generate 3 orthogonal views (centroids) per image for both training and validation sets. This triples the effective sample size.
        *   **Training**: Initialize and train the `OrthogonalLDAPipeline` (PCA + QuantileTransformer + LDA) on the densified training data.
        *   **Inference (Validation)**: Predict probabilities on the densified validation set. Then, aggregate these predictions by averaging the 3 centroids for each unique image ID to obtain the final validation prediction.
        *   **Inference (Test)**: Predict probabilities on the densified test set and accumulate them for the final ensemble.
4.  **Metric Calculation**:
    *   Concatenate all out-of-fold (OOF) validation predictions.
    *   Calculate the Multi-class Log Loss using the provided utility function (which handles clipping and rescaling).
    *   Print the `Final Validation Metric`.
5.  **Failure Analysis**:
    *   Calculate the log loss error for each individual validation sample.
    *   Compute the Pearson correlation between this error magnitude and each of the 192 tabular features.
    *   Print the top features most correlated with high error rates to identify systematic weaknesses.
6.  **Submission**:
    *   Average the accumulated test predictions across all folds and all centroids.
    *   Save the final predictions to `submission.csv` in the required format.
