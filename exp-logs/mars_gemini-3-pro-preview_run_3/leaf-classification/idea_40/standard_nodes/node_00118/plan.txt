The `torch.OutOfMemoryError` is caused by the feature extraction pipeline expanding each input image into 12 rotated views, effectively multiplying the configured batch size by 12 ($32 \times 12 = 384$ images), which exceeds the GPU's memory capacity. To fix this, I will reduce the `BATCH_SIZE` in `library/config.py` from 32 to 4. This ensures the effective batch size is $4 \times 12 = 48$, which fits safely within the available VRAM.
