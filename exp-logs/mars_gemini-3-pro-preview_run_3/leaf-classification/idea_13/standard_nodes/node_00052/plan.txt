            labels (np.ndarray): Shape (N,).

        Returns:
            Tuple[np.ndarray, np.ndarray, np.ndarray]:

                - Densified Tabular Features (3N, T)
                - Densified Labels (3N,)

        densified_img_list = []
        densified_tab_list = []
        densified_labels_list = []

    def aggregate_training_data(
