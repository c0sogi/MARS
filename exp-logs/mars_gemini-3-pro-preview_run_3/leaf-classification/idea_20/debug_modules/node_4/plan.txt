The issue is caused by Python's behavior regarding default argument values, which are evaluated only once at function definition time. In `library/utils.py`, the `format_submission` function binds `output_path` to the initial value of `Config.SUBMISSION_PATH` when the module is imported. When `runfile.py` subsequently updates `Config.SUBMISSION_PATH` at runtime to point to the demo directory, the function continues to use the old path, causing the submission to be saved to the wrong location and the verification step to fail.

To fix this, I will modify `format_submission` to set the default value of `output_path` to `None` and resolve the actual path from `Config.SUBMISSION_PATH` inside the function body. This ensures the current runtime value of the configuration is used. Cite debug_lesson_9.
