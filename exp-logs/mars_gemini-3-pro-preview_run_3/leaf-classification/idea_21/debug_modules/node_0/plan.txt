The following code demonstrates the complete pipeline of the Orientation-Specialized Linear Discriminant Experts (OS-LDE) system. 

**Implementation Strategy:**
1.  **Configuration Override**: We override the default `Config` parameters to use a temporary working directory and reduce the number of folds to 2 for speed.
2.  **Data Subsetting**: Instead of processing the full dataset, we create small, balanced subsets of the training and test metadata. This ensures the stratified cross-validation logic functions correctly with minimal runtime.
3.  **Feature Extraction**: We initialize the `FeatureExtractor` to process images from the subsets, generating 12-view embeddings using DINOv2 and ConvNeXt.
4.  **Orthogonal Partitioning**: We use `OrthogonalDataManager` to split the 12 views into three orthogonal sets (A, B, C) and compute their centroids.
5.  **Training**: We run the `OSLDETrainer` to train the ensemble of Linear Discriminant Analysis experts on the processed features.
6.  **Inference**: We execute `predict_test_set` to generate predictions and verify the final submission file's format and integrity.
