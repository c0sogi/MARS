Implementation strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided modules. Override `Config.DEBUG` and `Config.DEBUG_SAMPLES` to ensure the demonstration runs quickly on a small subset of data. Initialize the random seed.
2.  **Vision Components Demo**:
    *   Demonstrate `LeafRotationDataset` by loading a few samples and verifying the output tensor shape (12 views).
    *   Demonstrate `DualStreamExtractor` by initializing the model and running a dummy forward pass to verify the feature dimension (DINOv2 + ConvNeXt).
    *   Demonstrate `extract_rotational_features` to show the full feature extraction pipeline.
3.  **Topology Manager Demo**:
    *   Use `TopologyManager` to generate "densified" training data (3 centroids per image) and "canonical" inference data (1 centroid per image).
    *   Verify the shapes of the resulting feature arrays and label vectors to ensure the data topology is correct.
4.  **Pipeline Demo**:
    *   Instantiate the `LeafSpeciesPipeline`.
    *   Fit the pipeline on the small densified dataset generated in the previous step.
    *   Predict probabilities on the canonical validation set and verify the output shape and value range.
5.  **Engine (Full Workflow) Demo**:
    *   Run `run_cross_validation` in debug mode. This will train models for a few folds on limited data and save them.
    *   Run `generate_submission` in debug mode. This will load the saved models, predict on a subset of test data, and generate a submission file.
    *   Verify the existence and dimensions of the generated submission file.
