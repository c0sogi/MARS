# Proposed Solution: Cross-Validated Manifold-Densified LDA Ensemble with Independent Subspace Reduction

## Model
The architecture utilizes a **Dual-Stream Early Fusion** design driven by **Linear Discriminant Analysis (LDA)**, explicitly correcting the fusion flaw identified in Lesson 00052.

1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: **DINOv2 (ViT-Large)** to capture self-supervised geometric priors (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: **ConvNeXt Large** to capture high-frequency margin details (Cite solution_lesson_node_00019).
2.  **Independent Subspace Reduction**: Unlike previous iterations that fused raw features or applied global PCA, we apply **Principal Component Analysis (PCA)** to *each* visual stream independently, retaining **99% of the variance** for each. This ensures that the distinct manifold structures of the ViT and CNN embeddings are preserved without one dominating the other (Cite solution_lesson_node_00052).
3.  **Tabular Transformation**: The 192 engineered features are transformed using a **Quantile Transformer (Output distribution = Normal)** to strictly satisfy the Gaussian assumption of the downstream classifier (Cite solution_lesson_node_00021).
4.  **Early Fusion**: The PCA-reduced DINOv2 embeddings, PCA-reduced ConvNeXt embeddings, and Gaussianized tabular features are concatenated into a single feature vector (Cite solution_lesson_node_00039).
5.  **Classifier**: A **Linear Discriminant Analysis (LDA)** model with **Ledoit-Wolf shrinkage**. We rely on this single stable classifier per fold, avoiding complex bagging or boosting schemes that cause data starvation (Cite solution_lesson_node_00028).

## Data
We employ **Orthogonal View-Set Augmentation** (Manifold Densification) to structurally increase the sample size for covariance estimation while maintaining strict variance alignment for inference.

1.  **Multi-View Extraction**: For every image (Train and Test), we extract features for **12 equidistant rotations** (0°, 30°, 60°, ..., 330°).
2.  **Training Topology (Densification)**: For the training set, we generate **3 distinct centroids** per image by averaging mutually exclusive sets of 4 orthogonal views:
    *   Sample A: Average of {0°, 90°, 180°, 270°}
    *   Sample B: Average of {30°, 120°, 210°, 300°}
    *   Sample C: Average of {60°, 150°, 240°, 330°}
    *   This triples the effective training size ($N \to 3N$) using high-fidelity, variance-reduced samples, allowing the LDA to estimate a robust covariance matrix (Cite solution_lesson_node_00053).
3.  **Inference Topology**: For validation and test sets, we generate a **single canonical centroid** per image (Sample A: Average of {0°, 90°, 180°, 270°}). This ensures the model is evaluated on the exact variance profile it was trained on (Cite solution_lesson_node_00049).

## Training
We utilize **Stratified K-Fold Cross-Validation (K=10)** to construct an ensemble, mitigating the "lucky split" instability observed in single-split experiments (Cite solution_lesson_node_00033).

1.  **Feature Caching**: Execute the 12-view extraction pipeline once for the entire dataset using the GPU (Cite solution_lesson_node_00011).
2.  **Ensemble Construction**:
    *   Split the unique image IDs into 10 stratified folds.
    *   For each fold $k$:
        *   **Expand**: Construct the **Densified Training Set** ($3 \times$ samples) from the training IDs. Keep the Validation IDs as single canonical centroids.
        *   **Fit Transformers**: Fit the Independent PCAs and Quantile Transformer on the Densified Training Set.
        *   **Train Classifier**: Train the LDA model (Ledoit-Wolf) on the transformed Densified Training Set.
        *   **Store**: Save the pipeline (Transformers + LDA) as member $k$ of the ensemble.

## Evaluation
1.  **Inference**: For each test image:
    *   Generate the canonical centroid (Average of 0°, 90°, 180°, 270°) for both DINOv2 and ConvNeXt streams.
    *   Pass these centroids and the raw tabular features through all 10 saved ensemble pipelines.
    *   Each pipeline applies its specific Independent PCA projections, Quantile transformation, and LDA prediction.
2.  **Aggregation**: Compute the **arithmetic mean** of the probability vectors from all 10 models. This averaging smooths out decision boundary noise while utilizing 100% of the available training data (Cite solution_lesson_node_00028).
3.  **Formatting**: Apply probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the submission CSV.
