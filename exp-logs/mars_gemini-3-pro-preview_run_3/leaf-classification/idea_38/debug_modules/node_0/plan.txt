This script demonstrates the end-to-end usage of the Leaf Classification pipeline. It performs the following steps:

1.  **Configuration Setup**: It creates a dedicated working directory and generates small, valid subsets of the training and test metadata to ensure the demonstration runs quickly (under 5 minutes) and satisfies the class-balance requirements of Stratified K-Fold cross-validation. It updates the global `Config` object to point to these new files and directories.
2.  **Feature Extraction**: It utilizes `extract_dataset` to extract visual (DINOv2 + ConvNeXt) and tabular features from the images defined in our custom subset. It asserts that the output shapes match the expected dimensions (12 views for images, 192 features for tabular).
3.  **Densification**: It demonstrates `prepare_training_data` (Convex Hull augmentation, 6x expansion) and `prepare_inference_data` (Canonical Centroids, 3x expansion). It verifies the data expansion logic through assertions.
4.  **Modeling**: It instantiates the `Selective-Topology LDA` pipeline using `build_pipeline`, fits it on the densified training data, and verifies that it can make predictions.
5.  **Training Workflow**: It executes the full `run_training` loop, which handles cross-validation, model training, and evaluation. It checks that the models are successfully saved to disk.
6.  **Inference Workflow**: It generates a submission file using `generate_submission`, aggregating predictions from the trained models, and verifies the output format.
