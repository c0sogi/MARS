The `numpy.exceptions.AxisError` is caused by the manual demonstration section in `runfile.py` creating a debug dataset with only one species (2 samples of the same class). This results in the `LinearDiscriminantAnalysis` model training on a single class, producing a degenerate 1D decision output that fails when `predict_proba` attempts to apply `softmax` along axis 1 (which requires a 2D array). To fix this, I will modify the debug subset selection to include two samples from each of the top two species, ensuring a valid multi-class classification task (Cite debug_lesson_12). Additionally, I will update the assertions to dynamically verify the output shape based on the number of classes in the subset, rather than enforcing the full 99-class schema.
