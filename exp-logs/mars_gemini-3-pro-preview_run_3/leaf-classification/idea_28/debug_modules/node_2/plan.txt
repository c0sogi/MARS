The issue is caused by Python's behavior regarding default argument evaluation: the `save_submission` function binds its `filename` default argument to `Config.SUBMISSION_PATH` at import time. When `runfile.py` subsequently updates `Config.SUBMISSION_PATH` to a temporary demo directory at runtime, the function call in `library/modeling.py` (which uses the default argument) continues to use the stale, original path, causing the file to be saved to the wrong location while the verification logic checks the new location. To fix this, I will update the `save_submission` call in `library/modeling.py` to explicitly pass `filename=Config.SUBMISSION_PATH`, ensuring the function uses the current runtime value of the configuration variable.
