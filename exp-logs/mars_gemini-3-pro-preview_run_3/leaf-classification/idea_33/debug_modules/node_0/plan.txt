This script demonstrates the end-to-end usage of the provided library components to solve the leaf classification task. It overrides the configuration to run in `DEBUG` mode with a small subset of data for rapid execution. The workflow includes feature extraction (DINOv2 + ConvNeXt), manifold densification (generating orthogonal centroids), pipeline construction (PCA + QuantileTransformer + LDA), training, validation, and submission generation. It includes assertions to verify data shapes and logic at each step.
