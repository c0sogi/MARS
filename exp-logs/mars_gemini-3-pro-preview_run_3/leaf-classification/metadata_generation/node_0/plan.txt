The implementation strategy involves the following steps:
1.  **Setup**: Define input and output directories (`./input`, `./metadata`) and configuration constants (random state 42, 20% validation split).
2.  **Data Loading**: Read the `train.csv` and `test.csv` files from the input directory.
3.  **Feature Engineering**: Construct relative file paths for the images (e.g., `images/{id}.jpg`) and append them as a new column to the dataframes.
4.  **Splitting**: Perform a stratified shuffle split on the training data using the `species` column to ensure the validation set (20%) maintains the same class distribution as the training set.
5.  **Output Generation**: Save the split training, validation, and original test datasets to the metadata directory as CSV files.
6.  **Verification**:
    -   **Stats**: Reload the generated metadata and print summary statistics.
    -   **File Existence**: Randomly sample 1000 paths from each dataset and verify they exist in the input directory. Raise an error if the missing ratio exceeds 0.5.
    -   **Stratification**: Compare the class probability distributions of the training and validation sets. Raise an assertion error if the maximum difference in class proportions exceeds a reasonable threshold (0.05), ensuring the split was representative.
