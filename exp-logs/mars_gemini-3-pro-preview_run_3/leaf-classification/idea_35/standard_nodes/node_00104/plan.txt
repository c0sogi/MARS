The `torch.OutOfMemoryError` occurs because the feature extraction pipeline expands each single image into 12 rotated views, inflating the effective batch size passed to the model by a factor of 12. With `BATCH_SIZE = 32`, the model attempts to process $32 \times 12 = 384$ images simultaneously, which exceeds the available GPU memory. I will reduce the `BATCH_SIZE` to 4 to ensure the effective batch size is 48 ($4 \times 12$), fitting comfortably within memory limits. This fix directly applies the lesson of accounting for input expansion factors when sizing batches (Cite debug_lesson_13).
