Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class and set random seeds for reproducibility. Create necessary directories for output.
2.  **Data Processing**: Instantiate the `LeafDataProcessor`. This class handles the loading of cached features (or extraction if needed via `FeatureExtractor`) and performs the "Hyper-Densification" of training data (generating 9 orthogonal centroids per image) and canonical centroid generation for validation/test sets.
3.  **Cross-Validation Loop**: Iterate through the 10 folds defined in the configuration.
    *   Retrieve pre-processed fold data (densified training, canonical val/test).
    *   Train the `StackedEnsemble` model. This model internally performs 5-fold inner CV to generate OOF logits for the Meta-LDA, ensuring robust fusion weights.
    *   Perform inference on the validation set and store predictions for global metric calculation.
    *   Perform inference on the test set and accumulate probabilities for the final ensemble averaging.
4.  **Global Evaluation**: Concatenate validation predictions from all folds and calculate the Multi-class Log Loss. Print the metric in the strictly required format.
5.  **Failure Analysis**: Calculate the log loss per validation sample. Compute the Pearson correlation between this error magnitude and each of the 192 input features. Print the top 5 features most correlated with model error to identify weaknesses.
6.  **Submission**: Average the accumulated test probabilities across all folds. Format the DataFrame with the correct image IDs and class columns. Save the file to `./submission/submission.csv` as required.
