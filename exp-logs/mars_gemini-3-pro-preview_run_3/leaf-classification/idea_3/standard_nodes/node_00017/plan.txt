Implementation Strategy:
1.  **Initialization**: Set up the environment using `Config` and ensure reproducibility with `seed_everything`.
2.  **Feature Extraction**: Instantiate `FeatureExtractor` and run it with `load_cached_data=True`. This will load (or compute if missing) the augmentation-averaged embeddings (ResNet50 + ViT) and tabular features for train, validation, and test sets.
3.  **Preprocessing & Fusion**: Instantiate `FusionPipeline`. Fit it on the training data to learn scaling parameters (for tabular data) and PCA components (for image embeddings). Transform all datasets into fused feature vectors.
4.  **Model Training**: Train the `EnsembleClassifier` (Logistic Regression + LDA) on the fused training data.
5.  **Validation**: Optimize the ensemble mixing weight on the validation set. Compute the final Multi-class Log Loss.
6.  **Failure Analysis**: Calculate the log loss contribution for each validation sample. Compute and print the correlation between these error magnitudes and the original tabular features to identify systematic weaknesses.
7.  **Submission Logic**: Compare the final validation metric against the strict threshold (`3.715704343830924e-12`). If the metric is lower than the threshold, generate predictions for the test set, format them according to `sample_submission.csv`, and save the file. Otherwise, skip submission generation as per instructions.
