The implementation strategy involves creating a single, self-contained Python script that utilizes the provided library modules to execute an end-to-end leaf classification pipeline. The script is designed to run quickly by overriding configuration parameters to use a small debug subset of the data (20 samples).

The workflow proceeds as follows:
1.  **Setup**: Initialize the environment, set random seeds for reproducibility, and configure a custom working directory.
2.  **Data Loading**: Load the training, validation, and test datasets using `load_data` with the debug flag enabled. Assertions verify the data shapes and types.
3.  **Feature Extraction**: Instantiate the `FeatureExtractor` to process images (CNN + ViT backbones) and tabular data. The script forces a fresh run (bypassing cache) to demonstrate the extraction logic.
4.  **Preprocessing**: Use `FusionPipeline` to fit scalers and PCA components on the training data and transform all dataset splits into a fused feature representation.
5.  **Modeling**: Train the `EnsembleClassifier` (Logistic Regression + LDA) on the fused training features.
6.  **Optimization**: Optimize the ensemble mixing weight using the validation set. Special care is taken to filter the validation set for the debug run to ensure metric calculations only consider classes present in the small training subset.
7.  **Submission**: Generate predictions for the test set, map the predicted probabilities to the full 99-class schema required for submission, and save the result to a CSV file.
