This results in a submission file with fewer columns than required, triggering an assertion error. To fix this, I will move the `LabelEncoder` fitting logic to execute before the dataset is subsampled. This ensures the encoder learns the full global label space (99 classes) regardless of how many samples are actually used for training, effectively applying the principle from **Cite debug_lesson_2**.
