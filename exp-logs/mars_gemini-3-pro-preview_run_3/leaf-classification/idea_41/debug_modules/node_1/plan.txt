The issue is that the Vision Transformer (DINOv2) model is pre-trained with a fixed resolution (518x518) and relies on fixed position embeddings, but the pipeline is feeding it 224x224 images. Unlike CNNs, ViTs require explicit instruction to interpolate their position embeddings to match a new input resolution (Cite debug_lesson_5). To fix this, I will update the `_load_models` method in `library/feature_extraction.py` to pass the `img_size=Config.IMG_SIZE` argument when initializing the DINOv2 model via `timm.create_model`. I will leave the ConvNeXt initialization unchanged as it is a CNN and may not support or require this argument (Cite debug_lesson_26).
