The implementation strategy is as follows:

1.  **Initialization**: Setup the environment by importing necessary libraries and setting the random seed using the provided `seed_everything` utility to ensure reproducibility.
2.  **Training**: Instantiate the `Engine` class from the library. Execute `engine.train_folds()` to perform Stratified K-Fold Cross-Validation. This trains an ensemble of LDA classifiers on the densified training data (3 orthogonal centroids per image) and caches the trained models.
3.  **Hold-out Validation**:
    *   Load the separate validation dataset (`metadata/val.csv`) using `engine.processor.get_val_data()`.
    *   Perform inference using the trained ensemble on the validation set.
    *   Aggregate predictions by averaging probabilities across the 3 centroids for each image and across all models in the ensemble.
    *   Compute the **Multi-class Log Loss** on this hold-out set.
    *   Print the result in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the log loss contribution for each sample in the validation set.
    *   Compute correlations between the error magnitude and the mean signal intensity of the different feature modalities (DINOv2, ConvNeXt, Tabular). This helps identify if specific feature types are associated with higher error rates.
5.  **Submission**:
    *   Execute `engine.generate_submission()` to predict on the test set and generate the `submission.csv` file. This ensures the best submission is available for grading.
