The error `ValueError: Object arrays cannot be loaded when allow_pickle=False` occurs because the pipeline attempts to load NumPy arrays containing string data (the species labels) using the default security settings, which disable pickling. As identified in the error analysis, string arrays in NumPy are often stored as object arrays, requiring explicit permission to load. I will resolve this by adding `allow_pickle=True` to the `np.load` calls for label arrays in both `library/data_processing.py` and `library/feature_extraction.py`. Cite debug_lesson_21.
