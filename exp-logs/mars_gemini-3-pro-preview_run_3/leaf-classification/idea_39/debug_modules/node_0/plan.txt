The following implementation strategy outlines the steps to demonstrate the functionality of the provided machine learning library for leaf species classification.

### Implementation Strategy

1.  **Configuration Patching**: To ensure the demonstration runs quickly and reliably on a small subset of data, we will patch the `library.config` module at runtime. Specifically, we will reduce `N_FOLDS` to 2 and set `NUM_WORKERS` to 0 to avoid multiprocessing overhead on the small debug dataset.
2.  **Environment Setup**: We will initialize the random seed for reproducibility and clean the cache directory to ensure the demonstration performs the actual processing steps rather than loading stale data.
3.  **Feature Extraction Demo**: We will invoke `library.feature_extraction.run_extraction` with a small `debug_sample_size`. We will verify the logic by asserting that the output shapes of the extracted DINOv2 and ConvNeXt features match the expected dimensions (1024 and 1536 respectively) and that the number of views corresponds to the input size.
4.  **Data Processing Demo**: We will use `library.data_processor.load_dataset` to process the raw features into the densified format (orthogonal centroids). We will validate that the resulting feature vectors have the correct concatenated dimension (DINO + ConvNeXt + Tabular = 2752) and that the data is correctly densified by a factor of 3 (3 centroids per image).
5.  **Model Pipeline Demo**: We will instantiate the model pipeline using `library.model_builder.create_pipeline`, fit it on the debug training set, and generate predictions on the validation set. We will explicitly test the `aggregate_predictions` function to confirm it correctly reduces the densified predictions back to image-level probabilities.
6.  **Workflow Execution**: Finally, we will run the full end-to-end workflow using `library.workflow.train_ensemble` and `predict_ensemble`. This will execute the K-Fold cross-validation and generate a submission file. We will verify the existence and format of the final `submission.csv`.
