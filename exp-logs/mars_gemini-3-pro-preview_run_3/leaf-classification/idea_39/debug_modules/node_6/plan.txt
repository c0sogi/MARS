The issue is that the `load_array` utility function in `library/utils.py` explicitly sets `allow_pickle=False` when calling `numpy.load`. This prevents the loading of arrays containing strings (object arrays), such as the `classes.npy` file which stores species names, causing a `ValueError` during the workflow execution. To fix this, I will update `library/utils.py` to set `allow_pickle=True`, enabling the loading of trusted cache files containing string data (Cite debug_lesson_21).
