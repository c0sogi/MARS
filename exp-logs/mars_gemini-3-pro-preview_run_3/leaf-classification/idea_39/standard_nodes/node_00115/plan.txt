The `torch.OutOfMemoryError` occurs because the feature extraction pipeline expands each input image into 12 rotated views, causing the effective batch size passed to the GPU to be $32 \times 12 = 384$. This exceeds the memory capacity of the available GPU when running the large ConvNeXt model. To resolve this, I will reduce the `BATCH_SIZE` in `library/config.py` from 32 to 4, resulting in a manageable effective batch size of 48. Cite debug_lesson_13.
