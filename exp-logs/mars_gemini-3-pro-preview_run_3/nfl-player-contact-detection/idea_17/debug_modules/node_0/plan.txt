The following script demonstrates the end-to-end usage of the provided library modules for the NFL Contact Detection task.

**Implementation Strategy:**
1.  **Configuration Override**: At runtime, we modify the `Config` class attributes to use a temporary working directory and reduce model complexity (e.g., fewer trees) for rapid execution.
2.  **Utility Verification**: We validate the metric calculation (`calc_mcc`) and threshold optimization logic with synthetic data.
3.  **Data Loading & Splitting**: We use `DataFactory` in debug mode to load a small subset of the training data and verify the logic for splitting contact events into Stream A (Player-Player) and Stream B (Player-Ground).
4.  **Feature Engineering**: We instantiate `FeatureEngine` to generate features for both streams using the loaded subsets, asserting that the resulting DataFrames contain the expected engineered columns (e.g., `dist_p1_p2` for Stream A, `surge_a` for Stream B).
5.  **Model Training & Inference**: We use `StreamTrainer` to train XGBoost models on the generated features and produce predictions.
6.  **Pipeline Orchestration**: Finally, we run the full `Pipeline` class (training and inference) to ensure the components integrate correctly and generate a valid submission file.
