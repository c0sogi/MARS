The implementation strategy focuses on correcting the data sampling logic and refining the feature set based on previous lessons.

1.  **Correct Training Data Distribution**: The primary performance regression was caused by the `subsample_dataset` function in `runfile.py`, which performed uniform random sampling. This inadvertently discarded ~90% of the positive class samples, severely underfitting the minority class (Cite `solution_lesson_node_00060`). I will remove this function and rely on the `DualStreamGBDT` engine's internal `undersample` method, which implements "Targeted Majority Undersampling" (preserving 100% of positive cases).
2.  **Restore Model Capacity**: I will remove the configuration override in `runfile.py` that capped `n_estimators` at 1000. Restoring the default 3000 estimators allows the model to fully leverage the larger dataset, relying on early stopping to prevent overfitting.
3.  **Augment Stream A Features**: I will add raw `speed_p1` and `speed_p2` back into the Stream A feature set in `library/feature_engineering.py`. While derived features like relative surge/sway are valuable, Lesson `solution_lesson_node_00055` advises against replacing robust raw kinematic signals with derived ones entirely.

def subsample_dataset(X, y, ids, max_samples, seed):
    """
    Subsamples the dataset to max_samples to ensure fast training.
    """
    if len(X) <= max_samples:
        return X, y, ids

    print(f"Subsampling dataset from {len(X)} to {max_samples} samples...")
    np.random.seed(seed)
    indices = np.random.choice(len(X), max_samples, replace=False)

    # X is a DataFrame, y and ids are numpy arrays
    X_sub = X.iloc[indices].reset_index(drop=True)
    y_sub = y[indices]
    ids_sub = ids[indices]

    return X_sub, y_sub, ids_sub
