The implementation strategy focuses on enhancing the feature engineering pipeline and removing artificial constraints on model training to maximize performance.

1.  **Enrich Kinematic Features (Cite Lesson 00027):** We will augment the tracking data in both streams with physics-based derivatives, specifically `jerk` (change in acceleration) and `pose_motion_alignment` (alignment between body orientation and movement direction). These features have been shown to better discriminate between controlled movement and physical impact.
2.  **Cyclical Feature Encoding (Cite Lesson 00005):** We will replace raw angular features (`orientation`, `direction`) with their sine and cosine components. This resolves the numerical discontinuity at 0/360 degrees. Furthermore, in the Interaction Stream (A), we will replace simple absolute angular differences with `cosine_similarity` derived from these components, providing a topologically correct measure of alignment between players.
3.  **Full Data Utilization:** We will remove the "Fast Baseline" constraints in `runfile.py` (subsampling to 200k rows and limiting estimators to 1000). This ensures the XGBoost model trains on the complete dataset with sufficient capacity to learn the complex interaction boundaries, leveraging the full 4-hour runtime if necessary.
4.  **Cache Invalidation:** We update the working directory to `idea_12` to ensure the new feature set is generated from scratch and not loaded from stale cache.
