The following is the implementation strategy for the `runfile.py` script:

1.  **Setup and Imports**: Initialize the environment by setting random seeds for reproducibility and importing necessary components from the provided `library` modules (`config`, `dataset`, `model`, `trainer`, `data_processing`).
2.  **Data Loading**: Utilize `get_dataloaders` to efficiently load the training, validation, and test datasets. This leverages the caching mechanism implemented in `data_processing` to speed up execution.
3.  **Model Initialization**: Instantiate the `ContactMLP` model. The input dimension is dynamically determined from the feature set size of the loaded data.
4.  **Training Loop**: Configure the `Trainer` with `BCELoss` and the `Adam` optimizer. Execute the training process using `trainer.fit`, which includes automatic validation monitoring and early stopping to ensure a fast and optimal baseline.
5.  **Validation & Metric Calculation**:
    *   Load the best model weights saved during training.
    *   Optimize the decision threshold using the validation set to maximize the MCC score.
    *   Compute and print the `Final Validation Metric` using the optimized threshold.
6.  **Failure Analysis**:
    *   Retrieve the validation feature DataFrame using `get_data`.
    *   Calculate the absolute error between predictions and ground truth.
    *   Compute and print the correlation between the error magnitude and input features to identify sources of model failure.
7.  **Inference & Submission**: Generate predictions for the test set using the optimized threshold and save the results to `submission.csv` in the required format.
