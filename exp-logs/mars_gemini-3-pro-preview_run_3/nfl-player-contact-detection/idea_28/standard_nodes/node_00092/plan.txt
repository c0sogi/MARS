    *   Print the required metric string: `Final Validation Metric: <value>`.
    *   Conduct failure analysis by calculating the correlation between prediction errors (residuals) and input features to identify weak points in the model.

6.  **Submission Generation**:

    *   If successful, load the test dataset, generate features, and produce the final `submission.csv` using the `generate_submission` method.
