The following script demonstrates the end-to-end usage of the provided library modules. It includes:
1.  **Unit Verification of Physics Engine**: Validates core geometric and physics calculations.
2.  **Data Subsetting**: Creates minimal metadata files to ensure the pipeline runs quickly within the demo environment.
3.  **Pipeline Execution**: Runs `DataManager`, `FeatureBuilder`, and `ModelTrainer` to process data, generate features, and train models using the subsetted data.
4.  **Inference Simulation**: Generates a submission file using the trained models.

The script modifies configuration dictionaries in-place to point to the subsetted data and reduce model complexity (e.g., number of trees) for speed.
