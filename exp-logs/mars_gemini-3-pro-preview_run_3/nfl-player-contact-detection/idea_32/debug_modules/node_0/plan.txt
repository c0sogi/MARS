This script demonstrates the end-to-end execution of the provided machine learning pipeline for contact detection. It performs the following steps:

1.  **Configuration**: overrides default XGBoost hyperparameters to ensure the demonstration runs quickly (reducing estimators to 10).
2.  **Feature Engineering**: Uses `FeatureEngineer` to load and process a small "debug" subset (top 5 plays) of the training, validation, and test datasets. It verifies the structural integrity of the generated feature sets for both Stream A (Player-Player) and Stream B (Player-Ground).
3.  **Model Training**: Uses `ModelTrainer` to train the dual-stream XGBoost models on the processed training data, using the validation data for early stopping. It asserts that models are successfully created.
4.  **Optimization**: Uses `MetricOptimizer` to determine the optimal classification thresholds based on validation performance (MCC).
5.  **Inference & Submission**: Generates predictions on the test set and formats them into a valid submission file using the optimized thresholds. It verifies the output file format and content.
