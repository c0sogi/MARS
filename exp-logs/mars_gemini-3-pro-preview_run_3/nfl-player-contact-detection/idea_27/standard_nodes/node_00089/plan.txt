The solution involves orchestrating the "Invariant-Physics Temporal Pyramid Dual-Stream GBDT" pipeline. We will use the provided library classes to handle data loading, feature engineering, model training, and inference.

**Implementation Strategy:**
1.  **Setup**: Initialize the `PipelineManager` with `debug=False` to ensure the model trains on the full dataset (subject to the configured undersampling) for maximum performance. Set random seeds for reproducibility.
2.  **Training**: Execute `run_training_pipeline` to train both the Interaction (Stream A) and Impact (Stream B) XGBoost models. This process automatically handles feature caching, training, and threshold optimization.
3.  **Validation**: To compute the required "Final Validation Metric", we will explicitly reload the validation features for both streams, generate predictions using the optimized thresholds, and calculate the Matthews Correlation Coefficient (MCC) on the combined validation set.
4.  **Failure Analysis**: We will compute the absolute error of the predictions on the validation set and calculate the correlation between these errors and the input features. This identifies which features are most associated with model failure.
5.  **Submission**: If the calculated validation MCC exceeds the target of 0.6968, we trigger the `run_inference_pipeline` to generate the final `submission.csv`.
