The error `ValueError: data did not contain feature names` occurs because the `_undersample` method in `DualStreamXGBoost` converts the input features `X` into a NumPy array using `np.array(X)`, stripping away the column names. However, the validation data passed to XGBoost retains its DataFrame structure (and feature names). XGBoost requires consistency: if the validation set has feature names, the training set must also have them.

To fix this, I will modify `library/model_wrapper.py` to:
1.  Import `pandas` to support type checking.
2.  Update `_undersample` to check if `X` is a pandas DataFrame. If it is, I will use `.iloc` for indexing to preserve the DataFrame structure and column names. If it is not, I will fall back to NumPy array indexing. This ensures schema consistency between training and validation sets. Cite debug_lesson_15.
