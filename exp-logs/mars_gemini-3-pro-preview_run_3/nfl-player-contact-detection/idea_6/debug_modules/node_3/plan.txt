The issue is that `runfile.py` creates the mini-dataset for the training tracking and helmet files by filtering only for `train_plays`, excluding `val_plays`. However, the pipeline's `create_features` method (in `feature_engineering_tracking.py`) loads the training source file to generate features for the validation split (since validation is a subset of the training data). Because the validation plays are missing from the filtered file, the pipeline crashes with a `ValueError` when attempting to process the validation set. The fix is to include both `train_plays` and `val_plays` in the `mini_train_tracking.csv` and `mini_train_helmets.csv` files. Cite debug_lesson_2.
