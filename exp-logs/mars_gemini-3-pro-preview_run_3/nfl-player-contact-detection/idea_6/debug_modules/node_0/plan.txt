The following script demonstrates the end-to-end usage of the provided machine learning pipeline for NFL Contact Detection.

**Implementation Strategy:**
1.  **Environment Setup**: Initialize random seeds and logging.
2.  **Data Reduction (Optimization)**: To ensure the demonstration runs quickly (within seconds/minutes), we create a "Mini Dataset" by sampling a few plays from the original metadata and filtering the corresponding tracking and helmet data. These smaller files are saved to a temporary directory.
3.  **Configuration Patching**: We dynamically modify the `Config` class attributes to point to the new Mini Dataset paths and drastically reduce model hyperparameters (e.g., `n_estimators=10`) to speed up training.
4.  **Pipeline Execution**: We instantiate the `EnsemblePipeline` class, which orchestrates data loading, feature engineering (for both Kinematic and Visual streams), model training (XGBoost), and ensemble optimization.
5.  **Inference & Validation**: We run the inference step to generate predictions on the mini test set and validate the output format and logic using assertions.
