The `TypeError` occurs because recent versions of XGBoost have removed the `early_stopping_rounds` parameter from the `fit()` method in the Scikit-Learn API, requiring it to be passed to the `XGBClassifier` constructor instead. To resolve this, I will move the `early_stopping_rounds` configuration into the `XGB_PARAMS_BASE` dictionary in `library/config.py` so it is initialized with the model, and remove the deprecated argument from the `fit()` call in `library/model.py`.
