The following script demonstrates the end-to-end execution of the NFL Player Contact Detection pipeline using the provided library files.

To ensure the demonstration runs quickly (within the time limit) and verifies logic effectively, the script employs the following strategy:
1.  **Configuration Overrides**: It monkey-patches the `Config` class to use a temporary working directory, reduces the number of boosting rounds (estimators) for the XGBoost models, and simplifies the temporal lags to reduce feature dimensionality.
2.  **Data Subsetting**: It creates "mini" versions of the training, validation, and test metadata files containing only a few plays. It then redirects the `Config` paths to these mini datasets. This forces the `TrainPipeline` and `InferencePipeline` to process a tiny fraction of the data, ensuring rapid execution while still exercising all code paths (data loading, merging, feature engineering, training, and inference).
3.  **Execution & Verification**: It runs the training pipeline to generate models and thresholds, then runs the inference pipeline to generate predictions. Finally, it asserts that the output submission file exists and contains the expected number of rows corresponding to the mini test set.
