The following code demonstrates the end-to-end pipeline for the NFL Player Contact Detection task using the provided library files. It covers data loading, feature engineering for two distinct streams (Player-Player and Player-Ground), model training with XGBoost, and generating a submission file via the inference pipeline.

To ensure rapid execution for demonstration purposes, the script runs in `debug` mode (sampling a small subset of plays) and overrides the model hyperparameters to use fewer estimators.
