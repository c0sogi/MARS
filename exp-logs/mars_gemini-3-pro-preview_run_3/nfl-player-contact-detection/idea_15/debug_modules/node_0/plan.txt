The following script demonstrates the complete pipeline for the Context-Augmented Dual-Stream GBDT model. It performs the following steps:

1.  **Configuration Overrides**: Modifies the global `Config` to use a temporary working directory and reduces XGBoost hyperparameters (e.g., `n_estimators`) for rapid execution.
2.  **Data Subsampling**: Creates "mini" versions of the training, validation, and test metadata files to ensure the demonstration runs quickly (within minutes) while exercising all code paths.
3.  **Pipeline Execution**:
    *   Initializes the `DualStreamModel`.
    *   Trains both Stream A (Player-Player) and Stream B (Player-Ground) models.
    *   Optimizes decision thresholds based on validation performance.
    *   Generates predictions for the test set.
4.  **Validation**: Asserts that the models are trained, thresholds are valid, and the final submission file follows the required format and dimensions.
