The error `ValueError: Object arrays cannot be loaded when allow_pickle=False` arises because the cached `.npy` files contain arrays of strings (contact IDs), which are stored as object arrays. NumPy requires `allow_pickle=True` to load such arrays, but defaults to `False` for security. I will update `library/utils.py` to explicitly enable pickling when loading NumPy files to resolve this.
