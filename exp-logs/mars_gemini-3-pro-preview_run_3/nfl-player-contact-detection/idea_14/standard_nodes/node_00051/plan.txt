The strategy involves reverting the "Sequential Cascade" architecture back to independent streams (Idea 15 style) while enhancing the feature engineering for the Player-Ground stream with explicit kinematic derivatives.

**Strategy:**
1.  **Feature Engineering Enhancement (Cite Lesson `solution_lesson_node_00027`, `solution_lesson_node_00050`)**:
    -   Implement `jerk` (derivative of acceleration) and `angular_velocity` (derivative of orientation) to capture the physical mechanics of ground impact.
    -   Implement `cos_orient_dir` (Pose-Motion Alignment) to quantify controlled vs. uncontrolled motion.
    -   Add these to the `TRACKING_BASE_COLS` to ensure they are lagged and used in the model.
2.  **Architecture Simplification**:
    -   Remove the "Interaction Context" (OOF predictions) from Stream B. The previous experiment showed that replacing direct physics with probabilistic context degraded performance.
    -   Decouple the training of Stream A and Stream B.
3.  **Hyperparameter Optimization**:
    -   Restore `NUM_BOOST_ROUND` to 3000 (from 1000) to prevent underfitting, as indicated by Lesson `solution_lesson_node_00045`.

    def _generate_oof_stream_a(self, X, y, ids, groups, load_cached_data=True):
        """
        Generates Out-of-Fold predictions for Stream A to be used as context for Stream B.
        Uses GroupKFold to prevent leakage across plays.
        """
        # Determine valid number of splits based on available groups
        unique_groups = np.unique(groups)
        n_groups = len(unique_groups)
        n_splits = min(5, n_groups)

        if n_splits < 2:
            raise ValueError(
                f"Insufficient groups ({n_groups}) for Cross Validation. Need at least 2."
            )

        if n_splits < 5:
            print(
                f"Adjusting n_splits from 5 to {n_splits} due to limited groups (Debug Mode)."
            )

        cache_config = {
            "task": "oof_generation_stream_a",
            "n_splits": n_splits,
            "seed": Config.SEED,
            "debug": Config.DEBUG,
        }
        cache_path = get_cache_path(
            self.working_dir, "oof_preds_stream_a", cache_config, "parquet"
        )

        if load_cached_data and os.path.exists(cache_path):
            print(f"Loading cached OOF predictions from {cache_path}")
            return pd.read_parquet(cache_path)

        print(
            f"Generating OOF predictions for Stream A ({n_splits}-Fold GroupKFold)..."
        )

        # Initialize storage for OOF predictions
        oof_preds = []

        # GroupKFold Split
        gkf = GroupKFold(n_splits=n_splits)

        # We need to reconstruct a DataFrame to map predictions back to contact_ids
        # X is a DataFrame, y is numpy array, ids is numpy array

        fold = 1
        for train_idx, val_idx in gkf.split(X, y, groups=groups):
            print(f"  Processing Fold {fold}/{n_splits}...")

            # Slice data
            X_train_fold = X.iloc[train_idx]
            y_train_fold = y[train_idx]
            X_val_fold = X.iloc[val_idx]
            # y_val_fold = y[val_idx] # Not needed for prediction
            ids_val_fold = ids[val_idx]

            # Train Model
            model = XGBWrapper(Config.get_xgb_params("A"), model_path=None)
            model.fit(X_train_fold, y_train_fold)

            # Predict
            probs = model.predict(X_val_fold)

            # Store results
            fold_df = pd.DataFrame({"contact_id": ids_val_fold, "prob": probs})
            oof_preds.append(fold_df)

            fold += 1

        # Concatenate all folds
        oof_df = pd.concat(oof_preds, axis=0).reset_index(drop=True)

        # Save to cache
        print(f"Saving OOF predictions to {cache_path}")
        save_to_cache(oof_df, cache_path)

        return oof_df
