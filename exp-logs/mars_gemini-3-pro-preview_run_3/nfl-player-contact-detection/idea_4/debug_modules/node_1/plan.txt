The `ValueError` arises because the `nfl_player_id_2` column in the labels DataFrame is of type `object` (due to the presence of "G" for ground contacts), while the corresponding player ID column in the tracking DataFrame is of type `int64`. Pandas strictly prevents merging these incompatible types.

To fix this, I will explicitly coerce the player ID columns (`nfl_player_id_1` and `nfl_player_id_2`) to numeric types using `pd.to_numeric(..., errors='coerce')` before performing the merge operations in the `process_data` method. This ensures that the join keys match the integer type of the tracking data, effectively handling the "G" values (which become `NaN` but are filtered out for Stream A anyway) and preventing the type mismatch error. This applies the solution from **Debug Lesson 3** (Cite debug_lesson_3).
