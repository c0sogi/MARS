This script demonstrates the end-to-end usage of the provided machine learning pipeline for predicting contact events in football game footage. It covers data loading, feature engineering, model training with a dual-stream XGBoost architecture (Stream A for player-player interactions, Stream B for player-ground impacts), threshold optimization, prediction, and evaluation.

To ensure rapid execution for demonstration purposes, the script filters the dataset to a small subset of plays and reduces the number of boosting estimators.
