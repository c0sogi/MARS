The issue is caused by the validation set for Stream B containing only negative samples (all zeros) due to the small sample size in debug mode. Scikit-learn's `log_loss` function raises a `ValueError` when the provided ground truth labels (`y_true`) contain only one class, as it cannot infer the full set of expected labels (0 and 1) to calculate the loss correctly.

To fix this, we need to explicitly provide the `labels` argument to the `log_loss` function in `library/model_trainer.py`. By specifying `labels=[0, 1]`, we inform the function that this is a binary classification problem, allowing it to compute the loss even if the current batch of validation data lacks one of the classes.
