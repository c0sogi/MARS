The error `KeyError: 'game_play'` occurs because the `.add_suffix("_p1")` method renames all columns in the right-side DataFrame (including the join keys `game_play` and `step`), but the `merge` function's `right_on` argument still references the original unsuffixed names. As noted in **Cite debug_lesson_25**, when using `add_suffix` before a merge, the `right_on` keys must be updated to match the new suffixed column names (e.g., `game_play_p1`, `step_p1`) to avoid this error.

I will fix this in `library/features.py` by updating the `right_on` parameters in both the Player 1 and Player 2 merge operations within the `_compute_iou` method to use the correctly suffixed column names.
