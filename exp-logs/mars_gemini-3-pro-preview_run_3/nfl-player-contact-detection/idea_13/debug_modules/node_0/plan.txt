The following script demonstrates the end-to-end pipeline for the contact detection task using the provided library files. It performs the following steps:
1.  **Setup**: Initializes the environment and seeds for reproducibility.
2.  **Data Loading**: Loads a small subset of the training, validation, and test datasets to ensure quick execution.
3.  **Feature Engineering**: Generates kinematic, visual, and interaction features for the loaded data and splits them into Player-Player (Stream A) and Player-Ground (Stream B) streams.
4.  **Model Training**: Instantiates the `DualStreamGBDT` model, overrides hyperparameters for speed (reducing estimators), and trains both streams.
5.  **Inference**: Generates predictions on the test subset and creates a submission file.
6.  **Validation**: Asserts that the pipeline produced the expected outputs and shapes.
