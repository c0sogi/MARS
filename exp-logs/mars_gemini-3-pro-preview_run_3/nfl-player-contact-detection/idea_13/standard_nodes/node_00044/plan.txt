The solution implements the `runfile.py` script to orchestrate the Asymmetric Dual-Stream GBDT pipeline.
1.  **Setup**: Initializes the environment and sets random seeds for reproducibility.
2.  **Data Loading**: Loads Train, Validation, and Test datasets using `load_dataset`. Full datasets are loaded to preserve the temporal sequence required for lag features, relying on the model's internal undersampling for efficiency.
3.  **Feature Engineering**: Generates multi-modal features (Tracking + Visual Lags) for all splits using `generate_features`.
4.  **Model Training**: Instantiates and trains the `DualStreamGBDT` model. The model automatically handles stream splitting (Player-Player vs. Player-Ground) and applies random undersampling to the majority class.
5.  **Validation**: Performs inference on the hold-out validation set, reconstructs the ground truth, and calculates the Matthews Correlation Coefficient (MCC).
6.  **Failure Analysis**: Computes the absolute error of predictions and calculates the Pearson correlation between the error and input features to identify failure modes.
7.  **Submission**: Checks if the validation MCC exceeds the specified threshold (0.6771576187394703). If successful, generates predictions for the test set and saves `submission.csv`.
