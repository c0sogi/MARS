The following script demonstrates the end-to-end execution of the NFL Contact Detection pipeline using the provided library files.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the global `Config` class attributes to drastically reduce the number of XGBoost estimators and disable verbose logging. This ensures the demonstration runs quickly (within minutes) while exercising the full code path.
2.  **Training Pipeline**: We execute `run_training_pipeline` in `debug_mode=True`. This triggers the loading of a small subset of the metadata, generation of features for both Stream A (Player-Player) and Stream B (Player-Ground), training of the models, and optimization of thresholds.
3.  **Inference Pipeline**: We execute `generate_predictions` in `debug_mode=True`. This processes a subset of the test metadata, loads the models trained in the previous step, generates probabilities, applies thresholds, and produces a valid `submission.csv`.
4.  **Component Verification**: We explicitly instantiate the `FeatureEngineer` class and run it on a tiny manual slice of data to assert that feature shapes and specific column existence (e.g., 'jerk', 'iou') are correct, ensuring the logic inside the black-box pipeline functions is valid.
5.  **Artifact Validation**: We use assertions to confirm that model files, threshold mappings, and the final submission file are physically created in the expected directories.
