This script orchestrates the full machine learning pipeline for Kuzushiji character recognition. It begins by overriding the default configuration to ensure a fast baseline execution, reducing the number of epochs and using subsets of the training data. It then initializes the datasets and dataloaders for both the detector (HRNet) and classifier (ResNet). The training phase executes sequentially: first training the detector to localize characters, then the classifier to identify them. After training, the script performs a comprehensive validation on the hold-out set by running the full inference pipeline (Tiled Detection + Batch Classification) and computing the modified F1 score. It conducts a failure analysis to correlate prediction errors with image properties. Finally, if the validation score meets the specified threshold, it generates the submission file for the test set.
