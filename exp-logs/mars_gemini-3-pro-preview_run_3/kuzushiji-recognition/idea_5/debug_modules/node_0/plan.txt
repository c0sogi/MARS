This script demonstrates the usage of the provided Kuzushiji recognition pipeline components. It systematically verifies the utility functions, datasets, models, and the training/inference engine. To ensure rapid execution within the time limit, it dynamically adjusts the configuration to use a minimal subset of data (debug mode) and reduces the number of training epochs to 1.

The script performs the following steps:
1.  **Configuration & Setup**: Adjusts global `Config` parameters for a quick demonstration run.
2.  **Utility Verification**: Validates core helper functions like Gaussian generation, affine transformations, and the modified F1 metric.
3.  **Dataset Verification**: Instantiates both detection and classification datasets in debug mode, verifying data shapes and types.
4.  **Model Verification**: Performs a forward pass on both the CenterNet Detector and ResNet Classifier using dummy data to ensure architecture correctness.
5.  **Full Pipeline Execution**: Runs the `run_training_and_inference` engine function in debug mode, which trains both models for 1 epoch on a small subset and generates a submission file.
6.  **Output Validation**: Checks the format and content of the generated submission file.
