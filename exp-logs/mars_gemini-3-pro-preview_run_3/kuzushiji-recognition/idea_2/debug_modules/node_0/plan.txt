The following script demonstrates the usage of the provided Kuzushiji Recognition library. It sets up a minimal environment, verifies utility functions, tests the data processing pipeline, trains the models for a single step to verify the engine, and executes the inference pipeline on a subset of data.

Strategy:
1.  **Setup**: Create a temporary working directory and generate "mini" versions of the metadata files by sampling the provided metadata. This allows the code to run quickly without processing the full dataset.
2.  **Configuration**: Override `Config` paths to point to the mini-datasets and temporary output directories.
3.  **Verification**:
    *   **Utils**: Test geometric and metric functions (Gaussian generation, F1 score).
    *   **Data**: Run the preprocessing script (`prepare_classifier_data`) to generate crops, then load `Detector` and `Classifier` datasets to verify tensor shapes and augmentations.
    *   **Models & Training**: Instantiate the `CenterNetDetector` and `CharacterClassifier`. Run a single training step using the training engine to ensure the loss calculation and backpropagation work.
    *   **Inference**: Test coordinate correction logic and run the full `InferencePipeline` on the mini test set.
