Here is the implementation plan and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and setup necessary directories using the provided `library` modules.
2.  **Model Training**: Instantiate the `Trainer` class from `library.trainer`. Execute the training loop using `trainer.fit()`. To ensure the task completes within the time limit while providing a strong baseline, we will train for **10 epochs**. The ResNet-18 backbone with pre-trained weights converges relatively quickly on this dataset size.
3.  **Validation & Metric Calculation**: Implement a custom evaluation loop to calculate the specific **F1 Score** metric defined in the task (Point-in-Box matching).
    *   Iterate through the validation set using the trained model.
    *   Decode model outputs to obtain predicted class labels and coordinates.
    *   Transform coordinates back to the original image space.
    *   Match predictions to ground truth: A match is valid if the predicted label matches the ground truth label and the predicted center point lies within the ground truth bounding box.
    *   Compute global Precision, Recall, and F1 Score.
4.  **Failure Analysis**:
    *   Aggregate performance statistics per image (F1 score, TP, FP, FN).
    *   Calculate correlations between the error magnitude ($1 - F1$) and input features (number of characters, image width, image height) to identify potential weaknesses (e.g., performance drop on dense pages).
5.  **Submission Generation**: Use the provided `library.inference.generate_submission` function to predict on the test set and save the `submission.csv` file.
