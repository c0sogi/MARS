This script demonstrates the end-to-end usage of the provided Kuzushiji recognition library. It performs the following steps:
1.  **Configuration**: Overrides default hyperparameters (batch size, epochs, debug mode) to ensure the script runs quickly (under 5 minutes) while exercising all code paths.
2.  **Dataset Verification**: Instantiates the `KuzushijiDataset`, loads a sample, and verifies the shapes of the input images and generated ground truth heatmaps/offsets.
3.  **Model Verification**: Instantiates the `SparseCenterNet` model, performs a forward pass with dummy data, and asserts output shapes match the expected feature map dimensions (1/4th input resolution).
4.  **Loss Calculation**: Manually computes the loss on the dummy batch to verify the `SparseCenterNetLoss` logic.
5.  **Training Loop**: Uses the `Trainer` class to run a single epoch of training on a small subset of data, verifying that the model weights are updated and a checkpoint is saved.
6.  **Inference & Submission**: Runs the inference pipeline on the test set (debug mode) and verifies that a valid `submission.csv` is generated.
