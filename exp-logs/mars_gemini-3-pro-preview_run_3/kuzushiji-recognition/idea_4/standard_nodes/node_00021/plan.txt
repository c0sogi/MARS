Implementation strategy:
1.  **Configuration & Setup**: Initialize the environment, set random seeds for reproducibility, and override default configuration parameters (`DETECTOR_EPOCHS=10`, `CLASSIFIER_EPOCHS=3`) to ensure the training completes within the 2-hour limit while maintaining sufficient convergence.
2.  **Model Training**:
    *   Initialize and train the **CenterNet Detector** (Stage 1) using `DetectorTrainer`. This model learns to locate character centers on native resolution patches.
    *   Initialize and train the **ResNet-50 Classifier** (Stage 2) using `ClassifierTrainer`. This model learns to classify character crops.
    *   Explicitly invoke garbage collection and clear CUDA cache between stages to manage memory on the GPU.
3.  **Validation Inference**:
    *   Instantiate the `InferencePipeline`.
    *   Run the pipeline on the validation dataset (using `val_metadata.csv`) to generate predictions.
4.  **Metric Calculation**:
    *   Implement the modified F1 Score logic: parse ground truth and prediction strings, perform greedy matching based on label equality and point-in-box geometric verification.
    *   Compute and print the final validation metric with full precision.
5.  **Failure Analysis**:
    *   Calculate per-image error metrics (1 - F1).
    *   Compute Pearson correlations between the error magnitude and metadata features (number of characters, false positives, false negatives) to identify systematic weaknesses.
6.  **Submission Generation**:
    *   Check if the validation F1 score exceeds the threshold (0.8455).
    *   If successful, run the `InferencePipeline` on the test set (`test_metadata.csv`) and save the results to `./submission/submission.csv`.
