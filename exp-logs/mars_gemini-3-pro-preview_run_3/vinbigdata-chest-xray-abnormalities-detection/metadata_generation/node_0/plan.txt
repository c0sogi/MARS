The implementation strategy is as follows:

1.  **Setup and Loading**: Initialize the script by importing necessary libraries (`pandas`, `numpy`, `os`, `sklearn`). Define the input directory (`./input`) and output directory (`./metadata`). Load the `train.csv` and `sample_submission.csv` files.

2.  **Data Processing**:
    *   **Train Data**: Construct relative file paths for the training images by appending the `image_id` to `train/` and adding the `.dicom` extension.
    *   **Test Data**: Extract `image_id`s from the sample submission file and construct relative file paths (`test/{image_id}.dicom`).

3.  **Validation Split**:
    *   Perform a **Grouped Stratified Split**. Since the dataset contains multiple bounding boxes per image (multiple rows per `image_id`), we must ensure that all annotations for a single image remain in the same split to prevent data leakage.
    *   Group the training data by `image_id`.
    *   Define a stratification label for each image. We will use the presence of any finding (vs. "No finding", class ID 14) as the stratification target. This ensures the ratio of normal to abnormal cases is consistent across train and validation sets.
    *   Use `train_test_split` on the unique image IDs with `stratify` enabled and `random_state=42` to create an 80:20 split.

4.  **Metadata Generation**:
    *   Filter the original training DataFrame using the split image IDs to create `train_meta` and `val_meta` DataFrames.
    *   Create the `test_meta` DataFrame with image IDs and file paths.
    *   Save these DataFrames as CSV files in the `./metadata` directory.

5.  **Verification**:
    *   **Statistics**: Print the number of samples and unique images in each set.
    *   **File Existence**: Randomly sample 1000 file paths from each generated metadata file and verify they exist in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
    *   **Split Validation**: Assert that there is no overlap of `image_id`s between train and validation sets and that the split ratio is approximately correct.
