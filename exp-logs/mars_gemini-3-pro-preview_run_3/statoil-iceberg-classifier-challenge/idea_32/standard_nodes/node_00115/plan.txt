The implementation strategy for the `runfile.py` script is as follows:

1.  **Setup and Configuration**: Import necessary modules and the provided library components (`Config`, `BHAResNet`, `train_model`, etc.). Set the random seed for reproducibility. Override `Config.NUM_EPOCHS` to 35 to ensure the training completes quickly while allowing sufficient convergence for a baseline.
2.  **Training**: Execute `train_model(fold=0)` to train the Biased Hybrid-Attentive ResNet on the primary training split. This utilizes the provided training loop with early stopping.
3.  **Validation**:
    *   Initialize the model and load the best weights saved during training (`model_best_fold_0.pth`).
    *   Run inference on the validation set using the `val_loader`.
    *   Compute the **Log Loss** metric using `sklearn.metrics.log_loss` and print it in the required format `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Load the cached validation numpy arrays (`X_val.npy`, `angle_val.npy`) to extract image features (mean and std of Band 1 and Band 2) and incidence angles.
    *   Calculate the absolute error between predictions and targets.
    *   Compute and print the correlation between the error magnitude and these features to identify sources of model failure.
5.  **Submission**:
    *   Compare the final validation metric against the strict threshold `0.1806015565870406`.
    *   If the metric is lower (better), run inference on the test set using `test_loader`.
    *   Construct a DataFrame with `id` and `is_iceberg` columns and save it to `./submission/submission.csv` in the required format.
