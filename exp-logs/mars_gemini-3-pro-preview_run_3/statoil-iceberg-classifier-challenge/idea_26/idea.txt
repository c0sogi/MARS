Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Max-Attentive Deep-Downsampled ResNet (MAD-ResNet)**.

This solution synthesizes the superior feature extraction potential of **Residual Networks** (which proved to be strong base learners in Cite solution_lesson_node_00027) with the rigorous noise-filtering constraints of the **Plain CNN** (specifically aggressive downsampling, Cite solution_lesson_node_00046). It introduces **Max-Squeeze-and-Excitation** to align the attention mechanism with the domain's physics (Cite solution_lesson_node_00102) and incorporates **LeakyReLU** and **Bias Retention** to preserve signal integrity (Cite solution_lesson_node_00091, solution_lesson_node_00076).

# Model
The architecture is a **Custom 4-Stage Residual Network** optimized for detecting sparse, high-intensity targets in noisy SAR imagery.

*   **Backbone:** The network uses a Residual backbone to improve gradient flow and feature extraction. Crucially, it enforces **4 Downsampling Stages** (via strided convolutions) to reduce the 75x75 input to a ~5x5 feature map. This aggressive spatial reduction is explicitly chosen to filter high-frequency speckle noise via convolution before global pooling, addressing the failure of previous shallower ResNets (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each residual block consists of `Conv2d(bias=True)` $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ `Conv2d(bias=True)` $\to$ `BatchNorm2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers, overriding standard ResNet implementations. This preserves initialization dynamics and provides optimization slack critical for small datasets (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., normalized radar shadows) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy (Early Expansion):** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand to 128 channels immediately in the second stage to preserve low-level texture details (Cite solution_lesson_node_00050) but strictly cap the width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Structural Innovation (Max-SE Attention):** Within each residual block, we integrate a **Max-Squeeze-and-Excitation Module**.
    *   **Mechanism:** Unlike standard SE (which uses Average Pooling), this module uses **Global Max Pooling** to generate the channel descriptor during the "Squeeze" phase.
    *   **Rationale:** This ensures that channels detecting high-intensity peaks (icebergs) are strongly upweighted, preventing the signal dilution caused by average pooling and aligning the attention mechanism with the "Max Pooling Inductive Bias" proven effective for this dataset (Cite solution_lesson_node_00102, solution_lesson_node_00007).
*   **Pooling Strategy:** The final feature maps are processed using **Global Max Pooling** to capture the strongest signal response (Cite solution_lesson_node_00007).
*   **Feature Fusion (Raw Scale):** The flattened vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment (magnitude ~30-45) with the raw radar signal features (dB), avoiding optimization instability (Cite solution_lesson_node_00057).
*   **Classification Head:** A single hidden layer: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout` $\to$ `Output`. Dropout is applied *only* after the activation to preserve feature integrity (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce variance and maximize the performance of the enhanced base learner (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** to ensure numerical stability and prevent overfitting (Cite solution_lesson_node_00036).
*   **Duration:** We allocate a sufficient training budget (e.g., 50-75 epochs) to allow the regularized model to converge (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
