4.  **Validation & Metric Calculation**: Load the 5 trained models and perform inference on the hold-out validation set (`X_val`). Average the predictions to get the final ensemble probability. Calculate the Log Loss against the true labels (`y_val`) and print it as the "Final Validation Metric".
5.  **Failure Analysis**: Compute the absolute error for each validation sample. Extract scalar features from the validation images (Mean/Std/Min/Max for Band 1 & 2) and the incidence angle.
