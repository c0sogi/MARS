Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Projected Dual-Polarity Hybrid-SE CNN (PDPH-SE-CNN)**.

This solution represents the structural refinement of the **Projected Dual-Polarity** concept (Idea 40), explicitly stripping away the **DropBlock** regularization that caused its failure (Cite solution_lesson_node_00126). It synthesizes the robust **Plain CNN** backbone (Cite solution_lesson_node_00046) with **Hybrid Squeeze-and-Excitation** (Cite solution_lesson_node_00106) and a parameter-efficient **Dual-Polarity Readout** that captures both iceberg peaks and radar shadows without exploding the classifier's capacity.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed feature extraction under strict capacity constraints.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand early to preserve texture (Cite solution_lesson_node_00050) but cap width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Attention (Hybrid SE):** Within the SE Module, we use **Global Average Pooling** for the squeeze operation. This acts as a low-pass filter, providing a robust statistical summary of the channel distribution without overfitting to local noise spikes (Cite solution_lesson_node_00104).
*   **Structural Innovation (Projected Dual-Polarity Readout):**
    *   **Problem:** Capturing shadows via Min-Pooling is physically motivated but doubling the feature vector (Max+Min) causes overfitting in the dense layer (Cite solution_lesson_node_00124).
    *   **Solution:** At **Stage 3** and **Stage 4**, we first apply a **1x1 Convolution** to compress the channel dimension by half (128 $\to$ 64).
    *   **Dual-Polarity Pooling:** On these compressed maps, we apply both **Global Max Pooling** (to capture positive signal peaks/backscatter) and **Global Min Pooling** (implemented as `Max(-x)` to capture negative signal voids/shadows).
    *   **Result:** The output for each stage is $64_{max} + 64_{min} = 128$ features. This preserves the exact same dense layer input size as the single-polarity baseline (Idea 30), preventing parameter explosion while explicitly modeling the **Signal-to-Shadow Contrast** (Cite solution_lesson_node_00102).
*   **Feature Fusion (Raw Scale):** The pooled vectors are concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment with the raw radar signal (Cite solution_lesson_node_00057).
*   **Classification Head:** A single hidden layer: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** We use **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, ensuring consistent regularization on the raw scalar input without the instability of schedulers (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Regularization:** We explicitly **exclude** DropBlock and Spatial Dropout, as previous experiments showed these were destructive for feature maps of this resolution (Cite solution_lesson_node_00126, solution_lesson_node_00069). We rely on L2 decay and Head Dropout.
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
