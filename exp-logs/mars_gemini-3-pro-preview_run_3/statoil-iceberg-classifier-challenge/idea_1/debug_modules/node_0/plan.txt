This script demonstrates the end-to-end workflow for the Iceberg Classification task using the provided library modules.

### Implementation Strategy
1.  **Configuration Override**: We modify the `Config` class attributes to enable a fast demonstration mode. This includes setting a small `DEBUG_SAMPLE_SIZE` (200 samples) and reducing `NUM_EPOCHS` to 2.
2.  **Setup**: We call `Config.setup()` to ensure the necessary output directories (working, submission) exist.
3.  **Data Loading**: We use `library.dataset.get_data` to load the dataset. We explicitly pass `load_cached_data=False` to trigger the raw data processing logic (reading JSONs, flattening images, scaling) and ensure the pipeline works from scratch. We also pass the debug parameters explicitly to override default argument bindings.
4.  **Validation**: We perform assertion checks on the loaded data tensors to verify shapes (Input: 11250 features, Target: 1 scalar) and consistency between features and labels.
5.  **Model & Training**: We instantiate the `SimpleFCN` model and the `Trainer`. We run the training loop using `trainer.fit()`, explicitly passing the reduced epoch count.
6.  **Prediction**: We generate predictions on the test set using `trainer.predict()`.
7.  **Submission Verification**: Finally, we load the generated submission CSV to verify its existence, dimensions (matching the test set size), and content validity (probabilities between 0 and 1).
