Implementation Strategy:
1.  **Data Enhancement**: I will modify `library/model.py` to create a 3rd input channel representing the average of Band 1 and Band 2. This provides the model with explicit combined signal intensity, which is often a strong discriminator for icebergs.
2.  **Augmentation**: I will modify `library/dataset.py` to include `torchvision.transforms` (RandomHorizontalFlip, RandomVerticalFlip) for the training set. This addresses the small dataset size and helps the model generalize better.
3.  **Architecture Optimization**: I will update `IcebergCNN` in `library/model.py` to accept 3 input channels. Crucially, I will replace the `Flatten` operation with `Global Max Pooling`. This enforces translation invariance (detecting an iceberg anywhere in the image) and significantly reduces the parameter count in the fully connected layers, mitigating the overfitting observed in the previous run. I will also increase the filter count in the final convolutional layer to 128 to retain more semantic features before pooling.
4.  **Training Dynamics**: I will update `library/trainer.py` to include a `ReduceLROnPlateau` scheduler. This will progressively lower the learning rate when validation loss stagnates, allowing the model to settle into a better local minimum. I will also increase `NUM_EPOCHS` and `EARLY_STOPPING_PATIENCE` in `library/config.py` to give the scheduler time to work.
5.  **Conditional Submission**: I will modify `runfile.py` to strictly check if the final validation loss is lower than the baseline (0.2375) before generating the submission file.
