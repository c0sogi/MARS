# Solution: Simple Fully Connected Network (SFCN)

This approach establishes a fundamental deep learning baseline by discarding spatial inductive biases (convolutions) and feature engineering. It treats the problem as a raw high-dimensional pattern recognition task, providing a reference point to measure the value of spatial invariance (CNNs) or domain-specific features (Stats).

### Model
The architecture is a **Multi-Layer Perceptron (MLP)** designed to map raw pixel intensities directly to the class probability.
*   **Input Layer:** The 75x75x2 image volume is flattened into a single 1D vector of size 11,250.
*   **Feature Extraction Block:** The vector passes through a sequence of two Dense (Fully Connected) layers (e.g., 512 and 256 units). Each layer is followed by **Batch Normalization** (to stabilize training on the float dB data), **ReLU activation**, and **Dropout** (e.g., rate 0.4) to rigorously prevent overfitting on this small dataset.
*   **Auxiliary Integration:** The scalar `inc_angle` is concatenated with the feature vector output of the second dense layer.
*   **Output Layer:** A final Dense layer with a single unit and **Sigmoid activation** produces the iceberg probability.

### Data
*   **Imputation:** Missing values in the `inc_angle` field (marked as "na") are imputed using the median incidence angle of the training set.
*   **Normalization:** Unlike CNNs which can tolerate raw values, this MLP requires standardized inputs. The flattened pixel vectors are scaled to have zero mean and unit variance (StandardScaler) based on training set statistics.
*   **Formatting:** The JSON band lists are converted to NumPy arrays, stacked, and flattened. No data augmentation is applied, adhering to the philosophy of a strict baseline.

### Training
*   **Loss Function:** Binary Cross-Entropy (Log Loss), directly optimizing the competition metric.
*   **Optimizer:** Adam optimizer with default parameters (learning rate 1e-3 or 1e-4).
*   **Strategy:** Training utilizes **Early Stopping** monitoring the validation loss. Given the high parameter count relative to the sample size, training will likely be short (fewer than 50 epochs) before overfitting begins, ensuring a very fast runtime.

### Evaluation
*   **Inference:** The test set images are preprocessed using the statistics (mean/std) derived from the training set.
*   **Prediction:** The model performs a forward pass to output probabilities, which are written directly to the submission file.
