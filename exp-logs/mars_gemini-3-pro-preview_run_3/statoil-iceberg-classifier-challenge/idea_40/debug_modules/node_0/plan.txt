4.  **Training Loop Execution**: We will instantiate the `Trainer` class and call `fit()`. This will run a complete training cycle (training step + validation step) for the reduced number of epochs. We will verify that a model checkpoint is saved.
5.  **Inference and Submission**: We will call `predict()` on the trainer instance. We will verify that a submission CSV is generated and that it adheres to the required format (correct columns and row count corresponding to the debug dataset size).
