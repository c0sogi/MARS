Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Multi-Scale Max-Attention Network (MSMA-Net)**.

This solution synthesizes the structural innovation of **Multi-Scale Dilated Convolutions** (attempted in Idea 21 but failed due to insufficient training duration, Cite solution_lesson_node_00094) with the domain-specific **Max-Squeeze-and-Excitation** mechanism (Idea 22). It integrates these into the robust **Plain CNN** backbone using the high-regularization, long-duration training regime proven successful in Lesson 91 and Lesson 94.

# Model
The architecture is a **Custom 4-Stage Dual-Branch Convolutional Network** optimized for detecting sparse, high-intensity targets (icebergs) while capturing broader shadow context.

*   **Backbone:** The network employs a 4-stage structure to enforce aggressive spatial downsampling (75x75 $\to$ ~4x4), critical for filtering speckle noise (Cite solution_lesson_node_00046).
    *   **Dual-Branch Block:** Instead of a single convolution, each stage splits the input into two parallel branches to capture features at different scales:
        1.  **Local Branch:** `Conv2d(3x3, dilation=1, bias=True)` to capture fine-grained speckle and edge details.
        2.  **Context Branch:** `Conv2d(3x3, dilation=2, bias=True)` to capture wider context (e.g., radar shadows) without losing resolution.
        *   **Fusion:** The outputs are concatenated and passed through a `1x1 Conv` to restore the target channel width.
        *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (shadows/normalized dips) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Attention (Max-SE):** We implement a **Max-Squeeze-and-Excitation Module**. Unlike standard SE (which uses Average Pooling), this module uses **Global Max Pooling** to generate channel descriptors. This ensures that if a channel detects a high-intensity peak (iceberg) anywhere in the grid, it is strongly upweighted, preventing the signal dilution caused by averaging (Cite solution_lesson_node_00007).
    *   **Width Strategy:** Channels are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand early to preserve texture (Cite solution_lesson_node_00050) but cap width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Pooling Strategy (Selective Hierarchical):** We apply **Global Max Pooling** to the outputs of **Stage 3** and **Stage 4** only. We exclude early stages to filter noise (Cite solution_lesson_node_00035).
*   **Feature Fusion (Raw Scale):** The pooled vectors are concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment with the raw radar signal (Cite solution_lesson_node_00057).
*   **Classification Head:** A single hidden layer: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. We use high dropout (0.5) to counterbalance the increased model capacity (Cite solution_lesson_node_00091) and apply it only after activation (Cite solution_lesson_node_00017).

# Data
*   **Input:** 3-channel tensor (HH, HV, Synthetic Average) (Cite solution_lesson_node_00005).
*   **Resolution:** Native 75x75 (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Incidence angles imputed with training set median.

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** to reduce variance (Cite solution_lesson_node_00016).
*   **Optimizer:** **Adam** with a **constant learning rate** (e.g., 1e-3) (Cite solution_lesson_node_00019).
*   **Loss:** **`BCEWithLogitsLoss`** with **L2 Regularization (Weight Decay)** for stability (Cite solution_lesson_node_00036).
*   **Duration:** We explicitly set a **long training budget** (e.g., 75 epochs) with moderate patience (e.g., 12 epochs). This corrects the failure of Idea 21 by allowing the regularized, multi-scale model sufficient time to converge (Cite solution_lesson_node_00094).
*   **Initialization:** PyTorch Default (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Evaluation
*   **Inference:** Predictions are generated via a single forward pass (No TTA), as TTA degrades performance on this directional data (Cite solution_lesson_node_00041).
*   **Ensembling:** Final predictions are the average of the 5 fold models (Cite solution_lesson_node_00027).
