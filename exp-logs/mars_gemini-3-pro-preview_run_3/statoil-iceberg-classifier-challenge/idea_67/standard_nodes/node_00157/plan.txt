The implementation strategy follows the requirements to use the provided library modules for a fast baseline execution.

1.  **Initialization**: The script sets the random seed and suppresses warnings to ensure a clean, reproducible run.
2.  **Training**: It calls `library.train.train_all_folds(load_cached_data=True)` to execute the 5-fold cross-validation. This utilizes the **Leaky-Attentive Isomorphic CNN** architecture and saves the best model checkpoints for each fold.
3.  **Hold-out Validation**: To strictly adhere to the requirement of using the metadata-defined hold-out set, the script loads `metadata/val.csv`. It then filters the full training dataset (loaded via `library.data_loader`) to extract only the samples corresponding to the validation IDs. Missing incidence angles in this subset are imputed using the global median.
4.  **Ensemble Inference**: The script performs inference on this specific hold-out set by averaging the predictions from all 5 trained fold models.
5.  **Metric & Analysis**: It calculates and prints the **Log Loss** (Final Validation Metric). It then performs failure analysis by correlating the prediction error magnitude with input features (incidence angle and image band statistics).
6.  **Submission**: Finally, it checks if the validation metric is below the specified threshold (`0.1717...`). If the condition is met, it calls `library.train.generate_submission()` to create the final `submission.csv` for the test set.
