The issue is caused by Python's default argument binding behavior. The `save_checkpoint` function in `library/utils.py` defines `checkpoint_dir=Config.CHECKPOINT_DIR` as a default argument. This value is evaluated and bound once when the module is imported, capturing the initial configuration path (`./working/idea_74/checkpoints`). When `runfile.py` subsequently updates `Config.CHECKPOINT_DIR` to the demo directory (`./working/demo_execution/checkpoints`) at runtime, the `save_checkpoint` function continues to use the stale, originally bound path because it does not re-evaluate the default argument. Cite debug_lesson_10.
