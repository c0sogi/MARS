The issue is that the Cross-Validation (CV) loop in `get_dataloaders` uses the entire labeled dataset (`X_all`, `y_all`) to generate folds. However, the final evaluation in `runfile.py` uses a fixed hold-out set defined in `metadata/val.csv`. Since `X_all` contains both the training and the hold-out data, the models in the ensemble are inadvertently trained on the validation samples, causing **Data Leakage** and invalidating the final metric (Cite debug_lesson_7).

To fix this, I will modify `library/data_loader.py` to:
1.  Import `pandas` to read the metadata.
2.  In `get_dataloaders`, load `metadata/train.csv` to retrieve the indices of the samples explicitly assigned to the training set.
3.  Filter the full dataset (`X_all`) to create a subset (`X_cv`) containing only these training samples.
4.  Perform the Stratified K-Fold split on this `X_cv` subset, ensuring the hold-out validation set remains strictly unseen by the models during training.
