Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Efficient-Attentive Plain CNN (EAP-CNN)**.

This solution represents a structural evolution of the **Hybrid-Pooling SE-CNN** (Idea 27). It identifies a critical bottleneck in the previous best solution: the standard Squeeze-and-Excitation (SE) block reduces channel dimensionality by a factor of 16 (e.g., 128 $\to$ 8), forcing the model to compress complex channel interdependencies into an overly narrow latent space. This solution replaces the SE module with **Efficient Channel Attention (ECA)**, which models cross-channel interactions using a local 1D convolution without dimensionality reduction. This change maintains the robust "Plain CNN" backbone and "Hybrid Pooling" philosophy (Avg for Attention, Max for Readout) while removing the information bottleneck and further reducing parameter count to prevent overfitting.

# Model
The architecture is a **Custom 4-Stage Convolutional Network** optimized for efficient, full-rank channel attention.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the final pooling layer (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **ECA Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy (Early Expansion):** The channel dimensions are strictly configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand to 128 channels immediately in the second block to preserve low-level texture details (Cite solution_lesson_node_00050) but cap the width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Structural Innovation (Efficient Channel Attention):** We replace the SE Module with an **ECA Module**.
    *   **Mechanism:** The module performs **Global Average Pooling** (Cite solution_lesson_node_00104) followed by a **1D Convolution** (kernel size $k=3$) across the channel dimension, and finally a Sigmoid activation.
    *   **Rationale:** Unlike standard SE, which compresses channels (128 $\to$ 8), ECA maintains full channel resolution, allowing the network to model local cross-channel dependencies (e.g., between HH, HV, and Synthetic bands) without information loss. Simultaneously, it removes the dense fully connected layers of SE, reducing the parameter count and aligning with the "Simplicity" lesson (Cite solution_lesson_node_00031).
*   **Readout Strategy (Max Pooling):** At the end of the 4th stage, we use **Global Max Pooling** to extract the final feature vector. This captures the sparse, high-intensity peak signals characteristic of icebergs (Cite solution_lesson_node_00007, solution_lesson_node_00102).
*   **Feature Fusion (Raw Scale):** The flattened vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment (magnitude ~30-45) with the raw radar signal features (dB) (Cite solution_lesson_node_00057).
*   **Classification Head:** A single hidden layer: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after the activation to preserve feature integrity (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** to ensure numerical stability and prevent overfitting to noise (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 10-12) to allow the regularized model to converge (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
