The issue is that the `ids_test` array contains string identifiers, which NumPy stores as an object array. Modern versions of NumPy default to `allow_pickle=False` in `np.load()` for security, which prevents loading these object arrays. To fix this, I will explicitly set `allow_pickle=True` when loading the `ids_test` file in `library/data_loader.py`. Cite debug_lesson_1.
