This script demonstrates the usage of the provided library modules for the Ship vs. Iceberg classification task. It performs the following steps:

1.  **Configuration Override**: Adjusts the global `Config` to run in a lightweight "Debug" mode (fewer samples, fewer epochs, fewer folds) to ensure the script completes quickly.
2.  **Component Verification**:
    *   Instantiates the `DSN_CNN` model and verifies the forward pass with dummy tensors.
    *   Loads a small subset of data using `get_data_loaders` and verifies the shape of the batches produced by the `IcebergDataset`.
3.  **Pipeline Execution**: Runs the full K-Fold training and inference pipeline using `run_kfold_training`.
4.  **Result Validation**: Verifies that the submission file is generated correctly and adheres to the expected format.
