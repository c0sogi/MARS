Based on the comprehensive analysis of previous experiments and the derived lessons, I propose the **Dual-Scale Normalized Simple CNN (DSN-CNN)**.

This solution synthesizes the robust "Simple CNN" backbone (Idea 4) with the feature-richness of "Hierarchical Pooling" (Idea 7), while explicitly correcting the architectural flaws that caused previous iterations to fail (specifically: early channel bottlenecks, noise propagation from shallow layers, and ill-conditioned metadata fusion).

# Model
The architecture is a **Selective Hierarchical Convolutional Neural Network** designed to capture multi-scale signal peaks while strictly filtering out high-frequency speckle noise.

*   **Backbone:** The network retains the robust 4-block structure of the baseline. Each block consists of `Conv2d` $\to$ `BatchNorm` $\to$ `ReLU` $\to$ `MaxPool2d`.
    *   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We explicitly expand to 128 channels immediately in the second block ("Early Expansion") to preserve low-level texture details (Cite solution_lesson_node_00050), while capping the maximum width at 128 to prevent overfitting (Cite solution_lesson_node_00026).
    *   **Spatial Reduction:** The network aggressively downsamples the 75x75 input to a 4x4 grid at the final layer, ensuring noise is filtered via convolution before aggregation (Cite solution_lesson_node_00046).
*   **Structural Innovation (Selective Hierarchical Pooling):** We implement a **Partial Feature Pyramid**. Instead of pooling only the final layer (Baseline) or all layers (Idea 7), we apply **Global Max Pooling** to the outputs of **Block 3** and **Block 4**.
    *   **Rationale:** Block 3 (approx. 9x9 spatial grid) captures medium-scale context. Block 4 (approx. 4x4 spatial grid) captures abstract existence features. By concatenating these, we enrich the representation. Crucially, we **exclude** Block 1 and Block 2 from the pooling, as previous experiments proved that early-layer features in SAR data are dominated by speckle noise (Cite solution_lesson_node_00035).
    *   **Pooling Type:** We strictly use **Global Max Pooling** to preserve the sparse, high-intensity peak signals characteristic of icebergs (Cite solution_lesson_node_00007).
*   **Feature Fusion (Normalized):** The pooled vectors from Block 3 and Block 4 are concatenated with the **Incidence Angle**.
    *   **Correction:** Unlike previous iterations, the incidence angle is explicitly **Standard Scaled** (normalized to mean 0, std 1) before concatenation. This prevents the high-magnitude scalar (~40) from destabilizing the initialization of the dense layer (Cite solution_lesson_node_00054).
*   **Classification Head:** The fused vector passes through a **Single Hidden Layer** configuration: `Linear` $\to$ `ReLU` $\to$ `Dropout` $\to$ `Linear` $\to$ `Output`.
    *   We restrict the head to one hidden layer to limit capacity (Cite solution_lesson_node_00040).
    *   Dropout is applied *only* after the activation to preserve signal integrity (Cite solution_lesson_node_00017).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2). This composite input enriches the initial feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained. We avoid upscaling to prevent computational overhead and artifacts (Cite solution_lesson_node_00009).
*   **Preprocessing:**
    *   **Incidence Angle:** Missing values are imputed with the training median. Crucially, a `StandardScaler` is fit on the training angles and applied to both training and test angles to normalize the side-channel input (Cite solution_lesson_node_00054).
*   **Augmentation:** We use the optimized `torchvision.transforms` library for RandomHorizontalFlip and RandomVerticalFlip during training (Cite solution_lesson_node_00013).

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function & Regularization:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)**. This is crucial to prevent the instability and "confident errors" observed in unregularized runs (Cite solution_lesson_node_00036).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform). We explicitly reject manual fixed-scale initialization (Cite solution_lesson_node_00045) and do not freeze any layers (Cite solution_lesson_node_00012).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
