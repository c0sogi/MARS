Implementation strategy:
1.  **Setup**: Initialize the environment, set random seeds for reproducibility, and detect the available computation device (GPU/CPU).
2.  **Training**: Execute the provided `train.run_training()` function. This handles the 5-fold cross-validation loop, training the `SPPCNN` model for each fold, and saving the best checkpoints to the disk.
3.  **Validation & OOF Generation**: Iterate through each fold again to generate Out-Of-Fold (OOF) predictions on the validation sets using the saved best checkpoints. Collect predictions, targets, and metadata (incidence angles, image statistics) into a unified dataset.
4.  **Metric Calculation**: Compute the global Log Loss on the aggregated OOF predictions to determine the "Final Validation Metric".
5.  **Failure Analysis**: Calculate the absolute error for each validation sample. Compute and print the Pearson correlation between the error magnitude and input features (Incidence Angle, Band 1 Mean, Band 2 Mean) to identify systematic weaknesses.
6.  **Submission**: Compare the final validation metric against the specified threshold (0.1806...). If the model performs well enough, load the test dataset and generate predictions using an ensemble (average) of all 5 trained models. Save the results to `submission.csv` in the required format.
