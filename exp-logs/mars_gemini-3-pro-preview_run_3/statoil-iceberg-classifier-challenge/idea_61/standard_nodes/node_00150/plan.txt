5.  **Final Validation & Failure Analysis**: Load the best model checkpoint. Perform a full inference pass on the validation set to collect probabilities, targets, and incidence angles. Calculate the final Log Loss metric manually to ensure precision and print it in the required format. Compute the correlation between the absolute prediction error and the incidence angle to identify systematic failure modes.
6.  **Submission Generation**: Compare the final validation metric against the specified threshold (0.17174...).
