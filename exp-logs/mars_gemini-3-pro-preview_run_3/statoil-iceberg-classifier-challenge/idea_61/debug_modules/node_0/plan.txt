This script demonstrates the end-to-end usage of the provided library components for the Iceberg vs. Ship classification task.

It performs the following steps:
1.  **Configuration Override**: Adjusts hyperparameters in `Config` (epochs, batch size) to ensure the demonstration runs quickly.
2.  **Data Loading**: Uses `get_dataloaders` to prepare training, validation, and test data loaders, leveraging the pre-generated metadata and caching mechanisms.
3.  **Model Initialization**: Instantiates the `EA_IDPH_CNN` model and moves it to the appropriate computing device (CPU/GPU).
4.  **Training & Evaluation**: Runs a short training loop (2 epochs) using the `train_one_epoch` and `evaluate` functions from the engine, verifying that the loss is calculated and the model learns.
5.  **Inference**: Generates predictions on the test set.
6.  **Submission**: Formats the predictions into a CSV file matching the submission requirement.
7.  **Validation**: Includes assertions to verify data shapes, model output dimensions, and the integrity of the generated submission file.
