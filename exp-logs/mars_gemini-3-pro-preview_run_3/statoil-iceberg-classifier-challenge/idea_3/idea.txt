# Solution: Custom DenseNet with Global Max Pooling

### Model
The proposed architecture introduces a **Densely Connected Convolutional Network (DenseNet)** designed specifically for the 75x75 radar input. This represents a structural innovation over the previous simple stacked CNNs by introducing "Dense Blocks," where each layer receives feature maps from all preceding layers. This architecture promotes feature reuse and gradient flow, which is particularly effective for extracting complex features from small datasets without exploding the parameter count.

*   **Input Specification:** The model accepts a 3-channel image tensor (75x75x3).
*   **Backbone:** The network consists of a sequence of 3 Dense Blocks separated by Transition Layers (convolution + pooling).
*   **Pooling Strategy:** Following the final Dense Block, **Global Max Pooling** is applied. This is explicitly selected over Global Average Pooling (standard in DenseNets) to preserve the high-intensity peak signals characteristic of icebergs, preventing the signal dilution observed in previous experiments (Cite solution_lesson_node_00007).
*   **Feature Fusion:** The flattened output from the pooling layer is concatenated with the scalar **incidence angle**.
*   **Classification Head:** The fused vector is passed through a wide Fully Connected layer (e.g., 512 units) before the final output. This width is maintained to avoid the information bottleneck identified when channel dimensions are reduced too aggressively before classification (Cite solution_lesson_node_00006).

### Data
*   **Channel Composition:** The input data is preprocessed to form 3 channels: the HH band, the HV band, and a **synthetic average band** ((HH+HV)/2). This composite channel has been proven to enrich the feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native 75x75 resolution is preserved. The images are **not upscaled**, avoiding the computational overhead and artifact introduction associated with adapting to ImageNet-sized backbones (Cite solution_lesson_node_00009).
*   **Augmentation:** Data augmentation is performed using the optimized **`torchvision.transforms`** library (specifically RandomHorizontalFlip and RandomVerticalFlip). This ensures stability and efficiency, avoiding the pitfalls of manual tensor manipulation (Cite solution_lesson_node_00013).

### Training
*   **Initialization:** The model is trained **from scratch** using standard weight initialization (e.g., Kaiming He). No layers are frozen at any point. This strictly adheres to the finding that freezing randomly initialized layers prevents feature learning (Cite solution_lesson_node_00012).
*   **Optimization:** The model is optimized using the Adam optimizer with Binary Cross-Entropy (Log Loss).
*   **Validation:** A **5-Fold Cross-Validation** strategy is employed to maximize the utility of the limited training data and provide a robust estimate of model performance.

### Evaluation
*   **Ensembling:** For the final submission, the model iterates through the test set, and the final probability for each image is calculated as the **average of the predictions** from the 5 models trained during the cross-validation phase.
