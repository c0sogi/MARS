Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and set random seeds for reproducibility. Override `Config.NUM_EPOCHS` to 25 to ensure the training completes quickly while maintaining sufficient convergence.
2.  **Training**: Execute a 5-Fold Cross-Validation loop. For each fold, call `run_training_fold` which trains the `CustomDenseNet` model and saves the best checkpoint based on validation loss.
3.  **Validation**: Load the specific hold-out validation set defined in `metadata/val.csv` using the `original_index` to retrieve the correct samples from the cached training data.
4.  **Inference**: Perform inference on this hold-out set using an ensemble of the 5 trained models (averaging their probability outputs).
5.  **Evaluation**: Calculate the Log Loss metric on the hold-out set and print it in the required format.
6.  **Failure Analysis**: Calculate and print the correlation between the prediction error magnitude and input features (Incidence Angle and Mean Image Intensity) to identify systematic errors.
7.  **Submission**: If the calculated validation metric is below the threshold (0.2089...), generate predictions for the test set using the model ensemble and save the `submission.csv` file.
