The following script implements the end-to-end orchestration for the Iceberg vs. Ship classification task.

### Strategy Outline
1.  **Environment Setup**: Initializes random seeds and detects the compute device (GPU/CPU).
2.  **Data Loading**: Loads the pre-processed training and validation datasets from the cache (or raw files if cache is missing) using the provided library functions.
3.  **Cross-Validation Preparation**: Merges the training and validation sets to perform a robust 5-Fold Stratified Cross-Validation (CV). This ensures all data is utilized for training the ensemble.
4.  **Training Loop**: Iterates through 5 folds. For each fold:
    *   Splits the data into training and validation subsets.
    *   Trains the `MicroSEResNet` model using `run_fold_training` with early stopping and a limited epoch count (35) to satisfy the "fast baseline" requirement.
    *   Reloads the best model checkpoint and generates Out-Of-Fold (OOF) predictions on the validation subset using Test-Time Augmentation (TTA).
5.  **Validation**: Calculates the Log Loss metric on the aggregated OOF predictions to evaluate global performance.
6.  **Failure Analysis**: Computes the absolute error of predictions and calculates the Pearson correlation between the error and key input features (incidence angle, band statistics) to identify potential weaknesses.
7.  **Submission**: If the final validation metric is below the specified threshold (0.181459...), generates a submission file by ensembling predictions from all 5 trained models on the test set.
