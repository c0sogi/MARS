Implementation strategy:
1.  **Configuration**: I will use the provided `Config` class but override `NUM_EPOCHS` to 30 to ensure a fast execution while maintaining enough training steps for convergence. I will keep `MAX_SAMPLES` as `None` to use the full dataset (which is small, ~1600 samples) to ensure the validation metric is meaningful and meets the strict threshold.
2.  **Data Loading**: I will use `process_and_cache_data` to load the preprocessed tensors. This function handles the concatenation of training and validation metadata to form the full dataset for Cross-Validation, and imputes missing incidence angles.
3.  **Cross-Validation Loop**: I will implement a standard 5-Fold Cross-Validation loop. For each fold:
    *   Generate Train/Val DataLoaders using `get_cv_loaders`.
    *   Train the `IcebergSEResNet` model using `fit_fold`.
    *   Load the best checkpoint for the current fold.
    *   Perform inference on the validation fold to generate Out-Of-Fold (OOF) predictions.
    *   Perform inference on the test set and accumulate predictions.
4.  **Evaluation**: I will calculate the Log Loss on the concatenated OOF predictions against the ground truth labels. This provides the "Final Validation Metric".
5.  **Failure Analysis**: I will calculate the absolute error for each sample and compute the Pearson correlation between the error magnitude and key features (Incidence Angle, Band Means, Band Stds) to identify sources of systematic error.
6.  **Submission**: If the final metric is below the specified threshold (0.181459...), I will average the test predictions across all 5 folds and save the `submission.csv`.
