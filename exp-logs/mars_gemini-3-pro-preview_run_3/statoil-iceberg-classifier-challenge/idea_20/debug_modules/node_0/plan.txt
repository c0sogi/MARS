### Implementation Strategy

1.  **Configuration Override**: We will modify the `Config` class attributes at runtime to adapt the execution for a quick demonstration. This includes enabling `DEBUG` mode to use a tiny subset of data (20 samples), reducing `EPOCHS` to 2, and setting a dedicated `WORKING_DIR` to avoid conflicts with existing cache files.
2.  **Data Loading Verification**: We will invoke `get_loaders` to generate PyTorch DataLoaders. We will explicitly verify the shape and data types of a single batch (Images, Angles, Labels) to ensure the `IcebergDataset` and `_process_json_to_numpy` logic functions correctly.
3.  **Model Instantiation**: We will instantiate the `SelectiveSECNN` model and move it to the appropriate device (GPU/CPU). We will perform a dummy forward pass with the batch retrieved earlier to confirm the architecture handles the input dimensions and produces the correct output shape (logits).
4.  **Training Simulation**: We will execute `train_fold` for a single fold. This functions as an integration test for `train_one_epoch`, `validate`, loss calculation, and checkpoint saving. We will assert that the returned model is valid and the best score is a reasonable float value.
5.  **Inference Check**: We will manually iterate through the `test_loader` using the trained model to generate predictions. We will verify that the number of predictions matches the number of test IDs and that probabilities are within the valid [0, 1] range.
6.  **Reproducibility**: We will use `seed_everything` at the start to ensure deterministic behavior.
