Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose the **Stabilized Selective-Hierarchical SE-CNN**.

This solution represents the structural convergence of the most promising architectural components identified throughout the experiment history. It synthesizes the **Selective Hierarchical Pooling** (which showed high potential in Cite solution_lesson_node_00034 but failed due to noise inclusion in Cite solution_lesson_node_00035) with the **Squeeze-and-Excitation** attention mechanism (proven to enhance the base learner in Cite solution_lesson_node_00027). Crucially, it implements these advanced features within a rigorous stability framework—specifically correcting the initialization, scaling, and bias retention errors that caused previous complex models to fail (Cite solution_lesson_node_00078, Cite solution_lesson_node_00057, Cite solution_lesson_node_00076).

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** with Multi-Scale Feature Aggregation.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly choose this over ResNets to enforce aggressive sequential downsampling, which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `ReLU` $\to$ **SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers. Removing them was shown to negatively alter initialization dynamics and degrade performance (Cite solution_lesson_node_00076).
    *   **Attention:** An **SE Module** (Squeeze-and-Excitation, reduction ratio 16) is integrated into every block. This allows the network to dynamically recalibrate the importance of the HH, HV, and synthetic channels (Cite solution_lesson_node_00027).
    *   **Width Strategy (Early Expansion):** The channel dimensions are strictly configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We explicitly expand to 128 channels immediately in the second block to preserve low-level texture details (Cite solution_lesson_node_00050), while capping the maximum width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Structural Innovation (Selective Hierarchical Pooling):** We implement a **Partial Feature Pyramid** to capture signal peaks at multiple scales.
    *   We apply **Global Max Pooling** to the output of **Block 3** (medium-scale features, ~9x9 grid) and **Block 4** (abstract features, ~4x4 grid).
    *   We explicitly **exclude** Block 1 and Block 2 from pooling to prevent high-frequency speckle noise from bypassing the depth hierarchy (Cite solution_lesson_node_00035).
    *   **Pooling Type:** Global Max Pooling is strictly used to capture sparse, high-intensity signal peaks (Cite solution_lesson_node_00007).
*   **Feature Fusion (Raw Scale):** The pooled vectors from Block 3 (128 dim) and Block 4 (128 dim) are concatenated with the scalar **incidence angle**.
    *   **Crucial Correction:** We explicitly **do not normalize** the incidence angle. We inject the raw values (~30-45) as they naturally match the magnitude of the raw radar signal features (dB), avoiding the optimization issues caused by normalization (Cite solution_lesson_node_00057) or Batch Normalization on scalars (Cite solution_lesson_node_00066).
*   **Classification Head:** The fused vector passes through a **Single Hidden Layer**: `Linear` $\to$ `ReLU` $\to$ `Dropout` $\to$ `Output`.
    *   We restrict the head to one hidden layer to limit capacity (Cite solution_lesson_node_00040).
    *   Dropout is applied *only* after the activation to preserve the integrity of the compact feature vector (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (implicitly Kaiming Uniform with LeakyReLU gain). We explicitly reject manual "textbook" Kaiming Relu initialization or Fan-Out modes, which caused instability in previous attempts (Cite solution_lesson_node_00078, Cite solution_lesson_node_00064).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2). This composite input enriches the initial feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained. We avoid upscaling to prevent computational overhead and artifacts (Cite solution_lesson_node_00009).
*   **Augmentation:** We use the optimized `torchvision.transforms` library for RandomHorizontalFlip and RandomVerticalFlip during training (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function & Regularization:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)**. This is crucial to prevent the instability and "confident errors" observed in unregularized runs (Cite solution_lesson_node_00036).
*   **Patience:** We restrict Early Stopping patience (e.g., to 8-10 epochs) to prevent validation overfitting, rejecting the extended patience that caused degradation in previous experiments (Cite solution_lesson_node_00071).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
