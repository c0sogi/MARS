The implementation strategy follows the requirements to create a fast baseline using the "Stabilized Selective-Hierarchical SE-CNN" idea.

1.  **Setup and Data Loading**: The script initializes the environment with a fixed random seed for reproducibility. It loads the pre-processed data (training, hold-out validation, and test sets) using `library.data_loader._load_and_process_data`, leveraging the cached numpy arrays for speed.
2.  **5-Fold Cross-Validation**: To handle the small dataset size and high variance, the script performs 5-Fold Cross-Validation on the training portion of the data (80% of total). It uses `sklearn.model_selection.KFold` to generate splits. For each fold, it creates `IcebergDataset` instances (applying augmentations to the training subset) and trains the model using `library.trainer.train_fold`. The best model from each fold is stored in memory.
3.  **Ensemble Inference**: A `predict` helper function is defined to run inference. It iterates through the list of 5 trained models, computes probabilities for each batch, and averages them to produce a robust ensemble prediction.
4.  **Validation Assessment**: The ensemble is evaluated on the strictly hold-out validation set (the remaining 20% of data defined in metadata). The Log Loss is calculated and printed as the `Final Validation Metric`.
5.  **Failure Analysis**: The script calculates the absolute error for each sample in the hold-out set. It then computes statistical features (mean, std) for the image bands and correlates these features (along with incidence angle) with the error magnitude to identify sources of model failure.
6.  **Submission Generation**: If the final validation metric is below the specified threshold, the script proceeds to generate predictions for the test set using the full ensemble and saves the results to `submission.csv`.
