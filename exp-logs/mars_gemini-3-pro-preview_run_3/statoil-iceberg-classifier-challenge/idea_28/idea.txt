Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Selective Hierarchical Hybrid-SE CNN (SHH-SE-CNN)**.

This solution represents the structural synthesis of the most effective architectural components identified to date. It combines the robust **Plain CNN** backbone (Idea 4/20) with the **Hybrid Pooling** strategy of Idea 27 (Average Pooling for Attention, Max Pooling for Classification). Crucially, it re-introduces **Selective Hierarchical Aggregation** (Idea 11/15) to capture multi-scale signal peaks, but implements it within the rigorous stability framework (LeakyReLU, Bias Retention, Raw Scale Fusion) that was missing in previous hierarchical attempts.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** with Multi-Scale Feature Aggregation.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy (Early Expansion):** The channel dimensions are strictly configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand to 128 channels immediately in the second block to preserve low-level texture details (Cite solution_lesson_node_00050) but cap the width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Structural Innovation 1 (Hybrid Attention):** Within the **SE Module**, we use **Global Average Pooling** for the squeeze operation. This acts as a low-pass filter, providing a robust statistical summary of the channel distribution without overfitting to local noise spikes, correcting the failure of Max-SE (Cite solution_lesson_node_00104, solution_lesson_node_00106).
*   **Structural Innovation 2 (Selective Hierarchical Readout):** We implement a **Partial Feature Pyramid** for the classification readout.
    *   We apply **Global Max Pooling** to the output of **Stage 3** (medium-scale features, ~9x9 grid) and **Stage 4** (abstract features, ~4x4 grid).
    *   We explicitly **exclude** Stage 1 and Stage 2 to prevent high-frequency speckle noise from bypassing the depth hierarchy (Cite solution_lesson_node_00035).
    *   **Pooling Type:** Global Max Pooling is strictly used for the readout to capture the sparse, high-intensity peak signals characteristic of icebergs (Cite solution_lesson_node_00007).
*   **Feature Fusion (Raw Scale):** The pooled vectors from Stage 3 (128 dim) and Stage 4 (128 dim) are concatenated with the scalar **incidence angle**.
    *   **Scale Alignment:** We explicitly **do not normalize** the incidence angle. We inject the raw values (~30-45) as they naturally match the magnitude of the raw radar signal features (dB), avoiding the optimization issues caused by normalization (Cite solution_lesson_node_00057).
*   **Classification Head:** The fused vector (257 dims) passes through a **Single Hidden Layer**: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`.
    *   We restrict the head to one hidden layer to limit capacity (Cite solution_lesson_node_00040).
    *   Dropout is applied *only* after the activation to preserve the integrity of the compact feature vector (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In). We explicitly avoid manual fixed scales or `fan_out` modes (Cite solution_lesson_node_00078, solution_lesson_node_00064).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip during training (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function & Regularization:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** to ensure numerical stability and prevent overfitting to noise (Cite solution_lesson_node_00036).
*   **Duration:** We set a sufficient training budget (e.g., 50-75 epochs) with moderate patience (e.g., 10-12) to allow the regularized model to converge (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
