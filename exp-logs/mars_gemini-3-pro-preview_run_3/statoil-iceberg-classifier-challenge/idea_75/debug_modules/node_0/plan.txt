The following script demonstrates the end-to-end usage of the provided library components for the Iceberg vs. Ship classification task.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class to set up a "demo" environment. This includes enabling `DEBUG` mode to use a tiny subset of data (40 samples), reducing the number of epochs to 1, and setting a small batch size. This ensures the script executes within seconds while still exercising all code paths.
2.  **Environment Setup**: We initialize the random seeds and directories using `library.utils` and `library.config`.
3.  **Data Pipeline Verification**: We utilize `get_fold_loaders` to load training data. We explicitly fetch a batch to verify the shapes of the image tensors (N, 3, 75, 75), angle tensors (N,), and labels. We also verify the test loader.
4.  **Model Architecture Verification**: We instantiate the `CCTICNN` model, pass the fetched batch through it, and assert that the output shape matches the expected `(Batch_Size, 1)` logits.
5.  **Training Loop Execution**: We execute `run_fold(0)`, which runs the full training pipeline (training step, validation step, checkpointing) for the configured number of epochs (1). We assert that it returns a valid loss value.
6.  **Inference & Submission**: We run a quick inference pass on the test set using the trained model (or initialized model in this context) to demonstrate how to generate the submission file format required by the task.
