Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Inter-Stage Calibrated Isomorphic CNN (ISCI-CNN)**.

This solution represents a structural synthesis of the most effective components identified to date, explicitly correcting the "Leakage" flaw identified in **Lesson 147** while introducing a novel **Inter-Stage Calibration** mechanism. This mechanism resolves the independence assumption of the previous "Hierarchical Readout" (Idea 58) by allowing the high-level semantic context of the final stage to dynamically filter the detailed texture features of the penultimate stage *before* pooling. This is integrated into the robust **Plain CNN** backbone with **Hybrid SE** and **Isomorphic Dual-Polarity Readout**, strictly adhering to the capacity and stability constraints derived from previous failures.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed, context-aware feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Hybrid SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).
    *   **Attention:** **Hybrid SE** uses Global Average Pooling for the squeeze operation (low-pass filter) with reduction ratio $r=16$ (Cite solution_lesson_node_00104, solution_lesson_node_00146).

*   **Structural Innovation (Inter-Stage Calibration):**
    *   **Objective:** Enhance the selectivity of Stage 3 features using Stage 4 context without spatial upsampling (which introduces noise).
    *   **Mechanism:**
        1.  Extract **Stage 4 Features** ($X_4$) and **Stage 3 Features** ($X_3$).
        2.  **Context Extraction:** Compute the global context of Stage 4 via Global Average Pooling: $c_4 = \text{GAP}(X_4)$.
        3.  **Calibration Weights:** Pass $c_4$ through a lightweight MLP (Linear $\to$ LeakyReLU $\to$ Linear $\to$ Sigmoid) to generate channel-wise gates $g$.
        4.  **Calibration:** Re-weight Stage 3 features: $X_3' = X_3 \odot g$.
    *   **Rationale:** This allows the abstract "object presence" detected in Stage 4 to suppress irrelevant background textures in Stage 3 *before* the readout, improving the Signal-to-Clutter ratio of the hierarchical features.

*   **Readout (Corrected Decoupled Isomorphic):**
    *   We extract features from **Stage 3 (Calibrated)** and **Stage 4**.
    *   **Decoupled Projections:** Use separate 1x1 Convs for Stage 3 (`Proj3`) and Stage 4 (`Proj4`) (Cite solution_lesson_node_00144).
    *   **Isomorphic Dual-Polarity:**
        *   **Stage 3:** `Proj3(X_3')` $\to$ **Global Max Pooling** + **Global Min Pooling**.
        *   **Stage 4:** `Proj4(X_4)` $\to$ **Global Max Pooling** + **Global Min Pooling**.
    *   **Constraint:** Max and Min pooling share the *same* projection within a stage (Cite solution_lesson_node_00142).
    *   **Result:** A 256-dimensional vector that captures **Signal-to-Shadow Contrast** (Cite solution_lesson_node_00134, solution_lesson_node_00124).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle (Cite solution_lesson_node_00057).

*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Leak-Free Preprocessing:**
    *   **Imputation:** We explicitly calculate the median incidence angle **only on the training fold indices** and apply it to the validation fold. This corrects the data leakage identified in **Lesson 147**.

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
