Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Isomorphic Dual-Polarity Hierarchical CNN (IDPH-CNN)**.

This solution is a structural synthesis designed to resolve the specific trade-off identified between **Lesson 102** (the physical necessity of capturing "Shadow" information via Min-Pooling) and **Lesson 124** (the strict capacity constraints of the classifier head). Previous attempts to capture shadows failed because they either exploded the parameter count (leading to overfitting) or relied on complex regularization that was unstable. This solution introduces an **Isomorphic Projection** strategy: it replaces half of the redundant "Max-Pooled" features with "Min-Pooled" features via a learnable bottleneck, strictly maintaining the exact feature dimensionality of the successful baseline. This allows the model to capture the full **Signal-to-Shadow Contrast**—a fundamental physical discriminator in SAR—without increasing the classifier's capacity, integrated into the robust **Plain CNN** backbone.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed feature extraction under strict capacity constraints.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Hybrid SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand early to preserve texture (Cite solution_lesson_node_00050) but cap width to prevent overfitting (Cite solution_lesson_node_00026).
    *   **Attention:** Within the SE Module, we use **Global Average Pooling** for the squeeze operation. This acts as a low-pass filter, providing a robust statistical summary of the channel distribution without overfitting to local noise spikes (Cite solution_lesson_node_00104).

*   **Structural Innovation (Isomorphic Dual-Polarity Readout):**
    *   **Objective:** Capture **Peaks** (Icebergs) and **Shadows** (Signal Voids) from Stages 3 and 4 while keeping the dense layer input size exactly **256** (matching the baseline).
    *   **Mechanism:**
        1.  **Isomorphic Projection:** At the output of **Stage 3** (128ch) and **Stage 4** (128ch), we apply a **1x1 Convolution** to compress the channel dimension to **64**. This learnable bottleneck forces the network to select the most discriminative subspaces.
        2.  **Dual-Polarity Pooling:** On these 64-channel maps, we apply both **Global Max Pooling** (Peaks) and **Global Min Pooling** (Shadows, implemented as `Max(-x)`).
        3.  **Aggregation:**
            *   Stage 3 contribution: $64_{max} + 64_{min} = 128$ features.
            *   Stage 4 contribution: $64_{max} + 64_{min} = 128$ features.
    *   **Result:** The total image feature vector size is **256**. This creates a feature space that is structurally identical (isomorphic) to the baseline's "Stage 3 Max (128) + Stage 4 Max (128)" readout, but semantically enriched to explicitly model the **Signal-to-Shadow Contrast** (Cite solution_lesson_node_00102).

*   **Feature Fusion (Raw Scale):** The 256-dim feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment with the raw radar signal (Cite solution_lesson_node_00057).

*   **Classification Head:** A single hidden layer: `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Linear(256 -> 1)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** We use **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from the adaptive gradient updates, ensuring consistent regularization on the raw scalar input without the instability of schedulers (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** to ensure numerical stability and prevent overfitting to noise (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) to allow the regularized model to converge (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
