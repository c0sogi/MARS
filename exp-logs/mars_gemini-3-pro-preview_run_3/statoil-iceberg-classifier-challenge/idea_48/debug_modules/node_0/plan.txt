This script demonstrates the end-to-end usage of the provided machine learning library for the Iceberg Classification task. It performs the following steps:

1.  **Configuration & Monkey Patching**: Modifies global constants (e.g., `NUM_EPOCHS`, `CACHE_DIR`) across the library modules to ensure the demonstration runs quickly (2 epochs) and uses a separate working directory.
2.  **Data Loading**: Uses `library.config.load_and_process_data` to process the raw JSON data into NumPy arrays, verifying shapes and data integrity.
3.  **Dataset Verification**: Instantiates `IcebergDataset` directly to verify the data retrieval logic.
4.  **Model Verification**: Instantiates the `IDPH_CNN` model and performs a dummy forward pass to confirm output shapes.
5.  **Training Demonstration**: Executes a single fold of training using `library.train_eval.run_fold`, confirming that the training loop runs and a model checkpoint is saved.
6.  **Inference Demonstration**: Loads the saved checkpoint and generates predictions on a batch of test data using the `get_test_loader` utility.
