Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Contrast-Aware Feature-Pyramid CNN (CAFP-CNN)**.

This solution represents a structural evolution of the **Selective Hierarchical Hybrid-SE CNN** (Idea 30). It addresses the physical limitation identified in Lesson 102: while Global Max Pooling captures iceberg peaks, it ignores the "Shadow" (signal void) information which is a critical discriminator in SAR imagery. Previous attempts to capture shadows (Idea 40/41) failed due to parameter explosion in the classifier head (Cite solution_lesson_node_00124). This solution solves that trade-off by introducing a **Feature Pyramid Fusion** neck. By fusing the abstract features of Stage 4 with the spatial details of Stage 3 *convolutionally* before pooling, we can compress the feature representation. This allows us to afford **Dual-Polarity Pooling** (capturing both Peaks and Shadows) within the same parameter budget as the baseline, explicitly modeling the Signal-to-Clutter contrast.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** with a Top-Down Feature Pyramid and Dual-Polarity Readout.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Hybrid SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).
    *   **Attention:** **Hybrid SE** uses Global Average Pooling for the squeeze operation (low-pass filter) to be robust to noise (Cite solution_lesson_node_00104).
*   **Structural Innovation 1 (Feature Pyramid Fusion):**
    *   Instead of concatenating the pooled outputs of Stage 3 and Stage 4 directly (which doubles dimensions), we perform **Top-Down Fusion**.
    *   We upsample the **Stage 4** feature map (4x4, 128ch) to match **Stage 3** (9x9, 128ch) and concatenate them.
    *   We apply a **1x1 Convolution** (256 $\to$ 128 channels) followed by BatchNorm and LeakyReLU.
    *   **Rationale:** This fuses the semantic abstraction of Stage 4 with the spatial detail of Stage 3 into a compact 128-channel representation, respecting the depth hierarchy (Cite solution_lesson_node_00035).
*   **Structural Innovation 2 (Dual-Polarity Readout):**
    *   On the fused feature map, we apply both **Global Max Pooling** (Peak/Backscatter) and **Global Min Pooling** (Shadow/Void, implemented as `Max(-x)`).
    *   **Rationale:** This explicitly captures the **Signal-to-Shadow Contrast**, a key physical property of icebergs, without the signal washout of Average Pooling (Cite solution_lesson_node_00102).
*   **Feature Fusion (Raw Scale):** The pooled vectors ($128_{max} + 128_{min} = 256$) are concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle (Cite solution_lesson_node_00057).
*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`.
    *   We restrict the hidden dimension to 256 to strictly limit capacity, keeping the total parameter count (~66k) identical to the robust baseline (Cite solution_lesson_node_00124, solution_lesson_node_00040).
*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Median imputation for incidence angles.

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing the fusion of the raw scalar input (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
