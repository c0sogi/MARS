1.  **Setup and Data Loading**: Initialize the environment and random seeds using the provided `Config` and `library` modules. Load the training, validation, and test datasets separately using `load_dataset`. This strictly adheres to the requirement of using the specific hold-out validation set defined in the metadata.
2.  **Ensemble Training**: To ensure robustness and achieve the high performance required (Log Loss < 0.1806), train an ensemble of 5 `AAHACNN` models. Each model is trained on the full training set with a different random seed. The validation set is used for early stopping to prevent overfitting.
3.  **Validation and Metric Calculation**: Load the best saved state for each of the 5 models and generate predictions on the validation set. Average these predictions (bagging) to get the final ensemble prediction. Calculate the Log Loss on these averaged predictions and print it in the exact required format.
4.  **Failure Analysis**: Compute the absolute error between the ensemble predictions and the ground truth. Calculate the correlation between this error magnitude and input features (incidence angle, band mean/std) to identify sources of systematic error.
5.  **Submission Generation**: If the calculated validation metric is below the specified threshold, generate predictions for the test set using the same ensemble averaging method. Save the results to `submission.csv` in the required format.
