The implementation strategy involves creating a standalone script `runfile.py` that orchestrates the entire machine learning pipeline using the provided library components.

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and configure logging. We will define local training parameters (e.g., 30 epochs) to ensure the execution is fast while sufficient for convergence on this small dataset.
2.  **Data Loading**: Utilize `load_and_process_json` from `library.data` to load the training and test datasets with caching enabled. We will perform median imputation for missing incidence angles in the test set using training statistics.
3.  **Cross-Validation Training**: Implement a 5-Fold Cross-Validation loop manually (instead of using `library.train.run_training`) to allow for custom failure analysis and conditional submission logic. Inside the loop:
    *   Split data using `StratifiedKFold`.
    *   Instantiate the `CDICNN` model, `AdamW` optimizer, and `BCEWithLogitsLoss`.
    *   Train for a fixed number of epochs using `train_one_epoch` and `validate` from `library.train`.
    *   Save the best model checkpoint based on validation loss.
    *   Generate Out-Of-Fold (OOF) predictions for the validation set.
4.  **Validation Assessment**: Calculate the overall Log Loss on the aggregated OOF predictions. This metric will be printed in the required format.
5.  **Failure Analysis**: Compute the absolute error between OOF predictions and ground truth. Calculate correlations between this error and input features (Incidence Angle, Band 1 Mean, Band 2 Mean) to identify systematic weaknesses.
6.  **Conditional Submission**: Compare the final validation metric against the target threshold (0.17174082291273365). If the model performs better (lower loss), load the best checkpoints from all folds, generate test predictions, average them (ensemble), and save the `submission.csv`.
