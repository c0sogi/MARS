# Solution: Selective Hierarchical Hybrid-SE CNN with Decoupled Weight Decay

This solution represents the structural convergence of the most effective architectural components identified in the experiment history, synthesized into a unified "Best Practices" model. It combines the noise-filtering robustness of the **Plain CNN** backbone with the feature-enhancement of **Hybrid Squeeze-and-Excitation** and **Selective Hierarchical Pooling**. Crucially, it introduces **AdamW (Decoupled Weight Decay)** with a constant learning rate to resolve the optimization instability observed when fusing raw-scale metadata with regularized image features.

### Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** designed to balance noise filtering, feature recalibration, and multi-scale peak detection.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers. Removing them was shown to negatively alter initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning (Cite solution_lesson_node_00091).
    *   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand to 128 channels immediately in the second block to preserve low-level texture details (Cite solution_lesson_node_00050) but cap the width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Structural Innovation 1 (Hybrid Attention):** Within the **SE Module**, we use **Global Average Pooling** for the squeeze operation. This acts as a low-pass filter, providing a robust statistical summary of the channel distribution without overfitting to local noise spikes (Cite solution_lesson_node_00104).
*   **Structural Innovation 2 (Selective Hierarchical Readout):** We implement a **Partial Feature Pyramid** for the final classification.
    *   We apply **Global Max Pooling** to the output of **Stage 3** (medium-scale features, ~9x9 grid) and **Stage 4** (abstract features, ~4x4 grid).
    *   We explicitly **exclude** Stage 1 and Stage 2 to prevent high-frequency speckle noise from bypassing the depth hierarchy (Cite solution_lesson_node_00035).
    *   **Pooling Type:** Global Max Pooling is strictly used for the readout to capture the sparse, high-intensity peak signals characteristic of icebergs (Cite solution_lesson_node_00007).
*   **Feature Fusion (Raw Scale):** The pooled vectors from Stage 3 and Stage 4 are concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the incidence angle, preserving its natural scale alignment with the raw radar signal features (Cite solution_lesson_node_00057).
*   **Classification Head:** The fused vector passes through a **Single Hidden Layer**: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after the activation (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

### Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

### Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer (Innovation):** We use **AdamW** (Adam with Decoupled Weight Decay) with a **constant learning rate** (e.g., 1e-3).
    *   **Rationale:** Previous experiments mandated L2 Regularization (Cite solution_lesson_node_00036) but failed when combining AdamW with schedulers (Cite solution_lesson_node_00019). By using AdamW with a *constant* LR, we decouple the regularization term from the adaptive gradient updates. This ensures consistent regularization pressure on the **Incidence Angle** weights (which have different gradient dynamics than the image features), stabilizing the "Raw Scale" fusion.
*   **Loss Function:** **`BCEWithLogitsLoss`** (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) to allow the regularized model to converge (Cite solution_lesson_node_00094).

### Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
