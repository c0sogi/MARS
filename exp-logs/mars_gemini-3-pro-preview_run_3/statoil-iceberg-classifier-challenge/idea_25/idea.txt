Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Max-Attentive Plain CNN (MAP-CNN)**.

This solution represents a structural evolution of the "Stabilized Selective-Hierarchical SE-CNN" (Idea 20). It directly addresses the critical insight from Lesson 102: **Average Pooling dilutes the sparse, high-intensity signals** characteristic of icebergs in SAR imagery. By replacing the standard Squeeze-and-Excitation (which relies on Average Pooling) with a **Max-Squeeze-and-Excitation** mechanism, and strictly adhering to the robust "Plain CNN" backbone, this solution aligns the attention mechanism with the "Max Pooling Inductive Bias" proven effective for this domain.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for peak signal detection.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets/Dual-Branch architectures to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046, solution_lesson_node_00101).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Max-SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This allows the network to preserve negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy (Early Expansion):** The channel dimensions are strictly configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand to 128 channels immediately in the second block to preserve low-level texture details (Cite solution_lesson_node_00050) but cap the width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Structural Innovation (Max-Squeeze-and-Excitation):** We replace the standard SE block with a **Max-SE Module**.
    *   **Concept:** Standard SE blocks use Global *Average* Pooling to summarize channel statistics. In SAR imagery, an iceberg often appears as a few bright pixels in a sea of noise. Average pooling washes out this peak signal.
    *   **Mechanism:** The Max-SE module uses **Global Max Pooling** during the "Squeeze" phase to generate the channel descriptor. This ensures that if a channel detects a high-intensity peak (potential iceberg) anywhere in the spatial grid, the channel is strongly upweighted, aligning the attention mechanism with the domain's physics (Cite solution_lesson_node_00102, solution_lesson_node_00007).
*   **Pooling Strategy (Selective Hierarchical):** We implement a **Partial Feature Pyramid**.
    *   We apply **Global Max Pooling** to the output of **Stage 3** (medium-scale features) and **Stage 4** (abstract features).
    *   We explicitly **exclude** Stage 1 and Stage 2 to prevent high-frequency speckle noise from bypassing the depth hierarchy (Cite solution_lesson_node_00035).
    *   **Pooling Type:** Global Max Pooling is strictly used to capture sparse, high-intensity signal peaks (Cite solution_lesson_node_00007).
*   **Feature Fusion (Raw Scale):** The pooled vectors from Stage 3 and Stage 4 are concatenated with the scalar **incidence angle**.
    *   **Scale Alignment:** We explicitly **do not normalize** the incidence angle. We inject the raw values (~30-45) as they naturally match the magnitude of the raw radar signal features (dB), avoiding optimization issues caused by normalization (Cite solution_lesson_node_00057, solution_lesson_node_00066).
*   **Classification Head:** The fused vector passes through a **Single Hidden Layer**: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout` $\to$ `Output`.
    *   We restrict the head to one hidden layer to limit capacity (Cite solution_lesson_node_00040).
    *   Dropout is applied *only* after the activation to preserve the integrity of the compact feature vector (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform). We explicitly avoid manual fixed scales or `fan_out` modes (Cite solution_lesson_node_00078, solution_lesson_node_00064).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip during training (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00016).
*   **Optimizer:** We use **Adam** with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** to ensure numerical stability and prevent overfitting to noise (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous maximum epoch limit (e.g., 75) with moderate patience (e.g., 10-12). This ensures the model has sufficient duration to converge under strong regularization, addressing the failure of "Fast Baselines" (Cite solution_lesson_node_00094), while avoiding validation overfitting (Cite solution_lesson_node_00071).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image, as TTA has been shown to degrade performance on this directional SAR data (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
