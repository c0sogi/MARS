Implementation Strategy:
1.  **Environment & Data Setup**: Initialize the environment with a fixed seed and select the appropriate device (GPU). Load the preprocessed training, validation, and test datasets using the provided `get_dataloaders` function.
2.  **Cross-Validation Orchestration**: Combine the fixed training and validation splits into a single dataset to perform a rigorous 5-Fold Stratified Cross-Validation. This maximizes the use of labeled data for the ensemble.
3.  **Training Loop**: For each fold, use the `library.trainer.run_fold` function to train the `MASHCNN` model. This function handles the training loop, validation monitoring, early stopping, and saving the best model checkpoint.
4.  **OOF Inference**: Immediately after training a fold, load the best checkpoint and perform inference on the validation subset to collect Out-Of-Fold (OOF) predictions. These are essential for the global metric calculation and failure analysis.
5.  **Validation & Analysis**: Compute the overall Log Loss across all folds to determine the "Final Validation Metric". Perform failure analysis by calculating the correlation between the prediction error and the incidence angle to identify potential systematic weaknesses.
6.  **Conditional Submission**: Compare the final metric against the strict threshold (0.18120490171618245). If the model qualifies, generate predictions on the test set by averaging the outputs of all 5 fold models (Ensembling) and save the result to `submission.csv`.
