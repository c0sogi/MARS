Implementation Strategy:
1.  **Configuration Override**: We will modify the `Config` class attributes at runtime to enable `DEBUG` mode, reduce `BATCH_SIZE`, `NUM_EPOCHS`, and `NUM_FOLDS`. This ensures the script runs quickly (under a few minutes) while still exercising all code paths.
2.  **Compatibility Patching**: The provided `trainer.py` expects the data batch to be a dictionary (accessing images via `batch["image"]`) but also expects labels to be accessible via index `1` (`batch[1]`). However, `dataset.py` returns a tuple `(dict, tensor)`. To resolve this without modifying the library files, we will monkeypatch `IcebergDataset.__getitem__` to return a single dictionary containing the label under the key `1`.
3.  **Component Verification**:
    *   **Data Loading**: We will verify that the patched dataset produces batches with the correct shapes and keys.
    *   **Model**: We will instantiate `MASHCNN`, perform a forward pass with dummy data, and assert output validity.
    *   **Training Step**: We will manually run `train_one_epoch` and `validate` to verify the loss calculation and backpropagation logic.
    *   **Checkpointing**: We will save and load a checkpoint to verify state persistence.
    *   **Full Integration**: We will call the `train()` function from `trainer.py` (which runs a cross-validation loop) to demonstrate the high-level API usage.
