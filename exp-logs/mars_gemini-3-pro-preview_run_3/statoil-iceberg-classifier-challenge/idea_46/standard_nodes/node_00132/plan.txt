The following is the implementation of the orchestration script `runfile.py`. It utilizes the provided library modules to perform data loading, 5-fold cross-validation training, validation assessment, failure analysis, and submission generation.

**Strategy Outline:**
1.  **Setup & Data Loading**: Initialize the environment (seeds, device) and load the preprocessed datasets using `library.dataset.load_data`.
2.  **Data Preparation**: Merge the training and validation subsets provided by the metadata to form a complete labeled dataset. This ensures the 5-Fold Cross-Validation utilizes all available labeled data for maximum robustness.
3.  **Cross-Validation Loop**: Iterate through 5 stratified folds. For each fold:
    *   Construct `IcebergDataset` objects and DataLoaders (applying augmentations to training data).
    *   Train the `SPPCNN` model using `library.trainer.train_fold` with a limited epoch count (30) for a fast baseline.
    *   Load the best checkpoint for the current fold.
    *   Generate Out-Of-Fold (OOF) predictions for the validation split and predictions for the test set.
4.  **Validation Assessment**: Extract the OOF predictions corresponding specifically to the original hold-out validation set (defined in `metadata/val.csv`) and compute the Log Loss metric.
5.  **Failure Analysis**: Calculate correlations between the absolute prediction errors on the validation set and input features (incidence angle, mean band intensities) to identify systematic weaknesses.
6.  **Submission**: If the validation metric meets the required threshold, average the test predictions across all 5 folds and save the `submission.csv` file.
