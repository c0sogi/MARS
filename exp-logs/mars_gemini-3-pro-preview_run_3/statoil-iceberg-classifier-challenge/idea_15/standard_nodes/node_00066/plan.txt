The `NameError` is caused by a discrepancy between the class definition `SimpleCNN` and its usage as `SHSE_CNN` within the `run_training_pipeline` function in `library/model.py` (Cite debug_lesson_10). Furthermore, the script executes `run_training_pipeline()` at the global scope, causing the training logic (and the subsequent crash) to run immediately when `runfile.py` imports the module. The fix involves replacing the undefined `SHSE_CNN` with `SimpleCNN` and wrapping the pipeline execution in an `if __name__ == "__main__":` block to prevent side effects during import.
