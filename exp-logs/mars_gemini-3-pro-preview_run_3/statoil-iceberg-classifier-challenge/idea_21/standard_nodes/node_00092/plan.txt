Implementation of `runfile.py` following the strategy:

1.  **Setup**: Configures environment, seeds, and paths.
2.  **Training**: Executes 5-Fold Cross-Validation using the provided `train_kfold` function. This trains the `MSD_SE_CNN` model and saves checkpoints.
3.  **Validation**: Loads the specific validation subset defined in `./metadata/val.csv` using `load_data`. Performs inference using an ensemble of the 5 trained models.
4.  **Metric Calculation**: Computes Log Loss on the validation set.
5.  **Failure Analysis**: Calculates the correlation between prediction errors and input features (Incidence Angle, Band Means) on the validation set.
6.  **Submission**: If the validation metric meets the threshold, generates predictions for the test set using the ensemble and saves `submission.csv`.
