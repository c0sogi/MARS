Based on the empirical evidence gathered from the previous experiments, I propose a solution that evolves the successful "Simple CNN" baseline by integrating channel-wise attention mechanisms and enhancing the inference pipeline.

# Solution: Custom SE-CNN with Test-Time Augmentation

### Model
The architecture retains the core philosophy of a lightweight, custom Convolutional Neural Network trained from scratch (Cite solution_lesson_node_00009) but introduces **Squeeze-and-Excitation (SE) Blocks** to explicitly model channel interdependencies.

*   **Backbone:** A 4-layer Convolutional Network. Each block consists of a Convolution layer, Batch Normalization, ReLU activation, and a **Squeeze-and-Excitation (SE) Module**. The SE module performs a global average pooling of the feature map, passes it through a bottleneck multi-layer perceptron (reduction ratio $r=16$), and uses the sigmoid output to recalibrate (re-weight) the feature maps. This allows the network to dynamically emphasize the most informative radar bands (or the synthetic band) for each specific sample.
*   **Pooling Strategy:** Following the final convolutional block, **Global Max Pooling** is applied to extract the peak signal intensity (Cite solution_lesson_node_00007).
*   **Feature Fusion:** The flattened feature vector is concatenated with the scalar **incidence angle**.
*   **Classification Head:** The fused vector passes through a Dense layer (e.g., 512 units), followed by **Dropout** (Cite solution_lesson_node_00017), and finally a Dense output layer with Sigmoid activation. The channel width of the convolutional layers is kept wide (e.g., 64, 128) to prevent information bottlenecks (Cite solution_lesson_node_00006).

### Data
*   **Input Composition:** The input is a 3-channel tensor consisting of the HH band, the HV band, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Preprocessing:** Missing incidence angles are imputed with the training set median.
*   **Augmentation:** Training data is augmented using `torchvision.transforms` for random horizontal and vertical flips (Cite solution_lesson_node_00013).

### Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation** (Cite solution_lesson_node_00016).
*   **Optimization:** The Adam optimizer is used with a **constant learning rate** (e.g., 1e-3 or 1e-4). No learning rate scheduler is applied, relying on the implicit regularization of the constant step size to prevent overfitting to noise (Cite solution_lesson_node_00019).
*   **Initialization:** All layers are initialized from scratch; no pre-trained weights are used, and no layers are frozen (Cite solution_lesson_node_00012).

### Evaluation
*   **Test-Time Augmentation (TTA):** To further reduce variance and exploit the spatial invariance learned by the model, predictions for the test set are generated using TTA. For each test image, the model predicts probabilities for:
    1.  The original image.
    2.  The horizontally flipped image.
    3.  The vertically flipped image.
*   **Ensembling:** The final submission probability for a given ID is the average of the TTA predictions across all 5 folds of the Cross-Validation ensemble (Total: $5 \text{ folds} \times 3 \text{ views} = 15 \text{ predictions}$ per image).
