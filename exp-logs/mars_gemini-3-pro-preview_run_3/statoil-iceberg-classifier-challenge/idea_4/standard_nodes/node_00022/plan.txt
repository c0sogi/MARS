The error `AttributeError: np.Inf was removed in the NumPy 2.0 release. Use np.inf instead` occurs because the code uses the deprecated alias `np.Inf` to initialize the minimum validation loss in the `EarlyStopping` class. In NumPy 2.0+, this alias has been removed. The fix is to replace `np.Inf` with `np.inf` in `library/utils.py`.
