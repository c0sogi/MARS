Based on the lessons learned, particularly the superiority of shallow, custom architectures with strong inductive biases for peak detection (Cite solution_lesson_node_00031) and the necessity of ensembling (Cite solution_lesson_node_00027), I propose the following structural evolution.

# Solution: Hierarchical Max-Pooling CNN (HMP-CNN)

### Model
The proposed architecture is a **Hierarchical Max-Pooling Convolutional Neural Network**. It retains the "shallow and wide" philosophy of the successful baseline but introduces **Multi-Level Feature Aggregation** to explicitly capture signal intensity at different resolutions.

*   **Backbone:** A 4-block Convolutional Network. The channel widths are strictly constrained to **64, 64, 128, 128** to prevent the overfitting observed with wider (256+) layers (Cite solution_lesson_node_00026).
*   **Structural Innovation (Hierarchical Pooling):** Instead of utilizing only the final feature map, the model applies **Global Max Pooling** to the output of **every** convolutional block.
    *   Block 1 Output ($\mathbb{R}^{75 \times 75 \times 64}$) $\rightarrow$ Global Max Pool $\rightarrow$ Vector $v_1$ ($\mathbb{R}^{64}$)
    *   Block 2 Output ($\mathbb{R}^{37 \times 37 \times 64}$) $\rightarrow$ Global Max Pool $\rightarrow$ Vector $v_2$ ($\mathbb{R}^{64}$)
    *   Block 3 Output ($\mathbb{R}^{18 \times 18 \times 128}$) $\rightarrow$ Global Max Pool $\rightarrow$ Vector $v_3$ ($\mathbb{R}^{128}$)
    *   Block 4 Output ($\mathbb{R}^{9 \times 9 \times 128}$) $\rightarrow$ Global Max Pool $\rightarrow$ Vector $v_4$ ($\mathbb{R}^{128}$)
    *   **Rationale:** This design explicitly preserves the raw high-intensity peaks (characteristic of icebergs) found in early layers, which can be diffused or normalized away in deeper layers. It enforces the "Max Pooling" inductive bias (Cite solution_lesson_node_00007) at multiple scales of abstraction.
*   **Feature Fusion:** The vectors $v_1, v_2, v_3, v_4$ are concatenated along with the scalar **incidence angle** to form a rich, multi-scale feature embedding.
*   **Classification Head:** The fused vector is passed through a Dense layer (512 units) $\rightarrow$ ReLU $\rightarrow$ **Dropout** $\rightarrow$ Dense Output (Sigmoid). Dropout is strictly applied *after* the activation to preserve the integrity of the compact input features (Cite solution_lesson_node_00017).

### Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) consisting of the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained to avoid artifacts from upscaling (Cite solution_lesson_node_00009).
*   **Augmentation:** Data augmentation is performed using `torchvision.transforms` (RandomHorizontalFlip, RandomVerticalFlip) for stability and efficiency (Cite solution_lesson_node_00013).

### Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00016).
*   **Optimization:** The Adam optimizer is used with a **constant learning rate** (e.g., 1e-3). Learning rate schedulers are explicitly avoided to utilize the implicit regularization of a constant step size (Cite solution_lesson_node_00019).
*   **Initialization:** The model is trained from scratch with all layers trainable (Cite solution_lesson_node_00012).

### Evaluation
*   **Inference:** Predictions are generated using **Test-Time Augmentation (TTA)**. For each test image, the model predicts on the original, horizontally flipped, and vertically flipped versions, and the results are averaged.
*   **Ensembling:** The final submission probability for each ID is the average of the TTA predictions from all **5 models** trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
