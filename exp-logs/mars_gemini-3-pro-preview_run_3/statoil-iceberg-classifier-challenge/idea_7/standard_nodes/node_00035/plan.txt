To optimize the solution, I will implement a strategy that combines the superior feature extraction of the **Hierarchical Max-Pooling CNN (HMP-CNN)** with the variance reduction of **Ensembling**, evaluated on a strict hold-out set.

**Strategy:**
1.  **Architecture:** Retain the HMP-CNN (Cite `solution_lesson_node_00034`). Previous logs showed it achieved lower per-fold validation loss (~0.228) compared to the SimpleCNN (~0.251), indicating better base learner quality.
2.  **Evaluation Protocol:** Switch from Out-Of-Fold (OOF) evaluation on the full dataset to **Ensemble Evaluation on a Hold-out Set**. The previous solution failed because it compared a single-model proxy metric (OOF) against a threshold derived from an ensemble (Cite `solution_lesson_node_00027`). By training on the training split and ensembling predictions on the validation split, we leverage variance reduction to minimize the log loss.
3.  **Training Regime:** Perform 5-Fold Cross-Validation on the `train.csv` metadata only. The `val.csv` metadata will be reserved exclusively for the final ensemble evaluation to ensure a fair comparison with the target threshold.
4.  **Hyperparameters:** Maintain the constant learning rate (Cite `solution_lesson_node_00019`) and avoid input dropout (Cite `solution_lesson_node_00017`) to ensure stable convergence and robust feature learning.

def predict_with_tta(model, loader, device=DEVICE):
    """
    Generates predictions using Test-Time Augmentation (Original, H-Flip, V-Flip).

    Args:
        model (torch.nn.Module): The neural network model.
        loader (torch.utils.data.DataLoader): DataLoader for test data (returns img, angle, id).
        device (torch.device): Device to run inference on.

    Returns:
        dict: Dictionary mapping image_id (str) to predicted probability (float).
    """
    model.eval()
    predictions = {}

    with torch.no_grad():
        for images, angles, ids in loader:
            images = images.to(device)
            angles = angles.to(device)

            # 1. Original Prediction
            out1 = model(images, angles)

            # 2. Horizontal Flip Prediction (dim 3 is width in NCHW)
            images_h = torch.flip(images, [3])
            out2 = model(images_h, angles)

            # 3. Vertical Flip Prediction (dim 2 is height in NCHW)
            images_v = torch.flip(images, [2])
            out3 = model(images_v, angles)

            # Average the predictions
            avg_preds = (out1 + out2 + out3) / 3.0

            # Convert to numpy array
            probs = avg_preds.cpu().numpy().flatten()

            # Store results
            for i, img_id in enumerate(ids):
                predictions[img_id] = float(probs[i])

    return predictions
