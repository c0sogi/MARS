The implementation strategy is as follows:

1.  **Configuration & Setup**: Initialize the `Config` class, overriding `EPOCHS` to 20 to satisfy the "fast baseline" requirement while maintaining sufficient convergence. Set random seeds using `seed_everything` for reproducibility.
2.  **Data Loading**: Load the training data using `get_data(load_cached_data=True)` to leverage preprocessed `.npy` files.
3.  **Cross-Validation Loop**:
    *   Initialize an array `oof_preds` to store out-of-fold predictions.
    *   Iterate through 5 folds using `StratifiedKFold`.
    *   For each fold, call `run_fold` (from `library.train`) to train the model and save the best checkpoint.
    *   Reload the best checkpoint and perform inference on the fold's validation set (retrieved via `get_fold_loaders`) to populate `oof_preds`.
4.  **Validation Assessment**:
    *   Load the hold-out validation metadata from `./metadata/val.csv`.
    *   Map the IDs from the metadata to the indices in the full training set.
    *   Extract the ground truth labels and the corresponding OOF predictions for this specific subset.
    *   Calculate and print the `Final Validation Metric` (Log Loss).
5.  **Failure Analysis**:
    *   Calculate the absolute prediction error for the validation subset.
    *   Compute and print the Pearson correlation between these errors and the incidence angles (`inc_angle`) to identify if the model struggles with specific viewing geometries.
6.  **Submission**:
    *   Compare the final validation metric against the threshold (`0.17174082291273365`).
    *   If the metric is lower (better), call `predict_test` (from `library.inference`) to generate the submission file at `./submission/submission.csv`.
