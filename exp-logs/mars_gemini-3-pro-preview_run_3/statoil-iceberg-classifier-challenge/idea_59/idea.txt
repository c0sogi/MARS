Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Angle-Conditioned Isomorphic CNN (ACI-CNN)**.

This solution represents a structural evolution of the **Corrected Decoupled Isomorphic CNN** (Idea 58). It integrates the metadata (Incidence Angle) directly into the feature extraction process via **Conditional Squeeze-and-Excitation**, allowing the network to dynamically adapt its filters to the acquisition geometry (e.g., suppressing specific noise patterns that vary with angle). It also strictly implements the **Leak-Free Cross-Validation** protocol (Lesson 147) to ensure performance metrics are realistic, while retaining the robust **Plain CNN** backbone and **Dual-Polarity Readout**.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed, geometry-aware feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **AC-SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).

*   **Structural Innovation 1 (Angle-Conditioned Squeeze-and-Excitation):**
    *   We replace the standard SE module with an **AC-SE Module**.
    *   **Mechanism:**
        1.  **Squeeze:** Global Average Pooling (Cite solution_lesson_node_00104).
        2.  **Conditioning:** We concatenate the **Normalized Incidence Angle** with the squeezed channel vector.
        3.  **Excitation:** The MLP processes this combined vector `[Channels + 1]` to generate channel weights.
    *   **Rationale:** This effectively makes the convolutional filters "angle-aware." The network can learn to upweight or downweight specific feature maps (e.g., those sensitive to surface clutter) based on the look angle, performing dynamic domain adaptation within the backbone itself.

*   **Structural Innovation 2 (Corrected Decoupled Isomorphic Readout):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Decoupled Projections:** We use **separate** 1x1 Convolutional layers for Stage 3 (`Proj3`) and Stage 4 (`Proj4`) to learn depth-specific transformations (Cite solution_lesson_node_00144).
    *   **Isomorphic Dual-Polarity:**
        *   **Stage 3:** `Proj3(128 -> 64)` $\to$ **Global Max Pooling** + **Global Min Pooling**.
        *   **Stage 4:** `Proj4(128 -> 64)` $\to$ **Global Max Pooling** + **Global Min Pooling**.
    *   **Constraint:** Max and Min pooling share the *same* projection within a stage to ensure feature coherence (Cite solution_lesson_node_00142).
    *   **Result:** A 256-dimensional vector that captures **Signal-to-Shadow Contrast** without parameter explosion (Cite solution_lesson_node_00124, solution_lesson_node_00134).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **Raw Incidence Angle** (Late Fusion). We keep this unnormalized at the head to allow simple linear scaling (Cite solution_lesson_node_00057, solution_lesson_node_00141).

*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Leak-Free Preprocessing:**
    *   **Imputation:** Calculate median incidence angle **only on training folds** and apply to validation folds.
    *   **Normalization:** For the AC-SE module input, fit a StandardScaler **only on training folds** to normalize the angle (Cite solution_lesson_node_00147).

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
