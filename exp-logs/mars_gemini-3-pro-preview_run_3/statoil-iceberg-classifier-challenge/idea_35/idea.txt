Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Dual-Polarity Attentive CNN (DPA-CNN)**.

This solution represents a structural synthesis of the **Plain CNN** backbone's stability with a novel readout strategy derived from the physics of SAR imagery. It explicitly leverages the **LeakyReLU** lesson (Cite solution_lesson_node_00091) which established that negative activations (shadows) contain semantic information. By introducing **Dual-Polarity Pooling**, this architecture captures both the high-intensity signal peaks (Icebergs) and the deep signal voids (Shadows) without the signal dilution of Average Pooling (Cite solution_lesson_node_00102), while maintaining the robust **Hybrid SE** attention mechanism.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for high-contrast target detection.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution before it reaches the pooling layers (Cite solution_lesson_node_00046).
    *   **Block Structure:** Each block consists of `Conv2d` (with `bias=True`) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** We use **`LeakyReLU`** (negative slope 0.1) throughout. This preserves negative values (e.g., radar shadows normalized by BatchNorm) that carry semantic meaning, which standard ReLU destroys (Cite solution_lesson_node_00091).
    *   **Width Strategy:** The channel dimensions are configured as **64 $\to$ 128 $\to$ 128 $\to$ 128**. We expand to 128 channels immediately in the second block to preserve low-level texture details (Cite solution_lesson_node_00050) but cap the width to prevent overfitting (Cite solution_lesson_node_00026).
*   **Attention (Hybrid SE):** Within the SE Module, we use **Global Average Pooling** for the squeeze operation. This acts as a low-pass filter, providing a robust statistical summary of the channel distribution without overfitting to local noise spikes (Cite solution_lesson_node_00104).
*   **Structural Innovation (Dual-Polarity Readout):** At the final stage, we replace the standard pooling with **Dual-Polarity Pooling**.
    *   **Positive Polarity:** We apply **Global Max Pooling** to capture the strongest positive activations (Signal Peaks/Backscatter) (Cite solution_lesson_node_00007).
    *   **Negative Polarity:** We apply **Global Min Pooling** (implemented as `Max(-x)`) to capture the strongest negative activations (Signal Voids/Shadows).
    *   **Rationale:** Since LeakyReLU preserves negative values, and SAR targets are characterized by both bright returns and cast shadows (contrast), explicitly capturing the "deepest" shadow alongside the "brightest" peak provides a physically grounded descriptor of the object's dynamic range, avoiding the washout effect of Average Pooling (Cite solution_lesson_node_00102).
*   **Feature Fusion (Raw Scale):** The concatenated vectors ($128_{max} + 128_{min}$) are fused with the scalar **incidence angle**. We explicitly **do not normalize** the angle, preserving its natural scale alignment with the raw radar signal (Cite solution_lesson_node_00057).
*   **Classification Head:** A single hidden layer: `Linear` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).
*   **Initialization:** We strictly use **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2) (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained (Cite solution_lesson_node_00009).
*   **Augmentation:** We use `torchvision.transforms` for RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** We use **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from the adaptive gradient updates, ensuring consistent regularization on the raw scalar input without the instability of schedulers (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** We set a generous training budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) to ensure convergence (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Predictions are generated via a single forward pass on the original image (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
