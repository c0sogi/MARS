### Implementation Strategy

1.  **Configuration Setup**: We will dynamically modify the `Config` class attributes to set up a temporary cache directory (`./working/demo_cache`) and reduce hyperparameters (epochs, batch size) to ensure the demonstration runs quickly.
2.  **Data Processing**: We will utilize `preprocess_data` to load the raw data. To optimize speed, we will slice the resulting arrays to a very small subset (e.g., 50 samples) immediately after loading. This allows us to test the pipeline without processing the full dataset during the training loop.
3.  **Dataset Verification**: We will instantiate `IcebergDataset` via `get_fold_datasets` and assert that the output tensors have the correct shapes (3 channels, 75x75 spatial dims) and types. We will also verify that `inc_angle` imputation is working by checking for NaNs.
4.  **Model Verification**: We will instantiate the `AGICNN` model, perform a forward pass with dummy data derived from the dataset, and verify the output shape and value range (logits).
5.  **Training Loop Demonstration**: We will run a single epoch of training and validation using `train_one_epoch` and `validate`. We will assert that the loss is a valid finite number.
6.  **Checkpointing**: We will demonstrate `save_checkpoint` and `load_checkpoint`, verifying that model weights are correctly restored.
7.  **Cleanup**: We will remove the temporary directories created during the run.
