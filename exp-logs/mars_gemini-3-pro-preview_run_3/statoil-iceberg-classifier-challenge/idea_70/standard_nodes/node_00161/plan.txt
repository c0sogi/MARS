The implementation strategy is as follows:

1.  **Setup and Data Loading**: Initialize the environment with a fixed seed and load the preprocessed data (images, angles, labels, IDs) using the provided `preprocess_data` function with caching enabled.
2.  **Cross-Validation Loop**: Iterate through the 5 folds defined in the configuration. For each fold:
    *   Execute the training process using `run_fold`, which handles model training, validation monitoring, and checkpoint saving.
    *   After training, reload the best model checkpoint for that fold.
    *   Generate predictions on the validation set (Out-Of-Fold predictions) to construct a global validation result.
3.  **Global Evaluation**:
    *   Concatenate the OOF predictions and compute the overall Log Loss metric.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the absolute error between predictions and ground truth.
    *   Compute correlations between this error and key input features (Incidence Angle, Image Mean, Image Std Dev) to identify sources of systematic error.
5.  **Submission Generation**:
    *   Check if the validation metric meets the threshold (< 0.17174082291273365).
    *   If successful, perform inference on the test set using an ensemble of the 5 trained models (averaging their probabilities).
    *   Save the results to `submission.csv` in the specified format.
