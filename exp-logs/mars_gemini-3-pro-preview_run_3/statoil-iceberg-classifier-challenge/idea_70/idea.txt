Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Angle-Gated Isomorphic CNN (AGI-CNN)**.

This solution represents a structural synthesis of the most effective components identified to date, explicitly resolving the "Interaction" bottleneck identified in **Lesson 155**. While previous best models successfully extracted physics-informed features (Peaks and Shadows), they relied on a simple MLP to learn the relationship between these features and the incidence angle. **Lesson 155** implies that a simple concatenation (additive fusion) is suboptimal for modeling the physical radar equation, where the incidence angle modulates the backscatter intensity (gain) multiplicatively.

This solution introduces a **Multiplicative Angle-Gating Head** to explicitly model this physical interaction at the Late Fusion stage, integrated into the robust **Plain CNN** backbone with **Hybrid Activations** and **Corrected Isomorphic Readout**.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-consistent feature extraction and calibration.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Standard SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms in convolutional layers to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Hybrid Activation:**
        *   **Spatial Layers:** We use **`LeakyReLU`** (negative slope 0.1) to preserve negative values (shadows) generated by BatchNorm (Cite solution_lesson_node_00091).
        *   **Attention Bottleneck:** Within the SE Module, we strictly use **`ReLU`**. This enforces sparsity in the channel importance weights, preventing the noise-overfitting observed with LeakyReLU in attention gates (Cite solution_lesson_node_00158).
    *   **Attention:** We use **Global Average Pooling** for the squeeze operation (low-pass filter) to be robust to noise (Cite solution_lesson_node_00104), with a reduction ratio of $r=16$ (Cite solution_lesson_node_00146).

*   **Readout (Corrected Decoupled Isomorphic):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Decoupled Projections:** We use **separate** 1x1 Convolutional layers for Stage 3 (`Proj3`) and Stage 4 (`Proj4`) to learn depth-specific transformations (Cite solution_lesson_node_00144).
    *   **Isomorphic Dual-Polarity:**
        *   **Stage 3:** `Proj3(128 -> 64)` $\to$ **Global Max Pooling** + **Global Min Pooling**.
        *   **Stage 4:** `Proj4(128 -> 64)` $\to$ **Global Max Pooling** + **Global Min Pooling**.
    *   **Constraint:** Max and Min pooling share the *same* projection within a stage (Cite solution_lesson_node_00142).
    *   **Result:** A 256-dimensional vector ($F_{img}$) that captures **Signal-to-Shadow Contrast** without parameter explosion (Cite solution_lesson_node_00124, solution_lesson_node_00134).

*   **Structural Innovation (Angle-Gated Calibration):**
    *   Instead of concatenating the incidence angle ($\theta$), we use it to generate a **Multiplicative Gate**.
    *   **Gating Network:** A lightweight projection: `Linear(1 -> 256) -> Sigmoid`. This maps the scalar angle to a channel-wise gain vector $G \in (0, 1)^{256}$.
    *   **Calibration:** $F_{calibrated} = F_{img} \odot (1 + G)$. We use a residual formulation ($1+G$) to allow the network to default to the raw features if the angle is uninformative.
    *   **Rationale:** This explicitly models the physical interaction where the look angle attenuates or amplifies specific feature responses (e.g., surface clutter vs. volume scattering), adhering to the need for non-linear interaction (Cite solution_lesson_node_00155) while respecting the Late Fusion preference (Cite solution_lesson_node_00148).

*   **Classification Head:** `Dropout(0.5)` $\to$ `Linear(256 -> 1)` $\to$ `Output`. Dropout is applied to the calibrated features (Cite solution_lesson_node_00017).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Leak-Free Preprocessing:** Imputation of missing incidence angles is performed using the median calculated **only on the training fold indices** and applied to the validation fold (Cite solution_lesson_node_00147).

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing the fusion of the raw scalar input (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
