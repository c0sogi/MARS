Implementation Strategy:
The implementation will follow the "Selective Hierarchical Max-Pooling CNN" strategy using a 5-Fold Cross-Validation ensemble. 
1.  **Setup**: We will import necessary modules and the provided library components. We will monkey-patch `Config.NUM_EPOCHS` to 25 to ensure the "fast baseline" requirement is met without compromising convergence on this small dataset.
2.  **Data Loading**: We will use `prepare_data(load_cached_data=True)` to load the preprocessed tensors. We will then concatenate the provided train and validation splits to form a single training set for the 5-Fold CV, maximizing data utilization.
3.  **Cross-Validation Loop**: We will iterate through 5 stratified folds. In each fold:
    *   Construct `DataLoader`s for training and validation.
    *   Call `library.train.run_fold` to train the model and save the best checkpoint.
    *   Reload the best checkpoint and perform inference on the validation fold to collect Out-Of-Fold (OOF) probabilities.
4.  **Metric Calculation**: We will compute the Log Loss on the full set of OOF predictions and print it as `Final Validation Metric`.
5.  **Failure Analysis**: We will compute the absolute error of the predictions and calculate Pearson correlations with the Incidence Angle and basic image statistics (Band 1 mean, Band 2 std) to identify error sources.
6.  **Submission**: If the validation metric is below the specified threshold, we will run inference on the test set using all 5 trained models, average the probabilities, and save the result to `./submission/submission.csv`.
