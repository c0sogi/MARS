Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose the **Selective Hierarchical Max-Pooling CNN (SHMP-CNN)**.

This solution represents a structural evolution of the "Simple CNN" (Idea 4) and the "Hierarchical CNN" (Idea 7). It synthesizes the superior feature extraction capability of hierarchical pooling (Cite solution_lesson_node_00034) with the noise-robustness of deep, aggressive downsampling (Cite solution_lesson_node_00035, Cite solution_lesson_node_00046). It explicitly corrects the flaw in Idea 7 where including early, noisy layers degraded the ensemble performance.

# Model
The architecture is a **Selective Hierarchical Convolutional Neural Network** designed to capture multi-scale signal peaks while filtering out high-frequency speckle noise.

*   **Backbone:** The network retains the robust "Simple CNN" structure consisting of 4 Convolutional Blocks. Each block comprises `Conv2d` $\to$ `BatchNorm` $\to$ `ReLU` $\to$ `MaxPool2d`.
    *   **Width Constraint:** The channel dimensions are strictly constrained to **64 $\to$ 64 $\to$ 128 $\to$ 128**. We explicitly avoid expanding to 256+ channels to prevent the overfitting observed in wider networks (Cite solution_lesson_node_00026).
    *   **Spatial Reduction:** The network aggressively downsamples the 75x75 input to a 4x4 grid at the final layer, ensuring noise is filtered via convolution before aggregation (Cite solution_lesson_node_00046).
*   **Structural Innovation (Selective Hierarchical Pooling):** We implement a **Partial Feature Pyramid**. Instead of pooling only the final layer (Simple CNN) or all layers (Idea 7), we apply **Global Max Pooling** to the outputs of **Block 3** and **Block 4** only.
    *   **Rationale:** Block 3 (approx. 9x9 spatial grid) captures medium-scale shape/context features. Block 4 (approx. 4x4 spatial grid) captures abstract existence features. By concatenating these, we enrich the representation. Crucially, we **exclude** Block 1 and Block 2 from the pooling, as previous experiments proved that early-layer features in SAR data are dominated by speckle noise, which degrades generalization when fed directly to the classifier (Cite solution_lesson_node_00035).
    *   **Pooling Type:** We strictly use **Global Max Pooling** for both blocks to preserve the sparse, high-intensity peak signals characteristic of icebergs (Cite solution_lesson_node_00007).
*   **Feature Fusion:** The pooled vectors from Block 3 (128 features) and Block 4 (128 features) are concatenated with the scalar **incidence angle** (Late Fusion) (Cite solution_lesson_node_00039).
*   **Classification Head:** The fused vector (257 dimensions) passes through a **Single Hidden Layer** configuration: `Linear` $\to$ `ReLU` $\to$ `Dropout` $\to$ `Linear` $\to$ `Output`.
    *   We restrict the head to one hidden layer to limit capacity (Cite solution_lesson_node_00040).
    *   **Dropout Strategy:** Dropout is applied *only* after the activation function of the hidden layer. We explicitly avoid applying dropout to the compact input vector to preserve signal integrity (Cite solution_lesson_node_00017).

# Data
*   **Input Composition:** The input is a 3-channel tensor (75x75x3) comprising the **HH band**, the **HV band**, and a **synthetic average band** ((HH+HV)/2). This composite input enriches the initial feature space (Cite solution_lesson_node_00005).
*   **Resolution:** The native **75x75** resolution is maintained. We avoid upscaling to prevent computational overhead and artifacts (Cite solution_lesson_node_00009).
*   **Augmentation:** We use the optimized `torchvision.transforms` library for RandomHorizontalFlip and RandomVerticalFlip during training (Cite solution_lesson_node_00013).
*   **Imputation:** Missing incidence angles are imputed with the training set median.

# Training
*   **Strategy:** The model is trained using **5-Fold Cross-Validation Ensembling**. This is mandatory to reduce the high variance inherent in this small dataset (Cite solution_lesson_node_00016).
*   **Optimization:** We use the **Adam** optimizer with a **constant learning rate** (e.g., 1e-3). We explicitly avoid learning rate schedulers to utilize the implicit regularization of the constant step size (Cite solution_lesson_node_00019).
*   **Loss Function & Regularization:** We use **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)**. This is crucial to prevent the instability and "confident errors" observed in unregularized runs (Cite solution_lesson_node_00036).
*   **Initialization:** We strictly use **PyTorch Default Initialization**. We explicitly reject manual fixed-scale initialization schemes which caused convergence failures in previous attempts (Cite solution_lesson_node_00045). No layers are frozen (Cite solution_lesson_node_00012).

# Evaluation
*   **Inference:** We explicitly **disable Test-Time Augmentation (TTA)**. Previous experiments demonstrated that TTA degrades performance on this directional SAR data, likely due to physics-violating transformations of shadow and backscatter features (Cite solution_lesson_node_00041).
*   **Ensembling:** The final submission probability for each ID is the simple average of the direct predictions from the 5 models trained in the Cross-Validation loop (Cite solution_lesson_node_00027).
