The strategy involves loading the JSON datasets from the input directory using Pandas. Since the raw data contains large image arrays (`band_1`, `band_2`), these columns will be excluded from the metadata files to keep them lightweight. Instead, the metadata will store the `id`, `inc_angle`, `is_iceberg` (for training data), a `source_file` column pointing to the original JSON file relative to the input directory, and an `original_index` column to allow efficient retrieval of the image bands later. The training data will be split into training and validation sets using an 80:20 ratio with stratified sampling based on the `is_iceberg` label. Finally, the script will validate the generated metadata by checking file path existence, split ratios, and class distributions.
