Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Tri-Statistic Isomorphic CNN (TSI-CNN)**.

This solution represents a structural synthesis designed to capture the complete physical signature of icebergs—**Peak Intensity**, **Shadow Depth**, and **Surface Texture**—within a strictly constrained parameter budget. It resolves the conflict between **Lesson 143** (Texture is critical) and **Lesson 145** (Standard Deviation is too noisy) by introducing **Global MAD (Mean Absolute Deviation) Pooling** alongside the successful Dual-Polarity (Max+Min) readout. This is integrated into the robust **Plain CNN** backbone with **Hybrid SE** attention and **Leak-Free** training.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed, multi-statistic feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Standard SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).
    *   **Attention:** **Hybrid SE** uses Global Average Pooling for the squeeze operation (low-pass filter) to be robust to noise (Cite solution_lesson_node_00104), with reduction ratio $r=16$ (Cite solution_lesson_node_00146).

*   **Structural Innovation (Tri-Statistic Isomorphic Readout):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Decoupled Projections:** We use **separate** 1x1 Convolutional layers for Stage 3 (`Proj3`) and Stage 4 (`Proj4`) to learn depth-specific transformations (Cite solution_lesson_node_00144).
    *   **Compression:** We project the 128 channels down to **42 channels** (instead of 64). This allows us to add a third pooling statistic while keeping the total feature count constant ($\approx 256$).
    *   **Tri-Statistic Pooling:** On the projected maps, we apply three global pooling operations:
        1.  **Global Max Pooling:** Captures bright backscatter peaks (Icebergs) (Cite solution_lesson_node_00007).
        2.  **Global Min Pooling:** Captures deep signal voids (Shadows) (Cite solution_lesson_node_00134).
        3.  **Global MAD Pooling:** Calculates the **Mean Absolute Deviation** ($\text{Avg}(|x - \text{Avg}(x)|)$). This captures **Texture/Roughness** (Ice vs. Water) robustly, avoiding the outlier sensitivity of Standard Deviation (Cite solution_lesson_node_00143, solution_lesson_node_00145).
    *   **Result:** A 252-dimensional vector ($42 \times 3 \text{ stats} \times 2 \text{ stages}$) that models the full physical scattering profile without parameter explosion (Cite solution_lesson_node_00124).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle (Cite solution_lesson_node_00057).

*   **Classification Head:** `Linear(253 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`.
    *   We include the non-linear hidden layer to allow interaction between image features and the angle (Cite solution_lesson_node_00155).
    *   Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Leak-Free Preprocessing:** Imputation of missing incidence angles is performed using the median calculated **only on the training fold indices** and applied to the validation fold (Cite solution_lesson_node_00147).

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing the fusion of the raw scalar input (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
