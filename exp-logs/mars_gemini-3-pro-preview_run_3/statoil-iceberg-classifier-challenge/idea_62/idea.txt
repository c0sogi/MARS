Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Log-Sum-Exp Isomorphic CNN (LSE-I-CNN)**.

This solution represents a structural evolution of the **Isomorphic Dual-Polarity CNN** (Idea 47/58). It addresses a fundamental signal processing limitation in the readout layer: while **Max Pooling** captures peaks, it is sensitive to single-pixel speckle noise (Cite solution_lesson_node_00126), and while **Average Pooling** reduces noise, it washes out targets (Cite solution_lesson_node_00102).

This solution introduces **Global Log-Sum-Exp (LSE) Pooling**. Since the input data is in the logarithmic decibel (dB) scale, applying the LSE operation ($\log \sum \exp(x)$) effectively aggregates the **Linear Power (Radar Cross Section)** of the signal. This provides a physically consistent measure of the total target backscatter—robust to speckle (unlike Max) but preserving high-intensity peaks (unlike Average)—integrated into the robust **Plain CNN** backbone with **Isomorphic Dual-Polarity** architecture.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physically consistent, noise-robust feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise via convolution (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Hybrid SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).
    *   **Attention:** **Hybrid SE** uses Global Average Pooling for the squeeze operation (low-pass filter) to be robust to noise (Cite solution_lesson_node_00104).

*   **Structural Innovation (LSE Isomorphic Readout):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Decoupled Projections:** We use **separate** 1x1 Convolutional layers for Stage 3 (`Proj3`) and Stage 4 (`Proj4`) to learn depth-specific transformations (Cite solution_lesson_node_00144).
    *   **Physically-Consistent Dual-Polarity Pooling:**
        *   **Positive Polarity (Total RCS):** Instead of Max Pooling, we use **Global Log-Sum-Exp Pooling**: $y_+ = \log(\sum \exp(x))$. This aggregates the total linear power of the target, smoothing out speckle while preserving peak intensity.
        *   **Negative Polarity (Deepest Shadow):** We use **Global SoftMin Pooling**: $y_- = -\log(\sum \exp(-x))$. This aggregates the "darkness" of the shadow regions.
    *   **Mechanism:** Within each stage, LSE and SoftMin operate on the *same* projected feature map (Cite solution_lesson_node_00142).
    *   **Result:** A 256-dimensional vector ($64_{LSE3}+64_{SoftMin3}+64_{LSE4}+64_{SoftMin4}$) that captures robust physical signal properties without parameter explosion (Cite solution_lesson_node_00124).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle (Cite solution_lesson_node_00057).

*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Leak-Free Preprocessing:** Imputation of missing incidence angles is performed using the median calculated **only on the training fold indices** (Cite solution_lesson_node_00147).

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing the fusion of the raw scalar input (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
