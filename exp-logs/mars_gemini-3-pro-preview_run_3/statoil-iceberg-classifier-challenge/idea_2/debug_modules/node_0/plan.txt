This script demonstrates the end-to-end workflow using the provided library modules. It validates data loading, model architecture, training logic (on a reduced scale for speed), and inference generation.

1.  **Setup & Verification**: Initializes the environment with a fixed seed and suppresses warnings.
2.  **Data Loading**: Loads pre-processed data from the cache (or processes it if missing) using `data_loader.load_and_process_data`. It asserts that the data shapes and value ranges are correct.
3.  **Model Instantiation**: Initializes the `IcebergVGG16` model and verifies the output shape and value range (sigmoid probability) with a single batch pass.
4.  **Training Loop**: Executes a single epoch of training on Fold 0 using `train.run_fold` to demonstrate the training pipeline without consuming excessive time. It verifies that model checkpoints are successfully saved.
5.  **Inference**: Loads the saved checkpoint and performs inference on a small subset of the test data to verify the prediction pipeline.
6.  **Submission**: Demonstrates how to format and save the predictions into a CSV file.
