Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Magnitude-Preserving Dual-Polarity CNN (MPDP-CNN)**.

This solution represents a fundamental structural evolution of the **Isomorphic Dual-Polarity Hierarchical CNN** (Idea 47). It identifies a critical inconsistency in the previous best architecture: while the **Readout** was modified to capture "Shadows" (signal voids) via Min-Pooling (Cite solution_lesson_node_00134), the **Backbone** still relies on standard **Max-Pooling** for downsampling. Standard Max-Pooling ($\max(x)$) inherently biases the signal propagation towards positive values, actively destroying the deep shadow features (negative values preserved by LeakyReLU) generated in early layers before they can reach the final readout.

This solution introduces **Max-Magnitude Pooling** in the backbone to preserve the strongest signal response (whether Peak or Shadow) during downsampling, and **Leaky-SE** to allow shadow-dominant channels to participate in attention, integrated into the robust **Plain CNN** framework.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for preserving the full dynamic range of SAR signals (Peaks and Shadows).

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Leaky-SE Module** $\to$ **Max-Magnitude Pooling**.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).

*   **Structural Innovation 1 (Max-Magnitude Pooling):**
    *   We replace standard `MaxPool2d` in the backbone with **Max-Magnitude Pooling**.
    *   **Mechanism:** For each spatial pooling window (e.g., 2x2), we select the pixel with the **largest absolute value** ($|x|$), but propagate the **original signed value**.
    *   **Rationale:** Standard Max-Pooling selects $-0.1$ (noise) over $-10.0$ (strong shadow), destroying shadow information during downsampling. Max-Magnitude Pooling preserves the strongest physical signature—whether it is a bright reflection (positive) or a deep void (negative)—ensuring that the "Dual-Polarity" readout receives high-fidelity features from both ends of the spectrum (Cite solution_lesson_node_00134).

*   **Structural Innovation 2 (Leaky Squeeze-and-Excitation):**
    *   **Squeeze:** Global Average Pooling (Cite solution_lesson_node_00104).
    *   **Excitation:** $Linear \to \textbf{LeakyReLU} \to Linear \to Sigmoid$.
    *   **Rationale:** Standard SE uses ReLU in the bottleneck, which outputs zero for channels with negative average activations (shadow-dominant channels). By using **LeakyReLU**, we allow these channels to generate non-zero attention weights, enabling the network to explicitly attend to shadow features (Cite solution_lesson_node_00106).

*   **Readout (Isomorphic Dual-Polarity):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Projection:** Compress channels (128 $\to$ 64) via 1x1 Conv.
    *   **Pooling:** Apply both **Global Max Pooling** (Peaks) and **Global Min Pooling** (Shadows).
    *   **Result:** A 256-dimensional vector ($64_{max}+64_{min}$ from two stages) that strictly respects the capacity constraints of the baseline (Cite solution_lesson_node_00124).

*   **Feature Fusion (Raw Scale):** The feature vector is concatenated with the scalar **incidence angle**. We explicitly **do not normalize** the angle (Cite solution_lesson_node_00057).

*   **Classification Head:** `Linear(257 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017, solution_lesson_node_00040).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** 3-channel tensor (HH, HV, Synthetic Avg) (Cite solution_lesson_node_00005).
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Median imputation for incidence angles.

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing fusion (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
