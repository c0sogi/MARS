Based on the comprehensive analysis of the experiment history and the derived lessons, I propose the **Multi-Spectral Isomorphic CNN with Angle Embedding (MS-IDPH-CNN)**.

This solution represents a structural evolution of the current best **Isomorphic Dual-Polarity Hierarchical CNN** (Idea 47). It preserves the successful backbone and readout strategies but introduces two critical structural innovations to address identified weaknesses in **Data Representation** and **Metadata Fusion**.

1.  **Data Representation:** It expands the input space to **4 Channels** by explicitly calculating the **Depolarization Ratio** (HH - HV). While the "Synthetic Average" (Lesson 5) captures mean intensity, the difference between co-polarized (HH) and cross-polarized (HV) bands is the fundamental physical discriminator between volume scattering (Icebergs) and surface scattering (Water). Explicitly feeding this ratio allows the network to learn from the physical scattering properties directly.
2.  **Metadata Fusion:** It replaces the raw concatenation of the incidence angle with a learnable **Angle Embedding Module**. This resolves the conflict between **Lesson 54** (Optimization Instability from unnormalized scalars) and **Lesson 57** (Signal Mismatch from normalized scalars) by projecting the scalar into a high-dimensional latent space that matches the distribution of the image features *before* fusion.

# Model
The architecture is a **Custom 4-Stage Attentive Convolutional Network** optimized for physics-informed feature extraction.

*   **Backbone:** The network employs a **Plain CNN** structure (no residual connections) with 4 sequential blocks. We explicitly retain this over ResNets to enforce aggressive sequential downsampling (75x75 $\to$ ~4x4), which filters high-frequency speckle noise (Cite solution_lesson_node_00046).
    *   **Block Structure:** `Conv2d` (bias=True) $\to$ `BatchNorm2d` $\to$ `LeakyReLU` $\to$ **Hybrid SE Module** $\to$ `MaxPool2d`.
    *   **Bias Retention:** We explicitly retain bias terms to preserve initialization dynamics (Cite solution_lesson_node_00076).
    *   **Activation:** **`LeakyReLU`** (negative slope 0.1) preserves negative values (shadows) (Cite solution_lesson_node_00091).
    *   **Width Strategy:** **64 $\to$ 128 $\to$ 128 $\to$ 128** (Early Expansion) (Cite solution_lesson_node_00050).
    *   **Attention:** **Hybrid SE** uses Global Average Pooling for the squeeze operation (low-pass filter) to be robust to noise (Cite solution_lesson_node_00104).

*   **Readout (Isomorphic Dual-Polarity):**
    *   We extract features from **Stage 3** and **Stage 4** (Selective Hierarchical) (Cite solution_lesson_node_00035).
    *   **Projection:** We apply a **1x1 Convolution** to compress channels from 128 to **64**.
    *   **Dual-Polarity Pooling:** On these compressed maps, we apply both **Global Max Pooling** (Peaks) and **Global Min Pooling** (Shadows, implemented as `Max(-x)`).
    *   **Result:** A 256-dimensional vector ($64_{max}+64_{min}$ from two stages) that captures the **Signal-to-Shadow Contrast** without exploding the parameter count (Cite solution_lesson_node_00134, solution_lesson_node_00124).

*   **Structural Innovation (Angle Embedding):**
    *   Instead of concatenating the raw scalar angle, we pass it through a dedicated MLP: `Linear(1 -> 16) -> LeakyReLU`.
    *   **Fusion:** This 16-dimensional embedding is concatenated with the 256-dimensional image vector.
    *   **Rationale:** This allows the network to learn a non-linear transformation of the angle that aligns with the feature variance, preventing the scalar from either dominating gradients (if raw) or vanishing (if normalized).

*   **Classification Head:** `Linear(272 -> 256)` $\to$ `LeakyReLU` $\to$ `Dropout(0.5)` $\to$ `Output`. Dropout is applied *only* after activation (Cite solution_lesson_node_00017).

*   **Initialization:** **PyTorch Default Initialization** (Kaiming Uniform/Fan-In) (Cite solution_lesson_node_00078).

# Data
*   **Input Composition:** A **4-channel tensor** (75x75x4):
    1.  **HH Band**
    2.  **HV Band**
    3.  **Synthetic Average:** $(HH + HV) / 2$ (Cite solution_lesson_node_00005).
    4.  **Depolarization Ratio:** $HH - HV$. Since inputs are in dB (log scale), subtraction corresponds to the physical ratio of backscatter, highlighting the difference between volume and surface scattering.
*   **Resolution:** Native **75x75** (Cite solution_lesson_node_00009).
*   **Augmentation:** `torchvision` RandomHorizontalFlip and RandomVerticalFlip (Cite solution_lesson_node_00013).
*   **Imputation:** Median imputation for incidence angles.

# Training
*   **Strategy:** **5-Fold Cross-Validation Ensembling** (Cite solution_lesson_node_00016).
*   **Optimizer:** **AdamW** with a **constant learning rate** (e.g., 1e-3). This decouples weight decay from adaptive updates, stabilizing the fusion of the angle embedding (Cite solution_lesson_node_00019).
*   **Loss Function:** **`BCEWithLogitsLoss`** combined with **L2 Regularization (Weight Decay)** (Cite solution_lesson_node_00036).
*   **Duration:** Generous budget (e.g., 75 epochs) with moderate patience (e.g., 12 epochs) (Cite solution_lesson_node_00094).

# Evaluation
*   **Inference:** Explicitly **disable Test-Time Augmentation (TTA)** (Cite solution_lesson_node_00041).
*   **Ensembling:** Simple average of predictions from the 5 CV models (Cite solution_lesson_node_00027).
