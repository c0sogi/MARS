This script demonstrates the usage of the provided library modules for the Iceberg Classifier task. It performs the following steps:
1.  **Configuration**: overrides default hyperparameters (epochs, directories) for a fast demonstration run.
2.  **Data Processing**: loads and processes the raw JSON data into tensors using `data_loader.py`, verifying data shapes.
3.  **Model Initialization**: instantiates the `DPSCACNN` model and verifies the forward pass with dummy data.
4.  **Training Loop**: executes a single training fold for one epoch using `trainer.py`, validating loss calculation and checkpoint saving.
5.  **Inference**: generates predictions on the test set using `inference.py` and verifies the output submission format.
