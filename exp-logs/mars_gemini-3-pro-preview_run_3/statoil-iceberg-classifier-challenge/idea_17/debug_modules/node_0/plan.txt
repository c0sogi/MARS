The following strategy outlines the implementation of the demonstration script:

1.  **Configuration Override**: We will first modify the global `Config` class attributes to adapt the pipeline for a quick demonstration. This includes setting a dedicated working directory (`./working/demo_usage`), enabling `DEBUG` mode to process only a small subset of data (20 samples), reducing the number of epochs to 1, and setting the batch size to 4.
2.  **Data Processing**: We will invoke `process_and_cache_data` to demonstrate how raw JSON data is converted into numpy arrays and cached. We will verify the existence of these cache files.
3.  **Data Loading**: We will generate DataLoaders for a specific fold using `get_dataloaders`. We will iterate through one batch to verify the tensor shapes of images, incidence angles, and labels.
4.  **Model Initialization & Forward Pass**: We will instantiate the `WideSEResNet` model, move it to the appropriate device, and perform a dummy forward pass with a batch of data to verify the output shape and value validity (e.g., no NaNs).
5.  **Training Loop Execution**: We will run `train_fold(0)` to demonstrate the training engine. This will train for 1 epoch (as configured) and save a checkpoint. We will assert that the checkpoint file is created.
6.  **Inference & Submission**: We will run the `inference` function using the trained model on the test loader. Finally, we will use `save_submission` to generate a CSV file and verify its format and content.
