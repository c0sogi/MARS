### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `utils`. Ensure reproducible results by setting seeds.
2.  **Training Loop**: Iterate through the 5 folds defined in the configuration.
    *   Use the provided `train_fold` function from `library.engine` to train the `WideSEResNet` model. This function handles training, validation, and checkpointing.
    *   Since the dataset is small (~1600 samples), we use the full dataset to ensure we meet the strict validation threshold, relying on the efficient architecture for speed.
3.  **Validation & Failure Analysis Data Collection**:
    *   After training each fold, load the best checkpoint.
    *   Run a custom inference loop on the validation set to collect predictions, ground truth labels, and input features (Incidence Angle, Band 1/2 statistics) necessary for failure analysis.
    *   Simultaneously, generate predictions for the test set to prepare for a potential submission.
4.  **Global Evaluation**:
    *   Concatenate Out-Of-Fold (OOF) predictions and labels.
    *   Compute the **Log Loss** metric on the full validation set.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample.
    *   Compute Pearson correlations between the error magnitude and input features (e.g., incidence angle, signal mean/std) to identify sources of systematic error.
6.  **Submission**:
    *   Check if the validation metric is below the threshold (`0.18145903282502943`).
    *   If successful, average the test predictions across all 5 folds and save the `submission.csv` using the provided utility.
