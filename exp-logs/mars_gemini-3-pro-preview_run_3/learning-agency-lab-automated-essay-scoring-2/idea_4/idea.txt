Based on the provided lessons and constraints, I propose the following **Robust K-Fold Stacking Strategy with Adversarial Training**. This solution structurally evolves the pipeline from a single train/validation split to a full Out-of-Fold (OOF) cross-validation framework, while integrating adversarial robustness into the training loop.

# Model

*   **Backbone Architecture:** Utilize **`deberta-v3-large`** (Cite solution_lesson_node_00014) as the primary feature extractor. This model provides the necessary capacity to capture subtle scoring nuances.
*   **Pooling Mechanism:** Implement **Attention Pooling** applied exclusively to the **final hidden layer**. This retains the focused, task-specific signals optimized in the last layer (Cite solution_lesson_node_00013) while allowing the model to dynamically weight tokens (e.g., emphasizing argumentation over padding) better than simple mean pooling.
*   **Adversarial Regularization:** Integrate **Adversarial Weight Perturbation (AWP)** into the backbone architecture. AWP explicitly perturbs the model's weights during training to maximize the loss, forcing the optimizer to find a flatter (more robust) minimum. This is a structural change to the learning dynamics that improves generalization on unseen test data.
*   **Stacking Head:** The final estimator is a **LightGBM** regressor. It accepts a hybrid input vector consisting of the **OOF Embeddings** (from the backbone) and **Explicit Meta-Features** (Cite solution_lesson_node_00004).

# Data

*   **Stratified K-Fold Splitting:** Instead of a single 80/20 split, partition the `train.csv` dataset into **5 Stratified Folds** based on the `score`. This ensures the model is trained and evaluated on the entire dataset without leakage.
*   **Meta-Feature Engineering:** Calculate structural scalar features (character count, word count, sentence count, unique word ratio) for all essays. These provide magnitude signals that normalized embeddings lack (Cite solution_lesson_node_00002).
*   **Context Processing:** Use the `deberta-v3-large` tokenizer. For inference/feature extraction, apply a **sliding window** approach to generate embeddings for the full text, averaging the pooled vectors of the chunks.

# Training

*   **Stage 1: Cross-Validation Backbone Training:**
    *   Iterate through each of the 5 folds. Train the `deberta-v3-large` model on the training folds and generate predictions/embeddings for the validation fold (Out-of-Fold data).
    *   **Objective:** Minimize **Mean Squared Error (MSE)** (Cite solution_lesson_node_00001).
    *   **Optimization:**
        *   Use **Layer-wise Learning Rate Decay (LLRD)** to stabilize the training of the Large model (Cite solution_lesson_node_00014).
        *   Enable **Gradient Checkpointing** to fit the model on the A100 GPU.
        *   Use the unified **`torch.amp`** API for mixed-precision training (Cite solution_lesson_node_00012).
    *   **Cache Management:** Implement hash-based cache invalidation (using model config/seed hashes) to ensure Stage 2 never loads stale OOF predictions from previous experiments (Cite solution_lesson_node_00015).
*   **Stage 2: OOF Stacking:**
    *   Construct the training set for the LightGBM head by concatenating the OOF embeddings from all 5 folds. This allows the GBM to learn from 100% of the training data.
    *   Train the LightGBM regressor on this combined dataset (Embeddings + Meta-Features).
    *   **Regularization:** Set `feature_fraction` (subsampling) to < 1.0 (e.g., 0.7) to force the tree model to utilize the semantic embeddings and prevent over-reliance on length-based meta-features (Cite solution_lesson_node_00006).

# Evaluation

*   **Inference:**
    *   For each essay in the test set, generate embeddings using all 5 fine-tuned backbone models (one from each fold) and average them to create a robust "Ensemble Embedding".
    *   Calculate the meta-features for the test set.
*   **Prediction:**
    *   Pass the Ensemble Embeddings and meta-features into the trained LightGBM model to predict the continuous score.
*   **Post-Processing:**
    *   Clip the predictions to the [1, 6] range and round to the nearest integer to maximize the Quadratic Weighted Kappa (Cite solution_lesson_node_00001).
