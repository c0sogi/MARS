Based on the provided lessons and the available computational resources, I propose the following optimized strategy. This solution evolves the architecture by scaling the backbone capacity, refining the pooling mechanism, and stabilizing the training dynamics for large-scale models.

# Model
*   **Backbone Architecture**: Upgrade the backbone from `deberta-v3-base` to **`deberta-v3-large`**. The A100 GPU (40GB) allows for this significant increase in parameter count, which provides deeper semantic understanding and nuance detection critical for grading. To manage memory, **Gradient Checkpointing** will be enabled.
*   **Pooling Mechanism**: Replace the static Mean Pooling with **Attention Pooling** (Weighted Layer Pooling) applied to the **final hidden layer** (Cite solution_lesson_node_00013). Unlike Mean Pooling (Cite solution_lesson_node_00011), which treats all tokens equally, Attention Pooling learns a weighting mask to emphasize tokens that contribute most to the scoring decision (e.g., argumentative connectors vs. filler words) while down-weighting padding.
*   **Hybrid Stacking Head**: The final predictor remains a **LightGBM** regressor. It takes a concatenated vector of the **Attention-Pooled Embeddings** (from the fine-tuned backbone) and **Explicit Meta-Features** (word counts, lexical diversity, etc.) (Cite solution_lesson_node_00004).

# Data
*   **Tokenization**: Use the `deberta-v3-large` tokenizer.
*   **Sliding Window Processing**: To handle essays exceeding the transformer's context limit, input text will be split into overlapping chunks (e.g., 512 tokens with 128 overlap). During inference, embeddings from all chunks of an essay will be averaged to form the final document representation.
*   **Meta-Feature Engineering**: Calculate structural scalar features (e.g., character count, sentence count, unique word ratio) to capture magnitude and complexity signals that normalized embeddings might miss (Cite solution_lesson_node_00002).

# Training
*   **Stage 1: Backbone Fine-Tuning**:
    *   **Objective**: Minimize **Mean Squared Error (MSE)**, treating ordinal scores as continuous targets (Cite solution_lesson_node_00001).
    *   **Optimization Strategy**: Implement **Layer-wise Learning Rate Decay (LLRD)**. The learning rate will decrease progressively from the top layers to the bottom layers. This is crucial for fine-tuning "Large" models on smaller datasets (12k samples) to prevent catastrophic forgetting of the pre-trained linguistic features.
    *   **Precision**: Use the unified **`torch.amp`** API for Mixed Precision training to maximize throughput and batch size (Cite solution_lesson_node_00012).
*   **Stage 2: Stacking**:
    *   Extract embeddings using the fine-tuned backbone.
    *   Train the LightGBM regressor on the combined feature set.
    *   **Regularization**: Explicitly set `feature_fraction` (subsampling) to < 1.0 (e.g., 0.7) to force the tree model to utilize the semantic embeddings and prevent over-reliance on simple length heuristics (Cite solution_lesson_node_00006).

# Evaluation
*   **Inference**: Pass test essays through the sliding-window pipeline of the fine-tuned `deberta-v3-large` to generate embeddings.
*   **Prediction**: Feed the embeddings and calculated meta-features into the trained LightGBM model to predict continuous scores.
*   **Post-Processing**: Clip the predictions to the [1, 6] range and round to the nearest integer to maximize the Quadratic Weighted Kappa metric.
