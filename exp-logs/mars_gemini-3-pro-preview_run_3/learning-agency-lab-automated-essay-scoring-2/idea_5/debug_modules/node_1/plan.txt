The `RuntimeError` is caused by using `-1e9` as a masking value in `library/model.py` while Automatic Mixed Precision (AMP) is enabled. In `float16`, the minimum representable value is approximately -65,504, so `-1e9` causes an overflow. I will replace `-1e9` with `-1e4`, which is small enough to zero out softmax probabilities ($e^{-10000} \approx 0$) but fits safely within the `float16` range. Cite debug_lesson_3.
