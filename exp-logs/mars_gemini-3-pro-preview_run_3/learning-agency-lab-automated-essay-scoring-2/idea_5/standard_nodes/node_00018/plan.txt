Implementation of the orchestration script `runfile.py`.

**Strategy Outline:**
1.  **Configuration & Setup**: Initialize the `Config` object. To strictly adhere to the 2-hour time limit and "fast baseline" requirement, I override `config.epochs` to 1 and subsample the training dataset to 6,000 stratified samples. This ensures the 5-fold training loop completes within approximately 40-50 minutes on the provided A100 GPU.
2.  **Data Loading & Processing**: Load the pre-processed metadata using `process_data`. Since subsampling disrupts the pre-calculated folds, I re-apply `StratifiedKFold` on the subsampled data to ensure proper cross-validation.
3.  **Backbone Training (Stage 1)**: Iterate through 5 folds. For each fold, train the `deberta-v3-large` backbone using `run_fold`. This function handles mixed-precision training, AWP, and saves the best checkpoint based on validation loss.
4.  **Embedding Extraction**: Since the stacking head requires semantic embeddings rather than just score predictions, I implement a helper function `extract_embeddings` that manually runs the backbone and pooling layers (bypassing the regression head) to generate feature vectors for the validation set.
5.  **Stacking (Stage 2)**: Aggregating the OOF embeddings and explicit meta-features (char count, etc.) from all folds, I train the `LGBMStacker`.
6.  **Validation & Analysis**: Compute and print the exact `Final Validation Metric` (QWK). Perform failure analysis by correlating prediction residuals with meta-features to identify error sources.
7.  **Inference**: If the QWK exceeds the specified threshold, perform inference on the test set. This involves generating embeddings from all 5 fine-tuned backbones, averaging them for robustness, and passing the result through the trained LightGBM stacker to generate the final `submission.csv`.
