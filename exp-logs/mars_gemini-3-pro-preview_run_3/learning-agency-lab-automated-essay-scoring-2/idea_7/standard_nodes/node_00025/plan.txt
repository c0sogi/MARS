The `TypeError: Got unsupported ScalarType BFloat16` arises because NumPy does not support the `bfloat16` data type, which is used for the model's output tensors (`logits` and `embeddings`) when mixed precision training is enabled with `torch.bfloat16`. To resolve this, I will explicitly cast these tensors to `float32` using `.float()` before converting them to NumPy arrays in both `library/trainer.py` and `library/stacking.py`. This aligns with the guidance in Cite debug_lesson_7.
