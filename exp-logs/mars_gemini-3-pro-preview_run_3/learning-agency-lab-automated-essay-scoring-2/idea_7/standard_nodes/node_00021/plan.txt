Implementation strategy:
1.  **Configuration & Setup**: Initialize the `Config` class and override specific parameters to ensure the "fast baseline" requirement is met. Specifically, reduce `epochs` to 1 to fit within the 2-hour runtime limit while maintaining the full 5-fold structure for robustness.
2.  **Data Loading**: Use `load_and_preprocess` to load the metadata and generate meta-features. This leverages the existing stratified folds.
3.  **Backbone Training**: Execute `train_backbone` to fine-tune the DeBERTa-v3-large model on all 5 folds. This step generates and caches the Out-Of-Fold (OOF) embeddings required for the stacking head.
4.  **Stacking Training**: Execute `train_stacking` to train the LightGBM regressor on the OOF embeddings concatenated with meta-features.
5.  **Global Validation**: Re-assemble the OOF predictions from all folds to calculate the global Quadratic Weighted Kappa (QWK) on the entire training set. This serves as the "Final Validation Metric".
6.  **Failure Analysis**: Compute the absolute error of predictions and calculate correlations with meta-features (word count, etc.) to identify systematic biases.
7.  **Submission Logic**: Compare the final validation metric against the threshold (0.8246384329994252). If the threshold is exceeded, execute the inference pipeline to generate `submission.csv`.
