This script demonstrates the end-to-end usage of the provided machine learning pipeline library. It overrides configuration parameters to ensure a fast execution (using a small subset of data and fewer training iterations), performs data cleaning, feature engineering, trains three models (XGBoost, LightGBM, and a ResNet), ensembles them using a Ridge Meta-Learner, and generates a submission file. Assertions are included at every step to validate the logic and data integrity.
