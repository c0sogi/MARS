Based on the comprehensive analysis of the previous experiments and the specific lessons learned, I propose a **Tri-Modal Stacked Ensemble with Deep Spatial Residual Network**.

This strategy structurally evolves the solution from a pure Gradient Boosting ensemble (Idea 7) to a hybrid architecture that integrates Deep Learning. By adding a Neural Network optimized for tabular data, we introduce a third "strong" learner with a fundamentally different error surface (smooth manifold approximation) to complement the step-function approximations of the decision trees.

# Model
I propose a **Two-Stage Stacked Ensemble** comprising three distinct base learners and a linear meta-learner.

*   **Level 0 (Base Learners):**
    1.  **XGBoost Regressor:** Configured for **Depth-wise** growth using the **NVIDIA A100 GPU** (`tree_method='gpu_hist'`). This captures complex interactions via deep, symmetric trees (Retained from Idea 7).
    2.  **LightGBM Regressor:** Configured for **Leaf-wise** growth using the **12 vCPUs** (`boosting_type='gbdt'`). This captures asymmetric patterns using Gradient-based One-Side Sampling (Retained from Idea 7).
    3.  **New: Deep Spatial ResNet (MLP):** A Feed-Forward Neural Network designed for tabular data.
        - **Architecture:** A Residual Network (ResNet) block structure (Linear $\rightarrow$ BatchNorm $\rightarrow$ ReLU $\rightarrow$ Dropout $\rightarrow$ Residual Add) to facilitate gradient flow.
        - **Inputs:** It will utilize **Entity Embeddings** for categorical features (e.g., Day of Week) and **Dense Layers** for continuous features.
        - **Role:** Unlike trees which split space into discrete hypercubes, this model learns continuous, smooth spatial functions, addressing the "staircase" approximation error of GBDTs (Cite solution_lesson_node_00003).

*   **Level 1 (Meta-Learner):**
    -   **Ridge Regression:** A linear model trained on the out-of-sample predictions of the three base learners to learn the optimal blending weights dynamically (Cite solution_lesson_node_00027).

# Data
**Preprocessing (Correction & Exploitation):**
1.  **Universal Coordinate Sanitation:** I will apply the strict bounding box filter (Lat 40–42, Lon -73 to -75) to **Training, Validation, AND Test sets**. This is mandatory to prevent "distance explosion" from outliers (Cite solution_lesson_node_00016).
2.  **Target Filtering:** The training data will be filtered to `fare_amount` between 0 and 500 (Cite solution_lesson_node_00005).
3.  **Full Dataset Utilization:** All models will be trained on the full 55 million row dataset (Cite solution_lesson_node_00012).

**Feature Engineering (Dual-Pipeline Strategy):**
I will implement two distinct feature pipelines to respect the specific strengths of Trees vs. Neural Networks:

*   **Shared Features:**
    -   **Rotated Coordinates:** 29° alignment to match the NYC grid (Cite solution_lesson_node_00003).
    -   **Landmark Distances:** Haversine distances to major hubs (JFK, WTC, etc.) (Cite solution_lesson_node_00003).
*   **Tree-Specific Pipeline (XGBoost/LightGBM):**
    -   **Raw Integers:** Use ordinal integers for `Hour`, `Day`, `Month`. We explicitly avoid cyclical embeddings here as trees handle raw splits better (Cite solution_lesson_node_00024).
    -   **No Scaling:** Raw coordinate values are used.
*   **Network-Specific Pipeline (ResNet):**
    -   **Standard Scaling:** All continuous features (Coordinates, Distances) will be scaled to zero mean and unit variance. This is critical for Neural Network convergence, correcting the failure of Idea 2.
    -   **Cyclical Embeddings:** Transform `Hour` and `Month` into **Sine and Cosine** components. We explicitly reserve this transformation for the Neural Network, where preserving temporal continuity is mathematically beneficial (Cite solution_lesson_node_00024).

# Training
*   **Strategy:** **Hold-out Blending**.
    1.  **Split:** The 55M dataset is split into "Base Train" (90%) and "Meta Train" (10%).
    2.  **Base Training:**
        -   **XGBoost & ResNet:** Trained on the **NVIDIA A100 GPU**. The ResNet will use a large batch size (e.g., 4096) and the AdamW optimizer with a OneCycleLR scheduler for rapid convergence.
        -   **LightGBM:** Trained on the **12 vCPUs**.
    3.  **Meta Training:** The three models predict on the "Meta Train" set. These predictions form the input for the Ridge Regression meta-learner.

# Evaluation
*   **Inference:**
    1.  Process the test set through both the **Tree Pipeline** and the **Network Pipeline**.
    2.  Generate base predictions from XGBoost, LightGBM, and ResNet.
    3.  Feed base predictions into the Ridge Regression meta-learner to generate the final `fare_amount` submission.
