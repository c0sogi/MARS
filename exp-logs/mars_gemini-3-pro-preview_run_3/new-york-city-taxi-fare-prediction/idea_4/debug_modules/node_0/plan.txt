The following implementation strategy outlines the steps to demonstrate the provided library components:

1.  **Configuration Adjustment**: Dynamically modify the `Config` class attributes to reduce the computational load (e.g., reducing the number of boosting rounds and clusters) to ensure the script completes quickly within the demonstration context.
2.  **Data Processing**: Instantiate the `DataProcessor` class to load a small sample of the data (5,000 rows) from the metadata parquet files. This step demonstrates the cleaning and basic feature engineering pipeline.
3.  **Advanced Feature Engineering**: Initialize the `SpatiotemporalEngine` to perform spatial clustering (KMeans) and Target Encoding on the sampled data. This demonstrates the fit/transform workflow for generating advanced features.
4.  **Model Training**: Use the `ModelManager` to train both XGBoost and LightGBM models on the processed sample data. This verifies the training loop, early stopping, and model persistence.
5.  **Prediction & Submission**: Generate predictions on the test set using the trained ensemble and create a submission file in the expected format.
6.  **Validation**: Throughout the script, assertions are used to verify that data shapes are correct, features are generated, and models are successfully saved to disk.
