The implementation strategy involves the following steps:
1.  **Setup and Loading**: Define input/output directories and load the large `labels.csv` dataset (approx. 55M rows) using Pandas with the PyArrow engine for efficiency.
2.  **Stratification**: Create stratification bins based on the `fare_amount` target variable using quantiles (`pd.qcut`). This ensures that the distribution of fare amounts is preserved across splits, which is crucial for regression tasks.
3.  **Splitting**: Perform a randomized 80/20 split of the training data into training and validation sets using `sklearn.model_selection.train_test_split`, ensuring the fixed random state (42) and using the generated bins for stratification.
4.  **Saving Metadata**: Save the resulting splits (`train.parquet`, `val.parquet`) and the processed test set (`test.parquet`) to the `./metadata` directory. Parquet format is chosen for its efficiency with large tabular datasets.
5.  **Verification**: Reload the saved files to perform mandatory checks:
    *   Calculate and print summary statistics (shapes, target distribution).
    *   Assert that the validation split ratio is strictly within the 80:20 requirement.
    *   Assert that the stratification succeeded by comparing the mean `fare_amount` of the training and validation sets.
    *   Note that file path checks are skipped as the dataset is self-contained tabular data without external file references.
