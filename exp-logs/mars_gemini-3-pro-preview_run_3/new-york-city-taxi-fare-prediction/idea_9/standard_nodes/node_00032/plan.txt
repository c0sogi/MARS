The implementation strategy involves a streamlined execution pipeline designed to meet the time constraints while ensuring rigorous validation. First, the script initializes the environment and adjusts model hyperparameters (reducing epochs and estimators) to facilitate a fast baseline run. It then loads the data and performs stratified sampling on the training sets (reducing them to 200k and 50k rows respectively) to minimize computational load, while keeping the validation and test sets intact for accurate evaluation. Feature engineering is forced to run on these sampled datasets to ensure consistency. The pipeline then trains three base learners (XGBoost, LightGBM, and Spatial ResNet) and a Ridge Regression meta-learner. Finally, the model is evaluated on the full validation set, failure analysis is performed by correlating residuals with input features, and a submission file is generated if the validation RMSE meets the specified threshold.
