Here is the implementation strategy for the `runfile.py` script:

1.  **Initialization**: Set random seeds for reproducibility using `seed_everything` and define necessary paths and constants from the configuration file.
2.  **Data Loading**: Initialize the `InkDataset` for both training and validation splits. Limit `patches_per_epoch` to ensure the training epoch completes quickly within the baseline time constraints. Create PyTorch `DataLoader` instances with pinned memory and multiple workers.
3.  **Model Setup**: Instantiate the `InkDetectorFCN` model and move it to the GPU. Configure the Adam optimizer.
4.  **Training Loop**: Execute the training process using `train_model`. This handles the training steps, validation on random crops for early stopping, and saves the best model weights to the working directory.
5.  **Full Validation & Metrics**: Load the best saved model. Iterate through the full validation fragments defined in the metadata. Perform tiled inference on the entire validation volumes to compute the precise "Final Validation Metric" (F0.5 score) required for evaluation, rather than relying solely on patch-based metrics.
6.  **Failure Analysis**: During the full validation inference, sample pixels to calculate the L1 error between predictions and ground truth. Compute and print the Pearson correlation between this error magnitude and input features (mean and standard deviation of pixel intensities) to identify error patterns.
7.  **Submission**: Call the `generate_submission` function to run inference on the test set and produce the `submission.csv` file.
