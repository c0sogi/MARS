This script implements the end-to-end pipeline for the Parallel-Scale Dilated Network (PSDN). It configures the system for a fast baseline run by adjusting the number of training epochs and steps. It then executes the training process, prints the final validation metric, and performs a failure analysis by correlating prediction errors with input volume statistics (mean intensity and standard deviation) on the validation set. Finally, if the validation score exceeds the specified threshold, it generates the submission file in the required directory.
