The following implementation demonstrates the end-to-end usage of the provided library files for the Vesuvius Ink Detection task.

### Implementation Strategy
1.  **Configuration**: We dynamically override the `Config` class attributes to optimize for a quick demonstration. This includes reducing the number of epochs to 1, disabling Test-Time Augmentation (TTA), and setting temporary working directories to ensure the script is self-contained and safe.
2.  **Verification**: We include explicit assertions for the utility functions `rle_encode` and `fbeta_score` to verify their logic before proceeding.
3.  **Data Loading**: We use the `get_loaders` function to instantiate training, validation, and test data loaders. We verify the integrity of the data pipeline by checking the dimensions of a single batch.
4.  **Model Instantiation**: We initialize the `DSDN_GN` model, move it to the GPU, and perform a dummy forward pass to confirm the architecture is compatible with the input data.
5.  **Training**: We execute a single training epoch using the `train_one_epoch` function from the engine module.
6.  **Evaluation**: We run the `evaluate` function on the validation set to calculate the F0.5 score and determine the optimal decision threshold.
7.  **Inference**: Finally, we use `predict_and_submit` to generate predictions for the test set and verify the format of the resulting `submission.csv`.
