Based on the analysis of previous experiments and the specific failure modes identified in the lessons, I propose the **Spatially Gated Dilated Network (SGDN) with Group Normalization**.

This solution introduces a structural innovation within the residual blocks to explicitly decouple feature extraction from spatial relevance, addressing the model's tendency to rely on simple intensity heuristics (Lesson 00017) while preventing the memorization of global context observed in deep architectures (Lesson 00027).

### Model: Spatially Gated Dilated Network (SGDN)

The architecture is a fully convolutional network operating at full resolution. It replaces standard residual blocks with **Spatially Gated Blocks** to dynamically suppress background noise (fibers) that shares texture with ink but differs in structural plausibility.

1.  **Learnable 2.5D Projection (Input Stage):**
    The network initializes with a learnable `1x1` convolution to project the 65-channel volumetric input into a compact feature space (e.g., 32 channels). This retains the proven "soft" slice selection mechanism **Cite solution_lesson_node_00002**.

2.  **Spatially Gated Residual Backbone:**
    The core innovation is the replacement of standard convolutional blocks with **Spatially Gated Blocks**.
    *   **Structure:** Each block consists of two parallel branches:
        *   **Feature Branch:** A standard Dilated Convolution ($3 \times 3$) $\to$ Group Norm $\to$ GeLU. This extracts texture and shape features.
        *   **Gating Branch:** A lightweight $1 \times 1$ Convolution $\to$ Sigmoid. This produces a spatial attention map (values $0$ to $1$) indicating the "ink-probability" of each pixel based on local context.
        *   **Fusion:** The output is computed as $Y = (\text{Feature}(X) \times \text{Gate}(X)) + X$.
    *   **Rationale:** This structure forces the network to explicitly learn *where* to look (Gating) separate from *what* to see (Features). This is critical for suppressing papyrus fibers, which have high intensity (feature match) but linear/grid-like structures that differ from handwriting (gate suppression), directly addressing the underfitting/intensity-bias **Cite solution_lesson_node_00017**.

3.  **Constrained Hierarchical Depth:**
    The backbone will consist of a **medium depth** (e.g., 8 blocks) with sequentially increasing dilation rates (e.g., $1, 2, 4, 8, 1, 2, 4, 8$).
    *   **Sequential:** We retain the hierarchical aggregation proven superior to parallel designs **Cite solution_lesson_node_00015**.
    *   **Constrained:** We explicitly cap dilation at 8 and depth at ~8 blocks. This restricts the maximum receptive field to prevent the model from memorizing global coordinates or fragment-specific artifacts, addressing the overfitting observed in deeper models **Cite solution_lesson_node_00027**.

4.  **Group Normalization:**
    All normalization layers are **Group Normalization (GN)** (groups=8). This decouples training stability from batch size, allowing us to train this more expressive architecture without the instability caused by small-batch Batch Normalization **Cite solution_lesson_node_00025**.

### Data: Intensity Invariance and Deterministic Validation

1.  **Intensity Perturbation (Crucial Addition):**
    To directly counter the high error-to-intensity correlation observed in previous failures **Cite solution_lesson_node_00017**, we will introduce **Random Intensity Scaling** during training.
    *   **Method:** For each input patch, multiply the voxel values by a random factor (e.g., $0.8$ to $1.2$) and add a random offset.
    *   **Effect:** This destroys the absolute intensity signal, forcing the model to learn relative contrast and structural morphology (i.e., "ink is darker than *surrounding* fiber") rather than memorizing a global brightness threshold.

2.  **Preprocessing & Augmentation:**
    *   **Normalization:** Use Global Z-score statistics from the training set **Cite solution_lesson_node_00028**.
    *   **Geometric:** Apply random flips and discrete 90-degree rotations to enforce rotational invariance **Cite solution_lesson_node_00005**.
    *   **Patch Size:** Strictly maintain large patches ($256 \times 256$) to preserve structural context **Cite solution_lesson_node_00019**.

3.  **Deterministic Validation:**
    Validation will be performed on a **fixed, deterministic grid** of tiles covering the validation fragment. This ensures that metric improvements are genuine and not artifacts of stochastic sampling **Cite solution_lesson_node_00010**.

### Training: Balanced Optimization

1.  **Loss Function:**
    Use a **Balanced Loss** (`BCE + Dice`). We avoid skewing the loss weights (e.g., Tversky with high alpha) as this was shown to degrade the quality of the learned probability landscape **Cite solution_lesson_node_00011**, **Cite solution_lesson_node_00009**.

2.  **Optimization:**
    *   **Optimizer:** AdamW with weight decay.
    *   **Strategy:** Train with Early Stopping based on the stabilized F0.5 score from the deterministic validation set.

### Evaluation: Precision-Oriented Inference

1.  **Tiled Inference with TTA:**
    Inference will be performed using overlapping tiles. **Test-Time Augmentation (TTA)** (averaging predictions across 4 rotations and 2 flips) will be applied to suppress false positives from oriented fibers **Cite solution_lesson_node_00005**.

2.  **Dynamic Threshold Tuning:**
    The optimal binarization threshold will be explicitly searched for on the validation set to maximize the F0.5 score. This adapts the balanced model output to the precision-heavy metric without biasing the training process **Cite solution_lesson_node_00011**.
