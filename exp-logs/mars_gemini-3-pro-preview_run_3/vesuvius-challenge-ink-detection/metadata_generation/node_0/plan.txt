To implement the requested task, I will create a Python script that scans the `./input` directory to identify fragment data for training and testing. The script will treat each fragment (identified by its directory name) as a distinct group/sample.

The strategy is as follows:
1.  **Data Discovery**: The script will iterate through `input/train` and `input/test` directories. For each fragment, it will record the paths to key files (`mask.png`, `ir.png`, `inklabels.png`, and the `surface_volume` directory). It will also read the dimensions of the fragment using `opencv` to include in the metadata (height, width).
2.  **Splitting**: I will use a group-based splitting strategy. The training fragments will be listed and shuffled with a fixed random seed (42). I will perform an 80/20 split on these fragments to create training and validation sets. If the number of fragments is small (e.g., 2), I will ensure at least one fragment is assigned to each set to satisfy the requirement for a validation set.
3.  **Metadata Generation**: Three CSV files (`train.csv`, `val.csv`, `test.csv`) will be generated in the `./metadata` directory. These files will contain relative paths to the assets and metadata like image dimensions.
4.  **Verification**: Immediately after generation, the script will load the created metadata files. It will:
    *   Verify that the validation split is disjoint from the training set.
    *   Calculate summary statistics (count of fragments, average dimensions).
    *   Perform a file existence check. To ensure a robust check (aiming for ~1000 paths), I will not only check the main asset paths (mask, ir) but also sample individual `.tif` slice paths within the `surface_volume` directories referenced in the metadata.
    *   Raise errors if files are missing or if the split logic fails.
