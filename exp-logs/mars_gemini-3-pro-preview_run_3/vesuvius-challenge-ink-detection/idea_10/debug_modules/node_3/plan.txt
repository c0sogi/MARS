The `RuntimeError: expected scalar type Double but found Float` occurs because the normalization statistics (`mean` and `std`) are `float64` (NumPy default), causing the image data to be promoted to `float64` during normalization. This results in `DoubleTensor` inputs being fed to a `Float` model. To resolve this, I will modify `library/dataset.py` to explicitly cast the normalized image data back to `np.float32` in both `InkDataset` and `InferenceDataset` before converting to tensors. Cite debug_lesson_3.
