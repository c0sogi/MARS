Based on the lessons learned from previous iterations, I propose the **Densely Connected Dilated Network (DCDN)**. This solution introduces a structural innovation—**Global Feature Aggregation**—to resolve the conflict between preserving fine local details (texture) and capturing broad geometric context (shape), while strictly adhering to the stability and efficiency constraints identified in the failure analysis.

### Model: Densely Connected Dilated Network (DCDN)

The architecture is a fully convolutional network that operates at full resolution. It abandons the strictly sequential information flow of the baseline and the unstable parallel branches of previous attempts in favor of a **Dense Aggregation Topology**.

1.  **Learnable 2.5D Projection (Input Stage):**
    The network accepts the full 3D volume `(Batch, 65, H, W)` and initializes with a learnable `1x1` convolution to compress the depth dimension into a compact feature space (e.g., 32 channels). This retains the highly effective "soft" slice selection mechanism **Cite solution_lesson_node_00002**.

2.  **Sequential Dilated Backbone (Feature Extraction):**
    The backbone consists of a sequence of **Dilated Residual Blocks** with hierarchically increasing dilation rates (e.g., $r=1, 2, 4, 8$).
    *   **Sequential Hierarchy:** We retain the sequential arrangement, which was proven superior to parallel blocks for feature extraction **Cite solution_lesson_node_00015**.
    *   **Full Resolution:** Crucially, the network employs **no downsampling** (pooling). It maintains the original spatial resolution throughout to preserve pixel-thin ink traces **Cite solution_lesson_node_00008**.
    *   **Lean Width:** To prevent overfitting and maintain speed, each block keeps a constant, lean channel width (e.g., 32). This acts as a structural regularizer **Cite solution_lesson_node_00004**.

3.  **Global Feature Aggregation (Structural Innovation):**
    Instead of using only the output of the final block for classification, the network employs **Dense Skip Connections**.
    *   **Mechanism:** The output feature maps from *every* dilated block in the backbone are concatenated into a single "Hypercolumn" tensor at the end of the network.
    *   **Rationale:** This topology allows the final classifier to simultaneously access **high-frequency local texture** (from early, low-dilation blocks) and **low-frequency global shape** (from deep, high-dilation blocks). This explicitly addresses the "Error-to-Intensity" correlation **Cite solution_lesson_node_00017** by providing the classifier with the multi-scale context needed to distinguish dark ink from dark fibers, without the instability of multiplicative gating **Cite solution_lesson_node_00029**.

4.  **Output Head:**
    A final `1x1` convolution maps the aggregated features (e.g., $32 \times 4 = 128$ channels) to the single probability map.

### Data: High-Fidelity Context and Deterministic Validation

1.  **Preprocessing:**
    Input volumes are Z-score normalized using **Global Statistics** (mean/std) calculated from the training set. We explicitly reject instance normalization to preserve the physical density signal of the ink **Cite solution_lesson_node_00028**.

2.  **Patch Size & Augmentation:**
    *   **Large Context:** Training will strictly use **large patches (256x256)**. We will not sacrifice spatial context for throughput, as this destroys the structural signal **Cite solution_lesson_node_00019**.
    *   **Geometric Augmentation:** Random horizontal/vertical flips and discrete 90-degree rotations will be applied to force the model to learn rotationally invariant features **Cite solution_lesson_node_00005**.

3.  **Deterministic Validation:**
    Validation will be performed on a **fixed, deterministic grid** of tiles covering the validation fragment. This eliminates metric volatility and ensures that model selection is based on genuine generalization rather than sampling noise **Cite solution_lesson_node_00007**, **Cite solution_lesson_node_00010**.

### Training: Balanced Optimization and Stability

1.  **Loss Function:**
    The model will be trained using a **Balanced Loss** (`BCE + Dice`). We explicitly avoid Tversky Loss with high alpha (precision bias) during training, as this degrades the quality of the learned probability landscape. The precision requirement of the F0.5 metric will be handled via post-processing **Cite solution_lesson_node_00009**, **Cite solution_lesson_node_00011**.

2.  **Batch Size Priority:**
    We will prioritize a healthy **Batch Size (e.g., 32)** over model depth. The parameter efficiency of the Dense Aggregation (feature reuse) allows us to train a powerful model without reducing the batch size, avoiding the instability associated with small-batch Batch Normalization **Cite solution_lesson_node_00025**.

3.  **Patience:**
    We will adhere to a strict early stopping patience (e.g., 3-5 epochs) based on the stabilized validation metric, avoiding the trap of extending patience on noisy signals **Cite solution_lesson_node_00006**.

### Evaluation: Precision-Oriented Inference

1.  **Tiled Inference with TTA:**
    Predictions will be generated using overlapping tiles. **Test-Time Augmentation (TTA)** (averaging predictions across 4 rotations and 2 flips) will be applied to suppress false positives caused by specific fiber orientations **Cite solution_lesson_node_00005**.

2.  **Dynamic Threshold Tuning:**
    Instead of a fixed 0.5 threshold, the optimal binarization threshold will be explicitly searched for on the validation set to maximize the F0.5 score. This adapts the balanced model output to the competition's precision-weighted metric **Cite solution_lesson_node_00011**.
