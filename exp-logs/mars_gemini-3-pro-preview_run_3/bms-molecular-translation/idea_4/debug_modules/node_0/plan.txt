This script demonstrates the usage of the provided library components for the InChI prediction task. It covers the following steps:

1.  **Configuration**: Sets up the environment and overrides `Config` for a fast demonstration run (using subsets of data).
2.  **Tokenizer**: Initializes and fits the tokenizer on the training metadata. Verifies text-to-sequence conversion.
3.  **Dataset & DataLoader**: Loads metadata, subsets it for speed, and creates PyTorch Datasets and DataLoaders for training and testing. Verifies data shapes.
4.  **Model**: Instantiates the Seq2Seq model (EfficientNet encoder + GRU decoder). Verifies the forward pass and prediction shapes.
5.  **Training**: Runs a single epoch of training using the `Trainer` class on the small subset to demonstrate the training loop.
6.  **Submission**: Generates a submission file for the test subset using the trained model.
