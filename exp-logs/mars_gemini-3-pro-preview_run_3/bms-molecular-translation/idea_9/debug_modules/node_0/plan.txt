This script demonstrates the end-to-step usage of the provided InChI recognition library. To ensure the code runs quickly within the time limit, I create small subsets of the training and validation metadata files in the working directory. This avoids processing the entire dataset (1.5M+ rows) when initializing the tokenizer and dataset, specifically preventing the potentially long atom count pre-calculation.

The script performs the following steps:
1.  **Setup**: Sets random seeds and creates mini-metadata files.
2.  **Tokenizer**: Initializes the tokenizer on the mini-dataset and verifies encoding/decoding logic.
3.  **Dataset**: Initializes the dataset with the mini-metadata, verifying item structure and shapes.
4.  **Model**: Instantiates a smaller version of the `MixerTransformer` model and validates the forward pass dimensions.
5.  **Training**: Runs the provided `train_fn` for one epoch on the mini-dataset to demonstrate the training loop.
6.  **Evaluation**: Runs the provided `eval_fn` on the mini-validation set to demonstrate inference and metric calculation.
