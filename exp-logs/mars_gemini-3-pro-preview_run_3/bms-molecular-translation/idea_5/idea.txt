### Proposed Solution: ResNet-TCN (Convolutional Sequence Modeling)

This approach introduces a fully convolutional architecture for the Image-to-InChI translation task. It replaces the Recurrent Neural Networks (RNNs) found in **Model 1** and **Idea 4** and the Transformers found in **Model 2** and **Idea 2** with a **Temporal Convolutional Network (TCN)** decoder. This design prioritizes training throughput via parallelism while maintaining a distinct architectural inductive bias (hierarchical dilation) suitable for long sequence generation.

#### Model
*   **Encoder (CNN Backbone):** Utilize **ResNet-34** (pre-trained on ImageNet).
    *   This backbone offers a robust balance between feature extraction capability and computational speed.
    *   Apply **Global Average Pooling** to the final feature map to compress the spatial information into a single, compact global context vector. This vector summarizes the molecular structure (atoms, bond density, rings) without the computational overhead of maintaining a spatial grid for attention mechanisms.
*   **Decoder (TCN):** Implement a **Temporal Convolutional Network** as the sequence generator.
    *   **Architecture:** The decoder consists of a stack of **1D Causal Dilated Convolutional** layers. "Causal" ensures that the prediction at step $t$ depends only on history, not future tokens. "Dilated" ensures that the receptive field grows exponentially with depth, allowing the model to capture the long-range dependencies inherent in complex InChI strings (which can exceed 200 characters) without the vanishing gradient problems of RNNs.
    *   **Conditioning:** The global context vector from the encoder is projected and concatenated with the character embeddings at the input of the TCN, or added as a residual bias to every layer, ensuring the generated sequence remains strictly conditioned on the input image.
    *   **Output:** A final linear layer maps the TCN output channels to the character vocabulary size.

#### Data
*   **Preprocessing:**
    *   **Resizing:** Resize all input images to a fixed resolution of **256 x 256**. This resolution is sufficient to capture the connectivity of the majority of molecules while maximizing batch size and throughput.
    *   **Normalization:** Normalize pixel values to the range $[0, 1]$ using standard dataset statistics.
    *   **Tokenization:** Construct a character-level vocabulary from the training labels. Convert InChI strings into integer sequences, appending `<SOS>` (Start of Sequence) and `<EOS>` (End of Sequence) tokens. Pad all sequences to a fixed length (e.g., 256) to enable efficient batched tensor operations.
*   **Augmentation:** To establish a stable and fast baseline, no data augmentation will be applied.

#### Training
*   **Loss Function:** Standard **Cross-Entropy Loss**, calculated between the predicted character distribution and the ground truth indices.
*   **Optimizer:** Use the **AdamW** optimizer for stable convergence.
*   **Strategy (Parallelism):** A key advantage of this architecture is **fully parallelized training**. Unlike RNNs (Idea 1, Idea 4), which require sequential computation of hidden states, the TCN can process the entire ground-truth sequence and the image context simultaneously in a single forward pass (using causal masking). This drastically reduces the wall-clock time required per epoch.

#### Evaluation
*   **Inference Process:**
    *   Pass the test image through the ResNet encoder to obtain the global context vector.
    *   **Greedy Decoding:** Initialize the sequence with the `<SOS>` token.
    *   Iteratively run the TCN decoder: feed the current sequence, obtain the probability distribution for the next character, select the character with the highest probability, and append it to the sequence.
    *   Repeat until the `<EOS>` token is generated or a maximum length limit is reached.
    *   Reconstruct the InChI string from the generated tokens.
