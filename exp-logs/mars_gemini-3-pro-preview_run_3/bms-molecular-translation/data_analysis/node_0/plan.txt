This script performs a comprehensive Exploratory Data Analysis (EDA) on the training dataset defined in `metadata/train_metadata.csv`. It analyzes the target variable (InChI text strings) by examining sequence lengths and vocabulary composition. For the input data (images), it performs a stratified sampling of 5,000 images to efficiently compute statistics on dimensions, aspect ratios, channel counts, and pixel intensity distributions without processing the entire 1.5M dataset. Finally, it investigates relationships between image properties (size, aspect ratio) and the complexity of the target molecule (InChI length) to inform preprocessing decisions like image resizing and sequence padding.
