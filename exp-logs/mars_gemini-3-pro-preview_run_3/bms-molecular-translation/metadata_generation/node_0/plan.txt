The following Python script generates the required metadata files for the training, validation, and test datasets. It reads the provided labels and submission files, constructs the relative file paths for the images based on the specified folder structure, and creates a stratified 80/20 split for the training and validation sets based on the length of the InChI strings (as a proxy for molecule complexity). Finally, it performs rigorous validation checks to ensure the metadata is correct, file paths are valid, and the stratification was successful.
