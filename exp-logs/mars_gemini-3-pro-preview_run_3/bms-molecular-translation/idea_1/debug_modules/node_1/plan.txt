This mismatch causes a `RuntimeError` in the `BatchNorm1d` layer because it is initialized with 960 features but receives an input with 1280 features. To fix this, I will modify the `EncoderCNN` initialization to dynamically determine the correct output dimension by performing a dummy forward pass through the backbone.
