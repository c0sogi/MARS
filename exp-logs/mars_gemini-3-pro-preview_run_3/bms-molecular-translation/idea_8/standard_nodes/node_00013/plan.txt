This script orchestrates the entire pipeline. It first initializes the configuration and tokenizer. To ensure the training phase completes quickly within the baseline constraints, it enables debug mode with a limited sample size (20,000 samples) and runs for 2 epochs. It then trains the model using the provided `Trainer` class. After training, it performs a detailed validation and failure analysis on the hold-out validation set, calculating the Levenshtein distance and correlating errors with input features (InChI length and image dimensions). Finally, it disables debug mode to load the full test set and generates predictions for submission using the trained model.
