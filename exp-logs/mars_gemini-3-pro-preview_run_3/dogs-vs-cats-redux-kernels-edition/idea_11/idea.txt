Based on the accumulated lessons, I propose a **Triple Heterogeneous Ensemble with Multi-Axis Attention and Multi-Sample Dropout**.

This strategy structurally evolves the "Current Best" (Idea 8) by upgrading the Transformer backbone and the classification heads. It retains the successful "Decoupled Resolution" strategy but replaces the Window-based Swin Transformer with a **Multi-Axis Vision Transformer (MaxViT)** to capture stronger global context. Furthermore, it integrates **Multi-Sample Dropout** to explicitly optimize Log Loss, correcting the optimization mismatch that caused the failure of Idea 10.

### Model
**Architecture:** Implement a **Heterogeneous Ensemble** of three backbones, selected to maximize inductive bias diversity (Cite solution_lesson_node_00016, solution_lesson_node_00023):
1.  **ResNet-50:** The "Standard CNN" anchor. Provides robust, texture-based feature extraction (Cite solution_lesson_node_00002).
2.  **ConvNeXt-Small:** The "Modern CNN". Utilizes large kernels and inverted bottlenecks to capture semantic context (Cite solution_lesson_node_00016).
3.  **MaxViT-Tiny:** The "Multi-Axis Transformer". **Structural Innovation.** This replaces Swin-Tiny. While Swin is limited to local window attention, MaxViT employs **Block Attention (Local)** and **Grid Attention (Global)** in a single stage. This allows the model to capture long-range dependencies more effectively than Swin, providing a distinct error profile from the CNNs. We stick to the "Tiny" variant to avoid the convergence issues observed with larger models in short training windows (Cite solution_lesson_node_00031).

**Head Design (Structural Innovation):**
Replace the standard linear classification head in *all three models* with a **Multi-Sample Dropout Head**.
*   **Mechanism:** The feature map is passed through 5 parallel dropout layers (with varying rates, e.g., 0.1–0.5) before entering the final linear layer. The outputs are averaged.
*   **Rationale:** This creates a lightweight "internal ensemble" within each model. It smooths the decision boundary and penalizes overconfidence on noisy features, directly lowering Log Loss without the "loss floor" drawback of Label Smoothing (Cite solution_lesson_node_00012).

### Data
**Preprocessing:** Maintain the **Decoupled Input Pipeline** to maximize fidelity (Cite solution_lesson_node_00028).
*   **Pipeline A (ResNet-50, ConvNeXt-Small):** Resize images to **256x256**. This resolution allows the CNNs to exploit fine spatial details, which has been proven to improve performance (Cite solution_lesson_node_00005).
*   **Pipeline B (MaxViT-Tiny):** Resize images to **224x224**. This aligns with the native grid structure of the Transformer, avoiding the interpolation artifacts and performance loss seen when forcing Transformers to non-native resolutions (Cite solution_lesson_node_00028).
*   **Interpolation:** Strictly use **Bicubic Interpolation** for all pipelines to align with modern pre-training recipes (Cite solution_lesson_node_00024).

**Augmentation:** Apply **Context-Preserving Augmentation** (Cite solution_lesson_node_00005).
*   Use `RandomResizedCrop` with a scale of `(0.8, 1.0)` to ensure the subject is never cropped out.
*   Apply `ColorJitter` with intensity $\ge 0.2$ to handle lighting variance (Cite solution_lesson_node_00024).

### Training
**Strategy:** Train each model independently.
*   **Correction:** We explicitly **remove Stochastic Weight Averaging (SWA)**. Previous attempts (Idea 10) failed because the short training horizon was insufficient for SWA to stabilize (Cite solution_lesson_node_00034). We return to a standard, robust optimization path.
*   **Optimizer:** Use **AdamW** with a **Cosine Annealing** scheduler (Cite solution_lesson_node_00007).
*   **Loss Function:** Use **Binary Cross-Entropy with Logits Loss** (`BCEWithLogitsLoss`) **without Label Smoothing** (Cite solution_lesson_node_00012).
*   **Duration:** Train for **8-10 epochs**. This ensures the model receives sufficient gradient updates to converge, compensating for the batch size and the complexity of the MaxViT backbone (Cite solution_lesson_node_00009).

### Evaluation
**Inference & Aggregation:**
1.  **Test Time Augmentation (TTA):** For every test image, generate probabilities using both the original and a horizontally flipped version for each model. Average these pairs (Cite solution_lesson_node_00007).
2.  **Ensemble Averaging:** Calculate the final probability by taking the **arithmetic mean** of the outputs from the ResNet-50, ConvNeXt-Small, and MaxViT-Tiny. This combines the benefits of diverse architectures and decoupled resolutions (Cite solution_lesson_node_00016).
