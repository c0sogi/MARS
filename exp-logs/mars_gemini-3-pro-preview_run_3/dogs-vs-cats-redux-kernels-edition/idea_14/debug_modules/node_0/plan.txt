The following script demonstrates the usage of the provided machine learning library components. It follows a logical pipeline:
1.  **Setup**: Sets random seeds for reproducibility.
2.  **Data Verification**: Instantiates datasets in debug mode (subset) and verifies output shapes and types.
3.  **Model Initialization**: Creates the required ResNet, ConvNeXt, and MaxViT models (without pre-trained weights for speed).
4.  **Training Simulation**: Runs a single epoch of training for the teacher models and the student model (via distillation) on the debug dataset to generate valid checkpoint files.
5.  **Inference**: Executes the full inference pipeline using the generated checkpoints and the test dataset, producing a submission file.
6.  **Validation**: Asserts that the submission file is created correctly.
