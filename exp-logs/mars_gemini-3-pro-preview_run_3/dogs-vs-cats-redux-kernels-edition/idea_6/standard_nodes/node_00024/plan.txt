Implementation Strategy:
1.  **Setup & Imports**: Import necessary libraries and the provided modules (`library.config`, `library.utils`, `library.train`, `library.inference`, `library.dataset`, `library.models`). Set the random seed for reproducibility.
2.  **Training**: Execute `train_all_models()` to train the three architectures (ResNet50, ConvNeXt-Small, EfficientNetV2-S) sequentially. This utilizes the A100 GPU efficiently to complete within the time limit.
3.  **Validation**: Implement a custom `validate_ensemble` function.
    *   Load the validation dataset.
    *   Iterate through each trained model, load its best checkpoint, and generate predictions on the validation set.
    *   Use Test Time Augmentation (TTA) (averaging original and flipped predictions) during validation to match the inference strategy and maximize accuracy.
    *   Average the predictions from all models to form the ensemble prediction.
    *   Calculate the Log Loss against the ground truth labels.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**: Implement `analyze_failures`.
    *   Calculate the error magnitude (`|label - prediction|`) for each validation sample.
    *   Extract image metadata (width, height, aspect ratio, file size) from the validation files on-the-fly.
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify potential biases.
5.  **Submission Logic**:
    *   Compare the calculated validation metric against the strict threshold (`0.009311713870561527`).
    *   If the metric is lower than the threshold, call `run_ensemble()` to generate the submission file.
    *   Otherwise, skip submission and print a notification.
