Based on the accumulated lessons, specifically the need for architectural diversity (Lesson 00023) and the specific failure mode observed when integrating Transformers with CNNs (Lesson 00028), I propose a **Decoupled Multi-Resolution Hybrid Ensemble**.

This strategy structurally evolves the previous "Hybrid" attempt (Idea 7) by abandoning the "Lowest Common Denominator" preprocessing approach. Instead of forcing all models to a single resolution, we will implement parallel data pipelines that allow each architecture to operate at its optimal input fidelity.

### Model
**Architecture:** Implement a **Heterogeneous Ensemble** comprising three backbones with distinct inductive biases to maximize error decorrelation (Cite solution_lesson_node_00016):
1.  **ResNet-50:** The "Standard CNN" anchor. It provides robust texture-based feature extraction (Cite solution_lesson_node_00002).
2.  **ConvNeXt-Small:** The "Modern CNN". Its large-kernel, inverted bottleneck design captures broader semantic context (Cite solution_lesson_node_00016).
3.  **Swin-Tiny:** The "Hierarchical Transformer". This replaces the underperforming EfficientNetV2 (Cite solution_lesson_node_00024). It utilizes shifted-window self-attention, introducing a global dependency modeling capability that is fundamentally different from convolutions (Cite solution_lesson_node_00023).

**Initialization:** Initialize ResNet-50 with **`IMAGENET1K_V2`** weights and the others with their best available default pre-trained weights to ensure high-quality feature extraction (Cite solution_lesson_node_00006).

### Data
**Preprocessing (Structural Innovation):** Implement **Decoupled Input Pipelines** (Cite solution_lesson_node_00028).
*   **Pipeline A (High-Fidelity CNNs):** For ResNet-50 and ConvNeXt-Small, resize images to **256x256**. This preserves the fine spatial details that were proven to improve performance in earlier lessons (Cite solution_lesson_node_00005).
*   **Pipeline B (Native Transformer):** For Swin-Tiny, resize images to **224x224**. This respects the model's fixed window-attention mechanism without forcing the CNNs to downscale, avoiding the information loss that caused Idea 7 to fail (Cite solution_lesson_node_00028).
*   **Interpolation:** Strictly use **Bicubic Interpolation** for both pipelines to align with modern pre-training recipes and avoid texture aliasing (Cite solution_lesson_node_00024).

**Augmentation:** Apply **Context-Preserving Augmentation** to both pipelines.
*   Use `RandomResizedCrop` with a scale of `(0.8, 1.0)` to prevents subject loss.
*   Apply `ColorJitter` with intensity $\ge 0.2$ to handle lighting variance (Cite solution_lesson_node_00024).

### Training
**Strategy:** Train each of the three models independently.
*   **Optimizer:** Use **AdamW** with a **Cosine Annealing** scheduler to smooth the optimization path (Cite solution_lesson_node_00007).
*   **Loss Function:** Use **Binary Cross-Entropy with Logits Loss** (`BCEWithLogitsLoss`) **without Label Smoothing**. We strictly avoid Label Smoothing to prevent the "loss floor" issue, enabling the models to minimize Log Loss for high-confidence predictions (Cite solution_lesson_node_00012).
*   **Scaling:** Adjust the number of epochs (e.g., 8-10) to ensure the total number of gradient update steps remains sufficient, compensating for the batch size used (Cite solution_lesson_node_00009).

### Evaluation
**Inference & Aggregation:**
1.  **Test Time Augmentation (TTA):** For every test image, generate probabilities using both the original and a horizontally flipped version for each model. Average these pairs to stabilize predictions (Cite solution_lesson_node_00007).
2.  **Ensemble Averaging:** Calculate the final probability by taking the **arithmetic mean** of the outputs from the ResNet-50, ConvNeXt-Small, and Swin-Tiny. This leverages the uncorrelated errors of the diverse architectures (CNN vs. Transformer) while maintaining the resolution advantage of the CNNs (Cite solution_lesson_node_00016).
