The following script demonstrates the usage of the provided library files for the Dog vs Cat classification task.

### Implementation Strategy
1.  **Environment Setup**: We create a temporary working directory and generate "mini" versions of the training, validation, and test metadata (e.g., 50 training samples) to ensure the demonstration runs in seconds rather than hours.
2.  **Configuration Override**: We modify the `Config` class attributes to point to these mini-datasets and define a minimal model configuration (ResNet50, 1 epoch, reduced image size) to optimize for speed.
3.  **Component Verification**: We sequentially instantiate and verify the core components:
    *   **Data**: Check `CatDogDataset` and `DataLoader` for correct batch shapes.
    *   **Modeling**: Check `get_model` for correct output dimensions.
    *   **Engine**: Run a single training and validation step to verify the loop mechanics.
    *   **Calibration**: Verify the `Calibrator` logic with synthetic data.
4.  **Full Pipeline**: Execute `run_kfold_ensemble` in debug mode to simulate the full workflow and generate a valid submission file.
