The `AssertionError: height (48) must be divisible by window (7)` occurred because the `maxvit_tiny` model (a Hierarchical Vision Transformer) imposes strict geometric constraints on the input resolution. Specifically, the input height/width must be divisible by the product of the patch size (4) and the window size (7), i.e., 28. The configured image size of 192 is not divisible by 28 ($192 / 28 \approx 6.85$), causing the crash (Cite `debug_lesson_4`). I will update the configuration to use 224 (which is $28 \times 8$) for the first training phase of `maxvit_tiny`.

Additionally, since the pipeline crashed after successfully training `resnet50` and `convnext_small`, restarting the script would waste time re-training them. I will modify the training loop to check for the existence of the best model checkpoint before starting training, allowing the pipeline to resume execution from the failed model (Cite `debug_lesson_3`).
