The `TypeError` occurs because the `resnet50` model constructor in the `timm` library does not accept the `img_size` argument, which is typically required only for Vision Transformers (ViT) to initialize fixed-size positional embeddings. Standard CNNs like ResNet and ConvNeXt are fully convolutional and do not require an explicit input size at initialization. To fix this, I will modify `create_model` in `library/modeling.py` to conditionally pass `img_size` only when the `model_name` suggests a transformer architecture (e.g., contains "vit", "swin", or "deit").
