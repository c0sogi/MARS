This script demonstrates the end-to-end usage of the provided machine learning library for the Dog vs. Cat classification task.

The strategy involves:
1.  **Configuration Override**: Modifying the `Config` class to run in `DEBUG` mode with a small subset of data (100 samples), reduced batch size (8), and limited epochs (1) to ensure the script completes quickly (within minutes) while exercising all code paths.
2.  **Component Verification**: Systematically instantiating and verifying the logic of custom layers (`GeM`, `MultiSampleDropout`), data loaders, and the model factory.
3.  **Training & Inference Simulation**: Running a complete training cycle using the `Trainer` class, followed by evaluating the model and generating a submission file.
4.  **Validation**: Using assertions to confirm tensor shapes, data integrity, and the existence of the final output file.
