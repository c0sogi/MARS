### Implementation Strategy

1.  **Setup & Reproducibility**: Initialize the environment using `seed_everything` to ensure consistent results. Define a lightweight configuration (ResNet18, small batch size, 1 epoch) to ensure the demo runs quickly.
2.  **Data Pipeline Verification**:
    *   Load the metadata and generate folds using `load_data_and_create_folds`.
    *   **Crucial Optimization**: Subsample the dataframe to a tiny fraction (e.g., 50 images) to prevent long processing times during the demo.
    *   Verify `CatDogDataset` and `get_dataloaders` by inspecting output shapes and types.
3.  **Model & Training Verification**:
    *   Instantiate a lightweight model (`resnet18`) using `get_model`.
    *   Run the `fit` function on the subsampled data. This demonstrates the training loop, validation logic, and checkpoint saving mechanism.
    *   Assert that the model checkpoint is successfully created.
4.  **Inference & Ensemble Verification**:
    *   **Monkey Patching**: Temporarily override `library.inference.ENSEMBLE_CONFIGS` with the demo configuration. This forces the inference engine to use the model we just trained/configured instead of the heavy default ensemble.
    *   Execute `generate_ensemble_predictions` to generate a submission file.
    *   Validate the output submission file for correct format and value ranges.
