### **Baseline Proposal: End-to-End ResNet-18 Fine-Tuning**

This approach simplifies the hybrid pipeline described in **Model 3** by retaining the **ResNet-18** backbone but replacing the complex LightGBM classification stage with a standard, differentiable linear layer. This results in a unified, lightweight Convolutional Neural Network (CNN) that can be trained end-to-end, offering a perfect balance of speed and accuracy for a baseline.

#### **1. Model**
*   **Architecture:** Use a **ResNet-18** model pre-trained on ImageNet.
*   **Modification:** Remove the original 1000-class fully connected layer and replace it with a single fully connected layer with 1 output neuron (for binary classification).
*   **Initialization:** Initialize the backbone with pre-trained ImageNet weights to leverage learned feature representations (edges, textures) and initialize the new head randomly.

#### **2. Data**
*   **Preprocessing:** 
    *   **Resize:** Resize all images to **224x224** pixels (the native resolution for standard ResNet models).
    *   **Normalization:** Convert pixel values to tensors and normalize using standard ImageNet mean (`[0.485, 0.456, 0.406]`) and standard deviation (`[0.229, 0.224, 0.225]`).
*   **Loaders:** Use standard batch loaders with shuffling for the training set. No heavy augmentations (like MixUp or CutMix) will be used, only simple resizing and normalization to maintain high throughput.

#### **3. Training**
*   **Loss Function:** Use **Binary Cross-Entropy with Logits Loss** (`BCEWithLogitsLoss`), which combines a Sigmoid layer and the BCELoss in one single class, providing numerical stability.
*   **Optimizer:** Use the **Adam** optimizer with a conservative learning rate (e.g., `1e-4`) to fine-tune the weights without destroying the pre-trained features.
*   **Procedure:** Train for a small number of epochs (e.g., 3-5) to ensure convergence without overfitting, given the relatively small dataset size and strong pre-training.

#### **4. Evaluation**
*   **Inference:** Iterate through the test dataset using the same preprocessing steps (Resize + Normalize).
*   **Prediction:** Pass images through the model and apply a **Sigmoid** activation function to the raw output logits to obtain a probability score between 0 and 1 (representing the probability of the class "dog").
*   **Submission:** Map the resulting probabilities to the corresponding image IDs and save to CSV format.
