Implementation Strategy:
1.  **Environment Setup**: Configure random seeds and detect the computation device using `library.utils`.
2.  **Data Pipeline Verification**: Initialize dataloaders with a small `debug_subset` using `library.data`. Assert that batch shapes for images, labels, and IDs are correct.
3.  **Model Architecture Check**: Instantiate a `resnet101` model using `library.models`. Verify the presence of the custom `GeM` pooling layer and confirm that a dummy forward pass produces the expected output shape `(B, 1)`.
4.  **Training Simulation**: Execute `fit_model` from `library.engine` for a single epoch on the data subset. This verifies the integration of the optimizer, loss function, and training loop.
5.  **Inference & Validation**: Use the trained model to generate predictions on the test subset via `predict`. Validate that the output probabilities are within the `[0, 1]` range and match the number of input samples.
