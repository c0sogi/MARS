Implementation strategy:
1.  **Setup & Configuration**: Import necessary modules and set the random seed for reproducibility. Define the device (GPU/CPU) based on availability.
2.  **Data Preparation**: Initialize the `DogCatDataset` for both training and validation phases using the transformations defined in `get_transforms`. Create `DataLoader` instances with appropriate batch sizes and worker counts.
3.  **Model Training**: Iterate through the architectures defined in `Config.MODEL_ARCHS` (ResNet50 and ConvNeXt-Tiny). For each architecture:
    *   Initialize the model with pre-trained weights.
    *   Execute the training loop using the `fit` function, which handles optimization, scheduling, and checkpointing.
4.  **Ensemble Validation**:
    *   Load the best saved weights for each trained model.
    *   Generate predictions on the validation set using Test Time Augmentation (TTA) if enabled.
    *   Average the predictions from all models to form an ensemble.
    *   Compute the **Log Loss** on the validation set and print it as "Final Validation Metric".
5.  **Failure Analysis**:
    *   Calculate the absolute error between predictions and ground truth labels.
    *   Extract metadata (width, height, aspect ratio, file size) for validation images.
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify systematic failure modes.
6.  **Submission Generation**:
    *   Compare the final validation metric against the strict threshold (`0.014050961788691994`).
    *   If the metric is lower than the threshold, invoke `predict_ensemble` to generate predictions on the test set and save `submission.csv`.
