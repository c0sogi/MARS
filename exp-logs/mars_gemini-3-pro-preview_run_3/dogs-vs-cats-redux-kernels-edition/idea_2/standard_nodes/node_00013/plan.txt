Here is the optimization strategy:

2.  **Loss Function**: Set `LABEL_SMOOTHING` to `0.0`. Label smoothing artificially caps the model's confidence, making it mathematically impossible to achieve the target Log Loss of ~0.014 (Cite {solution_lesson_node_00012}).
3.  **Training Configuration**:
    *   Disable **LLRD** (`USE_LLRD = False`). While useful for Transformers/ConvNeXt, it adds unnecessary complexity for a standard ResNet fine-tuning task.
    *   Set `EPOCHS = 3`. Pre-trained models on this dataset converge very rapidly; longer training risks overfitting (Cite {solution_lesson_node_00001}).
    *   Set `BATCH_SIZE = 32`. This ensures stable gradient updates without requiring aggressive learning rate scaling (Cite {solution_lesson_node_00009}).
4.  **Augmentation**: Ensure `AUG_CROP_SCALE` is `(0.8, 1.0)` to preserve subject context (Cite {solution_lesson_node_00005}) and keep **TTA** enabled for inference stabilization (Cite {solution_lesson_node_00007}).
