Based on the accumulated lessons and the "Previous Ideas" (specifically the transition to K-Fold Cross-Validation in Idea 4), I propose a **Stacked Heterogeneous Ensemble with High-Fidelity Resolution**. This strategy structurally evolves the previous simple averaging ensembles into a two-stage **Stacked Generalization** pipeline and further scales the input resolution to match the increased capacity of the backbones.

### Model
**Architecture:** Implement a **Two-Stage Stacking Pipeline**:
1.  **Level-1 (Base Learners):** A **Heterogeneous Ensemble** consisting of **ResNet-101** and **ConvNeXt-Small**.
    *   **ResNet-101:** Selected to scale up the robust CNN backbone (Cite solution_lesson_node_00002) with deeper feature hierarchies.
    *   **ConvNeXt-Small:** Selected to scale up the modern, transformer-inspired backbone, ensuring diversity in inductive biases (Cite solution_lesson_node_00016).
    *   **Initialization:** Both models must be initialized with **`IMAGENET1K_V2`** (or best available) weights to ensure optimal feature extraction (Cite solution_lesson_node_00006).
2.  **Level-2 (Meta-Learner):** A **Logistic Regression** model.
    *   Instead of simple averaging, this model takes the out-of-fold (OOF) probability predictions from the Level-1 models as input features to predict the final label. This allows the system to learn optimal weighting and calibration for the specific Log Loss metric.

### Data
**Preprocessing:** Resize all images to **320x320**.
*   **Rationale:** Previous lessons showed that increasing resolution from 224 to 256 improved performance (Cite solution_lesson_node_00005). With the stronger ResNet-101 and ConvNeXt-Small backbones, increasing resolution further to 320x320 allows the models to exploit their larger receptive fields and capture finer details without incurring the excessive cost of 384+ resolutions.

**Augmentation:** Maintain the **Context-Preserving Augmentation** strategy.
*   Use `RandomResizedCrop` with a scale of `(0.8, 1.0)` to prevent subject loss, combined with `ColorJitter` and `RandomHorizontalFlip`. This balances regularization with the need for input fidelity (Cite solution_lesson_node_00005).

### Training
**Strategy:** **5-Fold Stratified Cross-Validation**.
*   **Rationale:** This ensures 100% of the training data is used for learning and generates the unbiased OOF predictions required to train the Level-2 Meta-Learner.

**Optimization:**
*   **Optimizer:** Use **AdamW** with **Cosine Annealing** scheduler for all folds (Cite solution_lesson_node_00007).
*   **Loss Function:** Use **BCEWithLogitsLoss** *without* Label Smoothing. We strictly avoid Label Smoothing to prevent the "loss floor" issue, allowing the Stacker to optimize for the extreme probabilities required by Log Loss (Cite solution_lesson_node_00012).
*   **Scaling:** Adjust the number of epochs (e.g., 6-8) to ensure sufficient gradient updates, compensating for the batch size (e.g., 64) required by the larger resolution/models (Cite solution_lesson_node_00009).

### Evaluation
**Inference Pipeline:**
1.  **TTA:** Apply Test Time Augmentation (Horizontal Flip) for each of the 10 Level-1 models (5 folds $\times$ 2 architectures) (Cite solution_lesson_node_00007).
2.  **Feature Assembly:** Aggregate the TTA-averaged predictions from all Level-1 models to form a feature vector for each test image.
3.  **Stacking:** Pass the feature vectors through the trained Level-2 Logistic Regression model to generate the final probability.
4.  **Safety:** Clip the final probabilities to `[1e-6, 1-1e-6]` to prevent infinite Log Loss penalties from numerical instability.
