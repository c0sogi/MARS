The following implementation strategy demonstrates the usage of the provided library modules for the Dog vs Cat classification task:

1.  **Setup**: We initialize the environment by setting a fixed random seed and detecting the available computation device (CPU/GPU) using `library.utils`.
2.  **Data Loading**: We verify the data pipeline by generating training and validation dataloaders using `library.data.get_loaders`. We assert that the batch shapes match the expected dimensions for a ResNet50 model ($Batch \times 3 \times 256 \times 256$).
3.  **Model Instantiation**: We initialize a ResNet50 model using `library.models.get_model`. To ensure speed and avoid network dependency during this demonstration, we initialize it without pretrained weights. We perform a dummy forward pass to confirm the output shape is $(Batch, 1)$.
4.  **Training & Validation**: We execute a minimal training loop using `library.engine`. We run one epoch limited to just 2 batches (`max_batches=2`) to verify the pipeline runs without error and returns a valid loss value. We repeat this for the validation step.
5.  **Inference**: We demonstrate the inference process using `library.data.get_test_loader` and `library.engine.predict_with_tta`. We verify that predictions are generated, probabilities are within the [0, 1] range, and the results are saved correctly using `save_submission`.
