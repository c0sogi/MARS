The strategy implements a Stratified K-Fold Heterogeneous Ensemble. It trains three diverse architectures (ResNet50, ConvNeXt-Small, MaxViT-Tiny) across 5 folds to maximize data utilization and inductive bias diversity. To adhere to the "fast baseline" requirement while maintaining the structural integrity of the idea, the script is configured to run for 1 epoch per model per fold. It includes a comprehensive failure analysis correlating prediction errors with image metadata and conditionally generates a submission if the strict validation metric threshold is met.
