Based on the accumulated lessons, particularly the success of **Resolution Diversity** (Lesson 00040) and the limitations of standard supervised learning on this medium-sized dataset (Lesson 00038), I propose a **Semi-Supervised Heterogeneous Ensemble with Decoupled Resolutions (Noisy Student)**.

This strategy structurally evolves the solution by transitioning from a purely Supervised pipeline to a **Semi-Supervised Learning (SSL)** pipeline. It leverages the high-accuracy predictions of the current best ensemble to generate soft pseudo-labels for the 12,500 unlabeled test images, effectively increasing the training data volume by 50%. This expanded data manifold allows the models to generalize better and calibrate probabilities more precisely than is possible with the labeled set alone.

### Model
**Architecture:** Implement a **Triple Heterogeneous Ensemble** for both the "Teacher" and "Student" stages. We retain the architecture trio that maximized inductive bias diversity in Lesson 00040:
1.  **ResNet-50:** The "Standard CNN" anchor (Cite solution_lesson_node_00002).
2.  **ConvNeXt-Small:** The "Modern CNN" with large kernels (Cite solution_lesson_node_00016).
3.  **MaxViT-Tiny:** The "Multi-Axis Transformer" with global grid attention (Cite solution_lesson_node_00040).

**Initialization:** Initialize all models with the highest quality pre-trained weights available (e.g., `IMAGENET1K_V2` for ResNet) to ensure robust feature extraction (Cite solution_lesson_node_00006).

### Data
**Preprocessing (Decoupled Pipelines):** Maintain the **Resolution Diversity** strategy established in Lesson 00040. This ensures the ensemble members capture features at different scales and avoids the "lowest common denominator" trap (Cite solution_lesson_node_00028):
1.  **Pipeline A (ResNet-50):** Resize to **256x256**.
2.  **Pipeline B (ConvNeXt-Small):** Resize to **288x288**. (Cite solution_lesson_node_00040).
3.  **Pipeline C (MaxViT-Tiny):** Resize to **224x224** (Native resolution).

**Augmentation:** Apply **Context-Preserving Augmentation** (Cite solution_lesson_node_00005).
*   Use `RandomResizedCrop` with a scale of `(0.8, 1.0)` to prevent subject loss.
*   Apply `ColorJitter` with intensity $\ge 0.2$ to handle lighting variance (Cite solution_lesson_node_00024).
*   Strictly use **Bicubic Interpolation** (Cite solution_lesson_node_00024).

### Training
**Strategy:** Implement a **Two-Stage Noisy Student Pipeline**.

**Stage 1: Teacher Training (Supervised)**
*   Train the three models (ResNet, ConvNeXt, MaxViT) independently on the original labeled **Train Set**.
*   **Schedules:** Use the **Asynchronous Schedules** proven in Lesson 00040: 8 epochs for CNNs, 15 epochs for MaxViT.
*   **Loss:** BCEWithLogitsLoss (No Label Smoothing) (Cite solution_lesson_node_00012).

**Stage 2: Pseudo-Label Generation**
*   Generate predictions for the entire **Test Set** using the Stage 1 ensemble.
*   **Soft Labels:** Store the raw probability outputs (soft labels) rather than hard 0/1 predictions. This preserves the ensemble's uncertainty, which is critical for minimizing Log Loss.

**Stage 3: Student Training (Semi-Supervised)**
*   Train a **new** set of the same three architectures (Student ResNet, Student ConvNeXt, Student MaxViT) from scratch (initialized with ImageNet weights).
*   **Dataset:** Combine the original **Train Set** (Hard Labels) and the **Pseudo-Labeled Test Set** (Soft Labels).
*   **Loss Function:**
    *   For Labeled Data: `BCEWithLogitsLoss(target=HardLabel)`.
    *   For Unlabeled Data: `BCEWithLogitsLoss(target=SoftLabel)`.
*   **Optimization:** Use **AdamW** with **Cosine Annealing**.
*   **Duration:** Scale the number of epochs (e.g., +50%) to account for the increased dataset size (37.5k vs 25k images) (Cite solution_lesson_node_00009).

### Evaluation
**Inference & Aggregation:**
1.  **Test Time Augmentation (TTA):** Generate probabilities using both the original and a horizontally flipped version for each of the three **Student** models. Average these pairs (Cite solution_lesson_node_00007).
2.  **Ensemble Averaging:** Calculate the final probability by taking the **arithmetic mean** of the outputs from the three Student models.
    *   **Rationale:** We ensemble only the Students. Ensembling Students with Teachers is risky due to correlation (Cite solution_lesson_node_00039). The Students, having seen 50% more data (via pseudo-labels) and maintaining the resolution diversity of the Teachers, will theoretically form a more robust and better-calibrated ensemble.
