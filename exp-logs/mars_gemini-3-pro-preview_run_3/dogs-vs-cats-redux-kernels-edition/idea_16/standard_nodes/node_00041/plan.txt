Implementation strategy:

1.  **Configuration & Setup**: Initialize the environment, set random seeds for reproducibility, and define the computation device (GPU). I will override the default epoch counts in the `Config` to ensuring the pipeline runs within the 2-hour limit (setting Teacher epochs to 3 and Student epochs to 4 per model).
2.  **Teacher Training (Phase 1)**: Iterate through the three ensemble architectures (ResNet50, ConvNeXt-Small, MaxViT-Tiny). For each, create training and validation dataloaders using the labeled training set. Train the models using the defined hyperparameters and save the best checkpoints based on validation loss.
3.  **Pseudo-Label Generation (Phase 2)**: Load the best checkpoints for all three teacher models. Generate soft probability predictions for the unlabeled test set using Test Time Augmentation (TTA). Average these predictions to create a "Pseudo-Labeled" dataset.
4.  **Student Training (Phase 3)**: Combine the original labeled training data with the pseudo-labeled test data. Re-initialize the three architectures (Students) and train them on this combined dataset for slightly longer than the teachers to exploit the larger data manifold. Save the best student checkpoints.
5.  **Validation & Analysis (Phase 4)**: Perform inference on the hold-out validation set using the ensemble of trained Student models. Calculate the final Log Loss. Perform failure analysis by correlating prediction errors with image metadata (width, height, file size) to identify biases.
6.  **Submission (Phase 5)**: Check if the final validation log loss meets the strict threshold (< 0.00907). If successful, generate final predictions for the test set using the Student ensemble and save the submission file.
