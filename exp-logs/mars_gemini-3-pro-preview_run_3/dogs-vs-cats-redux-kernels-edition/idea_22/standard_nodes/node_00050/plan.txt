The solution implements a Stratified K-Fold Heterogeneous Ensemble using ResNet50, ConvNeXt-Small, and MaxViT-Tiny. Due to the strict 21-minute time limit, the pipeline runs in a constrained mode (DEBUG enabled, 2 folds, 1 epoch, reduced dataset). The script overrides the default configuration to ensure execution completes within the limit. It trains the ensemble, optimizing a temperature scalar for each model using Out-Of-Fold (OOF) logits to calibrate probabilities. Post-training, it evaluates the ensemble on the hold-out validation set, performs failure analysis by correlating errors with image metadata (width, height, file size), and conditionally generates a submission file if the validation metric meets the specified threshold. The implementation leverages the provided library modules for data loading, architecture definition, training engine, and calibration.
