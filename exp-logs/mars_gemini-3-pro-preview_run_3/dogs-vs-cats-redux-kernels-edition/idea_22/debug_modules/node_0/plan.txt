The following script demonstrates the end-to-end usage of the provided library files for the Dog vs. Cat classification task.

**Implementation Strategy:**
1.  **Configuration & Setup**: The script initializes the `Config` class, enabling `DEBUG` mode and reducing `DEBUG_SAMPLES` to 60. This ensures the pipeline runs on a tiny subset of data, completing quickly while exercising all code paths. It also redirects output to a specific demo directory.
2.  **Data Pipeline Verification**: It utilizes `create_kfold_loaders` to generate training and validation loaders. It fetches a single batch to assert that image shapes and label dimensions are correct (Batch Size x 3 x H x W).
3.  **Model Initialization**: It instantiates the `resnet50` model using `get_model` and performs a dummy forward pass with the fetched batch to verify the architecture and output shapes (Batch Size x 1).
4.  **Training & Validation**: It executes `train_model` for 1 epoch. This tests the training loop, loss calculation, backpropagation, and model checkpointing logic.
5.  **Calibration**: Using the Out-Of-Fold (OOF) logits returned by the training function, it demonstrates `optimize_temperature` to find the optimal scaling factor for probability calibration.
6.  **Inference & Submission**: Finally, it runs `inference_with_tta` on the test set, applies the calculated temperature scaling via `calibrate_logits`, and generates a formatted `submission.csv` file.
