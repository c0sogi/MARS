The following script demonstrates the end-to-end usage of the provided library components for the Phrase Matching task. It covers data preparation, dataset creation, model initialization, loss calculation, and the training/validation loop using a small subset of data for speed.

### Implementation Strategy
1.  **Configuration Setup**: Override the default `cfg` to enable debug mode (using a small data subset) and reduce epochs/batch size for quick execution.
2.  **Data Preparation**: Use `prepare_data` to load and process the training and validation sets, verifying that the CPC context mapping works correctly.
3.  **Dataset & DataLoader**: Instantiate `PearsonDataset` and `DataLoader` with the custom `CollateFn`. Verify batch shapes and content.
4.  **Model & Loss**: Initialize `CustomModel` and `CompositeLoss`. Perform a dummy forward pass to verify output shapes and loss computation.
5.  **Training Loop**: Configure the optimizer using `get_optimizer_params` and run a single epoch of training using `train_fn` (including Adversarial Weight Perturbation initialization).
6.  **Validation**: Run `valid_fn` to generate predictions and calculate the Pearson correlation score.
7.  **Inference**: Demonstrate how to generate a submission file from the test set.
