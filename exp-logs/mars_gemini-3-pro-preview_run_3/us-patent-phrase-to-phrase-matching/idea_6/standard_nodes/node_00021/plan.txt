Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Initialization**: Set up the environment by seeding random number generators for reproducibility and initializing the logger. Ensure the output directory for submission exists.
2.  **Data Loading**: Use the provided `prepare_data` function to load training, validation, and test datasets. We utilize the caching mechanism (`load_cached_data=True`) to speed up loading.
3.  **Dataset & DataLoader**: Initialize the `AutoTokenizer` for `microsoft/deberta-v3-large`. Wrap the pandas DataFrames in the `PearsonDataset` class and create PyTorch DataLoaders using the custom `CollateFn`.
4.  **Model Setup**: Instantiate the `CustomModel` (DeBERTa-v3-large with attention pooling and dual heads) and move it to the GPU.
5.  **Training Configuration**:
    *   Define the optimizer with Layer-wise Learning Rate Decay (LLRD) using `get_optimizer_params`.
    *   Set up a cosine learning rate scheduler with warmup.
    *   Initialize the `CompositeLoss` (MSE + Pearson + CrossEntropy).
    *   Initialize `AWP` (Adversarial Weight Perturbation) for regularization.
6.  **Training Loop**: Iterate through the specified number of epochs. In each epoch, perform training with AWP and validation. Save the model weights if the validation Pearson score improves.
7.  **Final Validation & Failure Analysis**:
    *   Load the best saved model state.
    *   Compute the final Pearson correlation on the full validation set and print it in the required format.
    *   Perform failure analysis by calculating the correlation between prediction errors and input features (e.g., text lengths, context frequency) to identify weaknesses.
8.  **Inference & Submission**:
    *   Check if the validation score exceeds the threshold (`0.8582661747932434`).
    *   If passed, generate predictions for the test set.
    *   Clip predictions to the [0, 1] range.
    *   Save the results to `./submission/submission.csv`.
