This script demonstrates the end-to-end usage of the provided library files for the Phrase Matching task. It performs the following steps:

1.  **Configuration**: Overrides the default `Config` to use a lightweight model (`prajjwal1/bert-tiny`) and a small subset of data for rapid execution.
2.  **Data Preparation**: Loads the training data using `load_dataset`, merges CPC context descriptions, and creates a small stratified validation split.
3.  **Dataset Creation**: Instantiates `PhraseDataset` and PyTorch `DataLoader`s for training and validation.
4.  **Model Initialization**: Initializes the `CustomModel` (backbone + custom pooling/heads) and moves it to the appropriate device (GPU/CPU).
5.  **Training Setup**: Configures the optimizer with Layer-wise Learning Rate Decay (LLRD) using `get_optimizer_params`, sets up the scheduler, and initializes the `HybridLoss`.
6.  **Execution Loop**: Runs one epoch of training (`train_fn`) and validation (`valid_fn`).
7.  **Inference**: Runs inference (`inference_fn`) on the validation set to demonstrate prediction generation.
8.  **Verification**: Includes assertions throughout to verify data shapes, loss types, and prediction ranges.
