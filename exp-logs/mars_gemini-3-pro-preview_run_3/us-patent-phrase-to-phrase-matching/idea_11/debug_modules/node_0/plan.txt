The following script demonstrates the end-to-end usage of the provided library files for the Phrase Matching task.

### Implementation Strategy
1.  **Setup & Configuration**: We import the required modules and the provided library components (`library.*`). We override specific `CFG` parameters (model name, batch size, epochs) to ensure the demo runs quickly using a lightweight model (`microsoft/deberta-v3-xsmall`) and a small data subset.
2.  **Data Preparation**: We create a small subset (20 samples) of the training metadata and save it to the working directory. We then use `prepare_data` (which utilizes `CPCLoader`) to merge CPC context descriptions, and wrap the result in the `PhraseDataset` and `DataLoader`.
3.  **Model & Optimization**: We instantiate the `PhraseModel`, `HybridLoss`, and configure the optimizer using `get_optimizer_params` (which handles Layer-wise Learning Rate Decay). We also initialize `AWP` (Adversarial Weight Perturbation) and `EMA` (Exponential Moving Average) to demonstrate advanced training strategies.
4.  **Execution Loops**:
    *   **Training**: We run `train_fn` for one epoch to verify the training loop, gradient updates, and AWP integration.
    *   **Validation**: We run `valid_fn` to verify loss calculation, metric computation (Pearson correlation), and EMA weight application.
    *   **Inference**: We run `inference_fn` to generate predictions and verify output shapes.
5.  **Verification**: Assertions are placed throughout the script to ensure data integrity, correct output shapes, and valid loss values.
