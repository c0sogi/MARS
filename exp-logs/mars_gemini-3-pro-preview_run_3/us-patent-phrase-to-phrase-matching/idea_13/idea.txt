Based on the comprehensive analysis of the previous experiments and the "Lessons Learned," I propose the **Stratified Ensemble with Weighted Layer Pooling and Full-Convergence Optimization**.

This strategy structurally evolves the high-performing **Idea 6** (Hierarchical Context + Pearson Loss) by integrating the **Weighted Layer Pooling** and **EMA** architectures from **Idea 12**. Crucially, it addresses the failure of Idea 12 by correcting the training protocol: it explicitly accounts for the "Convergence Tax" of these advanced features by enforcing a full training duration, while strictly avoiding the destabilizing DAPT and Freeze-Thaw pipelines.

### Model
*   **Backbone:** We will utilize **`microsoft/deberta-v3-large`** as the core encoder. Its disentangled attention mechanism provides the strongest foundation for semantic matching (Cite solution_lesson_node_00001).
*   **Architecture:** We will persist with the **Cross-Encoder** design, concatenating the hierarchical context and phrase pairs into a single sequence to enable deep token-level interaction (Cite solution_lesson_node_00008).
*   **Weighted Layer Pooling (Structural Innovation):** Instead of utilizing only the final hidden state (which emphasizes abstract semantics), we will implement **Scalar Mixing**. We will learn a trainable scalar weight $w_i$ for every layer $i$ of the transformer backbone. The output representation will be the weighted sum of all layer outputs: $H_{mix} = \sum_{i=0}^{L} \frac{\exp(w_i)}{\sum_j \exp(w_j)} H_i$.
    *   *Rationale:* The scoring rubric distinguishes between "Exact Match" (1.0) and "Close Synonym" (0.75)—a difference that is often lexical rather than purely semantic. Lower layers of the transformer retain these lexical details, while higher layers capture broad meaning. This mechanism allows the model to utilize the full "vertical slice" of linguistic features, provided it is trained long enough to converge (Cite solution_lesson_node_00033).
*   **Pooling & Heads:** The mixed representation will be passed through an **Attention Pooling** layer (Cite solution_lesson_node_00011) to aggregate token embeddings, followed by **Multi-Sample Dropout** and a **Dual-Head** structure (Regression + Classification) to leverage multi-task learning (Cite solution_lesson_node_00014).

### Data
*   **Hierarchical Context Expansion:** We will map every `context` code to its full lineage of descriptions (Section > Class > Subclass) and inject this into the input sequence (e.g., `[CLS] Section Desc [SEP] Class Desc [SEP] Subclass Desc [SEP] Anchor [SEP] Target [SEP]`). This aligns the model with the specific technical domain (Cite solution_lesson_node_00021).
*   **Stratified K-Fold Split:** We will implement a **5-Fold Stratified Cross-Validation** scheme. We will split the training data into 5 folds, stratifying by the `score` distribution to ensure robust class representation in every model.

### Training
*   **Loss Function:** We will optimize the **Hybrid Pearson Loss**: $L_{Total} = L_{MSE} + \lambda_1 L_{CE} + \lambda_2 (1 - \rho)$. This combines geometric precision, decision-boundary sharpness, and direct metric optimization (Cite solution_lesson_node_00021).
*   **Regularization & Stabilization:**
    *   **Adversarial Weight Perturbation (AWP):** Applied to flatten the loss landscape (Cite solution_lesson_node_00012).
    *   **Exponential Moving Average (EMA):** We will maintain an EMA of the model weights to smooth out the noise from AWP and improve generalization (Cite solution_lesson_node_00033).
*   **Optimization:** We will use **AdamW** with **Layer-wise Learning Rate Decay (LLRD)** (Cite solution_lesson_node_00011) to preserve pre-trained features.
*   **Protocol - Full Convergence (Critical Correction):**
    *   **No DAPT:** We will explicitly skip Domain-Adaptive Pre-training to prevent catastrophic forgetting (Cite solution_lesson_node_00023).
    *   **No Freeze-Thaw:** We will perform **End-to-End Fine-Tuning** to avoid gradient shocks (Cite solution_lesson_node_00030).
    *   **Extended Epochs:** Unlike Idea 12, which failed due to under-training, we will train each fold for **5 epochs**. We accept the "Convergence Tax" (Cite solution_lesson_node_00033) imposed by Weighted Layer Pooling and EMA, utilizing the full 24-hour budget to ensure these complex features are properly learned.

### Evaluation
*   **Inference:** For each sample in the test set, we will generate predictions using the **EMA weights** from all 5 trained fold models.
*   **Ensemble Aggregation:** The final similarity score will be the **arithmetic mean** of the 5 predictions. This averaging reduces variance and improves generalization.
*   **Post-Processing:** The aggregated scores will be clipped to the [0, 1] range.
