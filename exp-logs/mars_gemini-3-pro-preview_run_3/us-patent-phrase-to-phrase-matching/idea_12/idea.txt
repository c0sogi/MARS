Based on the comprehensive analysis of the previous experiments and the specific failure modes identified in the lessons (Catastrophic Forgetting via DAPT and Divergence via Freeze-Thaw), I propose the **"Stratified Dynamic-Layer Ensemble with Metric-Aligned Optimization"**.

This strategy structurally evolves the "Current Best" solution (Idea 6) by integrating **Dynamic Layer Scalar Mixing** to capture the full vertical slice of linguistic features (lexical to semantic) and wrapping the solution in a **Stratified K-Fold Ensemble**. Crucially, it enforces a stable **End-to-End Fine-Tuning** protocol, explicitly rejecting the unstable DAPT and Freeze-Thaw pipelines.

### Model
*   **Backbone:** We will utilize **`microsoft/deberta-v3-large`** as the core encoder. Its disentangled attention mechanism provides the strongest foundation for semantic matching (Cite solution_lesson_node_00001).
*   **Architecture:** We will maintain the **Cross-Encoder** design, concatenating the hierarchical context and phrase pairs into a single sequence to enable deep token-level interaction (Cite solution_lesson_node_00008).
*   **Dynamic Layer Scalar Mixing (Structural Innovation):** Unlike the previous best model which relied on the final layer (abstract semantics), we will implement a learnable **Weighted Layer Pooling** mechanism. We will extract hidden states from *all* layers of the transformer and compute a weighted sum: $H_{mix} = \sum_{i=0}^{L} w_i \cdot H_i$, where $w_i$ are learnable scalar weights (softmax-normalized).
    *   *Rationale:* The task requires distinguishing between "Exact Matches" (lexical/syntax, found in lower layers) and "Synonyms" (semantic, found in higher layers). Dynamic mixing allows the model to adaptively select the appropriate level of abstraction for each pair.
*   **Head:** The mixed representation will be passed through an **Attention Pooling** layer (Cite solution_lesson_node_00011) to aggregate token embeddings, followed by **Multi-Sample Dropout** and a **Dual-Head** structure (Regression + Classification) to leverage multi-task learning (Cite solution_lesson_node_00014).

### Data
*   **Hierarchical Context Expansion:** We will map every `context` code to its full lineage of descriptions (Section > Class > Subclass) and inject this into the input sequence (e.g., `[CLS] Section Desc [SEP] Class Desc [SEP] Subclass Desc [SEP] Anchor [SEP] Target [SEP]`). This aligns the model with the specific technical domain (Cite solution_lesson_node_00021).
*   **Stratified K-Fold Split:** We will implement a **5-Fold Stratified Cross-Validation** scheme. We will split the training data into 5 folds, stratifying by the `score` distribution. This ensures that each fold maintains the class imbalance profile of the full dataset and provides a robust ensemble.

### Training
*   **Loss Function:** We will optimize the **Hybrid Pearson Loss**: $L_{Total} = L_{MSE} + \lambda_1 L_{CE} + \lambda_2 (1 - \rho)$. This combines geometric precision, decision-boundary sharpness, and direct metric optimization (Cite solution_lesson_node_00021).
*   **Optimization Strategy:** We will use **AdamW** with **Layer-wise Learning Rate Decay (LLRD)** (Cite solution_lesson_node_00011). This allows us to train the new mixing weights aggressively while preserving the pre-trained backbone features.
*   **Strict Stability Constraints:**
    1.  **No DAPT:** We will explicitly skip Domain-Adaptive Pre-training to prevent the catastrophic forgetting observed in previous attempts (Cite solution_lesson_node_00023).
    2.  **No Freeze-Thaw:** We will perform **End-to-End Fine-Tuning** from the first step. We will avoid freezing the backbone, as the sudden unfreezing was proven to cause gradient explosions and NaN divergence (Cite solution_lesson_node_00030).
*   **Regularization:** We will apply **Adversarial Weight Perturbation (AWP)** to flatten the loss landscape (Cite solution_lesson_node_00012) and maintain an **Exponential Moving Average (EMA)** of model weights to smooth out high-frequency noise.

### Evaluation
*   **Inference:** For each sample in the test set, we will generate predictions using the **EMA weights** from all 5 trained fold models.
*   **Ensemble Aggregation:** The final similarity score will be the **arithmetic mean** of the 5 predictions. This averaging reduces variance and improves generalization.
*   **Post-Processing:** The aggregated scores will be clipped to the [0, 1] range.
