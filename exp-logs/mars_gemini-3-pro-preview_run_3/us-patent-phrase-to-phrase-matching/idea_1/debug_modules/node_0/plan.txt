The following implementation demonstrates how to utilize the provided library files to train a Siamese Deep Averaging Network (DAN) for phrase similarity.

### Strategy
1.  **Configuration**: We modify the global `Config` class to enable `DEBUG` mode and reduce `EPOCHS` and `BATCH_SIZE`. This ensures the script runs quickly (under 1 minute) by using a small subset of the data.
2.  **Data Loading**: We explicitly call `get_dataloaders` to demonstrate how to prepare the data. We verify the integrity of the resulting DataLoaders and the structure of a single batch.
3.  **Model Verification**: We instantiate the `SiameseDAN` model directly and perform a forward pass with a sample batch. This verifies that the model architecture is valid and produces outputs of the expected shape.
4.  **Training Pipeline**: We utilize the `Trainer` class to orchestrate the full training, evaluation, and prediction loop. This demonstrates the high-level API provided by the library.
5.  **Output Validation**: Finally, we verify that the submission file and model artifacts are correctly generated and meet the format requirements.
