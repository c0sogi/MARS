The error `ValueError: too many values to unpack (expected 5)` occurs because `get_dataloaders` was updated to return 6 values (adding `embedding_matrix`), but `run_task` in `library/model.py` still expects 5. Additionally, `library/model.py` executes `run_task()` at the module level, causing it to run immediately when imported by `library/trainer.py`, triggering the crash. Furthermore, the pre-trained embeddings from `all-MiniLM-L6-v2` have a dimension of 384, which conflicts with `Config.EMBEDDING_DIM` (currently 100).

1.  **Update `library/config.py`**: Set `EMBEDDING_DIM` to 384 to match the pre-trained SentenceTransformer embeddings.

    *   Pass the `embedding_matrix` to the `SiameseDAN` constructor.
    *   Wrap the `run_task()` call at the end of the file in an `if __name__ == "__main__":` block to prevent execution during import.
