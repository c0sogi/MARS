The implementation strategy is to create a self-contained script that imports the provided library modules and orchestrates a complete machine learning pipeline (Data Loading -> Model Init -> Training -> Validation -> Inference). To satisfy the speed and resource constraints, the script will dynamically patch the `Config` class to use a lightweight model (`prajjwal1/bert-tiny`) and a small subset of the data (`debug=True`). It will verify the correctness of the custom components (`ScalarMixingModel`, `AWP`, `HybridLoss`) using assertions at each stage.
