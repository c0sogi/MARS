The implementation strategy follows a streamlined pipeline designed to maximize performance on the NVIDIA A100 GPU within the time constraints.

1.  **Configuration & Setup**: We initialize the environment and override specific `Config` parameters (increasing batch size to 32, reducing epochs to 3) to fully utilize the 40GB VRAM and ensure the run completes quickly. We also disable `tqdm` globally to meet the output requirements.
2.  **Domain-Adaptive Pre-training (DAPT)**: We execute the DAPT stage to fine-tune the `deberta-v3-large` backbone on the specific patent corpus (anchors, targets, and context descriptions) using Masked Language Modeling. This aligns the model's internal representations with the technical domain.
3.  **Model Initialization**: We instantiate the `CustomModel` using the DAPT-adapted weights. The model features a hybrid head (regression + classification) and utilizes Attention Pooling and Multi-Sample Dropout.
4.  **Training**: We train the model using a `HybridLoss` function and an `AdamW` optimizer configured with Layer-wise Learning Rate Decay (LLRD). Adversarial Weight Perturbation (AWP) is applied after the first epoch to improve generalization.
5.  **Validation & Analysis**: After training, we reload the best model checkpoint to compute the final Pearson correlation on the validation set. We perform failure analysis by calculating the correlation between the absolute prediction error and input meta-features (e.g., text length, Jaccard similarity) to identify systematic weaknesses.
6.  **Submission**: If the final validation metric exceeds the specified threshold, we generate predictions for the test set and save the `submission.csv` file.
