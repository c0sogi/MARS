The following script demonstrates the end-to-end usage of the provided library for the phrase matching task. It performs the following steps:

1.  **Configuration**: Overrides default `Config` settings to enable debug mode, reduce epochs, and set specific paths for a fast demonstration run.
2.  **Data Preparation**: Uses `cpc_utils` and `dataset` to load context-enriched data and create PyTorch DataLoaders. It verifies the data shapes and content.
3.  **Model Initialization**: Instantiates the `CustomModel` with the DeBERTa backbone and verifies the output shapes of the regression and classification heads.
4.  **Domain-Adaptive Pre-training (DAPT)**: Runs a minimal DAPT session on the debug dataset to demonstrate the masked language modeling workflow.
5.  **Training Loop**: Executes a single epoch of training using `engine.train_fn`, incorporating Layer-wise Learning Rate Decay (LLRD) and Adversarial Weight Perturbation (AWP).
6.  **Validation**: Evaluates the model using `engine.valid_fn` and computes the Pearson correlation score.
7.  **Inference**: Generates predictions on the test set using `engine.inference_fn` and creates a submission file.

Global progress bars are suppressed to keep the output clean, as requested.
