The following script performs the required metadata generation. It reads the raw CSV files from the `./input` directory, splits the training data into training and validation sets (80:20 ratio) using stratified sampling based on the similarity `score` to preserve class distribution, and saves the resulting datasets to the `./metadata` directory. It then reloads these files to verify the split statistics, ensuring the validation set size is correct and the score distribution matches the original data, satisfying all verification requirements.
