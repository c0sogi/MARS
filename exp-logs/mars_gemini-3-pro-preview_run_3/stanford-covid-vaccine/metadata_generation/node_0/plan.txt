The strategy is to parse the provided JSON datasets (`train.json` and `test.json`) into structured Pandas DataFrames. Since the data size is relatively small (thousands of sequences), we can store the full dataset including sequences, structures, and target arrays directly in Parquet format within the `./metadata` directory. This allows for efficient loading by downstream models without re-parsing the raw JSON files.

For the validation split, we will use the `SN_filter` column (Signal/Noise filter) as the stratification key if it exists, as this ensures that both high-quality and lower-quality samples are distributed evenly between training and validation sets. If `SN_filter` is absent, we will fall back to a purely random split. We will strictly adhere to the 80:20 split ratio and the fixed random state.

Finally, the script will verify the generated datasets by checking shapes, column existence, and split proportions.
