### Implementation Strategy

We will set a custom working directory for the demo to avoid overwriting existing files.
2.  **Component Verification**:

    *   **Layers**: We will instantiate individual layers (`ConvStem`, `StabilizedGLUInteraction`) and pass dummy tensors to verify input/output shapes and forward pass mechanics.

3.  **Model Execution**: We will instantiate the `DeepHierarchicalBiGRU` model with reduced complexity. We will perform a forward pass with a batch from the data loader to ensure the deep supervision outputs (list of tensors) are generated correctly.
4.  **Training Loop Simulation**: We will instantiate the `Trainer` and run a single training epoch and validation step to verify the integration of the optimizer, loss calculation, and backpropagation.
5.  **Submission Generation**: We will generate dummy predictions for the test set and use `create_submission_file` to verify the output format matches the competition requirements.
6.  **Cleanup**: We will clean up the temporary working directory used for the demonstration.
