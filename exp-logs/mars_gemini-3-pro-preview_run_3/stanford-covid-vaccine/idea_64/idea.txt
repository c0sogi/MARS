Based on the comprehensive analysis of the experimental history, I propose the following optimized strategy. This approach represents the **High-Capacity Stabilized Synthesis**.

It directly addresses the critical failure identified in **Lesson 103**, where previous attempts to implement sophisticated interaction modules failed because they sacrificed backbone capacity. It also resolves the stability paradox of deep networks (Lesson 68) and the "Loop Silencing" issue (Lesson 85). By employing a **Bottlenecked Gating** design, we can maintain the massive **4-Layer High-Capacity Backbone** required for performance while keeping the interaction module parameter-efficient and stable.

# Proposed Strategy: High-Capacity Bottlenecked-Decoupled BiGRU (HC-BD-BiGRU)

This strategy introduces a **4-Layer Bidirectional GRU** with a **High-Capacity Hidden Dimension** (384 per direction, 768 total). To make this deep, wide network trainable, it interleaves **Bottlenecked Decoupled Structural Injection** modules. This module uses a compressed hidden layer within the gating MLP to reduce parameter bloat while strictly adhering to the stabilization protocols (Internal Norm, Post-Norm) and bias-driven refinement mechanisms validated in previous lessons.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers. **Cite solution_lesson_node_00027**.

3.  **High-Capacity 4-Layer Backbone:**
    *   The backbone consists of **4 Blocks** (maximizing capacity, addressing **Cite solution_lesson_node_00026**). Each block contains a **Bidirectional GRU** followed by the **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** Hidden dimension of **384** (Total 768). We explicitly maintain this high capacity, as narrowing the backbone caused severe degradation. **Cite solution_lesson_node_00103** and **Cite solution_lesson_node_00063**.
    *   **Bottlenecked Decoupled Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **Decoupled Message (Bias-Refined):** $m_{ij} = \text{GELU}(W_{msg} \cdot h_j + b_{msg})$. We do **not** concatenate $h_i$. For unpaired bases ($h_j=0$), this becomes the bias $b_{msg}$, serving as a learnable "loop embedding" for self-refinement. **Cite solution_lesson_node_00080** and **Cite solution_lesson_node_00085**.
        *   **Stabilized Bottleneck MLP Gate:**
            *   **Bottleneck Projection:** $z_{low} = W_{in} \cdot [h_i; h_j]$. Projects the 1536-dim context to a lower dimension (e.g., 96) to control parameter count.
            *   **Internal Normalization:** $z_{norm} = \text{LayerNorm}(z_{low})$. Stabilizes the MLP internals. **Cite solution_lesson_node_00075**.
            *   Activation: $z_{act} = \text{GELU}(z_{norm})$.
            *   **Expansion:** $logits = W_{out} \cdot z_{act}$. Projects back to 768 dimensions for channel-wise gating.
            *   **No Logit Norm:** $g_{ij} = \sigma(logits)$. Allows full saturation. **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. Ensures stability for the deep 4-layer stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
