### Implementation Strategy

1.  **Configuration Override**: We will modify the global `config` object to reduce model complexity (hidden dimensions, layers) and training duration (epochs, batch size) to ensure the script runs quickly within the demonstration environment. We will also redirect output paths to a dedicated `./working/demo_run` directory.
2.  **Data Loading & Slicing**: Instead of using the full dataset, we will manually invoke the `load_or_process_data` function, slice the resulting numpy arrays to a small subset (e.g., 20 samples), and instantiate the `RNADataset` and `DataLoader` classes. This validates the data pipeline while minimizing runtime.
3.  **Model Verification**: We will instantiate the `HC_BD_BiGRU` model and perform a forward pass with a single batch to assert that the output shapes match the expected dimensions `(Batch, SeqLen, 5)`.
4.  **Metric Validation**: We will test the `calculate_mcrmse` function with synthetic data where the result is known, ensuring the scoring logic (slicing to `SEQ_SCORED` and filtering columns) is correct.
5.  **Training Loop**: We will initialize the `Trainer` with the subset dataloaders and run `fit()` for 1 epoch. We will verify that the model checkpoint is saved.
6.  **Inference & Submission**: We will run `generate_submission()`, check for the existence of the output CSV, and verify its structure (row count and columns).
