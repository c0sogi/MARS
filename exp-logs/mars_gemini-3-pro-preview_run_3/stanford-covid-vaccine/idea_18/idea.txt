# Proposed Strategy: Robust Iterative Structural-Refinement BiGRU (RISR-BiGRU)

This strategy builds directly upon the massive success of the **Deep Iterative Structural-Refinement** architecture (which reduced error to ~0.59). The core structural innovation is the evolution of the "Structural Interaction Module" into a **Windowed Interaction Module**. While the previous best model gathered features from the *exact* paired index $j$, this new approach gathers features from a small spatial window centered at $j$. This modification retains the powerful explicit topology injection **Cite solution_lesson_node_00057** while mitigating the model's sensitivity to register shifts and errors in the predicted secondary structure, addressing the noise risks identified in **Cite solution_lesson_node_00037**.

### Model

The architecture is a **Deep BiGRU with Interleaved Windowed-Structure Gating**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** We do **not** concatenate paired features at the input stage to ensure the convolutional stem extracts clean local motifs. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU) to project sparse inputs into a dense embedding space and aggregate local k-mers. **Cite solution_lesson_node_00027**.

3.  **Iterative Refinement Backbone:**
    *   The backbone consists of **3 Blocks**. Each block contains a **Bidirectional GRU** followed by a **Windowed Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** High-capacity Bidirectional GRU (Hidden Dimension = 384). We prioritize BiGRUs over Transformers for their superior inductive bias on short sequences. **Cite solution_lesson_node_00017**. We maximize capacity (width) over depth/complexity. **Cite solution_lesson_node_00026**.
    *   **Windowed Structural Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$ in the structure:
        *   **Window Gather:** Instead of retrieving only $h_j$, we retrieve a window of hidden states $[h_{j-1}, h_j, h_{j+1}]$ (handling boundaries with padding).
        *   **Local Aggregation:** These neighbors are compressed into a single context vector $h_{pair}$ using a lightweight learned projection or local attention (querying with $h_i$). This allows the model to "search" the immediate vicinity of the predicted pair, making it robust to slight misalignments in the provided structure.
        *   **Gated Injection:** We compute a trust gate $z_{ij} = \sigma(W_{gate} \cdot [h_i; h_{pair}])$ and update the state: $h'_i = h_i + z_{ij} \odot (W_{proj} \cdot h_{pair})$.
        *   **Benefit:** This preserves the explicit graph routing that yielded the 0.59 metric **Cite solution_lesson_node_00057** but adds the robustness required to handle noisy structure predictions **Cite solution_lesson_node_00037**.

4.  **Output Head:**
    *   A final Linear layer projects the output of the last BiGRU block to the 5 target values.

### Data

1.  **Preprocessing:**
    *   We will generate **Windowed Adjacency Maps** during preprocessing. For each paired position, we store the indices of the partner and its immediate neighbors.
    *   **Caching:** We will use **hash-based caching** for the preprocessed data (e.g., `train_data_{hash(config)}.npy`) to ensure the new window-based logic is correctly executed and versioned. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject filtering strategies to avoid distribution shift relative to the public test set. **Cite solution_lesson_node_00015**.

### Training

1.  **Objective (Unweighted Loss):**
    *   We will optimize the standard **MCRMSE** on all 5 target columns. We will **not** use inverse-variance weighting, as down-weighting noisy samples degrades performance on the unweighted competition metric. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. This is critical for convergence to a deep minimum. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** We will explicitly apply **Gradient Clipping** (max norm 1.0) to the training loop. This is **mandatory** to stabilize the deep, hybrid recurrent architecture and prevent exploding gradients. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Global Metric Aggregation:**
    *   We will implement a **Global Evaluation Loop** that concatenates predictions and targets for the entire validation set *before* calculating the MCRMSE. We will **not** average batch-wise RMSEs, as this produces optimistically biased results. **Cite solution_lesson_node_00045**.

2.  **Targeted Validation:**
    *   We will calculate the validation metric specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to ensure alignment with the competition leaderboard. **Cite solution_lesson_node_00017**.

3.  **Inference:**
    *   The test set sequences will be processed through the Stem and the Iterative Backbone with windowed gathering.
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) for submission.
