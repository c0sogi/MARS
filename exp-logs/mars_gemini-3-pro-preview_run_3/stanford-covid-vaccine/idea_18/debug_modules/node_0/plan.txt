3.  **Model Initialization & Forward Pass**: Instantiate the `RISRBiGRU` model. Perform a forward pass with the fetched batch and verify that the output tensor shape matches `(Batch, Seq_Len, Num_Targets)`.
4.  **Loss Calculation**: Instantiate `MCRMSELoss`. Compute the loss between model predictions and ground truth. Verify the loss is a valid scalar. Perform a manual calculation check on dummy data to ensure the custom metric logic is correct.
5.  **Training Loop**: Initialize the `Trainer` and run the `fit()` method. This demonstrates the full training pipeline including optimization, scheduler stepping, and model checkpointing.
6.  **Inference & Submission**: Load the test dataloader and the best saved model. Run inference to generate predictions and verify that the output dimensions align with the submission requirements.
