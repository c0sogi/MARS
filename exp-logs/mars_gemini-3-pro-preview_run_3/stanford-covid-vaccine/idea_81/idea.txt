Finally, it integrates the **Stabilized GLU-Decoupled Interaction Module**, synthesizing the best structural components: **Decoupled Gating** (Lesson 80), **GLU Messages** (Lesson 62), and **Bias-Driven Refinement** (Lesson 85).

# Proposed Strategy: Deep Residual High-Capacity BiGRU with Multi-Layer Feature Aggregation

This strategy introduces a **4-Layer Bidirectional GRU** with a **High-Capacity Hidden Dimension** (384 per direction, 768 total). It stabilizes this deep backbone using **Vertical Residual Connections** and interleaves it with **Stabilized GLU-Decoupled Structural Injection** modules. The final output is derived from a concatenation of all layer outputs, ensuring a rich multi-scale representation.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers. **Cite solution_lesson_node_00027**.

3.  **Deep Residual High-Capacity Backbone:**
    *   The backbone consists of **4 Blocks** (maximizing capacity, addressing **Cite solution_lesson_node_00026**).
    *   **A. Vertical Residual BiGRU:**
        *   For Layer 1: $h_1 = \text{BiGRU}_1(h_{stem})$.
        *   For Layers 2-4: $h_l = h_{l-1} + \text{BiGRU}_l(h_{l-1})$.
        *   **Innovation:** These **Vertical Residuals** allow gradients to bypass the recurrent non-linearities, facilitating the training of the deep 4-layer, 768-dim backbone which is critical for performance. **Cite solution_lesson_node_00103**.
    *   **B. Stabilized GLU-Decoupled Interaction Module:**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **GLU Message (Bias-Refined):** $m_{ij} = (W_c h_j + b_c) \odot \sigma(W_g h_j + b_g)$. We do **not** concatenate $h_i$ here (Decoupled). Crucially, for unpaired bases ($h_j=0$), this term becomes the learnable bias vector $b_c \odot \sigma(b_g)$, providing a "loop embedding" for self-refinement. **Cite solution_lesson_node_00085**, **Cite solution_lesson_node_00062**, **Cite solution_lesson_node_00080**.
        *   **Wide Stabilized MLP Gate:**
            *   **Wide Projection:** $z_{raw} = W_{in} \cdot [h_i; h_j]$. Projects to full width (768) to avoid bottlenecks. **Cite solution_lesson_node_00110**. No input normalization. **Cite solution_lesson_node_00079**.
            *   **Internal Normalization:** $z_{norm} = \text{LayerNorm}(z_{raw})$. Stabilizes MLP internals. **Cite solution_lesson_node_00075**.
            *   **Activation:** $z_{act} = \text{GELU}(z_{norm})$.
            *   **No Logit Norm:** $g_{ij} = \sigma(W_{out} \cdot z_{act})$. Allows full saturation. **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{struct} = h_l + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{struct})$. Ensures stability for the stack. **Cite solution_lesson_node_00068**.

4.  **Output Head (Multi-Layer Feature Aggregation):**
    *   **Concatenation:** $H_{final} = \text{Concat}(h_{out}^{(1)}, h_{out}^{(2)}, h_{out}^{(3)}, h_{out}^{(4)})$. This aggregates features from all depths, allowing the head to utilize both local chemical motifs and global structural contexts.
    *   **Projection:** Linear layer mapping $H_{final}$ to 5 target values.
