# Proposed Strategy: Neighborhood-Attentive Structural BiGRU

This strategy introduces a **Structural Neighborhood Attention Mechanism** as a structural innovation. This architecture evolves the "Latent Spatial Injection" concept (Idea 14) by relaxing the rigid dependency on the exact predicted base pairs. Instead of hard-linking position $i$ to position $j$, the model attends to a small window centered around $j$. This allows the network to leverage 3D folding constraints while being robust to the local misalignments and noise inherent in predicted secondary structures (addressing **Cite solution_lesson_node_00037**).

### Model

The architecture is a **Bidirectional GRU with a Structural Neighborhood Attention Module**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   We do **not** concatenate paired features at the input, preserving the purity of the local sequence for the convolutional stem. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem (Local Feature Extraction):**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** This projects the sparse inputs into a dense embedding space and aggregates immediate local context (k-mers) before any structural mixing occurs. **Cite solution_lesson_node_00027**.

3.  **Backbone (High-Capacity BiGRU):**
    *   The core sequence model is a **3-layer Bidirectional GRU** with a hidden dimension of 384.
    *   We prioritize the BiGRU over Transformers/Conformers due to its superior inductive bias for short sequences. **Cite solution_lesson_node_00017**.
    *   We maximize backbone capacity (width/depth) rather than adding complex hierarchical encoders (like Inception). **Cite solution_lesson_node_00026** and **Cite solution_lesson_node_00040**.

4.  **Structural Neighborhood Attention (Structural Innovation):**
    *   **Placement:** Inserted between the first and second GRU layers.
    *   **Mechanism:** For every position $i$ that is paired with position $j$ (according to the provided structure):
        *   **Query:** The hidden state $h_i$.
        *   **Keys/Values:** The hidden states of the window $[j-1, j, j+1]$ (handling boundary conditions).
        *   **Operation:** Compute Scaled Dot-Product Attention between $h_i$ and the window around $h_j$.
        *   **Residual:** The context vector is added to $h_i$ via a residual connection and a gating scalar.
    *   **Benefit:** Unlike hard concatenation (Idea 8) or single-point injection (Idea 14), this allows the model to "search" the immediate vicinity of the predicted pair. If the structure prediction is slightly off (e.g., a register shift), the attention mechanism can focus on the correct neighbor ($j-1$ or $j+1$), mitigating the noise issue identified in **Cite solution_lesson_node_00037** while still bridging the long-range dependency **Cite solution_lesson_node_00033**.

5.  **Output Head:**
    *   A final Linear layer projects the hidden states to the 5 target values.

### Data

1.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject filtering strategies to avoid distribution shift relative to the public test set. **Cite solution_lesson_node_00015**.

2.  **Robust Pipeline:**
    *   We will implement **hash-based caching** for the preprocessed data (e.g., `train_data_{hash(config)}.npy`). This ensures that the new adjacency-window logic is correctly executed and versioned. **Cite solution_lesson_node_00011**.

### Training

1.  **Objective (Unweighted Loss):**
    *   We will optimize the standard **MCRMSE** on all 5 target columns. We will **not** use inverse-variance weighting, as down-weighting noisy samples degrades performance on the unweighted competition metric. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler** to ensure convergence to a deep minimum. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** We will explicitly apply **Gradient Clipping** (max norm 1.0) to the training loop. This is mandatory to stabilize the high-capacity RNN and prevent the exploding gradients observed in previous hybrid attempts. **Cite solution_lesson_node_00046**.
    *   **Regularization:** Dropout will be applied after the Convolutional Stem and between GRU layers.

### Evaluation

1.  **Global Metric Aggregation:**
    *   We will implement a **Global Evaluation Loop** that concatenates predictions and targets for the entire validation set *before* calculating the MCRMSE. We will **not** average batch-wise RMSEs, as this produces optimistically biased results. **Cite solution_lesson_node_00045**.

2.  **Targeted Validation:**
    *   We will calculate the validation metric specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to ensure alignment with the competition leaderboard. **Cite solution_lesson_node_00017**.

3.  **Inference:**
    *   The test set sequences will be processed through the Conv Stem, BiGRU, and Structural Neighborhood Attention layers.
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) for submission.
