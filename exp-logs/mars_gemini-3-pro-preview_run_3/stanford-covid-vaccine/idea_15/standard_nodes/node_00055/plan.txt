This script orchestrates the training, evaluation, and submission process for the RNA Degradation Prediction task. It overrides the default configuration to ensure a fast execution (15 epochs), trains the `StructuralBiGRU` model, and computes the MCRMSE metric on the validation set. It then performs failure analysis by correlating prediction errors with input features like signal-to-noise ratio and GC content. Finally, if the validation score meets the specified threshold, it generates a submission file for the test set.
