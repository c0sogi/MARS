Implementation Strategy:
1.  **Setup & Loading**: Initialize the environment with fixed seeds. Load the training data from `./metadata/train.parquet`.
2.  **Target Variable Analysis**: Flatten the list-based target columns (`reactivity`, `deg_*`) to treat them as regression targets. Calculate global statistics (Mean, Std, Skewness, Kurtosis) and compute the Pearson correlation matrix between the different degradation conditions.
3.  **Input Analysis (Sequence)**: Analyze the RNA sequences, secondary structures, and predicted loop types as text data. Calculate sequence length distributions and character vocabulary frequencies (e.g., distribution of A/G/C/U, paired/unpaired brackets, and loop types).
4.  **Input Analysis (Tabular)**: Analyze metadata columns like `signal_to_noise` and `SN_filter`. Report descriptive statistics, outlier counts (IQR method), and categorical distributions.
5.  **Feature Relationships**: Aggregate features at the sample level (e.g., nucleotide content percentages, paired base percentages) and correlate them with the mean `reactivity` of the sample. Train a Random Forest regressor to identify the top 5 drivers of reactivity and check for feature redundancy.
