The issue arises because the `get_loader` function in `library/dataset.py` uses `Config.BATCH_SIZE` as a default argument, which is evaluated and bound at module definition time (when `Config.BATCH_SIZE` is 32). In `runfile.py`, `Config.BATCH_SIZE` is updated to 16 at runtime, but the subsequent call to `get_loader` without arguments uses the stale default value of 32. This causes the assertion `inputs.shape == (Config.BATCH_SIZE, ...)` to fail because the loader returns batches of size 32 while the assertion expects 16.

To fix this, I will modify `runfile.py` to explicitly pass the updated `batch_size=Config.BATCH_SIZE` when calling `get_loader`, ensuring the data loader uses the runtime configuration.
