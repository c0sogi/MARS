# Proposed Strategy: Stabilized Decoupled Bias-Refined BiGRU (SDBR-BiGRU)

This strategy synthesizes the high-performance backbone of Idea 17 with a refined **Decoupled Structural Interaction Module**. It rigorously corrects the "Loop Silencing" paradox by allowing unpaired bases to undergo self-refinement via learned bias terms, while ensuring optimization stability through correct normalization placement and gradient clipping.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers to initialize the backbone. **Cite solution_lesson_node_00027**.

3.  **Stabilized 3-Layer Backbone:**
    *   The backbone consists of **3 Blocks** (adhering to the optimal depth found in Idea 17, avoiding the instability of 4-layer variants discussed in **Cite solution_lesson_node_00068**). Each block contains a **Bidirectional GRU** followed by the **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** Hidden dimension of **384**. **Cite solution_lesson_node_00063**.
    *   **Decoupled Structural Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **Decoupled Message:** $m_{ij} = \text{GELU}(W_{msg} \cdot h_j + b_{msg})$. We do **not** concatenate $h_i$ here. Crucially, for unpaired bases ($h_j=0$), this term becomes the bias $b_{msg}$, effectively serving as a learnable "loop embedding" to allow self-refinement. **Cite solution_lesson_node_00080** and **Cite solution_lesson_node_00085**.
        *   **Stabilized MLP Gate:**
            *   Project Joint Context: $z_{raw} = W_{g1} \cdot [h_i; h_j]$. We do **not** normalize this input to preserve sparsity semantics. **Cite solution_lesson_node_00079**.
            *   **Internal Normalization:** $z_{norm} = \text{LayerNorm}(z_{raw})$. This stabilizes the MLP internals **Cite solution_lesson_node_00075**.
            *   Activation: $z_{act} = \text{GELU}(z_{norm})$.
            *   Logit Projection: $logits = W_{g2} \cdot z_{act}$.
            *   **No Logit Norm:** $g_{ij} = \sigma(logits)$. We strictly avoid normalizing logits to allow saturation. **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. This ensures stability for the recurrent stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
