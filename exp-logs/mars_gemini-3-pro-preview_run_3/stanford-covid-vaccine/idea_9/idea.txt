# Proposed Strategy: Multi-Scale Inception-GRU with Full-Spectrum Training

This strategy introduces a **Multi-Scale Inception Stem** as a structural innovation. This component enhances the "Convolutional Stem" concept established in previous successful iterations by explicitly capturing local structural motifs of varying lengths (k-mers) simultaneously. This is coupled with a high-capacity Recurrent backbone and a rigorous adherence to the data and optimization protocols defined in the lessons.

### Model

The architecture is a **Bidirectional GRU with a Multi-Scale Inception Stem**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings, as they increase parameters without benefit in this low-data regime. **Cite solution_lesson_node_00009**.
    *   We avoid "Spatial Augmentation" (concatenating paired features), as hard-coding long-range dependencies into local features disrupted the convolutional processing in previous attempts. **Cite solution_lesson_node_00037**.

2.  **Multi-Scale Inception Stem (Structural Innovation):**
    *   Instead of a single 1D Convolutional layer (which fixes the receptive field to a single k-mer size), we implement a parallel **Inception Block** as the entry point.
    *   **Mechanism:** The input tensor is processed in parallel by three 1D Convolutional layers with kernel sizes $k=\{1, 3, 5\}$ (padding='same').
    *   **Aggregation:** The outputs of these parallel branches are concatenated along the channel dimension and passed through a **GELU** activation.
    *   **Benefit:** This allows the model to simultaneously learn single-nucleotide properties, codon-sized motifs, and slightly larger structural contexts (5-mers) immediately at the projection stage. This provides a richer, multi-resolution embedding to the backbone compared to a standard stem. **Cite solution_lesson_node_00027**.

3.  **Backbone (High-Capacity BiGRU):**
    *   We employ a standard **Bidirectional GRU** (2 to 3 layers).
    *   **Capacity:** We prioritize the hidden dimension size (e.g., 384 or 512) over depth. Previous lessons indicated that maximizing backbone capacity is more effective than adding complex hierarchical encoders. **Cite solution_lesson_node_00026**.
    *   **Implementation:** We use the standard fused-kernel implementation rather than custom residual stacks, as residuals provided no benefit for shallow sequence models. **Cite solution_lesson_node_00032**.
    *   We avoid Transformers/Attention, as the pure RNN inductive bias is superior for these short sequences. **Cite solution_lesson_node_00017**.

4.  **Output Head:**
    *   A final Linear layer projects the hidden states to the 5 target values for each position.

### Data

1.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject the filtering strategy, as training on the full noisy distribution is required to generalize to the noisy public test set. **Cite solution_lesson_node_00015**.

2.  **Robust Pipeline:**
    *   We will implement **hash-based caching** for the preprocessed data (e.g., `train_data_{hash(config)}.npy`). This ensures that the switch to the Inception Stem and full dataset is correctly propagated, preventing stale data loading. **Cite solution_lesson_node_00011**.

### Training

1.  **Objective (Unweighted Loss):**
    *   We will optimize the standard **MCRMSE** (Mean Columnwise Root Mean Squared Error) on all 5 target columns.
    *   We will **not** use inverse-variance weighting, as down-weighting noisy samples degrades performance on the unweighted competition metric. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Scheduler:**
    *   We will use **AdamW** combined with a **Cosine Annealing Learning Rate Scheduler**. This dynamic learning rate is critical for converging to a deep minimum and preventing premature plateaus. **Cite solution_lesson_node_00031**.

### Evaluation

1.  **Internal Validation:**
    *   We will calculate the validation metric specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to ensure our internal benchmarking aligns with the competition leaderboard. **Cite solution_lesson_node_00017**.

2.  **Inference:**
    *   The test set sequences will be processed through the Inception Stem and BiGRU backbone.
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) and flattened for the final submission.
