The implementation strategy involves the following steps:

1.  **Setup and Configuration**: Import necessary modules and the provided library components (`Config`, `HCSDBR_BiGRU`, `run_training`, `get_dataloaders`, `scored_mcrmse`). Set the random seed for reproducibility.
2.  **Training**: Execute the training pipeline using `run_training` with `load_cached_data=True`. To satisfy the "fast baseline" requirement while ensuring meaningful convergence on the small dataset (1,728 samples), the number of epochs is set to 20.
3.  **Validation Inference**: Load the best model checkpoint saved during training. Perform inference on the full validation set to compute the `Final Validation Metric` using the competition-specific MCRMSE logic (slicing to 68 positions and selecting scored columns).
4.  **Failure Analysis**: Calculate the Root Mean Squared Error (RMSE) for each validation sample. Merge these errors with the validation metadata (loaded from Parquet) to compute and print the correlation between model error and `signal_to_noise` ratio, identifying if noisy data correlates with poor performance.
5.  **Submission Generation**: Check if the validation metric is below the specified threshold (0.5884...). If so, generate predictions for the test set. Format the output into the required `id_seqpos` row-wise CSV format, covering all 107 positions and 5 targets, and save it to `./submission/submission.csv`.
