# Proposed Strategy: Interleaved Gated-Structure BiGRU

This strategy introduces an **Interleaved Structural Interaction** mechanism. This is a structural evolution of the "Latent Injection" concepts (Ideas 11-14). Instead of injecting structural information only once at the input or after the stem, we interleave **Gated Structural Skip-Connections** between the layers of a high-capacity BiGRU backbone. This allows the model to iteratively refine its representation of the RNA sequence by alternating between sequential processing (BiGRU) and spatial structural updates (Gating), effectively mimicking the physical folding process while maintaining the computational efficiency of fused RNN kernels.

### Model

The architecture is a **Deep BiGRU with Interleaved Gated Structural Injection**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   We do **not** concatenate paired features at the input, preserving the purity of the local sequence for the convolutional stem. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem (Local Feature Extraction):**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** This projects the sparse inputs into a dense embedding space and aggregates immediate local context (k-mers) before any structural mixing occurs. **Cite solution_lesson_node_00027**.

3.  **Interleaved Backbone (Iterative Refinement):**
    *   The backbone consists of **3 Blocks**, where each block contains a **Bidirectional GRU Layer** followed by a **Structural Injection Layer** (except the final block).
    *   **BiGRU Layer:** Standard fused BiGRU (hidden dim 384) to capture sequential context. **Cite solution_lesson_node_00017** and **Cite solution_lesson_node_00026**.
    *   **Structural Injection Layer (The Innovation):**
        *   Placed *between* BiGRU layers (e.g., Output of GRU 1 $\to$ Injection $\to$ Input of GRU 2).
        *   **Mechanism:** For every position $i$, we identify its paired index $j$ from the provided structure.
        *   **Gating:** We compute a trust gate $g_{ij} = \sigma(W_{gate} \cdot [h_i; h_j])$, where $h$ are the hidden states from the previous GRU layer.
        *   **Update:** $h'_i = h_i + g_{ij} \odot (W_{proj} \cdot h_j)$.
        *   **Benefit:** This allows the model to "linearize" the graph structure **Cite solution_lesson_node_00033** dynamically. By interleaving this step, the network can use the sequential context learned in Layer 1 to decide which structural connections to trust in Layer 2, robustly handling noisy structure predictions. **Cite solution_lesson_node_00037**.

4.  **Output Head:**
    *   A final Linear layer projects the hidden states of the last BiGRU layer to the 5 target values.

### Data

1.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject filtering strategies to avoid distribution shift relative to the public test set. **Cite solution_lesson_node_00015**.

2.  **Robust Pipeline:**
    *   We will implement **hash-based caching** for the preprocessed data (e.g., `train_data_{hash(config)}.npy`). This ensures that the new interleaved architecture's data requirements are correctly met. **Cite solution_lesson_node_00011**.

### Training

1.  **Objective (Unweighted Loss):**
    *   We will optimize the standard **MCRMSE** on all 5 target columns. We will **not** use inverse-variance weighting, as down-weighting noisy samples degrades performance on the unweighted competition metric. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. This is critical for convergence. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** We will explicitly apply **Gradient Clipping** (max norm 1.0) to the training loop. This is **mandatory** to stabilize the deep, hybrid recurrent architecture and prevent the exploding gradients that caused previous similar attempts to underperform. **Cite solution_lesson_node_00046**.
    *   **Regularization:** Dropout will be applied after the Convolutional Stem and within the Structural Injection layers.

### Evaluation

1.  **Global Metric Aggregation:**
    *   We will implement a **Global Evaluation Loop** that concatenates predictions and targets for the entire validation set *before* calculating the MCRMSE. We will **not** average batch-wise RMSEs, as this produces optimistically biased results. **Cite solution_lesson_node_00045**.

2.  **Targeted Validation:**
    *   We will calculate the validation metric specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to ensure alignment with the competition leaderboard. **Cite solution_lesson_node_00017**.

3.  **Inference:**
    *   The test set sequences will be processed through the Stem and the Interleaved Backbone.
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) for submission.
