The implementation strategy follows the "High-Capacity Full-Rank Synthesis" idea. We will orchestrate the training and evaluation pipeline using the provided library modules.

1.  **Setup**: Initialize random seeds and the compute device using `library.config` and `library.utils`.
2.  **Data Loading**: Retrieve training, validation, and test dataloaders via `library.data`. We utilize the cached data for efficiency.
3.  **Model & Optimization**: Instantiate the `RNAModel` (4-layer BiGRU with GLU-Decoupled Interaction). Configure `AdamW` optimizer and `CosineAnnealingLR` scheduler. Use `MCRMSELoss` as the criterion.
4.  **Training**: Execute the training loop using `library.engine.fit`. We limit training to 20 epochs to satisfy the "fast baseline" requirement while ensuring sufficient convergence for the high-capacity backbone.
5.  **Evaluation**: Load the best model checkpoint. Compute predictions on the full validation set. Calculate and print the `Final Validation Metric` (MCRMSE on scored columns).
6.  **Failure Analysis**: Compute the Root Mean Squared Error (RMSE) for each validation sample. Correlate these errors with metadata features (`signal_to_noise`, `SN_filter`, sequence composition) to identify performance bottlenecks.
7.  **Submission**: If the validation metric meets the threshold (< 0.5884), generate predictions for the test set. Format the output according to the competition requirements (flattening `id` and `seqpos`) and save to `./submission/submission.csv`.
