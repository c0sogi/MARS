The issue is that the validation metric (MCRMSE) is currently calculated over all 5 target columns, whereas the task description specifies that only 3 columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) are scored. Including the non-scored columns (which likely contain higher variance or noise) inflates the error metric, causing it to fail the validity check.

To fix this, I will:
1.  Define `SCORED_COLS_INDICES = [0, 1, 3]` in `library/config.py` (Cite debug_lesson_8).
2.  Update the `validate` function in `library/train.py` to accept the `config` object and filter predictions/targets using these indices before metric calculation (Cite debug_lesson_1).
3.  Update the `validate` call sites and the final evaluation logic in `runfile.py` to perform the same filtering.
