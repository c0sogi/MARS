# Proposed Strategy: Latent Spatially-Augmented BiGRU

This strategy introduces a structural innovation called **Latent Spatial Mixing**. This addresses the failure of previous "Spatial Augmentation" attempts (Idea 7/8) by shifting the topology integration point. Instead of polluting the raw input features with noisy structural data before the convolutional stem (which disrupted local motif extraction per **Cite solution_lesson_node_00037**), we extract clean local features first and then inject structural context in the latent space. This is coupled with rigorous adherence to the optimization and evaluation protocols identified as critical in the lessons.

### Model

The architecture is a **Bidirectional GRU with Latent Spatial Mixing**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   We do **not** concatenate paired features at this stage, preserving the purity of the local sequence for the next step.

2.  **Convolutional Stem (Local Feature Extraction):**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** This projects the sparse inputs into a dense embedding space and aggregates immediate local context (k-mers) without interference from non-local structural noise. **Cite solution_lesson_node_00027**.

3.  **Latent Spatial Mixer (Structural Innovation):**
    *   **Mechanism:** After the convolutional projection, we perform the spatial augmentation. For every position $i$ in the sequence, we use the provided secondary structure to identify its paired index $j$.
    *   **Operation:** We retrieve the latent vector $h_j$ produced by the Conv Stem. If position $i$ is unpaired, we use a zero vector. We then fuse the local and paired vectors (e.g., via concatenation followed by a Linear projection or a Gated mechanism) to form a spatially-aware embedding $h'_{i}$.
    *   **Benefit:** This provides the backbone with "hyper-links" to 3D neighbors, linearizing the graph structure **Cite solution_lesson_node_00033**, but does so *after* robust local features have been established, avoiding the feature corruption observed in previous attempts **Cite solution_lesson_node_00037**.

4.  **Backbone (High-Capacity BiGRU):**
    *   The spatially-mixed sequence is fed into a **Bidirectional GRU** (2 to 3 layers, hidden dimension ~384).
    *   We prioritize the BiGRU over Transformers for its superior inductive bias on short sequences. **Cite solution_lesson_node_00017**.
    *   We focus on maximizing backbone capacity rather than adding hierarchical depth. **Cite solution_lesson_node_00026**.

5.  **Output Head:**
    *   A final Linear layer projects the hidden states to the 5 target values.

### Data

1.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject filtering to avoid distribution shift relative to the public test set. **Cite solution_lesson_node_00015**.

2.  **Robust Pipeline:**
    *   We will implement **hash-based caching** for the preprocessed data (e.g., `train_data_{hash(config)}.npy`). This ensures that the new Latent Spatial Mixing logic is correctly executed and versioned. **Cite solution_lesson_node_00011**.

### Training

1.  **Objective (Unweighted Loss):**
    *   We will optimize the standard **MCRMSE** on all 5 target columns. We will **not** use inverse-variance weighting, as it degrades performance on the unweighted competition metric. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler** to ensure convergence to a deep minimum. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** We will explicitly apply **Gradient Clipping** (norm value 1.0) to the training loop. This is mandatory to stabilize the high-capacity RNN and prevent the exploding gradients that likely hindered previous high-capacity attempts. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Global Metric Aggregation:**
    *   We will implement a **Global Evaluation Loop** that concatenates predictions and targets for the entire validation set *before* calculating the MCRMSE. We will **not** average batch-wise RMSEs, as this produces optimistically biased results. **Cite solution_lesson_node_00045**.

2.  **Inference:**
    *   The test set sequences will be processed through the Conv Stem, Latent Spatial Mixer, and BiGRU backbone.
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) for submission.
