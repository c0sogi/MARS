The following script demonstrates the end-to-end usage of the provided library components for the RNA degradation prediction task. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` settings to enable `DEBUG` mode, reduce batch sizes, and limit epochs for rapid execution.
2.  **Data Loading**: Uses `get_loaders` to process metadata and create PyTorch DataLoaders. It verifies the shape and integrity of the loaded batches.
3.  **Model Initialization**: Instantiates the `RNAModel` (High-Capacity GLU-Refined Decoupled BiGRU) and verifies its architecture and output dimensions via a dummy forward pass.
4.  **Loss & Metric Verification**: Tests the `MCRMSELoss` function and the `calculate_mcrmse` metric utility to ensure they handle the sequence length mismatch (107 predicted vs 68 scored) correctly.
5.  **Training Loop**: Executes a single training epoch and a validation step using the provided `train_one_epoch` and `evaluate` functions, asserting that loss values are valid.
6.  **Inference & Submission**: Runs the `generate_submission` function on the test set and validates the format of the resulting CSV file.
