Based on the comprehensive analysis of the experimental history, I propose the following optimized strategy.

This strategy represents the **High-Capacity Globally-Recalibrated Synthesis**. It addresses the critical findings that **Backbone Capacity is dominant** (Lesson 103) and that **Multiplicative Interactions** can be unstable if applied locally (Lesson 113). However, it identifies a missing inductive bias: while the current best models capture **Local** (CNN/RNN) and **Pairwise** (Structural Interaction) dependencies, they lack an explicit mechanism to model **Global** molecular properties (e.g., overall stability, GC-content, or signal quality) that modulate reactivity across the entire sequence.

To address this, I introduce **Global Sequence-Excitation (GSE)** modules interleaved within the massive **4-Layer Backbone**. Unlike local multiplicative interactions which failed due to noise, GSE aggregates statistics across the entire sequence length to robustly recalibrate feature channels, allowing the model to adapt its processing based on the holistic context of the RNA molecule. This is integrated with the **Stabilized GLU-Decoupled Interaction** mechanism (Lessons 62, 80, 85) and trained with **Multi-Task Learning** (Lesson 94).

# Proposed Strategy: High-Capacity Globally-Recalibrated Decoupled BiGRU (HC-GRD-BiGRU)

This strategy introduces a **4-Layer Bidirectional GRU** with a **High-Capacity Hidden Dimension** (384 per direction, 768 total). It interleaves this backbone with **Stabilized GLU-Decoupled Structural Injection** modules to handle base-pairing, followed immediately by **Global Sequence-Excitation** modules to recalibrate features based on whole-sequence context.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers. **Cite solution_lesson_node_00027**.

3.  **High-Capacity Recalibrated Backbone:**
    *   The backbone consists of **4 Blocks** processed sequentially (Strict Hierarchy, **Cite solution_lesson_node_00127**). Each block contains three sub-modules:
    *   **A. BiGRU Layer:** Hidden dimension of **384** (Total 768). We maintain this high capacity to capture complex dependencies. **Cite solution_lesson_node_00103**.
    *   **B. Stabilized GLU-Decoupled Interaction Module:**
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If unpaired, force $h_j = 0$. **Cite solution_lesson_node_00064**.
        *   **GLU Message (Bias-Refined):** $m_{ij} = (W_c h_j + b_c) \odot \sigma(W_g h_j + b_g)$. For unpaired bases ($h_j=0$), this becomes a learnable bias vector, enabling self-refinement. **Cite solution_lesson_node_00085**, **Cite solution_lesson_node_00062**.
        *   **Stabilized Gate:** MLP with Internal LayerNorm (no logit norm). **Cite solution_lesson_node_00075**, **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{struct} = h_{rnn} + g_{ij} \odot m_{ij}$.
    *   **C. Global Sequence-Excitation (GSE) Module (Structural Innovation):**
        *   **Global Pooling:** $z = \text{GlobalAveragePool}(h_{struct})$. Aggregates information across the entire sequence length $L$.
        *   **Recalibration MLP:** $s = \sigma(W_2 \cdot \text{GELU}(W_1 \cdot z))$. Compresses and expands global features to learn channel-wise importance weights.
        *   **Excitation:** $h_{calib} = h_{struct} \odot s$. Scales the sequence features based on global context (e.g., dampening noisy channels in unstable molecules). Unlike local affine modulation (which failed, **Cite solution_lesson_node_00113**), global averaging filters out local noise, making this multiplicative interaction robust.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{calib})$. Ensures stability for the deep stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
