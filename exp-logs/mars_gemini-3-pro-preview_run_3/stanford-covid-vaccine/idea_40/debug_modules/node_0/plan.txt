### Implementation Strategy

We will also redirect output paths to a specific demo directory in `./working`.
2.  **Data Pipeline Verification**: We will initialize the data loaders using `get_loaders(debug=True)`. We will fetch a single batch to assert that the input tensors (sequence features, structure indices) and target tensors have the correct shapes and data types.
3.  **Model Initialization and Forward Pass**: We will instantiate the `RNAModel` and perform a forward pass with the fetched batch. We will assert that the output shape matches `(Batch, Seq_Len, 5)` and that the model operates on the correct device.
4.  **Metric Verification**: We will manually calculate the `mcrmse_loss` and `competition_metric` on the model's output to verify the loss functions return valid scalar values.
5.  **Training Loop Execution**: We will run a short training loop (2 epochs) using the `train_epoch` and `validate` functions. We will check that the training process completes without error and returns loss metrics.
6.  **Inference and Submission**: We will invoke `generate_submission` to create a prediction file. Finally, we will load the generated CSV to verify its format (columns, row count) against the requirements.
