This script implements the High-Capacity Full-Rank Decoupled BiGRU strategy. It orchestrates the training, validation, failure analysis, and conditional submission generation.

**Strategy Outline:**
1.  **Configuration:** Overrides `MAX_EPOCHS` to 15 to ensure a fast baseline execution while maintaining sufficient convergence on the full training set (1728 samples).
2.  **Setup:** Sets random seeds and detects the computing device (GPU/CPU).
3.  **Data Loading:** Uses `get_dataloaders` with caching enabled to load pre-processed data efficiently.
4.  **Model & Training:** Initializes the `RNAModel` and trains it using `MCRMSELoss` (optimizing all 5 targets) and `AdamW` with Cosine Annealing. The best model based on validation MCRMSE (scored on 3 targets) is saved.
5.  **Validation:** Computes and prints the `Final Validation Metric` on the hold-out set.
6.  **Failure Analysis:** Calculates per-sample MCRMSE on the validation set and correlates these errors with metadata features (`signal_to_noise`, `SN_filter`, `gc_content`, `unpaired_pct`) to identify systematic weaknesses.
7.  **Submission:** Checks if the validation score is below the threshold (`0.5884...`). If so, generates predictions for the test set and saves them to `./submission/submission.csv`.
