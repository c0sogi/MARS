Implementation strategy:
1.  **Environment Setup**: Initialize the environment by setting the random seed for reproducibility and detecting the available computation device (GPU/CPU).
2.  **Data Loading**: Utilize the provided `get_data` function to load training, validation, and testing datasets. Wrap these in the `RNADataset` class and create PyTorch `DataLoader` instances.
3.  **Model Training**: Execute the training pipeline using `train_model` from the engine. This handles the training loop, validation monitoring, and early stopping.
4.  **Validation & Metric Calculation**:
    *   Generate predictions on the validation set.
    *   Reshape both predictions and ground truth targets to the shape `(N, 68, 5)` to align with the metric definition.
    *   Compute the MCRMSE using the provided utility function and print it with full precision.
5.  **Failure Analysis**:
    *   Calculate the Root Mean Squared Error (RMSE) for each sample in the validation set to quantify error magnitude.
    *   Load validation metadata (including Signal-to-Noise ratio and sequence content).
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify sources of difficulty.
6.  **Submission Generation**:
    *   Load the test set metadata.
    *   Use the `generate_submission` function to create the correctly formatted CSV file for the test set.
