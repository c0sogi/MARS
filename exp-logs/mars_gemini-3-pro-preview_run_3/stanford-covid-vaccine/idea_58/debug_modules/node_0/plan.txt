This script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:

1.  **Configuration Override**: Modifies the `Config` class to use a temporary working directory and reduces training parameters (epochs, batch size) for a fast execution.
2.  **Data Loading Verification**: Instantiates `RNADataset` with a small subset of data, verifying the shapes of input features, structure indices, and target variables.
3.  **Model & Loss Verification**: Initializes the `HCSDBiGRU` model, runs a forward pass on a batch, and computes the `MCRMSELoss` and competition metric to ensure architectural and mathematical correctness.
4.  **Training Simulation**: Executes the `run_training` pipeline for one epoch on a small dataset to demonstrate the training loop and model checkpointing.
5.  **Submission Generation**: Runs the inference pipeline using `generate_submission` and validates the format of the resulting CSV file.
