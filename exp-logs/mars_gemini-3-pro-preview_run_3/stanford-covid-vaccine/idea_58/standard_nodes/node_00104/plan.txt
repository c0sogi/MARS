### Implementation Strategy

1.  **Setup and Imports**: Initialize the environment by importing necessary standard libraries and the provided custom modules (`library.config`, `library.train_eval`, `library.dataset`, `library.model`, `library.loss_metric`). Set random seeds for reproducibility.
2.  **Training**: Execute the training pipeline using `run_training` from `train_eval.py`. We will use the full training set (1728 samples) but limit the epochs to 15 to ensure the script completes quickly (well within the 2-hour limit) while still establishing a valid baseline.
3.  **Validation Inference**: Load the best model saved during training. Run inference on the validation set in `eval` mode with `no_grad` to conserve memory and compute speed.
4.  **Metric Computation**: Calculate the MCRMSE score on the validation set using `compute_competition_metric`. Print the result in the exact required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Compute the per-sample RMSE for the validation set.
    *   Load the validation metadata (`val.parquet`) to retrieve auxiliary features (`signal_to_noise`, `SN_filter`) and derive sequence composition features (percentage of A, G, C, U).
    *   Calculate and print the Pearson correlation between the per-sample error and these features to identify sources of model failure.
6.  **Submission**: Check if the validation metric is below the specified threshold (0.5884495377540588). If the condition is met, generate the submission file using `generate_submission` from `train_eval.py`.
