The implementation strategy is as follows:

1.  **Setup & Configuration**: Initialize the environment with a fixed random seed for reproducibility and detect the available computation device (GPU/CPU). Define a reduced number of epochs (10) to satisfy the "fast baseline" requirement while ensuring sufficient convergence on the small dataset (~1700 samples).

2.  **Training**: Execute the training pipeline using `library.train.run_training`. This handles data loading (with caching), model initialization (`SDBR_BiGRU`), and the training loop with cosine annealing and gradient clipping.

3.  **Validation**: After training, reload the best model checkpoint. Perform inference on the full validation set to compute the final MCRMSE metric using `library.utils.calculate_metric`. This ensures the metric is calculated exactly as specified (slicing to 68 positions and filtering for the 3 scored columns).

4.  **Failure Analysis**: Calculate the error magnitude for each validation sample individually. Correlate these error values with sample metadata (Signal-to-Noise Ratio) and sequence properties (nucleotide content) to identify factors contributing to poor model performance.

5.  **Submission**: Compare the final validation metric against the threshold (0.5884495377540588). If the model performs better (lower metric), generate predictions for the test set using `library.train.predict_and_submit` and save them to `submission.csv`.
