### Implementation Strategy

1.  **Configuration Setup**: Override default `Config` parameters to define a temporary working directory (`./working/demo_execution/`) and reduce computational load (small subset of 50 samples, 2 epochs, batch size 8) for a fast demonstration.
2.  **Data Pipeline Verification**: Initialize the data loaders using `get_dataloaders`. Fetch a single batch from the training and test loaders to verify the tensor shapes of features (`X`), targets (`y`), weights (`w`), and IDs.
3.  **Model Architecture Check**: Instantiate the `SpatiallyAugmentedBiGRU` model. Perform a forward pass with the dummy batch to ensure the output shape matches `(Batch, Seq_Len, 5)`.
4.  **Loss Function Validation**: Compute the loss using `WeightedMCRMSELoss` on the model output and ground truth to confirm the loss calculation logic handles the sequence length mismatch (107 vs 68) correctly.
5.  **Training Loop Execution**: Initialize the `Trainer` and execute the `fit` method. Verify that the training completes without error and produces a saved model file (`best_model.pth`).
6.  **Inference and Submission**: Load the trained model, perform inference on the test set, and generate a submission file using `save_submission`. Validate the format of the generated CSV file.
7.  **Cleanup**: (Optional) The script leaves artifacts in `./working/demo_execution/` for inspection as permitted.
