# Proposed Strategy: Deep GLU-Refined Decoupled BiGRU with Multi-Task Learning

This strategy introduces a **4-Layer Bidirectional GRU** with a **High-Capacity Hidden Dimension** (384 per direction, 768 total). It interleaves this backbone with a **Stabilized GLU-Decoupled Structural Injection** module. Unlike previous iterations that used simple GELU messages or bottlenecked gates, this strategy employs a **GLU Message** for rich signal modulation and a **Wide Stabilized MLP Gate** to preserve full rank, all stabilized by rigorous normalization protocols.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers. **Cite solution_lesson_node_00027**.

3.  **High-Capacity 4-Layer Backbone:**
    *   The backbone consists of **4 Blocks** processed sequentially (enforcing strict hierarchical abstraction, **Cite solution_lesson_node_00127**). Each block contains a **Bidirectional GRU** followed by the **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** Hidden dimension of **384** (Total 768). We explicitly maintain this high capacity to capture complex dependencies. **Cite solution_lesson_node_00103** and **Cite solution_lesson_node_00063**.
    *   **GLU-Refined Decoupled Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **GLU Message (Bias-Refined):** Instead of a simple projection, we use a **Gated Linear Unit**: $m_{ij} = (W_c h_j + b_c) \odot \sigma(W_g h_j + b_g)$. This allows the neighbor signal to self-modulate. Crucially, for unpaired bases ($h_j=0$), this becomes a learnable bias vector $b_c \odot \sigma(b_g)$, providing a highly expressive "loop embedding" for self-refinement. **Cite solution_lesson_node_00085**, **Cite solution_lesson_node_00062**.
        *   **Wide Stabilized MLP Gate:**
            *   **Wide Projection:** $z_{wide} = W_{in} \cdot [h_i; h_j]$. We project to a **Wide Hidden Dimension** (e.g., 768) to avoid bottlenecks. **Cite solution_lesson_node_00110**. We do **not** normalize this input. **Cite solution_lesson_node_00079**.
            *   **Internal Normalization:** $z_{norm} = \text{LayerNorm}(z_{wide})$. Stabilizes the MLP internals. **Cite solution_lesson_node_00075**.
            *   **Activation:** $z_{act} = \text{GELU}(z_{norm})$.
            *   **Output:** $logits = W_{out} \cdot z_{act}$.
            *   **No Logit Norm:** $g_{ij} = \sigma(logits)$. Allows full saturation. **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$. We use additive injection. **Cite solution_lesson_node_00113**.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. Ensures stability for the deep 4-layer stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
