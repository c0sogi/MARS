The following script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:

1.  **Configuration**: Overrides default configuration settings (epochs, batch size, debug mode) to ensure the demonstration runs quickly.
2.  **Data Loading**: Loads a small debug subset of the training, validation, and test datasets using the library's data processing functions. It verifies the data shapes and integrity.
3.  **Model Initialization**: Instantiates the `RNANet` model and performs a dummy forward pass to validate input/output dimensions.
4.  **Metric Verification**: Validates the custom `MCRMSELoss` and `metric_calculator` functions with synthetic data to ensure correctness.
5.  **Training Loop**: Runs a short training session (2 epochs) using the `train_model` engine, demonstrating the optimization process and model checkpointing.
6.  **Inference**: Generates a submission file using the trained model on the debug test set via `generate_submission`, and verifies the output format.
