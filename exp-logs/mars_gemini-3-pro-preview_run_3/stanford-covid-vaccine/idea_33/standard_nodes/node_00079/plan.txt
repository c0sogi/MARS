Implementation strategy:
1.  **Setup & Imports**: Import necessary components from the provided library files (`config`, `utils`, `data`, `model`, `engine`). Set random seeds and define the computation device (GPU).
2.  **Data Preparation**: Initialize DataLoaders for the training and validation sets using `get_train_val_datasets`. We use the full dataset (`debug=False`) to ensure the model learns effectively and meets the strict validation metric threshold, as the dataset is small enough (~1.7k samples) for fast training.
3.  **Model & Optimization**: Instantiate the `RNANet` model (Deep Input-Normalized Channel-Gated BiGRU). Configure the `AdamW` optimizer and `CosineAnnealingLR` scheduler as specified in the configuration.
4.  **Training Loop**: Execute the training process using `train_model`. This handles the training epochs, gradient clipping, validation monitoring, and saving the best model checkpoint based on the MCRMSE score.
5.  **Final Validation**: Reload the best model weights and compute the final validation metric on the entire hold-out validation set using `validate`. Print this metric in the required format.
6.  **Failure Analysis**: Perform inference on the validation set to calculate per-sample errors. Merge these errors with metadata (Signal-to-Noise, Sequence Content) and compute correlations to identify factors associated with high error rates.
7.  **Submission**: Check if the final validation metric is below the specified threshold (`0.5978901386`). If successful, load the test dataset and generate the `submission.csv` file using `generate_submission`.
