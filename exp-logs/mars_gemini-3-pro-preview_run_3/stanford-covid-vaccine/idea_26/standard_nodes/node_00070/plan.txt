This inclusion of non-scored targets inflates the error metric and misaligns the optimization objective with the evaluation criteria (Cite debug_lesson_1).

To fix this, I will:
1.  Define `SCORED_TARGET_INDICES = [0, 1, 3]` in `library/config.py` to explicitly identify the columns to be scored (Cite debug_lesson_8).
2.  Update `library/utils.py` to import this constant and filter the prediction and target tensors in the `MCRMSE` function to only include these indices.
3.  Update `library/train.py` to similarly filter the tensors in the `train_one_epoch` function so that the model optimizes for the correct targets.
