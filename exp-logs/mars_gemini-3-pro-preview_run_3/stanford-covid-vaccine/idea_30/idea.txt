# Proposed Strategy: Deep Internally-Normalized Channel-Gated BiGRU (DIN-CG-BiGRU)

This strategy represents the "Stabilized Structural Evolution" of the architecture. It synthesizes the high-capacity **Deep Backbone** (Idea 25/26) and the superior **Channel-Wise Gating** (Idea 24) with the critical **Internal Normalization** mechanism (Lesson 75) that was present in the original best model but lost in subsequent iterations. This ensures the model can leverage fine-grained, feature-specific structural filtering without suffering from the gate saturation and gradient vanishing that caused recent high-potential architectures to fail.

### Model

The architecture is a **4-Layer Bidirectional GRU with Interleaved Internally-Normalized Channel-Gated Structural Injection**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** We do **not** concatenate paired features at the input stage. This ensures the convolutional stem extracts clean local motifs without interference from noisy structural predictions. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers to initialize the backbone. **Cite solution_lesson_node_00027**.

3.  **Deep Stabilized Backbone:**
    *   The backbone consists of **4 Blocks** (maximizing capacity within safe limits, addressing **Cite solution_lesson_node_00026**). Each block contains a **Bidirectional GRU** followed by the **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** We employ a **Bidirectional GRU** with a hidden dimension of **384**. We adhere to this width to balance capacity and trainability. **Cite solution_lesson_node_00063**. We prioritize BiGRUs over Transformers for their superior inductive bias. **Cite solution_lesson_node_00017**.
    *   **Internally-Normalized Channel-Gated Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$:
        *   **Gather:** Retrieve the hidden state vector $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Zero-Masking:** If position $i$ is **unpaired**, we explicitly force $h_j$ to be a **zero vector**. We strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **Non-Linear Message:** Transform the neighbor state via a dense layer with activation: $m_{ij} = \text{GELU}(W_{msg} \cdot h_j)$. This ensures expressivity. **Cite solution_lesson_node_00062**.
        *   **Internally-Normalized Channel-Gating:**
            *   Compute raw gate logits: $z_{ij} = W_{gate} \cdot [h_i; h_j]$.
            *   **Normalization:** Apply **Layer Normalization** to the logits: $\hat{z}_{ij} = \text{LayerNorm}(z_{ij})$. This prevents the Sigmoid function from saturating, correcting the critical failure mode identified in **Cite solution_lesson_node_00075**.
            *   **Activation:** Compute the channel-wise gate: $g_{ij} = \sigma(\hat{z}_{ij})$.
        *   **Injection:** Update the state: $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** Apply Layer Normalization *after* the residual update: $h_{out} = \text{LayerNorm}(h_{res})$. This ensures stability for the deep 4-layer stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   A final Linear layer projects the output of the last BiGRU block to the 5 target values.

### Data

1.  **Preprocessing:**
    *   Generate adjacency maps for the gather operations based on the provided secondary structures.
    *   **Caching:** Use **hash-based caching** (e.g., `train_data_{hash(config)}.npy`) to ensure pipeline integrity. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   Train on the **entire training dataset** (~1,728 samples). We explicitly reject subsampling and filtering strategies to avoid distribution shift relative to the public test set. **Cite solution_lesson_node_00015** and **Cite solution_lesson_node_00071**.

### Training

1.  **Objective (Unweighted Loss):**
    *   Optimize the standard **MCRMSE** on all 5 target columns. We do **not** use inverse-variance weighting. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** Explicitly apply **Gradient Clipping** (max norm 1.0). This is **mandatory** to stabilize the deep hybrid architecture. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Correct Metric Calculation:**
    *   **Slicing:** Before calculating the metric, explicitly **slice** the prediction and target tensors to the first 68 positions (`seq_scored`). Do *not* average over the padded length. **Cite solution_lesson_node_00066**.
    *   **Global Aggregation:** Concatenate these sliced tensors for the entire validation set *before* calculating the MCRMSE to avoid batch-averaging bias. **Cite solution_lesson_node_00045**.

2.  **Inference:**
    *   Process test sequences through the Stem and Deep Backbone.
    *   Generate predictions for all 107 positions, then slice to the first 68 positions (`seq_scored`) for submission.
