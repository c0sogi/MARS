The following script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Setup**: Configures the environment for a rapid demonstration (reduced batch size, subset of data, CPU/GPU selection) and ensures reproducibility.
2.  **Data Loading**: Uses the `get_dataloaders` function to load a small subset of the training and testing data from the metadata files. It validates the structure and shapes of the loaded batches.
3.  **Model Initialization**: Instantiates the `DeepBiasRefinedBiGRU` model and validates its forward pass logic.
4.  **Training Simulation**: Runs a minimal training loop (1 epoch, few batches) to demonstrate loss calculation (`MCRMSELoss`) and optimization.
5.  **Evaluation**: Demonstrates how to calculate the competition metric (`MCRMSE`) using the `calculate_metric` utility.
6.  **Inference**: Runs a forward pass on the test set to verify prediction shapes.
