# Proposed Strategy: Signal-Filtered Convolutional Transformer

Based on the analysis of previous experiments and lessons learned, I propose a **Signal-Filtered Convolutional Transformer**. This strategy evolves the architecture from a Recurrent Neural Network (BiGRU) to a Transformer-based approach to better capture global dependencies while strictly adhering to the data processing insights regarding encoding and sequence preservation.

## Model

The architecture is a **1D Convolutional Transformer Encoder**, designed to process the RNA sequence as a whole without flattening, while avoiding the complexity of explicit graph structures.

1.  **Input Representation:**
    *   The input will be a tensor of shape $(N, 107, C)$.
    *   We will strictly use **One-Hot Encoding** for the nucleotide sequence, secondary structure (dot-bracket), and predicted loop type, concatenating them into the channel dimension $C$. We will **not** use learned embeddings for these low-cardinality features. **Cite solution_lesson_node_00009**.
    *   The sequence dimension (107) is preserved throughout the network to maintain locality and translation invariance. **Cite solution_lesson_node_00002**.

2.  **Local Feature Extractor (Convolutional Tokenizer):**
    *   The one-hot encoded sequence is passed through a **1D Convolutional Layer** (kernel size 3 or 5, padding='same').
    *   This layer serves two purposes: it projects the sparse one-hot vectors into a dense latent dimension, and it aggregates immediate local context (e.g., a nucleotide and its immediate neighbors), which is the dominant factor for local stability. This acts as a learnable "k-mer" embedding.

3.  **Global Context Backbone (Transformer Encoder):**
    *   We replace the BiGRU/LSTM backbone with a **Transformer Encoder** (e.g., 2 to 4 layers, 4 to 8 heads).
    *   **Positional Encoding:** Sinusoidal positional encodings are added to the convolutional output to retain sequential order information.
    *   **Self-Attention:** The attention mechanism allows every nucleotide to attend to every other nucleotide. This effectively models the 3D folding interactions (where base $i$ interacts with base $j$) dynamically, without needing the rigid, explicit edge definitions of a GNN which proved suboptimal. **Cite solution_lesson_node_00010**.

4.  **Prediction Head:**
    *   A final Dense (Linear) layer projects the Transformer output at each position to the 5 target values.

## Data

1.  **Quality Filtering:**
    *   We will implement a strict filtering step during data loading. We will exclude all training samples where `SN_filter == 0`. This ensures the model trains exclusively on high-quality experimental data, addressing the noise-error correlation observed in previous failure analyses. We will ensure this logic is robustly integrated into the pipeline to prevent the caching failures seen previously. **Cite solution_lesson_node_00011**.

2.  **Preprocessing:**
    *   The test set will be processed identically (One-Hot + Shape preservation), but without filtering (predictions are required for all test samples).

## Training

1.  **Loss Function:** We will continue to use **MCRMSE** (Mean Columnwise Root Mean Squared Error).
2.  **Optimizer:** **AdamW** with a learning rate scheduler (e.g., Cosine Annealing with Warmup) to stabilize the training of the Transformer components.
3.  **Regularization:** Given the reduced dataset size (due to filtering) and the capacity of Transformers, we will apply **Dropout** (e.g., 0.2 - 0.4) within the Transformer blocks and potentially **Label Smoothing** to prevent overfitting.

## Evaluation

1.  **Inference:** The model will predict a $(N, 107, 5)$ tensor for the test set.
2.  **Post-processing:** We will slice the output to the first 68 positions (`seq_scored`) and flatten the result to the required submission format.
