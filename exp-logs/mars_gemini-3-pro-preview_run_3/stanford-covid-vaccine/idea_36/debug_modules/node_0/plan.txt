The following is a self-contained Python script that demonstrates how to utilize the provided library files (`config.py`, `utils.py`, `data.py`, `model.py`, `train.py`) to load data, train the `DDPNBiGRU` model, validate performance, and generate a submission.

The script overrides the default configuration to run a fast demonstration (1 epoch, small batch size) and includes assertions to verify the correctness of data shapes and pipeline logic.
