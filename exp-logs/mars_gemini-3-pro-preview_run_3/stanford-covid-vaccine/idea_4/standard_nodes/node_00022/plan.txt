The issue is a configuration mismatch where the `RNAGRU` model expects a `HIDDEN_DIM` attribute in the `Config` class, but the configuration file only defines `DIM_MODEL`. Additionally, the `Trainer` class expects `SCORED_INDICES` to be defined in `Config` for validation scoring, which is currently missing and will cause a subsequent error. Furthermore, based on `debug_lesson_6`, direct imports of the `Config` class (`from library.config import Config`) can lead to stale references in persistent environments; accessing the class via the module (`library.config.Config`) is more robust.

I will fix this by:
1.  Updating `library/config.py` to include `HIDDEN_DIM` (aliased to 128) and `SCORED_INDICES` (indices [0, 1, 3] corresponding to the scored targets).
2.  Refactoring `library/model.py` and `library/trainer.py` to import the `library.config` module instead of the class directly, ensuring they access the latest configuration values (Cite debug_lesson_6).
