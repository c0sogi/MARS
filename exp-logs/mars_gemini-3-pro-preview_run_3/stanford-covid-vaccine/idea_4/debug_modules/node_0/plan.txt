This script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Configuration**: Overrides default hyperparameters (epochs, batch size) to ensure a quick execution for demonstration purposes.
2.  **Data Loading**: Uses `get_dataloaders` to process the existing Parquet metadata into PyTorch DataLoaders, verifying input/output shapes.
3.  **Model Initialization**: Instantiates the `RNAConformer` model and performs a dummy forward pass to validate tensor dimensions.
4.  **Training Loop**: Uses the `Trainer` class to train the model for a few epochs, utilizing the training and validation sets.
5.  **Evaluation**: Validates the `MCRMSE` metric calculation logic.
6.  **Inference & Submission**: Generates predictions on the test set and creates a valid submission file using `create_submission`.
