# Proposed Strategy: Deep Input-Aware Channel-Gated BiGRU

This strategy represents the "Stabilized and Contextualized Evolution" of the best-performing concepts. It integrates the superior **Channel-Wise Gating** mechanism into a **Deep (4-Layer) Post-Norm Backbone** (correcting the stability issues of Idea 25). Crucially, it introduces a structural innovation: **Input-Aware Gating**. By injecting the static, local stem features into the deep gating logic, the model can explicitly verify physical base-pairing compatibility (e.g., "Does A pair with U?") at every layer, providing a robust safeguard against the structural noise identified in Lesson 37.

### Model

The architecture is a **4-Layer Bidirectional GRU with Interleaved Input-Aware Structural Injection**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** We do **not** concatenate paired features at the input stage. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space ($x^{stem}$) and aggregates local k-mers. We retain $x^{stem}$ for use in the interaction modules. **Cite solution_lesson_node_00027**.

3.  **Deep Refinement Backbone:**
    *   The backbone consists of **4 Blocks** (maximizing capacity within safe limits, addressing **Cite solution_lesson_node_00026**). Each block contains a **Bidirectional GRU** followed by an **Input-Aware Interaction Module** (except the final block).
    *   **BiGRU Layer:** We employ a **Bidirectional GRU** with a hidden dimension of **384**. We adhere to this width to balance capacity and trainability. **Cite solution_lesson_node_00063**. We prioritize BiGRUs over Transformers. **Cite solution_lesson_node_00017**.
    *   **Input-Aware Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$:
        *   **Gather:** Retrieve the hidden state $h_j$ and the *static stem feature* $x^{stem}_j$.
        *   **Zero-Masking:** If position $i$ is **unpaired**, explicitly force gathered vectors to zero. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **Non-Linear Message:** Transform the neighbor state via a dense layer: $m_{ij} = \text{GELU}(W_{msg} \cdot h_j)$. **Cite solution_lesson_node_00062**.
        *   **Input-Aware Channel-Gating:** Compute the gate using both dynamic hidden states *and* static stem features: $g_{ij} = \sigma(W_{gate} \cdot [h_i; h_j; x^{stem}_i; x^{stem}_j])$.
            *   *Benefit:* This allows the gate to verify physical constraints (e.g., nucleotide identity from $x^{stem}$) even in deep layers where $h$ might have drifted, effectively filtering out noisy/invalid structural edges.
        *   **Injection:** Update the state: $h_{res} = h_i + g_{ij} \odot m_{ij}$. This channel-wise control outperforms scalar gating. **Cite solution_lesson_node_00065**.
        *   **Post-Normalization:** Apply Layer Normalization *after* the residual update: $h_{out} = \text{LayerNorm}(h_{res})$. This is mandatory for stabilizing the 4-layer depth. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   A final Linear layer projects the output of the last BiGRU block to the 5 target values.

### Data

1.  **Preprocessing:**
    *   Generate adjacency maps for the gather operations.
    *   **Caching:** Use **hash-based caching** (e.g., `train_data_{hash(config)}.npy`) to ensure pipeline integrity. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   Train on the **entire training dataset** (~1,728 samples). We explicitly reject subsampling (which caused Idea 26 to fail) and filtering (Lesson 15). **Cite solution_lesson_node_00071**.

### Training

1.  **Objective (Unweighted Loss):**
    *   Optimize the standard **MCRMSE** on all 5 target columns. Do **not** use inverse-variance weighting. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** Explicitly apply **Gradient Clipping** (max norm 1.0). This is **mandatory** to stabilize the deep hybrid architecture. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Correct Metric Calculation:**
    *   **Slicing:** Explicitly **slice** predictions and targets to the first 68 positions (`seq_scored`) before calculating the metric. Do not average over padding. **Cite solution_lesson_node_00066**.
    *   **Global Aggregation:** Concatenate sliced tensors for the entire validation set *before* calculating MCRMSE to avoid batch-averaging bias. **Cite solution_lesson_node_00045**.

2.  **Inference:**
    *   Process test sequences through the Stem and Deep Backbone.
    *   Generate predictions for all 107 positions, then slice to the first 68 positions (`seq_scored`) for submission.
