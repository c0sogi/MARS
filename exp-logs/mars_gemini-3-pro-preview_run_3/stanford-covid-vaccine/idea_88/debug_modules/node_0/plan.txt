The implementation strategy involves creating a self-contained script that imports the provided library modules and orchestrates a demonstration of the entire machine learning pipeline. To ensure the code runs quickly (within the time limit) and safely, we will dynamically override the `Config` class attributes to enable `DEBUG` mode (using a small subset of data), reduce the number of epochs to 1, and redirect all file outputs to a dedicated `./working/demo_execution` directory. The script will sequentially verify the data loading process, the custom neural network layer (`StabilizedGLUInteraction`), the full model architecture (`HighCapacityBiGRU`), the loss/metric calculations, and finally the training and inference loops. Assertions will be used at each step to strictly validate shapes, types, and logical correctness.
