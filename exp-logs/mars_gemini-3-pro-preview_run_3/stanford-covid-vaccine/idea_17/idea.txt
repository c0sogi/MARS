# Proposed Strategy: Deep Iterative Structural-Refinement BiGRU (DISR-BiGRU)

This strategy synthesizes the "Interleaved Structural Interaction" concept (Idea 16) with the critical stability and evaluation protocols identified in the most recent lessons. It addresses the core conflict between the need for 3D structural context and the danger of hard-coding noisy predictions by using a **multi-stage iterative refinement** architecture. This is coupled with a rigorous "Full-Spectrum" training regime and "Global Metric" evaluation to prevent the silent failures and optimistic biases observed in previous runs.

### Model

The architecture is a **Deep Stacked BiGRU with Gated Structural Skip-Connections**. It processes the sequence iteratively, using the context learned in previous layers to dynamically validate and integrate structural dependencies.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings, as they add parameters without benefit in this low-data regime. **Cite solution_lesson_node_00009**.
    *   **Purity:** We do **not** concatenate paired features at the input stage. This ensures the initial local feature extraction is not corrupted by potentially noisy structural predictions. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem (Local Feature Extraction):**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** This projects the sparse inputs into a dense embedding space and aggregates immediate local context (k-mers) to initialize the recurrent backbone effectively. **Cite solution_lesson_node_00027**.

3.  **Iterative Refinement Backbone:**
    *   The backbone consists of **3 Blocks**, where Blocks 1 and 2 are followed by a **Structural Interaction Module**.
    *   **BiGRU Blocks:** High-capacity Bidirectional GRU layers (Hidden Dimension = 384). We prioritize BiGRUs over Transformers for their superior inductive bias on short sequences. **Cite solution_lesson_node_00017**. We maximize width/depth over complex sub-architectures like Inception. **Cite solution_lesson_node_00026** and **Cite solution_lesson_node_00040**.
    *   **Structural Interaction Module (The Innovation):**
        *   **Input:** The hidden states $H^{(l)}$ from the previous BiGRU block.
        *   **Gather:** For every position $i$, identify its paired index $j$ from the provided structure. Retrieve vector $h_j$.
        *   **Gating:** Compute a trust gate $z_{ij} = \sigma(W_{gate} \cdot [h_i; h_j])$, where $\sigma$ is the Sigmoid function. This allows the model to use the sequence context learned so far to decide if the structural connection is physically valid (e.g., suppressing G-A pairs or likely prediction errors).
        *   **Injection:** Update the state: $h'_i = h_i + z_{ij} \odot (W_{proj} \cdot h_j)$.
        *   **Benefit:** This "linearizes" the graph structure **Cite solution_lesson_node_00033** in a safe, latent manner. By placing this *after* a BiGRU pass, the gating mechanism is informed by the full sequence context, making it robust to noise in the provided structure. **Cite solution_lesson_node_00037**.

4.  **Output Head:**
    *   A final Linear layer projects the output of the last BiGRU block to the 5 target values.

### Data

1.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject filtering strategies, as training on the full noisy distribution is required to generalize to the noisy public test set and avoid distribution shift. **Cite solution_lesson_node_00015** and **Cite solution_lesson_node_00013**.

2.  **Robust Pipeline:**
    *   We will implement **hash-based caching** for the preprocessed data (e.g., `train_data_{hash(config)}.npy`). This ensures that the specific graph-processing logic required for the interaction modules is correctly executed and versioned. **Cite solution_lesson_node_00011**.

### Training

1.  **Objective (Unweighted Loss):**
    *   We will optimize the standard **MCRMSE** on all 5 target columns. We will **not** use inverse-variance weighting, as down-weighting noisy samples degrades performance on the unweighted competition metric. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. This is critical for convergence to a deep minimum. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** We will explicitly apply **Gradient Clipping** (max norm 1.0) to the training loop. This is **mandatory** to stabilize the deep, hybrid recurrent architecture and prevent the exploding gradients that caused previous hybrid attempts to fail. **Cite solution_lesson_node_00046**.
    *   **Regularization:** Dropout will be applied after the Convolutional Stem and within the Structural Interaction Modules.

### Evaluation

1.  **Global Metric Aggregation:**
    *   We will implement a **Global Evaluation Loop** that concatenates predictions and targets for the entire validation set *before* calculating the MCRMSE. We will **not** average batch-wise RMSEs, as this produces optimistically biased results. **Cite solution_lesson_node_00045**.

2.  **Targeted Validation:**
    *   We will calculate the validation metric specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to ensure alignment with the competition leaderboard. **Cite solution_lesson_node_00017**.

3.  **Inference:**
    *   The test set sequences will be processed through the Stem and the Iterative Backbone.
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) for submission.
