This script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` class to use a small subset of data and fewer epochs for a rapid demonstration.
2.  **Data Loading Verification**: Uses `get_dataloaders` to load the dataset and verifies the structure and shapes of the batches (features, masks, targets).
3.  **Model Initialization & Forward Pass**: Instantiates the `HC_WG_BiGRU` model and performs a forward pass with a single batch to verify output shapes and value integrity (finite checks).
4.  **Loss Calculation**: Computes the MCRMSE loss to ensure the criterion functions correctly.
5.  **Full Training Pipeline**: Executes `run_training()` to simulate a complete training run, including validation and model saving.
6.  **Submission Verification**: Validates the format and content of the generated submission CSV file.
