# Proposed Strategy: High-Capacity BiGRU with Deep Residual Stem and Stabilized GLU-Interaction

This strategy introduces a **Deep Residual Convolutional Stem** feeding into a **High-Capacity 4-Layer Bidirectional GRU**. The recurrent backbone is interleaved with **Stabilized GLU-Decoupled Structural Injection** modules. This architecture maximizes representational power at both local (CNN) and global (RNN/Graph) scales while ensuring optimization stability.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Deep Residual Convolutional Stem (Structural Innovation):**
    *   Instead of a single projection layer, we use a **3-Layer Residual 1D-CNN**.
    *   **Structure:** `Conv1D(k=3) -> ResBlock(k=5) -> ResBlock(k=3)`.
    *   **Capacity:** Projects inputs to the backbone dimension (**768**).
    *   **Purpose:** Explicitly models local k-mer motifs and secondary structure patterns (e.g., hairpins) hierarchically *before* temporal processing. This provides the RNN with richer, context-aware token embeddings. **Cite solution_lesson_node_00027**.

3.  **High-Capacity 4-Layer Backbone:**
    *   The backbone consists of **4 Blocks** processed sequentially (Strict Hierarchy, **Cite solution_lesson_node_00127**).
    *   **BiGRU Layer:** Hidden dimension of **384** per direction (**768 Total**). We explicitly maintain this high capacity to capture complex folding landscapes. **Cite solution_lesson_node_00103** and **Cite solution_lesson_node_00063**.
    *   **Stabilized GLU-Decoupled Interaction Module:**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **GLU Message (Bias-Refined):** Use a **Gated Linear Unit** for the message: $m_{ij} = (W_c h_j + b_c) \odot \sigma(W_g h_j + b_g)$. We do **not** concatenate $h_i$ here (Decoupled). Crucially, for unpaired bases ($h_j=0$), this term becomes the learnable bias vector $b_c \odot \sigma(b_g)$, providing a highly expressive "loop embedding" for self-refinement. **Cite solution_lesson_node_00085**, **Cite solution_lesson_node_00062**, **Cite solution_lesson_node_00080**.
        *   **Wide Stabilized MLP Gate:**
            *   **Wide Projection:** $z_{raw} = W_{in} \cdot [h_i; h_j]$. Projects to full width (768) to avoid bottlenecks. **Cite solution_lesson_node_00110**. No input normalization. **Cite solution_lesson_node_00079**.
            *   **Internal Normalization:** $z_{norm} = \text{LayerNorm}(z_{raw})$. Stabilizes MLP internals. **Cite solution_lesson_node_00075**.
            *   **Activation:** $z_{act} = \text{GELU}(z_{norm})$.
            *   **No Logit Norm:** $g_{ij} = \sigma(W_{out} \cdot z_{act})$. Allows full saturation. **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. Ensures stability for the deep stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
