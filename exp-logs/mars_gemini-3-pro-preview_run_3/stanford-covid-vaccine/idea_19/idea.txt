# Proposed Strategy: Distance-Augmented Structural-Refinement BiGRU (DASR-BiGRU)

This strategy evolves the highly successful **Deep Iterative Structural-Refinement** architecture (which achieved ~0.59 MCRMSE) by integrating **Relative Distance Awareness** and **Structural Regularization**. While the previous best model successfully routed information across paired bases, it treated all connections equally regardless of genomic distance. By explicitly injecting **Relative Distance Embeddings** into the gating mechanism, we provide the model with critical physical context (e.g., distinguishing between tight hairpin loops and long-range tertiary interactions). Furthermore, we introduce **Structural Edge Dropout** to explicitly address the risk of overfitting to noisy predicted structures, a vulnerability identified in **Cite solution_lesson_node_00037**.

### Model

The architecture is a **Deep BiGRU with Distance-Aware Structural Gating**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** We do **not** concatenate paired features at the input stage, ensuring the convolutional stem extracts clean local motifs. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU) to project sparse inputs into a dense embedding space. **Cite solution_lesson_node_00027**.

3.  **Iterative Refinement Backbone:**
    *   The backbone consists of **3 Blocks**. Each block contains a **Bidirectional GRU** followed by a **Distance-Aware Interaction Module** (except the final block).
    *   **BiGRU Layer:** High-capacity Bidirectional GRU (Hidden Dimension = 384). We prioritize BiGRUs over Transformers for their superior inductive bias on short sequences. **Cite solution_lesson_node_00017**. We maximize capacity over complexity. **Cite solution_lesson_node_00026**.
    *   **Distance-Aware Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$:
        *   **Gather:** Retrieve the hidden state $h_j$ directly. We avoid windowed gathering to prevent noise injection. **Cite solution_lesson_node_00058**.
        *   **Distance Embedding:** Calculate the relative sequence distance $d = |i - j|$. Map this distance to a dense vector $e_d$ using a learnable embedding layer (or sinusoidal encoding). This explicitly encodes the "loop size," a critical determinant of RNA stability.
        *   **Distance-Gated Injection:** Compute the trust gate $z_{ij} = \sigma(W_{gate} \cdot [h_i; h_j; e_d])$. By conditioning the gate on $e_d$, the model can learn physical priors (e.g., "short loops are rigid, long loops are flexible") to modulate the information flow.
        *   **Update:** $h'_i = h_i + z_{ij} \odot (W_{proj} \cdot h_j)$.
        *   **Benefit:** This maintains the explicit routing of **Cite solution_lesson_node_00057** but enriches the decision boundary with physical distance constraints.

4.  **Output Head:**
    *   A final Linear layer projects the output of the last BiGRU block to the 5 target values.

### Data

1.  **Preprocessing:**
    *   We will parse the structures to generate adjacency maps and pre-calculate the **relative distance matrix** for paired bases.
    *   **Caching:** We will use **hash-based caching** to ensure the new distance features are correctly generated and versioned. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios. We explicitly reject filtering to avoid distribution shift. **Cite solution_lesson_node_00015**.

### Training

1.  **Structural Regularization (Edge Dropout):**
    *   During training, we apply **Structural Edge Dropout**. With a probability $p$ (e.g., 0.15), we randomly mask out structural connections (setting $h_j$ to zero or preventing the update) in the Interaction Module.
    *   **Purpose:** This forces the model to remain robust even when the predicted structure is incorrect or missing, directly mitigating the noise sensitivity warning in **Cite solution_lesson_node_00037**.

2.  **Objective (Unweighted Loss):**
    *   We optimize the standard **MCRMSE** on all 5 target columns. We avoid inverse-variance weighting to align with the competition metric. **Cite solution_lesson_node_00034**.

3.  **Optimizer & Stability:**
    *   **AdamW** with **Cosine Annealing**. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping** (max norm 1.0) is mandatory to stabilize the deep hybrid architecture. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Global Metric Aggregation:**
    *   We will concatenate predictions for the entire validation set before calculating MCRMSE to avoid batch-averaging bias. **Cite solution_lesson_node_00045**.

2.  **Inference:**
    *   The test set sequences will be processed through the Stem and the Distance-Aware Backbone (with Edge Dropout disabled).
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) for submission.
