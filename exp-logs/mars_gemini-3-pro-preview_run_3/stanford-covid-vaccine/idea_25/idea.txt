# Proposed Strategy: Deep Pre-Norm BiGRU with Zero-Masked Structural Channel-Gating

This strategy represents the "Stabilized Deep Evolution" of the best-performing concepts. It integrates the **Zero-Masked Channel-Gating** (proven superior in Idea 24) into a **Deeper (4-Layer) Backbone**, stabilized by a **Pre-LayerNorm** configuration. This addresses the capacity limitations of shallower models while mitigating the optimization instability observed in previous deep attempts (Lesson 46, Lesson 63) and correcting the metric evaluation flaws (Lesson 66).

### Model

The architecture is a **4-Layer Bidirectional GRU with Interleaved Pre-Norm Structural Injection**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** We do **not** concatenate paired features at the input stage. This ensures the convolutional stem extracts clean local motifs without interference from noisy structural predictions. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers to initialize the backbone. **Cite solution_lesson_node_00027**.

3.  **Deep Refinement Backbone:**
    *   The backbone consists of **4 Blocks** (increased from 3 to maximize capacity within safe limits, addressing **Cite solution_lesson_node_00026**). Each block contains a **Bidirectional GRU** followed by a **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** We employ a **Bidirectional GRU** with a hidden dimension of **384**. We strictly adhere to this width, as it offers the optimal balance between capacity and trainability. **Cite solution_lesson_node_00063**. We prioritize BiGRUs over Transformers for their superior inductive bias. **Cite solution_lesson_node_00017**.
    *   **Pre-Norm Structural Interaction Module (Structural Innovation):**
        *   **Pre-Normalization:** We apply Layer Normalization to the input *before* the interaction logic: $h_{norm} = \text{LN}(h_{in})$. This stabilizes the gradients in the deeper 4-layer stack, preventing the explosions seen in previous deep attempts. **Cite solution_lesson_node_00046**.
        *   **Gather:** Retrieve the normalized hidden state vector $h_{norm, j}$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Zero-Masking:** If position $i$ is **unpaired**, we explicitly force $h_{norm, j}$ to be a **zero vector**. We strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **Non-Linear Message:** Transform the neighbor state via a dense layer with activation: $m_{ij} = \text{GELU}(W_{msg} \cdot h_{norm, j})$. This ensures expressivity. **Cite solution_lesson_node_00062**.
        *   **Channel-Wise Gating:** Compute a feature-vector gate $g_{ij} \in \mathbb{R}^{384}$ via a projection: $g_{ij} = \sigma(W_{gate} \cdot [h_{norm, i}; h_{norm, j}])$. This outperforms attention for fixed edges. **Cite solution_lesson_node_00065**.
        *   **Residual Injection:** Update the state: $h_{out} = h_{in} + g_{ij} \odot m_{ij}$.

4.  **Output Head:**
    *   A final Linear layer projects the output of the last BiGRU block to the 5 target values.

### Data

1.  **Preprocessing:**
    *   Generate adjacency maps for the gather operations based on the provided secondary structures.
    *   **Caching:** Use **hash-based caching** (e.g., `train_data_{hash(config)}.npy`) to ensure pipeline integrity. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   Train on the **entire training dataset**, including samples with low signal-to-noise ratios. We explicitly reject filtering to avoid distribution shift. **Cite solution_lesson_node_00015**.

### Training

1.  **Objective (Unweighted Loss):**
    *   Optimize the standard **MCRMSE** on all 5 target columns. We do **not** use inverse-variance weighting. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** Explicitly apply **Gradient Clipping** (max norm 1.0). This is **mandatory** to stabilize the deep hybrid architecture. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Correct Metric Calculation:**
    *   **Slicing:** Before calculating the metric, explicitly **slice** the prediction and target tensors to the first 68 positions (`seq_scored`). Do *not* average over the padded length. **Cite solution_lesson_node_00066**.
    *   **Global Aggregation:** Concatenate these sliced tensors for the entire validation set *before* calculating the MCRMSE to avoid batch-averaging bias. **Cite solution_lesson_node_00045**.

2.  **Inference:**
    *   Process test sequences through the Stem and Deep Backbone.
    *   Generate predictions for all 107 positions, then slice to the first 68 positions (`seq_scored`) for submission.
