This script demonstrates the usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Configuration**: Overrides default hyperparameters (epochs, batch size) and paths to ensure a fast, self-contained run within the `./working/demo_execution` directory.
2.  **Data Loading**: Uses `get_dataloaders` with `debug=True` to load a small subset of the training, validation, and test data. It verifies the shape of the input tensors and the application of the masking strategy in the training set.
3.  **Model Initialization**: Instantiates the `MaskedBiGRU` model and performs a dummy forward pass to verify output shapes for both the regression and reconstruction heads.
4.  **Training**: Executes the training loop using `run_training` for a few epochs, validating the loss reduction and model checkpointing.
5.  **Inference & Submission**: Loads the best saved model, generates predictions for the test set, and formats them into the required submission CSV format, verifying the structure against the sample submission.
