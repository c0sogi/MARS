The implementation strategy involves the following steps:

1.  **Environment Configuration**: We append the current directory to the system path to ensure the provided `library` modules can be imported correctly.
2.  **Hyperparameter Optimization**: We monkey-patch the `Config` class to use a lightweight configuration (reduced hidden dimensions, fewer filters, smaller batch size, and only 2 epochs). This ensures the code runs quickly within the demonstration constraints while still exercising all logic paths.
3.  **Data Loading & Verification**: We use `get_dataloaders` with `load_cached_data=False` to trigger the raw data processing pipeline from the provided Parquet metadata. We then explicitly verify the structure, keys, and shapes of the resulting data batches.
4.  **Model Execution**: We instantiate the `RNAModel`, perform a dummy forward pass to verify output tensor shapes, and then execute a short training loop using `train_fn` and `eval_fn`.
5.  **Inference & Submission**: We run inference on the test set, map the resulting tensor predictions back to the specific `id_seqpos` format required by the competition, and save the result as a CSV file.
