The following changes address the `InvalidMetricValueError` and the execution anomaly identified in the error analysis:

1.  **Remove Import Side-Effect (`library/config.py`)**: The `library/config.py` file incorrectly triggers a full training run (`run_pipeline()`) at the global scope. This causes a "ghost" training session to execute immediately upon importing the `Config` class. I will remove this function call to prevent the unintended execution.
2.  **Correct Metric Calculation (`library/train.py`)**: The `validate` function incorrectly computes MCRMSE by calculating the RMSE for each sequence position independently and then averaging them. This approach mathematically underestimates the error due to Jensen's Inequality. I will modify the function to flatten the batch and sequence dimensions (`N * L`) before computing the Mean Squared Error, ensuring the metric aggregates error over the entire column as required (Cite debug_lesson_1).
