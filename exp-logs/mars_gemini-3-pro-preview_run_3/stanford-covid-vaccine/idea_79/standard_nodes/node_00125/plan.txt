The following script implements the end-to-end pipeline for the RNA degradation prediction task. It orchestrates data loading, model training (using the `DeepResGLUBiGRU` architecture), validation, failure analysis, and submission generation.

**Strategy Outline:**
1.  **Configuration Override**: Adjusts `Config.EPOCHS` to 15 to ensure the "fast baseline" requirement is met while maintaining sufficient convergence for the deep model.
2.  **Training**: Initializes the `DeepResGLUBiGRU` model and `Trainer`, then executes the training loop. The best model based on validation MCRMSE is saved automatically.
3.  **Validation & Metric**: Reloads the best model checkpoint and performs a full inference pass on the validation set to compute the `Final Validation Metric` with full precision.
4.  **Failure Analysis**: Computes the sample-wise Root Mean Squared Error (RMSE) on the validation set. It then loads metadata to correlate this error with `signal_to_noise` and nucleotide content (`pct_A`, `pct_G`, etc.) to identify systematic failure modes.
5.  **Submission**: Checks if the validation metric is below the specified threshold (0.5884495377540588). If successful, it generates predictions for the test set, formats them into the required `id_seqpos` structure, and saves the file to `./submission/submission.csv`.
