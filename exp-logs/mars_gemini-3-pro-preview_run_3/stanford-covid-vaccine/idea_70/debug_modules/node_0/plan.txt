This script demonstrates the complete workflow for the RNA degradation prediction task using the provided library. It performs the following steps:

1.  **Configuration Override**: It modifies the `Config` class at runtime to establish a "Debug Mode". This involves setting a separate working directory (`./working/demo_run`), enabling the debug flag to process only 50 samples, and reducing model hyperparameters (layers, hidden dimensions) to ensure the script executes in seconds.
2.  **Data Verification**: It calls `data.get_loaders` to generate and load the dataset caches. It asserts that the shapes of the features, adjacency masks, and targets in the first batch match the expected dimensions `(Batch, 107, 14)` and `(Batch, 68, 5)`.
3.  **Model Verification**: It instantiates the `RNAModel` with the reduced configuration, performs a forward pass on the GPU (if available), and verifies that the output shape covers the full sequence length `(Batch, 107, 5)`.
4.  **Loss Verification**: It computes the `MCRMSELoss` on the dummy batch to ensure the objective function is valid and returns a non-negative scalar.
5.  **Pipeline Execution**: It executes `engine.run_training()`, which runs the full training loop (train, validation, scheduler) for 2 epochs and generates predictions on the test set.
6.  **Submission Check**: Finally, it loads the generated `submission_demo.csv`, validates its dimensions against the expected count (50 samples * 107 positions), and checks for data integrity.
