# Proposed Strategy: High-Capacity GLU-Decoupled BiGRU with Deep Stabilized Gating

This strategy introduces a **4-Layer Bidirectional GRU** with a **High-Capacity Hidden Dimension** (384 per direction, 768 total). It interleaves this backbone with a **GLU-Decoupled Structural Injection** module. This module replaces the simple GELU message with a **Gated Linear Unit**, providing a richer, self-modulated signal from neighbors, and controls injection via a **2-Layer Stabilized MLP Gate** to capture complex compatibility rules.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers. **Cite solution_lesson_node_00027**.

3.  **High-Capacity 4-Layer Backbone:**
    *   The backbone consists of **4 Blocks** (maximizing capacity, addressing **Cite solution_lesson_node_00026**). Each block contains a **Bidirectional GRU** followed by the **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** Hidden dimension of **384** (Total 768). We explicitly maintain this high capacity, as narrowing the backbone caused severe degradation in previous stabilized attempts. **Cite solution_lesson_node_00103** and **Cite solution_lesson_node_00063**.
    *   **GLU-Decoupled Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **GLU Message (Bias-Refined):** Instead of a simple projection, we use a Gated Linear Unit for the message: $m_{ij} = (W_c h_j + b_c) \odot \sigma(W_g h_j + b_g)$. This allows the neighbor to self-modulate its signal before injection. Crucially, for unpaired bases ($h_j=0$), this becomes a learnable bias vector $b_c \odot \sigma(b_g)$, enabling **Bias-Driven Loop Refinement**. **Cite solution_lesson_node_00085** and **Cite solution_lesson_node_00080**.
        *   **Deep Stabilized MLP Gate:**
            *   **Structure:** A 2-layer MLP to learn complex filtering logic. Input $[h_i; h_j]$.
            *   **Hidden Layer:** $z = \text{GELU}(\text{LayerNorm}(W_1 \cdot [h_i; h_j]))$. The internal LayerNorm stabilizes the deep gate. **Cite solution_lesson_node_00075**.
            *   **Output:** $g_{ij} = \sigma(W_2 \cdot z)$. We do **not** normalize the output logits, allowing full saturation. **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. Ensures stability for the deep 4-layer stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
