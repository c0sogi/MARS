This script implements the full pipeline for the RNA Degradation Prediction task using the **Deep Stabilized Bias-Refined Decoupled BiGRU** strategy.

**Strategy Outline:**
1.  **Configuration & Setup:** Overrides default configuration to establish a "fast baseline" by setting `NUM_EPOCHS` to 15, ensuring the training completes quickly while leveraging the full dataset (1,728 samples) to maximize performance.
2.  **Training Orchestration:** Executes the training loop via `library.train.run_training()`, which handles data loading, model initialization, optimization (AdamW + Cosine Annealing), and saving the best model based on validation MCRMSE.
3.  **Validation & Metric Calculation:** Loads the best model state and performs inference on the hold-out validation set. It computes the official MCRMSE metric using `library.utils.compute_mcrmse`, ensuring correct slicing (first 68 positions) and column filtering (reactivity, deg_Mg_pH10, deg_Mg_50C).
4.  **Failure Analysis:** Correlates the per-sample RMSE with metadata features (Signal-to-Noise Ratio, SN Filter, Nucleotide Content) to identify systematic error sources.
5.  **Submission Generation:** If the validation metric meets the threshold (< 0.5884), it generates predictions for the test set. The output is formatted into the required `id_seqpos` structure (240 samples × 107 positions = 25,680 rows) and saved to `submission.csv`.
