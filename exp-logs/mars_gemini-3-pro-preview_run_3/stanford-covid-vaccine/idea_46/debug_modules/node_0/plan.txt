This script demonstrates the end-to-end usage of the provided RNA Degradation Prediction library. It performs the following steps:
1.  **Configuration**: Overrides default configuration settings to run in a fast "debug" mode (small subset, few epochs).
2.  **Data Loading**: Uses `get_dataloaders` to load processed features and targets, verifying tensor shapes and data integrity.
3.  **Model Initialization**: Instantiates the `DeepStabilizedBiGRU` model and verifies the forward pass output dimensions.
4.  **Training & Validation**: Runs a single epoch of training and a validation pass using `train_one_epoch` and `validate`, asserting that loss and scores are calculated correctly.
5.  **Inference & Submission**: Generates predictions on the test set and constructs a submission file in the required format, verifying row counts and column structures.
