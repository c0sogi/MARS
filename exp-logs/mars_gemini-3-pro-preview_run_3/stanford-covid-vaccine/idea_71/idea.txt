# Proposed Strategy: High-Capacity FFN-Augmented Decoupled BiGRU

This strategy introduces a **4-Layer Bidirectional GRU** interleaved with **Decoupled GLU-Structural Injection** modules and **Pointwise Feed-Forward Networks**. This "Sandwich" block structure (BiGRU $\to$ Structural Injection $\to$ FFN) allows the model to sequentially process context, spatially integrate structural constraints, and then deeply refine the fused features via the FFN before passing them to the next layer.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers. **Cite solution_lesson_node_00027**.

3.  **High-Capacity Augmented Backbone:**
    *   The backbone consists of **4 Blocks**. Each block contains three sub-modules:
    *   **A. BiGRU Layer:** Hidden dimension of **384** (Total 768). We maintain this high capacity to capture complex sequential dependencies. **Cite solution_lesson_node_00103** and **Cite solution_lesson_node_00063**.
    *   **B. Decoupled GLU-Structural Module:**
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, force $h_j = 0$. **Cite solution_lesson_node_00064**.
        *   **GLU Message (Bias-Refined):** $m_{ij} = \text{Linear}(h_j) \odot \sigma(\text{Linear}(h_j))$. For unpaired bases ($h_j=0$), this relies on learned biases to provide a "loop embedding" for self-refinement. **Cite solution_lesson_node_00085** and **Cite solution_lesson_node_00062**.
        *   **Full-Rank Stabilized Gate:** A 2-layer MLP with **Internal LayerNorm** (to prevent saturation) but **No Logit Norm** (to allow switching). It projects to the full hidden dimension (768) to avoid bottlenecks. **Cite solution_lesson_node_00075**, **Cite solution_lesson_node_00078**, **Cite solution_lesson_node_00110**.
        *   **Injection:** $h_{struct} = \text{LayerNorm}(h_{in} + g_{ij} \odot m_{ij})$. **Cite solution_lesson_node_00068**.
    *   **C. Pointwise Feed-Forward Network (FFN):**
        *   **Structure:** `Linear -> GELU -> Dropout -> Linear`.
        *   **Purpose:** Adds non-linear processing capacity to "digest" the structural update before the next recurrent step, effectively deepening the network without adding time-steps.
        *   **Residual:** $h_{out} = \text{LayerNorm}(h_{struct} + \text{FFN}(h_{struct}))$.

4.  **Output Head:**
    *   Linear projection to 5 target values.
