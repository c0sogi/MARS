### Implementation Strategy

1.  **Setup & Configuration**: Initialize the `Config` object, overriding the epoch count to 15 to ensure the "Fast Baseline" requirement is met within the time limit. Set random seeds for reproducibility.
2.  **Data Loading**: Use the provided `get_dataset` factory to load training and validation data. Create PyTorch `DataLoader` instances with appropriate batch sizes and worker counts.
3.  **Model Training**: Instantiate the `DeepDecoupledBiGRU` model and the `Trainer`. Execute the training loop using `trainer.fit()`. The trainer handles optimization, gradient clipping, and early stopping.
4.  **Validation & Metric**: Load the best model checkpoint saved by the trainer. Perform inference on the full validation set to compute the `Final Validation Metric` (MCRMSE). Print this metric in the required format.
5.  **Failure Analysis**:
    *   Calculate sample-wise error magnitudes (MCRMSE per sample).
    *   Load validation metadata (from `val.parquet`) to retrieve auxiliary features like `signal_to_noise` and `SN_filter`.
    *   Compute sequence composition features (e.g., percentage of G/C content).
    *   Calculate and print Pearson correlations between the error magnitude and these features to identify failure modes.
6.  **Submission Generation**:
    *   Check if the validation metric is below the threshold (0.5978901386).
    *   If successful, load the test dataset and generate predictions for all 107 positions.
    *   Format the output into the required `id_seqpos` structure and save it to `submission.csv`.
