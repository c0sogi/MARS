The implementation strategy involves creating a main execution script `runfile.py` that orchestrates the machine learning pipeline using the provided library modules.

**Strategy Outline:**
1.  **Setup & Configuration**: Import necessary libraries and the provided `library` modules. modify `Config.EPOCHS` to a lower value (10) to satisfy the "fast baseline" requirement while ensuring convergence. Set random seeds for reproducibility.
2.  **Data Loading**: Use `library.data.preprocess_data` with `load_cached_data=True` to efficiently load the training, validation, and test DataLoaders.
3.  **Model Initialization**: Instantiate the `GatedFunnelNetwork` and move it to the configured device (GPU).
4.  **Training Loop**: Implement a manual training loop calling `library.train_eval.train_one_epoch` and `evaluate`. This allows for custom control over the execution flow, including early stopping and saving the best model based on Validation AUC.
5.  **Final Evaluation**: Load the best saved model state and perform a final evaluation on the full validation set to compute the required metric.
6.  **Metric Reporting**: Print the `Final Validation Metric` with full precision as required.
7.  **Failure Analysis**: Run inference on the validation set to calculate the absolute error for each sample. Compute and print the Pearson correlation between the error magnitude and each continuous input feature to identify sources of systematic error.
8.  **Conditional Submission**: Check if the final validation AUC exceeds the strict threshold (`0.9971550270448856`). If satisfied, generate the submission file using `library.train_eval.generate_submission`; otherwise, skip this step.
