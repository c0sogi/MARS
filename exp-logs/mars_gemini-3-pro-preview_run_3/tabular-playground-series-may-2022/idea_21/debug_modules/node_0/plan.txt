This script demonstrates the end-to-end usage of the provided Regularization-Spectrum Parallel Funnel Ensemble (RSPFE) library. It overrides the default configuration to run in a fast "Debug Mode" using a small subset of data. It verifies the data processing pipeline, the model architecture (specifically the multi-stream output), and the training loop logic using assertions. Finally, it performs a mock inference step to ensure the prediction pipeline is functional.
