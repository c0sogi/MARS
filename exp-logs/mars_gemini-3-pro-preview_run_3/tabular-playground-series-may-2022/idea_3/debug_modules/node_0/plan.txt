The following implementation demonstrates the end-to-end usage of the provided library files (`config.py`, `utils.py`, `data.py`, `model.py`, `train.py`).

### Strategy
1.  **Configuration Override**: To ensure the script runs quickly (within seconds/minutes), we override the default `Config` parameters. We set `PRETRAIN_EPOCHS` and `FINETUNE_EPOCHS` to 1 and reduce the `BATCH_SIZE`.
2.  **Data Subsetting**: Instead of processing the full 640k+ rows, we create temporary "mini-datasets" (1000 rows each) in the working directory by reading the head of the provided metadata files. We then point the `Config` paths to these subset files.
3.  **Component Verification**:
    *   **Data Processing**: We call `preprocess_features` and assert the shape and structure of the returned dictionaries.
    *   **Dataset Class**: We instantiate `ManufacturingDataset` in both 'supervised' and 'pretrain' modes to verify the `__getitem__` logic and shape consistency.
    *   **Models**: We instantiate the `DenoisingAutoencoder` and `ManufacturingClassifier`, passing dummy tensors to verify forward pass mechanics and output shapes.
4.  **Pipeline Execution**: We run the full training pipeline functions (`pretrain_dae`, `train_classifier`, `generate_submission`) on the mini-dataset and assert that the expected artifacts (model checkpoints, submission CSV) are created.
