Implementation strategy:
1.  **Environment Setup**: Initialize the environment by setting random seeds and detecting the compute device (GPU/CPU) using the provided utility functions.
2.  **Data Pipeline**: Trigger the data processing pipeline to load, engineer, and normalize the dataset. This utilizes the caching mechanism to save time if processed data already exists.
3.  **Model Instantiation**: Initialize the `MORPE` ensemble model. This involves creating 5 parallel streams with distinct architectures and embedding layers as defined in the configuration.
4.  **Optimizer Configuration**: Manually construct the optimizer parameter groups. This is a critical step where we iterate through the model's streams and assign the specific Weight Decay values (heterogeneous regularization) defined in `Config.STREAMS` to the corresponding parameters.
5.  **Training Loop**: Execute a training loop for a fixed number of epochs (optimized for the time limit). Within each epoch, perform a training pass and a validation pass. Track the best validation AUC and store the corresponding model state.
6.  **Failure Analysis**: After training, load the best model state. Compute predictions on the validation set and calculate the absolute error for each sample. Perform a correlation analysis between the error magnitude and all input features to identify which features are most associated with prediction errors.
7.  **Submission Logic**: Compare the best validation AUC against the strict threshold provided in the requirements. If the threshold is met, generate predictions for the test set and save the submission file.
