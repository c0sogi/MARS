# Proposed Strategy: Interaction-Augmented Parallel Ensemble (IAPE)

## Model
We will implement an **Interaction-Augmented Parallel Ensemble (IAPE)**. This architecture represents a structural evolution of the "Residual-Parallel" concept. It addresses the failure of the naive Wide-and-Deep approach (Cite solution_lesson_node_00087) by replacing the raw linear skip connection with an **Explicit Interaction Wide Path**, while retaining the proven **Parallel Independent Funnel** backbone.

1.  **Parallel Independent Architecture:**
    *   The model will consist of **5 independent streams** instantiated within a single computational graph (Cite solution_lesson_node_00064).
    *   **Independent Representation:** Each stream will possess its own **independent Entity Embedding layers** (dim=16) for the categorical features. We explicitly reject shared embeddings to ensure decorrelated representation learning (Cite solution_lesson_node_00065).

2.  **Stream Topology (The Innovation):**
    *   Each stream will implement a modified **Wide-and-Deep** structure designed to capture second-order interactions explicitly:
        *   **Deep Path (The Funnel):** The fused input (concatenated embeddings + continuous features) is processed by a **Funnel MLP** (512 $\to$ 256 $\to$ 128). This preserves the compressive inductive bias (Cite solution_lesson_node_00004).
        *   **Wide Path (The Interaction):** Instead of passing raw features to the linear skip (which failed to capture dependencies, Cite solution_lesson_node_00087), we construct an **Interaction Vector**.
            *   *Mechanism:* For the 10 character embeddings of `f_27`, we compute the **pairwise dot-products** between all unique pairs ($e_i \cdot e_j$).
            *   *Input:* This vector of scalar interactions is concatenated with the normalized continuous features and projected via a single **Linear Layer** to the output.
            *   *Rationale:* This explicitly models the "cross-product" features required for a successful Wide component (Cite solution_lesson_node_00087) using the dense learned embeddings, avoiding the sparsity/noise of N-gram tokens (Cite solution_lesson_node_00035).
        *   **Aggregation:** The final logit is the sum of the Deep Path output and the Wide Path output.

3.  **Heterogeneous Configuration:**
    *   We employ **Regularization Heterogeneity** (Cite solution_lesson_node_00069) to maximize ensemble diversity.
    *   **Streams 1 & 2 (Anchors):** Standard Funnel, Dropout **0.20**.
    *   **Stream 3 (Capacity Variant):** **Wide Funnel** (1024 $\to$ 512 $\to$ 256), Dropout **0.25** (Cite solution_lesson_node_00066).
    *   **Stream 4 (Safe-Aggressive):** Standard Funnel, Dropout **0.15**. We respect the safety floor to prevent overfitting (Cite solution_lesson_node_00077).
    *   **Stream 5 (Conservative):** Standard Funnel, Dropout **0.30**.

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets** (Cite solution_lesson_node_00021).
2.  **Feature Engineering:**
    *   **String Decomposition:** Decompose `f_27` into 10 fixed-position character columns (Cite solution_lesson_node_00001).
    *   **Discrete Features:** Treat `f_29` and `f_30` as categorical variables (Cite solution_lesson_node_00008).
    *   **Aggregate Signal:** Compute and append `unique_character_count` of `f_27` (Cite solution_lesson_node_00002).
3.  **Normalization:** Scale all continuous features using **StandardScaler**.
4.  **Data Volume:** Utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is calibrated to facilitate super-convergence while respecting the sensitivities of AdamW:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-4**. We use `1e-4` to account for AdamW's decoupled implementation (Cite solution_lesson_node_00063) while avoiding the aggressive `1e-2` (Cite solution_lesson_node_00023).
2.  **Scheduler:** **One-Cycle Learning Rate Policy** with `max_lr=1e-2`. We explicitly maintain the high learning rate magnitude to ensure the model can escape local minima (Cite solution_lesson_node_00072).
3.  **Loss Function:** The training objective is the **sum of Binary Cross-Entropy losses** calculated independently for each of the 5 streams.
4.  **Batch Size:** **1024** (Cite solution_lesson_node_00024).
5.  **Duration:** Train for **50 Epochs**. We explicitly avoid premature truncation to allow the highly regularized streams to fully converge (Cite solution_lesson_node_00080).

## Evaluation
1.  **Preprocessing:** Apply the global (transductive) vocabulary mappings and training set scalers to the test set.
2.  **Inference:** The IAPE model will generate 5 independent probability predictions per sample.
3.  **Submission:** The final prediction will be the **arithmetic mean** of these 5 probabilities.
