# Proposed Strategy: Structurally Diverse Parallel Ensemble (SDPE)

## Model
We will implement a **Structurally Diverse Parallel Ensemble (SDPE)**. This architecture evolves the "Heterogeneous Parallel Funnel Ensemble" (Cite solution_lesson_node_00066) by expanding the definition of "heterogeneity" beyond simple width/dropout variations. We will introduce **architectural diversity** by incorporating different activation functions and block structures (Standard vs. Gated) across the independent streams. This maximizes the decorrelation of errors between ensemble members, which is the primary driver of ensemble performance.

1.  **Parallel Backbone Structure:** The model will consist of **5 independent streams** trained simultaneously within a single computational graph (Cite solution_lesson_node_00064).
    *   **Input Stage:** Each stream possesses its own **independent Entity Embedding layers** to ensure diverse feature representation learning (Cite solution_lesson_node_00065).
    *   **Categorical Inputs:** The 10 decomposed character positions of `f_27` (Cite solution_lesson_node_00001) and discrete features `f_29`, `f_30` (Cite solution_lesson_node_00008).
    *   **Capacity:** Embedding dimension set to **16** for all categorical variables (Cite solution_lesson_node_00027).
    *   **Fusion:** **Early Fusion** (concatenation) of flattened embeddings and normalized continuous features (Cite solution_lesson_node_00029).

2.  **Diverse Streams:**
    *   **Streams 1 & 2 (The Anchors):** Standard **Funnel MLP** (512 $\to$ 256 $\to$ 128) with **ReLU** activation and **Dropout 0.20**. These retain the proven optimal backbone (Cite solution_lesson_node_00004).
    *   **Stream 3 (Smooth Manifold):** **Wide Funnel MLP** (1024 $\to$ 512 $\to$ 256) with **SiLU (Swish)** activation and **Dropout 0.20**. While Swish failed as a standalone replacement (Cite solution_lesson_node_00047), its non-monotonic, smooth nature provides a distinct inductive bias compared to ReLU, capturing different continuous signal patterns.
    *   **Stream 4 (Feature Selection):** **Gated Linear Unit (GLU) Network** (512 $\to$ 256 $\to$ 128) with **Dropout 0.30**. This stream uses GLU blocks to perform dynamic feature selection. We apply higher dropout to counteract the overfitting tendency identified in previous GLU experiments (Cite solution_lesson_node_00019).
    *   **Stream 5 (Deep & Robust):** **Deep Funnel MLP** (512 $\to$ 512 $\to$ 256 $\to$ 128) with **ReLU** and **Dropout 0.25**. This stream adds depth without narrowing the bottleneck (Cite solution_lesson_node_00020), allowing for higher-order interaction modeling.

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures every unique token in the test set has a distinct embedding index, preventing signal loss (Cite solution_lesson_node_00021).
2.  **String Decomposition:** `f_27` will be split into 10 fixed-position character columns (Cite solution_lesson_node_00001).
3.  **Feature Engineering:** Compute and append `unique_character_count` of `f_27` (Cite solution_lesson_node_00002).
4.  **Normalization:** StandardScaler for all continuous features.
5.  **Data Volume:** Utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is calibrated to balance stability with super-convergence, addressing previous optimizer pitfalls:

1.  **Optimizer:** **Adam** (Standard) with Weight Decay **1e-5**. We explicitly use standard Adam because `AdamW` with this decay value led to overfitting, and `AdamW` requires complex recalibration (Cite solution_lesson_node_00063).
2.  **Loss Function:** Sum of Binary Cross-Entropy losses from all 5 streams.
3.  **Scheduler:** **One-Cycle Learning Rate Policy** to facilitate super-convergence (Cite solution_lesson_node_00002).
4.  **Batch Size:** **1024**. We leverage the implicit regularization of moderate batch sizes (Cite solution_lesson_node_00024).
5.  **Strategy:** Direct Supervised Learning (Cite solution_lesson_node_00013).

## Evaluation
1.  **Preprocessing:** Apply global vocabulary mappings and training set scalers to the test set.
2.  **Inference:** The SDPE model will output 5 probability predictions per sample (one from each structurally diverse stream).
3.  **Submission:** The final prediction will be the **arithmetic mean** of the 5 probabilities.
