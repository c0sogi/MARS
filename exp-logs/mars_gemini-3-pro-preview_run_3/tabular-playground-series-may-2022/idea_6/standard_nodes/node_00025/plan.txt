The following implementation orchestrates the full machine learning pipeline using the provided library modules. It sets up the environment, processes the data with caching enabled, and initializes the Hybrid Transformer-Funnel model. To ensure a fast baseline execution as requested, the training data is subsampled to 100,000 instances and training is limited to 5 epochs. The script performs training, evaluates the model on the full validation set, reports the metric in the specified format, conducts a failure analysis by correlating errors with features, and generates a submission file if the performance threshold is met.
