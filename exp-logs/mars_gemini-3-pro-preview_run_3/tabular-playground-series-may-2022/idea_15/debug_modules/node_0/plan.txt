The implementation strategy involves creating a lightweight, end-to-end demonstration of the provided machine learning pipeline. I will then dynamically override the `Config` class attributes to point to these mini datasets, reduce the model complexity (fewer hidden layers), and lower the training epochs and batch size. The script will then systematically execute and verify the core components: `get_dataloaders` to ensure data processing works, `SwishFunnelNet` instantiation and forward pass to verify model architecture, `train_model` to verify the training loop and checkpointing, and `generate_submission` to verify inference and output formatting.
