# Proposed Strategy: Multi-Granularity Embedding Network with Squeeze-and-Excitation

## Model
We will implement a **Multi-Granularity Embedding Network** reinforced with **Squeeze-and-Excitation (SE) blocks**. This architecture introduces two structural innovations: (1) it explicitly models local sequential dependencies in the `f_27` string through N-gram embeddings, and (2) it employs a channel-wise attention mechanism to dynamically recalibrate feature importance within the proven Funnel backbone.

1.  **Multi-Granularity Input Layer:**
    *   **Unigram Embeddings:** We will decompose `f_27` into 10 individual character positions and embed them, along with the discrete features `f_29` and `f_30`, using **Entity Embeddings of dimension 16**. This adheres to the optimal capacity findings (Cite solution_lesson_node_00027) and decomposition strategy (Cite solution_lesson_node_00001).
    *   **Bigram Embeddings (Innovation):** To capture local context without the complexity of Transformers (Cite solution_lesson_node_00025) or the noise of global feature crossing (Cite solution_lesson_node_00006), we will generate 9 sliding-window bigrams from `f_27` (e.g., chars 0-1, 1-2, etc.). These will be mapped to **Entity Embeddings of dimension 8**. This provides the model with explicit "transition" signals between machine states.
    *   **Continuous Features:** Normalized continuous features (`f_00`–`f_28` and `unique_character_count`) will be concatenated with the flattened unigram and bigram embeddings (Early Fusion, Cite solution_lesson_node_00029).

2.  **SE-Funnel Backbone:**
    *   **Architecture:** We retain the **Funnel MLP** structure (decreasing layer widths: 512 $\to$ 256 $\to$ 128) as the primary backbone, as it provides the compressive inductive bias superior to ResNets (Cite solution_lesson_node_00004).
    *   **Squeeze-and-Excitation (SE) Blocks:** After each Linear layer and before the Activation/Dropout, we will inject an **SE Block**.
        *   *Mechanism:* The block learns a weight vector $\sigma(W_2 \delta(W_1 x))$ to explicitly model inter-dependencies between the hidden units (channels). It allows the network to selectively emphasize informative features and suppress noise on a per-sample basis. This provides the "gating" benefit sought in previous GLU experiments (Cite solution_lesson_node_00019) but with significantly fewer parameters and greater stability.
    *   **Output Head:** The final 128-unit representation connects directly to the output neuron, avoiding narrow bottlenecks (Cite solution_lesson_node_00020).

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures that every unique unigram and bigram token in the test set is assigned a distinct embedding index, preventing the signal loss caused by mapping unseen test tokens to "unknown" (Cite solution_lesson_node_00021).
2.  **Feature Engineering:**
    *   Decompose `f_27` into 10 unigram columns.
    *   Generate 9 bigram columns from `f_27`.
    *   Compute `unique_character_count` of `f_27` (Cite solution_lesson_node_00002).
3.  **Normalization:** All continuous features will be scaled using **StandardScaler** based on training set statistics.
4.  **Data Volume:** We will utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is calibrated to balance the model's increased capacity with robust regularization:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-5**. We explicitly avoid the default `1e-2`, which was proven too aggressive for this tabular task (Cite solution_lesson_node_00023).
2.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise (Cite solution_lesson_node_00024).
3.  **Scheduler:** **One-Cycle Learning Rate Policy**. We retain this schedule to facilitate super-convergence and robust minima selection (Cite solution_lesson_node_00002).
4.  **Regularization:** **Dropout (0.2)** will be applied within the backbone layers.
5.  **Strategy:** Direct Supervised Learning (Cite solution_lesson_node_00013).

## Evaluation
1.  **Preprocessing:** The test set will be processed using the global (transductive) vocabulary mappings and training set scalers.
2.  **Inference:** The trained Multi-Granularity SE-Funnel model will predict probabilities for the target class `1`.
3.  **Submission:** The resulting probabilities will be formatted into the submission CSV for AUC evaluation.
