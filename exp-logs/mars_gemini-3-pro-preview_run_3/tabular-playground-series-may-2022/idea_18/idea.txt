# Proposed Strategy: Parallel Independent Funnel Ensemble (PIFE)

## Model
We will implement a **Parallel Independent Funnel Ensemble (PIFE)**. This architecture represents a structural evolution of the "Tree-Structured" concept (Idea 17). Instead of utilizing a shared trunk—which induces error correlation and creates a single point of failure—we will construct a "Forest" topology consisting of **five (5) completely independent Funnel MLP streams** trained simultaneously within a single computational graph.

1.  **Independent Input Processing:**
    *   Each of the 5 streams will possess its own independent **Entity Embedding** layers.
    *   **Categorical Inputs:** The 10 decomposed character positions of `f_27` (Cite solution_lesson_node_00001) and the discrete features `f_29`, `f_30` (Cite solution_lesson_node_00008).
    *   **Optimal Capacity:** We will set the embedding dimension to **16** for all categorical variables. This adheres to the "sweet spot" capacity, avoiding the bottlenecks of dimension 8 (Cite solution_lesson_node_00018) and the noise of dimension 32 (Cite solution_lesson_node_00027).
    *   **Early Fusion:** Within each stream, the embeddings will be flattened and concatenated immediately with the normalized continuous features (`f_00`–`f_28` and `unique_character_count`) (Cite solution_lesson_node_00029).

2.  **Parallel Funnel Backbones:**
    *   Each stream will process its fused input through a distinct **Funnel MLP**.
    *   **Topology:** We strictly retain the decreasing layer width structure (512 $\to$ 256 $\to$ 128) which has consistently outperformed ResNets (Cite solution_lesson_node_00004).
    *   **Bottleneck Avoidance:** We terminate the hidden layers at width 128 before the final projection, explicitly avoiding tapering to 64 units to preserve information fidelity (Cite solution_lesson_node_00020).
    *   **Activation & Regularization:** We utilize standard **ReLU** activations and **Dropout (0.20)**. We explicitly exclude Layer Normalization (Cite solution_lesson_node_00039), Batch Normalization (Cite solution_lesson_node_00018), and GLUs (Cite solution_lesson_node_00019) to maximize robustness and prevent overfitting.

3.  **Aggregation Head:**
    *   The model outputs 5 independent probability predictions. The final prediction during inference is the arithmetic mean of these probabilities.

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures that every unique token in the test set is assigned a distinct embedding index, preventing the significant signal loss caused by mapping unseen test tokens to a generic "unknown" bucket (Cite solution_lesson_node_00021).
2.  **String Decomposition:** `f_27` will be split into 10 fixed-position character columns (Cite solution_lesson_node_00001). We explicitly avoid N-gram expansion (Cite solution_lesson_node_00035) and Token Dropout (Cite solution_lesson_node_00040) to preserve non-redundant positional signals.
3.  **Feature Engineering:** We will compute and append the `unique_character_count` of `f_27` as a normalized continuous feature (Cite solution_lesson_node_00002).
4.  **Normalization:** All continuous features will be scaled using **StandardScaler**.
5.  **Data Volume:** We will utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is precisely calibrated to facilitate super-convergence while maintaining generalization:

1.  **Multi-Stream Loss:** The training objective will be the **sum of the Binary Cross-Entropy losses** calculated for each of the 5 independent heads: $L = \sum_{i=1}^{5} BCE(y, \hat{y}_i)$. This forces each stream to learn a complete predictive function.
2.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-5**. We explicitly avoid the default `1e-2`, which was proven too aggressive for this tabular task (Cite solution_lesson_node_00023).
3.  **Scheduler:** **One-Cycle Learning Rate Policy**. We retain this schedule to facilitate super-convergence and robust minima selection (Cite solution_lesson_node_00002).
4.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise (Cite solution_lesson_node_00024).
5.  **Strategy:** Direct Supervised Learning (Cite solution_lesson_node_00013).

## Evaluation
1.  **Preprocessing:** The test set will be processed using the global (transductive) vocabulary mappings and training set scalers.
2.  **Inference:** The trained PIFE model will generate 5 probability predictions per sample. The final submission will be the **average** of these 5 probabilities.
3.  **Submission:** The resulting probabilities will be formatted into the submission CSV for AUC evaluation.
