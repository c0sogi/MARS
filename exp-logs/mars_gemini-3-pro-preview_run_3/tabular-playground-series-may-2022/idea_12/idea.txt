# Proposed Strategy: Self-Normalizing Funnel Network (SNN)

## Model
We will implement a **Self-Normalizing Funnel Network (SNN)**. This architecture represents a structural evolution from the standard ReLU-based MLP. Instead of relying on explicit normalization layers (like Batch or Layer Normalization) which have been shown to degrade performance or induce overfitting on this dataset (Cite solution_lesson_node_00039), or complex gated units (GLU) that increase parameter count and overfitting risk (Cite solution_lesson_node_00019), this network relies on the mathematical properties of the activation function to automatically maintain stable mean and variance throughout the deep network.

1.  **Input & Embeddings:**
    *   **Categorical Inputs:** The 10 decomposed character positions of `f_27` (Cite solution_lesson_node_00001) and the discrete features `f_29` and `f_30` (Cite solution_lesson_node_00008).
    *   **Optimal Capacity:** All categorical features will be mapped to **Entity Embeddings of dimension 16**. This adheres to the empirically determined "sweet spot," avoiding the signal bottleneck of dimension 8 (Cite solution_lesson_node_00018) and the noise overhead of dimension 32 (Cite solution_lesson_node_00027).
    *   **Early Fusion:** The embeddings will be flattened and concatenated immediately with the normalized continuous features (`f_00`–`f_28` and `unique_character_count`) (Cite solution_lesson_node_00029).

2.  **Self-Normalizing Backbone:**
    *   **Topology:** We retain the **Funnel** structure (decreasing layer widths: 512 $\to$ 256 $\to$ 128) as it provides the beneficial inductive bias of feature compression superior to constant-width ResNets (Cite solution_lesson_node_00004).
    *   **SNN Blocks:** We replace the standard `Linear -> ReLU -> Dropout` blocks with **`Linear -> SELU -> AlphaDropout`**.
        *   **SELU (Scaled Exponential Linear Unit):** This activation function induces self-normalizing properties, driving the neuron activations towards zero mean and unit variance. This eliminates the need for LayerNorm (which caused overfitting, Cite solution_lesson_node_00039) while ensuring the robust gradient flow required for super-convergence.
        *   **Alpha Dropout:** A specialized dropout variant that randomly sets inputs to the negative saturation value of the SELU function rather than zero. This preserves the mean and variance of the distribution, preventing the "distribution shift" caused by standard dropout in self-normalizing networks.
        *   **Initialization:** We will explicitly use **LeCun Normal** initialization for the weights, which is a mathematical requirement for the SNN fixed-point dynamics to hold.

3.  **Head:**
    *   The final 128-unit representation connects directly to the output neuron, explicitly avoiding tapering to narrower layers (e.g., 64) to prevent information bottlenecks (Cite solution_lesson_node_00020).

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures that every unique token in the test set is assigned a distinct embedding index, preventing the significant signal loss caused by mapping unseen test tokens to a generic "unknown" bucket (Cite solution_lesson_node_00021).
2.  **String Decomposition:** `f_27` will be split into 10 fixed-position character columns (Cite solution_lesson_node_00001). We explicitly avoid N-gram expansion to prevent noise (Cite solution_lesson_node_00035).
3.  **Feature Engineering:** We will compute and append the `unique_character_count` of `f_27` as a normalized continuous feature (Cite solution_lesson_node_00002).
4.  **Normalization:** All continuous features will be scaled using **StandardScaler**.
5.  **Data Volume:** We will utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is precisely calibrated to facilitate super-convergence while maintaining generalization:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-5**. We explicitly avoid the default `1e-2`, which was proven too aggressive for this tabular task (Cite solution_lesson_node_00023).
2.  **Scheduler:** **One-Cycle Learning Rate Policy**. We retain this schedule to facilitate super-convergence and robust minima selection (Cite solution_lesson_node_00002).
3.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise, avoiding the generalization gap observed with larger batches (Cite solution_lesson_node_00024).
4.  **Strategy:** Direct Supervised Learning. We avoid autoencoder pretraining as it provides no benefit for this high-signal dataset (Cite solution_lesson_node_00013).

## Evaluation
1.  **Preprocessing:** The test set will be processed using the global (transductive) vocabulary mappings and training set scalers.
2.  **Inference:** The trained Self-Normalizing Funnel Network will predict probabilities for the target class `1`.
3.  **Submission:** The resulting probabilities will be formatted into the submission CSV for AUC evaluation.
