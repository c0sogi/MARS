Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` to ensure reproducibility and directory structure.
2.  **Data Loading**: specific `get_dataloaders` from the library with `load_cached_data=True`. This leverages the pre-processed parquet files for speed.
3.  **Model Initialization**: Instantiate the `LayerNormFunnelMLP` using the vocabulary sizes derived from the data loading step and the hyperparameters defined in `Config`.
4.  **Fast Baseline Training**: Execute `train_model` with a reduced number of epochs (e.g., 5) to ensure the task completes quickly while establishing a strong baseline. This utilizes the A100 GPU efficiently.
5.  **Validation & Metric Calculation**:
    *   Manually iterate over the validation loader in evaluation mode to generate predictions.
    *   Compute the AUC score using `sklearn.metrics.roc_auc_score`.
    *   Print the metric in the strictly required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate the absolute error (`|target - prediction|`) for each validation sample.
    *   Compute the Pearson correlation between this error and all input features (both continuous and categorical indices).
    *   Print the top features most correlated with higher errors to identify systematic weaknesses.
7.  **Conditional Submission**:
    *   Compare the calculated validation AUC against the threshold `0.9971550270448856`.
    *   If the model passes, generate predictions for the test set using `predict`.
    *   Save the formatted submission file to `./submission/submission.csv`.
