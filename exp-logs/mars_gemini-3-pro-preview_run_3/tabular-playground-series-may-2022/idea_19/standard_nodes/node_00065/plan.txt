This script implements the end-to-end machine learning pipeline for the manufacturing control task. It leverages the provided library modules for configuration, data processing, model definition, and training engine.

**Implementation Strategy:**
1.  **Setup & Configuration:** Initialize the environment by setting random seeds via `Config.set_seed()` to ensure reproducibility.
2.  **Data Loading:** Use `library.dataset.preprocess_data` with `load_cached_data=True` to efficiently load the preprocessed training, validation, and test datasets along with metadata (vocabulary sizes, column names).
3.  **Data Preparation:** Wrap the pandas DataFrames into PyTorch `DataLoader` objects using the `ManufacturingDataset` class. This handles batching, shuffling, and moving data to the appropriate device (CPU/GPU).
4.  **Model Initialization:** Instantiate the `HPFEModel` (Heterogeneous Parallel Funnel Ensemble) using the metadata. This model features 5 parallel streams with diverse architectures to maximize ensemble robustness.
5.  **Training:** Execute the training loop using `library.engine.train_model`. This function manages the optimizer (Adam), scheduler (OneCycleLR), and early stopping based on validation AUC.
6.  **Validation:** After training, evaluate the best model on the full validation set to compute the final AUC score. This metric is printed with full precision.
7.  **Failure Analysis:** Perform a systematic error analysis on the validation set. Calculate the absolute error for each sample and compute the Pearson correlation between the error magnitude and input features (both continuous and categorical). Print the top 5 features most associated with model error.
8.  **Submission:** Compare the final validation AUC against the strict threshold of `0.9972038455079483`. If the model performance exceeds this benchmark, generate predictions for the test set using `library.engine.predict_and_submit` and save the `submission.csv` file.
