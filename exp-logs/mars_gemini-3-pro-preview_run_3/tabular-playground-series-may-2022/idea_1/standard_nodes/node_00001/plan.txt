Implementation Strategy:
The implementation will serve as the orchestration script `runfile.py`. It will leverage the provided library modules for data processing, model definition, and training management. The script will:
1.  **Setup & Config**: Import necessary libraries and set the random seed for reproducibility.
2.  **Data Loading**: Use `make_dataloaders` with caching enabled to efficiently load the preprocessed manufacturing data.
3.  **Model Initialization**: Instantiate the `EntityEmbeddingMLP` using vocabulary sizes derived from the training dataset.
4.  **Training**: Initialize the `Trainer` and execute the training loop for a limited number of epochs (10) to create a fast baseline, utilizing the A100 GPU.
5.  **Validation & Metric**: Manually run a validation pass using the best saved model checkpoint to compute the AUC score. This ensures the metric is calculated on the full hold-out set and printed with full precision as required.
6.  **Failure Analysis**: Calculate the absolute prediction errors on the validation set and compute their Pearson correlation with the continuous input features to identify systematic failure modes.
7.  **Submission**: Generate predictions for the test set and save them to the specified submission file format.
