Implementation strategy:
1.  **Setup & Imports**: Import necessary libraries and the provided modules (`library.utils`, `library.dataset`, `library.trainer`). Set the random seed for reproducibility.
2.  **Configuration**: Define training parameters. I will use 3 epochs to ensure the process completes within the 2-hour soft limit on the available A100 GPU, while still allowing the EfficientNetV2-Small model to converge sufficiently. The batch size is set to 64.
3.  **Data Loading**: Use `create_dataloaders` with `debug=False` to load the full dataset. This is crucial for achieving the target F1 score, as subsampling would likely miss rare classes in this high-cardinality dataset.
4.  **Training**: Instantiate the `Trainer` class and call the `fit` method. This handles the training loop, Mixup augmentation, and saving the best model based on validation F1.
5.  **Validation**: Load the best model weights saved during training. Perform a full inference pass on the validation set to calculate the final Macro F1 score. Print this metric with full precision as required.
6.  **Failure Analysis**: Align the validation predictions with the metadata. Sample 1000 instances to quickly extract input features (width, height, file size) from disk. Calculate and print the correlation between the model's error (binary) and these features to identify potential biases.
7.  **Submission**: Check if the final validation F1 score exceeds the threshold (0.5930838412243743). If it does, call `trainer.predict` to generate predictions on the test set using Test-Time Augmentation (horizontal flip) and save the submission file.
