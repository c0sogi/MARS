Passing sparse/raw IDs outside the model's range to `CrossEntropyLoss` triggers the assertion.

1.  **Update `library/config.py`**: Change the cache filename to `hierarchy_mappings_v2.parquet` to force regeneration of the hierarchy metadata with the new schema (Cite debug_lesson_8).

3.  **Update `library/data.py`**: Configure `PlantDataset` to use the mapped `species_label` for training and ensure these labels are correctly merged and cast in `get_dataloaders`.
4.  **Update `library/inference.py`**: Import `load_hierarchy_mappings` and use it to map the model's contiguous predictions back to the original `category_id`s for the submission file.
