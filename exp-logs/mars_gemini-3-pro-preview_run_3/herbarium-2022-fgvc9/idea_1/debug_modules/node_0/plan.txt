This script demonstrates the usage of the provided library modules for the plant categorization task. It performs the following steps:
1.  **Configuration**: Sets up the environment and overrides default configuration parameters (enabling debug mode, reducing batch size and epochs) to ensure the demonstration runs quickly.
2.  **Data Loading**: Verifies the functionality of the `get_dataloaders` function, ensuring that training, validation, and test loaders produce batches with the correct shapes.
3.  **Model Architecture**: Instantiates the `PlantClassifier` and verifies that the output layer matches the specific number of classes (15,501) and that a forward pass works correctly.
4.  **Training Pipeline**: Uses the `Trainer` class to run a single epoch of training on a small subset of data, verifying that the training loop executes without error and produces a model checkpoint.
5.  **Inference & Submission**: Executes the inference pipeline to generate predictions on the test set and verifies the format and existence of the resulting submission CSV file.
6.  **Metrics**: Validates the `compute_metrics` function using dummy data.
