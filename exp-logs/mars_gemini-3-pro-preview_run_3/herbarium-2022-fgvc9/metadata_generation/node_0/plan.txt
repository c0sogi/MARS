The strategy is to create a Python script that generates metadata CSV files for training, validation, and testing. 

1.  **Setup and Imports**: Initialize necessary libraries (`os`, `json`, `pandas`, `glob`, `sklearn`) and define the input/output directories.
2.  **Training Data Generation**: 
    *   Since the `train_metadata.json` is described primarily as containing taxonomic information and the training images are organized in a structured directory tree (`train_images/<subfolder1>/<subfolder2>/<filename>`), the script will scan the `input/train_images` directory to build the training dataset.
    *   It will parse the `category_id` directly from the filenames (format: `{category_id}__{image_num}.jpg`) to ensure accurate ground-truth labels.
    *   It will construct relative file paths for each image.
3.  **Test Data Generation**:
    *   Load `input/test_metadata.json` to get the list of test images and their IDs.
    *   Construct file paths by prepending `test_images/` to the `file_name` field provided in the JSON.
4.  **Validation Split**:
    *   The training data will be split into an 80% training set and a 20% validation set.
    *   **Stratification**: The split will be stratified based on `category_id` to maintain class distribution.
    *   **Rare Class Handling**: Classes with fewer than 2 samples cannot be stratified. These will be automatically assigned to the training set to prevent errors and ensure the model sees them.
5.  **Verification**:
    *   The script will check the existence of 1000 random file paths from each dataset to ensure data integrity.
    *   It will print summary statistics (shape, class counts) and raise an error if the missing file ratio exceeds 0.5.
6.  **Output**: Save `train.csv`, `val.csv`, and `test.csv` to the `metadata/` directory.
