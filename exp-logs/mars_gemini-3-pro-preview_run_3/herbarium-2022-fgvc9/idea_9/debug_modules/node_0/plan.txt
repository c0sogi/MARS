This script demonstrates the end-to-end usage of the provided library modules to train a hierarchical plant classification model and generate a submission.

**Implementation Strategy:**
1.  **Setup & Configuration**: Initialize the environment with a fixed seed, define the computation device (GPU/CPU), and create a working directory for outputs.
2.  **Metadata Processing**: Use `get_hierarchy_mappings` to parse the taxonomic structure from `train_metadata.json` and determine the number of classes for species, genera, and families.
3.  **Data Loading**: Load the pre-generated `train.csv` and `val.csv`. To ensure the demonstration runs quickly, we sample a small subset (200 training images, 50 validation images). We then create `PlantDataset` and `DataLoader` instances using the provided transforms.
4.  **Model Initialization**: Instantiate the `CascadingPlantModel` using the class counts derived from the hierarchy.
5.  **Training**: Configure the AdamW optimizer and OneCycleLR scheduler. Run the training loop for one epoch using `train_one_epoch` and evaluate using `validate`.
6.  **Inference**: Load a subset of `test.csv`, create a test `DataLoader`, and use `generate_submission` to produce predictions with Test Time Augmentation (TTA).
7.  **Verification**: Assert that the submission file is created correctly and matches the expected format.
