Implementation Strategy:
To implement the `runfile.py` as a fast baseline within the 2-hour time limit, I will adopt the following strategy:
1.  **Data Subsampling**: Instead of training on the full 530k dataset, I will create a random subset of 150,000 images (~28%). This balances training speed with the need for sufficient data to cover the 15,501 classes. I will save this subset to a temporary CSV and override `Config.TRAIN_CSV`.
2.  **Training Configuration**: I will override `Config.EPOCHS` to 3. With the A100 GPU and a batch size of 32, this is estimated to take approximately 70-80 minutes, leaving ample time for validation and inference.
3.  **Validation & Metrics**: After training, I will load the best model and evaluate it on the *entire* validation set to compute the `Final Validation Metric` (Macro F1), as required.
4.  **Failure Analysis**: To perform failure analysis efficiently, I will calculate prediction errors on the validation set. I will then extract image features (width, height, file size) for a random sample of 2,000 validation images (to avoid excessive I/O latency) and compute the correlation between these features and the error magnitude.
5.  **Conditional Submission**: I will check if the calculated Macro F1 score exceeds the threshold (`0.5930838412243743`). If it does, I will trigger the `generate_submission` function.
