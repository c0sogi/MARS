The error `pydantic_core._pydantic_core.ValidationError: 1 validation error for InitSchema size Field required` is caused by an API change in `albumentations` version 2.0. The `A.RandomResizedCrop` transform now requires a single `size` argument (a tuple of `(height, width)`) instead of separate `height` and `width` arguments. I will update `library/dataset.py` to conform to this new specification. Cite debug_lesson_3.

Additionally, I will update the initialization of `best_f1` in `library/train.py` from `0.0` to `-1.0`. This ensures that the model checkpoint is saved after the first epoch even if the F1 score is exactly `0.0`, preventing potential `FileNotFoundError` in downstream steps. Cite debug_lesson_2.
