The issue stems from a schema mismatch and stale caching. The `get_hierarchy_mappings` function in `library/config.py` fails to generate the `species_label` column required to map sparse `category_id`s (which can exceed the class count) to contiguous integers (0..N-1) for training (Cite debug_lesson_1). Additionally, the system loads an existing cache file that lacks this column, causing a `KeyError`. The `dataset.py` also incorrectly unpacks the hierarchy dictionaries and uses raw `category_id`s as targets, which would lead to device-side assertions.

I will fix this by:
1.  Updating `library/config.py` to generate the `species_label` mapping and versioning the cache file to `hierarchy_mappings_v2.parquet` to force regeneration (Cite debug_lesson_8).
2.  Updating `library/dataset.py` to correctly unpack the hierarchy dictionaries and use the mapped `species_label` for training targets.
