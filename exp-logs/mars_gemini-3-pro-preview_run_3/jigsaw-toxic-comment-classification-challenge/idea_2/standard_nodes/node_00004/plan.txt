Implementation Strategy:
The solution orchestrates a hybrid ensemble pipeline combining a linear NBSVM model and a deep learning RoBERTa model.
1.  **Setup & Data Loading**: We initialize the environment with a fixed seed and load the training, validation, and test datasets using the provided metadata-based loader.
2.  **NBSVM Pipeline**: We generate TF-IDF features (word and character n-grams) and train the NBSVM model. We generate probability predictions for both the validation and test sets.
3.  **RoBERTa Pipeline**: We tokenize the text and create PyTorch DataLoaders. We initialize a pre-trained `roberta-base` model and fine-tune it for 1 epoch on the training data to ensure execution speed fits within the limit while maintaining high performance. We then perform inference on validation and test sets.
4.  **Ensemble & Validation**: We combine the predictions from both models using a weighted average (0.6 RoBERTa / 0.4 NBSVM). We compute the Mean Column-wise ROC AUC on the validation set and print it in the required format.
5.  **Failure Analysis**: We calculate the correlation between the model's error magnitude and the comment length (word count) to identify if longer/shorter comments are harder to classify.
6.  **Submission**: If the validation metric exceeds the specified threshold, we save the test predictions to `submission.csv`.
