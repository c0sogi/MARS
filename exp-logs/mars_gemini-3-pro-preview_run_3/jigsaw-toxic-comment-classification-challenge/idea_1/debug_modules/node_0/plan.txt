This script demonstrates the end-to-end usage of the provided library modules for the toxic comment classification task. It is designed to run quickly by utilizing a subset of the data (`sample_size`) while verifying the correctness of the data loading, feature engineering, model training, and submission generation processes through assertions.

The implementation follows these steps:
1.  **Setup**: Configures the environment, seeds, and logging.
2.  **Component Demonstration**: Manually invokes `load_data`, `FeatureEngineer`, and `MultiLabelNBSVM` on a small data slice to verify shapes, types, and prediction outputs.
3.  **Workflow Demonstration**: Executes the high-level `train_validate` and `generate_submission` functions from `library.workflow` to simulate a full training and inference cycle.
4.  **Submission Validation**: Checks the generated submission file for the correct format and data integrity.
