### Proposed Solution: Multi-Task RoBERTa with Dual-Level Bias Mitigation

I propose a structural evolution of the previous Context-Aware Transformer approach by upgrading the backbone to **RoBERTa-base** and integrating a **Multi-Task Learning (MTL)** framework with **Targeted Loss Reweighting**. This strategy synthesizes the architectural benefits of contextual embeddings with advanced regularization techniques derived from the lessons to aggressively minimize unintended bias.

#### 1. Model
*   **Backbone Architecture**: We will replace the DistilBERT backbone with **RoBERTa-base**. RoBERTa (Robustly optimized BERT approach) utilizes dynamic masking and is trained on a larger corpus with longer sequences, making it superior at capturing the subtle syntactic nuances required to disentangle identity mentions from toxicity, a key advantage of contextual models. Cite solution_lesson_node_00006
*   **Unified Multi-Task Head**: Instead of a single output for toxicity, the model will feature a **Unified Projection Layer**: a single `nn.Linear` layer that projects the `[CLS]` embedding to 7 output logits simultaneously. These outputs correspond to the main `target` and the 6 auxiliary toxicity subtypes (e.g., `severe_toxicity`, `identity_attack`, `insult`). This structural change forces the shared encoder to learn a richer representation that distinguishes between specific types of toxicity (e.g., an identity attack vs. a general insult). Cite solution_lesson_node_00009
*   **Regularization**: We will retain **Multi-Sample Dropout** before the final projection layer to further prevent overfitting to specific training examples.

#### 2. Data
*   **Stochastic Identity Masking**: We will preserve the data augmentation strategy where tokens matching identity terms (e.g., "muslim", "gay") are randomly replaced with a mask token with a probability of 0.5. This forces the model to rely on surrounding context rather than the identity term itself. Cite solution_lesson_node_00001
*   **Targeted Sample Weighting**: We will implement a preprocessing step to assign a specific scalar weight to each training example. While standard examples receive a weight of 1.0, **non-toxic examples that mention an identity** (the "hard negatives" for bias) will receive a significantly higher weight (e.g., 3.0-5.0). This prepares the data for a loss function that heavily penalizes false positives on identity subgroups. Cite solution_lesson_node_00010
*   **Tokenization**: We will use the RoBERTa tokenizer (Byte-Pair Encoding), which is distinct from DistilBERT's WordPiece, requiring a rebuild of the identity term mapping for masking.

#### 3. Training
*   **Objective Function**: The loss will be a **Weighted Binary Cross Entropy** summed across all 7 tasks.
    *   The loss for the main `target` will be weighted by the pre-calculated sample weights to focus optimization on bias mitigation. Cite solution_lesson_node_00010
    *   The auxiliary tasks will be included in the total loss (e.g., $L_{total} = L_{main} + 0.5 \times L_{aux}$) to regularize the latent space and improve the specific BPSN metric. Cite solution_lesson_node_00008
*   **State Management**: We will implement a robust Early Stopping callback that uses `copy.deepcopy(model.state_dict())` to cache the best model weights. This ensures that the restored model is the exact snapshot that achieved the highest validation score, preventing the regression observed when using mutable references. Cite solution_lesson_node_00002
*   **Optimization**: Training will proceed with the AdamW optimizer, using a linear warmup and cosine decay schedule.

#### 4. Evaluation
*   **Inference**: The model will process the test set without identity masking.
*   **Prediction**: The output logits will be sliced to extract the first column (corresponding to the main `target`), which will be passed through a sigmoid function to generate the final probability for submission. Cite solution_lesson_node_00009
