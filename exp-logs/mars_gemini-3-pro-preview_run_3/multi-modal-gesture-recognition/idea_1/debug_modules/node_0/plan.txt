Implementation strategy:
1.  **Setup & Configuration**: Import the necessary library modules. Subclass or modify the `Config` class at runtime to optimize for a quick demonstration (reduce epochs, batch size, hidden dimensions) and point to a smaller "mini" dataset to ensure the script runs within a few minutes.
2.  **Data Preparation**: Create a mini-dataset by reading the provided metadata CSVs (`train.csv`, `val.csv`, `test.csv`), selecting the first few rows (e.g., 10 samples), and saving them as new CSVs in the working directory. This avoids processing the entire dataset.
3.  **Data Loading**: Use `get_dataloaders` with the mini-dataset configuration. Verify the shape and type of the yielded batches to ensure data integrity.
4.  **Model Initialization**: Instantiate the `BiGRUModel` with the reduced hyperparameters defined in the configuration. Perform a dummy forward pass to verify the model architecture and output shapes.
5.  **Training Loop**: Initialize the `Trainer` and run the training process for a minimal number of epochs (e.g., 2). Verify that the model checkpoint is successfully saved to the working directory.
6.  **Inference Pipeline**: Execute `run_inference` using the trained model on the mini-test set. Verify that the submission file is generated correctly and adheres to the expected format (SessionID, list of predictions).
7.  **Metric Verification**: Demonstrate the `compute_levenshtein_distance` function with synthetic ground truth and prediction data to verify the scoring logic.
