This script demonstrates the end-to-end usage of the provided library modules for the gesture recognition task. It first sets up a lightweight demonstration environment by creating a subset of the metadata and configuring the system to use temporary working directories. It then verifies the data loading pipeline, ensuring correct feature alignment and shape. Next, it instantiates the `PAKRNet` model and performs a forward pass to validate architecture compatibility. Finally, it executes a short training loop using the `Trainer` class and demonstrates how to generate predictions from the trained model, asserting correctness at each step.
