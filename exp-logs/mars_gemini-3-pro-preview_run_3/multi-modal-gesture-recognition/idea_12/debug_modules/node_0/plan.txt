This script demonstrates the end-to-end usage of the provided SA-AKN library components. It performs the following steps:

1.  **Configuration Setup**: Modifies the global `Config` class to run in a lightweight "Debug" mode (fewer samples, smaller batch size, single epoch) and sets up a temporary working directory.
2.  **Feature Extraction Verification**: Validates the `extract_features` function by creating a synthetic skeleton sequence and asserting the output dimensions match the expected kinematic feature set (240 channels).
3.  **Dataset Loading & Processing**: Initializes the `GestureDataset` in training mode. It verifies that data is loaded, sliding windows are generated correctly, and the `__getitem__` method returns tensors of the correct shape and type.
4.  **Model & Loss Initialization**: Instantiates the `SA_AKN` model and `CascadedLoss`. It performs a forward pass with a batch of data to verify the architecture's connectivity and asserts that the loss calculation produces a valid scalar.
5.  **Training Loop Simulation**: Runs a single epoch of training using the `train_epoch` function to demonstrate the optimization process and ensure the pipeline runs without runtime errors.
6.  **Inference & Evaluation**: Demonstrates the inference pipeline on a validation sample using `run_inference_on_sequence` and `decode_predictions`. It calculates the Levenshtein distance metric to verify the evaluation logic.
7.  **Submission Generation**: Mocks the submission process by saving the predictions to a CSV file using `save_submission`.
