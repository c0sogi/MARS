Based on the rigorous analysis of the "Lessons Learned" and the progression of "Previous Ideas," I propose the **Stochastic-Depth Decoupled-Gated Network (SD-DGN)**.

This solution explicitly addresses the **"Zombie Experiment" Failure** (Cite solution_lesson_node_00133) by successfully integrating the robust regularization techniques (Gaussian Noise, Label Smoothing) that failed to execute in previous attempts due to caching errors. Furthermore, it introduces **Stochastic Depth** to the refinement stages, a structural innovation designed to combat the overfitting inherent in deep temporal networks trained on small datasets (Cite solution_lesson_node_00053), while retaining the highly effective **Decoupled-Norm Gating** (Cite solution_lesson_node_00132) and **RF-Aligned TCN** (Cite solution_lesson_node_00127).

# Model
The architecture is a **Three-Stage Cascaded Network** designed for maximum regularization and noise robustness.

1.  **Stage 1: Decoupled-Norm Gated Encoder**
    *   **Input:** An **Early Fusion** vector consisting of two streams:
        *   **Skeleton Stream:** Kinematically Consistent features (Position, Velocity, Acceleration) derived via **Central Differences** (Cite solution_lesson_node_00127). We explicitly **retain Raw Millimeters** to preserve the signal-to-noise hierarchy (Position $\gg$ Acceleration) (Cite solution_lesson_node_00085).
        *   **Audio Stream:** MFCC features.
    *   **Decoupled-Norm Input Gating:** We retain the successful split-path gating mechanism:
        *   *Path A (Gate):* $X_{norm} = LayerNorm(X_{raw})$. Used to generate the attention mask.
        *   *Path B (Signal):* $X_{raw}$. Retains physical magnitude.
        *   *Fusion:* $\tilde{X} = X_{raw} \odot \sigma(Linear(X_{norm}))$. This allows dynamic noise suppression without saturating gradients on raw inputs (Cite solution_lesson_node_00132).
    *   **Backbone:** A **2-Layer Bi-directional GRU (Bi-GRU)** with **96 units per direction**. This capacity avoids both underfitting and overfitting (Cite solution_lesson_node_00066, solution_lesson_node_00110).
    *   **Regularization:** **Dropout (p=0.4)** between GRU layers (Cite solution_lesson_node_00091).
    *   **Output:** Initial frame-wise class probabilities ($P_1$).

2.  **Stage 2: Stochastic-Depth Monotonic Refinement**
    *   **Input:** Strictly the **class probabilities** ($P_1$) from Stage 1 (Cite solution_lesson_node_00020).
    *   **Architecture:** A stack of **Gated Dilated Temporal Convolutional Layers** using **Standard Convolutions** (Cite solution_lesson_node_00065).
    *   **Structural Innovation (Stochastic Depth):** We implement **Stochastic Depth (DropPath)** within the residual blocks of the TCN. During training, we randomly drop entire residual branches with probability $p_{drop}=0.2$, forcing the signal to propagate through the identity connection.
        *   *Rationale:* This effectively trains an implicit ensemble of shallower networks, acting as a powerful structural regularizer for small datasets where deep TCNs tend to overfit (Cite solution_lesson_node_00053).
    *   **Dilation Schedule:** **Monotonically Increasing** $[1, 2, 4, 8, 16]$. This yields a receptive field of 63 frames, perfectly matching the 64-frame window (Cite solution_lesson_node_00127).
    *   **Causality:** **Centered Padding** (Non-Causal) (Cite solution_lesson_node_00078).
    *   **Output:** Refined class probabilities ($P_2$).

3.  **Stage 3: Independent Stochastic-Depth Refinement**
    *   **Structure:** Identical to Stage 2 but with **independent weights** (Cite solution_lesson_node_00054).
    *   **Output:** Final class probabilities ($P_3$).

# Data
The data pipeline incorporates the "Zombie" fixes and ensures strict cache invalidation.

1.  **Robust Polymorphic Parsing (Structural Requirement):**
    *   The data loader implements a **Polymorphic Parser** for the `.mat` files to prevent silent failures (Cite solution_lesson_node_00045).

2.  **Noise-Robust Kinematic Derivation (Structural Innovation):**
    *   **Load:** Raw 3D Joint Positions ($P_{raw}$).
    *   **Center:** Apply **Root-Relative Centering**.
    *   **Augment 1 (Geometric):** Apply random 3D rotations (Y-axis) and scaling.
    *   **Augment 2 (Injection):** Inject **Gaussian Noise** ($\sigma=0.01$) to the position data *before* derivation.
        *   *Rationale:* This forces the model to learn kinematic features (Velocity/Acceleration) that are robust to high-frequency sensor jitter, a critical augmentation that failed to execute in previous attempts (Cite solution_lesson_node_00133).
    *   **Derive:** Calculate **Velocity** and **Acceleration** using **Central Differences** (`np.gradient`) on the noisy, augmented positions (Cite solution_lesson_node_00127).

3.  **Sampling Strategy:**
    *   **Windowing:** **Sliding Windows of 64 frames** (Cite solution_lesson_node_00017).
    *   **Stride:** **Moderate Stride** (32 frames) (Cite solution_lesson_node_00053).
    *   **Cache Invalidation:** Explicitly change the experiment ID to force re-computation of the dataset with the new noise injection (Cite solution_lesson_node_00133).

# Training
The training strategy employs robust loss formulations.

1.  **Cascaded Loss Function:**
    *   $L_{total} = L(P_1) + L(P_2) + L(P_3)$ (Deep Supervision) (Cite solution_lesson_node_00025).
    *   **Label-Smoothed Cross-Entropy:** We replace standard Cross-Entropy with **Label Smoothing ($\epsilon=0.1$)**.
        *   *Rationale:* This prevents the model from becoming over-confident on ambiguous boundary frames, reducing the penalty for slight temporal misalignments (Cite solution_lesson_node_00133).
    *   **Log-Space Smoothing Loss:** Truncated MSE on log-probabilities.
    *   **Calibration:** **Low Weight** ($\lambda=0.15$) and **Low Threshold** (1.0) (Cite solution_lesson_node_00111).

2.  **Optimizer:**
    *   **Adam** optimizer with **Weight Decay** (L2) (Cite solution_lesson_node_00055).

# Evaluation
1.  **Inference:** **Full Sequence Inference** (Batch Size=1) to preserve global temporal context (Cite solution_lesson_node_00079).
2.  **Model Selection:** Select best checkpoint based on **Levenshtein Distance** on full sequences (Cite solution_lesson_node_00075).
3.  **Decoding:**
    *   Apply `argmax` to $P_3$.
    *   Perform **Run-Length Encoding**.
    *   **Min Duration Filter:** Remove segments shorter than **5 frames** (Cite solution_lesson_node_00071).
