This script demonstrates the usage of the provided machine learning library for the Italian Gesture Recognition task. It performs the following steps:
1.  **Configuration**: Sets up a dedicated working directory (`./working/demo_execution`) to avoid conflicts and ensures reproducibility.
2.  **Utility Verification**: Validates the logic of Run-Length Encoding (RLE) and Levenshtein distance calculation functions.
3.  **Data Loading**: Instantiates the `GestureDataset` with a small subset of samples to verify data processing, caching, and shape consistency (features and targets).
4.  **Model Initialization & Forward Pass**: Initializes the `RDKRN` model, creates a dummy batch, and verifies the output shapes of the multi-stage architecture.
5.  **Loss Calculation**: Computes the `CascadedLoss` on the dummy outputs to ensure the loss function and its components (CrossEntropy + TruncatedMSE) work correctly.
6.  **Training Loop**: Executes a complete training run for 1 epoch on a small subset of data using `run_training`. This verifies the `Trainer` class, optimization steps, and checkpoint saving.
7.  **Inference Pipeline**: Runs the inference process on a test subset using `run_inference`, verifying that predictions are generated, aggregated, decoded, and saved to the submission file.
