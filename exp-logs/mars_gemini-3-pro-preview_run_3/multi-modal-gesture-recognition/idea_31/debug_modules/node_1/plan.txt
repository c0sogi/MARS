The issue arises because the dataset is cached using `np.savez` with `dtype=object` to handle variable-length sequences. When loaded back, the arrays retain the `object` data type, which PyTorch cannot convert to tensors, causing a `TypeError`. To fix this, I will explicitly cast the retrieved arrays to their native numeric types (`float32` for features, `int64` for labels) immediately before processing in both the data loader and the inference preprocessing function.
