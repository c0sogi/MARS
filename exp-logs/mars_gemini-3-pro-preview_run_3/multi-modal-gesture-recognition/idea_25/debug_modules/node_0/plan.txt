The following script demonstrates the usage of the provided multi-modal gesture recognition library.

**Implementation Strategy:**
1.  **Environment Setup**: We configure a reproducible environment by setting random seeds and preparing a working directory for outputs.
2.  **Data Loading Verification**: We instantiate the `GestureDataset` with a small subset (`limit=20`) to verify data parsing, feature extraction (Kinematics + MFCC), and sliding window generation. We assert the correctness of input feature dimensions (193 features) and label shapes.
3.  **Model Architecture Verification**: We instantiate the `NRGSNet` model and perform a forward pass with a dummy tensor. We verify that the model produces the expected Deep Supervision outputs (3 tensors) with the correct shape `(Batch, Time, Num_Classes)`.
4.  **Training Loop Demonstration**: Instead of running a full training session, we manually execute one training epoch and one validation epoch using the `train_epoch` and `validate_epoch` functions from `trainer.py`. We use a custom `DataLoader` with a small batch size to ensure quick execution. We verify that the loss decreases or is computed correctly and save the model weights.
5.  **Inference Pipeline Demonstration**: We load the saved model and run the `generate_submission` function from `inference.py` on a small subset of the test metadata (`limit=5`). We verify that the submission CSV is generated and follows the required format.
