This script demonstrates the end-to-end pipeline for the gesture recognition task using the provided library files. It performs the following steps:

1.  **Configuration Override**: Modifies the `Config` class at runtime to use a temporary working directory and a "mini" dataset (subset of the original metadata) to ensure the demonstration runs quickly (under 1 hour).
2.  **Data Preparation**: Creates mini CSV metadata files for training, validation, and testing by sampling the first few rows of the original metadata.
3.  **Data Loading Verification**: Uses `data_loader.load_data` and `GestureDataset` to load the mini-dataset and verifies the integrity of the batches (shapes of features and labels).
4.  **Model Verification**: Instantiates the `RS_KRN` model, performs a forward pass with a dummy batch, and asserts the output shapes are correct.
5.  **Training Loop Demonstration**: Runs a short training session (2 epochs) using `train_epoch` and `validate` to demonstrate the optimization process and metric calculation.
6.  **Inference & Submission**: Generates predictions for the mini test set using `inference.generate_submission` and verifies the output file format.
