The following script demonstrates the end-to-end usage of the provided machine learning library for the gesture recognition task. It performs the following steps:

1.  **Configuration Override**: Modifies the global configuration classes (`Paths`, `DataConfig`, `TrainConfig`) at runtime to use a temporary working directory and a small subset of data for a quick demonstration.
2.  **Data Loading Verification**: Uses `get_dataloaders` to load a batch of training data and asserts the correctness of feature dimensions (Skeleton + Audio) and label shapes.
3.  **Model Verification**: Instantiates the `CKARFNet` model, performs a forward pass with the loaded batch, and verifies the deep supervision outputs (multi-stage logits).
4.  **Metric Verification**: Validates the Levenshtein distance calculation function with known inputs.
5.  **Training Loop Execution**: Runs the full training pipeline (`run_training`) for a single epoch to ensure the optimization loop, loss calculation (CrossEntropy + LogSpaceSmoothing), and checkpointing work correctly.
6.  **Inference Execution**: Generates predictions on the test set using the trained model (`generate_submission`) and validates the output format.
