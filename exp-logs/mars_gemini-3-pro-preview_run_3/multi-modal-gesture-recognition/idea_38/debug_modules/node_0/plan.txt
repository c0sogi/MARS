This script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition. It performs the following steps:

1.  **Configuration**: Modifies the global `Config` to run in a lightweight "Demo" mode (using a temporary directory, reduced epochs, and a small data subset).
2.  **Data Loading**: Initializes the `GestureDataset` and `DataLoader`s, verifying that data is correctly loaded, batched, and shaped (Skeleton + Audio features).
3.  **Model Verification**: Instantiates the `SHCGKN` model, performs a forward pass with a batch of data, and validates the output structure and dimensions.
4.  **Utility Verification**: Tests the `decode_predictions` logic (converting frame probabilities to gesture sequences) and `calculate_levenshtein_distance` metric using synthetic data.
5.  **Training & Inference**: Runs a full `Trainer` cycle for 1 epoch. This includes training on the subset, validating, saving the best model, and generating a submission file.
