This script implements the end-to-end pipeline for the **Stabilized High-Capacity Gated-Kinematic Network (SHC-GKN)**. It orchestrates the training, validation, failure analysis, and conditional submission generation.

**Implementation Strategy:**
1.  **Configuration:** Modifies the `Config` class to ensure a fast baseline execution (12 epochs) and ensures reproducibility by setting fixed seeds.
2.  **Training Loop:** Implements a custom training loop using the `Trainer` class components. It iterates through epochs, computing training loss and validation Levenshtein distance, and saves the best model checkpoint.
3.  **Final Evaluation:** Loads the best model weights and computes the definitive validation metric, printing it in the required format.
4.  **Failure Analysis:** Performs a detailed analysis on the validation set. It reconstructs sequences, calculates error metrics per sample, and computes Pearson correlations between the error magnitude and input features (Duration, Motion Energy, Audio Energy) to identify systematic weaknesses.
5.  **Conditional Submission:** Checks if the final validation metric meets the threshold (< 0.2251). If successful, it invokes the submission generation routine to create `submission.csv` for the test set.
