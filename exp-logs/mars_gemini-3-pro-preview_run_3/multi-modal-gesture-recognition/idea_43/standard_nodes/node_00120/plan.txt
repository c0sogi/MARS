The implementation strategy is as follows:

1.  **Setup & Imports**: Import the necessary standard libraries and the provided modules (`library.config`, `library.trainer`, `library.data_loader`, `library.utils`). Set fixed random seeds for reproducibility.
2.  **Training**: Initialize the `Trainer` class and execute the `fit` method. We will limit the training to 30 epochs with early stopping to ensure the "fast baseline" requirement is met while allowing sufficient convergence for the small dataset.
3.  **Validation & Metric Calculation**: Load the best model checkpoint. Iterate through the validation dataset using the `get_dataloaders` function. For each sample, perform inference, decode the predictions using the provided RLE and filtering logic, and compute the Levenshtein distance against the ground truth. Aggregate these distances to calculate the `Final Validation Metric` exactly as defined.
4.  **Failure Analysis**: During the validation loop, collect metadata for each sample (error magnitude, sequence length, number of gestures, mean signal magnitude). Compute and print the Pearson correlation between the error and these input features to identify systematic failure modes.
5.  **Submission**: Compare the calculated final metric against the threshold of `0.2251`. If the condition `metric < 0.2251` is met, trigger the `trainer.predict_test_set()` method to generate the `submission.csv` file for the test set.
