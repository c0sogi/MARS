The error `ValueError: cannot reshape array of size 0 into shape (0,newaxis)` occurs because the data loader attempts to process sequences with zero length (likely due to missing or empty input files). When `extract_len` is 0, the code proceeds to slice an empty array and attempts to reshape it using an inferred dimension (`-1`), which fails in the current NumPy environment. To fix this, I will implement an early return pattern in `GestureDataset.__getitem__`. If `extract_len` is 0, the method will immediately return a zero-padded tensor and background labels, bypassing the kinematic computation and reshaping logic entirely (Cite debug_lesson_20).
