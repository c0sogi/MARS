The following script demonstrates the end-to-end pipeline for the MS-TCN Gesture Recognition task using the provided library modules.

**Implementation Strategy:**
1.  **Configuration Setup**: We dynamically modify the `Config` class to set up a lightweight "demo" environment. This includes reducing the batch size, number of epochs, and defining a specific working directory for temporary outputs to avoid overwriting production files. We also set a small `DEBUG_SUBSET_SIZE` to ensure the data loading and feature extraction steps complete quickly.
2.  **Data Loading & Feature Verification**: We utilize `library.features` and `library.dataset` to load a small subset of the training data. We assert that the feature dimensions (Skeleton + Audio) and label structures are correct.
3.  **Model & Loss Verification**: We instantiate the `MSTCN` model and `ActionSegmentationLoss`. We pass a single batch of data through the model to verify the forward pass shapes (ensuring the multi-stage output is correct) and compute the loss to ensure the gradient graph is established correctly.
4.  **Training Loop**: We initialize the `Trainer` and run a single epoch of training (`fit`). We verify that the training process runs without error and produces a model checkpoint.
5.  **Inference & Submission**: We run the inference pipeline using the trained checkpoint on a subset of the test data. We verify that the output submission file is generated and adheres to the required CSV format (SessionID, List of Labels).
