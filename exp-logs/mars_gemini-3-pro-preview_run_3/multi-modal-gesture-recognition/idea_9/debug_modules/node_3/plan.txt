The issue stems from a device mismatch between the tensors used in the loss calculation. The `CascadedLoss` class automatically moves its internal class weights to the GPU if CUDA is available, but the demonstration code in `runfile.py` initializes the model, dummy inputs, and dummy targets on the CPU by default. When the loss function is invoked, PyTorch raises a `RuntimeError` because it cannot perform operations combining CPU tensors and GPU weights. To fix this, I will explicitly detect the available device in `runfile.py` and ensure the model, inputs, and targets are all moved to that device before the forward pass and loss computation.
