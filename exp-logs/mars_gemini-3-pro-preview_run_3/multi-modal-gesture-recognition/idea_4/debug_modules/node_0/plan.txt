The following code demonstrates the complete pipeline for the gesture recognition task using the provided library files. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration parameters to create a fast, lightweight demonstration run (fewer epochs, smaller batch size, temporary directories).
2.  **Data Preparation**: Creates a mini-subset of the provided metadata to ensure the feature engineering process runs quickly.
3.  **Feature Engineering**: Demonstrates how to extract multi-modal features (Skeleton + Audio) using `FeatureEngineer`.
4.  **Dataset & DataLoader**: Verifies the creation of PyTorch Datasets and DataLoaders for both windowed training and full-sequence validation.
5.  **Model Initialization**: Instantiates the `CascadedNet` and verifies the forward pass logic and output shapes.
6.  **Loss Calculation**: Computes the `CombinedLoss` on dummy data to verify the integration of Cross-Entropy and Smoothing losses.
7.  **Training Loop**: Runs a full training cycle (training and validation) using the `Trainer` class for a few epochs.
8.  **Inference**: Generates predictions on a test subset using the trained model and saves the submission file.
