The previous implementation of `save_submission` generated a "ragged" CSV file where the number of columns varied per row because it used commas to separate the list of predicted gesture IDs (e.g., `Sample1,1,2,3`). This caused the `InvalidSubmissionError` because standard CSV parsers expect a fixed number of columns. Additionally, the submission IDs were raw strings (e.g., "Sample00300") instead of the expected integers (e.g., 300) found in `randomPredictions.csv`.

To fix this, I will modify `library/utils.py` to:
1.  Use a space delimiter for the sequence of predictions so that the entire sequence is treated as a single column ("Sequence"), ensuring a rectangular CSV structure. Cite `debug_lesson_1`.
2.  Sanitize the `sample_id` by removing the "Sample" prefix and converting it to an integer to match the required format. Cite `debug_lesson_5`.
3.  Add the `Id,Sequence` header to the output file.

    Format: Id,Sequence
    where Sequence is a space-separated list of gesture IDs.
    """
