Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and modify its attributes at runtime to create a lightweight "demo" configuration. This includes setting `DEBUG` to `True`, reducing batch sizes, limiting epochs to 1, and redirecting output paths to a specific `./working/demo_execution` directory to ensure isolation.
2.  **Utility Verification**: Validate the core utility functions `set_seed`, `levenshtein_distance`, and `collapse_predictions` with assertions to ensure the helper logic is correct.
3.  **Data Loading Demonstration**: Call `get_dataloaders` with the debug configuration. Fetch a single batch of data to verify the tensor shapes of features, class targets, and boundary targets against the model's expected input dimensions.
4.  **Model and Loss Verification**: Instantiate the `BA_AKN` model and `BoundaryAwareLoss`. Perform a forward pass with the fetched batch, verify the output dictionary structure (deep supervision outputs), compute the loss, and perform a backward pass to ensure the computational graph is valid.
5.  **Training Loop Execution**: Initialize the `Trainer` class. Monkey-patch `tqdm` to disable progress bars as requested. Execute the `fit` method for one epoch to demonstrate the full training pipeline, including validation and checkpoint saving.
6.  **Inference Execution**: Call `run_inference` to generate predictions using the trained model (from the previous step) and verify that the submission file is created in the correct format.
