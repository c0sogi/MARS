Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class first and override `EPOCHS` to 25 and `DEBUG` to `False`. This ensures the training fits within the time limit while using the full dataset for maximum performance. This must be done before importing other modules to ensure default arguments in those modules pick up the modified configuration.
2.  **Training Orchestration**: Instantiate the `Trainer` class and call the `fit()` method. This handles the training loop, validation on window-level metrics, and saving the best model checkpoint.
3.  **Rigorous Validation**: Since the provided `Trainer` computes validation metrics on sliding windows, I will implement a dedicated validation loop that reconstructs full sequences from the windowed predictions. This is necessary to compute the exact Levenshtein distance metric required by the task description.
4.  **Failure Analysis**: During the rigorous validation loop, I will collect per-sequence error rates and meta-features (sequence length, number of gestures). I will then compute and print the Pearson correlation between the errors and these features to identify failure modes.
5.  **Submission Generation**: I will check if the computed `Final Validation Metric` is below the threshold of 0.2251. If satisfied, I will invoke the `run_inference()` function to generate the final `submission.csv`.
