The `ValueError: num_samples=0` is caused by the `_load_mat_robust` function failing to parse any `.mat` files, resulting in an empty dataset. The failure stems from attempting to access the dictionary returned by `scipy.io.loadmat` using `.__dict__` and dot notation (`mat.Video`), which raises an `AttributeError` that is silently caught. Furthermore, when `squeeze_me=True` is used, MATLAB structs are often loaded as 0-d NumPy arrays, which must be unwrapped using `.item()` to access their fields. The fix involves accessing the "Video" variable using dictionary syntax (Cite debug_lesson_2) and explicitly unwrapping the potential 0-d array (Cite debug_lesson_16) before checking for the `Frames` attribute.
