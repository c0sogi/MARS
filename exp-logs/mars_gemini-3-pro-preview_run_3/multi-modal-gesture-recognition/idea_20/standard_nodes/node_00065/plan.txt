The implementation strategy focuses on orchestrating the `LG-KRN` model training and evaluation using the provided modular library components.

1.  **Setup & Initialization**: We will initialize the random seeds for reproducibility and setup the logging environment. We will utilize the `GestureDataset` class to load training, validation, and test data, leveraging the pre-computed caches (`load_cache=True`) for efficiency.
2.  **Model & Training Loop**: We will instantiate the `LGKRN` model, `CascadedSmoothLoss`, and `Adam` optimizer. The training loop will run for a fixed number of epochs (defined in config), calling `train_one_epoch` and `evaluate` from `library.engine` at each step. We will implement a check to save the model state whenever the validation Levenshtein metric improves.
3.  **Inference & Analysis**:
    *   **Metric**: We will load the best saved model and re-evaluate it on the validation set to print the `Final Validation Metric`.
    *   **Failure Analysis**: We will implement a custom inference loop (reusing logic from `evaluate`) to extract per-sample predictions and Levenshtein errors. We will then calculate the Pearson correlation between the error magnitude and the sequence length (feature) using `numpy`.
4.  **Submission**: If the final validation metric is below the specified threshold (0.2251), we will run inference on the test set and generate the submission file using `generate_submission_file`.
