The previous implementation caused an `InvalidSubmissionError` because the generated CSV file was "ragged" (rows had varying numbers of columns due to comma-separated gesture lists) and used incorrect string identifiers (e.g., "Sample00300") instead of the required integer IDs (e.g., 300). To fix this, I will modify `library/predict.py` and `library/train.py` to sanitize the sample IDs using regular expressions (Cite debug_lesson_5) and format the gesture sequences as space-separated strings within a single CSV column (Cite debug_lesson_1), ensuring a valid `Id,Sequence` structure with a proper header.
