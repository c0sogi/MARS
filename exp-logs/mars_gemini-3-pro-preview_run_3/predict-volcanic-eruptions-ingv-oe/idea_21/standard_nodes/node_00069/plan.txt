Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and verify that the library modules are accessible.
2.  **Data Loading**: Use the `library.data_processor.load_data` function to load the feature-engineered datasets (`train_df`, `val_df`, `test_df`). This leverages the cached Parquet files for speed.
3.  **Model Training**: Invoke `library.model_trainer.train_model_cv` with the training dataframe. This trains a LightGBM ensemble using Stratified K-Fold Cross-Validation and returns the list of trained models.
4.  **Validation & Inference**:
    *   Apply the trained ensemble to the hold-out validation set (`val_df`).
    *   Compute the average prediction across all models.
    *   Calculate the Mean Absolute Error (MAE) as the final validation metric.
    *   Print the metric in the required format.
5.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample.
    *   Compute the correlation between the absolute error and all feature columns.
    *   Identify and print the features most strongly correlated with high prediction errors to understand failure modes.
6.  **Submission Generation**:
    *   Compare the validation metric against the specified threshold.
    *   If the metric is below the threshold, use `library.model_trainer.generate_submission` to predict on the test set and save the `submission.csv` file.
