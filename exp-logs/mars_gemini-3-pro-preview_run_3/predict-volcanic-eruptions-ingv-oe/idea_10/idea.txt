Based on the analysis of previous experiments and the specific lessons learned, I propose the **Peak-Aware Stacked Kinematic Ensemble**.

This strategy introduces a structural evolution by combining the robust generalization of a **Stacking Architecture** (attempted in Ideas 8/9 but failed due to feature engineering flaws) with a **Peak-Sensitive Feature Paradigm**. It explicitly corrects the "Robustness Overkill" observed in Lesson 00031, where removing raw extrema to reduce noise inadvertently destroyed the most critical seismic signals (peak intensity).

# Model
The predictive architecture will be a **Two-Level Stacking Ensemble**.
*   **Level 0 (Base Learners):** Three distinct Gradient Boosted Decision Tree (GBDT) implementations: **LightGBM**, **XGBoost**, and **CatBoost**.
    *   *Rationale:* GBDTs are the proven superior backbone for this dataset (Cite solution_lesson_node_00008). Using diverse implementations captures different aspects of the feature space (e.g., CatBoost's symmetric trees vs. LGBM's leaf-wise growth) to reduce the variance associated with single-model solutions like Idea 4.
*   **Level 1 (Meta Learner):** A **Ridge Regression** model.
    *   *Rationale:* This linear meta-learner optimally combines the Out-of-Fold (OOF) predictions from the base learners, correcting systematic biases without introducing the complexity or overfitting risk of a neural network meta-learner.

# Data
The feature engineering pipeline is the core innovation. It synthesizes the "Exploitation" of kinematic/spectral features with a critical "Correction" regarding signal extrema.

1.  **Preprocessing:**
    *   **Imputation:** Fill missing values with the segment-wise column mean to preserve DC offsets (Cite solution_lesson_node_00002).
    *   **Dual-Stream Processing:** The pipeline will process both **Raw** data and **Smoothed** data in parallel.
        *   *Smoothing:* Apply a **Savitzky-Golay filter** with a **large window size (> 20)** to create a smoothed stream. This is mandatory for derivative calculations to prevent noise amplification (Cite solution_lesson_node_00006, solution_lesson_node_00023).

2.  **Feature Engineering (Peak-Sensitive Paradigm):**
    *   **View 1: Raw Extrema (Correction):** From the **Raw** stream, explicitly calculate **Global Minimum**, **Global Maximum**, and **Peak-to-Peak Range** for each sensor.
        *   *Rationale:* Lesson 00031 demonstrated that in seismic prediction, "outliers" are the signal. Removing these in favor of robust statistics destroys information about peak ground acceleration/velocity, which encodes the event severity (Cite solution_lesson_node_00031).
    *   **View 2: Smoothed Kinematics (Exploitation):** From the **Smoothed** stream, compute First (Velocity) and Second (Acceleration) derivatives. Extract **Quantiles (1st, 99th)**, Mean, and Std.
        *   *Rationale:* Derivatives capture the rate of change (Cite solution_lesson_node_00021), while Quantiles provide stable shape descriptors superior to unstable higher-order moments like Skewness/Kurtosis (Cite solution_lesson_node_00026).
    *   **View 3: Structural Spectral Features (Retention):** Compute Power Spectral Density (PSD) and extract **Band Power** (Low/Mid/High) and **Spectral Centroid**. This captures harmonic tremors better than generic FFT stats (Cite solution_lesson_node_00007).
    *   **View 4: Flattened Temporal Windows (Retention):** Divide the signal into non-overlapping windows. Compute **RMS** and **Mean** for each.
        *   *Constraint:* **Flatten** these into explicit features (e.g., `w1_rms`, `w2_rms`) to preserve the temporal "arrow of time" (Cite solution_lesson_node_00010).
    *   **View 5: Spatial Concatenation (Retention):** Concatenate features from all 10 sensors into a single wide vector. Do **not** aggregate across sensors, preserving the spatial geometry (Cite solution_lesson_node_00018).

3.  **Feature Selection:**
    *   Feed the full feature set to the models. Do **not** use RFE, allowing the GBDTs to utilize distributed signal information (Cite solution_lesson_node_00017).

# Training
*   **Strategy:** Use **Stratified K-Fold Cross-Validation** (e.g., 5 folds) based on the provided metadata bins.
*   **Procedure:**
    1.  Train Base Learners (LGBM, XGB, CatBoost) on training folds using **MAE** objective.
    2.  Generate OOF predictions for the training set.
    3.  Train the Ridge Meta-Learner on OOF predictions.
    4.  Retrain Base Learners on the full training set.
*   **Optimization:** Use **Early Stopping** for base learners to prevent overfitting (Cite solution_lesson_node_00002).

# Evaluation
1.  **Feature Extraction:** Process the test set using the full pipeline: Imputation -> Raw Extrema Extraction -> Large-Window Smoothing -> Kinematic/Spectral/Windowed Extraction -> Concatenation.
2.  **Inference:**
    *   Generate predictions from the retrained Base Learners.
    *   Feed base predictions into the Ridge Meta-Learner to produce the final `time_to_eruption`.
