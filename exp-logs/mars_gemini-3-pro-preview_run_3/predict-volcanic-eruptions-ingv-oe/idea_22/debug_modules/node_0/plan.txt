4.  **Model Training and Inference**: We will instantiate the `ModelTrainer`. We will run the `train` method on a small subset of data (50 samples) to verify the training pipeline and model artifact generation. 5.  **Reproducibility**: We will set a fixed random seed at the start to ensure consistent results.
