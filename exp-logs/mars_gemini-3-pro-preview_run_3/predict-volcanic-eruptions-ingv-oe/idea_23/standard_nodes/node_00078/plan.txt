**Key Changes:**

2.  **Hierarchical Temporal Aggregation:** I will replace the flattened window features (e.g., `w0_rms`, `w1_rms`) with aggregated statistics of the window metrics (e.g., `win_rms_mean`, `win_rms_std`). This addresses Lesson 50, which highlights that shift-invariant aggregation is superior for random signal snapshots.
3.  **Refine Distributional Features:** Instead of a "dense grid" of quantiles, I will use a combination of standard moments (Mean, Std) and specific quantiles (tails) to capture the distribution robustly without excessive noise.

def compute_temporal_features(data, prefix):
    """
    Computes aggregated statistics over temporal windows (Shift Invariance).
    Cite solution_lesson_node_00050: Shift Invariance vs. Temporal Specificity.
    """
    features = {}
    # Split into windows
    windows = np.array_split(data, Config.NUM_TEMPORAL_WINDOWS)

    features[f"{prefix}_win_rms_min"] = np.min(win_rms)
    features[f"{prefix}_win_rms_max"] = np.max(win_rms)
    
    return features
