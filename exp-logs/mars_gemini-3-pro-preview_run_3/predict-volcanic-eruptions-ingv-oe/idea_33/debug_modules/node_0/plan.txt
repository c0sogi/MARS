This script demonstrates the end-to-end workflow using the provided library files. It performs the following steps:
1.  **Configuration Override**: Modifies the `MODEL_PARAMS` in memory to ensure the LightGBM model trains quickly (fewer trees, smaller capacity) for demonstration purposes.
2.  **Data Loading & Feature Engineering**: Uses `data_loader.build_dataset` to generate features for small subsets (`debug_size`) of the training, validation, and test sets. This exercises the parallel feature extraction pipeline in `features.py`.
3.  **Validation**: Asserts that the generated feature matrices have the expected dimensions and that target variables are loaded correctly.
4.  **Model Training**: Trains a LightGBM model using `model_handler.train_model` on the debug training set and evaluates it on the debug validation set.
5.  **Inference**: Generates predictions on the debug test set using `model_handler.predict_model`.
6.  **Submission**: Creates a sample submission file formatted correctly, verifying the output path.
