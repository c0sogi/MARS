The implementation strategy involves the following steps:

1.  **Setup and Imports**: Import necessary libraries and the provided modules (`library.config`, `library.data_loader`, `library.model_handler`). Set random seeds for reproducibility.
2.  **Data Loading**: Utilize `build_dataset` to load the training set (`train.csv`) and the hold-out validation set (`val.csv`). We will use the full datasets as the sample count (~3200) is small enough to process quickly within the time limit using the provided 12 vCPUs.
3.  **Model Training (Ensemble)**: Implement a Stratified K-Fold Cross-Validation loop (5 folds) on the training data. In each fold, train a High-Capacity LightGBM regressor using `train_model`. Store the trained models to form a homogeneous ensemble.
4.  **Validation & Inference**:
    *   Use the ensemble to predict on the hold-out validation set.
    *   Compute the average prediction across all 5 models.
    *   Calculate the Mean Absolute Error (MAE) and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Calculate the absolute errors on the validation set and compute the Pearson correlation between the error magnitude and each feature. Print the top 5 features most correlated with high errors to identify systematic weaknesses.
6.  **Submission Generation**:
    *   Compare the final validation MAE against the strict threshold (`2617304.0647319085`).
    *   If the model passes, load the test set using `build_dataset('test')`.
    *   Generate predictions using the ensemble (averaging outputs).
    *   Construct the submission DataFrame using `segment_id` from the test metadata and save it to `./submission/submission.csv`.
