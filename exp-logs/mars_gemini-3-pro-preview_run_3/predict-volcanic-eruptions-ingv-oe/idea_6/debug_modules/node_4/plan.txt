The issue is a `TypeError` caused by passing `early_stopping_rounds` to the `fit()` method of the `XGBRegressor`, which is no longer supported in the installed version of XGBoost (3.0.5). In newer versions of XGBoost, the `early_stopping_rounds` parameter must be passed to the **constructor** of the `XGBRegressor` class (or via the `callbacks` parameter), rather than as an argument to `fit()`.

I will fix this by modifying `library/model_trainer.py` to pass `early_stopping_rounds` during the initialization of the `XGBRegressor` model and remove it from the `fit()` call. This change aligns the code with the environment's library version capabilities (Cite debug_lesson_3).
