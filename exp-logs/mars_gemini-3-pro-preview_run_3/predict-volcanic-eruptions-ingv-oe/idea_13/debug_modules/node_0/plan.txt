The following script demonstrates the usage of the provided machine learning library for the volcano eruption prediction task.

### Implementation Strategy
1.  **Configuration & Patching**: To ensure the demonstration runs quickly (within the time limit) and uses minimal resources, we monkey-patch the configuration parameters. We reduce the number of estimators for LightGBM/XGBoost to 10 and set the number of Cross-Validation folds to 2.
2.  **Data Processing**: We utilize the `DatasetBuilder` class from `library.data_processor` to load a small subset (`debug_size=10`) of the training data. This demonstrates the parallel feature extraction pipeline and the caching mechanism.
3.  **Feature Extraction**: We manually load a raw sensor file and pass it through `library.feature_extraction.process_segment` to verify the signal processing logic (Savitzky-Golay filtering, spectral analysis, etc.) produces the expected feature vector.
4.  **Model & Stacking**: We instantiate the `StackingTrainer` from `library.stacking_engine`. We run the full pipeline: training the base layer (generating OOF predictions), training the meta-learner (Ridge), retraining base models on the full subset, and generating final predictions.
5.  **Validation**: Throughout the script, `assert` statements are used to verify data shapes, type consistency, and pipeline integrity.
