Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose the **Hierarchical Siamese-Stacking with Dual-Stream Signal Processing** strategy.

This approach introduces a **Structural Innovation** by reshaping the learning problem: instead of treating the 10 sensors solely as a single concatenated vector (which creates high dimensionality with limited samples), it first employs a **Siamese Sensor Encoder** to learn generalized seismic patterns from individual sensor traces (augmenting the data 10x). This is coupled with a **Dual-Stream Feature Pipeline** that rigorously applies the noise-suppression and peak-preservation lessons from previous failures.

# Model
The architecture is a **Three-Stage Hierarchical Ensemble**:

1.  **Stage 1: Siamese Sensor Encoder (Dimensionality Reduction & Feature Learning)**
    *   **Architecture:** A single **LightGBM Regressor** shared across all sensor positions.
    *   **Input:** A feature vector representing a *single* sensor channel.
    *   **Innovation:** The training data is reshaped from `(N_segments, 10_sensors, Features)` to `(N_segments * 10, Features)`. This effectively increases the training set size by an order of magnitude, allowing the model to learn robust, universal seismic precursors (e.g., "what does a tremor look like?") without overfitting to specific sensor IDs (Cite solution_lesson_node_00002).
    *   **Output:** A predicted `time_to_eruption` for each of the 10 sensors.

2.  **Stage 2: Spatially-Coupled Stacking (Exploitation)**
    *   **Architecture:** A Heterogeneous Ensemble of **LightGBM**, **XGBoost**, and **CatBoost**.
    *   **Input:** A "Super-Vector" constructed by concatenating:
        *   The 10 individual predictions from Stage 1 (preserving spatial identity, Cite solution_lesson_node_00018).
        *   Statistical aggregates of these 10 predictions (Mean, Max, Std) to capture consensus and array-wide divergence.
        *   The full original concatenated feature vectors for all 10 sensors (Exploitation of Idea 10).
    *   **Rationale:** This allows the model to leverage both high-level "meta-features" (Stage 1 predictions) and low-level signal details, adhering to the lesson that GBDTs handle high dimensionality well without external selection (Cite solution_lesson_node_00017).

3.  **Stage 3: Meta-Learner**
    *   **Architecture:** A **Ridge Regression** model.
    *   **Function:** Linearly combines the Stage 2 predictions to correct systematic biases and minimize variance (Cite solution_lesson_node_00008).

# Data
The data processing pipeline implements the **Dual-Stream** paradigm to satisfy conflicting requirements (Noise Suppression vs. Peak Preservation).

1.  **Preprocessing:**
    *   **Imputation:** Fill missing values with segment-wise means to preserve DC offsets (Cite solution_lesson_node_00002).
    *   **Stream A (Raw):** Retain raw data for extremum extraction.
    *   **Stream B (Smoothed):** Apply a **Savitzky-Golay filter** with a **large window size (> 20)** to all sensors. This is mandatory to prevent noise amplification in derivative calculations (Cite solution_lesson_node_00006, solution_lesson_node_00023).

2.  **Feature Engineering (Per-Sensor):**
    *   **View 1: Raw Extrema (From Stream A):** Extract **Global Minimum**, **Global Maximum**, and **Peak-to-Peak Range**. This strictly adheres to the lesson that "outliers are the signal" in seismic prediction (Cite solution_lesson_node_00031).
    *   **View 2: Robust Kinematics (From Stream B):** Compute First (Velocity) and Second (Acceleration) derivatives. Extract **Quantiles (1st, 99th)**, Mean, and RMS. This discards unstable higher-order moments (Skew/Kurtosis) in favor of robust shape descriptors (Cite solution_lesson_node_00026, solution_lesson_node_00021).
    *   **View 3: Structural Spectral Features (From Stream A):** Compute PSD and extract **Band Power** (Low/Mid/High) and **Spectral Centroid** (Cite solution_lesson_node_00007).
    *   **View 4: Flattened Temporal Windows (From Stream A):** Divide signal into non-overlapping windows. Compute **RMS** and **Mean**. Flatten these into explicit features (e.g., `w1_rms`) to preserve the "arrow of time" (Cite solution_lesson_node_00010).

3.  **Feature Organization:**
    *   For Stage 1, features are generated per sensor.
    *   For Stage 2, features from all 10 sensors are **concatenated** side-by-side (Cite solution_lesson_node_00018).

# Training
1.  **Stage 1 Training:**
    *   Reshape training data to `(N_samples * 10, N_features)`.
    *   Use **GroupKFold** (grouped by `segment_id`) for Cross-Validation. This is critical to ensure that if Sensor 1 of Segment A is in the validation set, Sensor 2 of Segment A is *not* in the training set, preventing leakage.
    *   Objective: MAE.

2.  **Stage 2 Training:**
    *   Generate Out-of-Fold (OOF) predictions using the Stage 1 model.
    *   Construct the Stage 2 input dataset (Stage 1 OOFs + Raw Features).
    *   Train LGBM, XGB, and CatBoost using **StratifiedKFold** (based on target bins).
    *   Use **Early Stopping** (Cite solution_lesson_node_00002).

3.  **Stage 3 Training:**
    *   Train Ridge Regression on Stage 2 OOF predictions.

# Evaluation
1.  **Feature Extraction:** Process test files through the Dual-Stream pipeline (Imputation -> Smoothing -> Feature Calculation).
2.  **Stage 1 Inference:** Pass each sensor's features through the Siamese Encoder to get 10 initial predictions per segment.
3.  **Stage 2 Inference:** Concatenate Stage 1 predictions with the full feature set. Pass through the Stage 2 Ensemble (LGBM, XGB, CatBoost).
4.  **Stage 3 Inference:** Aggregate Stage 2 outputs using the Ridge Meta-Learner.
5.  **Submission:** Format as `segment_id,time_to_eruption`.
