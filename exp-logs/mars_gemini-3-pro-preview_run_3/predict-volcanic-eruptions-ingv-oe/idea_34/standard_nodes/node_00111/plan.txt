The `AttributeError` occurs because the `LGBMRegressorWrapper` in `library/model_handler.py` attempts to access `REG_ALPHA` and `REG_LAMBDA` from the configuration object, but these parameters are not defined in `library/config.py`. This mismatch between the consumer code and the configuration definition violates the requirement to synchronize dependencies (Cite debug_lesson_6). I will fix this by adding the missing `REG_ALPHA` and `REG_LAMBDA` attributes to the `Config` class in `library/config.py`, initializing them with a default value of 0.0.
