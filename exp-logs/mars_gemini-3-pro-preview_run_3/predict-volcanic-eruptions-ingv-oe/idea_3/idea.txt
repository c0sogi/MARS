Based on the lessons learned from the previous experiments, I propose a **Multi-Modal Heterogeneous Ensemble** strategy. This approach combines the efficiency and interpretability of the feature-based Gradient Boosting model (Exploitation) with the pattern-recognition capabilities of a Deep Convolutional Neural Network (Innovation).

# Model

The solution will consist of two distinct predictive streams whose outputs are ensembled:

1.  **Stream A: Feature-Based LightGBM (Exploitation)**
    *   This stream retains the Gradient Boosting Decision Tree (GBDT) architecture. It is designed to leverage the statistical descriptors that have proven effective in establishing a strong baseline (Cite solution_lesson_node_00002).
    *   The model will use a `LightGBMRegressor` with a high number of estimators, as previous experiments showed that limiting the iteration count prematurely caps performance (Cite solution_lesson_node_00002).

2.  **Stream B: Spectrogram-Based 2D CNN (Structural Innovation)**
    *   To address the limitation that global statistics obscure complex signal evolution (Cite solution_lesson_node_00005), this stream introduces a **2D Convolutional Neural Network (e.g., ResNet18 or EfficientNet-B0)**.
    *   Instead of raw waveforms, the input will be **Log-Mel Spectrograms**. This representation explicitly encodes the "Time-Frequency" information required to capture seismic precursors (Cite solution_lesson_node_00005) and preserves the "structural" location of energy in specific frequency bands (Cite solution_lesson_node_00007) as spatial features in the image.

# Data

The data processing pipeline will diverge for the two streams to maximize the information extracted from the sensor logs:

1.  **Common Preprocessing**
    *   **Imputation:** For both streams, missing values (NaNs) in sensors will be filled with the segment-wise column mean to preserve the DC offset without introducing zero-filling artifacts (Cite solution_lesson_node_00002).

2.  **Stream A (Tabular Features)**
    *   **Global Statistics:** Calculate Mean, Std, Skewness, Kurtosis, and Quantiles for the entire segment (Cite solution_lesson_node_00002).
    *   **Structural Spectral Features:** Compute the Power Spectral Density (PSD) using Welch's method. Extract **Band Power** (energy in specific frequency ranges) and **Spectral Centroid**, rather than generic statistics of the FFT magnitude, to capture physically meaningful tremors (Cite solution_lesson_node_00007).
    *   **Windowed Temporal Features:** Divide the signal into non-overlapping windows and compute local statistics (Mean, Std) to capture the temporal evolution and non-stationarity of the signal (Cite solution_lesson_node_00005).
    *   **Smoothing:** Apply a Savitzky-Golay filter before computing any derivative-based features (if used) to prevent the amplification of high-frequency noise (Cite solution_lesson_node_00006).

3.  **Stream B (Spectrogram Generation)**
    *   **Transformation:** Convert the 10-channel time-series data into 10-channel Log-Mel Spectrograms using Short-Time Fourier Transform (STFT). The windowing inherent in STFT acts as a low-pass filter, mitigating the noise issues observed with raw derivatives (Cite solution_lesson_node_00006).
    *   **Normalization:** Normalize the spectrograms (e.g., to dB scale) to ensure stable training for the CNN.

# Training

1.  **Stream A (LightGBM):**
    *   Train using the Mean Absolute Error (MAE) objective.
    *   Utilize Early Stopping based on the validation set to prevent overfitting, while allowing a high maximum `n_estimators` (e.g., 10,000) to ensure convergence (Cite solution_lesson_node_00002).

2.  **Stream B (CNN):**
    *   Train using the MAE loss function (L1 Loss).
    *   Use the AdamW optimizer with a "ReduceLROnPlateau" or Cosine Annealing scheduler to fine-tune the weights.
    *   Apply moderate image augmentation (e.g., Time Masking, Frequency Masking) to improve robustness given the small dataset size.

# Evaluation

1.  **Inference:**
    *   For each test segment, generate tabular features for Stream A and spectrograms for Stream B.
    *   Obtain predictions $P_A$ (LightGBM) and $P_B$ (CNN).
2.  **Ensemble:**
    *   Compute the final prediction as a weighted average: $P_{final} = \alpha P_A + (1-\alpha) P_B$. The weight $\alpha$ (e.g., 0.5) will be determined based on validation performance. This combines the robust statistical baseline with the deep pattern recognition of the CNN.
