The following script demonstrates the end-to-end pipeline for the seismic eruption prediction task using the provided library.

**Strategy:**
1.  **Configuration & Setup**: We override specific configuration constants (e.g., `EPOCHS`, `DEBUG_SAMPLE_SIZE`) to ensure the script runs quickly (under a few minutes) while still executing the full logic.
2.  **Data Preparation (Stream A - Tabular)**: We create small "mini" metadata files to simulate the dataset. We then use `process_tabular_data` to generate statistical features from the raw sensor logs.
3.  **Model Training (Stream A - LightGBM)**: We train a LightGBM regressor on the tabular features with reduced estimators.
4.  **Data Preparation (Stream B - CNN)**: We utilize the `get_spectrogram_loaders` function with `debug=True` to load a small subset of spectrograms on-the-fly.
5.  **Model Training (Stream B - CNN)**: We instantiate the `SeismicCNN` and run a short training cycle (1 epoch) using `run_cnn_training`.
6.  **Inference & Ensemble**: We generate predictions from both models on a test subset and combine them using the defined ensemble weights to produce a final submission file.
7.  **Validation**: Throughout the script, assertions verify data shapes, model outputs, and file generation.
