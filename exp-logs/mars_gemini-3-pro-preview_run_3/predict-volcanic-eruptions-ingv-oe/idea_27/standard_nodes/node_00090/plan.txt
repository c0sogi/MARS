Implementation Strategy:
1.  **Setup**: Initialize the environment, set random seeds, and import necessary modules from the provided `library`.
2.  **Data Loading**: Load the `train` and `val` metadata separately using `library.utils.load_metadata`. This ensures a strict separation between the training data and the hold-out validation set.
3.  **Feature Engineering**: Generate feature matrices for both the training and validation sets using `library.features.create_feature_matrix`. This leverages the caching mechanism to save time.
4.  **Model Training**:
    *   Instantiate the `library.model.EnsembleManager`.
    *   Instead of using the manager's default `train_loop` (which combines train and val), implement a custom Stratified K-Fold loop on the **training set only**.
    *   Train a LightGBM model for each fold using `library.model.train_lgbm_fold` and add it to the ensemble.
5.  **Validation**:
    *   Use the trained ensemble to predict on the hold-out validation set.
    *   Calculate the Mean Absolute Error (MAE) using `library.utils.calculate_mae`.
    *   Print the result in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample.
    *   Compute and print the correlation between the error magnitude and the input features to identify sources of systematic error.
7.  **Submission**:
    *   Compare the validation MAE against the specified threshold.
    *   If the metric is sufficient, use `ensemble.predict_average()` to generate predictions for the test set and save the `submission.csv`.
