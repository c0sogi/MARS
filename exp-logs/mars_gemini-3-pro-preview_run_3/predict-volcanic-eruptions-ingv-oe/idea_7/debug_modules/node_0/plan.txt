This script demonstrates the usage of the provided library modules for seismic data analysis. It covers feature extraction, dataset loading, model training (LightGBM and XGBoost), and the execution of a full stratified cross-validation pipeline.

The implementation strategy is as follows:
1.  **Environment Setup**: Fix random seeds and import necessary library functions.
2.  **Feature Extraction**: Process a single segment from the metadata to verify that the `extract_segment_features` function correctly computes kinematic, spectral, and temporal features.
3.  **Dataset Loading**: Retrieve a small debug subset (20 samples) of the training and test data using `get_train_data` and `get_test_data` to verify data shapes and integrity.
4.  **Model Verification**: Instantiate and train LightGBM and XGBoost models on the debug data to ensure they fit and predict without errors.
5.  **Full Pipeline**: Execute `run_stratified_cv` with minimal hyperparameters (low estimators, small data subset) to verify the end-to-end workflow, including cross-validation and submission file generation.
6.  **Validation**: Use assertions throughout to strictly validate outputs.
