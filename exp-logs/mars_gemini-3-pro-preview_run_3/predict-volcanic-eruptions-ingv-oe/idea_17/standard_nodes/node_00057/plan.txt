Based on the lessons learned, I will optimize the solution by reverting to a physics-based feature engineering strategy that prioritizes signal decomposition and shift-invariant temporal statistics over perceptual audio features and spatial pooling.

**Strategy:**
1.  **Remove MFCCs**: As noted in **Cite solution_lesson_node_00056**, perceptual audio features like MFCCs are misaligned with seismic data and introduce noise. I will remove them entirely.
2.  **Signal Decomposition**: I will implement the Trend/Texture decomposition strategy (**Cite solution_lesson_node_00049**). The signal will be split into a low-frequency Trend (via Savitzky-Golay) and a high-frequency Texture (residuals).
    - **Trend**: Calculate robust quantiles and kinematic derivatives (Velocity, Acceleration) to capture movement dynamics (**Cite solution_lesson_node_00021**).
    - **Texture**: Calculate statistical moments (RMS, Skew, Kurtosis) to capture signal complexity/roughness.
3.  **Shift-Invariant Temporal Statistics**: Instead of flattening window statistics (e.g., `w0_mean`, `w1_mean`) which assumes temporal alignment, I will aggregate them (e.g., `mean_of_window_means`, `std_of_window_means`) to capture the signal's volatility over time regardless of the start point (**Cite solution_lesson_node_00050**).
4.  **Remove Spatial Aggregation**: I will stop pooling statistics across sensors (e.g., `spatial_mean_std`) to preserve the spatial geometry of the array (**Cite solution_lesson_node_00018**).
5.  **Hyperparameters**: I will slightly increase the learning rate to `0.01` to ensure convergence with the refined feature set.

def get_mfcc(signal_np, sr=SAMPLE_RATE, n_mfcc=MFCC_N_MFCC):
    """
    Compute MFCCs using Torchaudio for a 1D numpy signal.
    """
    # Ensure input is long enough for FFT
    if len(signal_np) < N_FFT:
        return np.zeros(n_mfcc)

    tensor = torch.from_numpy(signal_np).float()

    # Define MFCC transform
    transform = torchaudio.transforms.MFCC(
        sample_rate=sr,
        n_mfcc=n_mfcc,
        melkwargs={
            "n_fft": N_FFT,
            "hop_length": HOP_LENGTH,
            "n_mels": 23,
            "center": False,
        },
    )

    # Compute MFCCs: Output shape (n_mfcc, time)
    mfcc = transform(tensor)

    # Return mean over time dimension to get a fixed-size vector
    return torch.mean(mfcc, dim=1).numpy()

    Extracts features for a single sensor using Signal Decomposition (Trend/Texture).
    """

    # --- View A: Trend (Kinematics) ---
    # Savitzky-Golay Filter (Low-Pass)
    trend = savgol_filter(signal, window_length=SAVGOL_WINDOW, polyorder=SAVGOL_POLY)

    # Derivatives of Trend
    vel = np.gradient(trend)
    acc = np.gradient(vel)

    # Trend Statistics
    features[f"{sensor_name}_trend_mean"] = np.mean(trend)
    features[f"{sensor_name}_trend_std"] = np.std(trend)
    
    # Quantiles on Trend (Robust)
    q01, q05, q95, q99 = np.quantile(trend, [0.01, 0.05, 0.95, 0.99])
    features[f"{sensor_name}_trend_q01"] = q01
    features[f"{sensor_name}_trend_q05"] = q05
    features[f"{sensor_name}_trend_q95"] = q95
    features[f"{sensor_name}_trend_q99"] = q99

    # Kinematic Statistics (on Trend)
    features[f"{sensor_name}_vel_std"] = np.std(vel)
    features[f"{sensor_name}_vel_max"] = np.max(np.abs(vel))
    features[f"{sensor_name}_acc_std"] = np.std(acc)
    features[f"{sensor_name}_acc_max"] = np.max(np.abs(acc))

    # --- View B: Texture (High-Frequency Residual) ---
    residual = signal - trend

    # Moments on Texture (Shape)
    features[f"{sensor_name}_txt_rms"] = np.sqrt(np.mean(residual**2))
    features[f"{sensor_name}_txt_skew"] = skew(residual)
    features[f"{sensor_name}_txt_kurt"] = kurtosis(residual)

    # --- View C: Spectral (Energy) ---
    # Welch's Method
    freqs, psd = welch(signal, fs=sr, nperseg=1024)
    features[f"{sensor_name}_psd_low"] = np.sum(psd[freqs < 2])
    features[f"{sensor_name}_psd_mid"] = np.sum(psd[(freqs >= 2) & (freqs < 10)])
    features[f"{sensor_name}_psd_high"] = np.sum(psd[freqs >= 10])
    features[f"{sensor_name}_psd_centroid"] = get_spectral_centroid(freqs, psd)

    # --- View D: Temporal Evolution (Shift-Invariant) ---
    # Split into 10 chunks
    chunks = np.array_split(signal, 10)
    chunk_means = []

        chunk_stds.append(np.std(chunk))
    
    # Aggregated Window Statistics (Shift Invariance)

    features[f"{sensor_name}_win_mean_range"] = np.ptp(chunk_means)
    features[f"{sensor_name}_win_std_mean"] = np.mean(chunk_stds)
    features[f"{sensor_name}_win_std_std"] = np.std(chunk_stds)

    return features
