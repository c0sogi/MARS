To improve the model's performance, I will refine the feature engineering pipeline by removing noise-sensitive and domain-incompatible features while strengthening the robust extraction of physical signal properties. Specifically, I will remove Mel-Frequency Cepstral Coefficients (MFCCs) as they are designed for human audio perception and have proven ineffective for seismic data (Cite solution_lesson_node_00056). I will also remove acceleration features (second derivatives) to reduce noise amplification, relying instead on velocity (Cite solution_lesson_node_00054). Furthermore, I will switch from flattened temporal window features to aggregated window statistics to ensure shift invariance (Cite solution_lesson_node_00050), and apply higher-order moments (skew, kurtosis) specifically to the signal texture (residuals) while using robust quantiles for the trend (Cite solution_lesson_node_00049).

def get_mfcc(signal_np, sr=SAMPLE_RATE, n_mfcc=MFCC_N_MFCC):
    """
    Compute MFCCs using Torchaudio for a 1D numpy signal.
    """
    # Ensure input is long enough for FFT
    if len(signal_np) < N_FFT:
        return np.zeros(n_mfcc)

    tensor = torch.from_numpy(signal_np).float()

    # Define MFCC transform
    transform = torchaudio.transforms.MFCC(
        sample_rate=sr,
        n_mfcc=n_mfcc,
        melkwargs={
            "n_fft": N_FFT,
            "hop_length": HOP_LENGTH,
            "n_mels": 23,
            "center": False,
        },
    )

    # Compute MFCCs: Output shape (n_mfcc, time)
    mfcc = transform(tensor)

    # Return mean over time dimension to get a fixed-size vector
    return torch.mean(mfcc, dim=1).numpy()
