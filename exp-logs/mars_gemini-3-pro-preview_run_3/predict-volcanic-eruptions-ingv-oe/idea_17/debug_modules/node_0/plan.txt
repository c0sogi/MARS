This script demonstrates the end-to-end usage of the provided machine learning pipeline components. It covers data loading with feature extraction, model training using cross-validation, and submission generation.

To ensure the demonstration runs quickly (within the time limit) while using the provided library files without modification, the script dynamically adjusts hyperparameters (like `N_ESTIMATORS`) by patching the imported module variables before execution. It uses a small subset of the data (`debug_size=20`) to verify the logic of the feature engineering and training pipelines.
