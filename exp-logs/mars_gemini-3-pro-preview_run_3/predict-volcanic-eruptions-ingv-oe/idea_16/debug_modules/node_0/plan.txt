Implementation Strategy:
1.  **Environment Setup**: Import necessary standard libraries and the provided custom library modules (`library.config`, `library.utils`, `library.data_loader`, `library.model_trainer`).
2.  **Configuration Patching**: To ensure the demonstration runs quickly and respects the time limit, I will monkey-patch the global constants in `library.model_trainer` (specifically `N_ESTIMATORS` and `EARLY_STOPPING_ROUNDS`) and update the `LGBM_PARAMS` dictionary in `library.config` to suppress verbose logging.

4.  **Model Training Demonstration**:
    *   **Single Fold**: Manually split the loaded training subset and train a LightGBM model using `library.model_trainer.train_lgbm_fold`. Verify the model object and its ability to predict.
    *   **Cross-Validation**: Create a synthetic dataset by replicating the small training subset (to ensure enough samples for stratified splitting). Run `library.model_trainer.run_stratified_cv` to demonstrate the full CV pipeline, including OOF predictions and test set inference.
5.  **Submission Generation**: Use the predictions from the CV step to generate a submission file using `library.model_trainer.generate_submission` and verify its creation.
6.  **Utility Demonstration**: Demonstrate the `save_artifact` and `load_artifact` functions from `library.utils` using a temporary file.
7.  **Assertions**: Throughout the script, I will use `assert` statements to strictly validate the logic and expected outputs.
