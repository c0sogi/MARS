The error occurs because the `impute_missing` function in `library/features.py` relies solely on `df.fillna(df.mean())`. When a sensor column contains only `NaN` values (e.g., a dead sensor), `df.mean()` returns `NaN` for that column, causing `fillna` to have no effect. This leaves `NaN`s in the data, which subsequently causes the `LinearRegression` fit in `compute_trend_profiling` to fail with `ValueError: Input y contains NaN`, leading to dropped samples and an assertion failure.

To fix this, I will update `impute_missing` in `library/features.py` to chain a `.fillna(0)` call. This ensures that any columns remaining `NaN` after mean imputation (due to being entirely empty) are filled with zeros, preventing downstream numerical errors.
