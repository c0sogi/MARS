Implementation strategy:
1.  **Environment Setup**: Initialize random seeds for reproducibility and import necessary libraries, including the provided helper modules (`library.config`, `library.data_loader`, `library.model_engine`, `library.utils`).
2.  **Data Loading**: Use `build_feature_dataset` to load the training and validation features. This leverages the caching mechanism (`load_cached_data=True`) to speed up execution if features were previously computed.
3.  **Model Training**: Execute the 5-Fold Cross-Validation training pipeline (`run_cross_validation`) using strictly the **training set**. This produces an ensemble of 5 LightGBM models. We exclude the validation set from training to ensure a strict hold-out evaluation as required by the prompt.
4.  **Validation & Evaluation**:
    *   Generate predictions on the **hold-out validation set** using the trained ensemble.
    *   Compute the Mean Absolute Error (MAE).
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample.
    *   Compute the Pearson correlation between the error magnitude and each input feature.
    *   Print the top 10 features most strongly correlated with the error to identify systematic weaknesses.
6.  **Submission**:
    *   Compare the validation MAE against the specified threshold (`2617304.0647319085`).
    *   If the model performs sufficiently well, load the test set features.
    *   Generate predictions for the test set using the ensemble.
    *   Save the results to `./submission/submission.csv` in the required format (`segment_id,time_to_eruption`).
