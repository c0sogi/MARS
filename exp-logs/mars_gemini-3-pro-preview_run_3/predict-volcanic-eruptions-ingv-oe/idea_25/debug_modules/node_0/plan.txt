The implementation strategy involves creating a single Python script that orchestrates the entire pipeline using the provided library modules. To ensure speed and correctness, the script will:

1.  **Setup & Configuration**: Import the `Config` class and override settings to run in "Debug" mode. This includes reducing the number of data samples processed, minimizing the number of Cross-Validation folds to 2, and adjusting LightGBM hyperparameters (fewer trees, smaller leaves) for rapid training.
2.  **Feature Generation**: Use `generate_dataset` from `library.dataset` to create feature matrices for both training and test sets. We will force `load_cached_data=False` to verify the feature extraction logic in `library.features` actually runs without errors. Assertions will verify the shape and consistency of the generated DataFrames.
3.  **Model Training**: Instantiate the `EnsembleTrainer` from `library.trainer`. We will train the model on the generated training data. Assertions will check that the Out-of-Fold (OOF) predictions are generated and that model files are correctly saved to the working directory.
4.  **Inference**: Use the trained `EnsembleTrainer` to predict on the test set. Assertions will ensure predictions are finite and match the expected dimensions.
5.  **Submission**: Use `save_submission` from `library.utils` to generate the final CSV. We will read this file back to verify it adheres to the required format.
