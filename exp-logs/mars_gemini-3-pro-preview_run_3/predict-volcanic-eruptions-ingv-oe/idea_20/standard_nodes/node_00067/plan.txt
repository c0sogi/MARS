To improve the model's performance and address the severe overfitting observed in the previous run (Train L1: ~50k vs Val L1: ~3M), I will implement the following optimizations based on the provided lessons:

1.  **Trend-Texture Decomposition (Cite Lesson 00049):** I will explicitly decompose the sensor signals into a "Trend" component (using a Savitzky-Golay filter) and a "Texture" component (residuals).
    *   **Kinematic Features** (Velocity, Acceleration) will continue to be derived from the Trend (via `savgol_filter` derivatives).
    *   **Texture Features** (RMS, Skewness, Kurtosis) will be calculated on the high-frequency residuals. This separates the signal's trajectory from its roughness, allowing the model to learn distinct physical properties.

2.  **Aggregated Window Statistics (Cite Lesson 00050):** The previous solution flattened window statistics into distinct features (e.g., `w0_rms`, `w1_rms`), which caused overfitting to specific temporal positions and increased feature dimensionality. I will replace this with **aggregated** window statistics (e.g., `win_rms_mean`, `win_rms_std`) to ensure shift-invariance and reduce the feature count.

3.  **Increased Regularization (Cite Lesson 00064):** To combat the massive generalization gap, I will significantly increase the LightGBM regularization parameters (`lambda_l1`, `lambda_l2`, `min_data_in_leaf`) and reduce the model capacity (`num_leaves`, `feature_fraction`).
