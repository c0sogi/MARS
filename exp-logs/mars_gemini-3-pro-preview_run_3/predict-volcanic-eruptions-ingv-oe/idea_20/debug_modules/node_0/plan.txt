The following script demonstrates the complete usage of the provided library files for the Volcano Eruption Prediction task.

**Implementation Strategy:**
1.  **Configuration Override**: We import the `Config` class and dynamically modify its attributes (paths and hyperparameters) to create a fast, isolated demonstration environment (`./working/demo_run`). This prevents interference with existing data and ensures the script runs in seconds.
2.  **Feature Engineering Verification**: We utilize `library.feature_engineering.generate_features` with a strict `debug_limit` to process a tiny subset of the data. We assert that the output DataFrame has the correct dimensions and contains the expected kinematic, texture, and spectral features.
3.  **Data Loading Verification**: We use `library.data_loader.create_dataset` to load the cached features into NumPy arrays, verifying shapes and checking for NaN values.
4.  **Model Logic Verification**: We instantiate `library.model.VolcanoLGBM`, train it on a minimal split of the data, and verify that it produces valid, finite predictions and saves the model artifact.
5.  **Full Pipeline Verification**: We execute `library.trainer.train_and_predict`, which orchestrates the entire workflow (Data Loading -> Stratified CV -> Ensemble Prediction -> Submission). We verify the final MAE score and the format of the generated submission CSV.
