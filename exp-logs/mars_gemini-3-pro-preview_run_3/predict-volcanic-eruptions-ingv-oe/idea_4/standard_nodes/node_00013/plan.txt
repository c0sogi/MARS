2.  **Feature Engineering Cleanup**:
    *   **Removing Kinematics**: Eliminating the calculation of velocity and acceleration derivatives and the associated Savitzky-Golay smoothing. Citing **Lesson 12**, differentiation amplifies high-frequency noise, and these features were shown to degrade performance.
    *   **Removing High-Order Moments**: Removing Skewness and Kurtosis from the statistical summary. **Lesson 12** indicates these complexity metrics can cause the model to memorize noise texture rather than signal dynamics.
    *   **Refining Spectral Features**: Adding a "Mid" frequency band power feature. The previous solution only captured Low (0-20%) and High (80-100%) bands. Capturing the middle band ensures the model has a complete view of the energy distribution, aligning with **Lesson 7**.
3.  **Threshold Update**: Updating the submission threshold in `runfile.py` to the previous best validation MAE (~2,739,761) to ensure we only submit if we improve.

def compute_kinematics(smoothed_data):
    """
    Computes first (velocity) and second (acceleration) derivatives.
    """
    velocity = np.gradient(smoothed_data, axis=0)
    acceleration = np.gradient(velocity, axis=0)
    return velocity, acceleration

    """
    Calculates basic statistics for a given array.
    Returns a dictionary.
