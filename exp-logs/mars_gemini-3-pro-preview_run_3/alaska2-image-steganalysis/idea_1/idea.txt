To address the task of detecting hidden messages in JPEG images, I propose a baseline approach that prioritizes simplicity, speed, and robustness. This solution, the **Mono-Residual ResNet**, focuses on the luminance channel and uses a single, fixed high-pass filter to expose noise artifacts, avoiding the complexity of large filter banks or heavy transformer architectures.

# Model
**Architecture: Mono-Residual ResNet**
The model is constructed using a standard **ResNet-18** backbone, chosen for its balance between inference speed and feature extraction capability. The architecture is modified as follows:
1.  **Input Adaptation**: The network accepts a single-channel input corresponding to the **Luminance (Y)** channel of the image. Steganographic signals in JPEGs are predominantly hidden in the luminance component, making color channels (Cb, Cr) less critical for a baseline.
2.  **Fixed Residual Layer**: A non-trainable preprocessing layer is prepended to the network. This layer consists of a single **$5 \times 5$ High-Pass Filter (KV Kernel)**. Unlike Model 1 which uses a bank of 30 filters, this baseline uses just one standard steganalysis kernel to suppress image content and isolate the noise residual (the "stego signal").
3.  **Backbone**: The filtered output is passed to a ResNet-18. If using ImageNet pretrained weights, the weights of the first convolutional layer (originally 3 channels) are summed to accommodate the single-channel input.
4.  **Output**: A final fully connected layer outputs a single scalar logit representing the likelihood of the image containing a hidden message.

# Data
**Preprocessing**
1.  **Channel Extraction**: For every image, convert the RGB input to the **YCbCr** color space and extract only the **Y (Luminance)** channel. This reduces the input data volume by 3x compared to RGB models.
2.  **Normalization**: The pixel values are normalized to the range `[0, 1]`. The High-Pass Filter in the model will naturally handle the centering of the residuals.

**Augmentation**
To preserve the delicate steganographic signal (which is often grid-aligned due to JPEG compression), destructive geometric transformations are avoided.
1.  **Training**: Apply **Dihedral Group** augmentations: random horizontal/vertical flips and random 90-degree rotations. No resizing, cropping, or color jittering is performed.
2.  **Evaluation**: Images are fed at their original resolution ($512 \times 512$).

# Training
**Procedure**
1.  **Labeling**: Treat the task as a binary classification problem. All three steganography algorithms (JMiPOD, JUNIWARD, UERD) are labeled as `1` (Stego), and unaltered images are labeled as `0` (Cover).
2.  **Sampling**: Ensure balanced batches containing an equal mix of Cover and Stego images.
3.  **Loss Function**: Use **Binary Cross Entropy with Logits**.
4.  **Optimizer**: Use **AdamW** with a standard learning rate (e.g., 1e-3) and a Cosine Annealing learning rate scheduler to converge efficiently within the time limit.
5.  **Regularization**: Apply a small amount of Label Smoothing (e.g., 0.05) to prevent the model from becoming overconfident on the noisy steganographic labels.

# Evaluation
**Prediction Strategy**
1.  **Test Time Augmentation (TTA)**: For each test image, generate predictions for the original image and its 90-degree rotated versions (4 views total).
2.  **Score Aggregation**: Average the sigmoid scores of the 4 views to produce the final prediction. This smooths out noise and improves the robustness of the baseline.
3.  **Submission**: The final averaged scores are written to the submission file.
