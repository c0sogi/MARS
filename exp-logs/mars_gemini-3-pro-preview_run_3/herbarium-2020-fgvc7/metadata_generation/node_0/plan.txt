This script generates the required metadata files (`train.csv`, `val.csv`, `test.csv`) for the NYBG2020 dataset.

### Implementation Strategy
1.  **Data Loading**: The script parses the JSON metadata files located in `input/nybg2020/train/` and `input/nybg2020/test/`. It extracts image file names, IDs, and category annotations.
2.  **Path Construction**: Relative file paths are constructed by prepending the dataset root paths (`nybg2020/train` or `nybg2020/test`) to the `file_name` fields found in the JSON.
3.  **Stratified Splitting**:
    *   The training data is analyzed to identify "singleton" classes (species with only 1 sample).
    *   Singleton classes are reserved for the training set to ensure the model has at least one example of every category.
    *   The remaining data (classes with $\ge$ 2 samples) is split into training (80%) and validation (20%) sets using stratified sampling to preserve class distribution.
    *   The singletons are then added back to the training set.
4.  **Output**: The resulting DataFrames are saved as CSV files in the `./metadata` directory.
5.  **Verification**: The script performs a post-generation check:
    *   Prints summary statistics (counts, shapes).
    *   Verifies that the training and validation sets do not overlap.
    *   Randomly samples 1000 file paths from each generated CSV and checks their existence on the disk to ensure path correctness.
