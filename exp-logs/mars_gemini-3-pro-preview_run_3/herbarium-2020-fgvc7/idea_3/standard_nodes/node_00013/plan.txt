Implementation strategy:
1.  **Setup and Initialization**: Set random seeds for reproducibility. Import necessary modules from the provided library.
2.  **Mapping Generation**: Explicitly call `config.get_mappings` using the original full training CSV. This ensures that the model architecture (number of classes) is defined based on the complete taxonomy, even if we train on a subset.
3.  **Data Subsetting**: Load the full training CSV, sample 100,000 images randomly, and save this subset to the working directory. Update `config.TRAIN_CSV` to point to this subset. This is crucial for meeting the "Fast Baseline" requirement within the time limit.
4.  **Cache Management**: Delete any existing cached training weights (`train_weights.npy`) to ensure they are recalculated for the new subset.
5.  **Training**: Initialize the `HierarchicalResNet` model and `Trainer`. Run the training for 2 epochs. The `Trainer` handles the training loop, validation at each epoch, and model checkpointing.
6.  **Validation Reporting**: After training, print the best validation F1 score in the required format.
7.  **Failure Analysis**: Iterate through a sample of the validation set (2000 images) to compute predictions. Calculate the correlation between prediction error (binary) and image metadata (width, height, aspect ratio, file size) using NumPy.
8.  **Submission**: If the best validation F1 score exceeds the threshold (0.3506), load the best model checkpoint and generate the submission file using the test set.
