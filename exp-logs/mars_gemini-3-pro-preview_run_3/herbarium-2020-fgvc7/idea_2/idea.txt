Based on the lessons learned from the ResNet-18 baseline experiments, I propose a solution that structurally evolves the approach from a standard classification problem to a **Metric Learning** problem using a stronger backbone. This addresses the high cardinality (32,093 classes) and fine-grained nature of the dataset.

### Model
*   **Backbone Architecture:** Upgrade the backbone from ResNet-18 to **ResNet-50**. The previous experiments indicated that while the sampling strategy helped, the shallow backbone likely lacked the capacity to effectively discriminate between over 30,000 fine-grained species. ResNet-50 provides a necessary increase in parameter count and depth without exceeding the compute budget of the A100 GPU.
*   **Classification Head (Structural Innovation):** Replace the standard Linear Classification Head (Euclidean space) with an **ArcFace (Additive Angular Margin)** head.
    *   *Rationale:* In standard Softmax classification, the decision boundaries are linear hyperplanes. With 32k classes, these boundaries become crowded. ArcFace projects the learned features onto a hypersphere and enforces an additive angular margin penalty. This forces the model to learn highly discriminative features with greater intra-class compactness and inter-class separability, which is critical for distinguishing between visually similar plant species.

### Data
*   **Preprocessing:** Images will be resized to **224x224** pixels. Pixel values will be normalized using ImageNet mean and standard deviation.
*   **Sampling Strategy:** Apply **Inverse Square-Root Weighted Random Sampling** ($1/\sqrt{N}$).
    *   *Rationale:* Previous experiments demonstrated that aggressive inverse-frequency sampling ($1/N$) caused overfitting on tail classes, while no sampling ignored them. The dampened square-root approach strikes the optimal balance for this long-tailed distribution. Cite {solution_lesson_node_00007}
*   **Augmentation:** Apply robust data augmentation including `RandomResizedCrop`, `RandomHorizontalFlip`, and `ColorJitter`.
    *   *Constraint:* Ensure that the augmentation intensity is matched with sufficient training time (see Training section).

### Training
*   **Loss Function:** Use **ArcFace Loss**. This combines the angular margin penalty with standard Cross-Entropy.
*   **Optimizer:** Use **SGD with Momentum** (0.9) and Weight Decay ($1e-4$) to prevent overfitting on the rare classes. Cite {solution_lesson_node_00007}
*   **Training Duration:** Train for a minimum of **15-20 epochs**.
    *   *Rationale:* Lesson 00008 revealed that increasing regularization (augmentation/weight decay) while reducing epochs leads to underfitting. Since ArcFace and strong augmentation make the optimization task harder, we must extend the training duration to allow for convergence. Cite {solution_lesson_node_00008}
*   **Validation Strategy:** Use a **Stratified Subset** of the training data for validation.
    *   *Rationale:* Random subsetting was shown to exclude rare classes entirely, leading to zero F1 scores. Stratification ensures the validation set reflects the long-tail distribution of the test set. Cite {solution_lesson_node_00004}
    *   *Monitoring:* Continue to monitor the correlation between per-sample loss and class frequency to ensure the long-tail is being learned. Cite {solution_lesson_node_00003}

### Evaluation
*   **Inference:** Resize test images to 256x256 and center crop to 224x224.
*   **Prediction:** Pass the image through the backbone to obtain the feature embedding. Calculate the cosine similarity between this embedding and the learned ArcFace class centers (weights). The class with the highest similarity score is the prediction.
