The `CUDA error: device-side assert triggered` indicates that the target labels passed to the loss function are outside the valid range `[0, num_classes - 1]`. The `HerbariumDataset` is currently returning raw `category_id`s (e.g., 15672), which are likely sparse and exceed the configured `NUM_CLASSES` (32093) or the contiguous index range expected by `CrossEntropyLoss` and the `ArcFace` head.

1.  Implement a `get_label_map` function in `library/dataset.py` that generates a mapping from raw `category_id`s to contiguous integers `[0, N-1]` based on the training data. This avoids modifying `library/config.py` (Cite debug_lesson_1) by storing the map in the existing `Config.WORKING_DIR`.
2.  Update `HerbariumDataset` to use this map to transform labels during training and validation.
3.  Update `generate_submission` in `library/train.py` to reverse this mapping, ensuring the submission file contains the original `category_id`s as required by the task.
