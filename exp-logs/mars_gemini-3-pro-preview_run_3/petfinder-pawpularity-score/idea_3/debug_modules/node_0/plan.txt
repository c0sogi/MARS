The implementation strategy involves creating a single Python script that imports the provided library modules and systematically exercises their functionality. To ensure the demonstration runs quickly and robustly, the script will:

1.  **Override Configuration**: Modify `Config` attributes at runtime to enable `DEBUG` mode (reducing the dataset to 50 samples), reduce the number of cross-validation folds to 2, and minimize model hyperparameters (e.g., LightGBM estimators). It will also redirect output to a dedicated `demo_execution` directory.
2.  **Verify Utilities**: Test the logger setup and RMSE calculation function.
3.  **Verify Data Loading**: Instantiate DataLoaders and inspect a single batch to confirm image tensor shapes `(Batch, 3, 224, 224)` and metadata consistency.
4.  **Verify Feature Extraction**: Run the `FeatureExtractor` to generate and cache features for the small subset, asserting correct output dimensions.
5.  **Verify Modeling**: Instantiate and fit `Level1Predictors` (SVR, LightGBM, Ridge) and the `MetaLearner` (Linear Regression) on the extracted features, checking prediction shapes.
6.  **Integration Test**: Execute the `CrossValidator` to run the full pipeline (Feature Extraction -> CV -> Stacking -> Inference) and verify that a valid `submission.csv` is generated.
