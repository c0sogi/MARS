Based on the accumulated lessons, I propose a **Two-Stage Adapted-Feature Stacking Strategy**. This approach synthesizes the representation power of deep learning with the superior regression capabilities of kernel methods, addressing the limitations of using purely frozen ImageNet features (Cite solution_lesson_node_00002) while avoiding the instability of end-to-end regression heads (Cite solution_lesson_node_00003).

# Model
The architecture evolves the previous "Dual-Backbone" design into a sequential pipeline:

1.  **Stage 1: Adaptive Feature Backbones**
    *   We retain the **Swin Transformer** (for global composition) and **EfficientNetV2** (for local detail) as the core feature extractors (Cite solution_lesson_node_00005).
    *   Instead of keeping them frozen on ImageNet weights, we will treat them as **trainable encoders**. A temporary, lightweight regression head (Linear + Sigmoid) will be attached to the concatenated outputs of these backbones to form an end-to-end trainable model.
    *   **Innovation:** This stage is **not** used for final predictions. Its sole purpose is to "warp" the high-dimensional feature manifold so that images with similar "Pawpularity" scores are clustered closer together, correcting the "efficacy gap" of generic classification features (Cite solution_lesson_node_00002).

2.  **Stage 2: Heterogeneous Stacking Ensemble**
    *   After Stage 1, the temporary head is discarded. The **fine-tuned backbones** are frozen and used as feature extractors.
    *   The regression logic leverages the **Stacked Generalization** architecture (Cite solution_lesson_node_00011), which was proven more robust than single models.
    *   **Level 1 Base Learners:**
        *   **Support Vector Regression (SVR)** with RBF Kernel: This remains the primary driver, as it effectively captures non-linear similarities in dense embedding spaces (Cite solution_lesson_node_00012). We will apply **PCA** dimensionality reduction specifically for this branch to maintain efficiency.
        *   **LightGBM**: To capture decision-tree-based interactions that SVR might miss.
        *   **Ridge Regression**: As a stable linear baseline.
    *   **Level 2 Meta-Learner**: A Linear Regression model aggregates the base predictions.

# Data
1.  **Stage 1 Preprocessing (Training):** To prevent the overfitting observed in previous fine-tuning attempts (Cite solution_lesson_node_00004), we will apply moderate data augmentation (Horizontal Flip, Random Resized Crop) during the backbone adaptation phase.
2.  **Stage 2 Preprocessing (Extraction):** For feature extraction, we will revert to deterministic resizing (224x224) but implement **Test-Time Augmentation (TTA)** by averaging the embeddings of the original and horizontally flipped images.
    *   **Correction:** We will ensure the caching mechanism includes a hash of the configuration (including the TTA flag) to prevent the "stale cache" bug encountered previously (Cite solution_lesson_node_00007).
3.  **Metadata:** The 12 binary metadata features will be concatenated with the extracted image embeddings before being fed into the Stage 2 Stacking Ensemble.

# Training
The training procedure is split into two distinct phases to maximize stability and performance:

1.  **Phase 1: Representation Adaptation (Fine-Tuning)**
    *   Train the Swin and EfficientNet backbones end-to-end on the training set using **MSE Loss**.
    *   Use a low learning rate (e.g., $1e-5$) and a Cosine Annealing scheduler to gently adapt the ImageNet weights to the "Pawpularity" task without destroying the pre-trained filters.
    *   This phase effectively creates "Task-Specific Embeddings."

2.  **Phase 2: Stack Training (Cross-Validation)**
    *   **Extraction:** Pass the entire dataset through the now fine-tuned (and frozen) backbones using TTA to generate a new feature matrix $X_{adapted}$.
    *   **Stacking:** Perform K-Fold Cross-Validation (5 folds) on $X_{adapted}$.
        *   Train SVR, LightGBM, and Ridge on the training folds.
        *   Generate Out-of-Fold (OOF) predictions for the validation folds.
        *   Train the Meta-Learner on the OOF predictions to minimize RMSE.
    *   **Final Fit:** Retrain all Level 1 and Level 2 models on the full dataset.

# Evaluation
1.  **Inference:** Process test images through the **fine-tuned** backbones (with TTA) to extract adapted features.
2.  **Prediction:** Feed the features + metadata into the retrained Level 1 models, aggregate their outputs using the Level 2 Meta-Learner, and clip the final result to the [1, 100] range.
