The implementation follows the Two-Stage Adapted-Feature Stacking Strategy. It first fine-tunes the dual-backbone architecture (Swin Transformer + EfficientNetV2) on the training set to learn task-specific embeddings. Then, it extracts features from the entire dataset using these adapted backbones with Test-Time Augmentation (TTA). Finally, it trains a Stacking Ensemble (SVR, LightGBM, Ridge) on the extracted features and evaluates performance on the hold-out validation set before generating the submission.
