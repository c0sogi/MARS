This script demonstrates the end-to-end usage of the provided library files to solve the Pawpularity prediction task. It optimizes for speed by enabling the `DEBUG` mode in the configuration, which processes a small subset of the data. The script verifies the integrity of data loading, feature extraction, model training, and submission generation using assertions.

1.  **Configuration**: Modifies `Config` to enable debug mode and reduce batch sizes for rapid execution.
2.  **Data Loading**: Initializes DataLoaders and verifies the shape and types of the yielded batches.
3.  **Feature Extraction**: Runs the MobileNetV2 feature extraction pipeline (bypassing cache to demonstrate logic) and verifies output dimensions.
4.  **Modeling**: Instantiates the `RidgeRegressor`, fits it to the extracted features, and validates predictions are within the valid range [1, 100].
5.  **Pipeline Integration**: Executes the high-level `train_and_evaluate` function to generate the final submission file.
6.  **Submission Verification**: Checks the generated CSV for correct formatting and absence of missing values.
