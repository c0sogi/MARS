Based on the comprehensive analysis of the previous experiments and lessons learned, I propose the **Quad-Stream Dual-Pooling Ensemble with Metadata Interaction**.

This strategy addresses the "Curse of Spatial Granularity" (Cite solution_lesson_node_00031) by replacing the risky Spatial Pyramid Pooling with **Dual-Statistic Pooling**, ensuring the model captures both salient details (e.g., sharp eyes) and global context without encoding accidental spatial noise. Furthermore, it enhances the stacking architecture by explicitly modeling the conditional relationship between metadata (e.g., "Blur") and visual features via **Interaction Engineering**.

### Model

The architecture consists of a **Salience-Aware Feature Extractor** feeding into an **Interaction-Augmented Stacking Ensemble**:

1.  **Quad-Stream Backbones (Frozen)**:
    We retain the four high-performing backbones to capture orthogonal signal modalities (Cite solution_lesson_node_00025):
    *   **Swin Transformer Large**: Global composition.
    *   **EfficientNetV2 Large**: Local texture and quality.
    *   **DINOv2 Large**: Geometric correspondence (Self-Supervised).
    *   **CLIP Vision Model (Large)**: Semantic/Affective "vibe" (Language-Contrastive).
    *   All backbones are **frozen** to prevent overfitting (Cite solution_lesson_node_00014).

2.  **Dual-Statistic Pooling (Avg + Max)**:
    To capture "Subject Focus" and "Salience" without the overfitting risks of Spatial Pyramid Pooling (Cite solution_lesson_node_00031), we implement **Dual-Statistic Pooling** for each backbone.
    *   Instead of a single Global Average Pooling (GAP) vector, we extract **both**:
        *   **Global Average Pool:** Captures the ambient/average signal (Context).
        *   **Global Max Pool:** Captures the highest activation values (Salience/Prominence).
    *   These two vectors are concatenated for each backbone. This allows the model to distinguish between a "generally blurry image" (low max, low avg) and a "sharp subject on blurred background" (high max, low avg), which GAP alone obscures.

3.  **Independent Component Compression**:
    We apply **Principal Component Analysis (PCA)** independently to the dual-pooled output of *each* backbone to retain 95% of the variance (Cite solution_lesson_node_00022). This compresses the doubled feature dimension while preserving the richest salience and context signals.

4.  **Interaction-Augmented Feature Engineering**:
    We construct the final feature vector by concatenating:
    *   **Compressed Image Features**: The PCA outputs from all four backbones.
    *   **Amplified Metadata**: The 12 binary metadata features scaled by a factor of 10.0 (Cite solution_lesson_node_00025).
    *   **Metadata-Visual Interactions**: We compute explicit interaction terms by calculating the element-wise product between the binary metadata vector and the **Top-3 Principal Components** of each backbone. This forces the downstream regressors to explicitly consider conditional logic (e.g., "If `Blur` is present, discount the `Texture` signal").

5.  **Stacking Ensemble Head**:
    We employ the optimized heterogeneous stacking configuration:
    *   **Level 1 Base Learners**:
        *   **Support Vector Regression (SVR)**: RBF Kernel, with high regularization parameter **$C \ge 20$** to handle the dense feature space (Cite solution_lesson_node_00026).
        *   **ExtraTrees Regressor**: Configured with **`max_features=None`** to ensure all PCA components are evaluated at every split (Cite solution_lesson_node_00027).
        *   **LightGBM**: Gradient Boosting for residual capture.
    *   **Level 2 Meta-Learner**: Linear Regression to aggregate predictions.

### Data

1.  **Preprocessing**:
    *   Images are resized to **224x224** and normalized.
    *   **Test-Time Augmentation (TTA)**: We apply Horizontal Flipping. The Dual-Pooled features (Avg+Max) are extracted for both original and flipped images, and their resulting embeddings are averaged (Cite solution_lesson_node_00007).
    *   **Caching**: Cache filenames will include a hash of the configuration (including "DualPool" and "Interaction") to ensure fresh feature extraction (Cite solution_lesson_node_00007).

2.  **Metadata Integration**:
    *   Apply the scaling (x10.0) and interaction generation steps described in the Model section effectively *after* feature extraction but *before* model training.

### Training

1.  **Feature Extraction & Compression**:
    *   Pass the dataset through the frozen backbones using TTA.
    *   Perform Dual-Statistic Pooling (Avg + Max).
    *   Fit four separate PCA transformers on the training set and transform the entire dataset.
    *   Generate Interaction Features.
2.  **Ensemble Training (Cross-Validation)**:
    *   Perform **5-Fold Cross-Validation**.
    *   Train Level 1 models (SVR, ExtraTrees, LightGBM) on the training folds and generate Out-of-Fold (OOF) predictions.
    *   Train the Level 2 Linear Meta-Learner on the OOF predictions to minimize RMSE.
3.  **Final Retraining**:
    *   Retrain all PCA transformers, Level 1 models, and the Level 2 learner on the full training set.

### Evaluation

1.  **Inference**:
    *   Process test images through frozen backbones with TTA and Dual-Pooling.
    *   Project vectors using learned PCA transformers.
    *   Construct the full feature vector with Scaled Metadata and Interaction terms.
2.  **Prediction**:
    *   Generate predictions from retrained Level 1 models.
    *   Aggregate using the Level 2 Meta-Learner.
    *   Clip final predictions to [1, 100].
