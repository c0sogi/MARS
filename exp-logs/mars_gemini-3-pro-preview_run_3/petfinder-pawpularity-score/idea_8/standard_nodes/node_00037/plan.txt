The implementation strategy follows the Quad-Stream Dual-Pooling Ensemble architecture. It begins by initializing the environment and loading the metadata. It uses the `PetDataset` and `DataLoader` to handle image loading with Test-Time Augmentation (TTA). The `FeatureExtractor` extracts features from four frozen backbones (Swin, EfficientNetV2, DINOv2, CLIP) using Dual-Pooling (Avg+Max). The `FeaturePreprocessor` then applies PCA compression and generates interaction features between the top principal components and the metadata.

For the validation phase, the `StackingEnsemble` is first trained on the training set only. OOF predictions are generated for the training set to fit the meta-learner. The ensemble then predicts on the hold-out validation set to compute the `Final Validation Metric` (RMSE). Failure analysis is performed by correlating the absolute prediction errors with the binary metadata features.

If the validation RMSE is below the specified threshold, the model is retrained on the combined training and validation sets to maximize performance, and predictions are generated for the test set and saved to `submission.csv`.
