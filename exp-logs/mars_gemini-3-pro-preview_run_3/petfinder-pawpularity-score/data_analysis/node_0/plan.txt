The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup and Configuration**: Initialize the environment, set random seeds for reproducibility, and define paths. We will use the pre-split training metadata (`./metadata/train_meta.csv`) to ensure no data leakage from the validation or test sets.

2.  **Target Variable Analysis**: We will analyze the `Pawpularity` score. Since this is a regression task, we will calculate descriptive statistics (mean, std, min, max), and assess the distribution shape using Skewness and Kurtosis to understand if the target deviates from a normal distribution.

3.  **Tabular Data Analysis**: The dataset contains 12 binary metadata features (e.g., `Focus`, `Eyes`). We will treat these as categorical/numerical features, checking for missing values and calculating the frequency of the positive class (1) for each feature.

4.  **Image Data Analysis**:
    *   We will iterate through the training images to extract metadata: dimensions (width, height) and aspect ratios.
    *   We will calculate global pixel statistics (mean and standard deviation) to inform normalization strategies. To ensure the script runs quickly, we will perform the pixel-level analysis on a representative random sample of the images, while dimension analysis will be performed on the full training set.
    *   We will check for channel consistency (RGB vs Grayscale).

5.  **Feature Relationships**:
    *   **Correlations**: We will calculate the Pearson correlation between the binary metadata features and the target `Pawpularity`.
    *   **Feature Importance**: We will train a lightweight Random Forest Regressor using the tabular features to identify which visual attributes (annotated by humans) are most predictive of engagement.
    *   **Redundancy**: We will check for collinearity among the binary features.
    *   **Meta-Feature Analysis**: We will analyze if image properties (like size or aspect ratio) correlate with the engagement score.

6.  **Reporting**: The results will be printed to the console in a structured, readable format as specified.
