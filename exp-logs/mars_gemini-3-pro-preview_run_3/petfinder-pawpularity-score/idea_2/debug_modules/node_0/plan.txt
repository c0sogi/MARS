The following implementation demonstrates the end-to-end pipeline for the Pet Pawpularity Prediction task.

### Strategy Outline
1.  **Configuration Override**: To ensure the script runs quickly (within minutes) and isolates its output, we override the global `config` to enable `DEBUG` mode (using only 100 samples per dataset), redirect the `WORKING_DIR` to a temporary demo folder, and simplify the SVR hyperparameter grid to a single iteration.
2.  **Data Loading**: We initialize the `PetDataset` and `DataLoader` via the `data_loader` module. We verify the integrity of the data pipeline by checking the shapes of the image tensors and metadata vectors from a single batch.
3.  **Feature Extraction**: We utilize the `feature_extractor` module to pass images through the dual-backbone (Swin Transformer + EfficientNetV2) and concatenate them with metadata. We force the extraction (bypassing cache) to demonstrate the logic.
4.  **Model Training**: We train the Support Vector Regressor (SVR) using the `svr_model` module on the extracted training features.
5.  **Validation & Inference**: We evaluate the model on the validation set, calculating the RMSE, and then generate predictions for the test set.
6.  **Submission**: Finally, we format the test predictions into a CSV file using the provided utility and verify the output format.
