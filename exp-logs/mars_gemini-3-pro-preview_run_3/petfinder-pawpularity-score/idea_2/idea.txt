Based on the lessons learned from the previous experiments, I propose a **Hybrid Feature Fusion with Support Vector Regression (SVR)** strategy. This approach addresses the insufficiency of linear probing on simple CNN features (Lesson 00002) and the overfitting/instability of deep non-linear heads (Lesson 00003) and end-to-end fine-tuning (Lesson 00004).

# Model
The architecture adopts a **Multi-Backbone Feature Extraction** paradigm coupled with a **Kernel-based Regressor**:

1.  **Dual-Backbone Feature Extractor (Frozen)**:
    *   **Swin Transformer (e.g., `swin_base_patch4_window7_224`)**: Unlike the CNN used previously, Swin Transformers utilize shifted window attention to capture global geometric composition and long-range dependencies. This directly addresses the finding that "cuteness" relies on composition and layout, which are orthogonal to the object identity features of standard CNNs (Cite Lesson 00002).
    *   **EfficientNetV2 (e.g., `tf_efficientnetv2_s`)**: A modern CNN is retained to capture high-frequency local details (texture, fur quality, sharpness) that Transformers sometimes overlook but are critical for image quality assessment.
    *   Both backbones will be pre-trained on ImageNet and **completely frozen**. Their outputs (global average pooled vectors) will be concatenated to form a rich, multi-view representation of each image.

2.  **Regression Head**:
    *   **Support Vector Regression (SVR)**: Instead of a Linear Ridge Regressor (which was "insufficient" per Cite Lesson 00002) or a Deep MLP (which "overfitted" per Cite Lesson 00003), we will use SVR with a Radial Basis Function (RBF) kernel.
    *   **Rationale**: The RBF kernel projects the features into a higher-dimensional space to find a linear hyperplane, effectively providing the **non-linear mapping** required to relate semantic features to subjective scores. Crucially, SVR is a convex optimization problem with strong regularization guarantees, avoiding the convergence instability and overfitting pitfalls of neural network heads (Cite Lesson 00003, Cite Lesson 00004).

# Data
1.  **Preprocessing**:
    *   Images will be resized to **224x224** and normalized using ImageNet statistics.
    *   **Metadata Integration**: The 12 binary metadata features will be scaled (if necessary) and concatenated with the image embeddings from both backbones, resulting in a single feature vector per sample: $X_{final} = [Embed_{Swin} \oplus Embed_{EffNet} \oplus Metadata]$.
2.  **No Augmentation**: Consistent with the preference for deterministic, efficient baselines (Cite Lesson 00004), we will not use random augmentations during the feature extraction phase to ensure stable, reproducible feature matrices.

# Training
The training process leverages the efficiency of "Linear Probing" workflows but applies it to a kernel method:
1.  **Feature Caching**: Iterate through the training set once using the GPU to extract and store the concatenated feature vectors from the frozen Swin and EfficientNet backbones.
2.  **Solver Fitting**: Train the SVR model on the cached feature matrix $X_{train}$ and targets $y_{train}$.
    *   We will perform a quick grid search (using cross-validation) for the SVR hyperparameters $C$ (regularization) and $\epsilon$ (margin of tolerance) to balance bias and variance.
    *   This separates the heavy lifting (GPU inference) from the learning (CPU solver), avoiding the slow convergence of end-to-end backpropagation (Cite Lesson 00004).

# Evaluation
1.  **Inference**: For the test set, run the images through the same dual-backbone pipeline to extract features.
2.  **Prediction**: Feed the concatenated test features into the trained SVR model.
3.  **Post-processing**: Clip predictions to the [1, 100] range to ensure valid outputs.
