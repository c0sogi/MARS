Based on the accumulated lessons, I propose a **Multi-Paradigm Feature Stacking Strategy with Independent Component Compression**. This approach addresses the "efficacy gap" of supervised classification features (Cite solution_lesson_node_00002) by integrating Self-Supervised Learning (SSL) representations and optimizes the ensemble's stability using a divide-and-conquer dimensionality reduction scheme.

# Model
The architecture employs a **Triple-Backbone Feature Extractor** followed by a **Compressed Stacking Ensemble**:

1.  **Multi-Paradigm Backbones (Frozen)**:
    *   **Swin Transformer (Supervised)**: Retained for its ability to capture global composition and layout (Cite solution_lesson_node_00005).
    *   **EfficientNetV2 (Supervised)**: Retained for high-frequency local detail and texture analysis (Cite solution_lesson_node_00005).
    *   **DINOv2 / ViT-DINO (Self-Supervised)**: We introduce a Vision Transformer pre-trained with **DINO (Self-Distillation with no Labels)**. Unlike ImageNet classifiers, DINO models are optimized for geometric correspondence and part-whole relationships without class-label bias. This directly tackles the finding that classification features map poorly to subjective scores (Cite solution_lesson_node_00002).
    *   All backbones are treated as **fixed feature extractors** to prevent the overfitting observed with fine-tuning on this small dataset (Cite solution_lesson_node_00014).

2.  **Independent Component Compression**:
    *   Instead of concatenating raw embeddings (totaling >3000 dimensions) which dilutes the signal for tree-based models (Cite solution_lesson_node_00012), we apply **PCA independently** to each backbone's output *before* concatenation.
    *   We retain 95% of the variance for each stream. This ensures that the "Geometry" signal (DINO), "Texture" signal (EffNet), and "Composition" signal (Swin) are balanced in the final vector, rather than being dominated by the backbone with the largest embedding dimension.

3.  **Stacking Ensemble Head**:
    *   **Level 1**: We employ the successful heterogeneous mix of **Support Vector Regression (SVR)** with RBF kernel, **LightGBM**, and **Ridge Regression** (Cite solution_lesson_node_00011).
    *   **Level 2**: A Linear Meta-Learner aggregates the base predictions.

# Data
1.  **Preprocessing**: Images are resized to 224x224 and normalized.
2.  **Test-Time Augmentation (TTA)**: We apply Horizontal Flipping during feature extraction. The embedding for an image is the average of the original and flipped views.
3.  **Robust Caching**: We enforce **configuration-hashed caching** for the extracted features. The cache filename will include a hash of the backbone names and preprocessing flags (e.g., `features_{hash}.npy`) to ensure that adding DINOv2 triggers a fresh extraction, avoiding the stale cache failure (Cite solution_lesson_node_00007).
4.  **Metadata**: The 12 binary metadata features are concatenated with the compressed image features.

# Training
1.  **Feature Extraction**: Run the three frozen backbones (Swin, EffNet, DINO) on the full dataset using TTA. Fit three separate PCA transformers on the training set embeddings and transform both train and test sets.
2.  **Stack Training (Cross-Validation)**:
    *   Perform 5-Fold Cross-Validation on the compressed feature matrix.
    *   Train Level 1 models (SVR, LGBM, Ridge) on training folds and generate Out-of-Fold (OOF) predictions.
    *   Train the Level 2 Meta-Learner on OOF predictions to minimize RMSE.
3.  **Final Retraining**: Retrain all PCA transformers, Level 1 models, and the Level 2 learner on the entire training dataset.

# Evaluation
1.  **Inference**: Process test images through the frozen backbones with TTA.
2.  **Projection**: Transform raw embeddings using the learned PCA matrices.
3.  **Prediction**: Generate base predictions using Level 1 models, aggregate with the Meta-Learner, and clip outputs to [1, 100].
