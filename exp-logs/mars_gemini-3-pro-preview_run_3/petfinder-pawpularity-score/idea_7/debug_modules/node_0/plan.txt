Implementation Strategy:
1.  **Setup and Configuration**: Import necessary modules and the provided library classes. Override `Config` settings to enable `DEBUG` mode, reduce `BATCH_SIZE`, `N_FOLDS`, and model estimators (e.g., `n_estimators=5`) to ensure the script runs quickly (within minutes).
2.  **Data Consistency**: Since the provided `DimensionalityReducer` reads the full metadata CSVs directly (ignoring `Config.DEBUG`), we will manually create small subsets of the metadata CSVs (matching `DEBUG_SAMPLE_SIZE`) in the `./working` directory. We then update the `Config` paths to point to these subset files. This ensures both `PetDataset` and `DimensionalityReducer` process the same reduced dataset.
3.  **Pipeline Execution**:
    *   **Feature Extraction**: Instantiate `FeatureEngine` and run it. We restrict `Config.BACKBONES` to a single model (`swin`) to minimize runtime.
    *   **Dimensionality Reduction**: Instantiate `DimensionalityReducer` and run it to fuse features and metadata.
    *   **Ensemble Training**: Instantiate `EnsembleTrainer` and run the stacking pipeline.
4.  **Verification**: After execution, verify that the submission file exists and contains the expected number of predictions (matching the debug sample size).
