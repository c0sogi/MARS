The following implementation demonstrates the usage of the provided library modules to execute the Quad-Stream Semantic-Geometric Ensemble pipeline.

**Strategy:**
1.  **Configuration Override:** We modify the `Config` class attributes at runtime to enable `DEBUG` mode (reducing the dataset to 20 samples) and reduce cross-validation folds to 2. This ensures the demonstration runs quickly within the time limit.
2.  **Component Verification:**
    *   **Data Loading:** We verify the `PawpularityDataset` correctly loads images and metadata, and handles Test-Time Augmentation (TTA) by checking tensor shapes.
    *   **Feature Extraction:** We run the `FeatureEngine` to extract features from the backbones on the small subset. We assert that the output dimensions match the sample size.
    *   **Preprocessing:** We verify `StreamProcessor` correctly concatenates PCA-reduced features and scaled metadata.
    *   **Modeling:** We test `Level1Estimators` (SVR, Ridge, LightGBM) and `StackingMetaLearner` by generating OOF predictions and fitting the meta-model.
3.  **End-to-End Execution:** Finally, we utilize the `CrossValidator` class to run the full pipeline (Extraction -> Processing -> Stacking -> Submission) to ensure all components integrate seamlessly.
