The issue stems from the fact that Python evaluates default argument values at function definition time (when the module is imported), not at call time. In `library/inference.py`, the `generate_submission` function binds `model_path` to the initial value of `Config.MODEL_CHECKPOINT_PATH` (which points to `idea_5`). Even though `runfile.py` updates the `Config` object later to point to `demo_run`, the function continues to use the stale path, causing a `FileNotFoundError`.

To fix this, I will modify `generate_submission` to use `None` as the default value for `model_path` (and `output_path` for consistency) and then resolve the path from `Config` inside the function body. This ensures the function uses the most up-to-date configuration values at runtime (Cite debug_lesson_3).
