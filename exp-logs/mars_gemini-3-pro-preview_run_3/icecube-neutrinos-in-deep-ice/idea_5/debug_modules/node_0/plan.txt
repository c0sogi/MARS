The following script demonstrates the end-to-end usage of the provided library components for the IceCube neutrino direction prediction task.

### Implementation Strategy

1.  **Configuration Setup**: We first override the global `Config` class attributes to enable a "Demo Mode". This includes setting `DEBUG` flags, reducing the number of epochs to 1, limiting batch sizes, and redirecting outputs to a specific working directory. This ensures the script runs quickly (within minutes) and does not overwrite existing production files.
2.  **Utility Verification**: We validate the core geometric utility functions (`spherical_to_cartesian`, `cartesian_to_spherical`) and the competition metric (`angular_dist_score`) using synthetic data to ensure mathematical correctness.
3.  **Data Pipeline Demonstration**: We instantiate the `IceCubeDataset` and `DataLoader` with a limited number of batches. We verify the shape and data types of the yielded tensors (features, geometric priors, and targets) to confirm the data loading and preprocessing logic works as expected.
4.  **Model Architecture Verification**: We instantiate the `ADGN_Model`, perform a forward pass with a sample batch, and assert that the output shape is correct `(Batch_Size, 3)` and that the output vectors are normalized (unit length).
5.  **Training Loop Execution**: We initialize the `Trainer` class and execute the `fit()` method. This runs a full training cycle (training step + validation step) for one epoch. We verify that the model checkpoint is successfully saved.
6.  **Inference and Submission**: We invoke the `generate_submission` function to run inference on a subset of the test data using the trained checkpoint. We verify that the resulting submission CSV file exists and adheres to the required format.
