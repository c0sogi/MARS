Implementation strategy:
1.  **Configuration Override**: Modify the `Config` class attributes at runtime to create a "Fast Baseline". Set `EPOCHS` to 2 and enable `DEBUG` mode with a subset size of 50,000 events. This ensures the training completes quickly while still learning from a representative sample.
2.  **Training**: Execute the `run_training` function from the provided library. This will train the PointNet-based model on the subset of data and save the best model weights.
3.  **Validation & Failure Analysis**:
    *   Load the trained model and the validation metadata.
    *   Run inference on the validation set (subset in debug mode).
    *   Compute the **Mean Angular Error (MAE)** element-wise.
    *   Print the `Final Validation Metric` as required.
    *   Extract features (`pulse_count`, `total_charge`) from the input tensors and calculate their Pearson correlation with the MAE to identify error patterns.
4.  **Submission**:
    *   Disable `DEBUG` mode to ensure the entire test set is processed.
    *   Call `predict_and_submit` to generate predictions for all test events and save the `submission.csv`.
5.  **Optimization**: Use `torch.no_grad()` and `model.eval()` during inference phases to minimize memory usage and runtime.
