The following implementation demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Configuration & Setup**: Initializes the environment and overrides specific configuration parameters (batch size, epochs, XGBoost estimators) to ensure the demo runs instantly.
2.  **Data Loading**: Loads the metadata and creates a tiny subset (20 samples) to facilitate rapid execution. It initializes the `PathologyDataset` and `DataLoaders`.
3.  **Model Training**: Instantiates a `convnext_tiny` model (without pretrained weights to avoid downloads) and runs a single training epoch.
4.  **Evaluation**: Executes the Test-Time Augmentation (TTA) evaluation pipeline on the validation subset.
5.  **Meta-Learning**: Simulates Out-Of-Fold (OOF) predictions and demonstrates the stacking pipeline: preparing data, training the XGBoost meta-learner, and generating the final submission.
