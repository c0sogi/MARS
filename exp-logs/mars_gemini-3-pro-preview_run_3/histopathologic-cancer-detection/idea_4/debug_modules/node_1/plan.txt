The `StopIteration` error occurs because the `train_loader` in `test_data_pipeline` is initialized using the default `batch_size` of 512 (evaluated at import time), whereas the demo dataset is very small (approx. 20 training samples per fold). With `drop_last=True` enabled in the DataLoader, a batch size larger than the dataset size results in zero batches, causing `next(iter(train_loader))` to fail. The fix is to explicitly pass the runtime-overridden `Config.BATCH_SIZE` (set to 8 in the demo) and `Config.NUM_WORKERS` when calling `get_dataloaders` in `runfile.py`.
