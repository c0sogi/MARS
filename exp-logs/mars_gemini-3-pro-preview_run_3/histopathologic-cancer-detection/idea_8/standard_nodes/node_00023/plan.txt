Implementation Strategy:
1.  **Configuration Override**: To ensure the pipeline completes within the ~1.5h time limit while processing the large dataset, I will override `Config.EPOCHS` to 2 and `Config.BATCH_SIZE` to 2048. This balances training time with sufficient convergence on the A100 GPU.
2.  **Data Preparation**: I will load the metadata and perform a Stratified 5-Fold split on the training data.
3.  **Base Model Training**: I will iterate through the two architectures (`convnext_tiny`, `densenet121`) and the 5 folds. For each combination, I will train the model, save the best checkpoint based on validation AUC, and generate Out-Of-Fold (OOF) predictions using 4-view Test Time Augmentation (TTA).
4.  **Meta-Learner Training**: I will aggregate the OOF predictions and train an XGBoost meta-learner to map base model probabilities to the ground truth.
5.  **Hold-Out Validation**: I will generate predictions for the separate `val.csv` hold-out set by averaging the TTA predictions from all 5 folds of each architecture, then passing these through the meta-learner.
6.  **Metric & Failure Analysis**: I will calculate and print the final AUC on the hold-out set. I will also perform failure analysis by computing the correlation between prediction errors and basic image statistics (brightness, contrast) on a subset of the validation data.
7.  **Submission**: If the validation AUC exceeds the specified threshold, I will generate predictions for the test set using the full ensemble and save the submission file.
