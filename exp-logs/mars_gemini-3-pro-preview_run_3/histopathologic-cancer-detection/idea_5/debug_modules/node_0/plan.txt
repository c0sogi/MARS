### Implementation Strategy

1.  **Configuration Override**: We will modify the `Config` class attributes at runtime to adapt the pipeline for a quick demonstration. This includes reducing the number of epochs to 1, setting the number of folds to 2, selecting a lightweight model (`resnet18`), and disabling extensive TTA.
2.  **Data Subsetting**: To ensure the script completes quickly, we will load the original metadata, sample a small stratified subset (e.g., 50 samples), and save these as new metadata files in the working directory. We will then point `Config` to these new files.
3.  **Component Verification**:
    *   **Dataset & Loader**: We will instantiate the `PathologyDataset` and `DataLoader` to verify that image loading, transformation, and batching work correctly.
    *   **Modeling**: We will initialize the model to confirm the architecture is valid and produces outputs of the correct shape.
    *   **Training Loop**: We will execute the full `run_fold` process for the configured 2 folds. This tests the training loop, validation, metric monitoring, and model saving.
    *   **Meta-Learner**: We will collect the Out-Of-Fold (OOF) predictions from the training step and use them to train the `StackingMetaLearner`.
    *   **Inference**: We will run the `run_inference` pipeline, which generates predictions on the test subset using the trained models and the meta-learner.
4.  **Validation**: Throughout the process, we will use assertions to verify shapes, file existence, and data integrity. Finally, we will check the format of the generated submission file.
