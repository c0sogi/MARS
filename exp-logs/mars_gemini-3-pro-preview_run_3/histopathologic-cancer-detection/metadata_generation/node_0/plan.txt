The following Python script generates metadata CSV files for training, validation, and testing datasets. It reads the raw labels and submission sample files from the `./input` directory, splits the training data into an 80/20 train/validation split using stratified sampling to maintain class balance, and saves the resulting metadata to the `./metadata` directory. Finally, it performs rigorous validation checks to ensure file paths are correct, the split ratio is accurate, and the class distribution is preserved.
