The error occurs because `torch.load` in PyTorch 2.6+ defaults to `weights_only=True`, which restricts deserialization to safe PyTorch types (like tensors) and blocks arbitrary Python objects such as the Scikit-Learn `LogisticRegression` model used for the meta-learner. To fix this, we must explicitly set `weights_only=False` when loading the meta-learner in `library/stacking.py`, as we trust the locally generated checkpoint.
