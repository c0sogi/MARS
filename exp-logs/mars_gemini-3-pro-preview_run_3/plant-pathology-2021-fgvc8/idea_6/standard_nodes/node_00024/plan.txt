Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using `Config` settings, including setting the random seed and selecting the A100 GPU device. Enable `cudnn.benchmark` for optimized training speed given the fixed input size.
2.  **Data Loading**: Load the full training and validation datasets using `get_train_val_loaders` with caching enabled to minimize I/O overhead.
3.  **Model Initialization**: Instantiate the `AppleDiseaseModel` (ConvNeXt-Small with GeM pooling) and move it to the GPU.
4.  **Training**:
    *   Configure the **AdamW** optimizer with parameters from `Config`.
    *   Implement a **SequentialLR** scheduler that combines a **Linear Warmup** (for stability) with **Cosine Annealing** (for convergence) over 50 epochs.
    *   Initialize **ModelEMA** to maintain a moving average of weights, improving generalization.
    *   Execute the training loop using `train_model`, which handles the forward/backward passes, logging, and checkpointing of the best model.
5.  **Validation**:
    *   Reload the best model checkpoint.
    *   Compute the final F1 score on the full validation set using `validate`.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Perform inference on the validation set to get per-sample predictions.
    *   Calculate the Mean Absolute Error (MAE) for each sample.
    *   Load original images to extract meta-features (width, height, aspect ratio, brightness).
    *   Calculate and print the Pearson correlation between these features and the error magnitude to identify systematic weaknesses.
7.  **Submission**:
    *   Compare the final validation F1 against the threshold (0.9096474096681636).
    *   If the threshold is met, load the test set and generate predictions using **Test Time Augmentation (TTA)** via `predict_tta`.
    *   Save the formatted predictions to `submission.csv`.
