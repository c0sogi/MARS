### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override specific parameters (e.g., `EPOCHS`, `PRETRAINED`, `WORKING_DIR`) to ensure the demonstration runs quickly and does not depend on external model weight downloads.
2.  **Data Loading**: Use `get_loaders(debug=True)` to load a small subset of the training, validation, and test data. This validates the data pipeline without processing the entire dataset.
3.  **Data Verification**: Perform assertions on the data batches to ensure image dimensions and target shapes match the configuration (Batch Size, Channels, Height, Width, Num Classes).
4.  **Model Initialization**: Instantiate the `AppleClassifier` and perform a dummy forward pass to verify the architecture and output dimensions.
5.  **Training Simulation**: Execute the `train_model` function for a single epoch using the debug data. This demonstrates the training loop, mixed-precision scaling, and checkpoint saving mechanisms.
6.  **Inference & Submission**: Run `predict_with_tta` on the test set to generate predictions. Validate the resulting CSV file format and content.
7.  **Reproducibility**: Apply `seed_everything` at the start to ensure deterministic behavior.
