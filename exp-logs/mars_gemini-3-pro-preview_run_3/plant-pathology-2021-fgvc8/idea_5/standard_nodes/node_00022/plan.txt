1.  **Initialization**: Set random seeds for reproducibility and initialize the computing device (GPU). Load the `AppleDiseaseModel` (ConvNeXt-Small with GeM pooling) and the `AppleDataset` loaders for training, validation, and testing.

3.  **Validation & Analysis**: Load the best-performing model weights. Evaluate the model on the full validation set to compute the Mean F1-Score. Perform failure analysis by calculating the correlation between the model's prediction error (BCE loss) and image statistics (brightness and contrast) to identify systematic weaknesses.
4.  **Submission**: If the validation F1 score exceeds the specified threshold (0.9096), generate predictions for the test set. Apply Test Time Augmentation (TTA) by averaging predictions from the original, horizontally flipped, and vertically flipped images.
