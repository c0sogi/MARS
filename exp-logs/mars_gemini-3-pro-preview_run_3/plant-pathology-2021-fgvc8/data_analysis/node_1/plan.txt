The `PicklingError` occurs because the script is being executed via `exec()`, which dynamically defines functions like `get_image_stats` in a way that makes them unimportable by the worker processes spawned by `ProcessPoolExecutor`. To fix this, I will replace the parallel execution block with a serial list comprehension, which runs the function in the main process and avoids the need for pickling.
