Implementation Strategy:
1.  **Setup & Configuration**: Import the provided library modules. Monkey-patch the `Config` class to optimize for a quick demonstration run (e.g., 1 epoch, reduced image size, small batch size) and set temporary output directories.
2.  **Data Pipeline Verification**: Load a small subset of the training metadata. Instantiate the `AppleDataset` and `get_transforms` to verify that data loading and augmentation produce tensors of the expected shape `(3, H, W)` and targets `(Num_Classes,)`.
3.  **Model Verification**: Initialize the `AppleConvNeXt` model. Perform a forward pass with a dummy input batch on the GPU to confirm the model architecture and output dimensions `(Batch, Num_Classes)` are correct.
4.  **Training Loop Demonstration**: Execute `train_model` using the subset data. This verifies the training loop, loss calculation, mixed-precision (AMP) integration, and checkpoint saving mechanism.
5.  **Inference Demonstration**: Run `run_inference` on a limited number of test samples. This validates the test-time augmentation (TTA), thresholding logic, and the generation of the submission CSV in the correct format.
6.  **Assertions**: Throughout the script, use assertions to enforce correctness of shapes, file existence, and data formats.
