Here is a proposal for a highly efficient baseline approach.

### Model
We will utilize the **ResNet-18** architecture. This is a lightweight Convolutional Neural Network (CNN) that uses residual skip connections to enable effective feature learning with relatively few parameters.
*   **Distinction**: Unlike Model 4 (which uses a larger, frozen ResNet-50 strictly for feature extraction coupled with an SVM), this approach will **fine-tune** the smaller ResNet-18 end-to-end. It differs from Model 1 and Model 3 by using a standard residual block design rather than MBConv or ConvNeXt blocks, and from Model 2 and Model 5 by being a pure CNN without Transformer components.
*   **Head Design**: The standard 1000-class classification head will be replaced with a single fully connected layer mapping the 512-dimensional feature vector to the 6 specific disease classes. A **Sigmoid** activation will be implicitly applied (via the loss function) to handle the multi-label nature of the task, allowing the model to predict multiple diseases for a single image.

### Data
*   **Preprocessing**: All images will be resized to a standard input resolution of **224x224** pixels. This drastically reduces the computational load compared to processing full-resolution images, ensuring the pipeline fits easily within the time limits.
*   **Normalization**: Pixel values will be normalized using the pre-calculated means and standard deviations of the ImageNet dataset to facilitate effective transfer learning.
*   **Augmentation**: To prioritize speed and establish a clean baseline, we will use minimal augmentation. Only **Random Horizontal Flips** will be applied during training. No computationally expensive transforms (like rotation or color jitter) will be used.

### Training
*   **Loss Function**: We will use **Binary Cross-Entropy with Logits Loss**. This treats each disease class as an independent binary classification problem, which is appropriate for multi-label data (e.g., an image can be both "scab" and "frog_eye_leaf_spot").
*   **Optimizer**: The **AdamW** optimizer will be used for its ability to handle weight decay correctly and converge faster than standard SGD.
*   **Precision**: We will enable **Automatic Mixed Precision (AMP)** using FP16. This leverages the NVIDIA A100's Tensor Cores to significantly accelerate training and reduce memory consumption.
*   **Scheduler**: A simple Cosine Annealing learning rate scheduler will be employed to gradually reduce the learning rate, helping the model settle into a stable minimum.

### Evaluation
*   **Inference**: The trained model will perform a forward pass on the test images to output logits, which are then converted to probabilities via the Sigmoid function.
*   **Thresholding**: We will apply a fixed threshold of **0.5** to the probabilities. If the probability for a specific disease class exceeds this threshold, the label is assigned to the image.
*   **Submission Generation**: The indices of the predicted classes will be mapped back to their string representations (e.g., "healthy", "rust") and joined by spaces to create the final submission file.
