1.  **Resolution and Capacity Upgrade**: I will increase the input image size from 224 to 320 and upgrade the backbone from ResNet18 to **ResNet34**. Higher resolution helps capture fine-grained disease features, and ResNet34 offers better feature extraction without excessive computational cost.
2.  **Class Imbalance Handling**: The dataset is imbalanced (e.g., Scab is ~30%, Powdery Mildew ~6%). I will implement **weighted `BCEWithLogitsLoss`** by calculating `pos_weight` (ratio of negatives to positives) for each class dynamically. This ensures the model pays more attention to rare classes, directly optimizing the Macro F1 metric which treats all classes equally.
3.  **Conditional Submission**: As required, I will modify the workflow to only generate a submission if the validation F1 score exceeds the baseline of ~0.8855.

I will also increase the epoch count to 15 to allow the larger model sufficient time to converge with the higher resolution inputs.

    print("Calculating class weights...")
    df = train_loader.dataset.df
    all_labels = []
    for labels_str in df["labels"]:
        all_labels.extend(labels_str.split())
    
    label_counts = {lbl: 0 for lbl in Config.CLASS_LABELS}
    for lbl in all_labels:
        if lbl in label_counts:
            label_counts[lbl] += 1
            
    # Calculate pos_weight: (N_neg / N_pos)
    N = len(df)
    pos_weights = []
    for lbl in Config.CLASS_LABELS:
        n_pos = label_counts[lbl]
        n_neg = N - n_pos
        weight = n_neg / (n_pos + 1e-6)
        pos_weights.append(weight)
    
    pos_weight_tensor = torch.tensor(pos_weights, dtype=torch.float32).to(device)
