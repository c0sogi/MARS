This script implements the end-to-end orchestration for the Apple Disease Detection task. It leverages the provided library modules to train a ResNet-18 baseline, evaluate it, perform failure analysis, and generate the final submission.

**Implementation Strategy:**
1.  **Setup**: We initialize the random seeds and detect the available device (NVIDIA A100) using the `Config` and `utils` modules.
2.  **Training**: We invoke `run_training` from the `engine` module. To ensure a fast baseline execution while retaining performance, we override the default epoch count to 5. This utilizes the pre-trained ResNet-18 model with Automatic Mixed Precision (AMP).
3.  **Validation & Metric**: We explicitly load the validation data loader and perform a full inference pass. We calculate the Mean F1-Score using the provided utility and print it in the strict format `Final Validation Metric: <value>`.
4.  **Failure Analysis**: During the validation loop, we compute simple image statistics (brightness and contrast) from the normalized tensors. We calculate the Mean Absolute Error (MAE) for each sample's prediction and compute the Pearson correlation between this error and the image statistics using pandas. This helps identify if lighting conditions correlate with model failure.
5.  **Submission**: Finally, we call `run_inference` to generate predictions on the test set and save them to `submission.csv`.
