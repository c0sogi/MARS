The following implementation demonstrates how to utilize the provided library classes and functions to create an end-to-end training and inference pipeline for the Apple Disease Detection task.

### Strategy
1.  **Configuration**: We initialize the `Config` class and override specific parameters (Epochs, Batch Size) to ensure the script runs quickly (under 5 minutes) while still exercising all code paths.
2.  **Data Loading**: We use `load_and_process_data` to load the metadata, then subsample the DataFrames to a minimal size (32 training, 16 validation, 10 test samples). This validates the data pipeline without the overhead of the full dataset.
3.  **Dataset & Transforms**: We instantiate `AppleDataset` with the appropriate `albumentations` transforms obtained from `get_transforms`. We verify the output shapes of the `DataLoader`.
4.  **Model & Training**: We set up the `AppleClassifier`, `AsymmetricLoss`, `AdamW` optimizer, and `CosineAnnealingLR` scheduler. We then execute the `fit` function from `engine.py` to train the model for 2 epochs.
5.  **Inference**: We use the trained model to perform Test Time Augmentation (TTA) inference on the test subset using `inference_tta`, verifying the output submission format.
6.  **Validation**: Assertions are placed throughout the script to strictly verify shapes, file existence, and data integrity.
