The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup and Configuration**: Initialize the environment, set random seeds for reproducibility, and define paths. The script will target the `./metadata/train.parquet` file as the source of truth for the training data to prevent data leakage.
2.  **Data Loading and Sampling**: Load the training dataset using Pandas. Given the large size of the dataset (approx. 24 million rows), a random sample of 1,000,000 rows will be extracted to ensure the analysis completes well within the 1-hour time limit while remaining statistically significant.
3.  **Data Integrity Check**: Verify that the analysis is performed strictly on the training set and check for missing or empty values within the text data.
4.  **Target Variable Analysis (Adapted for Text)**: Since the task is self-supervised (predicting a missing word), the "target" is effectively the vocabulary itself. The script will analyze the distribution of word frequencies, treating the vocabulary as classes. It will report on the imbalance between common stop words and rare words.
5.  **Input Data Analysis (Text Modality)**:
    *   **Lengths**: Analyze the distribution of sentence lengths in terms of characters and words (mean, std, min, max, outliers).
    *   **Vocabulary**: Tokenize the sampled text to calculate the unique vocabulary size and estimate the potential for Out-Of-Vocabulary (OOV) tokens based on frequency thresholds.
6.  **Feature/Signal Relationships**:
    *   **Meta-Feature Analysis**: Investigate the relationship between sentence length (word count) and lexical density (average character length of words) to see if longer sentences use more complex words.
    *   **Correlations**: Calculate the Pearson correlation between character counts and word counts.
7.  **Reporting**: Output the findings in a structured, text-based report format with capitalized sections and formatted floating-point numbers as requested.
