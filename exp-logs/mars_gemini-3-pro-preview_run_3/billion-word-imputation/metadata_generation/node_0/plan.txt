The strategy involves the following steps:
1.  **Setup and Configuration**: Define paths for input data (`./input/train_v2.txt`, `./input/test_v2.txt`) and output metadata (`./metadata`). Set the random seed to 42 and validation split ratio to 0.2.
2.  **Data Loading**: Use `pandas` to read the CSV-formatted text files. The `train_v2.txt` file is large (approx. 30 million lines), but with 220 GB of RAM, it can be loaded entirely into memory for processing.
3.  **Data Splitting**: Shuffle the training data randomly and split it into a training set (80%) and a validation set (20%). This creates a hold-out validation set since one is not provided.
4.  **Metadata Generation**: Save the resulting DataFrames (train, validation, test) as Parquet files in the `./metadata` directory. Parquet is chosen for its efficiency in storage and reading speed for large datasets. The metadata will contain the `id` and `sentence` columns, which serve as both the input and the ground truth (for the self-supervised masked language modeling task).
5.  **Verification**:
    -   Reload the generated Parquet files to ensure integrity.
    -   Print summary statistics (counts, column names).
    -   Verify the split ratio matches the requirement (80:20).
    -   Check for data leakage by ensuring no overlap of IDs between training and validation sets.
    -   Note that file path verification is skipped as the dataset contains inline text, not references to external files.
