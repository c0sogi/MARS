This script demonstrates the end-to-end usage of the provided library for the Glioblastoma genetic subtype prediction task.

### Strategy
1.  **Configuration Override**: To ensure the demonstration runs quickly (optimizing for speed), we will override the default `Config` parameters. We will reduce the number of epochs to 1 and the batch size to 2.
2.  **Data Subsetting**: Instead of processing the entire dataset (which would take time to load and cache from DICOMs), we will create a small subset of the metadata (5 samples) and point the `Config` to these temporary metadata files. This forces the `SSVEDataset` to load only a fraction of the data, verifying the data loading pipeline works without timing out.
3.  **Component Verification**: We will perform unit-test style assertions on key utility functions (`generate_strided_indices`) and the model architecture (`SSVEModel`) to ensure shapes and logic are correct.
4.  **Pipeline Execution**: We will trigger the full training (`run_training`) and inference (`run_inference`) loops using the subsetted data.
5.  **Result Validation**: Finally, we will verify that the submission file is generated correctly and follows the required format.
