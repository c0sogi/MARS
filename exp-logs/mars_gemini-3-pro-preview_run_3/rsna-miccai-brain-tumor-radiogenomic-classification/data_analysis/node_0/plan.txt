The following script performs a robust Exploratory Data Analysis (EDA) on the training dataset. It strictly adheres to the constraints, using only the training set metadata to prevent leakage. It analyzes the target distribution, extracts meta-features (slice counts, file sizes) from the MRI directory structure, attempts to read image statistics using `opencv` (handling potential format incompatibility gracefully), and evaluates feature relationships using statistical correlation and a Random Forest classifier.
