The following code demonstrates the end-to-end usage of the provided library files for the Glioblastoma MGMT promoter methylation prediction task.

### Implementation Strategy

1.  **Environment Setup**: We configure a temporary working directory (`./working/demo_run`) to store outputs and caches, ensuring we don't overwrite existing work.
2.  **Data Subsetting (Optimization)**: To ensure the demonstration runs quickly (seconds instead of minutes/hours), we create a subset of the metadata (first 10 samples) and redirect the `library.data` module to use this subset. This avoids processing thousands of DICOM files during the demo.
3.  **Model Verification**: We instantiate the `SDVNet` model and perform a forward pass with dummy tensors to verify input/output shapes and device compatibility.
4.  **Training Loop**: We execute the `run_training` function for 2 epochs on the subset data. We assert that the training completes and produces a `best_model.pth` file.
5.  **Inference**: We use the trained model to generate predictions on the test subset using `predict_submission`, verifying the output CSV format.
6.  **Reproducibility**: We use `seed_everything` to ensure deterministic results.
