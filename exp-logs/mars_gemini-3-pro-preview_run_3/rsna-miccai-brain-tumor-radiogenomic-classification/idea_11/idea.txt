Based on the comprehensive analysis of previous experiments and the derived lessons, I propose the **Modality-Grouped Stabilized 2.5D Network**.

This solution structurally evolves the "2.5D Stacking" approach. It resolves the conflict between the need for **high volumetric information density** (Cite solution_lesson_node_00012) and the **instability/overfitting** caused by high-channel inputs (Cite solution_lesson_node_00013, Cite solution_lesson_node_00034). By organizing the input tensor by modality and utilizing a **Grouped Convolutional Stem**, we can process the full 32-slice volume with significantly fewer parameters than a standard convolution, while ensuring stable initialization.

# Model
The architecture is a **2.5D Convolutional Neural Network** featuring a **Modality-Grouped Stabilized Stem**.
1.  **Input:** The model accepts a tensor of shape $(B, 128, 256, 256)$. This represents **32 spatial slices** for each of the 4 modalities ($32 \times 4 = 128$), maximizing volumetric coverage (Cite solution_lesson_node_00012). Crucially, the channels are arranged in **Modality Blocks** (e.g., channels 0-31 are FLAIR, 32-63 are T1w, etc.) rather than interleaved.
2.  **Modality-Grouped Stabilized Stem:**
    *   **Layer 1 (Modality-Wise Learning):** `Conv2d(in_channels=128, out_channels=64, kernel_size=3, padding=1, groups=4, bias=False)`.
        *   By setting `groups=4`, this layer processes each modality block (32 channels) independently, mapping it to 16 feature maps. This respects the distinct physical nature of each MRI sequence and reduces parameters by ~75% compared to a standard convolution, mitigating overfitting (Cite solution_lesson_node_00013).
    *   **Layer 2 (Cross-Modal Fusion):** `Conv2d(in_channels=64, out_channels=64, kernel_size=1, bias=False)`.
        *   This pointwise convolution mixes the features from all 4 modalities, performing **Early Fusion** (Cite solution_lesson_node_00018) before entering the backbone.
    *   **Normalization & Activation:** Both layers are followed by `BatchNorm2d` and `ReLU`.
    *   **Initialization:** Both layers must be explicitly initialized using **Kaiming/He Normal** initialization. This ensures the high-dimensional input is projected into a statistically stable feature space, preventing the gradient explosion observed in previous high-channel attempts (Cite solution_lesson_node_00034).
3.  **Backbone:** An **EfficientNet-B0** instantiated via the `timm` library (Cite solution_lesson_node_00038). We configure it with `in_chans=64` to accept the stem's output. Using the library implementation ensures we retain critical regularization like DropPath.
4.  **Head:** Global Average Pooling followed by a single fully connected layer (Sigmoid activation).

# Data
1.  **Global Volumetric Normalization:** For each patient, load the full 3D volume and normalize pixel intensities based on the global minimum and maximum of that volume. This preserves inter-slice contrast (Cite solution_lesson_node_00015).
2.  **High-Density Uniform Sampling:** Extract **32 slices** uniformly distributed across the 10%-90% depth range of the MRI volume (Cite solution_lesson_node_00003).
3.  **Block-Wise Stacking:** Unlike previous iterations that interleaved slices, stack the slices **by modality**: `[All_FLAIR_Slices, All_T1w_Slices, All_T1wCE_Slices, All_T2w_Slices]`. This alignment is required for the `groups=4` convolution to function as a modality-specific filter.
4.  **Deterministic Stride:** Ensure slices are sorted by depth index to maintain consistent physical spacing (Cite solution_lesson_node_00016).
5.  **Library Usage:** Use `pydicom` for robust data loading (Cite solution_lesson_node_00020).

# Training
1.  **Optimizer:** Use **Adam** with a learning rate of `1e-4`.
2.  **Regularization:** Do **not** use Weight Decay (AdamW) or aggressive geometric augmentations. Rely on the structural parameter reduction of the Grouped Stem and the native `timm` regularization (DropPath) (Cite solution_lesson_node_00007).
3.  **Loss Function:** **Binary Cross Entropy with Logits Loss**.
4.  **Strategy:** Train end-to-end. The Stem is trained from scratch (He init) while the backbone is fine-tuned.
