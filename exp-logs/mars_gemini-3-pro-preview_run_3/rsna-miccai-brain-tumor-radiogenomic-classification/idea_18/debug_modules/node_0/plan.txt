The following script demonstrates the usage of the provided library files to train a model and generate predictions for the Glioblastoma classification task.

The strategy involves:
1.  **Initialization**: Setting up the environment, random seeds, and logging using `library.utils`.
2.  **Data Inspection**: Using `library.data.get_dataloaders` with a `debug_limit` to quickly load a small subset of data. We then verify the shape and structure of the tensors produced by the custom `BraTSDataset`.
3.  **Model Verification**: Instantiating the `DVSEModel` from `library.model` and performing a forward pass with the dummy data to confirm the architecture produces the expected output dimensions.
4.  **Full Pipeline Execution**: Running the complete training, validation, and inference pipeline using `library.train.run` with reduced epochs and batch size for a rapid demonstration.
5.  **Output Validation**: Asserting that the submission file is generated correctly and contains valid probability predictions.
