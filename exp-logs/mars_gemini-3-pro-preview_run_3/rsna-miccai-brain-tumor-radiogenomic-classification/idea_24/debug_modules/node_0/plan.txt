This script demonstrates the usage of the provided library modules for the glioblastoma genetic subtype prediction task. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` class to enable `DEBUG` mode, reduce the dataset size, set a temporary cache directory, and limit training to 1 epoch. This ensures the demonstration runs quickly and does not interfere with full-scale training artifacts.
2.  **Data Loading Verification**: Explicitly calls `get_dataloaders` to generate PyTorch DataLoaders. It fetches a single batch to verify the input tensor shape `(Batch, 128, 224, 224)` and target shape `(Batch,)`.
3.  **Model Architecture Verification**: Instantiates the `RMSHDNet` model and performs a forward pass with the sample batch to confirm the output shape is `(Batch, 1)` (logits).
4.  **Training Pipeline Execution**: Runs the `run_training` function to simulate a full training cycle (data loading, forward/backward pass, validation, and model saving) on the reduced dataset.
5.  **Inference & Submission**: Executes `generate_submission` to load the trained model, predict on the (reduced) test set, and generate a submission file.
6.  **Validation**: Assertions are placed throughout to ensure data shapes, file existence, and logical consistency.
