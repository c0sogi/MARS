The following implementation orchestrates the end-to-end pipeline using the provided library modules.

1.  **Setup & Initialization**: The script sets the random seed for reproducibility and initializes the computing device.
2.  **Training**: It calls `run_training()` from `library.train`, which handles the entire training loop, including data loading (with caching), model initialization (S3D-Net), and early stopping. This function returns the best trained model.
3.  **Validation**: The script loads the validation set and performs a full inference pass to compute the `Final Validation Metric` (AUC). This metric is printed strictly in the required format.
4.  **Failure Analysis**: It performs a granular analysis by correlating the model's absolute prediction error on the validation set with metadata features (specifically, the number of slices per modality). This helps identify if data quantity impacts performance.
5.  **Submission**: It checks the validation AUC against the specified threshold (`0.6978181818181817`). If the condition is met, it runs inference on the test set, formats the `BraTS21ID` as integers (matching the sample submission), and saves the results to `./submission/submission.csv`.
