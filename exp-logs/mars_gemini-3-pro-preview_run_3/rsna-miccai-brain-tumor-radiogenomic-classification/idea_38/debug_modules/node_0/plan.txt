Implementation Strategy:
1.  **Setup Environment**: Configure the `Config` class to use a temporary directory in `./working` for caching and reduce the image size and dataset size (using `DEBUG` mode) to ensure the script runs quickly (within minutes).
2.  **Data Loading Demonstration**: Use `load_dataset` to process a small subset of the training data from scratch (bypassing existing caches). Verify the shape and data types of the returned NumPy arrays.
3.  **DataLoader Demonstration**: Initialize a PyTorch `DataLoader` using `get_dataloader`. Fetch a single batch to verify the dictionary structure (`even`, `odd`, `target`) and tensor dimensions.
4.  **Model Initialization**: Instantiate the `S3DNet` model. Perform a forward pass with the sample batch to verify the output shape matches `(Batch_Size, 1)`.
5.  **Training Loop Demonstration**: Run a single training epoch and a validation step using the `train_epoch` and `validate` functions. Assert that the loss is a valid number and the AUC score is calculated.
6.  **Cleanup**: Remove the temporary working directory to leave the environment clean.
