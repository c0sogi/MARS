Evaluating the truthiness of a NumPy array with multiple elements (e.g., `if not paths:`) is ambiguous and raises an exception. To resolve this, I will replace the implicit boolean check with an explicit length check (`if len(paths) == 0:`), which is robust for both lists and NumPy arrays. This approach directly addresses the root cause while maintaining the intended logic of handling empty path sequences.
