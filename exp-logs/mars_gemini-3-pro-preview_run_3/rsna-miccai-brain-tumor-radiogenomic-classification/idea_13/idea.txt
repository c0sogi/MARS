Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose the **Attention-Weighted Slice-Grouped 2.5D Network**.

This solution represents a structural evolution of the "2.5D Stacking" paradigm. It specifically resolves the critical conflict between the necessity of **high volumetric information density** (Cite solution_lesson_node_00012) and the **instability and overfitting** caused by feeding high-channel inputs directly into standard backbones (Cite solution_lesson_node_00013, Cite solution_lesson_node_00034). By introducing a **Grouped-Convolutional Stem with Slice Attention**, we enforce "Early Fusion" of modalities while dynamically suppressing noise from empty slices, all within a stabilized, parameter-efficient structure.

# Model
The architecture is a **2.5D Convolutional Neural Network** featuring a specialized stem designed to process spatially registered multi-modal slices.

1.  **Input:** The model accepts a tensor of shape $(B, 128, 256, 256)$. This represents **32 spatial slices** for each of the 4 modalities ($32 \times 4 = 128$), maximizing volumetric coverage (Cite solution_lesson_node_00012).
2.  **Attention-Weighted Slice-Grouped Stem:**
    *   **Layer 1 (Intra-Slice Feature Extraction):** `Conv2d(in_channels=128, out_channels=128, kernel_size=3, padding=1, groups=32, bias=False)`.
        *   **Mechanism:** By setting `groups=32`, the convolution is split into 32 parallel paths. Given the **Interleaved** data stacking (see Data section), each group processes exactly **4 channels** (the 4 modalities) corresponding to a single slice depth.
        *   **Benefit:** This enforces **Early Fusion** (Cite solution_lesson_node_00018) by learning pixel-level correlations between modalities for each slice independently. It drastically reduces parameters compared to a standard convolution, preventing overfitting (Cite solution_lesson_node_00013).
        *   **Initialization:** Must use **Kaiming/He Normal** initialization to prevent gradient explosion (Cite solution_lesson_node_00034).
    *   **Layer 2 (Slice-Wise Attention):** A Squeeze-and-Excitation (SE) block applied to the 128 channels.
        *   **Mechanism:** Global Average Pooling $\rightarrow$ FC $\rightarrow$ ReLU $\rightarrow$ FC $\rightarrow$ Sigmoid.
        *   **Benefit:** This allows the model to learn a weighting vector for the 32 slices. It can dynamically down-weight "empty" or irrelevant slices (e.g., skull/background) and up-weight tumor-containing slices, addressing the "noise" issue inherent in high-density sampling (Cite solution_lesson_node_00001).
    *   **Layer 3 (Channel Compression):** `Conv2d(in_channels=128, out_channels=64, kernel_size=1, bias=False)`.
        *   **Mechanism:** A pointwise convolution that mixes the features across the Z-axis (depth) and compresses the representation to 64 channels to match the backbone's expected input complexity.
    *   **Normalization:** All convolutional layers are followed by `BatchNorm2d` and `ReLU`.
3.  **Backbone:** An **EfficientNet-B0** instantiated via the `timm` library (Cite solution_lesson_node_00038). It is configured with `in_chans=64` to accept the stem's output, retaining native regularization like DropPath.
4.  **Head:** Global Average Pooling followed by a single fully connected layer (Sigmoid activation).

# Data
1.  **Global Volumetric Normalization:** For each patient, load the full 3D volume and normalize pixel intensities based on the global minimum and maximum of that volume. This preserves inter-slice contrast, ensuring that empty slices remain dark (low intensity) so the Attention mechanism can easily identify and suppress them (Cite solution_lesson_node_00015).
2.  **High-Density Uniform Sampling:** Extract **32 slices** uniformly distributed across the 10%-90% depth range of the MRI volume (Cite solution_lesson_node_00003).
3.  **Interleaved Stacking:** Stack the slices in an **interleaved** pattern: `[Slice0_FLAIR, Slice0_T1w, Slice0_T1wCE, Slice0_T2w, Slice1_FLAIR, ...]`.
    *   **Reasoning:** This ordering aligns with the `groups=32` structure of the stem, ensuring each convolutional group sees the full multi-modal context for exactly one slice depth. It also maintains a consistent physical stride (Cite solution_lesson_node_00016).
4.  **Library Usage:** Use `pydicom` for robust data loading (Cite solution_lesson_node_00020).

# Training
1.  **Optimizer:** Use **Adam** with a learning rate of `1e-4`.
2.  **Regularization:** Do **not** use Weight Decay (AdamW) or aggressive geometric augmentations. Previous lessons showed these suppress signal learning in this specific dataset (Cite solution_lesson_node_00007). Rely on the structural constraints of the Grouped Stem and `timm`'s native DropPath.
3.  **Loss Function:** **Binary Cross Entropy with Logits Loss**.
4.  **Strategy:** Train end-to-end. The Stem is trained from scratch (He init) while the backbone is fine-tuned.

# Evaluation
For each subject in the test set:
1.  Load metadata and file paths.
2.  Apply **Global Volumetric Normalization** and **High-Density Uniform Sampling** (32 slices).
3.  Construct the **Interleaved** input tensor $(128, 256, 256)$.
4.  Pass through the network. The Stem will extract multi-modal features per slice, weight them by relevance (Attention), and compress them for the backbone to predict `MGMT_value`.
