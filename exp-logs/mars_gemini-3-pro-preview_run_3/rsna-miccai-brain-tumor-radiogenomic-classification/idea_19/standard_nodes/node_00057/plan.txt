The implementation strategy follows the **Stabilized High-Density 2.5D Network (SHD-Net)** workflow as described.

1.  **Environment Setup**: We initialize the random seed and detect the compute device (GPU) using the provided utility functions to ensure reproducibility and performance.
2.  **Data Loading**: We instantiate the `BraTSDataset` for training and validation using the metadata paths defined in `Config`. This handles DICOM loading, global normalization, and caching. We wrap these in PyTorch `DataLoader`s.
3.  **Model Initialization**: We initialize the `SHDNet` model, which features the Stabilized Compression Stem and EfficientNet-B0 backbone. We define the `BCEWithLogitsLoss` and `Adam` optimizer.
4.  **Training**: We execute the training loop using the `train_model` function from the engine. This handles forward passes, backpropagation, validation monitoring, and saving the best model checkpoint based on AUC.
5.  **Evaluation & Failure Analysis**:
    *   We reload the best model checkpoint.
    *   We compute the **Final Validation Metric (AUC)** on the hold-out validation set.
    *   We perform failure analysis by calculating the absolute error for each validation sample and correlating it with metadata features (specifically, the number of slices per modality) to identify potential biases or systematic failures.
6.  **Submission**: If the validation AUC exceeds the specified threshold (0.6978...), we generate predictions for the test set and save them to `submission.csv`.
