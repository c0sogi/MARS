The following script demonstrates the end-to-end usage of the provided library components for the glioblastoma genetic subtype prediction task.

**Implementation Strategy:**
1.  **Configuration Setup**: We override specific `Config` parameters (directories, epochs, batch size) to run a fast demonstration using a temporary workspace (`./working/demo_workspace`).
2.  **Data Subsetting**: To ensure the demonstration runs quickly, we create a small subset of the original metadata (10 training, 5 validation, 5 test samples) and save it to a temporary metadata directory. This allows the data processing pipeline to finish in seconds rather than minutes.
3.  **Component Verification**:
    *   **Utils**: We verify `read_dicom_file` correctly loads and resizes images, and `get_depth_indices` returns correct slice indices.
    *   **Data Pipeline**: We run `prepare_datasets` on the subsetted metadata and verify the output shapes of the resulting `BraTSDataset` tensors (Dual-Stream format: Even/Odd streams).
    *   **Model**: We instantiate the `DualStreamSiameseNet`, perform a forward pass with dummy data, and verify the output shape.
4.  **Training Execution**: We execute `run_training` for 2 epochs on the subset data. This demonstrates the training loop, validation, and model checkpointing.
5.  **Inference & Submission**: We load the trained model, perform inference on the test subset, and generate a `submission.csv` file in the required format.
6.  **Cleanup**: We verify the existence of output files.
