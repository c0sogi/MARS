The issue is that the data loading pipeline blindly loads cached `.npy` files from a previous run (which used a different architecture/shape) without validating that the dimensions match the current model configuration. Specifically, the cache contains 5D tensors `(N, 2, 64, H, W)` while the current model expects 4D tensors `(N, 64, H, W)`. This causes a shape mismatch runtime error.

To fix this, I will modify `library/data.py` to verify the shape of the cached data against `Config.INPUT_CHANNELS` and `Config.IMG_SIZE` before loading it. If the shape is incorrect, the code will treat the cache as invalid and regenerate the dataset (Cite debug_lesson_1).
