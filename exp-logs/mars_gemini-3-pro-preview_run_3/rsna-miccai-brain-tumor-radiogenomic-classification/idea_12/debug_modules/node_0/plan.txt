The following script demonstrates the end-to-end workflow using the provided library. It performs the following steps:

1.  **Setup & Configuration**: Initializes the environment and defines a temporary working directory for the demo.
2.  **Data Subsetting**: Creates a small subset of the metadata (Train, Val, Test) to ensure the demo runs quickly (within minutes) instead of processing the full dataset.
3.  **Monkey-Patching**: Dynamically updates the paths and hyperparameters in the imported library modules to use the demo subset and reduced training epochs.
4.  **Model Verification**: Instantiates the `SliceGroupedFusionNet` and performs a dummy forward pass to verify input/output shapes.
5.  **Training Pipeline**: Executes `library.train.run_training`, which processes the subset data, trains the model for 1 epoch, and saves the best model.
6.  **Inference Pipeline**: Executes `library.predict.generate_submission` to generate predictions on the demo test set.
7.  **Validation**: Asserts that the output files exist and contain the expected data formats.
