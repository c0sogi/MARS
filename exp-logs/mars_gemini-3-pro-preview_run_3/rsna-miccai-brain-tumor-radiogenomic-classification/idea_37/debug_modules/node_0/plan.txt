The following script demonstrates the end-to-end usage of the provided library components to train and evaluate the Siamese SNR-Net model.

**Strategy:**
1.  **Configuration Override**: We modify `library.config` at runtime to enable `DEBUG` mode, reduce batch sizes, and limit the number of data samples processed. This ensures the script runs quickly (within minutes) while exercising the full data pipeline. We also redirect the cache to a temporary directory to avoid conflicts with existing full-run caches.
2.  **Data Loading**: We utilize `library.data_loader.get_dataloader` to generate PyTorch DataLoaders for training, validation, and testing. We verify the shape of the tensors produced (Even stream, Odd stream, and Labels).
3.  **Model Initialization**: We instantiate `library.model.SiameseSNRNet`, move it to the GPU, and verify a forward pass with a dummy batch.
4.  **Training & Evaluation**: We implement a standard PyTorch training loop for one epoch using `BCEWithLogitsLoss` and `Adam`. We then evaluate the model on the validation set to calculate the ROC AUC score.
5.  **Inference**: Finally, we generate predictions for the test set and format them into a submission CSV, demonstrating the required output format.
