The following script demonstrates the end-to-end usage of the provided library modules for the Glioblastoma genetic subtype prediction task.

To ensure the demonstration runs quickly and respects the resource constraints:
1.  **Data Subsetting**: We create small subsets of the original metadata (train, val, test) containing only a few samples. This significantly reduces the time required for DICOM image loading and processing.
2.  **Component Verification**: We systematically verify the `utils`, `data_loader`, `model`, `train`, and `predict` modules.
    *   **Utils**: Verifies single-patient processing and caching mechanisms.
    *   **Data Loader**: Verifies batch shapes and data types.
    *   **Model**: Verifies the Siamese network architecture and forward pass dimensions.
    *   **Training**: Runs a single epoch of the training loop to ensure the pipeline functions correctly.
    *   **Inference**: Generates a submission file using the trained model on the test subset.
