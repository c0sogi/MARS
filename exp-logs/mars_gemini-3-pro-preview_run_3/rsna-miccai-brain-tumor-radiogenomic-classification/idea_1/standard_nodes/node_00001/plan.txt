Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `library.config.Config` and ensure reproducibility with `library.utils.set_seed`.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. To ensure a fast baseline execution while maintaining sufficient learning, we will limit the epochs to 10. The training function handles data loading, model training, early stopping, and saving the best checkpoint.
3.  **Validation Assessment**:
    *   Reload the best saved model.
    *   Run inference on the full hold-out validation set.
    *   Compute the Area Under the ROC Curve (AUC) score.
    *   Print the required metric string: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Calculate the absolute error magnitude for each validation sample (`|prediction - target|`).
    *   Extract meta-features from the validation metadata (specifically, the number of slices per MRI modality) as these are the variable "input features" distinct from the standardized pixel tensors.
    *   Compute and print the correlation between the error magnitude and these meta-features to identify if data quantity/quality affects performance.
5.  **Submission**: Generate the final predictions for the test set using `library.predict.generate_submission`, which saves the results to `./submission/submission.csv`.
