The strategy for the `runfile.py` implementation is as follows:

1.  **Configuration Setup**: Import the `Config` class and override specific parameters to ensure the pipeline runs within the 2-hour limit. Specifically, reduce the number of notebooks for fine-tuning (e.g., to 5,000) and the number of LightGBM boosting rounds (e.g., to 500).
2.  **Pipeline Execution**:
    *   **Fine-Tuning**: Call `train_semantic_model` to fine-tune the SentenceTransformer backbone on the reduced dataset.
    *   **Regression Training**: Call `train_lgbm_regressor` to generate features and train the LightGBM model.
3.  **Validation and Analysis**:
    *   Manually reload validation features and the trained model to perform a detailed evaluation.
    *   Compute predictions and calculate the Mean Absolute Error (MAE) for each markdown cell.
    *   **Failure Analysis**: Calculate the Pearson correlation between the prediction error and input features (e.g., `n_code`, `md_len`, similarity scores) to identify sources of model weakness.
    *   **Metric Calculation**: Reconstruct the cell orders for the validation set and compute the global Kendall Tau metric. Print this metric in the required format.
4.  **Submission**:
    *   Compare the calculated validation metric against the threshold (0.8061).
    *   If the threshold is met, call `generate_submission_file` to produce the final `submission.csv`.
