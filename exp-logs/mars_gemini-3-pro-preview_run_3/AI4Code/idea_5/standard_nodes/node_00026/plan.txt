The solution implements the Multi-View Semantic Alignment pipeline. It begins by configuring the environment for a fast baseline execution, setting the debug sample size to 10,000 to ensure the process completes within the 2-hour limit while providing sufficient data for training.

The pipeline proceeds in four main stages:
1.  **Fine-Tuning**: It fine-tunes `microsoft/codebert-base` and `all-mpnet-base-v2` on a subset of the training data using contrastive loss to align markdown and code representations.
2.  **Feature Engineering**: It generates semantic features (raw and smoothed similarity matrices) for the training subset, the full validation set, and the full test set. This ensures the regressor is trained on a representative sample but evaluated on the complete hold-out sets.
3.  **Regression & Evaluation**: A LightGBM regressor is trained to predict the relative rank of markdown cells. The model is evaluated on the full validation set, and the Kendall Tau correlation is computed. Failure analysis is performed by correlating prediction errors with input features to identify weaknesses.
4.  **Submission**: If the validation Kendall Tau score exceeds the threshold of 0.8061, the model generates predictions for the test set and saves the submission file.
