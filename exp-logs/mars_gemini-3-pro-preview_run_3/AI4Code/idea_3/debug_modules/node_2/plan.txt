The issue is that the `InformationRetrievalEvaluator` in `library/model_finetuning.py` is initialized with `score_functions={"cosine": True}`, passing a boolean flag where a callable function is expected. This causes a `TypeError` when the evaluator attempts to call `True` as a function during validation. To fix this, I will import `util` from `sentence_transformers` and map the "cosine" key to `util.cos_sim`, ensuring the evaluator has a valid function to compute similarity scores.
