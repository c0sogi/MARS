The following script demonstrates the usage of the provided 2.5D U-Net++ MRI segmentation pipeline. It performs the following steps:

1.  **Configuration**: Overrides default hyperparameters in `CFG` to run a fast, minimal demonstration (Debug mode, 1 epoch, small batch size).
2.  **Utility Verification**: Validates RLE encoding/decoding and metric calculation functions (Dice, Hausdorff) using synthetic data.
3.  **Dataset Pipeline**: Loads metadata, processes 2.5D context (t-1, t, t+1), and validates the `UWMGIDataset` output shapes and normalization.
4.  **Model & Loss**: Instantiates the U-Net++ model and `CompositeLoss`, performing a forward pass and loss calculation to verify architectural integrity.
5.  **Training Loop**: Executes the full training routine (`train()`) for one epoch on a subset of data to generate model checkpoints.
6.  **Inference**: Runs the inference pipeline (`predict_and_submit()`) using the trained checkpoint to generate a submission file.
