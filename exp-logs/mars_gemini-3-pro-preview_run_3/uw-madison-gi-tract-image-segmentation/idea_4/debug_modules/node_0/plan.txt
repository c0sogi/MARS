The following script demonstrates the usage of the provided library components for the medical image segmentation task. It follows a structured approach:

1.  **Component Verification**: Validates utility functions (RLE encoding/decoding, 3D Connected Component Analysis) and metrics (Dice, Hausdorff) using synthetic data to ensure correctness.
2.  **Data Pipeline Verification**: Initializes the data loaders in debug mode and verifies the shape and structure of the 2.5D image volumes and segmentation masks.
3.  **Model & Loss Verification**: Instantiates the `UnetPlusPlus` model and `BCETverskyLoss`, performs a forward pass with real data, and verifies the output shapes and loss calculation.
4.  **Training Integration**: Executes a full training cycle for 1 epoch using the `Trainer` class on a subset of data to demonstrate the training loop and checkpoint generation.
5.  **Inference Integration**: Runs the inference pipeline using the generated checkpoint to produce a submission file, validating the output format.
