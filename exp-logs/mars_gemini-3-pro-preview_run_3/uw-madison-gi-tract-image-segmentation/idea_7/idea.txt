Based on the comprehensive analysis of previous attempts and the synthesized lessons, I propose the following optimized strategy. This approach introduces a **Multi-Task U-Net++** architecture and a **Native-Resolution Geometry Pipeline**. This strategy structurally evolves the model to explicitly handle the "empty slice" ambiguity (addressing Lesson 00012) while strictly adhering to the geometric fidelity required for the Hausdorff metric (addressing Lessons 00027 and 00028).

### Model
**Architecture: Multi-Task 2.5D U-Net++ with EfficientNet-B5**
I propose upgrading the architecture to a **Multi-Task U-Net++** with an **EfficientNet-B5** backbone.
*   **Structural Innovation (Auxiliary Classification Head):** To address the issue where models overfit to empty background slices or hallucinate organs in noise (Cite solution_lesson_node_00012), I will attach a global classification head to the encoder's bottleneck. This head will predict a binary vector indicating the presence/absence of each organ class in the current slice. This auxiliary task forces the encoder to learn robust global features and acts as a regularizer for the segmentation head.
*   **Backbone & Segmentation Head:** We will scale up to **EfficientNet-B5** to leverage the A100's capacity, as heavier backbones have shown faster convergence with Deep Supervision (Cite solution_lesson_node_00020). The decoder will remain a U-Net++ structure with nested skip connections to bridge the semantic gap for multi-scale organs (Cite solution_lesson_node_00020).
*   **2.5D Input:** The model will accept 3-channel inputs ($t-1, t, t+1$) to provide volumetric context (Cite solution_lesson_node_00004).

### Data
**Preprocessing: Native-Resolution "Pad-to-Max" Pipeline**
I will implement a strict **No-Resizing** policy to maximize spatial fidelity.
*   **Pad-to-Max:** The maximum image dimension in the dataset is 360 pixels. Previous attempts compromised performance by downsampling to 320 (Cite solution_lesson_node_00027) or warping aspect ratios (Cite solution_lesson_node_00022). I will **pad** all images to a fixed resolution of **384x384** (the nearest multiple of 32 > 360). This ensures that **100% of the original pixel data is preserved** without interpolation artifacts.
*   **Deterministic Metadata:** During loading, we will calculate and store the exact padding offsets (top, left) for each sample. This metadata will be passed through the pipeline to ensure pixel-perfect reconstruction during inference (Cite solution_lesson_node_00028).
*   **Normalization:** We will apply **Robust Per-Slice Normalization** (clipping to 1st/99th percentiles) to handle MRI intensity variations without being sensitive to outliers (Cite solution_lesson_node_00002, solution_lesson_node_00004).

### Training
**Protocol: Multi-Task Optimization with Deep Supervision**
*   **Loss Function:** The objective will be a weighted sum: $L_{total} = L_{seg} + \lambda L_{cls}$.
    *   $L_{seg}$: **BCE + Tversky Loss** ($\alpha=0.3, \beta=0.7$) to penalize False Positives in the segmentation masks (Cite solution_lesson_node_00005).
    *   $L_{cls}$: **Binary Cross Entropy** for the auxiliary classification head.
*   **Deep Supervision:** We will enable Deep Supervision on the segmentation decoder to prevent model collapse and accelerate gradient flow (Cite solution_lesson_node_00024).
*   **Stateful Optimization:** We will use **Automatic Mixed Precision (AMP)** with the `GradScaler` instantiated **outside** the epoch loop to ensure stable convergence (Cite solution_lesson_node_00009).
*   **Data Volume:** We will train on the **full dataset** to satisfy the data requirements of the B5 backbone (Cite solution_lesson_node_00013).

### Evaluation
**Inference: Deterministic Restoration and Volumetric Filtering**
*   **Coordinate Restoration:** Predictions generated at 384x384 will be cropped back to the original image dimensions using the stored padding metadata. This **Deterministic Restoration** eliminates the alignment errors that previously degraded the Hausdorff score (Cite solution_lesson_node_00028).
*   **Metric-Based Selection:** We will ignore 2D Slice Dice. Model checkpointing will be based on the **3D Competition Metric** (Dice + Hausdorff) calculated on the full validation volume at the end of each epoch (Cite solution_lesson_node_00010).
*   **3D Post-Processing:** We will apply **3D Connected Component Analysis (CCA)** to the reconstructed volumes, retaining only the largest connected component per class to remove scattered outliers (Cite solution_lesson_node_00005).
