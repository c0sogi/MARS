The following script demonstrates the end-to-end usage of the provided MRI segmentation library. It performs the following steps:
1.  **Configuration & Setup**: Initializes the environment with a fixed seed and debug configuration for speed.
2.  **Data Processing**: Generates the 2.5D metadata (linking adjacent slices) and validates the dataframe structure.
3.  **Dataset Verification**: Instantiates the dataset and transforms, verifying input tensor shapes (3 channels for 2.5D) and mask integrity.
4.  **Model Verification**: Instantiates the Feature Pyramid Network (FPN) and performs a dummy forward pass to confirm output dimensions.
5.  **Metric Verification**: Manually tests the Dice coefficient and 3D Hausdorff distance functions with synthetic data.
6.  **Training**: Runs a complete training loop in debug mode (fewer epochs, smaller dataset) and asserts a valid validation score is returned.
7.  **Inference**: Runs the inference pipeline using the trained model on a subset of test data and validates the submission file format.
