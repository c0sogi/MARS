The issue lies in the incorrect usage of PyTorch's `GradScaler` for mixed precision training in `library/engine.py`. The method `scaler.scale()` is designed to scale tensors (like the loss) to prevent underflow, but the code attempts to pass the `optimizer` object to it via `scaler.scale(optimizer).step()`. The correct method to perform the optimizer step with a scaler is `scaler.step(optimizer)`, which internally unscales the gradients before updating parameters.
