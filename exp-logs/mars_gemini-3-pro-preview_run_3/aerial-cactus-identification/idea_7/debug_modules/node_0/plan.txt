### Implementation Strategy

1.  **Configuration Override**: To ensure the script runs quickly within the time limit, I will modify the `Config` class attributes at runtime. I will enable `DEBUG` mode (which subsamples the dataset), reduce `EPOCHS` to 1, and set a small `BATCH_SIZE`. I will also redirect the working directory to a demo-specific folder.
2.  **Data Loading Verification**: I will instantiate the training and test data loaders using `library.data_loader`. I will fetch a single batch to verify the tensor shapes (Batch Size, Channels, Height, Width) and label shapes.
3.  **Architecture Verification**: I will iterate through the model names defined in `Config.MODELS`, instantiate each using `library.architectures.get_model`, and perform a forward pass with dummy data to confirm they output the correct shape `(Batch Size, 1)`.
4.  **Training Engine Demonstration**: I will select one model (Wide SE-ResNet) and run a complete training and validation step using `library.engine`. This verifies the loss calculation, backpropagation, and metric evaluation logic. I will also demonstrate Test-Time Augmentation (TTA) prediction.
5.  **Stacking Logic Demonstration**: Instead of training multiple models fully, I will simulate Out-Of-Fold (OOF) predictions and Test predictions using numpy arrays. I will then feed these into `library.stacking.train_meta_learner` and `generate_submission` to verify the meta-learner training and submission file generation.
6.  **Assertions**: Throughout the script, I will use `assert` statements to validate shapes, types, and file existence, ensuring the components work as expected.
