The following implementation demonstrates how to use the provided library modules (`utils`, `models`, `data`, `trainer`) to build a complete training and inference pipeline.

### Implementation Strategy
1.  **Setup**: Initialize random seeds and define the computation device (CPU/GPU).
2.  **Data Loading**: Use `load_and_cache_data` to load a small subset of the training and validation data (64 and 32 samples respectively) to ensure the script executes quickly.
3.  **Dataset Creation**: Wrap the loaded data in `CactusDataset` and apply augmentations using `get_transforms`.
4.  **Model Initialization**: Instantiate the `ModifiedWideSEResNet` and `ModifiedDenseNet` models. We verify their correctness by passing a dummy batch of data and checking the output shape. We use a reduced layer configuration for the ResNet to speed up the demonstration.
5.  **Training Loop**: Run a short training loop (2 epochs) using `train_one_epoch` and `validate` from the `trainer` module. This verifies the loss calculation, backpropagation, and metric evaluation.
6.  **Inference**: Demonstrate Test-Time Augmentation (TTA) using `predict_tta` on the validation set.
7.  **State Saving**: Use `save_state_dict` to save the trained model to disk.
