Based on the empirical lessons learned, I propose a **Stacked Heterogeneous Ensemble with K-Fold Cross-Validation**. This strategy evolves the previous simple ensemble into a robust stacking pipeline. It addresses the issue of "ensemble dilution" (Lesson 00013) by learning optimal combination weights rather than blindly averaging, and it maximizes data utility through cross-validation while adhering to the strict geometric constraints of low-resolution imagery (Lesson 00014).

### Model
I propose a **Heterogeneous Ensemble** consisting of two architecturally distinct base models, followed by a **Logistic Regression Meta-Learner** for prediction fusion.

1.  **Base Architectures**:
    *   **Wide SE-ResNet**: A Wide Residual Network augmented with Squeeze-and-Excitation blocks to model channel interdependencies.
    *   **DenseNet-BC**: A Densely Connected Network to maximize feature reuse and gradient flow.
    *   **Crucial Adaptation**: Both architectures will strictly modify the input "stem" layer. The standard 7x7 convolution (stride 2) and max-pooling layers will be replaced with a **single 3x3 convolution with stride 1**. This ensures the 32x32 spatial resolution is preserved for feature extraction, preventing the premature loss of fine details `Cite solution_lesson_node_00008`.

2.  **Stacking Structure**:
    *   Instead of a single model instance, we will instantiate **5 instances** of each architecture (10 models total) corresponding to a **5-Fold Cross-Validation** scheme.
    *   A **Meta-Learner (Logistic Regression)** will be trained on the Out-Of-Fold (OOF) predictions from the training set to learn the optimal weighting for combining the two architectures. This explicitly solves the "dilution" risk where weaker models degrade the ensemble performance in a simple average `Cite solution_lesson_node_00013`.

### Data
1.  **Preprocessing**:
    *   Images will be converted to tensors and normalized to the [0, 1] range.
    *   The training data will be split into **5 Stratified Folds** to ensure class distribution is preserved across all training and validation subsets.

2.  **Augmentation Strategy**:
    *   **Geometric (Lossless)**: We will strictly limit geometric augmentation to **RandomHorizontalFlip** and **RandomVerticalFlip**. We will **exclude** aggressive affine transformations (like large rotations or shears) which were found to degrade performance on 32x32 images due to interpolation artifacts and information loss `Cite solution_lesson_node_00014`.
    *   **Photometric**: We will apply **ColorJitter** (brightness and contrast) to the training data to resolve the model's proven sensitivity to lighting variations `Cite solution_lesson_node_00002`.
    *   **Regularization**: We will apply **Mixup augmentation** ($\alpha=1.0$) to the training batches. This encourages the high-capacity models to learn smoother decision boundaries and prevents overfitting `Cite solution_lesson_node_00010`.

### Training
1.  **Procedure**:
    *   We will train each of the 10 models (2 architectures $\times$ 5 folds) independently.
    *   **Optimizer**: Adam optimizer with a **Cosine Annealing** learning rate scheduler.
    *   **Loss Function**: Binary Cross Entropy.

2.  **Checkpointing & Convergence**:
    *   We will implement Early Stopping based on Validation AUC.
    *   **Extended Patience**: Because Mixup regularization slows convergence, we will set a high patience (e.g., 20 epochs) to prevent premature termination `Cite solution_lesson_node_00011`.
    *   **State Preservation**: We will strictly use **`copy.deepcopy(model.state_dict())`** when saving the best model weights. This ensures we retain the exact parameters that achieved the best metric, rather than a reference to the mutable state which would be overwritten by subsequent optimization steps `Cite solution_lesson_node_00001`.

### Evaluation
1.  **Inference (Base Models)**:
    *   For the Test Set, each of the 10 trained models will generate predictions.
    *   We will employ **Test-Time Augmentation (TTA)**: For every image, predictions will be generated for the original, horizontally flipped, and vertically flipped versions, then averaged. This enforces the rotational invariance required for aerial imagery `Cite solution_lesson_node_00008`.

2.  **Fusion (Stacking)**:
    *   The OOF predictions generated during training will be used to train the **Logistic Regression Meta-Learner**.
    *   The TTA-averaged test predictions from all 10 base models will be fed into this meta-learner to produce the final `has_cactus` probability. This ensures that the contribution of each architecture is weighted by its validated reliability, maximizing the ensemble's AUC.
