This script demonstrates the end-to-end usage of the provided library components for the Cactus Identification task. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration parameters to ensure a rapid execution (1 epoch, debug mode) suitable for demonstration and testing.
2.  **Data Validation**: Verifies that the `CactusDataset` and `DataLoader` correctly load images and labels with the expected shapes and types.
3.  **Model Verification**: Instantiates the `CactusResNet` model and performs a forward pass with a dummy batch to confirm the architecture produces outputs of the correct dimensionality.
4.  **Metric Logic Check**: Validates the `calculate_roc_auc` utility function using synthetic data to ensure metric calculation is accurate.
5.  **Training Pipeline**: Executes the `run_training` function to train the model on a small subset of data, verifying that the training loop completes and saves a model checkpoint.
6.  **Inference Pipeline**: Runs `run_prediction` using the trained checkpoint to generate predictions on the test set (debug subset), ensuring the submission file is generated correctly.
7.  **Submission Validation**: Checks the format and content of the generated submission CSV file.
