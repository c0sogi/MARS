Strategy Outline:
1.  **Configuration:** Initialize `Config` with `epochs=6` to ensure the 15-model ensemble (3 architectures $\times$ 5 folds) completes comfortably within the execution time limit while still learning effective features.
2.  **Training & OOF Generation:** Iterate through the three defined architectures (SE-ResNeXt50, DenseNet121, ResNet34) and 5 stratified folds. For each combination, train the model using `fit_model` (which includes Mixup and stem surgery). Collect and store Out-Of-Fold (OOF) predictions keyed by image ID to ensure proper alignment later.
3.  **Stacking:** Construct a feature matrix from the aligned OOF predictions of all base models. Train a Logistic Regression meta-learner to fuse these predictions, optimizing the ensemble weights.
4.  **Validation:** Compute the final ROC AUC score of the meta-learner's predictions against the ground truth labels to serve as the "Final Validation Metric".
5.  **Failure Analysis:** Load the training images and extract basic meta-features (brightness, contrast). Calculate the absolute error of the ensemble's OOF predictions and compute the Pearson correlation between this error and the meta-features to identify systematic failure modes.
6.  **Inference & Submission:** Generate test set predictions by averaging TTA outputs across all 5 folds for each architecture. Feed these aggregated predictions into the trained meta-learner to produce the final `has_cactus` probabilities and save the submission file.
