This script demonstrates the end-to-end workflow for the Cactus Identification task using the provided library modules.

**Implementation Strategy:**
1.  **Configuration**: We modify the `Config` class to enable `DEBUG` mode and reduce `EPOCHS` to 2. This ensures the script runs quickly (using only 500 samples) while exercising all code paths.
2.  **Data Preparation**: We load the training, validation, and test datasets using `load_data`. We create PyTorch `DataLoader` instances for each.
3.  **Model Training Loop**: We iterate through the three supported architectures (`resnet`, `densenet`, `efficientnet`). For each:
    *   We initialize the model using `get_model`.
    *   We train it for a few epochs using `train_one_epoch`.
    *   We generate predictions on the validation set (to simulate Out-Of-Fold predictions) and the test set using `predict_tta`.
4.  **Ensemble Stacking**: We utilize the `EnsembleStacker` to train a meta-learner (Logistic Regression) on the validation predictions and then generate the final fused predictions for the test set.
5.  **Submission**: We save the final predictions to `submission.csv`.
6.  **Verification**: Assertions are placed throughout to verify data shapes, prediction output formats, and file generation.
