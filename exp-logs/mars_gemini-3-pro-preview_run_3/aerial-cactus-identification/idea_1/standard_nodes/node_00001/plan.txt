The implementation strategy involves creating a single Python script `runfile.py` that orchestrates the entire machine learning pipeline using the provided library modules.

1.  **Setup & Configuration**: The script initializes the environment by setting random seeds for reproducibility and selecting the appropriate compute device (GPU/CPU). It defines constants for file paths and hyperparameters suited for a fast baseline (e.g., 10 epochs, batch size 64).
2.  **Data Loading**: It utilizes `library.dataset.create_dataloaders` to efficiently load training, validation, and test data. It enables caching (`load_cached_data=True`) to speed up data preprocessing.
3.  **Model Training**: The script instantiates the `SimpleCNN` model, Binary Cross Entropy loss, and Adam optimizer. It calls `library.train.fit_model` to execute the training loop, which includes early stopping to prevent overfitting and restore the best model weights.
4.  **Validation**: Post-training, it evaluates the model on the full validation set using `library.model.validate` to compute the Area Under the ROC Curve (AUC). It prints this metric in the specific required format.
5.  **Failure Analysis**: A dedicated function calculates the absolute error between model predictions and ground truth on the validation set. It then computes and prints the Pearson correlation between these errors and image meta-features (brightness and contrast) to identify potential weaknesses.
6.  **Submission**: Finally, the script generates predictions for the test set using `library.model.predict` and saves them to a CSV file in the required format.
