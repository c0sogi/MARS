To establish a robust and efficient baseline for the cactus classification task, I propose a **Simple Convolutional Neural Network (SimpleCNN)**. This approach synthesizes the convolutional principles found in the DenseNet architecture (Model 1) but strips away the complex dense connectivity and transition layers to prioritize speed and simplicity.

# Model
The architecture is a lightweight, sequential Convolutional Neural Network designed specifically for the small 32x32 input size.
*   **Input**: Accepts 32x32 RGB images.
*   **Feature Extraction**: The network consists of three sequential convolutional blocks. Each block contains:
    *   A **2D Convolution** layer with a 3x3 kernel and padding to preserve spatial dimensions (filters increasing, e.g., 32, 64, 128).
    *   **Batch Normalization** to stabilize training and accelerate convergence.
    *   **ReLU** activation for non-linearity.
    *   **Max Pooling** (2x2) to downsample the spatial dimensions and reduce computational cost.
*   **Classification Head**: Instead of flattening the feature map (which can lead to a large number of parameters), the model uses **Global Average Pooling** to condense the spatial features into a single vector. This is followed by a single **Dense (Fully Connected)** layer with a **Sigmoid** activation function to output the probability of the class `has_cactus`.

# Data
*   **Preprocessing**: All images (train, validation, and test) will be loaded and converted to floating-point tensors. Pixel intensity values will be normalized to the range **[0, 1]** by dividing by 255.0.
*   **Augmentation**: To maintain a strict baseline philosophy, augmentation will be minimal. Only **Random Horizontal Flipping** will be applied to the training set to encourage basic invariance. No augmentation will be applied to validation or test sets.
*   **Loading**: Data will be loaded using standard batch generators (e.g., PyTorch `DataLoader`) utilizing the file paths and labels provided in the metadata CSV files.

# Training
*   **Loss Function**: **Binary Cross Entropy (BCE)** loss will be used, as this is a binary classification task.
*   **Optimizer**: The **Adam** optimizer will be employed for its adaptive learning rate properties, minimizing the need for hyperparameter tuning compared to SGD.
*   **Procedure**: The model will be trained for a fixed number of epochs (e.g., 20). **Early Stopping** will be implemented to monitor the Area Under the ROC Curve (AUC) on the validation set, stopping training if performance does not improve for a set number of epochs. The model weights yielding the highest validation AUC will be restored.

# Evaluation
*   **Inference**: The trained model will process the test dataset in batches.
*   **Prediction**: The model will output a probability score (0 to 1) for each image.
*   **Submission**: These probabilities will be mapped to their corresponding image IDs and saved to a CSV file, adhering strictly to the required submission format.
