The implementation strategy is as follows:

1.  **Setup and Directories**: Define the input directory (`./input`) and the output metadata directory (`./metadata`). Ensure the output directory exists.
2.  **Load Data**: Read `train.csv` to get training labels and IDs. Read `sample_submission.csv` to get test IDs.
3.  **Path Construction**: Construct relative file paths for the images. For training data, paths will be `train/<id>`, and for test data, `test/<id>`.
4.  **Data Splitting**: Perform a stratified 80/20 split on the training data using the `has_cactus` label to create training and validation sets. Use `random_state=42` for reproducibility.
5.  **Save Metadata**: Save the resulting DataFrames (train, validation, test) to CSV files in the `./metadata` directory.
6.  **Verification - Statistics**: Reload the saved metadata and print summary statistics (counts, class distributions).
7.  **Verification - File Existence**: Randomly sample 1000 paths from each dataset and verify that the files actually exist in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
8.  **Verification - Stratification**: Check that the class distribution in the validation set closely matches the training set. Raise an assertion error if the split logic failed.
