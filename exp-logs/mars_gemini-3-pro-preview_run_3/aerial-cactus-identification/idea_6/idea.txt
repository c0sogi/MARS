Based on the empirical lessons learned and the saturation of the current metric, I propose a **Quad-Architecture Heterogeneous Stacking Strategy**. This approach evolves the previous "Orthogonal Triad" by introducing a fourth, fundamentally distinct architectural paradigm—**Self-Attention**—to capture global dependencies that Convolutional Neural Networks (CNNs) might miss.

# Model
To maximize the Area Under the ROC Curve (AUC) by leveraging architectural diversity `Cite solution_lesson_node_00018`, I propose an ensemble of four base models, each representing a distinct inductive bias.

1.  **Base Architectures (The "Orthogonal Quartet"):**
    *   **Modified Wide SE-ResNet:** Captures features via residual learning and channel-wise attention (Squeeze-and-Excitation) `Cite solution_lesson_node_00012`.
    *   **Modified DenseNet-BC:** Maximizes feature reuse and gradient flow through dense concatenations `Cite solution_lesson_node_00012`.
    *   **Modified EfficientNet:** Utilizes Inverted Residual blocks (MBConv) to expand features into high-dimensional space before filtering `Cite solution_lesson_node_00018`.
    *   **Compact Convolutional Transformer (CCT) [New]:** I will introduce a Transformer-based architecture designed specifically for small datasets (CIFAR-scale). Unlike the CNNs above which rely on local receptive fields, CCT employs a **Sequence Pooling** mechanism and **Self-Attention** layers to capture global context and long-range dependencies. Crucially, it uses a convolutional tokenizer to process the 32x32 input, avoiding the patch-size limitations of standard ViTs.
    *   **Crucial Adaptation:** For the three CNNs, the "stem" will remain a **single 3x3 convolution with stride 1** to preserve the 32x32 spatial resolution `Cite solution_lesson_node_00008`. The CCT will inherently handle this via its convolutional tokenizer.

2.  **Stacking Meta-Learner:**
    *   Predictions from these four architectures will be fused using a **Logistic Regression Meta-Learner** trained on **Out-Of-Fold (OOF)** predictions from 5-Fold Stratified Cross-Validation. This ensures the ensemble learns to weight contributions based on validated reliability rather than simple averaging `Cite solution_lesson_node_00015`.

# Data
1.  **Preprocessing:**
    *   Images will be converted to floating-point tensors and normalized to the [0, 1] range.
    *   Data will be split into **5 Stratified Folds**.

2.  **Augmentation Strategy:**
    *   **Geometric (Lossless Only):** We will strictly limit geometric transformations to **RandomHorizontalFlip** and **RandomVerticalFlip**. We will **exclude** rotation and shear to avoid interpolation artifacts that degrade performance on low-resolution 32x32 images `Cite solution_lesson_node_00014`.
    *   **Photometric:** We will apply **ColorJitter** (brightness and contrast) to resolve sensitivity to lighting variations `Cite solution_lesson_node_00002`.
    *   **Regularization:** We will apply **Mixup augmentation** ($\alpha=1.0$) to the training batches to encourage smoother decision boundaries and prevent overfitting `Cite solution_lesson_node_00010`.

# Training
1.  **Optimization:**
    *   **Optimizer:** All models will be trained using **AdamW** with weight decay to ensure stable regularization `Cite solution_lesson_node_00016`.
    *   **Hardware Optimization:** We will explicitly set `torch.backends.cudnn.benchmark = True` to enable the cuDNN autotuner for the fixed 32x32 input size `Cite solution_lesson_node_00017`.

2.  **Procedure:**
    *   **Shortened Cycles:** We will train each of the 20 models (4 architectures $\times$ 5 folds) for a moderate number of epochs (e.g., 15-20). We prioritize the diversity of the ensemble over the extended convergence of any single model, as this yields better returns on the compute budget `Cite solution_lesson_node_00018`.
    *   **Checkpointing:** We will use **`copy.deepcopy(model.state_dict())`** to save the best weights, ensuring the stored state is immutable `Cite solution_lesson_node_00001`.
    *   **Patience:** We will maintain a relaxed early stopping patience to accommodate the slower convergence caused by Mixup `Cite solution_lesson_node_00011`.

# Evaluation
1.  **Inference:**
    *   We will employ **Test-Time Augmentation (TTA)** using the original, horizontally flipped, and vertically flipped versions of each test image. These predictions will be averaged to enforce rotational invariance `Cite solution_lesson_node_00008`.

2.  **Fusion:**
    *   The TTA-averaged predictions from all 20 base models will be fed into the trained Logistic Regression meta-learner to generate the final probability `Cite solution_lesson_node_00015`.
