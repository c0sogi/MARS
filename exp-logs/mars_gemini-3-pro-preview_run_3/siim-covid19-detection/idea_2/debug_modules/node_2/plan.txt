The issue is that `torchvision` detection models (like RetinaNet) strictly require the target bounding boxes tensor to have a shape of `[N, 4]`, even when there are no objects in the image (i.e., `N=0`, shape should be `[0, 4]`). In the current implementation of `ChestXRayDataset`, when the `boxes` list is empty (for "Negative" cases), `torch.as_tensor(boxes)` produces a tensor of shape `[0]`. This causes an `AssertionError` during the model's forward pass.

To fix this, I will modify `library/dataset.py` to explicitly create a tensor of shape `(0, 4)` when the list of bounding boxes is empty.
