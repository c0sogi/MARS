This script demonstrates the end-to-end usage of the provided machine learning pipeline for radiograph classification and detection. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration parameters (paths, batch size, epochs) to create a lightweight, fast-running environment suitable for demonstration.
2.  **Data Preparation**: Samples a small subset of the real metadata to create temporary training, validation, and test sets. This ensures the code runs on actual data without the overhead of processing the entire dataset.
3.  **Component Verification**:
    *   **Utils**: Validates bounding box to mask conversion logic.
    *   **Dataset**: Verifies the `SIIMDataset` class, ensuring images and masks are loaded with correct shapes and types.
    *   **Model**: Instantiates the `MultiTaskUNet`, performs a forward pass with dummy data, and asserts output shapes.
    *   **Loss**: Calculates loss using `MultiTaskLoss` to ensure numerical stability.
4.  **Training & Inference Simulation**:
    *   Executes a single training epoch and validation step using the `train` module.
    *   Runs the inference pipeline using the `predict` module to generate a submission file.
    *   Validates the format and content of the generated submission.
