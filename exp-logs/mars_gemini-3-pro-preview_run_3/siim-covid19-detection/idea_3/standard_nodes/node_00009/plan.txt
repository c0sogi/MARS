3.  **Training Loop**: We will implement a standard PyTorch training loop using the `MultiTaskUNet` model and `MultiTaskLoss`. We will track validation loss to save the best model checkpoint.
4.  **Metric Calculation (mAP)**: We will implement a custom `calculate_global_map` function to compute the PASCAL VOC 2010 Mean Average Precision at IoU > 0.5. This involves running inference on the validation set, scaling predicted bounding boxes back to original image dimensions, and comparing them against ground truth boxes globally.
5.  **Failure Analysis**: During the validation pass, we will also compute the Dice score for each image. We will calculate the correlation between the "Error" (1 - Dice) and image metadata (width, height, aspect ratio) to identify systematic failures.
6.  **Submission**: Finally, we will invoke `library.predict.generate_submission` to generate predictions for the test set and save the `submission.csv` file.
