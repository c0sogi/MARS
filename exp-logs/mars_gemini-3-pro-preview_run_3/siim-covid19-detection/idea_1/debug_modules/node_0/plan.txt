The following implementation demonstrates the end-to-end usage of the provided library components for the SIIM-FISABIO-RSNA COVID-19 Detection task.

### Strategy Outline
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to set up a temporary working directory and reduce hyperparameters (image size, batch size, epochs) for rapid execution.
2.  **Dataset Instantiation**: We initialize the `SIIMDataset` for training and validation, subsetting them to a very small number of samples (20 for train, 10 for val) to ensure the script runs quickly.
3.  **Data Verification**: We fetch a single batch from the `DataLoader` to verify the shape of images and the structure of the target dictionaries (bounding boxes, labels, study labels).
4.  **Model Training**: We instantiate the `MultiTaskFasterRCNN` model and run a short training loop (1 epoch) using the `train_model` engine function. We verify that the loss is calculated correctly and a model checkpoint is saved.
5.  **Inference & Submission**: We use the `generate_submission` function to load the trained model, run inference on a subset of the test data, and generate a submission CSV. We assert the validity of the output file format.
