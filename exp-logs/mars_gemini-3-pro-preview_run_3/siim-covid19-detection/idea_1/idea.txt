To establish a robust and efficient baseline, I propose a **Multi-Task Faster R-CNN** architecture. This approach utilizes a standard two-stage object detection framework but extends it with a parallel classification head, allowing for the simultaneous prediction of study-level categories and image-level bounding boxes within a single forward pass. This design is distinct from the one-stage (YOLO), transformer-based (DETR), weakly supervised (CAM), segmentation-based (U-Net), and embedding-based (DINOv2) approaches previously listed.

### Model
The architecture is built upon a **ResNet-18** backbone equipped with a **Feature Pyramid Network (FPN)**. This choice balances feature extraction capability with computational efficiency and low memory footprint.
-   **Shared Backbone**: The ResNet-18-FPN extracts a hierarchy of spatial features from the input radiograph.
-   **Detection Branch (Image-Level)**: A Region Proposal Network (RPN) generates candidate regions of interest (ROIs) from the FPN features. These ROIs are processed by a Fast R-CNN head to regress bounding box coordinates and predict the presence of "opacity" opacities.
-   **Classification Branch (Study-Level)**: A parallel branch applies Global Average Pooling to the highest-level feature map of the backbone. This vector is fed into a lightweight fully connected layer (with Softmax activation) to predict the four mutually exclusive study categories: *Negative for Pneumonia*, *Typical Appearance*, *Indeterminate Appearance*, and *Atypical Appearance*.

### Data
1.  **Preprocessing**:
    -   **Loading**: Read DICOM files using the paths provided in the generated metadata. Handle `PhotometricInterpretation` (e.g., MONOCHROME1 vs MONOCHROME2) to ensure opacities always appear as high-intensity (white) regions.
    -   **Normalization**: Apply min-max scaling to the pixel data to normalize intensities to the [0, 1] range, followed by standardization using ImageNet mean and standard deviation.
    -   **Resizing**: Resize all images to a fixed resolution of **512x512** pixels. This resolution is sufficient for detecting large opacities while keeping training and inference rapid.
    -   **Label Encoding**: Map the "boxes" string in the metadata to a list of `[x_min, y_min, x_max, y_max]` coordinates. Images with "none" or empty boxes are treated as background-only samples for the detector.
2.  **Augmentation**: Apply simple, low-cost augmentations such as horizontal flipping and slight brightness/contrast shifts to improve generalization without increasing training time significantly.

### Training
-   **Loss Function**: The model is trained using a multi-task objective: $L_{total} = L_{RPN} + L_{ROI} + \lambda L_{Study}$.
    -   $L_{RPN}$ and $L_{ROI}$ are the standard object detection losses (smooth L1 for regression, cross-entropy for classification).
    -   $L_{Study}$ is a Cross-Entropy loss for the 4-class study classification head.
    -   $\lambda$ is a weighting factor (e.g., 1.0) to balance the tasks.
-   **Sampling**: Use a balanced sampler within the data loader to ensure each batch contains a mix of images with opacities and "Negative" images (no findings), preventing the detector from overfitting to background.
-   **Optimization**: Use the **AdamW** optimizer with a standard learning rate (e.g., 1e-4) and a cosine annealing scheduler. Train for a limited number of epochs (e.g., 10-12) to fit within the runtime constraints.

### Evaluation
1.  **Inference**: Perform a single forward pass for each test image to obtain study probabilities and a set of bounding boxes with confidence scores.
2.  **Post-Processing**:
    -   **Study Labels**: Select the class with the highest probability from the classification branch.
    -   **Image Labels**: Apply Non-Maximum Suppression (NMS) with an IoU threshold of 0.5 to remove overlapping duplicate boxes. Filter boxes with a confidence score below a set threshold (e.g., 0.25).
    -   **Consistency Handling**:
        -   If the detector predicts valid boxes, format the prediction string as `opacity <conf> <xmin> <ymin> <xmax> <ymax> ...`.
        -   If no boxes remain after thresholding, predict `none 1 0 0 1 1`.
3.  **Submission**: Combine the study-level class ID and the image-level prediction string into the required CSV format.
