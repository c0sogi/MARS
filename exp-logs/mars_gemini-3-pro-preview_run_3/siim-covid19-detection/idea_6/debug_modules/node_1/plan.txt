The `AttributeError: module 'torchvision.ops' has no attribute 'LastLevelMaxPool'` occurs because `LastLevelMaxPool` is located in the `torchvision.ops.feature_pyramid_network` submodule, not directly in the top-level `torchvision.ops` namespace in some versions. Additionally, the code incorrectly attempts to access box encoding/decoding utilities via `torchvision.ops.boxes.box_coder`, which does not exist; these utilities reside in `torchvision.models.detection._utils`.

To fix this, I will:
1.  Update the imports in `library/model.py` to correctly import `FeaturePyramidNetwork` and `LastLevelMaxPool` from `torchvision.ops.feature_pyramid_network`.
2.  Import `_utils` from `torchvision.models.detection` (aliased as `det_utils`) to access `encode_boxes` and `decode_boxes`.
3.  Replace the incorrect references in `BackboneWithFPN` and `CascadeRoIHeads` with the correct imported classes and functions.
