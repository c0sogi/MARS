The implementation strategy involves the following steps:

1.  **Setup and Initialization**: Import necessary libraries (`pandas`, `numpy`, `os`, `glob`, `sklearn`) and define paths for input (`./input`) and output (`./metadata`). Create the output directory if it doesn't exist.
2.  **File System Traversal**: Walk through the `./input/train` and `./input/test` directories to identify all DICOM files. Parse the file paths to extract `study_id`, `series_id`, and `image_id` based on the directory structure (`study/series/image.dcm`). Construct DataFrames containing these IDs and the relative file paths.
3.  **Data Loading and Merging**:
    *   Load `train_study_level.csv` and `train_image_level.csv`.
    *   Clean the ID columns by removing `_study` and `_image` suffixes to match the IDs extracted from file paths.
    *   Merge the file path DataFrame with the image-level metadata on `image_id`.
    *   Merge the result with the study-level metadata on `study_id`. This creates a comprehensive master DataFrame for the training data.
4.  **Group Stratified Split**:
    *   Identify unique studies and their corresponding labels from the study-level metadata.
    *   Create a stratification key (e.g., by converting one-hot labels to a string or integer class).
    *   Perform an 80:20 split on the **unique studies** using `train_test_split` with a fixed random state (`42`) and stratification. This ensures no study leaks between train and validation sets (Group Sampling) while maintaining class balance.
    *   Filter the master DataFrame into `train` and `validation` sets based on the split study IDs.
5.  **Metadata Generation**:
    *   Save the `train`, `validation`, and `test` DataFrames to CSV files in the `./metadata` directory.
6.  **Validation and Quality Checks**:
    *   Reload the generated metadata files.
    *   Print summary statistics (row counts, column names).
    *   **File Existence Check**: Randomly sample 1000 paths from each dataset and verify they exist in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
    *   **Split Verification**: Assert that the set of study IDs in the training set and validation set are mutually exclusive to confirm the group split was successful.
