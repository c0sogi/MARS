The error `TypeError: torch.FloatTensor is not a Module subclass` arises because the code attempts to store `nn.Parameter` objects (which wrap tensors) inside an `nn.ModuleList`. `nn.ModuleList` is strictly typed to contain `nn.Module` instances (like layers). To register a list of learnable parameters properly, `nn.ParameterList` must be used instead. This aligns with the guidance to avoid treating non-module objects as modules when using PyTorch containers. Cite debug_lesson_14. I will apply this correction to `ATSSHead` in both `library/detection_head.py` and `library/dyhead_modules.py`.
