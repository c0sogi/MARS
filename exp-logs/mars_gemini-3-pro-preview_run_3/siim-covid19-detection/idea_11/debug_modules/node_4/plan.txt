The `AssertionError: Input height (1024) doesn't match model (384)` occurs because the `timm` library enforces strict resolution checks for the Swin Transformer backbone, which is pretrained at 384x384, while the project configuration uses 1024x1024. Furthermore, `timm`'s Swin implementation typically outputs feature maps in NHWC (channels-last) format, whereas the downstream PyTorch components (like `F.interpolate` and `nn.Conv2d`) expect NCHW (channels-first).

To fix this:
1.  In `Backbone.__init__`, pass `img_size=Config.IMG_SIZE` to `timm.create_model` to authorize the custom input resolution.
2.  In `Backbone.forward`, detect if the output tensors are in NHWC format by comparing the last dimension to the expected channel count, and permute them to NCHW if necessary (Cite debug_lesson_11).
