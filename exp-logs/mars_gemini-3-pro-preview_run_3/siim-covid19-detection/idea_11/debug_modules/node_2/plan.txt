The issue is that the `collate_fn` in `library/utils.py` returns a tuple of image tensors, but the training loop in `runfile.py` attempts to call `.to(device)` on this tuple, which raises an `AttributeError`. Furthermore, the `Backbone` class expects a `NestedTensor` object (containing stacked images and a mask) as input, not a raw tensor or tuple.

To fix this, I will modify `library/utils.py` to:
1.  Import `NestedTensor` from `library.backbone`.
2.  Update `collate_fn` to stack the batch of images into a single tensor `(B, C, H, W)`, create a corresponding mask `(B, H, W)`, and wrap them in a `NestedTensor`. This ensures the output supports the `.to()` method and complies with the model's input contract (Cite debug_lesson_4).
