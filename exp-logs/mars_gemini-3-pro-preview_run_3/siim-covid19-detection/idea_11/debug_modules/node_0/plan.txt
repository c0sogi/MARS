The following script demonstrates the end-to-end usage of the provided library components for the COVID-19 detection task. It covers:
1.  **Configuration**: Overriding default settings for a quick demonstration run.
2.  **Data Loading**: Instantiating the `SIIMDataset` and `DataLoader`, verifying data shapes and target formats.
3.  **Model Initialization**: Setting up the `MultiTaskDINO` model with the Swin Transformer backbone.
4.  **Forward Pass**: Executing a forward pass to verify output structures (logits, boxes, study predictions).
5.  **Loss Calculation**: Computing losses using `DINOLoss` and `HungarianMatcher`.
6.  **Training & Evaluation**: Running a single epoch of training and an evaluation step using the `engine` module.
