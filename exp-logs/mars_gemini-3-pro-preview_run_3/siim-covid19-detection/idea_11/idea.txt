# Idea 11: Multi-Task DINO with Contrastive DeNoising and Relational Finding Aggregation

## Model
I propose a **Multi-Task DINO (DETR with Improved DeNoising Anchor Boxes)** architecture. This represents a structural evolution from the Co-DETR (Idea 10) and Deformable DETR (Idea 8) approaches. While Co-DETR focuses on auxiliary supervision, DINO fundamentally improves the DETR training paradigm by introducing **Contrastive DeNoising (CDN)**, which stabilizes bipartite matching and significantly accelerates convergence—a critical factor given the 24-hour runtime limit.

-   **Backbone**: I will utilize a **Swin Transformer Large (Swin-L)** backbone. This hierarchical vision transformer provides state-of-the-art feature extraction capabilities, capturing both the fine-grained details necessary for small opacity detection and the global context required for study classification.
-   **DINO Decoder (Structural Innovation)**: Unlike standard DETR decoders that rely solely on learned object queries, the DINO decoder utilizes a **Mixed Query Selection** strategy. It initializes anchor boxes using positional information from the encoder and refines them dynamically.
-   **Relational Finding Aggregator (Structural Innovation)**: Instead of using a parallel "Diagnosis Query" inside the decoder (as in Idea 10) or global pooling (Idea 1-7), I will attach a **Relational Transformer Head** *after* the DINO decoder.
    -   **Input**: This head takes the set of refined **Object Queries** (output embeddings representing detected opacities) from the DINO decoder.
    -   **Mechanism**: A lightweight Transformer Encoder layer applies self-attention across these object queries. This explicitly models the **spatial constellation and relationship** between findings (e.g., "multiple bilateral opacities" vs. "single focal opacity") to determine the study-level diagnosis ("Typical" vs. "Indeterminate"). This mimics the clinical reasoning process where the diagnosis is derived from the distribution of observed anomalies.

## Data
-   **Preprocessing (Strategic Retention)**: I will strictly implement **Letterbox Resizing** for all training and test images. Instead of warping images to a fixed square, I will resize the longest dimension to the target size (e.g., 1024 pixels) and pad the shorter dimension with zeros. This preserves the original aspect ratio of the radiographs, preventing the morphological distortion of lung opacities that was identified as a critical failure mode **Cite solution_lesson_node_00010**.
-   **Augmentation**: I will employ **Large Scale Jittering (LSJ)**, which resizes images within a wide scale range (0.1 to 2.0) followed by cropping, alongside **Random Horizontal Flipping**. I will explicitly exclude "Mosaic" augmentation to preserve the global anatomical structure required for the Relational Finding Aggregator to learn valid spatial dependencies.

## Training
-   **Contrastive DeNoising (CDN)**: During training, I will feed positive and negative noisy versions of the ground truth bounding boxes into the decoder as queries. The model is trained to reconstruct the original boxes. This "denoising" task prevents the bipartite matching instability common in DETR models and ensures the model learns to localize opacities rapidly.
-   **Loss Function**: The model will be trained end-to-end with a multi-task objective:
    -   **Detection Loss**: A combination of **Focal Loss** (for class labels), **L1 Loss** (for box coordinates), and **GIoU Loss** (for box overlap).
    -   **Study Loss**: **Cross-Entropy Loss** applied to the output of the Relational Finding Aggregator.
-   **Optimizer**: **AdamW** with a layer-wise learning rate decay to fine-tune the Swin-L backbone effectively.

## Evaluation
-   **Inference**: A single forward pass generates the study-level probabilities (via the Relational Head) and image-level bounding boxes (via the DINO decoder).
-   **Prediction Logic**:
    1.  **Study Level**: The label is determined by the argmax of the Relational Finding Aggregator's output.
    2.  **Image Level**:
        -   If the predicted Study Label is "Negative for Pneumonia", the image prediction is forced to `none 1 0 0 1 1`.
        -   Otherwise, the bounding boxes predicted by the DINO decoder are used. Since DINO performs one-to-one set prediction, **Non-Maximum Suppression (NMS) is not required**, and the raw boxes are formatted as the "opacity" prediction string.
