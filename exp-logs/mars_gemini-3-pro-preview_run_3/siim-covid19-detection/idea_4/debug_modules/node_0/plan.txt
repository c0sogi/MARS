The following script demonstrates the usage of the provided library files to train a Multi-Task EfficientDet model on a subset of the COVID-19 radiograph dataset and generate predictions.

### Implementation Strategy
1.  **Configuration**: Create a `DemoConfig` class inheriting from the base `Config` to override hyperparameters for a quick demonstration (1 epoch, reduced batch size).
2.  **Dataset Verification**: Instantiate the `CovidDataset`, retrieve a sample, and verify the data shapes and target structure using assertions.
3.  **Model Verification**: Instantiate the `MultiTaskEfficientDet` model, perform a forward pass with a batch of real data, and verify the output structure (losses in training mode, detections in evaluation mode).
4.  **Training Loop**: Initialize the `Trainer` with the `DemoConfig` and execute `fit(debug=True)`. The `debug` flag forces the trainer to use a small subset of the data (100 train, 50 val) to ensure the process completes quickly.
5.  **Inference & Submission**: Call `trainer.predict()` to generate predictions on the test set and save the submission file.
6.  **Result Validation**: Load the generated `submission.csv` and assert that it follows the required format and contains predictions.
