The issue is that the `DeformableDetrModel` from the Hugging Face `transformers` library manages object queries internally based on the provided configuration (`num_queries`) and does not accept an external `query_embeddings` argument in its `forward` pass, causing a `TypeError`. To fix this, I will remove the manual definition of `self.query_embeds` in the `__init__` method and stop passing `query_embeddings` to `self.model()` in the `forward` method, allowing the model to use its internal query embeddings as intended.
