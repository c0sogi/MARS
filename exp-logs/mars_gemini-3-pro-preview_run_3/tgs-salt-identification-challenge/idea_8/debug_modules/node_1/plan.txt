The `AttributeError: type object 'Config' has no attribute 'DEVICE'` occurs because the `Config.DEVICE` attribute is dynamically assigned within the `Config.setup()` method, but this method is never called in the main execution block of `runfile.py`. To fix this, I will invoke `Config.setup()` at the start of the `if __name__ == "__main__":` block in `runfile.py`. This ensures that the environment is properly initialized and the `DEVICE` attribute is available for use by the subsequent demo functions.
