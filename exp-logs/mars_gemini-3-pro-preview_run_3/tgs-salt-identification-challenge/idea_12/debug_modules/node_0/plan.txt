This script demonstrates the usage of the provided machine learning pipeline for salt segmentation. It systematically verifies the utility functions, dataset processing, model architecture, loss functions, and the training loop.

The strategy is as follows:
1.  **Utilities Verification**: Validate Run-Length Encoding (RLE) logic and the Kaggle mAP metric using synthetic data to ensure correctness.
2.  **Dataset Demonstration**: Instantiate the `SaltDataset` with synthetic numpy arrays to verify data loading, augmentation (padding to 128x128), and channel construction (seismic + depth) without relying on disk I/O.
3.  **Model Architecture Check**: Initialize the `UNetPlusPlus` model and perform a forward pass with dummy tensors in both training (deep supervision) and evaluation modes to confirm output shapes.
4.  **Loss Function Test**: Compute `BCEDiceLoss` and `LovaszHingeLoss` on random tensors to ensure they return valid scalar values.
5.  **Full Training Loop**: Execute `train_fold` with `debug=True`. This runs a shortened training cycle (2 epochs) using the actual provided metadata and images, demonstrating the integration of all components.
