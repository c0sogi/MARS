Implementation Strategy:
1.  **Configuration Override**: Dynamically modify the `Config` class attributes to adapt for a quick demonstration. This includes switching to a lightweight encoder (`resnet18`), reducing epochs to 1, setting the batch size to 4, and enabling debug paths to avoid processing the full dataset.
2.  **Utility Verification**: Validate the core utility functions (`pad_image`, `unpad_image`, `rle_encode`, `calc_map_score`) using assertions with synthetic data to ensure geometric transformations and metric calculations are correct.
3.  **Component Testing**:
    *   **Dataset**: Instantiate `SaltDataset` in debug mode and verify that the data loading, normalization, and shape transformations (HWC to CHW, padding) function as expected.
    *   **Model**: Instantiate the `SaltUNetPlusPlus` model (using the lightweight encoder) and perform a forward pass with a dummy tensor to verify the architecture's connectivity and output dimensions.
    *   **Loss**: Verify the `BCEDiceLoss` and `LovaszHingeLoss` functions by computing gradients on dummy predictions to ensure the computational graph is valid.
4.  **Integration Training**: Initialize the `Trainer` class and execute the `start()` method to run a complete training and validation cycle on the debug subset. This confirms the end-to-end pipeline works.
5.  **Inference & Submission**: Simulate the test phase by loading the trained model (from the integration step), running inference on the debug test set, applying run-length encoding, and generating a sample submission CSV format.
