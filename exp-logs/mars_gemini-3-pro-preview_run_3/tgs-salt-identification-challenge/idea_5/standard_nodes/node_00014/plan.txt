Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment with fixed seeds for reproducibility. Override the default `Config.EPOCHS` to 35 to ensure the training completes well within the time limit while providing sufficient convergence for the U-Net++ architecture.
2.  **Training**: Instantiate the `Trainer` class with `debug=False` to utilize the full training dataset. Execute the training pipeline, which includes a warm-up phase with BCE+Dice loss and a fine-tuning phase with Lovász-Hinge loss. The trainer automatically handles checkpointing of the best model based on validation mAP.
3.  **Validation & Threshold Optimization**: Load the best saved model. Perform inference on the validation set using Test-Time Augmentation (TTA) by averaging predictions from original and horizontally flipped images. Sweep through probability thresholds (0.3 to 0.8) to identify the optimal threshold that maximizes the competition metric (mAP over IoU thresholds).
4.  **Failure Analysis**: Calculate per-image error metrics on the validation set. Correlate these errors with metadata features (Depth and Salt Coverage) to identify systematic weaknesses, fulfilling the requirement to print these correlations.
5.  **Submission Generation**: If the optimized validation metric exceeds the threshold of 0.806, proceed to inference on the test set. Apply the same TTA strategy and the optimal threshold derived from validation. Encode the resulting binary masks using Run-Length Encoding (RLE) and save the submission file to the specified path.
