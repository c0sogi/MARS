This script implements the **Stabilized High-Fidelity Stratified Ensemble** strategy. It orchestrates a 5-fold cross-validation pipeline using a U-Net++ architecture with a ResNeXt-50 encoder. The training process features a two-stage curriculum: an initial warm-up phase using BCE+Dice loss to establish convergence, followed by a fine-tuning phase using Lovász-Hinge loss with a reduced learning rate to optimize the Jaccard index directly.

Key features include:
1.  **Stratified 5-Fold CV**: Ensures comprehensive data usage and robust evaluation.
2.  **Curriculum Learning**: Switches loss functions and adjusts learning rates at epoch 15 to prevent gradient shock and maximize metric alignment.
3.  **Global Threshold Optimization**: Aggregates Out-of-Fold (OOF) predictions to find the optimal decision threshold that maximizes mAP.
4.  **Failure Analysis**: Correlates prediction errors with depth and salt coverage to diagnose model weaknesses.
5.  **Ensemble Inference**: Averages predictions from all 5 fold models with Test-Time Augmentation (TTA) for the final submission.
