This script demonstrates the end-to-end usage of the provided machine learning pipeline for salt segmentation. It verifies the configuration, utility functions, dataset loading (including caching logic), model architecture, loss functions, and the full training loop via the `Trainer` class.

To ensure speed and correctness:
1.  **Configuration**: We use `debug=True` and force `epochs=1` to minimize runtime.
2.  **Dataset**: We verify the dataset using a small `limit_size` first, then clean up the cache to allow the Trainer to generate a consistent cache from a controlled subset of data.
3.  **Trainer**: We create temporary, small CSV subsets of the metadata to simulate a full training run (Train -> Val -> Threshold Optimization -> Submission) in a fraction of the time.
4.  **Verification**: Assertions are placed at every step to confirm shapes, values, and file existence.
