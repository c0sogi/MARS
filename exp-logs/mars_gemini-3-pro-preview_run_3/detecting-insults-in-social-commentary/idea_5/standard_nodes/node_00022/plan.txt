The following is the implementation of the orchestration script `runfile.py`. It integrates the provided library modules to perform Domain-Adaptive Pre-training, Validation with Failure Analysis, and Full-Data Training for Submission.

**Implementation Strategy:**
1.  **Environment Setup**: Initializes random seeds and cleans up specific cache files to ensure data integrity between the validation and submission phases.
2.  **Domain-Adaptive Pre-training (DAPT)**: Executes the `pretrain_mlm` module to adapt the RoBERTa backbone on the combined text corpus (Train + Val + Test). This runs only once.
3.  **Validation Phase**:
    *   **Monkey-Patching**: Temporarily replaces the data loading function in `data_factory` to load only the **Training** split. This prevents data leakage during validation.
    *   **Training**: Trains a single model (Seed 42) on this training split.
    *   **Evaluation**: Manually runs inference on the **Validation** split using the trained model.
    *   **Metric & Analysis**: Computes the AUC score and performs failure analysis (correlation of error with text length).
4.  **Submission Phase**:
    *   **Condition**: Checks if the validation AUC exceeds the specified threshold.
    *   **Full Training**: If passed, restores the original data loader and trains an ensemble of 3 models (using Seed Averaging) on the **Full Labeled Dataset** (Train + Val) to maximize performance.
    *   **Inference**: Generates the final submission file using the ensemble.
