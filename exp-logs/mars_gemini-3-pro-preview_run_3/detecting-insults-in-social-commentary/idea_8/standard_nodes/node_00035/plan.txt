The strategy involves optimizing the solution through two main avenues: **Heterogeneous Ensembling** improvements and **Pseudo-Labeling**.

1.  **Ensemble Optimization**: The previous solution showed that the `microsoft/deberta-v3-large` models were under-trained (2 epochs) compared to `roberta-large` (3 epochs). I will increase the training epochs for both architectures to 4 to ensure full convergence, particularly for DeBERTa which was still improving at the end of training. This addresses the performance gap observed in the previous run.

2.  **Pseudo-Labeling (Self-Training)**: To leverage the unlabeled test data (which is comparable in size to the training set), I will implement a two-stage training process.
    *   **Stage 1**: Train the initial ensemble on the labeled training data.
    *   **Pseudo-Label Generation**: Use the Stage 1 ensemble to predict on the test set. Samples with high confidence (probability > 0.95 or < 0.05) will be assigned their predicted labels and added to the training set.
    *   **Stage 2**: Retrain the ensemble on this augmented dataset. This allows the models to learn from the structure of the test data, potentially sharpening the decision boundary in low-density regions.

This approach directly applies **Lesson `solution_lesson_node_00034`** (Heterogeneous Ensembling) and **Lesson `solution_lesson_node_00027`** (Pseudo-Labeling), while ensuring that the batch size remains consistent to avoid the stability issues noted in previous lessons.

def train_ensemble(df_train, df_val, suffix=""):
    """
    Trains the ensemble of models defined in Config.
    Returns a list of dictionaries containing model paths and configs.
    """

            )

            trained_models_info.append({"path": save_path, "config": config})
            
    return trained_models_info


def inference_ensemble(trained_models_info, df_target, is_test=False):
    """
    Runs inference using the provided list of models on the target dataframe.
    Returns averaged predictions.
    """
    device = Config.DEVICE
    preds_accum = np.zeros(len(df_target))
    
    for info in trained_models_info:
        config = info["config"]
        path = info["path"]
        
        # Setup Tokenizer and Loader
        tokenizer = AutoTokenizer.from_pretrained(config["tokenizer_path"])
        loader = get_dataloader(
            df_target,
            tokenizer,
            batch_size=Config.VALID_BATCH_SIZE,
            is_test=is_test,
            shuffle=False,
        )
        
        # Load Model
        model = TransformerModel(
            model_name=config["model_name"],
            dropout=config["dropout"],
            freeze_layers=config["freeze_layers"],
        )
        model.load_state_dict(torch.load(path, map_location=device))
        model.to(device)
        model.eval()
        
        # Predict
        preds = predict(loader, model, device)
        preds_accum += np.array(preds)
        
        # Cleanup
        del model, tokenizer, loader
        torch.cuda.empty_cache()
