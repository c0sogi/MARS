The following implementation strategy demonstrates the usage of the provided library modules to train and validate an insult detection model.

**Strategy:**
1.  **Configuration**: Initialize `ModelConfig` and override specific parameters (model name, batch size, epochs) to ensure the demonstration runs quickly using a lightweight model (`prajjwal1/bert-tiny`) instead of the large default model.
2.  **Data Loading**: Use `load_dataset_df` to load the training data, then slice it to a tiny subset (10 samples) to simulate a rapid training cycle.
3.  **Dataset Preparation**: Initialize the tokenizer and create `InsultDataset` instances for training and validation.
4.  **Model Initialization**: Instantiate `InsultModel`. We verify its structure and perform a dummy forward pass to confirm the output shape is correct.
5.  **Training Setup**: Configure the optimizer (`AdamW`) and learning rate scheduler (`get_linear_schedule_with_warmup`) as required by the `fit` function.
6.  **Execution**: Run the `fit` function to simulate one epoch of training and validation.
7.  **Metric Verification**: Explicitly test the `get_score` function with dummy data to ensure the AUC metric calculation is correct.
