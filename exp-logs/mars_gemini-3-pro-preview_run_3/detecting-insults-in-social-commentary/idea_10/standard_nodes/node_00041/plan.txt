Implementation strategy:
1.  **Configuration**: Initialize the `Config` with 3 epochs to ensure the entire pipeline (12 model training runs) completes within the 2-hour limit on the provided hardware.
2.  **Stage 1 - Teacher Training**: Train an ensemble of 6 models (3 seeds of `roberta-large` and 3 seeds of `microsoft/deberta-v3-large`) on the labeled training set (`train.csv`). Save the best checkpoints based on validation performance.
3.  **Soft Target Generation**: Use the trained Teacher Ensemble to generate probability predictions (soft targets) for the unlabeled test set (`test.csv`). Average these predictions to create a robust distillation target.
4.  **Stage 2 - Student Training**: Train a new ensemble of 6 Student models (same architectures and seeds) using a hybrid loss function: Binary Cross-Entropy on the labeled data and Knowledge Distillation loss (KL/BCE) on the unlabeled test data using the generated soft targets. Enable Adversarial Weight Perturbation (AWP) to improve robustness.
5.  **Evaluation**: Aggregate the predictions of the Student Ensemble on the hold-out validation set (`val.csv`). Calculate and print the AUC score.
6.  **Failure Analysis**: Compute the correlation between the model's prediction error and input text length (character and word count) to identify systematic biases.
7.  **Submission**: If the validation AUC exceeds the specified threshold, generate predictions for the test set using the Student Ensemble and save them to `submission.csv` in the required format.
