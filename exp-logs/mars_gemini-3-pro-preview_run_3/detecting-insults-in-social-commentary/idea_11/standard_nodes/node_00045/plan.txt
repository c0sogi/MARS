Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Initialization**: Set up the environment using the provided `Config` class, ensuring reproducibility with `seed_everything`. Initialize the logger.
2.  **Data Loading**: Load the training, validation, and test datasets using `load_and_process_data`. The text is decoded and cached.
3.  **Stage 1: Teacher Ensemble**:
    *   Iterate through the specified model architectures (RoBERTa-Large, DeBERTa-v3-Large) and seeds (42, 43, 44).
    *   For each combination, train a "Teacher" model on the labeled training data for 5 epochs using the standard `train_fn`.
    *   Generate soft probability predictions on the unlabeled test set.
    *   Aggregate these predictions to form the "Soft Targets".
4.  **Stage 2: Adversarial Student Distillation**:
    *   Construct a **Combined Corpus** by merging the original labeled training data with the soft-labeled test data.
    *   Iterate through the models and seeds again to train "Student" models.
    *   Train using `train_fn_awp` which implements Adversarial Weight Perturbation (AWP) to improve robustness.
    *   During training, the loss function (BCEWithLogitsLoss) naturally handles the soft probabilities from the combined corpus.
5.  **Evaluation & Inference**:
    *   After training each student, generate predictions for both the validation set (for metrics) and the test set (for submission).
    *   Aggregate student predictions via arithmetic mean.
    *   Calculate the final AUC score on the validation set.
6.  **Failure Analysis**:
    *   Compute the absolute error between predictions and ground truth.
    *   Calculate the correlation between error magnitude and comment length (character count) to identify if sentence length impacts performance.
7.  **Submission**:
    *   Check if the validation AUC exceeds the threshold (0.9660591133004925).
    *   If successful, save the averaged test predictions to `submission.csv`.
