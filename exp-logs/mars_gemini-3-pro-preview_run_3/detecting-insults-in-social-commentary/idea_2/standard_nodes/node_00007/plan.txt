Based on the lessons learned, specifically `solution_lesson_node_00006`, I will optimize the solution by removing the NBSVM statistical stream, as it provided zero marginal gain when ensembled with the Transformer model. I will focus all computational resources on enhancing the Neural stream.

My strategy involves:
1.  **Upgrading the Model**: Switching from `roberta-base` to `roberta-large` to leverage better pre-trained representations.
2.  **Improving Architecture**: Implementing **Mean Pooling** of the last hidden states instead of using the default pooler output (which is just the `[CLS]` token processed). Mean pooling typically captures better semantic representations for sentence classification.
3.  **Refining Hyperparameters**: Lowering the learning rate to `1e-5` to ensure stable fine-tuning of the larger model on the small dataset, increasing `max_len` to 160 to capture more context, and increasing dropout to `0.15` to prevent overfitting.
4.  **Cleaning the Pipeline**: Removing the NBSVM code and ensemble logic from the execution scripts.

        tuple: (val_preds, test_preds) as numpy arrays.

def optimize_ensemble(val_true, pred_a, pred_b):
    """
    Finds the optimal weight w to combine two prediction vectors.
    Formula: w * pred_a + (1 - w) * pred_b

    Args:
        val_true: True labels.
        pred_a: Predictions from model A.
        pred_b: Predictions from model B.

    Returns:
        tuple: (best_weight, best_auc)
    """
    best_auc = 0.0
    best_w = 0.5

    # Grid search for weight w
    for w in np.arange(0.0, 1.01, 0.01):
        combined_preds = w * pred_a + (1 - w) * pred_b
        current_auc = roc_auc_score(val_true, combined_preds)

        if current_auc > best_auc:
            best_auc = current_auc
            best_w = w

    return best_w, best_auc


def run_pipeline(load_cached_data=True, max_samples=None, epochs=3, batch_size=16):
    """
    Main execution pipeline:
    1. Train NBSVM
    2. Train Neural Model
    3. Optimize Ensemble
    4. Generate Submission
    """
    set_seed(42)

    # 1. Run Statistical Stream
    nb_val_preds, nb_test_preds = run_nblr(

        max_samples=max_samples,
        epochs=epochs,
        batch_size=batch_size,

    val_df = load_data("val", load_cached_data=load_cached_data)

    best_w, best_auc = optimize_ensemble(y_val, nb_val_preds, neural_val_preds)
