Here is the implementation strategy followed by the code.

### Implementation Strategy

1.  **Environment Setup**: Initialize random seeds and define a working directory for temporary files to ensure isolation and reproducibility.
2.  **Data Loading & Preprocessing**:
    *   Use `library.utils.load_data` to load the metadata CSVs.
    *   Create a small subset (e.g., 50 samples) of the training, validation, and test data to ensure the demonstration runs quickly.
    *   Demonstrate `library.utils.clean_text` on a sample string.
3.  **Statistical Stream (TF-IDF + NBSVM)**:
    *   Use `library.data_factory.get_tfidf_features` to generate features for the subset. Verify the output shapes.
    *   Instantiate and train the `library.modeling.NBSVM` model on the generated features.
    *   Generate predictions and verify they are within the [0, 1] probability range.
4.  **Neural Stream (RoBERTa)**:
    *   Initialize the tokenizer and create `library.data_factory.InsultDataset` instances for the subset.
    *   Create PyTorch DataLoaders and verify the structure of a single batch (input IDs, attention masks, targets).
    *   Instantiate `library.modeling.RoBERTaClassifier`.
    *   Run `train_model` for 1 epoch on the small subset to demonstrate the training loop without consuming excessive time.
    *   Generate predictions using the trained model.
5.  **Ensemble Optimization**:
    *   Use `library.execution.optimize_ensemble` to find the best weighting between the NBSVM and RoBERTa predictions.
    *   Validate that the returned weight is valid (0.0 to 1.0).
6.  **Cleanup**: Remove the temporary working directory created for the demonstration.
