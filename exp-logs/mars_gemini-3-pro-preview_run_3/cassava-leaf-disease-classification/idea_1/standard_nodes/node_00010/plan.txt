EfficientNet architectures generally outperform ResNets on fine-grained classification tasks by balancing depth, width, and resolution. This aligns with **Lesson 7**, which emphasizes scaling capability, but here we scale via a more efficient architecture rather than just cardinality.
2.  **Increased Resolution**: I will increase the input image size from 224x224 to **300x300**, which is the native resolution for EfficientNet-B3. This allows the model to discern finer details of the disease patterns (spots, discoloration) that might be lost at lower resolutions.
3.  **Test Time Augmentation (TTA)**: I will implement TTA in both the validation and inference phases. By averaging predictions across three views (original, horizontal flip, and vertical flip), we can reduce prediction variance and improve robustness without retraining.
4.  **Hyperparameter Tuning**: I will adjust the `BATCH_SIZE` to 32 to accommodate the larger image size and increase `NUM_EPOCHS` to 12 to ensure convergence with the new architecture.

class CassavaResNet(nn.Module):
    """
    CassavaResNet model based on the ResNet-18 architecture.

    This model uses a ResNet-18 backbone, optionally pre-trained on ImageNet,
    and replaces the final classification head to match the number of classes
    in the Cassava Leaf Disease Classification task.
    """

    def __init__(
        self,
        pretrained: bool = Config.PRETRAINED,
        num_classes: int = Config.NUM_CLASSES,
    ):
        """
        Initialize the CassavaResNet model.

        Args:
            pretrained (bool): If True, loads weights pre-trained on ImageNet.
                               Defaults to Config.PRETRAINED.
            num_classes (int): The number of output classes.
                               Defaults to Config.NUM_CLASSES.
        """
        super(CassavaResNet, self).__init__()

        # Load the ResNeXt-50 backbone
        # We use the 'weights' parameter for newer torchvision versions
        if pretrained:
            weights = models.ResNeXt50_32X4D_Weights.DEFAULT
        else:
            weights = None

        self.model = models.resnext50_32x4d(weights=weights)

        # Replace the final fully connected layer
        # ResNet's final layer is named 'fc'
        in_features = self.model.fc.in_features
        self.model.fc = nn.Linear(in_features, num_classes)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        Forward pass of the network.

        Args:
            x (torch.Tensor): Input batch of images with shape (B, C, H, W).

        Returns:
            torch.Tensor: Raw output logits with shape (B, num_classes).
        """
        return self.model(x)
