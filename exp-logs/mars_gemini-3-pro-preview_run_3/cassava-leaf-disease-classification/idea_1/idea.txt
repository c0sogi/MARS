To establish a reliable and efficient baseline for the Cassava Leaf Disease Classification task, I propose a solution based on a standard **ResNet-18** architecture trained end-to-end. This approach simplifies the concepts found in the provided model architectures (specifically the CNN backbone of Model 1 and the feature extraction of Model 5) into a unified, single-stage pipeline that prioritizes speed and robustness.

### Model
The core of the solution will be a **ResNet-18** Convolutional Neural Network.
*   **Backbone**: We will utilize the ResNet-18 architecture. It is significantly lighter than the EfficientNet-B0 (Model 1) and deeper ResNet variants, making it ideal for a fast baseline. Its residual connections facilitate effective gradient flow, ensuring stable training.
*   **Pre-training**: The model will be initialized with weights pre-trained on ImageNet. This allows the model to leverage learned low-level feature extractors (edges, textures) immediately, which is critical given the moderate dataset size (~15k training images).
*   **Classification Head**: The final fully connected layer of the pre-trained network will be replaced with a single Linear layer projecting the 512-dimensional feature embedding to the 5 output classes (4 diseases + 1 healthy).

### Data
We will implement a streamlined data pipeline focusing on efficiency:
*   **Preprocessing**: All images will be resized from their original 800x600 resolution to **224x224 pixels**. This standard resolution matches the pre-training conditions and drastically reduces the computational cost per iteration.
*   **Normalization**: Input images will be normalized using the standard ImageNet mean (`[0.485, 0.456, 0.406]`) and standard deviation (`[0.229, 0.224, 0.225]`).
*   **Augmentation**: To adhere to the requirement for a lightweight baseline, we will avoid heavy augmentations (like the RandomResizedCrop suggested in Model 1). We will apply only **Random Horizontal Flip** during training to provide basic invariance to orientation without computational overhead.
*   **Handling Imbalance**: We will compute class weights based on the training set distribution (where Class 3 represents ~61% of data) to be used in the loss function.

### Training
The training procedure is designed for stability and quick convergence:
*   **Loss Function**: We will use **Weighted Cross-Entropy Loss**. The weights will be inversely proportional to the class frequencies calculated from the metadata. This ensures the model does not simply optimize for the dominant class (Cassava Mosaic Disease) at the expense of the minority classes.
*   **Optimizer**: We will use the **Adam** optimizer, which generally requires less hyperparameter tuning than SGD. A conservative learning rate (e.g., 1e-4) will be used to fine-tune the pre-trained weights without destroying the learned features.
*   **Validation**: We will monitor categorization accuracy on the validation set after each epoch. A simple Early Stopping mechanism will be employed to terminate training if validation accuracy does not improve for a set number of epochs, ensuring efficient use of runtime.

### Evaluation
*   **Inference**: The test images will be loaded and resized to 224x224 (without augmentation).
*   **Prediction**: The model will perform a forward pass to generate logits. We will apply `argmax` to these logits to select the class with the highest probability.
*   **Submission**: The resulting class IDs will be paired with their corresponding `image_id` and written to `submission.csv` in the required format.
