The following strategy outlines the implementation of the `runfile.py` script:

1.  **Configuration & Setup**: We will import the `CFG` class and override specific parameters to ensure a "fast baseline" execution as requested. Specifically, we will reduce the number of epochs to 6, which is sufficient for the pre-trained CoAtNet-2 model to converge on this dataset without exceeding the time limit. We will also set the random seeds using `seed_everything`.
2.  **Data Loading**: We will utilize `get_dataloaders` with `load_cached_data=True` to efficiently load the training and validation data.
3.  **Model Training**: We will initialize the `CassavaClassifier` and the `AdamW` optimizer with a `CosineAnnealingLR` scheduler. The training loop will be managed by `train_model`, which handles mixed-precision training (via the provided library structure), logging, and early stopping.
4.  **Validation & Failure Analysis**:
    *   Once training is complete, we will reload the best model weights.
    *   We will perform inference on the full validation set to calculate the **Final Validation Metric** (Accuracy).
    *   We will perform failure analysis by calculating the correlation between the error magnitude (correct/incorrect) and the class labels to identify if specific disease categories are more prone to errors.
5.  **Submission**: We will check if the final validation accuracy exceeds the specified threshold (`0.9022696929238986`). If it does, we will trigger `generate_submission` to create the `submission.csv` file using Test-Time Augmentation (TTA).
