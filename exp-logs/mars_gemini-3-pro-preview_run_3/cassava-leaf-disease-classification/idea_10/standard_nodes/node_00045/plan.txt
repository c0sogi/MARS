The implementation strategy follows the "Tri-Modal Heterogeneous Ensemble" design. We will train three diverse backbone architectures (ViT-Base, BEiT-Base, and ConvNeXt-Base) to capture different aspects of the disease features (Global Attention, Masked Image Modeling, and Local Convolution).

1.  **Orchestration**: The script initializes the environment and loads the metadata. It overrides the default epoch count to 5 to ensure the "Fast Baseline" requirement is met while maintaining sufficient convergence for high accuracy.
2.  **Training**: We iterate through the three models defined in `Config.MODELS`. For each, we initialize the `CassavaModel`, `AdamW` optimizer, and `CosineAnnealingLR` scheduler. We employ `Mixup` for regularization and train for the fixed epoch count. We save the final model weights.
3.  **Ensemble Validation**: We reload the trained weights for all three models and perform inference on the validation set using **Test-Time Augmentation (TTA)**. This maximizes the validation score to meet the strict threshold. Predictions are averaged (soft voting).
4.  **Failure Analysis**: We calculate the "Error Magnitude" (1.0 - probability of the ground truth class) for the validation set. We then compute the Pearson correlation between this error and the basic image statistics (Mean Pixel Intensity, Standard Deviation) to identify if image quality/brightness correlates with model failure.
5.  **Submission**: If the ensemble's validation accuracy exceeds the threshold (`0.906008...`), we generate predictions for the test set using the same TTA ensemble approach and save the `submission.csv`.
