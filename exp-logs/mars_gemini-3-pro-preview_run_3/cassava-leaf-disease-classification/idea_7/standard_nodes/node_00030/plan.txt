The following implementation orchestrates the Heterogeneous Ensemble pipeline. It first overrides the configuration to ensure a fast but effective training run (5 epochs) suitable for the time constraints. It then sequentially trains the ViT (Global Context) and EfficientNet (Local Texture) models using the provided library functions. After training, it performs a rigorous validation using the ensemble strategy with Test-Time Augmentation (TTA), computes the required validation metric, and conducts a failure analysis by correlating prediction errors with image brightness. Finally, it generates the submission file if the performance threshold is met.
