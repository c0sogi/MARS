### Implementation Strategy

1.  **Configuration Override**: To ensure the demonstration runs quickly within the time limit, I will override the default configuration (`CFG`) to use a lightweight model (`resnet18` instead of `vit_base`), smaller image size ($224 \times 224$), reduced batch size, and disable multiprocessing overhead.
2.  **Data Subsetting**: I will load the provided metadata files but restrict the dataframes to a very small subset (e.g., 16 samples) for both training and validation. This allows us to verify the pipeline mechanics without waiting for a full epoch.
3.  **Component Verification**:
    *   **Dataset & Transforms**: Instantiate the `CassavaDataset` and verify that it correctly loads images and applies augmentations.
    *   **Mixup/CutMix**: Verify the `Mixup` class by applying it to a batch and checking that the target labels become soft (float) and shapes are preserved.
    *   **Model**: Instantiate the model wrapper (`CassavaViT`) and perform a dummy forward pass to confirm output shapes `[Batch, Num_Classes]`.
    *   **Training Engine**: Run `train_one_epoch` on the subset to ensure the training loop, gradient accumulation, and logging function correctly.
    *   **Validation Engine**: Run `valid_one_epoch` to verify evaluation metrics.
4.  **Inference & TTA**:
    *   Save the trained model weights to the working directory.
    *   Create a temporary test metadata file containing a subset of the test data.
    *   Execute the `run_inference` function to demonstrate the full inference pipeline, including Test-Time Augmentation (TTA) and submission file generation.
5.  **Assertions**: Throughout the script, I will use `assert` statements to validate shapes, data types, and file existence, ensuring the logic is robust.
