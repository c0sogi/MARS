I will optimize the solution by replacing the oversized Swin-Large backbone with a **Swin-Base** model (`swin_base_patch4_window12_384.ms_in22k`). The previous use of the Large variant on this mid-sized dataset led to diminishing returns and forced a suboptimal batch size, causing instability (Cite {solution_lesson_node_00018}). By switching to the Base variant, I can increase the `BATCH_SIZE` from 8 to 32, which will improve the stability of gradient updates and Batch Normalization statistics (Cite {solution_lesson_node_00013}). Additionally, I will remove the epoch override in the execution script to allow the model to train for the full 10 epochs defined in the configuration.
