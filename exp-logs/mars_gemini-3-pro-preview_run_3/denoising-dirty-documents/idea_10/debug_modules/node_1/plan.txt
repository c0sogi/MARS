The error is caused by an unguarded call to `main()` at the global scope of `library/network.py`. When `runfile.py` imports `library.network`, this `main()` function is executed immediately, triggering a full training session with default high-memory settings (Batch Size 256) instead of the lightweight demo configuration. This leads to a CUDA OutOfMemoryError because the GPU cannot handle the default load. To fix this, I will wrap the `main()` call in an `if __name__ == "__main__":` block, ensuring it only runs when the script is executed directly, not when imported. Cite debug_lesson_3.

# Execute pipeline
main()
=======

    # Execute pipeline
    main()
