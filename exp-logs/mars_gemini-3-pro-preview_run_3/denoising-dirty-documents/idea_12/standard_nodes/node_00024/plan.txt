Implementation strategy:
1.  **Import Libraries**: Import standard libraries and the provided library modules (`config`, `train`, `dataset`, `utils`, `inference`, `model`).
2.  **Configure for Fast Baseline**:
    *   Monkey-patch `library.train` to reduce the number of epochs for Stage 1 and Stage 2 (e.g., 10 epochs each) to ensure the training completes quickly within the 2-hour limit.
    *   Monkey-patch `library.dataset.STRIDE_DENSE` to a larger value (e.g., 10 instead of 5) to reduce the number of training patches in Stage 2, significantly speeding up the heaviest part of training while maintaining coverage.
3.  **Execute Training**: Call `library.train.train_model(limit=None)`. Using `limit=None` allows using all training images but with reduced patch density and epochs, which is a better trade-off for performance than using fewer images.
4.  **Perform Validation**:
    *   Load the validation dataset using `library.dataset.get_processed_data`.
    *   Run inference using the trained model on the validation set.
    *   Compute the RMSE metric using `library.utils.calculate_rmse`.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the pixel-wise absolute error between the cleaned prediction and the target.
    *   Flatten the error map and the input image patches.
    *   Compute the Pearson correlation between the error magnitude and the input pixel intensity using `scipy.stats.pearsonr`.
    *   Print the correlation.
6.  **Conditional Submission**:
    *   Check if the validation RMSE is strictly lower than `0.011577641381826402`.
    *   If the condition is met, call `library.inference.generate_submission()` to generate `submission.csv`.
