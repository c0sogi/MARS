# Optimized Strategy: Deep Residual Denoising Network (ResDnCNN) with Geometric Self-Ensemble

## Model
I propose evolving the architecture from the simple "plain" stack of layers used in the DnCNN (Idea 4) to a **Deep Residual Denoising Network (ResDnCNN)**.

*   **Backbone Architecture**: Instead of a simple chain of Convolution-BatchNorm-ReLU layers (VGG-style), the network will be constructed from a deep stack of **Residual Blocks** (ResNet-style).
    *   **Structure**: Each block consists of `Conv -> BN -> ReLU -> Conv -> BN`, followed by an element-wise addition of the block's input to its output (Local Skip Connection).
    *   **Rationale**: This structural change addresses the throughput bottleneck of the RDN (Idea 7) while offering higher capacity than the DnCNN. By using element-wise addition instead of channel concatenation, we maintain the high computational throughput of "Linear Residual Stacks" favored in **Cite {solution_lesson_node_00018}**, avoiding the memory-heavy operations that caused the RDN to be too slow. However, the local skip connections allow us to train a significantly deeper network (e.g., 30+ layers) than the standard DnCNN without gradient degradation, capturing more complex textual structures.
    *   **Resolution Preservation**: Strictly adhering to **Cite {solution_lesson_node_00009}**, the network contains **no pooling or downsampling layers**. All convolutions operate at the original spatial resolution to preserve fine text strokes.
    *   **Dense Convolutions**: All layers use standard $3 \times 3$ convolutions (stride 1, dilation 1). We explicitly reject dilated convolutions to maintain the dense local receptive fields required for text denoising **Cite {solution_lesson_node_00011}**.
    *   **Stability**: Unlike the failed RDN attempts, we explicitly **retain Batch Normalization (BN)** layers within the blocks. This ensures training stability and prevents the signal explosion observed in BN-free architectures **Cite {solution_lesson_node_00017}**.
*   **Global Residual Learning**: The network retains the critical global skip connection from input to output, predicting the **noise residual** $\mathcal{R}(x)$ rather than the clean image **Cite {solution_lesson_node_00012}**.

## Data
*   **Preprocessing**: Normalize all image pixel intensities to the range $[0, 1]$.
*   **High-Density Patch Extraction**:
    *   We will employ **High-Density Patching** by extracting patches of size $50 \times 50$ with a **small stride** (e.g., 10 pixels).
    *   **Rationale**: **Cite {solution_lesson_node_00013}** warned against increasing model capacity without increasing data density. Since the ResDnCNN is computationally efficient (unlike the RDN), we can afford to process this much larger dataset of overlapping patches within the 24-hour limit, ensuring the deeper model is fully saturated with training examples.
*   **Augmentation**: Apply random horizontal/vertical flips and 90-degree rotations to the patches.

## Training
*   **Loss Function**: Minimize the **Mean Squared Error (MSE)** between the predicted noise residual and the ground truth noise.
*   **Optimizer**: Use **Adam** with a **Cosine Annealing** learning rate scheduler. This scheduler provides a smooth decay that often yields better convergence for residual networks compared to step drops.
*   **Strategy**: Train on the high-density patch set. The high throughput of the ResBlock architecture allows for a large number of iterations/epochs compared to dense-connection architectures.

## Evaluation
*   **Inference Strategy**: **Geometric Self-Ensemble (Test-Time Augmentation)**.
    *   Instead of a single forward pass, we will generate predictions for 8 versions of each test image: the original and its 7 geometric transformations (flips and 90-degree rotations).
    *   The model predicts the noise for each version. We inverse-transform the predicted noise maps back to the original orientation and compute the mean.
    *   **Rationale**: This strategy exploits the rotation invariance of the noise statistics. Averaging multiple predictions cancels out random variance in the model's output, typically resulting in a consistent RMSE improvement over single-pass inference.
*   **Reconstruction**: Compute $\text{Clean Image} = \text{Noisy Input} - \text{Averaged Predicted Noise}$.
*   **Submission**: Clip values to $[0, 1]$ and format as `image_row_col`.
