Based on the comprehensive failure analysis and empirical lessons from previous attempts, I propose the **Ensemble of Zero-Initialized Deep Residual Networks (EZ-ResDnCNN)**. This strategy synthesizes the high-throughput backbone of linear residual stacks with a mathematically stabilized initialization scheme and a density-matched data pipeline, leveraging the full 24-hour computational budget to maximize performance via ensembling.

# Model
I propose a **Homogeneous Ensemble of Deep Residual Denoising Networks**. The core architecture is a structural evolution of the "Simple DnCNN" into a **Stabilized Deep Residual Network**, explicitly correcting the initialization flaws that caused previous deep models to fail.

*   **Backbone Architecture**: The network consists of a deep stack (e.g., 20 blocks, 40+ layers) of **Residual Blocks**.
    *   **Linear Residual Stacks**: Each block follows the design `Conv(3x3) -> BN -> ReLU -> Conv(3x3) -> BN`, with an element-wise addition of the input to the output. We strictly prefer this linear topology over Dense Connectivity (RDN) to maximize computational throughput (samples/second), enabling more training iterations within the time limit **Cite {solution_lesson_node_00018}**.
    *   **Local Inductive Bias**: We strictly utilize standard dense $3 \times 3$ convolutions. We explicitly reject **Dilated Convolutions** (which miss local pixel correlations **Cite {solution_lesson_node_00011}**) and **Attention Mechanisms** (which add overhead without aiding local denoising **Cite {solution_lesson_node_00025}**).
    *   **Resolution Preservation**: The network contains **no pooling or downsampling layers**, operating entirely at the original spatial resolution to preserve fine text strokes **Cite {solution_lesson_node_00009}**.
*   **Structural Innovation (Zero-Gamma Identity Path)**: To enable the training of this deep regression network without the signal explosion observed in previous attempts, I implement **Zero-Gamma Initialization**. The learnable scaling parameter ($\gamma$) of the last Batch Normalization layer in *every* residual block is initialized to **zero**.
    *   **Mechanism**: This forces each block to behave mathematically as an identity function ($y = x + 0$) at initialization. This structural change prevents the linear accumulation of variance that destroys deep regression models, allowing the network to start stable and incrementally learn the noise residuals **Cite {solution_lesson_node_00019}**.
*   **Global Residual Learning**: The network is architected to predict the **noise residual** $\mathcal{R}(x)$, with the final output being $\text{Input} - \mathcal{R}(x)$ **Cite {solution_lesson_node_00012}**.

# Data
I propose a **High-Density Data Strategy** that is strictly matched to the model's capacity and the available runtime.

*   **Preprocessing**: Normalize all image pixel intensities to the range $[0, 1]$.
*   **High-Density Patch Extraction**:
    *   Extract patches of size $50 \times 50$ using a **small stride** (e.g., 10 pixels).
    *   **Rationale**: Previous attempts failed because they increased model capacity without increasing data density **Cite {solution_lesson_node_00013}**. Unlike previous short runs, our **24-hour budget** allows us to fully process this massive dataset, overcoming the "undertraining" issues associated with dense patching **Cite {solution_lesson_node_00020}**.
*   **Augmentation**: Apply random horizontal/vertical flips and 90-degree rotations to enforce rotation invariance.

# Training
*   **Ensemble Strategy**: Instead of training a single model, we will train **$K=5$ independent instances** of the ZI-ResDnCNN with different random seeds.
    *   **Rationale**: Ensembling is the most reliable method to reduce the variance of the error (RMSE). The high throughput of the Linear Residual Stacks combined with the 24-hour budget makes training multiple deep models feasible.
*   **Loss Function**: Minimize **Mean Squared Error (MSE)** between predicted and true noise.
*   **Optimizer**: Use **AdamW** with a **Cosine Annealing** learning rate scheduler. The Zero-Gamma initialization allows for a higher initial learning rate, accelerating convergence.

# Evaluation
*   **Dual-Level Inference**:
    1.  **Geometric Self-Ensemble (TTA)**: For each of the 5 models, generate predictions for 8 geometric transformations (flips/rotations) of the test image, inverse-transform the outputs, and average them.
    2.  **Model Averaging**: Compute the final prediction by averaging the TTA outputs of all 5 ensemble members.
*   **Reconstruction**: Compute $\text{Clean Image} = \text{Noisy Input} - \text{Ensemble Predicted Noise}$.
*   **Submission**: Clip pixel intensities to $[0, 1]$ and flatten to the `image_row_col` format.
