The issue is caused by Python's default argument evaluation behavior. The functions `load_ensemble` and `create_submission_file` in `library/inference_engine.py` define default arguments using values from `Config` (e.g., `Config.SUBMISSION_PATH`). These values are evaluated and bound when the module is first imported. Consequently, when `runfile.py` modifies `Config.SUBMISSION_PATH` and `Config.ENSEMBLE_SIZE` at runtime, the functions continue to use the old values captured at import time, leading to the submission file being saved to the wrong location and the assertion failure.

To fix this, I will modify `library/inference_engine.py` to use `None` as the default value for these arguments. Inside the functions, I will check if the argument is `None` and then access the current value from `Config`. This ensures the runtime configuration is respected.
