The issue is caused by **Early Binding** of default arguments in Python. The functions `load_ensemble`, `predict_image`, and `create_submission_file` in `library/inference_engine.py` bind their default parameter values (e.g., `Config.SUBMISSION_PATH`) at module import time. When `runfile.py` subsequently modifies these `Config` attributes at runtime, the functions continue to use the stale, originally imported values. This causes `create_submission_file` to write to the wrong location and `load_ensemble` to attempt loading the wrong number of models.

To fix this, I will implement **Late Binding** by changing the default values to `None` and resolving the configuration values inside the function bodies. This ensures the functions access the current runtime state of the `Config` class. Cite debug_lesson_4.
