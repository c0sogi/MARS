The following script performs a comprehensive Exploratory Data Analysis (EDA) on the image denoising dataset. It adheres to the constraints by using only the training set defined in the metadata, ensuring reproducibility with fixed seeds, and operating within the runtime limits.

The analysis strategy involves:
1.  **Data Loading**: Iterating through the training pairs defined in `./metadata/train.csv`.
2.  **Dimensionality Analysis**: Tracking image widths, heights, and aspect ratios to understand the variability in document sizes.
3.  **Pixel Intensity Analysis**:
    - Computing global mean and standard deviation for both noisy (input) and clean (target) images using online algorithms to handle memory efficiently.
    - Using histograms to calculate skewness and kurtosis of the target pixel distributions without storing all pixel values in memory.
4.  **Noise Characterization**: Analyzing the residual signal (Input - Target) to understand the noise distribution (mean, std) and its relationship with the signal.
5.  **Signal Relationships**: Calculating the Pearson correlation between noisy and clean images to quantify the signal-to-noise relationship.
6.  **Metadata Correlations**: Checking if image dimensions correlate with the density of text (mean pixel intensity).
