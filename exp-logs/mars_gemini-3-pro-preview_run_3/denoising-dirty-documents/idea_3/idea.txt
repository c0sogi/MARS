# Idea 3: Dilated Residual Denoising Network (DRDN)

### Model
I propose a **Dilated Residual Denoising Network (DRDN)**. This architecture is designed to capture both local texture and broader structural context without sacrificing spatial resolution.
*   **Backbone**: The model consists of a deep stack of convolutional layers (e.g., 15-20 layers). Unlike the U-Net, this architecture contains **no pooling or downsampling layers**, ensuring that the feature maps maintain the same spatial resolution as the input throughout the network. This directly addresses the lesson that downsampling causes the loss of high-frequency details like thin text strokes **Cite {solution_lesson_node_00009}**.
*   **Dilated Convolutions**: To overcome the limited receptive field of the "Simple DnCNN" (which only sees a small local window), I will introduce **Dilated Convolutions** in the intermediate layers. By progressively increasing the dilation rate (e.g., 1, 2, 4, 8, 4, 2, 1), the network can aggregate context from a much larger area to distinguish between noise and text structure, while keeping the resolution intact.
*   **Residual Learning Strategy**: The network will be designed to predict the **noise map** (residual) rather than the clean image directly. A global skip connection will subtract the predicted noise from the noisy input to yield the clean output.
*   **Non-Linearity**: The network utilizes ReLU activation functions after each convolution, ensuring it can model the non-linear separation between signal and noise, which global linear filters failed to do **Cite {solution_lesson_node_00001}**.

### Data
1.  **Preprocessing**: Normalize all image pixel intensities to the range $[0, 1]$.
2.  **Patch Extraction**:
    *   Unlike the "tiny 5x5 patches" used in the previous best solution, I will extract **moderate-sized patches** (e.g., $50 \times 50$ or $64 \times 64$) from the training images.
    *   This larger patch size is essential to allow the **Dilated Convolutions** to effectively utilize their expanded receptive field.
3.  **Augmentation**: Apply random horizontal/vertical flips and 90-degree rotations to the patches to increase dataset diversity and enforce rotation invariance.

### Training
*   **Loss Function**: Use **Mean Squared Error (MSE)** between the predicted noise map and the actual noise (Input - Clean Target). Minimizing this residual error directly optimizes the reconstruction quality.
*   **Optimizer**: Use **Adam** or **AdamW** with a learning rate scheduler (e.g., ReduceLROnPlateau) to fine-tune weights as convergence slows.
*   **Procedure**: Train on batches of the extracted patches. The residual formulation simplifies the optimization landscape, as the noise is generally sparser and has lower variance than the full image intensity.

### Evaluation
1.  **Inference**: Perform inference on the **full-resolution** test images. Since the model is fully convolutional and resolution-preserving, it can process arbitrary image sizes (memory permitting) or large overlapping tiles.
2.  **Reconstruction**:
    *   The model outputs the predicted noise.
    *   Compute: $\text{Clean Prediction} = \text{Noisy Input} - \text{Predicted Noise}$.
3.  **Post-processing**: Clip the resulting pixel values to $[0, 1]$ and format the output into the required `image_row_col` submission format.
