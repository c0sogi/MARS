Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration Override**: To ensure a "fast baseline" that completes quickly, I will programmatically override `Config.NUM_EPOCHS` to a low value (5) and `Config.EARLY_STOPPING_PATIENCE` to 2.
2.  **Training**: I will initialize the `Trainer` and call `fit()`. I will pass `load_cached_data=True` to utilize existing preprocessed data and `debug_limit=10000` to restrict the number of training patches, ensuring the training phase finishes rapidly.
3.  **Validation**: After training, I will reload the best model checkpoint saved by the trainer. I will then perform inference on the full validation set (without limits) to calculate the `Final Validation Metric` (RMSE).
4.  **Failure Analysis**: I will iterate through the validation set again to collect pixel-level predictions, targets, and inputs. I will calculate the absolute error magnitude for each pixel and compute its Pearson correlation with the input pixel intensities to identify if error is driven by brightness levels.
5.  **Submission**: I will compare the final validation RMSE against the specified threshold (`0.016654925420880318`). If the model performance is sufficient, I will invoke the `generate_predictions` function from the `inference` module to create the submission file.
