Based on the comprehensive analysis of previous failures and empirical findings, I propose the **Ensemble of Curriculum-Trained Zero-Initialized Deep Residual Networks (ECT-ZI-ResDnCNN)**. This strategy synthesizes the high-throughput backbone of linear residual stacks with a stabilized initialization scheme, optimized via a density-curriculum pipeline to balance model capacity with training efficiency, and robustified via ensembling.

# Model
I propose a **Homogeneous Ensemble** where each member is a **Zero-Initialized Deep Residual Denoising Network (ZI-ResDnCNN)**.

*   **Backbone Architecture**: Each network consists of a deep stack (e.g., 20 blocks, 40+ layers) of **Linear Residual Stacks** (Conv-BN-ReLU-Conv-BN).
    *   **Throughput Optimization**: We strictly adhere to this linear topology rather than Dense Connectivity (RDN) or Attention mechanisms. This maximizes computational throughput (samples/second), which is critical to enabling the training of multiple ensemble members within the time limit **Cite {solution_lesson_node_00018}**.
    *   **Inductive Bias**: We utilize standard dense $3 \times 3$ convolutions, explicitly rejecting dilated convolutions (which miss local pixel correlations **Cite {solution_lesson_node_00011}**) and attention mechanisms (which add overhead without aiding local denoising **Cite {solution_lesson_node_00025}**).
    *   **Resolution Preservation**: The network contains **no pooling or downsampling layers**, operating entirely at the original spatial resolution to preserve fine text strokes **Cite {solution_lesson_node_00009}**.
*   **Stabilized Initialization**: To enable the training of this deep regression network without the signal explosion observed in previous attempts, I implement **Zero-Gamma Initialization**. The learnable scaling parameter ($\gamma$) of the last Batch Normalization layer in *every* residual block is initialized to **zero**. This forces each block to behave as an identity function at initialization, preventing variance accumulation and allowing the deep network to learn residuals incrementally **Cite {solution_lesson_node_00019}**.
*   **Global Residual Learning**: The network predicts the **noise residual** $\mathcal{R}(x)$, with the final output being $\text{Input} - \mathcal{R}(x)$ **Cite {solution_lesson_node_00012}**.

# Data
I propose a **Curriculum-Based Data Strategy** to resolve the conflict between the need for high data density **Cite {solution_lesson_node_00013}** and the computational cost of processing it **Cite {solution_lesson_node_00020}**.

1.  **Preprocessing**: Normalize all image pixel intensities to $[0, 1]$.
2.  **Curriculum Datasets**:
    *   **Phase 1 (Sparse/Fast)**: Extract patches of size $50 \times 50$ with a **large stride** (e.g., 20 pixels). This creates a lightweight dataset for rapid initial convergence.
    *   **Phase 2 (Dense/Refined)**: Extract patches of size $50 \times 50$ with a **small stride** (e.g., 10 pixels). This creates a massive dataset to fully saturate the deep model's capacity.
3.  **Augmentation**: Apply random horizontal/vertical flips and 90-degree rotations.

# Training
*   **Ensemble Strategy**: Train **$K=5$ independent instances** of the model using different random seeds. Ensembling is the most reliable method to reduce variance and improve RMSE, enabled by the high throughput of the chosen backbone.
*   **Curriculum Procedure**:
    *   **Stage 1**: Train each ensemble member on the **Sparse Dataset** for the first ~20% of its allocated time. This allows the optimizer to quickly find a robust global minimum without being bottlenecked by the massive epoch time of dense data **Cite {solution_lesson_node_00020}**.
    *   **Stage 2**: Fine-tune the model on the **Dense Dataset** for the remaining time. This exposes the stabilized model to the maximum amount of spatial data, satisfying the density requirements for deep networks **Cite {solution_lesson_node_00013}**.
*   **Loss Function**: Minimize **Mean Squared Error (MSE)**.
*   **Optimizer**: Use **AdamW** with a **Cosine Annealing** scheduler.

# Evaluation
*   **Dual-Level Inference**:
    1.  **Geometric Self-Ensemble (TTA)**: For each of the $K$ models, generate predictions for 8 geometric transformations (flips/rotations) of the test image, inverse-transform the outputs, and average them.
    2.  **Ensemble Averaging**: Compute the final prediction by averaging the TTA outputs of all $K$ ensemble members.
*   **Reconstruction**: Compute $\text{Clean Image} = \text{Noisy Input} - \text{Ensemble Predicted Noise}$.
*   **Submission**: Clip pixel intensities to $[0, 1]$ and flatten to the `image_row_col` format.
