# Idea 2: Deep Convolutional U-Net for Spatially Adaptive Denoising

### Model
I propose implementing a **U-Net Architecture**, a fully convolutional neural network designed for image-to-image translation tasks.
*   **Architecture Design**: The model consists of a contracting path (encoder) and an expansive path (decoder). The encoder uses repeated blocks of convolutional layers followed by non-linear activations (ReLU) and max-pooling to capture context and distinguish between the statistical texture of noise and the structural patterns of text. The decoder uses up-sampling operators to restore the image resolution.
*   **Addressing Previous Limitations**: To directly address the finding that global linear filters "over-smooth" edges Cite {solution_lesson_node_00001}, this architecture incorporates **skip connections**. These connections concatenate feature maps from the encoder directly to the corresponding layers in the decoder. This allows high-frequency spatial information (such as the sharp edges of text characters) to bypass the bottleneck, enabling the network to denoise background regions while preserving the structural integrity of the text. The use of non-linear activation functions throughout the network ensures the model can learn the complex, non-linear relationship required to separate signal from noise, which the previous linear model failed to do Cite {solution_lesson_node_00001}.

### Data
1.  **Preprocessing**:
    *   Normalize pixel intensities of all images to the range $[0, 1]$ to stabilize gradient descent.
    *   Maintain the data as single-channel grayscale images.
2.  **Augmentation & Patching**:
    *   Given the relatively small dataset size (92 training images), training on full images may lead to overfitting or memory inefficiencies. Instead, I will employ **Random Patch Cropping**.
    *   During training, extract random patches (e.g., $128 \times 128$ or $256 \times 256$) from the source images. This significantly increases the effective number of training samples and forces the model to learn translation-invariant denoising features.
    *   Apply random horizontal/vertical flips to these patches to further augment the data, assuming the noise distribution is rotationally invariant even if the text is not.

### Training
*   **Loss Function**: Use **Mean Squared Error (MSE)** loss. Since the competition metric is RMSE, minimizing MSE is the direct proxy for optimizing the evaluation score.
*   **Optimizer**: Use the **Adam** optimizer, which adapts learning rates for each parameter, facilitating faster convergence compared to standard SGD.
*   **Procedure**:
    *   Train the network for a fixed number of epochs or until validation loss plateaus (Early Stopping).
    *   Feed batches of the augmented patches into the network, computing the loss against the corresponding clean patches.

### Evaluation
1.  **Inference**:
    *   Unlike the patch-based training, inference will be performed on the **full-resolution test images** (or large overlapping tiles if memory is constrained, though the A100 should handle these dimensions easily).
    *   Pass the normalized noisy test images through the trained U-Net to generate the cleaned output.
2.  **Post-processing**:
    *   Clip the output pixel values to the range $[0, 1]$ to ensure validity.
    *   Flatten the image arrays into the required `image_row_col` format for submission.
