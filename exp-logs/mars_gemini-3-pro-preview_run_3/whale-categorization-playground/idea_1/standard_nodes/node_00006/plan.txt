It allows the model to focus on salient features (like specific fluke patterns) rather than averaging the entire feature map, which is crucial when distinguishing between similar whales.
2.  **Resolution Increase:** I will increase the input image resolution from 224x224 to **256x256**. This allows the model to capture finer details of the whale flukes, which are essential for identification.
3.  **Regularization:** I will add **Random Erasing** to the training augmentations. This forces the model to learn distributed features rather than relying on a single scar or mark, improving generalization.
4.  **Hyperparameter Tuning:** I will increase the `BATCH_SIZE` to **32** (utilizing the A100's memory) and `EPOCHS` to **20** to ensure the model—and the new learnable pooling parameter—has sufficient time to converge.

class GeM(nn.Module):
    """
    Generalized Mean Pooling layer.
    """
    def __init__(self, p=3, eps=1e-6):
        super(GeM, self).__init__()
        self.p = nn.Parameter(torch.ones(1) * p)
        self.eps = eps

    def forward(self, x):
        return self.gem(x, p=self.p, eps=self.eps)

    def gem(self, x, p=3, eps=1e-6):
        return F.avg_pool2d(x.clamp(min=eps).pow(p), (x.size(-2), x.size(-1))).pow(1.0 / p)
