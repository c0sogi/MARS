To solve the Humpback Whale Identification challenge, I propose a baseline approach based on **Siamese Representation Learning**. This method focuses on learning a similarity metric between images rather than performing direct classification, making it highly effective for the "few-shot" nature of the dataset (where many whales appear only once) and the open-set requirement (identifying `new_whale`).

### Model
The architecture is a **Siamese Network** utilizing a shared, lightweight **ResNet-18** backbone.
*   **Backbone:** The ResNet-18 processes an input image and outputs a high-dimensional feature vector (embedding), typically 128 or 256 dimensions.
*   **Siamese Structure:** During training, the network accepts pairs of images. Both images are passed through the same backbone (sharing weights) to produce two embeddings, $E_1$ and $E_2$.
*   **Distance Metric:** The model computes the Euclidean distance between $E_1$ and $E_2$. This distance represents the dissimilarity between the two whale flukes.

### Data
*   **Preprocessing:** All images are resized to a standard resolution (e.g., 224x224) and normalized. Single-channel (grayscale) images are converted to 3-channel by replicating the channel.
*   **Pair Generation (Training):** Data is organized into pairs:
    *   **Positive Pairs:** Two different images of the same whale `Id`.
    *   **Negative Pairs:** Images of two different whale `Ids`.
    *   **'new_whale' Handling:** Images labeled `new_whale` are exclusively used to form **Negative Pairs** against known whales. This teaches the model that `new_whale` images are dissimilar to known identities, without forcing the model to cluster all distinct `new_whale` individuals together.
*   **Augmentation:** Lightweight augmentations (horizontal flips, slight rotations, brightness contrast) are applied to increase the variety of positive pairs, which is critical for classes with very few samples.

### Training
*   **Loss Function:** The model is trained using **Contrastive Loss**. This loss function encourages the distance between positive pairs to approach zero and the distance between negative pairs to exceed a fixed margin (e.g., 1.0).
*   **Optimizer:** Adam optimizer with a standard learning rate (e.g., 0.001) and weight decay.
*   **Strategy:** Training proceeds by iterating through balanced batches of positive and negative pairs to prevent the model from biasing towards predicting "different" (since negative pairs are combinatorially more abundant).

### Evaluation
*   **Gallery Construction:** After training, the backbone extracts embeddings for all images in the training set (excluding `new_whale` images) to create a "Gallery" of known whale identities.
*   **Inference:**
    1.  For each test image, generate its embedding using the trained backbone.
    2.  Compute the Euclidean distances between the test embedding and all embeddings in the Gallery.
    3.  **Ranking:** Identify the top $k$ nearest neighbors (e.g., top 50).
    4.  **Prediction:**
        *   Calculate the mean distance to the closest neighbors.
        *   If this distance exceeds a calibrated **threshold**, predict `new_whale` as the primary label.
        *   Otherwise, predict the `Id`s of the nearest neighbors, ordered by proximity.
        *   Fill any remaining slots in the top 5 prediction with `new_whale` (if not already predicted) and then the next closest IDs.
