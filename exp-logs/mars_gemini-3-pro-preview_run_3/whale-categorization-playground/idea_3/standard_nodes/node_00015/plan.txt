Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using `seed_everything` and load configurations from `CFG`.
2.  **Data Loading**:
    *   Initialize `WhaleDataset` for training with `exclude_new_whale=True` to train the metric learning model only on known identities.
    *   Initialize `WhaleDataset` for validation with `exclude_new_whale=False` to evaluate on the realistic distribution (including unknown whales).
    *   Use `get_transforms` for appropriate augmentations.
3.  **Model Initialization**: Instantiate `WhaleEfficientNet` with the number of classes derived from the training set. Move the model to the GPU.
4.  **Training**:
    *   Use `CurricularFaceLoss` as the criterion.
    *   Use `AdamW` optimizer and `CosineAnnealingLR` scheduler.
    *   Execute the `fit` function from `engine.py` with a limited number of epochs (12) to ensure the "Fast Baseline" requirement is met within the time limit.
5.  **Validation**:
    *   The `fit` function returns the best MAP@5 score.
    *   Print the `Final Validation Metric`.
6.  **Failure Analysis**:
    *   Iterate through the validation set in inference mode.
    *   Calculate the error magnitude (1 - Average Precision) for each sample.
    *   Extract input features like confidence (max logit) and image aspect ratio.
    *   Compute and print correlations between error and these features.
7.  **Submission**:
    *   Check if the validation score exceeds the strict threshold `0.8543859649122806`.
    *   If passed, use `predict_and_submit` to generate the submission file using k-Reciprocal Re-ranking on the test set.
