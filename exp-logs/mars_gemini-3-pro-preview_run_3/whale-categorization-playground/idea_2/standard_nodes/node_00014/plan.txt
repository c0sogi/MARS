The previous implementation failed the validation metric check because it filtered out `new_whale` samples from the validation set (Cite debug_lesson_3). To fix this, I will modify `library/data_loader.py` to include the full validation dataset (without filtering `new_whale`) in the validation DataLoader. Additionally, I will update `runfile.py` to replace the static failure analysis with a dynamic threshold optimization step. This will search for the optimal confidence threshold for classifying `new_whale` on the validation set and apply it during inference to maximize the final score.

def calculate_correlation(x, y):
    """
    Helper to calculate Pearson correlation coefficient between two arrays.
    """
    if len(x) != len(y) or len(x) < 2:
        return 0.0
    # np.corrcoef returns a covariance matrix, [0,1] is the correlation
    return np.corrcoef(x, y)[0, 1]
