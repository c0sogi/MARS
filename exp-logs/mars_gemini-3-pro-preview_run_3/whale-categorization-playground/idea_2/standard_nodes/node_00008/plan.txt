Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `library.config` and `library.utils`. Set the random seed for reproducibility and detect the computation device (GPU).
2.  **Data Loading**: Use `library.data_loader.get_dataloaders()` to load the training, validation, and gallery datasets. This function automatically handles the filtering of "new_whale" for the ArcFace training and prepares the necessary data transforms.
3.  **Model Initialization**: Instantiate the `WhaleDenseNet` model from `library.model` with the correct number of classes derived from the data loader. Move the model to the GPU.
4.  **Training**: Initialize the `Trainer` from `library.trainer`. Execute the training loop using `trainer.fit()`. To ensure the "Fast Baseline" requirement is met while retaining model quality, the number of epochs is set to 15 (down from the default 25), which is sufficient for convergence on the A100 GPU within the time limit.
5.  **Validation & Metric Calculation**:
    *   Load the best model weights saved during training.
    *   Perform a dedicated validation pass to compute the final **MAP@5** score on the hold-out validation set (known whales).
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   During the validation pass, collect per-sample predictions (correctness) and confidence scores.
    *   Load validation metadata to retrieve image properties (Width, Height).
    *   Compute and print correlations between the **Error** (Incorrect Prediction) and input features (Confidence, Image Area, Aspect Ratio) to identify systematic failure modes.
7.  **Submission**:
    *   Compare the final validation metric against the threshold `0.27967479674796747`.
    *   If the metric exceeds the threshold, invoke `library.inference.run_inference()` to generate predictions for the test set and save `submission.csv`. This function handles the open-set recognition logic (thresholding) and formatting.
