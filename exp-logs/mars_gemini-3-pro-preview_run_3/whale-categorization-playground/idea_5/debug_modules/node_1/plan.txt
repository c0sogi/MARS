The error occurs because newer versions of PyTorch (2.6+) default `torch.load` to `weights_only=True` for security, which prevents unpickling of non-PyTorch types like the NumPy scalar `best_map5` stored in the checkpoint. To fix this, I will explicitly set `weights_only=False` in the `torch.load` calls in both `runfile.py` (where the error triggered) and `library/utils.py` (to prevent future errors in the helper function), as we are loading a trusted local checkpoint.
