The `CUDA error: device-side assert triggered` is caused by a data mismatch between the cached `LabelEncoder` (likely created during a `DEBUG` run with only ~50 classes) and the full training dataset used in the current run. When the dataset encounters a whale ID not present in the stale cache, it returns a sentinel label of `-1`. This invalid index causes the `scatter_` operation in the `ArcFaceHead` to fail on the GPU. To fix this, we must force the `LabelEncoder` to be re-fitted on the complete dataset by disabling cache loading in `runfile.py`. This ensures all classes are correctly mapped to valid indices (Cite debug_lesson_5).
