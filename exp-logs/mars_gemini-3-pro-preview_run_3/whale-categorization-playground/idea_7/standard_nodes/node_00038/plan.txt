The strategy involves implementing a robust retrieval-based pipeline using a dual-backbone ensemble (EfficientNet-B2 and EfficientNet-B3) trained with ArcFace loss. We will override the default configuration to optimize for the 2-hour time limit by setting epochs to 12 and batch size to 32. The pipeline proceeds by training both models on known whale identities, then extracting embeddings for the Training (Gallery), Validation (Query), and Test sets. We fuse these embeddings and apply k-Reciprocal Re-ranking to enhance retrieval accuracy. Validation performance is measured using MAP@5, and failure analysis is conducted by correlating errors with image file sizes. Finally, if the validation score exceeds the specified threshold, we generate a submission file where `new_whale` is predicted based on the distance to the nearest known whale.
