The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and define paths. The script will rely on the pre-generated metadata in `./metadata/train.csv`.
2.  **Target Variable Analysis**: Load the training metadata. Analyze the `Id` column to determine the number of unique whale classes, the distribution of samples per class (highlighting the class imbalance), and specifically analyze the prevalence of the `new_whale` class.
3.  **Image Data Analysis**: Iterate through the training images located in `./input/train/`. For each image, extract dimensions (width, height), calculate aspect ratios, and check channel counts. To compute global pixel statistics (mean and standard deviation) efficiently without loading all images into memory simultaneously, we will use an accumulator approach (summing values and squared values).
4.  **Feature/Signal Relationships**: Investigate relationships between image metadata (e.g., image size, aspect ratio) and the target variable. Specifically, we will check if "new_whale" images differ significantly in resolution or aspect ratio compared to identified whales, which could inform preprocessing (e.g., resizing strategies).
5.  **Reporting**: Format the output into distinct, capitalized sections with floating-point numbers formatted to 4 decimal places, ensuring the script runs silently and robustly within the time limit.
