# Baseline Approach: Polynomial Ridge Regression with Structural Descriptors

## Model
The proposed model is a **Polynomial Ridge Regressor**, a regularized linear model that extends standard linear regression by explicitly modeling non-linear feature interactions. Unlike the gradient-boosted trees (Model 1) or deep neural networks (Model 4), this approach relies on a single, interpretable linear layer applied to a deterministically expanded feature space. It avoids the computational cost of graph convolutions (Model 2) or kernel matrix computations (Model 3) by using fixed feature engineering to capture the physics of the material system (e.g., compositional bowing effects).

## Data
The data pipeline integrates the provided tabular data with global structural descriptors derived from the geometry files:
1.  **Feature Extraction**:
    *   **Tabular**: Utilize atomic percentages (Al, Ga, In), lattice vectors, and angles.
    *   **Geometric**: Parse the `.xyz` files to calculate global properties such as **unit cell volume** and **atomic density**.
2.  **Encoding**: The `spacegroup` feature is one-hot encoded to handle categorical symmetry information.
3.  **Polynomial Expansion**: Generate degree-2 polynomial features (interaction terms and squared terms), specifically focusing on the atomic composition variables. This allows the linear model to capture quadratic relationships common in alloy physics (e.g., bandgap bowing).
4.  **Normalization**: Apply standard scaling (z-score normalization) to all features to ensure effective regularization.
5.  **Target Transformation**: Apply a natural logarithm transformation ($\log(1+y)$) to the target variables (`formation_energy_ev_natom` and `bandgap_energy_ev`). This aligns the model's inherent Mean Squared Error (MSE) objective with the competition's Root Mean Squared Logarithmic Error (RMSLE) metric.

## Training
The training procedure prioritizes speed and stability:
*   **Loss Function**: Mean Squared Error (MSE) on the log-transformed targets.
*   **Algorithm**: Train two independent Ridge Regression models (one for each target). Ridge regression minimizes the residual sum of squares plus a penalty term proportional to the square of the magnitude of the coefficients ($L2$ regularization).
*   **Optimization**: The weights are solved analytically (using Cholesky decomposition or SVD) or via an efficient iterative solver (e.g., LSQR), making training extremely fast compared to iterative gradient descent methods used in neural networks.
*   **Hyperparameter Tuning**: Perform K-fold cross-validation (e.g., $k=5$) to determine the optimal regularization strength ($\alpha$) for each target.

## Evaluation
For inference on the test set:
1.  Preprocess the test data (feature extraction, encoding, expansion, and scaling) using the pipelines fitted on the training data.
2.  Generate predictions using the trained Ridge models.
3.  Apply the inverse target transformation ($\exp(x) - 1$) to convert predictions back to the original energy scale.
4.  Construct the submission file with columns `id`, `formation_energy_ev_natom`, and `bandgap_energy_ev`.
