The issue is a cache collision between the geometry extraction step and the feature engineering pipeline. The `DataManager` saves raw geometry features to `train_features.parquet`, and the `FeaturePipeline` subsequently loads this same file, expecting it to contain the fully processed dataset (including targets), which it does not. To fix this, I will separate the cache file paths in `Config` into geometry caches (e.g., `train_geometry.parquet`) and processed feature caches (e.g., `train_processed.parquet`), and update `DataManager` and `runfile.py` to use their respective paths. This ensures that the feature pipeline computes features from the input dataframe (which has targets) rather than loading the incomplete geometry cache. (Cite Lesson: Data Leakage & Cache Management)
