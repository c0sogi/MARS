The implementation strategy involves creating a single Python script that imports the provided library modules and systematically exercises their functionality. To ensure speed, I will monkey-patch the `XGB_PARAMS` in the configuration to use a minimal number of estimators and set `max_samples` to small values (e.g., 5-20) when calling data loading and training functions. The script will proceed through four main stages: (1) Data Loading, verifying metadata and geometry loading; (2) Feature Extraction, verifying physical descriptor calculation; (3) GNN Embedding, verifying the generation of chemically-resolved embeddings using MatGL; and (4) Model Training & Inference, verifying the end-to-end pipeline from training XGBoost models to generating a submission file. Assertions will be used at each step to validate data types, shapes, and file existence.
