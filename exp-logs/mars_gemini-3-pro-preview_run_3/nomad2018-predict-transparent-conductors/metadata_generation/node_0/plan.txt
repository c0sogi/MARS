The implementation strategy involves the following steps:

1.  **Setup and Data Loading**: Define paths for input and metadata directories. Load the `train.csv` and `test.csv` files using pandas.
2.  **Metadata Generation**:
    *   For the training dataframe, construct the relative file path for each sample as `train/{id}/geometry.xyz`.
    *   For the test dataframe, construct the relative file path as `test/{id}/geometry.xyz`.
    *   Create a stratification column for the training data by binning the `formation_energy_ev_natom` target variable into quantiles. This ensures the validation set has a representative distribution of the target labels.
3.  **Data Splitting**:
    *   Split the training dataframe into training and validation sets using an 80:20 ratio and a fixed random state (42), stratifying on the binned target column.
    *   Clean up temporary columns (like the stratification bin) before saving.
4.  **Saving Metadata**: Save the resulting `train`, `val`, and `test` dataframes as CSV files in the `./metadata` directory.
5.  **Validation and Checks**:
    *   **Load**: Reload the generated metadata files.
    *   **Statistics**: Print summary statistics (shape, column names, target distribution statistics) for each dataset.
    *   **File Path Verification**: Randomly sample 1000 paths (or all if fewer than 1000) from each dataset and verify that the files exist in the `./input` directory. Calculate the missing ratio and raise an error if it exceeds 0.5.
    *   **Split Verification**: Assert that the training/validation split ratio is approximately 80:20.
