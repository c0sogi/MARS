This script demonstrates the end-to-end usage of the provided library modules. It first processes a small subset of the geometry files to generate features using `data_pipeline` and `feature_engineering`. Then, it verifies the calculation of specific geometric descriptors like Bond Valence Sums and Radial Distribution Functions. Finally, it trains a lightweight XGBoost model using `training.py` on the generated features to predict formation energy and bandgap energy, asserting the validity of the output.
