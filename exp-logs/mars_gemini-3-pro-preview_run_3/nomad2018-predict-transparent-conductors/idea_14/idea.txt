Based on the analysis of previous attempts and the accumulated lessons, I propose a **Chemically-Resolved Local Environment Moments (CR-LEM)** strategy.

This approach is a structural evolution of the **Radial Distribution Function (RDF)** strategy (Idea 10). While RDFs successfully capture 2-body radial constraints (Cite Lesson 29), the attempt to add 3-body constraints via **Angular Distribution Functions (ADF)** failed due to feature sparsity and over-resolution (Cite Lesson 34). This new strategy addresses that failure by compressing the high-dimensional angular/topological information into dense, chemically specific statistical moments (e.g., "Average Coordination Number of Aluminum") rather than sparse histograms. This preserves the critical polyhedral geometry information (tetrahedral vs. octahedral coordination) required for bandgap prediction without diluting the feature space.

# Model
-   **Architecture**: **XGBoost Regressor** (Cite Lesson 3). Tree ensembles remain the most robust predictor for this dataset when provided with high-signal, dense features.
-   **Input Features**: A concatenated feature vector consisting of:
    1.  **Explicit Physical Descriptors**: Unit Cell Volume and Mass Density derived from raw geometry (Cite Lesson 18).
    2.  **Radial Fingerprints (RDF)**: Element-resolved pairwise distance histograms (Cite Lesson 29).
    3.  **Local Environment Moments (Innovation)**: Dense statistical summaries of the local coordination environment (Coordination Number, Bond Angle Variance) aggregated by chemical species.
    4.  **Tabular Metadata**: Atomic composition and Spacegroup.

# Data
1.  **Geometric Feature Extraction (Raw Geometry)**:
    -   Load crystal structures from raw `.xyz` files using the `ase` library to ensure fidelity (Cite Lesson 18).
    -   **Global Physical Descriptors**: Calculate **Unit Cell Volume** and **Mass Density** directly from the atomic objects (Cite Lesson 18).
    -   **Radial Features (RDF)**: Compute element-resolved Radial Distribution Functions using a moderate cutoff (e.g., 6.0 Å) and bin count. Normalize these histograms by **atom count** to decouple topology from density (Cite Lesson 33).
    -   **Local Environment Features (The Innovation)**:
        -   **First-Shell Neighbor Analysis**: Construct a neighbor list using a short, physically motivated cutoff (e.g., ~3.0 Å) designed to capture only the immediate bonding environment (Metal-Oxygen polyhedra).
        -   **Atom-Level Metrics**: For every atom in the crystal, calculate:
            1.  **Coordination Number (CN)**: The count of immediate neighbors.
            2.  **Bond Angle Variance ($\sigma^2_{\theta}$)**: The variance of the angles formed between the central atom and its neighbors. This serves as a scalar proxy for polyhedral distortion.
        -   **Chemical Aggregation**: Group these atom-level metrics by element type (Al, Ga, In, O). Compute the **Mean** and **Standard Deviation** for each group (e.g., "Mean Al Coordination", "Std Dev of In Bond Angle Variance"). This yields a dense, fixed-size vector capturing 3-body topology without the sparsity of ADFs.

2.  **Preprocessing**:
    -   **Target Transformation**: Apply the natural logarithm transformation $z = \log(1 + y)$ to the target variables (`formation_energy_ev_natom` and `bandgap_energy_ev`) (Cite Lesson 2).
    -   **Feature Cleaning**: Drop constant columns to prevent noise.

# Training
-   **Algorithm**: Train separate XGBoost regressors for formation energy and bandgap energy.
-   **Optimization Strategy**:
    -   **Shrinkage**: Use a **low learning rate** (e.g., $\eta \approx 0.01$) and a **high number of estimators** (e.g., 3,000) (Cite Lesson 4).
    -   **Stochastic Subsampling**: Set row (`subsample`) and column (`colsample_bytree`) subsampling to $\approx 0.6 - 0.7$. This forces the model to utilize the diverse structural information (RDF and Local Moments) rather than relying solely on global density (Cite Lesson 4).
-   **Loss Function**: Mean Squared Error (MSE) on the log-transformed targets.

# Evaluation
-   **Inference**:
    1.  Process the test set `.xyz` files to generate Physical Descriptors, RDFs, and Local Environment Moments.
    2.  Generate predictions in the log-transformed space using the trained XGBoost models.
    3.  Apply the inverse transformation $\hat{y} = \exp(z) - 1$ to obtain the final energy predictions.
