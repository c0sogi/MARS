Implementation strategy:
1.  **Setup**: Initialize random seeds for reproducibility using `random`, `numpy`, and `torch`.
2.  **Data Loading**: Use `library.data_manager.process_dataset` to load metadata, generate features (Anisotropy, BVS, ECoN, RDFs), and split the data into training, validation, and test sets. Enable caching to speed up subsequent runs.
3.  **Preprocessing**: Use `library.preprocessor.preprocess_features` to remove constant columns and ensure data cleanliness.
4.  **Model Configuration**: Configure `XGBoost` parameters. Detect if a GPU is available via `torch.cuda.is_available()` and set `device="cuda"` and `tree_method="hist"` for accelerated training.
5.  **Training**: Instantiate `library.regressor.DualTargetRegressor` and fit it on the training data with early stopping based on the validation set performance.
6.  **Validation**: Evaluate the model on the hold-out validation set. Calculate the Column-wise Root Mean Squared Logarithmic Error (RMSLE) and print it in the required format: `Final Validation Metric: <value>`.
7.  **Failure Analysis**: Calculate the log-space error magnitude for each validation sample. Compute and print the top 10 features most correlated with this error to identify failure modes.
8.  **Submission**: If the validation metric is below the threshold of 0.05095, generate predictions for the test set and save them to `./submission/submission.csv` using `library.regressor.generate_submission`.
