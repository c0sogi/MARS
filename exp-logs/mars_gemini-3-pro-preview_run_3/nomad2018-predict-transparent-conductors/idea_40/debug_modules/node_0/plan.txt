This script demonstrates the end-to-end usage of the provided machine learning pipeline for material property prediction. It covers data loading, feature extraction, preprocessing, model training, and submission generation.

The script performs the following steps:
1.  **Configuration**: Patches the XGBoost parameters in `library.config` to ensure the demonstration runs quickly (reducing estimators from 3000 to 10).
2.  **Data Loading**: Loads metadata and a sample atomic structure to verify data access.
3.  **Feature Extraction**: Instantiates the `StructureFeaturizer` and computes features (RDF, Bond Valence, etc.) for a single structure to verify logic.
4.  **Preprocessing**: Runs the full preprocessing pipeline (feature generation + cleaning) for Train, Validation, and Test splits. This forces re-computation (`load_cached_data=False`) to demonstrate the pipeline in action.
5.  **Model Training**: Trains the XGBoost models using the processed data.
6.  **Inference**: Generates predictions for the test set and creates a submission file.
