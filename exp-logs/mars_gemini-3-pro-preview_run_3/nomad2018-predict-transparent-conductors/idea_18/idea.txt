Based on the comprehensive analysis of previous attempts and the accumulated lessons, I propose a **Hierarchical Sublattice-Resolved Geometric Fingerprinting** strategy.

This approach addresses the "feature dilution" observed in element-specific models (Cite solution_lesson_node_00016) and the "noise" inherent in naive global aggregates (Cite solution_lesson_node_00024). By explicitly modeling the crystal structure at two hierarchical levels—specific chemical species (Al, Ga, In) and the broader **Cation/Anion Sublattices**—we ensure the model receives dense, high-signal structural descriptors describing the framework's integrity (e.g., Metal-Oxygen polyhedra distortion) regardless of the specific alloy composition, while still retaining element-specific nuances.

# Model
-   **Architecture**: **XGBoost Regressor** (Cite solution_lesson_node_00003). Tree ensembles remain the most robust predictor for this dataset when provided with high-quality, mathematically defined features.
-   **Input Features**: A concatenated feature vector consisting of:
    1.  **Global Physical Descriptors**: Unit Cell Volume and Mass Density.
    2.  **Pairwise Fingerprints (RDF)**: Element-resolved Radial Distribution Functions.
    3.  **Hierarchical Local Moments (The Innovation)**: Geometric statistics (Coordination, Distortion) aggregated at both the **Element** level and the **Sublattice** level.
    4.  **Tabular Metadata**: Atomic composition and Spacegroup.

# Data
1.  **Geometric Feature Extraction (Raw Geometry)**:
    -   Load crystal structures from raw `.xyz` files using the `ase` library to ensure fidelity (Cite solution_lesson_node_00018).
    -   **Global Physical Descriptors**: Calculate **Unit Cell Volume** and **Mass Density** directly from the atomic objects (Cite solution_lesson_node_00018).
    -   **Radial Features (RDF)**: Compute element-resolved Radial Distribution Functions using a moderate cutoff (e.g., 6.0 Å). Normalize histograms by **atom count** to decouple topology from density (Cite solution_lesson_node_00033).
    -   **Hierarchical Local Moments**:
        -   **Atom-Level Calculation**: For every atom in the crystal, compute a set of local geometric descriptors based on its nearest neighbors (cutoff $\approx 3.0$ Å):
            *   **Coordination Number (CN)**.
            *   **Bond Length Variance**: A measure of radial distortion (e.g., off-center displacement).
            *   **Bond Angle Variance**: A measure of angular distortion (e.g., octahedral tilting) (Cite solution_lesson_node_00037).
        -   **Level 1 Aggregation (Element-Specific)**: Compute the **Mean** and **Standard Deviation** of these metrics for each species (Al, Ga, In, O) independently.
        -   **Level 2 Aggregation (Sublattice-Specific)**: Compute the **Mean** and **Standard Deviation** of these metrics for the **Metal Sublattice** (all Al, Ga, In atoms combined) and the **Oxygen Sublattice**. This creates a dense, robust baseline signal for the overall crystal quality that is never sparse, solving the feature dilution problem (Cite solution_lesson_node_00016).

2.  **Preprocessing**:
    -   **Target Transformation**: Apply the natural logarithm transformation $z = \log(1 + y)$ to the target variables (`formation_energy_ev_natom` and `bandgap_energy_ev`) (Cite solution_lesson_node_00002).
    -   **Feature Cleaning**: Drop constant columns.

# Training
-   **Algorithm**: Train separate XGBoost regressors for formation energy and bandgap energy.
-   **Optimization Strategy**:
    -   **Shrinkage**: Use a **low learning rate** (e.g., $\eta \approx 0.01$) and a **high number of estimators** (e.g., 3,000) (Cite solution_lesson_node_00004).
    -   **Stochastic Subsampling**: Set row (`subsample`) and column (`colsample_bytree`) subsampling to $\approx 0.6 - 0.7$. This forces the model to utilize the diverse structural hierarchy (Sublattice vs. Element) rather than overfitting to specific features (Cite solution_lesson_node_00004).
    -   **Regularization**: Constrain tree depth (e.g., `max_depth`=6) to prevent memorization of fine-grained geometric artifacts (Cite solution_lesson_node_00046).
-   **Loss Function**: Mean Squared Error (MSE) on the log-transformed targets.

# Evaluation
-   **Inference**:
    1.  Process the test set `.xyz` files to generate Physical Descriptors, RDFs, and Hierarchical Local Moments.
    2.  Generate predictions in the log-transformed space using the trained XGBoost models.
    3.  Apply the inverse transformation $\hat{y} = \exp(z) - 1$ to obtain the final energy predictions.
