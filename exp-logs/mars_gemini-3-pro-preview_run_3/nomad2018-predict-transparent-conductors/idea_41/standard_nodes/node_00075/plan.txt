The solution involves an end-to-end Python script `runfile.py` that orchestrates data loading, feature engineering, model training (XGBoost), validation, failure analysis, and submission generation.

**Implementation Strategy:**
1.  **Data Loading**: The script utilizes the provided `load_and_preprocess_data` function from `library.preprocessor`. This function handles loading metadata, computing/loading features via `library.feature_engine` (which implements the "Focused Chemo-Structural Distributional Fingerprinting" strategy), and cleaning the dataset.
2.  **Model Training**: It initializes the `XGBRegressorWrapper` from `library.model_wrapper`, which encapsulates two XGBoost regressors (one per target) with log-transformation logic. The `train` method is called with training and validation sets.
3.  **Validation**: After training, predictions are made on the validation set in the original scale. The competition metric (Column-wise Root Mean Squared Logarithmic Error) is explicitly calculated.
4.  **Failure Analysis**: The script computes the mean absolute error in log-space for each validation sample and correlates this error with input features to identify sources of poor performance.
5.  **Submission**: If the calculated validation metric is below the threshold of 0.05095, the model predicts on the test set, and a submission file is generated at `./submission/submission.csv`.
