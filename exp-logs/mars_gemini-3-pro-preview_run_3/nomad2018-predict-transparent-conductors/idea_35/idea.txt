Based on the comprehensive analysis of previous attempts and the accumulated lessons, I propose an **Alloy-Resolved Topological Distribution Fingerprinting** strategy.

This approach evolves the successful **Sublattice-Resolved** (Idea 34) and **Bond Valence Sum** (Idea 28) strategies by addressing the "smearing" of structural information in global aggregates. While previous models successfully captured *average* distortion (via global bond angle percentiles) and *local* chemical stability (via BVS), they failed to explicitly resolve the specific **cation-cation interactions** (e.g., Al-O-Ga vs. In-O-In linkages) that govern the bandgap bowing in semiconductor alloys. By decomposing the network topology into chemically specific distributions and aggregating them via robust percentiles, this strategy captures the precise structural consequences of alloying without the sparsity of histograms or the rigidity of derived physical indices.

# Model
-   **Architecture**: **XGBoost Regressor** (Cite solution_lesson_node_00003). Tree ensembles remain the most effective architecture for this dataset when provided with dense, high-signal descriptors.
-   **Input Features**: A concatenated feature vector representing the material from four physical perspectives:
    1.  **Macroscopic View**: Unit Cell Volume, Mass Density, and Tabular Metadata (Composition, Lattice Parameters) (Cite solution_lesson_node_00018, solution_lesson_node_00058).
    2.  **Radial View**: Element-resolved Radial Distribution Functions (RDF) for both Metal-Oxygen and Metal-Metal pairs (Cite solution_lesson_node_00029).
    3.  **Atomic Site View**: Chemically resolved percentiles of **Scalar Bond Valence Sums (BVS)** (Cite solution_lesson_node_00060) and **Effective Coordination Numbers (ECoN)** (Cite solution_lesson_node_00057).
    4.  **Alloy Topology View (The Innovation)**: Chemically resolved percentiles of **Metal-Oxygen-Metal (M-O-M) Bridging Angles**.

# Data
1.  **Geometric Feature Extraction (Raw Geometry)**:
    -   Load crystal structures from raw `.xyz` files using the `ase` library to ensure fidelity (Cite solution_lesson_node_00018).
    -   **Macroscopic**: Calculate **Unit Cell Volume** and **Mass Density** directly from the atomic objects.
    -   **Radial (RDF)**: Compute **Element-Resolved RDFs** using a moderate cutoff (e.g., 6.0 Å). Include **Metal-Metal** pairs (Al-Al, Al-Ga, etc.) to capture cation clustering. Normalize by **atom count** (Cite solution_lesson_node_00033).
    -   **Atomic Site Fingerprints**:
        -   Calculate **Scalar BVS** and **ECoN** for every atom.
        -   Group by element type (Al, Ga, In, O) and compute **Percentiles** (Min, 25%, 50%, 75%, Max). This captures the distribution of site stabilities (Cite solution_lesson_node_00054).
    -   **Alloy Topology Fingerprints**:
        -   Identify all **Metal-Oxygen-Metal** linkages in the crystal.
        -   Classify each linkage by the specific pair of metals involved (e.g., **Al-O-Al**, **Al-O-Ga**, **Ga-O-In**, etc.).
        -   For each class, collect the population of **Bond Angles**.
        -   Compute **Percentiles** (Min, 25%, 50%, 75%, Max) for each class.
        -   **Handling Sparsity**: If a specific linkage type (e.g., In-O-In) is missing in a crystal, assign **NaN**. XGBoost handles missing values natively, preventing the "feature dilution" caused by zero-filling (Cite solution_lesson_node_00016).

2.  **Preprocessing**:
    -   **Target Transformation**: Apply the natural logarithm transformation $z = \log(1 + y)$ to the target variables (Cite solution_lesson_node_00002).
    -   **Feature Cleaning**: Drop constant columns.

# Training
-   **Algorithm**: Train separate XGBoost regressors for formation energy and bandgap energy.
-   **Optimization Strategy**:
    -   **Shrinkage**: Use a **low learning rate** (e.g., $\eta \approx 0.01$) and a **high number of estimators** (e.g., 3,000) to maximize generalization (Cite solution_lesson_node_00004).
    -   **Stochastic Subsampling**: Set row (`subsample`) and column (`colsample_bytree`) subsampling to $\approx 0.6 - 0.7$. This forces the model to utilize the diverse structural views (Alloy Topology vs. Site Stability) rather than overfitting to specific features (Cite solution_lesson_node_00004).
-   **Loss Function**: Mean Squared Error (MSE) on the log-transformed targets.

# Evaluation
-   **Inference**:
    1.  Process the test set `.xyz` files to generate the Multi-Scale Alloy-Resolved features.
    2.  Generate predictions in the log-transformed space using the trained XGBoost models.
    3.  Apply the inverse transformation $\hat{y} = \exp(z) - 1$ to obtain the final energy predictions.
