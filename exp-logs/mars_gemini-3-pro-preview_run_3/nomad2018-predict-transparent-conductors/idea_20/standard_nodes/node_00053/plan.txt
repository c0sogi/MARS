Implementation of the `runfile.py` script.

This script orchestrates the full pipeline:
1.  **Data Loading**: Loads training, validation, and test datasets using the provided `library.data` module, leveraging cached parquet files for speed.
2.  **Preprocessing**: Removes the `id` column from feature matrices to prevent data leakage.
3.  **Training**: Trains a `DualTargetRegressor` (XGBoost) for both formation energy and bandgap energy.
4.  **Validation**: Computes the column-wise RMSLE on the validation set and prints it in the required format.
5.  **Failure Analysis**: Calculates correlations between prediction errors and input features to identify sources of error.
6.  **Submission**: Generates and saves predictions for the test set if the validation metric meets the specified threshold.
