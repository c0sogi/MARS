This script demonstrates the usage of the provided library components for the Question Answering task. It performs the following steps:
1.  **Configuration**: Overrides the default `Config` settings to enable `DEBUG` mode, reduce the number of epochs to 1, and limit the sample size for rapid execution.
2.  **Utility Verification**: Tests the `jaccard` scoring function and `split_sentences` logic with assertions.
3.  **Data Processing**: Demonstrates the `SparseRetriever` and uses `prepare_data` to load and process a small subset of the training, validation, and test data.
4.  **Model Initialization**: Instantiates the `QATokenClassifier` and verifies the forward pass (loss and logits shape) on a single batch.
5.  **Training & Inference**: Uses the `Trainer` class to run a single training epoch, evaluate on the validation set, and generate predictions for the test set.
6.  **Submission**: Saves the predictions to a CSV file, mimicking the final submission process.
