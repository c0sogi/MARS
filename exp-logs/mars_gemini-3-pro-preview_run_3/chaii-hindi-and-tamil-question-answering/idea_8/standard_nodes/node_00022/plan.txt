### Implementation Strategy

1.  **Initialization & Configuration**: We instantiate the `Config` class and set global random seeds to ensure reproducibility.
2.  **Task-Adaptive Pretraining (TAPT)**: We execute the TAPT engine to fine-tune the `xlm-roberta-base` model on the domain-specific corpus (concatenated train/val/test context). This adapts the embeddings to Hindi and Tamil.
3.  **QA Training**: We run the training pipeline, which trains three separate model instances (seeds 42, 43, 44) using the TAPT-initialized weights. This creates a robust ensemble.
4.  **Validation & Analysis**:
    *   We load the validation set and ground truth metadata.
    *   We generate predictions using the trained ensemble (applying majority voting).
    *   We calculate the exact Jaccard metric.
    *   We perform failure analysis by correlating the error magnitude with context and question lengths.
5.  **Submission**: We check if the validation metric exceeds the strict threshold of `0.3011529653320698`. If successful, we execute the inference pipeline on the test set to generate `submission.csv`.
