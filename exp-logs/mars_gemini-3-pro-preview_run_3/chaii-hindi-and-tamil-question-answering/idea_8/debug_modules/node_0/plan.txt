The implementation strategy involves creating a self-contained Python script that subclasses the provided `Config` class to create a `DemoConfig`. This configuration overrides default paths to use a temporary working directory (`./working/demo_run`) and reduces hyperparameters (epochs set to 1, batch size reduced, single seed) to ensure the code executes quickly within the time limit.

The script will first generate a small subset (20 samples) of the provided metadata files (`train.csv`, `val.csv`, `test.csv`) and store them in the demo directory. It will then sequentially execute the pipelines provided in the library:
1.  **Utility Verification**: Assert the correctness of the `jaccard` function.
2.  **TAPT Pipeline**: Run `run_tapt` to demonstrate domain adaptation on the subset corpus.
3.  **Training Pipeline**: Run `run_training` to demonstrate feature extraction and model training for Question Answering.
4.  **Inference Pipeline**: Run `run_inference` to generate predictions and a submission file.

Finally, the script verifies the existence and format of the output artifacts (model checkpoints and `submission.csv`) using assertions.
