Implementation Strategy:
1.  **Configuration & Setup**: Import the `Config` class and override specific hyperparameters (e.g., `EPOCHS`, `TAPT_EPOCHS`, `N_FOLDS`) to 1. This ensures the demonstration runs quickly (under a few minutes) while still executing the full pipeline. We also set the logging verbosity of the `transformers` library to error to keep the output clean.
2.  **Utility Verification**: Demonstrate and verify the `jaccard` metric and `clean_text` utility functions with assertions to ensure they behave as expected.
3.  **Data Processing & TAPT**: Execute the Task-Adaptive Pretraining (TAPT) pipeline. This involves generating the corpus from metadata and running the `run_tapt` function. We verify that the TAPT model is saved correctly.
4.  **QA Model Training**: Initialize the tokenizer and data loaders. We will simulate a single fold of training by retrieving the data loader for the first fold and the TAPT-finetuned model. We then execute `train_qa_fold` and verify that the best model checkpoint is saved.
5.  **Inference & Submission**: Run the full inference pipeline using `generate_submission`. This function loads the trained model(s), predicts on the test set, performs majority voting (trivial for 1 fold), and generates the submission CSV. We verify the structure and content of the final submission file.
