Implementation Strategy:
1.  **Setup & Configuration**: Import the `Config` class and monkey-patch its attributes (paths, epochs, batch sizes) to point to a temporary demo directory and use minimal hyperparameters (1 epoch, single seed) for speed.
2.  **Data Subsetting**: Create small subsets (top 20 rows) of the provided metadata CSVs (train, val, test) and save them to the demo directory. This ensures the training and inference steps complete almost instantly.
3.  **Component Verification**:
    *   **Utils**: Verify `set_seed` and `jaccard` metric logic.
    *   **Data**: Instantiate `QADataset` with the subset data, check item structure, and verify `qa_collate_fn` produces correct batch shapes.
    *   **Model**: Calculate class weights, instantiate `WeightedTokenClassifier`, and perform a forward pass (both with and without labels) to verify loss and logit generation.
    *   **TAPT Engine**: Execute `run_tapt` to demonstrate Task-Adaptive Pretraining on the text subset.
    *   **QA Engine**: Execute `run_training` to demonstrate the full fine-tuning loop on the subset, generating a model checkpoint.
    *   **Inference**: Execute `run_inference` using the trained checkpoint and test subset to generate a submission file, verifying the output format.
4.  **Assertions**: Use assertions throughout to validate that files are created, shapes are correct, and logic holds.
