This script demonstrates the end-to-end usage of the provided Hindi/Tamil Question Answering library. It performs the following steps:

1.  **Configuration Override**: Updates the global `Config` to use a temporary working directory and reduces hyperparameters (epochs, batch sizes) for rapid execution.
2.  **Data Subsampling**: Creates a tiny subset of the original metadata (train/val/test) to ensure the demonstration completes quickly (within minutes).
3.  **Utility Verification**: Validates the logic of helper functions like Jaccard similarity and BIO span decoding.
4.  **TAPT Execution**: Runs Task-Adaptive Pretraining on the subsampled corpus.
5.  **QA Data Preparation**: Tokenizes and processes the data into BIO-tagged features.
6.  **Model Training**: Fine-tunes the model on the QA task using the prepared data.
7.  **Inference**: Generates predictions on the test set and creates a submission file.
