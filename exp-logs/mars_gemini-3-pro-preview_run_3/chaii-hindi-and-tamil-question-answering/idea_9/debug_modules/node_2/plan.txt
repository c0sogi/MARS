When the loop index `i` reaches the padding region, accessing `sequence_ids[i]` fails. To fix this, I will constrain the loop execution to the length of the valid data by setting `seq_len` to the minimum of the `input_ids` length and `sequence_ids` length. This ensures the function stops processing before reaching the padding tokens, which are not part of the context or answer.
