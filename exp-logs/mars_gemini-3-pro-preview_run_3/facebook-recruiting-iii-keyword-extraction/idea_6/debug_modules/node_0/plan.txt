This script demonstrates the usage of the provided library modules (`config`, `utils`, `data`, `model`, `engine`) to perform a complete machine learning workflow for tag prediction.

The strategy involves:
1.  **Configuration Override**: Modifying the `config` module at runtime to point to temporary directories and use small hyperparameters (e.g., reduced vocabulary size, embedding dimension) for rapid execution.
2.  **Data Mocking**: Creating a synthetic, small-scale dataset (Raw CSVs and Metadata CSVs) within the working directory to simulate the input environment without processing the massive real dataset.
3.  **Component Verification**:
    *   **Utils**: Verifying text cleaning and metric calculation.
    *   **Data Processing**: Running the full `prepare_data` pipeline on the mock data to verify tokenization, tag encoding, and DataLoader creation.
    *   **Model**: Instantiating the `WideDeepTextCNN` and verifying the forward pass with dummy inputs.
    *   **Engine**: Running training, evaluation, and prediction loops for a single epoch to ensure the training logic holds.
4.  **Submission**: Generating a sample submission file using the trained model.
5.  **Cleanup**: Removing temporary artifacts.
