The `KeyError: 'Tags'` occurs because `pd.merge` encounters a `Tags` column in both `df_meta` (the metadata) and `df_raw` (the raw data). Since `Tags` is not included in the `on="Id"` parameter, Pandas automatically renames the colliding columns to `Tags_x` and `Tags_y`. Consequently, the resulting DataFrame does not have a column named `Tags`, causing the subsequent access to fail.

To fix this, I will modify `load_raw_data_split` in `library/data_processor.py` to check if `Tags` is already present in the metadata DataFrame. If it is, we will exclude `Tags` from the columns loaded from the raw CSV, thereby preventing the collision and preserving the `Tags` column from the metadata.
