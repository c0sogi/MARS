This script demonstrates the end-to-end usage of the provided machine learning library for the Stack Exchange tag prediction task.

### Implementation Strategy

1.  **Configuration Override**: We dynamically modify the `Config` class attributes to adapt the pipeline for a quick demonstration. This includes reducing the number of epochs, batch size, vocabulary size, and model dimensions (embedding size, filters) to ensure the script runs within a few minutes.
2.  **Data Loading Mock**: The original dataset is very large (130M+ rows). To demonstrate functionality without memory errors or long wait times, we use `unittest.mock` to intercept `pandas.read_csv` calls. We force the data loader to read only the first 2,000 rows of the raw data files from the `./input` directory, while allowing full reads of the metadata.
3.  **Component Validation**:
    *   **Utils**: We verify the `clean_text` function and `calculate_f1_score` metric with assertions.
    *   **Data Processing**: We execute `get_dataloaders` to verify the pipeline can tokenize text, build a vocabulary, and prepare PyTorch DataLoaders. We verify the shapes of the produced batches.
    *   **Model**: We instantiate the `TextCNN` model and perform a forward pass with dummy data to verify architecture correctness.
4.  **Training Loop**: We execute the `run_training` function, which handles training, validation, and inference. This proves the integration of all components.
5.  **Submission Check**: Finally, we verify that a submission file is generated in the expected location.
