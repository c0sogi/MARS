This script demonstrates the end-to-end usage of the provided library files to train a Neural Bag-of-Words (NBOW) model and generate predictions.

**Strategy:**
1.  **Configuration Override**: We modify the global `Config` class to use a temporary working directory (`./working/demo`) and reduce hyperparameters (epochs, batch size, vocab size) to ensure the script runs quickly (under 5 minutes) while still verifying the pipeline.
2.  **Data Loading**: We use `get_dataloaders` with `debug=True` to load a small subset of the data. We assert that the data shapes (tokens, offsets, labels) are correct.
3.  **Model Initialization**: We instantiate the `NBOWModel` using the vocabulary size and number of tags determined during data processing.
4.  **Training Loop**: We initialize the `Trainer` and run the `fit` method for 2 epochs. We verify that the training completes and returns a valid F1 score.
5.  **Inference**: We run prediction on the test set and generate a submission file. We validate the format of the output CSV.
6.  **Reproducibility**: We set a fixed random seed at the start.
