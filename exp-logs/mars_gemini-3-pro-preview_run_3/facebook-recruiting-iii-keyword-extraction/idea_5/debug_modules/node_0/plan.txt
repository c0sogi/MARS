This script demonstrates the end-to-end pipeline for the Stack Exchange Tag Prediction task using the provided library modules. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to run in a lightweight "Debug" mode (small sample size, fewer epochs, temporary directory) to ensure the script completes quickly.
2.  **Data Processing**: Verifies text cleaning utilities, builds a vocabulary from the small subset, and generates PyTorch DataLoaders.
3.  **Model Initialization**: Instantiates the `DualStreamTextCNN` model and verifies the forward pass with dummy data.
4.  **Training**: Runs a single epoch of training using the `Trainer` class to demonstrate the optimization loop and checkpoint saving.
5.  **Inference**: Loads the trained model, optimizes the decision threshold on the validation set, and generates a submission file for the test set.
6.  **Validation**: Includes assertions throughout to verify shapes, file outputs, and logic correctness.
