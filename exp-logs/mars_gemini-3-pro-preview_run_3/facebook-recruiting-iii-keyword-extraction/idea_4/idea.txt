# Solution Proposal: Hybrid CNN-Transformer Architecture

## Model
I propose a **Hybrid CNN-Transformer** architecture. This design bridges the gap between efficient local pattern matching and global context modeling.
*   **Embedding Layer**: The model starts with a learnable embedding layer to project integer token IDs into dense vectors.
*   **Local Feature Extraction (CNN)**: A 1D Convolutional layer (with `padding='same'`) processes the embeddings to capture local n-gram patterns (e.g., "visual studio", "runtime error"). This explicitly retains the parallel convolution strategy identified as highly effective for extracting technical keywords and phrases Cite solution_lesson_node_00006.
*   **Global Context Modeling (Transformer)**: Unlike the previous TextCNN which immediately collapsed the sequence via pooling, this model feeds the sequence of convolutional features into a **Shallow Transformer Encoder** (1-2 layers). This introduces a **Self-Attention** mechanism, allowing the model to learn long-range dependencies and interactions between the detected local phrases (e.g., relating a library name in the body to a language tag in the title) before aggregation.
*   **Aggregation & Output**: The output of the Transformer is aggregated using Global Average Pooling to form a document vector, which is then passed through a fully connected layer with a Sigmoid activation to predict the probability of each tag.

## Data
*   **Preprocessing**: Concatenate the `Title` and `Body` columns. Normalize text (lowercase, remove non-alphanumeric characters) and tokenize using a vocabulary of the top $N$ (e.g., 50,000) most frequent words.
*   **Sequence Standardization**: Pad or truncate all sequences to a fixed length (e.g., 300 tokens). This fixed-dimensional input is crucial for leveraging the GPU's parallel processing capabilities and maintaining the high throughput observed in previous experiments Cite solution_lesson_node_00006.
*   **Target Encoding**: Encode the top $K$ (e.g., 3,000) most frequent tags into binary multi-hot vectors.

## Training
*   **Loss Function**: Use **Binary Cross-Entropy with Logits Loss** (BCEWithLogitsLoss) for multi-label classification.
*   **Optimizer**: Use **AdamW** with a learning rate schedule that includes a warm-up phase followed by linear decay. This is essential for stabilizing the training of the Transformer layers.
*   **Efficiency Strategy**: Utilize Mixed Precision Training (AMP) on the NVIDIA A100 GPU. This will reduce memory consumption and computation time, allowing the heavier Hybrid model to train within the 24-hour limit while processing the large dataset.

## Evaluation
*   **Inference**: Process the test data into tokenized batches and pass them through the trained model to generate tag probabilities.
*   **Prediction**: Apply a threshold (tuned on the validation set F1-score) to the output probabilities to determine the final set of predicted tags.
*   **Formatting**: Map the predicted indices back to their string representations and join them with spaces for the submission file.
