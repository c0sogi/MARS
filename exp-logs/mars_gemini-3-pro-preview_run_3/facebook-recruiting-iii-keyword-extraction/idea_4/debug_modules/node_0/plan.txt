This script demonstrates the end-to-end usage of the provided machine learning library for the Stack Exchange tag prediction task.

### Strategy
1.  **Configuration Override**: We dynamically modify the global `library.config` settings to create a lightweight "demo" environment. This includes setting a small `DEBUG_SAMPLE_SIZE`, reducing model dimensions, and changing output directories to a temporary `./working/demo_pipeline` folder. This ensures the code runs quickly (within minutes) and doesn't interfere with main production files.
2.  **Component Verification**:
    *   **Utils**: We verify the F1-score calculation logic with deterministic numpy arrays.
    *   **Data Processing**: We instantiate `TextTokenizer` and `TagEncoder` separately to verify they fit and transform text/tags correctly.
    *   **Model Architecture**: We inspect the `HybridCNNTransformer` by passing a dummy tensor and asserting the output shape matches `(Batch_Size, Num_Classes)`.
3.  **Pipeline Execution**:
    *   **Training**: We execute `library.trainer.run_training`, which handles data loading, preprocessing, and the training loop. We assert that the model weights are saved successfully.
    *   **Inference**: We execute `library.inference.generate_submission`, which loads the saved model and generates predictions for the test set. We verify the submission file's format and content.
