The issue is caused by a breaking change in PyTorch 2.6+ (the environment uses 2.8.0), where `torch.load` defaults to `weights_only=True`. This security feature restricts unpickling to a specific allowlist of types. The checkpoint contains a NumPy scalar (`score`), which is not in the default allowlist, triggering a `_pickle.UnpicklingError`. As suggested by the error message, the targeted fix is to explicitly set `weights_only=False` in `torch.load` to allow loading the checkpoint containing the NumPy scalar.
