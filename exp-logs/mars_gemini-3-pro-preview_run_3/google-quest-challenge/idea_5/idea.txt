Based on the lessons learned from the previous experiments, particularly the failure of the "Early Fusion" ensemble due to the curse of dimensionality (Cite solution_lesson_node_00015) and the success of the Segment-Aware Cross-Encoder (Cite solution_lesson_node_00012), I propose the **Late-Fusion Ensemble of Segment-Aware Cross-Encoders**.

This strategy structurally evolves the solution by moving from a single feature space (concatenation) to independent predictive streams that are aggregated at the probability level. This avoids the "Curse of Dimensionality" while maximizing the diversity of the learned representations.

### Model
The architecture consists of two independent model streams that are combined only at the final prediction stage (Late Fusion).

1.  **Stream 1: MPNet Cross-Encoder**
    *   **Backbone:** `sentence-transformers/all-mpnet-base-v2`.
    *   **Architecture:** A Cross-Encoder processing the Question and Answer as a single sequence to leverage early interaction (Cite solution_lesson_node_00012).
    *   **Feature Extraction:** We extract a feature vector $X_{mpnet} = [h_{CLS}, h_{Q}, h_{A}, h_{diff}]$. Crucially, $h_{Q}$ (Question context) and $h_{A}$ (Answer context) are derived using **tokenizer-provided sequence masks** (via `sequence_ids()`) rather than heuristic splitting, ensuring noise-free pooling (Cite solution_lesson_node_00016).
    *   **Head:** A dedicated **Ridge Regression** model trained specifically on $X_{mpnet}$ (Cite solution_lesson_node_00004).

2.  **Stream 2: RoBERTa Cross-Encoder**
    *   **Backbone:** `roberta-base`.
    *   **Rationale:** Provides architectural and tokenizer diversity to complement MPNet.
    *   **Feature Extraction:** Identical segment-aware extraction strategy to produce $X_{roberta}$.
    *   **Head:** A separate **Ridge Regression** model trained specifically on $X_{roberta}$.

3.  **Aggregation:**
    *   The final prediction is the arithmetic mean of the probabilities output by the Stream 1 Ridge Head and the Stream 2 Ridge Head. This "Late Fusion" approach prevents the feature dimensionality from exceeding the sample size, solving the overfitting issue observed in Idea 4 (Cite solution_lesson_node_00015).

### Data
1.  **Input Formatting:**
    *   Concatenate text as `[CLS] Question_Title + Question_Body [SEP] Answer [SEP]` (adjusting for RoBERTa's `<s>` and `</s>` tokens).
    *   Tokenize with a maximum length of 512 tokens.
2.  **Mask Generation:**
    *   During tokenization, generate and store binary masks derived from `tokenizer.sequence_ids()` to explicitly identify tokens belonging to the Question segment versus the Answer segment. This is critical for the segment-aware pooling (Cite solution_lesson_node_00016).
3.  **Caching:**
    *   After fine-tuning the backbones, run inference on all data splits (Train, Val, Test) to generate and save the feature vectors ($X_{mpnet}$ and $X_{roberta}$) to disk. This decouples the heavy neural inference from the lightweight regression training (Cite solution_lesson_node_00003).

### Training
1.  **Stage 1: Independent Backbone Fine-Tuning**
    *   Train the MPNet and RoBERTa backbones independently on the training set using a temporary linear head.
    *   **Loss:** `BCEWithLogitsLoss`.
    *   **Stopping Criteria:** Monitor **Validation Loss**. Stop training immediately when the loss plateaus (likely around 3-5 epochs) to preserve the generalizability of the embeddings, even if the proxy metric continues to rise (Cite solution_lesson_node_00013).
    *   **Batch Size:** Use a physical batch size of 8 with minimal gradient accumulation (e.g., 1 step) to maximize the number of weight updates per epoch (Cite solution_lesson_node_00007).
    *   **Optimizer:** `AdamW` with a learning rate of 2e-5.

2.  **Stage 2: Independent Ridge Regression**
    *   Load the cached features for Stream 1 ($X_{mpnet}$). Train `RidgeCV` with Leave-One-Out Cross-Validation.
    *   Load the cached features for Stream 2 ($X_{roberta}$). Train a separate `RidgeCV` model.

### Evaluation
1.  **Inference:**
    *   Pass the test set through the fine-tuned MPNet to extract $X_{mpnet}$.
    *   Pass the test set through the fine-tuned RoBERTa to extract $X_{roberta}$.
2.  **Prediction:**
    *   Generate predictions $P_{mpnet}$ using the first Ridge model.
    *   Generate predictions $P_{roberta}$ using the second Ridge model.
3.  **Fusion:**
    *   Compute Final Predictions $P_{final} = 0.5 * P_{mpnet} + 0.5 * P_{roberta}$.
    *   Clip values to [0, 1] and format for submission.
