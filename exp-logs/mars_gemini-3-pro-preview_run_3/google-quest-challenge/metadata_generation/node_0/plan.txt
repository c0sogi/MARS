The following script generates metadata for the StackExchange question-answering task.

**Strategy:**
1.  **Setup & Loading:** The script defines the input and metadata directories. It reads `sample_submission.csv` to identify the 30 target columns (excluding `qa_id`). It then loads `train.csv` and `test.csv`.
2.  **Splitting (Group Sampling):** To prevent data leakage, the training data is split into training and validation sets using `GroupShuffleSplit` based on the `question_body` column. This ensures that all answers corresponding to the same question remain in the same split. The split ratio is fixed at 80:20 with `random_state=42`.
3.  **Metadata Generation:**
    *   The `train_metadata.csv` and `val_metadata.csv` files are created containing the features and ground-truth labels.
    *   The `test_metadata.csv` file is created from the test set.
    *   A column `original_file` is added to each metadata file pointing to the source CSV in `./input` (e.g., `train.csv` or `test.csv`). This allows us to perform the required file path verification.
4.  **Validation & Checks:**
    *   The script reloads the generated metadata to verify integrity.
    *   It prints summary statistics (row counts, column counts).
    *   It verifies the file paths in the `original_file` column relative to the `./input` directory.
    *   It programmatically asserts that the validation split respects the group constraint (no overlapping questions between train and val) and approximates the 80:20 ratio.
