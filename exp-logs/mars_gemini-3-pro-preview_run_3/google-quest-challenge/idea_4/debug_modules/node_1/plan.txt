The `ValueError` is caused by a shape mismatch between the meta-features (`X_meta_train`, 4394 rows) and the backbone features (`X_bb_train`, 4384 rows). This happens because the `train_loader` used for feature extraction is configured with `drop_last=True` (discarding the last 10 samples) and `shuffle=True` (randomizing the order). This violates data consistency across pipeline stages (Cite debug_lesson_3). To fix this, we must instantiate a dedicated `DataLoader` for inference on the training set with `shuffle=False` and `drop_last=False` to ensure all rows are extracted in the correct order.
