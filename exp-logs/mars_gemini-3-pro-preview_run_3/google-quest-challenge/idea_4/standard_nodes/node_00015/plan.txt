The implementation strategy involves the following steps:

1.  **Setup and Initialization**: Initialize the environment by setting random seeds for reproducibility and detecting the available computational device (GPU).
2.  **Meta-Feature Engineering**: Instantiate the `MetaFeatureEngineer` from the provided library to generate and cache structural features (e.g., text lengths, ratios) for the training, validation, and test sets.
3.  **Dual-Stream Backbone Processing**:
    *   **Stream 1 (MPNet)**: Invoke the `engine` module to fine-tune the MPNet backbone on the training data. Once trained, extract and cache the segment-aware embeddings for all data splits.
    *   **Stream 2 (RoBERTa)**: Repeat the process for the RoBERTa backbone to capture complementary semantic information.
4.  **Feature Fusion**: Load the processed target labels and concatenate the feature vectors from Stream 1, Stream 2, and the Meta-features to construct the final feature matrices ($X$ and $y$) for all splits.
5.  **Ensemble Training**: Train a Ridge Regression ensemble using the fused feature space on the training set and evaluate it on the validation set.
6.  **Validation and Failure Analysis**: Calculate the Spearman correlation metric on the validation set. Compute the correlation between the model's error magnitude and the input meta-features to identify systematic weaknesses.
7.  **Conditional Submission**: Compare the validation score against the required threshold. If the score is sufficient, generate predictions for the test set and save the final submission file.
