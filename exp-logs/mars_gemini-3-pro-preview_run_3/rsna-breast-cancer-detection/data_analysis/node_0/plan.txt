The following script performs a comprehensive Exploratory Data Analysis (EDA) on the training dataset. It handles the multi-modal nature of the data (tabular metadata and DICOM images) and adheres to all specified constraints, including runtime limits and read-only access.

**Implementation Strategy:**
1.  **Setup & Loading**: Sets random seeds for reproducibility and loads the training metadata from `./metadata/train_metadata.csv`.
2.  **Target Analysis**: Analyzes the `cancer` column to report class distribution and imbalance ratios.
3.  **Tabular Analysis**:
    *   **Numerical**: Computes statistics for `age`.
    *   **Categorical**: Analyzes cardinality and rare labels for columns like `site_id`, `view`, `laterality`, `density`, etc.
    *   **Missing Values**: Reports NaN counts.
4.  **Image Analysis**:
    *   Attempts to load a sample of DICOM images using `pydicom`.
    *   If `pydicom` is available, it reports dimensions (height, width, aspect ratio) and pixel intensity statistics.
    *   If `pydicom` is unavailable (as it's not in the strict package list), it falls back to analyzing file sizes as a proxy for signal complexity.
5.  **Feature Relationships**:
    *   **Correlation**: Computes correlations between numerical/encoded features and the target.
    *   **Feature Importance**: Trains a lightweight Random Forest model using only inference-time available features (excluding leakage columns like `biopsy` or `BIRADS`) to identify top predictors.
    *   **Meta-Analysis**: Investigates relationships between metadata (e.g., `age`, `density`) and the cancer target.
