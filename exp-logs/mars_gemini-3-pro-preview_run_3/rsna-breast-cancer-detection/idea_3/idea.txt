# Optimized Strategy: Analytically Calibrated EfficientNetV2 with ROI-Aware Preprocessing

This proposal outlines a streamlined yet mathematically robust strategy. It evolves the previous approaches by introducing **ROI-Aware Preprocessing** to maximize information density and replacing the complex two-stage training with **Analytical Prior Correction** to handle calibration.

### Model
*   **Architecture**: Use **EfficientNetV2-Small** as the backbone. This model is retained from Idea 2 due to its efficiency and ability to handle the fine-grained texture analysis required for mammography.
*   **Input Layer**: The model will accept single-view mammograms. Unlike the naive resizing in Idea 1, the effective resolution of the tissue will be significantly higher due to the preprocessing strategy described below.

### Data
*   **Structural Innovation: ROI-Aware Preprocessing**:
    *   **Cropping**: Mammograms often contain large regions of black background (voids) that contribute no information but consume pixel budget. Implement an automated **Region of Interest (ROI) Cropping** step: threshold the image to find the breast contour and crop the image to the bounding box of the tissue. This ensures that when the image is resized to the model input size (e.g., **640x640**), the breast tissue occupies the majority of the spatial dimensions, preserving critical micro-calcification details.
    *   **Normalization**: Apply **Percentile Normalization** (clipping to 1st/99th percentiles) to handle scanner artifacts, followed by scaling to [0, 1].
*   **Augmentation**: Apply spatial augmentations (flips, rotations) and intensity augmentations (random brightness/contrast) to the cropped ROI.

### Training
*   **Strategic Retention: Balanced Sampling**:
    *   Continue to use **Balanced Batch Sampling** (e.g., 50% positive, 50% negative) during training. This ensures the model receives sufficient gradient signal from the minority class to learn discriminative features, preventing the "all-negative" convergence trap. Cite {solution_lesson_node_00001}.
*   **Loss Function**: Use **Binary Cross-Entropy (BCE) with Logits**.
*   **Optimization**: Use the AdamW optimizer with a cosine annealing learning rate schedule to ensure stable convergence.

### Evaluation
*   **Structural Innovation: Analytical Prior Correction**:
    *   Instead of the two-stage retraining proposed in Idea 2, apply a direct mathematical correction to the model's output logits to fix the calibration distortion caused by balanced sampling.
    *   **Mechanism**: The model learns a biased prior of $P_{train} \approx 0.5$. The test set has a natural prior of $P_{test} \approx 0.02$. At inference time, adjust the predicted logits ($L_{pred}$) using the log-odds ratio:
        $$ L_{corrected} = L_{pred} - \log\left(\frac{P_{train}}{1 - P_{train}}\right) + \log\left(\frac{P_{test}}{1 - P_{test}}\right) $$
    *   Since $P_{train}=0.5$, the correction simplifies to adding the constant $\log(\frac{0.02}{0.98})$ to the logits before applying the sigmoid function. This guarantees that the output probabilities are calibrated to the natural prevalence without requiring a second training stage. Cite {solution_lesson_node_00001}.
*   **Aggregation**:
    *   Apply the sigmoid activation to the corrected logits to obtain calibrated probabilities.
    *   Group predictions by `prediction_id` and use **Max Pooling** to determine the final cancer likelihood for the breast, maintaining the clinical logic that a detection in any view implies risk.
