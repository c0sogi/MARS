# Optimized Strategy: Multi-View Attention MIL with Analytical Calibration

This proposal introduces a structural innovation by shifting from Single Instance Learning (SIL) to **Multiple Instance Learning (MIL)** with Attention. It synthesizes the successful ROI preprocessing and analytical calibration from previous ideas while addressing the limitations of independent image processing.

### Model
*   **Backbone Architecture**: Utilize **EfficientNetV2-Small** as the feature extractor. This backbone is retained for its balance of speed and parameter efficiency in capturing fine-grained tissue textures.
*   **Structural Innovation: Gated Attention MIL Head**:
    *   Instead of classifying each image independently, the model will process a **"bag" of images** corresponding to a specific breast (grouping the CC and MLO views together).
    *   **Feature Extraction**: Each image in the bag is passed through the backbone to generate a feature embedding.
    *   **Attention Mechanism**: A trainable Gated Attention layer processes these embeddings to assign an "attention score" to each view. This allows the model to dynamically focus on the view that best reveals the pathology (e.g., a mass visible in MLO but obscured in CC) while ignoring non-informative views.
    *   **Aggregation**: The embeddings are aggregated via a weighted sum (based on attention scores) into a single "breast context vector," which is then passed to the final classification layer.

### Data
*   **Preprocessing**:
    *   **ROI-Aware Cropping**: Retain the automated cropping strategy to remove background voids and center the breast tissue. This maximizes the signal-to-noise ratio and effective resolution.
    *   **Bag Construction**: Group the training and test data by `patient_id` and `laterality`. Each input sample is now a set of tensors representing all available views for that breast.
*   **Augmentation**: Apply consistent geometric (flips, rotations) and intensity augmentations to the individual images within the bag to improve robustness.

### Training
*   **Strategic Retention: Balanced Bag Sampling**:
    *   Implement **Balanced Batch Sampling** at the *bag level*. Construct training batches such that 50% of the bags are positive (cancer) and 50% are negative. This ensures the model receives a strong gradient signal for the minority class, which is critical for feature learning in this highly imbalanced dataset. Cite {solution_lesson_node_00001}.
*   **Optimization**: Train end-to-end using **Binary Cross-Entropy (BCE) with Logits** loss. The optimizer will update both the backbone and the attention mechanism simultaneously.

### Evaluation
*   **Structural Innovation: Analytical Prior Correction**:
    *   Since the model is trained on a balanced distribution ($P_{train} = 0.5$) but evaluated on the natural distribution ($P_{test} \approx 0.02$), the raw output probabilities will be systematically inflated.
    *   Instead of retraining a separate calibration head, apply a mathematical correction to the final **logits** before the sigmoid activation:
        $$ L_{corrected} = L_{pred} - \log\left(\frac{0.5}{1 - 0.5}\right) + \log\left(\frac{0.02}{1 - 0.02}\right) $$
    *   This adjustment shifts the decision boundary to align with the true prevalence, ensuring the **Probabilistic F1 (pF1)** score is maximized by providing calibrated probabilities. Cite {solution_lesson_node_00001}.
*   **Inference**: Generate a single probability score for the breast (bag) and assign this score to all `prediction_id` entries associated with that breast (e.g., `10006_L`).
