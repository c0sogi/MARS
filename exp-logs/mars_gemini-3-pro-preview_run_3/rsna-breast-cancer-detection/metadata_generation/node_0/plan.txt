The implementation strategy involves the following steps:

1.  **Setup and Directory Management**: Define the input directory (`./input`) and output directory (`./metadata`). Ensure the output directory exists.
2.  **Data Loading and Path Construction**:
    *   Load `train.csv` and `test.csv` using pandas.
    *   Construct the relative file paths for images by combining the directory prefix (`train_images` or `test_images`), `patient_id`, and `image_id` with the `.dcm` extension.
3.  **Stratified Group Splitting**:
    *   To prevent data leakage, the split must be performed at the `patient_id` level.
    *   Group the training data by `patient_id` and determine the target label for each patient (taking the maximum `cancer` value, as a patient is positive if any image is positive).
    *   Use `train_test_split` on the unique patient IDs with a fixed random state (42) and a test size of 0.2 (20%), stratifying by the patient-level labels.
    *   Filter the original training data into training and validation sets based on the selected patient IDs.
4.  **Saving Metadata**: Save the processed DataFrames (with the new `file_path` column) to the `./metadata` directory as CSV files.
5.  **Verification and Quality Checks**:
    *   **Statistics**: Print counts, class distributions, and unique patient counts for all sets.
    *   **File Existence**: Randomly sample 1,000 file paths from each generated metadata file and verify their existence in the `./input` directory. If more than 50% are missing, raise an error.
    *   **Split Integrity**: Programmatically verify that there is no overlap of `patient_id` between train and validation sets and that the split ratio is approximately correct.
