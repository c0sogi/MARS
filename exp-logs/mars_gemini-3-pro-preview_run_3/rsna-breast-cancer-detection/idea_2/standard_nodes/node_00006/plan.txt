The previous implementation caused a `torch.OutOfMemoryError` because the batch sizes were configured for a 40GB A100 GPU, whereas the runtime environment provided a GPU with approximately 16GB of VRAM. The large batch size of 32 for 512x512 images during full training (Stage 1) exceeded the available memory. I will fix this by reducing `STAGE1_BATCH_SIZE` to 8 and `STAGE2_BATCH_SIZE` to 32 in `library/config.py` to ensure the model fits within the 16GB VRAM limit.
