The implementation strategy is as follows:

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility using `seed_everything`.
2.  **Data Loading**: Use `get_dataloaders` to retrieve the training, validation, and test data loaders.
3.  **Training**: Instantiate the `Trainer` class. Execute the training loop using `trainer.fit()`. To ensure the "fast baseline" requirement is met, we will limit the number of epochs to 5 and the number of batches per epoch to 150. This ensures the training completes well within the time limit while seeing a representative variety of data.
4.  **Validation & Metric Calculation**:
    *   Load the best model weights saved during training.
    *   Perform inference on the full validation set in evaluation mode (`model.eval()`) with gradient calculation disabled (`torch.no_grad()`).
    *   Calculate the **Probabilistic F1 Score (pF1)** using the definitions provided in the task description.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample (`|y_true - y_pred|`).
    *   Load the validation metadata.
    *   Map categorical features (e.g., 'density', 'view') to numeric values.
    *   Compute and print the Pearson correlation between the error magnitude and input features to identify sources of systematic error.
6.  **Submission**: Call `run_inference()` to generate predictions for the test set and save the `submission.csv`. This function automatically handles loading the best model and formatting the output.
