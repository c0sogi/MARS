# Baseline Approach: Naive MIL with ResNet-18 and Max-Pooling

This proposal outlines a highly efficient baseline designed to establish a robust performance floor. It prioritizes speed and simplicity, using a lightweight architecture and standard training techniques to handle the large class imbalance and probabilistic metric.

### Model
The core architecture is a standard **ResNet-18**.
*   **Design**: This model is significantly lighter and faster to train than the EfficientNetV2 (Model 1) or Swin Transformer (Model 2) variants. It replaces the final fully connected layer with a single output neuron followed by a sigmoid activation function.
*   **Naive MIL Approach**: The model treats every mammogram image as an independent instance. It does not explicitly model the relationship between different views (CC vs. MLO) or use attention mechanisms (distinct from Models 2 and 3). This independence allows for massive parallelization and simplified data loading.

### Data
*   **Preprocessing**:
    *   **Loading**: Use a DICOM reader compatible with JPEG 2000 (e.g., `pydicom` with appropriate plugins) to load image data.
    *   **Resizing**: Resize all images to a fixed resolution of **512x512**. This is a "sweet spot" resolution that preserves sufficient detail for mass detection while ensuring low GPU memory footprint and fast training iterations.
    *   **Normalization**: Normalize pixel values to the [0, 1] range.
*   **Augmentation**: Apply only lightweight geometric augmentations: random horizontal flips and small rotations (±10 degrees). This avoids the compute overhead of heavy augmentations while preventing basic overfitting.

### Training
*   **Labeling Strategy**: Propagate the patient/breast-level label to all associated images. If a breast is labeled "cancer," all its images (CC, MLO, etc.) are labeled as positive. This is a "noisy label" assumption but works effectively as a baseline.
*   **Imbalance Handling**: Implement **Balanced Batch Sampling**. Instead of modifying the loss function (as in Model 1), construct each training batch to contain a fixed ratio of positive to negative samples (e.g., 1:1 or 1:3). This ensures the model constantly learns from the minority class (2% prevalence) without the instability sometimes caused by high loss weights.
*   **Loss Function**: Use standard **Binary Cross-Entropy (BCE)**. This is the canonical loss for probability estimation and will encourage the model to output calibrated probabilities, which are essential for the pF1 metric.
*   **Optimizer**: Use AdamW with a default learning rate (e.g., 1e-4) and a simple learning rate decay (StepLR) to ensure convergence within the 24-hour limit.

### Evaluation
*   **Inference**: Run the trained ResNet-18 on all images in the test set to generate a probability score for each image.
*   **Aggregation (Max Pooling)**: To generate the final prediction for a `prediction_id` (which represents a specific breast), take the **maximum** probability among all images associated with that ID.
    *   *Rationale*: This differs from the Mean Pooling in Model 1. It aligns with the clinical logic that if a sign of cancer is detected in *any* single view (even if hidden in others), the diagnosis should be positive. This approach is generally more sensitive for detection tasks.
