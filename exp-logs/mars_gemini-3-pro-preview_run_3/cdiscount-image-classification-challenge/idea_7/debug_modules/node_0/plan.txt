The following Python script demonstrates the end-to-end workflow for the product categorization task using the provided library files.

### Implementation Strategy
1.  **Environment Setup**: The script first imports necessary modules and overrides the `WORKING_DIR` variable in the library modules (`config`, `dataset`, `data_utils`). This ensures that all intermediate files (caches, features, models) are written to a dedicated `./working/demo_execution` directory, preventing interference with any existing training artifacts.
2.  **Data Subsetting**: To ensure the demonstration runs quickly (under 2 minutes), the script loads the pre-generated metadata files from `./metadata`, samples a tiny subset (100 training, 50 validation, 50 test records), and saves these "mini" metadata files to the working directory.
3.  **Feature Extraction**: It initializes the `EfficientNet-B0` model and utilizes the `_process_split` function from `library.feature_extractor` to extract 1280-dimensional embeddings for the mini datasets. This verifies the BSON image loading and preprocessing pipeline.
4.  **Model Training**: The script instantiates the `Trainer` class from `library.trainer` pointing to the generated mini-features. It runs the training loop for 2 epochs with a small batch size. Assertions confirm that the model checkpoint is successfully saved.
5.  **Inference**: Finally, the script uses `trainer.predict()` to generate predictions for the mini test set. It validates the output submission file for correct dimensions, column names, and data types.
