Implementation strategy:
1.  **Setup & Configuration**: Import necessary libraries and the provided helper modules. Set random seeds for reproducibility. Create the required output directory (`./submission`).
2.  **Feature Extraction (Subsets)**: To ensure the "Fast Baseline" runs within the time limit, I will extract features for a subset of the training (100,000 samples) and validation (20,000 samples) data using the `extract_and_aggregate` function. I will use the pre-trained ResNet-50 backbone and Dual-Statistic Pooling as defined in the library.
3.  **Model Training**: Train the `DualStatClassifier` (MLP) on the extracted training subset using `train_model`. The model will be saved to the working directory.
4.  **Validation & Metric Calculation**: Reload the best saved model and perform inference on the validation subset. Calculate the categorization accuracy and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Calculate the per-sample Cross-Entropy loss on the validation set. Compute the L2 norm of the input feature vectors (as a summary of "input features"). Calculate and print the Pearson correlation between the loss (error magnitude) and the feature norms to identify if signal strength correlates with error.
6.  **Submission Generation**: Check if the validation accuracy exceeds the threshold (0.50636). If so, extract features for the **entire** test set (utilizing the GPU acceleration) and generate the submission file. Finally, move the submission file to the specified location `./submission/submission.csv`.
