The issue is that the `best_val_acc` variable in `train_model` is initialized to `0.0`. During the demo run, the validation accuracy was exactly `0.0` (due to the tiny dataset), causing the condition `if val_acc > best_val_acc` to evaluate to `False` (since `0.0 > 0.0` is False). Consequently, the model checkpoint was never saved, causing the `AssertionError` in the subsequent step.

To fix this, I will initialize `best_val_acc` to `-1.0`. This ensures that the first epoch's accuracy (even if it is `0.0`) will trigger the save condition (`0.0 > -1.0`), guaranteeing that a model file is created. Cite debug_lesson_1.
