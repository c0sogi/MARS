The implementation strategy follows the **Decoupled EfficientNet-B0 with Feature-Space MixUp** architecture.

1.  **Metadata Generation**: We first ensure that metadata mapping product IDs to BSON byte offsets is generated for train, validation, and test sets using `library.metadata.generate_metadata`.
2.  **Feature Extraction**: We utilize `library.feature_extractor.run_feature_extraction` to process the raw BSON images. This uses a frozen **EfficientNet-B0** backbone to extract 1280-dimensional feature vectors for all products. The results are cached as `.npy` files to allow for rapid iteration and to fit within the runtime limits. We use the full dataset (`debug=False`) to maximize model performance.
3.  **Ensemble Training**: We invoke `library.training.train_ensemble` to train 5 independent MLP classifiers on the cached features. The training process incorporates **MixUp regularization** to improve generalization on the feature embeddings.
4.  **Validation & Analysis**: We perform inference on the hold-out validation set using the ensemble. We calculate the Categorization Accuracy and perform failure analysis by correlating prediction errors with the L2 norm of the feature vectors (a proxy for signal strength/complexity).
5.  **Submission**: If the validation accuracy exceeds the threshold of 0.50636, we generate predictions for the test set, decode the category IDs using the `CategoryEncoder`, and save the result to `./submission/submission.csv`.
