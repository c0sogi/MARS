# Baseline Proposal: Frozen ResNet-18 with Feature Averaging and MLP

### Model
The proposed solution is a **Two-Stage Feature Aggregation** network designed to decouple image processing from classification, maximizing throughput.
*   **Frozen Backbone:** Utilize a **ResNet-18** architecture pre-trained on ImageNet. The network's weights will be **frozen** (untrained), serving strictly as a static feature extractor. This removes the computational cost of calculating gradients for millions of convolutional parameters.
*   **Feature Aggregation:** Unlike previous ideas that average predictions (logits), this model averages **embeddings**. For a product with multiple images, the 512-dimensional feature vectors extracted from the backbone for each image are averaged element-wise. This results in a single, noise-reduced "Product Embedding" that represents the holistic visual information of the item.
*   **Classifier:** A lightweight **Multi-Layer Perceptron (MLP)** serves as the trainable component. It takes the 512-dimensional product embedding as input and projects it to the 5270 target categories.

### Data
*   **Preprocessing:** Images are decoded, resized to 224x224, and normalized using standard ImageNet mean and standard deviation.
*   **RAM-Resident Dataset:** Leverage the available 220 GB RAM to create an in-memory dataset.
    1.  Perform a **single forward pass** over the entire training set using the frozen backbone.
    2.  Extract the feature vector for every image.
    3.  Group features by `product_id`, compute the mean vector for each product, and store the resulting matrix (Shape: `[N_products, 512]`) in RAM.
*   **Benefit:** This step completely eliminates the bottleneck of reading BSON files and decoding JPEGs during the actual training phase, converting the problem from an image classification task to a high-speed tabular classification task.

### Training
*   **Procedure:** Train the MLP classifier on the pre-computed, in-memory product embeddings.
*   **Optimization:** Use the **Adam** optimizer with **Cross-Entropy Loss**.
*   **Throughput:** Because the input data is low-dimensional (512 floats) and resident in memory, use a very large batch size (e.g., 4096 or 8192). This allows the MLP to converge in seconds or minutes, rather than the hours required for end-to-end CNN training.

### Evaluation
*   **Inference Pipeline:** Iterate through the test BSON file. For each batch of images:
    1.  Pass them through the frozen ResNet-18 to obtain features.
    2.  Aggregate features by `product_id` (mean pooling).
    3.  Pass the aggregated feature vector through the trained MLP to generate class scores.
*   **Prediction:** Select the category ID corresponding to the highest score in the final output vector.
