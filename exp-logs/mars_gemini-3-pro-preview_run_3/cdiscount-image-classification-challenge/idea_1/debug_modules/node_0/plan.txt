5.  **Training Pipeline Execution**:
    *   Invoke `engine.train_model` to run a complete training loop for a single epoch.
    *   This demonstrates the integration of the loss function (with class weights), optimizer, and early stopping logic provided in the library.
6.  **Inference & Submission**:
    *   Execute `engine.generate_predictions` using the trained model and the test data loader.
    *   Verify that the submission file is generated correctly and adheres to the expected format.
