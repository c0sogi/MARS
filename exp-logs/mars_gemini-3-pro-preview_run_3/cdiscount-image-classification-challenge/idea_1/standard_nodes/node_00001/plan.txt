The implementation strategy focuses on creating a fast but complete baseline that satisfies all task requirements within the time limit.

1.  **Setup & Imports**: We import the necessary pre-defined classes and functions from the `library` package to avoid code duplication.
2.  **Data Subsampling**: To ensure the training phase completes quickly (allowing sufficient time for the computationally expensive inference on the large test set), we sample a subset of 50,000 records from the training metadata. This is saved to a temporary CSV in the working directory.
3.  **Model Training**: We initialize the `MobileNetV2Classifier` and train it for a single epoch on the subsampled data using the provided `train_model` engine. This establishes a functional baseline.
4.  **Validation & Metrics**: We perform a full evaluation on the validation set. We explicitly calculate and print the `Final Validation Metric` as required.
5.  **Failure Analysis**: We extract the `bson_length` feature from the validation metadata and correlate it with the model's prediction errors (Correct/Incorrect). This helps identify if file size (a proxy for image complexity or quantity) relates to model performance.
6.  **Submission**: We utilize the `generate_predictions` function to process the test set. Since the test dataset returns a variable number of images per product (returned as a stack), we use a batch size of 1. The model averages logits across all images of a product to make a final prediction.
