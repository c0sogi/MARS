This script demonstrates the full pipeline for the hierarchical product categorization task using the provided library files. It validates the functionality of the data loaders, feature extractors, model architecture, and training loop using a small subset of data to ensure rapid execution.

The strategy is as follows:
1.  **Configuration**: Override default `Config` settings to use a temporary working directory, a small subset size (50 samples), and minimal training epochs (2) for speed.
2.  **Data Loading & Hierarchy**: Verify `HierarchyMapper` correctly processes category levels and `BSONLoader` correctly reads raw images from the BSON file.
3.  **Feature Extraction**: Execute the `extract_and_save_features` pipeline on the small subset. This demonstrates the integration of the `DualBackbone` (ResNet+EfficientNet) and the `RawImageDataset`.
4.  **Dataset Creation**: Instantiate `FeatureDataset` using the extracted features to verify memory mapping and label processing.
5.  **Training Loop**: Initialize the `Trainer` and `HierarchicalMLP`, then run a short training session (`fit`) to verify the optimization step, loss calculation (including MixUp), and checkpointing.
6.  **Inference**: Run the `generate_submission` function to produce a submission file from the trained model, validating the end-to-end flow.
