# Baseline Proposal: Full-Scale Dual-Backbone with Conditional Hierarchical Cascading

### Model
I propose a **Dual-Backbone Conditional Network** that leverages feature diversity and explicit hierarchical dependencies to improve fine-grained classification.
*   **Dual Frozen Backbones:** The model will utilize two distinct pre-trained backbones in parallel to extract complementary visual features:
    1.  **ResNet-50:** Captures robust texture and shape representations (2048 dimensions).
    2.  **EfficientNet-B0:** Captures efficient, multi-scale features (1280 dimensions).
    *   *Rationale:* Combining architectures with different inductive biases provides a richer representation than scaling a single backbone. Both will be **frozen** to maintain the computational efficiency established in **Cite solution_lesson_node_00003**.
*   **Aggregation:** Apply **Mean Pooling** independently to the image features of each product from both backbones, then **concatenate** them to form a single **3328-dimensional** product embedding.
*   **Cascading Hierarchical Classifier:** Unlike previous parallel multi-task proposals, I will implement a **Conditional Cascading MLP** that explicitly models the taxonomy ($P(Level3 | Level2, Features)$):
    *   **Stage 1 (Level 1):** An MLP takes the product embedding and predicts the 49 coarse categories.
    *   **Stage 2 (Level 2):** An MLP takes the **concatenation** of the product embedding and the *Stage 1 logits* to predict the 483 sub-categories.
    *   **Stage 3 (Level 3 - Target):** An MLP takes the **concatenation** of the product embedding and the *Stage 2 logits* to predict the 5270 fine-grained categories.
    *   *Innovation:* This structure forces the model to refine its predictions sequentially, using the coarse category prediction as a strong prior feature for the fine-grained decision.

### Data
*   **Full-Dataset Decoupled Caching:** I will apply the decoupled feature extraction strategy to the **entire training dataset (~7 million products)** and the test set.
    *   *Strategic Retention:* This preserves the extreme speed of the decoupled approach (**Cite solution_lesson_node_00003**).
    *   *Correction:* Processing the full dataset is the direct remedy for the overfitting observed in **Cite solution_lesson_node_00005**. With 7 million samples, the model can effectively support the high dimensionality (3328-dim) of the fused embeddings, avoiding the "curse of dimensionality" that caused failure on the 100k subset.
    *   *Feasibility:* The estimated memory footprint for the fused features is ~118 GB, fitting comfortably within the 220 GB available RAM.
*   **Label Engineering:** Map `category_id` to Level 1 and Level 2 parents to create the targets for the cascading stages.

### Training
*   **Feature-Space MixUp:** To compensate for the frozen backbones, I will apply **MixUp** directly to the cached feature vectors during training. This interpolates between samples to enforce linear decision boundaries and improve generalization on the tabular data.
*   **Loss Function:** Use a **Sum of Cross-Entropy Losses** from all three stages ($L_{total} = L_{L3} + L_{L2} + L_{L1}$).
    *   *Correction:* I will explicitly **exclude** inverse-frequency class weights. As demonstrated in **Cite solution_lesson_node_00004**, class weighting optimizes for macro-recall and degrades the target metric (global accuracy). The cascading structure naturally handles class imbalance by leveraging the more balanced high-level categories to guide the lower levels.
*   **Optimizer:** Use **AdamW** with Weight Decay.

### Evaluation
*   **Inference Pipeline:**
    1.  Load pre-computed test set features (extracted via both backbones and fused).
    2.  Pass the fused features through the Cascading Network.
    3.  Select the category with the highest probability from the **Stage 3 (Level 3)** output as the final prediction.
