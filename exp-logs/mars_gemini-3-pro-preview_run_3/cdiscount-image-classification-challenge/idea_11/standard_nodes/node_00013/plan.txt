Implementation Strategy:
1.  **Environment Setup**: Import necessary modules and set random seeds for reproducibility.
2.  **Data Preparation**: 
    -   Load the full training metadata.
    -   Create a **training subset** (200,000 samples) to ensure the training phase completes quickly (Fast Baseline).
    -   Use the **full validation set** and **full test set** metadata to meet the requirements for accurate metric reporting and submission.
3.  **Feature Extraction**:
    -   Instantiate the `DualBackbone` model (ResNet50 + EfficientNet-B0) on the GPU.
    -   Iterate through the Train Subset, Full Validation, and Full Test datasets.
    -   Extract features using `ProductDataset` and `DataLoader` to handle BSON I/O efficiently.
    -   Save the extracted features (`.npy` files) to the working directory.
4.  **Model Training**:
    -   Initialize the `HierarchyManager` and `Trainer`.
    -   Create `DataLoaders` using the pre-computed feature files.
    -   Train the `ConditionalCascadeMLP` on the training subset for a limited number of epochs (10) to ensure convergence within the time limit.
5.  **Validation & Analysis**:
    -   Evaluate the trained model on the **entire** validation set.
    -   Print the required "Final Validation Metric".
    -   Perform failure analysis by calculating the correlation between prediction errors and feature vector norms.
6.  **Submission**:
    -   Check if the validation accuracy exceeds the threshold (0.6239621493939094).
    -   If successful, generate predictions for the full test set and save `submission.csv`.
