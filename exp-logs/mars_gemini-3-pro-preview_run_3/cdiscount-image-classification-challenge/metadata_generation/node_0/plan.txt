Implementation Strategy:
1.  **BSON Parsing**: Since the dataset consists of large BSON files (58GB) and the `bson` module is not guaranteed to be available or efficient enough for a pure metadata scan, I will implement a custom, lightweight BSON scanner using the `struct` module. This scanner will iterate through the file sequentially, reading the document size, and then parsing the document body to extract `_id` and `category_id`. It will skip the heavy `imgs` array field efficiently by reading its size and advancing the pointer, or by stopping the parse once the necessary metadata fields are found. This avoids decoding the image data, significantly speeding up the process.
2.  **Metadata Extraction**: I will process `train.bson` to extract `_id`, `category_id`, `bson_offset`, and `bson_length`. Similarly, I will process `test.bson` to extract `_id` (and other file info), noting that `category_id` is absent.
3.  **Data Splitting**: I will load the extracted training metadata into a pandas DataFrame. I will perform a stratified split (80% train, 20% validation) based on `category_id`. I will handle rare categories (with fewer than 2 samples) by forcing them into the training set to prevent errors during stratification.
4.  **Output Generation**: I will save the resulting DataFrames as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory. The file paths in these CSVs will be relative to `./input` (e.g., `train.bson`).
5.  **Validation**: I will implement the required checks:
    -   Print summary statistics (shapes, class distributions).
    -   Verify that 1000 random file paths from the metadata resolve correctly (checking `./input/train.bson` etc.).
    -   Assert that the validation split respects the stratification requirement.
