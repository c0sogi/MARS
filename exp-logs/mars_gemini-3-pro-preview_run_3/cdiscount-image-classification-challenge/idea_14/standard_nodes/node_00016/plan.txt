Implementation strategy:
1.  **Configuration Patching**: I will dynamically modify the `Config` class attributes to adapt the workflow for a "Fast Baseline". Specifically, I will set `DEBUG_SAMPLE_SIZE` to 200,000 to ensure we have enough data for a meaningful result while keeping runtime short. I will also adjust batch sizes and epoch counts to optimize for the A100 GPU.
2.  **Feature Extraction**: I will invoke `extract_features` for the training and validation sets with `debug=True` (using the 200k subset). Crucially, for the test set, I will use `debug=False` to ensure features are extracted for the entire test dataset (approx 706k records), which is required to generate a valid submission file matching the sample submission.
3.  **Ensemble Training**: I will train an ensemble of 3 `ConditionalCascadeMLP` models on the extracted training features. This leverages the diversity of initialization to improve robustness.
4.  **Validation & Analysis**: I will perform inference on the validation subset using the ensemble. I will calculate the final accuracy metric and perform failure analysis by correlating class prediction accuracy with class frequency in the training set.
5.  **Submission**: If the validation accuracy exceeds the specified threshold (0.6239...), I will run the ensemble inference on the full test set features and generate the `submission.csv`.
