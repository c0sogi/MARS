Implementation strategy:
1.  **Environment Setup**: Initialize random seeds for reproducibility and configure the device (GPU).
2.  **Data Subsampling**: To comply with the 2-hour time limit, create subsets of the training (500,000 samples) and validation (50,000 samples) metadata. This ensures the computationally expensive feature extraction and training phases complete quickly while providing sufficient data for a robust baseline.
3.  **Feature Extraction**: Use the `extract_dataset_features` function from `library.feature_engine` to process the images through the frozen ResNet-50 backbone. This caches the 2048-dimensional feature vectors to disk/RAM.
4.  **Training**: Initialize the `AttentionClassifier` and train it for 5 epochs using the `run_training` utility. Use class weights to handle imbalance.
5.  **Validation & Analysis**: Evaluate the trained model on the validation subset. Compute the "Final Validation Metric" (Accuracy) and perform failure analysis by calculating the correlation between prediction errors and the number of product images.
6.  **Submission**: If the validation metric exceeds the threshold (0.50636), perform feature extraction on the *entire* test set and generate the `submission.csv` file using the trained model.
