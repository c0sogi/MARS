This script demonstrates the end-to-end usage of the provided library files to solve the product categorization task. It performs the following steps:

1.  **Environment Setup**: Initializes seeds and creates a temporary working directory.
2.  **Data Subsetting**: Creates small subsets (50 train, 20 val, 20 test) of the metadata to ensure the demo runs quickly.
3.  **Utility Verification**: Validates the BSON reading logic by extracting images for a sample product.
4.  **Feature Extraction**: Uses the ResNet50 backbone (via `feature_engine.py`) to extract and cache features for the subsets.
5.  **Dataset Preparation**: Loads the cached features into `CachedFeatureDataset` and maps raw category IDs to model-compatible indices.
6.  **Model Training**: Trains the `AttentionClassifier` for 2 epochs using the `run_training` utility.
7.  **Inference & Submission**: Generates predictions for the test subset and saves them in the correct submission format.
