# Baseline Proposal: Full-Scale Dual-Backbone with Deep Feature Cascading (DFC)

### Model
I propose a **Deep Feature Cascading (DFC)** network designed to maximize information flow from coarse-grained concepts to fine-grained predictions.

*   **Dual Frozen Backbones:** The model will utilize two distinct pre-trained backbones in parallel to extract complementary visual features.
    1.  **ResNet-50:** Captures robust texture and shape representations (2048 dimensions).
    2.  **EfficientNet-B0:** Captures efficient, multi-scale features (1280 dimensions).
    *   *Strategic Retention:* Both backbones will be **frozen** to ensure the pipeline remains I/O bound rather than compute-bound (**Cite solution_lesson_node_00003**).
*   **Fused Aggregation:** For every product, features will be extracted for all associated images. I will apply **Mean Pooling** independently to the ResNet and EfficientNet features, then **concatenate** the results to form a single **3328-dimensional** product embedding.
    *   *Feasibility:* Storing these embeddings for the full 7 million product dataset requires ~93 GB of RAM, fitting comfortably within the 220 GB limit.
*   **Deep Feature Cascading Architecture:** Instead of parallel heads (Idea 5) or passing logits (Idea 14), this architecture passes **dense hidden representations** sequentially through the hierarchy.
    *   **Block 1 (Level 1):** Takes the 3328-dim product embedding. Contains a wide hidden layer (e.g., 1024 units). Outputs the Level 1 prediction (49 classes) AND forwards the **1024-dim hidden state**.
    *   **Block 2 (Level 2):** Takes the **concatenation** of the original product embedding and the **Block 1 hidden state**. Outputs the Level 2 prediction (483 classes) AND forwards its own **1024-dim hidden state**.
    *   **Block 3 (Level 3 - Target):** Takes the **concatenation** of the original product embedding and the **Block 2 hidden state**. Outputs the final Level 3 prediction (5270 classes).
    *   *Structural Innovation:* By passing dense hidden states rather than compressed logits, the model transfers rich, high-dimensional semantic information (e.g., "this looks like a vehicle part") to the fine-grained classifier, providing a robust inductive bias that guides the optimization in the massive class space.

### Data
*   **Full-Dataset Decoupled Caching:** I will apply the decoupled feature extraction strategy to the **entire training dataset (~7 million products)** and the test set.
    *   *Strategic Correction:* This directly addresses the failure in **Cite solution_lesson_node_00013**, where complex models failed due to data starvation. By using the full dataset, we provide sufficient signal to train the high-capacity DFC architecture (input dim > 4000), preventing the overfitting observed in **Cite solution_lesson_node_00005**.
*   **Label Engineering:** Map each `category_id` to its Level 1 and Level 2 parents to generate the hierarchical targets for the cascade blocks.

### Training
*   **Loss Function:** Use a **Sum of Cross-Entropy Losses** from all three blocks ($L_{total} = L_{L3} + L_{L2} + L_{L1}$).
    *   *Correction:* I will explicitly **exclude** inverse-frequency class weights. As demonstrated in **Cite solution_lesson_node_00004**, class weighting optimizes for macro-recall and degrades the target metric (global accuracy). The cascading structure naturally handles class imbalance by utilizing balanced high-level concepts to condition the lower levels.
*   **Feature-Space MixUp:** Since the backbones are frozen, I will apply **MixUp** regularization ($x' = \lambda x_i + (1-\lambda)x_j$) directly on the cached feature vectors during training. This enforces linear decision boundaries and prevents the MLP from memorizing the tabular data.
*   **Optimizer:** Train using **AdamW** with Weight Decay and **Label Smoothing** (0.1) to prevent overconfidence.

### Evaluation
*   **Inference Pipeline:**
    1.  Load the pre-computed test set features (Dual-Backbone Fused) from RAM.
    2.  Pass the features through an **Ensemble of 3** trained DFC models.
    3.  Average the probability distributions (Softmax) from the **Block 3 (Level 3)** outputs across the ensemble.
    4.  Select the category with the highest average probability as the final prediction.
