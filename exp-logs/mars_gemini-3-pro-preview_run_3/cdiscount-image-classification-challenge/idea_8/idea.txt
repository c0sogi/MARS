Based on the analysis of the previous experiments and the derived lessons, I propose the following optimized strategy. This solution directly addresses the overfitting observed in **Lesson 00005** by scaling the data volume to match the model capacity, and incorporates the hierarchical structure of the data to improve generalization.

# Baseline Proposal: Full-Scale ResNet-50 with Hierarchical Multi-Task Learning & Feature MixUp

### Model
I propose a **Hierarchical Multi-Task Network** built upon a **ResNet-50** backbone.
*   **Backbone:** Use **ResNet-50** (pre-trained on ImageNet).
    *   *Rationale:* **Cite solution_lesson_node_00005** identified that ResNet-50's 2048-dimensional features led to overfitting when trained on a small subset (100k). However, ResNet-50 captures richer representations than smaller backbones. By scaling the training data to the full 7 million records (see Data section), we can effectively utilize this high capacity without overfitting. The backbone will be **frozen** to ensure computational feasibility (**Cite solution_lesson_node_00003**).
*   **Aggregation:** Apply **Mean Pooling** to the image features of each product. This creates a single 2048-dimensional embedding per product, maintaining the efficiency proven in **Cite solution_lesson_node_00003**.
*   **Hierarchical Classification Head:** The classification head will be structured to mirror the product taxonomy found in `category_names.csv`. A shared MLP trunk will split into three parallel output heads:
    1.  **Level 1 Head:** Predicts the coarse category (49 classes, e.g., "Sports").
    2.  **Level 2 Head:** Predicts the sub-category (483 classes, e.g., "Cycles").
    3.  **Level 3 Head (Target):** Predicts the fine-grained category (5270 classes, e.g., "Bike Helmets").
    *   *Innovation:* This multi-task structure acts as a strong regularizer. By forcing the model to learn features that explain the broader category concepts, we improve the robustness of the fine-grained predictions.

### Data
*   **Full-Dataset Decoupled Caching:** I will apply the decoupled feature extraction strategy to the **entire training dataset (~7 million products)** and the test set.
    *   *Strategic Retention:* This preserves the extreme training speed (seconds/epoch) of the decoupled approach (**Cite solution_lesson_node_00003**).
    *   *Correction:* Processing the full dataset is the direct fix for the failure in **Cite solution_lesson_node_00005**. With 7 million examples, the model has sufficient signal to learn the 2048-dimensional feature space of ResNet-50, which failed when restricted to 100k samples.
    *   *Feasibility:* Storing 7 million x 2048-dim float32 vectors requires ~57 GB of RAM, which fits comfortably within the 220 GB available.
*   **Label Engineering:** Map each `category_id` to its parent Level 1 and Level 2 labels using `category_names.csv` to generate multi-task targets.

### Training
*   **Feature-Space MixUp:** Since the backbone is frozen, standard image augmentation is impossible during the MLP training phase. I will implement **MixUp** on the cached feature vectors.
    *   *Technique:* Randomly interpolate pairs of feature vectors ($x' = \lambda x_i + (1-\lambda) x_j$) and their labels. This enforces linear behavior in the decision boundaries and prevents memorization of the tabular features.
*   **Loss Function:** Use a **Multi-Task Sum of Cross-Entropy Losses**: $L_{total} = L_{Level3} + 0.5 \cdot L_{Level2} + 0.5 \cdot L_{Level1}$.
    *   *Correction:* I will explicitly **exclude** inverse-frequency class weights. As demonstrated in **Cite solution_lesson_node_00004**, class weighting harms global accuracy by optimizing for macro-recall. The hierarchical auxiliary tasks will naturally support rare classes by grouping them into frequent parent categories.
*   **Optimizer:** AdamW with Weight Decay to further regularize the large MLP.

### Evaluation
*   **Inference Pipeline:**
    1.  Load the pre-computed test set features from RAM.
    2.  Pass features through the trained Hierarchical Network.
    3.  Select the class with the highest probability from the **Level 3 Head** as the final prediction.
