# Baseline Proposal: Full-Scale Dual-Backbone with Projected Multi-Task Learning (PMTL)

### Model
I propose a **Projected Multi-Task Learning (PMTL)** network. This architecture is designed to fuse complementary visual signals and enforce hierarchical consistency without the optimization instability associated with sequential cascading.

*   **Dual Frozen Backbones:** The model will utilize two distinct pre-trained backbones in parallel to extract complementary visual features.
    1.  **ResNet-50:** Selected for its robust texture and shape representations (2048 dimensions).
    2.  **EfficientNet-B0:** Selected for its efficient, multi-scale features (1280 dimensions).
    *   *Strategic Retention:* Both backbones will be **frozen** to ensure the pipeline remains I/O bound rather than compute-bound (**Cite solution_lesson_node_00003**).
*   **Fused Aggregation & Projection:**
    *   For every product, features will be extracted for all associated images using both backbones.
    *   Apply **Mean Pooling** independently to the ResNet and EfficientNet features, then **concatenate** them to form a raw 3328-dimensional embedding.
    *   **Structural Innovation:** Introduce a **Learnable Linear Projection (Bottleneck)** layer immediately after concatenation to map the 3328-dimensional vector to a compact **1024-dimensional** latent product embedding.
    *   *Rationale:* This projection serves two critical functions:
        1.  It forces the model to learn a unified representation from the two backbones (Sensor Fusion) before classification.
        2.  It significantly reduces the parameter count of the downstream classifier, addressing the dimensionality-induced overfitting risks identified in **Cite solution_lesson_node_00005**.
*   **Flat Multi-Task Classifier:** The compressed 1024-dim embedding feeds into a shared MLP trunk that branches into three **parallel, independent heads**:
    *   **Head 1 (Level 1):** Predicts the 49 coarse categories.
    *   **Head 2 (Level 2):** Predicts the 483 sub-categories.
    *   **Head 3 (Level 3 - Target):** Predicts the 5270 fine-grained targets.
    *   *Correction:* I explicitly reject the sequential cascading architecture (Idea 17). As demonstrated in **Cite solution_lesson_node_00023**, a flat architecture ensures direct gradient flow from the fine-grained labels to the shared trunk, avoiding the error propagation and training instability seen in cascades.

### Data
*   **Full-Dataset Decoupled Caching:** I will apply the decoupled feature extraction strategy to the **entire training dataset (~7 million products)** and the test set.
    *   *Strategic Correction:* This directly addresses the failure in **Cite solution_lesson_node_00013**, where complex models failed due to data starvation. By using the full dataset, we provide sufficient signal to train the high-capacity Dual-Backbone architecture.
    *   *Feasibility:* The projected storage requirement (~93 GB) fits comfortably within the 220 GB RAM limit.
*   **Label Engineering:** Map each `category_id` to its Level 1 and Level 2 parents to generate the hierarchical targets.

### Training
*   **Loss Function:** Use a **Sum of Cross-Entropy Losses** ($L_{total} = L_{L3} + L_{L2} + L_{L1}$).
    *   *Correction:* I will explicitly **exclude** inverse-frequency class weights. As demonstrated in **Cite solution_lesson_node_00004**, class weighting optimizes for macro-recall and degrades the target metric (global accuracy). The auxiliary tasks (L1/L2) will instead provide structural regularization.
*   **Feature-Space MixUp:** Since the backbones are frozen, I will apply **MixUp** regularization ($x' = \lambda x_i + (1-\lambda)x_j$) directly on the cached feature vectors during training. This enforces linear decision boundaries and prevents the MLP from memorizing the tabular data.
*   **Optimizer:** Train using **AdamW** with Weight Decay and **Label Smoothing** (0.1).

### Evaluation
*   **Inference Pipeline:**
    1.  Load the pre-computed test set features from RAM.
    2.  Pass the features through an **Ensemble of 5** trained PMTL models.
    3.  Average the probability distributions (Softmax) from the **Head 3 (Level 3)** outputs across the ensemble.
    4.  Select the category with the highest average probability as the final prediction.
