Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` and setup working directories. Define subset sizes (200k Train, 50k Val) to ensure the "Fast Baseline" requirement is met within the 2-hour limit.
2.  **Data Subsetting**: Load the full metadata for training and validation. Sample the defined subsets and save them to temporary CSV files. This ensures the computationally expensive feature extraction runs on a manageable amount of data.
3.  **Feature Extraction**:
    *   Instantiate the `DualBackbone` model on the GPU.
    *   Run `process_split` for the **Train** and **Validation** subsets, overwriting any existing feature files to ensure consistency with the current run's subset.
    *   Run `process_split` for the **Test** set (full 700k records) only if features are not already cached, as this is required for submission.
4.  **Ensemble Training**: Call `train_ensemble()` from the library. This automatically picks up the generated feature files and trains 5 Hierarchical MLPs using the settings defined in `Config`.
5.  **Validation & Analysis**:
    *   Manually load the validation features and the trained ensemble models.
    *   Perform inference to calculate the `Final Validation Metric` (Accuracy).
    *   Compute the correlation between the error magnitude (0 for correct, 1 for incorrect) and the L2 norm of the feature vectors to satisfy the failure analysis requirement.
6.  **Submission**: If the validation accuracy exceeds the specified threshold, call `predict_ensemble()` to generate the final `submission.csv`.
