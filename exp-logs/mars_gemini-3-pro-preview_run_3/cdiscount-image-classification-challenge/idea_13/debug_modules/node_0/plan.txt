Implementation Strategy:
1.  **Configuration Override**: Since the library's `Config` class defines paths statically at import time, I will dynamically override these paths in the main script to point to a temporary working directory (`./working/demo_run`). This ensures the demonstration runs in isolation without overwriting existing work or processing the full 58GB dataset.
2.  **Mini-Dataset Creation**: I will load the provided metadata files (`train.csv`, `test.csv`) and sample a very small subset (e.g., 50 training samples, 20 validation samples, 20 test samples). These subsets will be saved as new metadata files. This allows the feature extractor to process real images from the BSON files via random access (seeking) without processing the whole file.
3.  **Feature Extraction**: I will invoke `extract_features` with the mini-metadata. This demonstrates the `DualBackbone` (ResNet+EfficientNet) and BSON parsing logic. I will verify the output `.npy` files.
4.  **Hierarchy Mapping**: I will instantiate `HierarchyMap` to verify it correctly processes category relationships and encodes labels.
5.  **Training Loop**: I will reduce hyperparameters (Epochs=1, Batch Size=16, Ensemble Size=1) and run `train_ensemble`. This demonstrates the `HierarchicalMLP` model, `HierarchicalLoss` (with MixUp), and the training pipeline.
6.  **Inference**: I will run `predict_ensemble` to generate predictions on the mini-test set and verify the submission file format.
7.  **Validation**: Throughout the script, I will use `assert` statements to validate shapes, file existence, and data integrity.
