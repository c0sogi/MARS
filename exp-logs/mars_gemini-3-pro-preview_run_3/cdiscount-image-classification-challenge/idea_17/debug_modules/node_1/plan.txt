The issue is that the `best_acc` variable is initialized to `0.0`, and the checkpoint saving condition `val_acc > best_acc` fails when the model's accuracy is exactly 0.0 (which occurred during the debug run). This prevents the model from being saved, causing a crash later when the script tries to load it. To fix this, I will initialize `best_acc` to `-1.0` so that even a 0.0 accuracy on the first epoch is considered an improvement and triggers a save. Cite debug_lesson_1.
