To demonstrate the usage of the provided library files for the product categorization task, I have implemented a self-contained Python script. This script performs the following steps:

1.  **Configuration Override**: Sets up a temporary working directory (`./working/demo_run`) and modifies the `Config` class to run in `DEBUG` mode. This limits the dataset to a small subset (64 samples) and reduces the training duration to 1 epoch, ensuring the script runs quickly.
2.  **Hierarchy Mapping**: Verifies the `get_hierarchy_mappings` utility to ensure category labels are correctly mapped to their hierarchical levels (L1, L2, L3).
3.  **Feature Extraction**: Instantiates the `FeatureExtractor` to process the raw BSON images. It extracts visual features using the pre-trained ResNet and EfficientNet backbones and saves them as NumPy arrays.
4.  **Dataset Verification**: Loads the generated feature arrays using `CachedFeatureDataset` and asserts that the data shapes and types are correct.
5.  **Model Verification**: Instantiates the `PDFCNet` model and performs a dummy forward pass to confirm that the architecture produces the correct output shapes for all three hierarchical levels.
6.  **Training**: Executes the `train_model` function, which runs a complete training loop (training and validation) on the extracted features and saves the best model checkpoint.
7.  **Inference**: Loads the trained model and the test set features to generate predictions. It maps the predicted indices back to the original `category_id`s and creates a submission file in the required format.
