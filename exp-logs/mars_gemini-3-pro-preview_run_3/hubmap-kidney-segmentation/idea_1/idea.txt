# Baseline Approach: Tissue-Aware FPN with ResNet-18

This approach establishes a robust and efficient baseline by combining a lightweight Feature Pyramid Network (FPN) with a region-filtering strategy that leverages the provided anatomical segmentations. This method prioritizes speed by strictly limiting computation to relevant tissue areas and using an architecture designed for efficient multi-scale feature fusion.

### Model
We employ a **Feature Pyramid Network (FPN)** segmentation architecture with a **ResNet-18** encoder.
*   **Encoder**: The ResNet-18 backbone, pre-trained on ImageNet, serves as a fast and lightweight feature extractor. It generates a hierarchy of feature maps at different scales (downsampling factors of 4, 8, 16, and 32).
*   **Decoder (FPN)**: Unlike the symmetric U-Net (Model 1), the FPN decoder constructs a top-down pathway with lateral connections. High-level semantic features are upsampled and added element-wise to the corresponding higher-resolution features from the encoder. This mechanism efficiently builds a rich feature pyramid without the heavy concatenation and convolution operations found in standard U-Net decoders.
*   **Segmentation Head**: The multi-scale features from the pyramid are merged (typically by upsampling to a common resolution like 1/4 scale) and passed through a final convolution layer to predict the binary mask, which is then upsampled to the original input resolution.

### Data
To handle the massive size of the Whole Slide Images (WSIs) and the scarcity of target objects (glomeruli), we implement a **Region-of-Interest (ROI) Tiling** strategy:
1.  **Anatomical Filtering**: We first rasterize the provided anatomical structure annotations (Cortex and Medulla polygons) into a low-resolution binary map. Since glomeruli are predominantly located in the cortex, we generate training and inference tiles **only** from regions intersecting the Cortex (or general tissue) mask. This drastically reduces the number of tiles to process, ignoring the vast background areas.
2.  **Tiling**: We extract fixed-size tiles (e.g., $1024 \times 1024$ pixels) from the valid regions.
3.  **Normalization**: Pixel values are normalized using standard ImageNet mean and standard deviation.
4.  **Channel Standardization**: As the dataset contains both 1-channel and 3-channel images, we standardize inputs by converting 1-channel images to 3-channel (replicating the single channel) to maintain compatibility with the pre-trained ResNet encoder.

### Training
*   **Loss Function**: We use a combined **BCE + Dice Loss**. The Binary Cross Entropy (BCE) component provides smooth gradients for pixel-level classification, while the Dice Loss directly optimizes the overlap metric used in the competition, helping to handle class imbalance.
*   **Optimization**: We use the **AdamW** optimizer with a standard learning rate (e.g., 1e-4) and a cosine annealing schedule to converge quickly.
*   **Strategy**: Training is performed on the filtered tiles. To further balance the data, we ensure a minimum ratio of positive tiles (containing glomeruli) per batch.

### Evaluation
1.  **Mask Generation**: For each test image, we first generate the tissue/cortex mask from the anatomical JSON files.
2.  **Sparse Inference**: We perform sliding-window inference **only** on tiles that fall within this tissue mask. This avoids wasting compute on empty background regions.
3.  **Stitching**: Predictions from the tiles are stitched back into the original image coordinate system. Overlapping regions (if any) are averaged to reduce edge artifacts.
4.  **Thresholding**: The final probability map is thresholded (e.g., at 0.5) to produce the binary mask, which is then Run-Length Encoded (RLE) for submission.
