The strategy involves three targeted optimizations to improve upon the baseline ResNet18-FPN solution, leveraging the "Hierarchical ROI Sampling" lesson (Cite solution_lesson_node_00003) which allows us to process larger, more informative tiles efficiently.

1.  **Architecture Upgrade**: I will replace the `ResNet18` backbone with `ResNet34`. ResNet34 provides a deeper feature extraction path (34 layers vs 18) while maintaining the same stride/channel structure, making it a drop-in replacement for the FPN encoder. This should capture more complex textural features of the FTUs without excessive computational cost. The class will be renamed to `FPNResNet` to reflect this change.
2.  **Resolution Increase**: I will increase the `TILE_SIZE` from 512 to 1024. Larger tiles provide significantly more global context, which is critical for distinguishing glomeruli from similar-looking tubule structures in the cortex. The ROI sampling ensures we don't waste compute on the increased background area.
3.  **Training Extension**: I will increase `EPOCHS` from 5 to 10 to allow the deeper model to converge properly.

Finally, I will update `runfile.py` to enforce the conditional submission requirement (generating submission only if the validation metric exceeds 0.8497).

    model = FPNResNet()

        state_dict = torch.load(Config.MODEL_SAVE_PATH, map_location=device)
        model.load_state_dict(state_dict)

        image_path = os.path.join(Config.INPUT_DIR, row["image_path"])
        anat_path = os.path.join(Config.INPUT_DIR, row["anatomical_json_path"])

            print(f"Error predicting {image_id}: {e}")

        shape = (height, width)
