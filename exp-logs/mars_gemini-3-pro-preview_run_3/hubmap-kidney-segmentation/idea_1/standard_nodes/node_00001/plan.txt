The implementation strategy involves a sequential execution of training, validation with failure analysis, and submission generation. 

1.  **Setup**: Initialize the environment with a fixed seed and detect the computing device (GPU/CPU).
2.  **Training**: Execute the training pipeline using `library.train.run_training`. To ensure the "fast baseline" requirement is met and the script completes within the time limit, the number of epochs is set to 5. This allows the model to learn sufficient features from the tiled WSI data without over-consuming time.
3.  **Validation & Failure Analysis**:
    *   Load the validation metadata.
    *   Load the best model checkpoint saved during training.
    *   Perform inference on each validation image using `library.inference.predict_wsi` to generate full-slide predictions.
    *   Compare predictions against ground truth RLE masks to calculate the Dice coefficient for each image.
    *   Compute the mean Dice score across the validation set and print it as `Final Validation Metric: <value>`.
    *   Calculate the correlation between the model's error (1 - Dice) and patient metadata features (e.g., age, BMI, cortex percentage) to identify failure modes.
4.  **Submission**: Generate predictions for the test set using `library.inference.generate_submission_csv` and save the result to the specified output directory.
