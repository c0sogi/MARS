The issue is that the `StainNet` model implementation does not support the Deep Supervision feature enabled in the configuration (`Config.DEEP_SUPERVISION = True`). The configuration expects the model to return a list of prediction tensors from different decoder levels, but the current implementation returns only a single tensor from the final layer. This violates the configuration contract (Cite debug_lesson_5).

To fix this, I will modify `library/model.py` to:
1.  Initialize auxiliary segmentation heads (`head_d3`, `head_d4`) in `__init__` if deep supervision is enabled.
2.  Update `forward` to compute outputs from these intermediate decoder levels (`d3`, `d4`), upsample them to the input size, and return a list containing the main output and auxiliary outputs.
