Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the environment using the provided `Config` and `set_seed` utility to ensure reproducibility.
2.  **Training**: Execute a fast training cycle using `library.train.train_model`. To adhere to the time limit and "fast baseline" requirement, I will override the default configuration to run for **5 epochs** with **500 samples per epoch**. This ensures the model learns basic features without timing out.
3.  **Full Validation**: Instead of relying on the patch-based validation metric from the training loop, I will perform **sliding-window inference** on the full validation images. This mirrors the test phase and provides an accurate Dice score.
    *   Load validation metadata.
    *   For each image, generate a prediction mask using `predict_sliding_window`.
    *   Decode the ground truth RLE.
    *   Compute the Dice coefficient for the whole image.
4.  **Failure Analysis**:
    *   Calculate the error metric (`1 - Dice`) for each validation sample.
    *   Correlate this error with patient metadata (Age, BMI, Cortex %, etc.) to identify systematic failure modes.
    *   Print the correlation matrix.
5.  **Submission**:
    *   Check if the mean validation Dice exceeds the threshold of **0.9132**.
    *   If successful, trigger `library.inference.make_submission` to generate the `submission.csv` file for the test set.
