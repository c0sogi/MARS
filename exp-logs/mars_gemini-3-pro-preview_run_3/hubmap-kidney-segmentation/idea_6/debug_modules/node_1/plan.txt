The issue arises because the `targets` tensor (and potentially `probs`) becomes non-contiguous in memory due to the geometric augmentations (like `torch.flip` and `torch.rot90`) applied in `GPUAugmentor`. The `view()` method strictly requires a contiguous memory layout, whereas `reshape()` can handle non-contiguous tensors by copying the data if necessary. I will replace `.view(-1)` with `.reshape(-1)` in `library/losses.py` to resolve the `RuntimeError`.
