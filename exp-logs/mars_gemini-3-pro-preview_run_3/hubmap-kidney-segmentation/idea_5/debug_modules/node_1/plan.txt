The `RuntimeError: Trying to resize storage that is not resizable` is caused by the `mask` tensor being derived from a `numpy.memmap` object (used in `_get_ground_truth_mask` with `mmap_mode='r'`). Even after slicing and casting with `.astype()`, the resulting array can retain properties of the memory-mapped file, creating a PyTorch tensor with non-resizable storage. This causes the `DataLoader`'s default collation function to fail when attempting to allocate shared memory for multiprocessing. The fix is to explicitly convert the mask crop to a standard `numpy.ndarray` using `np.array()`, which ensures the storage is standard and resizable.
