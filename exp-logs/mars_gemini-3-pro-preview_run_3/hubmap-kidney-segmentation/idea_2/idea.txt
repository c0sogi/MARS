# Improved Solution: Nested U-Net (U-Net++) with EfficientNet Backbone and Deep Supervision

### Model
We propose replacing the ResNet-FPN architecture with a **U-Net++** architecture utilizing an **EfficientNet-B4** backbone.
*   **Architecture Design**: Unlike the standard FPN used previously, U-Net++ introduces nested, dense skip connections between the encoder and decoder sub-networks. These nested pathways bridge the semantic gap between the feature maps of the encoder and decoder, facilitating more effective fusion of high-resolution spatial details with high-level semantic features. This is particularly critical for delineating the complex, globular boundaries of functional tissue units (FTUs) against similar-looking background tissue.
*   **Backbone**: We upgrade the feature extractor to **EfficientNet-B4**. This backbone offers a superior parameter-efficiency-to-accuracy ratio compared to ResNet-18, allowing the model to capture more subtle textural patterns indicative of glomeruli without incurring prohibitive computational costs.
*   **Deep Supervision**: The architecture includes multiple segmentation heads attached to the intermediate decoder nodes. This allows the model to be supervised at various semantic levels (scales), improving gradient flow and forcing the model to learn robust features at different resolutions.

### Data
*   **Hierarchical ROI Sampling**: We strictly retain the strategy of using anatomical structure annotations (Cortex/Medulla) to filter the training and inference space. By generating tiles only from regions intersecting the relevant tissue masks, we eliminate computation on background regions and focus the model on the challenging distinction between FTUs and other tissue structures. **Cite solution_lesson_node_00003**.
*   **Stain-Invariant Augmentation**: To address the "different tissue preparation pipelines" mentioned in the task description, we introduce a rigorous color augmentation pipeline. This includes heavy Hue-Saturation-Value (HSV) shifting, RandomGamma, and RGBShift. This forces the model to rely on morphological features (cell density, capillary arrangement) rather than specific color profiles associated with a particular stain or scanner.
*   **Preprocessing**: Tiles are extracted at $1024 \times 1024$ resolution. We normalize pixel values using ImageNet statistics, consistent with the pre-trained backbone.

### Training
*   **Loss Function**: We employ a **Deep Supervision Loss**, which is a weighted sum of the **BCE + Dice Loss** computed at the final output and the auxiliary outputs from the nested decoder branches. This accelerates convergence and regularizes the model, preventing it from overfitting to specific spatial scales.
*   **Optimization**: We use the **AdamW** optimizer with a "cosine annealing with warm restarts" learning rate scheduler. This schedule helps the model escape local minima and settle into a robust solution.
*   **Strategy**: Training is performed on the filtered tile set. We employ a "hard" sampling strategy where we oversample tiles containing glomeruli to maintain a high positive-to-negative ratio in each batch, countering the inherent class imbalance.

### Evaluation
*   **ROI-Constrained Inference**: During inference, we first rasterize the anatomical polygons to create a tissue mask. We generate predictions **only** for tiles within this mask, ignoring the background entirely. **Cite solution_lesson_node_00003**.
*   **Test-Time Augmentation (TTA)**: To further improve robustness, we apply horizontal and vertical flips to each tile during inference and average the predictions.
*   **Stitching**: The tile predictions (from the final segmentation head) are stitched back into the original image coordinates. Overlapping regions are averaged using a Gaussian weighting map to reduce edge artifacts before applying a final threshold (0.5) to generate the binary submission mask.
