This script demonstrates the end-to-end usage of the provided machine learning library for audio tagging.

**Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes at runtime to enable `DEBUG` mode, reduce `EPOCHS` to 2, and lower `BATCH_SIZE`. This ensures the script executes quickly (within minutes) while exercising all code paths.
2.  **Metric Verification**: We unit-test the `calculate_lwlrap` function with a deterministic example to ensure the scoring logic is correct.
3.  **Data Pipeline Verification**: We instantiate the `AudioDataset` in debug mode. We retrieve a single sample to assert that the input tensor shapes (spectrograms) and target vectors (multi-hot labels) are correct.
4.  **Model Architecture Verification**: We instantiate the `HybridEfficientNet` and perform a forward pass with a dummy batch to verify the output dimensions match the number of classes (80).
5.  **Training Loop Execution**: We create PyTorch DataLoaders and run the `fit_model` function. This validates the training loop, loss calculation, backpropagation, scheduler stepping, and validation logic.
6.  **Inference Demonstration**: We load the saved best model and generate predictions for a small batch of test data, verifying the output format.
