This script demonstrates the end-to-end usage of the provided audio tagging library. It performs the following steps:
1.  **Configuration**: Subclasses the base `Config` to create a fast-running "Demo" configuration (utilizing a small data subset, fewer epochs, and a separate output directory).
2.  **Data Loading**: Instantiates data loaders using the demo configuration and verifies the shape and integrity of the batches (spectrograms and labels).
3.  **Model Initialization**: Instantiates the `ConvNeXtAudio` model, verifies the architecture modifications (1-channel input), and performs a forward pass to check output dimensions.
4.  **Utilities Verification**: Tests the `mixup_data` augmentation logic and the `calculate_lrap` metric function with synthetic data to ensure correctness.
5.  **Training Pipeline**: Executes a complete (but short) training run using `trainer.run_training`, verifying that the training loop completes, computes metrics, and saves the best model artifact.
