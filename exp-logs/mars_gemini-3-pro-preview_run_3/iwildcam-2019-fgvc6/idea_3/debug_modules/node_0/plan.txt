This script demonstrates the end-to-end usage of the provided animal classification library. It performs the following steps:

1.  **Configuration**: Overrides default `Config` settings to enable "Debug" mode (using a small subset of data) and reduces training duration to 1 epoch for rapid execution.
2.  **Data Loading**: Instantiates the DataLoaders using `get_dataloaders` and verifies the structure and dimensions of the batches (images and labels).
3.  **Model Instantiation**: Initializes the `AnimalSwinV2` model and performs a forward pass with a real batch of data to verify input/output shapes.
4.  **Training Loop**: Uses the `Trainer` class to train the model for one epoch on the debug subset. It verifies that the training process completes and produces a model checkpoint.
5.  **Inference**: Uses the `generate_submission` function to create predictions on the test set using the trained checkpoint. It validates the format and integrity of the generated submission file.
6.  **Metric Calculation**: Demonstrates the `calculate_score` utility with synthetic data to verify the F1 metric calculation.
