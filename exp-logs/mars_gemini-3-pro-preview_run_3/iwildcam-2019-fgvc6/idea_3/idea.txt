# Proposed Solution: Swin Transformer V2 with Generalized Mean Pooling

## Model
We will structurally evolve the solution by transitioning from the Convolutional Neural Network (CNN) paradigm (EfficientNetV2) to a **Hierarchical Vision Transformer**, specifically the **Swin Transformer V2-Tiny**. 
- **Architectural Shift:** While CNNs rely on sliding windows and translation invariance, Swin Transformers utilize shifted window attention mechanisms. This allows the model to capture long-range dependencies and global context more effectively, which is crucial for distinguishing camouflaged animals from complex background vegetation—a limitation of local-texture-focused CNNs (Cite solution_lesson_node_00008).
- **Pooling Innovation:** We will replace the standard Global Average Pooling layer with **Generalized Mean (GeM) Pooling**. In this dataset, animals often occupy a small portion of the "empty" landscape. Standard average pooling dilutes the animal's signal with the dominant background features. GeM pooling is a learnable operation that can focus on high-activation spatial regions (the animal) while suppressing low-activation background noise, thereby improving feature specificity for the classification head.

## Data
- **Preprocessing:** Images will be resized to **256x256** to maintain the resolution benefit observed in previous experiments.
- **Sampling:** We will strictly retain the **Weighted Random Sampler** to address the 72% "empty" class dominance. This ensures that every batch contains a balanced representation of all 23 classes, preventing the model from biasing towards the majority class (Cite solution_lesson_node_00002).
- **Augmentation:** 
    - We will apply **Heavy Augmentation** (ShiftScaleRotate, RandomBrightnessContrast) to improve robustness against lighting and orientation variations (Cite solution_lesson_node_00003).
    - We will utilize **CoarseDropout** for regularization. Crucially, adhering to the findings on small object occlusion, we will configure this with a **distributed occlusion strategy** (e.g., `min_holes=4`, smaller hole sizes) rather than large block masking. This forces the model to learn from partial features without risking the complete removal of small animals from the input (Cite solution_lesson_node_00009, solution_lesson_node_00010).

## Training
- **Optimizer & Scheduler:** We will use **AdamW** combined with the **OneCycleLR** scheduler. We will maintain the aggressive maximum learning rate of **1e-3** to facilitate rapid convergence and escape local minima, as this has proven superior to conservative rates for this task (Cite solution_lesson_node_00004).
- **Regularization:** To support the deeper Transformer architecture, we will introduce **Stochastic Depth (DropPath)**. This technique randomly drops entire residual paths during training, acting as a structural regularizer that complements the input-level CoarseDropout.
- **Loss Function:** We will use standard **Cross-Entropy Loss**. We will explicitly avoid Label Smoothing, as it has been shown to degrade Macro F1 on this imbalanced dataset by penalizing the high confidence required for rare class recall (Cite solution_lesson_node_00006).

## Evaluation
- **Test-Time Augmentation (TTA):** Inference will be performed using **Test-Time Augmentation**. We will average the predictions of the original image and a horizontally flipped version. This "soft voting" approach reduces variance and has been proven to incrementally improve the Macro F1 score (Cite solution_lesson_node_00008).
