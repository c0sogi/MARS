To improve the model's performance, I will implement the following changes based on the provided lessons:

1.  **Switch Backbone to EfficientNetV2-S**: As noted in **Lesson 00011**, CNNs (specifically EfficientNetV2-S) outperformed Vision Transformers (Swin Tiny) on this mid-sized dataset (Macro F1 0.9293 vs 0.9182). The inductive biases of CNNs are more data-efficient for this task size. I will update `library/config.py` to use `tf_efficientnetv2_s.in21k_ft_in1k`.
2.  **Adapt Model Architecture**: I will modify `library/model.py` to replace the `AnimalSwinV2` class with `AnimalEfficientNet`. Crucially, I will remove the tensor permutation `x.permute(0, 3, 1, 2)` in the forward pass. Swin Transformers output channels last `(B, H, W, C)`, whereas standard CNNs like EfficientNet output channels first `(B, C, H, W)`. Retaining the permutation would scramble the spatial features before pooling (Cite **Lesson 00011**).
3.  **Update References**: I will update `library/trainer.py` and `library/inference.py` to instantiate the new `AnimalEfficientNet` class.

These changes revert the architecture to the stronger CNN baseline while maintaining the robust training pipeline (WeightedRandomSampler, OneCycleLR, CoarseDropout) established in previous successful experiments.

class AnimalSwinV2(nn.Module):
    """
    Swin Transformer V2 model for Animal Classification.
    Uses SwinV2 Tiny backbone with GeM pooling and a linear head.
    """

    def __init__(
        self,
        model_name=Config.MODEL_NAME,
        num_classes=Config.NUM_CLASSES,
        pretrained=Config.PRETRAINED,
        drop_path_rate=Config.DROP_PATH_RATE,
        use_gem=Config.USE_GEM_POOLING,
    ):
        """
        Args:
            model_name (str): Name of the timm model to load.
            num_classes (int): Number of output classes.
            pretrained (bool): Whether to load pretrained weights.
            drop_path_rate (float): Stochastic depth rate.
            use_gem (bool): Whether to use GeM pooling.
        """
        super(AnimalSwinV2, self).__init__()

        # Load backbone
        # global_pool='' ensures we get spatial features (B, H, W, C) for Swin
        # num_classes=0 removes the default classification head
        self.backbone = timm.create_model(
            model_name,
            pretrained=pretrained,
            num_classes=0,
            global_pool="",
            drop_path_rate=drop_path_rate,
        )

        # Get feature dimension (e.g., 768 for Swin Tiny)
        self.num_features = self.backbone.num_features

        # Pooling Layer
        self.use_gem = use_gem
        if self.use_gem:
            self.pooling = GeM()
        else:
            self.pooling = nn.AdaptiveAvgPool2d(1)

        # Classification Head
        self.head = nn.Linear(self.num_features, num_classes)

    def forward(self, x):
        """
        Args:
            x (torch.Tensor): Input images (B, C, H, W).
        Returns:
            torch.Tensor: Logits (B, Num_Classes).
        """
        # Backbone forward pass
        # Swin Transformer in timm returns features as (B, H, W, C)
        x = self.backbone(x)

        x = x.permute(0, 3, 1, 2)

        x = self.pooling(x)

        # Flatten -> (B, C)
        x = x.view(x.size(0), -1)

        # Classification Head -> (B, Num_Classes)
        x = self.head(x)

        return x
