Implementation Strategy:
1.  **Configuration & Setup**: Import necessary modules and the provided library components. Override `Config.NUM_EPOCHS` to 7 to ensure the training completes quickly (approx. 30 mins on A100) while allowing sufficient convergence. Set the device and random seeds.
2.  **Data Loading**: Retrieve training, validation, and test dataloaders using `library.dataset.get_dataloaders`.
3.  **Model & Optimization**: Initialize the `AnimalClassifier` (EfficientNetV2-S), `AdamW` optimizer, and `OneCycleLR` scheduler using parameters from `Config`.
4.  **Training Loop**: Execute a custom training loop for the defined epochs. Inside the loop, call `train_one_epoch` and `validate` from `library.train`. Track the best validation F1 score and save the best model checkpoint using `library.utils.save_checkpoint`.
5.  **Final Evaluation**: After training, load the best model checkpoint. Perform a dedicated inference pass on the validation set to collect all predictions, targets, and image IDs. Calculate the Macro F1 score and print it as `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Implement a function `run_failure_analysis` that samples ~2000 examples from the validation results. It will load the corresponding images to compute meta-features (Height, Width, AspectRatio, PixelMean, PixelStd) and calculate the correlation between these features and the model's error (0 for correct, 1 for incorrect).
7.  **Submission**: Compare the final validation metric against the required threshold (0.924199462184614). If the condition is met, call `library.predict.generate_submission` to generate the final `submission.csv` using Test-Time Augmentation.
