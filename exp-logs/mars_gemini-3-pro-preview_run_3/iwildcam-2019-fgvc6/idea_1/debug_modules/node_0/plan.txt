1.  **Configuration Override:** We first import the `Config` class and modify its attributes (enabling `DEBUG` mode, reducing `EPOCHS`, and lowering `BATCH_SIZE`) to ensure the demonstration runs quickly and uses a small subset of the data.
2.  **Data Loading Verification:** We initialize the DataLoaders and fetch a single batch to verify that the image tensors have the correct shape `(Batch, Channels, Height, Width)` and that labels are within the expected range.
3.  **Model Verification:** We instantiate the ResNet-18 model and perform a forward pass with the sample batch to confirm the output shape corresponds to `(Batch, Num_Classes)`.
4.  **Training Loop Execution:** We initialize the `Trainer` class and run the `fit()` method. This triggers the training process for 1 epoch on the debug subset. We verify that the model checkpoint is successfully saved.
5.  **Inference & Submission:** We utilize the `predict_and_submit` function to generate predictions on the test set. Finally, we validate the generated `submission.csv` to ensure it follows the required format (`Id` and `Predicted` columns).
