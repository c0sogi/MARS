# Proposed Baseline Solution

## Model
The proposed baseline is a standard **ResNet-18** Convolutional Neural Network. This architecture is chosen for its balance between performance and computational efficiency, utilizing residual skip connections to facilitate effective gradient flow. Unlike the EfficientNetV2 (Model 1) or Swin Transformer (Model 2), ResNet-18 relies on classic convolutional blocks, establishing a robust and widely understood baseline. The model will be initialized with pre-trained ImageNet weights to leverage generic visual features, with the final fully connected layer replaced to output logits for the 23 target classes.

## Data
Data preprocessing will be kept minimal to prioritize speed. Images will be resized to a fixed resolution of 224x224 pixels and normalized using standard ImageNet mean and standard deviation values. To address the severe class imbalance (where the "empty" class dominates) without resorting to complex loss functions, we will utilize **Weighted Random Sampling** at the data loading stage. This strategy assigns a sampling probability to each image inversely proportional to its class frequency. Consequently, the data loader will construct batches that contain a balanced representation of all species, ensuring the model sees minority classes frequently during training.

## Training
The training process will employ a standard **Transfer Learning** workflow. We will use the **Cross-Entropy Loss** function, which is the standard objective for multi-class classification. Because the class imbalance is handled via the data sampler, the loss function itself does not need to be weighted. The model will be optimized using **AdamW** with a standard learning rate schedule (e.g., StepLR or Cosine Annealing). We will perform a short warm-up period training only the classification head, followed by fine-tuning the entire network end-to-end.

## Evaluation
Inference will be performed by passing the test images through the trained network after applying the same resizing and normalization steps used during training. The model will output a vector of class probabilities, and the final prediction will be determined by the index of the maximum probability (argmax). This approach avoids the complexity of multi-stage pipelines or ensembles, providing a direct and fast evaluation method.
