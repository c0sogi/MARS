# Proposed Solution: ConvNeXt V2 with Multi-Sample Dropout and GeM Pooling

## Model
We will structurally evolve the solution by transitioning from the EfficientNetV2 architecture to **ConvNeXt V2-Tiny**.
- **Structural Innovation:** ConvNeXt V2 represents a fundamental shift in Convolutional Neural Network design, integrating architectural principles from Vision Transformers (such as large 7x7 kernels, Layer Normalization, and GELU activations) while retaining the inductive biases (locality and translation invariance) that were proven superior for this mid-sized dataset (Cite solution_lesson_node_00011). Furthermore, ConvNeXt V2 utilizes Masked Autoencoder (MAE) pre-training, which explicitly trains the model to reconstruct images from partial views. This aligns perfectly with the task's challenge of identifying animals partially occluded by vegetation.
- **Pooling Strategy:** We will strictly retain **Generalized Mean (GeM) Pooling** instead of standard Global Average Pooling. This ensures the model can dynamically focus on high-activation regions (the animal) rather than diluting the signal with the dominant background "empty" pixels (Cite solution_lesson_node_00013).
- **Classification Head:** We will introduce **Multi-Sample Dropout** in the final classification layer. By applying multiple different dropout masks to the same feature vector and averaging the resulting losses, this technique accelerates convergence and acts as a robust regularizer, complementing the aggressive learning rate strategy.

## Data
- **Preprocessing:** Images will be resized to **256x256** pixels. This resolution strikes the optimal balance between capturing fine-grained details and maintaining computational throughput (Cite solution_lesson_node_00008).
- **Sampling:** We will employ the **Weighted Random Sampler** with inverse-frequency weights. This is non-negotiable for addressing the 72% class imbalance and ensuring the model learns minority classes (e.g., 'bobcat') effectively from the first epoch (Cite solution_lesson_node_00002).
- **Augmentation:**
    - **Photometric & Geometric:** We will apply **Heavy Augmentation** (ShiftScaleRotate, RandomBrightnessContrast) to simulate varying lighting conditions and camera orientations (Cite solution_lesson_node_00003).
    - **Occlusion:** We will use **CoarseDropout** configured for **distributed occlusion** (e.g., `min_holes=4`, smaller hole sizes). We will explicitly avoid large block masking to prevent the complete removal of small animals, ensuring the model learns to recognize species from partial features (Cite solution_lesson_node_00009, solution_lesson_node_00010).

## Training
- **Optimizer & Scheduler:** We will use **AdamW** with the **OneCycleLR** scheduler. We will set the maximum learning rate to **1e-3** to leverage the "super-convergence" phenomenon, allowing the model to escape sharp local minima rapidly (Cite solution_lesson_node_00004).
- **Loss Function:** We will use standard **Cross-Entropy Loss**. We will explicitly avoid Label Smoothing, as it has been shown to degrade Macro F1 on this specific dataset by penalizing the high confidence required for rare class recall (Cite solution_lesson_node_00006).
- **Precision:** We will utilize **Mixed Precision (AMP)** training. This reduces memory usage and training time, allowing for the computationally heavier ConvNeXt backbone to fit within the runtime constraints (Cite solution_lesson_node_00013).
- **Duration:** We will fix the training duration to **10 epochs**. We will avoid arbitrarily extending the epochs, as this stretches the OneCycle schedule and can degrade the final convergence phase (Cite solution_lesson_node_00014).

## Evaluation
- **Test-Time Augmentation (TTA):** During inference, we will generate predictions for both the original image and a horizontally flipped version. The final logits will be averaged to reduce prediction variance and improve the robustness of the Macro F1 score (Cite solution_lesson_node_00008).
