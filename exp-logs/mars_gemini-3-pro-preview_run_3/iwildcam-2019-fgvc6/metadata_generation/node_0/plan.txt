This script generates metadata for the animal classification task. It performs the following steps:
1.  **Setup**: Defines input/output directories and random state.
2.  **Data Loading**: Reads `train.csv` and `test.csv` from the `./input` directory. It cleans column names and removes index artifacts.
3.  **Path Construction**: Creates a `file_path` column for both datasets by appending image IDs to the respective directory names (`train_images/` and `test_images/`) and adding the `.jpg` extension.
4.  **Splitting**: Splits the training data into an 80% training set and a 20% validation set using stratified sampling on the `Category` column. It handles rare classes (fewer than 2 samples) by forcing them into the training set to prevent errors during stratification.
5.  **Saving**: Saves the resulting dataframes as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
6.  **Verification**:
    *   Reloads the saved metadata files.
    *   Prints summary statistics (shape, class distribution).
    *   Checks the existence of 1000 random file paths for each dataset, raising an error if more than 50% are missing.
    *   Verifies the validation split ratio (~20%) and ensures the class distribution in the validation set matches the training set (stratification check).
