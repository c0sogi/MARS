Based on the comprehensive analysis of the provided lessons and the performance plateau observed in architectural variations, I propose the following optimized strategy. This solution shifts the locus of innovation from the *network architecture* (which has proven sensitive to complexity, Cite {solution_lesson_node_00027}) to the *training pipeline*. I introduce a **Variance-Gated Self-Training** framework that leverages the ensemble's consensus to robustly augment the limited training data, directly addressing the "aleatoric uncertainty" identified in Lesson {solution_lesson_node_00024}.

### Model: DeBERTa-v3-Large with Simple Linear Head
**Backbone:**
I will utilize **`microsoft/deberta-v3-large`**. This architecture is retained as the foundation because its disentangled attention mechanism provides superior boundary detection capabilities compared to RoBERTa (Cite {solution_lesson_node_00014}), and the "Large" variant offers necessary capacity improvements over "Base" (Cite {solution_lesson_node_00023}).

**Head Design (Exploitation):**
I will strictly employ a **Simple Linear Head** (outputting Start/End logits) attached to the final hidden layer. I will explicitly reject complex heads like Weighted Layer Pooling or Multi-Task Content Heads, as previous experiments demonstrated that aggregating lower layers or adding auxiliary tasks dilutes the spatial precision required for this task and destabilizes training (Cite {solution_lesson_node_00018}, Cite {solution_lesson_node_00027}).

### Data
**Preprocessing (Exploitation):**
1.  **Raw Input Fidelity:** The model will process **raw, unmodified text**. I will avoid whitespace normalization, as this destroys structural cues and degrades performance (Cite {solution_lesson_node_00020}).
2.  **Neutral Exclusion:** Training data will be filtered to exclude "neutral" sentiment rows, as they represent a trivial identity mapping that wastes model capacity (Cite {solution_lesson_node_00006}).
3.  **Alignment Filtering:** Samples where character labels cannot be cleanly mapped to tokens will be discarded to prevent training on noise (Cite {solution_lesson_node_00016}).
4.  **Target Generation:** Targets will be generated using **Mask-Based Overlap**, where any token overlapping the character span is part of the target, providing robustness against annotator noise (Cite {solution_lesson_node_00012}).

### Training: Variance-Gated Self-Training Pipeline
**Structural Innovation (Exploration):**
To break the performance ceiling, I will implement a **Two-Stage Semi-Supervised Training Loop** that treats the test set as unlabeled data to be exploited.

**Stage 1: Base Ensemble Training**
-   Train a **5-Fold Cross-Validation Ensemble** on the full labeled training dataset (Cite {solution_lesson_node_00028}).
-   **Objective:** Cross-Entropy with Label Smoothing (0.1) to prevent overconfidence (Cite {solution_lesson_node_00010}).
-   **Constraints:** 3 Epochs, Batch Size 32, Max Length 96 (Cite {solution_lesson_node_00007}).

**Stage 2: Variance-Gated Pseudo-Labeling**
-   **Inference:** Generate predictions on the **Test Set** using all 5 models from Stage 1.
-   **Consistency Check:** Calculate the **Inter-Fold Jaccard Consistency** for each test sample (the average Jaccard score between the 5 fold predictions). High consistency implies the ensemble is confident and the boundary is unambiguous.
-   **Filtering:** Select test samples where the Inter-Fold Consistency exceeds a strict threshold (e.g., $\tau > 0.9$).
-   **Augmentation:** Add these high-confidence pseudo-labeled samples to the training set.
-   **Retraining:** Train a *new* 5-Fold Ensemble from scratch on this augmented dataset. This allows the model to densify the decision manifold around "easy" unseen examples, improving generalization on "hard" examples (Cite {solution_lesson_node_00024}).

### Evaluation
**Inference Pipeline:**
1.  **Deterministic Rule:** If sentiment is "neutral", return the entire `text` (Cite {solution_lesson_node_00006}).
2.  **Ensemble Summation Decoding:** For "positive" and "negative" samples, average the logits from the Stage 2 ensemble. Select the span $(i, j)$ that maximizes the **sum of probabilities** ($P_{start}(i) + P_{end}(j)$). This method is empirically superior to joint probability maximization for fuzzy boundaries (Cite {solution_lesson_node_00019}).
