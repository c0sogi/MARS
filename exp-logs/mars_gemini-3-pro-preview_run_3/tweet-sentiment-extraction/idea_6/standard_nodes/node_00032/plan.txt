My optimization strategy focuses on maximizing data utilization and reducing model variance, reverting the regression caused by self-training in the previous solution.

1.  **Full-Dataset Cross-Validation**: I will concatenate the training and validation metadata into a single dataset (filtering out neutral tweets) and perform 5-Fold Cross-Validation on this combined set. This ensures the model trains on 100% of the available non-neutral data, providing more supervision signal than the fixed split approach (Cite solution_lesson_node_00028).
2.  **Ensemble Inference**: I will average the logits from all 5 fold-models for the test set predictions. This reduces the variance associated with individual models and fuzzy boundaries (Cite solution_lesson_node_00023).
3.  **Summation Decoding**: I will ensure the decoding logic maximizes the sum of start and end probabilities ($P_{start} + P_{end}$) rather than the product, as this is more robust for subjective spans (Cite solution_lesson_node_00019).
4.  **Removal of Self-Training**: I will remove the variance-gated self-training pipeline, which introduced confirmation bias and increased runtime without performance gains (Cite solution_lesson_node_00031).
5.  **Hyperparameters**: I will set `EPOCHS` to 3 to allow the DeBERTa-v3-Large model sufficient convergence on the larger combined dataset, while keeping the batch size at 8.
