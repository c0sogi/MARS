The implementation strategy follows the **Variance-Gated Self-Training** idea. The pipeline consists of two main training stages. In **Stage 1**, a 5-fold ensemble of DeBERTa-v3-Large models is trained on the labeled training data (excluding neutral tweets). These models generate predictions on the test set. We then calculate the **Inter-Fold Consistency** (Jaccard similarity between fold predictions) to identify high-confidence test samples. These samples are assigned pseudo-labels and added to the training set. In **Stage 2**, a new 5-fold ensemble is trained on this augmented dataset.

The final model performance is evaluated on the fixed validation set (`metadata/val.csv`). The inference logic applies a deterministic rule for neutral tweets (returning the full text) and uses **Ensemble Summation Decoding** for positive/negative tweets (averaging logits from the Stage 2 ensemble). If the validation score exceeds the threshold, a submission is generated. Failure analysis is performed by correlating the Jaccard error with text length.
