The following script demonstrates the end-to-end usage of the provided library modules for the Sentiment Extraction task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We override specific `Config` parameters (Batch Size, Epochs) to ensure the demonstration runs quickly on a small subset of data. We explicitly set the device to GPU.
2.  **Data Pipeline Verification**: We load a small sample (20 rows) from the pre-generated metadata. We verify the `TweetDataset` and `process_data` logic by inspecting the shapes of the generated tensors (`input_ids`, `start_labels`, etc.).
3.  **Model Initialization**: We instantiate the `TweetModel` (DeBERTa-v3-large backbone) and move it to the GPU. We perform a dummy forward pass to confirm the output shapes of the logits.
4.  **Training Loop**: We set up the optimizer and scheduler, then run `train_fn` for one epoch on the small subset. We assert that the returned loss is a valid finite number.
5.  **Inference & Evaluation**: We run `eval_fn` to generate predictions and calculate the Jaccard score. We also manually validate the `jaccard` utility function and the `get_selected_text` post-processing logic with specific test cases.
