Based on the comprehensive analysis of the provided lessons and the failure modes of previous attempts, I propose the following optimized strategy. This solution structurally evolves the training pipeline by integrating **Adversarial Weight Perturbation (AWP)** with a **Full-Budget Optimization Schedule**, directly addressing the "aleatoric uncertainty" and generalization issues identified in Lesson {solution_lesson_node_00024} while correcting the resource-constraint error that caused the previous AWP attempt to fail (Lesson {solution_lesson_node_00035}).

# Model
**Backbone: DeBERTa-v3-Large**
I will utilize the **`microsoft/deberta-v3-large`** architecture. This model is selected for its disentangled attention mechanism, which has been empirically proven to yield superior boundary detection compared to RoBERTa (Cite {solution_lesson_node_00014}), and its increased capacity over the "Base" variant, which is necessary for resolving complex sentiment contexts (Cite {solution_lesson_node_00023}).

**Head: Simple Linear Classification**
I will strictly employ a **Simple Linear Head** (outputting Start/End logits) attached to the final hidden layer. I will explicitly reject complex heads like Weighted Layer Pooling or Multi-Task Content Heads. Previous experiments demonstrated that aggregating lower layers or adding auxiliary tasks dilutes the spatial precision required for this task and destabilizes training (Cite {solution_lesson_node_00018}, Cite {solution_lesson_node_00027}).

# Data
**Preprocessing (Exploitation)**
1.  **Raw Input Fidelity:** The model will process **raw, unmodified text**. I will strictly avoid whitespace normalization, as this destroys structural cues (e.g., newlines) and degrades performance (Cite {solution_lesson_node_00020}).
2.  **Conditioned Input Formatting:** To ensure the model is explicitly conditioned on the target sentiment, the input sequence will be formatted as `[CLS] [Sentiment] [SEP] [Text] [SEP]`. Omitting the sentiment label was a critical failure in previous iterations (Cite {solution_lesson_node_00037}).
3.  **Neutral Exclusion:** Training data will be filtered to exclude "neutral" sentiment rows, as they represent a trivial identity mapping that wastes model capacity (Cite {solution_lesson_node_00006}).
4.  **Alignment Filtering:** Samples where character labels cannot be cleanly mapped to tokens will be discarded to prevent training on noise (Cite {solution_lesson_node_00016}).
5.  **Target Generation:** Targets will be generated using **Mask-Based Overlap**, where any token overlapping the character span is part of the target. This is more robust to annotator noise than strict offset matching (Cite {solution_lesson_node_00012}).

# Training
**Structural Innovation: Full-Budget Adversarial Weight Perturbation (AWP)**
To address the overfitting to noisy labels without the "blurring" effect of aggressive passive regularization (Cite {solution_lesson_node_00025}), I will implement **Adversarial Weight Perturbation (AWP)**. Unlike the previous failed attempt which reduced the training budget to compensate for AWP's cost (Cite {solution_lesson_node_00035}), this solution will prioritize the **full optimization trajectory**:

1.  **Mechanism:** The training loop will implement a min-max optimization. For each step, we first calculate the gradient to find the direction that maximizes the loss, inject a perturbation $\delta$ into the model weights, and then perform a second forward/backward pass to minimize the loss at this "worst-case" point. This forces the model to find a flat minimum in the loss landscape, improving robustness to fuzzy boundaries.
2.  **Schedule:** AWP will be enabled **only after Epoch 1**. This allows the model to learn a stable representation of the task before being subjected to adversarial noise, preventing early divergence.
3.  **Budget:** I will strictly maintain the optimal **3-epoch duration** and **Full 5-Fold Cross-Validation** (training on 100% of available data per fold). I will not use a fixed hold-out set (Cite {solution_lesson_node_00028}) or reduce epochs, as the model requires sufficient iterations to converge on the flattened landscape (Cite {solution_lesson_node_00035}).

**Objective Function:**
The model will be trained using **Cross-Entropy Loss with Label Smoothing (0.1)**. This prevents the model from becoming overconfident in subjective boundaries (Cite {solution_lesson_node_00010}).

# Evaluation
**Inference Pipeline**
1.  **Deterministic Rule:** If the sentiment is "neutral", the pipeline will bypass the model and return the entire `text` string (Cite {solution_lesson_node_00006}).
2.  **Ensemble Summation Decoding:** For "positive" and "negative" samples, I will average the logits from all 5 fold-models. I will select the span $(i, j)$ (where $i \le j$) that maximizes the **sum of probabilities** ($P_{start}(i) + P_{end}(j)$). This method is empirically superior to joint probability maximization ($P_{start} \times P_{end}$) for fuzzy boundaries, as it allows a strong signal at one boundary to compensate for uncertainty at the other (Cite {solution_lesson_node_00019}).
