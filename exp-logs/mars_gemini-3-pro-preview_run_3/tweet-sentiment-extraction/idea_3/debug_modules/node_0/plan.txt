The following code demonstrates the usage of the provided library files for the Sentiment Extraction task. It performs the following steps:

1.  **Configuration & Setup**: Initializes the `Config` and sets random seeds for reproducibility.
2.  **Data Preparation**: Uses `prepare_data` to load the dataset, then slices it to a very small subset (50 samples) to ensure the demonstration runs quickly. It creates `TweetDataset` and `DataLoader` instances for both training and validation.
3.  **Model Initialization**: Instantiates the `TweetModel` (DeBERTa-v3-base backbone) and verifies the forward pass with a single batch.
4.  **Utility Verification**: Explicitly validates the logic of the `jaccard` metric and the `decode_span` post-processing function using assertions.
5.  **Training & Evaluation**: Runs a minimal training loop (1 epoch on the subset) and an evaluation step using the provided `train_fn` and `eval_fn`, printing the resulting metrics.
