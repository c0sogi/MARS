To address the stochastic variance observed in the previous run and improve the model's generalization on this high-cardinality task (Cite solution_lesson_node_00004), I will implement **Stochastic Weight Averaging (SWA)**.

**Strategy:**
1.  **SWA Integration**: I will modify the training loop to start SWA from epoch 4 (index 3). This allows the model to converge into a basin of attraction using the standard Cosine Annealing scheduler before switching to SWA mode.
2.  **Hyperparameters**:
    *   `NUM_EPOCHS` remains 5 to fit within the 4-hour runtime limit (estimated runtime ~3.5 hours including BN update).
    *   `SWA_LR` is set to 0.005, providing a reasonably high constant learning rate to explore the flat minimum.
3.  **Batch Normalization Update**: After training, I will perform a pass over the training data to update the Batch Normalization statistics of the averaged model, which is crucial for SWA performance.
4.  **Submission**: The final submission will be generated using the SWA model, which is expected to be more robust than any single checkpoint.
