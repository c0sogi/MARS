I will implement a robust Exploratory Data Analysis (EDA) script specifically tailored for the Image Classification task provided.

**Strategy:**
1.  **Setup and Reproducibility**: Import necessary libraries (`pandas`, `numpy`, `cv2`, `os`, `scipy`) and set a fixed random seed for reproducibility.
2.  **Data Loading**: Load the `./metadata/train.csv` file. This ensures we only analyze the training split to prevent data leakage.
3.  **Target Variable Analysis**:
    *   Analyze the `category_id` column.
    *   Calculate the number of unique classes (cardinality).
    *   Compute class counts to determine the severity of class imbalance (min, max, median samples per class).
4.  **Image Data Analysis (Sampling Strategy)**:
    *   Due to the large dataset size (~1.4M images), processing every image is computationally infeasible within the time limit.
    *   I will sample **5,000 images** randomly from the training set.
    *   For each sampled image, I will extract:
        *   Dimensions (Height, Width).
        *   Channel count (to detect Grayscale vs RGB).
        *   Pixel statistics (Mean and Standard Deviation) computed incrementally to avoid memory issues.
        *   File size in bytes.
5.  **Feature Relationships**:
    *   **Meta-Feature Analysis**: I will analyze the relationship between image properties (File Size, Image Area) and the Target (Category). Specifically, I will check if the top 5 most frequent classes have distinct distributions of image sizes.
6.  **Output Formatting**: The results will be printed in the specified format with clear headers and floats formatted to 4 decimal places.
