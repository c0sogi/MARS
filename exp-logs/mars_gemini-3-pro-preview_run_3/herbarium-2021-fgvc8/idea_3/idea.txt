Based on the empirical evidence gathered from the previous experiments, I propose the following optimized strategy. This solution addresses the primary bottleneck identified in the ResNet-50 experiments (the massive classification head) by structurally reducing the embedding dimension, while strictly adhering to the sampling and training protocols required for extreme classification.

### Model
**Architecture: ConvNeXt-Small with Reduced Embedding Dimension**
*   **Backbone:** I will replace the ResNet-50 backbone with **ConvNeXt-Small**.
    *   **Structural Innovation:** The core motivation for this change is not just improved feature extraction, but a specific structural advantage regarding the output layer. ResNet-50 produces a 2048-dimensional embedding, resulting in a classification head with ~132 million parameters ($2048 \times 64500$). This massive layer was identified as the primary convergence bottleneck **Cite solution_lesson_node_00003**. ConvNeXt-Small outputs a **768-dimensional embedding**, which reduces the classification head to ~50 million parameters (a ~62% reduction). This structural change significantly lowers the memory footprint and gradient computation load, allowing the model to align the output space more efficiently.
*   **Classification Head:** I will retain the **monolithic linear layer** design. Despite the backbone change, a single dense projection remains the most efficient and effective method for mapping features to 64,500 classes, provided mixed precision is used **Cite solution_lesson_node_00002**.

### Data
**Preprocessing & Sampling**
*   **Full Dataset Utilization:** I will strictly enforce training on the **entire dataset** for every epoch. The previous attempt to use this architecture failed because it artificially subsampled the data, starving the model of the class density needed to learn decision boundaries in a 64,500-way space **Cite solution_lesson_node_00006**.
*   **Sampling Strategy:** The data loader will use a **Weighted Random Sampler** to ensure rare classes are seen frequently. This is essential for maximizing the Macro F1 score in a long-tailed distribution **Cite solution_lesson_node_00002**.
*   **Resolution:** Input images will be resized to **224x224**. This resolution balances detail with the need for larger batch sizes, which are facilitated by the reduced memory footprint of the ConvNeXt head.

### Training
**Procedure**
*   **Loss Function:** I will use **Cross-Entropy Loss with Label Smoothing (0.1)**. This regularization technique has been proven to significantly boost the F1 score by preventing the model from overfitting to the noisy labels of the training set **Cite solution_lesson_node_00003**.
*   **Optimizer & Precision:** Training will use **AdamW** (optimal for ConvNeXt) combined with **Automatic Mixed Precision (AMP)**. AMP is critical for fitting the model and its dense gradients into GPU memory **Cite solution_lesson_node_00002**.
*   **Stochastic Weight Averaging (SWA):** To address the high variance observed in metric scores between runs, I will implement **Stochastic Weight Averaging** starting from epoch 8 (of a 12-epoch schedule). By averaging the weights of the model along the trajectory of convergence, SWA will provide a more robust final model that is less sensitive to the specific noise of the final batch **Cite solution_lesson_node_00004**.

### Evaluation
**Inference Process**
*   **SWA Update:** Prior to inference, a pass over the training data will be performed to update the BatchNorm statistics using the averaged SWA weights.
*   **Prediction:** The final predictions will be generated using a standard argmax on the logits produced by the SWA model. No complex retrieval or post-processing is required **Cite solution_lesson_node_00002**.
