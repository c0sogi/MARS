The implementation strategy focuses on creating a robust yet efficient baseline that fits within the time constraints while addressing the specific requirements of the task.

1.  **Configuration for Speed and Performance**: To satisfy the "fast baseline" requirement and the 2-hour runtime limit, I will override the default configuration to set `EPOCHS = 1` and disable Stochastic Weight Averaging (`USE_SWA = False`). Training on the full dataset for a single epoch is chosen over subsampling because extreme classification tasks (64,500 classes) require seeing the long tail of data to achieve a viable F1 score.
2.  **Data Pipeline**: I will utilize the provided `get_dataloaders` function with `load_cached_data=True`. This ensures that the computationally expensive step of calculating class weights for the `WeightedRandomSampler` is skipped if the cache exists, further optimizing startup time.
3.  **Training Execution**: The `train_model` function from the library will be used to train the `ConvNeXt-Small` architecture. This handles mixed-precision training and gradient clipping automatically.
4.  **Validation and Metrics**: Post-training, I will run a dedicated validation pass using the `validate` function to compute the exact Macro F1 score on the hold-out set. This value will be printed in the required format `Final Validation Metric: <value>`.
5.  **Failure Analysis**: I will perform a post-hoc analysis on the validation set predictions. I will calculate the point-biserial correlation between the binary error term (correct/incorrect) and two features:
    *   **Class Frequency**: To determine if the model systematically fails on rare species.
    *   **File Size**: To check if image complexity/quality (proxied by file size) correlates with error rates.
6.  **Conditional Submission**: Finally, the script will check if the calculated F1 score exceeds the threshold of `0.3544800410153631`. If successful, it will generate the submission file using `generate_submission`; otherwise, it will skip this step to save time.
