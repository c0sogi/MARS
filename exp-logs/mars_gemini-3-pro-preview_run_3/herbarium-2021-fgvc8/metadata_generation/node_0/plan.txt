The implementation strategy involves parsing the provided COCO-format JSON metadata files to extract image IDs, file paths, and category labels. We will construct relative file paths by prepending the appropriate directory (`train/` or `test/`) to the `file_name` fields found in the JSON. To create a validation set, we will first identify "rare" classes (those with fewer than 2 samples) and assign them directly to the training set to avoid splitting errors. The remaining "common" classes will be split using a stratified 80:20 split. Finally, we will save the metadata to CSV files and perform rigorous verification checks, including verifying file existence and split statistics.
