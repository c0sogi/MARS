Implementation strategy:
1.  **Setup**: Initialize the environment using `Config.setup()` and set random seeds for reproducibility.
2.  **Data Preparation**: Load the metadata for training, validation, and test sets. Execute `preprocess_and_cache` for the training and validation sets to ensure 2.5D volumes are ready for the model.
3.  **Training**: Instantiate the `Trainer` class and execute the training loop for a limited number of epochs (defined in `Config`) to establish a fast baseline.
4.  **Validation**: Load the best model checkpoint saved during training. Perform inference on the validation set to obtain probabilities.
5.  **Metric Calculation**: Compute the "Weighted Multi-label Logarithmic Loss" using the provided utility function and print it in the required format.
6.  **Failure Analysis**: Calculate the error magnitude per sample (weighted BCE) and compute its Pearson correlation with the `patient_overall` label to identify if fracture cases are systematically harder to predict.
7.  **Submission**: Check if the validation metric is below the strict threshold of `0.12231192492082398`. If satisfied, preprocess the test set, generate predictions, map them to the required submission format, and save `submission.csv`.
