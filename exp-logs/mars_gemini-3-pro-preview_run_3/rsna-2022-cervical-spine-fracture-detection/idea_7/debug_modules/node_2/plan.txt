The issue stems from using `Config.N_SLICES` as a default argument in the `__init__` method of `CervicalSpineDataset`. In Python, default argument values are evaluated once at module definition time (import time). As a result, the dataset class binds to the initial value of `Config.N_SLICES` (64) and ignores the update to 8 made by `Config.setup()` in `runfile.py`. To fix this, I will change the default value of `n_slices` to `None` and assign it the value of `Config.N_SLICES` inside the method body, ensuring the configuration is read at runtime (Cite debug_lesson_3).
