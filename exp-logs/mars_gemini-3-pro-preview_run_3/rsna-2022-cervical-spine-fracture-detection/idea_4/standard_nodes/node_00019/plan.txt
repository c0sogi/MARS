This script implements the end-to-end pipeline for the Anatomically-Guided Attention-MIL Network. It overrides the default configuration to run a fast baseline (5 epochs) using the provided library modules. It trains the model, evaluating it against the validation set to save the best checkpoint. It then calculates the specific weighted log loss metric required, performs failure analysis by correlating error magnitude with fracture presence, and conditionally generates a submission file if the performance threshold is met.
