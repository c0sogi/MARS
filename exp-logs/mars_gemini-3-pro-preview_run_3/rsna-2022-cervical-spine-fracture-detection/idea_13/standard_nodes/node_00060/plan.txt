This script implements the end-to-end pipeline for the RSNA Cervical Spine Fracture Detection task using the provided library modules.

**Implementation Strategy:**
1.  **Configuration Override**: Adjusts `Config` parameters for a fast baseline run (5 epochs, increased workers for I/O efficiency) while maintaining reproducibility via seed setting.
2.  **Data Loading**: Initializes `RSNADataset` for training and validation using the pre-generated metadata. Uses DataLoaders with pinned memory and multiple workers to handle DICOM I/O.
3.  **Model Training**: Instantiates the `DualStreamConvNeXt` model and trains it using `engine.fit`. This handles the training loop, validation monitoring, and checkpointing of the best model.
4.  **Validation & Analysis**:
    *   Loads the best saved model.
    *   Computes the competition metric (Weighted Log Loss) on the validation set.
    *   Performs failure analysis by calculating the correlation between sample-level loss and input features (specifically, the number of slices in the scan and the ground truth fracture status).
5.  **Inference**: If the validation metric meets the threshold (< 0.0643), generates predictions for the test set using `engine.inference` and saves the submission file.
