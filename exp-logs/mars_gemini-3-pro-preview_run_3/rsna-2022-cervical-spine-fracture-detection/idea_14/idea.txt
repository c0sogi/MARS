Based on the comprehensive analysis of the accumulated lessons, I propose the **Multi-Stage Feature-Fused ConvNeXt MIL Network**.

This solution structurally evolves the architecture to address the critical trade-off between **feature resolution** (required for tiny fractures) and **training stability** (required for small batches). It synthesizes the **LayerNorm-Native Backbone** (Cite solution_lesson_node_00048), **Multi-Task Learning** (Cite solution_lesson_node_00045), and **Spatial Continuity** (Cite solution_lesson_node_00014) into a cohesive pipeline, while introducing **Multi-Stage Feature Fusion** to solve the signal dilution problem without the computational cost of dual-stream inputs.

### 1. Model
**Architecture:** 2.5D ConvNeXt-Tiny with Multi-Stage Feature Fusion and Contextual MIL
*   **Backbone:** **ConvNeXt-Tiny** (pretrained on ImageNet).
    *   *Strategic Retention:* We utilize ConvNeXt because it natively employs **Layer Normalization**. This eliminates the "Micro-Batch Instability" observed with ResNet-34/50, allowing us to train a deeper, more powerful model with a stable Batch Size of 8 (Cite solution_lesson_node_00022, Cite solution_lesson_node_00048).
*   **Input:** **2.5D Stacks** (3 channels: slices $z-1, z, z+1$) (Cite solution_lesson_node_00001).
*   **Structural Innovation (Multi-Stage Feature Fusion):**
    *   Instead of using only the final output of the backbone (which is downsampled 32x, potentially losing fine fracture details), we extract feature maps from the **last three stages** (e.g., downsampling ratios 8x, 16x, and 32x).
    *   Apply **Global Average Pooling** to each stage's map independently.
    *   **Concatenate** these pooled vectors to form a rich slice representation $F_{slice}$.
    *   *Justification:* This preserves "mid-level" texture and edge information from earlier layers, which is critical for detecting hairline fractures (Cite solution_lesson_node_00042), while maintaining the semantic abstraction of deeper layers. It avoids the computational overhead of processing high-resolution crops (Idea 13) while achieving similar signal preservation.
*   **Context Module:** **Non-Linear 1D Convolution**.
    *   Structure: `Conv1d(k=3, padding=1) -> LayerNorm -> GELU`.
    *   *Strategic Retention:* We retain 1D Convolution to leverage Z-axis spatial continuity (Cite solution_lesson_node_00014). We enforce Non-Linearity and Normalization for stability (Cite solution_lesson_node_00027) but explicitly reject Residual connections to prevent overfitting (Cite solution_lesson_node_00026).
*   **Heads:** **Multi-Task Instance Classifiers**.
    *   The model projects the fused, contextualized features to **8 distinct logits** per slice: [C1...C7, Patient_Overall].
    *   *Strategic Retention:* We use **Multi-Task Learning** (dedicated patient head) rather than deriving the patient prediction via `max()`, as this stabilizes training by allowing independent gradient flow for the global label (Cite solution_lesson_node_00045).
*   **Aggregation:** **Global Max Pooling** applied per channel.
    *   *Strategic Retention:* Max Pooling is superior to Attention or Average Pooling for detecting sparse anomalies (Cite solution_lesson_node_00019, Cite solution_lesson_node_00047) and superior to embedding-level aggregation (Cite solution_lesson_node_00024).

### 2. Data
*   **Ingestion Pipeline:**
    *   **Sorting:** Sort slices strictly by `ImagePositionPatient` z-coordinate to ensure physical continuity (Cite solution_lesson_node_00031).
    *   **Calibration:** Apply `RescaleSlope` and `RescaleIntercept` to convert to Hounsfield Units (HU) (Cite solution_lesson_node_00031).
    *   **Windowing:** Apply **Standard Bone Window** (Level: 400, Width: 1800). Do not use High-Density windows which wash out trabecular bone signal (Cite solution_lesson_node_00029).
*   **Caching:** Preprocess and cache 2.5D stacks as **`uint8`** to maximize I/O throughput (Cite solution_lesson_node_00021).
*   **Sampling:** Uniformly sample **64 slices** per exam. Increasing to 96 increases False Positive risk (Cite solution_lesson_node_00010).
*   **Augmentation:**
    *   **Volumetric-Consistent:** Apply the exact same geometric transform to every slice in the bag (Cite solution_lesson_node_00013).
    *   **Single-Step Affine:** Fuse rotation, scaling, and shifting into a single affine operation (`ShiftScaleRotate`) to minimize resampling blur and preserve high-frequency fracture signals (Cite solution_lesson_node_00042).
    *   **Non-Destructive:** Explicitly avoid `Cutout` or `Dropout` on inputs (Cite solution_lesson_node_00037).
    *   **Necessity:** Augmentation is structurally required to prevent memorization (Cite solution_lesson_node_00011).

### 3. Training
*   **Loss Function:** **Implicitly Weighted Multi-Task Loss**.
    *   $L = \text{mean}(\text{BCE}_{C1..C7}) + \text{BCE}_{\text{Patient}}$.
    *   *Strategic Retention:* This formulation naturally creates the **1:7 weighting ratio** required by the metric without explicit scalar multipliers that distort gradients (Cite solution_lesson_node_00008).
*   **Optimizer:** AdamW with **Batch Size 8**.
    *   *Strategic Retention:* Small batch size acts as a necessary regularizer for this small dataset (Cite solution_lesson_node_00032). The ConvNeXt backbone ensures stability.
*   **Scheduler:** **Decoupled Cosine Annealing**. Set `T_max` to **1.5x the number of epochs**.
    *   *Strategic Retention:* Prevents premature learning rate decay, allowing the model to escape local minima (Cite solution_lesson_node_00007).
*   **Regularization:** Do **not** use Dropout in the classification heads (Cite solution_lesson_node_00003).

### 4. Evaluation
*   **Inference:**
    *   Load test scans using the sorted/calibrated pipeline.
    *   Process through ConvNeXt-Tiny -> Multi-Stage Fusion -> Context -> Multi-Task Heads.
    *   Aggregate via Global Max Pooling to obtain 8 probabilities.
    *   Submit the 7 vertebral probabilities and the distinct `patient_overall` probability directly.
