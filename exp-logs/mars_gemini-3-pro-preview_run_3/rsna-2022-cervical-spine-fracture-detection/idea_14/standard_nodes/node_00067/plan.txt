Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `utils` (seeding, logging, device selection).
2.  **Data Loading**: Load the metadata CSVs for train, validation, and test sets. Initialize the DataLoaders using `get_dataloaders`.
3.  **Model Initialization**: Instantiate the `MultiStageConvNeXtMIL` model and the `RSNALoss` criterion. Move the model to the appropriate device (GPU).
4.  **Training**: Execute the training loop using the `fit` function. Crucially, pass `test_loader=None` to `fit` to bypass the automatic submission generation within the engine, allowing us to implement the conditional logic required by the task.
5.  **Validation & Metric**: Load the best model weights saved during training. Run the `validate` function on the validation set to compute the exact weighted logarithmic loss. Print this metric in the required format.
6.  **Failure Analysis**:
    *   Extract input features (specifically `num_slices` / volume depth) from the validation set by inspecting the file system.
    *   Manually compute the loss *per sample* on the validation set (replicating the `RSNALoss` logic of `Mean(Vertebrae_BCE) + Patient_BCE` but without reduction).
    *   Calculate the Pearson correlation coefficient between the per-sample error (loss) and the input feature (depth) using `numpy`.
    *   Print the correlation.
7.  **Conditional Submission**: Compare the final validation metric against the strict threshold (`0.06429807151236185`). If and only if the metric is lower, invoke the `inference` function to generate predictions for the test set and save `submission.csv`.
