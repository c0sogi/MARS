The following script demonstrates the complete pipeline for the RSNA Cervical Spine Fracture Detection task using the provided library files.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes to set up a "Debug" environment. This includes reducing the number of epochs to 1, batch size to 2, and the sequence length (slices) to 8. This ensures the code runs to completion quickly.
2.  **Runtime Patching**: We monkey-patch the `RSNAModel.__init__` method. The training script defaults to `pretrained=True`, which attempts to download weights. To ensure this runs in an offline or restricted environment without errors, we force `pretrained=False` dynamically.
3.  **Component Verification**:
    *   **Data**: We instantiate the `RSNADataset` and `DataLoader` to verify that DICOMs are processed and stacked into tensors of the correct shape `(Batch, Slices, Channels, H, W)`.
    *   **Model**: We perform a forward pass with the loaded data to verify the model outputs logits of shape `(Batch, 8)`.
    *   **Loss**: We compute the `ImplicitWeightedLoss` to ensure the loss function is operational.
4.  **Pipeline Execution**: We execute `run_training` and `predict` functions to simulate the full lifecycle from training to submission generation, validating the existence of the output files (`best_model.pth` and `submission.csv`).
