Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using `library.config.Config` and `library.utils.seed_everything`.
2.  **Training**: Execute `library.train.run_training` with a limited number of epochs (5) to ensure the code completes quickly while establishing a baseline. This function handles the training loop, optimizer, and model checkpointing.
3.  **Validation**:
    *   Load the best model checkpoint (`best_model.pth`).
    *   Load the validation metadata and create a `DataLoader` using `library.data.RSNADataset`.
    *   Perform inference in `eval` mode with `torch.no_grad()` and mixed precision to optimize speed.
    *   Calculate the **Weighted Multi-Label Logarithmic Loss** as specified. I will use weights of $7/14$ for `patient_overall` and $1/14$ for each vertebra level, averaged across all rows (predictions).
    *   Print the metric with full precision.
4.  **Failure Analysis**:
    *   Compute the loss per sample.
    *   Extract the `num_slices` feature for each validation study by counting files in the input directory (efficiently, without loading pixels).
    *   Calculate and print the Pearson correlation between the sample loss and `num_slices` to identify if scan depth affects performance.
5.  **Conditional Submission**:
    *   Check if the calculated validation metric is below the strict threshold `0.12231192492082398`.
    *   If the condition is met, call `library.inference.predict` to generate `submission.csv`.
