The error `AttributeError: type object 'Config' has no attribute 'AUG_HFLIP_PROB'` indicates that the `Config` class is missing a required hyperparameter for horizontal flip augmentation. This error persists even if the file is edited on disk because the Python process in the persistent environment has likely cached the old `Config` module definition in `sys.modules`, and `DataLoader` worker processes inherit this stale state (Cite debug_lesson_9). To resolve this, I will update `library/config.py` to include the missing attribute and explicitly patch the `Config` class in `runfile.py` at runtime to ensure the in-memory class definition is updated before training starts.
