The following script demonstrates the end-to-end usage of the provided machine learning library for cervical spine fracture detection.

**Implementation Strategy:**
1.  **Configuration Override:** We dynamically modify the `Config` class to enable a "Debug Mode". This reduces the dataset to just 4 samples and limits training to 1 epoch, ensuring the script runs within the time limit. We also disable pretrained weight downloading to avoid network dependencies and reduce image dimensions for speed.
2.  **Data Pipeline Verification:** We instantiate the `CervicalSpineDataset` and a `DataLoader`, fetching a single batch to verify that input tensors (Batch, Sequence, Channels, Height, Width) and target tensors (Batch, Classes) have the correct shapes.
3.  **Model & Loss Validation:** We initialize the `DynamicDepthConvNeXt` model and `ImplicitWeightedLoss`. We perform a forward pass on the fetched batch and calculate the loss, asserting that the outputs are valid (correct shape, no NaNs, non-negative scalar loss).
4.  **Training Loop:** We execute the `fit()` function to train the model for one epoch on the debug subset, verifying that a model checkpoint is saved.
5.  **Inference:** We run `run_inference()` using the saved checkpoint to generate a submission file, confirming the output file exists and adheres to the required format.
