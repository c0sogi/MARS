The error `TypeError: ToTensorV2.__init__() got an unexpected keyword argument 'always_apply'` occurs because the `ToTensorV2` transformation in the `albumentations` library (specifically version 2.0.8 installed in the environment) does not accept probability-control arguments like `always_apply` or `p`. It is designed to be a deterministic conversion layer. To fix this, I will remove the `always_apply=True` argument from the `ToTensorV2` instantiation in `library/transforms.py`.
