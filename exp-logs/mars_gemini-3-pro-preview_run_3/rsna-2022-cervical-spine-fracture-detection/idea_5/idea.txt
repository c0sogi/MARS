Based on the analysis of the provided lessons and previous attempts, I propose the **Anatomically-Conditioned Residual Sequence MIL** network.

This solution structurally evolves the "Sequence-Smoothed" approach (Idea 2) by integrating the "Positional Encoding" efficiency (Idea 3) and upgrading the sequence model to a **Residual** formulation. This addresses the conflict between the benefits of context modeling (Cite Lesson 00014) and the risks of signal dilution in subsampled data (Cite Lesson 00012).

### 1. Model
**Architecture:** 2.5D ResNet34 with Residual 1D Context Modulation
*   **Backbone:** Upgrade to **ResNet-34** (pretrained on ImageNet). This provides a moderate increase in feature extraction capacity over the ResNet-18 used in previous ideas, allowing for better detection of subtle fracture lines, while remaining well within the compute budget.
*   **Input:** 2.5D Stacks (3 channels: slices $z-1, z, z+1$).
*   **Feature Extraction:** Process 64 uniformly sampled slice stacks independently to generate a sequence of feature vectors $F \in \mathbb{R}^{64 \times D}$.
*   **Structural Innovation (Anatomical Residual Context):**
    *   **Positional Injection:** Concatenate the normalized relative depth $d_z = z/N$ to each feature vector in the sequence. This explicitly informs the model of the vertebral level (e.g., C1 vs. C7) before context modeling (Synthesizing Lesson 00018 and Lesson 00020).
    *   **Residual 1D Context Block:** Instead of a simple 1D Convolution (which risks blurring sparse signals, Cite Lesson 00012), apply a **Residual 1D Convolutional Block**: $F_{out} = F_{in} + \text{Conv1D}(\text{Activation}(\text{Conv1D}(F_{in})))$.
    *   **Purpose:** The residual connection allows the model to preserve the sharp, high-frequency signal of a fracture from a single slice (passing it through the identity shortcut) while the convolutional branch optionally adds smoothing context from neighbors only where beneficial. This resolves the trade-off between context (Cite Lesson 00014) and signal preservation (Cite Lesson 00019).
*   **Aggregation:** Apply **Global Max Pooling** across the sequence dimension. Max pooling is retained as it is superior to Attention for detecting sparse anomalies like fractures (Cite Lesson 00019).
*   **Head:** A classification layer maps the aggregated features to 7 logits (C1-C7).
*   **Patient Prediction:** Dynamically derive `patient_overall` as `max(C1...C7)`. Do not use Dropout in the head (Cite Lesson 00003).

### 2. Data
*   **Caching Strategy:** Preprocess and cache all 2.5D slice stacks as **`uint8`** arrays. This maximizes I/O throughput and reduces storage footprint, enabling faster training epochs (Cite Lesson 00021).
*   **Sampling:** Uniformly sample **64 slices** per exam. Maintain this bag size to avoid the increased False Positive risk associated with larger bag sizes in Max-Pooling networks (Cite Lesson 00010).
*   **Augmentation:** Apply **Volumetric-Consistent Augmentation**. Use a deterministic replay mechanism to ensure the exact same geometric transformation (rotation, shift, scale) is applied to every slice in the bag. This preserves the physical 3D continuity required for the 1D Context Block to function correctly (Cite Lesson 00013).

### 3. Training
*   **Loss Function:** **Hierarchical Compound Loss**.
    *   Compute `BCEWithLogits` for the 7 vertebral sub-labels.
    *   Compute `BCEWithLogits` for the derived `patient_overall` prediction (via `torch.max`) against the global target.
    *   Sum these losses. This enforces logical consistency and calibration (Cite Lesson 00005).
*   **Weighting:** **Implicit Weighting**.
    *   Calculate loss as `mean(vertebral_losses) + patient_loss`. This naturally achieves the competition's effective 1:7 weighting ratio without aggressive positive class weights that destabilize Max Pooling (Cite Lesson 00001, Cite Lesson 00008).
*   **Optimizer:** AdamW.
*   **Scheduler:** **Decoupled Cosine Annealing**. Set `T_max` to **1.5x the number of epochs** (e.g., 15 for a 10-epoch run). This prevents premature cooling of the learning rate, ensuring the heavier ResNet34 backbone converges effectively (Cite Lesson 00007).

### 4. Evaluation
*   **Inference:**
    *   Load test scans, apply 64-slice sampling, and preprocess (windowing/resizing).
    *   Pass through the ResNet34 backbone, inject position, process via the Residual 1D Context Block, and aggregate via Max Pooling.
    *   Output the 7 vertebral probabilities.
    *   Calculate `patient_overall` as the maximum of the 7 vertebral probabilities to ensure submission consistency.
