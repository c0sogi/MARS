The issue lies in the `weighted_log_loss_metric` function in `runfile.py`. The current implementation sums the weighted log losses for all 8 targets within each exam and then averages these sums across exams. This effectively calculates the average loss per exam (summed over targets), whereas the competition metric requires the loss to be averaged across all individual prediction rows (targets). Since there are 8 targets per exam, the calculated metric is approximately 8 times larger than it should be. The fix is to calculate the mean of the entire `loss_per_label` matrix (averaging over both exams and targets) to obtain the correct `final_metric`.
