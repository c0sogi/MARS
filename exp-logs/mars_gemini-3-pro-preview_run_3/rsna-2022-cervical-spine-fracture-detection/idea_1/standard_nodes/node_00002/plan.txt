3.  **Optimize Hyperparameters**: I will increase the training duration to 10 epochs to allow the model to converge with the new unweighted loss function.

def calculate_pos_weights(df, target_cols):
    """
    Calculates positive weights for BCEWithLogitsLoss based on class prevalence.
    Weight = (Total - Positive) / Positive
    """
    weights = []
    for col in target_cols:
        pos = df[col].sum()
        total = len(df)
        # Add epsilon to avoid division by zero
        weight = (total - pos) / (pos + 1e-5)
        weights.append(weight)
