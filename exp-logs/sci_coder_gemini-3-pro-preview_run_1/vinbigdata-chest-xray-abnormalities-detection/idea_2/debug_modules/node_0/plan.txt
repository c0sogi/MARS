Implementation Strategy:
1.  **Setup and Configuration**: Import necessary modules and the provided library components. Override the default `Config` parameters to enable `DEBUG` mode, reduce the number of epochs to 1, and set a small batch size. This ensures the script runs quickly within the time limit while still exercising all code paths.
2.  **Data Verification**: Instantiate the `VinBigDataDataset` in debug mode. Fetch a single sample to verify the data loading pipeline (DICOM reading, preprocessing, augmentation) and assert that the output tensor shapes are correct (Image: `[3, 512, 512]`, Heatmap: `[14, 128, 128]`).
3.  **Model & Loss Verification**: Instantiate the `MultiTaskCenterNet` and `MultiTaskLoss`. Perform a forward pass with a dummy batch to ensure the model architecture is valid and produces outputs with the expected keys and dimensions. Calculate the loss to verify the criterion.
4.  **Training Loop**: Initialize DataLoaders for training and validation. Set up the optimizer. Execute the `run_training` function from the `engine` module to train the model for one epoch and save the checkpoint.
5.  **Inference Pipeline**: Execute the `predict_and_format` function from the `inference` module. Pass the path to the newly trained model explicitly. This will run the model on the test set (using the full test set as the library function doesn't support debug mode easily, but inference is fast on A100), generate predictions, and save the submission file.
6.  **Result Validation**: Assert that the submission file exists and contains the expected columns and number of rows.
