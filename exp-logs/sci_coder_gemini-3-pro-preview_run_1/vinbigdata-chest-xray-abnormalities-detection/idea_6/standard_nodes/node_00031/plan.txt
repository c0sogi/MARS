The implementation strategy involves the following steps:

1.  **Configuration & Setup**: Initialize the environment, setting random seeds for reproducibility. Override default `Config` parameters to create a "fast baseline" suitable for the time limit (e.g., reducing the number of epochs to 5 and limiting the training dataset size to 5,000 samples).

2.  **Data Loading**: Instantiate the `ThoracicDataset` for training, validation, and testing. Wrap them in `DataLoader` instances. The training set will be shuffled, while validation and test sets will be sequential for consistent evaluation.

3.  **Model Initialization**: Load the `ThoracicModel` (EfficientNet-B0 + BiFPN + Decoupled Heads) and move it to the GPU. Initialize the optimizer (AdamW) and scheduler (CosineAnnealingLR).

4.  **Training Loop**: Execute the training for the defined number of epochs. In each epoch, run the training step and then a validation step (monitoring loss).

5.  **Metric Evaluation (mAP)**: Implement a custom Mean Average Precision (mAP) calculator compliant with PASCAL VOC 2010 standards at IoU > 0.4. Run inference on the validation set, decode predictions, and compare them against ground truth metadata to compute the final metric.

6.  **Failure Analysis**: Perform a specific pass on the validation set to analyze errors. Calculate the loss per image (using batch size 1 for granularity) and correlate this "error magnitude" with input image statistics (e.g., mean pixel intensity). Print the correlation coefficients.

7.  **Submission Generation**: Check if the calculated validation mAP exceeds the threshold (0.1783551866). If successful, run inference on the test set using the `generate_submission` utility and save the results to `submission.csv`.
