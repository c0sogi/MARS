To resolve the `torch.OutOfMemoryError` and ensure efficient, stable training on the available hardware, I will implement the following changes:

1.  **Reduce Batch Size**: In `library/config.py`, I will decrease `BATCH_SIZE` from 32 to 8. This aligns the memory footprint with the 16GB GPU capacity, preventing the OOM error (Cite debug_lesson_7).
2.  **Enable Mixed Precision (AMP)**: In `library/train.py`, I will integrate `torch.amp.autocast` and `torch.cuda.amp.GradScaler`. This reduces memory consumption and accelerates training by using float16 where appropriate.
3.  **Ensure Numerical Stability**: In `library/loss.py`, I will explicitly cast the heatmap logits to `float32` before applying the sigmoid activation and focal loss. This prevents numerical instability (NaNs) that can occur when performing logarithmic operations on float16 values during mixed precision training (Cite debug_lesson_5).
