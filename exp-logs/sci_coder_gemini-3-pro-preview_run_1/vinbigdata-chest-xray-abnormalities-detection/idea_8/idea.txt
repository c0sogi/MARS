Based on the lessons learned from previous iterations, I propose the following optimized strategy. This solution structurally evolves the "Multi-Task CenterNet" by implementing a **Task-Aligned Spatially-Decoupled Architecture**. This design explicitly resolves the conflict between translation invariance (required for classification) and translation covariance (required for anatomical regression), while strictly adhering to the data integrity and initialization protocols that caused previous advanced iterations to fail.

# Model
**Architecture: EfficientNet-B0 with BiFPN and Task-Aligned Decoupled Heads**

*   **Backbone (Retained):** Use **EfficientNet-B0**. We strictly adhere to this lightweight backbone to ensure the model can be trained on the **full dataset** within the compute budget. We reject larger backbones (e.g., B3) which necessitate data subsampling and lead to performance collapse **Cite {solution_lesson_node_00019}**.
*   **Neck (Retained & Refined):** Use a **Bi-directional Feature Pyramid Network (BiFPN)** to fuse features from levels P3 to P7. Crucially, we will **exclude P2 (Stride 4)** from the fusion process. Previous attempts to include these low-level features directly introduced high-frequency noise that degraded performance **Cite {solution_lesson_node_00032}**. The fused features will be upsampled to Stride 4 at the very end of the neck.
*   **Structural Innovation: Task-Aligned Split-Head Topology.**
    To resolve the **Invariance-Covariance Conflict** **Cite {solution_lesson_node_00033}**, we split the feature map after the BiFPN into two distinct adapter branches:
    1.  **Classification Branch (Heatmap):** Consists of standard convolutional layers. This preserves **Translation Invariance**, ensuring that a finding (e.g., a nodule) produces a high activation regardless of where it appears in the image.
    2.  **Regression Branch (Size/Offset):** Uses **Coordinate Convolution (CoordConv)** by concatenating normalized $(x, y)$ coordinate channels to the feature map *before* the regression convolutions. This injects absolute spatial priors explicitly for the regression task, allowing the model to learn anatomy-dependent sizing (e.g., "heart size depends on location") without biasing the detection heatmap.
    *   **Initialization Fix:** We will explicitly initialize the final convolutional layers of this unbounded regression branch with a **tiny standard deviation (e.g., 0.001)** and zero bias. This prevents the "exploding gradient" failure that previously destabilized training when using standard Kaiming initialization on regression tasks **Cite {solution_lesson_node_00023}**.
*   **Auxiliary Head (Retained):** A **Global Classification Head** attached to the deepest feature layer (P7) to predict the binary "Finding vs. No Finding" probability, serving as a gate **Cite {solution_lesson_node_00010}**.

# Data
**Preprocessing & Ingestion:**
*   **Semantically Normalized Binary Parser:** We will implement a custom binary DICOM parser to read pixel data directly, bypassing missing libraries. Crucially, this parser will perform **Semantic Normalization**: it will inspect the `Photometric Interpretation` tag and invert the pixel data if it is `MONOCHROME1` (White=0). This ensures all images share the same "Black=0" semantic meaning, resolving the "conflicting signals" failure **Cite {solution_lesson_node_00020}**.
*   **Coupled Metadata Loading:** We will implement a centralized loading function that returns the image tensor and extracts the *original dimensions* directly from that specific load operation. We will strictly avoid using separate header parsers or cached metadata, ensuring the coordinate space used for rescaling is mathematically consistent with the loaded image **Cite {solution_lesson_node_00022}** **Cite {solution_lesson_node_00003}**.
*   **Augmentation Strategy:**
    *   **Geometric:** Use `ShiftScaleRotate` with a strict **`min_visibility=0.3`** constraint. This filters out noisy targets where the object is cropped out but the label remains, which stabilizes regression training **Cite {solution_lesson_node_00013}**.
    *   **Photometric:** Use `RandomBrightnessContrast` for regularization. We will explicitly **exclude CLAHE**, as non-linear histogram equalization widens the domain gap and degrades performance on this task **Cite {solution_lesson_node_00015}**.

# Training
*   **Loss Function:** A multi-task loss comprising **Focal Loss** (Heatmap), **L1 Loss** (Regression), and **Binary Cross-Entropy** (Global Head).
*   **Optimizer & Schedule:** Use **AdamW** with a **Cosine Annealing** scheduler. This dynamic schedule improves convergence to sharp minima compared to constant learning rates **Cite {solution_lesson_node_00011}**.
*   **Duration:** Train for **20 Epochs**. The use of strong photometric augmentations increases the difficulty of the training task, requiring a longer horizon to converge and learn robust features. Stopping early (e.g., 5 epochs) results in underfitting **Cite {solution_lesson_node_00012}**.

# Evaluation
*   **Gated Inference:** For each test image, first check the **Global Classification Head**. If the "No Finding" probability exceeds a high threshold (e.g., 0.8), immediately output the "No finding" string (`14 1 0 0 1 1`). This leverages the auxiliary head to suppress false positives in normal scans **Cite {solution_lesson_node_00010}**.
*   **Coupled Rescaling:** For detected objects, map the bounding boxes from the model's input resolution back to the **original image dimensions** retrieved via the *coupled* metadata utility. This ensures accurate IoU calculation by guaranteeing the coordinate spaces match **Cite {solution_lesson_node_00003}**.
