The implementation strategy involves the following steps:

1.  **Setup and Loading**: Initialize paths and directories. Load the `train.csv` and `sample_submission.csv` files using pandas.
2.  **Path Construction**: Add a `file_path` column to the dataframes. The paths will be relative to the `./input` directory (e.g., `train/<image_id>.dicom`).
3.  **Data Splitting**:
    -   Use `StratifiedGroupKFold` from `sklearn.model_selection` to split the training data into training and validation sets.
    -   Set `n_splits=5` to achieve an 80:20 ratio.
    -   Use `image_id` as the group identifier to ensure that all annotations for a single image remain in the same split (preventing data leakage).
    -   Use `class_id` as the target for stratification to maintain class balance across splits.
    -   Set `random_state=42` for reproducibility.
4.  **Metadata Generation**: Save the resulting dataframes (`train_meta`, `val_meta`, `test_meta`) to the `./metadata` directory in CSV format.
5.  **Validation**:
    -   Print summary statistics (shape, unique images, class distribution).
    -   Programmatically verify file existence for a random sample of 1000 paths from each dataset. Raise an error if the missing file ratio exceeds 0.5.
    -   Verify the validation split by asserting no overlap in `image_id` between train and validation sets and checking that the split ratio is approximately 20%.
