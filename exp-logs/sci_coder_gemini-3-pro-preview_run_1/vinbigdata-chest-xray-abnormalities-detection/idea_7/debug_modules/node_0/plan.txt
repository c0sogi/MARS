### Implementation Strategy

1.  **Configuration Setup**: We will modify the global `Config` class attributes at runtime to adapt to a "demo" mode. This includes reducing the number of epochs to 1, setting a small batch size, and redirecting metadata paths to temporary subset files to ensure the script runs quickly (within minutes).
2.  **Data Subset Creation**: We will load the provided training metadata, sample a small subset of images (e.g., 20 images), and split them into training and validation sets. These subsets will be saved to the working directory.
3.  **Component Verification**:
    *   **Dataset**: Instantiate `ThoracicDataset` with the subset and verify the output shapes of images and targets (heatmaps, regression maps).
    *   **Model**: Instantiate `EfficientNetBiFPN`, perform a forward pass with a dummy batch, and assert the output shapes of the heads (heatmap, width/height, offset, global logits).
    *   **Loss**: Calculate the `CenterNetLoss` on the dummy outputs and targets to ensure the loss function returns a valid scalar.
4.  **Training Loop Execution**: Run `train_one_epoch` using the subset dataloader to verify the backpropagation and optimization steps.
5.  **Validation and Metric Calculation**: Run the `validate` function to generate predictions and calculate the mAP score using the provided `calculate_map` utility.
6.  **Inference Pipeline**: Execute the `run_inference` function on a small subset of the test data to demonstrate the end-to-end prediction and submission file generation process.
7.  **Cleanup**: Temporary files created during the execution will be managed within the working directory.
