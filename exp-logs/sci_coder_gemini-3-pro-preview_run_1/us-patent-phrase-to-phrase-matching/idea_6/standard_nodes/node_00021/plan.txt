The issue stems from `StratifiedGroupKFold` in scikit-learn requiring a discrete (categorical) target variable to perform stratification. The dataset's `score` column contains floating-point numbers (e.g., 0.0, 0.25), which scikit-learn identifies as a continuous target, triggering a `ValueError`. To resolve this, we cast the `score` column to strings within the `split` method, forcing scikit-learn to treat these discrete score values as class labels.
