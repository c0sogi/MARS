### 1. Model: DeBERTa-v3-Large with Multi-Sample Dropout
**Cite Lesson ID: solution_lesson_node_00002, solution_lesson_node_00005, solution_lesson_node_00010**

We will utilize the **`microsoft/deberta-v3-large`** backbone within a **Cross-Encoder** architecture. This model's disentangled attention mechanism provides the necessary capacity to resolve fine-grained semantic differences (**Cite Lesson 00010**), significantly outperforming Bi-Encoders (**Cite Lesson 00002**).

*   **Structural Innovation (Head Design):** We will replace the standard classification head with a **Multi-Sample Dropout (MSD)** head. Instead of a single dropout layer followed by a linear projection, this architecture instantiates multiple dropout masks (e.g., 5) in parallel. The token embeddings are passed through each mask, projected, and the results are averaged *before* calculating the loss. This acts as an internal ensemble within a single forward pass, smoothing the loss landscape and improving generalization. This structural change directly addresses the stability concerns raised in **Lesson 00011** and **Lesson 00019**.
*   **Base Configuration:** We will initialize the backbone using `AutoModelForSequenceClassification` to benefit from pre-trained weights, but we will override the classifier layer with the MSD module (**Cite Lesson 00005**).

### 2. Data: Hierarchical Semantic Context Injection
**Cite Lesson ID: solution_lesson_node_00001, solution_lesson_node_00010**

*   **Semantic Expansion:** We will evolve the context injection strategy from **Lesson 00001**. Instead of injecting the raw CPC code (e.g., "H04"), which is symbolic and abstract, we will parse the `input/description.md` file to map codes to their **full hierarchical natural language descriptions** (e.g., "H04" $\rightarrow$ "ELECTRICITY; ELECTRIC COMMUNICATION TECHNIQUE").
    *   **Input Format:** `[CLS] Context Hierarchy [SEP] Anchor [SEP] Target [SEP]`
    *   This ensures the Cross-Encoder conditions the similarity assessment on explicit semantic definitions rather than latent code associations.
*   **Splitting:** We will utilize **Stratified Group K-Fold Cross-Validation** (5 folds). We will group by the `anchor` phrase to strictly prevent "anchor leakage" (where the model memorizes the anchor's identity rather than its relationship) and stratify by the discrete `score` to maintain class balance (**Cite Lesson 00010**).

### 3. Training: Stabilized Regression with Layer-wise Decay
**Cite Lesson ID: solution_lesson_node_00007, solution_lesson_node_00011, solution_lesson_node_00018, solution_lesson_node_00019**

*   **Loss Function:** We will use **Mean Squared Error (MSE) Loss**. As established in **Lesson 00018**, MSE aligns geometrically with the Pearson correlation metric (which measures linear dependence), whereas BCE induces non-linear distortions that degrade performance even on bounded targets.
*   **Structural Innovation (Optimization):** To resolve the "fold collapse" and instability observed when training large models (**Cite Lesson 00011**), we will implement **Layer-wise Learning Rate Decay (LLRD)**. We will assign a high learning rate to the regression head and multiplicatively decay the rate (e.g., by 0.9x) for each subsequent lower layer of the Transformer. This ensures that the pre-trained linguistic features in the lower layers remain stable (preventing catastrophic forgetting) while the top layers adapt aggressively to the specific semantic similarity task (**Cite Lesson 00019**).
*   **Schedule:** We will adhere to a **short training horizon (3-4 epochs)** with a linear warmup. Extending training beyond this point yields diminishing returns and increases instability risk (**Cite Lesson 00011**).
*   **Hardware Optimization:** We will use **Mixed Precision (FP16)** and **Gradient Accumulation** to fit the large model and sufficient batch sizes into the GPU memory (**Cite Lesson 00010**).

### 4. Evaluation: Robust Ensemble Inference
**Cite Lesson ID: solution_lesson_node_00010**

*   **Inference:** We will generate predictions for the test set using all 5 models trained during the Stratified Group K-Fold Cross-Validation.
*   **Ensembling:** The final submission score for each pair will be the **arithmetic mean** of the predictions from the 5 folds. This ensemble approach mitigates the variance of individual models and leverages the full diversity of the training data to maximize the Pearson correlation score (**Cite Lesson 00010**).
