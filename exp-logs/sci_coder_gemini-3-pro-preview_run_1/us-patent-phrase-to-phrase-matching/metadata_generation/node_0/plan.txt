I will implement a Python script that generates metadata for the training, validation, and test datasets. The script will load the raw CSV files from the `./input` directory. It will then split the training data into a training set (80%) and a validation set (20%) using Stratified Sampling based on the `score` column to ensure the distribution of similarity scores remains consistent across splits. A fixed random state of 42 will be used for reproducibility. The resulting datasets will be saved as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory. Finally, the script will reload these generated metadata files to verify the split ratios, check the stratification quality, and print summary statistics. The file path verification step will be included but is expected to be skipped as the dataset consists of text phrases rather than file paths.
