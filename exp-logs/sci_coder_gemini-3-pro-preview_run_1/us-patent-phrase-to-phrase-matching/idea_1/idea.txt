# Baseline Approach: Siamese Bi-Encoder Transformer

## Model
The proposed model is a **Siamese Bi-Encoder** architecture that utilizes a lightweight, pre-trained Transformer backbone (such as `all-MiniLM-L6-v2`) with shared weights. Unlike the Cross-Encoder (Model 1) which processes pairs jointly, this architecture processes the `anchor` and `target` inputs independently through the same encoder.
1.  **Shared Encoder:** Both inputs pass through the Transformer to generate contextualized token embeddings.
2.  **Pooling:** A Mean Pooling operation is applied to the token embeddings to derive a single fixed-size vector representation for each phrase.
3.  **Similarity Head:** The final similarity score is calculated using the **Cosine Similarity** between the two resulting vectors. A simple learnable linear scaling ($score = w \cdot \cos(u, v) + b$) is applied to map the cosine output (typically -1 to 1) to the target score range (0 to 1).

## Data
To integrate the `context` (CPC classification) without requiring separate embedding layers or auxiliary inputs:
1.  **Context Prepending:** The raw context code is prepended to both the `anchor` and `target` text strings. For example, the input becomes `"[CLS] <context_code> [SEP] <phrase> [SEP]"`. This allows the self-attention mechanism to condition the phrase representation on the specific domain context.
2.  **Tokenization:** The modified strings are tokenized using the pre-trained Transformer's tokenizer with standard padding and truncation.

## Training
1.  **Objective:** The model is fine-tuned using **Mean Squared Error (MSE) Loss** between the predicted scaled cosine similarity and the ground truth `score`. This objective directly optimizes the vector space such that semantically similar phrases have smaller angular distances.
2.  **Optimization:** We use the **AdamW** optimizer with a standard learning rate (e.g., 2e-5) and a linear warmup scheduler.
3.  **Efficiency:** By using a "Mini" model and avoiding the quadratic complexity of cross-attending long concatenated sequences, this approach remains computationally lightweight and fast to train.

## Evaluation
During inference, the test set `anchor` and `target` phrases (with prepended contexts) are encoded into vectors. The Cosine Similarity is computed for each pair, passed through the learned linear scaler, and the result is clamped to the [0, 1] range to form the final prediction.
