The following implementation demonstrates the utilization of the provided library modules to train, evaluate, and run inference on the Phrase Similarity task.

**Implementation Strategy:**
1.  **Configuration**: We override specific settings in the `Config` class to enable `debug` mode (reducing dataset size to 100 samples) and reduce training epochs to 1. This ensures the script executes quickly while exercising all code paths.
2.  **Data Loading**: We use `cpc_loader` and `dataset` modules to parse CPC contexts and prepare the training, validation, and test dataframes.
3.  **Dataset Creation**: We instantiate `PhraseDataset` with a tokenizer and verify the structural integrity of the generated batches (input IDs, attention masks, and labels).
4.  **Model Initialization**: We load the `PhraseModel` (wrapping DeBERTa-v3-Large) and configure the optimizer using the Layer-wise Learning Rate Decay (LLRD) utility provided in `model.py`.
5.  **Training Loop**: We execute `engine.train_fn` which incorporates Mixed Precision training and Adversarial Weight Perturbation (AWP). We assert that the loss is a valid scalar.
6.  **Evaluation**: We run `engine.eval_fn` on the validation set and verify that the resulting Pearson correlation score is within the valid range [-1, 1].
7.  **Inference**: We generate predictions for the test set using `engine.inference_fn` and verify the output dimensions.
