The error `ValueError: Supported target types are: ('binary', 'multiclass'). Got 'continuous' instead` occurs because `StratifiedGroupKFold` in scikit-learn does not support stratification on floating-point targets, interpreting them as continuous regression targets rather than discrete classes. As detailed in **Cite debug_lesson_3**, the solution is to explicitly cast the score column to strings (e.g., `df["score"].astype(str)`) when passing it to the `split()` method. This forces the splitter to treat the scores as discrete multiclass labels, enabling correct stratification while preserving the original float values in the dataframe.
