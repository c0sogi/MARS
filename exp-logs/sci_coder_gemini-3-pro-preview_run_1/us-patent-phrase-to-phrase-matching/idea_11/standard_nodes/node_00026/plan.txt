Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment with a fixed random seed and logger. To strictly adhere to the 2-hour runtime limit while maintaining robust cross-validation, I will override the default configuration to use 4 folds and 3 epochs (instead of 5 folds and 4 epochs).
2.  **Data Preparation**: Load the stratified metadata files (`train.csv`, `val.csv`, `test.csv`). The `train.csv` will be used for the Cross-Validation loop, while `val.csv` will serve as the unseen hold-out set for the final metric calculation.
3.  **Model Training (CV Loop)**: Implement a Stratified Group K-Fold loop (grouping by `anchor`) on the training data. Inside each fold:
    *   Initialize the `DeBERTa-v3-Large` model with a standard regression head.
    *   Configure the optimizer with Layer-wise Learning Rate Decay (LLRD) to stabilize training.
    *   Train for 3 epochs using a Cosine schedule with warmup.
    *   Generate predictions on both the hold-out validation set and the test set.
4.  **Ensemble & Evaluation**: Average the predictions across all folds. Compute the Pearson correlation coefficient on the hold-out validation set to produce the "Final Validation Metric".
5.  **Failure Analysis**: Calculate the absolute error of the predictions on the validation set and compute correlations with input features (ground truth score, anchor length, target length) to identify error sources.
6.  **Submission**: If the final metric surpasses the threshold of 0.8673, format and save the test predictions to `./submission/submission.csv`.
