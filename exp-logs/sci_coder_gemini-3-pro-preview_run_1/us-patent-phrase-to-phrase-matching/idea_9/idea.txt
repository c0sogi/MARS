### 1. Model: DeBERTa-v3-Large Cross-Encoder with Multi-Sample Dropout
**Cite Lesson ID: solution_lesson_node_00002, solution_lesson_node_00010, solution_lesson_node_00019, solution_lesson_node_00024**

We will utilize the **`microsoft/deberta-v3-large`** backbone within a **Cross-Encoder** architecture. This model provides the necessary capacity to resolve fine-grained semantic differences (**Cite Lesson 00010**).

*   **Structural Innovation (Head Design):** We will employ a **Multi-Sample Dropout (MSD)** head. This module instantiates multiple dropout masks in parallel, projects the outputs, and averages them before the final regression neuron. This acts as an internal ensemble to stabilize the loss landscape (**Cite Lesson 00019**).
*   **Strategic Simplification:** We explicitly **discard** the Weighted Layer Pooling (WLP) and EMA components proposed in Idea 8. As established in **Lesson 00024**, these complex regularization techniques slow down convergence. Given the time limit, a simpler MSD head trained to full convergence (3-4 epochs) will outperform a complex head that is under-trained.

### 2. Data: Three-Stage Semantic Input via Native Pair Encoding
**Cite Lesson ID: solution_lesson_node_00001, solution_lesson_node_00022**

*   **Semantic Expansion:** We will parse the `input/description.md` file to map CPC codes to their **full hierarchical natural language descriptions** (e.g., "H04" $\rightarrow$ "ELECTRICITY; ELECTRIC COMMUNICATION TECHNIQUE").
*   **Structural Innovation (Input Construction):** We will implement a **Three-Stage Semantic Input** strategy using the tokenizer's native pair handling.
    *   Instead of simply concatenating the context and anchor with a space (which blurs the boundary between the domain definition and the phrase), we will insert a special separator token between them within the first segment.
    *   **Segment A (Text):** `Context Description + " [SEP] " + Anchor Phrase`
    *   **Segment B (Text Pair):** `Target Phrase`
    *   We will pass these as `text` and `text_pair` arguments to the tokenizer (**Cite Lesson 00022**). This results in a sequence structure like `[CLS] Context [SEP] Anchor [SEP] Target [SEP]`. This allows the model's attention mechanism to explicitly distinguish three distinct information blocks: the Domain Definition, the Anchor, and the Target, while correctly assigning segment IDs to distinguish the "Query" side from the "Candidate" side.

### 3. Training: Stabilized Regression with Layer-wise Decay
**Cite Lesson ID: solution_lesson_node_00007, solution_lesson_node_00011, solution_lesson_node_00018, solution_lesson_node_00019**

*   **Loss Function:** We will use **Mean Squared Error (MSE) Loss**. We reject Binary Cross Entropy (BCE) because MSE aligns geometrically with the Pearson correlation metric (linear dependence), whereas BCE induces non-linear distortions (**Cite Lesson 00018**).
*   **Optimization:** We will use the AdamW optimizer with **Layer-wise Learning Rate Decay (LLRD)**. We will assign a high learning rate to the MSD head and multiplicatively decay the rate (e.g., 0.9x) for each lower layer. This is critical for stabilizing the training of the Large backbone (**Cite Lesson 00019**).
*   **Schedule:** We will set the training duration to **4 epochs**. This strikes the optimal balance between the under-training observed at 2 epochs (**Cite Lesson 00024**) and the instability/diminishing returns observed at 5 epochs (**Cite Lesson 00011**).
*   **Hardware Optimization:** We will use **Mixed Precision (FP16)** and **Gradient Accumulation** to fit the large model into GPU memory (**Cite Lesson 00010**).

### 4. Evaluation: Stratified Group K-Fold Ensemble
**Cite Lesson ID: solution_lesson_node_00010**

*   **Validation Strategy:** We will employ **Stratified Group K-Fold Cross-Validation** (5 folds).
    *   **Grouping:** We will group by the `anchor` phrase. This is essential to prevent "anchor leakage," ensuring that the model cannot simply memorize the characteristics of a specific anchor seen during training (**Cite Lesson 00010**).
    *   **Stratification:** We will stratify by the discrete `score` to ensure consistent class distribution across folds.
*   **Inference:** We will generate predictions for the test set using all 5 models trained during the CV phase. The final score will be the **arithmetic mean** of these predictions, reducing variance and maximizing the Pearson correlation.
