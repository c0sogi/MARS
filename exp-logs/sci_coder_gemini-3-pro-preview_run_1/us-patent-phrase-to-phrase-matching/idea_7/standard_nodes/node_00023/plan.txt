The implementation strategy follows a strict "Fast Baseline" approach while satisfying all constraints:

1.  **Configuration Override**: We override `Config.epochs` to 2 to ensure the training completes well within the 2-hour limit while still providing sufficient convergence for the DeBERTa-Large model.
2.  **Data Management**: We utilize `prepare_data(load_cached_data=True)` to leverage cached preprocessing. Crucially, we manually reconstruct the fixed training and hold-out validation sets using the IDs from the `./metadata` CSVs. This ensures we strictly adhere to the requirement of using the specific hold-out validation set, rather than a random CV fold.
3.  **Training**: We train a single model instance (designated as "Fold 0") on this fixed split. This significantly reduces runtime compared to a full 5-fold cross-validation.
4.  **Validation & Analysis**: We reload the trained model to perform inference on the hold-out validation set. We compute the Pearson correlation and perform the required failure analysis by correlating prediction errors with input text lengths.
5.  **Submission**: We conditionally execute the inference pipeline. We temporarily set `Config.n_folds = 1` to instruct the `run_inference` function to use only our single trained model for generating the test set predictions.
