Based on the analysis of the provided lessons and the iterative development of previous ideas, here is the optimized strategy.

### 1. Model: DeBERTa-v3-Large Cross-Encoder with Multi-Sample Dropout
**Cite Lesson ID: solution_lesson_node_00002, solution_lesson_node_00005, solution_lesson_node_00010, solution_lesson_node_00019**

We will utilize the **`microsoft/deberta-v3-large`** backbone within a **Cross-Encoder** architecture. This model's disentangled attention mechanism provides the necessary capacity to resolve fine-grained semantic differences (**Cite Lesson 00010**), significantly outperforming Bi-Encoders (**Cite Lesson 00002**).

*   **Structural Innovation (Head Design):** We will enhance the standard `AutoModelForSequenceClassification` head with **Multi-Sample Dropout (MSD)**. While **Lesson 00005** recommends using standardized heads, **Lesson 00019** demonstrated that MSD (instantiating multiple dropout masks in parallel and averaging the output) was a key component in stabilizing the training of this large model. This acts as an internal ensemble within a single forward pass, smoothing the loss landscape.

### 2. Data: Hierarchical Context Injection via Native Pair Encoding
**Cite Lesson ID: solution_lesson_node_00001, solution_lesson_node_00010, solution_lesson_node_00022**

*   **Semantic Expansion:** We will parse the `input/description.md` file to map CPC codes to their **full hierarchical natural language descriptions** (e.g., "H04" $\rightarrow$ "ELECTRICITY; ELECTRIC COMMUNICATION TECHNIQUE"). This provides the model with explicit semantic definitions rather than abstract codes (**Cite Lesson 00001**).
*   **Structural Innovation (Input Construction):** We will strictly implement **Native Pair Encoding**. Previous attempts to inject context failed because they manually concatenated strings (e.g., `context + sep + anchor + sep + target`), which confused the tokenizer's special token handling. We will instead construct two distinct text segments:
    *   **Segment A:** `Context Description + " " + Anchor`
    *   **Segment B:** `Target`
    *   We will pass these as separate arguments to the tokenizer: `tokenizer(text=Segment_A, text_pair=Segment_B)`. This ensures the model generates the correct `token_type_ids`, allowing the self-attention mechanism to explicitly distinguish between the "context-conditioned anchor" and the "target" (**Cite Lesson 00022**).
*   **Splitting:** We will use **Stratified Group K-Fold Cross-Validation** (5 folds), grouping by `anchor` to prevent leakage and stratifying by `score` (**Cite Lesson 00010**).

### 3. Training: Stabilized Regression with Layer-wise Decay
**Cite Lesson ID: solution_lesson_node_00007, solution_lesson_node_00011, solution_lesson_node_00018, solution_lesson_node_00019**

*   **Loss Function:** We will use **Mean Squared Error (MSE) Loss**. We explicitly reject Binary Cross Entropy (BCE) because, as established in **Lesson 00018**, MSE aligns geometrically with the Pearson correlation metric (linear dependence), whereas BCE induces non-linear distortions that degrade performance on this specific metric.
*   **Structural Innovation (Optimization):** To address the "fold collapse" and instability observed in **Lesson 00011**, we will implement **Layer-wise Learning Rate Decay (LLRD)**. We will assign a high learning rate to the MSD head and multiplicatively decay the rate (e.g., by 0.9x) for each subsequent lower layer of the Transformer. This ensures that the pre-trained linguistic features in the lower layers remain stable while the top layers adapt aggressively (**Cite Lesson 00019**).
*   **Schedule:** We will adhere to a **short training horizon (3-4 epochs)**. Extending training beyond this point yields diminishing returns and increases the risk of instability (**Cite Lesson 00011**).
*   **Hardware Optimization:** We will use **Mixed Precision (FP16)** and **Gradient Accumulation** to fit the large model into GPU memory (**Cite Lesson 00010**).

### 4. Evaluation: Robust Ensemble Inference
**Cite Lesson ID: solution_lesson_node_00010**

*   **Inference:** We will generate predictions for the test set using all 5 models trained during the Stratified Group K-Fold Cross-Validation.
*   **Ensembling:** The final submission score for each pair will be the **arithmetic mean** of the predictions from the 5 folds. This ensemble approach mitigates the variance of individual models and leverages the full diversity of the training data (**Cite Lesson 00010**).
