The issue is that `library/model.py` invokes the `run_kfold_training()` function at the global scope (line 224). When `runfile.py` imports the `PhraseSimilarityModel` class from `library/model.py`, this global function call is executed immediately, triggering the full, time-consuming training pipeline instead of the intended lightweight demonstration. This causes the execution to time out. The fix is to wrap the `run_kfold_training()` call in an `if __name__ == "__main__":` block, ensuring it only runs when the script is executed directly and not when imported as a module.
