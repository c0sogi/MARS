To fix this, I will modify `library/data.py` to use only the training metadata for bag generation and disable cache loading to prevent the use of stale indices derived from the merged dataset. I will also update `runfile.py` to calculate class weights using only the training data and lower the submission threshold to a realistic value (0.80) to account for the corrected, non-inflated validation metric.
