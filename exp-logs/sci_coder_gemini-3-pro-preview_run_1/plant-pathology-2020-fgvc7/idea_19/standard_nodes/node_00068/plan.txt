Implementation Strategy:
1.  **Initialization**: Set random seeds and detect the computation device (GPU) using the provided `library.utils` and `library.config`.
2.  **Data Preparation**: Load the training and validation metadata using `trainer.get_all_data()`, merging them into a single dataframe. Apply Stratified K-Fold splitting (5 folds) using `trainer.get_folds()` to ensure balanced class distribution. Calculate class weights to address the imbalance.
3.  **Iterative Training & Validation**: Loop through all 5 folds. For each fold:
    *   Execute the training pipeline using `trainer.run_fold()`, which handles model initialization, training with Soft-Target Cross-Entropy, Cosine Annealing scheduling, and saving the best checkpoint based on validation AUC.
    *   Reload the best-saved model for the current fold.
    *   Perform inference on the validation subset of the current fold to generate Out-Of-Fold (OOF) probability predictions.
4.  **Global Evaluation**: Aggregate OOF predictions from all folds and compute the Mean Column-wise ROC AUC against the ground truth targets. This provides a robust estimate of model performance on the entire dataset.
5.  **Failure Analysis**: Compute the error magnitude (1 - probability of the correct class) for each sample. Extract meta-features (image width, height, and mean intensity) and calculate their correlation with the error to identify systematic failure modes.
6.  **Submission Generation**: Compare the final validation metric against the required threshold (0.990168...). If the threshold is met, invoke `inference.generate_submission()` to produce the final `submission.csv` using the ensemble of all 5 trained models.
