The `AssertionError` in `runfile.py` is caused by Python's default argument evaluation behavior. The `get_loaders` function in `library/dataset.py` defines `batch_size=Config.BATCH_SIZE` as a default argument, which binds the value of `Config.BATCH_SIZE` (32) at import time. Although `runfile.py` updates `Config.BATCH_SIZE` to 8 at runtime, calling `get_loaders(load_cached_data=True)` without an explicit `batch_size` uses the stale default value of 32. This causes the assertion `images.shape == (Config.BATCH_SIZE, ...)` to fail because 32 does not equal 8. The fix is to explicitly pass the updated `Config.BATCH_SIZE` when calling `get_loaders` in `runfile.py`.
