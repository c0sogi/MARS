Implementation Strategy:
1.  **Setup & Configuration**: Import the provided library modules. Override `Config` settings to drastically reduce runtime (1 epoch burn-in, 1 epoch SWA, small batch size) and disable pretrained weight downloading to ensure offline execution speed.
2.  **Data Subsetting**: Manually create small subsets (32 training samples, 16 test samples) from the metadata CSVs and save them as Parquet files in the expected cache location. This tricks the `get_loaders` function into loading this tiny dataset, ensuring the training loop completes almost instantly.
3.  **Component Verification**:
    *   **Utils**: Verify `calculate_class_weights` returns a tensor of correct shape.
    *   **Dataset**: Initialize loaders and verify batch dimensions (B, C, H, W) and data types.
    *   **Model**: Instantiate the model and perform a dummy forward pass to check output shape (B, Num_Classes).
4.  **Integration Testing**:
    *   **Training**: Run `run_swa_training()` to execute the full training pipeline on the subset. Verify the model artifact is saved.
    *   **Inference**: Run `predict_and_submit()` using the trained model. Verify the submission file is generated with the correct schema and row count matching the test subset.
