My optimization strategy focuses on replacing the Stochastic Weight Averaging (SWA) training routine with a standard training loop utilizing a **Cosine Annealing Learning Rate Scheduler**.

**Rationale:**
1.  **Learning Rate Schedule vs. SWA**: As identified in Lesson `solution_lesson_node_00028` (Cite solution_lesson_node_00028), SWA with a constant learning rate often underperforms on small datasets with limited epoch budgets compared to a dynamic schedule. The previous solution's failure to converge to a high metric suggests the constant LR prevented the model from reaching a sharp minimum.
2.  **Scheduler Synchronization**: Following Lesson `solution_lesson_node_00015` (Cite solution_lesson_node_00015), I will synchronize the scheduler's cycle length (`T_0`) exactly with the total number of epochs (15) to ensure the learning rate decays fully to the minimum value, facilitating effective fine-tuning.
3.  **Augmentation & Depth**: I am retaining the ResNet34 architecture and the robust augmentation pipeline (ShiftScaleRotate, RandomBrightnessContrast) which were proven effective in Lesson `solution_lesson_node_00003` (Cite solution_lesson_node_00003).

**Changes:**
-   **`library/config.py`**: Increased `EPOCHS` to 15 and removed SWA-specific parameters. Added `MIN_LR`.
-   **`library/engine.py`**: Removed the unused `run_swa_training` function.
-   **`runfile.py`**: Replaced the SWA setup with a standard optimizer and `CosineAnnealingWarmRestarts` scheduler.

def run_swa_training():
    """
    Executes the SWA training pipeline: Burn-in -> SWA Collection -> BN Update.

    Returns:
        torch.nn.Module: The trained SWA model.
    """
    # 1. Load Data
    # load_cached_data=True uses the cache generated by utils/dataset if available
    train_loader, _ = get_loaders(load_cached_data=True)

    # 2. Setup Class Weights
    class_weights = calculate_class_weights(
        metadata_path=Config.TRAIN_METADATA_PATH,
        target_columns=Config.CLASS_LABELS,
        load_cached_data=True,
    )

    # 3. Initialize Model and Optimizer
    model = get_model(pretrained=Config.PRETRAINED)
    model = model.to(Config.DEVICE)

    # SWA Model Wrapper
    swa_model = AveragedModel(model).to(Config.DEVICE)

    optimizer = torch.optim.Adam(
        model.parameters(), lr=Config.LEARNING_RATE, weight_decay=Config.WEIGHT_DECAY
    )

    criterion = nn.CrossEntropyLoss(weight=class_weights)

    print(f"Starting SWA Training on {Config.DEVICE}...")
    print(f"Burn-in: {Config.BURN_IN_EPOCHS} epochs | SWA: {Config.SWA_EPOCHS} epochs")

    # 4. Burn-in Phase
    for epoch in range(1, Config.BURN_IN_EPOCHS + 1):
        loss = train_one_epoch(model, train_loader, optimizer, criterion, Config.DEVICE)
        print(f"Epoch {epoch}/{Config.EPOCHS} (Burn-in) - Loss: {loss:.10f}")

    # 5. SWA Phase
    print("Starting SWA Collection Phase...")
    for epoch in range(Config.BURN_IN_EPOCHS + 1, Config.EPOCHS + 1):
        loss = train_one_epoch(model, train_loader, optimizer, criterion, Config.DEVICE)
        print(f"Epoch {epoch}/{Config.EPOCHS} (SWA) - Loss: {loss:.10f}")

        # Update SWA parameters
        swa_model.update_parameters(model)

    # 6. Update Batch Normalization Statistics
    print("Updating SWA Batch Normalization statistics...")
    update_bn(train_loader, swa_model, device=Config.DEVICE)

    # 7. Save Model
    save_path = os.path.join(Config.MODEL_OUTPUT_DIR, "swa_model.pth")
    torch.save(swa_model.state_dict(), save_path)
    print(f"SWA model saved to {save_path}")

    return swa_model
