### Implementation Strategy

1.  **Configuration Override**: To strictly comply with the requirement of validating on the hold-out set, I will override `Config.USE_FULL_DATA` to `False` immediately. This ensures the training data loader only loads the training split, keeping the validation set unseen.
2.  **Data Loading**:
    *   I will manually load the `train_metadata.csv` and `val_metadata.csv` using pandas.
    *   I will instantiate `AppleDataset` for both training and validation sets.
    *   I will use the provided `get_transforms` for augmentation (train) and resizing/normalization (validation).
3.  **Model & SWA Initialization**:
    *   I will initialize the ResNet34 model using `get_model`.
    *   I will wrap the model in `AveragedModel` from `torch.optim.swa_utils` to implement Stochastic Weight Averaging.
    *   I will calculate class weights using the provided utility to handle class imbalance.
4.  **Training Loop**:
    *   **Burn-in Phase**: Train for `Config.BURN_IN_EPOCHS` (10) using the standard `train_one_epoch` function from the library.
    *   **SWA Phase**: Train for `Config.SWA_EPOCHS` (5). At the end of each epoch, update the SWA model parameters.
    *   **BN Update**: Perform a final pass over the training data to update Batch Normalization statistics for the SWA model.
5.  **Validation & Metric**:
    *   Perform inference on the validation set using the SWA model.
    *   Calculate the Mean Column-wise ROC AUC using `sklearn.metrics.roc_auc_score`.
    *   Print the metric in the exact required format.
6.  **Failure Analysis**:
    *   Compute the Cross-Entropy loss for each validation sample to quantify "error magnitude".
    *   Extract simple meta-features (Mean Pixel Intensity) for each validation image.
    *   Calculate and print the Pearson correlation between error magnitude and image intensity to identify systematic failures related to lighting/brightness.
7.  **Submission**:
    *   Compare the validation metric against the threshold (0.9871488489626378).
    *   If the condition is met, use the `predict_and_submit` function from the library to generate the `submission.csv` file using Test-Time Augmentation (TTA).
