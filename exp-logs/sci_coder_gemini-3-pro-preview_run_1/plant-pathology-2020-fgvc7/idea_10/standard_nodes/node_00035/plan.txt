Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class, ensuring reproducibility with `seed_everything`.
2.  **Calibration Phase (Proxy Validation)**:
    *   Implement a 5-Fold Stratified Cross-Validation loop manually within the script (instead of calling `run_calibration`) to retain full control over metrics and predictions.
    *   For each fold, train the ResNet34 model for 15 epochs using `train_one_epoch`.
    *   For **Fold 0**, explicitly capture validation predictions, targets, and metadata for every epoch to enable detailed failure analysis later.
    *   For Folds 1-4, use the standard `validate_one_epoch` to track performance.
    *   Calculate the **Mean Column-wise ROC AUC** across all folds for each epoch.
3.  **Optimal Epoch Identification**:
    *   Identify the epoch ($E_{opt}$) where the mean validation AUC is maximized.
    *   Define the **Final Validation Metric** as this peak mean AUC score.
4.  **Failure Analysis**:
    *   Retrieve the predictions from Fold 0 corresponding to $E_{opt}$.
    *   Calculate the error magnitude (1 - probability of true class) for each validation sample.
    *   Compute correlations between this error and image metadata (Width, Height, Intensity) to identify systematic weaknesses.
5.  **Production Training**:
    *   If the Final Validation Metric exceeds the specified threshold (`0.9871488489626378`), proceed to the production phase.
    *   Call `train_final_model` to retrain the model on **100% of the data** (Train + Val) for exactly $E_{opt}$ epochs.
6.  **Inference & Submission**:
    *   Use the production model to generate predictions on the test set via `predict_and_submit`.
