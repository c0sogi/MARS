The following script demonstrates the end-to-end execution of the Apple Disease Detection pipeline using the provided library files.

**Strategy:**
1.  **Configuration Override**: We first modify the `Config` class attributes to reduce the computational load (1 epoch, 2 folds, 1 seed, smaller images) ensuring the script completes quickly while exercising all code paths.
2.  **Data Pipeline Verification**: We instantiate the DataLoaders and verify the structure of the batches (image shapes, label shapes) and the correctness of class weights.
3.  **Model Logic Verification**: We initialize the ResNet34 model and explicitly run the `verify_initialization` function to confirm the custom head initialization strategy works as expected. We also verify the forward pass output shapes.
4.  **Workflow Execution**: We execute the `AppleDiseaseWorkflow` class, running through Phase 1 (CV calibration), Phase 2 (Production training), and Submission generation.
5.  **Output Validation**: Finally, we check that the submission file is generated correctly and adheres to the expected format.
