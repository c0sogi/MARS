The issue is caused by the default security setting `weights_only=True` in `torch.load` (present in the installed PyTorch version), which prevents loading checkpoints containing arbitrary Python objects like NumPy arrays. In `runfile.py`, the code saves validation logits and image IDs as NumPy arrays into a temporary checkpoint and later attempts to load them, triggering a `_pickle.UnpicklingError`.
