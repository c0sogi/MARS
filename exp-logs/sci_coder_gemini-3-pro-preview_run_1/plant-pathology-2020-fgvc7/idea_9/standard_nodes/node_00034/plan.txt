The following modifications implement a strategy to optimize performance by reverting the Stochastic Weight Averaging (SWA) approach and replacing it with a robust "Best Checkpoint" strategy using Test-Time Augmentation (TTA) during validation.

**Strategy:**
1.  **Remove SWA**: Based on **Lesson 00032**, SWA can degrade performance on small datasets if the training trajectory does not circle the optimum effectively. We revert to a standard training loop.
2.  **Metric-Based Checkpointing**: We implement logic to save the model weights that achieve the highest validation AUC during training, rather than using the final epoch's weights. This directly addresses **Lesson 00031** ("Validation Checkpointing vs. Final State Evaluation").
3.  **Validation-Inference Parity**: We introduce `evaluate_tta` to perform validation using the same Test-Time Augmentation (Horizontal and Vertical flips) used for the final submission. This ensures we optimize for the actual inference pipeline and captures performance gains that single-view validation misses (**Lesson 00033**).
4.  **Optimization Schedule**: We utilize a standard `CosineAnnealingLR` schedule over 15 epochs to ensure convergence, consistent with the successful baseline in **Lesson 00003**.

def predict_tta(model, dataloader, device):
    """
    Performs inference on the test set using Test-Time Augmentation (TTA).
    Averages predictions from: Original, Horizontal Flip, and Vertical Flip.

    Args:
        model (torch.nn.Module): The trained model.
        dataloader (torch.utils.data.DataLoader): Test dataloader (returns image, image_id).
        device (str): The device to use for inference.

    Returns:
        pd.DataFrame: DataFrame containing image_ids and predicted probabilities.
    """
    model.eval()

    all_image_ids = []
    all_probs = []

    with torch.no_grad():
        for images, image_ids in dataloader:
            images = images.to(device)

            # 1. Original Image
            outputs_orig = model(images)
            probs_orig = F.softmax(outputs_orig, dim=1)

            # 2. Horizontal Flip (dim 3 is width)
            images_h = torch.flip(images, dims=[3])
            outputs_h = model(images_h)
            probs_h = F.softmax(outputs_h, dim=1)

            # 3. Vertical Flip (dim 2 is height)
            images_v = torch.flip(images, dims=[2])
            outputs_v = model(images_v)
            probs_v = F.softmax(outputs_v, dim=1)

            # Average the probabilities
            avg_probs = (probs_orig + probs_h + probs_v) / 3.0

            all_probs.append(avg_probs.cpu().numpy())
            all_image_ids.extend(image_ids)

    # Concatenate all batch results
    predictions = np.concatenate(all_probs, axis=0)

    # Create DataFrame
    df = pd.DataFrame(predictions, columns=Config.CLASS_LABELS)
    df.insert(0, "image_id", all_image_ids)

    return df
