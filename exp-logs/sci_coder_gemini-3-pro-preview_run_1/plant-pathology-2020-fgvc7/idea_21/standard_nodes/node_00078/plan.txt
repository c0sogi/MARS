Implementation strategy:
1.  **Configuration & Setup**: Import the provided library modules. Override `Config` parameters to ensure execution within the 14-minute limit (5 splits, 8 epochs, batch size 64). Initialize the device and random seeds.
2.  **Training Pipeline**: Iterate through the defined number of splits (5). For each split, invoke `train_single_fold` from the library to train a ResNet34 model using the SAM optimizer and save the best checkpoint.
3.  **Ensemble Evaluation**: Implement a custom evaluation function to load the fixed hold-out validation set (`val_metadata.csv`). Load all trained models, perform inference, average the predictions (soft voting), and calculate the Mean Column-wise ROC AUC.
4.  **Failure Analysis**: Compute the mean absolute error for each validation sample. Extract image meta-features (width, height, intensity) and calculate their correlation with the error magnitude to identify systematic failures.
5.  **Submission**: Check if the validation metric exceeds the strict threshold (0.990168...). If passed, invoke `generate_submission` to create the final predictions on the test set.
