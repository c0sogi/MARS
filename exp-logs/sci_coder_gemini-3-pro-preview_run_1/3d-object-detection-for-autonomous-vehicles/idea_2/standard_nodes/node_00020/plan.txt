The solution strategy focuses on correcting the coordinate frame mismatch identified as the root cause of the previous failure (Lesson `solution_lesson_node_00017`) and improving the feature map granularity (Lesson `solution_lesson_node_00019`).

1.  **Coordinate Transformation (Global $\leftrightarrow$ Sensor):**
    *   The previous model failed to learn because it attempted to map global coordinates (e.g., x=1800m) onto a local BEV grid (±100m), resulting in zero valid targets.
    *   I will modify `BEVDataset` to load the `ego_pose` and `calibrated_sensor` metadata.
    *   In `__getitem__`, I will calculate the transformation matrix from Global to Sensor frame.
    *   For training, I will transform the ground truth annotations from Global to Sensor frame before generating heatmaps.
    *   For inference, I will pass the inverse transformation (Sensor to Global) to the predictor to ensure the submission uses the required global coordinates.

2.  **Resolution Optimization:**
    *   The previous resolution of 0.8m/pixel was too coarse for the DLA-34 backbone to resolve objects effectively.
    *   I will increase the resolution to **0.4m/pixel** (Input Size: 512x512). This provides a 4x increase in pixel density, allowing the model to better capture object dimensions and orientation while remaining computationally feasible within the time limit.

3.  **Configuration:**
    *   Update `WORKING_DIR` to `idea_3` to ensure clean caching.
    *   Update `BEV_RESOLUTION` and `INPUT_SIZE`.

    def _get_transform_matrix(self, sample_token):
        """
        Computes the transformation matrix from Global to Sensor frame.
        Returns:
            global_to_sensor (4x4), sensor_to_global (4x4), yaw_correction (float)
        """
        if sample_token not in self.sample_to_lidar:
            # Fallback (Identity)
            return np.eye(4), np.eye(4), 0.0

        sd = self.sample_to_lidar[sample_token]
        ego = self.ego_pose_map[sd["ego_pose_token"]]
        calib = self.calib_sensor_map[sd["calibrated_sensor_token"]]

        # Global -> Ego
        # T_global_ego = [R_ego | t_ego]
        # We need inv(T_global_ego)
        
        # Rotation (Quaternion to Matrix)
        def q_to_rot(q):
            # q = [w, x, y, z]
            w, x, y, z = q
            return np.array([
                [1 - 2*y*y - 2*z*z, 2*x*y - 2*z*w, 2*x*z + 2*y*w],
                [2*x*y + 2*z*w, 1 - 2*x*x - 2*z*z, 2*y*z - 2*x*w],
                [2*x*z - 2*y*w, 2*y*z + 2*x*w, 1 - 2*x*x - 2*y*y]
            ])

        R_ego = q_to_rot(ego["rotation"])
        t_ego = np.array(ego["translation"])
        
        # T_ego_global (Ego to Global)
        T_ego_global = np.eye(4)
        T_ego_global[:3, :3] = R_ego
        T_ego_global[:3, 3] = t_ego

        # Ego -> Sensor
        R_calib = q_to_rot(calib["rotation"])
        t_calib = np.array(calib["translation"])
        
        # T_sensor_ego (Sensor to Ego)
        T_sensor_ego = np.eye(4)
        T_sensor_ego[:3, :3] = R_calib
        T_sensor_ego[:3, 3] = t_calib

        # T_sensor_global = T_ego_global @ T_sensor_ego
        T_sensor_global = T_ego_global @ T_sensor_ego
        
        # T_global_sensor = inv(T_sensor_global)
        T_global_sensor = np.linalg.inv(T_sensor_global)

        # Yaw correction
        # Yaw_global = Yaw_sensor + Yaw_bias
        # Yaw_bias is the yaw component of T_sensor_global
        # We can extract it from the rotation matrix
        # yaw = atan2(R[1,0], R[0,0])
        yaw_bias = np.arctan2(T_sensor_global[1, 0], T_sensor_global[0, 0])

        return T_global_sensor, T_sensor_global, yaw_bias
