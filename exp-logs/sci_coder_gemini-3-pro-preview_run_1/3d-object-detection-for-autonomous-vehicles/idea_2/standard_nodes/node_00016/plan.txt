    *   Print the result as `Final Validation Metric: <value>`.

4.  **Failure Analysis**:

    *   Calculate the correlation between "Error Magnitude" (spatial distance between predicted and ground truth centers) and "Input Features" (Ground Truth Depth/Distance and Volume).
    *   Print these correlations to identify systematic errors.

5.  **Submission**:
    *   Check if the validation metric exceeds the threshold (0.0876104272).
