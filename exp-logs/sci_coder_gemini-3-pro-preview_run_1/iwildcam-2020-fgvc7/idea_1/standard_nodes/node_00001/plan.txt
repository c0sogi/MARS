This script implements a fast baseline for the camera trap animal classification task.

**Implementation Strategy:**
1.  **Initialization**: We set the random seed for reproducibility and initialize the `Trainer` class. We restrict the dataset size to 20,000 samples and training to 5 epochs to ensure the script completes quickly (well within the 2-hour limit) while still learning useful features.
2.  **Training**: We execute the training loop using `trainer.fit()`, which handles the forward/backward passes, loss calculation (weighted cross-entropy), and validation monitoring.
3.  **Best Model Loading**: Before evaluation, we explicitly load the weights from the best epoch (saved by the trainer) to ensure our metrics reflect the optimal model performance.
4.  **Validation & Metrics**: We run inference on the validation set to calculate the categorization accuracy. This is printed as `Final Validation Metric` as required.
5.  **Failure Analysis**: We analyze the validation results by correlating the prediction error with two input features:
    *   `Is_Empty`: Whether the image actually contains an animal (Category 0 vs others).
    *   `Class_Frequency`: How common the specific animal class is in the training set.
    This helps identify if the model struggles with empty images or rare species.
6.  **Submission**: Finally, we generate the submission CSV for the test set using the trained model.
