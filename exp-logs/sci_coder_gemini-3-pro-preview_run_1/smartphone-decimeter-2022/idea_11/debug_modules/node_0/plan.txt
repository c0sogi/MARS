The following Python script demonstrates how to instantiate and utilize the classes and functions from the provided library files (`utils.py`, `data.py`, `model.py`, `train.py`, `inference.py`).

### Strategy:
1.  **Setup**: Initialize paths and random seeds using `library.utils`.
2.  **Utils**: Verify coordinate conversion functions (Geodetic <-> ECEF <-> ENU) with assertions.
3.  **Data**: Load a small subset of the training data using `library.data.load_data` with `max_drives=1` to ensure speed. Inspect the resulting `SmartphoneDataset` and features.
4.  **Model**: Instantiate the `ResUNet1D` model from `library.model` using the input dimensions derived from the loaded data. Perform a dummy forward pass to verify output shapes.
5.  **Training**: Execute the `train_model` function from `library.train` for a single epoch with a limited dataset to demonstrate the training loop and model checkpointing.
6.  **Inference**: Create a temporary "mini" test metadata file containing only one trip to limit the scope of the inference run. Monkeypatch the `TEST_META` constant in `library.inference` to point to this mini file, then run `generate_submission` to produce a submission file.
