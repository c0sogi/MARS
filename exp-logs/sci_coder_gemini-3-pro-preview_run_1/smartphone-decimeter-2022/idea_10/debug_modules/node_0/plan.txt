This script demonstrates the end-to-end usage of the provided GNSS positioning library. It performs the following steps:
1.  **Configuration**: Overrides default configuration to use a temporary working directory and reduces training epochs/batch size for speed.
2.  **Data Loading**: Loads a small subset of the training and validation metadata to demonstrate data preprocessing without processing the entire dataset.
3.  **Dataset Creation**: Instantiates `GNSSSequenceDataset` and `DataLoader` to prepare data for the PyTorch model.
4.  **Model Initialization**: Instantiates the `TransUNet1D` model and verifies its output shape.
5.  **Training**: Runs a single epoch of training using the `Trainer` class.
6.  **Inference**: Generates predictions for a subset of the test data using the trained model and the `generate_predictions` pipeline.
