This script orchestrates the training, validation, and submission generation for the GNSS location correction task. It implements the **Geometric-Aware 1D ResUNet** strategy.

**Strategy Outline:**
1.  **Configuration**: Overrides default epochs to 15 for a fast but effective baseline training session.
2.  **Training**: Executes the training loop using the provided `train_model` function, which handles data loading, model optimization, and checkpointing.
3.  **Validation & Metrics**: Re-loads the best model and runs inference on the hold-out validation set. It computes the official competition metric (mean of per-phone 50th/95th percentile errors) to ensure accurate evaluation.
4.  **Failure Analysis**: Aggregates prediction errors and input features from the validation set to calculate Pearson correlations, identifying which features (e.g., signal strength, elevation) correlate most with location error.
5.  **Submission**: Checks if the validation metric meets the threshold (< 3.802). If successful, generates the submission file for the test set using the `generate_predictions` function.
