This script demonstrates the usage of the provided GNSS localization library. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory and reduces training epochs/batch size for a quick demonstration.
2.  **Utility Verification**: Validates the logic of the `WGS84Converter` and `haversine_distance` functions.
3.  **Component Testing**: Individually instantiates and tests the `GNSSPreprocessor`, `GNSSSequenceDataset`, `MultiScaleResUNet1D` model, and `DeepSupervisionMAELoss` to ensure shapes and outputs are correct.
4.  **Pipeline Execution**: Runs the full `train_pipeline` in debug mode, which processes a small subset of data, trains the model for one epoch, and generates predictions.
