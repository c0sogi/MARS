The `RuntimeError: stack expects each tensor to be equal size` occurs because the `GnssSequenceDataset` pads features and targets to a fixed `window_size` (256) but fails to pad the `timestamp` array stored in the metadata dictionary. When the `DataLoader` collates a batch containing a partial sequence (e.g., length 116) alongside full sequences, the unpadded `timestamp` arrays have mismatched dimensions, causing `torch.stack` to fail.

To fix this, I will modify `library/dataset.py` to:
1.  Extract the `timestamps` array from the subset before the padding logic block.
2.  Explicitly pad the `timestamps` array with zeros when `pad_flag` is True, ensuring it matches the `window_size`.
3.  Update the `meta` dictionary to use the padded `timestamps` variable.

This ensures all batch-collated fields have consistent dimensions.
