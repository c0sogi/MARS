Implementation Strategy:
1.  **Configuration Setup**: Override `Config` paths to use a temporary working directory (`./working/demo`) to ensure isolation and avoid permission issues.
2.  **Utility Verification**: Test `WGS84` coordinate conversion functions and `haversine_distance` with known values to ensure correctness.
3.  **Synthetic Data Generation**: Create a helper function to generate a small, in-memory Pandas DataFrame that mimics the structure of the preprocessed GNSS data (features, targets, metadata). This avoids the time-consuming process of reading and processing the full raw dataset from disk.
4.  **Dataset Demonstration**: Instantiate `GnssSequenceDataset` using the synthetic data. Verify the length, item retrieval, and tensor shapes.
5.  **Model & Loss Demonstration**: Instantiate `SEResUNet1D` and `DeepSupervisionLoss`. Pass a batch of synthetic data through the model, calculate the loss, and verify output shapes and loss values.
6.  **Training Loop Demonstration**: Use `unittest.mock` to patch `library.preprocessing.PreProcessor.process_data`. This allows `train_model` to use the synthetic data instead of loading the full dataset. Run `train_model` for 1 epoch with `debug=True`.
7.  **Inference Demonstration**: Similarly patch `process_data` for `predict_drive` to demonstrate the inference pipeline using synthetic test data.
