Based on the lessons learned, I propose the **Phase-Aware Stratified 1D Attention ResUNet**.

This strategy structurally evolves the successful **Stratified 1D ResUNet** (Cite solution_lesson_node_00063) by integrating **Attention Gates** into the skip connections. While previous attempts at Attention mechanisms failed due to improper feature encoding (Cite solution_lesson_node_00064) and incorrect auxiliary targets (Cite solution_lesson_node_00060), this solution corrects those flaws to enable the network to dynamically filter noise. By explicitly separating "clean" (Phase-Locked/L5) and "noisy" (Low Elevation) signals into input strata, and then using Attention Gates to weight these strata based on the global trajectory context, the model can selectively suppress multipath errors during reconstruction.

### Model
**Architecture: 1D Residual U-Net with Attention Gates**
The model is a sequence-to-sequence Encoder-Decoder network designed to map a time-series of stratified sensor features to coordinate corrections.
*   **Stratified Input:** A multi-channel time-series tensor where channels represent statistics from distinct satellite groups (Global, High-Precision, High-Risk).
*   **Residual Encoder:** A stack of **1D Residual Blocks** followed by Max Pooling layers. This extracts hierarchical features ranging from local signal noise to global trajectory drifts (Cite solution_lesson_node_00018).
*   **ASPP Bottleneck:** An **Atrous Spatial Pyramid Pooling (ASPP)** module captures multi-scale temporal context, distinguishing between instantaneous signal spikes and long-term atmospheric drifts (Cite solution_lesson_node_00012).
*   **Attention-Gated Decoder:** Upsampling layers are connected to the encoder via **Attention Gates**.
    *   *Mechanism:* Instead of simple concatenation, the gate uses the upsampled decoder feature (which carries global context) to compute a weighting map for the encoder features (which carry local details). This allows the model to suppress features from the "High-Risk" stratum when they conflict with the trajectory, while passing through features from the "High-Precision" stratum.
*   **Decimated Auxiliary Heads:** Intermediate decoder layers are equipped with auxiliary output heads for Deep Supervision.

### Data
**Preprocessing Pipeline**
1.  **Temporal Quantization:** Raw GNSS logs and ground truth are aligned by **rounding timestamps to the nearest second (1Hz)**. This prevents data loss from clock jitter (Cite solution_lesson_node_00016).
2.  **Phase-Aware Stratification (Innovation):** For each timestamp, partition visible satellites into three strata:
    *   **Stratum 1 (Global):** All visible satellites.
    *   **Stratum 2 (High-Precision):** Satellites with `SignalType` in {L5, E5a, B2a} **OR** `AccumulatedDeltaRangeState` indicating **Valid Carrier Phase**. Valid phase is a strong physical proxy for line-of-sight signals.
    *   **Stratum 3 (High-Risk):** Satellites with Elevation < 30 degrees.
    *   For each stratum, compute **Mean, Standard Deviation, Minimum, and Maximum** for `Cn0DbHz` and `SvElevationDegrees` (Cite solution_lesson_node_00020).
3.  **Corrected Geometric Context:** Calculate the **Signal-Weighted Azimuth Centroid**. Crucially, decompose this angle into **Sine and Cosine components** before feeding it to the network to avoid numerical discontinuities (Cite solution_lesson_node_00064).
4.  **Translation Invariance:** Strictly exclude absolute `Latitude` and `Longitude` (Cite solution_lesson_node_00003).
5.  **Target Transformation:** Convert regression targets from Degrees to **Meters (East-North)** relative to the WLS baseline (Cite solution_lesson_node_00018).

### Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. The total loss is a weighted sum of the final output loss and auxiliary head losses. MAE is used for robustness to outliers (Cite solution_lesson_node_00001).
*   **Decimated Deep Supervision:** For auxiliary heads operating at lower temporal resolutions, the ground truth target is **decimated (subsampled)** to match the resolution, rather than average-pooled. This forces the encoder to learn valid instantaneous states, stabilizing the training of the Attention Gates (Cite solution_lesson_node_00060).
*   **Optimizer:** AdamW with **Gradient Clipping** and a **Cosine Annealing** learning rate schedule to ensure stability (Cite solution_lesson_node_00042).

### Evaluation
1.  **Inference:** Feed the preprocessed stratified feature sequence for a full test drive into the model. The model outputs the sequence of Cartesian residuals $(\Delta North, \Delta East)$ from the final high-resolution head.
2.  **Reconstruction:** Convert Cartesian offsets to angular offsets $(\Delta Lat, \Delta Lon)$ using local WGS84 approximations.
3.  **Correction:** Add the predicted offsets to the baseline WLS coordinates provided in the test set to generate the final submission.
