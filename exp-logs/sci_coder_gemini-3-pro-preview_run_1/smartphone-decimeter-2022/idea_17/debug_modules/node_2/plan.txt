The `RuntimeError` is caused by a data type mismatch between the model weights (`FloatTensor` / `float32`) and the input data (`DoubleTensor` / `float64`). This occurs in `library/dataset.py` during feature normalization: although the features are initially cast to `float32`, subtracting the `float64` mean/std values (calculated by NumPy/Pandas) promotes the entire feature array to `float64`. When converted to a PyTorch tensor, this becomes a `DoubleTensor`. To fix this, I will explicitly cast the features back to `float32` after the normalization step in the `SmartphoneLocationDataset` class.
