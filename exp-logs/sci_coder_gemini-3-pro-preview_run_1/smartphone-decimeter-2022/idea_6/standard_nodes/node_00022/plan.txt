Here is the implementation of the orchestration script `runfile.py`.

The script performs the following steps:
1.  **Setup**: Initializes the environment, sets random seeds, and detects the compute device (GPU/CPU).
2.  **Data Loading**: Loads the training, validation, and test datasets using the provided library functions. It limits the training data to 10 drives to ensure a fast baseline execution while using the full validation and test sets.
3.  **Model Training**: Initializes the `TransResUNet` model and trains it using the `Trainer` class with the AdamW optimizer.
4.  **Validation & Metric**: Evaluates the trained model on the hold-out validation set. It computes the competition-specific metric (mean of 50th and 95th percentile distance errors) by reconstructing the predicted residuals and comparing them to the ground truth.
5.  **Failure Analysis**: Analyzes the correlation between the prediction errors and input features (e.g., signal strength, elevation) to identify failure modes.
6.  **Submission**: Checks if the validation metric meets the required threshold (< 3.802) and, if so, generates the submission file for the test set.
