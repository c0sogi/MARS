Additionally, the script conditionally skipped generating a submission file because the validation metric did not meet a hardcoded threshold.

To fix this, I will modify `runfile.py` to:
1.  Remove the `max_drives` limit when calling `get_datasets` to ensure the model trains and validates on the full dataset.
2.  Set the number of epochs to `C.NUM_EPOCHS` (defined in the config) instead of the hardcoded value.
3.  Remove the conditional check for submission generation, ensuring a submission file is always created regardless of the validation score.
