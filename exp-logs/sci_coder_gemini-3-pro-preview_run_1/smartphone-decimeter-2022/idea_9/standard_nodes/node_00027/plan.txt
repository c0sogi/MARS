Implementation strategy:
1.  **Configuration Override**: Monkey-patch `library.config.Config` to reduce `NUM_EPOCHS` to 5 and increase `BATCH_SIZE` to 32 for faster training within the time limit.
2.  **Training**: Execute `library.train.train_model()`. This handles data loading (computing features if not cached), model initialization, and the training loop with validation.
3.  **Evaluation**:
    *   Load the validation dataset using `get_dataloaders`.
    *   Load the best saved model state.
    *   Iterate through the validation set to compute predictions.
    *   Reconstruct WGS84 coordinates from predicted Cartesian offsets and baselines.
    *   Compute the competition metric (mean of 50th/95th percentile errors averaged per phone).
    *   Print the `Final Validation Metric`.
4.  **Failure Analysis**:
    *   During the evaluation loop, collect error magnitudes and corresponding input feature statistics (Mean Signal Strength, Mean Elevation, Satellite Count).
    *   Compute and print Pearson correlation coefficients between errors and these features to identify failure modes.
5.  **Submission**:
    *   Compare the calculated validation metric against the threshold (3.802240262877392).
    *   If the metric is lower (better), call `library.inference.generate_submission()` to create the submission file for the test set.
