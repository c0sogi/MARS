This script demonstrates the end-to-step pipeline for the GNSS positioning task using the provided library. It performs the following steps:
1.  **Configuration Setup**: Overrides the default configuration to use a temporary directory and a small subset of data for rapid execution.
2.  **Data Preparation**: Creates "mini" metadata files by sampling a few drives from the provided metadata to simulate a small dataset.
3.  **Utils Verification**: Validates the coordinate conversion and error calculation functions.
4.  **Preprocessing**: Runs the `GNSSPreprocessor` to transform raw GNSS logs into tabular features.
5.  **Dataset & Scaler**: Instantiates the `GNSSSequenceDataset`, fits a scaler, and verifies data loading and shape.
6.  **Model & Loss**: Initializes the `StratifiedAttentionResUNet` and `DecimatedDeepSupervisionLoss`, performs a forward pass, and computes loss.
7.  **Training Loop**: Runs the `Trainer` for a single epoch to demonstrate the training, validation, and submission generation process.
