### Implementation Strategy

1.  **Configuration Setup**: Override default `Config` parameters to ensure a fast baseline execution. Specifically, reduce `EPOCHS` to 5 to fit within the time limit while still allowing convergence.
2.  **Training**: Execute the training pipeline using `library.train.run_training()`. This handles data loading, preprocessing, and model training with deep supervision.
3.  **Validation & Metric Computation**:
    *   Load the preprocessed validation data from the cache.
    *   Load the best saved model checkpoint.
    *   Run inference on the validation set to obtain predicted offsets.
    *   Calculate the Euclidean distance error between predicted positions and ground truth positions (derived from the targets).
    *   Compute the competition metric: the mean of the average (50th + 95th percentile) errors per trip.
4.  **Failure Analysis**:
    *   Compute Pearson correlation coefficients between the calculated distance errors and the input features (e.g., Signal Strength, Elevation).
    *   Print the correlations to identify features associated with high errors.
5.  **Submission**:
    *   Check if the calculated validation metric is strictly less than 3.802240262877392.
    *   If the condition is met, trigger the inference pipeline on the test set using `library.inference.generate_submission()` to produce `submission.csv`.
