This script demonstrates the end-to-step pipeline for the Smartphone Decimeter Challenge using the provided library files. It performs the following steps:
1.  **Utils Verification**: Validates the coordinate conversion and distance calculation functions.
2.  **Data Preparation**: Creates a small subset of the metadata to ensure the demonstration runs quickly (within minutes) instead of processing the entire dataset.
3.  **Model Verification**: Instantiates the `TemporalConvNet` and verifies input/output shapes.
4.  **Training Pipeline**: Executes the full training loop using `library.train.run_training` on the data subset, verifying artifact generation (model weights and submission file).
5.  **Inference Pipeline**: Simulates the inference process using `library.inference.generate_predictions` with the trained model.
