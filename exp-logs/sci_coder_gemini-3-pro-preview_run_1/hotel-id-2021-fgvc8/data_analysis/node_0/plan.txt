The following script performs a comprehensive Exploratory Data Analysis (EDA) on the hotel identification dataset. It focuses on the training metadata provided in `./metadata/train.csv` and samples actual image files from `./input` to analyze visual statistics.

**Implementation Strategy:**
1.  **Setup & Configuration**: Initialize random seeds for reproducibility and define paths.
2.  **Data Loading**: Load the training metadata.
3.  **Target Analysis**: Analyze the `hotel_id` column to understand class cardinality, distribution, and imbalance.
4.  **Image Analysis**:
    *   Since processing 70k+ images is computationally expensive, we sample 5,000 images to estimate dataset statistics.
    *   We compute distributions for dimensions (Width, Height), Aspect Ratios, and Channel counts.
    *   We calculate global pixel mean and standard deviation to inform normalization strategies.
5.  **Metadata Analysis**:
    *   Analyze the `chain` feature (cardinality and distribution).
    *   Parse `timestamp` to understand temporal coverage.
    *   Check correlations between metadata features (e.g., image size vs. chain).
6.  **Reporting**: Output the findings in the specified format with high precision.
