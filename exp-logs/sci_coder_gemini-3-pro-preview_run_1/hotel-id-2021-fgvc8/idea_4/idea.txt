Based on the previous experiments and the derived lessons, I propose a **GeM-Augmented EfficientNet Retrieval System**. This solution structurally upgrades the feature aggregation mechanism while strictly adhering to a training curriculum designed to navigate the stability-plasticity trade-off inherent in metric learning.

# Model
*   **Backbone:** Upgrade from MobileNetV3 to **EfficientNet-B0**. This architecture provides a stronger feature extraction capability necessary for capturing the fine-grained architectural details of hotel facades, while remaining computationally feasible within the 24-hour budget on an A100 GPU.
*   **Structural Innovation (Pooling):** Replace the standard Global Average Pooling (GAP) layer with **Generalized Mean (GeM) Pooling**. Unlike GAP, which treats all pixels equally and often dilutes small discriminative features (like signage or specific window patterns) with background noise, GeM introduces a learnable parameter $p$. This allows the network to dynamically transition between Average Pooling and Max Pooling, focusing on salient regions of the image which is critical for landmark retrieval.
*   **Head:** Utilize an **ArcFace** (Additive Angular Margin) head with a 512-dimensional embedding layer. This enforces high intra-class compactness, which is essential for distinguishing between the 7,700+ hotel classes.

# Data
*   **Preprocessing:** Resize images to **256x256** and perform a random crop to **224x224** during training (CenterCrop for evaluation).
*   **Dataset Integrity:** Utilize the **full training dataset** (70,000+ images). We explicitly reject any strategy involving random subsampling of the training data, as reducing the sample density per class destroys the positive pairs required for metric learning to function Cite {solution_lesson_node_00005}.
*   **Augmentation:** Apply **RandomResizedCrop** and **HorizontalFlip**. These augmentations are necessary for generalization but introduce variance that dictates the length of the warmup phase.

# Training
The training process utilizes a **Plasticity-Preserving Two-Stage Curriculum** with strict batch size constraints:

*   **Batch Size:** Fix the batch size at **64**. We explicitly avoid increasing the batch size (e.g., to 256) even if memory allows. The stochastic noise generated by smaller batches acts as a critical implicit regularizer that prevents the model from overfitting to the few samples available for long-tail classes Cite {solution_lesson_node_00004}.
*   **Optimizer:** Use **AdamW** with a cosine decay learning rate schedule.
*   **Stage 1: Stabilized Softmax Warmup**
    *   **Objective:** Train using standard CrossEntropy Loss (ArcFace margin $m=0$).
    *   **Duration:** Train for **3 epochs**. This duration is selected to balance two conflicting requirements:
        1.  It must be long enough to allow the model to learn coarse clusters despite the variance introduced by `RandomResizedCrop`, preventing the divergence seen when strict margins are applied too early Cite {solution_lesson_node_00007}.
        2.  It must be terminated *before* the model achieves high classification accuracy to ensure the embeddings remain "plastic" and capable of being reshaped by the metric loss in Stage 2 Cite {solution_lesson_node_00003}.
*   **Stage 2: Metric Fine-Tuning**
    *   **Objective:** Switch to **ArcFace Loss** (margin $m=0.5$, scale $s=30$).
    *   This transition prevents the "Cold-Start Convergence Failure" where the optimizer gets stuck in a high-loss state if the margin is applied to randomly initialized weights Cite {solution_lesson_node_00001}.

# Evaluation
*   **Inference:** Pass the test images through the EfficientNet backbone and GeM pooling layer to extract normalized 512-dimensional embeddings.
*   **Prediction:** Compute the **Cosine Similarity** between the test image embedding and the learned class centers (weights from the ArcFace head).
*   **Ranking:** Output the top 5 Hotel IDs with the highest similarity scores.
