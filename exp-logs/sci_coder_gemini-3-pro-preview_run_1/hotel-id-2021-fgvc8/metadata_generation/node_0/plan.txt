The following Python script generates the required metadata files for the hotel identification task. It performs the following steps:

1.  **Setup**: Defines input and output directories and ensures the output directory exists.
2.  **Train/Val Generation**:
    -   Reads `train.csv`.
    -   Constructs relative file paths for training images using the `chain` and `image` columns (e.g., `train_images/0/image_id.jpg`).
    -   Performs a stratified split to create a validation set. To handle classes with only one sample (singletons), it separates them first, performs the stratified split on multi-sample classes (80:20 ratio), and adds the singletons to the training set to ensure no data is lost and stratification is valid.
    -   Saves `train.csv` and `val.csv` to the metadata directory.
3.  **Test Generation**:
    -   Reads `sample_submission.csv` to identify test images.
    -   Constructs relative file paths (e.g., `test_images/image_id.jpg`).
    -   Saves `test.csv` to the metadata directory.
4.  **Validation**:
    -   Prints summary statistics for all datasets.
    -   Verifies that the generated file paths correspond to actual files in the `./input` directory by checking a random sample of 1000 paths. It raises an error if the missing file ratio exceeds 50%.
    -   Verifies the integrity of the train/validation split (no data leakage and correct class distribution logic).
