Based on the provided model architectures and the requirement for a highly efficient baseline, here is a proposal for a **Standard ResNet Classification Baseline**.

### Model
The architecture is a standard Convolutional Neural Network (CNN) designed for direct multi-class classification.
*   **Backbone**: Utilize a **ResNet-18** architecture pre-trained on ImageNet. ResNet-18 is chosen for its balance of speed and accuracy; it is significantly more lightweight than deeper variants (like ResNet-50) and often offers higher throughput than EfficientNet-B0 on standard GPU hardware due to its simple memory access patterns.
*   **Head**: Remove the original fully connected layer and replace it with a single linear layer that maps the 512-dimensional feature vector directly to the $N$ output classes (approximately 7,770 hotels).
*   **Mechanism**: Unlike the metric learning approach (Model 1) which learns embeddings for distance comparisons, this model learns to output a probability distribution over the specific training classes directly.

### Data
*   **Preprocessing**: To maximize throughput, images will be resized to a standard resolution of **224x224** pixels.
*   **Normalization**: Pixel values will be normalized using the standard ImageNet mean and standard deviation to align with the pre-trained weights.
*   **Augmentation**: To maintain simplicity and speed, only minimal augmentations will be applied during training, specifically a random resized crop. During evaluation, a simple center crop will be used.

### Training
*   **Objective**: The model will be trained using **Cross-Entropy Loss**, which is the standard objective function for multi-class classification problems. This penalizes the divergence between the predicted probability distribution and the one-hot encoded ground truth.
*   **Optimizer**: Use the **Adam** optimizer with a default learning rate (e.g., 1e-3 or 1e-4) for fast convergence.
*   **Strategy**: Perform full fine-tuning (updating all weights) rather than feature extraction. While freezing weights is faster per epoch, fine-tuning typically reaches a higher accuracy baseline with fewer total epochs for domain-specific tasks like hotel recognition.

### Evaluation
*   **Inference**: For each image in the test set, perform a forward pass through the network to obtain the raw output logits for all 7,770 classes.
*   **Ranking**: Apply a `top-k` operation to select the 5 indices with the highest logit values.
*   **Submission**: Map these indices back to their corresponding Hotel IDs to form the space-delimited prediction string.
