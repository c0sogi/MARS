The execution failure is caused by an API mismatch with the installed version of the `albumentations` library (version 2.0+). Specifically, the `A.RandomResizedCrop` and `A.CenterCrop` transformations now require a single `size` argument (a tuple of `(height, width)`) instead of separate `height` and `width` arguments. The traceback confirms this by showing a `pydantic.ValidationError` where the `size` field is missing from the input dictionary, which only contained `scale` (Cite debug_lesson_1).

To fix this, I will update `library/dataset.py` to pass `size=(image_size, image_size)` to both `A.RandomResizedCrop` and `A.CenterCrop`.
