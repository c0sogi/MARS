The following script demonstrates the usage of the provided library modules (`utils`, `dataset`, `model`, `trainer`, `inference`) to perform a complete but lightweight hotel identification workflow. 

To satisfy the requirement for speed, the script:
1.  **Monkey-patches the `Config` class** to use a separate working directory and reduce hyperparameters.
2.  **Subsets the data**: Instead of loading the full 70k+ dataset, it slices the metadata to the first 64 samples for training, validation, and testing. This ensures the "epoch" completes almost instantly.
3.  **Manually instantiates DataLoaders** using these subsets while leveraging the `HotelDataset` class.
4.  **Validates components**: It includes assertions for tensor shapes, metric calculations, and file outputs.
