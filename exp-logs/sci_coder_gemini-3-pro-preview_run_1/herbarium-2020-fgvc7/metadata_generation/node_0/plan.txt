The strategy involves the following steps:
1.  **Setup and Loading**: Initialize paths and directories. Load the large JSON metadata files for training and testing from the `nybg2020` directory. The system has ample RAM (220 GB), so loading the JSONs into memory is feasible.
2.  **Data Parsing**:
    - For the training set, parse the `images` and `annotations` lists. Merge them on `image_id` to associate file paths with category labels. Construct the relative file paths from the `input` directory root.
    - For the test set, parse the `images` list and construct relative file paths.
3.  **Data Splitting**:
    - Perform an 80:20 train/validation split on the training data.
    - To handle class imbalance and potential singleton classes (classes with only 1 sample), separate classes with fewer than 2 samples and assign them to the training set directly.
    - Apply stratified splitting on the remaining data to ensure the validation set distribution matches the training set.
4.  **Saving Metadata**: Save the resulting DataFrames as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
5.  **Verification**:
    - Reload the saved metadata files.
    - Print summary statistics (count, class distribution).
    - Perform a file existence check on a random sample of 1000 paths to ensure correctness.
    - Verify that the class distribution in the validation set closely matches the training set (stratification check).
