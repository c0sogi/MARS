The implementation strategy follows the Heterogeneous Ensemble approach outlined in the idea.

1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and import necessary configurations and library functions.
2.  **Data Loading**: Use `library.data_loader.load_and_process_data` to load the training, validation, and test sets. We enable caching (`load_cached_data=True`) to speed up subsequent runs. Crucially, we use the full dataset (`max_samples=None`) rather than subsampling, as the high validation threshold (0.9612) requires maximum model capacity, and the available NVIDIA A100 GPU ensures training remains fast (within the 2-hour limit) even with 3.6M samples.
3.  **Model Training**:
    *   Initialize `XGBoostWrapper` and `LightGBMWrapper` from the factory.
    *   Train both models on the full training set (`X_train`, `y_train`) while monitoring performance on the validation set (`X_val`, `y_val`) for early stopping. Both models utilize GPU acceleration (`tree_method='hist'`/`device='cuda'`) as defined in the config.
4.  **Validation & Ensemble**:
    *   Generate soft predictions (probabilities) for the validation set using both trained models.
    *   Combine these probabilities using `weighted_soft_voting` with weights defined in `Config` (0.5/0.5).
    *   Compute the final class predictions and calculate the **Multi-class classification accuracy**.
    *   Print the required metric string: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Identify misclassified samples in the validation set.
    *   Calculate the Pearson correlation between the binary error vector (1 for error, 0 for correct) and all input features.
    *   Print the top 10 features most strongly correlated with model failure to identify systematic weaknesses.
6.  **Submission Generation**:
    *   Check if the validation accuracy exceeds the strict threshold of `0.9612388888888889`.
    *   If the threshold is met, generate probabilities for the test set, ensemble them, and save the final predictions to `./submission/submission.csv` using `library.ensemble_utils.save_submission`.
