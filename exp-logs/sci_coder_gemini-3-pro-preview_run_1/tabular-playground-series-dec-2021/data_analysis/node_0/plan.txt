The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Initialization**: Set random seeds for reproducibility and define the path to the training data (`./metadata/train.csv`).
2.  **Data Loading**: Load the training dataset using Pandas.
3.  **Modality Detection**: Although the task description mentions "images", the metadata analysis confirms the data is tabular (56 columns, no file paths). The script will verify this by checking column data types.
4.  **Target Analysis**: Analyze the `Cover_Type` column. Since it is a classification task, calculate class counts and proportions to assess imbalance.
5.  **Tabular Data Analysis**:
    *   **Numerical Features**: Calculate descriptive statistics (mean, std, min, max) and identify outliers using the Interquartile Range (IQR) method.
    *   **Categorical Features**: Check cardinality and identify rare labels.
    *   **Missing Values**: Report the percentage of missing data per column.
6.  **Feature Relationships**:
    *   **Correlation**: Compute the Pearson correlation matrix to identify collinear features (redundancy > 0.90).
    *   **Feature Importance**: Train a lightweight Random Forest classifier on a stratified subsample of the data (to ensure speed given the 2.8M rows) and extract the top 5 most important features.
7.  **Output**: Print the findings in the specified format, ensuring all floating-point numbers are formatted to 4 decimal places.
