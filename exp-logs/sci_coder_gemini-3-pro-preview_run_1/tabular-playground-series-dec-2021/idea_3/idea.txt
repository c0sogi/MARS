Based on the lessons learned, particularly the success of geometric feature engineering and the failure of naive ensembling with weaker models, I propose a **Hybrid Stacking Strategy**. This approach introduces structural diversity through a Neural Network backbone while retaining the optimized Gradient Boosting architecture.

# Model
The solution will utilize a **Two-Stage Stacking Ensemble** designed to leverage the complementary strengths of tree-based and gradient-based learning.

*   **Level 0 (Base Learners):**
    1.  **Optimized XGBoost (Exploitation):** We will retain the high-capacity Gradient Boosting architecture (`max_depth=10`, `eta=0.05`) that proved successful. **Cite Lesson 00002, 00004**. We will continue to use the histogram-based GPU implementation for efficiency.
    2.  **Deep Tabular ResNet (Exploration):** We will introduce a Residual Neural Network (ResNet) adapted for tabular data. Unlike decision trees which make orthogonal cuts, this model uses continuous activation functions and dense layers with skip connections. This provides a fundamentally different inductive bias, capturing smooth decision boundaries that trees approximate inefficiently.
*   **Level 1 (Meta Learner):**
    *   Instead of the naive averaging that failed previously (**Cite Lesson 00006**), we will use a **Logistic Regression** meta-learner. This model will take the class probability outputs from the Level 0 models as input and learn the optimal weighting for each class, ensuring that the ensemble relies on the stronger model (XGBoost) while utilizing the Neural Network only where it provides additive signal.

# Data
*   **Feature Engineering (Exploitation):** We will strictly apply the physics-informed transformations identified as critical: Euclidean distance for hydrology (`sqrt(H^2 + V^2)`), relative elevation (`Elevation - Vertical_Dist`), and cyclic encoding for `Aspect`. **Cite Lesson 00007**.
*   **Preprocessing:**
    *   **Stratified K-Fold Split:** We will split the full training data into 5 stratified folds. This allows us to generate unbiased Out-Of-Fold (OOF) predictions for training the meta-learner without data leakage.
    *   **Normalization:** While XGBoost requires no scaling, the Neural Network input features will be **Standard Scaled** (Z-score normalization) to ensure stable gradient descent dynamics.

# Training
*   **Cross-Validation Loop:** We will train both the XGBoost and ResNet models on each of the 5 folds (training on 4, predicting on 1).
    *   **XGBoost:** Will be trained with `early_stopping_rounds` to manage convergence automatically, ignoring fixed iteration limits. **Cite Lesson 00003**.
    *   **ResNet:** Will be trained using the AdamW optimizer with a `ReduceLROnPlateau` scheduler and Early Stopping based on validation loss.
*   **Meta-Training:** The OOF probability predictions from all 5 folds will be concatenated to form a training set for the Level 1 Logistic Regression, which will be trained to minimize log-loss.

# Evaluation
*   **Inference:** For the test set, we will generate predictions using all 5 trained instances of the XGBoost model and all 5 instances of the ResNet model.
*   **Aggregation:** We will average the probabilities of the 5 XGBoost models to get a stabilized `XGB_Test_Pred` and similarly for the ResNet to get `NN_Test_Pred`.
*   **Final Prediction:** These two averaged probability vectors will be fed into the trained Level 1 Logistic Regression model to produce the final class probabilities, from which the class with the maximum probability will be selected.
