Based on the lessons learned and the analysis of previous attempts, I propose a **Self-Training Homogeneous Ensemble** strategy. This approach prioritizes data volume and geometric feature engineering—identified as critical success factors—while introducing a multi-stage pseudo-labeling pipeline to leverage the unlabeled test data, addressing the need for structural innovation without resorting to weaker disparate models.

# Model
The core architecture will remain the **Gradient Boosted Decision Tree (GBDT)** using **XGBoost**, as it has proven to be the strongest individual performer.
*   **Backbone:** We will utilize the XGBoost classifier with **GPU acceleration** (`tree_method='hist'`, `device='cuda'`) to ensure efficient processing of the large dataset.
*   **Configuration:** We will strictly adhere to the high-capacity configuration validated in previous experiments: `max_depth=10` and `eta=0.05`. This avoids the pitfalls of aggressive fine-tuning (**Cite solution_lesson_node_00004**) and ensures the model has sufficient complexity to capture boundaries in the full dataset (**Cite solution_lesson_node_00002**).
*   **Ensemble Structure:** Instead of combining disparate weak learners (which diluted performance previously, **Cite solution_lesson_node_00006**), we will employ **Homogeneous Bagging**. We will train multiple instances of this optimized XGBoost architecture on different folds of the data.

# Data
*   **Feature Engineering (Exploitation):** We will explicitly construct the physics-informed geometric features that yielded performance gains. This includes the **Euclidean Distance to Hydrology** ($\sqrt{Horizontal^2 + Vertical^2}$), **Relative Elevation** (Elevation - Vertical_Dist), and **Cyclic Encoding** (Sine/Cosine) of the Aspect feature. (**Cite solution_lesson_node_00007**).
*   **Preprocessing:** We will load the **full training dataset** (2.8M samples) and the full test set. We will **not subsample** the data, as maximizing data volume is prioritized over architectural complexity (**Cite solution_lesson_node_00009**).
*   **Augmentation (Innovation):** We will create an augmented training set by merging the original training data with high-confidence pseudo-labeled samples from the test set (generated in the Training phase).

# Training
The training will proceed in a **Two-Stage Self-Training Pipeline**:

1.  **Stage 1: Initial Bagging (Teacher):**
    *   Perform a **Stratified 5-Fold Cross-Validation** on the full original training set.
    *   Train 5 independent XGBoost models (one per fold). Use **Early Stopping** (patience=50) monitoring the validation fold to handle convergence automatically (**Cite solution_lesson_node_00003**).
    *   Generate probability predictions for the **Test Set** using all 5 models and average them to produce a stabilized `Stage1_Test_Probs`.

2.  **Stage 2: Pseudo-Labeling & Refinement (Student):**
    *   **Filter:** Identify test samples where the `Stage1_Test_Probs` indicate high confidence (e.g., maximum class probability > 0.99).
    *   **Augment:** Assign the predicted class labels to these high-confidence samples and append them to the original training set to form an `Augmented_Train_Set`.
    *   **Retrain:** Train a final **5-Fold Bagged Ensemble** of XGBoost models on this `Augmented_Train_Set`. Crucially, we will validate these models using the **original** validation folds (excluding pseudo-labels) to ensure the metric remains a reliable proxy for true performance.

# Evaluation
*   **Inference:** Pass the test set through the 5 models trained in **Stage 2**.
*   **Aggregation:** Compute the unweighted average of the class probability vectors from the 5 models.
*   **Prediction:** Select the class with the highest average probability for the final submission. This method leverages the variance reduction of bagging while refining the decision boundaries via self-training.
