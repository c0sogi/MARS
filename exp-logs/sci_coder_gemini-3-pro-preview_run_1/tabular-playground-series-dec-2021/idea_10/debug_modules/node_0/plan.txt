The following script demonstrates the usage of the provided library files. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` class to use a small subset of data and reduced hyperparameters (e.g., fewer trees, fewer folds) to ensure the script runs quickly (within seconds/minutes).
2.  **Data Preparation**: Creates temporary small training and test CSV files in the `./working` directory by sampling the original metadata.
3.  **Component Validation**:
    *   Validates utility functions (seeding, metric calculation).
    *   Validates the `MultiClassTargetEncoder` logic with a synthetic test case.
    *   Validates the `load_data` function and feature engineering pipeline.
4.  **Pipeline Execution**: Runs the full Cross-Validation and Inference pipeline (`run_cv_pipeline`) using the `training_engine` module.
5.  **Result Verification**: Checks that the submission file is generated correctly and adheres to the expected format.
