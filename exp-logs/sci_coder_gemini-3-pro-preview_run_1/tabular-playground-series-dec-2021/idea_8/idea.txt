Based on the lessons learned, I propose a **Semi-Supervised Homogeneous Ensemble with Dual-Representation Features**. This strategy evolves the solution from a purely supervised approach to a self-training pipeline, leveraging the high-performance baseline established in previous iterations to exploit the unlabeled test structure.

# Model
The core architecture will remain the **Homogeneous Ensemble of XGBoost Classifiers**, as this has proven superior to heterogeneous mixtures (**Cite solution_lesson_node_00006**) and stacking (**Cite solution_lesson_node_00018**).
*   **Backbone:** We will use XGBoost with **GPU acceleration** (`tree_method='hist'`, `device='cuda'`) and the high-capacity configuration (`max_depth=10`, `eta=0.05`) that successfully balanced complexity and convergence (**Cite solution_lesson_node_00002, solution_lesson_node_00004**).
*   **Loss Function:** We will optimize the `multi:softmax` objective but explicitly use **Log Loss (`mlogloss`)** as the evaluation metric for early stopping. This ensures the ensemble members optimize their probability calibration, which is critical for effective soft-voting, rather than just minimizing hard classification error (**Cite solution_lesson_node_00020**).

# Data
We will employ a **Dual-Representation Feature Engineering** strategy that maximizes the information available to the tree splits.
1.  **Data Volume:** We will load the **Full Training Dataset** (2.8M+ samples). We will strictly avoid subsampling (**Cite solution_lesson_node_00009**).
2.  **Physics-Informed Features (Exploitation):** We will generate the geometric features identified as critical: Euclidean Distance to Hydrology ($\sqrt{H^2 + V^2}$), Relative Elevation ($Elevation - Vertical\_Dist$), and Cyclic Aspect encoding (**Cite solution_lesson_node_00007**).
3.  **Dual-Representation for Categoricals (Exploitation/Refinement):**
    *   **Retention:** We will **retain** the original One-Hot Encoded (OHE) binary columns (e.g., `Soil_Type1`...`Soil_Type40`) to allow efficient isolation of specific categories (**Cite solution_lesson_node_00019**).
    *   **Augmentation:** We will *also* generate **Dense Integer Indices** for `Soil_Type` and `Wilderness_Area`. Crucially, we will **explicitly sort the column names numerically** before indexing to preserve ordinal semantics (**Cite solution_lesson_node_00013, solution_lesson_node_00014**). This provides the model with both the granular binary signals and the grouped integer signals.

# Training
We will implement a **Two-Stage Self-Training (Pseudo-Labeling) Pipeline**. This addresses the failure of previous attempts (**Cite solution_lesson_node_00010**) by ensuring the "Teacher" model is the fully optimized ensemble, not a weak proxy.

1.  **Stage 1: Teacher Training:**
    *   Perform **Stratified 5-Fold Cross-Validation** on the original training set.
    *   Train 5 XGBoost models using Early Stopping (patience=50) based on `mlogloss` (**Cite solution_lesson_node_00003**).
    *   Generate probability predictions for the **Test Set** using this ensemble.

2.  **Stage 2: Pseudo-Labeling:**
    *   Identify test samples where the Teacher Ensemble's maximum class probability exceeds a strict threshold (e.g., **0.99**).
    *   Assign the predicted labels to these samples and append them to the training data to create an `Augmented_Train_Set`.

3.  **Stage 3: Student Training:**
    *   Train a fresh **Stratified 5-Fold Ensemble** of XGBoost models on the `Augmented_Train_Set`.
    *   **Validation Constraint:** We will validate the Student models using the **original** validation folds (excluding pseudo-labels) to ensure the OOF metric remains a reliable proxy for true performance and prevents leakage.

# Evaluation
*   **Inference:** Pass the full test set through the 5 trained **Student** models from Stage 3.
*   **Aggregation:** Compute the **Unweighted Average (Soft Voting)** of the class probability vectors (**Cite solution_lesson_node_00012**).
*   **Prediction:** Select the class with the highest probability from the averaged vector.
