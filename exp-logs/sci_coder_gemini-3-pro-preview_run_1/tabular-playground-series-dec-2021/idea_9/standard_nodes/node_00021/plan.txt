Implementation strategy:
1.  **Setup & Data Loading**: Initialize the environment and load the preprocessed training, validation, and test datasets using the provided `library.data` module.
2.  **Inference Set Construction**: Concatenate the validation and test feature sets into a single `X_inference` dataframe. This allows efficient batch prediction during the cross-validation process.
3.  **Stage 1 (Teacher) Training**: Instantiate the `EnsemblePipeline` and run the initial 5-Fold Cross-Validation on the original training data. Collect predictions for the inference set.
4.  **Pseudo-Labeling**: Extract the test set predictions from the Stage 1 output. Use the pipeline's `generate_augmented_train_set` method to filter high-confidence predictions (threshold 0.99) and augment the training data.
5.  **Stage 2 (Student) Training**: Run a second 5-Fold Cross-Validation on the *augmented* training data. Crucially, pass `n_original_samples` to ensure the internal validation folds are drawn strictly from the original labeled data, preventing leakage.
6.  **Evaluation**: Extract the validation set predictions from the Stage 2 output. Compute the `Final Validation Metric` (accuracy) on the hold-out validation set.
7.  **Failure Analysis**: Compute the error magnitude (1 - probability of true class) for each validation sample. Calculate and print the correlation between input features and this error magnitude to identify weak points.
8.  **Submission**: If the final validation metric exceeds the specified threshold, generate the submission file using the averaged test predictions from Stage 2.
