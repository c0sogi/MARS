The following script demonstrates the usage of the provided library files to execute a complete machine learning pipeline, including data loading, feature engineering, model training, cross-validation, pseudo-labeling, and submission generation.

To ensure the demonstration runs quickly and efficiently within the constraints:
1.  **Data Loading**: The full dataset is loaded using `library.data`, but immediately subsampled to a small fraction (2,000 training samples, 500 test samples) to minimize processing time.
2.  **Configuration Override**: Key configuration parameters such as `N_FOLDS` and `NUM_BOOST_ROUND` are dynamically adjusted in the script to reduce computational overhead (e.g., reducing folds from 5 to 2, boosting rounds to 10).
3.  **Validation**: Assertions are placed throughout the script to verify:
    *   Correctness of feature engineering (column existence).
    *   Data shapes after splitting and augmentation.
    *   Model output formats (probabilities vs class labels).
    *   Submission file structure.
