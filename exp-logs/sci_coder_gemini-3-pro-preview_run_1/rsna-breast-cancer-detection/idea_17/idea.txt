Based on the progression of empirical findings—specifically the persistent "Age Shortcut" bias where single-stream models rely on demographic priors rather than visual evidence (Cite solution_lesson_node_00012, solution_lesson_node_00014), and the superiority of Single-Task Learning over Multi-Task Learning for this dataset (Cite solution_lesson_node_00021)—I propose the **Pyramid Symmetry-Difference Siamese Network**.

This strategy structurally evolves the previous "Early Fusion" approaches. By moving to a Siamese architecture, we can mathematically neutralize the problematic demographic signals (Age) via difference operations, while the multi-scale pyramid ensures sensitivity to both fine-grained microcalcifications and larger masses.

### Model
**Architecture: Pyramid Symmetry-Difference Siamese EfficientNet-B2**

*   **Siamese Backbone:** Utilize **EfficientNet-B2** in a Siamese configuration (shared weights). This ensures that both the **Target Image** (candidate for cancer) and the **Contralateral Image** (opposing breast, same view) are processed by the exact same feature extractor.
*   **Input Strategy (Early Fusion):**
    *   Retain the **Spatial Channel Expansion** technique (Cite solution_lesson_node_00002).
    *   The input tensor for both branches is $3 \times 768 \times 768$, comprising the **Image**, a spatially broadcasted **Age** map, and a spatially broadcasted **Implant** map.
    *   **Demographic Cancellation:** Since the Age and Implant maps are identical for the left and right breasts of the same patient, they will be mathematically zeroed out in the difference operations described below. This strictly prevents the "Age Shortcut" (Cite solution_lesson_node_00014) in the asymmetry stream.
*   **Multi-Scale Difference Module (Structural Innovation):**
    *   Instead of computing differences only at the final layer (which risks losing small lesions due to pooling), extract feature maps from **three distinct stages** of the backbone: **P3** (fine-grained texture), **P4** (mid-level patterns), and **P5** (global semantic structure).
    *   For each stage $i$, compute the **Signed Feature Difference**: $D_i = F_{target, i} - F_{contra, i}$.
    *   *Rationale:* This forces the network to detect asymmetry at the *microcalcification* level (P3) and the *mass* level (P5), while suppressing symmetric background tissue (density) which is strongly correlated with Age.
*   **Fusion & Classification Head:**
    *   Apply **Global Average Pooling (GAP)** to both the Target features ($F_{target, i}$) and the Difference features ($D_i$) at all three stages.
    *   **Concatenate** all resulting vectors: $V_{final} = \text{Concat}(\text{GAP}(F_{target}), \text{GAP}(D))$.
    *   Pass $V_{final}$ through a single fully connected layer to predict the cancer probability.

### Data
**Preprocessing & Augmentation**

*   **Paired Data Loading:**
    *   Construct training pairs by matching `patient_id` and `view` (e.g., Left CC paired with Right CC).
    *   **Fail Loudly:** The data loader must **raise an exception** immediately if a file is missing or corrupt due to I/O errors. Do not use silent fallbacks (e.g., returning black images), as this caused model collapse in previous iterations (Cite solution_lesson_node_00016).
    *   **Missing Counterparts:** Only for cases where a patient physically lacks a contralateral image (e.g., prior mastectomy), substitute a zero-tensor.
*   **Normalization:**
    *   Apply **Standard Scaling** (Zero Mean, Unit Variance) to the Age metadata before spatial broadcasting. This prevents the scalar value from being overpowered by image features or dominating gradients (Cite solution_lesson_node_00005).
*   **Augmentation:**
    *   **Synchronized Geometric Augmentation:** Apply identical random spatial transformations (Flip, Rotate, Shift) to *both* the target and contralateral images simultaneously. This preserves the pixel-wise correspondence required for the difference operation (Cite solution_lesson_node_00007).
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts. In mammography, absolute pixel intensity represents physical tissue density; altering it destroys the diagnostic signal (Cite solution_lesson_node_00008).

### Training
**Procedure**

*   **Objective:** **Single-Task Learning (STL)**.
    *   Train exclusively on the binary cancer target. Do not use auxiliary heads for Breast Density.
    *   *Rationale:* Auxiliary tasks on global features (like density) are "easier" to learn than lesion detection and exacerbate the age bias, leading to negative transfer (Cite solution_lesson_node_00021).
*   **Loss Function:** `BCEWithLogitsLoss` with `pos_weight` set to **47.0** (approximating the inverse class frequency).
    *   Aggressive positive weighting is required to maintain Probabilistic Recall in this highly imbalanced regime (Cite solution_lesson_node_00003).
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   Clipping gradients neutralizes the effect of the high `pos_weight`, preventing the optimizer from making the large updates necessary to correct errors on the minority class (Cite solution_lesson_node_00009).
*   **Optimizer:** AdamW (LR 1e-4) with a Cosine Annealing scheduler.

### Evaluation
**Inference Pipeline**

*   **Pair Construction:** Iterate through `test.csv`. For each prediction row, identify the file path for the contralateral view (same patient, same view, opposite laterality).
*   **Prediction:** Pass the pair through the Pyramid Siamese network.
*   **Aggregation:** Group predictions by `prediction_id` (which represents a specific breast). Compute the **Max** probability across all available views (CC and MLO) for that breast to generate the final submission score.
