Based on the task description and dataset analysis, I propose the following baseline approach. This method prioritizes simplicity and the integration of the highly predictive tabular metadata (specifically Age) directly into the visual feature learning process, distinguishing it from the late-fusion or pure-image approaches listed.

### Model: Metadata-Embedded CNN (Early Fusion)
**Architecture Design:**
The model is a **Metadata-Embedded Convolutional Neural Network**. Unlike standard CNNs (Model 1) that process only images, or Hybrid Ensembles (Model 5) that fuse features at the end, this architecture fuses patient demographics with visual data at the **input level**.

1.  **Input Layer**: The network accepts an input tensor of shape $(C+M) \times H \times W$, where $C$ is the image channel count (typically 1 for grayscale mammograms) and $M$ is the number of metadata features.
2.  **Metadata Embedding**: Key scalar metadata—specifically **Age** (identified as the top feature in analysis) and **Implant** status—are normalized and spatially broadcasted. This means the scalar value is repeated across the height ($H$) and width ($W$) dimensions to create "constant" feature maps. These maps are concatenated with the image along the channel dimension.
3.  **Backbone**: A lightweight **EfficientNet-B0** is used as the backbone. The first convolutional layer is modified to accept $C+M$ input channels instead of the standard 3. This allows the network's filters to learn texture features conditioned on patient demographics (e.g., distinguishing dense tissue patterns differently for young vs. elderly patients) from the very first layer.
4.  **Classification Head**: The backbone outputs a global feature vector via Global Average Pooling, which is passed through a single fully connected layer with a **Sigmoid** activation to output the cancer probability.

### Data
**Preprocessing:**
1.  **Image Loading**: Use **`rasterio`** to load the DICOM images, as it is available in the installed packages and supports various raster formats that `cv2` may struggle with. If a file cannot be read, replace it with a black placeholder to maintain pipeline stability.
2.  **Region of Interest (ROI) Crop**: Apply a simple intensity threshold to crop the image to the breast region, removing the large black background. This maximizes the resolution of the breast tissue relative to the input size.
3.  **Resizing**: Resize the cropped images to a fixed resolution of **512x512** pixels to balance training speed and detail preservation.
4.  **Normalization**: Normalize pixel values to the [0, 1] range.
5.  **Metadata Preparation**:
    *   **Age**: Min-Max scale the patient's age to [0, 1].
    *   **Implant**: Binary encoding (0 or 1).
    *   These values are expanded to 512x512 feature maps and stacked with the image.

### Training
**Procedure:**
1.  **Loss Function**: Use **BCEWithLogitsLoss** with a `pos_weight` parameter. Given the severe class imbalance (~1:47), setting `pos_weight` to approximately 20-40 ensures the model focuses sufficiently on the minority positive class.
2.  **Optimizer**: Use **AdamW** with a learning rate of 1e-4 and a weight decay of 1e-2.
3.  **Scheduler**: Implement a **Cosine Annealing** learning rate scheduler to converge smoothly within a short training window.
4.  **Augmentation**: Apply minimal augmentations—Horizontal Flip and slight Rotation (<15°)—to prevent overfitting without significantly increasing training time.
5.  **Duration**: Train for a maximum of 5 epochs. This is sufficient for a baseline to converge on the dominant features (Age + Density patterns) without wasting compute.

### Evaluation
**Inference Process:**
1.  **Pipeline**: Iterate through the `test.csv` file. For each row, load the corresponding image, apply the same ROI crop and resize steps, and construct the metadata channels.
2.  **Prediction**: Pass the tensor through the trained model to obtain a raw probability score.
3.  **Submission**: Map the predicted probability to the `prediction_id` and save to `submission.csv`. No test-time augmentation (TTA) or complex post-processing is applied to maintain high throughput.
