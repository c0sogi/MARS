Implementation Strategy:
1.  **Switch to Late Fusion Architecture**: To address the structural bias where the model over-relies on spatially broadcasted age (Cite {solution_lesson_node_00012}), I will modify the model to process the image and metadata separately. The EfficientNet backbone will process the image (converted to 3-channel RGB-like input), and the scalar metadata (Age, Implant) will be concatenated with the extracted features before the final classification layer.
2.  **Remove Auxiliary Task**: I will remove the auxiliary density classification task to simplify the optimization landscape and focus purely on the primary cancer detection task, as the structural fix (Late Fusion) renders the auxiliary task less critical for bias mitigation.
3.  **Adjust Training Parameters**: I will increase the training duration to 10 epochs to allow the Late Fusion architecture sufficient time to learn visual features, as it can no longer rely on the "easy" metadata shortcut in early layers. I will maintain the aggressive `POS_WEIGHT` (45.0) to handle the class imbalance (Cite {solution_lesson_node_00003}).

        n_features = self.backbone.num_features

        fused = torch.cat([features, metadata], dim=1)

        # Output logits
        cancer_logits = self.classifier(fused)

def train_one_epoch(model, loader, optimizer, device, epoch):

    total_loss_meter = 0.0
    cancer_loss_meter = 0.0
    density_loss_meter = 0.0

    # Loss functions
    # Weighted BCE for imbalance
    pos_weight = torch.tensor([Config.POS_WEIGHT]).to(device)
    cancer_criterion = nn.BCEWithLogitsLoss(pos_weight=pos_weight)

    # CrossEntropy for density (ignore -1 for missing labels)
    density_criterion = nn.CrossEntropyLoss(ignore_index=-1)

    for batch_idx, (inputs, cancer_targets, density_targets) in enumerate(loader):

        cancer_targets = cancer_targets.to(device).unsqueeze(1)  # [B, 1]

        # Forward
        cancer_logits, density_logits = model(inputs)

        # Compute Losses
        loss_c = cancer_criterion(cancer_logits, cancer_targets)
        loss_d = density_criterion(density_logits, density_targets)

        # Weighted Sum
        loss = loss_c + Config.AUX_WEIGHT * loss_d

        # Backward
        loss.backward()

        # No gradient clipping as per lesson 00009
