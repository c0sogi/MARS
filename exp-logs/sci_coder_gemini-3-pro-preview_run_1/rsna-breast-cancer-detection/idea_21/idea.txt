Based on the comprehensive analysis of the empirical findings—specifically the persistent "Age Shortcut" bias (Cite solution_lesson_node_00012, solution_lesson_node_00014), the superiority of Single-Task Learning (Cite solution_lesson_node_00021), and the necessity of preserving density signals (Cite solution_lesson_node_00008)—I propose the **Aligned-Attentive Siamese Network**.

This architecture structurally evolves the previous Siamese concepts by addressing the key weakness of rigid subtraction: anatomical misalignment. By integrating a **Spatial Alignment Module** with **Channel Attention**, we ensure that the difference operation effectively cancels out the symmetric demographic priors (Age) and background tissue, while robustly handling the natural non-rigid variations between breasts.

### Model
**Architecture: Aligned-Attentive Siamese EfficientNet-B2**

*   **Siamese Backbone:** Utilize **EfficientNet-B2** in a Siamese configuration (shared weights). This ensures that both the **Target Image** (candidate for cancer) and the **Contralateral Image** (opposing breast, same view) are processed by the exact same feature extractor.
*   **Input Strategy (Early Fusion):**
    *   Retain the **Spatial Channel Expansion** technique (Cite solution_lesson_node_00002).
    *   The input tensor for both branches is $3 \times 768 \times 768$, comprising the **Image**, a spatially broadcasted **Age** map, and a spatially broadcasted **Implant** map.
    *   **Demographic Cancellation:** Since the Age and Implant maps are identical for the left and right breasts of the same patient, they will be mathematically zeroed out in the difference operations described below, strictly preventing the "Age Shortcut" (Cite solution_lesson_node_00014).
*   **Multi-Scale Alignment & Difference Module (Structural Innovation):**
    *   Extract feature maps from **three stages** (P3, P4, P5).
    *   **Alignment:** At the coarsest level (P5), concatenate Target and Contralateral features to predict a dense **Deformation Field**. Upsample this field and use it to **Warp** the Contralateral features at all levels (P3-P5) to spatially align with the Target.
    *   **Difference:** Compute the **Aligned Difference**: $D_i = F_{target, i} - \text{Warp}(F_{contra, i})$.
    *   **Attentive Filtering:** Apply a **Squeeze-and-Excitation (SE) Block** to each difference map $D_i$. This dynamically re-weights channels to suppress residual noise caused by imperfect alignment while amplifying channels containing robust asymmetry signals (tumors).
*   **Fusion Head:**
    *   Concatenate the Global Average Pooled vectors of the Target features ($F_{target}$) and the Attended Difference features ($D$) from all levels.
    *   Pass through a single dense layer for binary classification.

### Data
**Preprocessing & Augmentation**

*   **Paired Data Loading:**
    *   Construct training pairs by matching `patient_id` and `view` (e.g., Left CC paired with Right CC).
    *   **Fail Loudly:** The data loader must **raise an exception** immediately if a file is missing or corrupt. Do not use silent fallbacks (e.g., returning black images), as this previously caused model collapse (Cite solution_lesson_node_00016).
    *   **Missing Counterparts:** Only for cases where a patient physically lacks a contralateral image, substitute a zero-tensor.
*   **Normalization:**
    *   Apply **Standard Scaling** (Zero Mean, Unit Variance) to the Age metadata before spatial broadcasting. This prevents the scalar value from being overpowered by image features or dominating gradients (Cite solution_lesson_node_00005).
*   **Augmentation:**
    *   **Synchronized Geometric Augmentation:** Apply identical random spatial transformations (Flip, Rotate, Shift) to *both* the target and contralateral images simultaneously. This preserves the global anatomical correspondence required for the alignment module (Cite solution_lesson_node_00007).
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts. In mammography, absolute pixel intensity represents physical tissue density; altering it destroys the diagnostic signal (Cite solution_lesson_node_00008).

### Training
**Procedure**

*   **Objective:** **Single-Task Learning (STL)**.
    *   Train exclusively on the binary cancer target. Do not use auxiliary heads for Breast Density.
    *   *Rationale:* Auxiliary tasks on global features are "easier" to learn than lesion detection and have been proven to exacerbate age bias, leading to negative transfer (Cite solution_lesson_node_00021).
*   **Loss Function:** `BCEWithLogitsLoss` with `pos_weight` set to **47.0** (approximating the inverse class frequency).
    *   Aggressive positive weighting is required to maintain Probabilistic Recall in this highly imbalanced regime (Cite solution_lesson_node_00003).
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   Clipping gradients neutralizes the effect of the high `pos_weight`, preventing the optimizer from making the large updates necessary to correct errors on the minority class (Cite solution_lesson_node_00009).
*   **Optimizer:** AdamW (LR 1e-4) with a Cosine Annealing scheduler.

### Evaluation
**Inference Pipeline**

*   **Pair Construction:** Iterate through `test.csv`. For each prediction row, identify the file path for the contralateral view (same patient, same view, opposite laterality).
*   **Prediction:** Pass the pair through the Aligned-Attentive Siamese network.
*   **Aggregation:** Group predictions by `prediction_id` (which represents a specific breast). Compute the **Max** probability across all available views (CC and MLO) for that breast to generate the final submission score.
