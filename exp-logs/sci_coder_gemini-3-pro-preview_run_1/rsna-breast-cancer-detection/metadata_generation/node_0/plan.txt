The following script generates metadata files for the RSNA Breast Cancer Detection dataset. It performs the following steps:
1.  **Data Loading**: Reads `train.csv` and `test.csv` from the `./input` directory.
2.  **Path Generation**: Constructs relative file paths for the DICOM images based on `patient_id` and `image_id`.
3.  **Validation Splitting**: Performs a group-stratified split on the training data. It groups by `patient_id` to ensure no patient appears in both training and validation sets (preventing data leakage) and stratifies by the maximum cancer label per patient to maintain class distribution.
4.  **Metadata Saving**: Saves the processed DataFrames to `./metadata/train.csv`, `./metadata/val.csv`, and `./metadata/test.csv`.
5.  **Verification**:
    *   Reloads the generated metadata.
    *   Checks for data leakage (patient overlap).
    *   Verifies the split ratio and class stratification.
    *   Validates that the referenced image files actually exist in the `./input` directory by sampling 1000 paths.
