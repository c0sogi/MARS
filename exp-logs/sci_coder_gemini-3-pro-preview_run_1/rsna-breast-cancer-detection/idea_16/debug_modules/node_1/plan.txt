The error `ValueError: Failed to load image (corrupt or unsupported format)` occurs because the pipeline attempts to load DICOM files (`.dcm`) using `cv2.imread`, which does not support the DICOM format in standard builds. The environment lacks specialized libraries like `pydicom` or `gdcm` to handle these files natively.

To resolve this, I will implement a robust "Cascading Fallback" loading strategy in `library/data.py` (Cite debug_lesson_8). The new `load_image` function will:
1.  Prioritize loading pre-processed `.npy` or `.png` files if they exist, decoupling ingestion from complex parsing (Cite debug_lesson_4).
2.  Attempt to load the original file with `cv2`.
3.  Fall back to `PIL.Image` (via `torchvision`'s dependency), which may support different formats or transfer syntaxes.
4.  As a critical fallback, search the raw binary stream for JPEG magic bytes (`0xFF 0xD8`) and decode the payload using `cv2.imdecode` (Cite debug_lesson_8).

This approach addresses the lack of DICOM drivers by leveraging available codecs for the underlying image data, while avoiding the "silent failure" of returning black images (Cite debug_lesson_10).

    def load_image(self, rel_path):
        """
        Loads an image from disk using cascading fallbacks.
        Supports .dcm (via PIL/Fallbacks), .png, and .npy.
        """
        if rel_path is None:
            return None

        full_path = os.path.join(Config.INPUT_DIR, rel_path)

        # 1. Check for pre-processed .npy (Cite debug_lesson_4)
        # This decouples ingestion from complex parsing
        npy_path = os.path.splitext(full_path)[0] + ".npy"
        if os.path.exists(npy_path):
            try:
                return np.load(npy_path)
            except Exception:
                pass

        # 2. Check for pre-processed .png
        png_path = os.path.splitext(full_path)[0] + ".png"
        if os.path.exists(png_path):
            img = cv2.imread(png_path, cv2.IMREAD_GRAYSCALE)
            if img is not None:
                return img

        if not os.path.exists(full_path):
            raise FileNotFoundError(f"Image file not found: {full_path}")

        # 3. Try OpenCV (Standard)
        img = cv2.imread(full_path, cv2.IMREAD_GRAYSCALE)
        if img is not None:
            return img

        # 4. Try PIL (Fallback) (Cite debug_lesson_8)
        # PIL handles some formats cv2 misses
        try:
            from PIL import Image
            with Image.open(full_path) as pil_img:

            pass
