The implementation strategy is to address the `RuntimeError` (exit code 1) caused by the top-level import of `tensorflow` in `library/data.py`. TensorFlow is not fork-safe, and importing it globally initializes thread pools that corrupt the state of child processes spawned by PyTorch's `DataLoader` (Cite debug_lesson_12). I will move the `tensorflow` import inside the `load_image` method (lazy loading) so it is only initialized within the worker processes. Additionally, I will ensure the GPU memory allocation restriction is applied within this lazy import block to prevent OOM errors (Cite debug_lesson_13).
