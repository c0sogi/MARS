2.  **Implement Cascading Fallbacks in `_load_image`**:
    *   Attempt to load with `cv2.imread`.
    *   Fallback to `rasterio.open` if `cv2` fails.
    *   Fallback to raw binary reading (`cv2.imdecode` or direct buffer reshaping) if `rasterio` fails.
    *   **Graceful Failure**: If all methods fail (or the file is missing), return a black image (zeros) instead of raising an exception. This ensures the `DataLoader` continues to function even with corrupt files (Cite debug_lesson_8).
3.  **Disable Multiprocessing in Debug Mode**: Update `get_dataloaders` to set `num_workers=0` when `debug=True`. This prevents "zombie" worker processes from exhausting system RAM and causing misleading OOM errors during debugging (Cite debug_lesson_32).
