Based on the analysis of the previous attempts and the specific lessons learned, I propose the following optimized strategy.

### Model
**Architecture: Stochastic Metadata-Regularized EfficientNet-B2**

*   **Backbone Upgrade:** Utilize **EfficientNet-B2**. While the B0 baseline converged, the B2 variant provides the necessary increase in parameter count and receptive field to resolve fine-grained microcalcifications, which are critical for this task, without incurring the massive computational cost of larger models.
*   **Input Strategy (Early Fusion):** Retain the **Spatial Channel Expansion** technique. The input tensor will be $3 \times H \times W$, comprising:
    1.  **Image Channel:** The preprocessed mammogram.
    2.  **Age Channel:** A spatially broadcasted map of the patient's age.
    3.  **Implant Channel:** A spatially broadcasted map of the binary implant status.
    *   *Cite Lesson 00002:* This structure allows the convolutional filters to learn context-aware features (entangling demographics with texture) from the first layer, which is structurally superior to Late Fusion for this dataset.
*   **Structural Innovation (Stochastic Modality Dropout):** Introduce a custom **Metadata Dropout Layer** immediately after the input construction. During training, this layer will randomly zero out the **Age** and **Implant** channels with a probability of $p=0.5$, while leaving the Image channel intact.
    *   *Rationale:* Previous experiments failed because the model engaged in "shortcut learning," relying heavily on the strong demographic prior (Age) and ignoring the complex visual signal, evidenced by high error-age correlations (*Cite Lesson 00012, Lesson 00014*). By intermittently removing the metadata, the network is forced to minimize loss using *only* the visual features for half the training steps, thereby robustly learning to identify tumor patterns without becoming an "age regressor."

### Data
**Preprocessing & Augmentation**

*   **Robust Data Loading:** Implement a data loader that **raises an exception** immediately if an image file is missing or corrupt, rather than returning a default zero-tensor.
    *   *Cite Lesson 00016:* Silent fallbacks in previous attempts masked pipeline failures, leading to model collapse. "Failing loudly" ensures we are training on actual data.
*   **Resolution:** Resize images to **768x768**. This higher resolution aligns with the B2 backbone's capacity and is necessary to preserve tissue density details.
*   **Metadata Normalization:** Apply **Standard Scaling** (Zero Mean, Unit Variance) to the Age feature before spatial broadcasting.
    *   *Cite Lesson 00005:* This ensures the metadata channel has unit variance, preventing it from being overpowered by image features (as seen with MinMax scaling) or dominating gradients due to magnitude.
*   **Augmentation Strategy:**
    *   Apply **Moderate Geometric Augmentations** (Shift, Scale, Rotate, Flip) to prevent overfitting.
    *   **Disable Photometric Augmentation:** Do not use brightness or contrast shifts.
    *   *Cite Lesson 00008:* In mammography, pixel intensity represents physical tissue density. Aggressive photometric augmentation destroys this primary diagnostic signal and degrades performance.

### Training
**Procedure**

*   **Loss Function:** Use `BCEWithLogitsLoss` with `pos_weight` set to approximately **47.0** (the inverse class frequency).
    *   *Cite Lesson 00003:* In this highly imbalanced regime (<3% positive), aggressive positive weighting is required to maintain Probabilistic Recall; conservative weights cause the model to collapse to the majority class.
*   **Gradient Strategy:** **Disable Gradient Clipping**.
    *   *Cite Lesson 00009:* Clipping gradients when using a high `pos_weight` neutralizes the weighting mechanism, leading to slow convergence and poor minority class prioritization.
*   **Optimizer & Schedule:** Use AdamW with a learning rate of 1e-4 and a Cosine Annealing scheduler.

### Evaluation
**Inference Pipeline**

*   **State:** Disable the Stochastic Modality Dropout layer (always provide full metadata channels) to maximize predictive power during inference.
*   **Aggregation:** For each `prediction_id` (representing a breast), generate predictions for all associated images (views). Compute the **Max** probability across these views to determine the final cancer likelihood.
