The following script demonstrates the end-to-end usage of the provided breast cancer detection library. It covers data loading, model instantiation, training, and inference.

Strategy:
1.  **Setup**: Initialize the environment and set random seeds for reproducibility.
2.  **Data Loading**: Use `library.data.get_dataloaders` to load a small subset (`max_samples=16`) of the training, validation, and test data. This ensures the demonstration runs quickly.
3.  **Data Verification**: Iterate through a single batch from the training loader to verify the shape and type of the input tensors (Target Image, Contralateral Image) and labels.
4.  **Model Initialization**: Instantiate the `PyramidSiameseEfficientNet` model from `library.model`.
5.  **Forward Pass Verification**: Pass the verified batch through the model to ensure the output logits have the correct shape `(Batch_Size, 1)`.
6.  **Training Loop**: Initialize the `Trainer` class and run a single epoch of training (`fit(epochs=1)`). This demonstrates the optimization step and metric calculation without consuming excessive time.
7.  **Inference**: Call `library.inference.generate_predictions` on the test subset to verify the submission file generation process.
8.  **Metric Validation**: Manually verify the `probabilistic_f1` function with synthetic data to ensure metric correctness.
