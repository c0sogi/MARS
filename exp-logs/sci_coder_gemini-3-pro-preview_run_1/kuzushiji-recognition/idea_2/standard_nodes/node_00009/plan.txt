The root cause of the `torch.OutOfMemoryError` is the excessive GPU memory consumption required to store the dense classification heatmap and its associated gradients. With a batch size of 8, 4,782 classes, and a $256 \times 256$ spatial resolution, the output tensor alone consumes approximately 9.34 GB. Combined with the backbone activations and other heads, this exceeds the 40GB VRAM capacity of the A100 GPU (Cite debug_lesson_1).

To resolve this, I will reduce the `BATCH_SIZE` in `library/config.py` from 8 to 4. This will halve the memory footprint of the high-cardinality output tensors and intermediate feature maps, allowing the model to fit within the available GPU memory.
