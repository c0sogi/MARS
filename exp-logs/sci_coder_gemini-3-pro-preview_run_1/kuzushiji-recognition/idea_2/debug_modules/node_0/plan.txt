The following script demonstrates the usage of the provided Kuzushiji character recognition library. It systematically verifies the core components: configuration, utility functions, dataset loading, model architecture, loss calculation, training engine, and inference pipeline.

To ensure rapid execution within the demonstration context, the script overrides the default configuration to use a minimal number of epochs and a small batch size. It performs validation checks on data shapes, tensor dimensions, and loss values to confirm the logic is functioning correctly. Finally, it executes a complete training and inference cycle on a debug subset of the data.
