# Optimized Strategy: HRNet with Deformable Convolutions

## Model
I propose replacing the ResNet-based "U-Net" style architecture with a **High-Resolution Network (HRNet-W32)** backbone augmented with **Deformable Convolutions (DCN)** in the detection heads.

*   **Backbone (HRNet-W32):** Unlike ResNet, which downsamples the feature map to 1/32 scale and then tries to recover spatial details via upsampling (the "Neck"), HRNet maintains high-resolution representations throughout the entire forward pass by connecting high-to-low resolution subnetworks in parallel. This structural change ensures that spatial precision—critical for separating dense, small characters—is never lost, addressing the need for high-capacity feature extraction **Cite solution_lesson_node_00004**.
*   **Adaptive Receptive Field (DCN):** I will insert a Deformable Convolution layer before the final prediction heads. Standard convolutions use a fixed rectangular grid, which struggles when the geometric center of a large, cursive character lands on empty whitespace (a key failure mode). DCNs learn dynamic offsets for their sampling grid, allowing the model to "reach out" and aggregate features from the actual ink strokes of the character to predict the center point effectively **Cite solution_lesson_node_00002**.

## Data
*   **Preprocessing:** Images will be resized to `1024x1024` with padding to preserve aspect ratio, consistent with the successful baseline.
*   **Augmentation:** I will strictly employ **geometric augmentations** (Random Scaling, Shifting, Rotation, and Shearing). Based on the negative results from photometric experiments, I will explicitly **exclude** Gaussian noise, blurring, and color jittering. These techniques destroy the high-frequency edge information (strokes) required for Optical Character Recognition (OCR) **Cite solution_lesson_node_00006**.

## Training
*   **Loss Functions:**
    *   **Heatmap:** Penalty-Reduced Focal Loss to handle class imbalance between centers and background.
    *   **Classification:** Cross-Entropy Loss applied only at ground truth center locations.
    *   **Regression:** L1 Loss for predicting bounding box dimensions and local offsets.
*   **Optimization:** Use the **AdamW** optimizer with a **Cosine Annealing** scheduler.
*   **Duration:** Train for **40 epochs**. The HRNet architecture is more complex than ResNet18, and the high-cardinality classification head requires sufficient iterations to converge **Cite solution_lesson_node_00004**.

## Evaluation
*   **Inference:** Pass test images through the HRNet+DCN model.
*   **Decoding:** Apply 3x3 Max Pooling to the output heatmap to extract local peaks. Select the top 1,200 peaks with confidence scores above a threshold (e.g., 0.1).
*   **Submission:** Map the predicted center coordinates from the 1024x1024 space back to the original image dimensions. The predicted class and center coordinates will be formatted directly for submission, leveraging the anchor-free alignment with the metric **Cite solution_lesson_node_00002**.
