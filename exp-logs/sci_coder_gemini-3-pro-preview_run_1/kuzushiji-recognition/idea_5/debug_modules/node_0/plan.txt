### Implementation Strategy

1.  **Configuration Override**: To ensure the script runs quickly within the demonstration constraints, I will dynamically modify the `Config` class attributes. I will set `DEBUG_SAMPLE_SIZE` to a small number (20) and `NUM_EPOCHS` to 1.
2.  **Reproducibility**: I will explicitly set random seeds for `torch`, `numpy`, and `random` at the start of the execution.
3.  **Dataset Verification**: I will instantiate the `KuzushijiDataset`, retrieve a single sample, and verify the shapes and data types of the generated tensors (image, heatmap, regression maps, indices).
4.  **Model & Loss Verification**: I will instantiate the `SwinCenterNet` model and pass the sample batch through it. I will check the output shapes of the heads (heatmap, width/height, regression, classification). Then, I will compute the loss using `CenterNetLoss` to ensure the forward pass and loss calculation logic are functioning correctly.
5.  **Training Loop Demonstration**: I will initialize the `Trainer` class and execute the `fit()` method. This will run a single epoch of training on the small debug dataset and save the best model.
6.  **Inference Demonstration**: I will run the `generate_submission` function using the trained model weights on a small subset of the test data.
7.  **Output Validation**: Finally, I will verify that the submission file is generated correctly and adheres to the required CSV format.
