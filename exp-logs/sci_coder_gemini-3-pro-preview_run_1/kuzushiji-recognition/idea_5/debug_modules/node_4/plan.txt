The `RuntimeError` in `library/loss.py` arises because the `_transpose_and_gather_feat` function returns a tensor with non-contiguous strides (a result of the `.permute()` operation). The downstream code attempts to reshape this tensor using `.view()`, which strictly requires a contiguous memory layout (Cite debug_lesson_11). To resolve this while maintaining the memory efficiency of processing only sparse detections (Cite debug_lesson_3), I will modify `_transpose_and_gather_feat` in `library/utils.py` to explicitly return a contiguous tensor.
