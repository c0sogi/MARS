# Optimized Strategy: Swin-Transformer CenterNet with Deformable Heads

## Model
I propose a hybrid architecture that combines the global context capabilities of Transformers with the geometric flexibility of Deformable Convolutions.

*   **Backbone (Swin Transformer - Base):** I will replace the CNN-based backbones (ResNet, HRNet) with a **Swin Transformer (Swin-B)**.
    *   **Addressing Failure Modes:** Previous experiments revealed that center-based detectors struggle with large, cursive characters because the geometric center often falls on empty whitespace, where local features are non-discriminative **Cite solution_lesson_node_00002**. The Swin Transformer's shifted-window self-attention mechanism allows the model to dynamically aggregate information from the ink strokes at the periphery of the character into the center representation, effectively solving this "blind spot."
    *   **Capacity:** The "Base" variant provides the high parameter capacity necessary to distinguish between the 3,800+ fine-grained classes, addressing the underfitting observed with lighter backbones **Cite solution_lesson_node_00004**.
*   **Neck (FPN):** A Feature Pyramid Network will be used to fuse multi-scale features (strides 4, 8, 16, 32). This is critical for handling the extreme scale variance between tiny inline annotations and large main-text characters.
*   **Heads (Deformable CenterNet):** The prediction heads (Heatmap, Regression, Classification) will utilize **Deformable Convolutions (DCNv2)** instead of standard convolutions. While the backbone captures global context, DCNs in the head allow the final sampling grid to adapt to the irregular, curved geometry of Kuzushiji characters, further refining localization accuracy **Cite solution_lesson_node_00002**.

## Data
*   **Preprocessing:**
    *   **Normalization:** Images will be resized to `1024x1024` and, crucially, **normalized using standard ImageNet mean and standard deviation**. This strict adherence to the pretrained model's input statistics is vital to prevent the catastrophic failure (0.0 F1 score) observed when normalization was omitted **Cite solution_lesson_node_00012**.
*   **Augmentation:**
    *   **Geometric Only:** The pipeline will exclusively employ geometric augmentations: **Random Scaling, Random Shifting, and Random Rotation**.
    *   **Exclusion:** I will explicitly **exclude** all photometric augmentations (Gaussian noise, blurring, color jitter). As established, these distortions degrade the high-frequency edge information (ink strokes) that constitutes the primary signal for OCR tasks **Cite solution_lesson_node_00006**.

## Training
*   **Loss Functions:**
    *   **Heatmap:** Penalty-Reduced Focal Loss to manage the foreground-background class imbalance.
    *   **Classification:** Cross-Entropy Loss applied only at ground truth center locations.
    *   **Regression:** L1 Loss for predicting bounding box dimensions and local offsets.
*   **Optimization:** Use the **AdamW** optimizer (standard for Transformers) with a **Cosine Annealing** learning rate scheduler.
*   **Duration:** The model will be trained for **30-40 epochs**. The increased capacity of the Swin-B backbone requires a sufficient training horizon to converge fully, as seen with ResNet50 **Cite solution_lesson_node_00004**.

## Evaluation
*   **Inference:** Pass test images through the network.
*   **Decoding:** Apply 3x3 Max Pooling to the output heatmap to extract local peaks. Select the top 1,200 peaks with a confidence score above 0.1.
*   **Submission:** Map the predicted center coordinates from the 1024x1024 model space back to the original image dimensions. This anchor-free output format aligns directly with the evaluation metric, requiring no heuristic box-to-point conversion **Cite solution_lesson_node_00002**.
