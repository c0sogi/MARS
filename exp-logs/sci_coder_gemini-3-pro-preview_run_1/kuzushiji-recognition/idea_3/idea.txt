# Optimized Strategy: Swin Transformer-based CenterNet with Geometric Augmentation

## Model
I propose a structural evolution by replacing the CNN-based backbones (ResNet, HRNet) with a **Swin Transformer (Swin-B)** backbone.

*   **Backbone (Swin-B):** Unlike the fixed receptive fields of ResNet (Idea 1) or HRNet (Idea 2), the Swin Transformer utilizes shifted-window self-attention. This allows the model to dynamically aggregate global context from the character's strokes into the center representation. This structural innovation directly addresses the failure mode where the geometric center of large, cursive characters falls on empty whitespace, making local convolution features non-discriminative **Cite solution_lesson_node_00002**. The "Base" variant (Swin-B) provides the necessary parameter capacity to model the fine-grained distinctions between the 3,800+ character classes **Cite solution_lesson_node_00004**.
*   **Neck (FPN):** A Feature Pyramid Network (FPN) will be used to fuse the hierarchical features from the Swin backbone (strides 4, 8, 16, 32) and upsample them to a unified high-resolution feature map (stride 4). This ensures the model can detect both small annotations and large main-text characters effectively.
*   **Head:** The model will retain the **Anchor-Free CenterNet Head** (Heatmap, Regression, Classification). This aligns perfectly with the evaluation metric and avoids the complexity of anchor box design for irregular shapes **Cite solution_lesson_node_00002**.

## Data
*   **Preprocessing:** Images will be resized to `1024x1024` with padding to preserve the aspect ratio.
*   **Augmentation:** I will strictly employ **Geometric Augmentations** (Random Scaling, Random Shifting, and Random Rotation). Crucially, I will **exclude** all photometric augmentations (Gaussian noise, blurring, color jitter). As established in the lessons, these distortions degrade the high-frequency edge information (ink strokes) that is vital for distinguishing characters in OCR tasks **Cite solution_lesson_node_00006**.

## Training
*   **Loss Functions:**
    *   **Heatmap:** Penalty-Reduced Focal Loss to handle the extreme foreground-background imbalance.
    *   **Classification:** Cross-Entropy Loss applied only at the ground truth center locations.
    *   **Regression:** L1 Loss for bounding box size and local offsets.
*   **Optimizer:** Use **AdamW**, which is standard for stabilizing Transformer training, with a **Cosine Annealing** learning rate scheduler.
*   **Duration:** Train for **40 epochs**. The high capacity of the Swin-B backbone and the complexity of the classification head require an extended training schedule to ensure full convergence **Cite solution_lesson_node_00004**.

## Evaluation
*   **Inference:** Forward pass the test images through the Swin-CenterNet model.
*   **Decoding:** Apply 3x3 Max Pooling to the output heatmap to extract local peaks. Select the top 1,200 peaks with a confidence score above 0.1.
*   **Submission:** Map the predicted center coordinates from the 1024x1024 model space back to the original image dimensions. The result will be formatted as `image_id, {label X Y} ...`, leveraging the direct alignment between the anchor-free prediction and the metric **Cite solution_lesson_node_00002**.
