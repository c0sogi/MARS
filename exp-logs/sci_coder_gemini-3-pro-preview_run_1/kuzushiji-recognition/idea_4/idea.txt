# Optimized Strategy: ConvNeXt-Base CenterNet with Deformable Heads

## Model
I propose replacing the ResNet backbone with a **ConvNeXt-Base** architecture, integrated with a **Feature Pyramid Network (FPN)** and **Deformable Convolution (DCNv2)** heads.

*   **Backbone (ConvNeXt-Base):** This architecture represents a structural evolution from the ResNet50 baseline. It modernizes the standard Convolutional Neural Network (CNN) by adopting "Transformer-style" design principles—specifically, using larger kernels ($7 \times 7$) and inverted bottlenecks. This provides two critical advantages:
    1.  **High Capacity:** With ~88M parameters, it significantly scales up the representational power compared to ResNet50 (~25M), directly addressing the need for capacity to handle the 3,800+ fine-grained classes **Cite solution_lesson_node_00004**.
    2.  **Large Receptive Field:** The larger kernels allow the model to capture global context and "see" the ink strokes of a character even when the geometric center lies on empty whitespace, mitigating the key failure mode of center-based detectors on large cursive text **Cite solution_lesson_node_00002**.
*   **Neck (FPN):** A Feature Pyramid Network will be employed to fuse features from multiple backbone stages. This ensures robust detection across the extreme scale variations of Kuzushiji characters (from tiny annotations to large headers).
*   **Heads (DCNv2):** Instead of standard convolutions, the prediction heads (Heatmap, Regression, Classification) will use **Deformable Convolutions**. These layers learn dynamic offsets to the sampling grid, allowing the model to adaptively aggregate features from the irregular, curved strokes of the characters rather than a fixed rectangular context **Cite solution_lesson_node_00002**.

## Data
*   **Preprocessing:** Images will be resized to `1024x1024` with padding to preserve the original aspect ratio.
*   **Augmentation:** The pipeline will strictly utilize **Geometric Augmentations** (Random Scaling, Random Shifting, Random Rotation, and Shearing).
    *   **Exclusion:** I will explicitly **exclude** all photometric augmentations (Gaussian noise, blur, color jitter). As determined in previous experiments, these distortions destroy the high-frequency edge information (strokes) that constitutes the primary signal for character recognition **Cite solution_lesson_node_00006**.

## Training
*   **Loss Functions:**
    *   **Heatmap:** Penalty-Reduced Focal Loss.
    *   **Classification:** Cross-Entropy Loss (at positive centers only).
    *   **Regression:** L1 Loss (for offsets and size).
*   **Optimizer:** **AdamW** with a **Cosine Annealing** scheduler.
*   **Duration:** Training will be extended to **40 epochs**. The increased capacity of the ConvNeXt-Base backbone requires a longer training horizon to fully converge compared to smaller ResNet variants **Cite solution_lesson_node_00004**.

## Evaluation
*   **Inference:** Forward pass test images through the ConvNeXt-CenterNet model.
*   **Decoding:** Apply 3x3 Max Pooling to the heatmap to extract local peaks. Select the top 1,200 peaks with confidence > 0.1.
*   **Submission:** Map the predicted center coordinates from the model space back to the original image dimensions. This anchor-free approach ensures direct alignment with the evaluation metric **Cite solution_lesson_node_00002**.
