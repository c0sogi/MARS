The following script demonstrates the usage of the provided library modules for the Kuzushiji character recognition task. It systematically verifies the data loading pipeline, model architecture, loss calculation, and the full training/inference loop.

The script performs the following steps:
1.  **Data Pipeline Verification**: Parses metadata, initializes the dataset in debug mode, and verifies the structure and shapes of a collated batch (images and dense targets).
2.  **Coordinate Transformation**: Validates the `post_process_coords` utility to ensure model predictions map correctly back to original image dimensions.
3.  **Model & Loss Verification**: Instantiates the `ConvNextCenterNet` and `CenterNetLoss`, runs a forward pass with a sample batch, and asserts that the loss is calculated correctly without NaNs.
4.  **End-to-End Execution**: Runs a short training session (1 epoch on a subset of data) and generates predictions using the `engine` module to verify the complete workflow.
