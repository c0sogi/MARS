The issue is a **CUDA Out-Of-Memory (OOM)** error caused by the massive size of the classification prediction tensor and an inefficient loss calculation strategy. With a batch size of 16 and ~4800 classes on a 256x256 grid, the tensor requires ~18.7 GiB. The `MaskedCrossEntropyLoss` attempts to `reshape` this entire tensor into a contiguous flat matrix, forcing a memory allocation that exceeds the GPU's capacity.

To resolve this, I will:
1.  **Reduce Batch Size**: Update `library/config.py` to lower `BATCH_SIZE` from 16 to 4, significantly reducing the memory footprint per iteration.
2.  **Optimize Loss Implementation**: Update `library/loss.py` to use boolean indexing. Instead of reshaping the full `(B, C, H, W)` tensor, I will extract only the relevant prediction vectors at the object centers defined by the mask. This avoids creating the large intermediate dense tensor.
