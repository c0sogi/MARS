The `torch.OutOfMemoryError` was caused by an excessively large batch size (`32`) configured in `runfile.py`. The model's classification head produces a dense output map of shape `(Batch, Num_Classes, Height/4, Width/4)`. With 4782 classes and a 1024x1024 input (resulting in 256x256 feature maps), a single batch of 32 requires approximately 37.36 GiB of memory for the output tensor alone, exceeding the GPU's available capacity.

To fix this, I will reduce `Config.BATCH_SIZE` in `runfile.py` from 32 to 4. This reduces the memory requirement for the classification tensor to approximately 4.7 GiB, which fits comfortably within the A100's memory alongside the model weights, gradients, and other intermediate activations.
