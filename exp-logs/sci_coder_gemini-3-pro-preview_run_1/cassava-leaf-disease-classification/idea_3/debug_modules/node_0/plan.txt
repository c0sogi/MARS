The following script demonstrates the usage of the provided library files to train, validate, and infer on the Cassava Leaf Disease dataset.

**Implementation Strategy:**
1.  **Setup & Overrides**: We import the `CFG` class and override key parameters (paths, epochs, batch size, model architecture) to ensure the script runs quickly (under 5 minutes) and uses a small subset of the data.
2.  **Data Subsetting**: We read the existing metadata files, sample a small fraction (e.g., 100 images), and save these subsets to the working directory. This simulates the full pipeline without the time cost.
3.  **Pipeline Execution**:
    *   **Loaders**: We use `get_loaders` to create PyTorch DataLoaders from the subset metadata.
    *   **Model**: We instantiate the `CassavaConvNeXt` wrapper. For demonstration speed, we patch `CFG.model_name` to `resnet18`.
    *   **Train/Val**: We run one training epoch and one validation epoch using the engine functions.
    *   **Inference**: We run the inference function with TTA on the test subset.
4.  **Verification**: We include assertions to check that loss is a valid float, output shapes are correct, and the submission file is generated properly.
