Implementation strategy:
1.  **Setup & Initialization**: Set global seeds for reproducibility and initialize the device (GPU).
2.  **Stage 1 (Warmup)**: Initialize the `CassavaConvNeXt` model. Freeze the backbone and train only the head for 1 epoch at 384x384 resolution to stabilize weights.
3.  **Stage 2 (Base Training)**: Unfreeze the backbone. Train the full model for 12 epochs at 384x384 using AdamW and Cosine Annealing scheduler. Save the best model based on validation accuracy.
4.  **Stage 3 (Fine-tuning)**: Load the best model from Stage 2. Increase image resolution to 512x512 (Progressive Resizing). Fine-tune for 5 epochs with a reduced learning rate. Save the best model.
5.  **Validation & Analysis**: Load the best performing model. Compute the final validation metric on the full hold-out set. Perform failure analysis by correlating prediction errors with file size.
6.  **Submission**: If the final validation metric exceeds the strict threshold (0.8972), generate predictions for the test set using Test Time Augmentation (TTA) and save `submission.csv`.
