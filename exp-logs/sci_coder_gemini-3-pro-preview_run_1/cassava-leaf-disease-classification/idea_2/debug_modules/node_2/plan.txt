The `albumentations` library version 2.0.8 introduced breaking changes to the API for transforms like `RandomResizedCrop`. The error `ValidationError: scale Input should be a valid tuple` indicates that the positional arguments `(CFG.image_size, CFG.image_size)` are being misinterpreted; specifically, the second integer is being assigned to the `scale` parameter (which expects a tuple), while `size` (the first parameter) also expects a tuple. To fix this, I will update `RandomResizedCrop` to use the `size` keyword argument with a tuple `(CFG.image_size, CFG.image_size)`. I will also update `Resize` to use explicit `height` and `width` keyword arguments to ensure strict compatibility.
