The following implementation orchestrates the training, validation, failure analysis, and submission generation for the Cassava Leaf Disease Classification task. It adheres to the "fast baseline" requirement by limiting the number of epochs while using the powerful EfficientNet-B4 backbone with Multi-Sample Dropout and CutMix/MixUp augmentation.

The script performs the following steps:
1.  **Setup**: Initializes the environment with fixed seeds for reproducibility and configures the logger.
2.  **Data Loading**: Loads metadata and creates DataLoaders. The training loader uses a custom `CollateMixupCutmix` for strong augmentation, while validation uses standard transforms.
3.  **Two-Stage Training**:
    *   **Stage 1**: Freezes the backbone and trains only the head for 1 epoch to stabilize weights.
    *   **Stage 2**: Unfreezes the full model and fine-tunes for additional epochs using a Cosine Annealing scheduler.
4.  **Failure Analysis**: Evaluates the best model on the validation set, calculates the final metric, and computes correlations between prediction errors and metadata (Label, File Size).
5.  **Submission**: If the validation accuracy exceeds the specified threshold, it generates predictions on the test set using Test Time Augmentation (TTA) and saves the submission file.
