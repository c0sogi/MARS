This script demonstrates the usage of the provided Cassava Leaf Disease Classification library. It performs the following steps:

1.  **Configuration & Setup**: Modifies the global `Config` to use lightweight parameters (small image size, few epochs, small batch size) suitable for a quick demonstration.
2.  **Data Loading Verification**: Creates a small subset of the training data, initializes the `CassavaDataset` and `DataLoader`, and verifies the `MixupCollate` function ensures targets are one-hot encoded or mixed correctly.
3.  **Model Architecture Verification**: Instantiates the `CassavaClassifier` using a lightweight backbone (`resnet18`) to avoid large downloads. It validates the output shapes of the backbone, GeM pooling, and the final classifier head.
4.  **Loss Function Verification**: Tests the `SoftTargetCrossEntropy` loss with dummy tensors to ensure mathematical correctness.
5.  **Training Loop Demonstration**: Runs a single epoch of training and validation using the subset data. It verifies that the loss decreases or is computed correctly and that the optimizer updates weights.
6.  **SWA (Stochastic Weight Averaging) Demonstration**: Simulates the SWA update and finalization process.
