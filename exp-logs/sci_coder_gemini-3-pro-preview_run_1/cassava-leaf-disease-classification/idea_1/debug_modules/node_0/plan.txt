The following script demonstrates the usage of the provided library files.

**Implementation Strategy**

1.  **Configuration Override**: We first modify the `Config` class attributes to enable `DEBUG` mode, reduce `EPOCHS` to 1, and set a small `DEBUG_SUBSET_SIZE`. This ensures the demonstration runs quickly.
2.  **Utility Verification**: We demonstrate `seed_everything` and `compute_class_weights`, asserting that the calculated weights have the correct shape and device placement.
3.  **Data Pipeline Verification**: We initialize data loaders using `get_dataloaders` and fetch a single batch to validate the tensor shapes of images and labels.
4.  **Model Verification**: We instantiate the `CassavaClassifier`, perform a forward pass to check output dimensions, and verify the logic of `freeze_backbone` and `unfreeze_backbone`.
5.  **Full Pipeline Execution**: We execute the `run` function from `library.engine`. This runs a complete training epoch, validation, and inference step.
6.  **Submission Validation**: Finally, we verify that the submission file is created correctly and matches the expected format and size.
