The error `RuntimeError: shape '[-1, 16, 3, 256, 256]' is invalid` occurs because the Swin Transformer model was initialized with its default resolution (256x256), creating fixed-size attention masks and window configurations (16 windows). However, the training loop provided 384x384 images (Phase 1), which require a different window configuration (36 windows). This mismatch causes the attention mechanism to fail (Cite debug_lesson_5).

To fix this, I will:
1.  Update `CassavaClassifier` in `library/modeling.py` to accept an `image_size` argument and pass it to `timm.create_model`. This ensures the model initializes its internal buffers (masks) for the correct resolution.
2.  Update `runfile.py` to pass the correct `image_size` during Phase 1 (384) and Phase 2 (512) initialization.
3.  In `runfile.py` (Phase 2), explicitly re-initialize the model with the new resolution (512) and filter out the incompatible `attn_mask` buffers when loading the weights from Phase 1. This allows the model to regenerate the correct masks for the new resolution while retaining learned weights.
4.  Update `library/inference.py` to initialize the model with the inference resolution (512).
