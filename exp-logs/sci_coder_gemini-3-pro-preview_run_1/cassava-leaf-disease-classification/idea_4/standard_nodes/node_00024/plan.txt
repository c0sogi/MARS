The issue stems from the use of `.squeeze()` without arguments on the gathered probabilities tensor. When the batch size is 1 (which occurs in the final batch of the validation set), `probs.gather(...)` returns a tensor of shape `(1, 1)`. Calling `.squeeze()` collapses this to a scalar tensor `()`, and `.tolist()` subsequently returns a single `float` instead of a `list`. The `extend` method then fails because it expects an iterable. The fix is to use `.squeeze(1)` to strictly remove the second dimension (index 1), ensuring the result is always a 1D tensor `(N,)` (even if N=1), which `.tolist()` converts to a list.
