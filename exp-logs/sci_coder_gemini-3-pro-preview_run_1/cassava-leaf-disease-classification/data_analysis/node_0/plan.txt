The implementation strategy involves a robust Python script that performs Exploratory Data Analysis (EDA) on the Cassava Leaf Disease dataset. The script is structured to handle the specific requirements of image classification tasks while ensuring data integrity by strictly using the training set.

**Strategy Outline:**
1.  **Setup & Configuration**: Initialize random seeds for reproducibility and define paths. Load the metadata (`./metadata/train.csv`) and the disease mapping JSON.
2.  **Target Variable Analysis**: Analyze the distribution of the `label` column, mapping IDs to disease names. Calculate class frequencies and imbalance ratios to identify if the dataset is skewed.
3.  **Image Data Analysis**:
    *   Iterate through the training images defined in the metadata.
    *   Extract physical properties: Width, Height, Aspect Ratio, and File Size.
    *   Detect channel counts (e.g., RGB vs. RGBA vs. Grayscale) using OpenCV.
    *   Compute Global Pixel Mean and Standard Deviation (normalized to [0, 1]) using a statistically significant random sample of images to ensure efficiency within the runtime limit.
4.  **Feature/Signal Relationships**:
    *   Construct a metadata dataframe containing image properties and labels.
    *   Analyze relationships by grouping meta-features (file size, dimensions) by disease class to check for systematic biases (e.g., "Does one disease have consistently lower resolution images?").
5.  **Reporting**: Output the findings in a clean, formatted text report with specific sections and 4-decimal precision, as requested.
