This script demonstrates the end-to-end workflow of the text normalization system using the provided library modules. It performs the following steps:
1.  **Configuration Override**: Modifies the `Config` class to run in a lightweight "Debug" mode, ensuring the script executes quickly by using small subsets of data and minimal training epochs.
2.  **Data Preparation**: Uses `load_data` to generate vocabularies, train a BPE tokenizer, build a knowledge base, and process training/validation datasets for both the Tagger and Seq2Seq models.
3.  **Model Initialization & Verification**: Instantiates the `PriorInformedTagger` and `CharLSTMSeq2Seq` models, verifying their architectures and forward pass outputs against expected shapes.
4.  **Training Simulation**: Runs a complete training epoch for both models using `TaggerTrainer` and `Seq2SeqTrainer`, validating that loss calculation and backpropagation function correctly.
5.  **Inference & Submission**: Executes the `InferencePipeline` on a subset of test data, generating predictions and saving them to a submission file, followed by format validation.
