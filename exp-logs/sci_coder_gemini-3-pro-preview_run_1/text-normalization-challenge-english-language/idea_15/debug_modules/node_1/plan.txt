The error `NameError: name 'Any' is not defined` occurs because the symbol `Any` is used in a type hint within the `TaggerDataset` class definition before it has been imported. In Python, names must be defined before they are referenced. The fix is to move `Any` from the import statement at the bottom of the file to the `typing` import block at the top of `library/datasets.py`.

```diff
library/datasets.py
<<<<<<< SEARCH
from typing import List, Dict, Optional, Tuple
=======
from typing import List, Dict, Optional, Tuple, Any
>>>>>>> REPLACE
```

```diff
library/datasets.py
<<<<<<< SEARCH
# Type alias for easier imports
from typing import Any
=======
>>>>>>> REPLACE
```
