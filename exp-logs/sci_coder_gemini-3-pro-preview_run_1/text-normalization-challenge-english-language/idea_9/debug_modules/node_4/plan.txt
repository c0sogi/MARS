The loop `for i, token_id in enumerate(ids):` assigns an entire list (or array) of IDs for a sentence to `token_id`, which then fails when used as a dictionary key. To fix this, I will implement a nested loop structure: the outer loop will iterate over the sentences in the batch, and the inner loop will iterate over the individual tokens within each sentence, ensuring that the correct token ID and corresponding predicted class index are processed.
