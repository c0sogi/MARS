Based on the accumulated lessons and the analysis of previous iterations, I propose the **Multi-Granularity Bi-LSTM Tagger with Transformer-Based Neural Fallback**.

This solution represents a structural evolution of "Idea 8" by enhancing the **Input Fidelity** of the Tagger (addressing Lesson 00009) and solidifying the **Generative Fallback** architecture (addressing Lesson 00027 and Lesson 00012).

### Model
The architecture follows the decoupled "Classify-Retrieve-Generate" paradigm **Cite {solution_lesson_node_00005}**, but introduces a **Multi-Granularity Input Layer** to eliminate information loss caused by Out-Of-Vocabulary (OOV) tokens.

1.  **Stage 1: Multi-Granularity Tagger (Classification)**
    *   **Structural Innovation (Input):** We will employ a **Tri-Hybrid Input Representation** to maximize fidelity **Cite {solution_lesson_node_00009}**:
        1.  **Word Embeddings:** A trainable embedding layer for the top $N$ most frequent words (capturing high-level semantics).
        2.  **Character-Level CNN:** A 1D-CNN processing character sequences to extract morphological features (e.g., digit patterns, capitalization), which are critical for normalization tasks.
        3.  **Subword (BPE) Embeddings:** We introduce **Byte-Pair Encoding (BPE)** embeddings. Unlike word embeddings which map rare words to `<UNK>`, and Char-CNNs which focus on local patterns, BPE captures meaningful sub-word semantic units (e.g., "bio", "graphy") for rare words. This ensures the model has a robust representation for *every* token, effectively eliminating the `<UNK>` bottleneck.
    *   **Backbone:** These three representations are concatenated and fed into a **Bi-directional LSTM (Bi-LSTM)**. As proven, this recurrent architecture converges significantly faster and captures local dependencies better than raw Transformers for this specific tagging task **Cite {solution_lesson_node_00012}**.
    *   **Head:** A standard **Softmax Classification Head**. We explicitly reject the CRF layer, as lessons indicate it hinders convergence for this locally-determinable task **Cite {solution_lesson_node_00028}**.

2.  **Stage 2: Hybrid Normalization Strategy**
    *   **Primary (Deterministic Memory):** A **Knowledge Base (KB)** maps `(raw_token, predicted_class)` pairs to their normalized text. This handles the vast majority of cases (93%+) with 100% precision **Cite {solution_lesson_node_00005}**.
    *   **Secondary (Neural Fallback):** For OOV tokens, we employ a **Character-Level Transformer Seq2Seq Model**.
        *   **Architecture:** A Transformer Encoder-Decoder. Transformers are structurally superior to LSTMs for generating long, coherent character sequences (e.g., spelling out complex numbers) **Cite {solution_lesson_node_00027}**.
        *   **Conditioning:** The model is conditioned on the **Class Embedding** predicted by the Tagger, ensuring the generation follows the correct semantic rules (e.g., treating "2025" as a date vs. a cardinal).

### Data
1.  **Knowledge Base Construction:** We will construct the KB using the **entire training dataset** to maximize coverage **Cite {solution_lesson_node_00007}**.
2.  **Tagger Data:** The Tagger is trained on the full dataset. We will generate BPE tokens for the entire corpus using a standard tokenizer (e.g., trained on the input text) to populate the subword embedding layer.
3.  **Fallback Data:** We will create a specialized dataset by filtering the training data to include only token pairs where `before != after`. This focuses the Transformer on learning non-trivial transformations **Cite {solution_lesson_node_00027}**.

### Training
1.  **Tagger Training:**
    *   **Loss Function:** Cross-Entropy Loss with **Square-Root Smoothed Class Weights** ($\sqrt{N/N_c}$). This penalizes errors on rare classes (like `MONEY`) without the gradient instability caused by raw inverse frequency weights **Cite {solution_lesson_node_00013}**.
    *   **Optimizer:** **Adam** optimizer paired with a **ReduceLROnPlateau** scheduler. This dynamic schedule is essential for allowing the LSTM to escape local minima and converge to a better generalization point than static rates **Cite {solution_lesson_node_00011}**.
2.  **Fallback Training:** The Transformer Seq2Seq will be trained using standard Cross-Entropy Loss with Teacher Forcing on the filtered "changed" dataset.

### Evaluation
1.  **Inference Pipeline:**
    *   **Step 1 (Tagging):** Pass the test sentence through the **Multi-Granularity Bi-LSTM** to obtain the predicted class for each token.
    *   **Step 2 (Retrieval):** Query the **Knowledge Base** using `(token, predicted_class)`. If a match is found, return the stored value.
    *   **Step 3 (Generation):** If the pair is missing from the KB (OOV) and the class is not `PLAIN`, pass the token and its class to the **Transformer Fallback Model** to generate the normalized text. This ensures robust handling of the "long tail" of unseen entities **Cite {solution_lesson_node_00027}**.
