This script demonstrates the end-to-end usage of the provided text normalization library. It begins by creating a small, self-contained dataset subset to ensure rapid execution. It then systematically instantiates and verifies the functionality of feature extractors (Regex, BPE, Priors), data loaders, model architectures (Bi-LSTM Tagger and Seq2Seq), and training loops. Assertions are used throughout to validate tensor shapes and data integrity.
