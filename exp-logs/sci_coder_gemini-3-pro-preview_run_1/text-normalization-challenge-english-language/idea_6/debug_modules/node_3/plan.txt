The `BiLSTM_CRF` model currently registers the `class_weights` buffer conditionally, depending on whether weights are passed to `__init__`. This causes a `RuntimeError` during inference because the checkpoint contains the `class_weights` key (from training), but the inference model instance (initialized without weights) does not expect it. To resolve this structural mismatch (Cite debug_lesson_8), I will modify the initialization to always register `class_weights`, defaulting to a tensor of ones if no weights are provided. This ensures the state dictionary keys remain consistent between training and inference while maintaining correct functionality (identity weighting) when explicit weights are absent.
