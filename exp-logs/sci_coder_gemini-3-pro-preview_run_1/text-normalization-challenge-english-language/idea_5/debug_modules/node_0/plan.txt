The following script demonstrates the end-to-end usage of the provided text normalization library. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use a temporary directory and reduced hyperparameters for a fast demonstration.
2.  **Data Preparation**: Creates a small subset of the training data to speed up processing.
3.  **Vocabulary & Knowledge Base**: Builds vocabularies and the deterministic knowledge base from the data subset.
4.  **Dataset & DataLoader**: Instantiates datasets for both the Tagger and Seq2Seq models, verifying batch shapes and content.
5.  **Model Initialization**: Initializes the `BiLSTMTagger` and `Seq2SeqModel` with reduced dimensions.
6.  **Training Simulation**: Runs a minimal training loop (1 epoch) using the `Trainer` class to verify the training pipeline.
7.  **Inference**: Sets up the `NormalizationPipeline` and generates predictions for a sample test set.
