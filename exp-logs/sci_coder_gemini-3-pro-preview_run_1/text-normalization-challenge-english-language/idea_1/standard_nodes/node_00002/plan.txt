2.  **Training Instability (NaN Loss)**: The LSTM training suffered from exploding gradients, causing the loss to become `NaN`. Because the loss was invalid, the trainer never saved a *new* checkpoint, causing the inference step to fall back to the stale, incompatible checkpoint mentioned above.

1.  **Clear Cache**: Update `runfile.py` to delete the `working` directory at the start of execution. This ensures a fresh start with consistent data and no stale checkpoints.
