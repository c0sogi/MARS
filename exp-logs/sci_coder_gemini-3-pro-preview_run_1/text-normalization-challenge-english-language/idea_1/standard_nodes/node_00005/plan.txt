The issue is caused by the presence of stale, truncated data files (specifically `test_grouped.parquet`) in the working directory from a previous debug run. The `runfile.py` script currently only removes the model checkpoint but leaves the data cache intact. Consequently, the pipeline loads the cached 100-sentence test file instead of processing the full test dataset, leading to an incomplete submission and the "Submission must have the same length as the answers" error.

To fix this, I will modify `runfile.py` to clear the entire `Config.WORKING_DIR` at the start of execution. This ensures that all data files are regenerated from the source metadata, guaranteeing the full test set is used. This applies the principle of ensuring a clean state to prevent stale artifacts from causing downstream failures (Cite debug_lesson_1).
