Based on the accumulated lessons and the analysis of previous iterations, I propose the **Attention-Augmented Bi-LSTM Tagger with Transformer-Based Neural Fallback**. This strategy synthesizes the robust classification of the Bi-LSTM baseline with the superior generative capabilities of Transformers, while correcting the specific architectural flaws (CRF) identified in recent failures.

# Model
The solution retains the successful "Classify-Retrieve-Generate" paradigm **Cite {solution_lesson_node_00005}**, but introduces structural enhancements to both the classification and generation stages.

1.  **Stage 1: Attention-Augmented Tagger (Classification)**
    *   **Input Representation:** We strictly retain the hybrid input strategy to ensure high fidelity **Cite {solution_lesson_node_00009}**. This consists of a trainable Word Embedding layer (maximized vocabulary) concatenated with Morphological Features extracted by a **1D-CNN** over character sequences.
    *   **Backbone:** We employ a **Bi-directional LSTM (Bi-LSTM)**. As proven, this architecture converges significantly faster and captures local dependencies better than raw Transformers for this specific tagging task **Cite {solution_lesson_node_00012}**.
    *   **Structural Innovation (Attention):** We introduce a **Multi-Head Self-Attention Layer** on top of the Bi-LSTM outputs. While the LSTM captures local sequential context, the attention mechanism allows the model to explicitly model long-range dependencies and global sentence context before making a classification decision. This enhances disambiguation without the training instability of a full Transformer backbone.
    *   **Head:** We utilize a standard **Softmax Classification Head**. We explicitly reject the Conditional Random Field (CRF) layer, as previous experiments demonstrated that the local nature of text normalization labels makes CRFs unnecessary and detrimental to convergence **Cite {solution_lesson_node_00028}**.

2.  **Stage 2: Hybrid Normalization Strategy**
    *   **Primary (Deterministic Memory):** A **Knowledge Base (KB)** maps `(raw_token, predicted_class)` pairs to their normalized text. This handles the vast majority of cases (93%+) with 100% precision.
    *   **Secondary (Neural Fallback):** For Out-of-Vocabulary (OOV) tokens, we employ a **Class-Conditioned Character-Level Transformer**.
        *   **Structural Innovation:** We replace the LSTM-based fallback with a **Transformer Encoder-Decoder**. Transformers are structurally superior at handling the generation of long character sequences (e.g., spelling out complex numbers or dates) and are more robust to vanishing gradients. This model is conditioned on the class predicted by the Tagger, ensuring the generation follows the correct semantic rules **Cite {solution_lesson_node_00027}**.

# Data
1.  **Knowledge Base Construction:** We will construct the KB using the **entire training dataset**. Performance is strictly bounded by memory coverage, so maximizing the number of stored keys is critical **Cite {solution_lesson_node_00007}**.
2.  **Tagger Data:** The Tagger is trained on the full dataset. We will use a maximized vocabulary size for the word embeddings to minimize `<UNK>` tokens and preserve input fidelity **Cite {solution_lesson_node_00009}**.
3.  **Fallback Data:** We will create a specialized dataset by filtering the training data to include only token pairs where `before != after`. This focuses the Transformer on learning non-trivial transformations rather than identity mappings **Cite {solution_lesson_node_00027}**.

# Training
1.  **Tagger Training:**
    *   **Loss Function:** We will use Cross-Entropy Loss with **Square-Root Smoothed Class Weights** ($\sqrt{N/N_c}$). This penalizes errors on rare classes (like `MONEY`) to prevent majority class bias, but avoids the gradient instability caused by raw inverse frequency weights **Cite {solution_lesson_node_00013}**.
    *   **Optimizer:** We will use the **Adam** optimizer paired with a **ReduceLROnPlateau** scheduler. This dynamic schedule is essential for allowing the LSTM to escape local minima and converge to a better generalization point than static rates **Cite {solution_lesson_node_00011}**.
2.  **Fallback Training:** The Transformer Seq2Seq will be trained using standard Cross-Entropy Loss with Teacher Forcing on the filtered "changed" dataset.

# Evaluation
1.  **Inference Pipeline:**
    *   **Step 1 (Tagging):** Pass the test sentence through the **Attention-Augmented Bi-LSTM** to obtain the predicted class for each token.
    *   **Step 2 (Retrieval):** For each token, query the **Knowledge Base** using `(token, predicted_class)`. If a match is found, return the stored value.
    *   **Step 3 (Generation):** If the pair is missing from the KB (OOV) and the class is not `PLAIN`, pass the token and its class to the **Transformer Fallback Model** to generate the normalized text. This ensures robust handling of the "long tail" of unseen entities **Cite {solution_lesson_node_00027}**.
