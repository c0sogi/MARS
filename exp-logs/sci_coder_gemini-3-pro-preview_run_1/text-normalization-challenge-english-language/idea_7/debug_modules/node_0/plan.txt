The following script demonstrates the end-to-end workflow for the Text Normalization task using the provided library. It performs the following steps:

1.  **Configuration & Setup**: Overrides default `Config` parameters to define a lightweight "demo" mode (reduced epochs, smaller batch size, smaller model dimensions) and sets up a separate working directory.
2.  **Data Preparation**: Creates a small subset of the training and test data from the provided metadata to ensure rapid execution. It then builds the `Vocabulary` and `KnowledgeBase` from this subset.
3.  **Preprocessing**: Uses library functions `process_tagger_data` and `process_seq2seq_data` to convert raw text into tensor-ready formats (IDs, character sequences).
4.  **Model Instantiation**: Initializes the `AttentionBiLSTMTagger` and `TransformerSeq2Seq` models using the dimensions derived from the vocabulary.
5.  **Training Simulation**: Runs a single epoch of training for both models using `TaggerEngine` and `Seq2SeqEngine` to demonstrate the training loop and verify loss calculation.
6.  **Inference**: Generates predictions on the test subset using the hybrid approach (Tagger -> Knowledge Base -> Seq2Seq Fallback) via `generate_submission`.
7.  **Validation**: Includes assertions to verify that vocabulary sizes are correct, models produce outputs, and the submission file follows the required format.
