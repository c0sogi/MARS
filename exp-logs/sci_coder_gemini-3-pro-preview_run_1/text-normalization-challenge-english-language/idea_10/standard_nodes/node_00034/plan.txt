Outline:
The implementation orchestrates the text normalization pipeline by leveraging the provided library modules. 
1.  **Configuration Override**: We monkey-patch the `Config` class to optimize for the 2-hour time limit. We set `NUM_EPOCHS` to 1 and `BATCH_SIZE` to 256. This ensures the model sees the entire dataset (crucial for building a complete Knowledge Base) while keeping training time within bounds. We utilize the powerful A100 GPU.
2.  **Training**: We sequentially execute `train_tagger_model` and `train_seq2seq_model`. These functions handle data preparation (including caching), vocabulary building, and model training with early stopping.
3.  **Validation & Metrics**: We implement a custom `run_validation_and_analysis` function. This function loads the trained models and the full validation dataset. It performs inference using the full hybrid pipeline (Tagger -> Knowledge Base -> Seq2Seq Fallback) to ensure the metric reflects the actual system performance. It calculates the exact match accuracy and prints it in the required format.
4.  **Failure Analysis**: We analyze the validation results by correlating error occurrences with token length and digit presence, printing these statistics to identify systematic weaknesses.
5.  **Submission**: We compare the calculated validation accuracy against the threshold (0.9949142925818993). If the model passes, we invoke `generate_submission` to produce the final predictions for the test set.
