Implementation strategy:
1.  **Environment Setup**: Import necessary libraries and the provided modules. Set a fixed random seed for reproducibility.
2.  **Data Subsetting**: To ensure the demonstration runs quickly (optimizing for speed), create small subsets of the provided metadata files (`train.csv`, `val.csv`, `test.csv`) and save them to a temporary working directory.
3.  **Configuration Override**: Dynamically update the `Config` class attributes to point to these new subset files and a new working directory. Also, reduce training hyperparameters (epochs, batch size) to minimal values.
4.  **Component Verification**:
    *   **Features**: Instantiate `RegexFeatureExtractor` and verify it correctly identifies patterns (e.g., digits) and produces the correct output shape.
    *   **Vocabularies & Knowledge Base**: Trigger the building of vocabularies and the knowledge base using the subset data, verifying their existence and basic functionality.
    *   **Datasets**: Instantiate `TaggerDataset` and `FallbackDataset`. Verify that they load the correct number of samples (based on the subset) and that `__getitem__` returns tensors with expected shapes. Verify the collation functions.
    *   **Models**: Instantiate `MorphEnhancedTagger` and `Seq2SeqFallback`. Perform a forward pass with dummy batches derived from the datasets to verify tensor shapes and model execution.
5.  **Engine Execution**: Instantiate the `Engine` class. Run the training loops for both models (`train_tagger`, `train_fallback`) for 1 epoch on the subset data. Finally, run `generate_submission` to produce a submission file for the subset test data and verify its format.
