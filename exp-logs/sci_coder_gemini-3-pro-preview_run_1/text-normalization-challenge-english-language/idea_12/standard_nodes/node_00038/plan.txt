This script implements the end-to-end pipeline for the text normalization task. It orchestrates the training of a Morphologically-Enhanced Bi-LSTM Tagger and a Seq2Seq Fallback model, performs rigorous validation and failure analysis, and conditionally generates a submission based on performance metrics.

The strategy prioritizes speed and resource efficiency by:
1.  **Limiting Training Data**: Using a representative subset of the training data (`limit` parameter) to ensure the baseline runs within the 2-hour limit while still learning effective patterns.
2.  **Optimized Inference**: Implementing a batch-wise validation loop that leverages the GPU and minimizes data transfer overhead.
3.  **Hybrid Architecture**: Utilizing a "Classify-Retrieve-Generate" approach where the Tagger directs tokens to either a deterministic Knowledge Base (KB) or a generative Neural Fallback, balancing high precision with robust generalization.
