This script demonstrates the end-to-end workflow of the text normalization system using the provided library. It performs the following steps:

1.  **Configuration Override**: It dynamically modifies the `library.config` settings to use a temporary working directory and reduced hyperparameters (1 epoch) for a fast demonstration.
2.  **Data Subsetting**: It creates a small, balanced subset of the provided metadata (train/val/test) to ensure the training and inference pipelines run quickly (within ~30 seconds to a few minutes) while still processing meaningful data (e.g., dates, cardinals).
3.  **Vocabulary Building**: It generates vocabularies from the subset data.
4.  **Model Training**: It initializes and trains both the `RegexBiLSTMTagger` (for classification) and `CharLSTMSeq2Seq` (for normalization) using the `library.trainer` module.
5.  **Inference**: It executes the `InferencePipeline` to generate predictions on the test subset.
6.  **Validation**: It asserts that the submission file is created and follows the correct format.
