Implementation Strategy:
1.  **Configuration & Optimization**: Monkey-patch `library.config` and `library.trainer` to reduce epochs to 1 and limit batch sizes. This ensures the training fits within the tight time limit.
2.  **Data Loading**: Use `library.data_loader` to load vocabularies and dataloaders. Implement a `LimitedLoader` wrapper to strictly cap the number of training batches (2000 for Tagger, 500 for Seq2Seq) to guarantee fast execution.
3.  **Model Training**: Initialize and train the `RegexBiLSTMTagger` and `CharLSTMSeq2Seq` using the provided trainer functions and the limited dataloaders.
4.  **Validation**:
    *   Temporarily redirect `config.TEST_DATA_PATH` to the validation dataset.
    *   Use `library.inference.InferencePipeline` to generate predictions for the full validation set. This leverages the optimized inference logic (batching, KB lookup) without rewriting it.
    *   Compare predictions against the ground truth in `metadata/val.csv` to compute the exact accuracy metric.
5.  **Failure Analysis**: Analyze the validation errors by calculating the correlation between error occurrence and input token length, and printing error rates by class.
6.  **Submission**: If the validation accuracy exceeds the threshold (0.9949142925818993), restore the config paths and run the inference pipeline on the actual test set to generate `submission.csv`.
