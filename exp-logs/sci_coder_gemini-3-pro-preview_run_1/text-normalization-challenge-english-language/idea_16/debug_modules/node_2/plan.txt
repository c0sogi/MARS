The issue is that the `run_inference` method in `library/predictor.py` iterates over `sent_indices`, which is a PyTorch tensor. Iterating over a tensor yields 0-dimensional tensor scalars (e.g., `tensor(0)`), not native Python integers. When these tensor scalars are used as keys for Pandas DataFrame lookups (`df_test.at[idx, ...]`) or list indexing (`final_predictions[idx]`), they cause a `KeyError` or `TypeError` because these containers expect standard integers (Cite debug_lesson_11).

The fix is to explicitly convert the tensor scalar to a Python integer using `.item()` inside the loop before using it for indexing.
