This script performs a comprehensive Exploratory Data Analysis (EDA) on the text normalization training dataset. It focuses on the specific nature of the task: converting raw text tokens (`before`) to spoken forms (`after`), categorized by token types (`class`).

**Implementation Strategy:**
1.  **Setup & Loading**: Sets random seeds for reproducibility and loads the training metadata (`./metadata/train.csv`). It handles potential missing values by treating all text columns as strings to preserve tokens like "null" or "nan" if they exist as text.
2.  **Target Analysis**:
    *   Analyzes the distribution of the `class` column, which acts as the routing category for normalization logic.
    *   Calculates the "Change Ratio" (how often `before` != `after`). This is critical for this task, as many tokens (like standard words or punctuation) often remain unchanged.
3.  **Text Modality Analysis**:
    *   Computes character length statistics for input tokens.
    *   Analyzes the vocabulary size and character coverage (e.g., presence of digits, ASCII vs. non-ASCII) to inform tokenizer choices.
    *   Examines sentence-level statistics by grouping tokens via `sentence_id`.
4.  **Feature Relationships**:
    *   Investigates the relationship between token class and text length.
    *   Analyzes which classes are most likely to require normalization (change from input to output).
5.  **Output**: Formats all findings into the requested capitalized sections with precise float formatting.
