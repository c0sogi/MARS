The issue is that the `Seq2SeqDataset` does not enforce the maximum sequence length defined in the configuration (`Config.MAX_SEQ2SEQ_LEN`), allowing sequences longer than the model's positional encoding buffer to pass through. This causes a dimension mismatch error during the forward pass when the model attempts to add positional encodings to embeddings that exceed the pre-allocated size. To fix this, I will modify `library/data_loader.py` to explicitly truncate the source and target text sequences within `Seq2SeqDataset.__getitem__` before encoding them, ensuring they strictly adhere to the model's architectural limits.
