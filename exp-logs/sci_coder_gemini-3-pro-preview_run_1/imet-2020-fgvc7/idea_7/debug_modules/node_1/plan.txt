The `_pickle.UnpicklingError` occurs because the model checkpoint contains NumPy scalars (specifically for the stored F1 score and threshold), which are blocked by the default `weights_only=True` security setting in newer PyTorch versions of `torch.load`. Since the checkpoint is generated locally and trusted, the fix is to explicitly set `weights_only=False` when loading the checkpoint in the `predict` method of `library/trainer.py`.
