Based on the extensive empirical analysis and lessons learned, I propose the **SE-ResNet18 Multi-Task U-Net with MixUp Regularization**.

This strategy introduces a structural innovation to the backbone (Squeeze-and-Excitation) and a new training paradigm (MixUp) to address the specific challenges of "Atypical" class discrimination and global context modeling, while strictly adhering to the lightweight architectural constraints and robust training protocols proven to be effective.

# Model
**Architecture: SE-ResNet18 Multi-Task U-Net**
*   **Backbone (Structural Innovation):** Modify the successful **ResNet18** backbone by injecting **Squeeze-and-Excitation (SE) blocks** after each residual block.
    *   *Rationale:* Previous experiments showed that standard ResNet18 lacks the capacity for subtle "Atypical" texture discrimination (Cite solution_lesson_node_00008), while heavier backbones (EfficientNet) and spatial aggregators (ASPP/Attention Gates) caused overfitting or signal loss (Cite solution_lesson_node_00012, solution_lesson_node_00015, solution_lesson_node_00029). SE blocks introduce a lightweight channel-attention mechanism that adaptively recalibrates feature maps using global information. This explicitly models the "global context" required for diagnosis without disrupting the spatial fidelity needed for segmentation.
*   **Decoder:** Retain the standard **U-Net Decoder** with symmetric, direct skip connections. This is strictly preferred over FPN or Attention Gates to preserve the gradient flow for coarse segmentation targets (Cite solution_lesson_node_00021).
*   **Heads:**
    *   **Classification:** A **Single Linear Layer** attached to the Global Average Pooling of the encoder. This enforces a "Shallow Head" constraint, preventing the task decoupling observed with MLPs (Cite solution_lesson_node_00008).
    *   **Segmentation:** A final 1x1 convolution on the decoder output.

# Data
**Preprocessing & Augmentation**
*   **Input:** Resize all images to **512x512** pixels.
*   **MixUp Regularization (New Paradigm):** Implement **MixUp** augmentation during training. This involves taking pairs of images $(x_1, x_2)$ and their targets $(y_1, y_2)$ and generating synthetic samples: $\hat{x} = \lambda x_1 + (1-\lambda)x_2$ and $\hat{y} = \lambda y_1 + (1-\lambda)y_2$.
    *   *Rationale:* This addresses the decision boundary ambiguity between "Indeterminate" and "Atypical" classes. By forcing the model to behave linearly between samples, we improve generalization and robustness, acting as a strong regularizer against the overfitting observed in previous extended runs.
*   **Label-Consistent CoarseDropout:** Apply `CoarseDropout` with large occlusion dimensions (~10% of image size). Crucially, set **`mask_fill_value=0`** to ensure that occluded regions in the image are also removed from the ground truth mask, preventing label noise (Cite solution_lesson_node_00003, solution_lesson_node_00004).

# Training
**Strategy**
*   **Loss Function:**
    *   **Study-Level:** Use **Soft Target CrossEntropy**. Since MixUp generates non-binary probabilistic labels (e.g., 0.6 Typical, 0.4 Negative), the loss function must handle soft targets while maintaining the Softmax constraint for mutual exclusivity (Cite solution_lesson_node_00010).
    *   **Image-Level:** Use **BCEWithLogitsLoss**. This handles the soft segmentation masks generated by MixUp and avoids the instability of Dice Loss on empty masks (Cite solution_lesson_node_00013).
*   **Loss Weighting:** Maintain the **1:10 weighting ratio** (1.0 for Classification, 10.0 for Segmentation) to prioritize the dense prediction task and force the encoder to learn spatial features (Cite solution_lesson_node_00010).
*   **Optimization:**
    *   **Optimizer:** AdamW.
    *   **Scheduler:** Use **Cosine Annealing** to dynamically adjust the learning rate (Cite solution_lesson_node_00023).
    *   **Batch Size:** Maximize batch size (e.g., 32) and strictly apply the **Linear Scaling Rule** to the learning rate to prevent iteration deficits (Cite solution_lesson_node_00020).
    *   **Duration:** Train for **25 Epochs**. The addition of MixUp typically slows convergence slightly, requiring a modest extension beyond the proven 20-epoch schedule to reach optimal performance (Cite solution_lesson_node_00002).

# Evaluation
**Inference Pipeline**
*   **Metric-Based Checkpointing:** Select the best model based on the **Composite Validation mAP** (averaging study and image metrics), ensuring the selected checkpoint performs well on the actual competition objective (Cite solution_lesson_node_00017).
*   **Test-Time Augmentation (TTA):** Apply horizontal flip TTA and average predictions to improve robustness (Cite solution_lesson_node_00023).
*   **Gated Prediction:**
    1.  Generate study-level class and segmentation mask.
    2.  **Logical Gating:** If the predicted study class is "Negative for Pneumonia", explicitly override the image-level prediction to "none 1 0 0 1 1". This couples the validation logic with the inference constraints (Cite solution_lesson_node_00026).
    3.  **Box Extraction:** For non-negative studies, threshold the probability mask and generate bounding boxes via contour extraction (Cite solution_lesson_node_00001).
