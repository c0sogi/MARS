Based on the accumulated lessons, I propose the **Multi-Scale FPN-Enhanced Multi-Task Network (ResNet34-FPN)**.

This strategy introduces a structural evolution from the standard U-Net to a Feature Pyramid Network (FPN) architecture. It addresses the limitation of the U-Net's classification head (which relies solely on the highly compressed bottleneck features) by leveraging the multi-scale feature pyramid for both segmentation and classification. This allows the model to capture the subtle textural details required for "Atypical" and "Indeterminate" classes while maintaining the robust segmentation performance of the baseline.

# Model
**Architecture:** **ResNet34 with Feature Pyramid Network (FPN)**
*   **Backbone (Encoder):** Upgrade the backbone to **ResNet34** (pre-trained on ImageNet). This provides a moderate increase in capacity over the ResNet18 used in the baseline, offering better feature extraction without the optimization instability and overfitting observed with EfficientNet architectures (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Neck (Structural Innovation):** Replace the standard U-Net decoder with a **Feature Pyramid Network (FPN)**. The FPN constructs a rich, multi-scale feature pyramid (P2, P3, P4, P5) by combining low-resolution, semantically strong features with high-resolution, spatially rich features via top-down pathways and lateral connections. This differs from the U-Net's simple concatenation and provides better gradient flow across multiple scales.
*   **Multi-Scale Classification Head:** Instead of applying Global Average Pooling (GAP) only to the final bottleneck (as in the U-Net), apply GAP to each level of the feature pyramid (P3, P4, P5), concatenate these vectors, and pass them through a **Single Linear Layer**. This ensures the study-level classifier has access to both global semantic structure and finer-grained textural details, which are critical for distinguishing "Typical" from "Atypical" appearances. This design adheres to the constraint of using a shallow, linear head to prevent decoupling (Cite solution_lesson_node_00008).
*   **Segmentation Head:** Upsample and aggregate the FPN feature maps (P2-P5) to a common resolution (e.g., 1/4 input size) to generate the pixel-wise probability map.

# Data
**Preprocessing & Augmentation:**
*   **Input:** Resize all images to **512x512** pixels.
*   **Label-Consistent CoarseDropout:** Apply `CoarseDropout` with large occlusion dimensions (~10% of image size) to force the model to learn global context (Cite solution_lesson_node_00004). Crucially, set **`mask_fill_value=0`** for the segmentation targets. This ensures that when an opacity is occluded in the image, it is also removed from the ground truth mask, preserving label consistency and preventing the "label noise" that degraded performance in previous iterations (Cite solution_lesson_node_00003).

# Training
**Strategy:**
*   **Loss Function:**
    *   **Study-Level:** Use **CrossEntropyLoss** (Softmax). Since the study labels (Negative, Typical, Indeterminate, Atypical) are mutually exclusive, Softmax provides a structural constraint that regularizes the model better than independent Sigmoids (Cite solution_lesson_node_00010).
    *   **Image-Level:** Use **BCEWithLogitsLoss** exclusively. Avoid Dice Loss, as it has proven unstable due to the high prevalence of empty masks (negative cases) in this dataset (Cite solution_lesson_node_00013).
*   **Loss Weighting:** Apply a **1:10 weighting ratio** (1.0 for Classification, 10.0 for Segmentation). This prioritizes the dense prediction task, forcing the shared encoder to learn generalizable spatial features (Cite solution_lesson_node_00010).
*   **Schedule:** Train for **20 epochs**. This extended schedule is necessary to allow the moderately heavier ResNet34 backbone to fully converge (Cite solution_lesson_node_00002).
*   **Batch Size & Optimization:** Use a standard batch size (e.g., 16 or 32) compatible with GPU memory. If increasing batch size, strictly scale the learning rate or total epochs to avoid the "iteration deficit" (Cite solution_lesson_node_00020).

# Evaluation
**Inference Pipeline:**
*   **Metric-Based Checkpointing:** Select the best model based on the **Composite Validation mAP** (averaging both study-level and image-level performance), mirroring the competition metric exactly. This avoids the "metric divergence" where a model might optimize for one sub-task while failing the global objective (Cite solution_lesson_node_00017).
*   **Gated Prediction:**
    1.  Generate study-level class and segmentation mask.
    2.  **Logical Gating:** If the predicted study class is "Negative for Pneumonia", explicitly override the image-level prediction to "none 1 0 0 1 1" (Cite solution_lesson_node_00001).
    3.  **Box Extraction:** For non-negative studies, threshold the probability mask and generate bounding boxes via contour extraction.
