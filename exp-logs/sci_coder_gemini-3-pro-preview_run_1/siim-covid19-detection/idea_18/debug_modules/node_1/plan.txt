The `IndexError` occurs because the `validate` function in `library/engine.py` incorrectly aggregates bounding boxes and scores into a hierarchical list of lists (one list per image), but passes them to `map_iou` which expects a flat list of boxes or a single-image context. When `map_iou` iterates over these lists as if they were individual boxes, it eventually passes an empty list (for an image with no predictions) to `calculate_iou`, causing `box1[0]` to crash.

To fix this, I will modify `library/engine.py` to calculate the Average Precision (AP) for each image individually within the validation loop and then compute the mean (mAP) of these scores. This avoids the aggregation error and correctly handles the data hierarchy (Cite `debug_lesson_4`).
