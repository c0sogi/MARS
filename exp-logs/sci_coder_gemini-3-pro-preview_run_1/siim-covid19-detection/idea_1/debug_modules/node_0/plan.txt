The implementation strategy involves creating a single Python script that systematically verifies the functionality of the provided library components (`dataset`, `model`, `loss`, `train`, `predict`) within the constraints of the environment.

1.  **Configuration**: We will override the default `Config` parameters to enable `DEBUG` mode, reduce the number of epochs to 1, and set a small batch size. This ensures the code runs quickly while still exercising the full pipeline.
2.  **Dataset Verification**: We will instantiate the `SIIMDataset` using the training metadata. We will explicitly fetch a sample to verify that the image, mask, and label tensors have the correct shapes and data types.
3.  **Model & Loss Verification**: We will instantiate the `MultiTaskUNet` and `MultiTaskLoss`. We will perform a forward pass with a dummy batch (derived from the dataset verification step) to check output shapes. We will also compute the loss and perform a backward pass to ensure the computational graph is valid.
4.  **Training Integration**: We will call the `run_training` function. This serves as an integration test for the training loop, validation logic, and model checkpointing. We will assert that the model checkpoint file is created.
5.  **Inference Integration**: We will call the `predict` function. This tests the inference loop, post-processing (mask to boxes), and submission formatting. We will assert that the submission CSV is created and contains the expected columns and row types (study vs. image).
