The following script demonstrates the end-to-end usage of the provided library for the SIIM-FISABIO-RSNA COVID-19 Detection task.

**Implementation Strategy:**
1.  **Configuration Override**: We monkey-patch the `Config` class to set a temporary output directory, reduce the number of epochs to 1, set a small batch size, and disable multiprocessing workers to ensure the demonstration runs quickly and reliably within the environment.
2.  **Utility Verification**: We explicitly validate the core geometric functions (`mask2bbox`, `compute_iou`) using synthetic data to ensure the bounding box logic is correct.
3.  **Data Pipeline Verification**: We execute `prepare_data` in debug mode to generate a small subset of cached data, then inspect the `SIIMDataset` and `DataLoader` to confirm correct tensor shapes (channels, dimensions) and data types.
4.  **Model Architecture Check**: We instantiate the `ResNet18UNetMultiScale` model, pass a dummy batch through it, and assert that the output shapes for both segmentation logits and classification logits match the expected dimensions.
5.  **Training Simulation**: We run the full `run_training` function in debug mode. This tests the training loop, loss calculation, backpropagation, validation step, and model checkpoint saving.
6.  **Inference & Submission**: We run the `inference` function to load the trained checkpoint, perform test-time augmentation (TTA), apply the gating logic, and generate a valid submission CSV file.
