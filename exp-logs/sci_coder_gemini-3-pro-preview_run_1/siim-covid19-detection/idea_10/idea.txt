Based on the comprehensive analysis of the previous experiments and lessons learned, I propose the **Multi-Scale Aggregated ResNet18 U-Net**.

This strategy introduces a structural innovation to the classification head to address the "Atypical" vs. "Indeterminate" discrimination weakness without disrupting the segmentation performance, while strictly adhering to the lightweight backbone and robust training protocols proven to be optimal.

# Model
**Architecture:** **ResNet18 U-Net with Multi-Scale Classification Head**
*   **Backbone (Encoder):** Retain the **ResNet18** backbone (pre-trained on ImageNet). Previous experiments confirmed that heavier backbones (EfficientNet) and complex aggregators (FPN/ASPP) degrade performance due to overfitting coarse annotations and signal loss (Cite solution_lesson_node_00012, solution_lesson_node_00021, solution_lesson_node_00029).
*   **Decoder:** Use the standard **U-Net Decoder** with symmetric, direct skip connections. This is strictly preferred over Attention Gates or FPN to preserve the spatial fidelity required for the segmentation of amorphous opacities (Cite solution_lesson_node_00015, solution_lesson_node_00021).
*   **Classification Head (Structural Innovation):** Replace the standard Global Average Pooling (GAP) of the final bottleneck with a **Multi-Scale Aggregation Head**.
    *   *Mechanism:* Apply Global Average Pooling to the output of **Encoder Layer 2**, **Encoder Layer 3**, and **Encoder Layer 4** (the bottleneck). Concatenate these three vectors into a single descriptor. Pass this concatenated vector through a **Single Linear Layer** to predict the study labels.
    *   *Rationale:* The standard ResNet18 classifier relies solely on the deepest, most abstract features (Layer 4), which often lose the subtle textural details required to distinguish "Atypical" viral patterns from "Indeterminate" appearances. By explicitly feeding mid-level features (Layer 2 and 3) to the classifier, we provide the head with multi-resolution texture information without the complexity of a Feature Pyramid Network (FPN), which was shown to degrade the segmentation task (Cite solution_lesson_node_00021). This adheres to the "Shallow Head" constraint (Cite solution_lesson_node_00008) while enriching the input signal.
*   **Segmentation Head:** A final 1x1 convolution on the decoder output (no deep supervision) (Cite solution_lesson_node_00027).

# Data
**Preprocessing & Augmentation**
*   **Input:** Resize all images to **512x512** pixels.
*   **Label-Consistent CoarseDropout:** Apply `CoarseDropout` with large occlusion dimensions (~10% of image size) to force global context learning (Cite solution_lesson_node_00004).
*   **Consistency Constraint:** Crucially, set **`mask_fill_value=0`** for the segmentation targets. This ensures that when an opacity is occluded in the image, it is also removed from the ground truth mask, preventing the "label noise" that degraded performance in previous iterations (Cite solution_lesson_node_00003).
*   **No MixUp:** Strictly avoid MixUp regularization, as it causes "ghosted" masks that degrade dense prediction performance in short training schedules (Cite solution_lesson_node_00032).

# Training
**Strategy**
*   **Loss Function:**
    *   **Study-Level:** Use **CrossEntropyLoss** (Softmax). Since the study labels are mutually exclusive, Softmax provides a structural constraint that regularizes the model better than independent Sigmoids (Cite solution_lesson_node_00010).
    *   **Image-Level:** Use **BCEWithLogitsLoss** exclusively. Avoid Dice Loss due to instability on empty masks (Cite solution_lesson_node_00013).
*   **Loss Weighting:** Apply a **1:10 weighting ratio** (1.0 for Classification, 10.0 for Segmentation). This prioritizes the dense prediction task, forcing the shared encoder to learn generalizable spatial features (Cite solution_lesson_node_00010).
*   **Optimization:**
    *   **Optimizer:** AdamW.
    *   **Scheduler:** Use **Cosine Annealing** to dynamically adjust the learning rate (Cite solution_lesson_node_00023).
    *   **Batch Size & Scaling:** Maximize the batch size (e.g., 32) and strictly apply the **Linear Scaling Rule** to the learning rate to prevent iteration deficits (Cite solution_lesson_node_00020).
    *   **Duration:** Train for **20 epochs** to ensure full convergence (Cite solution_lesson_node_00002).

# Evaluation
**Inference Pipeline**
*   **Metric-Based Checkpointing:** Select the best model based on the **Composite Validation mAP** (averaging study and image metrics), mirroring the competition metric exactly (Cite solution_lesson_node_00017).
*   **Test-Time Augmentation (TTA):** Apply horizontal flip TTA during inference and average the predictions to improve robustness (Cite solution_lesson_node_00023).
*   **Gated Prediction:**
    1.  Generate study-level class and segmentation mask.
    2.  **Logical Gating:** If the predicted study class is "Negative for Pneumonia", explicitly override the image-level prediction to "none 1 0 0 1 1". This couples the validation logic with the inference constraints (Cite solution_lesson_node_00026).
    3.  **Box Extraction:** For non-negative studies, threshold the probability mask and generate bounding boxes via contour extraction (Cite solution_lesson_node_00001).
