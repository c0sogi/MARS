This script demonstrates the end-to-end pipeline for the SIIM-FISABIO-RSNA COVID-19 Detection task using the provided library files.

**Implementation Strategy:**
1.  **Environment Setup**: We import necessary libraries and the provided modules. We set the random seed for reproducibility.
2.  **Configuration Override**: To ensure the demonstration runs quickly, we override the default `Config` parameters. We reduce the batch size, set epochs to 1, and redirect file paths to temporary locations in the `./working` directory.
3.  **Data Preparation**: Instead of processing the entire dataset, we create "mini" versions of the training, validation, and test metadata files by sampling the first few rows of the original CSVs. This allows us to test the data loading and processing logic without the overhead of reading thousands of DICOM files.
4.  **Component Verification**:
    *   **Data Loading**: We call `get_dataloaders` and verify that the returned DataLoaders yield batches with the correct shapes.
    *   **Model Instantiation**: We initialize the `EfficientNetB4Unet` model and perform a forward pass with a dummy batch to verify the output shapes of the study logits and segmentation masks (including deep supervision heads).
    *   **Loss Calculation**: We instantiate `HybridLoss` and compute the loss on the model outputs to ensure the loss function logic works correctly.
5.  **Training & Evaluation**: We execute `train_one_epoch` and `evaluate` using the mini-datasets. This verifies the training loop, backpropagation, and metric calculation (mAP). We save the resulting model weights to simulate a complete training run.
6.  **Inference**: We initialize the `Predictor` class, which loads the saved model, and run `generate_submission`. We verify that the submission file is generated correctly and contains the expected format.
