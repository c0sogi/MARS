Implementation strategy:
1.  **Setup & Configuration**: Import necessary modules and the provided library. Configure the `Config` class to use a dedicated working directory (`./working/demo_execution_v2`) to prevent cache conflicts. Enable `Config.DEBUG = True` initially to ensure the training phase uses a small subset of data for speed. Set `Config.EPOCHS = 1` and a moderate `BATCH_SIZE`.
2.  **Clean Start**: Ensure the working directory is clean by removing it if it exists, forcing data processing to run from scratch.
3.  **Unit Verification**: Implement assertions to verify the correctness of utility functions (`mask2bbox`, `calculate_map`) and the model architecture (forward pass shapes) before starting the heavy lifting.
4.  **Training Phase**: Execute `train_model()`. This will load the debug subset of training data, train for one epoch, and save `best_model.pth`.
5.  **Inference Phase**: Switch `Config.DEBUG = False`. This is crucial because the `predict()` function in `engine.py` iterates through the full test metadata CSV sequentially. To ensure the data loader aligns with the metadata loop, we must process the full test set (which is small, ~638 images) rather than a random subset. Execute `predict()` to generate `submission.csv`.
6.  **Result Validation**: Verify that the submission file exists, has the correct columns, and contains data.
