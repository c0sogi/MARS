The strategy for the implementation is as follows:
1.  **Directory Traversal**: We will traverse the `./input/train` and `./input/test` directories to map the file structure. Since the directory structure is `study_id/series_id/image_id.dcm`, we can extract the `study_id` and `image_id` directly from the file paths. This creates a reliable mapping between IDs and relative file paths.
2.  **Data Ingestion**: We will load `train_study_level.csv` and `train_image_level.csv` using pandas. We will clean the ID columns by removing the `_study` and `_image` suffixes to match the IDs extracted from the file paths.
3.  **Data Merging**: We will merge the file path information with the image-level metadata, and then merge that result with the study-level metadata. This consolidates all information (paths, bounding boxes, class labels) into a single DataFrame.
4.  **Dataset Splitting**: To create a validation set, we will use `GroupShuffleSplit` with `study_id` as the group. This ensures that all images belonging to the same study stay in the same split (either training or validation), preventing data leakage. We will use a fixed random state of 42 and an 80:20 split ratio.
5.  **Metadata Generation**: We will save the resulting DataFrames (`train`, `val`, `test`) to the `./metadata` directory in CSV format.
6.  **Verification**:
    *   **File Existence**: We will randomly sample 1000 paths from the generated metadata and verify they exist in the `./input` directory.
    *   **Split Integrity**: We will programmatically assert that there is no overlap of `study_id` between the training and validation sets.
    *   **Statistics**: We will print summary statistics (counts, class distributions) for the datasets.
