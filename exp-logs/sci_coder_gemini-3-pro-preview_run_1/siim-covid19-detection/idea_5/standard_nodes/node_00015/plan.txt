The issue stems from the `cache_data` function in `library/dataset.py`, which loads cached `.npy` files solely based on their existence without verifying if the cached data matches the current dataset requirements (e.g., full dataset vs. debug subset). This caused the training run to load a stale, tiny dataset from a previous debug session, resulting in invalid metrics. The fix is to add a validation check that compares the length of the loaded arrays against the length of the input DataFrame; if they differ, the code will discard the cache and reprocess the data.
