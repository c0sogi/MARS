This script demonstrates the end-to-end usage of the provided library modules for the COVID-19 Radiography Classification and Detection task.

The implementation strategy is as follows:
1.  **Configuration Setup**: We override specific `Config` parameters (enabling `DEBUG` mode, reducing sample size to 20, and setting `EPOCHS` to 1) to ensure the script executes quickly within the time limit.
2.  **Utility Verification**: We validate the core geometric utility functions (`mask_to_boxes`, `compute_iou`, `calculate_map`) using synthetic data to ensure the logic for bounding box generation and metric calculation is correct.
3.  **Data Loading**: We instantiate the `ChestXrayDataset` for training, validation, and testing splits. We assert that the data shapes (images, masks, labels) and types match the expected input for the model.
4.  **Model Initialization**: We instantiate the `EfficientNetUNet` model, move it to the GPU (if available), and perform a dummy forward pass to verify the output shapes of the segmentation and classification heads.
5.  **Training & Evaluation**: We run a single training epoch and a validation pass using the `engine` module functions (`train_one_epoch`, `validate`). We verify that the loss decreases or is computed correctly and that the returned metrics follow the expected dictionary structure.
