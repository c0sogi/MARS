Based on the comprehensive analysis of the accumulated lessons, I propose the **GeM-Pooled ResNet18 U-Net with Sub-Pixel Upsampling**.

This strategy introduces targeted structural innovations to the pooling and upsampling mechanisms of the baseline architecture. It addresses the specific weaknesses of Global Average Pooling (signal dilution) and Bilinear Upsampling (blurriness) while strictly adhering to the lightweight backbone and robust training protocols that have proven superior to heavier, more complex alternatives.

# Model
**Architecture:** **ResNet18 U-Net with GeM Pooling and PixelShuffle**
*   **Backbone (Exploitation):** Retain the **ResNet18** backbone (pre-trained on ImageNet). Previous experiments conclusively demonstrated that heavier backbones (EfficientNet) and complex aggregators (FPN/ASPP) degrade performance due to overfitting and optimization instability on this dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012, solution_lesson_node_00021, solution_lesson_node_00029).
*   **Classification Head (Structural Innovation):** Replace the standard Global Average Pooling (GAP) layer with **Generalized Mean Pooling (GeM)**.
    *   *Rationale:* GAP averages feature activations across the entire spatial grid, which dilutes the signal of small, focal opacities (characteristic of "Typical" pneumonia) against the large background of healthy lung. Max Pooling, conversely, loses global context. GeM introduces a learnable parameter $p$ ($f = (\frac{1}{|X|}\sum x^p)^{1/p}$), allowing the model to dynamically tune its focus between focal salient features and global averages. This enhances the discriminative power of the "Shallow Head" without adding the complexity of an MLP (Cite solution_lesson_node_00008). The head remains a **Single Linear Layer** attached to the GeM output (Cite solution_lesson_node_00035).
*   **Decoder (Structural Innovation):** Replace standard Bilinear Upsampling with **Sub-Pixel Convolution (PixelShuffle)**.
    *   *Rationale:* Standard upsampling methods are either non-learnable (Bilinear) or prone to checkerboard artifacts (Transposed Conv). PixelShuffle rearranges elements from the channel dimension into the spatial dimension, allowing the model to learn efficient, high-fidelity upsampling filters. This improves the sharpness of the segmentation masks for amorphous opacities (Cite solution_lesson_node_00001) while maintaining the direct skip connections that proved superior to Attention Gates (Cite solution_lesson_node_00015).

# Data
**Preprocessing & Augmentation**
*   **Input:** Resize all images to **512x512** pixels.
*   **Label-Consistent CoarseDropout:** Apply `CoarseDropout` with large occlusion dimensions (~10% of image size) to force global context learning (Cite solution_lesson_node_00004).
*   **Consistency Constraint:** Crucially, set **`mask_fill_value=0`** for the segmentation targets. This ensures that when an opacity is occluded in the image, it is also removed from the ground truth mask, preventing the "label noise" that degraded performance in previous iterations (Cite solution_lesson_node_00003).
*   **No MixUp:** Strictly avoid MixUp, as it degrades dense prediction performance on short schedules (Cite solution_lesson_node_00032).

# Training
**Strategy**
*   **Loss Function:**
    *   **Study-Level:** Use **CrossEntropyLoss** (Softmax) to enforce the mutual exclusivity of the study labels (Negative, Typical, Indeterminate, Atypical) (Cite solution_lesson_node_00010).
    *   **Image-Level:** Use **BCEWithLogitsLoss** exclusively. Avoid Dice Loss due to instability on empty masks (Cite solution_lesson_node_00013).
*   **Loss Weighting:** Apply a **1:10 weighting ratio** (1.0 for Classification, 10.0 for Segmentation). This prioritizes the dense prediction task, forcing the shared encoder to learn generalizable spatial features (Cite solution_lesson_node_00010).
*   **Optimization:**
    *   **Optimizer:** AdamW.
    *   **Scheduler:** Use **Cosine Annealing** to dynamically adjust the learning rate (Cite solution_lesson_node_00023).
    *   **Batch Size & Scaling:** Maximize the batch size (e.g., 32) and strictly apply the **Linear Scaling Rule** to the learning rate to prevent iteration deficits (Cite solution_lesson_node_00020).
    *   **Duration:** Train for **20 epochs** to ensure full convergence (Cite solution_lesson_node_00002).

# Evaluation
**Inference Pipeline**
*   **Metric-Based Checkpointing:** Select the best model based on the **Composite Validation mAP** (averaging study and image metrics), mirroring the competition metric exactly (Cite solution_lesson_node_00017).
*   **Test-Time Augmentation (TTA):** Apply horizontal flip TTA during inference and average the predictions to improve robustness (Cite solution_lesson_node_00023).
*   **Gated Prediction:**
    1.  Generate study-level class and segmentation mask.
    2.  **Logical Gating:** If the predicted study class is "Negative for Pneumonia", explicitly override the image-level prediction to "none 1 0 0 1 1". This couples the validation logic with the inference constraints (Cite solution_lesson_node_00026).
    3.  **Box Extraction:** For non-negative studies, threshold the probability mask and generate bounding boxes via contour extraction (Cite solution_lesson_node_00001).
