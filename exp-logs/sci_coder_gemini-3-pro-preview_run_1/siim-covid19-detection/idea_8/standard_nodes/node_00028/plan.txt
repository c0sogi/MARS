I will implement the `runfile.py` script to orchestrate the training, validation, failure analysis, and submission generation for the ASPP-Enhanced Multi-Task ResNet18 U-Net.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and ensure reproducibility with `seed_everything`.
2.  **Data Loading**: Use `get_dataloaders` to load the training, validation, and test sets. I will use the full dataset to ensure the model achieves the required performance metric, as the dataset size (approx. 5k images) is small enough to train quickly on the provided A100 GPU.
3.  **Model Training**: Instantiate the `ResNet18UNetASPP` model, `AdamW` optimizer, and `CosineAnnealingLR` scheduler. Execute the training loop using the `fit` function from the engine, which handles loss calculation, backpropagation, and metric-based checkpointing.
4.  **Validation & Metrics**:
    *   Load the best saved model.
    *   Perform a dedicated inference pass on the validation set to calculate the final mAP using `get_map_score`.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   During the validation pass, calculate the Intersection over Union (IoU) error per image (`1.0 - IoU`).
    *   Load validation metadata to extract features like "Target Area" (mask size) and "Num Boxes".
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify failure modes.
6.  **Submission Generation**:
    *   Check if the validation mAP exceeds the threshold `0.49944536565378`.
    *   If passed, run inference on the test set using **Test-Time Augmentation (TTA)** (horizontal flipping).
    *   Apply **Gated Prediction**: If the predicted study label is "Negative for Pneumonia", override the image prediction to "none".
    *   Format the predictions and save to `submission.csv` using `post_process_submission`.
