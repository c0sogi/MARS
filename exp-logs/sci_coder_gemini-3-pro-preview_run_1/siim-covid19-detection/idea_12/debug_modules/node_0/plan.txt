The following code demonstrates the end-to-end pipeline using the provided library files. It performs the following steps:
1.  **Configuration**: Overrides default `Config` settings to enable `debug` mode (using a small subset of data) and sets output directories to `./working/demo_execution` to ensure speed and isolation.
2.  **Data Loading**: Uses `get_loaders` to preprocess and load training, validation, and test data. It verifies the shape and integrity of the batches produced.
3.  **Model Initialization**: Instantiates the `ResNet18D_UNet` model and verifies the output shapes of the classification logits and segmentation masks.
4.  **Training**: Runs a single epoch of training using `train_one_epoch`, ensuring the loss is calculated and backpropagated correctly.
5.  **Validation**: executing the `validate` function to compute validation loss and mean Average Precision (mAP).
6.  **Inference**: Saves the trained model weights and invokes `predict_and_submit` to generate predictions on the test set.
7.  **Verification**: Validates the format and content of the generated `submission.csv`.
