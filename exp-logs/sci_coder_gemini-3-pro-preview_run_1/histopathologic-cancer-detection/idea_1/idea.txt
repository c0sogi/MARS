# Baseline Approach Proposal: Custom Shallow CNN with Center Cropping

## Model
I propose a **Custom Shallow Convolutional Neural Network (CNN)** trained entirely from scratch. Unlike the heavy, pre-trained architectures (like EfficientNet or ResNet) or the transformer-based approaches mentioned previously, this model prioritizes structural simplicity and computational speed.

The architecture will consist of three sequential convolutional blocks. Each block will comprise:
1.  A **3x3 Convolutional layer** to extract spatial features (edges, textures).
2.  **Batch Normalization** to stabilize learning and accelerate convergence.
3.  **ReLU Activation** to introduce non-linearity.
4.  **2x2 Max Pooling** to reduce spatial dimensions and computational load.

Following the third block, the feature maps will be flattened and passed through a lightweight classification head consisting of one fully connected hidden layer with Dropout (for regularization) and a final output neuron. This design is significantly smaller than standard backbones, allowing for rapid iteration.

## Data
To strictly adhere to the efficiency philosophy and the task definition, the data preprocessing will focus on dimensionality reduction via **Center Cropping**.
1.  **Cropping**: Instead of using the full 96x96 image, we will crop the **central 48x48 pixel region**. This region fully encapsulates the 32x32 target area while providing a minimal 8-pixel border for immediate context. This discards 75% of the input pixels (the peripheral background), which the problem statement indicates does not determine the label, thereby drastically reducing the computational cost.
2.  **Normalization**: Pixel values will be scaled to the [0, 1] range by dividing by 255.0.
3.  **Augmentation**: During training only, we will apply simple geometric augmentations—specifically random horizontal/vertical flips and 90-degree rotations—to leverage the rotation-invariant nature of pathology slides without adding computational overhead.

## Training
The training process will be designed for stability and speed:
*   **Loss Function**: We will use **Binary Cross-Entropy with Logits**, which is standard for binary classification tasks.
*   **Optimizer**: The **Adam** optimizer will be employed for its adaptive learning rate capabilities, minimizing the need for extensive hyperparameter tuning.
*   **Strategy**: We will train for a limited number of epochs (e.g., 10-15) with a relatively large batch size (e.g., 64 or 128) to maximize GPU throughput. An **Early Stopping** mechanism will be implemented to halt training if the validation AUC does not improve for 3 consecutive epochs, preventing overfitting and saving runtime.

## Evaluation
For the evaluation phase:
1.  Test images will undergo the same **Center Crop (48x48)** and **Normalization** steps as the training data.
2.  The processed images will be fed through the trained network in batches.
3.  The raw logic outputs will be passed through a Sigmoid function to generate the final probability scores required for the submission file.
