This script demonstrates the end-to-end usage of the provided library files for the Tumor Detection task. It covers:
1.  **Configuration**: Overriding default settings for a fast demonstration run.
2.  **Dataset Loading**: Loading stratified subsets of training, validation, and test data using the `PathologyDataset` class and `load_dataset` factory.
3.  **Model Instantiation**: creating the custom `EnsembleDenseNet` and verifying its architectural modifications (input stem and pooling).
4.  **Training Engine**: Running a single training epoch using `train_one_epoch`.
5.  **Validation Engine**: Evaluating the model using `validate` to get Loss and AUC.
6.  **Inference**: Generating predictions with Test Time Augmentation (TTA) using `predict_tta`.
7.  **Utilities**: Verifying the functionality of `AverageMeter` and `EarlyStopping`.

The script uses a small subset of data and a non-pretrained model to ensure execution within a few minutes while validating the logic of all components.
