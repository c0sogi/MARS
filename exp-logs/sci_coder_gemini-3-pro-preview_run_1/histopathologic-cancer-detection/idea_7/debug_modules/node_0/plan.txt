This script demonstrates the usage of the provided library files for the pathology classification task. It validates the core components (MetricMonitor, Dataset, Model, GeM Pooling) and executes a complete training and inference pipeline using a reduced dataset and configuration for speed.

The strategy is as follows:
1.  **Configuration Override**: Modify the `Config` class attributes to reduce epochs, batch size, and dataset size, ensuring the script runs quickly (within a few minutes).
2.  **Component Validation**:
    *   **MetricMonitor**: Verify mathematical correctness of the running average tracker.
    *   **Dataset & DataLoader**: Verify data loading, augmentation pipeline, and tensor shapes using the `get_loaders` function.
    *   **Model & GeM**: Verify the `DenseNet121GeM` architecture output shapes and the mathematical correctness of the Generalized Mean Pooling layer.
3.  **Training Execution**: Run the `fit` function for a single fold to demonstrate the training loop and model checkpointing.
4.  **Inference Execution**: Run the `run_inference` function to generate predictions using the trained model and verify the submission file format.
