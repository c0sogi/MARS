# Model: DenseNet121 with Modified Input Stem
I propose replacing the ResNet18 backbone with a **DenseNet121** architecture. DenseNets rely on feature concatenation rather than residual addition, which encourages feature reuse and is particularly effective at capturing fine-grained textural details in medical imaging while maintaining parameter efficiency.

To ensure this deeper architecture is compatible with the small input dimensions, I will apply the **Modified Stem** strategy. The standard DenseNet input block (a $7 \times 7$ stride-2 convolution followed by a $3 \times 3$ stride-2 max pooling) aggressively downsamples the image by $4\times$. For a $48 \times 48$ input, this would result in a $12 \times 12$ feature map before the first dense block, destroying spatial fidelity. I will replace this entire initial sequence with a single $3 \times 3$ convolution with stride 1 and no pooling, preserving the full $48 \times 48$ spatial resolution entering the first dense block.
*   **Cite solution_lesson_node_00003** (Adapt Standard Backbone Stems for Small Input Resolutions).

# Data: Hard Attention and Conservative Augmentation
**Preprocessing:**
I will strictly adhere to the **Hard Attention** strategy by cropping the central **48x48 pixel region** from the original images. This aligns the model's field of view with the ground truth definition (center 32x32) while retaining a minimal context margin, effectively removing background label noise.
*   **Cite solution_lesson_node_00001** (Hard Attention via ROI Cropping).

**Augmentation:**
During training, I will apply random horizontal flips, vertical flips, and 90-degree rotations. Crucially, I will apply **only moderate color augmentation** (e.g., weak brightness/contrast jitter). I will explicitly avoid the aggressive color jittering that was found to degrade performance by distorting stain-dependent biomarkers.
*   **Cite solution_lesson_node_00004** (Sensitivity of Histopathology Models to Aggressive Color Augmentation).

# Training: Volatility-Resistant Schedule
I will train the model using the **Adam** optimizer and a **Cosine Annealing** learning rate scheduler over 20 epochs. To address the issue of volatile training dynamics causing premature termination, I will **relax the Early Stopping patience**. I will set the patience to 6 epochs (30% of the total duration) to allow the model to recover from transient validation dips that occur during the high-learning-rate phases of the schedule.
*   **Cite solution_lesson_node_00007** (Premature Early Stopping with Volatile Training Dynamics).

# Evaluation: Test Time Augmentation (TTA)
For the final submission, I will implement **Test Time Augmentation**. For each test image, the model will predict probabilities for 4 views: the original 48x48 crop, and its horizontal flip, vertical flip, and 90-degree rotation. The final prediction will be the average of these four probabilities, marginalizing out orientation-specific variance.
*   **Cite solution_lesson_node_00005** (Robust Inference via Test Time Augmentation).
