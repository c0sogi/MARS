The `torch.OutOfMemoryError` indicates that the GPU memory (approx. 16GB) is insufficient to handle the current configuration of `BATCH_SIZE = 8` with the memory-intensive `efficientnet-b5` backbone and `1024x1024` input resolution. The activation maps generated during the forward pass consume the majority of the VRAM. To resolve this, I will reduce the `BATCH_SIZE` from 8 to 2 in `library/config.py`. This reduction scales the memory requirement inversely to the input resolution and model complexity, ensuring the batch fits within the available VRAM (Cite debug_lesson_1).
