The issue identified in the error analysis is that the `HuBMAPDataset` class assumes all input images are 3-channel (RGB) TIFFs by hardcoding `src.read([1, 2, 3])`. However, the dataset contains some 1-channel (grayscale) images, causing an `IndexError` when attempting to access non-existent bands.

To fix this, I will update the image reading logic in `library/dataset.py` to check the number of channels (`src.count`) available in the image file. If the image has 3 channels, it will proceed as before. If it has 1 channel, it will read the single band and replicate it 3 times to create a 3-channel image, ensuring compatibility with the model architecture (ResNet18). I will also apply the same fix to `library/inference.py` to prevent potential failures during the inference phase.
