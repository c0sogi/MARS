The following strategy outlines the implementation for the Exploratory Data Analysis (EDA) script:

1.  **Setup and Data Loading**: The script will initialize by setting random seeds for reproducibility and loading the `train_metadata.csv` file generated in the previous step. This ensures strict adherence to using only the training set to prevent data leakage.

2.  **Target Variable Analysis (Segmentation Masks)**:
    *   Since the target is an RLE-encoded mask, we will analyze the distribution of the "positive" class (glomeruli pixels).
    *   We will calculate the **Mask Coverage Ratio** (Total Glomerulus Area / Total Image Area) by parsing the RLE strings (summing run lengths) without decoding the full masks into memory.
    *   We will also parse the associated JSON files to count the number of distinct Glomeruli objects per image and analyze the distribution of individual object sizes.

3.  **Image Data Analysis**:
    *   We will utilize `rasterio` to handle the large TIFF files efficiently. Instead of loading the full multi-gigabyte images, we will read downsampled versions (thumbnails) or metadata tags to extract dimensions, channel counts, and bit depths.
    *   We will compute global pixel mean and standard deviation from these downsampled representations to inform normalization strategies.

4.  **Tabular/Metadata Analysis**:
    *   We will analyze the patient demographic and anatomical metadata (e.g., `age`, `bmi`, `percent_cortex`).
    *   We will report descriptive statistics, missing values, and cardinality for categorical features.

5.  **Feature Relationships**:
    *   We will examine correlations between patient metadata (e.g., `percent_cortex`) and the target characteristics (e.g., `mask_coverage`).
    *   We will use a lightweight Random Forest regressor to identify which metadata features are most predictive of the amount of functional tissue (mask coverage).

6.  **Reporting**: The results will be printed to standard output, organized into the required sections, with floats formatted to 4 decimal places.
