The strategy for the implementation is as follows:

1.  **Setup and Data Loading**:
    -   Define the root input directory (`./input`) and the output directory (`./metadata`).
    -   Load the `train.csv` (containing IDs and RLE masks) and `sample_submission.csv` (containing test IDs).
    -   Load `HuBMAP-20-dataset_information.csv` to retrieve metadata like `patient_number`, which is crucial for group-based splitting.

2.  **Data Processing**:
    -   For the training data:
        -   Merge the IDs from `train.csv` with the metadata from `HuBMAP-20-dataset_information.csv`.
        -   Construct relative file paths for the images (`.tiff`), glomerulus segmentations (`.json`), and anatomical structure segmentations (`.json`) located in the `input/train/` directory.
    -   For the test data:
        -   Use IDs from `sample_submission.csv`.
        -   Construct relative file paths for files located in the `input/test/` directory.
        -   Merge with metadata if available, though it's not strictly necessary for inference.

3.  **Splitting**:
    -   Use `GroupShuffleSplit` from `sklearn` to split the training data into training and validation sets.
    -   Group by `patient_number` to ensure that all images from the same patient stay in the same split, preventing data leakage.
    -   Set the test size to 20% and use `random_state=42`.

4.  **Metadata Generation**:
    -   Save the resulting DataFrames (train, val, test) as CSV files in the `./metadata` directory.

5.  **Validation**:
    -   **File Existence**: Randomly sample paths from the generated metadata and verify they exist in the `./input` directory. Raise an error if the failure rate exceeds 50%.
    -   **Split Verification**: Verify that the train/val split ratio is approximately correct and strictly enforce that no `patient_number` appears in both sets.
