The `albumentations` library version 2.0.8 introduced a breaking API change for `RandomResizedCrop`, requiring a `size` argument (tuple) instead of separate `height` and `width` arguments. The execution failed with a `ValidationError` because `size` was missing. I will fix this in `library/dataset.py` by updating the `RandomResizedCrop` instantiation to use `size=(image_size, image_size)`. Cite debug_lesson_albumentations_2_0_api_change.

```diff
library/dataset.py
<<<<<<< SEARCH
                A.RandomResizedCrop(
                    height=image_size, width=image_size, scale=(0.8, 1.0), p=1.0
                ),
=======
                A.RandomResizedCrop(
                    size=(image_size, image_size), scale=(0.8, 1.0), p=1.0
                ),
>>>>>>> REPLACE
```
