This script demonstrates the end-to-end usage of the provided library components to train a hierarchical plant classification model. 

**Implementation Strategy:**
1.  **Setup & Configuration**: Initialize the environment with a fixed seed and determine the computation device (GPU/CPU).
2.  **Data Preparation**: Load the generated metadata CSVs. To ensure the demonstration runs quickly, we sample a small subset (e.g., 100 images) of the training, validation, and test data.
3.  **Mapping Generation**: Utilize the utility functions to generate the necessary taxonomic mappings (Category ID to Family/Genus/Species indices) required by the dataset and model.
4.  **Dataset & DataLoader Instantiation**: Manually instantiate `HierarchicalPlantDataset` objects for the sampled data subsets and wrap them in PyTorch `DataLoader`s. This demonstrates how to handle the custom dataset class.
5.  **Model Initialization**: Create an instance of `HierarchicalConvNeXt`. We explicitly set `pretrained=False` to avoid potential network timeouts during the demo, although `True` would be used in production.
6.  **Training Loop**: Initialize the `HierarchicalTrainer` and execute the `fit` method for a minimal number of epochs (2) to demonstrate the training process, loss calculation, and checkpoint saving.
7.  **Verification**: Assert that the model checkpoint was successfully saved and perform a dummy inference pass on the test set to verify the prediction pipeline.
