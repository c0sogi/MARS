Implementation Strategy:
The following script demonstrates the complete pipeline for the hierarchical plant classification task using the provided library modules.
1.  **Configuration & Setup**: We initialize the `Config` class with `debug=True` and `num_epochs=1`. This limits the dataset to 5,000 samples and runs a single training epoch, ensuring the script completes quickly (minutes) while exercising all code paths. We also set the random seed for reproducibility.
2.  **Data Loading**: We instantiate `PlantDataset` and `DataLoader` for training, validation, and testing. We explicitly verify the shape of a single batch from the training loader to ensure data transformation and loading logic is correct.
3.  **Model & Loss Initialization**: We load the `HierarchicalConvNeXt` model and the `MultiTaskLoss`. We perform a forward pass with a dummy batch to verify that the model outputs the expected dictionary of logits (`species`, `genus`, `family`) and that the loss function computes a valid scalar gradient.
4.  **Training Loop**: We set up an `AdamW` optimizer and a `CosineAnnealingLR` scheduler, then invoke the `fit` function from `library.engine` to train the model and save the best checkpoint.
5.  **Inference**: We call `predict_and_submit` to generate predictions on the test set (also limited by debug mode) using the trained model. Finally, we verify that the submission CSV is created and contains the correct columns.
