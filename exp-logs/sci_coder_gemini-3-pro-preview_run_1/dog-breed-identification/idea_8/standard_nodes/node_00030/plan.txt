Implementation Strategy:
The solution orchestrates a **Heterogeneous Stacking Ensemble** pipeline designed to meet the strict log-loss requirement. The strategy involves:
1.  **Data Preparation**: Utilizing the provided `_process_data` function to cache resized and cropped images, ensuring efficient loading during training.
2.  **Expert Training (Level 1)**: Executing a 5-Fold Cross-Validation loop where two distinct expert models are trained per fold:
    *   **Expert A (ConvNeXt-Base)**: Trained via `run_regime_a` (Head Adaptation -> Fine-Tuning -> SWA).
    *   **Expert B (Swin-Base)**: Trained via `run_regime_b` (Head Adaptation -> Regularized Fine-Tuning with Mixup/CutMix -> Cooldown -> SWA).
    *   This results in 10 trained model checkpoints (5 folds × 2 architectures).
3.  **Stacking (Level 2)**: Using the `Stacker` class to:
    *   Generate Out-Of-Fold (OOF) predictions for the training set using Test Time Augmentation (TTA).
    *   Generate Test set predictions.
    *   Train a Logistic Regression Meta-Learner on the OOF logits to optimize calibration.
4.  **Validation & Analysis**:
    *   Computing the final Multi-Class Log Loss on the OOF set.
    *   Performing failure analysis by correlating prediction error magnitude with image metadata (width, height, aspect ratio) to identify systematic weaknesses.
5.  **Submission**: Generating the final `submission.csv` if and only if the validation metric is below the specified threshold of `0.12970461086690332`.

The script is implemented to be self-contained, importing necessary components from the provided libraries and utilizing the A100 GPU for efficient execution within the time limit.
