Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a solution that evolves the successful **ConvNeXt-Base** architecture into a **Stochastic Weight Averaging (SWA) Ensembled K-Fold Pipeline**. This strategy addresses the generalization gap and fine-grained nature of the task by introducing a third training phase (SWA) and moderately increasing input resolution, while strictly adhering to the geometric constraints identified as critical.

# Model
We will retain the **ConvNeXt-Base** architecture initialized with **ImageNet-1k** weights `Cite solution_lesson_node_00014`.
*   **Homogeneous Ensemble:** We will train **5 independent instances** of this model using Stratified K-Fold Cross-Validation. This avoids the "weak link" failure observed when ensembling different architectures (e.g., Swin) `Cite solution_lesson_node_00021`.
*   **Regularization:** Each model will include a **Dropout** layer in the classification head to prevent the overfitting observed in high-capacity models `Cite solution_lesson_node_00006`.

# Data
We will implement a **High-Resolution Geometric Pipeline** to capture the fine-grained details (e.g., fur texture, snout shape) required for breed classification.
*   **Input Scaling:** We will increase the input resolution from the previous 224x224 to **256x256**. This provides a higher signal-to-noise ratio for subtle features without the massive computational cost or risk of domain mismatch associated with 384x384 inputs `Cite solution_lesson_node_00017`.
*   **Aspect Ratio Preservation:** We will strictly use `Resize(274)` (integer argument) followed by `CenterCrop(256)`. This ensures the aspect ratio of the dog is preserved, avoiding the geometric distortion that caused previous failures `Cite solution_lesson_node_00018`.
*   **Augmentation:** We will use **only Random Horizontal Flips**, avoiding aggressive spatial distortions `Cite solution_lesson_node_00002`.

# Training
We will introduce a **Three-Phase Training Strategy** incorporating **Stochastic Weight Averaging (SWA)**. SWA allows the model to find a flatter minimum in the loss landscape, improving generalization on small datasets where standard models might settle into sharp, brittle minima.

1.  **Phase 1: Head Adaptation**
    *   **Action:** Freeze the backbone, train only the head for 3-5 epochs.
    *   **Goal:** Align the random head weights with the pre-trained features to prevent "optimization inertia" `Cite solution_lesson_node_00009`.

2.  **Phase 2: Discriminative Fine-Tuning**
    *   **Action:** Unfreeze the backbone. Apply **Discriminative Learning Rates** (e.g., `1e-6` for backbone, `1e-4` for head) `Cite solution_lesson_node_00006`.
    *   **Goal:** Adapt features to the specific dog breeds without catastrophic forgetting. We will use **Cross-Entropy Loss** (no Label Smoothing) `Cite solution_lesson_node_00004` and maintain a global metric tracker `Cite solution_lesson_node_00008`.

3.  **Phase 3: Stochastic Weight Averaging (SWA) (New)**
    *   **Action:** Continue training for a fixed number of epochs (e.g., 5-10) with a **constant or cyclic learning rate**. At the end of each epoch, capture a snapshot of the model weights and update an averaged model.
    *   **Goal:** Construct a final model whose weights are the average of these snapshots. This "structural innovation" creates a more robust model that is less sensitive to shifts in the test distribution, directly addressing the generalization gap seen in Lesson 00001.

# Evaluation
We will maximize prediction stability using a robust inference pipeline.
*   **Test Time Augmentation (TTA):** For each test image, we will predict on both the original and a horizontally flipped view `Cite solution_lesson_node_00014`.
*   **Ensemble Aggregation:** The final submission will be the average of probabilities from all **5 SWA-enhanced K-Fold models** (each with TTA). This combines the benefits of data diversity (K-Fold) with optimization robustness (SWA).
