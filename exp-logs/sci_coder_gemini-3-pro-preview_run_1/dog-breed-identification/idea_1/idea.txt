To establish a robust and efficient baseline, I propose a **Transfer Learning approach using the ResNet-18 architecture**. This solution prioritizes simplicity and training speed while leveraging deep convolutional features that are highly effective for image classification.

### Model
The core of the solution is the **ResNet-18** architecture, a lightweight Convolutional Neural Network characterized by its residual skip connections which facilitate gradient flow.
- **Backbone:** We will use a ResNet-18 model pre-trained on the ImageNet dataset. This serves as a powerful feature extractor that has already learned to recognize low-level edges and high-level patterns relevant to animals and objects.
- **Head:** The original 1000-class fully connected layer will be removed and replaced with a new linear classification layer that maps the 512-dimensional feature vector to the **120 dog breed classes**.
- **Distinction:** Unlike the EfficientNet (Model 1) and Swin Transformer (Model 2) approaches, ResNet-18 uses standard convolutions and a simpler residual structure, offering a different trade-off between throughput and parameter efficiency. It avoids the complexity of the hybrid tree/SVM methods (Models 3 & 4) by remaining a pure end-to-end differentiable deep learning pipeline.

### Data
Data processing will be kept minimal to maximize throughput and reproducibility.
- **Preprocessing:** All images will be resized to 256x256 pixels and then **center-cropped to 224x224**. This ensures fixed input dimensions while maintaining the aspect ratio of the central subject.
- **Normalization:** Pixel values will be normalized using the standard ImageNet mean (`[0.485, 0.456, 0.406]`) and standard deviation (`[0.229, 0.224, 0.225]`).
- **Augmentation:** To prevent overfitting without incurring high computational cost, we will apply only **Random Horizontal Flips** during training. Validation and testing will use only resizing and center cropping.

### Training
The training process uses a two-phase strategy to ensure stability and convergence.
- **Loss Function:** We will minimize **Cross-Entropy Loss**, which is the standard proxy for optimizing Multi-Class Log Loss.
- **Optimizer:** The **Adam** optimizer will be used for its adaptive learning rate capabilities, requiring less manual tuning than SGD.
- **Phase 1 (Head Adaptation):** Initially, the convolutional backbone will be **frozen**. Only the weights of the new classification head will be trained for a few epochs. This prevents the large gradients from the randomly initialized head from destroying the pre-trained weights in the backbone.
- **Phase 2 (Fine-Tuning):** We will then **unfreeze the final residual block (Layer 4)** and the classification head, training them together with a reduced learning rate (e.g., 10x smaller than Phase 1). This allows the model to adapt its high-level feature representations to the specific nuances of dog breeds.

### Evaluation
- **Inference:** Test images will undergo the same resizing, center cropping, and normalization as the validation set.
- **Prediction:** The model will output raw logits for each image. These logits will be passed through a **Softmax** function to generate a probability distribution over the 120 classes, ensuring the sum of probabilities is 1.0 as required for the Log Loss metric.
