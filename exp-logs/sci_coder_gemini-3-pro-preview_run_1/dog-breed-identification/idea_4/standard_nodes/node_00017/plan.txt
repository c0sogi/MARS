My implementation strategy follows the Stratified K-Fold Ensemble approach outlined in the idea.

1.  **Setup & Data Loading**: I will initialize the environment (seed, device) and load the datasets using the provided `load_datasets` function. This function combines the original training and validation sets into a single dataframe, maximizing the data available for the K-Fold process.
2.  **Stratified K-Fold Training**: I will utilize `StratifiedKFold` (5 folds) to split the combined training data. For each fold:
    *   I will create `DogDataset` instances for the training and validation splits.
    *   I will initialize the `DogClassifier` (ConvNeXt-Base) and move it to the GPU.
    *   I will execute the `train_loop`, which handles the two-phase training (Head Adaptation -> Fine-tuning) and saves the best model checkpoint.
    *   After training, I will reload the best checkpoint to generate Out-Of-Fold (OOF) predictions for the validation set and TTA predictions for the test set.
3.  **Validation & Failure Analysis**:
    *   I will aggregate the OOF predictions to compute the final Multi-Class Log Loss on the entire dataset.
    *   I will perform failure analysis by calculating the per-sample loss and correlating it with image metadata (width, height, aspect ratio, area) extracted via `cv2` to identify potential weaknesses related to image properties.
4.  **Submission**:
    *   I will average the test set predictions across all 5 folds to create a robust ensemble prediction.
    *   If the final validation metric meets the specified threshold (< 0.1414), I will format and save the predictions to `submission.csv`.
