This script demonstrates the usage of the provided library files for the salt segmentation task. It performs the following steps:

1.  **Setup**: Imports necessary modules and monkey-patches the library constants to use a temporary working directory and a small subset of the data for speed.
2.  **Data Preparation**: Creates a "mini" dataset by sampling the provided metadata and saving it to the temporary directory. This ensures the demonstration runs quickly without processing the entire dataset.
3.  **Utils Verification**: Validates the Run-Length Encoding (RLE) logic and IoU metric calculation with synthetic data.
4.  **Dataset & Model Verification**: Instantiates the `DeepResUNet` model and the data loaders. It runs a forward pass with a batch of data to verify tensor shapes and data pipeline integrity.
5.  **Loss Verification**: Tests the `CurriculumLoss` to ensure it computes gradients correctly.
6.  **Training Loop Demonstration**: Runs a short training cycle (2 epochs) using the `Trainer` class to demonstrate the integration of all components, followed by generating predictions on the mini test set.
