Here is the implementation strategy and the complete Python script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the working directory and set random seeds for reproducibility using `library.utils.set_seed`.
2.  **Utility Verification**:
    *   Create a synthetic binary mask.
    *   Test `rle_encode` and `rle_decode` to ensure the mask can be round-tripped (encoded and decoded back to the original) without data loss.
    *   Verify `calculate_iou` and `calculate_map_score` with known synthetic inputs (e.g., perfect match vs. no overlap).
3.  **Data Preparation**:
    *   Load the full `./metadata/train.csv` and `./metadata/val.csv`.
    *   Create "mini" subsets (e.g., 16 training samples, 8 validation samples) and save them to `./working` to ensure the training demonstration runs quickly.
4.  **Dataset & Pipeline Testing**:
    *   Instantiate `SaltDataset` using the mini-metadata.
    *   Retrieve a single sample to verify data shapes (Channels: 2 [Image+Depth], Height/Width: 128 padded) and value ranges.
    *   Verify that the depth channel is correctly fused.
5.  **Model & Loss Verification**:
    *   Instantiate `HyperColumnUNet`.
    *   Pass a batch of data through the model to confirm the forward pass works and produces the expected output shape `(Batch, 1, 128, 128)`.
    *   Compute `BCEDiceLoss` and `LovaszLoss` on the output to ensure gradients can be calculated and loss values are valid.
6.  **Training Integration**:
    *   Execute `library.train.run_fold` using the mini-datasets.
    *   Run for a minimal number of epochs (2) to demonstrate the full training loop (loading, forward pass, backward pass, validation, checkpointing) without exceeding time limits.
7.  **Final Validation**:
    *   Assert that the training process produced a saved model checkpoint (`best_model.pth`).
