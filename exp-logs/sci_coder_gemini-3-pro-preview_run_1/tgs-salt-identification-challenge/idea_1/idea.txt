Based on the provided dataset analysis and model architectures, here is a proposal for a highly efficient baseline approach.

### Model: Depth-Aware Lightweight U-Net
I propose a **custom Lightweight U-Net** that synthesizes the structural advantages of the U-Net (Model 1) with the efficient depth-handling strategy of the Vision Transformer (Model 2).

*   **Architecture Design**: Instead of using a heavy pre-trained backbone like ResNet-18 (as in Model 1), this model will use a streamlined, custom encoder-decoder built from scratch. This ensures the model remains lightweight and fast to train. The network will consist of 4 encoder blocks and 4 decoder blocks. Each block will utilize standard 3x3 convolutions, Batch Normalization, and ReLU activations.
*   **Depth Integration (Input Fusion)**: Leveraging the concept from Model 2, the scalar depth value (`z`) will be integrated at the input level rather than the bottleneck. The depth value will be normalized, repeated spatially to form a dense feature map of the same resolution as the image, and concatenated as a second channel. This allows the model's earliest filters to learn depth-dependent texture representations immediately.

### Data
*   **Preprocessing**:
    *   **Padding**: The 101x101 images will be padded (using reflection or constant padding) to **128x128** pixels. This power-of-two resolution is necessary to support the multiple downsampling operations in the U-Net without rounding errors or information loss.
    *   **Grayscale Conversion**: Despite the file analysis showing 3/4 channels, seismic data is inherently single-channel. Images will be converted to grayscale to reduce computational overhead.
    *   **Normalization**: Pixel values will be scaled to the [0, 1] range. Depth values will be z-score normalized (subtracted by mean, divided by std) using statistics from the training set.
*   **Augmentation**: To maintain high training speed while providing basic regularization, only **Random Horizontal Flips** will be used.

### Training
*   **Loss Function**: A composite loss of **Binary Cross Entropy (BCE) + Dice Loss** will be used. BCE ensures pixel-wise classification accuracy, while Dice Loss directly optimizes the overlap metric and helps mitigate the class imbalance between salt and sediment pixels.
*   **Optimizer**: The **Adam** optimizer will be used for its fast convergence properties, with a standard learning rate (e.g., 1e-3).
*   **Strategy**: The model will be trained with early stopping based on the validation set IoU to prevent overfitting.

### Evaluation
*   **Inference**: Test images will undergo the same padding and normalization as the training set.
*   **Post-Processing**:
    1.  The model's output (logits) will be passed through a sigmoid activation.
    2.  The 128x128 prediction will be **center-cropped** back to the original 101x101 dimensions.
    3.  A fixed threshold of **0.5** will be applied to generate the binary mask.
    4.  The binary mask will be converted to the required Run-Length Encoding (RLE) format for submission.
