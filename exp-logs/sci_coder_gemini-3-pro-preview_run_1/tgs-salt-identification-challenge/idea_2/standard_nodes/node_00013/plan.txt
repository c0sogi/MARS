Here is the implementation of the `runfile.py` script.

This script orchestrates the entire pipeline:
1.  **Setup**: Initializes the environment and random seeds.
2.  **Data Loading**: Loads the training and validation data using the provided library, utilizing caching for speed.
3.  **Training**: Trains the `ResNet34UNetPlusPlus` model using `BCEDiceLoss` and `ReduceLROnPlateau` scheduling. The training is limited to 25 epochs to serve as a fast baseline while ensuring sufficient convergence to meet the metric threshold.
4.  **Validation**: Evaluates the best model on the hold-out validation set and prints the **Final Validation Metric** (mAP).
5.  **Failure Analysis**: Calculates the Average Precision (AP) for each validation image, derives the error magnitude ($1 - AP$), and computes the Pearson correlation between this error and the input features (Depth and Salt Coverage).
6.  **Submission**: If the validation metric exceeds the threshold of 0.7647, it performs inference on the test set (with TTA) and generates the submission file.
