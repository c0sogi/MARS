The following script demonstrates the end-to-end pipeline for the Corrected Dual-Context Anchor Network (DC-AN) solution. It performs the following steps:

1.  **Configuration Setup**: Overrides the default `Config` to use a temporary working directory and a small subset of data (debug mode) to ensure quick execution.
2.  **Unit Testing**: Verifies the core metric calculation (`compute_kendall_tau`) and the ranking reconstruction logic (`get_ranks`) using synthetic data.
3.  **Preprocessing**: Runs the `Preprocessor` to extract text from the raw JSON notebooks (referenced in metadata) and generates Parquet feature files containing MPNet embeddings.
4.  **Dataset Verification**: Instantiates the `CachedNotebookDataset` and a `DataLoader` to verify that data loading, tensor collation, and padding logic function correctly.
5.  **Model Verification**: Initializes the `DualContextAnchorNetwork` and performs a forward pass with a batch of data to confirm tensor shapes and mask handling.
6.  **Training**: Executes the `Trainer` to train the model for one epoch on the subset, saving the best model checkpoint.
7.  **Inference**: Runs the `InferencePipeline` to generate predictions on the test set subset using the trained model, producing a submission file.
