1.  **Configuration & Setup**: Import the necessary modules from the provided `library` package. Override specific `Config` parameters (enabling `DEBUG` mode with a subset of 15,000 notebooks and reducing `EPOCHS` to 5) to ensure the entire pipeline executes within the 2-hour limit while still providing enough data for a meaningful baseline.
2.  **Preprocessing**: Execute the `Preprocessor` to generate MPNet embeddings for the training, validation, and test sets. This step handles the heavy lifting of text encoding.
3.  **Training**: Initialize the `CorrectedDCAN` model, `NotebookDataset`, and `DataLoader`s. Run the training loop using `train_one_epoch` and `validate` from the engine, saving the model with the best validation Kendall Tau score.
4.  **Final Validation**: Reload the best model and perform inference on the validation set. Calculate the global Kendall Tau metric and print it in the required format.
5.  **Failure Analysis**: Compute the Kendall Tau score for each individual notebook in the validation set. Correlate these scores with notebook properties (number of code cells, number of markdown cells) to identify error patterns and print the results.
6.  **Submission Logic**: Check if the final validation metric exceeds the threshold (0.8315021559000814). If successful, run inference on the test set, generate the `submission.csv` file, and save it.
