### Implementation Strategy

1.  **Environment Setup**: We will create a temporary directory (`./working/demo_run`) to store subsets of metadata and intermediate files, ensuring we don't interfere with the main training artifacts.
2.  **Data Subsetting**: We will load the provided metadata files (`train_metadata.csv`, etc.), sample a very small number of notebooks (e.g., 5), and save these mini-metadata files to our temporary directory.
3.  **Configuration Override**: We will override the `Config` class attributes to point to these new mini-metadata files and reduce training parameters (1 epoch, small batch size) to ensure the script runs quickly.
4.  **Component Verification**:
    *   **Data Loading**: Verify `read_notebook` and `load_notebook_cells` correctly parse JSON files and extract source code.
    *   **Feature Extraction**: Run the feature extraction pipeline on the mini-dataset and verify the output Parquet files contain embeddings.
    *   **Dataset & DataLoader**: Instantiate `HAPSDataset` and a `DataLoader` to verify batch collation, masking, and label generation.
    *   **Model & Loss**: Instantiate `HAPSModel` and `HAPSLoss`, run a forward pass with a dummy batch, and verify the loss calculation.
    *   **Inference**: Test the global sorting and refinement logic using the model's output.
5.  **Integration Test**: Execute the `train()` function from `library.train` to run a complete end-to-end training and inference cycle on the mini-dataset.
