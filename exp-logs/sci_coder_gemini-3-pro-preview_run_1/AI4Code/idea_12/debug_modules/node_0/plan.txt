The following implementation demonstrates the end-to-end usage of the provided library files for the notebook cell ordering task.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to enable `DEBUG` mode, reduce the dataset size to 50 samples, and set a small batch size. This ensures the script runs quickly within the time limit.
2.  **Preprocessing**: We instantiate the `Preprocessor` to generate feature embeddings (using `SentenceTransformer`) for the reduced training, validation, and test sets. We explicitly remove existing parquet files to ensure the debug settings are applied.
3.  **Data Loading**: We verify the `CachedNotebookDataset` and `collate_fn` by loading a single batch and asserting the shapes of the resulting tensors (Code embeddings, Markdown embeddings, Masks, Labels).
4.  **Model Execution**: We initialize the `DC_AN` model and perform a forward pass with the sample batch to verify the output shape `[Batch, Markdown_Len, Code_Len + 1]`.
5.  **Training & Validation**: We run a single training epoch using `train_one_epoch` and evaluate the model using `validate` to ensure the loss calculation and Kendall Tau metric logic are functioning correctly.
6.  **Inference**: We execute the full inference pipeline using `run_inference`, which generates a submission CSV. We verify the file's existence and format.
