The error `TypeError: can't convert np.ndarray of type numpy.object_` occurs because the `code_embeddings`, `markdown_embeddings`, and `markdown_labels` columns are loaded from the Parquet file as NumPy arrays of objects (due to their nested list structure). PyTorch's `torch.tensor()` constructor cannot directly convert these object arrays into tensors. To fix this, I will modify `library/dataset.py` to explicitly convert these arrays into standard Python lists using `.tolist()` before passing them to `torch.tensor()`, as recommended in `debug_lesson_3` (Cite debug_lesson_3).
