The error `TypeError: can't convert np.ndarray of type numpy.object_` occurs because the `code_embeddings` column (and likely `markdown_embeddings` and `markdown_labels`) is being loaded from the Parquet file as a NumPy array of objects (likely due to the nested list structure) rather than a standard Python list or numeric array. PyTorch's `torch.tensor()` constructor does not support NumPy arrays with `dtype=object`.

To fix this, I will explicitly convert these arrays to standard Python lists using the `.tolist()` method before passing them to `torch.tensor()`. This ensures the data is in a format (list of lists or list of numbers) that PyTorch can interpret, as recommended in **Cite debug_lesson_3**. I will apply this fix to the code embeddings, markdown embeddings, and label loading sections in `library/dataset.py`.
