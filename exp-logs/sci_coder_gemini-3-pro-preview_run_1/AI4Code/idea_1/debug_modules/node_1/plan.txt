The issue is that `runfile.py` monkey-patches `tqdm.auto.tqdm` using `functools.partial` to disable progress bars. However, downstream libraries (specifically `huggingface_hub`) attempt to create a subclass of `tqdm`. Since `partial` objects are not classes, this inheritance fails with a `TypeError`. The fix is to replace the `partial` object with a proper subclass of `tqdm` that sets `disable=True` in its initializer, maintaining the type hierarchy required for inheritance.
