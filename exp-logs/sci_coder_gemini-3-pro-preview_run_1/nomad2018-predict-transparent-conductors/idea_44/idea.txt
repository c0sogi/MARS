Based on the comprehensive analysis of previous experiments and the extracted lessons, I propose the **Anisotropic Multi-Scale Physics-Aware Deep Sets (AMSP-DS)** strategy.

This strategy represents a structural synthesis and correction of the most promising previous approaches (**Idea 41** and **Idea 42**). It builds upon the high-performing **Multi-Scale Chemical Context** (Lesson 92) by integrating **Geometric Distortion Ratios** (from Idea 42) and **Global Physical Inductive Biases** (from Idea 29). Crucially, it addresses the specific implementation failure of Idea 42 by strictly enforcing **Selective Feature Scaling** (Lesson 94), ensuring that categorical one-hot encodings are not corrupted by normalization. It also retains **Sparse Batching** (Lesson 89) and the **Wide/Regularized Architecture** (Lessons 17, 24, 36) essential for stability.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Distortion-Aware Point Processor):**
    *   **Input Features:** For each atom, construct a dense feature vector (17 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims). **Crucially, these are NOT scaled.**
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains critical node-level spatial variance (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance ($d_{min}$):** The scalar distance to the single closest neighbor (PBC-corrected) (**Cite Lesson 15**).
        *   **Local Packing Ratio:** The dimensionless ratio $R = d_{min} / d_{mean\_12}$, where $d_{mean\_12}$ is the mean distance to the $K=12$ nearest neighbors. This captures **local structural distortion** (e.g., deviation from ideal packing) orthogonal to density, providing a geometric signal distinct from pure distance (**Cite Lesson 82**).
        *   **Multi-Scale Chemical Contexts:** Two 4-dimensional vectors representing the **Inverse-Distance Weighted Composition** of the **$K=6$** (Short-Range) and **$K=24$** (Medium-Range) nearest neighbors. These capture the chemical identity of the immediate coordination shell and the broader crystal field (**Cite Lesson 92**).
    *   **Encoder:** A **Wide MLP** (e.g., 3 layers of 512 hidden units) to project features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation.
    *   **Output:** A **Linear** projection (no activation) to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) (**Cite Lesson 5**).

2.  **Global Stream (Anisotropic Physics Context):**
    *   **Input:**
        *   **Standard:** Lattice vector lengths, lattice angles, unit cell volume, atomic density, **explicit stoichiometry** (**Cite Lesson 13**), and **Total Number of Atoms** (**Cite Lesson 35**).
        *   **Lattice Aspect Ratios:** The ratios of lattice lengths ($a/b, b/c, c/a$). These explicitly encode macroscopic **anisotropy**, which correlates with bandgap directionality.
        *   **Composition-Weighted Physics:** The stoichiometry-weighted average of **Atomic Mass**, **Covalent Radius**, and **Electronegativity** for the crystal. While redundant at the atomic level, these provide a direct **chemical manifold** for the global stream, serving as a strong inductive bias for the material class (**Cite Lesson 29**).
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Neighbor Search:** Compute pairwise distances using lattice vectors (Periodic Boundary Conditions).
    *   **Feature Extraction:**
        *   Compute $d_{min}$ ($K=1$) and $d_{mean\_12}$ ($K=12$). Calculate **Packing Ratio**.
        *   Compute **Weighted Context Vectors** for $K=6$ and $K=24$.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, and **Total Atoms**.
    *   Calculate Unit Cell Volume, Atomic Density, **Lattice Aspect Ratios**, and **Weighted Physical Properties**.
    *   **Selective Scaling:** Apply Standard Scaling (z-score) **ONLY** to continuous features (coords, distances, ratios, contexts, global features). **Do NOT scale the one-hot encoded atomic identity columns** (**Cite Lesson 94**).
3.  **Batching Strategy:**
    *   Use **Sparse (Flattened) Batching** (concatenating atoms into one large tensor with an index vector) to preserve Batch Normalization statistics (**Cite Lesson 89**).
4.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables.

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$).
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-MultiScale/Ratio calculation, Selective Scaling).
2.  **Prediction:** Pass the processed data through the trained model using sparse batching.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
