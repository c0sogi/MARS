The following script demonstrates the complete pipeline for the Density-Calibrated Chemically-Contextualized Wide Deep Sets (DC3-WDS) model. It performs the following steps:
1.  **Configuration**: Patches the `Config` class to use a temporary working directory and enables "Debug Mode" to process only a small subset of data (20 samples) for rapid execution.
2.  **Geometry Parsing**: Directly tests `geometry_utils` by parsing a sample crystal structure and generating atomic features, verifying shapes and data types.
3.  **Data Loading**: Initializes the `MaterialDataset` and `DataLoader` via `get_loaders`, ensuring the pipeline correctly processes raw data into tensors.
4.  **Model Forward Pass**: Instantiates the `DC3_WDS` model and runs a single batch of data through it to verify architecture dimensions and output validity.
5.  **Training Loop**: Executes the `run_training` function (configured for 1 epoch) to demonstrate the optimization process, loss calculation, and model checkpointing.
6.  **Inference**: Runs `run_inference` to generate predictions using the trained model and verifies the creation of the submission file.
