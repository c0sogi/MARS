Based on the lessons learned, I propose an optimized strategy called **Interaction-Aware Lattice-Conditioned Deep Sets (IA-LCDS)**. This approach evolves the previous Deep Sets model by explicitly modeling atomic interactions (bonds and local environments) using pairwise distances, rather than relying on absolute Cartesian coordinates. This introduces rotational and translational invariance while retaining the successful global conditioning and aggregation strategies identified in the lessons.

### Model
The architecture consists of two branches that converge for the final prediction:

1.  **Interaction Branch (Structural Evolution):**
    *   **Input:** Instead of raw coordinates, this branch takes **Atomic Types** and **Pairwise Distances** ($d_{ij}$) between atoms in the unit cell (computed using the minimum image convention to respect periodic boundaries).
    *   **Edge Encoding:** For every pair of atoms $(i, j)$, construct an edge feature vector containing the distance $d_{ij}$ and the one-hot encodings of both atom types. Pass this vector through a **Wide MLP** (e.g., immediate expansion to 128+ channels) to project low-dimensional geometric data into a rich latent space **(Cite Lesson 6)**.
    *   **Local Aggregation:** For each atom $i$, aggregate the features of all connected edges using **Dual Pooling (Mean + Max)**. This creates a "Local Environment Vector" for each atom that captures both the intensity and existence of specific chemical interactions **(Cite Lesson 5)**.
    *   **Global Aggregation:** Aggregate these Local Environment Vectors across the entire crystal using **Mean and Max pooling** to form the global structure embedding. **Sum pooling is explicitly excluded** to ensure the representation remains robust for intensive targets like formation energy per atom **(Cite Lesson 7)**.

2.  **Lattice Branch (Strategic Retention):**
    *   **Input:** Macroscopic lattice parameters (lengths $a, b, c$ and angles $\alpha, \beta, \gamma$).
    *   **Processing:** A dedicated MLP encodes these global boundary constraints, which were found to be critical for correcting energy predictions **(Cite Lesson 2)**.

3.  **Fusion and Prediction:**
    *   Concatenate the Global Structure embedding and the Lattice embedding.
    *   Pass the result through a final regressor MLP to predict `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Preprocessing:**
    *   Iterate through `geometry.xyz` files. For each crystal, extract atom types and lattice vectors.
    *   Compute the **Pairwise Distance Matrix** for all atoms in the unit cell, applying the minimum image convention using the lattice vectors to handle periodic boundary conditions (PBC). This replaces the centering step from previous ideas with a fully invariant representation.
    *   Standardize lattice parameters and one-hot encode atomic species (Al, Ga, In, O).
2.  **Target Transformation:**
    *   Apply `log(1+y)` transformation to both target variables to align the training loss with the RMSLE metric.

### Training
1.  **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
2.  **Optimizer:** AdamW optimizer with weight decay.
3.  **Procedure:** Train for a fixed number of epochs with early stopping based on validation RMSLE.

### Evaluation
1.  **Inference:** Generate predictions using the trained model on the test set.
2.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs to recover the original energy scale.
3.  **Submission:** Save the results in the required CSV format.
