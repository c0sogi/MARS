Based on the comprehensive analysis of previous experiments and the extracted lessons, I propose the **Residual Tri-Pool Deep Sets (RT-DS)** strategy.

This strategy evolves the successful "Augmented Point-Cloud Deep Sets" (Idea 4) by upgrading the atomic encoder backbone from a standard MLP to a **Residual Network** to enable deeper feature extraction without gradient degradation. Furthermore, it enriches the aggregation mechanism by introducing **Standard Deviation Pooling** alongside Mean and Max pooling to capture the *variance* of local atomic environments (e.g., structural disorder). It strictly adheres to the successful feature engineering of Idea 4 (Nearest Neighbor distance, Explicit Stoichiometry) while addressing the regularization and capacity needs identified in Lessons 17 and 24, and avoiding the pitfalls of high-cardinality embeddings (Lesson 32) and redundant physical constants (Lesson 23).

### Model
The architecture consists of two parallel streams that process local and global information independently before a late fusion:

1.  **Atomic Stream (Deep Residual Point Processor):**
    *   **Input Features:** A compact feature vector for each atom: **One-hot encoding** of the element (Al, Ga, In, O), **Centered Cartesian coordinates** (Cite Lesson 10), and the **PBC-corrected Nearest Neighbor Distance** (Cite Lesson 15).
    *   **Backbone:** A **Wide Residual Network**. The input is projected to a high-dimensional latent space (512 units) via a linear layer (Cite Lesson 6). This is followed by a stack of **Residual Blocks** (e.g., 3 blocks). Each block follows the structure: `Linear -> BatchNorm -> ReLU -> Dropout -> Linear -> BatchNorm -> Add Input -> ReLU`. This allows the model to learn more complex non-linear transformations of the local geometry than a simple MLP, while the residual connections and Dropout ensure trainability and generalization (Cite Lesson 24).
    *   **Output Layer:** A **Linear** projection (no activation) to the final embedding dimension (Cite Lesson 18).
    *   **Aggregation (Tri-Pooling):** The atomic embeddings are aggregated into a global vector using **Mean**, **Max**, and **Standard Deviation** pooling.
        *   *Mean* captures average properties.
        *   *Max* captures salient/extreme features (Cite Lesson 5).
        *   *Standard Deviation* captures the **heterogeneity** of the crystal structure (e.g., variance in local bond environments), providing a signal distinct from the first-order moments, without the extensivity issues of Sum pooling (Cite Lesson 7).

2.  **Global Stream (Thermodynamic Context):**
    *   **Input:** Macroscopic features: Lattice vector lengths, lattice angles, unit cell volume, atomic density, and **explicit stoichiometry** (Cite Lesson 13).
    *   **Backbone:** A **High-Capacity MLP** (e.g., 3 layers, 256 units) to process these boundary conditions, ensuring the model has sufficient capacity to resolve energy variations driven by macroscopic constraints (Cite Lesson 9).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the Tri-Pooled atomic vector (3 * 512) and the Global embedding (256). (Cite Lesson 19).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Neighbor Calculation:** Compute the pairwise distance matrix using the lattice vectors to strictly respect **Periodic Boundary Conditions**. Extract the minimum non-zero distance for each atom as the "Nearest Neighbor" feature.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters and stoichiometry.
    *   Calculate derived features: **Unit Cell Volume** and **Atomic Density**.
    *   **Scaling:** Apply Standard Scaling (z-score) to all continuous features (atomic coords, NN distance, global features) to ensure balanced gradients.
3.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay (e.g., 1e-4) to regularize the wide residual layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The residual architecture allows for stable training over longer schedules (Cite Lesson 17).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-Neighbor calculation, Scaling).
2.  **Prediction:** Pass the processed data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs to recover the original energy scale.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
