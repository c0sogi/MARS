This script demonstrates the complete pipeline for the material property prediction task. It utilizes the provided library modules to process data, extract physics-aware features, train a Global-Physics Augmented Wide Deep Sets (GPA-WDS) model, and generate a submission file.

The script performs the following steps:
1.  **Utility Verification**: Validates geometric calculation functions.
2.  **Feature Extraction**: Processes a sample geometry file to verify feature dimensions.
3.  **Dataset Initialization**: Creates PyTorch datasets for training, validation, and testing, managing feature scaling and caching.
4.  **Model Execution**: Instantiates the GPA-WDS model and verifies a forward pass with a data batch.
5.  **Training Loop**: Runs a full training epoch using the `Engine` class.
6.  **Inference**: Generates predictions on the test set and creates a submission CSV.
