Based on the lessons learned from the previous experiments, I propose the **Global-Physics Augmented Wide Deep Sets (GPA-WDS)** strategy.

This strategy structurally evolves the successful "Augmented Point-Cloud Deep Sets" (Idea 4) by refining both the local and global feature engineering. Locally, it improves the geometric resolution by adding a **Local Packing Density** scalar (Mean Neighborhood Distance) to the Nearest Neighbor Distance, adhering to the principle of parsimonious descriptors (Lesson 21). Globally, it injects **Composition-Weighted Physical Properties** to provide a strong inductive bias for the material type, addressing the need for high-level chemical context (Lesson 13) while avoiding the redundancy issues of atomic-level physical features (Lesson 23). Architecturally, it strictly enforces the **Wide MLP**, **Batch Normalization**, and **Dropout** safeguards identified as critical for stability and generalization in Lessons 17, 24, and 36.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Wide Point Processor):**
    *   **Input Features:** For each atom, construct a compact, dense feature vector (9 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains critical node-level spatial variance (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance:** The scalar distance to the closest neighbor, calculated using Periodic Boundary Conditions (PBC) (**Cite Lesson 15**).
        *   **Local Packing Density:** The arithmetic mean of the distances to the $K=12$ nearest neighbors (PBC-corrected). This provides a robust scalar proxy for local steric crowding, distinguishing between tight and loose coordination environments better than the single nearest neighbor distance alone.
    *   **Encoder:** A **Wide MLP** (e.g., 512 hidden units) to project features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation. This is essential to handle the heterogeneous scales of the inputs and prevent overfitting in the wide layers.
    *   **Output:** A **Linear** projection (no activation) to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) to capture both average properties and salient features (**Cite Lesson 5**). Sum pooling is excluded to maintain intensivity (**Cite Lesson 7**).

2.  **Global Stream (Physics-Enhanced Context):**
    *   **Input:** A comprehensive vector of macroscopic properties:
        *   **Geometric:** Lattice vector lengths, lattice angles, unit cell volume.
        *   **Structural:** Atomic density and **Total Number of Atoms** (**Cite Lesson 35**).
        *   **Chemical:** **Explicit Stoichiometry** (composition percentages) (**Cite Lesson 13**).
        *   **Physical (New):** **Composition-Weighted Mean Properties**. Calculate the weighted average of **Atomic Mass**, **Covalent Radius**, and **Electronegativity** for the unit cell (e.g., $\sum P_{elem} \times Mass_{elem}$). While redundant at the atomic level (Lesson 23), these provide a direct, non-linear "chemical manifold" embedding for the global stream, serving as a strong inductive bias for the material class on this small dataset.
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout to model non-linear boundary condition effects (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Calculations:** Compute the pairwise distance matrix using lattice vectors to respect Periodic Boundary Conditions.
    *   **Feature Extraction:** For each atom, extract the minimum non-zero distance (NN Dist) and the mean of the 12 smallest distances (Local Packing Density).
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, and **Total Atoms**.
    *   Calculate Unit Cell Volume and Atomic Density.
    *   **Physics Injection:** Using a lookup table for Al, Ga, In, O, calculate the stoichiometry-weighted mean Mass, Radius, and Electronegativity for each crystal.
    *   **Scaling:** Apply Standard Scaling (z-score) to all continuous features (atomic coords, distances, global features) to ensure balanced gradients.
3.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$) to regularize the wide layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence over a longer schedule (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-Distance calculation, Physics Injection, Scaling).
2.  **Prediction:** Pass the processed data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs to recover the original energy scale.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
