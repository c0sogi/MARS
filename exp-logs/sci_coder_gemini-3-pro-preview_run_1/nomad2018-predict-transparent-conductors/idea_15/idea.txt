Based on the lessons learned from previous experiments, I propose the **Robust Potential-Augmented Wide Deep Sets (RPA-WDS)** strategy.

This strategy is a structural evolution of the successful "Augmented Point-Cloud Deep Sets" (Idea 4). It integrates the physics-inspired "Local Potential Proxy" from Idea 12 and Idea 14, but critically, it corrects the implementation flaws (missing Batch Normalization and System Cardinality) that caused those ideas to fail (referencing **Lesson 36** and **Lesson 35**). It strictly adheres to the architectural safeguards (Wide MLPs, Dropout, Late Fusion) that have proven essential for generalization on this dataset.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Wide Point Processor):**
    *   **Input Features:** For each atom, construct a compact, non-redundant feature vector:
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains critical node-level spatial variance (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance:** The scalar distance to the closest neighbor, capturing immediate steric constraints (**Cite Lesson 15**).
        *   **Local Potential Proxy:** The scalar sum of inverse distances to neighbors ($P_i = \sum_{j \neq i} \frac{1}{d_{ij}}$) calculated using Periodic Boundary Conditions. This adds a robust scalar measure of local atomic density and electrostatic environment, enriching the representation without the dimensionality bloat of vector fingerprints (**Cite Lesson 21**).
    *   **Encoder:** A **Wide MLP** (e.g., 512 hidden units) to project features into a high-dimensional latent space (**Cite Lesson 17**). Crucially, **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (**Cite Lesson 24**) are applied after every activation to handle feature scaling differences and prevent overfitting.
    *   **Output:** A **Linear** projection (no activation) to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) to capture both average properties and salient features (**Cite Lesson 5**). Sum pooling is excluded to maintain intensivity (**Cite Lesson 7**).

2.  **Global Stream (Thermodynamic Context):**
    *   **Input:** Macroscopic features: Lattice vector lengths, lattice angles, unit cell volume, atomic density, **explicit stoichiometry** (**Cite Lesson 13**), and the **Total Number of Atoms** (**Cite Lesson 35**).
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout to model non-linear boundary condition effects (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Calculations:** Compute the pairwise distance matrix using lattice vectors to respect Periodic Boundary Conditions.
    *   **Feature Extraction:** For each atom, extract the minimum non-zero distance (NN Dist) and compute the sum of inverse distances (Potential Proxy).
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, and **Total Atoms**.
    *   Calculate Unit Cell Volume and Atomic Density.
    *   **Scaling:** Apply Standard Scaling (z-score) to all continuous features (atomic coords, distances, potentials, global features).
3.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$) to regularize the wide layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence over a longer schedule (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-Potential calculation, Scaling).
2.  **Prediction:** Pass the processed data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
