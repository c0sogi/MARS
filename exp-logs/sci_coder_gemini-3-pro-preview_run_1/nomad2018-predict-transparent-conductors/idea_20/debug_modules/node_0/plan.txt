The implementation strategy is as follows:

1.  **Setup Demo Environment**: Create a temporary directory structure (`./working/demo_execution`) and generate small subsets (50 for train, 10 for val/test) of the provided metadata CSV files. This ensures the data loading and processing steps run quickly.
2.  **Configure System**: Override the `Config` class parameters to point to these new subset files and reduce hyperparameters like `MAX_EPOCHS` (to 2) and `BATCH_SIZE` (to 4) for speed. Set the cache directory to a demo-specific location.
3.  **Verify Geometry Utilities**: Load a sample geometry file (`train/1/geometry.xyz`), parse it, and verify that the geometric feature calculation functions (volume, density, and the computationally intensive local anisotropy) return arrays of the expected shapes and values.
4.  **Execute Pipeline**:
    *   Initialize the `MaterialsDataset` and `DataLoader` using the subset data.
    *   Instantiate the `LAWDS` model.
    *   Run a short training loop using the provided `train_step` and `validate_step` functions to confirm the loss decreases and is computed correctly.
    *   Run `generate_submission` to produce a prediction file and verify its format against the requirements.
