The implementation strategy involves the following steps:
1.  **Setup & Training**: Initialize the configuration and random seeds. Execute the training pipeline using `library.train.run_training`. This will preprocess data, train the CRN-DS model for 200 epochs (with early stopping), and save the best model checkpoint.
2.  **Validation**: Load the hold-out validation dataset and the trained model. Perform inference to obtain log-scale predictions. Calculate the Column-wise Root Mean Squared Logarithmic Error (RMSLE) by comparing these predictions against the log-transformed ground truth targets. Print the final metric with full precision.
3.  **Failure Analysis**: Compute the mean absolute error (MAE) for each validation sample. Construct a DataFrame of the global input features (lattice parameters, composition, density, etc.) and calculate their Pearson correlation with the error magnitude. Print the top correlated features to identify sources of systematic error.
4.  **Submission**: Compare the calculated validation metric against the threshold (0.05479004207787702). If the metric is lower, invoke `library.inference.generate_submission` to predict on the test set, apply the inverse log transformation, and save the results to `submission.csv`.
