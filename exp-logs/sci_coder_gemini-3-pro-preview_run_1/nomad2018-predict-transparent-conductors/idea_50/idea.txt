Based on the lessons learned from the previous experiments, I propose the **Aligned Multi-Scale Anisotropic Deep Sets (AMSA-DS)** strategy.

This strategy represents a structural evolution of the current state-of-the-art **Anisotropic Multi-Scale Physics-Aware Deep Sets** (Idea 44). While Idea 44 successfully utilized multi-scale *chemical* contexts ($K=6, 24$), its geometric descriptor (Packing Ratio) was fixed at a single scale ($K=12$), creating a misalignment between the chemical and geometric receptive fields. This new strategy resolves that misalignment by introducing **Multi-Scale Packing Ratios**, allowing the model to correlate local structural distortion with chemical composition at the exact same radial scales. Additionally, it enhances the global stream with **Angular Distortion** to better capture lattice shear strain, a feature identified as potentially useful in Idea 46 but failed previously due to the Gated Fusion mechanism (Lesson 103). The architecture strictly enforces the **Selective Scaling**, **Sparse Batching**, and **Wide/Regularized** safeguards identified in Lessons 17, 24, 36, 89, and 94.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Aligned Multi-Scale Processor):**
    *   **Input Features:** For each atom, construct a dense feature vector (18 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims). **[Unscaled]**
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance ($d_{min}$):** The scalar distance to the single closest neighbor (PBC-corrected) (**Cite Lesson 15**).
        *   **Multi-Scale Packing Ratios (New):** Two dimensionless scalars calculated as $R_6 = d_{min} / d_{mean\_6}$ and $R_{24} = d_{min} / d_{mean\_24}$. Here, $d_{mean\_K}$ is the mean distance to the $K$ nearest neighbors. This aligns the geometric distortion signal with the chemical context scales, allowing the model to distinguish, for example, a distorted first coordination shell ($R_6$) from a packed crystal field ($R_{24}$) (**Cite Lesson 82, Lesson 92**).
        *   **Multi-Scale Chemical Contexts:** Two 4-dimensional vectors representing the **Inverse-Distance Weighted Composition** of the **$K=6$** and **$K=24$** nearest neighbors. These capture the chemical identity of the immediate coordination shell and the broader crystal field (**Cite Lesson 92**).
    *   **Encoder:** A **Wide MLP** (e.g., 3 layers of 512 hidden units) to project features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation.
    *   **Output:** A **Linear** projection (no activation) to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) (**Cite Lesson 5**).

2.  **Global Stream (Strain-Aware Context):**
    *   **Input:**
        *   **Standard:** Lattice vector lengths, lattice angles, unit cell volume, atomic density, **explicit stoichiometry** (**Cite Lesson 13**), and **Total Number of Atoms** (**Cite Lesson 35**).
        *   **Lattice Aspect Ratios:** ($a/b, b/c, c/a$) to capture anisotropy (**Cite Lesson 100**).
        *   **Weighted Physics:** Composition-weighted mean Atomic Mass, Covalent Radius, and Electronegativity (**Cite Lesson 29**).
        *   **Angular Distortion (New):** A scalar quantifying lattice shear strain: $\Delta_{ang} = |\alpha - 90| + |\beta - 90| + |\gamma - 90|$. This provides a direct global measure of how far the crystal deviates from an orthogonal system, which often correlates with stability and bandgap (**Cite Idea 46**).
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract unit cell centroid.
    *   **PBC Neighbor Search:** Compute pairwise distances using lattice vectors.
    *   **Feature Extraction:**
        *   Identify neighbors for $K=1, 6, 24$.
        *   Compute $d_{min}$, $d_{mean\_6}$, $d_{mean\_24}$.
        *   Calculate **Packing Ratios** ($R_6, R_{24}$).
        *   Compute **Weighted Context Vectors** for $K=6$ and $K=24$.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, Total Atoms.
    *   Calculate Volume, Density, Aspect Ratios, Weighted Physics.
    *   Calculate **Angular Distortion**.
    *   **Selective Scaling:** Apply Standard Scaling (z-score) **ONLY** to continuous features (coords, distances, ratios, contexts, global features). **Do NOT scale** the Atomic Identity one-hot vectors (**Cite Lesson 94**).
3.  **Batching Strategy:**
    *   Use **Sparse (Flattened) Batching** to preserve Batch Normalization statistics (**Cite Lesson 89**).
4.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables.

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$).
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-MultiScale/Ratio calculation, Selective Scaling).
2.  **Prediction:** Pass the processed data through the trained model using sparse batching.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
