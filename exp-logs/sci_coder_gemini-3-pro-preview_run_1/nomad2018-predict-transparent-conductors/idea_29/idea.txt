Based on the lessons learned from the previous experiments, I propose the **Physics-Informed Global Wide Deep Sets (PIG-WDS)** strategy.

This strategy represents a structural evolution of the successful "Augmented Point-Cloud Deep Sets" (Idea 4). It retains the effective parsimonious local feature set of Idea 4 (avoiding the overfitting/sparsity issues of Ideas 18, 26, 27) but significantly enhances the **Global Stream** by injecting **Composition-Weighted Physical Properties**. This addresses the model's need for high-level chemical context (e.g., "this is a heavy, electronegative crystal") to set accurate energy baselines, which was hinted at in Lesson 13 but not fully exploited. Furthermore, it rigorously enforces the architectural safeguards—**Immediate Expansion**, **Batch Normalization**, and **Dropout**—that were identified as critical for stability in Lessons 6, 24, and 36.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Robust Point Processor):**
    *   **Input Features:** A compact, dense feature vector for each atom:
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains critical node-level spatial variance (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance:** The scalar distance to the closest neighbor, calculated using Periodic Boundary Conditions (PBC). This provides a high-signal steric constraint (**Cite Lesson 15**).
    *   **Encoder:** A **Wide MLP** (e.g., input $\to$ 512 $\to$ 512 $\to$ 512) to project features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation. This ensures the network can handle the heterogeneous scales of the input (one-hot vs. coords) without overfitting.
    *   **Output:** A **Linear** projection to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) to capture both average properties and salient features (**Cite Lesson 5**). Sum pooling is excluded (**Cite Lesson 7**).

2.  **Global Stream (Physics-Enhanced Context):**
    *   **Input:**
        *   **Geometric:** Lattice vector lengths, lattice angles, unit cell volume.
        *   **Structural:** Atomic density, **Total Number of Atoms** (**Cite Lesson 35**).
        *   **Chemical:** **Explicit Stoichiometry** (percentages of Al, Ga, In) (**Cite Lesson 13**).
        *   **Physical (New):** **Composition-Weighted Mean Properties**. Calculate the weighted average of **Atomic Mass**, **Covalent Radius**, and **Electronegativity** for the unit cell (e.g., $Mass_{avg} = \sum_{elem} P_{elem} \times Mass_{elem}$). While Lesson 23 showed these are redundant at the *atomic* level (linear combo of one-hot), they are **not** redundant at the *global* level, as the global branch does not see individual atoms. These features provide a direct "chemical manifold" for the crystal.
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout to model non-linear boundary condition effects (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Calculations:** Compute the pairwise distance matrix using lattice vectors to respect Periodic Boundary Conditions.
    *   **Feature Extraction:** Extract the minimum non-zero distance (NN Dist) for each atom.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, and **Total Atoms**.
    *   Calculate Unit Cell Volume and Atomic Density.
    *   **Physics Injection:** Using a lookup table for Al, Ga, In, O, calculate the stoichiometry-weighted mean Mass, Radius, and Electronegativity for each crystal.
    *   **Scaling:** Apply Standard Scaling (z-score) to all continuous features.
3.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$) to regularize the wide layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The robust architecture allows for stable convergence.

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-NN calculation, Physics Injection, Scaling).
2.  **Prediction:** Pass the processed data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
