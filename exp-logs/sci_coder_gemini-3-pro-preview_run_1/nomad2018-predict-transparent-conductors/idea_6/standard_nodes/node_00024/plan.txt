To optimize the performance of the PA-DSDS model, I will implement changes based on **Lesson 21** (Parsimony in Point-Wise Descriptors) and **Lesson 23** (Avoid Redundant Feature Engineering).

**Strategy:**
1.  **Refine Atomic Features (Lesson 23):** I will remove the explicit physical constants (atomic mass, radius, electronegativity) from the atomic input features. As established in Lesson 23, these are linear transformations of the one-hot encoding and add no expressive power to the first linear layer of the network, serving only to increase dimensionality and potential noise.
2.  **Simplify Geometric Descriptors (Lesson 21):** I will modify the local fingerprint generation to compute only the **nearest-neighbor distance** (`d_min`), discarding the mean and standard deviation of neighbor distances. Lesson 21 demonstrated that a single high-signal scalar proxy is superior to higher-dimensional raw descriptors for this task on small datasets.
3.  **Force Cache Refresh:** I will update the cache directory in `library/features.py` to ensure the new feature set is computed and used, rather than loading the previous (suboptimal) features.

These changes reduce the atomic input dimensionality from 13 to 8 (4 one-hot + 3 coords + 1 d_min), focusing the model on the most critical signals.
