Based on the comprehensive analysis of previous experiments and the extracted lessons, I propose the **Bond-Aware Anisotropic Deep Sets (BA-ADS)** strategy.

This strategy represents a structural synthesis of the current state-of-the-art **Anisotropic Multi-Scale Physics-Aware Deep Sets** (Idea 44) and the chemically-explicit concepts from **Idea 27**. It addresses the "Interaction Resolution" limit of Idea 44—which captures the *average* chemical environment via context vectors but smears out specific bond constraints—by injecting **Chemically-Resolved Reciprocal Proximities**. This allows the model to explicitly distinguish between specific bonding pairs (e.g., a short Ga-O bond vs. a short Al-O bond) while maintaining the robust environmental descriptors. Additionally, it enhances the Global Stream with **Physical Property Variance** to capture compositional disorder. The architecture strictly enforces the **Selective Scaling**, **Sparse Batching**, and **Wide/Regularized** safeguards identified in Lessons 17, 24, 36, 89, and 94.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Bond-Aware Point Processor):**
    *   **Input Features:** For each atom, construct a dense, high-fidelity feature vector (21 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims). **[Unscaled]**
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance ($d_{min}$):** The scalar distance to the single closest neighbor (PBC-corrected) (**Cite Lesson 15**).
        *   **Local Packing Ratio:** The dimensionless ratio $R = d_{min} / d_{mean\_12}$ (**Cite Lesson 82**).
        *   **Multi-Scale Chemical Contexts:** Two 4-dimensional vectors representing the **Normalized Inverse-Distance Weighted Composition** of the **$K=6$** and **$K=24$** nearest neighbors. These capture the "smeared" chemical environment at short and medium ranges (**Cite Lesson 92**).
        *   **Chemically-Resolved Reciprocal Proximity (New):** A 4-dimensional vector $[p_{Al}, p_{Ga}, p_{In}, p_{O}]$. Each component is $p_T = 1.0 / d_{min\_T}$, where $d_{min\_T}$ is the distance to the *nearest* atom of type $T$. If type $T$ is absent, $p_T = 0$. Unlike the Context vectors (which sum to 1), these features preserve the *magnitude* of the strongest interaction with each species, acting as explicit "bond detectors" without the sparsity issues of split distances (**Cite Lesson 27, Lesson 58**).
    *   **Encoder:** A **Wide MLP** (e.g., 3 layers of 512 hidden units) to project features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation.
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) (**Cite Lesson 5**).

2.  **Global Stream (Disorder-Aware Context):**
    *   **Input:**
        *   **Geometric:** Lattice vector lengths, lattice angles, unit cell volume, **Lattice Aspect Ratios** (anisotropy) (**Cite Lesson 100**).
        *   **Structural:** Atomic density, **Total Number of Atoms** (**Cite Lesson 35**).
        *   **Chemical:** **Explicit Stoichiometry** (percentages) (**Cite Lesson 13**).
        *   **Physical Means:** Composition-weighted average of Atomic Mass, Covalent Radius, and Electronegativity (**Cite Lesson 29**).
        *   **Physical Variances (New):** The **Standard Deviation** of Atomic Mass, Radius, and Electronegativity across the unit cell's composition. This explicitly encodes **chemical disorder** (e.g., size mismatch strain in alloys), which is a key driver of formation energy distinct from the mean properties.
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract unit cell centroid.
    *   **PBC Neighbor Search:** Compute pairwise distances using lattice vectors.
    *   **Feature Extraction:**
        *   Compute $d_{min}$, Packing Ratio ($d_{min}/d_{mean\_12}$).
        *   Compute **Weighted Context Vectors** (Normalized sums for $K=6, 24$).
        *   Compute **Reciprocal Proximity Vector**: For each atom, find min dist to Al, Ga, In, O separately. Take reciprocal.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, Total Atoms.
    *   Calculate Volume, Density, Aspect Ratios.
    *   **Physics Injection:** Calculate **Mean** and **Std Dev** of physical properties based on stoichiometry.
    *   **Selective Scaling:** Apply Standard Scaling (z-score) **ONLY** to continuous features (coords, distances, ratios, contexts, proximities, global features). **Do NOT scale** the Atomic Identity one-hot vectors (**Cite Lesson 94**).
3.  **Batching:**
    *   Use **Sparse (Flattened) Batching** to preserve Batch Normalization statistics (**Cite Lesson 89**).
4.  **Target Transformation:**
    *   Apply `log(1+y)` to targets.

### Training
*   **Loss Function:** Mean Squared Error (MSE) on log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$).
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process test set with the identical pipeline.
2.  **Prediction:** Pass data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1`.
4.  **Submission:** Format as `id,formation_energy_ev_natom,bandgap_energy_ev`.
