Based on the lessons learned from the previous experiments, I propose the **Global-Bonding Augmented Multi-Scale Deep Sets (GBA-MS-DS)** strategy.

This strategy represents a structural evolution of the current state-of-the-art **Anisotropic Multi-Scale Physics-Aware Deep Sets** (Idea 44). It retains the highly effective local feature engineering (Multi-Scale Contexts, Packing Ratio) and architectural safeguards (Wide MLPs, Selective Scaling) of the baseline. The key innovation is the injection of **Global Bond Statistics** into the global stream. Unlike "Physical Variance" (which failed in Idea 45 because it is mathematically redundant with stoichiometry), Global Bond Statistics are derived from the *actual 3D geometry*, providing the model with an explicit summary of the crystal's bonding state (e.g., average Al-O bond length) and clustering tendencies, which acts as a strong inductive bias for formation energy.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Distortion-Aware Point Processor):**
    *   **Input Features:** For each atom, construct a dense feature vector (17 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims). **[Unscaled]**
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance:** The scalar distance to the single closest neighbor (PBC-corrected) (**Cite Lesson 15**).
        *   **Local Packing Ratio:** The dimensionless ratio $R = d_{min} / d_{mean\_12}$, capturing local structural distortion (**Cite Lesson 82**).
        *   **Multi-Scale Chemical Contexts:** Two 4-dimensional vectors representing the **Inverse-Distance Weighted Composition** of the **$K=6$** and **$K=24$** nearest neighbors. These capture the chemical identity of the coordination shell and crystal field (**Cite Lesson 92**).
    *   **Encoder:** A **Wide MLP** (e.g., 3 layers of 512 hidden units) to project features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation.
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) (**Cite Lesson 5**).

2.  **Global Stream (Bonding-Enhanced Context):**
    *   **Input:**
        *   **Standard:** Lattice vector lengths, lattice angles, unit cell volume, atomic density, **explicit stoichiometry** (**Cite Lesson 13**), and **Total Number of Atoms** (**Cite Lesson 35**).
        *   **Lattice Aspect Ratios:** ($a/b, b/c, c/a$) to capture anisotropy (**Cite Lesson 100**).
        *   **Weighted Physics:** Composition-weighted mean Mass, Radius, and Electronegativity (**Cite Lesson 29**).
        *   **Global Bond Statistics (New):** A 10-dimensional vector containing the **Mean Pairwise Distance** for every possible element pair (Al-Al, Al-Ga, ..., O-O) within the unit cell.
            *   For each pair type, compute the average PBC-corrected distance between all atoms of those types.
            *   If a pair type is absent, use 0.0.
            *   This provides a macroscopic "fingerprint" of the crystal's bonding state (e.g., expanded vs. compressed bonds) and segregation (clustering), which provides orthogonal information to the stoichiometry and local features (**Cite Idea 38**).
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract unit cell centroid.
    *   **PBC Calculations:** Compute the full pairwise distance matrix using lattice vectors.
    *   **Feature Extraction:**
        *   **Local:** Compute $d_{min}$, Packing Ratio, and Weighted Context Vectors ($K=6, 24$).
        *   **Global:** Iterate through the distance matrix to compute the mean distance for each of the 10 unique element pairs.
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, Total Atoms.
    *   Calculate Volume, Density, Aspect Ratios, Weighted Physics.
    *   **Selective Scaling:** Apply Standard Scaling (z-score) **ONLY** to continuous features (coords, distances, ratios, contexts, global features). **Do NOT scale** the Atomic Identity one-hot vectors (**Cite Lesson 94**).
3.  **Batching Strategy:**
    *   Use **Sparse (Flattened) Batching** to preserve Batch Normalization statistics (**Cite Lesson 89**).
4.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables.

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$).
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-MultiScale/Bond-Stats calculation, Selective Scaling).
2.  **Prediction:** Pass the processed data through the trained model using sparse batching.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
