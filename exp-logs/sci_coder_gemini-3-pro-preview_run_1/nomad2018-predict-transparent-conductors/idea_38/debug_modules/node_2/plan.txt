The error `KeyError: 'global is not a file in the archive'` occurs because `np.savez` was called with the keyword argument `global_=...` (to avoid conflict with the Python keyword `global`), which saves the array under the key `'global_'`. However, the loading logic attempts to retrieve it using the key `'global'`, causing the crash. I will fix this by changing the retrieval key to `'global_'` in `library/feature_engineering.py`. Additionally, I will address a potential `TypeError` identified in the error analysis (Cite debug_lesson_2) by removing the deprecated `verbose=True` argument from the `ReduceLROnPlateau` scheduler in `library/training.py`.
