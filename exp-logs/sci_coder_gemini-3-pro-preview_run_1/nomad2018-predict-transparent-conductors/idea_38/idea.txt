Based on the analysis of the previous experiments and the extracted lessons, I propose the **Structural-Statistics Augmented Wide Deep Sets (SSA-WDS)** strategy.

This strategy represents a structural evolution of the successful "Augmented Point-Cloud Deep Sets" (Idea 4). It retains the robust, parsimonious local feature engineering of the baseline (Lesson 21, Lesson 77) but significantly enhances the **Global Stream** by injecting **Global Structural Statistics**. Specifically, it calculates the **Mean Pairwise Distances** for all element pairs (e.g., mean Al-Al distance, mean Al-O distance) within the unit cell. This provides the model with explicit descriptors of **atomic clustering** (homo-atomic distances) and **average bond lengths** (hetero-atomic distances), acting as a strong inductive bias for the crystal's thermodynamic state (e.g., compression, phase segregation) without the noise of atomic-level physical constants (Lesson 23) or the sparsity of local chemical fingerprints (Lesson 58). The architecture strictly enforces the **Wide MLP**, **Batch Normalization**, and **Dropout** safeguards identified as critical in Lessons 17, 24, and 36.

### Model
The architecture consists of two parallel processing streams that merge via Late Fusion:

1.  **Atomic Stream (Robust Point Processor):**
    *   **Input Features:** A compact, dense feature vector for each atom (8 dimensions):
        *   **Atomic Identity:** One-hot encoding (Al, Ga, In, O) (4 dims).
        *   **Spatial Context:** Centered Cartesian coordinates $(x, y, z)$ relative to the unit cell centroid. This retains critical node-level spatial variance (**Cite Lesson 10**).
        *   **Nearest Neighbor Distance:** The scalar distance to the single closest neighbor, calculated using Periodic Boundary Conditions (PBC). This serves as a high-signal proxy for immediate steric constraints (**Cite Lesson 15**).
    *   **Encoder:** A **Wide MLP** (e.g., 512 hidden units) to project features into a high-dimensional latent space via **Immediate Expansion** (**Cite Lesson 6**).
    *   **Regularization:** **Batch Normalization** (**Cite Lesson 36**) and **Dropout** (e.g., 0.1) (**Cite Lesson 24**) are applied after every ReLU activation. This handles the heterogeneous input scales and prevents overfitting.
    *   **Output:** A **Linear** projection (no activation) to the final embedding space (**Cite Lesson 18**).
    *   **Aggregation:** **Dual Pooling** (concatenation of Global Mean and Global Max) to capture both average properties and salient features (**Cite Lesson 5**). Sum pooling is excluded (**Cite Lesson 7**).

2.  **Global Stream (Structurally-Enhanced Context):**
    *   **Input:**
        *   **Macroscopic:** Lattice vector lengths, lattice angles, unit cell volume.
        *   **System:** Atomic density and **Total Number of Atoms** (**Cite Lesson 35**).
        *   **Composition:** **Explicit Stoichiometry** (percentages) (**Cite Lesson 13**).
        *   **Structural Statistics (New):** A vector containing the **Mean Pairwise Distance (PBC-corrected)** for every possible pair of elements present in the dataset (Al-Al, Al-Ga, ..., O-O).
            *   For each pair type (e.g., Al-O), compute the average distance between all Al and O atoms in the unit cell.
            *   If a pair type does not exist in the crystal (e.g., no In atoms), the value is set to 0.
            *   This captures global structural trends like **clustering** (short homo-atomic distances) and **lattice strain** (variations in hetero-atomic bond lengths) that are difficult to infer from local features alone.
    *   **Encoder:** A **High-Capacity MLP** (e.g., 256 units) with Batch Normalization and Dropout to model non-linear boundary condition effects (**Cite Lesson 9**).

3.  **Fusion Head:**
    *   **Late Fusion:** Concatenate the aggregated atomic embedding and the global embedding (**Cite Lesson 19**).
    *   **Regressor:** A final MLP predicts `formation_energy_ev_natom` and `bandgap_energy_ev`.

### Data
1.  **Geometry Preprocessing:**
    *   Parse `geometry.xyz` files.
    *   **Centering:** Subtract the unit cell centroid from all atomic coordinates.
    *   **PBC Calculations:** Compute the full pairwise distance matrix using lattice vectors to respect Periodic Boundary Conditions.
    *   **Feature Extraction:**
        *   **Atomic:** Extract the minimum non-zero distance (NN Dist) for each atom.
        *   **Global:** Iterate through all unique pairs of atoms in the cell. Accumulate distances by element-pair type (e.g., Al-Al, Al-O). Compute the mean for each type. Construct a fixed-size vector for all 10 possible pairs (4 elements choose 2 + 4 self-pairs).
2.  **Tabular Preprocessing:**
    *   Extract lattice parameters, stoichiometry, and **Total Atoms**.
    *   Calculate Unit Cell Volume and Atomic Density.
    *   **Scaling:** Apply Standard Scaling (z-score) to all continuous features (atomic coords, NN dist, global structural stats, lattice features).
3.  **Target Transformation:**
    *   Apply `log(1+y)` to both target variables to align the training objective (MSE) with the evaluation metric (RMSLE).

### Training
*   **Loss Function:** Mean Squared Error (MSE) on the log-transformed targets.
*   **Optimizer:** AdamW with weight decay ($1e-4$) to regularize the wide layers.
*   **Scheduler:** `ReduceLROnPlateau` monitoring validation loss.
*   **Strategy:** Train for **200 epochs** with early stopping (patience ~20 epochs). The wide, regularized architecture allows for stable convergence over a longer schedule (**Cite Lesson 17**).

### Evaluation
1.  **Inference:** Process the test set using the identical pipeline (Centering, PBC-Distance calculations, Scaling).
2.  **Prediction:** Pass the processed data through the trained model.
3.  **Inverse Transformation:** Apply `exp(x) - 1` to the model outputs to recover the original energy scale.
4.  **Submission:** Format the results as `id,formation_energy_ev_natom,bandgap_energy_ev`.
