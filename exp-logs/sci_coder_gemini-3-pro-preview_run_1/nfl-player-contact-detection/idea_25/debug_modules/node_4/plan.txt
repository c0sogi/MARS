The issue is a **Label Type Mismatch** caused by using strict Classifiers (`LGBMClassifier`, `XGBClassifier`) with continuous soft labels generated by the label smoothing process. Scikit-learn compatible classifiers enforce discrete target values, raising a `ValueError` when encountering continuous data.

To fix this, I will switch the model instantiations in `ModelFactory` to their Regressor counterparts (`LGBMRegressor`, `XGBRegressor`). These models support continuous targets while maintaining the binary classification objective (log-loss) configured in the parameters. I will also update `TriEnsemble.predict_proba` to handle the 1D probability arrays returned by the regressors and manually construct the expected 2D probability matrix `[1-p, p]`. This aligns with **Lesson 29** (Cite debug_lesson_29).
