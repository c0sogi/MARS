The following script demonstrates the usage of the provided machine learning pipeline for the NFL Contact Detection task. It validates the data loading, feature engineering, model training, and inference components.

The strategy is as follows:
1.  **Data Factory Verification**: We instantiate the `DataFactory` to load a small sample of the training data and generate features. We assert that the resulting DataFrame contains the expected kinematic features (e.g., neighbors, distance) and target variables.
2.  **Model Factory Verification**: We manually train the `LGBMWrapper` and `XGBWrapper` on this small dataset with reduced estimators to verify the training API, prediction shape, and model persistence (save/load).
3.  **Training Pipeline Integration**: We execute the `TrainingPipeline` in `debug` mode. This runs the full "Scout -> Mining -> Expert" curriculum on a subset of data (5000 rows), optimizing the threshold and saving artifacts.
4.  **Inference Logic Verification**: Finally, we use the `EnsemblePredictor` to load the models generated by the pipeline and perform inference on a sample set, verifying the ensemble logic.
