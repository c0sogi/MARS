The following script demonstrates the complete workflow of the Iterative Hard-Negative Mining Ensemble (IHNME) solution. It performs the following steps:

1.  **Configuration Overrides**: Modifies the global `Config` to use a temporary working directory and reduces model hyperparameters (e.g., `n_estimators=10`) to ensure the demonstration runs quickly.
2.  **Mini-Dataset Creation**: Samples a small subset of the provided training and test data (based on specific `game_play` IDs) to create lightweight metadata and tracking files. This ensures the feature engineering and training steps complete in seconds rather than hours.
3.  **Pipeline Execution**: Instantiates and runs the `IHNMEPipeline`. This automatically handles:
    *   Feature Engineering (Kinematics, Context, Physics derivatives).
    *   Phase 1: Scout Model Training (LightGBM).
    *   Phase 2: Hard Negative Mining.
    *   Phase 3: Expert Model Training (LightGBM + XGBoost Ensemble).
    *   Threshold Optimization.
    *   Inference and Submission generation.
4.  **Validation**: Assertions verify that the submission file is created correctly and contains the expected prediction format.
