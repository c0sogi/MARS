Based on the trajectory of the provided lessons—specifically the validation of **Kinematic Reachability Gating** (Cite solution_lesson_node_00039), the success of **Dual-Scout Mining** (Cite solution_lesson_node_00039), and the dominance of **Primary Interaction Physics** (Cite solution_lesson_node_00036)—I propose the **Quadratic-Gated Spectral-Kinematic Ensemble (QGS-KE)**.

This strategy introduces two Structural Innovations: **Quadratic Reachability Gating** (to capture accelerating impacts like dives) and **Transient Spectral Feature Engineering** (to explicitly quantify impact shockwaves). These are integrated into a **Tri-Model Expert Ensemble** to maximize algorithmic diversity.

### 1. Model
The architecture employs a **Unified Heterogeneous Tri-Ensemble** designed for maximum decision boundary diversity and capacity.

*   **Unified Backbone:** We utilize a single modeling framework for both Player-Player and Player-Ground contacts. We explicitly retain the **Sentinel Value Strategy** (Cite solution_lesson_node_00035), setting the `distance` feature for Ground interactions to `-1.0`. This allows the trees to isolate distinct modalities via root splits while leveraging the shared non-contact majority class for stability (Cite solution_lesson_node_00007).
*   **Tri-Model Expert Tier:** The final predictor expands the previous ensemble to three distinct Gradient Boosting implementations:
    1.  **LightGBM:** Leaf-wise growth (Best for dense numerical data).
    2.  **XGBoost:** Level-wise growth (Best for approximate splits).
    3.  **CatBoost:** Oblivious/Symmetric trees (Best for native categorical handling and reducing overfitting).
    *   *Rationale:* Adding CatBoost introduces a third structural bias, maximizing the ensemble's ability to resolve the "Hard Negatives" mined by the Scouts.
*   **High-Capacity Configuration:** All models are configured with deep trees (e.g., `num_leaves=256`, `max_depth=10`) to maximize information density (Cite solution_lesson_node_00003).

### 2. Data
The data pipeline implements **Quadratic Reachability Gating** to enable the computation of computationally intensive **Spectral Features** for the entire plausible search space.

*   **Stage 0: Quadratic Reachability Gating (Structural Innovation)**
    *   **Logic:** Instead of Linear Time-To-Collision (Cite solution_lesson_node_00039), we model the relative distance as a quadratic function of time: $d(t) = d_0 + v_{rel}t + 0.5 a_{rel}t^2$.
    *   **Filter:** We solve for the minimum distance in the window $t \in [0, 1.0s]$. If $\min(d(t)) < 1.0$ yard, the pair is retained.
    *   *Rationale:* This captures high-acceleration events (e.g., diving tackles, sudden stops) that linear extrapolation misses, reducing false negatives in the gating phase.

*   **Stage 1: Spectral-Kinematic Feature Engineering (Structural Innovation)**
    *   **Flattened Windows:** Retain +/- 10 step (1.0s) windows for relative kinematics (Cite solution_lesson_node_00001).
    *   **Transient Spectral Energy:** We decompose the relative acceleration profile of the window into "Trend" (Low-Frequency) and "Shock" (High-Frequency) components using a discrete high-pass filter (e.g., difference of Gaussians). We compute the **Energy (RMS)** of the high-frequency component.
        *   *Rationale:* Ground contacts and hard tackles are characterized by high-frequency "impulses" (shocks) that are distinct from smooth running. This extends the "Jerk" insight (Cite solution_lesson_node_00012) into a robust signal processing feature.
    *   **Primary Physics Primitives:** Retain **Kinetic Energy** ($v^2$) and **Sentinel-Aware Distance** (Cite solution_lesson_node_00035).
    *   **Context Exclusion:** Strictly exclude 3rd-party/environmental context to prevent signal dilution (Cite solution_lesson_node_00036).
    *   **Invariance:** Strictly exclude absolute coordinates (Cite solution_lesson_node_00024).

*   **Caching:** Enforce **parameter-aware caching** (Cite solution_lesson_node_00002).

### 3. Training
The training process executes a **Dual-Scout Diversity Mining Curriculum** to ensure the Expert learns from the hardest examples.

*   **Phase 1: Dual-Scout Training**
    *   Construct a balanced dataset from the **Quadratic Gated Survivors** (All Positives + Equal Random Negatives).
    *   Train **Scout A (LightGBM)** and **Scout B (XGBoost)** on this set using the **Full Spectral Feature Set**.
    *   *Constraint:* Scouts must see the exact same features as the Expert to prevent "Semantic Gaps" (Cite solution_lesson_node_00022).

*   **Phase 2: Diversity Mining**
    *   Run *both* Scouts on the **Entire Gated Survivor Pool**.
    *   Select **Hard Negatives**: Instances where $P(Contact) > 0.05$ from **either** Scout (Union).
    *   *Rationale:* Mining the union of errors from different architectures maximizes the capture of edge cases (Cite solution_lesson_node_00021, solution_lesson_node_00039).

*   **Phase 3: Expert Training**
    *   Construct the **Expert Dataset**: All Positives + The Union of Mined Hard Negatives + Small Buffer of Random Gated Negatives.
    *   Train the **Tri-Model Expert Ensemble** (LGBM + XGB + CatBoost) on this high-information-density dataset.
    *   **Imbalance Handling:** Use `is_unbalance=True` (LGBM), `scale_pos_weight` (XGB), and `auto_class_weights` (CatBoost) (Cite solution_lesson_node_00011).

### 4. Evaluation
1.  **Feature Generation:** Generate the **Full Spectral Feature Set** for the **Entire Test Set**. (Test set size allows full computation without gating).
2.  **Inference:** Run the **Tri-Model Expert Ensemble** on the test features.
3.  **Ensembling:** Compute the unweighted average of the probability outputs.
4.  **Thresholding:** Apply the decision threshold optimized on the validation set (maximizing MCC) to generate the final submission.
