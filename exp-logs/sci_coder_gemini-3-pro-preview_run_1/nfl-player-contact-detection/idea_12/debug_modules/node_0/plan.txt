This script demonstrates the end-to-end pipeline for the NFL Contact Detection task using the provided library files. It performs the following steps:

1.  **Configuration**: Loads and updates the training configuration to "Debug Mode" (reduced epochs, fewer trees) to ensure the script completes quickly within the time limit.
2.  **Feature Engineering**: Generates training, validation, and test datasets. It uses a sampled subset for training/validation (via `debug=True`) but processes the full test set as required for submission.
3.  **Curriculum Training**: Executes the `train_with_mining_curriculum` strategy, which trains a "Scout" model to mine hard negatives, followed by "Expert" models (LightGBM and XGBoost) trained on the refined dataset.
4.  **Inference**: Uses the trained ensemble to predict contact probabilities on the test set and applies the optimal threshold derived from the validation phase.
5.  **Submission**: Formats the predictions into the required CSV format, ensuring alignment with `sample_submission.csv`.
6.  **Verification**: Validates the output file structure and basic metric calculation logic.
