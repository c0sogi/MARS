The implementation strategy follows the Dual-Basis Vector-Spectral Anchored-Mining Ensemble (DB-VSAM) design. We first configure the environment for a fast baseline execution by overriding the default boosting rounds in the `Config` to 500 and reducing early stopping patience. The `TrainingManager` orchestrates the three-phase curriculum: (1) training diverse "Scout" models on balanced data, (2) mining "Hard Negatives" (high-confidence errors) from the full training set, and (3) training the "Expert" ensemble on an anchored dataset comprising positives, hard negatives, and random anchors with temporal label smoothing.

After training, we perform a rigorous validation on the hold-out set. We compute the Matthews Correlation Coefficient (MCC) and print it as required. We then conduct failure analysis by calculating the correlation between the model's error magnitude and the input features to identify systematic weaknesses. Finally, conditional on the validation performance exceeding the specified threshold (0.6865), we generate the submission file for the test set.
