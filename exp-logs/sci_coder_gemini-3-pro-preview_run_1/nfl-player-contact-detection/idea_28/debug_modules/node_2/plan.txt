The issue is that the installed version of XGBoost (3.0.5) no longer accepts `early_stopping_rounds` as an argument to the `.fit()` method; instead, it must be passed to the `XGBClassifier` constructor (`__init__`). To fix this, I will modify `library/model_factory.py` to inject `early_stopping_rounds` into the initialization parameters for the XGBoost model and remove it from the `fit_params` dictionary in the `fit` method. This aligns with the guidance in **Cite debug_lesson_7**.
