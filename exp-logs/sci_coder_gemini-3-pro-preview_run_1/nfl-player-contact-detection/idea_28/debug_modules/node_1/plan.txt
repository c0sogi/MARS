The issue is a "double join" of the directory path, causing an `OSError`. The function `get_cache_path` returns a full path (including `Config.WORKING_DIR`), but the consumer functions (`save_to_parquet`, `check_cache_exists`, etc.) also prepend `Config.WORKING_DIR` to their input argument. This redundancy results in a malformed path like `working/dir/working/dir/file.parquet`.

To fix this, I will modify `get_cache_path` in `library/utils.py` to return only the relative filename. This delegates the responsibility of resolving the full path to the specific I/O functions that are already configured to handle it, ensuring the directory path is applied exactly once.
