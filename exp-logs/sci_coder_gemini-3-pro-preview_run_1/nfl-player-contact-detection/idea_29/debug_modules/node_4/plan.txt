The error `ValueError: Unknown label type: continuous` occurs because the `LGBMClassifier` is being trained on soft labels (continuous probabilities) generated by the label smoothing process, but Scikit-Learn compatible classifiers strictly enforce discrete class labels. To resolve this, I will replace `LGBMClassifier` with `LGBMRegressor` in `library/models.py`, as regressors can handle continuous targets while still optimizing the binary objective (Cite debug_lesson_30). I will also update the `predict_proba` and `_print_metrics` methods to accommodate the API difference, as `LGBMRegressor` returns predictions directly via `predict()` rather than `predict_proba()`.
