The issue is that `LGBMClassifier` and `XGBClassifier` strictly enforce discrete class labels and reject the continuous (soft) targets generated by the label smoothing process in the pipeline. To resolve this, I will switch to using `LGBMRegressor` and `XGBRegressor` configured with binary objectives, which support continuous targets while optimizing the same log-loss metric (Cite debug_lesson_29). I will also update the `BaseWrapper` to manually construct the `(N, 2)` probability arrays and binary predictions from the 1D regression outputs, as regressors lack a native `predict_proba` method. Furthermore, I will modify `XGBWrapper` to set `early_stopping_rounds` via `set_params` instead of passing it to `fit`, ensuring compatibility with recent XGBoost versions (Cite debug_lesson_7).
