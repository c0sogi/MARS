The issue is an argument collision where `n_estimators` is passed to the model constructors both explicitly (as a keyword argument) and implicitly (via the `**self.params` dictionary unpacking), causing a `TypeError`. This occurs because the configuration dictionary `config.LGBM_PARAMS` (and `XGB_PARAMS`) was modified in `runfile.py` to include `n_estimators`, which is then duplicated during instantiation.

To fix this, I will modify `library/models.py` to explicitly remove (pop) the colliding arguments (`n_estimators` for both, and `early_stopping_rounds` for XGBoost) from the parameter dictionaries before passing them to the model constructors. This ensures that the wrapper configuration is isolated from the forwarded arguments, applying the principle from **debug_lesson_10**.
