Implementation Strategy:
1.  **Configuration & Setup**: Initialize random seeds for reproducibility. Detect GPU availability and dynamically patch the `LGBM_PARAMS` and `XGB_PARAMS` in the `config` module to enable GPU acceleration if available. Additionally, reduce `n_estimators` to 200 to ensure the training completes within the "Fast Baseline" time limit.
2.  **Data Loading & Preprocessing**: Load the full training and validation datasets using `DataLoader`. To adhere to the time constraints, downsample the training dataset to approximately 100,000 rows, ensuring all positive contact samples are retained while downsampling the negative class.
3.  **Model Training (KAM-AE Pipeline)**:
    *   **Scouts**: Train the LightGBM and XGBoost Scout models on the sampled training set.
    *   **Mining**: Mine hard negative examples from the sampled training set using the trained Scouts.
    *   **Experts**: Train the final Expert models on a dataset constructed from Positives, Mined Hard Negatives, and Random Anchors.
4.  **Evaluation**: Generate predictions for the full validation set using the trained Expert ensemble. Optimize the decision threshold to maximize the Matthews Correlation Coefficient (MCC). Print the result in the required format `Final Validation Metric: <value>` and save the threshold for the inference phase.
5.  **Failure Analysis**: Calculate the absolute error of predictions on the validation set. Compute and print the correlation between this error magnitude and the input features to identify systematic failure modes.
6.  **Inference**: Check if the validation MCC exceeds the threshold of 0.6865. If satisfied, execute the `InferencePipeline` to generate the final `submission.csv`.
