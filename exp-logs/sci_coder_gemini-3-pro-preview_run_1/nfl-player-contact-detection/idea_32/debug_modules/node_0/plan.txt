The following code demonstrates the complete workflow of the provided machine learning pipeline. It defines a `FastConfig` class to override hyperparameters for rapid execution (reducing the number of estimators and using a small data subset). It then systematically instantiates and verifies the core components:
1.  **Feature Engineering**: Generates time-domain features from tracking data.
2.  **Data Pipeline**: Constructs balanced datasets for "Scout" models.
3.  **Model Training**: Trains a heterogeneous ensemble (LightGBM, XGBoost) on the scout dataset.
4.  **Mining**: Identifies "Hard Negatives" (negatives confused as positives) using the trained scouts.
5.  **Full Pipeline Execution**: Runs the `TrainingPipeline` to train "Expert" models on the mined data, optimize thresholds, and generate a submission.

Validation checks are included at each step to ensure data shapes, class balances, and file outputs are correct.
