The error `ValueError: Input data must be 2 dimensional and non empty` is caused by the naive data subsampling strategy (`head(N)`) used in `DEBUG` mode. Because the dataset is highly imbalanced, the first N rows often contain zero positive contact examples. When the downstream `build_scout_dataset` function attempts to create a balanced dataset (1:1 ratio), it finds zero positives and thus samples zero negatives, resulting in an empty DataFrame passed to the model.

To fix this, I will modify `library/feature_engineering.py` to implement stratified sampling when `DEBUG` mode is active. This ensures that if positive labels are present (as in training/validation data), a sufficient number of them are included in the debug sample to allow for valid model training.
