Implementation strategy:
The script orchestrates the Dual-Scout Physics-Enhanced Mining Ensemble (DSP-EME) workflow. It initializes the `TrainingPipeline` and `DataLoader` from the provided libraries. To ensure the process completes within the 2-hour limit while maintaining high performance, the training data is loaded with a 50% sample fraction (`sample_fraction=0.5`). Feature loading utilizes caching (`load_cached=True`) for speed, but hard negative mining explicitly disables caching (`load_cached=False`) to prevent index mismatches caused by the data sampling. The script sequentially trains the heterogeneous Scout models (LightGBM and XGBoost), mines hard negatives, and trains the Expert ensemble. It then evaluates the Expert ensemble on the hold-out validation set to compute the Matthews Correlation Coefficient (MCC), printing it in the required format. Failure analysis is performed by calculating the correlation between the model's error magnitude and input features on the validation set. Finally, if the validation MCC exceeds the threshold of 0.6782, the script generates the submission file using the trained experts.
