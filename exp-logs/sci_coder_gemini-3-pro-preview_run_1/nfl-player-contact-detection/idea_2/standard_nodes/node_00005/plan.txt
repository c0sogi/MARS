To optimize the solution, I will implement the following changes based on the provided lessons and analysis:

1.  **Enhance Feature Engineering**:
    *   **Angular Differences**: I will add `dir_diff` (difference in movement direction) and `orient_diff` (difference in body orientation) to the derived features. These angular features help distinguish between players running alongside each other versus converging for a tackle, providing critical context missing from simple distance/speed metrics.
    *   **Improved Ground Handling**: Instead of setting Player 2's tracking features to `0.0` when the contact is with the "Ground", I will set them to `NaN`. This allows the LightGBM model to treat "Ground" as a distinct missing value category rather than conflating it with a player having zero speed or acceleration.

2.  **Maximize Information Density (Cite solution_lesson_node_00003)**:
    *   **Increase Model Capacity**: I will increase `num_leaves` from 63 to 128. The previous model stopped early (iteration 18), suggesting it exhausted the learning potential of the simpler trees too quickly. Deeper trees will allow the model to capture more complex interactions in the early boosting rounds.
    *   **Full Dataset Training**: I will remove the data subsampling (previously capped at 2M rows) to use the full ~3.4M training rows. This ensures the greedy split decisions in the early trees are based on the most representative population possible.
