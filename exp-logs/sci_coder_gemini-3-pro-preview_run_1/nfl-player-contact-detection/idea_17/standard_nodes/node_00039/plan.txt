Implementation strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided modules (`library.*`). Set random seeds for reproducibility. Override `Config.N_ESTIMATORS` to a lower value (e.g., 800) to ensure the training completes within the "Fast Baseline" time limit. Enable GPU parameters for XGBoost and LightGBM if possible to optimize speed.
2.  **Data Loading & Mining**: Initialize `DataManager` and `MiningStrategy`. Load the gated training features. Execute the mining strategy to train "Scout" models and identify "Hard Negative" indices from the training set.
3.  **Expert Training**: Construct the "Expert" dataset using the hard negatives, positives, and a random buffer. Train the Expert LightGBM and Expert XGBoost models on this enriched dataset. Use a split of the expert dataset for internal early stopping.
4.  **Full Validation**: To compute the required `Final Validation Metric` on the *entire* hold-out set (not just the gated subset), manually instantiate `FeatureEngineer` and process the validation metadata with `apply_gating=False`. Generate predictions using the Expert Ensemble (average of LGBM and XGB probabilities).
5.  **Threshold Optimization**: Iterate through potential thresholds to maximize the Matthews Correlation Coefficient (MCC) on the validation set. Print the final metric in the specified format.
6.  **Failure Analysis**: Calculate the absolute error between predictions and ground truth on the validation set. Compute correlations between the error and input features to identify failure modes.
7.  **Submission**: If the best validation MCC exceeds `0.6782`, load the test features (which are ungated by default), generate predictions using the optimized threshold, and save the `submission.csv` file.
