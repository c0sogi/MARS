The following script demonstrates the full execution pipeline of the provided machine learning solution. It performs the following steps:

1.  **Environment Setup**: Configures paths to use a temporary working directory (`./working/demo_execution`) to ensure no interference with the main input/output streams.
2.  **Data Subsampling**: Generates "Mini" versions of the metadata and tracking datasets. This is crucial for demonstrating the pipeline's logic quickly (within seconds) without processing the gigabytes of full data.
3.  **Configuration Patching**: Dynamically overrides the global constants in the imported library modules. This redirects the pipeline to use the mini datasets and reduces model complexity (e.g., `n_estimators=10`) for rapid execution.
4.  **Pipeline Execution**:
    *   **Training Loop**: Runs feature engineering, hard negative mining, expert model training (LGBM + XGBoost), and threshold optimization.
    *   **Inference Loop**: Generates features for the test set, loads the trained models, predicts contact events, and saves the submission file.
5.  **Validation**: Asserts that the output files (models, cache, submission) are created correctly and that the submission format matches requirements.
