The issue is that both LightGBM and XGBoost are configured to use early stopping, which strictly requires a validation dataset to monitor performance. However, the `train_scouts` method in the Trainer class trains models on the full balanced dataset without a validation split, causing LightGBM to raise a `ValueError` because `valid_sets` is empty. To fix this, I will modify `LGBMExpert.fit` to conditionally append the `early_stopping` callback only when validation sets are provided. Similarly, I will update `XGBExpert.fit` to pass `early_stopping_rounds` only when an evaluation set is present, ensuring robust handling of training calls without validation data.
