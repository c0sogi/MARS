Implementation Strategy:
1.  **Configuration Override**: Monkey-patch the `library.config` module to drastically reduce the number of estimators (trees) and early stopping rounds. This ensures the complex ensemble models train in seconds rather than hours for demonstration purposes.
2.  **Utility Verification**: Create synthetic DataFrames to validate the `reduce_mem_usage`, `calc_mcc`, and `gaussian_smooth_labels` functions from `library.utils`. Assert that memory is reduced and smoothing applies correctly to temporal sequences.
3.  **Feature Engineering Demonstration**: Instantiate `FeatureManager` and process a small `debug_sample` (e.g., 500 rows) of the training data. This verifies the data loading, merging, kinematic gating, and vector feature computation logic without processing the entire multi-gigabyte dataset.
4.  **Model Training Demonstration**: Instantiate `TriEnsemble` directly with synthetic data to verify the API (fit/predict) and the integration of LightGBM, XGBoost, and HistGradientBoosting.
5.  **Pipeline Integration**: Execute the full `TrainingPipeline` using the small debug sample. This tests the "Scout -> Mining -> Expert" curriculum learning flow.
6.  **Inference Execution**: Run the `InferencePipeline` to generate predictions on a sample of the test set, producing a valid `submission.csv`.
7.  **Validation**: Throughout the script, use `assert` statements to verify file creation, data shapes, and value ranges (e.g., probabilities between 0 and 1).
