The issue is that the validation dataset is being filtered using "Geometric Gating" (removing player pairs separated by more than 2.5 yards) in `runfile.py`. While this technique is beneficial for training efficiency (focusing on hard examples), applying it to the validation set removes a significant number of True Negatives. This distorts the confusion matrix and renders the Matthews Correlation Coefficient (MCC) invalid and incomparable to the target metric, as the validation distribution no longer matches the test distribution. To fix this, I will disable gating for the validation set generation in `runfile.py`, ensuring the metric is calculated on a representative sample of the full dataset (Cite debug_lesson_3).
