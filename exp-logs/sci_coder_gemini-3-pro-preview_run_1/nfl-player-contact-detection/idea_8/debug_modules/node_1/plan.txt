The `TimeoutError` was caused by Python's behavior regarding default argument evaluation. In `library/data_loader.py`, the `DataLoader` constructor defined `debug=Config.DEBUG` as a default argument, which was evaluated at import time when `Config.DEBUG` was `False`. Even though `runfile.py` later set `Config.DEBUG = True`, the `DataLoader` instances in `ExpertTrainer` (and `InferencePipeline`) continued to use the stale default value (`False`), causing them to process the full dataset instead of the debug subset.

To fix this, I will modify `ExpertTrainer` in `library/training.py` and `InferencePipeline` in `library/inference.py` to explicitly pass `debug=Config.DEBUG` when instantiating `DataLoader`. This ensures the loader receives the current runtime value of the configuration flag.
