This script demonstrates the end-to-end workflow of the NFL Contact Detection pipeline using the provided library modules. It performs the following steps:

1.  **Environment Setup**: Creates a temporary working directory and monkey-patches the global `config` module to point to this directory and use lightweight hyperparameters for speed.
2.  **Data Preparation**: Generates mini-datasets (Train, Validation, Test) by sampling a few plays from the original metadata and tracking files to ensure the demo runs quickly.
3.  **Feature Engineering**: Uses `data_loader` and `feature_engine` to merge tracking data, apply geometric gating, and generate temporal and Invariant Kinematic Set (IKS) features.
4.  **Curriculum Learning**: Demonstrates the `MiningCurriculum` class by training a "Scout" model to identify hard negatives and constructing an "Expert" dataset.
5.  **Model Training**: Trains the `UnifiedEnsemble` (LightGBM + XGBoost) on the Expert dataset.
6.  **Inference**: Generates predictions on the mini-test set and calculates the MCC score on the validation set.
