In `library/features.py`, the variable `non_ground_p2_ids` is a NumPy array (extracted via `.values`), and `pd.to_numeric` returns a NumPy array when passed a NumPy array. Consequently, the subsequent `.fillna(-1)` call fails. To fix this, I will replace the Pandas method chain with `np.nan_to_num`, which is the correct NumPy equivalent for replacing NaN values in an array, ensuring robust handling of mixed-type columns (Lesson ID: debug_lesson_16).
