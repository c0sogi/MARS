The following script demonstrates the execution of the Orthogonal-Spectral Vector-Anchored Ensemble (OSVA-E) pipeline using the provided library files.

**Strategy:**
1.  **Configuration Override**: We monkey-patch the `Config` class attributes immediately after import to enable `DEBUG` mode (reducing data size for speed) and drastically reduce the number of boosting estimators (to ensure the demo completes within seconds/minutes). We also redirect the working directory to `./working/demo_run`.
2.  **Workflow Execution**: We instantiate the `Workflow` class and invoke `run_full_workflow()`. This method orchestrates the entire pipeline: feature engineering, scout training, hard negative mining, expert training with temporal smoothing, and final inference.
3.  **Verification**: After execution, we perform assertions to ensure:
    *   The submission file exists and matches the expected row count.
    *   Model artifacts (Scouts and Experts) are saved correctly.
    *   Hard negative indices are generated.
    *   The pipeline produces a valid MCC score during validation.
