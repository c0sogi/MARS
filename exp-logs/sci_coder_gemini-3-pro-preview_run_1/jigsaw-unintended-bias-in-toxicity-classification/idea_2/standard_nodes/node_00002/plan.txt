The implementation strategy follows the baseline approach using the NBSVM architecture with bias-centric sample weighting.

1.  **Initialization**: We set the random seeds for reproducibility.
2.  **Data Loading**: We utilize `library.data_utils.load_data` to load the training, validation, and test datasets. This handles text preprocessing and binary target generation.
3.  **Feature Engineering**: We call `library.features.build_feature_matrix` to generate sparse TF-IDF matrices (combining word and character n-grams) for all datasets.
4.  **Bias Weighting**: We compute sample weights using `library.weighting.compute_sample_weights`. This assigns higher weights to "bias trap" examples (e.g., non-toxic comments mentioning identities) to force the model to learn these distinctions.
5.  **Model Training**: We instantiate the `NBSVMClassifier` from `library.nbsvm` and fit it to the training data using the computed sample weights. This model uses Naive Bayes log-count ratios to scale features before passing them to a Logistic Regression classifier.
6.  **Validation**: We generate probabilities for the validation set and compute the custom competition metric (Weighted combination of Overall AUC and Bias AUCs) using `library.evaluation.compute_final_metric`. The result is printed in the required format.
7.  **Failure Analysis**: We calculate the absolute error of predictions on the validation set and compute Pearson correlations between this error and specific features (text length and identity attributes) to identify systematic weaknesses.
8.  **Submission**: Finally, we generate predictions for the test set and save the formatted submission file to `./submission/submission.csv`.
