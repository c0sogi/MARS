Implementation strategy:
1.  **Configuration**: Initialize the `Config` class. Enable `debug` mode to allow training data subsampling (set to 100,000 samples) to ensure the code completes within the 2-hour limit on the A100 GPU. Adjust `epochs` to 1 and `awp_start_epoch` to 0 to ensure the adversarial training component is exercised within the single epoch.
2.  **Data Loading**: Use `get_dataloaders` to load training and validation data. Explicitly load the validation DataFrame using `load_and_process_data` for metric calculation and failure analysis.
3.  **Model Initialization**: Instantiate the `ToxicityModel` and move it to the GPU. Set up the `AdamW` optimizer, cosine scheduler, `CompositeLoss`, and `AWP` (Adversarial Weight Perturbation) as per the library modules.
4.  **Training**: Execute a training loop for the defined number of epochs using `train_fn`.
5.  **Validation & Evaluation**: After training, run inference on the full validation set using `eval_fn`. Compute the competition metrics using `JigsawEvaluator`. Print the required "Final Validation Metric".
6.  **Failure Analysis**: Calculate the absolute error between predictions and targets on the validation set. Compute and print the Pearson correlation between the error and key metadata features (identity columns) to identify systematic biases.
7.  **Submission**: Check if the final validation score exceeds the strict threshold (0.9268315106992828). If satisfied, run inference on the test set using `inference_fn` and save the results to `submission.csv`.
