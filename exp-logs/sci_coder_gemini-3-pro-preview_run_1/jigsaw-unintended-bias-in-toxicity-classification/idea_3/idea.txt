# Proposed Solution: Context-Aware Transformer with Bias-Weighted Loss

This strategy evolves the previous approaches by replacing the linear n-gram backbone with a deep learning architecture capable of semantic understanding, while strictly retaining the successful bias-mitigation strategy identified in the lessons.

### Model
**Architecture:** Deep Transformer Encoder (e.g., DistilBERT or RoBERTa-base).
**Structural Innovation:** Instead of relying on surface-level lexical features (TF-IDF n-grams) used in the NBSVM and Ridge Regression baselines, this solution utilizes a pre-trained Transformer backbone. Linear models struggled to differentiate between the *presence* of an identity term (e.g., "gay") and actual *toxicity* because they treat words as independent features. A Transformer uses self-attention mechanisms to capture the *context* in which an identity term appears, allowing the model to distinguish between a neutral identity statement and a slur.
**Output Layer:** A single linear classification head sits on top of the pooled embedding (e.g., the `[CLS]` token) to output a scalar toxicity score.

### Data
**Preprocessing:**
1.  **Tokenization:** The raw `comment_text` is processed using the specific tokenizer associated with the chosen pre-trained model (e.g., WordPiece or Byte-Pair Encoding), truncating sequences to a fixed length (e.g., 256 or 512 tokens) suitable for the GPU memory.
2.  **Bias-Centric Weight Generation:** We explicitly retain the weighting strategy that proved effective in the linear baseline. We generate a sample weight vector where examples belonging to specific "bias trap" subgroups—specifically **Non-Toxic examples mentioning an identity** and **Toxic examples mentioning an identity**—are assigned significantly higher weights (e.g., 5.0) compared to standard examples (1.0). This ensures the model focuses on the subgroups that caused the low BPSN scores in previous iterations. Cite solution_lesson_node_00002.

### Training
**Procedure:**
1.  **Objective Function:** We employ **Weighted Binary Cross-Entropy (BCE) Loss** with **Soft Targets**.
    *   **Soft Targets:** Unlike standard classification that rounds labels to 0 or 1, we train directly on the fractional `target` values (e.g., 0.6) provided in the dataset. This preserves the annotator uncertainty, which is often high for identity-related comments.
    *   **Sample Weighting:** The loss for each sample is multiplied by the pre-calculated bias weights. This forces the gradient descent process to prioritize minimizing error on the difficult identity subgroups, effectively reshaping the loss landscape to penalize bias-driven mistakes. Cite solution_lesson_node_00002.
2.  **Optimization:** The model is fine-tuned using the AdamW optimizer with a linear learning rate decay and a warm-up period. We freeze the lower layers of the Transformer for the first epoch to stabilize the classification head, then unfreeze the full model for fine-tuning.

### Evaluation
**Inference:**
The test set `comment_text` is tokenized and passed through the fine-tuned Transformer. The raw sigmoid output (probability) is extracted directly. No thresholding is applied, as the ROC-AUC metric relies on the rank order of predictions, and the regression-style training on soft targets provides well-calibrated probabilities for this purpose.
