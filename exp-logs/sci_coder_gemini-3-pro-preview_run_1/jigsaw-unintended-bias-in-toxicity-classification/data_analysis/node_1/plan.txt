The issue stems from `np.char.str_len` in NumPy 2.0+ (installed in the environment) not supporting object arrays, which is what `df["comment_text"].astype(str).values` returns. The fix is to replace the NumPy vectorization, which fails on object types, with a standard Python list comprehension to calculate string lengths, which is robust and sufficiently fast for this dataset size.
