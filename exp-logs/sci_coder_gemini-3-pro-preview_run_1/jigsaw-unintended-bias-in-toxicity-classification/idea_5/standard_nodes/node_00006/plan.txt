The issue stems from the `runfile.py` script attempting to load preprocessed data from the cache (`load_cached_data=True`). The cache currently holds stale, truncated data from a previous debug run (5,000 samples), whereas the validation step expects the full dataset (360,975 samples). This discrepancy causes the model to train on a tiny subset and the validation predictions to be largely zero-padded, resulting in an invalid metric. The fix is to explicitly disable cache loading in `runfile.py` to force the regeneration of the preprocessed data using the full dataset.
