# Proposed Solution: DeBERTa-v3-Large with Hybrid Ranking and Adversarial Robustness

### Model
**Architecture:**
We upgrade the backbone from the base model to **DeBERTa-v3-Large**. This model's larger parameter space and disentangled attention mechanism provide superior capacity for distinguishing the subtle semantic differences between neutral identity mentions and toxicity.
**Multi-Task Structure:**
We retain the successful Multi-Task Learning (MTL) framework. The encoder feeds into three distinct heads:
1.  **Primary Toxicity Head:** Predicts the main `target`.
2.  **Auxiliary Identity Head:** Predicts the presence of identity attributes. **Cite solution_lesson_node_00004**.
3.  **Auxiliary Identity Attack Head:** Predicts the `identity_attack` subtype.
*Rationale:* Explicitly predicting identity attributes forces the shared encoder to disentangle "identity" features from "toxicity" features, preventing the primary head from using identity as a lazy proxy for toxicity.

### Data
**Preprocessing:**
Tokenize `comment_text` using the DeBERTa-v3 tokenizer.
**Stratified Weighted Sampling:**
We utilize a **Weighted Random Sampler** for batch construction. This sampler is configured to oversample the specific "Bias Trap" subgroups (Non-Toxic + Identity Mention, Toxic + Identity Mention) significantly. This ensures that every mini-batch contains a dense mixture of these difficult examples, which is a prerequisite for the pairwise ranking loss to function effectively. **Cite solution_lesson_node_00007**.

### Training
**Loss Function:**
We employ a composite loss function: $L_{total} = L_{BCE} + \lambda_{rank} L_{Rank} + \lambda_{aux} L_{Aux}$.
1.  **Weighted Pointwise Loss ($L_{BCE}$):** We apply Binary Cross-Entropy on the soft toxicity targets. Crucially, we apply **Bias-Centric Sample Weights** (e.g., 5.0x for bias traps) to this loss component. This forces the model to prioritize minimizing absolute error on the specific subgroups that degrade the competition metric. **Cite solution_lesson_node_00002**.
2.  **Pairwise Margin Ranking Loss ($L_{Rank}$):** We mine hard pairs $(x_{pos}, x_{neg})$ within each batch (e.g., $x_{pos}$ is Toxic/No-Identity, $x_{neg}$ is Non-Toxic/Identity) and penalize the model if $Score(x_{neg}) > Score(x_{pos}) - margin$. This directly optimizes the rank-based AUC metric. **Cite solution_lesson_node_00007**.

**Structural Innovation: Adversarial Weight Perturbation (AWP):**
We introduce **AWP** into the training loop. After the standard forward and backward pass, AWP explicitly injects worst-case perturbations into the model's weights (ascending the loss surface) and performs a second forward/backward pass to minimize the loss at this perturbed state.
*Rationale:* Standard training often finds sharp minima where the model relies on brittle features (like specific identity tokens) to make predictions. AWP smooths the loss landscape, forcing the model to find a "flat" minimum that is robust to perturbations. This acts as a powerful regularizer, preventing the model from overfitting to specific identity terms and improving generalization on the unseen test set.

### Evaluation
**Inference:**
The test data is processed through the fine-tuned DeBERTa-v3-Large backbone. We extract predictions **only from the Primary Toxicity Head**. The auxiliary heads and adversarial training mechanics are discarded, having served their purpose of shaping a robust and disentangled encoder representation.
