The strategy for the implementation is as follows:

1.  **Setup and Initialization**: Define the input directory (`./input`) and the output directory (`./metadata`). Create the output directory if it does not exist.
2.  **Data Loading**: Load the raw `train.csv` and `test.csv` files using pandas.
3.  **Preprocessing for Split**: Create a binary target column (`label`) derived from the continuous `target` column (where `target >= 0.5` is positive) to facilitate stratified sampling.
4.  **Dataset Splitting**: Split the training data into training and validation sets using an 80:20 ratio with a fixed random state (42), stratifying by the binary label to ensure class balance is maintained.
5.  **Metadata Generation**: Save the resulting training, validation, and test dataframes as CSV files in the `./metadata` directory. These files will contain all necessary columns, including text, targets, and identity attributes.
6.  **Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (row counts, class distributions, identity subgroup statistics).
    *   Programmatically verify the split ratio (80:20).
    *   Programmatically verify that the class distribution in the validation set matches the training set (stratification check).
    *   Since the dataset consists of text embedded in CSVs rather than external file paths, the file path existence check will confirm the presence of the source CSVs.
