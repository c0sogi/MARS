The issue is that the installed version of XGBoost (`3.0.5`) requires `early_stopping_rounds` to be passed to the model constructor (`XGBRegressor(...)`) rather than the `fit()` method. The current configuration in `library/config.py` includes `early_stopping_rounds` in `XGB_FIT_PARAMS`, which causes a `TypeError` when unpacked into `model.fit()`. To fix this, I will move `early_stopping_rounds` from `XGB_FIT_PARAMS` to `XGB_PARAMS` in `library/config.py`.
