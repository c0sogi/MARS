The issue is caused by a stale cache: the `train_processed.parquet` and `val_processed.parquet` files were generated before new physics-informed features (like `en_0`, `n_bonds_0`) were added to `Config.FEATURES`. The `process_data` function loads these old files without checking if they contain the required features, causing a `KeyError` downstream when `data_loader.py` attempts to select the missing columns.

To fix this, I will modify `library/features.py` to validate the cached DataFrame against `Config.FEATURES`. If the cached data is missing any features defined in the configuration, it will be considered stale and the data will be reprocessed from scratch.
