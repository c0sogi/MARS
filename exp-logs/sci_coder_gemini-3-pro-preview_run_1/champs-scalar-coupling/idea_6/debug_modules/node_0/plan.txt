The implementation strategy is as follows:

1.  **Configuration**: I will programmatically override `config` settings to redirect output to a demo directory and drastically reduce XGBoost training complexity (fewer estimators, lower depth) to ensure the script runs quickly.
2.  **Data Loading**: I will load the metadata using `data_loader` and immediately sample it (e.g., 2000 rows) to keep the pipeline fast.
3.  **Feature Engineering**: I will invoke the `feature_engineering` pipeline. This will process the molecular graph (which happens once and is cached) and then generate features for the sampled datasets.
4.  **Modeling**: I will instantiate the `StratifiedEnsemble` from `model.py`, train it on the sampled data, and run inference.
5.  **Evaluation & Submission**: I will use `utils` to calculate the competition metric on the validation set and generate a formatted submission file for the test set.
6.  **Verification**: I will include assertions to verify file generation, data shapes, and the absence of NaNs in the final output.
