Implementation strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided modules (`library.config`, `library.feature_engineering`, `library.model_pipeline`, `library.utils`). Set random seeds for reproducibility.
2.  **Parameter Override**: Modify the `XGB_PARAMS` in `library.config` to reduce `n_estimators` and `max_depth`. This ensures the training runs quickly as a "fast baseline" while still testing the pipeline's mechanics.
3.  **Data Loading**: Use `get_data(load_cached_data=True)` to load the preprocessed features.
4.  **Subsampling**: Apply stratified subsampling to the training data (using `sklearn.model_selection.train_test_split`) to limit the dataset size to 200,000 samples. This preserves the distribution of coupling types while significantly reducing runtime. The validation set remains untouched to ensure a valid metric calculation.
5.  **Model Training**: Initialize the `StratifiedRegressor` and fit it on the subsampled training data.
6.  **Validation**: Generate predictions on the full validation set. Construct a DataFrame with true values and predictions, then calculate the Log MAE using `calculate_log_mae`. Print the result in the required format.
7.  **Failure Analysis**: Calculate the absolute error for validation samples. Compute the Pearson correlation between the absolute error and all numerical features in the validation set. Print the top 5 features most correlated with high error.
8.  **Submission Logic**: Compare the final validation metric against the specified threshold (`-1.1285...`). If the metric is lower (better), generate predictions for the test set and save the submission file using `save_submission`.
