The following strategy will be used to implement the solution:

1.  **Setup and Data Loading**: Define the input (`./input`) and output (`./metadata`) directories. Load the raw `train.csv` and `test.csv` files using pandas.
2.  **Metadata Enrichment**: Construct relative file paths for the molecular structure files (XYZ format) corresponding to each molecule. These paths will be stored in a new column `file_path` (e.g., `structures/dsgdb9nsd_000001.xyz`).
3.  **Group-based Splitting**: To prevent data leakage, the training data will be split by `molecule_name` rather than by individual atom pairs.
    -   Extract unique molecule names.
    -   Shuffle them using a fixed random seed (`RANDOM_STATE = 42`).
    -   Split the molecules into an 80% training set and a 20% validation set.
4.  **Metadata Generation**: Filter the original training data based on the molecule split to create `train.csv` and `val.csv` metadata files. The test set will be saved as `test.csv`. All files will be saved to the `./metadata` directory.
5.  **Verification**:
    -   Reload the generated metadata.
    -   Print summary statistics for each split.
    -   **Path Validation**: Randomly sample 1000 file paths from each dataset and verify they exist in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
    -   **Split Validation**: Assert that the set of molecules in the training and validation sets are disjoint (intersection is empty) to confirm the group split was successful.
