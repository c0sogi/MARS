# Solution Proposal: Stratified Gradient Boosting with Angular Projection Features

## Model
I propose a **Stratified Type-Specific Ensemble** architecture. Instead of training a single global model for all coupling types, we will instantiate and train **eight separate XGBoost Regressors**, one for each scalar coupling type (e.g., `1JHC`, `2JHH`, `3JHC`, etc.).

**Justification:**
*   **Physical Distinctness:** The physical mechanisms governing coupling constants vary significantly by type. 1-bond couplings (1J) are primarily determined by bond length and hybridization, while 2-bond and 3-bond couplings (2J, 3J) are heavily influenced by bond angles and dihedral angles (Karplus relationships). A single global model struggles to optimize for these competing physical regimes simultaneously.
*   **Regularization Strategy:** By stratifying the data, the categorical features identifying atom types (e.g., `atom_0=H`, `atom_1=C` for `1JHC`) become constant within each model. Following the insight on hidden regularization (Cite solution_lesson_node_00007), we will remove these constant features but explicitly lower the `colsample_bytree` hyperparameter. This compensates for the loss of "noise" features by forcing the trees to diversify their splits among the remaining geometric descriptors.

## Data
The feature engineering pipeline will be upgraded to capture explicit angular geometry while retaining the successful topological descriptors from previous iterations.

1.  **Preprocessing & Structure Merging:**
    *   Load the full training set and `structures.csv`.
    *   Merge 3D Cartesian coordinates for the atom pairs and calculate the Euclidean distance vector $\vec{r}_{01}$.
    *   **Retain:** Inverse distance features ($1/d, 1/d^2, 1/d^3$) to model field decay (Cite solution_lesson_node_00001).

2.  **Topological Features (Node-Level):**
    *   **Retain:** Generate "Bag of Neighbors" vectors (counts of C, H, N, O, F neighbors) and basic node stats (bond counts, mean neighbor distances) using the sparse aggregation method (Cite solution_lesson_node_00006, Cite solution_lesson_node_00009).
    *   **Implementation:** Use in-memory relational self-joins on `molecule_name` to generate these features without intermediate caching (Cite solution_lesson_node_00004).

3.  **New Feature: Angular Projections (Cosine Similarity):**
    *   To address the lack of angular information in the previous distance-only models, we will engineer **Cosine Bond Angles**.
    *   For each atom in the coupling pair (Atom 0 and Atom 1), identify all bonded neighbors.
    *   Construct the reference bond vector $\vec{v}_{ref} = \vec{r}_{1} - \vec{r}_{0}$.
    *   For each neighbor $n$ of Atom 0, calculate the vector $\vec{v}_{0n} = \vec{r}_{n} - \vec{r}_{0}$. Calculate the cosine similarity: $\cos(\theta) = (\vec{v}_{ref} \cdot \vec{v}_{0n}) / (|\vec{v}_{ref}| |\vec{v}_{0n}|)$.
    *   Perform the same for neighbors of Atom 1 (using $-\vec{v}_{ref}$).
    *   **Aggregation:** For each atom (0 and 1), compute the `mean`, `min`, and `max` of these cosine values. This creates a rotationally invariant descriptor of the local angular environment relative to the coupling axis, serving as a proxy for the bond angles and dihedrals required for J-coupling prediction.

## Training
The training regime prioritizes data volume and convergence stability over speed.

*   **Data Split:** Use the pre-generated `metadata/train.csv` and `metadata/val.csv` splits to ensure no molecular leakage.
*   **Regime:** Train on the **Full Dataset** (100% of available training rows) rather than subsampling (Cite solution_lesson_node_00008).
*   **Hyperparameters:**
    *   **Learning Rate:** Reduced to `0.05` to ensure fine-grained convergence (Cite solution_lesson_node_00008).
    *   **Estimators:** Increased to `25,000` with early stopping.
    *   **Colsample_bytree:** Set to `0.5` - `0.7`. This is a critical adjustment to prevent overfitting after removing the constant atom-type features in the stratified models (Cite solution_lesson_node_00007).
*   **Objective:** `reg:absoluteerror` (MAE) to align with the competition metric.

## Evaluation
1.  **Inference:** Iterate through each of the 8 coupling types found in `metadata/test.csv`. Load the corresponding trained model and generate predictions for that subset.
2.  **Concatenation:** Combine predictions from all 8 models into a single dataframe.
3.  **Validation:** Calculate the Log Mean Absolute Error per type and average them to estimate the final score.
4.  **Submission:** Format the combined results into `id,scalar_coupling_constant` CSV.
