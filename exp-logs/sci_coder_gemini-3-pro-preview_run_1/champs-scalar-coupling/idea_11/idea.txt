Based on the progression of empirical findings—specifically the success of "Simulated Message Passing" (Cite solution_lesson_node_00024), the necessity of "Stratified Feature Pruning" (Cite solution_lesson_node_00035), and the untapped potential of the provided physical decomposition data (`scalar_coupling_contributions.csv`)—I propose the **Physics-Aware Multi-Task Hybrid Ensemble (PA-MTHE)**.

This solution introduces a **Structural Innovation** by employing a Multi-Task Graph Neural Network to learn embeddings that explicitly disentangle the four underlying physical forces (Fermi Contact, Spin-Dipolar, etc.) governing the target. These "Physics-Aware" embeddings are then consumed by the robust Stratified XGBoost architecture established in previous successful iterations.

# Model
The architecture is a **Two-Stage Hybrid** system:

1.  **Stage 1: Multi-Task Graph Neural Network (MT-GNN)**
    *   **Backbone:** A deep Message Passing Neural Network (MPNN) taking atom types and RBF-encoded distances as input.
    *   **Structural Innovation (Multi-Task Heads):** Instead of a single output head for the `scalar_coupling_constant`, the network features **Five Parallel Output Heads**:
        1.  Total Coupling (Primary Target)
        2.  Fermi Contact contribution (`fc`)
        3.  Spin-Dipolar contribution (`sd`)
        4.  Paramagnetic Spin-Orbit contribution (`pso`)
        5.  Diamagnetic Spin-Orbit contribution (`dso`)
    *   **Rationale:** By training the shared encoder to predict these distinct physical components (provided in `scalar_coupling_contributions.csv`), we force the network to learn a latent representation that disentangles these competing forces (e.g., distinguishing electron density at the nucleus vs. orbital magnetic moments).
    *   **Output:** We extract the **Physics-Aware Interaction Embedding**—the concatenated node and edge states from the final shared layer—to serve as input for Stage 2.

2.  **Stage 2: Stratified XGBoost Ensemble**
    *   We retain the **Stratified Ensemble** structure (8 separate models) to handle the disjoint regimes of coupling types (Cite solution_lesson_node_00011).
    *   **Input:** A hybrid vector concatenating:
        *   **Symbolic Features:** High-precision tabular geometric descriptors.
        *   **Neural Features:** The Physics-Aware Embeddings from Stage 1.

# Data
The pipeline integrates the robust vectorized tabular engine with the new multi-task target generation.

1.  **Adaptive Graph Construction:**
    *   Construct molecular graphs using **Adaptive Covalent Radii Thresholds** ($r_i + r_j + \text{tolerance}$) to ensure valid connectivity even in strained molecules (Cite solution_lesson_node_00020).

2.  **Symbolic Feature Engineering (Vectorized):**
    *   **Level 0:** Physics-informed inverse distances ($1/d^n$) (Cite solution_lesson_node_00001).
    *   **Level 1 (Geometry):** **Late Aggregation** of Cosine Projections. Calculate individual bond angles first, *then* aggregate (`mean`, `std`, `min`, `max`) to preserve anisotropic signals (Cite solution_lesson_node_00028).
    *   **Level 2 (Topology):** **Vectorized Message Passing**. Aggregate neighbor features (Level 1) back to the central atom using global merges, simulating a GNN receptive field in tabular format (Cite solution_lesson_node_00024).
    *   **Implementation:** Strictly avoid iterative loops; use global DataFrame operations to process 100% of the data (Cite solution_lesson_node_00021).

3.  **Target Engineering:**
    *   Merge `scalar_coupling_contributions.csv` with `train.csv` to provide the ground truth labels for the auxiliary heads in Stage 1.

# Training
The training regime prioritizes representation quality and subspace optimization.

1.  **Phase 1: Multi-Task Representation Learning:**
    *   Train the MT-GNN on the **Full Training Set** (Cite solution_lesson_node_00008).
    *   **Loss Function:** $L_{total} = L_{MAE}(\text{Total}) + \lambda \sum_{c \in \{fc, sd, pso, dso\}} L_{MAE}(c)$. This leverages privileged training information to shape the embedding space.

2.  **Phase 2: Stratified Feature Pruning:**
    *   Split the hybrid dataset (Symbolic + Neural) by coupling type.
    *   **Per-Stratum Pruning:** For each stratum (e.g., `1JHC`), calculate feature variance and drop any feature (Symbolic or Neural) that is constant or invariant *within that specific subgroup*. This maximizes the efficiency of the tree's subspace sampling (Cite solution_lesson_node_00035).

3.  **Phase 3: High-Capacity Boosting:**
    *   Train the 8 XGBoost models on the pruned hybrid datasets.
    *   **Hyperparameters:** Use **High Capacity** settings (Depth 10-12, Learning Rate 0.01, Estimators 40,000+) with Early Stopping (Cite solution_lesson_node_00017, solution_lesson_node_00013).

# Evaluation
1.  **Inference Pipeline:**
    *   Generate graphs and symbolic features for `test.csv` using the Adaptive/Vectorized pipeline.
    *   Pass graphs through the trained MT-GNN (ignoring auxiliary heads, as component labels don't exist for test data) to extract the Physics-Aware Embeddings.
2.  **Stratified Prediction:**
    *   Split test data by coupling type.
    *   Apply the **same pruning masks** derived during training.
    *   Predict using the corresponding Stratified XGBoost model.
3.  **Submission:** Concatenate predictions into the final format.
