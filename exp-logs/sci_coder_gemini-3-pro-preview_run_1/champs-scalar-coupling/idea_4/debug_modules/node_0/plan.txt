This script demonstrates the end-to-end usage of the provided machine learning pipeline for molecular property prediction. It performs the following steps:

1.  **Configuration & Setup**: Imports the library modules and sets the random seed for reproducibility. It creates a small subset of the training, validation, and test metadata to ensure the demonstration runs quickly.
2.  **Monkey-Patching**: Dynamically overrides global configuration constants (file paths and XGBoost hyperparameters) to point to the subsetted data and reduce training time (e.g., reducing `n_estimators`).
3.  **Geometry Engine Demo**: Instantiates the `GeometryEngine`, verifies that molecular structures are loaded correctly, and tests the calculation of geometric features (shortest paths, angles, dihedrals) on the subset.
4.  **Feature Pipeline Demo**: Instantiates the `FeaturePipeline`, generates a full feature set (including distance, geometric, and node-neighbor features) for the training subset, and validates the data preparation logic for specific coupling types.
5.  **Trainer Demo**: Instantiates the `StratifiedTrainer`, runs a complete training cycle on the subsetted data, and generates predictions for the test subset. It asserts that models and submission files are correctly created.
