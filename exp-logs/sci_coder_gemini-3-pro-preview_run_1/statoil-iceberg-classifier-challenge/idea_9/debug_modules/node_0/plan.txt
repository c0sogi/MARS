The following script demonstrates the usage of the provided library modules to perform an end-to-end workflow for the Iceberg vs. Ship classification task.

The strategy is as follows:
1.  **Configuration Setup**: We override default `Config` parameters (e.g., reducing epochs, batch size) to ensure the demonstration runs quickly while still executing all logical paths.
2.  **Data Loading Verification**: We utilize `get_loaders` to process the raw JSON data (ignoring cache to verify processing logic), inspect the resulting DataLoaders, and verify the shape and types of the batches produced (Images, Angles, Labels).
3.  **Model Initialization & Forward Pass**: We instantiate the `IcebergResNet18` model, verify its parameter count, and perform a forward pass with a real batch from the data loader to confirm tensor shape compatibility.
4.  **Loss Function Verification**: We isolate the `DistillationLoss` class to verify it correctly handles both hard labels and soft targets (for knowledge distillation).
5.  **Training & Evaluation Loop**: We run a single epoch of training using `engine.train_one_epoch` and a validation pass using `engine.validate_with_tta` to demonstrate the training engine and Test Time Augmentation (TTA) logic.
6.  **Inference**: We generate predictions on a subset of the test set using `engine.predict_tta`.
