Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Calibrated Full-Fit ResNet-18 Ensemble with Trajectory Replay and Platt Scaling**.

This solution structurally evolves the **Full-Fit** strategy (Idea 10, 11) by integrating a **Trajectory Replay** mechanism to ensure optimization stability without a validation set, and adds a **Post-Hoc Calibration** stage (Platt Scaling) to explicitly minimize Log Loss, addressing the calibration issues observed in previous ensemble attempts.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants (ResNet-34) or depthwise-separable architectures (EfficientNet) for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Corrected Composite Fusion:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic to ensure equal modal contribution:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2 (Cite solution_lesson_node_00037).
    4.  Stack them to form the input.
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation**. We explicitly reject Bilinear interpolation to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline:
    *   **RandomRotate90** (Discrete rotations) (Cite solution_lesson_node_00028).
    *   **Rotate** with a limit of $\pm 20^{\circ}$ (Continuous rotation) (Cite solution_lesson_node_00031).
    *   Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Protocol** to maximize data usage while ensuring convergence stability and calibration.

**Phase 1: Calibration & Trajectory Extraction**
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimization:** Use **AdamW** (`weight_decay=0.01`) with a **Batch Size of 32** and a **ReduceLROnPlateau** scheduler. We strictly enforce Batch Size 32 to maintain the high gradient step volume (Cite solution_lesson_node_00038).
*   **Outputs:**
    1.  **Global Optimal Epoch ($E^*$):** The epoch minimizing the average validation loss across folds (Cite solution_lesson_node_00040).
    2.  **Trajectory Milestones:** The average epoch indices where the scheduler triggered LR reductions.
    3.  **Calibration Parameters:** Collect Out-Of-Fold (OOF) logits and labels to fit a **Platt Scaling** (Logistic Regression) model. This learns a scalar scaling factor to map model outputs to calibrated probabilities, minimizing Log Loss.

**Phase 2: Production (Full-Fit with Trajectory Replay)**
*   **Method:** Train **5 independent models** on **100% of the training data** (Train + Validation combined) for exactly $E^*$ epochs.
*   **Trajectory Replay (Structural Innovation):** Instead of using a reactive scheduler (which requires a validation set), we will use a **MultiStepLR** scheduler configured with the **Trajectory Milestones** extracted from Phase 1. This replicates the successful optimization dynamics of the calibration phase on the full dataset without needing a validation split.
*   **Optimization:** Same settings as Phase 1 (AdamW, Batch Size 32).

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views (Cite solution_lesson_node_00031).
*   **Ensemble & Calibration:**
    1.  Average the TTA probabilities for each model.
    2.  Average the probabilities across the 5 Full-Fit models.
    3.  Apply the **Platt Scaling** transformation (learned in Phase 1) to the final ensemble average. This ensures the final submission is statistically calibrated for the Log Loss metric.
