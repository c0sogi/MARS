This script demonstrates the end-to-end pipeline for the Iceberg/Ship classification task using the provided library. It covers data loading, model initialization, training, evaluation, calibration using Platt Scaling, and generating predictions for the test set.

The script performs the following steps:
1.  **Configuration Override**: Adjusts hyperparameters (epochs, batch size) for a rapid execution suitable for demonstration.
2.  **Data Preparation**: Loads and processes the dataset using `library.data`, verifying batch shapes and content.
3.  **Model Initialization**: Instantiates the ResNet18-based model from `library.model` and verifies the forward pass.
4.  **Training Loop**: Runs a short training cycle using `library.engine`, including backpropagation and loss calculation.
5.  **Evaluation**: Validates the model on the hold-out set and computes the Log Loss metric.
6.  **Calibration**: Fits a `PlattScaler` (Logistic Regression) on the validation logits to calibrate probabilities.
7.  **Inference**: Generates predictions on the test set and creates a submission file.
