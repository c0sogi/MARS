The following script demonstrates the usage of the provided library files to execute the Iceberg Classification pipeline. It performs the following steps:
1.  **Configuration Override**: Adjusts hyperparameters (epochs, batch size) and paths to ensure the demonstration runs quickly and uses a dedicated working directory.
2.  **Data Validation**: Manually loads and verifies the integrity of the processed data and `IcebergDataset` class.
3.  **Model Verification**: Instantiates the `IsovariantResNet18` model and performs a forward pass with dummy data to verify tensor shapes.
4.  **Pipeline Execution**: Runs the full `Pipeline` workflow, including:
    *   **Phase 1 (Calibration)**: Runs a shortened 5-fold cross-validation to determine optimal epochs.
    *   **Phase 2 (Production)**: Trains an ensemble of models using the optimal epoch count and Stochastic Weight Averaging (SWA).
    *   **Inference**: Generates predictions on the test set and saves the submission file.
5.  **Output Verification**: Validates the format and content of the generated submission file.
