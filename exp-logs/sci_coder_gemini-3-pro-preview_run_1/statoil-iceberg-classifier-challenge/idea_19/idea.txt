Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Calibrated Semi-Supervised ResNet-18 Ensemble with Adaptive GeM Pooling**.

This solution represents a structural evolution that synthesizes the robust optimization pipeline of Idea 13, the architectural potential of Idea 18 (corrected for optimization stability), and the data-expansion capability of Idea 16 (corrected for teacher stability). It addresses the "Data Scarcity" bottleneck by safely leveraging unlabeled test data through a rigorous **Self-Training** loop, grounded by a **GeM-equipped** backbone that adapts to the specific signal-to-noise characteristics of SAR imagery.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants for this small dataset (Cite solution_lesson_node_00012).
*   **Adaptive GeM Pooling (Structural Innovation):** We will replace the standard Global Average Pooling (GAP) with **Generalized Mean (GeM) Pooling**, initialized with parameter $p=1$ (equivalent to Average Pooling).
    *   **Rationale:** This initialization starts the model in the noise-robust regime preferred for SAR data (Cite solution_lesson_node_00019). However, by making $p$ learnable, the network can adaptively shift towards Max Pooling behavior to capture high-intensity targets (icebergs) if the signal-to-noise ratio permits, resolving the conflict between detecting bright spots and suppressing speckle noise (Cite solution_lesson_node_00016). We explicitly correct the failure of Idea 18 by pairing this with a high-patience scheduler (Cite solution_lesson_node_00070).
*   **Late Fusion:** We will retain the **Late Fusion** strategy, concatenating the normalized `inc_angle` with the pooled feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Head:** The classification head will consist of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline including **RandomRotate90** and **Continuous Rotation** ($\pm 20^{\circ}$) (Cite solution_lesson_node_00028, solution_lesson_node_00031). We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Stage Self-Training Protocol** that prioritizes stability to ensure high-quality pseudo-labels.

**Stage 1: Teacher Ensemble (Calibrated SWA)**
*   **Calibration (Global Epoch Selection):** Run **Stratified 5-Fold Cross-Validation** to determine the optimal convergence epoch ($E_{conv}$).
    *   **Optimization:** Use **AdamW** (`weight_decay=0.01`) with **Label Smoothing** ($\epsilon=0.05$) (Cite solution_lesson_node_00065).
    *   **Scheduler:** Use `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**. This explicitly corrects the premature convergence issues observed in Idea 16 and Idea 18 (Cite solution_lesson_node_00070, solution_lesson_node_00065).
    *   **Metric:** Select $E_{conv}$ based on the minimum **TTA-Validation Loss** (average of Original + Flips) to align training with inference (Cite solution_lesson_node_00025).
*   **Production:** Train **5 independent models** on **100% of the labeled data**.
    *   Train for $E_{conv}$ epochs (Standard Phase).
    *   Train for 12 additional epochs using **Stochastic Weight Averaging (SWA)** (Cite solution_lesson_node_00049).

**Stage 2: Student Ensemble (Semi-Supervised)**
*   **Pseudo-Labeling:** Generate predictions on the **Test Set** using the Stage 1 Teacher Ensemble (with TTA).
*   **Filtering:** Select samples that meet strict criteria: **High Confidence** ($p>0.95$ or $p<0.05$) AND **Low Variance** (StdDev across ensemble members $< 0.02$). This ensures the students only learn from stable, agreed-upon predictions (Cite solution_lesson_node_00053).
*   **Retraining:** Train **5 new independent SWA models** on the **Combined Dataset** (Labeled + Pseudo-Labeled) using the same robust architecture and schedule.

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views (Cite solution_lesson_node_00031).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Stage 2 (Student) models**.
