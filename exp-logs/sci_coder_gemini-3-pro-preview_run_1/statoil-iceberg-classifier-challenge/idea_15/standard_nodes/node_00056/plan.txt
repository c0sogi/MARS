The following script implements the **OOF-Calibrated SWA-ResNet Ensemble with Trajectory Replay** strategy.

### Strategy Outline
1.  **Phase 1: Exploration & Trajectory Extraction**: We train a ResNet18 model on the training split using `ReduceLROnPlateau`. This phase serves two purposes: determining the optimal convergence epoch ($E_{conv}$) and recording the epochs where the learning rate dropped (Milestones). We conclude this phase with Stochastic Weight Averaging (SWA) to obtain a robust model and reliable Out-Of-Fold (OOF) logits for the validation set.
2.  **Phase 2: Meta-Calibration**: We fit a `PlattScaler` (Logistic Regression) on the Phase 1 validation logits and targets. This learns a mapping to correct the model's raw logits into well-calibrated probabilities, minimizing Log Loss.
3.  **Failure Analysis**: We calculate the correlation between the incidence angle and the model's error on the validation set to verify if the model struggles with specific acquisition angles.
4.  **Phase 3: Production (Full-Fit)**: If the Phase 1 validation metric meets the requirement, we combine the Training and Validation datasets. We then train a fresh model on this full dataset. Crucially, we use **Trajectory Replay**: instead of a reactive scheduler, we use `MultiStepLR` with the milestones recorded in Phase 1 and train for exactly $E_{conv}$ epochs, followed by SWA. This ensures the production model follows the optimal optimization path found during exploration.
5.  **Inference**: We predict on the test set using Test-Time Augmentation (TTA) (Original + H-Flip + V-Flip), apply the `PlattScaler` calibration, and generate the submission.
