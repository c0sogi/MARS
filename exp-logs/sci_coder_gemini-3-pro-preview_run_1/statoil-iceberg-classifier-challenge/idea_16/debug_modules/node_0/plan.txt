The following script demonstrates the end-to-end pipeline for the Iceberg vs Ship classification task using the provided library. It covers configuration setup, data loading, model initialization, base training, pseudo-label generation (Semi-Supervised Learning), and final submission generation.

The script is optimized for speed by reducing the number of epochs, batch size, and using a subset of data for pseudo-labeling verification. It includes assertions to validate the shapes and logic at each step.
