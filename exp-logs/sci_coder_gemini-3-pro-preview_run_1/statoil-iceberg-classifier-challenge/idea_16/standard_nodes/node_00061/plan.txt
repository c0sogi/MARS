Implementation strategy for the Semi-Supervised SWA-ResNet Ensemble:

1.  **Setup & Data Loading**: Initialize the environment and seed for reproducibility. Load the training data using the provided `load_dataset_data` utility.
2.  **Phase 1: Calibration**:
    *   Perform a single-split validation (80/20) on the training set to determine the optimal number of training epochs ($E_{conv}$) and learning rate scheduler milestones.
    *   This avoids data leakage from the official hold-out validation set while providing a robust stopping criterion.
3.  **Phase 2: Teacher Ensemble Training**:
    *   Train 5 independent ResNet-18 models on the **full** training set.
    *   Utilize a "Replay" strategy: Train for $E_{conv}$ epochs using the milestones found in calibration, followed by a Stochastic Weight Averaging (SWA) phase to enhance generalization.
4.  **Phase 3: Pseudo-Labeling**:
    *   Use the Teacher Ensemble to predict on the test set.
    *   Select high-confidence samples with low ensemble variance to create a pseudo-labeled dataset.
5.  **Phase 4: Student Ensemble Training**:
    *   Combine the original training data with the pseudo-labeled data.
    *   Train a new ensemble of 5 Student models using the same Replay+SWA protocol.
6.  **Phase 5: Evaluation & Submission**:
    *   Evaluate the Student Ensemble on the official hold-out validation set using Exhaustive Test-Time Augmentation (TTA).
    *   Compute the Log Loss metric.
    *   Perform failure analysis by correlating prediction errors with incidence angles.
    *   If the validation score meets the target threshold (< 0.169), generate predictions for the test set and save the submission file.
