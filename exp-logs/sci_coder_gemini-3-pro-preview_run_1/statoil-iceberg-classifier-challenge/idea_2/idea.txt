# Proposed Solution: Transfer Learning with ResNet-18 and Robust Late Fusion

## Model
The proposed solution transitions from a shallow, custom CNN to a **Transfer Learning** approach using a **ResNet-18** backbone. This structural innovation aims to capture more complex, hierarchical texture features that the previous simple model missed, addressing the weakness in classifying low-contrast images.

*   **Input Construction**: The model will accept a **3-channel image** composed of Band 1 (HH), Band 2 (HV), and the arithmetic mean of both bands. This structure is preserved to maintain compatibility with standard RGB-designed architectures while explicitly representing signal correlation.
*   **Visual Backbone**: We will employ a **ResNet-18** architecture initialized with ImageNet weights. The network will serve as the primary feature extractor. We will rely on the network's Global Average Pooling (GAP) layer to produce a robust feature vector, replacing the "Flatten" approach of the previous model to enforce spatial invariance.
*   **Late Fusion**: We will explicitly retain the **Late Fusion** strategy found to be effective in previous iterations. The scalar `inc_angle` (normalized) will be concatenated with the 512-dimensional output vector from the ResNet backbone. This ensures the classifier can calibrate visual features based on the acquisition geometry (Cite solution_lesson_node_00001).
*   **Classification Head**: The fused vector (512 + 1 dimensions) will pass through a new top-head consisting of a Dense layer, Batch Normalization, ReLU activation, Dropout, and a final Sigmoid output.

## Data
1.  **Imputation & Normalization**: Missing `inc_angle` values will be imputed with the training set mean. Image bands (dB) will be Min-Max scaled to the [0, 1] range to match the expected input distribution for neural networks.
2.  **Upsampling**: To better leverage the pre-trained ResNet filters (designed for 224x224 images), we will resize the 75x75 input images to a larger resolution (e.g., 150x150 or 224x224) using bilinear interpolation.
3.  **Augmentation**: We will introduce real-time data augmentation, including random horizontal/vertical flips and slight rotations. This addresses the small dataset size (1604 samples) and helps the deeper model generalize better.

## Training
*   **Loss Function**: Binary Cross-Entropy (Log Loss).
*   **Optimizer**: We will use the **Adam** optimizer. We will employ a **ReduceLROnPlateau** scheduler to decay the learning rate when validation loss stagnates, allowing the model to settle into a better local minimum.
*   **Robust Checkpointing**: We will implement an Early Stopping mechanism with a strict fix for the state-saving bug identified previously. Instead of assigning the state dictionary to a variable, we will use `copy.deepcopy()` or save the weights directly to disk whenever the validation loss improves. This guarantees that the final model used for inference corresponds exactly to the epoch with the lowest validation loss, not the final training step (Cite solution_lesson_node_00002).

## Evaluation
1.  **Restoration**: Load the weights from the specific checkpoint saved during the "best" epoch (verified by the robust checkpointing strategy).
2.  **Inference**: Apply the same preprocessing (scaling, upsampling, angle imputation) to the test set.
3.  **Prediction**: Generate probabilities using the loaded model and format the submission file.
