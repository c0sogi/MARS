To improve the model's performance and reduce the Log Loss, I will implement a strategy focusing on **Test Time Augmentation (TTA)**, **Label Smoothing**, and enhanced **Data Augmentation**.

1.  **Data Augmentation (`library/dataset.py`)**: I will add `RandomAffine` (translation and scaling) to the training transforms. This helps the model generalize better given the small dataset size (approx. 1300 training samples).
2.  **Training Optimization (`library/trainer.py`)**:
    *   **Optimizer**: Switch from `Adam` to `AdamW`. `AdamW` decouples weight decay from the gradient update, often leading to better generalization.
    *   **Label Smoothing**: Implement manual label smoothing (epsilon=0.05) in the training loop. This prevents the model from predicting extremely high probabilities (close to 1.0 or 0.0), which penalizes Log Loss heavily if incorrect.
    *   **TTA in Inference**: Modify `predict_and_submit` to average predictions from the original image, a horizontal flip, and a vertical flip.
3.  **Validation Loop (`runfile.py`)**:
    *   Update the validation loop to use the same **TTA** strategy as inference. This ensures the reported validation metric reflects the improved inference capability and allows us to beat the threshold.
    *   Increase `num_epochs` to 25 to allow the model to converge with the harder augmentation and smoothing tasks.

I will preserve the **Late Fusion** (Cite solution_lesson_node_00001) and **ResNet Backbone** (Cite solution_lesson_node_00004) architectures as they are proven effective.
