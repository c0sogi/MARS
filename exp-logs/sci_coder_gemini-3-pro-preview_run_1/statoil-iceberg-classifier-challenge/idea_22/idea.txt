Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Angle-Calibrated SWA-ResNet Ensemble**.

This solution introduces **Angle-Gated Feature Calibration** as a structural innovation. Instead of simply concatenating the incidence angle to the visual features (Late Fusion), which relies on the final linear layer to model the complex physical relationship between viewing geometry and backscatter intensity, this approach uses the angle to explicitly modulate (scale) the feature channels via a gating mechanism. This is combined with the highly robust **Full-Fit SWA** training pipeline established in previous successful iterations.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Structural Innovation: Angle-Gated Feature Calibration:** We will replace the standard concatenation-based Late Fusion with a **Feature-wise Linear Modulation (FiLM)** style gating mechanism.
    1.  The normalized scalar `inc_angle` is passed through a lightweight MLP (Linear $1 \to 64$ $\to$ ReLU $\to$ Linear $64 \to 512$ $\to$ Sigmoid).
    2.  This produces a 512-dimensional "Attention Vector" $\alpha$, where $\alpha \in (0, 1)$.
    3.  The 512-dimensional visual feature vector $F_{img}$ (from GAP) is multiplied element-wise by this attention vector: $F_{calibrated} = F_{img} \odot \alpha$.
    4.  **Rationale:** This allows the viewing geometry to explicitly suppress or emphasize specific feature channels (e.g., dampening texture features that are unreliable at high incidence angles) *before* the classification decision, providing a more physically grounded fusion than simple concatenation (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The calibrated feature vector $F_{calibrated}$ will be passed to a block consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads on the visual path to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust, discrete geometric augmentation pipeline to ensure stability and group closure:
    *   **RandomRotate90** (Discrete rotations).
    *   Horizontal and Vertical Flips.
    *   We will **avoid** continuous perturbations (like small rotations) during fine-tuning to maximize stability (Cite solution_lesson_node_00077) and will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement the **Two-Phase Protocol** that combines rigorous calibration with full-data training.

**Phase 1: Calibration (Global Epoch Selection)**
*   **Objective:** Determine the optimal convergence epoch ($E_{conv}$) where the model stabilizes.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimization:** **AdamW** with a low learning rate of **2e-4** and `weight_decay=0.01` (Cite solution_lesson_node_00077).
*   **Scheduler:** Use `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**. This ensures the model converges deeply without the premature freezing caused by aggressive schedules (Cite solution_lesson_node_00065, solution_lesson_node_00070).
*   **Loss:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) (Cite solution_lesson_node_00065).
*   **Selection:** Identify $E_{conv}$ as the epoch that minimizes the average validation loss (Cite solution_lesson_node_00040).

**Phase 2: Production (Full-Fit SWA)**
*   **Objective:** Train 5 independent models on **100% of the training data** (Train + Validation combined).
*   **Standard Stage:** Train for exactly $E_{conv}$ epochs using the hyperparameter dynamics derived from Phase 1.
*   **SWA Stage:** Continue training for an additional 12 epochs using **Stochastic Weight Averaging (SWA)** with a constant learning rate. This flattens the loss landscape and improves generalization (Cite solution_lesson_node_00049, solution_lesson_node_00055).

# Evaluation
*   **Exhaustive Closed-Group TTA:** For every test image, we will generate predictions using the **Klein Four-Group**: Original, Horizontal Flip, Vertical Flip, and Rotate180 (composed flips). This ensures the ensemble average is mathematically invariant to the cardinal symmetries (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SWA models**.
