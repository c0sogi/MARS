This script demonstrates the end-to-end workflow using the provided library files. It covers:
1.  **Initialization**: Setting seeds and selecting the compute device.
2.  **Data Loading**: Processing raw JSON data into PyTorch DataLoaders using `library.data`.
3.  **Model Usage**: Instantiating the `IcebergResNet` and verifying the forward pass.
4.  **Training**: Running a single epoch of training and validation to demonstrate the loop and metric calculation.
5.  **Inference**: Generating predictions with Test Time Augmentation (TTA) and creating a submission file via the ensemble generation utility.

The script uses a small batch size and runs for only one epoch to ensure quick execution while verifying all logic with assertions.
