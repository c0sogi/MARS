# Proposed Baseline Approach: Composite-Input LeNet-Style CNN

## Model
The proposed model is a **Composite-Input CNN** that follows a classic LeNet/AlexNet-style architecture, prioritizing the explicit capture of inter-band correlations and spatial structure.

*   **Input Representation**: Unlike the provided architectures that may process the two bands directly, this model explicitly constructs a **3-channel image** input (75x75x3). The channels are defined as:
    1.  Band 1 (HH polarization)
    2.  Band 2 (HV polarization)
    3.  **Composite Band**: The arithmetic mean of Band 1 and Band 2. This synthetic channel helps the network easily identify signal consistency between polarizations.
*   **Feature Extractor**: The network consists of **three convolutional blocks**. Each block contains a 2D Convolution layer (with filter counts increasing, e.g., 64, 128, 128), followed by ReLU activation and 2x2 Max Pooling.
*   **Transition & Fusion**: Distinct from Model 1 (which uses Global Average Pooling), this model uses a **Flatten** layer after the final pooling step. This retains specific spatial activation patterns. The flattened vector is then concatenated with the preprocessed `inc_angle` scalar.
*   **Classifier Head**: The fused vector passes through two Dense (Fully Connected) layers. To mitigate overfitting on this small dataset, aggressive **Dropout** (e.g., rate of 0.5) is applied before the final Dense layer, which uses a Sigmoid activation to output the probability.

## Data
1.  **Incidence Angle Imputation**: Identify samples with "na" in the `inc_angle` field and replace them with the mean incidence angle calculated from the valid training samples.
2.  **Image Construction**: For every sample, stack `band_1` and `band_2` to form the first two channels. Compute the element-wise mean of these two bands to generate the third channel. Reshape the data into a (N, 75, 75, 3) tensor.
3.  **Normalization**: The raw values are in decibels (dB). Apply Min-Max scaling (or a fixed scaling factor based on global min/max stats) to normalize the pixel values into a range suitable for neural network convergence (e.g., [0, 1]).

## Training
*   **Loss Function**: Use **Binary Cross-Entropy** (Log Loss), which directly optimizes the competition metric.
*   **Optimizer**: Use the **Adam** optimizer with a default learning rate (e.g., 0.001) for fast convergence.
*   **Strategy**: Train for a fixed number of epochs (e.g., 50) but implement **Early Stopping** monitoring the validation loss. If the validation loss does not improve for a set number of epochs (patience), stop training and restore the best weights. This ensures the model remains lightweight and does not overfit.

## Evaluation
1.  **Preprocessing**: Apply the same angle imputation (using training mean), 3-channel construction, and normalization steps to the test dataset.
2.  **Inference**: Pass the processed test data through the trained model to generate probability predictions.
3.  **Submission**: Format the output IDs and predicted probabilities into a CSV file as required.
