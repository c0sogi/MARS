Based on the comprehensive analysis of previous attempts and the derived lessons, I propose the **Full-Data ResNet-18 Ensemble with Stochastic Weight Averaging (SWA)**.

This solution structurally evolves the training pipeline to resolve the critical conflict between **Data Scarcity** (Lesson 00020) and **Optimization Stability** (Lesson 00041). Previous "Full-Fit" attempts failed because "Fixed Epoch Replay" led to underfitting; the models were stopped too early based on noisy cross-validation averages. This proposal introduces **Stochastic Weight Averaging (SWA)** as a robust mechanism to extend training on the full dataset *beyond* the estimated stopping point, averaging the weights to find a flat, generalized minimum without requiring a validation set.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants (ResNet-34) or depthwise-separable architectures (EfficientNet) for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline:
    *   **RandomRotate90** (Discrete rotations) (Cite solution_lesson_node_00028).
    *   **Rotate** with a limit of $\pm 20^{\circ}$ (Continuous rotation) (Cite solution_lesson_node_00031).
    *   Horizontal and Vertical Flips.
    *   We will **not** use Mixup, as it was proven detrimental on this dataset (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Protocol** that leverages SWA to safely train on 100% of the data.

**Phase 1: Calibration (Epoch Estimation)**
*   **Objective:** Determine the "Convergence Epoch" ($E_{conv}$) where the model stabilizes.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimization:** Use **AdamW** (`weight_decay=0.01`) with a **Batch Size of 32** and a **ReduceLROnPlateau** scheduler (Cite solution_lesson_node_00038, solution_lesson_node_00009).
*   **Selection:** Identify $E_{conv}$ as the epoch where the validation loss (evaluated with TTA) minimizes (Cite solution_lesson_node_00025).

**Phase 2: Production (Full-Fit SWA)**
*   **Objective:** Train 5 independent models on **100% of the training data** (Train + Validation combined).
*   **Standard Stage:** Train for $E_{conv}$ epochs using the standard AdamW + Scheduler setup to reach the convergence region.
*   **SWA Stage (Structural Innovation):** Continue training for an additional $K$ epochs (e.g., 10-15) using a **constant or cyclical learning rate**. At the end of each epoch in this stage, update the **Stochastic Weight Averaging (SWA)** model.
    *   **Rationale:** This allows the model to explore the loss basin on the full dataset. Even if $E_{conv}$ is slightly inaccurate, SWA averages the trajectory, finding the "flat" center of the minimum which generalizes better than any single point estimate (Cite solution_lesson_node_00041).

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views (Cite solution_lesson_node_00031).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SWA models**.
