Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Calibrated SWA-ResNet Ensemble with Geometric Consistency Regularization**.

This solution structurally evolves the successful **SWA Ensemble** (Idea 13) by integrating **Geometric Consistency Regularization**. This addresses the "Invariance vs. Regularization" trade-off (Lesson 00006, 00030) by explicitly enforcing that the model's predictions remain stable across geometric transformations within the loss function itself, rather than relying solely on stochastic data augmentation. It retains the robust optimization protocols of Idea 13 while adding a mechanism to close the "TTA-Validation Gap" (Lesson 00025) during training.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input. This ensures the lower-magnitude HV band contributes equally to the structural features (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ a robust geometric augmentation pipeline including **RandomRotate90** and **Continuous Rotation** ($\pm 20^{\circ}$) (Cite solution_lesson_node_00028, solution_lesson_node_00031). We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Protocol** incorporating Consistency Regularization and SWA.

**Phase 1: Calibration (Global Epoch Selection)**
*   **Objective:** Determine the "Convergence Epoch" ($E_{conv}$) where the model stabilizes.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimization:** **AdamW** (`weight_decay=0.01`) with a **Gentle Scheduler** (`ReduceLROnPlateau`, factor 0.5) to ensure prolonged convergence without premature freezing (Cite solution_lesson_node_00065).
*   **Selection:** Identify $E_{conv}$ as the epoch where the average validation loss minimizes (Cite solution_lesson_node_00040).

**Phase 2: Production (Full-Fit SWA with Consistency)**
*   **Objective:** Train 5 independent models on **100% of the training data**.
*   **Consistency Loss (Structural Innovation):** For each training batch $x$, we will generate an augmented view $x' = T(x)$ (using flips/rotations). The loss function will be:
    $$L = \text{BCEWithLogits}(f(x), y) + \lambda \cdot ||\sigma(f(x)) - \sigma(f(x'))||^2$$
    This explicitly penalizes the model for changing its prediction based on orientation, enforcing the invariance required for TTA success directly during optimization (Cite solution_lesson_node_00025). We use **Label Smoothing** ($\epsilon=0.05$) in the BCE term (Cite solution_lesson_node_00065).
*   **SWA Schedule:** Train for $E_{conv}$ epochs using the standard schedule, then continue for 12 epochs using **Stochastic Weight Averaging (SWA)** with a constant learning rate. This ensures the model settles into a flat, robust minimum (Cite solution_lesson_node_00049) and avoids the "premature SWA" failure mode (Cite solution_lesson_node_00063).

# Evaluation
*   **Exhaustive Test Time Augmentation (TTA):** For every test image, we will generate predictions using the Original, Horizontal Flip, and Vertical Flip views (Cite solution_lesson_node_00031).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SWA models**.
