Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Calibrated SAM-SWA ResNet Ensemble with Dual-Domain Augmentation**.

This solution structurally evolves the successful **Full-Fit SWA** strategy (Idea 13) by integrating **Sharpness-Aware Minimization (SAM)**. It directly addresses the failure of Idea 23 (which failed due to a checkpointing implementation error, Cite solution_lesson_node_00089) by embedding SAM into a continuous training trajectory. This combines SAM's active search for flat minima during convergence with SWA's trajectory averaging, maximizing generalization on this small, noisy dataset.

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001). We avoid complex gating mechanisms (Cite solution_lesson_node_00082).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Dual-Domain Augmentation:** We will employ a hybrid augmentation pipeline to ensure full geometric invariance:
    *   **Discrete:** `RandomRotate90` to cover the cardinal axes (Cite solution_lesson_node_00028).
    *   **Continuous:** `ShiftScaleRotate` with a limit of $\pm 20^{\circ}$ to smooth the decision boundary (Cite solution_lesson_node_00031).
    *   **Flips:** Horizontal and Vertical Flips.
    *   We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement a **Two-Phase Protocol** using the **SAM Optimizer** to ensure convergence to flat minima.

**Phase 1: Calibration (Global Epoch Selection)**
*   **Objective:** Determine the optimal convergence epoch ($E_{conv}$).
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimizer (Structural Innovation):** **SAM (Sharpness-Aware Minimization)** wrapping **AdamW** (`lr=2e-4`, `weight_decay=0.01`). SAM performs dual forward/backward passes to minimize both loss value and sharpness ($\rho=0.05$).
*   **Scheduler:** `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**. This ensures deep convergence without premature freezing (Cite solution_lesson_node_00065, solution_lesson_node_00070).
*   **Selection:** Identify $E_{conv}$ as the epoch that minimizes the **TTA-Validation Loss** (average of Original + Flips) (Cite solution_lesson_node_00025).

**Phase 2: Production (Full-Fit SAM-SWA)**
*   **Objective:** Train 5 independent models on **100% of the training data** (Train + Validation combined).
*   **Continuous Trajectory:** Train from scratch for exactly $E_{conv}$ epochs using SAM and the hyperparameter dynamics from Phase 1. Then, immediately transition to **Stochastic Weight Averaging (SWA)** for an additional 12 epochs.
*   **Correction:** We explicitly **do not reload checkpoints**. The model transitions directly from the SAM convergence phase to the SWA averaging phase. This avoids the optimizer state mismatch that caused the failure in Idea 23 (Cite solution_lesson_node_00089).
*   **Loss Function:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) (Cite solution_lesson_node_00065).

# Evaluation
*   **Exhaustive Closed-Group TTA:** For every test image, we will generate predictions using the **Klein Four-Group**: Original, Horizontal Flip, Vertical Flip, and Rotate180 (composed flips). This ensures the ensemble average is mathematically invariant to the cardinal symmetries (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the TTA-averaged probabilities from the **5 Full-Fit SAM-SWA models**.
