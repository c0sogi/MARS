This script demonstrates the usage of the provided library modules for the Iceberg Classifier task. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration parameters to enable a fast "debug" mode (fewer epochs, smaller dataset subset) suitable for demonstration.
2.  **Dataset Verification**: Loads the training dataset, verifies the data shapes (images, angles, labels), and ensures the data loading pipeline functions correctly.
3.  **Model Initialization**: Instantiates the `IcebergResNet` model and performs a dummy forward pass to verify architecture and tensor shapes.
4.  **Training Simulation**: Executes a single fold training run using `run_fold`. This demonstrates the training loop, loss calculation, and checkpointing.
5.  **Inference and Submission**: Loads the test dataset, generates predictions using the trained model, and creates a submission file in the required format.
