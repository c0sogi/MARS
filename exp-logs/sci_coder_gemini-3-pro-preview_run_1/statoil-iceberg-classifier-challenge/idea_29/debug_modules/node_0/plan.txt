The following script demonstrates the usage of the provided library components to solve the Iceberg Classification task.

**Implementation Strategy:**
1.  **Configuration Overrides**: We dynamically modify the `Config` class attributes to reduce the computational load (fewer epochs, fewer folds, smaller batch size) suitable for a quick demonstration while maintaining the logic's integrity.
2.  **Data Loading & Verification**: We utilize `load_dataset` to prepare the training data and verify the structure of the `IcebergDataset` (image shapes, angle normalization, and label format).
3.  **Model Instantiation**: We initialize the `IcebergResNet18` model and perform a dummy forward pass to confirm the architecture (Backbone + Global Pooling + Late Fusion) functions correctly on the GPU.
4.  **Calibration Phase (Phase 1)**: We execute `run_calibration_phase` with the reduced hyperparameters. This demonstrates the Stratified K-Fold Cross-Validation and learning rate scheduling logic.
5.  **Production Phase (Phase 2)**: Instead of running the full 5-model ensemble loop (which is redundant for a demo), we manually execute `train_full_fit` for a single model using the convergence epoch determined in Phase 1. This demonstrates the Cosine Annealing and SWA (Stochastic Weight Averaging) training protocol.
6.  **Inference & Submission**: We use the trained model checkpoint to generate predictions on the test set via `generate_submission`, utilizing the Klein Test-Time Augmentation (TTA) implemented in the library.
7.  **Validation**: Assertions are placed throughout to verify shapes, file existence, and data integrity.
