Based on the comprehensive analysis of the previous attempts and the derived lessons, I propose the **Symmetrized SWA-ResNet Ensemble with Integrated Group-Inference Training**.

This solution introduces a **Symmetrized Forward Pass** as the primary structural innovation. Instead of treating geometric invariance as solely a data augmentation task or an inference-time trick (TTA), this approach embeds the **Closed Symmetry Group** (Lesson 00074) directly into the model's training objective. By optimizing the average prediction of the symmetry group during training, we align the optimization landscape with the inference strategy (Lesson 00025) and enforce robust invariance without the optimization conflicts of auxiliary consistency losses (Lesson 00066).

# Model
*   **Backbone Architecture:** We will utilize the **ResNet-18** architecture pretrained on ImageNet. We strictly adhere to the finding that shallow, dense convolutional networks are superior to deeper variants or depthwise-separable architectures for this small, noisy dataset (Cite solution_lesson_node_00008, solution_lesson_node_00012).
*   **Pooling Strategy:** We will use standard **Global Average Pooling (GAP)**. We explicitly reject Dual-Stream (Max+Avg) pooling, as Max Pooling amplifies speckle noise in SAR imagery (Cite solution_lesson_node_00019).
*   **Late Fusion:** We will retain the **Late Fusion** strategy. The scalar `inc_angle` will be normalized and concatenated with the 512-dimensional GAP feature vector (Cite solution_lesson_node_00001).
*   **Minimalist Classification Head:** The fused vector will be passed to a **Minimalist Head** consisting of Batch Normalization, **Dropout (rate 0.5)**, and a single Linear layer. We explicitly avoid complex MLP heads to prevent overfitting (Cite solution_lesson_node_00024).
*   **Meta-Architecture (Structural Innovation):** We will implement a **Symmetrized Forward Pass**. For every input image $x$, the model will internally generate a batch of 4 views corresponding to the **Klein Four-Group**: $\{Original, FlipLR, FlipUD, Rotate180\}$ (Cite solution_lesson_node_00074). The backbone will process all 4 views (sharing weights), and the resulting logits will be **averaged** to produce the final prediction used for loss calculation. This directly optimizes the ensemble performance of the geometric group.

# Data
*   **Independent Band Normalization:** We will construct the 3-channel input by strictly following the "Normalize then Average" logic:
    1.  Apply **Global Min-Max Normalization** to Band 1 (HH) using training set statistics.
    2.  Apply **Global Min-Max Normalization** to Band 2 (HV) using training set statistics.
    3.  Compute the **Composite Band** as the arithmetic mean of the *normalized* Band 1 and Band 2.
    4.  Stack them to form the input (Cite solution_lesson_node_00037, solution_lesson_node_00021).
*   **Bicubic Upsampling:** The 75x75 images will be upsampled to **224x224** using **Bicubic Interpolation** to preserve high-frequency texture details (Cite solution_lesson_node_00035).
*   **Augmentation:** We will employ **Continuous Rotation** ($\pm 20^{\circ}$) and **Random Shift/Scale** as base augmentations applied *before* the symmetry group generation. This ensures the model learns invariance to arbitrary poses (Cite solution_lesson_node_00031) while the Symmetrized Forward Pass handles the cardinal symmetries. We will **not** use Mixup (Cite solution_lesson_node_00030).

# Training
We will implement the **Two-Phase Protocol** established as the most robust strategy for this dataset (Cite solution_lesson_node_00040, solution_lesson_node_00055).

**Phase 1: Calibration (Global Epoch Selection)**
*   **Objective:** Determine the optimal convergence epoch ($E_{conv}$) for the Symmetrized Architecture.
*   **Method:** Run **Stratified 5-Fold Cross-Validation**.
*   **Optimization:** **AdamW** (`weight_decay=0.01`) with a **Batch Size of 32** (Cite solution_lesson_node_00038).
*   **Scheduler:** Use `ReduceLROnPlateau` with a **Gentle Decay Factor (0.5)** and **High Patience (10 epochs)**. This ensures the model converges deeply without the premature freezing observed with aggressive schedules (Cite solution_lesson_node_00065, solution_lesson_node_00070).
*   **Selection:** Identify $E_{conv}$ as the epoch that minimizes the average validation loss.

**Phase 2: Production (Full-Fit SWA)**
*   **Objective:** Train 5 independent models on **100% of the training data** (Train + Validation combined).
*   **Standard Stage:** Train for exactly $E_{conv}$ epochs using the hyperparameter dynamics derived from Phase 1.
*   **SWA Stage:** Continue training for an additional 12 epochs using **Stochastic Weight Averaging (SWA)** with a constant learning rate. This flattens the loss landscape and improves generalization (Cite solution_lesson_node_00049).
*   **Loss Function:** **BCEWithLogitsLoss** with **Label Smoothing** ($\epsilon=0.05$) (Cite solution_lesson_node_00065).

# Evaluation
*   **Inference:** For each test image, we will generate the same **4-view Klein Group** used in training ($Original, FlipLR, FlipUD, Rotate180$) and average the predictions (Cite solution_lesson_node_00074).
*   **Ensemble Aggregation:** The final submission will be the arithmetic mean of the probabilities from the **5 Full-Fit SWA models**.
