Based on the comprehensive analysis of the provided lessons, I propose the **Holistic Interleaved Transformer (HIT)**. This strategy evolves the successful "Interleaved Gap-Token" architecture by integrating **Rotary Positional Embeddings (RoPE)** and a **Contextual Regularization** objective.

This approach directly addresses the "Syntax/Semantics Entanglement" (Cite solution_lesson_node_00017) and "Error Propagation" (Cite solution_lesson_node_00021) issues by strengthening the shared encoder via auxiliary supervision while keeping the inference pipeline clean and decoupled.

# Model
The architecture is a **Multi-Head Transformer Encoder** with **Rotary Positional Embeddings** and **Tied Weights**.

1.  **Input Topology**: We retain the **Interleaved Gap-Token** strategy (Cite solution_lesson_node_00015). The input sequence is constructed by inserting a learnable `[GAP]` token between every pair of words (e.g., `[w1, GAP, w2, GAP, w3]`). This explicitly reifies the transition space.
2.  **Backbone with RoPE**: Instead of absolute positional embeddings, we employ **Rotary Positional Embeddings (RoPE)** in the Transformer Encoder. RoPE effectively encodes relative distances, which is crucial for the interleaved structure where the "gap" concept relies heavily on the immediate adjacency of neighboring words.
3.  **Hard Parameter Sharing**: We use a single deep encoder for all tasks (Cite solution_lesson_node_00017), ensuring that features learned for language understanding are directly available for gap detection.
4.  **Triple-Head Output**:
    *   **Localization Head**: Attached to `[GAP]` tokens. A binary classifier (Sigmoid) predicting $P(Missing | Gap_i)$. We use the **Local Objective** (BCE) as it outperforms global constraints for detection (Cite solution_lesson_node_00016).
    *   **Identification Head**: Attached to `[GAP]` tokens. A multi-class classifier predicting the missing word ID.
    *   **Context Reconstruction Head (Auxiliary)**: Attached to the *original word tokens*. A multi-class classifier predicting the identity of masked context words (Masked Language Modeling).
5.  **Weight Tying**: The Input Embedding Matrix is tied (shared) with the Output Dense Layers of both the Identification Head and the Context Reconstruction Head. This maximizes parameter efficiency and ensures semantic alignment.

# Data
1.  **Vocabulary**: Construct a fixed vocabulary of the top $K$ (e.g., 50,000) frequent words from `train_v2.txt`.
2.  **Dynamic Dual-Masking**:
    *   Sample a sentence from the training set.
    *   **Task Masking**: Select one word uniformly to remove (the "Target Missing Word"). This creates the primary supervision signal.
    *   **Regularization Masking**: Randomly mask 15% of the *remaining* context words (replace with a special `[MASK]` token). This creates the auxiliary supervision signal.
    *   **Interleaving**: Insert `[GAP]` tokens between the masked/unmasked words.
3.  **Targets**:
    *   **Localization**: 1 at the `[GAP]` corresponding to the "Target Missing Word", 0 elsewhere.
    *   **Identification**: The ID of the "Target Missing Word".
    *   **Context Reconstruction**: The IDs of the words replaced by `[MASK]`.

# Training
1.  **Multi-Task Objective**: The loss function is $L = \lambda_{loc}L_{Loc} + \lambda_{id}L_{ID} + \lambda_{aux}L_{Aux}$.
    *   $L_{Loc}$: **Weighted Binary Cross-Entropy** on the Localization Head (Cite solution_lesson_node_00003).
    *   $L_{ID}$: **Masked Cross-Entropy** on the Identification Head, calculated *only* at the true missing word gap (Cite solution_lesson_node_00015).
    *   $L_{Aux}$: **Masked Cross-Entropy** on the Context Reconstruction Head, calculated *only* at the `[MASK]` positions.
2.  **Optimization**: Use AdamW with a One-Cycle learning rate scheduler. The auxiliary task forces the model to learn robust bidirectional context representations (like BERT) which directly improves the quality of the gap embeddings, without requiring the "Bifurcation" that failed in Lesson 00017.

# Evaluation
1.  **Pruned Inference**:
    *   Preprocess the test sentence by interleaving `[GAP]` tokens. **Do not** apply the "Regularization Masking" (keep all context words visible).
    *   Forward pass to obtain Localization probabilities $P_{Loc}$ and Identification probabilities $P_{ID}$.
    *   **Discard the Context Reconstruction Head**. We strictly follow the insight from Lesson 00021: use the auxiliary task *only* for regularization during training to shape the encoder, but do not use its output to gate or modify the score during inference.
2.  **Score Fusion**:
    *   Compute the insertion score for word $w$ at gap $i$: $Score_{i,w} = P_{Loc}(i) \times P_{ID}(w | i)$.
    *   Select the tuple $(i, w)$ with the maximum score and reconstruct the sentence.
