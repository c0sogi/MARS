# Optimized Strategy: Global-Context Transformer for Dense Gap Infilling

## Model
To address the limitations of the previous CNN-based approach, I propose replacing the backbone with a **Word-Level Transformer Encoder**. While the **Dense Gap Classification** strategy (Cite solution_lesson_node_00003) proved effective for efficiency and handling unknown locations, the CNN lacked the capacity to model long-range semantic dependencies essential for correct word selection in complex sentences.

- **Architecture**: A Transformer Encoder (trained from scratch) with approximately 6-8 layers, 512 hidden units, and 8 attention heads.
- **Input**: The model accepts a sequence of word indices derived from a custom word-level vocabulary. This aligns perfectly with the whitespace-tokenized nature of the dataset and avoids subword tokenization artifacts.
- **Output Head**: A dense classification layer projects the hidden state of each token $i$ to a probability distribution over the entire vocabulary $V$ plus a special `[NO_INSERT]` class. This predicts the word to be inserted *immediately after* token $i$.
- **Strategic Retention**: The model retains the **single-pass inference mechanism** (Cite solution_lesson_node_00003), predicting predictions for all potential gaps simultaneously rather than using iterative masking.

## Data
- **Vocabulary Construction**: Create a vocabulary from the top $K$ (e.g., 60,000) most frequent words in `train_v2.txt`. Rare words are mapped to `[UNK]`. This ensures the model focuses on the most likely candidates for insertion.
- **Dynamic Training Samples**: Instead of a static dataset, use an online generator:
    1.  Read a sentence from the massive training corpus.
    2.  Uniformly select a word to remove (excluding the first and last words).
    3.  Generate the input sequence (sentence with word removed) and the target sequence.
    4.  **Target Definition**: For an input of length $L$, the target is a sequence of length $L$. If the word was removed after input word $i$, the target at index $i$ is the removed word's ID. All other target indices are labeled `[NO_INSERT]`.

## Training
- **Loss Function**: Employ **Weighted Cross-Entropy Loss** (Cite solution_lesson_node_00003). Given that valid insertions are sparse (1 per sentence) compared to `[NO_INSERT]` (N-1 per sentence), apply a significant down-weight (e.g., 0.05) to the `[NO_INSERT]` class to force the model to learn the insertion signal.
- **Optimization**: Use the AdamW optimizer with a "One Cycle" learning rate schedule (warmup followed by cosine decay) to rapidly converge on the large dataset within the 24-hour limit.
- **Compute Efficiency**: Leverage the NVIDIA A100 GPU with Automatic Mixed Precision (AMP) to maximize batch size (e.g., 512+), ensuring the model sees a large portion of the 30M training sentences.

## Evaluation
- **Inference Pipeline**:
    1.  Tokenize the test sentence.
    2.  Forward pass to obtain logits of shape $(L, |V|+1)$.
    3.  **Global Decoding**: Apply a mask to zero out probabilities for the `[NO_INSERT]` class and invalid boundary positions (first/last gaps).
    4.  Find the single `(position, word_id)` tuple with the maximum logit value across the entire matrix.
    5.  Reconstruct the sentence by inserting the predicted word at the predicted position.
- **Validation**: Periodically compute the Levenshtein distance on the validation set to monitor progress, as this is the competition metric.
