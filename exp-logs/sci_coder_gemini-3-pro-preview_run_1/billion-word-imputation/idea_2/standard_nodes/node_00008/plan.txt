The following script implements the end-to-end orchestration for the Gap Infilling task.

**Implementation Strategy:**
1.  **Setup & Configuration**: The script initializes by setting random seeds for reproducibility and configuring a logger. It overrides default `Config` parameters to establish a "Fast Baseline" strategy, specifically setting `EPOCHS` to 1 and `BATCH_SIZE` to 512 to utilize the A100 GPU efficiently.
2.  **Data Loading & Optimization**: It loads the vocabulary and data loaders using the provided library functions with caching enabled. To ensure the training completes well within the 2-hour limit, the training dataset is explicitly truncated to 500,000 samples.
3.  **Model Training**: The `GapTransformer` is initialized and trained using the `run_training` engine function. This function handles the training loop, loss calculation (with class weighting), and optimization.
4.  **Validation**: After training, the script computes the final validation metric (average Levenshtein distance) on the full hold-out validation set and prints it in the strict format required (`Final Validation Metric: <value>`).
5.  **Failure Analysis**: The script performs a failure analysis by iterating over a subset (10,000 samples) of the validation set. It calculates the correlation between the input sentence length and the error magnitude (Levenshtein distance) to identify performance characteristics relative to sequence length.
6.  **Submission Generation**: Finally, it checks if the validation metric is below the threshold of 7.70033. If the condition is met, it generates predictions for the test set and saves the `submission.csv` file using the `generate_submission` function.
