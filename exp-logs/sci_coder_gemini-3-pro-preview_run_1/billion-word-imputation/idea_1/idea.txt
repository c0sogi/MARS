To establish a robust and efficient baseline for the sentence infilling task, I propose a **Gated Convolutional Sequence Labeler**. This approach leverages 1D Convolutional Neural Networks (CNNs) to process text, offering a distinct architectural alternative to the Transformer, RNN, and statistical models previously suggested. It prioritizes training speed and inference throughput while explicitly addressing the challenge of the unknown missing word location.

### Model
The architecture is a **Fully Convolutional Network (FCN)** designed for sequence labeling.
*   **Embedding Layer**: The input sentence is converted into a sequence of dense vectors using a learnable embedding matrix.
*   **Convolutional Encoder**: The core consists of a stack of **1D Convolutional blocks**. Each block employs a sliding window (kernel size 3-5) to capture local context around every potential gap. To effectively propagate information and prevent vanishing gradients, the blocks utilize **Gated Linear Units (GLU)** for non-linearity and **Residual Connections**. This hierarchical structure allows the model to aggregate context from the entire sentence without the computational overhead of self-attention or the sequential dependency of RNNs.
*   **Gap-Classification Head**: The output of the encoder is projected to a classification layer that produces a probability distribution over the vocabulary for *every* inter-word gap in the sentence. Crucially, the vocabulary is augmented with a special **`[NO_INSERT]`** token. This allows the model to explicitly predict "no word missing here" for intact gaps, and predict the specific missing word for the target gap.

### Data
*   **Preprocessing**:
    *   Construct a vocabulary from the top $K$ most frequent words in the training set (e.g., 30,000).
    *   Add special tokens: `[UNK]` for out-of-vocabulary words and `[NO_INSERT]` to represent gaps where no word should be inserted.
    *   Tokenize data using simple whitespace splitting, matching the provided dataset format.
*   **Dynamic Sample Generation**:
    *   Instead of static files, use an online data generator during training. For each training batch, read original sentences and uniformly select one word to remove (excluding the first and last words, per the task constraints).
    *   Create the target label sequence corresponding to the gaps in the input. The gap at the removed location is labeled with the ID of the removed word. All other gaps are labeled with the `[NO_INSERT]` ID.

### Training
*   **Objective**: Minimize the **Weighted Cross-Entropy Loss** across all gap positions.
*   **Class Balancing**: Since the vast majority of gaps (approx. 95%+) are `[NO_INSERT]`, the loss function will assign a lower weight to the `[NO_INSERT]` class or a higher weight to the word classes. This prevents the model from converging to a trivial solution where it predicts "no insertion" everywhere.
*   **Optimization**: Use the AdamW optimizer with a learning rate scheduler (e.g., OneCycleLR) to ensure rapid convergence within the 24-hour limit.

### Evaluation
*   **Inference**:
    *   Feed the test sentence (with the missing word) into the model.
    *   Obtain the output probability matrix of shape $(N+1, |V|)$, where $N$ is the sequence length.
*   **Decoding**:
    *   Mask the probabilities for the first and last gap positions (setting them to zero), as the task description guarantees the missing word is not there.
    *   Mask the `[NO_INSERT]` column in the probability matrix.
    *   Select the single entry `(gap_index, word_id)` with the maximum probability across the entire matrix.
    *   Insert the predicted word at the predicted gap index to reconstruct the sentence.
