2.  **Data Generation**:
    *   We will create tiny synthetic datasets (Train, Validation, Test) containing simple English sentences. This ensures the code runs quickly and we have ground truth for logic verification.

4.  **Pipeline Execution**:
    *   **Training**: We will initialize the `Trainer` and run it for a single epoch. We will verify that the model saves a checkpoint (`best_model.pth`).
    *   **Inference**: We will initialize the `Predictor` (which loads the saved checkpoint) and generate predictions for the synthetic test set.
    *   **Submission**: We will verify that the submission file is created and follows the required CSV format.

5.  **Cleanup**: The script operates within `./working/demo_execution` and leaves artifacts there for inspection if needed.
