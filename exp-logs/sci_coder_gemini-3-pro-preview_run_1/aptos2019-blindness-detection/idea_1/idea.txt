To establish a highly efficient and robust baseline, I propose an **Ordinal Regression CNN** approach. This method synthesizes the convolutional feature extraction found in the provided architectures with a rank-consistent classification strategy, distinct from the pure regression (Model 1) or hybrid/ensemble methods (Models 2 & 3). It is designed to directly address the ordinal nature of the diabetic retinopathy severity scale (0 to 4) and the Quadratic Weighted Kappa metric while minimizing computational overhead.

### Model
The architecture utilizes **MobileNetV3-Small** as a lightweight, pre-trained backbone to extract visual features. This choice prioritizes inference speed and low parameter count over the heavier EfficientNet or Transformer architectures listed previously.
- **Backbone**: MobileNetV3-Small (pre-trained on ImageNet), with the final classification layer removed.
- **Head**: A simple fully connected layer with **4 output units** and **Sigmoid** activations.
- **Logic**: Unlike standard multi-class classification (which treats classes as independent) or direct regression (which assumes linearity), this model performs **ordinal decomposition**. The $k$-th output unit predicts the probability that the disease severity is **greater than** $k$ (i.e., $P(y > k)$).
    - Unit 1: Is severity > 0?
    - Unit 2: Is severity > 1?
    - Unit 3: Is severity > 2?
    - Unit 4: Is severity > 3?

### Data
1.  **Preprocessing**:
    -   **Resizing**: All images are resized to a fixed resolution of **256x256** pixels. This resolution is sufficient to detect major retinal features while ensuring rapid data loading and processing.
    -   **Normalization**: Pixel values are normalized using standard ImageNet mean and standard deviation to align with the pre-trained backbone.
2.  **Label Encoding**:
    -   Target labels are converted into **ordinal vectors** of length 4.
    -   *Example*: A label of **2** (Moderate) is encoded as `[1, 1, 0, 0]` (implying >0 is True, >1 is True, >2 is False, >3 is False).
    -   *Example*: A label of **0** (No DR) is encoded as `[0, 0, 0, 0]`.

### Training
-   **Loss Function**: The model is trained using **Binary Cross Entropy (BCE)** loss, summed across the 4 output units. This forces the model to learn the rank-consistent probabilities independently for each threshold.
-   **Optimizer**: **AdamW** is used for optimization to handle weight decay effectively, combined with a simple learning rate scheduler (e.g., Cosine Annealing) to ensure convergence.
-   **Strategy**: Training is performed for a fixed, small number of epochs (e.g., 10-15) with minimal augmentation (random horizontal flips) to maintain high throughput and avoid the computational cost of complex augmentations.

### Evaluation
-   **Inference**: For each test image, the model outputs 4 probabilities.
-   **Decoding**: The final predicted score is obtained by **summing the 4 probabilities**. This results in a continuous value between 0 and 4.
    -   *Example*: Outputs `[0.9, 0.8, 0.2, 0.1]` sum to `2.0`.
-   **Final Prediction**: The continuous sum is **rounded to the nearest integer** to produce the final class label (0, 1, 2, 3, or 4). This method is statistically robust for maximizing Quadratic Weighted Kappa as it naturally handles uncertainty between adjacent classes.
