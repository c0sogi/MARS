1.  **Configuration Override**: I will import the `Config` class and override specific attributes (debug mode, image size, batch size, backbone, epochs) to ensure the script runs quickly and consumes minimal resources while still exercising the full pipeline.

3.  **Data Pipeline Verification**: I will generate dataloaders using `create_dataloaders` and fetch a single batch to verify tensor shapes and data types (images as float tensors, targets as ordinal vectors).
4.  **Model Instantiation**: I will initialize the `OrdinalEfficientNet` with a lightweight backbone (`resnet18`) and no pre-trained weights to avoid network overhead. I will perform a forward pass with the fetched batch to verify output dimensions and value ranges (probabilities).
5.  **Training Loop Execution**: I will set up the optimizer and scheduler, then run `train_model` for a single epoch on the debug subset. This verifies the integration of the engine, loss calculation, and backpropagation.
6.  **Checkpoint Validation**: I will assert that the training loop successfully saved a `best_model.pth` checkpoint.
7.  **Inference & Submission**: I will load the saved checkpoint into a fresh model instance and run `generate_submission`. I will verify the output CSV's existence and schema.
8.  **Metric Logic Check**: I will run a standalone test of the `quadratic_weighted_kappa` function with known inputs to confirm metric correctness.
