The issue stems from Python's default argument evaluation behavior. In `library/utils.py`, the functions `save_checkpoint` and `load_checkpoint` define `filename=config.MODEL_SAVE_PATH` in their signatures. This default value is evaluated and bound once when the module is imported. Consequently, when `runfile.py` modifies `config.MODEL_SAVE_PATH` at runtime, the `utils` functions continue to use the old path (the value at import time) because they were called without an explicit `filename` argument.

To fix this, I will modify `save_checkpoint` and `load_checkpoint` in `library/utils.py` to set `filename` to `None` by default. Inside the function body, I will check if `filename` is `None` and assign it the current value of `config.MODEL_SAVE_PATH`. This ensures the path is resolved at runtime, reflecting any updates made to the configuration.
