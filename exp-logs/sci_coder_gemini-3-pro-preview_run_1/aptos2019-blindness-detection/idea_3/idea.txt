Based on the comprehensive analysis of previous experiments and the specific failure modes identified, I propose the following optimized strategy.

# Model
*   **Backbone Architecture:** Adopt **ConvNeXt-Tiny** (or Small) as the feature extractor.
    *   *Structural Innovation:* This marks a shift from the Batch Normalization-heavy architectures (EfficientNet/MobileNet) used previously to a modern CNN architecture that utilizes **Layer Normalization**.
    *   *Rationale:* Previous attempts to increase image resolution failed because the resulting small batch sizes destabilized Batch Normalization statistics `Cite solution_lesson_node_00007`. Since Layer Normalization computes statistics per sample rather than per batch, ConvNeXt allows us to train on higher resolution inputs with smaller batch sizes without the performance degradation associated with "micro-batches" in EfficientNet.
*   **Classification Head:** Retain the **Rank-Consistent Ordinal Regression Head**.
    *   *Structure:* A Global Average Pooling layer followed by a dense layer with 4 output units and Sigmoid activations.
    *   *Rationale:* This approach has consistently proven superior to standard classification for the ordered nature of diabetic retinopathy severity and the Quadratic Weighted Kappa metric `Cite solution_lesson_node_00001`.

# Data
*   **Resolution:** Increase input size to **384x384 pixels**.
    *   *Rationale:* Correlation analysis confirmed that the previous 256x256 resolution was a primary bottleneck, discarding fine-grained diagnostic features `Cite solution_lesson_node_00005`. The switch to a LayerNorm-based backbone makes this resolution increase computationally feasible without statistical instability.
*   **Preprocessing:** Apply **Pad-to-Square** resizing.
    *   *Method:* Instead of stretching images or cropping them, pad the shorter dimension with black pixels to make the image square, then resize to 384x384.
    *   *Rationale:* Previous attempts at "smart cropping" introduced variable geometric distortions (changing aspect ratios) which hurt performance `Cite solution_lesson_node_00009`. Padding ensures that the circular geometry of the eye is perfectly preserved across all samples, maintaining geometric consistency.
*   **Augmentation:** Utilize a full geometric augmentation suite: **Random Vertical Flips**, **Random Horizontal Flips**, and **Random 90-degree Rotations**.
    *   *Rationale:* Fundus images are rotationally invariant. Explicitly modeling this symmetry is a proven method to improve generalization `Cite solution_lesson_node_00004`.

# Training
*   **Loss Function:** **Binary Cross Entropy (BCE)** loss summed across the 4 ordinal output units.
*   **Optimizer:** **AdamW** with weight decay to prevent overfitting.
*   **Strategy:** Train for approximately 10-15 epochs. Given the use of ConvNeXt, the batch size can be set to the maximum that fits in GPU memory (likely 16-24) without worrying about the strict "minimum batch size" requirements of Batch Normalization.

# Evaluation
*   **Inference:** Generate 4 probability scores for each test image.
*   **Decoding:** Sum the probabilities to obtain a continuous severity score (0-4) and **round to the nearest integer**. This remains the most robust method for maximizing the QWK metric `Cite solution_lesson_node_00001`.
