The following script performs the required metadata generation and validation tasks.

**Strategy:**
1.  **Setup**: Define input and output directories. Ensure the `./metadata` directory exists.
2.  **Data Loading**: Read `train.csv` and `test.csv` from the `./input` directory using pandas.
3.  **Path Construction**: Create a `file_path` column for each dataset by appending the appropriate directory prefix (`train_images/` or `test_images/`) and the `.png` extension to the `id_code`. These paths are relative to `./input`.
4.  **Splitting**: Perform a stratified 80/20 split on the training data using `sklearn.model_selection.train_test_split` with `RANDOM_STATE=42` to create training and validation sets. This ensures the class distribution of `diagnosis` is preserved.
5.  **Saving**: Save the resulting dataframes (`train`, `val`, `test`) to CSV files in the `./metadata` directory.
6.  **Validation**:
    *   **Reload**: Load the newly created metadata files.
    *   **Statistics**: Print shapes and class distributions.
    *   **File Existence**: Randomly sample 1000 paths from each set and verify they exist in `./input`. Raise an error if the missing ratio exceeds 0.5.
    *   **Stratification Check**: Compare the class probability distributions of the train and validation sets. Raise an `AssertionError` if they differ significantly (tolerance > 1%).
