The strategy involves implementing a streamlined orchestration script `runfile.py` that leverages the pre-defined components in the `library` module. The script will execute a complete machine learning pipeline: setting up the environment, loading data, training the `DebertaDualEncoder` model, validating performance, performing failure analysis, and conditionally generating a submission.

**Key Steps:**
1.  **Configuration & Setup:** Initialize the random seed and device. Override the default epoch count to 3 to ensure the "fast baseline" requirement is met while still allowing sufficient convergence on the small dataset (~4.4k samples).
2.  **Data Loading:** Utilize `get_dataloaders` with `load_cached_data=True` to efficiently load pre-processed training, validation, and test sets.
3.  **Training Loop:** Implement a standard training loop using `train_fn` and `eval_fn`. The optimizer and scheduler are configured with differential learning rates as defined in `train.py`. The best model state is saved based on the validation Spearman correlation.
4.  **Validation & Metrics:** After training, reload the best model and perform a full evaluation on the validation set. The script will strictly output the `Final Validation Metric` in the required format.
5.  **Failure Analysis:** Load the validation dataframe and predictions to calculate the Mean Absolute Error (MAE) for each sample. Compute and print Spearman correlations between this error magnitude and key features (text lengths, metadata categories) to identify systematic weaknesses.
6.  **Conditional Submission:** Compare the final validation metric against the threshold (`0.40802662717842303`). If the model performs sufficiently well, generate predictions for the test set using `inference_fn` and save the formatted `submission.csv`.
