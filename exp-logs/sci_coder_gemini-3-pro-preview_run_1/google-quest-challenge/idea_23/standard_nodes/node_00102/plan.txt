Here is the implementation strategy and the complete Python script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class, setting random seeds and selecting the computation device (GPU).
2.  **Data Loading**: Load the pre-split metadata CSVs (`train.csv`, `val.csv`, `test.csv`) from the `./metadata` directory. Initialize the tokenizer and create `QuestDataset` instances for each split.
3.  **Model Initialization**: Instantiate the `SharedBottomSplitTopRoBERTa` model architecture defined in the library.
4.  **Training**: Execute the training loop using `library.engine.run_training`. This handles the training epochs, gradient accumulation, differential learning rates, and validation monitoring, saving the best model checkpoint.
5.  **Validation & Failure Analysis**:
    *   Reload the best saved model.
    *   Perform inference on the validation set to retrieve raw predictions.
    *   Compute the **Final Validation Metric** (Mean Spearman Correlation).
    *   Calculate the mean absolute error (MAE) for each validation sample.
    *   Compute and print the Spearman correlation between the error magnitude and text length features (Question Body Length, Answer Length) to identify systematic weaknesses.
6.  **Submission**: Check if the validation score exceeds the specified threshold (`0.4129102292393905`). If successful, generate predictions for the test set using `library.engine.predict_and_submit` and save the `submission.csv`.
