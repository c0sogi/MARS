### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `seed_everything` to ensure reproducibility.
2.  **Data Loading**: Use `load_data` to retrieve training, validation, and test DataFrames. We will use the cached data if available.
3.  **Dataset Preparation**: Instantiate `StackExchangeDataset` and `DataLoader` for both training and validation sets using the `Collate` function for dynamic padding.
4.  **Model Initialization**: Load the `DistilRoBERTaDualEncoder` and move it to the GPU.
5.  **Optimizer & Scheduler**: Replicate the differential learning rate strategy (Head: 1e-3, Backbone: 2e-5) and weight decay exclusion logic. Initialize a linear scheduler with warmup.
6.  **Training Loop**: Implement a 5-epoch loop.
    *   **Epoch 1**: Freeze the backbone and train only the head.
    *   **Epoch 2+**: Unfreeze the backbone for full fine-tuning.
    *   Save the model state whenever the validation Spearman correlation improves.
7.  **Final Validation**: Load the best saved model and compute the final validation metric on the full validation set.
8.  **Failure Analysis**:
    *   Calculate the Mean Absolute Error (MAE) for each validation sample across all 30 targets.
    *   Compute lengths of input features (title, body, answer).
    *   Calculate Spearman's correlation between the MAE and feature lengths to identify error sources.
9.  **Conditional Submission**: Compare the final validation metric against the threshold (`0.40826991743732177`). If superior, generate predictions on the test set and save `submission.csv`.
