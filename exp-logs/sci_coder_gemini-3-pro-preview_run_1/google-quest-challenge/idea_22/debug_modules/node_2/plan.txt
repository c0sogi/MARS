The error `_pickle.UnpicklingError` occurs because the application is running on PyTorch 2.6+, where `torch.load` defaults to `weights_only=True` for security. The model checkpoint contains a NumPy scalar (`best_score`), which is not in the default safe allowlist, causing the loading process to block the unpickling of the file. Since the checkpoints are generated locally and trusted, the fix is to explicitly set `weights_only=False` in all `torch.load` calls to allow full unpickling of the checkpoint data.
