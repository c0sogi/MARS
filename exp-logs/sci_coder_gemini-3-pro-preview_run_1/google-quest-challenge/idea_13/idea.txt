# Model
I propose a **Triple-Branch Siamese DistilRoBERTa with Granular Interaction Fusion**.

This architecture represents a structural evolution from the standard Dual-Encoder. It explicitly decomposes the "Question" into its constituent parts—**Title** and **Body**—to prevent the dense semantic signal of the Title from being diluted by the longer Body text, while maintaining the isolation required for intrinsic feature learning.

*   **Backbone Architecture:** Utilize **`distilroberta-base`**.
    *   *Rationale:* This backbone (82M params) is the empirically verified "Right-Sized" model for this dataset (**Cite solution_lesson_node_00023**, **Cite solution_lesson_node_00045**). It avoids the "Starved Batch" instability of larger models (**Cite solution_lesson_node_00022**) and provides sufficient capacity for the task.
*   **Triple-Branch Structure (Structural Innovation):**
    *   Process three distinct input streams via the shared backbone: **Question Title**, **Question Body**, and **Answer**.
    *   *Rationale:* Separating the Title ensures its concentrated "Intent" signal is encoded into a dedicated vector, rather than being averaged out by the significantly longer Body text in a single "Question" sequence. This addresses the context management issues (**Cite solution_lesson_node_00032**) while preserving the Dual-Encoder's ability to isolate intrinsic features (**Cite solution_lesson_node_00030**).
*   **Masked Hybrid Pooling:** Apply **Masked Global Average and Max Pooling** to the final hidden state of all three branches (**Cite solution_lesson_node_00003**).
*   **Granular Interaction Fusion:**
    *   Extract Average Pooled vectors ($t_{avg}, b_{avg}, a_{avg}$) and Max Pooled vectors ($t_{max}, b_{max}, a_{max}$).
    *   Compute explicit interaction terms (Element-wise Product and Absolute Difference) **only** on the Average Pooled vectors (**Cite solution_lesson_node_00007**).
    *   Calculate three sets of interactions to capture distinct semantic alignments:
        1.  **Title-Answer:** $t_{avg} \odot a_{avg}, |t_{avg} - a_{avg}|$ (Does the answer address the core intent?).
        2.  **Body-Answer:** $b_{avg} \odot a_{avg}, |b_{avg} - a_{avg}|$ (Does the answer cover the details?).
        3.  **Title-Body:** $t_{avg} \odot b_{avg}, |t_{avg} - b_{avg}|$ (Internal consistency/well-written check).
    *   Concatenate all raw pooled vectors and interaction terms.
    *   Apply **Layer Normalization** to the fused vector to stabilize the heterogeneous scales (**Cite solution_lesson_node_00009**).
*   **Minimalist Monolithic Head:**
    *   Pass the normalized vector through a simple MLP: `Linear` $\to$ `ReLU` $\to$ `Dropout` $\to$ `Linear`.
    *   *Rationale:* This provides the necessary non-linearity to mix features (**Cite solution_lesson_node_00027**) without the optimization instability of complex Gated/LayerNormed heads (**Cite solution_lesson_node_00054**, **Cite solution_lesson_node_00046**).
    *   Predict all 30 targets simultaneously to leverage inter-label correlations (**Cite solution_lesson_node_00016**).
    *   **Initialization:** Initialize the head's weights using a Normal distribution ($\mu=0, \sigma=0.02$) to match the backbone's scale (**Cite solution_lesson_node_00051**).

# Data
*   **Preprocessing:** Prepare three separate input strings for each sample:
    1.  `question_title`
    2.  `question_body`
    3.  `answer`
*   **Feature Selection:** Rely solely on text. Do not inject metadata or use auxiliary embeddings, as these induce overfitting and shortcut learning (**Cite solution_lesson_node_00039**, **Cite solution_lesson_node_00049**).
*   **Tokenization:** Use the `distilroberta-base` tokenizer.
*   **Dynamic Padding:** Pad sequences to the longest length in the batch to optimize throughput (**Cite solution_lesson_node_00018**).

# Training
*   **Batch Size:** Use **16**. This fits in memory (even with 3 branches) and provides the necessary gradient noise for robust generalization (**Cite solution_lesson_node_00012**).
*   **Differential Learning Rates:** Apply a high learning rate (`1e-3`) to the scratch-initialized Head and a low learning rate (`2e-5`) to the Backbone (**Cite solution_lesson_node_00015**).
*   **Parameter Grouping:** Explicitly exclude `bias` and `LayerNorm` parameters from weight decay in the AdamW optimizer (**Cite solution_lesson_node_00018**).
*   **Schedule:**
    *   **Epoch 1 (Head Warmup):** Freeze the backbone completely. Train only the head (**Cite solution_lesson_node_00050**).
    *   **Epochs 2-5 (Fine-tuning):** Unfreeze the backbone. Use a continuous linear decay schedule. Do **not** reset the optimizer/scheduler; allow momentum to carry over (**Cite solution_lesson_node_00019**).
*   **Loss Function:** Binary Cross Entropy (BCE) with Logits Loss.
*   **Preservation:** Do not re-initialize any backbone layers (**Cite solution_lesson_node_00052**).

# Evaluation
*   **Inference:** Pass the test set (Title, Body, Answer) through the trained model.
*   **Prediction:** Apply Sigmoid activation to the 30 output logits.
*   **Validation:** Monitor Mean Column-wise Spearman's Correlation. Accept the model if it exceeds the previous best (`~0.408`) plus a small noise margin (**Cite solution_lesson_node_00010**).
