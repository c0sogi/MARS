Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the following optimized strategy.

# Model
I propose a **Shared-Bottom Multi-Branch RoBERTa Dual-Encoder**.

This architecture introduces a **Structural Innovation** (Hybrid Parameter Sharing) to resolve the conflict between the need for **Independent Encoders** to handle disjoint label sets (**Cite solution_lesson_node_00076**) and the need for **Symmetric Backbones** to support valid geometric feature interactions (**Cite solution_lesson_node_00080**), while simultaneously addressing the **Overfitting** observed with fully independent large backbones (**Cite solution_lesson_node_00077**).

*   **Backbone Architecture:** Utilize **`roberta-base`**.
    *   *Rationale:* This model (125M params) provides the necessary capacity to model complex hierarchical dependencies in the Question text, outperforming distilled variants (**Cite solution_lesson_node_00077**).
*   **Shared-Bottom Encoder (Layers 0-9):**
    *   The first 10 layers of the transformer are **shared** between the Question and Answer branches.
    *   *Mechanism:* Both inputs are processed by this common stack.
    *   *Benefit:* This anchors the latent representations in a unified metric space, preventing the "Alignment Drift" that degrades geometric interaction features in fully independent models (**Cite solution_lesson_node_00080**, **Cite solution_lesson_node_00085**). It also acts as a regularizer, reducing the total parameter count compared to a full 2x RoBERTa setup, mitigating the rapid overfitting risk (**Cite solution_lesson_node_00077**).
*   **Independent-Top Encoders (Layers 10-11):**
    *   At Layer 10, the network splits into two independent branches: **Question-Specific Layers** and **Answer-Specific Layers**.
    *   *Initialization:* Both branches are initialized as copies of the pre-trained `roberta-base` layers 10-11.
    *   *Benefit:* This allows the model to learn specialized high-level semantic features for the disjoint target sets (Question Quality vs. Answer Relevance) without gradient interference, preserving the benefits of the Independent Encoder strategy (**Cite solution_lesson_node_00076**).
*   **Masked Hybrid Pooling:** Apply **Masked Global Average and Max Pooling** to the outputs of the independent top layers (**Cite solution_lesson_node_00003**).
*   **Interaction-Aware Fusion:**
    *   Compute explicit interactions (Element-wise Product and Absolute Difference) *only* on the **Average Pooled** vectors (**Cite solution_lesson_node_00007**).
    *   Construct Fused Vector $F = [u_{avg}, u_{max}, v_{avg}, v_{max}, u_{avg} \odot v_{avg}, |u_{avg} - v_{avg}|]$.
    *   Apply **Layer Normalization** to $F$ (**Cite solution_lesson_node_00009**).
*   **Residual Interaction Head:**
    *   Utilize the **Residual Projection Block** (**Cite solution_lesson_node_00076**).
    *   Architecture: $Output = \text{Linear}(\text{Concat}(F, \text{Dropout}(\text{ReLU}(\text{Linear}(F)))))$.
    *   *Benefit:* This preserves the raw interaction signals (via skip connection) while enabling non-linear feature mixing (**Cite solution_lesson_node_00027**).
    *   **Initialization:** Initialize head weights using a Normal distribution ($\mu=0, \sigma=0.02$) to match the backbone scale (**Cite solution_lesson_node_00051**).

# Data
*   **Preprocessing:**
    *   **Question Stream:** Use `tokenizer(question_title, question_body)`. This leverages the tokenizer's native separator insertion (`[CLS] Title [SEP] Body [SEP]`) to preserve semantic structure (**Cite solution_lesson_node_00070**).
    *   **Answer Stream:** Use `tokenizer(answer)`. Do not inject the Title here to avoid redundancy and truncation (**Cite solution_lesson_node_00063**).
    *   **Metadata:** Exclude categorical metadata to prevent shortcut learning (**Cite solution_lesson_node_00039**, **Cite solution_lesson_node_00049**).
*   **Tokenization:** Use the `roberta-base` tokenizer.
*   **Dynamic Padding:** Pad sequences to the longest length in the batch to optimize throughput (**Cite solution_lesson_node_00018**).

# Training
*   **Phantom Scheduling (Strategic Retention):**
    *   **Configuration:** Initialize the Learning Rate Scheduler with a total duration of **7 epochs**.
    *   **Execution:** Explicitly terminate training after **3 epochs**.
    *   *Rationale:* `roberta-base` peaks at Epoch 3 on this dataset (**Cite solution_lesson_node_00077**). "Phantom Scheduling" ensures the decay profile remains optimal for fine-tuning, avoiding the underfitting caused by compressing the schedule (**Cite solution_lesson_node_00078**).
*   **Differential Learning Rates:**
    *   **Head:** High Learning Rate (`1e-3`) (**Cite solution_lesson_node_00015**).
    *   **Backbone (Shared + Split):** Low Learning Rate (`2e-5`). Treat the split layers as backbone since they are pre-trained (**Cite solution_lesson_node_00053**).
*   **Head Warmup:** Freeze all backbone layers (Shared 0-9 and Split 10-11) for the first epoch. Train only the head (**Cite solution_lesson_node_00050**).
*   **Gradient Accumulation:** Set physical batch size to **8** and accumulate gradients (steps=2) to achieve an **effective batch size of 16** (**Cite solution_lesson_node_00022**).
*   **Loss Function:** Monolithic Binary Cross Entropy (BCE) with Logits Loss (**Cite solution_lesson_node_00016**).

# Evaluation
*   **Inference:** Pass the test set through the Shared-Bottom Multi-Branch model.
*   **Prediction:** Apply Sigmoid activation to the 30 output logits.
*   **Validation:** Monitor Mean Column-wise Spearman's Correlation, expecting peak performance at Epoch 3.
