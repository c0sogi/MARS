The `ValueError: could not convert string to float: 'train.csv'` arises because the `QuestDataset` class assumes the last 30 columns of the input dataframe are the numeric target labels and extracts them using positional indexing (`df.iloc[:, -30:]`). However, the metadata generation script appended a `filepath` column (containing string values) to the end of the dataframe, which is inadvertently included in this slice, causing the type conversion to fail.

To fix this, I will:
1.  Explicitly define the list of 30 target column names in `library/config.py`.
2.  Update `library/dataset.py` to select targets using this explicit list (`Config.TARGET_COLS`) instead of positional slicing. This ensures the code robustly selects the correct columns regardless of any additional metadata columns appended to the dataframe.
