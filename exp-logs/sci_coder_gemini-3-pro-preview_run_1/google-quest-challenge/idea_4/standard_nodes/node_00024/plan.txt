To optimize the solution, I will revert the backbone from `microsoft/deberta-v3-base` to `distilroberta-base`. As noted in **Lesson 00023**, larger models like DeBERTa-v3 often yield diminishing returns on small datasets (<5k samples) due to overfitting and the necessity of "starved" batch sizes. By switching to the lighter DistilRoBERTa, I can increase the physical batch size to 16 (Cite **Lesson 00012**), which improves generalization through implicit regularization.

I will also remove the complex `WeightedLayerPooling` and revert to the robust Hybrid Pooling (Average + Max) on the last hidden state, which proved more effective for this specific task (Cite **Lesson 00023**). Finally, I will extend the training duration to 6 epochs (Cite **Lesson 00011**) and slightly adjust the backbone learning rate to `2e-5` to ensure the model fully exhausts its convergence potential within the available time.

class WeightedLayerPooling(nn.Module):
    """
    Computes a learnable weighted average of the last `num_hidden_layers` from the backbone.
    """

    def __init__(self, num_hidden_layers=4):
        super(WeightedLayerPooling, self).__init__()
        self.num_hidden_layers = num_hidden_layers
        self.weights = nn.Parameter(torch.ones(num_hidden_layers))

    def forward(self, all_hidden_states):
        # all_hidden_states is a tuple of tensors (embeddings, layer_1, ..., layer_N)
        # We extract the last 'num_hidden_layers'
        selected_layers = all_hidden_states[-self.num_hidden_layers :]

        # Stack to shape: (batch, seq_len, hidden_size, num_layers)
        stacked = torch.stack(selected_layers, dim=-1)

        # Normalize weights using Softmax
        w = F.softmax(self.weights, dim=0)

        # Compute weighted sum along the last dimension
        # (batch, seq_len, hidden, num_layers) * (1, 1, 1, num_layers) -> sum over last dim
        weighted_output = (stacked * w.view(1, 1, 1, -1)).sum(dim=-1)

        return weighted_output
