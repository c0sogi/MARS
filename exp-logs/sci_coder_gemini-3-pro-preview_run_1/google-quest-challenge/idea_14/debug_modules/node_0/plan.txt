Implementation Strategy:
1.  **Configuration & Setup**: Import the provided library modules. Override specific `Config` attributes (e.g., `EPOCHS`, `BATCH_SIZE`, `MAX_LEN`, `WORKING_DIR`) to ensure the demonstration runs quickly and uses a dedicated workspace. Set random seeds for reproducibility.
2.  **Data Preparation**: Load a small subset (e.g., 20 samples) of the training, validation, and test data using `library.dataset.load_data`. Initialize the tokenizer. Create instances of `StackExchangeDataset` and wrap them in PyTorch `DataLoader`s.
3.  **Model Initialization**: Instantiate the `ContextualizedDualEncoder`. Perform a dummy forward pass with a single batch to verify the model architecture and output shape `(Batch_Size, 30)`.
4.  **Training Loop Execution**: Configure the optimizer using `get_optimizer_params` (handling Layer-wise Learning Rate Decay) and the scheduler. Execute `library.engine.run_training` for a few epochs on the data subset.
5.  **Inference & Submission**: Load the best saved model. Run inference on the test dataset subset. Construct a submission DataFrame matching the required format and save it to the working directory.
6.  **Validation**: Use assertions throughout the script to verify data shapes, model output dimensions, and file existence.
