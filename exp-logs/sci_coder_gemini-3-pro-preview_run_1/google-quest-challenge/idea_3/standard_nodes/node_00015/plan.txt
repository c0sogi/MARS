### Strategy Outline

1.  **Setup & Configuration**: Initialize the environment with a fixed random seed for reproducibility. Define hyperparameters suitable for a fast baseline on an A100 GPU (Batch Size: 8, Epochs: 4, Learning Rate: 2e-5).
2.  **Data Loading**: Utilize the provided `get_loaders` function to load train, validation, and test datasets. The dataset size (~4.4k samples) is small enough to use in full while meeting the "fast baseline" requirement (< 2 hours).
3.  **Model Initialization**: Instantiate the `DebertaDualHead` model from the library. Configure the AdamW optimizer with weight decay logic (excluding bias/LayerNorm) and a linear learning rate scheduler with warmup.
4.  **Training Loop**: Execute the training using the `Engine` class. Train for 4 epochs, validating after each epoch and saving the model checkpoint if the Spearman correlation improves.
5.  **Validation & Failure Analysis**:
    *   Load the best model checkpoint.
    *   Perform inference on the validation set to retrieve predictions.
    *   Calculate the final validation metric (Mean Column-wise Spearman's Correlation).
    *   **Failure Analysis**: Compute the Mean Absolute Error (MAE) for each validation sample. Correlate this error with the length of the question and answer texts to identify if text length is a source of systematic error.
6.  **Submission**: Compare the final validation metric against the strict threshold (`0.4033583081786146`). If the model performs better, generate predictions for the test set and save them to `./submission/submission.csv`.
