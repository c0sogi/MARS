This script demonstrates the usage of the provided library modules for the Google QUEST Q&A Labeling task. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration parameters to enable `debug` mode and reduce training epochs for a fast demonstration.
2.  **Data Processing Verification**: Validates the data loading pipeline, ensuring that the tokenizer and custom mask generation (identifying question vs. answer tokens) function correctly.
3.  **Model Architecture Verification**: Instantiates the custom `QuestModel` and performs a forward pass with a dummy batch to verify input/output shapes and the custom pooling logic.
4.  **Metric Verification**: Tests the `compute_spearmanr` function with synthetic data to ensure the evaluation metric is calculated correctly.
5.  **Full Training Loop Execution**: Runs the complete training, validation, and inference pipeline using the `run_training` engine, producing a submission file.
6.  **Output Verification**: Checks the generated submission file for the correct format and dimensions.
