Based on the provided dataset and model architectures, I propose the **"Attribute-Conditioned" (Multi-Task MobileNet)** approach. This method synthesizes the conceptual framework of Model 5 (Attribute-Guided) into a unified, end-to-end differentiable neural network. It addresses a primary weakness of lightweight visual models—the inability to accurately "count" atoms in large structures—by explicitly supervising the model to predict molecular composition alongside the structural string.

### Model
The architecture is a multi-branch network designed to ground sequence generation in explicit chemical attributes while maintaining high inference speed:
*   **Encoder**: The backbone is **MobileNetV3-Small**, chosen for its extreme efficiency and low parameter count. It processes the input image and outputs a global feature vector via a Global Average Pooling layer.
*   **Attribute Branch**: A lightweight Multi-Layer Perceptron (MLP) head is attached to the encoder's output. This branch projects the visual features to a vector of regression targets representing the **Molecular Formula** (counts of common atoms: C, H, O, N, S, P, Halogens) and the expected **InChI string length**. This forces the encoder to learn features relevant to the composition of the molecule, not just its shape.
*   **Decoder**: A **Gated Recurrent Unit (GRU)**. Unlike Idea 1 (which uses only visual features), the initialization of this decoder's hidden state is conditioned on the **concatenation** of the visual feature vector and the *predicted* attribute vector from the auxiliary branch. This primes the generator with a strong prior regarding the molecule's size and atom inventory.

### Data
*   **Image Preprocessing**: Images will be resized to a standard $256 \times 256$ resolution and normalized. No complex augmentations will be used to maintain baseline simplicity.
*   **Text Preprocessing**: InChI strings will be tokenized at the character level with standard special tokens (`<SOS>`, `<EOS>`, `<PAD>`).
*   **Attribute Extraction**: A preprocessing step will parse the ground truth InChI strings (specifically the main formula layer, e.g., `C13H20OS` from `InChI=1S/C13H20OS/...`) using regular expressions. This extracts the counts of specific atoms and the total string length, which are then normalized (e.g., scaled by 1/100) to serve as regression targets for the Attribute Branch.

### Training
*   **Loss Function**: A **Multi-Task Loss** will be employed, combining the sequence generation error and the attribute prediction error:
    $$L_{total} = L_{CrossEntropy} + \lambda \cdot L_{MSE}$$
    where $L_{MSE}$ measures the error between the predicted and actual atom counts/length, and $\lambda$ is a weighting factor (e.g., 0.5) to balance the tasks.
*   **Optimization**: The **Adam** optimizer will be used.
*   **Strategy**: **Teacher Forcing** will be applied to the decoder sequence generation. The attribute branch is trained simultaneously, ensuring the shared encoder learns representations that are both visually discriminative and chemically semantically rich.

### Evaluation
*   **Inference Process**: For test images, the model operates in a single forward pass. The image is encoded to produce visual features. The Attribute Branch predicts the atom counts and length. These vectors are concatenated to initialize the GRU.
*   **Decoding Strategy**: **Greedy Decoding** is used to generate the InChI string character-by-character until the `<EOS>` token is reached. This approach remains highly efficient as it avoids the computational cost of beam search or ensembles.
