Implementation Strategy:
1.  **Configuration**: I will override the default `Config` to enable a fast training run. Specifically, I will set `EPOCHS=1` and enable `DEBUG` mode with a sample size of 5,000. This ensures the training and validation phases complete quickly (within ~20-30 minutes), leaving sufficient time for the potentially expensive inference step.
2.  **Data Loading**: I will use the provided `get_dataloaders` to load the tokenizers and datasets. The training and validation will use the reduced debug dataset, while the submission generation will explicitly request the full test set as required.
3.  **Model & Training**: I will instantiate the `AttributeContextualizedTransformer` and train it using the `Trainer` class. The trainer handles the mixed objective (CrossEntropy + MSE) and teacher forcing.
4.  **Evaluation**: After training, I will perform a manual inference pass on the validation set (using the trainer's validation loader) to compute the exact Levenshtein distance and perform the required failure analysis (correlation between error and sequence length).
5.  **Submission**: I will check the computed validation metric against the threshold (81.604...). If the model performs well enough, I will call `generate_submission` with `debug=False` to generate predictions for the full test set.
