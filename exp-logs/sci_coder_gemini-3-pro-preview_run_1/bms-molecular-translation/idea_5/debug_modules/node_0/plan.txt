Implementation Strategy:
1.  **Configuration**: Initialize the `Config` class and override parameters to enable debugging mode (`DEBUG=True`), reduce the dataset size (`DEBUG_SAMPLE_SIZE=50`), set epochs to 1, and disable multiprocessing (`NUM_WORKERS=0`) for immediate execution. Redirect output paths to a specific demo directory.
2.  **Utility Verification**: Test the `parse_inchi_attributes` function with a known InChI string to verify atom counting logic. Test the `Tokenizer` by fitting it on dummy text and verifying encoding/decoding consistency.
3.  **Dataset Pipeline Verification**: Call `prepare_datasets` to generate the training and validation sets. Manually fetch a single sample and a batch (via `DataLoader` and `collate_fn`) to verify data shapes (images, token IDs, attributes) and types.
4.  **Model Architecture Verification**: Instantiate the `AttributeAugmentedAttnNet`. Perform a forward pass with the batch fetched in the previous step. Assert that the output shapes for sequence logits and attribute predictions match the expected dimensions based on batch size, sequence length, and vocabulary size.
5.  **Training Loop Verification**: Execute `run_training` using the modified configuration. This validates the integration of the data loader, model, loss functions, and optimizer. Verify that the model checkpoint is saved.
6.  **Inference Verification**: Execute `generate_predictions` to produce a submission file using the trained checkpoint. Verify the output file's existence and format.
