Implementation strategy:
1.  **Setup & Data Loading**: Initialize the `Tokenizer` and build the vocabulary. Load the metadata CSVs. To ensure the script completes within the 2-hour limit, sample a subset of the training data (e.g., 30,000 samples) for the training loop. Create a smaller subset of the validation data for monitoring training progress, but keep the full validation set for the final required metric calculation.
2.  **Model Initialization**: Instantiate the `ShowAndTell` model (ResNet18 Encoder + GRU Decoder). Define the `Adam` optimizer and `CrossEntropyLoss` (ignoring padding).
3.  **Training**: Initialize the `Trainer` class. Run the training loop for a few epochs (e.g., 5) on the sampled training set. Use the small validation subset for early stopping/checkpointing to save time.
4.  **Full Validation & Metric**: Load the best saved model. Create a `DataLoader` for the *entire* validation set with a larger batch size for efficient inference. Iterate through the full validation set to generate predictions, compute the Levenshtein distance for each sample, and print the mean as the "Final Validation Metric".
5.  **Failure Analysis**: Calculate the length of the ground truth InChI strings. Compute the Pearson correlation between the Levenshtein distance (error) and the sequence length to identify if longer molecules result in higher errors.
6.  **Submission**: Create a `DataLoader` for the test set. Generate predictions using the trained model. Construct the submission DataFrame and save it to `submission/submission.csv`.
