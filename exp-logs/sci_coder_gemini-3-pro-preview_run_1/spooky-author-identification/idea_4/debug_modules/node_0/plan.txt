The following script demonstrates the end-to-end usage of the provided machine learning library for the Author Identification task. It performs the following steps:

1.  **Configuration**: Overrides default configuration settings to enable a fast "debug" mode (using a small data subset and fewer training epochs) suitable for demonstration.
2.  **Data Loading**: Loads the training, validation, and test datasets using `load_raw_data`.
3.  **Feature Engineering**: Demonstrates the extraction of meta-features (punctuation, length) and syntactic features (POS tags) using `extract_meta_features` and `SpacyPreprocessor`.
4.  **Expert Model Training**:
    *   **Lexical Expert**: Trains a TF-IDF + Logistic Regression model on word/char n-grams.
    *   **Syntactic Expert**: Trains a TF-IDF + Logistic Regression model on POS tag sequences.
    *   **Transformer Expert**: Fine-tunes a DeBERTa-v3 model (for 1 epoch on the subset).
5.  **Meta-Learner**: Assembles predictions and uncertainty statistics from the experts, combined with meta-features, to train an XGBoost blender.
6.  **Inference & Submission**: Generates predictions on the test set and formats them for submission.
7.  **Validation**: Includes assertions throughout to verify data shapes, probability ranges, and logical correctness.
