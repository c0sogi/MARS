# Model
I propose a **Tri-Modal Blending Ensemble** that integrates semantic, lexical, and syntactic signals to robustly identify authorship.

1.  **Level 1: Heterogeneous Base Experts**
    *   **Expert A (Semantic):** A fine-tuned **`microsoft/deberta-v3-base`** transformer. This model utilizes disentangled attention to capture deep contextual and semantic dependencies, which has been proven superior to RoBERTa for this specific task **Cite {solution_lesson_node_00014}**.
    *   **Expert B (Lexical Stylometry):** A **Logistic Regression** model trained on **Hybrid TF-IDF features (Word N-grams 1-3 + Character N-grams 3-5)**. This branch explicitly preserves surface-level morphological "fingerprints" (like capitalization and suffix usage) that deep models often smooth over **Cite {solution_lesson_node_00001}**, **Cite {solution_lesson_node_00005}**.
    *   **Expert C (Syntactic Stylometry - Structural Innovation):** A new **Logistic Regression** model trained on **Part-of-Speech (POS) Tag N-grams**. By converting sentences into POS sequences (e.g., "DET ADJ NOUN") using `spacy` and applying TF-IDF, this branch isolates the *grammatical structure* and *rhythmic patterns* of the authors (e.g., sentence complexity, adjective density) independent of specific vocabulary. This adds a third, orthogonal signal to the ensemble.

2.  **Level 2: Uncertainty-Aware Meta-Learner**
    *   The outputs of the three experts will be combined using an **XGBoost Classifier**.
    *   **Input Features:** The meta-learner will ingest the class probabilities from the three experts, concatenated with **explicit meta-features** (text length, punctuation counts) **Cite {solution_lesson_node_00008}** and **uncertainty statistics** (Shannon entropy, standard deviation, and maximum confidence of the base predictions) **Cite {solution_lesson_node_00009}**. This allows the ensemble to dynamically down-weight experts when they exhibit high uncertainty (e.g., on short texts).

# Data
*   **Text Processing:**
    *   For **Expert A**, raw text will be tokenized using the DeBERTa-v3 tokenizer.
    *   For **Expert B**, text will be vectorized into Word and Character TF-IDF matrices. Crucially, these will be maintained in **Sparse Matrix format (CSR)** to ensure computational efficiency **Cite {solution_lesson_node_00001}**.
    *   For **Expert C**, text will be processed with `spacy` to generate POS-tag sequences, which are then vectorized into a sparse TF-IDF matrix (N-grams 1-4).
*   **Meta-Feature Extraction:** For every sample, we will compute the length-based and uncertainty-based statistics required for the Level 2 learner.

# Training
I will employ a **Hold-Out Blending Strategy** rather than K-Fold Stacking to maximize efficiency and performance **Cite {solution_lesson_node_00010}**.

1.  **Split:** The training data will be split into a **Base Training Set (80%)** and a **Blending Validation Set (20%)**.
2.  **Base Training:** Experts A, B, and C will be trained on the **Base Training Set**.
3.  **Inference for Blending:** The trained experts will generate predictions for the **Blending Validation Set**.
4.  **Meta-Training:** The XGBoost meta-learner will be trained on these validation predictions (augmented with meta-features and uncertainty stats) to predict the ground truth labels. This ensures the meta-learner is calibrated on "unseen" data distributions.

# Evaluation
1.  **Base Inference:** The trained Experts A, B, and C (trained on the 80% split) will generate probability predictions for the **Test Set**.
2.  **Feature Assembly:** Meta-features (length, punctuation) and uncertainty statistics (entropy, etc.) will be calculated for the test samples based on the base predictions.
3.  **Final Prediction:** The trained XGBoost meta-learner will process the assembled test vectors to produce the final probability distribution.
4.  **Post-Processing:** Probabilities will be clipped as per the metric requirements before submission.
