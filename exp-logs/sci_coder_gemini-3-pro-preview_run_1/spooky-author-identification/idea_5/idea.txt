Based on the comprehensive analysis of previous attempts and the lessons learned, I propose the **"High-Capacity OOF Stacking with Stylometric Residuals"** strategy. This solution optimizes the ensemble architecture by scaling up the semantic backbone while rigorously adhering to data-efficient stacking protocols and avoiding the feature bloat that hindered previous iterations.

# Model

I propose a **Two-Stage Stacking Ensemble** designed to balance deep semantic understanding with surface-level stylometry.

1.  **Level 1: Heterogeneous Base Experts**
    *   **Expert A (Deep Semantic):** I will upgrade the transformer backbone to **`microsoft/deberta-v3-large`**. Previous experiments demonstrated that backbone quality significantly outweighs ensemble complexity **Cite {solution_lesson_node_00018}**, and DeBERTa's disentangled attention mechanism is superior for capturing the syntactic rhythm of authors compared to RoBERTa **Cite {solution_lesson_node_00014}**.
    *   **Expert B (Surface Stylometric):** I will retain the **Logistic Regression model trained on Hybrid TF-IDF features (Word N-grams 1-3 + Character N-grams 3-5)**. This model acts as a crucial "stylometric residual," capturing morphological fingerprints (e.g., specific punctuation patterns, suffix usage) that deep transformers tend to smooth over **Cite {solution_lesson_node_00005}**.

2.  **Level 2: Conditional Meta-Learner**
    *   The predictions from both experts will be combined using an **XGBoost Classifier**.
    *   **Input Features:** The meta-learner will ingest the class probabilities from Expert A and Expert B, concatenated with **explicit meta-features** (Sentence Character Length, Word Count, and Punctuation Density). This allows the model to dynamically adjust weights based on input characteristics (e.g., trusting the TF-IDF model more on very short sentences) **Cite {solution_lesson_node_00008}**.
    *   **Constraint:** I will explicitly **exclude** derived statistical features (like Entropy or Standard Deviation) and the POS-tag expert, as these were found to introduce noise and dimensionality bloat without improving performance **Cite {solution_lesson_node_00021}**.

# Data

*   **Sparse Preservation:** For Expert B, the TF-IDF matrices will be generated and maintained strictly in **Sparse Matrix format (CSR)** throughout the pipeline to ensure the linear model trains in seconds rather than minutes **Cite {solution_lesson_node_00001}**.
*   **Efficient Tokenization:** For Expert A, text will be tokenized using the DeBERTa-v3 tokenizer. The maximum sequence length will be set based on the 99th percentile of the training data distribution (approx. 256 tokens) rather than an arbitrary limit like 512. This prevents "Context Bloat," allowing for larger batch sizes and more stable convergence **Cite {solution_lesson_node_00021}**.

# Training

I will employ a rigorous **5-Fold Out-of-Fold (OOF) Stacking Strategy**.

1.  **Base Model Training (Level 1):**
    *   Experts A and B will be trained using **5-Fold Cross-Validation**.
    *   For every fold, we will generate predictions for the validation hold-out. Concatenating these predictions results in a full set of **OOF predictions** for the entire training dataset.
    *   This approach ensures the meta-learner is trained on the full dataset size (14k samples) rather than a small hold-out (3.5k), maximizing its ability to learn subtle combination rules **Cite {solution_lesson_node_00019}**. This explicitly avoids the data starvation issues observed with Hold-Out Blending **Cite {solution_lesson_node_00015}**.
2.  **Meta-Learner Training (Level 2):**
    *   The XGBoost model will be trained on the OOF probability matrix augmented with the meta-features.

# Evaluation

1.  **Bagged Inference:** Instead of re-training the base models on the full dataset (which risks overfitting or convergence instability), I will utilize the **5 saved models per Expert** from the cross-validation process.
2.  **Procedure:**
    *   Pass the test set through all 5 DeBERTa models and average their probability outputs.
    *   Pass the test set through all 5 Logistic Regression models and average their probability outputs.
    *   Calculate meta-features for the test set.
    *   Feed the averaged probabilities and meta-features into the trained XGBoost meta-learner to generate the final submission.
