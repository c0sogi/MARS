The issue is a **Stale Cache Incompatibility** (Cite debug_lesson_1). The pipeline is loading cached predictions generated during a previous "Debug" run (1,000 samples) and attempting to use them in the current "Full" run (14,096 samples), causing a dimension mismatch in the Meta-Learner. The caching logic in the expert modules (`linear_expert.py` and `transformer_expert.py`) checks only for file existence, failing to validate that the cached data matches the current runtime configuration.

To fix this, I will modify `library/linear_expert.py` and `library/transformer_expert.py` to:
1.  Load the dataset (folds and test data) *before* checking the cache to establish the expected dimensions.
2.  Validate the loaded cache files against these expected dimensions.
3.  Discard the cache and recompute if a mismatch is detected, ensuring the downstream Meta-Learner receives the correct data size.
