Implementation strategy:
1.  **Configuration & Setup**: Initialize the environment using `Config.setup()`, set random seeds for reproducibility, and suppress warnings. Modify `Config.EPOCHS` to 3 to ensure the solution runs quickly as a baseline.
2.  **Model Execution**:
    *   Execute the **Linear Branch** (`run_linear_branch`) to get validation and test probabilities based on stylometric features.
    *   Execute the **Transformer Branch** (`run_transformer_branch`) to get validation and test probabilities based on deep contextual features.
3.  **Ensemble Optimization**: Use `optimize_weights` to find the best blending ratio between the two models that minimizes log loss on the validation set.
4.  **Validation**:
    *   Compute the final blended validation probabilities.
    *   Calculate and print the **Final Validation Metric** (Log Loss) in the required format.
5.  **Failure Analysis**:
    *   Compute the error magnitude for each validation sample (1 - probability of the true class).
    *   Analyze the correlation between error magnitude and text length to identify if sentence length impacts performance.
6.  **Submission**:
    *   Check if the validation metric meets the threshold (< 0.4535).
    *   If successful, blend the test predictions using the optimized weights.
    *   Format the output using `format_submission` and save it to `./submission/submission.csv`.
