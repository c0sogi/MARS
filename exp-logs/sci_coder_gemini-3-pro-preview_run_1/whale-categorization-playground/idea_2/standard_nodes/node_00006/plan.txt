Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `set_seed` for reproducibility.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. I will limit the training to 10 epochs to ensure the script completes well within the 2-hour limit while leveraging the A100 GPU for the computationally intensive 448x448 resolution and EfficientNet-B2 backbone.
3.  **Validation**: Load the best model checkpoint saved during training. Run inference on the hold-out validation set to compute the Mean Average Precision @ 5 (MAP@5).
4.  **Failure Analysis**: Analyze the validation results by calculating the correlation between the prediction error (1 - AP) and input image features (Width, Height, Aspect Ratio, Intensity). This helps identify if specific image characteristics drive model failure.
5.  **Submission**: Check if the validation MAP@5 exceeds the specified threshold (0.6279379157). If it does, perform inference on the test set, map the predicted indices back to Whale IDs using the `IdEncoder`, and generate the `submission.csv` file in the required format.
