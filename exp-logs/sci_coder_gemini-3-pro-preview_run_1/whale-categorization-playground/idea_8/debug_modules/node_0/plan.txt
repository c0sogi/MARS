This script demonstrates the usage of the provided library modules for the Whale Identification task. It performs the following steps:

1.  **Setup**: Initializes the environment and sets random seeds for reproducibility.
2.  **Data Preparation**: Creates small subsets of the training, validation, and test metadata to ensure the demonstration runs quickly.
3.  **Dataset & Transforms**: Demonstrates how to load the class mapping, create augmentation pipelines, and instantiate the `WhaleDataset` and `DataLoader`.
4.  **Model Initialization**: Instantiates the `WhaleDenseNet` model (DenseNet121 backbone with ArcFace head) and verifies the forward pass shapes.
5.  **Loss Function**: Initializes the `LabelSmoothingCrossEntropy` loss and verifies it produces a valid scalar loss.
6.  **Training Loop**: Runs a single epoch of training on the data subset using `engine.train_one_epoch`.
7.  **Validation Loop**: Evaluates the model on the validation subset using `engine.validate` and checks the MAP@5 metric.
8.  **Inference**: Runs Test-Time Augmentation (TTA) inference on the test subset using `engine.inference_tta`.
9.  **Metric Verification**: Manually verifies the correctness of the MAP@5 calculation utility with a known example.
