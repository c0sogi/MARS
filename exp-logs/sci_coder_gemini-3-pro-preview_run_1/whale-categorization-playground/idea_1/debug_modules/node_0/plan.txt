Implementation Strategy:
1.  **Environment Setup**: Initialize random seeds for reproducibility using `library.utils.set_seed`. Define working directories for temporary metadata and model checkpoints.
2.  **Utility Verification**: Test `AverageMeter` for correct mean calculation and `calculate_map5` with manually defined prediction/target tensors to ensure the metric logic is correct.
3.  **Data Loading Demonstration**:
    *   Create a "mini" metadata set by reading the top 20 rows of the provided metadata files and saving them to a temporary directory in `./working`. This ensures valid file paths while drastically reducing processing time.
    *   Use `library.data_loader.get_dataloaders` with this mini metadata to verify that data loading, resizing, and batching work correctly.
    *   Assert the shapes of the returned image tensors and label indices.
4.  **Model Component Verification**:
    *   Instantiate `WhaleClassifier` from `library.model`.
    *   Perform a forward pass with a dummy input tensor to verify output dimensionality.
    *   Test `save_checkpoint` and `load_checkpoint` functions to ensure model persistence works.
5.  **Full Pipeline Execution**:
    *   Run `library.train.train_model` using the mini metadata, restricted to 1 epoch and 2 batches per epoch. This tests the entire training loop, validation, and initial submission generation.
    *   Run `library.inference.generate_submission` using the checkpoint generated in the previous step to verify the standalone inference workflow.
    *   Validate that the output submission files are created and have the correct format.
