To establish a robust and efficient baseline for the whale species identification task, I propose a **Standard End-to-End CNN Classification** approach. This solution prioritizes simplicity and training speed, serving as a fundamental benchmark against which more complex metric-learning or meta-learning strategies can be compared.

### Model
The architecture utilizes a **ResNet-18** backbone, chosen for its lightweight nature and inference speed compared to deeper variants or Transformers.
*   **Backbone**: The ResNet-18 model is initialized with weights pre-trained on ImageNet to leverage learned feature extractors.
*   **Classification Head**: The original fully connected layer is replaced with a new linear layer that maps the feature vector to $N$ outputs, where $N$ is the total number of unique whale IDs in the training set (including the `new_whale` class).
*   **Activation**: A standard **Softmax** activation function is applied to the output to generate a probability distribution over all classes.

### Data
Preprocessing focuses on standardizing inputs for the CNN without complex augmentations.
*   **Input Handling**: All images are resized to a fixed dimension (e.g., 224x224 pixels).
*   **Channel Conversion**: Grayscale images (1 channel) are converted to RGB (3 channels) by replicating the single channel, ensuring compatibility with the pre-trained backbone.
*   **Normalization**: Pixel values are normalized using standard ImageNet mean and standard deviation statistics.
*   **Label Encoding**: The string `Id` labels are mapped to integer indices. The `new_whale` label is treated as a distinct class index (e.g., class 0) and included directly in the label set.

### Training
The training procedure follows a standard supervised classification paradigm.
*   **Loss Function**: **Categorical Cross-Entropy Loss** is used to minimize the difference between predicted probabilities and one-hot encoded ground truth labels. This differs from the ArcFace loss in Model 1 and the Contrastive loss in Model 5.
*   **Optimizer**: The **Adam** optimizer is employed for its adaptive learning rate capabilities, facilitating faster convergence without extensive hyperparameter tuning.
*   **Strategy**: The model is trained end-to-end (backbone and head) for a fixed number of epochs. Unlike Model 3, the backbone is not frozen, allowing the feature extractors to adapt to the specific domain of whale flukes. Unlike Model 2, training is performed on standard mini-batches rather than episodic support/query sets.

### Evaluation
Predictions are generated directly from the network's output probabilities.
*   **Inference**: For each image in the test set, the model computes the softmax probability distribution across all $N$ classes.
*   **Selection**: The top 5 class indices with the highest probabilities are selected.
*   **Formatting**: These indices are mapped back to their original string `Id`s (including `new_whale`) to construct the space-delimited prediction string required for the submission file.
