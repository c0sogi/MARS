The following is the implementation of the orchestration script `runfile.py`. It leverages the provided library modules to train a ResNet-18 baseline, evaluate it on the validation set, perform failure analysis, and generate the final submission file.

The strategy involves:
1.  **Training**: Using `library.train.train_model` to handle the full training loop, including data loading, checkpointing, and prediction generation. We set `epochs=8` to ensure a quick but effective baseline run.
2.  **Validation**: Reloading the best model checkpoint and the validation data loader to compute the final MAP@5 metric with full precision.
3.  **Failure Analysis**: Iterating through the validation set to calculate per-sample error scores (derived from MAP@5). We then extract basic image features (width, height, intensity) from the validation images and compute their correlation with the prediction error to identify potential biases.
4.  **Submission**: The submission file is automatically generated by the training pipeline, ensuring the output format matches the requirements.
