The following script demonstrates the usage of the provided library components for the Whale Identification task.

**Implementation Strategy:**
1.  **Configuration Setup**: We override specific `Config` parameters (setting `DEBUG=True`, `EPOCHS=1`, and a custom `WORKING_DIR`) to ensure the demonstration runs quickly and does not interfere with production artifacts.
2.  **Utility Verification**: We explicitly test the `AverageMeter` for tracking statistics and `calculate_map5` with synthetic data to verify the metric calculation logic.
3.  **Dataset & Pipeline Check**: We instantiate the `WhaleDataset` in debug mode, verify the loading of class mappings, and check that image transformations yield tensors of the expected shape.
4.  **Model & Loss Validation**: We initialize the `WhaleDenseNet` and `LabelSmoothingCrossEntropy`, performing a forward pass with dummy data to confirm output shapes and loss computation.
5.  **Training Integration**: We execute `train_model` for a single epoch on a small data subset. This validates the entire training loop, including backpropagation, logging, and checkpoint saving.
6.  **Inference Demonstration**: Finally, we demonstrate how to load the saved checkpoint and perform inference on the test set to generate a submission file in the required format.
