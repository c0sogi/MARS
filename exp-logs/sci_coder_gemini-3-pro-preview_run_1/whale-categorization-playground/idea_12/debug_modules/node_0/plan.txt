The following strategy outlines the implementation of the demonstration script:

1.  **Configuration Override**: We will modify the `Config` class attributes at runtime to adapt the pipeline for a quick demonstration. This includes reducing the number of epochs to 1, setting a small batch size, defining a single model for the ensemble (instead of four), and redirecting output paths to a specific demo directory.

2.  **Reproducibility**: We will invoke `seed_everything(42)` immediately to ensure deterministic behavior.

3.  **Data Loading Verification**: We will use `get_dataloaders` with a `debug_size` parameter to load a tiny subset of the training and validation data. We will assert that the data loaders yield batches of the correct shape and type.

4.  **Model and Loss Validation**:
    *   We will instantiate the `WhaleModel` (DenseNet121 backbone) and pass a dummy tensor through it to verify the output embedding shape matches `Config.EMBEDDING_SIZE`.
    *   We will instantiate the `ArcFaceLoss` module and calculate the loss on the dummy embeddings and random labels to ensure the loss computation graph is valid.

5.  **Training Loop Execution**: We will initialize the `Trainer` class with the debug data loaders and the model. We will execute `train_until_convergence()`, which will run for the reduced number of epochs. We will verify that a "best model" checkpoint is saved to disk.

6.  **Inference Pipeline**: We will trigger `predict_ensemble()`. Since we updated `Config.ENSEMBLE_MODELS` to point to our just-trained demo model, this function will load the checkpoint we just created, perform inference on the test set, and generate a `submission.csv`.

7.  **Metric Verification**: We will perform a unit test on the `calculate_map5` function with hardcoded predictions and targets to verify the scoring logic.

8.  **Output Verification**: Finally, we will check that the submission file exists and follows the required format.
