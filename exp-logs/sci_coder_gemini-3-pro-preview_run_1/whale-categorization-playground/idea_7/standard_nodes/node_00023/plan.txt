Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration Override**: To adhere to the "Fast Baseline" requirement, I will override the `Config` class attributes at the start of the script. I will reduce the number of training epochs (Stage 1: 8, Stage 2: 4) and limit the ensemble to a single seed (`42`). This ensures the training completes quickly (approx. 10-15 minutes on an A100) while still providing a meaningful model.
2.  **Training Orchestration**: I will loop through the defined seeds (now just one) and call `library.train.train_model(seed)`. This function handles the progressive resizing and ArcFace training pipeline.
3.  **Validation & Metric Calculation**:
    *   I will load the trained model and the validation dataset (using the `val.csv` metadata).
    *   I will perform inference using the `get_logits_inference` utility (which includes Test-Time Augmentation) to generate predictions.
    *   I will compute the **Mean Average Precision @ 5 (MAP@5)** and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   I will implement a function `analyze_failures` that calculates the error for each validation sample (`1.0 - score`).
    *   It will extract image metadata (Width, Height, Aspect Ratio, Mean Intensity) by reading the original image files.
    *   It will compute and print the Pearson correlation between these features and the model error to identify systematic weaknesses.
5.  **Submission Generation**:
    *   I will compare the calculated `Final Validation Metric` against the threshold `0.6545824094604581`.
    *   If the metric is higher, I will trigger `library.inference.run_inference`, which generates predictions for the test set and saves them to `./submission/submission.csv`.
