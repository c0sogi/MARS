The implementation strategy follows the Independent Convergence Ensemble (ICE) protocol. We will first train three independent DenseNet121 models using the seeds defined in the configuration (42, 2023, 999). Each model utilizes the ElasticFace loss to handle the high cardinality and singleton nature of the dataset. After training, we will perform an ensemble validation by averaging the logits of all three models (including Test-Time Augmentation with horizontal flips) on the hold-out validation set to compute the final MAP@5 score. We will then conduct a failure analysis by correlating the prediction error (1 - AP) with image metadata features (width, height, intensity) to identify systematic weaknesses. Finally, if the validation performance exceeds the specified threshold, we will generate the submission for the test set using the ensemble.
