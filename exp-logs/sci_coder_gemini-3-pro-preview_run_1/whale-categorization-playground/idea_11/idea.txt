Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose the following optimized strategy. This solution introduces a **Robust Elastic-Margin Ensemble** strategy.

The core structural innovation is the replacement of the static ArcFace loss with **ElasticFace (Elastic Angular Margin Loss)** and the implementation of an **Independent Convergence Ensemble (ICE)** protocol. This strategy directly addresses the "Singleton vs. Margin" conflict identified in previous lessons by introducing stochastic flexibility into the decision boundaries, while simultaneously correcting the training methodology failures of previous ensemble attempts.

# Model
I propose an **Ensemble of 3 Independent DenseNet121 Models**, each utilizing an **ElasticFace** head.

*   **Backbone:** **DenseNet121**.
    *   *Rationale:* This architecture has been empirically proven to outperform both deeper variants (DenseNet169) and modern isotropic designs (ConvNeXt) in this specific few-shot, fine-grained regime due to its efficient feature reuse **Cite solution_lesson_node_00016, solution_lesson_node_00020**.
*   **Pooling:** **Global Average Pooling (GAP)**.
    *   *Rationale:* We explicitly retain GAP and reject specialized pooling (GeM), which was shown to overfit to background artifacts **Cite solution_lesson_node_00010**.
*   **Neck (Optimized Projection):** **Linear Projection Head**.
    *   *Structure:* `Batch Normalization` $\to$ `Linear (Features $\to$ 512)` $\to$ `Batch Normalization`.
    *   *Rationale:* This learnable bottleneck is critical for adapting the semantic features of the backbone to the geometric constraints of the metric learning loss **Cite solution_lesson_node_00015**. Crucially, we **remove Dropout** from this neck. Previous experiments showed that combining Dropout with margin-based losses leads to underfitting in this domain **Cite solution_lesson_node_00030**.
*   **Head (Structural Innovation):** **ElasticFace (Elastic Angular Margin)**.
    *   *Rationale:* Standard ArcFace enforces a fixed margin $m$ for all classes. In a dataset where 76% of classes are singletons, a fixed margin forces the model to over-compress these single-sample classes, often leading to overfitting or optimization difficulties. **ElasticFace** replaces the fixed margin with a random margin sampled from a Gaussian distribution $N(m, \sigma)$ at each iteration. This stochasticity provides a "margin smoothing" effect similar to the benefit observed with Label Smoothing **Cite solution_lesson_node_00024**, allowing the model to learn robust embeddings for singletons without the gradient dilution associated with standard label smoothing.

# Data
*   **Splitting Strategy:** Strictly maintain the **Singleton-Inclusive Split**. All classes with only 1 sample must be included in the training set to prevent zero-shot validation errors **Cite solution_lesson_node_00002**.
*   **Resolution:** Fixed **320x320**.
    *   *Rationale:* This resolution strikes the optimal balance, avoiding the information loss of 224x224 **Cite solution_lesson_node_00005** and the overfitting risks of 448x448 **Cite solution_lesson_node_00007**. We explicitly reject progressive resizing **Cite solution_lesson_node_00023**.
*   **Augmentation:**
    *   **Geometric:** **Conservative** Affine transformations (Rotation $\pm 20^\circ$, Scale 0.9-1.1) and Horizontal Flips. Aggressive distortions are avoided to preserve feature integrity **Cite solution_lesson_node_00014**.
    *   **Photometric:** Brightness and Contrast adjustments only. Explicitly **exclude** Saturation and Hue jitter **Cite solution_lesson_node_00004**.

# Training
I propose an **Independent Convergence Ensemble (ICE)** protocol.

*   **Strategy:** Train **3 separate models** initialized with different random seeds.
    *   *Correction from previous failures:* Unlike Idea 8 (which failed due to undertraining) and Idea 10 (SWA, which failed due to embedding smearing), each model in this ensemble will be treated as a standalone entity.
*   **Convergence Criterion:** Each model will be trained until **Early Stopping** is triggered based on the validation metric. We explicitly reject fixed-epoch training **Cite solution_lesson_node_00026**.
*   **Loss Function:** **ElasticFace Loss**.
*   **Regularization:** **Enable Label Smoothing (0.1)**.
    *   *Rationale:* Retain mild label smoothing as it acts as a vital regularizer for singleton classes **Cite solution_lesson_node_00024**.
*   **Optimizer:** **AdamW** with **Cosine Annealing** scheduler.

# Evaluation
*   **Protocol:** Implement **Test-Time Augmentation (TTA)** using Horizontal Flips for **both** the validation loop and final inference.
    *   *Rationale:* The validation metric for *each* ensemble member must be calculated using TTA to ensure accurate checkpoint selection **Cite solution_lesson_node_00011**.
*   **Inference:**
    1.  Load the **Best Checkpoint** for each of the 3 models (determined individually by their TTA-Validation metric).
    2.  For each test image, generate embeddings/logits from all 3 models using both **Original** and **Horizontally Flipped** views (Total 6 predictions per image).
    3.  Average the logits across all views and models.
    4.  Select the top 5 `Id`s.
