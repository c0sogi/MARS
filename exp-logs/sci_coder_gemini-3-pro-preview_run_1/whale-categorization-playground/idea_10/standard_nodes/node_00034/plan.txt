3.  **Validation Inference**: Load the final SWA model checkpoint. Perform inference on the hold-out validation set using Test-Time Augmentation (TTA) (averaging predictions from original and horizontally flipped images). Calculate the exact Mean Average Precision @ 5 (MAP@5).
4.  **Metric Reporting**: Print the final validation metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: iterate through validation predictions, determining binary error status (1 if ground truth is not in top-5 predictions, else 0). Extract basic image metadata (width, height, intensity) for these samples and compute the correlation between these features and the error status to identify performance bottlenecks.
6.  **Submission Generation**: Compare the final validation metric against the threshold (0.6545824094604581). If the metric is higher, perform inference on the test set (using TTA), decode the predicted indices into whale IDs using the class mapping, and generate the `submission.csv` file.
