The error `ValueError: Object arrays cannot be loaded when allow_pickle=False` occurs because the code attempts to load a NumPy array containing string data (whale IDs) from a cached `.npy` file without explicitly enabling pickling. Modern NumPy versions disable pickling by default for security reasons, blocking the loading of object arrays (which strings are stored as). To fix this, I will modify `library/dataset.py` to set `allow_pickle=True` in the `np.load` call, as advised in `debug_lesson_3`.
