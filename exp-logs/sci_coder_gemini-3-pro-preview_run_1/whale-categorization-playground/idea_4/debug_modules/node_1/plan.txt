The execution failed with a `_pickle.UnpicklingError` because the checkpoint contains a NumPy scalar (`best_map5`), and the installed PyTorch version defaults to `weights_only=True` in `torch.load`, which restricts unpickling to tensors only. To fix this, I will modify `library/utils.py` to explicitly set `weights_only=False` when loading the checkpoint. This mirrors the logic of explicitly enabling pickling for trusted sources when loading mixed types in NumPy. Cite debug_lesson_3.
