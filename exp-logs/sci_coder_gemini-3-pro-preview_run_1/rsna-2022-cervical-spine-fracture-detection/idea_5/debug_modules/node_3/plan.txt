The previous implementation failed because the `SegmentationDataset` relied on `nibabel` to load NIfTI segmentation files, but `nibabel` is missing from the environment. The code attempted to handle this with a "soft import" (setting `nib = None`), which caused `process_segmentation` to return `None` for all files, resulting in an empty dataset and a `ValueError` in the DataLoader (Cite debug_lesson_10).

To fix this, I will refactor the data pipeline to eliminate the dependency on `nibabel` (Cite debug_lesson_7). Instead of using NIfTI segmentations, I will modify the `SegmentationDataset` to generate proxy segmentation masks using the provided bounding box data (`train_bounding_boxes.csv`), which relies only on standard libraries like `pandas` and `numpy`. This ensures the segmentation model (Stage 1) can still be trained to localize fractures/regions of interest, fulfilling the downstream requirement for cropping coordinates in Stage 2.

Here are the changes:
1.  **`library/utils.py`**: Remove the `nibabel` import and the `process_segmentation` function.
2.  **`library/data.py`**:
    *   Update `SegmentationDataset` to load bounding boxes instead of NIfTI files.
    *   Modify `get_dataloaders` to filter samples based on `has_bounding_box` instead of `has_segmentation`.
    *   Remove the logic that loads GT masks for the classifier stage (as it also relied on `process_segmentation`), defaulting to center crops.
3.  **`library/engine.py`**: Remove the unused import of `process_segmentation`.

def process_segmentation(path, reorient=True):
    """
    Loads a NIFTI segmentation file and returns the 3D volume.

    Args:
        path (str): Path to .nii file.
        reorient (bool): If True, reorients to RAS+ canonical orientation.

    Returns:
        np.ndarray: 3D numpy array of the mask (Z, Y, X).
    """
    if nib is None:
        return None

    try:
        nii = nib.load(path)

        # Standardize orientation to RAS+ (Right, Anterior, Superior)
        if reorient:
            nii = nib.as_closest_canonical(nii)

        mask = nii.get_fdata()

        # nibabel loads as (X, Y, Z). Transpose to (Z, Y, X) to match DICOM stack convention
        # (Depth, Height, Width)
        mask = mask.transpose(2, 1, 0)

        return mask
    except Exception as e:
        print(f"Error loading NIFTI {path}: {e}")
        return None

    def _prepare_samples(self):
        """
        Creates a list of valid slices based on DICOM counts.
        """
        print(f"Preparing Segmentation Dataset with {len(self.df)} studies...")

        for idx, row in self.df.iterrows():
            uid = row["StudyInstanceUID"]
            img_dir = os.path.join(Config.INPUT_DIR, row["image_path"])

            # Count slices by listing files
            try:
                # Fast count
                files = [f for f in os.listdir(img_dir) if f.endswith('.dcm')]
                num_slices = len(files)
            except Exception:
                num_slices = 0

            if num_slices == 0:
                continue

            # Add all slices for this volume
            # We add all slices, but only those with BBoxes will have positive masks.
            for z in range(num_slices):
                self.samples.append(
                    {
                        "StudyInstanceUID": uid,
                        "slice_idx": z,
                        "image_dir": img_dir,
                    }

            img = augmented["image"]
            mask = augmented["mask"]
        else:
            img = torch.from_numpy(img).unsqueeze(0)
