Implementation Strategy:
1.  **Configuration Setup**: We will import the `Config` class and override specific parameters (epochs, batch sizes, debug mode) to ensure the script runs quickly and uses a small subset of the data (5 samples) via the `DEBUG` flag.
2.  **Environment Cleanup**: We will clear specific cache files and checkpoints in the working directory to force the training and extraction functions to execute their logic rather than skipping due to existing files.
3.  **Model Verification**: We will instantiate the three core models (`UNetLocalizer`, `FractureEncoder`, `AnatomicalTransformer`) with dummy input tensors to verify their forward passes and output shapes.
4.  **Pipeline Execution**: We will sequentially execute the training functions from `library.engine`:
    *   `train_segmentor`: Trains the Stage 1 U-Net.
    *   `train_encoder`: Trains the Stage 2 CNN.
    *   `extract_features`: Uses the trained models to generate features for the dataset.
    *   `train_aggregator`: Trains the Stage 3 Transformer on the extracted features.
5.  **Inference Demonstration**: We will initialize the `InferencePipeline`, run the prediction step, and verify that a valid `submission.csv` is generated with the correct structure.
