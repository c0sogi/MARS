The implementation strategy involves orchestrating the three-stage training pipeline defined in the library modules, followed by a rigorous validation and conditional submission process.

1.  **Configuration & Setup**: Initialize the environment and override default training epochs to ensure the pipeline runs within the 2-hour limit (Fast Baseline).
2.  **Pipeline Execution**:
    *   **Stage 1 (Segmentation)**: Train the U-Net to localize the spine and generate anatomical probability maps.
    *   **Stage 2 (Encoder)**: Train the Dual-Branch CNN to extract slice-level features (fracture detection).
    *   **Stage 3 (Aggregator)**: Extract features for all patients using the trained Stage 1 & 2 models, then train the Bi-GRU to aggregate these sequences into patient-level predictions.
3.  **Validation**:
    *   Load the validation dataset and the trained Stage 3 model.
    *   Perform inference to get probabilities for all 8 targets (C1-C7, patient_overall).
    *   Compute the **Weighted Multi-label Logarithmic Loss** exactly as specified.
4.  **Failure Analysis**:
    *   Calculate the loss contribution of each patient.
    *   Compute the Pearson correlation between the error (loss) and the `patient_overall` label to identify if the model struggles more with positive or negative cases.
5.  **Submission**:
    *   Compare the validation metric against the threshold (0.9254394427010018).
    *   If the metric is lower (better), generate the submission file for the test set.
