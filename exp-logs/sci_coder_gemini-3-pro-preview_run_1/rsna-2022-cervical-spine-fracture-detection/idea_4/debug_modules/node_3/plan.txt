To resolve the `ZeroDivisionError` and the underlying data starvation issue, I will modify two files.

1.  **`library/datasets.py`**: I will refactor `prepare_segmentation_cache` to remove the global check that returns early if the cache directory is non-empty. Instead, I will implement a granular check inside the processing loop to skip only those specific studies that are already cached. This ensures that when the validation set is processed after the training set, the function doesn't mistakenly assume all data is present just because the training data exists. Cite debug_lesson_3.

2.  **`library/segmentation_engine.py`**: I will wrap the validation loop and metric calculation in a conditional check `if len(val_loader) > 0`. This prevents the division by zero error if the validation dataset happens to be empty (e.g., due to filtering or data issues) and sets the metrics to 0.0 in that case.
