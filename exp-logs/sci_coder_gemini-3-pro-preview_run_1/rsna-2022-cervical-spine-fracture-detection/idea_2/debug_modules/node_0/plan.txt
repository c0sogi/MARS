This script demonstrates the end-to-end pipeline for cervical spine fracture detection using the provided library. It sets up a demo environment, verifies data integrity, and executes training and inference steps for both the spine localization and fracture classification models.

To ensure rapid execution within the time limit, the script:
1.  Configures the system to run in `DEBUG` mode with a minimal dataset size.
2.  Creates a custom subset of training metadata ensuring that samples with bounding boxes are included (preventing empty datasets during localization training).
3.  Monkey-patches model creation functions to disable pretrained weight downloads (ensuring offline execution).
4.  Validates the successful generation of checkpoints and submission files.
