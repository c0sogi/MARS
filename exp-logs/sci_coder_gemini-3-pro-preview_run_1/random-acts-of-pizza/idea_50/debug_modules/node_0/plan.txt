The following script demonstrates the end-to-end pipeline for the "Random Acts of Pizza" prediction task using the provided library modules.

**Implementation Strategy:**
1.  **Configuration Setup**: We override specific `Config` parameters (enabling `DEBUG` mode, reducing epochs, and limiting Random Forest estimators) to ensure the script runs quickly and efficiently within the demonstration constraints.
2.  **Data Loading**: We use `get_splits` to load a small subset of the training, validation, and test data.
3.  **Feature Engineering**: We instantiate the `FeatureEngineer` and generate features. Crucially, we disable cache loading (`load_cached_data=False`) to ensure the generated feature dimensions match our reduced `DEBUG` dataset size, preventing mismatches with pre-existing full-dataset caches.
4.  **Data Preparation**: We wrap the generated features into `PizzaDataset` objects and create PyTorch `DataLoader`s for the MLP model.
5.  **Model Initialization**: We initialize both the Random Forest model and the custom FiLM-based MLP classifier. The MLP's input dimension is dynamically determined from the generated control features.
6.  **Training**:
    *   The Random Forest is trained on the sparse feature matrices.
    *   The MLP is trained using the training loop provided in `library.engine`, with validation monitoring.
7.  **Inference & Submission**: We generate predictions using the ensemble method (weighted average of RF and MLP) and save the results to `submission.csv`.
8.  **Verification**: Finally, we perform assertions to verify the submission file's existence, shape, and value validity.
