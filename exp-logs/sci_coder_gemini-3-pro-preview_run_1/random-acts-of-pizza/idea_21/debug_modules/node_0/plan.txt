The following script demonstrates the complete pipeline for predicting pizza request success. It leverages the provided library modules to perform feature engineering, train a Random Forest and an MLP model, and generate a submission file.

The script is optimized for speed by:
1.  Enabling `Config.DEBUG = True` to process only a small subsample (200 rows) of the data.
2.  Reducing the number of estimators for the Random Forest.
3.  Reducing the number of epochs for the MLP training.
4.  Disabling the loading of cached data to ensure the feature engineering pipeline is fully executed and verified.
