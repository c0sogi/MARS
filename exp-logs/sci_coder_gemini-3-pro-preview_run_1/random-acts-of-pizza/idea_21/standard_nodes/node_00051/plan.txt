The solution involves orchestrating a hybrid ensemble of a Soft-Cluster Augmented Random Forest and a Credibility-Gated Attention MLP. The script will first load and preprocess the data using the provided library functions, ensuring that features like GMM user profiles, SBERT embeddings, and engineered metadata are correctly generated and cached. It will then proceed to train the Random Forest and MLP models independently on the training set, using the validation set for early stopping and metric evaluation. Once trained, the models' predictions on the validation set will be combined via a simple weighted average (0.5/0.5) to compute the final ROC AUC. A failure analysis will be performed by correlating prediction errors with metadata features to identify weaknesses. Finally, if the validation AUC exceeds the specified threshold, the ensemble will generate predictions for the test set and save the submission file.
