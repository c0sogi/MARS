This script demonstrates the end-to-end execution of the provided machine learning pipeline for the Random Acts of Pizza task. It performs the following steps:

1.  **Configuration Overrides**: Monkey-patches the `library.config` module to reduce dataset size and model complexity (e.g., fewer epochs, smaller trees) for a rapid demonstration.
2.  **Data Loading**: Uses `library.data_loader` to load a small subset (50 rows) of the training, validation, and test data to ensure quick execution.
3.  **Feature Engineering**: Utilizes `library.features.FeatureEngineer` to generate TF-IDF, LSA, and SBERT embedding features. It validates the shapes of the generated feature matrices.
4.  **Model Training (Stream A - Random Forest)**: Trains the Random Forest model using `library.engine.train_rf` and validates the generated predictions.
5.  **Model Training (Stream B - MLP)**: Trains the Credibility-Gated MLP using `library.engine.train_mlp` and validates the output predictions.
6.  **Ensembling & Submission**: Combines predictions from both streams using a weighted average and generates a submission file using `library.utils.save_submission`.
