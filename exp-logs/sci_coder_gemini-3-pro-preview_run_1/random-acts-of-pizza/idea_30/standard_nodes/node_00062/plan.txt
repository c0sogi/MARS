The solution implements the orchestration script `runfile.py` to train the Hybrid Ensemble (Random Forest + Dual-Query MLP), evaluate it, and generate a submission.

### Implementation Strategy
1.  **Setup & Initialization**: Set random seeds for reproducibility and initialize the `FeatureEngineer` to prepare data.
2.  **Data Processing**:
    *   Load/Generate features for **Stream A** (Random Forest): Metadata, Top-K Subreddits, Alignment Scalars, and TF-IDF.
    *   Load/Generate features for **Stream B** (MLP): Embeddings (Title, Body, History), Masks, and Scaled Metadata.
3.  **Model Training**:
    *   Train the **Random Forest** (Stream A) on the tabular/TF-IDF data.
    *   Train the **Dual-Query MLP** (Stream B) on the tensor/embedding data using the validation set for early stopping.
4.  **Ensemble & Evaluation**:
    *   Generate probability predictions from both models on the validation set.
    *   Compute the **Weighted Ensemble** probability (0.5 RF + 0.5 MLP).
    *   Calculate and print the **Final Validation Metric (AUC)**.
5.  **Failure Analysis**:
    *   Compute prediction errors on the validation set.
    *   Calculate correlations between the error and input features (using Stream A's tabular features) to identify sources of difficulty.
6.  **Submission**:
    *   Check if the validation AUC exceeds the threshold (0.7036).
    *   If successful, generate ensemble predictions for the test set.
    *   Map predictions to the `sampleSubmission.csv` format and save to `./submission/submission.csv`.
