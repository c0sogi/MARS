1.  **Setup and Configuration**: Initialize the environment by setting the random seed for reproducibility. Import necessary libraries and the provided modules (`data_loader`, `feature_engine`, `model_rf`, `model_mlp`, `config`, `utils`).
2.  **Data Loading and Subsampling**: Load the dataset using `data_loader.load_dataset`. To ensure the demonstration runs quickly (optimizing for speed), subsample the training, validation, and test sets to a small number of rows (e.g., 50 samples each).
3.  **Hyperparameter Overrides**: Modify the configuration parameters in `library.config` at runtime to reduce computational cost. This includes reducing the number of Random Forest estimators and MLP epochs.
4.  **Feature Engineering**: Instantiate the `FeatureProcessor` from `feature_engine.py` and run the `process` pipeline on the subsampled data. This will generate the necessary feature dictionaries for both the Random Forest and MLP models.
5.  **Model Training (Random Forest)**: Execute `train_rf_model` using the generated features. Validate the output predictions (shape and value range) using assertions.
6.  **Model Training (MLP)**: Execute `train_mlp_model` using the generated features. Validate the output predictions using assertions.
7.  **Ensembling**: Compute the final predictions by averaging the outputs from both models (simple ensemble).
8.  **Submission Generation**: Create a submission DataFrame matching the required format and save it to the specified output directory.
9.  **Final Verification**: Verify that the submission file exists and has the correct dimensions.
