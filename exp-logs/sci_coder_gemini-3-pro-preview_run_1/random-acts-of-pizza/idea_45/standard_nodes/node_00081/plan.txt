The implementation strategy is as follows:

1.  **Setup and Imports**: Import necessary libraries and the provided modules from the `library` package (`config`, `data_loader`, `text_processing`, `feature_engineering`, `trainer`). Set random seeds for reproducibility.
2.  **Data Loading**: Use `load_dataset` to retrieve train, validation, and test DataFrames, leveraging caching for speed.
3.  **Feature Generation**: Call `generate_sbert_embeddings` and `generate_tfidf_features` to create base text features.
4.  **Feature Preparation**: Invoke `prepare_rf_features` and `prepare_mlp_features` to construct the specific input formats required for the Random Forest (Stream A) and MLP (Stream B) models.
5.  **Model Training**: Train both models independently using `train_rf_model` and `train_mlp_model`.
6.  **Validation**:
    *   Generate probability predictions on the validation set from both models.
    *   Compute the ensemble prediction (0.5/0.5 weighted average).
    *   Calculate and print the **Final Validation Metric** (ROC AUC).
7.  **Failure Analysis**:
    *   Calculate the absolute error between predictions and ground truth.
    *   Correlate this error with raw numerical metadata features from the validation set.
    *   Print the correlations to identify sources of systematic error.
8.  **Submission**:
    *   Check if the validation AUC exceeds the threshold `0.7135451153926904`.
    *   If successful, generate test set predictions, ensemble them, and save the submission file using `generate_submission`.
