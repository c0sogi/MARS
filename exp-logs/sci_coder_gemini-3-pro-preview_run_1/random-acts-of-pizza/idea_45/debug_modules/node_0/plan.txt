The following script demonstrates the end-to-end usage of the provided library modules. It performs the following steps:
1.  **Configuration Patching**: Modifies hyperparameters in the imported modules to ensure the demonstration runs quickly (e.g., reducing epochs, batch sizes, and estimators).
2.  **Data Loading**: Loads a small debug subset (50 samples) of the training, validation, and test data using `data_loader.load_dataset`.
3.  **Feature Generation**:
    *   Generates SBERT embeddings and TF-IDF features using `text_processing`.
    *   Prepares specific feature sets for Random Forest (Stream A) and MLP (Stream B) using `feature_engineering`.
4.  **Model Training & Inference**:
    *   Instantiates and trains the `InteractionRandomForest` model, validates predictions, and checks model persistence.
    *   Instantiates and trains the `MLPTrainer`, validates predictions, and checks model persistence.
5.  **Submission Generation**: Uses the `trainer` module to generate a submission file from the ensemble of predictions.
6.  **Verification**: Includes assertions throughout to verify data shapes, prediction ranges, and file outputs.
