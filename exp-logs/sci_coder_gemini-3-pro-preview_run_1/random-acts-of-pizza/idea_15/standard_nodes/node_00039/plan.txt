Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Initialization**: Set random seeds for reproducibility across `numpy`, `torch`, and `random`. Import necessary modules from the provided library files (`config`, `data_loader`, `model_rf`, `model_mlp`, `features`).
2.  **Model Training**:
    *   **Stream A (Random Forest)**: Execute `model_rf.train_rf_stream()` to train the Random Forest model and obtain validation and test probabilities.
    *   **Stream B (MLP)**: Execute `model_mlp.train_mlp_stream()` to train the Residual Attention MLP and obtain validation and test probabilities.
3.  **Ensemble**:
    *   Load the ground truth validation targets (`y_val`) using `data_loader.load_datasets()`.
    *   Combine the predictions from both streams using the weights defined in `config.ENSEMBLE_WEIGHTS` (0.5/0.5).
    *   Compute the final ROC AUC score on the validation set.
4.  **Validation & Failure Analysis**:
    *   Print the required `Final Validation Metric`.
    *   Perform failure analysis by calculating the absolute error of the ensemble predictions.
    *   Load validation metadata features and compute the Pearson correlation between the error and each feature to identify sources of systematic error. Print the top correlated features.
5.  **Submission**:
    *   Check if the validation AUC exceeds the threshold (0.6959737721862433).
    *   If successful, construct the submission DataFrame using `request_id`s from the test set and the ensembled test probabilities.
    *   Save the file to `./submission/submission.csv`.
