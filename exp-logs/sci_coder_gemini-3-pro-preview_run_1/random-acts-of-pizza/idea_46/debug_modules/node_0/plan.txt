This script demonstrates the usage of the provided machine learning library components for the "Random Acts of Pizza" task. It covers the entire pipeline from data loading and feature engineering to model training (Random Forest and MLP) and submission generation. To ensure the demonstration runs quickly and stays within the time limit, we sample a small subset of the training data and perform feature extraction and training on this reduced set.

The script performs the following steps:
1.  **Setup & Configuration**: Sets random seeds and overrides configuration parameters for speed (e.g., reduced epochs, smaller batch sizes).
2.  **Data Loading**: Loads a small sample of the raw metadata CSVs to avoid processing the entire dataset.
3.  **Feature Engineering**: Demonstrates the `MetadataExtractor`, `TextEmbedder`, `TfidfProcessor`, and `InteractionProcessor` classes to transform raw data into features suitable for the models.
4.  **Random Forest Model**: Instantiates the `InteractionProjectedRF`, fits it on the processed subset, and verifies predictions.
5.  **Neural Network (MLP)**: Prepares a `PizzaDataset` and `DataLoader`, instantiates the `OrthogonalSkipGatedMLP`, and performs a training step (forward and backward pass) to verify architecture correctness.
6.  **Submission**: Demonstrates how to format and save predictions using the utility function.
