Implementation strategy:
1.  **Environment Setup**: Initialize the environment, set random seeds for reproducibility, and detect the available computation device (CPU or GPU).
2.  **Data Loading**: Utilize the `library.data_loader.get_processed_features` function to load the pre-processed datasets (TF-IDF, SBERT embeddings, metadata) from the cache.
3.  **Stream A (Random Forest) Training**: Train the `InteractionProjectedRF` model using `library.tree_model.train_rf_model`. Generate probability predictions for the validation set.
4.  **Stream B (MLP) Training**:
    *   Initialize DataLoaders using `library.dataset.create_dataloaders`.
    *   Determine input dimensions dynamically from a training batch.
    *   Train the `OrthogonalSkipGatedMLP` using `library.neural_net.train_mlp_model`. To adhere to the "minimal printing" requirement, standard output during the training loop (epoch logs) will be suppressed.
    *   Generate probability predictions for the validation set using `library.neural_net.predict_mlp`.
5.  **Ensemble & Validation**:
    *   Compute the final validation predictions via a simple weighted average (0.5/0.5) of the RF and MLP probabilities.
    *   Calculate the ROC AUC score on the validation set.
    *   Print the final validation metric with full precision.
6.  **Failure Analysis**:
    *   Compute the absolute error between predictions and ground truth on the validation set.
    *   Correlate these errors with the input features (specifically mapping indices to feature types like TF-IDF, Metadata, and Interactions) to identify sources of error.
    *   Print the top 5 correlated feature indices/types.
7.  **Submission Generation**:
    *   Compare the validation AUC against the threshold (0.7135451153926904).
    *   If the threshold is met, generate predictions for the test set using both models, ensemble them, and save the result to `./submission/submission.csv` using `library.utils.save_submission`.
