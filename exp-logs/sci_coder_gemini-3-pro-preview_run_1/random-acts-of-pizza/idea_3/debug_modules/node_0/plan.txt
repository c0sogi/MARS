The following script demonstrates the end-to-end usage of the provided library modules. It performs the following steps:
1.  **Configuration Patching**: Temporarily overrides configuration paths and hyperparameters to use a temporary directory and reduce model complexity for a fast demonstration.
2.  **Data Loading**: Loads the raw CSV data using `data_processing.load_data`, then subsamples it to ensure the script runs quickly.
3.  **Feature Engineering**: Generates Sparse (Bag-of-Words) and Dense (Sentence Embedding) feature streams using `feature_streams.generate_streams`.
4.  **Model Training**: Initializes and trains the `HybridEnsemble` model on the processed streams.
5.  **Inference**: Generates predictions on the test set and verifies the output validity.
