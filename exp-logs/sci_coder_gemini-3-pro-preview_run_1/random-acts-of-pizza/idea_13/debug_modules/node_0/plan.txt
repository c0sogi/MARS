This script demonstrates the end-to-end execution of the pizza request success prediction pipeline using the provided library files. It performs the following steps:

1.  **Configuration**: Overrides default configuration settings (directories, hyperparameters) to ensure the demo runs quickly and does not interfere with the main working directories.
2.  **Data Loading**: Loads the dataset and creates a small subsample (50 training, 20 validation, 20 test samples) for rapid execution.
3.  **Feature Engineering**:
    *   Initializes the `SBERTEmbedder` for semantic text processing.
    *   Trains a `TopicAligner` (NMF) on the training subset to extract topic distributions.
    *   Uses `FeatureBuilder` to generate tabular features, TF-IDF vectors, and topic alignment scores.
4.  **Model Training**:
    *   **Stream A (Random Forest)**: Prepares hybrid features (Tabular + Topic + TF-IDF), trains the `TopicAlignedRF` model, and evaluates it.
    *   **Stream B (MLP)**: Prepares tensor inputs (Embeddings + Metadata), trains the `CredibilityGatedNet` using `MLPTrainer`, and evaluates it.
5.  **Inference**: Generates predictions on the test subset using an ensemble of both models and saves the submission file.
6.  **Validation**: Includes assertions at each step to verify data shapes, model outputs, and file generation.
