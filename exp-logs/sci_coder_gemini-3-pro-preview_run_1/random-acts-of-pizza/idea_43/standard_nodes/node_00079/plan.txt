The following is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds and suppressing warnings using the provided `library.utils` and `library.config` modules.
2.  **Data Loading**: Load the training, validation, and test datasets using `library.data_loader.load_data`. We enable caching (`load_cached_data=True`) to utilize pre-processed Parquet files if available, ensuring efficiency.
3.  **Model Stream A (Random Forest)**: Instantiate and execute the `RandomForestPipeline` from `library.stream_a_rf`. This pipeline handles TF-IDF vectorization, metadata assembly, and Top-K feature integration, returning predictions for both validation and test sets.
4.  **Model Stream B (MLP)**: Instantiate and execute the `MLPPipeline` from `library.stream_b_mlp`. This pipeline processes SBERT embeddings and the Unified Credibility Block, training a neural network with Dual-Query Attention and returning predictions.
5.  **Ensemble**: Combine the predictions from both streams using a weighted average (0.5/0.5) as defined in the configuration.
6.  **Validation & Metric**: Compute the Area Under the ROC Curve (AUC) on the validation set. Print the result in the specific format required (`Final Validation Metric: <value>`).
7.  **Failure Analysis**: Calculate the absolute prediction error on the validation set. Compute and print the Pearson correlation between this error and the numerical features in the validation metadata to identify sources of model failure.
8.  **Submission**: Compare the validation AUC against the specified threshold (0.7135451153926904). If the model performs sufficiently well, generate the `submission.csv` file containing `request_id` and the predicted probability `requester_received_pizza`.
