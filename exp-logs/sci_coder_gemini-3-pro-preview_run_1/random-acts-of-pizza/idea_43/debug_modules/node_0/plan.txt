The following script demonstrates the end-to-end execution of the provided machine learning pipeline for predicting Reddit pizza request success. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration parameters to enable `DEBUG` mode and reduce model complexity (fewer epochs, fewer trees) for rapid execution and verification.
2.  **Data Loading**: Uses the `data_loader` module to load a small subset of the training, validation, and test data.
3.  **Feature Engineering**: Explicitly invokes the `FeatureProcessor` to generate metadata, text embeddings (SBERT), and user history features, verifying the output structure and shapes.
4.  **Stream A (Random Forest)**: Initializes and runs the `RandomForestPipeline`, validating the generation of TF-IDF features and the resulting probability predictions.
5.  **Stream B (MLP)**: Initializes and runs the `MLPPipeline`, which constructs a PyTorch dataset, trains the `CredibilityGatedMLP` model, and generates predictions.
6.  **Ensembling**: Combines the predictions from both streams using the weights defined in the configuration.
7.  **Submission Generation**: Formats the final predictions into a CSV file matching the submission requirement.
