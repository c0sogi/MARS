The following script demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Configuration Overrides**: Monkey-patches the `library.config` module to reduce training epochs and estimator counts for a rapid execution.
2.  **Data Loading**: Uses `data_loader` to load a small debug subset of the data.
3.  **Feature Generation**:
    *   Uses `TextEncoder` to generate SBERT embeddings for text and user history.
    *   Uses `FeatureEngineer` to generate tabular, TF-IDF, and interaction features.
4.  **Component Verification**:
    *   Instantiates `PizzaDataset` and verifies tensor shapes.
    *   Instantiates `OrthogonalSkipGatedMLP` and verifies a forward pass.
5.  **Training Pipeline**: Uses the `trainer` module to train both the MLP and Random Forest models.
6.  **Inference & Submission**: Generates ensemble predictions and saves the submission file.
