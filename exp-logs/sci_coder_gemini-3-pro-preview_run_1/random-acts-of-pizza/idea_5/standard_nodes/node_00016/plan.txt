The following script implements the `runfile.py` entry point. It orchestrates the entire pipeline: loading data, performing stratified K-Fold cross-validation to train the base learners (Random Forest and Triple-Branch MLP), training a stacking meta-learner, evaluating on the hold-out validation set, performing failure analysis, and generating the submission if the performance threshold is met.

It overrides the default epoch count to ensure the "fast baseline" requirement is met while maintaining sufficient training iterations for convergence.
