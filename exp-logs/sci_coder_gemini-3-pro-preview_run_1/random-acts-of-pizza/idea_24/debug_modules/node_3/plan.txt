The error `AssertionError: Submission row count mismatch` occurs because `library/trainer.py` imports the `load_data` function directly (`from library.data_loader import load_data`). This creates an early binding to the original function object. When `runfile.py` mocks `data_loader.load_data` to return a small subsample for the demo, `trainer.py` continues to use the original function reference, causing it to load the full dataset (1162 test rows) instead of the demo subset (20 rows).

To fix this, I will modify `library/trainer.py` to import the `library.data_loader` module rather than the specific function. This ensures that `load_data` is looked up dynamically at runtime (`data_loader.load_data`), allowing the mock injected by `runfile.py` to be correctly utilized. Cite debug_lesson_14.
