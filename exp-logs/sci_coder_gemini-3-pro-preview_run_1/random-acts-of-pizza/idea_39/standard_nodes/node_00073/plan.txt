Implementation strategy:
1.  **Setup and Configuration**: Import necessary modules and the provided library files. Monkey-patch the `library.config` parameters to reduce training epochs and estimators, ensuring the solution runs quickly as a baseline (15 epochs, 100 trees).
2.  **Instrumentation (Monkey Patching)**: Since the provided library classes calculate validation AUC internally but do not return the raw validation predictions required for the ensemble metric and failure analysis, I will monkey-patch the `compute_auc` function in `library.utils` (and its references in `model_tree` and `model_nn`). This hook will intercept and store the validation ground truth and predictions during the training process.
3.  **Pipeline Execution**: Initialize the `Trainer` and run the Random Forest and MLP training streams sequentially.
4.  **Ensemble Validation**: Retrieve the stored validation predictions. For the MLP, identify the predictions corresponding to the best validation epoch. Compute the weighted ensemble probabilities and the final AUC score.
5.  **Failure Analysis**: Load the validation metadata. Calculate the absolute prediction error (`|y_true - y_pred|`) for the ensemble. Compute and print the correlation between this error and the numerical features to identify sources of model failure.
6.  **Submission**: If the final validation AUC exceeds the specified threshold, generate ensemble predictions for the test set and save them to `submission.csv` using the provided utility function.
