This script demonstrates the end-to-end execution of the pizza request prediction pipeline using the provided library files. It performs the following steps:

1.  **Configuration**: Overrides default `Config` settings to enable `DEBUG` mode, reduce model complexity (fewer trees, fewer epochs), and limit data size for rapid execution.
2.  **Data Loading**: Uses `load_data` to retrieve a small subset of the training, validation, and test sets.
3.  **Feature Engineering**: Instantiates `FeatureProcessor` to generate semantic embeddings (SBERT), TF-IDF vectors, and interaction features. It asserts the correctness of the generated feature dictionary.
4.  **Model Training (RF)**: Runs the Random Forest pipeline (`run_rf_pipeline`), validates predictions, and checks AUC calculation.
5.  **Model Training (MLP)**: Runs the Orthogonal Skip-Gated MLP pipeline (`run_mlp_pipeline`), verifies output shapes, and checks AUC calculation.
6.  **Ensembling**: Demonstrates a simple weighted average ensemble of the two models.
7.  **Submission**: Generates a sample submission file in the working directory.
