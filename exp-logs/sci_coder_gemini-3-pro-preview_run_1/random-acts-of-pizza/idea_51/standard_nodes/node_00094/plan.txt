Since the feature engineering pipeline saves `scipy.sparse` matrices (which are Python objects) into `.npz` files, NumPy requires pickling to be enabled to load them back. To resolve this, I will update the `np.load()` calls in `library/utils.py` to explicitly set `allow_pickle=True`.
