The issue is that the pipeline is loading stale cached data (100 samples) generated during a previous debug run, even though the current configuration is set to run on the full dataset (`DEBUG=False`). This causes the models to train on insufficient data and fail validation. To fix this, I will modify the cache file naming convention in both `DataLoader` and `FeatureGenerator` to include a suffix (`_debug` or `_full`) based on the `Config.DEBUG` flag. This ensures that the system distinguishes between debug and full-dataset caches, preventing the loading of mismatched data (Cite debug_lesson_1).
