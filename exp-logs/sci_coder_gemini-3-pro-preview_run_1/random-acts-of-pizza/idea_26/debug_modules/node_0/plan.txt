This script demonstrates the end-to-end workflow for the Random Acts of Pizza prediction task using the provided library files. It performs the following steps:

1.  **Configuration**: Updates the global `Config` class to optimize for speed (reducing epochs, estimators, and batch sizes) and sets a custom working directory.
2.  **Initialization**: Sets the random seed for reproducibility.
3.  **Feature Engineering**: Uses `FeatureEngineer` to process text (TF-IDF, SBERT) and metadata features. It handles caching automatically.
4.  **Random Forest**: Trains a Random Forest classifier on the processed features and generates predictions.
5.  **Neural Network**: Trains an Attention-Gated MLP using PyTorch on the embeddings and metadata, then generates predictions.
6.  **Ensembling**: Combines predictions from both models.
7.  **Submission**: Formats and saves the final predictions to a CSV file.
8.  **Validation**: Includes assertions to verify data shapes, prediction ranges, and file outputs.
