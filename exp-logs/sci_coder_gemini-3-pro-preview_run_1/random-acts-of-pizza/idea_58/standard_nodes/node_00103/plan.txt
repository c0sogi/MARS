This script implements the orchestration logic for the "Hybrid Ensemble with Decoupled Orthogonal Skip-Gated MLP and Multi-Interaction Trees" solution. It performs the following steps:
1.  **Setup**: Initializes the environment and random seeds for reproducibility.
2.  **Data Processing**: Loads and processes features using the `FeatureGenerator` pipeline (via `get_features`), utilizing caching to speed up execution.
3.  **Model Training**:
    *   Trains the **Multi-Interaction Random Forest** (Stream A) using high-fidelity TF-IDF and interaction features.
    *   Trains the **Decoupled Gated MLP** (Stream B) using SBERT embeddings and decoupled gating mechanisms.
4.  **Validation & Ensemble**: Generates predictions on the validation set, computes a weighted ensemble average, and calculates the Area Under the ROC Curve (AUC).
5.  **Failure Analysis**: Analyzes the correlation between prediction errors and key metadata features to identify systematic weaknesses.
6.  **Submission**: If the validation metric meets the specified threshold, generates predictions for the test set and saves the submission file.
