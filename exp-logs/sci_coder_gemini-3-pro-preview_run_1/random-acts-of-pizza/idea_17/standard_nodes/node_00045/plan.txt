The issue is a shape mismatch in the ensemble step because the `predict_mlp_model` function in `library/model_mlp.py` is hardcoded to use test set features (`text_test`, etc.) regardless of whether it is predicting on the validation or test set. This causes the validation predictions to have the length of the test set (1162) instead of the validation set (576).

To fix this, I will modify `predict_mlp_model` to accept a `split` argument (defaulting to "test") and dynamically select the corresponding feature keys (e.g., `f"text_{split}"`). Then, I will update `runfile.py` to explicitly pass `split="val"` when generating validation predictions and `split="test"` for test predictions. This ensures the function logic is synchronized with the caller's intent, preventing the dimension mismatch (Cite debug_lesson_3).
