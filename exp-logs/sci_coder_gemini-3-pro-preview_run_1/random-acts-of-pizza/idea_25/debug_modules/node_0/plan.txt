The following implementation demonstrates the usage of the provided machine learning library for the Pizza Request Prediction task. It systematically instantiates and verifies the functionality of the data manager, feature engineers, neural network components, and the random forest pipeline.

The script is optimized for speed by using `debug_mode=True` and a small `debug_size` (10 samples), ensuring it runs quickly while still exercising all code paths. It includes assertions to validate data shapes, types, and model outputs. Finally, it executes the full ensemble evaluation function to generate a sample submission.
