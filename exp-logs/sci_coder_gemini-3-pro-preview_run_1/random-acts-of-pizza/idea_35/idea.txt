Based on the comprehensive analysis of previous successes (e.g., **Dual-Query Attention**, **Global Consistency**, **Gated Fusion**) and specific failures (e.g., **Peak Relevance**, **Batch Normalization Instability**, **Sparse History in Trees**), I propose a **Hybrid Ensemble with Global-Consistency Augmented Trees and Dropout-Stabilized Dual-Query MLP**.

This solution structurally evolves the "Dual-View Consistency" approach (Idea 31) and corrects the "Peak-Relevance" deviation (Idea 34). It synthesizes the finding that **Global Consistency** (comparing the request to the user's average history) is a superior signal for credibility than selective relevance (Cite solution_lesson_node_00066). Simultaneously, it stabilizes the Neural Network by strictly enforcing a **Dropout-Only** regime (removing Batch Normalization) to prevent the overfitting observed in Lesson 00062, while retaining the high-performance **Dual-Query Attention** architecture (Cite solution_lesson_node_00059).

# Model

The solution employs an ensemble of two distinct, highly optimized learners fused via robust averaging.

**1. Stream A: Global-Consistency Augmented Random Forest**
*   **Goal**: Equip the Random Forest with a robust, multi-view representation of user history that prioritizes "Persona Consistency" (Global) and specific high-frequency behaviors (Top-K), avoiding the noise of full sparsity or the signal loss of selective max-pooling.
*   **Architecture**: A Random Forest Classifier with balanced class weights (Cite solution_lesson_node_00004).
*   **Input**:
    *   **High-Fidelity TF-IDF**: Concatenated Title+Body TF-IDF with continuous frequency weights and a large vocabulary (e.g., 5,000) (Cite solution_lesson_node_00031).
    *   **Full-Spectrum Metadata**: **Raw Magnitudes** (e.g., account age) + **Engineered Ratios** (e.g., upvote ratio) + **Text Meta-Features** (e.g., caps ratio) (Cite solution_lesson_node_00021, solution_lesson_node_00013).
    *   **Top-K Binary Community Indicators**: Binary flags (0/1) for the top $K=50$ most frequent subreddits. This provides specific, high-signal splits for common communities (Cite solution_lesson_node_00055).
    *   **Global Alignment Scalars (Structural Innovation)**:
        *   Calculate the **Cosine Similarity** between the *Request Title* and the *User History Centroid* (Mean of all past subreddit embeddings).
        *   Calculate the **Cosine Similarity** between the *Request Body* and the *User History Centroid*.
        *   **Rationale**: As identified in Lesson 00066, comparing against the *average* behavior (Global Consistency) is more predictive of credibility than finding the single best match (Peak Relevance). This gives the tree a dense signal for "Anomalous Request Detection."
    *   **Sentiment Scores**: VADER polarity and subjectivity scores to capture emotional tone.
*   **Configuration**: **Low Regularization** (`min_samples_leaf=1`) to preserve fine-grained sparse signals (Cite solution_lesson_node_00057).

**2. Stream B: Dropout-Stabilized Dual-Query MLP**
*   **Goal**: Model the complex interaction between Request and History using the most effective attention architecture found, stabilized for small-data training by removing noisy normalization layers.
*   **Architecture**: A neural network with multiple branches and a Gated Fusion mechanism.
    *   **Branch 1 (Title Semantics)**: Processes **Raw SBERT embedding** of Title (No early projection) (Cite solution_lesson_node_00051).
    *   **Branch 2 (Body Semantics)**: Processes **Raw SBERT embedding** of Body.
    *   **Branch 3 (Dual-Query History Attention)**:
        *   **Input**: Sequence of **Raw SBERT embeddings** for user history.
        *   **Head A (Topic Context)**: **Dot-Product Attention** (Query=Title, Key=History) (Cite solution_lesson_node_00059).
        *   **Head B (Narrative Context)**: **Dot-Product Attention** (Query=Body, Key=History).
        *   **Masking**: Apply **Explicit Additive Masking** ($-\infty$ to padding) before Softmax (Cite solution_lesson_node_00053).
    *   **Alignment Injection**: Concatenate the Global Alignment Scalars ($S_{title\_global}$, $S_{body\_global}$) to the fusion layer (Cite solution_lesson_node_00061).
    *   **Branch 4 (Metadata)**: Processes metadata via **Arcsinh Transformation** (Cite solution_lesson_node_00025).
    *   **Gated Fusion**: Metadata generates a **Credibility Gate** modulating the concatenated semantic vector (Cite solution_lesson_node_00028).
    *   **Regularization (Correction)**: **Dropout Only**. Explicitly remove all Batch Normalization layers. Use Dropout (e.g., 0.5 on embeddings, 0.2 on dense layers) to prevent the instability and overfitting observed in Lesson 00062.

# Data

1.  **Leakage Prevention**: Strictly apply `get_feature_intersection` to restrict inputs to columns present in both train and test sets (Cite solution_lesson_node_00002).
2.  **Semantic Feature Engineering**:
    *   Compute SBERT embeddings for Title, Body, and all User Subreddits.
    *   **Centroid**: Mean of user subreddit embeddings.
    *   **Global Alignment**: Dot-product between Request components and History Centroid.
3.  **Top-K Profiling**:
    *   Identify top 50 subreddits by frequency in `train`.
    *   Generate binary flags for train and test.
4.  **Preprocessing**:
    *   **Stream A (RF)**: Impute NaNs with median.
    *   **Stream B (MLP)**: Apply **Arcsinh Transformation** followed by **StandardScaler** to numerical metadata (Cite solution_lesson_node_00025).

# Training

1.  **Random Forest**: Trained with 500 estimators, balanced class weights, and `min_samples_leaf=1` (Cite solution_lesson_node_00057).
2.  **MLP**:
    *   **Optimizer**: AdamW with weight decay.
    *   **Regularization**: Dropout Only (Cite solution_lesson_node_00062).
    *   **Protocol**: **High Patience** (e.g., 15 epochs) and sufficient total epochs (e.g., 50) to allow the Dual-Attention layers to stabilize (Cite solution_lesson_node_00016).
3.  **Independence**: Train both models independently on the full training set.

# Evaluation

1.  **Inference**: Process test data through dual pipelines (Global-Consistency/Top-K/TF-IDF for RF, Sequence-History/SBERT for MLP).
2.  **Ensemble**: Calculate final probability as **Simple Weighted Average** (0.5/0.5) of the two models (Cite solution_lesson_node_00020).
