The issue is that the `load_data` function in `library/utils.py` uses `config.DEBUG` as a default argument value, which is evaluated only once at module import time (when `config.DEBUG` is `False`). Even though `runfile.py` updates `config.DEBUG` to `True` at runtime, `load_data` continues to use the stale default value (`False`) when called without arguments, causing it to load the full dataset instead of the debug subset. This leads to an assertion error when checking the dataset size.

To fix this, I will modify `load_data` to use `None` as the default value for the `debug` parameter and resolve the actual value from `config.DEBUG` inside the function body. This ensures the function uses the current runtime value of the configuration variable (Cite debug_lesson_3).
