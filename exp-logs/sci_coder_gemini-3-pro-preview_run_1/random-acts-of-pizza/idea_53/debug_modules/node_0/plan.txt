The following script demonstrates the end-to-end usage of the provided library components. To ensure rapid execution within the demonstration context, the script first creates a "mini" dataset (subset of the original metadata) and overrides the global configuration to use this subset and reduce model complexity (fewer estimators, fewer epochs). It then proceeds to train and evaluate both the Random Forest (Stream A) and Neural Network (Stream B) pipelines, verifying their outputs and logic along the way, before finally generating a submission file.
