Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup and Imports**: Import the necessary standard libraries (`pandas`, `numpy`) and the pre-defined modules from the `library` package (`config`, `utils`, `data_loader`, `model`). Set the random seed for reproducibility.
2.  **Data Loading**: Use `data_loader.load_data(load_cached_data=True)` to efficiently load the training, validation, and test datasets. The loader handles text combination and feature selection automatically.
3.  **Model Training**: Initialize the `PizzaRandomForest` class from `library.model`. Train it on the full training dataset. Given the dataset size (~2000 samples), the Random Forest will train very quickly without needing subsampling.
4.  **Validation and Metric**:
    *   Generate probability predictions for the validation set using `model.evaluate`.
    *   Calculate the ROC AUC score using `sklearn.metrics.roc_auc_score`.
    *   Print the required "Final Validation Metric: <value>" string with full precision.
5.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample: $|y_{true} - y_{pred}|$.
    *   Compute the Pearson correlation between this error term and each numerical feature available in the validation set.
    *   Print the top features most correlated with prediction error to identify potential weak points.
6.  **Inference and Submission**:
    *   Generate predictions for the test set using `model.predict_proba`.
    *   Extract `request_id`s and save the results to `./submission/submission.csv` using `utils.save_submission`.
