The error `pyarrow.lib.ArrowTypeError` occurs because the `request_text` column, which contains raw text and missing values (`NaN`), is not excluded from the dataset before saving to Parquet. The global `fillna(0)` operation replaces these `NaN`s with the integer `0`, creating a mixed-type column (strings and integers) that Parquet cannot serialize. This violates the principle of segregating imputation by data type (Cite debug_lesson_22).

1.  Add `request_text` to the `drop_cols` list in `library/feature_manager.py` to ensure this raw text column is excluded from the numerical/RF feature set.
2.  Replace the global `fillna(0)` with a type-aware imputation function (`safe_fill`) that fills numeric columns with `0`, object columns with `""`, and boolean columns with `False`. This prevents creating mixed-type columns in the future.
