The implementation strategy is as follows:

1.  **Setup and Initialization**: Import necessary libraries and the provided modules from the `library` package. Set the random seed for reproducibility.
2.  **Model Training**: Invoke `train_rf_model` and `train_nn_model` from `trainer.py`. We utilize the full dataset (since it is small, ~2.3k samples) and cached data to ensure the best possible performance to meet the strict AUC threshold, while relying on the inherent speed of the small dataset to satisfy the runtime constraints.
3.  **Ensemble Validation**:
    *   Load the validation dataset for both the Random Forest (tabular) and Neural Network (embeddings/sequences).
    *   Generate probability predictions from both models.
    *   Compute the weighted average of probabilities based on `ENSEMBLE_WEIGHTS`.
    *   Calculate the ROC AUC score and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the absolute error magnitude (`|True Label - Predicted Probability|`) for the validation set.
    *   Calculate the Pearson correlation between this error magnitude and all input features (metadata, sentiment, TF-IDF).
    *   Print the top 10 features most correlated with model error to identify systematic weaknesses.
5.  **Submission Generation**:
    *   Compare the final validation AUC against the provided threshold (`0.7036289345758168`).
    *   If the model performs sufficiently well, call `generate_submission` to predict on the test set and save the result to `./submission/submission.csv`.
