The issue is that the `save_checkpoint` and `load_checkpoint` functions in `library/utils.py` use `Config.MODEL_SAVE_PATH` as a default argument value. In Python, default arguments are evaluated once at function definition time (when the module is imported). Consequently, when `runfile.py` updates `Config.MODEL_SAVE_PATH` at runtime to point to the demo directory, the functions retain the original path value, causing the model to be saved in the wrong location and the assertion to fail (Cite debug_lesson_1).

To fix this, I will modify `save_checkpoint` and `load_checkpoint` to use `None` as the default value for the path (and device) arguments. Inside the function body, I will check if the argument is `None` and assign the current value from `Config`. This ensures the updated configuration is respected during execution.
