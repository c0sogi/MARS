The strategy is to create a Python script that generates metadata CSV files for the training, validation, and test sets. 

1.  **Data Loading**: We will use `pandas` to read the `train.csv` and `test.csv` files. To optimize for memory and speed given the potentially large file size (130M lines mentioned, though likely fewer records due to multiline text), we will only read the necessary columns: `Id` and `Tags` for training, and `Id` for testing.
2.  **Splitting**: We will split the training data into an 80% training set and a 20% validation set using `sklearn.model_selection.train_test_split` with a fixed random state (42).
    *   *Stratification Note*: While the task is classification, the target `Tags` column consists of space-delimited multi-label combinations. Exact stratification on these unique strings is impractical due to high cardinality and singleton classes (combinations appearing only once). Standard multi-label stratification is computationally expensive for millions of rows. Given the large dataset size, a random split is statistically sufficient to preserve the distribution. We will verify this by comparing tag frequencies.
3.  **Metadata Generation**:
    *   We will add a `file_path` column to the dataframes, pointing to the relative paths `train.csv` and `test.csv` respectively.
    *   The resulting dataframes will be saved to `./metadata/train_metadata.csv`, `./metadata/val_metadata.csv`, and `./metadata/test_metadata.csv`.
4.  **Verification**:
    *   We will reload the generated metadata to verify integrity.
    *   We will check that the validation split ratio is correct (~20%).
    *   We will verify that the referenced file paths exist in `./input`.
    *   We will compare the distribution of the most frequent tags in the training and validation sets to ensure the split is representative.
