I will also rename the model class to be generic and update the training loop to run a single stage for more epochs.

Here are the changes:

1.  **`library/dataset.py`**: Update `get_dataloaders` to accept `max_samples_per_class` and implement the hard undersampling logic (Cite `solution_lesson_node_00009`).

3.  **`library/inference.py`**: Update the import and usage of the renamed model class.
