The following script demonstrates the end-to-end usage of the provided library files. It covers data loading, model instantiation, training loop execution, and inference generation.

The strategy is as follows:
1.  **Setup & Reproducibility**: Initialize the environment and set random seeds.
2.  **Data Pipeline Verification**: Initialize dataloaders in debug mode (using a small data subset) and verify batch shapes and data types.
3.  **Model Logic Verification**: Instantiate the EfficientNet model, perform a forward pass with dummy data, and verify the backbone freezing/unfreezing logic.
4.  **Training Loop Demonstration**: Configure the `Trainer` with a loss function and optimizer, then run a single epoch of training to generate a checkpoint.
5.  **Inference Demonstration**: Use the generated checkpoint to run the inference pipeline and produce a submission file, verifying the output format.
