To improve the model's Macro F1 score, I will implement a **Class-Balanced Subsampling** strategy instead of the previous uniform random subsampling. The previous method randomly selected 20% of the data, which statistically purged thousands of rare classes (tail collapse), making it impossible for the model to learn them. As noted in the lesson (Cite solution_lesson_node_00001), Macro F1 requires the model to perform well on all classes, regardless of frequency.

My strategy involves:
1.  **Data Selection**: I will modify `runfile.py` to create a training subset that keeps up to $N=12$ images per class. This ensures that every single class (even those with 1 sample) is present in the training set, while downsampling the frequent "head" classes to prevent them from dominating the gradients. This should result in a dataset of approximately 450,000-500,000 images.
2.  **Training Schedule**: I will increase the number of epochs from 3 to 5. Given the slightly larger dataset and the need for the model to learn 64,500 distinct categories, more iterations are necessary. The estimated runtime (~2.5 hours) remains well within the 4-hour limit.
3.  **Conditional Submission**: I will add the logic to only generate the submission file if the validation metric exceeds the previous baseline of ~0.097.
