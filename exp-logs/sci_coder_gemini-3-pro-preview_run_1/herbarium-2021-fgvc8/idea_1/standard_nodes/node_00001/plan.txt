    *   Subsample the training data to 300,000 images (~20% of the total) to create a "fast baseline" that trains quickly while still providing a meaningful signal. Save this subsample to a temporary CSV and update `Config.TRAIN_CSV` to point to it.

    *   After training, perform a full inference pass on the validation set using the trained model.
    *   Calculate and print the **Macro F1 score** as required (`Final Validation Metric: <value>`).
5.  **Failure Analysis**: 
    *   Select a subset (first 2000 images) of the validation set for detailed analysis to save I/O time.
    *   Load these images to extract input features (width, height, aspect ratio).
    *   Calculate the correlation between the model's error (1 for incorrect, 0 for correct) and these features to identify potential biases or weaknesses.
6.  **Submission**: Call the provided `predict_and_submit` function to generate predictions for the test set and save the `submission.csv` file.
