This script demonstrates the end-to-end workflow of the plant species classification task using the provided library modules.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes to enable `DEBUG` mode, reduce the number of epochs to 1, and set a small sample size. This ensures the demonstration runs quickly while exercising all code paths.
2.  **Data Loading Verification**: We utilize `get_dataloaders` to load the training and validation sets. We verify the integrity of the data by checking batch shapes and ensuring label indices are within the valid range defined by the class mapping.
3.  **Model Instantiation**: We initialize the ResNet-18 model using `get_model` and verify its forward pass on a dummy batch to confirm the output dimensions match the number of classes.
4.  **Training Loop Execution**: We instantiate the `Trainer` class and execute the `train()` method. This validates the training loop, loss calculation, backpropagation, validation evaluation, and model checkpointing logic.
5.  **Inference and Submission**: We invoke `predict_and_submit` to generate predictions on the test set using the trained model. Finally, we validate the structure and content of the generated `submission.csv` file.
