Based on the comprehensive analysis of the previous experiments and the specific lessons learned, I propose the following optimized strategy. This solution structurally evolves the approach by introducing **Multi-Sample Dropout** and **Layer Re-initialization** into the **Adversarial Seed Ensemble**. These architectural changes are specifically designed to counteract the severe overfitting and memorization observed in Lesson 00047 while maintaining the robustness gains from Lesson 00046.

# Model
**Architecture: Regularized Multi-Task XLM-R Large**
*   **Backbone:** We will utilize **`xlm-roberta-large`**. As established, this generalist model outperforms region-specific ones in low-data regimes (Cite solution_lesson_node_00024).
*   **Structural Innovation 1 (Layer Re-initialization):** We will re-initialize the weights of the **top encoder layer** (Layer 23) of the backbone before training. The top layers of massive pre-trained models are highly specialized for the pre-training objective (Masked Language Modeling). By resetting them, we force the model to construct high-level features specific to this QA task from scratch, reducing the bias towards pre-trained patterns and slowing down the "memorization" of noise.
*   **Structural Innovation 2 (Multi-Sample Dropout):** We will replace the standard dropout in the classification heads with **Multi-Sample Dropout**. Instead of a single dropout mask, we will generate $K$ (e.g., 5) different dropout masks in parallel, pass the features through the fully connected layer $K$ times, and average the resulting losses. This technique acts as an "ensemble within the model," significantly accelerating convergence and improving generalization on small datasets by smoothing the loss landscape.
*   **Multi-Task Heads:** The model will retain the dual-head structure (Span Predictor + Relevance Classifier) to explicitly model answer presence (Cite solution_lesson_node_00030).

# Data
**Preprocessing & Caching:**
1.  **Token-Based Windowing:** Use the `xlm-roberta-large` tokenizer with `return_overflowing_tokens=True` and `return_offsets_mapping=True` to ensure precise splitting of long documents (Cite solution_lesson_node_00005).
2.  **Random Negative Sampling:** Generate all sliding windows. Retain 100% of "Positive" windows and randomly downsample "Negative" windows to maintain a strict **2:1 Negative-to-Positive ratio** (Cite solution_lesson_node_00021).
3.  **Full Dataset Merging:** Concatenate `train.csv` and `val.csv` into a single training set. We will not use cross-validation, as maximizing the training signal is critical (Cite solution_lesson_node_00027).
4.  **Deterministic Caching:** Save the processed features (including the specific random selection of negatives) to disk with explicit type sanitization to ensure reproducibility (Cite solution_lesson_node_00010, solution_lesson_node_00014).

# Training
**Procedure: Short-Schedule Adversarial Seed Ensemble**
*   **Ensemble Strategy:** Train **3 independent models** on the full merged dataset, initialized with different random seeds (Cite solution_lesson_node_00046).
*   **Adversarial Training:** Wrap the model with **Fast Gradient Method (FGM)**. Crucially, apply **Loss Normalization** (averaging clean and adversarial losses) to prevent gradient explosion (Cite solution_lesson_node_00039).
*   **Optimization Strategy:**
    *   **Differential Learning Rates (DLR):** Apply a low rate (`1e-5`) to the backbone and a higher rate (`5e-5`) to the heads (Cite solution_lesson_node_00031), using explicit module grouping (Cite solution_lesson_node_00033).
    *   **Global Weight Decay:** Apply weight decay to **ALL** parameters (including biases/LayerNorms) to dampen model capacity and prevent overfitting (Cite solution_lesson_node_00036).
    *   **Loss Weighting:** Strictly down-weight the auxiliary relevance loss: $L = L_{span} + 0.5 \times L_{relevance}$ (Cite solution_lesson_node_00035).
    *   **Short Duration:** Train for exactly **3 epochs**. Lesson 00047 demonstrated that extending training to 5 epochs causes severe overfitting (loss < 0.2) without validation gain. We rely on Multi-Sample Dropout to achieve robust convergence within this short horizon.

# Evaluation
**Inference Pipeline:**
1.  **Exhaustive Sliding Windows:** Process the test set into overlapping token-based windows and run inference on **every** chunk (Cite solution_lesson_node_00004).
2.  **Ensemble Aggregation:** For each window, average the `start`, `end`, and `relevance` logits across the 3 seed models.
3.  **Gated Scoring:** Calculate the final confidence score:
    $$ \text{Score} = (\text{Start\_Logit} + \text{End\_Logit}) + \text{Relevance\_Logit} $$
    (Cite solution_lesson_node_00030).
4.  **Reconstruction:** Select the span with the maximum Gated Score and map it back to the original text using the offset mapping.
