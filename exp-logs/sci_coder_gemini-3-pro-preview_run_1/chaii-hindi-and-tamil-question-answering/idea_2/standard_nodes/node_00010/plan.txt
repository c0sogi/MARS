The issue stems from `offset_mapping` being deserialized from the Parquet file as a NumPy array of objects (specifically `numpy.object_`) rather than a standard numeric structure. PyTorch's `torch.tensor()` function cannot convert arrays of type `object` directly to tensors, causing the `TypeError`. To fix this, we must explicitly convert the `offset_mapping` data into a Python list using `.tolist()` before passing it to `torch.tensor`. This ensures the validation process correctly handles the metadata required for inference-style evaluation, aligning with the principle of mirroring inference logic during validation (Cite debug_lesson_1).
