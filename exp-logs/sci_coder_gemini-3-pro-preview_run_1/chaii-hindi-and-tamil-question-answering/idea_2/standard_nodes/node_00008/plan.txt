The implementation strategy is to orchestrate the Extractive QA pipeline using the provided library modules. The script will first initialize the environment and load the data using `get_processed_data` (leveraging caching for speed) and `QADataset`. It will then initialize the `xlm-roberta-base` model and the optimizer. The training loop will run for a fixed number of epochs (defined in Config), invoking `train_fn` for training and `eval_fn` for validation at each step, saving the best model based on the Jaccard score. After training, the script will output the "Final Validation Metric" in the required format. It will then perform failure analysis by running inference on the validation set using the best model, calculating the error (1 - Jaccard) for each sample, and computing the Pearson correlation between the error and input text lengths (context and question). Finally, if the best validation score exceeds the specified threshold, the script will generate predictions for the test set using `predict_fn` and save them to the submission file using `save_submission`.
