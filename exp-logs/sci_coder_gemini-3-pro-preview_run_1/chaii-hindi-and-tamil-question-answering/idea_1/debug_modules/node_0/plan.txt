This script demonstrates the end-to-end workflow for the Hindi/Tamil Question Answering task using the provided library files. It covers configuration setup, utility validation, data loading, model training, and inference generation.

To optimize for speed and ensure the demonstration runs quickly within the allotted time, the script overrides `Config.DEBUG` to `True` (reducing the dataset to a few samples) and sets `Config.EPOCHS` to 1. It also includes assertions to verify the correctness of key utility functions and the integrity of the output files.
