This script demonstrates the end-to-end workflow of the provided Question Answering pipeline. It overrides the default configuration to run in "Debug" mode with a small subset of data and a lighter model backbone (`xlm-roberta-base` instead of `large`) to ensure rapid execution and verification within the time limit.

The script performs the following steps:
1.  **Configuration Override**: Adjusts `Config` parameters for a fast demonstration (1 epoch, debug data size, single seed, base model).
2.  **Data Loading**: Uses `create_loaders` to process the raw metadata into PyTorch DataLoaders.
3.  **Model Initialization & Verification**: Instantiates the `MultiTaskXLMR` model and validates the forward pass output shapes.
4.  **Training Loop**: Runs the `Trainer` for one epoch on the debug dataset and verifies the model checkpoint is saved.
5.  **Inference Pipeline**: Executes `run_inference` to generate predictions on the test set and validates the submission file format.
