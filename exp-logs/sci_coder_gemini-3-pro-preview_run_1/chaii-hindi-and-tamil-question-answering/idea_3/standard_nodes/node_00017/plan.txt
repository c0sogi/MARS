Here is the implementation of the `runfile.py` script. This solution implements a robust 5-Fold Cross-Validation Ensemble using the MuRIL backbone. It trains five independent models on stratified folds of the training data, aggregates their predictions via logit averaging, and performs a comprehensive evaluation on the hold-out validation set before generating the final submission.

The script includes:
1.  **Ensemble Training:** Iterates through 5 folds, training a model for each and accumulating inference logits for both validation and test sets.
2.  **Validation & Scoring:** Reconstructs answer spans for the hold-out validation set and computes the official Jaccard metric.
3.  **Failure Analysis:** Correlates prediction errors with context and question lengths to identify performance bottlenecks.
4.  **Conditional Submission:** Generates the `submission.csv` only if the validation score exceeds the specified threshold.
