Implementation Strategy:
The implementation will follow a linear pipeline to demonstrate the usage of the provided library components. 
1.  **Configuration Setup**: I will override the default `Config` attributes to create a lightweight execution environment suitable for a demonstration. This includes enabling `DEBUG` mode (to use a tiny subset of data), reducing `EPOCHS` to 1, disabling Adversarial Training (`USE_FGM = False`) for speed, and setting `NUM_WORKERS` to 0. I will also redirect working directories to `./working/demo_run` to ensure a clean state.
2.  **Data Processing**: I will utilize `library.data.prepare_data` to load and tokenize the data. I will explicitly disable caching to demonstrate the processing logic and assert that the resulting datasets are populated.
3.  **Model Initialization**: I will instantiate the `CustomXLMRoberta` model from `library.model` and move it to the GPU. I will perform a sanity check by running a forward pass with a single batch from the training loader to verify that the output logits (`start`, `end`, `relevance`) have the correct shapes.
4.  **Training**: I will configure the optimizer using `library.utils.get_optimizer_grouped_parameters` and execute the training loop using `library.engine.train_fn`. I will verify that the returned loss is a valid number.
5.  **Inference**: After training, I will save the model checkpoint to the expected output directory. Then, I will invoke `library.inference.run_inference`, which loads the test data and the saved model to generate predictions.
6.  **Validation**: Finally, I will verify that the `submission.csv` file is generated correctly and contains the expected columns.
