Based on the comprehensive analysis of the previous experiments and the specific lessons learned, I propose the following optimized strategy. This solution introduces a **Multi-Task Learning Architecture** to explicitly model window relevance, upgrades the backbone to **XLM-Roberta-Large** to maximize cross-lingual transfer, and implements a **Full-Data Training Strategy** to counteract the data starvation observed in cross-validation.

### Model
**Architecture: Multi-Task Extractive Network**
I propose a structural evolution from a simple span-prediction model to a **Multi-Task Network**.
*   **Backbone:** Upgrade from `xlm-roberta-base` to **`xlm-roberta-large`**. Lesson 00024 demonstrated that generalist multilingual models outperform region-specific ones (MuRIL) in this low-resource setting. Scaling to the "Large" variant leverages greater model capacity to capture latent cross-lingual patterns from the massive pre-training corpus, compensating for the scarcity of fine-tuning data.
*   **Dual Heads:**
    1.  **Span Head:** A standard linear layer to predict `start_logits` and `end_logits` for the answer span (Cite solution_lesson_node_00008).
    2.  **Relevance Head (Innovation):** A binary classification head applied to the `[CLS]` token embedding to predict whether the current window contains an answer or is irrelevant. This explicitly supervises the model to discriminate between positive and negative windows, reinforcing the signal provided by negative sampling (Cite solution_lesson_node_00021).

### Data
**Preprocessing:**
1.  **Token-Based Windowing:** Utilize the `xlm-roberta-large` tokenizer with `return_overflowing_tokens=True` and `return_offsets_mapping=True`. This ensures precise, token-aligned splitting of long documents without heuristic data loss (Cite solution_lesson_node_00005).
2.  **Negative Sampling:** Generate all possible sliding windows. Retain 100% of windows containing the answer. Randomly sample the "no-answer" windows to maintain a strict **2:1 Negative-to-Positive ratio**. This prevents the class imbalance that previously caused convergence failure (Cite solution_lesson_node_00021).
3.  **Dataset Merging (Crucial):** Concatenate the provided `train.csv` and `val.csv` (metadata splits) into a single **Combined Training Set**. Lesson 00027 proved that withholding 20% of the data for validation (or cross-validation) starves the model in this extreme low-resource regime (<1000 samples). We will train on the maximum available data.
4.  **Deterministic Caching:** Save the processed, merged, and sampled features to disk (Parquet) with explicit type sanitization (converting Numpy arrays to Lists). This locks in the stochastic negative sampling for reproducibility and efficiency (Cite solution_lesson_node_00010, solution_lesson_node_00014).

### Training
*   **Procedure:** Train a single instance of the model on the Combined Training Set.
*   **Joint Loss Function:** Minimize a weighted sum of losses: $L = L_{span} + \lambda L_{cls}$, where $L_{span}$ is Cross-Entropy for start/end tokens and $L_{cls}$ is Binary Cross-Entropy for the window relevance head.
*   **Hyperparameters:**
    *   **Batch Size:** Set to **4**. This accommodates the larger memory footprint of the `Large` backbone while maintaining the noise/regularization benefits of small batches observed in Lesson 00011.
    *   **Epochs:** Train for a fixed duration (e.g., 5 epochs), derived from the convergence behavior of previous successful runs (Cite solution_lesson_node_00011).

### Evaluation
*   **Exhaustive Inference:** Process the test set using the same token-based sliding window strategy. Run the model on **every** generated chunk without heuristic filtering (Cite solution_lesson_node_00004).
*   **Gated Score Aggregation:** For each window, compute a **Gated Confidence Score**:
    $$ \text{Score} = (\text{Start\_Logit} + \text{End\_Logit}) + \text{Relevance\_Logit} $$
    This mechanism uses the new Relevance Head to suppress high-confidence span predictions that appear in contextually irrelevant windows, reducing false positives.
*   **Selection:** For each document ID, select the span with the maximum Gated Confidence Score across all its windows.
*   **Reconstruction:** Map the selected token span back to the original text using the offset mapping to produce the final quoted prediction string.
