The `NameError: name 'BASE_SEED' is not defined` occurs because list comprehensions in Python 3 create their own local scope. When defined directly inside a class body, the comprehension cannot access other variables defined in that class scope (like `BASE_SEED`) because the class scope is not yet fully formed or accessible as a closure. To fix this, I will move the calculation of `SEEDS` into the `__init__` method, where these values can be accessed reliably via `self`.
