The error arises because list comprehensions defined directly within a class body (like `SEEDS = [BASE_SEED + i for i in range(N_SEEDS)]`) cannot access other class attributes (`BASE_SEED`) due to Python's scoping rules for comprehensions. This is a known issue where the comprehension creates a new scope that doesn't see the class namespace (Cite debug_lesson_6).

To fix this, I will remove the problematic class-level definition of `SEEDS`. The `Config` class already initializes `self.SEEDS` correctly inside the `__init__` method (where `self.BASE_SEED` is accessible), so the class-level definition is both redundant and the cause of the crash.
