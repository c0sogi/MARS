The following script demonstrates the end-to-end usage of the provided library files for the Hindi/Tamil Question Answering task. It initializes the configuration with overrides for a fast execution (debug mode), loads and verifies the datasets, instantiates the custom XLM-RoBERTa model, runs a single epoch of training, saves the model checkpoint, and finally executes the inference pipeline to generate a submission file. Assertions are included throughout to verify data structures and model outputs.
