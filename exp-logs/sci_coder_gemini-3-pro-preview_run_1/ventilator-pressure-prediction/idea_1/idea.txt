To establish a robust and efficient baseline, I propose a **Masked Bidirectional LSTM** approach. This solution simplifies the complex "Model 1" architecture described in the provided materials by removing heavy feature engineering (PID terms) and reducing network depth, focusing instead on a direct mapping of raw signals to pressure with a metric-aligned training strategy.

### Model
The architecture is a shallow, sequence-to-sequence regression model designed to capture the temporal dynamics of the breath cycle.
*   **Input Layer:** Accepts a sequence of shape `(Sequence Length, Feature Count)`. The input features are the raw time-varying controls (`u_in`, `u_out`, `time_step`) and the static lung attributes (`R`, `C`) which are repeated across all time steps of a breath.
*   **Recurrent Backbone:** Consists of two stacked Bidirectional LSTM (Long Short-Term Memory) layers. The bidirectional nature allows the model to utilize information from both past and future control inputs within the breath to infer the current pressure state.
*   **Projection Head:** A single fully connected (Linear) layer applied to the output of the LSTM at every time step to project the high-dimensional hidden states down to a scalar `pressure` prediction.

### Data
Preprocessing focuses on transforming the tabular CSV data into a 3D format suitable for sequence modeling while ensuring numerical stability.
1.  **Normalization:** Apply `StandardScaler` or `RobustScaler` to the continuous features (`u_in`, `time_step`, `R`, `C`) to center the data and scale it to unit variance. `u_out` is binary and left as is.
2.  **Reshaping:** Group the training and test data by `breath_id`. Since each breath in this dataset has a fixed length (80 time steps), reshape the data from `(Total Rows, Features)` to `(Number of Breaths, 80, Features)`.
3.  **Splitting:** Utilize the provided metadata split (train/val) to create distinct tensors for training and validation, ensuring no breath leakage.

### Training
The training procedure is optimized for the specific competition metric (MAE on the inspiratory phase).
*   **Loss Function:** Use Mean Absolute Error (L1 Loss). Crucially, implement a **Masked Loss**: multiply the calculated error at each time step by `(1 - u_out)`. This ensures gradients are only propagated for the inspiratory phase (where `u_out=0`), effectively forcing the model to prioritize the part of the breath that is actually scored, while ignoring the expiratory phase.
*   **Optimizer:** Use the AdamW optimizer for stable convergence.
*   **Scheduler:** Implement a `OneCycleLR` or `ReduceLROnPlateau` scheduler to rapidly traverse the loss landscape and fine-tune the weights.
*   **Batching:** Use a moderate batch size (e.g., 256 or 512) to maximize GPU throughput on the A100.

### Evaluation
1.  **Inference:** Pass the reshaped test set batches through the trained model to generate pressure sequences.
2.  **Post-processing:** Flatten the predicted sequences from `(Number of Breaths, 80)` back to a 1D array matching the original test set order.
3.  **Submission:** Construct the submission dataframe using the `id` column from the test set and the flattened predictions, then save to CSV.
