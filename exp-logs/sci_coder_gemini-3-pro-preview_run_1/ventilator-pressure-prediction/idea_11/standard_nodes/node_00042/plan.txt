Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration Override**: To adhere to the "fast baseline" requirement while maintaining model performance, I will override `Config.EPOCHS` to 15 (down from 35). This ensures the training completes well within the 2-hour limit on the provided A100 GPU, while allowing sufficient convergence to potentially meet the strict validation threshold. I will use the full dataset (`debug_limit=None`) to maximize the score.
2.  **Training**: I will execute `library.train.run_training` to train the model. This function handles data loading (with caching), model initialization, and the training loop with checkpointing.
3.  **Validation & Metric Calculation**:
    *   After training, I will reload the best saved model (`model.pth`) and the validation data loader.
    *   I will perform inference on the full validation set in evaluation mode (`model.eval()`), disabling gradients to optimize speed and memory.
    *   I will compute the `Final Validation Metric` using the provided `masked_mae_metric` function, strictly adhering to the output format requirements.
4.  **Failure Analysis**:
    *   I will isolate the inspiratory phase data (where `u_out == 0`) since the metric only evaluates this phase.
    *   I will calculate the absolute error for each prediction.
    *   I will compute and print the Pearson correlation between the error magnitude and all input features to identify sources of systematic error.
5.  **Submission**:
    *   I will compare the calculated validation metric against the threshold `0.2164510190486908`.
    *   If the condition is met, I will trigger `library.predict.generate_submission` to create the `submission.csv` file.
