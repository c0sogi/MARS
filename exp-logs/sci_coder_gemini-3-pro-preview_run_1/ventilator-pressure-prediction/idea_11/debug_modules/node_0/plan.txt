The following script demonstrates the end-to-end workflow of the Ventilator Pressure Prediction solution using the provided library modules.

**Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to reduce the number of epochs and batch size, ensuring the demonstration runs quickly.
2.  **Data Loading Verification**: We utilize `get_data_loaders` with a `debug_limit` to load a small subset of the data. We assert the correctness of tensor shapes (batch size, sequence length, feature dimensions).
3.  **Metric Unit Test**: We manually verify the `masked_mae_metric` function using synthetic tensors to ensure the masking logic (ignoring the expiratory phase) functions as expected.
4.  **Model Forward Pass**: We instantiate the `VentilatorModel`, perform a forward pass with real data, and verify the output shapes of the main and auxiliary heads.
5.  **Training Execution**: We run the full training loop via `run_training` for a single epoch on the subset of data and verify that the model checkpoint is saved.
6.  **Inference & Submission**: We execute `generate_submission` using the trained checkpoint and verify the format and existence of the resulting submission file.
