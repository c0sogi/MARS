The issue is that the `library/data.py` script expects a `CONTEXT_FEATURES` list in the configuration module to define which features (specifically the lung attributes `R` and `C`) should be prioritized for the "Curated Context" model architecture. However, this variable is missing from `library/config.py`, causing an `AttributeError`. This reflects a desynchronization between the configuration parameters and the architectural refactoring (Cite debug_lesson_3). I will fix this by defining `CONTEXT_FEATURES = ["R", "C"]` in `library/config.py` and adding it to the configuration dictionary for completeness.
