# Proposed Strategy: Wide-State Identity-Residual Physics-Injected Composite Network

This strategy introduces a structural evolution designed to resolve the conflict between "High Capacity" and "Training Stability" observed in previous attempts. It combines the **Wide-State** philosophy (Lesson 55) with **Strict Identity Residuals** (Lesson 64) to create a high-bandwidth gradient highway, while retaining the successful **Composite Block** design (Lesson 40) and **Deep Context Injection** (Lesson 35).

### Model
The architecture is a **Wide-State Identity-Residual Physics-Injected Composite Network**. It is designed to maintain a constant, wide latent dimension throughout the backbone without bottlenecking the Bi-LSTMs or corrupting the residual stream with unnecessary projections.

*   **Stem (Multi-Scale CNN):** The input sequence is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. The outputs are concatenated and projected to a model width of **$D_{model} = 512$** (Cite solution_lesson_node_00015).
*   **Backbone (Wide-State Identity-Residual Blocks):** The core consists of a stack of **4 Composite Blocks**. Crucially, we define the backbone width $D_{model}$ to exactly match the natural output dimension of the Bi-LSTMs ($2 \times \text{Hidden}$), enabling strict identity mappings.
    1.  **Deep Context Injection:** The input to the block is $x$ (dim 512). We form the LSTM input by concatenating $x$ with the **Static Physics Features** ($x_{in} = [x, F_{phys}]$). This ensures physical constraints are re-injected at every depth (Cite solution_lesson_node_00035).
    2.  **Wide-State Temporal Mixing (Bi-LSTM):** A Bidirectional LSTM processes $x_{in}$. We set the hidden dimension to **256 per direction**, resulting in a natural output dimension of **512**. This avoids the information bottleneck of compressing the state (Cite solution_lesson_node_00055).
    3.  **Strict Identity Residual 1:** The residual connection is applied as $y = x + \text{Dropout}(\text{LSTM}(x_{in}))$. Since the input $x$ and LSTM output both have dimension 512, we use a **strict identity mapping** on the skip connection (no linear projections), ensuring unimpeded gradient flow (Cite solution_lesson_node_00064).
    4.  **Pointwise Channel Mixing (FFN):** The output $y$ is passed through a **Pointwise Feed-Forward Network** (`Linear -> GELU -> Linear`) with an expansion factor of **2x** (1024 units). We avoid 4x expansion to maintain stability without normalization (Cite solution_lesson_node_00052).
    5.  **Strict Identity Residual 2:** A second identity residual is applied: $z = y + \text{Dropout}(\text{FFN}(y))$. We strictly **exclude Layer Normalization** to preserve the absolute pressure magnitude for regression (Cite solution_lesson_node_00044).
*   **Deep Supervision:** An **Auxiliary Regression Head** is attached to the output of the **2nd Block**. This accelerates convergence by providing a short-circuit for gradients (Cite solution_lesson_node_00039).
*   **Head:** A linear layer projects the output of the 4th Block to the final `pressure` prediction.

### Data
The data pipeline is engineered for **Physics Fidelity** and **Control Segregation**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$ (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms (`u_in * R`, `volume / C`) as input features. We avoid "Hard" additive residuals to prevent unit-mismatch biases (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` (Cite solution_lesson_node_00022).
*   **Control Segregation:** Explicitly segregate the `u_out` control flag. It must **not** be scaled or normalized, preserving its binary (0/1) nature for exact loss masking (Cite solution_lesson_node_00058). All other continuous features are scaled using `RobustScaler`.
*   **Robust Caching:** Generate cache filenames using a hash of the configuration to prevent stale data artifacts.

### Training
*   **Loss Function:** Weighted **Masked L1 Loss** ($L_{total} = L_{final} + 0.3 \cdot L_{aux}$). The mask is calculated as `1 - u_out` using the unscaled binary flag (Cite solution_lesson_node_00001).
*   **Optimizer:** **AdamW** with a **OneCycleLR** scheduler.
*   **Strict Gradient Clipping:** We enforce a gradient clipping threshold of **1.0**. This is a mandatory prerequisite for the convergence of the Wide-State LSTM backbone (Cite solution_lesson_node_00059).
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which is critical for solving the cumulative (elastic) dynamics of the system (Cite solution_lesson_node_00057, Cite solution_lesson_node_00028).
*   **Dropout Placement:** Dropout is applied strictly to the residual branch *before* addition (Cite solution_lesson_node_00024).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** Predictions are generated using only the **Final Head** (Block 4 output). The output is flattened and mapped to the `id` column for submission.
