The implementation strategy involves the following steps:

1.  **Setup & Configuration**: Initialize the `Config` class with `debug=True`. This ensures the script runs quickly by subsampling the dataset (100 breaths) and reducing the number of training epochs to 2. The working directory is cleaned to demonstrate a fresh execution flow.
2.  **Data Preparation**: Utilize the `prepare_data` function to load, feature-engineer, scale, and reshape the training and validation datasets. Assertions are used to verify that the returned datasets have the expected number of breaths (100 in debug mode) and the correct tensor shapes (80 time steps per breath).
3.  **Model Initialization**: Instantiate the `VentilatorModel` and move it to the configured device. A dummy forward pass with random tensors is performed to verify that the model architecture is valid and produces outputs of the expected shape `(Batch, 80, 1)`.
4.  **Training**: Create PyTorch `DataLoader`s and initialize the `Trainer`. The `fit` method is called to train the model. Post-training, the existence of the saved model checkpoint (`model.pth`) is verified.
5.  **Inference**: Invoke `generate_predictions` to process the test set and generate a submission file. The resulting CSV is loaded to verify it follows the required format (columns `id`, `pressure`), has the correct number of rows for the debug subset, and contains no missing values.
