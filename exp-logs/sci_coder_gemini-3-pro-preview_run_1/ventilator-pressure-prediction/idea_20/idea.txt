# Proposed Strategy: Curated-Identity Physics-Composite Network

This strategy represents the structural culmination of the "Physics-Injected" lineage. It resolves the specific conflict identified in **Lesson 66** (where indiscriminate injection of dynamic signals degraded performance) and **Lesson 64** (where parameterized residuals destabilized training). By strictly curating the deep injection to include *only* static system parameters and enforcing strict identity mappings in the residual stream, this architecture maximizes gradient flow and physical fidelity without introducing optimization bottlenecks.

### Model
The architecture is a **Curated-Identity Physics-Composite Network**. It is designed to maintain a pristine, unnormalized gradient highway while ensuring the deep LSTM layers remain grounded in the physical constraints of the lung.

*   **Stem (Multi-Scale CNN):** The input sequence (containing dynamic controls, physics interaction terms, and static attributes) is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. The outputs are concatenated and projected to a fixed Model Dimension of **$D_{model} = 512$** (Cite solution_lesson_node_00015).
*   **Backbone (Curated-Identity Composite Blocks):** The core consists of a stack of **4 Composite Blocks**. Each block is engineered to process context without corrupting the residual stream:
    1.  **Curated Context Injection:** The input to the recurrent layer is formed by concatenating the block input $x$ ($D=512$) with **only the static lung attributes** ($F_{static}$: scaled `R`, `C`). Crucially, we **exclude** all dynamic raw inputs (like `u_in`, lags, or time-varying physics terms) from this deep injection. This adheres to the hierarchy principle, preventing high-level layers from being overwhelmed by low-level signal noise (Cite solution_lesson_node_00066).
    2.  **Aligned Wide-State Bi-LSTM:** A Bidirectional LSTM processes the concatenated input $[x, F_{static}]$. We set the hidden dimension to **256 per direction**, resulting in a natural output dimension of **512**. This matches the block input $x$ exactly, avoiding the information bottleneck of compression (Cite solution_lesson_node_00055).
    3.  **Strict Identity Residual 1:** The residual connection is applied as $y = x + \text{Dropout}(\text{LSTM}(\dots))$. Because the dimensions match perfectly, we use a **strict identity mapping** (no linear weights) on the skip connection, ensuring unimpeded gradient flow (Cite solution_lesson_node_00064). Dropout is applied only to the residual branch (Cite solution_lesson_node_00024).
    4.  **Pointwise Channel Mixing (FFN):** The output $y$ is passed through a **Pointwise Feed-Forward Network** (`Linear -> GELU -> Linear`) with an expansion factor of **2x** (1024 units). We explicitly avoid 4x expansion to maintain optimization stability in the absence of normalization (Cite solution_lesson_node_00052).
    5.  **Strict Identity Residual 2:** A second identity residual is applied: $z = y + \text{Dropout}(\text{FFN}(y))$. We strictly **exclude Layer Normalization** to preserve the absolute pressure magnitude required for regression (Cite solution_lesson_node_00044).
*   **Deep Supervision:** An **Auxiliary Regression Head** is attached to the output of the **2nd Block**. This provides a gradient short-circuit to accelerate convergence and enforce feature quality in early layers (Cite solution_lesson_node_00039).
*   **Head:** A linear layer projects the output of the 4th Block to the final `pressure` prediction.

### Data
The data pipeline is engineered for **Physics Fidelity**, **Segregation**, and **Richness**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$ (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms derived from the Equation of Motion (`u_in * R`, `volume / C`) as **input features** to the Stem. We avoid "Hard" additive residuals at the output to prevent unit-mismatch biases (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` to capture system inertia (Cite solution_lesson_node_00022).
*   **Control Segregation:** Explicitly segregate the `u_out` control flag. It must **not** be scaled or normalized, preserving its binary (0/1) nature for exact loss masking (Cite solution_lesson_node_00058).
*   **Preprocessing:** All continuous features (including `R` and `C`) are scaled using `RobustScaler`. Data is reshaped to `(N_breaths, 80, N_features)`.

### Training
*   **Loss Function:** Weighted **Masked L1 Loss** ($L_{total} = L_{final} + 0.3 \cdot L_{aux}$). The mask is calculated as `1 - u_out` using the unscaled binary flag (Cite solution_lesson_node_00001).
*   **Optimizer:** **AdamW** with a **OneCycleLR** scheduler.
*   **Strict Gradient Clipping:** We enforce a gradient clipping threshold of **1.0**. This is a mandatory prerequisite for the convergence of the LSTM backbone (Cite solution_lesson_node_00059).
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which is critical for solving the cumulative (elastic) dynamics of the system (Cite solution_lesson_node_00057, Cite solution_lesson_node_00028).
*   **Batch Size:** Maintain a batch size of **512** to ensure a sufficient number of gradient updates (Cite solution_lesson_node_00019).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** Predictions are generated using only the **Final Head** (Block 4 output). The auxiliary head is discarded during inference. The output is flattened and mapped to the `id` column for submission.
