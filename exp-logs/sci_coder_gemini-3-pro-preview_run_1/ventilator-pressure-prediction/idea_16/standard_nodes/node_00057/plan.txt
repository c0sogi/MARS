Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and override configuration parameters to create a "Fast Baseline". Specifically, reduce `EPOCHS` to 6 and subsample the training dataset to 15,000 breaths (approx. 1.2M rows) to ensure the pipeline completes quickly while still allowing the model to converge sufficiently.
2.  **Data Loading**: Use `library.features.prepare_datasets` to load the full engineered datasets (leveraging caching). Manually subsample the training dataframe to the target size. Keep the validation and test datasets intact (full size) to ensure accurate metric calculation and valid submission generation.
3.  **Model Initialization**: Instantiate the `VentilatorModel` from `library.model`, move it to the GPU, and set up the `AdamW` optimizer and `OneCycleLR` scheduler. The scheduler is configured based on the reduced epoch count and subsampled dataset size.
4.  **Training Loop**: Execute the training loop for the defined epochs using `library.engine.train_one_epoch`. After each epoch, evaluate on the full validation set using `library.engine.evaluate` and save the model if the Masked MAE improves.
5.  **Final Evaluation**: Load the best saved model state. Compute the "Final Validation Metric" on the full hold-out validation set.
6.  **Failure Analysis**: Perform inference on the validation set to calculate element-wise absolute errors. Filter for the inspiratory phase (`u_out == 0`) and compute the Pearson correlation between the error magnitude and key input features (`time_step`, `u_in`, `R`, `C`). Print these correlations to identify error sources.
7.  **Submission**: Check if the Final Validation Metric is strictly lower than the threshold `0.2164510190486908`. If satisfied, generate predictions for the test set using `library.engine.predict`, format them according to the sample submission, and save to `submission.csv`.
