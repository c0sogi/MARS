# Proposed Strategy: Wide-State Weight-Normalized Physics-Injected Composite Network

This strategy resolves the "Capacity vs. Stability" deadlock identified in Lessons 44 and 52. It combines the **High-Capacity Pointwise FFNs** (which accelerated convergence in Lesson 51) with the **Wide-State Bi-LSTM** (which maximized temporal capacity in Lesson 55). Crucially, it introduces **Weight Normalization** as a structural innovation to stabilize the high-capacity blocks without the signal-destroying effects of Layer Normalization.

### Model
The architecture is a **Wide-State Weight-Normalized Physics-Injected Composite Network**. It prioritizes maintaining a high-magnitude gradient highway for continuous regression while maximizing the expressivity of channel mixing.

*   **Stem (Multi-Scale CNN):** The input sequence is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. The outputs are concatenated to capture both fine-grained signal noise and smoothed trend derivatives (Cite solution_lesson_node_00015).
*   **Backbone (Wide-State Composite Blocks):** The core consists of a stack of **4 Composite Blocks**. Each block is structured to preserve full temporal capacity and enable stable high-capacity channel mixing:
    1.  **Deep Context Injection:** The input to the block is the concatenation of the previous layer's output and the **Static Physics Features** (scaled `R`, `C`, `u_in * R`, `Vol / C`). This ensures physical constraints are re-injected at every depth (Cite solution_lesson_node_00035).
    2.  **Wide-State Temporal Mixing (Bi-LSTM):** A Bidirectional LSTM processes the sequence. Crucially, we **do not compress** the output. The output dimension is allowed to be $2 \times \text{Hidden Dim}$ (e.g., 1024 if Hidden is 512).
    3.  **Projected Residual 1:** We apply a learnable linear projection to the residual identity path to match the expanded LSTM output dimension, followed by addition. This avoids the information bottleneck of compressing the Bi-LSTM (Cite solution_lesson_node_00055).
    4.  **High-Capacity Channel Mixing (Weight-Norm FFN):** The output is passed through a Pointwise Feed-Forward Network with an **expansion factor of 4x** (Cite solution_lesson_node_00051).
        *   **Structural Innovation (Weight Normalization):** Instead of using Layer Normalization (which hurts regression magnitude, Cite solution_lesson_node_00044) or leaving the block unnormalized (which causes instability, Cite solution_lesson_node_00052), we apply **Weight Normalization** to the linear layers of the FFN. This decouples the magnitude of the weight vectors from their direction, stabilizing the training of high-capacity layers without enforcing a zero-mean distribution on the activations.
    5.  **Residual 2:** A simple additive residual connection is applied around the FFN.
*   **Deep Supervision:** An **Auxiliary Regression Head** is attached to the output of the **2nd Block**. This provides a gradient short-circuit to accelerate convergence and enforce feature quality in early layers (Cite solution_lesson_node_00039).
*   **Head:** A linear layer projects the output of the 4th Block to the final `pressure` prediction.

### Data
The data pipeline is strictly engineered for **Physics Fidelity** and **Reproducibility**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$. (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms derived from the Equation of Motion (`u_in * R`, `volume / C`) as input features. We avoid "Hard" additive residuals to prevent unit-mismatch biases (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` to capture system inertia (Cite solution_lesson_node_00022).
    *   **Continuous Attributes:** Treat `R` and `C` as continuous scaled inputs to preserve their ordinal magnitude (Cite solution_lesson_node_00022).
*   **Robust Caching:** Generate cache filenames using a **hash of the configuration and feature list** to prevent stale data artifacts (Cite solution_lesson_node_00002).
*   **Preprocessing:** Reshape to `(N_breaths, 80, N_features)` and normalize using `RobustScaler`.

### Training
*   **Composite Loss Function:** We utilize a weighted **Masked L1 Loss**.
    *   $L_{total} = L_{mask}(y_{final}, y_{true}) + 0.3 \cdot L_{mask}(y_{aux}, y_{true})$.
    *   Both losses are masked by `(1 - u_out)` to focus strictly on the inspiratory phase (Cite solution_lesson_node_00001).
*   **Optimization:** Use **AdamW** with a **OneCycleLR** scheduler.
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which is critical for the convergence of deep residual architectures (Cite solution_lesson_node_00028).
*   **Update Budget:** Maintain a batch size of **512**. We explicitly avoid increasing the batch size further to ensure a sufficient number of gradient updates are performed (Cite solution_lesson_node_00019).
*   **Dropout Placement:** Dropout is applied strictly to the residual branch *before* addition to preserve the identity path (Cite solution_lesson_node_00024).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** Predictions are generated using only the **Final Head** (Block 4 output). The auxiliary head is discarded during inference. The output is flattened and mapped to the `id` column for submission.
