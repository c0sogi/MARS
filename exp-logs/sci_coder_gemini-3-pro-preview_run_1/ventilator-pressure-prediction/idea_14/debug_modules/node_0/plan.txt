Here is the implementation strategy for the demonstration script:

1.  **Environment Setup**: Import necessary libraries and the provided modules (`library.config`, `library.data`, `library.model`, `library.train`, `library.utils`). Set a fixed random seed for reproducibility.
2.  **Configuration Override**: Modify the global `Config` class attributes at runtime to create a "Demo" configuration. This includes enabling `debug` mode (to use a small data subset), reducing `epochs` to 2, and setting a dedicated working directory to avoid interfering with main experiments.
3.  **Data Pipeline Verification**: Call `get_dataloaders` with `load_cached_data=False` to trigger the raw data loading and feature engineering pipeline. Assert that the resulting tensors have the correct 3D shapes `(Batch, Time, Features)` and verify the alignment of targets and masks.
4.  **Model Architecture Verification**: Instantiate the `HighCapacityCompositeModel`. Perform a forward pass with a batch of data to ensure the stem, composite blocks, and auxiliary heads produce outputs of the correct shape `(Batch, Time)`.
5.  **Loss Function Logic Check**: Instantiate `MaskedL1Loss`. Create synthetic prediction and target tensors to mathematically verify that the loss function correctly ignores the expiratory phase (`u_out=1`) and computes L1 loss for the inspiratory phase (`u_out=0`).
6.  **Training Loop Execution**: Initialize the `Trainer` with the model and dataloaders. Execute `trainer.fit()` to run the training and validation loops. This demonstrates the integration of the optimizer, scheduler, and gradient updates.
7.  **Artifact & Metric Validation**: Confirm that the model checkpoint (`model.pth`) was saved. Run the `compute_metric` function on model predictions to verify the evaluation logic.
