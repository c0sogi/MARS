# Proposed Strategy: Graduated-Capacity Physics-Context Composite Network

This strategy synthesizes the critical insights regarding **State Capacity** (Lesson 55), **Initialization Stability** (Lesson 73), and **Physics Fidelity** (Lesson 76). It introduces a **Graduated-Capacity Backbone** that initializes in a compressed "bottleneck" space to filter noise, naturally expands into a high-capacity "wide state" to model complex dynamics, and maintains a pristine gradient highway via **Strict Identity Residuals**.

### Model
The architecture is a **Graduated-Capacity Physics-Context Composite Network**. It features a funnel-like expansion trajectory that maximizes feature extraction efficiency while ensuring stability in deep layers.

*   **Stem (Bottleneck Initialization):** The input sequence (containing dynamic controls, raw physics terms, and static attributes) is processed by a **Multi-Scale 1D Convolutional Block** (Inception-style) with kernel sizes of `[3, 5, 7]`. Crucially, the output is projected to a compressed **Bottleneck Dimension of 512**. This avoids the instability and noise dilution observed when projecting raw inputs immediately to high dimensions (Cite solution_lesson_node_00073).
*   **Context Definition:** We define a **Curated Physics Context** vector containing Static Attributes ($R, C$) and **Derived Physics Interactions** ($R \cdot u_{in}$, $Volume / C$). We explicitly inject these pre-computed interaction terms into the deep layers to relieve the network of learning arithmetic multiplication, while strictly excluding raw noise sources like lags or bare control signals (Cite solution_lesson_node_00076, Cite solution_lesson_node_00066).
*   **Block 1 (The Expansion Block):** This block handles the transition from the bottleneck to the wide state.
    *   **Context Injection:** Concatenate Input ($D=512$) with the Curated Physics Context.
    *   **Expanding Bi-LSTM:** A Bidirectional LSTM processes the sequence with a hidden dimension of **512 per direction**. The output naturally concatenates to **1024**, expanding the state space without information loss (Cite solution_lesson_node_00055).
    *   **Projected Residual:** Since Input (512) $\neq$ Output (1024), we use a learnable linear projection on the residual path to match dimensions (Cite solution_lesson_node_00027).
    *   **Pointwise FFN:** A Feed-Forward Network processes the 1024-dim output (Expansion 2x $\to$ 2048 $\to$ 1024). We avoid 4x expansion to maintain stability without normalization (Cite solution_lesson_node_00052).
*   **Blocks 2-4 (Wide-State Identity Blocks):** These blocks maintain the high capacity established by Block 1.
    *   **Context Injection:** Concatenate Input ($D=1024$) with the Curated Physics Context.
    *   **Wide-State Bi-LSTM:** A Bidirectional LSTM (Hidden=512 per direction) processes the sequence. The output remains **1024**.
    *   **Strict Identity Residual 1:** Since Input (1024) matches Output (1024), we use a **Strict Identity Mapping** (no weights) on the skip connection. This creates an unhindered gradient highway for the deep layers (Cite solution_lesson_node_00064).
    *   **Pointwise FFN:** FFN processes the 1024-dim output.
    *   **Strict Identity Residual 2:** Additive identity residual around the FFN. **No Layer Normalization** is used to preserve regression magnitude (Cite solution_lesson_node_00044).
*   **Deep Supervision:** An **Auxiliary Regression Head** is attached to the output of **Block 2** to accelerate convergence (Cite solution_lesson_node_00039).
*   **Head:** A linear layer projects the output of Block 4 to the final `pressure`.

### Data
The data pipeline is strictly engineered for **Physics Fidelity** and **Control Segregation**.

*   **Physics-Fidelity Feature Engineering:**
    *   **Correct Integration:** Calculate `volume` as the cumulative sum of flow scaled by the time delta: $\sum (u_{in} \cdot \Delta t)$ (Cite solution_lesson_node_00031).
    *   **Soft Physics Integration:** Include interaction terms (`u_in * R`, `volume / C`) as input features to the Stem (Cite solution_lesson_node_00011).
    *   **Rich Dynamics:** Include Lags (1-4), First Differences, and Second Differences of `u_in` to capture system inertia (Cite solution_lesson_node_00022).
*   **Control Segregation:** Explicitly segregate the `u_out` control flag. It must **not** be scaled or normalized, preserving its binary (0/1) nature for exact loss masking (Cite solution_lesson_node_00058). All other continuous features are scaled using `RobustScaler`.
*   **Robust Caching:** Generate cache filenames using a hash of the configuration to prevent stale data artifacts.

### Training
*   **Loss Function:** Weighted **Masked L1 Loss** ($L_{total} = L_{final} + 0.3 \cdot L_{aux}$). The mask is calculated as `1 - u_out` using the unscaled binary flag (Cite solution_lesson_node_00001).
*   **Optimizer:** **AdamW** with a **OneCycleLR** scheduler.
*   **Strict Gradient Clipping:** We enforce a gradient clipping threshold of **1.0**. This is a mandatory prerequisite for the convergence of the Wide-State LSTM backbone (Cite solution_lesson_node_00059).
*   **Extended Optimization Horizon:** Train for **35 epochs**. This allows the OneCycleLR scheduler to fully anneal the learning rate, which is critical for solving the cumulative (elastic) dynamics of the system (Cite solution_lesson_node_00028, Cite solution_lesson_node_00057).
*   **Update Budget:** Maintain a batch size of **512**. We explicitly avoid increasing the batch size further to ensure a sufficient number of gradient updates are performed (Cite solution_lesson_node_00019).
*   **Dropout Placement:** Dropout is applied strictly to the residual branch *before* addition (Cite solution_lesson_node_00024).

### Evaluation
*   **Inference:** The test set is processed through the identical hashed caching and Physics-Fidelity feature pipeline.
*   **Prediction:** Predictions are generated using only the **Final Head** (Block 4 output). The auxiliary head is discarded during inference. The output is flattened and mapped to the `id` column for submission.
