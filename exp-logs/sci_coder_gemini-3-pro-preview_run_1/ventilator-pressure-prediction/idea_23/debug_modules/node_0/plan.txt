This script demonstrates the end-to-end usage of the provided ventilator pressure prediction library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to enable `DEBUG` mode (using a small data subset) and reduces training epochs/batch sizes for rapid execution.
2.  **Data Pipeline Verification**: Explicitly calls `prepare_dataset` to verify feature engineering, scaling, and data shapes.
3.  **Dataset Class Verification**: Instantiates `VentilatorDataset` to ensure PyTorch tensors are correctly formatted.
4.  **Model Architecture Verification**: Instantiates the `GraduatedCapacityNetwork`, runs a forward pass with dummy data, and asserts output shapes.
5.  **Loss Function Verification**: Tests `MaskedAuxiliaryLoss` with known inputs to confirm that the expiratory phase (`u_out=1`) is correctly masked out and the auxiliary loss is weighted correctly.
6.  **Training Loop Execution**: Runs the `Trainer` to simulate a full training cycle (training and validation) on the debug subset, ensuring the pipeline runs without errors and saves the model.
