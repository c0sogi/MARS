To improve the model's performance, I will implement a strategy based on the provided lessons, specifically targeting **Explicit Context Injection** and **Recurrent Capacity**.

**Strategy:**
1.  **Explicit Context Injection (Cite solution_lesson_node_00090, solution_lesson_node_00074, solution_lesson_node_00076):**
    The previous solution used a learned linear projection of *all* input features to generate the context vector. I will replace this with the explicit injection of specific physical attributes (`R`, `C`) and derived interaction terms (`R_u_in`, `vol_C`) at every layer. This ensures the model has direct access to the governing physical constraints without needing to disentangle them from a compressed latent representation.

2.  **Wide Bi-LSTM Capacity (Cite solution_lesson_node_00055):**
    The previous solution restricted the Bi-LSTM hidden dimension to `hidden_dim // 2` per direction to force the output size to match the input size. I will modify the `CompositeBlock` to use `hidden_size=hidden_dim` per direction (resulting in a `2 * hidden_dim` output) and use a linear projection to map it back to the residual stream dimension. This prevents bottlenecking the recurrent state capacity.

3.  **Selective Injection (Cite solution_lesson_node_00066):**
    I will ensure that only the high-level physical features are injected deep into the network, avoiding the re-injection of raw noisy control signals (like `u_in` lags) which can degrade performance.

4.  **Optimization:**
    I will increase the training epochs to 25 to allow for fuller convergence, as the previous 15 epochs showed the model was still learning.

class CompositeBlock(nn.Module):
    """
    Uniform Composite Block with Curated Context Injection and Strict Identity Residuals.
    Maintains uniform capacity (Hidden Dim 512) throughout.
    """

    def __init__(self, hidden_dim, context_dim, dropout=0.1):
        super().__init__()
        self.hidden_dim = hidden_dim

        # Aligned Bi-LSTM
        # Input is hidden_state + context
        # Hidden dim is hidden_dim // 2 per direction -> output is hidden_dim
        # This prevents the information bottleneck seen in standard Bi-LSTMs
        self.lstm = nn.LSTM(
            input_size=hidden_dim + context_dim,
            hidden_size=hidden_dim // 2,
            num_layers=1,
            batch_first=True,
            bidirectional=True,
        )

        # Pointwise FFN (Expansion 2x)
        # We avoid 4x expansion to maintain stability without normalization
        ffn_dim = hidden_dim * Config.FFN_EXPANSION_FACTOR
        self.ffn = nn.Sequential(
            nn.Linear(hidden_dim, ffn_dim), nn.GELU(), nn.Linear(ffn_dim, hidden_dim)
        )

        self.dropout = nn.Dropout(dropout)

    def forward(self, x, context):
        # x: (Batch, Seq, Hidden)
        # context: (Batch, Seq, Context)

        # 1. Curated Context Injection
        # We re-inject the static/physics context at every block
        lstm_input = torch.cat([x, context], dim=-1)

        # 2. Aligned Bi-LSTM
        lstm_out, _ = self.lstm(lstm_input)

        # 3. Strict Identity Residual 1
        # Dimensions match (512 -> 512), no linear projection on skip
        # Dropout applied to residual branch only
        x = x + self.dropout(lstm_out)

        # 4. Pointwise FFN
        ffn_out = self.ffn(x)

        # 5. Strict Identity Residual 2
        # No LayerNorm, preserving absolute pressure magnitude
        x = x + self.dropout(ffn_out)

        return x

class CompositeBlock(nn.Module):
    """
    Wide-Capacity Composite Block with Explicit Context Injection.
    Uses full-width Bi-LSTM (Output 2*Hidden) projected back to Hidden.
    Cite solution_lesson_node_00055: Preserving State Space Capacity.
    """

    def __init__(self, hidden_dim, context_dim, dropout=0.1):
        super().__init__()
        self.hidden_dim = hidden_dim

        # Wide Bi-LSTM
        # Input is hidden_state + context
        # Hidden dim is hidden_dim per direction -> output is 2 * hidden_dim
        # This maximizes state capacity.
        self.lstm = nn.LSTM(
            input_size=hidden_dim + context_dim,
            hidden_size=hidden_dim,
            num_layers=1,
            batch_first=True,
            bidirectional=True,
        )
        
        # Projection for Residual Connection
        # Maps 2*hidden_dim back to hidden_dim
        self.proj = nn.Linear(hidden_dim * 2, hidden_dim)

        # Pointwise FFN (Expansion 2x)
        ffn_dim = hidden_dim * Config.FFN_EXPANSION_FACTOR
        self.ffn = nn.Sequential(
            nn.Linear(hidden_dim, ffn_dim), nn.GELU(), nn.Linear(ffn_dim, hidden_dim)
        )

        self.dropout = nn.Dropout(dropout)

    def forward(self, x, context):
        # x: (Batch, Seq, Hidden)
        # context: (Batch, Seq, Context)

        # 1. Explicit Context Injection
        # Cite solution_lesson_node_00090: Explicit Injection vs Learned Projections
        lstm_input = torch.cat([x, context], dim=-1)

        # 2. Wide Bi-LSTM
        lstm_out, _ = self.lstm(lstm_input) # (Batch, Seq, 2*Hidden)
        
        # 3. Projection
        lstm_out = self.proj(lstm_out) # (Batch, Seq, Hidden)

        # 4. Residual 1
        x = x + self.dropout(lstm_out)

        # 5. Pointwise FFN
        ffn_out = self.ffn(x)

        # 6. Residual 2
        x = x + self.dropout(ffn_out)

        return x
