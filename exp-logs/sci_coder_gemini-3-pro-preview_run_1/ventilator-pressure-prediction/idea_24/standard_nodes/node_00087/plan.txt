2.  **Preprocessing Integrity (Cite solution_lesson_node_00058):** While adding `u_out` to the input features (which are scaled), I will explicitly preserve the raw `u_out` values (0/1) for the loss masking mechanism. This ensures the masking logic remains semantically correct while allowing the model to process the scaled control signal.
3.  **Training Horizon (Cite solution_lesson_node_00028):** I will increase the training duration from 20 to 35 epochs. The previous run showed the model was still learning (validation MAE decreasing), and the target metric is aggressive (0.216), requiring full convergence.
