### Implementation Strategy

1.  **Configuration Override**: We will modify the static `Config` class attributes at runtime to create a "Demo Mode". This includes enabling `DEBUG` (to use a tiny subset of data), reducing model size (`D_MODEL`, `NUM_LAYERS`), and setting a minimal number of epochs. This ensures the script runs in seconds while exercising all code paths.
2.  **Data Pipeline Verification**: We will invoke `get_data_loaders` with `load_cached_data=False` to force the execution of the raw data loading, feature engineering (`compute_features`), scaling, and reshaping logic. We will assert the output shapes of the resulting DataLoaders.
3.  **Model Initialization & Forward Pass**: We will instantiate the `VentilatorNet` with the reduced configuration and perform a forward pass with a real batch from the data loader. We will verify that the output shapes for both the final prediction and the auxiliary head are correct.
4.  **Training Loop Simulation**: We will run the `train_one_epoch` function and the `evaluate` function. This verifies the loss calculation (`MaskedL1Loss`), backpropagation, gradient clipping, and metric calculation.
5.  **Inference & Submission**: We will run the `predict` function to generate predictions for the test set and verify that the output dimensions match the expected number of time steps. Finally, we will demonstrate how to save these predictions to a CSV file matching the submission format.
6.  **Reproducibility**: Random seeds are set via the `Config.setup()` method (re-called after overrides) to ensure consistent results.
