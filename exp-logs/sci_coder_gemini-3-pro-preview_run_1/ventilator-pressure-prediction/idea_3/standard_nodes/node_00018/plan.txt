The `RuntimeError` is caused by a shape mismatch between the model's input layer and the generated dataset. The model, defined in `library/model.py`, expects an input dimension of 16 (based on `Config.CONT_FEATURES`), but the data preparation logic in `library/features.py` produces tensors with 18 channels by hardcoding the addition of `["R_cat", "C_cat"]`. This violates the contract defined by the configuration (Cite debug_lesson_1).

To fix this, I will:
1.  Update `library/features.py` to derive `feature_cols` strictly from `Config.CONT_FEATURES` and `Config.CAT_FEATURES`, removing the hardcoded extra columns.
2.  Update the `get_feature_hash` function in `library/features.py` to include a version string. This ensures the previously cached dataset (which contains the incorrect 18-channel data) is invalidated and regenerated with the correct shape.
