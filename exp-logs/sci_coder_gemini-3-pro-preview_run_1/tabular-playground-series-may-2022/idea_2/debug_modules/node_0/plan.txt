This script demonstrates the usage of the provided machine learning library components for the manufacturing control task. It validates the data processing pipeline, dataset construction, model architecture, and the full training loop using a small subset of data to ensure quick execution.

The implementation follows these steps:
1.  **Setup**: Initializes the environment and random seeds.
2.  **Data Processing Verification**: Manually invokes `process_data` with a small sample size to verify feature engineering and tokenization logic, asserting correct array shapes.
3.  **Dataset Verification**: Instantiates `ManufacturingDataset` to check data loading, tensor conversion, and batch structure.
4.  **Model Verification**: Initializes `ManufacturingNet` and performs a forward pass with dummy data to validate the architecture and output dimensions.
5.  **Full Pipeline Verification**: Executes `run_experiment` (which uses `Trainer`) on a small subset to demonstrate the end-to-end flow from training to submission generation, verifying the final output file.
