The implementation strategy focuses on leveraging the provided library modules to construct a high-performance, efficient training pipeline suitable for the A100 environment.

1.  **Configuration Optimization**: We override default `Config` parameters to utilize the A100's memory by increasing `BATCH_SIZE` to 2048 and setting `EPOCHS` to 15. This ensures the "fast baseline" requirement is met while providing sufficient training steps for the OneCycleLR scheduler to converge.
2.  **Data Pipeline**: We utilize `get_dataloaders()` to handle data loading and preprocessing, ensuring we use the stratified metadata splits.
3.  **Training & Validation**: We execute the training loop using `run_training()`, which handles the Hybrid Transformer model, AdamW optimizer, and OneCycleLR scheduler. We then reload the best checkpoint to perform a definitive evaluation on the validation set.
4.  **Failure Analysis**: We compute the absolute prediction errors on the validation set and calculate their Pearson correlation with each numerical feature. This identifies which input variables are most associated with model uncertainty or error.
5.  **Submission Logic**: We strictly adhere to the conditional submission requirement, generating predictions only if the final validation AUC exceeds the specified threshold.
