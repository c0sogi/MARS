Based on the comprehensive analysis of the previous experiments and lessons learned, I propose the **Residual Denoising Granular Unified Transformer (ResDeGUT)**.

This strategy introduces a **Structural Innovation** by implementing a **Dual-Branch Architecture**. It synthesizes the "Deep" interaction-modeling power of the Denoising Transformer (Lesson 00032) with the "Wide" positional rigidity and simplicity of flattened architectures (Lesson 00009). This design explicitly decouples the modeling of complex cross-feature interactions from simple main effects, allowing the Transformer to focus on the former without being burdened by the latter.

# Model
I propose the **ResDeGUT** architecture, which processes the input through two parallel branches that share a common embedding foundation.

1.  **Shared Embedding Layer (Strategic Retention):**
    *   **Sequence:** The `f_27` string is tokenized and mapped to **Entity Embeddings** (Cite solution_lesson_node_00006).
    *   **Numerical:** All continuous features (including `unique_characters`) are projected into distinct tokens using **Linear Feature Tokenization** ($x \cdot \mathbf{w} + \mathbf{b}$), which preserves magnitude information (Cite solution_lesson_node_00023).

2.  **Branch 1: The Deep Interaction Expert (Transformer):**
    *   **Input:** A unified sequence constructed from `[CLS]`, `Numerical Tokens`, and `Sequence Embeddings`.
    *   **Positional Encoding:** Learnable encodings are added to the sequence tokens to strictly preserve order (Cite solution_lesson_node_00015).
    *   **Backbone:** A stack of **6 Transformer Encoder layers**. We prioritize depth/capacity here as we will use a moderate batch size (Cite solution_lesson_node_00042).
    *   **Components:** We utilize **GEGLU** feed-forward blocks (Cite solution_lesson_node_00029) and explicit `nn.ModuleList` instantiation (Cite solution_lesson_node_00030).
    *   **Output:** The `[CLS]` token vector, which aggregates the complex, non-linear interactions of the system (Cite solution_lesson_node_00025).
    *   **Auxiliary Head:** A **Masked Reconstruction Head** is attached to the feature tokens to perform the Denoising task (Cite solution_lesson_node_00026).

3.  **Branch 2: The Wide Residual Expert (MLP) (Structural Innovation):**
    *   **Input:** A concatenation of the **Raw Standardized Numerical Features** and the **Flattened Sequence Embeddings**.
    *   **Why:** This branch exploits the finding that **Flattening** is superior for modeling "Positional Rigidity" in short sequences (Cite solution_lesson_node_00009) and that linear/MLP baselines efficiently capture main effects (Cite solution_lesson_node_00001). By bypassing the attention mechanism, this branch provides a direct "shortcut" for the model to leverage simple positional and magnitude signals.
    *   **Architecture:** A shallow Residual MLP (e.g., `Linear -> BN -> GELU -> Linear`) that projects this "Wide" input to the same dimension as the `[CLS]` token.

4.  **Fusion Head:**
    *   The `[CLS]` vector (Deep) and the Residual vector (Wide) are **concatenated**.
    *   This fused representation is passed to a final **High-Capacity MLP** to predict the target.

# Data
1.  **Feature Engineering:**
    *   We will explicitly calculate the **count of unique characters** (`unique_characters`) from `f_27`, as this global statistic is a critical signal (Cite solution_lesson_node_00003).
    *   **Dynamic Selection:** We will use `df.select_dtypes` to automatically capture all numerical columns (original + engineered) to ensure pipeline integrity (Cite solution_lesson_node_00018).
2.  **Preprocessing:**
    *   **Numerical:** Standardized (Z-score).
    *   **Sequence:** Tokenized into integers.
3.  **Denoising Setup:**
    *   We apply **Stochastic Masking (15%)** to the input tokens for the Transformer branch *only*. The Wide branch always receives clean data to serve as a stable anchor.

# Training
1.  **Loss Function:**
    *   $$L = L_{BCE}(y, \hat{y}) + \lambda \cdot L_{Recon}(x_{mask}, \hat{x}_{rec})$$
    *   We use **Label Smoothing (0.01)** on the BCE loss (Cite solution_lesson_node_00029).
    *   The Reconstruction Loss is calculated only on the masked tokens in the Transformer branch (Cite solution_lesson_node_00032).
2.  **Optimizer:** **AdamW** for all parameters.
3.  **Scheduler:** **OneCycleLR** with a duration of **35 epochs**. This extended duration ensures a gradual annealing phase for optimal convergence (Cite solution_lesson_node_00013).
4.  **Batch Size:** **512**. We explicitly avoid the larger batch sizes (e.g., 2048) used in previous attempts, as they were shown to degrade generalization performance in this high-precision regime (Cite solution_lesson_node_00042).
5.  **Data Regime:** We train **only on the Labeled Training Data**. We discard the Semi-Supervised approach as it was shown to be detrimental in this specific data regime (Cite solution_lesson_node_00040).

# Evaluation
For the test set, **no masking** is applied. The clean data is passed through both the Deep (Transformer) and Wide (Residual) branches. The final prediction is generated from the fused output of the Classification Head. The Reconstruction Head is ignored.
