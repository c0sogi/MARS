I will implement the orchestration script `runfile.py` to train the ResDeGUT model, evaluate it, perform failure analysis, and generate a submission if the performance criteria are met.

**Implementation Strategy:**
1.  **Setup & Imports**: Import the required classes and functions from the provided library files (`library.config`, `library.data`, `library.model`, `library.engine`, `library.utils`). Set random seeds for reproducibility.
2.  **Data Loading**: Use `process_data(load_cached_data=True)` to efficiently load the preprocessed data. Initialize `ManufacturingDataset` for training, validation, and testing. The training set will use stochastic masking (`mask_prob` from Config), while validation and test sets will remain unmasked.
3.  **Model Initialization**: Instantiate the `ResDeGUT` model using the feature dimensions derived from the data. Move the model to the configured device (GPU).
4.  **Training Loop**:
    *   Initialize `AdamW` optimizer and `OneCycleLR` scheduler.
    *   Run the training loop for `Config.EPOCHS` (35 epochs).
    *   In each epoch, execute `train_fn` and `eval_fn`.
    *   Track the best validation AUC and save the model state to `best_model.pth` whenever a new best score is achieved.
5.  **Final Evaluation**: Load the best saved model and compute the `Final Validation Metric` (AUC) on the full validation set.
6.  **Failure Analysis**:
    *   Generate predictions on the validation set.
    *   Calculate the absolute error (`|target - prediction|`).
    *   Compute the Pearson correlation between the error magnitude and each numerical feature in the validation set.
    *   Print the top 5 features most correlated with model error.
7.  **Submission**: Compare the final validation metric against the threshold `0.9977872734278943`. If the metric is higher, generate predictions for the test set using `predict_fn` and save them to `./submission/submission.csv`.
