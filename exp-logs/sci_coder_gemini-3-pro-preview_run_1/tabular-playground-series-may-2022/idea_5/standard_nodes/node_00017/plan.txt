Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting the random seed using `library.utils.seed_everything` and detecting the computation device (GPU/CPU) via `library.config.Config`.
2.  **Data Loading**: Use `library.data.get_dataloaders` with `load_cached_data=True` to efficiently load the preprocessed training, validation, and test datasets.
3.  **Model Training**: Instantiate the `UnifiedTransformer` from `library.model` and execute the training loop using `library.engine.train_model`. This handles the optimization, learning rate scheduling (OneCycleLR), and early stopping, saving the best checkpoint to disk.
4.  **Validation & Failure Analysis**:
    *   Load the best model checkpoint from disk.
    *   Perform inference on the full validation set in `eval` mode to compute the final AUC.
    *   Calculate the absolute prediction errors (`|target - prediction|`).
    *   Compute and print Pearson correlations between the error magnitude and each numerical feature to identify sources of systematic failure.
5.  **Submission**: Compare the final validation AUC against the threshold (`0.9920540777100928`). If the model performs sufficiently well, generate the submission file using `library.engine.generate_submission`.
