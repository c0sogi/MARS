3.  **Model Initialization**: Instantiate the `SentimentModel` (DeBERTa-v3-base with custom heads) and move it to the GPU.
4.  **Training Loop**:
    *   Setup the optimizer (AdamW) with Layer-wise Learning Rate Decay (LLRD) using `get_optimizer_params`.
    *   Setup a cosine schedule with warmup.
    *   Iterate through the epochs. In each epoch, run `train_fn` to update weights and `eval_fn` to monitor validation performance.
    *   Implement a "save best model" mechanism based on the Jaccard score.
5.  **Final Evaluation**: Load the best saved model state. Calculate the final validation metric using `eval_fn`. Print the metric in the required format.
6.  **Failure Analysis**:
    *   Generate predictions on the validation set using `predict_fn`.
    *   Load the validation metadata to get ground truth.
    *   Calculate individual Jaccard scores and the error magnitude ($1 - \text{Jaccard}$).
    *   Compute and print the Pearson correlation between error magnitude and text length.
    *   Compute and print the average error per sentiment class.
7.  **Submission**:
    *   Compare the final validation metric against the threshold ($0.7043342108129372$).
    *   If the threshold is met, generate predictions on the test set using `predict_fn`.
    *   Construct the submission DataFrame using `textID` from the test metadata and the predicted strings.
    *   Save to `submission.csv`.
