Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Setup and Imports**: Import necessary standard libraries (`pandas`, `numpy`, `torch`) and the required components from the provided `library` modules (`Config`, `TweetDataset`, `TweetModel`, `process_data`, `run_training`, `run_inference`, `jaccard`, `seed_everything`).
2.  **Training**: Execute the training pipeline using `library.engine.run_training`. This handles data loading, filtering of neutral tweets (as per the model strategy), training with mixed precision, and saving the best model checkpoint.
3.  **Validation & Failure Analysis**:
    *   Reload the validation dataset and the best-saved model.
    *   Perform inference on the full validation set to generate predictions.
    *   Calculate the word-level Jaccard score for each sample.
    *   Compute and print the **Final Validation Metric** (mean Jaccard score) with full precision.
    *   Perform failure analysis by calculating the "Error Magnitude" ($1 - \text{Jaccard}$) and computing its Pearson correlation with input features:
        *   **Text Length**: To check if longer tweets are harder to predict.
        *   **Sentiment**: To check if specific sentiments (positive vs. negative) are more error-prone.
4.  **Submission**: Execute the inference pipeline using `library.engine.run_inference`. This generates predictions for the test set (applying the neutral heuristic) and saves the `submission.csv` file.
