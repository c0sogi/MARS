# Model

**Architecture:** **DeBERTa-v3-Large with Corrected LLRD and CNN-Head**
We will upgrade the backbone from `base` to **`microsoft/deberta-v3-large`**.
*   **Rationale:** While `roberta-large` previously failed due to overfitting on this small dataset Cite {solution_lesson_node_00009}, `deberta-v3` is significantly more sample-efficient due to its disentangled attention mechanism Cite {solution_lesson_node_00011}. To harness this capacity without the previous failures, we will employ a specific optimization strategy (see "Training").

**Head Design:** **Weighted Pooling with Convolutional Context**
We will retain the highly effective head architecture from the best-performing iteration:
1.  **Weighted Layer Pooling:** Aggregate hidden states from the last four layers to capture both semantic and syntactic features Cite {solution_lesson_node_00007}.
2.  **1D Convolution:** Pass the pooled embeddings through a **1D Convolutional Layer** (kernel size 3) to capture local n-gram context and sharpen decision boundaries Cite {solution_lesson_node_00011}.
3.  **Projection:** A single Linear layer to predict Start and End logits.
*   **Exclusions:** We will explicitly **avoid** Recurrent layers Cite {solution_lesson_node_00019}, Multi-Scale convolutions Cite {solution_lesson_node_00022}, and Auxiliary Dense Heads Cite {solution_lesson_node_00025}, as these introduced unnecessary complexity and degraded performance.

# Data

**Preprocessing & Alignment:**
*   **"Normalize-First" Pipeline:** We will strictly enforce a synchronized normalization protocol. We will normalize whitespace (collapsing multiple spaces) on the raw text *before* tokenization. Crucially, we will use this **same normalized string** for the final substring extraction. This corrects the critical misalignment error identified in previous attempts Cite {solution_lesson_node_00018}.
*   **Input Formatting (Early Fusion):** We will format the input as `[CLS] Sentiment [SEP] Text [SEP]`. This **Early Fusion** allows the Transformer's self-attention to condition the text representation on the sentiment deep within the network, which is superior to Late Fusion Cite {solution_lesson_node_00033} or Decoupled Heads Cite {solution_lesson_node_00029}.
*   **Target Mapping (Containment):** We will generate token-level targets using **containment logic** (`token_start <= char_idx < token_end`). We will explicitly avoid boundary thresholding heuristics, which fail on subword splits Cite {solution_lesson_node_00030}.
*   **Strategic Filtering:** We will continue to **exclude 'neutral' tweets** from the training set entirely Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Soft Targets:** We will generate **Gaussian-smoothed targets** ($\sigma=1.0$) for the start and end indices to handle annotation noise Cite {solution_lesson_node_00006}.

# Training

**Optimization Strategy:**
*   **Corrected Layer-wise Learning Rate Decay (LLRD):** To enable the training of the `Large` backbone without overfitting or "forgetting" pre-trained features, we will implement LLRD with a decay factor of 0.9. Crucially, we will **increase the base learning rate** (e.g., to 5e-5) to compensate for the decay in the lower layers. This addresses the underfitting issue observed when LLRD was applied with a standard learning rate Cite {solution_lesson_node_00014}.
*   **Loss Function:** We will use **Kullback-Leibler (KL) Divergence Loss** to align with the Gaussian soft targets Cite {solution_lesson_node_00007}. We will **average** the start and end losses to preserve gradient scaling Cite {solution_lesson_node_00020}.
*   **Regularization:** We will use standard Dropout. We will explicitly **avoid** Multi-Sample Dropout Cite {solution_lesson_node_00012} and Adversarial Weight Perturbation (AWP) Cite {solution_lesson_node_00015} to maintain optimization stability.

# Evaluation

**Inference Pipeline:**
*   **5-Fold Cross-Validation Ensemble:** To further mitigate the variance caused by label noise Cite {solution_lesson_node_00006}, we will train the model on 5 distinct folds of the data. During inference, we will average the logits from all 5 models.
*   **Neutral Samples:** Deterministically predict the full `text` Cite {solution_lesson_node_00002}.
*   **Positive/Negative Samples:**
    1.  Pass the **normalized** text through the ensemble.
    2.  **Joint Logit Decoding:** Calculate the score for span $(i, j)$ as the **sum of averaged logits**: $Logit_{start}(i) + Logit_{end}(j)$. Select the span that maximizes this sum subject to $i \le j$ Cite {solution_lesson_node_00021}.
    3.  **Reconstruction:** Extract the predicted substring from the **normalized** input text using the tokenizer offsets Cite {solution_lesson_node_00018}.
