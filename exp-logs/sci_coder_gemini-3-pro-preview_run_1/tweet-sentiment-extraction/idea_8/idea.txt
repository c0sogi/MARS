Based on the comprehensive analysis of the provided lessons and the failure modes of previous iterations, I propose the following optimized strategy. This solution implements a **Mask-Guided Multi-Task Architecture**, which leverages dense token-level supervision to inform the sparse span extraction task, while strictly adhering to the stability and data alignment protocols established in successful experiments.

# Model

**Architecture:** **Mask-Guided DeBERTa-v3**
We will utilize **`microsoft/deberta-v3-base`** as the backbone due to its superior disentangled attention mechanism for span extraction tasks Cite {solution_lesson_node_00011}. We will introduce a **Cascaded Multi-Task Head** designed to bridge the gap between dense token classification and sparse boundary detection:

1.  **Weighted Layer Pooling:** We will aggregate hidden states from the last four layers of the transformer to capture a robust mix of syntactic and semantic features Cite {solution_lesson_node_00007}.
2.  **Auxiliary Mask Head (Dense Supervision):** The pooled embeddings will first pass through a Linear layer to predict a binary probability $P_{mask}$ for each token, indicating whether it belongs to the selected text. This provides dense gradients for every token in the sequence, stabilizing feature learning.
3.  **Feature Fusion (Structural Innovation):** Instead of treating the auxiliary task as independent, we will **concatenate** the predicted mask probabilities $P_{mask}$ with the original pooled embeddings. This fused representation ($Embeddings \oplus P_{mask}$) serves as the input to the primary span head. This explicitly conditions the boundary detection on the model's own token-level confidence, guiding the span predictor toward regions with high "selected" probability.
4.  **Primary Span Head:** The fused input is passed through a **1D Convolutional Layer** (kernel size 3) to capture local context boundaries Cite {solution_lesson_node_00011}, followed by a Linear projection to predict Start and End logits.
5.  **Regularization:** We will use standard Dropout. We will explicitly **avoid** Multi-Sample Dropout, as it has been shown to degrade precision in this specific task Cite {solution_lesson_node_00012}.

# Data

**Preprocessing & Alignment:**
*   **"Normalize-First" Pipeline:** We will strictly enforce a synchronized normalization protocol. We will normalize whitespace (collapsing multiple spaces) on the raw text *before* tokenization. Crucially, we will use this **same normalized string** for the final substring extraction during inference. This prevents the critical index misalignment observed when tokenizer offsets are applied to mismatched raw text Cite {solution_lesson_node_00018}.
*   **Strategic Filtering:** We will continue to **exclude 'neutral' tweets** from the training set entirely. These samples follow a trivial identity mapping, and training on them wastes model capacity Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Span Targets:** We will generate **Gaussian-smoothed targets** ($\sigma=1.0$) for the start and end indices to handle annotation noise Cite {solution_lesson_node_00006}.
*   **Mask Targets:** We will generate binary masks (0/1) for the auxiliary head, where 1 indicates the token is part of the ground truth span.

# Training

**Loss Function:**
*   **Component Losses:** We will use **Kullback-Leibler (KL) Divergence** for the Span Head (to align with soft targets) Cite {solution_lesson_node_00007} and **Binary Cross Entropy (BCE)** for the Auxiliary Mask Head.
*   **Loss Aggregation:** We will calculate the total loss as the **average** of the component losses: $L_{total} = 0.5 \times L_{span} + 0.5 \times L_{mask}$. We will explicitly avoid summing the losses to preserve the gradient scale and ensure compatibility with standard pre-trained learning rates Cite {solution_lesson_node_00020}.

**Optimization Strategy:**
*   **Optimizer:** AdamW with a linear learning rate scheduler.
*   **Stability First:** We will strictly **avoid** stacking complex optimization tricks like Adversarial Weight Perturbation (AWP) or Layer-wise Learning Rate Decay (LLRD). Previous lessons demonstrated that combining these with structural changes (like the proposed multi-task head) leads to optimization instability and catastrophic failure Cite {solution_lesson_node_00015}. We will rely on the structural innovation of Mask-Guidance rather than optimization hacks.

# Evaluation

**Inference Pipeline:**
1.  **Neutral Samples:** Deterministically predict the full `text` Cite {solution_lesson_node_00002}.
2.  **Positive/Negative Samples:** Pass the **normalized** text through the Mask-Guided DeBERTa model.
    *   **Joint Logit Decoding:** Calculate the score for span $(i, j)$ as the **sum of logits**: $Logit_{start}(i) + Logit_{end}(j)$. We will select the span that maximizes this sum subject to $i \le j$ Cite {solution_lesson_node_00021}.
    *   **Reconstruction:** Extract the predicted substring from the **normalized** input text using the tokenizer offsets, ensuring bit-perfect alignment Cite {solution_lesson_node_00018}.
