Based on the analysis of the provided lessons and previous experiments, I propose the following optimized strategy. This solution introduces a **Multi-Scale Context Aggregation Head** to refine boundary detection while strictly adhering to the robust data and inference pipelines established in successful iterations.

# Model

**Architecture:** **DeBERTa-v3 with Multi-Scale Context Aggregation**
We will utilize **`microsoft/deberta-v3-base`** as the backbone. Its disentangled attention mechanism has been empirically proven to be superior for span extraction tasks compared to RoBERTa variants Cite {solution_lesson_node_00011}.

**Structural Innovation (Head Design):**
To address the need for precise boundary localization without the latency and degradation of recurrent layers Cite {solution_lesson_node_00019}, we will replace the single-kernel CNN head with a **Multi-Scale Context Aggregation Head**.
1.  **Weighted Layer Pooling:** We will aggregate hidden states from the last four layers of the transformer to capture a rich blend of semantic and syntactic features Cite {solution_lesson_node_00007}.
2.  **Multi-Scale Convolution:** The pooled output will be fed into three parallel **1D Convolutional Layers** with distinct kernel sizes (e.g., $k=1$, $k=3$, and $k=5$).
    *   $k=1$: Captures token-specific features.
    *   $k=3$: Captures immediate local context (neighbors).
    *   $k=5$: Captures wider phrase-level context.
3.  **Concatenation & Projection:** The outputs of these parallel convolutions will be concatenated and passed through a final Linear layer to predict the Start and End logits. This design allows the model to simultaneously weigh immediate boundaries and wider context when making extraction decisions, offering a structural improvement over the single-kernel approach without the overfitting risks of complex auxiliary tasks Cite {solution_lesson_node_00015}.
4.  **Regularization:** We will use standard Dropout. We will explicitly avoid Multi-Sample Dropout, as it has been shown to blur decision boundaries in this specific task Cite {solution_lesson_node_00012}.

# Data

**Preprocessing & Alignment:**
*   **"Normalize-First" Pipeline:** We will implement a strict synchronization protocol. We will normalize whitespace (collapsing multiple spaces) on the raw text *before* tokenization. Crucially, we will use this **same normalized string** for the final substring extraction. This prevents the critical index misalignment observed when tokenizer offsets are applied to mismatched raw text Cite {solution_lesson_node_00018}.
*   **Strategic Filtering:** We will continue to **exclude 'neutral' tweets** from the training set entirely. These samples follow a trivial identity mapping, and training on them wastes model capacity Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Soft Targets:** We will generate **Gaussian-smoothed targets** ($\sigma=1.0$) for the start and end indices. This prevents the model from overfitting to the noisy and subjective boundaries inherent in the dataset Cite {solution_lesson_node_00006}.

# Training

**Loss Function:**
*   We will use **Kullback-Leibler (KL) Divergence Loss** to align with the Gaussian soft targets Cite {solution_lesson_node_00007}.
*   **Loss Averaging:** We will explicitly **average** the losses from the start and end heads (i.e., $L = 0.5 \times L_{start} + 0.5 \times L_{end}$) rather than summing them. This preserves the gradient scale and ensures compatibility with standard pre-trained learning rates Cite {solution_lesson_node_00020}.

**Optimization Strategy:**
*   **Optimizer:** We will use AdamW with a linear learning rate scheduler.
*   **Stability First:** We will strictly **avoid** stacking complex optimization tricks like Adversarial Weight Perturbation (AWP) or Layer-wise Learning Rate Decay (LLRD) in this configuration. Previous lessons demonstrated that combining these with structural changes leads to instability and catastrophic failure Cite {solution_lesson_node_00015}.

# Evaluation

**Inference Pipeline:**
1.  **Neutral Samples:** Apply the deterministic rule: predict the full `text` Cite {solution_lesson_node_00002}.
2.  **Positive/Negative Samples:** Pass the **normalized** text through the DeBERTa model.
    *   **Joint Logit Decoding:** Calculate the score for span $(i, j)$ as the **sum of logits**: $Logit_{start}(i) + Logit_{end}(j)$. We will select the span that maximizes this sum subject to $i \le j$. We will explicitly avoid maximizing the sum of probabilities, as that heuristic is suboptimal Cite {solution_lesson_node_00021}.
    *   **Reconstruction:** Extract the predicted substring from the **normalized** input text using the tokenizer offsets to ensure bit-perfect alignment Cite {solution_lesson_node_00018}.
