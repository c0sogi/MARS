To optimize performance on the Tweet Sentiment Extraction task, I propose a solution that evolves the previous DistilRoBERTa-based approach into a more robust **RoBERTa-base** architecture with **Multi-Layer Feature Aggregation** and **Label Smoothing**.

### Model
**Backbone:**
We will upgrade the backbone from `distilroberta-base` to **`roberta-base`**. The larger model capacity (12 layers vs. 6) and more extensive pre-training of RoBERTa-base will allow for a more nuanced understanding of the semantic relationship between the sentiment label and the tweet content.

**Head (Structural Innovation):**
Instead of relying solely on the final hidden state (which is optimized for semantic summary), we will implement a **Weighted Layer Pooling** mechanism.
- We will extract the hidden states from the **last four layers** of the transformer.
- These states will be concatenated or aggregated via a learned weighted average.
- This aggregated representation will be passed to the start/end classifiers.
- **Rationale:** The task requires identifying exact phrasing (syntactic features often found in lower/middle layers) driven by sentiment (semantic features in higher layers). Aggregating layers preserves this multi-level information better than the final layer alone.

### Data
**Preprocessing:**
- **Tokenization:** Use the `roberta-base` tokenizer (Byte-Level BPE) to generate input IDs and attention masks. Crucially, we will generate and store **offset mappings** to translate token predictions back to original character indices.
- **Input Format:** `<s> [Sentiment] </s> </s> [Tweet Text] </s>`.
- **Target Generation:** Convert the character-level `selected_text` boundaries into start and end token indices.

**Strategic Retention:**
- **Neutral Filtering:** We will strictly retain the strategy of **excluding 'neutral' tweets from the training set** Cite {solution_lesson_node_00002}. The model will only train on 'positive' and 'negative' samples to focus its capacity on the non-trivial cases.

### Training
**Loss Function (Structural Innovation):**
We will replace the standard Cross Entropy Loss with **Cross Entropy with Gaussian Label Smoothing**.
- **Problem:** The training labels are noisy; human annotators often include or exclude adjacent punctuation or stop words arbitrarily. A hard target (1.0 probability at index `k`) penalizes reasonable near-misses too harshly.
- **Solution:** Instead of a one-hot target, we will smear the target probability distribution using a Gaussian kernel or simple smoothing around the ground truth index (e.g., `[..., 0.1, 0.8, 0.1, ...]`). This encourages the model to predict the general vicinity of the start/end points rather than overfitting to specific annotator idiosyncrasies.

**Optimization:**
- Optimizer: AdamW with a linear warmup and decay.
- Precision: Mixed Precision (FP16) to manage the increased memory footprint of RoBERTa-base.

### Evaluation
**Inference Strategy:**
We will employ the **Hybrid Inference Pipeline** validated in previous experiments Cite {solution_lesson_node_00002}:
1.  **Neutral Tweets:** Apply a deterministic rule: `prediction = text`. This bypasses the model entirely for this class.
2.  **Positive/Negative Tweets:** Pass the tokenized text through the trained RoBERTa model.
    - Compute the start and end logits.
    - Select the span `(start, end)` that maximizes the joint probability `P(start) + P(end)` subject to `start <= end`.
    - Use the offset mappings to extract the substring from the original text.
