# Model

**Architecture:** **DeBERTa-v3-Large with Dual-Stream Convolutional Heads**
We will utilize **`microsoft/deberta-v3-large`** as the backbone. Previous experiments confirmed that the `Large` variant, when properly stabilized, offers superior sample efficiency and performance over `Base` models due to its disentangled attention mechanism Cite {solution_lesson_node_00036}.

**Structural Innovation (Dual-Stream Head):**
To address the distinct local syntactic patterns of "start" boundaries (e.g., leading spaces, capitalization) versus "end" boundaries (e.g., trailing punctuation, stop words), we will replace the shared classification head with a **Dual-Stream Architecture**.
1.  **Weighted Layer Pooling:** Aggregate hidden states from the last four layers to capture both semantic and syntactic features Cite {solution_lesson_node_00007}.
2.  **Stream Splitting:** The pooled embedding will branch into two independent paths:
    *   **Start Stream:** A **1D Convolutional Layer** ($k=3$) followed by **Dropout** and a Linear Projection to the Start Logit.
    *   **End Stream:** A separate **1D Convolutional Layer** ($k=3$) followed by **Dropout** and a Linear Projection to the End Logit.
    *   *Rationale:* This decoupling allows the convolutional filters to specialize in the unique n-gram contexts of span onsets and offsets without interference, offering a structural improvement over the shared-weight approach Cite {solution_lesson_node_00011} while avoiding the redundancy of multi-scale heads Cite {solution_lesson_node_00022}.
3.  **Regularization:** We will include standard **Dropout** in each stream to enable extended training without overfitting Cite {solution_lesson_node_00037}. We will explicitly **avoid** Multi-Sample Dropout, which degrades precision in this task Cite {solution_lesson_node_00012}.

# Data

**Preprocessing & Alignment:**
*   **"Normalize-First" Pipeline:** We will strictly enforce a synchronized normalization protocol. We will normalize whitespace (collapsing multiple spaces) on the raw text *before* tokenization and use this **same normalized string** for the final substring extraction. This prevents the critical index misalignment observed in previous attempts Cite {solution_lesson_node_00018}.
*   **Input Formatting (Early Fusion):** We will format the input as `[CLS] Sentiment [SEP] Text [SEP]`. This allows the Transformer's self-attention to condition the text representation on the sentiment deep within the network, which is superior to Late Fusion Cite {solution_lesson_node_00033} or Decoupled Sentiment Heads Cite {solution_lesson_node_00029}.
*   **Strategic Filtering:** We will continue to **exclude 'neutral' tweets** from the training set entirely Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Containment Mapping:** We will generate token-level targets using **containment logic** (`token_start <= char_idx < token_end`) to handle subword splits accurately Cite {solution_lesson_node_00030}.
*   **Soft Targets:** We will generate **Gaussian-smoothed targets** ($\sigma=1.0$) for the start and end indices to handle annotation noise Cite {solution_lesson_node_00006}.

# Training

**Optimization Strategy:**
*   **Layer-wise Learning Rate Decay (LLRD):** To train the `Large` backbone effectively, we will apply LLRD with a decay factor of 0.9 and a higher base learning rate (e.g., 5e-5). This ensures the task heads converge rapidly while the lower backbone layers are fine-tuned conservatively, preventing the underfitting observed with flat learning rates Cite {solution_lesson_node_00036}.
*   **Loss Function:** We will use **Kullback-Leibler (KL) Divergence Loss** to align with the soft targets Cite {solution_lesson_node_00007}.
*   **Loss Averaging:** We will explicitly **average** the losses from the Start and End streams ($L = 0.5 \times L_{start} + 0.5 \times L_{end}$) rather than summing them, preserving the gradient scale for the pre-trained backbone Cite {solution_lesson_node_00020}.

# Evaluation

**Inference Pipeline:**
*   **Proxy Protocol:** For the development phase, we will train on **3 folds** to balance computational efficiency with validation reliability Cite {solution_lesson_node_00038}.
*   **Neutral Samples:** Deterministically predict the full `text` Cite {solution_lesson_node_00002}.
*   **Positive/Negative Samples:**
    1.  Pass the **normalized** text through the model.
    2.  **Joint Logit Decoding:** Calculate the score for span $(i, j)$ as the **sum of logits**: $Logit_{start}(i) + Logit_{end}(j)$. Select the span that maximizes this sum subject to $i \le j$ Cite {solution_lesson_node_00021}.
    3.  **Reconstruction:** Extract the predicted substring from the **normalized** input text using the tokenizer offsets to ensure bit-perfect alignment Cite {solution_lesson_node_00018}.
