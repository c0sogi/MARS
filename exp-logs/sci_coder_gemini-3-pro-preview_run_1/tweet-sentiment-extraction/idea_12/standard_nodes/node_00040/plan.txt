To improve the model's performance and robustness, I will implement a **5-Fold Cross-Validation Ensemble** strategy, integrating the strengths of the previous Dual-Stream architecture with the stability of a full ensemble.

**Strategy:**
1.  **Full Ensemble Training (Cite solution_lesson_node_00038):** I will revert from the "Proxy Protocol" (1 fold) to a full 5-fold training loop. While the single-model Dual-Stream approach (Idea 13) was efficient, ensembling is the most reliable method to push the Jaccard score from ~0.706 to >0.709 by reducing variance and improving generalization.
2.  **Extended Training Schedule (Cite solution_lesson_node_00037):** I will increase the training duration from 2 to 3 epochs. The presence of Dropout (0.1) in the custom head allows the model to train longer without overfitting, enabling the backbone to better adapt to the task.
3.  **Dual-Stream Architecture (Cite solution_lesson_node_00039):** I will retain the Dual-Stream Convolutional Head from the previous solution, as it proved to be a more effective per-model architecture than the shared head.
4.  **Robust Validation on Hold-Out Set:** Instead of validating on a subset of the training data, I will use the dedicated `validation_metadata.csv` (20% hold-out) for the final performance assessment. This ensures the reported metric is unbiased and directly comparable to the leaderboard.
5.  **Logit-Level Ensembling (Cite solution_lesson_node_00021):** I will implement `inference_fn_ensemble` to average the logits from all 5 models before decoding. This maximizes the joint probability of the span boundaries across the ensemble.

def inference_fn(test_loader, model, device, test_df):
    model.eval()
    all_start_logits = []
    all_end_logits = []
    all_offsets = []

    with torch.no_grad():
        for d in test_loader:
            input_ids = d["input_ids"].to(device)
            attention_mask = d["attention_mask"].to(device)
            offsets = d["offsets"].cpu().numpy()

            start_logits, end_logits = model(input_ids, attention_mask)

            all_start_logits.append(start_logits.cpu().numpy())
            all_end_logits.append(end_logits.cpu().numpy())
            all_offsets.append(offsets)

    start_preds = np.concatenate(all_start_logits)
    end_preds = np.concatenate(all_end_logits)
    offsets_preds = np.concatenate(all_offsets)

    final_predictions = []

    for i, row in test_df.iterrows():
        text = normalize_text(str(row["text"]))
        sentiment = str(row["sentiment"])

        # Neutral Strategy: Return full text
        if sentiment == "neutral":
            final_predictions.append(f'"{text}"')
            continue

        s_logits = start_preds[i]
        e_logits = end_preds[i]
        offsets = offsets_preds[i]

        sum_logits = np.add.outer(s_logits, e_logits)
        mask = np.triu(np.ones_like(sum_logits))
        sum_logits[mask == 0] = -float("inf")

        best_idx = np.argmax(sum_logits)
        best_start, best_end = np.unravel_index(best_idx, sum_logits.shape)

        if best_start < len(offsets) and best_end < len(offsets):
            start_char = offsets[best_start][0]
            end_char = offsets[best_end][1]
            pred_text = text[start_char:end_char]
        else:
            pred_text = text

        final_predictions.append(f'"{pred_text}"')

    return final_predictions
