# Model

**Architecture:** **DeBERTa-v3-Large with Shared CNN Head**
We will utilize **`microsoft/deberta-v3-large`** as the backbone. This model has proven to be the most effective feature extractor when stabilized with appropriate optimization techniques Cite {solution_lesson_node_00036}.

**Head Design:** **Shared Feature Extraction**
We will implement a **Shared Convolutional Head** rather than decoupled streams. Previous experiments demonstrated that maintaining a shared representation allows the model to learn the strong correlations between start and end boundaries more efficiently than independent streams Cite {solution_lesson_node_00041}.
1.  **Weighted Layer Pooling:** Aggregate hidden states from the last four layers to capture both semantic and syntactic features Cite {solution_lesson_node_00007}.
2.  **Shared Context Layer:** Pass the pooled embeddings through a single **1D Convolutional Layer** (kernel size 3) to capture local n-gram context and sharpen decision boundaries Cite {solution_lesson_node_00011}.
3.  **Regularization:** Apply **Standard Dropout** to the convolutional output to prevent overfitting during extended training Cite {solution_lesson_node_00037}. We will explicitly avoid Multi-Sample Dropout as it blurs decision boundaries Cite {solution_lesson_node_00012}.
4.  **Projection:** A single Linear layer projects the shared features to 2 output logits (Start and End).

# Data

**Preprocessing & Alignment:**
*   **"Normalize-First" Pipeline:** We will strictly enforce a synchronized normalization protocol. We will normalize whitespace (collapsing multiple spaces) on the raw text *before* tokenization and use this **same normalized string** for the final substring extraction. This prevents the critical index misalignment observed in previous attempts Cite {solution_lesson_node_00018}.
*   **Input Formatting (Early Fusion):** We will format the input as `[CLS] Sentiment [SEP] Text [SEP]`. This allows the Transformer's self-attention to condition the text representation on the sentiment deep within the network Cite {solution_lesson_node_00033}.
*   **Strategic Filtering:** We will continue to **exclude 'neutral' tweets** from the training set entirely, as they follow a trivial identity mapping Cite {solution_lesson_node_00002}.

**Target Generation:**
*   **Containment Mapping:** We will generate token-level targets using **containment logic** (`token_start <= char_idx < token_end`) to handle subword splits accurately Cite {solution_lesson_node_00030}.
*   **Soft Targets:** We will generate **Gaussian-smoothed targets** ($\sigma=1.0$) for the start and end indices Cite {solution_lesson_node_00006}.

# Training

**Loss Function (Structural Innovation):** **Soft Jaccard Loss**
Standard Cross-Entropy/KL loss optimizes the start and end probabilities independently, ignoring the structural validity of the resulting span. To address this, we will introduce a **Differentiable Soft Jaccard Loss** term.
*   **Mechanism:** We will derive a probabilistic span mask $M_{pred}$ from the predicted start ($P_s$) and end ($P_e$) distributions using cumulative sums: $M_{pred}[k] = P(start \le k) \times P(end \ge k)$.
*   **Objective:** We will minimize $L_{Jaccard} = 1 - \frac{\sum (M_{pred} \cdot M_{gt})}{\sum M_{pred} + \sum M_{gt} - \sum (M_{pred} \cdot M_{gt})}$, where $M_{gt}$ is the ground truth binary mask.
*   **Total Loss:** $L_{total} = (1-\alpha) \cdot \text{Avg}(L_{KL\_start}, L_{KL\_end}) + \alpha \cdot L_{Jaccard}$. This explicitly couples the boundary predictions to maximize the evaluation metric directly.

**Optimization Strategy:**
*   **Layer-wise Learning Rate Decay (LLRD):** We will apply LLRD with a decay factor of 0.9 and a high base learning rate (e.g., 5e-5) to effectively train the `Large` backbone without destroying pre-trained features Cite {solution_lesson_node_00036}.
*   **Stability:** We will avoid stacking unstable techniques like AWP Cite {solution_lesson_node_00015}.

# Evaluation

**Inference Pipeline:**
*   **5-Fold Ensemble:** We will train the model on 5 distinct folds and average the logits during inference. This is critical to smooth out variance and beat single-model baselines Cite {solution_lesson_node_00042}.
*   **Neutral Samples:** Deterministically predict the full `text` Cite {solution_lesson_node_00002}.
*   **Positive/Negative Samples:**
    1.  Pass the **normalized** text through the ensemble.
    2.  **Joint Logit Decoding:** Select the span $(i, j)$ that maximizes $Logit_{start}(i) + Logit_{end}(j)$ subject to $i \le j$ Cite {solution_lesson_node_00021}.
    3.  **Reconstruction:** Extract the predicted substring from the **normalized** input text using the tokenizer offsets Cite {solution_lesson_node_00018}.
