1.  **Data Processing (`library/data.py`)**: Modify the `process_data` function to explicitly multiply the generated Gaussian soft targets by the `attention_mask` and re-normalize them. This ensures that the target probability mass is strictly confined to valid tokens and is exactly zero in padded regions.
2.  **Loss Function (`library/loss.py`)**: Update `compute_loss` to use a safer masking value (`-10000.0`) for logits. With the targets now guaranteed to be zero in padded areas, this restores the mathematical validity of the KL Divergence calculation ($0 \times \text{large} = 0$) while ensuring the Softmax correctly distributes probability only among valid tokens.
