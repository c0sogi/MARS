1.  **Configuration Override**: Modify `Config.NUM_EPOCHS` to 50 to satisfy the "fast baseline" requirement while ensuring enough training to get meaningful results. Keep `Config.MAX_TRAIN_SAMPLES` as `None` since the dataset is small (92 samples).
2.  **Training Orchestration**: Iterate through the defined streams (Context and Texture) and their seeds, calling `run_training_session` for each to build the ensemble.
3.  **Ensemble Validation**:
    *   Load all trained models.
    *   Load the validation dataset using `get_dataloaders` (leveraging Stream A's config for consistency).
    *   Perform inference using the ensemble strategy: apply Test-Time Augmentation (TTA) via `predict_with_tta` for each model, average the predictions across all models, and clamp values to [0, 1].
    *   Compute the global RMSE on the validation set.
4.  **Failure Analysis**:
    *   During validation inference, calculate the RMSE for each individual image.
    *   Calculate the mean and standard deviation of pixel intensities for each input image.
    *   Compute and print the Pearson correlation between the prediction error (RMSE) and these input statistics.
5.  **Submission Logic**: Compare the calculated `Final Validation Metric` against the threshold (`0.011870221132053216`). If the metric is lower, call `generate_submission` to create the output file.
