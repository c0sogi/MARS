This script demonstrates the end-to-end usage of the provided library components for the text denoising task. It performs the following steps:
1.  **Configuration Patching**: Modifies the training configuration (Epochs, Seeds) at runtime to ensure the demonstration runs quickly.
2.  **Dataset Verification**: Instantiates the dataset and dataloaders to verify data loading, augmentation (patching), and tensor shapes.
3.  **Model Verification**: Instantiates the U-Net model, performs a forward pass with dummy data, and asserts output dimensions and value ranges.
4.  **Training Loop**: Runs a single epoch of training using `train_model` to verify the training pipeline, loss calculation, and checkpoint saving.
5.  **Inference & Submission**: Generates predictions using the trained model via `generate_predictions` and verifies the format and integrity of the output submission file.
