The `_pickle.UnpicklingError` is caused by `torch.load` (which defaults to `weights_only=True` in recent PyTorch versions) encountering a NumPy scalar value (`numpy.float64` or similar) in the checkpoint. This scalar originates from the `rmse_score` function, which returns `np.sqrt(mse)`. NumPy scalars are not on the default allowlist for secure loading. To fix this, I will modify `rmse_score` in `library/utils.py` to explicitly cast the result to a native Python `float`. This ensures the `best_rmse` value saved in the checkpoint is a standard primitive, preventing the unpickling error during verification.
