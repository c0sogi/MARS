Recent versions of PyTorch default `torch.load` to `weights_only=True` for security, which rejects NumPy types like `numpy.float64` during unpickling. To resolve this, I will explicitly cast the `val_rmse` metric to a native Python `float` before saving it in the checkpoint dictionary within `library/engine.py`. Cite debug_lesson_7.
