The following implementation strategy demonstrates the usage of the provided library files (`config.py`, `utils.py`, `dataset.py`, `models.py`, `engine.py`) to perform a complete, albeit abbreviated, machine learning workflow.

### Strategy Outline
1.  **Setup & Configuration**: Initialize the environment with a fixed random seed and determine the compute device (CPU/GPU).
2.  **Utility Verification**: Demonstrate and verify the signal processing functions (`invert_signal`, `revert_signal`) and the metric function (`rmse_loss`) using assertions.
3.  **Data Pipeline**:
    *   Use `load_and_cache_data` to load a small subset (limit=10) of the training and validation metadata.
    *   Instantiate `DenoisingDataset` for both training (with augmentation and cropping) and validation (padding only).
    *   Create PyTorch `DataLoader` instances.
    *   Verify data shapes and value ranges.
4.  **Model Instantiation**:
    *   Construct both the "Context" and "Diversity" models using the builder functions provided in `models.py`.
    *   Perform a dummy forward pass to verify that input/output dimensions match the expected U-Net behavior.
5.  **Training Loop**:
    *   Configure an optimizer (`Adam`) and a learning rate scheduler.
    *   Use the `fit_model` function from `engine.py` to run a single training epoch.
    *   Verify that the training completes, returns a valid RMSE score, and saves a model checkpoint.
6.  **Checkpoint Management**: Verify that the saved checkpoint can be successfully loaded back into the model and optimizer using `load_checkpoint`.
