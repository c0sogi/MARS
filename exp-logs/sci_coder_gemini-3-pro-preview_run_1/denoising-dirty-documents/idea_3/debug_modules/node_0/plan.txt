The implementation strategy involves a step-by-step verification and execution pipeline contained within a single Python script.

1.  **Configuration Override**: We will first import the `Config` class and modify specific parameters (e.g., `NUM_MODELS=1`, `BATCH_SIZE=2`, `NUM_WORKERS=0`) to ensure the code runs quickly on the provided hardware without unnecessary overhead.
2.  **Component Verification**: We will systematically instantiate and test the core components:
    *   **Utils**: Verify the RMSE calculation logic.
    *   **Dataset**: Instantiate `DenoisingDataset` in debug mode for train, validation, and test splits. We will assert that the data shapes and types are correct (e.g., patches for training, full images for validation).
    *   **Model**: Instantiate the `AttentionUNet` and perform a forward pass with a dummy tensor to confirm input/output shape consistency.
3.  **Training Simulation**: We will execute `train_single_model` with `debug=True`. This function (from the provided library) runs a shortened training loop (2 epochs) on a subset of data. We will verify that the model checkpoint is successfully saved to the working directory.
4.  **Inference Simulation**: We will execute `generate_submission` with `debug=True`. This will load the trained checkpoint, perform inference with Test-Time Augmentation (TTA), and generate a CSV file. We will verify the existence and basic structure of the output file.
