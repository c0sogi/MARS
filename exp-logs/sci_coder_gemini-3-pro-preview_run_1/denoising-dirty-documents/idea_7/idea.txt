Based on the analysis of the provided lessons and the specific constraints of the task, I propose the following optimized strategy. This solution addresses the "Depth-Resolution Mismatch" identified in Lesson 26 by scaling the input patch size to unlock the capacity of deeper networks, and utilizes a "Fully Converged Ensemble" to minimize variance without the bias of undertraining.

# Model
**Architecture: Resolution-Scaled 4-Level U-Net**
I propose reverting to the **Standard 4-Level U-Net** architecture (Encoder: 32 $\to$ 64 $\to$ 128 $\to$ 256 $\to$ 512 filters), but with critical modifications to support the data strategy.
*   **Rationale:** Previous experiments (Cite {solution_lesson_node_00018}, Cite {solution_lesson_node_00026}) suggested that a 4-level network underperformed a 3-level one. However, Lesson 26 identified the root cause as **excessive spatial compression** in the bottleneck (10x10 pixels) when using 160x160 patches. By addressing the input resolution (see Data section), we can leverage the superior feature abstraction of the 4-level deep network without suffering from spatial information loss.
*   **Upsampling:** We will strictly employ **Bilinear Upsampling followed by Convolution** in the decoder. This avoids the checkerboard artifacts associated with Transposed Convolutions (Cite {solution_lesson_node_00009}).
*   **No Deep Supervision:** We will rely on a single output head, as auxiliary losses were found to over-constrain the decoder in this specific restoration task (Cite {solution_lesson_node_00017}).
*   **Direct Signal Prediction:** The model will predict the clean image directly, avoiding the "Residual Learning" (noise prediction) approach which failed due to lack of abstraction power in previous attempts (Cite {solution_lesson_node_00023}).

# Data
**Preprocessing & Augmentation**
*   **Super-Large Patch Training (Structural Innovation):** We will increase the training patch size from $160 \times 160$ to **$320 \times 320$ pixels**.
    *   **Reasoning:** With a 4-level U-Net (downsampling factor 16), a 320-pixel input results in a **$20 \times 20$ bottleneck**. This matches the bottleneck resolution of the successful 3-level model on smaller patches (Cite {solution_lesson_node_00026}). This change effectively resolves the "Depth-Patch Resolution Mismatch," allowing us to utilize a deeper, more powerful model while preserving the critical spatial context required for text reconstruction (Cite {solution_lesson_node_00016}).
*   **Aggressive Geometric Augmentation:** We will apply random horizontal flips, vertical flips, and 90-degree rotations. This exploits the rotational invariance of the noise to virtually multiply the dataset size (Cite {solution_lesson_node_00003}).
*   **Deterministic Loading:** We will implement a `worker_init_fn` to seed the data loader workers, ensuring that the random cropping is fully reproducible across runs (Cite {solution_lesson_node_00015}).

# Training
**Strategy: Seed-Averaging Ensemble of Fully Converged Models**
Instead of Cross-Validation (which reduces training data) or a single model (which has high variance), we will implement a **Bagging-style Ensemble** trained on the full dataset.
*   **Full Convergence (Key Correction):** We will train **5 independent models** with different random seeds, each for **1000 epochs**.
    *   Previous ensemble attempts failed because they sacrificed training duration for model count (Cite {solution_lesson_node_00012}). Since the dataset is small, training 5 models to full convergence is computationally feasible within the 24-hour limit. This combines the low bias of a fully trained deep model with the variance reduction of an ensemble.
*   **Optimization Velocity:** We will use the **Adam** optimizer with a **high learning rate (1e-3)** and **small batch size (16)** to maximize gradient update frequency (Cite {solution_lesson_node_00010}).
*   **Scheduler:** We will use **Cosine Annealing** with `T_max=1000`. This decouples the scheduler from early stopping, ensuring the learning rate decays fully to zero to refine fine-grained details (Cite {solution_lesson_node_00007}).
*   **Loss Function:** Mean Squared Error (MSE).

# Evaluation
**Inference Pipeline**
*   **Test-Time Augmentation (TTA):** For each test image, we will generate predictions for **8 geometric views** (Original, Rot90, Rot180, Rot270, and their horizontal flips). These will be inversely transformed and averaged. This smooths out prediction noise and aligns the evaluation protocol with the best-performing baselines (Cite {solution_lesson_node_00006}, Cite {solution_lesson_node_00025}).
*   **Ensemble Aggregation:** The TTA-averaged outputs from all **5 fully converged models** will be averaged together to produce the final pixel intensities.
*   **Padding:** Test images will be padded to be multiples of 16 (to match the 4-level downsampling) before inference and cropped after.
