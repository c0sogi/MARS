The implementation strategy is as follows:

1.  **Configuration Override**: We will override the `Config` class attributes to create a "Fast Baseline". Specifically, we will reduce the ensemble size to a single model (`seed=42`) and limit the training to 500 epochs. Given the small dataset size (92 images) and the powerful A100 GPU, 500 epochs will complete in a few minutes while ensuring sufficient convergence to potentially meet the strict validation threshold.
2.  **Training**: We will execute the training pipeline using `library.train.train_ensemble()`. This will train our single model and save the checkpoint.
3.  **Validation & Analysis**: We will manually iterate through the validation set using the trained model. We will calculate the global RMSE (Root Mean Squared Error) to satisfy the metric reporting requirement. Concurrently, we will collect per-image error statistics and input features (mean intensity, standard deviation, area) to compute Pearson correlations for the required failure analysis.
4.  **Submission**: We will compare the calculated final validation metric against the strict threshold (`0.011870221132053216`). If and only if the metric is lower, we will trigger the inference pipeline using `library.inference.predict_and_save()` to generate the `submission.csv`.
