The `RuntimeError` during inference occurs because the Test-Time Augmentation (TTA) strategy attempts to concatenate rotated images into a single batch. When processing non-square images (e.g., $272 \times 544$), a 90-degree rotation swaps the dimensions (to $544 \times 272$), making it impossible to stack them with the original image in the same tensor. To fix this, I will modify `apply_tta` to detect non-square inputs and split the inference into two separate batches: one for dimension-preserving transformations (original, 180° rotation, flips) and another for dimension-swapping transformations (90°/270° rotations). This approach isolates dimension-altering augmentations, ensuring tensor shapes match within each batch, as recommended in **debug_lesson_2**. Cite {debug_lesson_2}
