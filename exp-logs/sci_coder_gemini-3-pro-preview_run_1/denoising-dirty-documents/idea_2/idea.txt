To optimize the solution for the text image denoising task, I propose evolving the baseline U-Net into a **Residual U-Net (ResUNet)**. This strategy integrates the successful data and training paradigms identified in the lessons while introducing a more powerful architectural backbone capable of deeper feature extraction and better gradient flow.

### Model
**Architecture: Residual U-Net (ResUNet)**
Instead of the standard Convolutional U-Net used previously, we will implement a **Residual U-Net**.
*   **Structural Change:** Replace the standard convolutional blocks in both the encoder (contracting path) and decoder (expanding path) with **Residual Blocks**.
*   **Residual Block Design:** Each block consists of two $3 \times 3$ convolutional layers (with Batch Normalization and ReLU activation). Crucially, a shortcut connection adds the input of the block directly to its output ($F(x) + x$).
*   **Benefit:** This architecture allows the model to learn identity mappings more easily, which is ideal for denoising tasks where the output (clean image) is structurally similar to the input (noisy image). It mitigates the vanishing gradient problem, enabling the training of a deeper network to capture more complex noise patterns without degrading performance.

### Data
**Preprocessing & Augmentation**
*   **Patch-Based Training:** We will strictly avoid resizing the source images. Instead, we will generate **fixed-size random crops** (e.g., $128 \times 128$) from the high-resolution training images. This preserves the high-frequency noise artifacts and text textures essential for the model to learn. Cite {solution_lesson_node_00001}
*   **Geometric Augmentation:** We will apply **aggressive geometric augmentations** to the training patches, including Random Horizontal Flips, Random Vertical Flips, and Random 90-degree Rotations. This exploits the rotational invariance of pixel-level noise to virtually multiply the dataset size. Cite {solution_lesson_node_00003}

### Training
**Procedure & Optimization**
*   **Loss Function:** Mean Squared Error (MSE) will be used to directly minimize the competition metric.
*   **Scheduler:** We will employ a **Cosine Annealing Learning Rate** scheduler. Crucially, we will **decouple the scheduler horizon** by setting `T_max` (e.g., 1500 epochs) to be significantly longer than the actual training duration. This ensures the learning rate remains sufficiently high to escape local minima and continues refining weights throughout the entire training process. Cite {solution_lesson_node_00006}, Cite {solution_lesson_node_00007}
*   **Duration:** The model will be trained for an **extended duration** (e.g., 300–400 epochs) to allow full convergence on the geometrically augmented dataset. Cite {solution_lesson_node_00003}
*   **Performance Gating:** We will implement a conditional logic check at the end of training. The submission file will only be generated if the current model's validation RMSE is lower than the best metric recorded in previous experiments, preventing regression due to stochastic variance. Cite {solution_lesson_node_00005}

### Evaluation
**Inference Strategy**
*   **Full-Image Inference:** Test images will be padded to be divisible by the network's downsampling factor (e.g., 32), processed at full resolution, and then cropped back to the original size.
*   **Test-Time Augmentation (TTA):** We will apply TTA by generating predictions for the original image and three geometric variations (horizontal flip, vertical flip, and combined flip). The final output will be the pixel-wise average of these four predictions, reducing variance and smoothing out residual noise artifacts. Cite {solution_lesson_node_00006}
