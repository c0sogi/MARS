Here is the implementation strategy and the corresponding Python script.

### Implementation Strategy
1.  **Environment Setup**: Import standard data science libraries (`pandas`, `numpy`, `scipy`) and image processing tools (`cv2`). Set a fixed random seed to ensure reproducibility.
2.  **Data Loading**: Utilize the generated `./metadata/train.csv` to retrieve file paths for the training dataset. This ensures we only analyze the training split to prevent data leakage.
3.  **Iterative Analysis**: Loop through each image pair (noisy input and clean target) in the training set:
    *   **Image Properties**: Extract width, height, aspect ratio, and channel count.
    *   **Pixel Statistics**: Normalize pixel intensities to the [0, 1] range (as required by the submission format). Collect a random 5% subsample of pixels from each image to efficiently approximate the global distribution of pixel values for both noisy and clean sets.
    *   **Meta-Features**: Calculate image-level statistics (mean intensity, total area) to analyze relationships between the input signal and the target.
4.  **Statistical Computation**:
    *   **Target Analysis**: Compute Mean, Standard Deviation, Skewness, and Kurtosis on the aggregated clean pixel values to understand the regression target distribution.
    *   **Input Analysis**: aggregate dimensional stats and global pixel stats for the noisy images.
    *   **Relationships**: Calculate Pearson correlation coefficients to quantify relationships between metadata (e.g., Image Area) and target properties (e.g., Mean Clean Intensity).
5.  **Output**: Format the results into the required capitalized sections with values rounded to 4 decimal places.
