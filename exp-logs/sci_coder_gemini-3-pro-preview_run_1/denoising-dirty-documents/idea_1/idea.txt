Based on the provided dataset and task requirements, I propose a **Convolutional Autoencoder with Skip Connections (U-Net)** as the baseline approach. This method is synthesized from **Model 1** in the provided architectures, optimized for speed and simplicity while effectively handling the spatial nature of text denoising.

### Model
The architecture is a lightweight Fully Convolutional Network (FCN) following the U-Net design pattern. This structure is ideal for image-to-image translation tasks like denoising as it preserves spatial details through skip connections.
*   **Encoder (Contracting Path):** Consists of 3 blocks. Each block applies two $3 \times 3$ convolutional layers (with ReLU activation) followed by a $2 \times 2$ max-pooling operation to downsample the feature map and capture context. The number of filters will start small (e.g., 32) and double with each block (32 $\to$ 64 $\to$ 128) to remain lightweight.
*   **Bottleneck:** A central block of convolutional layers processing the compressed representation.
*   **Decoder (Expanding Path):** Consists of 3 blocks symmetric to the encoder. Each block performs upsampling (bilinear or transposed convolution), concatenates the feature map from the corresponding encoder level (skip connection), and applies two $3 \times 3$ convolutional layers. This allows the model to recover high-frequency details (text edges) lost during downsampling.
*   **Output Head:** A final $1 \times 1$ convolution with a **Sigmoid** activation function to project the pixel intensities into the normalized $[0, 1]$ range.

### Data
*   **Preprocessing:** All images (train, validation, and test) will be loaded in grayscale and normalized by dividing pixel intensities by 255.0 to scale them to the $[0, 1]$ range.
*   **Patch Extraction (Training):** Given the small dataset size (92 training images), training on full images is inefficient and limits data diversity. We will implement a dynamic patch generator that extracts random crops (e.g., $128 \times 128$ pixels) from the source images during training. This strategy effectively multiplies the dataset size, allowing the model to learn local noise patterns and text structures robustly.
*   **Validation:** Validation will be performed on the full-sized validation images (batch size of 1) to accurately monitor the global RMSE metric.

### Training
*   **Loss Function:** **Mean Squared Error (MSE)** will be used as the loss function. MSE is mathematically aligned with the competition's Root Mean Squared Error (RMSE) metric, ensuring the optimization process directly minimizes the target error.
*   **Optimizer:** The **Adam** optimizer will be employed for its adaptive learning rate capabilities, which generally leads to faster convergence compared to standard SGD.
*   **Procedure:** The model will be trained for a fixed number of epochs (e.g., 50) with a **Model Checkpoint** strategy that saves the weights achieving the lowest validation loss. Early stopping will be configured to halt training if validation loss stagnates, preventing overfitting and saving runtime.

### Evaluation
*   **Inference:** For the test set, the model will process the full-resolution images directly. Since the architecture is fully convolutional, it can handle the varying dimensions of the test images without resizing.
*   **Padding:** If the image dimensions are not divisible by the network's downsampling factor (e.g., 8), the images will be essentially padded (reflection or zero padding) before inference and cropped back to the original size afterwards.
*   **Submission Generation:** The predicted output tensors (clean images) will be flattened. Each pixel value will be paired with its corresponding `image_row_col` ID and written to the CSV submission file.
