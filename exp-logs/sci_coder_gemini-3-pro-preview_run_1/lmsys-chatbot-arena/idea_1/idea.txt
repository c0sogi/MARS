# Solution Proposal

### Model
The proposed architecture is a **Multi-Layer Perceptron (MLP) Classifier using Frozen Sentence Embeddings**. This approach bridges the gap between the tree-based models using scalar features (Model 1) and the computationally expensive fine-tuned transformers (Model 4).
*   **Feature Extractor:** A lightweight, pre-trained Sentence Transformer (e.g., `all-MiniLM-L6-v2`) serves as a static encoder. It independently processes the `Prompt`, `Response A`, and `Response B` texts to generate three dense, fixed-dimensional embedding vectors ($E_p, E_a, E_b$). The encoder weights are **frozen** throughout the process to maximize speed and minimize memory usage.
*   **Classifier Head:** The three embedding vectors are concatenated to form a single feature vector $X = [E_p, E_a, E_b]$. This vector is passed into a shallow MLP consisting of an input layer, one hidden layer with ReLU activation and Batch Normalization, and a final output layer with 3 units corresponding to the target classes (Model A, Model B, Tie).

### Data
1.  **Preprocessing:** Basic whitespace normalization is applied to all text columns.
2.  **Vectorization:** To ensure high efficiency, the expensive transformer inference is performed **once** as a preprocessing step. The `Prompt`, `Response A`, and `Response B` columns for the entire dataset (Train, Validation, and Test) are converted into embedding matrices using the frozen transformer.
3.  **Feature Engineering:** The three embedding matrices are concatenated along the feature axis.
4.  **Normalization:** The resulting dense feature matrix is normalized using Standard Scaling (Z-score normalization) to ensure stable gradient descent training for the MLP.

### Training
1.  **Objective:** The model is trained to minimize **Categorical Cross-Entropy Loss**.
2.  **Optimizer:** The **Adam** optimizer is used with a standard learning rate (e.g., 0.001) and weight decay for regularization.
3.  **Procedure:** The MLP is trained for a fixed number of epochs (e.g., 20) using mini-batch gradient descent. **Early Stopping** is implemented by monitoring the Log Loss on the validation set to halt training when performance plateaus, preventing overfitting.

### Evaluation
1.  **Inference:** The test data is processed through the same pipeline: text is vectorized using the frozen transformer, concatenated, and scaled using the statistics derived from the training set.
2.  **Prediction:** The pre-computed test features are fed into the trained MLP to obtain raw logits.
3.  **Formatting:** A **Softmax** activation function is applied to the logits to generate a valid probability distribution summing to 1 for the columns `winner_model_a`, `winner_model_b`, and `winner_tie`.
