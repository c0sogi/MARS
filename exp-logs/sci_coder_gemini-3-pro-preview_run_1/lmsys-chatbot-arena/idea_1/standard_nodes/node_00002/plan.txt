The issue stems from the `generate_predictions` function in `library/model.py` assuming that the provided `dataloader` always yields a single tensor (features). However, when `runfile.py` passes the validation loader (`val_loader`), the `ArenaDataset` yields tuples of `(features, targets)`, which the DataLoader collates into a list `[features, targets]`. Attempting to call `.to(device)` on this list raises the `AttributeError`. The fix involves checking if the batch yielded by the dataloader is a list or tuple, and if so, extracting the first element (the features) before proceeding with inference.
