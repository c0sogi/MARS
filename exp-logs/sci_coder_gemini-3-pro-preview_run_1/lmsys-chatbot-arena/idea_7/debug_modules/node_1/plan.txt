The issue is that while the `test_loader` respects the `Config.DEBUG` flag and only yields a subset of data (10 rows), the `predict` function in `library/engine.py` independently loads the full test CSV (5748 rows) to retrieve IDs for the submission file. This creates a length mismatch between the generated predictions array and the IDs column when constructing the DataFrame. The fix is to apply the same subsetting logic (using `Config.DEBUG_SUBSET_SIZE`) to the test DataFrame loaded in `predict` when debug mode is enabled.
