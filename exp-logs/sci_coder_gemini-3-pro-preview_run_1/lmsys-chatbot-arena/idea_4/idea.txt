# Solution Proposal

### Model
**Architecture:** Siamese DeBERTa-v3-Base with Weighted Layer Pooling
To address the underfitting observed in previous iterations (Cite **solution_lesson_node_00015**) and capture the subtle structural nuances required for quality ranking, I propose upgrading the backbone to **`microsoft/deberta-v3-base`**. This increases model capacity significantly compared to the `small` variant.
1.  **Siamese Backbone:** The model uses a shared DeBERTa-v3-Base encoder to process two input sequences:
    *   Branch A: `[CLS] Prompt [SEP] Response A [SEP]`
    *   Branch B: `[CLS] Prompt [SEP] Response B [SEP]`
2.  **Weighted Layer Pooling:** Instead of using simple Mean Pooling on the final layer (which Lesson **solution_lesson_node_00016** proved superior to [CLS] pooling), I will implement **Weighted Layer Pooling**. This mechanism learns a scalar weight for each of the last 4 hidden layers of the transformer and computes their weighted average. This allows the model to leverage both the high-level semantic abstractions of the final layer and the lower-level syntactic and structural signals (preserved in earlier layers) that are crucial for judging writing quality.
3.  **Interaction & Fusion:**
    *   Compute geometric interaction terms from the pooled embeddings $u$ and $v$: $|u - v|$ and $u \cdot v$ (Cite **solution_lesson_node_00013**).
    *   **Structural Injection:** Concatenate these interaction vectors with a set of **Explicit Scalar Features**.
4.  **Scalar Features:** Based on previous findings, the injected vector will strictly contain:
    *   **Global Statistics:** Character counts, word counts, and newline counts (Cite **solution_lesson_node_00006**, **solution_lesson_node_00008**).
    *   **Relative Interactions:** Explicit length ratios ($A/B$) and differences ($A-B$) (Cite **solution_lesson_node_00010**).
    *   *Exclusion:* Local token counts (e.g., code blocks, bold tags) will be excluded as the Transformer attention handles these locally (Cite **solution_lesson_node_00018**).

### Data
1.  **Preprocessing:** Tokenize inputs using the `deberta-v3-base` tokenizer with a max length of 512 tokens.
2.  **Feature Engineering:** Pre-compute the global scalar features (lengths, newlines, ratios) for the entire dataset.
3.  **Cache Management:** Implement explicit versioning in cache filenames (e.g., `features_v2_base.npy`) to prevent the "stale cache" silent failure (Cite **solution_lesson_node_00007**).
4.  **Dataset:** Train on the **full training dataset** (~41k samples) to maximize signal (Cite **solution_lesson_node_00006**).

### Training
1.  **Objective:** Minimize Categorical Cross-Entropy Loss.
2.  **Optimization:** Use **AdamW** with a **differential learning rate** strategy:
    *   Backbone: Lower LR (e.g., 1e-5) to preserve pre-trained knowledge.
    *   Head/Pooling Weights: Higher LR (e.g., 1e-3) to learn the task-specific fusion.
3.  **Convergence Strategy:** Train for a sufficient number of epochs (e.g., 3-4) to ensure the **Training Loss drops to or below the Validation Loss**. This explicitly addresses the underfitting signal (inverted loss delta) observed in previous experiments (Cite **solution_lesson_node_00015**).
4.  **Compute:** Utilize Mixed Precision (FP16) to fit the Base model and batch size (e.g., 8) within the A100 GPU memory.

### Evaluation
1.  **Inference:** Process the test set pairs through the fine-tuned Siamese Base model to obtain embeddings.
2.  **Fusion:** Apply the learned Layer Weights to pool the embeddings, compute interaction terms, and concatenate with the pre-computed test-set scalar features.
3.  **Prediction:** Generate the final probability distribution via the MLP head.
