# Solution Proposal: Siamese DeBERTa-Base with Late-Stage Cross-Attention

### Model
**Architecture:** Siamese DeBERTa-v3-Base with Weighted Layer Mixing and Cross-Attention Fusion.
This architecture bridges the gap between the efficiency of Siamese networks and the granular comparison capabilities of Cross-Encoders.
1.  **Backbone:** Utilize `microsoft/deberta-v3-base` as the shared encoder. This retains the high capacity required for subtle semantic distinctions (Cite **solution_lesson_node_00023**) while avoiding the memory constraints of larger models.
2.  **Siamese Encoding:** Process `Prompt + Response A` and `Prompt + Response B` independently to generate two distinct sequences of hidden states.
3.  **Weighted Layer Mixing:** Instead of pooling immediately, extract the hidden states from the **last 4 layers** and compute a learnable weighted sum for each token position. This produces a rich *sequence representation* ($H_A, H_B$) that preserves both high-level semantics and low-level structural signals (Cite **solution_lesson_node_00023**).
4.  **Late-Stage Cross-Attention (Structural Innovation):** Introduce a lightweight **Cross-Attention Block** (1-2 Transformer layers) that takes the two sequence representations $H_A$ and $H_B$ as inputs.
    *   Perform attention where $Q=H_A, K=H_B, V=H_B$ (and vice versa) to allow the model to explicitly align and compare specific segments (e.g., code blocks, arguments) between the two responses at the token level.
    *   This directly addresses the limitation of frozen/simple embeddings in capturing "quality" (Cite **solution_lesson_node_00002**) by enabling fine-grained contrastive learning similar to a Cross-Encoder, but within a Siamese framework.
5.  **Pooling & Fusion:**
    *   Apply **Mean Pooling** to the outputs of the Cross-Attention block to obtain global vectors $u_{cross}$ and $v_{cross}$ (Cite **solution_lesson_node_00016**).
    *   Concatenate these vectors with a set of **Relative Scalar Features**.
6.  **Classifier Head:** A Multi-Layer Perceptron (MLP) that maps the fused vector to the 3 target classes.

### Data
1.  **Dataset Strategy:** Train on the **full training dataset** (~41k samples). Do not subsample, as model capacity cannot compensate for data loss (Cite **solution_lesson_node_00019**).
2.  **Feature Engineering:**
    *   Compute global statistics: Character count, Word count, Newline count.
    *   **Strict Relative Constraint:** Convert all statistics into pairwise **Differences** ($A-B$) and **Ratios** ($A/B$). Explicitly **exclude** absolute values to prevent the model from learning non-generalizable heuristics like "longer is better" (Cite **solution_lesson_node_00020**).
    *   Retain these orthogonal structural signals as they complement the semantic attention (Cite **solution_lesson_node_00006**).
3.  **Preprocessing:** Tokenize inputs using `deberta-v3-base` tokenizer with a max length of 512 tokens per branch.

### Training
1.  **Compute Strategy:** Use **Gradient Accumulation** to achieve an effective batch size of 16-32 while fitting the Base model + Cross-Attention block into GPU memory (Cite **solution_lesson_node_00023**). Use Mixed Precision (FP16).
2.  **Optimization:**
    *   **Optimizer:** AdamW.
    *   **Differential Learning Rates:** Use a lower LR (e.g., 1e-5) for the pre-trained Backbone and a higher LR (e.g., 1e-4 or 1e-3) for the new Cross-Attention block and Classifier Head to facilitate rapid adaptation.
3.  **Convergence:** Train for 2-4 epochs. Explicitly monitor the **Training vs. Validation Loss delta**. Continue training until the Training Loss drops to or slightly below the Validation Loss to ensure the model is not underfitting (Cite **solution_lesson_node_00015**).
4.  **Regularization:** Apply dropout within the Cross-Attention block and early stopping based on Validation Log Loss (Cite **solution_lesson_node_00021**).

### Evaluation
1.  **Inference:** Pass test set pairs through the Siamese backbone to get sequences.
2.  **Interaction:** Process sequences through the learned Cross-Attention block.
3.  **Prediction:** Pool the outputs, fuse with pre-computed **relative** test-set scalar features, and generate probabilities via the MLP.
