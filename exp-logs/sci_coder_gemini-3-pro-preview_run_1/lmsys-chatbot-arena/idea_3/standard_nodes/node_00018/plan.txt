The `RuntimeError: mat1 and mat2 shapes cannot be multiplied` arises because the model's classification head is initialized with an input dimension based on `Config.NUM_SCALAR_FEATURES` (set to 5), while the data pipeline generates 7 features as defined in `Config.SCALAR_FEATURE_LIST`. This discrepancy causes the input tensor (size 3079) to mismatch the weight matrix (expecting 3077). Cite debug_lesson_2. To fix this, I will update `Config.NUM_SCALAR_FEATURES` in `library/config.py` to 7, ensuring it matches the actual number of features being generated.
