The implementation strategy involves the following steps:

1.  **Setup and Loading**: Initialize paths for input and output directories. Load the raw `train.csv` and `test.csv` files from the `./input` directory using pandas.
2.  **Path Construction**: Add a `file_path` column to the dataframes. For the training set, paths will be `train_images/{Id}.jpg`. For the test set, paths will be `test_images/{Id}.jpg`.
3.  **Data Splitting**:
    -   Check if a grouping column (e.g., `location`, `seq_id`) exists to perform Group Sampling. If not, default to Stratified Sampling based on the `Category` column.
    -   Split the training data into training (80%) and validation (20%) sets using `sklearn`'s splitting utilities with `random_state=42`.
4.  **Saving Metadata**: Save the processed dataframes (`train_meta.csv`, `val_meta.csv`, `test_meta.csv`) to the `./metadata` directory.
5.  **Verification**:
    -   Reload the generated metadata files.
    -   Print summary statistics (counts, class distribution).
    -   **File Existence Check**: Randomly sample 1000 paths from each dataset and verify they exist in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
    -   **Split Verification**: Verify that the validation split respects the stratification (or grouping) requirements by comparing label distributions or ensuring group exclusivity.
