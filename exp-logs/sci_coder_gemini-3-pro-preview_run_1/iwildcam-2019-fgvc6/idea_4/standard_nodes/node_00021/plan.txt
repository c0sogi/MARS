To optimize performance, I will implement a "dampened" class weighting strategy for the Focal Loss function. Based on the failure analysis of the previous solution, the linear inverse frequency weighting was too aggressive, causing the model to over-prioritize rare classes (negative correlation between error and class weight). I will switch to a square-root inverse frequency weighting scheme ($W \propto \sqrt{N_{total}/N_c}$), which reduces the weight variance between majority and minority classes while still addressing imbalance. This approach is directly derived from Lesson `solution_lesson_node_00020`.
