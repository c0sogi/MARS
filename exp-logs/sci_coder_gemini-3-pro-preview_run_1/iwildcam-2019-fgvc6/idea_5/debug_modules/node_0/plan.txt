### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override key parameters (Image Size, Batch Size, Directories) to create a lightweight "Demo" environment. This ensures the code runs quickly and does not interfere with production paths.
2.  **Dataset Verification**: Instantiate the `AnimalDataset` with a small sample size. Verify that data loading, image transformation, and label extraction work correctly by inspecting the shapes and types of the returned dictionary.
3.  **Model & Loss Verification**: Instantiate the `MultiTaskConvNeXt` model and `CompositeLoss`. Pass a dummy batch through the model to verify the forward pass and shape of the logits. Calculate the loss to ensure the mathematical operations (Focal Loss + BCE) function without errors.
4.  **Training Integration**: Execute the `train_model` function from the `engine` module with a limited sample size (e.g., 50 images) and 1 epoch. This verifies the end-to-end training loop, including data loading, backpropagation, EMA updates, and checkpoint saving.
5.  **Inference Integration**: Execute the `generate_submission` function. Verify that it loads the trained model and produces a submission file in the correct format.
6.  **Reproducibility**: Apply `seed_everything` at the start.
