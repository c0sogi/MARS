Here is the execution plan for the `runfile.py` script:

1.  **Setup & Imports**: Import necessary modules from the standard library and the provided `library` package (`config`, `utils`, `dataset`, `model`, `engine`).
2.  **Training**: Execute `engine.train_model`. To ensure the process completes within the 2-hour limit while maintaining high data fidelity, I will run the training for **2 epochs** on the **full dataset**. This provides a balance between convergence and runtime (estimated ~40-60 minutes on A100).
3.  **Validation**:
    *   Load the best saved model (which contains EMA weights).
    *   Run inference on the full validation set.
    *   Calculate and print the **Final Validation Metric** (Macro F1) with full precision.
4.  **Failure Analysis**:
    *   Construct a DataFrame of predictions vs. ground truth.
    *   Calculate the error status (0 for correct, 1 for incorrect).
    *   Load training metadata to compute class frequencies.
    *   Calculate and print the correlation between prediction error and training class frequency to identify if class imbalance is driving errors.
    *   Print the error rates for the most difficult classes.
5.  **Submission**: Compare the validation F1 score against the threshold (0.6423934219391719). If the score is higher, call `engine.generate_submission` to create the final `submission.csv`.
