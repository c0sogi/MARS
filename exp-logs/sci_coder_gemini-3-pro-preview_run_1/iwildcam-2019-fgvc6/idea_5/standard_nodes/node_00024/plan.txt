To resolve the `torch.OutOfMemoryError`, I will reduce the batch size and implement Automatic Mixed Precision (AMP) training. This addresses the memory limitation by processing fewer samples per step and using 16-bit precision where appropriate, which significantly lowers VRAM usage (Cite debug_lesson_6).

1.  **Modify `library/config.py`**: Reduce `BATCH_SIZE` from 32 to 16.
2.  **Modify `library/engine.py`**:
    *   Import `GradScaler` and `autocast` from `torch.cuda.amp`.
    *   Update `train_one_epoch` to accept a `scaler` argument and perform the forward pass/loss calculation within an `autocast` context.
    *   Replace standard backpropagation with `scaler.scale(loss).backward()` and optimizer stepping with `scaler.step(optimizer)` and `scaler.update()`.
    *   Initialize `GradScaler` in `train_model` and pass it to the training loop.
