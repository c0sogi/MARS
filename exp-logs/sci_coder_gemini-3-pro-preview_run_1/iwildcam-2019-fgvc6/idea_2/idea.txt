Based on the lessons learned from the previous experiments, I propose a new strategy that shifts the handling of class imbalance from the data loader (sampling) to the loss function and augmentation pipeline, while upgrading the model architecture to better handle the domain shift and feature extraction.

# Model
I will replace the lightweight MobileNetV3 with **ConvNeXt-Tiny**. ConvNeXt is a modern convolutional architecture that adopts design choices from Vision Transformers (e.g., larger kernel sizes, fewer activation functions, and layer normalization), offering a more robust feature extraction capability than MobileNet while remaining computationally feasible for the given budget. The model will be initialized with ImageNet-1k weights. The final classification head will be modified to output logits for the 23 target classes.

# Data
To address **Lesson 00002**, I will explicitly **remove the WeightedRandomSampler**. The previous use of oversampling on location-grouped data caused the model to memorize the specific backgrounds of rare classes rather than the animals themselves.
Instead, I will implement **Strong Data Augmentation** to prevent background memorization and force the model to focus on object features:
1.  **RandomResizedCrop**: To force the model to recognize animals from partial views and varying scales.
2.  **CoarseDropout (Cutout)**: Randomly masking out rectangular regions of the image. This acts similarly to CutMix but preserves hard labels, encouraging the model to utilize multiple descriptive features rather than relying on a single distinctive patch (or background artifact).
3.  **Color Jitter & Gaussian Blur**: To simulate the domain shift between the training set (California) and the test set (Idaho) by varying lighting, contrast, and texture sharpness.
The input resolution will remain 224x224, normalized to ImageNet statistics.

# Training
I will address the class imbalance using a **Class-Balanced Focal Loss**, correcting the implementation error identified in **Lesson 00004**.
1.  **Loss Function**: The loss will be formulated as $FL(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$.
    *   **Alpha ($\alpha_t$):** I will calculate class weights based on the inverse effective number of samples or simple inverse frequency ($N / N_{class}$) to down-weight the dominant "empty" class and up-weight rare animals. Crucially, these weights will be applied as an **external multiplier** to the loss term, *not* passed into the cross-entropy function used to compute probabilities, ensuring the gradient is not zeroed out for majority classes (Cite **Lesson 00004**).
    *   **Gamma ($\gamma$):** Set to 2.0 to focus learning on hard-to-classify examples.
2.  **Optimizer**: AdamW with a weight decay of 1e-2.
3.  **Scheduler**: A Cosine Annealing Learning Rate scheduler to smoothly decay the learning rate, which helps the ConvNeXt model converge to a flatter minimum.

# Evaluation
The evaluation process remains similar to the baseline but uses the more robust ConvNeXt model. Images will be resized to 224x224 and normalized. The model will output logits, and the class with the highest logit value (argmax) will be selected as the prediction. No test-time augmentation (TTA) will be used initially to prioritize inference speed, relying on the model's improved generalization capabilities.
