To improve the model's performance, I will implement the following changes based on the lesson learned regarding "Oversampling in Location-Grouped Data":

1.  **Remove WeightedRandomSampler**: I will stop using the `WeightedRandomSampler` which was causing the model to overfit to the backgrounds of the few available locations for rare classes. Instead, I will use a standard random shuffle in the DataLoader. Cite `solution_lesson_node_00002`.
2.  **Implement Focal Loss**: To handle the class imbalance without the drawbacks of oversampling, I will replace `CrossEntropyLoss` with `FocalLoss`. I will also incorporate class weights (inverse frequency) into the loss function to further penalize misclassifications of rare classes. Cite `solution_lesson_node_00002`.
3.  **Enhance Data Augmentation**: I will introduce stronger augmentations (`ColorJitter`, `ShiftScaleRotate`, `CoarseDropout`) to the training pipeline. This helps the model generalize better and focus on animal features rather than background artifacts. Cite `solution_lesson_node_00002`.
4.  **Adjust Hyperparameters**: I will increase `EPOCHS` to 10 and `WEIGHT_DECAY` to 0.01 to allow for better convergence with the new loss and stronger regularization. I will also utilize all 12 vCPUs for data loading.

class FocalLoss(nn.Module):
    """
    Focal Loss for addressing class imbalance.
    Cite solution_lesson_node_00002
    """
    def __init__(self, weight=None, gamma=2.0):
        super(FocalLoss, self).__init__()
        self.weight = weight
        self.gamma = gamma
        self.ce = nn.CrossEntropyLoss(weight=weight, reduction='none')

    def forward(self, inputs, targets):
        logpt = -self.ce(inputs, targets)
        pt = torch.exp(logpt)
        loss = ((1 - pt) ** self.gamma) * -logpt
        return loss.mean()
