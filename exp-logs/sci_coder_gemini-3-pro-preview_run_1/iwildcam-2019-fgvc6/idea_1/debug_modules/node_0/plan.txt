The following script demonstrates the end-to-end usage of the provided library files for the animal classification task.

### Implementation Strategy
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to optimize for a quick demonstration. This includes reducing the number of epochs to 1, the batch size to 8, and the image resolution to 128x128. We also enable `debug` mode to use a tiny subset of the data.
2.  **Component Verification**:
    *   **Data Loaders**: We instantiate the training, validation, and test loaders using `get_loaders`. We fetch a single batch to verify the tensor shapes (Batch Size, Channels, Height, Width) and label consistency.
    *   **Model Architecture**: We initialize the `AnimalClassifier` using `get_model` and perform a forward pass with dummy data to confirm the output shape matches `(Batch Size, Num Classes)`.
3.  **Training Execution**: We initialize the `Trainer` class and call the `fit()` method. This runs a complete training cycle (training step + validation step) and saves the best model checkpoint. We verify that the model file is created.
4.  **Inference Execution**: We call `generate_submission` to load the trained model and generate predictions on the test set. We verify the output CSV file's existence and structure.
5.  **Reproducibility**: We explicitly set random seeds at the start using `Config.set_seed`.
