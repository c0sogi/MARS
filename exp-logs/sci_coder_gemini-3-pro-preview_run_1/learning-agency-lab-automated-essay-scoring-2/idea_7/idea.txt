Based on the progression of empirical findings and the specific lessons learned, I propose the following optimized strategy. This solution implements a **Two-Stage Stacking Ensemble** that integrates the state-of-the-art deep learning backbone with explicit statistical feature engineering.

This approach addresses the "regression to the mean" and outlier detection issues identified in **Cite {solution_lesson_node_00001}** by combining the semantic reasoning of the Large Transformer (**Cite {solution_lesson_node_00020}**) with the strong surface-level signals (e.g., length, vocabulary richness) that correlate highly with essay scores.

# Model
**Architecture**: The solution utilizes a hierarchical **Stacking Ensemble**:
1.  **Level 1 (Semantic Backbone)**: **DeBERTa-v3-Large**.
    *   **Pooling**: **Attention Pooling** (Weighted Layer Pooling) to dynamically weight critical sentences and rhetorical structures **Cite {solution_lesson_node_00020}**.
    *   **Head**: A Linear Regression layer outputting a scalar score.
2.  **Level 2 (Calibration & Meta-Learner)**: A **Gradient Boosted Regressor (LGBM/XGBoost)** or **Ridge Regressor**.
    *   **Input**: This model takes a vector containing:
        *   The scalar prediction from the Level 1 backbone.
        *   **Explicit Meta-Features**: Character count, word count, sentence count, average word length, and unique word count.
    *   **Rationale**: **Cite {solution_lesson_node_00001}** identified a strong correlation (0.65+) between simple length metrics and scores, and noted that neural models often "regress to the mean." The Level 2 model explicitly re-introduces these magnitude signals to calibrate the Transformer's predictions, helping to distinguish high-scoring essays (which tend to be longer and more complex) from average ones.

# Data
**Preprocessing**:
1.  **Domain-Adaptive Corpus**: Construct a combined corpus of `train.csv` and `test.csv` text.
2.  **Meta-Feature Extraction**: For every essay in Train and Test, calculate the statistical features (Length, Word Count, etc.) to be used in Level 2.
3.  **Tokenization**: Use the DeBERTa-v3-Large tokenizer with a max length of **1024 tokens** to capture the full argumentation flow **Cite {solution_lesson_node_00001}**.

# Training
**Procedure**:
This solution employs a **Multi-Stage Pipeline**:

**Stage 1: Domain-Adaptive Pre-training (DAPT)**
*   **Objective**: Train DeBERTa-v3-Large on the combined corpus using **Masked Language Modeling (MLM)**.
*   **Rationale**: This adapts the model to the specific "lexical signal" and student writing style **Cite {solution_lesson_node_00001}** before supervised learning.

**Stage 2: Cross-Validated Fine-Tuning (Level 1)**
*   **Strategy**: Train the adapted backbone using **5-Fold Stratified Cross-Validation**.
*   **Loss Function**: **Mean Squared Error (MSE)**, strictly aligning with the QWK metric **Cite {solution_lesson_node_00012}**.
*   **Optimization**:
    *   **Layer-wise Learning Rate Decay (LLRD)**: Apply decaying learning rates to stabilize the Large backbone **Cite {solution_lesson_node_00020}**.
    *   **Adversarial Weight Perturbation (AWP)**: Inject noise during training to flatten the loss landscape and improve robustness against outliers.
*   **Output**: Generate **Out-of-Fold (OOF)** predictions for the entire training set and average predictions for the test set.

**Stage 3: Stacking (Level 2)**
*   **Strategy**: Train the Meta-Learner (LGBM/Ridge) on the training set.
    *   **Features**: `[OOF_Prediction, Meta_Features]`.
    *   **Target**: True Score.
*   **Rationale**: This allows the model to learn a correction function, using the explicit length/complexity features to adjust the semantic prediction, thereby mitigating the "regression to the mean" **Cite {solution_lesson_node_00001}**.

# Evaluation
**Inference Strategy**:
1.  **Level 1**: Pass test essays through the 5 DeBERTa-Large folds and average the scalar outputs.
2.  **Level 2**: Concatenate the averaged Level 1 prediction with the test set's Meta-Features. Pass this vector through the trained Meta-Learner.
3.  **Post-Processing**: Clip the final output to [1, 6] and round to the nearest integer **Cite {solution_lesson_node_00001}**.
