Implementation Strategy:
1.  **Environment Setup**: Initialize the environment by setting random seeds for reproducibility and suppressing verbose logging from the `transformers` library.
2.  **Configuration Override**: Modify the `Config` class attributes to enable debug mode (limiting the dataset to 50 samples), reduce the number of epochs to 1, and set smaller batch sizes. This ensures the script runs quickly within the constraints.
3.  **Data Preparation**: Initialize the `AutoTokenizer` and create training, validation, and test DataLoaders using `get_dataloaders`. We disable cache loading to ensure the DataLoaders read directly from the metadata CSVs. We verify the structure of a batch to ensure data is loading correctly.
4.  **Model Initialization**: Instantiate the `EssayRegressor` model and move it to the appropriate device (GPU or CPU). Perform a dummy forward pass with a batch of data to verify the model's output shape.
5.  **Training**: Configure the `AdamW` optimizer and a linear scheduler. Execute the `train_model` function to fine-tune the model on the debug subset.
6.  **Metric Verification**: Manually test the `compute_qwk` function with a known set of ground truth and predicted values to confirm the metric calculation logic is correct.
7.  **Inference & Submission**: Use the trained model to generate predictions on the test set via `generate_submission`. Finally, verify that the submission CSV exists, follows the correct schema, and contains valid scores.
