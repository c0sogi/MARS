To establish a highly efficient baseline, I propose a **Deep Averaging Network (DAN) Regressor**. This approach offers a middle ground between the statistical rigidity of linear models and the computational expense of recurrent or attention-based deep learning models.

### Model
The architecture is a feed-forward neural network designed to capture semantic compositionality without relying on complex sequence processing mechanisms like recurrence (RNNs) or self-attention (Transformers).
1.  **Embedding Layer**: The model begins with a trainable embedding layer that maps each token in the input sequence to a dense vector representation. Unlike Model 3 (which uses static FastText) or Model 1 (Contextual DeBERTa), this layer learns task-specific dense representations from scratch or fine-tunes lightweight pre-trained embeddings.
2.  **Global Average Pooling**: The variable-length sequence of embedding vectors is aggregated into a single fixed-size vector by computing the element-wise mean (average) of all word embeddings in the document. This operation effectively captures the "gist" of the essay by summarizing its vocabulary content while discarding word order and syntactic structure, making it extremely fast.
3.  **Non-Linear Regressor**: The averaged vector is fed into a shallow Multi-Layer Perceptron (MLP). This consists of one or two dense hidden layers with ReLU activation and Dropout for regularization, followed by a final single-neuron output layer with linear activation to predict the continuous score.

### Data
*   **Preprocessing**: The raw text will be lowercased and tokenized using a simple whitespace tokenizer. To maintain efficiency and focus on signal, the vocabulary will be built considering only the top $N$ most frequent words (e.g., top 20,000), treating less frequent words as "unknown" tokens. This reduces the embedding matrix size significantly.
*   **Input Formatting**: Essays will be converted into sequences of integer token IDs. Since the aggregation method is averaging, padding is not strictly necessary for the computation if using "scatter add/mean" operations, but standard fixed-length padding can be used for batched processing efficiency.

### Training
*   **Objective**: The problem will be treated as a regression task. The model will be trained to minimize the **Mean Squared Error (MSE)** loss between the predicted continuous score and the actual integer score. MSE is differentiable and generally correlates well with the Quadratic Weighted Kappa metric.
*   **Optimization**: An **Adam** or **AdamW** optimizer will be used to update the weights.
*   **Strategy**: Training will proceed with a relatively large batch size to leverage the lightweight nature of the model. Early stopping will be implemented by monitoring the validation loss to prevent overfitting.

### Evaluation
*   **Inference**: For each essay in the test set, the model will output a continuous scalar value.
*   **Post-processing**: To conform to the submission format, these continuous predictions will be clipped to the valid score range [1, 6] and then rounded to the nearest integer.
