Based on the empirical evidence and lessons learned, I propose the following optimized strategy. This solution implements a **Multi-Stage Domain-Adapted Stacked Ensemble**.

This approach synthesizes the state-of-the-art performance of the Large Transformer backbone (**Cite {solution_lesson_node_00020}**) with the bias-correction capabilities of statistical stacking (**Cite {solution_lesson_node_00027}**). Critically, it addresses the failure mode of previous ensemble attempts by allocating the full 24-hour computational budget to train on **100% of the data**, ensuring the base models are fully converged.

# Model
**Architecture**: The solution utilizes a hierarchical architecture:
1.  **Level 1 (Semantic Backbone)**: **DeBERTa-v3-Large**.
    *   **Pooling**: **Attention Pooling** (Weighted Layer Pooling). This allows the model to dynamically weight critical sentences and rhetorical structures, outperforming standard mean pooling **Cite {solution_lesson_node_00020}**.
    *   **Head**: A Linear Regression layer outputting a scalar score.
2.  **Level 2 (Calibration & Meta-Learner)**: A **Ridge Regressor** or **LightGBM**.
    *   **Input**: A vector concatenating the scalar prediction from Level 1 with **Explicit Meta-Features** (Character count, word count, sentence count, unique word count).
    *   **Rationale**: **Cite {solution_lesson_node_00001}** identified that neural models often "regress to the mean" and miss length-based signals. **Cite {solution_lesson_node_00027}** proved that a meta-learner can correct this bias (reducing length-error correlation), but the previous attempt failed because the base model was starved of data. This architecture retains the correction mechanism while relying on a robust base.

# Data
**Preprocessing**:
1.  **Domain-Adaptive Corpus**: Construct a combined corpus of `train.csv` and `test.csv` text for unsupervised pre-training.
2.  **Meta-Feature Extraction**: Calculate statistical features (Length, Word Count, etc.) for all samples to be used in Level 2.
3.  **Tokenization**: Use the DeBERTa-v3-Large tokenizer with a max length of **1024 tokens** to capture the full argumentation flow **Cite {solution_lesson_node_00001}**.
4.  **Data Volume**: We will strictly utilize **100% of the training data**. Previous experiments failed when subsampling to save time **Cite {solution_lesson_node_00019}**, **Cite {solution_lesson_node_00027}**.

# Training
**Procedure**:
This solution employs a **Three-Stage Pipeline** designed to fit within the 24-hour limit (estimated runtime ~14 hours):

**Stage 1: Domain-Adaptive Pre-training (DAPT)**
*   **Objective**: Train DeBERTa-v3-Large on the combined corpus using **Masked Language Modeling (MLM)**.
*   **Rationale**: This adapts the model to the specific "lexical signal" and student writing style before supervised learning.

**Stage 2: Cross-Validated Fine-Tuning (Level 1)**
*   **Strategy**: Fine-tune the adapted backbone using **5-Fold Stratified Cross-Validation**.
*   **Loss Function**: **Mean Squared Error (MSE)**. We retain MSE as it mathematically aligns with the Quadratic Weighted Kappa metric, avoiding the sub-optimal penalty structure of Ordinal Classification **Cite {solution_lesson_node_00012}**.
*   **Optimization**: Implement **Layer-wise Learning Rate Decay (LLRD)**. This is critical for stabilizing the Large backbone and preventing catastrophic forgetting of the pre-trained features **Cite {solution_lesson_node_00020}**.
*   **Output**: Generate Out-of-Fold (OOF) predictions for the training set.

**Stage 3: Stacking (Level 2)**
*   **Strategy**: Train the Meta-Learner on the OOF predictions + Meta-Features.
*   **Target**: True Score.

# Evaluation
**Inference Strategy**:
1.  **Level 1**: Pass test essays through the 5 DeBERTa-Large folds and average the scalar outputs. This reduces stochastic variance **Cite {solution_lesson_node_00010}**.
2.  **Level 2**: Concatenate the averaged Level 1 prediction with the test set's Meta-Features. Pass this vector through the trained Meta-Learner.
3.  **Post-Processing**: Clip the final output to [1, 6] and round to the nearest integer.
