The `torch.OutOfMemoryError` indicates that the DeBERTa-v3-large model, combined with the current batch sizes (4 for training) and sequence length (1024), exceeds the available 16GB VRAM. To resolve this, I will implement three key changes:
1.  **Reduce Batch Sizes**: Lower `mlm_batch_size`, `train_batch_size`, and `valid_batch_size` in `library/config.py` and `runfile.py` to fit within memory constraints (Cite debug_lesson_2).
2.  **Enable Mixed Precision (AMP)**: Update the `train_mlm` function in `library/engine.py` to use `torch.cuda.amp.autocast` and `GradScaler`, reducing memory usage during the MLM stage.
3.  **Configure Gradient Checkpointing**: Explicitly enable gradient checkpointing with `use_reentrant=False` in both `library/engine.py` (for MLM) and `library/model.py` (for SFT) to save memory without conflicting with AMP (Cite debug_lesson_5).
