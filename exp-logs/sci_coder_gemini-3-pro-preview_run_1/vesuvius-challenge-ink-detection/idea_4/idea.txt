Based on the accumulated lessons, I propose the **Parallel-Scale Dilated CNN**. This solution introduces a multi-branch topology to resolve the conflict identified in Lesson 00009 between preserving fine texture (requiring high resolution) and capturing structural continuity (requiring large receptive fields), without the downsampling artifacts of U-Nets.

# Model
The architecture is a fully convolutional network that maintains the original spatial resolution throughout (no pooling or strided convolutions).

1.  **Depth-to-Channel Projection (Input Stem):**
    The input tensor of shape `(Batch, 65, H, W)` is passed through a **1x1 Convolution** to compress the 65 depth slices into a dense feature map (e.g., 64 channels).
    *   **Normalization:** This layer is immediately followed by **Instance Normalization**. This decouples the model from global intensity shifts in the x-ray density, forcing it to learn relative structural features (Cite solution_lesson_node_00002).

2.  **Parallel-Scale Dilated Backbone (Structural Innovation):**
    Instead of a single sequential stack (which forces a trade-off between local and global processing), the features are split into **three parallel branches**, each processing the data with distinct dilation rates to capture features at different scales simultaneously:
    *   **Branch A (Texture Stream):** A stack of 3 Residual Blocks with **Dilation = 1**. This stream focuses on high-frequency details and fine ink texture, ensuring no resolution or sharpness is lost (Cite solution_lesson_node_00009).
    *   **Branch B (Stroke Stream):** A stack of 3 Residual Blocks with **Dilation = 2 and 4**. This stream captures the continuity of medium-sized ink strokes.
    *   **Branch C (Context Stream):** A stack of 3 Residual Blocks with **Dilation = 4 and 8**. This stream maximizes the receptive field to understand global shapes and reject noise, implementing the "Exponentially Increasing Dilation" strategy (Cite solution_lesson_node_00003).
    *   **Normalization:** All convolutional layers within these branches will use **Batch Normalization** to preserve the global statistics of the ink texture, avoiding the signal suppression caused by full Instance Norm (Cite solution_lesson_node_00005).

3.  **Fusion & Classification:**
    The outputs of the three branches are concatenated along the channel dimension. A **1x1 Convolution** fuses these multi-scale features, followed by a final **1x1 Convolution** and **Sigmoid** activation to generate the pixel-wise probability map.

# Data
1.  **Preprocessing:**
    Using `metadata/train.csv`, load the 65 `.tif` slices for each patch and stack them to form a `(65, H, W)` input volume. Normalize pixel values to `[0, 1]`.
2.  **Batch Strategy:**
    Strictly maintain a **Batch Size of 32**. Even though the parallel architecture adds width, we will control the channel count (e.g., 16 channels per branch) to fit this budget. This ensures we maximize the number of gradient updates (iterations) available for the small dataset, preventing the underfitting observed with larger batches (Cite solution_lesson_node_00004).

# Training
1.  **Loss Function:**
    Use **BCEWithLogitsLoss** with a `pos_weight` of 2.0 to address the class imbalance (approx. 13% ink).
2.  **Optimization:**
    Train using the **Adam** optimizer for 15-20 epochs. The parallel structure allows gradients to flow directly to the specific scale (texture vs. context) that needs adjustment, likely accelerating convergence compared to a deep sequential stack.

# Evaluation
1.  **Inference:**
    Generate probability maps for the test set using a sliding window approach with the trained model.
2.  **Threshold Calibration:**
    Do not use a default threshold of 0.5. After generating predictions on the **validation set**, perform a search to find the probability threshold that maximizes the **F0.5 score**. Apply this calibrated threshold to the test predictions to generate the final binary masks (Cite solution_lesson_node_00001).
