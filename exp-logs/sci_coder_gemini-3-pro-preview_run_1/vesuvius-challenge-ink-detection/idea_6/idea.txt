Based on the lessons learned from previous iterations, I propose the **Feature-Fused Dilated Convolutional Network (FFDC-Net)**. This solution addresses the critical trade-off between capturing global structural context and preserving fine local texture—without the computational instability of parallel branches or the resolution loss of downsampling.

# Model
The architecture is a fully convolutional network that maintains full spatial resolution (1x) throughout, employing a "Sequential-with-Fusion" topology to efficiently combine multi-scale features.

1.  **Volumetric Projection Stem:**
    The input tensor `(Batch, 65, H, W)` is passed through a **1x1 Convolution** to project the depth slices into a dense feature map (e.g., 64 channels).
    *   **Normalization:** This layer is immediately followed by **Instance Normalization**. This ensures the model is invariant to global X-ray intensity shifts, decoupling the ink signal from the background density (Cite solution_lesson_node_00002).

2.  **Texture Preservation Block:**
    The projected features pass through a sequence of 2 Residual Blocks with a fixed **Dilation Rate of 1**.
    *   **Purpose:** These layers focus exclusively on high-frequency details and sharp edges.
    *   **Normalization:** Unlike the stem, these layers utilize **Batch Normalization** to preserve the global statistics of the ink texture, ensuring consistent decision boundaries (Cite solution_lesson_node_00005).
    *   **Output:** The output of this block is stored as `Features_Texture`.

3.  **Context Aggregation Block:**
    The `Features_Texture` are then fed into a deeper stack of 4 Residual Blocks with **Exponentially Increasing Dilation rates (2, 4, 8, 16)**.
    *   **Purpose:** This expands the receptive field to capture the continuity of ink strokes and reject noise, without using pooling or downsampling (Cite solution_lesson_node_00003, solution_lesson_node_00009).
    *   **Output:** The output of this block is `Features_Context`.

4.  **Multi-Scale Fusion Head (Structural Innovation):**
    Instead of relying solely on the final highly abstract features (as in the previous sequential model), we **concatenate** `Features_Texture` and `Features_Context` along the channel dimension.
    *   **Mechanism:** This skip connection re-injects the fine-grained texture information directly into the classifier, allowing the model to utilize both the local edge definition and the global structural context simultaneously.
    *   **Classification:** A final **1x1 Convolution** reduces the fused features to a single channel, followed by a Sigmoid activation.

# Data
1.  **Preprocessing:**
    Load the 65 z-slices for each patch and stack them to form a `(65, H, W)` input volume. Normalize pixel values to `[0, 1]`.
2.  **Batch Strategy:**
    We will strictly maintain a **Batch Size of 32**. By avoiding the heavy parameter count of fully parallel backbones (Idea 5), this efficient architecture fits within GPU memory at a standard batch size. This ensures we maximize the number of gradient updates (iterations) available for the small dataset, preventing the underfitting observed with larger batches or the instability of tiny batches (Cite solution_lesson_node_00004, solution_lesson_node_00013).

# Training
1.  **Loss Function:**
    Use **BCEWithLogitsLoss** with a `pos_weight` of 2.0 to address the class imbalance (approx. 13% ink).
2.  **Optimization:**
    Train using the **Adam** optimizer for 15-20 epochs. The fusion architecture facilitates gradient flow to both the texture and context layers, ensuring stable convergence.

# Evaluation
1.  **Inference:**
    Generate probability maps for the test set using a sliding window approach.
2.  **Threshold Calibration:**
    We will not use a default threshold of 0.5. After generating predictions on the **validation set**, we will perform a post-hoc search to find the probability threshold that maximizes the **F0.5 score**. This calibrated threshold will then be applied to the test predictions to generate the final submission (Cite solution_lesson_node_00001).
