Implementation Strategy:
1.  **Setup**: Initialize the environment with fixed random seeds for reproducibility using the provided utility.
2.  **Data Loading**: Utilize `get_dataloaders` with `load_cached_data=True` to efficiently load the preprocessed training, validation, and test sets.
3.  **Model Training**: Execute `train_model` to train the `DepthProjectionCNN`. I will use a reasonable epoch limit (10) and patience (3) to ensure a fast baseline execution that fits within the time constraints.
4.  **Threshold Optimization**: Use `optimize_threshold` to find the probability cutoff that maximizes the F0.5 score on the validation set.
5.  **Validation & Analysis**: Manually iterate through the validation set to:
    *   Compute the precise `Final Validation Metric` using the optimized threshold.
    *   Extract input features (mean and standard deviation of intensity) and calculate prediction errors (Mean Absolute Error) to perform the required failure analysis (correlation).
6.  **Inference**: Run `predict_fragment` on the test set to generate reconstructed probability maps from the sliding-window predictions.
7.  **Submission**: Call `generate_submission_file` to apply the threshold, perform Run-Length Encoding, and save the predictions to `./submission/submission.csv`.
