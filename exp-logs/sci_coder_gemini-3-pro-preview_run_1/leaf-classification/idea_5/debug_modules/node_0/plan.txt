This script demonstrates the end-to-end usage of the provided library modules for the plant species identification task. It covers data loading, preprocessing, model training with the Fisher-Gaussian Process Ensemble, evaluation, and submission file generation.

**Strategy:**
1.  **Setup**: Initialize the environment and set random seeds for reproducibility.
2.  **Data Loading**: Use `library.data_loader` to load the full training, validation, and test sets. The dataset size (~700 training samples) is small enough to process fully without subsampling, ensuring all 99 classes are present for valid LDA dimensionality reduction.
3.  **Preprocessing**: Apply the `library.preprocessor` pipeline (Yeo-Johnson transform + Standardization) to normalize the feature distributions, which is crucial for the Linear Discriminant Analysis backbone.
4.  **Modeling**: Instantiate and train the `FisherGaussianEnsemble` from `library.model`. This hybrid model projects features into a Fisher subspace before applying a Gaussian Process Classifier.
5.  **Validation**: Verify the model's performance by calculating multi-class log loss on the validation set using `library.evaluation`.
6.  **Submission**: Generate predictions for the test set and create a formatted submission CSV using `library.evaluation`.
7.  **Verification**: Perform assertions at each step to ensure data shapes, model attributes, and output files are correct.
