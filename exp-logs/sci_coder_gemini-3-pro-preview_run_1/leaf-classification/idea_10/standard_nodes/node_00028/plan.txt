Implementation Strategy:
1.  **Environment Setup**: Import necessary standard libraries (`os`, `numpy`, `pandas`, `sklearn`) and the provided solution modules (`library.config`, `library.dataset`, `library.transforms`, `library.classifier`). Define a custom correlation function to avoid potential dependency issues with `scipy`.
2.  **Data Loading**: Utilize `dataset.load_dataset(load_cached_data=True)` to efficiently load the training, validation, and test sets, including the geometric feature augmentation defined in the library.
3.  **Preprocessing**: Implement a caching mechanism for the transformed features (PowerTransform + Scaling). Check if `.npy` files exist in the working directory; if not, fit the pipeline from `library.transforms` on the training data, transform all splits, and save them to disk.
4.  **Model Training**: Instantiate the `LeafLDA` classifier from `library.classifier`. Execute the `fit_transductive` method to train the supervisor model, generate pseudo-labels for high-confidence test samples, and retrain the student model.
5.  **Validation & Metric**: Perform inference on the validation set. Clip probabilities to the range $[10^{-15}, 1-10^{-15}]$ to prevent log-loss extremes. Calculate the multi-class log loss using `sklearn.metrics.log_loss` and print it in the strict format `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Calculate the per-sample error (negative log-likelihood of the true class) for the validation set. Compute the Pearson correlation between this error vector and each feature column. Print the top 5 features most strongly correlated with model error to identify failure modes.
7.  **Submission**: Compare the validation metric against the strict threshold ($1.47 \times 10^{-8}$). If the model performs sufficiently well, generate predictions for the test set, format the dataframe according to `sample_submission.csv` (ensuring correct column order and zero-filling missing classes), clip the probabilities, and save the result to `./submission/submission.csv`.
