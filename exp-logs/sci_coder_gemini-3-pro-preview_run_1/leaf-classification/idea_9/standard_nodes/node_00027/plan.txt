The implementation strategy involves orchestrating the Fisher-Embedded Bayesian Gaussian Process (FE-BGP) pipeline using the provided library modules. 

1.  **Setup and Initialization**: We will import the necessary modules (`config`, `data_loader`, `fe_bgp_model`) and set random seeds for reproducibility.
2.  **Data Loading**: We leverage `data_loader.load_data(load_cached_data=True)` to efficiently load the training, validation, and test sets.
3.  **Model Training (Validation)**: We instantiate the `FisherEmbeddedBGP` class and fit it on the training set (`X_train`, `y_train`).
4.  **Validation & Metric Calculation**: We generate probability predictions on the validation set (`X_val`) and compute the multi-class log loss. This metric is printed exactly as required: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: We calculate the log loss contribution for each validation sample. Then, we compute the Pearson correlation between these error magnitudes and each of the 192 input features to identify which features correlate most with model error.
6.  **Submission Logic**: We check if the validation metric is strictly lower than the specified threshold (`1.470544781593644e-08`).
    *   If the condition is met, we retrain the model on the combined dataset (`X_train` + `X_val`) to maximize signal, generate predictions for `X_test`, and save the `submission.csv`.
    *   If not, we skip submission generation to comply with the strict requirement.
