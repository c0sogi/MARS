My optimization strategy focuses on improving numerical stability and reducing floating-point noise in the high-precision regime of the Linear Discriminant Analysis (LDA) pipeline.

1.  **Use OAS Precision Matrix Directly**: In `library/model.py`, I will replace the manual Cholesky decomposition solver with the pre-computed `precision_` attribute from the `OAS` estimator. The Scikit-Learn implementation of OAS uses an SVD-based pseudo-inverse, which is numerically more robust for ill-conditioned covariance matrices than solving the linear system manually (Cite solution_lesson_node_00062).
2.  **Remove Redundant Normalization**: In `library/utils.py`, I will remove the redundant row-wise normalization (`probs / sum(probs)`) in the log loss computation. Since the `softmax` function already guarantees that probabilities sum to 1, this extra step introduces unnecessary floating-point noise that degrades the metric when errors are extremely small (Cite solution_lesson_node_00085).
3.  **Update Working Directory**: I will update the working directory in `library/config.py` to ensure a clean execution environment.
