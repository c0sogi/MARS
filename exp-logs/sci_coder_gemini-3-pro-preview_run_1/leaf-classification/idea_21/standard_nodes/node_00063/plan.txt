Implementation Strategy:
The implementation orchestrates the high-precision classification workflow defined by the "Geometrically-Consistent Linearized OAS Discriminant" strategy.
1.  **Setup & Data Loading**: Initialize the environment with a fixed seed and load the preprocessed datasets (Train, Val, Test) using `get_preprocessed_data`. This ensures the data is strictly `float64`, Yeo-Johnson transformed, and Standard Scaled.
2.  **Model Training**: Instantiate and fit the `LinearizedOASClassifier` on the training set. This model uses a deterministic closed-form solution (OAS covariance estimation + Linear Discriminant weights), ensuring fast and stable training without iterative epochs.
3.  **Validation & Metric Calculation**: Predict probabilities on the validation set. Compute the Multi-class Log Loss, strictly adhering to the competition's clipping ($10^{-15}$) and normalization rules.
4.  **Failure Analysis**: Analyze validation errors by calculating the per-sample log loss and correlating it with input features. This identifies which morphological features (margin, shape, texture) are most associated with prediction uncertainty.
5.  **Submission Generation**: Compare the final validation metric against the strict threshold (`1.2136771218566717e-09`). If the model performance is sufficient (metric is lower than threshold), generate predictions for the test set and save the submission file using the provided `save_submission` utility.
