Implementation strategy:
1.  **Environment Setup**: Import standard libraries and the provided modules from the `library` package. Set the random seed using `library.utils.set_seed`.
2.  **Utility Verification**: Create a function `demonstrate_utils` to validate `normalize_probabilities`, `clip_probabilities`, and `calculate_log_loss`. We will use assertions to ensure mathematical correctness (e.g., row sums equal to 1, values within clipped ranges).
3.  **Feature Extraction**: Create a function `demonstrate_feature_extraction`. We will load a small subset (5 rows) of the training metadata and run the `GeometricFeatureExtractor` on it. This verifies the OpenCV-based extraction logic without processing the entire dataset, adhering to the speed requirement. We will assert the output shape and data integrity.
4.  **Full Pipeline Execution**: Create a function `demonstrate_preprocessing_and_model` to run the core ML pipeline.
    *   **Preprocessing**: Instantiate `SanitizedGroupPreprocessor` and run `process_and_cache`. This handles data loading, geometric feature extraction (for the full set), variance thresholding, Yeo-Johnson transformation, and scaling. We will validate the structure and shapes of the returned data dictionary.
    *   **Modeling**: Instantiate `FactorizedOASLDA`, fit it on the processed training data, and predict on the validation set.
    *   **Evaluation**: Calculate the log loss using the utility function and assert that the model performs better than random guessing (log loss < 4.6 for 99 classes).
    *   **Test Inference**: Generate predictions for the test set to ensure the end-to-end flow works.
5.  **Execution**: Run these functions sequentially within the `__main__` block, catching and reporting any errors.
