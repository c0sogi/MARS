The implementation strategy follows the provided requirements strictly. It orchestrates the pipeline by leveraging the pre-built library components for data processing and modeling.

1.  **Setup**: Initializes the environment and seeds using `library.utils`.
2.  **Data Pipeline**: Instantiates `SanitizedGroupPreprocessor` from `library.preprocessing` to load and process data (utilizing caching). It retrieves training, validation, and test sets along with metadata.
3.  **Model Training**: Initializes `FactorizedOASLDA` from `library.model` and fits it to the training data. This model implements the "Sanitized Factorized High-Precision OAS Ensemble" described in the idea.
4.  **Validation**: Performs inference on the validation set. Calculates the Multi-class Log Loss using `library.utils.calculate_log_loss` and prints it in the required format.
5.  **Failure Analysis**: Computes the log loss contribution of each validation sample. Flattens the validation feature dictionary into a matrix and calculates the Pearson correlation between each feature and the error magnitude. Prints the top 5 features most associated with model error.
6.  **Submission**: Performs inference on the test set. Checks the validation metric against the strict threshold (`3.058881515561734e-14`). If the condition is met, it formats the predictions and saves `submission.csv` to the submission directory.
