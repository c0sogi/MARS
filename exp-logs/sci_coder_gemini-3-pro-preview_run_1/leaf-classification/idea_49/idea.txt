Based on the comprehensive analysis of the accumulated lessons—specifically the critical distinction between **Integral** and **Boundary-Fitting** features [Cite solution_lesson_node_00137], the necessity of **Absolute Geometry** [Cite solution_lesson_node_00118], and the catastrophic impact of **Polarity Inversion** [Cite solution_lesson_node_00145]—I propose the **Integral-Inertial High-Precision OAS Discriminant**.

This strategy introduces **Moment-Based Inertial Profiling** as a structural innovation. Previous geometric augmentation attempts relied on boundary-fitting algorithms (like `cv2.fitEllipse` or `cv2.minAreaRect`) which are sensitive to pixelation noise and contour approximation artifacts [Cite solution_lesson_node_00149]. Instead, we will derive the leaf's geometric properties (Axes, Eccentricity, Orientation) directly from the **Image Moments** (Integration of pixel intensities). This provides a mathematically robust, noise-resistant description of the object's "Inertia Tensor," which is fused with the tabular data and processed through the rigorous **High-Precision Pipeline** to break the metric floor.

# Model
The architecture is a **Custom Linear Discriminant** classifier designed for exact analytical inference using `float64` precision.

1.  **OAS Covariance Backbone (Retention):** We retain the **Oracle Approximating Shrinkage (OAS)** estimator. As established in Lesson 00047, OAS minimizes the Mean Squared Error of the covariance estimate for Gaussianized data.
2.  **SVD-Based Precision Access (Retention):** We explicitly use the library-provided `precision_` attribute (SVD-based pseudo-inverse). Lessons 00062 and 00111 demonstrated that this implementation handles ill-conditioning more robustly than manual linear solvers or Cholesky decompositions in this high-dimensional regime.
3.  **Linearized Inference (Retention):** We utilize the **Linear Formulation** to pre-compile decision boundaries ($W, b$), algebraically cancelling the unstable quadratic term found in distance-based formulations [Cite solution_lesson_node_00055].

# Data
1.  **Integral-Inertial Geometric Fusion (Innovation):**
    *   **Tabular:** Use the 192 pre-extracted features (`margin`, `shape`, `texture`).
    *   **Polarity Correction:** Invert images using `cv2.THRESH_BINARY_INV` to ensure leaves are foreground [Cite solution_lesson_node_00145].
    *   **Integral Primitives:** Compute raw **Image Moments** ($M_{ij}$) on the binary mask.
    *   **Inertial Descriptors:** Derive geometry from the **Covariance Matrix of Moments** (Inertia Tensor), avoiding boundary fitting [Cite solution_lesson_node_00137]:
        *   **Absolute Scale:** `Area` ($M_{00}$).
        *   **Inertial Axes:** Derive `Inertial_Major_Axis` and `Inertial_Minor_Axis` from the eigenvalues of the central moments ($\mu_{20}, \mu_{02}, \mu_{11}$). These represent the true axes of the mass distribution, robust to edge noise.
        *   **Inertial Shape:** `Eccentricity` derived from the eigenvalue ratio.
    *   **Macro-Geometry:**
        *   **Scanner Frame:** `AABB_Aspect_Ratio`, `AABB_Extent` (Area/AABB_Area). Captures orientation signal [Cite solution_lesson_node_00120].
        *   **Boundary Integrals:** Use `cv2.CHAIN_APPROX_NONE` [Cite solution_lesson_node_00149] to compute `Perimeter`, `Convex_Perimeter`.
        *   **Topology:** `Solidity` (Area/ConvexArea), `Convexity` (ConvexPerimeter/Perimeter).
    *   **Exclusion:** We explicitly reject `Equivalent_Diameter` (Redundant with Area [Cite solution_lesson_node_00150]), `Roundness` (Redundant with Area/Perimeter), `Compactness`, `Hu_Moments` (Noise [Cite solution_lesson_node_00140]), and `fitEllipse` outputs.
2.  **Configuration-Hashed Caching (Retention):** We implement hashing of the feature configuration to prevent stale data loading [Cite solution_lesson_node_00116].
3.  **Deterministic Schema:** We enforce **Alphanumeric Column Ordering** on the combined feature set to ensure deterministic memory layout and floating-point associativity [Cite solution_lesson_node_00094].
4.  **Inductive Preprocessing Pipeline:**
    *   **High-Precision Loading:** Data is loaded and processed in **`float64`** [Cite solution_lesson_node_00046].
    *   **Transformation:** Apply **Yeo-Johnson Power Transformation** (`standardize=False`) followed by **Standard Scaling**.
    *   *Crucial:* This transformation is applied to *all* features to stabilize variance [Cite solution_lesson_node_00028].
    *   **Inductive Fit:** Fitted **only on the Training set** [Cite solution_lesson_node_00041].

# Training
1.  **Parameter Estimation:**
    *   Compute empirical class means $\mu_k$ using the **Arithmetic Mean** [Cite solution_lesson_node_00066].
    *   Compute empirical priors $\pi_k$ [Cite solution_lesson_node_00033].
    *   Compute residuals $R = X - \mu_y$.
    *   Estimate covariance $\Sigma$ using `OAS(assume_centered=True).fit(R)` to ensure geometric consistency [Cite solution_lesson_node_00061].
2.  **Weight Derivation:**
    *   Extract the precision matrix $P = \text{estimator.precision\_}$.
    *   Compute weights $W_k = P \mu_k$.
    *   Compute bias $b_k = -0.5 (W_k \cdot \mu_k) + \log(\pi_k)$.
    *   *Constraint:* All operations must be performed in **`float64`**.

# Evaluation
1.  **Inference:**
    *   Extract the Integral-Inertial features from test images and merge with test tabular data.
    *   Preprocess using the fixed `float64` pipeline.
    *   **Linear Scoring:** Compute logits $Z = X_{test} W^T + b$ in **`float64`**.
    *   **Probability:** Apply `scipy.special.softmax` to $Z$ in **`float64`** [Cite solution_lesson_node_00085].
    *   **Precision:** Ensure no intermediate downcasting occurs, avoiding the $10^{-7}$ metric floor [Cite solution_lesson_node_00057].
