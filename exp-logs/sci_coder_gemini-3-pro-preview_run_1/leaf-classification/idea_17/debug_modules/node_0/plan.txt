### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed using `seed_everything` to ensure reproducibility.
2.  **Data Loading**: Use `data_manager.get_data` to load the raw training, validation, and test datasets. Validate that the data types are `float64` (raw precision) and that the class names match the expected 99 species.
3.  **Preprocessing Pipeline**:
    *   Demonstrate the `PrecisionPipeline` via `preprocessor.get_preprocessed_data`.
    *   **Validation**: Assert that the transformed data is cast to `float32` (quantization) and that the training features are standardized (mean $\approx$ 0, std $\approx$ 1).
4.  **Model Training (Transductive OAS)**:
    *   Instantiate the `TransductiveOAS` classifier.
    *   Fit the model using the training data and the unlabeled test data (for transductive covariance refinement).
    *   **Validation**: Verify that the internal model parameters (`means_`, `precision_`) are quantized to `float32` after fitting, ensuring precision consistency.
5.  **Evaluation**:
    *   Generate probability predictions on the validation set.
    *   Compute the Multi-class Log Loss using `utils.log_loss_metric`.
    *   **Validation**: Assert the loss is a valid non-negative number.
6.  **Submission Generation**:
    *   Generate predictions for the test set.
    *   Format and save the submission file using `utils.format_submission`.
    *   **Validation**: Check that the output file exists and has the correct dimensions.
