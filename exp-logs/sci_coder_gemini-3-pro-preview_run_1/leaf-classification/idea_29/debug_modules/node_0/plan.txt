### Implementation Strategy

2.  **Data Processing Verification**:
    *   Instantiate the `LeafDataProcessor`.

    *   Validate the `PreprocessingPipeline` separately on dummy data to ensure it handles `float64` conversion and transformation correctly.
3.  **Model Verification**:
    *   Instantiate the `CholeskyOASClassifier`.
    *   Fit the model on the processed training data.
    *   Generate probability predictions on the validation set.
    *   Assert that predictions have the correct shape `(n_samples, n_classes)` and that probabilities for each sample sum to approximately 1.0.
4.  **Evaluation Verification**:
    *   Calculate the multi-class log loss using `compute_log_loss` and verify it returns a valid float.
