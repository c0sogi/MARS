The following script demonstrates the end-to-end usage of the provided library modules for the leaf classification task. It performs data loading, feature preprocessing (Yeo-Johnson transformation + Standardization), model training using a Stratified Bagged LDA ensemble, evaluation using multi-class log loss, and final submission generation.

The script includes strict assertions to verify data shapes, statistical properties of transformed features, probability constraints, and output file formats, ensuring the logic is correct and robust.
