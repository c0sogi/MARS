The following script demonstrates the usage of the provided library modules (`config`, `utils`, `features`, `data`, `model`) to perform leaf classification.

**Implementation Strategy:**
1.  **Setup & Verification**: Initialize the environment using `utils.set_seed` and verify the existence of metadata files using `utils.load_metadata`.
2.  **Feature Extraction**: Demonstrate `features.process_dataset` with a small `debug_limit` to parse images and extract geometric features (e.g., area, geodesic length) alongside the provided tabular features, ensuring the pipeline handles image I/O correctly.
3.  **Data Preparation**: Instantiate `data.LeafDataManager` and run `prepare_data` with `load_cached_data=False` and a `debug_limit`. This validates the sanitization (VarianceThreshold), transformation (Yeo-Johnson), and scaling (StandardScaler) pipeline on raw data.
4.  **Model Training & Inference**: Use the preprocessed data to train the `model.SanitizedOASDiscriminant`. We verify the model's `fit` and `predict_proba` methods, asserting that output probabilities are valid (sum to 1, range [0, 1]).
5.  **Full Pipeline Execution**: Run `model.run_training_pipeline` to simulate an end-to-end run, producing a submission file, and verify the output file's structure.

All steps include assertions to ensure logical correctness and data integrity.
