Based on the comprehensive analysis of the accumulated lessons—specifically the "near-perfect" separation achieved by the **OAS-LDA backbone** [Cite solution_lesson_node_00047], the bottleneck of **Small Sample Size** ($N \approx 7$) on global covariance estimation [Cite solution_lesson_node_00015], and the **Precision Quantization Cap** [Cite solution_lesson_node_00057]—I propose the **Factorized High-Precision OAS Discriminant**.

This strategy introduces **Semantic Feature Factorization** (Naive Bayes assumption) as a structural innovation. By decomposing the 192-dimensional feature space into three independent semantic subspaces (Margin, Shape, Texture), we effectively triple the statistical power ($N/P$ ratio) available for covariance estimation. This addresses the "Small N" instability while allowing the **OAS Estimator** to apply distinct shrinkage intensities to each feature type. Furthermore, we aggregate these experts by **Summing Linear Logits**, which mathematically sharpens the probability distribution and pushes predictions closer to 1.0, enabling the model to break the log-loss floor imposed by global averaging.

### Model
The architecture is a **Bayesian Ensemble of Linear Discriminants** operating in strict **Double Precision**:

1.  **Factorized Backbones:** Three independent **Linear Discriminant Analysis (LDA)** models, each assigned to a specific feature group:
    *   **Expert M:** Trained on `margin_1`...`margin_64`.
    *   **Expert S:** Trained on `shape_1`...`shape_64`.
    *   **Expert T:** Trained on `texture_1`...`texture_64`.
    *   *Rationale:* This factorization reduces the covariance estimation problem from one $192 \times 192$ matrix (requires ~18k parameters) to three $64 \times 64$ matrices (requires ~6k parameters total). This significantly reduces estimation variance in the small-sample regime [Cite solution_lesson_node_00015].
2.  **Group-Wise OAS Covariance:** Each expert estimates its own covariance matrix $\Sigma_g$ using **Oracle Approximating Shrinkage (OAS)**.
    *   *Constraint:* We enforce **Geometric Consistency** by passing manually centered residuals to `OAS(assume_centered=True)` [Cite solution_lesson_node_00061].
3.  **Bayesian Logit Aggregation:** We combine the experts by summing their **Linear Logits**.
    *   *Formulation:* $Z_{final} = Z_{margin} + Z_{shape} + Z_{texture} - 2 \cdot \log(\pi)$.
    *   *Rationale:* This is equivalent to multiplying the likelihoods under the assumption of conditional independence. Unlike averaging probabilities (which dilutes confidence), summing logits **sharpens** the distribution, minimizing Log Loss for correct predictions.

### Data
1.  **Input:** The solution uses the 192 pre-extracted tabular features.
2.  **Semantic Splitting:** The feature matrix is sliced into three matrices ($X_M, X_S, X_T$) based on column name prefixes.
3.  **Inductive Preprocessing:**
    *   **High-Precision Loading:** Data is processed in **`float64`** to preserve signal [Cite solution_lesson_node_00046].
    *   **Transformation:** Apply **Yeo-Johnson Power Transformation** (`standardize=False`) followed by **Standard Scaling** [Cite solution_lesson_node_00025].
    *   **Inductive Fit:** Transformers are fitted **only on the Training set** [Cite solution_lesson_node_00041].

### Training
1.  **Parameter Estimation (Per Group):**
    *   For each group $g \in \{M, S, T\}$:
        *   Compute class means $\mu_{g,k}$ using the **Arithmetic Mean** [Cite solution_lesson_node_00066].
        *   Compute residuals $R_g = X_g - \mu_{g,y}$.
        *   Estimate $\Sigma_g$ using `OAS(assume_centered=True)` [Cite solution_lesson_node_00047].
        *   Extract the precision matrix using the robust SVD-based `precision_` attribute [Cite solution_lesson_node_00062].
        *   Derive the linear weights $W_g$ and bias $b_g$ using the **Linear Formulation** to avoid quadratic instability [Cite solution_lesson_node_00055].
2.  **No Optimization:** The aggregation is analytical, avoiding the pitfalls of discriminative calibration on perfectly separable data [Cite solution_lesson_node_00077].

### Evaluation
1.  **Inference:**
    *   Preprocess test data to get $X_{test, M}, X_{test, S}, X_{test, T}$.
    *   Compute logits for each group in **`float64`**: $Z_g = X_{test, g} W_g^T + b_g$.
    *   **Aggregation:** $Z_{total} = Z_M + Z_S + Z_T - 2 \log(\pi)$.
    *   **Probability:** Apply `scipy.special.softmax` to $Z_{total}$ in **`float64`**.
    *   *Constraint:* Avoid manual softmax implementations or redundant re-normalization [Cite solution_lesson_node_00085].
2.  **Robustness:** This strategy maximizes the statistical power for covariance estimation via factorization and utilizes logit-summation to achieve the extreme probability saturation required to break the current metric floor [Cite solution_lesson_node_00057].
