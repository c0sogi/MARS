The following script demonstrates the usage of the provided library components for the leaf classification task.

**Implementation Strategy:**
1.  **Environment Setup**: Initialize the random seed for reproducibility using `library.utils.set_seed`.
2.  **Component Verification (Unit Testing)**:
    *   **Geometry Extraction**: Manually instantiate `GeometryExtractor` and process a single image to verify feature vector shape and content type. Create a small temporary metadata subset to verify batch processing without running the full dataset.
    *   **Data Loading**: Use `load_and_merge_data` to load the training set. Verify the merging of geometric and tabular features, ensuring correct dimensions and data types (`float64`).
    *   **Pipeline**: Instantiate `SanitizedTransformer`. Fit and transform a subset of the data to verify variance thresholding, Yeo-Johnson transformation, and scaling. Check output statistics (mean ~0, std ~1).
    *   **Model**: Instantiate `OASDiscriminant`. Fit on the transformed subset and generate predictions. Verify that `predict_proba` returns valid probabilities (summing to 1, range [0,1]) and that `compute_log_loss` functions correctly.
3.  **End-to-End Execution**: Run the `run_training_process` function in `debug` mode. This orchestrates the entire flow (Data Load -> Pipeline -> Model -> Submission) on a subset of data to ensure the integration works correctly and generates the `submission.csv` file.
4.  **Validation**: Assertions are placed throughout to confirm shapes, types, and logic.
