The implementation strategy follows the orchestration of the "Sanitized Orthogonal-Geometric High-Precision OAS Discriminant" pipeline. 

1.  **Setup & Data Loading**: We initialize the environment with a fixed seed and load the training, validation, and test datasets using the `load_and_merge_data` function. This handles the extraction of the 7 geometric basis features and merges them with the tabular data.
2.  **Pipeline Execution**: We run the `run_pipeline` function, which applies the `VarianceThreshold`, `PowerTransformer` (Yeo-Johnson), and `StandardScaler` to the data. This ensures the features are Gaussianized and standardized, which is critical for the OAS estimator.
3.  **Model Training**: We instantiate and fit the `OASDiscriminant` model on the processed training data. This model uses an analytic solution for the decision boundaries based on the OAS covariance estimate.
4.  **Validation & Evaluation**: We predict probabilities on the validation set and compute the multi-class log loss using the competition-specific metric function. The result is printed with full precision.
5.  **Failure Analysis**: We calculate the per-sample log loss (error magnitude) and compute the Pearson correlation coefficient between this error vector and each feature in the validation set. This identifies which features are most associated with prediction errors.
6.  **Submission Generation**: We check if the validation metric meets the specified strict threshold. If successful, we generate predictions for the test set and save them to the submission file in the required format.
