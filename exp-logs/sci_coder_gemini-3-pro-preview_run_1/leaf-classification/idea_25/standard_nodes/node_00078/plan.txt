Based on the empirical findings in **Lesson 77 (solution_lesson_node_00077)**, applying discriminative calibration (via L-BFGS-B optimization) to a generative model that already achieves perfect separation on the training set is redundant and introduces numerical noise. The previous solution's validation log loss of `1.213678e-09` is slightly worse than the optimal `1.213677e-09` achieved by the pure analytical approach.

To optimize the solution, I will:
1.  **Refactor `library/model.py`**: Remove the discriminative calibration phase entirely. The model will rely solely on the closed-form analytical solution of Linear Discriminant Analysis with Oracle Approximating Shrinkage (OAS). This eliminates the floating-point noise introduced by re-computing logits and exponentials during the unnecessary optimization step.
2.  **Rename the model class**: Change `CalibratedOASDiscriminant` to `AnalyticalOASDiscriminant` to reflect the removal of the calibration head.
3.  **Update `runfile.py`**: Instantiate the new `AnalyticalOASDiscriminant` class.

This strategy leverages **Lesson 77** (Avoid Probabilistic Wrappers/Calibration on Linearly Separable Data) while maintaining the benefits of **Lesson 47** (OAS over Ledoit-Wolf) and **Lesson 73** (High Precision Inference).

from sklearn.covariance import OAS

class CalibratedOASDiscriminant(BaseEstimator, ClassifierMixin):

    Phase 1 (Generative): Learns a robust low-rank manifold using Linear Discriminant Analysis
    with Oracle Approximating Shrinkage (OAS) for covariance estimation. This phase fixes
    the projection directions (W) and an initial analytical bias (b_init).

    Phase 2 (Discriminative): Freezes the projection W and optimizes a global temperature
    scale (s) and a bias correction vector (b) to explicitly minimize Multi-class Log Loss.

    Attributes:
        classes_ (np.ndarray): Unique class labels.
        W_ (np.ndarray): Projection matrix of shape (n_classes, n_features).
        b_init_ (np.ndarray): Initial analytical bias of shape (n_classes,).
        s_ (float): Optimized scalar scale factor.
        b_ (np.ndarray): Optimized bias vector of shape (n_classes,).
    """

        self.le_ = None
        self.W_ = None
        self.b_init_ = None
        self.s_ = None
        self.b_ = None
        self.means_ = None
        self.precision_ = None

        Fits the model using the two-stage hybrid approach.

        Args:
            X (array-like): Training features of shape (N, D).
            y (array-like): Training labels of shape (N,).

        Returns:
            self

        # We need to compute means and center the data to estimate covariance
        self.means_ = np.zeros((n_classes, n_features), dtype=config.FLOAT_PRECISION)
        priors = np.zeros(n_classes, dtype=config.FLOAT_PRECISION)
        X_centered = np.zeros_like(X, dtype=config.FLOAT_PRECISION)

        for k in range(n_classes):

            mask = y_encoded == k
            X_k = X[mask]

            priors[k] = len(X_k) / n_samples

        term1 = -0.5 * np.sum(self.means_ * self.W_, axis=1)

        # Project training data to generative logits: Z = X @ W.T
        Z = X @ self.W_.T
