The implementation strategy involves the following steps:

1.  **Setup and Reproducibility**: Initialize the environment, suppress warnings, and set random seeds for NumPy to ensure consistent results.
2.  **Feature Extraction Demonstration**: Directly utilize `extract_single_image_features` on a sample image from the training set to verify that geometric features (e.g., area, perimeter) are correctly calculated and returned in the expected dictionary format.
3.  **Data Management**: Instantiate `LeafDataManager` to load the full dataset. This handles the merging of provided tabular features with the extracted visual features, applies Yeo-Johnson transformation and Standard Scaling, and returns processed NumPy arrays (float64). We will validate the shapes and data types of these arrays.
4.  **Preprocessor Demonstration**: Create a synthetic dataset to explicitly demonstrate the `HighPrecisionPreprocessor` class. We will fit and transform this data to verify that the class enforces strict `float64` precision and correctly standardizes the data.
5.  **Model Training and Evaluation**:
    *   Instantiate the `OASDiscriminant` classifier.
    *   Train it using the processed training data (`X_train`, `y_train`).
    *   Generate predictions on the validation set (`X_val`).
    *   Calculate and print accuracy and multi-class log loss to evaluate performance.
6.  **Submission Generation**:
    *   Generate probability predictions for the test set (`X_test`).
    *   Construct a submission DataFrame using the test IDs and class names.
    *   Apply the log-loss clipping constraint mentioned in the task description (though usually handled by the metric, it's good practice for the submission).
    *   Save the final CSV to the designated submission directory.
