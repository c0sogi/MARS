This script demonstrates the end-to-end usage of the provided library modules to solve the plant species identification task. It covers data loading, feature extraction (combining pre-extracted tabular features with custom geometric descriptors), robust preprocessing using a sanitized pipeline, model training with an OAS Linear Discriminant, and generating predictions for submission.

The script performs the following steps:
1.  **Setup**: Initializes the environment and sets random seeds for reproducibility.
2.  **Data Loading**: Loads the full training, validation, and test datasets using `library.data.load_dataset`. This automatically triggers the feature generation pipeline defined in `library.features` if the cache is missing.
3.  **Preprocessing**: Instantiates and fits the `SanitizedPreprocessor` on the training data to handle scaling, normalization, and constant feature removal.
4.  **Model Training**: Trains the `OASDiscriminant` model, which uses Oracle Approximating Shrinkage to estimate robust covariance matrices for high-dimensional, low-sample data.
5.  **Validation**: Evaluates the model on the validation set, calculating Multi-class Log Loss and Accuracy, and verifying the integrity of the probability outputs.
6.  **Submission**: Generates predictions for the test set and creates a submission file formatted according to the competition requirements.
