Here is the implementation strategy followed by the complete Python script.

### Implementation Strategy
1.  **Setup and Loading**: The script initializes by setting random seeds for reproducibility and loading the training metadata from `./metadata/train.csv`. It constructs full file paths for images by prepending the input directory.
2.  **Target Variable Analysis**: It analyzes the `species` column to determine the number of classes and checks for class imbalance by calculating the ratio of the most frequent to the least frequent class.
3.  **Tabular Data Analysis**: The script iterates through the 192 numerical features (`margin`, `shape`, `texture`). It calculates descriptive statistics (mean, std, min, max) and identifies outliers using the Interquartile Range (IQR) method. It also checks for missing values. Given the high dimensionality, it summarizes these statistics rather than printing 192 individual lines.
4.  **Image Data Analysis**: It iterates through all images referenced in the training set. It loads each image to extract dimensions (width, height), aspect ratios, and channel counts. It computes global pixel statistics (mean and standard deviation) to inform normalization strategies.
5.  **Feature Relationships**:
    *   **Correlation**: It computes the correlation matrix for the numerical features and identifies pairs with high collinearity (> 0.90).
    *   **Feature Importance**: It trains a lightweight Random Forest classifier on the tabular features to identify and report the top 5 most important features for species classification.
    *   **Meta-Feature Analysis**: It investigates if image properties (specifically image area) have any relationship with the target class by performing a one-way ANOVA test.
