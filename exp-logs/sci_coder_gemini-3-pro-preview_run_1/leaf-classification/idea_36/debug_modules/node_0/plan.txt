### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by suppressing warnings and setting random seeds to ensure reproducibility.
2.  **Utility Verification**: distinct functions will be created to verify the correctness of low-level utility functions (`stable_softmax`, `clip_probabilities`) using assertions with known inputs.
3.  **Data Loading Demonstration**: Use `data_loader.py` to load the raw training and validation data. Assertions will verify the data shapes and types (specifically `float64`).
4.  **Preprocessing Demonstration**: Demonstrate the `Float64Preprocessor` from `preprocessing.py`. We will fit it on the training data and transform both train and validation sets, verifying that the output statistics (mean/std) are close to 0 and 1 respectively.
5.  **Model Training & Inference**: Instantiate and train the `MetricOptimizedCholeskyLDA` model from `model.py`. We will verify that the grid search finds an optimal alpha and that the model produces valid probability distributions (summing to 1).
6.  **Submission Generation**: Run the full pipeline on the test set, format the predictions according to the sample submission schema, and save the result to the working directory.
