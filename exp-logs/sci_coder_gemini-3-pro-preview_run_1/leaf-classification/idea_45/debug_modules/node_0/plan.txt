Implementation strategy:
1.  **Setup**: Configure the environment using `library.utils.set_seed` to ensure reproducibility.
2.  **Feature Extraction Demo**: Manually invoke `library.features.extract_features_from_image` on a sample image from the training set. Verify that the returned dictionary contains all expected keys defined in `library.config` and that values are valid floats.
3.  **Data Loading**: Use `library.data.load_data` to load the dataset. I will use `debug_sample_size=None` (loading the full dataset) because the dataset is small (~1000 images) and splitting it arbitrarily via the debug parameter would cause the `LabelEncoder` to miss classes present in the validation set, leading to errors. Processing the full dataset is fast enough for this demonstration.
4.  **Data Validation**: Assert that the loaded arrays (`X_train`, `X_val`, etc.) have the correct shapes, `float64` precision, and contain no NaNs.
5.  **Preprocessing Demo**: Instantiate `library.preprocessing.HighPrecisionPreprocessor` separately and apply it to a small synthetic dataset to demonstrate its API and verify it preserves `float64` precision and standardizes data correctly.
6.  **Model Training**: Instantiate and fit `library.model.OASDiscriminant` on the training data.
7.  **Evaluation**: Predict probabilities on the validation set. Assert that probabilities sum to 1 and calculate accuracy and log loss.
8.  **Submission**: Generate predictions for the test set and save the results to `working/demo_submission.csv` in the required format.
