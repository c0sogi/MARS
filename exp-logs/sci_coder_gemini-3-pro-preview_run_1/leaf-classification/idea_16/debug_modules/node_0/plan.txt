This script demonstrates the usage of the provided library modules for the plant species identification task. It systematically verifies the utility functions, data loading, preprocessing, custom model logic, and the full solver pipeline.

The implementation strategy is as follows:
1.  **Utilities Verification**: Validates the probability normalization and log loss calculation logic to ensure compliance with the competition metric.
2.  **Model Unit Test**: Tests the `FixedMeanOASDiscriminant` class on synthetic data to verify that class means, residuals, and covariance estimation work as expected before applying it to the real dataset.
3.  **Data & Preprocessing**: Loads the provided metadata and executes the `RobustPreprocessor` pipeline to transform features using Yeo-Johnson and Standardization.
4.  **Full Solver Execution**: Runs the end-to-end `run_solver` function, which performs semi-supervised learning, and validates the format and integrity of the generated submission file.
