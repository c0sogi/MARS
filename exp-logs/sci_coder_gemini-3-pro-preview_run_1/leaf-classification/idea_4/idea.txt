Based on the lessons learned, particularly the near-perfect performance of the Power-Transformed LDA [Cite solution_lesson_node_00006] and the limitations of global covariance assumptions in high-cardinality tasks, I propose a **Taxonomy-Regularized Hierarchical LDA Ensemble**.

This strategy introduces a structural innovation by decomposing the 99-class problem into a two-tier taxonomic hierarchy (Genus $\rightarrow$ Species). This allows the model to learn **genus-specific covariance structures**, relaxing the rigid assumption of a single global covariance matrix (standard LDA) without suffering from the instability of class-specific matrices (QDA).

### Model
The architecture is a probabilistic ensemble of two distinct Linear Discriminant Analysis (LDA) pipelines:

1.  **Global LDA (Baseline):** A single LDA model trained on all 99 classes. This component is retained from the previous best solution [Cite solution_lesson_node_00006] to ensure stability and capture global linear separability using the full dataset.
2.  **Hierarchical LDA (Innovation):** A two-level Bayesian tree:
    *   **Level 1 (Genus Expert):** An LDA model trained to classify the **Genus** of the specimen (e.g., *Acer*, *Quercus*), extracted from the species labels.
    *   **Level 2 (Species Experts):** A collection of independent LDA models, each trained exclusively on samples from a specific Genus to discriminate between species *within* that Genus.
    *   *Rationale:* Different plant families may rely on different feature correlations (e.g., *Acer* might be distinguished by shape, while *Quercus* is distinguished by margin texture). This hierarchy allows the model to adapt the covariance matrix locally to each biological family.

### Data
1.  **Input:** The model will use the 192 extracted tabular features (`margin`, `shape`, `texture`).
2.  **Target Engineering:** A new target variable `Genus` will be created by parsing the first token of the `species` string (e.g., `Acer_Capillipes` $\rightarrow$ `Acer`).
3.  **Preprocessing:**
    *   **Power Transformation:** Apply the **Yeo-Johnson** transformation to all features to enforce the multivariate Gaussian distribution required by LDA [Cite solution_lesson_node_00006].
    *   **Scaling:** Apply **Standard Scaling** (zero mean, unit variance) after the transformation to ensure numerical stability for the covariance inversion.
    *   **Note:** Rank-based transformers (like QuantileTransformer) are explicitly rejected to preserve linear feature correlations [Cite solution_lesson_node_00010].

### Training
1.  **Global Training:** Train the Global LDA on the full transformed dataset with automatic shrinkage (Ledoit-Wolf) [Cite solution_lesson_node_00005].
2.  **Hierarchical Training:**
    *   Train the **Level 1 Genus LDA** on the full dataset using `Genus` labels.
    *   For each Genus with sufficient samples ($N \ge 5$), train a **Level 2 Species LDA** on the subset of data belonging to that Genus.
    *   *Fallback:* For Genera with insufficient samples to estimate a covariance matrix, the Hierarchical branch will default to the Global model's conditional probabilities.
3.  **Optimization:** No complex weight optimization is required [Cite solution_lesson_node_00008]. The ensemble will simply average the Global and Hierarchical probability estimates.

### Evaluation
1.  **Inference:** For each test sample $x$:
    *   Compute the global probability vector $P_{global}(S|x)$.
    *   Compute the hierarchical probability vector:
        $$P_{hier}(S|x) = P(S | G_S, x) \times P(G_S | x)$$
        where $G_S$ is the genus of species $S$, $P(G_S|x)$ comes from the Level 1 model, and $P(S|G_S, x)$ comes from the specific Level 2 model.
2.  **Aggregation:** Calculate the final probability as the arithmetic mean of the Global and Hierarchical predictions. This acts as a regularization mechanism: the Global model stabilizes predictions where local Genus data is sparse, while the Hierarchical model refines predictions where distinct sub-population structures exist.
