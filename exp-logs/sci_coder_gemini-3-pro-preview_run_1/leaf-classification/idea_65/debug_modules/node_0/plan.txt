This script demonstrates the end-to-end execution of the leaf species classification pipeline using the provided library modules. It covers data loading, preprocessing, model training with the custom OAS Discriminant, evaluation, and submission generation.

**Implementation Strategy:**
1.  **Setup & Configuration**: Initialize the environment and set random seeds for reproducibility using `library.utils`.
2.  **Data Loading**: Use `library.preprocessing.load_data` with `debug=True` to quickly load a subset of the data. This demonstrates the pipeline's capability to handle raw images, extract geometric features, and apply sanitization without processing the entire dataset.
3.  **Verification**: Assert data integrity (shapes, data types, and absence of NaNs) to ensure the `SanitizedPipeline` logic functioned correctly.
4.  **Model Execution**: Instantiate and train the `library.model.OASDiscriminant`. This model is specifically designed for high-precision estimation in this task.
5.  **Evaluation**: Calculate the Multi-class Log Loss on the validation set to verify model learning.
6.  **Submission**: Generate predictions for the test set, format them into a DataFrame matching the competition requirements, and save the result.
