The error `ValueError: y contains previously unseen labels` occurs because the `run_demo` function creates a small debug dataset by slicing the first 50 rows of the training and validation dataframes. In a high-cardinality dataset (99 plant species), a small random slice of the training set will not cover all classes. Consequently, the validation slice contains a species (`'Populus_Adenopoda'`) that is absent from the training slice. When the `LabelEncoder` (fitted only on the training slice) attempts to transform the validation targets, it fails upon encountering this unseen label.

To fix this, I will modify `library/preprocessing.py` to filter the validation set before encoding. Specifically, I will identify and remove any validation samples whose labels were not seen during the training phase. This ensures that `LabelEncoder.transform` only receives valid labels, preventing the crash while preserving the integrity of the debug run (Cite debug_lesson_1).
