The following script demonstrates the end-to-end usage of the provided library modules for the leaf classification task. It begins by validating the feature extraction logic on a single image, ensuring geometric and topological features are correctly computed. It then proceeds to load the training data using the data manager, verifying the integration of tabular and image-derived features. The script explicitly instantiates and tests the high-precision preprocessing pipeline and the custom OAS Discriminant model to confirm data transformations and probability predictions meet the required constraints. Finally, it executes the full pipeline to generate a submission file, validating the output format against the sample submission.
