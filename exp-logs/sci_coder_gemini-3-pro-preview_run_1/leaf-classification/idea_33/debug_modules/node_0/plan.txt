The following script demonstrates the usage of the provided library modules for the leaf classification task. It follows a structured approach:

1.  **Preprocessing Demonstration**: It explicitly instantiates the `Float64Preprocessor` class to show how the high-precision feature transformation (Yeo-Johnson + Scaling) is applied to raw data, verifying the output statistics and data types.
2.  **Data Loading**: It uses `load_data` to fetch the training, validation, and test sets. This function handles reading the metadata, sorting features alphanumerically, and applying the inductive preprocessing pipeline.
3.  **Model Training and Inference**: It initializes the `CholeskyOASDiscriminant` model, fits it on the training data, and generates probability predictions for the validation set.
4.  **Validation**: It performs assertions to ensure predictions are valid probability distributions (summing to 1, within [0, 1]) and calculates the multi-class log loss.
5.  **Submission Generation**: It uses `save_submission` to format the test predictions into the required CSV format.
6.  **Full Pipeline Execution**: Finally, it calls the `run_pipeline` function to demonstrate the end-to-end workflow in a single call.
