The implementation strategy follows the rigorous requirements of the high-precision analytical pipeline.

1.  **Data Management**: We utilize the provided `DataManager` to load the dataset. This class automatically handles the complex feature engineering (Dual-Envelope Morphological Fusion) and preprocessing (Yeo-Johnson transformation and Standard Scaling in `float64`) while utilizing the caching mechanism to ensure speed.
2.  **Model Training**: We instantiate the `HighPrecisionOAS` classifier. Since this is a closed-form analytical estimator (using Oracle Approximating Shrinkage for covariance matrices), training is deterministic and extremely fast. We execute this on the CPU as the provided library code is optimized for NumPy/SciPy operations.
3.  **Validation**: We generate probability predictions for the validation set and compute the Multi-class Log Loss. The metric is printed with full precision to verify against the strict threshold.
4.  **Failure Analysis**: We compute the element-wise cross-entropy loss for the validation samples to quantify "error magnitude". We then calculate the Pearson correlation coefficient between this error signal and every feature in the dataset to identify features associated with model uncertainty.
5.  **Conditional Submission**: We strictly adhere to the logic that a submission file is only generated if the validation log loss is below `3.3382359570696616e-14`. If this condition is met, we infer on the test set and save the formatted `submission.csv`.
