The following script demonstrates the end-to-end usage of the provided library components to solve the Leaf Classification task.

The strategy is as follows:
1.  **Setup**: Initialize the environment and set random seeds for reproducibility using `library.config` and `library.utils`.
2.  **Feature Extraction Demo**: Demonstrate the low-level `extract_visual_features_for_row` function from `library.image_processing` on a single metadata row to verify geometric feature extraction logic.
3.  **Data Pipeline**: Instantiate the `DataManager` from `library.data_loader` to load, process, and cache the training, validation, and test datasets. This handles tabular feature loading, geometric extraction, Yeo-Johnson transformation, and standardization.
4.  **Model Training**: Initialize and train the `HighPrecisionOAS` classifier from `library.model`. This model is specifically designed for high-dimensional, potentially ill-conditioned data using Oracle Approximating Shrinkage.
5.  **Validation**: Evaluate the model on the validation set using Multi-class Log Loss to ensure performance.
6.  **Submission**: Generate predictions on the test set and format the output CSV according to the competition requirements, saving it to the specified submission path.
