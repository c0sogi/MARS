The implementation strategy follows the "Holistic Geometric High-Precision OAS Discriminant" idea, leveraging the provided library modules to construct a robust, high-precision linear classification pipeline.

1.  **Setup & Initialization**: We begin by setting the random seed for reproducibility using `library.utils.set_seed`.
2.  **Data Loading**: We utilize `library.data_loader.load_and_augment_data` with caching enabled. This function loads the metadata, extracts the critical geometric features (Area, Perimeter, Solidity, etc.) from the binary images, and merges them with the tabular features (Margin, Shape, Texture), ensuring `float64` precision.
3.  **Preprocessing**: We apply the `library.preprocessing.preprocess_features` pipeline. This performs a Yeo-Johnson Power Transformation (to stabilize variance, especially for geometric features) followed by Standard Scaling, strictly maintaining double precision to avoid metric floors.
4.  **Model Training**: We instantiate and train the `LinearOASDiscriminant` from `library.model`. This model uses the Oracle Approximating Shrinkage estimator to compute a well-conditioned covariance matrix and derives linear decision boundaries analytically.
5.  **Validation & Evaluation**:
    *   We generate probabilities for the validation set.
    *   We compute the **Multi-class Log Loss** using `sklearn.metrics.log_loss` and print it with full precision.
6.  **Failure Analysis**:
    *   We calculate the negative log-likelihood (error magnitude) for each validation sample.
    *   We compute the Pearson correlation coefficient between this error vector and each feature column to identify which features correlate most with model uncertainty or error.
7.  **Conditional Submission**:
    *   We check if the validation log loss is strictly lower than the specified threshold (`3.3382359570696616e-14`).
    *   If the condition is met, we generate predictions for the test set, clip probabilities to the `[1e-15, 1-1e-15]` range to ensure numerical stability, and save the submission file using `library.utils.save_submission`.
