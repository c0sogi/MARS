The solution implements the **Exact Cholesky-OAS Linear Discriminant** pipeline as described. It orchestrates the data loading, preprocessing, model training, validation, failure analysis, and conditional submission generation.

### Strategy Outline
1.  **Setup & Data Loading**: Initializes the environment with a fixed seed and loads the training, validation, and test datasets using the `data_loader` module with caching enabled for efficiency.
2.  **Preprocessing**: Applies the `RobustPipeline` (Yeo-Johnson + Standard Scaling) via the `preprocessing` module. The pipeline is fitted on the training set and applied to all splits, ensuring `float64` precision is maintained.
3.  **Model Training**: Instantiates and fits the `CholeskyOASLinearDiscriminant`. This model uses the OAS estimator for covariance and a Cholesky solver for weight derivation, avoiding explicit matrix inversion to preserve numerical stability.
4.  **Validation & Scoring**: Generates probability predictions for the validation set and computes the Multi-class Log Loss using the `metrics` module. The result is printed as "Final Validation Metric".
5.  **Failure Analysis**: Calculates the per-sample log loss (error magnitude) on the validation set. It then computes and prints the correlation between this error magnitude and the input features to identify sources of systematic error.
6.  **Conditional Submission**: Checks if the validation metric is strictly lower than the specified threshold (`1.2136771218566717e-09`). If the condition is met, it generates predictions for the test set and saves the `submission.csv`; otherwise, it skips submission generation.
