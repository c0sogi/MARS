This script demonstrates the usage of the provided machine learning library modules for the leaf classification task. It overrides the configuration to run in `DEBUG` mode with a small subset of data for speed. It systematically verifies the functionality of the data loader, preprocessing pipeline, linear discriminant model, and metric calculation, ensuring strict type adherence (float64) and logical correctness via assertions. Finally, it executes the full end-to-end pipeline and verifies the generation of a valid submission file.
