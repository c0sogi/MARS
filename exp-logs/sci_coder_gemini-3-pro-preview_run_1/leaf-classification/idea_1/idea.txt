Based on the task requirements and the provided model architectures, I propose the following highly efficient baseline approach.

### Model
I will implement a **Light Gradient Boosting Machine (LightGBM)**. This model is a gradient boosting framework that uses tree-based learning algorithms. It is chosen as the baseline for its exceptional speed and efficiency compared to traditional XGBoost, specifically due to its histogram-based algorithm for splitting and leaf-wise tree growth strategy. The model will rely **exclusively on the 192 pre-extracted tabular features** (margin, shape, and texture), intentionally omitting the raw image data. This design decision prioritizes simplicity and low resource consumption, avoiding the computational overhead of Convolutional Neural Networks while leveraging the high-quality engineered features provided in the dataset.

### Data
1.  **Input Source**: The solution will strictly use `train.csv` and `test.csv`. The `images/` directory will be ignored.
2.  **Feature Selection**: All 192 numerical columns (`margin_1`–`64`, `shape_1`–`64`, `texture_1`–`64`) will be used as input features.
3.  **Preprocessing**:
    *   The `species` target column will be encoded into integers (0-98) using a Label Encoder.
    *   The `id` column will be removed from the training features but retained for the submission file.
    *   No feature scaling or normalization is required, as decision tree-based algorithms are invariant to monotonic transformations of features.

### Training
1.  **Objective Function**: The model will be trained to minimize **multi-class log loss** (`multi_logloss`), directly aligning with the competition metric.
2.  **Validation Strategy**: I will employ **Stratified K-Fold Cross-Validation** (e.g., K=5). Given the small dataset size and the large number of classes (99 classes with ~10 samples each), stratification is critical to ensure every fold contains a representative distribution of all species.
3.  **Procedure**:
    *   The model will be trained on K-1 folds and validated on the remaining fold.
    *   **Early Stopping** will be implemented to halt training when the validation log loss stops improving, preventing overfitting on the small dataset.
    *   Hyperparameters (e.g., `num_leaves`, `learning_rate`, `feature_fraction`) will be set to robust baseline values.

### Evaluation
1.  **Inference**: For the test set, predictions will be generated using the models trained from each of the K folds.
2.  **Aggregation**: The final submission probabilities will be calculated by **averaging the probability outputs** of the K models. This averaging reduces variance and provides a more stable prediction than a single model.
3.  **Post-processing**: The resulting probability vectors will be clipped (if necessary, though Softmax handles this) and formatted into a CSV file matching the sample submission structure, with columns corresponding to the sorted species names.
