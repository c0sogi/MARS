The implementation strategy follows the strict requirements of the task. It utilizes the provided library modules to orchestrate the pipeline: loading data, preprocessing, training the OAS Discriminant model, and validating performance.

1.  **Initialization**: The script sets the random seed for reproducibility.
2.  **Data Loading**: It calls `load_and_process_data` to retrieve training, validation, and test sets, including the extraction of geometric features and fusion with tabular data.
3.  **Preprocessing**: It applies the `RobustPreprocessor` pipeline (Variance Thresholding, Yeo-Johnson Transformation, Standard Scaling) via `preprocess_data`.
4.  **Training**: It initializes the `OASDiscriminant` and fits it on the transformed training data.
5.  **Validation**: It generates probabilities for the validation set and computes the multi-class log loss using the provided utility. The result is printed in the required format.
6.  **Failure Analysis**: It calculates the per-sample log loss and computes the Pearson correlation between the error magnitude and each feature in the validation set. The top 5 features most correlated with error are reported.
7.  **Submission Gate**: It checks if the validation metric is strictly lower than the specified threshold (`3.058881515561734e-14`).
    *   If the condition is met, it retrains the model on the combined training and validation sets, generates predictions for the test set, and saves the submission file.
    *   If the condition is not met, it skips submission generation to comply with the "if and only if" constraint.
