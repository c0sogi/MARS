Based on the comprehensive analysis of the "Lessons Learned" and the specific failure modes of previous complex architectures (Learning-to-Rank, Visual Filtering, Metadata Hybridization), I propose the **Decay-Weighted Behavioral Cascade (DWBC)**.

This solution introduces a structural innovation in the **Collaborative Filtering (CF) Matrix Construction** phase. Instead of treating all historical interactions within a window as equal (binary) or merely count-based, we explicitly embed temporal decay into the training matrix itself. This effectively creates a "Rolling Similarity" graph that prioritizes current fashion associations over obsolete ones, addressing the "Recency over Volume" principle (Cite {solution_lesson_node_00007}) without discarding valuable long-tail data. We couple this with a **Stratified Vectorized Inference** mechanism to strictly enforce the successful "Cascade" logic (Cite {solution_lesson_node_00016}) within a high-speed linear algebra framework.

### Model
The architecture is a **Three-Stage Stratified Retrieval System** implemented via vectorized sparse matrix operations. It generates a single unified score vector $R_u$ for each user, where signal sources are mapped to disjoint numerical ranges to enforce a strict priority hierarchy: **Habit > Recent Similarity > Global Trend**.

1.  **Stratum 1: Habitual Repurchase (The "Priors" Layer)**
    *   **Logic:** Users are most likely to rebuy what they recently bought.
    *   **Mechanism:** Retrieve the user's history vector $U_{hist}$. Apply strict temporal decay ($1 / \text{days\_elapsed}$).
    *   **Stratification:** Scores are shifted to the range $[2000, \infty)$. This ensures explicit history *always* outranks inferred similarity, preserving the strong baseline performance (Cite {solution_lesson_node_00002}).

2.  **Stratum 2: Decay-Weighted Collaborative Filtering (The "Discovery" Layer)**
    *   **Structural Innovation:** We construct a **Time-Decayed Interaction Matrix** $X_{decay}$.
        *   Standard CF uses $X_{ui} \in \{0, 1\}$. We define $X_{ui} = w(t_{ui}) \cdot \text{IDF}_i$, where $w(t_{ui})$ is a decay function (e.g., $\frac{1}{\sqrt{\text{days} + 1}}$) applied to the *training* transactions.
        *   **Why:** This ensures that the learned similarity matrix $S = X_{decay}^T X_{decay}$ is driven by *concurrent* market behavior. If Users A and B both bought items $i$ and $j$, but did so 8 weeks ago, the contribution to $S_{ij}$ is lower than if they bought them yesterday. This dynamically adapts the graph to the fast-fashion cycle.
    *   **Normalization:** We apply **Row-wise (User) Normalization** to $X_{decay}$ to mitigate power-user bias (Cite {solution_lesson_node_00004}) and **IDF Weighting** to penalize globally popular items (Cite {solution_lesson_node_00011}).
    *   **Inference:** $R_{cf} = U_{query} \times S$. The query vector $U_{query}$ is also weighted by recency (Cite {solution_lesson_node_00005}).
    *   **Stratification:** Scores are normalized and scaled to the range $[100, 1000]$. This allows strong behavioral signals to rank high but never override explicit history.

3.  **Stratum 3: Global Trend (The "Fallback" Layer)**
    *   **Logic:** Time-decayed sales velocity for cold-start users.
    *   **Stratification:** Scores are scaled to $[0, 10]$.

### Data
1.  **Temporal Windowing:**
    *   We will extend the training window to **8 weeks** but apply the **Decay-Weighting** described above. This allows the model to leverage a larger volume of data for stability (Long Tail) while mathematically suppressing the noise from obsolete trends (Recency), resolving the conflict identified in Lesson {solution_lesson_node_00007}.
2.  **Validation Strategy:**
    *   **Time-Based Split:** Train on Weeks $T-8$ to $T-1$, Validate on Week $T$. This ensures the model has access to the user history required for Strata 1 and 2 (Cite {solution_lesson_node_00026}).
3.  **Precision:**
    *   Use **float32** for all matrix accumulators. This prevents the numerical overflow issues observed when using `float16` with stratified offsets (Cite {solution_lesson_node_00010}).

### Training
Since this is a memory-based heuristic model, "training" is the efficient construction of the sparse matrices:
1.  **Interaction Matrix:** Construct sparse $X_{decay}$ where values are decay weights.
2.  **Weighting:** Apply IDF to columns and L2 normalization to rows (Users).
3.  **Similarity:** Compute $S = X_{decay}^T X_{decay}$ via sparse matrix multiplication.
4.  **Pruning:** Retain only the top-100 neighbors per item to optimize inference speed.

### Evaluation
1.  **Vectorized Inference:**
    *   Generate predictions using **Vectorized Sparse Matrix Multiplication** ($R = U \times S$). This captures the "long tail" of similarity signals better than iterative lookups (Cite {solution_lesson_node_00012}).
2.  **Stratified Aggregation:**
    *   Compute $R_{total} = (U_{hist} \cdot 2000) + (R_{cf} \cdot 100) + V_{trend}$.
    *   This vectorized addition mathematically enforces the cascade logic: $Sort(R_{total})$ is equivalent to $Sort(Habit)$ followed by $Sort(CF)$ followed by $Sort(Trend)$ (Cite {solution_lesson_node_00016}).
3.  **Retrieval:**
    *   Employ the **Mask-and-Partition** technique (Cite {solution_lesson_node_00013}) to select the top 12 items in linear time.
