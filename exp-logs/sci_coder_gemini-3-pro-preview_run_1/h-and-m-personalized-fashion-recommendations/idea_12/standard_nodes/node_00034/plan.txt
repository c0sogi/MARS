The implementation strategy follows the standard machine learning pipeline: Data Preparation, Model Training/Validation, Failure Analysis, and Inference.

1.  **Setup & Configuration**: We initialize the environment by setting random seeds for reproducibility.
2.  **Validation Pipeline**:
    *   We manually execute the validation steps (similar to `evaluation.validate`) within the script to retain access to the prediction objects and ground truth data.
    *   We load the training metadata and perform a time-based split (last 7 days for validation).
    *   We construct the **Temporal-Graph** artifacts (Interaction Matrix, Similarity Matrix) strictly on the training portion to prevent data leakage.
    *   We fit the `TGSCRecommender` and generate predictions for the validation set.
    *   We compute the **MAP@12** metric and print it in the required format.
3.  **Failure Analysis**:
    *   Using the validation predictions, we calculate the Average Precision (AP) for each user.
    *   We aggregate user statistics (History Length, Recency) from the training data.
    *   We compute and print the Pearson correlation between these features and the model's performance (AP) to understand error sources (e.g., cold-start vs. heavy users).
4.  **Submission**:
    *   We check if the validation MAP@12 exceeds the threshold (0.0265060791).
    *   If successful, we invoke `stratified_inference.generate_submission()`, which retrains the model on the full dataset (Train + Validation) and generates predictions for the test set.
