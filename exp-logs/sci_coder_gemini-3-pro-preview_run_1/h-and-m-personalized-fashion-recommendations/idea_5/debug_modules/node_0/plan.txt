The following implementation demonstrates the usage of the provided library files. It sets up a lightweight demonstration environment by creating a small subset of the dataset in the working directory. This ensures the code runs quickly while exercising all key components: data loading, graph construction, hybrid inference, and evaluation.

The script performs the following steps:
1.  **Environment Setup**: Creates a temporary directory and generates small, consistent subsets of the training, validation, and article data to simulate a complete run.
2.  **Configuration Override**: Monkey-patches the `library.config` module to point to these temporary datasets, ensuring the library code uses them instead of the full 20GB+ dataset.
3.  **Data Processing**: Demonstrates `DataLoader` to ingest data and generate integer mappings.
4.  **Graph Engineering**: Uses `SimilarityOptimizer` to build behavioral and variant similarity graphs.
5.  **Inference**: Instantiates `StratifiedRecommender` to generate predictions using the hybrid strategy (History + CF + Trends).
6.  **Evaluation**: Calculates the MAP@12 score using the provided metric function.
