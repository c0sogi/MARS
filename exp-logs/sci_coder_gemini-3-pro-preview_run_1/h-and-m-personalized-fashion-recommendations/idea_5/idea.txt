Based on the comprehensive analysis of the "Lessons Learned" and the failure modes of previous ideas (particularly the "Visual Similarity" and "Learning-to-Rank" experiments), I propose the **Stratified Vectorized Hybrid-Graph Cascade**.

This solution introduces a structural innovation by **densifying the Item-Item Similarity Graph** using explicit product metadata (Variants) rather than noisy visual embeddings. It integrates this into a fully vectorized, stratified linear algebra framework that strictly enforces the successful "Cascade" logic while leveraging the efficiency of sparse matrix operations.

### Model
The architecture is a **Three-Stage Stratified Retrieval System** that generates a unified score vector $R_u$ for each user. It preserves the high-precision "Cascade" hierarchy (Cite {solution_lesson_node_00016}) by mapping signals to disjoint score ranges, but innovates within the "Collaborative Filtering" stage by fusing behavioral and metadata signals.

1.  **Stratum 1: Habitual Repurchase (The "Priors" Layer)**
    *   **Logic:** Users are most likely to rebuy what they recently bought.
    *   **Mechanism:** Retrieve the user's purchase history from the training window. Score items using strict temporal decay ($1 / \text{days\_elapsed}$).
    *   **Stratification:** Shift scores to the range $[1000, \infty)$. This ensures that explicit history *always* outranks inferred similarity, preserving the strong baseline performance (Cite {solution_lesson_node_00002}).

2.  **Stratum 2: Hybrid Graph Retrieval (The "Discovery" Layer)**
    *   **Innovation:** Instead of relying solely on behavioral co-occurrence (which suffers from sparsity) or visual similarity (which introduces noise, Cite {solution_lesson_node_00020}), we construct a **Hybrid Similarity Matrix** $S_{hybrid}$.
    *   **Matrix Construction:** $S_{hybrid} = S_{behavior} + \lambda \cdot S_{variant}$.
        *   **$S_{behavior}$ (Behavioral):** The standard Item-Item co-occurrence matrix ($X^T X$). It is constructed using **Row-wise (User) Normalization** to mitigate power-user bias (Cite {solution_lesson_node_00004}) and **IDF Weighting** to penalize globally popular items (Cite {solution_lesson_node_00011}).
        *   **$S_{variant}$ (Metadata):** A sparse binary adjacency matrix where $S_{ij}=1$ if item $i$ and item $j$ share the same `product_code` (i.e., they are different colorways of the same product). This effectively "densifies" the graph, allowing the model to recommend the "White T-Shirt" if the user bought the "Black T-Shirt," a high-precision substitute signal that visual embeddings failed to capture reliably.
    *   **Inference:** Compute scores via **Vectorized Sparse Matrix Multiplication**: $R_{cf} = U_{decayed} \times S_{hybrid}$. The user vector $U_{decayed}$ weights seed items by their recency (Cite {solution_lesson_node_00005}).
    *   **Stratification:** Normalize and scale scores to the range $[10, 900]$. This allows the model to recommend relevant new items without overriding explicit history.

3.  **Stratum 3: Global Trend (The "Fallback" Layer)**
    *   **Logic:** Capture aggregate market momentum for cold-start users.
    *   **Mechanism:** Calculate sales velocity with time decay.
    *   **Stratification:** Scale scores to the range $[0, 9]$.

### Data
1.  **Temporal Windowing:**
    *   Restrict training data to the **last 5 weeks**. This adheres to the "Recency over Volume" principle (Cite {solution_lesson_node_00007}) to avoid concept drift.
2.  **Precision:**
    *   Use **float32** for all matrix accumulators and score calculations. This prevents the numerical overflow issues observed when using `float16` with stratified offsets (Cite {solution_lesson_node_00010}).
3.  **Preprocessing:**
    *   Generate the $S_{variant}$ matrix by grouping `articles.csv` by `product_code` and creating links between all items in the same group.

### Training
Since this is a memory-based heuristic model, "training" is the efficient construction of the sparse matrices:
1.  **Behavioral Matrix:** Compute $S_{behavior} = X_{norm}^T X_{norm}$ with IDF weighting.
2.  **Variant Matrix:** Construct $S_{variant}$ from metadata.
3.  **Hybrid Fusion:** Compute $S_{hybrid} = S_{behavior} + 0.1 \cdot S_{variant}$. The scalar $\lambda=0.1$ ensures that actual co-occurrence (stronger signal) dominates mere product identity, but product identity provides coverage where co-occurrence is missing.

### Evaluation
1.  **Vectorized Inference:**
    *   Generate predictions using **Vectorized Sparse Matrix Multiplication** ($R = U \times S$). This captures the "long tail" of similarity signals better than iterative neighbor lookups (Cite {solution_lesson_node_00012}).
2.  **Retrieval Strategy:**
    *   Employ the **Mask-and-Partition** technique (Cite {solution_lesson_node_00013}):
        1.  Compute the dense stratified score vector $R_u$.
        2.  Use `np.argpartition` to select the top 12 indices in linear time.
        3.  Sort the top 12 items.
    *   This avoids the $O(N \log N)$ cost of sorting the entire vocabulary for every user.
