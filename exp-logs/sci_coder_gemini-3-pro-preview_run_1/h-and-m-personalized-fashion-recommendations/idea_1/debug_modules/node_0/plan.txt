The following script demonstrates the usage of the provided library modules (`config`, `utils`, `metrics`, `data_loader`, `model`) for the H&M Recommendation task.

### Implementation Strategy
1.  **Configuration & Utilities**: Verify the `Config` paths and demonstrate `set_seed` for reproducibility. Test `reduce_mem_usage` on a synthetic DataFrame to confirm memory optimization logic.
2.  **Metrics**: Validate `calculate_map12` by creating a controlled ground truth and prediction set with a known theoretical MAP score, asserting that the function returns the correct value.
3.  **Data Loading**:
    *   Create temporary dummy CSV files (transactions, customers, articles) in the `./working` directory to simulate the input data. This avoids loading the massive full dataset, ensuring the demo runs quickly.
    *   Demonstrate `IdMapper` functionality: fitting, transforming, inverse transforming, and saving/loading mappings.
    *   Demonstrate `load_filtered_transactions` using the dummy files to verify date filtering and ID mapping logic.
4.  **Model**:
    *   Instantiate `TrendRepurchaseCascade`.
    *   Fit the model on the processed dummy data.
    *   Generate predictions and verify the logic: ensure previously purchased items appear in predictions (History) and popular items fill the remaining slots (Trend).
    *   Check that the output format is correct (list of integers).
5.  **Cleanup**: Remove temporary files created during the execution.
