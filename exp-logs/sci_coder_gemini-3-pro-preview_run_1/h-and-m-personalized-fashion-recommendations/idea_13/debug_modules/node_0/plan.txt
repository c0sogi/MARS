Implementation Strategy:
1.  **Configuration Setup**: Initialize the `Config` class and override paths to point to a temporary working directory (`./working/demo_execution`) to avoid interfering with existing files. Enable `DEBUG` mode and reduce sample sizes/neighbors to ensure the script completes quickly within the time limit.
2.  **Data Loading & Preprocessing**: Use `library.data_utils` to load the training transactions. Verify that the time-decay weights (`weight_fast`, `weight_slow`) are computed correctly. Extract the active inventory items to demonstrate the inventory filtering logic.
3.  **Graph Construction**: Instantiate `GraphBuilder`. Explicitly run the `fit_mappings` method to establish User/Item IDs. Execute the `run` method to build the interaction (`X`) and similarity (`S`) matrices for both "Fast" and "Slow" graphs. Validate the sparsity and dimensions of these matrices using assertions.
4.  **Recommendation Inference**: Instantiate `MSGRecommender`. Create a small subset of test customers (e.g., 100 users) to simulate a submission scenario. Call `generate_submission` to produce predictions.
5.  **Result Validation**: Load the generated submission file. Verify the CSV structure, ensuring `customer_id` and `prediction` columns exist. Check that predictions are space-separated strings of item IDs and do not exceed the maximum limit of 12 items.
