The following script demonstrates the complete pipeline for the H&M Recommendation task using the provided library files. It covers data loading, time-based splitting, TMVC model fitting, validation scoring (MAP@12), and final submission generation.

**Implementation Strategy:**
1.  **Setup:** Initialize the environment with a fixed random seed for reproducibility.
2.  **Data Management:** Use `DataManager` to load the raw transaction data and generate a time-based split (Training vs. Validation). We also extract specific temporal subsets (Structure, Velocity, History) required by the TMVC architecture.
3.  **Model Initialization:** Instantiate the `TMVCRecommender`.
4.  **Training:** Fit the model using the training subsets. This involves generating ID mappings, building a time-decayed interaction matrix, and computing an item-item similarity matrix.
5.  **Validation:** Generate predictions for the validation set customers and compute the MAP@12 score using the `calculate_map12` utility to verify model performance.
6.  **Inference:** Generate predictions for the final test set (from `sample_submission.csv`) and save the results to a submission file.
