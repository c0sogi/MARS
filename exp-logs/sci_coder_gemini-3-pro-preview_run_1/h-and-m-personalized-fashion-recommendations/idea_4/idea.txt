Based on the comprehensive analysis of previous experiments and the specific "Lessons Learned," I propose the **Stratified Multi-Modal Matrix Cascade (SMMC)**.

This solution introduces a structural innovation by implementing a **Tiered Score Stratification** mechanism. Instead of a traditional "Weighted Ensemble" (which failed in Lesson 00016) or a complex "Learning-to-Rank" model (which failed in Lesson 00009), this approach maps different signal sources into disjoint numerical ranges (strata). This effectively enforces a strict priority cascade (Repurchase > Behavior > Visual > Trend) within a fully vectorized linear algebra framework, allowing for high-speed inference while strictly preserving the high-precision priors identified in the failure analysis.

### Model
The architecture is a **Four-Stage Stratified Retrieval System** that generates a single unified score vector $R_u$ for each user $u$. The innovation lies in the **Stratification Logic**, which assigns a base magnitude offset to each signal source to prevent lower-precision signals (like Visual Similarity) from overriding high-precision signals (like Repurchase), effectively vectorizing the "Cascade" concept.

1.  **Stratum 1: Habitual Repurchase ($V_{rep}$)**
    *   **Source:** Direct user history.
    *   **Logic:** Items are scored by recency decay ($1 / (\text{days} + \alpha)$).
    *   **Stratification:** Scores are shifted to the range $[1000, \infty)$. This ensures that any item previously bought by the user (and active in the window) will *always* outrank a recommendation derived solely from similarity. Cite {solution_lesson_node_00002}.

2.  **Stratum 2: Behavioral Co-occurrence ($V_{beh}$)**
    *   **Source:** Item-Item Collaborative Filtering.
    *   **Logic:** Computed via $U_{hist} \times S_{behavior}$.
    *   **Matrix Construction:** $S_{behavior}$ is constructed using **Row-wise (User) Normalization** (Cite {solution_lesson_node_00004}) and **IDF Weighting** (Cite {solution_lesson_node_00011}) to mitigate power-user and popularity biases.
    *   **Stratification:** Scores are normalized and scaled to the range $[100, 900]$. This allows strong behavioral signals to rank high but never override explicit repurchase history.

3.  **Stratum 3: Visual Style Transfer ($V_{vis}$)**
    *   **Source:** Content-Based Filtering using Image Embeddings.
    *   **Logic:** Computed via $U_{hist} \times S_{visual}$. This layer addresses the "Cold Start" and "Sparsity" problems by recommending items that look identical to purchased items but lack sufficient co-occurrence data.
    *   **Matrix Construction:** $S_{visual}$ is a sparse matrix of the Top-K ($K=50$) cosine nearest neighbors derived from **ResNet50** embeddings of the item images.
    *   **Stratification:** Scores are scaled to the range $[10, 90]$. This ensures visual look-alikes are only recommended when behavioral signals are weak or exhausted.

4.  **Stratum 4: Global Trend ($V_{trend}$)**
    *   **Source:** Population-level sales velocity.
    *   **Logic:** Time-decayed sales counts.
    *   **Stratification:** Scores are scaled to range $[0, 9]$. This acts as the final fallback.

**Final Aggregation:**
$$ R_u = V_{rep} + V_{beh} + V_{vis} + V_{trend} $$
Because the ranges are disjoint, the addition operation effectively implements a cascade: $Sort(R_u)$ is equivalent to $Sort(V_{rep})$ followed by $Sort(V_{beh})$, etc.

### Data
1.  **Temporal Windowing:**
    *   Training data will be restricted to the **last 5 weeks** of transactions. This adheres to the "Recency over Volume" principle to minimize noise from obsolete fashion trends. Cite {solution_lesson_node_00007}.

2.  **Visual Feature Extraction:**
    *   We will use a pre-trained **ResNet50** (via `torchvision`) to extract 2048-dimensional embeddings for all `article_id`s active in the 5-week window.
    *   We will compute the Top-50 Nearest Neighbors for each item using Cosine Similarity to build the sparse $S_{visual}$ matrix.

3.  **Matrix Preprocessing:**
    *   **User History ($U_{hist}$):** Constructed with **Temporal Decay Propagation**, weighting the "seed" items in the user vector by their recency ($1 / \text{days\_elapsed}$). Cite {solution_lesson_node_00005}.
    *   **Precision:** All calculations will use **float32** to prevent the overflow issues observed when using `float16` with large scalar offsets. Cite {solution_lesson_node_00010}.

### Training
Since this is a memory-based heuristic model, "training" is defined as the efficient construction of the sparse matrices:
1.  **Behavioral Matrix ($S_{behavior}$):**
    *   Compute the Interaction Matrix $X$.
    *   Apply IDF weighting to columns.
    *   Normalize rows (Users) to L2 unit norm.
    *   Compute $S_{behavior} = X^T X$ (sparse matrix multiplication).
    *   Prune to Top-K per item to maintain sparsity.

2.  **Visual Matrix ($S_{visual}$):**
    *   Compute embeddings for active items.
    *   Use a blocked matrix multiplication or Faiss to find Top-K visual neighbors.
    *   Construct sparse $S_{visual}$.

3.  **Stratification Parameters:**
    *   The scaling factors (1000, 100, 10) are fixed structural hyperparameters designed to enforce the cascade logic derived from Lesson 00016.

### Evaluation
1.  **Vectorized Inference:**
    *   We will generate predictions using **Vectorized Sparse Matrix Multiplication** ($R = U \times S$) rather than iterative lookups. This captures the "long tail" of similarity signals. Cite {solution_lesson_node_00012}.

2.  **Retrieval Strategy:**
    *   We will employ the **Mask-and-Partition** technique:
        1.  Compute the dense stratified score vector $R_u$.
        2.  Use `np.argpartition` to select the top 12 indices in linear time.
        3.  Sort the top 12 items to produce the final ranked list.
    *   This avoids the overhead of sorting the entire vocabulary. Cite {solution_lesson_node_00013}.
