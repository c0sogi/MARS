Based on the comprehensive analysis of the "Lessons Learned" and the specific failure modes of previous experiments, I propose the **Time-Decayed Graph Cascade (TDGC)**.

This solution introduces a structural innovation in the **Graph Topology Construction** phase. It resolves the critical conflict between **Lesson 00007** (Long history introduces concept drift) and **Lesson 00012** (Vectorized inference benefits from the "long tail" of data) by embedding continuous temporal decay directly into the interaction graph's edge weights. This allows the model to utilize a significantly longer historical window to capture latent connections between rare items while mathematically suppressing obsolete signals, all within a strictly enforced vectorized cascade.

# Model
The architecture is a **Three-Stage Stratified Retrieval System** implemented via vectorized linear algebra. It generates a single unified score vector $R_u$ for each user, where signal sources are mapped to disjoint numerical ranges to enforce a strict priority hierarchy: **Habit > Time-Decayed Similarity > Global Trend**.

1.  **Stratum 1: Habitual Repurchase (The "Priors" Layer)**
    *   **Logic:** Users are overwhelmingly likely to rebuy recent items. Cite {solution_lesson_node_00002}.
    *   **Mechanism:** Retrieve the user's history vector $U_{hist}$. Apply strict temporal decay ($1 / \text{days\_elapsed}$).
    *   **Stratification:** Scores are shifted to the range $[2000, \infty)$. This ensures explicit history *always* outranks inferred similarity, strictly adhering to the "Cascade > Ensemble" principle. Cite {solution_lesson_node_00016}.

2.  **Stratum 2: Time-Decayed Collaborative Filtering (The "Discovery" Layer)**
    *   **Structural Innovation:** Instead of binary interactions over a short window, we construct a **Time-Weighted Interaction Matrix** $X_{decay}$.
        *   **Edge Weighting:** $X_{ui} = e^{-\lambda \cdot t_{ui}} \cdot \text{IDF}_i$, where $t_{ui}$ is the days elapsed since the transaction and $\lambda$ is a decay rate (e.g., corresponding to a 30-day half-life).
        *   **Why:** This allows the graph to retain "Long Tail" connectivity (Cite {solution_lesson_node_00012}) from 4-5 months ago (e.g., rare items bought together) but scales their magnitude down so they cannot override recent, concurrent trends. This solves the "Concept Drift" issue (Cite {solution_lesson_node_00007}) without discarding valuable data.
    *   **Normalization:** We apply **Row-wise (User) Normalization** to $X_{decay}$ to mitigate power-user bias. Cite {solution_lesson_node_00004}.
    *   **Similarity:** We compute $S = X_{decay}^T X_{decay}$. This defines item similarity not just by "bought together," but "bought together *concurrently*."
    *   **Inference:** $R_{cf} = U_{query} \times S$. The query vector $U_{query}$ is also weighted by recency. Cite {solution_lesson_node_00005}.
    *   **Stratification:** Scores are normalized and scaled to the range $[100, 1000]$.

3.  **Stratum 3: Global Trend (The "Fallback" Layer)**
    *   **Logic:** Time-decayed sales velocity for cold-start users.
    *   **Stratification:** Scores are scaled to $[0, 10]$.

**Final Aggregation:**
$$ R_{total} = R_{rep} + R_{cf} + R_{trend} $$
Sorting $R_{total}$ is mathematically equivalent to the heuristic cascade: Sort(Repurchase) $\rightarrow$ Sort(CF) $\rightarrow$ Sort(Trend).

# Data
1.  **Temporal Windowing:**
    *   We will extend the training window to **20 weeks**. This is significantly longer than the successful 5-week window from previous experiments, but the **Exponential Decay** ensures that the effective "attention" of the model remains focused on the recent period.
2.  **Validation Strategy:**
    *   **Time-Based Split:** Train on Weeks $T-20$ to $T-1$, Validate on Week $T$. This ensures the model has access to the user history required for Strata 1 and 2, rectifying the failure of User-Group splitting. Cite {solution_lesson_node_00026}.
3.  **Precision:**
    *   Use **float32** for all matrix accumulators. This prevents the numerical overflow issues observed when using `float16` with stratified offsets. Cite {solution_lesson_node_00010}.
4.  **Exclusion:**
    *   We explicitly exclude Visual Embeddings (Cite {solution_lesson_node_00020}) and Metadata Hybridization (Cite {solution_lesson_node_00027}) as previous lessons demonstrated they introduce noise that degrades the high-precision behavioral signal.

# Training
Since this is a memory-based heuristic model, "training" is the efficient construction of the sparse matrices:
1.  **Interaction Matrix:** Construct sparse $X_{decay}$ using the exponential decay formula.
2.  **Weighting:** Apply IDF to columns (Cite {solution_lesson_node_00011}) and L2 normalization to rows (Users).
3.  **Similarity:** Compute $S = X_{decay}^T X_{decay}$ via sparse matrix multiplication.
4.  **Pruning:** Retain only the top-100 neighbors per item to optimize inference speed.

# Evaluation
1.  **Vectorized Inference:**
    *   Generate predictions using **Vectorized Sparse Matrix Multiplication** ($R = U \times S$). Cite {solution_lesson_node_00012}.
2.  **Retrieval Strategy:**
    *   Employ the **Mask-and-Partition** technique: Densify the score vector, mask history items (unless Repurchase score overrides), and use `np.argpartition` to select top 12 items in linear time. Cite {solution_lesson_node_00013}.
