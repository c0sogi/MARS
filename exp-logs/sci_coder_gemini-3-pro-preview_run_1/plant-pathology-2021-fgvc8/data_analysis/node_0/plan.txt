The following script performs a comprehensive Exploratory Data Analysis (EDA) on the apple disease dataset. It focuses on the training set defined in `./metadata/train.csv` to ensure data integrity. The analysis covers target variable distribution (accounting for multi-label classification), image-specific properties (dimensions, channels, pixel statistics), and relationships between metadata and disease classes.

Strategies used:
1.  **Data Loading**: Uses the pre-generated metadata file.
2.  **Target Analysis**: Parses space-delimited labels to handle the multi-label nature of the dataset, calculating frequencies and co-occurrences.
3.  **Image Analysis**: 
    -   Uses `PIL` to quickly extract dimensions from all images without loading pixel data.
    -   Computes pixel mean and standard deviation on a stratified sample of images to ensure computational efficiency within the time limit.
4.  **Relationships**: Analyzes correlations between image metadata (size, aspect ratio) and specific diseases, as well as label co-occurrence patterns.
