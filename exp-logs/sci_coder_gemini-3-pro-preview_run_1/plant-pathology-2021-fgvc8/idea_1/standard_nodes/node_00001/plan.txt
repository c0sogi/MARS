2.  **Data Loading**: I will utilize `get_dataloaders` from `library.data_loader` to fetch the training, validation, and test sets. I will enable `load_cached_data=True` to leverage any pre-processed metadata, ensuring efficient startup.
3.  **Model Training**: I will instantiate the `AppleDiseaseModel` (based on EfficientNetV2-Small) and the `Trainer`. The training loop will run for the configured number of epochs (10), optimizing the model with AdamW and saving the best weights based on validation F1-Score.
4.  **Validation Assessment**: Post-training, I will load the best model weights and perform inference on the full validation dataset in evaluation mode. I will calculate the Mean F1-Score using `library.utils.calculate_score` and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: I will analyze the model's errors on the validation set. This involves calculating the error magnitude (Hamming distance between predicted and target vectors) for each image. I will then extract image dimensions (width, height, aspect ratio) and compute their Pearson correlation with the error magnitude to identify if image geometry correlates with poor performance.
6.  **Submission Generation**: Finally, I will use `trainer.predict(test_loader)` to generate predictions for the hidden test set and save the formatted `submission.csv`.
