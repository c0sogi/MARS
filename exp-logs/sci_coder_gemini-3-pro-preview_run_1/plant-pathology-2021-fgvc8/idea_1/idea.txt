To establish a robust and efficient baseline for the apple disease detection task, I propose a solution centered on a **Scalable Fused-MBConv Network**. This approach prioritizes computational efficiency and training speed while effectively handling the multi-label nature of the dataset.

### Model
The architecture is a lightweight Convolutional Neural Network (CNN) designed to balance parameter efficiency with representational power, drawing directly from the principles of **Model 1**.
*   **Backbone:** The network utilizes a hierarchical structure composed of **Fused-MBConv** blocks in the early stages and standard **MBConv** blocks in deeper stages. The Fused-MBConv layers replace the standard depthwise-separable convolutions with dense convolutions followed by squeeze-excitation, which significantly improves memory access speeds on the GPU.
*   **Compound Scaling:** The network width and depth are scaled moderately to fit a "Small" profile, ensuring the model remains lightweight (approx. 20M parameters) compared to larger variants.
*   **Classification Head:** The feature maps from the backbone are aggregated using a Global Average Pooling layer. This is followed by a single fully connected layer with output units equal to the number of unique classes (6: `scab`, `healthy`, `frog_eye_leaf_spot`, `rust`, `complex`, `powdery_mildew`).
*   **Activation:** A **Sigmoid** activation function is applied to the final logits to produce independent probabilities for each class, suitable for the multi-label classification task.

### Data
*   **Preprocessing:** Given the high resolution of the source images (mean ~4000x2600), all training and test images will be resized to a fixed square resolution of **256x256 pixels**. This drastic reduction is crucial for maintaining a high throughput baseline. Pixel values will be normalized using the dataset's mean and standard deviation calculated during the EDA phase.
*   **Augmentation:** To prevent overfitting without incurring high CPU overhead, only lightweight geometric augmentations will be applied during training:
    *   Random Horizontal Flip
    *   Random Vertical Flip
*   **Label Encoding:** The target labels will be encoded into a Multi-Hot binary vector (e.g., `[1, 0, 1, 0, 0, 0]` for an image with multiple diseases).

### Training
*   **Loss Function:** **Binary Cross-Entropy with Logits Loss (BCEWithLogitsLoss)** will be used. This loss function treats each class prediction as an independent Bernoulli distribution, which is the standard mathematical framework for multi-label classification.
*   **Optimizer:** The **AdamW** optimizer will be employed to decouple weight decay from gradient updates, promoting better generalization.
*   **Scheduler:** A **Cosine Annealing** learning rate scheduler will be used. It will start with a warm-up phase to stabilize the initial gradients and then gradually decrease the learning rate to fine-tune the weights.
*   **Strategy:** The model will be trained for a limited number of epochs (e.g., 10) to strictly adhere to the "speed" philosophy, using the validation set F1-score to monitor convergence.

### Evaluation
*   **Inference:** Test images will be resized to 256x256 and normalized identically to the training set.
*   **Prediction:** The model will output probability scores for all 6 classes. A fixed threshold of **0.5** will be applied to these scores. Any class with a probability > 0.5 will be included in the prediction string.
*   **Submission:** The predicted class names will be concatenated into a space-delimited string (e.g., "scab rust") for each image ID to generate the final submission file.
