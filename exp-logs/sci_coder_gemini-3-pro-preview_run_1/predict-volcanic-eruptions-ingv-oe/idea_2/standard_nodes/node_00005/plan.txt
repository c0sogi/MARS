To improve the model's performance, I will shift the feature engineering strategy from hierarchical (window-based) aggregation to global statistical aggregation. As highlighted in Lesson `solution_lesson_node_00004`, averaging statistics across local windows dilutes the signal of sparse, high-magnitude events (like seismic precursors). Instead, computing global statistics (e.g., max, 99th percentile) over the entire 10-minute segment preserves these critical signals. This approach also aligns with the successful baseline described in Lesson `solution_lesson_node_00001`.

I will modify `library/config.py` to remove windowing parameters and define the global statistics. Then, I will update `library/features.py` to implement the global feature extraction logic. The configuration change will automatically trigger a cache refresh (Cite `solution_lesson_node_00002`).
