Implementation Strategy:
1.  **Setup & Imports**: Import necessary standard libraries and the provided classes/configurations from the `library` package. Set the random seed for reproducibility.
2.  **Feature Extraction (Train)**: Load the training metadata and slice the first 20 rows to create a small dataset for rapid demonstration. Initialize `FeatureManager` and extract features for this subset, explicitly disabling cache loading to verify the extraction pipeline. Validate the output dimensions and data integrity.
3.  **Model Training**: Create a modified LightGBM configuration optimized for the small dataset (reduced estimators, adjusted tree parameters). Instantiate `CrossValidator` with this config and train on the extracted features. Verify that cross-validation scores are produced and model files are saved to the working directory.
4.  **Inference & Submission**: Load a small subset of the test metadata (5 rows) and extract features. Instantiate `InferenceModel` to load the previously trained models. Generate predictions and create a submission file. Validate the existence and format of the submission file.
