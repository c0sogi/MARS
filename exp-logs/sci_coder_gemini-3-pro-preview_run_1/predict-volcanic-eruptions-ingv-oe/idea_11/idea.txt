Based on the extensive analysis of prior experiments and the distilled lessons, I propose the **Magnitude-Preserving Hybrid Ensemble with Selective Feature Robustness**. This strategy structurally evolves the solution by resolving the conflict between "Robustness" (Lesson 00021) and "Signal Preservation" (Lesson 00032) through a **Multi-View Feature Engineering Paradigm**, and by implementing a novel **Global-Scale Normalization** for the Vision branch to fix the energy-loss failure of previous attempts.

# Model
The solution utilizes a **Heterogeneous Stacking Ensemble** combining a high-capacity Tabular Learner with a Magnitude-Aware Vision model.

1.  **Branch A: Multi-View Tabular Regressor (LightGBM)**
    *   **Architecture:** A Gradient Boosting Machine (LightGBM) optimized for a dense feature space.
    *   **Structural Innovation (Multi-View Robustness):** Instead of applying a blanket "robustness" policy (which deleted valuable extreme data in Idea 10) or a "kitchen sink" policy (which added spectral noise in Idea 5), we implement a **Domain-Specific Aggregation Policy**:
        *   **Time-Domain View:** Aggregates using **Full Statistics** (including Min, Max, Skew, Kurtosis) to preserve the magnitude of impulsive seismic events (Cite solution_lesson_node_00032).
        *   **Frequency-Domain View:** Aggregates using **Robust Statistics Only** (Mean, Std, Q05, Q95) for spectral features (FFT, MFCCs) to filter out transient spectral artifacts (Cite solution_lesson_node_00021).

2.  **Branch B: Global-Scale Vision Model (EfficientNet)**
    *   **Architecture:** An **EfficientNet-B0** CNN modified to accept 10-channel inputs.
    *   **Structural Innovation (Global-Scale Normalization):** To address the failure of Instance Standardization (which destroyed energy information in Idea 10) and the convergence issues of unnormalized data (Idea 3), we implement **Global Log-Max Scaling**. This normalizes inputs to a bounded range $[0, 1]$ using a *fixed global constant* derived from the training set, strictly preserving the relative energy differences between "quiet" and "loud" segments (Cite solution_lesson_node_00032).

3.  **Meta-Learner:**
    *   A **Ridge Regression** model (Unconstrained) trained on Out-of-Fold (OOF) predictions to optimally weigh the orthogonal contributions of the two branches (Cite solution_lesson_node_00027).

# Data
The data pipeline implements strict safeguards against stale data (Cite solution_lesson_node_00002) and enforces the specific feature engineering lessons.

1.  **Branch A Preprocessing (Tabular):**
    *   **Time-Domain Features:** Mean, Std, Skew, Kurtosis, Min, Max, Quantiles (0.01, 0.05, 0.95, 0.99).
    *   **Energy Features:** **Absolute Quantiles** (`quantile(abs(x))`) to measure polarity-independent signal power (Cite solution_lesson_node_00014).
    *   **Structural Features:** **Raw Zero-Crossing Rate** (without centering) to utilize signal offset as an amplitude gate (Cite solution_lesson_node_00007).
    *   **Spectral Features:** FFT Statistics (Mean, Std, Dominant Freq) and **MFCCs** restricted to **Coefficients 1-13** (Low-Order) to capture timbre without high-frequency noise (Cite solution_lesson_node_00025). **Wavelet Features** (Energy/Entropy) are also included.
    *   **Aggregation Rule:** Apply the **Multi-View Policy**: keep Min/Max for Time/Energy features; drop Min/Max for Spectral/MFCC features.
    *   **Spatial Features:** Correlation Matrix between all sensors (Cite solution_lesson_node_00017).
    *   **Exclusion:** Explicitly exclude raw gradients/derivatives (Cite solution_lesson_node_00020).

2.  **Branch B Preprocessing (Vision):**
    *   **Transformation:** Convert sensor data to Log-Mel Spectrograms.
    *   **Normalization:** Compute the global maximum value $M$ across a subset of the training data. Transform all spectrograms $X$ via $X_{norm} = \frac{\log(X + 1)}{\log(M + 1)}$. This bounds the input for the CNN while preserving the absolute magnitude information critical for predicting eruption time.
    *   **Target Scaling:** Apply **Log-Scaling** (`np.log1p`) to the `time_to_eruption` target (Cite solution_lesson_node_00009).

# Training
1.  **Strategy:** 5-Fold Cross-Validation for both branches.
2.  **Tabular Branch:** Train LightGBM with early stopping based on validation MAE.
3.  **Vision Branch:** Train using **AdamW** with **Cosine Annealing**. Extend training to **30+ epochs** to ensure convergence on the complex texture patterns (Cite solution_lesson_node_00017).
4.  **Meta-Learner:** Train Ridge Regression on the OOF predictions against the ground truth.

# Evaluation
1.  **Inference:**
    *   Generate the Multi-View Feature Matrix and Global-Scaled Spectrograms for the test set.
    *   Predict with LightGBM (Branch A).
    *   Predict with EfficientNet (Branch B) and apply **Inverse Target Transformation** (`np.expm1`).
2.  **Submission:** Input both prediction vectors into the trained Ridge Meta-Learner to produce the final `time_to_eruption` estimate.
