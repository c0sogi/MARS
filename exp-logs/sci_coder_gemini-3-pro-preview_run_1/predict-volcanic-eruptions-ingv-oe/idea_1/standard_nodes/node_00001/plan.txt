The implementation strategy follows the provided library structure to orchestrate the pipeline efficiently.

1.  **Setup & Data Loading**:
    -   Initialize the script and set random seeds for reproducibility.
    -   Load the training and validation data using `library.dataset.get_train_data(load_cached_data=True)`. This function handles feature extraction (calculating statistics like mean, std, quantiles per sensor) and caching.
    -   Load the test data using `library.dataset.get_test_data(load_cached_data=True)`.

2.  **Model Training**:
    -   Use `library.trainer.run_cross_validation` to train a LightGBM regressor.
    -   The training is performed on the `X_train` subset (derived from `metadata/train.csv`).
    -   A 5-fold cross-validation scheme is used, resulting in an ensemble of 5 trained models. This improves robustness compared to a single model.
    -   To ensure a "fast baseline" as requested, we rely on the efficiency of LightGBM and the relatively small dataset size (~3200 training samples), which allows training to complete in seconds without aggressive subsampling.

3.  **Validation & Evaluation**:
    -   Generate predictions on the hold-out validation set (`X_val`) using the ensemble of trained models via `library.trainer.predict`.
    -   Compute the **Mean Absolute Error (MAE)** between the predictions and `y_val`.
    -   Print the `Final Validation Metric` in the required format.

4.  **Failure Analysis**:
    -   Calculate the absolute error for each validation sample.
    -   Compute the Pearson correlation between the absolute error and all input features.
    -   Identify and print the top features that correlate most strongly with high errors, providing insight into where the model struggles (e.g., specific sensors or signal characteristics).

5.  **Inference & Submission**:
    -   Generate predictions for the test set (`X_test`) using the trained ensemble.
    -   Format the predictions into a DataFrame with `segment_id` and `time_to_eruption`.
    -   Save the final submission file to `./submission/submission.csv` using `library.inference.predict_and_submit`.
