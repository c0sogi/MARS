The following script demonstrates the usage of the provided library files to execute a complete machine learning pipeline for seismic eruption prediction.

### Implementation Strategy

1.  **Configuration Override**: We first import the `Config` class and override key parameters (e.g., `DEBUG=True`, `EPOCHS=1`, `N_FOLDS=2`) to ensure the script executes quickly within the provided environment. We also redirect output paths to a temporary `demo_run` directory to avoid conflicts with existing caches.
2.  **Feature Engineering**: We instantiate the `FeatureEngineer` class and manually trigger the generation of tabular and vision features for a small subset of the training data. This demonstrates how to create the inputs required for the models.
3.  **Component Verification**:
    *   **Dataset**: We instantiate `SeismicDataset` using the generated features and verify that it correctly loads dual-resolution spectrograms, scalar features, and targets.
    *   **Model**: We instantiate the `ScalarFusedEfficientNet` (CNN) and perform a forward pass with a batch of data to verify the architecture and output dimensions.
4.  **Full Pipeline Execution**: We call the `run_training()` function from `train_eval.py`. This function orchestrates the entire workflow: loading data, running 5-fold cross-validation for both LightGBM and CNN models, stacking their predictions using a Meta-Learner, and generating a submission file.
5.  **Validation**: Throughout the script, assertions are used to confirm that files are created, shapes are correct, and the pipeline completes successfully.
