Based on the analysis of the previous experiments and the distilled lessons, I propose the **Dual-Resolution Scalar-Fused Stacking Strategy**. This approach structurally evolves the solution by combining the successful **Dual-Resolution** vision backbone (Idea 12) with a **Normalized Scalar Fusion** mechanism, specifically correcting the "Feature Scale Mismatch" failure of Idea 13 (Cite solution_lesson_node_00044) to guarantee the model utilizes absolute signal magnitude.

# Model
The solution utilizes a **Heterogeneous Stacking Ensemble** designed to explicitly capture the absolute energy evolution of the seismic signals through both expert feature engineering and multi-modal deep learning.

1.  **Branch A: Energy-Partitioned Tabular Regressor (LightGBM)**
    *   **Architecture:** A Gradient Boosting Machine (LightGBM) optimized for a feature space that prioritizes absolute magnitude.
    *   **Feature Engineering Policy (Multi-View Robustness):**
        *   **Time/Energy Domain:** We retain **Full Statistics** (including Min, Max, Kurtosis) and **Absolute Quantiles** (`quantile(abs(x))`) to explicitly preserve the magnitude of extreme seismic events (Cite solution_lesson_node_00032, solution_lesson_node_00014).
        *   **Spectral Domain:** We use **Robust Statistics Only** (Mean, Std, Q05, Q95) for MFCCs and FFTs to avoid transient noise artifacts (Cite solution_lesson_node_00021).
    *   **Structural Innovation (Sub-band Energy):** To address the magnitude-blindness of standard spectral features, we explicitly engineer **Log-Subband Energies**. We divide the spectrum into distinct bands (e.g., 0-2Hz, 2-5Hz) and calculate the log-sum-squared magnitude for each, providing the model with granular, intensity-aware spectral descriptors (Cite solution_lesson_node_00037).

2.  **Branch B: Dual-Resolution Scalar-Fused Vision Model (EfficientNet)**
    *   **Architecture:** An **EfficientNet-B0** CNN modified to accept **20 input channels** (2 views per sensor).
    *   **Input 1 (Dual-Resolution Spectrograms):** For each sensor, we generate two Log-Mel Spectrograms: one with a **Short Window** (high time resolution for shocks) and one with a **Long Window** (high frequency resolution for tremors). These are stacked channel-wise (Cite solution_lesson_node_00015).
    *   **Input 2 (Normalized Scalar Injection):** We extract a vector of global energy statistics (Log-Total-Energy, Global Max, Crest Factor).
    *   **Structural Innovation (Normalized Fusion):** Unlike Idea 13, which failed due to scale mismatch, we apply **Batch Normalization** to the scalar vector *before* concatenating it with the CNN's image embedding in the dense layer. This ensures the gradients from the high-magnitude scalars do not destabilize the network, allowing the model to safely use "Volume" information to scale its predictions (Cite solution_lesson_node_00044).

3.  **Meta-Learner:**
    *   A **Ridge Regression** model (Unconstrained) trained on Out-of-Fold (OOF) predictions. This allows the ensemble to optimally weigh the orthogonal contributions of the Tabular and Vision branches (Cite solution_lesson_node_00027).

# Data
The data pipeline implements strict safeguards against stale data using **Configuration Hashing** (Cite solution_lesson_node_00002).

1.  **Branch A Preprocessing (Tabular):**
    *   **Features:** Sub-band Energies, Crest Factor (Cite solution_lesson_node_00037), Robust MFCCs (Coefficients 1-13) (Cite solution_lesson_node_00025), Absolute Quantiles, Raw Zero-Crossing Rate (Cite solution_lesson_node_00007), and Spatial Correlation (Cite solution_lesson_node_00017).
    *   **Exclusion:** Explicitly exclude raw gradients/derivatives (Cite solution_lesson_node_00020).

2.  **Branch B Preprocessing (Vision):**
    *   **Spectrograms:** Generate Dual-Resolution Log-Mel Spectrograms. Normalize via **Global Log-Max Scaling**: $X_{norm} = \frac{\log(X + 1)}{\log(M_{global} + 1)}$, where $M_{global}$ is a fixed constant from the training set. This preserves relative energy differences between segments (Cite solution_lesson_node_00032).
    *   **Target Scaling:** Apply **Log-Scaling** (`np.log1p`) to the `time_to_eruption` target to prevent convergence failure (Cite solution_lesson_node_00009).

# Training
1.  **Strategy:** 5-Fold Cross-Validation for both branches to generate aligned OOF predictions.
2.  **Tabular Branch:** Train LightGBM with early stopping based on validation MAE.
3.  **Vision Branch:** Train using **AdamW** with **Cosine Annealing**. Extend training to **30+ epochs** to ensure convergence on the complex dual-resolution features (Cite solution_lesson_node_00017).
4.  **Meta-Learner:** Train Ridge Regression on the OOF predictions against the ground truth.

# Evaluation
1.  **Inference:**
    *   Generate Energy-Partitioned Tabular Features and Dual-Resolution Spectrograms + Normalized Scalars for the test set.
    *   Predict with LightGBM (Branch A).
    *   Predict with EfficientNet (Branch B) and apply **Inverse Target Transformation** (`np.expm1`).
2.  **Submission:** Input both prediction vectors into the trained Ridge Meta-Learner to produce the final `time_to_eruption` estimate.
