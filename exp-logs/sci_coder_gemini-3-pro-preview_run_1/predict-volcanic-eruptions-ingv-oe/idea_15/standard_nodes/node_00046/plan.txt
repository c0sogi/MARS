Implementation Strategy:
1.  **Environment Setup**: Initialize the environment and set random seeds using `seed_everything` for reproducibility.
2.  **Configuration Override**: Dynamically adjust `Config.EPOCHS` to 10 (down from 35) to ensure the training completes within the "Fast Baseline" time constraints while maintaining sufficient convergence.
3.  **Data Processing**:
    *   Instantiate `FeatureEngineer`.
    *   Process the **Training** set (`metadata/train.csv`), **Validation** set (`metadata/val.csv`), and **Test** set (`metadata/test.csv`) to generate tabular features, scalars, and spectrograms. Use caching (`load_cached_data=True`) to speed up execution.
4.  **Model Training**:
    *   Execute `run_tabular_cv` to train the LightGBM ensemble on the training set.
    *   Execute `run_vision_cv` to train the EfficientNet-FiLM ensemble on the training set.
    *   Train the Ridge Regression **Meta-Learner** using the Out-of-Fold (OOF) predictions from both branches.
5.  **Hold-out Validation**:
    *   Perform inference on the processed **Validation** set (`df_val`) using the trained models.
    *   Apply the Meta-Learner to combine predictions.
    *   Calculate and print the **Final Validation Metric** (MAE) with full precision.
6.  **Failure Analysis**:
    *   Calculate absolute errors for the validation set.
    *   Compute and print correlations between the error magnitude and input features to identify failure modes.
7.  **Submission**:
    *   Compare the validation MAE against the threshold (`1920624.12`).
    *   If the metric is below the threshold, call `generate_submission` to predict on the test set and save `submission.csv`.
