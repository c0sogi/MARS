This script demonstrates the usage of the provided Seismic Eruption Prediction library. It performs the following steps:

1.  **Setup**: Creates a temporary working environment and generates "mini" metadata files (subsets of the original data) to ensure the demonstration runs quickly.
2.  **Configuration**: Overrides global `Config` parameters (paths, hyperparameters) to use the mini datasets and reduce training time (e.g., fewer epochs, fewer estimators).
3.  **Feature Engineering**: Demonstrates how to generate statistical and signal processing features using `generate_feature_matrix`.
4.  **LightGBM Pipeline**: Runs the LightGBM cross-validation pipeline (`run_lgbm_cv`) on the mini dataset.
5.  **Deep Learning Data Loading**: Demonstrates the `SeismicDataset` class for loading and preprocessing raw sensor data on-the-fly.
6.  **ResNet Pipeline**: Runs the 1D-ResNet cross-validation pipeline (`run_resnet_cv`) on the mini dataset.
