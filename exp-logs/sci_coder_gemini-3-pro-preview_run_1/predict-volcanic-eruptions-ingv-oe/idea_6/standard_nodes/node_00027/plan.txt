The previous implementation of the stacking meta-learner suffered from data leakage, as it was trained and evaluated on the same Out-Of-Fold (OOF) predictions, resulting in an invalid validation metric (Cite debug_lesson_3). Additionally, the use of Ridge Regression (minimizing MSE) was suboptimal for the competition's MAE metric.

To fix this:
1.  In `library/model_stacking.py`, I will replace the `Ridge`-based `MetaLearner` with a `MaeBlender` that performs a grid search to find the optimal weighted average of the base models (Tabular and Vision) to directly minimize MAE.
2.  In `runfile.py`, I will implement K-Fold Cross-Validation for the meta-learner. This ensures that the "Stacked OOF" predictions used for the final validation score are generated on data not seen during the blender's weight optimization. I will also ensure the meta-learner is retrained on the full OOF dataset before generating the final submission if the threshold is met.

from sklearn.base import BaseEstimator, RegressorMixin
from sklearn.metrics import mean_absolute_error

from library.config import Config
from library.utils import seed_everything, get_score


class MetaLearner(BaseEstimator, RegressorMixin):
    """
    Implements a Stacking Meta-Learner that optimizes for MAE directly.
    Replaces Ridge Regression (MSE) with a grid-search Weighted Blender.
    """

    def __init__(self):
        self.config = Config()
        self.weights = None

    def train(self, X, y):
        """
        Trains the Blender by finding the optimal weight 'w' that minimizes MAE.
        Model: preds = w * col0 + (1-w) * col1

        Args:
            X (pd.DataFrame or np.ndarray): Input features (predictions from base models).
            y (pd.Series or np.ndarray): Ground truth targets.
        """
        X_arr = np.array(X)
        y_arr = np.array(y)

        best_mae = float('inf')
        best_w = 1.0  # Default to first model (Tabular) if unsure

        # Grid search for optimal weight in [0, 1]
        # Since we have only 2 models, this is efficient and robust
        for w in np.linspace(0.0, 1.0, 101):
            preds = w * X_arr[:, 0] + (1 - w) * X_arr[:, 1]
            mae = np.mean(np.abs(y_arr - preds))
            if mae < best_mae:
                best_mae = mae
                best_w = w

        self.weights = [best_w, 1.0 - best_w]

    def predict(self, X):
        """
        Predicts using the trained weights.

        Args:
            X (pd.DataFrame or np.ndarray): Input features.

        Returns:
            np.ndarray: Predictions.
        """
        X_arr = np.array(X)
        preds = self.weights[0] * X_arr[:, 0] + self.weights[1] * X_arr[:, 1]
        # Ensure non-negative predictions
        return np.maximum(0, preds)
