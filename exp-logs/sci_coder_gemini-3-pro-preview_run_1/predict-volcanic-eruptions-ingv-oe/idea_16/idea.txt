Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose the **Trend-Augmented Spectral Stacking Strategy**. This approach structurally evolves the "Current Best" Idea 13 by addressing its primary weakness—the lack of explicit temporal evolution modeling in the tabular branch—while rigorously maintaining the "Global-Scale" and "Domain-Specific" constraints that defined its success.

# Model
The solution utilizes a **Heterogeneous Stacking Ensemble** designed to capture the three critical dimensions of seismic prediction: Global Magnitude, Temporal Intensification, and Spectral Texture.

1.  **Branch A: Trend-Aware Tabular Regressor (LightGBM)**
    *   **Architecture:** A Gradient Boosting Machine (LightGBM) optimized for a feature space that models both static magnitude and dynamic evolution.
    *   **Structural Innovation (Segmented Trend Features):** To capture the *acceleration* of seismic activity (a critical precursor) without the signal dilution caused by averaging (Cite solution_lesson_node_00004), we implement a **Segmented Feature Extraction** paradigm. We divide the 10-minute segment into three overlapping blocks (Start, Middle, End). For the most predictive high-energy metrics (Sub-band Energies, Absolute Quantiles), we compute the values for each block and extract **Trend Features** (e.g., `End_Value - Start_Value`). This explicitly models the intensification of the tremor over the 10-minute window.
    *   **Feature Policy (Multi-View Robustness):**
        *   **Domain-Specific Bands:** We replace generic spectral descriptors with **Log-Subband Energies** calculated over physically relevant frequency bands (e.g., 0-2Hz, 2-5Hz, 5-10Hz) to capture volcanic tremor harmonics (Cite solution_lesson_node_00046).
        *   **Robustness:** We retain **Full Statistics** (Min, Max, Kurtosis) for Time/Energy features to preserve extreme events (Cite solution_lesson_node_00032) but use **Robust Statistics Only** (Mean, Std, Q05, Q95) for MFCCs to filter spectral noise (Cite solution_lesson_node_00021).

2.  **Branch B: Global-Scaled Vision Model (EfficientNet)**
    *   **Architecture:** An **EfficientNet-B0** CNN modified to accept **Single-Resolution** 10-channel spectrogram inputs (Cite solution_lesson_node_00045).
    *   **Normalization Strategy:** We strictly enforce **Global Log-Max Scaling** ($X_{norm} = \frac{\log(X + 1)}{\log(M_{global} + 1)}$), using a fixed global maximum derived from the training set. This preserves the absolute energy differences between segments, which Instance Standardization destroys (Cite solution_lesson_node_00032).
    *   **Target Scaling:** We apply **Log-Scaling** (`np.log1p`) to the `time_to_eruption` target to prevent convergence failure (Cite solution_lesson_node_00009).

3.  **Meta-Learner:**
    *   A **Ridge Regression** model (Unconstrained) trained on Out-of-Fold (OOF) predictions. This allows the ensemble to optimally weigh the orthogonal contributions of the Tabular and Vision branches, correcting systematic biases without the constraints of a weighted average (Cite solution_lesson_node_00027).

# Data
The data pipeline implements strict safeguards against stale data using **Configuration Hashing** (Cite solution_lesson_node_00002).

1.  **Branch A Preprocessing (Tabular):**
    *   **Trend Features:** Compute `Log_Energy_Band_X` and `Abs_Quantile_99` for 3 temporal blocks. Calculate gradients.
    *   **Static Features:** Global Sub-band Energies, Robust MFCCs (Coefficients 1-13 only, Cite solution_lesson_node_00025), Absolute Quantiles (Cite solution_lesson_node_00014), Raw Zero-Crossing Rate (Cite solution_lesson_node_00007), and Spatial Correlation (Cite solution_lesson_node_00017).
    *   **Exclusion:** Explicitly exclude raw gradients (Cite solution_lesson_node_00020) and beamforming aggregation (Cite solution_lesson_node_00029).

2.  **Branch B Preprocessing (Vision):**
    *   **Spectrograms:** Generate Single-Resolution Log-Mel Spectrograms ($N_{FFT}=1024$).
    *   **Normalization:** Apply Global Log-Max Scaling.
    *   **Target:** Apply Log-Scaling to the target variable.

# Training
1.  **Strategy:** 5-Fold Cross-Validation for both branches to generate aligned OOF predictions.
2.  **Tabular Branch:** Train LightGBM with early stopping based on validation MAE.
3.  **Vision Branch:** Train using **AdamW** with **Cosine Annealing**. Extend training to **30+ epochs** to ensure convergence on the complex texture patterns (Cite solution_lesson_node_00017).
4.  **Meta-Learner:** Train Ridge Regression on the OOF predictions against the ground truth.

# Evaluation
1.  **Inference:**
    *   Generate Trend-Aware Tabular Features and Global-Scaled Spectrograms for the test set.
    *   Predict with LightGBM (Branch A).
    *   Predict with EfficientNet (Branch B) and apply **Inverse Target Transformation** (`np.expm1`).
2.  **Submission:** Input both prediction vectors into the trained Ridge Meta-Learner to produce the final `time_to_eruption` estimate.
