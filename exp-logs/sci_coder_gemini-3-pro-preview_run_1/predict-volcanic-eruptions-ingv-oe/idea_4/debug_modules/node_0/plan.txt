### Implementation Strategy

    -   Reduce the number of epochs for the CNN and estimators for LightGBM.
    -   Reduce the number of cross-validation folds.
    -   Disable heavy logging.
3.  **Mini-Dataset Creation**: We will generate small CSV files (`mini_train.csv`, `mini_val.csv`, `mini_test.csv`) in the `./working` directory. These will reference a few valid files existing in the `./input` directory (based on the provided dataset description) to serve as a lightweight dataset for demonstration.
