The strategy is to create a Python script that reads the raw JSONL files from the `./input` directory, extracts the necessary metadata (example IDs, document URLs for grouping, and annotations), and stores this information in Parquet format in the `./metadata` directory. To ensure a proper validation split, the script will use `GroupShuffleSplit` on the training data based on the `document_url` field, preventing information leakage from the same Wikipedia article between training and validation sets. The script will also generate metadata for the test set without splitting. Finally, the script will include a verification step to load the generated metadata, calculate summary statistics, check for the existence of the referenced files, and assert that the training and validation sets have no overlapping document groups.
