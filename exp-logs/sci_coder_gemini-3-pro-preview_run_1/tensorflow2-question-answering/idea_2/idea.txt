Based on the provided Model Architectures and the constraints for a high-efficiency baseline, here is the proposed solution.

### **Model: Dual-Encoder Convolutional Network (DE-ConvNet)**

This approach synthesizes the **convolutional efficiency of Model 2** with the **two-stage ranking logic of Model 4**, replacing complex attention mechanisms and recurrent layers with lightweight 1D-Convolutions and linear classifiers.

*   **Long Answer Ranker (Siamese 1D-CNN):**
    *   **Architecture:** A Siamese network that processes the **Question** and **Candidate Text** in parallel branches.
    *   **Embedding:** Uses fixed, pre-trained word embeddings (e.g., GloVe) to avoid the computational overhead of training embeddings from scratch or using heavy Transformers.
    *   **Encoding:** Each branch utilizes a **1D-Convolutional Layer** (with multiple filter sizes, e.g., 3, 4, and 5) followed by **Global Max Pooling**. This efficiently captures local n-gram patterns (e.g., specific phrases or dates) and creates a fixed-size dense vector representation for both the question and the candidate.
    *   **Interaction & Classification:** The two vector representations are combined via concatenation and element-wise multiplication. This fused vector is passed through a small Feed-Forward Network (FFN) with a sigmoid activation to output a relevance probability.
*   **Short Answer Extractor (Sliding Window Logistic Regression):**
    *   Instead of a complex pointer network, a simple **Logistic Regression** model is used.
    *   It evaluates sliding windows of tokens (e.g., windows of 5 to 10 words) within the selected Long Answer.
    *   **Features:** Lightweight handcrafted features for each window, such as "Contains Digit", "Is Capitalized", and "Exact Match Count with Question Tokens".

### **Data**

*   **Preprocessing:**
    *   **Tokenization:** Perform simple whitespace tokenization and map tokens to the pre-trained embedding vocabulary. Unknown words are mapped to a generic `<UNK>` token.
    *   **Truncation:** Truncate Long Answer candidates to a fixed length (e.g., 300 tokens) to ensure consistent and fast tensor operations on the GPU.
    *   **Window Generation:** For the Short Answer model, generate sliding windows from the ground-truth Long Answers. Windows with high Intersection-over-Union (IoU) with the ground-truth short answer are labeled as positive (`1`); others are negative (`0`).
*   **Subsampling:** To handle the massive class imbalance in the Long Answer task, construct the training set by keeping all positive examples and randomly sampling negative candidates (e.g., at a 1:5 ratio).

### **Training**

*   **Long Answer Model:** Train the Siamese 1D-CNN using **Binary Cross Entropy Loss** and the Adam optimizer.
*   **Short Answer Model:** Train the Logistic Regressor independently using the windows generated from valid Long Answers in the training set.
*   **Strategy:** Use Early Stopping based on the validation set's Micro F1 score to prevent overfitting and minimize training time.

### **Evaluation**

1.  **Ranking:** Pass all `(Question, Candidate)` pairs in the test set through the trained **DE-ConvNet** to obtain relevance probabilities.
2.  **Long Answer Selection:** Identify the candidate with the highest probability. If this probability is below a tuned threshold $\alpha$, predict `NULL` (No Answer). Otherwise, select it as the predicted Long Answer.
3.  **Short Answer Extraction:** If a Long Answer is selected, run the **Sliding Window Logistic Regressor** over its text.
4.  **Final Prediction:** Select the window with the highest regression score. If this score exceeds a secondary threshold $\beta$, predict it as the Short Answer; otherwise, predict a Long Answer only. Format the resulting token indices for submission.
