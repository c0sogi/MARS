The `TypeError` arises because the `vocabulary_` attributes of scikit-learn vectorizers contain NumPy `int64` values, and `avgdl` in `BM25Transformer` is a NumPy float, neither of which are natively serializable by Python's `json` module. I will modify `BM25Transformer.save_state` and `FeatureGenerator._save_state` in `library/feature_engineering.py` to explicitly cast these NumPy types to standard Python `int` and `float` types before serialization.
