This `nan` value bypassed the exception handler and propagated through the pipeline, causing the final validation check to fail. The fix involves manually iterating through each class column, checking if it contains both positive and negative samples, calculating the AUC for valid classes only, and returning the average. def compute_auc(y_true, y_pred):
    """
    Computes the Area Under the ROC Curve (ROC AUC) robustly.
    Calculates AUC per class and averages only valid scores (ignoring classes with only one label).

    Args:
        y_true (np.ndarray): Ground truth binary labels (N, num_classes).
        y_pred (np.ndarray): Predicted probabilities (N, num_classes).

    Returns:
        float: Macro-averaged ROC AUC score.
    """
    aucs = []
    num_classes = y_true.shape[1]

    for i in range(num_classes):
        # Check if the class has both 0s and 1s
        if len(np.unique(y_true[:, i])) > 1:
            try:
                score = roc_auc_score(y_true[:, i], y_pred[:, i])
                aucs.append(score)
            except ValueError:
                # Should not happen given the unique check, but safe fallback
                pass

    if len(aucs) == 0:
        return 0.0

    return np.mean(aucs)
