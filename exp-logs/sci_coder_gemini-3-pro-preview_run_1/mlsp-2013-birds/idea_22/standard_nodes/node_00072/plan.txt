Implementation strategy:
1.  **Setup & Initialization**: Set random seeds for reproducibility and initialize logging.
2.  **Stage 1: Teacher Ensemble Training**:
    - Iterate 3 times to train three independent `ResNet-34` Teacher models on the labeled training set (Fold 0).
    - Use `DynamicBatchCollate` for temporal jittering and `Mixup` for augmentation.
    - Employ `CosineAnnealingLR` and `SWA` (Stochastic Weight Averaging) to maximize generalization.
    - Save the SWA checkpoint for each teacher.
3.  **Stage 2: Pseudo-Label Generation**:
    - Load the 3 trained Teacher SWA models.
    - Perform Multi-Scale Test-Time Augmentation (TTA) on the Test Set (Fold 1) using `inference.predict_ensemble_tta`. This averages predictions across models, scales, and flips.
    - Save the resulting soft pseudo-labels to a Parquet file.
4.  **Stage 3: Student Training**:
    - Initialize a single `ResNet-34` Student model.
    - Train on the combined dataset (Labeled Train + Pseudo-Labeled Test) using the same augmentation and SWA strategy as the teachers.
    - Save the final Student SWA model.
5.  **Evaluation**:
    - Validate the Student model on the hold-out Validation Set (Fold 0 Val) using single-scale inference.
    - Compute and print the `Final Validation Metric` (ROC AUC).
6.  **Failure Analysis**:
    - Calculate the Mean Absolute Error (MAE) per sample on the validation set.
    - Correlate the error with pre-computed histogram features to identify failure modes.
    - Print the top 5 correlated features.
7.  **Submission**:
    - If the validation AUC exceeds the threshold (0.9594082190886809), generate the submission file using the Student model and save it to `./submission/submission.csv`.
