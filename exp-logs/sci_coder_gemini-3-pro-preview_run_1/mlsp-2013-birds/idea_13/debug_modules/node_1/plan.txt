The issue is that the `roc_auc_score` function with `average='macro'` returns `nan` (instead of raising an error) when the validation set is small or imbalanced and contains "degenerate" classes (classes with only negative or only positive samples). This causes the downstream assertion `assert 0.0 <= val_auc <= 1.0` to fail. To fix this, I will manually iterate through each class, verify that it contains both positive and negative samples before calculating the AUC, and then compute the mean of these valid scores. This approach explicitly handles degenerate subsets as recommended in **Cite debug_lesson_5**.
