This is an implementation of the optimized ResNet-50 ensemble strategy.

### Strategy Outline
1.  **Setup & Data Loading**: Initialize configuration and seeds. Load the training data (`metadata/train.csv`) and the fixed hold-out validation data (`metadata/val.csv`).
2.  **Stratified 5-Fold Cross-Validation**:
    - Split the training data into 5 stratified folds to handle class imbalance.
    - For each fold, train a `BirdResNet` (ResNet-50) model.
    - Use `BirdDataset` (random crops, Mixup, SpecAugment) for training and `InferenceDataset` (sliding window) for inner-fold validation (Early Stopping).
    - Store the best model from each fold.
3.  **Ensemble Inference**:
    - Implement a custom `get_predictions` function that replicates the sliding window logic from the provided engine but aggregates probabilities across the 5-model ensemble.
    - Run this ensemble inference on the hold-out validation set.
4.  **Evaluation**:
    - Compute the macro-averaged ROC AUC on the hold-out set.
    - Print the required metric string.
5.  **Failure Analysis**:
    - Calculate the Mean Absolute Error (MAE) per sample on the validation set.
    - Compute simple signal features (Mean Intensity, Standard Deviation) for validation images.
    - Calculate and print the Pearson correlation between error magnitude and these features.
6.  **Submission**:
    - If the validation AUC exceeds the threshold (0.9255537489325414), load the test data (`metadata/test.csv`).
    - Generate ensemble predictions for the test set.
    - Format and save `submission.csv`.
