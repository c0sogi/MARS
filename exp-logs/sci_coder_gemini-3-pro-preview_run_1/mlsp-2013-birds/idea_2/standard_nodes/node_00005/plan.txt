The implementation strategy involves creating a main execution script `runfile.py` that orchestrates the entire machine learning pipeline using the provided library modules. 

1.  **Configuration & Setup**: I will import the `Config` class and override the `EPOCHS` parameter to 20 to ensure the training completes quickly while still allowing convergence on the small dataset. I will set the random seed for reproducibility.
2.  **Data Loading**: I will utilize the `BirdDataset` class and `get_transforms` to load the training, validation, and test datasets. `load_cached_data=True` will be used to leverage any pre-processed metadata.
3.  **Model Initialization**: I will instantiate the ResNet-34 model using `get_model`, along with the AdamW optimizer and Cosine Annealing scheduler as defined in the library.
4.  **Training Loop**: I will implement a custom training loop that iterates through epochs, calling `train_one_epoch` and `validate` from the `library.trainer` module. This loop will include logic to track the best validation AUC and save the best model state to `Config.BEST_MODEL_PATH`.
5.  **Final Evaluation**: After training, I will load the best model weights and perform inference on the full validation set. This allows me to compute the `Final Validation Metric` (AUC) and gather predictions for failure analysis.
6.  **Failure Analysis**: I will compute the Mean Absolute Error (MAE) for each validation sample. I will then calculate the correlation between this error magnitude and two input features: the signal intensity (mean pixel value of the spectrogram) and the label complexity (number of active species). This fulfills the requirement to identify systematic error patterns.
7.  **Submission Logic**: I will compare the final validation AUC against the specified threshold (0.6514627421758025). If the metric exceeds this value, I will generate predictions for the test set using the `predict` function and save them to `submission.csv` using `save_submission`.
