Based on the comprehensive analysis of previous experiments and the "Lessons Learned," I propose the **Iterative Attentive SWA-Distillation with High-Fidelity Alignment**.

This strategy introduces a structural innovation—**Iterative Self-Distillation (Multi-Generational Training)**—to the semi-supervised pipeline. By extending the distillation process to a second generation (where the first Student becomes the Teacher), we refine the quality of the pseudo-labels further, leveraging the unlabeled test data more effectively than a single-pass approach. This is coupled with the **SE-ResNet-34** architecture and rigorous corrections for the implementation failures (normalization, seeding, scheduling) identified in previous attempts.

### Model
*   **Backbone:** Utilize the **SE-ResNet-34** (Squeeze-and-Excitation ResNet) architecture initialized with ImageNet weights.
    *   *Rationale:* This architecture integrates lightweight **Channel Attention** (SE blocks) into the robust ResNet-34 backbone. This explicitly addresses the "cocktail party" problem by allowing the model to adaptively recalibrate feature responses, emphasizing frequency channels containing bird calls while suppressing noise, a capability lacking in standard ResNet-34 **Cite solution_lesson_node_00012**.
*   **Classification Head:** Use a standard **Linear Layer** projecting to the 19 species classes, strictly avoiding complex aggregation heads to minimize overfitting **Cite solution_lesson_node_00007**.

### Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Resolution:** Resize images to **256 pixels (Height) x 640 pixels (Width)**. This preserves the native frequency resolution **Cite solution_lesson_node_00013** and captures fine-grained temporal morphology **Cite solution_lesson_node_00041**. Crucially, all models in the iterative pipeline will operate at this resolution to prevent knowledge dilution **Cite solution_lesson_node_00036**.
    *   **Input Adaptation:** Use **Channel Replication** (grayscale to RGB) **Cite solution_lesson_node_00022**.
    *   **Normalization (Critical Fix):** Explicitly apply **ImageNet Mean and Standard Deviation normalization**. This corrects the distribution shift that caused the failure of previous SE-ResNet attempts **Cite solution_lesson_node_00045**.
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Use purely dynamic in-memory loading without disk caching **Cite solution_lesson_node_00018**.
    *   **Deterministic Seeding (Critical Fix):** Explicitly pass a fixed seed to the NumPy `default_rng()` generator within augmentation classes to ensure reproducibility and prevent hidden variance **Cite solution_lesson_node_00043**.
*   **Augmentation:**
    *   **Unstructured Cutout:** Apply random rectangular masks to preserve partial features of short signals **Cite solution_lesson_node_00038**.
    *   **Horizontal Flip:** Enable random time inversion **Cite solution_lesson_node_00039**.
    *   **Conservative Mixup:** Apply Mixup with **alpha = 0.2** **Cite solution_lesson_node_00030**.

### Training
I will implement a **Four-Stage Iterative Pipeline** with extended schedules to ensure convergence **Cite solution_lesson_node_00044**:

1.  **Stage 1: Attentive Teacher Ensemble**
    *   Train **3 independent SE-ResNet-34 models** on the labeled training set (Fold 0).
    *   **Schedule:** Train for **50 epochs**. Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs **Cite solution_lesson_node_00028**.
    *   **Loss:** BCEWithLogitsLoss **Cite solution_lesson_node_00008**.

2.  **Stage 2: Generation 1 Distillation (Ensemble -> Student 1)**
    *   Generate predictions for the Test Set (Fold 1) using the 3 Teachers with **Test-Time Augmentation (TTA)** (Horizontal Flips). Average the predictions to create robust pseudo-labels.
    *   **Sanitize:** Assert no `NaN` values **Cite solution_lesson_node_00027**.
    *   Train **Student 1 (SE-ResNet-34)** on the Combined Dataset (Labeled + Pseudo-Labeled).
    *   **Schedule:** 50 epochs with SWA.

3.  **Stage 3: Generation 2 Distillation (Student 1 -> Student 2)**
    *   **Structural Innovation:** Use the converged **Student 1** (which typically outperforms the teachers) to re-generate pseudo-labels for the Test Set using TTA.
    *   Train **Student 2 (SE-ResNet-34)** on the Combined Dataset using these refined targets. This second iteration allows the model to learn from cleaner, higher-confidence labels derived from a model that has already seen the test distribution.
    *   **Schedule:** 50 epochs with SWA.

### Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, apply **ImageNet Normalization**, and perform a single forward pass using the final **Student 2** model.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities.
