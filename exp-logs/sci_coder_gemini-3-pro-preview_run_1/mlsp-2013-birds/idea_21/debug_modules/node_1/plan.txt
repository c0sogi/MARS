The error is caused by the `BirdDataset` class using implicit pattern matching (`startswith("species_")`) to identify label columns. The metadata files contain 20 label columns (indices 0-19) due to an upstream discrepancy, but the `Config` and task description specify only 19 classes. This results in the dataset yielding 20-dimensional target vectors, causing a shape mismatch assertion failure against the expected 19 dimensions.

To fix this, I will modify `BirdDataset` and `get_dataloaders` to explicitly construct the list of label columns using `Config.NUM_CLASSES` (Cite debug_lesson_1). This ensures the dataset strictly adheres to the configuration and ignores any extraneous columns in the data files.
