Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Manifold-Regularized High-Fidelity SWA-Distillation**.

This strategy introduces a structural innovation—**Manifold Mixup**—to the training pipeline. While previous successful attempts utilized Input Mixup (Cite solution_lesson_node_00030), this approach extends the regularization into the hidden layers of the network. By interpolating hidden representations, we force the model to learn smoother, more robust decision boundaries in the deep feature space, which is critical for generalization in micro-data regimes (N=208). This is combined with the proven **High-Fidelity (640px)** resolution and **Single-Stage Distillation** pipeline, while strictly adhering to the architectural constraints (Vanilla ResNet-34) identified in Lesson 00056 and Lesson 00068.

### Model
*   **Backbone:** Utilize the **Vanilla ResNet-34** architecture initialized with ImageNet weights.
    *   *Strategic Retention:* This backbone is retained as the optimal choice. It outperforms MLPs (Cite solution_lesson_node_00006) and avoids the suppression of co-occurring classes observed with SE-ResNet architectures in multi-label tasks (Cite solution_lesson_node_00056).
    *   *Structural Innovation (Manifold Mixup):* Modify the forward pass to support **Manifold Mixup**. Instead of only mixing input images, the model will randomly select a layer $k \in \{Input, Layer1, Layer2\}$ at each step. It will process the batch up to layer $k$, apply the Mixup interpolation on the intermediate feature maps, and then continue the forward pass. This regularizes the model more deeply than standard Input Mixup.
*   **Classification Head:** Use a standard **Linear Layer** projecting to the 19 species classes, strictly avoiding complex aggregation heads (Cite solution_lesson_node_00007).
*   **Input Adaptation:** Use **Channel Replication** (copying the single-channel spectrogram to R, G, and B inputs) to preserve natural image statistics (Cite solution_lesson_node_00022).

### Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Resolution:** Resize images to **256 pixels (Height) x 640 pixels (Width)**. This resolution preserves the native frequency resolution (Cite solution_lesson_node_00013) and captures the fine-grained temporal morphology required for high performance (Cite solution_lesson_node_00041). Crucially, both Teachers and Student will operate at this resolution to prevent knowledge dilution (Cite solution_lesson_node_00036).
    *   **Normalization:** Explicitly apply **ImageNet Mean and Standard Deviation normalization**. This is mandatory to uphold the transfer learning contract (Cite solution_lesson_node_00045).
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Implement purely dynamic in-memory loading without disk caching to prevent stale data issues (Cite solution_lesson_node_00018).
    *   **Deterministic Seeding:** Explicitly pass a fixed seed to the NumPy `default_rng()` generator within augmentation classes to prevent hidden variance (Cite solution_lesson_node_00043).
*   **Augmentation:**
    *   **Unstructured Cutout:** Apply random rectangular masks (Cite solution_lesson_node_00038).
    *   **Horizontal Flip:** Enable random time inversion (Cite solution_lesson_node_00039).

### Training
I will implement a **Single-Stage Ensemble Distillation Pipeline** with extended schedules. I will explicitly avoid iterative (multi-generational) distillation, as it has been proven to degrade performance on this dataset (Cite solution_lesson_node_00065).

1.  **Stage 1: Teacher Ensemble Training**
    *   Train **3 independent ResNet-34 models** on the labeled training set (Fold 0).
    *   **Regularization:** Apply **Manifold Mixup** (alpha=0.2) at random eligible layers.
    *   **Schedule:** Train for **50 epochs** to ensure convergence (Cite solution_lesson_node_00044).
    *   **SWA Protocol:** Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs (Cite solution_lesson_node_00028).
    *   **Safety:** Explicitly disable Early Stopping during the SWA phase (Cite solution_lesson_node_00050).
    *   **Loss:** BCEWithLogitsLoss (Cite solution_lesson_node_00008).

2.  **Stage 2: Robust Pseudo-Label Generation**
    *   Generate predictions for the Test Set (Fold 1) using the 3 Teachers.
    *   **TTA:** Apply **Test-Time Augmentation** (Horizontal Flips) during inference and average the results.
    *   **Ensemble Averaging:** Average the predictions across the 3 teachers to create low-variance soft targets.
    *   **Sanitize:** Assert no `NaN` values (Cite solution_lesson_node_00027).

3.  **Stage 3: Student Training**
    *   Train a single **ResNet-34 Student** on the **Combined Dataset** (Labeled Train + Pseudo-Labeled Test).
    *   **Training Data:** Maximize data volume by using the full Labeled set + Pseudo-Labeled Test set (Cite solution_lesson_node_00012).
    *   **Regularization:** Apply **Manifold Mixup** + SWA.
    *   **Schedule:** 50 epochs.

### Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, apply **ImageNet Normalization**, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities.
