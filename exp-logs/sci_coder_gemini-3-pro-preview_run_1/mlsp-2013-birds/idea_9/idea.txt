Based on the comprehensive analysis of previous experiments and the "Lessons Learned," I propose the **Multi-Resolution Ensemble Distillation with SWA**.

This strategy introduces a structural innovation—**Multi-Resolution Knowledge Distillation**—to address the trade-off between signal densification and temporal fidelity identified in Lesson 00015. By ensembling teachers trained at different temporal compression rates, we capture a broader range of morphological features (from dense, high-energy pulses to fine-grained spectral textures) to generate robust pseudo-labels, which are then distilled into a single student model.

### Model
*   **Backbone:** Utilize the **ResNet-34** architecture initialized with ImageNet weights. This backbone is retained as it offers the optimal capacity for this micro-dataset, outperforming both shallower MLPs (Cite solution_lesson_node_00006) and complex architectures like EfficientNet (Cite solution_lesson_node_00015).
*   **Input Adaptation:** Employ **Channel Replication** (copying the single-channel spectrogram to R, G, and B inputs). This preserves the natural image statistics expected by the pretrained weights, avoiding the degradation caused by engineered features (Cite solution_lesson_node_00022).
*   **Classification Head:** Use a simple **Linear Layer** projecting to the 19 species classes, strictly avoiding complex aggregation heads to minimize overfitting (Cite solution_lesson_node_00007).

### Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (Multi-Resolution Innovation):**
    *   **Vertical Dimension:** Fix height at **256 pixels** for all models to preserve native frequency resolution (Cite solution_lesson_node_00013).
    *   **Horizontal Dimension (Variable):** Instead of a single fixed width, define three distinct resolutions for the Teacher Ensemble to exploit the "Densification vs. Fidelity" trade-off (Cite solution_lesson_node_00015):
        *   **Resolution A (Dense):** 384 pixels width (High compression, emphasizes strong signal presence).
        *   **Resolution B (Balanced):** 512 pixels width (The current optimal baseline).
        *   **Resolution C (Detailed):** 640 pixels width (Higher fidelity, preserves short temporal structures).
    *   **Student Resolution:** The Student model will operate at the balanced **512 pixels** width.
*   **Pipeline Integrity:** Implement purely dynamic in-memory loading (Cite solution_lesson_node_00018) and defensive target merging to prevent `NaN` corruption (Cite solution_lesson_node_00027).
*   **Augmentation:** Apply **Conservative Mixup** (alpha=0.2) (Cite solution_lesson_node_00030) and SpecAugment.

### Training
I will implement a **Three-Stage Pipeline** with extended schedules (Cite solution_lesson_node_00029):

1.  **Stage 1: Multi-Resolution Teacher Training**
    *   Train **3 independent ResNet-34 models** on the labeled training set (Fold 0).
    *   **Teacher 1:** Trained on 256x384 inputs.
    *   **Teacher 2:** Trained on 256x512 inputs.
    *   **Teacher 3:** Trained on 256x640 inputs.
    *   Use **BCEWithLogitsLoss** (Cite solution_lesson_node_00008) and a stable learning rate of **3e-4** (Cite solution_lesson_node_00025). Save best states using `copy.deepcopy()` (Cite solution_lesson_node_00001).

2.  **Stage 2: Multi-Scale Pseudo-Labeling**
    *   Generate predictions for the unlabeled Test Set (Fold 1) using each Teacher. Crucially, resize the test images to match the specific training resolution of each Teacher during inference.
    *   Average the probabilities across the three teachers. This ensemble consensus integrates features learned at different compression rates, reducing the variance of the pseudo-labels.
    *   **Sanitize:** Explicitly assert that targets contain no `NaN` values (Cite solution_lesson_node_00027).

3.  **Stage 3: Student Training with SWA**
    *   Train a single **ResNet-34 Student** on the **Combined Dataset** (Labeled Train + Sanitized Pseudo-Labeled Test).
    *   **Input Resolution:** 256x512 (Balanced).
    *   **SWA Protocol:** Train for an extended duration (e.g., 50 epochs). Activate **Stochastic Weight Averaging (SWA)** for the final 30% of epochs (Cite solution_lesson_node_00028).
    *   **Regularization:** Maintain Mixup throughout the standard training phase to ensure manifold regularization (Cite solution_lesson_node_00030).

### Evaluation
*   **Inference:** Preprocess test images to the Student's resolution (**256 x 512**), normalize, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities.
