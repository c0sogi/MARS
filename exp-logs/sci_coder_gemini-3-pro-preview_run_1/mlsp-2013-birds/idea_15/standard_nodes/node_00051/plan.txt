The implementation strategy follows the **Robust Iterative Attentive SWA-Distillation** protocol. We will execute a three-stage pipeline:
1.  **Stage 1 (Teachers):** Train an ensemble of 3 ResNet-34 models on the labeled training set (Fold 0) for 50 epochs using Stochastic Weight Averaging (SWA) and Cosine Annealing.
2.  **Stage 2 (Distillation Gen 1):** Generate pseudo-labels for the test set (Fold 1) using the teacher ensemble. Train "Student 1" on the combined labeled and pseudo-labeled dataset.
3.  **Stage 3 (Distillation Gen 2):** Refine the pseudo-labels using "Student 1" (which has learned the test distribution). Train "Student 2" on the combined dataset with these refined targets.

Finally, we evaluate "Student 2" on the hold-out validation set, perform failure analysis to correlate errors with signal characteristics (energy and label cardinality), and generate a submission if the performance threshold is met.
