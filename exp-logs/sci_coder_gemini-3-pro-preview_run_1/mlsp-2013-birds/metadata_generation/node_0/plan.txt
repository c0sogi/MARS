Implementation Strategy:
1.  **Setup and Paths**: Define the input directory (`./input`) and output directory (`./metadata`). Ensure the output directory exists.
2.  **Data Loading**:
    -   Read `CVfolds_2.txt` to identify the provided train/test split (Fold 0 vs Fold 1).
    -   Read `rec_id2filename.txt` to map recording IDs to filenames.
    -   Read `rec_labels_test_hidden.txt` to obtain labels. Handle the variable length of labels and the `?` placeholder for test data.
    -   Read `species_list.txt` to determine the number of classes (19 species).
3.  **Data Merging**: Create a unified internal representation (DataFrame) containing `rec_id`, `file_path` (relative to `./input`), `fold`, and `labels`.
4.  **Stratified Validation Split**:
    -   Isolate the training pool (Fold 0).
    -   Convert labels into a binary matrix (one-hot encoding) for multi-label stratification.
    -   Use `skmultilearn.model_selection.IterativeStratification` with `n_splits=5` to generate folds. Select the first fold as the validation set (20%) and the remaining as the training set (80%). This handles the multi-label nature of the data better than random splitting.
    -   If a class is extremely rare or stratification fails, fallback to a random split with `random_state=42`.
5.  **Metadata Generation**:
    -   Save `train.csv`, `val.csv`, and `test.csv` to `./metadata`.
    -   Include columns for `rec_id`, `file_path`, `labels` (as a string or list), and individual binary columns for each species.
6.  **Verification**:
    -   Reload the generated metadata files.
    -   Print summary statistics (count, class distribution).
    -   Perform the required file existence check on a random sample of paths.
    -   Verify the split ratios and stratification logic.
