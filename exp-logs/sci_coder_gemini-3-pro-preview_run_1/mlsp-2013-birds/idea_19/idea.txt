Based on the comprehensive analysis of the "Lessons Learned" and the trajectory of previous experiments, I propose the **Multi-Generational High-Fidelity ResNet-34 Distillation with SWA**.

This strategy represents a **structural evolution** of the successful Idea 11 (High-Fidelity Distillation). It applies the **Iterative Self-Distillation (Multi-Generational)** framework—which previously failed in Idea 15 due to the use of the suboptimal SE-ResNet architecture—to the proven **Vanilla ResNet-34** backbone. Since the Idea 11 Student (AUC 0.959) demonstrably outperformed its Teacher Ensemble (AUC ~0.93), the precondition for successful iterative distillation is now met (Cite solution_lesson_node_00054), allowing us to squeeze further performance from the unlabeled test data.

# Model
*   **Backbone:** Utilize the **Vanilla ResNet-34** architecture initialized with ImageNet weights.
    *   *Strategic Retention:* This backbone is retained as the optimal choice for this micro-dataset. It significantly outperforms MLPs (Cite solution_lesson_node_00006) and, crucially, avoids the performance degradation seen with Squeeze-and-Excitation (SE) blocks in multi-label tasks, where global channel attention suppresses co-occurring classes (Cite solution_lesson_node_00056).
*   **Classification Head:** Use a standard **Linear Layer** projecting to the 19 species classes. I will strictly avoid complex aggregation heads (like ConcatPooling) to minimize overfitting risks (Cite solution_lesson_node_00007).
*   **Input Adaptation:** Use **Channel Replication** (copying the single-channel spectrogram to R, G, and B inputs) to preserve the natural image statistics expected by the pretrained weights (Cite solution_lesson_node_00022).

# Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Resolution:** Resize images to **256 pixels (Height) x 640 pixels (Width)**. This specific resolution preserves the native frequency resolution (Cite solution_lesson_node_00013) and captures the fine-grained temporal morphology required for high performance (Cite solution_lesson_node_00041). Crucially, all models in all generations will operate at this resolution to prevent knowledge dilution (Cite solution_lesson_node_00036).
    *   **Normalization:** Explicitly apply **ImageNet Mean and Standard Deviation normalization**. This is a mandatory correction to ensure the transfer learning contract is upheld (Cite solution_lesson_node_00045).
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Implement purely dynamic in-memory loading without disk caching to prevent stale data issues (Cite solution_lesson_node_00018).
    *   **Deterministic Seeding:** Explicitly pass a fixed seed to the NumPy `default_rng()` generator within augmentation classes to prevent hidden variance (Cite solution_lesson_node_00043).
*   **Augmentation:**
    *   **Unstructured Cutout:** Apply random rectangular masks instead of structured SpecAugment to preserve partial features of short signals (Cite solution_lesson_node_00038).
    *   **Horizontal Flip:** Enable random time inversion to regularize the high-dimensional 640px input space (Cite solution_lesson_node_00039).
    *   **Conservative Mixup:** Apply Mixup with **alpha = 0.2** (Cite solution_lesson_node_00030).

# Training
I will implement a **Three-Stage Multi-Generational Pipeline**. This is justified because the Idea 11 Student outperformed its Teachers, satisfying the condition for iterative improvement (Cite solution_lesson_node_00054).

1.  **Stage 1: Teacher Ensemble (Generation 0)**
    *   Train **3 independent ResNet-34 models** on the labeled training set (Fold 0).
    *   **Schedule:** Train for **50 epochs** to ensure full convergence with Mixup (Cite solution_lesson_node_00044).
    *   **SWA Protocol:** Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs (Cite solution_lesson_node_00028).
    *   **Safety:** Explicitly disable Early Stopping during the SWA phase to prevent returning uninitialized models (Cite solution_lesson_node_00050).
    *   **Loss:** BCEWithLogitsLoss (Cite solution_lesson_node_00008).

2.  **Stage 2: Student 1 (Generation 1)**
    *   **Pseudo-Labeling:** Generate predictions for the Test Set (Fold 1) using the 3 Teachers. Apply **Test-Time Augmentation (TTA)** (Horizontal Flips) and average the results to create robust targets.
    *   **Sanitize:** Assert no `NaN` values (Cite solution_lesson_node_00027).
    *   **Training:** Train **Student 1 (ResNet-34)** on the Combined Dataset (Labeled + Pseudo-Labeled).
    *   **Schedule:** 50 epochs with SWA.

3.  **Stage 3: Student 2 (Generation 2 - Structural Innovation)**
    *   **Refined Pseudo-Labeling:** Use the converged **Student 1** (which is expected to be a "Super-Teacher") to re-generate pseudo-labels for the Test Set. Use **TTA** to further denoise these predictions.
    *   **Training:** Train **Student 2 (ResNet-34)** on the Combined Dataset using these refined targets. This second generation allows the model to leverage the superior manifold learned by Student 1 to further clean the noisy test labels.
    *   **Schedule:** 50 epochs with SWA.

# Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, apply **ImageNet Normalization**, and perform a single forward pass using the final **Student 2 (SWA)** model.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities. This leverages the finding that a single model trained on maximal data outperforms cross-validation ensembles (Cite solution_lesson_node_00012).
