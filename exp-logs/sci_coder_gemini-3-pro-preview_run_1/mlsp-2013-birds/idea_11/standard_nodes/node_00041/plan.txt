The issue is that `sklearn.metrics.roc_auc_score` with `average='macro'` returns `nan` instead of raising a `ValueError` when some classes in the validation set lack positive samples (undefined AUC). The existing code only catches `ValueError`, allowing `nan` to propagate and invalidate the final metric, causing the submission generation to be skipped.

To fix this, I will modify `library/training.py` to explicitly check if the calculated AUC is `nan`. If it is, the code will fallback to a robust calculation method that iterates over each class, computes the AUC only for classes with valid targets (containing both positive and negative samples), and returns the mean of these valid scores. This applies **Debug Lesson 2** (Explicitly Handle NaN Returns in Metric Calculations).
