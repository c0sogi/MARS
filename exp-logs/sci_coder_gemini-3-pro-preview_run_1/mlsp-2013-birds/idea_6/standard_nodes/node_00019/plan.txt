This script implements the **Spectral-Dynamic ResNet-34 with Self-Distillation** pipeline. It proceeds in two main stages:
1.  **Teacher Training**: Trains a ResNet-34 on the labeled training set (Fold 0) to learn initial features from the spectral dynamics (Deltas).
2.  **Student Training (Self-Distillation)**: Uses the Teacher to generate soft pseudo-labels for the unlabeled test set (Fold 1). A new Student model is then trained on the combined dataset (Labeled Train + Pseudo-Labeled Test) to leverage the unlabeled data structure.

Following training, the script evaluates the Student model on the validation set, performs a failure analysis by correlating prediction errors with input signal characteristics (intensity, contrast, complexity), and generates a submission file if the performance threshold is met.
