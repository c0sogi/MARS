Based on the comprehensive analysis of the previous experiments and the "Lessons Learned," I propose the **Attentive High-Fidelity SWA-Distillation with Deterministic TTA**.

This strategy introduces a structural innovation in the model architecture—**Squeeze-and-Excitation (SE) Attention**—to explicitly model channel dependencies, addressing the "cocktail party" problem of overlapping calls. It combines this with a rigorous **Test-Time Augmented (TTA) Distillation** pipeline and strictly enforces **Deterministic Randomness** to correct the hidden variance identified in Lesson 00043.

# Model
*   **Backbone (Structural Innovation):** Upgrade the architecture from ResNet-34 to **SE-ResNet-34** (Squeeze-and-Excitation ResNet).
    *   *Rationale:* While ResNet-34 offers the optimal depth for this micro-dataset (Cite solution_lesson_node_00006, solution_lesson_node_00015), standard convolutions treat all channels equally. **SE blocks** introduce a lightweight attention mechanism that adaptively recalibrates channel-wise feature responses. In the context of spectrograms, this allows the model to learn to selectively emphasize specific frequency bands (feature channels) containing bird calls while suppressing noise channels, enhancing discriminability without the overfitting risks of larger backbones like ResNet-50.
*   **Input Adaptation:** Maintain **Channel Replication** (copying the single-channel spectrogram to R, G, and B inputs) to preserve the natural image statistics expected by the pretrained weights (Cite solution_lesson_node_00022).
*   **Classification Head:** Use a standard **Linear Layer** projecting to the 19 species classes, strictly avoiding complex aggregation heads (Cite solution_lesson_node_00007).

# Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (High-Fidelity Alignment):**
    *   **Vertical Dimension:** Fix height at **256 pixels** to strictly preserve native frequency resolution (Cite solution_lesson_node_00013).
    *   **Horizontal Dimension:** Fix width at **640 pixels**. This high-fidelity resolution captures fine-grained temporal morphology (Cite solution_lesson_node_00041) and must be consistent across both Teacher and Student models to prevent knowledge dilution (Cite solution_lesson_node_00036).
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Implement purely dynamic in-memory loading without disk caching to prevent stale data issues (Cite solution_lesson_node_00018).
    *   **Deterministic Seeding (Critical Fix):** Explicitly pass a fixed seed to the NumPy `default_rng()` generator used within the augmentation classes (Mixup, Cutout). This corrects the hidden non-determinism that caused performance variance in previous high-fidelity runs (Cite solution_lesson_node_00043).
*   **Augmentation:**
    *   **Unstructured Cutout:** Apply random rectangular masks instead of structured SpecAugment to preserve partial features of short signals (Cite solution_lesson_node_00038).
    *   **Horizontal Flip:** Enable random time inversion to regularize the high-dimensional 640px input space (Cite solution_lesson_node_00039).
    *   **Conservative Mixup:** Apply Mixup with **alpha = 0.2** (Cite solution_lesson_node_00030).

# Training
I will implement a **Three-Stage Pipeline** enhanced with TTA and SWA:

1.  **Stage 1: Attentive Teacher Ensemble with SWA**
    *   Train **3 independent SE-ResNet-34 models** on the labeled training set (Fold 0).
    *   **SWA Protocol:** Train for an extended schedule (e.g., 40 epochs). Activate **Stochastic Weight Averaging (SWA)** for the final 25% of epochs to create robust teachers with flat loss minima (Cite solution_lesson_node_00028).
    *   **Optimization:** Use **BCEWithLogitsLoss** (Cite solution_lesson_node_00008) and a stable learning rate of **3e-4** (Cite solution_lesson_node_00025).

2.  **Stage 2: TTA-Enhanced Pseudo-Labeling**
    *   Generate predictions for the unlabeled Test Set (Fold 1) using the 3 SWA Teachers.
    *   **TTA Innovation:** Instead of a single forward pass, perform **Test-Time Augmentation** (specifically Horizontal Flips) during inference. Average the standard and flipped predictions for each teacher, then average across the ensemble. This generates significantly smoother and more robust soft targets than standard inference.
    *   **Sanitize:** Explicitly assert that the merged targets contain no `NaN` values (Cite solution_lesson_node_00027).

3.  **Stage 3: Attentive Student with SWA**
    *   Train a single **SE-ResNet-34 Student** on the **Combined Dataset** (Labeled Train + Sanitized Pseudo-Labeled Test).
    *   **Input Resolution:** **256x640**.
    *   **SWA Protocol:** Train for an extended duration (50 epochs) and activate SWA for the final 30% of epochs to ensure full convergence (Cite solution_lesson_node_00029).

# Evaluation
*   **Inference:** Preprocess test images to **256 x 640**, normalize, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits to generate probabilities. This leverages the finding that a single model trained on maximal data outperforms cross-validation ensembles (Cite solution_lesson_node_00012).
