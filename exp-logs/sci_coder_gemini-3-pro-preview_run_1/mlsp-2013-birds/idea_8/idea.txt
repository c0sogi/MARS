Based on the comprehensive analysis of the previous experiments and the "Lessons Learned," I propose the **Sanitized Ensemble-Distilled ResNet-34 with Stochastic Weight Averaging (SWA)**.

This strategy introduces two key structural innovations:
1.  **Sanitized Ensemble Distillation:** A rigorous semi-supervised pipeline that addresses the critical data scarcity (Cite solution_lesson_node_00012) by leveraging the unlabeled test data, but explicitly incorporates a "Target Sanitation" protocol to prevent the data corruption that caused previous attempts to fail (Cite solution_lesson_node_00027).
2.  **Stochastic Weight Averaging (SWA):** An advanced optimization technique integrated into the Student's training loop. SWA averages the weights of the model across the optimization trajectory to find a flatter, more robust minimum, significantly improving generalization in micro-data regimes without the computational cost of inference-time ensembles.

### Model
*   **Backbone:** Utilize the **ResNet-34** architecture initialized with ImageNet weights. This backbone has been empirically proven to offer the optimal balance of capacity and regularizability for this specific dataset, outperforming both shallower MLPs (Cite solution_lesson_node_00006) and more complex architectures like EfficientNet (Cite solution_lesson_node_00015).
*   **Input Adaptation:** Employ **Channel Replication** (copying the single-channel spectrogram to R, G, and B inputs). This preserves the natural image statistics expected by the pretrained weights, avoiding the degradation caused by engineered features like "Deltas" (Cite solution_lesson_node_00022).
*   **Classification Head:** Use a simple **Linear Layer** projecting to the 19 species classes. I will strictly avoid complex aggregation heads (like ConcatPooling) to minimize overfitting risks (Cite solution_lesson_node_00007).

### Data
*   **Source:** `supplemental_data/spectrograms`.
*   **Preprocessing (Densified Global Resize):**
    *   **Vertical Dimension:** Resize images to a fixed height of **256 pixels**. This strictly preserves the native frequency resolution of the source files (Cite solution_lesson_node_00013).
    *   **Horizontal Dimension:** Resize images to a fixed width of **512 pixels**. This "Global Resize" strategy ensures the model sees the entire 10-second context (Cite solution_lesson_node_00010) while acting as **feature densification**, making sparse bird signals easier to learn than in high-fidelity 1280px inputs (Cite solution_lesson_node_00015).
*   **Pipeline Integrity:**
    *   **Dynamic Loading:** Implement purely dynamic in-memory data loading without persistent disk caching to prevent "stale cache" data starvation (Cite solution_lesson_node_00018).
    *   **Target Sanitation (Structural Innovation):** When merging pseudo-labels, explicitly validate the data frame to ensure no `NaN` values are introduced before feeding them to the loss function (Cite solution_lesson_node_00027).
*   **Augmentation:** Apply **Conservative Mixup** (alpha=0.2) and SpecAugment to the training data (Cite solution_lesson_node_00007).

### Training
I will implement a **Three-Stage Pipeline**:

1.  **Stage 1: Teacher Ensemble Training**
    *   Train **3 independent ResNet-34 models** on the labeled training set (Fold 0) using different random seeds.
    *   Use **BCEWithLogitsLoss** (Cite solution_lesson_node_00008) and a stable learning rate of **3e-4** (Cite solution_lesson_node_00025).
    *   Save the best state for each using `copy.deepcopy()` (Cite solution_lesson_node_00001).

2.  **Stage 2: Sanitized Pseudo-Label Generation**
    *   Generate predictions for the unlabeled Test Set (Fold 1) using all 3 Teachers.
    *   Average the probabilities to create robust soft targets (Variance Reduction).
    *   **Sanitize:** Explicitly assert that the generated targets contain no `NaN`s or infinite values.

3.  **Stage 3: Student Training with SWA**
    *   Train a single **ResNet-34 Student** on the **Combined Dataset** (Labeled Train + Sanitized Pseudo-Labeled Test).
    *   **SWA Protocol:** Train for a total of $N$ epochs. For the final 25% of epochs, switch to **Stochastic Weight Averaging**: capture the model weights at the end of each epoch and maintain a running average.
    *   At the end of training, perform a forward pass on the training data to update the BatchNorm statistics of the averaged weights.

### Evaluation
*   **Inference:** Preprocess test images to **256 x 512**, normalize, and perform a single forward pass using the final **SWA Student Model**.
*   **Output:** Apply Sigmoid activation to the logits. This approach respects the finding that a single model trained on maximal data outperforms a cross-validation ensemble (Cite solution_lesson_node_00012).
