I will implement the `runfile.py` script to execute the Heterogeneous Non-Attentive Ensemble Distillation strategy. The script will first train four teacher models (two ResNet-34 and two DenseNet-121) using the training set, applying Stochastic Weight Averaging (SWA) in the final epochs. It will then generate pseudo-labels for the test set using this ensemble. Subsequently, a single ResNet-34 student model will be trained on the combined dataset (labeled training data plus pseudo-labeled test data). Finally, the script will evaluate the student model on the validation set, perform a failure analysis correlating errors with signal intensity, and generate a submission file if the performance threshold is met.
