The crash occurs because `torch.optim.swa_utils.update_bn` expects the data loader to yield input tensors (or a list/tuple where the first element is the input), but the `BirdDataset` yields a dictionary `{'image': ..., 'label': ..., ...}`. Consequently, `update_bn` fails when it attempts to call `.to(device)` on the dictionary. I will fix this by wrapping the `train_loader` in a generator that extracts and yields only the `"image"` tensor before passing it to `update_bn`.
