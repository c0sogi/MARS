This script demonstrates the end-to-end workflow using the provided library. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to reduce epochs, batch size, and ensemble size for rapid execution.
2.  **Data Loading**: Verifies the `BirdDataset` and `DataLoader` functionality, checking image and label shapes.
3.  **Teacher Training**: Trains a single ResNet-34 "teacher" model for a few epochs using the `fit` engine with SWA (Stochastic Weight Averaging).
4.  **Pseudo-Label Generation**: Uses the trained teacher to generate soft pseudo-labels for the test set via the `distillation` module.
5.  **Student Training**: Loads the combined dataset (labeled train + pseudo-labeled test) and trains a "student" model.
6.  **Inference**: Generates predictions on the test set using the student model and verifies the submission format.
