The implementation strategy follows the **Anti-Aliased High-Fidelity ResNet-34d Distillation with SWA** idea. The pipeline consists of three stages:
1.  **Teacher Ensemble Training**: Three independent `resnet34d` models (with anti-aliasing and deep stem) are trained on the labeled training set (Fold 0). Training uses a cosine annealing schedule for 50 epochs, with Stochastic Weight Averaging (SWA) active in the final 25% of epochs to improve generalization.
2.  **Pseudo-Label Generation**: The ensemble of SWA Teacher models generates soft pseudo-labels for the unlabeled test set (Fold 1). Test-Time Augmentation (TTA) and ensemble averaging are applied to ensure robust targets.
3.  **Student Distillation**: A single Student model is trained on the combined dataset (Labeled Train + Pseudo-Labeled Test). It learns from both ground truth and the teachers' soft targets, using the same SWA schedule.

Finally, the Student model is validated. A failure analysis correlates prediction errors with label cardinality. If the validation AUC exceeds the strict threshold of 0.9594, a submission is generated.
