# Baseline Approach: Shallow Multi-Layer Perceptron (MLP) on Histogram Features

## Model
I propose a simple **Feed-Forward Neural Network (Multi-Layer Perceptron)** designed to operate on the pre-computed tabular features. This architecture serves as a lightweight baseline, contrasting with the tree-based (Model 1), kernel-based (Model 5), and deep convolutional (Models 2 & 3) approaches.

*   **Input Layer:** Accepts the 100-dimensional feature vector from the "histogram of segments" representation.
*   **Hidden Layers:** Consists of two fully connected (dense) layers (e.g., 64 and 32 neurons respectively). Each hidden layer utilizes **ReLU** activation functions to introduce non-linearity and **Dropout** layers to prevent overfitting on the small dataset.
*   **Output Layer:** A final dense layer with 19 neurons (corresponding to the 19 bird species).
*   **Activation:** A **Sigmoid** activation function is applied to the output layer to produce independent probabilities between 0 and 1 for each species, suitable for the multi-label classification task.

## Data
*   **Source:** The model will exclusively use the `supplemental_data/histogram_of_segments.txt` file, which provides a fixed-length 100-dimensional feature vector for each recording. This avoids the computational overhead of processing raw audio or images.
*   **Preprocessing:**
    1.  **Merging:** Match the `rec_id` in the histogram file with the `rec_id` in the provided metadata (`train.csv`, `val.csv`, `test.csv`) to align features with labels.
    2.  **Imputation:** If any recording IDs are missing from the histogram file, impute them with a zero vector (representing an empty histogram).
    3.  **Normalization:** Apply **Standard Scaling** (Z-score normalization) to the features using statistics computed from the training set. This ensures that the input features have a mean of 0 and a standard deviation of 1, which is crucial for the convergence of neural networks.

## Training
*   **Loss Function:** Use **Binary Cross-Entropy Loss** (specifically `BCEWithLogitsLoss` for numerical stability), which treats each species prediction as an independent binary classification problem.
*   **Optimizer:** Utilize the **Adam** optimizer, which is standard for efficient convergence on tabular data.
*   **Strategy:** Train for a fixed number of epochs (e.g., 50-100) with a small batch size (e.g., 16 or 32) given the small dataset size. Implement **Early Stopping** monitoring the validation AUC to terminate training if the model stops improving, ensuring the most efficient use of runtime.

## Evaluation
*   **Inference:** For the test set, load the corresponding histogram features, apply the scaler fitted on the training data, and perform a forward pass through the trained MLP.
*   **Output:** The raw sigmoid outputs will serve as the predicted probabilities for each species. These will be formatted into the required submission structure (mapping `rec_id` and `species` index to the specific `Id` format).
