I will implement a comprehensive EDA script for the Image Classification task. The strategy involves:
1.  **Setup & Loading**: Load the generated training metadata (`./metadata/train.csv`).
2.  **Target Analysis**: Analyze the `category_id` column to report class distribution, imbalance ratios, and identify rare classes.
3.  **Image Analysis**: Since processing 186k images is computationally expensive, I will perform stratified sampling (approx. 5,000 images) to statistically estimate image properties. I will use `concurrent.futures` to parallelize image reading.
    *   **Dimensions**: Analyze width, height, and aspect ratios.
    *   **Channels**: Check for consistency (RGB vs Grayscale).
    *   **Pixel Stats**: Compute global mean and standard deviation for normalization.
4.  **Meta-Feature Relationships**: Construct a temporary tabular dataset using image metadata (Width, Height, Aspect Ratio, File Size) and analyze their relationship with the target variable using Mutual Information and a lightweight Random Forest model.
5.  **Reporting**: Output the results in a structured, text-based report format.
