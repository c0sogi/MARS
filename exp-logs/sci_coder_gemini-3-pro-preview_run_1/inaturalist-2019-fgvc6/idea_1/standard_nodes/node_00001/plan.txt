Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `utils` modules. Set the random seed for reproducibility and define the computation device (GPU).
2.  **Data Preparation**: Instantiate `INatDataset` for both training and validation sets using the metadata CSVs. Wrap them in `DataLoader` instances with appropriate batch sizes and worker counts.
3.  **Model Initialization**: Load the MobileNetV3-Large model using `get_mobilenet_model`, configured for the 1010 species classes. Initialize the `AdamW` optimizer and `CosineAnnealingLR` scheduler.
4.  **Training Loop**: Execute a short training run (2 epochs) to establish a fast baseline. In each epoch, perform training using `train_one_epoch` and validation using `validate`. Save the model checkpoint whenever validation accuracy improves.
5.  **Failure Analysis & Metric**:
    *   Load the best saved model.
    *   Run a custom inference pass on the validation set to collect predictions and targets.
    *   Compute and print the **Top-1 classification error** in the required format: `Final Validation Metric: <value>`.
    *   Iterate through the validation dataset to extract metadata (file size, aspect ratio) for each image.
    *   Calculate and print the correlation between the error (misclassification) and these metadata features to identify potential failure modes.
6.  **Submission**: Call the `generate_submission` function from the `predict` module to generate predictions for the test set and save the `submission.csv` file.
