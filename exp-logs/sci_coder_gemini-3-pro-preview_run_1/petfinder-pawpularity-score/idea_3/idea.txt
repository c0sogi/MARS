# Proposed Strategy: Dual-Backbone Ensemble Linear Probing

## Model
To address the finding that "Backbone Capacity Dominates Linear Probing Baselines" (Cite `solution_lesson_node_00014`) and to overcome the limitations of a single feature extractor, I propose a **Dual-Backbone Feature Extraction** architecture.

1.  **Feature Extractors**: Instead of relying solely on **Swin Transformer Large**, I will introduce a second high-capacity backbone with a distinct inductive bias, such as **ConvNeXt Large** (a pure CNN architecture).
    *   *Rationale*: While Swin Transformers excel at capturing global composition and long-range dependencies, CNNs like ConvNeXt are often superior at capturing local texture and high-frequency details. Combining these complementary representations creates a richer "Super-Embedding" that captures both the semantic "cuteness" and the photographic quality of the image.
2.  **Fusion**: The embeddings from both backbones will be concatenated into a single feature vector.
3.  **Prediction Head**: This combined vector will be fed into a **Ridge Regression** head. This preserves the efficiency and robustness of the linear probing approach (Cite `solution_lesson_node_00005`) while leveraging a significantly more powerful feature space.

## Data
1.  **Feature-Space Augmentation**: I will apply the "Feature-Space Augmentation Averaging" technique (Cite `solution_lesson_node_00009`). For every image, I will compute embeddings for both the original and a horizontally flipped version using both backbones. The original and flipped embeddings will be averaged for each backbone *before* concatenation to reduce noise and enforce invariance.
2.  **Multimodal Fusion**: The 12 binary metadata features will be concatenated with the dual-backbone image embeddings.
3.  **Normalization**: Crucially, I will apply **StandardScaler** to the entire concatenated feature matrix (image embeddings + metadata). This ensures that the binary metadata flags are not drowned out by the high-variance image features and allows the regularized linear solver to weigh them appropriately (Cite `solution_lesson_node_00007`).

## Training
1.  **Algorithm**: I will use **RidgeCV** (Ridge Regression with built-in Cross-Validation) to solve for the weights.
2.  **Hyperparameter Expansion**: Given that concatenating two large backbones will double the feature dimensionality (potentially exceeding 3,000 dimensions) relative to the dataset size (~7,000 samples), the risk of overfitting is elevated (Cite `solution_lesson_node_00004`). Therefore, I will define a search grid for the regularization strength (`alpha`) that extends significantly higher than previous experiments (e.g., up to 20,000 or 50,000). This proactively addresses the "Boundary Clipping" issue (Cite `solution_lesson_node_00010`) and ensures the model can apply sufficient constraints to the high-dimensional feature space.

## Evaluation
1.  **Inference**: Test images will be processed through the dual-backbone pipeline (Swin Large + ConvNeXt Large) with flip-averaging.
2.  **Prediction**: The standardized features will be passed through the learned Ridge Regression weights to generate the final `Pawpularity` score.
3.  **Validation**: I will continue to use the stratified validation set to verify that the ensemble approach yields a lower RMSE than the single-backbone Swin Large baseline.
