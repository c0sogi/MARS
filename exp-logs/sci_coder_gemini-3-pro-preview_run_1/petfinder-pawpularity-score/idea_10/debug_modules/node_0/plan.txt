Implementation Strategy:
1.  **Configuration Override**: Modify the `Config` class attributes at runtime to enable debugging mode, reduce the number of cross-validation folds to 2, and minimize hyperparameter search spaces (e.g., fewer trees for ExtraTrees, single alpha for Ridge). This ensures the script runs within the time limit.
2.  **Data Loading Demonstration**: Load the training metadata, create a small subset (e.g., 20 samples), and utilize `get_loader` from `data_factory.py` to verify that data loading, image processing, and augmentation (flipping) function correctly.
3.  **Feature Extraction**: Instantiate `BackboneExtractor` and run the `extract` method on the small training and test subsets using the 'convnext' backbone. This demonstrates the integration of HuggingFace models and caching mechanisms.
4.  **Feature Processing**: Use `FeatureProcessor` to demonstrate how raw embeddings and metadata are transformed for different model types (StandardScaler for linear models, PCA for tree models). Verify output shapes with assertions.
5.  **Level-0 Training**: Instantiate `Level0Trainer` and run the `run_expert` method for both 'ridge' and 'et' (ExtraTrees) models. This validates the cross-validation logic and out-of-fold (OOF) prediction generation.
6.  **Level-1 Stacking**: Instantiate `Level1MetaLearner`, aggregate the OOF and test predictions from the previous step, and execute `train_and_predict`. This verifies the meta-learning process and final submission file generation.
7.  **Validation**: Throughout the script, assertions will be used to check data shapes, file existence, and logical consistency (e.g., RMSE calculation).
