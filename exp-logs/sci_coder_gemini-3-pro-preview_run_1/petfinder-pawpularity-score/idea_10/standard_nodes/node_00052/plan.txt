The execution failure is caused by an API mismatch between the installed `scikit-learn` version (1.7.2) and the configuration. The `BayesianRidge` model no longer accepts the `n_iter` parameter (which was deprecated and removed); it now uses `max_iter`.

To fix this, I will:
1.  Update `library/config.py` to rename the `n_iter` key to `max_iter` in `META_MODEL_PARAMS`.
2.  Update `library/stacking_engine.py` to dynamically handle the parameter renaming at runtime. This ensures that even if the `Config` object remains stale in the persistent environment (Cite debug_lesson_3), the consumer code will correctly map the old `n_iter` parameter to `max_iter` before initializing the model.
