To address the task of predicting 'Pawpularity' with a focus on speed, simplicity, and establishing a reliable baseline, I propose a **Linear Probing** approach using a lightweight pre-trained backbone. This method differs from the provided architectures by utilizing a strictly linear regression head (Ridge) rather than non-linear deep heads (MLP), tree ensembles (LightGBM), kernel methods (SVR), or instance-based learning (KNN).

### Model
The architecture consists of two distinct stages designed for maximum efficiency:
1.  **Feature Extractor**: Utilize **MobileNetV3-Small**, a convolutional neural network optimized for speed and low latency, pre-trained on ImageNet. This backbone will remain completely **frozen** (no gradient updates). We will extract the high-dimensional feature vector from the final Global Average Pooling layer.
2.  **Linear Regressor**: The extracted image features will be concatenated with the 12 binary metadata features. This combined vector serves as the input to a **Ridge Regression** model (Linear Least Squares with L2 regularization). This model learns a simple weighted sum of the deep visual features and metadata tags to predict the score.

### Data
1.  **Preprocessing**: Images will be resized to a standard resolution of 224x224 pixels and normalized using standard ImageNet mean and standard deviation values.
2.  **No Augmentation**: Consistent with the philosophy of a baseline, we will not apply data augmentation (e.g., flips, rotations) to keep the pipeline deterministic and fast.
3.  **Feature Caching**: To accelerate the training phase, we will process the entire training dataset once through the frozen MobileNetV3 backbone and save the output vectors (embeddings) to memory or disk. This converts the image problem into a simple tabular regression problem.

### Training
1.  **Feature Standardization**: Before training the regressor, the extracted image embeddings will be standardized (scaled to zero mean and unit variance) to ensure the L2 regularization is applied uniformly across all dimensions.
2.  **Optimization**: We will train the Ridge Regression model on the cached features and metadata. Unlike neural networks that require iterative gradient descent over many epochs, Ridge Regression can be solved very quickly using closed-form solvers (e.g., Cholesky decomposition) or efficient iterative solvers (e.g., SAG/SAGA) provided by standard libraries like Scikit-Learn.
3.  **Hyperparameter Tuning**: The only hyperparameter to tune is the regularization strength (alpha). This can be quickly optimized using Cross-Validation on the training set.

### Evaluation
For each sample in the test set:
1.  Load and preprocess the image.
2.  Pass the image through the frozen MobileNetV3 backbone to obtain the embedding.
3.  Concatenate the embedding with the corresponding test metadata.
4.  Compute the dot product of this vector with the learned weights (plus bias) from the Ridge Regressor to output the final `Pawpularity` score.
