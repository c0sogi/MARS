Here is the implementation strategy and the complete code for `runfile.py`.

### Implementation Strategy

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility and defining the necessary file paths using the provided `Config` class.
2.  **Data Preparation**:
    *   Instantiate `PawpularityDataset` for the training, validation, and test sets using the metadata files generated in the `./metadata` directory.
    *   Apply the standard ImageNet preprocessing pipeline (`get_transforms`) to resize and normalize images.
    *   Wrap datasets in PyTorch `DataLoader`s with a batch size of 64 to efficiently feed data to the GPU.
3.  **Feature Extraction (Caching)**:
    *   Initialize the `MobileNetExtractor` which uses a frozen MobileNetV3-Small backbone.
    *   Process the full training, validation, and test datasets to extract 576-dimensional image embeddings.
    *   Save these embeddings, along with metadata and targets/IDs, to the `./working/idea_1` directory. This converts the image problem into a tabular regression problem, significantly speeding up the "training" phase.
4.  **Model Training**:
    *   Load the cached training features and metadata.
    *   Initialize the `RidgeHead` regressor (Ridge Regression with Standard Scaling).
    *   Fit the regressor on the training data.
5.  **Validation and Evaluation**:
    *   Load cached validation features.
    *   Generate predictions and compute the Root Mean Squared Error (RMSE).
    *   Print the required `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample.
    *   Compute the Pearson correlation between the absolute error and each of the 12 binary metadata features.
    *   Print these correlations to identify which features are associated with higher prediction errors.
7.  **Submission Generation**:
    *   Load cached test features.
    *   Generate predictions for the test set.
    *   Save the results to `./submission/submission.csv` in the required format using the `RidgeHead.save_submission` method.
