The implementation strategy involves creating a self-contained Python script that performs the required Exploratory Data Analysis (EDA) in four main stages. First, it loads the training metadata from the pre-generated `./metadata/train.csv` file. Second, it analyzes the target variable (`Pawpularity`) to report distribution statistics, skewness, kurtosis, and outliers. Third, it analyzes the input data, handling the binary tabular features (calculating frequencies and checking for rare labels) and the image data (calculating dimensions, aspect ratios, and pixel statistics on a representative sample to ensure efficiency). Finally, it investigates feature relationships by calculating correlations, identifying redundant features, and training a Random Forest regressor to determine feature importance. The script is designed to be robust, reproducible (using fixed seeds), and formatted according to the specific requirements.
