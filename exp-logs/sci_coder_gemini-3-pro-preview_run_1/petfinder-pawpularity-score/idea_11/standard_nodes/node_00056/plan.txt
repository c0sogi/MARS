This implementation orchestrates the Stratified Tri-Paradigm Stacking Ensemble. It begins by loading the metadata for train, validation, and test sets. It then utilizes the `DeepFeatureExtractor` to generate or load cached embeddings for three backbones (SigLIP, DINOv2, ConvNeXt). The core logic performs a 5-Fold Stratified Cross-Validation on the training set to train 12 Level-0 experts (Ridge, SVR, ExtraTrees, LightGBM per backbone) and generate Out-of-Fold (OOF) predictions. These OOF predictions train a Level-1 Bayesian Ridge Meta-Learner. The script evaluates the ensemble on the hold-out validation set, prints the required metric, performs failure analysis by correlating errors with metadata, and finally generates a submission if the performance threshold is met.
