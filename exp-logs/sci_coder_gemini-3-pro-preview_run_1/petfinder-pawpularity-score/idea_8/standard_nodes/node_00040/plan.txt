The issue is that the `Level0Trainer` currently concatenates the training and validation sets before performing cross-validation. This causes data leakage because the Level-0 models (and their hyperparameter tuning) are exposed to the validation data, leading to an invalid validation metric.

To fix this, I will modify `library/level0_experts.py` to:
1.  Perform cross-validation **only** on the training set (`X_train`) to generate OOF predictions for the training data.
2.  Generate predictions for the validation set (`X_val`) and test set (`X_test`) by averaging the predictions from the models trained on each training fold (bagging).
3.  Concatenate the training OOF predictions and the averaged validation predictions to form the final `oof` array, preserving the structure expected by the downstream `MetaLearner`.
4.  Update the cache file prefix to `_strict` to ensure that the old, leaked cache files are not reused (Cite debug_lesson_5).
