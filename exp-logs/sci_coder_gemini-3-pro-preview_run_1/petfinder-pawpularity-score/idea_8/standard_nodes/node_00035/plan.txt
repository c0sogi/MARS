The strategy involves a sequential execution of the machine learning pipeline using the provided library modules. First, we initialize the environment and set random seeds. Then, we execute the feature extraction process for all three backbones (CLIP, DINO, ConvNeXt) across training, validation, and test splits, leveraging the caching mechanism to avoid redundant computation. Next, we instantiate and run the `MetaLearner`, which orchestrates the training of Level-0 experts via cross-validation and generates the initial submission. To fulfill the strict validation requirement, we retrieve the generated meta-features, slice them back into training and hold-out validation sets, and retrain the Level-1 meta-learner on the training split to evaluate it on the hold-out split. We then perform failure analysis by correlating prediction errors with metadata features. Finally, we compare the calculated validation RMSE against the required threshold and remove the submission file if the performance criterion is not met.
