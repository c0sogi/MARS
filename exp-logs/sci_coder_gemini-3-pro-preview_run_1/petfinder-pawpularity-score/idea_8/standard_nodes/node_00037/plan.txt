The error `ValueError: Found array with 0 sample(s)` in `runfile.py` is caused by loading stale cache files from a previous "debug" execution (containing only 100 samples) during a full dataset run (expecting ~8920 samples). The mismatch causes the validation set slicing `X_meta[n_train:]` to result in an empty array because `n_train` (7136) exceeds the total length of the cached data (100).

To fix this, I will implement cache validation logic in `library/feature_extraction.py`, `library/level0_experts.py`, and `library/level1_meta.py`. This logic will verify that the sample count of the loaded artifacts matches the expected count for the current configuration (Debug vs. Full). If a mismatch is detected, the system will ignore the cache and trigger re-computation (Cite debug_lesson_5).
