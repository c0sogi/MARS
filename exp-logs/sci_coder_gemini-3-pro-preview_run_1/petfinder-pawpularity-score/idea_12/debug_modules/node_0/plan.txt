### Implementation Strategy

1.  **Configuration Overrides**: Immediately modify the global `Config` class to enable `DEBUG` mode (limiting data to 100 samples), reduce the number of cross-validation folds to 2, and drastically reduce the number of estimators/iterations for LightGBM, ExtraTrees, SVR, and the Meta-Learner to ensure execution completes in seconds/minutes.
2.  **Data Loading Verification**: Instantiate `PetDataset` and `DataLoader` to verify that image loading, transformation, and metadata extraction work correctly. Assert output shapes match expectations (batch size, channels, dimensions).
3.  **Feature Extraction**: Initialize `FeatureExtractor` with a single backbone (ConvNeXt) to save time. Run a small extraction batch to verify the output format (embeddings, IDs, metadata).
4.  **Feature Processing**: Create synthetic data to test `ExpertPreprocessor` (both Linear and Tree modes) and `create_interaction_matrix`. Verify that dimensions expand correctly (e.g., PCA reduction, interaction terms).
5.  **Level-0 Expert Training**: Use `Level0Trainer` to train a lightweight Ridge regression model on the extracted features. Verify that Out-Of-Fold (OOF) and Test predictions are generated and cached correctly.
6.  **Meta-Learner Integration**: Instantiate the `MetaLearner`. Monkey-patch its backbone list to use only the single ConvNeXt model (avoiding the overhead of loading SigLIP and DINOv2). Execute the full `train_predict` pipeline and verify that a valid submission file is generated.
7.  **Cleanup**: Ensure all operations use a designated subdirectory in `./working` to avoid clutter, though the environment cleans up automatically.
