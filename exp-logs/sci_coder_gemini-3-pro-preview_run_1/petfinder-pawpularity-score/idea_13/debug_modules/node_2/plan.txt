The error `TypeError: BayesianRidge.__init__() got an unexpected keyword argument 'n_iter'` occurs because the `n_iter` parameter in scikit-learn's `BayesianRidge` model was deprecated and renamed to `max_iter` in recent versions (v1.0+), and removed in the installed version (v1.7.2). Following the guidance of **Cite debug_lesson_5**, I will resolve this API incompatibility by renaming the parameter `n_iter` to `max_iter` in the global configuration dictionary (`library/config.py`) and in the demo override settings (`runfile.py`).

        "max_iter": 300,
        "tol": 1e-3,
        "alpha_1": 1e-6,
