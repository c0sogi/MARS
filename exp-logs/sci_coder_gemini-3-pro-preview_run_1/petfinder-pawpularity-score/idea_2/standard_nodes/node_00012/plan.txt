However, upgrading to `swin_large` (1536 dimensions) increases the risk of overfitting in the linear head, as noted in Lesson 00004. To mitigate this and address the boundary clipping observed in Lesson 00010 (where the optimal alpha hit the maximum search value of 1000), I will significantly expand the regularization strength (`alpha`) search space in `RidgeCV` to include values up to 20,000. This ensures the linear model can adequately regularize the high-dimensional features from the larger backbone.

Finally, I will update the submission threshold to the previous best validation RMSE (17.93) to ensure we only generate a submission if performance improves.
