The implementation strategy is as follows:

1.  **Setup & Loading**: Define input/output directories. Load the raw `train.csv` and `test.csv` files from the `./input` directory.
2.  **Feature Engineering**: Generate a `file_path` column for both datasets. The paths will be relative to the `./input` directory (e.g., `train/{id}.jpg` and `test/{id}.jpg`).
3.  **Stratified Splitting**: Since the target `Pawpularity` is a continuous variable with a specific distribution, create a temporary binning feature (using 14 bins based on dataset size) to enable stratified sampling. Split the training data into an 80% training set and a 20% validation set using `sklearn.model_selection.train_test_split` with `stratify` enabled and a fixed `random_state=42`.
4.  **Saving**: Save the processed training, validation, and test dataframes as CSV files in the `./metadata` directory.
5.  **Validation**:
    *   Reload the saved metadata files.
    *   Print summary statistics (counts, target distribution).
    *   Perform a file existence check on 1000 random samples from each dataset; raise a `FileNotFoundError` if more than 50% of paths are invalid.
    *   Verify the validation split ratio is within an acceptable range (approx 0.2).
    *   Verify that the target distribution (mean/std) in the validation set closely matches the training set to confirm successful stratification.
