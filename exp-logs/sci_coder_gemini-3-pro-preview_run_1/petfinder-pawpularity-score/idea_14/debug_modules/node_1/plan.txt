To fix this, I will modify `library/processors.py` to dynamically clamp `n_components` to the minimum of the configured value, the number of samples, and the number of features before initializing PCA. This ensures the dimensionality reduction adapts to the available data size, preventing runtime crashes on small datasets, as described in debug_lesson_4 (Cite debug_lesson_4).
