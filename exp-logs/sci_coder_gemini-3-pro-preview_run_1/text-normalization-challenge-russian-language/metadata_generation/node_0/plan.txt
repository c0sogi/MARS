The strategy is to load the raw CSV data using pandas, perform a group-based split on `sentence_id` to create training and validation sets (ensuring sentences remain intact to preserve context), and save these splits as new CSV files in the `./metadata` directory. The test set will also be processed and saved. Finally, the script will reload the generated metadata to verify the split integrity (no sentence leakage), print statistics, and confirm that the data is ready for downstream usage.
