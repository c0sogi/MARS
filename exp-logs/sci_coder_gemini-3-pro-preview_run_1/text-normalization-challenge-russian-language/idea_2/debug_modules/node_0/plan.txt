The following script demonstrates the end-to-end usage of the provided library components. It performs the following steps:

1.  **Setup**: Configures a temporary working directory and overrides the global `Config` to use lightweight hyperparameters (small model, few epochs) and synthetic "mini" datasets for speed.
2.  **Data Generation**: Creates small synthetic training, validation, and test CSV files mimicking the structure of the real dataset.
3.  **Tokenizer**: Demonstrates vocabulary building, encoding, and decoding, verifying that round-trip conversion works.
4.  **N-gram Statistics**: Generates unigram/bigram/trigram statistics from the synthetic data and verifies the output structure.
5.  **Dataset Loading**: Instantiates the `NormalizationDataset` to show how it filters data (e.g., selecting tokens with digits) and constructs context windows.
6.  **Model Training**: Runs the `run_training` loop using the `Trainer` class, verifying that the loss decreases and a model checkpoint is saved.
7.  **Hybrid Inference**: Uses the `HybridPredictor` to generate predictions on the test set, combining N-gram lookups and the trained neural model, and validates the submission format.
