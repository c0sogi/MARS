### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` object, setting a fixed random seed for reproducibility. Override default parameters (epochs, batch size) to create a "fast baseline" that fits within the time limit while utilizing the A100 GPU efficiently.
2.  **Data Preparation**: Use `DataManager` to reconstruction sentences and prepare neural sequences. Train the `HybridTokenizer` on the raw training data to handle both BPE (context) and Character (target) tokenization.
3.  **Symbolic Model Construction**: Build the `HierarchicalNgram` model (Trigram/Bigram/Unigram statistics) using the training data. This handles the majority of "easy" tokens (Plain, Punctuation).
4.  **Neural Model Training**: Initialize the `DualGranularityTransformer` and `ModelTrainer`. Train the model on the filtered dataset (tokens with digits + semiotic classes) for a few epochs. Save the best checkpoint.
5.  **Hybrid Validation**: Implement a custom validation loop that mimics the inference routing logic:
    *   **Priority 1**: Check Trigram statistics.
    *   **Priority 2**: If the token contains digits and wasn't solved by Trigram, route to the Neural Model.
    *   **Priority 3**: Backoff to Bigram -> Unigram -> Identity.
    *   Compute the **Final Validation Metric** (Accuracy) on the full validation set.
6.  **Failure Analysis**: Analyze the validation results by calculating accuracy per class and the correlation between token length and error rate.
7.  **Submission**: If the validation accuracy exceeds the specified threshold, instantiate the `HybridRouter` (Inference Engine) to generate predictions for the test set and save `submission.csv`.
