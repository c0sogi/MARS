The following implementation demonstrates the end-to-end usage of the provided text normalization library. It begins by setting up a lightweight demonstration environment with dummy data to ensure rapid execution. It then systematically instantiates and verifies the core components: data processing (tokenization and dataset creation), the symbolic N-gram model, the neural transformer model (including training), and the hybrid inference engine. Assertions are used throughout to validate the correctness of data shapes, model outputs, and file generation.
