The following script demonstrates the end-to-end usage of the provided library modules for the Glioblastoma classification task. It performs the following steps:

1.  **Configuration Setup**: Overrides default configurations to use a temporary working directory and reduced hyperparameters (batch size, epochs) for rapid execution.
2.  **Data Preparation**: Creates mini-subsets of the training and test metadata to ensure the demo runs quickly without processing the entire dataset.
3.  **Geometry Processing**: Demonstrates how `geometry_utils` calculates slice indices for the volumetric stack based on the Center of Mass.
4.  **Dataset & DataLoader**: Verifies the `ARVSDataset` and `get_dataloader` functionality, checking input tensor shapes and label formats.
5.  **Model Initialization**: Instantiates the `ARVSNet` model, verifying the custom input layer for 9-channel input (3 modalities × 3 offsets).
6.  **Training Loop**: Runs a minimal training session using `engine.train_model` to verify the training and validation logic and generates a model checkpoint.
7.  **Inference**: Uses `inference.predict_test_set` to generate predictions on the mini-test set using the trained model and verifies the submission file format.
