# Aligned-Relative Volumetric Stack (ARVS) Network

This solution introduces a **Content-Based Structural Innovation**. It moves beyond "Geometric Heuristics" (like median file index) to **"Signal-Based Anatomical Alignment"**. By calculating the Center of Mass (CoM) of the brain tissue, we anchor the input spatially, allowing us to use a **Scale-Invariant Volumetric** input structure. This is coupled with **Gaussian Weight Inflation** to bridge the gap between 2D pretraining and 3D data, and a **Strictly Coupled Augmentation** strategy.

### Model
*   **Architecture:** We utilize **EfficientNet-B0**. This backbone is retained for its parameter efficiency and proven stability on this dataset (Cite solution_lesson_node_00002).
*   **Input Structure:** The network accepts a **9-channel** input tensor $(224 \times 224 \times 9)$, employing **Early Fusion** (Cite solution_lesson_node_00031).
    *   **Channels 0-2:** [FLAIR, T1wCE, T2w] at **Relative Depth -10%** from the Brain CoM.
    *   **Channels 3-5:** [FLAIR, T1wCE, T2w] at **Brain Center of Mass (CoM)**.
    *   **Channels 6-8:** [FLAIR, T1wCE, T2w] at **Relative Depth +10%** from the Brain CoM.
    *   *Rationale:* Packing these views into a single tensor allows the model to learn volumetric texture gradients via convolution immediately. This avoids the "Subject Identity Overfitting" observed when correlated slices are treated as independent samples (Cite solution_lesson_node_00058) and prevents the signal dilution of Siamese pooling (Cite solution_lesson_node_00018).
*   **Innovation: Gaussian Weight Inflation:**
    *   To utilize 9 channels without destroying ImageNet priors (Cite solution_lesson_node_00009) or using unstable learnable adapters (Cite solution_lesson_node_00025), we mathematically adapt the backbone's first convolutional layer weights $W_{rgb}$.
    *   We initialize with a **Center-Biased (Gaussian) Prior**:
        *   **Center Slices (Channels 3-5):** Initialize with **50%** of the original weight energy ($0.5 \times W_{rgb}$). This preserves the strong "Middle Slice" baseline behavior at epoch 0.
        *   **Peripheral Slices (Channels 0-2, 6-8):** Initialize with **25%** of the weight energy ($0.25 \times W_{rgb}$). This allows the model to gradually integrate volumetric context.

### Data
The pipeline employs **Content-Based Alignment** and **Strict Integrity Verification**.

1.  **Independent Center-of-Mass (CoM) Alignment:**
    *   For **each modality independently**, we load the volume and threshold pixels $>0$ to identify the brain tissue. We calculate the **Z-axis Center of Mass** of these non-zero pixels.
    *   *Benefit:* This anchors the sampling to the biological center of the brain, robust to variations in scan Field-of-View (FOV) and positioning, solving the "Middle Slice Fallacy" (Cite solution_lesson_node_00002) and misalignment issues (Cite solution_lesson_node_00036).
2.  **Scale-Invariant Relative Sampling:**
    *   We calculate the **Brain ROI Depth** (max non-zero index - min non-zero index).
    *   We extract slices at $CoM$, $CoM - 0.1 \times Depth$, and $CoM + 0.1 \times Depth$.
    *   *Benefit:* This ensures scale invariance. A 10% offset represents the same anatomical distance relative to the brain size regardless of slice thickness.
3.  **High-Fidelity Preprocessing:**
    *   **Precision:** Use **float32** to preserve dynamic range (Cite solution_lesson_node_00016).
    *   **Normalization:** Apply **Independent Channel Min-Max Scaling** to $[0, 1]$ *before* stacking (Cite solution_lesson_node_00023). Avoid ImageNet mean/std (Cite solution_lesson_node_00017).
4.  **Integrity Check:** We implement a strict assertion that the dataset length matches the expected subject count (~523) and that CoM metadata is present. We explicitly **remove legacy fallback logic** to prevent silent failures (Cite solution_lesson_node_00092).

### Training
*   **Loss Function:** Binary Cross-Entropy (BCE) with Logits.
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Weight Decay:** Set to **$1e-2$** (aggressive) to prevent overfitting (Cite solution_lesson_node_00010).
    *   **Dropout:** Enforce a rate of **0.3** in the classifier (Cite solution_lesson_node_00044).
    *   **Exclusion:** We strictly **exclude** Structured Input Dropout (Cite solution_lesson_node_00096).
*   **Coupled Augmentation Strategy:**
    *   Apply **Elastic Transformations**, **Grid Distortions**, **Rotations**, and **Flips**.
    *   **Strictly Exclude:** Random Translations (Shift) and Scaling. Since we are using Content-Based CoM alignment, the tumor location is spatially anchored. Translation augmentation destroys this strong spatial prior and degrades performance (Cite solution_lesson_node_00065, solution_lesson_node_00102).
*   **Strategy:** **5-Fold Cross-Validation** grouped by Subject ID (Cite solution_lesson_node_00051).

### Evaluation
*   **Inference:** For each test subject, calculate the Per-Modality CoM and deterministically generate the 9-channel input (CoM, -10%, +10%).
*   **Prediction:** Pass the tensor through the ARVS network.
*   **Submission:** Average the probabilities from the 5 fold models. This leverages the robustness of the volumetric context without the need for stochastic test-time ensembles (Cite solution_lesson_node_00015).
