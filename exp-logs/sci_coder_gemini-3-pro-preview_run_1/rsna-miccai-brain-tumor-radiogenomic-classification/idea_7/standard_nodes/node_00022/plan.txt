This script implements the end-to-end pipeline for the Glioblastoma subtype prediction task. It leverages the provided library modules to perform model training using a 2.5D Spatial Montage EfficientNet-B0. The workflow includes:

1.  **Setup**: Initializes the environment and random seeds for reproducibility.
2.  **Training**: Executes the training loop via `library.train.run_training`, which handles data loading (with caching), model optimization, and checkpointing the best model based on validation AUC.
3.  **Validation**: Reports the final validation metric from the best epoch.
4.  **Failure Analysis**: Reloads the best model to perform inference on the validation set. It calculates the correlation between prediction error and specific metadata features (Target Class and FLAIR slice count) to identify potential biases.
5.  **Submission**: If the validation AUC exceeds the specified threshold, it generates predictions for the test set and saves them to `submission/submission.csv`.
