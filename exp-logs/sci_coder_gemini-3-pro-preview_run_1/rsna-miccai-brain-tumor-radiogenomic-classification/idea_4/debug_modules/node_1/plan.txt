The issue is caused by the implicit boolean evaluation of a NumPy array in `library/data.py`. When the file lists are loaded from the Parquet cache, they are deserialized as NumPy arrays rather than Python lists. The condition `if files and len(files) > 0:` attempts to check the truthiness of `files` (the array), which raises a `ValueError` when the array contains more than one element. To fix this, I will remove the ambiguous truthiness check and rely solely on `len(files) > 0`, which works correctly for both lists and NumPy arrays.
