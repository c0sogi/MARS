Implementation Strategy:
1.  **Configuration Patching**: Since the provided `Config` class contains default settings for a full training run (15 epochs, specific directories), we will first import `Config` and modify its attributes (monkey-patching) to suit a quick demonstration. We will set `NUM_EPOCHS` to 1, `BATCH_SIZE` to 16, and redirect outputs to a dedicated `./working/demo_execution` directory to avoid conflicts.
2.  **Data Loading & Verification**: We will use `library.data.get_loaders` to initialize the training and validation data loaders. This will trigger the caching mechanism in `GLiClassDataset`. We will iterate through a single batch to verify the data shapes (Batch, 3, 224, 224) and value ranges (normalization).
3.  **Model Initialization & Check**: We will instantiate the `GLiClassModel` and perform a forward pass with a dummy tensor to confirm the architecture is valid and produces the expected output shape `(Batch, 1)`.
4.  **Training Execution**: We will execute `library.train.run_training` for 1 epoch. This demonstrates the training loop, loss calculation, validation step, and model checkpointing.
5.  **Inference & Submission**: We will run `library.inference.predict_and_submit` using the model trained in the previous step. We will verify that the output `submission.csv` is created and adheres to the required format (correct columns and probability values).
6.  **Reproducibility**: We will use `library.utils.seed_everything` to ensure the run is deterministic.
