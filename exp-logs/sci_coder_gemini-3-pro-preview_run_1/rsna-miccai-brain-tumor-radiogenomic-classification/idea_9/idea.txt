# Multi-Slice Data Expansion with Brain-Centric Geometric Sampling

This solution introduces a **Data-Centric Structural Innovation**. Instead of increasing model complexity (which failed in Ideas 2, 3, 5, 6, 7, 8), we fundamentally alter the **Feature Engineering Paradigm** by shifting from "Subject-Level Classification" to **"Slice-Level Classification with Deterministic Expansion"**.

This approach addresses the "Small Data" bottleneck (Cite solution_lesson_node_00010) by tripling the effective training set size, and mitigates the "Middle Slice Fallacy" (Cite solution_lesson_node_00002) by covering a broader anatomical range, all while avoiding the optimization instability of 3D/Siamese architectures (Cite solution_lesson_node_00018).

### Model
*   **Architecture:** We retain **EfficientNet-B0** initialized with ImageNet weights. This backbone is selected for its proven stability and parameter efficiency on this dataset (Cite solution_lesson_node_00002).
*   **Input:** A standard 3-channel 2D image $(224 \times 224 \times 3)$.
    *   Channel 1: **FLAIR** slice.
    *   Channel 2: **T1wCE** slice.
    *   Channel 3: **T2w** slice.
*   **Configuration:** We strictly adhere to the backbone's default hyperparameters (e.g., dropout) to avoid the performance regression observed when manually overriding them (Cite solution_lesson_node_00012).

### Data
The innovation lies in the **Preprocessing and Sampling Pipeline**:

1.  **Brain-Centric ROI Definition (Refined Geometric Prior):**
    *   Instead of relying on the naive "Middle of File List" (which risks selecting neck/skull if the scan is off-center, Cite solution_lesson_node_00002), we compute the **Z-axis Bounding Box** of the brain.
    *   For each subject, we load the middle slice of the file list to determine a threshold (e.g., pixel value > 0). We then scan the file list to identify the `start_index` and `end_index` where brain tissue (non-zero pixels) actually begins and ends.
    *   This defines the **Brain Volume of Interest (VOI)**.

2.  **Deterministic Data Expansion:**
    *   From this Brain VOI, we extract **3 distinct slices** at relative depths of **45%, 50%, and 55%**.
    *   Crucially, we treat these 3 slices as **independent training examples**, all inheriting the patient's global `MGMT_value` label.
    *   *Rationale:* This effectively triples the dataset size (~1200 samples vs ~400), providing the high-capacity backbone with more diverse variations of the tumor appearance without the label noise of stochastic sampling (Cite solution_lesson_node_00015).

3.  **High-Fidelity Preprocessing:**
    *   **Precision:** All operations are performed in **float32**. We strictly avoid casting to `uint8` to preserve the high dynamic range of the MRI sensors (Cite solution_lesson_node_00016).
    *   **Normalization:** We apply **Independent Channel Min-Max Scaling** to the $[0, 1]$ range. We normalize FLAIR, T1wCE, and T2w separately *before* stacking to prevent high-intensity modalities from suppressing low-intensity ones (Cite solution_lesson_node_00023). We avoid ImageNet mean/std normalization (Cite solution_lesson_node_00017).

### Training
*   **Loss Function:** Binary Cross-Entropy (BCE) with Logits.
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Aggressive Weight Decay:** Set to **$1e-2$**. Since we are training a high-capacity model on a relatively small dataset (even after expansion), strong regularization is critical to force feature generalization (Cite solution_lesson_node_00010).
    *   **Augmentation:** We apply **Elastic Transformations** and **Grid Distortions** to the 2D images. Non-rigid augmentations are essential for modeling anatomical variance (Cite solution_lesson_node_00010).
*   **Validation Strategy:** We employ **5-Fold Cross-Validation** (Cite solution_lesson_node_00028). Crucially, the split is performed at the **Subject Level**, ensuring that slices from the same patient never appear in both train and validation sets simultaneously (preventing data leakage).

### Evaluation
*   **Inference:** For each test subject, we generate the same 3 inputs (Brain-Centric slices at 45%, 50%, 55%).
*   **Consensus Aggregation:** We pass each slice through the model independently to obtain 3 probability scores. The final prediction for the subject is the **mean** of these scores.
    *   *Rationale:* This acts as a deterministic "Test-Time Augmentation" in the Z-dimension. If the tumor is small and only visible in the 50% slice, the 45% and 55% slices might output lower confidence, but the average will still be pulled up by the strong detection. If the tumor is large, all three will contribute. This avoids the signal dilution of Siamese networks (Cite solution_lesson_node_00018) while providing robustness against positioning errors.
