# 2.5D Volumetric Sequence Transformer

This solution evolves the "Multiple Instance Learning" (MIL) concept from Idea 2 into a **Sequence Modeling** approach. While standard MIL treats slices as an unordered "bag," this architecture explicitly models the spatial continuity of the tumor along the Z-axis, leveraging the 3D anatomical structure without the computational cost of 3D convolutions.

### Model
The architecture is a **Time-Distributed CNN coupled with a Transformer Encoder**.
1.  **Feature Extractor (Backbone):** A standard **EfficientNet-B0** (pretrained on ImageNet) is used as a shared feature extractor. It processes each slice in the input sequence independently to generate a high-dimensional feature vector, preserving local texture and radiomic details (Cite Lesson 00003).
2.  **Positional Encoding:** Unlike the MIL approach in Idea 2, we inject **Positional Embeddings** (learnable or sinusoidal) to the sequence of feature vectors. This informs the model of the relative depth of each slice, allowing it to distinguish between the center of the brain (more likely to contain tumor bulk) and the periphery.
3.  **Sequence Aggregation (Transformer):** The sequence of features is passed through a lightweight **Transformer Encoder** (2 layers, 4 heads). The self-attention mechanism allows the model to attend to relevant tumor slices while considering the context of adjacent slices (e.g., distinguishing a tumor that spans multiple slices from isolated noise artifacts).
4.  **Classification Head:** The output corresponding to a learnable `[CLS]` token (or Global Average Pooling of the sequence) is passed to a fully connected layer with a sigmoid activation to predict `MGMT_value`.

### Data
To address the failures of previous sampling heuristics, the data pipeline uses a robust **Geometric Volumetric Sampling** strategy:
1.  **Preprocessing:** For each subject, load the file lists for FLAIR, T1wCE, and T2w. Sort them by instance number to establish the Z-axis.
2.  **ROI Definition:** Discard the top and bottom 15% of the file list to remove anatomical noise (skull/neck), relying on the **Geometric Prior** that the brain is centrally located (Cite Lesson 00006).
3.  **Sampling:** From the remaining central volume, uniformly sample a sequence of $N=24$ indices. This ensures coverage of the potential tumor location without relying on a single "Middle Slice" (Cite Lesson 00002) or risky unsupervised metrics like variance.
4.  **Input Construction:** For each sampled index, load the corresponding slices from the three modalities to form a $(N, 224, 224, 3)$ input tensor.

### Training
*   **Loss Function:** Binary Cross-Entropy (BCE) with Logits Loss.
*   **Optimizer:** AdamW with a learning rate of $1e-4$ and weight decay of $1e-2$.
*   **Regularization:** Heavy Dropout ($p=0.3$) within the Transformer layers and Feature Extractor to prevent overfitting, as the effective parameter count is higher than simple 2D models.
*   **Augmentation:** Apply consistent 2D spatial augmentations (rotation, shift) across all slices in a sequence to maintain spatial coherence.

### Evaluation
*   **Inference:** For each test subject, generate the input sequence using the same "Strided Central Sampling" ($N=24$) used in training.
*   **Prediction:** Pass the sequence through the model to obtain the probability.
*   **Validation:** Monitor ROC AUC on the validation set. This approach avoids the "Middle Slice Fallacy" (Cite Lesson 00002) by assessing the entire central volume and avoids the texture loss of MIP (Cite Lesson 00003) by processing slices individually before aggregation.
