The following script demonstrates the usage of the provided library modules (`config`, `utils`, `model`, `data`, `train`) to perform the glioblastoma subtype prediction task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We override the default `Config` parameters to enable `DEBUG` mode, reduce the dataset size, batch size, and number of epochs. This ensures the script runs quickly (within minutes) while still exercising all code paths.
2.  **Utility Verification**: We validate the helper functions in `library.utils`, including metric calculation and submission file generation.
3.  **Data Pipeline Verification**: We instantiate the `SIRVDataset` via `get_dataloader`. We assert that the data loader yields batches with the correct shape `(Batch, 9, 224, 224)`, confirming the 3-modality x 3-depth stacking logic.
4.  **Model Initialization & Forward Pass**: We instantiate the `SIRVEfficientNet`, verify that the first convolutional layer has been adapted for 9 input channels, and perform a forward pass to check output dimensions.
5.  **Training Loop Execution**: We manually execute `train_one_epoch` and `validate_one_epoch` using the components from `library.train` to demonstrate the training workflow without running a full cross-validation cycle.
6.  **Inference & Submission**: We run the trained model on the test set using the test data loader and generate a submission file in the valid format.
