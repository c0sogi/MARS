Implementation Strategy:
1.  **Environment Setup**: Import necessary libraries and the provided custom modules (`library.config`, `library.dataset`, `library.model`, `library.train`, `library.inference`, `library.data_processing`). Set the random seed for reproducibility.
2.  **Data Optimization**: To ensure the script runs quickly (within the time limit) while still verifying logic, I will create "mini" versions of the training and test metadata files containing only the first 4 subjects. I will then monkey-patch the path variables in `library.data_processing` to point to these mini datasets. This avoids processing the entire dataset (reading hundreds of DICOM series) during the demo.
3.  **Dataset Verification**: Instantiate the `BraTSDataset` with the mini training set. Verify that the dataset length is correct (4) and that the `__getitem__` method returns a tensor of the expected shape `(9, 224, 224)` and a scalar label.
4.  **Model Verification**: Instantiate the `CASIVNet` model. Perform a forward pass with a batch of data from the dataset to confirm the model architecture accepts the input and produces logits of shape `(Batch, 1)`.
5.  **Training Logic Verification**: Create a `DataLoader` and run a single epoch of training using `library.train.train_one_epoch`. Verify that the loss is calculated and returned. Run the `library.train.validate` function to ensure metric calculation works.
6.  **Inference Pipeline Verification**:
    *   Save the initialized model weights to a temporary directory, simulating the output of a K-Fold training run (saving 5 copies as `best_model_foldX.pth`).
    *   Call `library.inference.predict_test_set` using the mini test set and the temporary model directory.
    *   Verify that a valid submission CSV is generated with the correct columns and number of rows.
7.  **Cleanup**: All temporary files are stored in a subdirectory of `./working`.
