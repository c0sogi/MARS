# Weight-Inited Thick-Slab Independent Instance Network (WITS-Net)

This solution introduces a **Structural Innovation** in Input Representation and Network Initialization. It synthesizes the robustness of "Independent Instance Learning" (Idea 13) with the local volumetric fidelity of "Thick Slabs" (Idea 8), while strictly avoiding the failure modes of "Naive Stacking" (Cite solution_lesson_node_00009) and "Learnable Projections" (Cite solution_lesson_node_00025).

### Model
*   **Architecture:** We utilize **EfficientNet-B0** as the backbone.
*   **Input Structure:** The network accepts a **9-channel** input tensor $(224 \times 224 \times 9)$.
    *   Channels 0-2: **FLAIR** slab (3 consecutive slices).
    *   Channels 3-5: **T1wCE** slab (3 consecutive slices).
    *   Channels 6-8: **T2w** slab (3 consecutive slices).
*   **Structural Innovation: Weight Inflation Initialization:**
    *   Instead of using a learnable adapter (which failed, Cite solution_lesson_node_00025) or random initialization (which destroys priors), we mathematically adapt the pretrained ImageNet weights.
    *   The first convolutional layer weights $W_{old}$ of shape $(C_{out}, 3, K, K)$ are expanded to $W_{new}$ of shape $(C_{out}, 9, K, K)$.
    *   **Mechanism:**
        *   The weights for the 3 FLAIR channels are initialized as $W_{old}[:, 0, :, :] / 3$. (Distributing the "Red" channel energy).
        *   The weights for the 3 T1wCE channels are initialized as $W_{old}[:, 1, :, :] / 3$. (Distributing the "Green" channel energy).
        *   The weights for the 3 T2w channels are initialized as $W_{old}[:, 2, :, :] / 3$. (Distributing the "Blue" channel energy).
    *   *Rationale:* This preserves the pretrained feature extractors' response magnitude and semantics (edges/gradients) while allowing the model to process local 3D volumetric texture immediately, avoiding the signal dilution of MIP (Cite solution_lesson_node_00003).

### Data
The pipeline employs **Wide-Field Stratified Slab Sampling** to address the "Middle Slice Fallacy" (Cite solution_lesson_node_00002) and "Small Data" constraints (Cite solution_lesson_node_00010).

1.  **Independent Heuristic Alignment:**
    *   For each subject and modality, we identify the **Median Index** ($M$) independently. We do not project depth across modalities (Cite solution_lesson_node_00036).
2.  **Deterministic Slab Extraction:**
    *   We define a stride $\delta$ (e.g., 10 slices).
    *   We extract **3 Slabs** per subject. Each slab consists of 3 consecutive slices $[z-1, z, z+1]$.
        *   **Slab A (Lower):** Centered at $M-\delta$.
        *   **Slab B (Center):** Centered at $M$.
        *   **Slab C (Upper):** Centered at $M+\delta$.
    *   **Crucially**, we treat these 3 slabs as **independent training examples**, assigning the patient's global label to each. This triples the dataset size and forces the model to learn robust features from multiple anatomical cross-sections.
3.  **High-Fidelity Preprocessing:**
    *   **Precision:** All operations use **float32** (Cite solution_lesson_node_00016).
    *   **Normalization:** We apply **Independent Channel Min-Max Scaling** to $[0, 1]$ *before* stacking. This ensures high-intensity modalities (like T2w) do not suppress others (Cite solution_lesson_node_00023). We avoid ImageNet mean/std normalization (Cite solution_lesson_node_00017).

### Training
*   **Loss Function:** Binary Cross-Entropy (BCE) with Logits.
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Aggressive Weight Decay:** Set to **$1e-2$** to prevent overfitting on the small dataset (Cite solution_lesson_node_00010).
    *   **Dropout:** Use a rate of **0.3** (Cite solution_lesson_node_00044).
    *   **Augmentation:** Apply **Elastic Transformations** and **Grid Distortions** to the 9-channel slab. The same geometric transform is applied to all 9 channels to preserve alignment (Cite solution_lesson_node_00010).
*   **Strategy:** **5-Fold Cross-Validation** grouped by Subject ID (Cite solution_lesson_node_00028).

### Evaluation
*   **Inference:** For each test subject, deterministically generate the same 3 Slabs ($M-\delta, M, M+\delta$).
*   **Prediction:** Pass each 9-channel slab through the WITS-Net to obtain 3 probability scores.
*   **Aggregation:** The final prediction is the **mean** of these 3 scores. This acts as a deterministic ensemble, capturing volumetric context and robustness against positioning errors without the complexity of 3D architectures (Cite solution_lesson_node_00008).
