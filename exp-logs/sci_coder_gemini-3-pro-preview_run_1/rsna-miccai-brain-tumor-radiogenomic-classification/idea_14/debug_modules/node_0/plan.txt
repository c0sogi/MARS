The following script demonstrates the end-to-end usage of the provided WITS-Net library. It begins by overriding the default configuration to run in a fast "debug" mode (using a tiny subset of data and minimal epochs). It then verifies the data loading pipeline by instantiating the dataset and checking tensor shapes. Next, it initializes the model and verifies the custom 9-channel input adaptation. The script then executes the training loop and generates a submission using the inference pipeline. Finally, it validates the output submission file format.
