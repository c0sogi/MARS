2.  **Restore Default Dropout (0.2):** `Cite solution_lesson_node_00012` highlights that enforcing a higher dropout rate (0.3) manually caused a regression compared to the architecture's default (0.2). I will revert `DROPOUT_RATE` to 0.2.
3.  **Simplify Architecture:** By using a standard 3-channel input, I can remove the "Weight Inflation" initialization logic. This ensures we fully leverage the pretrained ImageNet weights without modification, preserving the learned priors (`Cite solution_lesson_node_00009`).
4.  **Deterministic Heuristic:** I will use only the center slice (offset 0), adhering to `Cite solution_lesson_node_00015` which favors deterministic geometric heuristics over stochastic or multi-instance sampling for this dataset.
5.  **Training Duration:** I will increase the number of epochs to 20 to ensure convergence, as the dataset size is effectively reduced (1 instance per subject instead of 3).

    def inflate_weights(self, old_layer, new_layer):
        """
        Implements Weight Inflation Initialization logic.

        The pretrained RGB weights (Shape: Out, 3, K, K) are distributed to the new
        9-channel weights (Shape: Out, 9, K, K) as follows:

        1. FLAIR (Channels 0-2) receives the Red channel weights / 3.
        2. T1wCE (Channels 3-5) receives the Green channel weights / 3.
        3. T2w   (Channels 6-8) receives the Blue channel weights / 3.

        Division by 3 ensures the total magnitude of activations remains consistent
        with the pretrained network's expectations.
        """
        with torch.no_grad():
            w_old = old_layer.weight.data  # Shape: (Out, 3, K, K)
            w_new = torch.zeros_like(new_layer.weight.data)  # Shape: (Out, 9, K, K)

            # Note: w_old[:, 0:1, :, :] keeps the channel dim for broadcasting

            w_new[:, 3:6, :, :] = w_old[:, 1:2, :, :] / 3.0

            w_new[:, 6:9, :, :] = w_old[:, 2:3, :, :] / 3.0
