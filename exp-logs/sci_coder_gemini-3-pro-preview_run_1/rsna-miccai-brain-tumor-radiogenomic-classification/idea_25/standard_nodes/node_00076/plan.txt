The implementation strategy follows the Corrected Anatomically-Anchored Weight-Inflated Volumetric (C-AA-WIV) Network design.

1.  **Setup & Integrity Check**: The script initializes the environment with fixed seeds for reproducibility. It loads the training and validation metadata, concatenates them to form the full training set, and verifies that the dataset size meets the expected count (~523 subjects) to prevent data truncation bugs.
2.  **5-Fold Cross-Validation**: It executes a stratified 5-fold cross-validation loop. For each fold, it calls `train_eval.run_fold` to train the EfficientNet-B0 model with the specific 9-channel volumetric input and Gaussian weight inflation.
3.  **OOF Inference**: After training each fold, the script reloads the best model checkpoint and performs inference on the validation fold to generate Out-Of-Fold (OOF) predictions. This ensures the validation metric reflects the best model state.
4.  **Metric Calculation**: The Area Under the ROC Curve (AUC) is calculated on the aggregated OOF predictions and printed in the required format `Final Validation Metric: <value>`.
5.  **Failure Analysis**: The script calculates the absolute error of the predictions. It then extracts filesystem metadata (file counts for FLAIR, T1wCE, T2w) as proxy features for image complexity and calculates their Pearson correlation with the error magnitude to identify systematic failure modes.
6.  **Submission**: If the final AUC exceeds the specified threshold (`0.6705...`), the script invokes the submission generation routine, which ensembles predictions from all 5 fold models on the test set.
