# Corrected Anatomically-Anchored Weight-Inflated Volumetric (C-AA-WIV) Network

This solution implements a **Structural Innovation** in Input Representation and Initialization. It combines the volumetric fidelity of "Thick Slabs" with the parameter efficiency of "Early Fusion," while enforcing strict **Data Integrity Protocols** and **Spatially-Preserved Augmentation** to correct the specific failure modes of previous iterations.

### Model
*   **Backbone:** We utilize **EfficientNet-B0**. This architecture is retained for its proven stability and parameter efficiency on this dataset (Cite solution_lesson_node_00002).
*   **Input Structure:** The network accepts a **9-channel** input tensor $(224 \times 224 \times 9)$, employing **Early Fusion** (Cite solution_lesson_node_00031).
    *   **Channels 0-2:** [FLAIR, T1wCE, T2w] at **Depth $z-\delta$**.
    *   **Channels 3-5:** [FLAIR, T1wCE, T2w] at **Depth $z$** (Centroid).
    *   **Channels 6-8:** [FLAIR, T1wCE, T2w] at **Depth $z+\delta$**.
    *   *Rationale:* Packing these views into a single tensor allows the model to learn volumetric texture gradients via convolution immediately, avoiding the signal dilution of Siamese pooling (Cite solution_lesson_node_00018) and the overfitting caused by treating correlated slices as independent samples (Cite solution_lesson_node_00058).
*   **Innovation: Gaussian Weight Inflation:**
    *   To utilize 9 channels without destroying ImageNet priors (Cite solution_lesson_node_00009) or using unstable learnable adapters (Cite solution_lesson_node_00025), we mathematically adapt the backbone's first convolutional layer weights $W_{rgb}$.
    *   We initialize with a **Center-Biased (Gaussian) Prior**:
        *   **Center Slices (Channels 3-5):** Initialize with **50%** of the original weight energy ($0.5 \times W_{rgb}$). This preserves the strong "Middle Slice" baseline behavior at initialization.
        *   **Peripheral Slices (Channels 0-2, 6-8):** Initialize with **25%** of the weight energy ($0.25 \times W_{rgb}$). This allows the model to gradually integrate volumetric context without starting from a high-entropy state.

### Data
The pipeline employs **Per-Modality Centroid Alignment** and **Strict Integrity Verification**.

1.  **Independent Anatomical Centroid Alignment:**
    *   Instead of the "Median File Index" (which fails on off-center scans, Cite solution_lesson_node_00002), we compute the **Z-axis Center of Mass** of the brain tissue.
    *   For **each modality independently**, we threshold pixels $>0$ to define the Brain ROI and calculate its geometric centroid index $C$. This handles varying Fields-of-View without the misalignment caused by cross-modality projection (Cite solution_lesson_node_00036).
2.  **Strided Volumetric Packing:**
    *   We define a stride $\delta = 5$ slices.
    *   We extract slices at $C-\delta$, $C$, and $C+\delta$ for each modality and stack them into a single 9-channel tensor per subject.
3.  **High-Fidelity Preprocessing:**
    *   **Precision:** Use **float32** to preserve dynamic range (Cite solution_lesson_node_00016).
    *   **Normalization:** Apply **Independent Channel Min-Max Scaling** to $[0, 1]$ *before* stacking (Cite solution_lesson_node_00023). Avoid ImageNet mean/std (Cite solution_lesson_node_00017).
4.  **Integrity Check:** Explicitly verify that the loaded dataset size matches the full training set count (~523 subjects) before training begins. This prevents the silent cache truncation bug that invalidated previous attempts (Cite solution_lesson_node_00071).

### Training
*   **Loss Function:** Binary Cross-Entropy (BCE) with Logits.
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Weight Decay:** Set to **$1e-2$** (aggressive) to prevent overfitting (Cite solution_lesson_node_00010).
    *   **Dropout:** Enforce a rate of **0.3** in the classifier (Cite solution_lesson_node_00044).
*   **Spatially-Preserved Augmentation:**
    *   Apply **Elastic Transformations**, **Grid Distortions**, **Rotations**, and **Flips**.
    *   **Strictly Exclude:** Random Translations (Shift) and Scaling. Since the data is aligned to the anatomical centroid, the tumor location is spatially anchored. Translation augmentation destroys this strong spatial prior and degrades performance (Cite solution_lesson_node_00065).
*   **Strategy:** **5-Fold Cross-Validation** grouped by Subject ID. This ensures the training set size (~418 subjects) remains above the critical mass required for generalization (Cite solution_lesson_node_00051).

### Evaluation
*   **Inference:** For each test subject, calculate the Per-Modality Centroid $C$ and deterministically generate the 9-channel input ($C-\delta, C, C+\delta$).
*   **Prediction:** Pass the tensor through the C-AA-WIV network.
*   **Submission:** Average the probabilities from the 5 fold models. This leverages the robustness of the volumetric context without the need for stochastic test-time ensembles (Cite solution_lesson_node_00015).
