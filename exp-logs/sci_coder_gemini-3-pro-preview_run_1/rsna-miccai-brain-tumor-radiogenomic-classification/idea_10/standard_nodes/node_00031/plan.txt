The solution implements the Tri-Stream Modality-Specific Volumetric Network (TMSV-Net) pipeline. It orchestrates the process by initializing the environment, loading the cached datasets (Train, Validation, Test) using the provided library functions, and executing a training loop with early stopping. The training utilizes the `TMSVNet` model, which processes FLAIR, T1wCE, and T2w modalities in parallel streams.

After training, the script re-evaluates the best model on the hold-out validation set to report the `Final Validation Metric`. It then performs a failure analysis by correlating the prediction error magnitude with the number of FLAIR slices per subject, providing insights into whether scan depth/volume impacts performance. Finally, if the validation AUC exceeds the specified threshold, it generates predictions for the test set, aggregates them by subject (averaging the expanded samples), and saves the `submission.csv`.
