The following script demonstrates the end-to-end usage of the provided VCAE (Verified Content-Anchored Ensemble) library.

**Strategy:**
1.  **Configuration Override**: We modify the global `Config` class to run in a "Demo Mode". This involves enabling `DEBUG` to use a tiny subset of data, reducing `NUM_EPOCHS` to 1, reducing `NUM_FOLDS` to 2, and limiting the `EXPERTS` dictionary to a single expert (Expert_B). This ensures the script runs quickly (within minutes) while exercising all code paths.
2.  **Data Pipeline Verification**: We instantiate the DataLoaders using `get_dataloaders` and assert that the output batch shapes and value ranges are correct (e.g., images are $B \times 3 \times 224 \times 224$ and normalized).
3.  **Model Architecture Verification**: We instantiate the `EfficientNetExpert` model and perform a forward pass with a dummy batch to verify the output shape matches the binary classification task ($B \times 1$).
4.  **Training Loop Execution**: We execute `run_expert_training`. This function handles the training loop, validation, and model checkpointing. We verify that the model artifact (`.pth` file) is created.
5.  **Inference & Submission**: We run `generate_submission`, which loads the trained model, performs inference on the test set, aggregates results, and generates a CSV. We verify the CSV structure and content.
