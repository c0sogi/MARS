# Stratified Instance-Level 2.5D Network (SIL-Net)

This solution introduces a **Data-Centric Structural Innovation**. Instead of increasing model complexity (which consistently failed in Ideas 2, 3, 5, 6, 7, 8, 10), we fundamentally alter the training paradigm from "Subject-Level Classification" to **"Independent Instance Learning"**.

This approach addresses three critical failure modes identified in the lessons:
1.  **Small Data:** It triples the effective training set size, allowing the high-capacity backbone to generalize better (Cite solution_lesson_node_00010).
2.  **Alignment Mismatch:** It uses **Native-Space Sampling** to avoid the artifacts caused by cross-modality geometric projection (Cite solution_lesson_node_00036).
3.  **Signal Dilution:** By training on instances independently, it forces the model to learn robust features from every slice, avoiding the "pooling" pitfalls of Siamese networks (Cite solution_lesson_node_00018).

### Model
*   **Architecture:** We utilize a standard **EfficientNet-B0** backbone initialized with ImageNet weights.
*   **Input:** A standard 3-channel 2D composite image $(224 \times 224 \times 3)$.
    *   Channel 1: **FLAIR** slice.
    *   Channel 2: **T1wCE** slice.
    *   Channel 3: **T2w** slice.
*   **Design Rationale:** We strictly adhere to **Early Fusion** (stacking modalities) to preserve parameter efficiency (Cite solution_lesson_node_00031). We retain the backbone's default hyperparameters (e.g., dropout) to avoid the "Silent Defaults" regression (Cite solution_lesson_node_00012).

### Data
The innovation lies in the **Native-Space Stratified Sampling** pipeline:

1.  **Independent Heuristic Sampling:**
    *   For each subject and **for each modality independently**, we sort the file list and identify the **Median Index** ($M$).
    *   We do *not* attempt to project the depth from one modality to another (e.g., "T2w depth 50% = FLAIR depth 50%"), as this failed due to varying Fields-of-View (Cite solution_lesson_node_00036).
2.  **Deterministic Data Expansion:**
    *   From each modality's sorted list, we extract 3 slices at indices: **$M-2$, $M$, and $M+2$**.
    *   We construct 3 distinct composite images per subject:
        *   Instance A: $[FLAIR_{M-2}, T1wCE_{M-2}, T2w_{M-2}]$
        *   Instance B: $[FLAIR_{M}, T1wCE_{M}, T2w_{M}]$
        *   Instance C: $[FLAIR_{M+2}, T1wCE_{M+2}, T2w_{M+2}]$
    *   **Crucially**, we treat these 3 images as **independent training samples**, assigning the patient's global `MGMT_value` label to each. This triples the dataset size while keeping the spatial sampling tight enough to minimize label noise (Cite solution_lesson_node_00015).
3.  **High-Fidelity Preprocessing:**
    *   **Precision:** All operations are performed in **float32** to preserve the dynamic range (Cite solution_lesson_node_00016).
    *   **Normalization:** We apply **Independent Channel Min-Max Scaling** to $[0, 1]$ *before* stacking. This prevents high-intensity modalities from suppressing low-intensity ones (Cite solution_lesson_node_00023) and avoids domain-inappropriate ImageNet statistics (Cite solution_lesson_node_00017).

### Training
*   **Loss Function:** Binary Cross-Entropy (BCE) with Logits.
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Aggressive Weight Decay:** Set to **$1e-2$**. Strong regularization is critical for small medical datasets (Cite solution_lesson_node_00010).
    *   **Augmentation:** We apply **Elastic Transformations** and **Grid Distortions**. Non-rigid augmentations are essential for modeling anatomical variance (Cite solution_lesson_node_00010).
*   **Validation Strategy:** We employ **5-Fold Cross-Validation** grouped by **Subject ID**. This ensures that all 3 instances from a single patient reside in the same fold (either all train or all val) to prevent data leakage (Cite solution_lesson_node_00028).

### Evaluation
*   **Inference:** For each test subject, we deterministically generate the same 3 instances ($M-2, M, M+2$) using the independent median heuristic.
*   **Consensus Aggregation:** We pass each instance through the model to obtain 3 probability scores. The final prediction is the **mean** of these scores. This acts as a deterministic ensemble, robustifying the prediction against slight positioning offsets without the complexity of 3D architectures.
