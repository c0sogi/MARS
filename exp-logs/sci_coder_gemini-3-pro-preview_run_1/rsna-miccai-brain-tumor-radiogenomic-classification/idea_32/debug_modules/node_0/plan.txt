This script demonstrates the end-to-end usage of the provided machine learning pipeline components for the Glioblastoma genetic subtype prediction task.

The implementation strategy follows these steps:
1.  **Data Processing Verification**: It loads a small subset of the training metadata and processes the DICOM images into 3D volumes (9 channels) using `process_dataset`. It asserts that the output dimensions match the expected shape `(N, 224, 224, 9)`.
2.  **Dataset & Augmentation Verification**: It instantiates the `BraTSDataset` class. It specifically verifies the `StructuredInputDropout` mechanism by forcing the dropout probability to 1.0 and asserting that either the center channels or the peripheral channels are zeroed out in the returned tensors.
3.  **Model Architecture Verification**: It initializes the `RNVSNetwork` and confirms that the first convolutional layer has been successfully modified to accept 9 input channels (instead of the standard 3). It also performs a forward pass with dummy data to verify output shapes.
4.  **Full Training Pipeline**: It executes a single epoch of the training loop using `run_training(debug=True)` to ensure the `trainer`, `dataloader`, and `model` integrate correctly without runtime errors.
5.  **Inference Verification**: It checks that the pipeline successfully generates a `submission.csv` file.
