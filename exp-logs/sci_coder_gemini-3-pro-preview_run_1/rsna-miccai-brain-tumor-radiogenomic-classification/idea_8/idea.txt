# 2.5D EfficientNet with Learnable Multi-Slice Projection (LMSP)

This solution introduces a **Learnable Input Adapter** to bridge the gap between the robustness of 2D pre-trained models and the informational value of volumetric data. It addresses the "Middle Slice Fallacy" (Cite solution_lesson_node_00002) by providing volumetric context, while avoiding the pitfalls of naive channel stacking (Cite solution_lesson_node_00009), texture-destroying MIP (Cite solution_lesson_node_00003), and stochastic label noise (Cite solution_lesson_node_00015).

### Model
The architecture consists of a **Learnable Projection Stem** prepended to a standard **EfficientNet-B0** backbone.
1.  **Input:** A 9-channel tensor $(H, W, 9)$ representing a "Thick Slab" of the brain. The channels correspond to 3 MRI modalities (FLAIR, T1wCE, T2w) across 3 spatially adjacent depth slices (Middle-1, Middle, Middle+1).
2.  **Learnable Adapter (Innovation):** A `Conv2d(in_channels=9, out_channels=3, kernel_size=1)` layer.
    *   **Purpose:** Instead of manually collapsing slices (MIP) or modifying the backbone's first layer (which destroys ImageNet priors), this layer learns the optimal linear combination of the 9 input channels to synthesize a 3-channel "Super-RGB" image.
    *   **Initialization:** To ensure stability, we initialize this layer to act as an **Identity Pass-Through** for the middle slice. The weights corresponding to the middle slice channels are set to 1 (identity), while weights for the neighboring slices are initialized to 0. This guarantees the model starts with the performance of the proven "Middle Slice" baseline (Cite solution_lesson_node_00002) and gradually learns to incorporate contextual information from the adjacent slices during training.
3.  **Backbone:** Standard **EfficientNet-B0** initialized with ImageNet weights. It processes the synthesized 3-channel output of the adapter.
4.  **Head:** Global Average Pooling followed by a fully connected layer with sigmoid activation.

### Data
The data pipeline employs **Deterministic Slab Sampling** and **High-Fidelity Preprocessing**.
1.  **Sampling:** For each subject, we identify the file lists for FLAIR, T1wCE, and T2w. We select **3 consecutive slice indices** centered at the geometric median of the volume (Indices: $M-1, M, M+1$). This provides deterministic local context (Cite solution_lesson_node_00015) without the memory cost of full sequences (Cite solution_lesson_node_00008).
2.  **Preprocessing:**
    *   **Precision:** Load and process all data as **float32**. We strictly avoid casting to `uint8` to preserve the 12-16 bit dynamic range of the MRI sensors (Cite solution_lesson_node_00016).
    *   **Normalization:** Apply **Independent Channel Min-Max Scaling** to $[0, 1]$. We normalize each modality (FLAIR, T1wCE, T2w) separately *before* stacking to prevent high-intensity modalities from suppressing low-intensity ones (Cite solution_lesson_node_00023). We avoid ImageNet mean/std normalization (Cite solution_lesson_node_00017).
3.  **Input Construction:** Stack the processed slices to form the $(224, 224, 9)$ input tensor.

### Training
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Weight Decay:** Set to **$1e-2$** (aggressive) to prevent overfitting on the small dataset (Cite solution_lesson_node_00010).
    *   **Dropout:** Use the default dropout rate of the backbone (Cite solution_lesson_node_00012).
*   **Augmentation:** Apply **Elastic Transformations** and **Grid Distortions** to the 9-channel slab. Crucially, the same geometric transformation is applied to all 9 channels simultaneously to preserve spatial alignment (Cite solution_lesson_node_00010).
*   **Strategy:** Employ **5-Fold Cross-Validation** to mitigate stochastic variance (Cite solution_lesson_node_00011).

### Evaluation
*   **Inference:** For each test subject, deterministically generate the same 9-channel input (Middle-1, Middle, Middle+1).
*   **Prediction:** Pass the input through the trained model (Adapter -> Backbone -> Head). The final submission is the average probability across the 5 folds. This approach leverages the "Ensemble of Deterministic Models" to maximize robustness.
