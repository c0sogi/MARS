# Multi-Planar 2.5D Holographic Network with ROI-Centering

This solution introduces a **Multi-Planar Siamese Architecture**. Instead of relying on a single axial "middle slice" (which risks missing the tumor, Cite solution_lesson_node_00002) or redundant adjacent slices (which dilute the signal, Cite solution_lesson_node_00018), this approach effectively "triangulates" the tumor by processing the geometric center of the brain from three orthogonal perspectives (Axial, Coronal, and Sagittal).

### Model
The architecture is a **Three-Stream Siamese Network** with shared weights.
*   **Backbone:** A single **EfficientNet-B0** (pretrained on ImageNet) serves as the shared feature extractor. Using a shared backbone acts as a powerful regularizer for this small dataset, forcing the model to learn rotation-invariant texture features applicable across all anatomical planes (Cite solution_lesson_node_00010).
*   **Input:** The network accepts 3 distinct inputs per subject, each a 3-channel composite (FLAIR, T1wCE, T2w):
    1.  **Axial View:** The central slice along the Z-axis (Transverse).
    2.  **Coronal View:** The central slice along the Y-axis (Frontal).
    3.  **Sagittal View:** The central slice along the X-axis (Lateral).
*   **Fusion Head:** The three feature vectors (output of the backbone's Global Average Pooling) are **concatenated** into a single vector. This preserves the distinct spatial information from each view, unlike element-wise pooling which failed due to signal dilution (Cite solution_lesson_node_00018). The concatenated vector is passed to a fully connected layer with a sigmoid activation to predict `MGMT_value`.

### Data
The data pipeline implements a **Content-Based Geometric Centering** strategy to address the "Middle Slice Fallacy" (Cite solution_lesson_node_00002).
1.  **3D Reconstruction & ROI Cropping:** For each subject, we load the full stack of DICOMs to reconstruct the 3D volume. We then compute the **3D Bounding Box** of the non-zero pixel values (the brain tissue), effectively trimming the black background and neck artifacts.
2.  **Orthogonal Extraction:** We calculate the geometric center of this *brain-specific ROI* (not the file list center) and extract the middle slice for each of the three orthogonal planes (Axial, Coronal, Sagittal). This ensures the input views intersect the core of the brain tissue, regardless of the patient's position in the scanner.
3.  **Preprocessing:**
    *   **Resolution:** Resize all views to $224 \times 224$.
    *   **Precision:** Maintain **float32** precision throughout. We strictly avoid casting to `uint8` to preserve the high dynamic range of the MRI sensor data (Cite solution_lesson_node_00016).
    *   **Normalization:** Apply **Instance-level Min-Max Scaling** to $[0, 1]$. We avoid ImageNet mean/std normalization as it distorts the grayscale histograms of medical data (Cite solution_lesson_node_00017).

### Training
*   **Loss Function:** Binary Cross-Entropy (BCE) with Logits.
*   **Optimizer:** AdamW with a learning rate of $1e-4$.
*   **Regularization:**
    *   **Weight Decay:** Set to **$1e-2$** to aggressively penalize complexity in the small-data regime (Cite solution_lesson_node_00010).
    *   **Dropout:** Use the default dropout rate of the EfficientNet backbone. We avoid manually overriding this default, as "fixing" it has previously led to performance regression (Cite solution_lesson_node_00012).
*   **Augmentation:** Apply **Elastic Transformations** and **Grid Distortions** independently to each of the 3 views. Non-rigid augmentations are critical for preventing overfitting (Cite solution_lesson_node_00010).

### Evaluation
*   **Strategy:** Perform **5-Fold Cross-Validation** to mitigate the high stochastic variance observed in single training runs (Cite solution_lesson_node_00011).
*   **Inference:** For each test subject, generate the 3 orthogonal views using the ROI-Centering logic. Pass the triplet through the Siamese network to obtain the probability. The final submission will be the average prediction across the 5 folds.
