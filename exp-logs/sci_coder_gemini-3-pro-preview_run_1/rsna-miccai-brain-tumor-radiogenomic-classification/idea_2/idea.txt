To address the limitations of previous approaches—specifically the failure of geometric heuristics (Cite solution_lesson_node_00002), the loss of texture in projections (Cite solution_lesson_node_00003), and the unreliability of unsupervised variance metrics (Cite solution_lesson_node_00006)—I propose a **Multiple Instance Learning (MIL) Network with Attention**.

This approach fundamentally shifts the problem formulation from "classifying a single representative image" to "classifying a bag of candidate slices," allowing the model to learn *which* slices contain the relevant tumor signal in a supervised manner.

# Model
The architecture is designed as a **2.5D Multiple Instance Learning (MIL) Network**.
*   **Input Structure:** Instead of a single image, the input for each subject is a "bag" (sequence) of $N$ 2D composite images (e.g., $N=32$), sampled from the 3D volume. Each image in the bag is a 3-channel composite of spatially aligned FLAIR, T1wCE, and T2w slices.
*   **Feature Extractor (Instance Level):** A shared **EfficientNet-B0** backbone (pretrained on ImageNet) processes each of the $N$ images independently. This extracts a high-dimensional feature vector for every slice, preserving the local textural details and cross-sectional anatomy that were lost in projection-based methods (Cite solution_lesson_node_00003).
*   **Attention Aggregation (Bag Level):** The $N$ feature vectors are fed into a **Gated Attention Mechanism**. This module learns a scalar weight for each slice, representing its relevance to the prediction. The final patient-level representation is a weighted sum of the slice features. This allows the model to dynamically "focus" on slices containing tumor tissue and ignore healthy or noisy slices, overcoming the "Middle Slice Fallacy" (Cite solution_lesson_node_00002) and avoiding the pitfalls of unsupervised selection metrics (Cite solution_lesson_node_00006).
*   **Classifier:** The aggregated feature vector is passed through a fully connected layer with a sigmoid activation to output the final methylation probability.

# Data
*   **Sampling Strategy:** To ensure the tumor is captured without relying on a single geometric point, we employ **Uniform Depth Sampling**.
    1.  For each subject, sort the DICOM files by instance number for the three modalities (FLAIR, T1wCE, T2w).
    2.  Discard the top and bottom 10% of the volume to remove non-brain noise (skull caps/neck).
    3.  From the remaining volume, uniformly sample $N=32$ indices.
    4.  Load the corresponding slices to form $N$ composite images of shape $(256, 256, 3)$.
*   **Normalization:** Apply Min-Max scaling to each slice independently to standardizing pixel intensities to $[0, 1]$.
*   **Augmentation:** Apply standard 2D augmentations (random rotations, flips, brightness contrast) to the slices during training. Crucially, apply the *same* random transformation parameters to all $N$ slices in a bag during a single step to preserve spatial consistency, or treat them independently to encourage robustness; independent augmentation is generally preferred in MIL to prevent the model from overfitting to specific artifacts.

# Training
*   **Loss Function:** Use **Binary Cross-Entropy (BCE) Loss** on the final bag-level prediction.
*   **Optimizer:** Use **AdamW** with a learning rate of $1e-4$ and weight decay of $1e-2$.
*   **Regularization:** Implement **Dropout** (p=0.5) before the final classification layer and within the attention mechanism to prevent the model from relying on a single "lucky" slice.
*   **Strategy:** Train for 15-20 epochs. Since the effective batch size is smaller (due to processing $N$ images per subject), use gradient accumulation if necessary to maintain a stable batch size of 8-16 subjects (processing $8 \times 32 = 256$ images per forward pass).

# Evaluation
*   **Inference:** For each test subject, generate the bag of $N=32$ slices using the same uniform sampling strategy.
*   **Prediction:** Pass the bag through the trained MIL network. The model will internally weight the slices and output a single probability score.
*   **Submission:** Save the predicted probability and `BraTS21ID` to the submission file.
