The following script demonstrates the end-to-end usage of the provided library components for the glioblastoma genetic subtype classification task.

### Implementation Strategy

1.  **Setup & Imports**: We import the necessary classes and functions from the `library` package (`dataset`, `model`, `engine`, `config`, `utils`).
2.  **Data Loading & Subsetting**: To ensure the demonstration runs quickly (under 1 hour), we load the generated metadata files and create small subsets (16 training samples, 8 validation samples, 8 test samples).
3.  **Preprocessing**: We utilize `prepare_data_cache` to scan the directory structures for the subsetted data. This generates the necessary file lists for the dataset class.
4.  **Dataset & Loader Instantiation**: We create `RSNADataset` instances for training, validation, and testing, applying the appropriate Albumentations transforms. These are wrapped in PyTorch `DataLoader`s.
5.  **Model Initialization**: We instantiate the `MILNet` (Multiple Instance Learning Network) with the EfficientNet backbone and move it to the available device (GPU/CPU).
6.  **Training**: We execute `run_training` for a limited number of epochs (2) to demonstrate the training loop, loss calculation, and metric evaluation without consuming excessive time.
7.  **Inference**: We use `generate_submission` to predict probabilities for the test subset and save the results to a CSV file.
8.  **Verification**: Finally, we perform assertions to verify that the submission file is created correctly, follows the required format, and contains valid probability values.
