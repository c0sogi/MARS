This script demonstrates the end-to-end usage of the provided machine learning library for the Glioblastoma genetic subtype prediction task.

### Strategy
1.  **Configuration & Patching**: To ensure the demonstration runs quickly and does not overwrite critical files, we monkey-patch the configuration variables in the imported modules (`library.config`, `library.dataset`, `library.engine`). We enable `DEBUG` mode, reduce the dataset size to 6 samples, set `NUM_EPOCHS` to 1, and redirect cache/output paths to a temporary directory.
2.  **Data Loading**: We use `library.dataset.get_datasets(load_cached_data=False)` to trigger the DICOM processing pipeline on the small subset of data. This verifies the image loading, resizing, and normalization logic.
3.  **Model Initialization**: We instantiate the `VAANet` model using `library.model.build_model()` and move it to the GPU.
4.  **Training**: We create PyTorch DataLoaders and run a single epoch of training using `library.engine.train_model`. We verify that the training loop completes and returns a validation score.
5.  **Inference**: We generate predictions on the test subset using `library.engine.generate_submission` and save them to a CSV file.
6.  **Validation**: Finally, we assert that the submission file exists, follows the correct schema, and contains valid probability values.
