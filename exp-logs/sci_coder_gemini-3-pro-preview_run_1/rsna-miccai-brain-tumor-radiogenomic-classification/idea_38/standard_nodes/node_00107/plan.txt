The following implementation orchestrates the Verified Anatomically-Anchored (VAA) Network pipeline. It performs 5-Fold Cross-Validation on the combined training and validation data to maximize the utility of the small dataset (~500 subjects). The script manages the full lifecycle: data loading (with caching), stratified splitting, model training with early stopping, out-of-fold (OOF) validation, failure analysis, and conditional submission generation.

**Strategy:**
1.  **Data Unification**: We merge the provided `train` and `val` splits into a single pool to perform rigorous 5-Fold Stratified Cross-Validation. This ensures robust performance estimation and allows us to ensemble 5 models for the final test set prediction.
2.  **Fast Baseline Execution**: We limit training to 15 epochs with an early stopping patience of 5. This fits comfortably within the time limit while allowing sufficient convergence for the EfficientNet-B0 backbone.
3.  **Failure Analysis**: We compute pixel-level statistics (mean and standard deviation per channel) for every subject and correlate these with the model's prediction error on the validation set. This identifies if specific image properties (e.g., low contrast scans) are driving failures.
4.  **Submission Logic**: We strictly adhere to the requirement of only generating a submission if the OOF ROC AUC exceeds the specified threshold (`0.6705454545454544`).
