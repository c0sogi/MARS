# Model
I propose a **Hybrid Semantic-Structural Ensemble** that integrates two distinct modeling paradigms to capture both the high-level intent and the low-level morphological patterns of insulting comments.

1.  **Deep Semantic Branch (Contextual)**: The first component is a pre-trained Transformer model (e.g., **RoBERTa** or **DeBERTa**). Unlike the previous Bag-of-Words approaches, this architecture utilizes self-attention mechanisms to understand the *context* of words. This is critical for distinguishing between "profanity used casually" and "profanity intended as an insult," a key distinction noted in the task guidelines.
2.  **Robust Structural Branch (Statistical)**: The second component is an **NBSVM (Naive Bayes - Support Vector Machine)**. This enhances the previous Logistic Regression baseline by scaling the TF-IDF features with Naive Bayes log-count ratios before feeding them into a linear classifier. This branch explicitly retains the **Dual-Granularity TF-IDF** approach (Word + Character n-grams).
    *   We preserve the specific **Character N-grams** to maintain robustness against obfuscation and noise (Cite solution_lesson_node_00002).
3.  **Ensemble Aggregation**: The final prediction is a weighted average of the probability scores from both branches. This combines the Transformer's semantic grasp with the Linear model's precision on specific lexical triggers.

# Data
The data processing pipeline will diverge for the two branches to maximize their respective strengths:

1.  **For the Semantic Branch**:
    *   Input text will be processed using the specific **Subword Tokenizer** associated with the chosen Transformer (e.g., Byte-Pair Encoding). This preserves case information and sentence structure necessary for the model to interpret intent.
2.  **For the Structural Branch**:
    *   **Preprocessing**: Text will be lowercased and stripped of unicode characters to standardize the input.
    *   **Feature Extraction**: We will generate a sparse feature matrix using two TF-IDF vectorizers.
        *   **Word N-grams**: Restricted to the range **(1, 2)** (unigrams and bigrams).
        *   **Character N-grams**: Restricted to the range **(3, 5)**.
        *   This specific configuration explicitly adheres to the lesson regarding "Feature Space Dilution," avoiding the overfitting risks associated with aggressive expansion into trigrams or single characters (Cite solution_lesson_node_00004).

# Training
The training procedure utilizes a split-and-merge strategy:

1.  **Semantic Training**: Fine-tune the Transformer model on the training data using the **AdamW** optimizer with a linear learning rate decay. We will employ techniques like **early stopping** based on validation loss to prevent overfitting the small dataset (~3,000 samples).
2.  **Structural Training**:
    *   Compute the Naive Bayes log-count ratios ($r$) for each feature based on the training labels.
    *   Element-wise multiply the TF-IDF matrix by $r$.
    *   Train a linear classifier (e.g., Logistic Regression or Linear SVM) on this scaled matrix.
3.  **Ensemble Optimization**: Use **K-Fold Cross-Validation** (e.g., 5-fold) to generate Out-of-Fold (OOF) predictions for both models. These OOF predictions will be used to determine the optimal scalar weights for blending the two models (e.g., 0.6 * Transformer + 0.4 * NBSVM) to maximize the AUC metric.

# Evaluation
To generate predictions for the submission:
1.  Pass the test set text through the fine-tuned Transformer to obtain probability vector $P_{sem}$.
2.  Pass the test set text through the fitted TF-IDF vectorizers and NBSVM model to obtain probability vector $P_{struct}$.
3.  Compute the final prediction as $P_{final} = w \cdot P_{sem} + (1-w) \cdot P_{struct}$, using the weights $w$ derived from the cross-validation step.
