### Implementation Strategy

1.  **Configuration Setup**: We will override the default `Config` parameters to enable `debug` mode and reduce the number of epochs to 1. This ensures the demonstration runs quickly on a small subset of data (50 samples).
2.  **Data Preparation**: We will utilize `prepare_fold_data` from `library.dataset` to load the metadata, generate SVD features using `library.features`, and create PyTorch Datasets. We will verify the integrity of the generated datasets (length and item structure).
3.  **Model Initialization**: We will instantiate the `HybridModel` from `library.model` using the backbone specified in the config. We will perform a dummy forward pass with a batch of data to verify the model architecture and output dimensions.
4.  **Adversarial Weight Perturbation (AWP)**: We will instantiate the `AWP` class and simulate an attack and restore cycle to ensure the weight perturbation logic executes correctly without errors.
5.  **Training & Validation Loop**: We will execute a single epoch of training and validation using `train_one_epoch` and `valid_one_epoch` from `library.trainer`. This demonstrates the integration of the optimizer, scheduler, loss calculation, and metric monitoring.
6.  **Inference**: We will run the `predict` function on the test dataset to demonstrate how to generate final predictions and verify the output shape matches the number of test samples.
