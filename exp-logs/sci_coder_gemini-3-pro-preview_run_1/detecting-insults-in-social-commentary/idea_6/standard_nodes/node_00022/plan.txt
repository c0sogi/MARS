Implementation strategy:
1.  **Environment Setup**: Initialize the random seed using `seed_everything` from the library to ensure reproducibility.
2.  **Data Loading**: Load the pre-split metadata (`train.csv`, `validation.csv`, `test.csv`) using `load_data`.
3.  **Feature Engineering**: Generate structural features (TF-IDF + TruncatedSVD) using `get_structural_features`. This fits on the training set and transforms validation and test sets.
4.  **Stage 1 (Domain Adaptation)**: Check if a pre-trained MLM model exists. If not, execute `run_mlm` to fine-tune the DeBERTa backbone on the combined text corpus.
5.  **Stage 2 (Supervised Training)**:
    *   Construct a combined dataframe of training and validation data.
    *   Define explicit indices to respect the fixed train/validation split provided in the metadata.
    *   Utilize the `run_fold` function from `trainer.py` (treating the fixed split as "Fold 0") to train the model and evaluate it.
6.  **Validation Reporting**: Print the `Final Validation Metric` as returned by the training process.
7.  **Failure Analysis**:
    *   Reload the best-saved model from Stage 2.
    *   Run inference on the validation set to obtain probability predictions.
    *   Calculate the absolute error between predictions and ground truth.
    *   Compute correlations between the error magnitude and input text length (character and word counts) to identify error patterns.
8.  **Submission**:
    *   Compare the final validation AUC against the required threshold (`0.9586453201970443`).
    *   If the threshold is met, load the sample submission file, populate it with the test set predictions, and save it to the specified output path.
