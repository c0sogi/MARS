The runtime error occurs because the `TruncatedSVD` algorithm automatically caps the number of output components to the number of samples when the dataset is smaller than the requested `n_components`. In the demo execution, the training fold contains only 15 samples, forcing the SVD output to 15 dimensions instead of the configured 16. However, the `HybridModel` is statically initialized using `Config.svd_components` (16), creating a shape mismatch in the `LayerNorm` layer.

To fix this, I will modify `library/pipeline.py` to initialize the `HybridModel` using the actual dimension of the generated SVD features (`train_svd.shape[1]`) rather than the static configuration value. This ensures the model architecture dynamically adapts to the data constraints (Cite debug_lesson_4).
