The issue is that `scaler.unscale_(optimizer)` is being called twice within a single training step when Adversarial Weight Perturbation (AWP) is active: once inside the AWP block and again unconditionally before gradient clipping. PyTorch's `GradScaler` forbids multiple calls to `unscale_` between updates because it modifies gradients in-place. To fix this, I will make the second `unscale_` call mutually exclusive with the first by placing it inside an `else` block, ensuring it only runs if AWP (which handles unscaling) did not run.
