The `RuntimeError: unscale_() has already been called on this optimizer since the last update()` occurs because `scaler.unscale_(optimizer)` is invoked twice within a single training step when Adversarial Weight Perturbation (AWP) is active. The first call happens inside the AWP block to prepare gradients for the attack, and the second call happens unconditionally before gradient clipping. PyTorch's `GradScaler` enforces that `unscale_` is called exactly once per step.

To fix this, I will modify the control flow in `library/model.py` to ensure `scaler.unscale_(optimizer)` is called in the `else` branch only if the AWP block (which already performs unscaling) was not executed. This ensures the optimizer is always unscaled exactly once before gradient clipping.
