To address the task of detecting insulting comments with a highly efficient baseline, I propose the following approach. This solution prioritizes computational speed and simplicity while effectively handling the specific linguistic challenges of insults (such as obfuscation and unique phrasing) without relying on the specific Bayesian scaling of NBSVM, the dimensionality reduction of SVD, or deep neural networks.

# Model
The architecture is a **Logistic Regression classifier operating on Dual-Granularity TF-IDF features**.
*   **Design**: The core model is a linear classifier (a single dense layer with a sigmoid activation function). Unlike the NBSVM approach, this model learns weights directly from the raw TF-IDF statistics without injecting Naive Bayes log-count priors. Unlike the LightGBM approach, it operates directly on the high-dimensional sparse feature space rather than compressed dense vectors.
*   **Key Components**: The model relies on a "wide" feature set that combines semantic understanding (words) with morphological pattern matching (characters). This linearity ensures the model is interpretable and extremely fast to train.

# Data
The data processing pipeline focuses on capturing both the meaning and the structure of the text to handle standard and obfuscated insults.
1.  **Preprocessing**: Convert all text to lowercase and strip unicode characters to standardize the input.
2.  **Feature Extraction (Dual-Granularity)**:
    *   **Word N-grams**: Apply a TF-IDF vectorizer to extract word unigrams and bigrams. This captures standard offensive phrases and context.
    *   **Character N-grams**: Apply a separate TF-IDF vectorizer to extract character n-grams (e.g., lengths 3 to 5). This is crucial for detecting obfuscated profanity (e.g., "f**k", "sh!t") or typos, which word-level tokenizers often miss.
3.  **Integration**: Concatenate the sparse matrices from both vectorizers into a single unified feature set.

# Training
The training procedure is designed for speed and stability on the high-dimensional input.
*   **Objective**: Minimize the Binary Cross-Entropy loss (Log Loss).
*   **Optimization**: Use a standard solver (such as L-BFGS or Liblinear) which is highly efficient for sparse linear models.
*   **Regularization**: Apply L2 regularization (Ridge) to prevent overfitting, given the large number of features relative to the dataset size (approx. 3,000 samples).
*   **Strategy**: Enable class weighting (balanced) to automatically adjust the loss function for the ~26% positive class prevalence, ensuring the model does not bias heavily towards the neutral class.

# Evaluation
To generate predictions:
1.  Transform the test set text using the fitted Word and Character TF-IDF vectorizers from the training step.
2.  Concatenate the resulting sparse matrices.
3.  Pass the matrix through the trained Logistic Regression model.
4.  Output the probability scores (via the `predict_proba` method) to satisfy the submission requirement of a continuous number between [0, 1].
