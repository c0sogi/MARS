    *   Inside the loop, I will instantiate the `HybridDeberta` model and `Trainer`.

    *   After training, I will use the trained model to generate inference predictions on the **fixed hold-out validation set** (`metadata/validation.csv`) and the **test set**.
    *   I will save the model weights for each fold to ensure reproducibility and potential reuse, though inference is done immediately to save memory.
4.  **Ensembling**: I will average the probability predictions from all 5 folds for both the hold-out validation set and the test set to reduce variance.
5.  **Metric Calculation**: I will compute the AUC on the hold-out validation set using the ensemble predictions and print it as `Final Validation Metric`.
6.  **Failure Analysis**: I will compute the absolute error of the ensemble predictions on the validation set and calculate Pearson correlations with text features (character count, word count, caps ratio, exclamation count).
7.  **Submission**: I will compare the final metric against the threshold (`0.9582101806239737`). If it passes, I will format the test predictions into a DataFrame matching `sample_submission_null.csv` and save it to `./submission/submission.csv`.
