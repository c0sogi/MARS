The following script demonstrates the end-to-end usage of the provided library files to train a Hybrid DeBERTa model and generate predictions.

**Strategy:**
1.  **Configuration Override**: We modify the `Config` class at runtime to enable `debug` mode, reduce `epochs` to 1, and lower `batch_size` and `svd_components`. This ensures the script runs quickly (within minutes) and uses minimal resources while still exercising all code paths (Data Processing, Model, AWP, Trainer).
2.  **Data Processing**: We call `get_datasets` with `load_cached_data=False` to force the regeneration of features using the reduced `svd_components` setting. We verify the integrity and shape of the resulting datasets.
3.  **Model Verification**: We instantiate the `HybridDeberta` model and perform a dummy forward pass with a single batch to verify that the architecture and tensor shapes are correct before starting the training loop.
4.  **Training & Inference**: We utilize the `Trainer` class to run the training loop (including Adversarial Weight Perturbation) and then generate predictions on the test set.
5.  **Submission**: Finally, we format the predictions into a CSV file matching the required submission format.
