Based on the lessons learned from the previous experiments, I propose the following optimized strategy. This solution evolves the "Hybrid DeBERTa" concept (Idea 3) by introducing **Adversarial Robustness** and **Multi-Sample Dropout** to address the specific challenges of small-data generalization and obfuscated text.

# Model
I propose a **Robust Hybrid DeBERTa-v3 with Multi-Sample Dropout**. This architecture retains the successful fusion of semantic and structural features but redesigns the classification head and integration strategy to maximize stability and generalization.

1.  **Semantic Backbone**: We will utilize **`microsoft/deberta-v3-base`** (Cite solution_lesson_node_00015). Its disentangled attention mechanism provides superior natural language understanding compared to RoBERTa. We will extract the **`[CLS]` token embedding** for classification (Cite solution_lesson_node_00008).
2.  **Structural Branch**: We will generate a **Multi-Granularity Feature Vector** by concatenating **Word N-grams (1-2)** and **Character N-grams (3-5)** (Cite solution_lesson_node_00012).
    *   These sparse features will be compressed to a 256-dimensional dense vector using **TruncatedSVD**.
    *   **Innovation**: We will apply **Layer Normalization** to this SVD vector before fusion. This ensures the statistical features have a similar scale and distribution to the Transformer embeddings, facilitating smoother gradient flow during fusion.
3.  **Fusion & Classification Head (Structural Innovation)**:
    *   The 768-dim `[CLS]` embedding and the 256-dim normalized SVD vector are concatenated.
    *   Instead of a single dropout layer, we implement **Multi-Sample Dropout**. The fused vector is passed through 5 separate dropout masks (with different random seeds) in parallel. The outputs are fed into shared linear layers, and the final logits are averaged. This technique acts as an "ensemble within a model," significantly reducing overfitting on small datasets (~3k samples) by forcing the model to rely on diverse feature subsets.

# Data
The data pipeline prioritizes raw signal integrity and multi-view representation:

1.  **Text Preprocessing**: We will feed **raw, uncleaned text** to the DeBERTa tokenizer (Cite solution_lesson_node_00009). This allows the model to learn from natural noise (e.g., capitalization, punctuation) which contains insult signals (Cite solution_lesson_node_00004).
2.  **Feature Engineering**:
    *   Fit TF-IDF vectorizers (Word 1-2, Char 3-5) on the training corpus.
    *   Fit TruncatedSVD (256 components) on the TF-IDF matrix of the training data.
    *   Transform both Training and Test data using these fitted transformers to create the static structural inputs.

# Training
The training procedure introduces **Adversarial Regularization** to create a smoother decision boundary, critical for a small dataset with noisy labels.

1.  **Adversarial Weight Perturbation (AWP)**: We will implement AWP in the training loop. After the standard forward and backward pass, we explicitly perturb the model's embedding weights in the direction that maximizes the loss (adversarial attack), and then perform a second update to minimize this "worst-case" loss. This forces the model to find a flat local minimum, improving robustness against the "obfuscation" and "unique phrasing" mentioned in the task description.
2.  **Differential Learning Rates**: We will strictly apply differential optimization (Cite solution_lesson_node_00015):
    *   **Backbone**: $2 \times 10^{-5}$ (to preserve pre-trained knowledge).
    *   **Head/Fusion Layers**: $1 \times 10^{-3}$ (to rapidly learn the new fusion logic).
3.  **Loss Function**: Binary Cross-Entropy Loss.
4.  **Scheduler**: Linear decay with a small warmup ratio (0.05).

# Evaluation
1.  **Cross-Validation**: Perform Stratified 5-Fold Cross-Validation. This is essential to gauge the stability of the model given the small dataset size.
2.  **Inference**:
    *   For each fold, process the test set to generate Token IDs and SVD vectors.
    *   Pass inputs through the trained model to get probability scores.
    *   Average the probabilities across all 5 folds to produce the final submission. This averaging further smooths variance and improves the AUC score.
