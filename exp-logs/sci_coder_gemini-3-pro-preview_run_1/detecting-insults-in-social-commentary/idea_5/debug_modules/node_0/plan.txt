This script demonstrates the end-to-end usage of the provided machine learning library for the Insult Detection task. It performs the following steps:
1.  **Configuration & Setup**: Sets random seeds and overrides default configuration parameters (e.g., batch size, epochs) to ensure a rapid execution suitable for demonstration.
2.  **Data Loading & Processing**: Utilizes `load_data` to generate TF-IDF/SVD features and create PyTorch datasets. It verifies the integrity of the data structures and slices them into small subsets for quick testing.
3.  **Model Initialization**: Instantiates the `InsultDetector` model (DeBERTa-v3 backbone + SVD fusion) and validates the forward pass output shape.
4.  **Adversarial Weight Perturbation (AWP)**: Demonstrates the AWP mechanism by performing a mock attack, verifying that weights are perturbed, and confirming they are correctly restored.
5.  **Training Loop**: Runs a single epoch of training using the `Trainer` class on the data subset to verify the optimization process and loss calculation.
6.  **Evaluation & Inference**: Performs validation and test set inference, asserting that predictions fall within the valid probability range [0, 1] and calculating the AUC metric.
