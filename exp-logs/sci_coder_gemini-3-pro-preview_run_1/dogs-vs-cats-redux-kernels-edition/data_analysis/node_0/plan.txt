The following script performs a comprehensive Exploratory Data Analysis (EDA) on the provided image dataset. It adheres to all constraints: it relies solely on the training metadata to prevent leakage, processes image-specific properties (dimensions, channels, pixel statistics), analyzes the target distribution, and investigates relationships between image metadata (like size and aspect ratio) and the class labels. The script is optimized to run efficiently within the time limit and formats the output as a clean, readable report.
