This implementation orchestrates the Two-Stage Self-Distillation (Noisy Student) pipeline. It first trains a Teacher model on the combined dataset, uses it to generate soft pseudo-labels for the noisy subset, and then trains a Student model using these refined labels. Finally, it evaluates the Student model and generates a submission if the performance threshold is met.

The script is optimized for the 2-hour time limit by adjusting the number of epochs to 12 per stage, ensuring a fast but effective baseline execution on the A100 GPU.
