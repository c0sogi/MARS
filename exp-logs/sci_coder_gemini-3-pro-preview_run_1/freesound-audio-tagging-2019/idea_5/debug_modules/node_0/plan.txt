This script demonstrates the end-to-end usage of the provided library files for the Audio Tagging task. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters (Batch Size, Epochs, Workers) to ensure the demonstration runs quickly and efficiently on a small subset of data.
2.  **Metric Verification**: Validates the `calculate_lwlrap` function using synthetic data to ensure the scoring logic is correct (e.g., a perfect prediction yields a score of 1.0).
3.  **Data Loading**: Loads the pre-generated metadata, creates small subsets (10-20 samples) for training, validation, and testing, and initializes the `AudioDataset` and `DataLoader` via the factory function. It verifies the shape of the generated spectrograms and target tensors.
4.  **Model Initialization & Forward Pass**: Instantiates the `AudioEfficientNet` model, performs a forward pass with a sample batch, and asserts that the output dimensions match `(Batch_Size, Num_Classes)`.
5.  **Training Loop Simulation**: Runs `train_one_epoch` and `validate` functions from the engine using the subset data. It verifies that loss values are computed and returned correctly.
6.  **Inference & Submission**: Demonstrates the inference pipeline, generates a submission CSV, and verifies its format.
7.  **Teacher-Student Distillation Helper**: Simulates the generation of soft labels (teacher predictions) for the noisy dataset, verifying the caching mechanism and output structure.
