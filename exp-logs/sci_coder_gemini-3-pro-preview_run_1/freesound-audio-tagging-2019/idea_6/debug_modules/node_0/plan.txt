This script demonstrates the end-to-end usage of the provided audio tagging library. It performs the following steps:
1.  **Configuration**: Sets up the environment and overrides configuration parameters (like batch size and epochs) to ensure the demonstration runs quickly.
2.  **Metric Verification**: Validates the `calculate_lwlrap` function with dummy data to ensure the metric logic is correct.
3.  **Data Loading**: Instantiates the `AudioDataset` for training and validation, creates small subsets to minimize runtime, and verifies the `DataLoader` and `collate_fn` output shapes.
4.  **Augmentation**: Applies `SpecAugment` and `mixup_data` to a batch of data to verify the augmentation pipeline.
5.  **Model Initialization**: Instantiates the `AudioClassifier` (without downloading pretrained weights for speed) and performs a forward pass to check input/output dimensions.
6.  **Training Loop**: Executes the `fit` function for a single epoch on the data subset to demonstrate the training and validation process.
7.  **Inference**: Runs a prediction pass on a subset of the test data and formats the output as a pandas DataFrame, mimicking the submission format.
