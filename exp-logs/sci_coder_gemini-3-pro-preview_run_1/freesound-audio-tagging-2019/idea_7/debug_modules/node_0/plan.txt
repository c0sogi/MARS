This script demonstrates the end-to-end usage of the provided library modules for the Audio Tagging task. It performs the following steps:
1.  **Setup**: Sets random seeds and overrides configuration parameters (batch size, epochs, data subset size) to ensure the demonstration runs quickly.
2.  **Data Loading**: Loads the metadata, creates subsets of the data, and initializes `AudioDataset` and `DataLoader` for training, validation, and testing. It verifies the output shapes of the data loader.
3.  **Model Initialization**: Instantiates the `AudioResNeSt` model and verifies its forward pass on a dummy batch.
4.  **Training & Evaluation**: Runs a complete training epoch using `train_fn`, evaluates on the validation set using `valid_fn`, and verifies the returned metrics.
5.  **Inference & Submission**: Generates predictions on the test set using `inference_fn`, saves the submission using `save_submission`, and verifies the output file format.
6.  **Metric Verification**: Independently verifies the logic of the `calculate_lwlrap` function with a controlled example.
