Based on the task description and the provided model architectures, I propose the following baseline approach. This solution synthesizes the conceptual foundation of the U-Net (Model 1) but utilizes a lighter, standard ResNet backbone to establish a highly efficient and robust baseline.

### Model
The architecture will be a **2D U-Net with a ResNet-18 backbone**.
*   **Encoder:** We will utilize a ResNet-18 pre-trained on ImageNet as the encoder. This backbone is selected for its architectural simplicity and inference speed, offering a lightweight alternative to the EfficientNet-B0 suggested in the provided examples. The fully connected layers will be removed, and feature maps will be extracted from the four residual blocks.
*   **Decoder:** A standard U-Net decoder will be employed, consisting of upsampling layers (bilinear interpolation or transpose convolution) followed by convolutional blocks. Skip connections will link the encoder feature maps to the corresponding decoder layers to recover spatial resolution and fine-grained boundary details.
*   **Head:** The final layer will be a 1x1 convolution with 3 output channels (corresponding to Large Bowel, Small Bowel, and Stomach), followed by a **Sigmoid** activation function. This treats the problem as a multi-label pixel-wise classification task, allowing for overlapping masks if necessary.

### Data
*   **Preprocessing:**
    1.  **Normalization:** The analysis indicates pixel values reach up to ~15,800. We will apply **Min-Max scaling** per image to normalize pixel intensities to the range [0, 1].
    2.  **Resizing:** To ensure computational efficiency and uniform batching, all input images and corresponding masks will be resized to a fixed resolution of **256x256** pixels.
    3.  **Formatting:** Images will be converted to float32 tensors. Masks will be one-hot encoded into 3 channels.
*   **Augmentation:** To maintain simplicity while preventing basic overfitting, we will apply only **Random Horizontal Flips** and **Random Vertical Flips** during training.

### Training
*   **Loss Function:** We will minimize a combined **BCE + Dice Loss**. Binary Cross Entropy (BCE) ensures pixel-wise classification accuracy, while the Dice Loss directly optimizes the overlap metric used in the competition evaluation.
*   **Optimizer:** We will use the **Adam** optimizer, which is standard for fast convergence in segmentation tasks.
*   **Procedure:** The model will be trained using the case-aware split provided in the metadata (training on `metadata/train.csv` and validating on `metadata/val.csv`). This ensures the model is evaluated on unseen patients, preventing data leakage. A learning rate scheduler (ReduceLROnPlateau) will be used to decay the learning rate when validation loss plateaus.

### Evaluation
*   **Inference:** For each image in the test set, we will apply the same normalization and resizing (to 256x256) used during training.
*   **Post-processing:**
    1.  **Resizing:** The predicted probability maps will be resized back to the original image dimensions using bilinear interpolation.
    2.  **Thresholding:** A fixed threshold of **0.5** will be applied to the probability maps to generate binary masks.
    3.  **Encoding:** The binary masks will be converted into the required Run-Length Encoding (RLE) format.
*   **Submission:** The RLE strings will be formatted into the submission CSV, ensuring the correct class order (large_bowel, small_bowel, stomach) and ID matching.
