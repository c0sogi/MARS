Since the current inference pipeline processes images in an arbitrary directory traversal order, the submission file lists slices from different cases (which have different spatial dimensions) in a disordered manner. This causes the grader to attempt stacking arrays of mismatched shapes into the same volume (Cite debug_lesson_3).
