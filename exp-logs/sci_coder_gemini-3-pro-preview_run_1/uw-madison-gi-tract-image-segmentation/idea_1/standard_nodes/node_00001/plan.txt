The following script orchestrates the end-to-end machine learning workflow for the stomach and intestine segmentation task.

**Implementation Strategy:**
1.  **Setup & Configuration**: Sets reproducibility seeds and defines hyperparameters (5 epochs, 50% data fraction) to ensure the pipeline completes within the 2-hour execution limit while using the powerful A100 GPU.
2.  **Training**: Calls the provided `run_training` module to train a U-Net with a ResNet-18 backbone. This phase automatically handles data loading, model optimization, and checkpoint saving.
3.  **Validation & Metrics**: Loads the best model checkpoint and iterates over the full validation set. It computes the Dice coefficient and Hausdorff distance per sample, aggregating them into the competition's specific weighted metric ($0.4 \cdot \text{Dice} + 0.6 \cdot (1 - \text{HD})$).
4.  **Failure Analysis**: Calculates the correlation between the model's error magnitude and input characteristics (Mask Area and Image Intensity) to identify performance bottlenecks.
5.  **Inference**: Uses the `run_inference` module to generate predictions on the test set, resize masks to original resolutions, RLE-encode them, and save the final `submission.csv`.
