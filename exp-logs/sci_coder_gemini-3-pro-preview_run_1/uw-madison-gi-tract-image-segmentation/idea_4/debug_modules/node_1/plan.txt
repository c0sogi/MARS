The `_pickle.UnpicklingError` occurs because the training script saves a checkpoint containing a NumPy scalar (`best_dice`), which is blocked by the default `weights_only=True` security setting in `torch.load` on newer PyTorch versions (2.6+). As the checkpoint is generated locally and trusted, the fix is to explicitly disable this restriction by setting `weights_only=False` during the loading process in `library/inference.py`.
