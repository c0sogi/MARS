The following script demonstrates the end-to-end usage of the provided library components for the Stomach and Intestines MRI Segmentation task. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration settings (epochs, batch size) to ensure the demonstration runs quickly.
2.  **Dataset Verification**: Validates the `UWDataset` class, checking data loading, normalization, and shape consistency.
3.  **Model & Loss Verification**: Instantiates the `UnetPlusPlus` model and `DeepSupervisionLoss`, verifying forward passes and loss calculation logic.
4.  **Training Loop**: executes a short training run (1 epoch on a subset of data) using the `Trainer` class to generate a model checkpoint.
5.  **Inference Pipeline**: Runs the `InferencePipeline` on a small subset of the test data using the trained checkpoint to generate a submission file.
