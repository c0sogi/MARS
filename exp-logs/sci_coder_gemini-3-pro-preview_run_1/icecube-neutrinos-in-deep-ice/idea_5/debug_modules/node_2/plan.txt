This inefficient I/O caused the operation to exceed the time limit.

The fix is to modify the subsampling logic in `library/dataset.py` to prioritize data locality, as recommended in `debug_lesson_6`. Instead of sampling individual events globally, the code will now select a subset of *batches* sufficient to cover the requested `subset_size`, and then sample events only from those selected batches. This ensures that the number of files opened scales with the subset size, drastically reducing I/O overhead.
