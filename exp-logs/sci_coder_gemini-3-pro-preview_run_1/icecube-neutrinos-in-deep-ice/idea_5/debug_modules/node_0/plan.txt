This script demonstrates the end-to-end usage of the provided IceCube neutrino direction prediction library. It performs the following steps:
1.  **Configuration**: Overrides default `Config` parameters to ensure the demonstration runs quickly (using small data subsets and 1 epoch). It also creates a temporary, smaller test metadata file to ensure the submission generation step does not process the entire 13M event test set.
2.  **Verification**: Validates the logic of utility functions (geometry loading, coordinate transforms), the dataset class (loading, shaping, normalization), and the model architecture (forward pass shapes).
3.  **Execution**: Runs the full training pipeline via `run_training`, which trains the model, validates it, and generates a submission file.
4.  **Validation**: Checks the generated submission file for correct format and value ranges.
