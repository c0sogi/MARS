### Implementation Strategy

1.  **Environment Setup**: Import necessary classes and functions from the provided `library` modules (`data_loader`, `model`, `utils`, `config`). Set the random seed to ensure reproducibility.
2.  **Data Loading (Constrained)**: Load the training and validation datasets using `load_train_dataset` and `load_val_dataset`. To ensure the "fast baseline" requirement is met and to avoid memory issues during the initial run, I will limit the training set to 300,000 samples and the validation set to 60,000 samples using the `debug_n_rows` parameter.
3.  **Model Training**: Initialize the `DirectionalLGBM` model (which wraps three LightGBM regressors for the X, Y, and Z vector components). Train the model on the loaded subsets, using the validation set for early stopping to prevent overfitting. Save the trained model to disk.
4.  **Validation & Metrics**: Predict the direction vectors for the validation set. Convert both the predicted vectors and the true target vectors (originally loaded as Cartesian components) back to spherical coordinates (`azimuth`, `zenith`). Compute the **Mean Angular Error** using the provided `angular_dist_score` function and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Calculate the angular error for each individual event in the validation set. Compute the Pearson correlation between this error magnitude and each input feature to identify conditions where the model performs poorly. Print these correlations.
6.  **Inference & Submission**: Load the **full** test dataset (passing `debug_n_rows=None` to `load_test_dataset`). Use the trained model to predict direction vectors for all test events. Convert these vectors to `azimuth` and `zenith` angles. Construct a DataFrame with `event_id`, `azimuth`, and `zenith`, and save it to `./submission/submission.csv`.
