# End-to-End Fine-Tuned EfficientNet with Tabular Fusion

## Model
To address the critical generalization gap observed where frozen features failed to capture domain-specific patterns, the proposed model transitions from a static feature extraction pipeline to a fully trainable **End-to-End Dual-Branch Network**.

1.  **Image Branch (Backbone)**: Replace the frozen MobileNetV3 with an **EfficientNet-B1** backbone initialized with ImageNet weights. Crucially, **all layers will be unfrozen** to allow the network to adjust its feature representations specifically for dermatological textures and lesions, directly addressing the failure of generic features to separate malignant cases Cite {solution_lesson_node_00001}.
2.  **Tabular Branch**: A dedicated Multi-Layer Perceptron (MLP) will process the metadata. It will take the processed tabular inputs (encoded sex, anatomy, and age) and project them into a dense embedding vector (e.g., 64 dimensions).
3.  **Fusion Head**: The global average pooled output from the EfficientNet image branch will be concatenated with the tabular embedding. This combined vector is fed into a final classification block (Dropout + Linear + Sigmoid) to output the malignancy probability.

## Data
**Image Preprocessing:**
-   **Resolution**: Resize images to **256x256** to preserve more fine-grained texture details than the previous 224x224.
-   **Augmentation**: To combat the overfitting seen in the previous linear probe, apply robust training augmentations including **Random Horizontal/Vertical Flips**, **Random Rotation**, and **Color Jitter** (brightness/contrast). This forces the model to learn invariant biological features rather than memorizing pixel artifacts.
-   **Normalization**: Standard ImageNet normalization.

**Tabular Preprocessing:**
-   Retain the successful preprocessing strategy from the previous iteration: Simple Mean Imputation for numerical values, "missing" token replacement for categorical values, One-Hot Encoding for categorical features, and Standard Scaling for numerical features.

## Training
-   **Loss Function**: Use **Binary Cross Entropy with Logits**.
-   **Imbalance Handling**: Instead of simple class weighting, implement a **WeightedRandomSampler**. This sampler will oversample the minority (malignant) class in every batch to ensure the model sees a balanced distribution of positive and negative samples during gradient updates.
-   **Optimizer**: Use **AdamW** with a learning rate scheduler (e.g., Cosine Annealing) to converge effectively.
-   **Regularization**: Apply **Dropout** in the fusion head and **Weight Decay** in the optimizer to further mitigate the risk of overfitting to the small number of positive samples.

## Evaluation
-   **Test-Time Augmentation (TTA)**: During inference, generate predictions for the original image and multiple augmented versions (e.g., horizontal and vertical flips). Average these probabilities to produce the final `target` prediction. This stabilizes predictions and typically improves AUC by smoothing out noise.
