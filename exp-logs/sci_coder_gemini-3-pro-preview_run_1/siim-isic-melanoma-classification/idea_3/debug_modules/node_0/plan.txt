The following strategy outlines the implementation of the demonstration script:

1.  **Configuration & Patching**: Since the library files import constants (like `EPOCHS`, `DEBUG`) directly into their namespaces, we will monkey-patch these values in `library.config`, `library.dataset`, and `library.train` to enable `DEBUG` mode (using a small data subset) and reduce `EPOCHS` to 1. This ensures the script executes quickly within the time limit.
2.  **Utility Verification**: We will validate the `calculate_roc_auc` function using deterministic dummy data to ensure metric calculation is correct.
3.  **Data Pipeline Verification**: We will initialize the DataLoaders using `get_dataloaders`. We will fetch a single batch to verify the shapes of the image tensors, tabular feature vectors, and target labels. We will also confirm that the `DEBUG` flag successfully reduced the dataset size.
4.  **Model Architecture Verification**: We will instantiate the `SwinTransformerGLU` model. We will perform a forward pass with the batch retrieved in the previous step to verify that the fusion of image and tabular data works without errors and produces the correct output shape `[Batch_Size, 1]`.
5.  **Full Training Loop Execution**: We will execute `run_training()`. This serves as an integration test, running the full pipeline (training, validation, checkpointing, and inference) on the reduced dataset.
6.  **Submission Verification**: Finally, we will verify that the submission file is generated correctly and matches the expected format.
