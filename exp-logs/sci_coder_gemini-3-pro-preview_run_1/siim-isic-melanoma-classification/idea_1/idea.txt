# Baseline Solution: Frozen MobileNetV3 with Metadata-Augmented Logistic Regression

## Model
The proposed model is a **Feature Extraction Baseline** designed for maximum speed and minimal resource usage. Unlike previous approaches that fine-tune neural networks or train dual-branch architectures, this solution utilizes a pre-trained **MobileNetV3** backbone as a fixed, frozen feature extractor. The backbone weights are never updated.

The architecture consists of:
1.  **Image Feature Extractor**: A MobileNetV3 (e.g., `mobilenetv3_large_100`) pre-trained on ImageNet. The final classification layer is removed, leaving the global average pooled output vector.
2.  **Tabular Processor**: A simple encoding block where categorical variables (`sex`, `anatom_site_general_challenge`) are one-hot encoded, and the continuous variable (`age_approx`) is standardized.
3.  **Classifier**: A single **Logistic Regression** layer that takes the concatenated vector (Image Features + Tabular Features) as input and outputs the probability of malignancy.

## Data
**Image Preprocessing:**
-   Resize all images to **224x224** pixels to match the standard input resolution of the pre-trained MobileNetV3.
-   Apply standard ImageNet normalization (mean: `[0.485, 0.456, 0.406]`, std: `[0.229, 0.224, 0.225]`).
-   No test-time augmentation (TTA) or complex augmentations are used; only resizing and normalization.

**Tabular Preprocessing:**
-   **Imputation**: Fill missing values in `age_approx` with the mean and missing categorical values with a "missing" token.
-   **Encoding**: Apply One-Hot Encoding to categorical features and Standard Scaling (z-score) to the age feature.

## Training
The training process is split into two distinct, lightweight phases:
1.  **Feature Extraction Phase**: Iterate through the training dataloader once. Pass the images through the frozen MobileNetV3 backbone to generate a matrix of image embeddings (e.g., shape `N_samples x 1280`). Simultaneously, process the corresponding tabular data. Concatenate these to form the final training matrix `X`.
2.  **Classifier Training Phase**: Train a Logistic Regression model (using a library like `scikit-learn`) on the matrix `X` and target `y`.
    -   **Loss**: Log Loss (Binary Cross Entropy).
    -   **Optimizer**: L-BFGS or SAG solver (standard for logistic regression).
    -   **Imbalance Handling**: Set the `class_weight` parameter to `'balanced'` to automatically adjust weights inversely proportional to class frequencies, addressing the 1.8% malignancy rate without complex sampling strategies.

## Evaluation
For the test set, the same pipeline is applied:
1.  Load test images and metadata.
2.  Pass images through the frozen MobileNetV3 to extract embeddings.
3.  Process test metadata using the encoders fitted on the training set.
4.  Concatenate features and feed them into the trained Logistic Regression model to predict the probability of malignancy (`target`).
