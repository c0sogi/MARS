This script demonstrates the end-to-end workflow using the provided library modules. It performs the following steps:
1.  **Setup**: Sets random seeds and defines temporary paths.
2.  **Data Loading & Subsetting**: Loads the metadata and samples a small subset (50 training, 20 validation, 20 test) to ensure the demonstration runs quickly.
3.  **Tabular Preprocessing**: Uses `TabularTransformer` to impute, scale, and encode metadata features.
4.  **Data Loading**: Initializes `ISICDataset` and `DataLoaders` via `get_dataloaders` to handle image and tabular data batches.
5.  **Feature Extraction**: Uses `process_and_cache_features` with a `CNNBackbone` (MobileNetV3) to extract image embeddings and combine them with tabular features.
6.  **Model Training**: Trains a `MalignancyClassifier` (Logistic Regression) on the extracted features and evaluates it on the validation set.
7.  **Inference & Submission**: Generates predictions for the test set and saves them using `save_submission`.

Throughout the script, assertions are used to verify data shapes and logic correctness.
