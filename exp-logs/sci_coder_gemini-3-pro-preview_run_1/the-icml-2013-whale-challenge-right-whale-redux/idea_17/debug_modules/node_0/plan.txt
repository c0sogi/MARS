### Implementation Strategy

1.  **Configuration Setup**: I will override specific parameters in the `Config` class to enable a "Debug Mode". This involves reducing the dataset size (e.g., to 50 samples), setting the number of epochs to 1, and using a small batch size. This ensures the code runs within the time limit while exercising the full pipeline.
2.  **Component Verification**: I will perform unit tests on individual model components (`ContextGatingBlock`, `AttentionPooling`) using dummy tensors to verify input/output shapes and logic correctness.
3.  **Data Pipeline Execution**: I will utilize `get_dataloaders` with `debug=True` to generate training, validation, and testing loaders. I will verify the batch shapes produced by these loaders.
4.  **Model Training Simulation**: I will run `fit_one_seed` to train the model for one epoch on the reduced dataset. This demonstrates the integration of the model, loss function, optimizer, and training loop.
5.  **Inference and Submission**: I will use the trained model artifact to generate a submission file via `generate_submission`, verifying the output format and consistency with the test set size.
6.  **Reproducibility**: I will apply `seed_everything` at the start to ensure deterministic behavior.
