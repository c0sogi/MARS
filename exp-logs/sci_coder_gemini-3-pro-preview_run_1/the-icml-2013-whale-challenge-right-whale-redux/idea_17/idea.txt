Based on the comprehensive history of experiments and the specific lessons learned, I propose the **Ensemble of Time-Preserving Context-Gated Hierarchical ConvNeXt-Pico CRNNs**.

This solution introduces a **Structural Innovation** by modernizing the feature extraction backbone to **ConvNeXt-Pico**. This architecture employs large-kernel depthwise convolutions ($7\times7$), which are physically better suited for capturing the extended time-frequency "sweep" of whale calls compared to the small $3\times3$ kernels of ResNet. It integrates this modern backbone into the highly successful **Context-Gated Hierarchical** framework (Lesson 00072), strictly adhering to the resolution and stability constraints established in previous successes.

### Model

The solution employs a **Deep Ensemble** of 10 independently trained models to mitigate run-to-run variance (Cite solution_lesson_node_00066). Each model follows this architecture:

1.  **Backbone: Time-Preserving ConvNeXt-Pico**
    *   **Architecture**: Replace ResNet-18 with **ConvNeXt-Pico** initialized with **ImageNet weights** (averaging the first projection layer for 1-channel input) (Cite solution_lesson_node_00020).
    *   **Why ConvNeXt**: Unlike ResNet's $3\times3$ kernels, ConvNeXt uses **$7\times7$ kernels**. In a spectrogram, this larger receptive field (~70ms vs ~30ms) allows the backbone to capture longer continuous segments of the whale call "up-sweep" within a single layer, providing a stronger inductive bias for this specific signal structure.
    *   **Time-Preservation**:
        *   **Stages 1 & 2**: Retain **Standard Downsampling** (4x and 2x respectively). This preserves the receptive field hierarchy (Cite solution_lesson_node_00059).
        *   **Stages 3 & 4**: Modify the downsampling layers to use **Asymmetric Strides `(2, 1)`** (Frequency, Time). This ensures the temporal resolution remains at $T/8$ (approx. 25-30 steps for a 2s clip), preserving the sequence length required for the RNN to detect motion (Cite solution_lesson_node_00012).

2.  **Feature Aggregation: Context-Gated Spectral Pooling**
    *   **Extraction**: Extract feature maps from **Stage 2** (High-Res Texture), **Stage 3** (Mid-Level Shape), and **Stage 4** (Semantic Abstraction).
    *   **Context Gating**: Apply the **Top-Down Attention** mechanism proven in Lesson 00072.
        *   Use **Stage 4** features to generate a semantic context sequence.
        *   Project this context to generate dynamic **Spectral Attention Masks** for Stage 2 and Stage 3.
        *   Apply these masks to selectively emphasize signal-dominant frequency bands in the shallow layers, effectively using the deep semantic detection to "denoise" the high-resolution texture features.
    *   **Fusion**: Concatenate the gated features and pass through a **1x1 Conv Bottleneck** (Cite solution_lesson_node_00057).

3.  **Head: Bi-GRU with Attention Pooling**
    *   Process the fused sequence with a **Bi-Directional GRU** to model the temporal contour (Cite solution_lesson_node_00001).
    *   Aggregate the sequence via **Attention Pooling** to focus on the call segment (Cite Idea 3).

### Data

1.  **Preprocessing**:
    *   **Input Window**: Load the full **2.0-second** clip. Do not truncate (Cite solution_lesson_node_00023).
    *   **Resolution**: Generate Log-Mel Spectrograms using a **Large FFT Window (1024 samples)**. This ensures high frequency resolution (~2Hz/bin), which is fundamental for resolving the tonal structure of the whale call (Cite solution_lesson_node_00064).
    *   **Channels**: Use **1-Channel** input (Cite solution_lesson_node_00042).

2.  **Augmentation**:
    *   **Mixup**: Apply Mixup ($\alpha=0.4$) to training batches (Cite solution_lesson_node_00020).
    *   **SpecAugment**: Apply Frequency and Time Masking.
    *   **Constraint**: Strictly limit **Time Mask width to < 200ms** to prevent signal occlusion (Cite solution_lesson_node_00011).

### Training

1.  **System Strategy**: Train **10 independent models** with different random seeds. This robust ensemble strategy addresses the "Run-to-Run Variance" bottleneck (Cite solution_lesson_node_00066).
2.  **Loss Function**: Use **Binary Cross-Entropy with Positive Class Weight** (e.g., 9.0) to explicitly handle the 1:9 class imbalance (Cite solution_lesson_node_00058).
3.  **Optimization**:
    *   **Optimizer**: Use **Adam** (or AdamW if preferred for ConvNeXt, but Adam is proven stable here).
    *   **Batch Size**: **Maximize Batch Size** to the GPU limit (e.g., 256+) to improve throughput and batch statistics (Cite solution_lesson_node_00074).
    *   **Scheduler**: Use **ReduceLROnPlateau** (Cite solution_lesson_node_00006).
4.  **Metric Validity**: Monitor **Validation AUC** on unmixed data (Cite solution_lesson_node_00022).

### Evaluation

1.  **Inference**: Process test clips into High-Resolution Log-Mel Spectrograms (2.0s, 1024 FFT).
2.  **Ensemble Prediction**: Pass inputs through all 10 trained models. **Average the probability outputs** to produce the final prediction. This guarantees a stable, high-performance submission.
