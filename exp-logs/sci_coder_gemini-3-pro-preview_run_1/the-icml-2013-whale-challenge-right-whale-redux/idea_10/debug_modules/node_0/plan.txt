This script demonstrates the usage of the provided library components for the Right Whale Detection task. It validates the data loading process, the model architecture, and the training pipeline using a small subset of the data for rapid execution.

The implementation strategy involves:
1.  **Configuration Override**: Modifying the `Config` class to run in `DEBUG` mode with a small subset of data (50 samples) and for only 1 epoch. This ensures the script finishes quickly.
2.  **Data Loading Verification**: Using `get_dataloaders` to load the debug subset and asserting that the batch shapes for spectrograms and labels are correct.
3.  **Model Architecture Verification**: Instantiating the `CSKResNet18CRNN` model and performing a forward pass with a dummy batch to confirm the output shape matches the expected `(Batch_Size, 1)`.
4.  **Training Pipeline Execution**: Initializing the `Trainer` class and running the `fit` method for one epoch, followed by the `predict` method to generate submission predictions.
5.  **Output Verification**: Checking that the submission file is created and has the correct format.
