4.  **Training Cycle**: I will instantiate the `Trainer` class and run the `train()` method. This will demonstrate the full training loop, including loss calculation, backpropagation, and validation, on the reduced dataset.
5.  **Inference and Submission**: I will run the `predict()` method to generate predictions on the test set and verify that the output submission file follows the required format and contains the correct number of rows.
