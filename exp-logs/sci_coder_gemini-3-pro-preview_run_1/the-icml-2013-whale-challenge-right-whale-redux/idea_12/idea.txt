Based on the comprehensive history of experiments and the specific lessons learned, I propose the **Multi-Band Hierarchical Coordinate-Attention ResNet-18 CRNN**.

This solution introduces a **Structural Innovation** in the feature aggregation stage: **Multi-Band Hierarchical Pooling**. It addresses the limitation of the previous "Hierarchical" approach (Lesson 00057), where global frequency pooling indiscriminately mixed signal and noise. By explicitly slicing the frequency dimension of early, high-resolution layers into bands, we enable the recurrent head to discriminate between "low-frequency textures" (signal) and "high-frequency textures" (noise), leveraging the physical characteristics of the right whale call while maintaining the robust "Time-Preserving" architecture.

### Model

The architecture is a **Convolutional Recurrent Neural Network (CRNN)** designed to preserve spectro-temporal detail while enforcing frequency-aware feature selection.

1.  **Backbone: Time-Preserving ResNet-18 with Coordinate Attention**
    *   **Base Architecture**: We retain the **ResNet-18** backbone equipped with **Coordinate Attention (CA)** blocks. This combination is proven to be the most robust feature extractor for this task (Cite solution_lesson_node_00031, solution_lesson_node_00047).
    *   **Time-Preservation**: We strictly maintain **Asymmetric Strides `(2, 1)`** (Frequency, Time) in Layers 3 and 4. We **retain standard strides** (downsampling in both dimensions) in Layer 2. This ensures the temporal resolution is aligned at `T/8` across Layers 2, 3, and 4, preserving the receptive field hierarchy essential for feature learning (Cite solution_lesson_node_00059).
    *   **Initialization**: Initialize with **ImageNet pre-trained weights**, averaging the first layer to accept 1-channel input (Cite solution_lesson_node_00020).

2.  **Structural Innovation: Multi-Band Hierarchical Pooling**
    *   **Motivation**: Standard hierarchical fusion globally pools the frequency dimension. However, Layer 2 possesses high frequency resolution. Globally pooling it smears high-frequency noise (e.g., boat engines, water splash) with low-frequency signal (whale calls).
    *   **Mechanism**:
        *   **Layer 2 Extraction**: Split the feature map $(C, F_{high}, T)$ along the frequency axis into **2 Bands** (Low-Freq, High-Freq). Apply Global Average Pooling to each band separately. Result: Two vectors per time step.
        *   **Layer 3 Extraction**: Split the feature map $(C, F_{mid}, T)$ into **2 Bands**. Apply Global Average Pooling to each.
        *   **Layer 4 Extraction**: Apply standard Global Average Pooling to the map $(C, F_{low}, T)$, as it is already abstract and spatially compressed.
        *   **Aggregation**: Concatenate all resulting vectors (Layer 2 Bands + Layer 3 Bands + Layer 4 Global) along the channel dimension.
    *   **Effect**: The downstream RNN receives a feature vector that explicitly separates "Low-Band Texture" from "High-Band Texture," allowing it to learn to ignore the noise-dominant high bands of the early layers while utilizing their fine-grained temporal details in the signal band.

3.  **Head: Bi-GRU with Attention Pooling**
    *   The Multi-Band feature sequence is projected via a 1x1 convolution and fed into a **Bi-Directional GRU** (Cite solution_lesson_node_00001).
    *   The sequence is aggregated via **Attention Pooling** to focus on the call segment (Cite Idea 3).

### Data

1.  **Preprocessing**:
    *   **Input Window**: Generate Log-Mel Spectrograms covering the **full 2.0-second duration** of the clip. Do not truncate (Cite solution_lesson_node_00023).
    *   **Channel Format**: Use a **1-channel** input representation (Cite solution_lesson_node_00042).
    *   **Spectrogram Parameters**: Use **128 Mel bins** to ensure sufficient resolution for the band-splitting operation in Layer 2.

2.  **Augmentation**:
    *   **Mixup**: Apply Mixup ($\alpha=0.4$) to training batches to regularize the model and accelerate convergence (Cite solution_lesson_node_00020).
    *   **SpecAugment**: Apply Frequency and Time Masking.
    *   **Constraint**: Strictly limit the **Time Mask width to a maximum of 200ms** (approx. 20 frames) to avoid occluding the short whale call (Cite solution_lesson_node_00011).

### Training

1.  **Loss Function**: Use **Binary Cross-Entropy with Logits Loss**.
    *   **Class Weighting**: Apply a **Positive Class Weight** (e.g., 9.0) to explicitly handle the 1:9 class imbalance. This is superior to Focal Loss for this specific imbalance ratio (Cite solution_lesson_node_00058).
    *   **Target Handling**: Compute loss against the **mixed soft targets** generated by Mixup.

2.  **Optimizer**: Use **Adam** with a standard learning rate.

3.  **Scheduler**: Implement **ReduceLROnPlateau** to decay the learning rate when Validation AUC stagnates (Cite solution_lesson_node_00006).

4.  **Metric Validity**: Monitor **Validation AUC** on unmixed data. Do not rely on training metrics computed against hard labels during Mixup (Cite solution_lesson_node_00022).

### Evaluation

1.  **Inference**: Process test clips into 2.0s Log-Mel Spectrograms (128 bins).
2.  **Prediction**: Pass inputs through the Multi-Band Hierarchical model.
3.  **Output**: Apply a Sigmoid activation to the final output of the Attention Pooling layer to generate the probability `p`.
