Based on the comprehensive history of experiments and lessons learned, I propose the **Ensemble of Context-Gated Hierarchical CA-ResNet-18 CRNNs**.

This solution introduces a **Structural Innovation** in the feature aggregation stage: **Context-Gated Spectral Pooling**. This mechanism supersedes the "Adaptive Spectral Pooling" of Idea 14 and the "Multi-Band Pooling" of Idea 12. Instead of relying on fixed pooling grids or hard-coded frequency bands, it utilizes the semantic context from the deepest layer to dynamically generate attention weights for the frequency bins of shallower layers. This allows the model to selectively extract high-resolution spectral textures (from early layers) only when they spatially align with the semantic detection of a call (from deep layers), effectively filtering out noise while preserving signal fidelity (Cite solution_lesson_node_00060, solution_lesson_node_00071).

### Model

The solution employs a **Deep Ensemble** of 5 independently trained models to mitigate run-to-run variance (Cite solution_lesson_node_00066). Each model follows this architecture:

1.  **Backbone: Time-Preserving ResNet-18 with Coordinate Attention**
    *   **Base**: **ResNet-18** initialized with **ImageNet weights** (averaging the first layer for 1-channel input) (Cite solution_lesson_node_00020).
    *   **Attention**: Replace standard Residual Blocks with **Coordinate Attention (CA) Blocks** to capture long-range spectral and temporal dependencies within the backbone (Cite solution_lesson_node_00047).
    *   **Strides**:
        *   **Layers 1 & 2**: Retain **Standard Strides** (downsampling in both Frequency and Time). This preserves the receptive field hierarchy and ensures robust feature formation (Cite solution_lesson_node_00059).
        *   **Layers 3 & 4**: Apply **Asymmetric Strides `(2, 1)`** (Frequency, Time). This preserves the temporal resolution ($T/4$) required for the downstream RNN to detect the "up-sweep" motion (Cite solution_lesson_node_00012).

2.  **Structural Innovation: Context-Gated Spectral Pooling**
    *   **Extraction**: Extract feature maps from **Layer 2** ($F_{high}$), **Layer 3** ($F_{mid}$), and **Layer 4** ($F_{low}$).
    *   **Context Generation**: Apply Global Average Pooling to **Layer 4** to generate a **Semantic Context Vector** sequence ($T \times C_4$).
    *   **Gated Pooling**:
        *   For **Layer 2** and **Layer 3**: Project the Context Vector to generate **Spectral Attention Weights** ($\alpha \in [0, 1]^{F}$) for each time step.
        *   Apply these weights to the frequency dimensions of Layer 2 and Layer 3 before summing. This performs a **Weighted Average Pooling** where the model learns to focus on signal-dominant frequency bins and suppress noise-dominant bins, guided by the high-level call detection.
    *   **Fusion**: Concatenate the gated features from L2/L3 with the context features from L4. Pass through a **1x1 Conv Bottleneck + SE Block** to fuse and compress dimensionality (Cite solution_lesson_node_00057).

3.  **Head: Bi-GRU with Attention Pooling**
    *   Process the fused sequence with a **Bi-Directional GRU** to model the temporal contour (Cite solution_lesson_node_00001).
    *   Aggregate the sequence via **Attention Pooling** to focus on the call segment (Cite Idea 3).

### Data

1.  **Preprocessing**:
    *   **Input Window**: Load the full **2.0-second** clip. Do not truncate (Cite solution_lesson_node_00023).
    *   **Resolution**: Generate Log-Mel Spectrograms using a **Large FFT Window (1024 samples)**. This ensures high frequency resolution (~2Hz/bin), which is fundamental for resolving the tonal structure of the whale call. The Context-Gated Pooling will handle the dimensionality reduction intelligently (Cite solution_lesson_node_00064).
    *   **Channels**: Use **1-Channel** input (Cite solution_lesson_node_00042).

2.  **Augmentation**:
    *   **Mixup**: Apply Mixup ($\alpha=0.4$) to training batches to regularize and accelerate convergence (Cite solution_lesson_node_00020).
    *   **SpecAugment**: Apply Frequency and Time Masking.
    *   **Constraint**: Strictly limit **Time Mask width to < 200ms** to prevent signal occlusion (Cite solution_lesson_node_00011).

### Training

1.  **Strategy**: Train **5 models** with different random seeds.
2.  **Loss Function**: Use **Binary Cross-Entropy with Positive Class Weight** (e.g., 9.0) to explicitly handle the 1:9 class imbalance (Cite solution_lesson_node_00058).
3.  **Target Handling**: Compute loss against **mixed soft targets** generated by Mixup.
4.  **Metric Validity**: Monitor **Validation AUC** on unmixed data. Do not rely on training metrics computed against hard labels during Mixup (Cite solution_lesson_node_00022).
5.  **Optimizer**: Use **Adam** with **ReduceLROnPlateau** scheduler (Cite solution_lesson_node_00006).

### Evaluation

1.  **Inference**: Process test clips into High-Resolution Log-Mel Spectrograms (2.0s, 1024 FFT).
2.  **Ensemble Prediction**: Pass inputs through all 5 trained Context-Gated CRNN models. **Average the probability outputs** to produce the final prediction. This stabilizes the decision boundary and ensures the submission exceeds the high-performance threshold (Cite solution_lesson_node_00066).
