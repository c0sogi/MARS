The following strategy outlines the implementation of the demonstration script:

1.  **Configuration Override**: We will modify the `Config` class attributes at runtime to enable `DEBUG` mode, reduce the number of epochs to 1, set a small batch size, and limit the number of samples. This ensures the script executes quickly (within seconds/minutes) while exercising the full pipeline.
2.  **Dataset & DataLoader Verification**: We will instantiate the data loaders using `get_dataloaders`. We will fetch a single batch to verify the data shapes (spectrogram dimensions), label types, and ensure the pipeline handles the raw audio files correctly.
3.  **Model Architecture Verification**: We will instantiate the `CoordinateAttentionCRNN` model, pass the fetched batch through it, and assert that the output logits have the expected shape `(Batch_Size, 1)`.
4.  **Utility Function Verification**: We will explicitly test the `mixup_data` and `compute_auc` functions with synthetic tensors to ensure the augmentation and metric calculation logic works as expected.
5.  **Full Training Loop Simulation**: We will instantiate the `Trainer` class and execute a single epoch of training, followed by validation and inference. This demonstrates the integration of all components.
6.  **Submission Check**: Finally, we will verify that the inference step successfully generated a submission file in the correct format.
