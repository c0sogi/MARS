Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility using `library.utils.set_seed`.
2.  **Data Loading**: Utilize `library.dataset.get_dataloaders` to load the training, validation, and test datasets. This function handles caching to speed up data loading on subsequent runs.
3.  **Model Training**: Instantiate the `Trainer` class from `library.trainer` and execute the `fit` method. This handles the training loop, validation, early stopping, and saving the best model checkpoint. The full dataset and default epoch count (30) are used to ensure the high AUC threshold is reachable, as the dataset is small enough for the A100 GPU to process quickly.
4.  **Metric Reporting**: Print the final validation AUC in the required format (`Final Validation Metric: <value>`).
5.  **Failure Analysis**:
    *   Load the best saved model.
    *   Perform inference on the validation set to calculate absolute prediction errors.
    *   Compute basic statistical features (mean, std, max, min) from the input spectrograms.
    *   Calculate and print the correlation between these input features and the prediction error to identify potential weaknesses (e.g., if louder or quieter clips cause more errors).
6.  **Submission Generation**: Compare the best validation AUC against the specified threshold (0.986034259016142). If the threshold is exceeded, use `trainer.predict` to generate predictions for the test set and save them to `submission.csv`.
