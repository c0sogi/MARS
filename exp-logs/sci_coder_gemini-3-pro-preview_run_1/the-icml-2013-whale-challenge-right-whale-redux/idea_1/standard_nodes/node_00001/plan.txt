The implementation strategy is as follows:

1.  **Configuration & Setup**: Import the provided library modules. Override the `Config.EPOCHS` to a smaller number (e.g., 5) to ensure the script runs quickly as a baseline. Set random seeds for reproducibility.
2.  **Data Loading**: Use `get_datasets(load_cached_data=True)` to efficiently load the training, validation, and test datasets. Wrap them in PyTorch `DataLoader`s with appropriate batch sizes and worker counts.
3.  **Model Initialization**: Instantiate the `BiGRUClassifier` and move it to the configured device (GPU). Define the `BCEWithLogitsLoss` (with positive class weighting) and the `Adam` optimizer.
4.  **Training Loop**: Implement a concise training loop reusing `train_one_epoch` and `validate` functions from `library.trainer`. Save the model checkpoint whenever validation AUC improves.
5.  **Validation Assessment**: After training, load the best model checkpoint. Evaluate it on the full validation set to compute the final AUC. Print this metric in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Perform inference on the validation set to get probabilities.
    *   Calculate the absolute error magnitude (`|target - probability|`) for each sample.
    *   Extract simple statistical features from the input spectrograms (Mean, Standard Deviation, Max Value) to represent "input features".
    *   Compute and print the Pearson correlation between the error magnitude and these features to identify potential weaknesses (e.g., does the model fail more on quiet or loud clips?).
7.  **Submission Generation**: Run inference on the test set in evaluation mode (`model.eval()`, `torch.no_grad()`). Collect predictions and clip IDs, then use `save_submission` to generate the `submission.csv` file.
