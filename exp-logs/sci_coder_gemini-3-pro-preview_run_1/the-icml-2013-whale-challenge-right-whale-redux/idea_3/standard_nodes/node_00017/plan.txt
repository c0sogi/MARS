The implementation strategy involves the following steps:

1.  **Setup and Initialization**: Set random seeds for reproducibility and define the computation device (GPU) using the provided `Config`.
2.  **Training**: Execute the training pipeline using `library.trainer.run_training`. We utilize the full dataset (`debug=False`) and the default epoch count defined in the configuration to ensure the model has sufficient capacity and training time to meet the high AUC threshold required for submission. The `load_cached_data=True` flag is used to expedite data loading.
3.  **Validation Inference**: Although the trainer runs validation, we explicitly reload the validation `DataLoader` and perform a dedicated inference pass. This allows us to capture the raw predictions and ground truth labels necessary for both the final metric calculation and the detailed failure analysis.
4.  **Metric Calculation**: Compute the Area Under the ROC Curve (AUC) on the full validation set and print it in the specific format required: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: Compute the absolute error magnitude for each validation sample. Extract statistical features (Mean, Std, Max, Range) from the input spectrograms and calculate their Pearson correlation with the error magnitude. This identifies which signal characteristics are associated with model failure.
6.  **Submission**: Compare the calculated validation AUC against the strict threshold (`0.986034259016142`). If the model performance is sufficient, generate the submission file using `library.trainer.predict_and_submit`.
