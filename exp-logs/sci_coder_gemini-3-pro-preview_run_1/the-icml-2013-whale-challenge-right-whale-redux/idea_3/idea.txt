Based on the comprehensive failure analysis and empirical findings from the provided lessons, I propose the **Time-Preserving ResNet-BiGRU-Attention** architecture. This solution addresses the critical failure of the previous deep learning attempt (Lesson 00012) by redesigning the backbone to preserve temporal resolution while leveraging the robust sequential modeling of the baseline (Lesson 00001) and the calibrated augmentation strategies (Lesson 00011).

### Model
The proposed architecture is a **Convolutional Recurrent Neural Network (CRNN)** that integrates a structurally modified deep feature extractor with a recurrent temporal aggregator.

1.  **Backbone: Time-Preserving ResNet-18**
    Standard computer vision backbones like ResNet-18 aggressively downsample inputs (typically 32x), which destroys the temporal structure of short audio clips (Cite Lesson 00012). To fix this while retaining the capacity of a deep network, we will utilize a **ResNet-18** modified with **Asymmetric Strides**.
    *   **Input**: Log-Mel Spectrograms with increased frequency resolution (128 Mel bins) to accommodate deeper spectral processing.
    *   **Structure**: The first convolutional layer and the first residual block will retain standard strides. However, for the subsequent residual blocks (Layer 2, 3, and 4), we will set the stride along the **Time axis to 1** while keeping the stride along the **Frequency axis at 2**.
    *   **Effect**: This results in a feature map where the frequency dimension is compressed to extract abstract spectral features, but the time dimension is only downsampled by a factor of 4 (vs 32). This preserves a sequence length of ~50-60 steps for a 2-second clip, sufficient to capture the "up-sweep" motion of the whale call.

2.  **Temporal Modeling: Bi-Directional GRU**
    The output of the backbone is permuted to a sequence format $(T \times Features)$ and fed into a **Bi-directional Gated Recurrent Unit (BiGRU)**. This component is explicitly retained from the baseline success, as it effectively models the specific temporal contour of the whale call (Cite Lesson 00001).

3.  **Aggregation: Attention Pooling**
    Instead of Global Max Pooling, we will implement an **Attention Pooling** mechanism. A learnable "context vector" will compute a weight for each time step in the GRU output, allowing the model to dynamically compute a weighted sum of the sequence. This focuses the classification decision on the specific timeframe containing the call, suppressing background noise segments.

### Data
1.  **Preprocessing**:
    *   Generate **Log-Mel Spectrograms** from the raw audio. Increase the number of Mel bins to **128** to support the deeper convolution stack, while maintaining a window size of approx 25ms and hop length of 10ms.
    *   Normalize the spectrograms using dataset-level mean and standard deviation.

2.  **Augmentation**:
    *   Apply **SpecAugment** (Frequency and Time Masking) during training to improve generalization (Cite Lesson 00006).
    *   **Critical Constraint**: Set the maximum width of the Time Mask to **20 frames (approx. 200ms)**. This ensures that the augmentation does not occlude the entire short-duration whale call, which would introduce label noise (Cite Lesson 00011).

### Training
*   **Loss Function**: Use **Binary Cross-Entropy with Logits Loss**. Apply a **positive class weight** (e.g., 9.0) to address the 1:9 class imbalance (Cite Lesson 00001).
*   **Optimizer**: Use **Adam** with a standard learning rate (e.g., 1e-3).
*   **Scheduler**: Implement a **ReduceLROnPlateau** scheduler to decay the learning rate when Validation AUC stagnates, allowing the model to settle into a finer optimum (Cite Lesson 00006).
*   **Regularization**: Apply weight decay and Dropout within the fully connected layers of the Attention head to prevent overfitting.

### Evaluation
*   **Inference**: Process the test set clips into Log-Mel Spectrograms using the same parameters as the training set (128 bins).
*   **Prediction**: Pass the spectrograms through the trained Time-Preserving ResNet-BiGRU. The output of the Attention Pooling layer is passed through a Sigmoid activation to generate the final probability `p`.
*   **Submission**: Map the probabilities to the corresponding clip filenames and save to `submission.csv`.
