The strategy for the `runfile.py` implementation is as follows:

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility and setting up the `Config` class. We will override `Config.EPOCHS` to 20 to ensure the training completes well within the time limit while allowing sufficient convergence for the pre-trained EfficientNet backbone.
2.  **Data Loading**: Use `get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test datasets, utilizing the pre-processing cache if available.
3.  **Model Initialization**: Instantiate the `TimePreservingEfficientNet` model and move it to the appropriate computing device (GPU).
4.  **Training Loop**: Implement a standard training loop for the specified number of epochs. Inside the loop:
    *   Train for one epoch using `train_one_epoch`.
    *   Evaluate on the validation set using `evaluate`.
    *   Update the learning rate scheduler based on validation AUC.
    *   Save the model weights if the validation AUC improves (`best_model.pth`).
5.  **Final Evaluation**: After training, load the best model checkpoint and perform a final evaluation on the full validation set to obtain the `Final Validation Metric`.
6.  **Failure Analysis**: Implement a custom `analyze_failures` function. This function will:
    *   Generate predictions for the validation set.
    *   Calculate the absolute error for each sample.
    *   Extract basic audio features (RMS Energy, Max Amplitude, Zero Crossing Rate) from the validation audio files.
    *   Compute and print the Pearson correlation between these features and the model's error magnitude to identify potential weaknesses.
7.  **Conditional Submission**: Compare the `Final Validation Metric` against the strict threshold of `0.9934990421176494`. If the metric exceeds this threshold, generate predictions for the test set using `predict` and save them to `submission.csv`.
