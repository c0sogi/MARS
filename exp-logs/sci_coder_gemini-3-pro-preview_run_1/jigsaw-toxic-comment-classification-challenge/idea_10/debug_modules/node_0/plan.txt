This script demonstrates the usage of the provided library modules (`config`, `utils`, `data`, `model`, `engine`) to perform a complete machine learning workflow on the toxicity dataset. It overrides the default configuration to run in "debug" mode, ensuring the execution completes quickly by using a small subset of the data (1000 samples) and minimal training epochs. It validates the logic of data loading, model architecture (including custom components like Multi-Layer Fusion), and the training/evaluation loops.
