The `torch.OutOfMemoryError` during the Domain-Adaptive Pre-training (MLM) phase is caused by the high memory requirement of the output layer (projecting to 128,000 vocabulary tokens) combined with a batch size of 16. The GPU (~16GB capacity) cannot allocate the ~3.91 GiB required for the logits tensor because memory is already saturated by model weights and activations. To fix this, I will reduce the `mlm_batch_size` to 4. I will also conservatively reduce the supervised `batch_size` to 8 to prevent a subsequent OOM during the supervised phase, which runs in FP32 and has higher activation memory overhead (Cite debug_lesson_3).
