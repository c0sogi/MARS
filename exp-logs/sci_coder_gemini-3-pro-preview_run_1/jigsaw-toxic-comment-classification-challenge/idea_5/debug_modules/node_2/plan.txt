The `torch.OutOfMemoryError` indicates that the current configuration (Batch Size 8 with DeBERTa-v3-large) exceeds the available GPU memory. To resolve this, I will implement three changes:
1.  **Enable Gradient Checkpointing** in `library/model.py`. This trades compute for memory by recomputing activations during the backward pass, drastically reducing the memory footprint.
2.  **Reduce Batch Size** in `library/config.py` and `runfile.py` from 8 to 4. This directly reduces the memory required for activations and gradients. Cite debug_lesson_4.
3.  **Increase Gradient Accumulation** in `runfile.py` from 1 to 2 to maintain a reasonable effective batch size while keeping the physical batch size small.
