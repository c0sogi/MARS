The solution implements a Semi-Supervised Learning pipeline with Domain-Adaptive Pre-training (DAPT).

**Strategy Outline:**
1.  **Setup & Configuration:** Initialize the provided `Config`, setting random seeds for reproducibility. To ensure the pipeline completes within the 2-hour limit while maintaining high performance, we override the default epoch counts: 1 epoch for DAPT, 2 for Teacher, and 2 for Student training.
2.  **Stage 1: DAPT (Domain-Adaptive Pre-training):** Load `deberta-v3-base` as a Masked Language Model. Fine-tune it on the combined text from training and test sets to adapt the encoder to the specific toxicity domain. Save this "DAPT backbone" locally.
3.  **Stage 2: Teacher Training:** Initialize the custom classification model using the DAPT backbone. Train it on the labeled training set using 5-fold cross-validation logic (simplified to single split for speed here, relying on the robust backbone).
4.  **Pseudo-Label Generation:** Use the trained Teacher model to predict toxicity probabilities for the entire unlabeled test set.
5.  **Stage 3: Student Training:** Initialize a new Student model from the DAPT backbone. Train it on a combined dataset of "Hard-Labeled Train Data" + "Soft-Labeled Test Data" to leverage the manifold structure of the larger test set.
6.  **Evaluation & Failure Analysis:** Calculate the final ROC AUC on the hold-out validation set. Analyze performance by computing the correlation between prediction error magnitude and input text length.
7.  **Submission:** If the validation metric exceeds the specified threshold (0.9920...), generate final inference on the test set and save `submission.csv`.
