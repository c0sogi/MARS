# Solution: Semi-Supervised DeBERTa-v3 with DAPT and Feedback-Loop Training

## Model
I propose a robust architecture designed to maximize signal extraction and leverage unlabeled data.

1.  **Backbone (Strategic Retention):** We will utilize **DeBERTa-v3-base**. This model outperforms RNNs (Cite solution_lesson_node_00007) and offers superior context understanding via disentangled attention. We select the "Base" variant to ensure we can train on the full dataset and execute the multi-stage pipeline within the 24-hour limit, prioritizing data coverage over parameter count (Cite solution_lesson_node_00014).
2.  **Weighted Layer Aggregation (Strategic Retention):** We will implement a **learnable weighted sum of the last 4 encoder layers**. Lesson 00009 highlighted that lower layers contain critical lexical information (slang, profanity) that must be adapted. Aggregating these layers provides the head with direct access to these raw signals alongside high-level semantics (Cite solution_lesson_node_00009).
3.  **Hybrid Pooling Head (Strategic Retention):** We will apply the proven hybrid pooling strategy to the aggregated representation:
    *   **Global Max Pooling:** To extract the strongest local toxic signal (e.g., a specific slur) regardless of context (Cite solution_lesson_node_00001).
    *   **Linear Attention Pooling:** To compute a context-aware weighted average, prioritizing relevant tokens while filtering noise (Cite solution_lesson_node_00002). We will use simple **Linear Attention** ($w^T h_t$) for efficient convergence (Cite solution_lesson_node_00003).
    *   These two vectors will be concatenated.
4.  **Multi-Sample Dropout (Strategic Retention):** The concatenated vector will pass through 5 parallel dropout masks to smooth the loss landscape (Cite solution_lesson_node_00016).

## Data
1.  **Tokenization (Strategic Retention):** We will use the **DeBERTa-v3 Tokenizer** (SentencePiece) to preserve punctuation and special characters, which are critical features for toxicity detection (Cite solution_lesson_node_00004).
2.  **Unsupervised Corpus:** We will concatenate `train.csv` and `test.csv` to create a domain-specific corpus for pre-training.
3.  **Pseudo-Labeled Dataset (Structural Innovation):** For the final training stage, we will combine the original training data with the test data, assigning **soft labels** (probabilities) to the test samples based on predictions from an intermediate "Teacher" model. This allows the model to learn from the structure of the significantly larger test set (153k vs 127k samples).

## Training
I propose a **Three-Stage Training Pipeline** (Structural Innovation) to maximize domain adaptation and boundary refinement.

**Stage 1: Domain-Adaptive Pre-training (DAPT)**
*   **Objective:** Fine-tune the DeBERTa-v3 backbone on the combined (train + test) corpus using **Masked Language Modeling (MLM)** for 3 epochs.
*   **Rationale:** This adapts the tokenizer embeddings and lower layers to the specific toxic vocabulary (slang, profanity) of the dataset before supervised learning begins, addressing the lexical gap identified in Lesson 00009.

**Stage 2: Teacher Training (Robust Supervised CV)**
*   **Strategy:** Fine-tune the DAPT backbone using **5-Fold Cross-Validation** on the labeled training set.
*   **Optimization:** Use **AdamW** with a **Uniform Learning Rate** (rejecting Layer-wise Decay to allow lower layers to adapt, Cite solution_lesson_node_00009) and **Adversarial Weight Perturbation (AWP)** (Cite solution_lesson_node_00018) to maximize robustness.
*   **Scheduling:** Use **OneCycleLR** with a sufficient duration (e.g., 5 epochs) to avoid the performance degradation of compressed schedules (Cite solution_lesson_node_00006).

**Stage 3: Student Training (Self-Training with Soft Labels)**
*   **Pseudo-Label Generation:** Use the ensemble of Stage 2 models to predict toxicity probabilities for the entire test set.
*   **Refinement:** Train a new 5-Fold ensemble on the **combined dataset** (Original Train + Soft-Labeled Test).
*   **Rationale:** This stage exploits the manifold structure of the unlabeled test data to smooth decision boundaries in low-density regions, effectively using the "Teacher" ensemble's confidence to guide the "Student" model.

## Evaluation
1.  **Inference:** Generate predictions for the test set using the **Stage 3 (Student)** models.
2.  **Ensembling:** Average the probabilities from the 5 folds.
3.  **Submission:** Format the averaged probabilities into the required CSV structure.
