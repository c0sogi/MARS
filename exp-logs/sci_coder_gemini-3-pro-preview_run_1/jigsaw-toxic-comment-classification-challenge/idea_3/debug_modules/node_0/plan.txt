This script demonstrates the end-to-end usage of the provided library modules for the toxicity classification task. It performs the following steps:
1.  **Configuration**: Modifies the global `Config` to run in `debug` mode (using a small subset of data) and sets a temporary working directory to avoid conflicts with existing cached data.
2.  **Data Preparation**: Uses `get_dataloaders` to load, tokenize, and batch the data. It verifies the integrity of the batches (shapes and types).
3.  **Model Initialization**: Instantiates the `ToxicityModel` and performs a dummy forward pass to verify the architecture and output dimensions.
4.  **Training & Evaluation**: Runs a short training loop (1 epoch) using `train_fn` and evaluates using `eval_fn`, asserting that loss and AUC metrics are calculated correctly.
5.  **Prediction**: Generates predictions on the test set using `predict_fn` and formats the results into a submission DataFrame.
