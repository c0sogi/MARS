### Implementation Strategy

1.  **Configuration Setup**: We will import the `Config` class and override specific parameters (like `DEBUG`, `EPOCHS`, and `CACHE_DIR`) to ensure the script runs quickly (using a small subset of data) and does not interfere with existing cache files.
2.  **Component Verification**:
    *   **Utils**: We will demonstrate `load_dataset` to verify it correctly merges metadata with raw text.
    *   **Data Loading**: We will verify the `TextTokenizer` manually with dummy data to ensure tokenization logic works. Then, we will use `get_dataloaders` (in debug mode) to generate PyTorch DataLoaders and verify batch shapes.
    *   **Model**: We will instantiate the `BiGRU_Pool_Net` with random embeddings and perform a forward pass with a dummy input tensor to confirm the output shape corresponds to the 6 toxicity classes.
3.  **Integration Testing (Trainer)**: We will instantiate the `Trainer` class, which encapsulates the entire pipeline. We will run `fit()` for one epoch on the debug subset, followed by `predict()` and `save_submission()`.
4.  **Validation**: Throughout the script, assertions will be used to validate data shapes, file existence, and logical correctness.
