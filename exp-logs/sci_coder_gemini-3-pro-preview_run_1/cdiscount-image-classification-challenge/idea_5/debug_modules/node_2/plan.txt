The previous implementation failed because the `best_acc` variable was initialized to `0.0`. During the debug run, the model achieved a validation accuracy of exactly `0.0`. The condition `if val_acc > best_acc` evaluated to `False` (`0.0 > 0.0`), causing the model checkpoint logic to be skipped entirely. This resulted in the missing file error. To fix this, I will initialize `best_acc` to `-1.0`, ensuring that the first validation result (even if it is 0.0) is strictly greater than the initial value, guaranteeing that the model is saved at least once.
