This script demonstrates the usage of the provided library components for the Cdiscount image categorization task. It performs the following steps:
1.  **Configuration & Setup**: Sets random seeds and overrides default configuration parameters (batch size, epochs) to ensure the demo runs quickly within the time limit.
2.  **Hierarchy Management**: Initializes the `HierarchyManager` to verify the loading of category mappings and tests the conversion between raw category IDs and internal class indices.
3.  **Dataset & DataLoader**: Instantiates the `BSONDataset` with a small subset of data (using `limit_size`) to demonstrate efficient data loading from the binary BSON file. It verifies the structure and shapes of the yielded tensors (images, masks, targets).
4.  **Model Initialization & Forward Pass**: Loads the `MultiLevelResNet` model, performs a forward pass with a dummy batch, and asserts that the output logits for all three hierarchical levels (Coarse, Intermediate, Fine) have the correct dimensions.
5.  **Training Loop Simulation**: Sets up the optimizer, loss function (`HierarchicalLoss`), and mixed-precision scaler. It runs a single training epoch and a validation step on the small data subset to demonstrate the training pipeline's functionality.
