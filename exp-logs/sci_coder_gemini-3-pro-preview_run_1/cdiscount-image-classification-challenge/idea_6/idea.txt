Based on the accumulated lessons and the analysis of previous attempts, I propose a **Multi-Level ResNet-50 with Feature Fusion and Deep Hierarchical Supervision**.

This strategy structurally evolves the "Deep Supervision" concept by introducing **Feature Fusion**. Instead of relying solely on the final abstract features for the target classification, this model explicitly concatenates mid-level features (Stage 3) with high-level features (Stage 4). This addresses the fine-grained nature of the task, where texture and local patterns (preserved better in earlier stages) are often as discriminative as semantic shapes. Crucially, it adheres to the paramount lesson of training on the **Full Dataset**.

### Model
I will implement a **Multi-View ResNet-50 with Multi-Level Feature Fusion**.
*   **Backbone:** **ResNet-50** (pretrained on ImageNet) will serve as the encoder. This provides higher capacity than the ResNet-18 used in the baseline, necessary for the 5,270 classes.
*   **Multi-Level Feature Extraction (Structural Innovation):** Instead of taking only the final output, the model will extract feature maps from two points in the backbone:
    1.  **Stage 3 Output:** 1024 channels (Mid-level features: texture, parts).
    2.  **Stage 4 Output:** 2048 channels (High-level features: semantic object shape).
*   **Aggregation:** I will apply **Global Max Pooling** independently to both the Stage 3 and Stage 4 feature maps across the variable number of images ($N=1..4$) per product. This retains the strongest signal from any view for both texture and shape features **Cite solution_lesson_node_00001**.
*   **Hierarchical Heads:**
    1.  **Coarse Head (Auxiliary):** A simple **Linear Layer** **Cite solution_lesson_node_00003** attached to the aggregated Stage 3 features. Predicts **Level 1** categories.
    2.  **Intermediate Head (Auxiliary):** A Linear Layer attached to the aggregated Stage 4 features. Predicts **Level 2** categories.
    3.  **Fine-Grained Head (Target):** The aggregated features from Stage 3 and Stage 4 will be **Concatenated** (resulting in a 3072-dimensional vector) and fed into a final Linear Layer to predict the target **Level 3** categories. This fusion ensures the classifier has access to both fine-grained details and high-level semantics.

### Data
*   **Full Dataset Training:** The model will be trained on the **entire training dataset** (~7 million products). I will strictly avoid data pruning, as architectural gains cannot compensate for the loss of data coverage in high-cardinality tasks **Cite solution_lesson_node_00010**.
*   **Metadata Indexing:** I will utilize the CSV-based metadata index to perform random-access reads directly from the BSON files, avoiding the I/O bottleneck of file extraction **Cite solution_lesson_node_00001**.
*   **Preprocessing:** Images will be decoded, resized to 180x180, and normalized. I will use only simple augmentations (Random Horizontal Flip) and avoid heavy augmentations like ColorJitter which were found to hinder convergence in short schedules **Cite solution_lesson_node_00003**.

### Training
*   **Hardware Saturation:** I will maximize the batch size (targeting **512** or higher) to fully saturate the NVIDIA A100 GPU and use **12 data loader workers** to maintain throughput **Cite solution_lesson_node_00004**.
*   **Optimization Strategy:**
    *   **Scheduler:** **OneCycleLR** with a short duration of **2-3 epochs**. On the full dataset, this provides millions of gradient updates, which is sufficient for convergence **Cite solution_lesson_node_00005**.
    *   **Linear Scaling Rule:** The peak learning rate will be scaled linearly with the batch size to ensure effective weight updates despite the reduced iteration count **Cite solution_lesson_node_00006**.
*   **Loss Function:** The total loss will be a weighted sum: $L_{total} = L_{fine} + 0.3 L_{mid} + 0.1 L_{coarse}$.
*   **Regularization:** I will apply **Label Smoothing (0.1)** to the Fine-Grained head to prevent overfitting on the noisy target labels **Cite solution_lesson_node_00003**.

### Evaluation
*   **Inference:** The model will process the test set using the `test_metadata.csv` index.
*   **Prediction:** For each product, images will be processed through the backbone. The final prediction will be generated by the **Fine-Grained Head** using the concatenated Stage 3+4 features. Auxiliary heads will be ignored.
