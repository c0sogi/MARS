This script demonstrates the complete pipeline for the EEG Seizure Detection task using the provided library. It performs the following steps:

1.  **Configuration Override**: Modifies the default `Config` parameters (reducing epochs and dataset size) to ensure the demonstration runs quickly (under 1 minute) while maintaining full functionality.
2.  **Tqdm Patching**: Disables progress bars to comply with the requirement for silent execution.
3.  **Data Loading**: Initializes the `HMSDataset` and `DataLoader` for training, validation, and testing. It includes a verification step to assert that the data shapes match the model's expected input (EEG: `20x5000`, Spectrogram: `5x512x512`).
4.  **Model Initialization**: Instantiates the `DeepSupervisedModel` (Dual-Stream EEG + Spectrogram network) and verifies the forward pass logic.
5.  **Training**: Runs a short training loop (2 epochs) using the `Trainer` class, utilizing the custom Multi-Task KL Divergence loss.
6.  **Inference & Submission**: Generates predictions on the test set and saves the `submission.csv` file.
7.  **Final Validation**: Checks the integrity of the submission file, ensuring correct dimensions and that probabilities sum to 1.0.
