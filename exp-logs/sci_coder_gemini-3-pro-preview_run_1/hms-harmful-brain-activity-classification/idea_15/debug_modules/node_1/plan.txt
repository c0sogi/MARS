The `RuntimeError: Trying to resize storage that is not resizable` during inference is caused by the `HMSDataset` returning EEG tensors of varying shapes for the test set. The original code assumed test files were exactly 50 seconds long and skipped the cropping/padding logic used for training data. However, test files vary in length, leading to shape mismatches when the `DataLoader` attempts to collate the batch.

The fix involves unifying the EEG processing logic for all modes. We will modify `_process_eeg` in `library/dataset.py` to default the offset to 0 for the test set (handling the missing metadata column, Cite debug_lesson_6) and then apply the standard slicing and padding logic to enforce the fixed sequence length defined in `Config`.
