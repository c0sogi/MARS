Here is the implementation strategy and the corresponding Python script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by suppressing `tqdm` output to comply with the "no progress bars" rule, setting random seeds for reproducibility, and creating necessary directories via `Config.setup()`.
2.  **Data Loading**: Instantiate `HMSDataset` for training, validation, and testing. The training dataset automatically applies the "Global Random Subsampling" strategy defined in `Config`. Create `DataLoader` instances with optimized settings (pinned memory, appropriate workers) for the A100 GPU.
3.  **Model Initialization**: Build the `DeepSupervisedModel` (Dual-Stream EEG + Spectrogram with Coordinate Fusion) and move it to the GPU.
4.  **Training Configuration**: Set up the `AdamW` optimizer and `OneCycleLR` scheduler. Initialize the provided `Trainer` class.
5.  **Execution**: Run `trainer.fit()` to train the model for the configured epochs (5) on the subsampled dataset (20k).
6.  **Validation & Analysis**:
    *   Load the best saved checkpoint.
    *   Perform inference on the full validation set to compute the `Final Validation Metric` (KL Divergence).
    *   Conduct failure analysis by calculating per-sample KL divergence and correlating it with metadata features (e.g., signal offsets, vote counts) to identify error sources.
7.  **Submission**: Check if the validation metric meets the threshold (< 0.6822). If successful, generate predictions on the test set using the `predict_and_submit` function.
