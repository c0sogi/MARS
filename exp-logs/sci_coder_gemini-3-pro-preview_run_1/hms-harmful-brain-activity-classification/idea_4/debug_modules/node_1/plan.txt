The error arises because the test set metadata (`test.csv`) does not contain the `eeg_label_offset_seconds` and `spectrogram_label_offset_seconds` columns, as the test files are already pre-cropped to the correct duration. The `EEGSpecDataset` class attempts to access these columns unconditionally, causing a `KeyError` during inference. To fix this, I will modify `library/data.py` to use the `.get()` method on the pandas Series `row`, providing a default offset of 0 when these columns are missing. This ensures compatibility with both training data (which has offsets) and test data (which implies 0 offset).
