The issue is caused by the `get_dataloaders` function in `library/data.py` using a stale default argument for `train_batch_size`. The default value (`Config.BATCH_SIZE`) is evaluated at import time as 32. Although `runfile.py` updates `Config.BATCH_SIZE` to 4 at runtime, `get_dataloaders` continues to use the old value of 32 because it is not explicitly passed in `run_training`. With the debug dataset size of 20 and `drop_last=True`, a batch size of 32 results in 0 batches, causing the `OneCycleLR` scheduler to fail with a `ValueError`.

To fix this, I will modify `get_dataloaders` to set the default values of `train_batch_size` and `val_batch_size` to `None` in the function signature. I will then assign them the current value of `Config.BATCH_SIZE` inside the function body. This ensures the function uses the runtime configuration value, resolving the empty DataLoader issue.
