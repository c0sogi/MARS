The implementation strategy for the `runfile.py` orchestration script is as follows:

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility. Modify the `Config` parameters to execute a "fast baseline" run. Specifically, set `EPOCHS` to 1 and `DEBUG` to `False`. This ensures the model sees the entire training dataset once, which is sufficient for a robust baseline within the 2-hour time limit, compared to training on a small debug subset.
2.  **Training**: Invoke the `run_training` function from the library. This handles the end-to-end training process, including data loading, model initialization, optimization, and saving the best model checkpoint based on validation loss.
3.  **Full Validation**: After training, explicitly load the full hold-out validation dataset using `get_dataloaders(debug=False)`. Perform a dedicated inference pass on this set to calculate the global Kullback-Leibler (KL) Divergence. This ensures the reported metric is accurate and comparable.
4.  **Failure Analysis**: Utilize the validation predictions to compute the KL divergence error for each individual sample. Correlate these error magnitudes with metadata features (specifically EEG and Spectrogram time offsets) to identify if the model struggles with specific temporal contexts.
5.  **Submission**: Compare the calculated final validation metric against the provided threshold (`0.9343236597211053`). If the model's performance is superior (i.e., the metric is lower), call `run_inference` to generate predictions for the test set and save the `submission.csv` file.
