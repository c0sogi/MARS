Implementation Strategy:
1.  **Setup & Imports**: Import necessary system libraries (`os`, `numpy`, `pandas`, `torch`, `scipy`) and the provided library modules (`Config`, `Trainer`, `get_dataloaders`, `generate_submission`).
2.  **Reproducibility**: Implement a `set_seed` function to ensure consistent results across runs.
3.  **Metric Calculation**: Implement a `calculate_metric` function to compute the Kullback-Leibler Divergence on the full validation set, ensuring the model is in evaluation mode and gradients are disabled.
4.  **Failure Analysis**: Implement a `failure_analysis` function that computes the KL divergence error for each sample in the validation set. It will then calculate and print the Pearson correlation between this error magnitude and the metadata offset features (`eeg_label_offset_seconds`, `spectrogram_label_offset_seconds`).
5.  **Main Execution Flow**:
    *   Initialize seeds.
    *   **Configure for Speed**: Override `Config.EPOCHS` to 3 to satisfy the "fast baseline" requirement while keeping `Config.DEBUG = False`. This ensures the model trains on the full dataset and, crucially, generates a valid submission file for *all* test IDs (which a debug subset would fail to do).
    *   **Train**: Initialize the `Trainer` and call `fit()`. This handles the training loop, early stopping, saving the best model, and automatically generating the submission file.
    *   **Validate**: Reload the best model weights and compute the final validation metric on the hold-out validation set. Print it in the required format.
    *   **Analyze**: Run the failure analysis on the validation set.
    *   **Verify**: Confirm the submission file exists.
