Based on the accumulated lessons, I propose the **Offset-Guided Attention Dual-Stream Network**.

This strategy structurally evolves the "Current Best" (Dual-Stream with Cross-Attention) by addressing a critical alignment inefficiency. While the previous best model successfully fused raw EEG and spectrograms, it relied on the attention mechanism to blindly find the 50-second "needle" (the labeled event) within the 10-minute "haystack" (the spectrogram). The "Tri-View" experiment (Lesson 00004) attempted to solve this by adding a cropped input but failed due to redundancy and overfitting. This new strategy solves the alignment problem *internally* by injecting metadata (the time offset) directly into the attention mechanism, guiding the model to focus on the relevant spectral region without the computational cost or redundancy of processing a third input stream.

### 1. Model
The architecture is a multimodal network composed of two streams fused by a metadata-aware attention mechanism:

*   **Stream A: Raw EEG Encoder (Waveform Stream)**
    *   **Architecture:** This branch retains the **Multi-Scale 1D CNN (Inception)** backbone. It processes the raw EEG time series using parallel convolutional branches with varying kernel sizes (e.g., 3, 5, 7, 9).
    *   **Rationale:** This component is explicitly preserved to leverage its proven ability to learn frequency-specific filters and phase information directly from the waveform, which is superior to spectrograms for high-resolution temporal features **Cite {solution_lesson_node_00002}**.
    *   **Input:** All 20 channels (19 EEG + 1 EKG) are processed jointly, avoiding the performance degradation associated with manual channel splitting or exclusion **Cite {solution_lesson_node_00005}**.

*   **Stream B: Global Spectrogram Encoder (Context Stream)**
    *   **Architecture:** This branch uses an **EfficientNet-B2** backbone (a moderate upgrade from B0 to capture finer details).
    *   **Modification:** Crucially, the Global Average Pooling layer is removed. The output is a feature map $(Batch, Channels, Time_{spec}, Freq)$ which is flattened along the frequency axis to preserve the temporal sequence $(Batch, Channels, Time_{spec})$.
    *   **Rationale:** This provides the strong spectral inductive bias and long-term context (10 minutes) required for stable convergence **Cite {solution_lesson_node_00003}**.

*   **Fusion: Offset-Guided Cross-Attention**
    *   **Mechanism:** The model utilizes a Cross-Attention layer where the EEG features (Stream A) act as **Queries**, and the Spectrogram features (Stream B) act as **Keys and Values**.
    *   **Innovation:** A **Gaussian Bias Mask** is constructed using the `spectrogram_label_offset_seconds` metadata input. This mask is added to the attention logits before the Softmax operation. It creates a "soft spotlight" centered on the time frames corresponding to the 50-second labeled window within the 10-minute spectrogram.
    *   **Benefit:** This structurally enforces alignment, ensuring the model attends to the specific event features (solving the resolution mismatch) while still allowing gradient flow from the global context (avoiding the information loss of cropping) **Cite {solution_lesson_node_00004}**.

### 2. Data
The data pipeline prepares the two streams and the guidance metadata:

*   **Raw EEG:** Extract the central **50-second window**. Downsample to **100 Hz** to reduce dimensionality while maintaining the Nyquist frequency for relevant brain rhythms **Cite {solution_lesson_node_00002}**. Apply channel-wise instance normalization.
*   **Spectrogram:** Load the full **10-minute spectrogram**. Apply Log transformation (dB scale) and resize to a standard resolution (e.g., $512 \times 512$).
*   **Metadata:** Extract `spectrogram_label_offset_seconds` for each sample. Normalize this value to the range $[0, 1]$ corresponding to the relative position in the spectrogram time axis.
*   **Augmentation:** Apply **SpecAugment** (masking) to the spectrogram and **Channel Dropout** to the EEG.

### 3. Training
*   **Loss Function:** Use **Kullback-Leibler (KL) Divergence**. This metric aligns with the soft probability targets and has been empirically proven to outperform Cross-Entropy for this task **Cite {solution_lesson_node_00002}**.
*   **Optimizer:** Use **AdamW** combined with a **OneCycle Learning Rate** scheduler. This schedule facilitates super-convergence, which is essential for training this dual-stream architecture efficiently within the compute budget **Cite {solution_lesson_node_00003}**.
*   **Strategy:** Train end-to-end. The guided attention mechanism is expected to accelerate convergence further by removing the need for the model to "search" for the relevant time window during the early epochs.

### 4. Evaluation
*   **Inference:** For each test sample, load the 50s EEG, the 10m Spectrogram, and the offset metadata (which is 0 or centered for test data if not provided, but `test.csv` implies structure similar to train; if offset is missing in test, we assume the test EEG is the center of the test spectrogram).
*   **Prediction:** Pass inputs through the model. The output logits are processed via Softmax to produce probabilities.
*   **Submission:** Ensure the 6 class probabilities sum to 1.0.
