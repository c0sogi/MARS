I will implement a Python script that generates the required metadata files for the HMS Harmful Brain Activity Classification task.

**Implementation Strategy:**
1.  **Setup & Loading**: Define input/output directories and column constants. Load the raw `train.csv` and `test.csv` from `./input`.
2.  **Feature Engineering (Metadata)**:
    *   Construct file paths for EEG and spectrogram files relative to the `./input` directory (e.g., `train_eegs/{eeg_id}.parquet`).
    *   Normalize the target vote counts in the training data into probability distributions (summing to 1) to create the ground-truth labels.
3.  **Data Splitting**:
    *   Extract unique `patient_id`s from the training data.
    *   Shuffle patients using `RANDOM_STATE = 42`.
    *   Perform a Group Split (80% Train, 20% Validation) based on patients to prevent data leakage.
4.  **Saving**: Save the resulting DataFrames (`train.csv`, `val.csv`, `test.csv`) to the `./metadata` directory.
5.  **Verification**:
    *   Load the newly created metadata.
    *   Print summary statistics (shapes, patient counts, class distributions).
    *   Perform a "sanity check" on file paths by verifying the existence of 1000 randomly sampled files in the `./input` directory.
    *   Assert that the train/validation split strictly respects patient grouping (no overlap).
