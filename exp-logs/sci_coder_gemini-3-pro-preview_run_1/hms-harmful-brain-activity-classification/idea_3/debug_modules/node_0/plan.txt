This script demonstrates the usage of the provided machine learning library for EEG seizure detection. It covers:
1.  **Configuration**: Setting up the environment and hyperparameters for a quick demonstration.
2.  **Data Loading**: Instantiating datasets and dataloaders, and verifying data shapes.
3.  **Model Initialization**: Creating the Hybrid Dual-Stream model and verifying the forward pass.
4.  **Training Logic**: Executing a manual training step to verify loss calculation and backpropagation.
5.  **Full Pipeline Execution**: Running the high-level training and inference functions with patched configurations for speed.
