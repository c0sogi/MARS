Based on the comprehensive analysis of the provided lessons and the structural evolution of previous ideas, I propose the **Bottleneck-Projected Coordinate-Fusion Network**.

This strategy structurally evolves the "Current Best" approach (Idea 10) by resolving the conflict between **feature richness** and **overfitting**. While Coordinate Injection (Lesson 00011) successfully highlights the event within the global context, previous attempts to exploit this failed because they either used high-dimensional concatenation which led to memorization (Lesson 00019), or high-resolution maps which introduced noise (Lesson 00018). This solution introduces **Low-Rank Bottleneck Projections** to compress the coordinate-aware features into a compact semantic space *before* fusion, ensuring the model generalizes rather than memorizes.

### 1. Model
The architecture is a **Dual-Stream Network** that fuses compressed waveform dynamics with compressed, coordinate-aware global context.

*   **Stream A: Raw EEG Encoder (Waveform Stream)**
    *   **Backbone:** Retain the **Multi-Scale 1D Convolutional (Inception)** architecture.
    *   **Function:** Processes the 50-second raw EEG window (20 channels) using parallel convolutional branches with varying kernel sizes.
    *   **Rationale:** This component is explicitly preserved to extract phase and frequency-specific features directly from the waveform, which has been proven superior to spectrograms for short-window analysis **Cite {solution_lesson_node_00002}**.
    *   **Constraint:** Process all 20 channels jointly to capture full spatial dependencies **Cite {solution_lesson_node_00005}**.

*   **Stream B: Coordinate-Aware Spectrogram Encoder (Context Stream)**
    *   **Backbone:** Use a lightweight **EfficientNet-B0**.
    *   **Input:** Construct a **5-channel input tensor**. Channels 1-4 are the standard recording regions. Channel 5 is a **Coordinate Map**—a linear gradient encoding the relative temporal distance from the center of the labeled event.
    *   **Rationale:** This injection breaks translation invariance, allowing the CNN to effectively locate the event within the 10-minute context **Cite {solution_lesson_node_00011}**.
    *   **Tokenization:** The output feature map is flattened into tokens. **Crucially, do not pool the frequency dimension**, preserving spectral semantics **Cite {solution_lesson_node_00009}**.

*   **Structural Innovation: Low-Rank Bottleneck Projections**
    *   **Mechanism:** Before the fusion layer, project the output features of **both** streams (Sequence $E$ from EEG and Tokens $S$ from Spectrogram) down to a low-dimensional space (e.g., $D=128$) using learnable linear layers (or $1\times1$ convolutions) followed by Batch Normalization and ReLU.
    *   **Rationale:** This explicitly prevents the "Information Superhighway" problem observed in Idea 17, where high-dimensional features (1280-dim) caused the model to memorize noise. The bottleneck forces the encoders to distill the most salient semantic features (e.g., "spike presence" vs. "pixel noise") before they interact **Cite {solution_lesson_node_00019}**.

*   **Fusion: Asymmetric Cross-Attention**
    *   **Mechanism:** Implement a **Single-Layer Cross-Attention** block operating in the bottleneck dimension ($D=128$) **Cite {solution_lesson_node_00013}**.
    *   **Directionality:** Configure strictly as **EEG queries Spectrogram** ($Q=E_{proj}, K=S_{proj}, V=S_{proj}$).
    *   **Rationale:** This allows the randomly initialized EEG stream to extract stable features from the pretrained Spectrogram backbone without destabilizing it **Cite {solution_lesson_node_00012}**.

### 2. Data
*   **Raw EEG:** Extract the central 50-second window. Downsample to **100 Hz** to maintain the Nyquist frequency while reducing sequence length **Cite {solution_lesson_node_00002}**. Apply channel-wise instance normalization.
*   **Spectrograms:** Load the full 10-minute spectrogram. Resize to a standard resolution (e.g., $512 \times 512$).
*   **Coordinate Map:** Generate the 5th channel by creating a matrix where each column's value corresponds to its normalized temporal distance (e.g., $[-1, 1]$) from the `spectrogram_label_offset_seconds` **Cite {solution_lesson_node_00011}**.
*   **Augmentation:** Apply **SpecAugment** (masking) to the spectrogram channels (excluding the coordinate channel) and **Channel Dropout** to the EEG.

### 3. Training
*   **Strategy: Global Random Subsampling**
    *   **Protocol:** Randomly sample a fixed subset of the data (e.g., ~25,000 samples) at the start of the run.
    *   **Iterations:** Train on this **same subset** for multiple epochs (e.g., 4-5).
    *   **Rationale:** This prioritizes iterative convergence and Batch Normalization stability over single-pass data coverage. It avoids the underfitting of single-epoch training **Cite {solution_lesson_node_00014}** and the catastrophic forgetting of sequential partitioning **Cite {solution_lesson_node_00015}**.
*   **Loss Function:** **Kullback-Leibler (KL) Divergence** to align with soft targets **Cite {solution_lesson_node_00002}**.
*   **Constraint:** Do not use Deep Supervision (auxiliary heads), as it degrades complementary fusion **Cite {solution_lesson_node_00017}**.
*   **Optimizer:** **AdamW** with a **OneCycle Learning Rate** scheduler **Cite {solution_lesson_node_00003}**.

### 4. Evaluation
*   **Inference:** For each test sample, generate the 50-second EEG and the 5-channel Spectrogram.
*   **Alignment:** If `spectrogram_label_offset_seconds` is missing in the test metadata, assume the test EEG is centered within the spectrogram (offset = 0) to generate the coordinate map.
*   **Prediction:** Pass the inputs through the network. The attention outputs are Global Average Pooled and processed via Softmax to produce probabilities. Ensure the output sums to 1.0.
