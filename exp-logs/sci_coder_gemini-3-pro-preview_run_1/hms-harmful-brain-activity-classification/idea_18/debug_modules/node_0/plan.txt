This script demonstrates the end-to-end usage of the provided library components for classifying EEG brain activity.

### Strategy
1.  **Configuration Override**: We modify the `Config` class attributes to use a minimal subset of data (16 samples), a small batch size (4), and a temporary writable cache directory. This ensures the script executes in seconds rather than hours.
2.  **Data Pipeline**: We load the metadata, slice the first few rows, and pass this subset to `get_dataloader`. This triggers the `process_and_cache_dataset` function, which converts raw Parquet files into pre-processed Numpy arrays. We assert that the resulting DataLoader yields tensors with the correct dimensions for both the EEG stream (Time-Series) and Spectrogram stream (Image).
3.  **Model Execution**: We instantiate the `BottleneckProjectedFusionNet`, move it to the GPU, and perform a forward pass. We verify that the output logits match the expected shape `(Batch_Size, Num_Classes)`.
4.  **Training Simulation**: We initialize the optimizer, scheduler, and the custom `KLDivLossWithLogits`. We then run `train_one_epoch` to verify the backpropagation loop and ensure the loss is calculated correctly (non-NaN, positive).
5.  **Inference Verification**: We manually run the model in evaluation mode, apply the softmax function, and assert that the predicted probabilities for each sample sum to 1.0, satisfying the submission requirement.
