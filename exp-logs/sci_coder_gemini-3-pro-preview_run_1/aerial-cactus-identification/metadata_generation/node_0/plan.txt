This script generates metadata for the Aerial Cactus Identification task. It performs the following steps:

1.  **Setup**: Defines input (`./input`) and output (`./metadata`) directories and ensures the output directory exists.
2.  **Data Loading**: Reads the raw `train.csv` and `sample_submission.csv` files.
3.  **Path Construction**: Adds a `file_path` column to the dataframes.
    *   For training data, paths are `train/<id>`.
    *   For test data, paths are `test/<id>`.
4.  **Splitting**: Performs a stratified 80/20 split on the training data using `has_cactus` as the target and `RANDOM_STATE=42`.
5.  **Saving**: Saves the resulting `train`, `val`, and `test` metadata as CSV files in the `./metadata` directory.
6.  **Verification**:
    *   Loads the generated metadata files.
    *   Prints summary statistics (count, class distribution).
    *   Validates that the stratified split preserved the class distribution.
    *   Checks that the relative file paths correctly resolve to existing files in the `./input` directory.
