Based on the comprehensive analysis of previous iterations and the extracted lessons, I propose a solution that structurally evolves the **Heterogeneous Stacking** approach by replacing the underperforming "modern" backbones with a **Dual-Domain** strategy. This approach directly targets the "Data Quality" bottleneck (compression artifacts) by explicitly feeding texture/edge information to the model, rather than relying solely on architectural diversity.

# Model
I propose a **Heterogeneous Dual-Domain Stacking Ensemble**.

### 1. Diverse Domain-Specialized Base Learners
Instead of using architectures that are ill-suited for low-resolution data (like ConvNeXt), the ensemble will use the highly efficient **RepVGG** and **ResNet** backbones. The structural innovation lies in the **Input Domain**:
1.  **Spatial Specialist (CactusRepVGG-Spatial):** A standard **RepVGG** backbone taking **RGB** inputs. It focuses on color and shape features.
2.  **Texture Specialist (CactusRepVGG-Texture):** A **RepVGG** backbone taking **4-channel inputs** (RGB + **Laplacian Edge Map**).
    *   **Rationale:** Cacti are defined by spines (high-frequency texture), and the primary noise source is JPEG blocking (high-frequency artifacts). By explicitly computing the Laplacian (second-order derivative), we provide the network with a "texture-first" view, allowing it to better distinguish between biological spines and compression noise **(Cite solution_lesson_node_00029)**.
3.  **Baseline Stabilizer (CactusResNet-Spatial):** A standard **ResNet** backbone taking **RGB** inputs to provide architectural diversity.

### 2. Structural Components
All base learners will strictly adhere to the following design principles derived from previous lessons:
*   **Conservative Downsampling:** All stems will use a 3x3 convolution with stride 1 and no pooling to strictly preserve the 32x32 spatial resolution **(Cite solution_lesson_node_00001)**.
*   **3x3 Kernels:** All convolutions will strictly use **3x3 kernels**, avoiding the signal blurring caused by larger kernels on small images **(Cite solution_lesson_node_00016)**.
*   **Re-parameterization:** The RepVGG models will use multi-branch blocks (3x3 + 1x1 + Identity) during training for stability, fused into single layers for inference **(Cite solution_lesson_node_00017)**.

### 3. Quality-Aware Modulation (FiLM + MTL)
To address the correlation between error rates and file size, all models will incorporate:
*   **Feature-wise Linear Modulation (FiLM):** A shared MLP will project the normalized **Image File Size** into scale and shift parameters to modulate feature maps throughout the network. This allows the model to dynamically suppress texture filters when processing low-quality (highly compressed) images **(Cite solution_lesson_node_00035, solution_lesson_node_00045)**.
*   **Multi-Task Learning (MTL):** An **Auxiliary Regression Head** will be trained to predict the log-transformed file size, forcing the backbone to explicitly encode quality-related features **(Cite solution_lesson_node_00045)**.

# Data
*   **Preprocessing & Caching:** The entire dataset will be decoded and **cached in RAM** as floating-point tensors **(Cite solution_lesson_node_00020)**.
*   **Feature Engineering:**
    *   **Laplacian Map:** For the "Texture Specialist" models, the Laplacian edge map will be computed for each image and concatenated as a 4th channel.
    *   **Metadata:** Image file sizes will be extracted, Z-score normalized (for FiLM), and log-transformed/scaled (for MTL targets).
*   **Augmentation:**
    *   **Geometric:** **RandomHorizontalFlip** and **RandomVerticalFlip** to exploit rotational invariance **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** **Mild Mixup** ($\alpha=0.2$) applied to inputs and targets to close the generalization gap **(Cite solution_lesson_node_00004)**.

# Training
*   **Strategy:** **5-Fold Stratified Cross-Validation** will be performed for each of the 3 configurations (15 models total). This generates unbiased Out-Of-Fold (OOF) predictions for the meta-learner **(Cite solution_lesson_node_00033)**.
*   **Optimizer:** **AdamW** for effective weight decay.
*   **Scheduler:** **Cosine Annealing** for **30 epochs** per fold to ensure convergence with Mixup **(Cite solution_lesson_node_00003)**.
*   **Stochastic Weight Averaging (SWA):** Activated in the final 5 epochs of training to locate flat minima and improve robustness without the cost of SAM **(Cite solution_lesson_node_00029)**.
*   **Loss Function:** Weighted sum of Binary Cross-Entropy (Class) and MSE (Quality).

# Evaluation
*   **Structural Fusion:** Before inference, RepVGG models will be re-parameterized (fused) to maximize speed **(Cite solution_lesson_node_00017)**.
*   **Inference Strategy:**
    1.  **TTA:** Each model generates predictions using **4-view Test Time Augmentation** (original, flips, rotation) **(Cite solution_lesson_node_00002)**.
    2.  **Stacking:** The aggregated OOF predictions from the Spatial RepVGG, Texture RepVGG, and Spatial ResNet, along with the file size metadata, will be fed into a **Logistic Regression Meta-Learner** to produce the final probability **(Cite solution_lesson_node_00033)**.
