Implementation Strategy:
1.  **Orchestration**: I will implement a robust `runfile.py` that orchestrates the entire pipeline using the provided library modules. This ensures code reuse and adherence to the specified architecture.
2.  **Data Management**: The script will leverage `library.dataset.load_and_cache_images` to load the dataset and cache it in RAM. This eliminates I/O bottlenecks. I will use `StratifiedKFold` (5 splits) to ensure the training and validation sets are statistically representative.
3.  **Model Training (SWA)**: For each fold, I will initialize a `RepVGGClassifier`. Training will proceed for 35 epochs. I will use a `CosineAnnealingLR` scheduler initially, then switch to `SWAHandler` at epoch 25 to perform Stochastic Weight Averaging. This two-phase approach ensures convergence to a robust flat minimum.
4.  **Inference Optimization**: Post-training, I will use `model_to_deploy` to structurally re-parameterize the RepVGG models. This fuses the multi-branch blocks into single 3x3 convolutions, significantly optimizing inference speed and memory usage.
5.  **Evaluation & Failure Analysis**: I will compute the Out-Of-Fold (OOF) AUC score. I will then calculate the residuals (absolute error) for the validation set and correlate them with image statistics (mean intensity and contrast) to identify potential failure modes as requested.
6.  **Submission with TTA**: Assuming the model performs better than random guessing (AUC > 0.5), I will generate predictions for the test set. I will employ Test Time Augmentation (TTA) by averaging predictions from 4 views (Original, H-Flip, V-Flip, 180-Rotate) across all 5 fold models to maximize accuracy.
