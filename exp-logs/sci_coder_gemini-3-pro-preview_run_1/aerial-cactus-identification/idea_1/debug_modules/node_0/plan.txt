The following script demonstrates the end-to-end usage of the provided library files to solve the Cactus Identification task.

**Implementation Strategy:**
1.  **Configuration**: We initialize the `Config` class with `debug=True`. This sets the system to use a small subset of the data (500 images) and runs only 2 epochs, ensuring the demonstration completes quickly while exercising all code paths.
2.  **Component Verification**: Before running the full pipeline, we verify the individual components:
    *   **Data Loading**: We instantiate the DataLoaders using `get_dataloaders` and fetch a single batch to assert that the image tensors have the correct shape `(Batch, 3, 32, 32)` and labels are present.
    *   **Model Architecture**: We instantiate the `CactusResNet` model and perform a forward pass with the dummy batch to confirm the output shape is `(Batch, 1)`.
3.  **Pipeline Execution**: We call the `run()` function from `engine.py`. This function handles the entire workflow: setting seeds, initializing the optimizer/scheduler, training with early stopping, and generating predictions on the test set.
4.  **Output Validation**: Finally, we load the generated submission CSV file to verify it adheres to the required format (correct columns, probability values between 0 and 1, and correct row count matching the debug subset).
