Based on the comprehensive analysis of the accumulated lessons, specifically the breakthrough in **Lesson 00062** (using auxiliary quality errors as trust scores) and the validation of **Heterogeneous Stacking** in **Lesson 00033**, I propose a solution that structurally evolves the ensemble strategy into a **Heterogeneous Trust-Gated Mixture of Experts**.

This approach resolves the conflict between the need to handle data quality issues (Lesson 00029) and the redundancy of explicit metadata injection (Lesson 00054). Instead of feeding metadata *into* the network (which proved ineffective), we use the *error* in predicting metadata to **gate** the ensemble members, dynamically up-weighting models that demonstrate a correct understanding of the image's quality context.

# Model
I propose a **Trust-Gated Mixture of Experts (MoE)** architecture.

### 1. The Experts: Heterogeneous Quality-Aware Backbones
The ensemble will consist of two distinct backbone architectures to ensure diversity in feature representation.
*   **Expert A (CactusRepVGG):** A re-parameterizable architecture using multi-branch blocks (3x3 + 1x1 + Identity) during training, fused into single-path 3x3 convolutions for inference **(Cite solution_lesson_node_00017)**.
*   **Expert B (CactusResNet):** A standard residual network backbone providing a stable, diverse alternative to the VGG-style stream.

**Universal Structural Constraints:**
Both experts will strictly adhere to the following design principles:
*   **Conservative Downsampling:** Stems will use a single 3x3 convolution with stride 1 and **no pooling** to strictly preserve the 32x32 spatial resolution **(Cite solution_lesson_node_00001)**.
*   **Small Kernel Constraint:** All convolutions will strictly use **3x3 kernels** to avoid the signal blurring observed with larger kernels on small images **(Cite solution_lesson_node_00016)**.
*   **Implicit Quality Supervision:** Both experts will feature an **Auxiliary Regression Head** attached to the final feature layer, trained to predict the **Log-Transformed File Size**. This forces the backbones to *implicitly* learn compression artifacts without the redundancy of explicit metadata injection at the input level **(Cite solution_lesson_node_00054, solution_lesson_node_00062)**.

### 2. The Router: Trust-Gating Network
Instead of a static heuristic (Lesson 00062) or a linear stacker (Lesson 00033), I will implement a **Learnable Gating Network**.
*   **Input:** A vector containing the **Trust Scores** (Absolute Error between predicted and actual file size) from all experts.
*   **Architecture:** A lightweight Multilayer Perceptron (MLP) ending in a **Softmax** layer.
*   **Output:** A set of mixing weights $w_i$ that sum to 1.
*   **Mechanism:** The final prediction is the weighted sum of the experts' probabilities: $\hat{y} = \sum w_i(Error) \cdot p_i$. This allows the system to learn non-linear relationships between model reliability (error) and ensemble influence, effectively "turning off" experts that are hallucinating the image quality context.

# Data
*   **Preprocessing & Caching:** The entire dataset (train and test) will be decoded and **cached in RAM** as floating-point tensors to eliminate I/O latency **(Cite solution_lesson_node_00020)**.
*   **Target Engineering:**
    *   **Training:** File sizes will be extracted, log-transformed, and normalized (0-1) to serve as targets for the Auxiliary Regression Heads.
    *   **Gating:** Out-Of-Fold (OOF) auxiliary errors will be computed to train the Gating Network.
*   **Augmentation:**
    *   **Geometric:** **RandomHorizontalFlip** and **RandomVerticalFlip** to exploit rotational invariance **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** **Mild Mixup** ($\alpha=0.2$) applied to both class labels and regression targets to close the generalization gap **(Cite solution_lesson_node_00004)**.

# Training
I propose a **Two-Stage Stratified SWA Pipeline**.

### Stage 1: Train Experts
*   **Strategy:** **5-Fold Stratified Cross-Validation** will be performed for each architecture (10 models total). This generates unbiased OOF predictions and Trust Scores **(Cite solution_lesson_node_00033)**.
*   **Optimizer:** **AdamW** with a **Cosine Annealing** scheduler for **30 epochs** per fold.
*   **Stochastic Weight Averaging (SWA):** Activated during the final 10 epochs (with cyclic learning rates) to locate flat minima in the loss landscape, improving robustness without the cost of SAM **(Cite solution_lesson_node_00029)**.
*   **Loss Function:** Weighted Multi-Task Loss: $L_{total} = L_{BCE}(\text{Class}) + \lambda L_{MSE}(\text{Quality})$.

### Stage 2: Train Router
*   **Data:** The OOF Trust Scores (Errors) from Stage 1 are used as inputs; the OOF Class Predictions are the features to be weighted; the ground truth labels are the targets.
*   **Objective:** Minimize the Binary Cross-Entropy of the weighted ensemble prediction. This freezes the experts and optimizes only the mixing weights to maximize the collective trust.

# Evaluation
*   **Structural Fusion:** Before inference, RepVGG models will be re-parameterized into single layers **(Cite solution_lesson_node_00017)**.
*   **Inference Strategy:**
    1.  **TTA:** Each of the 10 trained models generates predictions (Class + File Size) using **4-view Test Time Augmentation** **(Cite solution_lesson_node_00002)**.
    2.  **Trust Calculation:** Calculate the Trust Score (Auxiliary Error) for each model on each test image using the known test file sizes **(Cite solution_lesson_node_00062)**.
    3.  **Gating:** Feed the Trust Scores into the trained Gating Network to obtain optimal weights.
    4.  **Aggregation:** Compute the final weighted average probability.
