### Implementation Strategy

1.  **Configuration Setup**: We will modify the global `Config` class attributes to point to a temporary working directory (`./working/demo_run`) and reduce training parameters (1 epoch, minimal SWA start) to ensure the script runs quickly.
2.  **Dataset Verification**: We will demonstrate loading data using `load_data_to_memory`, instantiate the `CactusDataset`, and verify the output shapes and data types of the items produced by the dataset (image tensors, metadata, and labels).
3.  **Model Architecture Verification**: We will instantiate the `MetadataFusedRepVGG` model, perform a forward pass with dummy data to verify output dimensions, and demonstrate the structural re-parameterization (fusion) capability by calling `switch_to_deploy()` and verifying the layer structure changes.
4.  **Training Loop Demonstration**: We will set up DataLoaders and the `Trainer` class, then execute `trainer.fit()` for a single epoch. We will verify that the training process completes and generates the expected model checkpoints.
5.  **Inference Pipeline Demonstration**: We will execute the `run_inference()` function (which utilizes the trained model and test metadata) and verify that it produces a submission file in the correct format.
6.  **Cleanup**: No cleanup is strictly required as we work in a designated `./working` subdirectory, but the script is designed to be idempotent.
