The `RuntimeError: Unexpected key(s) in state_dict: "n_averaged"` occurs because the checkpoints were saved using PyTorch's `AveragedModel` (SWA), which adds a buffer named `n_averaged` to track the number of averaged models. When loading this state dictionary back into the standard base model architecture (e.g., `CactusRepVGG`), this key is not recognized. To fix this, we must explicitly filter out the `n_averaged` key when processing the state dictionary for loading, as identified in **debug_lesson_7**. Cite debug_lesson_7.
