Here is the implementation strategy and the complete Python script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the environment using `Config.setup()` and `seed_everything()` to ensure reproducibility and proper directory structure.
2.  **Data Loading & Verification**:
    *   Use `get_datasets()` to load the training, validation, and test datasets.
    *   Verify the integrity of the dataset by checking the length and the shape of a single sample (image, label, metadata).
    *   Demonstrate the `mixup_data` function by applying it to a dummy batch and asserting the output shapes.
3.  **Model Architecture Verification**:
    *   Iterate through all supported backbones (`RepVGG`, `ResNet`, `NeXt`).
    *   Instantiate `CactusModel` for each backbone.
    *   Perform a forward pass with dummy tensors (images and file size metadata) to verify that the model produces classification logits and auxiliary quality predictions of the correct shape.
    *   Specifically for `RepVGG`, verify the `switch_to_deploy` functionality which fuses layers for inference.
4.  **Training & Evaluation Loop**:
    *   Create a small subset of the training and validation data (e.g., 32 samples) to allow for rapid execution.
    *   Initialize the `CactusModel` (using ResNet for this demo), an optimizer, and loss functions.
    *   Execute `train_one_epoch` to demonstrate the training logic, including Mixup and Multi-Task Learning.
    *   Execute `validate` to demonstrate the evaluation logic and metric calculation (ROC AUC).
5.  **SWA (Stochastic Weight Averaging) Demonstration**:
    *   Configure `SWAHandler` with a low start epoch.
    *   Simulate a short training cycle to trigger SWA model updates.
    *   Perform the `finalize` step to update BatchNorm statistics and verify the SWA model is ready for inference.
