### Implementation Strategy

1.  **Environment Setup**: Initialize the random seed using `library.utils.seed_everything` and determine the computation device (CPU/GPU).
2.  **Dataset Preparation**: Instantiate `CactusDataset` for both training and validation sets using the provided metadata files. We will use a dedicated cache directory for this demonstration to ensure clean execution. We will verify the data loading process by inspecting a single batch from the `DataLoader`.
3.  **Model Initialization**: Initialize the `QualityRepVGG` model (specifically the lightweight "RepVGG-A0" variant) using `library.model.get_repvgg_model`. We will perform a dummy forward pass to validate the output shapes for both classification and quality regression heads.
4.  **Training Simulation**: configure an optimizer and a learning rate scheduler, then execute the training loop using `library.engine.train_model`. We will limit the run to 2 epochs to satisfy the speed constraint. This step demonstrates the integration of the dataset, model, and training engine (including Mixup and Multi-Task Loss).
5.  **Inference and Calibration**: Use the `library.inference.predict_with_calibration` function to generate predictions on the test set. This demonstrates the advanced inference pipeline, including Test Time Augmentation (TTA), model reparameterization (fusing blocks for speed), and dynamic quality-based calibration.
6.  **Output Verification**: Finally, load the generated submission CSV to verify its format, dimensions, and value ranges, ensuring the pipeline produced a valid result.
