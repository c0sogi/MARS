Based on the accumulated lessons, specifically the critical insight from **Lesson 00054** (explicit metadata injection is redundant/harmful) and **Lesson 00029** (errors are driven by data quality/compression artifacts), I propose a solution that leverages **Multi-Task Learning** to enforce implicit quality awareness, combined with a novel **Quality-Calibrated Inference** strategy.

# Model
I propose a **Quality-Supervised RepVGG** architecture.

*   **Backbone:** The core feature extractor will be a **Custom RepVGG**.
    *   **Conservative Downsampling:** The network will use a "conservative stem" (3x3 convolution, stride 1, no pooling) to strictly preserve the 32x32 spatial resolution, preventing the signal destruction caused by standard stems **(Cite solution_lesson_node_00001)**.
    *   **Kernel Sizing:** All convolutions will strictly use **3x3 kernels**, avoiding the blurring effects of large kernels on small images **(Cite solution_lesson_node_00016)**.
    *   **Training Topology:** Blocks will use a multi-branch design (3x3 + 1x1 + Identity) to maximize gradient flow **(Cite solution_lesson_node_00017)**.
*   **Structural Innovation (Dual-Head Supervision):**
    *   **Classification Head:** Standard head for predicting `has_cactus`.
    *   **Auxiliary Quality Head:** A regression head attached to the final feature layer, trained to predict the **Log-Transformed File Size** of the input image.
    *   **Rationale:** Instead of injecting metadata as an input (which failed in **Lesson 00054**), this forces the backbone to *implicitly* learn features related to compression artifacts (blocking, ringing) by backpropagating the file size prediction error. This ensures the visual representation is "quality-aware" by design.

# Data
*   **Preprocessing & Caching:** The entire dataset (train and test) will be decoded and **cached in RAM** as floating-point tensors to eliminate I/O latency **(Cite solution_lesson_node_00020)**.
*   **Target Engineering:** The file size (in bytes) for each image will be extracted.
    *   **Training:** Log-transformed and normalized (0-1) to serve as the target for the Auxiliary Quality Head.
    *   **Inference:** The actual file sizes of the test set will be stored to enable the calibration strategy.
*   **Augmentation:**
    *   **Geometric:** **RandomHorizontalFlip** and **RandomVerticalFlip** to exploit rotational invariance **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** **Mild Mixup** ($\alpha=0.2$) applied to both class labels and regression targets to close the generalization gap **(Cite solution_lesson_node_00004, solution_lesson_node_00006)**.

# Training
I propose a **Stratified SWA Cross-Validation Pipeline**.
*   **Strategy:** **5-Fold Stratified Cross-Validation** to ensure robustness across the data distribution **(Cite solution_lesson_node_00033)**.
*   **Optimizer:** **AdamW** with a **Cosine Annealing** scheduler for **30 epochs** per fold **(Cite solution_lesson_node_00003)**.
*   **Stochastic Weight Averaging (SWA):** Activated during the final 10 epochs (with cyclic learning rates) to locate flat minima in the loss landscape, improving generalization without the computational cost of SAM **(Cite solution_lesson_node_00029)**.
*   **Loss Function:** Weighted Multi-Task Loss: $L_{total} = L_{BCE}(\text{Class}) + \lambda L_{MSE}(\text{Quality})$.

# Evaluation
*   **Structural Fusion:** Before inference, the RepVGG blocks will be re-parameterized into single layers **(Cite solution_lesson_node_00017)**. Both heads are retained.
*   **Inference Strategy (Quality-Calibrated Ensemble):**
    1.  **TTA:** Each of the 5 fold models generates predictions using **4-view Test Time Augmentation** **(Cite solution_lesson_node_00002)**.
    2.  **Dynamic Calibration:** For each test image, we compare the model's *predicted* file size ($\hat{Q}$) with the *actual* file size ($Q_{true}$). We calculate a confidence weight $w_i = \exp(-|Q_{true} - \hat{Q}_i|)$.
    3.  **Aggregation:** The final probability is the weighted average of the 5 models. This gives higher influence to models that correctly assessed the image's quality context, effectively filtering out predictions from models that "misunderstood" the compression artifacts.
