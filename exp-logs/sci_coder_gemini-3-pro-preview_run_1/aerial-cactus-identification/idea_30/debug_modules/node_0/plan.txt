The following implementation demonstrates the usage of the provided library files to create a complete machine learning pipeline for the cactus classification task.

### Strategy
1.  **Configuration Override**: We dynamically modify the `Config` class to set a temporary working directory (`./working/demo_run`) and reduce hyperparameters (1 epoch, batch size 64) to ensure the script runs quickly (under 1 hour).
2.  **Data Pipeline**: We utilize `get_dataloaders` to process images from the read-only `./input` directory and cache them. We verify the batch structure and shapes.
3.  **Model & Training**: We instantiate the `CactusRepVGG` model and run a single epoch of training using `train_one_epoch` and validation using `validate` to confirm the engine's functionality.
4.  **SWA Integration**: We demonstrate the `SWAHandler` by simulating a weight averaging step and finalizing batch normalization statistics.
5.  **Stacking**: We use `StackingDataManager` to load ground truth data and `run_stacking` to train a meta-learner on synthetic Out-Of-Fold (OOF) predictions, generating a final submission file.
6.  **Verification**: Assertions are placed at every critical step to validate shapes, types, and file existence.
