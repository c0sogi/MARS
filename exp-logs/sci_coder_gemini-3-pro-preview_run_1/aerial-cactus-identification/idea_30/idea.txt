Based on the comprehensive analysis of the accumulated lessons, specifically the validation of **Heterogeneous Stacking** (Lesson 00033) and the breakthrough in **Dynamic Quality Calibration** (Lesson 00062), I propose a solution that resolves the limitation of linear meta-learners by implementing **Interaction-Based Trust-Weighted Stacking**.

This approach structurally enforces the "Trust" logic—where a model's influence is gated by its understanding of the image quality—directly into the stacking features, enabling a simple linear meta-learner to perform non-linear gating.

# Model
I propose a **Heterogeneous Interaction-Based Trust-Weighted Ensemble**.

### 1. Diverse Quality-Aware Base Learners
The ensemble will consist of two distinct backbone architectures to ensure diversity in feature representation and error profiles.
*   **CactusRepVGG-MTL:** A re-parameterizable architecture using multi-branch blocks (3x3 + 1x1 + Identity) during training, fused into single-path 3x3 convolutions for inference **(Cite solution_lesson_node_00017)**.
*   **CactusResNet-MTL:** A standard residual network backbone providing a stable, diverse alternative.

**Universal Structural Constraints:**
Both architectures will strictly adhere to the following design principles:
*   **Conservative Downsampling:** Stems will use a single 3x3 convolution with stride 1 and **no pooling** to strictly preserve the 32x32 spatial resolution **(Cite solution_lesson_node_00001)**.
*   **Small Kernel Constraint:** All convolutions will strictly use **3x3 kernels**, avoiding the signal blurring observed with larger kernels on small images **(Cite solution_lesson_node_00016)**.
*   **Implicit Quality Supervision:** Both architectures will feature an **Auxiliary Regression Head** attached to the final feature layer, trained to predict the **Log-Transformed File Size**. This forces the backbones to *implicitly* learn compression artifacts without the redundancy of explicit metadata injection at the input level **(Cite solution_lesson_node_00054, solution_lesson_node_00062)**.

### 2. Structural Innovation: Interaction-Based Meta-Features
Standard stacking (Lesson 00033) feeds raw probabilities to a linear meta-learner. Idea 28 fed probabilities and trust scores separately. However, a linear meta-learner cannot model the *interaction* (i.e., "Ignore Model A *if* Trust A is low").
I propose constructing **Interaction Features** for the Meta-Learner:
*   **Trust Score Calculation:** $T_{model} = \exp(-|FileSize_{pred} - FileSize_{true}|)$.
*   **Feature Engineering:** Instead of raw probabilities $P$, we feed **Modulated Probabilities**: $P_{mod} = P_{raw} \times T_{model}$.
*   **Rationale:** This hard-codes the gating logic: if a model "hallucinates" the file size (low Trust), its modulated probability shrinks toward zero (or a neutral baseline), effectively removing it from the ensemble decision *before* the linear combination. This allows the Logistic Regression meta-learner to focus on calibrating the reliable signals **(Cite solution_lesson_node_00062)**.

# Data
*   **Preprocessing & Caching:** The entire dataset (train and test) will be decoded and **cached in RAM** as floating-point tensors to eliminate I/O latency **(Cite solution_lesson_node_00020)**.
*   **Target Engineering:**
    *   **Training:** File sizes will be extracted, log-transformed, and normalized (0-1) to serve as targets for the Auxiliary Regression Heads.
    *   **Meta-Training:** Out-Of-Fold (OOF) auxiliary errors will be computed to construct the Trust Scores.
*   **Augmentation:**
    *   **Geometric:** **RandomHorizontalFlip** and **RandomVerticalFlip** to exploit rotational invariance **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** **Mild Mixup** ($\alpha=0.2$) applied to both class labels and regression targets to close the generalization gap **(Cite solution_lesson_node_00004)**.

# Training
*   **Strategy:** **5-Fold Stratified Cross-Validation** will be performed for each architecture (10 models total). This generates the unbiased OOF predictions and Trust Scores required to train the Meta-Learner **(Cite solution_lesson_node_00033)**.
*   **Optimizer:** **AdamW** with a **Cosine Annealing** scheduler for **30 epochs** per fold to ensure convergence with Mixup **(Cite solution_lesson_node_00003)**.
*   **Stochastic Weight Averaging (SWA):** Activated during the final 10 epochs (with cyclic learning rates) to locate flat minima in the loss landscape, improving robustness without the cost of SAM **(Cite solution_lesson_node_00029)**.
*   **Loss Function:** Weighted Multi-Task Loss: $L_{total} = L_{BCE}(\text{Class}) + \lambda L_{MSE}(\text{Quality})$.

# Evaluation
*   **Structural Fusion:** Before inference, RepVGG models will be re-parameterized into single layers **(Cite solution_lesson_node_00017)**.
*   **Inference Strategy:**
    1.  **TTA:** Each of the 10 trained models generates predictions (Class + File Size) using **4-view Test Time Augmentation** **(Cite solution_lesson_node_00002)**.
    2.  **Trust Calculation:** For each test image, calculate the Trust Score for each model using the known test file size.
    3.  **Feature Generation:** Compute the Interaction Features ($P \times T$) for all models.
    4.  **Meta-Prediction:** Feed these modulated features into the trained Logistic Regression Meta-Learner to produce the final probability.
