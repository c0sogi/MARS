The issue identified is **data leakage** in the stacking meta-learner evaluation. The original code trained the meta-learner on the full set of Out-Of-Fold (OOF) features and then evaluated it on the exact same dataset, leading to an invalid, overly optimistic AUC score (near 1.0). To fix this, I will implement **Nested Cross-Validation** using `cross_val_predict`. This generates unbiased predictions for the OOF set (where each prediction comes from a model trained on a subset not containing that sample) to calculate a valid validation metric, while still fitting the final meta-learner on the full dataset for test-time inference. def run_meta_learning(oof_features, oof_targets):

    stacker = StackingEnsemble()

    # FIX: Use Cross-Validation to get unbiased predictions for scoring
    # This prevents leakage where the model is evaluated on data it was trained on.
    print("Performing internal CV for Meta-Learner evaluation...")
    cv = StratifiedKFold(n_splits=Config.N_FOLDS, shuffle=True, random_state=Config.SEED)

    # Generate unbiased probability predictions
    # cross_val_predict returns (N, n_classes) for method='predict_proba'

        oof_features,
        oof_targets,
