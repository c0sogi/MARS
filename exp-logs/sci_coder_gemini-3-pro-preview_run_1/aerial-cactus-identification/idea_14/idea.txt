Based on the accumulated lessons and the trajectory of previous ideas, I propose a solution that structurally evolves the "Metadata Gating" concept into a **Deep Feature Modulation** strategy, implemented within a **Heterogeneous Stacking Ensemble**. This approach maximizes the utility of the critical data quality signal (file size) by allowing it to influence feature extraction at multiple depths, rather than just calibrating the final output.

# Model
I propose a **Heterogeneous Feature-Modulated Stacking Ensemble**.

*   **Level 1: Diverse Modulated Base Learners**
    The ensemble will consist of three distinct architectures to ensure diversity in error profiles.
    1.  **CactusRepVGG-FiLM:** A re-parameterizable backbone (3x3 + 1x1 + Identity training topology) **(Cite solution_lesson_node_00017)**.
    2.  **CactusResNet-FiLM:** A standard residual network backbone.
    3.  **CactusNeXt-FiLM (3x3):** A modernized backbone using Depthwise Convolutions, LayerNorm, and GELU, strictly enforcing **3x3 kernels** to fit the image scale **(Cite solution_lesson_node_00016)**.

    **Structural Innovation (FiLM):**
    Instead of a single gating mechanism at the classification head (as in Idea 12/13), each architecture will incorporate **Feature-wise Linear Modulation (FiLM)** layers.
    *   **Mechanism:** A shared lightweight MLP will project the normalized **Image File Size** metadata into a set of scale ($\gamma$) and shift ($\beta$) parameters.
    *   **Integration:** These parameters will modulate the feature maps at the end of each network stage (e.g., $Feature_{out} = \gamma \cdot Feature_{in} + \beta$).
    *   **Rationale:** This allows the network to dynamically adapt its internal feature extraction process—such as suppressing high-frequency texture filters when processing highly compressed (low file size) images—providing a deeper inductive bias than simple output calibration **(Cite solution_lesson_node_00029, solution_lesson_node_00035)**.

    **Strategic Retention:**
    *   **Conservative Downsampling:** All backbones will use a stride-1, pooling-free stem to strictly preserve the 32x32 spatial resolution **(Cite solution_lesson_node_00001)**.
    *   **Re-parameterization:** The RepVGG variant will be mathematically fused into single-layer blocks for inference **(Cite solution_lesson_node_00017)**.

*   **Level 2: Meta-Learner**
    A **Logistic Regression** meta-learner will be trained to aggregate the probabilities from the base learners, correcting for any remaining architectural biases **(Cite solution_lesson_node_00033)**.

# Data
*   **Preprocessing & Caching:** The entire dataset will be decoded and **cached in RAM** as floating-point tensors to eliminate I/O latency **(Cite solution_lesson_node_00020)**.
*   **Feature Engineering:** Image file sizes will be extracted and **Z-score normalized** to serve as the input for the FiLM generators.
*   **Augmentation:**
    *   **Geometric:** **RandomHorizontalFlip** and **RandomVerticalFlip** will be applied to exploit rotational invariance **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** **Mild Mixup** ($\alpha=0.2$) will be applied to close the generalization gap without drowning out the signal **(Cite solution_lesson_node_00004, solution_lesson_node_00006)**.

# Training
*   **Strategy:** **5-Fold Stratified Cross-Validation** will be performed for each of the 3 architectures. This generates unbiased Out-Of-Fold (OOF) predictions for training the Meta-Learner **(Cite solution_lesson_node_00033)**.
*   **Optimizer:** **AdamW** will be used for effective weight decay.
*   **Scheduler:** A **Cosine Annealing** scheduler will be employed for **30 epochs** per fold to ensure convergence with Mixup **(Cite solution_lesson_node_00003)**.
*   **Stochastic Weight Averaging (SWA):** To efficiently locate flat minima in the loss landscape without the computational doubling of SAM, SWA will be activated during the final epochs of training for each fold **(Cite solution_lesson_node_00029)**.
*   **Loss Function:** **Binary Cross-Entropy with Logits** to handle soft Mixup targets.

# Evaluation
*   **Structural Fusion:** Before inference, the RepVGG-FiLM models will undergo structural re-parameterization to fuse the convolutional branches, while retaining the FiLM modulation layers **(Cite solution_lesson_node_00017)**.
*   **Inference Strategy:**
    1.  **TTA:** For every test image, each of the 15 trained models (3 archs $\times$ 5 folds) will generate predictions using **4-view Test Time Augmentation** (original, horizontal flip, vertical flip, 180-degree rotation). The same file size metadata will be fed to the FiLM generator for all views **(Cite solution_lesson_node_00002)**.
    2.  **Aggregation:** Predictions will be averaged across folds for each architecture.
    3.  **Stacking:** The aggregated scores will be fed into the Meta-Learner to produce the final prediction.
