Here is the implementation of the `runfile.py` orchestration script.

**Strategy Outline:**
1.  **Configuration Patching**: To satisfy the "Fast Baseline" requirement within the 2-hour limit, the script dynamically modifies the `Config` class to reduce the number of training epochs (from 30 to 5) and cross-validation folds (from 5 to 2). This ensures the pipeline executes quickly on the A100 GPU while still running the complete workflow.
2.  **Training**: The script invokes `train.run_training()` to train the three heterogeneous architectures (RepVGG, ResNet, NeXt) with the FiLM modulation mechanism.
3.  **Inference & Submission**: It calls `inference.run_inference()` to generate Out-Of-Fold (OOF) predictions, train the stacking meta-learner, and generate the final `submission.csv` for the test set.
4.  **Validation & Analysis**:
    *   It explicitly loads the hold-out validation set defined in `val_metadata.csv`.
    *   It loads the trained checkpoints for all architectures and folds.
    *   It generates predictions on the validation set using 4-view Test Time Augmentation (TTA).
    *   It computes and prints the **Final Validation Metric** (ROC AUC) with full precision.
    *   It performs failure analysis by calculating the correlation between the absolute prediction error and the image file size (the key metadata feature), printing the result to identify systematic biases.
