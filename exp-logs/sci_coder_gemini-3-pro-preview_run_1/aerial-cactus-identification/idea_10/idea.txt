Based on the comprehensive analysis of previous iterations and the extracted lessons, I propose a solution that structurally evolves the system from a single-architecture classifier to a **Heterogeneous Stacking Ensemble with Metadata Injection**. This approach directly addresses the "Data Quality" bottleneck identified in Lesson 00029 and leverages the diversity of multiple architectural paradigms to maximize AUC.

# Model
I propose a **Two-Stage Stacking Architecture**.

*   **Stage 1: Diverse Base Learners**
    Instead of relying on a single backbone, I will train three distinct architectures. This ensures the ensemble captures diverse feature representations (e.g., spatial vs. channel-wise, standard vs. inverted bottleneck).
    1.  **CactusResNet (The Baseline):** The proven custom ResNet with **Conservative Downsampling** (stride 1 stem, no early pooling) to preserve 32x32 resolution **(Cite solution_lesson_node_00001)**. It uses standard convolutions, Batch Normalization, and ReLU.
    2.  **CactusRepVGG (The Efficient):** The re-parameterizable architecture that uses multi-branch blocks (3x3 + 1x1 + Identity) during training for stability, fused into single layers for inference **(Cite solution_lesson_node_00017)**.
    3.  **CactusNeXt-3x3 (The Modern Evolution):** A structural evolution of the failed ConvNeXt attempt. It will retain the modern ConvNeXt block design (Depthwise Convolutions, Inverted Bottlenecks, Layer Normalization, GELU) but will strictly enforce **3x3 kernels** instead of 7x7. This adapts the modern architecture to the low-resolution constraint, preventing the signal loss caused by large kernels while providing feature diversity via its unique topology **(Cite solution_lesson_node_00016)**.

*   **Stage 2: Metadata-Aware Meta-Learner**
    The outputs of the base learners will be fed into a **Logistic Regression Meta-Learner**.
    *   **Structural Innovation (Metadata Injection):** Crucially, this meta-learner will take not only the class probabilities from the base models but also the **Image File Size** as an input feature. Lesson 00029 identified a strong correlation between error rates and file size (compression artifacts). By explicitly providing this signal, the meta-learner can learn to calibrate the ensemble's confidence based on the quality of the image, robustly handling the "hard" examples that pure pixel-based models struggle with **(Cite solution_lesson_node_00029)**.

# Data
*   **Preprocessing & Caching:** To eliminate I/O bottlenecks, the entire dataset (train and test) will be decoded and **cached in RAM** as floating-point tensors. File sizes will be extracted and normalized to be used as metadata features **(Cite solution_lesson_node_00020)**.
*   **Splitting:** I will employ **5-Fold Stratified Cross-Validation**. This generates Out-Of-Fold (OOF) predictions for the entire training set, which are necessary to train the Meta-Learner without leakage **(Cite solution_lesson_node_00029)**.
*   **Augmentation:**
    *   **Geometric:** **RandomHorizontalFlip** and **RandomVerticalFlip** will be applied, exploiting rotational invariance **(Cite solution_lesson_node_00002)**.
    *   **Regularization:** **Mild Mixup** ($\alpha=0.2$) will be applied to the base learners to close the generalization gap without drowning out the signal **(Cite solution_lesson_node_00004, solution_lesson_node_00006)**.

# Training
*   **Base Learner Training:** Each of the 3 architectures will be trained on the 5 folds (total 15 models).
    *   **Optimizer:** **AdamW** for effective weight decay.
    *   **Scheduler:** **Cosine Annealing** for **30 epochs**. This duration ensures proper convergence with Mixup **(Cite solution_lesson_node_00003)**.
    *   **Loss:** **Binary Cross-Entropy with Logits** to handle soft Mixup targets.
*   **Meta-Learner Training:** After training the base learners, their OOF predictions will be concatenated with the normalized file size metadata to form a new training matrix. The Logistic Regression meta-learner will be trained on this matrix to predict the ground truth labels, effectively learning how to weight each model's opinion given the image quality.

# Evaluation
*   **Inference Strategy:**
    1.  **TTA:** For every test image, each of the 15 base models (3 archs $\times$ 5 folds) will generate predictions using **4-view Test Time Augmentation** (original, horizontal flip, vertical flip, 180-degree rotation) **(Cite solution_lesson_node_00002)**.
    2.  **Fold Aggregation:** Predictions from the 5 folds of each architecture will be averaged, resulting in 3 distinct probability scores per image (one per architecture).
    3.  **Stacking:** These 3 scores, along with the image's file size, will be fed into the trained Meta-Learner to produce the final `has_cactus` probability. This hierarchical approach maximizes robustness against both model variance and data quality issues.
