The issue in the previous implementation is data leakage within the stacking meta-learner. The function `train_stacker` trained the logistic regression model on the full set of Out-Of-Fold (OOF) predictions and then evaluated it on the exact same dataset. This results in an invalid, overly optimistic validation metric because the model is being tested on data it has already seen. To fix this, I will modify `train_stacker` to perform an internal Stratified Cross-Validation loop. This allows us to generate unbiased predictions for the training set (where the model for each fold is trained only on the other folds) to calculate a valid ROC AUC score, while subsequently training a final model on the full dataset for inference on the test set.

def train_stacker(oof_preds_dict, file_sizes, y_true):
    """
    Trains the stacking meta-learner on Out-Of-Fold predictions.

    Args:
        oof_preds_dict (dict): Dictionary of OOF predictions per model.
        file_sizes (array-like): File sizes for the training set.
        y_true (array-like): Ground truth labels.

    Returns:
        tuple: (trained_learner, oof_auc_score)
    """
    seed_everything(Config.SEED)

    print("Preparing meta-features for stacking...")
    X = prepare_meta_features(oof_preds_dict, file_sizes)

    print(
        f"Feature matrix shape: {X.shape} (Samples: {X.shape[0]}, Features: {X.shape[1]})"
    )

    # --- Internal Cross-Validation for Valid Scoring ---
    print("Performing internal Cross-Validation for Stacker evaluation...")
    skf = StratifiedKFold(
        n_splits=Config.N_FOLDS, shuffle=True, random_state=Config.SEED
    )
    stacker_oof_preds = np.zeros(len(y_true))

    for train_idx, val_idx in skf.split(X, y_true):
        # Split data
        X_train, X_val = X[train_idx], X[val_idx]
        y_train = y_true[train_idx]

        # Train fold-specific learner
        fold_learner = MetaLearner()
        fold_learner.fit(X_train, y_train)

        # Predict on hold-out
        fold_preds = fold_learner.predict_proba(X_val)
        stacker_oof_preds[val_idx] = fold_preds

    # Calculate unbiased AUC
    score = calculate_roc_auc(y_true, stacker_oof_preds)
    print(f"Stacker CV ROC AUC: {score}")

    # --- Final Training ---
    print("Training final Logistic Regression Meta-Learner on full OOF set...")
    learner = MetaLearner()
    learner.fit(X, y_true)

    return learner, score
