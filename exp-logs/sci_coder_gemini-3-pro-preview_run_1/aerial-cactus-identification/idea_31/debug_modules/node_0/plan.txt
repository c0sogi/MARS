The following script demonstrates the end-to-end usage of the provided library files to train a RepVGG-based cactus classifier. It verifies the data loading pipeline, model architecture (including Deep Supervision and RepVGG re-parameterization), training loop with Mixup, and inference with Test Time Augmentation (TTA).

The script is optimized for speed by running only 2 epochs, which is sufficient to demonstrate convergence and functionality on the high-performance A100 GPU provided.
