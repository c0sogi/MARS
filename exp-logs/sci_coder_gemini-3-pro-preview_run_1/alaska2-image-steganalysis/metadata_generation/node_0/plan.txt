The following script generates the required metadata files. It first scans the `Cover` directory to retrieve all unique image IDs. To prevent data leakage, it splits these IDs into training and validation sets (80/20 split) before generating the file paths; this ensures that the Cover image and its corresponding Stego versions (JMiPOD, JUNIWARD, UERD) always reside in the same dataset. It then constructs the metadata DataFrames by expanding each ID into its four corresponding file paths and labels. Finally, it generates metadata for the test set, saves all files to the `./metadata` directory, and performs the required validation checks (file existence, split integrity, and statistics).
