To establish a highly efficient baseline for this steganography detection task, I propose the **Single-Stream High-Pass Filtered CNN (HPF-CNN)**. This approach prioritizes simplicity and training speed while addressing the fundamental challenge of steganalysis: suppressing image content to reveal the weak hidden signal.

### Model
The architecture is a streamlined Convolutional Neural Network designed to operate on noise residuals rather than raw pixel intensities.
*   **Preprocessing (The HPF Block):** The first layer is a **fixed, non-trainable High-Pass Filter (HPF)**. It uses a single $5 \times 5$ convolutional kernel (such as a standard residual filter like $K_{spam}$ or a Laplacian) to calculate the difference between a pixel and its neighbors. This operation subtracts the semantic "cover" content (edges, smooth areas) from the image, leaving behind a "noise map" where steganographic artifacts are most visible.
*   **Backbone:** The noise map is fed into an **EfficientNet-B0**. This backbone is chosen for its parameter efficiency and speed. It is initialized with ImageNet weights to leverage pre-learned feature extractors, which adapt quickly to texture features in the noise map.
*   **Head:** The network terminates with a Global Average Pooling layer followed by a single dense layer that outputs a scalar logit representing the likelihood of hidden data.

### Data
*   **Input Handling:** Images are loaded in RGB format. To maintain the integrity of the steganographic signal (which often relies on the $8 \times 8$ JPEG grid), images are **randomly cropped** to a fixed size (e.g., $512 \times 512$) during training rather than resized.
*   **Augmentation:** Augmentations are strictly limited to **Horizontal Flips, Vertical Flips, and 90-degree Rotations**. These transformations preserve the pixel grid alignment and the statistical properties of the noise, whereas interpolation-based methods (scaling, shearing) would destroy the hidden signal.
*   **Labeling:** The problem is treated as a binary classification task. The three steganography classes (JMiPOD, JUNIWARD, UERD) are mapped to a single positive label (`1`), and the Cover images are mapped to the negative label (`0`).

### Training
*   **Loss Function:** **Binary Cross-Entropy (BCE) with Logits** is used to optimize the classification objective.
*   **Optimizer:** The **AdamW** optimizer is employed for its ability to handle weight decay effectively, helping to prevent the model from memorizing unique artifacts of specific cover images.
*   **Strategy:** Training uses a **One-Cycle Learning Rate Policy**. This allows for a rapid warm-up to a high learning rate followed by a decay, ensuring fast convergence within a few epochs (e.g., 3–5 epochs), fitting the tight runtime constraint.

### Evaluation
*   **Inference:** Test images are processed using the same pipeline (loading and HPF extraction). If test images vary in size, they can be passed through the fully convolutional architecture directly, or center-cropped if batching is required.
*   **Scoring:** The raw output logits are converted to probabilities using a Sigmoid function. These scores are directly used for the submission, as they correlate with the confidence required for the Weighted AUC metric.
