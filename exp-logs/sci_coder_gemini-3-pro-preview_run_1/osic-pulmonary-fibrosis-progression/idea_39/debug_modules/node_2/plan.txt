The previous implementation failed with a `RuntimeError: Unknown model (efficientnet-b0)` because the `timm` library uses underscores rather than hyphens for its model registry keys. Specifically, the configuration defined `BACKBONE_NAME = "efficientnet-b0"`, but the correct identifier expected by `timm.create_model` is `"efficientnet_b0"`.

To fix this, I will update the `BACKBONE_NAME` variable in `library/config.py` to use the correct underscore-based naming convention (Cite debug_lesson_8).
