The following script demonstrates the end-to-end usage of the provided library files for the lung function decline prediction task.

It performs the following steps:
1.  **DICOM Processing**: Verifies that raw DICOM files can be converted into orthogonal Tri-Slab MIP images using `library.dicom_processing`.
2.  **Data Loading**: Instantiates the `LungDataset` and `DataLoaders` from `library.data` to verify data shapes and feature engineering.
3.  **Model Inference**: Initializes the `ModalityAwareDualAxisNet` from `library.model` and performs a forward pass to check output shapes and value validity.
4.  **Loss Calculation**: Computes the custom Laplace Log Likelihood loss using `library.loss` and validates it against a manual calculation.
5.  **Training Loop**: Executes a fast 1-epoch training run using `library.train.train_model` to verify the optimization loop, checkpointing, and inference pipeline.
6.  **Submission Verification**: Checks the generated submission file for correct formatting and dimensions.
