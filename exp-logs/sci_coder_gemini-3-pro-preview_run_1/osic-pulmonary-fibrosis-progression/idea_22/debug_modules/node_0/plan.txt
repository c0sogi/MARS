This script demonstrates the usage of the provided library files (`config.py`, `utils.py`, `data.py`, `model.py`, `train.py`, `predict.py`). It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory and reduces batch size/epochs for rapid execution.
2.  **Data Subsetting**: Creates small subsets of the training, validation, and test metadata to ensure the data loading and processing steps complete quickly (processing only a few patients).
3.  **Metric Verification**: Validates the `get_score` function against a manually calculated value to ensure metric correctness.
4.  **Data Pipeline Verification**: Uses `prepare_data` to load the subsetted data, verifying the `LungDataset` outputs correct tensor shapes and metadata.
5.  **Model Architecture Verification**: Instantiates the `CASDAN` model, performs a forward pass with dummy data, and asserts the output shapes (alpha, sigma_base, sigma_growth) and loss calculation.
6.  **Training Loop Demonstration**: Runs a single training epoch and a validation step using the `train_epoch` and `validate` functions to demonstrate the training pipeline.
7.  **Inference Demonstration**: Simulates the inference process by running the model on the test subset and generating a submission file, verifying the output format.
