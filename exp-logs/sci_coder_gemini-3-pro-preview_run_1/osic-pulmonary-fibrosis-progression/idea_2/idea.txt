### **Model: Tri-Slab Depth-Encoded Network with Dynamic Uncertainty**

**Architecture Design**
This solution evolves the previous "MIP-Based Linear Decay" approach by addressing two key limitations: the loss of depth information in a single 2D projection and the static modeling of uncertainty.

1.  **Visual Backbone (Pseudo-3D Input):** Instead of a single grayscale MIP, the model utilizes a **Tri-Slab** representation. The CT volume is split along the Z-axis (depth) into three equal sections (Upper, Middle, Lower lung). A Maximum Intensity Projection (MIP) is computed for each section. These three projections are stacked as channels (R, G, B) to form a single color image. This allows a standard 2D **EfficientNet-B0** backbone to process the data while retaining critical spatial information about the vertical distribution of fibrosis (which often progresses from the lung base upwards), effectively preserving the benefits of dimensionality reduction Cite solution_lesson_node_00003.
2.  **Tabular Branch:** A Multi-Layer Perceptron (MLP) processes the baseline metadata (Age, Sex, SmokingStatus) and `Baseline_Percent`.
3.  **Parametric Head with Time-Dependent Uncertainty:** The features from the visual and tabular branches are concatenated. The head predicts three scalar values (parameters) per patient, rather than point estimates for every week Cite solution_lesson_node_00004:
    *   $\alpha$ (Slope): The rate of FVC decline.
    *   $\sigma_{base}$ (Base Confidence): The uncertainty at time $t=0$.
    *   $\sigma_{growth}$ (Uncertainty Growth Rate): A coefficient modeling how confidence degrades over time.

**Inference Logic**
The prediction for any given week $t$ is calculated analytically:
*   **FVC:** $\text{FVC}_{pred}(t) = \text{Baseline\_FVC} + \alpha \times t$
*   **Confidence:** $\text{Confidence}(t) = \sigma_{base} + \sigma_{growth} \times |t|$

This dynamic confidence term specifically addresses the finding that prediction error correlates with time, preventing the metric from penalizing the model excessively for long-term extrapolations.

### **Data: Preprocessing and Preparation**

**Training & Evaluation Data**
1.  **Tri-Slab Generation:** For each patient's CT scan:
    *   Sort files by slice location.
    *   Divide the stack into three equal contiguous chunks (Top, Middle, Bottom).
    *   Compute the MIP for each chunk.
    *   Normalize pixel values (Hounsfield Units -1000 to 400 mapped to 0-1).
    *   Merge the three MIPs into a 3-channel (RGB) image ($224 \times 224 \times 3$).
2.  **Augmentation Strategy:** Apply **only** geometric augmentations (e.g., Horizontal Flip, slight Shift/Scale/Rotate). Strictly avoid intensity-based augmentations (like RandomBrightnessContrast) to preserve the physical density signal of the CT Hounsfield Units Cite solution_lesson_node_00005.
3.  **Tabular Normalization:** Standardize numerical inputs and one-hot encode categorical inputs.

### **Training: Procedure and Strategy**

*   **Loss Function:** Train directly on the competition's **Modified Laplace Log Likelihood** metric. The loss is computed using the dynamic inference logic:
    $$ \text{Loss} = \text{Metric}(\text{True\_FVC}, \text{Baseline\_FVC} + \alpha t, \sigma_{base} + \sigma_{growth}|t|) $$
*   **Optimization:** Use the AdamW optimizer with a Cosine Annealing scheduler. The EfficientNet backbone should be initialized with ImageNet weights to leverage transfer learning on the 3-channel input Cite solution_lesson_node_00003.
*   **Sampling:** Treat every `(Patient, Week)` pair in the training history as a sample, utilizing the patient's static baseline CT and metadata as input, but varying the target `FVC` and time delta $t$.

### **Evaluation: Prediction Generation**

1.  **Inference:** For each test patient, generate the Tri-Slab MIP image and pass it through the model to obtain $\alpha$, $\sigma_{base}$, and $\sigma_{growth}$.
2.  **Extrapolation:** For every requested `Patient_Week` in the submission file:
    *   Calculate the relative week $t$.
    *   Compute the predicted FVC and Confidence using the parametric formulas defined above.
    *   Clip the Confidence at 70 (as per metric definition) if the raw prediction is lower, though the model should naturally learn this lower bound.
