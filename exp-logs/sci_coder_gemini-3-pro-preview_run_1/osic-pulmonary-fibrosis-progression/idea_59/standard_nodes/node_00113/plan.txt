Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `seed_everything` for reproducibility and detect the computation device (GPU/CPU).
2.  **Training**: Execute the training pipeline using `library.train.run_training`. To ensure a fast baseline execution as requested, we will limit the training to 10 epochs. This is sufficient for the small dataset size (~1100 samples) to demonstrate convergence without exceeding time limits.
3.  **Validation & Metric Calculation**:
    *   Load the best saved model state.
    *   Iterate through the validation `DataLoader` to generate predictions (`FVC`, `Confidence`) and collect ground truth targets.
    *   Compute the specific Modified Laplace Log Likelihood metric on the full validation set.
    *   Print the metric in the exact required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the absolute error between predicted and true FVC.
    *   Extract input features (Age, Percent, Base FVC) from the validation batches.
    *   Calculate and print the Pearson correlation between the absolute error and these features to identify potential sources of bias or failure.
5.  **Submission Logic**:
    *   Compare the calculated validation metric against the threshold (`-6.510164260864258`).
    *   If the model performance is superior (higher metric), call `library.predict.generate_submission` to create the `submission.csv` file using the test set.
