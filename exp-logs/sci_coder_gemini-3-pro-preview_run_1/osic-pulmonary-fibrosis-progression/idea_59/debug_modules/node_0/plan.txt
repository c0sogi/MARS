4.  **Training Loop Execution**: We utilize the `run_training` function from `library.train` to execute a minimal training session (1 epoch, small batch size) to ensure the training pipeline, loss calculation, and checkpoint saving mechanisms function correctly without errors.
5.  **Inference and Submission**: We use the `generate_submission` function from `library.predict` to generate predictions on the test set using the model trained in the previous step. We verify the output CSV file's structure and content.
