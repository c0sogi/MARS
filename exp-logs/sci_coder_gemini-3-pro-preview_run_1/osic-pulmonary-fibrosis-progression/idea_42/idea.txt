Based on the comprehensive analysis of the accumulated lessons, specifically the trade-off between **Model Capacity** (Lesson 79) and **Feature Fidelity** (Lesson 39, 78), I propose the **Capacity-Regulated Holistic Dual-Axis Network (CR-HDAN)**.

This solution represents a structural synthesis that corrects the "Capacity-Driven Instability" observed in the previous high-fidelity attempt (Idea 40/41). It strictly adheres to the **Low-Capacity Regime** required for this small dataset while enforcing the **Holistic Readout** strategy to preserve the contextualized clinical priors, resolving the bottleneck of "Visual-Exclusive" approaches.

### 1. Model: Capacity-Regulated Holistic Dual-Axis Network (CR-HDAN)

**Architecture Design**
1.  **Independent Low-Capacity Visual Backbones:**
    *   We revert to **EfficientNet-B0** (initialized with ImageNet weights) instead of B1.
    *   **Dual-Axis:** Two independent backbones process the **Axial** and **Coronal** views separately (Cite solution_lesson_node_00010, solution_lesson_node_00014).
    *   **High-Fidelity Extraction:** We apply **Global Average Pooling (GAP)** to the output feature maps. **Crucially**, we maintain the **native backbone dimensionality** (1280-dim) and do **not** project these down. This adheres to the lesson that compressing visual features destroys critical texture signals (Cite solution_lesson_node_00039), but by using B0, we keep the parameter count within the stable regime (Cite solution_lesson_node_00079). Explicit modality embeddings are omitted (Cite solution_lesson_node_00056).

2.  **Shallow Non-Linear Tabular Alignment:**
    *   To address the failure of linear projections (Cite solution_lesson_node_00070) without triggering the instability of "Deep" MLPs (Cite solution_lesson_node_00079), we employ a **Shallow Alignment MLP**.
    *   **Structure:** The raw metadata (Age, Sex, Smoking, **Percent** - Cite solution_lesson_node_00017) is projected to 1280-dim via a compact 2-layer network: `Linear(Input -> 1280) -> LayerNorm -> GeLU -> Linear(1280 -> 1280)`.
    *   *Rationale:* This provides the necessary non-linearity to map scalars to the semantic visual space without the parameter explosion of deep networks or granular tokenization (Cite solution_lesson_node_00043).

3.  **Pre-Norm Symmetric Attention (Contextualization Phase):**
    *   **Tokenization:** We stack the vectors into a sequence: $[V_{ax}, V_{cor}, V_{tab}]$.
    *   **Fusion:** A single **Multi-Head Self-Attention** layer processes this sequence. We employ **Pre-Normalization** (LayerNorm before Attention) for stability (Cite solution_lesson_node_00008). We retain the Feed-Forward Network (FFN) but apply high dropout (0.5) to balance capacity (Cite solution_lesson_node_00070).
    *   **Mechanism:** This allows the visual tokens to be "contextualized" by the tabular token via Symmetric Self-Attention (Cite solution_lesson_node_00028).

4.  **Holistic Pooled Readout (Structural Correction):**
    *   **Correction:** We apply **Global Average Pooling** across **ALL** updated tokens ($V'_{ax}, V'_{cor}, V'_{tab}$) to derive the fused context vector.
    *   *Rationale:* Unlike "Visual-Exclusive" strategies that discarded the tabular token (causing information loss - Cite solution_lesson_node_00078), this approach preserves the *contextualized* clinical signal (how the metadata was modified by the image). Pooling prevents the overfitting associated with flattening (Cite solution_lesson_node_00047).

5.  **Prior-Anchored Parametric Head:**
    *   We concatenate the Holistic Fused Vector with the **Raw Tabular Features** (original scalars) via a skip connection. This guarantees the regression head has direct, uncorrupted access to the strong scalar priors (Baseline FVC, Percent) (Cite solution_lesson_node_00018).
    *   **Constraint:** The head predicts $\alpha$ (Slope), $\sigma_{base}$, and $\sigma_{growth}$. **Crucially**, we do **not** include `Week` or `Time` as inputs. The parameters are derived solely from static baseline characteristics (Cite solution_lesson_node_00062).
    *   **Activation:** We apply **Softplus** activation to the $\sigma$ outputs (Cite solution_lesson_node_00021).

### 2. Data: Fixed Overlapping Orthogonal Tri-Slabs

**Preprocessing**
1.  **Dual-View Generation:** For each patient, generate two inputs to capture 3D spatial heterogeneity (Cite solution_lesson_node_00010).
    *   **Axial Tri-Slab (RGB):** Split the CT volume along the Z-axis (Depth) into three slabs with **fixed boundaries** (0-33%, 33-66%, 66-100%) and **15% overlap**. Compute MIPs and map to RGB (Cite solution_lesson_node_00006). We strictly avoid stochastic jitter (Cite solution_lesson_node_00035).
    *   **Coronal Tri-Slab (RGB):** Split along the Y-axis (Anterior-Posterior) into three overlapping slabs, compute MIPs, and map to RGB.
2.  **Resolution:** Resize all images to **224x224**. This matches the **native resolution of EfficientNet-B0**, strictly avoiding the overfitting caused by resolution mismatch (Cite solution_lesson_node_00009).

**Augmentation**
1.  **Spatial Only:** Apply random horizontal flips, shifts, and slight rotations (Cite solution_lesson_node_00007).
2.  **No Intensity Changes:** Strictly **disable** brightness/contrast augmentations (Cite solution_lesson_node_00005).

### 3. Training: Robust Metric Optimization

**Procedure**
*   **Loss Function:** Modified Laplace Log Likelihood. We explicitly **retain the error clipping** (thresholding absolute error at 1000 ml) to filter outliers (Cite solution_lesson_node_00013). No auxiliary losses (Cite solution_lesson_node_00016).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.
*   **Strategy:** Use a strict patience (e.g., 6-8 epochs) for **Early Stopping**. We avoid Stochastic Weight Averaging (SWA) as it degrades performance on this small dataset (Cite solution_lesson_node_00030).

### 4. Evaluation: Parametric Inference

For every `Patient_Week` in the test set:
1.  Generate the Fixed Overlapping Axial and Coronal Tri-Slab images (224x224).
2.  Pass inputs and baseline metadata through the **CR-HDAN** to obtain static parameters $\alpha, \sigma_{base}, \sigma_{growth}$.
3.  Calculate predictions using the anchored trajectory logic (Cite solution_lesson_node_00045):
    *   $$ \text{FVC} = \text{Baseline\_FVC} + \alpha \times (\text{Week} - \text{Baseline\_Week}) $$
    *   $$ \text{Confidence} = \sigma_{base} + \sigma_{growth} \times |\text{Week} - \text{Baseline\_Week}| $$
4.  Clip the Confidence at 70 ml as required by the metric.
