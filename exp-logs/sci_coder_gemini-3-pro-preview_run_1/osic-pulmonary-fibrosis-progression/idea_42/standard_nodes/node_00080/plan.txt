This solution implements the **Capacity-Regulated Holistic Dual-Axis Network (CR-HDAN)** pipeline. It orchestrates the training of the model using the provided library, evaluates it on the hold-out validation set, performs failure analysis to identify error sources, and generates a submission file if the performance threshold is met.

The script overrides the default configuration to ensure a fast execution (15 epochs) while maintaining sufficient training duration to converge on the small dataset. It leverages the GPU for accelerated inference and strictly adheres to the provided file interfaces.
