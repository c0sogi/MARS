3.  **Model Training**: We instantiate the `SLHDAN` model, which uses dual EfficientNet-B0 backbones and a shared latent tabular encoder. The training loop uses the Modified Laplace Log Likelihood loss (`loss_fn`) and saves the model with the best validation score.
4.  **Validation & Failure Analysis**: After training, we reload the best model and perform inference on the validation set. We calculate the exact competition metric. We then perform failure analysis by computing the correlation between the absolute prediction error and key clinical features (Age, Percent, Weeks) to identify systematic biases.
5.  **Submission**: If the final validation metric exceeds the specified threshold (-6.510164260864258), we generate the submission file for the test set using the parametric inference logic (predicting slope and sigmas to construct the trajectory).
