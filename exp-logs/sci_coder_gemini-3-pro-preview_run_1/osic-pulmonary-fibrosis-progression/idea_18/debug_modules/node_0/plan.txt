The following script demonstrates the end-to-end usage of the provided library components for the Lung Function Decline Prediction task. It covers:
1.  **Configuration & Reproducibility**: Setting up the environment and overriding settings for a fast demonstration.
2.  **Data Pipeline**: Instantiating the `LungDataset`, generating cached images, and verifying batch structure.
3.  **Model Architecture**: Initializing the `CalibratedSymmetricDualAxisNetwork` and verifying forward pass dimensions.
4.  **Loss & Metric**: Validating the custom `LaplaceLoss` and the competition metric calculation with known values.
5.  **Training Loop**: Running a single training epoch to ensure gradient propagation.
6.  **Inference**: Generating predictions using the test-mode dataset structure.
