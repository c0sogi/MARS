Here is the implementation strategy and the `runfile.py` script.

### Implementation Strategy
1.  **Setup & Configuration**: Initialize the environment with a fixed random seed for reproducibility. Override the default epoch count in the `Config` class to 25 to ensure the "fast baseline" requirement is met while allowing sufficient convergence.
2.  **Data Loading**: Instantiate `LungDataset` and `DataLoader` for training, validation, and testing using the provided library classes. Enable caching (`load_cached=True`) to speed up data retrieval.
3.  **Model Initialization**: Initialize the `DAVRNet` model and move it to the detected device (GPU/CPU). Set up the AdamW optimizer and Cosine Annealing scheduler.
4.  **Training Loop**: Execute the training process using `engine.fit`. This handles the training epochs, validation at each step, and saves the best model based on the metric.
5.  **Evaluation**: Load the best saved model state. Compute the final validation metric using `engine.evaluate` and print it with full precision as required.
6.  **Failure Analysis**: Perform a separate inference pass on the validation set to calculate absolute prediction errors for each sample. Compute and print the Pearson correlation between these errors and key input features (Age, Percent, Relative Week, Baseline FVC) to identify systematic failure modes.
7.  **Submission**: Compare the final validation metric against the threshold (-6.510164260864258). If the model performs better (higher score), generate predictions for the test set using `engine.predict` and save the `submission.csv`.
