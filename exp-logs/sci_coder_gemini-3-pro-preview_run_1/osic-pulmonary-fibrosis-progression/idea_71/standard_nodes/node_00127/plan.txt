The following script orchestrates the pipeline for the Lung Function Decline prediction task. It performs the following steps:
1.  **Configuration & Setup**: Sets random seeds for reproducibility and initializes the device.
2.  **Training**: Executes the training loop for the DBSL-Net model using `library.train.run_training`. We limit the epochs to 25 to ensure the process completes quickly within the time constraints while allowing sufficient convergence on this small dataset.
3.  **Validation**: Loads the best checkpoint saved during training and performs inference on the hold-out validation set.
4.  **Metric Calculation**: Computes the modified Laplace Log Likelihood on the validation set and prints it in the required format.
5.  **Failure Analysis**: Calculates the absolute prediction error for each validation sample and computes the Pearson correlation coefficient between this error and the input features (Age, Percent, Sex, Smoking, Confidence). This helps identify systematic weaknesses.
6.  **Submission**: Checks if the validation metric exceeds the specified threshold (-6.510164260864258). If successful, it generates the submission file for the test set using `library.predict.run_prediction`.
