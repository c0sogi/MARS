The implementation strategy is as follows:

1.  **Setup and Directory Creation**: Define input and output directories. Create the `./metadata` directory if it doesn't exist.
2.  **Load Raw Data**: Read `train.csv`, `test.csv`, and `sample_submission.csv` using pandas.
3.  **Process Training Data**:
    *   Construct the relative file path for the DICOM directories (`train/{Patient}`) and add it as a column.
    *   Perform a Group Shuffle Split on the training data to create a validation set. This ensures that all records for a single patient remain in either the training or validation set (preventing data leakage) while maintaining an 80:20 split.
    *   Save the resulting dataframes to `metadata/train.csv` and `metadata/val.csv`.
4.  **Process Test Data**:
    *   Use `sample_submission.csv` as the base since it defines the required prediction targets (`Patient_Week`).
    *   Parse the `Patient` ID and target `Week` from the `Patient_Week` column.
    *   Merge patient metadata (Age, Sex, SmokingStatus, Baseline FVC, etc.) from `test.csv` into the submission dataframe.
    *   Construct the relative file path for the test DICOM directories (`test/{Patient}`).
    *   Save the enriched dataframe to `metadata/test.csv`.
5.  **Verification and Statistics**:
    *   Print summary statistics (shape, unique patients, label distribution) for all generated datasets.
    *   Perform a file path existence check on a random sample of 1000 paths from each dataset to ensure the `dicom_dir` column points to valid directories in `./input`.
    *   Verify the training/validation split to ensure no patient overlap and that the split ratio is approximately correct. Raise assertions if these checks fail.
