Implementation strategy:
1.  **Configuration & Setup**: Import necessary modules and the provided library components (`Config`, `Runner`, `NSLHN`, etc.). Modify `Config` parameters (Epochs, Patience) to ensure the training completes quickly within the time limit while maintaining reasonable performance.
2.  **Training**: Initialize the `Runner` class and execute the training pipeline. This handles data loading, model initialization, and the training loop with early stopping.
3.  **Validation & Analysis**:
    *   Load the best model checkpoint saved during training.
    *   Perform inference on the validation set to compute the `Final Validation Metric` using the provided `laplace_log_likelihood_metric`.
    *   Conduct failure analysis by calculating the absolute error for each validation sample and computing correlations with input features (Weeks, Percent, Age, etc.) to identify error sources.
4.  **Submission**:
    *   Check if the validation metric exceeds the specified threshold.
    *   If successful, regenerate the data loaders to retrieve the `test_loader`.
    *   Run inference on the test set using the trained model.
    *   Format the predictions into the required CSV format (`Patient_Week`, `FVC`, `Confidence`) and save it to the submission directory.
