This script demonstrates the end-to-end usage of the provided library components to solve the lung function decline prediction task. It performs the following steps:

1.  **Configuration**: overrides default `Config` parameters (enabling `DEBUG` mode, reducing epochs and batch size) to ensure the script runs quickly within the time limit.
2.  **Data Loading**: uses `get_dataloaders` to process the metadata, cache the DICOM images (converting them to 3-channel slabs), and create PyTorch DataLoaders. It verifies the structure and shapes of the data batches.
3.  **Model Initialization**: instantiates the `NBCSLN` model and performs a dummy forward pass to validate the architecture and output dimensions.
4.  **Training & Evaluation**: runs a single epoch of training using `train_fn` and a validation pass using `eval_fn`, asserting that the loss and metrics are valid (non-NaN).
5.  **Inference**: generates predictions on the test set using `inference_fn`, validates the output format, and saves the submission file.
