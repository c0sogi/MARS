Based on the comprehensive analysis of the accumulated lessons and the identification of the specific readout bottleneck that hindered the previous "High-Fidelity" attempt (Lesson 78), I propose the **Holistic High-Fidelity Dual-Axis Network (H2-DAN)**.

This solution represents a structural synthesis that corrects the "Visual-Exclusive" error. It strictly enforces the preservation of the **Contextualized Clinical Prior** within the fusion layer, ensuring that the non-linear interactions learned by the attention mechanism are not discarded. It combines this with **Deep Tabular Alignment**, **Independent High-Fidelity Backbones**, and **Parametric Constraints** to maximize performance on the small dataset.

### 1. Model: Holistic High-Fidelity Dual-Axis Network (H2-DAN)

**Architecture Design**
1.  **Independent Scaled Visual Backbones:**
    *   We upgrade the backbones to **EfficientNet-B1** (initialized with ImageNet weights) to capture finer textural details of fibrosis.
    *   **Dual-Axis:** Two independent backbones process the **Axial** and **Coronal** views separately (Cite solution_lesson_node_00010, solution_lesson_node_00014).
    *   **High-Fidelity Extraction:** We apply **Global Average Pooling (GAP)** to the output feature maps. **Crucially**, we maintain the **native backbone dimensionality** (1280-dim) and do **not** project these down. This strictly adheres to the lesson that compressing visual features destroys critical texture signals in small datasets (Cite solution_lesson_node_00039). Explicit modality embeddings are omitted as independent backbones render them redundant (Cite solution_lesson_node_00056).

2.  **Deep Tabular Alignment:**
    *   To address the failure of linear projections (Cite solution_lesson_node_00070) while avoiding the overfitting of granular tokenization (Cite solution_lesson_node_00043), we employ a **Deep Multi-Layer Perceptron (MLP)** for tabular embedding.
    *   **Structure:** The raw metadata (Age, Sex, Smoking, **Percent** - Cite solution_lesson_node_00017) is projected to 1280-dim via a 3-layer network with non-linear activations (`Linear -> GeLU -> Linear -> GeLU -> Linear`).
    *   *Rationale:* This ensures the low-dimensional clinical prior is transformed into a rich, non-linear semantic manifold *before* entering the fusion block, enabling effective interaction with the deep visual features.

3.  **Pre-Norm Symmetric Attention (Contextualization Phase):**
    *   **Tokenization:** We stack the vectors into a sequence: $[V_{ax}, V_{cor}, V_{tab}]$.
    *   **Fusion:** A single **Multi-Head Self-Attention** layer processes this sequence. We employ **Pre-Normalization** (LayerNorm before Attention) for stability (Cite solution_lesson_node_00008). We **retain the Feed-Forward Network (FFN)** within the block (with high dropout) to provide necessary non-linear capacity (Cite solution_lesson_node_00070).
    *   **Mechanism:** This allows the visual tokens to be "contextualized" by the tabular token and vice-versa via Symmetric Self-Attention (Cite solution_lesson_node_00028).

4.  **Holistic Pooled Readout (Structural Correction):**
    *   **Correction:** Unlike the previous iteration which discarded the tabular token (Lesson 78), we apply **Global Average Pooling** across **ALL** updated tokens ($V'_{ax}, V'_{cor}, V'_{tab}$) to derive the fused context vector.
    *   *Rationale:* The contextualized tabular token contains unique information ("How the clinical state is modified by the visual evidence"). Including it ensures the model captures the full bidirectional interaction learned by the attention layer (Cite solution_lesson_node_00078), while pooling prevents the overfitting associated with flattening (Cite solution_lesson_node_00047).

5.  **Prior-Anchored Parametric Head:**
    *   We concatenate the Holistic Fused Vector with the **Raw Tabular Features** (original scalars) via a skip connection. This guarantees the regression head has direct, uncorrupted access to the strong scalar priors (Baseline FVC, Percent) (Cite solution_lesson_node_00018).
    *   **Constraint:** The head predicts $\alpha$ (Slope), $\sigma_{base}$, and $\sigma_{growth}$. **Crucially**, we do **not** include `Week` or `Time` as inputs. The parameters are derived solely from static baseline characteristics (Cite solution_lesson_node_00062).
    *   **Activation:** We apply **Softplus** activation to the $\sigma$ outputs (Cite solution_lesson_node_00021).

### 2. Data: Fixed Overlapping Orthogonal Tri-Slabs

**Preprocessing**
1.  **Dual-View Generation:** For each patient, generate two inputs to capture 3D spatial heterogeneity (Cite solution_lesson_node_00010).
    *   **Axial Tri-Slab (RGB):** Split the CT volume along the Z-axis (Depth) into three slabs with **fixed boundaries** (0-33%, 33-66%, 66-100%) and **15% overlap**. Compute MIPs and map to RGB (Cite solution_lesson_node_00006). We strictly avoid stochastic jitter to preserve semantic spatial consistency (Cite solution_lesson_node_00035).
    *   **Coronal Tri-Slab (RGB):** Split along the Y-axis (Anterior-Posterior) into three overlapping slabs, compute MIPs, and map to RGB.
2.  **Resolution:** Resize all images to **240x240**. This matches the **native resolution of EfficientNet-B1**, strictly avoiding the overfitting caused by resolution mismatch (Cite solution_lesson_node_00009).

**Augmentation**
1.  **Spatial Only:** Apply random horizontal flips, shifts, and slight rotations (Cite solution_lesson_node_00007).
2.  **No Intensity Changes:** Strictly **disable** brightness/contrast augmentations to preserve the physical Hounsfield Unit density signal (Cite solution_lesson_node_00005).

### 3. Training: Robust Metric Optimization

**Procedure**
*   **Loss Function:** Modified Laplace Log Likelihood. We explicitly **retain the error clipping** (thresholding absolute error at 1000 ml) to filter outliers (Cite solution_lesson_node_00013). No auxiliary losses (Cite solution_lesson_node_00016).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.
*   **Strategy:** Use a strict patience (e.g., 6-8 epochs) for **Early Stopping**. We avoid Stochastic Weight Averaging (SWA) as it degrades performance on this small dataset (Cite solution_lesson_node_00030).

### 4. Evaluation: Parametric Inference

For every `Patient_Week` in the test set:
1.  Generate the Fixed Overlapping Axial and Coronal Tri-Slab images (240x240).
2.  Pass inputs and baseline metadata through the **H2-DAN** to obtain static parameters $\alpha, \sigma_{base}, \sigma_{growth}$.
3.  Calculate predictions using the anchored trajectory logic (Cite solution_lesson_node_00045):
    *   $$ \text{FVC} = \text{Baseline\_FVC} + \alpha \times (\text{Week} - \text{Baseline\_Week}) $$
    *   $$ \text{Confidence} = \sigma_{base} + \sigma_{growth} \times |\text{Week} - \text{Baseline\_Week}| $$
4.  Clip the Confidence at 70 ml as required by the metric.
