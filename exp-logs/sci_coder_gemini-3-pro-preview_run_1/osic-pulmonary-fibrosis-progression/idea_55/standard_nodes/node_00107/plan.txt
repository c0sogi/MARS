    *   Run a dedicated inference pass on the validation set to collect ground truth, predictions, and metadata.
    *   Calculate the **Final Validation Metric** using the provided formula and print it with full precision.
    *   Calculate the absolute error for each validation sample.
    *   Compute Pearson correlations between the absolute error and key features (Age, Percent, Weeks, Baseline FVC) to identify sources of error. Print these correlations.

5.  **Submission Generation**:
