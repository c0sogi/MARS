This script demonstrates the end-to-end usage of the provided machine learning pipeline for lung function decline prediction.

**Implementation Strategy:**
1.  **Configuration & Setup**: We first import the necessary modules and monkey-patch the `Config` class to adapt it for a rapid demonstration (reducing epochs, batch size, and dataset size). We also ensure reproducibility using `seed_everything`.
2.  **Data Loading & Verification**: We utilize `get_dataloaders` with the debug flag enabled. We explicitly verify the structure and shapes of the batches produced by the `DataLoader` to ensure the `CTPreprocessor` and `LungDataset` are functioning correctly.
3.  **Model Instantiation & Forward Pass**: We instantiate the `CG_SDAN` model and perform a forward pass with a single batch. We verify that the outputs (`alpha`, `sigma_base`, `sigma_growth`) have the expected dimensions and gradient tracking enabled.
4.  **Loss Calculation**: We compute the loss using the custom `criterion` function and verify that backpropagation can be initiated.
5.  **Full Training Loop**: We execute `run_training` (which uses `train_one_epoch` and `validate`) to simulate a complete training cycle on the reduced dataset. We verify that a model checkpoint is saved.
6.  **Inference**: We use the trained model to generate predictions on the test set via the `predict` function and verify the format and constraints of the resulting submission file.
