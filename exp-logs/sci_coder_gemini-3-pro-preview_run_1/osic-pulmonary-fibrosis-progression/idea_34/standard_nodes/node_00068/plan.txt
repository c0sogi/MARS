This script implements the full pipeline for the Anchored Symmetric-Attention Dual-Axis Network (ASA-DAN).

**Implementation Strategy:**
1.  **Configuration:** I import the `Config` class and override `EPOCHS` (set to 25) and `PATIENCE` (set to 6) to ensure the training completes quickly within the "fast baseline" constraints while still allowing convergence on the small dataset.
2.  **Training:** I utilize the provided `run_training()` function from `library.train`. This handles the training loop, validation monitoring, and saves the best model checkpoint to disk.
3.  **Validation Inference:** After training, I load the best model checkpoint and run inference on the validation set in `eval` mode with `torch.no_grad()`. I collect predictions, ground truth, and metadata features.
4.  **Metric & Failure Analysis:**
    *   I compute the modified Laplace Log Likelihood using the `score` function and print it as `Final Validation Metric: <value>`.
    *   I calculate the absolute prediction errors and compute their correlation with input features (Age, Sex, Smoking, Percent, Baseline FVC, Week) to identify failure modes.
5.  **Submission:** If the validation metric exceeds the specified threshold (-6.510164260864258), I generate predictions for the test set, format them according to the sample submission, and save the file to `./submission/submission.csv`.
