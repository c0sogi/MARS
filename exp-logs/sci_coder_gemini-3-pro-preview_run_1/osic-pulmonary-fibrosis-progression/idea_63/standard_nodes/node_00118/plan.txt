Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and `seed_everything()` to ensure reproducibility. Define the computation device (GPU).
2.  **Data Loading**: Utilize `get_dataloaders()` from the library to retrieve the training, validation, and submission data loaders.
3.  **Model Initialization**: Instantiate the `BBSLNet` model and move it to the GPU. Set up the AdamW optimizer and Cosine Annealing scheduler as specified in the configuration.
4.  **Training Loop**: Implement a training loop for `Config.epochs`. Inside the loop:
    *   Execute `train_fn` to update weights.
    *   Execute `eval_fn` to compute validation loss.
    *   Implement Early Stopping: Monitor validation loss, save the best model state to `best_model.pth`, and stop if patience is exceeded.
5.  **Final Evaluation**: Load the best saved model. Re-run inference on the validation set to calculate the precise `Final Validation Metric` (Laplace Log Likelihood) and print it with full precision.
6.  **Failure Analysis**:
    *   Extract predictions and targets from the validation set.
    *   Compute the absolute error for each sample.
    *   Calculate Spearman correlations between the error magnitude and input features (Age, Percent, Baseline FVC, etc.) to identify sources of model weakness.
7.  **Submission Generation**:
    *   Compare the final validation metric against the threshold (`-6.510164260864258`).
    *   If the model performs better (higher score), execute `inference_fn` on the submission loader to generate predictions.
    *   Save the results to `./submission/submission.csv`.
