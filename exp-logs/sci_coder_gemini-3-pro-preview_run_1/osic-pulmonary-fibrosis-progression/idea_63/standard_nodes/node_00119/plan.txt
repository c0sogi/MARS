The issue stems from the presence of DICOM files compressed with codecs (like JPEG Lossless) that are missing in the current environment, causing `pydicom` to raise a `RuntimeError` when accessing `pixel_array`. Additionally, when `load_scan` fails (returning `None`), the fallback black image is not cached, causing the system to repeatedly attempt the expensive and failing load operation in subsequent epochs (Cite debug_lesson_8).

To fix this:
1.  I will modify `load_scan` in `library/data.py` to iterate through slices and access `pixel_array` within a `try-except` block, filtering out slices that trigger the decompression error (Cite debug_lesson_2).
2.  I will update `_get_image` in `library/data.py` to save the fallback black image to the disk cache when `load_scan` returns `None`, ensuring that subsequent requests for that patient return immediately without retrying the failed load.
