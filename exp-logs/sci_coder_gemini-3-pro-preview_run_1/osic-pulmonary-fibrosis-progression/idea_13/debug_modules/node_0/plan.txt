This script demonstrates the end-to-end usage of the provided machine learning library for the lung function decline prediction task.

### Strategy
1.  **Data Subset Creation**: To ensure the demonstration runs quickly (within seconds/minutes), we create a small subset of the metadata (3 patients for training, 2 for validation, 2 for testing) and save it to a temporary working directory. This avoids processing the entire dataset.
2.  **Component Initialization**: We explicitly initialize the `LungDataProcessor` (via `get_dataloaders`) and the `DualAxisNet` model. We override defaults like `num_workers=0` and `pretrained=False` to minimize overhead and avoid external network calls.
3.  **Training Loop Execution**: Instead of using the hardcoded `fit` function, we manually construct the training loop using `train_one_epoch` and `validate` from `library.trainer`. This demonstrates how to use the modular components flexibly.
4.  **Inference & Verification**: We generate predictions using the `predict` function and perform assertions to verify that the model output shapes, loss calculations, and submission file format are correct.
