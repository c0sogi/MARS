The implementation strategy involves a sequential pipeline orchestrated in `runfile.py`. First, we initialize the environment (seeds, device) and trigger the training process using the provided `run_training` function from `library.train`. This function handles the training loop, validation monitoring, and saves the best model checkpoint. Second, we load this best model and perform a dedicated inference pass on the validation set to calculate the final official metric and perform failure analysis by correlating prediction errors with input features using NumPy. Finally, conditional on the metric exceeding the defined threshold, we generate predictions for the test set using the `OSICDataset` in test mode, format the results, and save the submission file.
