Based on the comprehensive analysis of the accumulated lessons and the evolution of previous strategies, I propose the **Lightweight-Attention Residual-Fusion Network (LARF-Net)**.

This solution represents a structural evolution designed to balance the high-fidelity requirements of the visual signal with the strict regularization needs of the small dataset. It synthesizes the successful components (Independent Backbones, Native Dimensionality, Symmetric Attention) while removing the architectural excess (Feed-Forward Networks, Projection Bottlenecks) that caused overfitting in previous Transformer-based attempts.

### 1. Model: Lightweight-Attention Residual-Fusion Network (LARF-Net)

**Architecture Design**
1.  **Independent High-Fidelity Visual Backbones:**
    *   The model utilizes two separate **EfficientNet-B0** backbones (initialized with ImageNet weights) to process the orthogonal views.
    *   **Branch A (Axial):** Processes the Axial Tri-Slab input.
    *   **Branch B (Coronal):** Processes the Coronal Tri-Slab input.
    *   **High-Fidelity Extraction:** We apply **Global Average Pooling (GAP)** to the output feature maps to obtain robust global descriptors $V_{ax}$ and $V_{cor}$. **Crucially**, we maintain the **native backbone dimensionality** (1280-dim) and do **not** project these down. This strictly adheres to the lesson that compressing visual features destroys critical texture signals in small datasets (Cite solution_lesson_node_00039). Independent backbones allow view-specific texture learning without explicit modality embeddings (Cite solution_lesson_node_00014, solution_lesson_node_00056).

2.  **Unified Tabular Projection:**
    *   A simple Multi-Layer Perceptron (MLP) encodes the clinical metadata (Age, Sex, SmokingStatus, **Percent** - Cite solution_lesson_node_00017).
    *   **Up-Projection:** The tabular embedding is projected **UP** to match the visual dimensionality (1280-dim), creating vector $V_{tab}$. We avoid complex Gated Linear Units (GLU) or granular tokenization to minimize parameter count (Cite solution_lesson_node_00043).

3.  **Lightweight Symmetric Attention (Structural Innovation):**
    *   **Tokenization:** We stack the vectors into a sequence: $[V_{ax}, V_{cor}, V_{tab}]$.
    *   **Fusion:** We employ a custom **Lightweight Attention Block**.
    *   **Mechanism:** Standard Transformer layers consist of Self-Attention followed by a large Feed-Forward Network (FFN). To address the overfitting observed with full Transformers (Cite solution_lesson_node_00068), we **remove the FFN entirely**. The block consists solely of **Pre-Norm** (LayerNorm) followed by **Multi-Head Self-Attention** and a Residual connection.
    *   *Rationale:* This retains the contextualization capability of attention (Cite solution_lesson_node_00028) while drastically reducing the model capacity to suit the small dataset size (~1,100 samples).

4.  **Holistic Pooled Readout:**
    *   We apply **Global Average Pooling** across the contextualized sequence $[V'_{ax}, V'_{cor}, V'_{tab}]$.
    *   *Rationale:* This aggregates the residuals from all modalities into a robust context vector. We avoid "Visual-Exclusive" selection (which failed in previous iterations due to implementation errors or information loss) and flattening (which leads to overfitting) (Cite solution_lesson_node_00047).

5.  **Prior-Anchored Parametric Head:**
    *   We concatenate the pooled fusion vector with the **Raw Tabular Features** (the original scalars) via a skip connection. This guarantees the regression head has direct, uncorrupted access to the strong scalar priors (Baseline FVC, Percent) (Cite solution_lesson_node_00018).
    *   **Constraint:** The head predicts $\alpha$ (Slope), $\sigma_{base}$, and $\sigma_{growth}$. **Crucially**, we do **not** include `Week` or `Time` as inputs to this network. The parameters are derived solely from static baseline characteristics (Cite solution_lesson_node_00062).
    *   **Activation:** We apply **Softplus** activation to the $\sigma$ outputs to strictly enforce positivity via architecture (Cite solution_lesson_node_00021).

### 2. Data: Fixed Overlapping Orthogonal Tri-Slabs

**Preprocessing**
1.  **Dual-View Generation:** For each patient, generate two inputs to capture 3D spatial heterogeneity (Cite solution_lesson_node_00010).
    *   **Axial Tri-Slab (RGB):** Split the CT volume along the Z-axis (Depth) into three slabs with **fixed boundaries** (0-33%, 33-66%, 66-100%) and **15% overlap**. Compute the Maximum Intensity Projection (MIP) of each slab and map to RGB channels (Cite solution_lesson_node_00006). We strictly avoid stochastic jitter to preserve semantic spatial consistency (Cite solution_lesson_node_00035).
    *   **Coronal Tri-Slab (RGB):** Split along the Y-axis (Anterior-Posterior) into three overlapping slabs, compute MIPs, and map to RGB.
2.  **Resolution:** Resize all images to **224x224** (native resolution) to strictly avoid overfitting caused by upscaling artifacts (Cite solution_lesson_node_00009).

**Augmentation**
1.  **Spatial Only:** Apply random horizontal flips, shifts, and slight rotations. This is critical for regularizing the small dataset (Cite solution_lesson_node_00007).
2.  **No Intensity Changes:** Strictly **disable** brightness/contrast augmentations to preserve the physical Hounsfield Unit density signal (Cite solution_lesson_node_00005).

### 3. Training: Robust Metric Optimization

**Procedure**
*   **Loss Function:** Modified Laplace Log Likelihood. We explicitly **retain the error clipping** (thresholding absolute error at 1000 ml) within the loss calculation to filter outliers (Cite solution_lesson_node_00013). We do **not** use auxiliary losses (Cite solution_lesson_node_00016).
*   **Optimizer:** AdamW with Cosine Annealing scheduler.
*   **Strategy:** Use a strict patience (e.g., 6-8 epochs) for **Early Stopping**. We avoid Stochastic Weight Averaging (SWA) as it degrades performance on this small dataset (Cite solution_lesson_node_00030).

### 4. Evaluation: Parametric Inference

For every `Patient_Week` in the test set:
1.  Generate the Fixed Overlapping Axial and Coronal Tri-Slab images.
2.  Pass inputs and baseline metadata through the **LARF-Net** model to obtain the static parameters $\alpha, \sigma_{base}, \sigma_{growth}$.
3.  Calculate predictions using the anchored trajectory logic (Cite solution_lesson_node_00045):
    *   $$ \text{FVC} = \text{Baseline\_FVC} + \alpha \times (\text{Week} - \text{Baseline\_Week}) $$
    *   $$ \text{Confidence} = \sigma_{base} + \sigma_{growth} \times |\text{Week} - \text{Baseline\_Week}| $$
4.  Clip the Confidence at 70 ml as required by the metric.
