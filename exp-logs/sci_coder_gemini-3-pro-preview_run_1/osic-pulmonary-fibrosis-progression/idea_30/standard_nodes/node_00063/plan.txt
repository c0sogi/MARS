The logic for the `runfile.py` script is structured to ensure a robust and compliant execution of the task. 

1.  **Initialization**: We import the necessary modules and set the random seed for reproducibility using `seed_everything`. We also define the computation device (GPU).
2.  **Data Loading**: We utilize `get_dataloaders(debug=False)` to load the full training, validation, and test datasets. This ensures we use the preprocessed metadata and caching mechanisms defined in the library.
3.  **Model Training**: Instead of using the pre-packaged `run_training` function, we explicitly implement the training loop. This allows us to:
    *   Monitor the validation score at each epoch.
    *   Implement early stopping based on the competition metric.
    *   Save the best model state to `Config.BEST_MODEL_PATH`.
4.  **Validation & Metric**: After training, we reload the best model and perform a full inference pass on the validation set. We calculate the Modified Laplace Log Likelihood using `library.utils.score_function` and print it in the exact required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: During the validation pass, we collect predictions, targets, and input features. We compute the absolute error for each sample and calculate the Pearson correlation coefficients between the error and key features (Weeks, Baseline FVC, Age, Percent). This helps identify if errors are driven by specific patient characteristics or time intervals.
6.  **Submission**: We compare the final validation metric against the threshold (`-6.510164260864258`). If the model performance is superior (higher), we invoke `predict_and_submit` to generate the `submission.csv` file for the test set.
