5.  **Final Validation & Failure Analysis**:
    *   Load the best saved model weights.
    *   Run a dedicated inference pass on the full validation set to compute the `Final Validation Metric`.
    *   During this pass, collect predictions, targets, and input features (Age, Sex, Smoking, Time Delta).
    *   Calculate the absolute prediction error for each sample.
    *   Compute and print the Pearson correlation between the error magnitude and the input features to identify sources of systematic error.

6.  **Submission Generation**: Compare the final validation metric against the threshold (`-6.661946993018998`). If the model performs better (i.e., metric is higher), call `generate_submission` to create the `submission.csv` file for the test set.
