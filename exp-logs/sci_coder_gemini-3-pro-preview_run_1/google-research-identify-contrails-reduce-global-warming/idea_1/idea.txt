Based on the objective to establish a highly efficient baseline that prioritizes speed and simplicity, I propose the **Ash-Net Baseline**. This approach synthesizes the structural reliability of the U-Net (from Model Architecture 1) with the domain-specific feature engineering of the "Ash" color composite (from Model Architecture 2), while stripping away the computational overhead of temporal processing and complex backbones.

### Model
The architecture is a lightweight, standard **2D U-Net**.
*   **Encoder**: Instead of a heavy pre-trained backbone, we will use a simple 4-level convolutional encoder. Each level consists of two 3x3 convolutions followed by a max-pooling operation. This drastically reduces parameter count and memory usage compared to an EfficientNet or Transformer.
*   **Input**: The model accepts a **3-channel input** (H x W x 3) representing the "Ash" color composite of the labeled frame. This differs significantly from Model 1 (which uses 72 channels) by discarding the temporal dimension to maximize inference speed, relying on the assumption that the spectral signature of contrails in the Ash bands is sufficiently discriminative for a baseline.
*   **Decoder**: A symmetric decoder uses bilinear upsampling followed by concatenation with skip connections from the encoder to preserve spatial resolution.
*   **Output**: A 1x1 convolution with a Sigmoid activation produces a single channel probability mask (H x W x 1).

### Data
Preprocessing focuses on reducing the high-dimensional satellite data into a physically meaningful 3-channel RGB image (the "Ash" composite) for the labeled time step (the 5th image in the sequence).
1.  **Band Selection**: Extract Band 11, Band 14, and Band 15 for the `(n_times_before + 1)`-th frame (index 4).
2.  **Ash Composite Construction**:
    *   **Red Channel**: Difference between Band 15 and Band 14 (represents optical depth).
    *   **Green Channel**: Difference between Band 14 and Band 11 (represents particle phase).
    *   **Blue Channel**: Band 14 raw values (represents temperature).
3.  **Normalization**: Apply min-max scaling to each channel based on standard physical bounds for contrails (e.g., scaling the temperature difference [-4, 2] to [0, 1]) to ensure the neural network receives standardized inputs.
4.  **Ground Truth**: Load the `human_pixel_masks` and ensure they are binary (0 or 1).

### Training
The training procedure is designed for stability and convergence speed.
*   **Loss Function**: A combined **Dice Loss + Binary Cross Entropy (BCE)** loss. Dice Loss directly optimizes the evaluation metric and handles the extreme class imbalance (contrails are rare), while BCE provides smooth gradients for pixel-level classification.
*   **Optimizer**: **Adam** with a default learning rate (e.g., 1e-4).
*   **Batch Size**: Maximize batch size (e.g., 32 or 64) to utilize the GPU fully, given the lightweight model and 3-channel input.
*   **Validation**: Monitor the global Dice coefficient on the validation set after each epoch. Save the model checkpoint with the highest validation Dice score.

### Evaluation
1.  **Inference**: For each record in the test set, generate the Ash composite for the 5th frame and feed it into the trained model.
2.  **Post-Processing**: Apply a fixed threshold (e.g., 0.5) to the predicted probabilities to generate a binary mask.
3.  **Formatting**: Flatten the binary mask and convert it to Run-Length Encoding (RLE) strings. Empty predictions are marked with a hyphen. The results are saved to a CSV file matching the submission format.
