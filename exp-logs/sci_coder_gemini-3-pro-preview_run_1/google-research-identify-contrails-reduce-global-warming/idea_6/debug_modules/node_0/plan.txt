This script demonstrates the end-to-end usage of the provided Contrail Identification library. It performs the following steps:
1.  **Data Preparation**: Creates a small subset of the training metadata to ensure the demonstration runs quickly.
2.  **Dataset Verification**: Instantiates the `ContrailDataset`, verifies image shapes, and checks that the Ash False-Color Composite normalization logic produces values within the expected [0, 1] range.
3.  **Model Verification**: Instantiates the `UNetPlusPlus` model and performs a forward pass with dummy data to verify output dimensions.
4.  **Loss & Metric Verification**: Validates the `CompositeLoss` and `GlobalDiceMeter` logic with synthetic predictions and targets, ensuring the math holds up.
5.  **Utility Verification**: Tests the Run-Length Encoding (`rle_encode`) function against a known binary mask pattern.
6.  **Training Integration**: Runs a single epoch of training and validation using the provided `train_one_epoch` and `validate` functions on the data subset, ensuring the pipeline executes without errors.
