### Implementation Strategy

1.  **Configuration Override for Speed**: To ensure the script completes within the 10-minute limit, I will programmatically override the `Config` parameters. I will reduce the number of epochs to 2 and subsample the training dataset to 2,000 random samples. This provides a "fast baseline" execution while still exercising the full training pipeline.
2.  **Training Pipeline**: I will manually construct the training loop using the provided `UNetPlusPlus` model, `CompositeLoss`, and `train_one_epoch` / `validate` functions from the library. This gives me fine-grained control over the data loading (allowing for subsampling) compared to the pre-packaged `run_training` function.
3.  **Validation & Metrics**: After training, I will evaluate the best model on the full validation set to compute the `Final Validation Metric` (Global Dice).
4.  **Failure Analysis**: I will implement a custom analysis pass over the validation set. I will calculate the per-image error (1 - Dice) and correlate this error with metadata fields (timestamp, spatial coordinates) to identify systematic weaknesses.
5.  **Conditional Submission**: I will check if the validation metric exceeds the specified threshold (`0.5973177358563411`). If it does, I will run inference on the test set, apply the sigmoid threshold, encode the masks using RLE, and generate the `submission.csv`.
