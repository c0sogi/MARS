The issue stems from the default behavior of `albumentations.pytorch.ToTensorV2`, which preserves the dimensions of segmentation masks, resulting in channel-last tensors `(H, W, C)` (e.g., `(256, 256, 1)`). PyTorch models and the provided verification script expect channel-first tensors `(C, H, W)` (e.g., `(1, 256, 256)`). I will fix this by setting `transpose_mask=True` when initializing `ToTensorV2` in the dataset's transformation pipelines, ensuring the mask dimensions are correctly transposed. Cite debug_lesson_1.
