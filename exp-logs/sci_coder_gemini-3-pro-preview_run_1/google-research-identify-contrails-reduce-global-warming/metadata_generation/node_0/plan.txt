    *   Load the provided `train_metadata.json` and `validation_metadata.json` files.
    *   Merge this metadata (containing timestamps, projection info, etc.) into the file path DataFrames based on `record_id`.
5.  **Output Generation**:
    *   Save the final DataFrames for training, validation, and test sets as CSV files in the `./metadata` directory.
6.  **Verification**:
