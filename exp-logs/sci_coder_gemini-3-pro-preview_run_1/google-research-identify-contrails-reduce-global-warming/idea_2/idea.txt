Based on the lessons learned, I propose the **ResNet-Ash U-Net**, a strategy that evolves the architecture from a custom lightweight CNN to a robust, pre-trained backbone system while strictly adhering to the successful data and training paradigms identified in previous iterations.

# Model
**Architecture: ResNet34-UNet**
I propose replacing the custom 4-level encoder used in the previous "SimpleUNet" with a **ResNet-34 backbone pre-trained on ImageNet**.
*   **Encoder:** The ResNet-34 encoder provides a significantly deeper and more expressive feature extraction path compared to the previous shallow custom encoder. This addresses the need for higher model capacity to distinguish subtle contrail features from complex cloud backgrounds.
*   **Decoder:** The decoder will consist of symmetric upsampling blocks (bilinear upsampling followed by convolutions) that concatenate skip connections from the corresponding ResNet layers (relu1, layer1, layer2, layer3, layer4) to preserve spatial resolution.
*   **Input Compatibility:** The model will accept a 3-channel input, allowing direct utilization of the pre-trained ImageNet weights without modifying the first convolutional layer.

# Data
**Preprocessing: Physics-Informed Ash Composite**
We will retain the **Ash color composite** input representation, as it successfully isolates physical properties of contrails (temperature, optical depth, particle phase).
*   **Channel Construction:**
    *   Red: Band 15 $-$ Band 14 (Optical Depth proxy)
    *   Green: Band 14 $-$ Band 11 (Particle Phase proxy)
    *   Blue: Band 14 (Temperature)
*   **Normalization:** Crucially, we will apply **global, fixed-range normalization** for these difference channels rather than per-image statistics, ensuring physical thresholds remain consistent across the dataset. Cite solution_lesson_node_00001
*   **Augmentation:** We will employ **only discrete geometric transformations** (Horizontal Flip, Vertical Flip, Random 90-degree Rotation). We will explicitly exclude interpolation-heavy augmentations (scaling, shearing, arbitrary rotation) to prevent "smearing" the thin, high-frequency contrail features. Cite solution_lesson_node_00012

# Training
**Strategy: Stability-Focused Optimization**
The training regime is designed to counter the extreme class imbalance and gradient instability inherent in sparse segmentation.
*   **Loss Function:** A weighted sum of **Focal Loss (75%)** and **Dice Loss (25%)**. This prioritization ensures that pixel-wise classification gradients (Focal) drive the learning process, providing stability, while Dice Loss acts as a secondary shape-refinement objective. Cite solution_lesson_node_00006
*   **Focal Loss Configuration:** We will set the Focal Loss alpha parameter to **$\alpha=0.5$** (balanced) rather than the default 0.25. This prevents the loss function from aggressively down-weighting the already sparse minority class. Cite solution_lesson_node_00010
*   **Optimization:**
    *   **Optimizer:** AdamW.
    *   **Scheduler:** `ReduceLROnPlateau` monitoring validation Dice, allowing the model to settle into minima effectively over a longer training duration (30+ epochs).

# Evaluation
**Inference Process**
1.  **Input Generation:** For each test record, generate the 3-channel Ash composite for the labeled frame (5th image in sequence) using the fixed normalization constants defined in training.
2.  **Prediction:** Pass the tensor through the ResNet34-UNet.
3.  **Thresholding:** Apply a sigmoid activation and threshold the output at 0.5 to generate the binary mask.
4.  **Encoding:** Convert the binary mask to Run-Length Encoding (RLE) for submission.
