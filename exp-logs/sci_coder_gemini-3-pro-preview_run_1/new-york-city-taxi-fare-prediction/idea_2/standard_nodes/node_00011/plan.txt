Implementation Strategy
1.  **Setup & Configuration**: Initialize the environment using the provided `config` module and set random seeds for reproducibility.
2.  **Data Management**: Use `TaxiDataManager` to load the dataset.
    *   **Training**: Load a 10% sample (approx. 4.4 million rows) of the training data. This balances the requirement for a "fast baseline" with the need for sufficient data to achieve a high score (low RMSE).
    *   **Validation**: Load the *full* validation set to ensure the final metric is accurate and complies with the task requirements.
    *   **Test**: Load the full test set for prediction.
3.  **Spatial Feature Engineering**: Use `SpatialRouteEncoder` to implement the core idea.
    *   Fit K-Means clusters on the training coordinates to define neighborhoods.
    *   Generate **Out-of-Fold (OOF)** target encoded features (`mean_fare_route`) for the training set to prevent data leakage.
    *   Create a global route map (Route -> Mean Fare) from the training data and apply it to the validation and test sets.
4.  **Model Training**: Train the `FareModel` (LightGBM) on the augmented training set.
    *   The model will use both the geometric features (distances, rotations) and the new statistical spatial features.
    *   Validate using the augmented validation set with early stopping to prevent overfitting.
5.  **Evaluation & Failure Analysis**:
    *   Compute the RMSE on the full validation set and print it in the required format.
    *   Calculate residuals (absolute error) and compute their correlation with input features to identify sources of error.
6.  **Submission**:
    *   Check if the Validation RMSE is below the specified threshold (3.8253...).
    *   If successful, generate predictions for the test set and save the submission file to `./submission/submission.csv`.
