The strategy is to create a robust metadata generation script that handles the large tabular dataset (55M rows) efficiently using Pandas and PyArrow.

1.  **Setup & Loading**: The script will define input/output directories and load the `test.csv` and `labels.csv` (training data). Given the 220GB RAM, loading the entire 55M row dataset into a Pandas DataFrame is feasible.
2.  **Stratification**: Since the task is regression on `fare_amount`, we cannot use standard class-based stratification. Instead, we will bin the `fare_amount` variable into quantiles (using `pd.qcut`) to create a proxy categorical variable. This ensures that the validation set has a representative distribution of fare prices, including rare high-fare rides.
3.  **Splitting**: We will perform an 80:20 train/validation split using `sklearn.model_selection.train_test_split`, stratifying on the created bins with a fixed random state (42).
4.  **Saving**: The resulting train, validation, and test datasets will be saved as Parquet files in the `./metadata` directory. Parquet is chosen for its efficiency in storage and I/O speed compared to CSV, serving as the "processed metadata" for downstream tasks.
5.  **Verification**:
    *   **Stats**: Print shapes and `fare_amount` statistics for all sets.
    *   **Split Quality**: Programmatically verify the split ratio (approx 0.2) and the stratification success by asserting that the mean `fare_amount` of the training and validation sets differs by less than 1%.
    *   **File Paths**: The script includes logic to detect columns containing file paths (relative to `./input`). If detected, it verifies a random sample of 1000 paths. (Note: This dataset is purely tabular, so this check will likely not find path columns, effectively passing).
