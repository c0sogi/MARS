The implementation strategy is as follows:

1.  **Setup and Loading**: The script will initialize by setting random seeds for reproducibility and loading the training dataset from `./metadata/train.parquet`. Since the dataset is large (approx. 44 million rows), we will load the full dataset for univariate statistics (distributions, missing values) but use a stratified sample (e.g., 100,000 rows) for computationally intensive tasks like correlation analysis and training the lightweight Random Forest.

2.  **Target Variable Analysis**: We will analyze the `fare_amount` column. This includes calculating basic descriptive statistics, skewness, and kurtosis to assess normality. We will also check for logical inconsistencies, such as negative fare amounts.

3.  **Input Data Analysis (Tabular)**:
    *   **Numerical Features**: We will analyze the coordinate columns (`pickup/dropoff_latitude/longitude`) and `passenger_count`. We will calculate mean, standard deviation, min/max, and identify outliers using the Interquartile Range (IQR) method.
    *   **Temporal Features**: We will parse `pickup_datetime` to extract meaningful components (Hour, Year, Month, Day of Week) to treat them as numerical/ordinal features for the relationship analysis.
    *   **Missing Values**: We will check for and report any missing values (NaNs).

4.  **Feature Relationships**:
    *   **Feature Engineering for EDA**: To make the relationship analysis meaningful for this specific domain, we will calculate the **Haversine distance** (great-circle distance) between pickup and dropoff points. Raw coordinates rarely correlate linearly with fare, but distance is the primary driver.
    *   **Correlation**: We will calculate Pearson correlations between the target (`fare_amount`) and features (including the derived distance and time features).
    *   **Feature Importance**: We will train a lightweight `RandomForestRegressor` (low depth, few estimators) on the sampled data to identify the top 5 most predictive features.
    *   **Redundancy**: We will check for collinearity between features (correlation > 0.90).

5.  **Reporting**: The script will output the findings in a structured, readable format with distinct capitalized sections, ensuring all floating-point numbers are formatted to 4 decimal places.
