Based on the comprehensive analysis of the accumulated lessons, I propose the **Pyramid-Context Anchored Input-Injected Network (PCA-IIN)**. This solution introduces a structural innovation—**Temporal Pyramid Anchoring**—to refine the "Global Anchor" concept from the previous best model. By capturing multi-scale temporal context (coarse-to-fine) rather than a single static summary, this architecture explicitly addresses the need for robust sequence modeling on small datasets, while rigorously adhering to the successful feature engineering and optimization strategies identified in the lessons.

# Model

The architecture is a **Multi-Stream Hybrid Network** that evolves the "Global-Context Anchored" backbone by replacing the simple global average pooling with a hierarchical temporal pyramid.

1.  **Decoupled Input Stems (Strategic Retention):**
    We process modalities independently to prevent gradient dominance and allow specific feature extraction (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates (Flattened) via `Linear Projection -> Temporal Conv1d(k=7) -> ReLU -> Dropout`. The kernel size of 7 ensures a robust local receptive field (Cite solution_lesson_node_00040), and the ordering ensures correct feature extraction (Cite solution_lesson_node_00010). We strictly avoid graph convolutions (Cite solution_lesson_node_00039) and explicit velocity inputs (Cite solution_lesson_node_00053).
    *   **Audio Stream:** Processes MFCCs via an identical stem tailored for audio dimensions.

2.  **Gated Fusion & Pyramid Context Anchor (Structural Innovation):**
    *   **Fusion:** The outputs from both stems are concatenated and normalized via **Layer Normalization** (Cite solution_lesson_node_00011).
    *   **Context Gating:** We apply the **Context Gating** mechanism ($Y_t = X_t \odot \sigma(W X_t + b)$) immediately after fusion. This acts as a "Gate-Once" noise filter (Cite solution_lesson_node_00036, solution_lesson_node_00067).
    *   **Temporal Pyramid Anchor:** Instead of a single Global Average Pool (which discards temporal order), we compute a **Temporal Pyramid**:
        *   **Level 1:** Global Average Pooling of the entire sequence (1 vector).
        *   **Level 2:** The sequence is split into 2 equal halves, and Average Pooling is computed for each (2 vectors).
        *   **Level 3:** The sequence is split into 4 equal segments, and Average Pooling is computed for each (4 vectors).
        *   **Aggregation:** These vectors are concatenated to form a **Pyramid Context Vector** ($P$) that captures the holistic "fingerprint" of the sequence at multiple temporal resolutions (e.g., "high energy in the start" vs "static in the end"). This provides a richer structural prior than a simple mean (Cite solution_lesson_node_00086).

3.  **Pyramid-Injected Recurrent Backbone (Structural Innovation):**
    We employ a 2-layer **Bidirectional GRU** (Hidden Dim=256) with a **Dual-Injection** topology.
    *   **Layer 1:** Processes the Gated Fusion sequence $Y$. Output is $H_1$.
    *   **Layer 2:** Processes a composite input formed by the previous hidden state, the original local input, and the Pyramid Anchor.
        *   $Input_2 = H_1 + \text{Proj}_{local}(Y) + \text{Proj}_{pyramid}(P)$.
    *   **Rationale:** Standard Input Injection ($H_1 + Y$) provides high-frequency boundary cues (Cite solution_lesson_node_00070). Injecting the Pyramid Anchor ($P$) stabilizes the internal state against drift by providing a coarse "map" of the sequence's future evolution, rendering the model robust to local noise without the complexity of Attention (Cite solution_lesson_node_00049). The projections decouple model width from input size (Cite solution_lesson_node_00061).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) for all frames. Never use raw absolute coordinates (Cite solution_lesson_node_00079).
    *   **Audio Feature Extraction:** Extract MFCCs using a **Physics-Based Alignment**. Set the Hop Length to match the video frame rate ($16000/20 = 800$) and set the **FFT Window Size** significantly larger (e.g., `n_fft=2048`) to ensure temporal overlap (Cite solution_lesson_node_00080, solution_lesson_node_00054).
    *   **Robust Ingestion:** Implement strict shape-based validation (e.g., `if shape == (20, 3)`) to handle `.mat` file variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Independent Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00016).

2.  **Augmentation (Structural Evolution):**
    *   **Global Speed Jittering (Resampling):** Instead of local noise (which proved redundant in Lesson 00090), apply **Random Uniform Temporal Scaling**. Resample the entire multi-modal sequence by a factor of $\alpha \sim U(0.8, 1.2)$ (interpolating features). This targets **global manifold variations** as recommended in Lesson 00090, forcing the Pyramid Anchor to learn scale-invariant temporal descriptors.
    *   **Remove:** Gaussian Noise and Temporal Cutout (Cite solution_lesson_node_00090).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index to anchor null-state predictions (Cite solution_lesson_node_00076).
    *   **Label Smoothing (0.1):** To handle boundary ambiguity (Cite solution_lesson_node_00011).
    *   **Background Class Weight (0.7):** Maintain a higher weight for the background class to prevent insertion errors during transitions (Cite solution_lesson_node_00070).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** to maximize gradient updates per epoch (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU forward pass to ensure correct backward context (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the PCA-IIN.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
