The implementation strategy is as follows:
1.  **Setup & Configuration**: Initialize the environment by setting the random seed for reproducibility using `library.utils.set_seed`.
2.  **Model Training**: Execute the training pipeline by calling `library.train.train_model`. We will limit the training to 30 epochs to ensure the script completes quickly as a baseline, while still allowing sufficient convergence on the small dataset.
3.  **Validation & Failure Analysis**:
    *   Load the best checkpoint saved during training.
    *   Iterate through the validation dataset using the `val_loader` from `library.data_loader`.
    *   For each sample, generate predictions, compute the Levenshtein distance against the ground truth, and store metadata (sequence length, number of gestures).
    *   Compute and print the `Final Validation Metric` (Levenshtein Error Rate).
    *   Calculate the Pearson correlation between the error magnitude and input features (sequence length, gesture count) to identify failure modes.
4.  **Submission Generation**:
    *   Compare the final validation metric against the strict threshold of `0.0765306122`.
    *   If the metric is below the threshold, iterate through the `test_loader`, generate predictions for the test set, and format them as `SessionID,Label1,Label2,...`.
    *   Save the predictions to `./submission/submission.csv`.
