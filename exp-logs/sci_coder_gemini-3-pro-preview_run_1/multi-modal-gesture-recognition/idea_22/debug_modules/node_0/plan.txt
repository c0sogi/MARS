This script demonstrates the usage of the provided Multi-Scale Context-Gated Input-Injected Network (MSC-IIN) library. It performs the following steps:

1.  **Configuration Override**: Modifies the `Config` class to set up a fast demonstration environment (reduced epochs, batch size, and sample count) and directs outputs to a temporary directory.
2.  **Utility Verification**: Validates the logic of the Levenshtein distance metric and Run-Length Encoding (RLE) decoding functions.
3.  **Data Loading**: Instantiates the `GestureDataset` and `DataLoader` to verify data reading, shape consistency, and batch collation.
4.  **Model Execution**: Performs a forward pass through the `MSC_IIN` model to confirm architecture compatibility with the input data.
5.  **Training Loop**: Runs the `Trainer` to simulate a complete training and validation cycle, ensuring the optimization loop functions correctly.
6.  **Submission Generation**: Generates a submission file using the trained model to verify the inference pipeline.
