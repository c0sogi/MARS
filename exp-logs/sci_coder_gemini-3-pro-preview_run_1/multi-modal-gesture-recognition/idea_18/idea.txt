Based on the comprehensive analysis of the accumulated lessons, I propose the **Multi-View Anchored Input-Injected Network (MVA-IIN)**. This solution synthesizes the robust architectural core of the current best model (Idea 15) with the expressive "Multi-View" anchoring concept (attempted in Idea 17 but failed due to weighting) and introduces **Global Manifold Augmentation** to address the specific data scarcity issues identified in Lesson 00090.

# Model

The architecture is a **Multi-Stream Hybrid Network** that evolves the "Global-Context Anchored" backbone by enriching the anchor representation and enforcing position invariance.

1.  **Decoupled Input Stems (Strategic Retention):**
    We process modalities independently to prevent gradient dominance (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates (Flattened) via `Linear Projection -> Temporal Conv1d(k=7) -> ReLU -> Dropout`. The kernel size of 7 ensures a robust local receptive field (Cite solution_lesson_node_00040), and the ordering ensures correct feature extraction (Cite solution_lesson_node_00010). We strictly avoid graph convolutions (Cite solution_lesson_node_00039) and explicit velocity inputs (Cite solution_lesson_node_00053).
    *   **Audio Stream:** Processes MFCCs via an identical stem tailored for audio dimensions.

2.  **Gated Fusion & Multi-View Anchor (Structural Innovation):**
    *   **Fusion:** The outputs from both stems are concatenated and normalized via **Layer Normalization** (Cite solution_lesson_node_00011).
    *   **Context Gating:** We apply the **Context Gating** mechanism ($Y_t = X_t \odot \sigma(W X_t + b)$) immediately after fusion to suppress noise (Cite solution_lesson_node_00036).
    *   **Multi-View Anchor ($G$):** We compute both **Global Average Pooling** (Mean) and **Global Max Pooling** (Max) of the gated sequence $Y$ (ignoring padding). These are concatenated to form the anchor $G$. While Mean Pooling captures the holistic "background" context, Max Pooling captures the "peak" salient events (e.g., a sharp clap or rapid hand motion) that might be washed out by averaging. This provides a richer, yet still **position-invariant**, sequence descriptor (Cite solution_lesson_node_00093).

3.  **Dual-Injected Recurrent Backbone (Strategic Retention):**
    We employ a 2-layer **Bidirectional GRU** (Hidden Dim=256) with the successful **Dual-Injection** topology.
    *   **Layer 1:** Processes the Gated Fusion sequence $Y$. Output is $H_1$.
    *   **Layer 2:** Processes a composite input formed by the previous hidden state, the original local input, and the Multi-View Anchor.
        *   $Input_2 = H_1 + \text{Proj}_{local}(Y) + \text{Proj}_{global}(G)$.
    *   **Rationale:** This ensures deep layers have direct access to high-frequency boundaries ($Y$) and stable global context ($G$), preventing signal dilution (Cite solution_lesson_node_00070, solution_lesson_node_00086).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) for all frames. Never use raw absolute coordinates (Cite solution_lesson_node_00079).
    *   **Audio Feature Extraction:** Extract MFCCs using a **Physics-Based Alignment**. Set the Hop Length to match the video frame rate ($16000/20 = 800$) and set the **FFT Window Size** significantly larger (e.g., `n_fft=2048`) to ensure temporal overlap (Cite solution_lesson_node_00080, solution_lesson_node_00054).
    *   **Robust Ingestion:** Implement strict shape-based validation (e.g., `if shape == (20, 3)`) to handle `.mat` file variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Independent Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00016).

2.  **Augmentation (Structural Innovation):**
    *   **Global Temporal Resampling:** Instead of local noise (which proved redundant in Lesson 00090), apply **Uniform Temporal Resampling**. Randomly resample the entire multi-modal sequence length by a factor $\alpha \sim U(0.8, 1.2)$ using linear interpolation. This simulates global speed variations (manifold augmentation), forcing the Multi-View Anchor to learn scale-invariant descriptors (Cite solution_lesson_node_00090).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).
    *   **Remove:** Gaussian Noise and Temporal Cutout (Cite solution_lesson_node_00090).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index to anchor null-state predictions (Cite solution_lesson_node_00076).
    *   **Label Smoothing (0.1):** To handle boundary ambiguity (Cite solution_lesson_node_00011).
    *   **Background Class Weight (0.5):** **Crucially**, set the background class weight to **0.5**. This corrects the specific hyperparameter failure that caused Idea 17 (which used 0.7) to collapse, despite its sound architecture (Cite solution_lesson_node_00095).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** to maximize gradient updates per epoch (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU forward pass to ensure correct backward context (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the MVA-IIN.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
