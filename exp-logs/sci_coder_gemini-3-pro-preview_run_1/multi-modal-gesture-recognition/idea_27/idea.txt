Based on the comprehensive analysis of the accumulated lessons, I propose the **Magnitude-Preserving Context-Injected Network (MPC-Net)**. This solution introduces a structural evolution by synthesizing **Wide Feature Stems** with a **Magnitude-Preserving Fusion Topology** and a **Regularized Input-Injected Backbone**.

This architecture explicitly corrects the "Normalization Interference" (Cite solution_lesson_node_00111, solution_lesson_node_00127) and "Dropout Misplacement" (Cite solution_lesson_node_00135, solution_lesson_node_00138) flaws that hampered previous high-capacity models. By strictly removing normalization layers around the gating mechanism and enforcing vertical regularization within the injection topology, it maximizes signal integrity and generalization.

# Model

The architecture is a **Multi-Stream Hybrid Network** designed to preserve the absolute signal amplitude (critical for distinguishing "background" from "action") while stabilizing the recurrent backbone with refined global context.

1.  **Wide Independent Stems (Strategic Retention):**
    We process modalities independently to prevent gradient dominance (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates via a **Wide** `Linear -> Conv1d(k=7, channels=256) -> ReLU -> Dropout` block. We prioritize a single wide branch to maintain representational richness, avoiding the bottlenecks of thin multi-scale stems (Cite solution_lesson_node_00117).
    *   **Audio Stream:** Processes **MFCCs** via an identical wide stem. We strictly use compact MFCCs rather than high-dimensional Mel Spectrograms (Cite solution_lesson_node_00096).

2.  **Magnitude-Preserving Gated Fusion (Structural Innovation):**
    *   **Fusion:** The outputs from both stems are concatenated to form the raw fused sequence $X_{raw}$.
    *   **No Pre-Gate Normalization:** We strictly **remove Layer Normalization** before the gating block. Normalization standardizes background noise to the same scale as active signals; removing it preserves the amplitude cues required for effective filtering (Cite solution_lesson_node_00111).
    *   **Masked Global Context:** We compute the **Global Average Pooling (GAP)** of $X_{raw}$ using **Explicit Masking** to exclude padded time-steps ($G_{raw} = \sum(X \cdot mask) / \sum(mask)$). This corrects the "naive pooling" bug (Cite solution_lesson_node_00123).
    *   **Conditioned Gating:** The gate is computed as $Gate_t = \sigma(W_x X_{raw,t} + W_g G_{raw} + b)$. The gated output is $Y_t = X_{raw,t} \odot Gate_t$.
    *   **No Post-Gate Normalization:** We strictly **remove Layer Normalization** after gating. This ensures that suppressed frames remain numerically close to zero, allowing the backbone to treat them as "silence" (Cite solution_lesson_node_00127).

3.  **Regularized Input-Injected Backbone (Structural Innovation):**
    We employ a **2-layer Bidirectional GRU** (Hidden Dim=256) with a specific connectivity pattern that enforces **Vertical Dropout** and **Refined Context Injection**.
    *   **Refined Anchor:** We compute the **Masked GAP** of the *gated* sequence $Y$ to obtain $G_{refined}$ (Cite solution_lesson_node_00106).
    *   **Layer 1:** Processes $Y_t$. Output is $H_1$.
    *   **Injection & Regularization:** We construct the input for Layer 2 by summing the previous state, the projected local features, and the projected global anchor, *then* applying dropout.
        *   $Sum_2 = H_1 + \text{Proj}(Y) + \text{Proj}(G_{refined})$
        *   $Input_2 = \text{Dropout}(Sum_2)$
    *   **Layer 2:** Processes $Input_2$.
    *   **Rationale:** Applying dropout *after* the summation ensures that the model cannot bypass the noisy recurrent path to rely solely on the stable injection path, forcing robust feature learning (Cite solution_lesson_node_00138). This explicit vertical dropout prevents co-adaptation between layers (Cite solution_lesson_node_00135).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Anchor Modality Alignment:** Treat Video as the anchor. Pad/interpolate Audio to match Video duration. **Never truncate** or rescale timestamps (Cite solution_lesson_node_00132).
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) (Cite solution_lesson_node_00079).
    *   **Audio Processing:** Mix stereo channels in the **time domain** (Cite solution_lesson_node_00114). Extract MFCCs using a **Physics-Based Hop Length** ($Hop = SampleRate / VideoFPS = 800$) and a **Window Size of 2048** (~2.5x Hop) to ensure temporal overlap (Cite solution_lesson_node_00080, solution_lesson_node_00128).
    *   **Robust Ingestion:** Implement strict shape-based validation to handle `.mat` variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Global Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00107).

2.  **Augmentation:**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** to the entire multi-modal sequence (scaling length by $\alpha \sim U(0.8, 1.2)$) (Cite solution_lesson_node_00102).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index (Cite solution_lesson_node_00076).
    *   **Background Class Weight (0.5):** **Crucially**, set the background class weight to **0.5** to prevent model collapse (Cite solution_lesson_node_00095).
    *   **Label Smoothing (0.1):** To handle boundary ambiguity (Cite solution_lesson_node_00011).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU forward pass (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the MPC-Net.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
