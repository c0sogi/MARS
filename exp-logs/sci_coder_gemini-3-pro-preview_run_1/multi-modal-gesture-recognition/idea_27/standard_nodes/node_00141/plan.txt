This occurs because the data loader's fallback logic for missing or corrupted files allows `num_frames` to be 0 (or reads 0 from metadata), and the caching mechanism persists these invalid samples. To fix this, I will enforce a strict invariant that `num_frames >= 1` in all data loading paths (Cite debug_lesson_22) and validate cached data before use. I will also clear the statistics file in `runfile.py` to prevent contamination from previous invalid runs (Cite debug_lesson_14).
