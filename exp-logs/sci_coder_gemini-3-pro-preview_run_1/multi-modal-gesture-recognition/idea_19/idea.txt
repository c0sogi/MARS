Based on the comprehensive analysis of the accumulated lessons, I propose the **Global-Conditioned Input-Injected Network (GCI-Net)**. This solution introduces a structural innovation—**Global-Conditioned Gating**—to the feature fusion stage. By conditioning the noise-suppression gate on a holistic sequence summary (Global Average Pooling) rather than just local frames, this architecture enables the model to adapt its filtering strategy to the global context (e.g., suppressing audio channels in globally silent sequences). Crucially, this proposal isolates the architectural logic of "Conditioned Gating" from the hyperparameter failures (incorrect class weighting) and feature engineering errors (Max Pooling, Mel Spectrograms) that caused similar previous attempts to fail.

# Model

The architecture is a **Multi-Stream Hybrid Network** that evolves the "Global-Context Anchored" backbone by making the gating mechanism globally aware.

1.  **Decoupled Input Stems (Strategic Retention):**
    We process modalities independently to prevent gradient dominance and allow specific feature extraction (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates (Flattened) via `Linear Projection -> Temporal Conv1d(k=7) -> ReLU -> Dropout`. The kernel size of 7 ensures a robust local receptive field (Cite solution_lesson_node_00040), and the ordering ensures correct feature extraction (Cite solution_lesson_node_00010). We strictly avoid graph convolutions (Cite solution_lesson_node_00039) and explicit velocity inputs (Cite solution_lesson_node_00053).
    *   **Audio Stream:** Processes **MFCCs** via an identical stem. We strictly use compact MFCCs rather than high-dimensional Mel Spectrograms to prevent noise overfitting (Cite solution_lesson_node_00096).

2.  **Global-Conditioned Gating (Structural Innovation):**
    *   **Fusion:** The outputs from both stems are concatenated to form the raw fused sequence $X$.
    *   **Global Context Extraction:** We compute the **Global Average Pooling (GAP)** of $X$ (masking padding) to obtain a raw context vector $C_{raw}$. We strictly avoid Global Max Pooling to prevent broadcasting local outliers (Cite solution_lesson_node_00098).
    *   **Conditioned Gating:** We apply a gating mechanism where the gate activation depends on *both* the local frame $X_t$ and the global context $C_{raw}$:
        *   $Gate_t = \sigma(W_x X_t + W_c C_{raw} + b)$
        *   $Y_t = X_t \odot Gate_t$
    *   **Rationale:** Standard Context Gating ($X \odot \sigma(X)$) filters noise based only on local cues (Cite solution_lesson_node_00036). Conditioned gating allows the model to use the entire sequence's "fingerprint" to determine feature reliability frame-by-frame.

3.  **Dual-Injected Recurrent Backbone (Strategic Retention):**
    We employ a 2-layer **Bidirectional GRU** (Hidden Dim=256) with the successful **Dual-Injection** topology.
    *   **Layer 1:** Processes the Gated Fusion sequence $Y$. Output is $H_1$.
    *   **Layer 2:** Processes a composite input formed by the previous hidden state, the cleaned local input, and a refined global anchor ($G_{clean} = \text{GAP}(Y)$).
        *   $Input_2 = H_1 + \text{Proj}_{local}(Y) + \text{Proj}_{global}(G_{clean})$.
    *   **Rationale:** This ensures deep layers have direct access to high-frequency boundaries ($Y$) and stable global context ($G_{clean}$), preventing signal dilution (Cite solution_lesson_node_00070, solution_lesson_node_00086).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) for all frames. Never use raw absolute coordinates (Cite solution_lesson_node_00079).
    *   **Audio Feature Extraction:** Extract MFCCs using a **Physics-Based Alignment**. Set the Hop Length to match the video frame rate ($16000/20 = 800$) and set the **FFT Window Size** significantly larger (e.g., `n_fft=2048`) to ensure temporal overlap (Cite solution_lesson_node_00080, solution_lesson_node_00054).
    *   **Robust Ingestion:** Implement strict shape-based validation (e.g., `if shape == (20, 3)`) to handle `.mat` file variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Independent Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00016).

2.  **Augmentation (Structural Evolution):**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** to the entire multi-modal sequence (scaling length by $\alpha \sim U(0.8, 1.2)$). This targets **global manifold variations** (speed changes), forcing the Global Anchor to learn scale-invariant descriptors, which is more effective for this architecture than local noise injection (Cite solution_lesson_node_00090).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index to anchor null-state predictions (Cite solution_lesson_node_00076).
    *   **Background Class Weight (0.5):** **Crucially**, set the background class weight to **0.5**. This corrects the specific hyperparameter failure that caused previous Conditioned Gating attempts to collapse (Cite solution_lesson_node_00095).
    *   **Label Smoothing (0.1):** To handle boundary ambiguity (Cite solution_lesson_node_00011).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** to maximize gradient updates per epoch (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU forward pass to ensure correct backward context (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the GCI-Net.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
