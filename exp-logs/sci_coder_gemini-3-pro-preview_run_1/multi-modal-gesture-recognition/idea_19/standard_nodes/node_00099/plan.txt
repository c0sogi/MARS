Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and selecting the appropriate computation device (GPU/CPU). Import all necessary components from the provided library files (`config`, `utils`, `data_loader`, `model`, `trainer`).
2.  **Data Preparation**: Instantiate `GestureDataset` objects for training, validation, and testing using the pre-generated metadata CSVs. Wrap these datasets in `DataLoader`s with the provided `collate_fn` to handle variable-length sequences via padding.
3.  **Model Training**: Initialize the `GCINet` model and the `Trainer` class. Execute the training loop via `trainer.fit()`, which handles forward passes, backpropagation, validation monitoring, and checkpointing the best model based on the Levenshtein Error Rate.
4.  **Validation & Failure Analysis**: Load the best-saved model checkpoint. Perform a dedicated inference pass on the validation set to compute the final Levenshtein Error Rate. Simultaneously, collect metadata (sequence length, number of gestures) and error metrics for each sample to calculate and print correlations, identifying potential failure modes.
5.  **Submission Generation**: Compare the final validation metric against the strict threshold (0.0765306122). If the model performs sufficiently well, generate predictions for the test set. Decode the frame-wise predictions into gesture sequences using Run-Length Encoding (RLE) and save the results in the specified CSV format (`SessionID,Label1,Label2,...`).
