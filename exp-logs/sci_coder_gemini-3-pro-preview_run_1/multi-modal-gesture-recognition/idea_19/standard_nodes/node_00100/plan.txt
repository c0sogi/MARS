The issue is that `np.load` returns a lazy-loading `NpzFile` object that maintains an open file handle. When `self.stats` stores this object and is pickled/sent to multiple DataLoader worker processes, the shared file handle leads to race conditions and corruption (`zipfile.BadZipFile`). The fix is to explicitly materialize the `.npz` contents into a standard Python dictionary and close the file handle immediately using a context manager, preventing concurrent file access issues (Cite debug_lesson_12).
