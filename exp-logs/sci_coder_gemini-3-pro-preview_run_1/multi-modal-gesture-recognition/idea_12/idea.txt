Based on the accumulated lessons, I propose the **Skip-Context Residual Network (SCR-Net)**. This solution introduces a structural evolution of the backbone—**Systematic Input Injection**—to maximize the benefits of the "Input Injection" topology identified in Lesson 00070, while rigorously adhering to the successful feature engineering and optimization strategies from the previous best experiments.

# Model

The architecture is a **Multi-Stream Hybrid Network** that evolves the previous "Context-Gated" approach by ensuring the clean, gated signal is directly accessible at all depths of the recurrent backbone.

1.  **Decoupled Input Stems:**
    We process modalities independently to prevent gradient dominance and allow specific feature extraction (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes Normalized Joint Coordinates (Flattened) via `Linear Projection -> Temporal Conv1d(k=7) -> ReLU -> Dropout`. The kernel size of 7 ensures a robust local receptive field (Cite solution_lesson_node_00040), and the ordering ensures correct feature extraction before regularization (Cite solution_lesson_node_00010). We avoid graph convolutions (Cite solution_lesson_node_00039) and explicit velocity inputs (Cite solution_lesson_node_00053).
    *   **Audio Stream:** Processes MFCCs via an identical stem tailored for audio dimensions.

2.  **Gated Fusion:**
    *   **Fusion:** The outputs from both stems are concatenated and normalized via **Layer Normalization** (Cite solution_lesson_node_00011).
    *   **Context Gating:** We apply the **Context Gating** mechanism ($Y = X \odot \sigma(W X + b)$) immediately after fusion. This acts as a "Gate-Once" noise filter, suppressing unreliable modalities before they enter the backbone (Cite solution_lesson_node_00036, solution_lesson_node_00067).

3.  **Skip-Context Backbone (Structural Innovation):**
    We replace the standard stacked BiGRU with a **Skip-Context** topology that generalizes the "Input Injection" success (Cite solution_lesson_node_00070).
    *   **Layer 1:** A Bidirectional GRU processes the **Gated Fusion Output** ($F$).
    *   **Layer 2:** A second Bidirectional GRU processes a combination of the previous layer's output ($H_1$) and a **fresh projection** of the Gated Fusion Output ($F$).
        *   Equation: $Input_2 = H_1 + \text{Linear}(F)$.
    *   **Rationale:** Unlike standard residuals ($H_2 = \text{GRU}(H_1) + H_1$) which propagate processing noise, or standard stacking ($Input_2 = H_1$) which dilutes the original signal, this topology injects the pristine, context-aware input directly into deeper layers. The learnable linear projection decouples the capacity, allowing the backbone to be wider than the input (Cite solution_lesson_node_00061).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the final backbone output to class probabilities, providing the necessary capacity to disentangle hidden states (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Skeleton:** Compute relative coordinates (`Joint - HipCenter`) to ensure user-position invariance (Cite solution_lesson_node_00005).
    *   **Audio:** Extract MFCCs using a **Physics-Based Hop Length** ($Hop = SampleRate / VideoFPS$) to ensure mathematical alignment with video frames without interpolation artifacts (Cite solution_lesson_node_00054).
    *   **Normalization:** Apply **Independent Z-score Normalization** (Zero Mean, Unit Variance) to both modalities using global training statistics. Do not use physical unit scaling (Cite solution_lesson_node_00016).
    *   **Ingestion:** Use shape-based tensor validation to robustly handle `.mat` file variability (Cite solution_lesson_node_00064).

2.  **Augmentation:**
    *   **Random Channel Masking:** Randomly zero out ~10% of feature channels for the entire sequence (Cite solution_lesson_node_00013).
    *   **Random Time Masking (Temporal Cutout):** Randomly zero out contiguous chunks (5-15 frames) to force reliance on temporal context (Cite solution_lesson_node_00040).
    *   **Additive Gaussian Noise:** Inject noise into skeleton inputs (Cite solution_lesson_node_00007).

# Training

1.  **Loss Function:**
    *   **Masked Frame-wise Cross Entropy:** Explicitly mask out padded time-steps from the loss calculation to accelerate convergence (Cite solution_lesson_node_00069).
    *   **Label Smoothing (0.1):** To handle boundary ambiguity (Cite solution_lesson_node_00011).
    *   **Background Class Weight (0.7):** Maintain a moderate-to-high weight for the background class to prevent insertion errors during transitions (Cite solution_lesson_node_00070).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** to maximize gradient updates per epoch (Cite solution_lesson_node_00050).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** to prevent overfitting in the recurrent layers (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW optimizer with **Cosine Annealing** for smooth convergence (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint that minimizes the **Levenshtein Error Rate** on the validation set (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the SCR-Net model.
    *   Apply a **Median Filter** (window size 5) to smooth frame-wise probability maps (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the final list of gesture IDs, filtering out the background class and segments shorter than 5 frames. Avoid complex multi-stage refinement (Cite solution_lesson_node_00019).
