The issue is that PyTorch 2.6+ defaults `torch.load` to `weights_only=True`, which restricts unpickling to safe types (tensors). The checkpoint file contains NumPy scalars (e.g., `val_metric`), causing a `_pickle.UnpicklingError` (Cite debug_lesson_9). To fix this, I will update the `torch.load` calls in `library/utils.py` and `library/engine.py` to explicitly set `weights_only=False`, as these checkpoints are generated locally and trusted. I will use concise search blocks to ensure the patch applies correctly (Cite debug_lesson_7).
