The following script demonstrates the usage of the provided multimodal gesture recognition library.

**Implementation Strategy:**
1.  **Configuration Setup**: We first import the `Config` class and override specific paths and hyperparameters (e.g., `WORKING_DIR`, `EPOCHS`, `BATCH_SIZE`) to create a lightweight "demo" environment. This ensures the script runs quickly and doesn't overwrite existing production artifacts.
2.  **Data Loading**: We use `get_dataloaders(debug=True)` to load a tiny subset of the data (20 training samples). We verify the integrity of the batches (shapes of skeleton, audio, and label tensors).
3.  **Model Verification**: We instantiate the `IICGRN` model and perform a forward pass with a dummy batch to confirm the architecture processes inputs correctly without errors.
4.  **Training Loop**: We initialize the `Trainer` and run the `fit` method for a single epoch. We assert that the training process produces a model checkpoint.
5.  **Inference & Submission**: We run the `predict` method on the test set and verify that a valid submission CSV is generated.
6.  **Metric Validation**: We manually test the `compute_levenshtein` function with known sequences to ensure the scoring logic is accurate.
