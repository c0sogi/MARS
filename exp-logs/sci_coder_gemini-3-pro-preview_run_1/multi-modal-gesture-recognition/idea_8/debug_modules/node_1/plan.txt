The issue is that `pd.read_csv` expects a tabular format with a consistent number of columns per row. The submission file, however, contains "ragged" data where each row (sequence of gestures) can have a different length, causing the parser to crash when it encounters a row with more columns than the first row. To fix this, I will replace the Pandas usage with standard Python file I/O (`open(...).readlines()`) to read the submission file line by line, which allows for variable-length rows without enforcing a rigid schema.
