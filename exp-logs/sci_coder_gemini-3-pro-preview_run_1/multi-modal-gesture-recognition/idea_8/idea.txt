Based on the lessons learned from previous experiments, I propose the **Kinematic-Aware Multi-Task Residual Network (KA-MTRN)**. This solution structurally evolves the successful Context-Gated GRU (Idea 4) by introducing **Explicit Kinematic Streams** and **Auxiliary Boundary Supervision**. This addresses the remaining challenges of segmentation jitter and feature robustness while strictly adhering to the optimization strategies proven to work on this small-scale dataset.

# Model

The architecture is a **Tri-Stream Hybrid Network** designed to explicitly model static pose, dynamic motion, and audio context independently before fusion.

1.  **Tri-Stream Input Encoders (Structural Innovation):**
    Instead of implicitly relying on the RNN to infer motion from positions, we decouple the input into three independent streams to allow modality-specific feature extraction (Cite solution_lesson_node_00021).
    *   **Pose Stream:** Processes Normalized Joint Coordinates via `Linear -> Conv1d(k=7) -> ReLU -> Dropout`. The kernel size of 7 ensures a sufficient local receptive field (Cite solution_lesson_node_00040), and the ordering ensures correct feature extraction (Cite solution_lesson_node_00010).
    *   **Velocity Stream:** Processes **Explicit Velocity Features** (frame-to-frame coordinate differences) via an identical stem. This provides a strong inductive bias for action recognition, ensuring the model attends to movement dynamics (Cite solution_lesson_node_00005).
    *   **Audio Stream:** Processes MFCCs via an identical stem tailored for audio dimensions.

2.  **Gated Fusion:**
    *   **Fusion:** The outputs from all three stems are concatenated and immediately normalized via **Layer Normalization** to stabilize the distribution of heterogeneous features (Cite solution_lesson_node_00011).
    *   **Context Gating:** A **Context Gating** block ($Y = X \odot \sigma(W X + b)$) is applied to the fused vector. This allows the model to dynamically suppress unreliable modalities (e.g., noisy joints or silent audio) frame-by-frame before they enter the recurrent backbone (Cite solution_lesson_node_00036).

3.  **Residual Recurrent Backbone:**
    *   The sequence is processed by a **Residual Bidirectional GRU** (2 layers, Hidden Dim=256). The residual connections prevent signal degradation, while the restricted hidden dimension acts as a structural regularizer against overfitting (Cite solution_lesson_node_00023, solution_lesson_node_00036). We avoid global attention mechanisms which have proven ineffective on this small dataset (Cite solution_lesson_node_00049).

4.  **Multi-Task Output Heads (Structural Innovation):**
    *   **Classification Head:** A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) outputs frame-wise class probabilities. This provides the necessary capacity to disentangle the hidden state (Cite solution_lesson_node_00051).
    *   **Boundary Head:** An auxiliary MLP outputs a binary probability indicating whether the current frame is a **transition** (change in gesture). This explicitly penalizes segmentation jitter, addressing the disconnect between frame-wise loss and the event-based Levenshtein metric (Cite solution_lesson_node_00025).

# Data

1.  **Preprocessing:**
    *   **Kinematics:** Compute relative coordinates (`Joint - HipCenter`) for the Pose stream (Cite solution_lesson_node_00005). Compute $\Delta Joint$ (current frame - previous frame) for the Velocity stream.
    *   **Audio:** Extract MFCCs aligned to the video frame rate.
    *   **Normalization:** Apply **Independent Z-score Normalization** (Zero Mean, Unit Variance) to Pose, Velocity, and Audio streams separately using global training statistics. This prevents numerical dominance by any single stream (Cite solution_lesson_node_00016, solution_lesson_node_00021).

2.  **Augmentation:**
    *   **Random Channel Masking:** Randomly zero out ~10% of feature channels for the entire sequence to force reliance on redundant signals (Cite solution_lesson_node_00013).
    *   **Random Time Masking (Temporal Cutout):** Randomly zero out contiguous chunks (5-15 frames) to force the RNN to rely on temporal context (Cite solution_lesson_node_00040).
    *   **Additive Gaussian Noise:** Inject noise into the skeleton inputs (Cite solution_lesson_node_00007).

# Training

1.  **Loss Function:**
    *   **Multi-Task Loss:** $L = L_{Class} + 0.5 \times L_{Boundary}$.
    *   **$L_{Class}$:** Frame-wise Cross Entropy with **Label Smoothing (0.1)** and **Background Class Weight (0.5)** to handle boundary ambiguity and class imbalance (Cite solution_lesson_node_00011).
    *   **$L_{Boundary}$:** Binary Cross Entropy on dynamically generated transition labels ($y_t=1$ if $label_t \neq label_{t-1}$).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** to maximize gradient updates per epoch on this small dataset (Cite solution_lesson_node_00050).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** to prevent overfitting in the recurrent layers (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW optimizer with **Cosine Annealing** for smooth convergence (Cite solution_lesson_node_00031).
    *   **Target Alignment:** Generate targets dynamically based on the loaded tensor shape to ensure perfect alignment (Cite solution_lesson_node_00051).
    *   **Checkpointing:** Save the checkpoint that minimizes the **Levenshtein Error Rate** on the validation set, not the validation loss (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the KA-MTRN model.
    *   Use the **Classification Head** output for prediction.
    *   Apply a **Median Filter** (window size 5) to smooth the probability maps (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames. Avoid complex multi-stage refinement modules (Cite solution_lesson_node_00019).
