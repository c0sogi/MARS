The implementation strategy is as follows:
1.  **Setup & Configuration**: Initialize the environment by setting random seeds and ensuring the configuration directories exist.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. To satisfy the "fast baseline" requirement, we override the default epochs to 20. This allows the model to converge sufficiently on the small dataset without exceeding the time limit.
3.  **Validation & Analysis**:
    *   Load the best model checkpoint saved during training.
    *   Iterate through the validation dataset to generate predictions.
    *   Compute the Levenshtein Error Rate (LER) for each sample and the global Final Validation Metric.
    *   Perform failure analysis by calculating the Pearson correlation between the input sequence length (frames) and the per-sample error rate to identify if longer sequences are harder to predict.
4.  **Conditional Submission**: Compare the Final Validation Metric against the strict threshold (0.061224489795918366). If the model performs better (lower score), generate the submission file using `library.predict.generate_submission`.
