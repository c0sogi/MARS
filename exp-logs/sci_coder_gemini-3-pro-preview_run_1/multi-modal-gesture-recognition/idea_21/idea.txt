Based on the comprehensive analysis of the accumulated lessons, I propose the **State-Refined Input-Injected Network (SR-IIN)**. This solution introduces a structural innovation—**State-Level Anchoring**—to the recurrent backbone. It evolves the "Refined Context" concept (Lesson 00106) by deriving the global anchor from the *temporally integrated hidden states* of the first recurrent layer, rather than just the static input features. This provides the deeper layers with a semantic summary of the sequence evolution, while strictly adhering to the robust optimization and feature engineering strategies identified in the lessons.

# Model

The architecture is a **Multi-Stream Hybrid Network** that progressively refines the context used to stabilize the recurrent backbone.

1.  **Decoupled Input Stems (Strategic Retention):**
    We process modalities independently to prevent gradient dominance and allow specific feature extraction (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates (Flattened) via `Linear Projection -> Temporal Conv1d(k=7) -> ReLU -> Dropout`. The kernel size of 7 ensures a robust local receptive field (Cite solution_lesson_node_00040), and the ordering ensures correct feature extraction (Cite solution_lesson_node_00010). We strictly avoid graph convolutions (Cite solution_lesson_node_00039) and explicit velocity inputs (Cite solution_lesson_node_00053).
    *   **Audio Stream:** Processes **MFCCs** via an identical stem. We use compact MFCCs rather than high-dimensional Mel Spectrograms to prevent noise overfitting (Cite solution_lesson_node_00096).

2.  **Global-Conditioned Gating (Strategic Retention):**
    *   **Fusion:** The outputs from both stems are concatenated and normalized via **Layer Normalization** (Cite solution_lesson_node_00011).
    *   **Conditioned Gating:** We apply a gating mechanism ($Y_t = X_t \odot \sigma(W_x X_t + W_g G_{raw} + b)$) where $G_{raw}$ is the **Global Average Pooling** of the raw fused sequence. This filters noise based on the initial static context (Cite solution_lesson_node_00102).

3.  **State-Refined Recurrent Backbone (Structural Innovation):**
    We employ a 2-layer **Bidirectional GRU** (Hidden Dim=256) with a **Progressive Anchoring** topology.
    *   **Layer 1:** Processes the Gated Fusion sequence $Y$. Output is $H_1$.
    *   **State Anchor Extraction:** We compute the **Global Average Pooling** of the first layer's hidden states $H_1$ (masking padding) to obtain the State Anchor $S$. Unlike the input anchor (which captures feature statistics), $S$ captures the **semantic gist** of the temporal sequence (e.g., "continuous circular motion detected"). We strictly use Average Pooling, avoiding Max Pooling (Cite solution_lesson_node_00098).
    *   **Layer 2 (Dual Injection):** Processes a composite input formed by the previous hidden state, the original high-frequency local input, and the new State Anchor.
        *   $Input_2 = H_1 + \text{Proj}_{local}(Y) + \text{Proj}_{state}(S)$.
    *   **Rationale:** This topology provides the deep layers with the best of both worlds: direct access to high-frequency boundaries via $Y$ (Cite solution_lesson_node_00070) and a stable, temporally-integrated semantic prior via $S$, which is a more robust descriptor than the static input average used in previous iterations (Cite solution_lesson_node_00106).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) for all frames. Never use raw absolute coordinates (Cite solution_lesson_node_00079).
    *   **Audio Feature Extraction:** Extract MFCCs using a **Physics-Based Alignment**. Set the Hop Length to match the video frame rate ($16000/20 = 800$) and set the **FFT Window Size** significantly larger (e.g., `n_fft=2048`) to ensure temporal overlap (Cite solution_lesson_node_00080, solution_lesson_node_00054).
    *   **Robust Ingestion:** Implement strict shape-based validation (e.g., `if shape == (20, 3)`) to handle `.mat` file variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Global Z-score Normalization** to both modalities using global training statistics. Do not use Instance-Level Normalization (Cite solution_lesson_node_00107, solution_lesson_node_00108).

2.  **Augmentation:**
    *   **Global Temporal Resampling:** Apply **Uniform Temporal Resampling** to the entire multi-modal sequence (scaling length by $\alpha \sim U(0.8, 1.2)$). This targets global manifold variations (Cite solution_lesson_node_00102, solution_lesson_node_00090).
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).
    *   **Avoid:** 3D Rotation (Cite solution_lesson_node_00103).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index (Cite solution_lesson_node_00076).
    *   **Background Class Weight (0.5):** **Crucially**, set the background class weight to **0.5** to prevent model collapse (Cite solution_lesson_node_00095).
    *   **Label Smoothing (0.1):** To handle boundary ambiguity (Cite solution_lesson_node_00011).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** to maximize gradient updates per epoch (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU forward pass to ensure correct backward context (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the SR-IIN.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
