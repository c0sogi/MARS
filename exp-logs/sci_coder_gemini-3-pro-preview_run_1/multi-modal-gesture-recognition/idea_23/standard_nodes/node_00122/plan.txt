The implementation strategy is as follows:
1.  **Setup & Imports**: Initialize the environment, set random seeds for reproducibility, and import the required modules from the provided library files (`library.config`, `library.utils`, `library.data_loader`, `library.model`, `library.train`, `library.predict`).
2.  **Training**: Execute the training pipeline using `run_training`. We will set `num_epochs=30` to ensure the process completes quickly as a fast baseline, utilizing cached data to speed up loading.
3.  **Validation & Failure Analysis**:
    *   Load the best model checkpoint saved during training.
    *   Perform a dedicated inference pass on the validation set using `torch.no_grad()` and `model.eval()` for efficiency.
    *   Compute the Levenshtein error rate and print it in the exact format: `Final Validation Metric: <value>`.
    *   Extract sample-level features (sequence length, audio energy, skeleton energy) and compute their Pearson correlation with the normalized error rate to identify failure modes.
4.  **Submission**: Compare the final validation metric against the strict threshold (`0.05697278911564626`). If and only if the metric is lower than this threshold, execute `run_prediction` to generate the `submission.csv` file.
