The `RuntimeError: mat1 and mat2 must have the same dtype, but got Double and Float` occurs because the normalization statistics (mean and std) loaded from the NumPy `.npz` file are in `float64` (Double) precision by default, whereas the model weights and input data are initialized as `float32`. When these statistics are applied in `__getitem__`, PyTorch promotes the input tensors to `float64`, causing a type mismatch at the first linear layer of the model. I will fix this by explicitly casting the normalization statistics to `float32` using `.float()` immediately after loading them in `library/data_loader.py`.
