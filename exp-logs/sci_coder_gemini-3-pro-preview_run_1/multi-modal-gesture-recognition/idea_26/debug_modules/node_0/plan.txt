This script demonstrates the end-to-end usage of the provided SAMP-Net library for gesture recognition. It begins by verifying the correctness of the Levenshtein distance metric. Then, it overrides the default configuration to ensure the demonstration runs quickly (reducing epochs and batch size) and uses a temporary working directory. It explicitly validates the data loading process by checking tensor shapes and verifies the model's forward pass dimensions. Finally, it executes the full training and inference pipelines using the library's high-level functions, confirming that the model trains and generates a submission file correctly.
