The following script demonstrates the usage of the provided machine learning library for the gesture recognition task. It overrides the default configuration to run a lightweight, fast execution suitable for demonstration and verification.

The strategy involves:
1.  **Configuration Override**: Modifying `Config` parameters (epochs, batch size, hidden dimensions) and redirecting the working directory to `./working/demo_run` to ensure a quick runtime and isolation.
2.  **Output Suppression**: Monkey-patching `tqdm` to disable progress bars and filtering warnings to comply with the silent execution requirement.
3.  **Data Loading & Validation**: Loading a small subset of training data, computing dense labels (required for the frame-wise loss), and verifying the `GestureDataset` and `robust_collate_fn` produce correctly shaped tensors.
4.  **Model Verification**: Instantiating the `ACGRNet` model and performing a forward pass with a real data batch to confirm input/output dimensions.
5.  **Training Loop**: Running the `Trainer` for a few epochs on the data subset to demonstrate the training process and verifying that the best model checkpoint is saved.
6.  **Inference**: Using the trained model to generate predictions on a subset of the test data and validating the submission file format.
7.  **Metric Check**: Unit testing the Levenshtein distance function with known inputs to ensure metric calculation correctness.
