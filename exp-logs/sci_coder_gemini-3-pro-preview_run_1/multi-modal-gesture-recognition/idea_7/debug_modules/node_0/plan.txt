The following script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition. It performs the following steps:

1.  **Configuration Overrides**: Modifies global configuration parameters (e.g., number of epochs, batch size) to ensure the demonstration runs quickly.
2.  **Data Preparation**: Manually loads a small subset of the metadata (first 10 samples) and initializes `GestureDataset` and `DataLoader` instances to avoid processing the entire dataset.
3.  **Model Verification**: Instantiates the `KAGRN` model, passes a batch of data through it, and asserts that the output shapes for classification and boundary detection are correct.
4.  **Utility Verification**: Validates the logic of helper functions like `levenshtein_distance` and `rle_decode` using test cases with known outputs.
5.  **Training Loop**: Initializes the `Trainer` class and runs the training process (`fit`) on the data subset for a few epochs to verify the optimization loop.
6.  **Inference**: Runs the prediction pipeline (`predict`) on a test subset and verifies that the submission file is generated in the correct format.
