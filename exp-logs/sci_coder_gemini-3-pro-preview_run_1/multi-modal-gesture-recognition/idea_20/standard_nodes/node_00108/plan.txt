The following code changes implement the optimization strategy based on the provided lessons. Specifically, I am switching from instance-level normalization to global scaling (Lesson 107) and refining the global context injection mechanism to use gated features instead of raw inputs (Lesson 106).

1.  **`library/config.py`**: Defined `SKELETON_SCALE` and `AUDIO_SCALE` for global normalization.
2.  **`library/data_loader.py`**: Replaced per-sample Z-score normalization with fixed global scaling.
3.  **`library/model.py`**: Updated the `DAGINet` forward pass to compute "Refined Anchors" from the gated output `y` and use these for the second-layer injection, while keeping "Raw Anchors" for the initial gating step.
