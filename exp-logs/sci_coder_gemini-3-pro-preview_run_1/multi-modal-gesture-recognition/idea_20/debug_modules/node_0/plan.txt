The following script demonstrates the usage of the provided library files for the multimodal gesture recognition task.

**Implementation Strategy:**
1.  **Environment Setup**: Defines a temporary working directory (`./working/demo_execution`) to store subsets of metadata and cached data, ensuring the main environment remains clean.
2.  **Data Preparation**: Creates tiny subsets (5 samples each) of the original `train.csv` and `val.csv` metadata files. This ensures the demonstration runs quickly.
3.  **Configuration Patching**: Runtime modifies the `Config` class attributes to point to these new subset metadata files and adjusts hyperparameters (epochs, batch size) for a rapid execution cycle.
4.  **Component Verification**:
    *   **Utils**: Validates `levenshtein_distance` and `rle_decode` logic with assertions on synthetic data.
    *   **Data Loader**: Instantiates the `GestureDataset` and `DataLoader`, verifying the shape and integrity of the multimodal batches (Skeleton, Audio, Labels).
    *   **Model**: Instantiates `DAGINet`, performs a forward pass with a real batch, and verifies output dimensions.
5.  **Training Pipeline**: Executes a full (but short) training run using `run_training`, confirming that the training loop, validation, and model checkpointing work as expected.
