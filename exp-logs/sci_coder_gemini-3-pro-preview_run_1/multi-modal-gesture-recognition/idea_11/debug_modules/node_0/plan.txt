This script demonstrates the end-to-end usage of the provided machine learning pipeline for gesture recognition. It covers configuration setup, utility verification, data loading, model instantiation, training loop execution, and inference post-processing.

The script performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory and reduced hyperparameters (epochs, batch size) for a fast demonstration.
2.  **Utility Verification**: Validates helper functions like Run-Length Encoding (RLE) decoding and Levenshtein distance calculation with assertions.
3.  **Data Loading**: Initializes the `GestureDataset` and `DataLoader` using the provided CSV metadata, verifies batch shapes, and checks data integrity.
4.  **Model Initialization**: Instantiates the `RCGRNet` model and performs a forward pass with real batch data to verify tensor shapes and flow.
5.  **Training Loop**: Runs a short training session using the `Trainer` class to demonstrate the optimization process and model checkpointing.
6.  **Inference & Evaluation**: Loads the best saved model, performs inference on a validation batch, decodes the predictions, and computes the Levenshtein error rate.
