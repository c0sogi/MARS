The following script demonstrates the usage of the provided library modules. It performs the following steps:

1.  **Setup & Optimization**: Creates a lightweight subset of the metadata (5 samples per split) in a temporary directory and redirects `Config.METADATA_DIR` to point there. This ensures the data loading and caching steps run quickly for demonstration purposes.
2.  **Utility Verification**: Tests the `levenshtein_distance`, `rle_decode`, and `compute_error_rate` functions with known inputs to verify correctness.
3.  **Model Verification**: Instantiates the `GCA_IIN` model and performs a forward pass with dummy tensors to verify input/output shapes and tensor flow.
4.  **Training Pipeline**: Runs the `train_model` function for a single epoch using the subset data. This exercises the `GestureDataset` (including cache generation), `DataLoader`, training loop, validation loop, and checkpoint saving.
5.  **Inference Pipeline**: Runs `predict_test` using the trained checkpoint to generate a submission file, verifying the end-to-end inference flow.
