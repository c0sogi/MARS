Based on the comprehensive analysis of the accumulated lessons, I propose the **Global-Context Anchored Input-Injected Network (GCA-IIN)**. This solution introduces a structural innovation—**Dual-Injection Topology** (Local + Global)—to the recurrent backbone. It is designed to stabilize long-term sequence tracking while maintaining high-frequency segmentation precision, correcting the implementation flaws (CTC loss, absolute coordinates) that prevented similar previous concepts from succeeding.

# Model

The architecture is a **Multi-Stream Hybrid Network** that evolves the successful "Input-Injected" backbone by anchoring the deep recurrent layers with a global sequence summary.

1.  **Decoupled Input Stems:**
    We process modalities independently to prevent gradient dominance and allow specific feature extraction (Cite solution_lesson_node_00021).
    *   **Skeleton Stream:** Processes **Root-Relative** Joint Coordinates (Flattened) via `Linear Projection -> Temporal Conv1d(k=7) -> ReLU -> Dropout`. The kernel size of 7 ensures a robust local receptive field (Cite solution_lesson_node_00040), and the ordering ensures correct feature extraction (Cite solution_lesson_node_00010). We strictly avoid graph convolutions (Cite solution_lesson_node_00039) and explicit velocity inputs (Cite solution_lesson_node_00053).
    *   **Audio Stream:** Processes MFCCs via an identical stem tailored for audio dimensions.

2.  **Gated Fusion & Global Anchor (Structural Innovation):**
    *   **Fusion:** The outputs from both stems are concatenated and normalized via **Layer Normalization** (Cite solution_lesson_node_00011).
    *   **Context Gating:** We apply the **Context Gating** mechanism ($Y_t = X_t \odot \sigma(W X_t + b)$) immediately after fusion. This acts as a "Gate-Once" noise filter (Cite solution_lesson_node_00036, solution_lesson_node_00067).
    *   **Global Anchor:** We compute the **Global Average Pooling** of the gated sequence $Y$ (explicitly ignoring padded time-steps) to obtain a static context vector $G$. This vector captures the holistic "fingerprint" of the sequence, addressing the stability issues observed in long sequences (Cite solution_lesson_node_00079).

3.  **Dual-Injected Recurrent Backbone (Structural Innovation):**
    We employ a 2-layer **Bidirectional GRU** (Hidden Dim=256) with a **Dual-Injection** topology.
    *   **Layer 1:** Processes the Gated Fusion sequence $Y$. Output is $H_1$.
    *   **Layer 2:** Processes a composite input formed by the previous hidden state, the original local input, and the global anchor.
        *   $Input_2 = H_1 + \text{Proj}_{local}(Y) + \text{Proj}_{global}(G)$.
    *   **Rationale:** Standard Input Injection ($H_1 + Y$) provides high-frequency boundary cues (Cite solution_lesson_node_00070). Injecting the Global Anchor ($G$) stabilizes the internal state against drift over long durations, providing a robust "sequence prior" without the complexity of Attention mechanisms (Cite solution_lesson_node_00049). The projections decouple model width from input size (Cite solution_lesson_node_00061).

4.  **Non-Linear Output Head:**
    *   A non-linear MLP (`Linear -> ReLU -> Dropout -> Linear`) projects the backbone output to class probabilities (Cite solution_lesson_node_00051).

# Data

1.  **Preprocessing:**
    *   **Geometric Normalization:** Explicitly compute **Root-Relative Coordinates** (`Joint - HipCenter`) for all frames. Never use raw absolute coordinates (Cite solution_lesson_node_00079).
    *   **Audio Feature Extraction:** Extract MFCCs using a **Physics-Based Alignment**. Set the Hop Length to match the video frame rate ($16000/20 = 800$) and set the **FFT Window Size** significantly larger (e.g., `n_fft=2048`) to ensure temporal overlap (Cite solution_lesson_node_00080, solution_lesson_node_00054).
    *   **Robust Ingestion:** Implement strict shape-based validation (e.g., `if shape == (20, 3)`) to handle `.mat` file variability (Cite solution_lesson_node_00064).
    *   **Normalization:** Apply **Independent Z-score Normalization** to both modalities using global training statistics (Cite solution_lesson_node_00016).

2.  **Augmentation:**
    *   **Random Channel Masking:** Zero out ~10% of feature channels (Cite solution_lesson_node_00013).
    *   **Random Time Masking:** Zero out contiguous chunks (5-15 frames) to force reliance on the Global Anchor and hidden state (Cite solution_lesson_node_00040).

# Training

1.  **Loss Function:**
    *   **Supervised Padding:** Use Frame-wise Cross Entropy Loss and **do not mask** padded time-steps. Ensure the padding value corresponds to the "Background" class index to anchor null-state predictions (Cite solution_lesson_node_00076). **Do not use CTC Loss** (Cite solution_lesson_node_00083).
    *   **Label Smoothing (0.1):** To handle boundary ambiguity (Cite solution_lesson_node_00011).
    *   **Background Class Weight (0.5):** Maintain a moderate weight for the background class (Cite solution_lesson_node_00011).

2.  **Optimization Strategy:**
    *   **Micro-Batching:** Use a **Batch Size of 8** to maximize gradient updates per epoch (Cite solution_lesson_node_00050).
    *   **Packed Sequence Execution:** Strictly use `pack_padded_sequence` for the BiGRU forward pass to ensure correct backward context (Cite solution_lesson_node_00081).
    *   **Aggressive Regularization:** Use **Weight Decay = 0.05** (Cite solution_lesson_node_00050).
    *   **Scheduler:** AdamW with **Cosine Annealing** (Cite solution_lesson_node_00031).
    *   **Checkpointing:** Save the checkpoint minimizing the **Levenshtein Error Rate** (Cite solution_lesson_node_00025).

# Evaluation

1.  **Inference:**
    *   Pass test sequences through the GCA-IIN.
    *   Apply a **Median Filter** (window size 5) to smooth predictions (Cite solution_lesson_node_00005).
    *   **Decoding:** Use **Run-Length Encoding (RLE)** to generate the gesture list, filtering out the background class and segments shorter than 5 frames (Cite solution_lesson_node_00019).
