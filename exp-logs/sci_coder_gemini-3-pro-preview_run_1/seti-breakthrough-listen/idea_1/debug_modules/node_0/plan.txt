The following script demonstrates the end-to-end usage of the provided SETI Technosignature Detection library.

**Implementation Strategy:**
1.  **Configuration & Setup**: We first modify the `Config` class to run in `DEBUG` mode with minimal epochs and batch size. This ensures the demonstration completes quickly while still exercising the full pipeline. We also suppress warnings for cleaner output.
2.  **Data Loading**: We utilize `get_dataloaders` to initialize the data pipeline. We fetch a single batch to assert that the input shapes (images and targets) match the expected dimensions for the Spatial Difference CNN.
3.  **Model Verification**: We instantiate `SpatialDifferenceCNN`, move it to the active device (CPU or GPU), and perform a forward pass with the sample batch. We assert that the output logits have the correct shape.
4.  **Training Simulation**: We call `run_training` with `epochs=1` and `debug=True`. This validates the training loop, loss computation, optimizer step, and model checkpoint saving functionality.
5.  **Inference & Submission**: We execute `predict_test_set` to generate predictions using the saved model. We verify that the submission CSV is created and contains the required columns and data rows.
6.  **Metric Utility**: Finally, we test the `calculate_roc_auc` function with synthetic data to ensure the evaluation metric logic is correct.
