# Idea 3: Spatiotemporal 3D ResNet (R3D-18)

## Model
We propose a **3D Convolutional Neural Network (R3D-18)** to explicitly model the spatiotemporal structure of the cadence. Previous approaches failed because they either collapsed the temporal dimension, destroying drift information (Cite solution_lesson_node_00001), or stacked frames as channels in a 2D CNN, which aggregated features too early and failed to detect low-SNR modulation (Cite solution_lesson_node_00006).

The R3D-18 architecture treats the input as a 5D tensor of shape `(Batch, Channels=1, Depth=6, Height=273, Width=256)`, where "Depth" corresponds to the 6 cadence panels (ABACAD). By using **3D convolutional kernels** $(K_{depth} \times K_{height} \times K_{width})$, the model can:
1.  **Track Signal Trajectory:** Follow the Doppler-drifting "diagonal lines" across the 6 discrete time steps of the cadence, preserving the motion information that static 2D approaches ignore.
2.  **Learn Modulation Patterns:** The temporal depth of the kernels allows the network to learn specific ON-OFF-ON-OFF intensity changes (technosignatures) versus constant RFI, without averaging them out in the first layer.
The backbone will end with a 3D Global Average Pooling layer followed by a linear classifier.

## Data
The preprocessing pipeline is designed to format the data for 3D convolution while maintaining signal integrity:
1.  **Input Formatting:** Load the raw `(6, 273, 256)` numpy arrays. Unlike previous attempts that stacked these as channels or concatenated them spatially (Cite solution_lesson_node_00008), we will reshape the array to `(1, 6, 273, 256)` to represent a single-channel video sequence of 6 frames.
2.  **Normalization:** Apply instance-wise normalization (zero mean, unit variance) to the entire 3D volume to handle varying noise floors.
3.  **Augmentation:** We will apply **identical spatial augmentations** (flips, crops) to all 6 frames in the sequence to preserve the relative position of the signal. Crucially, we will apply **random frequency translations** (shifting the image up/down) to help the model generalize to signals appearing at different frequencies, as the "needle" location is not fixed.

## Training
The model will be trained using **Binary Cross-Entropy with Logits Loss** and the **AdamW optimizer**. Given the complexity of 3D convolutions, we will use a **OneCycleLR** scheduler to stabilize training. We will initialize the model weights from a standard video classification checkpoint (e.g., Kinetics-400) if available, or use Kaiming initialization, as the domain gap between natural video and spectrograms is large. We will monitor the validation ROC AUC and implement **Early Stopping**.

## Evaluation
For inference, test set snippets will be reshaped to `(1, 6, 273, 256)` and normalized using the same statistics as the training phase. The 3D CNN will process the sequence and output a probability score. This approach ensures that the temporal "blinking" logic (ON vs. OFF) and the frequency drift are evaluated simultaneously in a unified spatiotemporal feature space.
