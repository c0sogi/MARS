# Idea 2: Multi-Channel Deep Residual Network

## Model
We propose a **Multi-Channel ResNet-18**, a deep convolutional neural network adapted to process the full temporal cadence directly. Unlike the previous **Spatial Difference CNN**, which collapsed the time dimension via averaging and subtraction, this architecture modifies the input stem (the first convolutional layer) to accept **6 input channels** corresponding to the 6 panels of the cadence (ABACAD). This design allows the model to learn independent spatial features for "ON" and "OFF" observations and, crucially, preserves the sequential information necessary to detect non-stationary features like Doppler-drifting signals. By using a deep residual backbone, the model can capture complex, hierarchical patterns that a shallow custom CNN cannot. Cite solution_lesson_node_00001

## Data
The preprocessing pipeline will be fundamentally altered to strictly preserve the input dimensions:
1.  **Input Loading:** We will load the raw cadence snippets with shape `(6, 273, 256)`.
2.  **Channel Preservation:** Instead of computing a "Difference Map", we will pass the 6 panels directly as channels. This ensures that the specific trajectory of a moving signal across the "A" panels (channels 0, 2, 4) is retained, while allowing the network to learn to ignore static RFI present in the "B/C/D" panels (channels 1, 3, 5). Cite solution_lesson_node_00001
3.  **Normalization:** We will apply instance-wise normalization (zero mean, unit variance) to each sample independently to handle the varying intensity scales of the spectrograms.
4.  **Augmentation:** We will introduce spatial augmentations such as vertical/horizontal flips and random frequency shifts (translation along the frequency axis) to improve generalization, applied identically across all 6 channels to maintain temporal coherence.

## Training
The model will be trained using **Binary Cross-Entropy with Logits Loss**. We will utilize the **AdamW optimizer** combined with a **OneCycleLR** learning rate scheduler to ensure efficient convergence and regularization. Given the increased capacity of the ResNet-18 backbone compared to the previous shallow model, we will monitor the validation ROC AUC closely and employ **Early Stopping** to prevent overfitting. The training will run on the GPU, taking advantage of the optimized CUDA kernels for standard ResNet architectures.

## Evaluation
During inference, the test set snippets will undergo the same normalization and will be fed into the trained Multi-Channel ResNet-18. The model will output a single scalar logit for each 6-channel input, which will be converted to a probability using a sigmoid function. These probabilities will be mapped to their respective IDs for the final submission.
