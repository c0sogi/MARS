# Model
**Architecture: RGB-Temporal Dilated EfficientNet-B2**

I propose a structural evolution from a single-channel "Spectrogram-CNN" to a **3-Channel "Spectro-Temporal" CNN**. This design aligns the audio feature representation with the native 3-channel (RGB) architecture of standard vision backbones, explicitly encoding temporal dynamics without the instability of Recurrent Neural Networks (Cite solution_lesson_node_00035).

*   **Backbone (EfficientNet-B2):** We will retain the **EfficientNet-B2** backbone (Cite solution_lesson_node_00024).
    *   **Input Adaptation:** Instead of averaging weights to create a 1-channel input (Cite solution_lesson_node_00016), we will utilize the **native 3-channel input** initialized with the original **ImageNet RGB weights**.
        *   **Channel 1:** Log-Mel Spectrogram (Static spectral energy).
        *   **Channel 2:** **Delta Features** (First-order temporal derivative, representing velocity of spectral change).
        *   **Channel 3:** **Delta-Delta Features** (Second-order temporal derivative, representing acceleration).
    *   **Benefit:** This allows the model to utilize the pretrained color/texture correlation filters to detect dynamic speech patterns (e.g., formant transitions) immediately, rather than learning to infer motion from a static single-channel image.
*   **Resolution Preservation:** We will apply **Dilated Convolutions** (stride=1, dilation=2) in the final backbone stage. This preserves the temporal resolution (~6-7 frames) required to distinguish short phonemes, avoiding the feature collapse of standard striding (Cite solution_lesson_node_00009, Cite solution_lesson_node_00025).
*   **Head:** We will use **Attentive Pooling** to dynamically weight active speech segments and suppress background noise (Cite solution_lesson_node_00017).
*   **Output:** The model will output probabilities for **31+ Fine-Grained Classes** (all unique command words) rather than the compressed 12-class target set (Cite solution_lesson_node_00028).

# Data
**Preprocessing & Augmentation Pipeline:**
*   **Waveform Noise Injection:** We will inject background noise into the raw waveform *before* spectrogram generation (SNR 10-30dB, Prob 0.5) to force invariance to environmental conditions (Cite solution_lesson_node_00029).
*   **Dynamic Silence Synthesis:** We will synthesize the 'silence' class by randomly cropping background noise files (Cite solution_lesson_node_00001).
*   **3-Channel Feature Generation (GPU):**
    *   Generate Log-Mel Spectrograms: **128 Mels**, **1024 FFT** (64ms), **160 Hop** (10ms) (Cite solution_lesson_node_00005, Cite solution_lesson_node_00008).
    *   Compute **Delta** and **Delta-Delta** features on the GPU to create the 3-channel tensor.
*   **Balancing:** We will employ **Variance-Aware Balancing** (Cite solution_lesson_node_00026). Target commands will be upsampled to ~2,000, while the diverse auxiliary classes (the "Unknown" source) will be kept at their natural counts (~9,000 total) to preserve variance.

# Training
**Strategy:**
*   **GPU-Accelerated Regularization:**
    *   **SpecAugment:** Apply Time/Frequency masking to the 3-channel tensor (masking all channels identically) to force distributed feature learning (Cite solution_lesson_node_00003).
    *   **Mixup:** Apply Mixup with **$\alpha = 1.0$** (Cite solution_lesson_node_00016). This high-intensity regularization is critical for the multi-channel model.
    *   **Note:** All augmentations will be performed on the GPU to avoid the CPU data-loading bottlenecks identified in Lesson 34 (Cite solution_lesson_node_00034).
*   **Optimization:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing** learning rate scheduler (Cite solution_lesson_node_00003).
    *   **Model EMA (Exponential Moving Average):** We will maintain an EMA of the model weights (decay=0.999) during training. This stabilizes the decision boundaries formed under aggressive Mixup/Noise injection and often yields a performance boost similar to ensembling.
*   **Duration:** Train for **50 epochs** to ensure convergence of the 3-channel fusion features (Cite solution_lesson_node_00002).
*   **Validation:** Model selection will be based on **Fine-Grained Validation Accuracy** (31 classes) to ensure precise decision boundaries (Cite solution_lesson_node_00031).

# Evaluation
**Inference:**
*   Test clips will be processed into the same 3-Channel format (Mel, Delta, Delta2).
*   The model (using EMA weights) will predict probabilities for the 31+ fine-grained classes.
*   **Post-Hoc Mapping:** Map the fine-grained predictions to the final submission format (Cite solution_lesson_node_00028):
    *   Target Labels (`yes`, `no`...) $\rightarrow$ Target Labels.
    *   `silence` $\rightarrow$ `silence`.
    *   Auxiliary Labels (`bed`, `bird`...) $\rightarrow$ `unknown`.
