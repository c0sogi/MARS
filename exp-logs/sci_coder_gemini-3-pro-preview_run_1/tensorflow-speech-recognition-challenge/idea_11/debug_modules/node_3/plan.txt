The issue is that `torch.where(condition, x, y)` requires `condition` to be a PyTorch Tensor (e.g., a `BoolTensor`), but `lam > 0.5` evaluates to a Python boolean (or NumPy boolean) because `lam` is a scalar float returned by `np.random.beta`. Since the mixup coefficient `lam` is uniform across the batch, we can simply use a standard Python conditional expression to select the target tensor.
