Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and prepare the output directories (`./submission`).
2.  **Training Orchestration**: Instantiate the provided `Trainer` class from `library.trainer`. Execute the `train()` method, which manages the training loop, Stochastic Weight Averaging (SWA), and saves the best/SWA models. The training configuration (50 epochs) is retained to ensure the high accuracy threshold is met, leveraging the A100 GPU for speed.
3.  **Validation & Metric Calculation**: After training, load the SWA model and the validation data loader. Perform a full inference pass on the validation set to calculate the final multiclass accuracy. This metric determines whether the submission file is generated.
4.  **Failure Analysis**: Compute the error magnitude for each validation sample ($1 - P(\text{True Class})$). Extract audio signal features (Duration, RMS, Spectral Centroid, Zero Crossing Rate) from the raw audio files. Calculate and print the Pearson correlation between these features and the error magnitude to identify systematic weaknesses.
5.  **Submission Generation**: Compare the final validation accuracy against the strict threshold ($0.98729...$). If the threshold is exceeded, copy the submission file generated by the `Trainer` to the required `./submission/submission.csv` path.
