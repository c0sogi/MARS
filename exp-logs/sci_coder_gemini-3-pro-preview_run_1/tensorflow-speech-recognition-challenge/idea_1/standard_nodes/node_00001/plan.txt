The implementation strategy involves the following steps:

1.  **Initialization**: Set random seeds for reproducibility and configure the device (GPU/CPU) using the provided `Config` class.
2.  **Training Pipeline**: Execute the `run_training` function from the `library.trainer` module. This function orchestrates the entire training process, including dataset loading, model initialization, the training loop with early stopping, saving the best model weights, and generating the final submission file (`submission.csv`) for the test set.
3.  **Validation Evaluation**:
    *   Reload the validation dataset and the best-saved model weights.
    *   Perform inference on the full validation set to compute the Multiclass Accuracy.
    *   Print the `Final Validation Metric` in the required format.
4.  **Failure Analysis**:
    *   Analyze the validation results to identify patterns in errors.
    *   Extract simple audio features (Duration and RMS/Loudness) from a sample of the validation set.
    *   Calculate and print the correlation between the model's error (binary: correct vs. incorrect) and these input features to understand if clip length or volume affects performance.
