The following script demonstrates the end-to-end usage of the provided library components for the Speech Command Recognition task.

**Implementation Strategy:**
1.  **Configuration Setup**: We modify the global `Config` class attributes to enable debug mode (`debug=True`) and reduce the dataset size (`debug_sample_size=100`), batch size, and epoch counts. This ensures the demonstration runs quickly (under a few minutes) while exercising all code paths.
2.  **Data Loading**: We utilize `get_dataloaders()` to prepare training, validation, and test loaders. We verify the integrity of the data pipeline by asserting the shape of the generated batches (Mel-spectrogram dimensions).
3.  **Model Verification**: We instantiate the `DilatedEfficientNet` and perform a dummy forward pass to confirm that the architecture produces logits of the correct shape `(Batch, Num_Classes)`.
4.  **Loss Function Check**: We manually test the `DistillationLoss` to ensure it computes gradients correctly given student and teacher logits.
5.  **Full Pipeline Execution**: We initialize the `Trainer` and execute the `run()` method. This triggers the two-stage training process (Teacher training -> Student distillation) and generates a submission file.
6.  **Result Validation**: Finally, we verify that the submission file is created and follows the expected format.
