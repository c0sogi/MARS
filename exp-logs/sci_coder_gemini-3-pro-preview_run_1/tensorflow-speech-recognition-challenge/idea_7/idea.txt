Based on the accumulated lessons, I propose a structural evolution that shifts the learning paradigm from **Coarse-Grained Classification** (forcing diverse non-target sounds into a single "Unknown" bucket) to **Fine-Grained Classification with Post-Hoc Mapping**. This approach leverages the high variance of the "Unknown" class identified in Lesson 26 but resolves the optimization difficulty of learning a non-convex "garbage class" boundary.

# Model
**Architecture: Dilated EfficientNet-B2 with Attentive Pooling (Fine-Grained Output)**

*   **Backbone (Dilated EfficientNet-B2):** We will retain the **EfficientNet-B2** backbone due to its strong inductive bias for constrained training budgets (Cite solution_lesson_node_00024).
    *   **Initialization:** We will initialize with **ImageNet weights**, adapting the first layer by **averaging the RGB weights** to preserve learned feature detectors for the 1-channel spectrogram (Cite solution_lesson_node_00013, Cite solution_lesson_node_00016).
    *   **Resolution Preservation:** We will strictly apply **Dilated Convolutions** (dilation rate=2, stride=1) in the final stage to maintain a temporal resolution of ~6-7 frames. This is superior to FPNs for attention-based tasks (Cite solution_lesson_node_00025) and prevents the feature map collapse observed in standard backbones (Cite solution_lesson_node_00009).
*   **Head (Attentive Pooling):** We will use **Attentive Pooling** to dynamically weight relevant speech segments, effectively ignoring background noise (Cite solution_lesson_node_00017).
*   **Structural Innovation (Output Layer):** Instead of the standard 12 output units (10 targets + Silence + Unknown), the model will be modified to output **$N$ classes**, where $N$ is the total number of unique command folders in the training set (e.g., "bed", "bird", "cat", "happy", "left", "right"... approx. 30-35 classes). This allows the model to learn distinct features for "cat" vs. "bird" rather than struggling to map disparate audio signals to a single monolithic "Unknown" vector.

# Data
**Preprocessing:**
*   **Label Engineering:** The metadata generation will be altered to preserve the **original folder names** for all audio clips. We will **not** map non-target folders to "unknown" during training.
*   **Spectrograms:** We will generate Log-Mel Spectrograms with **128 Mel bands**, **N_FFT of 1024** (64ms), and a **Hop Length of 160** (10ms). This balances high frequency resolution (Cite solution_lesson_node_00005) with the temporal precision required for short phonemes (Cite solution_lesson_node_00008).
*   **Dynamic Silence Synthesis:** We will continue to **dynamically synthesize the 'silence' class** by randomly cropping 1-second segments from background noise files (Cite solution_lesson_node_00001).
*   **Balancing:** We will employ a **Natural Asymmetric Balancing** strategy (Cite solution_lesson_node_00026).
    *   Target commands (e.g., "up", "down") will be upsampled to a fixed count (e.g., 2000).
    *   Auxiliary classes (e.g., "bird", "bed") will be kept at their natural counts.
    *   This naturally results in the "Unknown" super-category having significantly more total samples than any single target class, satisfying the variance requirement without explicit complex sampling.

# Training
**Strategy:**
*   **Objective:** We will train using **Cross-Entropy Loss** over the full set of $N$ fine-grained classes.
*   **Regularization:** We will apply **SpecAugment** (Time/Freq masking) (Cite solution_lesson_node_00003) and **Mixup** with **$\alpha = 1.0$**. This high-intensity regularization is critical for preventing memorization in high-capacity models (Cite solution_lesson_node_00006, Cite solution_lesson_node_00016).
*   **Optimization:** We will use **AdamW** with a **Cosine Annealing** scheduler to ensure convergence despite the noise from Mixup (Cite solution_lesson_node_00003).
*   **Duration:** We will train for **40-50 epochs** to allow the model to learn the fine-grained distinctions between the auxiliary classes (Cite solution_lesson_node_00002).

# Evaluation
**Inference:**
*   The model will predict probabilities for all $N$ fine-grained classes.
*   **Post-Hoc Mapping:** We will map the predictions to the required 12 submission labels:
    *   If the predicted class is one of the 10 target commands (`yes`, `no`, `up`, `down`, `left`, `right`, `on`, `off`, `stop`, `go`), output that label.
    *   If the predicted class is `silence`, output `silence`.
    *   If the predicted class is any of the auxiliary labels (`bed`, `bird`, `cat`, etc.), output `unknown`.
*   This strategy simplifies the decision boundary for the network (learning "cat" is easier than learning "not-a-command") while producing the correct submission format.
