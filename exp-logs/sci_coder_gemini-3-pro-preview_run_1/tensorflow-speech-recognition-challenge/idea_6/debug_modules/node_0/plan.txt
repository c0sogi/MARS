The following script demonstrates the usage of the provided library components to train a speech command recognition model.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `TrainConfig` and `PathConfig` classes at runtime to enable `DEBUG` mode (using a tiny subset of data), reduce the number of epochs to 2, and redirect outputs to a dedicated `./working/demo_run` directory. This ensures the script executes quickly and doesn't overwrite existing work.
2.  **Data Loading Verification**: We utilize `get_dataloaders()` to fetch training and validation batches. We assert that the input tensors (Mel Spectrograms) and target labels have the expected shapes and value ranges.
3.  **Model Architecture Verification**: We instantiate the `FeaturePyramidEfficientNet` model and perform a forward pass with a dummy batch to verify that the output logits have the correct dimensions corresponding to the 12 classes.
4.  **Training Loop Execution**: We initialize the `Trainer` class and run the `fit()` method. This demonstrates the full training pipeline including Mixup augmentation, forward/backward passes, and validation.
5.  **Submission Generation**: We invoke `generate_submission()` to create a prediction file for the test set.
6.  **Output Validation**: Finally, we verify that the model checkpoint and submission CSV file were physically created and that the CSV follows the required format.
