The following script demonstrates the end-to-end pipeline for the Speech Command recognition task using the provided library.

**Strategy:**
1.  **Configuration Override**: We modify the global training parameters in memory to reduce the number of epochs and sample counts, ensuring the demonstration runs quickly (under a few minutes) while exercising all code paths (training, validation, SWA, inference).
2.  **Data Subsampling**: Instead of loading the full dataset, we manually load the metadata CSVs, sample a small fraction (e.g., 50 samples), and instantiate the `SpeechCommandsDataset` directly. This bypasses the time-consuming balancing logic used for the full training run.
3.  **Model Verification**: We instantiate the `DilatedEfficientNet` and perform a dummy forward pass to verify input/output tensor shapes and the custom `AttentivePooling` mechanism.
4.  **Training Execution**: We initialize the `Trainer` with the subsampled DataLoaders and execute the `fit()` method. This runs the training loop, validation, and the Stochastic Weight Averaging (SWA) phase.
5.  **Submission Generation**: We call `predict_and_submit()` to generate predictions on the subsampled test set and verify the output file format.
6.  **Assertions**: Throughout the script, assertions enforce expected behaviors (tensor shapes, file existence, loss reduction).
