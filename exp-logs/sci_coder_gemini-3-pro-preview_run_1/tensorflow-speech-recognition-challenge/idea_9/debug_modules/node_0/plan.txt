The following script demonstrates the complete pipeline for the Speech Command Recognition task using the provided library.

### Implementation Strategy
1.  **Configuration Override**: We dynamically modify `Config.BATCH_SIZE` and `Config.EPOCHS` to small values (8 and 1, respectively) to ensure the demonstration runs quickly.
2.  **Component Verification**:
    *   **Transforms**: We verify the `DualChannelProcessor` by passing a random tensor and asserting the output spectrogram shape matches the expected dimensions `(2, 128, 101)`.
    *   **Data Loading**: We use `get_dataloaders` with a `debug_subset_size` of 50 to load a tiny fraction of the data. We assert that the `MixupCollator` correctly produces 4D inputs and one-hot encoded targets.
    *   **Model**: We perform a forward pass with `DualResEfficientNet` to confirm it accepts the dual-channel input and outputs class logits.
3.  **Training Loop**: We instantiate the `Trainer` and run `fit()` for one epoch. We verify that the training completes without error and saves a `best_model.pth`.
4.  **Inference**: We execute `generate_submission`, which loads the trained model and generates predictions for the test set. We validate the output CSV format and ensure all predicted labels are within the allowed 12 classes.
