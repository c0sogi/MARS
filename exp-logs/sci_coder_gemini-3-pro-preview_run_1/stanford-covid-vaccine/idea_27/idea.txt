Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Synchronized-Augmented Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that shifts focus from architectural novelty to **Capacity Maximization** and **Data Fidelity**. It synthesizes the robust "Wide-Stream" backbone with a novel "Synchronized Structural Augmentation" paradigm to resolve the regularization conflicts identified in Lesson 00067, allowing us to safely scale the model width as recommended in Lesson 00022.

# Model
**Architecture: Wide-Stream Residual BiGRU with Scalar Aggregation**
We will construct a high-capacity deep recurrent network optimized for information flow and structural fidelity.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide. Crucially, we will maintain **High-Dimensional Embeddings (e.g., 128)** for all inputs to prevent the information bottleneck identified in **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or RBFs **Cite solution_lesson_node_00042**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will increase the stream width $W$ to **512** (up from 384). Lesson 00022 proved that width is the primary driver of performance, and Lesson 00065 showed that "Shallow and Wide" outperforms "Deep and Narrow". The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=512$ throughout (BiGRU hidden size 256 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** acts as a depth ensemble and is superior to dynamic gating for noisy data **Cite solution_lesson_node_00061** and dense concatenation **Cite solution_lesson_node_00055**. We use iterative accumulation for memory efficiency **Cite solution_lesson_node_00063**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053** and keep the head simple to prevent overfitting **Cite solution_lesson_node_00048**.

# Data
*   **Synchronized Structural Augmentation (Feature Engineering Innovation)**:
    *   To address the failure of partial structural dropout **Cite solution_lesson_node_00067**, we will implement a logically consistent augmentation strategy.
    *   During training, with probability $p$ (e.g., 0.15), we will drop a base pair $(i, j)$.
    *   **Synchronization**: When an edge is dropped, we will **simultaneously**:
        1.  Set the Pairing Distance embedding for $i$ and $j$ to the value corresponding to $0$ (Unpaired).
        2.  Update the **Loop Type** embedding for $i$ and $j$ to a generic "Unpaired/External" token.
    *   **Rationale**: This prevents feature conflicts (e.g., a "Stem" loop type with "0" distance) that confused previous models. It forces the model to learn robust features from the sequence context when structural data is unreliable, acting as a powerful regularizer for the high-capacity backbone.

*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** mask any input sequence tokens **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW with **High Weight Decay (e.g., 0.01)** to constrain the 512-width backbone **Cite solution_lesson_node_00060**.
*   **Scheduler**: **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.
*   **Checkpointing**: Save the model with the **lowest Validation MCRMSE**, rejecting SWA/tail-averaging **Cite solution_lesson_node_00060**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model (Augmentation disabled). Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
