Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the `Config` class, setting a reduced number of epochs (10) to ensure the baseline runs quickly within the time limit. Set random seeds for reproducibility.
2.  **Data Loading**: Utilize `get_dataloader` to load training and validation data, enabling caching (`load_cached_data=True`) to speed up preprocessing.
3.  **Model Training Loop**: Implement a custom training loop using `train_fn` and `eval_fn` from `library.engine`. This allows granular control over saving the best model and tracking performance without relying on the pre-packaged `run_training` function which unconditionally generates submissions.
4.  **Final Evaluation**: After training, load the best saved model state and compute the MCRMSE on the full validation set. Print the result in the required format.
5.  **Failure Analysis**:
    *   Extract validation predictions and ground truth.
    *   Calculate the Root Mean Squared Error (RMSE) for each sample individually.
    *   Load the validation metadata (from `val.parquet`) to extract features like Signal-to-Noise Ratio (SNR), Sequence Length, and calculate GC content and Structure Density (paired bases).
    *   Compute and print the Pearson correlation between these features and the sample-wise RMSE to identify sources of error.
6.  **Conditional Submission**: Check if the final validation metric is strictly lower than the threshold `0.6176461577`. If satisfied, invoke `generate_submission` to create the `submission.csv` file.
