This script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:

1.  **Setup & Configuration**: Overrides the default `Config` to use a temporary directory and reduces hyperparameters (epochs, batch size) for a fast execution.
2.  **Data Preparation**: Creates "mini" subsets of the provided metadata Parquet files to simulate a quick training cycle.
3.  **Component Verification**:
    *   **Dataset/DataLoader**: Verifies that data is loaded correctly and batches have the expected shapes.
    *   **Model**: Instantiates the `RNAModel` and verifies the forward pass output dimensions.
    *   **Metric**: Manually validates the `MCRMSE` calculation with known tensors.
4.  **Training Loop**: Runs the `train_and_evaluate` engine on the mini-dataset.
5.  **Inference & Submission**: Generates predictions using the trained model and formats them into the required CSV submission structure.
