Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Channel-Weighted Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that maximizes model capacity (addressing Lesson 00022) while correcting the regularization flaws that hindered previous wide models (Lesson 00070), and refines the aggregation mechanism to be feature-specific without the overfitting risks of dense concatenation.

# Model
**Architecture: Channel-Weighted Wide-Stream Residual BiGRU**
We will construct a high-capacity recurrent network optimized for deep information flow and precise feature selection.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide, maintaining **High-Dimensional Embeddings (e.g., 128)** to prevent information bottlenecks **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or RBFs **Cite solution_lesson_node_00042**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. Lesson 00022 proved that width is the primary driver of performance. The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks** (adhering to the "Shallow and Wide" principle **Cite solution_lesson_node_00065**).
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=512$ throughout (BiGRU hidden size 256 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**. We strictly use pure RNN blocks, avoiding interleaved MLPs which degrade performance **Cite solution_lesson_node_00047**.

*   **Channel-Wise Layer Aggregation (Structural Innovation)**:
    *   We will evolve the "Scalar Mixture" (Idea 19) into a **Channel-Wise Mixture**.
    *   Instead of learning a single scalar weight $w_l$ for each layer $l$, we will learn a **weight vector** $W_l \in \mathbb{R}^{C}$ (where $C=512$).
    *   The aggregated output is $h_{final} = \sum_{l=0}^{L} \text{Softmax}(W, dim=0)_l \odot h_l$.
    *   **Rationale**: Standard Scalar Mixture forces the model to assign the same importance to a layer for *all* features. Dense Concatenation (Idea 21) allows full flexibility but explodes the parameter space of the head. **Channel-Wise Aggregation** strikes the optimal balance: it allows the model to select specific features from specific depths (e.g., "keep the local motif features from Layer 1, but the global fold features from Layer 6") while maintaining the **Global Static** property required for noisy data **Cite solution_lesson_node_00061** and preserving the aligned vector space of the residual stream **Cite solution_lesson_node_00055**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053** and keep the head simple **Cite solution_lesson_node_00048**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** mask any input sequence tokens or perform auxiliary Masked Language Modeling **Cite solution_lesson_node_00020**.
    *   **No Augmentation**: Avoid Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly correct the failure of previous wide models by reducing weight decay. RNNs are highly sensitive to L2 penalties; a value of 1e-2 (used in Idea 28) suppresses the recurrent signal, while 1e-4 allows the 512-width model to train effectively **Cite solution_lesson_node_00070**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.
*   **Checkpointing**:
    *   Save the model with the **lowest Validation MCRMSE**, rejecting SWA/tail-averaging to avoid overfitting artifacts **Cite solution_lesson_node_00060**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
