Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Context-Modulated Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that enhances the "Current Best" backbone by refining the input representation through **Geometric-Context Modulation**. This addresses the need for feature interaction (Lesson 00110) and proportional representation (Lesson 00099) while strictly adhering to the stability protocols (Gradient Clipping, Low Weight Decay, No Stem Dropout) that define the state-of-the-art.

# Model
**Architecture: Context-Modulated Wide-Stream Residual BiGRU**
We will construct a deep recurrent network that conditions geometric features on structural context before fusing them into a robust, high-capacity backbone.

*   **Proportional Input Embeddings**: We will implement the **Heterogeneous Feature Embedding** strategy to balance information content with parameter efficiency **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or discrete bins **Cite solution_lesson_node_00114**.

*   **Geometric-Context Modulation (Structural Innovation)**:
    *   Before concatenation, we will apply **Feature-wise Linear Modulation (FiLM)** to the Distance Embeddings, conditioned on the Loop Type Embeddings.
    *   **Mechanism**: The Loop embedding for each position is projected to a scale vector $\gamma$ and shift vector $\beta$. The Distance embedding is modulated: $E_{dist}' = \gamma \odot E_{dist} + \beta$.
    *   **Rationale**: The physical implication of a "distance of 5" varies significantly depending on the structural context (e.g., inside a tight hairpin vs. a long stem). This modulation allows the model to adapt the geometric inductive bias dynamically based on the local topology, enhancing feature interaction without the optimization downsides of dual-stream processing **Cite solution_lesson_node_00110**.

*   **Early Fusion & Recurrent Stem**:
    *   The Sequence, Loop, and Modulated Distance embeddings are **concatenated** (Total Dim 256). We strictly avoid independent normalization **Cite solution_lesson_node_00102**.
    *   The fused input is projected via a single **BiGRU layer** to the model's residual stream width $W=384$.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem to preserve the fidelity of the initial projection **Cite solution_lesson_node_00109**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We **maintain the full residual stream width** $W=384$ throughout (BiGRU hidden size 192 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiGRU but before the residual addition. This is strictly superior to Zoneout **Cite solution_lesson_node_00076**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is critical for stabilizing the deep recurrent backbone **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
