Based on the analysis of the previous experiments and the derived lessons, I propose a **Hybrid CNN-BiGRU** strategy. This approach represents a structural evolution that synthesizes the strengths of the baseline CNN (local motif detection) and the current best Bi-GRU (global sequential context), while adhering to the constraints required for small-data regimes.

# Model
**Architecture: 1D-ResNet + Bidirectional GRU Hybrid**
We will construct a two-stage encoder that explicitly models both the local chemical interactions and the global folding stability of the RNA molecule.

*   **Input Embeddings**: We will retain the multi-channel embedding strategy (Sequence, Structure, Predicted Loop Type) which has proven effective. These features will be embedded and concatenated to form the input tensor.
*   **Stage 1: Local Feature Extractor (CNN)**: The first stage will consist of a stack of **Residual 1D Convolutional Blocks (1D-ResNet)**.
    *   **Rationale**: RNA degradation is heavily influenced by "local chemical context" (neighboring bases and immediate structural state). While the Bi-GRU can learn these, Convolutional Neural Networks have a strong **inductive bias for locality**, making them far more efficient at extracting local $k$-mer motifs than Recurrent networks **Cite solution_lesson_node_00009**. This stage effectively acts as a learnable feature engineer that feeds higher-level motif representations to the next stage.
*   **Stage 2: Global Context Aggregator (Bi-GRU)**: The output of the CNN stage will be fed into a **Bidirectional GRU**.
    *   **Rationale**: As established, local features are insufficient for predicting stability in folded polymers where distant bases interact. The Bi-GRU ensures the model maintains a **Global Receptive Field** and allows information to propagate across the entire 107-nucleotide sequence **Cite solution_lesson_node_00004**. By placing the RNN *after* the CNN, we process a sequence of rich structural motifs rather than raw nucleotides, potentially easing the optimization landscape.
    *   This choice also respects the lesson to **prioritize sequential inductive biases** over flexible but data-hungry architectures like Transformers in this small-data regime (<2,500 samples) **Cite solution_lesson_node_00010**.
*   **Output Head**: A shared Multi-Layer Perceptron (MLP) will project the hidden states from the Bi-GRU to the 5 target degradation values.

# Data
*   **Full-Context Processing**: We will process the complete 107-nucleotide sequence for every sample. We will **not crop** the input sequences to the scored length (68), as the downstream regions contain structural information essential for the correct folding of the upstream scored regions **Cite solution_lesson_node_00002**.
*   **Preprocessing**: The categorical text inputs (`sequence`, `structure`, `predicted_loop_type`) will be integer-encoded. The `structure` input will be treated as a feature channel rather than a graph topology, avoiding the noise issues associated with Graph Neural Networks on predicted structures **Cite solution_lesson_node_00009**.

# Training
*   **Masked Loss Function**: We will use a **Masked Mean Squared Error (MSE)** loss. The model will output predictions for all 107 positions to maintain the integrity of the sequence processing, but the loss will be calculated by applying a binary mask that zeros out the error for positions $>67$ (and any other unscored positions). This allows the model to utilize the full structural context during the forward pass while optimizing only against valid ground truth labels **Cite solution_lesson_node_00002**.
*   **Optimizer**: We will use the **AdamW** optimizer with a standard learning rate (e.g., 1e-3) and a ReduceLROnPlateau scheduler to fine-tune the weights as the loss converges.

# Evaluation
*   **Inference**: The test set sequences (length 107) will be passed through the Hybrid CNN-BiGRU model.
*   **Formatting**: The model will output a tensor of shape `(N_samples, 107, 5)`. We will flatten this tensor to match the `id_seqpos` format required by the submission file. Predictions for indices 68-106 will be included in the submission file to meet format requirements, even though they are not scored.
