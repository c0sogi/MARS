Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose an **Uncertainty-Aware Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that enhances the robust "Wide-Stream" backbone (proven essential in Lesson 00022) by integrating a **Dual-Head Architecture** to leverage the previously unused experimental error data. This provides a structural mechanism to regularize the model against noise without the pitfalls of sample weighting or robust loss functions.

# Model
**Architecture: Uncertainty-Aware Wide-Stream Residual BiGRU**
We will construct a high-capacity deep recurrent network that simultaneously learns to predict degradation rates and experimental uncertainty, forcing the shared backbone to encode signal fidelity features.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide. We will strictly maintain **High-Dimensional Embeddings (128)** to prevent the information bottleneck identified in **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$.
    *   **Capacity Control**: We will set the stream width $W$ to **384**. This balances the need for capacity **Cite solution_lesson_node_00022** with the risk of overfitting observed at width 512 **Cite solution_lesson_node_00081**. The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=384$ throughout (BiGRU hidden size 192 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Regularization**: We will apply **Inter-Layer Dropout (p=0.1)** after the BiGRU in each block, which is superior to Zoneout for this task **Cite solution_lesson_node_00076**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**, dense concatenation **Cite solution_lesson_node_00055**, or channel-wise weighting **Cite solution_lesson_node_00073**. We strictly exclude raw input embeddings from this mixture **Cite solution_lesson_node_00092**.

*   **Dual Output Heads (Structural Innovation)**:
    *   The aggregated context vector is fed into **two parallel Linear Projections**:
        1.  **Value Head**: Predicts the 3 scored targets (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
        2.  **Uncertainty Head**: Predicts the corresponding 3 error columns (`reactivity_error`, `deg_error_Mg_pH10`, `deg_error_Mg_50C`).
    *   **Rationale**: By sharing the backbone and aggregation layers **Cite solution_lesson_node_00053**, we force the model to learn features that explain both the signal and its reliability. This acts as a powerful regularizer, preventing the model from overfitting to noisy samples (which will have distinct structural signatures captured by the Uncertainty Head) without distorting the primary gradient via sample weighting **Cite solution_lesson_node_00011**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` (and their errors) from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Multi-Task MSE**: $L = \text{MSE}(y, \hat{y}) + \lambda \cdot \text{MSE}(\sigma_{GT}, \hat{\sigma})$.
    *   We use the provided `*_error_*` columns as ground truth $\sigma_{GT}$.
    *   **Loss Type**: Strictly use **MSE (L2)** for both terms. Reject "Robust" losses to ensure alignment with the evaluation metric **Cite solution_lesson_node_00012**.
    *   **Masking**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions from the **Value Head** for the 3 scored columns and fill unscored columns with 0.0. The Uncertainty Head is ignored during inference.
