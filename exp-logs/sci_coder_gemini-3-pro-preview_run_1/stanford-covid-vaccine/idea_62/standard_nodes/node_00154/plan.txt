Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Environment & Configuration**: Initialize the environment by setting random seeds for reproducibility and detecting the available computation device (CUDA/CPU). Import necessary modules from the provided library files (`config`, `dataset`, `model`, `engine`, `loss`).
2.  **Data Pipeline**: Use `get_dataloaders` to efficiently load training, validation, and test datasets. This leverages the pre-computed Parquet metadata and caching mechanisms implemented in the library.
3.  **Model Training**: Instantiate the `RNA_Model` (Sequence-Gated Wide-Stream Residual BiGRU). Configure the `AdamW` optimizer and `CosineAnnealingLR` scheduler as specified. Execute the training loop using the `fit` function, which handles training epochs, validation, and checkpointing the best model.
4.  **Validation & Assessment**:
    *   Reload the best model checkpoint.
    *   Compute the final MCRMSE on the validation set and print it in the required format.
    *   **Failure Analysis**: Extract validation predictions and ground truth. Calculate sample-wise error metrics. Load the validation metadata (including signal-to-noise ratios and sequence properties) and compute Pearson correlations between the model's error and these features to identify systematic weaknesses.
5.  **Submission Generation**:
    *   Check if the validation metric meets the threshold (< 0.6176461577).
    *   If successful, run inference on the test set in `eval` mode with `no_grad`.
    *   Format the predictions into the required `id_seqpos` structure, mapping the 3 model outputs to the correct columns and filling the unscored columns (`deg_pH10`, `deg_50C`) with zeros.
    *   Save the result to `submission.csv`.
