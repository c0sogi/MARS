This script demonstrates the end-to-end usage of the provided library files for the RNA degradation prediction task. It covers feature engineering verification, dataset loading, model instantiation, forward pass validation, loss calculation, a short training run, and submission generation.

The strategy is as follows:
1.  **Configuration**: Create a customized `Config` object for a quick demonstration run (fewer epochs, specific output directory).
2.  **Feature Engineering**: Validate the helper functions in `library.features` that process RNA secondary structures.
3.  **Dataset**: Instantiate the `RNADataset` to ensure data loading and preprocessing works correctly, verifying tensor shapes.
4.  **Model & Loss**: Initialize the `RNAMultiTaskBiGRU` model and `JointAlignedLoss`, performing a dummy forward pass to check input/output compatibility.
5.  **Training**: Execute the `train_model` function for a minimal number of epochs to demonstrate the training loop.
6.  **Inference**: Run `predict_and_submit` to generate a submission file and verify its format.
