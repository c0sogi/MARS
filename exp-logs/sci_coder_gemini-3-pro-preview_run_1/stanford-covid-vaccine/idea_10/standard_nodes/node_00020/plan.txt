Here is the execution plan and the complete Python script `runfile.py`.

### Execution Plan

1.  **Configuration**: Initialize a custom configuration inheriting from the provided `Config` class. We will adjust `EPOCHS` to 15 to ensure the "fast baseline" requirement is met while allowing sufficient convergence for the deep BiGRU architecture. We will set the working directory to `./working/execution`.
2.  **Training**: Execute the `train_model` function from the library. This handles the training loop, validation checks, and saves the best model checkpoint to the working directory.
3.  **Validation & Metric**:
    *   Retrieve the best MCRMSE score returned by the training function.
    *   Print the metric in the strictly required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Reload the best model and the validation dataset.
    *   Perform inference on the full validation set to generate predictions.
    *   Calculate the Root Mean Squared Error (RMSE) for each sample individually.
    *   Load the validation metadata (from `./metadata/val.parquet`) to access auxiliary features like `signal_to_noise` and sequence properties.
    *   Compute and print the Pearson correlation between the sample-wise Error and these features to identify sources of model failure.
5.  **Submission**:
    *   Check if the `Final Validation Metric` is below the threshold `0.6226052641868591`.
    *   If successful, execute `predict_and_submit` to generate predictions for the test set and save `submission.csv`.
