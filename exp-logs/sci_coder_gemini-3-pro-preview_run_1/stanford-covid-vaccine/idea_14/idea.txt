Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Channel-Attentive Distance-Aware Residual BiGRU** strategy. This approach represents a structural evolution of the "Distance-Aware Residual BiGRU" (Idea 8) by integrating a **Squeeze-and-Excitation (SE)** mechanism directly into the recurrent blocks. This enhances the model's ability to utilize its high-dimensional feature space by explicitly modeling channel-wise dependencies derived from global context, reinforcing the "Global Receptive Field" requirement without the pitfalls of Transformers or CNNs.

# Model
**Architecture: Channel-Attentive Deep Residual BiGRU**
We will construct a deep recurrent network where each residual block incorporates a channel-attention mechanism to dynamically recalibrate feature maps based on the global sequence context.

*   **Input Embeddings**: We will retain the successful feature set from the Current Best Solution:
    *   **Sequence & Loop**: Learnable embeddings for nucleotide identity (A, G, C, U) and predicted loop type. We will strictly use **atomic character tokens**, avoiding K-mers which dilute data in small regimes **Cite solution_lesson_node_00028**.
    *   **Signed Sinusoidal Pairing Distance**: We will use the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ (preserving directionality) using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**, **Cite solution_lesson_node_00024**. This provides implicit structural bias without the complexity of graph edges **Cite solution_lesson_node_00023**.
*   **Backbone: SE-Res-BiGRU**:
    *   The encoder will consist of **5-6 layers** of Bidirectional GRUs.
    *   **Pre-LayerNorm Configuration**: We will apply Layer Normalization before the GRU (`x + Block(Norm(x))`) to ensure stable gradient flow in this deep network **Cite solution_lesson_node_00017**.
    *   **Squeeze-and-Excitation (SE) Integration (Innovation)**: Inside each residual block, immediately after the BiGRU layer and before the residual addition, we will insert an **SE Block** adapted for 1D sequences.
        *   **Squeeze**: Perform Global Average Pooling across the sequence length dimension to compress the output into a single channel descriptor vector $(1, C)$. This captures the global distribution of features (e.g., "this sequence is GC-rich" or "contains many stems") **Cite solution_lesson_node_00004**.
        *   **Excitation**: Pass this vector through a bottleneck MLP (FC $\to$ ReLU $\to$ FC $\to$ Sigmoid) to generate channel-wise weights.
        *   **Scale**: Multiply the original BiGRU output by these weights. This allows the model to selectively emphasize specific feature channels (e.g., "stem-detectors") based on the global context, maximizing the utility of the **High Hidden Dimension (384)** **Cite solution_lesson_node_00022**.
*   **Output Head**:
    *   A shared MLP projecting the final hidden states to **3 output channels**, corresponding strictly to the scored targets (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: We will process the complete 107-nucleotide sequence for every sample. We will **not crop** inputs, ensuring the model utilizes downstream structural information that causally affects the scored region **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. We will only train on the three scored columns to prevent high-variance unscored noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: We will **not** mask any input tokens or perform auxiliary Masked Language Modeling, as it corrupts the precision regression signal **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE), preventing the under-prediction of outliers **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally. We will **not** weight samples by their signal-to-noise ratio, avoiding the distribution mismatch that degrades performance on unweighted metrics **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler.

# Evaluation
*   **Inference**: The test sequences (length 107) will be passed through the model to generate predictions for the 3 scored columns.
*   **Formatting**: We will construct the final submission file by placing the predictions into their respective columns and filling the unscored columns (`deg_pH10`, `deg_50C`) with 0.0. The results will be flattened to the `id_seqpos` format.
