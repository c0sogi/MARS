Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Log-Space Uncertainty-Aware Wide-Stream BiGRU**. This strategy represents a structural evolution that resolves the "Destructive Interference" failure of Idea 36 (Lesson 00094) by implementing a mathematically robust **Homoscedastic Multi-Task Learning** framework. It leverages the previously discarded experimental error data to regularize the high-capacity backbone without distorting the primary gradients, strictly adhering to the architectural constraints established in the lessons.

# Model
**Architecture: Log-Space Uncertainty-Aware Wide-Stream Residual BiGRU**
We will construct a high-capacity deep recurrent network that simultaneously learns signal and signal-fidelity features, forcing the backbone to learn robust representations that distinguish structural degradation from experimental noise.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide. We will strictly maintain **High-Dimensional Embeddings (128)** to prevent the information bottleneck identified in **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers which dilute data in small regimes **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or RBFs **Cite solution_lesson_node_00042**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$.
    *   **Width**: We will set $W=384$. This balances the need for capacity **Cite solution_lesson_node_00022** with the risk of overfitting observed at width 512 **Cite solution_lesson_node_00081**. The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=384$ throughout (BiGRU hidden size 192 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Regularization**: We will apply **Inter-Layer Dropout (p=0.2)** after the BiGRU in each block, which is superior to Zoneout for this task **Cite solution_lesson_node_00076**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061** or dense concatenation **Cite solution_lesson_node_00055**. We strictly exclude raw input embeddings from this mixture **Cite solution_lesson_node_00092**.

*   **Dual Output Heads (Structural Innovation)**:
    *   The aggregated context vector is fed into **two parallel Linear Projections**:
        1.  **Value Head**: Predicts the 3 scored targets (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
        2.  **Uncertainty Head**: Predicts the **Log-Transformed** error values for the same 3 columns.
    *   **Rationale**: Sharing the backbone **Cite solution_lesson_node_00053** forces the model to encode features that explain both the value and its reliability. This acts as a regularizer against noisy samples without the need for destructive sample weighting **Cite solution_lesson_node_00011**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **Auxiliary Target Transformation**: We will extract the corresponding error columns (`reactivity_error`, etc.) and apply a **Log-Transformation**: $y_{err} = \log(\sigma_{GT} + \epsilon)$. This compresses the dynamic range of the errors (which caused the failure in **Cite solution_lesson_node_00094**) to a scale comparable to the primary targets.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function: Homoscedastic Multi-Task Loss**:
    *   We will implement a learnable loss weighting to balance the primary and auxiliary tasks automatically, avoiding manual tuning failure **Cite solution_lesson_node_00094**.
    *   $L = \frac{1}{2} e^{-s_1} \mathcal{L}_{val} + \frac{1}{2} e^{-s_2} \mathcal{L}_{unc} + \frac{1}{2}(s_1 + s_2)$
    *   Where $s_1, s_2$ are learnable scalar parameters (initialized to 0).
    *   $\mathcal{L}_{val} = \text{MSE}(y_{pred}, y_{GT})$ (Primary Targets).
    *   $\mathcal{L}_{unc} = \text{MSE}(\sigma_{pred}, \log(\sigma_{GT} + \epsilon))$ (Auxiliary Targets).
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **Masking**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.

*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.
*   **Checkpointing**:
    *   Save the model with the **lowest Validation MCRMSE** (calculated on primary targets only), rejecting SWA/tail-averaging **Cite solution_lesson_node_00060**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions from the **Value Head** for the 3 scored columns and fill unscored columns with 0.0. The Uncertainty Head is ignored during inference.
