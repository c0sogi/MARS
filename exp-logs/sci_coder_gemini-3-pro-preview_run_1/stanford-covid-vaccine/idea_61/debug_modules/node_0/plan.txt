This script demonstrates the end-to-end workflow for the RNA degradation prediction task using the provided library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to create a lightweight "demo" environment (reduced epochs, batch size, and dataset size) and sets up a dedicated working directory.
2.  **Data Loading**: Uses `get_dataloaders` to process the metadata and create PyTorch DataLoaders. It verifies the shape and integrity of the input batches.
3.  **Model Initialization**: Instantiates the `StabilizedWideBiLSTM` model and performs a dummy forward pass to verify output dimensions.
4.  **Training Loop**: Executes a shortened training routine using `train_model`, which includes training epochs and validation steps.
5.  **Inference & Submission**: Generates predictions on the test set using `generate_submission` and validates the format of the resulting CSV file.
