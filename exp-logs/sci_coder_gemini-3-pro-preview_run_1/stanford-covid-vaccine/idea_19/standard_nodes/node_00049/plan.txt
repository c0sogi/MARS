Here is the implementation strategy for the `runfile.py` script:

1.  **Configuration & Setup**: Import the necessary classes and functions from the provided library files (`config`, `utils`, `dataset`, `model`, `engine`). Set the `Config.EPOCHS` to 20 to ensure the training completes quickly while still providing a robust baseline.
2.  **Training**: Execute the `run_training()` function from `library.engine`. This handles the training loop, validation at each epoch, and saves the best model checkpoint to the working directory.
3.  **Failure Analysis**: Implement a custom function `perform_failure_analysis` that:
    *   Loads the best trained model and the validation dataset.
    *   Generates predictions for the validation set.
    *   Calculates the Root Mean Squared Error (RMSE) for each sample.
    *   Loads the validation metadata to retrieve sample attributes (Signal-to-Noise Ratio, SN Filter, Sequence Composition).
    *   Computes and prints the Pearson correlation between the sample-wise RMSE and these attributes to identify sources of error.
    *   Returns the exact MCRMSE score on the validation set.
4.  **Metric Reporting**: Print the final validation metric in the strictly required format: `Final Validation Metric: <value>`.
5.  **Submission Logic**: Compare the final validation metric against the threshold (0.6226052641868591). If the model performs better (lower score), call `predict_and_submit()` from `library.engine` to generate the `submission.csv` file for the test set.
