The issue is that `library/config.py` functions as both a configuration definition and an executable script, calling `train_and_predict()` at the global scope (line 473). When `runfile.py` imports `ModelConfig`, this function executes immediately, attempting to train a legacy model (`RBFEncodedBiGRU`) that fails because `ModelConfig` lacks the required `num_rbf` attribute. To fix this, I will guard the execution block with `if __name__ == "__main__":`, ensuring the training logic only runs when the file is executed directly, not when imported as a module.
