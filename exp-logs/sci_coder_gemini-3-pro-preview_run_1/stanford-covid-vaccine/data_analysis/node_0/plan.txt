Here is the implementation strategy and the complete Python script for the Exploratory Data Analysis.

### Implementation Strategy

1.  **Setup & Loading**:
    *   Initialize random seeds for reproducibility.
    *   Load the training data from `./metadata/train.parquet`.
    *   Identify target columns (`reactivity`, `deg_*`) which contain vector data (lists of floats) and input columns (sequences).

2.  **Target Variable Analysis (Regression)**:
    *   Since targets are vectors of length 68, convert them into NumPy arrays for efficient computation.
    *   Calculate global statistics (Mean, Std, Min, Max) for each of the 5 target variables.
    *   Compute Skewness and Kurtosis to assess the normality of the degradation rates.

3.  **Input Data Analysis (Text/Sequence Modality)**:
    *   Treat `sequence`, `structure`, and `predicted_loop_type` as text data.
    *   **Lengths**: Verify sequence lengths (expected 107).
    *   **Vocabulary**: Analyze unique characters (e.g., A, G, C, U for sequence; (, ), . for structure).
    *   **Tabular Metadata**: Analyze `signal_to_noise` and `SN_filter` as numerical/categorical tabular features.

4.  **Feature/Signal Relationships**:
    *   **Feature Engineering**: specific to RNA, derive scalar features for each sample to enable correlation and Random Forest analysis:
        *   Nucleotide counts (A, C, G, U).
        *   Structure counts (Paired '(', Unpaired '.').
        *   Loop type counts (Stem, Hairpin, etc.).
    *   **Correlation**: Calculate Pearson correlation between these derived features and the mean target value per sample.
    *   **Importance**: Train a lightweight Random Forest Regressor to predict the mean `reactivity` of a sample based on its structural composition and signal-to-noise ratio.

5.  **Output**:
    *   Print a structured report with capitalized sections and formatted floating-point numbers.
