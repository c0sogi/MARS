The implementation strategy involves creating a custom orchestration script `runfile.py` that leverages the provided library modules to train and evaluate the RNA degradation prediction model.

**Strategy Outline:**
1.  **Setup & Initialization**: Import necessary components from the `library` package. Initialize the environment using `Config.setup_environment` and `seed_everything` to ensure reproducibility.
2.  **Data Loading**: Use `get_dataloaders` to load the training, validation, and test sets. We will use the full dataset as the size (approx. 2000 samples) is small enough for rapid training on an A100 GPU within the time limit.
3.  **Model & Training**: Instantiate the `RNAModel`, `MaskedMSELoss`, `AdamW` optimizer, and `CosineAnnealingLR` scheduler. Implement a training loop that iterates for `Config.EPOCHS` (20), calling `train_one_epoch` and `validate` at each step. We will track the best model based on the MCRMSE metric and save it.
4.  **Final Evaluation**: After training, load the best model checkpoint. Perform a dedicated inference pass on the validation set to calculate the final MCRMSE and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Compute the error magnitude (MCRMSE) for each sample in the validation set.
    *   Load the validation metadata (`val.parquet`) to extract features like `signal_to_noise`, `SN_filter`, and nucleotide counts.
    *   Calculate and print the Pearson correlation between the error magnitude and these features to identify sources of systematic error.
6.  **Submission**: Check if the final validation metric is below the specified threshold (`0.6199890971183777`). If satisfied, generate predictions for the test set using `generate_submission` and save the result to `submission.csv`.
