### Implementation Strategy

1.  **Configuration Override**: We will modify the global `Config` class attributes at runtime to adapt the pipeline for a quick demonstration. This includes setting a separate working directory (`./working/demo_run`), reducing the number of epochs to 2, setting the batch size to 4, and disabling multiprocessing overhead.
2.  **Component Verification**:
    *   **Data Loading**: We will initialize the `get_dataloaders` function with a `debug_subset` of 20 samples. We will fetch a single batch to verify the tensor shapes of sequences, masks, and targets.
    *   **Model Instantiation & Forward Pass**: We will instantiate the `RNAModel` and perform a forward pass with the fetched batch to ensure the output shape matches `(Batch, Seq_Len, Num_Targets)`.
    *   **Loss Calculation**: We will use `MaskedMSELoss` to compute the loss between predictions and targets, verifying that the loss is a valid scalar.
3.  **Full Pipeline Execution**: We will execute the `run_training` function (imported from the library) with the debug subset. This demonstrates the integration of all components, including the training loop, validation, and submission generation.
4.  **Output Validation**: Finally, we will verify that the submission file is created, contains the correct columns, and has the expected number of rows based on the debug subset size.
