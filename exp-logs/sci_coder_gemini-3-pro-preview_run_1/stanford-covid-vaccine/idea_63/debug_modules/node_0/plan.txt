### Implementation Strategy

1.  **Configuration Setup**: We will modify the static `Config` attributes to point to a temporary working directory (`./working/demo_run`) and reduce the batch size for the demonstration.
2.  **Component Verification (Unit Testing)**:
    *   **Data Loading**: Initialize the dataloaders with a small subset (`max_samples=20`) and assert that the batch shapes for sequences, loops, distances, and targets match the expected dimensions `(Batch, 107, ...)`.
    *   **Model Architecture**: Instantiate the `RNAModel`, perform a forward pass with a dummy batch, and verify that the output shape is `(Batch, 107, 3)`.
    *   **Metric Calculation**: Create synthetic prediction and target tensors with known values to verify that the `mcrmse_loss` function calculates the error correctly (focusing on the scored length of 68).
3.  **Pipeline Execution (Integration Testing)**:
    *   Execute the `run_training` function from `library.train` with `epochs=2` and `max_samples=50`. This will train the model, save the best checkpoint, and generate a submission file.
4.  **Result Validation**:
    *   Load the generated `submission.csv` and verify it has the correct number of rows (samples × sequence length) and the required columns.
    *   Confirm the existence of the saved model checkpoint.
