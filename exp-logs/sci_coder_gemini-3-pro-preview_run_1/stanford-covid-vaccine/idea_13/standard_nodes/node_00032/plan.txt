The error `AttributeError: type object 'Config' has no attribute 'VOCAB_SIZE'` arises because the `RNAResidualBiGRU` model attempts to access `Config.VOCAB_SIZE` to define its embedding layer, but this parameter is not defined in `library/config.py`. The configuration file currently defines `K_MER_VOCAB_SIZE`, but the data processing logic (`library/data.py`) and model architecture have shifted to using atomic tokenization (mapping individual bases A, G, C, U to indices 1-4). To resolve this schema mismatch (Cite debug_lesson_2), I will add `VOCAB_SIZE = 5` (representing 4 bases + 1 padding index) to the `Config` class.
