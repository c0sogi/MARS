Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **K-mer Enhanced Distance-Aware BiGRU with Input Injection** strategy. This approach is a structural evolution that addresses the "Local vs. Global" trade-off by replacing the failed CNN hybrids with a discrete "Stacking-Interaction" representation (K-mers) and ensuring signal preservation in deep networks via Input Injection.

# Model
**Architecture: K-mer Enhanced Distance-Aware BiGRU with Input Injection**
We will construct a deep recurrent network that processes "Stacking Triplets" rather than single nucleotides and maintains direct access to these physicochemical features at every network depth.

*   **Input Embeddings**:
    *   **3-mer Sequence Encoding (Innovation)**: Instead of embedding single nucleotides (A, G, C, U), we will tokenize the sequence into overlapping **3-mers** (e.g., `ACG`, `CGU`) using a sliding window with stride 1.
        *   **Rationale**: RNA stability is locally dominated by **Base Stacking Interactions** (the energy between adjacent parallel bases). By embedding the triplet directly, the model receives a discrete, atomic representation of the local stacking context (the central base and its immediate neighbors) **Cite solution_lesson_node_00013**. This provides the "Local Inductive Bias" sought in previous CNN attempts without the feature smoothing/pooling that caused them to fail.
    *   **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the signed scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We strictly use **Signed** distances to preserve directionality **Cite solution_lesson_node_00024**.
    *   **Predicted Loop Type**: Standard embedding for the structural context.
*   **Backbone: Deep Input-Injected Residual BiGRU**:
    *   **Structure**: A stack of **5-6 Bidirectional GRU layers**.
    *   **Pre-LayerNorm**: We will use the **Pre-LayerNorm** configuration (`x + GRU(Norm(x))`) to facilitate the training of this deep architecture **Cite solution_lesson_node_00017**.
    *   **Input Injection (Innovation)**: We will concatenate the initial input embedding vector (K-mer + Distance + Loop) to the input of **every** BiGRU layer in the stack.
        *   **Rationale**: In deep networks, the original high-frequency signal (exact base identity) can be diluted by repeated state transitions. Input Injection creates a "short-circuit," ensuring that the raw physicochemical features are available to the deeper layers and the final classifier, preventing the "over-processing" of simple local signals.
    *   **Capacity**: We will maintain a **High Hidden Dimension (e.g., 384)**, as reducing width has been proven to degrade performance **Cite solution_lesson_node_00022**.
*   **Output Head**:
    *   A shared MLP projecting the final hidden states to **3 output channels** (scored targets).

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: We will process the complete 107-nucleotide sequence. We will **not crop** inputs, ensuring the model utilizes downstream structural information **Cite solution_lesson_node_00002**.
    *   **K-mer Tokenization**: We will generate the 3-mer vocabulary (size $4^3=64$ plus padding) and convert sequences into integer streams. Boundary positions will be handled with padding tokens to maintain the 107 sequence length.
    *   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data, training only on the three scored columns to avoid high-variance noise **Cite solution_lesson_node_00019**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**, rejecting "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally, avoiding the distribution mismatch caused by signal-to-noise weighting **Cite solution_lesson_node_00011**.
*   **No Auxiliary Tasks**: We will **not** use Masked Language Modeling, as it corrupts the precision regression signal **Cite solution_lesson_node_00020**.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler.

# Evaluation
*   **Inference**: The test sequences (length 107) will be tokenized into 3-mers and passed through the model.
*   **Formatting**: The model will output predictions for the 3 scored columns. We will construct the submission file by filling the unscored columns (`deg_pH10`, `deg_50C`) with 0.0 and flattening the result to the `id_seqpos` format.
