2.  **Data Loading**: Utilize the `get_dataloaders` function with `load_cached_data=True` to efficiently load the training, validation, and test datasets.
3.  **Training**: Instantiate the `Engine` class and execute the `fit` method to train the "Dynamic-Depth Wide-Stream Residual BiGRU" model. This handles the training loop, loss calculation, and checkpointing of the best model based on validation performance.
4.  **Evaluation**:
    *   Load the best model weights from the saved checkpoint.
    *   Perform inference on the full validation set to compute the final MCRMSE score.
    *   Print the "Final Validation Metric" in the required format.
5.  **Failure Analysis**:
    *   Calculate the RMSE for each sample in the validation set.
    *   Load the validation metadata (`val.parquet`) to access sample attributes.
    *   Compute and print Pearson correlations between the model's error and key features (Signal-to-Noise Ratio, SN Filter, and Nucleotide counts) to identify systematic weaknesses.
6.  **Submission**: Compare the final validation metric against the threshold (0.6199890971183777). If the model performs better (lower score), generate predictions for the test set using `engine.predict` and save the submission file.
