This script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It begins by configuring the global settings for a rapid demonstration (reducing model size, batch size, and epoch count). It then validates individual components: loading data via `get_dataloaders`, performing a forward pass with `DynamicDepthWideStreamBiGRU`, calculating loss with `MaskedMSELoss`, and computing metrics with `compute_mcrmse`. Finally, it utilizes the `Engine` class to orchestrate a complete training and inference cycle, verifying the generation of a valid submission file.
