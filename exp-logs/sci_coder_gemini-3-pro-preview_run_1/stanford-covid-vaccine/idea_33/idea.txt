Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Structural Shortcut Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution of the "Scalar-Aggregated Wide-Stream Residual BiGRU" (Idea 19). It retains the robust, high-capacity backbone identified as the "Current Best" but introduces a novel **Structural Shortcut Readout** to explicitly resolve the long-range dependency bottleneck inherent in RNNs, without the optimization instability of GNNs or the overfitting risks of wider backbones.

# Model
**Architecture: Structural Shortcut Wide-Stream Residual BiGRU**
We will construct a deep recurrent network that processes sequence-native features and fuses them with a topology-aware readout mechanism.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide. We will strictly maintain **High-Dimensional Embeddings (128)** to prevent the information bottleneck identified in **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers which dilute data in small regimes **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or RBFs **Cite solution_lesson_node_00042**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$.
    *   **Capacity Control**: We will set the stream width $W$ to **384**. While wider models (512) exist, they have proven prone to overfitting on this dataset **Cite solution_lesson_node_00081**. The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**, avoiding the pitfalls of linear stems **Cite solution_lesson_node_00082** or global initialization **Cite solution_lesson_node_00059**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=384$ throughout (BiGRU hidden size 192 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**. We strictly use stacked RNNs, avoiding interleaved MLPs **Cite solution_lesson_node_00047**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**, dense concatenation **Cite solution_lesson_node_00055**, or channel-wise weighting **Cite solution_lesson_node_00073**.

*   **Structural Shortcut Readout (Structural Innovation)**:
    *   Instead of predicting the target $y_i$ solely from the aggregated state $h_i$, we will introduce a **Topology-Aware Fusion**.
    *   For each position $i$, we identify its paired base index $j$ from the provided structure.
    *   We gather the aggregated hidden state $h_j$ (the "Partner State"). If $i$ is unpaired, we use a zero vector.
    *   We **concatenate** the local state and the partner state: $h_{fused} = [h_i; h_j]$.
    *   **Projection**: A **Shared Linear Projection** maps $h_{fused}$ ($384 \times 2 \to 3$) to the **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
    *   **Rationale**: This creates a direct information path (shortcut) from the paired base to the prediction site at the high-level feature space. It allows the model to leverage the rich, deeply processed features of the partner base without forcing the RNN to maintain this dependency over potentially 100+ timesteps, effectively creating a "Readout-Level Graph" without the noise of GNN message passing. We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** mask any input sequence tokens or perform auxiliary Masked Language Modeling **Cite solution_lesson_node_00020**.
    *   **No Augmentation**: Avoid Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Regularization**: Use **Inter-Layer Dropout** (e.g., 0.1) which outperforms Zoneout **Cite solution_lesson_node_00076**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.
*   **Checkpointing**:
    *   Save the model with the **lowest Validation MCRMSE**, rejecting SWA/tail-averaging to avoid overfitting artifacts **Cite solution_lesson_node_00060**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. The Structural Shortcut will use the provided test structure to gather features. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
