The implementation strategy involves the following steps:

1.  **Initialization**: Import necessary modules and the provided library components (`Config`, `run_training`, `generate_submission`, etc.). Set the random seed for reproducibility.
2.  **Configuration Override**: Update `Config.submission_path` to point to `./submission/submission.csv` as required by the task, and ensure the directory exists.
3.  **Training**: Execute the `run_training()` function. This handles the full training loop, validation monitoring, and saves the best model checkpoint to the working directory.
4.  **Validation & Analysis**:
    *   Load the best model checkpoint.
    *   Run inference on the full validation set to collect predictions and targets.
    *   Compute the **Final Validation Metric** (MCRMSE) and print it with full precision.
    *   Perform **Failure Analysis**: Calculate the Root Mean Squared Error (RMSE) for each validation sample. Load the validation metadata (Parquet file) to retrieve sample attributes (`signal_to_noise`, `SN_filter`). Compute and print the Pearson correlation between the sample error and these features to identify error sources.
5.  **Submission**: Compare the final validation metric against the threshold (0.6199890971183777). If the model performs well enough, call `generate_submission()` to create the submission file at the designated path.
