Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Bond-Aware Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that enhances the "Current Best" backbone (Idea 19/25) by integrating explicit physicochemical interaction features ("Soft Features") while strictly adhering to the architectural constraints and training protocols that have proven stable.

# Model
**Architecture: Bond-Aware Wide-Stream Residual BiGRU**
We will construct a deep recurrent network that integrates explicit base-pairing semantics with the robust "Wide-Stream" information flow.

*   **Input Embeddings**: We will concatenate four distinct feature channels per nucleotide. We will maintain **High-Dimensional Embeddings (e.g., 128)** to prevent information bottlenecks **Cite solution_lesson_node_00068**.
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy with **Fixed Inductive Bias**. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using fixed **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.
    4.  **Bond-Type Embedding (Structural Innovation)**: We will introduce a new "Soft Feature" channel **Cite solution_lesson_node_00086**.
        *   We will tokenize the specific **base-pair interaction** for each nucleotide.
        *   Vocabulary: "A-U", "U-A", "G-C", "C-G", "G-U", "U-G" (Wobble), "Mismatch", "Unpaired".
        *   **Rationale**: While the RNN can theoretically infer the partner identity from the distance embedding, explicitly providing the bond type (which correlates directly with thermodynamic stability, e.g., 3 H-bonds for G-C vs 2 for A-U) reduces the learning burden. This respects the "Atomic" granularity **Cite solution_lesson_node_00028** and avoids the pitfalls of "Hard Architectural Shortcuts" **Cite solution_lesson_node_00086**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$.
    *   **Width**: We will set $W=384$. This balances the need for capacity **Cite solution_lesson_node_00022** with the risk of overfitting observed at width 512 **Cite solution_lesson_node_00081**. The Recurrent Stem ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=384$ throughout (BiGRU hidden size 192 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**. We strictly use stacked RNNs, avoiding interleaved MLPs **Cite solution_lesson_node_00047**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**, dense concatenation **Cite solution_lesson_node_00055**, or channel-wise weighting **Cite solution_lesson_node_00073**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053** and keep the head simple **Cite solution_lesson_node_00048**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **Feature Generation**: Generate the Bond-Type tokens by checking the sequence identity at indices $i$ and $j$ (from structure). Ensure this is synchronized with the Distance embedding.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Regularization**: Use **Inter-Layer Dropout** (e.g., 0.1) which outperforms Zoneout **Cite solution_lesson_node_00076**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
