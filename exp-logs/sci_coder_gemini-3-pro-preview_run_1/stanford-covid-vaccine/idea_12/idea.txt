Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose an **Interaction-Aware Residual BiLSTM** strategy. This approach represents a structural evolution of the "Distance-Aware Residual BiGRU" (Idea 8) and corrects the failures of the "Structure-Augmented" attempt (Idea 11) by replacing high-complexity explicit features with efficient physicochemical semantics, and upgrading the recurrent core to handle deeper dependencies.

# Model
**Architecture: Interaction-Aware Deep Residual BiLSTM**
We will construct a deep recurrent network that integrates explicit physicochemical bond information with a robust long-term memory backbone.

*   **Input Embeddings**: We will concatenate four distinct feature channels per nucleotide:
    1.  **Sequence**: Learnable embeddings for the nucleotide identity (A, G, C, U).
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the signed scalar distance $j-i$ using **Sinusoidal Positional Encodings**. This preserves the directionality (upstream vs. downstream pairing) which is critical for resolving structural ambiguities **Cite solution_lesson_node_00024**, while avoiding the pitfalls of categorical structure tokens **Cite solution_lesson_node_00016**.
    4.  **Bond-Type Interaction (Innovation)**: We will introduce a new "Physicochemical Semantics" feature. Instead of the high-dimensional "teleportation" of paired embeddings (which failed due to complexity **Cite solution_lesson_node_00023**), we will compute a categorical token representing the specific **base-pair identity** (e.g., "G-C", "A-U", "G-U", "Unpaired"). This explicitly informs the model of the *bond strength* (3 hydrogen bonds for G-C vs. 2 for A-U vs. Wobble for G-U) at the input level, providing a low-dimensional but semantically rich inductive bias that complements the geometric distance feature.
*   **Backbone: Deep Pre-LayerNorm Residual BiLSTM**:
    *   We will replace the GRU with a **Bidirectional LSTM (Long Short-Term Memory)**. While GRUs are efficient, LSTMs possess a separate cell state with linear update pathways, which theoretically improves gradient flow and information retention in very deep networks.
    *   **Structure**: A stack of **5-6 BiLSTM layers** using the **Pre-LayerNorm** configuration (`x + LSTM(Norm(x))`). This design is essential for stabilizing the training of deep recurrent architectures **Cite solution_lesson_node_00017**.
    *   **Capacity**: We will maintain a **High Hidden Dimension (e.g., 384)**. Reducing capacity below this threshold has been proven to degrade performance significantly in this task **Cite solution_lesson_node_00022**.
*   **Output Head**:
    *   A shared Multi-Layer Perceptron (MLP) will project the final hidden states to **3 output channels**, corresponding strictly to the scored targets (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).

# Data
*   **Full-Context Processing**: We will process the complete 107-nucleotide sequence for every sample. We will **not crop** inputs to the scored length (68), ensuring the model utilizes downstream structural information (e.g., 3' stem halves) that causally affects the 5' scored region **Cite solution_lesson_node_00002**.
*   **Feature Engineering**:
    *   **Interaction Tokens**: During preprocessing, we will parse the `structure` and `sequence` to generate the "Bond-Type" tokens.
    *   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. We will only train on the three scored columns to prevent high-variance unscored noise from diluting the gradients **Cite solution_lesson_node_00019**.
*   **No Masking**: We will **not** mask any input tokens. Joint Masked Language Modeling has been shown to corrupt the input signal for this precision regression task **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE), preventing the under-prediction of outliers **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally. We will **not** weight samples by their signal-to-noise ratio, avoiding the distribution mismatch that degrades performance on unweighted metrics **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler to stabilize the deep residual network.

# Evaluation
*   **Inference**: The test sequences (length 107) will be passed through the model to generate predictions for the 3 scored columns.
*   **Formatting**: We will construct the final submission file by placing the predictions into their respective columns and filling the unscored columns (`deg_pH10`, `deg_50C`) with 0.0. The results will be flattened to the `id_seqpos` format.
