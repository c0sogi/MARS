The following script demonstrates the usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Metric Verification**: Validates the `mcrmse_metric` function with a manual calculation to ensure scoring logic is correct.
2.  **Data Pipeline Verification**: Loads a subset of the data using `get_dataloaders`, verifying tensor shapes and data integrity (e.g., sequence length, target dimensions).
3.  **Model Architecture Verification**: Instantiates the `ScaledResidualWideStreamBiGRU` model and performs a forward pass with a batch of real data to confirm output shapes and compatibility.
4.  **End-to-End Training & Inference**: Executes the full `train_model` pipeline with a reduced dataset size (`debug_subset=50`) and minimal epochs (`epochs=2`) to demonstrate the training loop, validation, and submission generation within the time limit.
5.  **Submission Verification**: Checks the generated submission file for correct formatting, column names, and row counts.
