Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **LayerDrop-Stabilized High-Capacity Wide-Stream BiGRU** strategy. This approach represents a structural evolution that finally unlocks the high-performance potential of the **Width 512** regime (identified as critical in **Cite solution_lesson_node_00022**) by synthesizing the "Current Best" backbone with **Stochastic Depth (LayerDrop)** and **Gradient Clipping**. This specific combination addresses the optimization instability and overfitting that caused previous high-capacity attempts to fail (Lessons 00081, 00097, 00070).

# Model
**Architecture: LayerDrop-Stabilized High-Capacity Wide-Stream BiGRU**
We will construct a deep, high-capacity recurrent network optimized for maximum information density, using structural regularization to train a model that is significantly wider and deeper than the current baseline.

*   **Proportional Input Embeddings**: We will maintain the **Heterogeneous Feature Embedding** strategy to balance information content with parameter efficiency **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.

*   **High-Fidelity Recurrent Stem**:
    *   The concatenated embeddings (Total Dim 256) are projected via a single **BiGRU layer** to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. We explicitly target this high capacity to maximize performance **Cite solution_lesson_node_00022**.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem to preserve the fidelity of the initial projection **Cite solution_lesson_node_00109**.

*   **Backbone: Deep Wide-Stream Blocks with LayerDrop**:
    *   The encoder will consist of **8 Blocks** (increased depth).
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We **maintain the full residual stream width** $W=512$ throughout, explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Stochastic Depth (LayerDrop) (Structural Innovation)**:
        *   We will apply **LayerDrop** to the residual branch of each block.
        *   During training, we randomly drop the transformation function (the BiGRU) of block $l$ with probability $1 - p_l$, effectively setting the block to an identity mapping ($x_{l+1} = x_l$).
        *   We will linearly decay the survival probability $p_l$ from **1.0 (first block)** to **0.6 (last block)**.
        *   **Rationale**: This allows us to train a significantly deeper (8 layers) and wider (512 dim) network by reducing the effective depth and path length during training. This acts as a powerful regularizer that prevents the overfitting observed in previous 512-width attempts **Cite solution_lesson_node_00081**, while allowing the model to utilize its full capacity during inference.
    *   **Inter-Layer Dropout**: We also apply standard **Dropout (p=0.2)** after the BiGRU within active blocks. This is strictly superior to Zoneout **Cite solution_lesson_node_00076**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 8 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**. We rely on LayerDrop and Inter-Layer Dropout for regularization.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is the critical stabilizer that allows the 512-width backbone to converge, preventing the divergences observed in previous high-capacity attempts **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model (using full depth, with weights scaled by survival probabilities if not handled automatically by the layer implementation). Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
