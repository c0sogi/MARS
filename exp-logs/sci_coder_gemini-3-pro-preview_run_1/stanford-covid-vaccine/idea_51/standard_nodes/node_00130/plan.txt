To optimize performance, I will revert the "High-Capacity" and "LayerDrop" modifications that caused regression in the previous solution and align the architecture with the "Current Best Solution" described in the lessons (specifically Idea 44).

**Strategy:**
1.  **Reduce Model Capacity (Cite Lesson 00081, 00129):** Decrease `HIDDEN_DIM` from 512 to 384 and `N_LAYERS` from 8 to 6. High capacity combined with small data led to overfitting/underfitting issues previously.
2.  **Remove LayerDrop (Cite Lesson 00129):** Eliminate Stochastic Depth regularization. In low-data regimes (~2k samples), skipping layers randomly prevents the model from effectively learning representations.
3.  **Switch to BiLSTM (Cite Lesson 00112):** Replace GRU with LSTM. While GRUs are efficient, the best reported metric (0.6176) was achieved with a Stabilized Wide-Stream BiLSTM, likely due to better handling of counting/nested dependencies in RNA structures.
4.  **Optimize Dropout (Cite Lesson 00109, 00076):** Set inter-layer dropout to 0.1 and ensure the Stem layer has **no** dropout to preserve input signal fidelity.
5.  **Batch Size:** Revert to 32 to ensure stable gradient updates for the 384-dimensional model.

class LayerDropBlock(nn.Module):
    """
    A Pre-LN BiGRU block with Stochastic Depth (LayerDrop).
    Uses a wide residual stream (512 dim) and applies dropout.
    """

    def __init__(self, hidden_dim, dropout, survival_prob):
        super().__init__()
        self.survival_prob = survival_prob

        # Pre-LayerNorm configuration
        self.ln = nn.LayerNorm(hidden_dim)

        # Wide-Stream BiGRU
        # Input: hidden_dim (512)
        # Hidden: hidden_dim // 2 (256) per direction -> Output 512 (concatenated)
        self.gru = nn.GRU(
            input_size=hidden_dim,
            hidden_size=hidden_dim // 2,
            batch_first=True,
            bidirectional=True,
        )

        # Inter-layer Dropout
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        residual = x

        # Pre-LN
        out = self.ln(x)

        # Transformation
        out, _ = self.gru(out)
        out = self.dropout(out)

        # Stochastic Depth Logic
        if self.training:
            # Randomly drop the block transformation
            # We apply this decision per-batch for efficiency
            if torch.rand(1).item() < self.survival_prob:
                # Block survives: Add residual + transformation
                return residual + out
            else:
                # Block dropped: Identity mapping
                return residual
        else:
            # Inference: Scale the residual branch by survival probability
            # This aligns the expected value of the output with training
            return residual + (self.survival_prob * out)
