Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Structurally Modulated Wide-Stream BiGRU with Learnable Geometric Bias**. This strategy represents a structural evolution of the "Scalar-Aggregated Wide-Stream Residual BiGRU" (Idea 19). It retains the successful backbone and aggregation mechanisms while introducing **Learnable Fourier Features** to optimize the geometric inductive bias and **Token-Wise Feature Modulation (FiLM)** to explicitly condition the recurrent processing on structural context.

# Model
**Architecture: Structurally Modulated Wide-Stream BiGRU with Learnable Geometric Bias**
We will construct a deep recurrent network that optimizes the representation of RNA topology and reinforces structural context at every depth without signal dilution.

*   **Input Embeddings**:
    *   **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens** **Cite solution_lesson_node_00028**.
    *   **Loop Context**: Learnable embeddings for the predicted loop type (S, M, I, B, H, E, X).
    *   **Learnable Fourier Geometric Bias (Innovation)**: We will evolve the "Sinusoidal Pairing Distance" **Cite solution_lesson_node_00016** into a **Learnable Fourier Positional Encoding (LFPE)**.
        *   Instead of fixed frequencies, we will initialize a bank of frequencies $\{w_k\}$ using the standard geometric progression but define them as **learnable parameters**.
        *   For every nucleotide $i$ paired with $j$, we encode the **signed** distance $d = j-i$ **Cite solution_lesson_node_00024** as $[\sin(w_1 d), \cos(w_1 d), \dots]$.
        *   **Rationale**: This retains the superior continuous bias of sinusoidal encodings over RBFs **Cite solution_lesson_node_00042** while allowing the model to fine-tune the frequency bands to match the specific characteristic lengths of RNA motifs (e.g., typical hairpin sizes) during training.

*   **Recurrent Stem**:
    *   A single **BiGRU layer** projects the concatenated embeddings (Sequence + LFPE + Loop) to the model's residual stream width $W$ (e.g., 384). This ensures temporal contextualization before the residual stack **Cite solution_lesson_node_00046**.

*   **Backbone: Modulated Wide-Stream Residual Blocks**:
    *   The encoder consists of **6 Blocks**.
    *   **Wide Stream**: We maintain the full stream width $W$ throughout (BiGRU hidden size $W/2$), avoiding bottlenecks **Cite solution_lesson_node_00041**.
    *   **Token-Wise Feature Modulation (FiLM) (Innovation)**:
        *   Inside each block, before the BiGRU, we re-inject the **Loop Context** using **Feature-wise Linear Modulation**.
        *   We project the loop embedding of each position to scale ($\gamma$) and shift ($\beta$) vectors.
        *   Operation: $x_{mod} = \gamma \odot \text{LayerNorm}(x) + \beta$.
        *   **Rationale**: This reinforces the structural context (e.g., "this base is in a Stem vs. Hairpin") at every depth. Unlike "Input Injection" (concatenation) which failed due to noise propagation **Cite solution_lesson_node_00035**, FiLM acts as a **gating mechanism**, allowing the structural type to dynamically modulate the recurrent processing without polluting the feature stream with raw inputs.
    *   **Core**: BiGRU($x_{mod}$) $\to$ Dropout.
    *   **Residual**: Additive connection ($x + \text{Core}$).

*   **Output Head**:
    *   **Scalar Mixture Aggregation**: We compute a learnable weighted sum of outputs from the Stem and all 6 Blocks **Cite solution_lesson_node_00049**. This acts as a depth ensemble **Cite solution_lesson_node_00055**.
    *   **Shared Projection**: A simple Linear layer maps the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00048**, **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training set. Train **only** on the three scored columns to prevent high-variance noise from diluting gradients **Cite solution_lesson_node_00019**.
    *   **Feature Generation**: Generate signed distance matrices ($j-i$) and integer tokens for sequence and loop types.
    *   **No Masking**: Do **not** use auxiliary Masked Language Modeling **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally to avoid distribution mismatch **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW.
*   **Scheduler**: **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). We strictly prefer this deterministic schedule over `ReduceLROnPlateau` for fixed-budget runs to guarantee convergence to a fine-tuning phase **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Calculation**: Calculate MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass full 107-length test sequences through the model. Extract predictions for the 3 scored columns. Fill unscored columns (`deg_pH10`, `deg_50C`) with 0.0 to meet submission requirements.
