Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Stabilized Wide-Stream Residual BiLSTM** strategy. This approach represents a structural evolution that shifts the recurrent core from GRUs to **LSTMs** to better manage gradient flow in the high-capacity **Width 512** regime (addressing Lesson 00022 and Lesson 00081), while strictly enforcing the regularization and metric protocols that were identified as critical missing components in previous failures.

# Model
**Architecture: Stabilized Wide-Stream Residual BiLSTM**
We will construct a high-capacity deep recurrent network optimized for maximum information density and stable long-term dependency modeling.

*   **Proportional Input Embeddings**: We will implement the **Proportional Feature Embedding** strategy to balance information content with parameter efficiency **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.
    *   **Fusion**: These are concatenated (Total Dim 256) without independent normalization **Cite solution_lesson_node_00102**.

*   **Recurrent Stem**:
    *   The fused input is projected via a single **BiLSTM layer** to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. Lesson 00022 proved that width is the primary driver of performance. We switch to **LSTM** (Long Short-Term Memory) because its separate cell state ($c_t$) provides a "Constant Error Carousel," which theoretically supports stable gradient propagation in wider, deeper networks better than the GRU used in previous failed wide attempts **Cite solution_lesson_node_00081**.

*   **Backbone: Wide-Stream Residual BiLSTM Blocks**:
    *   The encoder will consist of **6 Blocks** (adhering to the "Shallow and Wide" principle **Cite solution_lesson_node_00065**).
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=512$ throughout (BiLSTM hidden size 256 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiLSTM but before the residual addition. This is strictly superior to Zoneout for this task **Cite solution_lesson_node_00076** and is critical for stabilizing the 512-width backbone.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061** or dense concatenation **Cite solution_lesson_node_00055**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is the critical missing component that caused previous high-capacity models to diverge **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact identified in **Cite solution_lesson_node_00105** and **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
