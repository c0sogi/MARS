1.  **Configuration Setup**: Import the `Config` class and override specific parameters (e.g., `DEBUG=True`, `EPOCHS=2`, `BATCH_SIZE=4`) to ensure the demonstration runs quickly and uses a separate working directory (`./working/demo_run`) to avoid overwriting existing files.
2.  **Data Loading & Verification**: Use `load_data` to load a debug subset of the training data. Verify the returned `RNADataset` contains the expected number of samples and that the data shapes (sequence, targets, masks) match the configuration.
3.  **Model Instantiation & Forward Pass**: Instantiate the `DenseAggregatedBiGRU` model. Create a dummy batch from the loaded data and perform a forward pass to verify the output shape corresponds to `(Batch, Sequence_Length, 3)`.
4.  **Loss & Metric Validation**: Create synthetic prediction and target tensors with known values (e.g., perfect match vs. off-by-one). Use `masked_mse_loss` and `compute_mcrmse` to verify that the loss and metric calculations behave as expected (0.0 for perfect match, 1.0 for unit error).
5.  **Training Integration**: Instantiate the `Trainer` class and run the `fit` method in debug mode. This acts as an integration test for the training loop, optimizer, scheduler, and checkpointing mechanism. Verify that a "best_model.pth" file is created.
6.  **Inference & Submission**: Load the test set (debug subset) and use the `generate_submission` function to create a submission file. Verify the file's existence, column structure, and row count.
