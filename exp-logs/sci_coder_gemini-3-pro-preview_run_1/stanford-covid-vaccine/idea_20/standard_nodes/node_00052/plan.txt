The implementation strategy involves creating a main execution script `runfile.py` that orchestrates the machine learning pipeline using the provided library modules.

1.  **Configuration Override**: We will programmatically modify the `Config` class to reduce the number of epochs (e.g., to 25) and adjust patience parameters. This ensures the training completes quickly, satisfying the "fast baseline" requirement.
2.  **Setup and Data Loading**: We will initialize the environment (seeds, logger) and load the data using `get_dataloaders(load_cached_data=True)` to leverage pre-processed files.
3.  **Model Training**: We will instantiate the `Net` model, `AdamW` optimizer, `ReduceLROnPlateau` scheduler, and `MaskedMSELoss`. We will then use the `Trainer` class to fit the model to the training data.
4.  **Validation and Metric Calculation**: After training, we will load the best model checkpoint and perform inference on the full validation set. We will manually calculate the Mean Columnwise Root Mean Squared Error (MCRMSE) to ensure it exactly matches the competition metric and print it in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**: We will compute the Mean Squared Error for each validation sample. We will then calculate and print the Pearson correlation between this error magnitude and various input features (Signal-to-Noise, Nucleotide Counts) to identify potential weaknesses.
6.  **Conditional Submission**: We will compare the calculated validation metric against the threshold `0.6209375959946717`. If the model performs better (lower metric), we will invoke the `run_prediction` function to generate the `submission.csv` file.
