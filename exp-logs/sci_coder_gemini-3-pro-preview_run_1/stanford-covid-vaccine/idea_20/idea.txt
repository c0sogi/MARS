Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Target-Aware Layer-Aggregated Wide-Stream BiGRU** strategy. This approach represents a structural evolution of the "Scalar-Aggregated Wide-Stream Residual BiGRU" (Idea 19) by refining the aggregation mechanism to be target-specific and correcting the optimization schedule flaw identified in Lesson 00051.

# Model
**Architecture: Target-Aware Layer-Aggregated Wide-Stream BiGRU**
We will construct a deep recurrent network that maintains a high-capacity residual stream and aggregates multi-scale features independently for each target variable, acknowledging that different physical properties (e.g., reactivity vs. thermal degradation) may rely on different levels of structural abstraction.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide:
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers which dilute data in small regimes **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and prefer this over RBFs **Cite solution_lesson_node_00042**.

*   **Recurrent Stem**:
    *   We will process the concatenated embeddings using a single **BiGRU layer** that projects the input to the model's residual stream width $W$ (e.g., 384). This ensures the input to the first residual block is temporally contextualized **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W$ throughout. The BiGRU layer within the block will have hidden size $W/2$ (output $W$), avoiding any bottleneck projection **Cite solution_lesson_node_00041**.

*   **Target-Specific Scalar Mixture (Structural Innovation)**:
    *   Instead of a single set of scalar weights for aggregating layers (as in Idea 19), we will implement **3 parallel aggregation heads**, one for each scored target (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`).
    *   For each target $k$, we learn a unique set of softmax-normalized scalar weights $\{w_{0}^{(k)}, ..., w_{L}^{(k)}\}$.
    *   We compute three distinct context vectors per position: $h_{final}^{(k)} = \sum_{l=0}^{L} w_l^{(k)} \cdot h_l$.
    *   **Rationale**: This allows the model to dynamically select the optimal abstraction level for each physical property (e.g., `reactivity` might depend more on local features from early layers, while `deg_Mg_50C` might depend on global folding from deeper layers), refining the aggregation concept from **Cite solution_lesson_node_00049**.

*   **Output Heads**:
    *   Three independent Linear projections, each mapping its specific aggregated vector $h_{final}^{(k)}$ to a single scalar prediction.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: We will process the complete 107-nucleotide sequence. We will **not crop** inputs, ensuring the model utilizes downstream structural information **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. We will only train on the three scored columns to prevent high-variance unscored noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: We will **not** mask any input tokens or perform auxiliary Masked Language Modeling, as it corrupts the precision regression signal **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE) **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally. We will **not** weight samples by their signal-to-noise ratio, avoiding the distribution mismatch that degrades performance on unweighted metrics **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer.
*   **Scheduler (Correction)**: We will use **ReduceLROnPlateau** (monitoring Validation MCRMSE) instead of a duration-dependent Cosine Annealing scheduler. This decouples the learning rate decay from the number of epochs, preventing the "stretched schedule" issue that hindered convergence in previous long runs **Cite solution_lesson_node_00051**.

# Evaluation
*   **Metric Correction**: During validation, we will calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: The test sequences (length 107) will be passed through the model. The predictions for the 3 scored columns will be extracted, and the unscored columns (`deg_pH10`, `deg_50C`) will be filled with 0.0 to meet the submission format requirements.
