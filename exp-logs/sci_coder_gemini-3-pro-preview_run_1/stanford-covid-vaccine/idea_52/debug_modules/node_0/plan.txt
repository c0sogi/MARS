This script demonstrates the usage of the provided RNA degradation prediction library. It performs the following steps:

1.  **Unit Verification**: Validates the correctness of the `mcrmse` metric and the sinusoidal embedding function using synthetic data.
2.  **Configuration Override**: Adjusts the `Config` class attributes to direct outputs to a temporary `./demo_execution` directory, ensuring the demo is self-contained.
3.  **Pipeline Execution**: Runs the full training and inference pipeline using `run_training(debug=True)`. This mode uses a subset of the data and fewer epochs for rapid execution.
4.  **Output Validation**: Verifies that the model checkpoint and submission file are generated correctly and adhere to the expected format.
