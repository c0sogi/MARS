This script demonstrates the usage of the provided RNA Degradation Prediction library. It performs the following steps:
1.  **Configuration Override**: Adjusts the `Config` class to run a fast, minimal demonstration (fewer epochs, smaller batch size, debug subset) without affecting the main working directory.
2.  **Metric Verification**: Validates the `mcrmse_loss` function with a manual calculation.
3.  **Data Loading**: Uses `get_dataloaders` to load and process a subset of the data, verifying the structure and shapes of the batches.
4.  **Model Verification**: Instantiates the `MultiTaskRNANet`, performs a forward pass with real batch data, and asserts output shapes.
5.  **Training & Inference**: Uses the `Engine` class to run a complete training epoch and generate a submission file, verifying the creation and format of the output artifacts.
