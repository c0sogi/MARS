This script implements the Vector-Scaled Wide-Stream Residual BiGRU strategy. It orchestrates the training using the provided library modules, performs a detailed validation assessment including failure analysis, and generates a submission file if the performance threshold is met.

The implementation follows these steps:
1.  **Training**: Executes the training loop via `library.train.run_training` for 20 epochs (defined in Config), saving the best model based on MCRMSE.
2.  **Validation**: Reloads the best model and performs inference on the hold-out validation set.
3.  **Metric Calculation**: Computes and prints the `Final Validation Metric` with full precision.
4.  **Failure Analysis**: Calculates the Mean Squared Error (MSE) for each validation sample and computes the Pearson correlation between this error and key input features (Signal-to-Noise ratio, Nucleotide counts, Paired base counts) to identify systematic weaknesses.
5.  **Submission**: If the validation metric is below the threshold (0.6176461577), it generates predictions for the test set, formats them according to the competition requirements (filling unscored columns with 0.0), and saves the result to `./submission/submission.csv`.
