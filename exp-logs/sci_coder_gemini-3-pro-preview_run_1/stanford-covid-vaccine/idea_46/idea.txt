Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Discrete-Topology Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that resolves the limitations of continuous geometric encodings identified in Lesson 00113 by implementing **Discrete Topological Tokenization**, while strictly adhering to the robust backbone and training protocols of the "Current Best" solution.

# Model
**Architecture: Discrete-Topology Wide-Stream Residual BiGRU**
We will construct a deep recurrent network optimized for RNA sequence modeling that replaces continuous inductive biases with learnable topological manifolds.

*   **Proportional Input Embeddings**: We will maintain the **Heterogeneous Feature Embedding** strategy to balance information content **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Discrete Topological Distance (Structural Innovation)**: Instead of projecting raw distances through a fixed sinusoidal function (which enforces a continuous, smooth bias), we will **tokenize** the signed pairing distances into discrete bins (e.g., indices representing $\dots, -2, -1, 0, +1, +2, \dots$).
        *   **Mechanism**: We map the signed distance $d = j-i$ to an integer index (clipping at $\pm 32$ to handle long-range interactions). These indices look up learnable embedding vectors (**64 dim**).
        *   **Rationale**: RNA structural motifs often rely on specific, non-linear distance constraints (e.g., a loop of 4 bases is chemically distinct from 5). Discrete embeddings allow the model to learn arbitrary, discontinuous manifolds for these topological relationships, outperforming continuous encodings in hierarchical grammar tasks **Cite solution_lesson_node_00113**.

*   **Early Fusion**: The three embedding channels are **concatenated** (Total Dim 256) immediately. We strictly avoid independent normalization **Cite solution_lesson_node_00102** or dual-stream processing **Cite solution_lesson_node_00110** to preserve local feature coupling.

*   **Recurrent Stem**:
    *   The fused input is projected via a single **BiGRU layer** to the model's residual stream width $W$.
    *   **Capacity Control**: We will set the stream width $W$ to **384**. This width has proven robust and effective **Cite solution_lesson_node_00109**, whereas width 512 has consistently led to overfitting or optimization issues **Cite solution_lesson_node_00081**, **Cite solution_lesson_node_00112**.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem to preserve the fidelity of the initial projection **Cite solution_lesson_node_00109**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks** (adhering to the "Shallow and Wide" principle **Cite solution_lesson_node_00065**).
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We **maintain the full residual stream width** $W=384$ throughout (BiGRU hidden size 192 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiGRU but before the residual addition. This is strictly superior to Zoneout **Cite solution_lesson_node_00076**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061** or dense concatenation **Cite solution_lesson_node_00055**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **Distance Tokenization**: Pre-calculate the signed distance matrix from the structure string and map values to integer bins (e.g., bin 0 for distance 0, bin 1 for +1, etc., with clipping).
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is critical for stabilizing the deep recurrent backbone **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
