Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `set_seed` for reproducibility. Define the device (GPU/CPU).
2.  **Data Loading**: Use `get_dataloaders` to load training, validation, and test datasets. We will use the full provided training set (1728 samples) and validation set (432 samples) as the dataset size is small enough to train quickly (approx. 5-10 minutes) while maximizing the chance of meeting the performance threshold.
3.  **Model Initialization**: Instantiate the `RNAModel` (Discrete-Topology Wide-Stream Residual BiGRU) and move it to the device.
4.  **Training Loop**: Implement the training loop for `Config.EPOCHS` (20). Use `train_one_epoch` for training and `evaluate` for validation monitoring. Save the best model based on MCRMSE.
5.  **Final Validation**: Load the best model state. Perform a full evaluation on the validation set to compute the `Final Validation Metric`.
6.  **Failure Analysis**:
    *   Compute sample-wise Mean Squared Error (MSE) on the validation set.
    *   Load validation metadata (from `val.parquet`).
    *   Compute correlations between the sample-wise error and metadata features (`signal_to_noise`, `SN_filter`, sequence properties).
    *   Print the correlations to identify error sources.
7.  **Submission**: Check if the validation metric is below the threshold (0.6176461577). If so, generate predictions for the test set using `generate_submission` and save to `./submission/submission.csv`.
