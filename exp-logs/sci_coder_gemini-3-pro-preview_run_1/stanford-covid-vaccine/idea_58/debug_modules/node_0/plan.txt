### Implementation Strategy

1.  **Configuration Override**: Modify the global `Config` class attributes to adapt the pipeline for a rapid demonstration. This includes enabling `DEBUG` mode (to use a small data subset), reducing `EPOCHS` to 2, setting a small `BATCH_SIZE`, and redirecting cache/output directories to `./working` to avoid clutter.
2.  **Metric Verification**: Create synthetic ground truth and prediction arrays to verify the `calculate_mcrmse` function against a manual calculation, ensuring the scoring logic is correct.
3.  **Data Pipeline Verification**: Instantiate the DataLoaders using `get_dataloaders`. Iterate through a single batch from the training loader to assert the shapes of the sequence inputs, structural embeddings, targets, and masks.
4.  **Model Architecture Verification**: Initialize the `RNAModel` and perform a forward pass with the batch retrieved in the previous step. Assert that the output tensor shape matches `(Batch, Seq_Len, Num_Targets)`.
5.  **Loss Function Verification**: Calculate the loss using `masked_mse_loss` on the model output and assert it returns a valid scalar tensor.
6.  **Integration Run**: Execute the high-level `run_training` function. This tests the entire loop (training, validation, checkpointing, and inference) with the demo configuration.
7.  **Submission Validation**: Check for the existence of the generated submission CSV file and verify its dimensions and column names against the requirements.
