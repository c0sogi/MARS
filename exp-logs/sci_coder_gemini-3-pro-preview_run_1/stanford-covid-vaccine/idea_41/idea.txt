Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Capacity-Stabilized Proportional Wide-Stream BiGRU**. This strategy represents a structural evolution that finally unlocks the high-performance potential of the **Width 512** regime (identified in Lesson 00022) by resolving the specific optimization and overfitting bottlenecks that caused previous high-capacity attempts to fail (Lessons 00081, 00099, 00070, 00102). It synthesizes a **Proportional Embedding** interface with a **Stabilized Wide-Stream Backbone**.

# Model
**Architecture: Capacity-Stabilized Proportional Wide-Stream BiGRU**
We will construct a high-capacity deep recurrent network optimized for maximum information density and gradient stability.

*   **Proportional Input Embeddings (Structural Innovation)**:
    *   Instead of uniform embedding dimensions (which cause input bloat) or reduced dimensions (which cause bottlenecks), we will allocate capacity proportional to feature entropy **Cite solution_lesson_node_00099**.
    *   **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    *   **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the 7-class structural context.
    *   **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings** **Cite solution_lesson_node_00057**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones or RBFs **Cite solution_lesson_node_00042**.
    *   **Fusion**: These are concatenated (Total Dim 256) without independent normalization **Cite solution_lesson_node_00102**.

*   **Recurrent Stem**:
    *   The fused input is projected via a single **BiGRU layer** to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. We explicitly target this high capacity **Cite solution_lesson_node_00022**, relying on the specific regularization suite below to prevent the overfitting observed in previous attempts **Cite solution_lesson_node_00081**. The Stem ensures temporal contextualization **Cite solution_lesson_node_00046**.

*   **Backbone: Stabilized Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks** (adhering to the "Shallow and Wide" principle **Cite solution_lesson_node_00065**).
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We will **maintain the full residual stream width** $W=512$ throughout (BiGRU hidden size 256 per direction), explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041** and grouped recurrence **Cite solution_lesson_node_00098**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiGRU but before the residual addition. This is strictly superior to Zoneout for this task **Cite solution_lesson_node_00076** and is critical for stabilizing the 512-width backbone.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**, dense concatenation **Cite solution_lesson_node_00055**, or channel-wise weighting **Cite solution_lesson_node_00073**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). We enforce shared parameters to leverage inter-target correlations **Cite solution_lesson_node_00053** and keep the head simple **Cite solution_lesson_node_00048**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
    *   **No Auxiliary Tasks**: Do not predict error columns **Cite solution_lesson_node_00094**, **Cite solution_lesson_node_00096**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**. We rely on Inter-Layer Dropout and Proportional Embeddings for regularization.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is the critical missing component that caused previous high-capacity models to diverge **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
