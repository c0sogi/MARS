Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility. Define the device (GPU/CPU).
2.  **Data Loading**: Use the provided `library.data.load_data` function to load training, validation, and test datasets. Wrap them in PyTorch `DataLoader`s.
3.  **Model Initialization**: Instantiate the `CapacityStabilizedBiGRU` model from `library.model` (which wraps the architecture defined in `library.config`). Initialize the optimizer (AdamW) and scheduler (CosineAnnealingLR) as per the configuration.
4.  **Training Loop**: Execute the training loop for the specified number of epochs. Inside the loop, use `library.engine.train_one_epoch` for training and `library.engine.validate` for validation monitoring. Save the model weights whenever the validation MCRMSE improves.
5.  **Final Evaluation**: After training, load the best saved model state. Compute the final validation metric on the full validation set and print it in the required format.
6.  **Failure Analysis**: Calculate the element-wise squared errors on the validation set. Correlate the mean error per sample with metadata features (Signal-to-Noise, SN_filter, GC content) to identify sources of error. Print these correlations.
7.  **Submission Generation**: Check if the final validation metric is below the specified threshold (0.6199...). If so, generate predictions for the test set. Format the output to match the submission requirements (107 rows per sample, filling unscored columns with 0.0) and save to `./submission/submission.csv`.
