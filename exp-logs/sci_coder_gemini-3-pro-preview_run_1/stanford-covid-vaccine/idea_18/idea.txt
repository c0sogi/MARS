Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose an **Interleaved Wide-Stream BiGRU-MLP** strategy. This approach represents a structural evolution of the "Distance-Aware Residual BiGRU" (Idea 8) by integrating the "Wide Stream" and "Recurrent Stem" concepts from Lessons 00041 and 00046, and introducing a **Pointwise MLP** sub-layer to decouple feature processing from temporal propagation.

# Model
**Architecture: Interleaved Wide-Stream BiGRU-MLP**
We will construct a deep hierarchical encoder that interleaves temporal mixing (RNN) with channel-wise feature transformation (MLP), maintaining a high-capacity residual stream throughout.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide:
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers which dilute data in small regimes **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024**, while avoiding the pitfalls of RBFs **Cite solution_lesson_node_00042**.
*   **Recurrent Stem (Innovation)**:
    *   Instead of a linear projection, we will use a single **BiGRU layer** to project the concatenated embeddings into the model's hidden dimension $D$ (e.g., 384).
    *   **Rationale**: This ensures that the input to the first residual block is already temporally contextualized, aligning the semantic level of the skip connection with the processed path **Cite solution_lesson_node_00046**.
*   **Backbone: Interleaved Wide-Stream Blocks**:
    *   The encoder will consist of **5-6 Blocks**. Each block contains two residual sub-layers using the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**:
        1.  **Wide-Stream BiGRU**: A Bidirectional GRU layer. Crucially, we will **maintain the residual stream width**. If the stream dimension is $D$, the BiGRU will have hidden size $D/2$ (so output is $D$). We will **not** project this output back down or compress it, avoiding the information bottleneck **Cite solution_lesson_node_00041**.
            *   $x = x + \text{BiGRU}(\text{LN}(x))$
        2.  **Pointwise MLP (Structural Innovation)**: A dense Feed-Forward Network (Expansion factor 2-4, GeLU activation) applied to each position independently.
            *   $x = x + \text{MLP}(\text{LN}(x))$
            *   **Rationale**: Pure RNN stacks couple "memory" (temporal propagation) with "computation" (non-linear transformation). By interleaving Pointwise MLPs, we increase the model's capacity to process complex physicochemical features (channel mixing) at each step without increasing the gradient path length through time. This mimics the successful "Mixer" design of Transformers/Conformers while retaining the superior Sequential Inductive Bias of the RNN **Cite solution_lesson_node_00010**.
*   **Output Head**:
    *   A shared MLP projecting the final hidden states to **3 output channels**, corresponding strictly to the scored targets (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00019**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: We will process the complete 107-nucleotide sequence. We will **not crop** inputs, ensuring the model utilizes downstream structural information **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. We will only train on the three scored columns to prevent high-variance unscored noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: We will **not** mask any input tokens or perform auxiliary Masked Language Modeling, as it corrupts the precision regression signal **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE) **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally. We will **not** weight samples by their signal-to-noise ratio, avoiding the distribution mismatch that degrades performance on unweighted metrics **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler.

# Evaluation
*   **Metric Correction**: During the validation phase, we will calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: The test sequences (length 107) will be passed through the model to generate predictions for the 3 scored columns.
*   **Formatting**: We will construct the final submission file by placing the predictions into their respective columns and filling the unscored columns (`deg_pH10`, `deg_50C`) with 0.0. The results will be flattened to the `id_seqpos` format.
