Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **SWA-Optimized Pre-Mixed Wide-Stream BiGRU with Global Initialization**. This strategy represents a structural evolution of the "Scalar-Aggregated Wide-Stream Residual BiGRU" (Idea 19). It enhances the architecture with a **Non-Linear Feature Fusion Stem** and **Global Context Initialization** to maximize information extraction before temporal processing, and employs **Stochastic Weight Averaging (SWA)** to ensure robust generalization in this small-data regime.

# Model
**Architecture: Pre-Mixed Wide-Stream Residual BiGRU with Global Initialization**
We will construct a deep recurrent network designed to fuse local physicochemical features non-linearly and prime the recurrent state with global context.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide:
    1.  **Atomic Sequence**: Learnable embeddings for nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer this over RBFs **Cite solution_lesson_node_00042**.

*   **Non-Linear Feature Fusion (Structural Innovation)**:
    *   Before the recurrent stem, the concatenated embeddings (Sequence + Loop + Distance) will pass through a **Pointwise MLP** (Linear $\to$ GELU $\to$ Linear).
    *   **Rationale**: Standard concatenation relies on the BiGRU's linear input projection ($W_{ih}x$) to mix features. An explicit MLP allows the model to learn non-linear combinations of local features (e.g., "Adenine paired at distance +5") *before* temporal propagation begins, creating a richer feature set for the RNN while respecting the "Concatenation over Modulation" lesson **Cite solution_lesson_node_00057**.

*   **Global Context Initialization (Structural Innovation)**:
    *   We will compute the **Global Average Pool** of the fused embeddings across the sequence length.
    *   This global vector will be projected via a Linear layer to initialize the **hidden state ($h_0$)** of the Recurrent Stem.
    *   **Rationale**: Standard RNNs initialize with zero vectors. By priming the state with the sequence's global properties (e.g., GC content, overall loop density), we explicitly enhance the **Global Receptive Field** from the very first timestep **Cite solution_lesson_node_00004**, without the noise of "Input Injection" into deep layers **Cite solution_lesson_node_00035**.

*   **Recurrent Stem**:
    *   A single **BiGRU layer** processes the fused features and projects them to the model's residual stream width $W$ (e.g., 384). This ensures the input to the residual stack is temporally contextualized **Cite solution_lesson_node_00046**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **5-6 Blocks**.
    *   **Wide Stream Design**: We use **Pre-LayerNorm** **Cite solution_lesson_node_00017** and **maintain the full residual stream width** $W$ throughout, avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Structure**: $x = x + \text{BiGRU}(\text{LayerNorm}(x))$.

*   **Output Head**:
    *   **Scalar Mixture Aggregation**: We compute a learnable weighted sum of outputs from the Stem and all Blocks **Cite solution_lesson_node_00049**, **Cite solution_lesson_node_00055**.
    *   **Shared Projection**: A simple Linear layer maps the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00048**, **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training set. Train **only** on the three scored columns to prevent high-variance noise from diluting gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: Do **not** use auxiliary Masked Language Modeling **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW.
*   **Scheduler**: **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20) **Cite solution_lesson_node_00056**.
*   **Stochastic Weight Averaging (SWA) (Strategy Innovation)**:
    *   We will implement a simplified SWA/Checkpoint Averaging. We will save the model weights at the end of the last 5 epochs (where the learning rate is minimal due to Cosine Annealing).
    *   The final model will be the **arithmetic mean** of these checkpoints.
    *   **Rationale**: In small-data regimes with noisy loss landscapes, SWA finds a broader, flatter minimum that generalizes better than any single snapshot, providing a virtually free ensemble effect without increasing inference cost.

# Evaluation
*   **Metric Calculation**: Calculate MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00032**.
*   **Inference**: Pass full 107-length test sequences through the SWA-averaged model. Extract predictions for the 3 scored columns. Fill unscored columns (`deg_pH10`, `deg_50C`) with 0.0.
