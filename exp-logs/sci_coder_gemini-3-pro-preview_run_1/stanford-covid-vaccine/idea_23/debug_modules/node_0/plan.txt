Here is the implementation strategy:

1.  **Configuration Override**: We will modify the static `Config` class attributes at runtime to create a "demo mode". This involves reducing the number of epochs, model size (hidden dimensions, layers), and batch size to ensure the script executes quickly (within minutes) while still exercising the entire pipeline.
2.  **Component Verification**: Before running the full loop, we will instantiate individual components (Dataset, Model, Loss) and perform assertion checks.
    *   **Data Loading**: Verify that `get_dataloaders` returns batches with correct shapes and data types.
    *   **Model Forward Pass**: Pass a batch of data through `RNAModel` and assert that the output shape matches `(Batch, Seq_Len, Num_Targets)`.
    *   **Loss Logic**: specific verification for `MaskedMSELoss` to ensure it correctly ignores predictions beyond the scored sequence length (68), validating the masking mechanism.
3.  **Pipeline Execution**: We will execute the `run_training` function, which orchestrates the training, SWA (Stochastic Weight Averaging), and inference processes.
4.  **Output Validation**: Finally, we will verify that the submission file and model checkpoints are generated correctly in the specified working directories.
