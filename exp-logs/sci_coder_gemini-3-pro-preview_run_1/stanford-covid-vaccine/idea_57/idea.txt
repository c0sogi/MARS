Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Vector-Scaled High-Capacity Wide-Stream BiGRU** strategy. This approach represents a structural evolution that finally unlocks the high-performance potential of the **Width 512** regime (identified as critical in **Cite solution_lesson_node_00022**) by resolving the optimization bottlenecks of previous attempts. It synthesizes the robust "Wide-Stream" backbone with **Channel-Wise Residual Scaling (Vector LayerScale)** initialized to identity, strictly adhering to the stability protocols (Gradient Clipping, Low Weight Decay, Small Batch Size) that prevented convergence in prior high-capacity experiments.

# Model
**Architecture: Vector-Scaled High-Capacity Wide-Stream BiGRU**
We will construct a deep, high-capacity recurrent network optimized for precise feature selection and stable gradient propagation in the 512-width regime.

*   **Proportional Input Embeddings**: We will maintain the **Heterogeneous Feature Embedding** strategy to balance information content with parameter efficiency **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or discrete bins **Cite solution_lesson_node_00114**.
    *   **Fusion**: These are concatenated (Total Dim 256) without independent normalization **Cite solution_lesson_node_00102**.

*   **High-Fidelity Recurrent Stem**:
    *   The fused input is projected via a single **BiGRU layer** to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. We explicitly target this high capacity to maximize performance **Cite solution_lesson_node_00022**.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem to preserve the fidelity of the initial projection **Cite solution_lesson_node_00109**.

*   **Backbone: Vector-Scaled Residual Blocks (Structural Innovation)**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We **maintain the full residual stream width** $W=512$ throughout, explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Channel-Wise (Vector) Residual Scaling**: We introduce a learnable **diagonal matrix** (vector) $\Lambda_l \in \mathbb{R}^{512}$ for each block.
        *   Mechanism: $x_{l+1} = x_l + \Lambda_l \odot \text{Dropout}(\text{BiGRU}(\text{LayerNorm}(x_l)))$.
        *   **Rationale**: Unlike scalar gating which failed because it coupled all features **Cite solution_lesson_node_00141**, vector scaling allows the model to independently dampen or amplify specific feature channels in the 512-dimensional space.
        *   **Identity Initialization**: We initialize $\Lambda_l$ to **1.0** (all ones). This avoids the "dead layer" optimization trap caused by near-zero initialization in shallow networks **Cite solution_lesson_node_00084**, ensuring the model starts as a stable standard ResNet and progressively learns to regulate capacity.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** within the residual branch **Cite solution_lesson_node_00076**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns to prevent high-variance noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation to prevent feature conflicts **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is the critical stabilizer that allows the 512-width backbone to converge, preventing the divergences observed in previous high-capacity attempts **Cite solution_lesson_node_00097**.
    *   **Batch Size**: Strictly use **32**. Increasing to 64 reduces gradient updates and hurts performance in this low-data regime **Cite solution_lesson_node_00131**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
