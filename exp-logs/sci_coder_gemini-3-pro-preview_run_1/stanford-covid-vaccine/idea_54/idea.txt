Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Local-Global Parallel Wide-Stream BiGRU** strategy. This approach represents a structural evolution that resolves the "Local vs. Global" feature extraction trade-off by integrating a **Parallel Depthwise Convolution** stream within the recurrent backbone. This allows the model to explicitly capture local chemical motifs ($k$-mers) and global folding dependencies simultaneously, while unlocking the high-performance **Width 512** regime by strictly adhering to the stability protocols (Gradient Clipping, Low Weight Decay) identified as critical in Lessons 00097 and 00070.

# Model
**Architecture: Local-Global Parallel Wide-Stream BiGRU**
We will construct a high-capacity deep network that fuses sequence-native local processing with global recurrent context.

*   **Proportional Input Embeddings**: We will maintain the **Heterogeneous Feature Embedding** strategy to balance information content **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057**.

*   **Recurrent Stem**:
    *   The concatenated embeddings (Total Dim 256) are projected via a single **BiGRU layer** to the model's residual stream width $W$.
    *   **Capacity Scaling**: We will set the stream width $W$ to **512**. We explicitly target this high capacity to maximize performance **Cite solution_lesson_node_00022**.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem to preserve the fidelity of the initial projection **Cite solution_lesson_node_00109**.

*   **Backbone: Local-Global Parallel Blocks (Structural Innovation)**:
    *   The encoder will consist of **6 Blocks**.
    *   **Parallel Topology**: Instead of a single BiGRU, each block processes the input through two parallel branches:
        1.  **Global Branch**: A **BiGRU** (Hidden 256 per direction) to capture long-range folding dependencies.
        2.  **Local Branch**: A **Depthwise Conv1D** (Kernel Size 3, Padding 1) to explicitly model immediate neighbor interactions ($k$-mers) without the vanishing gradient issues of RNNs.
    *   **Fusion**: The outputs of both branches are summed: $h_{out} = \text{BiGRU}(x_{norm}) + \text{Conv1D}(x_{norm})$.
    *   **Rationale**: This hybrid design respects the "Sequence-Native" lesson **Cite solution_lesson_node_00009** but addresses the RNN's weakness in capturing sharp local motifs. By processing them in parallel (rather than stacked), we provide the gradient with a direct path for local features, stabilizing the optimization of the wide backbone.
    *   **Wide Stream Design**: We **maintain the full residual stream width** $W=512$ throughout **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the summation but before the residual addition **Cite solution_lesson_node_00076**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)** **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is the critical stabilizer that allows the 512-width backbone to converge, preventing the failures observed in previous high-capacity attempts **Cite solution_lesson_node_00097**.
    *   **Batch Size**: Strictly use **32**. Increasing to 64 reduces gradient updates and hurts performance **Cite solution_lesson_node_00131**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20) **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
