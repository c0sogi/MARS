Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Structure-Shortcut Deep Residual BiGRU** strategy. This approach represents a structural evolution of the "Distance-Aware Residual BiGRU" (Idea 8). It retains the successful backbone and feature engineering while introducing a novel **Structural Shortcut Head** to explicitly resolve the "Global Receptive Field" limitation of RNNs without the complexity of Transformers or the noise of Input Injection.

# Model
**Architecture: Structure-Shortcut Deep Residual BiGRU**
We will construct a deep recurrent network that processes the sequence-native context and fuses it with a direct "teleportation" of structural features at the decision layer.

*   **Input Embeddings**: We will concatenate three distinct feature channels per nucleotide:
    1.  **Atomic Sequence**: Learnable embeddings for the nucleotide identity (A, G, C, U). We strictly use **atomic character tokens**, rejecting K-mers which dilute data in small regimes **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Learnable embeddings for the structural context (S, M, I, B, H, E, X).
    3.  **Signed Sinusoidal Pairing Distance**: We will retain the **Explicit Geometric Encoding** strategy. For every nucleotide $i$ paired with $j$, we encode the **signed** scalar distance $j-i$ using **Sinusoidal Positional Encodings** **Cite solution_lesson_node_00016**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024**.
*   **Backbone: Deep Pre-LayerNorm Residual BiGRU**:
    *   The encoder will consist of **5-6 layers** of Bidirectional GRUs.
    *   **Pre-LayerNorm**: We will use the **Pre-LayerNorm** configuration (`x + GRU(Norm(x))`) to facilitate the training of this deep architecture **Cite solution_lesson_node_00017**.
    *   **Capacity**: We will maintain a **High Hidden Dimension (e.g., 384)**, as reducing width has been proven to degrade performance **Cite solution_lesson_node_00022**.
    *   **Standard Residuals**: We will **not** use Input Injection, adhering to the lesson that standard additive residuals handle noise better **Cite solution_lesson_node_00035**.
*   **Structural Shortcut Head (Innovation)**:
    *   Instead of predicting the target $y_i$ solely from the hidden state $h_i$, we will introduce a parameter-free structural gathering operation.
    *   For each position $i$, we identify its paired base index $j$ from the `structure`.
    *   We gather the hidden state $h_j$ (the "Partner State"). If $i$ is unpaired, we use a zero vector.
    *   We **concatenate** the local state and the partner state: $h_{fused} = [h_i; h_j]$.
    *   **Rationale**: This creates a direct information path (shortcut) from the paired base to the prediction site, bypassing the sequence length limitation of the RNN. Unlike previous attempts that did this at the *input* (which failed due to feature space explosion **Cite solution_lesson_node_00023**), doing this at the *output* allows the classifier to leverage the rich, high-level representations learned by the deep RNN, enforcing the physical constraint that stability is a coupled property of the base pair.
*   **Classifier**:
    *   A shared MLP projecting the fused vector $h_{fused}$ to **3 output channels** (scored targets).

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: We will process the complete 107-nucleotide sequence. We will **not crop** inputs, ensuring the model utilizes downstream structural information **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: We will explicitly discard the columns `deg_pH10` and `deg_50C` from the training data. We will only train on the three scored columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to prevent high-variance unscored noise from diluting the gradients **Cite solution_lesson_node_00019**.
    *   **No Masking**: We will **not** mask any input tokens or perform auxiliary Masked Language Modeling, as it corrupts the precision regression signal **Cite solution_lesson_node_00020**.

# Training
*   **Objective Function: Masked Mean Squared Error (MSE)**.
    *   **Loss**: We will strictly use **MSE (L2) Loss**. We will reject "Robust" losses (Huber/L1) to ensure the training objective aligns perfectly with the evaluation metric (RMSE) **Cite solution_lesson_node_00012**.
    *   **Masking**: The loss will be calculated **only** for the first 68 positions where ground truth is available **Cite solution_lesson_node_00002**.
*   **No Sample Weighting**: We will treat all samples equally. We will **not** weight samples by their signal-to-noise ratio, avoiding the distribution mismatch that degrades performance on unweighted metrics **Cite solution_lesson_node_00011**.
*   **Optimizer**: AdamW optimizer with a Cosine Annealing scheduler.

# Evaluation
*   **Metric Correction**: During the validation phase, we will calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact identified in previous experiments **Cite solution_lesson_node_00032**.
*   **Inference**: The test sequences (length 107) will be passed through the model. The Structural Shortcut will use the provided test structure to gather features.
*   **Formatting**: We will construct the final submission file by placing the predictions into their respective columns and filling the unscored columns (`deg_pH10`, `deg_50C`) with 0.0. The results will be flattened to the `id_seqpos` format.
