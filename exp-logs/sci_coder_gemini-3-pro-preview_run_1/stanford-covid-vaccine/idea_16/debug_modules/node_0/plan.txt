The following script demonstrates the end-to-end usage of the RNA degradation prediction pipeline. It performs the following steps:
1.  **Configuration**: Overrides default hyperparameters in `Config` to run in a fast "DEBUG" mode (small subset of data, 1 epoch, minimal batch size).
2.  **Data Verification**: Directly accesses the feature processing pipeline (`get_data`) and the PyTorch Dataset (`RNADataset`) to validate input shapes and data types.
3.  **Model Verification**: Instantiates the `StructureShortcutResBiGRU` model and performs a forward pass with a real batch to confirm output dimensions.
4.  **Training & Inference**: Executes the full training loop and inference pipeline using the `engine` module, resulting in a `submission.csv` file.
5.  **Output Validation**: Checks the generated submission file against the expected format.
