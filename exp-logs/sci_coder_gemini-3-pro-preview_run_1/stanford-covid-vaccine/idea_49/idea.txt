Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Spectral-Topological Wide-Stream Residual BiGRU** strategy. This approach represents a structural evolution that addresses the "Global Topology" gap identified in previous iterations by integrating **Laplacian Positional Encodings (LPE)**. This provides the model with a continuous, manifold-aware coordinate system derived from the RNA secondary structure, while strictly adhering to the robust **BiGRU Backbone** and **Stability Protocols** that have proven superior to high-capacity LSTMs or GNNs.

# Model
**Architecture: Spectral-Topological Wide-Stream Residual BiGRU**
We will construct a deep recurrent network that fuses atomic sequence data with spectral graph features to capture the global connectivity of the RNA fold without the noise of global attention.

*   **Heterogeneous Feature Embeddings**: We will implement the **Proportional Feature Embedding** strategy **Cite solution_lesson_node_00099**.
    1.  **Atomic Sequence**: High-dimensional embeddings (**128**) for nucleotide identity (A, G, C, U) to preserve high-frequency signal **Cite solution_lesson_node_00068**. We strictly use atomic tokens **Cite solution_lesson_node_00028**.
    2.  **Predicted Loop Type**: Moderate-dimensional embeddings (**64**) for the local structural context.
    3.  **Signed Sinusoidal Pairing Distance**: Moderate-dimensional embeddings (**64**) using **Fixed Sinusoidal Encodings**. We preserve the sign to distinguish upstream/downstream dependencies **Cite solution_lesson_node_00024** and strictly prefer fixed encodings over learnable ones **Cite solution_lesson_node_00057** or discrete bins **Cite solution_lesson_node_00114**.
    4.  **Laplacian Positional Encoding (Structural Innovation)**: We will introduce **Spectral Graph Embeddings**.
        *   **Graph Construction**: For each sample, we construct a graph where nodes are nucleotides and edges represent backbone links ($i, i+1$) and base pairs ($i, j$) from the `structure`.
        *   **Spectral Decomposition**: We compute the **Normalized Laplacian** of this graph and extract the first **8 non-trivial eigenvectors**.
        *   **Feature**: These eigenvectors provide a continuous, low-dimensional coordinate system that maps the global topology of the RNA (e.g., placing nodes in the same stem-loop close together in spectral space). We project these 8 values to a **32-dimensional** embedding.
        *   **Rationale**: Unlike pairwise distances (geodesic), LPE captures the "connectivity volume" and global community structure of the fold. Being a dense, continuous node-level feature, it respects **Early Fusion** **Cite solution_lesson_node_00110** and avoids the pitfalls of global attention **Cite solution_lesson_node_00106**.

*   **Recurrent Stem**:
    *   The concatenated embeddings (Total Dim ~288) are projected via a single **BiGRU layer** to the model's residual stream width $W$.
    *   **Capacity Control**: We will set the stream width $W$ to **384**. We explicitly choose **BiGRU** over BiLSTM and limit width to 384 because previous experiments demonstrated that BiLSTM (Lesson 00108) and Width 512 (Lesson 00081) consistently lead to optimization difficulties and overfitting in this low-data regime.
    *   **No Stem Dropout**: We strictly **remove dropout** from the output of this stem to preserve signal fidelity **Cite solution_lesson_node_00109**.

*   **Backbone: Wide-Stream Residual Blocks**:
    *   The encoder will consist of **6 Blocks**.
    *   **Wide Stream Design**: Each block uses the **Pre-LayerNorm** configuration **Cite solution_lesson_node_00017**. We **maintain the full residual stream width** $W=384$ throughout, explicitly avoiding bottleneck projections **Cite solution_lesson_node_00041**.
    *   **Inter-Layer Dropout**: We apply **Dropout (p=0.2)** after the BiGRU but before the residual addition. This is strictly superior to Zoneout **Cite solution_lesson_node_00076**.

*   **Aggregation: Scalar Mixture**:
    *   We will compute a learnable weighted sum of outputs from the Stem and all 6 Blocks. This **Global Static Aggregation** is superior to dynamic gating **Cite solution_lesson_node_00061**. We strictly **exclude** raw inputs from this mixture **Cite solution_lesson_node_00092**.

*   **Output Head**:
    *   A **Shared Linear Projection** mapping the aggregated vector to **3 output channels** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) **Cite solution_lesson_node_00053**.

# Data
*   **Preprocessing**:
    *   **Full-Context Processing**: Process the complete 107-nucleotide sequence. Do **not** crop inputs **Cite solution_lesson_node_00002**.
    *   **Target Filtering**: Explicitly discard `deg_pH10` and `deg_50C` from the training data. Train **only** on the three scored columns **Cite solution_lesson_node_00019**.
    *   **LPE Generation**: Pre-calculate the Laplacian Eigenvectors for each sample using the `structure` string.
    *   **No Masking/Augmentation**: Do **not** mask inputs **Cite solution_lesson_node_00020**. Do **not** use Structural Dropout or Causal Augmentation **Cite solution_lesson_node_00067**, **Cite solution_lesson_node_00069**.

# Training
*   **Objective Function**:
    *   **Masked Mean Squared Error (MSE)**: Calculate loss **only** for the first 68 positions **Cite solution_lesson_node_00002**.
    *   **Loss Type**: Strictly use **MSE (L2)**. Reject "Robust" losses (Huber/L1) to ensure alignment with the RMSE evaluation metric **Cite solution_lesson_node_00012**.
    *   **No Sample Weighting**: Treat all samples equally **Cite solution_lesson_node_00011**.
*   **Optimizer**:
    *   **AdamW** with **Low Weight Decay (e.g., 1e-4)**. We explicitly avoid high weight decay (1e-2) which suppresses recurrent signals **Cite solution_lesson_node_00070**.
    *   **Gradient Clipping**: Clip gradients to norm **1.0**. This is critical for stabilizing the deep recurrent backbone **Cite solution_lesson_node_00097**.
*   **Scheduler**:
    *   **Cosine Annealing** with `T_max` set to the fixed number of epochs (e.g., 20). This deterministic schedule is preferred over `ReduceLROnPlateau` for fixed-budget runs **Cite solution_lesson_node_00056**.

# Evaluation
*   **Metric Correction**: During validation, calculate the MCRMSE by **averaging the RMSE of each column (target)**, rather than averaging the RMSE of each position. This corrects the "Mean of Sqrts" artifact **Cite solution_lesson_node_00105**, **Cite solution_lesson_node_00032**.
*   **Inference**: Pass the test sequences through the model. Extract predictions for the 3 scored columns and fill unscored columns with 0.0.
