The strategy is to read the line-delimited JSON files (`train.json` and `test.json`) into Pandas DataFrames. A `source_file` column will be added to track the origin of each sample, which also serves as a target for the required file path verification. The training data will be split into training and validation sets (80:20) using a fixed random seed. If a signal-to-noise filter column (`SN_filter`) exists, it will be used for stratification; otherwise, a simple random split will be performed. The resulting datasets will be saved as Parquet files in the `./metadata` directory to preserve the list-based structure of the target columns. Finally, the script will reload the data to verify sample counts, split ratios, ID uniqueness, and the validity of the file paths.
