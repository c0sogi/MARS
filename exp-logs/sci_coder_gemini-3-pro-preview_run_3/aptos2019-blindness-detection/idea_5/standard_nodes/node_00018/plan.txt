The error is caused by passing `global_pool="gem"` to `timm.create_model` in `library/model.py`. The `timm` library's model factory for ConvNeXt (specifically the `SelectAdaptivePool2d` layer) does not support "gem" (Generalized Mean Pooling) as a valid string argument, raising an `AssertionError`. To fix this, I will change the `global_pool` argument to `"avg"` (Average Pooling), which is a standard and supported pooling method for this architecture.
