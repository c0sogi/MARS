The strategy implements a Progressive High-Resolution GeM-ConvNeXt pipeline. It utilizes a two-stage training process: first learning structural features on 512x512 images, then fine-tuning on 1024x1024 images with gradient accumulation to handle the increased memory load. The model uses a GeM pooling head to better capture fine-grained lesions and outputs a continuous regression score, which is optimized using MSE loss.
