# Proposed Strategy: Geometry-Preserving 2.5D U-Net++ with Curriculum Boundary Optimization

Based on the synthesis of previous failures and successes, I propose a comprehensive strategy that structurally evolves the model training pipeline. This approach integrates the superior architecture of **U-Net++** (Lesson 00020) with a **Geometry-Preserving** data paradigm (addressing Lesson 00022) and a **Curriculum Learning** objective to safely incorporate distance-based losses (resolving the conflict between Lesson 00010 and Lesson 00024).

### Model
**Architecture: 2.5D U-Net++ with Deep Supervision**
I will utilize the **U-Net++ (Nested U-Net)** architecture, which has proven superior to standard U-Net for this task due to its dense skip pathways that bridge the semantic gap for multi-scale organ segmentation (Cite solution_lesson_node_00020).
*   **Backbone**: **EfficientNet-B4**. This provides a deep, high-capacity feature extractor that, when paired with Deep Supervision, converges significantly faster than lighter backbones (Cite solution_lesson_node_00020).
*   **Deep Supervision**: This is a critical structural component. We will compute loss at multiple decoder levels (nested nodes). This provides direct gradient injection to early layers, preventing the model collapse observed when training complex backbones on sparse data (Cite solution_lesson_node_00024).
*   **Input Channels**: The model will accept a 3-channel input tensor representing slices $t-1, t, t+1$. This **2.5D representation** allows the 2D CNN to leverage volumetric context (continuity of organs) without the computational overhead of 3D convolutions (Cite solution_lesson_node_00004).

### Data
**Preprocessing: Geometry-Preserving Pipeline**
To address the metric degradation caused by warping images (Lesson 00022), I will implement an **Aspect-Ratio Preserving** preprocessing strategy.
*   **Pad-to-Square**: Instead of resizing (warping) images to fixed dimensions, we will resize the longest dimension to the target size (e.g., 320) and **pad** the shorter dimension with zeros. This preserves the physical shape of the organs, which is crucial for minimizing the Hausdorff distance.
*   **Robust Normalization**: We will strictly apply **Per-Slice Robust Normalization** (clipping to 1st/99th percentiles, then Min-Max scaling). We reject volume-global scaling (Cite solution_lesson_node_00004) and simple min-max (Cite solution_lesson_node_00002) to ensure consistent contrast handling.
*   **Full Dataset**: We will train on the **100% dataset**, as high-capacity models like U-Net++ require the full distribution to stabilize (Cite solution_lesson_node_00013).

### Training
**Protocol: Curriculum-Based Boundary Optimization**
To align the model with the competition metric (Lesson 00010) without triggering the model collapse observed when using complex losses from the start (Lesson 00024), I will implement a **Loss Curriculum**.
*   **Phase 1 (Warmup)**: Train using **BCE + Tversky Loss** with Deep Supervision. This phase focuses on maximizing overlap (Dice) and establishing a stable segmentation baseline.
*   **Phase 2 (Refinement)**: After the model stabilizes (e.g., Epoch 5), introduce **Boundary Loss** to the objective function. This explicitly penalizes the distance between predicted and ground-truth contours, directly optimizing the Hausdorff metric.
*   **Optimization**:
    *   **Stateful AMP**: Instantiate the `GradScaler` **outside** the epoch loop to ensure gradient scaling states persist, preventing training instability (Cite solution_lesson_node_00009).
    *   **Maximized Batch Size**: Use the largest possible batch size to stabilize Batch Normalization statistics (Cite solution_lesson_node_00007).

### Evaluation
**Validation: Coordinate-Corrected Volumetric Monitoring**
*   **Correction Step**: To fix the validation failure observed in Idea 5, we will implement **Coordinate-Corrected Validation**. Predictions generated in the padded model space (320x320) will be inverse-transformed (cropped and resized) back to the **original image space** before being compared to the ground truth. This ensures the metric reflects true performance (Cite solution_lesson_node_00025).
*   **Metric-Based Checkpointing**: We will ignore 2D Slice Dice. At the end of each epoch, we will reconstruct full 3D volumes from the validation set, apply 3D CCA, and save the checkpoint with the best **3D Competition Score** (Dice + Hausdorff) (Cite solution_lesson_node_00012).

**Inference: Topology-Aware Post-Processing**
*   **3D CCA**: We will apply **3D Connected Component Analysis** to the final predicted volumes, retaining only the largest connected component per class. This eliminates scattered false positives that disproportionately penalize the Hausdorff score (Cite solution_lesson_node_00005).
