The `RuntimeError: Unknown model (efficientnet-b4)` occurs because the `timm` library uses underscores instead of hyphens for EfficientNet model identifiers (Cite debug_lesson_3). Additionally, the attempt to override this setting in `runfile.py` failed because it assigned to `Config.Backbone` (case-sensitive mismatch) instead of `Config.BACKBONE`, leaving the original invalid string active (Cite debug_lesson_6). I will correct the string in `library/config.py` to use `efficientnet_b4` and update `runfile.py` to correctly target `Config.BACKBONE` with `efficientnet_b0`.
