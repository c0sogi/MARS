This script demonstrates the end-to-end pipeline for the stomach and intestine segmentation task using the provided library. It covers data loading, model initialization, loss computation, a training loop iteration, and metric validation.

The strategy involves:
1.  **Configuration Override**: Modifying the `Config` class to run in `DEBUG` mode with minimal epochs and batch sizes for rapid execution.
2.  **Data Verification**: Loading a batch from the data loader and asserting the correctness of input shapes (2.5D stacking) and target masks.
3.  **Model & Loss Verification**: Instantiating the U-Net++ model and the Curriculum Loss, running a forward pass, and verifying the output structure (Deep Supervision) and loss calculation.
4.  **Utility Verification**: Testing the RLE encoding/decoding and metric functions (Dice, Hausdorff) with synthetic data to ensure correctness.
5.  **Training Loop**: Executing the `fit` function from the engine to demonstrate the training and validation process on a small data subset.
