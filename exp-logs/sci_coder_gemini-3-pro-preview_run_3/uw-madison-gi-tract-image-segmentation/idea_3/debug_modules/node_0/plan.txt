The following script demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Configuration & Setup**: Sets random seeds and overrides configuration parameters (epochs, batch size) to ensure the demonstration runs quickly.
2.  **Data Preparation**: Loads the metadata, subsets it to a small number of cases for speed, and creates training and validation DataLoaders using `UWMadissonDataset`.
3.  **Model & Loss Verification**: Instantiates the `SegmentationModel` and `BCETverskyLoss`, passing a single batch to verify forward pass shapes and loss calculation.
4.  **Training Loop**: Executes a complete training run (1 epoch) using the `Trainer` class on the reduced dataset, triggering training, validation, metric calculation, and model checkpointing.
5.  **Utility Verification**: Explicitly tests the RLE encoding/decoding and metric functions (`get_dice_score`, `get_3d_hausdorff`) with synthetic data to ensure correctness.
