The following script demonstrates the end-to-end usage of the provided machine learning pipeline for the UW-Madison GI Tract Segmentation task.

### Strategy Outline
1.  **Configuration Setup**: We first import the `Config` class and override specific hyperparameters (e.g., `EPOCHS`, `BATCH_SIZE`, `DEBUG_SAMPLE_SIZE`) to ensure the script runs quickly and fits within the compute constraints for this demonstration.
2.  **Data Pipeline Verification**: We manually load the metadata, invoke the `prepare_data` function to generate 2.5D context (slice $t-1, t, t+1$), and instantiate the `UWDataset`. We verify that the dataset yields tensors of the correct shape and data type.
3.  **Model & Loss Verification**: We instantiate the `UNetEfficientNet` model and the `BCETverskyLoss`. We perform a forward pass with a dummy batch to confirm the model architecture produces the expected output dimensions and that the loss function calculates a valid scalar gradient.
4.  **Metric Validation**: We create synthetic ground truth and prediction masks to validate the logic of the `dice_coef` and `hausdorff_3d` functions, ensuring they handle edge cases (like empty masks) correctly.
5.  **Training Integration**: We execute the `run_training` function in debug mode. This tests the full training loop, including data loading, backpropagation, validation, and checkpoint saving.
6.  **Inference Integration**: We execute the `predict` function in debug mode. This tests the inference loop, 3D post-processing (CCA), RLE encoding, and submission file generation.
7.  **Final Checks**: We assert that the expected artifacts (model checkpoint and submission CSV) are created in the working directory.
