The following strategy outlines the implementation of a self-contained Python script to demonstrate the cactus classification pipeline:

1.  **Configuration**: Initialize the `Config` class with `debug=True`. This reduces the dataset size (to 500 samples) and the number of epochs (to 2), ensuring the script executes quickly (within minutes) while still exercising all code paths.
2.  **Data Loading**: Use `get_dataloaders` to retrieve training and validation sets for a specific fold. We will assert that the batch shapes are correct (32x32 images).
3.  **Model Instantiation**: Create a `resnet34` model using `get_model`. We will verify that the "stem surgery" (modifying the first convolutional layer for small images) is correctly applied by inspecting the kernel size and stride of the first layer.
4.  **Training**: Execute the training loop using `fit_model`. This function handles training, validation, early stopping, and generates Out-Of-Fold (OOF) predictions. We will verify that the returned OOF predictions match the size of the validation set.
5.  **Inference**: Load the best checkpoint saved during training and generate predictions on the test set using `predict` (which includes Test-Time Augmentation logic).
6.  **Stacking**: Demonstrate the ensemble capability by creating a dummy second set of predictions (perturbed version of the first). We will use `train_meta_learner` to fit a logistic regression on these OOF predictions and `predict_stack` to generate the final ensemble probabilities.
7.  **Submission**: Finally, use `generate_submission` to save the results to a CSV file in the required format.
