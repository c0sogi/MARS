# Optimized Strategy: Residual Network with Test-Time Augmentation

## Model
I propose replacing the sequential SimpleCNN with a **Residual Neural Network (ResNet)** architecture specifically adapted for 32x32 input resolution. Unlike the previous linear stack of layers, this architecture introduces **residual blocks** containing skip connections. These connections allow gradients to flow more easily through the network, enabling the training of a deeper model to capture more subtle textural features of the cacti without suffering from performance degradation.
- **Structure**: The model will consist of an initial convolution layer (preserving spatial dimensions), followed by three stages of residual blocks (each containing two 3x3 convolutions, Batch Normalization, and ReLU), and concluding with Global Average Pooling and a single dense output layer.

## Data
- **Preprocessing**: Images will be converted to floating-point tensors and normalized to the [0, 1] range.
- **Augmentation**: Building on the empirical findings regarding domain invariants, the training pipeline will employ a targeted augmentation strategy. This includes **RandomVerticalFlip** and **RandomRotation** to exploit the top-down aerial perspective where orientation is arbitrary, and **ColorJitter** (adjusting brightness and contrast) to resolve the model's previously identified sensitivity to lighting conditions. ## Training
- **Optimizer & Scheduler**: The model will be trained using the **Adam** optimizer with **Binary Cross Entropy** loss. To further refine the weights, a **Cosine Annealing** learning rate scheduler will be introduced.
- **Checkpointing**: A strict early stopping mechanism will be used. Crucially, when the Validation AUC improves, the model's state dictionary will be saved using **`copy.deepcopy(model.state_dict())`**. This ensures that the stored weights are a distinct snapshot of the best performance and are not implicitly updated by the optimizer in subsequent epochs. Cite `solution_lesson_node_00001`

## Evaluation
- **Inference Strategy**: To maximize the AUC score, the evaluation process will implement **Test Time Augmentation (TTA)**. For each test image, the model will predict probabilities for the original image as well as horizontally and vertically flipped versions. These predictions will be averaged to produce the final `has_cactus` probability. This pipeline step structurally enforces the geometric invariance principles identified in the lessons, smoothing out noise and improving robustness.
