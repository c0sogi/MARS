The error arises because `predict_tta` iterates over the `loader` assuming it yields only image tensors (as is typical for a test loader), but in the `runfile.py` demonstration, it is called with `val_loader`. The `val_loader` yields batches of `(images, labels)` tuples (collated as lists), which causes the loop variable `images` to be a list instead of a tensor. Since lists do not have a `.to()` method, the code fails.

To fix this, I will modify `predict_tta` in `library/engine.py` to check the structure of the yielded batch. If the batch is a list or tuple (indicating the presence of labels), it will unpack the images from the first element; otherwise, it will treat the batch as the images tensor itself.
