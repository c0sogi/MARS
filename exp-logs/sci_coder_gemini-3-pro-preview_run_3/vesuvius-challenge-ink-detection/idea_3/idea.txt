Based on the accumulated lessons, I propose the **Parallel-Scale Dilated Network (PSDN)**. This solution evolves the architecture from a serial dilated FCN to a parallel multi-scale aggregation structure, enhancing the model's ability to simultaneously resolve fine ink strokes and suppress broad texture noise without sacrificing spatial resolution.

### Model: Parallel-Scale Dilated Network (PSDN)
The architecture is a fully convolutional network that maintains the original image resolution throughout, specifically designed to capture multi-scale context without the information loss associated with downsampling.

1.  **Learnable 2.5D Projection (Input Stage):**
    The network initializes with a `1x1` convolution to project the high-dimensional input `(Batch, 65, H, W)` into a compact feature space (e.g., 32 channels). This retains the highly effective "soft" slice selection mechanism, allowing the model to learn the optimal weighting of depth slices while keeping the backbone lightweight **Cite solution_lesson_node_00002**, **Cite solution_lesson_node_00004**.

2.  **Parallel Atrous (Dilated) Backbone:**
    Instead of stacking dilated convolutions serially (as in the previous best FCN), this architecture utilizes **Parallel Atrous Blocks**. Within each block, the feature map is processed by multiple parallel convolutional branches with different dilation rates (e.g., $r=1, 2, 4, 8$).
    *   **Structural Innovation:** These branches are fused (concatenated and projected) at the end of each block. This allows the model to simultaneously capture **local high-frequency details** (rate 1, essential for sharp ink boundaries) and **global geometric context** (rate 8, essential for distinguishing ink from fiber texture) at the same network depth.
    *   This design leverages the benefits of expanded receptive fields **Cite solution_lesson_node_00003** while strictly adhering to the requirement of maintaining full spatial resolution (no pooling or strided convolutions) **Cite solution_lesson_node_00008**.

3.  **Deep & Lean Design:**
    The network will consist of a deep stack of these parallel blocks but will maintain a constant, low channel width (e.g., 32 or 64) throughout. This acts as a structural regularizer, preventing overfitting to spatial noise in the limited training data **Cite solution_lesson_node_00004**.

### Data: Robust Sampling and Geometric Invariance
1.  **Preprocessing:**
    Input volumes will be Z-score normalized using global statistics to ensure consistent intensity distributions.

2.  **Geometric Augmentation:**
    During training, input patches will undergo random horizontal/vertical flips and discrete 90-degree rotations. This forces the model to learn rotationally invariant features, which is critical for distinguishing ink from oriented papyrus fibers **Cite solution_lesson_node_00005**.

3.  **Low-Variance Validation:**
    To address the high metric volatility observed in previous experiments, the validation process will use a **large, fixed set of patches** (e.g., 4,000+ or a dense grid) rather than a small random subsample. This ensures that the "best model" selection is based on a stable signal rather than sampling noise **Cite solution_lesson_node_00010**, **Cite solution_lesson_node_00007**.

### Training: Balanced Optimization
1.  **Loss Function:**
    The model will be trained using a **Balanced Loss** (e.g., `BCE + Dice`) rather than a skewed Tversky loss. Even though the metric (F0.5) is skewed towards precision, training with a balanced objective produces a higher quality probability landscape. The precision bias will be handled via threshold tuning during post-processing **Cite solution_lesson_node_00011**.

2.  **Optimization:**
    Use the Adam optimizer. Early stopping will be employed, but decisions will be based on the stabilized validation metric described above.

### Evaluation: TTA and Threshold Tuning
1.  **Tiled Inference with TTA:**
    Predictions will be generated using overlapping tiles. **Test-Time Augmentation (TTA)** (averaging predictions from rotated and flipped versions of the input) will be applied to further suppress false positives caused by specific fiber orientations **Cite solution_lesson_node_00005**.

2.  **Post-Training Threshold Optimization:**
    Instead of using a fixed threshold of 0.5, the optimal decision threshold will be explicitly searched for on the validation set to maximize the F0.5 score. This effectively adapts the balanced model output to the precision-heavy metric **Cite solution_lesson_node_00011**.
