Based on the comprehensive analysis of the "Lessons" and "Previous Ideas," I propose the **Wide Sequential Dilated Network with Auxiliary Boundary Supervision (WSDN-ABS)**.

This solution synthesizes the high-capacity feature extraction of the most successful architecture (Lesson 00036) with a new structural regularization strategy to enforce the learning of geometric continuity over texture memorization. It explicitly rejects the trade-offs that caused recent failures (thinning the backbone, U-Net connections, Group Norm) and introduces auxiliary supervision to directly address the model's struggle with structural definition.

### Model: Wide Sequential Dilated Network with Auxiliary Boundary Supervision

The architecture is a high-capacity, fully convolutional network operating at full resolution, designed to maximize receptive field and feature definition without succumbing to the instability of complex connectivity or insufficient channel width.

1.  **Learnable 2.5D Projection (Input Stage):**
    The network initializes with a learnable `1x1` convolution to project the 65-channel volumetric input into a **64-channel** feature space.
    *   **Retention:** We retain the "soft" slice selection mechanism **Cite solution_lesson_node_00002**.
    *   **Optimization:** We strictly maintain a **64-channel width** (doubled from early baselines). Previous experiments proved that "Wider" backbones generalize significantly better than "Thin" ones, even if it requires a smaller batch size **Cite solution_lesson_node_00040**, **Cite solution_lesson_node_00036**.

2.  **Wide Sequential Dilated Backbone:**
    The core is a deep stack of **Dilated Residual Blocks** arranged sequentially with dilation rates $r = 1, 2, 4, 8, 16$.
    *   **Sequential Hierarchy:** We adhere to the sequential arrangement, proven superior to parallel blocks for hierarchical feature extraction **Cite solution_lesson_node_00015**.
    *   **Full Resolution:** No downsampling (pooling) is used to preserve pixel-thin ink traces **Cite solution_lesson_node_00008**.
    *   **No Skip Connections:** We explicitly reject U-Net style long-range skip connections, as they were shown to propagate background noise in this low-SNR task **Cite solution_lesson_node_00035**.
    *   **Normalization:** We use **Batch Normalization (BN)**. We reject Group Normalization, as it degrades performance on sparse signals **Cite solution_lesson_node_00037**.

3.  **Auxiliary Boundary Head (Structural Innovation):**
    The network splits into two parallel `1x1` convolutional heads at the output:
    *   **Primary Head:** Predicts the binary Ink Mask.
    *   **Auxiliary Head:** Predicts the **Ink Boundaries** (edges).
    *   **Rationale:** This forces the shared backbone to explicitly encode high-frequency structural edges and distinguish them from the texture of papyrus fibers. It acts as a structural regularizer, addressing the "Error-to-Intensity" correlation **Cite solution_lesson_node_00017** without adding inference latency (the aux head is discarded at test time).

### Data: Global Consistency and Boundary Generation

1.  **Preprocessing:**
    Input volumes are Z-score normalized using **Global Statistics** (mean/std) from the training set to preserve physical density signals **Cite solution_lesson_node_00028**.

2.  **Target Generation:**
    *   **Ink Masks:** Standard binary labels.
    *   **Boundary Masks:** Generated on-the-fly during training (e.g., by calculating the morphological difference between dilated and eroded versions of the ground truth mask).

3.  **Patch Size & Augmentation:**
    *   **Large Context:** Training will strictly use **256x256 patches**. We reject smaller patches as they destroy the structural context required for the dilation hierarchy **Cite solution_lesson_node_00019**.
    *   **Geometric Augmentation:** Random horizontal/vertical flips and discrete 90-degree rotations are applied to enforce rotational invariance **Cite solution_lesson_node_00005**.

### Training: Joint Optimization and Regularized Sampling

1.  **Loss Function:**
    The model is trained on a joint objective: $L_{total} = L_{mask} + \lambda L_{boundary}$.
    *   $L_{mask}$: **Balanced Loss** (`BCE + Dice`). We avoid skewed Tversky losses during training to ensure a high-quality probability landscape **Cite solution_lesson_node_00011**.
    *   $L_{boundary}$: Weighted BCE to handle the sparsity of edge pixels.

2.  **Batch Size Strategy:**
    We use a **Batch Size of 8**. While small, previous successful experiments confirmed that a 64-channel model with BS=8 outperforms a 32-channel model with BS=32 **Cite solution_lesson_node_00040**, **Cite solution_lesson_node_00036**.

3.  **Sampling Regularization:**
    We explicitly **limit the number of patches sampled per epoch** (e.g., 12,000). This prevents the model from overfitting to the specific fiber patterns of the single training fragment, acting as a necessary regularizer **Cite solution_lesson_node_00034**.

### Evaluation: Precision-Oriented Inference

1.  **Tiled Inference with TTA:**
    Predictions are generated using overlapping tiles with **Test-Time Augmentation (TTA)** (averaging 4 rotations $\times$ 2 flips). This is essential for suppressing false positives from oriented fibers **Cite solution_lesson_node_00033**.

2.  **Dynamic Threshold Tuning:**
    The optimal binarization threshold is explicitly searched for on the validation set to maximize the F0.5 score. This adapts the balanced model output to the precision-heavy metric **Cite solution_lesson_node_00033**. The auxiliary boundary output is ignored during inference.
