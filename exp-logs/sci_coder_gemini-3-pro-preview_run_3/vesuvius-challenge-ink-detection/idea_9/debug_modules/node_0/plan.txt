### Implementation Strategy

1.  **Configuration Setup**: We will import the `Config` class and override specific parameters (e.g., `MAX_PATCHES_PER_EPOCH`, `EPOCHS`, `BATCH_SIZE`) to ensure the demonstration runs quickly and uses minimal resources.
2.  **Data Loading Verification**: We will use `load_fragment_data` to load a sample fragment ('2') and verify the structure and dimensions of the returned volume, mask, and labels. We will then instantiate the `InkDataset` with explicit normalization statistics to bypass the time-consuming global statistics calculation, and verify the shape of the tensors produced by the `__getitem__` method.
3.  **Model Architecture Check**: We will instantiate the `ESDN_PCH` model and perform a forward pass with a dummy input tensor matching the expected dimensions. We will assert that the output shape is correct (Batch, 1, Height, Width).
4.  **Loss Function Test**: We will initialize the `BCEDiceLoss` and compute the loss between the model's dummy output and a random target tensor to ensure the loss calculation logic is valid and returns a scalar.
5.  **Training & Evaluation Loop**: We will create a minimal `DataLoader` and run `train_one_epoch` and `evaluate` for a single iteration. This verifies the integration of the model, data, optimizer, and loss function without training for a full duration.
6.  **Inference Utilities**:
    *   **RLE Encoding**: We will create a known small binary mask and assert that `rle_encode` produces the expected run-length encoded string.
    *   **Threshold Optimization**: We will use synthetic probability and label arrays to verify that `optimize_threshold` correctly identifies a threshold that maximizes the F0.5 score.
    *   **Tiled Inference**: We will generate a synthetic 3D volume (smaller than the real data but larger than the patch size) and run `predict_tiled`. We will verify that the output probability map matches the spatial dimensions of the input.
