Implementation Strategy:
1.  **Configuration Setup**: We will override specific `Config` parameters (like `CACHE_DIR`, `BATCH_SIZE`, `EPOCHS`, and `DEBUG_SAMPLE_SIZE`) to ensure the script runs quickly and uses a separate cache directory within `./working`.
2.  **Utility Verification**: We will validate the `rle_encode` and `fbeta_score` functions with simple synthetic data to ensure the metric logic is correct.
3.  **Data Pipeline**: We will instantiate the `InkDataset` and `DataLoaders` using the `debug=True` flag to load a tiny subset of the data. We will verify the shape of the tensors (Volumes and Labels).
4.  **Model Initialization**: We will initialize the `HDNPCA` model, move it to the configured device, and perform a forward pass with a dummy batch to verify the architecture and output dimensions.
5.  **Training Loop**: We will execute `train_one_epoch` on the small training subset to demonstrate the optimization process and verify that the loss is calculated.
6.  **Evaluation**: We will run the `evaluate` function on the validation subset to check the F0.5 score calculation.
7.  **Inference Workflow**: Instead of running the monolithic `run_inference` (which processes the full dataset), we will manually compose the inference steps (`predict_full_map`, `find_best_threshold`, `generate_submission`) using a limited test dataset to demonstrate the submission generation process efficiently.
