The following script demonstrates the end-to-end usage of the provided Vesuvius Challenge Ink Detection library.

### Implementation Strategy
1.  **Verification of Utilities**: We first validate the helper functions `rle_encode` and `fbeta_score` using synthetic data to ensure the metric logic is correct.
2.  **Dataset Initialization**: We instantiate `InkDataset` for both 'train' and 'val' splits. Note that this step involves loading the 3D X-ray volumes into memory and caching them to the `./working` directory, which may take a minute due to the data size (~12GB). We set `patches_per_epoch` to a small value (4) to make the subsequent training iteration extremely fast.
3.  **Model Setup**: We initialize the `InkDetectorFCN` model and verify its forward pass with a dummy input tensor to confirm shape compatibility.
4.  **Training Loop**: We run `train_model` for a single epoch. This demonstrates the integration of the data loader, loss function (`BCEDiceLoss`), optimizer, and validation loop. The model weights are saved to `./working/demo_model.pth`.
5.  **Inference & Submission**: We call `generate_submission` using the saved model. This function processes the test set (loading volumes, running tiled inference, applying thresholds, and RLE encoding) and produces the required `submission.csv`.
6.  **Final Assertions**: We verify that the submission file exists and contains data.
