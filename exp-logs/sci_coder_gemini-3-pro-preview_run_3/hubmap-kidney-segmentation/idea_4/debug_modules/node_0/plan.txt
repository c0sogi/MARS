The following script demonstrates the usage of the provided HuBMAP kidney segmentation library. It validates the core components—including RLE utilities, stain deconvolution, dataset loading, model architecture, and loss calculation—before running a complete (but minimized) training and inference cycle.

The script modifies the global `Config` to run in `DEBUG` mode with reduced epochs and batch sizes, ensuring the demonstration completes quickly while exercising all relevant code paths.
