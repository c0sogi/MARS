The `RuntimeError: Trying to resize storage that is not resizable` occurs because the `DataLoader` is attempting to collate tensors backed by read-only or file-mapped memory (`numpy.memmap`). In `library/dataset.py`, the ground truth masks are loaded using `np.load(..., mmap_mode='r')`. When a slice of this mask (`mask_crop`) is converted to a numpy array, the underlying storage might still be linked to the file mapping or flagged as non-resizable, especially if the slice was not padded (padding creates a copy). To fix this, we must explicitly force a copy of the data into standard heap memory using `copy=True` when creating the final numpy array for the mask. We will also apply `.copy()` to the image tensor to ensure it is contiguous and in writable memory, preventing similar issues (Cite debug_lesson_6).
