The following script demonstrates the end-to-end pipeline for Functional Tissue Unit (FTU) detection using the provided library files. It covers data processing (loading, tiling, normalization), dataset creation, model instantiation, loss calculation, a complete training epoch, and inference on the test set.

Strategies for optimization and verification:
1.  **Data Processing**: We manually invoke specific processing functions (`read_tiff`, `macenko_normalize`, `rasterize_json_polygons`) on a small region of interest to verify logic without processing gigapixel images.
2.  **Dataset**: We use the `debug=True` flag and a reduced `tile_size` (256x256) to drastically reduce memory usage and initialization time.
3.  **Model & Training**: We run a single epoch with a small batch size. We verify the model's deep supervision outputs and the loss function's ability to handle them.
4.  **Inference**: We execute the inference pipeline on the test set using the model trained in the previous step, ensuring the submission file is generated correctly and contains valid RLE data.
