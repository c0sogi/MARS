### Implementation Strategy

1.  **Environment Setup**: Import necessary libraries and the provided modules (`library.config`, `library.utils`, etc.). Set random seeds for reproducibility.
2.  **Artifact Cleanup**: Define a helper to clean the working directory (`./working/idea_1`) to ensure tests run on fresh states and don't accidentally reuse cached data from previous steps (e.g., dataset tiles).
3.  **Component Verification**:
    *   **Utils**: Verify `rle_encode`/`rle_decode` consistency, `polygons_to_mask` correctness, and `dice_coef` calculation.
    *   **Dataset**: Load the training metadata, slice it to a single image for speed, and instantiate `HuBMAPDataset`. Verify that it generates tiles and that `__getitem__` returns tensors of the correct shape.
    *   **Model & Loss**: Instantiate `FPNResNet18` and `BCEDiceLoss`. Pass dummy tensors to verify the forward pass output shape and loss scalar calculation.
    *   **Training**: Configure `Config` for a minimal run (1 epoch, batch size 2). Execute `run_training(debug=True)` and assert that the model checkpoint is saved.
    *   **Inference**: Execute `generate_submission_csv(debug=True)` and assert that the submission CSV is generated with the correct format.
4.  **Execution**: Run all verification steps sequentially within the `if __name__ == "__main__":` block.
