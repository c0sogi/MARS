The error `RuntimeError: Unknown model (tu-convnext_tiny)` occurs because the configuration uses the `segmentation_models_pytorch` naming convention (`tu-` prefix), but the code in `library/model.py` instantiates the model directly using `timm.create_model`. The `timm` library does not recognize the `tu-` prefix and expects the standard model identifier `convnext_tiny`. To resolve this, I will update `ENCODER_NAME` in `library/config.py` to match the exact string identifier required by the `timm` registry. Cite debug_lesson_2.
