This script demonstrates the end-to-end usage of the provided library for the Jigsaw Toxicity Classification task. It performs the following steps:

1.  **Data Preparation**: Loads the metadata CSVs and creates smaller subsets for training and validation to ensure the demonstration runs quickly. It saves the training subset to a temporary file to allow the vocabulary builder to process just the subset.
2.  **Configuration Override**: Modifies the global `Config` class attributes at runtime to point to the temporary subset files and adjusts hyperparameters (reducing epochs and batch size) for a rapid execution cycle.
3.  **Training**: Instantiates the `Trainer` class and executes the training loop. It verifies that the model trains without error and produces a validation score.
4.  **Prediction**: Runs inference on a subset of the test data using the trained model and saves the submission file.
5.  **Verification**: Includes assertions to validate that the submission file is created correctly, contains the expected columns, and that the model state was successfully updated and saved.
