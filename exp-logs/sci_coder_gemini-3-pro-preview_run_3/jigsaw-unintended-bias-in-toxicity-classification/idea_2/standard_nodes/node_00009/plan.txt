To optimize the model's performance and bias mitigation, I will implement Multi-Task Learning (MTL) using auxiliary toxicity labels, as recommended in **Cite solution_lesson_node_00008**. This involves adding a secondary classification head to the DistilBERT model to predict toxicity subtypes (e.g., `identity_attack`, `threat`), which helps the model disentangle specific toxic features from identity mentions. I will also scale the training to the full dataset (1.44M samples) and increase the epoch count to 2 to ensure sufficient exposure to rare identity subgroups.
