The implementation strategy involves creating an end-to-end orchestration script `runfile.py` that leverages the provided library modules to train a DistilBERT-based toxicity classifier with stochastic identity masking.

**Strategy Outline:**
1.  **Configuration & Setup**: Initialize the environment and seed for reproducibility. We will override specific `Config` parameters to create a "Fast Baseline" suitable for the 2-hour limit. Specifically, we will set `EPOCHS` to 1 and subsample the training data to 1,000,000 samples (approx. 70% of the dataset) to balance execution speed with the high performance requirement.
2.  **Data Preparation**: Load the training metadata, perform the subsampling, and save the subset to the working directory. We will dynamically update `Config.TRAIN_PATH` to point to this new subset.
3.  **Training**: Instantiate the `Trainer` class (which uses the modified configuration) and execute the training loop. The trainer handles the DistilBERT model initialization, data loading, and optimization.
4.  **Validation**: After training, we will manually run an inference pass on the full validation set using the trained model. We will compute the competition's custom weighted AUC metric using `JigsawEvaluator` and print it in the required format.
5.  **Failure Analysis**: We will analyze the model's errors on the validation set by calculating the correlation between the absolute prediction error and input features (text length and identity attributes) to identify systematic biases.
6.  **Submission**: We will check if the final validation metric exceeds the strict threshold of `0.8997695301144136`. If successful, we trigger the `trainer.predict_and_submit()` method to generate predictions on the test set and save the `submission.csv` file.
