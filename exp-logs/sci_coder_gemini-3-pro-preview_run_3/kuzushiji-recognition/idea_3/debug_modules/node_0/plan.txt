Implementation Strategy:
1.  **Configuration & Setup**: Import the `Config` class and override specific configurations (paths, batch sizes, epochs) to create a lightweight "demo" environment within a dedicated `./working/demo_run` directory. This ensures the script runs quickly and doesn't interfere with existing outputs.
2.  **Data Preparation**: Create "mini" metadata files by sampling the first few rows of the provided training, validation, and test metadata CSVs. This allows us to use the real data pipeline without processing the entire dataset.
3.  **Component Verification**:
    *   **Datasets & DataLoaders**: Initialize the data loaders using the mini metadata. Fetch a single batch from both the detector and classifier loaders to verify tensor shapes and data types.
    *   **Models**: Instantiate the `KuzushijiDetector` and `KuzushijiClassifier`. Perform a dummy forward pass with random tensors to confirm the model architecture produces outputs with the expected dimensions.
    *   **Metrics**: validate the `calc_modified_f1` function with a manually constructed test case to ensure the scoring logic works as defined.
4.  **Training Loop Demonstration**: Execute the `fit_detector` and `fit_classifier` functions for 1 epoch using the mini datasets. This validates the training engine, loss calculation, and model checkpointing.
5.  **Inference & Submission**: Run the `generate_submission` function using the trained "mini" models on the mini test set. This verifies the end-to-end inference pipeline, including tiling, NMS, and output formatting.
