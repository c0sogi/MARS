The issue is that `set_seed` is defined as a standalone function in the global scope of `library/config.py`, but `runfile.py` attempts to invoke it as a method of the `Config` class (`Config.set_seed(42)`). This mismatch triggers an `AttributeError`. To fix this, I will move the `set_seed` function definition inside the `Config` class and decorate it with `@staticmethod`. This ensures the function is accessible as `Config.set_seed`, aligning the definition with the existing call site (Cite debug_lesson_1).
