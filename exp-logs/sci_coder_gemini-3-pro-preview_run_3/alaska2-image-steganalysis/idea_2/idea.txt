Based on the empirical findings and lessons learned, I propose the **SRM-EfficientNet** strategy. This approach structurally evolves the feature extraction capabilities of the model while implementing a specific data sampling strategy to maximize the Weighted AUC metric.

# Model
**Architecture: SRM-EfficientNet with GeM Pooling**
The model architecture is upgraded to a specialized steganalysis network that moves beyond the single-filter approach.
1.  **Multi-Residual Stem (Structural Innovation):** Replace the single high-pass filter with a **Fixed SRM Filter Bank**. This layer consists of 30 non-trainable $5 \times 5$ convolutional kernels derived from the Spatial Rich Models (SRM) framework. Unlike the single KV kernel, this bank extracts residuals across multiple orientations and correlations, providing a much richer "noise map" to the backbone. **Cite solution_lesson_node_00001**.
2.  **Backbone:** Process the 30-channel noise map using an **EfficientNet-B0** backbone. The first convolutional layer of the EfficientNet is modified to accept 30 input channels instead of 3. This backbone offers superior parameter efficiency and feature hierarchy compared to ResNet-18.
3.  **Pooling:** Replace the standard Global Average Pooling with **Generalized Mean (GeM) Pooling**. Since steganographic artifacts can be localized or sparse, GeM pooling allows the network to focus on high-activation regions (salient noise) rather than diluting the signal through simple averaging.

# Data
**Preprocessing**
1.  **Channel Extraction:** Continue to extract and use only the **Luminance (Y)** channel from the YCbCr color space, as this contains the majority of the steganographic signal. **Cite solution_lesson_node_00001**.
2.  **Augmentation:** Apply Dihedral group augmentations (rotations and flips) during training to exploit the grid-aligned nature of JPEG compression without destroying the signal.

**Sampling Strategy**
1.  **Class Balancing:** Address the 1:3 class imbalance (1 Cover vs. 3 Stego algorithms) by **Oversampling the Minority (Cover) Class**. Instead of undersampling the Stego images (which reduces data diversity), use a weighted sampler to ensure that Cover images appear in the batch with the same frequency as the sum of all Stego images. This effectively repeats each Cover image approximately 3 times per epoch, tightening the decision boundary around the "clean" distribution and improving specificity for the Weighted AUC. **Cite solution_lesson_node_00005**.

# Training
**Procedure**
1.  **Loss Function:** Use **Binary Cross Entropy with Logits**.
2.  **Optimizer:** Use **AdamW** with a cosine annealing learning rate scheduler.
3.  **Label Smoothing:** Apply mild label smoothing (e.g., 0.05) to prevent overfitting to the noisy labels.
4.  **Validation:** Monitor the Weighted AUC on the validation set, which must be strictly split by `ImageID` to prevent leakage.

# Evaluation
**Prediction Strategy**
1.  **Test Time Augmentation (TTA):** For each test image, generate predictions for the original image and its 3 rotated versions (90, 180, 270 degrees).
2.  **Aggregation:** Average the sigmoid scores of the 4 views to produce the final stability score. This reduces variance and improves the robustness of the detection.
