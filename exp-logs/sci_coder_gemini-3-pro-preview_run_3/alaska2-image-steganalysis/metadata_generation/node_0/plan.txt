To ensure a robust validation strategy, I will use Group Sampling (via `GroupShuffleSplit`) based on the image ID, ensuring that all versions of a specific image (Cover and its stego counterparts) reside exclusively in either the training or validation set, preventing data leakage. Finally, the script will generate metadata for the test set, save all files to the `./metadata` directory, and perform the required validation checks, including file path resolution and split integrity verification.
