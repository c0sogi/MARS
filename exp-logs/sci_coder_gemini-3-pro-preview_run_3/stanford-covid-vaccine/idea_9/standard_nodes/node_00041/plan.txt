Based on the lessons learned, specifically **Lesson 00040** (Complexity Penalty) and **Lesson 00031** (Optimizing Convergence), the strategy is to simplify the model architecture and extend the training duration. The previous attempt with a Multi-Scale Inception stem and a deeper 3-layer GRU led to overfitting and degraded performance compared to a simpler baseline.

Therefore, I will:
1.  **Simplify Architecture**: Revert the `InceptionStem` to a standard `Conv1d` stem (kernel size 3) and reduce the BiGRU backbone from 3 layers (384 units) to 2 layers (256 units). This aligns with the finding that architectural simplicity acts as regularization in low-data regimes (Cite solution_lesson_node_00040).
2.  **Optimize Convergence**: Increase the training epochs from 15 to 50. The previous best solution achieved its score with 50 epochs using Cosine Annealing, allowing the model to settle into a better minimum (Cite solution_lesson_node_00031).

class InceptionStem(nn.Module):
    """
    Multi-Scale Inception Stem.
    Applies parallel 1D convolutions with different kernel sizes to capture
    local structural motifs at varying resolutions (single nucleotide, codon, etc.).
    """

    def __init__(self, in_channels, out_channels_per_branch, kernel_sizes):
        super(InceptionStem, self).__init__()
        self.branches = nn.ModuleList()

        for k in kernel_sizes:
            # padding='same' ensures the output sequence length matches the input length.
            # This is valid for odd kernel sizes with stride=1.
            self.branches.append(
                nn.Conv1d(
                    in_channels=in_channels,
                    out_channels=out_channels_per_branch,
                    kernel_size=k,
                    padding="same",
                )
            )

        self.activation = nn.GELU()

    def forward(self, x):
        """
        Args:
            x (torch.Tensor): Input tensor of shape (Batch, In_Channels, Seq_Len).
        Returns:
            torch.Tensor: Output tensor of shape (Batch, Out_Channels * Branches, Seq_Len).
        """
        # Apply each branch in parallel
        branch_outputs = [branch(x) for branch in self.branches]

        # Concatenate outputs along the channel dimension (dim=1)
        out = torch.cat(branch_outputs, dim=1)

        # Apply activation
        out = self.activation(out)
        return out
