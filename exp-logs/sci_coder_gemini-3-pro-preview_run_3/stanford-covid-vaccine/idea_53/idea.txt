# Proposed Strategy: Deep Stabilized Bias-Refined Decoupled BiGRU with Multi-Task Learning

This strategy represents the "Corrected & Stabilized" evolution of the architecture. It combines a **4-Layer BiGRU** (maximizing capacity) with a **Stabilized MLP-Gated Interaction Module**. Crucially, it satisfies the conflicting normalization constraints identified in Lessons 75, 78, and 79 by applying normalization *only* to the internal hidden layer of the gating MLP. Furthermore, it explicitly trains on all 5 targets to leverage the shared physical constraints of the auxiliary data, correcting the regression observed in Lesson 94.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers. **Cite solution_lesson_node_00027**.

3.  **Deep Stabilized Backbone:**
    *   The backbone consists of **4 Blocks** (maximizing capacity within safe limits, addressing **Cite solution_lesson_node_00026**). Each block contains a **Bidirectional GRU** followed by the **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** Hidden dimension of **384**. **Cite solution_lesson_node_00063**.
    *   **Decoupled Structural Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **Decoupled Message (Bias-Refined):** $m_{ij} = \text{GELU}(W_{msg} \cdot h_j + b_{msg})$. We do **not** concatenate $h_i$ here. Crucially, for unpaired bases ($h_j=0$), this term becomes the bias $b_{msg}$, effectively serving as a learnable "loop embedding" to allow self-refinement. **Cite solution_lesson_node_00080** and **Cite solution_lesson_node_00085**.
        *   **Stabilized MLP Gate:**
            *   Project Joint Context: $z_{raw} = W_{g1} \cdot [h_i; h_j]$. We do **not** normalize this input to preserve sparsity semantics. **Cite solution_lesson_node_00079**.
            *   **Internal Normalization:** $z_{norm} = \text{LayerNorm}(z_{raw})$. This stabilizes the MLP internals, preventing saturation issues. **Cite solution_lesson_node_00075**.
            *   Activation: $z_{act} = \text{GELU}(z_{norm})$.
            *   Logit Projection: $logits = W_{g2} \cdot z_{act}$.
            *   **No Logit Norm:** $g_{ij} = \sigma(logits)$. We strictly avoid normalizing logits to allow the gate to fully saturate (open/close). **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. This ensures stability for the deep 4-layer stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.

### Data

1.  **Preprocessing:**
    *   Generate adjacency maps for gather operations.
    *   **Caching:** Use hash-based caching to ensure pipeline integrity. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   Train on the **entire training dataset** (~1,728 samples). Explicitly reject subsampling and filtering to avoid distribution shift. **Cite solution_lesson_node_00015** and **Cite solution_lesson_node_00071**.

### Training

1.  **Objective (Multi-Task Learning):**
    *   Optimize the standard **MCRMSE** on **all 5 target columns**. We explicitly revert to Multi-Task Learning to utilize the auxiliary signal from `deg_pH10` and `deg_50C`, as training only on scored targets degraded performance. **Cite solution_lesson_node_00094**.
    *   No inverse-variance weighting. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **AdamW** with **Cosine Annealing**. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** Max norm 1.0. This is **mandatory** for the 4-layer hybrid architecture. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Metric Integrity:**
    *   **Slicing:** Slice predictions/targets to the first 68 positions (`seq_scored`) *before* metric calculation. **Cite solution_lesson_node_00066**.
    *   **Column Filtering:** Calculate Validation MCRMSE **only on the 3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) for model selection, even though we train on all 5. **Cite solution_lesson_node_00076**.
    *   **Global Aggregation:** Concatenate tensors for the full validation set before calculation. **Cite solution_lesson_node_00045**.

2.  **Inference:**
    *   Generate predictions for 107 positions, slice to 68 for submission.
