# Proposed Strategy: Channel-Wise Gated Structural-Refinement BiGRU (CGSR-BiGRU)

This strategy represents a **Structural Evolution** of the interaction mechanism introduced in the previous best model. While the DISR-BiGRU successfully routed information across structural pairs, it relied on a **scalar** gating mechanism, effectively treating the structural connection as an "all-or-nothing" switch. This new architecture introduces **Channel-Wise Gating**, allowing the model to selectively filter specific feature channels during the structural injection. This provides fine-grained control over the information flow (e.g., propagating base-pairing constraints while blocking noise), mimicking the selective permeability of biological interactions.

### Model

The architecture is a **Deep BiGRU with Interleaved Channel-Wise Structural Gating**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** We do **not** concatenate paired features at the input stage, preserving the purity of the local sequence for the convolutional stem. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** This projects sparse inputs into a dense embedding space and aggregates local k-mers to initialize the backbone. **Cite solution_lesson_node_00027**.

3.  **Channel-Wise Refinement Backbone:**
    *   The backbone consists of **3 Blocks**. Each block contains a **Bidirectional GRU** followed by a **Channel-Wise Interaction Module** (except the final block).
    *   **BiGRU Layer:** High-capacity Bidirectional GRU (Hidden Dimension = 384). We prioritize BiGRUs over Transformers for their superior inductive bias on short sequences. **Cite solution_lesson_node_00017**. We maximize capacity over complexity. **Cite solution_lesson_node_00026**.
    *   **Channel-Wise Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$ in the structure:
        *   **Gather:** Retrieve the full hidden state vector $h_j$ directly. We trust the latent representation of the encoder and avoid windowed gathering. **Cite solution_lesson_node_00058**.
        *   **Channel-Wise Gating:** Instead of a scalar gate, we compute a feature-vector gate $z_{ij} \in \mathbb{R}^{384}$ using a non-linear projection: $z_{ij} = \sigma(W_{gate} \cdot [h_i; h_j] + b)$.
        *   **Selective Injection:** The update is performed element-wise: $h'_i = h_i + z_{ij} \odot (W_{proj} \cdot h_j)$. This allows the model to independently regulate the flow of different features (e.g., allowing "pairing stability" signals while blocking "noise" signals) across the structural edge.
        *   **Stabilization:** We apply **Layer Normalization** to $h'_i$ before passing it to the next BiGRU block. This stabilizes the distribution of features in the deep recurrent stack, addressing the stability concerns raised in **Cite solution_lesson_node_00046**.

4.  **Output Head:**
    *   A final Linear layer projects the output of the last BiGRU block to the 5 target values.

### Data

1.  **Preprocessing:**
    *   We will parse the structures to generate adjacency maps for the gather operations.
    *   **Caching:** We will use **hash-based caching** for the preprocessed data (e.g., `train_data_{hash(config)}.npy`) to ensure the pipeline integrity. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios. We explicitly reject filtering to avoid distribution shift relative to the public test set. **Cite solution_lesson_node_00015**.

### Training

1.  **Objective (Unweighted Loss):**
    *   We will optimize the standard **MCRMSE** on all 5 target columns. We will **not** use inverse-variance weighting, as down-weighting noisy samples degrades performance on the unweighted competition metric. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. This is critical for convergence to a deep minimum. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** We will explicitly apply **Gradient Clipping** (max norm 1.0) to the training loop. This is **mandatory** to stabilize the deep, hybrid recurrent architecture and prevent exploding gradients. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Global Metric Aggregation:**
    *   We will implement a **Global Evaluation Loop** that concatenates predictions and targets for the entire validation set *before* calculating the MCRMSE. We will **not** average batch-wise RMSEs, as this produces optimistically biased results. **Cite solution_lesson_node_00045**.

2.  **Inference:**
    *   The test set sequences will be processed through the Stem and the Channel-Wise Refinement Backbone.
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) for submission.
