This script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:

1.  **Environment Setup**: Configures a reproducible environment and suppresses unnecessary warnings.
2.  **Data Preparation**: Creates a small subset of the training, validation, and test data to ensure the demonstration runs quickly (within seconds/minutes).
3.  **Component Verification**: Validates core utility functions like `get_pair_map` and `one_hot_encode` with assertions.
4.  **Pipeline Execution**:
    *   Initializes the `Config` and overrides paths to use the demo dataset.
    *   Processes data using `get_dataloaders` (demonstrating the caching mechanism).
    *   Instantiates the `SpatiallyAugmentedBiGRU` model and verifies the forward pass.
    *   Runs the `Trainer` for a few epochs to demonstrate the training loop and metric calculation.
    *   Generates a submission file using the trained model.
5.  **Final Validation**: Checks the structure and integrity of the generated submission file.
