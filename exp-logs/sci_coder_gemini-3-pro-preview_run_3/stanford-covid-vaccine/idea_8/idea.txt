# Proposed Strategy: Spatially-Augmented Convolutional BiGRU

This strategy synthesizes the structural innovation of **Spatial Feature Augmentation** (Idea 7) with the robust architectural and training baseline established in the "Current Best" solution (Idea 5/6). It specifically corrects the implementation errors—namely the use of weighted loss and reduced training data—that caused the spatial augmentation approach to underperform in previous iterations.

### Model

The architecture is a **Spatially-Augmented Bidirectional GRU with a Convolutional Stem**. It is designed to "linearize" the 3D RNA folding structure into the local feature space, allowing a standard recurrent backbone to process long-range base-pairing interactions as immediate local dependencies.

1.  **Input Representation (Structural Innovation):**
    *   **Feature Construction:** We will strictly use **One-Hot Encoding** for the nucleotide sequence, secondary structure (dot-bracket), and predicted loop type, resulting in a base vector of 14 channels. We avoid learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Spatial Augmentation:** We explicitly construct the input tensor to capture 3D topology. For every position $i$, we identify its paired partner $j$ from the secondary structure. We then concatenate the feature vector of position $j$ to the feature vector of position $i$. If a base is unpaired, we concatenate a zero vector.
    *   **Result:** This transforms the input from shape $(N, 107, 14)$ to $(N, 107, 28)$. This allows the model to instantly assess the stability of a base pair (e.g., G-C vs. G-U) without needing a Graph Neural Network to pass messages across the sequence. **Cite solution_lesson_node_00033** and **Cite solution_lesson_node_00010**.

2.  **Convolutional Stem:**
    *   The augmented input is passed through a **1D Convolutional Layer** (kernel size 3, filters 256) followed by a **GELU** activation.
    *   This projects the sparse, binary input features into a dense, context-aware embedding space. It aggregates local n-gram context before recurrent processing, which is critical for sparse sequence data. **Cite solution_lesson_node_00027**.

3.  **Backbone (BiGRU):**
    *   We employ a standard **2-layer Bidirectional GRU** with a hidden dimension of 256.
    *   We prioritize the **BiGRU** over Transformers due to its superior inductive bias for short sequences and limited data. **Cite solution_lesson_node_00017**.
    *   We use the standard, optimized implementation (fused kernels) rather than a custom residual stack, as residual connections provided no benefit for this shallow depth. **Cite solution_lesson_node_00032**.

4.  **Output Head:**
    *   A final Linear layer projects the hidden states to the 5 target values for each position.

### Data

1.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject the filtering strategy used in Idea 3, as training on the full noisy distribution is required to generalize to the noisy public test set. **Cite solution_lesson_node_00015**.

2.  **Robust Pipeline:**
    *   We will implement **hash-based caching** for the preprocessed data. This ensures that the complex spatial augmentation logic is correctly executed and versioned, preventing stale data loading. **Cite solution_lesson_node_00011**.

### Training

1.  **Objective (Unweighted Loss):**
    *   We will optimize the standard **MCRMSE** (Mean Columnwise Root Mean Squared Error) on all 5 target columns.
    *   Crucially, we will **not** use the inverse-variance weighted loss proposed in Idea 7. Since the competition metric is unweighted, penalizing noisy samples degrades performance by biasing the model away from the test set distribution. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Scheduler:**
    *   We will use **AdamW** combined with a **Cosine Annealing Learning Rate Scheduler**. This dynamic learning rate is essential for converging to a deep minimum and preventing the premature plateaus observed with constant learning rates. **Cite solution_lesson_node_00031**.

3.  **Regularization:**
    *   Dropout will be applied after the Convolutional Stem and between GRU layers to prevent overfitting.

### Evaluation

1.  **Internal Validation:**
    *   We will calculate the validation metric specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to ensure our internal benchmarking aligns with the competition leaderboard. **Cite solution_lesson_node_00017**.

2.  **Inference:**
    *   For the test set, we will generate the spatially augmented features using the provided test structures (pairing position $i$ with $j$) and pass them through the model.
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) and flattened for the final submission.
