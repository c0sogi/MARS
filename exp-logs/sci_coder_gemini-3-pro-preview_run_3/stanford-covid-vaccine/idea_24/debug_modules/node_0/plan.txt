This script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Configuration Setup**: Overrides the default `Config` to use a temporary directory and reduce training epochs for a quick demonstration.
2.  **Data Pipeline Verification**: Initializes the `RNADataset` via `get_loader`, fetches a batch, and asserts the correctness of input shapes (sequence, adjacency, mask) and target shapes.
3.  **Model Architecture Verification**: Instantiates the `RNAModel`, performs a forward pass with the fetched batch, and verifies the output dimensions.
4.  **Loss Function Verification**: Computes the MCRMSE loss and scored metrics, ensuring they return valid scalar values.
5.  **Training Loop Execution**: Runs a full training cycle (1 epoch) using the `run_training` function to validate the optimization pipeline, checkpointing, and validation logic.
6.  **Inference & Submission**: Executes `generate_submission` to predict on the test set and verifies the format and dimensions of the generated CSV file.
7.  **Cleanup**: Removes the temporary directory used for the demonstration.
