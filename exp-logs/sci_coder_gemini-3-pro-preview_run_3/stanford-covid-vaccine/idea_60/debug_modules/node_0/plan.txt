The following script demonstrates the complete pipeline for the RNA degradation prediction task using the provided library modules. It performs the following steps:

1.  **Configuration Override**: Adjusts `Config` parameters (reducing epochs, batch size, and dataset size) to ensure the demonstration runs quickly and efficiently.
2.  **Data Loading**: Uses `get_dataloaders` in debug mode to load a small subset of the data, verifying the shape and integrity of the batches (inputs, targets, adjacency matrices, and masks).
3.  **Model Verification**: Instantiates the `HCSDBR_BiGRU` model, performs a forward pass with a sample batch, and asserts that the output shape matches the expected dimensions `(Batch, Sequence_Length, Num_Targets)`.
4.  **Metric & Loss Verification**: Validates the `MCRMSELoss` function and the competition-specific `scored_mcrmse` metric to ensure they produce valid scalar values.
5.  **Training Loop**: Executes a full training cycle for one epoch using `run_training`, ensuring the training pipeline functions correctly without errors.
6.  **Inference & Submission**: Runs inference on the test set, formats the predictions according to the competition requirements (flattening sequence positions), and generates a valid `submission.csv` file.
