The following script demonstrates the usage of the provided library modules (`config`, `utils`, `data`, `model`, `train`) to solve the RNA degradation prediction task.

### Implementation Strategy
1.  **Configuration Override**: We first modify the `Config` class attributes to set up a lightweight demonstration environment (reduced model size, smaller batch size, CPU execution) to ensure the script runs quickly.
2.  **Data Processing**: We utilize `process_data` to load the training and test data from the provided Parquet files in `./metadata`. We verify the integrity of the loaded data using assertions.
3.  **Dataset & DataLoader**: We instantiate `RNADataset` and wrap it in a `DataLoader`. We inspect a single batch to confirm the shapes of inputs, structural masks, and targets.
4.  **Model Initialization**: We initialize the `RNAModel`. We verify that the architecture adapts to the overridden configuration (e.g., input dimensions, hidden sizes).
5.  **Forward Pass & Loss**: We perform a forward pass on a batch of data and calculate the loss using `MCRMSELoss`. We perform a manual calculation check to ensure the loss function logic is correct.
6.  **Training & Validation**: We run a single training epoch and a validation step using the provided functions `train_epoch` and `validate`.
7.  **Inference & Submission**: We demonstrate how to generate predictions for the test set and format them into the required submission structure.
