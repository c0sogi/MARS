Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class and set random seeds for reproducibility.
2.  **Training**: Execute the training pipeline using `run_training` from the library. We limit the epochs to 25 to ensure the "Fast Baseline" requirement is met while still allowing convergence on this dataset size.
3.  **Inference & Validation**:
    *   Load the best saved model checkpoint.
    *   Perform inference on the full validation set to retrieve raw predictions.
    *   Compute the **MCRMSE** metric specifically on the scored columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) and the first 68 sequence positions.
    *   Print the `Final Validation Metric` with full precision.
4.  **Failure Analysis**:
    *   Calculate per-sample error magnitudes.
    *   Merge these errors with validation metadata (loaded from `val.parquet`).
    *   Compute and print correlations between the error and key features like `signal_to_noise`, `SN_filter`, `GC_content`, and `unpaired_ratio` to identify systematic weaknesses.
5.  **Submission Generation**:
    *   Check if the validation metric is below the specified threshold (0.5884495377540588).
    *   If successful, run inference on the test set.
    *   Format the predictions into the required CSV format (flattening `id` and `seqpos`, including all 5 target columns for all 107 positions).
    *   Save the result to `./submission/submission.csv`.
