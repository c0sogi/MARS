This strategy represents the **High-Capacity Topology-Disentangled Synthesis**. It resolves the critical trade-off identified in **Lesson 103** (Backbone Capacity is dominant) by maintaining the massive **4-Layer Backbone**. Crucially, it addresses the "Loop Silencing" paradox (**Lesson 85**) and the "Self-Loop Noise" issue (**Lesson 64**) by introducing a **Topology-Disentangled Interaction Module**. Unlike previous iterations that either ignored unpaired bases (zero-masking) or treated them as generic neighbors (self-loops), this approach explicitly splits the processing stream into two specialized paths with distinct parameters: one for rigid paired regions (Stems) and one for flexible unpaired regions (Loops).

# Proposed Strategy: High-Capacity Topology-Disentangled BiGRU (HC-TD-BiGRU)

This strategy introduces a **4-Layer Bidirectional GRU** with a **High-Capacity Hidden Dimension** (384 per direction, 768 total). It interleaves this backbone with a **Topology-Disentangled Structural Injection** module. This module applies distinct, specialized transformations for **Paired Bases** and **Unpaired Bases**, allowing the model to learn distinct physical laws for different structural contexts without parameter interference, stabilized by rigorous normalization protocols.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers to initialize the backbone. **Cite solution_lesson_node_00027**.

3.  **High-Capacity 4-Layer Backbone:**
    *   The backbone consists of **4 Blocks** (maximizing capacity to capture complex dependencies, addressing **Cite solution_lesson_node_00026**). Each block contains a **Bidirectional GRU** followed by the **Disentangled Interaction Module** (except the final block).
    *   **BiGRU Layer:** Hidden dimension of **384** (Total 768). We explicitly maintain this high capacity, as narrowing the backbone caused severe degradation in previous stabilized attempts. **Cite solution_lesson_node_00103** and **Cite solution_lesson_node_00063**.
    *   **Topology-Disentangled Interaction Module (Structural Innovation):**
        *   **Mechanism:** We apply a hard switch based on the adjacency mask $M_{pair}$ (1 if paired, 0 if unpaired).
        *   **Path A: Paired Interaction (Stems):**
            *   **Source:** Neighbor state $h_j$.
            *   **Message:** **GLU** ($W_{p1} h_j \odot \sigma(W_{p2} h_j)$). Provides rich non-linear modulation. **Cite solution_lesson_node_00062**.
            *   **Gate:** **Full-Rank Stabilized MLP** taking $[h_i; h_j]$. Uses Internal LayerNorm to prevent saturation **Cite solution_lesson_node_00075**, but no Logit Norm **Cite solution_lesson_node_00078**.
            *   **Update:** $u_{paired} = Gate_p([h_i; h_j]) \odot Message_p(h_j)$.
        *   **Path B: Unpaired Refinement (Loops):**
            *   **Source:** Self state $h_i$.
            *   **Message:** **GLU** ($W_{u1} h_i \odot \sigma(W_{u2} h_i)$). Uses **distinct weights** from Path A. This solves "Loop Silencing" by allowing data-dependent updates for loops **Cite solution_lesson_node_00085**, while avoiding the noise of shared-weight self-loops **Cite solution_lesson_node_00064**.
            *   **Gate:** **Full-Rank Stabilized MLP** taking $h_i$.
            *   **Update:** $u_{unpaired} = Gate_u(h_i) \odot Message_u(h_i)$.
        *   **Fusion:** $u_{total} = M_{pair} \cdot u_{paired} + (1 - M_{pair}) \cdot u_{unpaired}$.
        *   **Injection:** $h_{res} = h_i + u_{total}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. Ensures stability for the deep 4-layer stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
