### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` object and set random seeds for reproducibility. We will override the default number of epochs to 15 to ensure the "fast baseline" requirement is met while still allowing convergence on this small dataset (~1.7k samples).
2.  **Data Loading**: Utilize `load_or_process_data` to load training and validation datasets. We will also load the raw validation metadata (Parquet) to extract auxiliary features (like Signal-to-Noise ratio) required for the failure analysis.
3.  **Model Training**: Instantiate the `RNAModel` (Deep Decoupled Post-Norm BiGRU). We will execute a training loop using `train_epoch` and `validate` from the provided libraries. We implement a "Best Model" checkpointing mechanism based on the MCRMSE score.
4.  **Validation & Failure Analysis**:
    *   After training, load the best model state.
    *   Compute the final validation metric on the full validation set.
    *   **Failure Analysis**: Calculate the RMSE per sample. Correlate this error with metadata features (Signal-to-Noise, SN_filter, and GC content calculated from sequences) to identify error sources.
5.  **Conditional Submission**:
    *   Check if the final validation metric is below the threshold (0.5978901386).
    *   If successful, load the test set, generate predictions for all 107 positions, format them into the required `id_seqpos` structure, and save the submission file.
