### Implementation Strategy

1.  **Configuration Setup**: Initialize the `Config` class and override specific parameters (enabling debug mode, reducing epochs to 1, setting a small subset size) to ensure the demonstration runs quickly within the provided environment.
2.  **Component Verification (Unit Tests)**:
    *   **Data Utils**: Manually verify `one_hot_encode` and `get_adjacency_info` with simple inputs to ensure feature generation logic is correct.
    *   **Loss Function**: Create dummy prediction and target tensors with known values to verify that `MCRMSELoss` and `calculate_mcrmse` correctly slice the sequences and compute the metric.
    *   **Model Architecture**: Instantiate `RNAModel`, pass synthetic data through it, and assert that the output shape matches `(Batch, Seq_Len, Num_Targets)`.
3.  **Pipeline Integration**:
    *   Execute the full training pipeline using `train_model` with the modified configuration. This tests data loading, the training loop, validation, and model saving.
    *   Execute the submission generation using `generate_submission` to verify inference and output formatting.
4.  **Assertions**: Validations are placed at each step to confirm expected behaviors (shapes, values, file existence).
