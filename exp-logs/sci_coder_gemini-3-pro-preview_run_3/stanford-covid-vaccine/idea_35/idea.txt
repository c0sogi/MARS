# Proposed Strategy: Deep Decoupled Channel-Gated BiGRU (DDCG-BiGRU)

This strategy represents the "Corrected Deep Evolution" of the architecture. It synthesizes the high-capacity **4-Layer Backbone** with a rigorously designed **Decoupled Structural Interaction Module**. This module separates the "content" pathway from the "gating" pathway to prevent feature redundancy and strictly adheres to stability protocols (Post-Normalization, No Norm on Sparse Inputs) that caused previous deep architectures to fail.

### Model

The architecture is a **4-Layer Bidirectional GRU with Interleaved Decoupled Structural Injection**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** We do **not** concatenate paired features at the input stage. This ensures the convolutional stem extracts clean local motifs without interference from noisy structural predictions. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers to initialize the backbone. **Cite solution_lesson_node_00027**.

3.  **Deep Stabilized Backbone:**
    *   The backbone consists of **4 Blocks** (maximizing capacity, addressing **Cite solution_lesson_node_00026**). Each block contains a **Bidirectional GRU** followed by the **Decoupled Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** We employ a **Bidirectional GRU** with a hidden dimension of **384**. We adhere to this width to balance capacity and trainability. **Cite solution_lesson_node_00063**. We prioritize BiGRUs over Transformers for their superior inductive bias. **Cite solution_lesson_node_00017**.
    *   **Decoupled Structural Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$:
        *   **Gather:** Retrieve the hidden state vector $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Zero-Masking:** If position $i$ is **unpaired**, we explicitly force $h_j$ to be a **zero vector**. We strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **Decoupled Message:** Derive the update content *solely* from the neighbor: $m_{ij} = \text{GELU}(W_{msg} \cdot h_j)$. We do **not** concatenate $h_i$ here, forcing the branch to learn the structural delta. **Cite solution_lesson_node_00080**. We do **not** apply LayerNorm here, as it would destroy the zero-masking semantics. **Cite solution_lesson_node_00079**.
        *   **Context-Aware Gating:** Derive the gate from the joint context: $g_{ij} = \sigma(W_{gate} \cdot [h_i; h_j])$. This allows the model to verify compatibility (e.g., A-U pairing). We do **not** normalize the inputs or logits. **Cite solution_lesson_node_00078**.
        *   **Injection:** Update the state: $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization (Critical Fix):** Apply Layer Normalization *after* the residual update: $h_{out} = \text{LayerNorm}(h_{res})$. This ensures stability for the deep 4-layer stack without corrupting the sparse signals inside the block. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   A final Linear layer projects the output of the last BiGRU block to the 5 target values.

### Data

1.  **Preprocessing:**
    *   Generate adjacency maps for the gather operations based on the provided secondary structures.
    *   **Caching:** Use **hash-based caching** (e.g., `train_data_{hash(config)}.npy`) to ensure pipeline integrity. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   Train on the **entire training dataset** (~1,728 samples). We explicitly reject subsampling and filtering strategies to avoid distribution shift. **Cite solution_lesson_node_00015** and **Cite solution_lesson_node_00071**.

### Training

1.  **Objective (Unweighted Loss):**
    *   Optimize the standard **MCRMSE** on all 5 target columns. We do **not** use inverse-variance weighting. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** Explicitly apply **Gradient Clipping** (max norm 1.0). This is **mandatory** to stabilize the deep hybrid architecture. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Correct Metric Calculation:**
    *   **Slicing:** Before calculating the metric, explicitly **slice** the prediction and target tensors to the first 68 positions (`seq_scored`). **Cite solution_lesson_node_00066**.
    *   **Target Filtering:** Calculate the MCRMSE **only on the 3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`). Do not average in the noisy auxiliary targets. **Cite solution_lesson_node_00076**.
    *   **Global Aggregation:** Concatenate these sliced, filtered tensors for the entire validation set *before* calculating the MCRMSE to avoid batch-averaging bias. **Cite solution_lesson_node_00045**.

2.  **Inference:**
    *   Process test sequences through the Stem and Deep Backbone.
    *   Generate predictions for all 107 positions, then slice to the first 68 positions (`seq_scored`) for submission.
