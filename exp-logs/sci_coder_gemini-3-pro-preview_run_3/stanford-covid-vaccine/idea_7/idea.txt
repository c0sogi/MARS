# Proposed Strategy: Spatially-Augmented BiGRU with Noise-Aware Training

This strategy introduces a **Structural Innovation** in the input representation called **Spatial Augmentation**, which explicitly flattens the 3D RNA folding information into the local feature space. This addresses the limitations of Graph Neural Networks (complexity/noise) and standard RNNs (long-term dependency struggles) by providing immediate access to spatially neighboring base information. Additionally, it implements a **Noise-Weighted Loss** to effectively utilize the full dataset without being misled by low-quality samples.

### Model

The architecture is a **Spatially-Augmented Bidirectional GRU**.

1.  **Input Representation (Structural Innovation):**
    *   **Concept:** Instead of relying on the RNN to "remember" the opening parenthesis of a base pair until it encounters the closing one, or using a GNN to pass messages, we explicitly construct the feature vector of a nucleotide to include the features of its **paired partner**.
    *   **Mechanism:** For every position $i$ in the sequence:
        *   Extract its local features $f_i$ (One-Hot Sequence, Structure, Loop Type).
        *   Parse the secondary structure to find the index $j$ of the nucleotide paired with $i$.
        *   If paired, retrieve $f_j$. If unpaired, use a zero vector.
        *   Concatenate $[f_i, f_j]$ to form the augmented feature vector.
    *   **Benefit:** This transforms a "long-range" dependency (in sequence space) into a "local" feature interaction, allowing the model to instantly assess base-pairing stability (e.g., G-C vs. G-U wobble) without complex graph topology. **Cite solution_lesson_node_00010**.
    *   **Encoding:** We strictly use **One-Hot Encoding** for all features, avoiding learned embeddings. **Cite solution_lesson_node_00009**.

2.  **Convolutional Stem:**
    *   The augmented input tensor (shape $N \times 107 \times 28$) is processed by a **1D Convolutional Layer** (kernel size 3, filters 256) followed by a **GELU** activation.
    *   This projects the sparse binary features into a dense, context-aware embedding space before recurrent processing. **Cite solution_lesson_node_00027** and **Cite solution_lesson_node_00031**.

3.  **Backbone (BiGRU):**
    *   We employ a standard **2-layer Bidirectional GRU**.
    *   We prioritize the **BiGRU** over Transformers or Hybrid architectures due to its superior inductive bias for short sequences and limited data. **Cite solution_lesson_node_00017** and **Cite solution_lesson_node_00029**.
    *   We avoid custom residual stacks for this shallow depth, relying on the optimized fused kernels of the standard implementation. **Cite solution_lesson_node_00032**.

4.  **Output Head:**
    *   A final Linear layer projects the hidden states to the 5 target values.

### Data

1.  **Preprocessing:**
    *   We will parse the `structure` string for every sample to generate the pairing map and construct the spatially augmented feature tensors.
    *   We will use **hash-based caching** to ensure this new feature engineering pipeline is correctly executed and versioned. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including noisy samples (`SN_filter == 0`). We will not discard data, as this creates a distribution shift relative to the test set. **Cite solution_lesson_node_00015**.

### Training

1.  **Objective (Noise-Aware Loss):**
    *   To safely train on the full dataset without overfitting to noise (addressing the issues in **solution_lesson_node_00013**), we will implement a **Weighted MCRMSE Loss**.
    *   We will use the provided error columns (`reactivity_error`, `deg_error_*`) to calculate sample weights: $w_{ij} = \frac{1}{\sigma_{ij}^2 + \epsilon}$.
    *   This ensures the model learns aggressively from high-confidence measurements while being robust to noisy/uncertain data points, effectively combining the benefits of filtering with the statistical power of the full distribution.

2.  **Optimizer:**
    *   **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. This is critical to ensure the model converges to a deep minimum rather than plateauing early. **Cite solution_lesson_node_00031**.

### Evaluation

1.  **Internal Validation:**
    *   We will calculate the metric specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to ensure alignment with the competition leaderboard. **Cite solution_lesson_node_00017**.
2.  **Inference:**
    *   The test set sequences will be processed to generate the augmented $[f_i, f_j]$ features (using the provided test structures) and passed through the trained model.
    *   Predictions will be sliced to the first 68 positions and flattened for submission.
