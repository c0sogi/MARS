The following script demonstrates the end-to-end usage of the provided library components for the RNA degradation prediction task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We first import the necessary modules and override specific `Config` parameters (e.g., `EPOCHS`, `BATCH_SIZE`) to ensure the demonstration runs quickly on a small subset of data.
2.  **Data Loading & Processing**: We manually load a small slice of the training and test metadata (Parquet files) using pandas. We then utilize `process_data` to convert these dataframes into the feature tensors and adjacency matrices required by the model, verifying the shapes of the generated data.
3.  **Model Initialization & Verification**: We instantiate the `HC_DBR_BiGRU` model and perform a dummy forward pass with a single batch of data. We assert that the output dimensions match the expected shape `(Batch, Seq_Len, Num_Targets)`.
4.  **Training Loop**: We execute a minimal training loop (2 epochs) using `train_one_epoch` and `validate`. This demonstrates the optimization process and metric calculation without consuming significant time.
5.  **Inference & Submission**: We process a subset of the test data, generate predictions using the trained model, and create a submission file using `generate_submission`. Finally, we validate the format of the output CSV file against the competition requirements.
