# Proposed Strategy: High-Capacity Decoupled Bias-Refined BiGRU (HC-DBR-BiGRU)

This strategy introduces a **4-Layer Bidirectional GRU** with a wide hidden dimension (384 per direction, 768 total), interleaved with **Stabilized Decoupled Structural Injection** modules. It rigorously maintains the high parameter count required for this task while using specific architectural stabilizations to prevent the optimization difficulties usually associated with deep, wide hybrid networks.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers to initialize the backbone. **Cite solution_lesson_node_00027**.

3.  **High-Capacity 4-Layer Backbone:**
    *   The backbone consists of **4 Blocks** (maximizing capacity to capture complex dependencies, addressing **Cite solution_lesson_node_00026**). Each block contains a **Bidirectional GRU** followed by the **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** Hidden dimension of **384** (Total 768). We explicitly maintain this high capacity and do not reduce it, as narrowing the backbone caused severe degradation in previous stabilized attempts. **Cite solution_lesson_node_00103** and **Cite solution_lesson_node_00063**.
    *   **Decoupled Structural Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **Decoupled Message (Bias-Refined):** $m_{ij} = \text{GELU}(W_{msg} \cdot h_j + b_{msg})$. We do **not** concatenate $h_i$ here. Crucially, for unpaired bases ($h_j=0$), this term becomes the bias $b_{msg}$, serving as a learnable "loop embedding" to allow self-refinement. **Cite solution_lesson_node_00080** and **Cite solution_lesson_node_00085**.
        *   **Stabilized MLP Gate:**
            *   Project Joint Context: $z_{raw} = W_{g1} \cdot [h_i; h_j]$. We do **not** normalize this input to preserve sparsity semantics. **Cite solution_lesson_node_00079**.
            *   **Internal Normalization:** $z_{norm} = \text{LayerNorm}(z_{raw})$. This stabilizes the MLP internals, preventing saturation issues in the deep network. **Cite solution_lesson_node_00075**.
            *   Activation: $z_{act} = \text{GELU}(z_{norm})$.
            *   Logit Projection: $logits = W_{g2} \cdot z_{act}$.
            *   **No Logit Norm:** $g_{ij} = \sigma(logits)$. We strictly avoid normalizing logits to allow the gate to fully saturate. **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. This ensures stability for the deep 4-layer stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
