### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` class with `debug=True` and `num_epochs=2` to ensure the demonstration runs quickly on a small subset of data. Set random seeds for reproducibility using `utils.set_seed`.
2.  **Data Pipeline Verification**: Use `data.get_dataloaders` to load the training, validation, and test loaders. Fetch a single batch from the training loader to verify the shapes of inputs (sequence features), structural adjacency indices, masks, and target values.
3.  **Model Architecture Verification**: Instantiate the `RNARegressor` model. Perform a forward pass with the fetched batch to confirm the model accepts the inputs correctly and produces outputs of the expected shape `(Batch, Seq_Len, 5)`. Check for numerical stability (no NaNs).
4.  **Metric Logic Verification**: Create synthetic ground truth and prediction arrays to test the `mcrmse_metric` function. Verify that identical arrays yield a score of 0.0 and that the function correctly handles the `seq_scored` slicing logic.
5.  **Full Training Loop Execution**: Execute the `train.run_training` function. This encapsulates the training loop, validation, checkpointing, and inference/submission generation.
6.  **Submission Artifact Verification**: After the training run completes, verify that the submission CSV file exists in the specified working directory. Check its dimensions and column names against the competition requirements.
