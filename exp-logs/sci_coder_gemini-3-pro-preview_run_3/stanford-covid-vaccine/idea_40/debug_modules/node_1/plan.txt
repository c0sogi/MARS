The `PermissionError` occurs because the script attempts to create a directory path (`./input/../working/demo_execution`) that traverses the `./input` directory. In this environment, `./input` is mounted as read-only, and the operating system blocks the traversal even though the final destination is writable. The fix is to define the working directory path directly relative to the project root (`./working/demo_execution`), avoiding the unnecessary detour through the read-only input folder.
