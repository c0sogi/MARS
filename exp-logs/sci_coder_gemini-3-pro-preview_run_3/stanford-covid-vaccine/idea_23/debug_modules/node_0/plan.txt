The following script demonstrates the end-to-end usage of the provided library. It performs the following steps:
1.  **Configuration Override**: Modifies the `Config` class at runtime to enable `DEBUG` mode (using a small subset of data) and sets a temporary working directory to ensure the demonstration runs quickly and does not overwrite existing work.
2.  **Component Verification**:
    *   **Data Loading**: Instantiates a `DataLoader` and verifies the shape and integrity of a batch.
    *   **Model**: Instantiates the `SPMHABiGRU` model, performs a forward pass, and checks output dimensions.
    *   **Loss**: Calculates the `MCRMSELoss` on the dummy batch to ensure the criterion functions correctly.
3.  **Pipeline Execution**: Runs the full training and inference pipeline using `library.train.run()`.
4.  **Output Validation**: Asserts that the model checkpoint and submission file are generated correctly.
