# Proposed Strategy: Attention-Augmented Deep Residual BiGRU

This strategy represents a structural evolution that synthesizes the superior inductive bias of Recurrent Neural Networks (RNNs) for this task with modern architectural enhancements to maximize capacity and global context awareness. It specifically addresses the trade-off between local feature extraction and backbone capacity identified in the lessons.

### Model

The architecture is a **Deep Residual BiGRU with a Convolutional Stem and Self-Attention Refinement**.

1.  **Input Representation:**
    *   The input will be a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We will strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We will **not** use learned embeddings, as they add parameters without performance gain in this low-data regime. **Cite solution_lesson_node_00009**.
    *   Explicit secondary structure features (dot-bracket) are included to handle topology without the overhead of Graph Neural Networks. **Cite solution_lesson_node_00010**.

2.  **Convolutional Stem (Projection):**
    *   Instead of feeding sparse one-hot vectors directly into the RNN, we process the input with a **Single 1D Convolutional Layer** (kernel size 3, filters=256, activation=GELU).
    *   This "Stem" projects the sparse inputs into a dense, rich feature space and aggregates immediate local context (n-grams) before the recurrent processing begins. **Cite solution_lesson_node_00027**.

3.  **Backbone (Deep Residual BiGRU):**
    *   The core sequence model is a stack of **4 to 6 Bidirectional GRU layers**.
    *   **Structural Innovation:** We introduce **Residual Connections** between the GRU layers (i.e., $Input_{i+1} = Layer_i(Input_i) + Input_i$).
    *   This residual structure allows us to significantly increase the depth and parameter capacity of the backbone (e.g., hidden dimension 256 or 512) to model complex dependencies, directly addressing the finding that backbone capacity is more valuable than hierarchical feature extraction. **Cite solution_lesson_node_00026**.
    *   We prioritize the BiGRU over Transformers for this stage due to its superior inductive bias for short, data-scarce sequences. **Cite solution_lesson_node_00017**.

4.  **Global Refinement (Self-Attention):**
    *   We place a **Multi-Head Self-Attention Block** (1-2 layers) *after* the RNN backbone.
    *   While the RNN excels at sequential context, it can struggle with very long-range dependencies. This final attention mechanism allows the model to "look back" across the entire processed sequence to refine predictions based on global folding patterns, leveraging the rich sequential features already extracted by the RNN.

5.  **Output Head:**
    *   A final Linear projection maps the refined hidden states to the 5 target values for each position.

### Data

1.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject the filtering strategy, as training on the full noisy distribution is required to generalize to the noisy public test set. **Cite solution_lesson_node_00015** and **Cite solution_lesson_node_00013**.

2.  **Robust Pipeline:**
    *   We will implement **hash-based caching** for preprocessed data (e.g., `train_data_{hash(config)}.npy`). This ensures that our configuration changes (e.g., reverting to full dataset, changing input shapes) are guaranteed to trigger data regeneration, preventing silent failures. **Cite solution_lesson_node_00011**.

### Training

1.  **Objective:** We optimize the **MCRMSE** on all 5 target columns. This encourages the model to learn a robust shared representation of RNA stability physics, even though only 3 columns are scored.
2.  **Optimizer:** **AdamW** with a Cosine Annealing learning rate scheduler to ensure convergence of the deeper residual network.
3.  **Regularization:** Dropout will be applied within the Residual GRU blocks and the Self-Attention block.

### Evaluation

1.  **Internal Validation:** We will monitor the MCRMSE specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) during validation to align our model selection with the competition metric, avoiding the metric mismatch observed previously. **Cite solution_lesson_node_00017**.
2.  **Inference:** The model processes the `test.json` sequences to produce a $(N, 107, 5)$ tensor.
3.  **Submission:** We extract the first 68 positions (`seq_scored`) and flatten them into the required `id_seqpos` format.
