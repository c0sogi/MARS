1.  I will define `SCORED_INDICES = [0, 1, 3]` in `library/config.py` to explicitly identify the scored targets.
2.  I will update the `validate` function in `library/train.py` to pass these indices to the `MCRMSELoss` criterion, ensuring the loss is calculated only on the relevant columns.
3.  I will update the failure analysis in `runfile.py` to compute per-sample errors using only the scored columns, aligning it with the corrected validation metric.
