# Proposed Strategy: Latent Structure-Gated BiGRU

This strategy introduces a **Latent Structure-Gating Mechanism** as a structural innovation. This architecture resolves the conflict between the need to utilize 3D structural dependencies (Lesson 33) and the danger of corrupting local feature extraction with noisy, hard-coded structural inputs (Lesson 37). By injecting structural context *after* the convolutional stem and gating it dynamically, the model can leverage valid base-pairing information without being misled by incorrect structure predictions.

### Model

The architecture is a **Bidirectional GRU with Gated Latent Spatial Injection**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We will strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We will **not** use learned embeddings, as they add parameters without benefit in this low-data regime. **Cite solution_lesson_node_00009**.
    *   Crucially, we do **not** concatenate paired features at the input stage, preserving the purity of the local sequence for the convolutional stem. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem (Local Feature Extraction):**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** This projects the sparse inputs into a dense embedding space and aggregates immediate local context (k-mers). By placing this *before* any structural mixing, we ensure the convolution learns clean, local sequential patterns without interference from non-local signals. **Cite solution_lesson_node_00027**.
    *   We avoid multi-scale Inception blocks to maintain architectural simplicity and prevent overfitting. **Cite solution_lesson_node_00040**.

3.  **Gated Latent Spatial Injection (Structural Innovation):**
    *   **Mechanism:** After the convolutional projection, we inject the structural context. For every position $i$, we use the provided secondary structure to identify its paired index $j$.
    *   **Operation:**
        1.  **Gather:** Retrieve the latent local vector $h_i$ and the paired vector $h_j$ (if unpaired, $h_j$ is a zero vector).
        2.  **Gate:** Compute a learnable trust gate $g_{ij} = \sigma(W_{gate} \cdot [h_i; h_j] + b_{gate})$, where $\sigma$ is the Sigmoid function. This allows the model to dynamically assess if the pairing is physically consistent with the local features (e.g., suppressing the connection if the structure prediction is likely noisy).
        3.  **Inject:** Update the feature vector: $h'_i = h_i + g_{ij} \odot (W_{proj} \cdot h_j)$.
    *   **Benefit:** This "linearizes" the graph structure **Cite solution_lesson_node_00033** while explicitly mitigating the risk of hard-coding noisy structure predictions **Cite solution_lesson_node_00037**. It allows the backbone to access long-range dependencies as immediate local features, but only when the model deems the connection reliable.

4.  **Backbone (High-Capacity BiGRU):**
    *   The spatially-enriched sequence is fed into a **Bidirectional GRU** (3 layers, hidden dimension 384).
    *   We prioritize the BiGRU over Transformers for its superior inductive bias on short sequences. **Cite solution_lesson_node_00017**.
    *   We maximize backbone capacity (width and depth) rather than adding complex hierarchical encoders, as capacity has proven more valuable than architectural complexity. **Cite solution_lesson_node_00026**.
    *   We use standard fused kernels rather than custom residual stacks, as residuals provided no benefit for this depth. **Cite solution_lesson_node_00032**.

5.  **Output Head:**
    *   A final Linear layer projects the hidden states to the 5 target values.

### Data

1.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject filtering strategies, as training on the full noisy distribution is required to generalize to the noisy public test set and avoid distribution shift. **Cite solution_lesson_node_00015** and **Cite solution_lesson_node_00013**.

2.  **Robust Pipeline:**
    *   We will implement **hash-based caching** for the preprocessed data (e.g., `train_data_{hash(config)}.npy`). This ensures that the new Gated Spatial Injection logic is correctly executed and versioned, preventing stale data loading. **Cite solution_lesson_node_00011**.

### Training

1.  **Objective (Unweighted Loss):**
    *   We will optimize the standard **MCRMSE** on all 5 target columns. We will **not** use inverse-variance weighting, as down-weighting noisy samples degrades performance on the unweighted competition metric. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. This dynamic schedule is critical for converging to a deep minimum and preventing premature plateaus. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** We will explicitly apply **Gradient Clipping** (max norm 1.0) to the training loop. This is mandatory to stabilize the high-capacity RNN and prevent the exploding gradients that hinder convergence in hybrid architectures. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Global Metric Aggregation:**
    *   We will implement a **Global Evaluation Loop** that concatenates predictions and targets for the entire validation set *before* calculating the MCRMSE. We will **not** average batch-wise RMSEs, as this produces optimistically biased results. **Cite solution_lesson_node_00045**.

2.  **Targeted Validation:**
    *   While the model predicts all 5 targets, we will calculate the validation metric specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to ensure alignment with the competition leaderboard. **Cite solution_lesson_node_00017**.

3.  **Inference:**
    *   The test set sequences will be processed through the Conv Stem, Gated Spatial Injection layer, and BiGRU backbone.
    *   Predictions will be generated for all 107 positions, then sliced to the first 68 positions (`seq_scored`) for submission.
