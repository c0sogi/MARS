Here is the implementation strategy and the complete Python script `runfile.py`.

### Implementation Strategy

1.  **Configuration Override**: To ensure a fast baseline execution within the time limit, I will override `Config.MAX_EPOCHS` to 20. The dataset size (1728 training samples) is small enough that subsampling is not necessary for speed, and using the full dataset ensures the "best possible score" objective is met.
2.  **Data Loading**: I will use `library.data.get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test sets.
3.  **Training**: I will invoke `library.train.run_training` to train the `RNAModel`. This function handles the training loop, validation monitoring, and saving the best model to `best_model.pth`.
4.  **Validation & Metrics**:
    *   After training, I will reload the best model state.
    *   I will run inference on the full validation set to obtain predictions.
    *   I will compute the `Final Validation Metric` using `library.utils.compute_score` and print it in the required format.
5.  **Failure Analysis**:
    *   I will calculate the Root Mean Squared Error (RMSE) for each validation sample, focusing on the scored positions and columns.
    *   I will load the validation metadata (`val.parquet`) to access input features like `signal_to_noise`, `SN_filter`, and sequence content.
    *   I will merge the error metrics with the metadata and calculate the Pearson correlation between the model's error and these features to identify systematic weaknesses.
6.  **Submission**:
    *   I will compare the `Final Validation Metric` against the threshold `0.5884495377540588`.
    *   If the metric is lower (better), I will call `library.train.generate_submission` to create `submission.csv` for the test set.
