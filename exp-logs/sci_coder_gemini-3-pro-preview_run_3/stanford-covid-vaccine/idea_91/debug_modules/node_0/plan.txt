This script demonstrates the end-to-end usage of the provided machine learning library for RNA degradation prediction. It performs the following steps:

1.  **Configuration Patching**: Modifies the `Config` class at runtime to set up a lightweight demonstration environment (reduced model size, fewer epochs, temporary directories) to ensure the script runs quickly.
2.  **Data Loading**: Uses `get_dataloaders` to process raw metadata into PyTorch DataLoaders, verifying the shape and structure of the resulting tensors.
3.  **Model Instantiation**: Initializes the `RNAModel` with the modified hyperparameters and performs a test forward pass to validate output dimensions.
4.  **Metric Verification**: Calculates the MCRMSE loss and validation score on dummy data to ensure metric functions operate correctly.
5.  **Training Loop**: Executes a short training run (2 epochs) using `run_training`, which handles optimization, backpropagation, and model checkpointing.
6.  **Inference**: Generates predictions using the trained model via `generate_submission` and validates the format of the output CSV file.
