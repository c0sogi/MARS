This script implements the full training, validation, analysis, and submission pipeline for the RNA degradation prediction task. It utilizes the provided library modules for configuration, data loading, model definition, and training engine.

The strategy involves:
1.  **Setup**: Initializing the environment and random seeds for reproducibility.
2.  **Data Loading**: Loading cached preprocessed data for training, validation, and testing using `get_dataloaders`.
3.  **Training**: Training the `DeepResBiGRU` model (4-layer Bidirectional GRU with Vertical Residuals and GLU Interaction) using the `Trainer` class. The training runs for the number of epochs defined in `Config` (50), which fits comfortably within the time limit given the dataset size and A100 hardware.
4.  **Validation**: Evaluating the best model on the validation set. The MCRMSE metric is computed specifically on the scored columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) and printed with full precision.
5.  **Failure Analysis**: Analyzing the validation errors by correlating the per-sample RMSE with metadata features like Signal-to-Noise Ratio (SNR) and GC content to identify performance bottlenecks.
6.  **Submission**: If the validation metric meets the specified threshold, predictions are generated for the test set (all 107 positions) and saved in the required CSV format.
