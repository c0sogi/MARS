This implementation orchestrates the Deep Hierarchical BiGRU solution using the provided library modules. It overrides the default epoch count to 10 to ensure a fast baseline execution within the time limit while maintaining sufficient convergence. The script performs the following steps:
1.  **Setup**: Initializes the environment, sets random seeds, and prepares directories.
2.  **Data Loading**: Loads training, validation, and test datasets using the cached data loader.
3.  **Training**: Trains the 4-layer BiGRU model with Deep Supervision using the `Trainer` class.
4.  **Evaluation**: Computes the MCRMSE on the full validation set and prints it in the required format.
5.  **Failure Analysis**: Calculates the correlation between sample-wise error magnitudes and metadata features (Signal-to-Noise, SN_filter, Nucleotide content) to identify error sources.
6.  **Submission**: Generates the submission file for the test set if the validation metric meets the specified threshold.
