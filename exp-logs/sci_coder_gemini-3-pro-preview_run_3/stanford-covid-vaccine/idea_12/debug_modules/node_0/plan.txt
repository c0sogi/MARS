### Implementation Strategy

1.  **Configuration Setup**: Create a subclass of the provided `Config` to override hyperparameters for a rapid demonstration. Specifically, reduce `epochs` to 2 and set a specific `working_dir` to avoid conflicts.
2.  **Utility Verification**: Validate the `parse_structure_pairs` function from `data_utils` with a known secondary structure string to ensure pairing logic is correct.
3.  **Dataset Validation**: Instantiate the `RNADataset` for the training split. Retrieve a single sample to verify the shapes of the input tensor (Sequence, Structure, Loop), the pair index tensor, and the target tensor.
4.  **Model Architecture Check**: Instantiate the `LatentSpatialBiGRU` model. Perform a forward pass with a dummy batch of data derived from the dataset validation step to confirm the output shape matches `(Batch, Seq_Len, 5)`.
5.  **Loss Function Check**: Instantiate `MCRMSELoss`. Compute the loss between the model's dummy output and the ground truth targets. Verify the calculation logic manually for a trivial case.
6.  **Training Loop Execution**: Initialize the `Trainer` with the modified configuration. Run the `fit()` method to demonstrate the full training pipeline, including data loading, forward/backward passes, validation, and model saving.
7.  **Inference & Submission**: After training, load the test dataset. Generate predictions using the trained model, format them according to the submission requirements (flattening sequence positions), and save a `submission.csv`.
