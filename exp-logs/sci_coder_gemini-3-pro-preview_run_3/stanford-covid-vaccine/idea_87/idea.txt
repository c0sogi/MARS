# Proposed Strategy: High-Capacity Stabilized GLU-Decoupled BiGRU

This strategy introduces a **4-Layer Bidirectional GRU** with a **High-Capacity Hidden Dimension** (384 per direction, 768 total). It interleaves this backbone with a **Stabilized GLU-Decoupled Structural Injection** module. This design maximizes representational power while ensuring gradient flow and correct physical modeling of both paired stems and unpaired loops.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. The sequence dimension is preserved to maintain locality. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings are used to minimize input-layer overfitting. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input stage. This ensures the convolutional stem extracts clean local motifs without interference from noisy structural predictions. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers to initialize the backbone. **Cite solution_lesson_node_00027**.

3.  **High-Capacity 4-Layer Backbone:**
    *   The backbone consists of **4 Blocks** processed sequentially (enforcing strict hierarchical abstraction, **Cite solution_lesson_node_00127**). Each block contains a **Bidirectional GRU** followed by the **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** Hidden dimension of **384** per direction (**768 Total**). We explicitly maintain this high capacity, as narrowing the backbone has been proven to degrade performance. **Cite solution_lesson_node_00103** and **Cite solution_lesson_node_00063**.
    *   **Stabilized GLU-Decoupled Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **GLU Message (Bias-Refined):** Use a **Gated Linear Unit** for the message: $m_{ij} = (W_c h_j + b_c) \odot \sigma(W_g h_j + b_g)$. We do **not** concatenate $h_i$ here (Decoupled). Crucially, for unpaired bases ($h_j=0$), this term becomes the learnable bias vector $b_c \odot \sigma(b_g)$, providing a highly expressive "loop embedding" for self-refinement. **Cite solution_lesson_node_00085**, **Cite solution_lesson_node_00062**, **Cite solution_lesson_node_00080**.
        *   **Wide Stabilized MLP Gate:**
            *   **Wide Projection:** $z_{raw} = W_{in} \cdot [h_i; h_j]$. Projects to full width (768) to avoid bottlenecks. **Cite solution_lesson_node_00110**. No input normalization to preserve sparsity. **Cite solution_lesson_node_00079**.
            *   **Internal Normalization:** $z_{norm} = \text{LayerNorm}(z_{raw})$. Stabilizes MLP internals, preventing saturation issues. **Cite solution_lesson_node_00075**.
            *   **Activation:** $z_{act} = \text{GELU}(z_{norm})$.
            *   **No Logit Norm:** $g_{ij} = \sigma(W_{out} \cdot z_{act})$. Allows full saturation (binary switching). **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. Ensures stability for the deep 4-layer stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
