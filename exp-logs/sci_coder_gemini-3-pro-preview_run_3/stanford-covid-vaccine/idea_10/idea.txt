# Proposed Strategy: Masked-Reconstruction Regularized BiGRU

This strategy introduces a **Multi-Task Learning Framework with Input Masking** as a structural innovation. It addresses the critical issue of overfitting identified in Lesson 40 not by reducing model capacity, but by introducing a challenging auxiliary objective: reconstructing masked input features. This forces the high-capacity backbone to learn robust, physically grounded representations of RNA structure (e.g., base-pairing rules) rather than memorizing noisy degradation targets.

### Model

The architecture is a **Bidirectional GRU with a Dual-Head Output**, designed to perform simultaneous regression and masked feature reconstruction.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   We preserve the sequence dimension to maintain locality and translation invariance. **Cite solution_lesson_node_00002**.

2.  **Dynamic Input Masking (Structural Innovation):**
    *   Before the input enters the network, we apply a **random mask** during training. Approximately 15% of the sequence positions are randomly selected, and their feature vectors are replaced with a zero vector (or a special mask token vector).
    *   This forces the network to rely on context from the surrounding unmasked sequence to infer the missing information, effectively learning the "grammar" of RNA folding (e.g., if position $i$ is a 'G' and paired with masked position $j$, $j$ is likely a 'C' or 'U').

3.  **Convolutional Stem:**
    *   The (potentially masked) input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   This projects the sparse inputs into a dense embedding space and aggregates local n-gram context. **Cite solution_lesson_node_00027**.

4.  **Backbone (High-Capacity BiGRU):**
    *   We employ a standard **2-layer Bidirectional GRU** with a hidden dimension of 256.
    *   We prioritize the BiGRU over Transformers due to its superior inductive bias for short sequences. **Cite solution_lesson_node_00017**.
    *   We maintain high capacity (256 hidden units) to model complex dependencies, relying on the auxiliary task for regularization rather than reducing network depth/width. **Cite solution_lesson_node_00026**.

5.  **Dual Output Heads:**
    *   **Regression Head (Main):** A Linear layer projects the hidden states to the 5 degradation targets.
    *   **Reconstruction Head (Auxiliary):** A separate Linear layer projects the *same* hidden states back to 14 dimensions (predicting the original one-hot input vector).

### Data

1.  **Full-Spectrum Training:**
    *   We will train on the **entire training dataset**, including samples with low signal-to-noise ratios (`SN_filter == 0`). We explicitly reject filtering, as the model must learn to handle the noisy distribution present in the test set. **Cite solution_lesson_node_00015**.

2.  **Robust Pipeline:**
    *   We will implement **hash-based caching** for the preprocessed data to ensure the pipeline integrity. **Cite solution_lesson_node_00011**.

### Training

1.  **Objective (Multi-Task Loss):**
    *   The total loss will be a weighted sum: $L_{total} = L_{MCRMSE} + \lambda \cdot L_{CrossEntropy}$.
    *   **Main Task:** Unweighted **MCRMSE** on the 5 degradation targets. We avoid inverse-variance weighting to align with the competition metric. **Cite solution_lesson_node_00034**.
    *   **Auxiliary Task:** Cross-Entropy loss between the Reconstruction Head's output and the *original, unmasked* input features. This loss is calculated **only on the masked positions**, preventing the model from learning a trivial identity mapping.
    *   This auxiliary task acts as a powerful regularizer, preventing the overfitting observed in previous high-capacity models. **Cite solution_lesson_node_00040**.

2.  **Optimizer & Scheduler:**
    *   We will use **AdamW** combined with a **Cosine Annealing Learning Rate Scheduler**. This dynamic schedule is critical for convergence in deep recurrent networks. **Cite solution_lesson_node_00031**.

### Evaluation

1.  **Inference:**
    *   During inference (and validation), **masking is disabled**. The model sees the full, clean input sequence.
    *   We only use the output from the **Regression Head**.
    *   The model processes the `test.json` sequences to produce a $(N, 107, 5)$ tensor.

2.  **Submission:**
    *   We extract the first 68 positions (`seq_scored`) from the regression output and flatten them into the `id_seqpos` format required for the submission file.
