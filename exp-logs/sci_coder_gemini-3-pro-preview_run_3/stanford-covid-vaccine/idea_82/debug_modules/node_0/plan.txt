### Implementation Strategy

1.  **Configuration Override**: We will modify the `Config` class attributes to run in `DEBUG` mode with a small subset of data (100 samples) and limited epochs (2). We will also redirect the working directory to `./working/demo_execution` to avoid conflicts.
2.  **Unit Testing Utilities**: We will explicitly test the `parse_structure_to_adj` function with a known RNA structure string to verify the graph adjacency logic before proceeding to the pipeline.
3.  **Data Pipeline Verification**: We will initialize the DataLoaders using `get_dataloaders` (forcing reprocessing to test the raw data handling) and verify the shape and types of a single batch yielded by the training loader.
4.  **Model Initialization & Forward Pass**: We will instantiate the `RNAModel`, move it to the configured device, and perform a forward pass with the verification batch. We will assert that the output shape matches `(Batch Size, Seq Length, Num Targets)`.
5.  **Training Loop Execution**: We will run a short training loop using `train_fn` and `eval_fn` from the `engine` module. We will verify that the loss is a valid finite number.
6.  **Inference & Submission**: We will generate predictions on the test set using `inference_fn` and create a submission file using `generate_submission`. Finally, we will validate the format of the generated CSV file.
