The error `RuntimeError: view size is not compatible with input tensor's size and stride` occurs because the tensor `y_pred` passed to `mcrmse_loss` is a slice of the original model output (created via `outputs[:, : Config.SEQ_SCORED, :]`). Slicing modifies the stride, resulting in a non-contiguous tensor in memory. PyTorch's `.view()` method requires contiguous tensors. To fix this, I will replace `.view()` with `.reshape()` in `library/utils.py`. `.reshape()` is robust to memory layout as it automatically handles non-contiguous tensors by copying data if necessary (Cite debug_lesson_2).
