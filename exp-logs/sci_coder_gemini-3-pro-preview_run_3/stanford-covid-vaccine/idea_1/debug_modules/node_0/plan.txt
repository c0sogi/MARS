### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by importing necessary standard libraries and the provided custom library modules (`library.config`, `library.dataset`, `library.model`, `library.engine`, `library.utils`).
2.  **Configuration Override**: Modify the `Config` class attributes at runtime to reduce the computational load (fewer epochs, smaller hidden layers, smaller batch size) for a quick demonstration.
3.  **Data Loading and Verification**:
    *   Use `get_data` to load training, validation, and test datasets.
    *   Validate the shapes of the loaded feature and target matrices against the expected dimensions defined in `Config`.
    *   Instantiate `RNADataset` and `DataLoader` for all splits.
4.  **Metric Verification**: Create a simple synthetic test case for the `MCRMSE` loss function to confirm it calculates error correctly before training.
5.  **Model Training**:
    *   Initialize the `GlobalMLP` model.
    *   Execute the training loop using `train_model`.
    *   Assert that the training history contains the expected number of epochs and that loss values are valid numbers.
6.  **Inference and Submission**:
    *   Generate predictions on the test set using `generate_submission`.
    *   Verify the generated submission file's format (row count, column names) matches the competition requirements.
7.  **Cleanup**: Ensure the script runs to completion without errors, leaving the artifacts in the `./working` directory as allowed.
