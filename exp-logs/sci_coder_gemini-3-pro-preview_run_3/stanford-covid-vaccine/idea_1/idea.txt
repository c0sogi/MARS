To establish a robust and lightweight baseline, I propose a **Global Feedforward Perceptron (MLP)**. This approach treats the RNA prediction task as a standard multivariate regression problem, ignoring the explicit sequential or graph-based symmetries utilized in more complex architectures. It serves to benchmark how well a model can perform by simply correlating global input patterns to output targets without specialized inductive biases for locality or topology.

### Model
The architecture is a straightforward, fully connected Deep Neural Network (DNN):
*   **Input Layer**: Accepts a single, flattened feature vector representing the entire 107-nucleotide RNA sequence. This vector is the concatenation of one-hot encoded features for the nucleotide sequence, secondary structure (dot-bracket), and predicted loop type for every position.
*   **Hidden Layers**: A stack of 3 to 4 Dense (fully connected) layers. Each layer is followed by Batch Normalization to stabilize learning and ReLU activation for non-linearity.
*   **Regularization**: Dropout layers are inserted between hidden layers to prevent overfitting, which is crucial given the relatively small training set size (~2,000 samples) compared to the input dimensionality.
*   **Output Layer**: A final Dense layer with linear activation that projects the last hidden state directly to a vector of size $340$ ($68 \text{ positions} \times 5 \text{ targets}$). This layer simultaneously predicts all required values for the scored positions.

### Data
*   **Feature Encoding**:
    1.  **Tokenization**: Map the characters in `sequence` (A, G, C, U), `structure` ((, ), .), and `predicted_loop_type` (S, M, I, B, H, E, X) to integer indices.
    2.  **One-Hot Encoding**: Convert these indices into binary vectors. For a sequence length of 107, this results in a tensor of shape $(107, C)$, where $C$ is the sum of unique characters across all three modalities (approx. 14 channels).
    3.  **Flattening**: Reshape this tensor into a 1D vector of size $107 \times C$ for each sample.
*   **Target Processing**:
    1.  Extract the 5 target lists (`reactivity`, `deg_Mg_pH10`, `deg_pH10`, `deg_Mg_50C`, `deg_50C`).
    2.  Stack them and flatten into a single 1D vector of length 340 per sample.
*   **Splitting**: Use the provided stratified metadata (Train/Val split) to create the final tensors.

### Training
*   **Loss Function**: Optimize using **Mean Squared Error (MSE)**, which acts as a direct proxy for the competition metric (MCRMSE).
*   **Optimizer**: Use **AdamW** with a standard learning rate (e.g., 1e-3) and weight decay to further mitigate overfitting.
*   **Procedure**: Train for a fixed number of epochs (e.g., 50-100) with **Early Stopping** monitoring the validation MCRMSE. The batch size should be relatively large (e.g., 64 or 128) to stabilize gradient updates given the noisy nature of the experimental data.

### Evaluation
*   **Inference**: Preprocess the public test set (`test.json`) using the same flattening pipeline. Pass the data through the trained MLP to obtain the 340-dimensional output vectors.
*   **Post-processing**: Reshape the output vectors from $(N, 340)$ back to $(N, 68, 5)$ to match the sequence positions.
*   **Submission**: Format the predictions into the required CSV structure, ensuring that the `id_seqpos` keys correctly map to the first 68 positions of each test sample.
