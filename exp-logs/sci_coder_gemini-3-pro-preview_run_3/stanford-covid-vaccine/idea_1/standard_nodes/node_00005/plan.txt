The `RuntimeError` is caused by the application loading stale cached data files (`.npy`) that contain flattened feature vectors (dimension 1498) generated for a previous MLP architecture. The current GRU model requires sequential input (dimension 14 per position), creating a shape mismatch. To fix this, I will modify `library/config.py` to rename the cache file paths. This effectively invalidates the old cache and forces the data pipeline to regenerate the features with the correct dimensions, applying the lesson "Invalidate Data Caches When Modifying Input Dimensions" (Cite debug_lesson_2).
