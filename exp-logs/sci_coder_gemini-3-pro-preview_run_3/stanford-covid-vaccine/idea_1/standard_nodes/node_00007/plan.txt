To improve the model's performance, I will transition from a flattened Global MLP to a sequence-aware architecture using a Bidirectional GRU. This directly addresses the lesson that flattening sequence data destroys locality and translation invariance (Cite solution_lesson_node_00002).

Here is the implementation strategy:
1.  **`library/config.py`**: Update `INPUT_DIM` to represent channels per position (14) rather than the flattened vector size. Define RNN hyperparameters (`RNN_HIDDEN_DIM`, `RNN_LAYERS`). Update cache paths to store the new 3D tensors.
2.  **`library/dataset.py`**: Modify data processing functions to return 3D tensors `(N, 107, 14)` for features and `(N, 68, 5)` for targets, removing the flattening steps.
3.  **`library/model.py`**: Replace `GlobalMLP` with `RNA_GRU`, a bidirectional GRU followed by a linear projection. Update `train_one_epoch` and `validate` to slice the model's full sequence output (107 positions) to match the ground truth targets (first 68 positions) before calculating loss.
4.  **`library/engine.py`**: Update to use `RNA_GRU`. Modify `generate_submission` to utilize the model's predictions for the full sequence length instead of zero-filling non-scored positions.
5.  **`runfile.py`**: Adjust the validation evaluation logic to handle the 3D output tensors and correct slicing.

class GlobalMLP(nn.Module):
    """
    Global Feedforward Perceptron (MLP) for RNA degradation prediction.

    Architecture:
    - Input Layer: Flattened feature vector (1498 dimensions).
    - Hidden Layers: Stack of Dense -> BatchNorm -> ReLU -> Dropout blocks.
    - Output Layer: Dense (Linear) projection to flattened targets (340 dimensions).
    """

    def __init__(
        self,
        input_dim=Config.INPUT_DIM,
        output_dim=Config.OUTPUT_DIM,
        hidden_layers=Config.HIDDEN_LAYERS,
        dropout_rate=Config.DROPOUT_RATE,
    ):
        """
        Initializes the GlobalMLP model.

        Args:
            input_dim (int): Size of the input feature vector.
            output_dim (int): Size of the output target vector.
            hidden_layers (list): List of integers defining the size of each hidden layer.
            dropout_rate (float): Probability of an element to be zeroed in Dropout.
        """
        super(GlobalMLP, self).__init__()

        layers = []
        current_dim = input_dim

        # Construct Hidden Layers
        for h_dim in hidden_layers:
            layers.append(nn.Linear(current_dim, h_dim))
            layers.append(nn.BatchNorm1d(h_dim))
            layers.append(nn.ReLU())
            layers.append(nn.Dropout(dropout_rate))
            current_dim = h_dim

        # Output Layer
        layers.append(nn.Linear(current_dim, output_dim))

        self.model = nn.Sequential(*layers)

    def forward(self, x):
        """
        Forward pass of the model.

        Args:
            x (torch.Tensor): Input tensor of shape (batch_size, input_dim).

        Returns:
            torch.Tensor: Output tensor of shape (batch_size, output_dim).
        """
        return self.model(x)

class RNA_GRU(nn.Module):
    """
    Bidirectional GRU for RNA degradation prediction.
    Preserves sequence dimension to capture locality and sequential dependencies.
    Cite solution_lesson_node_00002.
    """

    def __init__(
        self,
        input_dim=Config.INPUT_DIM,
        hidden_dim=Config.RNN_HIDDEN_DIM,
        num_layers=Config.RNN_LAYERS,
        dropout=Config.RNN_DROPOUT,
        num_targets=Config.NUM_TARGETS,
    ):
        super(RNA_GRU, self).__init__()
        self.gru = nn.GRU(
            input_dim,
            hidden_dim,
            num_layers,
            batch_first=True,
            bidirectional=True,
            dropout=dropout,
        )
        self.fc = nn.Linear(hidden_dim * 2, num_targets)

    def forward(self, x):
        # x: (Batch, Seq_Len, Channels)
        out, _ = self.gru(x)
        # out: (Batch, Seq_Len, Hidden*2)
        out = self.fc(out)
        # out: (Batch, Seq_Len, Num_Targets)
        return out
