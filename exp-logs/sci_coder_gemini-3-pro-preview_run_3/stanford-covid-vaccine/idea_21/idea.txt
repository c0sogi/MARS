# Proposed Strategy: High-Capacity Non-Linear Channel-Gated BiGRU

This strategy synthesizes the structural strengths of the best-performing model (Idea 17) with the theoretical refinement of channel-wise gating (Idea 20), while rigorously correcting the capacity and linearity flaws that caused Idea 20 to fail.

The core innovation is the **Non-Linear Channel-Wise Structural Interaction Module**. Unlike Idea 17 (which used scalar gating) and Idea 20 (which used linear channel gating with reduced capacity), this approach maintains the massive backbone capacity required for this dataset **Cite solution_lesson_node_00026** and employs a **Non-Linear** projection for the structural messages **Cite solution_lesson_node_00062**. This allows the model to selectively filter specific feature channels (e.g., propagating base-pairing constraints while blocking noise) with high expressivity, robustly handling the noisy structure predictions identified in **Cite solution_lesson_node_00037**.

### Model

The architecture is a **Deep BiGRU with Interleaved Non-Linear Channel-Gated Structural Injection**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** We strictly use **One-Hot Encoding** for the nucleotide sequence (4), secondary structure (3), and predicted loop type (7). We do **not** use learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** We do **not** concatenate paired features at the input stage. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   The raw one-hot input is processed by a **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers to initialize the backbone. **Cite solution_lesson_node_00027**.

3.  **High-Capacity Refinement Backbone:**
    *   The backbone consists of **3 Blocks**. Each block contains a **Bidirectional GRU** followed by a **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** We employ a **High-Capacity Bidirectional GRU** with a hidden dimension of **768**. We explicitly retain this high capacity, as reducing it to 384 caused a severe regression in previous attempts. **Cite solution_lesson_node_00026** and **Cite solution_lesson_node_00062**.
    *   **Non-Linear Channel-Gated Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$:
        *   **Gather:** Retrieve the full hidden state vector $h_j$ directly. We use point-to-point gathering, avoiding windowed aggregation to preserve signal precision. **Cite solution_lesson_node_00058**.
        *   **Non-Linear Value Projection:** Transform the neighbor state via an MLP: $v_{ij} = \text{Dropout}(\text{GELU}(W_{val} \cdot h_j))$. This non-linearity is critical for expressivity. **Cite solution_lesson_node_00062**.
        *   **Channel-Wise Gating:** Compute a feature-vector gate $z_{ij} \in \mathbb{R}^{768}$ via a separate non-linear path: $z_{ij} = \sigma(W_{gate} \cdot \text{GELU}(W_{mix} \cdot [h_i; h_j]))$.
        *   **Selective Injection:** Update the state element-wise: $h'_i = h_i + z_{ij} \odot v_{ij}$.
        *   **Stabilization:** Apply **Layer Normalization** to $h'_i$ to stabilize the deep recurrent stack.

4.  **Output Head:**
    *   A final Linear layer projects the output of the last BiGRU block to the 5 target values.

### Data

1.  **Preprocessing:**
    *   Generate adjacency maps for the gather operations based on the provided secondary structures.
    *   **Caching:** Use **hash-based caching** (e.g., `train_data_{hash(config)}.npy`) to ensure the pipeline integrity. **Cite solution_lesson_node_00011**.

2.  **Full-Spectrum Training:**
    *   Train on the **entire training dataset**, including samples with low signal-to-noise ratios. We explicitly reject filtering to avoid distribution shift. **Cite solution_lesson_node_00015**.

### Training

1.  **Objective (Unweighted Loss):**
    *   Optimize the standard **MCRMSE** on all 5 target columns. Do **not** use inverse-variance weighting. **Cite solution_lesson_node_00034**.

2.  **Optimizer & Stability:**
    *   **Optimizer:** **AdamW** with a **Cosine Annealing Learning Rate Scheduler**. **Cite solution_lesson_node_00031**.
    *   **Gradient Clipping:** Explicitly apply **Gradient Clipping** (max norm 1.0). This is **mandatory** to stabilize the high-capacity (768-dim) hybrid architecture. **Cite solution_lesson_node_00046**.

### Evaluation

1.  **Global Metric Aggregation:**
    *   Concatenate predictions and targets for the entire validation set *before* calculating the MCRMSE to avoid batch-averaging bias. **Cite solution_lesson_node_00045**.

2.  **Targeted Validation:**
    *   Calculate the validation metric specifically on the **3 scored columns** (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to align with the competition leaderboard. **Cite solution_lesson_node_00017**.

3.  **Inference:**
    *   Process test sequences through the Stem and Backbone.
    *   Generate predictions for all 107 positions, then slice to the first 68 positions (`seq_scored`) for submission.
