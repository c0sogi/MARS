### Implementation Strategy

1.  **Configuration Override**: To ensure the demonstration runs quickly within the time limit, I will modify the `Config` class attributes at runtime. I will enable `DEBUG` mode (reducing the dataset size to 100 samples), reduce the number of model layers and hidden dimensions, and set the number of epochs to 1.
2.  **Data Processing & Verification**: I will utilize `get_dataloaders` to generate training and validation batches. I will explicitly verify the shape and data types of the yielded batches (features, pair indices, masks, and targets) to ensure the `RNADataset` and `process_data` functions are working correctly.
3.  **Unit Testing Utility Functions**: I will perform a targeted check on `get_structure_adj` with a known simple RNA structure string to confirm it correctly identifies base pairs and generates the appropriate adjacency masks.
4.  **Model Component Verification**: I will instantiate the `ChannelGatedInteraction` module separately and pass dummy tensors to verify that the shape transformations and masking logic function without error.
5.  **Full Model & Training Loop**: I will instantiate the `DeepBiGRUNet` with the reduced configuration. I will run a single training epoch using `train_one_epoch` and a validation pass using `evaluate`, asserting that the loss decreases or is finite and the metric calculation is valid.
6.  **Submission Generation**: I will execute `generate_submission` using the trained model and the test loader, saving the output to the `./working` directory. I will then load the generated CSV to verify its dimensions and column names against the requirements.
