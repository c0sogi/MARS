Implementation Strategy:
1.  **Configuration Management**: Create a `DemoConfig` class inheriting from the provided `Config` to override hyperparameters (epochs, batch size, model dimensions) for rapid execution. We will also dynamically update the global `Config.CACHE_DIR` in the library to ensure data processing uses a dedicated demo directory.
2.  **Data Loading**: Utilize `get_dataloaders` to process the metadata Parquet files into PyTorch DataLoaders. We will verify the integrity of the data (shapes of features, masks, and targets) using assertions.
3.  **Model Initialization**: Instantiate the `RNAModel` using the lightweight `DemoConfig`. We will perform a dummy forward pass on a single batch to verify tensor shapes and ensure no numerical instabilities (NaN/Inf).
4.  **Training Simulation**: Execute `train_model` for a minimal number of epochs (2) to demonstrate the training loop, validation metric calculation, and checkpoint saving logic.
5.  **Inference & Submission**: Load the trained model, run inference on the test set, and format the predictions into the required CSV structure. We will verify the final output dimensions against the expected test set size.
6.  **Reproducibility**: Apply `seed_everything` to ensure consistent results.
