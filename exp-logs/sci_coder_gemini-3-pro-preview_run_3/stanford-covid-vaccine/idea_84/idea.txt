# Proposed Strategy: Massive-Capacity Stabilized Decoupled BiGRU (MC-SD-BiGRU)

This strategy introduces a **4-Layer Bidirectional GRU** with an unprecedented **512-dimension hidden state per direction (1024 total)**. To make this massive hybrid network trainable, it interleaves **Stabilized GLU-Decoupled Interaction Modules** that rigorously adhere to normalization constraints and utilize learned biases to refine unpaired loops without noise.

### Model

1.  **Input Representation:**
    *   **Tensor Shape:** $(N, 107, 14)$. Sequence dimension is preserved. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly **One-Hot Encoding** for nucleotide (4), secondary structure (3), and predicted loop type (7). No learned embeddings to minimize input-layer overfitting. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input; structural info is handled exclusively by the interaction modules. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 512, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense, high-dimensional embedding space matching the backbone width. **Cite solution_lesson_node_00027**.

3.  **Massive-Capacity 4-Layer Backbone:**
    *   The backbone consists of **4 Blocks** processed sequentially (Strict Hierarchy, **Cite solution_lesson_node_00127**).
    *   **BiGRU Layer:** Hidden dimension of **512** per direction (**1024 Total**). This maximizes representational power to capture complex folding landscapes. **Cite solution_lesson_node_00103**.
    *   **Stabilized GLU-Decoupled Interaction Module:**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Input Zero-Masking:** If $i$ is unpaired, explicitly force $h_j = 0$. Strictly avoid self-loops. **Cite solution_lesson_node_00064**.
        *   **GLU Message (Bias-Refined):** $m_{ij} = (W_c h_j + b_c) \odot \sigma(W_g h_j + b_g)$. We do **not** concatenate $h_i$ here. Crucially, for unpaired bases ($h_j=0$), this term becomes the learnable bias vector $b_c \odot \sigma(b_g)$, providing a highly expressive "loop embedding" for self-refinement. **Cite solution_lesson_node_00085**, **Cite solution_lesson_node_00062**, **Cite solution_lesson_node_00080**.
        *   **Stabilized MLP Gate:**
            *   **Wide Projection:** $z_{raw} = W_{in} \cdot [h_i; h_j]$. Projects to full width (1024) to avoid bottlenecks. **Cite solution_lesson_node_00110**. No input normalization. **Cite solution_lesson_node_00079**.
            *   **Internal Normalization:** $z_{norm} = \text{LayerNorm}(z_{raw})$. Stabilizes MLP internals, essential for this depth/width. **Cite solution_lesson_node_00075**.
            *   **Activation:** $z_{act} = \text{GELU}(z_{norm})$.
            *   **No Logit Norm:** $g_{ij} = \sigma(W_{out} \cdot z_{act})$. Allows full saturation. **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. Ensures signal stability for the deep stack. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection from 1024 dimensions to 5 target values.
