The following script demonstrates the end-to-end usage of the provided RNA degradation prediction library.

**Implementation Strategy:**
1.  **Configuration Setup**: We first modify the global `Config` class to define a temporary working directory and reduce hyperparameters (epochs, batch size) for a rapid execution suitable for demonstration.
2.  **Data Loading & Verification**: We utilize `get_dataloaders` to load a small subset of the training data. We explicitly verify the tensor shapes of inputs, structure indices, and targets to ensure the data pipeline is functioning correctly.
3.  **Model Initialization & Forward Pass**: We instantiate the `RNAModel` and perform a forward pass with a single batch of data. We assert that the output dimensions match the expected sequence length and number of target columns.
4.  **Metric Verification**: We independently verify the `MCRMSE` loss function using synthetic tensors to guarantee that the slicing (scoring only the first 68 positions) and column filtering logic is correct.
5.  **Training Loop Execution**: We execute `run_training` for a single epoch on a small data subset. This demonstrates the training pipeline, validation step, and model checkpointing.
6.  **Inference & Submission**: Finally, we use the trained model to generate a submission file via `generate_submission` and verify the output file's structure and content.
