This script demonstrates the end-to-end usage of the provided library components to train a High-Capacity Topology-Aware Dual-Path BiGRU model for RNA degradation prediction.

It performs the following steps:
1.  **Configuration**: Overrides the default `Config` to run in a fast "debug" mode (small data subset, fewer epochs) and sets a custom working directory.
2.  **Data Preparation**: Uses `get_loaders` to load and preprocess the data (handling caching automatically). It asserts the correctness of the data shapes.
3.  **Model Initialization**: Instantiates the `HCTADPBiGRU` model and validates the forward pass output shape.
4.  **Loss Verification**: Computes the `MCRMSELoss` on dummy data to ensure the loss function works as expected.
5.  **Training Loop**: Executes a short training cycle (2 epochs) using `train_one_epoch` and `validate`, asserting that the model learns (loss reduction) or at least executes without error.
6.  **Inference**: Generates predictions on the test set using `generate_submission` and verifies the format of the output CSV.
