This script implements the Deep Affine-Decoupled BiGRU (DAD-BiGRU) pipeline. It overrides the default configuration for a fast baseline execution (10 epochs), trains the model, and evaluates it using the specified MCRMSE metric. It includes a custom failure analysis module that correlates prediction errors with input features (nucleotide composition, structural content, and signal-to-noise ratio). Finally, it conditionally generates a submission file if the validation performance meets the required threshold.
