### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override specific parameters to ensure the script runs quickly and reproducibly. We will enable `DEBUG` mode to use a small subset of the data and reduce `EPOCHS` to 2.
2.  **Data Loading**: Use `get_dataloaders` to initialize the training, validation, and test data loaders. We will verify the structure of a batch to ensure data processing is correct.
3.  **Model Initialization**: Instantiate the `DeepInputAwareBiGRU` model and move it to the appropriate device (CPU or GPU).
4.  **Training Loop**: Execute the `fit` function from the `engine` module. This handles the training process, validation scoring, and saving the best model checkpoint.
5.  **Inference**: Load the best saved model and perform inference on the test set.
6.  **Submission Generation**: Process the model predictions (shape `[Batch, Seq_Len, 5]`) into the required CSV format (one row per sequence position).
7.  **Verification**: Include assertions to validate the shape of the predictions and the existence of the output file.
