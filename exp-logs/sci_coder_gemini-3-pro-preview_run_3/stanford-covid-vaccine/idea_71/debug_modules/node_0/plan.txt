The following script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It initializes the configuration in debug mode for speed, loads the data using the custom `RNADataset` and `DataLoader` utilities, instantiates the `HighCapacityAugmentedBiGRU` model, and verifies the forward pass, loss calculation, and training/inference loops. Assertions are included to validate tensor shapes and data integrity at each step.
