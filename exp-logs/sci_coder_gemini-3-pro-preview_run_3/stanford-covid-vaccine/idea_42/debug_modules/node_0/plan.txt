The following script demonstrates the end-to-end usage of the provided RNA degradation prediction library. It performs the following steps:
1.  **Configuration Override**: Modifies the global `Config` to run in `DEBUG` mode with a small subset of data and reduced epochs for rapid execution.
2.  **Data Pipeline Verification**: Initializes `DataLoaders` and verifies the structure and shape of the batches (inputs, adjacency matrices, and targets).
3.  **Model Instantiation & Inference**: Initializes the `RNAModel`, performs a forward pass on a single batch, and validates the output dimensions.
4.  **Metric Calculation**: Demonstrates how to calculate the MCRMSE loss using the provided utility functions.
5.  **Full Training & Inference Loop**: Executes the `run_training` and `generate_submission` functions from `library.train` to verify the complete workflow, including model saving and submission file generation.
