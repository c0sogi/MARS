The implementation strategy follows the "Deep Bias-Refined Decoupled BiGRU" architecture defined in the library files. We will override the default configuration to ensure the run completes quickly (within the 2-hour limit) by reducing the number of epochs to 15, which is sufficient for this dataset size (~1.7k samples). The script orchestrates the data loading, model initialization, training loop with cosine annealing, and early stopping.

After training, the script re-evaluates the best model on the full validation set to compute the required "Final Validation Metric". It then performs a failure analysis by correlating the sample-wise MCRMSE errors with input features (Signal-to-Noise, Sequence Length, Nucleotide Composition) to identify systematic weaknesses. Finally, if the validation performance meets the specified threshold (< 0.5884), it generates predictions for the test set and saves the submission file to the designated `./submission/submission.csv` path.
