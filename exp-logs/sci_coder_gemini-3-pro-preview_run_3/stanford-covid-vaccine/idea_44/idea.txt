# Proposed Strategy: Stabilized MLP-Gated Decoupled BiGRU

This strategy represents the "Corrected & Stabilized" evolution of the state-of-the-art Idea 17. It retains the optimal depth (3 layers) and capacity (384 dim) but replaces the ambiguous gating mechanism with a **Stabilized 2-Layer MLP Gate**. This gate applies normalization strictly to the *hidden* layer of the MLP, satisfying the stability requirement of Lesson 75 without destroying the binary switching capability (Lesson 78) or corrupting sparse inputs (Lesson 79).

### Model

The architecture is a **3-Layer Bidirectional GRU with Interleaved Stabilized MLP-Gated Structural Injection**.

1.  **Input Representation:**
    *   The input is a sequence-preserved tensor of shape $(N, 107, 14)$. **Cite solution_lesson_node_00002**.
    *   **Feature Channels:** Strictly One-Hot Encoding for nucleotide (4), structure (3), and loop type (7). No learned embeddings. **Cite solution_lesson_node_00009**.
    *   **Purity:** No concatenation of paired features at the input. **Cite solution_lesson_node_00037**.

2.  **Convolutional Stem:**
    *   **1D Convolutional Layer** (kernel size 3, filters 256, activation GELU).
    *   **Purpose:** Projects sparse inputs into a dense embedding space and aggregates local k-mers. **Cite solution_lesson_node_00027**.

3.  **Stabilized Refinement Backbone:**
    *   The backbone consists of **3 Blocks** (sticking to the optimal depth of Idea 17, avoiding the instability of 4-layer attempts). Each block contains a **Bidirectional GRU** followed by the **Structural Interaction Module** (except the final block).
    *   **BiGRU Layer:** Hidden dimension of **384**. **Cite solution_lesson_node_00063**.
    *   **Stabilized MLP-Gated Interaction Module (Structural Innovation):**
        *   **Context:** For every position $i$ paired with index $j$.
        *   **Gather:** Retrieve $h_j$ directly (Point-to-Point). **Cite solution_lesson_node_00058**.
        *   **Zero-Masking:** If $i$ is unpaired, force $h_j = 0$. No self-loops. **Cite solution_lesson_node_00064**.
        *   **Decoupled Message:** $m_{ij} = \text{GELU}(W_{msg} \cdot h_j + b_{msg})$. The bias term $b_{msg}$ allows unpaired bases (where $h_j=0$) to receive a learnable "loop embedding," enabling self-refinement. **Cite solution_lesson_node_00080** and **Cite solution_lesson_node_00085**.
        *   **Stabilized MLP Gate:**
            *   Project Joint Context: $z_{raw} = W_{g1} \cdot [h_i; h_j]$.
            *   **Hidden Normalization:** $z_{norm} = \text{LayerNorm}(z_{raw})$. This stabilizes the MLP internals **Cite solution_lesson_node_00075** without destroying the sparsity of the input **Cite solution_lesson_node_00079**.
            *   Activation: $z_{act} = \text{GELU}(z_{norm})$.
            *   Logit Projection: $logits = W_{g2} \cdot z_{act}$.
            *   **No Logit Norm:** $g_{ij} = \sigma(logits)$. We strictly avoid normalizing these logits to allow saturation. **Cite solution_lesson_node_00078**.
        *   **Injection:** $h_{res} = h_i + g_{ij} \odot m_{ij}$.
        *   **Post-Normalization:** $h_{out} = \text{LayerNorm}(h_{res})$. **Cite solution_lesson_node_00068**.

4.  **Output Head:**
    *   Linear projection to 5 target values.
