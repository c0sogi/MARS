Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class. To ensure a "fast baseline" execution within the time limit, I will override the default `EPOCHS` to 15. Random seeds will be fixed using `seed_everything`.
2.  **Data Loading**: Utilize `get_dataloaders(load_cached_data=True)` to efficiently load the pre-processed training, validation, and test datasets.
3.  **Model Initialization**: Instantiate the `RNAModel` (3-Layer BiGRU with Stabilized MLP-Gated Interaction) and move it to the GPU.
4.  **Training**: Configure the `AdamW` optimizer and `CosineAnnealingLR` scheduler. Execute the training loop using `run_training`, which handles backpropagation, gradient clipping, and early stopping.
5.  **Validation**: Load the best saved model weights. Compute the global MCRMSE on the validation set using `eval_fn` and print it in the required format.
6.  **Failure Analysis**:
    *   Compute the Root Mean Squared Error (RMSE) for each individual sample in the validation set (sliced to the scored positions and columns).
    *   Load the validation metadata (`val.parquet`) to retrieve features like `signal_to_noise` and `SN_filter`.
    *   Calculate and print the Pearson correlation between the sample-wise RMSE and these features to identify error sources.
7.  **Submission Generation**:
    *   Check if the validation metric satisfies the threshold (< 0.5884495377540588).
    *   If valid, run inference on the test set to generate predictions for all 107 positions.
    *   Format the output into the required `id_seqpos` structure (flattening the (N, 107, 5) tensor).
    *   Save the result to `submission.csv`.
