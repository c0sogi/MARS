The implementation strategy follows the provided guidelines to create a fast, robust baseline using the `InterleavedBiGRU` architecture.

1.  **Setup & Configuration**: We initialize the environment with fixed seeds for reproducibility and configure the device (GPU/CPU). We explicitly override `Config.EPOCHS` to 10 to ensure the training completes quickly within the time limit while still providing a meaningful baseline.
2.  **Data Loading**: We utilize `get_loaders` with `load_cached_data=True` to efficiently load the preprocessed training and validation datasets.
3.  **Training**: We instantiate the `InterleavedBiGRU` model and execute the training loop using `train_model` from the engine. This handles the optimization (AdamW + CosineAnnealing) and saves the best model based on validation performance.
4.  **Validation**: We reload the best model weights and perform a full inference pass on the validation set. We manually calculate the MCRMSE on the specific scored columns (`reactivity`, `deg_Mg_pH10`, `deg_Mg_50C`) to report the `Final Validation Metric`.
5.  **Failure Analysis**: We compute the per-sample RMSE and correlate it with metadata features (`signal_to_noise`, `SN_filter`) loaded from the validation parquet file. This identifies if low-quality samples are driving errors.
6.  **Submission**: We check if the final metric is below the specified threshold (0.7247761841173526). If satisfied, we load the test data and generate the `submission.csv` using the `inference` function.
