The following code demonstrates how to utilize the provided library modules for the smartphone location task. It performs the following steps:
1.  **Configuration Override**: Monkey-patches configuration settings to reduce runtime (fewer epochs, smaller dataset).
2.  **Data Loading**: Loads metadata and raw sensor data for a single drive to demonstrate data handling.
3.  **Feature Engineering**: Generates Doppler velocity estimates and aggregated features from GNSS/IMU data.
4.  **Target Generation**: Calculates Ground Truth targets (East/North/Up residuals) using coordinate transformation utilities.
5.  **Model Training**: Trains the LightGBM-based `ResidualRegressor` on the processed sample data.
6.  **Trajectory Optimization**: Applies the physics-based global optimization to refine the predicted trajectory.
7.  **Utility Verification**: Validates coordinate transformation functions with round-trip assertions.
