Based on the accumulated lessons, specifically the superiority of **Gradient Boosting** for sensor data (Cite solution_lesson_node_00010), the necessity of **Residual Learning** (Cite solution_lesson_node_00007), and the critical insight that **Directional Context** is required to correct vector errors (Cite solution_lesson_node_00033), I propose the **Geometry-Projected Residual Boosting (GPR-Boost)** strategy.

This strategy structurally evolves the "Sector-Based" feature engineering of the previous best idea into a **Continuous Geometric Projection** framework. Instead of binning errors into discrete quadrants (which loses resolution), this approach explicitly projects satellite residuals onto the local East/North axes using the satellite's Azimuth and Elevation. This effectively provides the model with the "Net Error Force" vector and the "Geometry Matrix" components, allowing the GBDT to approximate a non-linear Weighted Least Squares correction.

### 1. Model
The core architecture consists of an **Ensemble of LightGBM Regressors**.
*   **Backbone:** Independent LightGBM models trained on $K$ cross-validation folds.
*   **Targets:** The models predict the **ENU (East-North-Up) Residuals** in meters.
    *   $\Delta E = East_{GT} - East_{WLS}$
    *   $\Delta N = North_{GT} - North_{WLS}$
    *   This retains the residual learning paradigm, leveraging the WLS baseline as a robust physical prior (Cite solution_lesson_node_00007).

### 2. Data
The preprocessing pipeline replaces discrete sector binning with continuous geometric projections derived from the linearized GPS observation equation.

*   **Coordinate Transformation:** Convert Ground Truth and WLS positions to a local ENU frame.
*   **Physics-Based Feature Extraction (Innovation):**
    For each timestamp $t$, process the set of visible satellites:
    1.  **Raw Residuals:** Calculate $r_i = \rho_{meas, i} - \rho_{calc, i}$ for each satellite $i$, where $\rho_{calc}$ is the distance to the WLS baseline.
    2.  **Common Mode Isolation:** Estimate the residual receiver clock bias/drift as $b_t = \text{Median}(\{r_i\})$. Compute adjusted residuals $\tilde{r}_i = r_i - b_t$. This isolates the differential errors that drive position offsets.
    3.  **Geometric Projection:** Calculate the Line-of-Sight (LOS) unit vector $\vec{u}_i = [\cos(El)\sin(Az), \cos(El)\cos(Az), \sin(El)]$ for each satellite.
    4.  **Projected Error Features:** Compute the "Net Error Force" vector by summing the projected residuals:
        $$ \vec{F}_{err} = \sum_{i} w_i \cdot \tilde{r}_i \cdot \vec{u}_i $$
        where $w_i$ is a weight based on signal strength (`Cn0DbHz`). This feature vector $[\sum \tilde{r} u_E, \sum \tilde{r} u_N]$ directly correlates with the direction and magnitude of the position error (Cite solution_lesson_node_00033).
    5.  **Geometry Conditioning:** Compute the elements of the covariance matrix approximation (Sum of outer products of unit vectors): $\sum u_{E}^2, \sum u_{N}^2, \sum u_{E}u_{N}$. These features describe the "Dilution of Precision" (DOP), allowing the model to scale its corrections based on the constellation geometry.
*   **Global Features:** IMU dynamics (Mean/Std of acceleration) and signal quality stats (Mean Cn0).
*   **Constraint:** Strictly **Point-Wise** features only (no temporal windowing) to prevent trajectory memorization (Cite solution_lesson_node_00011).

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss minimizes the impact of heavy-tailed outliers inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Validation Strategy:** **GroupKFold** cross-validation grouped by `drive_id`. This ensures the model is evaluated on completely unseen drives, enforcing generalization.

### 4. Evaluation
The inference pipeline relies on robust ensemble aggregation, explicitly rejecting temporal smoothing to avoid outlier smearing (Cite solution_lesson_node_00014).
1.  **Feature Generation:** Compute the Geometry-Projected features for the test set.
2.  **Ensemble Prediction:** Generate predictions ($\Delta E, \Delta N$) from all $K$ fold models.
3.  **Robust Aggregation:** Compute the **Pixel-wise Median** of the predictions.
4.  **Reconstruction:** Convert the median ENU residuals back to Geodetic offsets and apply them to the WLS baseline to generate the final trajectory.
