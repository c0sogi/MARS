The issue is that the demonstration script (`runfile.py`) selects only a single trip for the training subset to speed up execution. Since `GroupKFold` splits data based on groups (which corresponds to `drive_id` in this pipeline), having only one trip (and thus one drive) results in only one group. `GroupKFold` requires at least as many groups as the number of splits (`n_splits=2`), causing the `ValueError`.

To fix this, I will modify the data selection logic in `runfile.py` to select trips from at least two distinct drives for the training set. This ensures that the training data contains enough groups to satisfy the cross-validation constraints while still keeping the dataset small for demonstration purposes.
