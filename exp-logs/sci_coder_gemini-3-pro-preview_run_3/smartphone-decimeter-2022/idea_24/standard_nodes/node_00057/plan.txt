The strategy implemented in this runfile is **Unified Geometric-Boosting with Robust Carrier-Phase Graph Optimization**.

1.  **Data Preparation**: We load the preprocessed dataset which combines training and validation splits. To ensure a rigorous evaluation, we explicitly split this dataset back into `train` and `val` sets based on the `drive_id`s defined in the metadata. This prevents data leakage during validation.
2.  **Model Training**: We train two LightGBM regressors (one for Easting error, one for Northing error) solely on the `train` split. The models learn to correct the Weighted Least Squares (WLS) baseline using geometric features (Satellite Force vectors, Geometry Matrix elements) and signal quality indicators.
3.  **Validation**: We evaluate the trained models on the held-out `val` split. The predictions are converted from local ENU residuals to global Latitude/Longitude, and the competition metric (mean of 50th and 95th percentile errors) is computed.
4.  **Failure Analysis**: We analyze the correlation between the prediction error and input features (e.g., Signal Strength, Satellite Count) to understand the model's limitations.
5.  **Global Optimization**: If the validation metric meets the threshold, we proceed to the test phase. We generate baseline predictions for the test set using the trained models. Then, we apply a **Graph Optimizer** that fuses these ML "anchors" with precise relative odometry derived from Time-Differenced Carrier Phase (TDCP) measurements. This step enforces physical trajectory constraints to smooth out ML outliers and improve local accuracy.
