This implementation orchestrates the **Sector-Based Pseudorange-Residual Boosting** pipeline. It leverages the provided library modules to load preprocessed data (caching it for speed), trains a LightGBM ensemble on the training set, and evaluates it on the hold-out validation set using the competition's specific metric (mean of 50th and 95th percentile errors). It includes a failure analysis step to correlate errors with signal features and generates a submission file if the performance threshold is met.
