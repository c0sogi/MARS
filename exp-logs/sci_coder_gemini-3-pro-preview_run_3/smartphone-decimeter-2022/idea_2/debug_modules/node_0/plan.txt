Implementation Strategy:
1.  **Setup & Imports**: Import necessary modules from the provided `library` package and standard libraries (pandas, os).
2.  **Data Subsampling**: To ensure the script runs quickly, load the original metadata files (`train_metadata.csv`, `val_metadata.csv`, `test_metadata.csv`), sample a small number of trips (e.g., 2 trips), and save these subset metadata files to the `./working` directory.
3.  **Feature Engineering**: Use `library.features.generate_dataset` directly with the subsampled metadata paths to generate feature DataFrames for training, validation, and testing. This bypasses processing the entire dataset.
4.  **Data Preparation**: Extract feature matrices (`X`) and target vectors (`y`) from the generated DataFrames using the column definitions in `library.config`.
5.  **Model Training**: Instantiate the `LGBMRegressorWrapper` with reduced hyperparameters (e.g., `n_estimators=10`) for a fast demonstration. Train the model on the prepared training and validation subsets.
6.  **Inference**: Use the trained model to predict latitude and longitude errors on the test subset.
7.  **Submission Generation**: Use `library.model.generate_submission` to apply the predicted errors to the baseline WLS positions and create a sample submission file.
8.  **Validation**: Perform assertions throughout the script to verify data shapes, column existence, and prediction validity.
