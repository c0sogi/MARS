Based on the accumulated lessons, specifically the superiority of **Gradient Boosting** for sensor residuals (Cite solution_lesson_node_00010), the effectiveness of **Geometric Projection** features (Cite solution_lesson_node_00043), and the high precision of **Carrier Phase (TDCP)** for relative motion (Cite solution_lesson_node_00046), I propose the **Split-Band Projected Boosting with Robust Graph Trajectory Optimization** strategy.

This approach structurally evolves the previous "Geometry-Projected" idea by **splitting the projection features by frequency band (L1 vs. L5)**. Since L5 signals are physically more robust to multipath than L1, explicitly separating their error gradients allows the model to learn a dynamic weighting scheme superior to the fixed WLS baseline. Furthermore, the inference stage replaces simple smoothing with a **Multi-Modal Factor Graph** that prioritizes carrier-phase kinematics but robustly falls back to Doppler velocity when phase locks are lost.

### 1. Model: Split-Band LightGBM Ensemble
The predictive core remains an ensemble of **LightGBM Regressors**, optimized to map instantaneous signal snapshots to position errors.

*   **Architecture:** Two independent models will be trained:
    *   **East Model:** Predicts the Easting error ($\Delta E$).
    *   **North Model:** Predicts the Northing error ($\Delta N$).
*   **Target:** The model predicts the **ENU (East-North-Up) Residuals** ($P_{GT} - P_{WLS}$) in meters. This leverages the WLS baseline as a robust physical prior (Cite solution_lesson_node_00007).
*   **Input Features (Structural Innovation):**
    Instead of a single "Net Error Force" vector, the model receives three distinct force vectors per timestamp:
    1.  **L1 Pseudorange Force:** $\sum_{L1} w_i r_i \vec{u}_i$. The net error gradient derived only from L1 signals (GPS L1, GAL E1, etc.).
    2.  **L5 Pseudorange Force:** $\sum_{L5} w_i r_i \vec{u}_i$. The net error gradient derived only from L5 signals (GPS L5, GAL E5a, etc.), which are cleaner but sparser.
    3.  **Doppler Force:** $\sum w_i r_{dop, i} \vec{u}_i$. The net error gradient derived from Doppler residuals, indicating dynamic inconsistency (Cite solution_lesson_node_00033).
    *   **Geometry Context:** Elements of the DOP matrix calculated separately for L1 and L5 subsets.
    *   **Global Context:** Aggregated signal quality and IMU dynamics.

### 2. Data: Point-Wise Physics & Kinematics
The preprocessing pipeline strictly adheres to a **Point-Wise** paradigm (no temporal windowing) to prevent trajectory memorization (Cite solution_lesson_node_00011).

*   **Coordinate Transformation:** Convert Ground Truth and WLS positions to a local ENU frame.
*   **Kinematic Extraction:**
    *   **TDCP Odometry:** Calculate Time-Differenced Carrier Phase displacements between consecutive epochs. Apply **RANSAC** to robustly reject cycle slips and estimate the relative motion vector with millimeter-level precision.
    *   **Doppler Velocity:** Calculate instantaneous velocity using a WLS solution on raw Doppler measurements.
*   **Feature Engineering:** Compute the Split-Band Projected features described above for every timestamp in Train and Test.

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss minimizes the median error, ensuring the predicted "anchors" are robust to the massive outliers inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Validation:** **GroupKFold** cross-validation grouped by `drive_id`. This ensures the model is evaluated on completely unseen drives, enforcing generalization.

### 4. Evaluation: Multi-Modal Graph Optimization
The inference pipeline uses a **Global Factor Graph** to fuse the ML predictions with the best available physical constraints, solving the "smearing" issue of standard smoothers (Cite solution_lesson_node_00014).

1.  **Anchor Generation:** Use the trained LightGBM ensemble to predict residuals and correct the WLS baseline, producing a sequence of absolute positions $\hat{P}_{ML}$.
2.  **Graph Construction:** Define a cost function over the trajectory $X = \{x_0, \dots, x_N\}$:
    $$ J(X) = \sum_{t} \rho(x_t - \hat{P}_{ML, t}) + \sum_{t} w_t ||(x_t - x_{t-1}) - \Delta \vec{x}_{kin, t}||^2 $$
    *   **Anchor Term:** $\rho$ is a **Huber Loss**. It pulls the trajectory towards the ML predictions but allows it to "break" away from large ML outliers.
    *   **Shape Term:** The L2 penalty enforces the relative shape $\Delta \vec{x}_{kin, t}$.
        *   **Priority Logic:** If RANSAC TDCP is successful (sufficient inliers), set $\Delta \vec{x}_{kin, t} = \Delta \vec{x}_{TDCP}$ and $w_t = High$.
        *   **Fallback:** If TDCP fails (cycle slips), set $\Delta \vec{x}_{kin, t} = \vec{V}_{Doppler} \cdot \Delta t$ and $w_t = Medium$.
3.  **Optimization:** Minimize $J(X)$ to obtain the final trajectory. This fuses the global accuracy of the Split-Band ML model with the local precision of Carrier Phase physics.
