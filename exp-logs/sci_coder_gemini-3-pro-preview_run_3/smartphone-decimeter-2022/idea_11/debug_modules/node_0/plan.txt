This script demonstrates the end-to-end usage of the provided library files (`config.py`, `utils.py`, `features.py`, `data_loader.py`, `model.py`). It performs the following steps:

1.  **Configuration Override**: Modifies global hyperparameters in `library.model` (e.g., number of folds, estimators) to ensure the script runs quickly.
2.  **Data Preparation**: Creates small subsets of the metadata files to limit the amount of raw sensor data processed.
3.  **Feature Generation**: Uses `library.features` to process raw GNSS/IMU logs into feature dataframes for training, validation, and testing.
4.  **Model Training**: Instantiates the `PhysicsEnsembleModel`, trains it using the generated features, and validates the model structure.
5.  **Inference**: Generates predictions (East/North offsets) on the test subset.
6.  **Reconstruction**: Converts the predicted offsets back to WGS84 Latitude/Longitude.
7.  **Utility Verification**: Runs unit tests on key utility functions like coordinate conversions and distance calculations.
