The error `ValueError: Input contains NaN` encountered during training indicates that the regression targets (`delta_east`, `delta_north`) contain missing values. This happens because the `process_drive` function has a logical flaw: when `is_train=True` but the ground truth file (`gt_rel`) is missing or invalid for a specific drive, the code falls through to the `else` block. This block returns a DataFrame containing only features (intended for inference), which lacks the target columns. When these DataFrames are concatenated with valid training data, pandas fills the missing target columns with `NaN`s, polluting the training set. Additionally, the metadata grouping logic for `gt_path` was fragile.

I will fix this by:
1.  Modifying `process_drive` in `library/features.py` to explicitly return `None` if `is_train=True` but ground truth is missing, preventing schema mismatch.
2.
