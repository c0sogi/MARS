Based on the lessons learned, specifically the superiority of **Gradient Boosting** for sensor residuals (Cite solution_lesson_node_00010), the effectiveness of **Geometric Projection** features (Cite solution_lesson_node_00043), and the high precision of **Carrier Phase (TDCP)** for relative motion (Cite solution_lesson_node_00046), I propose the **Split-Band Projected Boosting with Hierarchical Graph Optimization** strategy.

This strategy structurally evolves the previous best approach (Idea 16) in two ways:
1.  **Feature Engineering:** It splits the geometric projection features by frequency band (L1 vs. L5). Since L5 signals are physically more robust to multipath, explicitly separating their error gradients allows the model to learn a dynamic weighting scheme superior to the fixed WLS baseline.
2.  **Trajectory Reconstruction:** It replaces the simple global optimization with a **Hierarchical Factor Graph**. This graph prioritizes millimeter-precise carrier-phase kinematics but robustly falls back to Doppler velocity when phase locks are lost (cycle slips), addressing the robustness issues of pure TDCP methods.

### 1. Model
The predictive core remains an ensemble of **LightGBM Regressors**, optimized to map instantaneous signal snapshots to position errors.

*   **Architecture:** Two independent models will be trained:
    *   **East Model:** Predicts the Easting error ($\Delta E$).
    *   **North Model:** Predicts the Northing error ($\Delta N$).
*   **Target:** The model predicts the **ENU (East-North-Up) Residuals** ($P_{GT} - P_{WLS}$) in meters. This leverages the WLS baseline as a robust physical prior (Cite solution_lesson_node_00007) and avoids the distortion of geodetic coordinates (Cite solution_lesson_node_00036).
*   **Input Features (Structural Innovation):**
    Instead of a single "Net Error Force" vector (Cite solution_lesson_node_00043), the model receives **Split-Band Projections**:
    1.  **L1 Pseudorange Force:** $\vec{F}_{L1} = \sum_{i \in L1} w_i r_i \vec{u}_i$. The net error gradient derived only from L1 signals.
    2.  **L5 Pseudorange Force:** $\vec{F}_{L5} = \sum_{i \in L5} w_i r_i \vec{u}_i$. The net error gradient derived only from L5 signals.
    3.  **Doppler Force:** $\vec{F}_{Dop} = \sum_{all} w_i r_{dop, i} \vec{u}_i$. The net error gradient derived from Doppler residuals, indicating dynamic inconsistency (Cite solution_lesson_node_00033).
    *   **Geometry Context:** Elements of the DOP matrix calculated separately for L1 and L5 subsets.
    *   **Global Context:** Aggregated signal quality and IMU dynamics.

### 2. Data
The preprocessing pipeline strictly adheres to a **Point-Wise** paradigm (no temporal windowing) to prevent trajectory memorization (Cite solution_lesson_node_00011).

*   **Coordinate Transformation:** Convert Ground Truth and WLS positions to a local ENU frame.
*   **Kinematic Extraction (Hierarchical Odometry):**
    For every pair of timestamps $(t-1, t)$:
    *   **Tier 1 (TDCP):** Calculate Time-Differenced Carrier Phase displacements. Apply **RANSAC** to robustly reject cycle slips and estimate the relative motion vector $\Delta \vec{x}_{TDCP}$.
    *   **Tier 2 (Doppler):** Calculate instantaneous velocity using a WLS solution on raw Doppler measurements to get $\Delta \vec{x}_{Dop}$.
*   **Feature Engineering:** Compute the Split-Band Projected features described above for every timestamp in Train and Test.

### 3. Training
*   **Loss Function:** **Mean Absolute Error (MAE)**. This L1 loss minimizes the median error, ensuring the predicted "anchors" are robust to the massive outliers inherent in urban GNSS data (Cite solution_lesson_node_00007).
*   **Validation:** **GroupKFold** cross-validation grouped by `drive_id`. This ensures the model is evaluated on completely unseen drives, enforcing generalization.

### 4. Evaluation
The inference pipeline uses a **Global Factor Graph** to fuse the ML predictions with the best available physical constraints, solving the "smearing" issue of standard smoothers (Cite solution_lesson_node_00014).

1.  **Anchor Generation:** Use the trained LightGBM ensemble to predict residuals and correct the WLS baseline, producing a sequence of absolute positions $\hat{P}_{ML}$.
2.  **Graph Construction:** Define a cost function over the trajectory $X = \{x_0, \dots, x_N\}$:
    $$ J(X) = \sum_{t} \rho(x_t - \hat{P}_{ML, t}) + \sum_{t} \lambda_t ||(x_t - x_{t-1}) - \Delta \vec{x}_{kin, t}||^2 $$
    *   **Anchor Term:** $\rho$ is a **Huber Loss**. It pulls the trajectory towards the ML predictions but allows it to "break" away from large ML outliers.
    *   **Shape Term:** The L2 penalty enforces the relative shape.
        *   **Hierarchical Logic:** If RANSAC TDCP is valid (sufficient inliers), set $\Delta \vec{x}_{kin, t} = \Delta \vec{x}_{TDCP}$ and $\lambda_t = High$. If TDCP fails, set $\Delta \vec{x}_{kin, t} = \Delta \vec{x}_{Dop}$ and $\lambda_t = Medium$.
3.  **Optimization:** Minimize $J(X)$ using a sparse solver (e.g., `scipy.optimize` or PyTorch) to obtain the final trajectory.
