The following script demonstrates the usage of the provided library modules for the smartphone location task. It performs the following steps:
1.  **Configuration Override**: Updates `library.config` to use a temporary working directory and reduced hyperparameters for a quick demonstration.
2.  **Data Preparation**: Samples a small subset of the provided metadata to create lightweight training, validation, and test sets.
3.  **Data Processing**: Uses `library.data_factory` to load and process raw GNSS/IMU data for the sampled trips.
4.  **Dataset & DataLoader**: Demonstrates `library.dataset` by creating dataloaders and verifying batch shapes.
5.  **Model Initialization**: Instantiates the `ResidualBiLSTM` model from `library.model`.
6.  **Training Loop**: Runs a short training session using `library.trainer` to verify the training pipeline and model saving.
7.  **Inference**: Generates a submission file using the trained model.
8.  **Utility Verification**: Validates the geometric conversion and metric calculation functions in `library.utils`.
