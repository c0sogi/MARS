This script implements the end-to-end pipeline for the smartphone location task. It proceeds by loading the metadata and generating windowed features for the training and validation sets. A LightGBM-based Residual Regressor is then trained to predict the error between the Weighted Least Squares (WLS) baseline and the ground truth. The predictions on the validation set are refined using a Kalman Smoother to ensure kinematic consistency. The script evaluates the model using the competition metric and performs a failure analysis by correlating prediction errors with input features. Finally, if the validation score meets the specified threshold, it generates predictions for the test set, applies smoothing, and creates the submission file.
