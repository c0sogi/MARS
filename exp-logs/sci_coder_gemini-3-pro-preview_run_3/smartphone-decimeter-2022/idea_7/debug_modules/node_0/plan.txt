This script demonstrates the end-to-line machine learning pipeline for smartphone location tracking using the provided library files. It performs the following steps:
1.  **Configuration**: Adjusts global configuration to run in `DEBUG` mode with reduced boosting rounds for rapid execution.
2.  **Feature Engineering**: Loads raw GNSS/IMU data, aggregates it, computes kinematic features, and generates targets (residuals) for both training and validation splits.
3.  **Model Training**: Trains a LightGBM regressor using GroupKFold cross-validation to predict position errors (residuals).
4.  **Inference**: Generates predictions on the validation set.
5.  **Post-Processing**: Applies an Innovation-Gated Kalman Filter (Kinematic Smoother) to refine the predicted trajectories.
6.  **Evaluation**: Calculates the competition metric (mean of 50th and 95th percentile errors) comparing the smoothed path against Ground Truth.
