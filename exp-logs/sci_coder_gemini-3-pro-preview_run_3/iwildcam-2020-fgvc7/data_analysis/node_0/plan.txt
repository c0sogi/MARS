The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup and Loading**: Initialize the environment, set random seeds for reproducibility, and load the training metadata from `./metadata/train_metadata.csv`.
2.  **Target Variable Analysis**: Analyze the `category_id` column to determine the number of classes, the distribution of samples per class, and the severity of class imbalance (specifically checking the ratio of the most frequent to the least frequent class).
3.  **Image Data Analysis**: Due to the large dataset size, perform a stratified random sampling of approximately 2,000 images (or fewer if the dataset is smaller) to efficiently estimate image statistics.
    *   **Dimensions**: Calculate distributions for width, height, and aspect ratios.
    *   **Channels**: Verify if images are RGB or Grayscale.
    *   **Pixel Stats**: Estimate global pixel mean and standard deviation using the sampled images.
4.  **Meta-Feature Relationships**:
    *   Analyze the relationship between the MegaDetector's `max_detection_conf` and the target variable, specifically contrasting "Empty" images (Category 0) vs. "Animal" images.
    *   Investigate if image file size or dimensions correlate with specific categories (though less likely in fixed camera traps, it's a standard check).
5.  **Reporting**: Output the findings in a structured, text-based report with distinct sections and formatted floating-point numbers as requested.
