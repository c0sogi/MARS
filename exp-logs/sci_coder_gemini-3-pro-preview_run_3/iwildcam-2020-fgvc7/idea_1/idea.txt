# Proposed Baseline Approach: Detector-Guided MobileNetV3

## Model
We will employ a **MobileNetV3-Small** architecture, designed specifically for speed and efficiency on mobile and edge devices. Unlike standard approaches that process the entire image (which includes significant background noise), this model will focus exclusively on the region of interest identified by the provided MegaDetector. The architecture will consist of the pre-trained MobileNetV3-Small backbone followed by a standard classification head (global average pooling, a dropout layer, and a fully connected layer) outputting probabilities for the species classes.

## Data
1.  **Filtering:** We will utilize the `max_detection_conf` from the metadata to create a hybrid data pipeline. Images with a maximum detection confidence below a set threshold (e.g., 0.2) will be designated as "Empty" (Class 0) by heuristic and excluded from the neural network dataset entirely.
2.  **Cropping:** For the remaining images, we will extract the bounding box associated with the highest confidence score. This transforms the problem from "scene classification" to "object classification."
3.  **Resizing:** These cropped regions will be resized to a standard, lightweight resolution (e.g., 224x224 pixels) and normalized using ImageNet statistics. This significantly reduces the input dimensionality compared to processing full-resolution camera trap images.

## Training
The model will be fine-tuned end-to-end using **Cross-Entropy Loss**. We will use the **AdamW** optimizer with a standard learning rate schedule (e.g., Cosine Annealing). Since the "easy" empty images are filtered out by the detector logic, the training set will be naturally balanced toward actual animal species, allowing the model to focus on distinguishing between species rather than learning to detect animals from backgrounds.

## Evaluation
Inference will follow a highly efficient two-stage cascade:
1.  **Stage 1 (Rule-based):** Check the `max_detection_conf` for the test image. If it is below the defined threshold, immediately predict Class 0 (Empty).
2.  **Stage 2 (Model-based):** If the confidence is above the threshold, crop the region corresponding to the highest-confidence bounding box, pass it through the fine-tuned MobileNetV3-Small, and select the class with the highest probability.
