Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment by setting random seeds for reproducibility and defining the computation device (GPU/CPU).
2.  **Data Loading (Training)**: Utilize the provided `get_dataloaders` function. To ensure a fast baseline execution within the time limit, we will limit the training dataset to 20,000 samples. This allows for rapid model convergence verification without processing the entire 120k+ image dataset.
3.  **Model Initialization**: Instantiate the MobileNetV3-Small species classifier using `get_species_classifier` and move it to the GPU.
4.  **Training Loop**: Execute the training process using `train_model`. We will reduce the number of epochs to 5 to further speed up the baseline run while still allowing the model to learn.
5.  **Full Validation Assessment**:
    *   The standard validation loader only contains "high-confidence" images. To compute the true **Categorization Accuracy**, we must account for the entire validation set.
    *   We will load the full validation metadata and split it: images below the confidence threshold are automatically predicted as "Empty" (Class 0). Images above the threshold are processed by the trained model.
    *   We will combine these predictions to calculate the global accuracy and print it in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   We will calculate the binary error (1 for incorrect, 0 for correct) for each validation sample.
    *   We will compute and print the correlation between the model's error and the `max_detection_conf` metadata field to understand if confidence levels relate to misclassifications.
7.  **Submission Generation**: Finally, we will use the provided `get_test_dataloader` and `generate_submission` functions to produce the `submission.csv` file for the test set, applying the same hybrid (heuristic + model) logic.
