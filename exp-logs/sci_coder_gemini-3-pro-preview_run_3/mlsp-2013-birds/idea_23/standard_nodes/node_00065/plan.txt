Here is the implementation strategy and the complete execution script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the `Config` object with a moderate number of epochs (30) to ensure the pipeline completes well within the 2-hour limit while ensuring convergence on this small dataset. Set random seeds for reproducibility.
2.  **Data Preparation**: Load the dataset splits using `load_data_splits` with caching enabled. This provides the 5-fold cross-validation structure created via Iterative Stratification.
3.  **Training Phase**: Iterate through the three heterogeneous architectures (ResNet18, EfficientNet-B0, DenseNet121) and the 5 folds. For each combination, execute `run_fold` from the `trainer` module. This handles training, validation monitoring, and saving the Top-3 snapshot checkpoints.
4.  **Validation & OOF Generation**: After training, perform Out-Of-Fold (OOF) inference.
    *   Iterate through each fold.
    *   Load the validation data for that fold.
    *   Load the saved Top-3 checkpoints for all 3 models corresponding to that fold.
    *   Generate predictions using Test-Time Augmentation (TTA) and average them to create a robust ensemble prediction for the validation set.
    *   Aggregate ground truth and predictions across all folds.
5.  **Metric Calculation**: Compute the macro-averaged ROC AUC on the aggregated OOF predictions. This serves as the "Final Validation Metric".
6.  **Failure Analysis**:
    *   Calculate the reconstruction error (L1 distance) per sample between predictions and ground truth.
    *   Compute simple input features (e.g., image brightness mean/std, number of labels).
    *   Calculate and print the Pearson correlation between the error magnitude and these features to identify potential biases (e.g., does the model fail more on dark images or complex multi-species recordings?).
7.  **Submission**: Compare the calculated validation AUC against the threshold (0.9479806884980326). If the model performs sufficiently well, invoke `inference.run_inference()` to generate predictions on the test set and save `submission.csv`.
