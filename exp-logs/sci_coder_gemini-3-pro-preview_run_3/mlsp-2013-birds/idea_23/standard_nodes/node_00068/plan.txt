The current file search pattern (`*.pth`) is too broad, causing the inference and validation loops to attempt loading these incompatible files, leading to `KeyError: 'model_state_dict'` and potentially invalidating the metric calculation. To fix this, I will update the `OUTPUT_DIR` to a fresh location to ensure a clean environment and invalidate stale data caches (Cite debug_lesson_11). Additionally, I will refine the `glob` search patterns in both `library/inference.py` and `runfile.py` to strictly match the `_epoch_` naming convention used by the `Trainer`, ensuring only valid checkpoints are loaded.
