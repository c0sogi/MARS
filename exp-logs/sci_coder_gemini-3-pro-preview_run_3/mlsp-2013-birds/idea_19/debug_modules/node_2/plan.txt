The issue is that the `IterativeStratification` class from `scikit-multilearn` hardcodes `shuffle=False` when initializing its parent class, but the code passes a `random_state`. In modern versions of `scikit-learn`, passing a `random_state` when `shuffle` is `False` raises a `ValueError`. To fix this, I will remove the `random_state` argument from the `IterativeStratification` constructor in `library/data.py`. This aligns with the guidance in **Cite debug_lesson_2**.
