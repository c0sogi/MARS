### Implementation Strategy

1.  **Configuration Setup**: Import the `Config` class and override settings to enable `DEBUG` mode. This reduces the dataset size (to 32 samples) and limits training to 1 epoch, ensuring the script executes quickly (within minutes) while still exercising all code paths. We also redirect the working directory to a demo-specific location.
2.  **Data Pipeline Verification**:
    *   Execute `make_folds` to generate the cross-validation split and verify the resulting DataFrame structure.
    *   Initialize data loaders using `get_loaders` and `get_test_loader`.
    *   Fetch a single batch from the training loader to assert that input tensors (images) and targets (labels) have the correct shapes and data types.
3.  **Model Architecture Verification**:
    *   Instantiate a model (ResNet18) using `get_model`.
    *   Perform a forward pass with a dummy tensor to confirm the model outputs logits with the expected shape `(Batch Size, Num Classes)`.
4.  **Training Engine Verification**:
    *   Run `train_fold` for a single fold. This tests the training loop, mixup augmentation, backpropagation, validation loop, metric calculation, and checkpoint saving.
    *   Assert that the best model checkpoint file is physically created on disk.
5.  **Inference and Submission Verification**:
    *   Use the trained checkpoint to run `inference` on the test set.
    *   Verify the output dimensions of the predictions.
    *   Generate a submission file using `save_submission` and validate its format (columns and row count) against the sample submission.
