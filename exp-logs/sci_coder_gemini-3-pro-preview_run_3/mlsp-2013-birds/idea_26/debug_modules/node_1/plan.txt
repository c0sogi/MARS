The issue is caused by passing a `random_state` argument to `IterativeStratification` while `shuffle` defaults to `False`. Modern versions of `scikit-learn` (which `scikit-multilearn` relies on) strictly forbid setting a random seed when shuffling is disabled, raising a `ValueError`. To fix this, I will manually shuffle the DataFrame deterministically before preparing the data for stratification and then instantiate `IterativeStratification` without the `random_state` argument, as detailed in `debug_lesson_2`.
