The following script demonstrates the usage of the provided library files for the Bird Species Classification task. It covers data loading, model initialization, the SAM optimizer, and a complete execution of the training and inference pipeline using a lightweight configuration.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the global `Config` class to use a temporary working directory, reduce the number of epochs to 1, limit cross-validation to 2 folds, and select a single lightweight model architecture (`resnet18`) to ensure the demo runs quickly.
2.  **Dataset Verification**: We explicitly load a subset of the training data using `load_data`, apply augmentations using `get_transforms`, and verify the output shapes of the `BirdDataset`.
3.  **Model & Optimizer Verification**: We instantiate the model and the `SAM` optimizer, performing a manual forward/backward pass with the required closure to verify the sharpness-aware minimization logic.
4.  **Pipeline Execution**: We execute `run_training(debug=True)` to simulate the training process on a small data subset, followed by a custom inference step that mimics `run_inference` (adapted to ensure it uses the checkpoints generated in the demo).
5.  **Output Validation**: We assert that the submission file is generated correctly and checks the integrity of the results.
