Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds, and configure the device (GPU).
2.  **Training Loop**: Implement a nested loop over the 5 folds and 3 architectures (ResNet18, EfficientNet-B0, DenseNet121).
    *   For each combination, load data using `get_dataloaders`.
    *   Initialize the model, optimizer (AdamW), and scheduler (CosineAnnealingLR).
    *   Train using the `Trainer` class, which handles Gradient Accumulation, Mixup, and Top-K checkpointing.
    *   Immediately after training, average the Top-3 checkpoints for that fold/architecture.
    *   Perform inference on the validation set using the averaged model to collect Out-Of-Fold (OOF) predictions.
3.  **Validation & Metric**: Aggregate the OOF predictions across all architectures and folds. Compute the macro-averaged ROC-AUC score on the entire labeled dataset (Train + Val combined) to serve as the "Final Validation Metric".
4.  **Failure Analysis**: Calculate the Mean Absolute Error (MAE) for each sample. Extract audio features (Energy, Std Dev) from the source WAV files and compute their Pearson correlation with the prediction error to identify systematic failure modes.
5.  **Submission**: Compare the final validation metric against the threshold (0.9479806884980326). If the threshold is exceeded, instantiate the `InferenceEngine` to generate the final submission file using the ensemble of 15 models with Test-Time Augmentation.
