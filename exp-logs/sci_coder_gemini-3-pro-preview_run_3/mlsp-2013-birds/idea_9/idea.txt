# Optimized Strategy: Multi-Instance ResNet-18 on Domain-Curated Spectrograms

### Model
The solution will implement a **Multi-Instance Learning (MIL)** framework using a **ResNet-18** backbone. This architecture resolves the tension between the need for temporal resolution and the constraint of using standard pre-trained input dimensions, while avoiding the pitfalls of custom learnable pooling layers.
- **Backbone:** Use **ResNet-18** (pretrained on ImageNet). This model offers the optimal balance of capacity and generalization for this micro-dataset (**Cite solution_lesson_node_00003**).
- **Multi-Instance Aggregation:** Instead of resizing the entire 10-second spectrogram into a single 224x224 image (which distorts temporal patterns), the model will treat each recording as a "bag" of **3 overlapping temporal tiles**.
    - Each tile is processed independently by the shared ResNet-18 backbone to produce logits.
    - A **Max-Pooling** operation aggregates the logits across the 3 tiles. This ensures that if a bird is detected with high confidence in *any* segment, the recording is labeled positive. This preserves local temporal context (**Cite solution_lesson_node_00001**) without adding any learnable parameters, avoiding the overfitting observed with Attention Pooling (**Cite solution_lesson_node_00019**).
- **Input Adaptation:** Strictly adhere to the "3-Channel Rule" by replicating the single-channel spectrogram 3 times to form a pseudo-RGB image. This preserves the pre-trained weights' integrity (**Cite solution_lesson_node_00014**).

### Data
The pipeline fundamentally pivots back to using the **Provided Spectrograms** (`supplemental_data/spectrograms`) instead of generating them from raw audio.
- **Source Selection:** Use the provided BMP spectrograms. **Cite solution_lesson_node_00028** demonstrated that generating Log-Mel spectrograms from raw audio failed to match the performance of the provided BMPs, which likely contain domain-specific contrast enhancements.
- **Preprocessing & Tiling:**
    1.  Load the provided BMP image.
    2.  **Time Shifting:** Apply random **Horizontal Translation** (rolling) to the full BMP *before* tiling to simulate temporal variability (**Cite solution_lesson_node_00007**).
    3.  **Tiling:** Resize the image height to 224 pixels (preserving aspect ratio if possible, or resizing width proportionally) and extract 3 overlapping square crops (224x224) along the time axis.
- **Augmentation:**
    1.  **Photometric Augmentation:** Apply **Brightness and Contrast Jitter** to the tiles. This mimics variations in recording gain and SNR, which is critical for robustness (**Cite solution_lesson_node_00009**).
    2.  **Mixup:** Apply **Mixup Regularization** at the bag level (interpolating tiles and labels) to prevent overfitting (**Cite solution_lesson_node_00007**).
    3.  **Constraint:** Strictly **disable Horizontal Flipping** (**Cite solution_lesson_node_00006**).

### Training
- **Splitting Strategy:** Implement **Iterative Stratification** (5 Folds). This is mandatory to ensure that rare species (appearing <5 times) are distributed representatively across all folds, preventing training collapse (**Cite solution_lesson_node_00017**).
- **Loss Function:** Use **BCEWithLogitsLoss** applied to the max-pooled bag logits.
- **Optimizer & Schedule:** Use **AdamW** with a **Monotonic Cosine Annealing** scheduler (decaying over the full epoch count without restarts). We avoid cyclic restarts to ensure the model converges stably on this data-scarce task (**Cite solution_lesson_node_00022**).

### Evaluation
- **Ensemble Inference:** Train 5 independent models (one for each fold of the Iterative Stratification).
- **Process:** For each test recording, generate the 3 fixed tiles, pass them through each of the 5 models, apply max-pooling to obtain bag probabilities, and then **average the probabilities across the 5 models**. This ensemble approach minimizes the variance inherent in small-data learning.
