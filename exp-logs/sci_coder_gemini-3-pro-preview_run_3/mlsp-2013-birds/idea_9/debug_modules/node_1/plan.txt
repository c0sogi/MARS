The existing code only catches `ValueError`, so the `nan` value bypasses the fallback logic and propagates to the assertion in `runfile.py`, causing the crash.

1.  Explicitly check if the initial `roc_auc_score` is `nan` and raise a `ValueError` to trigger the robust per-class fallback calculation.
2.  Sanitize the final return value to ensure it is never `nan` (returning 0.5 as a default) and convert it to a native Python float to prevent potential serialization issues.
