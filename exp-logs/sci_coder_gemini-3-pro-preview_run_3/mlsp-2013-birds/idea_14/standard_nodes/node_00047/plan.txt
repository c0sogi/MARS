The strategy involves implementing a robust heterogeneous ensemble pipeline. We will train 30 distinct models, derived from the combination of 3 backbone architectures (ResNet18, EfficientNet-B0, DenseNet121), 2 data sources (Standard and Filtered Spectrograms), and 5 cross-validation folds. The training process utilizes the provided `run_fold` function, which handles training loops, Mixup augmentation, and EMA (Exponential Moving Average) updates.

For inference, we will perform a two-stage process. First, we generate Out-Of-Fold (OOF) predictions by evaluating each model on its specific validation fold. These OOF predictions are aggregated to compute a reliable "Final Validation Metric" (ROC AUC) across the entire dataset, avoiding data leakage. Second, we generate predictions for the test set using the full ensemble of 30 models.

Finally, we perform failure analysis by correlating the prediction error (MAE) with the number of bird species present in each recording to understand if complexity drives error. If the validation metric exceeds the specified threshold, we format and save the test predictions to `submission.csv`.
