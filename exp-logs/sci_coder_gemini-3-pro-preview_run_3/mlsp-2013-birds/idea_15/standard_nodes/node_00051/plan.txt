### Implementation Strategy

1.  **Setup & Configuration**: Initialize the environment using the provided `Config` class, setting random seeds for reproducibility. Adjust `Config.EPOCHS` to 30 to ensure the pipeline completes within the time limit while allowing sufficient convergence for the small dataset.
2.  **Data Loading**: Load the training (`train.csv`) and hold-out validation (`val.csv`) metadata. Use `preprocess_and_cache_images` to load and cache all spectrograms into memory for fast access.
3.  **Cross-Validation**: Implement 5-fold cross-validation on the training set (`train.csv`). Use `IterativeStratification` (from `scikit-multilearn`) to preserve the multi-label distribution across folds. Fallback to `KFold` if stratification fails due to rare classes.
4.  **Ensemble Training**:
    - Iterate through each of the 5 folds.
    - Inside each fold, iterate through the 3 backbone architectures (`resnet18`, `efficientnet_b0`, `densenet121`).
    - Train each model using the `train_fold` function, which handles the optimizer, scheduler, and EMA (Exponential Moving Average) updates.
    - Save the best checkpoint for each of the 15 models (3 backbones $\times$ 5 folds).
5.  **Validation & Inference**:
    - Load the 15 trained model checkpoints.
    - Perform inference on the unseen hold-out validation set (`val.csv`) using the ensemble (averaging probabilities).
    - Compute and print the **Final Validation Metric** (Area Under ROC Curve).
6.  **Failure Analysis**: Calculate the correlation between the model's error magnitude (Mean Absolute Error) and the input signal intensity (mean pixel value) on the validation set to identify potential biases.
7.  **Submission**: If the validation metric exceeds the specified threshold (`0.94798`), generate predictions for the test set (`test.csv`) using the full ensemble, format the output as required (`Id` = `rec_id * 100 + species`), and save to `submission.csv`.
