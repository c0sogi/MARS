# Optimized Strategy: Multi-Modal Hybrid Ensemble (Deep Texture + Symbolic Clusters)

### Model
The solution will implement a **Multi-Modal Hybrid Ensemble** that fuses two distinct modeling paradigms. This approach addresses the "Diversity of Errors" principle (**Cite solution_lesson_node_00043**) by combining the global time-frequency texture analysis of deep CNNs with the robust, local cluster-frequency analysis of a shallow MLP, explicitly leveraging the success of Bag-of-Words features on this micro-dataset (**Cite solution_lesson_node_00008**).

1.  **Deep Learning Stream (Texture Analysis):** A **Heterogeneous Ensemble** of three distinct CNN architectures: **ResNet-18**, **EfficientNet-B0**, and **DenseNet-121**.
    *   **Input Adaptation:** Strictly adhere to the **3-Channel Rule** by replicating the single-channel spectrograms 3 times to form pseudo-RGB images, preserving pre-trained weights (**Cite solution_lesson_node_00014**).
    *   **Head Design:** Use native classification heads to avoid the overfitting caused by complex custom heads (**Cite solution_lesson_node_00053**, **Cite solution_lesson_node_00051**).
2.  **Symbolic Learning Stream (Cluster Analysis):** A **Shallow Multi-Layer Perceptron (MLP)**.
    *   **Input:** The 100-dimensional Bag-of-Audio-Words features (`histogram_of_segments.txt`).
    *   **Architecture:** A lightweight topology (e.g., Linear(100, 64) $\to$ ReLU $\to$ Dropout $\to$ Linear(64, 19)) to prevent overfitting.
3.  **Fusion:** The final prediction will be a weighted average of the Deep Stream and the Symbolic Stream.

### Data
The pipeline will utilize two distinct data sources, prioritizing domain-curated features and rigid spatial adherence.

*   **Stream A (CNNs):**
    *   **Source:** Strictly use the **Provided Standard Spectrograms** (`supplemental_data/spectrograms`). Explicitly exclude "Filtered Spectrograms" to avoid signal loss (**Cite solution_lesson_node_00048**) and avoid raw audio generation (**Cite solution_lesson_node_00028**).
    *   **Preprocessing:** Resize all spectrograms to **224x224**. This rigid adherence to the pre-trained model's spatial expectations is superior to tiling or custom aspect ratios for this micro-dataset (**Cite solution_lesson_node_00030**).
    *   **Augmentation:**
        1.  **Safe-Zone Horizontal Translation:** Apply time-shifting using **Zero-Padding** (**Cite solution_lesson_node_00033**) limited to **<10%** of the image width to prevent moving short bird calls out of the frame (**Cite solution_lesson_node_00071**).
        2.  **Photometric Augmentation:** Apply **Brightness and Contrast Jitter** to mimic Gain and SNR variations (**Cite solution_lesson_node_00009**).
        3.  **Calibrated Mixup:** Apply **Mixup Regularization** with **alpha = 0.4** to bias synthetic samples closer to the ground truth (**Cite solution_lesson_node_00064**).
        4.  **Constraint:** Strictly **disable Horizontal Flipping** (**Cite solution_lesson_node_00006**).

*   **Stream B (MLP):**
    *   **Source:** `supplemental_data/histogram_of_segments.txt`.
    *   **Augmentation:** Apply **Feature Noise** (adding small Gaussian noise) and **Manifold Mixup (alpha=0.4)** directly to the feature vectors to improve decision boundary smoothness (**Cite solution_lesson_node_00007**).

### Training
*   **Splitting Strategy:** Implement **Iterative Stratified K-Fold** (5 Folds). Crucially, ensure the splitting logic is **dynamic** (physically separating dataframes per fold) to prevent the "static split" error that leads to model cloning (**Cite solution_lesson_node_00063**).
*   **Optimization (CNNs):**
    *   **Optimizer:** **AdamW** with **High Weight Decay** (`1e-2`) to strictly control model complexity (**Cite solution_lesson_node_00052**).
    *   **Scheduler:** **Monotonic Cosine Annealing** (**Cite solution_lesson_node_00022**). Avoid Layer-Wise Learning Rate Decay (**Cite solution_lesson_node_00073**).
    *   **Batch Size:** Maintain physical batch size of **32** (**Cite solution_lesson_node_00054**).
    *   **Early Stopping:** Use **Aggressive Patience** (15 epochs) to prevent overfitting the validation folds (**Cite solution_lesson_node_00060**).
*   **Optimization (MLP):** Standard Adam optimizer with Dropout regularization.
*   **Loss Function:** **BCEWithLogitsLoss** for all models. Avoid specialized imbalance losses like ASL (**Cite solution_lesson_node_00034**).
*   **Validation:** Use a **Robust Metric Implementation** that explicitly handles missing classes in validation batches to prevent premature stopping (**Cite solution_lesson_node_00038**).

### Evaluation
*   **Snapshot Prediction Averaging:** For the CNN stream, save the **Top-3 Best Checkpoints** (based on validation AUC) for each fold. Generate predictions using all 3 checkpoints and average them. This mitigates the volatility of single-epoch selection (**Cite solution_lesson_node_00043**) without the risks of weight-space averaging (**Cite solution_lesson_node_00057**).
*   **No TTA:** Strictly avoid Test-Time Augmentation with padding/shifting, as it introduces artifacts that degrade performance (**Cite solution_lesson_node_00074**).
*   **Final Inference:** Average the probability outputs of the CNN Ensemble (15 models $\times$ 3 snapshots) and the MLP Ensemble (5 models).
