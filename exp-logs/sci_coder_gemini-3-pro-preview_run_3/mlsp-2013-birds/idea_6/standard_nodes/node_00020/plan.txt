The implementation strategy follows the optimized plan using a ResNet-18 backbone with Spatial Pyramid Pooling (SPP) and Iterative Stratification.

1.  **Setup & Configuration**: The script initializes the environment using the provided `Config` class and sets random seeds for reproducibility.
2.  **5-Fold Cross-Validation Training**:
    *   The script iterates through 5 folds using `get_dataloaders` which handles the iterative stratification and caching.
    *   For each fold, a `BirdResNetSPP` model is instantiated and trained using the `Trainer` class. The training includes Mixup augmentation, AdamW optimizer, Cosine Annealing scheduler, and Early Stopping.
    *   After training each fold, the best model is used to generate predictions for the validation fold. These are stored as Out-Of-Fold (OOF) predictions to ensure a non-leaky evaluation.
3.  **Validation Assessment**:
    *   The script loads the specific hold-out validation metadata (`val.csv`).
    *   It retrieves the OOF predictions corresponding to the `rec_id`s in `val.csv`. This provides a rigorous validation metric on the requested hold-out set without data leakage.
    *   The Area Under the ROC Curve (AUC) is computed and printed as the "Final Validation Metric".
4.  **Failure Analysis**:
    *   The script calculates the Binary Cross Entropy loss for each sample in the validation set.
    *   It computes and prints the correlation between this error and the number of labels (species count), identifying if the model struggles with complex, multi-species recordings.
5.  **Submission**:
    *   If the validation metric exceeds the specified threshold, the script proceeds to inference.
    *   It performs ensemble inference on the test set by averaging predictions from all 5 trained models.
    *   The results are formatted according to the submission requirements (`Id` = `rec_id * 100 + species`) and saved to `submission.csv`.
