# Optimized Strategy: ResNet-34 with Attention-Based Pooling (Weakly Supervised SED)

### Model
The solution will evolve from a standard image classification architecture to a **Weakly Supervised Sound Event Detection (SED)** framework.
- **Backbone:** Upgrade the backbone to **ResNet-34** (pretrained on ImageNet). This offers a deeper feature extraction capability than the previous ResNet-18 while maintaining a manageable parameter count for the small dataset.
- **Input Adaptation:** Strictly adhere to the "3-Channel Rule" for transfer learning. The model will accept 3-channel inputs by **replicating the single-channel Log-Mel spectrogram three times**. This ensures the pretrained filters are utilized effectively without the destructive re-initialization caused by modifying the first layer (Cite solution_lesson_node_00014).
- **Structural Innovation (Attention Pooling):** Replace the standard Global Average Pooling (GAP) layer with a **Learnable Attention Pooling** mechanism.
    - *Rationale:* Bird calls are intermittent and sparse within a 10-second clip. GAP dilutes the signal of a short call by averaging it with seconds of background silence (Cite solution_lesson_node_00001). Attention pooling allows the model to learn a weighting map, assigning high importance to time frames containing bird calls and suppressing silence/noise before aggregation. This effectively preserves the temporal context required to disentangle overlapping sounds.

### Data
The pipeline will process raw audio into spectral representations with domain-specific augmentations.
- **Preprocessing:** Generate **Log-Mel Spectrograms** from the raw WAV files (e.g., 128 Mel bins).
- **Augmentation Pipeline:**
    1.  **Photometric Augmentation:** Apply **Brightness and Contrast Jitter** to the spectrograms. This mathematically simulates variations in recording gain (volume) and Signal-to-Noise Ratio (SNR), improving robustness to environmental diversity (Cite solution_lesson_node_00009).
    2.  **Time Shifting:** Apply random **Horizontal Translation** (rolling the spectrogram along the time axis) to simulate temporal variability (Cite solution_lesson_node_00007).
    3.  **Mixup:** Apply **Mixup Regularization** (linear interpolation of images and labels) to smooth decision boundaries and prevent overfitting on the sparse data (Cite solution_lesson_node_00007).
    4.  **Constraint:** Strictly **disable Horizontal Flipping**, as this reverses the time axis and distorts the semantic structure of bird calls (Cite solution_lesson_node_00006).

### Training
- **Loss Function:** Use **BCEWithLogitsLoss** (Binary Cross Entropy) for multi-label classification.
- **Optimizer:** Use **AdamW** with a **Cosine Annealing** learning rate scheduler to ensure convergence to a flat minimum.
- **Cross-Validation:** Implement **Stratified 5-Fold Cross-Validation**. Given the small dataset size (206 samples), training on a single split is unreliable. We will train 5 independent models to maximize data utilization and stability.

### Evaluation
- **Ensemble Inference:** Pass the test set spectrograms through all 5 trained fold models.
- **Aggregation:** Average the probability outputs from the 5 models. This ensemble approach reduces the variance associated with the small training set and provides a robust final prediction.
