Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment with fixed random seeds. Override the default epoch count to 20 to ensure the pipeline completes within the 2-hour limit while maintaining sufficient convergence for the small dataset.
2.  **Data Loading**: Load the pre-processed metadata and features using the provided library functions. This includes the combined training/validation set (with fold assignments), the test set, and the Bag-of-Audio-Words features.
3.  **Ensemble Training (5-Fold CV)**: Iterate through 5 cross-validation folds. Within each fold, train a heterogeneous ensemble consisting of:
    *   **MLP Stream**: A lightweight Multi-Layer Perceptron trained on histogram features.
    *   **CNN Stream**: Three distinct architectures (ResNet18, EfficientNet-B0, DenseNet121) trained on spectrograms.
    *   **Optimization**: Use AdamW with Cosine Annealing and early stopping. Save the top-3 best checkpoints for each model to stabilize predictions (Snapshot Ensemble).
4.  **Inference**:
    *   **OOF Predictions**: Generate Out-Of-Fold predictions for the validation subset of each fold to construct an unbiased estimate for the entire training dataset.
    *   **Test Predictions**: Generate predictions for the test set by averaging outputs from all models across all folds (Bagging).
5.  **Validation & Analysis**:
    *   Extract the OOF predictions corresponding strictly to the samples in the original hold-out `val.csv` file.
    *   Compute the robust Area Under the ROC Curve (AUC) metric.
    *   Perform failure analysis by correlating prediction error (BCE) with the number of labels per sample.
6.  **Submission**: If the validation AUC exceeds the threshold (0.9479), generate and save the `submission.csv` file in the required format.
