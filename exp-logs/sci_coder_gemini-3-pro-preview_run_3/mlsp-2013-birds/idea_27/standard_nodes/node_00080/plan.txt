The error is caused by saving a NumPy scalar (specifically the AUC score) directly into the PyTorch checkpoint dictionary. Newer versions of PyTorch default to `weights_only=True` during loading, which restricts unpickling to a safe allowlist that excludes NumPy types like `numpy.float64`. To fix this, I will explicitly cast the metric score to a native Python `float` before saving it to the checkpoint state, ensuring compatibility with the default security settings (Cite debug_lesson_10).
