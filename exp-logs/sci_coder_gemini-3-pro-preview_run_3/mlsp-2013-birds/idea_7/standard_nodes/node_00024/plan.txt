The issue is that the `roc_auc_score` function with `average='macro'` fails (returns `nan` or raises an error) when specific classes are missing from the ground truth labels in the validation set, which occurs due to the extreme class imbalance and small dataset size. This `nan` value causes the training loop to stop early and prevents the final submission generation. To fix this, I will implement a robust AUC calculation in `library/trainer.py` and `runfile.py` that computes the score per class, ignoring classes with no positive samples, and then averages the valid scores. I will also update `runfile.py` to generate a submission file regardless of the metric threshold. Cite debug_lesson_4.
