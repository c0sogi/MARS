Implementation Strategy:
1.  **Setup and Configuration**: Import the provided library modules. Override `Config` parameters to enable debug mode, reduce the number of epochs to 1, set a small batch size, and disable multiprocessing. This ensures the script runs quickly within the time limit.
2.  **Data Processing**: Call `get_dataloaders` with `load_cached_data=False`. This triggers the `load_or_generate_data` function, which processes the raw audio files into spectrograms and saves them to the cache. We then assert the shapes of the generated batches (inputs and targets) to verify the Multi-Instance Learning (MIL) tiling logic.
3.  **Model Verification**: Instantiate the `MILResNet18` model. Perform a forward pass with a batch from the training loader to verify that the model accepts the 5D input tensor `(Batch, Tiles, Channels, Height, Width)` and outputs the correct shape `(Batch, Num_Classes)`.
4.  **Training Loop**: Execute `run_fold(0)` to run a complete training and validation cycle for the first fold. This utilizes the `trainer.py` module, which handles the optimization loop, mixup augmentation, and checkpoint saving.
5.  **Inference and Submission**: Load the best model checkpoint saved during the training step. Iterate through the `test_loader` to generate probability predictions. Format these predictions into the required submission structure (`Id` calculated as `rec_id * 100 + species_id`) and save the result to a CSV file.
