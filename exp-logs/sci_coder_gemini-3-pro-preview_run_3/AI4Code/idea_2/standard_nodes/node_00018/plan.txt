The issue is that the execution pipeline in `runfile.py` generates raw embeddings using `EmbeddingGenerator` but fails to convert them into the tabular features required by the LightGBM model. The `ModelTrainer` attempts to load `train_tabular.parquet`, but this file is never created because `RegressionFeatureGenerator` is not called. To fix this, I will update `runfile.py` to import `RegressionFeatureGenerator` and execute its `process_split` method for both the training and validation sets immediately after the embedding generation step. This ensures the necessary data dependencies are met before the training phase begins (Cite debug_lesson_4).
