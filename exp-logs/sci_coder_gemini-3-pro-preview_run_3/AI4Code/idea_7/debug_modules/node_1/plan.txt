The issue is that `runfile.py` configures `Config.FINE_TUNED_MODEL_PATH` as a file path ending in `.pth`, but the `library/fine_tuning.py` script treats this path as a directory (calling `os.makedirs`) because `SentenceTransformer` saves multiple artifacts (config, model weights, tokenizer) into a folder, not a single file. The presence of an existing file named `dsapr_model.pth` at that location causes `os.makedirs` to raise a `FileExistsError`.

To fix this, I will update `runfile.py` to point `Config.FINE_TUNED_MODEL_PATH` to a directory name (e.g., removing the `.pth` extension). This ensures `os.makedirs` creates a directory as intended and avoids conflict with the existing file.
