The following script demonstrates the end-to-end pipeline using the provided library classes. It performs the following steps:
1.  **Configuration**: Overrides default `Config` settings to enable debug mode and redirect outputs to a specific working directory (`./working/demo_run`) to ensure a clean, fast execution.
2.  **Semantic Model Training**: Initializes the `FineTuner`, prepares training pairs from a small subset of the data, and runs a minimal fine-tuning session (1 epoch) on the `sentence-transformers` backbone.
3.  **Feature Engineering**: Uses the `generate_features` function (which utilizes `FeatureExtractor`) to create semantic features for both training and validation sets using the fine-tuned model.
4.  **Ranker Training**: Instantiates the `LGBMRanker` and trains it using the generated features.
5.  **Inference & Evaluation**: Runs predictions on the validation set, reconstructs the cell order using `reconstruct_order`, and verifies the result using the `calc_kendall_tau` metric.
