Based on the accumulated lessons, I propose the **Bidirectional Contextualized Regressor (BCR)**. This solution structurally evolves the "High-Capacity Smoothed Semantic Regressor" (Idea 8) by fundamentally altering the fine-tuning objective to capture the full topological context (preceding and succeeding code) and integrating the "Structural Heatmap" concept (Idea 11) to resolve global positioning patterns.

# Model
The architecture employs a two-stage pipeline designed to maximize semantic resolution and spatial awareness:

1.  **Semantic Backbone (High-Capacity):**
    *   **Architecture:** `sentence-transformers/all-mpnet-base-v2`.
    *   **Rationale:** I retain the MPNet backbone, which offers superior semantic resolution for abstract markdown compared to smaller models like MiniLM (Cite solution_lesson_node_00030). I strictly avoid dual-backbone ensembles to prevent the data starvation caused by complexity penalties (Cite solution_lesson_node_00028).

2.  **Feature Extractor (Bidirectional & Structural):**
    *   **Smoothed Similarity:** Apply **1D Convolutional Smoothing** (window size=3) to the pairwise cosine similarity vector to suppress noise and identify dense alignment regions (Cite solution_lesson_node_00030).
    *   **Spatial Anchors:** Extract `best_match_loc` (index of max similarity) and `center_of_mass` (weighted average index) from the smoothed vector. These are the primary explicit alignment signals (Cite solution_lesson_node_00004).
    *   **Structural Heatmap:** Resample (interpolate) the smoothed similarity vector to a fixed length of 20 bins. Unlike scalar distributional statistics (which failed, Cite solution_lesson_node_00007), this feature preserves the **global spatial structure** of the alignment (e.g., distinguishing a markdown cell that matches the *start* of the notebook from one that matches the *end*) without distorting the aspect ratio.
    *   **Global Context:** Explicitly include `n_code` (total code cells) and `md_len` (markdown length) to allow the regressor to scale normalized predictions correctly (Cite solution_lesson_node_00015).

3.  **Regressor Head:**
    *   **Architecture:** **LightGBM Regressor**.
    *   **Rationale:** Tree-based models consistently outperform end-to-end Transformers when provided with explicit, spatially-grounded alignment features (Cite solution_lesson_node_00012).

# Data
**Preprocessing:**
1.  **Fine-Tuning Dataset (Bidirectional Relaxed Proximity):**
    *   **Innovation:** Previous iterations used a "Nearest Subsequent" heuristic (Cite solution_lesson_node_00027), training the model only to predict the *next* code cell. I propose a **Bidirectional** strategy: for every markdown cell $M$, create **two** positive training pairs where possible:
        1.  $(M, C_{prev})$: The nearest *preceding* code cell.
        2.  $(M, C_{next})$: The nearest *subsequent* code cell.
    *   **Rationale:** Markdown cells often summarize the *output* of a previous block or introduce the *logic* of the next. Training on both directions forces the embedding space to place the markdown cell topologically *between* its neighbors, sharpening the "Center of Mass" signal.
    *   **Volume:** Construct pairs from **40,000 notebooks**. This ensures high data volume for the MPNet backbone (Cite solution_lesson_node_00028) while staying within the 24-hour limit.

2.  **Regression Dataset (Full Volume):**
    *   Utilize the **Full Training Dataset** (~95,000 notebooks) for the LightGBM stage.
    *   **Rationale:** The regressor requires the maximum possible data volume to resolve the complex interactions between the high-dimensional heatmap features and the target position (Cite solution_lesson_node_00009).

# Training
1.  **Stage 1: Contrastive Fine-Tuning**
    *   **Objective:** Optimize **Multiple Negatives Ranking Loss (MNRL)**.
    *   **Procedure:** Train the `all-mpnet-base-v2` backbone for 1 epoch on the Bidirectional dataset. This aligns the vector space such that markdown cells are semantically similar to their entire local code context (Cite solution_lesson_node_00025).

2.  **Stage 2: Regression Training**
    *   **Objective:** Minimize **Mean Squared Error (MSE)**.
    *   **Procedure:** Train LightGBM to predict the normalized rank $y \in [0, 1]$ using the concatenated feature vector (Anchors + Heatmap + Context).

# Evaluation
1.  **Inference:**
    *   Encode all test set cells using the fine-tuned MPNet backbone.
    *   Compute the Pairwise Cosine Similarity Matrix for each notebook.
    *   **Feature Extraction:**
        *   Apply **1D Smoothing** to the similarity vector.
        *   Extract `best_match_loc`, `center_of_mass`, `sim_max`.
        *   Interpolate the smoothed vector to 20 bins to generate the `structural_heatmap`.
        *   Append `n_code` and `md_len`.
    *   Predict normalized position $\hat{y}$ using LightGBM.
2.  **Ordering:**
    *   Convert $\hat{y}$ to integer rank: $Rank_{pred} = \hat{y} \times n\_code$.
    *   Construct the sequence with Code cells at fixed indices ($0, 1, \dots$) and Markdown cells at $Rank_{pred}$.
    *   Sort the combined list to produce the final `cell_order`.
