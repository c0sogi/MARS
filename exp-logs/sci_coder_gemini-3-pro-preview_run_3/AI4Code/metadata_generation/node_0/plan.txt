This script generates metadata for the AI4Code dataset. It performs the following steps:

1.  **Setup**: Creates the `./metadata` directory and defines paths for input files.
2.  **Data Loading**: Reads `train_orders.csv` and `train_ancestors.csv`. It merges these dataframes to associate each notebook with its `ancestor_id`, which is crucial for grouping during the train/validation split to prevent data leakage (since notebooks with the same ancestor are versions of each other). It also reads `sample_submission.csv` to identify test set IDs.
3.  **Preprocessing**: Fills missing `ancestor_id`s with the notebook's own `id` (assuming isolated notebooks are their own ancestors). It constructs relative file paths for all notebooks (e.g., `train/{id}.json`).
4.  **Splitting**: Uses `GroupShuffleSplit` with `ancestor_id` as the group to split the training data into an 80% training set and a 20% validation set. This ensures that all versions of a specific notebook lineage remain in the same split.
5.  **Saving**: Saves the resulting dataframes as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
6.  **Validation**:
    - Loads the generated metadata files.
    - Prints summary statistics (count, unique ancestors, class distribution proxy).
    - Verifies that the validation split does not share any `ancestor_id` with the training split.
    - Checks a random sample of 1000 file paths from each set to ensure the files actually exist in the `./input` directory, raising an error if more than 50% are missing.
