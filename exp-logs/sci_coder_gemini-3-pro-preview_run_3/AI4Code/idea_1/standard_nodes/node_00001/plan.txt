Implementation strategy:
1.  **Setup and Configuration**: Initialize the environment and set random seeds for reproducibility. Import necessary modules from the provided `library` package.
2.  **Data Loading**: Load the training, validation, and test metadata using `library.data_loader.load_metadata`. To ensure the script completes within the time limit (acting as a fast baseline), we will sample a subset of the training data (e.g., 20,000 notebooks) while using the full validation set for accurate metric calculation.
3.  **Model Training**: Initialize the `PositionRegressor` from `library.model`. Train the model using the sampled training data and the validation data. The model handles feature extraction (TF-IDF, cosine similarity) and LightGBM training internally.
4.  **Validation & Metric Calculation**:
    *   Generate relative position predictions for the validation set using `model.predict`.
    *   Implement a helper function `reconstruct_orders` (mirroring the logic in `generate_submission`) to convert continuous position scores into ordered lists of cell IDs.
    *   Compute the Kendall Tau correlation using `library.utils.compute_kendall_tau` and print the `Final Validation Metric`.
5.  **Failure Analysis**:
    *   Retrieve the validation feature set (which includes ground truth targets) using the feature extractor.
    *   Merge predictions with targets to calculate the absolute error for each markdown cell.
    *   Compute and print the correlation between the error and key features (e.g., `sim_mean`, `md_len`, `n_code`) to identify sources of model inaccuracy.
6.  **Submission Generation**: Generate the final submission file for the test set using `model.generate_submission`, which saves the result to `./submission/submission.csv`.
