This script demonstrates the end-to-end pipeline of the Distribution-Aware Semantic Regressor (DASR) solution. It performs the following steps:
1.  **Setup**: Creates a lightweight demonstration environment by sampling a small subset of the metadata (50 training, 20 validation, 20 test notebooks) and overriding configuration parameters for speed (e.g., 1 epoch, small batch sizes).
2.  **Fine-Tuning**: Uses `FineTuner` and `RelaxedProximityDataset` to fine-tune the SentenceTransformer backbone on the sampled training data using contrastive learning.
3.  **Feature Extraction**: Uses `FeatureEngineer` to generate semantic and structural features (e.g., global heatmaps, local anchors) from the notebooks using the fine-tuned model.
4.  **Regression**: Trains the `RankRegressor` (LightGBM) on the extracted features to predict the relative position of markdown cells.
5.  **Inference**: Uses `Predictor` and `generate_submission` to predict cell orders for the test set and create a submission file.
6.  **Validation**: Verifies the logic using assertions at each step and calculates the Kendall Tau metric on the validation set to ensure the scoring function works correctly.
