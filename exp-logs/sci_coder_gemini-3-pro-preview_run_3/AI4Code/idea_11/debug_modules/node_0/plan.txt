The following code demonstrates the usage of the provided library components for the Google AI4Code task.

**Implementation Strategy:**
1.  **Configuration Override:** We modify the global `Config` class to point to a temporary working directory (`./working/demo_run`) and drastically reduce hyperparameters (1 epoch, 10 boosting rounds, small sample sizes) to ensure the script executes within minutes.
2.  **Data Subsetting:** We load the provided metadata files, sample a small subset (20 notebooks each for train/val/test), and save these as "demo" metadata files. We then point `Config` paths to these subsets. This ensures the heavy data loading and processing steps run quickly.
3.  **Component Verification:**
    *   **Utils:** We validate the `read_notebook` function and the `kendall_tau` metric with a known synthetic example.
    *   **Backbone:** We instantiate `BackboneTrainer` and run a fine-tuning cycle on the small dataset. We verify that the model saves correctly.
    *   **Feature Engineering:** We use `FeatureEngineer` to extract features from the demo notebooks, asserting that the resulting DataFrames contain the expected structural similarity features.
    *   **Ranker:** We train the `LGBMRanker` (LightGBM) on the extracted features and verify the model file generation.
    *   **Inference:** We run the `InferencePipeline` to generate a submission file and calculate a validation score, ensuring the end-to-end flow works.
