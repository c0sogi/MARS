# Solution: Multi-Scale Structural Heatmap Regressor (MS-SHR)

### Model
I propose a **Multi-Scale Hybrid Architecture** that evolves the "Smoothed Semantic Regressor" by introducing a **Structural Heatmap** and **Multi-Scale Processing**. This design addresses the limitation of scalar point-estimates (like `argmax`) which discard the global shape of the alignment distribution, while strictly adhering to the "Spatial Location" priority and "Data Volume" requirements identified in the lessons.

1.  **High-Capacity Semantic Backbone:**
    *   **Architecture:** `sentence-transformers/all-mpnet-base-v2`.
    *   **Rationale:** I retain the MPNet backbone as it offers superior semantic resolution for abstract markdown compared to smaller models, provided it is fed sufficient data. Cite solution_lesson_node_00030. I explicitly reject the dual-backbone approach (e.g., adding CodeBERT) to avoid the complexity penalty that forces dataset reduction. Cite solution_lesson_node_00028.

2.  **Multi-Scale & Heatmap Feature Engineering:**
    *   **Multi-Scale Smoothing:** Instead of a single smoothing kernel, I apply **1D Convolutional Smoothing** with three distinct window sizes ($k=1, 3, 5$) to the pairwise cosine similarity vector. This captures alignment signals at the atomic (line), block (function), and module (chunk) levels. Cite solution_lesson_node_00030.
    *   **Spatial Anchors:** From *each* of the three scales, extract **Spatial Alignment Features**: `best_match_loc` (index of max similarity) and `center_of_mass` (weighted average index). Cite solution_lesson_node_00004.
    *   **Structural Heatmap (Innovation):** I introduce a **Fixed-Dimension Interpolation** feature. The smoothed similarity vector (from the $k=3$ scale) is resampled to a fixed length of 20 bins. This creates a normalized "heatmap" vector that preserves the *spatial structure* of the alignment (e.g., distinguishing between a single sharp peak at the start vs. a broad plateau in the middle) without reducing it to a single scalar, allowing the regressor to learn complex positioning logic.
    *   **Global Context:** Explicitly include `n_code` (total code cells) and `md_len` (markdown length) to allow the regressor to correctly scale the normalized predictions. Cite solution_lesson_node_00015.

3.  **Regressor Head:**
    *   **Architecture:** **LightGBM Regressor**.
    *   **Rationale:** Tree-based models consistently outperform end-to-end Transformers when provided with explicit, spatially-grounded alignment features. Cite solution_lesson_node_00012.

### Data
**Preprocessing:**
1.  **Fine-Tuning Dataset (Relaxed Proximity):**
    *   Construct **Positive Pairs** $(M, C_{target})$ by pairing every markdown cell $M$ with its **nearest subsequent** code cell $C_{target}$ in the ground truth order.
    *   **Volume:** Scale the fine-tuning dataset to **40,000 notebooks** (approx. 40% of training data).
    *   **Rationale:** This strategy corrects the "Strict Adjacency" flaw (Cite solution_lesson_node_00027) and provides sufficient volume for the high-capacity MPNet backbone, balancing model size with the 24-hour compute limit (Cite solution_lesson_node_00030).
2.  **Regression Dataset (Full Volume):**
    *   Utilize the **Full Training Dataset** (~95,000 notebooks) for the LightGBM stage.
    *   **Rationale:** The regressor requires the maximum possible data volume to resolve the interactions between the high-dimensional heatmap features and the target position. Cite solution_lesson_node_00009.

### Training
1.  **Stage 1: Contrastive Fine-Tuning**
    *   **Objective:** Optimize **Multiple Negatives Ranking Loss (MNRL)**.
    *   **Procedure:** Train the `all-mpnet-base-v2` backbone for 1 epoch on the 40k notebook subset. This aligns the embedding space such that markdown cells are topologically close to the code blocks they describe. Cite solution_lesson_node_00025.

2.  **Stage 2: Regression Training**
    *   **Objective:** Minimize **Mean Squared Error (MSE)**.
    *   **Procedure:** Train LightGBM to predict the normalized rank $y \in [0, 1]$ using the concatenated feature vector (Multi-Scale Anchors + Structural Heatmap + Global Context).

### Evaluation
1.  **Inference:**
    *   Encode all test set cells using the fine-tuned MPNet backbone.
    *   Compute the Pairwise Cosine Similarity Matrix for each notebook.
    *   **Feature Extraction:**
        *   Apply Smoothing ($k=1, 3, 5$) -> Extract `best_match_loc`, `center_of_mass` for each scale.
        *   Apply Resampling ($N=20$) to the $k=3$ vector -> Extract `heatmap` vector.
        *   Append `n_code`, `md_len`.
    *   Predict normalized position $\hat{y}$ using LightGBM.
2.  **Ordering:**
    *   Convert $\hat{y}$ to integer rank: $Rank_{pred} = \hat{y} \times n\_code$.
    *   Construct the sequence with Code cells at fixed indices and Markdown cells at $Rank_{pred}$.
    *   Sort the combined list to produce the final `cell_order`.
