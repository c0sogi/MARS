1.  **Switch to Single-Fold Fixed Split Training**: I will abandon the 5-fold cross-validation strategy in favor of training a single model on the pre-defined training and validation splits (`train_metadata.csv` and `val_metadata.csv`). This avoids "recursive splitting" (reducing training data by 20%) and allows the model to fully converge on the maximum available data, which was identified as the superior strategy in **Cite solution_lesson_node_00024** and **Cite solution_lesson_node_00025**.
2.  **Remove Stride 1 Decoder Layers**: I will modify the `UNetPlusPlus` architecture to remove the "Level -1" decoder blocks (Stride 1). Instead, the model will predict logits at Stride 2 (Level 0) and bilinearly upsample them to the original resolution. This reduces model complexity and acts as a structural regularizer, preventing overfitting to high-frequency noise in the seismic data, as recommended in **Cite solution_lesson_node_00040**.
3.  **Update Configuration**: I will set `FOLDS = 1` and remove the unused channel dimension from `DECODER_CHANNELS` to reflect the architectural change.

def _load_fixed_data(phase):
    """
    Loads data for a specific phase (train/val) from metadata files.
    Cite solution_lesson_node_00025: Avoid Recursive Splitting.
    """
    if phase == "train":
        df = pd.read_csv(Config.TRAIN_METADATA)
    else:
        df = pd.read_csv(Config.VAL_METADATA)

    n_samples = len(df)
    images = np.zeros((n_samples, Config.ORIG_SIZE, Config.ORIG_SIZE), dtype=np.uint8)
    depths = np.zeros((n_samples,), dtype=np.float32)
    masks = np.zeros((n_samples, Config.ORIG_SIZE, Config.ORIG_SIZE), dtype=np.uint8)
    ids = df["id"].values

    for idx, row in df.iterrows():
        img_path = os.path.join(Config.INPUT_DIR, row["image_path"])
        img = cv2.imread(img_path, cv2.IMREAD_GRAYSCALE)
        images[idx] = img
        depths[idx] = row["z"] / 1000.0
        
        mask_path = os.path.join(Config.INPUT_DIR, row["mask_path"])
