2.  **Stage 1 (Supervised Training)**: Load the training metadata, split it into stratified folds, and train a model on Fold 0 using the original labeled data. Save the best checkpoint.
3.  **Pseudo-Label Generation**: Use the trained Stage 1 model to predict masks for the unlabelled test set. Convert these predictions into RLE format and construct a "pseudo-labeled" dataframe.
4.  **Stage 2 (Semi-Supervised Training)**: Concatenate the original labeled data (Fold 0 train) and the pseudo-labeled test data. Train a fresh model on this expanded dataset for 20 epochs.
5.  **Validation & Failure Analysis**: Evaluate the Stage 2 model on the hold-out validation set (Fold 0 val). Compute the final metric. Perform failure analysis by calculating the correlation between the Intersection over Union (IoU) scores and metadata features (Depth `z` and Salt Coverage).
6.  **Submission**: If the final validation metric exceeds the threshold of 0.827, generate the submission file using the Stage 2 model.
