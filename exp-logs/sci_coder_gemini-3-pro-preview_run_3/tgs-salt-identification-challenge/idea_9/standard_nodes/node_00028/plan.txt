Implementation strategy:
1.  **Configuration & Setup**: Initialize the environment and set random seeds for reproducibility. Override the default `TrainConfig` to reduce the number of epochs (from 80 to 10) and warmup epochs (to 5). This ensures the pipeline completes within the 2-hour "fast baseline" limit while still training on the full dataset.
2.  **Data Preparation**: Load the consolidated training data (images, masks, depths, coverage classes) using the provided library functions. Reconstruct the Stratified K-Fold splits to ensure we can align the Out-Of-Fold (OOF) predictions with their corresponding metadata (depth, salt coverage) for failure analysis.
3.  **Training Loop**: Iterate through all 5 folds. For each fold, execute the `train_fold` function to train the `SaltUNetPlusPlus` model. Save the path to the best checkpoint for each fold.
4.  **Evaluation & Optimization**:
    *   For each trained model, generate OOF predictions on its validation set using `Evaluator.predict_fold`.
    *   Aggregate predictions and targets from all folds.
    *   Perform a threshold sweep to find the binarization threshold that maximizes the Mean Average Precision (mAP) metric.
    *   Calculate and print the **Final Validation Metric** using this optimal threshold.
5.  **Failure Analysis**:
    *   Calculate the mAP score for each individual image in the validation set.
    *   Compute the correlation between the prediction error (1 - mAP) and the image metadata (Depth and Salt Coverage Class).
    *   Print these correlations to identify systematic weaknesses.
6.  **Submission**: Check if the Final Validation Metric exceeds the required threshold of 0.827. If successful, use the ensemble of all 5 models (with Test-Time Augmentation) to generate predictions for the test set and save the `submission.csv` file.
