To solve the task of segmenting salt in seismic images, I propose a highly efficient baseline approach using a **LinkNet architecture with a ResNet18 encoder**. This approach prioritizes inference speed and parameter efficiency while effectively utilizing the provided depth information.

### Model
The core architecture is **LinkNet**, a lightweight segmentation model designed specifically for efficiency.
*   **Encoder:** We utilize a **ResNet18** backbone. This is significantly lighter than the ResNet34 used in Model 1 and provides a robust feature extractor initialized with ImageNet weights.
*   **Decoder:** Unlike the U-Net (Model 1), which concatenates encoder features with decoder features, LinkNet uses **addition** for its skip connections. This design choice prevents the accumulation of feature map channels in the decoder, drastically reducing the parameter count and memory footprint, leading to faster training and inference.
*   **Depth Integration:** To utilize the scalar depth (`z`) variable without breaking the pretrained weight structure or requiring custom layer initialization, we construct a 3-channel input tensor for the model. The first two channels will contain the grayscale seismic image, and the third channel will contain a constant value map representing the normalized depth of that image. This allows the model to treat depth as a spatial feature channel, leveraging the pretrained filters to correlate local texture (seismic) with global context (depth) immediately.

### Data
1.  **Preprocessing:**
    *   **Padding:** The original 101x101 images will be padded to **128x128** using reflection padding. This ensures the spatial dimensions are compatible with the downsampling operations of the ResNet encoder (which typically requires dimensions divisible by 32).
    *   **Depth Normalization:** The depth values (ranging approx. 50-960) will be min-max scaled to the range [0, 1] to match the normalized pixel intensity distribution.
    *   **Input Construction:** For each sample, we create a (128, 128, 3) input volume where:
        *   Channel 0: Normalized Seismic Image.
        *   Channel 1: Normalized Seismic Image (duplicated).
        *   Channel 2: Normalized Depth value (expanded to a constant 128x128 mask).
2.  **Augmentation:** To maintain the "baseline" philosophy, we apply only minimal augmentations: horizontal flipping and slight brightness/contrast jitter.

### Training
*   **Loss Function:** We will use a combined **Binary Cross Entropy (BCE) + Dice Loss**. BCE provides smooth gradients for pixel-wise classification, while Dice Loss directly optimizes the overlap metric, handling the class imbalance (salt vs. sediment) effectively.
*   **Optimizer:** The **AdamW** optimizer will be used for its efficient handling of weight decay and convergence speed.
*   **Scheduler:** A Cosine Annealing learning rate scheduler will be employed to gradually reduce the learning rate, helping the model settle into a robust minimum without manual tuning.
*   **Procedure:** The model will be trained for a fixed number of epochs (e.g., 30-50) with early stopping based on the validation Dice score.

### Evaluation
1.  **Inference:** The model will predict masks for the 128x128 padded inputs.
2.  **Post-processing:** The output masks will be center-cropped back to the original **101x101** dimensions.
3.  **Threshold Optimization:** Since the metric evaluates Mean Average Precision over a range of IoU thresholds (0.5 - 0.95), we will perform a search on the validation set to find the single optimal probability threshold (e.g., 0.45 vs 0.5) that maximizes the competition metric.
4.  **Submission:** The final binary masks will be converted to the required Run-Length Encoding (RLE) format for submission.
