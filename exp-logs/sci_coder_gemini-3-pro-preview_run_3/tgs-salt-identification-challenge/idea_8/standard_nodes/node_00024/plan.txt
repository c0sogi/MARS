Implementation strategy:
1.  **Configuration & Setup**: Override the default configuration to ensure the pipeline fits within the time limit (e.g., reducing epochs to 40). Initialize random seeds for reproducibility.
2.  **Stratified 5-Fold Training**: Iterate through 5 folds. For each fold, execute the training routine (`run_fold`) which handles data loading, model training with deep supervision and curriculum learning (BCE+Dice -> Lovasz), and checkpoint saving.
3.  **OOF Inference & Aggregation**: After training, iterate through the folds again to generate Out-of-Fold (OOF) predictions. Load the best checkpoint for each fold, perform inference on the validation set with Test-Time Augmentation (TTA) (horizontal flip), and aggregate the predictions and ground truth masks.
4.  **Threshold Optimization**: Perform a sweep over probability thresholds (0.3 to 0.75) on the aggregated OOF predictions to find the threshold that maximizes the competition metric (mAP @ IoU 0.5:0.95).
5.  **Failure Analysis**: Calculate per-image error metrics on the validation set and compute Pearson correlations with depth and salt coverage metadata to identify systematic weaknesses.
6.  **Submission Generation**: If the optimized validation metric exceeds the threshold (0.827), perform ensemble inference on the test set using all 5 models with TTA. Apply the optimal threshold, Run-Length Encode (RLE) the masks, and save the submission file.
