This script demonstrates the usage of the provided machine learning library for the salt segmentation task. It covers data processing (RLE encoding/decoding), metric calculation (mAP), dataset loading, model instantiation, loss computation, and a full training integration test using a reduced subset of data.

The strategy involves:
1.  **Unit Testing Utilities**: Verifying Run-Length Encoding logic and the Mean Average Precision metric with synthetic data.
2.  **Data Subset Creation**: Generating a small temporary metadata file containing only 20 samples to ensure the demonstration runs quickly.
3.  **Configuration Overrides**: Monkey-patching the `Config` class to point to the temporary data, reduce epochs, and set a temporary working directory.
4.  **Component Verification**: Instantiating the `SaltDataset`, `SaltModel`, and loss functions (`BCEDiceLoss`, `LovaszHingeLoss`) to verify shapes and forward passes.
5.  **Integration Test**: Executing `run_fold` from `library.train` to simulate a complete training cycle on the subset.
