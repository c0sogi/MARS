The implementation strategy follows the "High-Fidelity Dynamic Ensemble" idea while adhering to the strict time constraints.

1.  **Configuration Override**: To ensure the script completes within the 1-hour limit, the total epochs are reduced to 12 (6 for Phase 1, 6 for Phase 2) while maintaining the 5-fold structure. This balances training speed with the need for a robust ensemble.
2.  **Training Pipeline**: A 5-fold cross-validation loop is implemented. For each fold:
    *   The **SaltUNetPlusPlus** model is initialized.
    *   **Phase 1 (Warm-up)**: Trained with `BCEDiceLoss` and Deep Supervision enabled to stabilize feature learning.
    *   **Phase 2 (Fine-tuning)**: Trained with `LovaszHingeLoss` and Deep Supervision disabled to directly optimize the IoU-based metric.
    *   The best model (based on validation mAP) is saved.
3.  **OOF Generation & Optimization**: After training each fold, Out-of-Fold (OOF) predictions are generated. Once all folds are complete, a global pixel probability threshold sweep (0.3 to 0.7) is performed to find the threshold that maximizes the competition metric.
4.  **Failure Analysis**: The script calculates the correlation between the per-image mAP scores and metadata features (Depth, Salt Coverage) to identify error sources.
5.  **Submission**: If the optimized validation mAP exceeds 0.827, the script loads the test set and performs inference using the 5-model ensemble with Test-Time Augmentation (TTA). Predictions are averaged, thresholded, and RLE-encoded for submission.
