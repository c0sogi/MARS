implementation strategy
The implementation strategy follows the "U-Net++ with Deep Supervision and Input Channel Multiplexing" architecture defined in the provided library files. To ensure a fast yet effective baseline execution within the time constraints, the script overrides the training configuration to run for 30 epochs (15 epochs BCE+Dice warmup, 15 epochs Lovász-Hinge fine-tuning). This provides sufficient convergence while keeping the runtime short.

The workflow proceeds as follows:
1.  **Environment Setup:** Suppress progress bars (`tqdm`) to keep the output clean and set random seeds for reproducibility.
2.  **Training:** Initialize the `Trainer` and execute the `fit()` method. This handles the two-stage loss curriculum, adaptive learning rate scheduling, and checkpointing of the best model based on validation mAP.
3.  **Validation & Metric Calculation:** Load the best model checkpoint and perform inference on the full validation set. Test-Time Augmentation (horizontal flip) and the optimized binarization threshold (determined during training) are applied to maximize performance. The final validation metric (mAP over IoU thresholds 0.5-0.95) is calculated and printed.
4.  **Failure Analysis:** Compute the correlation between the prediction error (1 - mAP) and metadata features (Depth and Salt Coverage) for each validation image. This identifies if the model struggles with specific depths or salt quantities.
5.  **Submission:** If the final validation metric exceeds the threshold of 0.8101666667, generate predictions for the test set and save them to `submission.csv`.
