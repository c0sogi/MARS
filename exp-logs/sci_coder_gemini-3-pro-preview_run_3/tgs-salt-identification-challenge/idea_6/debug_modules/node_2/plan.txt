The error arises because the `load_data` function in `library/utils.py` pre-allocates the `images` array as a 3D tensor `(N, H, W)`, expecting grayscale images (single channel), but `cv2.imread` with the `cv2.IMREAD_UNCHANGED` flag loads the source images as 3-channel RGB arrays `(H, W, 3)`. This causes a shape mismatch `ValueError` when attempting to assign the 3-channel loaded image into the single-channel container. The fix is to explicitly load images (and masks) as grayscale using `cv2.IMREAD_GRAYSCALE` to ensure the dimensions match the pre-allocated buffers.
