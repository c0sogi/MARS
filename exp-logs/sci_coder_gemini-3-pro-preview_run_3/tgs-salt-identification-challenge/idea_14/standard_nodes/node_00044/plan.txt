The implementation strategy follows the "Stabilized Semi-Supervised U-Net++ Ensemble" idea but adapts it as a fast baseline by training only a single fold (Fold 0) with reduced epochs to satisfy the time limit while verifying the pipeline.

1.  **Setup**: Initialize configuration, seed, and device. Override default epochs to 15 (Phase 1) and 5 (Phase 2) to ensure rapid execution.
2.  **Phase 1 (Supervised)**: Train the `SaltUNetPlusPlus` model on Fold 0 using the supervised loss curriculum (BCE+Dice -> Lovasz). Save the best checkpoint.
3.  **Pseudo-Labeling**: Use the converged Phase 1 model to generate soft predictions (probabilities) for the unlabeled test set.
4.  **Phase 2 (Semi-Supervised)**: Construct a combined dataset (Labeled Train + Soft-Labeled Test). Fine-tune the model using `SoftBCELoss` for the mixed targets to leverage the unlabeled data structure.
5.  **Validation & Analysis**: Evaluate the final model on the hold-out validation set. Compute the competition metric (mAP). Perform failure analysis by correlating error rates with depth, salt coverage, and image intensity.
6.  **Submission**: If the validation metric exceeds the threshold (0.827), optimize the binarization threshold based on validation performance, generate RLE predictions for the test set, and save `submission.csv`.
