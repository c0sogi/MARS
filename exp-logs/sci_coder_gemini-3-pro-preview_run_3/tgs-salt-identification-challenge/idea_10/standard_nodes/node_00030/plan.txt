This script implements the **Holistic High-Fidelity Stratified Ensemble** strategy. It performs 5-fold cross-validation using the provided U-Net++ architecture with ResNeXt-50 encoder. It manages the two-stage training curriculum (BCE+Dice -> Lovasz-Hinge), optimizes the global probability threshold based on Out-of-Fold (OOF) predictions, performs failure analysis, and generates a submission if the validation metric threshold is met.
