The following script generates the required metadata files for the salt segmentation task.

**Implementation Strategy:**
1.  **Setup and Loading**: The script defines the input and output directories and loads the raw CSV files (`train.csv`, `depths.csv`, `sample_submission.csv`) using pandas.
2.  **Path Construction**: It constructs relative file paths for images and masks (e.g., `train/images/{id}.png`) and merges depth information into the dataframes.
3.  **Stratification**: To ensure a representative validation set, the script calculates the "salt coverage" for each training image based on its RLE mask. It then bins this coverage into classes and uses `train_test_split` with the `stratify` parameter to create an 80:20 split.
4.  **Saving**: The resulting training, validation, and test metadata are saved as CSV files in the `./metadata` directory.
5.  **Verification**: Immediately after generation, the script reloads the metadata to perform the required checks:
    *   **Summary Statistics**: Prints shapes and distribution info.
    *   **File Existence**: Randomly checks 1000 file paths to ensure they resolve to existing files in `./input`. Raises an error if the missing ratio exceeds 0.5.
    *   **Stratification Check**: Compares the distribution of salt coverage classes in the training and validation sets, raising an `AssertionError` if they diverge significantly.
