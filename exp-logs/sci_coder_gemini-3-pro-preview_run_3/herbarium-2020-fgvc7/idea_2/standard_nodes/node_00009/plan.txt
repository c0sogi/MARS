This solution orchestrates the training and evaluation of a ResNet-50 model with an ArcFace classification head to classify plant species.

### Strategy
1.  **Configuration**: We override the default epoch count to 3 to ensure the pipeline completes within the 2-hour limit while still learning from the large dataset. We utilize the provided A100 GPU and 12 vCPUs.
2.  **Data Loading**: We load the full training and validation datasets using the provided `get_dataloaders` function. We enable caching to speed up the weighted sampler initialization.
3.  **Training**: We train the `ArcFaceResNet` model using SGD with Momentum and CrossEntropyLoss. We save the model with the best Macro F1 score on the validation set.
4.  **Evaluation**: After training, we reload the best model and perform a full inference pass on the validation set to calculate the final Macro F1 score and collect predictions for analysis.
5.  **Failure Analysis**: We analyze the correlation between the model's prediction error (binary) and the class frequency (from training data) to quantify how well the model handles the long-tail distribution.
6.  **Submission**: If the final validation metric exceeds the specified threshold, we generate the submission file for the test set.
