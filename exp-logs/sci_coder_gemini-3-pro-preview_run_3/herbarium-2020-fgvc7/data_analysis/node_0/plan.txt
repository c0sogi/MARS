The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup and Configuration**: Initialize random seeds for reproducibility and define paths to the input data and generated metadata.
2.  **Target Variable Analysis**:
    *   Load the `train.csv` metadata file.
    *   Analyze the `category_id` column to understand the class distribution.
    *   Calculate metrics such as the number of unique classes, the range of samples per class (min, max, mean), and the degree of class imbalance (e.g., identifying "rare" classes).
3.  **Image Data Analysis**:
    *   Since the dataset is large (over 600k images), perform analysis on a stratified random sample (e.g., 5,000 images) to ensure execution within the time limit.
    *   Iterate through the sampled images to extract:
        *   **Dimensions**: Width, Height, and Aspect Ratio.
        *   **Channels**: Verify if images are RGB or Grayscale.
        *   **Pixel Statistics**: Calculate running sums of pixel values to compute the global mean and standard deviation for normalization.
    *   Report summary statistics (mean, std, min, max) for these properties.
4.  **Feature/Signal Relationships**:
    *   **Meta-Feature Analysis**: Investigate if image properties (like file size or aspect ratio) have a relationship with the target variable.
    *   Specifically, check if the "rarity" of a class (class frequency) correlates with the image quality or size.
    *   Perform a one-way ANOVA on the Aspect Ratio across the top most frequent classes to see if physical dimensions are a discriminative feature for species.
5.  **Output**: Print the findings in the specified format, ensuring no data leakage by strictly using the training set.
