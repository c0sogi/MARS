The following implementation demonstrates the usage of the provided library modules (`config`, `utils`, `dataset`, `model`, `trainer`). To ensure the demonstration runs quickly within the time limit, the script performs the following steps:

1.  **Configuration Overrides**: It modifies the global configuration to use a temporary working directory and reduces the number of epochs and batch size.
2.  **Data Subsetting**: It creates small subsets of the original training, validation, and test metadata CSVs (50 samples each). This allows the data loading and training loops to execute almost instantly while still verifying the logic.
3.  **Component Verification**:
    *   **Utils**: Verifies the metric calculation and logging utilities.
    *   **Dataset**: Verifies the data loader construction, batch shapes, and data types.
    *   **Model**: Instantiates the `HierarchicalResNet` and verifies the forward pass output shapes (species and genus logits).
    *   **Trainer**: Runs a complete training cycle for 1 epoch on the subset and generates a submission file, verifying that artifacts (checkpoints, submission CSV) are created correctly.
