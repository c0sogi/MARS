# Baseline Approach: ResNet-18 with Class-Balanced Sampling

### Model
The architecture utilizes a **ResNet-18** backbone, which is significantly more lightweight and faster to train than the EfficientNetV2-M (Model 1) or ResNet-50 (Model 3) variants.
-   **Backbone:** We use a standard ResNet-18 pre-trained on ImageNet to leverage learned texture and shape features.
-   **Head:** The final fully connected layer is replaced with a linear projection mapping the 512-dimensional feature vector to the 32,093 class logits.
-   **Why distinct?** Unlike Model 1, this approach avoids complex compound scaling and progressive resizing. Unlike Model 4, it uses an end-to-end differentiable classification head rather than a tree ensemble. Unlike Model 5, it uses a flat, single-head topology.

### Data
-   **Preprocessing:** All images are resized to **224x224** pixels. This is the standard input resolution for ResNet architectures and ensures low computational overhead compared to the larger resolutions (384/480) proposed in Model 1.
-   **Normalization:** Pixel values are normalized using standard ImageNet mean and standard deviation.
-   **Augmentation:** Minimal augmentations are applied (random horizontal flips and random crops) to maintain simplicity and training speed.

### Training
-   **Loss Function:** We use standard **Cross-Entropy Loss**.
-   **Imbalance Strategy:** Instead of modifying the loss function (like the Focal Loss in Model 1), we address the extreme class imbalance at the data level using a **Weighted Random Sampler**.
    -   Weights are assigned to each sample inversely proportional to the frequency of its class in the training set.
    -   This ensures that each mini-batch contains a relatively uniform distribution of classes, allowing the model to see singleton and rare species as frequently as common ones without specialized loss formulations.
-   **Optimizer:** Stochastic Gradient Descent (SGD) with Momentum or AdamW, using a standard learning rate schedule (e.g., StepLR or Cosine Annealing).

### Evaluation
-   **Inference:** Test images are resized to 256x256 and center-cropped to 224x224.
-   **Prediction:** The model computes the logits for the cropped image, and the class with the highest probability (argmax) is selected as the prediction. No test-time augmentation (TTA) or ensemble methods are used.
