Implementation Strategy:
1.  **Environment Setup**: Import necessary modules and the provided library components. Ensure the random seed is fixed using `seed_everything`.
2.  **Configuration Override**: Modify the `Config` class attributes to create a "Demo Mode". This includes setting a dedicated working directory, enabling debug mode with a small sample size (50 images), reducing the batch size, and limiting training to 2 epochs with SWA starting at epoch 1. This ensures the script runs very quickly.
3.  **Utility Verification**: Validate the `calculate_f1_macro` function with known inputs to ensure metric calculation logic is correct.
4.  **Dataset & DataLoader Demonstration**:
    *   Load the metadata CSVs.
    *   Instantiate `HerbariumDataset` directly to verify `__getitem__` returns tensors of the correct shape and type.
    *   Invoke `get_dataloaders` and iterate through one batch to confirm the data loading pipeline works and respects the debug sample size.
5.  **Model Architecture Demonstration**:
    *   Instantiate the `HerbariumConvNeXt` model.
    *   Perform a forward pass with a dummy input tensor to verify the output shape corresponds to `(Batch_Size, Num_Classes)`.
6.  **Full Training Pipeline Execution**:
    *   Run `run_training(debug=True, epochs=2)`. This tests the entire training loop, including mixed precision, backpropagation, SWA, and checkpoint saving.
    *   Assert that the model checkpoint and submission file are created.
7.  **Inference Pipeline Execution**:
    *   Run `run_prediction(debug=True)`. This tests the model loading (specifically SWA weights) and prediction generation logic.
    *   Assert that the final submission file exists and has the correct number of rows.
