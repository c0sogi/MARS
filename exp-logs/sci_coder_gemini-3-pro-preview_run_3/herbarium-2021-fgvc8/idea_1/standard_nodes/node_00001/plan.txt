The implementation strategy follows the provided library structure to create an efficient baseline solution. 

1.  **Setup & Configuration**: The script initializes the environment with a fixed seed for reproducibility. It overrides the `Config.NUM_EPOCHS` to 1 to ensure the "fast baseline" requirement is met while still training on the full dataset using the powerful A100 GPU.
2.  **Data Loading**: It utilizes `get_dataloaders` with `load_cached_data=True` to quickly retrieve the training, validation, and test sets. It also constructs an inverse mapping dictionary to convert model predictions (class indices) back to the required `category_id` for submission.
3.  **Model & Training**: A `HerbariumResNet` (ResNet50) is initialized along with an SGD optimizer and Cosine Annealing scheduler. The `Trainer` class is used to manage the training loop, leveraging Automatic Mixed Precision (AMP) via the provided library to maximize throughput.
4.  **Validation**: After training, the model is evaluated on the full validation set. The `Macro F1` score is calculated and printed in the specific format required (`Final Validation Metric: <value>`).
5.  **Failure Analysis**: To identify error patterns, the script extracts a subset of validation predictions, loads the corresponding image metadata (width, height), and calculates the Pearson correlation between the error magnitude (binary) and these features using NumPy.
6.  **Submission**: Finally, the model generates predictions for the test set in inference mode (using `torch.no_grad` and AMP). These predictions are mapped to their original category IDs and saved to `submission.csv` in the required format.
