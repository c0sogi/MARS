This script demonstrates the end-to-end usage of the provided library files for the essay scoring task. It performs the following steps:

1.  **Data Preparation**: Creates a small subset of the training and validation data (50 samples each) to ensure the demonstration runs quickly. It overrides the `Config` file paths to point to these subsets.
2.  **Data Loading**: Uses `library.data` to process the raw text, extract meta-features, and create PyTorch DataLoaders. It verifies the shape of the batches produced.
3.  **Model Initialization**: Instantiates the `EssayModel` (DeBERTa-v3-Large backbone with a custom regression head) and verifies the forward pass logic by checking output shapes.
4.  **Backbone Training**: Runs a short training loop (1 epoch) using `library.engine` to fine-tune the backbone model on the subset.
5.  **Feature Extraction**: Uses the fine-tuned backbone to extract embeddings for the dataset via sliding window inference (`library.stacking`). It verifies the dimensions of the combined features (embeddings + meta-features).
6.  **Stacking**: Trains a LightGBM regressor on the extracted features and generates predictions for a test subset.
7.  **Evaluation**: Computes the Quadratic Weighted Kappa (QWK) score to verify the metric calculation.
