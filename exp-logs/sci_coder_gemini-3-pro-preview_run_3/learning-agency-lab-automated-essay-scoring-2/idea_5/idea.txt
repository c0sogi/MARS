Based on the progression of experiments and the specific lessons learned, I propose a **Robust K-Fold Stacking Strategy with Adversarial Regularization**. This solution evolves the architecture from a single-split fine-tuning approach to a fully cross-validated pipeline that maximizes data utilization and generalization stability.

### Model
*   **Backbone Architecture**: Use **`deberta-v3-large`** as the primary feature extractor. The transition to the "Large" architecture has been empirically proven to provide the necessary capacity for this task (Cite solution_lesson_node_00014).
*   **Pooling Mechanism**: Implement **Attention Pooling** on the **final hidden layer** exclusively.
    *   *Reasoning*: Lesson 14 demonstrated the efficacy of Attention Pooling with large models, while Lesson 13 showed that aggregating multiple top layers degrades performance compared to using the final layer alone (Cite solution_lesson_node_00013).
*   **Adversarial Regularization**: Integrate **Adversarial Weight Perturbation (AWP)** into the training loop. This technique explicitly perturbs model weights to maximize the loss during training, forcing the optimizer to find flatter, more robust minima. This is a structural innovation to improve generalization on unseen test data.
*   **Stacking Head**: The final estimator is a **LightGBM** regressor. It accepts a hybrid input vector consisting of the **OOF Embeddings** and **Explicit Meta-Features** (Cite solution_lesson_node_00004).

### Data
*   **Stratified K-Fold Splitting**: Partition the training data into **5 Stratified Folds** based on the `score`. This ensures the LightGBM head is trained on out-of-fold predictions for the entire dataset, eliminating the data waste inherent in a single 80/20 split.
*   **Context Processing**: Use the `deberta-v3-large` tokenizer. Apply a **sliding window** approach (e.g., 512 tokens with stride) to process full texts, averaging the pooled embeddings of the chunks to generate the document-level vector.
*   **Meta-Feature Engineering**: Calculate explicit structural scalar features—specifically **character count, word count, sentence count, and unique word ratio**. These features must be concatenated with the embeddings to capture magnitude signals that normalized vectors miss (Cite solution_lesson_node_00002).

### Training
*   **Stage 1: Backbone Fine-Tuning (Cross-Validation)**
    *   **Objective**: Minimize **Mean Squared Error (MSE)**, treating scores as continuous targets (Cite solution_lesson_node_00001).
    *   **Optimization**:
        *   Implement **Layer-wise Learning Rate Decay (LLRD)** to stabilize the training of the Large backbone (Cite solution_lesson_node_00014).
        *   Enable **Gradient Checkpointing** to manage memory constraints (Cite solution_lesson_node_00014).
        *   Use the unified **`torch.amp`** API for mixed-precision training to ensure numerical stability and efficiency (Cite solution_lesson_node_00012).
        *   **AWP Trigger**: Activate Adversarial Weight Perturbation after the first epoch to refine the decision boundary.
    *   **Cache Management**: Implement **hash-based cache invalidation** (using model config/seed hashes) for saving OOF embeddings. This prevents the critical failure of loading stale features from previous experiments (Cite solution_lesson_node_00015).
*   **Stage 2: Stacking**
    *   Train the LightGBM regressor on the concatenated OOF embeddings and meta-features from all 5 folds.
    *   **Hyperparameters**: Explicitly set `feature_fraction` (subsampling) to **< 1.0** (e.g., 0.7). This forces the tree model to utilize the semantic embeddings and prevents it from over-relying on the strong length-based meta-features (Cite solution_lesson_node_00006).

### Evaluation
*   **Inference**: For each test essay, generate embeddings using all 5 fine-tuned backbone models (one from each fold) and average them to create a robust "Ensemble Embedding".
*   **Prediction**: Feed the Ensemble Embedding and calculated meta-features into the trained LightGBM model.
*   **Post-Processing**: Clip the continuous predictions to the [1, 6] range and round to the nearest integer to maximize the Quadratic Weighted Kappa metric (Cite solution_lesson_node_00001).
