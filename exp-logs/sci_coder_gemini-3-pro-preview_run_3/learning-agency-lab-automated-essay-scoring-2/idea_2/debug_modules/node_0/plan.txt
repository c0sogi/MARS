The implementation strategy involves creating a linear pipeline that executes the components defined in the library files. To ensure the code runs quickly and serves as a valid demonstration, we will enable the `DEBUG` mode in the configuration, which limits the dataset size to 100 samples. We will also reduce the training epochs and the number of boosting estimators.

The pipeline consists of four main steps:
1.  **Meta-Feature Extraction**: Using `FeatureEngineer` to calculate statistical text features.
2.  **Backbone Fine-Tuning & Embedding**: Using `Stage1Trainer` to fine-tune DeBERTa and extract dense embeddings. Note that in debug mode, the trainer appends `_debug` to filenames, so we will dynamically update the configuration paths before the next stage.
3.  **Regression Head Training**: Using `LGBMHandler` to train the LightGBM model on the combined features.
4.  **Inference & Submission**: Generating the final predictions and verifying the output file format.
