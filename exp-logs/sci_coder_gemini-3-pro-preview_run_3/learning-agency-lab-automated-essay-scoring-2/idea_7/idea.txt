Based on the comprehensive analysis of the provided lessons and the expanded 24-hour computational budget, I propose the following **Full-Scale K-Fold Strategy with Adversarial Robustness**.

This solution structurally evolves the pipeline from a single-split approach to a fully cross-validated ensemble. It specifically addresses the failure observed in Lesson 20—where advanced regularization (AWP) failed due to data subsampling—by leveraging the extended runtime to apply robust training techniques on the **entire dataset**.

### Model
*   **Backbone Architecture**: Utilize **`deberta-v3-large`** as the primary feature extractor. The transition to the "Large" architecture provides the necessary parameter capacity to capture subtle scoring nuances (Cite solution_lesson_node_00014).
*   **Pooling Mechanism**: Implement **Attention Pooling** applied exclusively to the **final hidden layer**. This avoids the performance degradation observed when aggregating multiple top layers (Cite solution_lesson_node_00013) and allows the model to dynamically weight informative tokens (e.g., argumentation) over padding.
*   **Adversarial Regularization**: Integrate **Adversarial Weight Perturbation (AWP)** into the backbone training. AWP explicitly perturbs weights to maximize loss during training, smoothing the loss landscape. While previously computationally prohibitive under a 2-hour limit (Cite solution_lesson_node_00020), the 24-hour budget allows us to apply this technique to the full dataset to significantly improve generalization.
*   **Stacking Head**: The final estimator is a **LightGBM** regressor. It accepts a hybrid input vector consisting of the **Ensembled Embeddings** and **Explicit Meta-Features** (Cite solution_lesson_node_00004).

### Data
*   **Stratified K-Fold Splitting**: Partition the `train.csv` dataset into **5 Stratified Folds** based on the `score`. This ensures the LightGBM head is trained on Out-Of-Fold (OOF) predictions for the **entire dataset**, maximizing data utilization compared to a single 80/20 split.
*   **Meta-Feature Engineering**: Calculate explicit structural scalar features—specifically **character count, word count, sentence count, and unique word ratio**. These must be concatenated with the embeddings to capture magnitude signals that normalized vectors miss (Cite solution_lesson_node_00002).
*   **Context Processing**: Use the `deberta-v3-large` tokenizer. Apply a **sliding window** approach (e.g., 512 tokens with 128 stride) to process full texts. The embeddings for all chunks of an essay will be averaged to generate the document-level vector.

### Training
*   **Stage 1: Backbone Fine-Tuning (5-Fold CV)**
    *   **Procedure**: Train 5 independent `deberta-v3-large` models, one for each fold.
    *   **Objective**: Minimize **Mean Squared Error (MSE)**, treating ordinal scores as continuous targets (Cite solution_lesson_node_00001).
    *   **Optimization**:
        *   Implement **Layer-wise Learning Rate Decay (LLRD)** to stabilize the training of the Large backbone (Cite solution_lesson_node_00014).
        *   Enable **Gradient Checkpointing** to fit the model on the A100 GPU (Cite solution_lesson_node_00014).
        *   Use the unified **`torch.amp`** API for mixed-precision training (Cite solution_lesson_node_00012).
    *   **Cache Management**: Save OOF embeddings to disk using **hash-based filenames** (derived from model config/seed) to strictly prevent the loading of stale features from previous runs (Cite solution_lesson_node_00015).
*   **Stage 2: Stacking**
    *   Construct the training set for the LightGBM head by concatenating the OOF embeddings from all 5 folds.
    *   Train the LightGBM regressor on this combined dataset (Embeddings + Meta-Features).
    *   **Regularization**: Explicitly set `feature_fraction` (subsampling) to **< 1.0** (e.g., 0.7). This forces the tree model to utilize the semantic embeddings and prevents over-reliance on strong length-based meta-features (Cite solution_lesson_node_00006).

### Evaluation
*   **Inference**: For each essay in the test set, generate embeddings using **all 5 fine-tuned backbone models** and average them to create a robust "Ensemble Embedding".
*   **Prediction**: Feed the Ensemble Embedding and calculated meta-features into the trained LightGBM model to predict the continuous score.
*   **Post-Processing**: Clip the predictions to the [1, 6] range and round to the nearest integer to maximize the Quadratic Weighted Kappa metric (Cite solution_lesson_node_00001).
