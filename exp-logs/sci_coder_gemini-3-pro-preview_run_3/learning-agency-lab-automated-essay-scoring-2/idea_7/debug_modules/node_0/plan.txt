The following script demonstrates the essay scoring pipeline by utilizing the provided library modules. It performs the following steps:
1.  **Configuration**: Patches the `Config` class to use a tiny model (`bert-tiny`) and minimal hyperparameters (2 folds, 1 epoch) for rapid execution.
2.  **Data Processing**: Loads and preprocesses the metadata, generating stratified folds and meta-features.
3.  **Model Verification**: Instantiates the `EssayDataset` and `EssayModel`, performing a forward pass to verify tensor shapes.
4.  **AWP Verification**: Demonstrates Adversarial Weight Perturbation by checking if weights are modified during an attack.
5.  **Training**: Runs the backbone training loop for 2 folds using the `trainer` module.
6.  **Stacking**: Trains the LightGBM stacking head on the Out-Of-Fold (OOF) embeddings generated during training.
7.  **Inference**: Generates predictions on the test set using the full ensemble pipeline.
