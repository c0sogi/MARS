This solution implements the `runfile.py` script to orchestrate the "Full-Scale Robust K-Fold Ensemble" pipeline.

**Strategy:**
1.  **Configuration Override:** To comply with the strict 2-hour time limit for this baseline run while maintaining high performance, we override the default configuration to use **1 Epoch** and **3 Folds**. This ensures the computationally expensive DeBERTa-v3-large backbone can be fine-tuned on the A100 GPU within the allotted time (approx. 25 mins per fold). We also enable AWP from the first epoch.
2.  **Backbone Training:** We iterate through the specified folds, training the backbone model on the training metadata and generating embeddings for the validation set. We use aggressive garbage collection to manage GPU memory.
3.  **Stacking:** We train the LightGBM regressor on the aggregated embeddings and meta-features from the validation set.
4.  **Validation & Analysis:** We evaluate the full pipeline on the hold-out validation set to compute the Quadratic Weighted Kappa (QWK). We also perform failure analysis by correlating prediction errors with essay length features (character count, word count, etc.) to identify potential biases.
5.  **Inference:** If the validation QWK exceeds the threshold (0.8246), we generate predictions for the test set using the ensemble of backbones and the trained stacking head.
