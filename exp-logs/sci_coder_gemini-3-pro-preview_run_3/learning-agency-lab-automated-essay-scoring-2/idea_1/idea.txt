To establish a highly efficient and robust baseline, I propose a **Frozen Transformer-based Ridge Regression** approach. This method synthesizes the semantic depth of deep learning architectures with the computational efficiency of linear models, distinct from the fine-tuning or sparse-linear approaches previously listed.

### Model
The architecture consists of two distinct stages:
1.  **Static Feature Extractor**: A pre-trained, lightweight Sentence Transformer (e.g., a `MiniLM` variant) is used as a fixed encoder. Unlike Model 2, this component is **frozen**; its weights are not updated during training. It processes the full essay text to output a single, dense, fixed-length vector (embedding) that encapsulates the semantic meaning of the response.
2.  **Regression Head**: The dense vectors produced by the transformer are fed into a **Ridge Regression** model (Linear Least Squares with L2 regularization). This linear layer maps the high-dimensional semantic features directly to the holistic score.

### Data
1.  **Preprocessing**: Minimal text cleaning is applied (e.g., whitespace normalization) to preserve the natural language context that transformers rely on.
2.  **Encoding**: The training, validation, and test datasets are processed through the frozen transformer in batches. This converts the raw text dataset into a tabular dataset where rows represent essays and columns represent the dimensions of the embedding vector (e.g., 384 dimensions).
3.  **Target Preparation**: The integer scores (1-6) are treated as continuous floating-point targets to allow the regression model to learn the ordinal relationship between classes.

### Training
1.  **Procedure**: Training is strictly limited to the Ridge Regression layer. Because the transformer backbone is frozen, the heavy computational cost of backpropagation through deep layers is eliminated.
2.  **Optimization**: The model minimizes the Mean Squared Error (MSE) with an L2 penalty term. The regularization strength (alpha) is selected via efficient cross-validation on the training embeddings. This process is mathematically deterministic and extremely fast compared to gradient descent-based training.

### Evaluation
1.  **Inference**: The test set essays are encoded into embeddings using the same frozen transformer.
2.  **Prediction**: The trained Ridge Regression model predicts a continuous score for each test embedding.
3.  **Post-Processing**: To satisfy the submission format and metric requirements, the continuous predictions are **clipped** to the range [1, 6] and **rounded** to the nearest integer. These final integer values are used to calculate the Quadratic Weighted Kappa.
