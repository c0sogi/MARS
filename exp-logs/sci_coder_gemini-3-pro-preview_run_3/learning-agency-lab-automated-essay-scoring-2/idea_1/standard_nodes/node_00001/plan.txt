Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Environment Setup**: Initialize the environment by setting random seeds for Python, NumPy, and PyTorch to ensure reproducibility. Call `Config.setup()` to create necessary directories.
2.  **Data Loading**: Use the provided `load_essay_data` function to load the training, validation, and test datasets. This retrieves essay IDs, full texts, and scores (where applicable).
3.  **Feature Extraction**: Instantiate the `EmbeddingEngine` from the library. Generate dense vector embeddings for the training, validation, and test texts. This step utilizes the GPU (A100) for efficient batch processing via the frozen MiniLM transformer.
4.  **Model Training**: Initialize the `RidgeRegressor`. Train the model using the training embeddings and scores. The `RidgeCV` within the class automatically handles hyperparameter tuning (alpha selection) efficiently.
5.  **Validation & Metric Calculation**:
    *   Generate predictions on the validation set.
    *   Post-process these predictions (clip to 1-6, round, cast to integer) using `post_process_preds`.
    *   Compute the Quadratic Weighted Kappa (QWK) using `compute_qwk` and print it in the required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate the absolute error between the continuous model predictions and the ground truth scores.
    *   Compute auxiliary features (essay character length) from the raw validation texts.
    *   Calculate and print the Pearson correlation between the error magnitude and these features (essay length, ground truth score) to identify if the model struggles with specific lengths or score ranges.
7.  **Submission Generation**:
    *   Generate predictions for the test set embeddings.
    *   Post-process them into integers.
    *   Construct a Pandas DataFrame with `essay_id` and `score`.
    *   Save the dataframe to the specified submission path.
