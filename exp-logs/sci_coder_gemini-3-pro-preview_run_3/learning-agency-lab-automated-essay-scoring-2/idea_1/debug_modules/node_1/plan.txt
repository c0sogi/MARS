The issue stems from Python's behavior where default argument values are evaluated only once at function definition time. In `library/data_loader.py`, the `debug` parameter defaults to `Config.DEBUG` (False) when the module is imported. Even though `runfile.py` later updates `Config.DEBUG` to `True`, the `load_essay_data` function retains the old default value of `False`. To fix this, I will change the default values of `debug` and `debug_size` to `None` in the function signature and assign them the current values from `Config` inside the function body.
