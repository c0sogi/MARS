The `NaN` loss is caused by the interaction between Automatic Mixed Precision (AMP) and Adversarial Weight Perturbation (AWP). In AMP, gradients are scaled to prevent underflow, often resulting in `Infinity` values in float16 before unscaling. The AWP attack calculates perturbations using `grad / norm(grad)`; if the gradients are scaled and contain `Infinity`, this results in `NaN` (`Inf / Inf`), which corrupts the model weights. To fix this, we must explicitly unscale the gradients using `scaler.unscale_(optimizer)` *before* accessing them in `awp.attack()` (Cite debug_lesson_8). Consequently, we must ensure `scaler.unscale_(optimizer)` is not called a second time during the gradient accumulation step, as this would raise a `RuntimeError` (Cite debug_lesson_7). We implement this by making the unscale call in the accumulation block conditional on `awp` being `None`.
