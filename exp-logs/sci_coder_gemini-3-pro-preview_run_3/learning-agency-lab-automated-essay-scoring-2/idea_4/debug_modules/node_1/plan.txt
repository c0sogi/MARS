The previous implementation caused a `TypeError` because it monkey-patched `tqdm.auto.tqdm` with a function (`nop_tqdm`) to suppress output. The `huggingface_hub` library, which is imported subsequently, attempts to create a class that inherits from `tqdm.auto.tqdm`. Since Python classes cannot inherit from a function, this operation failed. The fix is to replace `tqdm.auto.tqdm` with a class (`SilentTqdm`) that inherits from the original `tqdm` class but explicitly sets `disable=True` in its initialization. This preserves the class structure required by dependencies while successfully silencing progress bars.

    def __init__(self, *args, **kwargs):
