To establish a highly efficient baseline, I propose a **Sparse Multi-Layer Perceptron (MLP)** approach. This method bridges the gap between the speed of linear models (like Model 1) and the capacity of neural networks, utilizing the GPU to train a shared representation for all tags simultaneously rather than training thousands of independent classifiers.

### Model
The architecture is a simple Feed-Forward Neural Network (MLP) designed to operate directly on high-dimensional sparse inputs.
*   **Input Layer**: Accepts a sparse TF-IDF vector representing the document (Title + Body).
*   **Hidden Layer**: A dense linear layer projects the high-dimensional input into a lower-dimensional latent space (e.g., 512 or 1024 units), followed by a ReLU activation function and Dropout for regularization. This layer allows the model to learn non-linear interactions between words.
*   **Output Layer**: A dense linear layer maps the latent representation to the output space, where the number of units equals the number of target tags.
*   **Activation**: A Sigmoid activation is applied to the final logits to output independent probabilities for each tag (multi-label classification).

### Data
*   **Text Preprocessing**:
    *   Concatenate the `Title` and `Body` columns.
    *   Remove HTML tags (e.g., `<p>`, `<code>`) and non-alphanumeric characters to reduce noise.
    *   Normalize text to lowercase.
*   **Feature Extraction**:
    *   Apply **TF-IDF Vectorization** (Term Frequency-Inverse Document Frequency) to the cleaned text.
    *   Use unigrams and bigrams.
    *   Limit the vocabulary to the top `N` (e.g., 25,000) most frequent features to maintain memory efficiency and sparsity.
*   **Label Encoding**:
    *   Filter the target tags to retain only the top `K` (e.g., 5,000 to 10,000) most frequent tags. This covers the vast majority of samples while removing "tail" tags that are difficult to predict and add noise.
    *   Use a **Multi-Label Binarizer** to convert the lists of tags into a binary multi-hot encoded vector (0s and 1s) for training.

### Training
*   **Loss Function**: Use **Binary Cross-Entropy with Logits Loss** (BCEWithLogitsLoss). This is standard for multi-label classification where each tag is treated as an independent Bernoulli trial.
*   **Optimizer**: Use the **Adam** optimizer for fast convergence.
*   **Procedure**:
    *   Convert the SciPy sparse TF-IDF matrix into a PyTorch Sparse Tensor (or dense batches during iteration) to leverage the NVIDIA A100 GPU.
    *   Train with a relatively large batch size (e.g., 1024 or 2048) to maximize GPU throughput.
    *   Monitor the F1-score on the validation set to trigger early stopping.

### Evaluation
*   **Inference**: Pass the preprocessed test data through the trained network to obtain probability scores for each tag.
*   **Thresholding**: Apply a fixed threshold (e.g., 0.5) or a tuned threshold based on validation performance to convert probabilities into binary predictions.
*   **Formatting**: Map the predicted indices back to their corresponding string tags and join them with spaces to match the submission format.
