1.  **Configuration Patching**: To ensure the demonstration runs quickly and respects the "Optimize for Speed" requirement without modifying the read-only library files, I will import `library.config` first and override key parameters at runtime. 3.  **Pipeline Execution**: I will systematically import and execute the components from the provided libraries in the logical order of a machine learning pipeline:
    *   **Data Processing**: Use `data_processor.process_data` to vectorize text and binarize labels.
    *   **Data Loading**: Use `dataset.get_dataloaders` to create PyTorch DataLoaders.
    *   **Modeling**: Instantiate `model.SparseMLP`.
    *   **Training**: Use `trainer.run_training` to train the model on the subset.
    *   **Inference**: Use `trainer.generate_submission` to predict on the test subset.
4.  **Validation**: Throughout the script, I will use `assert` statements to verify shapes, file existence, and logic (e.g., ensuring the F1 score calculation is correct and the submission file matches the test set dimensions).
