The strategy is to create a Python script that generates metadata CSVs for training, validation, and testing without duplicating the large text content of the original dataset. 

1.  **Data Loading**: The script will read `train.csv` and `test.csv` from the `./input` directory. To ensure efficiency and avoid memory issues with the large dataset, it will only load the `Id` and `Tags` columns for the training set, and just the `Id` column for the test set.
2.  **Metadata Generation**:
    *   **Train/Val Split**: The training data will be split into an 80% training set and a 20% validation set.
    *   **Stratification**: The split will use the `Tags` column for stratification. Since this is a multi-label problem represented as space-delimited strings, we will treat each unique tag string as a class (Label Powerset). Tag combinations appearing fewer than 2 times ("rare" classes) will be separated and split randomly to preserve the 80:20 ratio, while the rest will be stratified.
    *   **File Paths**: A `file_path` column will be added to each metadata entry, pointing relatively to the original source file (e.g., `train.csv`).
    *   **Output**: The resulting DataFrames will be saved as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
3.  **Validation**: After generation, the script will reload the metadata to:
    *   Print summary statistics.
    *   Verify that at least 50% of a random sample of 1000 file paths resolve correctly.
    *   Assert that the train/validation split ratio is approximately 80:20.
    *   Assert that the distribution of the top tags is consistent between training and validation sets (stratification check).
    *   Assert that there is no ID overlap between training and validation sets.
