Based on the objective to establish a highly efficient baseline that prioritizes speed and simplicity while remaining distinct from the previous Sparse MLP approach, I propose a **Neural Bag-of-Words (NBOW)** model (often associated with the "FastText" architecture).

### Model
The proposed architecture is a **Neural Bag-of-Words (NBOW)** model, designed to learn dense representations efficiently without the complexity of recurrent or convolutional layers.
*   **Input Layer**: Accepts variable-length sequences of integer token IDs representing the concatenated Title and Body.
*   **Embedding Layer**: A learnable embedding matrix projects each token ID into a low-dimensional dense vector (e.g., 128 dimensions). Unlike TF-IDF, which uses fixed statistics, this layer learns semantic word similarities during training.
*   **Aggregation**: A **Global Average Pooling** operation computes the mean of the embedding vectors for all tokens in a sequence. This compresses the variable-length document into a single, fixed-size context vector.
*   **Classification Head**: A single dense linear layer maps the context vector directly to the output tag space.
*   **Activation**: A Sigmoid activation is applied to the output logits to generate independent probabilities for each tag.

### Data
*   **Text Preprocessing**: Concatenate `Title` and `Body`. Perform basic normalization (lowercase, remove non-alphanumeric characters) and tokenize by splitting on whitespace.
*   **Vocabulary Construction**: Build a vocabulary of the top $N$ (e.g., 100,000) most frequent words from the training corpus. Assign a unique integer ID to each word and reserve an ID for unknown tokens.
*   **Sequence Vectorization**: Convert the text of each sample into a list of integer IDs. Unlike the sparse TF-IDF approach, this preserves the token count and density.
*   **Target Encoding**: Use a Multi-Label Binarizer to encode the top $K$ (e.g., 5,000) most frequent tags into binary vectors (0s and 1s).

### Training
*   **Implementation**: Use PyTorch's `nn.EmbeddingBag` module. This component fuses the lookup and averaging operations into a single optimized GPU kernel, offering significantly higher throughput and lower memory usage than standard embedding layers followed by manual pooling.
*   **Loss Function**: Use **Binary Cross-Entropy with Logits Loss** (BCEWithLogitsLoss) to optimize the multi-label classification objective.
*   **Optimizer**: Use the **Adam** optimizer for efficient convergence.
*   **Regularization**: Apply Dropout to the aggregated embedding vector before the linear classifier to improve generalization.

### Evaluation
*   **Inference**: Pass the tokenized test data through the model to generate probability scores for all tags.
*   **Thresholding**: Apply a fixed or validation-tuned probability threshold (e.g., 0.5) to determine the presence of each tag.
*   **Formatting**: Map the indices of the predicted tags back to their string labels and join them with a space delimiter to create the submission file.
