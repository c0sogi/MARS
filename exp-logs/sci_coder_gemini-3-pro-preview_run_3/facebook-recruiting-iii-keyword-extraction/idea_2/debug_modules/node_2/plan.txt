The issue arises because Python evaluates default function arguments at definition time (module import), not at call time. The `Vocabulary` class uses `Config.VOCAB_SIZE` (originally 100,000) as the default value for `max_size`. Although `runfile.py` updates `Config.VOCAB_SIZE` to 1000 at runtime, the `Vocabulary` instance in `get_dataloaders` is created without arguments, causing it to use the stale default value of 100,000. This results in a vocabulary much larger than the model's embedding layer expects (initialized with the runtime value of 1000), leading to a "device-side assert triggered" (index out of bounds) error on the GPU. The fix is to explicitly pass the current `Config.VOCAB_SIZE` when instantiating `Vocabulary`.
