Implementation Strategy:
1.  **Configuration & Setup**: Override `Config.NUM_EPOCHS` to 3 to ensure the baseline runs quickly within the time limit while still learning. Initialize directories and set random seeds for reproducibility.
2.  **Data Loading**: Utilize `get_dataloaders(load_cached_data=True)` to load the training, validation, and test datasets. This leverages cached artifacts if available, significantly speeding up the pipeline.
3.  **Model Training**: Instantiate the `NBOWModel` (Neural Bag-of-Words), Adam optimizer, and Binary Cross-Entropy loss. Use the `Trainer` class to execute the training loop, which includes validation and checkpointing of the best model.
4.  **Best Model Retrieval**: After training, explicitly load the best model checkpoint from disk to ensure that the validation analysis and test submission use the optimal weights, not just the final epoch's weights.
5.  **Validation & Failure Analysis**: Run a dedicated validation pass to calculate the exact Mean F1-Score. Simultaneously, compute the correlation between the input text length (derived from token offsets) and the error rate (1 - F1) to identify if sequence length impacts model performance.
6.  **Submission**: Generate predictions on the test set and format them into the required CSV structure using the `run_inference` utility.
