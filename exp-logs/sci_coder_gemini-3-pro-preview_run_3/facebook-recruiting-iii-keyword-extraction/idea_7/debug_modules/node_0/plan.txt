The following script demonstrates the usage of the provided library files for the Stack Exchange tag prediction task.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to enable `DEBUG` mode, reduce the dataset size (500 samples), set `EPOCHS` to 1, and redirect outputs to a temporary working directory. This ensures the script runs quickly and does not overwrite existing production artifacts. We also manually update dependent file path attributes in `Config` since they are initialized at import time.
2.  **Utility Verification**: We validate the `calculate_f1_samples` and `optimize_f1_threshold` functions using synthetic numpy arrays to ensure metric calculation logic is correct.
3.  **Data Processing Demonstration**: We invoke `process_data` to generate tokenized inputs and label vectors. We verify the shapes of the resulting arrays and test the `TokenizerHandler` and `TargetEncoder` classes to ensure they correctly encode/decode text and tags.
4.  **Model Architecture Verification**: We instantiate the `DilatedWideAndDeep` model with the modified configuration and perform a forward pass with a dummy batch. We assert that the output shape matches `(Batch_Size, Num_Classes)`.
5.  **Full Pipeline Execution**: We run the complete `run_pipeline` function from `library.train_eval`. This trains the model for one epoch on the debug subset and generates a submission file. We verify the existence and format of the output CSV.
