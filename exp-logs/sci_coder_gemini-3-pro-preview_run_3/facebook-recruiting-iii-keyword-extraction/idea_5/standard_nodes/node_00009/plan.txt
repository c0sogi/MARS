Implementation Strategy
1.  **Configuration**: I will modify the `Config` class attributes to enable `DEBUG` mode (limiting the dataset to 50,000 samples) and reduce `NUM_EPOCHS` to 5. This ensures the script runs as a fast baseline within the 2-hour limit. I will also adjust `BATCH_SIZE` to 128 to ensure sufficient gradient updates on the smaller dataset.
2.  **Setup**: I will initialize the random seeds, logger, and compute device using the provided utility functions.
3.  **Data Loading**: I will call `get_dataloaders` with `load_cached_data=True`. This will generate or load the preprocessed data (vocabulary, tokenized text, and binarized labels).
4.  **Model Training**: I will instantiate the `DualStreamTextCNN`, `BCEWithLogitsLoss`, `AdamW` optimizer, `OneCycleLR` scheduler, and `GradScaler`. I will then initialize the `Trainer` and execute the training loop via `trainer.fit()`.
5.  **Evaluation**: I will load the best model checkpoint and run inference on the validation set. I will optimize the probability threshold to maximize the F1-score and print the `Final Validation Metric`.
6.  **Failure Analysis**: I will calculate the per-sample error magnitude (defined as `1 - F1_score`) and compute its Pearson correlation with the lengths of the Title and Body inputs. These correlations will be printed to identify systematic errors.
7.  **Submission**: If the final validation metric exceeds the threshold of `0.33488`, I will run inference on the test set and generate the `submission.csv` file using the optimized threshold.
