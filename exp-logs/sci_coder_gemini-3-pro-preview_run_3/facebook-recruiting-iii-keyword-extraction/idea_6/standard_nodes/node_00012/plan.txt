The `ArrayMemoryError` occurs because the operation `(y_prob > thresh).astype(int)` creates a dense 64-bit integer array (`int64`) for the prediction matrix. For a validation set of ~1.1 million samples and 5,000 classes, this requires approximately 40.5 GB of contiguous memory ($1.1M \times 5000 \times 8$ bytes), which exhausts the available RAM.

To fix this, we will cast the boolean prediction mask to `np.int8` instead of the default `int`. This reduces the memory requirement by a factor of 8 (from 8 bytes to 1 byte per element), bringing the allocation down to a manageable ~5 GB (Cite debug_lesson_3). We will also cast the ground truth array `y_true` to `np.int8` to further conserve memory during the iterative threshold search.
