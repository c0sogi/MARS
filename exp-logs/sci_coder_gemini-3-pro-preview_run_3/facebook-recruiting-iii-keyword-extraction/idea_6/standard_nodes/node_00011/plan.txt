The `ArrayMemoryError` occurs because `MultiLabelBinarizer` creates a dense `int64` matrix by default. For the training set (4.3 million samples, 5000 classes), this intermediate matrix consumes approximately 174 GB of RAM ($4.3M \times 5000 \times 8$ bytes). When the code subsequently attempts to allocate another 20 GB for the `int8` version, the total memory requirement exceeds the available 220 GB. The fix is to configure `MultiLabelBinarizer` with `sparse_output=True`. This generates a memory-efficient sparse matrix first, which is then cast to `int8` and converted to a dense array, bypassing the creation of the massive `int64` dense matrix (Cite debug_lesson_3).
