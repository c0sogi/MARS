The issue is that the `Tokenizer` class and `_process_tags` function in `library/data_processing.py` rely on default arguments (like `Config.MAX_LEN` and `Config.TOP_K_TAGS`) that are evaluated only once at module import time. Even though `runfile.py` updates the `Config` values at runtime, the `Tokenizer` instantiation and function calls inside `prepare_data` continue to use the stale default values (Cite debug_lesson_2). To fix this, I will modify `library/data_processing.py` to explicitly pass the current configuration values (`Config.MAX_LEN`, `Config.VOCAB_SIZE`, `Config.MIN_FREQ`, and `Config.TOP_K_TAGS`) when instantiating `Tokenizer` and calling `_process_tags`.
