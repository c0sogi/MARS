The issue is that default arguments in Python functions and class constructors are evaluated only once at definition time (import time), not at call time. The `Tokenizer` class and `_process_tags` function use `Config` attributes (like `Config.MAX_LEN` and `Config.TOP_K_TAGS`) as default values. When `runfile.py` modifies these `Config` attributes at runtime, the `Tokenizer` instantiated without explicit arguments continues to use the old values captured at import, leading to shape mismatches and incorrect vocabulary sizes (Cite debug_lesson_2). To fix this, I will modify `library/data_processing.py` to explicitly pass the current `Config` values when instantiating `Tokenizer` and calling `_process_tags`.
