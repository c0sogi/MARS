The `FileNotFoundError` occurs because of a safety mechanism in `library/data.py`. When `config.DEBUG_SAMPLE_SIZE` is set (as it is in `runfile.py` for the demo), `prepare_data` intentionally skips saving the tokenizer and label encoder to disk to prevent overwriting the full dataset's cache with partial debug data. However, `runfile.py` asserts that these files must exist after training.

To fix this without compromising the safety logic in the shared library, I will modify `runfile.py` to manually save the tokenizer and encoder artifacts immediately after the training step. This ensures the files exist for the assertion check and potential inference use within the isolated demo environment.
