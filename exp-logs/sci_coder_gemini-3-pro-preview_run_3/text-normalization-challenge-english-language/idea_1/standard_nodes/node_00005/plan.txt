The error arises because `True * len(groupby_cols)` evaluates to an integer (since `True` is treated as `1` in arithmetic operations), and Python does not support adding an integer to a list (`[False]`). The intention is to create a list of boolean `True` values corresponding to the grouping columns. The fix is to wrap `True` in a list (`[True]`) before multiplying, which will perform list replication instead of integer multiplication.
