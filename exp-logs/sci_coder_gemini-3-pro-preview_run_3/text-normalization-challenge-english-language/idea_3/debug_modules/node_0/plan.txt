This script demonstrates the end-to-end usage of the provided text normalization library. It overrides the default configuration to run in "Debug Mode," ensuring rapid execution by using a small subset of data (1,000 samples) and a lightweight Transformer model (fewer layers, smaller dimensions, 1 epoch).

The implementation follows these steps:
1.  **Configuration**: Modifies `Config` to use a temporary working directory and reduced model complexity for speed.
2.  **Tokenizer Verification**: Demonstrates `CharTokenizer` functionality, including encoding, decoding, and special token handling.
3.  **Data Processing**: Validates `load_parquet_data` and context window generation (`prev`, `next` token alignment).
4.  **Symbolic Model**: Manually verifies the N-gram lookup logic (Trigram/Bigram/Unigram) using a synthetic dataframe.
5.  **Neural Model**: Instantiates the `TransformerSeq2Seq` model, validates input/output tensor shapes during a forward pass, and runs a short training loop via `train_neural_model`.
6.  **Inference Pipeline**: Executes the `HybridNormalizer` on the test set (subsampled) and generates a submission file, verifying the output format.
