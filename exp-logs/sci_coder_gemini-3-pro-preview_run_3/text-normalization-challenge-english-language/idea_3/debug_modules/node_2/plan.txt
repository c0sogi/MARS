The issue is that the `generate_submission` function uses `Config.SUBMISSION_PATH` as a default argument, which is evaluated once at module import time. When `runfile.py` updates `Config.SUBMISSION_PATH` at runtime, the function continues to use the stale path captured during import, causing the submission to be saved to the wrong location and triggering a `FileNotFoundError` during verification. To fix this, I will modify `generate_submission` to use `None` as the default argument and resolve `Config.SUBMISSION_PATH` dynamically inside the function body, ensuring the runtime value is used (Cite debug_lesson_2).
