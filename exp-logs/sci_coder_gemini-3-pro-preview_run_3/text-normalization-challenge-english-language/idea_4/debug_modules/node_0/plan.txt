The following script demonstrates the end-to-end usage of the provided text normalization library. It begins by configuring the environment for a rapid demonstration (reducing dataset size and model complexity). It then iteratively validates each component: the character tokenizer, the symbolic memory layer (N-gram statistics), the retrieval system (TF-IDF/KNN), the data loading pipeline, the neural network trainer, and finally the hybrid cascade inference system. Each section includes assertions to verify correctness.
