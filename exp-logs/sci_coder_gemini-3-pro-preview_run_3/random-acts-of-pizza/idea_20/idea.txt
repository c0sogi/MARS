# Solution Proposal: Tri-Modal Stacking with Manifold Regularization

Based on the comprehensive analysis of the "Lessons Learned," I propose a **Tri-Modal Stacking Ensemble with Manifold Regularization**. This architecture structurally evolves the "Symmetric Dual-Topology" approach (Idea 19) by introducing a third algorithmic paradigm—**Instance-Based Learning (k-Nearest Neighbors)**—to the dense modeling layer. This addresses the need for **Algorithmic Diversity** (Cite solution_lesson_node_00025) beyond just Bagging and Boosting. Additionally, it introduces explicit **Cross-Modal Interaction Features** to bridge the gap between text and behavior without violating the sparsity constraints (Cite solution_lesson_node_00009), and rigorously applies the **Validation-Guided Retraining** protocol (Cite solution_lesson_node_00027).

## Model

The architecture is a **Stacking Ensemble** composed of **six** "Level 1" base learners, organized into topology-specific branches that feed into a "Level 2" meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Augmented Global Metadata**.
        *   *Retention:* Random Forests on sparse TF-IDF consistently outperform dense methods for capturing specific keyword triggers (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with the **Augmented Global Metadata**.
        *   *Retention:* Treating user history as a "Bag-of-Concepts" document captures niche community memberships effectively (Cite solution_lesson_node_00018).

3.  **Dense Unified Branch (Semantic + Persona Modality)**
    *   **Input:** A unified dense vector containing **Frozen MPNet Text Embeddings**, **Frozen MPNet Behavior Embeddings**, and **Augmented Global Metadata**.
    *   **Learner A: Semantic Booster (XGBoost):** Captures non-linear decision boundaries and interactions in the dense space (Cite solution_lesson_node_00018).
    *   **Learner B: Semantic Bagger (Random Forest):** Captures structural patterns and provides stability (Cite solution_lesson_node_00025).
    *   **Learner C: Manifold Neighbor (kNN):** A **k-Nearest Neighbors Classifier** (using Cosine Similarity).
        *   *Innovation:* This introduces a distinct inductive bias (Instance-Based Learning) that exploits the local manifold structure of the embedding space. In small-sample regimes (~2,000 rows), retrieving similar historical "success stories" via semantic proximity provides a robust signal orthogonal to tree-based splits.

4.  **Contextual Branch (Linear Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Augmented Global Metadata**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

## Data

The data pipeline enforces strict leakage prevention, robust typing, and cross-modal feature engineering.

1.  **Leakage Prevention:**
    *   Source Text: `request_text_edit_aware` (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Cross-Modal Interaction (Innovation):** Calculate the **Cosine Similarity** between the user's **Text Embedding** (Current Request) and **Behavior Embedding** (History). This compact feature explicitly models the consistency between *what* the user is asking for and *who* they are (e.g., a "gamer" asking for "gaming" related pizza), allowing the sparse models to see this interaction without being flooded by dense embedding dimensions (Cite solution_lesson_node_00009).
    *   **Augmented Global Metadata:** User Stats (Age, Karma), Temporal Features, and the new **Interaction Feature**. Concatenate this to **all** base learners (Cite solution_lesson_node_00023). *Note:* Explicit text complexity features are excluded to reduce noise (Cite solution_lesson_node_00027).
    *   **Text Features:**
        *   *Sparse:* TF-IDF (Unigrams/Bigrams, Top 3,000) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
        *   *Dense:* Frozen `all-mpnet-base-v2` Embeddings (Cite solution_lesson_node_00015).
    *   **Behavioral Features:**
        *   *Sparse:* Robustly serialize `requester_subreddits_at_request` using duck typing (Cite solution_lesson_node_00017) -> TF-IDF.
        *   *Dense:* Serialize subreddits -> MPNet Embedding.
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs (Metadata and Embeddings) (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly to prevent alignment corruption (Cite solution_lesson_node_00024).

## Training

The training procedure implements the **Validation-Guided Retraining Protocol** to prevent overfitting.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear / kNN:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'` and `min_samples_leaf=2` for RFs.
    *   **XGBoost:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on OOF matrix.
4.  **Final Retraining:**
    *   **RF / Linear / kNN:** Retrain on the **Full Training Set** (Train + Validation).
    *   **XGBoost:** Retrain on the **Full Training Set** but explicitly pass the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" caused by fixed iteration counts (Cite solution_lesson_node_00027).

## Evaluation

1.  Process the test set to generate all feature views (Lexical, Behavioral, Embeddings, Metadata, Interaction).
2.  Pass specific views to the six base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
