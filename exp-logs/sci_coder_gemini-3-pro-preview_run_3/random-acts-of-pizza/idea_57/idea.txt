Based on the comprehensive empirical analysis of the "Lessons Learned," particularly the success of **Full-Spectrum Topology Matching** (Cite solution_lesson_node_00025), the critical importance of **Input Consistency** in stacking (Cite solution_lesson_node_00081), and the robustness of **Hybrid Inference** (Cite solution_lesson_node_00072), I propose a **Non-View Full-Spectrum Stacking Ensemble with Consistent Hybrid Inference**.

This solution structurally evolves the "Hept-View" architecture by expanding to **nine** base learners to achieve complete algorithmic symmetry: every modality (Text, History, Metadata) is modeled by both Linear and Non-Linear backbones. Crucially, it resolves the distribution mismatch identified in Lesson 00081 by performing Cross-Validation on the **union** of Training and Validation data, ensuring the meta-learner is trained on consistent OOF predictions while leveraging CV-Bagging for robust test-time inference.

# Model

The architecture is a **Stacking Ensemble** composed of **nine** "Level 1" base learners, organized into four topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger (RF):** Trained on **TF-IDF vectors of Concatenated Title and Edit-Aware Body** + Metadata.
        *   *Retention:* Concatenation maximizes signal (Cite solution_lesson_node_00044). Regularized (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).
    *   **Lexical Anchor (Linear):** A **Logistic Regression** model trained on the same sparse feature set.
        *   *Structural Innovation:* Adds a high-bias linear baseline to the strongest modality, capturing global separability and enhancing diversity (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger (RF):** Trained on **TF-IDF vectors of Subreddit History** + Metadata.
        *   *Retention:* Uses "Bag-of-Concepts" with **Top 1,000** vocabulary. Superior to dense embeddings for categorical sets (Cite solution_lesson_node_00029) and prevents overfitting (Cite solution_lesson_node_00042).
    *   **Community Anchor (Linear):** A **Logistic Regression** model trained on the same sparse feature set.
        *   *Structural Innovation:* Completes the symmetry. Provides a robust linear baseline for behavioral signals, stabilizing predictions if the tree model overfits sparse history.

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster (XGB):** Trained on **Frozen Compact Embeddings** + Metadata.
        *   *Retention:* Captures non-linear signals in continuous space (Cite solution_lesson_node_00018). Uses `scale_pos_weight` (Cite solution_lesson_node_00034).
    *   **Semantic Gradient (LGBM):** Trained on **Frozen Compact Embeddings** + Metadata.
        *   *Retention:* Provides algorithmic diversity via leaf-wise growth (Cite solution_lesson_node_00025).
    *   **Semantic Bagger (RF):** Trained on **Frozen Compact Embeddings** + Metadata.
        *   *Retention:* Provides structural diversity. Uses **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor (Linear):** A **Logistic Regression** model trained on **Augmented Global Metadata**.
        *   *Retention:* High-bias regularizer (Cite solution_lesson_node_00006).
    *   **Temporal Booster (Non-Linear):** A **LightGBM Classifier** trained on **Augmented Global Metadata**.
        *   *Retention:* Captures non-linear temporal drift via raw timestamps (Cite solution_lesson_node_00041).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Hygienic Feature Selection**.

1.  **Leakage Prevention:**
    *   **Source Text:** Use `request_text_edit_aware` exclusively (Cite solution_lesson_node_00062).
    *   **Exclusion:** Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Augmented Global Metadata:** Explicitly **Allow-List** (Cite solution_lesson_node_00030):
        *   **Raw Timestamp:** `unix_timestamp_of_request_utc` (Cite solution_lesson_node_00041).
        *   **User Stats:** Account Age, Karma, Total Post Counts.
        *   **Restored RAOP History:** Include `requester_number_of_posts_on_raop_at_request` etc. (Cite solution_lesson_node_00067).
        *   **Exclusion:** Exclude derived text length features (Cite solution_lesson_node_00027).
        *   *Note:* Concatenate this vector to **all** base learners (Cite solution_lesson_node_00023).
    *   **Text Concatenation:** Join `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00044).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs.
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

# Training

The training procedure implements a **Consistent Hybrid Inference Protocol** (Cite solution_lesson_node_00081, Cite solution_lesson_node_00072).

1.  **Dataset Merging:** Combine the provided Training and Validation sets into a single **Union Dataset**.
2.  **Fold Generation:** 5-Fold Stratified Cross-Validation on the Union Dataset.
3.  **Ensemble Training (Per Fold):**
    *   **Volatile Learners (XGBoost / LightGBM):** Train on 4 folds, using the **1 validation fold** for **Early Stopping**.
    *   **Stable Learners (RF / Linear):** Train on 4 folds.
    *   **OOF Generation:** Generate predictions for the validation fold.
    *   **Persistence:** Save all 9 models for this fold.
4.  **Meta-Learner Training:** Train on the full matrix of OOF predictions.
5.  **Stable Learner Retraining:** Train single instances of the Stable Learners (RF/Linear) on the full Union Dataset to maximize data usage (Cite solution_lesson_node_00044).

# Evaluation

1.  **Hybrid Inference:**
    *   **Volatile Branches:** Generate predictions using all 5 saved fold-models and **average** them (CV-Bagging). This reduces variance without the risk of blind retraining (Cite solution_lesson_node_00027).
    *   **Stable Branches:** Generate predictions using the single fully-retrained model.
2.  **Stacking:** Feed the resulting 9 probability scores to the Meta-Learner for the final prediction.
