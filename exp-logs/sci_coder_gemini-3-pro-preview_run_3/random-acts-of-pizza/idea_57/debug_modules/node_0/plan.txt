This script demonstrates the end-to-end execution of the provided stacking ensemble pipeline for the Random Acts of Pizza task.

### Implementation Strategy
1.  **Configuration Override**: To ensure the demonstration runs quickly (within the time limit) and uses minimal resources, we first modify the `Config` class attributes. We reduce the number of cross-validation folds to 2, limit the number of estimators (trees) for ensemble models to 10, and reduce iteration counts for linear models. We also redirect output directories to a specific demonstration folder in `./working`.
2.  **Data Preparation**: We use `data_factory.prepare_datasets` with `debug=True` to load a small random sample (100 rows) of the training and test data. This validates the data loading and merging logic without processing the full dataset.
3.  **Feature Engineering**: We instantiate the `FeatureManager` to generate Lexical (TF-IDF), Behavioral (Community History), Semantic (Embeddings), and Metadata features. We verify the output structure and shapes of the generated feature matrices.
4.  **Model Training (Stacking)**: We initialize the `HybridEnsembleTrainer`.
    *   **Level 1**: We run `train_level_1()` to perform Stratified CV, generating Out-of-Fold (OOF) predictions and saving volatile models (XGBoost/LightGBM) per fold.
    *   **Stable Retraining**: We run `retrain_stable_models()` to retrain stable learners (Random Forest, Logistic Regression) on the full training set for final inference.
    *   **Level 2**: We train the Meta-Learner (Logistic Regression) on the OOF predictions.
5.  **Inference and Submission**: We generate predictions for the test set using the hybrid inference strategy (bagging for volatile models, single model for stable ones) and save the results to a CSV file using `utils.save_submission`.
6.  **Validation**: Throughout the script, `assert` statements define the expected behavior (shapes, value ranges, file existence) to guarantee logic correctness.
