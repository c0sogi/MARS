Based on the empirical insights from the "Lessons" and "Previous Ideas", I propose a **Tri-View Stacking Ensemble with Fine-Tuned Semantics**. This solution structurally evolves the previous "Multi-Paradigm Stacking" approach by introducing a dedicated Deep Learning branch (replacing frozen embeddings with fine-tuning) and a specialized "Style" branch (replacing high-dimensional embeddings with explicit linguistic features).

# Model

The architecture is a **Stacking Ensemble** composed of three "Level 1" base learners, each targeting a specific modality of the data, feeding into a "Level 2" meta-learner.

**Level 1: Base Learners**
1.  **Lexical Bagger (Sparse View):** A **Random Forest Classifier** trained on **TF-IDF** vectors concatenated with **User Metadata**.
    *   *Rationale:* Retained from the previous best solution. Random Forests on sparse TF-IDF features provided the strongest predictive signal, outperforming dense embeddings (Cite 00013). This branch captures specific high-impact keywords (e.g., "paycheck", "rent") using the robustness of Bagging (Cite 00005).
2.  **Semantic Fine-Tuner (Deep View):** A **Transformer (e.g., DistilBERT)** fine-tuned end-to-end on the classification task using the raw request text.
    *   *Innovation:* Instead of using frozen, generic SBERT embeddings which were found to be weaker than TF-IDF (Cite 00013), this branch fine-tunes the encoder weights. This allows the model to learn task-specific semantic nuances (e.g., distinguishing "gratitude" from "desperation") that generic pre-trained models might miss.
3.  **Contextual Booster (Dense Style View):** An **XGBoost Classifier** trained on **User Metadata** concatenated with **Explicit Linguistic Features** (Sentiment, Readability, Punctuation stats).
    *   *Innovation:* The previous "Semantic Booster" (XGB on Embeddings) performed poorly because Gradient Boosting struggles with high-dimensional noisy vectors (Cite 00005). This component replaces embeddings with a compact set of engineered "style" features (e.g., subjectivity scores, text length, punctuation density), providing a dense, structured input that XGBoost can effectively leverage.

**Level 2: Meta-Learner**
*   **Stacking Classifier:** A **Logistic Regression** model that combines the probability outputs of the three base learners.
    *   *Rationale:* Stacking with a linear meta-learner was proven to effectively calibrate the contributions of diverse views, automatically upweighting the stronger Lexical signal while extracting residual value from the Semantic views (Cite 00012).

# Data

The data pipeline enforces strict leakage prevention and generates view-specific feature sets:

1.  **Leakage Prevention:** Use `request_text_edit_aware` as the source text and rigorously exclude all columns suffixed with `_at_retrieval` to ensure temporal validity (Cite 00003).
2.  **Feature Engineering:**
    *   **Lexical View:** Generate a **TF-IDF Matrix** (Top 3,000 unigrams/bigrams).
    *   **Deep View:** Tokenize raw text for the Transformer model.
    *   **Style View:** Extract explicit linguistic features: **Sentiment Polarity** and **Subjectivity** (via TextBlob/NLTK), **Character/Word Counts**, and **Punctuation Density** (e.g., frequency of "!" and "?").
    *   **Metadata:** Include `requester_account_age`, `requester_upvotes_minus_downvotes_at_request`, and derived temporal features (`request_hour`, `day_of_week`). Ensure all derived features are explicitly allow-listed (Cite 00007).
3.  **Preprocessing:**
    *   Impute missing numerical values with the median.
    *   Scale dense features (StandardScaler) only for the Style View if necessary (though XGBoost is robust to scale).

# Training

The training procedure utilizes **5-Fold Cross-Validation Stacking** to prevent leakage:

1.  **Fold Generation:** Split the training data into 5 stratified folds.
2.  **Level 1 Training (OOF Generation):**
    *   **Lexical RF:** Train on 4 folds, predict on the 5th. Use `class_weight='balanced'`.
    *   **Semantic Transformer:** Fine-tune on 4 folds (with early stopping based on validation loss) and predict on the 5th. This isolates the deep learning signal.
    *   **Contextual XGB:** Train on 4 folds, predict on the 5th.
3.  **Level 2 Training:** Train the Logistic Regression meta-learner on the collected Out-Of-Fold (OOF) predictions from all three branches.
4.  **Final Retraining:** Retrain all Level 1 models on the full training dataset. Retrain the Level 2 model on the full OOF matrix.

# Evaluation

For the test set:
1.  Process the test data to generate TF-IDF vectors, Tokenized sequences, and Linguistic/Metadata features.
2.  Pass the respective features to the fully trained Level 1 models to obtain three probability scores per sample.
3.  Feed these probabilities into the Level 2 Meta-Learner.
4.  The output is the final predicted probability for `requester_received_pizza`.
