Based on the comprehensive empirical analysis of the "Lessons Learned," particularly the critical importance of **Granular Signal Preservation** (Cite solution_lesson_node_00083), the necessity of **Input Consistency** in stacking (Cite solution_lesson_node_00081), and the value of **Algorithmic Diversity** (Cite solution_lesson_node_00025), I propose a **Deca-View Full-Spectrum Stacking Ensemble with Consistent Hybrid Inference**.

This solution structurally evolves the "Hept-View" architecture by expanding the ensemble to **ten** base learners. It re-integrates the **ExtraTrees Classifier** (previously attempted in Idea 56 but failed due to protocol mismatch) to maximize diversity in the dominant textual modality. Crucially, it applies the **Consistent Hybrid Inference Protocol** to resolve the distribution shift that plagued previous high-capacity ensembles.

# Model

The architecture is a **Stacking Ensemble** composed of **ten** "Level 1" base learners, organized into four topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Granular Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Title and Edit-Aware Body** combined with the **Augmented Global Metadata**.
        *   *Retention:* Concatenation maximizes signal (Cite solution_lesson_node_00044). Regularization (`min_samples_leaf=2`) prevents overfitting (Cite solution_lesson_node_00025).
    *   **Lexical Randomizer:** An **ExtraTrees Classifier** trained on the same feature set.
        *   *Structural Innovation:* Introduces a randomized decision tree ensemble. ExtraTrees selects split points randomly, providing a lower-variance estimator that complements the greedy optimization of Random Forests, enhancing **Algorithmic Diversity** (Cite solution_lesson_node_00025).
    *   **Lexical Anchor:** A **Logistic Regression** model trained on the same feature set.
        *   *Retention:* Adds a high-bias linear baseline to the strongest modality (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** combined with the **Augmented Global Metadata**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts" with a vocabulary limit of **Top 1,000** subreddits. This sparse representation is superior to dense embeddings for categorical sets (Cite solution_lesson_node_00029).
    *   **Community Anchor:** A **Logistic Regression** model trained on the same feature set.
        *   *Retention:* Provides a robust linear baseline for the behavioral signal.

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster (XGB):** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Correction:* We enforce **Conservative Boosting** (`learning_rate=0.01`, `colsample_bytree=0.6`) and explicitly use `scale_pos_weight` (Cite solution_lesson_node_00084).
    *   **Semantic Gradient (LGBM):** A **LightGBM Classifier** trained on the same features.
        *   *Retention:* Provides algorithmic diversity via leaf-wise growth (Cite solution_lesson_node_00025).
    *   **Semantic Bagger (RF):** A **Random Forest Classifier** trained on the same features.
        *   *Retention:* Provides structural diversity. We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor (Linear):** A **Logistic Regression** model trained on the **Augmented Global Metadata**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).
    *   **Temporal Booster (Non-Linear):** A **LightGBM Classifier** trained on the **Augmented Global Metadata**.
        *   *Retention:* Captures non-linear temporal drift via raw timestamps (Cite solution_lesson_node_00041).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Hygienic Feature Selection**.

1.  **Leakage Prevention:**
    *   **Source Text:** Use `request_text_edit_aware` exclusively (Cite solution_lesson_node_00062).
    *   **Exclusion:** Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Augmented Global Metadata:** Explicitly **Allow-List** (Cite solution_lesson_node_00030):
        *   **Raw Timestamp:** `unix_timestamp_of_request_utc` (Cite solution_lesson_node_00041).
        *   **Restored RAOP History:** Include `requester_number_of_posts_on_raop_at_request` etc. (Cite solution_lesson_node_00067).
        *   **User Stats:** Account Age, Karma, Post Counts.
        *   **Exclusion:** Exclude derived text length features (Cite solution_lesson_node_00027).
        *   *Note:* Concatenate this vector to **all** base learners (Cite solution_lesson_node_00023).
    *   **Text Concatenation:** Join `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00044).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) with `sublinear_tf=True`, `min_df=2` (Open Vocabulary, Cite solution_lesson_node_00090), and `token_pattern=r"\w{1,}"` (Granular Tokenization, Cite solution_lesson_node_00083).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Union Strategy:** Merge the provided Training and Validation sets into a single **Union Dataset** for the entire pipeline (Cite solution_lesson_node_00081).
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs.

# Training

The training procedure implements a **Consistent Hybrid Inference Protocol** to resolve the conflict between early stopping and data utilization (Cite solution_lesson_node_00072, Cite solution_lesson_node_00081).

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation on the **Union Dataset**.
2.  **Ensemble Training (Per Fold):**
    *   **Volatile Learners (XGBoost / LightGBM):** Train on 4 folds, using the **1 validation fold** for **Early Stopping**.
        *   *Correction:* Explicitly set `load_best_model_at_end=True` and pass the validation set to `fit()` to ensure the optimal state is restored (Cite solution_lesson_node_00087).
    *   **Stable Learners (RF / ExtraTrees / Linear):** Train on 4 folds.
    *   **OOF Generation:** Generate predictions for the validation fold.
    *   **Persistence:** Save all 10 models for this fold.
3.  **Meta-Learner Training:** Train on the full matrix of OOF predictions from the Union Dataset.
4.  **Stable Learner Retraining:** Train single instances of the Stable Learners on the full Union Dataset to maximize data usage (Cite solution_lesson_node_00044).

# Evaluation

1.  **Hybrid Inference:**
    *   **Volatile Branches:** Generate predictions using all 5 saved fold-models and **average** them (CV-Bagging). This reduces variance without the risk of blind retraining (Cite solution_lesson_node_00027).
    *   **Stable Branches:** Generate predictions using the single fully-retrained model.
2.  **Stacking:** Feed the resulting 10 probability scores to the Meta-Learner for the final prediction.
