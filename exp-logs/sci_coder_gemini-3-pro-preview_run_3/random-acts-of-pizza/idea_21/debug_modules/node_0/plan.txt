This script demonstrates the full execution of the Hex-View Stacking Ensemble pipeline. To ensure the demonstration runs quickly and correctly handles the data flow, the script performs the following steps:

1.  **Configuration Override**: It modifies the global configuration to use a temporary working directory and reduces model hyperparameters (e.g., number of trees, folds) for speed.
2.  **Data Subsampling**: It creates a consistent, small subset of the training, validation, and test metadata files. It then updates the configuration paths to point to these subsets. This ensures that the `StackingTrainer` (which reads the test file from disk to retrieve IDs) aligns perfectly with the generated features.
3.  **Pipeline Execution**: It sequentially executes the `DataCleaner`, `FeatureExtractor`, and `StackingTrainer` components.
4.  **Verification**: It includes assertions to verify feature shapes, data types, and the successful generation of the submission file.
