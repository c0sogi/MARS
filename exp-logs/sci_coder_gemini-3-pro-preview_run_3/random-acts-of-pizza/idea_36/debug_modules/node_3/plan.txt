The issue is that the `XGBClassifier` ("SemanticBooster") is initialized with `early_stopping_rounds` in the configuration, which mandates the presence of an `eval_set` during training. However, in the cross-validation loop within `StackingTrainer.run`, the `.fit()` method is called without providing a validation dataset, triggering a `ValueError`.

To fix this, I will modify `library/stacking_trainer.py` to:
1.  Extract the validation targets (`y_val_fold`) for the current fold.
2.  Pass the validation fold (`X_sem_xgb_val`, `y_val_fold`) as the `eval_set` to the `SemanticBooster.fit` call.

This solution aligns with **Cite debug_lesson_14**, which highlights that constructor-defined early stopping requires an explicit validation set or must be disabled. Since validation data is available in the CV loop, providing it is the correct approach.
