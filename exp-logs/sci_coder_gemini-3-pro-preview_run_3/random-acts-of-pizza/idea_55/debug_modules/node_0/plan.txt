The following script demonstrates the end-to-end execution of the provided machine learning pipeline. It utilizes the library modules to load data, extract features (lexical, behavioral, semantic, and metadata), train a hybrid stacking ensemble (combining stable and volatile strategies), and generate predictions.

To ensure the demonstration runs quickly within the time limit, the script dynamically overrides the default configuration to use a smaller subset of the data (100 samples), fewer cross-validation folds (2 folds), and reduced model complexity (fewer trees/iterations). It includes assertions at key stages to verify data integrity, feature shapes, and the generation of valid submission files.
