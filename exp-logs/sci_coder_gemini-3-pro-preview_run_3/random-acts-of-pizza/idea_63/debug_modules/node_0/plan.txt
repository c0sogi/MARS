This script demonstrates the end-to-end execution of the Hept-View architecture for the Random Acts of Pizza task. It performs the following steps:

1.  **Configuration Patching**: Modifies the global `Config` to use a temporary working directory, reduces the number of cross-validation folds to 2, and drastically lowers model hyperparameters (e.g., `n_estimators=10`) to ensure the script completes quickly (under 5 minutes).
2.  **Data Loading**: Uses `DataFactory` to load a small debug subset (200 training samples, 50 test samples) of the Union and Test datasets.
3.  **Feature Engineering**: Instantiates `FeaturePipeline` to generate the four required feature sets: Augmented Metadata, Granular Lexical (TF-IDF), Behavioral (Community TF-IDF), and Semantic Dense (Embeddings).
4.  **Model Training & Inference**: Initializes the `HybridEnsembleEngine` with the generated features. It executes the Level 1 Cross-Validation (generating OOF predictions), trains the Level 2 Meta-Learner, retrains stable models on the full dataset, and generates final predictions for the test set.
5.  **Validation**: Asserts that all expected output files (OOF predictions, submission file, model artifacts) are created and that the submission follows the correct format.
