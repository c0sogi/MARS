Based on the comprehensive empirical analysis and the "Lessons Learned," specifically the metric consistency paradox (Cite solution_lesson_node_00034), the validation leakage in early stopping (Cite solution_lesson_node_00035), and the architectural success of the Pent-View topology (Cite solution_lesson_node_00025), I propose a **Robust Pent-View Stacking Ensemble with Nested Internal Validation**.

This solution structurally evolves the previous best-performing architecture (Idea 27) by implementing a **Nested Validation Protocol**. This innovation resolves the critical flaw where previous iterations either "peeked" at the hold-out set for early stopping (causing metric inflation) or trained blindly (causing overfitting), ensuring that the high-capacity XGBoost learners are optimized without data leakage.

# Model

The architecture is a **Stacking Ensemble** composed of **five** "Level 1" base learners, organized into three topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Global Metadata Vector**.
        *   *Retention:* Random Forests on sparse TF-IDF consistently outperform dense methods for capturing specific high-impact keywords (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent the overfitting observed in unregularized sparse models (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with the **Global Metadata Vector**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts" document. This sparse representation is superior to dense embeddings for unordered categorical sets (Cite solution_lesson_node_00029) and captures niche community signals effectively (Cite solution_lesson_node_00018).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Retention:* Gradient Boosting excels at extracting non-linear signals from dense, continuous embeddings (Cite solution_lesson_node_00018). We maintain high capacity (2,000 estimators) (Cite solution_lesson_node_00022) but control it via the new Nested Validation protocol.
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Retention:* Using both Bagging and Boosting on the same dense view provides significant lift by capturing diverse structural patterns (Cite solution_lesson_node_00025).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer based on robust heuristics (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Positive Feature Selection**.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Global Metadata Vector:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) a curated set of dense features: User Stats (Age, Karma) and Temporal Features. Concatenate this to **all** base learners to preserve cross-modal interactions (Cite solution_lesson_node_00023).
        *   *Correction:* Explicitly **exclude** derived text length features (e.g., character count), as they were found to be noisy and correlated with prediction error (Cite solution_lesson_node_00027).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams, Top 3,000) with `sublinear_tf=True` and `min_df=5` to ensure robust scaling (Cite solution_lesson_node_00024).
        *   *Text:* From request text.
        *   *History:* From robustly serialized subreddit list using duck typing (Cite solution_lesson_node_00017).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim). We use this compact model instead of larger variants to avoid the curse of dimensionality in this small-sample regime (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation for numerical columns.
    *   **Scaling:** `StandardScaler` applied to dense inputs (Metadata and Embeddings) (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly to prevent alignment corruption (Cite solution_lesson_node_00024).

# Training

The training procedure implements the **Nested Internal Validation Protocol** to resolve the conflict between early stopping and data leakage (Cite solution_lesson_node_00035).

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation for the Stacking loop.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'` and `min_samples_leaf=2`.
    *   **XGBoost (The Innovation):** For each Stacking fold (where we have 4 training folds), perform an **Internal Split** (e.g., 90% Train / 10% Internal-Val). Train the XGBoost model on the 90% and use the 10% Internal-Val for **Early Stopping**. Then, predict on the 5th Stacking fold (OOF). This ensures the OOF predictions are generated by a model tuned on data strictly disjoint from the test fold, preventing the bias seen in Idea 15.
3.  **Level 2 Training:** Train Meta-Learner on the unbiased OOF matrix.
4.  **Final Retraining:**
    *   **RF / Linear:** Retrain on the **Full Training Set**.
    *   **XGBoost:** Retrain on the **Full Training Set**. To determine the optimal stopping point without a hold-out set, use the **average optimal iteration count** derived from the 5 internal folds in step 2. This avoids the need to "peek" at the final test/validation set (Cite solution_lesson_node_00027).

# Evaluation

1.  Process the test set to generate all feature views (Lexical, Behavioral, Semantic, Metadata).
2.  Pass specific views to the five base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
