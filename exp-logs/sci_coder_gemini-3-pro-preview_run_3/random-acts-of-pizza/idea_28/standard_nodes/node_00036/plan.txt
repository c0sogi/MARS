The implementation strategy follows the architecture defined in the provided library files. 
1.  **Setup**: Initialize the environment with a fixed seed for reproducibility.
2.  **Data Loading**: Use `load_datasets` to retrieve the training, validation, and test dataframes, leveraging caching where available.
3.  **Feature Generation**: Use `generate_features` to create the four feature views (Lexical, Behavioral, Semantic, Metadata) for all splits. This handles TF-IDF vectorization, embedding generation via SentenceTransformers, and metadata scaling.
4.  **Model Training**: Instantiate the `NestedStackingTrainer`.
    *   Execute `train_cv()` to perform 5-fold cross-validation, generating Out-of-Fold (OOF) predictions while using nested internal validation to tune the XGBoost component without leakage.
    *   Execute `train_meta_learner()` to train the Level 2 Logistic Regression on the OOF predictions.
    *   Execute `retrain_full_models()` to retrain all Level 1 base learners on the full training set using the optimal hyperparameters found during CV.
5.  **Validation**: Generate predictions on the hold-out validation set using the fully trained ensemble. Calculate and print the Area Under the ROC Curve (AUC) as the `Final Validation Metric`.
6.  **Failure Analysis**: Calculate the prediction error on the validation set. Compute the correlation between this error and the numerical input features to identify sources of systematic bias.
7.  **Submission**: If the validation AUC exceeds the specified threshold, generate predictions for the test set and save them to `submission.csv` in the required format.
