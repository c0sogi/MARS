Based on the lessons learned, I propose a **Multi-Paradigm Stacking Ensemble** that structurally evolves the previous "Multi-View" approach. This solution addresses the high-dimensional sparse/dense conflict by strictly segregating feature views and introduces a meta-learning layer to optimally combine diverse algorithmic inductive biases.

# Model
I propose a **Stacking Ensemble** architecture composed of three distinct "Level 1" base learners and one "Level 2" meta-learner. This design explicitly separates sparse and dense text representations (Cite 00009) and combines the robustness of Bagging with the precision of Boosting.

**Level 1: Base Learners**
1.  **Lexical Bagger (Sparse View):** A **Random Forest Classifier** trained on **TF-IDF** vectors concatenated with **User Metadata**.
    *   *Rationale:* Random Forests are proven to outperform Boosting on high-dimensional sparse data (Cite 00005). This branch captures specific keyword interactions (e.g., "paycheck", "rent") that might be smoothed out by embeddings.
2.  **Semantic Bagger (Dense View A):** A **Random Forest Classifier** trained on **SBERT Embeddings** concatenated with **User Metadata**.
    *   *Rationale:* This preserves the strongest individual component from the previous solution (Cite 00009). It leverages the semantic understanding of pre-trained transformers while maintaining the stability of bagging.
3.  **Semantic Booster (Dense View B):** An **XGBoost Classifier** trained on **SBERT Embeddings** concatenated with **User Metadata**.
    *   *Rationale:* While Boosting struggled with sparse TF-IDF data (Cite 00005), it is state-of-the-art for dense, structured data. Applying XGBoost to the dense embeddings and metadata introduces algorithmic diversity (Boosting vs. Bagging) to the semantic view.

**Level 2: Meta-Learner**
*   **Stacking Classifier:** A **Logistic Regression** model that takes the probability outputs of the three base learners as input features to predict the final target.
    *   *Rationale:* Instead of simple averaging (Soft Voting), a meta-learner mathematically determines the optimal weight for each branch. This automatically mitigates the impact of weaker learners (Cite 00010) without requiring manual pruning.

# Data
The data pipeline will be strictly "edit-aware" and structurally segregated:

1.  **Leakage Prevention:** Use `request_text_edit_aware` as the source text and drop all columns suffixed with `_at_retrieval` to ensure temporal validity (Cite 00003).
2.  **Feature Engineering:**
    *   **Text Representations:** Generate two parallel representations: a **TF-IDF Matrix** (Top 3,000 unigrams/bigrams) for the Lexical branch, and **SBERT Embeddings** (384-dimensional dense vectors) for the Semantic branches (Cite 00009).
    *   **Metadata Expansion:** Explicitly calculate and **allow-list** derived features: `request_hour`, `request_day_of_week`, `request_word_count`, and `requester_account_age_in_days_at_request`. This ensures these new signals are not silently discarded by the feature selector (Cite 00007).
3.  **Preprocessing:**
    *   Impute missing numerical values with the median.
    *   No feature scaling is applied to the base learners (Trees/Boosting), but the predictions fed into the Level 2 Logistic Regression will be standardized if necessary.

# Training
The training process utilizes **Cross-Validation Stacking** to prevent data leakage during ensemble construction:

1.  **K-Fold Cross-Validation:** The training set is split into 5 folds.
2.  **OOF Generation:** For each fold, the Level 1 models are trained on the remaining 4 folds and predict on the current fold. These "Out-Of-Fold" (OOF) predictions form the training data for the Level 2 Meta-Learner.
3.  **Full Retraining:** After generating OOF predictions, the Level 1 models are retrained on the full training dataset for final inference.
4.  **Class Imbalance:** All Level 1 models will utilize class weighting (e.g., `class_weight='balanced'` for RF, `scale_pos_weight` for XGBoost) to address the ~25% positive class prevalence.

# Evaluation
For the test set:
1.  Generate TF-IDF, Embeddings, and Metadata features using the transformers fitted on the full training set.
2.  Pass the specific feature subsets to their respective Level 1 models (Lexical Bagger, Semantic Bagger, Semantic Booster) to obtain three probability scores per sample.
3.  Feed these three probabilities into the trained Level 2 Meta-Learner.
4.  The output of the Meta-Learner is the final predicted probability for `requester_received_pizza`.
