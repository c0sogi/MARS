The following script demonstrates the complete pipeline for the Pizza Request Success Prediction task using the provided library. It performs the following steps:

1.  **Configuration Override**: Modifies global settings to run on a small subset of data with reduced model complexity for rapid execution.
2.  **Data Processing**: Loads raw data, performs feature engineering, and imputes missing values.
3.  **Feature Extraction**: Generates two views of the data: a Lexical View (TF-IDF + Metadata) and a Semantic View (SBERT Embeddings + Metadata).
4.  **Stacking Ensemble Training**: Runs Cross-Validation to train Level 1 base learners (Random Forest, XGBoost) and the Level 2 Meta-Learner (Logistic Regression).
5.  **Retraining**: Retrains base learners on the full training set.
6.  **Inference**: Generates predictions for the test set.
7.  **Submission**: Formats and saves the final predictions.

Validation checks are included at each stage to ensure data integrity and model correctness.
