This script demonstrates the end-to-end execution of the Hex-View Stacking Ensemble pipeline for the Random Acts of Pizza task. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to enable `DEBUG` mode (using a small subset of data) and reduces model hyperparameters (e.g., number of trees) to ensure the script executes rapidly (under 60 seconds).
2.  **Data Loading**: Uses `DataLoader` to load and preprocess the training, validation, and test datasets. It forces a reload from raw metadata to apply the debug sampling.
3.  **Feature Engineering**: Uses `FeatureEngineer` to generate four distinct feature views:
    *   **Lexical**: TF-IDF vectors of the request text.
    *   **Behavioral**: TF-IDF vectors of subreddit history.
    *   **Semantic**: Dense embeddings from a pre-trained Transformer.
    *   **Metadata**: Scaled numerical features (account age, karma, etc.).
4.  **Ensemble Training**: Uses `EnsembleTrainer` to:
    *   Generate Out-of-Fold (OOF) predictions for Level 1 base models.
    *   Train the Level 2 Logistic Regression meta-learner.
    *   Retrain all Level 1 base models on the full training + validation data (or using early stopping).
5.  **Submission Generation**: Generates final predictions for the test set and saves the submission file.
6.  **Verification**: Includes assertions to validate data shapes, file outputs, and pipeline integrity.
