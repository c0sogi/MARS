Based on the critical "Lessons Learned," particularly the discovery of **Target Leakage via Post-Hoc Edits** (Cite solution_lesson_node_00062), the breakthrough success of **Textual Field Concatenation** (Cite solution_lesson_node_00044), and the necessity of **Raw Temporal Anchors** (Cite solution_lesson_node_00041), I propose a **Leakage-Robust Hex-View Stacking Ensemble with Temporal-Regime Profiling**.

This solution structurally evolves the "Pent-View" architecture by enforcing strict data hygiene (using edit-aware text), restoring valid metadata signals that were inadvertently pruned, and introducing a **Non-Linear Temporal Branch** to capture complex community drift.

# Model

The architecture is a **Stacking Ensemble** composed of **six** "Level 1" base learners, organized into four topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Title and Edit-Aware Body** combined with the **Global Metadata Vector**.
        *   *Correction:* We strictly use `request_text_edit_aware` to eliminate the leakage found in previous high-scoring solutions (Cite solution_lesson_node_00062).
        *   *Retention:* Concatenating Title + Body maximizes signal (Cite solution_lesson_node_00044). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** combined with the **Global Metadata Vector**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts." We strictly limit the vocabulary to the **Top 1,000** subreddits to prevent overfitting (Cite solution_lesson_node_00042) and maintain the superiority of sparse representations for categorical sets (Cite solution_lesson_node_00029).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster (XGB):** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Edit-Aware Body)** combined with Metadata.
        *   *Retention:* Captures non-linear signals in the continuous semantic space (Cite solution_lesson_node_00018). We use `scale_pos_weight` (Cite solution_lesson_node_00034) and maintain high capacity (2,000 estimators).
    *   **Semantic Bagger (RF):** A **Random Forest Classifier** trained on **Frozen Compact Embeddings (Title + Edit-Aware Body)** combined with Metadata.
        *   *Retention:* Provides structural diversity (Cite solution_lesson_node_00025). We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) to prevent memorization of dense noise (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor (Linear):** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).
    *   **Temporal Booster (Non-Linear):** A **LightGBM Classifier** trained on the **Global Metadata Vector**.
        *   *Structural Innovation:* Unlike the linear anchor, this tree-based model can split on the **Raw Timestamp** to identify specific temporal regimes (e.g., "Pre-2012 vs. Post-2012") and non-linear interactions between user stats (Cite solution_lesson_node_00041). This recovers the temporal signal lost when relying solely on linear models.

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Positive Feature Selection**.

1.  **Leakage Prevention:**
    *   **Strict Text Source:** Use `request_text_edit_aware` exclusively for all text processing. Do not touch `request_text` (Cite solution_lesson_node_00062).
    *   **Exclusion:** Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Text Concatenation:** Join `request_title` and `request_text_edit_aware` into a single string (Cite solution_lesson_node_00044).
    *   **Global Metadata Vector:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) a curated set of dense features:
        *   **Raw Timestamp:** Include `unix_timestamp_of_request_utc`. This is critical for capturing non-cyclic temporal drift (Cite solution_lesson_node_00041).
        *   **User Stats:** Account Age, Karma, Post Counts.
        *   **Interaction Counters:** Restore valid pre-request counters (e.g., `requester_number_of_posts_on_raop_at_request`) which were inadvertently pruned in previous cleanup attempts (Cite solution_lesson_node_00062).
        *   **Exclusion:** Explicitly exclude derived text length features as they are noisy proxies (Cite solution_lesson_node_00027).
        *   *Note:* Concatenate this vector to **all** base learners (Cite solution_lesson_node_00023).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) derived from the concatenated text (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs (Metadata and Embeddings) (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly to prevent alignment corruption (Cite solution_lesson_node_00024).

# Training

The training procedure implements the **Validation-Guided Retraining Protocol** to prevent overfitting while maximizing data usage.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation on the Training partition.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'`.
    *   **XGBoost / LightGBM:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on the OOF matrix.
4.  **Final Retraining:**
    *   **RF / Linear:** Retrain on the **Full Training Set** (Train + Validation). This maximizes data for the stable learners (Cite solution_lesson_node_00044).
    *   **XGBoost / LightGBM:** Retrain on the **Training Set only**, explicitly passing the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" caused by using fixed iteration counts derived from CV (Cite solution_lesson_node_00027) and avoids the instability of nested validation on small data (Cite solution_lesson_node_00036).

# Evaluation

1.  Process the test set to generate all feature views (Lexical, Behavioral, Semantic, Metadata).
2.  Pass specific views to the six base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
