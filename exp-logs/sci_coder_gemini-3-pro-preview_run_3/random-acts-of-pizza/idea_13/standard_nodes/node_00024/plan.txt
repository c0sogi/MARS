Implementation strategy:
1.  **Setup and Configuration**: Import necessary libraries and the provided modules. Explicitly set random seeds for reproducibility.
2.  **Data Preparation**: Use the `DataPreparer` class to load and preprocess the training, validation, and test datasets. This handles feature extraction (Lexical, Behavioral, Semantic) and caching.
3.  **Model Training**: Initialize the `StackingEnsemble`. Train it using the processed training data. The ensemble automatically handles cross-validation for the meta-learner and final retraining on the full training set.
4.  **Validation**: Generate predictions on the hold-out validation set. Compute the ROC AUC score and print it in the required format.
5.  **Failure Analysis**: Calculate the absolute prediction error on the validation set. compute the Pearson correlation between this error and the raw numerical features (loaded from the validation metadata) to identify which features correlate with model failure.
6.  **Submission**: Check if the validation score exceeds the specified threshold. If so, generate predictions for the test set and save the submission file using the provided utility function.
