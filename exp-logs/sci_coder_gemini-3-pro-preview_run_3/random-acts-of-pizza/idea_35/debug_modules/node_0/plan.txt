The following script demonstrates the complete pipeline for the Pizza Request Success Prediction task using the provided library files.

**Implementation Strategy:**
1.  **Configuration Patching**: To ensure the demonstration runs quickly (within the time limit) and uses minimal resources, we first monkey-patch the `Config` class. We reduce the number of cross-validation folds to 2, limit vocabulary sizes for TF-IDF, and drastically reduce the number of estimators (trees) for Random Forest and XGBoost models.
2.  **Data Processing**: We utilize `data_manager.get_processed_data` to load the stratified metadata (parquet files) and perform initial text construction (concatenating titles, bodies, and subreddit history).
3.  **Feature Engineering**: We initialize the `FeaturePipeline` to generate three types of features:
    *   **Sparse**: TF-IDF vectors for unified, lexical, and community text views.
    *   **Dense**: Semantic embeddings using a pre-trained SentenceTransformer (MiniLM).
    *   **Metadata**: Scaled numerical features extracted from the raw data.
4.  **Model Training & Stacking**: We instantiate the `TrainingEngine`, which orchestrates:
    *   **Level 1**: Training base models (RF, XGB, LR) on the generated features using 2-fold CV to produce Out-of-Fold (OOF) predictions.
    *   **Level 2**: Training a Logistic Regression meta-learner on the stacked OOF predictions.
    *   **Retraining**: Retraining base models on the full training set (using validation data for early stopping where applicable).
5.  **Submission**: Generating predictions for the test set and saving the final `submission.csv`.
6.  **Verification**: Throughout the script, assertions verify data shapes, file existence, and pipeline integrity.
