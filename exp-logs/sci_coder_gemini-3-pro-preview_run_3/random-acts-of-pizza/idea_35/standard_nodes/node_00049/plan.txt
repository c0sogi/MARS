The solution implements the `runfile.py` script to orchestrate the Unified Interaction-Aware Stacking Ensemble pipeline.

**Implementation Strategy:**
1.  **Setup & Imports**: Import necessary classes from the provided `library` modules (`Config`, `Timer`, `FeaturePipeline`, `TrainingEngine`, `ModelZoo`, `data_manager`). Set random seeds for reproducibility.
2.  **Data & Features**: Load the processed data using `get_processed_data` with caching enabled. Generate feature views (Sparse, Semantic, Metadata) using `FeaturePipeline`.
3.  **Level 1 Training (CV)**: Use `TrainingEngine` to run 5-fold Cross-Validation on the training set. This produces Out-of-Fold (OOF) predictions required for the meta-learner.
4.  **Level 2 Training**: Train the Meta-Learner (Logistic Regression) on the OOF predictions.
5.  **Hold-Out Validation**:
    *   To strictly evaluate the model on the hold-out validation set (`val.parquet`), we manually train the Level 1 base learners on the full training set.
    *   We generate predictions on the validation set using these models.
    *   We stack these predictions and pass them to the trained Meta-Learner to compute the final `Final Validation Metric`.
6.  **Failure Analysis**: Compute the absolute error of predictions on the validation set and calculate the correlation between the error and each metadata feature to identify failure modes.
7.  **Submission Logic**: Compare the validation AUC against the threshold (0.7138293787137718).
    *   If the metric is sufficient, trigger `TrainingEngine.retrain_base_models` (which optimally uses the validation set for retraining/early stopping) and `generate_submission` to create the final `submission.csv`.
