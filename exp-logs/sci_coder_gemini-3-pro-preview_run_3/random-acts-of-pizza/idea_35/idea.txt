Based on the rigorous empirical analysis of the "Lessons Learned," particularly the breakthrough success of **Textual Field Concatenation** (Cite solution_lesson_node_00044), the failure of dense interaction features (Cite solution_lesson_node_00042), and the necessity of **Raw Temporal Anchors** (Cite solution_lesson_node_00041), I propose a **Unified Interaction-Aware Stacking Ensemble**.

This solution structurally evolves the "Pent-View" architecture by introducing a **Unified Sparse Branch**. Instead of "siloing" text and history or relying on weak dense interaction features (like cosine similarity), this branch physically concatenates Request Text and User History into a single sparse document. Crucially, it applies **Token Prefixing** to the history terms to prevent namespace collisions, allowing the Random Forest to learn explicit cross-modal rules (e.g., "IF 'paycheck' in text AND 'sub_borrow' in history") directly.

# Model

The architecture is a **Stacking Ensemble** composed of **six** "Level 1" base learners, organized into three topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Unified Sparse Branch (Structural Innovation)**
    *   **Interaction Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Document (Title + Body + Prefixed History)** combined with the **Global Metadata Vector**.
        *   *Rationale:* By merging modalities into a single sparse view, we enable the tree model to discover non-linear interactions between user intent and community behavior (Cite solution_lesson_node_00023). This replaces the failed dense interaction features (Cite solution_lesson_node_00042).

2.  **Specialized Sparse Branches (Retention)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of (Title + Body)** + Metadata.
        *   *Retention:* Captures pure textual signals without noise from history (Cite solution_lesson_node_00044). Regularized with `min_samples_leaf=2` (Cite solution_lesson_node_00025).
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of (Subreddit History)** + Metadata.
        *   *Retention:* Captures pure persona signals. We strictly limit the vocabulary to the **Top 1,000** subreddits to prevent overfitting to rare communities (Cite solution_lesson_node_00042).

3.  **Dense Semantic Branch (Retention)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Body)** + Metadata.
        *   *Retention:* Captures non-linear signals in the continuous semantic space (Cite solution_lesson_node_00018). We use `scale_pos_weight` (Cite solution_lesson_node_00034) and maintain high capacity (2,000 estimators) (Cite solution_lesson_node_00022).
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings (Title + Body)** + Metadata.
        *   *Retention:* Provides structural diversity (Cite solution_lesson_node_00025). We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) to prevent memorization of dense noise (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Retention)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Positive Feature Selection**.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Unified Document Construction (Innovation):**
        *   Step 1: Concatenate `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00044).
        *   Step 2: Serialize `requester_subreddits_at_request` (Cite solution_lesson_node_00017) and apply a **prefix** (e.g., `sub_`) to each subreddit name.
        *   Step 3: Join Text and Prefixed History into a single string.
    *   **Global Metadata Vector:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) a curated set of dense features:
        *   **Raw Timestamp:** Include `unix_timestamp_of_request_utc` to capture temporal drift (Cite solution_lesson_node_00041).
        *   **User Stats:** Account Age, Karma, Post Counts.
        *   **Exclusion:** Explicitly exclude derived text length features (Cite solution_lesson_node_00027).
        *   *Note:* Concatenate this vector to **all** base learners (Cite solution_lesson_node_00023).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) derived from Title+Body. We use this compact model to avoid the curse of dimensionality (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs (Metadata and Embeddings) (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

# Training

The training procedure implements the **Validation-Guided Retraining Protocol** to prevent overfitting while maximizing data usage.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation on the Training partition.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'`.
    *   **XGBoost:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on the OOF matrix.
4.  **Final Retraining:**
    *   **RF / Linear:** Retrain on the **Full Training Set** (Train + Validation). This maximizes data for the stable learners (Cite solution_lesson_node_00044).
    *   **XGBoost:** Retrain on the **Training Set only**, explicitly passing the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" caused by using fixed iteration counts derived from CV (Cite solution_lesson_node_00027) and avoids the instability of nested validation on small data (Cite solution_lesson_node_00036).

# Evaluation

1.  Process the test set to generate all feature views (Unified, Lexical, Behavioral, Semantic, Metadata).
2.  Pass specific views to the six base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
