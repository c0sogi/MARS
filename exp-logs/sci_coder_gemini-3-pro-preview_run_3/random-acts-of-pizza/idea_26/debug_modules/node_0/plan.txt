### Implementation Strategy

1.  **Configuration Override**: To ensure the demonstration runs quickly (as per the "Optimize for Speed" requirement), I will dynamically modify the hyperparameters in the imported `library.config` module. I will reduce the number of estimators for Random Forests and XGBoost to 10 and limit the sample size of the data to 100 rows.
2.  **Data Loading**: I will use `library.data_loader.load_data` with the `sample_size` argument to load a small subset of the training, validation, and test data.
3.  **Feature Engineering**: I will instantiate `library.feature_engineering.ViewBuilder`, fit it on the training data, and transform all splits (train, val, test) into the four required views (Metadata, Lexical, Behavioral, Semantic). I will verify the integrity of these views (shapes and types) using assertions.
4.  **Model Training**: I will instantiate `library.training_engine.StackingTrainer` and run the `fit` method. This demonstrates the full pipeline: 5-fold CV for OOF generation, Meta-Learner training, and Validation-Guided Retraining of base learners.
5.  **Prediction & Submission**: I will use the trained ensemble to generate predictions on the test view and save the results using `save_predictions`.
6.  **Validation**: Finally, I will verify that the submission file exists, contains the correct number of rows, and that predictions are valid probabilities.
