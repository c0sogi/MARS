The following script demonstrates the complete pipeline for the Random Acts of Pizza prediction task using the provided library modules.

**Strategy:**
1.  **Configuration Overrides**: We dynamically modify the global `config` object to reduce the computational load. We lower the number of cross-validation folds to 2 and reduce the number of estimators/iterations for all models (Random Forest, XGBoost, LightGBM, Logistic Regression) to ensure the script completes quickly.
2.  **Feature Engineering**: We instantiate the `FeaturePipeline` to generate Lexical (TF-IDF), Behavioral (Community Bag-of-Concepts), Semantic (Embeddings), and Contextual (Metadata) features. We explicitly disable cache loading to demonstrate the actual feature generation logic.
3.  **Data Validation**: We assert that the generated feature matrices have the correct dimensions and types (sparse vs. dense) before proceeding.
4.  **Model Training (Hept-View Ensemble)**: We initialize the `EnsembleEngine` with the generated data. It performs the Hybrid Inference Protocol:
    *   Runs 2-Fold CV on "volatile" models (Gradient Boosting) to generate OOF predictions.
    *   Retrains "stable" models (Random Forest, Linear) on the full dataset.
    *   Trains a Level-2 Meta-Learner (Logistic Regression) on the stacked OOF predictions.
5.  **Submission**: We generate predictions for the test set and verify the output file's format and existence.
