The error `TypeError: XGBClassifier.fit() got an unexpected keyword argument 'early_stopping_rounds'` arises because in XGBoost 3.0.5, the `early_stopping_rounds` parameter must be passed to the model constructor (`__init__`) rather than the `fit()` method. I will modify `library/ensemble_pipeline.py` to instantiate `semantic_booster` with `early_stopping_rounds` via the factory function (which passes kwargs to the constructor) and remove the argument from the `fit()` calls. This ensures the configuration is applied in the correct API scope (Cite debug_lesson_10).
