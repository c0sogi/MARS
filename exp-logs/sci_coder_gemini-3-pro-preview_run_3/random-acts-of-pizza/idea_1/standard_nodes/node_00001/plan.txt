The implementation strategy involves orchestrating the machine learning pipeline using the provided library modules. First, the script will initialize the environment and random seeds for reproducibility. It will then load the preprocessed training, validation, and test datasets using the `load_processed_data` function, which handles caching and feature engineering (TF-IDF vectorization and numerical imputation). The `PizzaSuccessModel` (Random Forest) will be instantiated and trained on the training data.

After training, the script will perform inference on the validation set to compute the Area Under the ROC Curve (AUC). This metric will be printed in the specific required format. Following validation, a failure analysis will be conducted by calculating the absolute prediction errors on the validation set and computing the Pearson correlation coefficient between these errors and the numerical input features. This identifies which features are most associated with model inaccuracies. Finally, the model will generate predictions for the test set, and the results will be saved to the submission CSV file using the `save_submission` utility.
