    *   Replace `RF_PARAMS` with `XGB_PARAMS`, configured with regularization (shallow depth, subsampling) and GPU acceleration (`device="cuda"`).
2.  **`library/model.py`**: 
    *   Replace `RandomForestClassifier` with `xgboost.XGBClassifier`.
    *   Implement **early stopping** using the validation set to prevent overfitting.
3.  **`runfile.py`**: 
    *   Add the conditional logic to only generate a submission if the Validation AUC exceeds the baseline of `0.6556`.
