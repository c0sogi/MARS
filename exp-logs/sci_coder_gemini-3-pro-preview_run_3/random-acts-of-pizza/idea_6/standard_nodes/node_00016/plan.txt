This script orchestrates the full machine learning pipeline for the Random Acts of Pizza prediction task. It begins by setting reproducible seeds and loading the dataset using the provided data loader, leveraging caching for efficiency. It then generates three distinct feature views (Lexical, Semantic, and Community) using the feature pipeline. The `TriViewStackingEnsemble` is initialized and trained on these features. Post-training, the script evaluates the model on the hold-out validation set, printing the required metric. It performs a failure analysis by correlating prediction errors with input features to diagnose weaknesses. Finally, it conditionally generates and saves the test set submission if the validation performance meets the specified threshold.
