The issue is that the `clean_data` function in `library/data_loader.py` drops the target column (`requester_received_pizza`) from the validation set because it relies on the `is_train` flag to decide whether to keep the target. The validation set is processed with `is_train=False` (to use training medians), causing the target to be dropped before it can be extracted in `load_data`. This is a schema mismatch where the validation set is treated as a pure inference set too early (Cite debug_lesson_1). The fix is to modify `clean_data` to preserve the target column whenever it is present in the dataframe, regardless of the `is_train` flag.
