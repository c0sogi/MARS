The following implementation demonstrates the complete pipeline for the Pizza Request Success Prediction task using the provided library.

**Implementation Strategy:**
1.  **Configuration Override**: We first modify the global `Config` class to drastically reduce the computational load for the demonstration. This includes reducing the number of cross-validation folds to 2 and limiting the number of estimators (trees) in all Random Forest, XGBoost, and LightGBM models to minimal values (e.g., 2-10). This ensures the code runs within the time limit while exercising all code paths.
2.  **Data & Feature Verification**: We explicitly call `DataFactory` and `FeatureGenerator` to verify that data loading and feature engineering (including text embeddings and TF-IDF) function correctly and produce matrices of expected shapes.
3.  **Full Training Pipeline**: We instantiate `CrossValidationTrainer` to execute the Level 1 (Base Learners) and Level 2 (Meta-Learner) training. This saves the trained models to the working directory.
4.  **Inference Pipeline**: We instantiate `HybridPredictor` to load the saved models and generate predictions for the test set.
5.  **Validation**: Throughout the process, assertions are used to verify file existence, data shapes, and prediction integrity.
