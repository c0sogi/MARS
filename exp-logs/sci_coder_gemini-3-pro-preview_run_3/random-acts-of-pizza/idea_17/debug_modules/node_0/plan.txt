implementation strategy
The following script demonstrates the usage of the provided machine learning pipeline for predicting pizza request success. It is divided into two main demonstration functions:

1.  **`demo_high_level_api`**: This function showcases the primary entry point, the `Predictor` class. It initializes the predictor in debug mode (using a small subset of data for speed), executes the full pipeline (feature engineering, stacking ensemble training, and inference), and validates the generation and format of the submission file.

2.  **`demo_low_level_api`**: This function breaks down the pipeline into its constituent components (`FeaturePipeline`, `ModelFactory`, `StackingTrainer`). It demonstrates how to manually generate specific feature views, instantiate the trainer with these views, and execute the training and prediction steps. This serves to verify the internal logic and data flow of the architecture.

The script ensures reproducibility by setting a fixed random seed and manages the environment by cleaning up temporary artifacts (cache and submission files) between runs to prevent state leakage.
