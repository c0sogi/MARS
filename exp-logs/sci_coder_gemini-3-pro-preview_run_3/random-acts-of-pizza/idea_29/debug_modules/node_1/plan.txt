The error occurs because `pd.read_parquet` often deserializes list columns as NumPy arrays rather than Python lists. The existing code checks `isinstance(x, list)`, which evaluates to `False` for these arrays, causing the code to fall through to `pd.notnull(x)`. When `x` is an array, `pd.notnull(x)` returns a boolean array, triggering the "ambiguous truth value" `ValueError` in the conditional check. To fix this, I will update the type check to include `np.ndarray`, ensuring that array-like collections are correctly processed by `" ".join(x)`.
