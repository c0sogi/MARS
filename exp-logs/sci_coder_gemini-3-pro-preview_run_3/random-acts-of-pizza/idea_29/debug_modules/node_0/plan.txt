This script demonstrates the usage of the provided library components for the Random Acts of Pizza prediction task. It follows a two-part structure:
1.  **Component-Level Demonstration**: Manually instantiates `DataLoader`, `FeatureEngineer`, and `PentViewEnsemble` to verify data flow, feature shapes, and model training logic on a small data subset.
2.  **Workflow-Level Demonstration**: Uses the `WorkflowManager` to execute the full Cross-Validation Bagging pipeline and generate a submission file, ensuring the end-to-end process functions correctly.

To ensure rapid execution, the script overrides configuration parameters (reducing dataset size, number of estimators, and cross-validation folds) before initialization.
