Based on the comprehensive empirical analysis of the "Lessons Learned," particularly the critical trade-offs regarding **Retraining Protocols** (Cite solution_lesson_node_00027, Cite solution_lesson_node_00036), **Feature Dimensionality** (Cite solution_lesson_node_00028), and **Algorithmic Diversity** (Cite solution_lesson_node_00025), I propose a **Pent-View Stacking Ensemble with Cross-Modal Consistency and CV-Bagging Inference**.

This solution structurally evolves the high-performing "Pent-View" architecture by introducing a **Cross-Modal Consistency** feature to bridge the semantic gap between user history and request text without exploding dimensionality. Crucially, it replaces the fragile "Final Retraining" step with a robust **CV-Bagging Inference** strategy, effectively resolving the conflict between early stopping requirements and data utilization.

# Model

The architecture is a **Stacking Ensemble** composed of **five** "Level 1" base learners, organized into three topology-matched branches (Sparse, Dense, Linear). These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Global Metadata Vector**.
        *   *Retention:* Random Forests on sparse TF-IDF consistently outperform dense methods for capturing specific high-impact keywords (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with the **Global Metadata Vector**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts" document. This sparse representation is superior to dense embeddings for unordered categorical sets (Cite solution_lesson_node_00029) and captures niche community signals effectively (Cite solution_lesson_node_00018).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Retention:* Gradient Boosting excels at extracting non-linear signals from dense, continuous embeddings (Cite solution_lesson_node_00018). We maintain high capacity (2,000 estimators) (Cite solution_lesson_node_00022).
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Retention:* Using both Bagging and Boosting on the same dense view provides significant lift by capturing diverse structural patterns (Cite solution_lesson_node_00025).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer based on robust heuristics (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Positive Feature Selection**.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Cross-Modal Consistency (Innovation):** Calculate the **Cosine Similarity** between the **Text Embedding** (Request) and the **History Embedding** (Subreddits).
        *   *Rationale:* This scalar feature captures the semantic alignment between "what the user wants" and "who the user is" (e.g., a gamer posting in gaming subreddits) without exposing the model to the noise of high-dimensional history embeddings (Cite solution_lesson_node_00028).
    *   **Global Metadata Vector:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) User Stats (Age, Karma), Temporal Features, and the new **Consistency Feature**. Concatenate this to **all** base learners (Cite solution_lesson_node_00023).
        *   *Correction:* Explicitly **exclude** derived text length features, as they are noisy proxies (Cite solution_lesson_node_00027).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams, Top 3,000) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs.
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

# Training

The training procedure replaces the risky "Final Retraining" with a **CV-Bagging Inference Protocol** to resolve the conflict between early stopping and data utilization (Cite solution_lesson_node_00036).

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Ensemble Training (Per Fold):**
    *   For each fold $k$ (Training on 4 folds, Validation on 1 fold):
        *   **XGBoost:** Train on the 4 training folds, using the **Validation Fold ($k$)** for **Early Stopping**. This ensures the model is optimally tuned without "peeking" at a test set (Cite solution_lesson_node_00027).
        *   **RF / Linear:** Train on the 4 training folds.
        *   **Meta-Learner:** Train on the OOF predictions generated by these models.
    *   **Persistence:** Save the fully trained ensemble (L1 + L2) for Fold $k$.
3.  **No Blind Retraining:** Do *not* retrain a single final model on the full dataset. This avoids the risk of underfitting (due to small nested validation sets) or overfitting (due to fixed iteration counts) (Cite solution_lesson_node_00036).

# Evaluation

1.  **Multi-Model Inference:** Pass the test data through **all 5 saved fold-ensembles**.
2.  **Aggregation:** Average the probability outputs from the 5 ensembles to produce the final prediction. This effectively utilizes 100% of the training data for inference (via bagging) while maintaining rigorous early stopping for every component model.
