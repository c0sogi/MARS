The implementation strategy follows a structured pipeline approach leveraging the provided library modules.

1.  **Setup and Initialization**: The script begins by setting the random seed for reproducibility and ensuring the Python path includes the working directory for module resolution.
2.  **Data Processing**: It utilizes the `DataPipeline` class to load and process the dataset. The `load_cached_data=True` flag is used to prioritize loading pre-computed features from the `./working` directory, ensuring efficiency.
3.  **Ensemble Training**: The `PentViewStackingEnsemble` is instantiated and fitted on the training data. This class encapsulates the 5-fold cross-validation logic for the Level 1 base learners (Lexical, Behavioral, Semantic, and Contextual views) and the training of the Level 2 Logistic Regression meta-learner.
4.  **Validation**: Predictions are generated for the hold-out validation set. The ROC AUC score is calculated and printed in the specific format required (`Final Validation Metric: <value>`).
5.  **Failure Analysis**: The script calculates the absolute prediction errors on the validation set. It then computes the Pearson correlation between these errors and the global numerical metadata features to identify which attributes are most strongly associated with model failure. The top 5 correlated features are reported.
6.  **Submission**: Finally, the validation AUC is compared against the strict threshold of `0.6913548345419015`. If the model's performance exceeds this benchmark, predictions are generated for the test set, formatted according to the sample submission, and saved to `./submission/submission.csv`.
