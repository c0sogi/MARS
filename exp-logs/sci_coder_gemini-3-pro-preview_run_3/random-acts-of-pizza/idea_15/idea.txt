# Solution Proposal: Pent-View Hybrid-Topology Stacking Ensemble

### Model
I propose a **Pent-View Hybrid-Topology Stacking Ensemble**. This architecture synthesizes the strongest elements of previous iterations by strictly aligning algorithmic inductive biases with data topology (Sparse vs. Dense) while restoring the algorithmic diversity and regularization that were lost in recent attempts.

The ensemble consists of five "Level 1" base learners, each processing a specific view of the data but sharing a global context, feeding into a "Level 2" meta-learner.

1.  **Lexical Bagger (Sparse Text View):** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Global Metadata Vector**.
    *   *Rationale:* Random Forests consistently outperform Boosting on high-dimensional sparse text (Cite solution_lesson_node_00005). By concatenating metadata, we ensure the model captures interactions between specific keywords and user status (Cite solution_lesson_node_00023).
    *   *Correction:* We explicitly apply regularization (e.g., `min_samples_leaf > 1`) to prevent the overfitting observed when default parameters were used on this high-dimensional view (Cite solution_lesson_node_00025).
2.  **Behavioral Bagger (Sparse History View):** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with the **Global Metadata Vector**.
    *   *Rationale:* Treating user history as a "Bag-of-Concepts" document provides a stronger signal than dense SVD reduction (Cite solution_lesson_node_00018). We use Bagging to handle the sparsity.
3.  **Semantic Booster (Dense Embedding View):** An **XGBoost Classifier** trained on **Frozen SBERT Embeddings** concatenated with the **Global Metadata Vector**.
    *   *Rationale:* Gradient Boosting excels at extracting non-linear signals from dense, continuous embeddings (Cite solution_lesson_node_00018). We use frozen embeddings to prevent overfitting (Cite solution_lesson_node_00015).
4.  **Semantic Bagger (Dense Embedding View):** A **Random Forest Classifier** trained on **Frozen SBERT Embeddings** concatenated with the **Global Metadata Vector**.
    *   *Rationale:* We restore this component from the "Current Best" solution. Previous experiments showed that using *both* RF and XGB on the semantic view provides significant lift because they capture different structural patterns (diversity) in the dense space (Cite solution_lesson_node_00025).
5.  **Contextual Baseline (Dense Linear View):** A **Logistic Regression** model trained exclusively on the **Global Metadata Vector**.
    *   *Rationale:* This provides a high-bias "anchor" based solely on robust heuristics (account age, karma), acting as a regularizer for the ensemble (Cite solution_lesson_node_00006).

**Level 2 Meta-Learner:**
*   **Logistic Regression:** A linear model to optimally calibrate the ensemble weights (Cite solution_lesson_node_00012).

### Data
The data pipeline enforces strict leakage prevention, robust typing, and global context availability.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Global Metadata Vector:** Explicitly generate and **allow-list** (Cite solution_lesson_node_00007) a comprehensive set of dense features (User Stats, Temporal, Text Complexity). This vector is concatenated to **all five** base learners (Cite solution_lesson_node_00023).
    *   **Lexical View:** TF-IDF Matrix (Unigrams/Bigrams, Top 3,000) from request text. Use `sublinear_tf=True` and `min_df=5` for robust scaling.
    *   **Behavioral View:** Robustly serialize `requester_subreddits_at_request` using duck typing (Cite solution_lesson_node_00017) into a string, then generate a TF-IDF Matrix (Unigrams, Top 1,000).
    *   **Semantic View:** Extract **Frozen SBERT Embeddings** (384-dim) (Cite solution_lesson_node_00015).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation for numerical columns.
    *   **Scaling:** Apply `StandardScaler` to the **Global Metadata Vector** before concatenation. This is mandatory for the XGBoost and Linear branches (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly to prevent alignment corruption (Cite solution_lesson_node_00024).

### Training
The training procedure utilizes **5-Fold Cross-Validation Stacking** with high-capacity base learners (Cite solution_lesson_node_00022).

1.  **Fold Generation:** Split training data into 5 stratified folds.
2.  **Level 1 Training (OOF Generation):**
    *   **Lexical & Behavioral RFs:** Train on 4 folds, predict on the 5th. Use `class_weight='balanced'` and `min_samples_leaf=2` (Cite solution_lesson_node_00025).
    *   **Semantic XGB:** Train on 4 folds, predict on the 5th. Use `scale_pos_weight` and early stopping.
    *   **Semantic RF:** Train on 4 folds, predict on the 5th. Use `class_weight='balanced'`.
    *   **Contextual LogReg:** Train on 4 folds, predict on the 5th.
3.  **Level 2 Training:** Train the Logistic Regression meta-learner on the matrix of Out-Of-Fold (OOF) predictions.
4.  **Final Retraining:** Retrain all Level 1 models on the full training dataset and the Level 2 model on the full OOF matrix.

### Evaluation
1.  Process the test set to generate the feature views and Global Metadata Vector.
2.  Pass the specific feature subsets to their respective Level 1 models to obtain five probability scores per sample.
3.  Feed the aggregated probabilities into the Level 2 Meta-Learner to generate the final prediction.
