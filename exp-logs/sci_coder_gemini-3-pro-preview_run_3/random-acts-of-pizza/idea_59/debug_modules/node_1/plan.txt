Instead, this metric should be configured via the model constructor or the `.set_params()` method (Cite debug_lesson_10). I will update `library/models.py` to conditionally set `eval_metric` using `set_params` for XGBoost models, while retaining the existing argument passing for LightGBM models where it may still be supported or handled differently.
