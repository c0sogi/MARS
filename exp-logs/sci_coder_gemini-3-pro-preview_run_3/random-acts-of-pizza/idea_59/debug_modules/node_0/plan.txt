The following script demonstrates the complete pipeline for the pizza request prediction task. It leverages the provided library modules to load data, generate features (metadata, lexical, behavioral, and semantic), train a stacked ensemble of models, and produce a submission file.

To ensure the demonstration runs quickly within the time limit, the script first modifies the configuration to reduce the number of cross-validation folds and model estimators. It then executes the pipeline steps sequentially, verifying the outputs at each stage.
