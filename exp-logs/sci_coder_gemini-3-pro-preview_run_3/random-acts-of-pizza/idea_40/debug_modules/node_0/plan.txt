The following script demonstrates the usage of the provided machine learning pipeline components. It performs the following steps:
1.  **Configuration Patching**: Overrides default `Config` settings to use a temporary directory and reduces hyperparameters (e.g., `n_estimators`, `n_folds`) to ensure the demo runs quickly.
2.  **Data Processing**: Loads the metadata and cleans the text/tabular features using `process_data`. It then subsets the data to a small sample size for speed.
3.  **Feature Extraction**: Uses `FeatureFactory` to generate Lexical (TF-IDF), Behavioral (Subreddit history), Semantic (Embeddings), Metadata, and Latent Interaction features. It asserts that the output shapes correspond to the sampled data.
4.  **Model Validation**: Instantiates each Level 1 model (Random Forests, XGBoost, LightGBM, Logistic Regression), fits them on the sampled data, and verifies that `predict_proba` returns valid probabilities.
5.  **Workflow Execution**: Runs the `CrossValidator` to generate Out-Of-Fold predictions and the `FinalRetrainer` to stack the models using the `MetaLearner` and generate a final submission file.
