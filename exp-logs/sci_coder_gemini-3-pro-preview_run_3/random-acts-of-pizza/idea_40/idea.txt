Based on the rigorous empirical analysis of the "Lessons Learned," particularly the failure of **Early Fusion** due to vocabulary contention (Cite solution_lesson_node_00049), the failure of **Scalar Target Encoding** for behavioral history (Cite solution_lesson_node_00055), and the breakthrough success of **Textual Field Concatenation** (Cite solution_lesson_node_00044), I propose a **Hex-View Stacking Ensemble with Latent Cross-Modal Interaction**.

This solution structurally evolves the high-performing "Pent-View" architecture by introducing a dedicated **Latent Interaction Branch**. This branch utilizes **Truncated SVD** to project both the Sparse Text and Sparse History views into a shared low-rank dense space, enabling a **LightGBM** classifier to learn non-linear interactions between "what is requested" and "who is asking" without the dimensionality issues of sparse concatenation or the information loss of scalar encoding.

# Model

The architecture is a **Stacking Ensemble** composed of **six** "Level 1" base learners, organized into four topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Title and Body** (Cite solution_lesson_node_00044) combined with the **Global Metadata Vector**.
        *   *Retention:* Random Forests on sparse TF-IDF consistently outperform dense methods for capturing specific high-impact keywords (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** combined with the **Global Metadata Vector**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts." We strictly limit the vocabulary to the **Top 1,000** subreddits to prevent overfitting (Cite solution_lesson_node_00042) and maintain the superiority of sparse representations for categorical sets (Cite solution_lesson_node_00029).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Retention:* Captures non-linear signals in the continuous semantic space (Cite solution_lesson_node_00018). We use `scale_pos_weight` (Cite solution_lesson_node_00034) and maintain high capacity (2,000 estimators) controlled via early stopping.
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Retention:* Provides structural diversity (Cite solution_lesson_node_00025). We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) to prevent memorization of dense noise (Cite solution_lesson_node_00038).

4.  **Latent Interaction Branch (Structural Innovation)**
    *   **Interaction Booster:** A **LightGBM Classifier** trained on a **Unified Low-Rank Dense Vector** (SVD_Text + SVD_History) combined with Metadata.
        *   *Innovation:* We apply **Truncated SVD** separately to the Text TF-IDF and History TF-IDF matrices to extract latent components (e.g., 32 dimensions each). Concatenating these creates a compact, dense representation.
        *   *Rationale:* This allows a gradient boosting model to learn specific cross-modal rules (e.g., "User in 'Financial' cluster AND Request about 'Rent'") that are missed by the siloed sparse models (Cite solution_lesson_node_00023) and the high-dimensional embeddings. We use **LightGBM** to introduce algorithmic diversity alongside XGBoost (Cite solution_lesson_node_00025).

5.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Positive Feature Selection**.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Text Concatenation:** Join `request_title` and `request_text_edit_aware` (Cite solution_lesson_node_00044).
    *   **Global Metadata Vector:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) Raw Timestamp (`unix_timestamp_of_request_utc`) to capture temporal drift (Cite solution_lesson_node_00041) and User Stats. Explicitly **exclude** derived text length features as they are noisy (Cite solution_lesson_node_00027).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Embeddings:** Frozen `all-MiniLM-L6-v2` (384-dim) (Cite solution_lesson_node_00028).
    *   **Latent Interaction Features:**
        *   Compute Truncated SVD (n=32) on the Text TF-IDF matrix.
        *   Compute Truncated SVD (n=32) on the History TF-IDF matrix.
        *   Concatenate these 64 dense features with the Metadata vector for the Interaction Booster.
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs.
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

# Training

The training procedure implements the **Validation-Guided Retraining Protocol**.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation on the Training partition.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'`.
    *   **XGBoost / LightGBM:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on the OOF matrix.
4.  **Final Retraining:**
    *   **RF / Linear:** Retrain on the **Full Training Set** (Train + Validation) to maximize data usage (Cite solution_lesson_node_00044).
    *   **XGBoost / LightGBM:** Retrain on the **Training Set only**, explicitly passing the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" caused by using fixed iteration counts derived from CV (Cite solution_lesson_node_00027).

# Evaluation

1.  Process the test set to generate all feature views (Lexical, Behavioral, Semantic, Latent Interaction, Metadata).
2.  Pass specific views to the six base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
