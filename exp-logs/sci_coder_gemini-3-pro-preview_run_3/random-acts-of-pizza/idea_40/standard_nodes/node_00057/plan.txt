The strategy involves a rigorous validation pipeline followed by a production retraining phase. First, we load the pre-processed data and generate all feature views (Lexical, Behavioral, Semantic, Metadata, Latent Interaction) using the provided `FeatureFactory`. We then execute the `CrossValidator` to generate Out-Of-Fold (OOF) predictions on the training set, which are used to train the Level 2 Meta-Learner.

To compute the required "Final Validation Metric" on the hold-out validation set without leakage, we train a temporary set of Level 1 models strictly on the training data (using an internal split for early stopping where necessary) and generate predictions for the validation set. These are fed into the Meta-Learner to produce the final validation probabilities and AUC score. We then perform failure analysis by correlating prediction errors with metadata features.

Finally, if the validation AUC exceeds the specified threshold, we execute the `FinalRetrainer`. This component retrains the models using the full available data (Train + Validation) to maximize performance for the test set submission, ensuring the best possible result is saved to `submission.csv`.
