The following script demonstrates the end-to-end usage of the provided machine learning library. It performs the following steps:
1.  **Setup**: Configures the environment and seeds for reproducibility.
2.  **Data Loading**: Uses `load_datasets` with `debug=True` to load a small subset of the data for rapid execution and verification.
3.  **Feature Engineering**: Instantiates the `FeatureEngineer` to transform raw text and metadata into Lexical (TF-IDF), Semantic (SBERT embeddings), and Community (SVD) features.
4.  **Ensemble Training**: Calls `train_ensemble` to perform stratified cross-validation, train base learners (Random Forest, XGBoost), and train a stacking meta-learner (Logistic Regression).
5.  **Inference**: Generates predictions on the test set using the trained ensemble.
6.  **Submission**: Saves the final predictions to a CSV file using `save_submission`.

Assertions are included throughout to verify data shapes, feature integrity, and prediction validity.
