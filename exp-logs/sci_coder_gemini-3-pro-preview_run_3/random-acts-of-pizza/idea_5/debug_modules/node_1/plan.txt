The issue arises because the `TfidfVectorizer` for community features is initialized with `min_df=2`, meaning a subreddit must appear in at least two requests to be included in the vocabulary. In debug mode, where the dataset is subsampled to only 100 entries, it is highly likely that no subreddit meets this frequency threshold, causing the vectorizer to prune all tokens and raise an empty vocabulary error. To fix this, I will modify `library/features.py` to dynamically set `min_df` to 1 when running in debug mode, ensuring features are generated even for small sample sizes.
