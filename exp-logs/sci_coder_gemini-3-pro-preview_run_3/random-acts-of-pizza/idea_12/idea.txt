# Solution Proposal: High-Capacity Topology-Matched Stacking Ensemble

### Model
I propose a **High-Capacity Topology-Matched Stacking Ensemble**. This architecture synthesizes the strongest components of previous iterations into a unified system that strictly aligns algorithmic inductive biases with data topology (Sparse vs. Dense) while correcting the capacity constraints that caused recent failures.

The model consists of three "Level 1" base learners feeding into a "Level 2" meta-learner:

1.  **Lexical Bagger (Sparse Text View):** A **Random Forest Classifier** trained on **TF-IDF** vectors of the request text concatenated with user metadata.
    *   *Rationale:* Random Forests consistently outperform Boosting on high-dimensional sparse text data (Cite solution_lesson_node_00005). This branch captures specific high-impact keywords (Cite solution_lesson_node_00013).
2.  **Behavioral Bagger (Sparse History View):** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with user metadata.
    *   *Rationale:* Treating user history as a sparse "Bag-of-Concepts" document provides a stronger signal than dense SVD reduction (Cite solution_lesson_node_00018). We assign a Random Forest here to handle the high-dimensional sparse nature of this view, correcting the misalignment in Idea 10 (which used XGBoost for behavior).
3.  **Semantic Booster (Dense Context View):** An **XGBoost Classifier** trained on **Frozen SBERT Embeddings** concatenated with **Augmented Metadata** (User Stats + Text Complexity Features).
    *   *Rationale:* We explicitly restore **XGBoost** for the dense embedding view. Previous experiments showed that replacing XGBoost with Random Forest for dense embeddings caused a performance drop (Cite solution_lesson_node_00018). This branch captures non-linear interactions in the dense semantic space.
    *   *Correction:* Unlike Idea 11, which reduced model capacity to fit this third view, we will maintain **High Capacity** (e.g., high `n_estimators`) for all learners, as reducing capacity to accommodate feature expansion was proven to be detrimental (Cite solution_lesson_node_00022).

**Level 2 Meta-Learner:**
*   **Logistic Regression:** A linear model to calibrate the contributions of the three views (Cite solution_lesson_node_00012).

### Data
The data pipeline enforces strict leakage prevention and robust feature engineering:

1.  **Leakage Prevention:**
    *   Source text: `request_text_edit_aware` (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Lexical View:** TF-IDF Matrix (Unigrams/Bigrams, Top 3,000) from request text.
    *   **Behavioral View:** Robustly serialize the `requester_subreddits_at_request` list (using duck typing to handle arrays, Cite solution_lesson_node_00017) into a space-separated string, then generate a TF-IDF Matrix (Unigrams, Top 1,000).
    *   **Semantic View:** Extract **Frozen SBERT Embeddings** (384-dim) (Cite solution_lesson_node_00015).
    *   **Augmented Metadata:** Explicitly calculate and **allow-list** (Cite solution_lesson_node_00007) text complexity features: **Word Count**, **Sentence Count**, and **Sentiment Polarity**. These are fed into the Dense XGBoost branch to help it distinguish "effort" from "semantics".
3.  **Preprocessing:**
    *   **Imputation:** Median imputation for numerical columns.
    *   **Scaling:** Apply `StandardScaler` *only* to the dense inputs of the Semantic Booster (XGBoost) and the Level 2 Meta-Learner. The Random Forests do not require scaling.

### Training
The training procedure utilizes **5-Fold Cross-Validation Stacking**:

1.  **Fold Generation:** Split the training data into 5 stratified folds.
2.  **Level 1 Training (OOF Generation):**
    *   **Lexical & Behavioral RFs:** Train on 4 folds, predict on the 5th. Use `class_weight='balanced'` and **n_estimators=500** (High Capacity).
    *   **Semantic XGB:** Train on 4 folds, predict on the 5th. Use `scale_pos_weight` and **n_estimators=1000** (High Capacity) with early stopping.
3.  **Level 2 Training:** Train the Logistic Regression meta-learner on the matrix of Out-Of-Fold (OOF) predictions.
4.  **Final Retraining:** Retrain all Level 1 models on the full training dataset and the Level 2 model on the full OOF matrix.

### Evaluation
1.  Process the test set to generate the three specific feature views (Lexical TF-IDF, Behavioral TF-IDF, Semantic Dense) using the transformers fitted on the training set.
2.  Pass each view to its corresponding Level 1 model to obtain probability scores.
3.  Feed the aggregated probabilities into the Level 2 Meta-Learner to generate the final `requester_received_pizza` probability.
