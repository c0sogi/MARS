This script demonstrates the end-to-end execution of the pizza request prediction pipeline using the provided library files. It first monkey-patches the global configuration to reduce computational load (fewer epochs, smaller ensembles, fewer folds) for a rapid demonstration. It then runs the training pipeline on a small subset of data (`debug_size=50`) to generate feature artifacts and train both Level 1 base models and the Level 2 meta-learner. Finally, it executes the inference pipeline to generate predictions and verifies the output submission file's validity.
