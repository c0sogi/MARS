Based on the comprehensive empirical analysis of the "Lessons Learned," particularly the breakthrough finding regarding **Textual Field Concatenation** (Cite solution_lesson_node_00044), the necessity of **Vocabulary Constraints** for behavioral data (Cite solution_lesson_node_00042), and the critical importance of **Raw Temporal Anchors** (Cite solution_lesson_node_00041), I propose an **Enhanced-Text Pent-View Stacking Ensemble with Validation-Guided Inference**.

This solution structurally evolves the robust "Pent-View" architecture (Idea 15/32) by integrating the high-signal "Title + Body" fusion strategy, enforcing strict dimensionality constraints on the sparse behavioral view, and utilizing a rigorous retraining protocol that maximizes data usage without leakage.

# Model

The architecture is a **Stacking Ensemble** composed of **five** "Level 1" base learners, organized into three topology-matched branches (Sparse, Dense, Linear). These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Enhanced Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Title and Request Body** (Cite solution_lesson_node_00044) combined with the **Global Metadata Vector**.
        *   *Rationale:* Concatenating the title and body ensures the model captures the full context of the user's intent in a single dense representation, significantly improving signal over body-only vectors. We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Constrained Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** combined with the **Global Metadata Vector**.
        *   *Correction:* We strictly limit the vocabulary to the **Top 1,000** subreddits. Limiting the "long tail" of rare communities prevents the tree model from overfitting to noise (Cite solution_lesson_node_00042) while maintaining the superiority of sparse representations for categorical sets (Cite solution_lesson_node_00029).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Retention:* Gradient Boosting excels at extracting non-linear signals from dense embeddings (Cite solution_lesson_node_00018). We use `scale_pos_weight` (Cite solution_lesson_node_00034) and maintain high capacity (2,000 estimators), controlled via early stopping.
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with Metadata.
        *   *Retention:* Captures diverse structural patterns (Cite solution_lesson_node_00025). We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) to prevent memorization of continuous noise (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer based on robust heuristics (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Positive Feature Selection** including temporal anchors.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Text Concatenation (Innovation):** Construct a new text field by joining `request_title` and `request_text_edit_aware`. This is the source for both TF-IDF and Embeddings (Cite solution_lesson_node_00044).
    *   **Global Metadata Vector:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) a curated set of dense features:
        *   **Raw Timestamp:** Include `unix_timestamp_of_request_utc`. This is critical for capturing non-cyclic temporal drift (Cite solution_lesson_node_00041).
        *   **User Stats:** Account Age, Karma, Post Counts.
        *   **Exclusion:** Explicitly exclude derived text length features (e.g., character count) as they are noisy proxies (Cite solution_lesson_node_00027).
        *   *Note:* Concatenate this vector to **all** base learners (Cite solution_lesson_node_00023).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) derived from the concatenated text. We use this compact model to avoid the curse of dimensionality (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs (Metadata and Embeddings) (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly to prevent alignment corruption (Cite solution_lesson_node_00024).

# Training

The training procedure implements the **Validation-Guided Retraining Protocol** to prevent overfitting while maximizing data usage.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation on the Training partition.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'`.
    *   **XGBoost:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on the OOF matrix.
4.  **Final Retraining:**
    *   **RF / Linear:** Retrain on the **Full Training Set** (Train + Validation). This maximizes the data available for the stable learners (Cite solution_lesson_node_00044).
    *   **XGBoost:** Retrain on the **Training Set only**, explicitly passing the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" caused by using fixed iteration counts derived from CV (Cite solution_lesson_node_00027).

# Evaluation

1.  Process the test set to generate all feature views (Concatenated Lexical, Constrained Behavioral, Semantic, Metadata).
2.  Pass specific views to the five base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
