# Solution Proposal: Temporal-Aware Pent-View Stacking with Modality-Specific Regularization

Based on the rigorous empirical analysis of the "Lessons Learned," particularly the critical finding that removing raw timestamps destroys performance (Cite solution_lesson_node_00041), the necessity of modality-specific regularization for dense trees (Cite solution_lesson_node_00038), and the superiority of validation-guided retraining (Cite solution_lesson_node_00027), I propose a **Temporal-Aware Pent-View Stacking Ensemble**.

This solution structurally restores the high-performing "Pent-View" architecture (Idea 15) but applies three critical corrections: it reintegrates the **Raw Timestamp** as a monotonic anchor, enforces **Strict Depth Constraints** on the dense Random Forest branch, and utilizes the **Global Validation Set** to govern early stopping for the boosting branch.

# Model

The architecture is a **Stacking Ensemble** composed of **five** "Level 1" base learners, organized into three topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Global Metadata Vector**.
        *   *Retention:* Random Forests on sparse TF-IDF consistently outperform dense methods for capturing specific high-impact keywords (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with the **Global Metadata Vector**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts" document. This sparse representation is superior to dense embeddings for unordered categorical sets (Cite solution_lesson_node_00029) and captures niche community signals effectively (Cite solution_lesson_node_00018).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Retention:* Gradient Boosting excels at extracting non-linear signals from dense, continuous embeddings (Cite solution_lesson_node_00018). We maintain high capacity (2,000 estimators) (Cite solution_lesson_node_00022) and use `scale_pos_weight` (Cite solution_lesson_node_00034).
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Correction:* We apply **Modality-Specific Regularization**. Unlike the sparse RFs, this dense RF is strictly constrained with `max_depth=12` and `min_samples_leaf=4`. This prevents the tree from memorizing noise in the continuous embedding space, addressing the overfitting observed in Idea 29 (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer based on robust heuristics (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Positive Feature Selection** that explicitly includes temporal anchors.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` to remove post-hoc edits (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Global Metadata Vector:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) a curated set of dense features:
        *   **Raw Timestamp:** Include `unix_timestamp_of_request_utc`. This is critical for capturing non-cyclic temporal drift (e.g., community evolution) that cyclic features miss (Cite solution_lesson_node_00041).
        *   **User Stats:** Account Age, Karma, Post Counts.
        *   **Cross-Modal Interaction:** Cosine Similarity between Text and History Embeddings (Cite solution_lesson_node_00009).
        *   *Exclusion:* Exclude derived text length features (Cite solution_lesson_node_00027).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams, Top 3,000) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs (Metadata and Embeddings) (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

# Training

The training procedure implements the **Validation-Guided Retraining Protocol** to prevent overfitting while maximizing data usage.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'`. Apply `min_samples_leaf=2` for Sparse RFs and `max_depth=12` for Dense RFs.
    *   **XGBoost:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on OOF matrix.
4.  **Final Retraining (The Fix):**
    *   **RF / Linear:** Retrain on the **Full Training Set** (Train + Validation).
    *   **XGBoost:** Retrain on the **Full Training Set** but explicitly pass the **Global Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" caused by using fixed iteration counts derived from CV (Cite solution_lesson_node_00027) and avoids the instability of nested validation on small data (Cite solution_lesson_node_00036).

# Evaluation

1.  Process the test set to generate all feature views (Lexical, Behavioral, Semantic, Metadata).
2.  Pass specific views to the five base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
