The following script demonstrates the usage of the provided machine learning pipeline components. It begins by configuring the environment for a fast demonstration run by patching the `Config` class with reduced hyperparameters (fewer trees, smaller datasets). It then verifies the data loading and feature engineering process, checking the integrity and shapes of the generated sparse and dense features. Next, it instantiates and validates each individual model class (Level 1 Base Learners and Level 2 Meta-Learner) by fitting them on a small debug dataset and asserting that predictions are valid probabilities. Finally, it executes the full training pipeline in debug mode to ensure the end-to-end workflow produces a valid submission file.
