Implementation strategy:
1.  **Environment Setup**: Initialize the logger and set random seeds for reproducibility using the provided library functions.
2.  **Data Loading**: Use `library.data_loader.load_and_process_data` to load the pre-computed features (Lexical, Behavioral, Semantic, Metadata) for Train, Validation, and Test splits.
3.  **Level 1 Training (OOF)**: Implement a 5-Fold Stratified Cross-Validation loop on the Training set. Inside the loop, train the five base learners (`LexicalBagger`, `CommunityBagger`, `SemanticBooster`, `SemanticBagger`, `MetadataAnchor`) and generate Out-Of-Fold (OOF) predictions.
4.  **Level 2 Training**: Train the `StackingMetaLearner` (Logistic Regression) on the OOF predictions from the training set.
5.  **Validation Assessment**:
    *   Train fresh instances of the five base learners on the *entire* Training set (using a 90/10 split of the training set for XGBoost early stopping to preserve the integrity of the hold-out validation set).
    *   Generate predictions on the hold-out Validation set using these base learners.
    *   Feed these predictions to the trained Meta-Learner to get final validation probabilities.
    *   Compute and print the ROC AUC score as the "Final Validation Metric".
6.  **Failure Analysis**: Calculate the correlation between the absolute prediction errors on the validation set and each feature in the metadata vector to identify sources of error.
7.  **Submission Generation**:
    *   Check if the validation metric exceeds the specified threshold.
    *   If passed, retrain the base learners for the final submission:
        *   **RF/Linear Models**: Retrain on the combined Training + Validation set.
        *   **XGBoost**: Retrain on the Training set, using the Validation set for early stopping (following the "Fix" strategy).
    *   Generate predictions on the Test set.
    *   Save the predictions to `submission.csv` in the required format.
