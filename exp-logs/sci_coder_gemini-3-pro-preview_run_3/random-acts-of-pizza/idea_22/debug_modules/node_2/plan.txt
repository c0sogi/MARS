The issue is that the `early_stopping_rounds` parameter is being passed to the `fit()` method of the `XGBClassifier`, which is deprecated and removed in recent versions of the XGBoost Scikit-Learn API. As detailed in **Cite debug_lesson_10**, this parameter must now be set via the model's constructor (`__init__`) or dynamically using `set_params()` before training.

To fix this, I will modify `library/model_definitions.py` and `library/retraining_protocol.py` to move `early_stopping_rounds` from the `.fit()` call to a preceding `.set_params()` call for the XGBoost model (`semantic_booster`). This ensures compatibility with the installed XGBoost version while preserving the early stopping functionality.
