Based on the comprehensive analysis of the "Lessons Learned," particularly the potential of **Community Profiling** (if leakage is controlled, Cite solution_lesson_node_00050), the success of **Textual Field Concatenation** (Cite solution_lesson_node_00044), and the necessity of **Raw Temporal Anchors** (Cite solution_lesson_node_00041), I propose an **Asymmetric Pent-View Stacking Ensemble with Nested Community Profiling**.

This solution structurally evolves the "Pent-View" architecture by introducing a rigorous **Nested Target Encoding** layer. This converts the high-dimensional sparse subreddit history into a dense, leakage-free "Community Generosity Score," enabling the dense semantic learners to access behavioral signals that were previously siloed, without violating the sparsity constraints of the behavioral branch.

# Model

The architecture is a **Stacking Ensemble** composed of **five** "Level 1" base learners, organized into three topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Concatenated Title and Body** (Cite solution_lesson_node_00044) combined with the **Augmented Global Metadata**.
        *   *Retention:* Random Forests on sparse TF-IDF consistently outperform dense methods for capturing specific high-impact keywords (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** combined with the **Augmented Global Metadata**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts" document. We strictly limit the vocabulary to the **Top 1,000** subreddits to prevent overfitting to rare communities (Cite solution_lesson_node_00042) and maintain the superiority of sparse representations for categorical sets (Cite solution_lesson_node_00029).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with **Augmented Global Metadata**.
        *   *Innovation:* This model now receives the **Community Generosity Score** (via metadata). This allows the booster to learn non-linear interactions between the semantic tone of the request (e.g., "desperation") and the historical success probability of the user's communities, bridging the modality gap (Cite solution_lesson_node_00023).
        *   *Retention:* We use `scale_pos_weight` (Cite solution_lesson_node_00034) and maintain high capacity (2,000 estimators), controlled via early stopping (Cite solution_lesson_node_00027).
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings (Title + Body)** combined with **Augmented Global Metadata**.
        *   *Retention:* Provides structural diversity (Cite solution_lesson_node_00025). We apply **Modality-Specific Regularization** (`max_depth=12`, `min_samples_leaf=4`) to prevent memorization of dense noise (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Augmented Global Metadata**.
        *   *Retention:* Acts as a high-bias regularizer (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

# Data

The data pipeline enforces strict leakage prevention, robust typing, and **Nested Feature Engineering**.

1.  **Leakage Prevention:**
    *   Source Text: Use `request_text_edit_aware` (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Nested Community Profiling (Structural Innovation):** Generate a **Community Generosity Score** using **5-Fold Nested Cross-Validation** within the training set.
        *   *Procedure:* Split training data into 5 folds. For each fold, calculate the average target value ($P(Pizza)$) for each subreddit using only the *other 4 folds*. Map these probabilities to the users in the current fold based on their subreddit history (averaging the scores of their subreddits). Handle unseen subreddits with the global mean.
        *   *Correction:* This fixes the leakage in Lesson 00050 by ensuring the feature value for a training sample is never derived from its own label.
    *   **Augmented Global Metadata:** Explicitly **Allow-List** (Cite solution_lesson_node_00030):
        *   **Raw Timestamp:** `unix_timestamp_of_request_utc` (Cite solution_lesson_node_00041).
        *   **User Stats:** Account Age, Karma, Post Counts.
        *   **Community Generosity Score:** The new dense behavioral feature.
        *   **Exclusion:** Exclude derived text length features (Cite solution_lesson_node_00027).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams) on Concatenated Text with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim) (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs.
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

# Training

The training procedure implements the **Validation-Guided Retraining Protocol**.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation for the Stacking loop.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'`.
    *   **XGBoost:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on the OOF matrix.
4.  **Final Retraining:**
    *   **Target Encoding:** Fit the Community Profiler on the **Full Training Set** (to apply to Test data).
    *   **RF / Linear:** Retrain on the **Full Training Set** (Train + Validation) to maximize data usage (Cite solution_lesson_node_00044).
    *   **XGBoost:** Retrain on the **Training Set only**, explicitly passing the **Global Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" (Cite solution_lesson_node_00027) and avoids the instability of small nested validation sets (Cite solution_lesson_node_00036).

# Evaluation

1.  Process the test set to generate all feature views.
2.  Apply the global Community Profiler (fitted on full train) to generate the `Community Generosity Score` for test samples.
3.  Pass specific views to the five base learners to obtain probability scores.
4.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
