The implementation strategy follows the "Restored-History Hex-View Stacking Ensemble with CV-Bagging" architecture. The script orchestrates the pipeline by initializing the `CVEnsembleTrainer` to perform 5-fold cross-validation training of the six base learners (Lexical Bagger, Community Bagger, Semantic Booster, Semantic Bagger, Metadata Anchor, Temporal Booster) and the Level-2 Meta-Learner. 

To strictly adhere to the requirement of evaluating on the hold-out validation set while using a CV-Bagging approach (where the validation set is merged into the training pool), the script identifies the indices corresponding to the original `val.parquet` hold-out set and evaluates the **Out-Of-Fold (OOF)** predictions for those specific samples. This provides an unbiased performance metric without data leakage. Failure analysis is performed by correlating the prediction errors on this validation subset with the contextual metadata features. Finally, the submission is generated using the full ensemble if the validation AUC exceeds the specified threshold.
