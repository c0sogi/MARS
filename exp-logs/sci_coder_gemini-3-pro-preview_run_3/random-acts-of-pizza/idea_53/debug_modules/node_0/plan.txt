Implementation Strategy:
1.  **Environment Setup**: Initialize a dedicated working directory (`./working/demo_run`) to ensure the demonstration is isolated and does not interfere with existing cache or models.
2.  **Configuration Override**: Dynamically patch the module-level path variables in the provided library files (`data_loader`, `feature_extraction`, `training_engine`, `inference_engine`) to point to the new working directory. This ensures all artifacts are saved in the demo location.
3.  **Data Loading & Subsampling**: Load the training and test datasets using `data_loader`. Subsample them significantly (e.g., 50 training samples, 10 test samples) to ensure the script executes within seconds while still exercising the full logic.
4.  **Feature Pipeline Execution**: Instantiate the `FeaturePipeline` and run `fit_transform` on the subsampled training data. This demonstrates the multi-modal feature extraction (Text, Metadata, History) and embedding generation.
5.  **Model Training**: Instantiate the `HybridTrainer` with `debug=True`. This enables the "fast mode" (reduced estimators, fewer iterations, 2-fold CV). Run the `train` method to generate and save the base models and the meta-learner.
6.  **Inference**: Instantiate the `HybridPredictor` (configured with `n_folds=2` to match the debug training) and generate predictions for the subsampled test set.
7.  **Validation**: Perform assertions to verify that:
    *   Feature matrices have the correct dimensions.
    *   Model files are physically created on disk.
    *   The submission file is generated with the correct schema and probability values.
