The error `TypeError: XGBClassifier.fit() got an unexpected keyword argument 'eval_metric'` occurs because modern versions of XGBoost (v1.6+) have removed the `eval_metric` parameter from the `.fit()` method to align with the Scikit-Learn API. This parameter must now be defined during initialization or via `.set_params()` Cite debug_lesson_10.

To fix this, I will modify `library/training_engine.py` to check the model type before calling `.fit()`. For `XGBClassifier` instances, I will move `eval_metric` to a `.set_params()` call. For `LGBMClassifier` instances, I will continue passing `eval_metric` to `.fit()` as it remains supported in the LightGBM Scikit-Learn API Cite debug_lesson_17.
