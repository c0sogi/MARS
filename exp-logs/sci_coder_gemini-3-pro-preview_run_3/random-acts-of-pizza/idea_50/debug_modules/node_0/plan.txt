The following script demonstrates the end-to-end execution of the provided machine learning pipeline. It performs the following steps:
1.  **Configuration Patching**: Overrides the default hyperparameters in `library.config` to use a minimal number of estimators and folds. This ensures the demonstration runs quickly (seconds instead of hours) while exercising all code paths.
2.  **Data Loading**: Uses `library.data_loader` to load the dataset, then subsets it to a very small number of samples (50 train, 20 val, 20 test) to further optimize speed.
3.  **Feature Engineering**: Initializes the `FeatureEngineer` to generate Lexical (TF-IDF), Community (TF-IDF), Semantic (Embeddings), and Metadata features. It explicitly bypasses the cache to demonstrate the computation logic.
4.  **Pipeline Execution**: Instantiates the `HybridStackingRunner` to execute the Hex-View Stacking strategy. This involves:
    *   Merging Train and Validation sets.
    *   Running Level 1 Cross-Validation (training 6 different base models per fold).
    *   Performing Hybrid Inference (CV-Bagging for volatile models, Retraining for stable models).
    *   Training the Level 2 Meta-Learner.
    *   Generating final predictions.
5.  **Verification**: Validates that the feature shapes are correct and that the final submission file is generated with the expected format and content.
