The following script implements the `runfile.py` orchestration logic. It strictly adheres to the "Hex-View Stacking Ensemble" architecture and the "Hybrid Inference Protocol" defined in the provided library files.

**Implementation Strategy:**
1.  **Data Loading & Isolation:** The script loads the dataset and isolates the official `val` set (from `val.parquet`) to ensure it is **never** seen by the training pipeline. The `train` set is split internally to satisfy the `run_stacking` method's signature (which expects two datasets to merge for Cross-Validation), ensuring the model trains on the full training set without leaking the hold-out validation data.
2.  **Feature Engineering:** It utilizes the `FeatureEngineer` to generate Lexical (TF-IDF), Community (Sparse History), Semantic (Dense Embeddings), and Metadata features for all data splits.
3.  **Pipeline Execution:** It instantiates `HybridStackingRunner` to execute the training loop. This handles 5-Fold CV, OOF generation, and Hybrid Inference (CV-Bagging for volatile boosters, Full-Retraining for stable learners) to produce the final Test submission.
4.  **Hold-out Validation:** Post-training, the script manually loads the saved model artifacts to perform inference on the isolated validation set. This ensures the reported "Final Validation Metric" is a true unbiased estimate.
5.  **Failure Analysis & Submission Guard:** It calculates the correlation between prediction errors and input features on the validation set. Finally, it enforces the submission threshold logic, removing the generated submission file if the validation AUC does not meet the requirement.
