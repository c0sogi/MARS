The following script performs a comprehensive Exploratory Data Analysis (EDA) on the training dataset (loaded from `./metadata/train.parquet`). It is designed to handle the mixed modality of the dataset (Text + Tabular).

**Strategy:**
1.  **Setup & Loading**: Initialize the environment, set random seeds for reproducibility, and load the training data from the pre-generated Parquet file.
2.  **Target Analysis**: Analyze the distribution of the `requester_received_pizza` column to establish the baseline class balance.
3.  **Tabular Analysis**:
    *   Identify numerical columns (e.g., account age, upvotes) and compute descriptive statistics (mean, std, outliers).
    *   Identify categorical columns (e.g., user flair) and analyze cardinality and missing values.
4.  **Text Analysis**:
    *   Focus on `request_text` and `request_title`.
    *   Calculate sequence lengths (characters and words).
    *   Compute vocabulary size using a simple tokenizer.
5.  **Feature Relationships**:
    *   Compute correlations between numerical features to identify redundancy (collinearity).
    *   Train a lightweight Random Forest model using numerical metadata and derived text features (lengths) to determine feature importance.
    *   Analyze the relationship between text length and the success of the request.
