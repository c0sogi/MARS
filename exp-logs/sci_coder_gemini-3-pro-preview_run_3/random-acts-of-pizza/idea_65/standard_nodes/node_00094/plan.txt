Implementation Strategy:
1.  **Environment Setup**: Initialize logging (suppressing verbose library output) and set random seeds for reproducibility.
2.  **Data Loading**: Manually load `train.parquet`, `val.parquet`, and `test.parquet` from the `./metadata` directory. This allows us to perform a strict hold-out validation check before proceeding to the full "Union Strategy" training.
3.  **Phase 1 (Validation)**:
    *   Train the ensemble using *only* the training set (`train.parquet`).
    *   Use the `Trainer` class to manage the stacking pipeline.
    *   Generate predictions on the validation set (`val.parquet`) by passing it as the "test" set to the `Trainer`.
    *   Compute and print the **Final Validation Metric** (ROC AUC) on this hold-out set.
    *   Perform **Failure Analysis** by calculating the correlation between prediction error and input features on the validation set.
4.  **Phase 2 (Submission)**:
    *   Check if the validation metric exceeds the required threshold (0.7222984867326668).
    *   If successful, implement the **Union Strategy**: Merge training and validation sets into a single dataset.
    *   Retrain the entire ensemble on this union dataset to maximize signal.
    *   Generate predictions for the test set (`test.parquet`).
    *   Save the final submission to `./submission/submission.csv`.
