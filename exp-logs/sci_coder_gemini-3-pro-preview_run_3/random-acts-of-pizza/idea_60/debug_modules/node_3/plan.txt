The `TypeError` is caused by passing the `verbose` argument to the `.fit()` method of the `LGBMClassifier`, which was removed in LightGBM v4.0+. While `XGBClassifier` still accepts `verbose` in `.fit()`, LightGBM now manages verbosity via the `verbosity` parameter in `__init__` or callbacks. To resolve this, I will modify the training loop to conditionally pass `verbose=False` to `.fit()` only when the model is not a LightGBM classifier, ensuring compatibility with both libraries.
