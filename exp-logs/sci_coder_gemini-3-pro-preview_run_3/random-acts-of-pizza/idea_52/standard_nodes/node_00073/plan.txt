The implementation strategy follows the Hept-View Stacking Ensemble architecture with a Hybrid Inference Protocol.

1.  **Setup and Data Loading**: Initialize the environment with fixed seeds and logging. Load the training, validation, and test datasets using the provided `data_loader`.
2.  **Feature Engineering**: Instantiate the `FeaturePipeline`. Fit it on the training set to learn vocabulary and scaling parameters. Transform the training, validation, and test sets to generate Lexical (sparse), Behavioral (sparse), Semantic (dense), and Metadata (dense) feature matrices.
3.  **Model Training (Level 1)**:
    *   **Volatile Learners (XGBoost, LightGBM)**: Train using `HybridTrainer.train_volatile` with 5-fold Cross-Validation. This method utilizes the validation fold for early stopping and persists all 5 fold-models for bagged inference.
    *   **Stable Learners (Random Forest, Logistic Regression)**: Train using `HybridTrainer.train_stable`. This generates Out-of-Fold (OOF) predictions via CV, then retrains a single model on the full training set for inference.
4.  **Meta-Learner Training (Level 2)**: Stack the OOF probabilities from all 7 base learners and train the Logistic Regression Meta-Learner.
5.  **Validation**: Use `HybridPredictor` to generate predictions for the hold-out validation set. Compute and print the final ROC AUC metric.
6.  **Failure Analysis**: Calculate the absolute prediction error on the validation set and compute Pearson correlations with the metadata features to identify error sources.
7.  **Submission**: If the validation AUC exceeds the threshold, generate predictions for the test set using the full ensemble and save the submission file.
