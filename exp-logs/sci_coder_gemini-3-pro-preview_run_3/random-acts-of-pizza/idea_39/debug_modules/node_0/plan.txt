The following script demonstrates the end-to-end execution of the Hex-View Stacking Ensemble pipeline using the provided library files. It includes steps for data loading, feature engineering, model instantiation, stacking training (OOF generation + meta-learning), and final prediction.

To ensure the demonstration runs quickly within the time limit, the script:
1.  Overrides configuration parameters to use fewer estimators (trees), smaller vectorizer vocabularies, and fewer SVD components.
2.  Uses a small subset (top 100 samples) of the training and validation data.
3.  Reduces the number of cross-validation folds to 2.
4.  Includes assertions to verify the shapes and types of intermediate outputs.
