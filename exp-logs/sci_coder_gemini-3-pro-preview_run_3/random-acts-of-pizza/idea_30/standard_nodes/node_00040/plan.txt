This causes an `IndexError` when the ensemble model attempts to index the small feature matrices using indices from the full dataset.

To fix this, I will modify `library/features.py` to validate the dimensions of the loaded cached features against the current training dataframe. If the dimensions do not match, the code will discard the cache and regenerate the features.
