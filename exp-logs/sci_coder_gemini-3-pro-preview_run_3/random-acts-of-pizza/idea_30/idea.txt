# Solution Proposal: Regularized Pent-View Stacking with Cross-Modal Interaction

Based on the comprehensive empirical analysis of the "Lessons Learned," particularly the critical importance of **Modality-Specific Regularization** (Cite solution_lesson_node_00038), the effectiveness of **Validation-Guided Retraining** (Cite solution_lesson_node_00027), and the need for **Compact Representations** (Cite solution_lesson_node_00028), I propose a **Regularized Pent-View Stacking Ensemble with Cross-Modal Interaction**.

This solution structurally evolves the high-performing "Pent-View" architecture (Idea 15) by explicitly correcting the regularization flaws that caused the regression in Idea 29. It integrates the **Cross-Modal Consistency** feature (to bridge text and behavior) while strictly enforcing depth constraints on dense tree models and utilizing a robust retraining protocol.

## Model

The architecture is a **Stacking Ensemble** composed of **five** "Level 1" base learners, organized into three topology-matched branches. These learners feed into a "Level 2" Logistic Regression meta-learner.

**Level 1: Base Learners**

1.  **Sparse Lexical Branch (Text Modality)**
    *   **Lexical Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the request text** concatenated with the **Global Metadata Vector**.
        *   *Retention:* Random Forests on sparse TF-IDF consistently outperform dense methods for capturing specific high-impact keywords (Cite solution_lesson_node_00013). We apply regularization (`min_samples_leaf=2`) to prevent overfitting (Cite solution_lesson_node_00025).

2.  **Sparse Behavioral Branch (History Modality)**
    *   **Community Bagger:** A **Random Forest Classifier** trained on **TF-IDF vectors of the Subreddit History** concatenated with the **Global Metadata Vector**.
        *   *Retention:* We treat user history as a "Bag-of-Concepts" document. This sparse representation is superior to dense embeddings for unordered categorical sets (Cite solution_lesson_node_00029) and captures niche community signals effectively (Cite solution_lesson_node_00018).

3.  **Dense Semantic Branch (Text Modality)**
    *   **Semantic Booster:** An **XGBoost Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Correction:* We explicitly restore `scale_pos_weight` to handle class imbalance (Cite solution_lesson_node_00034) and maintain high capacity (2,000 estimators) (Cite solution_lesson_node_00022), controlled via early stopping.
    *   **Semantic Bagger:** A **Random Forest Classifier** trained on **Frozen Compact Embeddings** concatenated with Metadata.
        *   *Correction:* We apply **Modality-Specific Regularization**. Unlike the sparse RFs, this dense RF is strictly constrained with `max_depth=12` and `min_samples_leaf=4`. This prevents the tree from memorizing noise in the continuous embedding space, addressing the root cause of the failure in Idea 29 (Cite solution_lesson_node_00038).

4.  **Contextual Branch (Metadata Modality)**
    *   **Metadata Anchor:** A **Logistic Regression** model trained on the **Global Metadata Vector**.
        *   *Retention:* Acts as a high-bias regularizer based on robust heuristics (Cite solution_lesson_node_00006).

**Level 2: Meta-Learner**
*   **Logistic Regression:** Calibrates the ensemble weights (Cite solution_lesson_node_00012).

## Data

The data pipeline enforces strict leakage prevention, robust typing, and **Positive Feature Selection**.

1.  **Leakage Prevention:**
    *   Source Text: `request_text_edit_aware` (Cite solution_lesson_node_00003).
    *   Exclusion: Drop all columns suffixed with `_at_retrieval`.
2.  **Feature Engineering:**
    *   **Cross-Modal Interaction (Innovation):** Calculate the **Cosine Similarity** between the **Text Embedding** (Request) and the **History Embedding** (Subreddits).
        *   *Rationale:* This scalar feature captures the semantic alignment between "what the user wants" and "who the user is" without exposing the model to the dimensionality curse of the full history embedding (Cite solution_lesson_node_00028).
    *   **Global Metadata Vector:** Explicitly **Allow-List** (Cite solution_lesson_node_00030) User Stats (Age, Karma), Temporal Features, and the new **Interaction Feature**. Concatenate this to **all** base learners (Cite solution_lesson_node_00023).
        *   *Correction:* Explicitly **exclude** derived text length features, as they are noisy proxies (Cite solution_lesson_node_00027).
    *   **Sparse Features:** TF-IDF (Unigrams/Bigrams, Top 3,000) with `sublinear_tf=True` and `min_df=5` (Cite solution_lesson_node_00024).
    *   **Dense Features:** Frozen `all-MiniLM-L6-v2` Embeddings (384-dim). We use this compact model to avoid the curse of dimensionality (Cite solution_lesson_node_00028).
3.  **Preprocessing:**
    *   **Imputation:** Median imputation.
    *   **Scaling:** `StandardScaler` applied to dense inputs (Metadata and Embeddings) (Cite solution_lesson_node_00006).
    *   **No Caching:** Recompute features on-the-fly (Cite solution_lesson_node_00024).

## Training

The training procedure implements the **Validation-Guided Retraining Protocol** to prevent overfitting while maximizing data usage.

1.  **Fold Generation:** 5-Fold Stratified Cross-Validation.
2.  **Level 1 Training (OOF Generation):**
    *   **RF / Linear:** Train on 4 folds, predict on 5th. Use `class_weight='balanced'` and appropriate regularization (`min_samples_leaf=2` for Sparse, `max_depth=12` for Dense).
    *   **XGBoost:** Train on 4 folds, predict on 5th. Use `scale_pos_weight`.
3.  **Level 2 Training:** Train Meta-Learner on OOF matrix.
4.  **Final Retraining (The Fix):**
    *   **RF / Linear:** Retrain on the **Full Training Set** (Train + Validation).
    *   **XGBoost:** Retrain on the **Full Training Set** but explicitly pass the **Validation Set** (from the metadata split) as the `eval_set` to the `fit()` method to trigger **Early Stopping**. This prevents "blind overfitting" caused by using fixed iteration counts derived from CV (Cite solution_lesson_node_00027).

## Evaluation

1.  Process the test set to generate all feature views (Lexical, Behavioral, Semantic, Metadata).
2.  Pass specific views to the five base learners to obtain probability scores.
3.  Feed aggregated probabilities to the Meta-Learner for the final prediction.
