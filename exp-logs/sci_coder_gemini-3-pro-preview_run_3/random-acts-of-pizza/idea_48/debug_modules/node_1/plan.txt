The issue is that the `LGBMClassifier` (and potentially `XGBClassifier`) is initialized with `early_stopping_rounds` set in `config.py`, which mandates the presence of an `eval_set` during training. In the `train_and_predict_oof` method, the models are trained using standard cross-validation (`model.fit(X_tr_fold, y_tr_fold)`) without a validation set, causing LightGBM to raise a `ValueError` because it cannot evaluate the stopping condition.

To fix this, I will modify `library/ensemble_pipeline.py` to explicitly disable `early_stopping_rounds` (by setting it to `None` via `set_params`) for any model that has it configured, specifically within the OOF generation loop where no validation set is provided.
