This script demonstrates the end-to-end execution of the provided machine learning pipeline for the Random Acts of Pizza task. It performs the following steps:

1.  **Configuration**: Overrides default configuration settings to run in "Debug Mode" for speed (reducing sample size, number of estimators, and cross-validation folds).
2.  **Data Loading**: Uses `load_datasets` to retrieve a small subset of the training, validation, and test data.
3.  **Feature Extraction**: Uses `extract_features` to generate Lexical (TF-IDF), Semantic (SBERT embeddings), Behavioral (Subreddit history), and Metadata features.
4.  **Model Training**: Instantiates the `TriViewStackingClassifier` and trains it using `fit_cv`. This involves training base Random Forest models on each view and a Logistic Regression meta-learner on the stacked predictions.
5.  **Prediction**: Generates probabilities for the test set.
6.  **Submission**: Formats the predictions into the required CSV format and saves the file.
7.  **Verification**: Includes assertions throughout to verify data shapes, model states, and output formats.
