The issue is caused by a strict type check in `library/features.py` that only accepts `list` objects for the subreddit column, ignoring `np.ndarray` objects which are frequently produced by pandas when loading data from Parquet files or during internal processing. This causes valid subreddit data to be converted into empty strings, resulting in an empty input set for the `TfidfVectorizer` and triggering the `ValueError`. To fix this, I will update the `isinstance` checks in both the `fit` and `transform` methods of `FeaturePipeline` to accept both `list` and `np.ndarray`, ensuring valid data is correctly processed.
