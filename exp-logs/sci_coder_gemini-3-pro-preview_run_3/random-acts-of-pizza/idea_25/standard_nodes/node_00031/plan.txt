Implementation strategy:
1.  **Setup and Imports**: Import necessary libraries (`pandas`, `numpy`, `sklearn`) and the provided modules (`StackingManager`, `Config`).
2.  **Initialization**: Instantiate the `StackingManager` to leverage its pre-configured feature engine and model factory.
3.  **Feature Engineering**: Generate feature sets for Train, Validation, and Test splits using `manager.feature_engine`. This utilizes caching to save time.
4.  **Level 1 Cross-Validation (Train)**: Manually execute the Stratified K-Fold Cross-Validation on the Training set to generate Out-of-Fold (OOF) predictions. This is necessary to train the Meta-Learner without leakage.
5.  **Level 2 Meta-Training**: Train the Meta-Learner (Logistic Regression) on the generated OOF predictions from the training set.
6.  **Hold-out Validation**:
    *   Train all base models on the *full* Training set. For the XGBoost model, use a small internal split of the training set for early stopping to maintain the integrity of the hold-out validation set.
    *   Generate predictions on the hold-out Validation set using these base models.
    *   Feed these predictions to the trained Meta-Learner to get final validation probabilities.
    *   Calculate and print the **Final Validation Metric** (ROC AUC).
7.  **Failure Analysis**: Compute the absolute error on the validation set and calculate the correlation between the error and the numerical metadata features. Print the top correlations to identify systematic failures.
8.  **Submission Generation**:
    *   Check if the validation AUC exceeds the specified threshold.
    *   If yes, retrain all base models on the combined Training + Validation set. For XGBoost, use the Validation set for early stopping (following the strategy in `StackingManager`).
    *   Generate predictions on the Test set.
    *   Save the submission file to the specified path.
