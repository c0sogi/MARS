The following script demonstrates the usage of the provided library to solve the Random Acts of Pizza prediction task.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes at runtime to optimize for speed. We reduce the dataset size (`DEBUG_SAMPLE_SIZE`), the number of cross-validation folds (`N_FOLDS`), and the complexity of the models (number of estimators/trees). We also redirect the cache and submission directories to the `./working` folder to ensure a clean run.
2.  **Component Verification**: We individually test the utility functions (`clean_text`, `serialize_subreddits`) and the `FeatureEngine` to ensure data processing and feature generation work as expected.
3.  **Pipeline Execution**: We instantiate the `StackingManager` and run the full `train_and_predict` pipeline. This orchestrates feature engineering, Level 1 model training (base learners), Level 2 model training (meta-learner), and final test set prediction.
4.  **Result Validation**: Finally, we verify that the submission file is generated correctly, checking its dimensions, columns, and value ranges.
