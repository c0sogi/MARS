2.  **Utility Verification**: Test the `seed_everything` function for reproducibility and the `calculate_accuracy` function with dummy NumPy and Tensor data to ensure metric calculation logic is correct.
3.  **Dataset & DataLoader Setup**: Use `get_dataset` to load training, validation, and test sets in debug mode. Verify the integrity of the data (shapes, types) and wrap them in PyTorch `DataLoader` instances.
4.  **Model Architecture Check**: Instantiate the `DualStreamModel` and perform a forward pass with a dummy input tensor to verify that the model architecture is valid and produces outputs of the expected shape `(Batch_Size, Num_Classes)`.
5.  **Training Execution**: Invoke `train_model` from `library.engine`. This function handles the training loop, gradient accumulation, and validation. We assert that a model checkpoint is saved upon completion.
6.  **Inference Execution**: Invoke `generate_submission` from `library.engine` using the trained model and test loader. This demonstrates the inference pipeline including Test-Time Augmentation (TTA).
7.  **Result Validation**: Load the generated submission CSV file and assert that it contains the correct number of rows (matching the debug sample size) and the required columns.
