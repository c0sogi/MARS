Based on the lessons learned from the previous experiments, I propose the following optimized strategy. This solution introduces a structural evolution in the backbone architecture and the data augmentation paradigm while retaining successful regularization techniques.

# Model
I propose replacing the ResNet/ResNeXt family with the **EfficientNet-B4** architecture.
*   **Structural Innovation**: Unlike the standard convolution blocks found in ResNet and ResNeXt, EfficientNet utilizes **Mobile Inverted Bottleneck Convolution (MBConv)** blocks with integrated **Squeeze-and-Excitation (SE)** optimization. This architecture employs compound scaling to balance depth, width, and resolution, providing the high representational capacity required for this task (Cite Lesson 00010) while being more parameter-efficient.
*   **Pre-training**: The model will be initialized with **NoisyStudent** or ImageNet weights to leverage robust feature extractors immediately.
*   **Head**: The classification head will consist of a Global Average Pooling layer followed by a Dropout layer and a final Linear layer outputting to the 5 classes.

# Data
*   **Preprocessing**: Images will be resized to **380x380 pixels**. This higher resolution (compared to the previous 224x224) is native to EfficientNet-B4 and allows the model to capture finer details of leaf lesions, which are critical for distinguishing between similar diseases.
*   **Augmentation Strategy**:
    *   **Geometric (Heavy)**: We will employ robust geometric transformations, including `RandomResizedCrop`, `HorizontalFlip`, `VerticalFlip`, and `Transpose`. These were proven safe and effective (Cite Lesson 00004).
    *   **Photometric (Light)**: We will strictly limit color-based augmentations (specifically `HueSaturationValue`) to avoid destroying the specific color signals (yellowing/browning) that define the disease classes (Cite Lesson 00004).
    *   **Mixing (New)**: We will implement **CutMix** or **MixUp** augmentation. This technique mixes pixels and labels from two different images during training. This addresses the class imbalance and overfitting issues by synthetically expanding the dataset and enforcing smoother decision boundaries, effectively replacing the failed loss-weighting strategy (Cite Lesson 00001).

# Training
*   **Loss Function**: We will use **Cross Entropy Loss with Label Smoothing (0.1)**. This component is explicitly retained from the previous successful experiment, as it prevents the model from becoming overconfident and improves generalization on the validation set (Cite Lesson 00007).
*   **Optimizer**: We will use **AdamW** with a **Cosine Annealing Warm Restarts** scheduler. This ensures efficient convergence and allows the model to escape local minima.
*   **Procedure**: The model will be trained for approximately 10-15 epochs. The CutMix/MixUp probability will be set to 0.5 to balance between mixed and clean samples.

# Evaluation
*   **Inference**: We will re-introduce **Test-Time Augmentation (TTA)**.
*   **Rationale**: Previous experiments showed TTA failed when applied to a weak backbone (ResNet-18). However, now that we are using a high-capacity backbone (EfficientNet-B4), TTA (averaging predictions across original, horizontally flipped, and vertically flipped versions) will act as a performance multiplier rather than a compensation mechanism (Cite Lesson 00010).
