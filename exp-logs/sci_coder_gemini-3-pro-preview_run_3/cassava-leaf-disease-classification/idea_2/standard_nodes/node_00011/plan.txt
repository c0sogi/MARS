The implementation strategy is as follows:
1.  **Setup**: Initialize the environment with fixed seeds and configure the device. Override the default batch sizes to 64 (train) and 128 (val) to fully utilize the A100 GPU's memory and speed up execution.
2.  **Data Loading**: Load the training and validation metadata. Instantiate `CassavaDataset` with the corresponding Albumentations transforms defined in `library.augmentations`. Create optimized `DataLoader`s.
3.  **Training Loop**: Initialize the `CassavaModel` (EfficientNet-B4 backbone). Train for 10 epochs using `AdamW` optimizer and `CosineAnnealingWarmRestarts` scheduler. Use `CrossEntropyLoss` with label smoothing (0.1). Track validation accuracy and save the best model checkpoint.
4.  **Evaluation**: Load the best model. Compute and print the exact final validation metric. Perform failure analysis by calculating the Pearson correlation between prediction errors and input image statistics (mean and standard deviation) to identify systematic biases.
5.  **Submission**: Check if the validation accuracy exceeds the specified threshold. If so, perform inference on the test set using **Test-Time Augmentation (TTA)** (averaging predictions from original, horizontally flipped, and vertically flipped images). Save the results to `./submission/submission.csv`.
