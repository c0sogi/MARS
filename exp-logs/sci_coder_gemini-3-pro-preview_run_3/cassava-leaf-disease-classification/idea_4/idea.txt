Based on the progression of experiments and the lessons learned, I propose the following optimized strategy. This solution represents a structural evolution from the pure Vision Transformer approach (Idea 3) to a **Hierarchical Vision Transformer** architecture, specifically the **Swin Transformer**. This architecture synthesizes the global context capabilities of Transformers with the local processing efficiency of CNNs, directly addressing the trade-offs observed in previous iterations.

# Model
I propose replacing the standard Vision Transformer (ViT-Base) with the **Swin Transformer (Swin-Large)** architecture.
*   **Structural Innovation**: While the ViT (Idea 3) excels at global context (Cite Lesson 00015), it lacks the inductive bias for local features that CNNs (Idea 2) possess. The Swin Transformer introduces a **Hierarchical** structure using **Shifted Window Attention**. This mechanism computes self-attention within local windows (capturing fine-grained disease details like CNNs) and shifts these windows between layers to establish cross-window connections (capturing global leaf patterns like ViTs). This effectively unifies the strengths of the CNN and ViT backbones used in previous ideas.
*   **Pre-training**: The model will be initialized with weights pre-trained on **ImageNet-22k** (or similar large-scale datasets) to ensure robust feature extraction capability immediately (Cite Lesson 00010).
*   **Head**: A simple Linear classification head will be used on top of the final pooled feature map.

# Data
*   **Preprocessing**: Images will be resized to **384x384 pixels**. This resolution matches the native window size of the Swin Transformer and preserves the high-fidelity details required for fine-grained classification (Cite Lesson 00015).
*   **Augmentation**:
    *   **Mixing**: We will strictly retain **MixUp and CutMix** augmentation. These are essential for preventing overfitting in high-capacity models and enforcing linear decision boundaries (Cite Lesson 00012).
    *   **Geometric vs. Photometric**: We will continue to prioritize geometric transformations (flips, slight rotations) and avoid aggressive photometric augmentations (like Hue/Saturation shifts) to preserve the specific color signals of the diseases (Cite Lesson 00004).
    *   **Determinism**: To address the variance observed in multi-process training, we will implement **Deterministic Data Loading**. Random augmentation decisions (e.g., whether to apply MixUp) will be seeded based on the image index or handled within the `__getitem__` method rather than the main loop, ensuring that data presentation is reproducible across runs (Cite Lesson 00014).

# Training
*   **Loss Function**: We will use **Cross Entropy Loss with Label Smoothing (0.1)**. This remains a critical regularizer to prevent the high-capacity Swin Transformer from becoming overconfident (Cite Lesson 00007).
*   **Optimizer**: We will use **AdamW** with a Cosine Annealing scheduler.
*   **Strategy**:
    *   **Early Stopping**: We will employ **Early Stopping** based on validation accuracy rather than prolonged training with Stochastic Weight Averaging (SWA). Since fine-tuned Transformers on this dataset tend to converge to a sharp, optimal minimum rapidly (often by Epoch 5-8), stopping at the peak is more efficient and effective than averaging weights from the tail end of training (Cite Lesson 00017).
    *   **Batch Size**: We will maximize the batch size to the limits of the A100 GPU memory. If necessary, we will use Gradient Accumulation to maintain a high effective batch size, ensuring stable Batch Normalization statistics (Cite Lesson 00013).

# Evaluation
*   **Inference**: We will utilize **Test-Time Augmentation (TTA)**.
*   **Rationale**: Given the extremely high capacity of the Swin-Large backbone, TTA (averaging predictions from the original and flipped versions) will act as a robust performance multiplier, further boosting the model's generalization capabilities (Cite Lesson 00010).
