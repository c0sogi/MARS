To improve the model's performance, I will implement a strategy focused on maximizing the potential of the single strongest architecture, the Vision Transformer (ViT), rather than relying on an ensemble with a weaker learner.

**Optimization Strategy:**
1.  **Revert to Single Model**: I will remove the EfficientNet-B4 model and the ensemble logic. Previous lessons (Cite `solution_lesson_node_00033`) demonstrated that averaging a strong model (ViT) with a weaker one (EfficientNet) dilutes the overall accuracy.
2.  **Optimize ViT Training**: I will increase the training duration from 7 to 10 epochs and reduce the batch size from 64 to 32. This aligns with the configuration of the best-performing historical run ("Idea 3"), as smaller batch sizes often provide better regularization and convergence stability for ViTs on this dataset (Cite `solution_lesson_node_00013`).
3.  **Refine Inference**: I will update the inference pipeline to use Test-Time Augmentation (TTA) on the single ViT model, ensuring we capture the full capacity of the optimized backbone.

    # Load Test Data
    # get_dataloaders returns (train, val, test), we only need test

    # ====================================================
    # Model A Inference (Global Expert: ViT)
