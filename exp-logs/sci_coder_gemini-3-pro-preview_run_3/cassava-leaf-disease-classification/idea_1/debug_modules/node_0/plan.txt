Implementation Strategy:
1.  **Configuration & Setup**: Import the `Config` class and override key parameters (e.g., `DEBUG`, `NUM_EPOCHS`, `BATCH_SIZE`, `PRETRAINED`) to ensure the script runs quickly (under 1 minute) and uses minimal resources. Set the working directory to a temporary location.
2.  **Reproducibility**: Apply the `seed_everything` utility to ensure consistent results.
3.  **Component Verification**:
    *   **Dataset**: Instantiate the training dataset using `get_dataset`. Verify the subset size matches the debug configuration and check the shape/type of the returned tensors.
    *   **Model**: Instantiate `CassavaResNet`. Perform a forward pass with a dummy input tensor to verify the output shape corresponds to `(batch_size, num_classes)`.
4.  **Pipeline Execution**:
    *   **Training**: Execute `run_training` for a single epoch. This validates the data loading, loss calculation, backpropagation, and validation loop.
    *   **Checkpoint Handling**: Since the training loop only saves the model if validation accuracy improves (which isn't guaranteed in a 1-epoch debug run with random weights), manually save a model checkpoint if one wasn't created. This ensures the inference step has a file to load.
    *   **Inference**: Execute `run_inference` using the saved checkpoint. Verify that the submission CSV is generated and contains the correct number of rows and columns.
5.  **Validation**: Use assertions throughout to confirm that file paths exist, tensor shapes are correct, and dataframes have the expected structure.
