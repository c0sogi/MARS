The implementation strategy is as follows:

1.  **Configuration & Setup**: Initialize the environment, setting random seeds for reproducibility. Override `Config.EPOCHS` to 1 to satisfy the "fast baseline" requirement while maintaining the full 5-fold structure.
2.  **Data Preparation**: Ensure the training data is processed and stratified folds are assigned. Load the metadata to align Out-Of-Fold (OOF) predictions correctly.
3.  **Level 0 Training (Base Models)**:
    *   Iterate through the three specified architectures: `vit_base_patch16_384`, `beit_base_patch16_384`, and `convnext_base_384_in22ft1k`.
    *   For each architecture, perform 5-Fold Cross-Validation.
    *   Train each fold for 1 epoch using Automatic Mixed Precision (AMP) and MixUp regularization.
    *   Generate OOF predictions on the validation fold and store them.
    *   Save model checkpoints for later inference.
4.  **Level 1 Training (Meta-Learner)**: Concatenate the OOF predictions from all architectures and train a Logistic Regression meta-learner to fuse the base model outputs.
5.  **Hold-out Evaluation**:
    *   Load the distinct hold-out validation set (`metadata/val.csv`).
    *   Generate predictions using all 15 trained models (3 architectures $\times$ 5 folds).
    *   Aggregate predictions via the Meta-Learner.
    *   Compute and print the **Final Validation Metric**.
6.  **Failure Analysis**: Analyze the performance on the hold-out set by computing the confusion matrix and checking for systematic errors correlated with class labels.
7.  **Submission**: If the validation metric exceeds the specified threshold (0.908678...), generate predictions for the test set using the full ensemble and save the `submission.csv`.
