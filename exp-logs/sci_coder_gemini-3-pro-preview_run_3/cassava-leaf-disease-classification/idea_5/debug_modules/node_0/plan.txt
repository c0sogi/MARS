The following implementation strategy outlines the steps to demonstrate the Cassava Leaf Disease Classification pipeline:

1.  **Configuration Setup**: We will import the `CFG` class from `library.config` and override specific parameters to create a fast "demo" mode. This includes enabling debug mode (to use a tiny data subset), reducing epochs to 1, reducing image size to 224x224, and setting a custom output directory.
2.  **Data Loading**: We will utilize `get_dataloaders` from `library.dataset` to initialize training and validation loaders. We will explicitly verify the shape of the batches and the functionality of the MixUp augmentation.
3.  **Model Initialization**: We will instantiate the `CassavaClassifier` from `library.model`. To ensure the script runs quickly and without requiring internet access for weight downloads, we will initialize it with `pretrained=False`. We will validate the model architecture by running a dummy forward pass.
4.  **Training Execution**: We will set up the optimizer (AdamW) and scheduler (CosineAnnealingLR) and execute the training loop using `train_model` from `library.engine`. We will verify that the training completes and the best model weights are saved to the specified directory.
5.  **Inference and Submission**: We will call `generate_submission` from `library.inference`, which loads the saved model weights and performs Test-Time Augmentation (TTA) on the test set. Finally, we will verify the existence and format of the generated `submission.csv`.
