The issue is caused by an API mismatch with `albumentations` version 2.0. The `Resize` and `CenterCrop` transforms in the validation pipeline are instantiated using a single `size` tuple argument, but these specific classes strictly require separate `height` and `width` arguments in this version. This is a known pitfall where API changes (like `RandomResizedCrop` accepting `size`) are incorrectly assumed to apply to other components (Cite debug_lesson_1). I will modify `library/dataset.py` to provide explicit `height` and `width` arguments for `A.Resize` and `A.CenterCrop`.
