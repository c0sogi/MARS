Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Setup & Configuration**: Initialize the `Config` class, set random seeds for reproducibility, and define the computation device (GPU).
2.  **Data Loading**: Use the provided `load_and_process_data` function to load training and validation metadata. Create `AppleDataset` instances with appropriate transforms (augmentation for training, resizing for validation). Wrap these in `DataLoader`s.
3.  **Model Initialization**: Instantiate the `AppleClassifier` (EfficientNet-B0) and move it to the GPU.
4.  **Training Loop**: Configure the `AdamW` optimizer, `CosineAnnealingLR` scheduler, and `AsymmetricLoss`. Use the `fit` function from the `library.engine` module to train the model. This handles the training epochs, validation, and early stopping, saving the best model to disk.
5.  **Final Evaluation**:
    *   Reload the best model weights.
    *   Calculate the final validation F1 score using the `validate` function and print it in the required format.
6.  **Failure Analysis**:
    *   Perform a separate inference pass on the validation set to retrieve raw predictions and targets.
    *   Calculate the "Error Magnitude" for each sample (Mean Absolute Error between probabilities and targets).
    *   Extract image metadata (Width, Height, Brightness) for the validation images on-the-fly.
    *   Compute and print the Pearson correlation between the error magnitude and these metadata features to identify systematic weaknesses.
7.  **Submission**:
    *   Compare the final validation F1 score against the threshold (0.8854796331311056).
    *   If the threshold is met, load the test metadata, create a test `DataLoader`, and generate the submission file using `inference_tta` (Test Time Augmentation).
