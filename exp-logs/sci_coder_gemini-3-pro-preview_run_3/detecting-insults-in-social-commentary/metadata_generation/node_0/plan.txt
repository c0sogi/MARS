The following script performs the metadata generation task for the Insult Detection dataset.

**Strategy:**
1.  **Setup**: Creates the `./metadata` directory to store the output files.
2.  **Data Loading**: Reads `train.csv` and `test.csv` from the `./input` directory using Pandas. It handles potential quoting issues by relying on the standard CSV parser which respects double quotes.
3.  **Preprocessing**: It identifies the label column (`Insult`) and the feature columns (`Date`, `Comment`). It ensures the label is treated as an integer for stratification.
4.  **Splitting**: It uses `StratifiedShuffleSplit` with a fixed random state (42) to split the training data into an 80% training set and a 20% validation set, preserving the class distribution of the `Insult` label.
5.  **Metadata Generation**: Saves the resulting dataframes (`train`, `val`, `test`) to the `./metadata` directory as CSV files. This effectively serves as the metadata containing the text content and labels.
6.  **Validation**:
    *   Reloads the generated metadata files.
    *   Prints summary statistics (row counts, label distribution).
    *   Verifies that the train/val split respects the 80:20 ratio and that stratification was successful (checking label distribution similarity).
    *   Since the dataset is text-based and contained within the CSVs (no external image/audio files), the file path resolution check is skipped as there are no external file paths to verify.
