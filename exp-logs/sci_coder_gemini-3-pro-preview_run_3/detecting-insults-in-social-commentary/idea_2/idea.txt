To address the limitations of the linear baseline while preserving its efficiency in capturing explicit signals, I propose a **Hybrid Statistical-Neural Ensemble**. This strategy structurally evolves the solution by introducing a deep learning branch to capture semantic context, which is then fused with the n-gram based linear model.

# Model
The architecture consists of two parallel classification streams whose outputs are combined via a meta-learner:

1.  **Stream A (Statistical Branch):** A **Naive Bayes-weighted Logistic Regression (NB-LR)** model. This component is retained to exploit its proven ability to detect explicit insults and morphological patterns efficiently Cite {solution_lesson_node_00002}. It will utilize **Word n-grams (1-3)** and **Character n-grams (3-5)**, explicitly avoiding the noisy 2-gram window identified as detrimental in previous experiments Cite {solution_lesson_node_00003}.
2.  **Stream B (Neural Branch):** A **Fine-Tuned Transformer** (specifically `roberta-base`). Unlike the linear model, this branch utilizes self-attention mechanisms to capture long-range dependencies, context, and implicit insults (e.g., sarcasm or insults without profanity) that n-gram models often miss.
3.  **Fusion Layer:** The probability outputs from both streams will be combined using a **Weighted Average Ensemble**, where the weights are optimized on the validation set to maximize AUC.

# Data
Preprocessing will be bifurcated to suit each stream:
1.  **Common Preprocessing:** All text will undergo unicode decoding to resolve escaped characters (e.g., `\u0027` to `'`).
2.  **Stream A Preparation:** The text will be vectorized into sparse TF-IDF matrices for both word and character n-grams. The Naive Bayes log-count ratios will be computed on the training set and applied to scale these features Cite {solution_lesson_node_00002}.
3.  **Stream B Preparation:** The text will be tokenized using the pre-trained RoBERTa tokenizer (Byte-Pair Encoding), truncating or padding sequences to a fixed maximum length (e.g., 128 or 256 tokens) suitable for the model.

# Training
The training procedure will handle the two streams independently before fusion:
1.  **Stream A:** Trained using a Logistic Regression solver (e.g., Liblinear) with L2 regularization. The regularization strength `C` will be tuned, keeping in mind the lesson that overly strong regularization can underfit high-dimensional features Cite {solution_lesson_node_00003}.
2.  **Stream B:** Trained using a standard deep learning loop on the GPU. Key techniques include:
    *   **Optimizer:** AdamW with a linear learning rate scheduler (warmup followed by decay).
    *   **Loss Function:** Binary Cross-Entropy.
    *   **Regularization:** Dropout within the transformer layers and early stopping based on Validation AUC to prevent overfitting on this relatively small dataset.
3.  **Ensemble Optimization:** After training both models, a simple grid search or linear regression will be performed on the validation set predictions to find the optimal scalar weights $w_A$ and $w_B$ such that $P_{final} = w_A \cdot P_A + w_B \cdot P_B$.

# Evaluation
For the test set, the raw text will be processed through both pipelines:
1.  **Inference A:** Generate probability scores using the fitted NB-LR model.
2.  **Inference B:** Generate probability scores using the fine-tuned RoBERTa model.
3.  **Final Prediction:** Compute the weighted average of the two probability vectors using the weights determined during the training phase. These final scores will be submitted.
