Based on the accumulated lessons, I propose a **Domain-Adapted RoBERTa-Large Ensemble with Full-Data Training**.

This strategy introduces a structural innovation by implementing a **Domain-Adaptive Pre-training (DAPT)** stage. This allows us to leverage the unlabeled test data (which is comparable in size to the training set) to adapt the model's linguistic representation to the specific vernacular of the forum comments before supervised fine-tuning. This directly addresses the data scarcity issue without the risks of pseudo-labeling.

# Model
1.  **Backbone: RoBERTa-Large**
    We will retain **RoBERTa-Large** as the backbone. Previous experiments demonstrated that for explicit sentiment tasks, the more complex DeBERTa-v3 architecture offered negligible performance gains (+0.000008 AUC) while increasing training time and instability **Cite {solution_lesson_node_00020}**.
2.  **Aggregation: Mean Pooling**
    We will use **Mean Pooling** of the final hidden states for the classification head. We explicitly reject complex heads like Attention Pooling, which were shown to overfit on this small dataset **Cite {solution_lesson_node_00013}**, and prefer Mean Pooling over the standard `[CLS]` token for better context aggregation **Cite {solution_lesson_node_00007}**.
3.  **Regularization Configuration**
    *   **Dropout:** Set to **0.2** to prevent overfitting, strictly avoiding the default 0.1 **Cite {solution_lesson_node_00008}**.
    *   **Layer Freezing:** We will **freeze the embeddings and the bottom 6 encoder layers**. This improves efficiency and acts as regularization by preserving general linguistic features **Cite {solution_lesson_node_00010}**.

# Data
1.  **Preprocessing:** Standard unicode decoding will be applied.
2.  **Tokenization:** We will use a **Maximum Sequence Length of 160**. This is critical to capture the full context of longer, rant-style comments which are often truncated by the standard 128 length **Cite {solution_lesson_node_00008}**.
3.  **Dataset Construction:**
    *   **DAPT Corpus:** We will concatenate the text from the **Train, Validation, and Test** sets. This creates a larger unsupervised corpus for domain adaptation.
    *   **Supervised Corpus:** We will **explicitly concatenate** the Train and Validation datasets into a single labeled set **Cite {solution_lesson_node_00021}**. We reject Cross-Validation splits because fragmenting the small dataset (e.g., using only 80% for training) degrades the performance of the individual models **Cite {solution_lesson_node_00018}**.

# Training
The training pipeline consists of two distinct stages:

1.  **Stage 1: Domain-Adaptive Pre-training (Masked Language Modeling)**
    We will train the RoBERTa-Large backbone on the **DAPT Corpus** using the Masked Language Modeling (MLM) objective. This adapts the model to the specific noise, slang, and structure of the comments (including unicode artifacts) without requiring labels.

2.  **Stage 2: Supervised Fine-Tuning with Seed Averaging**
    We will fine-tune the domain-adapted model on the **Supervised Corpus**.
    *   **Ensembling Strategy:** Instead of K-Fold CV (which reduces data), we will use **Seed Averaging**. We will train **3 independent models** on the *entire* labeled dataset using different random seeds. This mitigates the hardware stochasticity observed in previous runs **Cite {solution_lesson_node_00012}** while ensuring every model sees 100% of the available training data.
    *   **Scheduler:** We will use a linear scheduler with warmup, ensuring the decay is calculated based on the fixed number of epochs/steps to avoid the compressed schedule failure **Cite {solution_lesson_node_00011}**.
    *   **Batch Size:** We will maintain a stable effective batch size (e.g., 16) using Gradient Accumulation if necessary, to avoid the instability caused by small physical batches **Cite {solution_lesson_node_00015}**.

# Evaluation
1.  **Inference:** The test set will be processed by the 3 trained models (from the Seed Averaging stage).
2.  **Prediction:** The final submission will be the arithmetic mean of the probability outputs from these 3 models.
