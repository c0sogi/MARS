The issue stems from `StratifiedKFold` interpreting the floating-point `score` column as a continuous variable, which it does not support. Stratification requires discrete classes. Even though the scores are discrete (0.0, 0.25, etc.), their data type causes the error. The fix is to cast the `score` column to a string type during the split generation, forcing scikit-learn to treat these values as categorical labels.
