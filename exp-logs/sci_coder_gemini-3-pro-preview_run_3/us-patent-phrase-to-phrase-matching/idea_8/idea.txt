Based on the comprehensive analysis of previous attempts and the lessons learned, I propose the **Stratified Cross-Validation Ensemble with Weighted Layer Pooling**.

This strategy structurally evolves the single-model approach of Idea 6 by introducing a **Weighted Layer Pooling** mechanism to capture linguistic features from all depths of the network (improving upon the failed implementation in Idea 7) and wrapping the solution in a **Stratified K-Fold Ensemble** to maximize generalization and stability. Crucially, it explicitly discards the Domain-Adaptive Pre-training (DAPT) phase that caused catastrophic failure in Idea 7.

### Model
*   **Backbone:** We will utilize **`microsoft/deberta-v3-large`** as the core encoder. Its disentangled attention mechanism provides the strongest foundation for semantic matching (Cite solution_lesson_node_00001).
*   **Architecture:** We will persist with the **Cross-Encoder** design, concatenating context and phrases into a single sequence to enable deep token-level interaction (Cite solution_lesson_node_00008).
*   **Weighted Layer Pooling (Structural Innovation):** Instead of utilizing only the final hidden state (Idea 6) or a concatenation of the last four (Idea 7), we will implement **Scalar Mixing (Weighted Layer Pooling)**. We will learn a scalar weight $w_i$ for every layer $i$ of the transformer backbone. The output representation will be the weighted sum of all layer outputs: $H = \sum_{i=0}^{L} \frac{\exp(w_i)}{\sum_j \exp(w_j)} H_i$.
    *   *Rationale:* Different layers of a Transformer capture different linguistic properties (e.g., lower layers capture syntax/lexical matches, higher layers capture abstract semantics). By allowing the model to dynamically weight these contributions, we improve its ability to distinguish between "exact matches" (lexical) and "synonyms" (semantic), addressing the nuances of the scoring rubric.
*   **Head:** The weighted output will be passed through an **Attention Pooling** layer (Cite solution_lesson_node_00011) to aggregate token embeddings, followed by **Multi-Sample Dropout** and the **Dual-Head** structure (Regression + Classification) (Cite solution_lesson_node_00014).

### Data
*   **Hierarchical Context Expansion:** We will map every `context` code to its full lineage of descriptions (Section > Class > Subclass) and inject this into the input sequence (e.g., `[CLS] Section Desc [SEP] Class Desc [SEP] Subclass Desc [SEP] Anchor [SEP] Target [SEP]`). This proven technique aligns the model with the specific technical domain (Cite solution_lesson_node_00021).
*   **Stratified K-Fold Split:** We will implement a **5-Fold Stratified Cross-Validation** scheme. We will split the training data into 5 folds, stratifying by the `score` distribution. This ensures that each fold maintains the class imbalance profile of the full dataset, which is critical for training the classification head effectively.

### Training
*   **No DAPT:** We will explicitly **skip Domain-Adaptive Pre-training**. Previous experiments demonstrated that DAPT on this specific corpus led to catastrophic forgetting and model corruption (Cite solution_lesson_node_00023). We will rely on the robust pre-trained weights of DeBERTa-v3-Large directly.
*   **Loss Function:** We will optimize the **Hybrid Pearson Loss**: $L_{Total} = L_{MSE} + \lambda_1 L_{CE} + \lambda_2 (1 - \rho)$. This combines geometric precision, decision-boundary sharpness, and direct metric optimization (Cite solution_lesson_node_00021).
*   **Regularization:** We will apply **Adversarial Weight Perturbation (AWP)** during training to flatten the loss landscape and improve robustness against unseen phrasing (Cite solution_lesson_node_00012).
*   **Optimization:** We will use the AdamW optimizer with **Layer-wise Learning Rate Decay (LLRD)**. We will set a higher learning rate for the pooling/heads and a progressively lower rate for the backbone layers to preserve pre-trained knowledge (Cite solution_lesson_node_00011).
*   **Ensemble Training:** We will train 5 independent models, one on each fold of the data.

### Evaluation
*   **Inference:** For each sample in the test set, we will generate predictions using all 5 trained models.
*   **Ensemble Aggregation:** The final similarity score will be the **arithmetic mean** of the 5 predictions. This averaging reduces the variance associated with any single model's initialization or data split.
*   **Post-Processing:** The aggregated scores will be clipped to the [0, 1] range.
