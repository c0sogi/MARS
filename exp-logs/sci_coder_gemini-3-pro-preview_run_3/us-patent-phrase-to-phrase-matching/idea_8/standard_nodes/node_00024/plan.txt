Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment, set random seeds for reproducibility, and instantiate the `Config` class to ensure output directories exist. Override `Config.epochs` to 3 to ensure the execution completes within the time limit while maintaining performance.
2.  **Data Preparation**: Load the training (`metadata/train.csv`), validation (`metadata/val.csv`), and test (`metadata/test.csv`) datasets. Apply Stratified K-Fold splitting (5 folds) to the training dataset. The validation dataset is kept strictly as a hold-out set for final evaluation.
3.  **Model Training (5-Fold CV)**: Iterate through each fold. For each fold:
    *   Initialize the `CustomModel` (DeBERTa-v3-Large with Weighted Layer Pooling).
    *   Setup the optimizer with Layer-wise Learning Rate Decay (LLRD) and a cosine scheduler.
    *   Train the model using the `HybridLoss` (MSE + Pearson + CrossEntropy) and Adversarial Weight Perturbation (AWP).
    *   Validate on the fold's validation split after each epoch and save the best model checkpoint.
4.  **Hold-out Evaluation**: Load the best models from all 5 folds. Perform ensemble inference (averaging predictions) on the unseen hold-out validation dataset (`metadata/val.csv`). Calculate and print the final Pearson correlation metric.
5.  **Failure Analysis**: Analyze the prediction errors on the validation set. Calculate correlations between the error magnitude and input features (e.g., text lengths, context length) to identify systematic weaknesses.
6.  **Submission**: If the final validation score exceeds the specified threshold (0.8698...), perform ensemble inference on the test set (`metadata/test.csv`) and save the results to `submission.csv`.
