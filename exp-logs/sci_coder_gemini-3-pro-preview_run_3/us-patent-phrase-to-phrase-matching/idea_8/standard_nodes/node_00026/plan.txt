The `torch.OutOfMemoryError` is caused by the high memory consumption of the `deberta-v3-large` backbone, particularly when Adversarial Weight Perturbation (AWP) doubles the computational graph size during training. To resolve this, I will enable Gradient Checkpointing, which trades compute for memory by re-calculating intermediate activations during the backward pass (Cite debug_lesson_8).

To implement this robustly, I will modify `library/model.py` to:
1.  Explicitly disable `use_cache` in the model configuration before initialization to prevent conflicts with checkpointing (Cite debug_lesson_6).
2.  Enable gradient checkpointing on the backbone model with `use_reentrant=False` to avoid "backward through graph a second time" errors common with DeBERTa (Cite debug_lesson_7).
