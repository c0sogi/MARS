The `compute_pearson` function in `library/utils.py` currently returns a NumPy scalar (e.g., `numpy.float64`) because `scipy.stats.pearsonr` returns NumPy types. This causes the `isinstance(val_pearson, float)` check in `runfile.py` to fail, as NumPy scalars do not inherit from Python's native `float` class. I will fix this by explicitly casting the correlation coefficient to a native Python `float` before returning it.
