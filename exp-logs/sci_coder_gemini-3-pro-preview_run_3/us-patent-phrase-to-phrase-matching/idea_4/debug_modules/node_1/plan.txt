The `RuntimeError: Trying to backward through the graph a second time` is caused by **Gradient Checkpointing**, which complicates the autograd graph by re-computing activations during the backward pass. This often leads to conflicts when using custom training loops or specific library interactions. Since the available hardware (A100 40GB) has sufficient memory for the model, we can disable this optimization to resolve the error and simplify the graph (Cite debug_lesson_1). Additionally, we will explicitly cast the Pearson correlation score from a NumPy scalar to a native Python `float` to prevent potential type-related issues at interface boundaries (Cite debug_lesson_2).
