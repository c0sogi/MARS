The `RuntimeError` occurs because the `bert-tiny` model used in the demo has fewer layers (2 transformer layers + embeddings = 3 hidden states) than the default configuration expects (4 layers). This leads to a shape mismatch in the regression head: the model produces a concatenated embedding of size $128 \times 3 = 384$, but the linear layer is initialized expecting $128 \times 4 = 512$. The fix is to explicitly set `Config.pool_layers` to 2 in `runfile.py` when overriding the configuration for the demo, ensuring the model architecture matches the backbone's depth.
