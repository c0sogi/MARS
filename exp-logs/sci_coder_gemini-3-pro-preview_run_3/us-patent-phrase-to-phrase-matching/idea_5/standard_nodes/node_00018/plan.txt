The execution failed with a `torch.OutOfMemoryError` during the Domain-Adaptive Pre-training (DAPT) phase because the `AutoModelForMaskedLM` instance was not configured to use gradient checkpointing, and the batch size (32) was too large for the available GPU memory (approx. 16GB as per the traceback).

To fix this, I will:
1.  Enable gradient checkpointing for the DAPT model in `library/engine.py`. This ensures the auxiliary model used for pre-training is memory-optimized (Cite debug_lesson_4).
2.  Reduce the batch sizes in `runfile.py` to 8 (compatible with 16GB VRAM) and enable gradient checkpointing for the main `CustomModel` instance to prevent subsequent OOM errors during the main training loop.
