To establish a highly efficient baseline, I propose a **Siamese Deep Averaging Network (DAN)**. This approach strikes a balance between the learnable semantic representations of deep learning and the computational efficiency of bag-of-words models. It eliminates the computational overhead of recurrent (RNN/LSTM) or attention-based (Transformer) mechanisms while still allowing for dense feature learning.

### Model
The architecture is designed as a Siamese network with three inputs: the `anchor` phrase, the `target` phrase, and the `context` label.
1.  **Shared Encoder (Siamese Branch):** Both the `anchor` and `target` phrases are fed into a shared encoder. This encoder consists of:
    *   **Token Embedding Layer:** Maps input tokens to dense vectors.
    *   **Global Average Pooling:** Computes the mean of the token vectors for the input phrase. This effectively captures the "average meaning" of the phrase without processing sequence order, significantly speeding up computation.
    *   **Projection Layer:** A dense (fully connected) layer with a non-linear activation (ReLU) to project the averaged representation into a more expressive semantic space.
2.  **Context Branch:** The `context` code is passed through a separate, smaller embedding layer to learn a dense representation of the technical domain.
3.  **Fusion & Regression Head:** The encoded `anchor` vector ($u$) and `target` vector ($v$) are combined using heuristic matching operations—specifically, their element-wise absolute difference ($|u - v|$) and element-wise product ($u * v$). These matching features are concatenated with the original vectors ($u, v$) and the `context` embedding. The resulting vector is fed into a final linear layer to predict the scalar similarity score.

### Data
1.  **Tokenization:** A simple whitespace tokenizer will be used to split phrases into words. Text will be lowercased to reduce vocabulary size.
2.  **Vocabulary Construction:** A vocabulary will be built from the training corpus. Rare tokens (appearing fewer than a set threshold) will be mapped to an `<UNK>` token to keep the embedding matrix small.
3.  **Context Indexing:** The unique `context` labels (CPC codes) will be mapped to integer indices for the context embedding layer.
4.  **Batching:** Input sequences will be padded to the maximum length within a batch (or a fixed length) to enable efficient tensor operations.

### Training
1.  **Loss Function:** The model will be trained using **Mean Squared Error (MSE)** loss, which is appropriate for regressing the continuous similarity scores.
2.  **Optimizer:** The **Adam** optimizer will be used with default parameters, as it generally converges well for simple architectures without extensive tuning.
3.  **Strategy:** Training will proceed for a fixed number of epochs with a small batch size. To prevent overfitting given the model's simplicity, a moderate dropout rate will be applied after the embedding and projection layers.

### Evaluation
1.  **Inference:** For the test set, the preprocessed `anchor`, `target`, and `context` inputs will be passed through the trained network to generate raw similarity scores.
2.  **Post-Processing:** The raw predictions will be clipped to the [0, 1] range to ensure valid output values.
3.  **Submission:** The resulting scores will be paired with their corresponding `id`s and saved to the submission file.
