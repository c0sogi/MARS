The error occurs because the `SiameseDAN` model is initialized using the hardcoded `Config.EMBEDDING_DIM` (100), while the `pretrained_embeddings` loaded from the SentenceTransformer have a dimension of 384. This mismatch triggers the validation check in the model's constructor. To fix this, I will update `library/trainer.py` and `runfile.py` to dynamically derive the `embedding_dim` from the `embedding_matrix` shape if it is available, rather than relying on the static configuration value. This ensures the model dimensions align with the loaded assets (Cite debug_lesson_1).
