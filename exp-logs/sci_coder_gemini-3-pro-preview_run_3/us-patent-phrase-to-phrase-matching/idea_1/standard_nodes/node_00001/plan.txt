The implementation strategy focuses on orchestrating the provided library components to create a fast, efficient, and reproducible baseline.

1.  **Configuration & Setup**: We start by setting the random seed for reproducibility. To satisfy the "fast baseline" requirement, we override the default configuration to reduce the number of epochs to 10 and increase the batch size to 128. This ensures the training completes well within the time limit while still learning meaningful representations.
2.  **Training & Submission**: We utilize the `Trainer` class to handle the heavy lifting. The `trainer.train()` method is called to execute the training loop, perform early stopping based on validation loss, and automatically generate the submission file (`submission.csv`) using the best model. We enable `load_cached_data=True` to speed up data loading.
3.  **Validation Assessment**: After training, we explicitly reload the best saved model state and the validation data loader. We run a dedicated evaluation pass to compute the Pearson correlation coefficient on the full validation set. This value is printed in the required format `Final Validation Metric: <value>`.
4.  **Failure Analysis**: We perform a post-hoc analysis on the validation set. We calculate the absolute error for each prediction and compute the correlation between this error and specific input meta-features (Jaccard similarity, character length difference, and common word count). This helps identify if the model struggles with specific types of phrase pairs (e.g., those with no common words).
