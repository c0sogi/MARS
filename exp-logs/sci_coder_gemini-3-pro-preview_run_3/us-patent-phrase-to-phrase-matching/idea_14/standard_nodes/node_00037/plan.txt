To resolve the `torch.OutOfMemoryError` caused by the large model size and batch configuration, I will implement a comprehensive memory optimization strategy.

1.  **Reduce Batch Size**: I will lower `train_batch_size` from 16 to 8 in `library/config.py` to fit the `DeBERTa-v3-large` model within the 16GB VRAM limit. Cite {debug_lesson_13}.
2.  **Enable Gradient Checkpointing & Disable Cache**: In `library/model.py`, I will explicitly set `config.use_cache = False` (Cite {debug_lesson_5}) and enable gradient checkpointing on the backbone (Cite {debug_lesson_8}). This trades computation for memory by recomputing activations during the backward pass.
3.  **Implement Mixed Precision (AMP)**: In `library/engine.py` and `runfile.py`, I will introduce `torch.amp.autocast` and `torch.amp.GradScaler`. This reduces memory usage by performing operations in float16 where possible. I will also ensure the `scaler` handles the adversarial weight perturbation (AWP) steps correctly by scaling gradients before backward passes and unscaling them before clipping. Cite {debug_lesson_8}.
