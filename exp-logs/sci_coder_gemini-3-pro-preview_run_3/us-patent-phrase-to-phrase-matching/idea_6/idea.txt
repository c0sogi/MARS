Based on the lessons learned from previous iterations, I propose an optimized strategy titled **"Hierarchical Context-Aware Cross-Encoder with Pearson-Objective Optimization"**. This solution structurally evolves the previous approaches by deepening the input representation through hierarchical context injection and aligning the training objective directly with the evaluation metric.

# Model
*   **Backbone:** We will utilize **`microsoft/deberta-v3-large`** as the core transformer. This preserves the high-capacity, pre-trained linguistic representations that were proven essential for this task (Cite solution_lesson_node_00001).
*   **Architecture:** We will maintain the **Cross-Encoder** design, processing the context and phrase pairs as a single concatenated sequence to capture token-level interactions (Cite solution_lesson_node_00008).
*   **Hierarchical Context Injection:** Instead of injecting only the leaf-level CPC description (as in Idea 5), we will construct a **Hierarchical Context String**. We will map each `context` code to its full lineage (e.g., Section Description + Class Description + Subclass Description). The input format will be: `[CLS] Section Desc [SEP] Class Desc [SEP] Subclass Desc [SEP] Anchor [SEP] Target [SEP]`. This provides the model with both the broad domain (e.g., "Electricity") and the specific technical field (e.g., "Wireless Communication"), reducing ambiguity for polysemous terms.
*   **Pooling & Heads:** We will employ **Attention Pooling** to aggregate the token embeddings, allowing the model to dynamically weight informative terms (Cite solution_lesson_node_00011). The output will feed into a **Dual-Head** structure (Regression and Classification) to leverage the benefits of multi-task learning (Cite solution_lesson_node_00014).

# Data
*   **Context Expansion:** We will generate a metadata dictionary mapping every unique CPC code in the dataset to its hierarchical text descriptions using the official CPC scheme.
*   **Input Formatting:** Training and test samples will be pre-processed into the hierarchical input format described above.
*   **Domain-Adaptive Pre-training (DAPT):** We will continue to perform DAPT on the corpus of unique phrases and context descriptions to adapt the backbone's vocabulary to the patent domain (building on the trajectory of previous ideas).

# Training
*   **Loss Function (Structural Innovation):** We will introduce a **Pearson Correlation Loss** component to directly optimize the competition metric. The total loss will be a weighted sum: $L_{Total} = L_{MSE} + \lambda_1 L_{CE} + \lambda_2 (1 - \rho)$, where $\rho$ is the Pearson correlation of the batch. This combines the geometric stability of MSE and the decision boundaries of Cross-Entropy (Cite solution_lesson_node_00014) with a direct maximization of the target metric.
*   **Regularization:** We will integrate **Adversarial Weight Perturbation (AWP)** into the training loop to flatten the loss landscape and improve generalization on unseen pairs (Cite solution_lesson_node_00012).
*   **Optimization:** We will use the AdamW optimizer with **Layer-wise Learning Rate Decay (LLRD)**, setting a lower learning rate for the backbone layers and a higher one for the heads to preserve pre-trained features (Cite solution_lesson_node_00011).

# Evaluation
*   **Inference:** Test set pairs will be formatted with the full hierarchical context strings.
*   **Prediction:** The model will predict raw scores using the regression head.
*   **Post-Processing:** Predictions will be clipped to the [0, 1] range.
