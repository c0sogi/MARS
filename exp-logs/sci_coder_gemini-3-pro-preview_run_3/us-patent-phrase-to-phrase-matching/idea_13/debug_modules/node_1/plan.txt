The `RuntimeError: value cannot be converted to type at::Half without overflow` occurs because the code uses `-1e9` to mask padding tokens while running in Mixed Precision (FP16). The value `-1e9` exceeds the range of `float16` (approximately $\pm 65,504$), causing an overflow during the cast. To fix this, I will replace `-1e9` with `-1e4` ($-10,000$). This value is safe for `float16` and sufficiently negative to ensure the subsequent Softmax operation yields zero probability for masked tokens. Cite debug_lesson_4.
