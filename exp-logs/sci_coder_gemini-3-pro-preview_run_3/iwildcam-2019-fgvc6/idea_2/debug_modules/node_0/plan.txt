This script demonstrates the end-to-end usage of the provided animal classification library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to enable debug mode (using a small subset of data), disable pretrained weight downloads (for speed), and reduce training epochs to 1. This ensures the demonstration runs quickly.
2.  **Utility Verification**: Validates the metric calculation (`calculate_macro_f1`) and checkpoint saving/loading functions from `library.utils`.
3.  **Dataset Verification**: Instantiates the DataLoaders via `library.dataset.get_dataloaders` and asserts that the batch shapes, data types, and label dimensions are correct.
4.  **Model Verification**: Instantiates the `AnimalClassifier` from `library.model`, performs a forward pass with a dummy batch, and verifies the output shape matches `(Batch_Size, Num_Classes)`.
5.  **Training Integration**: Executes the full training pipeline using `library.train.run_training`. This trains the model on the debug subset for one epoch and saves the best model.
6.  **Inference Integration**: Executes the prediction pipeline using `library.predict.generate_submission` and verifies that the output submission CSV is correctly formatted and contains the expected number of rows.
