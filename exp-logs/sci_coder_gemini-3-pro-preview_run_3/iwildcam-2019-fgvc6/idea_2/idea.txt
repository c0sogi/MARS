# Proposed Solution: EfficientNetV2 with Test-Time Augmentation

## Model
We will transition the backbone architecture from the standard ResNet-18 to **EfficientNetV2-Small**.
- **Structural Innovation:** Unlike the ResNet-34 experiment which simply scaled depth and failed to improve performance (Cite solution_lesson_node_00006), EfficientNetV2 introduces fundamental architectural improvements. It utilizes **Fused-MBConv** blocks for faster training inference and **Squeeze-and-Excitation (SE)** attention mechanisms. These SE blocks allow the model to explicitly model channel-wise interdependencies, which is critical for distinguishing between visually similar species (e.g., Wolf vs. Coyote) by emphasizing informative features and suppressing background noise.
- The model will be initialized with pre-trained ImageNet weights, and the classification head will be adapted to the 23 target classes.

## Data
- **Preprocessing:** We will increase the input image resolution from 224x224 to **256x256**. This moderate increase helps preserve fine-grained details necessary for identifying smaller animals or animals at a distance, without incurring the excessive computational cost of very high resolutions.
- **Sampling:** We will strictly retain the **Weighted Random Sampler** to handle the extreme class imbalance (Cite solution_lesson_node_00002). This ensures that rare classes like 'mountain_lion' are sampled with equal frequency to the dominant 'empty' class within each batch.
- **Augmentation:** We will employ the **Heavy Augmentation** strategy (ShiftScaleRotate, RandomBrightnessContrast) which was proven to significantly improve generalization and robustness (Cite solution_lesson_node_00003).

## Training
- **Optimizer & Scheduler:** We will use the **OneCycleLR** scheduler with the **AdamW** optimizer. Following the success of aggressive learning rates in previous experiments, we will set the maximum learning rate to **1e-3** to facilitate rapid convergence and escape sharp local minima (Cite solution_lesson_node_00004).
- **Loss Function:** We will use standard **Cross-Entropy Loss**. We will explicitly avoid Label Smoothing, as previous experiments indicated it degrades Macro F1 on this specific dataset by diluting confidence on rare classes (Cite solution_lesson_node_00006).

## Evaluation
- **Test-Time Augmentation (TTA):** To further boost the Macro F1 score, we will implement a Test-Time Augmentation strategy. During inference, we will predict on both the original image and a horizontally flipped version. The final prediction will be the average of the logits (soft voting) from these views. This technique reduces prediction variance and is particularly effective for improving the recall of minority classes by smoothing out noise in the decision boundary.
