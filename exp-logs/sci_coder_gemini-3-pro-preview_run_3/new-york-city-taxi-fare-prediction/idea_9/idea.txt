Based on the analysis of the previous experiments and the accumulated lessons, I propose a **Tri-Modal Stacked Ensemble with Learnable Spatial Embeddings**.

This strategy represents a structural evolution of the ensemble approach (Idea 7). It addresses the need for a third "strong" learner to diversify the stack by introducing a Deep Learning component. However, unlike the failed hybrid attempt in Idea 2 (Cite solution_lesson_node_00011), this Neural Network is explicitly designed with **Spatial Grid Embeddings** to overcome the difficulty MLPs have in learning high-frequency spatial variations from raw coordinates.

# Model
I propose a **Two-Stage Stacked Ensemble** integrating three distinct base learners and a linear meta-learner.

*   **Level 0 (Base Learners):**
    1.  **XGBoost Regressor:** Configured for **Depth-wise** growth using the **NVIDIA A100 GPU** (`tree_method='gpu_hist'`). This captures complex interactions via deep, symmetric trees (Retained from Idea 7).
    2.  **LightGBM Regressor:** Configured for **Leaf-wise** growth using the **12 vCPUs** (`boosting_type='gbdt'`). This captures asymmetric patterns using Gradient-based One-Side Sampling (Retained from Idea 7).
    3.  **New: Spatial ResNet with Grid Embeddings:** A Residual Neural Network designed for geospatial tabular data.
        *   **Structural Innovation:** Instead of feeding only raw continuous coordinates (which requires the NN to approximate complex street-level price functions via dense layers), I will introduce **Coordinate Grid Embeddings**.
        *   **Mechanism:** Latitude and Longitude will be discretized into fine-grained bins (e.g., 0.002° resolution, approx. 200m). These indices will map to learnable embedding vectors, allowing the network to learn a smooth, continuous "price map" of the city end-to-end.
        *   **Backbone:** A ResNet architecture (Linear $\rightarrow$ BatchNorm $\rightarrow$ ReLU $\rightarrow$ Residual Add) to facilitate deep feature extraction.

*   **Level 1 (Meta-Learner):**
    *   **Ridge Regression:** A linear model trained on the out-of-sample predictions of the three base learners. This dynamically learns the optimal weighting strategy, correcting for the biases of individual models (Cite solution_lesson_node_00027).

# Data
**Preprocessing (Correction & Exploitation):**
1.  **Universal Coordinate Sanitation:** I will apply a strict bounding box filter (Latitude 40–42, Longitude -73 to -75) to the **Training, Validation, AND Test sets**. This is mandatory to prevent "distance explosion" from outliers (e.g., 0,0 coordinates) that invalidated previous attempts (Cite solution_lesson_node_00016).
2.  **Target Filtering:** The training data will be filtered to keep `fare_amount` between 0 and 500. This protects the MSE loss function from extreme outliers (Cite solution_lesson_node_00005).
3.  **Full Dataset Utilization:** All models will be trained on the full 55 million row dataset. Data volume is the primary driver of performance (Cite solution_lesson_node_00012).

**Feature Engineering (Dual-Pipeline Strategy):**
I will implement two distinct feature pipelines to respect the specific strengths of Trees vs. Neural Networks:

*   **Shared Features:**
    *   **Rotated Coordinates:** 29° alignment to match the NYC grid (Cite solution_lesson_node_00003).
    *   **Landmark Distances:** Haversine distances to major hubs (JFK, WTC, etc.) (Cite solution_lesson_node_00003).
*   **Tree-Specific Pipeline (XGBoost/LightGBM):**
    *   **Raw Integers:** Use ordinal integers for `Hour`, `Day`, `Month`. I will explicitly **avoid** cyclical embeddings here, as trees perform superior splits on raw ordinal integers (Cite solution_lesson_node_00024).
    *   **Raw Coordinates:** Trees will use the raw floating-point coordinates.
*   **Network-Specific Pipeline (Spatial ResNet):**
    *   **Standard Scaling:** All continuous features (Distances, Raw Coords) will be scaled to zero mean and unit variance.
    *   **Grid Discretization:** `pickup_lat`, `pickup_lon`, `dropoff_lat`, `dropoff_lon` will be bucketed into integer indices for the Embedding layers.
    *   **Cyclical Embeddings:** `Hour` and `Month` will be transformed into Sine/Cosine components to preserve temporal continuity.

# Training
*   **Strategy:** **Hold-out Blending**.
    1.  **Split:** The 55M dataset is split into "Base Train" (90%) and "Meta Train" (10%).
    2.  **Base Training:**
        *   **XGBoost:** Trained on Base Train (GPU).
        *   **LightGBM:** Trained on Base Train (CPU).
        *   **Spatial ResNet:** Trained on Base Train (GPU). I will use a large batch size (e.g., 4096) and the AdamW optimizer.
    3.  **Meta Training:** The three models predict on the "Meta Train" set. These predictions form the input for the Ridge Regression meta-learner.

# Evaluation
*   **Inference:**
    1.  Process the test set through both the **Tree Pipeline** and the **Network Pipeline**.
    2.  Generate base predictions from XGBoost, LightGBM, and Spatial ResNet.
    3.  Feed these base predictions into the Ridge Regression meta-learner to generate the final `fare_amount` submission.
