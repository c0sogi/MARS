The following implementation outlines a complete pipeline to demonstrate the Taxi Fare Prediction library.

### Implementation Strategy

1.  **Configuration Override**: We dynamically modify the `Config` class attributes to enable `DEBUG` mode and reduce hyperparameters (e.g., number of epochs, tree depth, cluster count). This ensures the script runs quickly and uses a small subset of the data (5,000 samples).
2.  **Data Processing**: We utilize `library.data_loader.load_and_process_data` to trigger the feature engineering pipeline. We explicitly assert that new features (e.g., `pickup_cluster`, `haversine_dist`) are correctly generated.
3.  **Model Training (GBDT)**: We use `library.engine.train_gbdt` to train the Gradient Boosting model. We verify the model artifact is saved and perform a sanity check prediction on the validation set.
4.  **Model Training (Neural Network)**: We use `library.engine.train_nn` to train the MLP. We verify the creation of DataLoaders, the scaler, and the model artifact. We check that the model can perform a forward pass on a test batch.
5.  **Ensemble & Submission**: We call `library.engine.generate_predictions` to combine predictions and generate the final CSV. We verify the output file format.
6.  **Reproducibility**: We use `library.utils.set_seed` at the start to ensure deterministic results.
