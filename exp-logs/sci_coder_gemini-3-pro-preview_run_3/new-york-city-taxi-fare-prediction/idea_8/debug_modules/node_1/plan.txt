The execution failure is caused by an API mismatch in the XGBoost training call. The `train_xgboost` function in `library/gbdt_models.py` passes the `early_stopping_rounds` parameter to the `.fit()` method, but in modern versions of XGBoost, this parameter has been deprecated in `.fit()` and must instead be passed to the `XGBRegressor` constructor.

To fix this, I will modify `library/gbdt_models.py` to:
1.  Move the `early_stopping_rounds` configuration to the model initialization step by updating the parameters dictionary passed to `XGBRegressor`.
2.  Ensure that if `early_stopping_rounds` is not already present in `config.XGB_PARAMS` (as is the case in the default config, though `runfile.py` injects it), a default value of 50 is used to preserve the original logic.
3.  Remove the `early_stopping_rounds` argument from the `.fit()` call.
