The implementation strategy is as follows:

1.  **Setup & Imports**: Initialize the environment, set random seeds for reproducibility, and import necessary libraries and the provided helper modules (`Config`, `process_data`, `ModelFactory`, `generate_submission`).
2.  **Data Loading**: Call `process_data` with `load_cached_data=True` and `debug_sample_size=None`. This ensures the **full** validation set is loaded (critical for the required metric calculation) and checks for cached processed data to save time.
3.  **Fast Baseline Sampling**: Manually sample the training dataframe to 500,000 rows. This satisfies the requirement to "limit maximum number of training samples" for a fast baseline execution while keeping the validation set intact.
4.  **Model Training**:
    *   Initialize XGBoost and LightGBM models using `ModelFactory`.
    *   Override default configuration with "fast" hyperparameters: `n_estimators=1000` (down from 5000) and `learning_rate=0.05` to ensure quick convergence.
    *   Train both models using the sampled training data and the full validation data for early stopping.
    *   Save trained models to disk.
5.  **Evaluation**:
    *   Generate predictions on the **entire** hold-out validation set using the weighted ensemble.
    *   Calculate the Root Mean Squared Error (RMSE).
    *   Print the metric in the exact required format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**:
    *   Calculate absolute residuals (error magnitude) on the validation set.
    *   Compute and print the correlation between input features and the error magnitude to identify sources of systematic error.
7.  **Submission**:
    *   Compare the calculated RMSE against the threshold (3.3935366001817666).
    *   If the model performs well enough, call `generate_submission` to predict on the test set and save `submission.csv`.
