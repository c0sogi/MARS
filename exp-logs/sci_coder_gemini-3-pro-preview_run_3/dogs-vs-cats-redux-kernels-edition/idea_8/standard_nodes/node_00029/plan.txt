Implementation strategy:
1.  **Setup & Configuration**: Import necessary libraries and the provided modules (`library.*`). Set the random seed for reproducibility. Modify `Config.NUM_EPOCHS` to 5 to ensure the training completes quickly (creating a "fast baseline") while still allowing convergence.
2.  **Training**: Iterate through the defined models (`resnet50`, `convnext_small`, `swin_tiny`). Use `engine.train_model` to train each model. This function handles data loading, model creation, and saving the best checkpoint based on validation loss.
3.  **Ensemble Validation**:
    *   Load the validation metadata (`val.csv`).
    *   For each trained model, load the best checkpoint and perform inference on the validation set using Test Time Augmentation (TTA) via `inference.predict_with_tta`.
    *   Average the probabilities from all models to form an ensemble prediction.
    *   Calculate the **Log Loss** metric on the validation set and print it in the required format.
4.  **Failure Analysis**:
    *   Calculate the absolute error for each validation sample.
    *   Extract metadata features (image width, height, and file size) for the validation images.
    *   Compute and print the Pearson correlation between the prediction error and these features to identify potential biases.
5.  **Submission**:
    *   Compare the final validation metric against the strict threshold (`0.009311713870561527`).
    *   If and only if the metric is lower (better) than the threshold, execute `inference.ensemble_predictions` to generate the submission file for the test set.
