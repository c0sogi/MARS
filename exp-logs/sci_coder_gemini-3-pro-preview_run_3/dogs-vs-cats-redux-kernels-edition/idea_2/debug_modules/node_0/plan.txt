The following script demonstrates the usage of the provided library modules for the Dog vs Cat classification task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We start by setting the random seed for reproducibility. We then create a "mini" dataset by sampling a few rows from the original metadata CSVs and saving them to the working directory. This ensures the demonstration runs quickly.
2.  **Config Overrides**: We monkey-patch the `Config` class to point to these mini datasets and reduce hyperparameters (1 epoch, small batch size, no pretrained weights) to minimize runtime and resource usage.
3.  **Data Loading Demonstration**: We utilize `get_dataloaders` to initialize PyTorch DataLoaders and verify the shape and type of the yielded batches.
4.  **Model Initialization**: We instantiate the model using `get_model` with `pretrained=False` (to avoid downloads) and verify its output shape with a dummy forward pass.
5.  **Training & Validation Loop**: We manually execute a training and validation step using `train_one_epoch` and `validate`, asserting that loss values are valid.
6.  **Inference Pipeline**: We save the trained model weights and execute the full inference pipeline using `run_inference`, verifying that a submission file is generated correctly.
