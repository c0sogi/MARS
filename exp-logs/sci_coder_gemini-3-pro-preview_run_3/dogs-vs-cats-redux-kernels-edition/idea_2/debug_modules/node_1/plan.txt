The issue is caused by Python's default argument evaluation behavior. The default values for the `get_dataloaders` function in `library/dataset.py` (e.g., `test_csv=Config.TEST_CSV`) are evaluated once at module import time. Consequently, when `runfile.py` modifies the `Config` attributes at runtime (pointing them to the mini datasets), these changes are ignored by `get_dataloaders` when it is called without explicit arguments in `library/inference.py`. This causes the inference process to load the full test set (2500 images) instead of the mini test set (16 images), leading to the row count mismatch assertion error.

To fix this, I will modify `get_dataloaders` to use `None` as the default value for these arguments and resolve them to the current `Config` values inside the function body. This ensures that the runtime modifications to `Config` are correctly picked up.
