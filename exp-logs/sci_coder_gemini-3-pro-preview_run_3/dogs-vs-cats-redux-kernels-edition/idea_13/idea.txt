Based on the comprehensive analysis of the "Lessons" and "Previous Ideas," I propose a **Heterogeneous Ensemble with Self-Supervised Vision Transformer (SSL-ViT)**.

This strategy structurally evolves the solution by addressing the recurring failure of the "third pillar" in the ensemble (where EfficientNet, Swin, and MaxViT previously failed). Instead of selecting another architecture based solely on topology (CNN vs. Transformer), we introduce diversity in the **learning paradigm** by integrating a Self-Supervised Learning (SSL) backbone.

### Model
**Architecture:** Implement a **Triple Heterogeneous Ensemble** that combines three distinct feature extraction paradigms:
1.  **ResNet-50 (Standard CNN):** The robust anchor. Initialize with **`IMAGENET1K_V2`** weights (Supervised) to leverage high-quality texture-based discrimination (Cite solution_lesson_node_00002, solution_lesson_node_00006).
2.  **ConvNeXt-Small (Modern CNN):** Captures semantic context via large kernels. Initialize with best available Supervised weights (Cite solution_lesson_node_00016).
3.  **ViT-Small (Self-Supervised Transformer):** **Structural Innovation.** Replace the previously failing Supervised Transformers (Swin/MaxViT) with a standard **Vision Transformer (ViT-Small-Patch16-224)** initialized with **DINOv2** (or MAE) weights.
    *   **Rationale:** Previous lessons showed that supervised Transformers (Swin/MaxViT) struggled with convergence or resolution constraints (Cite solution_lesson_node_00028, solution_lesson_node_00034). Self-Supervised models like DINOv2 learn features based on part-whole relationships and global shape rather than class labels. This introduces a fundamentally different "view" of the data compared to the supervised CNNs, maximizing the error decorrelation required for a successful ensemble (Cite solution_lesson_node_00016).

### Data
**Preprocessing (Decoupled Pipelines):** Implement the **Decoupled Input Pipeline** strategy to respect architectural constraints without penalizing the ensemble (Cite solution_lesson_node_00028).
*   **Pipeline A (ResNet-50, ConvNeXt-Small):** Resize images to **256x256**. This resolution allows the CNNs to exploit fine spatial details, which has been proven to improve performance (Cite solution_lesson_node_00005).
*   **Pipeline B (ViT-Small):** Resize images to **224x224**. This aligns with the native patch structure of the ViT, preventing the interpolation artifacts and performance loss observed when forcing Transformers to non-native resolutions.
*   **Interpolation:** Strictly use **Bicubic Interpolation** for all pipelines to align with modern pre-training recipes (Cite solution_lesson_node_00024).

**Augmentation:** Apply **Context-Preserving Augmentation** across all pipelines.
*   Use `RandomResizedCrop` with a scale of `(0.8, 1.0)` to ensure the subject is never cropped out (Cite solution_lesson_node_00005).
*   Apply `ColorJitter` with intensity $\ge 0.2$ to handle lighting variance (Cite solution_lesson_node_00024).
*   **Constraint:** Do not subsample the dataset; train on the full 25,000 images (Cite solution_lesson_node_00036).

### Training
**Strategy:** Train each model independently.
*   **Optimizer:** Use **AdamW** combined with a **Cosine Annealing** scheduler (Cite solution_lesson_node_00007).
*   **Loss Function:** Use **Binary Cross-Entropy with Logits Loss** (`BCEWithLogitsLoss`) **without Label Smoothing**. We strictly avoid Label Smoothing to prevent the "loss floor," allowing the models to minimize Log Loss for high-confidence predictions (Cite solution_lesson_node_00012).
*   **Specific Optimization for ViT:** Apply **Layer-wise Learning Rate Decay (LLRD)** (e.g., decay rate 0.9) to the ViT-Small backbone. This is critical for Self-Supervised weights, as it preserves the robust pre-trained features in lower layers while allowing the head to adapt, preventing the "catastrophic forgetting" that often affects Transformers on small datasets.
*   **Duration:** Train for **5-8 epochs**. This respects the rapid convergence of transfer learning while providing sufficient steps for the ViT to align (Cite solution_lesson_node_00001).

### Evaluation
**Inference & Aggregation:**
1.  **Test Time Augmentation (TTA):** For every test image, generate probabilities using both the original and a horizontally flipped version for each of the three models. Average these pairs to stabilize predictions (Cite solution_lesson_node_00007).
2.  **Ensemble Averaging:** Calculate the final probability by taking the **arithmetic mean** of the outputs from the ResNet-50, ConvNeXt-Small, and ViT-Small. This leverages the structural diversity of the architectures (Standard CNN, Modern CNN, SSL Transformer) and the decoupled resolutions to minimize Log Loss (Cite solution_lesson_node_00016).
