The implementation strategy follows the "Heterogeneous Ensemble with SSL-ViT" idea. It orchestrates the training of three distinct models (ResNet-50, ConvNeXt-Small, and ViT-Small with DINO weights) using the provided library functions. After training, it performs a custom ensemble validation by loading the best checkpoints for each model, generating predictions on the validation set with Test Time Augmentation (TTA), and averaging the results. The script then calculates the final log loss metric. A failure analysis is performed by correlating the prediction errors with image meta-features (width, height, aspect ratio, file size) extracted on the fly. Finally, if the validation metric meets the strict threshold, the script generates the submission file for the test set.
