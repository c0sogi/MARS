This script performs a comprehensive Exploratory Data Analysis (EDA) on the provided dog vs. cat dataset. It first loads the training metadata to identify the data modality (Image) by inspecting file extensions. It then analyzes the target variable distribution (class balance). For the image data, it iterates through the training set to calculate distributions for image dimensions (width, height, aspect ratio), channel counts, and file sizes. It estimates global pixel mean and standard deviation using a stratified sample to ensure efficiency. Finally, it analyzes the relationship between these image meta-features and the target label (e.g., do dogs tend to have larger file sizes or different aspect ratios than cats?) and prints a formatted report.
