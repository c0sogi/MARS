The `TypeError` occurs because the `timm.create_model` function is called with the `img_size` argument for all models, but standard CNN architectures like ResNet (and ConvNeXt) do not accept this argument in their `__init__` method. Only Vision Transformers (like Swin) typically require or support explicit image size definition during initialization to handle embedding or window partitioning. To fix this, I will modify `library/model_factory.py` to conditionally pass `img_size` via `kwargs` only when the model architecture is identified as a Transformer (e.g., contains "swin" or "vit"), ensuring the factory respects the architectural differences between the models (Cite debug_lesson_4).
