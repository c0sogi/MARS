This script implements the orchestration of the Stratified K-Fold Heterogeneous Ensemble. It leverages the provided library modules to execute a fast baseline run. The script is designed to:
1.  **Configure for Speed:** Activates `debug` mode in `Config` (reducing folds and epochs) and subsamples the training data to 1500 samples to ensure the pipeline completes well within the 51-minute limit.
2.  **Orchestrate Training:** Loops through the defined models (ResNet, ConvNeXt, MaxViT) and folds, training each using the `train_model_fold` pipeline function.
3.  **Validate & Analyze:** Aggregates Out-Of-Fold (OOF) predictions to calculate the global `Final Validation Metric` (Log Loss). It performs failure analysis by correlating prediction errors with image metadata (file size, dimensions).
4.  **Conditional Submission:** Generates a submission file using the calibrated ensemble only if the validation metric meets the specified strict threshold.
