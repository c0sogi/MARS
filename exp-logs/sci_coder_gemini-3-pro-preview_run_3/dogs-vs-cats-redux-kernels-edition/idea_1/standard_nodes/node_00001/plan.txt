Implementation strategy:
1.  **Setup & Imports**: Import necessary libraries (`torch`, `pandas`, `numpy`, `cv2`, `os`) and the provided modules (`Config`, `dataset`, `model`, `engine`). Set random seeds for reproducibility.
2.  **Training Loop**: Implement a training loop that runs for `Config.EPOCHS`. Inside the loop, use `train_one_epoch` for training and `evaluate` for validation. Implement a "best model" checkpointing system based on the validation loss (Log Loss).
3.  **Metric Reporting**: After training, print the best validation loss using the exact format required: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Load the best model state.
    *   Run inference on the validation set to get probabilities.
    *   Load the validation metadata (`val.csv`) and extract image features (width, height, file size) for each image.
    *   Calculate the error magnitude (`|label - prediction|`).
    *   Compute and print the correlation between the error magnitude and the extracted features to identify potential failure modes.
5.  **Submission**:
    *   Run inference on the test set using the `predict` function.
    *   Format the results (ID sorting, integer IDs) and save them to `submission.csv`.
