Here is the implementation of the orchestration script `runfile.py` based on the Stratified K-Fold Heterogeneous Ensemble strategy.

Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment and random seeds. Define a "Fast Baseline" configuration (reduced dataset size and epochs) to ensure the script completes within the time limit while still verifying the pipeline.
2.  **Data Preparation**: Load the full training metadata (combined Train+Val) and perform a stratified subsample to speed up execution. Load test metadata.
3.  **Cross-Validation Loop**: Implement a 5-Fold Stratified Cross-Validation loop.
    *   Iterate through each fold and each of the 3 architectures (ResNet50, ConvNeXt, MaxViT).
    *   Train each model for a limited number of epochs.
    *   Generate Out-Of-Fold (OOF) predictions for the validation subset.
    *   Generate Test predictions using Test Time Augmentation (TTA) and accumulate them across folds.
4.  **Ensemble Optimization**: Collect OOF predictions for all models. Use `scipy.optimize` (via `library.ensemble`) to find the optimal weights that minimize Log Loss on the OOF data.
5.  **Validation & Reporting**: Apply the optimal weights to the OOF predictions corresponding to the hold-out validation set (`val.csv`). Compute and print the final Log Loss.
6.  **Failure Analysis**: Calculate the correlation between prediction error and image file size on the validation set to identify potential biases.
7.  **Submission**: If the validation metric meets the threshold, apply the ensemble weights to the aggregated test predictions and save the submission file.
