Implementation strategy:
1.  **Configuration & Setup**: Import necessary libraries and the provided modules. Monkey-patch the `Config` class to reduce `NUM_EPOCHS` to 5 and `SWA_START_EPOCH` to 3. This ensures the "fast baseline" requirement is met while still leveraging SWA.
2.  **Model Training Loop**: Iterate through the three model architectures defined in `Config.MODEL_SPECS`. For each:
    *   Initialize DataLoaders and the Model.
    *   Execute the training pipeline (`run_swa_training`), which handles SWA and saves the best/SWA checkpoints.
    *   Clean up GPU memory after each model to prevent OOM errors.
3.  **Ensemble Validation**:
    *   Load the validation metadata.
    *   For each trained model, load the saved weights and generate predictions on the validation set using Test Time Augmentation (TTA).
    *   Compute the ensemble prediction (arithmetic mean).
    *   Calculate and print the `Final Validation Metric` (Log Loss).
4.  **Failure Analysis**:
    *   Compute the absolute error for each validation sample.
    *   Extract metadata features (width, height, file size) from the validation images.
    *   Calculate and print the Pearson correlation between these features and the prediction error to identify systematic failures.
5.  **Submission**:
    *   Compare the final validation metric against the strict threshold (`0.009241249605204765`).
    *   If the metric is lower, trigger the `run_inference` function to generate predictions on the test set and save `submission.csv`.
