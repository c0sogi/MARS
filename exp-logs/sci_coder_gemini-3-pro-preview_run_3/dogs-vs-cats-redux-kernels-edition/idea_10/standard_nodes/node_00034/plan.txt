The `RuntimeError` occurs because the logic to detect and strip the `module.` prefix from SWA checkpoints relies on checking only the first key of the state dictionary. Since `AveragedModel` checkpoints often start with the `n_averaged` buffer (which lacks the prefix), the check fails, causing the code to skip sanitization and pass invalid keys to the model. To fix this (Cite debug_lesson_7), I will replace the index-based heuristic with a robust loop that iterates through all keys, conditionally stripping the `module.` prefix and removing the `n_averaged` buffer to ensure the weights match the base model's architecture. I will apply this correction to both `runfile.py` and `library/inference.py`.
