Based on the accumulated lessons and the specific failure modes of previous scaling attempts, I propose a **Heterogeneous Ensemble with Multi-Axis Attention and Stochastic Weight Averaging (SWA)**.

This strategy structurally evolves the solution by:
1.  **Architectural Evolution:** Replacing the Window-based Transformer (Swin) with a **Multi-Axis Transformer (MaxViT)** to introduce a stronger global attention mechanism.
2.  **Head Innovation:** Implementing **Multi-Sample Dropout** to explicitly minimize Log Loss through internal regularization.
3.  **Optimization Innovation:** Integrating **Stochastic Weight Averaging (SWA)** to find flatter minima, improving calibration without the cost of training more models.

### Model
**Architecture:** Implement a **Triple Heterogeneous Ensemble** consisting of three backbones with distinct inductive biases and "Small/Tiny" capacities (to ensure convergence within the compute budget, unlike Idea 9):
1.  **ResNet-50:** The "Standard CNN" anchor. Provides robust, texture-based feature extraction (Cite solution_lesson_node_00002).
2.  **ConvNeXt-Small:** The "Modern CNN". Utilizes large kernels and inverted bottlenecks for semantic context (Cite solution_lesson_node_00016).
3.  **MaxViT-Tiny:** The "Multi-Axis Transformer". **New Addition.** This replaces Swin. Unlike Swin's local window attention, MaxViT employs **Multi-Axis Attention** (Block Attention + Grid Attention), allowing for efficient global interactions in a single block. This provides a structurally distinct global view compared to both CNNs and Window-based Transformers.

**Head Design (Structural Innovation):**
Replace the standard single linear layer with a **Multi-Sample Dropout Head**.
*   **Mechanism:** Instead of a single dropout path, create 5 parallel dropout masks with different rates (e.g., 0.1 to 0.5) feeding into shared weights.
*   **Rationale:** This technique creates an "internal ensemble" within each model, smoothing the decision boundary and significantly reducing Log Loss by penalizing overconfidence on noisy features, without the "loss floor" of Label Smoothing (Cite solution_lesson_node_00012).

**Initialization:** Use **`IMAGENET1K_V2`** weights for ResNet and the best available modern weights for ConvNeXt/MaxViT (Cite solution_lesson_node_00006).

### Data
**Preprocessing (Decoupled Pipelines):** Maintain the decoupled resolution strategy to maximize fidelity (Cite solution_lesson_node_00028).
*   **Pipeline A (ResNet-50, ConvNeXt-Small):** Resize to **256x256**. This resolution improves accuracy by preserving spatial details (Cite solution_lesson_node_00005).
*   **Pipeline B (MaxViT-Tiny):** Resize to **224x224**. This aligns with the native grid size of the Transformer, avoiding interpolation artifacts.
*   **Interpolation:** Strictly use **Bicubic Interpolation** for all pipelines (Cite solution_lesson_node_00024).

**Augmentation:**
*   **Context-Preservation:** Use `RandomResizedCrop` with scale `(0.8, 1.0)` to prevents subject loss (Cite solution_lesson_node_00005).
*   **Photometric Noise:** Apply `ColorJitter` with intensity $\ge 0.2$ to handle lighting variance (Cite solution_lesson_node_00024).

### Training
**Strategy:** Train each model independently with **Stochastic Weight Averaging (SWA)**.
*   **Optimizer:** Use **AdamW** with a standard Cosine Annealing scheduler initially (Cite solution_lesson_node_00007).
*   **Loss Function:** Use **BCEWithLogitsLoss** *without* Label Smoothing (Cite solution_lesson_node_00012).
*   **SWA Procedure:**
    1.  Train for a standard duration (e.g., 8 epochs) to ensure convergence (Cite solution_lesson_node_00009).
    2.  For the final 2-3 epochs, switch to a constant, low learning rate and capture a snapshot of the model weights at the end of each epoch.
    3.  **Average these snapshots** to create the final model weights. SWA finds a solution centered in a flat region of the loss landscape, which theoretically and empirically improves generalization and probability calibration (Log Loss).

### Evaluation
**Inference & Aggregation:**
1.  **Test Time Augmentation (TTA):** For every test image, generate probabilities using both the original and a horizontally flipped version for each of the three SWA-enhanced models. Average these pairs (Cite solution_lesson_node_00007).
2.  **Ensemble Averaging:** Calculate the final probability by taking the **arithmetic mean** of the outputs from the ResNet-50, ConvNeXt-Small, and MaxViT-Tiny. This combines the benefits of diverse architectures (CNN vs. Modern CNN vs. Multi-Axis Transformer), decoupled resolutions, and SWA-calibrated weights (Cite solution_lesson_node_00016).
