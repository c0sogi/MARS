The following strategy outlines the implementation:

1.  **Setup & Configuration**: We will import the `Config` class and modify its attributes at runtime. This allows us to switch to a lightweight model (ResNet18 instead of ResNet50), reduce the number of epochs to 1, and redirect file paths to a temporary working directory.
2.  **Data Preparation**: To ensure the demonstration runs quickly and avoids shape mismatches in the provided `run_inference` function (which reads the full test CSV while the loader might sample in debug mode), we will manually create small "mini" versions of the training, validation, and test metadata CSVs (20 samples each). We will then point the `Config` metadata paths to these mini files.
3.  **Component Verification**:
    *   **Data Loading**: We will instantiate the DataLoaders and verify that they yield batches of the correct shape.
    *   **Model Creation**: We will create the model and verify it is a valid PyTorch module.
    *   **Training**: We will run the `run_swa_training` function for one epoch and verify that the best model checkpoint is saved.
    *   **Inference**: We will run the `run_inference` function and verify that a submission file is generated with the expected number of rows and valid probability values.
4.  **Execution**: The script will run these steps sequentially, using assertions to validate correctness at each stage.
