Based on the comprehensive analysis of the accumulated lessons and the available computational resources (24-hour runtime, A100 GPU), I propose a **SWA-Enhanced Stratified K-Fold Heterogeneous Ensemble with Post-Hoc Calibration**.

This strategy structurally evolves the "Current Best" (Idea 22) by integrating **Stochastic Weight Averaging (SWA)** into the Cross-Validation pipeline. Previous attempts at SWA (Lesson 00034) failed because the strict epoch limits prevented the algorithm from sampling a sufficient portion of the loss landscape. By leveraging the 24-hour budget to extend the training horizon, we allow SWA to locate flatter minima, which theoretically and empirically improves generalization and calibration (Log Loss). This is combined with the **Decoupled Resolution** and **Temperature Scaling** strategies proven in previous lessons.

### Model
**Architecture:** Implement a **Heterogeneous Ensemble** consisting of three distinct backbones, replicated across **5 Stratified Folds** (Total 15 models). We retain the "Golden Trio" identified in Lesson 00040 for their maximized inductive bias diversity:
1.  **ResNet-50:** The "Standard CNN" anchor. Provides robust, texture-based feature extraction (Cite solution_lesson_node_00002).
2.  **ConvNeXt-Small:** The "Modern CNN". Captures semantic context via large kernels and inverted bottlenecks (Cite solution_lesson_node_00016).
3.  **MaxViT-Tiny:** The "Multi-Axis Transformer". Utilizes Block (Local) and Grid (Global) attention to capture long-range dependencies, providing a distinct error profile from the CNNs (Cite solution_lesson_node_00040).

**Initialization:** Initialize all models with the highest quality pre-trained weights available (e.g., `IMAGENET1K_V2` for ResNet, `in1k` for others) to strictly adhere to the lesson that modern recipes outperform legacy weights (Cite solution_lesson_node_00006).

### Data
**Preprocessing (Decoupled Pipelines):** Implement **Resolution Diversity** to maximize feature extraction scales without forcing a "lowest common denominator" (Cite solution_lesson_node_00028, solution_lesson_node_00040):
1.  **Pipeline A (ResNet-50):** Resize to **256x256**.
2.  **Pipeline B (ConvNeXt-Small):** Resize to **288x288**.
3.  **Pipeline C (MaxViT-Tiny):** Resize to **224x224** (Native resolution).
*   **Interpolation:** Strictly use **Bicubic Interpolation** for all resizing operations (Cite solution_lesson_node_00024).

**Augmentation:** Apply **Context-Preserving Augmentation** across all pipelines.
*   Use `RandomResizedCrop` with a scale of `(0.8, 1.0)` to ensure the subject is never cropped out (Cite solution_lesson_node_00005).
*   Apply `ColorJitter` with intensity $\ge 0.2$ to handle lighting variance (Cite solution_lesson_node_00024).

### Training
**Strategy:** **5-Fold Stratified Cross-Validation with SWA**.
*   Train an independent instance of each architecture on each fold (15 total models). This ensures 100% data utilization (Cite solution_lesson_node_00036).
*   **Optimization:** Use **AdamW** with a **Cosine Annealing** scheduler initially (Cite solution_lesson_node_00007).
*   **Loss Function:** **BCEWithLogitsLoss** *without* Label Smoothing (Cite solution_lesson_node_00012).

**SWA Integration (Structural Innovation):**
*   **Extended Schedule:** Train each model for **16-20 epochs**. This extended duration addresses the failure of Lesson 00034, ensuring the model fully converges before SWA begins.
*   **SWA Phase:** For the final 25% of epochs (e.g., epochs 13-16 or 16-20), switch to a constant or cyclic learning rate and cache the model weights at the end of each epoch.
*   **Averaging:** Construct the final model for each fold by averaging these cached weights. This locates the center of a flat minimum in the loss landscape, improving probability calibration and robustness.

### Evaluation
**Inference & Calibration Pipeline:**
1.  **Test Time Augmentation (TTA):** Generate raw logits using both the original and a horizontally flipped version for each of the 15 SWA models (Cite solution_lesson_node_00007).
2.  **Quality Gating:** Calculate the Out-Of-Fold (OOF) Log Loss for each model. Discard any model whose OOF loss exceeds a safety threshold (e.g., > 0.05) to prevent the "Poison Pill" effect (Cite solution_lesson_node_00043).
3.  **Temperature Scaling:**
    *   For each accepted model, learn a single scalar parameter $T$ using its OOF logits to minimize Negative Log Likelihood.
    *   Apply this $T$ to the model's Test Set logits ($Logits / T$) before applying the sigmoid function. This explicitly corrects the overconfidence of deep models (Cite solution_lesson_node_00051).
4.  **Aggregation:** Calculate the final probability by taking the **arithmetic mean** of the *calibrated* probabilities from all passing models. We prefer simple averaging over complex stacking to avoid overfitting (Cite solution_lesson_node_00023).
