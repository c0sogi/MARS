Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and set random seeds for reproducibility.
2.  **Model Iteration**: Loop through the three architectures defined in `Config.MODEL_ARCHITECTURES` (ResNet-50, ConvNeXt-Small, MaxViT-Tiny).
    *   **Data Loading**: Instantiate `train_loader` and `val_loader` with the specific resolution for the current model (256x256 or 224x224).
    *   **Model Construction**: Build the model using `build_model`, applying GeM pooling or Multi-Sample Dropout as specified.
    *   **Training**: Train the model using the `Trainer` class for the defined epochs. Save the best checkpoint with a unique name.
    *   **Inference**: Generate predictions for both the validation set (for ensemble weighting/analysis) and the test set (using Test Time Augmentation).
    *   **Cleanup**: Explicitly delete model and data objects and clear GPU cache to prevent OOM errors between iterations.
3.  **Ensemble Aggregation**: Compute the arithmetic mean of the predictions from all three models for both validation and test sets.
4.  **Validation & Analysis**:
    *   Calculate the final Log Loss on the validation set.
    *   Perform failure analysis by correlating prediction errors with image metadata (file size, dimensions) to identify systematic weaknesses.
5.  **Submission**: Check if the validation metric meets the strict threshold (< 0.00924). If successful, generate and save `submission.csv`.
