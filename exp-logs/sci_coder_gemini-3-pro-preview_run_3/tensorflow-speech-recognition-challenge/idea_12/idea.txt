Based on the comprehensive analysis of the provided lessons, I propose the **Frequency-Preserving Multi-Resolution SK-ResNet-CRNN**.

This strategy represents a structural evolution of the current best approach (Idea 7). While Idea 7 optimized the input resolution (Multi-Res Spectrograms) and the backbone's receptive field (SK-Net), it utilized a standard aggregation method—averaging features over the frequency dimension—before passing them to the recurrent layer. This operation discards critical vertical structural information (e.g., formant trajectories and harmonic relations) necessary for distinguishing spectrally complex commands. My proposal introduces **Frequency-Preserving Feature Flattening**, ensuring the Recurrent Neural Network (RNN) receives the full spectro-temporal profile of the signal, addressing the "Information Bottleneck" identified in **Lesson 00039**.

# Model
I propose the **Frequency-Preserving Multi-Resolution SK-ResNet-CRNN**.

*   **Input:** **3-Channel Multi-Resolution Log-Mel Spectrogram**.
    *   We retain the highly effective input strategy of generating three spectrograms with varying STFT window sizes (e.g., 20ms, 40ms, 60ms) and stacking them as RGB channels. This maps the time-frequency uncertainty trade-off directly to the channel dimension **Cite solution_lesson_node_00020**.
    *   **Resolution:** We will use **80 Mel bands** to ensure feature fidelity scales with the model capacity **Cite solution_lesson_node_00022**.
*   **Backbone:** **Selective Kernel ResNet34 (SK-ResNet34)**.
    *   We use the SK-ResNet34 backbone. Its "Split-Attention" mechanism dynamically adjusts receptive fields, allowing the model to adaptively focus on the optimal resolution channel (Short vs. Long window) for each audio segment **Cite solution_lesson_node_00029**.
    *   **Adaptation:** The 3-channel input is mapped directly to the pretrained RGB weights **Cite solution_lesson_node_00005**.
    *   **Temporal & Frequency Preservation:** The strides of the final two residual stages (Layer 3 and 4) will be set to `(1, 1)`. This prevents excessive downsampling in *both* the Time and Frequency dimensions, ensuring the output feature map retains sufficient sequence length and spectral detail **Cite solution_lesson_node_00017**.
*   **Neck (Structural Innovation): Frequency-Preserving Flattening & Projection.**
    *   Instead of averaging the feature map $(B, C, F, T)$ over the frequency dimension $F$ (which collapses spectral structure), we will **permute and flatten** the tensor to $(B, T, C \times F)$.
    *   This flattened sequence is passed through a **Linear Projection Layer** (e.g., $C \times F \to 1024$) to compress the representation while learning to preserve relevant spectral correlations.
    *   **Sequence Modeling:** The projected sequence is passed to a **Bidirectional GRU (BiGRU)**. This allows the RNN to model dependencies based on the full spectral profile (e.g., "rising pitch") rather than just average energy **Cite solution_lesson_node_00034**.
*   **Head:** **Multi-Head Attention Pooling**.
    *   The recurrent states are aggregated using Multi-Head Attention (4 heads). This allows the model to simultaneously attend to distinct temporal events (e.g., onset and offset) rather than averaging them **Cite solution_lesson_node_00031**.

# Data
*   **Preprocessing & Caching:**
    *   We will **pre-compute** the 3-Channel Multi-Resolution Spectrograms (16kHz, padded to 1s, `n_mels=80`) and save them to disk as `.npy` files. This eliminates the CPU bottleneck associated with on-the-fly STFT computation **Cite solution_lesson_node_00028**.
*   **Sampling Strategy:**
    *   We will use the **Full Unknown Dataset** (~30k samples) and employ a **Weighted Random Sampler**. This ensures every batch is balanced across all 12 classes, maximizing the diversity of negative examples the model sees without discarding data **Cite solution_lesson_node_00022**.
*   **Augmentation:**
    *   **SpecAugment Only:** Apply Frequency and Time Masking to the cached features.
    *   **Configuration:** Use **inclusive bounds** for mask generation **Cite solution_lesson_node_00011**. Fill masks with the **minimum value** of the spectrogram **Cite solution_lesson_node_00010**. Strictly limit time masks to **<20%** of the duration to preserve short command context **Cite solution_lesson_node_00008**.
    *   **Exclusion:** We will **NOT** use MixUp or Label Smoothing, as these have been shown to cause underfitting by over-regularizing the model given the small generalization gap **Cite solution_lesson_node_00016** **Cite solution_lesson_node_00019**.

# Training
*   **Loss Function:** Standard **Cross-Entropy Loss**.
*   **Optimizer:** **AdamW** with weight decay.
*   **Scheduler:** **Cosine Annealing** learning rate scheduler to ensure smooth convergence.
*   **Validation:** We will strictly monitor performance on the speaker-disjoint validation set provided in the metadata (`val.csv`) to ensure generalization to unseen users **Cite solution_lesson_node_00001**.

# Evaluation
*   **Inference:** For each test file, generate the 3-Channel Multi-Resolution Spectrogram (without augmentation).
*   **Prediction:** Pass the input through the Frequency-Preserving MR-SK-ResNet-CRNN. The Multi-Head Attention Pooling will aggregate features from the active speech segments, handling the uncropped nature of the test data. The final prediction is the class with the highest probability.
