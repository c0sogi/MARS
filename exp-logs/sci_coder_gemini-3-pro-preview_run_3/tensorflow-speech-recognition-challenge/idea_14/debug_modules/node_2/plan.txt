The issue is a `ValueError` caused by passing a dummy input with a batch size of 1 to the model while it is in training mode. The ResNeSt backbone uses Split-Attention blocks containing Global Average Pooling followed by Batch Normalization. When the spatial dimensions are reduced to $1 \times 1$ and the batch size is 1, the Batch Normalization layer receives only a single value per channel, making it impossible to calculate variance (Cite debug_lesson_6).

To fix this, I will increase the batch size of the dummy input from 1 to 2 in `library/model.py`. This ensures that the Batch Normalization layers have sufficient data to compute statistics during the shape inference step, preventing the crash without needing to toggle the model's training mode.
