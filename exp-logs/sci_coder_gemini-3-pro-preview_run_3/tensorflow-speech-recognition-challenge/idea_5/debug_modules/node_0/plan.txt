The following script demonstrates the usage of the provided library files for the Speech Command Recognition task. It performs the following steps:
1.  **Configuration & Setup**: Sets random seeds and configures the environment for a rapid demonstration run.
2.  **Data Preparation**: Creates a small subset of the training and validation metadata to ensure the training loop executes quickly (optimizing for speed).
3.  **Dataset Verification**: Instantiates the `SpeechCommandsDataset`, retrieves a sample, and asserts that the input shapes (Multi-Resolution Log-Mel Spectrograms) and targets are correct.
4.  **Model Verification**: Instantiates the `MultiResConvNeXtCRNN` model, passes a dummy input, and verifies the output dimensions.
5.  **Training Loop**: Runs the `Trainer` for a single epoch on the subset data to demonstrate the training process.
6.  **Prediction**: Generates predictions on the test set (using a subset for speed) and verifies the submission file format.
