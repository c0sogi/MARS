Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment using the provided `Config` and `utils`. Set random seeds for reproducibility.
2.  **Training**: Execute the `train_model` function from `library.training_loop`. This handles data caching (computing Multi-Resolution Spectrograms), training the `MR_SK_CRNN` model (SK-ResNet34 + BiGRU + Multi-Head Attention), and saving the best model based on validation accuracy. We use the full dataset (`debug=False`) to meet the high accuracy requirement.
3.  **Validation & Metrics**:
    *   Load the saved best model.
    *   Run inference on the full validation set to obtain predictions and probabilities.
    *   Calculate and print the `Final Validation Metric` (Accuracy) with full precision.
4.  **Failure Analysis**:
    *   Load validation metadata (`val.csv`).
    *   Calculate "Error Magnitude" for each sample defined as $1.0 - P(\text{correct\_class})$.
    *   Extract audio duration for all validation files.
    *   Compute and print the Pearson correlation between Error Magnitude and input features (Duration, Label ID) to identify error patterns.
5.  **Submission**: Compare the final validation accuracy against the strict threshold (`0.9779602420051858`). If the threshold is exceeded, trigger `predict_submission` to generate `submission.csv` for the test set.
