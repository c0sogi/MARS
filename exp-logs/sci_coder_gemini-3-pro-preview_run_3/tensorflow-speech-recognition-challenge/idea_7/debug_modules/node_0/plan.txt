The following script demonstrates the usage of the provided library components for the Speech Command Recognition task. It follows a logical flow:
1.  **Configuration Setup**: Overrides default configuration parameters (e.g., reducing epochs, batch size, and sample sizes) to ensure the demonstration runs quickly.
2.  **Audio Processing**: Validates the loading and spectrogram generation functions on a real sample from the training metadata.
3.  **Dataset & Augmentation**: Demonstrates how the dataset class handles caching and how SpecAugment modifies the input features.
4.  **Model Architecture**: Instantiates the Multi-Resolution Selective Kernel CRNN and validates the forward pass with dummy data.
5.  **Training & Inference Pipeline**: Executes the full training and inference loop using the debug mode to verify end-to-end functionality and generates a submission file.
