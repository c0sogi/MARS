Based on the comprehensive analysis of the previous experiments and the specific lessons learned, I propose the **Multi-Resolution SK-ResNet-CRNN with Multi-Head Attention Pooling**.

This strategy represents the culmination of the architectural insights gained so far. It integrates the superior feature extraction of **Selective Kernel Networks** (Lesson 00029), the robust input representation of **Multi-Resolution Spectrograms** (Lesson 00020), and the sequential modeling of **CRNNs** (Lesson 00017). The key structural innovation is the introduction of **Multi-Head Attention Pooling**, which addresses the limitation of standard Attention Pooling by allowing the model to capture multiple distinct temporal events (e.g., the initial plosive and the trailing vowel) simultaneously, rather than averaging them into a single global vector.

### Model
I propose a **Multi-Resolution Selective Kernel CRNN with Multi-Head Attention**.

*   **Input:** **3-Channel Multi-Resolution Log-Mel Spectrogram**.
    *   We retain the highly effective strategy of mapping the time-frequency trade-off to the channel dimension. The input will be a 3-channel image where channels correspond to Short (20ms), Medium (40ms), and Long (60ms) STFT windows **Cite solution_lesson_node_00020**.
*   **Backbone:** **Selective Kernel ResNet34 (SK-ResNet34)**.
    *   We use the SK-ResNet34 backbone which utilizes "Split-Attention" to dynamically reweight the input channels and adjust receptive fields. This is perfectly suited for the multi-resolution input, as the network can adaptively focus on the "Short Window" channel for transient sounds and the "Long Window" channel for tonal structures **Cite solution_lesson_node_00029**.
    *   **Adaptation:** The 3-channel audio input is mapped directly to the pretrained RGB weights **Cite solution_lesson_node_00005**.
    *   **Temporal Preservation:** The strides of the final two residual stages (Layer 3 and 4) will be set to `(1, 1)` to prevent excessive downsampling, ensuring the feature map retains sufficient temporal length for the recurrent layer **Cite solution_lesson_node_00017**.
*   **Neck:** **Bidirectional GRU (BiGRU)**.
    *   The features are averaged over the frequency dimension and passed to a BiGRU to explicitly model the sequential order of phonemes **Cite solution_lesson_node_00017**.
*   **Head (Structural Innovation):** **Multi-Head Attention Pooling**.
    *   Instead of standard Attention Pooling (which computes a single weighted sum of time steps), we will implement **Multi-Head Attention**. The model will learn $K$ distinct attention masks (e.g., $K=4$).
    *   *Mechanism:* Each head computes its own attention weights, allowing Head 1 to focus on the start of the command (e.g., "s" in "stop"), Head 2 on the middle (e.g., "o"), and Head 3 on the end (e.g., "p").
    *   *Aggregation:* The weighted sums from all heads are concatenated to form a rich, multi-part representation vector before the final classification layer. This provides a more granular descriptor of the spoken command than a single global average.

### Data
*   **Preprocessing & Caching:**
    *   We will **pre-compute** the 3-Channel Multi-Resolution Spectrograms (16kHz, padded to 1s, `n_mels=64`) and save them to disk as `.npy` files to eliminate the CPU bottleneck identified in previous runs **Cite solution_lesson_node_00028**.
*   **Sampling Strategy:**
    *   We will use the **Full Unknown Dataset** (approx. 30k samples) and employ a **Weighted Random Sampler**. This ensures every batch is balanced across all 12 classes, maximizing the diversity of negative examples the model sees **Cite solution_lesson_node_00022**.
*   **Augmentation:**
    *   **SpecAugment Only:** Apply Frequency and Time Masking to the cached features.
    *   **Configuration:** Use **inclusive bounds** for mask generation **Cite solution_lesson_node_00011**. Fill masks with the **minimum value** of the spectrogram **Cite solution_lesson_node_00010**. Strictly limit time masks to **<20%** of the duration to preserve short command context **Cite solution_lesson_node_00008**.
    *   **Exclusion:** We will **NOT** use MixUp or Label Smoothing, as these techniques have been shown to cause underfitting by over-regularizing the model given the small generalization gap **Cite solution_lesson_node_00016** **Cite solution_lesson_node_00019**.

### Training
*   **Loss Function:** Standard **Cross-Entropy Loss**.
*   **Optimizer:** **AdamW** with weight decay.
*   **Scheduler:** **Cosine Annealing** learning rate scheduler to ensure smooth convergence.
*   **Procedure:** Train on the cached features using the Weighted Random Sampler for a fixed number of epochs (e.g., 20-25). Monitor accuracy on the speaker-disjoint validation set.

### Evaluation
*   **Inference:** For each test file, generate the 3-Channel Multi-Resolution Spectrogram (without augmentation).
*   **Prediction:** Pass the input through the MR-SK-CRNN. The Multi-Head Attention Pooling will aggregate features from the active speech segments, handling the uncropped nature of the test data. The final prediction is the class with the highest probability.
