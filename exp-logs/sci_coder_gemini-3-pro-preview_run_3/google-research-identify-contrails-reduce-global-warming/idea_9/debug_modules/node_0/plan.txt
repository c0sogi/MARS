This script demonstrates the usage of the provided Contrail Identification library. It covers the following steps:
1.  **Utility Verification**: Validates the Run-Length Encoding (RLE) and Dice score functions with deterministic inputs.
2.  **Dataset & DataLoader**: Demonstrates how to instantiate the dataset in debug mode (loading a small subset) and verifies the shape of the input tensors (9-channel temporal composites) and masks.
3.  **Model Architecture**: Instantiates the U-Net with ConvNeXt backbone and verifies the forward pass output dimensions.
4.  **Training Loop**: Runs a minimal training loop (1 epoch, few batches) using the `DiceBCELoss` and `train_one_epoch` engine function.
5.  **Validation**: Runs the validation engine to compute the Global Dice score.
6.  **Inference & Submission**: Saves a checkpoint and generates a submission file using the `make_submission` function with Test Time Augmentation (TTA).
