The following script demonstrates the end-to-end usage of the provided library modules for the contrail detection task. It performs the following steps:

1.  **Configuration**: Overrides default configuration settings (enabling debug mode, reducing epochs and batch size) to ensure the script runs quickly for demonstration purposes.
2.  **Data Loading**: Instantiates the `ContrailDataset` and `DataLoaders` for training, validation, and testing. It verifies the shape and integrity of the loaded data batches.
3.  **Model Initialization**: Instantiates the `ContrailUNetPlusPlus` model, moves it to the appropriate device (GPU/CPU), and verifies the output shapes for both training (deep supervision list) and evaluation (single tensor) modes.
4.  **Loss Function**: Demonstrates the calculation of `BCEDiceLoss` on dummy data.
5.  **Training Loop**: Runs the `fit` engine for a single epoch using a subset of data. This validates the integration of the optimizer, loss function, and checkpoint manager.
6.  **Inference**: Generates predictions using the trained model on the test set and saves the submission file using `predict_and_submit`.
7.  **Validation**: Checks the generated submission file to ensure it meets the required format.
