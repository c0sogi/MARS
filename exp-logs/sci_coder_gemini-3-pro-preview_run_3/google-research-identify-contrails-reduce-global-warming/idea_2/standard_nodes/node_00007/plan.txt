Here is the implementation strategy for the `runfile.py` script:

1.  **Environment Setup**: Import necessary libraries and the provided modules (`config`, `utils`, `data`, `model`, `training`). Set random seeds for reproducibility.
2.  **Configuration Override**: Modify `Config.EPOCHS` to 5 to create a "fast baseline" that fits within the time limit while still processing the full dataset.
3.  **Training**: Execute `train_model(debug=False)`. This function orchestrates the training loop, validation monitoring, and saves the best model (averaged from top checkpoints) to `Config.BEST_MODEL_PATH`.
4.  **Validation & Inference**:
    *   Load the best averaged model weights.
    *   Iterate through the validation set using `val_loader`.
    *   Compute the global Dice coefficient (`Final Validation Metric`).
    *   Collect per-image error metrics (1 - Dice) for failure analysis.
5.  **Failure Analysis**: Map the per-image errors back to the validation metadata (timestamp, spatial coordinates) and calculate Pearson correlations to identify systematic error sources.
6.  **Submission Generation**:
    *   Check if the `Final Validation Metric` exceeds the threshold (0.5558921016716757).
    *   If passed, run inference on the test set (`test_loader`).
    *   Apply a threshold (0.5) to probabilities, generate Run-Length Encodings (RLE) for the binary masks, and save the results to `./submission/submission.csv`.
