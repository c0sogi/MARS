To establish a highly efficient baseline that balances speed with reliable performance, I propose a **Lightweight Vanilla U-Net on Physics-Informed Composites**.

### Model
The architecture is a custom, shallow Encoder-Decoder Convolutional Neural Network (CNN) designed to be significantly smaller and faster than standard backbone-based models (like Model 1's EfficientNet).
*   **Input:** Instead of stacking all raw bands and time steps (which results in high dimensionality), the model utilizes a compact 6-channel input tensor.
    *   **Channels 1-3 (Spatial/Spectral):** The "Ash" false-color composite of the labeled frame. This composite is a domain-specific combination of infrared bands known to highlight contrails (based on optical depth and particle size properties).
    *   **Channels 4-6 (Temporal):** The pixel-wise difference between the Ash composite of the current frame ($t$) and the immediately preceding frame ($t-1$). This explicitly provides the network with motion and formation cues without requiring recurrent layers or 3D convolutions.
*   **Encoder:** A simple stack of 3-4 convolutional blocks. Each block consists of two $3 \times 3$ convolutions followed by Batch Normalization, ReLU activation, and $2 \times 2$ Max Pooling. The number of filters starts low (e.g., 16 or 32) to maintain high throughput.
*   **Decoder:** Symmetric to the encoder, using bilinear upsampling followed by concatenation with the corresponding encoder feature map (skip connections) to preserve spatial resolution.
*   **Output Head:** A final $1 \times 1$ convolution with a Sigmoid activation function to produce a binary probability map of the same resolution as the input ($256 \times 256$).

### Data
Preprocessing focuses on reducing the raw data into the physics-informed features required by the model.
1.  **Brightness Temperature Conversion:** Convert the raw pixel values of Bands 11, 13, 14, and 15 into brightness temperatures (Kelvin) using the calibration parameters provided in the metadata.
2.  **Ash Composite Generation:** Construct the 3-channel Ash image for the labeled frame ($t=4$) and the previous frame ($t=3$) using the standard formula:
    *   Red: Band 15 minus Band 13 (Difference).
    *   Green: Band 14 minus Band 11 (Difference).
    *   Blue: Band 14 (Temperature).
3.  **Temporal Difference:** Subtract the Ash composite at $t=3$ from the Ash composite at $t=4$ to create the temporal difference channels.
4.  **Normalization:** Linearly scale the Ash and Difference channels to a $[0, 1]$ range based on global min/max statistics calculated from a subset of the training data. This ensures stable gradients during training.

### Training
The training procedure prioritizes convergence speed and stability.
*   **Loss Function:** A combined **Dice Loss + Binary Cross-Entropy (BCE) Loss**. The Dice Loss directly optimizes the evaluation metric, while BCE provides smooth gradients for pixel-level classification.
*   **Optimizer:** Adam optimizer with a default learning rate (e.g., $1e-3$) and a learning rate scheduler that reduces the rate upon a plateau in validation loss.
*   **Strategy:** Train on the generated 6-channel inputs. Since the model is lightweight, large batch sizes can be used to maximize GPU utilization. No heavy augmentations (like elastic transforms) are applied; only simple flips and 90-degree rotations are used to prevent overfitting.

### Evaluation
*   **Inference:** For each sample in the test set, generate the Ash composite and temporal difference features as described above. Pass this 6-channel tensor through the trained network.
*   **Post-Processing:** Apply a fixed threshold (e.g., 0.5) to the output probability map to create a binary mask.
*   **Formatting:** Flatten the binary mask and convert it to Run-Length Encoding (RLE) strings as specified in the submission format. Empty predictions are marked with a hyphen.
