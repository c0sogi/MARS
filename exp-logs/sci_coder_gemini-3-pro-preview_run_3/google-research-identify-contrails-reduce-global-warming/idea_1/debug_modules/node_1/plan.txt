The error arises because the `verbose` parameter in `torch.optim.lr_scheduler.ReduceLROnPlateau` has been deprecated and removed in recent PyTorch versions (including the installed version 2.8.0). To fix this, I will remove the `verbose=False` argument from the scheduler initialization in both `library/model.py` and `library/train.py`.
