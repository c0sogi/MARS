To optimize the solution, I will implement a strategy based on the provided lessons:

1.  **Loss Function Alignment**: I will replace the standard `BCEWithLogitsLoss` with a **Hybrid Loss (BCE + Dice)**. The previous solution failed (Dice ~0.43) largely because pure BCE allows the model to ignore the sparse minority class (contrails < 1%). A region-based loss is critical for this imbalance (Cite {solution_lesson_node_00010}).
2.  **Backbone Efficiency**: I will switch the backbone from `efficientnet_b4` to `efficientnet_b0`. Lesson 8 demonstrates that `efficientnet_b0` converges faster and achieves competitive results (Dice ~0.56) compared to heavier custom models, and Lesson 11 warns that heavier backbones like B4 can underperform if not trained extensively. B0 is sufficient and allows for faster epochs (Cite {solution_lesson_node_00008}).
3.  **Extended Training**: I will increase the training duration from 10 to 30 epochs. Lesson 9 shows that extending `T_max` in Cosine Annealing significantly boosts performance by allowing more exploration before convergence (Cite {solution_lesson_node_00009}).
4.  **Test Time Augmentation (TTA)**: I will implement TTA (Horizontal and Vertical Flips) during inference. This provides a consistent, zero-training-cost performance boost by marginalizing over spatial variances (Cite {solution_lesson_node_00016}).

class DiceLoss(nn.Module):
    """
    Differentiable Dice Loss for training.
    Cite {solution_lesson_node_00010}: Region-based loss is critical for imbalanced segmentation.
    """
    def __init__(self, smooth=1e-6):
        super(DiceLoss, self).__init__()
        self.smooth = smooth

    def forward(self, logits, targets):
        probs = torch.sigmoid(logits)
        probs = probs.view(-1)
        targets = targets.view(-1)
        
        intersection = (probs * targets).sum()
        union = probs.sum() + targets.sum()
        
        dice = (2.0 * intersection + self.smooth) / (union + self.smooth)
        return 1.0 - dice


class CombinedLoss(nn.Module):
    """
    Hybrid Loss: BCE + Dice.
    """
    def __init__(self):
        super(CombinedLoss, self).__init__()
        self.bce = nn.BCEWithLogitsLoss()
        self.dice = DiceLoss()

    def forward(self, logits, targets):
        return self.bce(logits, targets) + self.dice(logits, targets)
