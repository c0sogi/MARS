The implementation strategy is as follows:

1.  **Setup & Configuration**: We will initialize the environment by setting random seeds for reproducibility. We will override the `Config` class paths to point to a temporary working directory (`./working/demo_execution`) to ensure we do not interfere with existing experiment files and to demonstrate a self-contained run.
2.  **Data Subset Selection**: To optimize for speed, we will load the training metadata and select a tiny subset of data (4 images across 2 classes). This is sufficient to satisfy the Linear Discriminant Analysis (LDA) requirement of having at least two classes while keeping runtime minimal.
3.  **Component Verification**: We will systematically instantiate and test each core component from the library:
    *   **`LeafImageProcessor`**: Verify it loads images and generates exactly 12 rotated views of the correct dimensions.
    *   **`DualStreamExtractor`**: Verify it extracts features from the views and outputs a vector of size 2560 (1024 for DINOv2 + 1536 for ConvNeXt).
    *   **`DataManager`**: execute the full feature extraction, tabular processing, manifold densification, and feature fusion logic on the subset. We will assert that the data shapes transform correctly (e.g., densification should triple the sample count).
    *   **`LDAPipeline`**: Train the model on the densified features and generate predictions on the inference features.
4.  **Execution**: The script will run these steps sequentially, printing status updates and using assertions to validate correctness at each stage.
