# Proposed Solution: Manifold-Densified Linear Discriminant Analysis via Orthogonal View-Set Augmentation

## Model
The architecture retains the high-performance "Extract-Reduce-Fuse" design but is trained on a topologically densified feature manifold.
1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: We will utilize **DINOv2 (ViT-Large)** to capture self-supervised geometric priors (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: We will utilize **ConvNeXt Large** to capture high-frequency margin details (Cite solution_lesson_node_00019).
2.  **Early Fusion**: The embeddings from both backbones are concatenated with the **Quantile-Transformed** tabular features. We strictly prefer Early Fusion over Late Fusion to leverage cross-modal correlations (Cite solution_lesson_node_00039).
3.  **Dimensionality Reduction**: **Principal Component Analysis (PCA)** is applied to the fused vector, retaining **99% of the variance** to preserve discriminative tail signals (Cite solution_lesson_node_00019).
4.  **Classifier**: A single **Linear Discriminant Analysis (LDA)** model with **Ledoit-Wolf shrinkage**. We retain this classifier for its dominance in few-shot regimes (Cite solution_lesson_node_00021) and stability compared to bagging (Cite solution_lesson_node_00028).

## Data
The core innovation is **Orthogonal View-Set Augmentation**, which triples the training sample size without violating the statistical assumptions of the inference phase.
1.  **Multi-View Extraction**: For every image in the dataset (Train and Test), we extract features for **12 equidistant rotations** (0°, 30°, 60°, ..., 330°) instead of the standard 4.
2.  **Training Topology (Densification)**: Instead of creating one centroid per image, we generate **3 distinct "Orthogonal Centroids"** per training image by averaging mutually exclusive sets of 4 orthogonal views:
    *   **Sample A**: Average of views {0°, 90°, 180°, 270°}.
    *   **Sample B**: Average of views {30°, 120°, 210°, 300°}.
    *   **Sample C**: Average of views {60°, 150°, 240°, 330°}.
    *   **Impact**: This increases the training set size from $N$ to $3N$ (approx. 2100 samples). Crucially, unlike the failed "single-view" expansion in Lesson 00049, each of these samples has the **exact same variance profile** (variance reduced by factor 4) as the inference samples. This allows the LDA to learn a robust covariance matrix from a dense cloud of valid centroids.
3.  **Inference Topology**: For test images, we generate a single feature vector using the standard orthogonal set (**Sample A**: Average of {0°, 90°, 180°, 270°}). This ensures the test data lies exactly within the distribution learned during training.

## Training
1.  **Feature Caching**: Run the 12-view extraction pipeline once for the entire dataset using the GPU (Cite solution_lesson_node_00011).
2.  **Pipeline Fitting**:
    *   Construct the **Densified Training Matrix** ($3N$ rows).
    *   Fit the **Quantile Transformer** (on tabular columns) and **PCA** (on fused columns) on this densified matrix.
    *   Train the **LDA model** on the projected densified matrix. This allows the model to learn from the subtle aliasing and grid-alignment variations between the 0°, 30°, and 60° orientations, effectively filling holes in the class manifolds (Cite solution_lesson_node_00033).

## Evaluation
1.  **Inference**: For each test sample:
    *   Retrieve the 4 standard orthogonal views (0°, 90°, 180°, 270°).
    *   Compute the element-wise average to form the test centroid.
    *   Concatenate with the transformed tabular features.
2.  **Prediction**:
    *   Project the test centroid using the PCA model fitted on the densified training set.
    *   Predict probabilities using the LDA model fitted on the densified training set.
3.  **Formatting**: Apply the required probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the submission CSV.
