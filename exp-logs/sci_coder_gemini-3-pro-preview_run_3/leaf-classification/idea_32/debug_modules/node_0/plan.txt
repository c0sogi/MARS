Implementation Strategy:
1.  **Setup and Configuration**: Import necessary libraries and the provided modules. Override `Config` parameters to enable `DEBUG` mode, reduce `BATCH_SIZE`, set `N_FOLDS` to 2, and switch the deep learning models to `resnet18` (via `timm`) to ensure the script runs quickly and fits within the time/compute constraints.
2.  **Data Preparation**: Create a small, valid subset of the training metadata containing only 2 species and a few samples. This prevents `StratifiedKFold` errors during the demo execution (since the full dataset has 99 classes, a random small sample might not have enough members per class for cross-validation).
3.  **Utility Demonstration**: Demonstrate `load_image`, `rotate_image`, and `clip_probabilities` using a real image from the dataset, verifying outputs with assertions.
4.  **Feature Extraction**: Instantiate `FeatureExtractor` and run it on the prepared subset. Verify that the output feature arrays have the expected dimensions (N, 12, 1024) given the switch to ResNet18 (512 output dim per stream).
5.  **Data Processing**: Instantiate `DataProcessor`. Manually invoke `_compute_centroids` and `_densify` on the extracted features to demonstrate the manifold densification logic. Verify shapes of the densified data.
6.  **Model Pipeline**: Instantiate `LeafClassifier`. Generate synthetic data matching the densified dimensions and train the pipeline. Verify that predictions are valid probabilities.
7.  **Engine Execution**: Run the full `Engine` workflow using the modified configuration. This ties everything together, performing training, inference, and submission generation on the demo subset.
