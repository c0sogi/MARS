The error arises because `StratifiedKFold` is configured with `n_splits=10`, but the dataset contains classes with as few as 5 samples. Scikit-learn requires that the number of splits be less than or equal to the minimum number of samples in any class to ensure stratification is possible. To resolve this, I will reduce `N_FOLDS` in `library/config.py` to 5, which matches the minimum class size found in the data analysis.
