Based on the comprehensive analysis of the previous experiments and the distilled lessons, particularly the conflict between **Manifold Densification** (success in Lesson 00053) and **Manifold Complexity** (failure in Lesson 00065), I propose the following optimized strategy.

This solution introduces **Orientation-Specialized Linear Discriminant Experts (OS-LDE)**. This structural innovation resolves the "Linear Separability vs. Robustness" trade-off by handling distinct rotational alignments with specialized linear classifiers, ensuring that no single LDA model is forced to resolve a non-linear, rotation-induced manifold.

# Proposed Solution: Orientation-Specialized Linear Discriminant Experts (OS-LDE)

## Model
The architecture employs a **Multi-Expert Ensemble** design. Instead of a single LDA classifier trying to learn a decision boundary across all rotational variances (which Lesson 00065 proved destroys separability), we deploy parallel linear experts, each specialized for a specific orthogonal subspace.

1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: **DINOv2 (ViT-Large)** to capture self-supervised geometric priors (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: **ConvNeXt Large** to capture high-frequency margin details (Cite solution_lesson_node_00019).
2.  **Independent Subspace Reduction**: We apply **Principal Component Analysis (PCA)** to each visual stream *independently*, retaining **99% of the variance** for each. This preserves the distinct manifold structures of the ViT and CNN embeddings (Cite solution_lesson_node_00052).
3.  **Global Gaussianization**: We apply a **Quantile Transformer (Output distribution = Normal)** to **ALL** feature streams (PCA-reduced DINOv2, PCA-reduced ConvNeXt, and tabular). This strictly enforces the Gaussian assumption required by the downstream LDA experts (Cite solution_lesson_node_00021).
4.  **Early Fusion**: The Gaussianized features are concatenated into a single vector (Cite solution_lesson_node_00039).
5.  **Classifier Bank**: The core innovation is replacing the single LDA with a bank of **3 Independent Linear Discriminant Analysis (LDA)** models (with Ledoit-Wolf shrinkage).
    *   **Expert 1**: Specialized on the $0^\circ$-aligned orthogonal set.
    *   **Expert 2**: Specialized on the $30^\circ$-aligned orthogonal set.
    *   **Expert 3**: Specialized on the $60^\circ$-aligned orthogonal set.
    *   *Rationale*: This ensures that each LDA expert sees a **unimodal** distribution for each class. Mixing multiple alignments into a single LDA (as in Lesson 00065) creates multimodal or ring-shaped distributions that violate LDA's Gaussian assumption.

## Data
We utilize **Orthogonal View-Set Partitioning** to generate specialized training data for each expert.

1.  **Multi-View Extraction**: For every image (Train and Test), extract features for **12 equidistant rotations** (0°, 30°, 60°, ..., 330°).
2.  **Orthogonal Set Generation**: Partition these views into 3 mutually exclusive sets per image:
    *   **Set A (0-Series)**: {0°, 90°, 180°, 270°}
    *   **Set B (30-Series)**: {30°, 120°, 210°, 300°}
    *   **Set C (60-Series)**: {60°, 150°, 240°, 330°}
3.  **Centroid Computation**: Compute the **element-wise average** (centroid) for each set.
    *   *Note*: Unlike Lesson 00053, we do *not* combine these centroids into a single training set. Centroid A is used *only* for Expert 1, Centroid B for Expert 2, etc. This maintains strict variance alignment (Cite solution_lesson_node_00049) and linear separability (Cite solution_lesson_node_00065).

## Training
We employ **Stratified K-Fold Cross-Validation (K=10)** (Cite solution_lesson_node_00033) to train the expert bank.

1.  **Feature Caching**: Execute the 12-view extraction pipeline once using the GPU (Cite solution_lesson_node_00011).
2.  **Expert Training (Per Fold)**:
    *   Split unique image IDs into training and validation sets.
    *   **Train Expert 1**: Fit Independent PCAs, Quantile Transformer, and LDA on **Centroid A** of the training IDs.
    *   **Train Expert 2**: Fit separate Transformers and LDA on **Centroid B** of the training IDs.
    *   **Train Expert 3**: Fit separate Transformers and LDA on **Centroid C** of the training IDs.
    *   *Result*: Three distinct pipelines, each optimized for a specific rotational slice of the data manifold.

## Evaluation
1.  **Multi-Expert Inference**: For each test image:
    *   Generate Centroids A, B, and C.
    *   Pass **Centroid A** through **Expert 1** pipeline $\rightarrow$ Probability Vector $P_A$.
    *   Pass **Centroid B** through **Expert 2** pipeline $\rightarrow$ Probability Vector $P_B$.
    *   Pass **Centroid C** through **Expert 3** pipeline $\rightarrow$ Probability Vector $P_C$.
2.  **Aggregation**: Compute the arithmetic mean of the probability vectors: $P_{final} = \frac{1}{3}(P_A + P_B + P_C)$.
    *   This provides the robustness of "Full-Manifold Aggregation" (Idea 19) without the risk of "Manifold Complexity" destroying the classifier's decision boundary.
3.  **Ensemble Averaging**: Average the results across the 10 K-Fold models to minimize split variance (Cite solution_lesson_node_00028).
