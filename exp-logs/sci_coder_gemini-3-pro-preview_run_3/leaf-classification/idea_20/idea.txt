# Proposed Solution: Full-Manifold Orthogonal Densification with Independent Gaussianized Subspaces

## Model
The architecture utilizes a **Dual-Stream Early Fusion** design driven by a single **Linear Discriminant Analysis (LDA)** classifier. This design leverages the proven linear separability of the feature space (Cite solution_lesson_node_00019) while strictly enforcing the statistical assumptions required for stable covariance estimation.

1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: We will utilize **DINOv2 (ViT-Large)** to capture self-supervised geometric priors (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: We will utilize **ConvNeXt Large** to capture high-frequency margin details (Cite solution_lesson_node_00019).
2.  **Independent Subspace Reduction**: We will apply **Principal Component Analysis (PCA)** to each visual stream *independently*, retaining **99% of the variance** for each. This ensures that the distinct manifold structures of the ViT and CNN embeddings are preserved without one dominating the other, correcting the fusion flaw identified in previous attempts (Cite solution_lesson_node_00052).
3.  **Global Gaussianization**: We will apply a **Quantile Transformer (Output distribution = Normal)** to **ALL** feature streams: the PCA-reduced DINOv2 embeddings, the PCA-reduced ConvNeXt embeddings, and the 192 tabular features.
    *   *Rationale*: LDA theoretically assumes class-conditional Gaussian densities. While PCA decorrelates features, it does not guarantee normality. Explicitly warping the deep feature space to a Gaussian distribution strictly satisfies the classifier's assumptions (Cite solution_lesson_node_00021).
4.  **Early Fusion**: The Gaussianized vectors from all streams are concatenated into a single feature vector. We strictly prefer Early Fusion to leverage cross-modal correlations (Cite solution_lesson_node_00039).
5.  **Classifier**: A single **Linear Discriminant Analysis (LDA)** model with **Ledoit-Wolf shrinkage**. We rely on this stable classifier to dominate the few-shot regime (Cite solution_lesson_node_00009), avoiding the data starvation caused by bagging (Cite solution_lesson_node_00028).

## Data
We employ **Orthogonal View-Set Averaging** (Manifold Densification) to structurally increase the sample size for covariance estimation. Crucially, we limit the augmentation to a validated range (12 views) to avoid the manifold destruction observed with excessive rotation (Cite solution_lesson_node_00065).

1.  **Multi-View Extraction**: For every image in the dataset (Train and Test), we extract features for **12 equidistant rotations** (0°, 30°, 60°, ..., 330°).
2.  **Training Topology (Densification)**: We generate **3 distinct "Orthogonal Centroids"** per image by averaging mutually exclusive sets of 4 orthogonal views:
    *   Centroid A: Average of {0°, 90°, 180°, 270°}
    *   Centroid B: Average of {30°, 120°, 210°, 300°}
    *   Centroid C: Average of {60°, 150°, 240°, 330°}
    *   *Impact*: This triples the effective training sample size ($3N$) with high-quality, variance-aligned representations ($\sigma^2/4$), allowing the LDA to estimate a robust covariance matrix (Cite solution_lesson_node_00053).
3.  **Tabular Augmentation**: The invariant tabular features are replicated for each of the 3 centroids.

## Training
We utilize **Stratified K-Fold Cross-Validation (K=10)** to construct an ensemble, ensuring robustness against "lucky split" variance (Cite solution_lesson_node_00033).

1.  **Feature Caching**: Execute the 12-view extraction pipeline once for the entire dataset using the GPU (Cite solution_lesson_node_00011).
2.  **Ensemble Construction**:
    *   Split the unique image IDs into 10 stratified folds.
    *   For each fold $k$:
        *   **Expand**: Construct the **Densified Training Set** ($3 \times$ samples) from the training IDs.
        *   **Fit Transformers**: Fit the Independent PCAs and the Global Quantile Transformer on this densified training set.
        *   **Train Classifier**: Train the LDA model (Ledoit-Wolf) on the transformed densified set.
        *   **Store**: Save the pipeline as member $k$ of the ensemble.

## Evaluation
1.  **Full-Manifold Test-Time Aggregation (Innovation)**: Unlike previous iterations that inferred on a single canonical centroid (Cite solution_lesson_node_00053), we generate **all 3 Orthogonal Centroids** (A, B, and C) for each test image.
    *   Pass all 3 centroids through the saved ensemble pipelines.
    *   This strictly adheres to the "Train on the Aggregation" principle (Cite solution_lesson_node_00049) while utilizing the full rotational manifold of the test data to smooth out alignment noise.
2.  **Aggregation**:
    *   Compute the average probability vector across the 3 centroids for each model.
    *   Compute the average probability vector across the 10 K-Fold models (Cite solution_lesson_node_00028).
3.  **Formatting**: Apply probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the submission CSV.
