The error `ValueError: Object arrays cannot be loaded when allow_pickle=False` occurs because the pipeline attempts to load the `train_densified_labels.npy` file, which contains string data (class names). NumPy stores arrays of strings as object arrays (`dtype=object`), and for security reasons, `np.load` defaults to `allow_pickle=False`, preventing these arrays from being loaded. To resolve this, I will update the `load_npy` function in `library/utils.py` to explicitly set `allow_pickle=True`, enabling the loading of string arrays containing labels and IDs.
