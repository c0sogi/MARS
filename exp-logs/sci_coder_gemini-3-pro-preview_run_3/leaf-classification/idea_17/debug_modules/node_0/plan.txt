Implementation Strategy:
1.  **Setup & Configuration Override**: We initialize a demo environment by creating a separate working directory (`./working/demo_run`) and overriding the global `Config` settings. We reduce the number of folds, inner folds, and training centroids to ensure the script executes rapidly (within minutes).
2.  **Data Subsetting**: Instead of processing the full dataset (which would take significant time for feature extraction), we create a small subset of the metadata containing only the top 3 classes and a few images per class. This subset is saved to the demo directory, and `Config` is updated to point to it.
3.  **Feature Extraction**: We utilize the `FeatureExtractor` to compute DINOv2, ConvNeXt, and tabular features for our subset. We force a reload to ensure the new subset is processed.
4.  **Data Processing**: We use `LeafDataProcessor` to handle hyper-densification (generating multiple views/centroids per training image) and dimensionality reduction (PCA). We verify the shapes of the processed data.
5.  **Modeling**: We instantiate and train the `StackedEnsemble`, which performs a two-level stacking (Base Experts -> Meta Learner) using OOF logits.
6.  **Inference & Submission**: We generate predictions for the validation and test sets, calculate the log loss metric, and format the final predictions into a CSV submission file, verifying the output format.
