Based on the comprehensive analysis of the previous experiments and the distilled lessons, I propose the following optimized strategy. This solution introduces **Stacked Discriminant Analysis with Hyper-Densified OOF Projection**. This structural innovation evolves the "Early Fusion" (Lesson 00039) and "Hierarchical" concepts into a rigorous **Stacked Generalization** framework. It explicitly addresses the issue where powerful backbones create "perfectly separated" training manifolds that prevent downstream classifiers from learning robust fusion weights, while maximizing statistical stability via **Hyper-Densification** (Lesson 00053).

# Proposed Solution: Stacked Discriminant Analysis with Hyper-Densified OOF Projection

## Model
The architecture is a **Two-Level Stacked Ensemble** designed to decouple modality-specific feature extraction from cross-modal calibration.

1.  **Level 1: Modality-Specific Discriminant Experts**:
    *   **Stream A (Global Geometry)**: **DINOv2 (ViT-Large)** embeddings, reduced via **Independent PCA** (99% variance) (Cite solution_lesson_node_00052, solution_lesson_node_00021).
    *   **Stream B (Local Texture)**: **ConvNeXt Large** embeddings, reduced via **Independent PCA** (99% variance) (Cite solution_lesson_node_00019).
    *   **Stream C (Engineered Metadata)**: 192 tabular features transformed via **Quantile Transformer** (Gaussian output) (Cite solution_lesson_node_00021).
    *   **Base Classifiers**: Each stream is fed into a dedicated **Linear Discriminant Analysis (LDA)** model (with Ledoit-Wolf shrinkage). These models project the high-dimensional inputs onto $C-1$ (98) discriminant axes (logits).

2.  **Level 2: Meta-Discriminant Fusion**:
    *   **Input**: The concatenation of the **decision function values** (logits) from the three Base LDAs. This creates a compact, highly discriminative feature vector of size $3 \times 98 = 294$.
    *   **Meta-Classifier**: A final **Meta-LDA** model trained on this concatenated vector. By operating on logits rather than raw features, the Meta-LDA learns to weigh the *confidence* of each modality rather than just its variance.

## Data
We employ **Hyper-Densification via Orthogonal View-Set Averaging** to strictly enforce variance alignment while maximizing the sample size for the Base and Meta learners.

1.  **Multi-View Extraction**: For every image (Train and Test), we extract features for **36 equidistant rotations** (0°, 10°, ..., 350°).
2.  **Training Topology (Hyper-Densification)**: For the training set, we generate **9 distinct "Orthogonal Centroids"** per image by averaging mutually exclusive sets of 4 orthogonal views (e.g., Centroid 1: {0°, 90°, ...}, Centroid 2: {10°, 100°, ...}).
    *   This increases the effective training size to **$9N$** (approx. 6,400 samples) with variance-aligned samples ($\sigma^2/4$), enabling robust covariance estimation (Cite solution_lesson_node_00053, solution_lesson_node_00049).
3.  **Inference Topology**: For validation and test sets, we generate a **single canonical centroid** per image (Average of {0°, 90°, 180°, 270°}).

## Training
We utilize **Stratified K-Fold Cross-Validation (K=10)** for the outer evaluation loop (Cite solution_lesson_node_00033). Crucially, we employ **Out-Of-Fold (OOF) Stacking** to train the Meta-Learner.

1.  **Feature Caching**: Execute the 36-view extraction pipeline once for the entire dataset using the GPU (Cite solution_lesson_node_00011).
2.  **Ensemble Construction (Per Fold)**:
    *   **Inner CV for Meta-Features**: Within the training data of the current fold, perform a 5-Fold split. Train Base LDAs on 4/5ths and predict logits on the held-out 1/5th. Repeat to generate **OOF Logits** for the entire training set.
    *   **Meta-Training**: Train the **Meta-LDA** on these OOF Logits. This forces the Meta-Learner to handle the *realistic uncertainty* of the Base Learners, preventing it from learning a trivial identity mapping from "perfect" training predictions.
    *   **Base-Retraining**: Retrain the three Base LDAs on the *full* training set of the current fold (using the Hyper-Densified topology) to prepare for inference.
    *   **Store**: Save the full pipeline (Transformers + Base LDAs + Meta LDA) as member $k$.

## Evaluation
1.  **Inference**: For each test image:
    *   Generate the canonical centroid (Average of 0°, 90°, 180°, 270°) for DINOv2 and ConvNeXt.
    *   Pass these centroids and tabular features through all 10 saved ensemble pipelines.
    *   **Step 1**: Project data through the Base LDAs to get logits.
    *   **Step 2**: Concatenate logits and feed into the Meta-LDA.
2.  **Aggregation**: Compute the **arithmetic mean** of the probability vectors from all 10 Meta-LDAs (Cite solution_lesson_node_00028).
3.  **Formatting**: Apply probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the submission CSV.
