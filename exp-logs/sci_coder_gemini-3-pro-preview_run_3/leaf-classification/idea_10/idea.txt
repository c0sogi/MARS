# Proposed Solution: Multi-Fidelity Dimensionality Ensemble of Early-Fused LDA Classifiers

## Model
The proposed architecture is a **Multi-Fidelity Dimensionality Ensemble** that structurally addresses the stability-precision trade-off identified in the "High Dimension, Low Sample Size" (HDLSS) regime. Instead of relying on a single "optimal" dimensionality reduction threshold (which leads to the bimodal stability issues observed in **Cite solution_lesson_node_00033**), this design ensembles three parallel Linear Discriminant Analysis (LDA) pipelines, each operating at a distinct level of feature variance retention.

1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: We utilize **DINOv2 (ViT-Large)** to capture self-supervised geometric priors (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: We utilize **ConvNeXt Large** to capture high-frequency margin details (Cite solution_lesson_node_00019).
2.  **Multi-Fidelity Branches**: The architecture consists of three parallel branches. In each branch, the visual embeddings from both streams are independently reduced via **Principal Component Analysis (PCA)** with different cumulative variance thresholds:
    *   **High-Fidelity Branch (99% Variance)**: Retains the "tail" of the spectral energy to maximize linear separability for "lucky" splits where the signal is clear (Cite solution_lesson_node_00019).
    *   **Mid-Fidelity Branch (95% Variance)**: Balances detail with noise reduction.
    *   **High-Stability Branch (90% Variance)**: Aggressively reduces dimensionality ($P \ll N$) to ensure robust covariance matrix estimation in LDA, directly addressing the instability and "data starvation" observed in previous attempts (Cite solution_lesson_node_00033).
3.  **Early Fusion**: Within each branch, the PCA-reduced visual features are concatenated with the 192 **Quantile-Transformed** tabular features. This **Early Fusion** strategy is strictly preferred over late fusion to leverage cross-modal correlations (Cite solution_lesson_node_00039).
4.  **Classifiers**: Each branch employs a dedicated **Linear Discriminant Analysis (LDA) model with Ledoit-Wolf shrinkage** (Cite solution_lesson_node_00009). This preserves the dominance of LDA over Logistic Regression (Cite solution_lesson_node_00021) while avoiding the pitfalls of bagging (Cite solution_lesson_node_00028).

## Data
1.  **Multi-View Canonical Averaging**: To enforce strict rotation invariance, we generate 4 canonical rotated views (0°, 90°, 180°, 270°) for every image. We extract embeddings for all views using both backbones and compute the **element-wise average** of the raw embeddings *before* PCA. This creates a robust, orientation-invariant centroid for each sample (Cite solution_lesson_node_00017).
2.  **Tabular Preprocessing**: The 192 engineered features (margin, shape, texture) are transformed using a **Quantile Transformer (Output distribution = Normal)** to satisfy the Gaussian assumption of the LDA classifiers (Cite solution_lesson_node_00021).
3.  **Cross-Validation Setup**: We utilize **Stratified K-Fold Cross-Validation (K=10)** to generate Out-Of-Fold (OOF) predictions for weight optimization, ensuring the solution is robust to data splits (Cite solution_lesson_node_00033).

## Training
1.  **Feature Extraction**: Execute the multi-view extraction pipeline once for the entire dataset using the GPU (Cite solution_lesson_node_00011).
2.  **Ensemble Optimization (Cross-Validation)**:
    *   For each fold in the 10-Fold CV:
        *   Fit PCA models (at 99%, 95%, 90% thresholds) and Quantile Transformers on the training subset.
        *   Train three independent LDA models (one per branch) on the transformed training data.
        *   Generate probability predictions for the validation subset (OOF predictions).
    *   **Weight Optimization**: Concatenate the OOF predictions from all folds. Perform a **Discrete Grid Search** (including boundaries 0 and 1) to find the optimal scalar weights $w_{99}, w_{95}, w_{90}$ that minimize the Log Loss of the combined prediction. This ensures that if the High-Fidelity branch is unstable, the ensemble can fall back to the High-Stability branch (Cite solution_lesson_node_00013, solution_lesson_node_00014).
3.  **Final Fitting**: Retrain the three PCA models, Quantile Transformers, and LDA classifiers on the **full training dataset**.

## Evaluation
1.  **Inference**: For each test sample:
    *   Generate multi-view averaged embeddings and raw tabular features.
    *   Pass the data through the three parallel branches (High, Mid, Stability) to generate three probability vectors.
2.  **Aggregation**: Compute the weighted average of the probability vectors using the optimized weights $w_{99}, w_{95}, w_{90}$ derived from the cross-validation step.
3.  **Formatting**: Apply the required probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the submission CSV.
