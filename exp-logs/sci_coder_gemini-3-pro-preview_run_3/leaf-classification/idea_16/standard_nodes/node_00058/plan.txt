The strategy involves the following steps:
1.  **Ensemble Training**: Initialize the `KFoldTrainer` and execute `train_kfold_ensemble`. This triggers the feature extraction pipeline (using `DensifiedDataLoader` and `ImageEmbedder`) to generate hyper-densified features for training and canonical features for validation. It then trains 10 Hierarchical LDA models (one per fold) and saves them to disk.
2.  **Hold-Out Validation**: Use `DensifiedDataLoader` to load the official hold-out validation set (`val.csv`) and generate its canonical features. Manually load the 10 saved models, perform inference on the validation set, and average the probabilities to form the ensemble prediction.
3.  **Metric Calculation**: Compute the Multi-class Log Loss on the hold-out validation set predictions and print it as `Final Validation Metric`.
4.  **Failure Analysis**: Calculate the per-sample log loss for the validation set. Compute the Spearman correlation between this error metric and each of the 192 tabular features. Print the top 10 features most strongly correlated with model error to identify potential weaknesses.
5.  **Submission Generation**: Call `trainer.generate_submission` to generate predictions for the test set using the trained ensemble and save the result to `./submission/submission.csv`.
