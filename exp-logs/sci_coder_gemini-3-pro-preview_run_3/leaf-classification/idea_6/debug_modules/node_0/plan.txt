This script demonstrates the end-to-end usage of the provided library components for the Leaf Species Classification task. It covers data loading, feature extraction using the dual-stream architecture (DINOv2 + ConvNeXt), model training with the Bagged LDA ensemble, and submission generation.

**Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class to reduce dataset size (`MAX_SAMPLES=40`) and ensemble size (`N_ESTIMATORS=2`). This ensures the script executes quickly (within minutes) while still exercising all code paths.
2.  **Data Loading**: We utilize `get_dataloaders` to fetch a small batch of data and verify the shapes of the multi-view image tensors and tabular features.
3.  **Feature Extraction**: We instantiate `DualStreamExtractor` to process the images through the pre-trained backbones. This confirms the deep learning components are functioning correctly on the available hardware (GPU/CPU).
4.  **Ensemble Training**: We initialize `BaggedLDAPipeline`. To ensure stable training on the tiny demo dataset, we map the target labels to a smaller subspace (5 classes). This prevents Linear Discriminant Analysis (LDA) errors related to singleton classes that might occur when subsampling 99 classes into 40 samples.
5.  **Validation**: Assertions are placed throughout to verify tensor dimensions, probability constraints (sum to 1, range [0, 1]), and file output formats.
