The implementation strategy is as follows:
1.  **Setup and Data Loading**: Initialize the environment with a fixed random seed. Load the training, validation, and test data loaders using the provided `get_dataloaders` utility.
2.  **Feature Extraction**: Utilize the `process_split` function to extract or load cached features (DINOv2, ConvNeXt, and Tabular) for all three datasets (train, val, test). This leverages the pre-computed features in the working directory to save time.
3.  **Model Training**: Instantiate the `BaggedLDAPipeline` defined in the library. Fit the ensemble model on the training features (`X_train`).
4.  **Validation & Evaluation**:
    *   Generate probability predictions for the validation set.
    *   Compute the **Multi-class Log Loss** metric using `sklearn.metrics.log_loss`.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
5.  **Failure Analysis**:
    *   Calculate the per-sample log loss to quantify error magnitude.
    *   Compute the Pearson correlation between the error magnitude and each of the 192 tabular features (Margin, Shape, Texture).
    *   Print the top features most correlated with high error to identify failure modes.
6.  **Submission**:
    *   Generate predictions for the test set.
    *   Save the predictions to `submission.csv` using the provided `save_submission` utility, ensuring the file is created for grading.
