The issue is a shape mismatch in the `BaggedLDAPipeline` ensemble caused by bootstrap sampling. When sampling with replacement (`replace=True`), rare classes may be excluded from the training subset of individual estimators. Consequently, these estimators learn fewer classes than the global set (e.g., 98 instead of 99) and produce probability matrices with fewer columns. Attempting to sum these matrices directly (`avg_probs += probs`) causes a broadcasting error.

To fix this, I will modify `BaggedLDAPipeline.predict_proba` in `library/ensemble.py`. Instead of direct summation, the code will:
1.  Initialize a zero-filled accumulator matrix with dimensions matching the *global* number of classes.
2.  For each estimator, map its output columns (corresponding to the subset of classes it learned) to the correct indices in the global matrix using `np.searchsorted`.
3.  Accumulate the probabilities into these mapped columns.

This approach ensures that missing classes are implicitly treated as having zero probability for that specific estimator, resolving the shape mismatch as per **Cite debug_lesson_7**.
