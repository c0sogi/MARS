The following script demonstrates the end-to-end usage of the provided library modules for the leaf classification task.

### Implementation Strategy
1.  **Configuration & Setup**: The script starts by importing the necessary modules and overriding key configurations in `library.config` to ensure the demo runs quickly. This includes reducing the number of cross-validation folds (`N_FOLDS=2`), batch size, and changing the working directory to a temporary demo folder.
2.  **Data Preparation**: It creates a small, stratified subset of the original metadata (12 training samples, 4 validation samples, 4 test samples) with simplified labels ("Species_A", "Species_B"). This ensures the 2-fold cross-validation runs without error and completes in seconds.
3.  **Component Demonstration**:
    *   **Feature Extraction**: Instantiates `LeafFeatureExtractor` to verify image preprocessing, multi-view generation, and batch feature extraction logic.
    *   **Data Management**: Uses `LeafDataManager` to process the raw images into densified, orthogonal centroid features suitable for the pipeline. It verifies data shapes and alignment.
    *   **Pipeline Building**: Constructs the hybrid pipeline (PCA + QuantileTransformer + LDA) using `pipeline_builder` and performs a dry-run fit.
    *   **Execution Engine**: Runs the full `train_ensemble` loop (training 2 folds) and `predict_submission` to generate the final CSV.
4.  **Validation**: Assertions are placed throughout to verify shapes, file existence, and logical correctness of the outputs.
