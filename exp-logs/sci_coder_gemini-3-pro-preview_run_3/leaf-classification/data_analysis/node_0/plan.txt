Here is the implementation strategy and the corresponding Python script for the Exploratory Data Analysis.

### Implementation Strategy

1.  **Environment Setup**: Import necessary libraries (`pandas`, `numpy`, `cv2`, `sklearn`, `os`) and set random seeds for reproducibility.
2.  **Data Loading**: Load the training metadata from `./metadata/train.csv`. This ensures we strictly use the training split defined in the previous step.
3.  **Target Variable Analysis**: Analyze the `species` column to determine the number of classes and check for class imbalance by calculating the distribution statistics (mean, std, min, max of class counts).
4.  **Tabular Data Analysis**:
    *   Group the 192 features into three categories: `Margin`, `Shape`, and `Texture`.
    *   For each group, calculate aggregated statistics (mean, std, min, max) and count outliers using the IQR method to keep the report concise.
    *   Check for missing values across all tabular features.
5.  **Image Data Analysis**:
    *   Iterate through all images referenced in the training set.
    *   Extract dimensions (Width, Height), Aspect Ratios, and Channel counts.
    *   Calculate global pixel mean and standard deviation to inform normalization strategies.
6.  **Feature Relationships**:
    *   **Correlation**: Calculate the correlation matrix for tabular features and count highly collinear pairs (> 0.90).
    *   **Feature Importance**: Train a lightweight Random Forest classifier to identify the top 5 most discriminative tabular features.
    *   **Meta-Feature Relationship**: Analyze if image geometry (Aspect Ratio) varies significantly between species using a one-way ANOVA test.
7.  **Output**: Print the results in the specified format with clear headers and formatted floating-point numbers.
