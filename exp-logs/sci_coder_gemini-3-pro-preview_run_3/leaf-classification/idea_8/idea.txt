# Proposed Solution: Random Subspace Ensemble of Linear Discriminant Analysis with Multi-View Self-Supervised Features

## Model
The proposed architecture is a **Random Subspace Ensemble (Feature Bagging) of Linear Discriminant Analysis (LDA) Classifiers**. This design structurally evolves the previous approaches by addressing the "High Dimension, Low Sample Size" (HDLSS) instability identified in the Cross-Validation experiments (Cite solution_lesson_node_00033) while strictly avoiding the "data starvation" caused by sample-based bagging (Cite solution_lesson_node_00028).

1.  **Dual-Stream Feature Extraction**:
    *   **Global Geometry Stream**: We will utilize **DINOv2 (ViT-Large)**. Its self-supervised training provides superior geometric inductive biases for binary shapes compared to supervised baselines (Cite solution_lesson_node_00021).
    *   **Local Texture Stream**: We will employ **ConvNeXt Large** to capture high-frequency margin details, utilizing a modern architecture that yields highly separable feature manifolds (Cite solution_lesson_node_00019).
2.  **Preprocessing & Fusion**:
    *   **Multi-View Averaging**: To enforce rotation invariance, we will generate 4 canonical views (0°, 90°, 180°, 270°) for each image, pass them through the backbones, and compute the **element-wise average** of the embeddings (Cite solution_lesson_node_00017).
    *   **Initial Reduction**: We will apply **Principal Component Analysis (PCA)** to each stream, retaining **99% of the variance** to preserve discriminative tail signals (Cite solution_lesson_node_00019).
    *   **Tabular Transformation**: The 192 engineered features will be transformed using a **Quantile Transformer (Output distribution = Normal)** to satisfy LDA normality assumptions (Cite solution_lesson_node_00021).
    *   **Fusion**: These streams are concatenated into a single high-dimensional feature vector.
3.  **Classifier (Innovation)**: Instead of a single LDA (prone to overfitting specific splits) or a Sample-Bagged Ensemble (prone to data starvation), we will implement a **Random Subspace Ensemble**.
    *   The ensemble consists of $M$ (e.g., 50) independent **LDA models with Ledoit-Wolf shrinkage** (Cite solution_lesson_node_00009).
    *   Crucially, each model is trained on the **full set of training samples** (preserving $N$) but utilizes a **random subset of the fused features** (reducing $P$).
    *   This strategy explicitly stabilizes the covariance matrix estimation by ensuring $P_{subset} \ll N$ for each estimator, while allowing the ensemble as a whole to leverage the entire feature set.

## Data
1.  **Augmentation**: Generate the 4 rotated views for every image in the Train, Validation, and Test sets.
2.  **Standardization**:
    *   Fit the PCA models (for image embeddings) and Quantile Transformer (for tabular data) on the full training set.
    *   Apply these transformations to all data splits.
3.  **Validation Strategy**: We will employ **Stratified K-Fold Cross-Validation** to validate the stability of the Random Subspace Ensemble, ensuring that the bimodal performance observed in previous single-split attempts is resolved (Cite solution_lesson_node_00033).

## Training
1.  **Feature Caching**: Execute the multi-view extraction pipeline once for the entire dataset using the GPU to generate the master feature matrix (Cite solution_lesson_node_00011).
2.  **Ensemble Construction**:
    *   Initialize $M=50$ LDA estimators.
    *   For each estimator $m$:
        *   Randomly select a feature mask retaining $f\%$ (e.g., 50%) of the columns from the fused feature matrix.
        *   Train the LDA model (with Ledoit-Wolf shrinkage) using **all available training samples** restricted to these features.
    *   This ensures no sample is left out (solving the small-class issue from Cite solution_lesson_node_00028) while decorrelating the errors of the individual classifiers.

## Evaluation
1.  **Inference**: For each test sample:
    *   Generate the multi-view averaged, PCA-reduced, and Quantile-transformed feature vector.
    *   Pass this vector through all $M$ estimators in the ensemble (each applying its specific feature mask).
2.  **Aggregation**: Compute the **arithmetic mean** of the probability vectors from all $M$ models. This averaging of subspace projections provides a robust estimate of the true class posterior, smoothing out artifacts from specific feature dimensions.
3.  **Formatting**: Apply the required probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the submission CSV.
