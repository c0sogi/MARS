To resolve the `torch.OutOfMemoryError`, I will implement two changes to reduce the peak GPU memory footprint during feature extraction.

1.  **Reduce Batch Size**: I will lower the `BATCH_SIZE` in `library/config.py` from 32 to 4. Since each image is expanded into 12 rotated views, a batch size of 32 results in 384 high-resolution inputs ($32 \times 12$) being processed simultaneously, which causes the memory overflow. Reducing this to 4 results in a manageable effective batch of 48 images (Cite debug_lesson_14).
2.  **Serialize Model Inference with AMP**: In `library/feature_extractor.py`, I will modify the `extract_features` method to process the two models (DINOv2 and ConvNeXt) sequentially instead of in parallel. I will also wrap the forward passes in `torch.amp.autocast("cuda")` to enable Automatic Mixed Precision, which significantly reduces activation memory usage. Explicitly deleting tensors and clearing the cache between the two model calls will further ensure that memory is released before the second model is loaded (Cite debug_lesson_7).
