The `torch.OutOfMemoryError` is caused by the data expansion strategy in the feature extraction pipeline, where each image is rotated 12 times. This results in an effective batch size of $32 \times 12 = 384$ images being processed simultaneously by the large ConvNeXt model, which exceeds the available GPU memory. To fix this, I will reduce the configured `BATCH_SIZE` from 32 to 4, bringing the effective batch size down to 48 ($4 \times 12$), which fits safely within the memory budget. Cite debug_lesson_13.
