The following script demonstrates the complete pipeline for the leaf classification task using the provided library. It optimizes execution speed by creating a small subset of the metadata (20 training samples, 5 validation samples, 5 test samples) to minimize the runtime of the heavy feature extraction phase (DINOv2 + ConvNeXt). It then verifies the logic of the `DataManager` (specifically Manifold Densification), trains the `OrthogonalLDAPipeline`, and generates a valid submission file, ensuring all components work correctly and reproducibly.
