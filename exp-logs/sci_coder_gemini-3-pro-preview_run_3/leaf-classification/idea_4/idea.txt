# Proposed Solution: Self-Supervised Geometric Features with Gaussianized Tabular Fusion

## Model
The proposed architecture evolves the "Dual-Backbone Feature Fusion" approach by shifting the feature extraction paradigm from purely supervised representations to **Self-Supervised Learning (SSL)** and strictly enforcing statistical assumptions for the generative classifier.

1.  **Dual Feature Extractors**:
    *   **Global Shape Stream (SSL)**: We will replace the supervised ViT-Base with **DINOv2 (ViT-Large)**. Unlike supervised models trained on ImageNet labels (which may bias towards texture), DINOv2 is trained via self-supervision to understand object geometry and part-whole relationships. This is structurally superior for binary leaf images where shape is the only signal.
    *   **Local Texture Stream**: We will upgrade the CNN backbone to **ConvNeXt Large** (from Tiny) to capture high-frequency margin details with greater capacity, utilizing the "Extract-Reduce-Fuse" strategy (Cite solution_lesson_node_00011).
2.  **Feature Transformation**:
    *   **Visual**: We will apply **Principal Component Analysis (PCA)** to each backbone's embeddings, retaining **99% of the variance** to preserve subtle discriminative signals in the tail of the spectrum (Cite solution_lesson_node_00019).
    *   **Tabular (Innovation)**: Instead of Standard Scaling, we will apply a **Quantile Transformer (Output distribution = Normal)** to the 192 tabular features. The tabular data consists of histograms (texture, margin) which are likely non-Gaussian. Since the downstream **Linear Discriminant Analysis (LDA)** classifier assumes class-conditional Gaussian densities, this transformation explicitly aligns the data distribution with the model's theoretical assumptions.
3.  **Classifier**: The classification head remains the **Ensemble of Linear Discriminant Analysis (LDA) with Ledoit-Wolf shrinkage** and **Regularized Multinomial Logistic Regression** (Cite solution_lesson_node_00009).

## Data
1.  **Multi-View Embedding Averaging**: To enforce rotation invariance, we will generate 4 rotated views (0°, 90°, 180°, 270°) for every image. We will extract embeddings for all views using both backbones and compute the **element-wise average** to produce a single, robust feature vector per sample (Cite solution_lesson_node_00017).
2.  **Preprocessing**:
    *   **Images**: Resized to the specific input resolution of the backbones (e.g., 224x224 or 518x518 for DINOv2), with 3-channel replication for the binary input.
    *   **Tabular**: The Quantile Transformer will be fit on the training set and applied to validation and test sets.
3.  **Fusion**: The final vector is the concatenation of the PCA-reduced DINOv2 embeddings, PCA-reduced ConvNeXt embeddings, and Gaussianized tabular features.

## Training
1.  **Extraction**: Pass the multi-view dataset through the frozen DINOv2 and ConvNeXt backbones on the GPU.
2.  **Projection & Transformation**: Fit the PCA models and Quantile Transformer solely on the training data. Transform the validation and test sets.
3.  **Model Fitting**:
    *   Train **LDA** (Ledoit-Wolf) on the fused training data.
    *   Train **Logistic Regression** (L-BFGS, L2 penalty) on the fused training data.
4.  **Ensemble Weight Optimization**: Perform a **Discrete Grid Search** (step size 0.01) for the mixing weight $w$ on the validation set. This search must explicitly evaluate the boundaries ($w=0$ and $w=1$) to prevent ensemble contamination if one model significantly outperforms the other (Cite solution_lesson_node_00013, solution_lesson_node_00014).

## Evaluation
1.  Process test images through the multi-view averaging and PCA pipeline.
2.  Transform test tabular features using the fitted Quantile Transformer.
3.  Generate probability vectors from LDA and Logistic Regression.
4.  Combine using the optimal validation weight $w$.
5.  Apply the required probability clipping and format for submission.
