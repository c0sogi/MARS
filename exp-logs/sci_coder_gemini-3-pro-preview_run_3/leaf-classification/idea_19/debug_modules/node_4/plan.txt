The error occurs because the default argument `path=Config.SUBMISSION_PATH` in the `save_submission` function is evaluated and bound when the `library.utils` module is imported. At that time, `Config.SUBMISSION_PATH` holds its initial value. When `runfile.py` subsequently updates `Config.SUBMISSION_PATH` at runtime to point to the demo directory, the `save_submission` function continues to use the stale default value. To fix this, I will modify `save_submission` to set the default value of `path` to `None` and explicitly resolve `Config.SUBMISSION_PATH` inside the function body. This ensures the function always uses the current runtime value of the configuration variable. Cite debug_lesson_9.
