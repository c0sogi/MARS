# Proposed Solution: Bagged Dual-Stream Generative Classifier with Self-Supervised Shape Priors

## Model
The proposed architecture is a **Bagged Dual-Stream Generative Classifier**. This design structurally evolves the previous "Dual-Backbone" approach by transitioning from a single hold-out validation strategy to a **Bagging (Bootstrap Aggregating)** framework. This directly addresses the "High Dimension, Low Sample Size" (HDLSS) nature of the dataset by reducing the variance of the covariance estimates in the Linear Discriminant Analysis (LDA) classifier.

1.  **Dual Feature Extractors**:
    *   **Self-Supervised Shape Stream**: We will utilize **DINOv2 (ViT-Large)** as the primary geometric feature extractor. Unlike supervised models, DINOv2 is trained via self-supervision to understand object geometry and part-whole relationships without relying on texture labels. This provides a superior inductive bias for binary leaf shapes compared to standard ImageNet-supervised models.
    *   **Supervised Texture Stream**: We will employ **ConvNeXt Large** to capture high-frequency margin details and local texture patterns. This modern architecture generates more linearly separable feature manifolds than ResNet variants (Cite solution_lesson_node_00019).
2.  **Dimensionality Reduction**: We will apply **Principal Component Analysis (PCA)** to the embeddings of each stream independently, retaining **99% of the variance**. This high retention threshold ensures that subtle discriminative signals in the tail of the spectrum are preserved (Cite solution_lesson_node_00019).
3.  **Tabular Transformation**: The 192 tabular features will be transformed using a **Quantile Transformer (Output distribution = Normal)**. This explicitly enforces the Gaussian assumption required by the downstream LDA classifier (Cite solution_lesson_node_00021).
4.  **Classifier**: The classification head will be a **Bagging Ensemble of Linear Discriminant Analysis (LDA)** models. We will discard the Logistic Regression component entirely, as previous experiments demonstrated that LDA dominates performance in this few-shot regime (Cite solution_lesson_node_00021) and mixing in weaker models causes ensemble contamination (Cite solution_lesson_node_00013).

## Data
1.  **Multi-View Averaging**: To enforce strict rotation invariance, we will generate 4 rotated views (0°, 90°, 180°, 270°) for every image in the dataset. We will pass all views through both backbones and compute the **element-wise average** of the embeddings *before* PCA. This creates a canonical, rotation-robust representation for each leaf (Cite solution_lesson_node_00017).
2.  **Preprocessing**:
    *   **Images**: Resized to 518x518 (for DINOv2) and 384x384 (for ConvNeXt), with 3-channel replication for the binary input.
    *   **Tabular**: The Quantile Transformer will be fitted within each fold of the bagging process to prevent data leakage.
3.  **Fusion**: The final feature vector for a sample is the concatenation of the PCA-reduced DINOv2 embeddings, PCA-reduced ConvNeXt embeddings, and Gaussianized tabular features.

## Training
The training process will utilize **Stratified K-Fold Cross-Validation** (e.g., K=10) to create the bagging ensemble:
1.  **Feature Extraction**: Perform the multi-view extraction for the entire dataset once using the GPU (Cite solution_lesson_node_00011).
2.  **Ensemble Training**: For each of the $K$ folds:
    *   **Split**: Divide the data into training and validation subsets.
    *   **Fit Transformers**: Fit the PCA models and Quantile Transformer solely on the training subset of the current fold.
    *   **Transform**: Apply these transformations to the training and validation data.
    *   **Fit Classifier**: Train an **LDA model with Ledoit-Wolf shrinkage** on the transformed training data. This shrinkage is critical for regularizing the covariance matrix in this high-dimensional space (Cite solution_lesson_node_00009).
    *   **Store**: Save the fitted pipeline (Transformers + LDA) as one member of the ensemble.

## Evaluation
1.  **Inference**: For each sample in the test set:
    *   Pass the multi-view averaged images and tabular features through each of the $K$ saved pipelines.
    *   Each pipeline will independently project the data (PCA/Quantile) and predict probabilities using its specific LDA model.
2.  **Aggregation**: Compute the **arithmetic mean** of the probability vectors from all $K$ models. This averaging stabilizes the decision boundaries and reduces the variance associated with any single training split.
3.  **Formatting**: Apply the required probability clipping ($[10^{-15}, 1-10^{-15}]$) and format the final CSV for submission.
