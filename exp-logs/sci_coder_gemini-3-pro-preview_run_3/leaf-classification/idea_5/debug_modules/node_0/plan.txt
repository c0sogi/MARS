The following script demonstrates the end-to-end usage of the provided machine learning library for the leaf classification task. The strategy is divided into three main parts:

1.  **Component Verification**: We first instantiate the `LeafDataset` and `load_tabular_data` functions in debug mode. This verifies that data loading and preprocessing (including multi-view generation) work correctly without processing the entire dataset.
2.  **Training Pipeline Execution**: We execute `train_bagging_ensemble` with `debug=True`. This function integrates feature extraction (using DINOv2 and ConvNeXt backbones), dimensionality reduction (PCA), and classification (LDA) within a cross-validation loop. Running in debug mode restricts the data to a small subset (20 samples) and reduces the number of folds, ensuring the demonstration completes quickly while validating the entire logic flow.
3.  **Inference and Submission**: We run `predict_ensemble` with `debug=True` to generate predictions on the test set using the models trained in the previous step. Finally, we validate the format and integrity of the generated submission file.
