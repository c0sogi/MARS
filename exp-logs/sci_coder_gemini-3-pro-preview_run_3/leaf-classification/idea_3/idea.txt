# Proposed Solution: Dual-Backbone Feature Fusion with Augmentation-Averaged Embeddings

## Model
The proposed architecture evolves the previous "Hybrid Deep-Linear" approach into a **Dual-Backbone Multi-Modal Ensemble**. This design addresses the potential bias of a single CNN architecture by integrating inductive biases from both Convolutional Neural Networks and Vision Transformers, while enforcing rotational invariance through feature-level averaging.

1.  **Dual Feature Extractors**:
    *   **CNN Stream**: We will retain the **ResNet50** (pre-trained on ImageNet) to capture local high-frequency details (margins, textures).
    *   **Transformer Stream (New)**: We will introduce a **Vision Transformer (ViT-Base)** (pre-trained on ImageNet). ViTs process images as sequences of patches, allowing them to capture global geometric dependencies and long-range shape contexts that CNNs might miss.
2.  **Dimensionality Reduction**: To manage the increased dimensionality from two backbones and adhere to the "Extract-Reduce-Fuse" strategy, we will apply independent **Principal Component Analysis (PCA)** to the embeddings of each backbone, retaining 95% of the variance for each (Cite solution_lesson_node_00011).
3.  **Classifier**: The classification head remains the **Ensemble of Linear Discriminant Analysis (LDA) and Logistic Regression**. The LDA model will utilize **Ledoit-Wolf shrinkage** to handle the fused feature covariance, while Logistic Regression will provide a regularized discriminative baseline (Cite solution_lesson_node_00009).

## Data
1.  **Augmentation-Averaged Feature Extraction**: To enforce rotational invariance—critical for leaf identification—we will not extract features from a single image view. Instead, for every sample (train/val/test), we will generate **4 rotated views** (0°, 90°, 180°, 270°). We will pass all views through both backbones and compute the **element-wise average** of the embeddings *before* PCA. This creates a robust "canonical" embedding for each leaf.
2.  **Tabular Preprocessing**: The 192 original tabular features (margin, shape, texture) will be **Standard Scaled** (Z-score normalization) (Cite solution_lesson_node_00001).
3.  **Fusion**: The final feature vector for each sample will be the concatenation of:
    *   The Standardized Tabular Features.
    *   The PCA-reduced ResNet50 Embeddings.
    *   The PCA-reduced ViT-Base Embeddings.

## Training
1.  **Feature Caching**: Run the augmentation-averaged extraction process for the entire dataset once using the GPU.
2.  **Projection**: Fit the PCA models solely on the training set embeddings and transform the validation/test sets.
3.  **Model Fitting**:
    *   Train the **Logistic Regression** model (L-BFGS, L2 penalty) on the fused training data.
    *   Train the **LDA** model (Ledoit-Wolf shrinkage) on the fused training data.
4.  **Ensemble Weight Optimization**: Perform a **Discrete Grid Search** (step size 0.01) for the mixing weight $w$ on the validation set. Crucially, this search must explicitly evaluate the boundaries ($w=0$ and $w=1$) to avoid the "ensemble contamination" and "boundary precision" issues identified in previous attempts (Cite solution_lesson_node_00013, solution_lesson_node_00014).

## Evaluation
1.  Transform the test images using the same augmentation-averaging and PCA pipelines.
2.  Concatenate with the standardized test tabular features.
3.  Generate probability vectors from both the LDA and Logistic Regression models.
4.  Combine the vectors using the optimal weight $w$ found during validation.
5.  Apply the required clipping ($[10^{-15}, 1-10^{-15}]$) and format for submission.
