The following script demonstrates the end-to-end usage of the provided library to solve the leaf classification task.

**Implementation Strategy:**
1.  **Configuration & Setup**: We import the necessary modules and the `Config` class. We override specific configurations (paths, number of folds) to create a fast-running demonstration environment.
2.  **Data Subsetting**: To ensure the script executes quickly (optimizing for speed), we create a "demo" dataset by sampling a small subset (e.g., 20 samples) from the original metadata files. This prevents the heavy feature extraction process from running on the entire dataset.
3.  **Unit Testing Logic**: We verify the core logic of the `DensificationManager`—specifically the centroid computation and data flattening—using synthetic numpy arrays. This ensures the mathematical transformations are correct before processing real data.
4.  **Pipeline Execution**: We instantiate the `ModelExecutor` to run the full training and inference pipeline.
    *   **Feature Extraction**: Automatically handled by the library using the subset metadata.
    *   **Training**: We train a 2-fold ensemble of the Hybrid LDA pipeline.
    *   **Inference**: We generate predictions for the test subset.
5.  **Validation**: We assert that the output submission file has the correct dimensions and probability values, confirming the system works as expected.
