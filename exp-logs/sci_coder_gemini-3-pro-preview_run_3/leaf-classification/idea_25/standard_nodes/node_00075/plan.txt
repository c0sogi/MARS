Implementation Strategy:
1.  **Initialization**: Set up logging and random seeds using the provided utility functions to ensure reproducibility.
2.  **Executor Instantiation**: Initialize the `ModelExecutor` class, which encapsulates the entire pipeline logic (data loading, densification, model definition, and training).
3.  **Ensemble Training**: Call `executor.train_ensemble()` to train the Stratified K-Fold ensemble of LDA models. This leverages the pre-implemented "Selective-Topology Orthogonal Manifold-Densified" strategy.
4.  **Hold-Out Validation**:
    *   Explicitly load the hold-out validation set using `executor.densification_manager.prepare_validation_data()`.
    *   Run inference using the trained ensemble on this validation set.
    *   Aggregate the predictions across the 3 orthogonal centroids per image and then across the ensemble members.
    *   Compute and print the **Multi-class Log Loss** on this hold-out set as the "Final Validation Metric".
5.  **Failure Analysis**:
    *   Calculate the log loss contribution of each validation sample.
    *   Compute the Pearson correlation between the per-sample loss and the aggregated tabular features (margin, shape, texture).
    *   Print the top 5 features most correlated with model error to identify systematic weaknesses.
6.  **Submission Generation**:
    *   Execute `executor.generate_submission()` to predict on the test set and generate the `submission.csv` file.
    *   This method handles the aggregation of test-time centroids and ensures the output format matches the sample submission.
