The error `ValueError: Object arrays cannot be loaded when allow_pickle=False` occurs because the cached `labels` array contains string data (species names), which NumPy saves as an object array. By default, `np.load` disables pickling for security reasons, preventing these arrays from loading. To resolve this, I will explicitly enable pickling for the `labels` array by passing `allow_pickle=True` to `np.load()`, as recommended in **debug_lesson_10**.
