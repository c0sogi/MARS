2.  **Data Subsetting**: To satisfy the speed requirement, load the provided metadata files (`train.csv`, `val.csv`, `test.csv`) and create small subsets. We will select the top 3 species and sample a minimal number of images (e.g., 6 per class for training, 3 for validation) to ensure the deep learning feature extraction and LDA training complete in seconds while maintaining stratification requirements for Cross-Validation.
3.  **Config Overrides**: Dynamically patch the `Config` class attributes to point to these new subset metadata files and the temporary working directory. Reduce `N_FOLDS` to 2 to minimize training iterations.
4.  **Component Verification**:
    *   **Feature Extraction**: Instantiate `FeatureExtractor` and run it on the subset. Verify that the output feature tensors (DINOv2 and ConvNeXt) have the correct dimensions corresponding to the number of images and the 12 multi-view rotations.
    *   **Data Processing**: Use `DatasetManager` to load the extracted features and perform manifold densification (converting $N$ images to $3N$ orthogonal centroids). Assert the shape transformations are correct.
    *   **Pipeline Construction**: Use `ModelFactory` to build the scikit-learn pipeline and verify it contains the expected steps (PCA, QuantileTransformer, LDA).
    *   **Training Loop**: Execute `Trainer.run()`. This will perform the 2-fold CV on the subset, train the LDA models, and generate a submission file.
    *   **Inference**: Execute `InferenceEngine.run()` to verify the test-time aggregation logic and ensure the final submission file is generated correctly.
5.  **Final Validation**: Check the generated submission file for the correct format (header, columns, row count) and clean up.
