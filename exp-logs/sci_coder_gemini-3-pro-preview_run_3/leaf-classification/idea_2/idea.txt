# Proposed Solution: Hybrid Deep-Linear Ensemble with Visual-Tabular Feature Fusion

## Model
The proposed architecture is a **Hybrid Feature Fusion Ensemble** that integrates deep visual representations with the existing high-quality tabular descriptors. This approach evolves the solution from a purely tabular linear baseline to a multi-modal system while strictly adhering to the "High Dimension, Low Sample Size" (HDLSS) principles established in the lessons.

1.  **Visual Feature Extractor (New Component)**: We will utilize a pre-trained Convolutional Neural Network (e.g., **ResNet50**) initialized with ImageNet weights as a fixed feature extractor. The final classification layer will be removed, and **Global Average Pooling** will be applied to the last convolutional block to generate a dense embedding vector (e.g., 2048 dimensions) for each binary leaf image. This adds a "learned" shape representation to the "engineered" features.
2.  **Dimensionality Reduction**: To prevent the high-dimensional image embeddings from overwhelming the 192 tabular features, we will apply **Principal Component Analysis (PCA)** to the extracted image features, retaining components that explain 95% of the variance.
3.  **Feature Fusion**: The reduced image embeddings will be concatenated with the 192 original tabular features to form a single, comprehensive feature vector per sample.
4.  **The Classifier (Preserved)**: The classification head will remain the **Ensemble of Regularized Multinomial Logistic Regression and Linear Discriminant Analysis (LDA)**. We retain this specific combination because previous experiments proved that combining discriminative and generative linear models minimizes log loss effectively in this specific data regime (Cite solution_lesson_node_00009).

## Data
1.  **Tabular Preprocessing**: The 192 margin, shape, and texture features will undergo **Standard Scaling** (Z-score normalization) to ensure they contribute equally to the linear decision boundaries and regularization penalties (Cite solution_lesson_node_00001).
2.  **Image Preprocessing**: The binary leaf images will be resized to the input resolution of the CNN (e.g., 224x224). Since the pre-trained backbone expects RGB input, the single-channel binary masks will be replicated three times to create a pseudo-RGB image. Pixel values will be normalized using standard ImageNet mean and standard deviation.
3.  **Split**: The provided training and validation splits from the metadata will be used to ensure consistent evaluation.

## Training
The training process is a multi-stage pipeline designed to be computationally efficient:
1.  **Feature Extraction**: Pass the entire dataset (train, validation, and test images) through the frozen ResNet50 backbone to generate raw image embeddings. This is done once, avoiding the need for expensive backpropagation through the CNN.
2.  **Projection**: Fit PCA on the training image embeddings and transform the validation/test embeddings.
3.  **Fusion**: Concatenate the PCA-transformed image features with the scaled tabular features.
4.  **Model Fitting**:
    *   **Logistic Regression**: Train on the fused features using L-BFGS optimization. Perform a **Grid Search** for the inverse regularization strength `C` using the validation set to find the optimal bias-variance balance (Cite solution_lesson_node_00001).
    *   **LDA**: Fit a Linear Discriminant Analysis model on the fused features using **Ledoit-Wolf shrinkage** to regularize the covariance matrices, which is critical for stability in high-dimensional spaces (Cite solution_lesson_node_00009).

## Evaluation
1.  Generate prediction probabilities for the test set using both the optimized Logistic Regression model and the LDA model.
2.  Compute the **unweighted average** of the probability vectors from both models.
3.  Apply the required clipping (min/max bounds) and formatting to produce the final submission CSV.
