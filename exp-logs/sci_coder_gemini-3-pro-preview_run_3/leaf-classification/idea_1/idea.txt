# Proposed Baseline Approach: Regularized Multinomial Logistic Regression

## Model
The proposed model is a **Regularized Multinomial Logistic Regression** classifier. Unlike the tree-based (Model 1), kernel-based (Model 3), or deep neural network architectures (Models 2, 4, 5) previously suggested, this approach relies on a linear decision boundary. The architecture consists of a single linear layer that maps the input feature vector directly to 99 output logits (one per species), followed immediately by a Softmax activation function. This design provides a strictly probabilistic interpretation of the features and serves as the most fundamental baseline for minimizing log-loss.

## Data
We will utilize the **192 tabular features** (Margin, Shape, and Texture) exclusively, ignoring the raw image data to maintain simplicity and speed.
1.  **Normalization**: Since the data analysis revealed varying scales (e.g., Shape features have a mean of ~0.0006 while Texture features have a mean of ~0.0156) and high multicollinearity, we will apply **Z-score standardization** (subtracting the mean and dividing by the standard deviation) to all 192 features. This ensures that the regularization penalty is applied uniformly across all predictors.
2.  **Splitting**: The provided metadata files (`train.csv`, `val.csv`) will be used to create training and validation sets.

## Training
The training process focuses on direct optimization of the target metric without complex iterative loops or backpropagation through deep layers.
*   **Objective**: Minimize the **Categorical Cross-Entropy (Log Loss)** augmented with an **L2 Regularization (Ridge)** penalty. The L2 penalty is critical here to handle the 441 highly correlated feature pairs identified in the data analysis, preventing coefficient explosion and overfitting on the small dataset.
*   **Optimization**: We will use a second-order optimization algorithm (such as L-BFGS) which is highly efficient for convex problems like logistic regression and typically converges in seconds on datasets of this size.
*   **Hyperparameter Tuning**: A simple grid search will be performed solely for the regularization strength parameter (C), selected based on the log-loss performance on the validation set.

## Evaluation
To generate predictions for the test set:
1.  The standardized test features are passed through the trained linear model.
2.  The output logits are transformed via the Softmax function to produce a probability distribution over the 99 classes.
3.  These probabilities are formatted into the submission CSV, ensuring they fall within the [0, 1] range.
