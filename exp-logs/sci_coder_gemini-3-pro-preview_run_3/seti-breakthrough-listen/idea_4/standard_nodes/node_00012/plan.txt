This script implements the full training and evaluation pipeline for the Siamese EfficientNet-B0 model.

**Strategy:**
1.  **Setup & Configuration:** Initializes the environment, sets random seeds for reproducibility, and configures the device (GPU).
2.  **Data Loading with Subsampling:** Loads the training metadata. To strictly adhere to the "fast baseline" requirement and time limits, it subsamples the training set to 15,000 samples (stratified by target) before creating the `CadenceDataset` and `DataLoader`. Validation data is loaded in full.
3.  **Model Initialization:** Instantiates the `SiameseEfficientNet` with pretrained ImageNet weights and moves it to the GPU.
4.  **Training Loop:** Runs for a maximum of 12 epochs using `AdamW` optimizer and `CosineAnnealingLR` scheduler. It employs `EarlyStopping` based on validation AUC to prevent overfitting and save the best model.
5.  **Validation & Metric:** Loads the best model checkpoint and performs a final evaluation on the full validation set, printing the required `Final Validation Metric`.
6.  **Failure Analysis:** Iterates through the validation set in inference mode to calculate prediction errors. It extracts basic statistical features (mean, std, max) from the input tensors and computes their correlation with the error magnitude to identify potential causes of failure.
7.  **Submission:** If the final validation AUC exceeds the specified threshold, it generates predictions for the test set (using Test Time Augmentation via horizontal flips) and saves the `submission.csv`.
