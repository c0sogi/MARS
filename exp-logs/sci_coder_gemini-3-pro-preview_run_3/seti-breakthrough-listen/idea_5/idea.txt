Based on the success of the Siamese architecture (Idea 4) and the failure of standard 2D/3D approaches to implicitly learn the comparison logic, I propose a **Siamese Spatial-Fusion Network**. This architecture evolves the previous "Vector-Difference" Siamese approach by performing the comparison in the **spatial feature domain** rather than the global vector domain. This preserves the localization of "needle" signals, allowing the network to detect anomalies that are spatially distinct in the "On" frames compared to the "Off" frames, even if they drift slightly.

# Model
**Architecture: Siamese EfficientNet-B0 with Spatial Feature Fusion**

1.  **Siamese Backbone:** The core feature extractor is an **EfficientNet-B0** initialized with ImageNet weights (Cite `solution_lesson_node_00011`).
    *   **Dual Inputs:** The network accepts two separate input tensors:
        *   **Stream A (Signal):** A 3-channel image constructed by stacking the "On-Target" cadence frames (Indices 0, 2, 4).
        *   **Stream B (Reference):** A 3-channel image constructed by stacking the "Off-Target" cadence frames (Indices 1, 3, 5).
    *   **Shared Weights:** Both streams pass through the *same* backbone instance to ensure they are projected into the same latent feature space. This produces two spatial feature maps, $F_{on}$ and $F_{off}$, typically of shape $(C, H', W')$ (e.g., $1280 \times 7 \times 7$).

2.  **Spatial Fusion Head:**
    *   **Concatenation:** Instead of applying Global Average Pooling (GAP) immediately (which destroys spatial information), we concatenate the raw feature maps along the channel dimension: $F_{fused} = \text{Concat}(F_{on}, F_{off})$.
    *   **Interaction Block:** The fused volume $(2C, H', W')$ is passed through a lightweight convolutional block (e.g., $1 \times 1$ Conv to reduce dimensionality, followed by a $3 \times 3$ Conv). This allows the network to learn **local comparison filters** (e.g., "High activation at $(x,y)$ in Channel $i$ AND Low activation at $(x,y\pm\delta)$ in Channel $j$"). This explicitly addresses the need for flexible, non-linear comparisons (Cite `solution_lesson_node_00002`) while avoiding the information loss of vector-based subtraction.

3.  **Classification:** The output of the interaction block is processed via Global Average Pooling and a final Linear layer to predict the binary target.

# Data
**Preprocessing & Augmentation**
1.  **Input Construction:** For each cadence, separate the 6 observations into "On" and "Off" sets. Stack each set to form two 3-channel arrays. This leverages **Channel Stacking** to align temporal features (Cite `solution_lesson_node_00003`).
2.  **Resizing:** Resize both arrays to `(224, 224)`. As established, this moderate downsampling acts as a beneficial low-pass filter for low-SNR signals and enables the use of standard pretrained backbones (Cite `solution_lesson_node_00006`, `solution_lesson_node_00014`).
3.  **Synchronized Augmentation:** Apply **Horizontal Flip** (Time Reversal) and **Vertical Flip** (Frequency Inversion) (Cite `solution_lesson_node_00014`). Crucially, these must be applied **identically** to both the "On" and "Off" streams for a given sample to maintain the pixel-wise correspondence required for the Siamese comparison. We will use the augmentation library's dual-target functionality (e.g., `additional_targets`) to prevent "Shadowed Pipelines" (Cite `solution_lesson_node_00015`).

# Training
*   **Loss Function:** `BCEWithLogitsLoss`.
*   **Optimizer:** `AdamW` with learning rate `1e-3` and weight decay `1e-2`.
*   **Regularization:** **Mixup** ($\alpha=0.2$) will be applied to the inputs. This is critical for preventing the model from memorizing noise patterns in the small dataset (Cite `solution_lesson_node_00011`).
*   **Scheduler:** `CosineAnnealingLR` (T_max=10 epochs).

# Evaluation
*   **Inference:** Pass the test set "On" and "Off" stacks through the Siamese Spatial-Fusion model.
*   **Test Time Augmentation (TTA):** Perform inference on the original inputs, as well as Horizontally and Vertically flipped versions (applied synchronously to both streams). Average the probabilities. This exploits the geometric invariance of the spectrograms to improve robustness (Cite `solution_lesson_node_00014`).
