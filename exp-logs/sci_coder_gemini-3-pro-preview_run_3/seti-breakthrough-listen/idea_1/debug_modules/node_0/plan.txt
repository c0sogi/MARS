The following script demonstrates the usage of the provided library files for the SETI technosignature detection task. It performs the following steps:

1.  **Dataset Verification**: Instantiates the `SETIDataset` class using the provided metadata and verifies that the output tensors (spectrograms and targets) have the correct shapes and data types.
2.  **Model Verification**: Instantiates the `BaselineCNN` model, performs a forward pass with dummy data, and asserts that the output dimensions match the expected binary classification logits.
3.  **Training Pipeline**: Executes the `run_training` function from the engine with reduced hyperparameters (1 epoch, debug mode, small sample size) to demonstrate the training loop and model saving mechanism quickly.
4.  **Inference Pipeline**: Executes the `generate_submission` function to demonstrate how predictions are generated and saved to a CSV file.
