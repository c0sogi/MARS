The strategy involves initializing the environment and configuration, loading the datasets using the provided library, and training the `Shallow3DCNN` model for a limited number of epochs (5) to ensure a fast baseline. We will use the `AdamW` optimizer and `CosineAnnealingLR` scheduler. After training, the best model (based on validation AUC) is re-loaded to perform a detailed validation inference. During this inference, we calculate the final AUC and extract image statistics (mean, std, max, on-off difference) to compute their correlation with the prediction error for failure analysis. Finally, if the validation AUC exceeds the specified threshold, we generate predictions on the test set using Test Time Augmentation (TTA) and save the submission file.
