The issue arises because `predict_and_submit` in `library/engine.py` loads the full test metadata from `Config.TEST_CSV` (6000 rows), while the `test_loader` in debug mode operates on a subsampled dataset (50 rows). This discrepancy causes a `ValueError` when trying to assign the 50 predictions to the 6000-row DataFrame. The fix is to retrieve the DataFrame directly from `test_loader.dataset.df`, which guarantees that the metadata (IDs) matches the data used for inference, regardless of whether debug sampling is active.
