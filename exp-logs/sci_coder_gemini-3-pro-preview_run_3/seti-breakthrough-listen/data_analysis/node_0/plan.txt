The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup and Data Loading**: Initialize the environment, set random seeds for reproducibility, and load the training metadata from `./metadata/train.csv`. This ensures we only analyze the training split to prevent data leakage.
2.  **Target Variable Analysis**: Analyze the `target` column to report the distribution of classes (0 vs 1) and calculate the class balance ratio to identify any imbalance.
3.  **Input Data Analysis (Spectrograms)**:
    *   Treat the `.npy` files as 6-channel image data (corresponding to the 6 cadence positions).
    *   Sample a subset of the training data (e.g., 2,000 files) to keep the runtime efficient.
    *   Iterate through the sample to verify dimensions (Shape: 6 x 273 x 256).
    *   Calculate global pixel statistics (Mean, Standard Deviation, Min, Max) by accumulating sums and squared sums.
4.  **Feature/Signal Relationships**:
    *   **Feature Engineering**: Extract statistical meta-features from the sampled spectrograms. Specifically, calculate the mean and standard deviation for "On-Target" panels (indices 0, 2, 4) versus "Off-Target" panels (indices 1, 3, 5). Calculate the contrast (On - Off).
    *   **Correlation**: Check the correlation between these extracted signal statistics and the target variable.
    *   **Importance**: Train a lightweight Random Forest Classifier using these meta-features to predict the target. Report the top 5 most important features to understand if simple statistical properties can distinguish the "needles" from the haystack.
5.  **Reporting**: Output the results in the specified format with distinct capitalized sections and 4-decimal precision.
