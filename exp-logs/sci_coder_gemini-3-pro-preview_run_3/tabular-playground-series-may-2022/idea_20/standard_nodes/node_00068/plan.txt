Implementation Strategy:
1.  **Environment Setup**: Initialize the environment with a fixed seed and detect the computation device (GPU/CPU).
2.  **Configuration Override**: Modify `Config` parameters to satisfy the "fast baseline" requirement (reducing epochs to 10) and set the correct submission path (`./submission/submission.csv`).
3.  **Data Loading**: Leverage the provided `get_dataloaders` function with caching enabled to load the preprocessed manufacturing data efficiently.
4.  **Model Initialization**: Instantiate the `SDPEModel` (Structurally Diverse Parallel Ensemble) using the vocabulary sizes and continuous feature counts derived from the data loader.
5.  **Training Loop**: Implement a standard training loop using the Adam optimizer and OneCycleLR scheduler. The loop includes epoch-wise training, validation, and model checkpointing based on AUC score.
6.  **Final Evaluation**: Load the best-performing model weights and compute the final validation AUC on the full validation set.
7.  **Failure Analysis**: specific function to analyze the correlation between prediction error magnitude and input continuous features on the validation set, identifying potential weak points.
8.  **Conditional Submission**: Check if the final validation AUC exceeds the strict threshold (0.9975746465492954). If successful, generate predictions for the test set and save them to the specified submission file.
