# Proposed Strategy: Layer-Normalized Funnel MLP with Token Dropout

## Model
We will implement a **Layer-Normalized Funnel MLP**. This architecture introduces two structural innovations to the standard MLP backbone: (1) **Token Dropout** at the embedding layer to enforce distributed representation learning, and (2) **Layer Normalization** within the dense blocks to stabilize optimization without the batch-dependency of BatchNorm.

1.  **Input & Embedding Layer:**
    *   **Categorical Inputs:** The 10 decomposed character positions of `f_27` (Cite solution_lesson_node_00001) and the discrete features `f_29`, `f_30` (Cite solution_lesson_node_00008).
    *   **Compact Embeddings:** All categorical features will be mapped to **Entity Embeddings of dimension 16**. This dimension strikes the optimal balance, avoiding the signal bottleneck of dimension 8 (Cite solution_lesson_node_00018) and the noise/overhead of dimension 32 (Cite solution_lesson_node_00027).
    *   **Token Dropout (Innovation):** Before flattening, we will apply **Token Dropout** (also known as Embedding Dropout) to the sequence of 10 character embeddings from `f_27`. This mechanism randomly zeros out the *entire* embedding vector for specific character positions with a low probability (e.g., 0.1) during training. This forces the model to learn robust, distributed representations of the machine state, preventing it from over-relying on any single character position (addressing the specific feature correlations seen in failure analyses, Cite solution_lesson_node_00021).

2.  **Early Fusion:**
    *   The processed embeddings are flattened and concatenated with the normalized continuous features (`f_00`–`f_28` and `unique_character_count`). We strictly utilize **Early Fusion**, avoiding the performance degradation observed with dual-stream architectures (Cite solution_lesson_node_00029).

3.  **Layer-Normalized Funnel Backbone:**
    *   **Topology:** We retain the **Funnel** structure (decreasing layer widths: 512 $\to$ 256 $\to$ 128) as it provides the compressive inductive bias superior to ResNets for this dataset (Cite solution_lesson_node_00004).
    *   **Block Architecture (Innovation):** Instead of the standard `Linear -> ReLU -> Dropout` or the unstable `GLU` blocks, we will use a **`Linear -> LayerNorm -> ReLU -> Dropout`** block structure.
        *   **LayerNorm:** We insert Layer Normalization before the activation. This stabilizes the gradient flow and inputs to the ReLU, enabling the model to benefit from the "Super-Convergence" schedule without the overfitting risks of GLUs (Cite solution_lesson_node_00019) or the performance degradation caused by BatchNorm on this specific data (Cite solution_lesson_node_00018).
    *   **Head:** The final 128-unit representation connects directly to the output neuron, explicitly avoiding tapering to narrower layers (e.g., 64) to prevent information bottlenecks (Cite solution_lesson_node_00020).

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures that every unique token in the test set is assigned a distinct embedding index, preventing the signal loss caused by mapping unseen test tokens to "unknown" (Cite solution_lesson_node_00021).
2.  **String Decomposition:** `f_27` will be split into 10 fixed-position character columns (Cite solution_lesson_node_00001). We explicitly avoid N-gram expansion to prevent noise (Cite solution_lesson_node_00035).
3.  **Feature Engineering:** We will compute and append the `unique_character_count` of `f_27` as a normalized continuous feature (Cite solution_lesson_node_00002).
4.  **Normalization:** All continuous features will be scaled using **StandardScaler**.
5.  **Data Volume:** We will utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is precisely calibrated to facilitate super-convergence while maintaining generalization:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-5**. We explicitly avoid the default `1e-2`, which was proven too aggressive for this tabular task (Cite solution_lesson_node_00023).
2.  **Scheduler:** **One-Cycle Learning Rate Policy**. We retain this schedule (max LR ~1e-2) to facilitate super-convergence and robust minima selection (Cite solution_lesson_node_00002).
3.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise, avoiding the generalization gap observed with larger batches (Cite solution_lesson_node_00024).
4.  **Loss Function:** Binary Cross-Entropy.
5.  **Strategy:** Direct Supervised Learning. We avoid autoencoder pretraining as it provides no benefit for this high-signal dataset (Cite solution_lesson_node_00013).

## Evaluation
1.  **Preprocessing:** The test set will be processed using the global (transductive) vocabulary mappings and training set scalers.
2.  **Inference:** The trained Layer-Normalized Funnel MLP will predict probabilities for the target class `1`.
3.  **Submission:** The resulting probabilities will be formatted into the submission CSV for AUC evaluation.
