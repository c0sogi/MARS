Here is the implementation of the orchestration script `runfile.py`.

The strategy employed is as follows:
1.  **Fast Baseline Configuration**: We override the default epoch count from 50 to 20. This utilizes the A100 GPU's speed to train on the full dataset efficiently (approx. 5-10 minutes) while ensuring enough convergence to potentially meet the high validation threshold.
2.  **Data Pipeline**: We utilize the `get_data` function with caching enabled to quickly load the preprocessed training, validation, and test sets. These are wrapped in the provided `ManufacturingDataset` class and loaded via pinned-memory DataLoaders.
3.  **Model Training**: We initialize the `SRPFEModel` (Selective-Residual Parallel Funnel Ensemble) and train it using the `train_model` engine. This handles the optimization, scheduling, and saving of the best model based on validation AUC.
4.  **Validation & Failure Analysis**: Post-training, we reload the best model state and perform a full inference pass on the validation set. We calculate the final AUC and compute the Pearson correlation between the absolute prediction error and input features to identify sources of model failure.
5.  **Conditional Submission**: We strictly compare the final validation AUC against the required threshold (`0.9975746465492954`). Only if this threshold is exceeded do we generate predictions for the test set and save the `submission.csv`.
