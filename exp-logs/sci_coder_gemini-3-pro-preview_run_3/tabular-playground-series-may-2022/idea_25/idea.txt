# Proposed Strategy: Multi-Objective Regularized Parallel Ensemble (MORPE)

## Model
We will implement a **Multi-Objective Regularized Parallel Ensemble (MORPE)**. This architecture evolves the "Parallel Independent Funnel Ensemble" (Cite solution_lesson_node_00064) by introducing **Regularization Heterogeneity** not just in Dropout (as in previous attempts), but explicitly in **Weight Decay** across the streams. This structural innovation ensures that the ensemble members are forced to navigate the loss landscape under different constraints, maximizing the decorrelation of their errors (Cite solution_lesson_node_00066).

1.  **Parallel Independent Architecture:**
    *   The model will consist of **5 independent streams** instantiated within a single computational graph.
    *   **Independent Representation:** Each stream will possess its own **independent Entity Embedding layers**. We explicitly reject shared embeddings to ensure that each stream learns a unique representation of the categorical manifold (Cite solution_lesson_node_00065).
    *   **Input Fusion:** Early Fusion (concatenation) of embeddings and normalized continuous features (Cite solution_lesson_node_00029).

2.  **Backbone Topology (The Funnel):**
    *   All streams utilize the **Funnel MLP** structure (decreasing layer widths) to leverage its compressive inductive bias (Cite solution_lesson_node_00004).
    *   **Bottleneck Avoidance:** The final hidden layer will remain at width 128, avoiding tapering to 64 units (Cite solution_lesson_node_00020).
    *   **Activation:** Standard **ReLU** exclusively (Cite solution_lesson_node_00041).
    *   **Exclusions:** No Layer Normalization (Cite solution_lesson_node_00039), No Input Noise (Cite solution_lesson_node_00053).

3.  **The Multi-Regularized Configuration:**
    *   **Streams 1 & 2 (Anchors):** Standard Funnel (512 $\to$ 256 $\to$ 128). **Dropout 0.20**. **Weight Decay 1e-4**. These provide the robust baseline.
    *   **Stream 3 (Capacity Variant):** **Wide Funnel** (1024 $\to$ 512 $\to$ 256). **Dropout 0.25**. **Weight Decay 1e-4**. Captures subtler patterns via increased width (Cite solution_lesson_node_00066).
    *   **Stream 4 (Constraint Variant):** Standard Funnel. **Dropout 0.15** (Safety Floor, Cite solution_lesson_node_00077). **Weight Decay 1e-3**. Here, we lower dropout but increase weight decay, forcing the model to rely on L2 constraints rather than stochastic masking.
    *   **Stream 5 (Stochastic Variant):** Standard Funnel. **Dropout 0.30**. **Weight Decay 1e-5**. Here, we increase dropout but relax weight decay, forcing the model to rely on redundancy.

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures every unique token in the test set is assigned a distinct embedding index (Cite solution_lesson_node_00021).
2.  **Feature Engineering:**
    *   **String Decomposition:** Decompose `f_27` into 10 fixed-position character columns (Cite solution_lesson_node_00001). Avoid N-grams (Cite solution_lesson_node_00035).
    *   **Discrete Features:** Treat `f_29` and `f_30` as categorical variables (Cite solution_lesson_node_00008).
    *   **Aggregate Signal:** Compute and append `unique_character_count` of `f_27` (Cite solution_lesson_node_00002).
3.  **Embedding Capacity:** Set dimension to **16** for all categorical variables (Cite solution_lesson_node_00018, solution_lesson_node_00027).
4.  **Normalization:** Scale all continuous features using **StandardScaler**.
5.  **Data Volume:** Utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is precisely calibrated to facilitate super-convergence while respecting the specific sensitivities of tabular optimizers:

1.  **Optimizer:** **AdamW** with **Per-Parameter Group Weight Decay**. We will configure the optimizer to apply the specific weight decay values defined above to the parameters of the corresponding streams. This leverages AdamW's decoupled decay for stable convergence (Cite solution_lesson_node_00079).
2.  **Scheduler:** **One-Cycle Learning Rate Policy** with `max_lr=1e-2`. We explicitly maintain the high learning rate magnitude to ensure the model can escape local minima (Cite solution_lesson_node_00072).
3.  **Loss Function:** The training objective is the **sum of Binary Cross-Entropy losses** calculated independently for each of the 5 streams.
4.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise (Cite solution_lesson_node_00024).
5.  **Duration:** Train for **50 Epochs**. We explicitly avoid premature truncation to allow the highly regularized streams to fully converge (Cite solution_lesson_node_00080).

## Evaluation
1.  **Preprocessing:** Apply the global (transductive) vocabulary mappings and training set scalers to the test set.
2.  **Inference:** The MORPE model will generate 5 independent probability predictions per sample.
3.  **Submission:** The final prediction will be the **arithmetic mean** of these 5 probabilities.
