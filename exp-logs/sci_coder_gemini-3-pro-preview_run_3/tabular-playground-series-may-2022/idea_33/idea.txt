# Proposed Strategy: Continuous-Residual Heterogeneous Parallel Ensemble (CR-HPE)

## Model
We will implement a **Continuous-Residual Heterogeneous Parallel Ensemble (CR-HPE)**. This architecture introduces a structural innovation by refining the "Wide-and-Deep" concept. Unlike previous attempts that passed *all* features to the linear skip connection (which failed due to embedding noise, Cite solution_lesson_node_00087), we will implement a **Modality-Specific Residual**. We will add a linear skip connection exclusively for the **continuous features**, allowing the model to trivially capture linear sensor trends while forcing the MLP backbone to focus on complex categorical interactions and residuals.

1.  **Parallel Independent Architecture:**
    *   The model will consist of **5 independent streams** instantiated within a single computational graph (Cite solution_lesson_node_00064).
    *   **Independent Representation:** Each stream will possess its own **independent Entity Embedding layers** (Dim 16) for the categorical features. We explicitly reject shared embeddings to ensure decorrelated representation learning (Cite solution_lesson_node_00065).
    *   **Input Fusion:** Each stream will independently flatten its embeddings and concatenate them with the normalized continuous features (**Early Fusion**) (Cite solution_lesson_node_00029).

2.  **Stream Topology (The Innovation):**
    *   Each stream will implement a **Continuous-Residual** topology:
        *   **Deep Path (The Funnel):** The fused input (Embeddings + Continuous) is processed by a **Funnel MLP** (decreasing layer widths) to leverage its compressive inductive bias (Cite solution_lesson_node_00004).
        *   **Linear Path (The Continuous Skip):** The **Continuous Features Only** (excluding embeddings) are projected via a single **Linear Layer** directly to the output node.
        *   **Rationale:** This explicitly models the dataset as $y = W_{cont}x_{cont} + MLP(x_{cont}, x_{cat})$. It resolves the "underfitting of continuous features" observed in previous regularized models (Cite solution_lesson_node_00096) without introducing the sparsity noise of categorical embeddings into the linear term (Cite solution_lesson_node_00087).
        *   **Aggregation:** The final logit is the sum of the Deep Path output and the Linear Path output.

3.  **Heterogeneous Configuration:**
    *   We employ **Regularization Heterogeneity** (Cite solution_lesson_node_00069) and **Capacity Heterogeneity** (Cite solution_lesson_node_00066) while respecting the **Safety Floor** (Cite solution_lesson_node_00077).
    *   **Streams 1, 2, 3 (Anchors):** Standard Funnel (512 $\to$ 256 $\to$ 128). Dropout **0.20**.
    *   **Streams 4, 5 (Capacity Variants):** **Wide Funnel** (1024 $\to$ 512 $\to$ 256). Dropout **0.25**.
    *   **Activation:** Standard **ReLU** exclusively (Cite solution_lesson_node_00041).
    *   **Exclusions:** No Layer Normalization (Cite solution_lesson_node_00039), No Input Noise (Cite solution_lesson_node_00053).

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and explicitly includes the critical set-operation feature:

1.  **Feature Engineering:**
    *   **Set Cardinality:** Explicitly compute and append the `unique_character_count` of `f_27`. This corrects the regression observed when this feature was omitted (Cite solution_lesson_node_00103).
    *   **String Decomposition:** Decompose `f_27` into 10 fixed-position character columns (Cite solution_lesson_node_00001).
    *   **Discrete Features:** Treat `f_29` and `f_30` as categorical variables (Cite solution_lesson_node_00008).
    *   **Exclusions:** No Frequency Encoding (Cite solution_lesson_node_00101), No N-grams (Cite solution_lesson_node_00035).
2.  **Transductive Vocabulary Alignment:** Fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets** (Cite solution_lesson_node_00021).
3.  **Normalization:** Scale all continuous features using **StandardScaler**.
4.  **Data Volume:** Utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is calibrated to balance super-convergence with the specific sensitivities of AdamW, addressing previous tuning conflicts:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **2e-5**.
    *   *Rationale:* Previous experiments showed `1e-5` (Adam baseline) was slightly prone to categorical errors, while `1e-4` (AdamW) caused underfitting on continuous features (Cite solution_lesson_node_00096). We select **2e-5** as the optimal midpoint to regularize the decoupled decay without suppressing the continuous manifold.
2.  **Scheduler:** **One-Cycle Learning Rate Policy** with `max_lr=1e-2`. We explicitly maintain the high learning rate magnitude to ensure the model can escape local minima (Cite solution_lesson_node_00072).
3.  **Loss Function:** The training objective is the **sum of Binary Cross-Entropy losses** calculated independently for each of the 5 streams.
4.  **Batch Size:** **1024** (Cite solution_lesson_node_00024).
5.  **Duration:** Train for **50 Epochs**. We explicitly avoid premature truncation to allow the high-capacity streams to fully converge (Cite solution_lesson_node_00080).

## Evaluation
1.  **Preprocessing:** Apply the global (transductive) vocabulary mappings and training set scalers to the test set.
2.  **Inference:** The CR-HPE model will generate 5 independent probability predictions per sample.
3.  **Submission:** The final prediction will be the **arithmetic mean** of these 5 probabilities.
