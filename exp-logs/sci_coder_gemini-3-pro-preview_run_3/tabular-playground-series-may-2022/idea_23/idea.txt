# Proposed Strategy: Anchor-Variant Parallel Funnel Ensemble (AV-PFE)

## Model
We will implement an **Anchor-Variant Parallel Funnel Ensemble (AV-PFE)**. This architecture synthesizes the variance-reduction benefits of **Parallel In-Network Ensembling** (Cite solution_lesson_node_00064) with the robustness of **Regularization Heterogeneity** (Cite solution_lesson_node_00069), while strictly avoiding the pitfalls of structural complexity (e.g., deep networks or exotic activations) identified in recent failures.

1.  **Parallel Independent Architecture:**
    *   The model will consist of **5 independent streams** instantiated within a single computational graph.
    *   **Independent Representation:** Crucially, each stream will possess its own **independent Entity Embedding layers**. We explicitly reject shared embeddings to ensure that each stream learns a unique, decorrelated representation of the categorical manifold (Cite solution_lesson_node_00065).
    *   **Input Fusion:** Each stream will independently flatten its embeddings and concatenate them with the normalized continuous features (**Early Fusion**) to preserve cross-modal signal fidelity (Cite solution_lesson_node_00029).

2.  **Backbone Topology (The Funnel):**
    *   All streams will utilize the **Funnel MLP** structure (decreasing layer widths: 512 $\to$ 256 $\to$ 128). This provides the compressive inductive bias that has consistently outperformed ResNets (Cite solution_lesson_node_00004) and Transformers (Cite solution_lesson_node_00025).
    *   **Shallow Depth:** We strictly limit the depth to 3 hidden layers. We explicitly exclude deeper streams (e.g., 4+ layers) as they have been shown to induce overfitting without improving generalization in this ensemble context (Cite solution_lesson_node_00071).
    *   **Bottleneck Avoidance:** The final hidden layer will remain at width 128 before projecting to the output, avoiding the information loss associated with tapering to 64 units (Cite solution_lesson_node_00020).
    *   **Activation:** Standard **ReLU** exclusively. We avoid Swish/SELU/GLU as they add complexity without performance gain (Cite solution_lesson_node_00041, solution_lesson_node_00047).
    *   **Exclusions:** No Layer Normalization (Cite solution_lesson_node_00039), No Input Noise (Cite solution_lesson_node_00053).

3.  **The Anchor-Variant Configuration:**
    *   **Streams 1 & 2 (Anchors):** Standard Funnel (Dropout **0.20**). These provide the robust, proven baseline performance.
    *   **Stream 3 (Capacity Variant):** **Wide Funnel** (1024 $\to$ 512 $\to$ 256, Dropout **0.25**). This stream utilizes increased width to capture subtler high-frequency patterns (Cite solution_lesson_node_00066).
    *   **Stream 4 (Aggressive Variant):** Standard Funnel (Dropout **0.10**). This low-regularization stream aggressively fits the training data.
    *   **Stream 5 (Conservative Variant):** Standard Funnel (Dropout **0.30**). This high-regularization stream acts as a stabilizer (Cite solution_lesson_node_00069).

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures every unique token in the test set is assigned a distinct embedding index, preventing the signal loss caused by mapping unseen test tokens to "unknown" (Cite solution_lesson_node_00021).
2.  **Feature Engineering:**
    *   **String Decomposition:** Decompose `f_27` into 10 fixed-position character columns (Cite solution_lesson_node_00001). We explicitly avoid N-gram expansion to prevent noise (Cite solution_lesson_node_00035).
    *   **Discrete Features:** Treat `f_29` and `f_30` as categorical variables for embedding (Cite solution_lesson_node_00008).
    *   **Aggregate Signal:** Compute and append the `unique_character_count` of `f_27` as a normalized continuous feature (Cite solution_lesson_node_00002).
3.  **Embedding Capacity:** Set the embedding dimension to **16** for all categorical variables. This is the optimal "sweet spot" between the bottleneck of dimension 8 (Cite solution_lesson_node_00018) and the noise of dimension 32 (Cite solution_lesson_node_00027).
4.  **Normalization:** Scale all continuous features using **StandardScaler**.
5.  **Data Volume:** Utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is precisely calibrated to facilitate super-convergence while respecting the specific sensitivities of tabular optimizers:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-4**. We increase the decay from the Adam baseline (`1e-5`) to account for AdamW's decoupled implementation (Cite solution_lesson_node_00063) but strictly avoid the default `1e-2` which is too aggressive (Cite solution_lesson_node_00023).
2.  **Scheduler:** **One-Cycle Learning Rate Policy** with `max_lr=1e-2`. We explicitly maintain the high learning rate magnitude to ensure the model can escape local minima, correcting previous failures caused by reducing it (Cite solution_lesson_node_00072).
3.  **Loss Function:** The training objective is the **sum of Binary Cross-Entropy losses** calculated independently for each of the 5 streams.
4.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise (Cite solution_lesson_node_00024).
5.  **Duration:** Train for **50 Epochs** to allow the heterogeneous streams (especially the high-capacity one) to fully converge (Cite solution_lesson_node_00066).

## Evaluation
1.  **Preprocessing:** Apply the global (transductive) vocabulary mappings and training set scalers to the test set.
2.  **Inference:** The AV-PFE model will generate 5 independent probability predictions per sample.
3.  **Submission:** The final prediction will be the **arithmetic mean** of these 5 probabilities.
