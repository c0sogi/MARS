1.  **Configuration Override**: Import the `Config` class and override key parameters to ensure the script runs quickly and within the provided environment. This includes setting `DEBUG=True`, reducing `EPOCHS` to 1, and redirecting output paths to a dedicated `./working/demo_execution` directory to avoid conflicts with existing caches.
2.  **Data Processing**: Explicitly call `prepare_data` with `load_cached_data=False` to force the creation of a small, debug-sized dataset (2000 samples). Verify the integrity of the resulting DataLoaders and vocabulary sizes using assertions.
3.  **Model Instantiation**: Instantiate the `AVPFEModel` using the dimensions derived from the data. Perform a dummy forward pass with a single batch to verify that the model architecture produces the expected output shape (Batch Size, 5 Streams).
4.  **Training Loop**: Execute a single epoch of training using `train_one_epoch` and evaluate using `validate`. This demonstrates the training pipeline without waiting for full convergence. Assert that loss values are valid and AUC scores are within range.
5.  **Inference & Submission**: Save the trained model state to disk, then invoke `generate_submission`. Verify that the submission file is generated correctly and matches the expected dimensions of the debug dataset.
