### Implementation Strategy

2.  **Data Preparation (Optimized)**: Instead of loading the full dataset (which is large), manually load a small subset (e.g., 2000 rows) of the training, validation, and test data from the `./metadata` directory. This satisfies the "Optimize for Speed" requirement.
3.  **Preprocessing Demonstration**: Instantiate the `ManufacturingPreprocessor` from `library.preprocessing`. Fit it on the sampled data and transform the datasets. Verify that the resulting dataframes contain the expected engineered features and correct data types.
4.  **Dataset and DataLoader**: Create instances of `ManufacturingDataset` from `library.dataset` using the processed dataframes. Verify the integrity of a single sample (keys, shapes, types) retrieved from the dataset. Wrap these in PyTorch DataLoaders.
5.  **Model Initialization**: Instantiate the `IAPEModel` from `library.model` using the configuration derived from the preprocessor (continuous columns, categorical cardinalities) and the `STREAM_CONFIGS` from `library.config`. Perform a dummy forward pass to assert the output shape is `[batch_size, num_streams]`.
6.  **Training Loop Execution**: Configure the optimizer, scheduler, and loss function. Use `library.engine.train_model` to train the model for a minimal number of epochs (e.g., 2) on the CPU (or GPU if available) to demonstrate the training pipeline without long wait times.
7.  **Inference and Submission**: Use `library.engine.generate_submission` to generate predictions for the test set. Verify that the output CSV file is created, follows the correct format, and contains the expected number of rows.
