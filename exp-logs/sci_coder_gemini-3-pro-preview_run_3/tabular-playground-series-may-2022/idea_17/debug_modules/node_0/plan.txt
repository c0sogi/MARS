Implementation Strategy:
1.  **Configuration Override**: Import the `Config` class from `library.config` and modify runtime parameters (epochs, directories) to ensure a fast execution (1 epoch) and isolation of outputs (using a `demo_execution` directory).
2.  **Data Loading & Subsetting**: Use `get_preprocessed_data` from `library.preprocessing` to load the dataset. To satisfy the "Optimize for Speed" requirement, slice the resulting numpy arrays to create a small subset (e.g., 2000 samples) for training, validation, and testing.
3.  **Dataset Creation**: Instantiate `ManufacturingDataset` from `library.dataset` using the subsetted data. Wrap these in PyTorch `DataLoader`s.
4.  **Model Training**: Invoke `train_model` from `library.engine`. This function handles model instantiation, the training loop, validation, and saving the best model.
5.  **Inference**: Call `generate_submission` from `library.engine` to create predictions on the test subset and save the CSV.
6.  **Verification**: Perform assertions to ensure the model output shape is correct, the loss decreases (or is valid), and the submission file follows the required format and schema.
