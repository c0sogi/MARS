The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup and Loading**: Initialize the environment, suppress warnings, and set random seeds for reproducibility. Load the training data from `./metadata/train.csv`.
2.  **Modality Detection**: Heuristically determine the data modality. Given the problem description (manufacturing control data), the script will primarily identify and process it as **Tabular** data, distinguishing between numerical and categorical columns.
3.  **Target Analysis**: Analyze the `target` column to determine if the task is classification or regression. Calculate distributions, class balance, or skewness/kurtosis accordingly.
4.  **Tabular Data Analysis**:
    *   **Numerical**: Compute descriptive statistics (mean, std, min, max) and detect outliers using the Interquartile Range (IQR) method.
    *   **Categorical**: Analyze cardinality and identify columns with high cardinality or rare labels.
    *   **Missing Values**: Report the prevalence of missing data.
5.  **Feature Relationships**:
    *   **Correlation**: Calculate Pearson correlations to identify collinear features (redundancy > 0.90).
    *   **Feature Importance**: Train a lightweight Random Forest model (on a subset of data to ensure speed) to identify the top 5 most predictive features.
6.  **Formatting**: Ensure all outputs are printed in distinct, capitalized sections with floating-point numbers formatted to 4 decimal places.
