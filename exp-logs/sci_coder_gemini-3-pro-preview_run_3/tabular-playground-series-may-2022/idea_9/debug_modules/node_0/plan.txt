This script demonstrates the usage of the provided machine learning library for the manufacturing control task. It performs the following steps:

1.  **Configuration Setup**: Overrides default configuration parameters to create a lightweight execution environment (fewer epochs, smaller dataset subset) suitable for a quick demonstration.
2.  **Data Pipeline Verification**: Uses `get_data_loaders` to load and preprocess data, asserting that the resulting DataLoaders and metadata (vocabulary sizes, continuous dimensions) are correct.
3.  **Model Architecture Verification**: Instantiates the `InputInjectedFunnelMLP` model and performs a dummy forward pass to verify input/output shapes and tensor handling.
4.  **Full Training Cycle**: Executes `run_training` to simulate a complete training run, including training, validation, early stopping, and inference.
5.  **Output Validation**: Checks for the existence and validity of the generated model checkpoint and submission file.
