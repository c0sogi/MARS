# Proposed Strategy: Hybrid-Capacity Parallel Funnel Ensemble (HC-PFE)

## Model
We will implement a **Hybrid-Capacity Parallel Funnel Ensemble (HC-PFE)**. This architecture represents a structural evolution of the "Heterogeneous Parallel Funnel Ensemble" (Cite solution_lesson_node_00066). It explicitly synthesizes the variance-reduction of parallel ensembling with **Capacity Heterogeneity** and **Optimizer-Aligned Regularization**, while strictly adhering to the "Safety Floor" to prevent the overfitting observed in previous aggressive attempts.

1.  **Parallel Independent Architecture:**
    *   The model will consist of **5 independent streams** instantiated within a single computational graph (Cite solution_lesson_node_00064).
    *   **Independent Representation:** Each stream will possess its own **independent Entity Embedding layers**. We explicitly reject shared embeddings to ensure that each stream learns a unique, decorrelated representation of the categorical manifold (Cite solution_lesson_node_00065).
    *   **Input Fusion:** Each stream will independently flatten its embeddings and concatenate them with the normalized continuous features (**Early Fusion**) (Cite solution_lesson_node_00029).

2.  **Structural Diversity (The Hybrid Backbone):**
    *   Instead of a uniform backbone or structurally complex blocks (which failed in Cite solution_lesson_node_00069), we will introduce diversity through **Network Width (Capacity)**.
    *   **Streams 1, 2, & 3 (Standard Anchors):** Utilize the proven **Standard Funnel MLP** topology (512 $\to$ 256 $\to$ 128). These provide the robust baseline performance (Cite solution_lesson_node_00004).
    *   **Streams 4 & 5 (High-Capacity Variants):** Utilize a **Wide Funnel MLP** topology (1024 $\to$ 512 $\to$ 256). These streams possess significantly larger hypothesis spaces, allowing them to capture subtler, high-frequency patterns that the standard streams might underfit (Cite solution_lesson_node_00066).
    *   **Bottleneck Avoidance:** All streams terminate at a width $\ge$ 128, explicitly avoiding tapering to 64 units to prevent information bottlenecks (Cite solution_lesson_node_00020).
    *   **Activation:** Standard **ReLU** exclusively (Cite solution_lesson_node_00041).

3.  **Regularization Configuration:**
    *   We employ **Regularization Heterogeneity** but strictly enforce the **Safety Floor** (Cite solution_lesson_node_00077).
    *   **Dropout Rates:** We will vary dropout across the streams within the safe range of **0.20 to 0.30**. We explicitly exclude rates below 0.15 to prevent the overfitting observed in "aggressive" streams.
    *   **Exclusions:** No Layer Normalization (Cite solution_lesson_node_00039), No Batch Normalization (Cite solution_lesson_node_00091), No Input Noise (Cite solution_lesson_node_00053).

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures every unique token in the test set is assigned a distinct embedding index (Cite solution_lesson_node_00021).
2.  **Feature Engineering:**
    *   **String Decomposition:** Decompose `f_27` into 10 fixed-position character columns (Cite solution_lesson_node_00001). Avoid N-grams (Cite solution_lesson_node_00035).
    *   **Discrete Features:** Treat `f_29` and `f_30` as categorical variables (Cite solution_lesson_node_00008).
    *   **Aggregate Signal:** Compute and append the `unique_character_count` of `f_27` (Cite solution_lesson_node_00002).
3.  **Embedding Capacity:** Set the embedding dimension to **16** for all categorical variables (Cite solution_lesson_node_00027).
4.  **Normalization:** Scale all continuous features using **StandardScaler**.
5.  **Data Volume:** Utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is precisely calibrated to facilitate super-convergence using the superior AdamW optimizer, correcting previous tuning missteps:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-4**. We switch to AdamW for its superior convergence properties (Cite solution_lesson_node_00079) and use `1e-4` to account for its decoupled implementation (Cite solution_lesson_node_00063), avoiding the aggressive `1e-2` (Cite solution_lesson_node_00023).
2.  **Scheduler:** **One-Cycle Learning Rate Policy** with `max_lr=1e-2`. We explicitly maintain the high learning rate magnitude to ensure the model can escape local minima (Cite solution_lesson_node_00072).
3.  **Loss Function:** The training objective is the **sum of Binary Cross-Entropy losses** calculated independently for each of the 5 streams.
4.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise (Cite solution_lesson_node_00024).
5.  **Duration:** Train for **50 Epochs**. We explicitly avoid premature truncation to allow the high-capacity and highly-regularized streams to fully converge (Cite solution_lesson_node_00080).

## Evaluation
1.  **Preprocessing:** Apply the global (transductive) vocabulary mappings and training set scalers to the test set.
2.  **Inference:** The HC-PFE model will generate 5 independent probability predictions per sample.
3.  **Submission:** The final prediction will be the **arithmetic mean** of these 5 probabilities.
