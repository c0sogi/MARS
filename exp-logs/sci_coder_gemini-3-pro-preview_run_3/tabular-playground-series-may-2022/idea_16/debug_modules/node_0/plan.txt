This implementation demonstrates the end-to-end usage of the provided machine learning library for the manufacturing control task.

### Strategy Outline
1.  **Configuration**: We override the default `Config` parameters (epochs, batch size) to ensure the script runs quickly (under 1 minute) while still exercising all code paths.
2.  **Data Loading**: We use `get_dataloaders` with the `max_samples` argument to load a small subset (2048 samples) of the data. This verifies the preprocessing pipeline, caching mechanisms, and DataLoader construction without processing the entire dataset.
3.  **Model Verification**: We manually instantiate the `NoiseRegularizedFunnelMLP` and perform a forward pass with a single batch to verify the architecture and tensor shapes before training.
4.  **Training**: We execute the `train_model` function, which handles the training loop, validation, optimizer steps, and model checkpointing.
5.  **Submission**: We generate predictions using `predict`. To verify `generate_submission` with our data subset, we create a temporary matching sample submission file and confirm the final output format.
