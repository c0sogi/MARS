This script demonstrates the usage of the provided library modules for the manufacturing control data classification task. It follows a step-by-step approach:
1.  **Data Loading & Processing**: It utilizes `library.data_processor.make_dataloaders` to load raw data, perform feature engineering (splitting the string feature `f_27`), encode categorical variables, and scale continuous features. It verifies the structure and shapes of the resulting batches.
2.  **Model Initialization**: It initializes the `EntityEmbeddingMLP` model using vocabulary sizes derived from the dataset, verifying the model architecture and forward pass dimensions.
3.  **Training & Validation**: It instantiates the `Trainer` class to manage the training loop. It runs a shortened training session (1 epoch) to demonstrate the fitting process and verifies that the model learns (or at least runs without error) and produces valid AUC scores.
4.  **Inference & Pipeline**: It demonstrates the high-level `run_training_pipeline` function to generate a submission file, verifying the output format.
