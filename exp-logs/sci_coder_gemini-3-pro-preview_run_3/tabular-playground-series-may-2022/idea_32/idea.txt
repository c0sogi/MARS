# Proposed Strategy: Deeply-Supervised Parallel Funnel Ensemble (DSPFE)

## Model
We will implement a **Deeply-Supervised Parallel Funnel Ensemble (DSPFE)**. This architecture evolves the "Heterogeneous Parallel Funnel Ensemble" by introducing **Deep Supervision** (Auxiliary Classifiers) to each stream. This structural innovation enforces strong, discriminative feature learning in the early layers of the network, directly combating the "categorical error" correlation (Cite solution_lesson_node_00096) by mitigating the vanishing gradient problem through the depth of the funnel.

1.  **Parallel Independent Architecture:**
    *   The model will consist of **5 independent streams** instantiated within a single computational graph (Cite solution_lesson_node_00064).
    *   **Independent Representation:** Each stream will possess its own **independent Entity Embedding layers** (Dim 16) for the categorical features. We explicitly reject shared embeddings to ensure decorrelated representation learning (Cite solution_lesson_node_00065).
    *   **Input Fusion:** Each stream will independently flatten its embeddings and concatenate them with the normalized continuous features (**Early Fusion**) (Cite solution_lesson_node_00029).

2.  **Backbone Topology (Deeply Supervised Funnel):**
    *   All streams utilize the **Funnel MLP** structure (decreasing layer widths: 512 $\to$ 256 $\to$ 128) to leverage its compressive inductive bias (Cite solution_lesson_node_00004).
    *   **Auxiliary Heads (The Innovation):** We attach a linear classification head (Linear $\to$ Sigmoid) to the output of the **first hidden layer** (width 512) of each stream.
    *   **Mechanism:** During training, these auxiliary heads predict the target variable based solely on the low-level features extracted by the first layer. This forces the embedding layers and the initial projection to immediately learn linearly separable representations, preventing the model from deferring all discriminative power to the final layers.
    *   **Main Head:** The final hidden layer (width 128) projects to the primary output neuron (Cite solution_lesson_node_00020).
    *   **Activation:** Standard **ReLU** exclusively (Cite solution_lesson_node_00041).

3.  **Heterogeneous Configuration:**
    *   We employ **Regularization Heterogeneity** (Cite solution_lesson_node_00069) while respecting the **Safety Floor** (Cite solution_lesson_node_00077).
    *   **Streams 1 & 2 (Anchors):** Standard Funnel, Dropout **0.20**.
    *   **Stream 3 (Capacity Variant):** **Wide Funnel** (1024 $\to$ 512 $\to$ 256), Dropout **0.25** (Cite solution_lesson_node_00066).
    *   **Stream 4 (Safe-Aggressive):** Standard Funnel, Dropout **0.15**.
    *   **Stream 5 (Conservative):** Standard Funnel, Dropout **0.30**.

4.  **Data Volume:** Utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is calibrated to balance super-convergence with the specific sensitivities of AdamW:

1.  **Loss Function:** The training objective is the weighted sum of the Main and Auxiliary losses for all streams:
    $$L_{total} = \sum_{s=1}^{5} (BCE_{main}^{(s)} + 0.4 \cdot BCE_{aux}^{(s)})$$
    The coefficient $0.4$ ensures the auxiliary task guides representation learning without dominating the final objective.
2.  **Optimizer:** **AdamW** with a calibrated weight decay of **2e-5**. We select this value as a safe midpoint between the baseline `1e-5` and the overly aggressive `1e-4` (Cite solution_lesson_node_00096), accounting for AdamW's decoupled implementation (Cite solution_lesson_node_00063).
3.  **Scheduler:** **One-Cycle Learning Rate Policy** with `max_lr=1e-2`. We explicitly maintain the high learning rate magnitude to ensure the model can escape local minima (Cite solution_lesson_node_00072).
4.  **Batch Size:** **1024** (Cite solution_lesson_node_00024).
5.  **Duration:** Train for **50 Epochs** (Cite solution_lesson_node_00080).

## Evaluation
1.  **Preprocessing:** Apply the global (transductive) vocabulary mappings and training set scalers to the test set.
2.  **Inference:** The DSPFE model will generate 5 independent probability predictions per sample (using only the **Main Heads**).
3.  **Submission:** The final prediction will be the **arithmetic mean** of these 5 probabilities.
