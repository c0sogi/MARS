# Proposed Strategy: Gated Funnel Network with Enhanced Regularization

## Model
We will implement a **Gated Funnel Network** that synthesizes the rapid convergence properties of Gated Linear Units (GLU) with a robust regularization scheme designed to counteract the overfitting observed in previous gated experiments.

1.  **Backbone Architecture:** We will retain the **Funnel MLP** topology (decreasing layer widths: 512 $\to$ 256 $\to$ 128). This structure provides the compressive inductive bias that has consistently outperformed constant-width ResNets and Transformers on this dataset (Cite solution_lesson_node_00004, solution_lesson_node_00025).
2.  **Gated Linear Units (GLU):** We will replace standard `Linear -> ReLU` blocks with **Gated Linear Units**.
    *   *Mechanism:* Each layer will project the input $x$ into two parallel vectors, a "value" $V = W_v x + b_v$ and a "gate" $G = W_g x + b_g$. The output is the element-wise product $V \otimes \sigma(G)$.
    *   *Rationale:* This allows the network to dynamically select relevant features and interactions, accelerating convergence significantly compared to standard MLPs (Cite solution_lesson_node_00019).
3.  **Regularization (The Correction):** To address the overfitting caused by the increased parameter count of GLUs (Cite solution_lesson_node_00019), we will implement a strict regularization protocol:
    *   **High Dropout:** We will increase the Dropout rate to **0.30** (up from the baseline 0.20).
    *   **No Normalization Layers:** We explicitly exclude Layer Normalization and Batch Normalization. Previous lessons demonstrated that LayerNorm induces overfitting on this data (Cite solution_lesson_node_00039) and BatchNorm underperforms Dropout (Cite solution_lesson_node_00018). We rely solely on the gating mechanism and Dropout for stability.
4.  **Input & Embeddings:**
    *   **Categorical Inputs:** The 10 decomposed character positions of `f_27` (Cite solution_lesson_node_00001) and discrete features `f_29`, `f_30` (Cite solution_lesson_node_00008).
    *   **Optimal Capacity:** All categorical features will be mapped to **Entity Embeddings of dimension 16**. This adheres to the "sweet spot" identified between the bottlenecks of dim 8 (Cite solution_lesson_node_00018) and the noise of dim 32 (Cite solution_lesson_node_00027).
    *   **Early Fusion:** Embeddings will be flattened and concatenated immediately with normalized continuous features (Cite solution_lesson_node_00029).
5.  **Output Head:** The final 128-unit representation connects directly to the output neuron, avoiding bottlenecks (Cite solution_lesson_node_00020).

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures every unique token in the test set has a distinct embedding index, preventing the signal loss caused by mapping unseen test tokens to "unknown" (Cite solution_lesson_node_00021).
2.  **String Decomposition:** `f_27` will be split into 10 fixed-position character columns (Cite solution_lesson_node_00001). We explicitly avoid N-gram expansion (Cite solution_lesson_node_00035) and Token Dropout (Cite solution_lesson_node_00040) to preserve non-redundant positional signals.
3.  **Feature Engineering:** We will compute and append the `unique_character_count` of `f_27` as a normalized continuous feature (Cite solution_lesson_node_00002).
4.  **Normalization:** All continuous features will be scaled using **StandardScaler**.
5.  **Data Volume:** We will utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is calibrated to balance the GLU's speed with the need for generalization:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-5**. We explicitly avoid the default `1e-2`, which was proven too aggressive for this tabular task (Cite solution_lesson_node_00023).
2.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise, avoiding the generalization gap observed with larger batches (Cite solution_lesson_node_00024).
3.  **Scheduler:** **One-Cycle Learning Rate Policy**. We retain this schedule to facilitate super-convergence and robust minima selection (Cite solution_lesson_node_00002).
4.  **Strategy:** Direct Supervised Learning (Cite solution_lesson_node_00013).

## Evaluation
1.  **Preprocessing:** The test set will be processed using the global (transductive) vocabulary mappings and training set scalers.
2.  **Inference:** The trained Gated Funnel Network will predict probabilities for the target class `1`.
3.  **Submission:** The resulting probabilities will be formatted into the submission CSV for AUC evaluation.
