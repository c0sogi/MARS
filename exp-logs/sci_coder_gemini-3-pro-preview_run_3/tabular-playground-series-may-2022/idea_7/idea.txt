# Proposed Strategy: Dual-Stream Gated Funnel Network

## Model
We will implement a **Dual-Stream Gated Funnel Network**. This architecture introduces a structural innovation by processing categorical "state" information and continuous "sensor" signals in separate, specialized streams before fusing them. This design allows the network to perform feature selection and noise filtering specific to each data modality before attempting to learn complex cross-modal interactions.

1.  **Stream 1: Categorical State Processing**
    *   **Inputs:** The 10 decomposed character positions of `f_27` (Cite solution_lesson_node_00001) and the discrete features `f_29` and `f_30` (Cite solution_lesson_node_00008).
    *   **High-Fidelity Embeddings:** Each feature will be mapped to a learnable embedding vector of dimension **32**. This ensures sufficient capacity to capture the high-cardinality signal without the information bottlenecks observed with lower dimensions (Cite solution_lesson_node_00018).
    *   **Gated Feature Selection:** The flattened embeddings will pass through a dedicated **Gated Linear Unit (GLU)** block. This allows the model to dynamically suppress irrelevant character positions or state codes early in the forward pass (Cite solution_lesson_node_00019).

2.  **Stream 2: Continuous Signal Processing**
    *   **Inputs:** All normalized continuous features (`f_00`–`f_28`) and the engineered `unique_character_count`.
    *   **Gated Noise Filtering:** These features will pass through a separate GLU block. Given the simulated nature of the data, this acts as a learnable filter to suppress sensor noise before it pollutes the state embeddings.

3.  **Funnel Backbone (The Exploitation):**
    *   **Fusion:** The outputs of the two streams are concatenated.
    *   **Architecture:** The combined vector is processed by a **Funnel MLP** with decreasing layer widths (512 $\to$ 256 $\to$ 128). We retain this macroscopic structure as it provides the beneficial inductive bias of feature compression found to be superior to ResNets for this dataset (Cite solution_lesson_node_00004).
    *   **Block Structure:** Each layer in the funnel will utilize a **LayerNorm $\to$ GLU $\to$ Dropout** structure. The LayerNorm stabilizes the gating mechanism, while the GLU accelerates convergence (Cite solution_lesson_node_00019).
    *   **Head:** The final 128-unit representation connects directly to the output neuron, explicitly avoiding any further tapering (e.g., to 64 units) to prevent information bottlenecks at the decision boundary (Cite solution_lesson_node_00020).

## Data
The preprocessing pipeline corrects previous vocabulary alignment errors and ensures maximum data fidelity:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures that every unique token in the test set is assigned a distinct embedding index, preventing the significant signal loss caused by mapping unseen test tokens to a generic "unknown" bucket (Cite solution_lesson_node_00021).
2.  **String Decomposition:** The `f_27` feature will be split into 10 fixed-position character columns (Cite solution_lesson_node_00001).
3.  **Feature Engineering:** We will compute and append the `unique_character_count` of `f_27` as a normalized continuous feature (Cite solution_lesson_node_00002).
4.  **Normalization:** All continuous features will be scaled using StandardScaler.
5.  **Data Volume:** We will utilize the **full training dataset**, strictly avoiding subsampling to ensure the complex gated architecture has sufficient data to converge and generalize (Cite solution_lesson_node_00022).

## Training
The training configuration is precisely calibrated to balance the fast convergence of GLUs with robust regularization:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-5**. We explicitly avoid the default `1e-2`, which was proven too aggressive for this tabular task (Cite solution_lesson_node_00023).
2.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise, avoiding the generalization gap observed with larger batches (Cite solution_lesson_node_00024).
3.  **Scheduler:** **One-Cycle Learning Rate Policy**. We retain this schedule to facilitate super-convergence and robust minima selection (Cite solution_lesson_node_00002).
4.  **Regularization:** A Dropout rate of **0.25** will be applied within the GLU blocks. This stronger regularization is necessary to counteract the increased parameter count and overfitting tendency of gated architectures (Cite solution_lesson_node_00019).
5.  **Strategy:** Direct Supervised Learning. We avoid autoencoder pretraining as it provides no benefit for this high-signal dataset (Cite solution_lesson_node_00013).

## Evaluation
1.  **Preprocessing:** The test set will be processed using the global (transductive) vocabulary mappings and training set scalers.
2.  **Inference:** The trained Dual-Stream Gated Funnel model will predict probabilities for the target class `1`.
3.  **Submission:** The resulting probabilities will be formatted into the submission CSV for AUC evaluation.
