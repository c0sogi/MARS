# Proposed Strategy: Safe-Spectrum Parallel Funnel Ensemble (SSPFE)

## Model
We will implement a **Safe-Spectrum Parallel Funnel Ensemble (SSPFE)**. This architecture is a structural evolution of the "Anchor-Variant" ensemble. It retains the powerful **Parallel In-Network Ensembling** backbone but rigorously corrects the regularization strategy by enforcing a "Safety Floor." We explicitly reject the "Aggressive" low-dropout streams that caused overfitting in previous iterations (Cite solution_lesson_node_00077) and instead constrain the ensemble's diversity to a safe, high-generalization zone.

1.  **Parallel Independent Architecture:**
    *   The model will consist of **5 independent streams** instantiated within a single computational graph (Cite solution_lesson_node_00064).
    *   **Independent Representation:** Crucially, each stream will possess its own **independent Entity Embedding layers**. We explicitly reject shared embeddings to ensure that each stream learns a unique, decorrelated representation of the categorical manifold (Cite solution_lesson_node_00065).
    *   **Input Fusion:** Each stream will independently flatten its embeddings and concatenate them with the normalized continuous features (**Early Fusion**) (Cite solution_lesson_node_00029).

2.  **Backbone Topology (The Funnel):**
    *   All streams will utilize the **Funnel MLP** structure (decreasing layer widths: 512 $\to$ 256 $\to$ 128). This provides the compressive inductive bias that has consistently outperformed ResNets (Cite solution_lesson_node_00004).
    *   **Shallow Depth:** We strictly limit the depth to 3 hidden layers, rejecting deeper networks which induce overfitting (Cite solution_lesson_node_00071).
    *   **Bottleneck Avoidance:** The final hidden layer will remain at width 128, avoiding tapering to 64 units (Cite solution_lesson_node_00020).
    *   **Exclusions:** No Layer Normalization (Cite solution_lesson_node_00039), No Input Noise (Cite solution_lesson_node_00053), No GLU/Swish (Cite solution_lesson_node_00069).

3.  **The Safe-Spectrum Configuration:**
    *   **Streams 1 & 2 (Anchors):** Standard Funnel with **Dropout 0.20**. These provide robust baseline performance via Initialization Diversity (Cite solution_lesson_node_00071).
    *   **Stream 3 (Capacity Variant):** **Wide Funnel** (1024 $\to$ 512 $\to$ 256) with **Dropout 0.25**. This stream utilizes increased width to capture subtler patterns (Cite solution_lesson_node_00066).
    *   **Stream 4 (Safe-Aggressive Variant):** Standard Funnel with **Dropout 0.15**. We explicitly raise the dropout floor from the failed 0.10 (Cite solution_lesson_node_00077) to 0.15 to prevent the overfitting that contaminated previous ensembles.
    *   **Stream 5 (Conservative Variant):** Standard Funnel with **Dropout 0.30**. This high-regularization stream acts as a stabilizer (Cite solution_lesson_node_00069).

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures every unique token in the test set is assigned a distinct embedding index (Cite solution_lesson_node_00021).
2.  **Feature Engineering:**
    *   **String Decomposition:** Decompose `f_27` into 10 fixed-position character columns (Cite solution_lesson_node_00001). Avoid N-grams (Cite solution_lesson_node_00035).
    *   **Discrete Features:** Treat `f_29` and `f_30` as categorical variables (Cite solution_lesson_node_00008).
    *   **Aggregate Signal:** Compute and append the `unique_character_count` of `f_27` (Cite solution_lesson_node_00002).
3.  **Embedding Capacity:** Set the embedding dimension to **16** for all categorical variables. This is the optimal "sweet spot" (Cite solution_lesson_node_00018, solution_lesson_node_00027).
4.  **Normalization:** Scale all continuous features using **StandardScaler**.
5.  **Data Volume:** Utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is calibrated to balance super-convergence with the specific sensitivities of AdamW on tabular data:

1.  **Optimizer:** **AdamW** with a calibrated weight decay of **1e-4**. We increase decay from the Adam baseline (`1e-5`) to account for AdamW's decoupled implementation (Cite solution_lesson_node_00063) but strictly avoid the aggressive `1e-2` (Cite solution_lesson_node_00023).
2.  **Scheduler:** **One-Cycle Learning Rate Policy** with `max_lr=1e-2`. We explicitly maintain the high learning rate magnitude to ensure the model can escape local minima (Cite solution_lesson_node_00072).
3.  **Loss Function:** The training objective is the **sum of Binary Cross-Entropy losses** calculated independently for each of the 5 streams.
4.  **Batch Size:** **1024**. We utilize this moderate batch size to leverage the implicit regularization of stochastic gradient noise (Cite solution_lesson_node_00024).

## Evaluation
1.  **Preprocessing:** Apply the global (transductive) vocabulary mappings and training set scalers to the test set.
2.  **Inference:** The SSPFE model will generate 5 independent probability predictions per sample.
3.  **Submission:** The final prediction will be the **arithmetic mean** of these 5 probabilities.
