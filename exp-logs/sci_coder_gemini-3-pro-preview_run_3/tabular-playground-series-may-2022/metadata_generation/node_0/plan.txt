The following script performs the required task. It reads the tabular data from the `./input` directory, performs a stratified 80/20 split on the training data to create a validation set, and saves the resulting datasets to the `./metadata` directory. It includes a `source_path` column in the metadata to reference the original files relative to the input directory. Finally, it performs rigorous verification checks on the generated metadata, including file path resolution, split ratios, and stratification consistency.
