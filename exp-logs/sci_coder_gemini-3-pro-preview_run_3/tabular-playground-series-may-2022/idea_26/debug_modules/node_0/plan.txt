This script demonstrates the usage of the provided machine learning library components for the manufacturing control task. It performs the following steps:

1.  **Feature Engineering Verification**: Manually invokes the `FeatureEngineer` on a small subset of data to verify that the `f_27` string column is correctly decomposed into character features and that ordinal encoding/scaling is applied.
2.  **Dataset Verification**: Instantiates the `ManufacturingDataset` to ensure it correctly yields tensors for continuous features, categorical features, and targets with the expected shapes and types.
3.  **Model Verification**: Instantiates the `RPFEModel` (Residual-Parallel Funnel Ensemble) and performs a forward pass with dummy data to confirm the architecture produces the correct output shape (batch_size, num_streams).
4.  **Full Pipeline Execution**: Uses the `Engine` class to run a complete training and inference cycle. To optimize for speed, this is run on a debug subset (500 samples) for just 1 epoch.
5.  **Submission Validation**: Checks the generated submission file to ensure it adheres to the required format and that predictions are valid probabilities.
