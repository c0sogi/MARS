# Proposed Strategy: Residual-Parallel Funnel Ensemble (RPFE)

## Model
We will implement a **Residual-Parallel Funnel Ensemble (RPFE)**. This architecture introduces a structural innovation by transforming each stream in the parallel ensemble into a **Wide-and-Deep** learner. By adding a direct linear skip connection from the input to the output logit, we allow the MLP backbone to focus exclusively on learning non-linear residuals, effectively leveraging the high signal-to-noise ratio of the dataset while preserving the proven Funnel architecture.

1.  **Parallel Independent Architecture:**
    *   The model will consist of **5 independent streams** instantiated within a single computational graph (Cite solution_lesson_node_00064).
    *   **Independent Representation:** Each stream will possess its own **independent Entity Embedding layers**. We explicitly reject shared embeddings to ensure that each stream learns a unique, decorrelated representation of the categorical manifold (Cite solution_lesson_node_00065).
    *   **Input Fusion:** Each stream will independently flatten its embeddings and concatenate them with the normalized continuous features (**Early Fusion**) (Cite solution_lesson_node_00029).

2.  **Stream Architecture (The Innovation):**
    *   Each stream will implement a **Residual (Wide-and-Deep)** topology:
        *   **Deep Path (The Funnel):** The fused input is processed by a **Funnel MLP** (decreasing layer widths: 512 $\to$ 256 $\to$ 128). This preserves the compressive inductive bias superior to ResNets (Cite solution_lesson_node_00004).
        *   **Wide Path (The Skip):** The fused input is simultaneously projected via a single **Linear Layer** directly to the output node (Input $\to$ 1).
        *   **Aggregation:** The final logit for the stream is the **sum** of the Deep Path output and the Wide Path output.
    *   **Rationale:** This structure avoids the "shallow mapping" bias of input injection at intermediate layers (Cite solution_lesson_node_00032) while ensuring the model can trivially capture strong linear signals without wasting deep capacity, a crucial feature for high-precision synthetic data.

3.  **Heterogeneous Configuration:**
    *   We employ **Regularization Heterogeneity** (Cite solution_lesson_node_00069) and **Capacity Variation** (Cite solution_lesson_node_00066) while strictly enforcing a **Uniform Optimization** landscape (Cite solution_lesson_node_00082).
    *   **Streams 1 & 2 (Anchors):** Standard Funnel (512 $\to$ 256 $\to$ 128) with **Dropout 0.20**.
    *   **Stream 3 (Capacity Variant):** **Wide Funnel** (1024 $\to$ 512 $\to$ 256) with **Dropout 0.25**.
    *   **Stream 4 & 5 (Conservative Variants):** Standard Funnel with **Dropout 0.25** and **0.30**.
    *   **Safety Constraint:** We explicitly avoid dropout rates below 0.15 to prevent the overfitting observed in "aggressive" streams (Cite solution_lesson_node_00077).

## Data
The preprocessing pipeline is designed to ensure maximum signal fidelity and correct previous vocabulary alignment errors:

1.  **Transductive Vocabulary Alignment:** We will fit the categorical `OrdinalEncoder` on the **concatenation of the Train, Validation, and Test sets**. This ensures every unique token in the test set is assigned a distinct embedding index (Cite solution_lesson_node_00021).
2.  **Feature Engineering:**
    *   **String Decomposition:** Decompose `f_27` into 10 fixed-position character columns (Cite solution_lesson_node_00001). Avoid N-grams (Cite solution_lesson_node_00035).
    *   **Aggregate Signal:** Compute and append the `unique_character_count` of `f_27` (Cite solution_lesson_node_00002).
3.  **Embedding Capacity:** Set the embedding dimension to **16** for all categorical variables. This is the optimal "sweet spot" (Cite solution_lesson_node_00018, solution_lesson_node_00027).
4.  **Normalization:** Scale all continuous features using **StandardScaler**.
5.  **Data Volume:** Utilize the **full training dataset**, strictly avoiding subsampling (Cite solution_lesson_node_00022).

## Training
The training configuration is calibrated to facilitate super-convergence while respecting the sensitivities of AdamW:

1.  **Optimizer:** **AdamW** with a uniform weight decay of **1e-4**. We use `1e-4` to account for AdamW's decoupled implementation (Cite solution_lesson_node_00063) but avoid the aggressive `1e-2` (Cite solution_lesson_node_00023). We strictly avoid heterogeneous weight decay (Cite solution_lesson_node_00082).
2.  **Scheduler:** **One-Cycle Learning Rate Policy** with `max_lr=1e-2`. We maintain the high learning rate to ensure the model can escape local minima (Cite solution_lesson_node_00072).
3.  **Loss Function:** The training objective is the **sum of Binary Cross-Entropy losses** calculated independently for each of the 5 streams.
4.  **Duration:** Train for **50 Epochs**. We explicitly avoid premature truncation to allow the highly regularized streams to fully converge (Cite solution_lesson_node_00080).
5.  **Batch Size:** **1024** (Cite solution_lesson_node_00024).

## Evaluation
1.  **Preprocessing:** Apply the global (transductive) vocabulary mappings and training set scalers to the test set.
2.  **Inference:** The RPFE model will generate 5 independent probability predictions per sample.
3.  **Submission:** The final prediction will be the **arithmetic mean** of these 5 probabilities.
