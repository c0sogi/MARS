Implementation strategy:
1.  **Environment & Data**: Initialize the `Config` and set the device. Load the training, validation, and test datasets using `load_and_preprocess_data` to leverage cached artifacts and ensure consistent preprocessing.
2.  **Model Initialization**: Inspect the datasets to dynamically determine the input dimensions (categorical cardinalities and continuous feature count) required to instantiate the `AVPFE` model.
3.  **Training**: Execute a training loop for 20 epochs using `AdamW` and `OneCycleLR`. Inside the loop, use `train_epoch` and `validate` from `train_utils`. Save the model state whenever validation AUC improves.
4.  **Evaluation & Failure Analysis**: Load the best model checkpoint. Calculate the final validation AUC on the full validation set. Compute the absolute error for each validation sample and calculate the Pearson correlation between this error and the continuous input features to identify systematic weaknesses.
5.  **Submission**: Compare the final validation AUC against the strict threshold (`0.9975746465492954`). If the model passes, run inference on the test set, format the output, and save `submission.csv`.
