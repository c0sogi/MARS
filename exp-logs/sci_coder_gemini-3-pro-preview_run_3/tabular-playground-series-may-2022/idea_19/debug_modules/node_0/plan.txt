3.  **Dataset & DataLoader**: We will instantiate `ManufacturingDataset` for training, validation, and testing, and wrap them in PyTorch `DataLoader`s.
4.  **Model Initialization**: We will initialize the `HPFEModel` using the metadata generated during preprocessing. We will perform a "dry run" forward pass with a single batch to verify that the model architecture produces the expected output shapes (list of 5 tensors).
5.  **Training**: We will execute the `train_model` function from `library.engine`. We will assert that the training completes and returns a model instance.
6.  **Inference & Submission**: We will run `predict_and_submit` to generate predictions on the test set.
7.  **Final Validation**: We will load the generated `submission.csv` and verify its format (columns, row count, value ranges) to ensure the pipeline produced a valid result.
