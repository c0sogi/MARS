1.  **Setup and Configuration**: We will start by setting the random seeds using `library.utils.set_seed` to ensure reproducibility. To satisfy the requirement for a fast baseline, we will override `Config.EPOCHS` to 10. This provides a balance between training speed and model convergence for the small dataset.
2.  **Training**: We will instantiate the `library.trainer.Trainer` class and call its `fit()` method. This handles the training loop, validation monitoring, and saving of the best model based on ROC AUC.
3.  **Validation and Metrics**: We will load the best model weights saved during training. We will then perform inference on the hold-out validation set using the `val_loader`. We will calculate the "Mean column-wise ROC AUC" using `sklearn.metrics.roc_auc_score` with `multi_class='ovr'` and `average='macro'`, printing it in the required format.
4.  **Failure Analysis**: During the validation pass, we will compute the error magnitude for each sample (defined as `1.0 - probability_of_true_class`). We will then iterate through the validation metadata to load the raw images and extract meta-features (Brightness and Contrast). We will calculate and print the Pearson correlation between the error magnitude and these features to identify systematic failures.
5.  **Submission**: Finally, we will invoke `library.inference.predict_and_submit()` to generate predictions for the test set and save the formatted `submission.csv` to the submission directory.
