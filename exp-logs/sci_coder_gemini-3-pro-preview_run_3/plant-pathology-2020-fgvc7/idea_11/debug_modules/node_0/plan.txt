Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override key parameters (Epochs, Batch Size, Model Name, Image Size) to ensure the demonstration runs rapidly (1 epoch, small batch, lightweight ResNet18 backbone).
2.  **Utility Verification**: Test the `calculate_roc_auc` function with synthetic data and verify `compute_class_weights` logic using a dummy DataFrame to ensure mathematical correctness.
3.  **Data Loading & Processing**: Load the pre-generated metadata DataFrames. Slice them to a tiny subset (e.g., 20 samples) to minimize I/O and processing time. Instantiate the `AppleDataset` and verify that it yields tensors of the correct shape and type.
4.  **Model Initialization**: Instantiate the `AppleNet` model using the overridden lightweight configuration. Perform a dummy forward pass with random noise to confirm the architecture (Backbone + GeM + Head) produces logits of the expected shape `(Batch, Num_Classes)`.
5.  **Training Loop Execution**: Invoke the `train_fold` function from the engine using the subsetted data. This will verify the integration of the data loader, model, loss function, optimizer, scaler, and EMA mechanism.
6.  **Inference Execution**: Use the trained model checkpoint to run the `inference` function on the test subset, verifying the Test-Time Augmentation (TTA) logic and output format.
7.  **Cleanup**: The script runs within the allocated working directory and does not modify inputs.
