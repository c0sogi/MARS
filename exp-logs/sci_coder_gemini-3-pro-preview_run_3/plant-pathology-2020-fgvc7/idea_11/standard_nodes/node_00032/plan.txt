Implementation Strategy:
1.  **Configuration & Setup**: I will start by setting the random seed for reproducibility and overriding the `Config.EPOCHS` to 5 and `Config.PATIENCE` to 3. This ensures the 5-fold cross-validation for two architectures completes quickly (within the 2-hour limit) while still providing a meaningful baseline.
2.  **Data Preparation**: I will load the training and validation metadata using `load_dataset_dfs`, concatenate them into a single dataframe, and generate a new 5-fold stratified split. This ensures we utilize the entire available annotated dataset for the ensemble cross-validation.
3.  **Training & Inference Pipeline**: I will iterate through each of the 5 folds. Inside each fold, I will train both the `EfficientNetV2-M` (512x512) and `MaxViT-Small` (384x384) models using the `engine.train_fold` function. Immediately after training, I will generate Out-of-Fold (OOF) predictions for the validation set and predictions for the test set using `engine.inference`.
4.  **Evaluation**: I will accumulate the OOF predictions to calculate the global Mean Column-wise ROC AUC score. This metric will be printed in the required format.
5.  **Failure Analysis**: I will implement a function to calculate the prediction error for each validation sample and correlate it with image statistics (Brightness, Contrast, Greenness). This helps identify if the model struggles with specific lighting or color conditions.
6.  **Submission**: I will average the test predictions from all 10 models (5 folds $\times$ 2 architectures) to create a robust ensemble. If the validation AUC indicates the model has learned (AUC > 0.5), I will generate the `submission.csv` file.
