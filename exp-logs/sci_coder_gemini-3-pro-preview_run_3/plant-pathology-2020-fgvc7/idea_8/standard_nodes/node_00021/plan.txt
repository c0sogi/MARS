The implementation strategy involves orchestrating a complete 5-Fold Stratified Cross-Validation pipeline using the provided library modules. The script first loads the training metadata and creates stratified folds. It then iterates through each fold, training both the `AppleEfficientNet` (texture expert) and `AppleMaxViT` (global context expert) models. Training utilizes the pre-defined engine functions, including Automatic Mixed Precision and Cosine Annealing, with model checkpoints saved based on the best validation ROC AUC.

After training all 10 models (5 folds × 2 architectures), the script evaluates the ensemble on the hold-out validation set (`val.csv`) to compute the final metric and performs failure analysis by correlating prediction errors with image meta-features (brightness, contrast, color). Finally, it generates the submission file by running inference on the test set (`test.csv`) with Test-Time Augmentation (TTA), averaging the predictions from all models.
