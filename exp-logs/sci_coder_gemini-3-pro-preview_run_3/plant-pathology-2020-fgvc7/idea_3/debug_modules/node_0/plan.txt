### Implementation Strategy

1.  **Configuration Override**: We will modify the global `Config` class attributes to enable `DEBUG` mode, reduce `EPOCHS` to 1, disable `USE_SWA` (Stochastic Weight Averaging), and set a small `BATCH_SIZE`. This ensures the code runs quickly using a tiny subset of data.
2.  **Utility Verification**: We will validate `calculate_class_weights` by comparing its output against expected dimensions and `compute_metric` using synthetic numpy arrays to ensure the ROC AUC calculation logic is correct.
3.  **Data Loading Demonstration**: We will utilize `get_loaders` with `debug=True`. We will fetch a single batch to assert that image tensors have the correct shape `(B, C, H, W)` and targets match the number of classes.
4.  **Model Instantiation**: We will create an instance of `Config.MODEL_2_NAME` (ConvNeXt-Tiny) using `create_model`. We will perform a dummy forward pass to confirm the output logits shape `(B, Num_Classes)`.
5.  **Training Loop Integration**: We will execute the `fit` function from `engine.py`. This serves as an integration test for the training engine, validation loop, and checkpoint saving mechanism. We will verify that a checkpoint file is created in the working directory.
6.  **Inference Demonstration**: Instead of running the full `run_inference` pipeline (which requires multiple trained models), we will demonstrate the core inference logic by calling `predict_with_tta` on the trained model and the test loader, verifying the output probability shapes.
