The following strategy outlines the implementation:

1.  **Configuration Patching**: To ensure the code runs quickly, I will override the `EPOCHS`, `BATCH_SIZE`, and `PATIENCE` constants in the imported library modules (`library.config`, `library.training`, `library.data`). This forces the training to run for only 1 epoch with a small batch size.
2.  **Data Verification**: I will instantiate the dataloaders using `get_dataloaders` in debug mode and assert that the batch shapes for images and labels are correct.
3.  **Model Verification**: I will initialize a model using `get_model` and perform a forward pass with dummy data to verify the output shape corresponds to the number of classes.
4.  **Training Integration**: I will execute `run_training` for both the ConvNeXt and EfficientNet models. This verifies the training loop, loss calculation, and model saving functionality.
5.  **Inference Integration**: Using the weights saved from the training step, I will run `ensemble_predictions` to generate the final submission file and verify its format.
