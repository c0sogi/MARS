The `RuntimeError: CUDA error: CUBLAS_STATUS_NOT_INITIALIZED` occurs because the CUDA context is initialized in the main process (via `seed_everything`), but the `DataLoader` attempts to fork new processes (`num_workers=4`) which inherit a corrupted CUDA state. To fix this, I will set `num_workers=0` in `library/data_processing.py`, ensuring data loading happens in the main process where the CUDA context is valid.
