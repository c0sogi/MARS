This script demonstrates the end-to-end usage of the provided machine learning library for the Cover Type prediction task. It performs the following steps:

1.  **Configuration Setup**: Overrides the default `Config` paths to use a temporary working directory and creates "mini" versions of the datasets to ensure the demonstration runs quickly (under 1 minute) while validating all logic.
2.  **Data Loading & Processing**: Uses `library.data_loader` to ingest the mini-datasets, apply feature engineering, scale continuous features, and generate PyTorch DataLoaders. It verifies data shapes and pipeline integrity.
3.  **Model Architecture Verification**: Instantiates the `ParallelDCNResNet` model from `library.model`, performs a forward pass with dummy data, and asserts that the output dimensions match the expected class count.
4.  **Training Loop**: Uses `library.train.Trainer` to run a short training session (2 epochs). It validates that the loss decreases or the model runs without error and saves checkpoints.
5.  **Inference & Submission**: Executes the inference pipeline using `library.infer`, generating predictions on the test set and verifying the output submission file format.
