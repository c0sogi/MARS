The following script demonstrates the end-to-end usage of the provided library files (`config.py`, `data_loader.py`, `model.py`, `trainer.py`).

### Implementation Strategy
1.  **Environment Setup**: Initialize a working directory for the demonstration to avoid conflicts with existing cache files. Set random seeds for reproducibility.
2.  **Data Subsetting**: To satisfy the "Optimize for Speed" requirement, we create a "Mini Dataset" by reading only the first 2,000 rows of the provided metadata parquet files. This ensures the pipeline runs quickly (seconds instead of hours).
3.  **Configuration Override**: Monkey-patch the `Config` class to point to the new mini-dataset paths and reduce hyperparameters (e.g., `EPOCHS=1`, `BATCH_SIZE=64`) to minimize runtime.
4.  **Data Loading**: Use `library.data_loader.get_dataloaders` to process the raw data, apply feature engineering, and generate PyTorch DataLoaders. We verify the output shapes and types.
5.  **Model Initialization**: Instantiate the `DeepParallelVectorDCNResNet` model using `library.model.get_model`. We validate the architecture by running a dummy forward pass and checking the output dimensions.
6.  **Training Loop**: Execute the training pipeline using `library.trainer.run_training`. We verify that the training completes without error and that the best model weights are saved to disk.
7.  **Inference & Submission**: Load the best saved model, generate predictions on the test set using `library.model.predict`, and verify the output shape matches the test IDs. Finally, we demonstrate how to map predictions back to original labels and save a submission file.
