The following script demonstrates the end-to-end usage of the provided library components for the Forest Cover Type prediction task.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the global `config` object to set a temporary working directory and enable "debug mode". This ensures the code runs on a tiny subset of data (1000 rows) with minimal epochs (1 epoch) and a small batch size, satisfying the speed requirement.
2.  **Data Pipeline Verification**: We call `get_dataloaders` with `load_cached_data=False` to force the `FeatureEngineer` to process the raw metadata parquets. We assert that the resulting data tensors have the expected dimensions (Batch Size, Input Dim).
3.  **Model Instantiation & Forward Pass**: We initialize the `ParallelDCNResNet` model and perform a dummy forward pass with a single batch to verify the architecture produces the correct output shape `(Batch Size, Num Classes)`.
4.  **Training Loop Execution**: We instantiate the `Trainer` class and run the `.fit()` method. This validates the optimizer, loss calculation, backpropagation, and scheduler logic.
5.  **Inference & Submission**: We generate predictions using `.predict()` and save them using `save_submission()`. We verify the output file exists and contains the correct number of rows matching the test IDs.
