2.  **Data Loading**: Use `get_dataloaders(load_cached_data=True)` to efficiently load the pre-processed and cached datasets (Train, Val, Test). Extract the input dimension from the dataset to dynamically configure the model.
3.  **Model Training**: Instantiate the `ParallelDCNResNeXt` model and the `Trainer`. Execute the training loop using `trainer.fit()`, which handles the optimizer, cosine annealing schedule, and early stopping, returning the best-performing model state.
4.  **Validation & Metrics**: Run a dedicated inference pass on the validation set using the best model. Calculate the overall classification accuracy and print it in the required format (`Final Validation Metric: <value>`).
5.  **Failure Analysis**: Compute the binary error vector (1 for incorrect, 0 for correct) for the validation set. Calculate the Pearson correlation coefficient between each input feature and the error vector. Sort and print the top 10 features most strongly associated with model failure to identify systematic weaknesses.
6.  **Submission**: Compare the final validation accuracy against the specified threshold (0.9625041666666667). If the model meets the criteria, generate predictions for the test set using `generate_submission` and save the result to `submission.csv`.
