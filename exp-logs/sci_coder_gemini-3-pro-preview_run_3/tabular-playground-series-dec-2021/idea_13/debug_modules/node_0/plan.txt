This script demonstrates the usage of the provided library files (`config.py`, `data_utils.py`, `model.py`, `train_utils.py`) to train and evaluate the `ParallelLowRankDCNResNet` model.

To optimize for speed while verifying the logic, the script performs the following steps:
1.  **Configuration Override**: Adjusts `Config` parameters (e.g., batch size, epochs) to suit a quick demonstration.
2.  **Data Loading & Slicing**: Calls `process_data` to load and engineer features, then slices the resulting arrays to a tiny subset (1,000 samples) to ensure the training loop completes almost instantly.
3.  **Component Instantiation**: Manually instantiates the `TabularDataset`, `DataLoader`, and `ParallelLowRankDCNResNet` using the sliced data.
4.  **Training Loop Verification**: Runs a short training loop (2 epochs) using `train_one_epoch` and `validate`, asserting that loss values are valid and shapes are correct.
5.  **Utility Verification**: Explicitly tests the `EarlyStopping` class with synthetic loss values to confirm it triggers correctly.
6.  **Inference Verification**: Runs the model on a subset of test data and verifies the output format.
