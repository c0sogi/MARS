Instead, `early_stopping_rounds` must now be passed to the model's constructor (`__init__`). The current implementation in `library/model.py` passes it to `fit()`, causing a `TypeError`.

To fix this, I will modify `library/model.py` to:
1.  Add `early_stopping_rounds` to the `self.params` dictionary in the `__init__` method, using the value from `Config`.
2.  Remove the `early_stopping_rounds` argument from the `self.model.fit()` call in the `fit` method.
