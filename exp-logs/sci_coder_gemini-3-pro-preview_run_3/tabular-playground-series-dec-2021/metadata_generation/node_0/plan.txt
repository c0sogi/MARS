The implementation strategy involves the following steps:

1.  **Setup and Initialization**: Define the input directory (`./input`) and the metadata directory (`./metadata`). Create the metadata directory if it doesn't exist.
2.  **Data Loading**: Load the raw `train.csv` and `test.csv` files using Pandas. The script will identify the target column (`Cover_Type`) and the ID column (`Id`).
3.  **Validation Split**: Perform a stratified 80/20 split on the training data using `sklearn.model_selection.train_test_split` with `random_state=42` to create training and validation sets. This ensures the class distribution is preserved.
4.  **Metadata Generation**: Save the split training, validation, and original test datasets as Parquet files in the `./metadata` directory. Parquet is chosen for its efficiency in storage and reading speed compared to CSV.
5.  **Verification and Quality Checks**:
    *   **Reload**: Load the generated metadata files back into memory.
    *   **Statistics**: Print summary statistics (row counts, column counts, class distributions).
    *   **Stratification Check**: Assert that the distribution of the target variable in the validation set matches the training set within a strict tolerance (1%).
    *   **Leakage Check**: Assert that there is no overlap of `Id`s between the training and validation sets.
    *   **File Path Check**: Include logic to check for broken file paths if any column ending in `path` or `file` were to exist (though none are expected for this tabular dataset).
