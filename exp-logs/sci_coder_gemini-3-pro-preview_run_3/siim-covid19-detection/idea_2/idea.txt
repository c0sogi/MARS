Based on the provided architectures and the need for a highly efficient baseline distinct from the previous Multi-Task Faster R-CNN proposal, here is the proposed solution.

### **Idea 2: Class-Aware One-Stage Detector (YOLOv8-Nano)**

This approach leverages a state-of-the-art **one-stage detector** to solve both classification and detection tasks simultaneously by treating study-level categories as distinct object types. This eliminates the need for a separate classification head or a two-stage proposal mechanism, prioritizing inference speed and architectural simplicity.

#### **Model**
We will employ the **YOLOv8-Nano** architecture, which is significantly more lightweight (~3.2M parameters) than the ResNet-based Faster R-CNN. 
-   **Architecture**: The model uses a **CSPDarknet** backbone to extract features and a **Path Aggregation Network (PANet)** neck to fuse features across different scales.
-   **Detection Head**: Unlike the standard approach of detecting a generic "opacity" class, we configure the head to predict **three specific classes**: "Typical", "Indeterminate", and "Atypical". This allows the model to inherently learn the study-level features within the bounding box detection task itself.
-   **One-Stage Design**: By predicting bounding boxes and class probabilities directly from a dense grid in a single forward pass, this model avoids the computational overhead of the Region Proposal Network (RPN) used in Idea 1.

#### **Data**
1.  **Label Mapping**: We merge the study-level and image-level metadata.
    -   If a study is labeled "Typical Appearance", all bounding boxes in its images are assigned the class label **"Typical"**.
    -   The same logic applies to "Indeterminate" and "Atypical" labels.
    -   Studies labeled "Negative for Pneumonia" are treated as **background samples** (images with no bounding boxes), teaching the model to predict nothing when no opacities are present.
2.  **Preprocessing**: All DICOM images are resized to a standard resolution of **640x640** pixels. Pixel values are normalized to the [0, 1] range.
3.  **Augmentation**: We utilize standard lightweight detection augmentations, specifically **Mosaic** (combining 4 training images into one) and horizontal flipping, to improve the model's ability to detect objects at various scales without increasing the dataset size.

#### **Training**
-   **Loss Function**: The model is trained using the compound YOLOv8 loss:
    -   **CIoU Loss** (Complete Intersection over Union) for precise bounding box regression.
    -   **Distribution Focal Loss (DFL)** for class prediction, dealing with class imbalance between the opacity types.
-   **Optimization**: We use the **Adam** optimizer with a linear warmup followed by a cosine annealing learning rate schedule. We initialize the model with pre-trained COCO weights to accelerate convergence and train for a limited epoch count (e.g., 10-15 epochs) to satisfy runtime constraints.

#### **Evaluation**
1.  **Inference**: For each test image, the model predicts a list of bounding boxes, each with a class ("Typical", "Indeterminate", or "Atypical") and a confidence score.
2.  **Study-Level Logic**:
    -   If **no boxes** are detected above a confidence threshold (e.g., 0.25), the study is classified as **"Negative"**.
    -   If boxes are detected, the study label is determined by the **class of the highest-confidence bounding box**.
3.  **Image-Level Logic**:
    -   All detected boxes are collected. Their specific class labels (e.g., "Typical") are mapped back to the generic **"opacity"** string required by the submission format.
    -   If no boxes are detected, the prediction string is set to **"none 1 0 0 1 1"**.
