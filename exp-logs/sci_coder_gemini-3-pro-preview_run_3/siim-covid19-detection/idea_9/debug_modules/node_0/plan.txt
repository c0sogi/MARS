The following script demonstrates the end-to-end usage of the provided library for the COVID-19 radiography task.

**Implementation Strategy:**
1.  **Configuration**: We override `Config` parameters to enable `DEBUG` mode (using a small subset of data), reduce `BATCH_SIZE` to 2, and set `EPOCHS` to 1. This ensures the script runs quickly and fits within memory constraints while verifying the pipeline.
2.  **Data Loading**: We utilize `get_dataloader` to create training and validation loaders. We fetch a single batch to verify the tensor shapes of images and the structure of the targets (bounding boxes and study labels).
3.  **Model Initialization**: We instantiate the `SwinDyHeadNet` model. We perform a forward pass with the fetched batch to verify that the output dictionary contains the expected keys (`cls_logits`, `bbox_preds`, `study_logits`) and that the tensor dimensions match the anchor generation logic.
4.  **Loss Calculation**: We initialize the `Criterion` and compute the loss on the model outputs and targets. We assert that the total loss and individual components (classification, regression, study) are valid scalars.
5.  **Training Loop**: We set up the `Engine` with an optimizer and run `train_one_epoch` followed by `evaluate`. This verifies the backpropagation steps, metric calculation (mAP), and the integration of the training engine.
6.  **Utility Verification**: We explicitly test the `weighted_boxes_fusion` function with synthetic data to ensure the post-processing logic for bounding boxes functions correctly.
