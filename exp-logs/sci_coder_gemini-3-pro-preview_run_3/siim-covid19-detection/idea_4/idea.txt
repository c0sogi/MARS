# Solution: Multi-Scale BiFPN Detection with Auxiliary Global Classification

## Model
I propose a **Multi-Task EfficientDet-D3** architecture. This represents a structural evolution from the ResNet-based Faster R-CNN (Idea 1) and the lightweight YOLOv8-Nano (Idea 2) by adopting a scalable EfficientNet backbone coupled with a **Bi-directional Feature Pyramid Network (BiFPN)**.

-   **Backbone & Neck**: The model uses **EfficientNet-B3** as the backbone to extract rich features, feeding into a **BiFPN** neck. Unlike the standard FPN used in Idea 1, BiFPN allows for weighted, bi-directional feature fusion, enabling the model to better handle opacities of varying sizes (multi-scale) which are common in COVID-19 progression.
-   **Dual-Head Design**:
    1.  **Detection Branch**: Standard EfficientDet box regression and classification sub-networks are used to predict bounding boxes for the generic "opacity" class.
    2.  **Global Classification Branch (Structural Innovation)**: I will attach a new auxiliary head to the deepest layer of the BiFPN (P7). This head consists of a Global Average Pooling layer followed by a dense layer to explicitly predict the four study-level categories ("Negative", "Typical", "Indeterminate", "Atypical"). This decouples the global diagnosis from local localization, allowing the model to learn study-level features (like diffuse patterns) that might not have distinct bounding boxes.

## Data
-   **Preprocessing (Aspect-Ratio Preservation)**: Addressing the critical failure identified in the previous iteration, I will implement **Letterbox Resizing** for all input images. Instead of simply stretching images to a fixed square resolution (which distorts the morphology of lung opacities), I will resize the image so that its longest dimension fits the target size (e.g., 640x640), and pad the shorter dimension with constant values (black/zero) to maintain the original aspect ratio **Cite solution_lesson_node_00010**.
-   **Augmentation**: I will employ **Mosaic Augmentation** (retained from Idea 2) to improve detection of small objects, along with random horizontal flips and mild contrast adjustments.
-   **Input Size**: The model will be trained at a resolution of **640x640**, balancing feature granularity with computational efficiency on the A100 GPU.

## Training
-   **Loss Function**: A multi-task loss function will be minimized:
    $$L_{total} = L_{box\_reg} + L_{box\_cls} + \lambda L_{study\_cls}$$
    -   $L_{box\_reg}$: CIoU or Huber loss for bounding box coordinates.
    -   $L_{box\_cls}$: Focal Loss for the "opacity" vs. background detection task.
    -   $L_{study\_cls}$: Cross-Entropy Loss for the 4-class study categorization.
    -   $\lambda$: A scalar weight (e.g., 1.0) to balance the global classification task with detection.
-   **Optimizer**: **AdamW** with a cosine annealing learning rate schedule.
-   **Strategy**: The backbone will be initialized with ImageNet weights. The entire network will be trained end-to-end.

## Evaluation
-   **Inference**: For each test image, the model performs a single forward pass to generate both bounding boxes and study-level probabilities.
-   **Prediction Logic**:
    1.  **Study Level**: The class with the highest probability from the Global Classification Branch is selected.
    2.  **Image Level**:
        -   If the Global Branch predicts "Negative for Pneumonia" with high confidence (e.g., > 0.5), the image prediction is forced to `none 1 0 0 1 1`.
        -   Otherwise, the predicted bounding boxes from the Detection Branch are subjected to Non-Maximum Suppression (NMS) and formatted as the "opacity" prediction string.
    3.  **Submission**: The study label (formatted as a 1-pixel box) and the image-level prediction string are combined for the final CSV.
