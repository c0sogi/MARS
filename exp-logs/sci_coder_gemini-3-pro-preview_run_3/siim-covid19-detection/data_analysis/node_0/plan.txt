I will implement a robust EDA script that analyzes the chest radiograph dataset. The strategy involves loading the pre-generated training metadata, analyzing the distribution of study-level classification labels and image-level bounding boxes, and extracting technical image properties (dimensions, pixel intensity statistics) from the DICOM files. To ensure efficiency within the time limit, I will process DICOM metadata for the entire training set but calculate pixel-level statistics on a representative sample using parallel processing. Finally, I will explore relationships between these image meta-features and the diagnostic labels.
