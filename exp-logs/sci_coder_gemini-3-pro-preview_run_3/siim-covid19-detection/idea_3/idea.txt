### Idea 3: Multi-Task U-Net Segmentation

This approach utilizes a **segmentation-based** paradigm, treating the detection of opacities as a pixel-wise classification problem rather than a bounding-box regression task. This fundamentally differs from the region-based (Idea 1) and grid-based (Idea 2) object detectors by focusing on the semantic shape of the findings.

#### **Model**
We will employ a **U-Net** architecture, a standard choice for biomedical image segmentation, adapted for multi-task learning.
-   **Backbone (Encoder)**: We use a pre-trained **MobileNetV2** as the encoder. This lightweight CNN progressively downsamples the image to capture semantic context and provides a compact bottleneck feature map.
-   **Decoder**: The decoder upsamples the bottleneck features, concatenating them with skip connections from the encoder layers to recover spatial details lost during downsampling.
-   **Segmentation Head (Image-Level)**: The final decoder layer feeds into a 1x1 convolution with a Sigmoid activation, outputting a **binary probability mask** (same resolution as input) where each pixel represents the confidence of an opacity being present.
-   **Classification Head (Study-Level)**: To predict the specific study category, we attach a Global Average Pooling layer to the encoder's bottleneck, followed by a dense layer with Softmax activation. This predicts the four study-level classes ("Negative", "Typical", "Indeterminate", "Atypical") based on the global context of the image.

#### **Data**
1.  **Mask Generation**: We convert the provided bounding box annotations into binary ground-truth masks. For each image, we create a black canvas and fill the regions defined by the bounding boxes with white (1s). Images with "none" labels result in empty black masks (0s).
2.  **Preprocessing**: Images are resized to **512x512** pixels to balance spatial resolution with memory efficiency. Pixel intensities are normalized to [0, 1].
3.  **Augmentation**: We apply spatial augmentations such as rotation, scaling, and horizontal flipping to encourage the model to learn robust shape features.

#### **Training**
-   **Loss Function**: We use a combined loss function: $L_{total} = L_{Dice} + L_{Class}$.
    -   **Dice Loss ($L_{Dice}$)**: Optimizes the overlap between the predicted segmentation mask and the ground truth mask, handling the class imbalance between background (majority) and opacity pixels effectively.
    -   **Cross-Entropy Loss ($L_{Class}$)**: Supervises the study-level classification head.
-   **Optimization**: The model is trained using the **Adam** optimizer. We freeze the MobileNetV2 encoder weights for the first few epochs to stabilize the decoder weights, then unfreeze for fine-tuning.

#### **Evaluation**
1.  **Inference**: The model outputs a probability mask and a study-level class probability vector for each test image.
2.  **Box Generation**:
    -   We threshold the predicted mask (e.g., >0.5) to obtain a binary map.
    -   We use **contour detection** (e.g., OpenCV's `findContours`) to identify isolated regions of opacity.
    -   A bounding rectangle is computed for each contour to generate the final box coordinates (`xmin`, `ymin`, `xmax`, `ymax`).
    -   The confidence score for each box is calculated as the mean pixel probability within that contour.
3.  **Prediction Logic**:
    -   **Study Label**: We select the class with the highest probability from the classification head.
    -   **Consistency Check**: If the classification head predicts "Negative", we override the segmentation output and predict "none 1 0 0 1 1". Otherwise, we submit the generated bounding boxes with the generic "opacity" label.
