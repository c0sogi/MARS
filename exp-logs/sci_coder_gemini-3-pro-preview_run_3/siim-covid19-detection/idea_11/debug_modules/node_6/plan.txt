The issue is that the training and evaluation loops blindly attempt to move all values in the `targets` dictionary to the GPU using `.to(device)`, but the dictionary contains string metadata (like `image_id` and `study_id`) which do not support this method. To fix this, we must check if a value is an instance of `torch.Tensor` before attempting to move it to the device, ensuring that non-tensor metadata is preserved without causing a crash.
