The following script demonstrates the usage of the provided library modules to train a model on a small subset of data and run inference. It overrides the default configuration to ensure the process completes quickly within the demo environment.

1.  **Configuration**: Modifies the `Config` class to enable debug mode (limiting dataset size), reduces epochs to 1, and redirects output to a demo directory.
2.  **Dataset**: Instantiates the `ChestXrayDataset` to verify data loading and transformation logic.
3.  **Model & Loss**: Builds the Co-DETR model and the loss criterion, performing a dummy forward pass and loss calculation to verify tensor shapes and gradients.
4.  **Engine**: Uses the `Engine` class to execute a full training epoch and an inference run, generating a submission file.
5.  **Verification**: Includes assertions throughout to ensure files are created and outputs match expected dimensions.
