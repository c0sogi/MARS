The error `KeyError: 'height'` occurs because the metadata CSV files generated by the setup script do not contain `height` and `width` columns, yet the `ChestXrayDataset` attempts to access them to populate the `orig_size` target. To fix this, I will modify `library/dataset.py` to extract the original image dimensions (`orig_h`, `orig_w`) directly from the loaded image array (`image.shape`) immediately after reading the DICOM file. This ensures that the dimensions are always available and consistent with the actual image data processed, aligning with **Debug Lesson 9** (Synchronize Fallback Image Dimensions) by ensuring metadata matches the physical image even in fallback scenarios.
