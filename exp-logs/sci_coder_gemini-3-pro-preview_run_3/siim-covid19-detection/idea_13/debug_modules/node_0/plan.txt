This script demonstrates the end-to-end usage of the provided library for the chest radiograph classification and detection task. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to run in a lightweight "demo" mode (reduced image size, fewer epochs, debug data subset) to ensure execution within the time limit.
2.  **Dataset Initialization**: Loads the training and validation datasets using `SIIMDataset` and verifies the data shapes and formats.
3.  **Model Instantiation**: Builds the `MultiTaskDINO` model (Backbone + DINO + Diagnosis Module) using `build_model`.
4.  **Training Simulation**: Runs a single epoch of training using `train_one_epoch` to demonstrate the optimization loop and loss calculation.
5.  **Evaluation Simulation**: Runs a validation pass using `evaluate` to compute metrics (mAP and accuracy).
6.  **Inference Demonstration**: Simulates the inference process on the test set, showing how predictions are generated and formatted.
