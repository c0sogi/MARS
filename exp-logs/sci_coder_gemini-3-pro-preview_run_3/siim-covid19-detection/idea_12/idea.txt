# Idea 12: Multi-Task DINO with Dual-Stream Geometric-Semantic Reasoning

## Model
I propose a **Multi-Task DINO (DETR with Improved DeNoising Anchor Boxes)** architecture. This represents a structural evolution from the standard Deformable DETR (Idea 8) and Co-DETR (Idea 10) by leveraging the state-of-the-art DINO framework, while introducing a novel reasoning head to explicitly address the complex mapping between local findings and global study labels.

-   **Backbone**: I will utilize a **Swin Transformer Large (Swin-L)** backbone. This hierarchical vision transformer provides the necessary capacity to capture both fine-grained details (essential for small opacity detection) and global context (essential for distinguishing diffuse viral patterns).
-   **Detector Core**: The model employs the **DINO** decoder. DINO improves upon standard DETR by using a mixed query selection strategy and contrastive denoising training, which significantly stabilizes convergence and improves localization precision.
-   **Study Classification Head (Structural Innovation)**: Instead of a simple pooling layer or a generic transformer head (as in Idea 11), I will implement a **Dual-Stream Reasoning Module** attached to the output of the DINO decoder.
    1.  **Semantic Stream**: This branch takes the **Object Query Embeddings** (which contain the visual/texture information of detected objects) and processes them via a Self-Attention layer. This learns dependencies related to the *nature* of the opacities (e.g., ground-glass vs. consolidation).
    2.  **Geometric Stream**: This branch takes the **Predicted Bounding Box Coordinates** and processes them via a lightweight MLP. This explicitly models the *spatial configuration* of the findings (e.g., bilateral distribution, peripheral location), which is a key clinical criterion for differentiating "Typical" from "Indeterminate" COVID-19 appearances.
    3.  **Fusion**: The outputs of both streams are concatenated and fed into a final classifier to predict the four study-level categories. This design forces the model to synthesize both the "what" (visual features) and the "where" (spatial distribution) for diagnosis.

## Data
-   **Preprocessing (Strategic Retention)**: I will strictly implement **Letterbox Resizing** for all training and test images. Instead of blindly resizing images to a fixed square (which distorts shapes), I will resize the longest dimension to the target size (e.g., 1024 pixels) and pad the shorter dimension with zeros. This preserves the original aspect ratio of the radiographs, preventing the morphological distortion of lung opacities that was identified as a critical failure mode **Cite solution_lesson_node_00010**.
-   **Augmentation**: I will employ **Large Scale Jittering (LSJ)**, which resizes images within a wide scale range (0.1 to 2.0) followed by cropping, alongside **Random Horizontal Flipping**. I will explicitly exclude "Mosaic" augmentation to preserve the global anatomical structure required for the Geometric Stream to learn valid spatial dependencies.

## Training
-   **Loss Function**: The model will be trained end-to-end using a multi-task objective:
    -   **Detection Loss**: A combination of **Focal Loss** (for class labels), **L1 Loss** (for box coordinates), and **GIoU Loss** (for box overlap).
    -   **Study Loss**: **Cross-Entropy Loss** applied to the output of the Dual-Stream Reasoning Module.
    -   **Contrastive DeNoising (CDN)**: I will use DINO's denoising training strategy, feeding noisy ground-truth boxes into the decoder to accelerate bipartite matching convergence.
-   **Optimizer**: **AdamW** with a layer-wise learning rate decay (lower rates for the backbone) to fine-tune the Swin-L backbone effectively.

## Evaluation
-   **Inference**: A single forward pass generates the study-level probabilities (via the Reasoning Module) and image-level bounding boxes (via the DINO decoder).
-   **Prediction Logic**:
    1.  **Study Level**: The label is determined by the argmax of the Dual-Stream Reasoning Module's output.
    2.  **Image Level**:
        -   If the predicted Study Label is "Negative for Pneumonia", the image prediction is forced to `none 1 0 0 1 1`.
        -   Otherwise, the bounding boxes predicted by the DINO decoder are used. Since DINO performs one-to-one set prediction, **Non-Maximum Suppression (NMS) is not required**, and the raw boxes are formatted as the "opacity" prediction string.
