The issue is a tensor layout mismatch between the Swin Transformer backbone (which outputs Channel-Last format `(N, H, W, C)`) and the Deformable DETR detection head (which expects Channel-First format `(N, C, H, W)`). As identified in the error analysis and **Cite debug_lesson_11**, simply plugging a Transformer backbone into a CNN-based head without permuting the dimensions causes convolution layers to misinterpret spatial dimensions as channels.

To fix this, I will introduce a `SwinBackboneWrapper` class in `library/model.py` that intercepts the backbone's output and permutes the feature maps to the correct `(N, C, H, W)` layout before passing them to the detection head. I will then apply this wrapper in the `MultiTaskDINO` initialization if a Swin backbone is detected.
