The `RuntimeError` is caused by a dimension mismatch between the feature maps extracted from the Swin Transformer backbone and the position embeddings generated by the `transformers` library. Specifically, the Swin backbone outputs tensors in Channel-Last format `(N, H, W, C)`. The `transformers` library incorrectly uses the last two dimensions `(W, C)` to generate the padding mask, resulting in a mask shape of `(N, W, C)` instead of `(N, H, W)`. Consequently, the position embeddings are generated for the wrong spatial dimensions (summing to 202,752 elements) while the feature maps are correctly permuted to `(N, C, H, W)` (summing to 92,565 elements).

To fix this, I will modify `SwinBackboneWrapper` in `library/model.py` to manually regenerate the padding mask (`p_mask`) by interpolating the original input `pixel_mask` to match the spatial dimensions of the permuted feature maps. This ensures the mask and features are aligned, allowing the position embeddings to be generated correctly.
