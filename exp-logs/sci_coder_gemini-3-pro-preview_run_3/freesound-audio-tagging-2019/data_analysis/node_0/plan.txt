The strategy for the Exploratory Data Analysis (EDA) script is as follows:

1.  **Setup and Loading**: Initialize the environment with fixed random seeds for reproducibility. Load the training metadata from `./metadata/train.csv`. This file contains the filenames, relative file paths, and ground truth labels.
2.  **Target Variable Analysis**: Parse the multi-label strings into individual labels. Calculate the frequency of each label to determine the distribution. Compute the class imbalance ratio (most frequent / least frequent) and identify the most and least common sound categories.
3.  **Audio Data Analysis**: Iterate through the training files referenced in the metadata. Use the `soundfile` library to efficiently read the header information of each `.wav` file (without loading the full audio data) to extract technical properties: Duration (seconds), Sample Rate (Hz), Channels (Mono/Stereo), and Bit Depth (Subtype).
4.  **Audio Statistics**: Aggregating the extracted audio properties to report descriptive statistics (mean, std, min, max) for duration, and frequency counts for sample rates, channel configurations, and bit depths.
5.  **Feature/Signal Relationships**:
    *   **Meta-Feature Analysis**: Analyze the relationship between audio duration and the number of labels per clip (complexity).
    *   **Class-Specific Analysis**: Determine if specific classes are associated with significantly longer or shorter audio clips compared to the global average.
6.  **Output**: Print the findings in a structured, readable format as specified, ensuring strict adherence to the read-only constraints of the input directory.
