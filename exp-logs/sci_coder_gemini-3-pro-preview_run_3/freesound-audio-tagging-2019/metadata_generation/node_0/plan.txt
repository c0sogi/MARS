The following Python script generates the required metadata files for the training, validation, and test datasets.

**Implementation Strategy:**
1.  **Data Loading & Cleaning**: The script reads the curated and noisy training CSVs. It removes the specific file identified as corrupted (`1d44b0bd.wav`) and the five files identified as having wrong labels to ensure data quality.
2.  **Path Construction**: It constructs relative file paths for all audio clips (e.g., `train_curated/filename.wav`) based on the directory structure provided.
3.  **Data Combination**: It merges the curated and noisy datasets into a single training pool. This is necessary to perform a global stratified split that respects the distribution of the entire provided training data.
4.  **Stratified Splitting**: Since this is a multi-label classification task, standard stratification is insufficient. The script uses `iterative_train_test_split` from `skmultilearn` to perform a robust multi-label stratified split (80% Train, 20% Validation), ensuring the validation set accurately reflects the label frequencies of the training data.
5.  **Metadata Generation**: It saves the resulting splits and the test set information into `train.csv`, `val.csv`, and `test.csv` within the `./metadata` directory.
6.  **Verification**: Finally, it runs the required checks:
    *   Prints summary statistics (shapes, unique label counts).
    *   Verifies that at least 50% of a random sample of 1000 file paths exist on the filesystem.
    *   Validates the stratification by calculating the correlation between the class distributions of the training and validation sets, raising an error if they diverge significantly.
