The error in `runfile.py` occurs because the `calculate_overall_lwlrap` function in `library/utils.py` computes the mean precision across all classes, including those that have no positive samples (zero support) in the ground truth. Including these absent classes (which have a score of 0.0) incorrectly deflates the final average score. As detailed in **Cite debug_lesson_1**, the metric should only average over classes that are actually present in the provided `truth` data.

To fix this, I will modify `calculate_overall_lwlrap` to calculate the support (counts) for each class and filter the per-class scores to exclude those with zero support before computing the mean.

def calculate_overall_lwlrap(truth, scores):
    """
    Calculates the overall label-weighted label-ranking average precision.

    Args:
        truth (np.array or torch.Tensor): Binary ground truth matrix.
        scores (np.array or torch.Tensor): Predicted probability matrix.

    Returns:
        float: The mean LWLRAP across all classes.
    """
    # Ensure inputs are numpy arrays for count calculation
    if torch.is_tensor(truth):
        truth = truth.cpu().numpy()

    per_class_score = calculate_per_class_lwlrap(truth, scores)

    # Only average over classes that are present in the ground truth
    class_counts = truth.sum(axis=0)
    mask = class_counts > 0

    if np.sum(mask) == 0:
        return 0.0

    return np.mean(per_class_score[mask])
