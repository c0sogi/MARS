Implementation strategy:
1.  **Configuration Override**: Modify `Config` parameters at runtime to ensure a fast execution (reduced epochs, increased batch size) while utilizing the powerful A100 GPU.
2.  **Training**: Initialize the `Trainer` and execute the training loop (`fit`). This will automatically handle data caching, model training, and saving the best checkpoint based on validation LWLRAP.
3.  **Validation**: Explicitly retrieve the validation dataloader and run a final validation pass using the best model weights to compute and print the exact `Final Validation Metric`.
4.  **Failure Analysis**: Iterate through the validation set with the trained model to compute the Binary Cross-Entropy loss for each sample. Correlate this error magnitude with input complexity proxies (number of labels and file size) to identify error patterns.
5.  **Submission**: Check if the validation metric exceeds the specified threshold (0.711...). If successful, generate predictions on the test set and save the `submission.csv`.
