The following script demonstrates the end-to-end usage of the provided breast cancer detection library.

**Implementation Strategy:**
1.  **Configuration Override**: We modify the `Config` class attributes at runtime to enable `DEBUG` mode, reduce the dataset size (20 samples), disable pretrained weights (to avoid network dependency/latency), and set `NUM_WORKERS` to 0 for immediate execution.
2.  **Data Loading**: We utilize `get_dataloaders` to process metadata and generate PyTorch DataLoaders. We verify the structure of a training batch (image lists and target dictionaries).
3.  **Model Instantiation & Forward Pass**: We initialize the `MilTransformerModel` and perform a forward pass with a real batch to verify output shapes for the multi-task heads (cancer, density, biopsy).
4.  **Training Simulation**: We initialize the `Trainer` and run `fit()` for a single epoch. We verify that the training loop completes and saves a model checkpoint.
5.  **Inference & Calibration**: We load the trained model, perform inference on the test set, apply the `calibrate_probabilities` function (log-odds correction), and format the results.
6.  **Metric Calculation**: We demonstrate the `pf1_score` function using the generated predictions and dummy ground truth to ensure the metric logic holds.
