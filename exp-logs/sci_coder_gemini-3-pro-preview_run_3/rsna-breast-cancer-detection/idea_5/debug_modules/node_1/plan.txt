The Multi-Instance Learning approach multiplies the effective batch size by the number of views per bag, exacerbating the memory pressure.

To resolve this, I will implement a targeted fix that reduces the memory footprint in two ways:
1.  **Reduce Batch Size:** I will lower the `BATCH_SIZE` in both `library/config.py` (default) and `runfile.py` (demo override) from 16/4 to 2.
2.  **Enable Mixed Precision Training (AMP):** I will modify `library/trainer.py` to use `torch.cuda.amp.GradScaler` and `autocast`. This significantly reduces activation memory usage without altering the model architecture.

I will also update the configuration to reflect the hardware constraints.
