This script implements the full pipeline for the "Analytically Calibrated EfficientNetV2" solution.

**Implementation Strategy:**
1.  **Configuration Override**: To ensure the code runs within the "fast baseline" time limit (2 hours), I override `Config.EPOCHS` to 2. This provides enough training signal to evaluate the method without exceeding the time budget.
2.  **Training**: I initialize the `Trainer` class from `library.train` and execute the `fit()` method. This handles the training loop, balanced sampling, and checkpointing of the best model based on the pF1 score.
3.  **Validation & Metric Calculation**:
    *   I load the best saved model checkpoint.
    *   I iterate through the validation set using the data loader (preserving order).
    *   I apply the **Analytical Prior Correction** (shifting logits based on the ratio of training prevalence to test prevalence) to the model outputs.
    *   I compute the **Probabilistic F1 (pF1)** score on the full validation set and print it in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   I merge the validation predictions with the metadata (`val_metadata.csv`).
    *   I calculate the absolute error (`|target - prediction|`) for each sample.
    *   I compute and print the Pearson correlation between this error and key features (`age`, `density`, `machine_id`) to identify sources of systematic bias. Categorical features like `density` are encoded numerically for this calculation.
5.  **Submission**:
    *   I compare the final validation metric against the threshold (`0.06310755014419556`).
    *   If the model performs well enough, I call `predict_and_submit` from `library.inference` to generate predictions for the test set and save `submission.csv`.
