The previous execution failed with a `torch.OutOfMemoryError` because the `EfficientNetV2-Small` model with a batch size of 32 and 640x640 resolution exceeds the available GPU memory when using standard float32 precision. To fix this without reducing the batch size (which would degrade training throughput), I will implement **Automatic Mixed Precision (AMP)** using `torch.amp.autocast` and `torch.amp.GradScaler`. This reduces memory usage by storing activations in half-precision (Cite debug_lesson_2).

I will modify `library/train.py` to use `GradScaler` for the backward pass and wrap the forward passes in `autocast`. I will also modify `library/inference.py` to use `autocast` during inference to ensure consistency and memory efficiency.
