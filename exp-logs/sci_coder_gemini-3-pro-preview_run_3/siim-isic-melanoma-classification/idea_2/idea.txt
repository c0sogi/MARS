# Proposed Strategy: Hybrid EfficientNet-B3 with Tabular Fusion

## Model
I propose a **Hybrid Vision-Tabular Architecture** to integrate the high-value metadata signals identified in the data analysis (specifically `age_approx`) with visual features.
*   **Visual Branch:** Upgrade the backbone from EfficientNet-B0 to **EfficientNet-B3**. This increases model capacity to capture finer dermatoscopic textures (like reticular networks) while remaining computationally efficient on the A100 GPU.
*   **Tabular Branch:** Implement a lightweight Multi-Layer Perceptron (MLP) to process the metadata (`age_approx`, `sex`, `anatom_site_general_challenge`). Categorical variables will be one-hot encoded, and numerical variables normalized.
*   **Fusion:** The output of the visual backbone (after Global Average Pooling) will be concatenated with the output of the tabular MLP. This combined feature vector will pass through a final fully connected layer to predict the malignancy probability.

## Data
*   **Resolution:** Increase the input image resolution from 224x224 to **384x384**. This higher resolution is critical for resolving small diagnostic features (e.g., dots and globules) that may be blurred at lower resolutions.
*   **Augmentation:**
    *   **Geometric Only:** Apply random horizontal/vertical flips and rotations. Explicitly **exclude** color augmentations (Hue/Saturation/Value) to preserve diagnostic chromatic signals. Cite {solution_lesson_node_00003}.
    *   **Scaled CoarseDropout:** Apply CoarseDropout with a hole size scaled proportionally to the new resolution (approx. 32-40 pixels). This maintains the effective occlusion ratio (~10%) found successful previously, while ensuring the holes remain smaller than the typical lesion ROI to prevent total occlusion of the diagnostic target. Cite {solution_lesson_node_00009} and Cite {solution_lesson_node_00006}.

## Training
*   **Loss Function:** Use **BCEWithLogitsLoss** with a **Dampened Positive Weight** (e.g., `pos_weight=15.0`). This value is significantly lower than the theoretical inverse class frequency (~55.0) to prevent gradient explosions and overfitting to noisy minority samples. Cite {solution_lesson_node_00004}.
*   **Optimizer:** Use **AdamW** with a standard weight decay of **0.01**. Avoid aggressive weight decay (e.g., 0.05) to allow the model to learn the large weights necessary for high-confidence logit predictions. Cite {solution_lesson_node_00005}.
*   **Scheduler:** Implement a Cosine Annealing Learning Rate scheduler to smoothly decay the learning rate, facilitating convergence into a robust minimum.

## Evaluation
*   **Inference:** Resize test images to 384x384 and normalize using the same statistics as the training set.
*   **Tabular Handling:** Preprocess test metadata identically to the training set (imputing missing values with training set statistics) to feed the tabular branch.
*   **Prediction:** Generate probabilities using the full hybrid model.
