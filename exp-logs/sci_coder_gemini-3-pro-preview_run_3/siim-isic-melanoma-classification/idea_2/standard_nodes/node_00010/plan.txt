The strategy for implementing the `runfile.py` script is as follows:

1.  **Setup and Configuration**: Import the necessary modules and the pre-defined library functions (`config`, `utils`, `dataset`, `model`, `train`). I will override the `EPOCHS` setting in the configuration to 5. This ensures the training completes quickly (satisfying the "fast baseline" and "limit training steps" requirements) while still processing the full dataset to achieve the high AUC target.
2.  **Data Loading**: Use `get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test data. I will also retrieve the processed metadata dataframe using `get_processed_metadata` to facilitate the required failure analysis later.
3.  **Model Initialization**: Instantiate the `HybridEfficientNet` using the metadata dimension obtained from the data loading step. Move the model to the detected GPU device.
4.  **Training Loop**: Implement a custom training loop for 5 epochs. In each epoch, I will:
    *   Run `train_one_epoch` to update model weights.
    *   Run `validate` to evaluate performance on the hold-out set.
    *   Update the learning rate scheduler.
    *   Save the model checkpoint if the validation AUC improves.
5.  **Failure Analysis**: After training, load the best model checkpoint. Perform a dedicated inference pass on the validation set to generate predictions. Calculate the absolute error between predictions and ground truth. Then, compute and print the correlation between these errors and the input metadata features (e.g., age, anatomical site) to identify sources of systematic error.
6.  **Final Evaluation and Submission**: Print the `Final Validation Metric` (AUC) with full precision. Compare this metric against the specified threshold (0.8860349415712139). If the model's performance exceeds this threshold, run the `inference` function on the test set to generate and save the `submission.csv` file.
