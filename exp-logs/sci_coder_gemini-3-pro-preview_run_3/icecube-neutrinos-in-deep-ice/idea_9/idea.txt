Based on the progression of previous experiments and the critical insights from **Lesson 00006**, **Lesson 00010**, and **Lesson 00014**, I propose the **Dual-Frame Hierarchical Graph Transformer (DF-HGT)**.

This strategy synthesizes the robust geometric alignment of the "Dual-Frame" approach (Idea 7) with the global context modeling of Transformers (Idea 5), while introducing a **hierarchical structure** to explicitly model the causal evolution of the neutrino track.

### Model
The architecture is a hybrid Geometric Deep Learning model that processes the event as a spatiotemporal sequence of local geometric clusters.

1.  **Dual-Frame Input Embedding (Cite Lesson 00014):**
    To address the learning difficulty of global rotational invariance, the model accepts a composite feature vector for each pulse. This vector concatenates:
    *   **Raw Coordinates:** $(x, y, z, t)$ to preserve absolute detector geometry and handle complex events where SVD fails.
    *   **Canonical Coordinates:** $(x', y', z')$ derived from SVD alignment. This provides the model with a simplified "standardized" view where the track is roughly aligned with the Z-axis.
    *   **Pulse Features:** Charge $q$ and auxiliary status.

2.  **Local Topological Backbone (Cite Lesson 00010):**
    The first stage is a **Dynamic Edge Convolution (DynEdge)** network.
    *   **Graph Construction:** It constructs a **Spatiotemporal k-NN graph** ($D^2 = \Delta \vec{x}^2 + \alpha \Delta t^2$) to link causally connected pulses, ensuring the topology respects the particle's motion.
    *   **Local Feature Extraction:** It computes edge features based on relative vectors in both Raw and Canonical frames, extracting dense local geometric descriptors (e.g., track linearity, local density).

3.  **Hierarchical Tokenization (Structural Innovation):**
    Instead of globally pooling the graph immediately (which destroys vector information, **Cite Lesson 00006**), the model applies a **Graph Clustering/Pooling** operation (e.g., k-means clustering on spatiotemporal coordinates or SAGPool). This reduces the cloud of $N$ pulses into a sequence of $M$ "Super-Nodes" (e.g., $M=16$), where each Super-Node represents a distinct segment of the track or a cluster of the cascade.

4.  **Global Causal Transformer:**
    These $M$ Super-Nodes are treated as tokens and fed into a **Transformer Encoder**.
    *   **Self-Attention:** This mechanism allows the model to learn the global dependencies between track segments (e.g., relating the "start" segment to the "end" segment) to resolve the directionality ($\vec{v}$ vs $-\vec{v}$) that scalar statistics miss (**Cite Lesson 00006**).
    *   **Positional Encoding:** Explicit time-based positional encodings are added to enforce the temporal order of the segments.

5.  **Vectorial Readout Head:**
    The output of the Transformer is aggregated via **Attention Pooling** (preserving the dominant directional signal) and passed to an MLP to regress the 3D unit vector $(n_x, n_y, n_z)$.

### Data
1.  **Geometry Merging:** Merge `sensor_geometry.csv` with pulse data to obtain physical coordinates.
2.  **Canonical Frame Computation (Cite Lesson 00014):**
    For every event:
    *   Compute the charge-weighted covariance matrix of pulse positions.
    *   Perform SVD to find the principal axis $\vec{v}_1$.
    *   **Orientation Correction:** Calculate the covariance between the projection of positions onto $\vec{v}_1$ and time $t$. If negative, flip $\vec{v}_1$ to align with time flow.
    *   Rotate the event to align $\vec{v}_1$ with the Z-axis to generate Canonical Coordinates $(x', y', z')$.
3.  **Spatiotemporal Sampling:**
    Sample a fixed number of pulses (e.g., $N=256$). Use a **Hybrid Strategy**: 50% highest charge (energy core) and 50% earliest time (track initiation) to ensure the causal structure is captured for the Transformer.

### Training
1.  **Loss Function:** **Cosine Similarity Loss** ($L = 1 - \vec{y}_{true} \cdot \vec{y}_{pred}$). This directly optimizes the angular alignment (the competition metric) and is superior to MSE for directional tasks (**Cite Lesson 00010**).
2.  **Optimizer:** **AdamW** with a **Cosine Annealing with Warm Restarts** scheduler. The restarts help the model escape local minima in the complex loss landscape of 3D rotations.
3.  **Strategy:** Train on GPU. The hierarchical reduction (Pooling -> Transformer) keeps the computational cost manageable while allowing the model to "see" the entire event evolution.

### Evaluation
1.  **Inference:**
    *   Load test batches.
    *   Compute SVD and generate Canonical Coordinates for each event.
    *   Construct the Dual-Frame input and pass through the DF-HGT model.
2.  **Prediction:**
    *   The model outputs the predicted vector $\vec{v}_{pred}$.
3.  **Post-Processing:**
    *   Normalize $\vec{v}_{pred}$ to unit length.
    *   Convert Cartesian components to spherical coordinates (`azimuth`, `zenith`) and generate the submission CSV.
