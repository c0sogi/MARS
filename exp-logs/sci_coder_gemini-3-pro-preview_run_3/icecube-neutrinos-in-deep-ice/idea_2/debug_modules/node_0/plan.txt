This script demonstrates the end-to-end usage of the provided library files for the neutrino direction prediction task. It covers:
1.  **Logic Verification**: Validating coordinate conversion and error computation utilities.
2.  **Data Loading**: Using the `FeatureEngineeringPipeline` to load a small debug subset of the data (bypassing cache to ensure the subset is generated).
3.  **Model Training**: Instantiating `VectorRegressor`, dynamically adjusting hyperparameters for speed, and training on the debug set.
4.  **Evaluation & Inference**: Calculating metrics on validation data and generating predictions for the test set.
