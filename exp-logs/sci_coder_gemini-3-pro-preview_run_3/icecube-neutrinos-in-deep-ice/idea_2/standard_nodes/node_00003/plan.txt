The implementation strategy follows these steps:
1.  **Setup & Initialization**: Set random seeds for reproducibility and define a debug sample size (500,000 events) to ensure the baseline runs within the allocated time limit while providing sufficient data for training.
2.  **Data Loading**: Utilize the provided `load_datasets` function to retrieve training, validation, and test splits. This leverages the pre-built feature engineering pipeline which computes aggregate statistics (charge, time, spatial distribution) for the neutrino events.
3.  **Model Training**: Instantiate and train the `VectorRegressor`. This class manages three independent LightGBM regressors to predict the $x, y, z$ components of the neutrino's direction vector. Training includes validation monitoring for early stopping.
4.  **Validation & Metric**: Perform inference on the validation set. Manually calculate the Mean Angular Error by computing the arccosine of the dot product between predicted and true unit vectors. This ensures we have access to individual error values and prints the metric in the required format.
5.  **Failure Analysis**: Create a DataFrame of validation features and their corresponding angular errors. Calculate Pearson correlations to identify which input features are most strongly associated with high prediction errors.
6.  **Submission Generation**: Predict direction vectors for the test set, convert these Cartesian vectors back to spherical coordinates (`azimuth`, `zenith`) using the provided utility, and save the final formatted CSV to the submission directory.
