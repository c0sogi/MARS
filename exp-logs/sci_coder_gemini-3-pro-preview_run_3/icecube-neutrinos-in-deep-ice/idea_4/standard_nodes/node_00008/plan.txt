Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration Override**: We will import `library.config` and override specific parameters (`EPOCHS`, `DEBUG_SAMPLE_SIZE`) to ensure the training runs quickly as a baseline (under 2 hours) while processing enough data to learn.
2.  **Data Loading**: We will use `library.data.get_dataloaders` with `load_cached_data=True` to efficiently load the training, validation, and test sets.
3.  **Model Training**: We will invoke `library.model.train_model`, which encapsulates the training loop, validation monitoring, and best-model checkpointing.
4.  **Validation & Metric**: After training, we will run a dedicated validation pass using `library.model.validate` to compute the Mean Angular Error. We will print this in the required format `Final Validation Metric: <value>`.
5.  **Failure Analysis**: We will perform a custom inference pass on the validation set to extract predictions, ground truth, and event features (pulse count, max charge). We will calculate the angular error per event and compute Pearson correlations to identify error sources.
6.  **Conditional Submission**: We will compare the validation metric against the threshold (`1.5329564173900305`). If the model performs well enough, we will generate the submission file using `library.model.generate_submission`.
