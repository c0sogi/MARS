The implementation strategy involves creating a single Python script that imports the provided library modules and systematically demonstrates their functionality.

1.  **Configuration Override**: We will first override the default `Config` parameters to enable `DEBUG` mode, reduce the number of epochs to 1, and set a specific working directory. This ensures the script runs quickly (within minutes) and does not interfere with existing data.
2.  **Component Verification**:
    *   **Utils**: We will verify the sensor geometry loading and the mathematical correctness of the angular conversion functions and the canonical frame rotation matrix (checking for orthogonality and determinant).
    *   **Dataset**: We will instantiate the `IceCubeDataset` in debug mode, fetch a sample, and assert that the input feature dimensions (9 channels) and target shapes are correct.
    *   **Model**: We will instantiate the `DFCGN` model, pass a small batch of data through it, and verify the output shape. We will also compute the loss and metric to ensure they return valid scalar values.
3.  **Pipeline Execution**:
    *   **Training**: We will call `train_model()` to run a single epoch of training on the subset and verify that the model checkpoint is saved.
    *   **Inference**: We will call `predict_and_submit()` to generate predictions on the test subset and verify that the submission CSV is created with the correct schema.
