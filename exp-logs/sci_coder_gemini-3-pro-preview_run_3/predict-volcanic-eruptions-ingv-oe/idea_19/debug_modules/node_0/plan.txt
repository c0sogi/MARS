The following script demonstrates the usage of the provided library modules to perform the volcano eruption prediction task. It covers the end-to-end workflow: loading data and extracting features (using a small subset for speed), training a single LightGBM model, running a cross-validation loop, and generating a submission file.

The script overrides default hyperparameters (like `n_estimators`) to ensure execution completes quickly while validating the logic of the feature engineering and model training pipelines.
