The following script demonstrates the end-to-end usage of the provided library components for the volcano eruption prediction task. It covers feature engineering on raw sensor data, parallel data loading with caching, stratified cross-validation training using LightGBM, and generating predictions with an ensemble.

To ensure the demonstration runs quickly and robustly within the provided environment:
1.  **Configuration Override**: We modify the global `Config` class to use a temporary working directory, reduce the number of boosting rounds, decrease model complexity (leaves/bins) to suit the small demo dataset, and limit the number of cross-validation folds.
2.  **Data Subsampling**: We utilize the `debug_size` parameter in the data loader to process only a small fraction of the training and test sets (20 and 5 samples, respectively).
3.  **Validation**: Assertions are placed after every major step to verify data shapes, feature existence, and prediction outputs.
4.  **Reproducibility**: Random seeds are fixed at the start.
