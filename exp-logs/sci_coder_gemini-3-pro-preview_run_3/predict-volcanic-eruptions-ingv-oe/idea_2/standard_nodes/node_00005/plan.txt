The implementation strategy follows the provided instructions and leverages the pre-built library modules to execute the Time-Frequency Spectral Fingerprinting idea.

1.  **Data Loading**: The script uses `library.data_loader.build_dataset` to load training and validation data. It utilizes the caching mechanism (`load_cached_data=True`) to avoid redundant feature extraction if the parquet files already exist in `./working/idea_2`.
2.  **Feature Preparation**: It separates features and targets using `library.data_loader.prepare_features_target`.
3.  **Model Training**: It calls `library.model_trainer.train_regressor`. To ensure a fast baseline while maintaining performance, `n_estimators` is set to 5000 (half the config default, but sufficient for convergence given the learning rate).
4.  **Validation**: The script prints the `Final Validation Metric` as required.
5.  **Failure Analysis**: It computes the absolute errors on the validation set and calculates the Pearson correlation between these errors and the input features to identify which signal characteristics are most associated with prediction difficulty.
6.  **Submission**: It checks the validation MAE against the specified threshold (4,164,831.55). If the model performs well enough, it loads the test set and generates the submission file using `library.model_trainer.generate_submission`.
