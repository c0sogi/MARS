The issue is located in the `preprocess_signal` function within `library/features.py`. When a sensor column contains only missing values (NaNs), `df.mean()` returns `NaN` for that column. Consequently, `df.fillna(df.mean())` fails to replace the NaNs, leaving them in the DataFrame. This causes `scipy.signal.detrend` to raise a `ValueError` because it requires input arrays to be free of NaNs and Infs. To fix this, I will modify the imputation line to chain a `.fillna(0)` call, ensuring that any columns remaining as NaN (due to being entirely empty) are filled with 0 before signal processing proceeds.
