Implementation strategy:
1.  **Setup and Configuration**: Initialize the environment by setting random seeds for reproducibility. Modify the `config.LGBM_PARAMS` at runtime to ensure the model training is fast and fits within the time limits (reducing estimators, adjusting learning rate).
2.  **Data Processing**: Use `library.data_processor.process_set` to load (or compute) features for the training set (`train.csv`) and the hold-out validation set (`val.csv`). This leverages the provided caching mechanism.
3.  **Model Training**: Execute `library.trainer.run_cross_validation` using only the training data. This produces an ensemble of 5 LightGBM models.
4.  **Validation**: Use the trained ensemble to predict on the hold-out validation set. Compute the Mean Absolute Error (MAE) as the "Final Validation Metric".
5.  **Failure Analysis**: Calculate the absolute errors for the validation set and compute correlations between these errors and the input features to identify sources of inaccuracy.
6.  **Submission**: Check if the validation MAE is below the specified threshold. If so, process the test set (`test.csv`) and generate the submission file using `library.trainer.generate_submission`.
