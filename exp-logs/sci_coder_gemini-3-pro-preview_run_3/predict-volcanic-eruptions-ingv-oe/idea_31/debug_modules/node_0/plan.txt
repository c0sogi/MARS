This script demonstrates the end-to-end usage of the provided library modules for the seismic eruption prediction task. It performs the following steps:

1.  **Configuration Override**: Modifies the global configuration in `library.config` to use a temporary working directory, reduce model complexity (fewer trees, smaller leaves), and set the number of folds to 2. This ensures the demo runs quickly and produces reproducible results.
2.  **Feature Extraction Verification**: Manually loads a single sensor file and runs the `extract_segment_features` function from `library.features` to verify that feature engineering logic produces the expected output format and data types.
3.  **Data Processing**: Uses `library.data_processor` to process a small subset (sample) of the training and validation metadata. It validates that the resulting feature matrices contain the correct columns and no missing values.
4.  **Model Training**: Combines the processed training and validation data and runs the cross-validation pipeline using `library.trainer`. It asserts that the expected number of models are trained and saved as artifacts.
5.  **Inference & Submission**: Executes the inference pipeline using `library.inference`, which processes a sample of the test set, loads the trained models, generates predictions, and saves a submission file.
6.  **Final Validation**: Checks the generated submission file for the correct format and dimensions.
