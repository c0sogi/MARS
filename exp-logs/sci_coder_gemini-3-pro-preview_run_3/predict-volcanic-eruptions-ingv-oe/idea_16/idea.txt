Based on the progression of empirical findings—specifically the success of signal decomposition (Lesson 00049) and the identified overfitting risks of temporal flattening in random crops (Lesson 00050)—I propose the **Shift-Invariant Orthogonal Decomposition with Optimized Gradient Boosting** strategy.

This approach structurally evolves the solution by resolving the contradiction between "capturing temporal evolution" and "arbitrary time cropping." It synthesizes the **Orthogonal Decomposition** pipeline (Trend vs. Texture vs. Energy) with a **Shift-Invariant Temporal Aggregation** scheme, ensuring the model learns robust signal characteristics rather than memorizing noise at specific window indices.

# Model
The predictive core will be a **Single, Highly-Optimized LightGBM Regressor**.
*   **Rationale:** Extensive experimentation has demonstrated that a single, well-tuned Gradient Boosted Decision Tree (GBDT) outperforms complex Stacking Ensembles of under-optimized base learners (Cite solution_lesson_node_00046). By concentrating computational resources on tuning one strong backbone (optimizing `num_leaves`, `learning_rate`, and `min_data_in_leaf`), we avoid the variance and "weak learner" pitfalls observed in previous ensemble attempts.

# Data
The data processing pipeline is designed to extract physically meaningful signal components while strictly enforcing shift invariance to prevent overfitting.

1.  **Preprocessing:**
    *   **Imputation:** Fill missing values with the segment-wise column mean to preserve DC offsets (Cite solution_lesson_node_00002).
    *   **Orthogonal Decomposition:** For each sensor, generate three distinct signal views (Cite solution_lesson_node_00049):
        *   **View A (Trend):** Apply a **Savitzky-Golay filter** with a **large window size (> 20)**. This isolates low-frequency kinematic motion.
        *   **View B (Texture):** Compute residuals ($Texture = Raw - Trend$). This isolates high-frequency tremors and noise structure.
        *   **View C (Energy):** Retain the original **Raw** signal.

2.  **Feature Engineering (The Shift-Invariant Paradigm):**
    *   **From View A (Trend):** Compute **First (Velocity)** and **Second (Acceleration)** derivatives. Extract **Quantiles (1st, 99th)**, Mean, and Std.
        *   *Benefit:* Captures pure kinematic evolution without noise amplification (Cite solution_lesson_node_00021, solution_lesson_node_00026).
    *   **From View B (Texture):** Extract **Higher-Order Moments (Skewness, Kurtosis)** and **Wavelet Energy** (using DWT).
        *   *Benefit:* Captures the "roughness" and harmonic complexity of the seismic event (Cite solution_lesson_node_00049).
    *   **From View C (Energy):** Extract **Global Minimum**, **Global Maximum**, and **Peak-to-Peak Range**.
        *   *Benefit:* Strictly preserves the absolute intensity of the event, correcting the failure of robust statistics to capture critical outliers (Cite solution_lesson_node_00031).
    *   **From View C (Spectral):** Compute **PSD Band Power** (Low/Mid/High) and **Spectral Centroid** (Cite solution_lesson_node_00007).
    *   **Shift-Invariant Temporal Statistics (Structural Innovation):**
        *   Divide the signal (from View C) into $N$ non-overlapping windows.
        *   Compute statistics (RMS, Mean) for each window.
        *   **Crucial Step:** Instead of flattening these into distinct features (e.g., `win1_rms`, `win2_rms`), calculate **Aggregated Distributional Statistics** across the windows (e.g., `mean_of_window_means`, `std_of_window_rms`, `min_of_window_rms`).
        *   *Rationale:* This captures the *volatility* and *variability* of the signal over time without forcing the model to look for patterns at specific absolute positions, which leads to overfitting in arbitrary temporal crops (Cite solution_lesson_node_00050).

3.  **Feature Organization:**
    *   **Spatial Concatenation:** Concatenate the feature vectors of all 10 sensors side-by-side. Do **not** aggregate features across sensors (Cite solution_lesson_node_00018).
    *   **No External Selection:** Feed the full feature set to the model. Do **not** use RFE (Cite solution_lesson_node_00017).

# Training
*   **Strategy:** Use **Stratified K-Fold Cross-Validation** (e.g., 5 or 10 folds) based on the provided metadata bins.
*   **Objective:** Minimize **Mean Absolute Error (MAE)**.
*   **Optimization:**
    *   Set a high `n_estimators` (e.g., 5,000+) to ensure convergence (Cite solution_lesson_node_00002).
    *   Implement **Early Stopping** based on the validation set MAE.
    *   Focus hyperparameter tuning on regularization (`lambda_l1`, `lambda_l2`) and tree complexity (`num_leaves`) to handle the rich feature set effectively.

# Evaluation
1.  **Feature Extraction:** Process the test set using the Shift-Invariant Orthogonal Decomposition pipeline (Imputation -> Trend/Texture/Energy Separation -> Feature Extraction with Aggregated Windows -> Concatenation).
2.  **Inference:** Generate predictions using the trained LightGBM model.
3.  **Submission:** Format the output as `segment_id,time_to_eruption`.
