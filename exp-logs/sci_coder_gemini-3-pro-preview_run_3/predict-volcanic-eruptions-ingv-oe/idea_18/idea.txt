Based on the progression of empirical findings—specifically the success of **Orthogonal Signal Decomposition** (Idea 15, MAE ~2.61M) and the critical failures regarding temporal flattening (Lesson 00050), spectral noise (Lesson 00054), and open-ended filtering (Lesson 00058)—I propose the **Robust Shift-Invariant Orthogonal Decomposition** strategy.

This approach structurally evolves the "Current Best" solution by resolving the contradiction between capturing temporal evolution and avoiding overfitting to random crops. It synthesizes the **Signal Decomposition** pipeline with **Shift-Invariant Temporal Profiling** and **Physically-Constrained Spectral Analysis**, wrapped in a single optimized Gradient Boosting model.

# Model
The predictive core will be a **Single, Highly-Optimized LightGBM Regressor**.
*   **Rationale:** Extensive experimentation has demonstrated that a single, well-tuned Gradient Boosted Decision Tree (GBDT) outperforms complex Stacking Ensembles of under-optimized base learners (Cite solution_lesson_node_00046). We will focus computational resources on tuning `num_leaves`, `learning_rate`, and `min_data_in_leaf` for this specific feature set rather than managing the variance of a heterogeneous stack (Cite solution_lesson_node_00008).

# Data
The data processing pipeline is designed to extract physically meaningful signal components while strictly enforcing shift invariance and noise suppression.

1.  **Preprocessing:**
    *   **Imputation:** Fill missing values with the segment-wise column mean to preserve DC offsets (Cite solution_lesson_node_00002).
    *   **Orthogonal Decomposition:** For each sensor, generate three distinct signal views (Cite solution_lesson_node_00049):
        *   **View A (Trend):** Apply a **Savitzky-Golay filter** with a **large window size (> 20)** (e.g., window=51, poly=3). This isolates low-frequency kinematic motion.
        *   **View B (Texture):** Compute the **Residuals** ($Texture = Raw - Trend$). This isolates high-frequency tremors and noise structure.
        *   **View C (Energy):** Retain the original **Raw** signal.

2.  **Feature Engineering (The Shift-Invariant Paradigm):**
    *   **From View A (Trend - Kinematics):** Compute **First (Velocity)** and **Second (Acceleration)** derivatives. Extract **Quantiles (1st, 5th, 95th, 99th)**, Mean, and Std.
        *   *Benefit:* Captures pure kinematic evolution using robust shape descriptors (Cite solution_lesson_node_00026), avoiding the noise amplification of raw derivatives (Cite solution_lesson_node_00006).
    *   **From View B (Texture - Roughness):** Extract **Higher-Order Moments (Skewness, Kurtosis)** and **Wavelet Energy** (using Discrete Wavelet Transform).
        *   *Benefit:* Captures the "roughness" and harmonic complexity of the seismic event on the residual stream, where this information is cleanest (Cite solution_lesson_node_00049).
    *   **From View C (Energy - Intensity):** Extract **Global Minimum**, **Global Maximum**, and **Peak-to-Peak Range**.
        *   *Benefit:* Strictly preserves the absolute intensity of the event, correcting the failure of robust statistics to capture critical outliers (Cite solution_lesson_node_00031).
    *   **From View C (Spectral Structure):** Compute **Power Spectral Density (PSD)** using **Welch's Method**. Extract **Band Power** using **Explicit Closed Intervals** (e.g., 0.1-3Hz, 3-10Hz, 10-45Hz) and **Spectral Centroid**.
        *   *Constraint 1:* Use Welch's method to ensure stability, avoiding the noise of Raw Periodograms (Cite solution_lesson_node_00054).
        *   *Constraint 2:* Use closed band-pass filters to avoid fitting to high-frequency system noise, correcting the failure of open-ended filters (Cite solution_lesson_node_00058).
    *   **From View C (Shift-Invariant Temporal Profiling):**
        *   Divide the signal into $N$ non-overlapping windows.
        *   Compute statistics (RMS, Mean) for each window.
        *   **Structural Innovation:** Instead of flattening these into distinct features (e.g., `win1_rms`), calculate **Aggregated Distributional Statistics** *across* the windows (e.g., `mean_of_window_means`, `std_of_window_rms`, `range_of_window_rms`).
        *   *Benefit:* This captures the *volatility* and *variability* of the signal over time without forcing the model to look for patterns at specific absolute positions, preventing the overfitting observed with flattened windows on random crops (Cite solution_lesson_node_00050).

3.  **Feature Organization:**
    *   **Spatial Concatenation:** Concatenate the feature vectors of all 10 sensors side-by-side. Do **not** aggregate features across sensors (Cite solution_lesson_node_00018).
    *   **No External Selection:** Feed the full feature set to the model. Do **not** use RFE (Cite solution_lesson_node_00017).

# Training
*   **Strategy:** Use **Stratified K-Fold Cross-Validation** (e.g., 5 folds) based on the provided metadata bins.
*   **Objective:** Minimize **Mean Absolute Error (MAE)**.
*   **Optimization:**
    *   Set a high `n_estimators` (e.g., 5,000+) to ensure convergence (Cite solution_lesson_node_00002).
    *   Implement **Early Stopping** based on the validation set MAE.
    *   Tune `num_leaves` (start > 64) and `reg_alpha`/`reg_lambda` to handle the rich feature set effectively.

2.  **Inference:** Generate predictions using the trained LightGBM model.
3.  **Submission:** Format the output as `segment_id,time_to_eruption`.
