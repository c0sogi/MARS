The following script implements the end-to-end pipeline for the Volcano Eruption Prediction task. It leverages the provided library modules to perform feature engineering, model training, and evaluation.

The implementation follows these steps:
1.  **Data Loading**: It uses `library.feature_engineering.generate_features` to load the training, validation, and test datasets. This function handles reading metadata, processing sensor logs, and caching features to Parquet files for efficiency.
2.  **Preprocessing**: Feature matrices and target vectors are extracted from the DataFrames.
3.  **Training**: The `VolcanoLGBM` model is initialized and trained using the training set, with the validation set used for early stopping.
4.  **Evaluation**: The script calculates the Mean Absolute Error (MAE) on the hold-out validation set and prints it in the required format.
5.  **Failure Analysis**: It performs a correlation analysis between the model's absolute errors and the input features to identify variables associated with poor performance.
6.  **Submission**: If the validation score meets the specified threshold, the model generates predictions for the test set, and a submission file is saved.
