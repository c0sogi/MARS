The `AssertionError` is caused by `NaN` values in the feature matrix, specifically generated during the calculation of skewness and kurtosis in `get_kinematic_features`. When a sensor signal is constant (e.g., due to imputation of dead sensors), its standard deviation is zero, causing division-by-zero errors in these statistical functions (Cite debug_lesson_4). I will fix this in `library/features.py` by wrapping the `stats.skew` and `stats.kurtosis` calls with `np.nan_to_num`, which replaces undefined values with zero.
