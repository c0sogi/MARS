Based on the comprehensive analysis of the "Lessons" and the empirical progression of "Previous Ideas," I propose the **Single-Stream High-Resolution Hybrid Decomposition with Differential Temporal Profiling** strategy.

This approach structurally evolves the "Current Best" Idea 15 by synthesizing the **Orthogonal Decomposition** framework with a suite of corrective innovations: **Polynomial Order Constraints** (Lesson 00094), **High-Resolution Spectral Extraction** (Lesson 00082), and **Split-Granularity Feature Engineering** (resolving the conflict between Lessons 00059 and 00077). Crucially, it introduces **Differential Temporal Profiling** to explicitly model the "ramping up" of seismic energy, addressing the limitations of static window flattening. It reverts to a **Single High-Capacity Model** to maximize the sample-to-feature ratio, respecting Lesson 00106.

# Model
The predictive core will be a **Single, Highly-Optimized LightGBM Regressor**.

*   **Architecture:** A single LightGBM model with high capacity (e.g., `num_leaves=128`, `learning_rate` < 0.05).
*   **Rationale:** Lesson 00106 demonstrated that in data-scarce regimes (low sample-to-feature ratio), training on the full dataset (or a single large split) outperforms Cross-Validation Ensembling (Bagging) because the loss of training data in CV folds hurts manifold learning more than variance reduction helps. A single, well-tuned GBDT has consistently outperformed complex ensembles in this task (Cite solution_lesson_node_00046).
*   **Objective Function:** The model will be trained using **L2 Loss (Mean Squared Error)**.
    *   **Rationale:** Lesson 00060 proved that optimizing L2 Loss yields better convergence and lower final MAE than L1 Loss due to superior gradient dynamics (informative gradients vs. constant sign gradients).

# Data
The data processing pipeline implements a **High-Resolution Hybrid-Transform Decomposition** to extract physically distinct signal components using strict physics-based constraints.

1.  **Preprocessing:**
    *   **Imputation:** Fill missing values with the segment-wise column mean to preserve DC offsets (Cite solution_lesson_node_00002).
    *   **Decomposition:** For each sensor, generate three distinct signal views:
        *   **View A (Trend):** Apply a **Savitzky-Golay filter** with a **large window size (e.g., 51)** and a **Polynomial Order of 2 (Quadratic)**.
            *   *Correction:* Strictly use **Order 2** to prevent fitting local noise artifacts (Cite solution_lesson_node_00094) and a large window to isolate baseline drift (Cite solution_lesson_node_00070).
        *   **View B (Texture):** Apply a **Discrete Wavelet Transform (DWT)** (e.g., `db4`) to the **Residuals** ($Raw - Trend$) and extract Detail Coefficients. This provides a multi-resolution representation of roughness, superior to simple subtraction-based residuals (Cite solution_lesson_node_00060).
        *   **View C (Raw):** Retain the original **Raw** signal.

2.  **Feature Engineering (The Split-Granularity & Differential Paradigm):**
    *   **From View A (Trend Shape - Split Granularity):** Extract a **Dense Grid of Quantiles** (e.g., 1%, 5%, ..., 95%, 99%) directly from the **Trend** signal.
        *   *Rationale:* The Trend is smooth; dense quantiles accurately describe the "shape" of the deformation without overfitting, recovering information lost by abstract moments (Cite solution_lesson_node_00059).
    *   **From View A (Robust Kinematics - Split Granularity):** Compute **First (Velocity)** and **Second (Acceleration)** derivatives of the Trend. Extract **Higher-Order Moments (Skewness, Kurtosis)**, Mean, and Std.
        *   *Correction:* Do **not** use dense quantiles on derivatives. Lesson 00077 proved that moments capture signal "impulsiveness" better than quantiles for derivatives, which otherwise overfit to noise artifacts (Cite solution_lesson_node_00077).
    *   **From View B (Wavelet Texture):** Extract **Energy**, **Entropy**, **Skewness**, and **Kurtosis** from the DWT Detail Coefficients (Cite solution_lesson_node_00049).
    *   **From View C (Absolute Intensity):** Extract **Global Minimum**, **Global Maximum**, and **Peak-to-Peak Range**.
        *   *Rationale:* Strictly preserves the absolute intensity of the event, adhering to the lesson that "outliers are the signal" (Cite solution_lesson_node_00031).
    *   **From View C (High-Resolution Spectral Structure):** Compute **PSD Band Power** using **Welch's Method** with **Closed Intervals** (Low: 0.1-3Hz, Mid: 3-10Hz, High: 10-45Hz).
        *   *Correction:* Explicitly set the window size (`nperseg`) to a high value (e.g., **1024**) to ensure at least **10-20 frequency bins** fall within the critical 0.1-3Hz Low band, correcting previous aliasing issues (Cite solution_lesson_node_00082).
    *   **From View C (Differential Temporal Profiling - Structural Innovation):**
        *   Divide the signal into $N$ non-overlapping windows. Compute statistics (RMS, Mean) for each window.
        *   **Step 1 (Snapshots):** Flatten these into explicit features (e.g., `w1_rms`, `w2_rms`) to preserve the "arrow of time" (Cite solution_lesson_node_00010).
        *   **Step 2 (Differential Dynamics):** Compute the **First-Order Differences** between consecutive windows (e.g., `diff_w2_w1 = w2_rms - w1_rms`).
        *   *Rationale:* This explicitly encodes the *gradient of the energy envelope* (i.e., is the signal ramping up?), adding a robust physical descriptor to the static snapshots.

3.  **Feature Organization:**
    *   **Spatial Concatenation:** Concatenate features for all 10 sensors side-by-side. Do **not** aggregate across sensors (Cite solution_lesson_node_00018).

# Training
*   **Strategy:** Train a single model on a large data split (e.g., 90% Train / 10% Validation) to maximize the sample-to-feature ratio (Cite solution_lesson_node_00106).
*   **Optimization:** Use **Early Stopping** based on the Validation MAE (Cite solution_lesson_node_00002).
*   **Hyperparameters:** Set `num_leaves=128` to leverage the high capacity of the single model (Cite solution_lesson_node_00075).
