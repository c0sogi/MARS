Based on the lessons learned from the previous experiments, I propose the **Stacked Heterogeneous Ensemble with Robust Quantile-Kinematic Features**.

This strategy introduces a **Stacking Architecture** (Structural Innovation) to synthesize the predictive power of diverse Gradient Boosting implementations. It couples this with a rigorously corrected feature engineering pipeline that replaces unstable statistical moments with robust quantiles and enforces strict noise suppression protocols, directly addressing the failure modes observed in Ideas 5, 6, and 7.

# Model
The predictive architecture will evolve from a single model or simple weighted average to a **Two-Level Stacking Ensemble**.

*   **Level 0 (Base Learners):** Three distinct Gradient Boosted Decision Tree (GBDT) models: **LightGBM**, **XGBoost**, and **CatBoost**.
    *   *Rationale:* Previous lessons confirmed that GBDTs are the superior backbone for this dataset compared to Deep Learning (Cite solution_lesson_node_00008). However, single models (Idea 4) have high variance. By utilizing three different libraries, we exploit algorithmic diversity (different split-finding strategies and regularization schemes), allowing the ensemble to capture patterns that a single GBDT might miss without the risk of including a non-convergent weak learner like a CNN.
*   **Level 1 (Meta Learner):** A **Ridge Regression** model (Linear Regression with L2 regularization).
    *   *Rationale:* Rather than using arbitrary manual weights (which failed in Idea 3), the meta-learner will be trained to optimally combine the Out-of-Fold (OOF) predictions from the base learners, correcting for systematic biases.

# Data
The data processing pipeline is the core of the solution, synthesizing the "Exploitation" of successful features with the "Correction" of identified flaws.

1.  **Preprocessing:**
    *   **Imputation:** Fill missing values with the segment-wise column mean to preserve DC offsets (Cite solution_lesson_node_00002).
    *   **Robust Smoothing (Correction):** Apply a **Savitzky-Golay filter** with a **large window size (> 20)** to all raw sensor data. This is mandatory to prevent the noise amplification observed when calculating derivatives with small windows or raw data (Cite solution_lesson_node_00006, solution_lesson_node_00023).

2.  **Feature Engineering (The "Robust Multi-View" Paradigm):**
    *   **View 1: Robust Kinematics (Exploitation & Correction):** Compute the first (velocity) and second (acceleration) derivatives of the *smoothed* signals. Extract **Quantiles (1st, 5th, 95th, 99th)**, Mean, and Std.
        *   *Correction:* Explicitly prioritize **Quantiles** and discard unstable higher-order moments (Skewness/Kurtosis). Lesson 00026 demonstrated that quantiles provide stable boundaries for impulsive signals, whereas moments introduced variance that degraded performance (Cite solution_lesson_node_00026).
    *   **View 2: Structural Spectral Features (Exploitation):** Compute the Power Spectral Density (PSD) and extract **Band Power** (Low/Mid/High) and **Spectral Centroid**. This retains the physical "location" of energy, which is superior to generic FFT statistics (Cite solution_lesson_node_00007).
    *   **View 3: Multi-Resolution Wavelets (Exploitation):** Apply Discrete Wavelet Transform (DWT) (e.g., `db4`) to decompose signals and extract energy/std from approximation and detail coefficients. This retains the texture-capturing success of Idea 4.
    *   **View 4: Flattened Robust Windows (Correction):** Divide signals into non-overlapping windows. Compute **RMS** and **Mean** for each window.
        *   *Constraint 1:* **Flatten** these into explicit features (e.g., `w1_rms`, `w2_rms`) to preserve the temporal "arrow of time" (Cite solution_lesson_node_00010).
        *   *Constraint 2:* Strictly avoid `Min` and `Max` on windows to prevent overfitting to outliers (Cite solution_lesson_node_00023).
    *   **View 5: Spatial Concatenation (Correction):** Concatenate the feature vectors of all 10 sensors into a single wide input. Do **not** aggregate features across sensors (e.g., via global means), as this destroys the spatial geometry required to distinguish localized noise from generalized events (Cite solution_lesson_node_00018).

3.  **Feature Selection:**
    *   Feed the full feature set to the models. Do **not** use aggressive wrapper methods like RFE, as GBDTs handle high dimensionality internally and external pruning discards valuable distributed signal (Cite solution_lesson_node_00017).

# Training
*   **Strategy:** Use **Stratified K-Fold Cross-Validation** (e.g., 5 folds) based on the provided metadata bins.
*   **Procedure:**
    1.  Train each Base Learner (LGBM, XGB, CatBoost) on the training folds, optimizing for **MAE**.
    2.  Generate "Out-of-Fold" (OOF) predictions for the training set.
    3.  Train the Meta Learner (Ridge) on the OOF predictions to predict the target `time_to_eruption`.
    4.  Retrain Base Learners on the full training set for final inference.
*   **Optimization:** Set a high `n_estimators` (e.g., 10,000) for base learners and use **Early Stopping** based on validation MAE to ensure convergence without overfitting (Cite solution_lesson_node_00002).

# Evaluation
1.  **Feature Extraction:** Process the test set using the full pipeline: Imputation -> Large-Window Smoothing -> Quantile-Kinematic/Spectral/Wavelet/Windowed Feature Extraction -> Spatial Concatenation.
2.  **Base Inference:** Generate predictions from the retrained LightGBM, XGBoost, and CatBoost models.
3.  **Stacked Inference:** Feed the base predictions into the trained Ridge Meta-Learner to produce the final `time_to_eruption`.
4.  **Submission:** Format the output as `segment_id,time_to_eruption`.
