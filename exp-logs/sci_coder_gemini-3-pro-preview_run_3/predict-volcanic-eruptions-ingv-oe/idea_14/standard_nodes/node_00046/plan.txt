Here is the implementation strategy and the complete Python script.

### Implementation Strategy

1.  **Setup & Configuration**: Import the provided library modules. Override the `Config` parameters (specifically `N_ESTIMATORS`) to ensure the training runs quickly as a baseline. Update the model-specific parameter dictionaries (`LGBM_PARAMS`, `XGB_PARAMS`, `CATBOOST_PARAMS`) to reflect these limits.
2.  **Data Loading**: Use `load_train_data`, `load_val_data`, and `load_test_data` with `load_cached_data=True`. This leverages the pre-computed Parquet feature files to skip the time-consuming feature engineering step.
3.  **Pipeline Execution**: Initialize the `StackingManager` and call `fit_pipeline` on the training data. This handles the stratified cross-validation for base models (LightGBM, XGBoost, CatBoost), trains the Ridge meta-learner, and retrains base models on the full training set.
4.  **Validation**: Predict on the hold-out validation set. Compute the Mean Absolute Error (MAE) and print it in the strict format required (`Final Validation Metric: <value>`).
5.  **Failure Analysis**: Calculate the absolute error for validation predictions. Compute the correlation between the error magnitude and all input features. Print the top 10 features most strongly correlated with model failure.
6.  **Submission**: Check if the validation MAE is below the threshold (2,739,761.26). If successful, generate predictions for the test set and save the submission file using `save_submission`.
