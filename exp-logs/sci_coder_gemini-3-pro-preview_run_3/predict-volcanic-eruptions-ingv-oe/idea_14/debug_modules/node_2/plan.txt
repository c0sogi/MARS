The error `TypeError: XGBModel.fit() got an unexpected keyword argument 'early_stopping_rounds'` occurs because the code attempts to pass `early_stopping_rounds` to the `fit()` method of `XGBRegressor`. In newer versions of XGBoost (specifically 3.x, which is installed), this parameter has been removed from `fit()` and must be passed to the model constructor instead.

To fix this, I will modify `library/models.py` to:
1.  Update the `XGBRegressor` initialization to conditionally include `early_stopping_rounds` in the constructor arguments when validation data is present (Cite debug_lesson_8, Cite debug_lesson_13).
2.  Remove the `early_stopping_rounds` argument from the `fit()` call for XGBoost.
