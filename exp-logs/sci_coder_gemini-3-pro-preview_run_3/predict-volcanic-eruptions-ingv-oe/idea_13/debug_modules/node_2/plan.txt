The `AssertionError: Features contain NaNs` is caused by the `extract_spatial` function in `library/feature_extraction.py`. When a sensor signal is constant (e.g., a dead sensor imputed with zeros), its variance is zero, causing the Pearson correlation calculation (`df_smooth.corr()`) to result in `NaN` values due to division by zero. To fix this, I will apply `.fillna(0)` to the correlation matrix, replacing undefined correlations with zero. This solution directly addresses the mathematical undefinedness caused by zero-variance signals, as described in **Cite debug_lesson_4**.
