Implementation strategy:
1.  **Setup & Configuration**: Initialize the `Config` class to ensure all directory paths (cache, submission) are created.
2.  **Model Training**: Instantiate the `ModelEngine` and execute `train_kfold_ensemble(size=None)`. We use `size=None` to utilize the full dataset (combining Train and Validation splits) for 5-Fold Cross-Validation. This is essential to satisfy the "Homogeneous Bagging" strategy and achieve the high accuracy required by the metric threshold.
3.  **Validation & Metric Calculation**: To produce the "Final Validation Metric" accurately without data leakage, we reconstruct the Out-Of-Fold (OOF) predictions. We load the full dataset, replicate the Stratified K-Fold split using the fixed random seed, and generate predictions for each fold's validation chunk using the corresponding trained model. We then compute the Mean Absolute Error (MAE) on these aggregated OOF predictions.
4.  **Failure Analysis**: We calculate the absolute error for each prediction and compute the correlation between these errors and the input features. This identifies which signal characteristics (e.g., specific frequency bands or statistical moments) are most associated with prediction failures.
5.  **Submission**: We compare the calculated MAE against the specified threshold (`2617304.0647319085`). If the model performs sufficiently well, we call `predict_ensemble()` to generate predictions for the test set and save the `submission.csv`.
