Based on the comprehensive analysis of the previous experiments and the derived lessons, I propose a **Multi-Resolution Wavelet & Smoothed Dynamics** strategy. This approach maintains the high-efficiency Gradient Boosting framework (Exploitation) while introducing a sophisticated signal processing layer to capture non-stationary patterns and kinematic evolution (Innovation) that previous iterations missed or modeled incorrectly.

# Model
The predictive core will remain a **LightGBM Regressor**, as previous results demonstrated that Gradient Boosting on tabular features is significantly more data-efficient and performant than Deep Learning for this specific dataset size (Cite solution_lesson_node_00008).

However, the **Input Architecture** will be fundamentally restructured into a **Multi-Domain Representation**. Instead of a flat list of simple statistics, the input vector will be composed of four distinct feature blocks:
1.  **Global Statistical Block:** Captures the overall amplitude distribution.
2.  **Explicit Temporal Block:** Captures the signal's trajectory over time.
3.  **Spectral Structure Block:** Captures energy in specific frequency bands.
4.  **Multi-Resolution Wavelet Block (Innovation):** Captures non-stationary time-frequency details using Discrete Wavelet Transforms (DWT), which provide a superior representation for seismic signals compared to the fixed-resolution FFT used in Idea 2.

# Data
The data processing pipeline will be upgraded to address the noise sensitivity and information loss identified in previous lessons.

1.  **Preprocessing & Imputation:**
    *   Load sensor data and impute missing values with the segment-wise column mean to preserve DC offsets (Cite solution_lesson_node_00002).
    *   **Signal Smoothing (Correction):** Apply a **Savitzky-Golay filter** to the raw sensor data. This is a critical step to enable the safe extraction of derivative features, preventing the noise amplification observed in previous attempts (Cite solution_lesson_node_00006).

2.  **Feature Engineering:**
    *   **Global & Windowed Stats (Retention):** Compute moments (Mean, Std, Skew, Kurtosis) and Quantiles for the whole segment. Additionally, split the signal into non-overlapping windows and compute these stats for *each* window, flattening them into explicit features (e.g., `win1_mean`, `win2_mean`) to preserve the "arrow of time" (Cite solution_lesson_node_00010).
    *   **Structural Spectral Features (Retention):** Compute the Power Spectral Density (PSD) and extract **Band Power** (energy in Low/Mid/High freq bands) and **Spectral Centroid**. This preserves the "location" of energy better than generic FFT statistics (Cite solution_lesson_node_00007).
    *   **Wavelet Decomposition (Structural Innovation):** Apply a **Discrete Wavelet Transform (DWT)** (e.g., using the Daubechies `db4` wavelet) to decompose the signal into Approximation and Detail coefficients at multiple levels (e.g., 4 levels). Calculate energy, entropy, and standard deviation for each set of coefficients. This captures "texture" and transient seismic events that global FFT averages out (Cite solution_lesson_node_00005).
    *   **Smoothed Kinematics (Correction):** Calculate the first and second derivatives (velocity and acceleration) of the *smoothed* signal. Compute statistics on these derivatives. This allows the model to learn from the *rate of change* of the seismic activity without overfitting to high-frequency measurement noise (Cite solution_lesson_node_00006).

# Training
The training process is optimized for the Gradient Boosting architecture.

*   **Objective Function:** Minimize Mean Absolute Error (MAE).
*   **Hyperparameters:** Set a high limit for `n_estimators` (e.g., 10,000) to ensure the model is not artificially constrained, as previous runs showed under-convergence (Cite solution_lesson_node_00002).
*   **Regularization:** Implement **Early Stopping** (e.g., patience of 100 rounds) based on the validation set MAE. This allows the model to leverage the expanded feature space (Wavelets + Derivatives) without overfitting.
*   **Validation:** Strictly use the stratified `metadata/train.csv` and `metadata/val.csv` splits to ensure the distribution of eruption times is representative.
