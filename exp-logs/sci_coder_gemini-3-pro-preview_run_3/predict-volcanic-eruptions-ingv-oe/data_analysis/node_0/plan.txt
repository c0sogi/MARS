The following strategy outlines the implementation of the Exploratory Data Analysis (EDA) script:

1.  **Setup and Configuration**: Import necessary libraries (Pandas, NumPy, Scikit-Learn, SciPy) and set random seeds for reproducibility. Define paths for input and metadata.
2.  **Target Variable Analysis**: Load the training metadata (`./metadata/train.csv`). Analyze the `time_to_eruption` column to report distribution statistics, skewness, and kurtosis, confirming the regression nature of the task.
3.  **Input Data Sampling**: Since the full dataset (thousands of CSVs) is too large to load into memory at once, we will randomly sample 200 files from the training set. This provides a statistically significant subset (~12 million rows) to analyze the sensor readings without exceeding memory limits.
4.  **Tabular/Signal Analysis**: Treat the sampled sensor logs as tabular data.
    *   **Numerical Stats**: Compute mean, standard deviation, min, max, and outlier counts (using the IQR method) for each of the 10 sensor columns.
    *   **Missing Values**: Calculate the percentage of missing values (NaNs) per sensor.
    *   **Signal Consistency**: Verify that all sampled files have the expected length (60,001 rows) to ensure signal consistency.
5.  **Feature Relationships**:
    *   **Feature Engineering**: Aggregate the sampled time-series data into static features (Mean and Standard Deviation per sensor per segment).
    *   **Correlation**: Calculate Pearson correlation between these aggregated features and the target `time_to_eruption`.
    *   **Feature Importance**: Train a lightweight Random Forest Regressor on the aggregated features to identify which sensors or statistics are most predictive.
    *   **Redundancy**: Identify highly correlated feature pairs to detect redundancy.
6.  **Reporting**: Output the findings in a structured, text-based report with capitalized sections and formatted numbers, as requested.
