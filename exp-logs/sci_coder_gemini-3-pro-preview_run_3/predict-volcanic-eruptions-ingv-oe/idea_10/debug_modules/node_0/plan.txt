This script demonstrates the usage of the provided machine learning library for the volcano eruption prediction task. It follows a logical flow:
1.  **Feature Engineering Verification**: Validates the extraction of signal processing features (kinematics, spectral, etc.) from a single sensor segment.
2.  **Data Processing Verification**: Tests the batch generation of feature matrices with caching and debug slicing.
3.  **Model Configuration**: Inspects the model definitions and applies "Monkey Patching" to the trainer module to reduce the number of estimators and folds. This ensures the demonstration runs quickly (optimizing for speed) while exercising the full pipeline logic.
4.  **Full Pipeline Execution**: Runs the end-to-end training and inference pipeline using the modified settings and validates the generation of the submission file.
