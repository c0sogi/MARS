The `ValueError: Object arrays cannot be loaded when allow_pickle=False` occurs because the `label_encoder_classes.npy` file contains an array of strings (whale IDs), which NumPy treats as objects. Modern NumPy versions disable pickling by default during loading for security, similar to the `weights_only` constraint discussed in **Cite debug_lesson_6**. To resolve this, I will update the `np.load` calls in both `runfile.py` and `library/dataset.py` to explicitly set `allow_pickle=True`, permitting the deserialization of the string array.
