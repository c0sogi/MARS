The issue stems from a refactoring of the model architecture in `library/model.py` where the class `WhaleDenseNet` was replaced with `WhaleEfficientNet`, but the dependent files `library/inference.py` and `runfile.py` were not updated to reflect this name change. This causes an `ImportError` when these scripts attempt to import or instantiate the old class name. To fix this, I will replace all references to `WhaleDenseNet` with `WhaleEfficientNet` in the affected files.

```diff
library/inference.py
<<<<<<< SEARCH
from library.model import WhaleDenseNet
from library.data_loader import get_dataloaders
=======
from library.model import WhaleEfficientNet
from library.data_loader import get_dataloaders
>>>>>>> REPLACE
```
