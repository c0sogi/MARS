The implementation strategy involves the following steps:

1.  **Setup and Directory Handling**: Define the input (`./input`) and output (`./metadata`) directories. Ensure the output directory exists.
2.  **Training Data Processing**:
    *   Load `train.csv`.
    *   Generate relative file paths for images (e.g., `train/ImageID.jpg`).
    *   **Stratified Split Logic**: Analyze the class distribution (whale `Id`). Identify "singleton" classes (IDs with only one image). To prevent data loss and ensure every class is represented in the training set, assign all singletons to the training set. Perform a standard stratified 80/20 split on the remaining multi-sample classes using `sklearn.model_selection.train_test_split` with a fixed random state (42).
    *   Combine the singleton training data with the stratified training data to create the final training set.
3.  **Test Data Processing**:
    *   Scan the `./input/test` directory for all `.jpg` files.
    *   Create a DataFrame containing the image names and their relative file paths (`test/ImageID.jpg`).
4.  **Metadata Output**: Save the processed DataFrames as `train.csv`, `val.csv`, and `test.csv` in the `./metadata` directory.
5.  **Validation and Verification**:
    *   Reload the generated metadata files.
    *   Print summary statistics (sample counts, unique IDs).
    *   **File Existence Check**: Randomly sample 1000 file paths from each dataset and verify they exist in the `./input` directory. Raise an error if the missing ratio exceeds 0.5.
    *   **Split Verification**: Assert that the validation set is not empty, contains no data leakage (overlap with train images), and that all classes present in the validation set are also present in the training set.
