Implementation strategy:
1.  **Setup & Imports**: Import necessary libraries and the provided `library` modules. Set random seeds and detect the computing device (GPU) using `library.utils`.
2.  **Data Loading**: Use `library.data.prepare_data` with `load_cached_data=True` to efficiently load the preprocessed datasets. We will use the full dataset (`debug=False`) to ensure the model learns enough to meet the strict validation threshold.
3.  **Model Configuration**: Initialize the `PERDHNet` model, `AdamW` optimizer, and `MaskedL1Loss` as defined in the library.
4.  **Fast Baseline Training**: Initialize the `Trainer` and run the training loop. To adhere to the "fast baseline" requirement while ensuring convergence, we will limit the training to 12 epochs (down from the config's 80). This balances runtime constraints with the need for high accuracy.
5.  **Validation**: Load the best model checkpoint. Perform inference on the full validation set. Calculate the `Final Validation Metric` (MAE on the inspiratory phase) and print it in the required format.
6.  **Failure Analysis**: Calculate the absolute error for each prediction in the inspiratory phase. Correlate these errors with the input features to identify which variables drive model performance degradation. Print the top correlations.
7.  **Submission**: Check if the validation metric is below the threshold (0.1639...). If successful, generate predictions for the test set, map them to the correct `id`s using the metadata (ensuring correct sorting), and save the `submission.csv`.
