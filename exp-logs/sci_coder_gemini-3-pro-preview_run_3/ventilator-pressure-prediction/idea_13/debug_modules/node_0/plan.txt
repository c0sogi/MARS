The following script demonstrates the end-to-end usage of the provided library for the ventilator pressure prediction task.

### Strategy Outline
1.  **Environment Setup**: We import necessary modules and set the random seed using `library.utils.seed_everything` to ensure reproducibility.
2.  **Data Subsetting**: To ensure the demonstration runs quickly, we create a small subset of the training and test data (containing only a few breaths) and save them to the `./working` directory.
3.  **Configuration Override**: We dynamically modify the `Config` class attributes to point to these temporary subset files and define temporary cache paths. This prevents the script from processing the full 4GB+ dataset and ensures the demo completes within seconds.
4.  **Data Pipeline Verification**: We call `prepare_datasets` to process the raw CSVs into feature-engineered numpy arrays. We assert that the output data loaders contain the expected number of batches and shapes.
5.  **Model Verification**: We instantiate the `TAPINNet` model and perform a dummy forward pass with random tensors to verify the architecture and output dimensions (batch size, sequence length).
6.  **Training Loop**: We execute `train_model` with a minimal epoch count and debug mode enabled. We verify that the training completes and produces a saved model file.
7.  **Inference & Metric**: We load the trained model, perform inference on the test subset, and verify the submission format. We also independently verify the `compute_metric` function using manual tensors to ensure the custom masking logic (ignoring the expiratory phase) works correctly.
