The following script demonstrates the end-to-end usage of the provided MCRH-Net library.

**Implementation Strategy:**
1.  **Configuration Override**: We first modify the `Config` class to enable `DEBUG` mode, reduce the number of epochs to 2, and set a specific working directory for this demonstration. This ensures the code runs quickly (within minutes) and does not interfere with existing production files. We also verify that path configurations are correctly updated.
2.  **Component Verification**:
    *   **Loss Function**: We instantiate `MaskedL1Loss` and verify it correctly ignores the expiratory phase (`u_out=1`) and computes the Mean Absolute Error for the inspiratory phase (`u_out=0`).
    *   **Model Architecture**: We instantiate `MCRHNet` with a dummy input shape, pass a random tensor through it, and assert that the output shape matches the expected `(Batch, Sequence_Length, 1)` dimensions.
3.  **Pipeline Execution**:
    *   We utilize the `Runner` class to manage the training and inference process.
    *   The `train()` method is called to train the model on the small debug subset.
    *   The `generate_submission()` method is called to produce predictions.
4.  **Output Validation**: Finally, we verify that the submission file is created, contains the correct columns, and has the expected number of rows corresponding to the debug test set.
