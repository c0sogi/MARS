The following implementation demonstrates the end-to-end usage of the provided library for the Ventilator Pressure Prediction task.

### Strategy Outline
1.  **Configuration Override**: We modify the global `Config` class to enable `DEBUG` mode, reduce `EPOCHS` to 2, and set a small `BATCH_SIZE`. This ensures the script runs quickly (within seconds/minutes) by processing only a tiny subset of the data (200 breaths).
2.  **Feature Engineering**: We instantiate the `FeatureEngineer` to process the raw metadata. We assert that the output shapes match the expected 3D time-series format `(N_Breaths, 80, Features)`.
3.  **Data Loading**: We utilize `get_dataloaders` to generate PyTorch DataLoaders and verify the batch dimensions.
4.  **Model & Loss Verification**: We instantiate the `PCDRHNet` model and `MaskedL1Loss`. We perform a forward pass with dummy data to verify tensor shapes and run a manual calculation check on the loss function to ensure the masking logic (ignoring the expiratory phase) works as intended.
5.  **Training Loop**: We initialize the `Trainer` and run the `.fit()` method. We verify that the best model checkpoint is saved to the working directory.
6.  **Inference**: We run predictions on the test set, verify the output length matches the test IDs, and generate a valid submission CSV file.
