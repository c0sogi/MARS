1.  **Setup & Configuration**: Initialize the environment with a fixed seed and detect the available device (GPU). Override the default epoch count in `Config` to 35 to ensure a fast execution that still converges sufficiently to meet the strict validation threshold.
2.  **Data Preparation**: Load the pre-processed and cached training, validation, and test datasets using `prepare_datasets(load_cached_data=True)`. Create efficient `DataLoaders` with pinned memory.
3.  **Model Initialization**: Instantiate the `LANNet` (Lookahead-Augmented Non-Causal Hybrid) model and move it to the GPU.
4.  **Training**: Configure the `AdamW` optimizer, `ReduceLROnPlateau` scheduler, and `MaskedL1Loss`. Execute the training loop using the `Trainer` class, saving the best model based on validation MAE.
5.  **Validation & Metrics**: Load the best model checkpoint. Run inference on the full validation set to compute the final Masked MAE. Print the metric with full precision as required.
6.  **Failure Analysis**: Flatten the validation predictions, targets, and input features. Filter for the inspiratory phase (where `u_out == 0`). Calculate the correlation between the absolute error and each input feature to identify sources of error.
7.  **Conditional Submission**: Compare the final validation metric against the threshold (0.22291307151317596). If the model performs well enough, generate predictions for the test set and save the submission file to `./submission/submission.csv`.
