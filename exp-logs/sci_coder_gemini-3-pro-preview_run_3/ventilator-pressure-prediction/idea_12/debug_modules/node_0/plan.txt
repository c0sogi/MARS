This script demonstrates the end-to-end usage of the provided ventilator pressure prediction library. It performs the following steps:

1.  **Configuration Override**: Modifies the global `Config` to use a temporary working directory and reduces parameters (epochs, batch size) for a rapid demonstration.
2.  **Component Verification**:
    *   **Data Pipeline**: Validates `prepare_datasets` in debug mode, ensuring correct data shapes and feature engineering.
    *   **Model Architecture**: Instantiates `LANNet` and verifies the forward pass output shape.
    *   **Loss & Metric**: Unit tests `MaskedL1Loss` and `compute_metric` with manual tensors to verify that the expiratory phase is correctly ignored.
3.  **Integration Test**: Runs the full `train_model` pipeline (training, validation, inference) on a small data subset and verifies the generation of the submission file.
