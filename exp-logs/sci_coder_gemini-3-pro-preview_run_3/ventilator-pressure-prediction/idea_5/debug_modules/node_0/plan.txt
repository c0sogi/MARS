This script demonstrates the end-to-end usage of the provided library components for the Ventilator Pressure Prediction task. It validates the data loading pipeline, model architecture, metric calculation, and the full training loop using a reduced dataset and model size for rapid execution.

1.  **Configuration Setup**: It overrides the default `Config` parameters to use a temporary working directory, enable debug mode (small subset of data), and reduce model complexity (smaller LSTM/TCN layers) to ensure the script runs quickly.
2.  **Data Pipeline Verification**: It calls `get_dataloaders`, fetches a single batch, and asserts that the input tensors (`x`), targets (`y`), and auxiliary masks (`u_out`) have the correct shapes corresponding to the batch size, sequence length (80), and feature dimension (9).
3.  **Model Architecture Verification**: It instantiates the `CAPNet` model, performs a forward pass with the sample batch, and verifies that the output shape matches the target shape.
4.  **Metric Logic Verification**: It creates synthetic tensors to test `masked_mae_loss` and `compute_metric`, ensuring that the logic correctly ignores the expiratory phase (`u_out=1`) and computes the error only for the inspiratory phase (`u_out=0`).
5.  **Full Training Loop**: It executes `run_training` for a few epochs. Finally, it verifies that the model checkpoint and submission file are successfully generated and that the submission file follows the required format.
