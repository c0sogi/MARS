Implementation Strategy:
1.  **Environment Setup**: Import necessary libraries and the provided modules (`library.*`). Define a `main` execution block.
2.  **Configuration Patching**:
    *   Override `Config` attributes to create an isolated "Demo" environment.
    *   Set `Config.DEBUG = True` to limit the dataset to 1000 breaths, ensuring the script runs quickly (within minutes).
    *   Set `Config.EPOCHS = 2` to demonstrate the training loop without a long wait.
    *   Redirect all file paths (cache, models, submission) to a `./working/demo_execution` directory to avoid conflicts with existing files.
3.  **Data Pipeline Execution**:
    *   Call `get_data_loaders(load_cached_data=False)`. This forces the execution of the full preprocessing pipeline: loading CSVs, generating PID/Physics features, RobustScaling, and reshaping to 3D tensors.
    *   **Verification**: Assert that the resulting DataLoaders yield tensors of the correct shape `(Batch, 80, Features)`.
4.  **Model Logic Verification**:
    *   Instantiate the `PMNCNet` model.
    *   Perform a forward pass with a single batch of data.
    *   **Verification**: Assert that the output shape matches the target shape `(Batch, 80)`.
5.  **Training Loop**:
    *   Instantiate the `Trainer` class.
    *   Run `trainer.fit()`.
    *   **Verification**: Check that the best model checkpoint file is created.
6.  **Inference & Submission**:
    *   Call `generate_submission`.
    *   **Verification**: Load the generated CSV, check that it has the correct columns (`id`, `pressure`) and the expected number of rows (80,000 for the 1000-breath debug subset).
