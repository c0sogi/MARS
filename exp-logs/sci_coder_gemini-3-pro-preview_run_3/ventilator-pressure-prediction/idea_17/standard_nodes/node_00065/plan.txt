The implementation strategy is as follows:
1.  **Configuration**: Initialize the `Config` with parameters suitable for a fast baseline. We will set `EPOCHS` to 12 and enable `DEBUG` mode with a sample size of 30,000 breaths (approx. 60% of the data) to balance runtime speed with model performance.
2.  **Setup**: Set random seeds for reproducibility.
3.  **Data Preparation**: Load the datasets using `prepare_datasets`. This handles feature engineering, caching, and DataLoader creation.
4.  **Training**: Train the `DCLKNet` model using `train_model`. This function handles the training loop, validation monitoring, and saving the best model.
5.  **Validation & Metric**: Iterate through the validation set in evaluation mode. We will accumulate the absolute errors specifically for the inspiratory phase (`u_out == 0`) to compute the exact global Mean Absolute Error (MAE).
6.  **Failure Analysis**: During the validation loop, collect feature values and error magnitudes. Calculate the Pearson correlation between each feature and the prediction error to identify sources of model failure.
7.  **Submission**: Check if the calculated validation metric is below the strict threshold of `0.1642141044139862`. If successful, generate predictions on the test set and save the submission file using `predict_and_submit`.
