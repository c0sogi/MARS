This script demonstrates the end-to-end usage of the provided library files to train the RPC-Net model and generate a submission.

### Implementation Strategy

1.  **Configuration Override**: We dynamically modify the `Config` class attributes to set up a "Demo" environment. This involves enabling `DEBUG` mode (to use a tiny subset of data), reducing `EPOCHS` to 2 for speed, and redirecting working directories to avoid overwriting existing artifacts. We also manually update dependent file paths (like cache locations) since they are initialized at import time.
2.  **Data Pipeline Verification**: We utilize `get_dataloaders` to process the raw CSV data into tensors. We assert that the resulting DataLoaders yield batches with the correct shapes (Batch Size, Sequence Length, Features) and data types.
3.  **Model Architecture Verification**: We instantiate the `RPCNet` model and perform a forward pass with a dummy batch to ensure the Pyramidal TCN and Bi-LSTM branches interact correctly and produce the expected output shape.
4.  **Training Execution**: We execute `run_training`, which encapsulates the training loop, validation, early stopping, and inference. This proves that the `train_utils` module functions correctly with the configuration.
5.  **Submission Validation**: Finally, we verify that the submission file is generated, contains the correct columns (`id`, `pressure`), and matches the expected number of rows for the debug dataset.
