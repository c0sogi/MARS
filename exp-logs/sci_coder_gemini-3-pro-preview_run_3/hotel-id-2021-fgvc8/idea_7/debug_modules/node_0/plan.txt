This script demonstrates the end-to-end workflow for the Hotel Identification task using the provided library modules. It overrides the default configuration to run in `debug` mode, ensuring quick execution by using a small subset of the data. The script initializes the data loaders, sets up the ArcFace-based model, runs a single epoch of training, validates the performance using MAP@5, and generates a submission file. Assertions are included throughout to verify the correctness of tensor shapes, data integrity, and output formats.
