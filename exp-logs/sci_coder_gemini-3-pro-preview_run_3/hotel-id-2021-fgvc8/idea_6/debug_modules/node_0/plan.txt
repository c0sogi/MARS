The following script demonstrates the end-to-end usage of the provided hotel recognition library.

**Implementation Strategy:**
1.  **Configuration Override**: We dynamically modify the `Config` class attributes to adapt the pipeline for a quick demonstration (reducing image size, batch size, and epochs, and switching to a lighter backbone).
2.  **Utility Verification**: We validate the metric calculation functions (`apk`, `mapk`) with known inputs to ensure correctness.
3.  **Data Loading**: We instantiate the DataLoaders using `get_dataloaders` in debug mode and verify the shape and type of the yielded batches.
4.  **Model Instantiation & Forward Pass**: We initialize the `HotelRecognitionModel`, perform a forward pass with and without labels (training vs. inference mode), and assert output shapes.
5.  **Training Loop**: We execute `run_training` for a single epoch on a subset of data to generate a model checkpoint, verifying that the output file is created.
6.  **Inference & Submission**: We run `predict_and_submit` using the generated checkpoint and verify the format of the resulting submission CSV.
