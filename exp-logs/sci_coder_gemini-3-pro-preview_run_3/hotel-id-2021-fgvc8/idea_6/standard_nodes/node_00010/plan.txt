This script implements the full pipeline for the hotel identification task. It overrides the default configuration to optimize for the available A100 GPU, runs the training loop, performs a detailed validation and failure analysis, and generates a submission if the performance threshold is met.

**Implementation Strategy:**
1.  **Configuration Override**: Adjusts `Config` parameters (Batch Size: 96, Epochs: 5) to maximize GPU utilization and ensure convergence within the time limit.
2.  **Training**: Executes the training pipeline using `library.train.run_training`, which handles the training loop, validation monitoring, and checkpoint saving.
3.  **Validation & Metric**: Reloads the best model and performs inference on the validation set to calculate the `MAP@5` score. The result is printed in the required format.
4.  **Failure Analysis**: Correlates the per-sample Average Precision (AP) scores with the class frequency of the target hotel. This helps identify if the model struggles with rare classes (long-tail distribution).
5.  **Submission**: Checks the validation metric against the specified threshold (`0.5589516758918762`). If the condition is met, it triggers the inference pipeline to generate `submission.csv` using Test-Time Augmentation.
