The strategy for the implementation is as follows:

1.  **Setup and Directory Creation**: Define the input directory (`./input`) and the output directory (`./metadata`). Create the output directory if it doesn't exist.
2.  **Data Loading**:
    -   Read `train.csv` to get training labels and image metadata.
    -   Read `sample_submission.csv` to get the list of test images.
3.  **Path Construction**:
    -   For the training data, construct the relative file path using the `chain` ID and `image` filename (format: `train_images/<chain>/<image>`).
    -   For the test data, construct the path using the `image` filename (format: `test_images/<image>`).
4.  **Train/Validation Split**:
    -   Analyze the distribution of the target variable `hotel_id`.
    -   Identify classes with only one sample ("singletons") and classes with multiple samples.
    -   Assign all singletons to the training set to ensure every class is represented in training.
    -   Perform a stratified 80/20 split on the remaining data (classes with >1 sample) using `sklearn.model_selection.train_test_split` with `random_state=42`.
    -   Combine the singletons and the split training data to form the final training set.
5.  **Saving Metadata**: Save the resulting DataFrames to `metadata/train.csv`, `metadata/val.csv`, and `metadata/test.csv`.
6.  **Verification**:
    -   **Load**: Reload the generated metadata files.
    -   **Statistics**: Print shapes, class counts, and basic stats.
    -   **File Existence Check**: Randomly sample 1000 paths from each dataset and verify they exist relative to `./input`. Raise an error if >50% are missing.
    -   **Split Verification**: Verify that the validation set is roughly 20% of the non-singleton data and that stratification was applied correctly (by checking distribution consistency). Ensure no data leakage between train and val.
