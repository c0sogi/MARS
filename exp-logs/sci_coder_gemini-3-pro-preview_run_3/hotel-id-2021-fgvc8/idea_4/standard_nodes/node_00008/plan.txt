Implementation strategy:
1.  **Setup & Configuration**: Import necessary modules and the provided library components. Override `Config.NUM_EPOCHS` to 5 to ensure the training completes efficiently within the time limit while providing a robust baseline.
2.  **Data Loading**: Use `get_dataloaders` to retrieve training, validation, and test loaders, along with the class mapping (`idx_to_hotel`).
3.  **Model Initialization**: Instantiate the `HotelRecognitionModel` (EfficientNet-B0 + GeM + ArcFace) and move it to the GPU.
4.  **Training Loop**: Implement a standard training loop using `train_one_epoch`. Use AdamW optimizer and Cosine Annealing scheduler. Save the model checkpoint to `Config.MODEL_SAVE_PATH` after every epoch to ensure the latest weights are available for inference.
5.  **Validation & Metric Calculation**: Implement a custom `calculate_map5` function. This function will extract embeddings for the validation set, compute cosine similarity against the ArcFace class centers, retrieve the top-5 predictions, and calculate the Mean Average Precision @ 5 (MAP@5).
6.  **Failure Analysis**: Implement `perform_failure_analysis` to compute the correlation between prediction error (1 - AP) and the class frequency (derived from training metadata). This identifies if the model struggles with rare classes.
7.  **Submission Logic**: Compare the final validation MAP@5 against the specified threshold (0.1457...). If the model passes, call the provided `generate_submission` function to create the final `submission.csv`.
