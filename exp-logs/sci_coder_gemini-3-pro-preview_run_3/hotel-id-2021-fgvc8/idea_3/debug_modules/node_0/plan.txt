The following script demonstrates the end-to-end usage of the provided library files for the hotel identification task.

### Strategy
1.  **Environment Configuration**: We override the default `Config` parameters to enable `DEBUG` mode, reduce image sizes, and limit the dataset size. This ensures the script runs quickly (within seconds) while exercising all code paths.
2.  **Mocking Utilities**: To comply with the requirement of suppressing progress bars, we inject a mock object for `tqdm` before importing the library modules.
3.  **Component Instantiation**: We systematically instantiate and verify the core components:
    *   **Data Processing**: `process_data` is called to generate the necessary metadata and label encoders.
    *   **Data Loading**: `HotelDataset` and `BalanceClassSampler` are initialized. We verify the `DataLoader` produces batches with the correct dimensions (P classes $\times$ K samples).
    *   **Model**: `HotelIdModel` is initialized with a lightweight backbone (`resnet18`) for speed. We verify the output shape of a forward pass.
4.  **Execution Loop**: We run a single training epoch and a validation pass using the provided `train_one_epoch` and `validate` functions. We assert that the loss is valid and the metric calculation logic is correct.
5.  **Inference**: We demonstrate how to generate predictions on the test set and decode them using the saved label encoder.
