The issue is caused by a `_pickle.PicklingError` when attempting to use `ProcessPoolExecutor` for parallel processing. This happens because the script is being executed via `exec()` in a wrapper environment, making the `get_image_stats` function (defined in the local scope) inaccessible to worker processes which look for it in `__main__`. To fix this, I will replace the parallel execution with a sequential list comprehension, which runs the function in the same process and avoids the need for pickling. I will also remove the unused import.
