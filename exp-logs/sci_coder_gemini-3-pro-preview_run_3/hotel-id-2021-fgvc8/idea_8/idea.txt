Based on the progression of experiments and the lessons learned, I propose the following optimized strategy. This solution addresses the throughput bottlenecks of previous high-resolution attempts while introducing a structural innovation to handle the high intra-class variance of hotel imagery.

# Model
**Architecture: EfficientNet-V2-S with GeM Pooling and Sub-center ArcFace**
*   **Backbone (Structural Innovation):** Adopt **EfficientNet-V2-S**. This architecture represents a structural evolution over the EfficientNet-B0 used in Idea 4. It utilizes Fused-MBConv blocks in the early stages to significantly improve training speed and parameter efficiency compared to V1 or standard ResNets. This choice directly addresses the "Resolution-Throughput Trade-off" (Cite solution_lesson_node_00011) by providing a higher-capacity model that fits within the computational budget, avoiding the underfitting observed with slower backbones like ConvNeXt-Tiny at high resolutions.
*   **Aggregation:** Retain **Generalized Mean (GeM) Pooling**. This remains the critical component for fine-grained retrieval, allowing the model to focus on salient regions (signage, landmarks) while ignoring background noise (Cite solution_lesson_node_00008).
*   **Neck:** Retain the **Batch Normalization (BN) Neck**. This stabilizes the feature distribution before the metric learning head, ensuring convergence (Cite solution_lesson_node_00008).
*   **Head (Structural Innovation):** Implement **Sub-center ArcFace** (with $K=3$ centers per class). Standard ArcFace enforces a single prototype vector for each hotel. However, hotels are inherently multi-modal (e.g., images of the pool, the lobby, and the exterior look completely different). Sub-center ArcFace relaxes this constraint by allowing the model to learn multiple centers for each class, dynamically assigning the image to the nearest sub-center during training. This improves the model's ability to capture the high intra-class variance of the dataset.

# Data
**Preprocessing & Throughput Optimization**
*   **Input Resolution:** Fix input size at **224x224 pixels**. We strictly adhere to the lesson that throughput (batch size * speed) is more critical than resolution for convergence in this time-constrained setting (Cite solution_lesson_node_00011).
*   **Sampling:** Use **Standard Random Sampling**. We explicitly reject Class-Balanced (P-K) sampling to prevent the model collapse caused by the dataset's heavy "singleton" tail (Cite solution_lesson_node_00007).
*   **Augmentation:** Apply **Mild Augmentation** (Resize, Random Crop, Horizontal Flip). We avoid aggressive spatial distortions like `RandomResizedCrop` which were shown to hinder convergence in sparse-data regimes (Cite solution_lesson_node_00004).

# Training
**Procedure & Stability**
*   **Optimizer:** Use **AdamW** with a **Cosine Decay** learning rate schedule.
*   **Warmup:** Implement a **Linear Warmup** period (e.g., 1-2 epochs) to stabilize the gradients of the new V2 backbone and Sub-center head at the start of training (Cite solution_lesson_node_00009).
*   **Loss Function:** Minimize **Sub-center ArcFace Loss**.

# Evaluation
**Inference with Test-Time Augmentation**
*   **Prediction:** Extract embeddings using the trained EfficientNet-V2-S model.
*   **Test-Time Augmentation (TTA):** Perform inference on the original image and a horizontally flipped version, averaging the embeddings (Cite solution_lesson_node_00008).
*   **Ranking:** Compute Cosine Similarity between the averaged test embedding and the learned sub-centers. For each class, use the maximum similarity across its $K$ sub-centers to rank the predictions.
