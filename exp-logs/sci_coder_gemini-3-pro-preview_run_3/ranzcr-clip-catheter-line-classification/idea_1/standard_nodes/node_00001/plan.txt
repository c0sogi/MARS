The implementation strategy involves orchestrating the catheter detection pipeline using the provided library modules.

1.  **Configuration & Setup**: We will initialize the `Config` and override specific parameters (like `EPOCHS` and training set size) to ensure the solution runs within the "fast baseline" time constraints (under 2 hours). We will set the random seed for reproducibility.
2.  **Data Loading**: We will load the pre-generated metadata CSVs from the `./metadata` directory. To speed up training while maintaining a representative baseline, we will subsample the training data to 10,000 samples. We will instantiate `CatheterDataset` and `DataLoader` for training, validation, and testing using the transforms defined in `dataset.py`.
3.  **Model Training**: We will initialize the `CatheterResNet` model (pre-trained ResNet-34) and move it to the GPU. We will use the `AdamW` optimizer and `CosineAnnealingLR` scheduler. The training loop will be executed using the `fit` function from `engine.py`, utilizing Automatic Mixed Precision (AMP) for efficiency.
4.  **Validation**: After training, we will load the best model checkpoint and evaluate it on the full validation set using the `validate` function. We will print the `Final Validation Metric` (Average AUC) as required.
5.  **Failure Analysis**: We will perform inference on the validation set to calculate the Mean Absolute Error (MAE) for each sample. We will then iterate through the validation images to extract basic metadata (width, height, aspect ratio) and calculate their correlation with the model's error to identify potential failure modes related to image geometry.
6.  **Submission**: Finally, we will generate predictions for the test set using the `predict` function and save the results to `./submission/submission.csv`.
