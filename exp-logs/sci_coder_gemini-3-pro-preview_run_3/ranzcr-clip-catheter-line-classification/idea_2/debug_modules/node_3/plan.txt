The execution failure is caused by an unhandled edge case in the `get_score` function within `library/utils.py`. In the debug environment with a small dataset, some target columns contain only a single class (e.g., all zeros). The `roc_auc_score` function (in scikit-learn 1.7.2) returns `nan` for the macro-average in this scenario instead of raising a `ValueError`. Consequently, the existing `try...except ValueError` block is bypassed, and the `nan` value propagates, causing an assertion failure in `runfile.py`. I will update `get_score` to explicitly check if the returned score is `nan` and raise a `ValueError` to trigger the fallback logic, which calculates the AUC per column and ignores invalid ones.
