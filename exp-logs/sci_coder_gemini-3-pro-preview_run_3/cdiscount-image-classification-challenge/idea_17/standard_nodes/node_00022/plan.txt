Implementation strategy:
1.  **Configuration & Setup**: Monkey-patch the `Config` class to enable `DEBUG` mode with a limited sample size (20,000) and reduced epochs (2). This ensures the pipeline completes within the 56-minute constraint, acting as a fast baseline.
2.  **Feature Extraction**: Instantiate `FeatureExtractor` and call `extract_features()`. This will either load existing features from the disk or compute them on-the-fly for the subset defined by the debug configuration.
3.  **Ensemble Training**: Train an ensemble of 3 `PDFCNet` models. For each iteration, update the random seed and the model save path, then call `train_model()`. Store the paths of the saved checkpoints.
4.  **Validation & Failure Analysis**:
    *   Load the validation dataset (subset if in debug mode).
    *   Perform inference using the ensemble (averaging probabilities).
    *   Compute and print the **Final Validation Metric** (Accuracy).
    *   Perform failure analysis by calculating the correlation between the model's error (binary) and the L2 norm of the input feature vectors.
5.  **Submission**:
    *   Compare the validation metric against the threshold (0.6239621493939094).
    *   If the threshold is met, load the test dataset, perform ensemble inference, map the predicted indices back to `category_id`s using the hierarchy mappings, and save the results to `submission.csv`.
