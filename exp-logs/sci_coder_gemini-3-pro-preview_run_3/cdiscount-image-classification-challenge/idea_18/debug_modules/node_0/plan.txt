The following code demonstrates the complete pipeline for the product categorization task using the provided library files. It overrides the default configuration to run in `DEBUG` mode, processing only a small subset of the data (50 samples) to ensure rapid execution and verification.

The script performs the following steps:
1.  **Setup**: Configures a temporary working directory and enables debug mode.
2.  **Hierarchy Mapping**: Initializes `HierarchyMapper` to build the category tree and verifies mapping consistency.
3.  **Feature Extraction**: Uses `FeatureEngine` to extract features from the raw BSON files (ResNet50 + EfficientNet-B0) for the debug subset.
4.  **Data Loading**: Creates a `CachedFeatureDataset` and `DataLoader` to serve the extracted features.
5.  **Model Usage**: Instantiates the `ProjectedMultiTaskMLP`, verifies the forward pass shapes, and runs a short training loop with `CombinedLoss`.
6.  **Inference**: Runs the model on the test subset and generates a sample submission file.
