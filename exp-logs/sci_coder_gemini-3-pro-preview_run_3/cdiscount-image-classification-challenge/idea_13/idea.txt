# Baseline Proposal: Full-Scale Dual-Backbone Fusion with Hierarchical Ensemble

### Model
I propose a **Dual-Backbone Feature Fusion Network** that maximizes feature diversity and robustness while maintaining the computational feasibility of the decoupled paradigm.
*   **Dual Frozen Backbones:** The model will utilize two distinct pre-trained backbones in parallel to extract complementary visual features:
    1.  **ResNet-50:** Selected for its deep architecture and robust texture/shape feature extraction (2048 dimensions).
    2.  **EfficientNet-B0:** Selected for its efficient, multi-scale representation (1280 dimensions).
    *   *Rationale:* Combining these architectures leverages their complementary inductive biases. Both will be **frozen** to ensure the pipeline remains I/O bound rather than compute-bound (**Cite solution_lesson_node_00003**).
*   **Fused Aggregation:** For every product, features will be extracted for all associated images using both backbones. I will apply **Mean Pooling** independently to the ResNet and EfficientNet features, then **concatenate** the results to form a single **3328-dimensional** product embedding.
    *   *Feasibility:* Storing these embeddings for 7 million products requires ~93 GB of RAM, which fits safely within the 220 GB limit.
*   **Hierarchical Ensemble:** The classifier will consist of an **Ensemble of 5 Multi-Task MLPs**. Each MLP will feature a shared trunk that branches into three outputs corresponding to the dataset's hierarchy:
    *   **Level 1 Head:** Predicts the 49 coarse categories.
    *   **Level 2 Head:** Predicts the 483 sub-categories.
    *   **Level 3 Head (Target):** Predicts the 5270 fine-grained categories.
    *   *Innovation:* This structure acts as a regularizer, forcing the model to learn semantically consistent features, which is crucial when training on pre-computed embeddings where spatial information is lost.

### Data
*   **Full-Dataset Decoupled Caching:** I will apply the decoupled feature extraction strategy to the **entire training dataset (~7 million products)** and the test set.
    *   *Strategic Correction:* This directly addresses the failure in **Cite solution_lesson_node_00013**, where a complex Dual-Backbone model failed because it was trained on a subset. By using the full dataset, we provide sufficient signal to train the high-capacity (3328-dim) features, preventing the overfitting observed in **Cite solution_lesson_node_00005**.
*   **Label Engineering:** Map each `category_id` to its Level 1 and Level 2 parents to generate the hierarchical targets.

### Training
*   **Loss Function:** Use a **Multi-Task Sum of Cross-Entropy Losses**: $L_{total} = L_{Level3} + L_{Level2} + L_{Level1}$.
    *   *Correction:* I will explicitly **exclude** inverse-frequency class weights. As demonstrated in **Cite solution_lesson_node_00004**, class weighting optimizes for macro-recall and degrades the target metric (global accuracy). The hierarchical auxiliary tasks will instead provide structural regularization.
*   **Feature-Space MixUp:** Since the backbones are frozen, standard image augmentation is impossible. I will apply **MixUp** regularization ($x' = \lambda x_i + (1-\lambda)x_j$) directly on the cached feature vectors during MLP training. This enforces linear decision boundaries and prevents the MLP from memorizing the tabular data.
*   **Optimizer:** Train each ensemble member using **AdamW** with Weight Decay.

### Evaluation
*   **Inference Pipeline:**
    1.  Load the pre-computed test set features (Dual-Backbone Fused) from RAM.
    2.  Pass the features through all 5 trained Hierarchical MLPs.
    3.  Average the probability distributions (Softmax) from the **Level 3 Heads** across the ensemble.
    4.  Select the category with the highest average probability as the final prediction.
