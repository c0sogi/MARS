Since the script was running on a small subset of data for debugging purposes, the accuracy (0.2685) naturally fell below this threshold, causing the script to skip creating the submission file. This resulted in a pipeline failure as the evaluation system could not find the required output artifact. To fix this, I will remove the conditional check and ensure the submission file is generated and saved at the end of every run, regardless of the model's performance metrics. Cite debug_lesson_4.
