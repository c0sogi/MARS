Implementation Strategy:
1.  **Setup & Configuration**: Initialize the environment and set random seeds. Create a dedicated working directory (`./working/demo_execution`) for temporary files.
2.  **Data Subsetting**: To ensure the script runs within the 10-minute limit, create "mini" versions of the metadata files (train, val, test) containing only a small number of records (e.g., 50-100). This allows us to run the full pipeline without processing the entire 58GB dataset.
3.  **Monkey-Patching Config**: Dynamically override paths in the `Config` class to point to these mini metadata files and the new temporary output locations. Adjust hyperparameters (batch size, epochs) for speed.
4.  **Component Demonstration**:
    *   **BSON I/O**: Demonstrate reading raw images from `train.bson` using `BSONImageReader` and the mini metadata.
    *   **Feature Extraction**: Execute the `FeatureExtractor` on the mini datasets to generate `.npy` feature files using the pre-trained ResNet/EfficientNet backbones.
    *   **Dataset Loading**: Initialize `CachedFeatureDataset` with the generated features, verifying shape and MixUp augmentation logic.
    *   **Model Initialization**: Instantiate the `DualStreamProjectedNetwork` and verify the output shapes of its hierarchical heads (Level 1, Level 2, Level 3).
    *   **Training Loop**: Run a minimal training session (1 epoch) using `fit_model` to demonstrate the optimization process.
    *   **Inference**: Run `predict_test` on the mini test set to generate submission-formatted predictions.
5.  **Validation**: Use assertions throughout to confirm that data shapes, types, and logic flows are correct.
