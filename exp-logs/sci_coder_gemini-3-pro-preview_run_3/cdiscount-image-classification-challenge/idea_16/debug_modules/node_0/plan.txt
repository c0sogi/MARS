This script demonstrates the end-to-end usage of the provided library modules for the product categorization task. It performs the following steps:
1.  **Configuration**: Sets up a temporary working directory and overrides default configuration parameters (batch sizes, epochs) to ensure rapid execution on a small subset of data.
2.  **Hierarchy Mapping**: Demonstrates how to parse the category hierarchy using `HierarchyMapper`, validating the mapping between raw IDs and hierarchical labels.
3.  **Feature Extraction**: Runs the `DualBackboneExtractor` via `extract_features_for_split` on a small subset of the training BSON file to generate feature vectors. This validates the BSON parsing and image preprocessing pipeline.
4.  **Data Loading**: Initializes `CachedTensorDataset` and DataLoaders to verify that the pre-computed features can be loaded and batched correctly.
5.  **Model Training**: Instantiates the `DeepFeatureCascade` model and runs a short training loop using `train_model`. This validates the forward pass, loss calculation (including MixUp), and backpropagation.
6.  **Inference**: Simulates the inference phase by extracting features from a subset of the test data, generating predictions, and mapping the output class indices back to original category IDs.
