This script demonstrates the end-to-end usage of the provided library components for the product categorization task. It performs the following steps:

1.  **Configuration & Setup**: Patches the `Config` class to use a temporary working directory and reduced hyperparameters (small batch size, few epochs) for rapid execution.
2.  **Data Loading Verification**: Instantiates the `BSONProductDataset` and `DataLoader` to verify that raw BSON records are correctly parsed, images are extracted/preprocessed, and batches are collated correctly.
3.  **Model Architecture Verification**: Instantiates the `ImageEncoder` (ResNet-50 backbone) and `DualStatClassifier` (MLP) to validate input/output tensor shapes.
4.  **Feature Extraction Pipeline**: Runs the `extract_and_aggregate` function on a small subset of the training data to demonstrate how image embeddings are generated and pooled (Mean+Max) per product.
5.  **Training Loop**: Uses the extracted features to run a short training session via `train_model`, verifying the optimization loop and model checkpointing.
6.  **Inference & Submission**: Generates predictions using `generate_submission` on the demo data and validates the format of the output CSV.
