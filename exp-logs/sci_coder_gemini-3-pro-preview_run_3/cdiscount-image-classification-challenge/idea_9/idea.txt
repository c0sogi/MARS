Based on the lessons learned from the previous experiments, I propose the following optimized strategy. This solution synthesizes the efficiency of the decoupled architecture, the necessity of scaling data to match model capacity, and the importance of metric-aligned loss functions.

# Baseline Proposal: Full-Scale Decoupled ResNet-50 with Hierarchical Ensemble

### Model
I propose an **Ensemble of Hierarchical Multi-Task Networks** built upon a **ResNet-50** backbone.
*   **Backbone:** Use **ResNet-50** (pre-trained on ImageNet).
    *   *Rationale:* While **Cite solution_lesson_node_00005** showed that ResNet-50's 2048-dimensional features caused overfitting on a small subset (100k), the backbone itself captures richer representations than smaller models. By scaling the training data to the full 7 million records (see Data section), we can effectively utilize this high capacity without overfitting. The backbone will be **frozen**.
*   **Aggregation:** Apply **Mean Pooling** to the image features of each product. This creates a single 2048-dimensional embedding per product, maintaining the computational efficiency proven in **Cite solution_lesson_node_00003**.
*   **Hierarchical Classification Heads:** Instead of a single classifier, I will train an **ensemble of 5 independent Multi-Layer Perceptrons (MLPs)**. Each MLP will be structured to mirror the product taxonomy:
    *   **Shared Trunk:** A series of fully connected layers processing the product embedding.
    *   **Level 1 Head:** Predicts the coarse category (49 classes).
    *   **Level 2 Head:** Predicts the sub-category (483 classes).
    *   **Level 3 Head (Target):** Predicts the fine-grained category (5270 classes).
    *   *Innovation:* This multi-task structure acts as a strong regularizer, forcing the model to learn features that respect the semantic hierarchy of the products.

### Data
*   **Full-Dataset Decoupled Caching:** I will apply the decoupled feature extraction strategy to the **entire training dataset (~7 million products)** and the test set.
    *   *Strategic Retention:* This preserves the extreme training speed of the decoupled approach (**Cite solution_lesson_node_00003**), transforming the heavy visual task into a RAM-bound tabular one.
    *   *Correction:* Processing the full dataset is the direct fix for the failure in **Cite solution_lesson_node_00005**. With 7 million examples, the model has sufficient signal to learn the 2048-dimensional feature space of ResNet-50, which failed when restricted to 100k samples.
    *   *Feasibility:* Storing 7 million x 2048-dim float32 vectors requires ~57 GB of RAM, which fits comfortably within the 220 GB available.

### Training
*   **Feature-Space MixUp:** Since the backbone is frozen, standard image augmentation is impossible during the MLP training phase. I will implement **MixUp** on the cached feature vectors.
    *   *Technique:* Randomly interpolate pairs of feature vectors ($x' = \lambda x_i + (1-\lambda) x_j$) and their labels during training. This enforces linear behavior in the decision boundaries and prevents memorization of the tabular features.
*   **Loss Function:** Use a **Multi-Task Sum of Cross-Entropy Losses**: $L_{total} = L_{Level3} + L_{Level2} + L_{Level1}$.
    *   *Correction:* I will explicitly **exclude** inverse-frequency class weights. As demonstrated in **Cite solution_lesson_node_00004**, class weighting optimizes for macro-recall and harms the target metric (global accuracy). The hierarchical auxiliary tasks will instead provide the necessary gradient signal for under-represented classes by grouping them into larger parent categories.
*   **Optimizer:** Train the ensemble members using **AdamW** with Weight Decay.

### Evaluation
*   **Inference Pipeline:**
    1.  Load the pre-computed test set features from RAM.
    2.  Pass the features through all 5 trained Hierarchical MLPs.
    3.  Average the **Level 3** probability distributions (Softmax outputs) across the ensemble.
    4.  Select the category with the highest average probability as the final prediction.
