The implementation strategy follows the "Idea 5" proposal, utilizing a decoupled architecture to handle the large-scale dataset efficiently.

1.  **Setup**: Initialize the environment and set random seeds for reproducibility using `engine.set_seed`.
2.  **Feature Extraction**: Instantiate `FeatureExtractor` and run `run_all(load_cached_data=True)`. This step uses a frozen ResNet-50 to process the full training and test datasets. It checks for existing `.npy` files in the working directory to avoid redundant computation. If files are missing, it processes the BSON files, extracting 2048-dimensional embeddings and generating hierarchical labels (Level 1, Level 2, Level 3).
3.  **Training**: Call `engine.fit()`. This function loads the pre-computed embeddings into RAM using `EmbeddingDataset` and trains the `HierarchicalMLP`. The training uses a multi-task loss function (weighted sum of L1, L2, and L3 cross-entropy losses) and saves the model with the best validation accuracy.
4.  **Validation & Analysis**:
    *   Manually load the validation dataset and the best saved model.
    *   Compute the **Final Validation Metric** (Categorization Accuracy) on the hold-out set.
    *   Perform **Failure Analysis**: Calculate the correlation between prediction errors and input feature norms (to check if weak signals cause errors) and class frequencies (to check the impact of imbalance).
5.  **Submission**: Compare the final metric against the threshold (0.50636). If successful, invoke `engine.generate_submission()` to predict on the test set and save the `submission.csv`.
