# Baseline Proposal: Full-Scale ResNet-50 with Hierarchical Multi-Task Learning

### Model
I propose a **Hierarchical Multi-Task Network (H-MTN)** that leverages the taxonomy of the product categories to improve fine-grained classification.
*   **Backbone:** Upgrade the feature extractor to **ResNet-50** (pre-trained on ImageNet). This provides a richer feature space (2048-dim) than the ResNet-18 used in the successful baseline, essential for distinguishing 5,270 classes. The backbone will remain **frozen** to ensure high throughput (Cite solution_lesson_node_00003).
*   **Aggregation:** Apply **Mean Pooling** to the image features of each product. I will revert to this simple aggregation method (proven in Idea 2) rather than the complex Dual-Statistic pooling (Idea 4), as Mean Pooling produces a lower-dimensional embedding (2048 vs 4096), reducing the risk of overfitting.
*   **Hierarchical Classification Head:** Instead of a single flat classifier, the MLP will branch into three heads corresponding to the product hierarchy provided in `category_names.csv`:
    *   **Shared Layers:** A series of fully connected layers (with Batch Normalization and ReLU) to process the product embedding.
    *   **Head 1 (Auxiliary):** Predicts the **Level 1** Category (e.g., "Sports").
    *   **Head 2 (Auxiliary):** Predicts the **Level 2** Category (e.g., "Cycles").
    *   **Head 3 (Primary):** Predicts the **Level 3** Category (Target `category_id`).
    *   *Rationale:* Training with auxiliary losses for coarser categories acts as a regularizer, guiding the model to learn robust high-level features before refining them for the specific class, thereby improving generalization on the fine-grained target.

### Data
*   **Full-Dataset Decoupled Caching:** I will apply the decoupled feature extraction strategy to the **entire training dataset (~7 million products)** and the test set.
    *   **Extraction:** Iterate through `train.bson` and `test.bson` using the frozen ResNet-50 on the A100 GPU.
    *   **Storage:** Store the aggregated 2048-dimensional product embeddings in RAM. The estimated memory footprint is ~56 GB, which fits comfortably within the 220 GB available.
    *   **Correction:** This explicitly addresses the failure of Idea 4 (Cite solution_lesson_node_00005) by ensuring the dataset size is large enough (7M samples) to support the high dimensionality of the ResNet-50 features, preventing the overfitting observed when using subsets.
*   **Label Engineering:** Pre-process `category_names.csv` to map every `category_id` to its corresponding Level 1 and Level 2 parent classes, creating a multi-label target for each training sample.

### Training
*   **Loss Function:** Use a **Multi-Task Sum of Cross-Entropy Losses**: $L_{total} = L_{Level3} + \lambda_1 L_{Level2} + \lambda_2 L_{Level1}$.
    *   I will use standard Cross-Entropy Loss **without** inverse-frequency class weights. As established, weighting for class imbalance harms global accuracy (Cite solution_lesson_node_00004).
*   **Optimizer:** Use **AdamW** with a standard learning rate schedule.
*   **Procedure:** Train the Multi-Task MLP on the in-memory feature dataset. Because the data is RAM-resident, I will use a large batch size (e.g., 4096) for rapid convergence.

### Evaluation
*   **Inference:**
    1.  Load the pre-computed test set embeddings from RAM.
    2.  Pass them through the trained H-MTN.
    3.  Take the prediction from the **Level 3 Head** (the primary target) as the final `category_id`.
*   **Efficiency:** This pipeline retains the extreme efficiency of the decoupled approach (Cite solution_lesson_node_00003), allowing the heavy visual processing to be done once, while the complex hierarchical learning happens rapidly on the tabular features.
