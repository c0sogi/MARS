# Baseline Proposal: Full-Scale ResNet-50 with Attention-Based Aggregation

### Model
I propose a **Multi-Stage Attention Network** that builds upon the efficiency of decoupled feature extraction while addressing the expressivity limitations of simple mean pooling.
*   **Backbone:** Upgrade the feature extractor from ResNet-18 to **ResNet-50** (pre-trained on ImageNet). This deeper architecture captures more complex visual hierarchies essential for distinguishing between 5,270 fine-grained categories. The backbone will remain **frozen** to maintain the computational benefits discovered previously.
*   **Learnable Aggregation (Attention Head):** Instead of the static mean pooling used in the previous attempt, I will implement an **Attention-Based Pooling** mechanism (inspired by Multiple Instance Learning).
    *   For a product with $N$ images, the model will generate a set of feature vectors.
    *   A lightweight attention network will compute a scalar "relevance score" for each image, allowing the model to dynamically prioritize the most informative view (e.g., focusing on the product cover while down-weighting generic back-of-box text).
    *   The final product embedding is a weighted sum of the image features based on these learned attention scores.
*   **Classifier:** A Multi-Layer Perceptron (MLP) with **Dropout** and **Batch Normalization** layers will process the aggregated embedding to predict the category.

### Data
*   **Decoupled Feature Caching:** I will apply the **Decoupled Feature Caching** strategy (Cite solution_lesson_node_00003) to separate the heavy computer vision workload from the classification training.
*   **Full Dataset Utilization:** Unlike the previous iteration which relied on a small subset, I will process the **entire training dataset (7 million products)**.
    *   **Extraction:** Iterate through the full `train.bson` and `test.bson` once using the frozen ResNet-50 on the GPU.
    *   **Storage:** The resulting feature vectors (2048-dimensional) will be stored in RAM. With ~10 million total images, the memory footprint (~80 GB) fits comfortably within the available 220 GB RAM.
    *   **Benefit:** This leverages the lesson that caching transforms the task into a fast tabular problem, enabling us to train on the full dataset to mitigate the overfitting observed with the 200k subset.

### Training
*   **In-Memory Training:** The Attention-MLP head will be trained using the pre-loaded features in RAM. This allows for extremely high batch sizes (e.g., 4096) and rapid epoch completion.
*   **Class Imbalance Handling:** To address the severe class imbalance (up to 8000x difference), I will implement **Class-Weighted Cross-Entropy Loss**. Weights will be pre-calculated based on the inverse frequency of each category in the full training set.
*   **Regularization:** Given the high capacity of the ResNet-50 features, I will employ **aggressive Dropout** (e.g., p=0.5) within the MLP and **Weight Decay** in the AdamW optimizer to prevent overfitting, a key weakness identified in the previous lesson.

### Evaluation
*   **Inference Pipeline:**
    1.  Load the pre-computed test set features from RAM (extracted during the data processing phase).
    2.  Pass the feature sets through the trained Attention-MLP head to generate class probabilities.
    3.  Select the `category_id` with the highest probability.
*   **Optimization:** Since features are already cached, inference is purely a matrix multiplication task, allowing the entire test set to be predicted in seconds.
