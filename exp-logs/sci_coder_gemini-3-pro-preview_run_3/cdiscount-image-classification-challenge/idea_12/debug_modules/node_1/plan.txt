The `AttributeError: 'Pandas' object has no attribute '_id'` occurs because Pandas' `itertuples()` method generates `namedtuple` objects for each row. Since valid Python identifiers (and thus `namedtuple` field names) cannot start with an underscore, Pandas automatically renames the `_id` column (typically to a positional name like `_1`), making `row._id` inaccessible. To resolve this, I will rename the `_id` column to `product_id` within the `__iter__` method before iteration, ensuring the field is accessible via a valid attribute name.
