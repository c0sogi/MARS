The implementation strategy is as follows:

1.  **Configuration Override**: We will first import the `library.config` module and override key parameters (paths, batch sizes, sample sizes, epochs) to ensure the script runs in a "demo mode" within a separate working directory (`./working/demo_execution`). This prevents overwriting existing work and ensures execution finishes quickly (using only 50 samples).
2.  **Hierarchy Verification**: We will instantiate the `HierarchyMapper` to generate the category mappings and verify that the mapping logic (L3 to L1/L2 parents) is consistent.
3.  **Feature Extraction**: We will trigger the `extract_and_cache_features` function. Because we set `DEBUG_SAMPLE_SIZE` to 50, this will process a tiny subset of the `train.bson` and `test.bson` files, extracting features using the pre-defined ResNet/EfficientNet backbone and saving them to `.npy` files.
4.  **Dataset Loading**: We will load the generated `.npy` files using `CachedFeatureDataset` and verify that the data shapes and hierarchical labels are correct.
5.  **Model Training**: We will run `train_ensemble` (reduced to a single model for speed). This demonstrates the training loop, loss calculation (MultiTaskLoss), and checkpoint saving.
6.  **Inference**: We will run `generate_submission` using the trained demo model to produce a submission CSV, verifying the output format.
