This script demonstrates the end-to-end usage of the provided machine learning pipeline components. It performs the following steps:

1.  **Configuration**: Patches training hyperparameters (epochs, ensemble size) to ensure the demo completes quickly.
2.  **Data Preparation**: Creates small subsets of the provided metadata (train, val, test) to simulate a full run on a manageable scale.
3.  **Validation**: Verifies the `CategoryEncoder` and `RawImageDataset` to ensure data is correctly loaded from BSON files and encoded.
4.  **Feature Extraction**: Uses `extract_features_to_disk` to process the image subsets through the EfficientNet backbone and save features to disk.
5.  **Training**: Trains a lightweight MLP classifier on the extracted features using `train_ensemble`.
6.  **Inference**: Generates predictions on the test subset and creates a submission file.
