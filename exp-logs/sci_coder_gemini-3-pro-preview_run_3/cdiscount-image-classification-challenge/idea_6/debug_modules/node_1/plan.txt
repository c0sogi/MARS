The issue stems from the `ReduceLROnPlateau` scheduler initialization in `library/training.py`, which includes the `verbose=True` argument. This argument has been deprecated and removed in recent PyTorch versions (including the installed 2.8.0), causing a `TypeError`. I will remove this argument to fix the crash. Additionally, I will change the initialization of `best_val_acc` from `0.0` to `-1.0`. This ensures that even if the model achieves 0.0 accuracy (the minimum possible), the condition `val_acc > best_val_acc` will evaluate to true, guaranteeing that a model checkpoint is saved and preventing a subsequent `FileNotFoundError` when loading the best model.
