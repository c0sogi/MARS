# Baseline Proposal: Decoupled EfficientNet-B0 with Feature-Space MixUp

### Model
I propose a **Decoupled Feature Extraction** architecture that replaces the ResNet family with an **EfficientNet-B0** backbone.
*   **Backbone:** Use **EfficientNet-B0** (pre-trained on ImageNet) via the `timm` library.
    *   *Structural Innovation:* EfficientNet-B0 produces a **1280-dimensional** feature vector, which is significantly more compact than ResNet-50's 2048 dimensions (Cite solution_lesson_node_00005). This reduction in dimensionality naturally acts as a regularizer, reducing the parameter count of the downstream classifier and mitigating the risk of overfitting observed in previous experiments. The backbone will be **frozen**.
*   **Aggregation:** Apply **Mean Pooling** to the image features of each product. This retains the computational simplicity proven successful in **Lesson 00003**.
*   **Classifier:** A Multi-Layer Perceptron (MLP) with Batch Normalization, ReLU activations, and Dropout.

### Data
*   **Full-Dataset Decoupled Caching:** I will apply the decoupled feature extraction strategy to the **entire training dataset (~7 million products)** and the test set.
    *   *Strategic Retention:* This leverages the speed of the decoupled approach (Cite solution_lesson_node_00003).
    *   *Correction:* By using the full dataset, we ensure the volume of data is sufficient to support the model's capacity, directly addressing the "dimensionality vs. data size" failure mode identified in **Lesson 00005**.
*   **Preprocessing:** Images will be resized to 224x224 (EfficientNet standard) and normalized. The extracted features (1280-dim) will be stored in RAM (approx. 35 GB for 7M samples), which fits comfortably within the 220 GB limit.

### Training
*   **Feature-Space Augmentation (MixUp):** Since the backbone is frozen, we lose standard image augmentations. To compensate, I will implement **MixUp Regularization** directly on the cached feature vectors during MLP training.
    *   *Innovation:* Pairs of feature vectors and their labels will be linearly interpolated ($x' = \lambda x_i + (1-\lambda) x_j$) to create synthetic training samples. This enforces linearity in the decision boundaries and improves generalization on the tabular feature space.
*   **Loss Function:** Use standard **Cross-Entropy Loss**.
    *   *Correction:* I will explicitly **exclude** inverse-frequency class weights, as **Lesson 00004** demonstrated that they optimize for macro-recall at the expense of the target metric (global accuracy).
*   **Ensembling:** Train **5 independent MLP models** on the full cached dataset using different random seeds. The low computational cost of training on cached features makes this feasible within the runtime limit.

### Evaluation
*   **Inference:**
    1.  Load the pre-computed test set features from RAM.
    2.  Pass the features through all 5 trained MLPs.
    3.  Average the predicted probabilities (Softmax outputs) across the ensemble.
    4.  Select the category with the highest average probability.
