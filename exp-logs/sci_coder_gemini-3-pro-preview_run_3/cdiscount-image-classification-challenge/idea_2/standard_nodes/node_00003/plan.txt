The implementation strategy follows a strict pipeline designed for speed and memory efficiency, leveraging the provided library functions.

1.  **Setup & Configuration**: We initialize the environment by setting random seeds for reproducibility. We define subset sizes for the training (200,000 samples) and validation (50,000 samples) sets to ensure the "Fast Baseline" executes within the time limit, while keeping the Test set full (1.7M samples) to generate a valid submission.
2.  **Feature Extraction (Stage 1)**: We utilize the `FrozenResNet` model to extract 512-dimensional feature vectors from the images. This is performed via the `extract_features` function, which handles batching, GPU acceleration, and caching.
    *   We process the **Train** and **Validation** subsets first.
    *   We process the **Test** set in full.
    *   The results (embeddings, labels, IDs) are stored in binary format (NumPy) in the `./working` directory to allow for rapid reloading if the script is re-run.
3.  **Model Training (Stage 2)**: We train a lightweight Multi-Layer Perceptron (MLP) using `train_mlp`. This model learns to map the pre-computed image embeddings to the 5270 product categories. Training on embeddings is extremely fast compared to end-to-end CNN training.
4.  **Validation & Analysis**:
    *   We evaluate the trained model on the validation embeddings to compute the **Categorization Accuracy**.
    *   We perform **Failure Analysis** by calculating the Pearson correlation between the magnitude (L2 norm) of the image embeddings and the classification error. This helps identify if "weaker" feature signals correlate with incorrect predictions.
5.  **Submission**: We generate predictions for the full test set. These predictions (class indices) are mapped back to their original `category_id` values using the mapping derived from `category_names.csv`. The final result is saved to `./submission/submission.csv` as required.
