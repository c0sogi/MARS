Implementation strategy:
1.  **Setup & Initialization**: Initialize the environment using the provided `Config` class and set random seeds for reproducibility.
2.  **Task-Adaptive Pretraining (TAPT)**: Execute the `run_tapt()` function to fine-tune the `xlm-roberta-base` model on the domain-specific text corpus (context from train/val/test). This adapts the embeddings to Hindi/Tamil morphology.
3.  **Data Preparation**: Call `prepare_qa_data()` to generate tokenized features and PyTorch datasets for training, validation, and testing. Crucially, manually load the validation features from the generated Parquet cache to obtain the raw text and offsets required for validation inference.
4.  **Ensemble Training**: Iterate through the defined seeds (42, 43, 44) and train three independent QA models using `train_fold()`. Each model starts from the TAPT-adapted weights.
5.  **Validation & Metrics**:
    *   Run inference on the validation set for each trained model.
    *   Aggregate predictions using Majority Voting.
    *   Compute the Word-level Jaccard score against the ground truth loaded from `metadata/val.csv`.
    *   Print the final metric in the required format.
6.  **Failure Analysis**: Calculate correlations between the prediction error (1 - Jaccard) and input features (context length, question length) to identify performance bottlenecks.
7.  **Submission**: If the validation metric exceeds the specified threshold, execute `predict_and_submit()` to generate predictions for the test set and save the `submission.csv` file.
