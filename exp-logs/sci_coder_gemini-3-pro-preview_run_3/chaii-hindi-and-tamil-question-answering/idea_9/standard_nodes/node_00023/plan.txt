The following is the implementation strategy for the `runfile.py` script:

1.  **Configuration & Setup**: Import the provided library modules. Override the `Config.EPOCHS` and `Config.TAPT_EPOCHS` to smaller values (3 and 3 respectively) to ensure the pipeline executes quickly within the time limit, while maintaining the full pipeline logic. Set the random seed for reproducibility.
2.  **Task-Adaptive Pretraining (TAPT)**: Call `run_tapt_training` to fine-tune the `xlm-roberta-base` model on the domain corpus (concatenated train, val, and test contexts). This produces the domain-adapted model weights.
3.  **QA Model Training**: Iterate through the defined seeds in `Config.SEEDS`. For each seed, call `train_model` using the TAPT-adapted weights as initialization. Collect the paths of the saved best models.
4.  **Validation & Failure Analysis**:
    *   Load the validation dataset and prepare a `DataLoader`.
    *   Run inference on the validation set using each trained model via `predict_for_model`.
    *   Aggregate the predictions using `majority_vote_ensemble`.
    *   Compute the Jaccard score for each sample against the ground truth.
    *   Calculate and print the **Final Validation Metric** (mean Jaccard).
    *   Perform failure analysis by creating a DataFrame of errors and calculating the Pearson correlation between the error magnitude (`1 - Jaccard`) and input features (Context Length, Question Length). Print these correlations.
5.  **Submission**: Compare the Final Validation Metric against the threshold (`0.3011529653320698`). If the metric is higher, call `generate_submission` to create the final `submission.csv` using the ensemble of trained models.
