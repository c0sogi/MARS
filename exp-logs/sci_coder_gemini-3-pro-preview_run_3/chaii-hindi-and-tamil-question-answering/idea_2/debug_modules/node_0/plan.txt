The following strategy outlines the implementation of a self-contained Python script to demonstrate the Question Answering pipeline:

1.  **Configuration & Setup**: We will import the `Config` class and override specific parameters (paths, epochs, seeds) to create a lightweight "demo" environment. This ensures the code runs quickly (within minutes) and does not overwrite existing production artifacts. We will use a dedicated working directory (`./working/demo_run`).
2.  **Metric Verification**: We will validate the `jaccard` and `compute_score` functions from `utils.py` using assertions to ensure the evaluation logic is correct.
3.  **Data Loading**: We will invoke `get_dataloaders` with `debug=True`. This triggers the processing of a small subset (20 samples) of the data and caches it. We will inspect the resulting DataLoader batches to verify tensor shapes and keys.
4.  **Model Check**: We will instantiate the model using `get_model`, move a batch of data to the GPU, and perform a forward pass. We will assert that the output contains the expected loss and logits.
5.  **Training Execution**: We will run `train_runner` for a single seed. This utilizes the cached debug data to train the model for 1 epoch. We will verify that the model checkpoint (`.pt` file) is successfully saved.
6.  **Inference Execution**: We will run `run_inference_pipeline`. This will load the trained model and the cached test data to generate predictions. We will verify the final `submission.csv` format.
