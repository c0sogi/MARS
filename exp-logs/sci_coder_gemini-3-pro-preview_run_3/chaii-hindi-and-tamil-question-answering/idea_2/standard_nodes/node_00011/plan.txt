To improve the model's performance, I will implement a strategy focused on mitigating the severe class imbalance inherent in the sliding window approach for long documents. This directly addresses the lessons learned from the previous failure where the model converged to predicting "no answer" for everything.

**Strategy:**
1.  **Downsample Negative Windows (Cite solution_lesson_node_00010):** I will modify the data loading pipeline to filter out a significant portion (80%) of "negative" windows (windows containing no answer) from the training set. This will artificially balance the positive-to-negative ratio, ensuring the model receives sufficient gradient signal for the "Answer" class.
2.  **Increase Batch Size (Cite solution_lesson_node_00010):** I will increase the batch size from 8 to 16. Combined with downsampling, this ensures that a higher percentage of batches contain at least one positive example, preventing the model from collapsing to a trivial "all-background" solution.
3.  **Suppress Output:** I will remove progress bars (`tqdm`) to comply with the requirement to only print required information.
