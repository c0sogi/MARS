This script demonstrates the end-to-end pipeline for the Hindi/Tamil Question Answering task using the provided library. It covers Task-Adaptive Pretraining (TAPT), data loading verification, QA model fine-tuning, and inference generation.

To ensure the demonstration runs quickly within the time limit, the script monkey-patches the `Config` class to use a separate working directory, reduces the number of epochs to 1, limits the batch size, and runs only a single random seed.
