Here is the implementation strategy and the complete Python script for `runfile.py`.

### Implementation Strategy

1.  **Configuration and Setup**: Import the provided library modules. Override `Config.EPOCHS` to a lower value (5) to ensure the baseline runs quickly within the time limit. Initialize the environment using `Config.setup()`.
2.  **Data Loading**: Use `prepare_data(load_cached_data=True)` to efficiently load the processed PyTorch datasets. Load the raw validation and test CSVs to align predictions with ground truth and IDs.
3.  **Model Initialization**: Instantiate the `QATokenClassifier` and `AutoTokenizer`. Create the `Trainer`, Optimizer (AdamW), and Learning Rate Scheduler.
4.  **Training**: Execute a training loop for the specified epochs. At each epoch, calculate training loss and validation Jaccard score. Save the model checkpoint whenever the validation score improves.
5.  **Validation & Metric Reporting**: Load the best performing model. Run inference on the validation set to generate prediction strings. Calculate the overall Jaccard score and print it in the strict format: `Final Validation Metric: <value>`.
6.  **Failure Analysis**: Calculate the error ($1 - \text{Jaccard}$) for each validation sample. Extract features (Context Length, Question Length, Language). Compute and print the Pearson correlation between these features and the model error to identify performance bottlenecks.
7.  **Submission**: Run inference on the test set using the best model. Create a DataFrame with `id` and `PredictionString` columns and save it to `./submission/submission.csv`.
