Based on the lessons learned from previous attempts, I propose the **Scalable Physics-Regularized Continuous Filter Network (SP-CFN)**. This strategy resolves the conflict between the high performance of the simple baseline (due to data scalability) and the theoretical benefits of the advanced models (physics-awareness and geometric expressivity) by integrating them into a unified, efficient architecture.

### Model
**Backbone: Node-Centric Continuous Filter GNN**
We will revert to a **Node-Centric** architecture (similar to SchNet) rather than the Edge-Centric/Triplet models (DMPNN) proposed in later ideas. Lessons 00029 and 00035 demonstrated that on dense radius graphs, Node-Centric models are computationally far more efficient ($O(Nk)$ vs $O(Nk^2)$) and converge significantly faster.
*   **Continuous Filter Convolutions:** We will employ continuous filters generated from **Gaussian Radial Basis Functions (RBF)** of inter-atomic distances **Cite solution_lesson_node_00007**. Crucially, we will enforce that these filters condition the message passing at **every interaction layer**, not just at the input, to preventing geometric signal dilution **Cite solution_lesson_node_00031**.

**Structural Innovation: Physics-Regularized Auxiliary Branches**
To capture the electronic environment without the computational cost of explicit angular modeling, we will attach **Auxiliary Prediction Heads** to the node embeddings. These heads will predict **Magnetic Shielding Tensors** and **Mulliken Charges**. This forces the shared latent space to encode valid physical constraints (electron density and magnetic environment), significantly improving sample efficiency **Cite solution_lesson_node_00024**.

**Readout: Edge-Injected Conditional Shared Head**
We will replace the disjoint or simple readouts of previous ideas with a **Shared Conditional Architecture**:
1.  **Shared Backbone:** A single MLP will predict for all coupling types to leverage transfer learning across the dataset **Cite solution_lesson_node_00022**.
2.  **Conditional Embedding:** We will concatenate a learnable **Coupling Type Embedding** to the input to handle target heterogeneity **Cite solution_lesson_node_00022**.
3.  **Edge Injection:** We will explicitly concatenate the **RBF-expanded distance** (edge feature) of the interacting pair with their learned node embeddings ($h_i, h_j$) in the final layer. This resolves the bottleneck where precise distance information was lost in node pooling **Cite solution_lesson_node_00011**.

### Data
**Preprocessing: Flattened Structure-of-Arrays (SoA)**
To ensure we can train on the **full 3.3M+ dataset** (the primary driver of the baseline's success **Cite solution_lesson_node_00014**), we will strictly utilize a **Flattened Contiguous Memory Layout**. We will pre-compute the graph topology (radius graph 5.0 Å) and store components (nodes, edge indices, RBF attributes) as monolithic Numpy arrays. This eliminates the overhead of Python object lists that caused previous advanced models to fail **Cite solution_lesson_node_00016**.

**Target Standardization**
*   **Primary:** We will apply **Per-Group Target Standardization**, transforming targets $z = \frac{y - \mu_{type}}{\sigma_{type}}$ independently for each of the 8 coupling types **Cite solution_lesson_node_00003**.
*   **Auxiliary:** We will **standardize the auxiliary targets** (Shielding/Charges) to zero mean and unit variance. This prevents the "Task Dominance" failure where auxiliary losses hijacked the gradient descent **Cite solution_lesson_node_00009**.
*   **Indexing:** We will enforce **Canonical Integer Indexing** for all categorical maps immediately upon loading **Cite solution_lesson_node_00017**.

### Training
**Loss Function**
We will use a balanced Multi-Task Loss: $L_{total} = L_{coupling} + \lambda (L_{shielding} + L_{charge})$.
*   **Primary:** We will use **L1 Loss (MAE)** to align with the competition metric and prevent outliers in the heavy-tailed target distribution from distorting gradients **Cite solution_lesson_node_00013**.
*   **Balancing:** With all targets standardized to unit variance, we will set $\lambda \approx 0.1$, ensuring auxiliary tasks act as regularizers rather than dominant objectives **Cite solution_lesson_node_00009**.

**Optimizer**
We will use **AdamW** with a **Cosine Annealing Warm Restarts** scheduler to efficiently navigate the loss landscape.

### Evaluation
**Inference Pipeline**
1.  Load test structures into the flattened SoA format.
2.  Pass data through the SP-CFN.
3.  Extract node embeddings ($h_i, h_j$), the specific edge distance features ($e_{ij}$), and the coupling type embedding.
4.  Pass these to the **Shared Conditional Head** to predict the standardized value $z_{pred}$.
5.  **Inverse Transform:** Convert predictions back to the physical scale using the training statistics: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ **Cite solution_lesson_node_00003**.
