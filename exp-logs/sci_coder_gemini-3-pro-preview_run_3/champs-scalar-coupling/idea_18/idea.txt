# Optimized Strategy: Molecule-Parallel Deep Interaction Network (MP-DIN)

### Model
**Backbone: Deep Node-Centric Continuous Filter Network**
We will utilize a **Node-Centric Graph Neural Network** (similar to SchNet) rather than an Edge-Centric or Triplet-based model. Empirical evidence confirms that Node-Centric models converge significantly faster and scale linearly ($O(Nk)$) on the dense radius graphs required for this task, whereas Triplet models suffer from combinatorial explosion ($O(Nk^2)$), forcing data subsampling **Cite solution_lesson_node_00029**, **Cite solution_lesson_node_00035**.
*   **Continuous Filter Convolutions:** We will employ continuous filters generated from **Gaussian Radial Basis Functions (RBF)** of inter-atomic distances **Cite solution_lesson_node_00007**. Crucially, we will enforce that these filters condition the message passing at **every interaction layer**, not just at the input, to prevent the geometric distance signal from being diluted in deeper layers **Cite solution_lesson_node_00031**.
*   **Increased Depth:** Leveraging the computational speedup from the data pipeline (see below), we will increase the network depth (e.g., to 6-8 interaction blocks). This allows the model to implicitly capture long-range angular dependencies via multi-hop propagation, avoiding the numerical instability and computational cost of explicit angular features **Cite solution_lesson_node_00008**.

**Readout: Interaction-Aware Shared Conditional Head**
We will implement a robust readout architecture that explicitly models pairwise interactions, correcting the flaws of previous "New" solutions:
1.  **Shared Backbone:** A single MLP will predict for all coupling types to leverage transfer learning across the dataset **Cite solution_lesson_node_00022**.
2.  **Conditional Embedding:** We will concatenate a learnable **Coupling Type Embedding** to the input to handle target heterogeneity **Cite solution_lesson_node_00022**.
3.  **Edge Injection:** We will explicitly concatenate the **RBF-expanded distance** ($e_{ij}$) of the interacting pair with their learned node embeddings ($h_i, h_j$) in the final layer. This resolves the bottleneck where precise distance information was lost in node pooling **Cite solution_lesson_node_00011**.
4.  **Explicit Multiplicative Interaction:** Crucially, we will calculate and concatenate the **Dot Product** ($h_i \cdot h_j$) of the node embeddings. Previous experiments proved that standard MLPs struggle to approximate this multiplicative interaction, and its removal was a primary cause of failure in advanced models **Cite solution_lesson_node_00036**.

### Data
**Preprocessing: Flattened SoA with Molecule-Parallel Batching**
To enable training on the **full 3.3M+ dataset** (the primary driver of success **Cite solution_lesson_node_00014**), we will strictly utilize a **Flattened Contiguous Memory Layout (Structure-of-Arrays)**. We will pre-compute graph topologies and store them as monolithic Numpy arrays to minimize memory overhead **Cite solution_lesson_node_00016**.
*   **Molecule-Centric Batching:** We will batch data by **Molecule** rather than by coupling pair. This allows the GNN to process a molecule once and predict *all* coupling pairs within it simultaneously, yielding a **40x speedup** compared to the baseline's redundant processing **Cite solution_lesson_node_00037**.
*   **Canonical Indexing:** We will enforce **Canonical Integer Indexing** for all categorical maps immediately upon loading to prevent silent data corruption **Cite solution_lesson_node_00017**.

**Target Standardization**
*   **Per-Group Standardization:** We will transform targets $z = \frac{y - \mu_{type}}{\sigma_{type}}$ independently for each of the 8 coupling types. This prevents high-magnitude types (like `1JHC`) from dominating the gradients **Cite solution_lesson_node_00003**.

### Training
**Loss Function**
*   **Primary:** We will use **L1 Loss (Mean Absolute Error)**. This aligns the optimization with the competition metric and prevents outliers in the heavy-tailed target distribution from distorting gradients **Cite solution_lesson_node_00013**.
*   **Exclusion of Auxiliary Tasks:** We will **exclude** auxiliary tasks (Shielding/Charges). Lessons learned indicate that these tasks often dominate the gradient or cause negative transfer when combined with a shared backbone in a regression setting **Cite solution_lesson_node_00037**, **Cite solution_lesson_node_00009**. The efficiency of the pipeline allows us to focus purely on the primary target.

**Optimizer**
We will use **AdamW** with a **Cosine Annealing Warm Restarts** scheduler. The molecule-parallel efficiency allows for a more aggressive learning rate schedule and more epochs within the 24-hour limit.

### Evaluation
**Inference Pipeline**
1.  Load test structures into the flattened SoA format.
2.  Pass full molecular graphs through the MP-DIN backbone.
3.  For every target pair in the molecule, extract node embeddings ($h_i, h_j$), compute the dot product ($h_i \cdot h_j$), and retrieve the specific edge distance filters ($e_{ij}$).
4.  Pass these features (along with the coupling type embedding) to the **Shared Conditional Head** to predict the standardized value $z_{pred}$.
5.  **Inverse Transform:** Convert predictions back to the physical scale using the training statistics: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ **Cite solution_lesson_node_00003**.
