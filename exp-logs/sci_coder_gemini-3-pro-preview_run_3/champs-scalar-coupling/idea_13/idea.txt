# Optimized Strategy: Scalable Directional Message Passing with Shared Conditional Readout

### Model
1.  **Backbone: Directional Message Passing (DMPNN) with Continuous Filters**
    *   **Edge-Centric Architecture:** To capture the bond angles critical for scalar coupling (via the Karplus equation), the model will maintain and update embeddings for **directed edges** ($j \to i$) rather than atoms. This allows the explicit aggregation of messages from "preceding" edges ($k \to j$) to model the angle $\theta_{kji}$ **Cite solution_lesson_node_00020**.
    *   **Continuous Filter Convolutions:** We will replace static edge weights with **Continuous Filter Convolutions** to learn non-linear physical interactions.
        *   **Distances:** Bond lengths will be expanded using **Gaussian Radial Basis Functions (RBF)** and passed through an MLP to generate dynamic filters **Cite solution_lesson_node_00007**.
        *   **Angles:** The cosine of bond angles ($\cos \theta_{kji}$) will be computed and expanded using **Gaussian RBFs** defined over the interval $[-1, 1]$. This avoids the numerical instability of recursive Spherical Bessel Functions while retaining high-dimensional expressivity **Cite solution_lesson_node_00008**.

2.  **Readout: Shared Conditional Architecture with Edge Injection**
    *   **Edge Injection:** To eliminate the information bottleneck identified in previous iterations, the final prediction vector will be constructed by explicitly concatenating the **learned edge embedding** ($e_{ij}$) of the interacting pair with the node embeddings ($h_i, h_j$). This injects the precise, high-frequency geometric information captured by the DMPNN directly into the regressor **Cite solution_lesson_node_00011**.
    *   **Shared Conditional Head:** Instead of disjoint heads (which fragmented the training signal), we will use a **Single Shared MLP**. To handle target heterogeneity, we will concatenate a learnable **Coupling Type Embedding** (e.g., a vector for `1JHC`) to the input. This allows the model to learn universal physical laws (like distance decay) from the entire dataset while modulating predictions for specific types **Cite solution_lesson_node_00022**.

3.  **Regularization: Physics-Informed Auxiliary Heads**
    *   We will attach auxiliary heads to the node embeddings to predict **Magnetic Shielding Tensors** and **Mulliken Charges**. This forces the shared latent space to encode valid electronic environments, significantly improving sample efficiency **Cite solution_lesson_node_00024**.

### Data
1.  **Preprocessing: Flattened Structure-of-Arrays (SoA)**
    *   **Structural Innovation:** We will abandon the object-oriented `InMemoryDataset` (list of `Data` objects) that caused previous directional models to run out of memory. Instead, we will pre-compute the graph topology (radius graph 5.0 Å) and triplet indices ($k, j, i$) and store them as **monolithic, flattened Numpy arrays** (e.g., one giant `edge_index` tensor, one `triplet_index` tensor). This "Structure-of-Arrays" layout minimizes memory fragmentation and Python overhead, enabling training on the full 3.3M+ dataset **Cite solution_lesson_node_00016**.
    *   **Canonical Indexing:** We will ensure all categorical maps (coupling types) use integer indices immediately upon loading to prevent silent data corruption **Cite solution_lesson_node_00017**.

2.  **Target Standardization**
    *   **Primary:** We will strictly apply **Per-Group Target Standardization**. We will calculate the mean ($\mu_{type}$) and standard deviation ($\sigma_{type}$) for the `scalar_coupling_constant` independently for each of the 8 coupling types. The training targets will be transformed: $z = \frac{y - \mu_{type}}{\sigma_{type}}$ **Cite solution_lesson_node_00003**.
    *   **Auxiliary:** We will also standardize the auxiliary targets (Shielding/Charges) to zero mean and unit variance. This ensures their loss magnitudes are comparable to the primary task, preventing task dominance **Cite solution_lesson_node_00009**.

### Training
1.  **Loss Function**
    *   **Primary:** We will use **L1 Loss (Mean Absolute Error)**. This aligns the optimization with the competition metric and prevents outliers in the heavy-tailed target distribution from distorting gradients (unlike MSE) **Cite solution_lesson_node_00013**.
    *   **Total:** $L_{total} = L_{coupling\_L1} + \lambda (L_{shielding\_L1} + L_{charge\_L1})$, with $\lambda \approx 0.1$. Since all targets are standardized to unit variance, this weighting ensures the auxiliary tasks act as regularizers rather than dominant objectives **Cite solution_lesson_node_00009**.
2.  **Optimizer**
    *   **AdamW** with a **Cosine Annealing Warm Restarts** scheduler to efficiently navigate the loss landscape and refine the solution within the 24-hour limit.

### Evaluation
1.  **Inference**
    *   Load test structures into the flattened SoA format.
    *   Pass through the DMPNN.
    *   Extract $h_i, h_j$, the specific edge embedding $e_{ij}$, and the coupling type embedding.
    *   Pass to the **Shared Conditional Head** to predict $z_{pred}$.
2.  **Inverse Transformation**
    *   Convert predictions back to the physical scale: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ **Cite solution_lesson_node_00003**.
