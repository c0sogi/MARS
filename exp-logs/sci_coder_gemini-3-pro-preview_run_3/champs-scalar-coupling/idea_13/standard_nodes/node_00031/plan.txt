The `CUDA out of memory` error is caused by the `BATCH_SIZE` of 1024 being too large for the `DMPNN` architecture, which explicitly models bond angles using triplets of atoms. As explained in `debug_lesson_8` (Cite debug_lesson_8), geometric GNNs experience a combinatorial explosion of intermediate tensors for triplets ($O(N \times \text{degree}^2)$), causing memory usage to scale aggressively with batch size. To resolve this, I will reduce the `BATCH_SIZE` in `library/config.py` from 1024 to 256, which will reduce the number of triplets processed in parallel and keep memory usage within the 40GB limit of the A100 GPU.
