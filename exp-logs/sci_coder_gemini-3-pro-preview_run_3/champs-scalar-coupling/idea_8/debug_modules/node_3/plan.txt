The `UnpicklingError` occurs because `torch.load` in PyTorch 2.6+ defaults to `weights_only=True`, which restricts loading to a safe allowlist of types. The `TargetScaler` saves a state dictionary containing numpy scalars (generated by Pandas aggregations), which are not on this default allowlist. To resolve this, I will explicitly set `weights_only=False` in the `TargetScaler.load` method, mirroring the successful fix applied to the dataset loader in Lesson 15. Cite: debug_lesson_15
