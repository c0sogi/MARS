The following script demonstrates the usage of the provided library files to train and evaluate the Scalar Coupling Prediction model.

### Implementation Strategy
1.  **Configuration Override**: We modify the `Config` class attributes to direct outputs to a temporary directory (`./working/demo_run`) and reduce parameters (epochs, batch size, debug samples) for a rapid execution. We ensure all dependent path variables in `Config` are updated to reflect the new working directory.
2.  **Component Verification**:
    *   **GaussianSmearing**: We instantiate this layer and verify that it correctly expands scalar distances into RBF vectors.
    *   **TargetScaler**: We create a synthetic dataframe to test the fitting, transformation, and inverse transformation logic, ensuring data integrity.
3.  **Data Loading**: We utilize `get_data_loaders` with `debug=True`. This triggers the `MoleculeDataset` processing logic on a small subset (50 molecules) of the metadata. We assert that the loaders return valid PyTorch Geometric `Batch` objects with the expected attributes (`x`, `edge_index`, `coupling_index`).
4.  **Model Inference**: We instantiate the `SDG_CFC` model and perform a forward pass with a single batch from the data loader. We verify the shapes of the primary coupling predictions and auxiliary outputs (shielding, charges).
5.  **Full Training Loop**: We initialize the `ModelTrainer` and execute `trainer.run()`. This runs a complete cycle of training (1 epoch), validation, and submission generation using the reduced dataset.
6.  **Cleanup**: We verify the generation of the submission file and then clean up the temporary directory.
