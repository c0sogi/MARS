# Optimized Strategy: Stabilized Dual-Graph Network with Continuous Filter Convolutions (SDG-CFC)

This approach addresses the primary limitations of previous models: the inability of isotropic GCNs to model angles (Idea 1), the numerical instability of spherical harmonics (Idea 2), the information bottleneck in readout layers (Idea 5), and the optimization imbalance in multi-task learning (Idea 5/6).

### Model
1.  **Backbone: Dual-Graph Architecture with Continuous Filters**
    *   **Hierarchical Structure:** The model will operate on two interlinked graphs to explicitly capture the many-body geometric interactions required for predicting coupling constants (e.g., the Karplus equation for 3-bond couplings).
        *   **Atom Graph:** Nodes represent atoms; edges represent spatial proximity (radius graph).
        *   **Line Graph:** Nodes represent the *edges* of the Atom Graph; edges in this graph connect adjacent bonds, explicitly representing bond angles.
    *   **Continuous Filter Convolutions (CFConv):** Instead of using static edge weights or standard graph convolutions, we will employ **Continuous Filter Convolutions** in *both* graphs.
        *   **Spatial Filters:** In the Atom Graph, scalar Euclidean distances will be expanded using **Gaussian Radial Basis Functions (RBF)** and processed by an MLP to generate dynamic edge filters. This allows the model to learn non-linear distance dependencies **Cite solution_lesson_node_00007**.
        *   **Angular Filters:** In the Line Graph, we will compute the cosine of bond angles ($\cos \theta_{ijk}$). Crucially, we will expand these cosine values using **Gaussian RBFs** defined over the interval $[-1, 1]$ rather than using recursive Spherical Bessel Functions. This ensures numerical stability while retaining high-dimensional expressivity for angular features **Cite solution_lesson_node_00008**.
    *   **Message Passing Flow:** The network will alternate updates between the Line Graph (updating bond representations based on angular geometry) and the Atom Graph (updating atom representations based on bond features).

2.  **Readout: Edge-Centric Injection & Type-Specific Routing**
    *   **Edge Injection:** To eliminate the information bottleneck identified in previous iterations, the final prediction vector will be constructed by concatenating the learned node embeddings of the interacting pair ($h_i, h_j$) *and* the learned edge embedding ($e_{ij}$) from the final layer of the Line Graph. This explicitly injects the high-precision geometric state of the bond into the regressor **Cite solution_lesson_node_00011**.
    *   **Type-Specific Heads:** This concatenated vector will be routed to one of **8 distinct MLP heads** based on the coupling type (e.g., `1JHC`, `3JHH`). This allows the model to learn specialized functions for the distinct physical mechanisms of each coupling type (e.g., Fermi contact vs. Spin-dipolar).

3.  **Regularization: Physics-Calibrated Auxiliary Tasks**
    *   We will attach auxiliary heads to the Atom Graph nodes to predict **Magnetic Shielding Tensors** and **Mulliken Charges**. This forces the latent space to encode valid electronic environments, acting as a physics-informed regularizer.

### Data
1.  **Preprocessing**
    *   Construct **Atom Graphs** using a 5.0 Å radius cutoff to capture relevant long-range interactions.
    *   Construct **Line Graphs** by connecting edges in the Atom Graph that share a common atom (forming triplets).
    *   Precompute Gaussian RBF expansions for edge lengths (distances) and angular cosines.
2.  **Target Standardization (Primary)**
    *   We will strictly apply **Per-Group Target Standardization**. We will calculate the mean ($\mu_{type}$) and standard deviation ($\sigma_{type}$) for the `scalar_coupling_constant` independently for each of the 8 coupling types.
    *   The training targets will be transformed: $z = \frac{y - \mu_{type}}{\sigma_{type}}$. This ensures that the loss function is not dominated by high-magnitude types like `1JHC` **Cite solution_lesson_node_00003**.
3.  **Target Standardization (Auxiliary)**
    *   To prevent **Task Dominance**, we will also standardize the auxiliary targets (Shielding Tensors and Mulliken Charges) to have zero mean and unit variance. This ensures that the auxiliary loss magnitude is comparable to the primary loss, preventing the optimizer from ignoring the coupling prediction **Cite solution_lesson_node_00009**.

### Training
1.  **Loss Function**
    *   We will use a balanced Multi-Task Loss: $L_{total} = L_{coupling} + \lambda (L_{shielding} + L_{charge})$.
    *   Since all targets (primary and auxiliary) are standardized to unit variance, we can safely set $\lambda \approx 0.1$. This treats the physics prediction as a supporting regularizer rather than a dominant objective, avoiding the gradient hijacking observed previously **Cite solution_lesson_node_00009**.
2.  **Optimizer**
    *   We will use **AdamW** with a **Cosine Annealing Warm Restarts** scheduler. This schedule is effective for traversing the complex loss landscape of geometric deep learning models and refining the solution within the 24-hour limit.

### Evaluation
1.  **Inference**
    *   Process the test set structures to generate Atom and Line graphs.
    *   Pass the data through the SDG-CFC network.
    *   Extract the atom embeddings ($h_i, h_j$) and the specific edge embedding ($e_{ij}$) for the target pair.
    *   Route these features to the appropriate **Type-Specific Head** to predict the standardized value $z_{pred}$.
2.  **Inverse Transformation**
    *   Convert the predictions back to the original physical scale using the pre-computed training statistics: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ **Cite solution_lesson_node_00003**.
