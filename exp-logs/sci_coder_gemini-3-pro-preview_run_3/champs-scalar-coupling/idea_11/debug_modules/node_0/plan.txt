The following script demonstrates the end-to-end usage of the provided library for the scalar coupling prediction task.

### Implementation Strategy

1.  **Environment Setup**: We define a temporary working directory (`./working/demo_execution`) to store truncated datasets and model artifacts, ensuring we don't interfere with existing data.
2.  **Data Truncation**: To ensure the script executes quickly (within seconds/minutes rather than hours), we create a subset of the original dataset. We sample a small number of molecules (e.g., 50 train, 20 val, 20 test) and filter all related CSV files (`structures.csv`, `magnetic_shielding_tensors.csv`, etc.) to contain only data for these molecules.
3.  **Configuration Patching**: We dynamically modify the `Config` class attributes to point to these newly created truncated files. We also adjust hyperparameters like `MAX_EPOCHS`, `BATCH_SIZE`, and `NUM_WORKERS` to values suitable for a quick demonstration.
4.  **Data Processing**: We instantiate the `DataProcessor` to convert the raw CSV/XYZ data into the flattened Structure-of-Arrays (SoA) format used by the model.
5.  **Dataset Verification**: We load the `MolecularGraphDataset` and verify that the data shapes (nodes, edges, triplets, targets) are correct and consistent with the truncated input.
6.  **Model Verification**: We instantiate the `ScalarCouplingModel`, perform a forward pass with a single batch, and assert that the output shapes match the expected dimensions (coupling predictions, shielding tensors, charges).
7.  **Training Loop**: We initialize the `Trainer` and run the `fit()` method for a few epochs. We verify that the model trains without errors and saves a checkpoint.
8.  **Inference**: We run the `predict()` method to generate a submission file for the test set and verify its format.
