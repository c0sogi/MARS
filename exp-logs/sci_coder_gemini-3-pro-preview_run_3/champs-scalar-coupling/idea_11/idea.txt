# Optimized Strategy: Scalable Directional Message Passing with Shared Conditional Readout

### Model
1.  **Backbone: Directional Message Passing (DMPNN)**
    *   **Edge-Centric Updates:** Unlike the Current Best (SchNet), which updates atoms, this model will update **directed edge embeddings** ($j \to i$). This allows the explicit aggregation of messages from "preceding" edges ($k \to j$), enabling the model to distinguish bond angles ($\theta_{kji}$) critical for the Karplus equation **Cite solution_lesson_node_00020**.
    *   **Stable Geometric Basis:**
        *   **Distances:** Scalar bond lengths will be expanded using **Gaussian Radial Basis Functions (RBF)** and processed by an MLP to generate continuous filters **Cite solution_lesson_node_00007**.
        *   **Angles:** The cosine of bond angles ($\cos \theta_{kji}$) will be computed and expanded using **Gaussian RBFs** defined over $[-1, 1]$. This avoids the numerical instability of Spherical Bessel Functions found in previous attempts **Cite solution_lesson_node_00008**.

2.  **Readout: Shared Conditional Architecture with Edge Injection**
    *   **Shared Backbone:** Instead of the disjoint, type-specific heads used in Idea 10 (which fragmented the training signal), we will use a **Single Shared MLP** for the final prediction.
    *   **Conditional Embedding:** To handle the heterogeneity of coupling types, we will concatenate a learnable **Coupling Type Embedding** (e.g., a vector representing `1JHC`) to the input of the shared MLP. This allows the model to learn universal physical laws (like distance decay) from the entire dataset while modulating predictions for specific types **Cite solution_lesson_node_00022**.
    *   **Edge Injection:** We will explicitly concatenate the final **learned edge embedding** ($e_{ij}$) of the interacting pair with the node embeddings ($h_i, h_j$) and the type embedding. This injects the precise, high-frequency geometric information captured by the DMPNN directly into the regressor, bypassing the bottleneck of node-only readouts **Cite solution_lesson_node_00011**.

3.  **Regularization: Physics-Informed Auxiliary Heads**
    *   We will attach auxiliary heads to the node embeddings to predict **Magnetic Shielding Tensors** and **Mulliken Charges**. This forces the shared latent space to encode valid electronic environments, improving sample efficiency **Cite solution_lesson_node_00024**.

### Data
1.  **Preprocessing: Flattened Structure-of-Arrays (SoA)**
    *   To overcome the memory limitations that crippled Idea 10, we will abandon the object-oriented `InMemoryDataset`. We will pre-compute the graph topology (radius graph 5.0 Å) and store all components (nodes, edge indices, triplet indices, attributes) as **monolithic, flattened Numpy arrays**. This enables high-throughput training on the full 3.3M+ dataset **Cite solution_lesson_node_00016**.
    *   **Canonical Indexing:** We will ensure all categorical maps (coupling types) use integer indices immediately upon loading to prevent silent data corruption **Cite solution_lesson_node_00017**.

2.  **Target Standardization**
    *   **Primary:** We will strictly apply **Per-Group Target Standardization**. We will calculate $\mu_{type}$ and $\sigma_{type}$ for each of the 8 coupling types and transform training targets $z = \frac{y - \mu_{type}}{\sigma_{type}}$ **Cite solution_lesson_node_00003**.
    *   **Auxiliary:** We will also standardize the auxiliary targets (Shielding/Charges) to zero mean and unit variance. This ensures their loss magnitudes are comparable to the primary task, preventing task dominance **Cite solution_lesson_node_00009**.

### Training
1.  **Loss Function**
    *   **Primary:** We will use **L1 Loss (Mean Absolute Error)**. This aligns the optimization with the competition metric and prevents outliers in the heavy-tailed target distribution from distorting gradients (unlike MSE) **Cite solution_lesson_node_00013**.
    *   **Total:** $L_{total} = L_{coupling\_L1} + \lambda (L_{shielding\_L1} + L_{charge\_L1})$, with $\lambda \approx 0.1$ since all targets are standardized.
2.  **Optimizer**
    *   **AdamW** with a **Cosine Annealing Warm Restarts** scheduler to efficiently navigate the landscape and refine the solution within the 24-hour limit.

### Evaluation
1.  **Inference**
    *   Load test structures into the flattened SoA format.
    *   Pass through the DMPNN.
    *   Extract $h_i, h_j$, the specific edge embedding $e_{ij}$, and the coupling type embedding.
    *   Pass to the **Shared Conditional Head** to predict $z_{pred}$.
2.  **Inverse Transformation**
    *   Convert predictions back to the physical scale: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ **Cite solution_lesson_node_00003**.
