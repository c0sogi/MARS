Specifically, `NUM_RBF` determines the dimensionality of the edge filters in the `CFConvLayer`. Since the model performs element-wise multiplication between node features (of size `HIDDEN_DIM`) and these edge filters, `NUM_RBF` must equal `HIDDEN_DIM` (128) to ensure dimensions match and prevent incorrect broadcasting or shape mismatches (Cite debug_lesson_1). I will define `NUM_RBF = 128` in `library/config.py`.
