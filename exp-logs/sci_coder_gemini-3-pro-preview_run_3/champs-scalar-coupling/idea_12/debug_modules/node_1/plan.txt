The issue is a referential integrity violation between the metadata files and the `structures.csv` file. The metadata contains molecule IDs (like `dsgdb9nsd_020124`) that are missing from the structure data, causing a `KeyError` when the code attempts to retrieve the structure group without validation. This matches the scenario described in **Cite debug_lesson_2**, which advises verifying that keys exist in decoupled data sources before access.

To fix this, I will modify `library/data.py` to:
1.  Explicitly check if a molecule exists in the `structures` groups before processing it, skipping any missing molecules.
2.  Handle the edge case where a split results in zero valid molecules (due to filtering) by saving an empty map file. This ensures downstream components like `SOADataset` do not crash due to missing files or empty lists.
