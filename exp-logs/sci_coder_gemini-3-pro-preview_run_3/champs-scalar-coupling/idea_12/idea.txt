# Optimized Strategy: Scalable Directional Message Passing with Shared Conditional Readout

### Model
1.  **Backbone: Directional Message Passing (DMPNN) with Continuous Filters**
    *   **Edge-Centric Updates:** To capture the bond angles critical for scalar coupling (Karplus equation), the model will update **directed edge embeddings** ($j \to i$) rather than node embeddings. This allows the aggregation of messages from "preceding" edges ($k \to j$) to explicitly model the angle $\theta_{kji}$ **Cite solution_lesson_node_00020**.
    *   **Continuous Filter Convolutions:** We will replace static edge weights with **Continuous Filter Convolutions**.
        *   **Distances:** Bond lengths will be expanded using **Gaussian Radial Basis Functions (RBF)** and passed through an MLP to generate dynamic filters **Cite solution_lesson_node_00007**.
        *   **Angles:** The cosine of bond angles ($\cos \theta_{kji}$) will be expanded using **Gaussian RBFs** defined over $[-1, 1]$. This avoids the numerical instability of recursive Spherical Bessel Functions while retaining high-dimensional expressivity **Cite solution_lesson_node_00008**.

2.  **Readout: Shared Conditional Architecture with Edge Injection**
    *   **Shared Backbone:** We will replace the disjoint, type-specific heads of previous attempts with a **Single Shared MLP**. This allows the model to learn universal physical laws (like distance decay) from the entire dataset, improving data efficiency **Cite solution_lesson_node_00022**.
    *   **Conditional Embedding:** To handle target heterogeneity, we will concatenate a learnable **Coupling Type Embedding** (e.g., vector for `1JHC`) to the input of the shared MLP **Cite solution_lesson_node_00022**.
    *   **Edge Injection:** We will explicitly concatenate the final **learned edge embedding** ($e_{ij}$) of the interacting pair with the node embeddings ($h_i, h_j$) and the type embedding. This injects the precise, high-frequency geometric information captured by the DMPNN directly into the regressor, bypassing the bottleneck of node-only readouts **Cite solution_lesson_node_00011**.

3.  **Regularization: Physics-Informed Auxiliary Heads**
    *   We will attach auxiliary heads to the node embeddings to predict **Magnetic Shielding Tensors** and **Mulliken Charges**. This forces the shared latent space to encode valid electronic environments, improving sample efficiency **Cite solution_lesson_node_00024**.

### Data
1.  **Preprocessing: Flattened Structure-of-Arrays (SoA)**
    *   To enable training on the full 3.3M+ dataset (which was the primary success factor of the baseline **Cite solution_lesson_node_00014**), we will strictly use a **Flattened Contiguous Memory Layout**. We will pre-compute the graph topology (radius graph 5.0 Å) and triplet indices ($k, j, i$) and store them as **monolithic Numpy arrays** (e.g., one giant `edge_index` tensor, one `triplet_index` tensor). This eliminates the overhead of Python object lists (`InMemoryDataset`) that caused previous directional models to run out of memory **Cite solution_lesson_node_00016**.
    *   **Canonical Indexing:** We will ensure all categorical maps (coupling types) use integer indices immediately upon loading to prevent silent data corruption **Cite solution_lesson_node_00017**.

2.  **Target Standardization**
    *   **Primary:** We will apply **Per-Group Target Standardization**. We will calculate $\mu_{type}$ and $\sigma_{type}$ for each of the 8 coupling types and transform training targets $z = \frac{y - \mu_{type}}{\sigma_{type}}$ **Cite solution_lesson_node_00003**.
    *   **Auxiliary:** We will also standardize the auxiliary targets (Shielding/Charges) to zero mean and unit variance. This ensures their loss magnitudes are comparable to the primary task, preventing task dominance **Cite solution_lesson_node_00009**.

### Training
1.  **Loss Function**
    *   **Primary:** We will use **L1 Loss (Mean Absolute Error)**. This aligns the optimization with the competition metric and prevents outliers in the heavy-tailed target distribution from distorting gradients (unlike MSE) **Cite solution_lesson_node_00013**.
    *   **Total:** $L_{total} = L_{coupling\_L1} + \lambda (L_{shielding\_L1} + L_{charge\_L1})$, with $\lambda \approx 0.1$ since all targets are standardized.
2.  **Optimizer**
    *   **AdamW** with a **Cosine Annealing Warm Restarts** scheduler to efficiently navigate the landscape and refine the solution within the 24-hour limit.

### Evaluation
1.  **Inference**
    *   Load test structures into the flattened SoA format.
    *   Pass through the DMPNN.
    *   Extract $h_i, h_j$, the specific edge embedding $e_{ij}$, and the coupling type embedding.
    *   Pass to the **Shared Conditional Head** to predict $z_{pred}$.
2.  **Inverse Transformation**
    *   Convert predictions back to the physical scale: $y_{pred} = z_{pred} \cdot \sigma_{type} + \mu_{type}$ **Cite solution_lesson_node_00003**.
