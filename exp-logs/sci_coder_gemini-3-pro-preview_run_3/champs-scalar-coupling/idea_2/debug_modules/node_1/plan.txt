The issue is located in the `test_model_forward` function within `runfile.py`. The test manually initializes the atom type tensor `z` using raw atomic numbers (`[1, 6, 1]` for H, C, H), but the model's `EmbeddingBlock` expects mapped integer indices corresponding to `Config.ATOM_MAP` (where H=0, C=1). Passing `6` to an embedding layer of size 5 causes the `IndexError`. I will correct the tensor initialization to use the mapped values `[0, 1, 0]`.
