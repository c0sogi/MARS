The previous implementation failed because the test dataset processing logic silently skipped molecules when their structure files were missing or not found in the CSV cache. This resulted in an empty dataset and a `RuntimeError`, violating the inference contract that requires predictions for all input IDs.

To fix this, I will modify `library/data.py` to:
1.  Create a mapping from molecule names to their file paths using the metadata, ensuring robust file location.
2.  Implement an imputation strategy: if a structure file cannot be found or loaded, generate a dummy single-atom structure instead of skipping the molecule. This ensures the dataset maintains the correct cardinality and prevents the pipeline from crashing (Cite `debug_lesson_3`).
