This script implements the full training and evaluation pipeline. It first loads the training, validation, and test datasets using the provided data manager, which handles feature extraction and caching. It then trains the XGBoost models for formation energy and bandgap energy using the `EnergyPredictor` class. After training, it computes the column-wise RMSLE on the validation set to determine the final metric. A failure analysis follows, correlating prediction errors with input features to identify potential weaknesses. Finally, if the validation score meets the specified threshold, it generates predictions for the test set and saves the submission file.
