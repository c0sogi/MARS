This script performs a comprehensive Exploratory Data Analysis (EDA) on the materials science dataset. It loads the training metadata, analyzes the distribution and skew of the regression targets (`formation_energy_ev_natom` and `bandgap_energy_ev`), and examines the tabular features provided in the CSV. Additionally, it processes the associated geometry files (`.xyz`) using the `ase` library to extract physical meta-features such as cell volume and density, analyzing their distributions and correlations with the target variables. Finally, it assesses feature importance using a Random Forest regressor to identify key drivers for material properties.
