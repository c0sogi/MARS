Implementation Strategy:
The script orchestrates the full machine learning pipeline using the provided library modules.
1.  **Setup**: Imports necessary libraries (`pandas`, `numpy`, `sklearn`) and the custom `EnergyPredictor` class from `library.model_trainer`.
2.  **Training**: Initializes the `EnergyPredictor` and triggers model training. This step automatically handles data loading, feature engineering (physical descriptors + mock GNN embeddings), and XGBoost training for both target variables (`formation_energy_ev_natom` and `bandgap_energy_ev`).
3.  **Validation**:
    *   Manually retrieves the validation dataset (`X_val`, `y_val`) from the predictor.
    *   Generates predictions using the trained models.
    *   Calculates the Column-wise Root Mean Squared Logarithmic Error (RMSLE) for each target and computes the mean to get the `Final Validation Metric`.
    *   Prints the metric with full precision.
4.  **Failure Analysis**:
    *   Calculates the mean absolute error (in log space) for each validation sample.
    *   Computes the Pearson correlation between this error and all input features to identify which features correlate most with prediction errors.
    *   Prints the top 10 correlated features.
5.  **Submission**:
    *   Checks if the `Final Validation Metric` is strictly lower than the threshold `0.06278041684313306`.
    *   If the condition is met, calls `predictor.predict_and_submit()` to generate predictions on the test set and save `submission.csv`.
    *   Otherwise, skips submission generation to comply with the conditional requirement.
