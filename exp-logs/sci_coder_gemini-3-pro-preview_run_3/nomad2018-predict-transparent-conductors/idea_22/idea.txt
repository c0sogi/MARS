Based on the progression of experiments and the accumulated lessons, I propose a **Dual-Sublattice Distributional Fingerprinting** strategy.

This approach evolves the successful **Distributional Local Environment (DLE)** strategy (Idea 21, Lesson 54) by addressing a critical physics blind spot: the connectivity of the anion sublattice. While previous successful models focused heavily on cation (Metal) coordination environments, the electronic band structure of oxides is equally governed by the **Metal-Oxygen-Metal (M-O-M)** bridging angles, which determine orbital overlap and band width. To capture this without incurring the sparsity penalties of full Angular Distribution Functions (Lesson 34), this strategy applies the robust **Percentile Aggregation** method to both the Cation (Intra-polyhedral) and Anion (Inter-polyhedral) sublattices.

# Model
-   **Architecture**: **XGBoost Regressor** (Cite solution_lesson_node_00003). Tree ensembles remain the most effective architecture for this dataset when provided with dense, high-signal descriptors.
-   **Input Features**: A concatenated feature vector consisting of:
    1.  **Explicit Physical Descriptors**: Unit Cell Volume and Mass Density.
    2.  **Radial Fingerprints (RDF)**: Element-resolved pairwise distance histograms.
    3.  **Cation Distributional Fingerprints**: Element-specific percentiles of Coordination Number and Bond Angle Variance (from Idea 21).
    4.  **Anion Distributional Fingerprints (The Innovation)**: Percentiles of the Metal-Oxygen-Metal bridging angles, capturing the global network topology.
    5.  **Tabular Metadata**: Atomic composition and Spacegroup.

# Data
1.  **Geometric Feature Extraction (Raw Geometry)**:
    -   Load crystal structures from raw `.xyz` files using the `ase` library to ensure fidelity (Cite solution_lesson_node_00018).
    -   **Physical Descriptors**: Calculate **Unit Cell Volume** and **Mass Density** directly from the atomic objects (Cite solution_lesson_node_00018).
    -   **Radial Features (RDF)**: Compute element-resolved Radial Distribution Functions (e.g., Al-O, Ga-O, In-O) using a moderate cutoff (e.g., 6.0 Å). Normalize histograms by **atom count** (Cite solution_lesson_node_00033).
    -   **Cation Sublattice Features (Intra-polyhedral)**:
        -   For each Metal atom (Al, Ga, In), calculate the **Coordination Number (CN)** and **Bond Angle Variance** ($\sigma^2_{\theta}$) within a bonded cutoff (e.g., 3.0 Å).
        -   Group these values by element type and compute **Percentiles** (Min, 25%, Median, 75%, Max). This captures the distribution of local distortions for each species (Cite solution_lesson_node_00054).
    -   **Anion Sublattice Features (Inter-polyhedral)**:
        -   For every Oxygen atom, identify all Metal neighbors.
        -   Calculate all unique **Metal-Oxygen-Metal (M-O-M)** bond angles centered at that Oxygen.
        -   Collect *all* such angles in the crystal into a single distribution.
        -   Compute **Percentiles** (Min, 25%, Median, 75%, Max) of this distribution. This creates a dense, robust descriptor of the polyhedral connectivity (corner-sharing vs. edge-sharing) without the sparsity issues of element-pair-specific angular histograms (Cite solution_lesson_node_00016, solution_lesson_node_00034).

2.  **Preprocessing**:
    -   **Target Transformation**: Apply the natural logarithm transformation $z = \log(1 + y)$ to the target variables (`formation_energy_ev_natom` and `bandgap_energy_ev`) (Cite solution_lesson_node_00002).
    -   **Feature Cleaning**: Drop constant columns to prevent noise.

# Training
-   **Algorithm**: Train separate XGBoost regressors for formation energy and bandgap energy.
-   **Optimization Strategy**:
    -   **Shrinkage**: Use a **low learning rate** (e.g., $\eta \approx 0.01$) and a **high number of estimators** (e.g., 3,000) to maximize generalization (Cite solution_lesson_node_00004).
    -   **Stochastic Subsampling**: Set row (`subsample`) and column (`colsample_bytree`) subsampling to $\approx 0.6 - 0.7$. This forces the model to utilize the diverse structural views (Radial, Cation-Local, Anion-Global) rather than overfitting to specific features (Cite solution_lesson_node_00004).
    -   **Tree Constraints**: Limit `max_depth` (e.g., 5-6) to prevent memorization of fine-grained geometric artifacts (Cite solution_lesson_node_00046).
-   **Loss Function**: Mean Squared Error (MSE) on the log-transformed targets.

# Evaluation
-   **Inference**:
    1.  Process the test set `.xyz` files to generate Physical Descriptors, RDFs, and Dual-Sublattice Distributional features.
    2.  Generate predictions in the log-transformed space using the trained XGBoost models.
    3.  Apply the inverse transformation $\hat{y} = \exp(z) - 1$ to obtain the final energy predictions.
