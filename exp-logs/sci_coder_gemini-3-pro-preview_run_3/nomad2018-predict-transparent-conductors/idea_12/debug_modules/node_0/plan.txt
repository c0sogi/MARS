The following script demonstrates the end-to-end pipeline using the provided library modules. It performs the following steps:
1.  **Configuration Override**: Modifies the global configuration in memory to ensure the demonstration runs quickly (reducing XGBoost estimators and enabling debug mode).
2.  **Data Loading**: Loads a small subset of the data (50 samples) and extracts structural features (RDF, ADF, physical properties) using `library.data_loader`.
3.  **Preprocessing**: Cleans the data, log-transforms targets, and removes constant features using `library.preprocessing`.
4.  **Modeling**: Trains XGBoost regressors for both target variables using `library.model`.
5.  **Prediction**: Generates predictions on the test set and formats the submission.
6.  **Validation**: Includes assertions to verify data shapes, column existence, and prediction validity.
