This script demonstrates the utilization of the provided library components to build a machine learning pipeline. It performs the following steps:
1.  **Data Preparation**: Creates a small subset of the training and validation metadata to ensure the demonstration runs quickly.
2.  **Feature Engineering**: Uses `library.features.process_dataset` to generate physical descriptors (Global, RDF, Local Moments) for the subset.
3.  **Model Training**: Instantiates and trains the `DualTargetRegressor` (XGBoost wrapper) on the processed features.
4.  **Inference & Validation**: Generates predictions on the validation subset and verifies the output format and data integrity.
