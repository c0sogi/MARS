This script demonstrates the end-to-end usage of the provided library components. It performs the following steps:
1.  **Configuration**: Overrides default configuration settings (sample size, XGBoost parameters, working directory) to ensure the demonstration runs quickly and outputs to a separate folder.
2.  **Data Loading**: Uses `data_manager` to load a small subset of the training metadata and verifies the sampling logic.
3.  **Feature Extraction**: Directly instantiates `MatGLExtractor` to process a single atomic structure, verifying that GNN embeddings are generated correctly.
4.  **Pipeline Execution**: Runs `prepare_features` to generate feature matrices and target vectors for training, ensuring data shapes and types are correct.
5.  **Model Training**: Uses `train_xgboost_models` to train regressors on the prepared subset, verifying that models are returned and a validation score is computed.
6.  **Inference**: Generates predictions on a subset of the test data using the trained models.
7.  **Submission**: Formats and saves the predictions to a CSV file, verifying the file's existence.
