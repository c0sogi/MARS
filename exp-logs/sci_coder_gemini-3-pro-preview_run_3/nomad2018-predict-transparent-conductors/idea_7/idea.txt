Based on the analysis of previous attempts and the lessons learned, I propose a **Hybrid GNN-GBDT with Distributional Embedding Pooling** strategy. This approach addresses the "feature dilution" issue of element-specific pooling (Lesson 16) while capturing the structural variance that global mean pooling (Idea 4) misses. It also strictly enforces the use of raw geometry for physical descriptors (Lesson 18).

# Model
The architecture is a two-stage hybrid system:

1.  **Structural Backbone (Pre-trained MatGL)**:
    *   Utilize the **MatGL (M3GNet)** graph neural network, initialized with **pre-trained weights** (e.g., from Materials Project), to serve as a feature extractor (Cite solution_lesson_node_00010).
    *   **Structural Innovation (Distributional Pooling)**: Instead of simple global mean pooling (which loses local variance) or element-wise pooling (which creates sparse, diluted features for missing elements, Cite solution_lesson_node_00016), implement **Global Distributional Pooling**. For each crystal graph, compute the **Mean**, **Standard Deviation**, and **Range (Max - Min)** of the node-level embeddings across *all* atoms. This results in a dense, fixed-size feature vector that encodes both the average chemical environment and the *disorder/variance* of the structure, which is critical for alloy bandgap prediction.

2.  **Predictive Head (Gradient Boosting)**:
    *   Use an **XGBoost Regressor** as the final predictor (Cite solution_lesson_node_00003).
    *   The input features will be the concatenation of the Distributional GNN Embeddings, Explicit Physical Descriptors, and Tabular Metadata.

# Data
1.  **Explicit Physical Descriptors (Raw Geometry)**:
    *   **Volume & Density**: Calculate unit cell volume and mass density directly from the **raw `.xyz` geometry files** using the `ase` library. This avoids the precision loss associated with deriving these from CSV metadata (Cite solution_lesson_node_00018).
    *   **Geometric Statistics**: Calculate the **Average Nearest Neighbor Distance** (bond length) for each crystal from the raw geometry. This adds an explicit constraint related to lattice deformation and bond strength.

2.  **Tabular Features**:
    *   Include atomic composition (Al, Ga, In percentages) and spacegroup (one-hot encoded).

3.  **Target Transformation**:
    *   Apply the natural logarithm transformation $z = \log(1 + y)$ to both `formation_energy_ev_natom` and `bandgap_energy_ev`. This aligns the model's objective with the RMSLE metric (Cite solution_lesson_node_00002).

# Training
1.  **Algorithm**: Train separate XGBoost regressors for each target variable.
2.  **Optimization Strategy**:
    *   **Shrinkage**: Use a low learning rate (e.g., $\eta \approx 0.01$) and a high number of estimators (e.g., 2,500) to improve generalization (Cite solution_lesson_node_00004).
    *   **Stochastic Subsampling**: Set row (`subsample`) and column (`colsample_bytree`) subsampling to $\approx 0.6 - 0.7$. This prevents overfitting to the high-dimensional embedding features and forces the model to utilize the robust physical descriptors (Cite solution_lesson_node_00004).
3.  **Loss Function**: Minimize Squared Error on the log-transformed targets.

# Evaluation
1.  **Inference**:
    *   Process the test set `.xyz` files to generate the Distributional Embeddings and Physical Descriptors.
    *   Generate predictions in log-space using the trained XGBoost models.
2.  **Post-Processing**:
    *   Apply the inverse transformation $\hat{y} = \exp(z) - 1$ to obtain final energy predictions in eV.
