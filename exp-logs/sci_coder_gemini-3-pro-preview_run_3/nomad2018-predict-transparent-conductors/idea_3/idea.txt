Based on the empirical success of Gradient Boosting over Linear models (Cite solution_lesson_node_00003) and the critical importance of derived physical descriptors like density and volume (Cite solution_lesson_node_00002), I propose a **MACE-Embedding Augmented Gradient Boosting** strategy. This approach evolves the previous "Hybrid GNN-GBDT" idea by utilizing a specific, state-of-the-art equivariant backbone (MACE) and employing a more sophisticated aggregation strategy to capture the distribution of local atomic environments, rather than just a global pool.

# Model
The architecture consists of a two-stage pipeline:
1.  **Structural Backbone (MACE)**: Utilize the **MACE (Multi-Atomic Cluster Expansion)** model (available via `mace-torch`) as a fixed feature extractor. MACE is an equivariant message-passing neural network that captures high-order body interactions and local symmetries far better than simple geometric scalars. We will extract the **node-level (atomic) embeddings** from the pre-trained model for every atom in the unit cell.
2.  **Aggregation Layer**: Instead of a simple sum or mean readout (which can lose information about the variance of local environments), compute **statistical moments** (mean, standard deviation, min, max) of the node embeddings across all atoms in a crystal. This creates a fixed-size vector representing the distribution of local chemical/structural environments.
3.  **Predictive Head (XGBoost)**: An **XGBoost Regressor** acts as the final predictor. It takes the concatenated vector of:
    *   Aggregated MACE embeddings.
    *   Explicit physical descriptors (Volume, Density) (Cite solution_lesson_node_00002).
    *   Original tabular features (Lattice vectors, Composition).

# Data
1.  **Geometry Preprocessing**:
    *   Load crystal structures from `geometry.xyz` files.
    *   Calculate **Volume** and **Density** explicitly, as these are proven high-value features (Cite solution_lesson_node_00002).
    *   Pass the atomic structures through the pre-trained MACE model to obtain per-atom latent vectors.
    *   Compute the statistical moments (mean, std, min, max) of these vectors to form the structural feature set.
2.  **Target Transformation**: Apply the logarithmic transformation $z = \log(1 + y)$ to the formation and bandgap energy targets. This aligns the regression objective with the RMSLE metric (Cite solution_lesson_node_00002).
3.  **Feature Assembly**: Construct the final training matrix $X$ by joining the structural features, physical descriptors, and tabular metadata.

# Training
1.  **Algorithm**: Train independent XGBoost regressors for each target variable.
2.  **Optimization Strategy**: Implement the **Shrinkage and Subsampling** strategy (Cite solution_lesson_node_00004) to prevent overfitting on the high-dimensional embedding features:
    *   Set a low learning rate (e.g., $\eta \le 0.01$) and a correspondingly high number of estimators (e.g., $>2000$).
    *   Enable stochastic subsampling for both rows (`subsample`) and columns (`colsample_bytree`) to force the model to utilize the diverse feature set robustly.
3.  **Loss Function**: Minimize the Squared Error on the log-transformed targets.

# Evaluation
1.  **Inference**:
    *   Process the test set geometries through the MACE backbone and aggregation layer.
    *   Generate predictions in the log-transformed space using the trained XGBoost models.
2.  **Post-processing**: Apply the inverse transformation $\hat{y} = \exp(z) - 1$ to return the predictions to the original energy scale (eV).
