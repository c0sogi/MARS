This script orchestrates the end-to-end machine learning pipeline for predicting material properties. It begins by setting random seeds for reproducibility. It then loads the training and validation datasets, utilizing the `feature_pipeline` to extract features including MACE structural embeddings and physical descriptors. The target variables are log-transformed to align with the RMSLE metric. XGBoost regressors are trained on the processed data. The model is evaluated on the validation set, and the final RMSLE metric is reported. A failure analysis is performed to identify features correlated with prediction errors. Finally, if the validation score meets the specified threshold, the script generates predictions for the test set and saves the submission file.
