This script demonstrates the complete pipeline for predicting formation energy and bandgap energy using the provided library components. It performs the following steps:
1.  **Data Loading & Sampling**: Loads the metadata, samples a small subset for demonstration purposes to ensure quick execution.
2.  **Feature Engineering**: Generates geometric features (RDF, angles, etc.) using the `generate_features` function from the library. It verifies that features are correctly extracted from the atomic structure files.
3.  **Data Preparation**: Merges tabular and geometric features, applies log-transformation to targets, and splits the data into training and validation sets.
4.  **Model Training**: Instantiates the `DualTargetRegressor` (XGBoost-based) with speed-optimized hyperparameters and trains it on the subset.
5.  **Evaluation**: Predicts on the validation set, applies the inverse transformation to get values in eV, and calculates RMSE.
6.  **Submission Generation**: Processes a subset of the test data and generates a submission file in the correct format.
