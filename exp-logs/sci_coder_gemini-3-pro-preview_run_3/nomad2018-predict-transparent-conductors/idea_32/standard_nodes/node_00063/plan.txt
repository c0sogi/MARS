Implementation Strategy:
1.  **Environment Setup**: Set random seeds for reproducibility and ensure the output directory (`./submission`) exists.
2.  **Data Loading**: Use the provided `DatasetLoader` to load the train, validation, and test datasets. This handles feature generation (using the `feature_engineering` module) and caching automatically.
3.  **Data Preparation**: Separate the features (X) from the targets (y) and metadata (id, file_path). Ensure categorical features (if any remain) are handled or dropped if not supported by the model configuration (XGBoost handles numerics well).
4.  **Model Configuration**: Check for GPU availability. If available, update the XGBoost parameters to use the GPU (`device='cuda'`) to satisfy the inference optimization requirement.
5.  **Training**: Use the `train_and_evaluate` function from the `library.training` module. This handles the training of two separate XGBoost regressors (one for each target), applies the log-transformation to targets, and evaluates performance on the validation set.
6.  **Validation & Failure Analysis**:
    *   Print the `Final Validation Metric` (average RMSLE).
    *   Calculate the absolute prediction errors on the validation set.
    *   Compute and print the Pearson correlation between these errors and the input features to identify sources of error.
7.  **Submission**: Check if the validation metric meets the threshold (< 0.05095). If successful, generate predictions for the test set, apply the inverse transformation (expm1), format the dataframe according to the sample submission, and save it to `submission.csv`.
