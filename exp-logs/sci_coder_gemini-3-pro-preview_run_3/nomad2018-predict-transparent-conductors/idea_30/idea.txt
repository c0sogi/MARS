Based on the comprehensive analysis of previous attempts and the accumulated lessons, I propose a **Bond-Valence Vector & Global Instability Fingerprinting** strategy.

This approach evolves the successful **Bond Valence Sum (BVS)** strategy (Idea 28, Lesson 60) by extending the concept of "chemical valency" from a scalar quantity to a vector field and a global stability metric. While scalar BVS successfully captures radial chemical saturation, it is blind to the *directional* symmetry of the bonds. By calculating the **Bond Valence Vector Sum (BVVS)**, we explicitly quantify the symmetry breaking and local dipoles (weighted by bond strength) that drive bandgap opening. Additionally, we introduce the **Global Instability Index (GII)**, a standard crystallographic metric derived from BVS errors, to serve as a direct proxy for formation energy.

# Model
-   **Architecture**: **XGBoost Regressor** (Cite {solution_lesson_node_00003}). Tree ensembles remain the most robust architecture for this dataset.
-   **Input Features**: A concatenated feature vector representing the material's stability and symmetry:
    1.  **Global Physical Descriptors**: Unit Cell Volume, Mass Density, and **Global Instability Index (GII)** (The Innovation).
    2.  **Radial Fingerprints (RDF)**: Element-resolved pairwise distance histograms (Cite {solution_lesson_node_00029}).
    3.  **Chemo-Symmetry Fingerprints**: Chemically resolved percentiles of **Bond Valence Sums (BVS)** and **Bond Valence Vector Sums (BVVS)** (The Innovation).
    4.  **Topological Fingerprints**: Percentiles of Metal-Oxygen-Metal bridging angles (Cite {solution_lesson_node_00059}).
    5.  **Tabular Metadata**: Atomic composition and Spacegroup.

# Data
1.  **Geometric Feature Extraction (Raw Geometry)**:
    -   Load crystal structures from raw `.xyz` files using the `ase` library (Cite {solution_lesson_node_00018}).
    -   **Global Physical**: Calculate Unit Cell Volume and Mass Density.
    -   **Radial (RDF)**: Compute element-resolved RDFs using a moderate cutoff (e.g., 6.0 Å) and normalize by **atom count** (Cite {solution_lesson_node_00033}).
    -   **Bond Valence Analysis**:
        -   **Bond Valences**: For every Metal-Oxygen bond, calculate the valence $s_{ij} = \exp((R_{0} - d_{ij}) / 0.37)$, using standard $R_0$ parameters for Al, Ga, and In.
        -   **Scalar BVS**: For each atom $i$, compute $V_i = \sum_j s_{ij}$. This measures bond saturation.
        -   **Vector BVS (BVVS)**: For each atom $i$, compute the magnitude of the resultant valence vector: $\xi_i = \left| \sum_j s_{ij} \frac{\mathbf{r}_{ij}}{|\mathbf{r}_{ij}|} \right|$. Unlike simple geometric anisotropy, this weights the directional distortion by the chemical strength of the bond, providing a high-fidelity signal for electronic symmetry breaking.
        -   **Global Instability Index (GII)**: Calculate the root-mean-square deviation of the scalar BVS from the ideal formal valence ($V_{ideal}$) across the unit cell: $GII = \sqrt{\frac{1}{N} \sum (V_i - V_{ideal})^2}$. This single scalar is a strong physical predictor of thermodynamic stability (Formation Energy).
    -   **Aggregation**: Group the atom-level metrics (Scalar BVS, Vector BVVS) by element type and compute **Percentiles** (Min, 25%, 50%, 75%, Max) to capture the distribution of local states (Cite {solution_lesson_node_00054}).
    -   **Topology**: Calculate Metal-Oxygen-Metal bridging angle percentiles.

2.  **Preprocessing**:
    -   **Target Transformation**: Apply the natural logarithm transformation $z = \log(1 + y)$ to the target variables (Cite {solution_lesson_node_00002}).
    -   **Feature Cleaning**: Drop constant columns.

# Training
-   **Algorithm**: Train separate XGBoost regressors for formation energy and bandgap energy.
-   **Optimization Strategy**:
    -   **Shrinkage**: Use a **low learning rate** (e.g., $\eta \approx 0.01$) and a **high number of estimators** (e.g., 3,000) (Cite {solution_lesson_node_00004}).
    -   **Stochastic Subsampling**: Set row (`subsample`) and column (`colsample_bytree`) subsampling to $\approx 0.6 - 0.7$. This forces the model to utilize the diverse physics-informed features (GII, BVVS) alongside raw geometry (Cite {solution_lesson_node_00004}).
-   **Loss Function**: Mean Squared Error (MSE) on the log-transformed targets.

# Evaluation
-   **Inference**:
    1.  Process the test set `.xyz` files to generate Physical, RDF, BVS/BVVS, and GII features.
    2.  Generate predictions in the log-transformed space using the trained XGBoost models.
    3.  Apply the inverse transformation $\hat{y} = \exp(z) - 1$ to obtain the final energy predictions.
