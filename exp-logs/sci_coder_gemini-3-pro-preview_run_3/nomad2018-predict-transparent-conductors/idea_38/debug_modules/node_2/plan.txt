The issue is that the `XGBRegressor.fit()` method in newer versions of XGBoost (1.6+) no longer accepts the `early_stopping_rounds` argument directly; instead, this parameter must be set in the model constructor or via `set_params` before training (Cite debug_lesson_1). To fix this, I will modify `library/regressor.py` to set `early_stopping_rounds` using `self.models[target].set_params(...)` immediately before calling `.fit()`, and remove the argument from the `.fit()` call itself.
