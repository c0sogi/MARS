The implementation strategy involves orchestrating the data preparation, model training, validation, failure analysis, and submission generation using the provided library modules.

1.  **Data Loading & Preparation**: Use `library.regression_model.prepare_data` to load precomputed features for training, validation, and test sets. This leverages the cached parquet files for speed.
2.  **Feature Alignment**: Ensure that the validation and test feature matrices have the exact same columns as the training matrix, filling missing columns with zeros and dropping extra ones.
3.  **Model Training**: Instantiate the `LogTransformedXGBoost` class for both `formation_energy_ev_natom` and `bandgap_energy_ev`. Train them on the training set and evaluate on the validation set.
4.  **Validation Metric**: Calculate the column-wise Root Mean Squared Logarithmic Error (RMSLE) for both targets on the validation set and compute the average as the final metric.
5.  **Failure Analysis**: Calculate the absolute error between predicted and actual log-transformed values for the validation set. Compute the correlation of these errors with the input features to identify sources of inaccuracy.
6.  **Submission**: If the final validation metric is below the specified threshold (0.05095), generate predictions for the test set, format them into a DataFrame, and save to `submission.csv`.
