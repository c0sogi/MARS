This script demonstrates the end-to-end execution of the recommendation pipeline using the provided library. To ensure the execution completes quickly (within minutes) and fits within the resource constraints, the script performs the following steps:

1.  **Configuration Override**: It dynamically modifies the `library.config` paths and hyperparameters to point to a temporary "demo" workspace and use reduced model complexity (e.g., fewer trees, smaller K for KNN).
2.  **Data Subsampling**: It creates a consistent mini-dataset by filtering the original metadata. It selects a small subset of active customers and popular articles, ensuring that the heavy computations (like image embedding generation and graph building) run on only ~1,000 items instead of ~100,000.
3.  **Pipeline Execution**:
    *   **Data Management**: Generates ID mappings for the subset.
    *   **Visual Module**: Extracts ResNet embeddings for the subset of articles and builds a visual similarity graph.
    *   **Retrieval**: Constructs a sequential transition graph from the transaction history and retrieves candidate items for users using the dual-view strategy (Sequential + Visual).
    *   **Feature Engineering**: Generates ranking features (popularity, visual consistency, etc.) for the retrieved candidates.
    *   **Ranking**: Trains a LightGBM ranker on a history-vs-target split and predicts the final items for the test set.
4.  **Validation**: It includes assertions to verify that data shapes are correct, files are generated, and the model produces valid scores.
