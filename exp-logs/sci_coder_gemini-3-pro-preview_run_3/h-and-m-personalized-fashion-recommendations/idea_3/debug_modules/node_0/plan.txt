Implementation Strategy:
1.  **Setup & Configuration**: Import necessary libraries and the provided modules. Set random seeds for reproducibility. Adjust global configuration parameters (e.g., LightGBM estimators) to ensure the script runs quickly for demonstration purposes.
2.  **Data Mocking/Subsetting**: Since the full dataset is large (~25M transactions), I will use `unittest.mock` to patch the `data_loader` functions. This allows the complex `RankerDatasetBuilder` class to operate on a small subset of data (e.g., 100k transactions, 1k articles) without modifying the library code, ensuring the pipeline runs in minutes rather than hours.
3.  **Stage 1 - Sparse Retrieval**: Instantiate `SparseGraphRetriever`, fit it on a subset of transaction data, and verify it can generate candidates.
4.  **Stage 2 - Dataset Building**: Use `RankerDatasetBuilder` to generate training and validation datasets. This involves generating candidates, extracting visual features (using `ImageEmbedder` on the GPU), and merging metadata.
5.  **Stage 3 - Ranking Model**: Initialize `LGBMRankerWrapper`, train it on the generated datasets using the LightGBM LambdaRank objective, and verify feature importance extraction.
6.  **Stage 4 - Inference & Submission**: Generate candidates for test users, predict scores using the trained ranker, and format the final submission file.
7.  **Validation**: Throughout the script, use assertions to verify data shapes, file existence, and logical correctness of the outputs.
