To improve the model's performance, I will implement a **Hybrid Strategy** that combines the Time-Aware Markov Chain with a **Repeat Purchase Heuristic**, as suggested in the lesson (Cite solution_lesson_node_00002). The previous solution relied solely on the transition graph from the *last* purchased item, which suffers from sparsity. By incorporating the user's most frequent and recent purchases from the training window as high-priority candidates, we can capture the strong tendency of users to repurchase preferred items or styles.

**Implementation Strategy:**
1.  **Modify `library/data_loader.py`**: Add a `get_user_top_items` function. This function will aggregate the time-weighted transaction history (already filtered to the last 10 weeks) to identify the top-weighted items per user. This serves as our "Repurchase" candidate set.
2.  **Modify `library/model.py`**: Update `generate_predictions` to accept this additional history. The prediction logic will be updated to prioritize candidates in this order:
    *   **Markov Candidates**: Contextual next-items based on the immediate last purchase.
    *   **Repurchase Candidates**: High-weight items from the user's recent history.
    *   **Global Popularity**: Fallback for filling the remaining slots.
3.  **Update Pipelines**: Adjust `library/inference.py` and `runfile.py` to generate these history features and pass them to the model during both validation and final inference.

This ablation targets the "sparsity" weakness of the Order-1 Markov Chain by filling gaps with personalized history rather than generic popularity.

def get_user_top_items(transactions_df, load_cached_data=True):
    """
    Aggregates transactions by user and item, summing the time weights,
    and retrieves the top K items per user.

    Args:
        transactions_df (pd.DataFrame): Weighted transactions.
        load_cached_data (bool): Whether to use cache.

    Returns:
        pd.DataFrame: DataFrame with 'customer_id' and 'history_items' (list of article_ids).
    """
    cache_path = config.WORKING_DIR / "user_top_items.parquet"

    if load_cached_data and cache_path.exists():
        print(f"Loading user top items from cache: {cache_path}")
        return pd.read_parquet(cache_path)

    print("Extracting user top items from scratch...")

    # Group by customer and article, sum the time-decay weights
    # This ranks items by a combination of frequency and recency
    grouped = (
        transactions_df.groupby(["customer_id", "article_id"])["weight"]
        .sum()
        .reset_index()
    )

    # Sort by customer and weight (descending)
    grouped = grouped.sort_values(["customer_id", "weight"], ascending=[True, False])

    # Take top K items per customer
    top_k = grouped.groupby("customer_id").head(config.TOP_K)

    # Aggregate into lists
    result = (
        top_k.groupby("customer_id")["article_id"]
        .apply(list)
        .reset_index()
        .rename(columns={"article_id": "history_items"})
    )

    print(f"Saving user top items to cache: {cache_path}")
    result.to_parquet(cache_path, index=False)

    return result
