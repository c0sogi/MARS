Implementation strategy:
1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and set random seeds for reproducibility.
2.  **Data Generation**: Use `RankerFeatureFactory` to load (or generate if not cached) the training and validation datasets. The factory handles the complex dual-graph retrieval and feature engineering.
3.  **Optimization**: To ensure the "fast baseline" requirement is met, downsample the training dataset (keeping all positive samples and a subset of negative samples) to reduce LightGBM training time.
4.  **Model Training**: Instantiate `LGBMRanker` and train it on the processed datasets.
5.  **Validation & Metric Calculation**:
    *   Generate predictions for the validation set using the trained model.
    *   Load the ground truth validation transactions.
    *   Implement the exact MAP@12 calculation function as per the task description.
    *   Print the final metric.
6.  **Failure Analysis**:
    *   Compute the model's prediction error (absolute difference between binary label and sigmoid-transformed score).
    *   Calculate and print the correlation between this error and the input features to identify weak points.
7.  **Inference**:
    *   Check if the validation MAP@12 exceeds the threshold (0.026059042).
    *   If successful, generate the inference dataset for test users and produce the final submission file.
