# Model: Siamese DeBERTa-v3-Base with Multi-Layer Response-Isolated Pooling

I propose a **Siamese Contextual Transformer** architecture that integrates deep semantic extraction with explicit heuristic signals.

*   **Backbone Architecture:** I will utilize **`microsoft/deberta-v3-base`**.
    *   **Rationale:** Previous experiments demonstrated that pre-trained Transformers significantly outperform scratch-trained LSTMs (Cite solution_lesson_node_00022). While the "Large" model theoretically offers better reasoning, it failed to converge within the time limit due to resource bottlenecks (Cite solution_lesson_node_00027). The "Base" variant represents the optimal trade-off, allowing for sufficient batch sizes and training epochs on the A100 GPU to reach a stable minimum.
*   **Siamese Input Structure:** The model will process two parallel branches sharing the same encoder weights:
    1.  **Branch A:** `[CLS] Prompt [SEP] Response A [SEP]`
    2.  **Branch B:** `[CLS] Prompt [SEP] Response B [SEP]`
    *   **Rationale:** This Siamese approach is strictly superior to Cross-Encoders (concatenating all three) for this task because it avoids the aggressive text truncation required to fit `Prompt + Resp A + Resp B` into a single context window, ensuring the model has access to the full context (Cite solution_lesson_node_00023).
*   **Structural Innovation: Multi-Layer Response-Isolated Pooling:**
    *   Instead of pooling only the final hidden layer, I will implement a **Hierarchical Pooling** mechanism.
    *   **Extraction:** Extract the hidden states from the **last 4 layers** of the Transformer.
    *   **Isolation:** For each layer, apply a **binary mask** to zero out the `Prompt` tokens. This ensures that the final embeddings represent *only* the `Response` content (which is already contextualized by the Prompt via self-attention), removing the shared "noise" of the Prompt (Cite solution_lesson_node_00025).
    *   **Aggregation:** Apply **Learned Attention Pooling** (Cite solution_lesson_node_00011) to each of the 4 masked layers *independently*, then **concatenate** the resulting vectors. This captures a rich spectrum of features, from syntactic structure (lower layers) to semantic reasoning (higher layers).
*   **Hybrid Classification Head:** The multi-layer pooled vectors ($u_{resp}, v_{resp}$) will be combined via interaction terms ($u, v, |u-v|, u \cdot v$) and concatenated with **Explicit Scalar Features** (log-transformed lengths of Prompt, Response A, and Response B) before the final MLP. This preserves the high-signal "verbosity bias" features identified in earlier iterations (Cite solution_lesson_node_00004).

# Data: Full Dataset with Symmetric Augmentation

*   **Dataset Utilization:** The model will be trained on the **Full Training Set** (approx. 41k samples). Data volume is the primary driver of performance, and downsampling for model complexity is detrimental (Cite solution_lesson_node_00015).
*   **Symmetric Augmentation:** I will double the effective training size by swapping the input order. For every pair $(A, B)$ with target $T$, I will generate a sample $(B, A)$ with target $1-T$. This enforces the symmetric consistency required by the Siamese architecture.
*   **Preprocessing:**
    *   **Tokenization:** Use the `deberta-v3-base` tokenizer.
    *   **Feature Consistency:** Calculate the scalar length features based on the **tokenized sequences** to ensure mathematical consistency with the encoder inputs (Cite solution_lesson_node_00005).
    *   **Sequence Management:** Set a maximum sequence length of **512 tokens per branch**. Use a truncation strategy that **preserves the full Prompt** and truncates the Response only if necessary, preventing the loss of critical context (Cite solution_lesson_node_00013).

# Training: Efficiency-Optimized Fine-Tuning

*   **Optimization:** Use **AdamW** with a learning rate suitable for Base models (e.g., 1e-5) and a linear warmup schedule.
*   **Efficiency:** Enable **Gradient Checkpointing** and **Mixed Precision (FP16)**. This allows the "Base" model to fit into GPU memory with a sufficiently large batch size to ensure stable gradients, addressing the stability issues observed with larger models (Cite solution_lesson_node_00027).
*   **Loss Function:** Standard Cross-Entropy Loss (Log Loss) on the soft probability targets.

# Evaluation

*   **Inference:** Preprocess the test set using the same Siamese formatting and scalar feature extraction.
*   **Test-Time Augmentation (TTA):** To maximize robustness, predict on both $(A, B)$ and $(B, A)$ for each test id. Average the consistent probabilities (i.e., $P_{final}(A) = 0.5 \times (P_{AB}(A) + P_{BA}(B))$) to produce the final submission.
