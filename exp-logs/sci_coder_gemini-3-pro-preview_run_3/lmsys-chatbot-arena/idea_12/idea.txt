This strategy evolves the successful "Base" architecture (Lesson 29) by introducing a **Decoupled Pooling** mechanism to explicitly model the relationship between the prompt's intent and the response's features, addressing the information loss inherent in pure response-isolation.

# Model: Siamese DeBERTa-v3-Base with Decoupled Context-Response Pooling

I propose a **Siamese Contextual Transformer** that separates the extraction of "Context" (Prompt) and "Content" (Response) to enable context-aware preference judging.

*   **Backbone Architecture:** I will utilize **`microsoft/deberta-v3-base`**.
    *   **Rationale:** Previous experiments confirmed that pre-trained Transformers outperform LSTMs (Cite solution_lesson_node_00022). While "Large" models offer high theoretical capacity, they failed to converge reliably within the compute/time limits (Cite solution_lesson_node_00027). The "Base" variant represents the optimal trade-off, allowing for sufficient training epochs and stable batch sizes on the A100 GPU (Cite solution_lesson_node_00029).
*   **Siamese Input Structure:** The model will process two parallel branches sharing weights:
    1.  **Branch A:** `[CLS] Prompt [SEP] Response A [SEP]`
    2.  **Branch B:** `[CLS] Prompt [SEP] Response B [SEP]`
    *   **Rationale:** This Siamese approach is superior to Cross-Encoders for this task because it avoids the aggressive truncation required to fit `Prompt + Resp A + Resp B` into a single context window, ensuring the model accesses the full content (Cite solution_lesson_node_00023).
*   **Structural Innovation: Decoupled Multi-Layer Pooling:**
    *   I will evolve the "Response-Isolated Pooling" (Cite solution_lesson_node_00025) into a **Decoupled Dual-Stream** mechanism.
    *   **Layer Extraction:** Extract hidden states from the **last 4 layers** of the Transformer.
    *   **Stream 1 (Content):** For each branch, apply a binary mask to zero out `Prompt` tokens. Apply **Learned Attention Pooling** (Cite solution_lesson_node_00011) to the `Response` tokens. This yields pure response vectors $R_A$ and $R_B$.
    *   **Stream 2 (Context):** Simultaneously, apply a binary mask to zero out `Response` tokens. Apply Learned Attention Pooling to the `Prompt` tokens. Since the prompt is identical in both branches, average the resulting vectors to obtain a robust context vector $P$.
    *   **Rationale:** Previous best methods masked the prompt to reduce noise in the difference vector $|R_A - R_B|$. However, the *criteria* for a good response depend heavily on the prompt (e.g., "creative writing" favors length/complexity, while "debugging" favors brevity). By explicitly re-introducing $P$ into the classifier, we allow the model to condition its preference logic on the prompt type without diluting the comparative signal.
*   **Hybrid Classification Head:** The final feature vector will be a concatenation of:
    *   **Interaction:** $R_A, R_B, |R_A - R_B|, R_A \cdot R_B$ (Standard Siamese features).
    *   **Context Modulation:** $P$ (The explicit prompt vector).
    *   **Explicit Scalars:** Log-transformed lengths of Prompt, Response A, and Response B (Cite solution_lesson_node_00004).

# Data: Full Dataset with Symmetric Augmentation

*   **Dataset:** Train on the **Full Training Set** (approx. 41k samples). Do not downsample; data volume is the primary driver of performance (Cite solution_lesson_node_00015).
*   **Symmetric Augmentation:** Double the dataset by creating a swapped copy $(B, A)$ with target $1-T$ for every pair $(A, B)$. This enforces permutation invariance and doubles the effective training signal (Cite solution_lesson_node_00029).
*   **Preprocessing:**
    *   **Tokenization:** Use the `deberta-v3-base` tokenizer.
    *   **Feature Consistency:** Compute scalar length features from the **tokenized sequences** to ensure mathematical consistency with the encoder (Cite solution_lesson_node_00005).
    *   **Sequence Length:** Set max length to **512 tokens per branch**. Truncate the Response if necessary, but **always preserve the full Prompt** to ensure the context vector $P$ is accurate (Cite solution_lesson_node_00013).

# Training: Efficiency-Optimized Fine-Tuning

*   **Optimization:** Use **AdamW** with a learning rate suitable for Base models (e.g., 1e-5) and a linear warmup schedule.
*   **Efficiency:** Enable **Gradient Checkpointing** and **Mixed Precision (FP16)**. This allows the model to fit into GPU memory with a sufficiently large batch size to ensure stable gradients (Cite solution_lesson_node_00027).
*   **Loss Function:** Standard Cross-Entropy Loss (Log Loss) on the soft probability targets.

# Evaluation: Robust Inference

*   **Test-Time Augmentation (TTA):** For every test instance, predict on both $(A, B)$ and $(B, A)$. Average the resulting probabilities (flipping the winner for the swapped pair) to produce the final prediction. This neutralizes any residual positional bias (Cite solution_lesson_node_00029).
*   **Pipeline:** Preprocess test data into Siamese pairs, extract scalar features, pass through the Decoupled Pooling model, and apply Softmax.
