The following is the implementation strategy for the `runfile.py` script:

1.  **Setup and Imports**: Import necessary system libraries and the provided modules from the `library` package (`config`, `utils`, `data`, `model`, `engine`). Set the random seed for reproducibility.
2.  **Training**: Execute the training pipeline using `library.engine.run_training`. This function manages the data loading (utilizing cached `.npz` files), model initialization, training loop, validation monitoring, and early stopping. It saves the best model checkpoint.
3.  **Validation**:
    *   Load the validation dataset using `library.data.prepare_data` with `load_cached_data=True`.
    *   Load the best saved model state.
    *   Perform inference on the validation set using the `predict` function (which ensures `torch.no_grad()` and GPU usage).
    *   Calculate the **Log Loss** metric using `sklearn.metrics.log_loss` comparing the predicted probabilities against the ground truth soft targets.
    *   Print the metric in the required format: `Final Validation Metric: <value>`.
4.  **Failure Analysis**:
    *   Compute the per-sample cross-entropy loss (error magnitude) for the validation set.
    *   Extract the scalar features (log-transformed lengths of prompt and responses) from the validation dataset.
    *   Calculate and print the Pearson correlation between the error magnitude and these input features to identify systematic weaknesses.
5.  **Submission**:
    *   Compare the calculated validation metric against the threshold `1.0392143626595562`.
    *   If the metric is lower than the threshold, call `library.engine.generate_submission` to create the `submission.csv` file for the test set.
