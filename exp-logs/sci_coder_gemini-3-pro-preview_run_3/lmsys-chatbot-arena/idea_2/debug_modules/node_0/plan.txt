This script demonstrates the end-to-end usage of the provided library modules for the Chatbot Arena task. It covers data processing, model instantiation, training, and inference.

1.  **Configuration**: It overrides the default `Config` settings to enable `DEBUG` mode, reduce the number of epochs to 1, and set a small batch size. This ensures the demonstration runs quickly.
2.  **Tokenizer Verification**: It explicitly tests the `RegexTokenizer` by fitting it on dummy data and asserting that encoding works as expected.
3.  **Data Pipeline**: It calls `prepare_data` to generate the necessary `.npz` cache files from the metadata and creates PyTorch DataLoaders. It verifies the structure and shapes of a single batch from the training loader.
4.  **Model Architecture**: It instantiates the `ESIMHybridModel`, performs a forward pass with the sample batch, and asserts that the output logits have the correct dimensions `(Batch_Size, Num_Classes)`.
5.  **Training Loop**: It executes `run_training` for one epoch. This validates the loss calculation, backpropagation, and checkpoint saving mechanisms.
6.  **Inference**: It runs `generate_submission` using the trained model checkpoint to produce predictions on the test set, verifying the final output file's format and content.
