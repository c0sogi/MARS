# Model: Siamese DeBERTa-v3-Large with Disentangled Hierarchical Pooling

I propose a **Siamese Contextual Transformer** architecture that explicitly disentangles "Content" (Response) from "Context" (Prompt) to combine deep reasoning capabilities with noise-free feature extraction.

*   **Backbone Architecture:** I will utilize **`microsoft/deberta-v3-large`**.
    *   **Rationale:** Previous experiments confirmed that pre-trained Transformers outperform LSTMs (Cite solution_lesson_node_00022). While "Base" models have performed well (Cite solution_lesson_node_00029), "Large" models offer superior reasoning capacity for subtle preference judgments. The previous failure of the "Large" model was due to underfitting caused by resource constraints (Cite solution_lesson_node_00027), which I will address via specific training techniques (Gradient Accumulation).
*   **Siamese Input Structure:** The model will process two parallel branches sharing weights:
    *   **Branch A:** `[CLS] Prompt [SEP] Response A [SEP]`
    *   **Branch B:** `[CLS] Prompt [SEP] Response B [SEP]`
    *   **Rationale:** This Siamese approach is strictly superior to Cross-Encoders for this task because it avoids the aggressive truncation required to fit `Prompt + Resp A + Resp B` into a single context window, ensuring the model accesses the full content (Cite solution_lesson_node_00023).
*   **Structural Innovation: Disentangled Hierarchical Pooling:**
    *   I will implement a dual-stream pooling strategy that synthesizes the strengths of **Response-Isolation** (Cite solution_lesson_node_00025) and **Multi-Layer Concatenation** (Cite solution_lesson_node_00033), while preserving the context signal.
    *   **Stream 1 (Response Content):** For each branch, apply a binary mask to zero out `Prompt` tokens. Extract the hidden states from the **last 4 layers**. Apply independent **Learned Attention Pooling** (Cite solution_lesson_node_00011) to each layer and **concatenate** the results. This yields a deep, multi-scale response vector that preserves fine-grained hierarchical signals without the "layer averaging" loss (Cite solution_lesson_node_00033).
    *   **Stream 2 (Prompt Context):** Simultaneously, apply a binary mask to zero out `Response` tokens. Extract the **final hidden layer only** and apply Learned Attention Pooling. Average the resulting vectors from both branches to obtain a robust context vector $P$.
    *   **Rationale:** Lesson 25 showed that including the prompt in the main difference vector dilutes the discriminative signal. However, the *criteria* for a good response depend on the prompt. By extracting $P$ separately and concatenating it to the final representation, we allow the classifier to condition its judgment on the prompt type without polluting the comparative features $|R_A - R_B|$.
*   **Hybrid Classification Head:** The final feature vector will be a concatenation of:
    *   **Response Interaction:** $R_A, R_B, |R_A - R_B|, R_A \cdot R_B$ (Derived from the high-fidelity multi-layer streams).
    *   **Context Modulation:** $P$ (The explicit prompt vector).
    *   **Explicit Scalars:** Log-transformed lengths of Prompt, Response A, and Response B (Cite solution_lesson_node_00004).

# Data: Full Dataset with Symmetric Augmentation

*   **Dataset:** Train on the **Full Training Set** (approx. 41k samples). Do not downsample; data volume is the primary driver of performance (Cite solution_lesson_node_00015).
*   **Symmetric Augmentation:** Double the effective dataset size by creating a swapped copy $(B, A)$ with target $1-T$ for every pair $(A, B)$. This enforces permutation invariance and provides the model with a robust, balanced signal (Cite solution_lesson_node_00029).
*   **Preprocessing:**
    *   **Tokenization:** Use the `deberta-v3-large` tokenizer.
    *   **Feature Consistency:** Compute scalar length features from the **tokenized sequences** to ensure mathematical consistency with the encoder inputs (Cite solution_lesson_node_00005).
    *   **Sequence Length:** Set max length to **512 tokens per branch**. Truncate the Response if necessary, but **always preserve the full Prompt** to ensure the context vector $P$ is accurate (Cite solution_lesson_node_00013).

# Training: Gradient Accumulation for Large Model Convergence

*   **Strategy:** To solve the underfitting issue observed in Lesson 27, I will decouple the physical batch size from the logical batch size.
    *   **Gradient Accumulation:** Set the physical batch size to fit within the A100's memory (e.g., 2 or 4) but accumulate gradients over multiple steps to achieve a **Target Effective Batch Size of 64**. This ensures stable optimization dynamics comparable to smaller models.
*   **Efficiency:** Enable **Gradient Checkpointing** to minimize activation memory, allowing the "Large" model to fit. Use **Mixed Precision (FP16)** for throughput.
*   **Optimization:** Use **AdamW** with a conservative learning rate (e.g., 5e-6) and a linear warmup schedule.
*   **Loss Function:** Standard Cross-Entropy Loss (Log Loss) on the soft probability targets.

# Evaluation: Robust Inference

*   **Test-Time Augmentation (TTA):** For every test instance, predict on both $(A, B)$ and $(B, A)$. Average the resulting probabilities (flipping the winner for the swapped pair) to produce the final prediction. This neutralizes any residual positional bias (Cite solution_lesson_node_00029).
*   **Pipeline:** Preprocess test data into Siamese pairs, extract scalar features, pass through the Disentangled Hierarchical model, and apply Softmax.
