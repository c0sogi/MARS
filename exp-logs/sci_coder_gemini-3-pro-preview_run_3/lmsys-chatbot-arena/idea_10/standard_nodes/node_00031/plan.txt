The implementation strategy for `runfile.py` is as follows:

1.  **Setup & Configuration**: Initialize the environment using `Config.setup()` and `seed_everything()`. Crucially, override `Config.epochs` to 1 and ensure `Config.debug` is `False`. This ensures the model trains on the full dataset to achieve a competitive score while finishing within the "fast baseline" time constraints (approx. 30-45 mins for 1 epoch on A100).
2.  **Data Preparation**: Utilize `get_dataloaders(load_cached_data=True)` to efficiently load the pre-processed training, validation, and test datasets.
3.  **Model Initialization**: Instantiate the `SiameseDeberta` model and move it to the GPU.
4.  **Training Loop Construction**: Replicate the optimizer (`AdamW`), scheduler (linear warmup), and `GradScaler` setup from `engine.py`. Execute a training loop for 1 epoch, calling `train_one_epoch` for optimization and `validate` for monitoring. The best model state (lowest validation loss) is saved to disk.
5.  **Evaluation & Failure Analysis**: Load the best model and compute the final validation metric, printing it with high precision. Manually iterate through the validation loader to retrieve ground truth targets and input scalar features (log-transformed lengths). Compute the per-sample log loss (error magnitude) and calculate its Pearson correlation with the input features to identify failure modes.
6.  **Conditional Submission**: Compare the final validation log loss against the specified threshold (`1.0005665522536111`). If the metric is lower, generate predictions for the test set using `predict` (which applies Test-Time Augmentation) and save the results to `submission.csv`.
