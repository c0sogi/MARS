Implementation Strategy:
1.  **Configuration Setup**: Initialize the `Config` class with parameters optimized for a quick demonstration (e.g., reduced epochs, specific batch size, limited vocabulary size).
2.  **Component Verification (Unit Tests)**:
    *   **Tokenizer**: Instantiate a `Tokenizer`, fit it on sample text, and verify that text-to-sequence conversion and save/load functionality work correctly.
    *   **Model Architecture**: Instantiate the `DeepAveragingNetwork`. Create dummy input tensors matching the expected shapes and perform a forward pass to verify the output shape (logits for 3 classes).
3.  **Pipeline Execution (Integration Test)**:
    *   **Training**: Execute `engine.run_training` using the configured parameters. This will process the real metadata, train the model for one epoch, and save the checkpoint.
    *   **Inference**: Execute `engine.generate_submission`. This will load the saved model, predict on the test set, and generate the submission CSV.
4.  **Output Validation**: Load the generated submission file to verify its dimensions and content format against the requirements.
