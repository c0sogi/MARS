### Model
I propose a **Deep Averaging Network (DAN)** architecture. This approach serves as a lightweight neural baseline that sits between linear models and heavy Transformer architectures.
*   **Embedding Layer:** The model utilizes a trainable, dense embedding layer that maps token indices to continuous vector representations. This layer is shared across the Prompt, Response A, and Response B inputs to ensure a consistent feature space.
*   **Encoder (Global Average Pooling):** Instead of using complex recurrence (RNNs) or attention mechanisms (Transformers), the model computes the unweighted average of the word embeddings for each input sequence. This results in three fixed-size dense vectors representing the Prompt ($v_p$), Response A ($v_a$), and Response B ($v_b$).
*   **Interaction & Classification:** These three vectors are concatenated into a single feature vector. To explicitly assist the model in comparing the responses, the element-wise difference ($v_a - v_b$) is also included in the concatenation. This combined vector is fed into a Feed-Forward Neural Network (MLP) with non-linear activation functions (e.g., ReLU) and Dropout for regularization. The final layer projects the features to 3 output logits corresponding to the classes: Winner A, Winner B, and Tie.

### Data
*   **Vocabulary Building:** Construct a vocabulary from the training corpus by identifying the top $N$ (e.g., 20,000 to 50,000) most frequent tokens. Tokens can be determined via simple whitespace splitting and punctuation removal. Rare words are mapped to a generic "unknown" token.
*   **Tokenization & Indexing:** Convert the raw text of the Prompt, Response A, and Response B into sequences of integer indices based on the built vocabulary.
*   **Padding/Truncation:** Fix a maximum sequence length (e.g., 512 or 1024 tokens) to handle the variance in text length. Sequences longer than this limit are truncated, and shorter ones are padded with a designated padding token (which is masked out during the averaging operation).

### Training
*   **Loss Function:** Use **Cross-Entropy Loss** to minimize the divergence between the predicted probability distribution and the ground truth labels (which are soft probabilities in this dataset).
*   **Optimizer:** Utilize the **Adam** optimizer, which is standard for training neural networks, with a standard learning rate (e.g., 1e-3 or 1e-4).
*   **Regularization:** Apply **Dropout** within the MLP layers to prevent overfitting, given the high dimensionality of the concatenated embeddings relative to the simple averaging mechanism.
*   **Batching:** Train using mini-batches to ensure stable gradient updates and efficient GPU utilization.

### Evaluation
*   **Inference:** For each sample in the test set, preprocess the text using the same vocabulary and truncation rules as training. Pass the tokenized inputs through the trained network.
*   **Prediction:** Apply the **Softmax** function to the output logits to generate a valid probability distribution summing to 1 for the three target classes (Winner A, Winner B, Tie). These probabilities are formatted directly for submission.
