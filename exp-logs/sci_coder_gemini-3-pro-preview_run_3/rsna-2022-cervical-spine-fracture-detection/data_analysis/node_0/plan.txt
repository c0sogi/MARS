This script performs an Exploratory Data Analysis (EDA) on the RSNA Cervical Spine Fracture Detection dataset. It analyzes the target variable distributions, checks for label consistency, and examines the image data properties (volume depth, file sizes) by scanning the directory structure. It also attempts to extract DICOM metadata if the library is available, handling the environment constraints gracefully. Finally, it explores relationships between the extracted meta-features (like scan depth) and the fracture targets.
