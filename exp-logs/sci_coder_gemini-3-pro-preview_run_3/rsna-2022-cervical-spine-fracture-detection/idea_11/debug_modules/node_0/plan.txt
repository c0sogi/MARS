This script demonstrates the end-to-end usage of the provided machine learning pipeline for cervical spine fracture detection. It performs the following steps:

1.  **Configuration Setup**: Overrides default `Config` parameters (image size, slice depth, batch size) to create a lightweight execution environment suitable for a quick demonstration.
2.  **Data Preparation**: Selects a small subset of the training metadata to create temporary training and validation sets.
3.  **Preprocessing**: Runs the `preprocess_and_cache` function to convert raw DICOM series into preprocessed 3D numpy arrays stored in a temporary cache.
4.  **Dataset Verification**: Instantiates the `CervicalSpineDataset`, retrieves a sample, and asserts that the output tensor shapes and data types are correct.
5.  **Model & Loss Verification**: Instantiates the `CervicalMILModel` and `ImplicitlyWeightedMultiTaskLoss`, performs a forward pass with dummy data, and verifies the output shape and loss calculation.
6.  **Training Loop**: Runs the `Trainer` for a single epoch on the subset data to demonstrate the training workflow and artifact saving.
7.  **Metric Verification**: Validates the competition metric calculation logic using synthetic ground truth and predictions.
