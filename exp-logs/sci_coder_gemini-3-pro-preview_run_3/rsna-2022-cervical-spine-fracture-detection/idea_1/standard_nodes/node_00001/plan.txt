Here is the implementation strategy and the complete `runfile.py` script.

### Implementation Strategy

1.  **Configuration & Setup**: Initialize the environment using `Config.setup()` and `seed_everything()` to ensure reproducibility. We override `Config.EPOCHS` to a smaller number (5) to ensure the baseline runs quickly within the time limit.
2.  **Training**: Execute the training pipeline using `library.train.run_training`. This handles data loading, model optimization, and saving the best checkpoint based on validation loss.
3.  **Validation & Metric Calculation**:
    *   Load the best saved model and the validation dataset.
    *   Perform inference to get probabilities for C1-C7.
    *   Derive the `patient_overall` probability as the maximum of C1-C7 probabilities.
    *   Calculate the **Weighted Multi-label Logarithmic Loss** as specified. We assign a weight of 1.0 to each vertebra and 7.0 to the `patient_overall` label to reflect the higher importance described in the task.
    *   Print the `Final Validation Metric` with full precision.
4.  **Failure Analysis**:
    *   Calculate the loss contribution for each sample in the validation set.
    *   Compute Pearson correlations between the sample loss and the ground truth labels (e.g., `patient_overall`) to identify if positive cases are systematically harder to predict.
    *   Print these correlations.
5.  **Submission**: Call `library.inference.generate_submission` to generate predictions for the test set and save them to `submission.csv`.
