I will implement the optimization strategy based on **Lesson 00005 (Optimizing Differentiable Aggregates for Hierarchical Metrics)**. The core issue with the previous solution was that the model was trained only on subtype labels (C1-C7), while the evaluation metric heavily weights the `patient_overall` label (derived via max-pooling). This disconnect caused the model to produce high false positives on subtypes, which propagated to the overall prediction, ruining the score.

My strategy involves:
1.  **Dataset Modification**: Updating `FractureDataset` to return the `patient_overall` label alongside the C1-C7 labels during training and validation.
2.  **Loss Function Optimization**: Modifying the training loop in `library/train.py` to use a **compound loss function**. This loss will be the sum of the standard BCE loss on subtypes and a BCE loss on the aggregated `patient_overall` prediction (computed as the differentiable `max` of subtype logits). This forces the model to learn that predicting a fracture on *any* vertebra implies the patient is fractured, calibrating the max-pooled output.
3.  **Evaluation Update**: Adjusting the validation routine in `runfile.py` to handle the updated target format (8 columns instead of 7).
4.  **Hyperparameters**: Increasing epochs to 15 to allow for convergence with the new objective.
