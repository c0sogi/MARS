# Proposed Baseline Solution: 2.5D Stacked-Slice CNN with Max-Pooling Aggregation

## Model
The proposed architecture is a **Weakly Supervised 2.5D Convolutional Neural Network** designed to operate on study-level labels without requiring dense slice-level annotations.

1.  **Input Representation (2.5D Stacking)**: To capture local volumetric context without the computational cost of 3D convolutions, the model treats the input as a 3-channel 2D image. These channels correspond to three consecutive axial slices ($z-1, z, z+1$). This allows the 2D CNN to detect fracture features that persist or evolve across adjacent slices.
2.  **Backbone**: A lightweight **ResNet-18** (pretrained on ImageNet) serves as the feature extractor. This choice prioritizes inference speed and convergence stability over deeper, heavier models like EfficientNet or ResNet-50.
3.  **Slice-Level Classifier**: The backbone feeds into a fully connected layer that outputs 7 probabilities (corresponding to vertebrae C1 through C7) for *each* input stack.
4.  **Aggregation (Max-Pooling MIL)**: To generate a prediction for the entire exam, the model applies a **Global Max Pooling** operation across the predictions of all processed slice stacks. The logic follows a Multiple Instance Learning (MIL) assumption: if the model predicts a high probability of a C1 fracture on *any* single slice stack, the entire study is classified as having a C1 fracture.
5.  **Patient Overall Prediction**: The `patient_overall` probability is derived as the maximum probability among the 7 vertebrae predictions, ensuring logical consistency.

## Data
1.  **Slice Selection**: To reduce I/O overhead and processing time, the model will not process every slice. Instead, it will **uniformly subsample** a fixed number of slices (e.g., 64) from the scan volume. This provides sufficient coverage of the cervical spine while keeping memory usage constant.
2.  **Preprocessing**:
    *   **Windowing**: DICOM pixel values will be converted to Hounsfield Units (HU) and windowed specifically for bone structures (e.g., Center: 300, Width: 2000). This enhances the contrast of fractures while suppressing soft tissue.
    *   **Normalization**: Windowed values will be normalized to the range [0, 1].
    *   **Resizing**: Images will be resized to a standard resolution of **256x256** pixels to minimize GPU memory footprint.
    *   **Stacking**: For every selected slice $z$, the input image is formed by concatenating slices $z-1$, $z$, and $z+1$.

## Training
1.  **Loss Function**: A **Weighted Binary Cross-Entropy (BCE) Loss** will be used. Weights will be assigned to the positive classes for specific vertebrae (e.g., C3, C4) to counteract their low prevalence (class imbalance) observed in the dataset statistics.
2.  **Weak Supervision**: The model is trained using only the study-level labels provided in `train.csv`. The Max-Pooling aggregation allows gradients to backpropagate from the study-level label to the specific slice stack that contributed the maximum score, effectively teaching the model to localize fractures without explicit bounding boxes.
3.  **Optimization**: The model will be optimized using **Adam** with a standard learning rate (e.g., 1e-4) and a cosine annealing scheduler to ensure convergence within the limited runtime.

## Evaluation
1.  **Inference Pipeline**: For each test exam, the system will load the volume, apply the same uniform subsampling (64 slices) and preprocessing (bone windowing, resizing, stacking) as used in training.
2.  **Prediction Aggregation**: The model will predict C1-C7 probabilities for every sampled stack. The final submission row for each vertebra will be the maximum probability observed across all stacks in that exam.
3.  **Consistency**: The `patient_overall` prediction will be calculated as the maximum of the final C1-C7 probabilities for that exam.
