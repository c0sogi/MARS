The implementation strategy focuses on creating a self-contained script that overrides the default configuration to ensure rapid execution while verifying the functionality of all provided library components.

1.  **Configuration Override**: We will modify the `Config` class attributes at runtime. We will enable `DEBUG` mode, reduce `EPOCHS` to 1, `BATCH_SIZE` to 4, and `SEQ_LEN` to 16. This ensures the code runs within seconds/minutes rather than hours.
2.  **Data Loading**: We will instantiate the dataloaders using `get_dataloaders` and fetch a single batch to assert that the input tensor shapes `(Batch, Seq, 3, H, W)` and label shapes `(Batch, 8)` are correct.
3.  **Model Verification**: We will instantiate `SequenceSmoothedMIL` (forcing `pretrained=False` for the unit test to avoid potential network issues, although the training loop uses the default) and perform a forward pass to verify the output logits shape.
4.  **Loss & Metric**: We will compute the `HierarchicalCompoundLoss` on the dummy batch and calculate the `competition_log_loss` on synthetic numpy arrays to ensure the mathematical components function as expected.
5.  **Training Loop**: We will call the high-level `train_model` function. Since we modified the global `Config`, this function will execute a very short training run on a subset of data and save a model checkpoint. We will verify the existence of this checkpoint.
6.  **Inference Setup**: We will initialize the test dataloader to demonstrate readiness for the inference phase.
