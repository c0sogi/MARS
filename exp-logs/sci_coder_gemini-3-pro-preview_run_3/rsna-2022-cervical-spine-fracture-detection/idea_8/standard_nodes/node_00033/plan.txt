Implementation strategy:
1.  **Setup & Initialization**: Initialize the environment using `Config.setup()` and set random seeds for reproducibility. Define the computation device.
2.  **Data Preparation**: Instantiate the DataLoaders for training, validation, and testing using `get_dataloaders()`. The loaders will automatically handle caching and preprocessing.
3.  **Model Configuration**: Initialize the `BoxGuidedMILModel` with a pretrained ResNet18 backbone and move it to the GPU. Configure the AdamW optimizer.
4.  **Training Loop**: Execute the training process using the provided `fit()` function. I will limit training to 5 epochs to ensure the "fast baseline" requirement is met while still allowing the model to learn from the small dataset.
5.  **Validation & Metric Calculation**: After training, load the best saved model state. Perform a manual inference pass on the validation set to calculate the `Final Validation Metric` (Weighted Log Loss) with full precision.
6.  **Failure Analysis**: Compute the per-sample loss on the validation set. Calculate the Pearson correlation coefficient between the error magnitude and two features: fracture presence (`patient_overall`) and scan depth (number of slices). This identifies if the model struggles with positive cases or complex scans.
7.  **Conditional Submission**: Compare the final validation metric against the threshold `0.12231192492082398`. If the metric is lower, create the `./submission` directory, update the submission path configuration, and run the `inference()` function to generate the `submission.csv`.
