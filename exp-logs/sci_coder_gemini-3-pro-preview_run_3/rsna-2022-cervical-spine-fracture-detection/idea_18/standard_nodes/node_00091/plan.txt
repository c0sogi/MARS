The `CUDA out of memory` error is caused by the model's architecture processing a large number of slices (64) for each patient. With a batch size of 8, the backbone receives an effective batch of $8 \times 64 = 512$ images, exceeding the GPU's memory capacity (Cite debug_lesson_10). To fix this, I will reduce the `BATCH_SIZE` to 2 in `library/config.py` and implement Automatic Mixed Precision (AMP) in `library/engine.py` using `torch.cuda.amp`. This combination will significantly reduce memory usage by handling fewer patients per step and using lower precision for activations where possible.

        model: The PyTorch model.

        loss_fn: The loss function.
        device: The device to train on.

        float: Average training loss.
    """

    running_loss = 0.0
    dataset_size = 0

        inputs = inputs.to(device, non_blocking=True)
        targets = targets.to(device, non_blocking=True)

        optimizer.zero_grad()

        # Forward pass with AMP

            loss = loss_fn(logits, targets)

        dataset_size += batch_size
