Implementation Strategy:
1.  **Configuration Setup**: Import the `Config` class and override key parameters (e.g., `EPOCHS`, `BATCH_SIZE`, `BAG_SIZE`, `DEBUG`) to ensure the demonstration runs quickly and uses a minimal subset of data.
2.  **Utility Verification**:
    *   Test `window_dicom` with a synthetic numpy array to verify correct normalization and clipping.
    *   Test `get_weighted_log_loss` with synthetic ground truth and prediction DataFrames to ensure the metric calculation logic is correct.
3.  **Dataset Verification**:
    *   Load the pre-generated training metadata.
    *   Instantiate `CervicalSpineDataset` with the training metadata.
    *   Retrieve a single sample to verify the shape and data types of the output tensors (`bag_images`, `bag_positions`, `targets`).
4.  **Model Verification**:
    *   Instantiate the `AnatomicallyGuidedResNet` model.
    *   Create dummy input tensors matching the shapes observed in the dataset verification.
    *   Perform a forward pass and verify that the output shape corresponds to the expected logits (Batch Size, 8).
5.  **Training Pipeline Execution**:
    *   Invoke `run_training` from `library.engine` with `debug=True`. This will run a short training loop (1 epoch on a small subset) using the overridden configuration.
6.  **Inference Pipeline Execution**:
    *   Invoke `inference` from `library.engine` using the model checkpoint generated during the training step.
    *   Verify that a submission file is created.
